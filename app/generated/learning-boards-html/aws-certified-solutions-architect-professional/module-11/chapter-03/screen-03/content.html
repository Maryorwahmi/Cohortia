Module 11 › Chapter 11.3 › Practice Objectives
Hands-on outcomes
  • Create LongLivedStaticAssetsPolicy and ShortLivedAPICachePolicy and attach them to behaviors.
  • Enable Brotli and Gzip for static content and confirm your origin is not double compressing.
  • Build a Global WAF Web ACL, test rules in Count mode, and then switch to Block when safe.
  • Tune origin settings like custom headers, connection and response timeouts, and enable Origin Shield when needed.
  • Use CloudWatch metrics and CloudFront access logs to trace low cache hit ratios back to cache key parameters or short TTLs.
Mnemonic
Think: Key + TTL + Forwarding = Cache behavior. Tune these three to control hit ratio, correctness, and origin load.
