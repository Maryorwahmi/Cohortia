Definition › Advanced Origin Settings
Custom Headers
Add a header like X-CloudFront-Verify with a shared secret so the origin can verify requests originate from CloudFront.
Use Origin Access Control for S3 origins alongside headers for stronger protection.
Connection & Response Timeouts
Tune how long CloudFront waits to connect and to receive a response from the origin. Longer timeouts help slow backends; shorter timeouts fail fast and free edge resources.
Origin Shield
Enable Origin Shield to route origin requests through a Regional Edge Cache, reducing origin traffic for multiple distributions or high miss rates.
Key Takeaway

Combine custom headers for verification, tuned timeouts for reliability, and Origin Shield to minimize origin load when appropriate.
