Comparison › Cache Key Design
Headers
Include when the response changes by header, for example localization headers. Avoid including broad headers that vary per client.
Query Strings
Include only query params that change resource content; ignore tracking parameters that create unnecessary variants.
Cookies
Only include cookies that affect content. Never include per-session cookies like session IDs or auth tokens in the cache key.
Concrete scenario
A site uses ?v= for cache busting. Exclude this parameter from the cache key for image assets if you serve versioned filenames; include it only if the parameter truly alters content.
Key Takeaway

Measure and include only the request parameters that produce different responses. Use logs and metrics to validate the effect on cache hit ratio.
