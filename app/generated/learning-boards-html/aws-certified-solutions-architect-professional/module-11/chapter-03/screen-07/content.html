Definition › Origin Request Policies
What they do
Specify which headers, query strings, and cookies CloudFront forwards to the origin on a cache miss.
  • Forward for logging or origin-side logic without changing cache key behavior.
  • Keep cache key minimal while giving origin necessary context.
  • Common forward: User-Agent, X-Forwarded-For, specific query args needed for origin routing.
Example scenario
Static assets: minimal cache key (no headers), but forward User-Agent and a custom header X-Client-Meta for server logging and analytics when CloudFront needs the origin.
Misconception check: forwarding many headers requires including them in the cache key — not necessarily; you can forward them separately to avoid cache fragmentation.
Key Takeaway

Use origin request policies to give the origin what it needs while keeping the cache key lean for better reuse.
