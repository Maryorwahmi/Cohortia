Summary › Key Concepts
Cache Policy
Defines TTLs and cache-key parameters that govern caching behavior.
Origin Request Policy
Controls which headers, cookies, and query strings are forwarded to the origin on misses.
Compression (Gzip/Brotli)
Edge compression reduces bandwidth; Brotli typically offers better ratios for text assets.
Summary takeaway

Design cache keys carefully, forward only what the origin needs, enable edge compression for static text assets, and use monitoring to validate your configuration.
