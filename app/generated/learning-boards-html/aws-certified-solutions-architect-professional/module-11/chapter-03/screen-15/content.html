Minimize Cache Keys
Only include parameters that change the response.
Forward Only Needed Data
Use Origin Request Policies to forward headers/cookies/query strings without enlarging the cache key.
Protect & Monitor
Attach WAF at the edge and use CloudWatch and access logs to iterate on rules and policies.
Final takeaway

Balancing cache key design, forwarding needs, compression, and edge security is how you maximize performance and minimize origin cost and risk.
