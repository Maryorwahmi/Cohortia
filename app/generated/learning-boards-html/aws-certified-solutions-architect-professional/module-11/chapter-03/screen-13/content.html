Hands-on Activity › Create cache policies & WAF
Part 1: Create Cache Policies
  1. Create LongLivedStaticAssetsPolicy with Min 86400, Default 2592000, Max 31536000, no headers/cookies/query strings, enable Brotli/Gzip.
  2. Create ShortLivedAPICachePolicy with Min 0, Default 300, Max 300, include Authorization and Accept headers if response varies, include query strings as needed.
Tip: name policies clearly so you can reuse them across behaviors and distributions.
Part 2: Attach Behaviors & WAF
  1. Create behavior for /assets/* and attach LongLivedStaticAssetsPolicy and an appropriate origin request policy.
  2. Create behavior for /api/v1/* and attach ShortLivedAPICachePolicy; use HTTPS-only viewer policy.
  3. Create Global WAF Web ACL, add managed rule sets in Count mode, associate with distribution, then monitor and switch to Block when safe.
Misconception check: Do not forward or include per-session cookies in static asset cache keys.
Key Takeaway

Deploy targeted policies for different content types, attach behaviors with correct origin forwarding, and validate using CacheHitRatio and WAF logs.
