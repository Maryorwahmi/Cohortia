Example caution
Always fetch and patch the existing config; using the ETag prevents race conditions. Enable compression on the behavior that serves static assets and ensure the cache policy enables Accept-Encoding flags if required.
Key Takeaway

Follow a fetch-modify-update pattern and validate the updated behavior in a staging distribution before applying to production.
