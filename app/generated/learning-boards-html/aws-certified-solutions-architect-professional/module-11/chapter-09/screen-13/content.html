Activity: Signed URLs for Private Content
Follow this ordered checklist to configure and validate signed URL delivery.
Part 1 — Prepare S3
Create a private bucket, upload premium-video.mp4, and block public access.
Part 2 — Create CloudFront
Create distribution with S3 origin, enable OAC, Redirect HTTP to HTTPS, Restrict viewer access, and create a new trusted key group.
Part 3 — Manage keys
Generate RSA key pair locally; upload the public key to CloudFront and add to your key group.
Part 4 — Sign & test
Run the Python script to generate a signed URL, open it in the browser, then verify expiry and direct origin denial.
Reflection
Decide whether signed URLs or signed cookies better suit streaming scenarios that need multiple resource requests without changing URLs.
