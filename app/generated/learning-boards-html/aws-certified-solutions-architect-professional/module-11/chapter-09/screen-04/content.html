Definition: Multi‑tier and CDN roles
How the presentation, application, and data layers map to caching and edge behavior.
Presentation (static)
Versioned assets in S3 are ideal for CloudFront with long TTLs to maximize edge caching and reduce origin requests.
Application (dynamic)
APIs behind ALB or API Gateway can be fronted by CloudFront to improve connection performance and optionally partial cache.
Data (origin)
Databases stay behind the origin; caching decisions should never sacrifice data correctness.
Key Takeaway

Map caching policies to tier mutability and personalization: long TTLs for versioned static assets, short/conditional caching for dynamic data.

Example architecture card
E‑learning example
Static course pages and assets in S3 with OAC; CloudFront caches them with long TTLs. API calls for user progress routed to ALB via CloudFront with short caching or no caching where personalization is required.
Common misconception
Believing CDNs only help static files. In practice, a CDN reduces latency for dynamic cache misses and can compress and optimize responses.
