Module 11 › Chapter 11.9 › Edge Compute
CloudFront Functions
Ultra-fast, small payloads, ideal for rewrites and header tweaks.
Use cases
URL normalization, security header injection, lightweight A/B routing.
Characteristics
Very low latency and cost, but limited runtime and no external network calls in some contexts.
Lambda@Edge
More compute and flexibility for heavier logic at the edge.
Use cases
Complex authentication, personalization that requires external calls, or A/B experiments with server-side variation.
Characteristics
Greater capability but higher cold‑start risk and larger deployment footprints.
Decision guide
If latency is critical and the logic is small, choose Functions. If you need external calls or complex logic, choose Lambda@Edge.
