Layered Security Pattern
Edge protections plus origin controls create a resilient security posture.
Edge: AWS WAF
Block common web exploits and apply rate limits at CloudFront.
DDoS: Shield
Protect high‑value endpoints with additional DDoS mitigation.
Origin: OAC & Signed URLs
Restrict S3 access and grant short, verifiable access for private content.
Example flow
WAF blocks bad requests, CloudFront applies signatures and caching, origin denies direct access through OAC, signed URLs grant temporary playback rights.
