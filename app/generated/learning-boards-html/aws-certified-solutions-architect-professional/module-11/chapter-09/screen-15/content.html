Module 11 › Chapter 11.9 › Operational Reminders
What to Remember
Three concise cards with configuration reminders.
Origin Access Control
Ensure S3 is private and CloudFront is the only allowed principal for object retrieval.
Edge runtime choice
Prefer CloudFront Functions for tiny, high‑speed transformations; use Lambda@Edge for complex tasks.
Global routing
Use Global Accelerator for path optimization and Route 53 for DNS routing policies and failover.
Final takeaway
Balance caching, security, edge compute, and global routing to deliver fast, secure, and resilient multi‑tier applications.
