Module 11 › Chapter 11.9 › Caching Strategy
Cache Policy Design
Choose TTLs and what to include in the cache key to balance freshness and hit rate.
Immutable naming
Embed a content hash in filenames so you can use long TTLs safely.
Cache key
Avoid forwarding cookies and unnecessary headers for static assets — keep keys small to increase cache reuse.
Edge compression
Enable Gzip/Brotli at the edge to reduce bandwidth for text assets.
Key Takeaway

Combine versioned filenames with long TTLs and tightly scoped cache keys for optimal static delivery.

Concrete example
GET /static/app.2a7f.js
Cache-Control: max-age=31536000, public
CloudFront TTL: 31536000 (1 year)
Origin: S3 (OAC enforced)
Common mistake
Changing files in place without versioned names leads to stale cached content across edge locations.
