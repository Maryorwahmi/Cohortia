Python Signed URL Example
A complete local signing flow using an RSA private key and CloudFront signer.
Key steps
  1. Generate RSA key pair locally and keep private key secure.
  2. Upload public key to CloudFront and add to a trusted key group.
  3. Use a Python script to sign a URL with an expiration timestamp.
  4. Test signed URL access and verify direct origin denies requests.
Security reminders
  • Never embed the private key in client apps.
  • Rotate keys and update key groups when needed.
  • Use OAC so signed URLs control CloudFront access while S3 remains private.
Reference script
import datetime
from botocore.signers import CloudFrontSigner
from cryptography.hazmat.backends import default_backend
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.asymmetric import padding

CF_DOMAIN = "d1234abcd.cloudfront.net"
KEY_PAIR_ID = "K123ABCDEF4567"
PRIVATE_KEY_PATH = "private_key.pem"
OBJECT_PATH = "premium-video.mp4"
EXPIRES_AT = datetime.datetime.now() + datetime.timedelta(minutes=5)

def rsa_signer(message):
  with open(PRIVATE_KEY_PATH, 'rb') as key_file:
    private_key = default_backend().load_rsa_private_key(
      key_file.read(),
      password=None
    )
  return private_key.sign(message, padding.PKCS1v15(), hashes.SHA1())

cloudfront_signer = CloudFrontSigner(KEY_PAIR_ID, rsa_signer)

signed_url = cloudfront_signer.generate_presigned_url(
  f"https://{CF_DOMAIN}/{OBJECT_PATH}",
  date_less_than=EXPIRES_AT
)

print(f"Generated Signed URL:
{signed_url}")
print(f"URL expires at: {EXPIRES_AT}")
