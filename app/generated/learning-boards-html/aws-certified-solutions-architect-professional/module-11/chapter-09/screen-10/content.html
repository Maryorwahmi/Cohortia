When to use Global Accelerator
Optimize network entry and provide static IPs for critical or non‑HTTP traffic.
Use cases
  • Gaming, VoIP, and custom protocols that need low jitter and static IPs.
  • Critical APIs that need the fastest possible traversal of the AWS backbone.
  • Multi‑region active‑active setups that require quick failover.
How it complements CloudFront
CloudFront caches and serves HTTP content; Global Accelerator optimizes the path to regional load balancers and doesn't cache content.
Example
Use Global Accelerator for a game's real‑time matchmaking API and CloudFront for the game's website and static assets.
Mistake
Confusing Global Accelerator with a CDN — it improves routing but does not cache.
