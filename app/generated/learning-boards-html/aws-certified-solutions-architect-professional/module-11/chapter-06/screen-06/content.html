Module 11 › Chapter 11.6 › Forwarding Rules
Rule anatomy
  • Domain name: the name or suffix to match, e.g., corp.local.
  • Rule type: FORWARD to send queries externally.
  • Resolver endpoint ID: ties the rule to an outbound endpoint.
  • Target IPs: on‑prem DNS server addresses that will receive the forwarded query.
Example mapping
A rule named OnPremDomainForwarding maps domain corp.local with target IP 10.0.0.10 and references the outbound endpoint ID so queries for corp.local leave via that endpoint.
Troubleshooting tips
  • Verify the domain string exactly matches the on‑prem namespace you intend to forward.
  • Confirm target IPs are reachable over the chosen connectivity and allowed by SGs and route tables.
  • Check that the rule is associated with the correct outbound endpoint ID.
Common mistake

A typo in the domain or target IP often causes queries to fail silently; always test end‑to‑end and capture logs if available.
