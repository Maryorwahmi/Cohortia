Resolver Endpoints
Availability & Security
  • Place ENIs in at least two subnets/AZs for HA.
  • Security groups must allow UDP/TCP 53 only from trusted sources.
  • Ensure routing and Direct Connect/VPN connectivity is configured to carry DNS traffic.
Key Takeaway

Treat resolver endpoints as network services: document, secure, and make them highly available across AZs.

Security group example rules
Allow inbound UDP and TCP on port 53 from on‑prem CIDRs and allow outbound to on‑prem DNS IPs. Deny wider access to reduce attack surface.
Operational notes
  • Monitor forwarded query failures and endpoint health.
  • Document which domains are forwarded and why.
  • Automate creation of endpoints across subnets for repeatable HA deployments.
