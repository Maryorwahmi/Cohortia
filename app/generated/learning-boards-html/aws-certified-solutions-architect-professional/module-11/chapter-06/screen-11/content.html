Module 11 › Chapter 11.6 › Lab Walkthrough
Prerequisites
  • VPC with two subnets in different AZs and a test EC2 instance.
  • Security group permitting UDP/TCP 53 from VPC CIDR and on‑prem ranges.
  • Private hosted zone with a test record associated with the VPC.
Execution steps
  1. Create outbound endpoint across two subnets and record the resolver endpoint ID.
  2. Create forwarding rule mapping onprem.corp.local to the on‑prem DNS IP.
  3. Create inbound endpoint and record its ENI IPs for conditional forwarders.
  4. Test with dig from EC2 and conceptually validate on‑prem forwards to inbound IPs.
Example test
On EC2: run dig onprem.corp.local and observe whether the query is forwarded via the outbound endpoint. If the target IP is mock, the path still verifies the forwarding configuration.
Reflection
Which component would fail first if Direct Connect were missing? Consider where packets need to traverse to reach on‑prem DNS or the inbound endpoint IPs.
