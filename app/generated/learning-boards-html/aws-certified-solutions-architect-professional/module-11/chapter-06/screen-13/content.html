Module 11 › Chapter 11.6 › Key Concepts
Resolver Inbound Endpoint
Provides IP addresses your on‑prem DNS servers forward to so they can resolve AWS private hosted zone names.
Conditional Forwarding
Configure on‑prem DNS to forward only the private AWS domain suffix to the inbound endpoint IPs.
Elastic Network Interface (ENI)
ENIs created by resolver endpoints provide the IP addresses used for inbound and outbound DNS traffic; distribute them across AZs for HA.
Final takeaway

Hybrid DNS requires explicit endpoints, forwarding rules, and network design; ensure connectivity, security, and AZ distribution to avoid resolution outages.
