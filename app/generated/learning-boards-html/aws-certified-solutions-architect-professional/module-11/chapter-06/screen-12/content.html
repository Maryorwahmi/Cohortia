Module 11 › Chapter 11.6 › Key Concepts
Route 53 Resolver
The VPC DNS server that resolves public names, AWS‑provided names, and private hosted zone records associated with the VPC.
Resolver Outbound Endpoint
ENIs in a VPC that act as egress points to forward VPC queries to on‑premises DNS servers.
Forwarding Rule
A rule that maps a domain to target IPs and ties to an outbound endpoint to forward queries outside the VPC.
Summary

Remember the three pieces: resolver answers local names, outbound endpoint sends queries out, and forwarding rules decide which names go where.
