Validation tasks
  • Create endpoints in at least two subnets in different AZs for HA.
  • Set security groups to allow UDP/TCP 53 to and from expected sources.
  • Use dig or nslookup to confirm queries take the expected path and return results.
Common checks
Connectivity
Ensure Direct Connect or VPN is up for resolver traffic to cross.
Security groups
Confirm port 53 is allowed and sourced correctly.
Test prompt
After creating endpoints and rules, run a query for the target domain and observe whether the response is authoritative or indicates a forward failure.
