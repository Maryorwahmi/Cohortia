Module 11 › Chapter 11.6 › Learning Objectives
01 • VPC Resolver
Explain the default VPC resolver behavior for public, AWS‑provided, and private hosted zone names.

Knowing the default lets you decide when endpoints are required to cross environment boundaries.

02 • Hybrid DNS
Understand why hybrid DNS is necessary and the two resolution directions it must handle.

This helps you identify the right endpoint type for each use case.

VERIFIED COMPETENCY MILESTONE
03 • Outbound Endpoints
Configure outbound endpoints and forwarding rules so VPC resources resolve on‑prem domains.

Focus on subnet distribution, security group rules, and the domain‑to‑IP mappings in rules.

VERIFIED COMPETENCY MILESTONE
04 • Inbound Endpoints
Configure inbound endpoints and set conditional forwards on on‑prem DNS servers to reach private hosted zones.

You’ll learn how to capture the endpoint IPs and add them to on‑prem conditional forwarders.
