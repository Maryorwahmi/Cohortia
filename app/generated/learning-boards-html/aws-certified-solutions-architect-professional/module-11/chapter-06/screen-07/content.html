Module 11 › Chapter 11.6 › Inbound Endpoints
How it works

Create inbound endpoint with ENIs in multiple subnets. Capture the IP addresses assigned to those ENIs. Configure your on‑prem DNS server to conditionally forward the AWS private domain to those IPs. The inbound endpoint then relays queries to the VPC resolver and returns answers to on‑prem clients.

Example
Create an InboundToAWS endpoint and register its two IPs on your on‑prem DNS conditional forwarder for internal.prod.mycompany.com so on‑prem servers can resolve test.aws.private names.
Operational checklist
  • Record inbound endpoint IPs after creation.
  • Configure on‑prem conditional forwarder to those IPs for the private domain.
  • Allow UDP/TCP 53 from on‑prem CIDRs in the inbound endpoint security group.
Key Takeaway

Inbound endpoints are the on‑prem facing targets that allow conditional forwarding into AWS private hosted zones.
