Module 11 › Chapter 11.2 › Assessment scenario and reasoning
Scenario

Personalized web app served behind an ALB, static assets on S3. Session cookie determines per-user content; static assets are identical across users.

Recommended config
  • /personal/* → ALB origin, forward specific session cookie, short TTL.
  • /static/* → S3 origin, no cookies/headers forwarded, long TTL.
Why this works

Separating behaviors keeps personalization correct while preserving cache efficiency for shared static content.

Key Takeaway

Articulate which request fields must vary responses and restrict forwarding to those fields to keep cache hits high.
