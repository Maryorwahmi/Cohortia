Module 11 › Chapter 11.2 › Cache policy mechanics and TTLs
TTL definitions
  • Minimum TTL: the shortest time CloudFront will keep an object before considering revalidation.
  • Default TTL: the caching time used when the origin provides no cache-control headers.
  • Maximum TTL: a ceiling on caching regardless of origin headers.
Example choices

Image assets: min 3600s, default 86400s, max 31536000s. API responses: min 0s, default 60s, max 300s. Adjust based on update cadence.

Common mistake

Setting TTLs uniformly high for everything causes stale dynamic content. Conversely, setting TTLs too low removes caching benefits and increases origin load.

Key Takeaway

Choose TTLs based on how often content changes. Use low TTLs for dynamic data and long TTLs for stable static assets.
