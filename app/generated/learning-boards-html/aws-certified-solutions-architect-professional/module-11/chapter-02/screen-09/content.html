Module 11 › Chapter 11.2 › Hands-on: Deploy a static site with CloudFront and OAC
Lab steps (summary)
  1. Create an S3 bucket and upload index.html and an image.
  2. In CloudFront, create a Web Distribution and choose the S3 bucket as the origin.
  3. Select "Yes, use OAC" and create a new Origin Access Control; copy the generated bucket policy.
  4. Set viewer protocol policy to Redirect HTTP to HTTPS and default root object to index.html.
  5. Apply the provided bucket policy to the S3 bucket to restrict direct access and wait for distribution deployment.
  6. Confirm the CloudFront domain shows the site and direct S3 URLs are denied.
index.html (example)
<!DOCTYPE html>
<html>
<head>
  <title>My CloudFront Site</title>
  <style>body{font-family:Arial;text-align:center;margin-top:50px}</style>
</head>
<body>
  <h1>Welcome to My Global Site!</h1>
  <p>Delivered by Amazon CloudFront.</p>
  <img src="logo.png" alt="Logo" width="200">
</body>
</html>
Key Takeaway

Follow the OAC-provided bucket policy to ensure CloudFront alone can read S3 objects and prevent direct public access.
