Module 11 › Chapter 11.2 › Security: HTTPS, ACM, and Origin TLS
Viewer security

Use ACM certificates for your custom domain and set CloudFront viewer protocol policy to Redirect HTTP to HTTPS or HTTPS Only to guarantee encrypted viewer connections.

Why it matters
HTTPS protects user data in transit and is required for many browser features and security expectations from users and compliance regimes.
Origin security

Configure CloudFront to use HTTPS for origin connections when possible, and for S3 use Origin Access Control so the bucket allows reads only from your distribution.

Common mistake
Assuming HTTPS to viewers is enough. If the origin is publicly readable or origin connections are unencrypted, content or credentials may be exposed.
Key Takeaway

Use ACM for viewer TLS, enforce HTTPS, and use OAC or TLS to origin to protect both viewer and origin legs of delivery.
