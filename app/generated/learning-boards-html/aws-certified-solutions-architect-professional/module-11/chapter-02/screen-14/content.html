Module 11 › Chapter 11.2 › Key Concepts
Amazon CloudFront
A global CDN that caches content at edge locations for low latency and reduced origin load.
Distribution & Cache Behavior
A distribution defines origins and behaviors. Cache behaviors map path patterns to specific origins and caching rules.
Security & OAC
Use HTTPS for viewers, TLS to origin where possible, and Origin Access Control to restrict S3 access to CloudFront distributions.
Summary

Design distributions by balancing performance, correctness, and security: cache aggressively where safe, forward only necessary fields, and lock origin access with OAC.
