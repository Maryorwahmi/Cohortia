Module 11 › Chapter 11.2 › Learning Objectives — Applied Skills
Objective clusters
Design cache behaviors. Map path patterns to origins and set viewer protocol and allowed methods correctly for each behavior.
Create custom cache policies. Configure TTL windows and choose which headers, query strings, and cookies to forward to keep content correct without poisoning cache efficiency.
Secure origin access. Implement OAC for S3 and enforce HTTPS for both viewer and origin connections to prevent data leakage.
Test and verify. Deploy a static site, check the CloudFront URL, and confirm direct S3 access is denied after applying the OAC-provided bucket policy.
Competency check
Apply
Create a distribution that serves static assets from S3 with long TTLs and an API path that forwards specific cookies and uses a short TTL.
Verify
After deploying, confirm content returned by CloudFront is correct and that direct S3 requests are blocked.
