Module 11 › Chapter 11.2 › Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Explain CloudFront
Describe how edge caching, distributions, and origins accelerate content delivery and reduce origin load. This knowledge helps you decide when to use a CDN for performance.
VERIFIED COMPETENCY MILESTONE
02
Differentiate Distributions
Choose the right distribution type and origin: S3 for static assets, custom HTTP for dynamic APIs or media packagers. This reduces design mistakes during rollout.
VERIFIED COMPETENCY MILESTONE
03
Configure Origins
Set up S3 or custom HTTP/HTTPS origins and understand origin domain, bucket policies, and TLS to origin. Correct origin setup avoids accidental public exposure.
VERIFIED COMPETENCY MILESTONE
04
Apply Cache Policies
Create cache policies with appropriate TTLs and forward only necessary headers/cookies to keep content correct and cache-efficient.
VERIFIED COMPETENCY MILESTONE
More objectives
05
Enforce HTTPS
Use ACM certificates and viewer protocol policies to enforce HTTPS and protect data in transit.
VERIFIED COMPETENCY MILESTONE
06
Use OAC for S3
Implement Origin Access Control to ensure only CloudFront can fetch S3 objects and prevent public S3 reads.
VERIFIED COMPETENCY MILESTONE
07
Optimize Cache Key
Forward only needed headers, query strings, and cookies. Over-forwarding reduces cache hit ratio dramatically.
VERIFIED COMPETENCY MILESTONE
08
Use Compression
Enable Gzip or Brotli to reduce payload sizes and improve transfer speeds to viewers.
VERIFIED COMPETENCY MILESTONE
