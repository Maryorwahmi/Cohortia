Module 11 › Chapter 11.2 › What is Amazon CloudFront?
Definition

CloudFront is a CDN that caches content at edge locations worldwide. It routes viewer requests to the nearest edge location, serving cached objects when available and retrieving them from the origin when not.

How it works
  • Viewer requests content.
  • CloudFront routes to nearest Edge Location.
  • If cached, serve directly; otherwise fetch from origin and cache.
Concrete example
An image in an S3 bucket is requested by users worldwide. CloudFront caches a copy at an edge region and serves it to subsequent viewers without contacting the S3 origin each time.
Key Takeaway

CloudFront reduces latency by delivering cached content from edge locations; your cache choices determine freshness and origin load.

Common misconception

Assuming any cache means no origin load. In practice, cache misses and inappropriate TTLs can still generate significant origin traffic. Configure TTLs and cache keys to avoid unexpected origin requests.
