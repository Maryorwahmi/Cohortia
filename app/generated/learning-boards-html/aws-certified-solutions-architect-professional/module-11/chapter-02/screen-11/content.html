Module 11 › Chapter 11.2 › Compression and performance optimizations
Compression choices
Enable Gzip or Brotli in CloudFront so compatible browsers receive compressed responses. Text assets benefit most: HTML, CSS, JS, JSON, and SVG.
Pre-compress vs runtime
If your build pipeline produces compressed files, serve pre-compressed assets from the origin. Otherwise enable CloudFront compression at delivery time.
Combine with caching
Compressed static assets should have long TTLs and be served from S3 origin with aggressive caching. Dynamic endpoints should avoid long TTLs even if compressed.
Key Takeaway

Compression reduces payloads; pair it with sensible cache policies so compression benefits are consistent and cost-effective.
