Module 11 › Chapter 11.2 › Common mistakes and safety notes
Frequent pitfalls
  • Overly long TTLs for dynamic content causing stale data.
  • Leaving S3 publicly readable instead of implementing OAC.
  • Forwarding everything (headers/cookies/query strings) and destroying cache efficiency.
  • Not enforcing HTTPS for viewers or origin connections.
Monitoring and remediation
Watch cache hit ratios, origin request rates, and latency. When issues appear, verify TTLs, cache key composition, OAC status, and whether the origin itself is slow.
Action

Run an audit: confirm OAC is applied, check TTLs per behavior, and review what you forward in the cache key.
