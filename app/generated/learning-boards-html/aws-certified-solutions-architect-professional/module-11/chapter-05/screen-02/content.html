Learning Objectives
A Bloom progression prepares you to explain, configure, monitor, and design Route 53 solutions.
01
Explain Route 53 and its global DNS network

Describe how Route 53 resolves names globally and why distribution reduces lookup latency. This matters for predictable DNS performance.

Verified Competency Milestone
02
Configure advanced routing policies

Set weighted, latency-based, geolocation and geoproximity rules to direct users to the optimal endpoints for performance or regulatory needs.

Verified Competency Milestone
03
Implement DNS health checks and failover

Use health checks and calculated checks to monitor endpoints so Route 53 can fail over automatically when needed.

Verified Competency Milestone
04
Design private hosted zones and Alias usage

Associate private hosted zones with VPCs for internal DNS, and prefer Alias records for AWS resources to reduce costs and automate updates.

Verified Competency Milestone
