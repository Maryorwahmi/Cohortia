Alias Records vs CNAME and TTL Strategy
Choose record types and TTLs to balance manageability, cost, and failover speed.
Alias records
Prefer for AWS resources. Alias records map to AWS resource DNS names, track underlying IP changes, and avoid extra DNS query charges.
CNAME records
Use for non-AWS targets or when Alias is not available. Remember CNAMEs have restrictions at the zone apex and can carry additional lookup costs.
TTL considerations
  • • Short TTLs (e.g., 60s) enable fast changes but increase DNS query workload and cost.
  • • Long TTLs reduce queries but delay propagation of updates or failover.
  • • Use shorter TTLs during deployments, then lengthen when stable.
Key Takeaway

Pick Alias for AWS targets and choose TTLs to balance responsiveness with DNS query cost.
