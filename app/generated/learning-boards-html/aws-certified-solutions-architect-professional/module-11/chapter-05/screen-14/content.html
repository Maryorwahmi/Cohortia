Key Concepts
Three compact concept cards to remember.
Amazon Route 53
A highly available, globally distributed authoritative DNS web service.
Hosted Zone & Record Set
A hosted zone contains record sets that map domain names to IPs or other DNS names.
Routing Policies
Rules like weighted, failover, latency, geolocation, and geoproximity that shape DNS responses.
Summary

These concepts form the foundation for designing resilient, performant DNS with Route 53.
