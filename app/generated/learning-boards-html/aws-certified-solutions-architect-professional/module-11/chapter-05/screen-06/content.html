Failover Routing and DNS Health Checks
Configure active-passive failover with tuned health checks and calculated checks.
How to use failover
  • • Mark primary record as primary and add a secondary record as the failover target.
  • • Attach a health check to the primary so Route 53 can detect failure.
  • • Optionally attach health checks to the secondary and use calculated checks to combine multiple signals.
Example
Primary ALB in us-east-1 with HTTP health check; secondary ALB in us-west-2 used automatically when primary fails configured checks.
Tuning and pitfalls
Aggressive checks: too short intervals can cause false failovers during transient issues.
Lenient checks: too many failures required can delay failover and increase downtime.
Calculated checks: combine multiple endpoints for composite health decisions.
Key Takeaway

Use health checks to drive failover, and test thresholds to balance sensitivity and stability.
