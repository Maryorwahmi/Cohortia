Hands-on: Weighted Routing with Health Checks
Follow the four parts to simulate blue/green deployment and failover using Route 53.
Part 1 — Mock endpoints
• Create two S3 buckets and upload index.html with distinct messages.
• Enable static website hosting and record endpoint URLs.
Part 2 — Health checks
Create HTTP health checks for each endpoint and choose test-friendly intervals and failure thresholds.
Part 3 — Weighted records
• Create two weighted records for the same name, weights 90 and 10.
• Associate health checks and set a short TTL during testing.
Part 4 — Test and simulate failover
Access the domain repeatedly to observe distribution; disable one endpoint to trigger health check-based failover and validate behavior.
Reflection

Use this lab to build intuition for DNS timing, TTL behavior, and health check sensitivity before applying similar patterns in production.
