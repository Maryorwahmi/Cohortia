Private Hosted Zones and VPC Integration
Provide internal DNS names only resolvable inside associated VPCs and connected networks.
How to use private zones
• Create a private hosted zone and associate it with the VPCs that need internal resolution.
• Use custom names for internal services, avoiding public exposure.
• For hybrid environments, connect on-prem networks and use the private zone for consistent naming.
Example
Create my-internal-app.corp.local and associate with prod VPCs; internal services resolve by name while public DNS remains unchanged.
Pitfalls and patterns
Over-association: avoid associating private zones with VPCs that should not see internal names.
Split-horizon: maintain separate private and public zones for same domain carefully to avoid record conflicts.
Key Takeaway

Use private hosted zones for secure internal naming and associate them only with the VPCs that require access.
