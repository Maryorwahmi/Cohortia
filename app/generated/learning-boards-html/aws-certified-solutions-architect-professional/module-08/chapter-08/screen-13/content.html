Module 8 › Chapter 8.8 › Common Mistakes
Avoid These Pitfalls
  • • No stop conditions or weak alarms.
  • • No stated hypothesis to compare against.
  • • Overly broad IAM permissions for FIS.
  • • Running tests only in staging that doesn't match production.
  • • Poor communication with operations and stakeholders.
  • • Skipping post-experiment analysis and validation of fixes.
  • • Treating a single run as conclusive instead of iterating.
Avoid risk
Start small and escalate scope only after verifying behavior.
Key Takeaway

Design conservative experiments, instrument them well, and iterate with fixes and re-tests to build confidence safely.
