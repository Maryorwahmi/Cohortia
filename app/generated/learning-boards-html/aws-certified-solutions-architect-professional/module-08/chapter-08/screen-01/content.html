Chaos Engineering and Resilience Testing
Proactive fault injection to validate system steady state and improve resilience
This lesson teaches the hypothesis-driven method, safety practices, and how AWS Fault Injection Simulator (FIS) helps create repeatable, automated chaos experiments with stop conditions and defined blast radius.
In this lesson
Form hypotheses, design safe experiments, and use FIS to inject faults like instance termination or CPU stress.
Coming up
Hands-on template walkthrough, stop condition patterns, and interpretation of experiment results.
