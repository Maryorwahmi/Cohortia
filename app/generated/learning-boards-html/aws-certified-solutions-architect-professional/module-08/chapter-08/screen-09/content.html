Module 8 › Chapter 8.8 › Design Experiment
Step-by-step Plan
1. Prepare
Tag instances, ensure IAM instance profiles, and activate monitoring dashboards.
2. Alarm
Create a CloudWatch alarm such as StatusCheckFailed_Instance or ALB 5XX to use as a stop condition.
3. Role
Create FISExperimentRole with AWSFISServiceRolePolicy and least privilege.
  1. Create an FIS experiment template targeting PERCENTAGE(50) or PERCENTAGE(25) of tagged WebApp instances.
  2. Add action aws:ec2:terminate-instances and map it to the target.
  3. Attach the CloudWatch alarm ARN as a stop condition and select the FIS role.
  4. Notify teams, then start the experiment and observe EC2, ALB, and CloudWatch.
Example Observation
If instances terminate and auto-scaling takes too long, you'll see increased 5XX errors and the alarm may stop the experiment.
Key Takeaway

Follow the plan: prepare, limit blast radius, monitor, and communicate to keep experiments safe and informative.
