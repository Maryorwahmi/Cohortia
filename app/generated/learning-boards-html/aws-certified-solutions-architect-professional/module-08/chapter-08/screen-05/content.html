Iterate
  • • Define the steady state using measurable metrics before injecting faults.
  • • Choose realistic faults that reveal how components interact under stress.
  • • Automate actions and observation so results are repeatable and auditable.
  • • Always include stop conditions and a rollback strategy to prevent escalation.
Example Configuration
Hypothesis: The web tier will maintain acceptable latency when 25% of instances are terminated. Design: Target 25% of tagged web instances, action terminate-instances, stop on ALB 5XX alarm. Automation: Use an FIS template tied to an IAM role with least privilege. Safety: Start in dev, then increase scope gradually.
Common Mistake
Skipping the hypothesis makes results hard to interpret — always state what you expect to observe.
Key Takeaway

Principles guide safe experiments: hypothesis, realistic faults, automation, stop conditions, and limited blast radius.
