# Runbook: High CPU remediation (conceptual)
- Preconditions: CPU > 80% for 5m on instance group service-A
- Step 1: Collect metrics and top process list
- Step 2: Notify channel with snapshot and link to logs
- Step 3: If CPU sustained and process known, restart serviceA
- Step 4: Monitor for 2 minutes; if unchanged, escalate to playbook owner
Design checklist
  • Document preconditions and expected outputs.
  • Start with read-only diagnostics, then add cautious remediations.
  • Include rollback steps and human confirmation for risky actions.
Measure runbook effectiveness by how often it resolves incidents without human escalation and refine using post-mortem data.
