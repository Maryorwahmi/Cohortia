Module 9 › Chapter 8.9 › Hands-on Activity
Steps
  1. Create Slack channel: #aws-ops-alerts.
  2. Create SNS topic: CriticalAppAlerts and note ARN.
  3. Create CloudWatch alarm for CPUUtilization > 80%, action: publish to SNS.
  4. Configure AWS Chatbot: authorize Slack, attach SNS topic, and assign a least-privilege IAM role.
  5. Test by setting alarm state to 'In alarm' or generating CPU load, then verify Slack receives the alert.
  6. Clean up created resources after testing.
Terminal Demo Snippet
# Example: manually set alarm state (conceptual)
aws cloudwatch set-alarm-state --alarm-name HighCPUAlarmForDemo \
  --state-value ALARM --state-reason "Testing Chatbot alert"

# Example: run a quick CPU stress on EC2 (optional test)
sudo yum install -y stress && stress --cpu 1 --timeout 600
Reminder: use the manual alarm state option for safe testing in demos rather than stressing production instances.
