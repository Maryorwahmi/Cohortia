Definition

Systems Manager Incident Manager

A capability that centralizes incident data and automates notifications, runbooks, and escalations to accelerate response.
Automated actions: create incidents, notify responders, execute runbooks.
Sources: CloudWatch, EventBridge, Security Hub.
Benefits: consistent escalation, reduced manual coordination, faster MTTR.
