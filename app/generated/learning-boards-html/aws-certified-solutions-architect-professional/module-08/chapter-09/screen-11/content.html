Comparison

Symptom vs Root Cause

Symptom
Service restarted to clear high CPU.
Root Cause
New release increased memory usage; load tests didn’t cover peak traffic.
Using 5 Whys — short example
  1. Why did the service crash? Out of memory.
  2. Why out of memory? New feature increased allocations.
  3. Why not caught? Load test scenarios did not include this traffic profile.
  4. Why missing? No requirement to update load testing after feature changes.
  5. Root fix: update CI policies to require load-test updates for feature changes.
