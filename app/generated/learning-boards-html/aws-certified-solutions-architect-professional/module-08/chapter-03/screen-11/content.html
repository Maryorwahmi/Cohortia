End-to-End Pipeline Timeline
A predictable timeline clarifies latency and processing windows from generation through archival and analysis.
1. Generate
Application logs, container stdout, and Lambda logs are produced with structured fields for service and environment.
2. Collect
CloudWatch Agent, logging drivers, and native Lambda integration send logs to CloudWatch or directly to Firehose.
3. Ingest
Firehose buffers, compresses, and writes to S3 and/or OpenSearch.
4. Process & Analyze
S3 triggers Lambda for processing, Athena for ad-hoc SQL over archives, and OpenSearch for dashboards.
Latency notes
  • Firehose buffer window adds delivery delay.
  • Lambda adds processing delay after S3 write.
  • Athena queries run on archived batches; not for real-time alerts.
Key Takeaway

Map timeline components to your alerting and compliance windows to choose buffering and retention parameters.
