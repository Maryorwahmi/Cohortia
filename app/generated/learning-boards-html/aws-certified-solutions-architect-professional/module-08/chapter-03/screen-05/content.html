Process Flow
Log Collection: EC2, Containers, Lambda
EC2
Install and configure the CloudWatch Logs Agent to tail files, apply multiline parsing for stack traces, and tag events with service and environment.
Containers
Use container logging drivers or a sidecar like Fluentd to forward stdout/stderr. Ensure log rotation and backpressure are handled to avoid container OOMs.
Lambda
Lambda writes to CloudWatch Logs natively. Use subscription filters to route those logs into Firehose or OpenSearch for downstream use.
Common mistakes
  • No multiline parsing for stack traces.
  • Insufficient IAM permissions for agents.
  • Uncontrolled debug-level logging at scale.
Pro tip

Add structured fields like service, instance_id, and environment to every log entry so you can filter and visualize reliably in OpenSearch and Athena.

Key Takeaway

Choose collectors that match compute types and always handle multiline, permissions, and sampling to avoid noisy pipelines.
