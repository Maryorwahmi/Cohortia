Operationalizing and Monitoring the Logging Pipeline
Key metrics
  • Firehose delivery success and buffer age.
  • S3 put object counts and sizes.
  • OpenSearch CPU, disk, and search latency.
Alerts & checks
  • Alert on failed deliveries and high error rates.
  • Synthetic logs: verify end-to-end every 5–15 minutes.
  • Monitor agent heartbeats to detect outages.
Security
  • Use least-privilege IAM roles and VPC endpoints where needed.
  • Encrypt data at rest in S3 and OpenSearch.
Key Takeaway

Operational checks and synthetic tests keep your logging pipeline reliable; monitor both delivery and search health and track costs regularly.
