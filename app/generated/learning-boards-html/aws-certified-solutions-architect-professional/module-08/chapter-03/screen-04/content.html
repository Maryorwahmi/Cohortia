Core Concept
What is Centralized Logging?
Aggregating logs from applications and infrastructure into a consistent pipeline for analysis and retention.
Why it matters

Helps teams find root causes quickly and supports compliance through central retention and auditability.

Migration example

Tail legacy files with Fluentd on EC2, send to Kinesis Firehose, deliver compressed archives to S3 and recent data to OpenSearch.

Common misconception

Centralization does not require self-managed search: managed AWS services reduce operational overhead.

Architecture cards
Collection
Agents, container drivers, native Lambda logs.
Ingestion
Kinesis Firehose for streaming, batching, and delivery.
Storage & Analytics
S3 for archive, OpenSearch for search and dashboards.
Key Takeaway

Centralization reduces operational friction and enables both fast search and inexpensive long-term storage.
