Sending Test Logs to Firehose
Use the AWS CLI to put records into an active Firehose stream to validate delivery and S3 archiving.
Example CLI commands
aws firehose put-record \
  --delivery-stream-name MyAppLogsToS3 \
  --record '{"Data": "{\"timestamp\": \"2023-10-27T10:00:00Z\", \"level\": \"INFO\", \"service\": \"web-app\", \"message\": \"User logged in: user-123\"}
"}'

aws firehose put-record \
  --delivery-stream-name MyAppLogsToS3 \
  --record '{"Data": "{\"timestamp\": \"2023-10-27T10:01:05Z\", \"level\": \"ERROR\", \"service\": \"payment-service\", \"message\": \"Failed to process payment for order-ABC\"}
"}'

aws firehose put-record \
  --delivery-stream-name MyAppLogsToS3 \
  --record '{"Data": "{\"timestamp\": \"2023-10-27T10:02:30Z\", \"level\": \"DEBUG\", \"service\": \"data-processor\", \"message\": \"Batch job started for report-XYZ\"}
"}'
What to verify
  • Confirm objects appear under the S3 prefix after buffer interval.
  • Check the Firehose delivery stream metrics for Put record success.
  • Inspect the error_logs/ prefix for failed records and permission issues.
Misconception check

Firehose will not automatically transform complex logs: use a Lambda transform for lightweight parsing if needed.
