Comparison
S3 Archive vs OpenSearch Indexing
S3 (Archive)
Low-cost, durable storage. Ideal for retention and historical analysis with Athena. Use compression and partition prefixes for cost savings.
OpenSearch (Index)
Fast, indexed search and visualization. Best for recent operational queries and dashboards; more expensive per GB.
Patterns
  • Firehose delivers to both S3 and OpenSearch to satisfy search and archival simultaneously.
  • Use index lifecycle and retention policies: keep hot indices short-lived, archive to S3 for older data.
  • Use Athena on S3 for ad-hoc analytics, and OpenSearch for dashboards and alerts.
Practical rule

If you query data frequently and need dashboards, index in OpenSearch; if data is rarely accessed, archive to S3 and query with Athena when needed.
