Definition
Amazon OpenSearch Service for Real-Time Analytics
Managed OpenSearch domains let you index logs and build dashboards to monitor operational health in real time.
Use cases
Search recent errors, visualize latency distributions, and investigate security events with Kibana dashboards.
Sizing & availability
Choose data and master node types, configure EBS storage, and deploy across AZs for resiliency.
Common mistake
Underestimating index storage and query load can cause slow searches; monitor and scale gradually.
Operational checklist
  • Enable VPC access and IAM policies to secure the domain.
  • Plan index lifecycle: hot for recent data, warm/cold or S3 for archives.
  • Use Kibana to build dashboards and saved searches for alerts.
Key Takeaway

OpenSearch delivers fast, ad-hoc operational queries and visualization; plan sizing, storage, and security before indexing production logs.
