Lambda and S3 for Cost-Effective Processing
Trigger Lambda on S3 object creation to extract, transform, and route archived logs without running always-on compute.
Example
Lambda parses a GZIP file, extracts security events, writes a summary to DynamoDB, and sends critical alerts to SNS.
Practical constraints
Monitor object sizes; consider step functions for large jobs and ensure Lambda memory/time limits align with processing needs.
Checklist
  • Give Lambda permission to GetObject from S3 and write to downstream services.
  • Consider compressed file handling and streaming reads.
  • Use retries and dead-letter queues for transient failures.
Key Takeaway

Event-driven Lambda on S3 provides low-cost, on-demand processing for archived logs and supports enrichment and alerting workflows.
