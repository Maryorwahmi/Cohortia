Module 8 › Chapter 8.3 › Technical Outcomes
Collection setup
  • CloudWatch Agent for EC2 logs and custom files.
  • Container drivers or sidecars for ECS/EKS logs.
  • Lambda uses native CloudWatch integration.
Firehose tuning
  • Buffer size and interval trade latency for cost.
  • Compression reduces storage and transfer costs.
  • Multiple destinations: S3 for archive, OpenSearch for search.
Analytics & processing
  • OpenSearch for real-time dashboards and queries.
  • Lambda triggers on S3 for enrichment and alerts.
  • Athena for serverless SQL over archived logs.
