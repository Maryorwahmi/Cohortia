Learning Objectives
Master the end-to-end flow: collection, ingestion, storage, real-time search, and serverless processing.
01
Design a centralized logging architecture
Translate application tiers into a single, secure log pipeline. This skill helps you create a single-pane view for operations and security teams.
VERIFIED COMPETENCY MILESTONE
02
Implement log collection from EC2, containers, Lambda
Configure agents and logging drivers so logs reliably reach CloudWatch or Firehose. Reliable collection reduces blind spots during incidents.
VERIFIED COMPETENCY MILESTONE
03
Use Kinesis Firehose for ingestion and delivery
Leverage Firehose for scaling, batching, compression, and multi-destination delivery to S3 and OpenSearch for efficient pipelines.
VERIFIED COMPETENCY MILESTONE
04
Integrate S3, Lambda, and Athena for processing
Use Lambda to process stored logs and Athena for ad-hoc queries on archive data, enabling both automated reactions and investigative analysis.
VERIFIED COMPETENCY MILESTONE
