Module 8 › Chapter 8.1 › Assessing Operational Excellence
Review questions
• Can the full environment be recreated from versioned templates?
• Are runbooks current, tested, and stored with templates?
• Does CI/CD support single-service rollback and canary testing?
• Are alert thresholds tuned and actionable with documented remediation?
Scenario
Manual security group change caused outage
Assess whether security groups are defined in templates, whether the change would be overwritten on redeploy, and whether alerts would detect the issue before user impact grows.
Action
Prioritize encoding network configuration and adding monitoring alerts as part of the remediation plan.
