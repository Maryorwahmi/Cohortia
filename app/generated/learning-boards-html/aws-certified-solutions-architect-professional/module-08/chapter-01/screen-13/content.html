Module 8 › Chapter 8.1 › Closing the Feedback Loop
Sequence of improvement
Detect
Alerts and monitoring spot anomalies.
Analyze
Blameless post-mortem identifies root cause.
Fix
Update templates, runbooks, and automation.
Verify
Add tests or run drills to confirm the fix.
Concrete example
A post-mortem led to a template update, an alert, and an integration test in CI that triggered during future merges to catch regressions early.
Misconception
Fixes that remain as tickets or runbook notes are likely to be forgotten; encoding them in code and tests makes them permanent.
