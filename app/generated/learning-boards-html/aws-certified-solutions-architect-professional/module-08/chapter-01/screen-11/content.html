Module 8 › Chapter 8.1 › CloudFormation S3 Walkthrough
Template (example)
AWSTemplateFormatVersion: '2010-09-09'
Description: A simple S3 bucket with versioning enabled for operational excellence demo.

Parameters:
  BucketName:
    Type: String
    Description: The name for the S3 bucket. Must be globally unique.
    MinLength: '3'
    MaxLength: '63'
    AllowedPattern: '[a-z0-9]([a-z0-9-]*[a-z0-9])?'

Resources:
  MyOperationalBucket:
    Type: AWS::S3::Bucket
    Properties:
      BucketName: !Ref BucketName
      VersioningConfiguration:
        Status: Enabled
      Tags:
        - Key: Project
          Value: OperationalExcellenceDemo
        - Key: Environment
          Value: Development

Outputs:
  BucketArn:
    Description: The ARN of the newly created S3 bucket.
    Value: !GetAtt MyOperationalBucket.Arn
  BucketNameOutput:
    Description: The name of the S3 bucket.
    Value: !Ref MyOperationalBucket
Steps
  1. Create file s3-bucket-template.yaml and paste the template.
  2. Deploy with aws cloudformation create-stack and pass the BucketName parameter.
  3. Verify stack status until CREATE_COMPLETE, then confirm versioning is enabled in the console.
  4. Update: add a lifecycle configuration to the template and run update-stack to apply a small, reversible change.
  5. Clean up with delete-stack when finished.
Best practice
Use CI to validate templates and run updates in a non-production account before promotion.
