Advanced Feature
Nested Stacks
Compose smaller templates as child stacks for modular architectures.
Reusability
Common infra like network definitions can be reused across projects.
Versioning
Child templates can be updated independently and referenced by TemplateURL from the parent.
Hierarchy Example
NetworkStack
Defines VPC, subnets, and routing. Exports VpcId and PublicSubnetId.
WebServerStack
Consumes network outputs and provisions an EC2 instance with security group.
Master Stack
References both child templates and exposes the application public IP as a master output.
Key Takeaway

Use nested stacks to decompose complexity into logical modules that can be maintained and versioned independently.
