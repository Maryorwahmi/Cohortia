Safety Mechanism
Change Sets
Generate a preview of create/update/delete actions before executing changes on a stack.
What you see
A detailed list of resource-level actions like Add, Modify, Replace, or Remove.
When to use
Before production updates or when changes might replace stateful resources.
Process
1. Create change set
Use CLI or console to create a change set from the proposed template and parameter set.
2. Review details
Inspect adds, deletes, and replacements and assess risk to stateful resources.
3. Approve & execute
After automated checks or sign-off, execute the change set to apply changes.
Key Takeaway

Incorporate change sets into your deployment pipeline to preview and approve resource-level changes before they happen.
