AWS CDK (example)
Define infrastructure with code and synthesize to CloudFormation for deployment.
Why use CDK
Encapsulate patterns as reusable constructs and reduce YAML/JSON boilerplate.
CDK Python example
from aws_cdk import (
  aws_s3 as s3,
  core as cdk
)

class MyS3Stack(cdk.Stack):
  def __init__(self, scope: cdk.Construct, construct_id: str, **kwargs) -> None:
    super().__init__(scope, construct_id, **kwargs)

    s3.Bucket(self, "MyOperationalBucket",
      versioned=True,
      removal_policy=cdk.RemovalPolicy.DESTROY  # For demo, be careful in production!
    )

app = cdk.App()
MyS3Stack(app, "OperationalExcellenceS3Stack")
app.synth()  # Synthesizes into CloudFormation
This code synthesizes to a CloudFormation template that can be reviewed and deployed. Keep synth output under source control in pipelines for review with change sets.
Key Takeaway

CDK helps teams express infrastructure using familiar languages while retaining CloudFormation safety and deployment semantics.
