Learning Objectives
Learn, Understand, Apply, Master
Bloom: Learn → Master
01
Reinforce IaC principles
Define infrastructure as code and store templates in version control to prevent drift and enable rollbacks. This ensures environments remain consistent across teams and time.
VERIFIED COMPETENCY MILESTONE
02
Master CloudFormation
Write declarative JSON or YAML templates that describe AWS resources and let CloudFormation safely create and update them as a single stack.
VERIFIED COMPETENCY MILESTONE
03
Use advanced features
Apply nested stacks, change sets, and custom resources to modularize large deployments, preview updates, and extend functionality with Lambda-backed logic.
VERIFIED COMPETENCY MILESTONE
04
Extend with custom resources
Create custom resource handlers to manage resources not supported natively, enabling consistent provisioning across your stack.
VERIFIED COMPETENCY MILESTONE
