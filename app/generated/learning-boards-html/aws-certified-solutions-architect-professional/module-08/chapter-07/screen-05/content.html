AWS CloudFormation
Declarative stacks and safe orchestration
Templates describe desired state; CloudFormation determines the operations required to achieve it.
Dependency handling
CloudFormation orders resource operations by implicit dependencies between resources and references.
Parameters & Outputs
Parameterize values for environment differences and export outputs to be consumed by nested or separate stacks.
Safety note
Always preview changes with change sets to avoid unintended resource replacement or deletion.
Stack architecture (example)
Network
VPC, subnets, route tables.
Compute
Auto-scaling groups, security groups, EC2 instances.
Data
RDS, S3 buckets, backups.
Example scenario
One template defines a full environment so dev, staging, and prod can be created from the same source.
Key Takeaway
Model full stacks and rely on CloudFormation to orchestrate safe updates.
