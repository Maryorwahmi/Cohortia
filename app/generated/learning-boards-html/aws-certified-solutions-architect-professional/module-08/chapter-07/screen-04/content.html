Core Concept
Infrastructure as Code
Machine-readable definitions, stored in version control, used to provision cloud infrastructure deterministically.
Why it matters
Prevents configuration drift, improves repeatability, and enables automated pipelines and audit trails.
Common misconception
IaC is not a substitute for testing or operations; it's a tool to make those processes safer and faster.
Example
Store CloudFormation templates in Git, run CI checks, and deploy via a pipeline to create identical dev, staging, and prod environments.
Key Takeaway

IaC converts manual infrastructure actions into repeatable, versioned code so teams can test and automate safely.

Illustration: IaC workflow
Author
Write template or construct and commit to Git.
Pipeline
Lint, test, and synthesize templates; create change sets for review.
Provision
Apply changes to create drift-free, versioned environments.
