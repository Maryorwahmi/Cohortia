Module 8 › Chapter 8.2 › Objectives — Verification
Objective verification steps
Short hands-on checks to confirm each capability.
Publish a custom metric
Use CLI or SDK to put-metric-data and confirm the Namespace shows the metric graph.
Create metric math expression
Compute a derived series such as error rate and validate values over a known interval.
Enable anomaly detection
Train a model on the metric and create an alarm with a standard-deviation threshold.
Quick checklist
  • Publish data points and watch the metric stabilize.
  • Derive KPI with metric math.
  • Create composite and anomaly alarms and test with out-of-band values.
