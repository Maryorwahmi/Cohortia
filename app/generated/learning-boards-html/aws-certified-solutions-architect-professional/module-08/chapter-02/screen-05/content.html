Module 8 › Chapter 8.2 › Metric Math
Process
Assemble base metrics and compute derived indicators
Step 1
Identify base metrics
Counts, sums, averages with consistent units.
Step 2
Define math expression
E.g., error_rate = errors / requests.
Step 3
Select period & alignment
Use compatible aggregation types and periods.
Example
Compute error rate from API Gateway's 5XXError and Count metrics: ERR_RATE = m1 / m2. Alert when ERR_RATE crosses a business-relevant threshold.
Expression example
# pseudo-expression used in CloudWatch console m1 = METRIC(\"API/5XXError\", Stat=Sum) m2 = METRIC(\"API/Count\", Stat=Sum) ERR_RATE = m1 / m2
Key takeaway
Metric Math turns low-level telemetry into actionable service indicators to reduce noise and focus alerts.
Pitfall
Avoid dividing sums by averages or combining incompatible statistics; pick aggregation types that reflect your calculation intent.
