Find and aggregate error messages across Lambda streams
Use filters and parse expressions to extract the error text, then group by the message to see frequency and recency.
Sample query
fields @timestamp, @message
| filter @logStream like /my-lambda-function/
| filter @message like /ERROR/
| parse @message "*ERROR: *" as errorMessage
| stats count() as errorCount, latest(@timestamp) as lastSeen by errorMessage
| sort errorCount desc
| limit 20
Why it matters
Logs Insights helps you quickly find the most frequent or recent errors, which speeds incident response and pinpoints the code paths to inspect.
Pro tip
Use parse to extract structured fields from JSON logs and include those fields in stats to get counts by endpoint, user, or request ID.
Key takeaway
Interactive log queries let you triage incidents faster by surfacing the highest-impact errors and their contributing fields.
