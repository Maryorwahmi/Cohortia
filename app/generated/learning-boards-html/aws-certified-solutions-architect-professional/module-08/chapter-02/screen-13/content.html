Module 8 › Chapter 8.2 › Incident Triage
Workflow
Dashboard → Logs Insights → Contributor Insights → Remediate
Confirm scope, identify frequent errors, rank contributors, and then take corrective action with focused code or configuration changes.
Logs Insights example
fields @timestamp, @message
| filter @logStream like /my-lambda-function/
| filter @message like /ERROR/
| parse @message "*ERROR: *" as errorMessage
| stats count() as errorCount, latest(@timestamp) as lastSeen by errorMessage
| sort errorCount desc
| limit 20
Practical example
If Logs Insights shows a single endpoint returning many errors, use Contributor Insights keyed on endpoint to confirm the top offending route and prioritize a rollback or patch.
Key takeaway
Follow a log-driven triage order to quickly pinpoint the root cause and reduce mean time to recovery.
