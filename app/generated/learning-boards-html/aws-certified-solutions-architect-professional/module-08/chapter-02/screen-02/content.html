Learning Objectives
A set of verifiable milestones to confirm you can apply advanced CloudWatch features in production.
01
Publish & interpret custom metrics
Send application KPIs to CloudWatch and use metric math to compute ratios and aggregates.
VERIFIED COMPETENCY MILESTONE
02
Implement composite & anomaly alarms
Combine alarms and use ML-based baselining to reduce false positives.
VERIFIED COMPETENCY MILESTONE
03
Use Logs Insights & Contributor Insights
Run interactive queries and find top contributors during incidents.
VERIFIED COMPETENCY MILESTONE
04
Design dashboards & use Synthetics/RUM
Build multi-account dashboards and monitor with canaries and real-user metrics.
VERIFIED COMPETENCY MILESTONE
