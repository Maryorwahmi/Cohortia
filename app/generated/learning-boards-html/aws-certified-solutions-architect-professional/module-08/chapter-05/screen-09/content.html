Module 8 › Chapter 8.5 › SSM Patch Manager
Patch Manager essentials
Patch baselines
Define which patches are approved for your environments and which should be rejected.
Patch groups and windows
Map instances to groups and schedule maintenance windows to control when patching runs.
Phased rollouts
Apply patches to a small group first, validate, then expand to reduce risk.
Operational checklist
  • Define baselines aligned to security policy.
  • Schedule windows in off-peak times and notify stakeholders.
  • Test patches in staging and roll out gradually.
Key Takeaway

Patch Manager enforces a consistent and auditable patch strategy, but must be paired with testing and phased deployments to avoid disruption.
