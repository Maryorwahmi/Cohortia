AWS Systems Manager
A suite for operational automation and visibility across managed resources.

Agent installed on nodes enabling SSM features and secure communication with the service.

Execute scripts across managed instances securely and collect outputs centrally.
Summary takeaway
Validate agents and permissions, choose the right SSM capability for the task, and codify procedures into Automation documents and OpsCenter runbooks for repeatable, auditable operations.
