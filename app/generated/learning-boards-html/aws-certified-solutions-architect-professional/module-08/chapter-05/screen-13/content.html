Module 8 › Chapter 8.5 › SSM Agent & Hybrid Management
SSM Agent checklist
  • Install the SSM Agent package for your OS.
  • Attach AmazonSSMManagedInstanceCore role to EC2 or use activations for hybrid servers.
  • Verify agent is running (service status) and node appears in Fleet Manager.
  • Test Run Command to confirm communication and permissions.
Hybrid considerations
On-premises servers must register using an activation with Systems Manager and have network paths to the SSM endpoints. Ensure IAM permissions and secure storage of activation credentials.
Key Takeaway

Validate the agent and permissions early. Agent visibility is the gating factor for all SSM automation and remediation workflows.
