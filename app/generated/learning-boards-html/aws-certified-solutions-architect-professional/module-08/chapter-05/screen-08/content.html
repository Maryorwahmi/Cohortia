Module 8 › Chapter 8.5 › Capability Comparison
Run Command — Ad-hoc
Best for diagnostic scripts, quick fixes, or one-time updates. Example: gather df and free outputs during an incident.
State Manager — Continuous
Declare desired state and enforce it periodically to prevent drift. Example: enforce correct Apache config across web tier.
Automation — Orchestration
Chain steps and API calls for multi-step workflows. Example: automated remediation that restarts an instance, validates health, and creates an OpsItem if failure persists.
Decision guide
  1. Is the task one-time or ad-hoc? Use Run Command.
  2. Is it continuous enforcement? Use State Manager.
  3. Is it a sequence of steps or requires branching? Use Automation.
Integration note
Automation documents can call Run Command and reference State Manager compliance as part of a broader runbook. They are complementary, not exclusive.
