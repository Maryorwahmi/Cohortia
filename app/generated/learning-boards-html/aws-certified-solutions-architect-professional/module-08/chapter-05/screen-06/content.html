Module 8 › Chapter 8.5 › Run Command Example
Example command
aws ssm send-command \ --instance-ids "i-0abcdef1234567890" \ --document-name "AWS-RunShellScript" \ --parameters 'commands=["ps aux", "df -h", "free -h", "hostname"]' \ --comment "Gather diagnostics"
Expected outputs
  • Process list for troubleshooting load.
  • Disk usage to check free space before deployments.
  • Memory usage metrics for sizing decisions.
Safety checklist
Test targets first
Run on a single staging instance to validate commands and outputs before fleet-wide execution.
Limit outputs
Choose CloudWatch or S3 destinations carefully and restrict access to sensitive outputs.
Rollbacks and logging
Include idempotent scripts and logging to detect and revert unintended changes.
Key Takeaway

Treat Run Command like any privileged operation: test, log, restrict outputs, and plan rollbacks.
