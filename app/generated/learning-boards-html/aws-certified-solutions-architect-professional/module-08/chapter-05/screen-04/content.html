Module 8 › Chapter 8.5 › What is AWS Systems Manager?
Definition
A collection of capabilities that automate operational tasks, from ad-hoc commands to runbooks, patching, and aggregated operational views.
Why it matters
Reduces manual effort, ensures consistency, and allows architects to codify operations for repeatability and auditability.
Common misconception
SSM does not replace monitoring; it complements monitoring by enabling remediation and configuration enforcement.
Concrete example
After a migration, update a configuration file across hundreds of web servers using a single Run Command that runs a script and stores outputs centrally.
Components (quick view)
Run Command
Remote, secure command execution without SSH/RDP.
State Manager
Enforce and correct desired configuration over time.
Patch Manager
Automated OS and application patching with baselines and windows.
Automation
Runbooks as code to chain multiple SSM and API steps.
Explorer & OpsCenter
Aggregate operational data and manage OpsItems with attached runbooks for centralized response.
Key Takeaway

SSM lets you convert manual operational tasks into auditable automation, improving scale and reducing human error.
