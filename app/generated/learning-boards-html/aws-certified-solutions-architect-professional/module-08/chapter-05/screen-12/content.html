Module 8 › Chapter 8.5 › Lab: Run Command
Step-by-step checklist
  1. Launch EC2 with AmazonSSMManagedInstanceCore role and confirm agent is running.
  2. Verify the instance appears in Fleet Manager as a managed node.
  3. Prepare commands: df -h, free -h, hostname.
  4. Run AWS-RunShellScript targeting the instance and enable output if needed.
  5. Open Command history and review per-instance output.
  6. Terminate the instance when done.
Starter script
df -h free -h hostname
Tips
Use a staging instance for your first run, and secure any S3 output buckets with least privilege.
Key Takeaway

This lab shows how quickly you can gather diagnostics without SSH and why verifying the SSM Agent and permissions first is crucial.
