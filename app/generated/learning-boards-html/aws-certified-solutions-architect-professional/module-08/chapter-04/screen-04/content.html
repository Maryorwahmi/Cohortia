Module 08 › Chapter 8.4 › Event-Driven Architecture
What it is
A pattern where events produced by sources trigger decoupled consumers that implement operational logic.
Key benefits:
  • Reduced polling and lower operational cost.
  • Faster incident response through immediate triggers.
  • Improved resilience via decoupled components.
Concrete example
A scheduled EventBridge rule triggers Lambda to stop non-production EC2 instances at the end of the business day, replacing a manual or polling process.
Common misconception
Asynchronous does not mean unreliable. Use idempotency, retries, and DLQs to ensure predictable outcomes.
Analogy: fire alarm
An alarm is an event that triggers multiple responses. Similarly, an operational event may notify teams, queue tasks, and invoke remediation simultaneously.
Key Takeaway

Identify one manual operational task and ask if it can be replaced by an event source plus a small handler to save time and reduce errors.
