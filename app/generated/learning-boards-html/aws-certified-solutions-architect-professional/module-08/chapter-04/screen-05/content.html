EventBridge routing model
Rules match events and forward them to one or more targets. Use schedule and service-detail patterns for operational automation.
Important operational targets:
  • Lambda for automated remediation and short tasks.
  • SNS for notifications to teams and downstream systems.
  • SQS for buffering when consumers need backpressure.
  • Systems Manager Automation for runbook executions.
Design tip
Keep rules narrow, test with sample events, and prefer SQS when durability and retry control are necessary.
Example rule (EC2 stopped)
{
  "source": ["aws.ec2"],
  "detail-type": ["EC2 Instance State-change Notification"],
  "detail": {
    "state": ["stopped"]
  }
}
This rule matches EC2 instance stopped events and can target multiple consumers.
Common mistake

Treating EventBridge as a durable queue. Use SQS for buffering to avoid lost retries and for backpressure control.
