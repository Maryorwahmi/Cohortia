Module 08 › Chapter 8.4 › Lab Walkthrough
Activity steps
  1. Launch or identify a t2.micro EC2 instance and note its Instance ID. Prefer test accounts.
  2. Create EC2SchedulerLambda (Python) and set environment variables ACTION and INSTANCE_ID.
  3. Attach IAM permissions: ec2:StartInstances, ec2:StopInstances, ec2:DescribeInstances. Use least privilege in production.
  4. Deploy code, test invocation, and review CloudWatch Logs for outcomes.
  5. Create EventBridge scheduled rules to trigger stop and start at chosen times and verify behavior.
  6. Clean up rules, function, and test instance when finished.
Test checklist
Verify instance transitions, CloudWatch logs show function execution, and EventBridge rule metrics indicate invocations. Confirm IAM policy least-privilege before moving to production.
Safety & cleanup

Remove scheduled rules and the Lambda after testing to avoid unintended charges or automated actions. Terminate test instances.
