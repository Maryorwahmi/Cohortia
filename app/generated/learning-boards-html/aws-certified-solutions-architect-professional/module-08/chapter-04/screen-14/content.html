Module 08 › Chapter 8.4 › Key Concepts — Part 2
Amazon SQS
Durable queue for buffering messages and enabling controlled consumer processing with DLQs and visibility timeouts.
AWS Lambda
Serverless compute used to implement remediation, processing, and orchestration logic in response to events.
Idempotency & DLQ
Idempotency ensures repeated processing is safe; DLQs store failed payloads for diagnosis and reprocessing.
Summary: these building blocks — SQS, Lambda, idempotency, and DLQs — are the practical tools that keep event-driven automations safe and observable.
