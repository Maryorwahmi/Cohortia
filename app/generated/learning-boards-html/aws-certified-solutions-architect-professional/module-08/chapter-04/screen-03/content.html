Module 08 › Chapter 8.4 › Learning Objectives — Deep Dive
Demonstrable skills
Each objective now maps to a small verification task you can perform in a lab.
Event mapping
Create a diagram listing sources, schema keys you will match, and intended targets. Verify with sample events.
EventBridge rules
Implement a scheduled rule and a service-detail rule and confirm they invoke target functions on test events.
SNS vs SQS
Deploy an SNS topic with two subscribers and an SQS queue with a consumer to observe fan-out vs buffering behavior.
Lambda resilience
Add retries, idempotency checks, and a dead-letter queue. Trigger failure scenarios and validate message capture.
Verification plan
Each task is small, repeatable, and observable. For example, a scheduled rule triggering Lambda to stop an EC2 instance is verifiable by observing the instance state change and the Lambda log entry.
