Instrument Lambda and set up the X-Ray daemon for EC2 or containers so segments and subsegments are produced and buffered correctly. Small timeline mnemonic shows enable → collect → send.

03
Interpret service maps and traces
Read service map nodes, average times, and drill into trace timelines to locate bottlenecks or errors. A simple annotated map helps memory retention.

04
Combine X-Ray with CloudWatch RUM
Use RUM to locate affected users and X-Ray to find the backend cause, reducing time to root cause for real user issues. A two-circle Venn shows RUM and X-Ray meeting at “end-to-end observability”.
