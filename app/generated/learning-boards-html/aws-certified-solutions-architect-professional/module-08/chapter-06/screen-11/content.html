Hands-on Activity › Lambda X-Ray Lab
Step checklist
  1. Create Lambda function 'XRayDemoFunction' with Python runtime.
  2. Paste the function code that creates subsegments and uses boto3.
  3. Enable Active tracing in Configuration → Monitoring and operations tools.
  4. Invoke the function multiple times to generate traces.
  5. Open X-Ray console → Service map and Traces to inspect results.
Starter code (concept)
import time
import boto3
from aws_xray_sdk.core import xray_recorder

def lambda_handler(event, context):
  time.sleep(0.1)
  with xray_recorder.in_subsegment('process_input'):
    input_data = event.get('key', 'default_value')
    time.sleep(0.05)
  s3 = boto3.client('s3')
  try:
    response = s3.list_buckets()
  except Exception as e:
    xray_recorder.current_subsegment().add_exception(e)
  return {'statusCode':200}
Deploy and test. Use the X-Ray console to verify segments and subsegments appear as expected.
