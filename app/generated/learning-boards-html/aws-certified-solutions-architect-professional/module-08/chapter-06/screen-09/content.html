What RUM captures
  • Page load and resource timings.
  • JavaScript and HTTP errors in the browser.
  • User interaction latency and navigation metrics for SPAs.
  • Session metadata for filtering by browser, device, or geography.

How to use RUM data
Use filters in the RUM console to isolate affected users, then export or cross-reference the time window with backend traces to find root cause.
Example
RUM shows long load times for Chrome users in a region; X-Ray traces reveal a backend query executed only for that route.
Misconception
RUM is not a replacement for server-side tracing; it complements traces by showing actual client impact.
Key Takeaway

RUM tells you which users are affected; X-Ray tells you why. Use both to prioritize fixes that improve actual user experience.
