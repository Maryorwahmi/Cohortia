Lambda Tracing › Active tracing
Enable active tracing
Turn on X-Ray active tracing in the Lambda configuration to capture function segments and common SDK calls automatically.
No daemon required: the Lambda platform handles trace submission.
Add manual subsegments for internal operations you want timed.
Check IAM permissions for xray:PutTraceSegments if traces are not appearing.
Concrete example
A Lambda that lists S3 buckets will show an S3 SDK subsegment. If you wrap a database call in a subsegment, it will appear in the same timeline with its duration and any exceptions recorded.
Pro tip
Use test invocations and the X-Ray console immediately to confirm expected subsegments are present.
Misconception
Active tracing does not automatically instrument every custom operation; add manual subsegments where needed.
Key Takeaway

Lambda active tracing simplifies capture of function timelines; but deliberate subsegments provide the detail you need.
