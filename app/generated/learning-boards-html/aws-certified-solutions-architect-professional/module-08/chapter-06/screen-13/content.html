Synthesis › RUM + X-Ray
Pattern
  1. Use RUM to identify affected sessions and the time window.
  2. Filter RUM by browser/device/region to quantify impact.
  3. Open X-Ray and find traces for the same endpoint within the time window.
  4. Drill into traces to find the slow subsegment and decide the fix.
Concrete scenario
RUM shows 15% slower first contentful paint for European mobile users at 10:15–10:25. Filter sessions in RUM, note the API endpoints called, and inspect X-Ray traces for that endpoint in the same interval. A trace reveals a synchronous DB call adding 300ms; fix options: parallelize calls, cache responses, or optimize the query.
Key Takeaway

Correlate RUM cohorts with X-Ray traces to move quickly from reported symptom to targeted backend optimization.
