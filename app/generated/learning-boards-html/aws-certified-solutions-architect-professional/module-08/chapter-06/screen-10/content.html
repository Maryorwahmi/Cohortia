Comparison › X-Ray vs RUM
X-Ray
  • End-to-end distributed tracing across services.
  • Segments and subsegments show internal timing and errors.
  • Best for backend root-cause analysis.
Example: identify a slow DB query inside a Lambda by inspecting subsegments.
CloudWatch RUM
  • Collects real browser session metrics and errors.
  • Segments by browser, device, and geography.
  • Best for measuring actual user experience and prioritizing fixes.
Example: detect that only Chrome mobile users in a region see slow first contentful paint.
Start with RUM to confirm user impact.
Use X-Ray to find the backend cause.
Combine both for prioritized, effective optimization.
