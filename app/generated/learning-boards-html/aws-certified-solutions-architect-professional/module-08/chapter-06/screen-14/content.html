What to Remember › Key Concepts
Distributed Tracing
Track a single request across services to locate latency and errors precisely.
AWS X-Ray
Collects segments and subsegments, offers service maps and trace timelines for debugging and optimization.
CloudWatch RUM
Collects real browser session metrics and errors so you know which users are impacted.
Takeaway

Use RUM to prioritize affected users and X-Ray traces to find the backend operation to fix — instrumentation and sampling should be intentional.
