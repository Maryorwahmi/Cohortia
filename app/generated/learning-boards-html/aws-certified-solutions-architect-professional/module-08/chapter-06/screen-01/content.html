Performance Monitoring with X-Ray and RUM
Trace requests across services and measure real user experience in the browser to pinpoint root causes.
Why it matters: metrics alone can hide where a request stalls. Tracing shows the exact segment causing latency. RUM shows whether users actually notice the slowness.
Concrete outcome: locate a slow database call shown in X-Ray and confirm affected user sessions in RUM by geography or browser.
In this lesson
Implement X-Ray SDKs, read service maps and trace timelines, run the X-Ray daemon, and add CloudWatch RUM to the client.
