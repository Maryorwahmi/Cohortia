EBS Recommendations
Identify over-provisioned volumes and consider smaller sizes or gp2→gp3 changes to reduce cost. Check IOPS and throughput before resizing.
Example: gp2 100GB with low I/O → gp3 with lower provisioned IOPS for similar performance.
Lambda Memory Tuning
Compute Optimizer tests memory configurations and recommends the memory that minimizes execution duration and cost. Higher memory often means shorter execution time due to more vCPU available.
Example: increasing memory reduces duration, lowering total cost for CPU-bound functions.
