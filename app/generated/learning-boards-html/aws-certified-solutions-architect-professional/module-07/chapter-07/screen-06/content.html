Module 7 › Chapter 7.7 › Compute Optimizer
Definition & Scope
A machine-learning service that analyzes CloudWatch metrics and recommends EC2 instance types, EBS volume right-sizing, and Lambda memory settings to balance cost and performance.
EC2 recommendations consider CPU, memory, network, and storage
EBS recommendations suggest smaller sizes or gp3 for better cost
Lambda recommendations tune memory to reduce duration and cost
Example
Compute Optimizer might recommend moving from m5.large to m6g.medium for improved price-performance. Before migrating, verify application compatibility with the ARM-based Graviton platform.
Confidence Score
A numeric indicator to help you prioritize which recommendations to act on first.
