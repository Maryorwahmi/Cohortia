Module 7 › Chapter 7.7 › Trusted Advisor
Definition
A continuous inspection tool that provides guidance across cost, performance, security, fault tolerance, and service limits, with steps to remediate.
Underutilized EC2 instances — low CPU that suggests downsizing or stop
Idle Load Balancers — ELBs without traffic
Unassociated Elastic IPs — provisioned but unused addresses
Underutilized EBS volumes and old S3 buckets
Example & Guidance
If Trusted Advisor flags many t3.large instances running at 5% CPU, consider resizing to t3.small after verifying memory and disk I/O. Record estimated savings and schedule a maintenance window if needed.
Key Takeaway
Trusted Advisor brings high-level, account-wide signals. Use them as prioritized suggestions and verify before changing production systems.
Common mistake
Ignoring small recommendations because they seem minor; small items add up across many resources.
