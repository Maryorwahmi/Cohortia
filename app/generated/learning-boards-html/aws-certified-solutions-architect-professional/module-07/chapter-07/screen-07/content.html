Module 7 › Chapter 7.7 › EC2 Recommendations
Recommendation Anatomy
  • Suggested type (example: m5.xlarge → m5.large)
  • Platform change (example: m5.large → m6g.medium)
  • Estimated monthly savings
  • Confidence score to prioritize
Guided Example
A recommendation to move to Graviton likely saves cost but requires validating that your application and dependencies run on ARM. Run a staging test and measure CPU, memory, and latency before switching production workloads.
Misconception
Not every recommended platform change is safe to apply without testing. Confidence scores help decide which to pilot first.
