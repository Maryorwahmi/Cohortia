Module 7 › Chapter 7.7 › Key Concepts
AWS Trusted Advisor
Real-time guidance that checks best-practice categories and reports estimated savings and remediation steps.
AWS Compute Optimizer
ML-driven recommendations for EC2, EBS, and Lambda based on historical CloudWatch data.
Right-sizing
Matching instance types, volume sizes, and function memory to actual workload needs to reduce cost.
Summary Takeaway

Use Trusted Advisor for account-wide flags, Compute Optimizer for per-resource ML recommendations, and follow a measurement loop when you apply changes.
