Module 7 › Chapter 7.7 › Cost Optimization Checks
Checklist
  • Underutilized EC2 instances — consider stop or downsize
  • Idle Load Balancers — remove unused ELBs
  • Unassociated Elastic IPs — release unused addresses
  • Underutilized EBS volumes — resize or change type (gp2 → gp3)
  • Old or unused S3 buckets — archive or delete stale data
Concrete Example
Trusted Advisor flagged many t3.large instances with sustained low CPU. After verifying memory and disk patterns, you schedule a maintenance window to resize a sample instance to t3.small, monitor performance for a week, then roll changes if safe.
Why act
Quick wins reduce base spend; treat the results as inputs to longer-term right-sizing and automation campaigns.
