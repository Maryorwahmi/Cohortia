Common mistakes & cost anti-patterns

Know the typical traps and a clear remediation path for each.

Anti-patterns
  • NAT-bound S3 traffic instead of VPC Endpoint.
  • Chatty cross-AZ synchronous replication.
  • Origin-only global delivery without CDN.
  • No monitoring of Data Transfer Out.
Fix pattern
  1. Identify the top-volume flows.
  2. Route to endpoints or cache at the edge.
  3. Replicate data instead of remote reads.
  4. Validate via Cost Explorer and flow logs.
Concrete remediation
If NAT egress is high for S3, add a Gateway VPC Endpoint for S3, update route tables, and monitor NAT data transfer metrics until they drop.
