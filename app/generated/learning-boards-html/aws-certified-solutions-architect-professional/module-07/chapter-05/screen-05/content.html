VPC Endpoints & AWS PrivateLink

Private routing to AWS services or private service endpoints reduces egress and attack surface.

How a Gateway VPC Endpoint works
You create an endpoint and associate it with route tables. S3 DNS resolves to the endpoint and traffic routes internally. No NAT or internet gateway path is required for supported services.
Example
EC2 in a private subnet reads from S3 through a Gateway Endpoint, avoiding NAT Gateway egress costs.
Misconfiguration risk
Forgetting to update the route table or IAM policy will keep traffic going via the internet instead of the endpoint.
Key Takeaway

Use endpoints to replace frequent internet-bound service calls when cost and security justify them.
