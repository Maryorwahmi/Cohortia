Assessment Scenario questions

Assessment idea & practical questions

Practice with scenarios that require both design choice and validation planning.

Sample question 1
Backend EC2 instances access S3 through a NAT Gateway and incur high Data Transfer Out. What do you recommend and why?
Expected: Gateway VPC Endpoint for S3, update route tables, measure NAT egress drop in Cost Explorer.
Sample question 2
A global audience downloads static images from S3 in one region. How would you lower cost and improve latency?
Expected: front S3 with CloudFront, set cache-control, estimate hit ratio and verify origin egress reduction.
Grading rubric
  • Flow mapping and GB/month estimate — 30%.
  • Appropriate service recommendation and justification — 40%.
  • Validation plan using Cost Explorer or flow logs — 30%.
