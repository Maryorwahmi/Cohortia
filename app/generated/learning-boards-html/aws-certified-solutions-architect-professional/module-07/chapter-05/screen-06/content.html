CloudFront vs Origin egress

Edge caching transforms origin egress into cheaper edge transfer and fewer origin bytes.

Direct origin delivery
  • Every user request hits the origin.
  • Origin sees full bandwidth and egress costs.
  • Latency varies by user geography.
Cost risk
High global downloads create large S3 or EC2 egress charges.
CloudFront fronting the origin
  • Edge caches serve repeat requests near users.
  • Origin handles fewer requests and less egress.
  • Improved latency and lower origin transfer costs.
Example
Serving product images via CloudFront often yields large egress savings versus direct S3 delivery for a global audience.
Pro tip: use cache-control headers and monitor origin request counts to verify savings.
