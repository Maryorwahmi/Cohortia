Core Concept Ingress vs Egress

Ingress vs Egress — the fundamental rule

Understanding directionality of data determines where costs appear and which tools reduce them.

Formal definition
Ingress: data entering AWS services or regions, usually free. Egress: data leaving a service, AZ, region, or AWS to the internet — usually charged.
Concrete example
Uploads from clients to an S3 bucket in the same region are ingress and typically not billed, while downloads to users are egress and billed.
Common misconception
Some teams assume all intra-AWS traffic is free. Cross-AZ and cross-region transfers are charged and need planning.
Key Takeaway

Classify flows by ingress or egress and prioritize high-volume egress for optimization.

Flow classification checklist
  • Client → AWS origin: ingress (usually free).
  • AWS origin → Client: egress (billed to Data Transfer Out).
  • Between AZs in same region: cross-AZ (billed).
  • Between regions: cross-region (more expensive).
