Module 7 › Chapter 7.3 › Intelligent-Tiering
What it does
Automatically monitors object access and moves between frequent and infrequent tiers. No application changes required.
Practical example
User uploads lifecycle
Images are hot for the first 7–14 days, then rarely accessed. Intelligent-Tiering moves older objects to infrequent tier automatically, saving monthly storage costs without manual rules.
Misconception
It always saves money
Small objects and extremely large object counts may be harmed by per-object automation fees; estimate break-even first.
Decision checklist
  • Is access pattern unpredictable? If yes, consider Intelligent-Tiering.
  • Estimate per-object monitoring fee vs expected savings.
  • Test with a sample prefix and monitor movement and costs.
Key Takeaway
Key Takeaway

Intelligent-Tiering is powerful for unpredictable workloads but requires a cost break-even check before wide adoption.
