Module 7 › Chapter 7.3 › Hands-on: Lifecycle
Activity steps
  1. Create bucket with unique name and default block public access.
  2. Upload sample files into logs/ prefix to simulate generated logs.
  3. Create lifecycle rule scoped to logs/: transition after 30, 90, 180 days and expire at 365 days.
  4. Create rule to delete incomplete multipart uploads after 7 days.
  5. Monitor transitions and run a small restore test from Glacier to verify retrieval behavior.
Example lifecycle rule (visualized)
logs/* → 30d → Standard-IA
logs/* → 90d → Glacier Flexible Retrieval
logs/* → 180d → Glacier Deep Archive
logs/* → 365d → Expire
Delete incomplete multipart uploads → 7d
Expected outcome

Objects move through cost tiers automatically; expired objects are removed and incomplete uploads are cleaned up, lowering storage bills.
