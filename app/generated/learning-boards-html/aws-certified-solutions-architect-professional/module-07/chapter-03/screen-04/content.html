Module 7 › Chapter 7.3 › S3 Classes
Quick comparison
S3 Standard
High availability and immediate access; use for hot data and active workloads.
Standard-IA / One Zone-IA
Lower storage cost for infrequently accessed objects; One Zone-IA lowers resilience for extra savings.
Glacier / Deep Archive
Lowest cost for long-term archives; different retrieval times and cost tiers available.
Common-mistake
Aggressive archiving without retrieval planning
Putting moderately accessed data into Deep Archive can create heavy retrieval bills and long delays when that data is needed.
Example scenarios and takeaway
Transcoding pipeline
0–60 days: S3 Standard for frequent access during processing and distribution.
Monthly audit logs
30–90 days: Standard-IA for reduced cost; 90+ days: Glacier for archival retention.
Compliance archive
Deep Archive for data rarely accessed but required long-term; test retrieval before committing.
Key Takeaway

Pick class by access frequency and retrieval tolerance. Cheaper tiers need retrieval planning.
