Deploy Intelligent-Tiering
Enable for buckets with unknown access; verify movement with access metrics and monitor monthly automation fees versus savings.

Store transition and expiration rules per prefix. Test with a sample object set to observe transitions over time.
VERIFIED COMPETENCY MILESTONE
Right-size EBS & manage snapshots
Use monitoring to resize or change volume type; automate snapshot lifecycle with DLM or Backup to delete old snapshots.
VERIFIED COMPETENCY MILESTONE
Enable EFS IA and select throughput
Set lifecycle to move dormant files after a period and choose bursting or provisioned throughput to match demand.

Verification checklist

  • Show snapshot deletion logs and resulting storage reduction.
  • Compare EFS bills before and after enabling IA for a sample dataset.
