EFS Infrequent Access
Enable lifecycle management to move files not accessed for a configured number of days into the IA tier. No application changes are required to read files that move back to primary storage, but there are different access charges.
Use case
Shared developer home directories with many dormant files; enable IA after 30 days to reduce storage cost while preserving access semantics.
Throughput modes
Bursting mode is ideal for intermittent spikes; provisioned mode is for consistent, predictable throughput needs. Choose to avoid over-provisioning and extra monthly charges.
Bursting: cost-effective for variable workloads like occasional builds.
Provisioned: use when workloads need guaranteed throughput for continuous operations.
Key Takeaway

Combine EFS IA with the correct throughput mode to lower cost without sacrificing required performance.
