Process Flow › Tag Policies Workflow

Steps to enforce tags

1
Design allowed values
Decide the controlled lists for Environment and other critical keys.
2
Author Tag Policy
Create the JSON policy and include required keys and value constraints.
3
Attach to OU
Apply at the OU level so accounts under it inherit the rules.
4
Audit & remediate
Use compliance reports and automated tagging for remediation of legacy resources.
Misconception
Tag Policies do not retroactively fix old resources; remediation and automation are required for legacy cleanup.

Policy Example (concept)

Authoring concept
{
  "tagPolicy": {
    "rules": [
      {"key": "Environment", "required": true, "allowedValues": ["Dev","Test","Prod"]},
      {"key": "CostCenter", "required": true}
    ]
  }
}
Example Outcome
Resources missing required keys will be non-compliant and flagged for remediation, reducing unallocated costs.
Key Takeaway

Use Tag Policies to enforce the taxonomy; pair enforcement with remediation for legacy resources.
