How Cost Categories work

Define named categories using rules. Rules evaluate tags, accounts, services, and other categories to assign costs.

Example Rule
If tag Project is Phoenix → Category Project-Phoenix.
Fallback Rule
Use Unallocated-Costs for anything that fails to match category rules.
Practical Test
After creating the category, open Cost Explorer, group by Cost Category, and validate that Project-Phoenix and Project-Hydra appear as expected over a recent time range.
Key Takeaway

Use Cost Categories as a translation layer so finance sees project and application costs without needing to parse the CUR.

Design tips

  • Start with a handful of business-focused categories.
  • Use tags and accounts in rules; keep precedence predictable.
  • Include an Unallocated fallback for auditing.
Misconception
Cost Categories simplify views but do not alter raw billing data; use them as a reporting abstraction.
