Hands-on Activity › Implement Cost Categories

Step-by-step

  1. Ensure resources are tagged: Project=Phoenix or Project=Hydra.
  2. Create a Cost Category named MyProjectCosts and add rules for Phoenix and Hydra.
  3. Add an optional Unallocated rule for any unmatched costs.
  4. Open Cost Explorer, set the time range and Group by the new Cost Category to validate.
CLI Example to tag an EC2 instance
aws ec2 run-instances --image-id ami-0abcdef1234567890 --instance-type t3.micro --tag-specifications 'ResourceType=instance,Tags=[{Key=Project,Value=Phoenix}]'
Validation Tip
Allow a short time for CUR and Cost Explorer to reflect new tags, then check grouped results for expected category values.

Example Rules Snapshot

PhoenixProject
Dimension=Tag, Tag key=Project, Operator=Is, Tag values=Phoenix → Category=Project-Phoenix
HydraProject
Dimension=Tag, Tag key=Project, Operator=Is, Tag values=Hydra → Category=Project-Hydra
Key Takeaway

Validate categories against real tagged resources so showback reports map to actual project owners.
