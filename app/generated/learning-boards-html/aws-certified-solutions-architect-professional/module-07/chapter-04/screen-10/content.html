Module 7 › Chapter 7.4 › Spectrum vs Athena
Amazon Athena

Serverless interactive queries

No provisioning; pay for data scanned. Great for ad-hoc analysis and small to medium queries.

Best practice
Store data in Parquet and partition by date to reduce data scanned and cost.
Redshift Spectrum

Query S3 from Redshift

Augment your data warehouse with external S3 data without loading it into the cluster. You pay for data scanned by the Spectrum queries.

When to use
Use Spectrum when combining external S3 datasets with cluster-resident tables for complex analytics workflows.
