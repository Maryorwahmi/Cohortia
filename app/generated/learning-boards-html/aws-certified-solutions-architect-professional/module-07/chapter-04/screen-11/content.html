Module 7 › Chapter 7.4 › Athena Table Example
Code Walkthrough
Create an external table pointing at partitioned data. Prefer Parquet for production to reduce data scanned.
CREATE EXTERNAL TABLE IF NOT EXISTS sales_db.sales_data (
  `date` string,
  `product` string,
  `amount` int
)
ROW FORMAT SERDE 'org.apache.hadoop.hive.serde2.OpenCSVSerde'
WITH SERDEPROPERTIES (
  'separatorChar' = ',',
  'quoteChar' = '"',
  'escapeChar' = '\\'
)
LOCATION 's3://my-athena-data-YOURNAME/sales/';
After creating the table, run a GROUP BY query and observe the data scanned in Athena's query details. Convert the files to Parquet and compare the metric to see the savings.
Practical tips
  • Partition by date to limit files scanned for period-based queries.
  • Prefer Parquet or ORC to minimize I/O and scanning cost.
  • Set an Athena query result S3 location and track query data scanned over time.
Key Takeaway

Measure before and after converting formats and partitioning to quantify cost savings in Athena.
