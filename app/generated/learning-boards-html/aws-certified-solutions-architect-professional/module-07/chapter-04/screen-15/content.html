Redshift Spectrum
Run SQL on S3 data without loading into Redshift; pay for data scanned.
Amazon Athena
Serverless queries over S3. Cost is driven by how much data a query scans.
AWS Glue DPUs
Glue charges by DPUs per hour; reduce cost by right-sizing and optimizing ETL scripts.
Final takeaway

Data layout and ETL efficiency are the most effective levers to reduce analytics costs; pair them with operational cleanup routines.
