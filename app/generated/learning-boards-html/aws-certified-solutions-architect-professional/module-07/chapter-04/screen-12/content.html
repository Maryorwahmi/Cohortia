Optimization

Control DPU-hours with right-sizing and script efficiency

Right-size DPUs
Test jobs at multiple DPU sizes and compare runtime × DPU to find the lowest-cost configuration that meets SLAs.
Script efficiency
Avoid unnecessary shuffles and wide transformations; use partition pruning and pushdown filters where possible.
Scheduling
Run jobs only when needed; consider streaming for continuous loads to avoid repeated batch overhead.
Concrete example: run the ETL job at 2, 4, and 8 DPUs. Record runtime and compute DPU-hours. If 4 DPUs finishes fast enough at lower DPU-hours than 8, prefer 4 for cost efficiency.
Key Takeaway

Glue cost is DPU-hours. Optimize code and schedule to reduce runtime and total DPU consumption.
