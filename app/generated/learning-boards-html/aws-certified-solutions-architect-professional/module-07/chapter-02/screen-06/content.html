Spot Instances
Cheap capacity that can be reclaimed with short notice.
Suitability
  • Batch jobs, analytics, CI/CD, dev/test, stateless microservices.
  • Not suitable for single‑node stateful, interruption‑intolerant services.
Safety patterns

Checkpoint work, externalize state, use ASGs with mixed purchase options and multiple instance types to increase capacity availability.

Architecture tip

Set a minimal On‑Demand base capacity and let Spot fill transient demand to balance cost and reliability.

Concrete scenario
A nightly ETL pipeline breaks data into tasks saved to durable storage. Spot workers pull tasks, process them, and write results back. If workers are reclaimed, in‑progress tasks are retried by remaining workers — the job completes with minimal manual intervention.
Key Takeaway

Spot delivers dramatic discounts when systems are built for interruption and fast recovery.
