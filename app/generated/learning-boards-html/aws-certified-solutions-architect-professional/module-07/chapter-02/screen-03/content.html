Module 7 › Chapter 7.2 › Learning Objectives
Verification workflow
Use data, small experiments, and automation to prove cost reductions without risking availability.
Analyze

Use Cost Explorer and CloudWatch metrics to find steady and idle patterns. Capture baselines before changes.

Experiment

Try Savings Plans or Graviton on a staging subset. Measure throughput and cost per request.

Automate

Schedule non‑prod shutdowns and alerts for underutilized instances using Instance Scheduler or Lambda scripts.

Verify

Confirm savings, track availability, and document the rollback plan for each change.

Tip
Small, reversible changes scale safely

Always run limited pilots to validate cost and performance before broad commitments or migrations.
