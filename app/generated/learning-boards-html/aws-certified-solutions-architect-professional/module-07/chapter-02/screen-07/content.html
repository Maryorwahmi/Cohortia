Module 7 › Chapter 7.2 › ASG Mixed Instances
Design pattern
Base On‑Demand capacity + Spot for scale = cost and resilience.
Key steps
  1. Create a launch template with multiple compatible instance types.
  2. Set ASG purchase options to mix Spot and On‑Demand.
  3. Choose allocation strategy: capacity‑optimized or lowest‑price.
  4. Set base On‑Demand capacity and target tracking policies.
Common pitfall

Not including enough instance type choices reduces Spot availability and increases launch failures.

Concrete ASG example
# Launch Template user data example
#!/bin/bash
yum update -y
yum install -y nginx
systemctl start nginx
systemctl enable nginx
echo "<h1>Hello from AWS (Instance ID: $(curl -s http://169.254.169.254/latest/meta-data/instance-id))</h1>" > /usr/share/nginx/html/index.html
Key Takeaway

A mixed ASG with multiple instance types and a small On‑Demand base protects availability while leveraging Spot savings.
