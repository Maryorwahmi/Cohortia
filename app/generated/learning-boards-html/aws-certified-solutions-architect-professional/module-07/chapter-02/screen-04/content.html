Reserved Instances (RIs)
Commit to capacity for large discounts on steady workloads.
Types
  • Standard RIs: highest discount, least flexible.
  • Convertible RIs: smaller discount, change family/OS/tenancy allowed.
When to use

Core, 24/7 services with predictable capacity such as primary databases or always‑on app tiers.

Common mistake

Buying RIs without analyzing usage trends, then being stuck if the architecture changes.

Concrete example
A cluster of database instances running 24/7 shows consistent CPU and instance counts across months. Converting that baseline to Standard RIs for a 3‑year term reduces the hourly cost significantly and stabilizes budget forecasts.
Key Takeaway

RIs are best for predictable, always‑on capacity. Validate usage before committing to avoid wasted commitments.
