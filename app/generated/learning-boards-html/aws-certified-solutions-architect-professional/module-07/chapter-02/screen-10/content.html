AWS Lambda cost model
You pay for actual execution time and memory allocation, eliminating idle costs.
Good use cases
  • Event‑driven processors (S3, SNS, SQS).
  • API backends with intermittent traffic.
  • Background tasks and transformations.
Right‑size functions

Adjust memory and timeout to balance faster execution against higher per‑millisecond cost. Measure cost per request.

Misconception

Lambda is not always cheaper than EC2 for very high, constant traffic; evaluate both options for steady workloads.

Concrete example
An image upload pipeline triggers a Lambda function that resizes images and stores derivatives. When uploads are rare, the monthly cost is tiny compared to an always‑running EC2 instance performing the same task.
Key Takeaway

Serverless shifts cost to execution. Use Lambda for event workloads and right‑size functions to balance latency and cost.
