Module 7 › Chapter 7.2 › Pricing Model Comparison
Reserved Instances

Best for predictable, steady workloads. Large discounts, less flexibility.

Good when: 24/7, stable instance usage
Savings Plans

Flexible $/hour commitment that can apply across EC2, Fargate, Lambda for evolving stacks.

Good when: multi‑service or changing families
Spot Instances

Deepest discounts for interruptible workloads. Requires resilience and checkpointing.

Good when: batch, analytics, stateless microservices
Decision checklist
  • Is the workload steady over months? If yes, consider RIs or EC2 savings.
  • Will compute services or instance families change? If yes, favor Compute Savings Plans.
  • Can the workload tolerate interruption? If yes, use Spot with resilient design.
