Savings Plans
Commit to $/hour for broad discounts across compute services.
Types
  • Compute Savings Plans: apply across EC2, Fargate, Lambda.
  • EC2 Instance Savings Plans: larger discount, tied to instance family and region.
When to use

Environments with mixed compute — containers, functions, and EC2 — that may change instance types over time.

Practical tip

Use billing history to estimate committed hourly spend and choose Compute Savings Plans when you need cross‑service coverage.

Concrete example
A multi‑tier app using Fargate for containers and Lambda for background jobs can commit to a Compute Savings Plan that lowers cost across both compute types rather than buying EC2‑specific commitments.
Key Takeaway

Savings Plans provide flexible discounts across services. Match the plan scope to your multi‑service footprint.
