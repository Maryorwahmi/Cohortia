What it is

Line-item billing data

CUR contains every charge line with fields like resource ID, usage type, operation, pricing, and timestamps; delivered to S3 for external analysis.

Usage pattern

Partition by date in S3 and query slices with Athena for performant, auditable reporting.

Athena example
A basic SQL pattern to aggregate cost by resource and month:
SELECT
  date_trunc('month', usage_start_date) as month,
  resource_id,
  usage_type,
  sum(cost) as total_cost
FROM cur_table
WHERE usage_start_date BETWEEN date '2023-08-01' AND date '2023-08-31'
GROUP BY 1,2,3
ORDER BY 1,4 DESC;
Note: cur_table represents your CUR partitioned table. Use date filters and resource filters to limit scan size.
Key Takeaway

CUR with Athena turns raw billing lines into repeatable chargeback and cost-per-component reports when partitioned and filtered correctly.
