Module 7 › Chapter 7.1 › Tagging
Core idea

Consistent tags = accurate allocation

Use standardized keys like Project, Owner, and Environment to map resources to business units and billing reports.

Policy example

Create a Tag Policy that requires key Project and enforces allowed values such as Phoenix and Hydra.

Cautions

Do not store secrets in tag values and use consistent casing to avoid duplicate categories.

Practical enforcement
Attach the tag policy to the OU for development accounts and verify compliance via AWS Organizations reports.
Outcome

With enforced tags, Cost Explorer and CUR reports will show fewer unallocated costs and enable chargeback.

Common trade-off

Strict enforcement increases data quality but requires clear onboarding and automation to apply tags at resource creation.
