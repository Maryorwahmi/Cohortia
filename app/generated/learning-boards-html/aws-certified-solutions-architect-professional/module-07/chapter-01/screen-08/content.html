Step-by-step

Create a cost budget

  1. Choose budget type: cost or usage and set period (monthly).
  2. Set budget amount, for example $50 for a small project.
  3. Scope with filters: select Tag → Project → Phoenix.
  4. Add alert thresholds: forecast 80% and actual 100% via email or SNS.
Operational note

Define an action plan for each alert: who investigates, whether to scale down resources, and how to update stakeholders.

Example
Budget for Project:Phoenix

Monthly budget $50. Add an 80% forecast alert and a 100% actual alert. Filter by Tag: Project = Phoenix to ensure only project costs are tracked.

Common mistake

Setting budgets too narrowly so they miss correlated costs across accounts, or too broadly so alerts are meaningless.

Pro tip

Use historical Cost Explorer forecasts when choosing thresholds to reduce false positives.
