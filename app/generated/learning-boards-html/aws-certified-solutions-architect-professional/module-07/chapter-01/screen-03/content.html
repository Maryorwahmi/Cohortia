Lab Objectives

Complete a tag policy, resource launches, and a project budget to validate your governance loop.

Lab Step
Create Tag Policy

Define a required Project key and enforce allowed values for predictable allocation.

Lab Step
Launch Resources

Observe compliance differences when instances are created with and without the tag.

Lab Step
Create Budget

Scope a monthly budget to a Project tag and set 80% and 100% alerts to practice operational responses.
