Module 8 › Chapter 7.8 › Key Concepts
Serverless First
Prioritize serverless for spiky, stateless workloads to pay only for actual usage and reduce idle costs.
Containerization
Use containers with Fargate or Spot instances for scalable, cost-efficient compute where isolation matters.
Tiered Storage
Match storage classes and use lifecycle policies to move cold data to lower-cost tiers automatically.
Database Right-sizing
Choose RIs, Savings Plans, or serverless database modes based on workload predictability and cost.
Egress Minimization
Use CloudFront and VPC endpoints and prefer local resource access to reduce costly data transfer.
Continuous Optimization
Integrate monitoring, tagging, and recommendations into operations so savings persist over time.
Summary

Use these six principles to guide choices across compute, storage, database, network, and operations for cost-efficient architectures.
