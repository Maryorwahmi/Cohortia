Module 8 › Chapter 7.8 › Web Tier
Pattern cards
S3 + CloudFront
Host static SPA assets in S3 and front with CloudFront to reduce origin egress and improve global performance.
Lambda + API Gateway
Serve dynamic APIs with serverless compute to pay per execution and avoid idle instances during lulls.
Hybrid approach
Combine caching for static assets with serverless for spikes, and minimal reserved capacity for steady background tasks.
Explanation, example, and pitfalls
  • Use cache-control and TTLs so CloudFront can serve most requests without hitting S3 origin.
  • Example: An e-commerce SPA with product images on S3 and CloudFront reduces origin egress by serving cached images at edge locations.
  • Misconception: CloudFront always eliminates costs — invalidations and origin fetches still matter; design cache patterns carefully.
