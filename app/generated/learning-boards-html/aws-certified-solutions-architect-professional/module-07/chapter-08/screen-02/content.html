Module 8 › Chapter 7.8 › Learning Objectives
01
Integrate cost optimization into design

Frame tradeoffs during architecture discussions so choices reflect long-term cost and performance outcomes. This prevents costly rework after deployment.

Mnemonic: Design = Dollars + Demand
VERIFIED COMPETENCY MILESTONE
02
Evaluate serverless vs containers

Match spiky workloads to Lambda and predictable services to Fargate or EC2 with Savings Plans. Consider preemption tolerance for Spot use cases.

Mnemonic: Spike → Serverless, Steady → Reserved
VERIFIED COMPETENCY MILESTONE
03
Design storage and databases for cost

Use lifecycle policies and appropriate storage classes, and choose database capacity modes that match read/write patterns to avoid overpaying.

Mnemonic: Hot data where you pay, cold data where you save
VERIFIED COMPETENCY MILESTONE
04
Optimize network to minimize egress

Design for locality, use CloudFront, and prefer VPC endpoints to limit costly internet egress and NAT gateway traffic.

Mnemonic: Keep data local
VERIFIED COMPETENCY MILESTONE
Why these objectives matter

These objectives shift cost work from firefighting to design. Successful architects make service choices that scale cost predictably and embed automation to keep costs visible.
