S3 Lifecycle example
{ "Rules": [ { "ID": "images-tiering", "Status": "Enabled", "Filter": {"Prefix": "uploads/"}, "Transitions": [ {"Days": 30, "StorageClass": "STANDARD_IA"}, {"Days": 365, "StorageClass": "GLACIER"} ], "Expiration": {"Days": 1825} } ] }
This rule moves objects under uploads/ to lower-cost tiers automatically, reducing storage cost as objects age.
DynamoDB capacity switch
aws dynamodb update-table \ --table-name Orders \ --billing-mode PAY_PER_REQUEST
Switching to pay-per-request removes the need to provision capacity for unpredictable workloads and aligns cost with usage.
Key Takeaway

Implement lifecycle policies and choose DynamoDB modes that reflect traffic patterns to avoid overpaying for unused capacity.
