Module 8 › Chapter 7.8 › Compute Layer
Compute patterns
Serverless (Lambda + API Gateway)
Best for stateless, spiky APIs where you pay per execution and avoid idle capacity costs.
Containers (Fargate / Fargate Spot)
Good for microservices that benefit from isolation with pay-for-use, and Spot can cut cost for interruptible workloads.
EC2 with Savings Plans / RIs + Graviton
Appropriate for long-running, predictable services where reserved capacity yields deep discounts.
Explanation & example
  • Define workload attributes: stateful/stateless, steady/spiky, latency needs, and interruption tolerance.
  • Example: Use Lambda for promotional traffic spikes to avoid running large fleets of instances idle between events.
  • Misconception: serverless is not always cheaper for steady, high-duration compute; reserved instances or Savings Plans can be more cost-effective.
Scenario

A video transcoding background job that tolerates interruption should use Spot Instances or AWS Batch to minimize cost while still meeting throughput goals.

Key Takeaway

Classify workloads, then apply the cheapest consumption model that satisfies availability and latency requirements.
