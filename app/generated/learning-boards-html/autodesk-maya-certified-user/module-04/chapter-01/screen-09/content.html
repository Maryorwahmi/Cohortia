Code Example (Maya Python)

Run in Maya Python script editor to create a reproducible three-point setup.
import maya.cmds as cmds # Create a sphere for the subject cmds.polySphere(name='mySubject', r=1, sx=20, sy=20) cmds.move(0, 0.5, 0, 'mySubject') # Create Key Light (Directional) key_light = cmds.directionalLight(name='key_light_main') cmds.setAttr(f'{key_light}.intensity', 1.0) cmds.setAttr(f'{key_light}.color', 1.0, 0.98, 0.95, type='double3') cmds.setAttr(f'{key_light}.useRayTraceShadows', 1) cmds.rotate(-30, 45, 0, key_light) # Create Fill Light (Point) fill_light = cmds.pointLight(name='fill_light_front') cmds.setAttr(f'{fill_light}.intensity', 0.4) cmds.setAttr(f'{fill_light}.color', 0.95, 0.98, 1.0, type='double3') cmds.setAttr(f'{fill_light}.decayRate', 2) cmds.setAttr(f'{fill_light}.useRayTraceShadows', 0) cmds.move(2, 1, -2, fill_light) # Create Back Light (Spot) back_light = cmds.spotLight(name='back_light_rim') cmds.setAttr(f'{back_light}.intensity', 0.7) cmds.setAttr(f'{back_light}.decayRate', 2) cmds.setAttr(f'{back_light}.useRayTraceShadows', 1) cmds.setAttr(f'{back_light}.shadowDensity', 0.5) cmds.move(0, 1.5, -3, back_light) cmds.rotate(-15, 0, 0, back_light)

How to Use This Script

  • Run to create a baseline three-point setup around a sphere.
  • Render snapshots after each change to isolate effects of attributes.
  • Adjust only one attribute at a time (intensity, color, decay) to learn cause and effect.
Classroom Task

Run the script, then change fill intensity to 0.2 and re-render. Observe contrast and shadow recovery.
