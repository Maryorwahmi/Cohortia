Attribute Cards

Intensity — controls brightness. Lower before adding lights. Use small increments and compare renders.
Color — tints light to set mood. Use subtle shifts to avoid artificial coloring of materials.
Decay Rate — controls falloff with distance. Quadratic decay approximates real-world light falloff.
Shadows — depth map for speed, raytraced for accuracy. Control density and resolution for quality.

Practical Checks

  • Test intensity by rendering passes with incremental values.
  • Use slight color temperature shifts rather than saturated hues.
  • Enable Quadratic decay on point/spot lights for physical falloff.
  • Choose shadow type based on quality vs. render time needs.
Common Mistake

Setting color at full intensity can overwhelm material responses. Reduce intensity when applying strong color tints.
