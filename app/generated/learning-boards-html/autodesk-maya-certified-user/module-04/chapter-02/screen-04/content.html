Core Concept

Default vs Custom Cameras

Default cameras are built into every scene for navigation. Create custom cameras when you need shots that stay fixed for renders and animation.

Why create custom cameras?
  • Lock down renderable views independently from modeling viewports.
  • Attach aim locators or rigs for precise targeting.
  • Set lens and DOF attributes per render camera.
Common mistake

Using default cameras as final shots causes accidental shifts; always make a custom camera for final composition.

Key Takeaway

Use custom cameras for rendering and animation; keep default cameras for modeling and navigation.

Quick Comparison
Default Cameras
Persistent, non-deletable views for modeling and navigation.
Custom Cameras
User-created, adjustable for lens, DOF, and animation.
Concrete example

Create a camera for a hero shot and save it as a bookmark. Continue modeling using the persp view without changing the saved shot.
