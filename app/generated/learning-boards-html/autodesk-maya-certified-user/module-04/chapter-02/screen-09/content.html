Look Through Selected & Navigation

Switch to a camera view to compose interactively, or edit transforms directly for precision.

Step

Select camera transform in Outliner then choose Panels › Look Through Selected to view the camera's perspective.

Navigation

Use Alt + Left/Middle/Right drag to orbit, pan, and dolly while looking through the camera; these actions change the camera transform.

Concrete example

Create Camera and Aim, look through it, Alt-dolly forward until the sphere fills roughly one third of the frame, then set focal length if needed and bookmark the view.

Common mistake

Expecting viewport navigation to be a temporary preview; when looking through a camera the navigation edits the camera's transform permanently unless undone.

Pro tip

Before making big changes, create a Camera Bookmark so you can return to the previous composition instantly.

Key Takeaway

Looking through a camera turns interactive navigation into precise camera placement, letting you compose like a photographer.
