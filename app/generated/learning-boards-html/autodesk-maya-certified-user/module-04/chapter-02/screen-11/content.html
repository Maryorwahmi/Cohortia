Module 4 › Chapter 4.2 › Camera Animation
Process Flow

Animate with Keyframes

Set keys on Translate and Rotate, then refine motion for cinematic timing.

Set initial key

Position camera at frame 1, select the transform, and press 's' to key translate and rotate.

Set final key

Move to frame 120, adjust camera, press 's' again, then play to preview the interpolation.

Refine curves

Open the Graph Editor to adjust easing and timing for a natural camera move.

Concrete example

Keyframe a wide shot at frame 1 and a close-up at frame 120. Play the Time Slider and use the Graph Editor to ease into the close-up for a cinematic push-in.

Misconception

Animating shape attributes changes lens or DOF; animate transforms for motion and shape attributes for optical changes intentionally.

Key Takeaway

Key transforms at frames, then refine using the Graph Editor so the camera movement supports the scene rhythm.
