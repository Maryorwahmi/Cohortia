Module 4 › Chapter 4.2 › Camera Bookmarks
Process

Create and recall bookmarks

Bookmarks let you store composed camera views to return to them quickly while iterating on a scene.

How to save

Select camera, ensure you are looking through it, then use View › Bookmarks › Edit Bookmarks › New Bookmark and give it a name.

What is saved

Bookmarks save position, rotation and focal length to restore exact framing later.

Concrete example

Compose an establishing shot, save as "Initial Shot", then create a close-up and save as "CU". Toggle between them to render both angles without re-positioning manually.

Practical tip

Name bookmarks with intent so collaborators understand the purpose of each saved view.

Key Takeaway

Bookmarks speed iteration by reliably restoring composed camera views during the creative process.
