Automate camera setup

This example creates primitives, a camera with aim, sets focal length and DOF, and keyframes transforms for a simple animation.

Code (Maya Python)
import maya.cmds as cmds

# Create primitives
cmds.polySphere(name='sphere_obj', r=1)
cmds.move(0, 0, 0, 'sphere_obj')
cmds.polyCube(name='cube_obj', w=2, h=2, d=2)
cmds.move(0, 0, -3, 'cube_obj')
cmds.polyCylinder(name='cylinder_obj', r=1, h=3)
cmds.move(0, 0, -6, 'cylinder_obj')

# Create a camera with aim
cam_transform, cam_shape, aim_transform = cmds.camera(name='myAnimatedCamera', sa=True)

# Position camera and aim
cmds.move(0, 2, 5, cam_transform)
cmds.move(0, 0, -3, aim_transform)  # Aim at the cube

# Set focal length
cmds.setAttr(f'{cam_shape}.focalLength', 50)

# Set up Depth of Field (Arnold specific)
cmds.setAttr(f'{cam_shape}.aiEnableDOF', 1)
cmds.setAttr(f'{cam_shape}.aiFocusDistance', 5)  # Adjust based on scene
cmds.setAttr(f'{cam_shape}.aiApertureSize', 0.2)

# Keyframe camera position and rotation
cmds.currentTime(1)
cmds.setKeyframe(cam_transform, attribute='translateX')
cmds.setKeyframe(cam_transform, attribute='translateY')
cmds.setKeyframe(cam_transform, attribute='translateZ')
cmds.setKeyframe(cam_transform, attribute='rotateX')
cmds.setKeyframe(cam_transform, attribute='rotateY')
cmds.setKeyframe(cam_transform, attribute='rotateZ')

cmds.currentTime(120)
cmds.move(0.5, 1.5, 1, cam_transform, absolute=True)
cmds.rotate(5, -10, 0, cam_transform, relative=True)
cmds.setKeyframe(cam_transform, attribute='translateX')
cmds.setKeyframe(cam_transform, attribute='translateY')
cmds.setKeyframe(cam_transform, attribute='translateZ')
cmds.setKeyframe(cam_transform, attribute='rotateX')
cmds.setKeyframe(cam_transform, attribute='rotateY')
cmds.setKeyframe(cam_transform, attribute='rotateZ')

cmds.playbackOptions(minTime=1, maxTime=120)
Notes
  • Script sets transform and shape attributes separately.
  • Verify Focus Distance based on actual scene measurements.
  • Keyframe transforms for motion and shape attributes for lens/DOF changes.
Practice

Run the snippet in a fresh scene, then open the Outliner and Look Through Selected to validate the created camera before rendering frames.

Key Takeaway

Automation speeds iteration, but always check camera view and DOF visually after running scripts.
