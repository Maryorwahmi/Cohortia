Module 4 › Chapter 4.2 › Depth of Field
Definition

Depth of Field

DOF controls the plane of sharp focus and the amount of blur elsewhere based on focus distance and aperture.

Focus Distance

Set this to the distance from camera to the point you want in sharp focus. Use Measure Tools if needed.

Aperture Size

Controls blur strength. Small values give subtle blur; larger values create stronger separation.

Concrete example

Create three primitives along Z: Sphere at Z=0, Cube at Z=-3, Cylinder at Z=-6. Enable DOF, set Focus Distance to the cube, then raise Aperture Size from 0.1 to 0.5 and render frames to see the background soften.

Misconception check

DOF does not replace composition. Use it to emphasize, not to hide important scene information.

Key Takeaway

Use focus distance to choose the plane of sharpness and aperture to control how much of the scene is blurred.
