Common issues and quick checks
  • • Black render → check light intensity, enabled lights, and camera position.
  • • Missing textures → confirm File > Set Project and that textures live in sourceimages.
  • • Long render times → reduce Camera AA, sampling, or geometry density for tests.
  • • Noise/jagged edges → increase Camera AA or target Diffuse/Specular samples.
Example fix

If reflections are noisy, raise specular samples modestly rather than increasing all sample types; this isolates the cause and saves time.

Check sequence and folder

After a batch render completes, inspect the project's images folder for the numbered sequence and open the Script Editor for a final success message. If files are missing, verify the file prefix and frame range in Render Settings.

Misconception

Assuming noise requires boosting every sample leads to long renders; instead, find the noisy component and raise its samples selectively.

Key Takeaway

Diagnose first: lights, camera, and project paths solve many black or missing-texture issues; then adjust samples appropriately for noise.
