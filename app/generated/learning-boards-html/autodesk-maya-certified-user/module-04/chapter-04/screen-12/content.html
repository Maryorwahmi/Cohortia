Module 5 › Chapter 4.4 › Activity
Steps
  1. Create a new scene and add a Sphere at the origin.
  2. Set keyframe at frame 1 (TranslateX = 0) and frame 60 (TranslateX = 5).
  3. Add a Directional Light, enable Cast Shadows, and place a camera to view the motion.
  4. File > Set Project > create myRenderProject.
  5. Render Settings: Common → Image Format = png, Frame/Animation Ext = name.#.ext, Name = sphere_animation, Start = 1, End = 60.
  6. Arnold → Sampling → Camera (AA) = 3 for a quick test, then Render > Batch Render.
Locate output

Open myRenderProject/images and confirm files sphere_animation.0001.png to sphere_animation.0060.png. Check Script Editor for completion messages.

Playblast comparison

Playblast offers a fast preview but does not execute renderer sampling or produce AOVs—use it for quick motion checks, not final color or lighting validation.

Key Takeaway

Follow the checklist: animate, set the project, configure render settings precisely, batch render, and verify the numbered images in the images folder.
