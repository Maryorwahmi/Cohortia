Module 5 › Chapter 4.4 › Learning Objectives
Learn
Execute a single-frame render and save the output

Run Render Current Frame, inspect the Render View, and save images in the correct format like PNG for transparency. Saving to the project's images folder keeps your pipeline organized.

VERIFIED COMPETENCY MILESTONE
Understand
Perform a basic batch render for animation

Configure frame range, naming convention and image format in Render Settings, then use Render > Batch Render to produce an ordered image sequence for playback or compositing.

VERIFIED COMPETENCY MILESTONE
Apply
Explain render layers and render passes for compositing

Use render layers to isolate objects or lights, and passes to export components like diffuse, specular or Z-depth. These make non-destructive compositing possible.

VERIFIED COMPETENCY MILESTONE
Master
Identify basic techniques to optimize render times

Lower sampling for test renders, use fewer efficient lights, reduce texture resolution, and render regions to focus iteration without full-frame cost.
