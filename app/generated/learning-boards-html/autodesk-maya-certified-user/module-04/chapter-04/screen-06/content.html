Module 5 › Chapter 4.4 › Batch Render
Batch Render Checklist
  • • Set File > Set Project to ensure correct output paths.
  • • Open Render Settings → Common: set Image Format and Frame/Animation Ext to name.#.ext.
  • • Define Start Frame and End Frame; select your renderable camera.
  • • Adjust renderer sampling for tests or finals, then Render > Batch Render.
Example

A 60-frame sphere animation named sphere_animation produces sphere_animation.0001.png through sphere_animation.0060.png in the project's images folder after a successful batch render.

Misconception

Some think batch rendering always halts the GUI; many setups allow background or farm rendering so artists keep working.

Key Takeaway

Batch rendering writes ordered frames to disk for playback and compositing—confirm naming pattern and project path first.
