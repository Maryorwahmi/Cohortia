Module 5 › Chapter 4.4 › Render Current Frame
Step-by-step
  1. Select the camera you want to render.
  2. Choose Render > Render Current Frame or click the status-line icon.
  3. Watch the Render View progress and inspect sampling areas.
  4. In Render View: File > Save Image and choose PNG, JPEG, or EXR.
Example

Render a sphere lit by a directional light and save as PNG if you need an alpha channel for compositing over a background plate.

Visual: Render View checklist
  • • Confirm the active camera is the intended renderable camera.
  • • Watch sampling noise in corners and reflections.
  • • If textures appear black, set your project and check sourceimages folder.
Common mistake

Saving to a random folder instead of the project's images folder makes it hard to find outputs later—always Set Project first.

Key Takeaway

Use Render View for single frames and select a file format based on whether you need alpha (PNG) or high dynamic range (EXR).
