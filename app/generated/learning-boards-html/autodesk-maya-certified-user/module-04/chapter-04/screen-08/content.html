Module 5 › Chapter 4.4 › Format Comparison
PNG

Lossless, supports alpha. Good for compositing stills where you need transparency and crisp edges.

JPEG

Compressed and smaller. Use for quick previews or web delivery where alpha and maximum fidelity are not required.

EXR

High dynamic range and multi-channel support. Use for professional compositing and color grading workflows.

When to choose which format
  • • Need alpha or lossless stills → PNG
  • • Fast preview or small file size → JPEG
  • • Compositing, AOVs, high dynamic range → EXR
Misconception

Assuming JPEG is fine for compositing leads to missing alpha and compression artifacts—avoid JPEG for final compositing tasks.

Key Takeaway

Match format to purpose: PNG for alpha, EXR for professional composite, JPEG for quick sharing.
