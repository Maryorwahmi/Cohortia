Module 5 › Chapter 4.4 › Practice Checks
Verification 01
Project and Output Path

Ensure File > Set Project points to your working folder and that renders appear in the images subfolder. This prevents missing textures and misplaced files.

Verification 02
Filename Pattern

Use name.#.ext in Frame/Animation Ext so rendered sequences are numbered and easy to import into editing or compositing tools.

Verification 03
AOVs and Passes

Confirm your renderer's AOV list includes the passes you need—diffuse, specular, Z-depth—so you can adjust them later in compositing.

Verification 04
Test vs Final

Run lower sample test renders to iterate quickly, then compare to final higher-sample renders to ensure acceptable image quality.
