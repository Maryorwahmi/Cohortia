Module 4 › Chapter 4.3 › Configure Arnold Settings
Process

UI steps and a short script

Follow the checklist, then optionally run the script to apply the same attributes programmatically.

UI checklist
  • Set Render Using → Arnold
  • Common tab: File Format → png; Name → myFirstRender; Start/End → 1
  • Resolution: HD 1080
  • Arnold tab: Camera (AA)=5, Diffuse=4, Specular=4
When to adjust
If reflections are grainy, raise Specular. For soft-shadow noise, raise Diffuse. Test with single frames before rendering sequences.
Script example (Maya Python)
import maya.cmds as cmds

# Ensure Arnold is loaded and set as current renderer
if not cmds.pluginInfo('mtoa', query=True, loaded=True):
  cmds.loadPlugin('mtoa')
cmds.setAttr('defaultRenderGlobals.currentRenderer', 'arnold', type='string')

# Set Common Render Settings
cmds.setAttr('defaultRenderGlobals.imageFormat', 32)  # PNG format
cmds.setAttr('defaultRenderGlobals.animation', 0)     # Single frame
cmds.setAttr('defaultRenderGlobals.startFrame', 1)
cmds.setAttr('defaultRenderGlobals.endFrame', 1)
cmds.setAttr('defaultRenderGlobals.byFrame', 1)
cmds.setAttr('defaultRenderGlobals.imageFilePrefix', 'myFirstRender', type='string')
cmds.setAttr('defaultResolution.width', 1920)
cmds.setAttr('defaultResolution.height', 1080)

# Set Arnold sampling
cmds.setAttr('defaultArnoldRenderOptions.AASamples', 5)
cmds.setAttr('defaultArnoldRenderOptions.GIDiffuseSamples', 4)
cmds.setAttr('defaultArnoldRenderOptions.GISpecularSamples', 4)
Key takeaway
Use the UI for learning and confirmation; use the script for repeatability once you know the right values.
