Common Tab

File output, frames, camera, and resolution

These settings apply regardless of renderer and determine your files' technical characteristics.

File Output
Choose PNG for transparency, EXR for high dynamic range, or JPEG for smaller files with lossy compression.
Frame Range
Set Start and End frames for sequences. For a still, set Start and End to the same value.
Renderable Camera
Select which camera view the render will use; confirm custom cameras before rendering.
Image Size
Use presets like HD 1080 for 1920×1080, or set custom resolution for deliverable requirements.
Practical example
To create a PNG still named myFirstRender at HD 1080: set Image Format to png, Frame Range to Start=1 End=1, Name to myFirstRender, Renderable Camera to your camera, and Preset to HD 1080.
Key takeaway
Confirm file format, frame range, camera, and resolution before rendering to avoid wasted time and incorrect files.
Why it matters
Wrong frame range or camera can render the wrong frames or views; wrong format can lack needed transparency or dynamic range.
