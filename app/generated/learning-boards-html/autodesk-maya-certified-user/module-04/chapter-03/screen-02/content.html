Learning Objectives

Build practical skills for rendering stills and animation sequences in Maya.

Bloom: Learn → Understand → Apply → Master
01
Explain rendering
Describe how 3D scene data becomes a 2D image and why that matters for delivery and compositing.
VERIFIED COMPETENCY MILESTONE

Differentiate render engines
Identify Maya Software, Hardware 2.0, and Arnold and choose them by speed, feature set, and final quality needs.
VERIFIED COMPETENCY MILESTONE

Navigate Render Settings
Find the Common tab, set file output, frame range, camera, and resolution for a render job.

04
Configure output attributes
Choose image format, set a frame range for stills or sequences, and pick the renderable camera.
