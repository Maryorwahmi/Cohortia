Visual summary
Render Engines
Maya Software — CPU-based, basic quality, useful for simple or stylized renders.
Hardware 2.0 — GPU-accelerated, fast previews, best for playblasts and game asset checks.
Arnold — Production-ready, unbiased path tracer for photorealism and complex lighting.
Render Settings
Common tab — image format, frame range, camera, resolution.
Arnold tab — sampling controls such as Camera (AA), Diffuse, Specular.
Tip: test low, refine high.
Quick Reference
PNG for transparency; EXR for high dynamic range compositing.
Camera (AA) reduces overall aliasing; increase carefully for final renders.
Render fast tests at low samples and lower resolution before final high-quality renders.
Explore Key Topics
Render engines: pick one depending on preview speed versus realism.
Common tab: set format, frame range, camera, and resolution for desired output.
Sampling: adjust Camera, Diffuse, and Specular samples to reduce noise with focused increases.
