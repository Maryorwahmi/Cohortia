Module 4 › Chapter 4.3 › Image Format Choices
Comparison

PNG • JPEG • EXR

Match format to your needs: transparency, speed, or high dynamic range for compositing.

PNG
Preserves alpha channel; ideal for single frames needing transparency and standard color range.
JPEG
Smaller files using lossy compression; good for quick review renders where artifacts are acceptable.
EXR
High dynamic range and multi-channel support; best for professional compositing and color grading.
Recommendation
Preview with JPEG or low-resolution PNG; deliver or composite with EXR where color depth matters.
Scenario
For an animation sequence intended for compositing, render to EXR sequence. For a single image with transparency for a mockup, render PNG.
Key takeaway
Select file formats based on compositing needs and desired bit depth rather than convenience alone.
