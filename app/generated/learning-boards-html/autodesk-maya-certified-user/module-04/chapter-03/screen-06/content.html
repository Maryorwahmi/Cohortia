Module 4 › Chapter 4.3 › Render Settings Window
Process

Open, choose renderer, set common parameters

Start with the Common tab, then adjust renderer-specific tabs. Confirm the renderable camera and output naming before rendering.

Step 1 — Renderer
Select Maya Software, Hardware 2.0, or Arnold in the renderer dropdown.
Step 2 — Common tab
Set file format, frame range, renderable camera, and image size preset.
Step 3 — Renderer tab
Adjust sampling and engine-specific controls like Arnold's Camera (AA) and Diffuse samples.
Checklist & Example
Example: to render a high-quality still, choose Arnold, set File Output to PNG, name the file, set Start and End frame to the same value, choose your camera, and set the preset to HD 1080.
Key takeaway
Set Common tab values first, then tweak engine settings. Confirm camera and filename before rendering.
Pitfall
Switching renderers can reset or expose different parameters—always re-check the renderer tab after changing the engine.
