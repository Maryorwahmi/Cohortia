Start Frame, End Frame, and filename patterns

Proper frame range and file naming produce reliable image sequences for downstream editing and compositing.

Single frame
Set Start and End to the same frame and use name.ext.
Animation sequence
Set Start and End to the sequence range and use name.#.ext to include frame numbers automatically.
Frame step
Use By Frame to skip frames if you only need samples for every nth frame during tests.
Example
For frames 1 to 100 and PNG files: set Start=1, End=100, Frame/Animation Ext=name.#.png. Run a single-frame test first.
Pitfall
Incorrect filename patterns can overwrite frames or produce files that don't sequence properly in compositing tools.
