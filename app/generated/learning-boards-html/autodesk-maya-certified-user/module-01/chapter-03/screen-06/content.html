Definition

Uniform vs non-uniform scaling

Scaling changes the size of an object. Choose uniform for consistent proportions and non-uniform for targeted dimension adjustments.

Central cube — Uniform
Drag to scale all axes together, preserving proportions.
Axis cubes — Non-uniform
Scale a single axis to stretch or compress geometry.
Example & Checks
Example: Resize a table
Use uniform scaling to double overall dimensions. If you scale only width, check how UVs and normal maps behave after export.
Pitfall
Non-uniform scale can cause shading and animation issues if not accounted for in workflows.
Pro tip
After scaling, freeze transforms so the new scale becomes the default local size for exports.
Key Takeaway

Decide uniform vs non-uniform consciously; scale then freeze for consistent exports and predictable downstream behavior.
