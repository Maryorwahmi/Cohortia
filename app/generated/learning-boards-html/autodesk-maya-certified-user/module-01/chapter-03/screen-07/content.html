Architecture

What each handle controls

Knowing manipulator parts reduces mistakes and speeds precision work across modeling, rigging, and animation handoffs.

Axis arrows
Move along a single axis with numeric predictability.
Plane squares
Constrain movement to a plane — great for flat alignment tasks.
Center handle
Free transforms relative to view — useful for artistic adjustments.
Rotation rings
Provide axis-specific or visual orientation control with the inner free ring.
Scale cubes
Axis or uniform scaling with the center cube for proportional adjustments.
Checks & Notes
  • Manipulators reflect local or world orientation based on your transform space setting.
  • Parenting changes apparent manipulator behavior — confirm pivot relationships before bulk operations.
  • Use snapping to combine precise magnet-style placement with manipulator control.
Key Takeaway

Treat the manipulator as a precision instrument; select the handle that enforces the constraint you need.
