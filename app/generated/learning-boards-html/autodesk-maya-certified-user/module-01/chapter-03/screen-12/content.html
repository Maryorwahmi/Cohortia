Module 2 › Chapter 1.3 › Curve Snapping
Use Case

Place objects along paths

Use curve snapping to follow rails or paths for repeated asset placement, saving time and ensuring consistent alignment.
Step: Snap pivot to curve
Select the pivot or component, hold the curve snap key, and drag onto the curve to attach it.
Tip
For even spacing, snap one object, duplicate it along the curve, or use duplication tools with snapping enabled.
Common Mistakes
  • Forgetting to select the pivot or component before snapping.
  • Leaving the snap hotkey pressed and causing unintended subsequent snaps.
  • Snapping while in pivot edit mode and accidentally moving the pivot instead of the object.
Key Takeaway

Curve snapping is powerful for path placement — confirm your selection target and release the hotkey after each placement.
