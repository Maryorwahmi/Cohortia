Modes

Grid, Point, Curve

Use snapping to solve alignment problems quickly and consistently when placing modular assets, props, and rails.
Grid snapping
Snap transforms to grid lines and intersections for modular layout precision.
Point snapping
Snap to exact vertices for edge-to-edge alignment and dimensionally tight seams.
Curve snapping
Snap an object's pivot or component to follow a curve for path placement tasks.
Practical Tips
  • Hold the snapping hotkey only while moving. Release it after placement.
  • Combine snapping with plane handles to keep alignment clean on a selected plane.
  • Use point snapping when assembling modular geometry to avoid gaps or overlaps.
Key Takeaway

Pick the snapping mode that matches your task: grid for layout, point for seams, curve for paths — and release hotkeys when done.
