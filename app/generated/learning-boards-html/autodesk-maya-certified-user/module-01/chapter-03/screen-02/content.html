Tool Mastery: Move/Rotate/Scale
You will perform axis-constrained and plane-constrained transforms to position and size objects accurately. This matters because predictable transforms speed up modeling and prevent export surprises.

Pivot Control

VERIFIED COMPETENCY MILESTONE

Precision Snapping

Cleanup for Export
You will freeze transforms and delete history so objects import into engines with predictable defaults and light scene size.

How we'll practice
  • Create a cube and practice axis and plane movement.
  • Edit a cylinder pivot to simulate a door hinge and rotate it.
  • Use grid and point snapping to align two cubes exactly.
  • Freeze transforms and delete history before exporting a final asset.
