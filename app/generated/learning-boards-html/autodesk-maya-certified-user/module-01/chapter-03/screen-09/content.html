Module 2 › Chapter 1.3 › Door Pivot Walkthrough
Step-by-step
  1. Create a polygon cylinder to represent the door geometry.
  2. Press D to enter pivot edit mode; the pivot becomes movable.
  3. Move the pivot to the cylinder’s edge, snapping to a vertex for precision if needed.
  4. Press D to lock the pivot, then switch to Rotate and test the swing.
  5. If satisfied, use Freeze Transformations so the new pose becomes the default local transform.
This reproducible procedure ensures that rotations behave logically and that exports reflect the intended default orientation.
Checks & Common Issues
  • Did the pivot move far enough to the edge? If not, rotations may still look centered.
  • Are child objects behaving unexpectedly after pivot change? Re-parent or adjust as needed.
  • Remember to freeze transforms to set clean default values before exporting.
Key Takeaway

Test pivot edits immediately by rotating and then freeze transforms to make them permanent for exports.
