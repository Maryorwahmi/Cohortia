Module 2 › Chapter 1.3 › Rotate Tool
Definition

Rotate with axis rings and free ring

Rotation orients an object. You will use axis rings for exact control and the inner ring to visually match the camera view.

Axis ring
Drag a colored ring to rotate around that axis and watch the channel values update.
Inner ring
Rotate freely relative to the camera for visual alignment of props or art direction tweaks.
Example & Pitfalls
Example: Tilt a lamp shade
Activate Rotate, select the appropriate axis ring, and drag until the shade tilts to the desired world angle. Use the Channel Box to type an exact degree if needed.
Misconception
Assuming rotation ignores pivot location. If the pivot is offset, rotation will appear to move the object in space rather than simply turning it.
Pro tip
Check pivot placement before rotating and freeze transforms when preparing animated exports.
Key Takeaway

Rotation is always relative to the pivot; set pivots intentionally and use axis rings for reproducible orientations.
