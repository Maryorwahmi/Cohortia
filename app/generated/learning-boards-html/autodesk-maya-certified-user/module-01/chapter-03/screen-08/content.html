Module 2 › Chapter 1.3 › Pivot Point
Definition & Steps

Edit pivot with intent

Follow a clear process when editing pivots so rotations and scales behave as expected in rigs and exports.
1. Select object
Confirm geometry and intended rotation axis before editing pivot.
2. Press D to enable pivot edit
The pivot becomes movable with the Move manipulator.
3. Position pivot and press D to lock
Locking ensures future transforms use the new pivot.
Example & Cautions
Example: Door hinge
Move the pivot to the cylinder’s edge to simulate a hinge. After locking, rotations produce a realistic swing.
Common Mistake
Leaving pivot edit active and then trying to transform the object instead of the pivot.
Pro tip
When pivoting for animation, consider local axes and parent relationships first.
Key Takeaway

A correctly placed pivot produces predictable transformations and reduces surprises when animating or exporting.
