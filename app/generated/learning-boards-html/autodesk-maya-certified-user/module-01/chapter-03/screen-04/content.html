Process

Translate along axes and planes

Step-by-step practice and the reasoning behind axis vs plane movement for precise placement.

1. Activate Move (W)
Switching tools by hotkey keeps modeling flow fast and low-friction.
2. Use axis arrows
Drag a colored arrow to move along a single axis without affecting the others.
3. Use plane handles
Drag the square between axes to constrain motion to that plane — ideal for aligning to surfaces.
Visual Guide
Manipulator Anatomy
  • Arrows = single-axis translation (X, Y, Z).
  • Between-axis squares = plane-constrained moves (XY, YZ, XZ).
  • Center square = free move relative to view.
Example
Create a cube. Press W. Drag the red arrow to place it exactly along a corridor wall.
Common Mistake
Using free move when you need grid alignment — this can misalign modular geometry.
Key Takeaway

Choose axis or plane handles intentionally; pair with snapping for repeatable placement.
