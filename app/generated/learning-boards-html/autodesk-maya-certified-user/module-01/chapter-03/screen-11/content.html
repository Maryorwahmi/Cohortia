Module 2 › Chapter 1.3 › Snapping Comparison
Grid Snapping

When to use

Best for modular layout and consistent world alignment across large scenes.

Example
Aligning modular floor tiles or city blocks so they tessellate on a fixed grid.
Point Snapping

When to use

Use when two specific vertices must occupy the exact same position.

Example
Snapping a corner vertex of one wall segment to the corner of another for a seamless joint.
Common Mistake

Don’t substitute grid snapping for vertex snapping when an exact seam is required; use point snapping for perfect matches.
