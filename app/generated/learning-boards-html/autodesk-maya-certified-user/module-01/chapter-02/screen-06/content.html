Module 1 › Chapter 1.2 › Create & Rename Workflow
Five-step process
1. Create
Use Create > Polygon Primitives to place new geometry at the origin.
2. Rename
Rename the transform node right away in the Outliner or Channel Box with a descriptive label.
3. Position
Move and rotate the transform to place the primitive in the scene where you need it.
4. Inspect shape
Confirm the shape node exists so you can apply materials or edit geometry when necessary.
5. Organize
Group or parent the object once it belongs to a larger assembly.
Example task
Create three primitives: cube, sphere, cylinder. Rename them Body, Head, Neck. Move the Head above the Neck and the Neck above the Body so they visually stack. Inspect the Outliner to see pCube1 and pCubeShape1 entries reflected by your renames.
Check your understanding
What happens if you rename only the shape node but not the transform? You may still see the default transform name appear in selection lists and export utilities.
