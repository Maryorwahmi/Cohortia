Module 1 › Chapter 1.2 › Hands-on Lab
Lab walkthrough
Steps
  1. Create a cube, sphere, and cylinder from Create > Polygon Primitives.
  2. Rename transforms to Body, Head, Neck in the Outliner.
  3. Position Head above Neck and Neck above Body using Move.
  4. Parent Head to Neck and Neck to Body using P or drag in the Outliner.
  5. Select all and press Control+G to create SimpleCharacter_GRP and rename it.
  6. Adjust the group's pivot if rotation behaves unexpectedly.
Common checks
  • Does the Outliner show Body → Neck → Head?
  • Do materials apply to shape nodes rather than transforms?
  • Is the group pivot centered appropriately for rotation?
Scenario
You are preparing a character for a game engine. Build and organize the simple character so it exports as a single group and retains local motion for head and neck during animation.
Key Takeaway

This lab reinforces the create → name → parent → group sequence that keeps assets clear and engine-friendly.
