Module 1 › Chapter 1.2 › Primitive Objects
Definition
Primitive objects are basic polygonal shapes created as starting geometry or placeholders during scene layout. They appear at the origin and should be renamed immediately.
Common primitives
Cube, Sphere, Cylinder, Cone, Plane, Torus — each useful for different modeling goals or placeholder roles.
Practical tip
Rename freshly created primitives in the Outliner or Channel Box to descriptive names like Body, Head, or Neck to avoid later confusion.
Hands-on example
Create a cube, a sphere, and a cylinder. Rename them to Body, Head, and Neck to simulate character parts. Observe they appear in the Outliner with those names.
Example
In a blank scene create: Cube → rename Body; Sphere → rename Head; Cylinder → rename Neck. These three form the simple character core.
Common mistake
Leaving default names like pCube1 makes selection and export confusing as scenes grow. Avoid this by renaming immediately.
Key Takeaway

Treat primitives as intentional geometry or placeholders and name them clearly to support future edits and exports.
