Grouping — when and how to use it
What grouping does
Creates an empty transform node that becomes the parent for selected objects, enabling collective operations without altering the internal parent-child relationships of those objects.
How to group
Select objects and press Control+G, then rename the group node. Adjust the pivot if necessary with the pivot tool before transforming.
Example
Select Body, Neck, Head, press Control+G to create SimpleCharacter_GRP. Rotate the group to move the assembly together; adjust pivot if rotation looks off.
Common mistake
Grouping without setting the pivot can lead to awkward rotations. Always check and set the pivot after grouping if the default center is not suitable.
Key Takeaway

Use groups to collect related items for export and scene management, and correct pivots to avoid transformation surprises.
