Rule 1: Rename
Give primitives meaningful names immediately.
Rule 2: Nodes
Transform for motion; shape for geometry and materials.
Rule 3: Organize
Parent for behavior, group for packaging and export.
Final takeaway

Apply these three rules each time you create objects. Consistency is the fastest path to scenes that are easy to animate, maintain, and export.
