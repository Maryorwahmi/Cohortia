Module 1 › Chapter 1.2 › Transform vs Shape
Claim
Every polygonal object in Maya consists of a transform node (position, rotation, scale) and a shape node (geometry and material). They are separate, linked objects in the scene graph.
Transform node
Holds translate, rotate, and scale values manipulated by tools. Parenting and grouping affect transforms.
Shape node
Holds mesh data and material assignments. Materials attach to the shape, not to the transform.
Concrete example
Create a sphere. In the Outliner you will see pSphere1 and pSphereShape1. Select pSphere1 and move it. The shape follows because transforms control placement. Select the shape to change material or geometry.
Misconception
Applying a texture to the transform has no effect. Materials must be applied to the shape node which owns geometry data.
Key Takeaway

Know which node holds transforms and which holds geometry so you edit the correct attributes and avoid wasted steps.
