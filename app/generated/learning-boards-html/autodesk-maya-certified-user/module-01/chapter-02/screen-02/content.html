Learning Objectives
Learn core scene-building skills and why they matter for modeling, animation, and game export.
01
Create & manipulate primitives
Practice generating cubes, spheres, and cylinders and adjusting transforms. This skill matters because primitives are the building blocks of models and quick placeholders during layout.
Mnemonic: three shape icons in a row
VERIFIED COMPETENCY MILESTONE
02
Differentiate transform and shape nodes
Understand that transforms control position, rotation, and scale while shape nodes store geometry and materials. Knowing this avoids confusion when duplicating or instancing geometry.
Mnemonic: split card labeled Transform / Shape
VERIFIED COMPETENCY MILESTONE
03
Use the Outliner effectively
Rename, drag, and reorder scene elements. A clean Outliner saves time and prevents selection errors later in animation and export stages.
Mnemonic: stacked list icon
VERIFIED COMPETENCY MILESTONE
04
Group and parent objects
Create groups and parent-child hierarchies so assemblies respond as a unit while allowing local edits. This is essential for animation rigs and game assets.
Mnemonic: nested boxes icon
VERIFIED COMPETENCY MILESTONE
