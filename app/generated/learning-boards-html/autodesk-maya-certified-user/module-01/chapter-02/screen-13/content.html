Quick runtime checks
Move test
Select the top-level parent or group and translate it. All children should follow with identical relative offsets.
Rotate test
Rotate the parent and ensure children rotate around the intended pivot. If rotation is wrong, adjust the pivot.
Local child control
Select a child and perform a local transform to confirm it still retains independent control relative to the parent.
Troubleshooting
If children do not follow, re-check the Outliner to ensure the correct parent-child relationship, and verify you did not group incorrectly.
Key Takeaway

Simple move and rotate tests catch hierarchy mistakes early and prevent problems in animation and export stages.
