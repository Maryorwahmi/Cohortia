Module 1 › Chapter 1.1 › Mini Lab
Step-by-step
  1. Create a polygon cube and frame it with the frame key.
  2. Practice orbit, pan, and zoom until movement is smooth.
  3. Add a sphere and the move tool to a custom shelf using the modifier click.
  4. Use Q, W, E, R to select, move, rotate, and scale the objects.
  5. Set a transform value in the channel panel and save the workspace.
Reflection
Which step felt slow? Repeat that drill three times. Habit comes from short, frequent practice cycles.
Key Takeaway

Completing the full lab once gives you a reproducible layout and a short checklist to repeat when starting any new project.
