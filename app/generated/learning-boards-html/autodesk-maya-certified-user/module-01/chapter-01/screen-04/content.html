Definitions & Roles
Menu Bar — full command catalogue for all Maya operations.
Status Line — quick toggles and commonly used modes for immediate changes.
Shelves — your custom toolbar made of icons and short commands.
  • Practical: add sphere and move to a custom shelf so they are a single click away.
  • Misconception: you don't need to memorize every menu; curate the small set you use daily.
Example workflow
Modeling setup
Open the polygons shelf, add primitives and boolean tools, then save the shelf to keep these tools for all modeling sessions.
Key Takeaway

Top-row controls reduce friction: menus hold everything, status shortcuts speed common actions, and shelves make your frequent tools instant.
