Three-step navigation routine
  1. Frame the object with the frame key so it fills the view and becomes the camera focus.
  2. Orbit to inspect shape by holding Alt and using the left mouse button to rotate around the subject.
  3. Pan with Alt plus the middle button to shift the camera horizontally or vertically without rotating.
  4. Zoom with Alt plus right button or the scroll wheel to move closer or farther for details.
Misconception
Navigation moves the camera, not the object. Use the transform tools for object movement.
Guided example
Create a cube. Press F to frame it. Orbit 90 degrees to view the side, pan down to center the subject, then zoom in to examine edges. If you lose the cube, press A to frame everything in the scene.
Key Takeaway

Practice the frame-orbit-pan-zoom loop until it becomes a single fluid action you perform before edits.
