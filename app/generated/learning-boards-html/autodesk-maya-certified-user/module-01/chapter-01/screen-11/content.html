Shelves: quick customization
Hold the modifier keys described in the UI and click a menu entry to add it to a shelf. Group tools by task: Modeling, Rigging, or Rendering.
Tip: add both primitives and transformation tools to the same shelf for one-click access during layout tasks.
Save workspace
Arrange panels, then save via the workspace menu under a descriptive name so you can recall it later. Save frequently and after any meaningful change.
Key Takeaway

A saved workspace is a small configuration that consistently returns your tools and panels to the positions that support your best work.
