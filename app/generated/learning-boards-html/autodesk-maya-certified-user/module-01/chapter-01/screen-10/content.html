Core hotkeys
Q — Select
W — Move
E — Rotate
R — Scale
Spacebar — Toggle single view and quad view
Drill: one-minute speed run
Create a cube and then, using only hotkeys, select it, move it, rotate it, and scale it. Toggle quad view with Spacebar to check alignment. Repeat until you can complete the sequence in under one minute.
Key Takeaway

Commit a small set of hotkeys to memory; they deliver the largest immediate productivity gains.
