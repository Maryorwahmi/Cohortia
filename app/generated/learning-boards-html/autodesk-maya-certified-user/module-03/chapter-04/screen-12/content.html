Module 4 › Chapter 3.4 › Lab: Polygon Pipe
Starter steps
  • Create a Polygon Pipe and add subdivisions and caps.
  • Apply a Blinn with a 10–12 repeat checker for visual validation.
  • Apply Cylindrical Mapping and inspect initial projection in the UV Editor.
Editing steps
  1. Select seam edge loops and run Cut UV Edges to form body and caps.
  2. Unfold each shell (Unfold 3D for the body) and run Optimize to relax distortion.
  3. Match texel density by scaling shells relative to a chosen reference.
  4. Run UV > Layout with padding 0.005, then tidy shells manually for tighter packing.
Verification checklist
Checker uniformity across body and caps.
No overlapping shells, and adequate padding visible in the UV Editor.
Delete history to avoid export issues.
