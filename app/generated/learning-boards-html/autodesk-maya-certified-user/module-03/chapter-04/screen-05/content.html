Module 4 › Chapter 3.4 › Cut & Sew
Step-by-step
  1. Edge selection: Switch to edge mode and pick a continuous loop to define your seam.
  2. Cut: Use Cut UV Edges to separate shells and create islands for unfolding.
  3. Unfold check: Unfold shells to inspect distortion before any sewing attempts.
  4. Sew: Select matching border edges and use Sew UV Edges to stitch shells; confirm vertex order alignment.
  5. Iterate: Repeat cut, unfold, optimize, and sew until shells balance distortion and paintability.
Illustrative cards
Example: On a pipe, cut a vertical seam and separate cap edges so each can be unfolded cleanly.
Pitfall: Sewing mismatched borders can create flipped islands. Reverse or reselect edges to correct order.
Pro tip: Use shell preview after cuts to see how many islands you have before committing to heavy sewing.
Key Takeaway

Cut to control how a surface flattens; sew to reduce seams when it improves painting or packing without reintroducing stretch.
