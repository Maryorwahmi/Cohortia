Module 4 › Chapter 3.4 › Unfold & Optimize
How Unfold works
Unfold relaxes a shell by minimizing local distortion while trying to preserve proportional relationships from the 3D surface. Use Unfold 3D for curved geometry to respect surface curvature during flattening.
Best practices
  • Run Unfold on each shell, then use Optimize to smooth small irregularities.
  • Iterate: if distortion remains, change seams instead of forcing shells to compensate.
  • Validate with a checker texture — visual uniformity beats numeric perfection.
Misconception
Unfold won't fix poor seam choices; it works best when shells are logically laid out and not artificially constrained by bad cuts.
Example check
Apply a 10x10 checker, run Unfold on the cylinder body, then Optimize; the squares should become near-uniform.
Pro tip: Relax edges manually if pinching persists after Unfold and Optimize.
Key Takeaway

Unfold then Optimize as an iterative loop; validate with a checker and adjust seams if visual stretch remains.
