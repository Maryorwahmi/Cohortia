Module 4 › Chapter 3.4 › Texel Density — Hands-on
Step-by-step: numeric + visual
  1. Choose a target density based on texture size and model scale.
  2. Apply a checker texture to the object with a repeat that makes the target size visible.
  3. Select a shell and use the UV Toolkit measure/set density tools or scale while observing the checker until it matches.
  4. Repeat for all shells that should share density, then re-pack and re-check after layout.
Pro tip
Use a consistent measuring unit across your assets so values transfer well between models and texture atlases.
Example: pipe shells
Unfold the body, set the body’s density as the target, then scale the top and bottom caps so the checker squares match in size. Finally, run Layout to pack shells with consistent scale.
Common mistake
Scaling shells without re-packing can leave overlaps or wasted space; always verify layout after density changes.
