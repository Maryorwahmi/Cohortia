Module 4 › Chapter 3.4 › Bleeding & Padding
What causes bleeding
Mipmapping and compression blend neighboring texels at lower resolutions. If shells sit too close, those blended pixels appear on adjacent shells, producing color smears or artifacts.
How to prevent it
  • Set shell padding in Layout to a small positive value (e.g., 0.005).
  • Leave extra margin for shells that will be scaled up in-game or use unique detail maps.
  • Test with downscaled mipmap previews or engine imports to validate.
Example & checklist
Example: Two nearby shells with an 8px color edge will bleed into each other when mipmapped; add padding to avoid it.
Checklist: set padding, re-pack, run mipmap preview, and inspect edges for color smears.
