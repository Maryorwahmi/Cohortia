Common Mistakes
What to check first
Small misconfigurations cause big visual errors. Follow a checklist to save time.
File Color Space
Set normal maps to raw/linear. Color maps typically use sRGB.
Bump2D Use As
Switch Use As to Tangent Space Normals for normal maps; use Height for bump maps.
Bump Depth
Keep values subtle; exaggerated depth reads as fake under dynamic lighting.
Workflow Tips
Naming & Grouping
Name nodes and group them so you can find and fix misconnected maps quickly in Hypershade.
Bake for Engine
Bake procedural networks to textures for runtime efficiency, keeping per-asset tiling and UVs consistent.
