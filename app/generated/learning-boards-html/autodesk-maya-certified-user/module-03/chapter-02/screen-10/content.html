Module 3 › Chapter 3.2 › Bump vs Normal
Comparison
Bump Mapping
Grayscale maps adjusting perceived height. Easier to author but limited in directional accuracy.
When to use
Quick prototyping and subtle surface noise where directionality is not critical.
Limitations
Cannot represent full normal direction; silhouette remains unchanged.
Comparison
Normal Mapping
RGB maps storing surface orientation vectors for accurate shading and directional detail under varied lighting.
When to use
High-fidelity game assets, baked from high-poly models to preserve edge definition and directional shading.
Setup Note
Set File node color space to Raw and Bump2D Use As to Tangent Space Normals when using a tangent-space normal map.
