Architecture
Hypershade Node Graphs
Build materials by connecting outputs to inputs. Nodes represent Files, Procedurals, Utilities, and Shaders.
Nodes
File, Ramp, Noise, Bump2D, Blinn, and utility nodes each provide outputs you can wire into material inputs.
Concrete Example

Connect ramp1.outColor → my_advanced_blinn.color and noise1.outAlpha → bump2d1.inAlpha → my_advanced_blinn.bumpMap.

Naming
Name nodes clearly and group related nodes so you can reuse textures across materials while varying parameters per instance.
