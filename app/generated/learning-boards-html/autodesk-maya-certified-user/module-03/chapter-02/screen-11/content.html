Module 3 › Chapter 3.2 › Hands-on Build
Setup
Scene & Material
Create a polygon sphere and directional light. Open Hypershade and make my_advanced_blinn.
Ramp to Color
Click the Color link and choose Ramp. Set Type to Radial for a soft core or Linear for bands.
Noise → Bump2D
Connect Noise to Bump2D and adjust Bump Depth and Frequency to taste. Layer noises for complexity.
Observe
What to Look For
Rotate around the sphere and watch highlights. Ramp affects color; noise affects surface shading without changing the silhouette.
Common Fixes
If bump looks extreme, reduce Bump Depth. If normal information looks wrong, check the File node color space and Bump2D settings.
