Module 3 › Chapter 3.2 › Ramp & Checker
Step-by-Step
Create Render Node → Ramp/Checker → Tweak
This flow helps you iterate color and pattern without external textures.
1. Select a Blinn
Click the checkered box by Color in the Attribute Editor to open Create Render Node.
2. Choose Ramp or Checker
Maya creates the node and links it automatically. Adjust Repeat UV or Color Entry List next.
Concrete Example
Set ramp1 Type to Radial on a sphere and place color stops to make a lit-core effect, then use noise to add subtle surface variation.
Checks & Tips
UV Awareness
If procedurals stretch, fix UVs or adjust Repeat UV to maintain proportion.
Combine Masks
Multiply a grunge map over a Ramp to break uniform gradients and add realism.
