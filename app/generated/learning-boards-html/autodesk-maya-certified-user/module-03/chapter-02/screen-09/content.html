Module 3 › Chapter 3.2 › Noise → Bump2D
Process
Noise → Bump2D → Material
Create procedural depth cues with layered noise and controlled bump depth.
Parameters to Tune
  • Noise Frequency — scale of features
  • Bump Depth — intensity of apparent height
  • Noise Ratio/Depth — complexity and contrast
Concrete Example
Layer a low-frequency noise for overall roughness and a high-frequency noise for fine grain. Connect both into a layered bump network for depth variation.
Misconception
Bump maps change shading only. They do not alter geometry silhouette; use normal maps when silhouette detail is required.
Observation Checklist
Viewport Check
Press 6 to show textures, rotate camera, and inspect how highlights react to bump adjustments.
Performance Tip
Prefer procedural noise for tiling and memory efficiency; bake to textures later if needed for engines.
