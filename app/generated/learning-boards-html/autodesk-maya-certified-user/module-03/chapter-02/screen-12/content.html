Module 3 › Chapter 3.2 › Normal Map Setup
Definition
Color Space & Use As
Keep normal maps in raw color space and set Bump2D to read them as tangent-space normals for accurate vector data.
Step
Load normal map in File node → set Color Space to Raw/Linear → connect to Bump2D → set Use As to Tangent Space Normals → connect to Normal Camera.
Why it matters
Preserving RGB values ensures the encoded vector directions remain correct and highlights respond properly to lighting.
Checks
Rotate Light
Correct normals will alter highlight direction as lights move. If lighting looks wrong, re-check color space and Use As.
Result Demo
When set correctly, a sword's edge will catch light as if geometry were present, despite being low-poly.
