In this lesson

You will learn how physical attributes like reflectivity and roughness change shading, how incandescence creates glow, and how to assemble those properties with Hypershade nodes. Practical examples target game-ready assets where polygon budgets matter.

Why it matters
Control over these properties lets you sell material realism while keeping geometry light, essential for performant game assets.
How you'll practice
