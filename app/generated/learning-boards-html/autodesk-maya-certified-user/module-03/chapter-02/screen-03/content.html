Practical Outcomes
Concrete skills to use on a test sphere and game asset prototypes
Workflow
Create a Blinn called my_advanced_blinn, connect a Ramp to Color, and connect Noise through Bump2D to the Bump Map.
Debug Steps
Check viewport mode, set normal maps to raw color space, and set Bump2D Use As to Tangent Space Normals when appropriate.
Goal
Produce a convincing surface on a low-poly asset that reads well under game lighting while keeping file sizes small.
Check
Compare bump vs normal by rotating the camera and watching highlight behavior; decide which preserves silhouette and which only affects shading.
