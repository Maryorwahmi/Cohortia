Module 3 › Chapter 3.2 › Incandescence
Definition
Emissivity / Incandescence
Make a surface appear to emit light by setting a color and intensity on the incandescence attribute.
Visual Use
Use for screens, lights, or magical glows that should read as lit even without nearby lights.
Concrete Example

Set a soft blue incandescence on a robot eye to simulate self-illumination for a game character and pair it with bloom in post for effect.

Common Mistake
Expecting incandescence alone to light surrounding geometry in all renderers. Confirm renderer support for emissive lighting if needed.
Practical Checks
Renderer Compatibility
If you need actual light, add a small light source or use a renderer that converts emission to scene lighting.
Art Direction
Use color and intensity to match environment mood; strong incandescence can appear flat without bloom or contrast.
