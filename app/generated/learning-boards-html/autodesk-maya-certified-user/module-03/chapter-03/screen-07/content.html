Module 3 › Chapter 3.3 › Planar Projection
When to use

Flat, single-direction surfaces

Best for walls, floors, and planar faces; quick and precise when the surface aligns with an axis.

Step-by-step
  1. Select faces or object.
  2. UV > Planar Mapping > set axis in options.
  3. Adjust the manipulator and scale in the UV Editor.
  4. Verify with a checker and pack into 0-1.
Example

Project a book cover from the front axis so the cover becomes a neat rectangle in the UV Editor ready for painting.

Common mistake

Applying planar mapping to curved geometry causes extreme stretching and visible seams.

Check

After projection, apply a checker with repeats of 10,10 and ensure tiles are uniform; if not, reposition or choose a different projection type.
