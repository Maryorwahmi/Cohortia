The normalized UV square

This area defines the coordinates that a single texture occupies. Proper placement here affects sampling, mipmaps, and atlasing.

Packing & Texel Density

Scale shells so comparable parts share consistent texel density. Tiny shells yield blurry detail; oversized shells waste texture space.

Overlaps

Intentional overlaps can mirror symmetric details. Unintentional overlaps cause texture conflicts and baking errors.

Quick Tip

Use a tiled checker with repeat values to compare square sizes across shells rapidly.

Visual check
Good

Shells scaled and packed evenly, no overlap.

Problem

Tiny shell and a very large shell cause inconsistent detail and wasted space.
