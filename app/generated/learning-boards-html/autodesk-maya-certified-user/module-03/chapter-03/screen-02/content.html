Learning Objectives

Progress from definition to applied UV workflows you can use in Maya.

Bloom: Learn → Understand → Apply → Master
01
Define UVs

Explain U and V coordinates and why they map 2D pixels to a 3D mesh. This vocabulary helps you fix mapping issues faster.

VERIFIED COMPETENCY MILESTONE
02
Use the 0-1 UV space

Place and pack UV shells within the normalized square so textures and atlases behave predictably in renderers and game engines.

VERIFIED COMPETENCY MILESTONE
03
Navigate the UV Editor

Select UVs, edges, faces and apply transforms to adjust layout. Visual checks like a checker help find stretching quickly.

VERIFIED COMPETENCY MILESTONE
04
Apply basic projections

Choose planar, cylindrical, or spherical mapping for the right geometry and learn to split complex models into shells to avoid distortion.
