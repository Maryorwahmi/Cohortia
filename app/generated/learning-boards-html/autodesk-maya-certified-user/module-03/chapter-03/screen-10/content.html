Module 3 › Chapter 3.3 › Projection Comparison
Planar

Best for flat faces. Pitfall: severe stretching on curved surfaces.

Cylindrical

Wraps around tubes. Pitfall: seams and cap distortion if caps are not projected separately.

Spherical

Fits dome shapes. Pitfall: pole pinching and seam placement issues.

Try this experiment

Apply each projection to a sphere, cylinder, and plane and watch how the checker responds. The contrast is instructive.

Key Takeaway

Use the projection that matches curvature; refine with seams and separate shells when needed.
