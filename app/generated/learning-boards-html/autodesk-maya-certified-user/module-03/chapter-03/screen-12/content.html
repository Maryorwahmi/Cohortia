Cutting seams and building shells

Break models into logical pieces so each shell can be unwrapped with minimal distortion.

Planning seams
  • Pick hidden or natural edges where seams are less visible.
  • Avoid seams across detailed painted features.
Maya tools

Select edges and use UV > Cut, then unfold/relax and edit shells in the UV Editor.

Example

Split a character into torso, sleeves, and head shells. Project each appropriately and scale to equal texel density before packing.
