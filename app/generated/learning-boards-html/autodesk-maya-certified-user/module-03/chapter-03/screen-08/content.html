Module 3 › Chapter 3.3 › Cylindrical Projection

Use case and mechanics

Wraps textures like a label around the object. Adjust axis and radius with the manipulator for a clean unwrap.

Step-by-step
  1. Select faces or object.
  2. UV > Cylindrical Mapping > set axis (e.g., Y).
  3. Adjust manipulator to align radius and axis.
  4. Project caps separately if needed.
Practical Example

A tree trunk: cylindrical-map the bark region, planar-map the top and bottom to avoid pole distortion.

Issues to watch
  • Seam location where the wrap starts and ends may be visible; place seams where least noticeable.
  • Caps often need separate projections to avoid distortion at pole regions.
Check

Verify side tiles are square and seams are placed on non-prominent areas of the model.
