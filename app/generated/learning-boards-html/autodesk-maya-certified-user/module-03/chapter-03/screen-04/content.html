Module 3 › Chapter 3.3 › What are UVs?
Definition

UV coordinates explained

UVs pair every 3D vertex with a point in 2D texture space so that images map correctly onto geometry. They do not contain color data themselves.

Analogy
Unwrapping a gift box or peeling an orange to lay the surface flat for painting.
Common misconception

UVs are not the texture image. They are the coordinate system that tells the texture where to appear on the mesh.

Key Takeaway

A correct UV map is the foundation for any texture to look right on a 3D model.

Concrete example

Imagine painting eyes in a 2D image. If the head’s UVs for the eye region point to that painted area within the 0-1 square, the eyes will appear correctly on the model. If they point elsewhere, the texture will not match the mesh’s intended features.
