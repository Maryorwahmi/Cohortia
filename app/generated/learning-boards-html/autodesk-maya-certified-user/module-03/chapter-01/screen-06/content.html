Module 3 › Chapter 3.1 › Assigning Materials
Process

Three common assignment paths

  1. Right-click → Assign New Material: Fast for single objects during modeling.
  2. Hypershade create + drag: Create materials centrally and middle-mouse drag swatches to objects.
  3. Assign Existing Material: Reuse and swap materials without creating new nodes.
Pro tip: Use Hypershade when you plan to connect textures or utility nodes. Use right-click for quick visualization checks.
Concrete example
Create a sphere, cube, cylinder. In Hypershade make my_matte_red (Lambert), my_shiny_blue (Blinn), my_glossy_green (Phong) and drag each onto the primitives.
Common mistake
If you don’t see color changes, enable Hardware Texturing (press 6) — viewport preview must be active to show material colors and textures.
Key Takeaway

Use Hypershade for organized material work; use viewport assign for fast checks. Always confirm with hardware texturing.
