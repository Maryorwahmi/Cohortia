Module 3 › Chapter 3.1 › What is Shading?
Definition

Shading explained

  • Shading = rules that govern light interaction with a surface.
  • Includes diffuse response, specular highlights, and transmission.
  • Depends on surface normals, lighting, and view direction.
Common mistake
Editing object display color does not change shading; change the material attributes instead.
Key Takeaway

Observe the same object under a directional light and notice how diffuse and specular responses change with material parameters.

Concrete example: wall vs doorknob
Matte painted wall
Diffuse dominant, little to no specular. Light scatters; appearance remains similar from many angles.
Polished doorknob
Specular dominant; sharp bright highlights follow the light source and viewer position.
Try this
Rotate the camera and observe how specular highlights move—this verifies the highlight is a lighting interaction, not color.
Misconception check
If changing color has no effect, confirm hardware texturing is enabled so materials preview correctly in the viewport.
