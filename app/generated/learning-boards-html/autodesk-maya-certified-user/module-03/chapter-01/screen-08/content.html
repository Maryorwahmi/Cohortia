Attribute Editor

Key material attributes

  • Color: base diffuse tint used in shading computations.
  • Transparency: amount of light passing through a material.
  • Specular Roll Off (Blinn): intensity of the highlight.
  • Eccentricity (Blinn): spread of the highlight.
  • Cosine Power (Phong): sharpness of the highlight.
Practical order: set color, then specular type and roll, then tune eccentricity or cosine power while observing lighting response.
Concrete walkthrough
Select a sphere with my_shiny_blue, open Attribute Editor, find blinn1, drag Specular Roll Off and watch highlight intensity change in the viewport with hardware texturing enabled.
Misconception
Don't fix a dull material by only adjusting lights; first check material specular controls to achieve the intended reflectivity.
Key Takeaway

Adjust material attributes in the Attribute Editor and verify in the viewport with hardware texturing to judge final appearance.
