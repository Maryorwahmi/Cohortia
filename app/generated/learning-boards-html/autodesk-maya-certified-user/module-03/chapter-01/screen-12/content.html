Module 3 › Chapter 3.1 › Common Mistakes & Troubleshooting
Checklist
  • Enable Hardware Texturing (press 6).
  • Open Attribute Editor and confirm the material node is assigned.
  • Ensure shader type supports specular if you expect highlights.
  • Rename materials in Hypershade to avoid duplicates.
Following this checklist in order helps you quickly isolate viewport or assignment issues without changing lighting prematurely.
Concrete fix
If a new material appears gray, press 6 to enable hardware texturing. If still gray, confirm the object truly has the new material node in the Attribute Editor.
Avoid
Avoid changing the display/wireframe color and expecting render changes — that is a separate setting from the material node.
Key Takeaway

A short checklist — hardware texturing, attribute confirmation, shader capability, naming — resolves most visibility problems.
