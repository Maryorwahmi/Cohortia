Module 3 › Chapter 3.1 › Hands-on Activity
Scene setup
  1. Create Sphere, Cube, Cylinder via Create > Polygon Primitives.
  2. Add a Directional Light to illuminate the set.
  3. Open Hypershade (Windows > Rendering Editors > Hypershade).
Create materials
  • Lambert → rename my_matte_red → set Color to red.
  • Blinn → rename my_shiny_blue → set Color to blue.
  • Phong → rename my_glossy_green → set Color to green.
Assignment & verification
  1. Middle-mouse drag each material swatch from Hypershade onto the target primitive.
  2. Select object, open Attribute Editor to confirm the node name matches.
  3. Press 6 or enable Shading > Hardware Texturing to preview colors in viewport.
Common mistake: creating unnamed duplicate materials instead of renaming — use clear names for reusability.
Key Takeaway

Follow a create-rename-assign-check loop and always preview with hardware texturing to confirm your work.
