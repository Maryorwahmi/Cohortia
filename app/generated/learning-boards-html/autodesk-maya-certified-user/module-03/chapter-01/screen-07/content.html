Module 3 › Chapter 3.1 › Hypershade Overview
Hypershade panels
Create
Pick a material type to instantiate a node into the graph.
Browser
Locate existing nodes, textures, and utilities to reuse.
Work Area
Visually connect nodes; middle-mouse drag swatches to the viewport.
Start simple: create a material, rename it for your scene, drag to assign. Organize names like my_shiny_blue so you know the shader intent when reusing it later.
Concrete example
Create my_shiny_blue in Hypershade, middle-mouse drag onto a sphere, then open Attribute Editor to adjust Blinn specular controls.
Misconception
Some learners create duplicate unnamed materials instead of renaming nodes—this makes reuse and scene cleanup harder later.
Key Takeaway

Use Hypershade early to organize and name materials; it prevents duplicate shader nodes and simplifies reuse.
