Module 3 › Chapter 3.1 › Learning Objectives
01 Explain shading
Skin of the model
Practice describing how diffuse vs specular responses change the perceived material. Try comparing chalk and polished plastic aloud.
Mnemonic: skin = surface rules for light
VERIFIED COMPETENCY MILESTONE
02 Identify shaders
Matte, soft, sharp
Match Lambert to matte surfaces, Blinn to soft highlights, and Phong to sharp, mirror-like highlights.
Mnemonic: matte / soft / sharp
VERIFIED COMPETENCY MILESTONE
03 Assign materials
Drag or assign
Practice assigning with middle-mouse drag from Hypershade and with viewport right-click Assign Existing commands.
Mnemonic: drag or assign
VERIFIED COMPETENCY MILESTONE
04 Edit attributes
Attribute Editor is authoritative
Change color, transparency and specular controls in the Attribute Editor — not the object display color — to affect rendered appearance.
Mnemonic: Attribute Editor = render attributes
VERIFIED COMPETENCY MILESTONE
