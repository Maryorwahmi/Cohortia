Module 6 › Chapter 6.4 › Point Constraint
Definition

Point Constraint

Transfers translation only. Useful when you want position control without affecting orientation.

When to use
Props, locators, or cases where orientation should remain driven by another node.
Pairing
Combine with Orient Constraint if you need both translation and rotation control but want to keep them separate logically.
Key Takeaway

Use Point Constraints when only position should follow the control and orientation must remain independent.

Concrete Example
Prop Positioning
Create a locator for a prop, apply a Point Constraint from the hand control so the prop follows hand translation while rotation stays controlled elsewhere.
Misconception
Point does not copy rotation. If the slave appears rotated unexpectedly, check other constraints or parent transforms affecting orientation.
