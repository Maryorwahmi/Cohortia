Core Concept

Control Objects: NURBS Curves as Animator Handles

Controls are lightweight, non-rendering shapes that let animators pose without touching rig internals.

Definition
Custom NURBS curves used as the animator-facing handles for a rig.
Why use NURBS curves?
  • They don’t render, avoiding render overhead.
  • They are easy to select and reshape.
  • Color and form provide fast visual cues for animators.
Common-mistake
Using meshes as controls or creating overly complex shapes that slow viewport selection.
Key Takeaway

Simple NURBS curves provide clear, non-rendering handles that save animators time and prevent errors.

Visual Examples
Circle — head
Square — hips
Arrow — hands/feet
Color-coding
Use left/right or body-area color conventions so animators instantly recognize controls.
