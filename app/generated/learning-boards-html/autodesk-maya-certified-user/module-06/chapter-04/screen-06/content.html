Module 6 › Chapter 6.4 › Freeze & History
Definition

Freeze Transformations & Delete History

Two cleanup steps that set an object's zero pose and remove construction nodes.

Freeze Transformations
Sets translate, rotate, and scale channel values to zero while keeping the object in place visually.
Delete History
Removes construction history so old tool operations do not affect later edits.
Key Takeaway

Always freeze and delete history before constraining a control to ensure resets are predictable and the scene is clean.

Concrete Example
Creation Snap Example
You create a control at the origin, move it into place but forget to freeze. Later, the animator resets channels and the control jumps back to origin. Freeze fixes this by zeroing internal channels without moving the visible shape.
Misconception Check
Freezing does not change the visible position; it changes internal channel values. If it appears to move, a parent transform still affects it.
