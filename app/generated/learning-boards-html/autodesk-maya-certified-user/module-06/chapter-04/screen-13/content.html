Module 6 › Chapter 6.4 › Key Concepts — Part 1
Control Object
A NURBS curve used by animators to pose a character without touching joints.
Constraint
A node that makes one object drive another's transform attributes.
Parent Constraint
Transfers translate, rotate, and scale from master to slave.
Summary

Keep controls simple, freeze and clear history, and choose the right constraint so animators have stable, reversible rigs.
