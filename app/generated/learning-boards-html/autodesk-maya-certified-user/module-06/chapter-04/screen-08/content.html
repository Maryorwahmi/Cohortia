Module 6 › Chapter 6.4 › Orient Constraint
Definition

Orient Constraint

Transfers rotation only. Ideal when position should remain driven elsewhere.

Usage
Use for fingers, head, or any joint where rotation control must be separate from translation.
Maintain Offset
Keep relative rotation if you don’t want the slave to snap to the master on apply.
Key Takeaway

Orient Constraints isolate rotation control, allowing position to remain governed by parent relationships or IK systems.

Concrete Example
Head Control
Make a head control rotate the head joint but keep head translation inherited from the neck joint. Apply Orient Constraint: control first, then head joint.
Misconception
Assuming Orient will handle position — it won't. Use Point Constraint if you need translation control too.
