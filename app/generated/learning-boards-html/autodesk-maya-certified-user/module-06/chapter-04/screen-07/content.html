Module 6 › Chapter 6.4 › Parent Constraint
Definition

Parent Constraint

Transfers translate, rotate, and scale from the master to the slave. Often used to make controls drive IK handles or joints.

When to use
When you need full transform control over the slave, e.g., a hand control driving an IK handle.
Options to watch
Maintain Offset toggles whether the slave keeps its relative transform to the master or snaps to it immediately.
Key Takeaway

Parent Constraints are powerful; confirm selection order and maintain offset settings to avoid unexpected snaps or overrides.

Example
Hand Control → IK Handle
Select the hand control, Shift-select the arm IK handle, apply Parent Constraint. Turn off Maintain Offset if you want the IK handle to snap to the control immediately.
Misconception
A Parent Constraint does not change object hierarchy. It only drives transforms; hierarchy and constraints together determine final behavior.
