Create a Control: From NURBS to Zeroed Handle

Follow the steps to craft a control that behaves predictably when reset and when constrained.

  1. Create a NURBS primitive or draw a curve to match the anatomy.
  2. Position & scale it so it surrounds the joint or IK handle comfortably.
  3. Freeze Transformations to set the current transforms as zero.
  4. Delete History to remove construction nodes that can cause instability.
  5. Group & name controls (eg. _CONTROLS_GRP) for Outliner clarity.
Check
Move and rotate the control, then reset transforms to verify no snapping occurs.
Example Scenario
Wrist IK control
Create a circle, snap it to the wrist IK handle, freeze transforms, delete history, and parent the curve under _CONTROLS_GRP. Test by dragging and resetting the control.
Common Mistake

Freezing while the control is still under a parent with non-zero transforms will keep unexpected offsets. Re-parent to world, freeze, then re-parent if needed.
