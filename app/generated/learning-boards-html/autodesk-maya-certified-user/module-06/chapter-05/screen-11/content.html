Process Flow
Iterative testing steps
  1. Pose: exercise neutral and extreme joint rotations.
  2. Animate: create short 1–3 second cycles to reveal dynamic pops.
  3. Isolate: hide non-essential helpers and test geometry alone.
  4. Adjust: fix weights, change joint influences, or add corrective shapes.
  5. Log: record test results and fixes for handoff history.
Common Mistake

Only testing in bind pose hides rotational artifacts. Always test across range of motion and with combined controls (e.g., twist + stretch + blend shapes).
