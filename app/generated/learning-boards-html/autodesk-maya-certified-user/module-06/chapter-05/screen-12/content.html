Module 6 › Chapter 6.5 › Cleanup & Export
Checklist
Final cleanup steps
  • Freeze Transformations on controls so channel defaults are zero/one.
  • Delete History on controls and non-deforming nodes — not on skinned meshes.
  • Hide joints/IK on display layers titled RIG_HELPERS.
  • Lock and hide attributes animators shouldn't change (scale, unwanted rotates).
  • Confirm clean hierarchy with a single root group like C_global_GRP.
Export Safety
Before exporting as FBX: bake animations if required, check joint orientations, remove non-deformer custom nodes, and select only the rig root and skinned geometry for Export Selection.
Key Takeaway

A predictable, minimal scene prevents headaches in downstream applications like game engines.

Simulated Export Walkthrough
Example sequence you would perform before File > Export Selection:
  1. Rename root: C_global_GRP.
  2. Hide helpers: place joints and IK into RIG_HELPERS layer and set visibility off.
  3. Lock & hide scale on controls like L_hand_CTRL.
  4. Delete history on controls only; do NOT delete history on skinned meshes.
  5. Select root + skinned meshes > File > Export Selection > FBX with Skins checked.
Export Options to check
Geometry: Smooth Mesh; Animation: Skins (and Bake if you exported animation); Embed Media if you want textures packed.
