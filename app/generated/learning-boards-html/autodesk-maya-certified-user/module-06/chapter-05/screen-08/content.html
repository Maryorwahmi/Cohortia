Process

IK, FK, Controls, and Constraints

Design animator-facing controls, implement IK/FK where appropriate, and apply constraints for reliable motion.

Control creation rules
  • • Build NURBS-curve controls, freeze transforms, delete control history, and name with _CTRL.
  • • Lock/hide attributes animators shouldn't alter (e.g., scale on translate-only controls).
  • • Group controls logically (e.g., L_arm_CONTROLS_GRP) for tidy Outliners.
IK vs FK guidance
  • • Use IK for planted interactions: hands and feet that stick to world space.
  • • Use FK for smooth rotational arcs and precise rotational animation.
  • • Consider an FK/IK blend when both behaviors are required by the shot.
Concrete scenario
If animating a character picking up a cup: use IK on the hand during the pick, then switch to FK for natural follow-through in the arm. Ensure pole vectors are set so the elbow consistently points where expected during the IK phase.
Key Takeaway

Expose only necessary animator controls, use clear naming and frozen transforms, and test IK/FK behavior in representative actions.
