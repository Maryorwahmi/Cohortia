Learning Objectives

Skills you will practice and verify during hands-on work.

Learn → Understand → Apply → Master
01
Outline a Rigging Workflow

Be able to describe each step from model prep through final cleanup and why it matters for reliable rigs.

Mnemonic: PB BPC C (Prepare, Build, Bind, Paint, Controls, Clean)
VERIFIED COMPETENCY MILESTONE
02
Implement Naming Conventions

Apply consistent prefixes and suffixes for side and type, so assets are searchable and scriptable.

Example: L_shoulder_JNT, R_hand_CTRL
VERIFIED COMPETENCY MILESTONE
03
Perform Scene Cleanup

Use delete history, freeze transforms, hide helpers, and lock animator-facing attributes correctly before handoff.

Mnemonic: Freeze, Hide, Lock — but don’t delete skin history after binding.
VERIFIED COMPETENCY MILESTONE
04
Prepare Rigs for Export

Ensure clean hierarchies, compatible nodes, and baked animation where required for engines like Unity or Unreal.

Quick check: single root, no non-deformer nodes, correct joint orientations.
VERIFIED COMPETENCY MILESTONE
