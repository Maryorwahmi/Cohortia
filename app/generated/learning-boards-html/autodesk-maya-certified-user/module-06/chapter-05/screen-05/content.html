Module 6 › Chapter 6.5 › Model Prep & Naming
Definition

Model Preparation

Ensure the mesh has clean topology, correct scale, and no construction or transform issues that would interfere with skinning and deformation.

Checklist
  • • Quads preferred; avoid N-gons where possible.
  • • Freeze transforms and set pivots correctly before creating controls.
  • • Fix non-manifold geometry and merge overlapping vertices.
  • • Only delete history on non-deforming objects; do not delete history on skinned meshes after binding.
Naming convention
Use: prefix for side + descriptive name + suffix for type. Keep names short but descriptive to aid searching and scripting.
L_shoulder_JNT
R_hand_CTRL
C_global_GRP
Why it matters
Consistent names let you select, script, and debug quickly. On complex rigs, descriptive names are the difference between a few minutes and hours of work when troubleshooting.
Common mistakes
  • • Using default names like joint1 or nurbscurve1 makes automation and handoff painful.
  • • Deleting history on skinned meshes after binding will remove the skin cluster and break the rig.
  • • Inconsistent side prefixes cause ambiguous selections and broken scripts.
Key Takeaway

Fix geometry and adopt a naming pattern before rigging. It saves debugging time and supports automation.
