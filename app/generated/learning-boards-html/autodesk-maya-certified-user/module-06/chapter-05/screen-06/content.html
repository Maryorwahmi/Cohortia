Architecture

Skeleton Creation & Joint Orientation

Design a logical hierarchy and unify joint axes for predictable rotations and clean constraints.

Hierarchy pattern
  • • C_root_JNT → pelvis chain → spine → clavicle → limb chains
  • • End joints for fingers and toes parented under respective wrists/ankles
Orientation tips
Use Orient Joint with consistent axis choice. Test with 45-degree rotations to reveal rotated axes that need correction.
Example check
Rotate the shoulder FK: the elbow should bend along a clean plane. If it twists unexpectedly, the elbow joint orientation needs adjusting.
Common mistake
Placing joints visually without snapping to pivot centers or leaving inconsistent local axes. This causes animation issues and makes constraints behave unpredictably.
Key Takeaway

Lock in joint positions and orientations before skinning. Test rotations immediately to confirm behavior.
