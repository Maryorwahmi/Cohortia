Definition
What is a blend shape?

A blend shape is a deformation node that linearly interpolates between a base mesh and one or more target meshes. Targets must share topology and vertex order with the base to blend correctly.

Workflow Checklist
  • Create target shapes (smile, frown, blink) preserving vertex order.
  • Select targets, then base mesh, use Deform > Blend Shape.
  • Expose sliders and connect them to controls or utility nodes.
Scenario

Drive a blink target via a control that also triggers an automated rapid blink when the character blinks naturally, using a utility remap for timing.

Key Takeaway

Blend shapes complement joint rigs for organic facial movement and should be named and organized for easy animator access.

Example: Simple Smile Blend
Steps illustrated:
  1. Sculpt the smile target mesh, keep topology identical.
  2. Select target(s) then base mesh, run Deform > Blend Shape.
  3. Rename slider to smile_BSH and parent an animator control to drive it.

Common misconception: "Blend shapes always replace joints." In reality, blend shapes often layer with joint deformation; ordering and intent determine whether they correct or override joint-driven results.
