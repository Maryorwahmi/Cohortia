Process

Initial Skinning and Weight Painting

Bind with smooth bind, then sculpt vertex influences using the Paint Skin Weights tool.

Core steps
  • • Smooth bind the geometry to the skeleton as the initial step.
  • • Test key poses immediately to identify problem regions.
  • • Use Paint Skin Weights to assign and smooth vertex influences.
  • • Save incremental versions before major changes.
Common adjustments
  • • Reduce influence from distant joints causing pinching.
  • • Add influence to joints that should carry the crease or twist.
  • • Smooth weights across an area to avoid hard seams.
Concrete example
If the elbow pins when you bend the arm, isolate the elbow region and paint stronger influence for the elbow joint while reducing shoulder influence. Test the bend until the silhouette reads correctly across poses.
Key Takeaway

Automatic binds are a starting point. Human-directed weight painting creates polished, believable deformations.
