Module 6 › Chapter 6.3 › Create IK Handle
Steps
  1. Prepare joint chain: confirm orientations and names like shoulder_JNT.
  2. Select start and end joints: shoulder_JNT then wrist_JNT.
  3. Create IK Handle: Rigging > Skeleton > Create IK Handle, choose solver in options.
  4. Rename and test: rename to L_arm_IK_HNDL and move it to verify behavior.
Quick tip
If joints rotate oddly after creating the handle, check joint orientation and undo to fix orientation before recreating the IK handle.
Visual Aid
Create IK Handle Options
Rotate Plane Solver for limbs; Single Chain Solver for single-axis chains like tails or simplified spines.
Example rename
L_arm_IK_HNDL — keeps the Outliner clear and indicates left side, limb, and handle type.
Key Takeaway

Selecting an appropriate solver during creation and testing immediately prevents downstream solving surprises.
