Module 6 › Chapter 6.3 › FK/IK Blend
Concept

Smooth transition between FK and IK

A blend attribute interpolates between FK rotations and IK solver output so animators can use both techniques on a single limb.

When to use
Switch to IK for contact or placement, use FK for arcs and follow-through. Blend when a shot needs both.
Important
Pose matching between FK and IK is necessary to avoid popping when the blend value changes.
Animator example
Use FK for a character's throw wind-up, switch to IK as the hand contacts the object, then blend back for follow-through arcs.
Misconception
Blending alone won't solve misaligned poses; you must align FK and IK poses for a smooth transition.
Key Takeaway

Blending provides flexibility but requires planning: align poses before switching to avoid visual pops.
