Module 6 › Chapter 6.3 › Activity: IK Arm — Create & Connect
Steps
  1. Select shoulder_JNT then wrist_JNT and use Create IK Handle with Rotate Plane Solver.
  2. Rename handle to L_arm_IK_HNDL and verify cross-shaped manipulator at the wrist.
  3. Select L_elbow_PV_CTRL, Shift-select L_arm_IK_HNDL, then use Pole Vector to connect.
  4. Parent or constraint L_arm_IK_HNDL under L_hand_CTRL and test movement.
Testing checklist
Move the wrist control to verify the arm follows, then move the pole control to check bend direction while wrist position stays fixed.
Debug tip
If elbow flips, move pole control further out and test different angles, or recheck joint orientation before recreating the handle.
Scene hygiene
Group rig controls and name nodes clearly. Parent controls under a rig group so animators can toggle visibility easily.
Key Takeaway

A connected pole vector and a parented IK handle deliver stable bending and a natural animator workflow.
