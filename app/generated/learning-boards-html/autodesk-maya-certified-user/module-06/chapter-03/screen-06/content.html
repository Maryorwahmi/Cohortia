What is a solver?

The algorithm that computes rotations

Solvers evaluate the joint chain and the end effector to compute each joint's rotation so the chain reaches the target position while respecting the solver's constraints.

Rotate Plane Solver (RP)
For limbs with an elbow or knee. Works in a bend plane and pairs with a pole vector.
Single Chain Solver (SC)
For chains with a single bend axis like tails or simplified spines.
Practical check
After selecting a solver, test typical animator poses to ensure the solver produces the expected bend and that a pole vector resolves ambiguity when needed.
Example
An RP solver for an arm yields a stable elbow when a pole vector is placed in front of the elbow; the SC solver used on a tail creates consistent single-axis bending.
Misconception
A solver choice is not permanent — you can recreate or retarget the handle if another solver fits the animation better, but plan around the animator's needs first.
Key Takeaway

Match the solver to the motion: RP for defined elbows/knees with pole vectors, SC for single-axis chains.
