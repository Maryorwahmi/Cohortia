Module 6 › Chapter 6.3 › Pole Vectors
Definition

An object that defines bend direction

Positioning a pole vector determines which side the elbow or knee faces by defining the solver's bend plane reference.

How to set up
  1. Create a NURBS curve or empty group and position it in front of the joint you want to control.
  2. Freeze transforms and delete history on the pole control.
  3. Select pole control, Shift-select IK handle, then Rigging > Skeleton > Pole Vector.
Best practice
Place the pole control at a comfortable animator distance, not too close, and test motions to confirm stability across poses.
Example
Place L_elbow_PV_CTRL in front of the elbow so the elbow consistently points forward when the hand moves.
Common mistake
Not connecting a pole vector to an RP solver often causes sudden flipping when the IK handle passes certain singularities.
Key Takeaway

A correctly placed and connected pole vector is the most reliable way to prevent elbow and knee flipping in RP IK chains.
