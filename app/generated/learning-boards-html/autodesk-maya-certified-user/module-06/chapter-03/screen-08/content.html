How to

Create and assign NURBS controls

1. Create controls
Make a NURBS circle for the wrist and a small shape for the pole vector. Place them at their target joints.
2. Freeze and clean
Freeze transforms and delete history to ensure controls have zeroed transforms for predictable parenting and constraints.
3. Parent or constrain the IK handle
Parent the IK handle to the wrist control or use a parent constraint so the control drives the handle while keeping the original solve behavior.
Scenario
An animator grabs L_hand_CTRL to place the hand; the wrist control moves the IK handle so the arm follows, and the L_elbow_PV_CTRL sets the elbow direction.
Naming convention
Use side prefixes and clear suffixes: L_hand_CTRL, L_elbow_PV_CTRL, L_arm_IK_HNDL to keep Outliner readable.
Test
Move the wrist control, move the pole control, and verify the wrist position stays consistent while the elbow updates to the pole position.
Key Takeaway

Animator-facing controls make rigs comfortable to use and hide technical nodes like IK handles and pole vectors from everyday selection.
