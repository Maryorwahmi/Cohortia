Practice checklist
A short, ordered checklist to follow in Maya when building an IK limb.
1. Prepare joints
Confirm joint orientations and naming for the shoulder, elbow, and wrist so rotation axes behave predictably.
2. Create controls
Make a NURBS circle for the wrist control, place a pole control in front of the elbow, freeze transforms and delete history, then rename controls clearly.
3. Create IK handle & connect pole
Use Create IK Handle with Rotate Plane Solver, then connect the pole vector to lock the bend direction.
4. Parent and test
Parent the IK handle under the wrist control and verify moving the wrist moves the limb; moving the pole changes bend without shifting the end effector.
Common mistake
Not assigning a pole vector or placing it too close to the joint chain can cause the elbow or knee to flip unpredictably during animation.
Key Takeaway

A properly placed pole vector and clean naming prevent flipping and simplify animator workflows.
