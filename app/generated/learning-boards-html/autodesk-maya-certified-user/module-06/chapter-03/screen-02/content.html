Learning Objectives
Four scaffolded skills you will practice, each mapped to a verified competency milestone.
01
Differentiate FK vs IK

You will explain when to use FK and when IK by comparing a waving shoulder to a foot placement task. This matters because each method maps better to different animator goals.

VERIFIED COMPETENCY MILESTONE
02
Create and manipulate IK handles

You will place an IK handle on a shoulder-to-wrist chain and move it to see how joint rotations adapt automatically.

VERIFIED COMPETENCY MILESTONE
03
Explain IK solvers

You will describe RP and SC solvers and how a pole vector defines the bend plane for RP solvers.

VERIFIED COMPETENCY MILESTONE
04
Implement IK controls and pole vectors

You will create NURBS controls for wrist and pole vector, constrain the IK handle, and test bending to ensure stable animation controls.
