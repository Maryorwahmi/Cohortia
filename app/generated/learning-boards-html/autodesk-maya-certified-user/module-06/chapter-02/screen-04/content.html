Skinning
Attach mesh to a skeleton and assign weights so deformation looks organic during joint motion.
Key properties:
  • Weights per vertex are in the range 0 to 1 and sum to 1.
  • Multiple joints can influence a vertex for blended deformation.
  • Automatic bind gives a starting state that usually needs refinement.
Key Takeaway

Skinning is the bridge between a rig and believable mesh motion: it must be tested and refined, not assumed correct.

Vertex weight example
// conceptual per-vertex weights Vertex A: shoulder 0.6, upperArm 0.4, others 0.0 Vertex B: upperArm 0.2, elbow 0.8 Sum per vertex = 1.0
These numbers determine how much each joint moves the vertex when animated.
Concrete example
For an elbow bend, blend influence between the upper arm and forearm joints. If one joint has full influence the mesh will collapse or crease sharply; blended weights create a smooth arc.
