Hands-on Lab › Cylinder Arm Walkthrough
Steps to complete
Follow these steps in Maya and test rotation after each change.
  1. Create cylinder and set Subdivisions Height to 10–15. Freeze transforms and delete history.
  2. Create shoulder_JNT, elbow_JNT, wrist_JNT and orient joints with X along the bone.
  3. Select shoulder_JNT, Shift-select cylinder. Open Bind Skin options, use Geodesic Voxel, Max Influences = 3, then Bind Skin.
  4. Rotate joints to test. Open Paint Skin Weights Tool to correct any collapsing or pinching.
  5. Use Replace to remove wrong influence, Add to rebuild, and Smooth to blend. Re-test rotations after each pass.
Key Takeaway

Small, iterative painting steps with frequent testing produce reliable deformation faster than large, sweeping edits.

Scenario
Your elbow pinches. Select the elbow joint and use Smooth to relax the crease, then add influence around the neighboring rings to restore shape.
Save strategy
Save incremental versions: prepare-bind, paint-pass-1, paint-pass-2. This makes it easy to revert if a painting change makes other areas worse.
