Key Concepts › What to Remember
Skinning
Attach mesh to the rig and assign normalized weights so vertices deform predictably.
Bind Options
Bind Method, Max Influences and Dropoff Rate set the initial behavior and painting workload.
Paint Skin Weights
Use Replace, Add, and Smooth to correct influence; visualize with color ramp and test by rotating joints.
Takeaway
A disciplined prepare-bind-paint-test loop with thoughtful settings is the fastest path to stable, natural-looking deformations.
