Process › Paint Skin Weights Tool
Interactive painting
Select a joint then paint its influence using modes designed for precise control.
Brush modes
  • Replace: set a specific weight value; useful for removing unwanted influence.
  • Add: increase the selected joint's weight where more influence is needed.
  • Smooth: average neighbor weights to remove sharp transitions and creases.
Visualization
Enable Color Ramp to see a gradient representing 0 to 1 influence and quickly find problem vertices.
Pro tip

Work on one joint at a time: reduce wrong influence first, then build correct influence for the desired joint.

Example workflow
If the shoulder pulls the forearm, select the shoulder joint, paint Replace with zero on the forearm vertices, then select the forearm joint and Add influence where appropriate.
Color Ramp
Blue = 0 influence, red = 1 influence. Use this to guide where to paint or smooth.
