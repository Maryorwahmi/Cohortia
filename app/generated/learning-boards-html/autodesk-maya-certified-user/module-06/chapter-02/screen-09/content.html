Brush modes in practice
Match brush choice to the correction you need and test often.
Replace
Set an exact weight value to remove wrong influence quickly.
Add
Incrementally increase the selected joint's influence in small amounts.
Smooth
Average neighbors to remove creases and produce gradual transitions.
Sequence example
Replace (clear wrong influence) → Add (build correct influence) → Smooth (blend transitions). Test rotation between each step.
Common mistake

Relying only on Smooth will rarely fix a wrong influence assignment; it blends existing values rather than removing them.
