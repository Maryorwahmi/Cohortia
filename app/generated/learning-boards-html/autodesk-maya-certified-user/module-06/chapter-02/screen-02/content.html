Mnemonic & Workflow
Remember PRIM: Prepare, Rig, Initial bind, Modify weights. Use symmetry for bilateral meshes and always test by rotating joints after binding.
Practical checks
  • Freeze transforms and delete history before binding.
  • Set Max Influences to a small number like 3–4 for manageability.
  • Use Geodesic Voxel for complex meshes to improve initial weights.
