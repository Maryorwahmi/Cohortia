Forward Kinematics
Parent rotations drive children; use FK for animator control over rotation order.
Joint Orientation
Align local axes (X down the bone) to avoid skewed rotations and erratic IK behavior.
Outliner
Organize, name, and re-parent to maintain a clear transform flow and ease selection.
Final takeaway: practice the create → orient → name → test loop and use the FK/orientation/Outliner triage when debugging rotations.
