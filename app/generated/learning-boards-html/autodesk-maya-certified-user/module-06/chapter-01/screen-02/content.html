Learning Objectives

Bloom bar: Learn → Understand → Apply → Master

01
Explain the purpose of rigging
You will explain how a skeleton enables posing and how rigs drive mesh deformation. This matters because animators manipulate the rig, not the raw mesh.
Mnemonic: Puppet core
VERIFIED COMPETENCY MILESTONE
02
Create and manipulate joint chains
Use the Joint Tool to place parent and child joints and finalize chains for animation. Practice ensures precise pivot placement for natural motion.
Mnemonic: Click, Chain, Enter
VERIFIED COMPETENCY MILESTONE
03
Manage hierarchies in the Outliner
Organize joints under a root and re-parent with middle-mouse drag to keep the scene selectable and logical for animators.
Mnemonic: Root first
VERIFIED COMPETENCY MILESTONE
04
Orient joints and troubleshoot rotations
Visualize local rotation axes and use Orient Joint to align primary and secondary axes so FK behaves predictably. Diagnose skewed rotation by checking orientation consistency.
Mnemonic: Axis align
VERIFIED COMPETENCY MILESTONE
