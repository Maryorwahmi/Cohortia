Local rotation axes

Visualize axes with Display → Transform Display → Local Rotation Axes. Align primary axis down the bone for consistent rotation behavior.

Open Orient Joint options: set Primary Axis = X, Secondary Axis = Y, and choose world orientation as needed.
Test by rotating parent joints; if children rotate predictably, orientation is consistent.
Concrete check
Select a joint and enable Local Rotation Axes. Confirm X points down the bone. If not, use Orient Joint to align axes and re-test rotations.
Troubleshooting
If rotations look skewed, inspect axes rather than immediately adjusting skin weights; inconsistent axes are a common root cause.
Key Takeaway

Consistent joint orientation is essential for predictable FK and for stable IK behavior later on.
