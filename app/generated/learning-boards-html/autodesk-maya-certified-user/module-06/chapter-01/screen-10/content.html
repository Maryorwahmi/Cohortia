Definition › Display & names

Display options

Adjust Joint Size from Display → Animation. Use Drawing Overrides for Bone or Box styles to highlight specific chains.

Visual cues help differentiate controllers, deformers, and helper joints in crowded scenes.
Use larger or boxed displays for primary controls and smaller default spheres for helper joints.
Naming convention
Adopt a pattern: Side_Part_Suffix, for example L_shoulder_JNT, R_elbow_JNT. This helps other artists and scripts identify parts quickly.
Common mistake
Using generic names like joint1 or spine_a makes automations brittle and confuses teams during handoff.
Key Takeaway

Standardize display types and naming at the start to improve readability, selection, and scripting later on.
