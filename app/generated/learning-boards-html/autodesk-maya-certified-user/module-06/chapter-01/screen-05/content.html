Create a joint chain

Follow these numbered steps each time you start a skeleton to ensure consistent results.

  1. 1. Switch to Rigging workspace and select Joint Tool (Rigging → Skeleton → Joint Tool).
  2. 2. Use an orthographic view and click for root, then click children; press Enter to finish.
  3. 3. Rename joints in the Outliner using a consistent suffix like _JNT.
  4. 4. Test by rotating the root joint; children should follow.
Concrete example
In Front view, click shoulder, then elbow, then wrist. Press Enter. Rename in Outliner: shoulder_JNT, elbow_JNT, wrist_JNT. Rotate shoulder to verify FK chain.
Common mistake
Placing joints from perspective can shift depth and misalign the chain; always use orthographic views for placement accuracy.
Key Takeaway

A repeatable joint creation routine — place, finalize, rename, test — reduces placement errors and saves time when animating.
