Module 6 › Chapter 5.5 › Guided Practice
Practice Steps
  1. Create a simple three-piece arm mesh and combine into one geometry.
  2. Use Skeleton › Create Joints and place shoulder, elbow, wrist, fingertip.
  3. Select mesh then Shift-select root joint and use Skin › Bind Skin with Smooth settings.
  4. Rotate joints to test deformation and open Paint Skin Weights to refine.
Verify by rotating the elbow: the mesh should bend smoothly with blended vertex influence.
Common Quick Checks
If you see pinching or stretching, check joint placement, inspect influences with weight visualization, and use the Smooth brush to blend values. Confirm normalization so vertex influences sum to one.
Tip: rotate parent joints to ensure children follow and test extremes of motion.
Verification
A functioning arm rig that bends the elbow with no severe pinching.
