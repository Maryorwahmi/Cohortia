Tool Walkthrough › Paint Skin Weights Tool
Brush Modes
  • Add — increases joint influence where painted.
  • Replace — sets the painted area to a specific value.
  • Smooth — evens out abrupt transitions between weights.
Adjust opacity for finer control and always test by rotating joints after each pass.
Example Workflow
Select elbow joint, paint with low-opacity Add across the crease, then run Smooth to blend. Rotate the elbow and repeat until deformation is natural.
Pitfall
Painting without checking poses or using too-high opacity will create abrupt, unnatural weight jumps.
Pro Tip
Use Smooth after every Add pass to maintain normalized, gradual transitions.
Check
Are all vertices around the joint influenced by 2–4 nearby joints for organic motion?
Remember
Lower opacity strokes allow smoother iterative refinement.
