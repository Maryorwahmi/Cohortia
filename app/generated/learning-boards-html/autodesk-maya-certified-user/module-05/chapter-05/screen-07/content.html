Process Flow › Bind Mesh (Smooth Bind)
Quick Bind Steps
1. Select mesh(es)
2. Shift-select root joint
3. Skin > Bind Skin > Options
4. Set Bind To: Selected Joints
5. Set Skinning Method: Smooth
6. Click Bind Skin
After binding, rotate joints to observe deformation and prepare for weight painting as needed.
Why Smooth Bind?
Smooth Bind allows multiple joints to influence a vertex, producing organic bends where influences are blended rather than switching abruptly between bones.
Common Misconception
Believing Smooth Bind removes all painting tasks — it provides initial weights that need refinement around articulations.
Example

Bind a combined three-piece arm and rotate the elbow to see blended deformation from upper and lower arm joints.
