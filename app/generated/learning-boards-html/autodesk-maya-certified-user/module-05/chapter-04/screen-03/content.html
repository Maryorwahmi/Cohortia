01 Practice selection and parenting
  • Select child(s) first, parent last, press P to parent.
  • Shift+P to unparent and check Outliner updates.
  • Test: move parent — children should follow.

02 Pivot and constraints drills
  • Press D to edit pivot, place at joint, exit with D.
  • Use Point to match position only; Orient for rotation only.
  • Check for double transforms if both parented and constrained.
VERIFIED COMPETENCY MILESTONE
Quick checklist
Selection order, pivot alignment, constraint type, and Outliner verification. If any motion looks wrong, re-check pivot placement and whether a constraint plus parenting created double transforms.
