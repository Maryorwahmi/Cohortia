What is a double transform?
An object receives the same transform through both parenting and a constraint, causing amplified or unexpected motion.
Diagnosis steps
  1. Inspect Outliner for multiple relationships.
  2. Check constraint nodes on the object in the Channel Box.
  3. Temporarily disable constraints to isolate the source.
Fix strategies
  • Prefer constraints OR parenting for the same relationship.
  • Use Maintain Offset or weighted constraints instead of hard parenting when flexibility is needed.
  • Simplify transform paths until motion is predictable.
Pro tip

When in doubt, disable constraints one by one and test animation steps; this quickly isolates where transforms are being applied twice.
