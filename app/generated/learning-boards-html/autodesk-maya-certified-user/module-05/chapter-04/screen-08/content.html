Module 5 › Chapter 5.4 › Aim & Scale Constraints
Aim Constraint
Forces an axis to always point at a target. Use for cameras, turrets, and eye gaze. Set the aim axis and an up-vector to avoid flips.
Scale Constraint
Copies target scale so objects keep proportional size. Useful for linked mechanical parts or UI elements in a scene.
Practical checks
  • Animate the target while observing for axis flipping on Aim constraints.
  • Use an up-vector or helper to stabilize the aim direction.
  • Confirm Scale constraints are appropriate for rig logic and won't unintentionally scale children.
Key Takeaway

Use Aim for directional following and Scale for proportional matching; always test target animation to catch flipping or double transform issues.
