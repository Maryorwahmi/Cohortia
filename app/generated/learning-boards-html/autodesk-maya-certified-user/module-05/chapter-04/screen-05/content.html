Module 5 › Chapter 5.4 › Establishing Parent-Child Relationships
Step-by-step
  1. Select the child object(s) first.
  2. Select the intended parent object last.
  3. Press P to parent; press Shift+P to unparent.
  4. Open Window → Outliner to verify the tree structure.
Tip: Use clear naming before parenting so the Outliner remains readable, and test by moving the parent to confirm children follow.
Common mistake
Reversed selection order. If you parent the parent to the child by mistake, transforms will not propagate as intended and will be difficult to fix if not noticed early.
Quick verification
  • Move parent — children must follow.
  • Rotate intermediate joints — descendants follow relative to pivots.
