Module 5 › Chapter 5.4 › Crane Arm Hands-on
Step sequence
  1. Create three Polygon Cubes and rename Base, Arm1, Arm2.
  2. Position Base at origin; Arm1 above; Arm2 extended from Arm1.
  3. Edit pivots with D: Arm1 pivot at bottom, Arm2 pivot at connecting end.
  4. Parent Arm1 to Base (select Arm1 then Base, press P); parent Arm2 to Arm1.
  5. Create a Sphere, select Arm2 then Sphere, Constrain → Point (Maintain Offset on).
Terminal-style command reminder
select -r Arm1;
select -add Base;
parent;   // press P in the viewport

select -r Arm2;
select -add Arm1;
parent;

// Edit pivot
// select object, press D, move pivot, press D to exit

// Constrain payload
select -r Arm2;
select -add Sphere;
pointConstraint -mo true Arm2 Sphere;
This pseudo-command block mirrors the manual steps: selection order, parenting, pivot edit, and adding a point constraint with maintain offset.
