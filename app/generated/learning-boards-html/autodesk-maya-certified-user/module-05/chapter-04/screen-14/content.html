Module 5 › Chapter 5.4 › Quick Reference
Selection order
Child first, parent last. Press P to parent; Shift+P to unparent.
Pivot edit
Press D or Insert to move the pivot. Place it at the hinge for correct rotation.
Constraint choice
Point = position, Orient = rotation, Parent = full transform, Aim = directional pointing, Scale = proportional match.
Final thought
Before animation, verify pivots, Outliner hierarchy, and constraint setup to avoid surprises during motion tests.
