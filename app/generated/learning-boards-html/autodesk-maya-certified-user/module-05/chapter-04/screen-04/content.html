Module 5 › Chapter 5.4 › Hierarchy: Parent & Child
Definition

Parent-child means children inherit their parent's translation, rotation, and scale while keeping local transforms. It forms the backbone of rig structure.

How to parent
  • Select child object(s) first, then select the parent.
  • Press P to parent and Shift+P to unparent.
  • Verify structure in Window > Outliner.
Example
Arm chain
Torso → UpperArm → Forearm → Hand. Rotate UpperArm, Forearm follows but retains local rotation ability.

Key Takeaway

Design hierarchies deliberately; use the Outliner to confirm and avoid parenting mistakes that cause unexpected motion.
