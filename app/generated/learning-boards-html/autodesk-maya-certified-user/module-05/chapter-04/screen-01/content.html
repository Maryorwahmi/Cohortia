Hierarchies, Pivots, and Constraints
Organize motion, define articulation, and automate relationships in Maya.
Orientation

You will learn to build parent-child relationships, edit local pivot points for realistic joints, and apply Parent, Point, Orient, and Aim constraints. These tools keep rigs flexible and non-destructive.
