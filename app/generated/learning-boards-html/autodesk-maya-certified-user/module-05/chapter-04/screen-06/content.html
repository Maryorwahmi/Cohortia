What is a pivot?

The object's local origin used for rotation and scaling. It determines how the object articulates when animated.

How to edit
  • Select object, press D (or Insert) to enter pivot mode.
  • Move pivot with the Move tool, press D again to commit.
Common mistake
Forgetting to reposition pivots
Leads to rotations that look wrong because they use the geometric center instead of the joint.
Example: door hinge
A door should rotate around the hinge, not its center. Move the pivot to the hinge and the rotation becomes correct. This small change immediately improves animation believability.
Key Takeaway

Align pivots with real joints; check pivot placement after parenting and before animating.
