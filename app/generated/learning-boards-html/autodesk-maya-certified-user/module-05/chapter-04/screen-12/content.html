Module 5 › Chapter 5.4 › Applying a Point Constraint
When to use
Attach objects to follow position only, like props attached to hands where orientation should remain independent.
Steps
  1. Select the target(s) first, constrained object last.
  2. Constrain → Point; in options check Maintain Offset if you want to preserve current offset.
  3. Test by moving target and verifying position follows while rotation stays local.
Example
Attach a sphere payload to Arm2 using Point Constraint. The sphere follows Arm2's position but will not rotate with it.
Key Takeaway

Point constraints are ideal for position-only attachments; always check Maintain Offset and test animation to confirm the result.
