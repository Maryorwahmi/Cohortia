Module 5 › Chapter 5.4 › Constraints: Parent, Point, Orient
Parent Constraint
Follows translation, rotation, and scale with adjustable weights and multiple targets. Use when you need parenting-like behavior but want control and blending.
Point Constraint
Follows position only. Ideal for attaching an object to the end of an arm without copying rotation.
Orient Constraint
Follows rotation only. Useful for making one object match another's orientation while staying in place.
Example scenarios
  • Parent Constraint: switch a camera between multiple mounts with weight blending.
  • Point Constraint: attach a prop to hand position but keep its own facing.
  • Orient Constraint: make eye joints follow a target rotation without moving their positions.
Pitfall
Combining parenting and constraints on the same pair can cause double transformations. Prefer one or plan offsets carefully.
