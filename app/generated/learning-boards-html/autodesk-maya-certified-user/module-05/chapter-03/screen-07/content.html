Module 5 › Chapter 5.3 › Common mistakes & fixes
Mistakes
• Scaling a single axis only — breaks volume.
• Deformation that lingers — makes motion feel slow or rubbery.
• No neutral keys around extremes — deformation reads as an abrupt jump.
Warning

If volume feels inconsistent, the audience will perceive a change in object mass—this undermines believability.

Fixes
• Compensate other axes when scaling an axis to preserve volume.
• Insert neutral keys before and after extremes to make deformation a quick impulse.
• Use the Graph Editor: steep tangents for snap, soft tangents for smooth stretch.
Comparison exercise: duplicate your animation layer and toggle between versions with and without squash to see the difference in perceived weight.
