Module 5 › Chapter 5.3 › Squash & Stretch
Principle
Deforming an object to show compression and extension while preserving perceived volume.
• Preserve apparent volume: compensate other axes when one axis scales.
• Use squash at impact, stretch during quick motion or launch, neutral at rest.
• Amount of deformation depends on material: soft objects squash more than hard ones.
Key Takeaway

Always compensate axes to keep the object's perceived volume consistent during deformation.

Maya implementation — practical steps
Impact frame
Keyframe Scale Y to a smaller value and key Scale X/Z to larger values at impact; return to 1.0 before and after.
Launch frame
Keyframe Scale Y larger for stretch and scale X/Z smaller as the object accelerates upward.
Example values
Impact: Scale Y = 0.7, Scale X/Z = 1.2. Stretch: Scale Y = 1.2, Scale X/Z = 0.9. Neutral: all = 1.0.
Common mistake: only changing Scale Y. That breaks volume and makes the object appear to grow or shrink instead of deforming.
