Module 5 › Chapter 5.3 › Implementing Anticipation
Workflow
Block, insert prep, refine with Graph Editor and playblasts.
• Find the main action start frame.
• Add a short opposing key 1–4 frames earlier for snappy moves, or longer for dramatic timing.
• Combine slight scale compression with Translate changes to suggest stored energy.
Check

If viewers miss the cue, shorten or increase the contrast of the prep until intent is clear.

Concrete example — jump
Frame 17: Crouch low (anticipation)
  TranslateY = -0.2
  ScaleY = 0.95
  ScaleX = 1.05
Frame 20: Launch (main action)
  TranslateY = +1.5
  ScaleY = 1.1
  ScaleX = 0.95
Frame 22: Peak
  TranslateY = +2.0
  Scale = 1.0
Tweak how many frames the crouch occupies and refine tangents so the prep snaps into the launch without feeling delayed.
