Module 5 › Chapter 5.3 › Bouncing Ball Exercise
Step-by-step practice
1. Add a Polygon Sphere and block Translate Y for 48 frames with 2–3 bounces.
2. Before the first fall, add a small upward anticipation and slight stretch.
3. On each impact frame: ScaleY ≈ 0.7; ScaleX/Z ≈ 1.2; neutral keys before/after impact.
4. Add a small tag or pendulum and offset its keys to create follow-through and damping.
5. Use Graph Editor to sharpen impact tangents and smooth stretch curves; playblast often.
Quick reference
Impact values:
  ScaleY = 0.7
  ScaleX = 1.2
  ScaleZ = 1.2
Stretch values:
  ScaleY = 1.2
  ScaleX = 0.9
  ScaleZ = 0.9
Timing:
  Anticipation = 2-4 frames
  Offset secondary keys = +2 to +6 frames
Reflection prompt: How did anticipation alter the perceived force of the first bounce? Tweak and compare to see its effect.
