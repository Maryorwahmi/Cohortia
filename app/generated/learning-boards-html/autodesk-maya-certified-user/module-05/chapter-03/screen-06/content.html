Module 5 › Chapter 5.3 › Keyframing Squash & Stretch
Process
A repeatable sequence for the bouncing ball exercise.
  1. Create a Polygon Sphere and animate Translate Y for 48 frames with 2–3 bounces.
  2. Identify impact and peak frames for each bounce.
  3. At impact: key Scale Y smaller (e.g., 0.7) and Scale X/Z larger (e.g., 1.2).
  4. Before/after impact: key all scales to 1.0 to neutralize the shape.
  5. At launch: key Scale Y larger and Scale X/Z smaller to show stretch.
  6. Refine tangents in the Graph Editor and playblast to check timing.
Concrete example values
Frame 12: Impact
  ScaleY = 0.7
  ScaleX = 1.2
  ScaleZ = 1.2
Frame 14: Post-impact
  ScaleX = 1.0
  ScaleY = 1.0
  ScaleZ = 1.0
Frame 16: Launch
  ScaleY = 1.2
  ScaleX = 0.9
  ScaleZ = 0.9
Frame 20: Peak
  ScaleX = 1.0
  ScaleY = 1.0
  ScaleZ = 1.0
Use the Graph Editor to sharpen the impact tangent so the squash hits quickly, and use smooth tangents on stretches for airy motion.
Pro tip

Playblast short loops often; small timing tweaks produce large differences in perceived weight.
