Module 5 › Chapter 5.1 › Set / Edit / Delete Keys
Process Flow
Quick workflow
  1. Select object and move Current Time Indicator to the frame.
  2. Press s to key all animatable attributes.
  3. Or right-click an attribute in the Channel Box and choose Key Selected.
  4. Confirm the Channel Box field turns red and a red tick appears on the Time Slider.
Editing keys
  • Drag key ticks to move timing.
  • Select keys and Shift-drag ends to scale a selection.
  • Select a key and press Delete to remove it.
Example exercise
Key Translate X at frames 1, 24, and 48. Then select the frame 24 key and drag it left to make the movement happen earlier and appear faster. Observe Channel Box values as you scrub.
Common mistake

Forgetting to check the Channel Box after moving an object will leave you thinking a key exists when it doesn't. Always confirm the red indicators.

Key Takeaway

Precise key placement and verification prevent timing errors and accidental edits.
