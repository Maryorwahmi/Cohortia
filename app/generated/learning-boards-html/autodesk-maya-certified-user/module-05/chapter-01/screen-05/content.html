Module 5 › Chapter 5.1 › What is a Keyframe?
Concept
A keyframe records the value of an attribute at a particular frame. Interpolation creates the motion between keyed values.
Stores attribute values like Translate X, Rotate Y, or Scale Z.
Interpolation fills frames between keys to form continuous motion.
Attributes can be keyed independently to stagger timing.
Key Takeaway

Keys are snapshots; the feel of motion depends on where you place those snapshots in time.

Example
Key Translate X at frame 1 to 0 and at frame 24 to 5. Scrub the timeline and notice how the value changes smoothly due to interpolation.
Common misconception
Keys do not contain an animation curve by themselves; they are points on a curve Maya constructs. Removing keys removes the points that define motion.
Check your understanding
If you move an object at frame 10 but do not set a key, will the motion be recorded? No — without a key, Maya has no saved value at that frame and will not interpolate from that change.
