Module 5 › Chapter 5.1 › Playblast
Definition
Why Playblast
Fast, hardware-rendered preview that captures timing reliably.
Useful for reviews, sharing with teammates, and diagnosing timing differences across machines.
Workflow
  1. Open Window > Playblast > Playblast Options.
  2. Choose format, set resolution/scale, and select save location if needed.
  3. Generate the Playblast and review the resulting video for timing accuracy.
Example
Create a Playblast for a 48-frame run. Use a lower resolution for speed while reviewing motion and increase only when detail inspection is needed.
Common mistake

Relying on viewport playback alone can hide dropped frames; Playblast provides a recorded representation of timing for dependable review.

Key Takeaway

Always produce Playblasts for final timing checks and when sharing work for review.
