Module 5 › Chapter 5.1 › Practice & Review
Bloom: Apply → Master
Check 1 — Navigation
  • Move the Current Time Indicator to a given frame and type a frame number to confirm precise positioning.
  • Use Range Slider handles to limit playback to a short segment for focused review.
  • Milestone: you can jump to frame 24 and play between frames 1 and 48.
Check 2 — Keyframe Verification
  • Set a key and confirm the Channel Box field turns red and a red tick appears on the Time Slider.
  • Milestone: set keys on Translate X at frames 1, 24, and 48 and confirm visual markers.
  • Common mistake: moving geometry without setting a key leaves no recorded motion.
Check 3 — Auto Keyframe
Enable Auto Key to record changes automatically, then disable it before adjusting modeling transforms to avoid unwanted keys.
Check 4 — Playblast
Produce a Playblast to verify timing in a saved video file rather than relying solely on viewport playback.
