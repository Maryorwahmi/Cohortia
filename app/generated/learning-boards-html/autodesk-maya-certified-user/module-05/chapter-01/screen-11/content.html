Module 5 › Chapter 5.1 › Box Movement — Part 1
Timeline
Step-by-step
  1. Create > Polygon Primitives > Cube.
  2. Set Time Slider to frame 1; Key Selected for Translate X,Y,Z.
  3. Move to frame 24; reposition cube to a second pose and key Translate channels.
  4. Move to frame 48; set a third pose and key again. Scrub to review the motion.
Example values
Frame 1: Translate X=0, Y=0. Frame 24: Translate X=5, Y=2. Frame 48: Translate X=-5, Y=0. These values create a clear arc and let you observe interpolation.
Common oversight

Not checking the Channel Box after setting keys can leave you unsure whether the key was recorded. Look for red attributes and ticks.

Key Takeaway

Practicing manual keying builds muscle memory for intentional timing adjustments.
