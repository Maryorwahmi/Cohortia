Common Mistakes
Accidental Auto Key
If unexpected keys appear, disable Auto Key, remove the unwanted keys, and replay to confirm normal behavior.
Symptom
Red ticks appear after a modeling move.
Dropped frames vs real timing
Use Play every frame to evaluate every key and Playblast to produce a consistent playback file for judgment.
Unexpected interpolation
If motion eases unexpectedly, check tangent types in the Graph Editor; keys are points, tangents shape the curve between them.
Accidental deletion
Confirm selection before Delete and keep incremental saves. Restoring from an earlier save is faster than reconstructing complex timing.
