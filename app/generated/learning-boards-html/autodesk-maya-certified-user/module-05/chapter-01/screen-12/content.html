Timeline
Refine timing
  • Select and drag individual key ticks to change timing.
  • Select multiple keys and Shift-drag an end to scale the selection.
  • Observe how compression or expansion changes the perceived speed and weight.
Safety tip

Save an incremental scene or duplicate keys before large timing changes so you can revert if needed.

Create a Playblast
  1. Open Window > Playblast > Playblast Options.
  2. Choose a low resolution for speed and set a save location if needed.
  3. Generate and review the video to confirm timing across machines.
Key Takeaway

Refining timing is mostly about spacing keys; Playblast gives you a reliable playback to judge your edits.
