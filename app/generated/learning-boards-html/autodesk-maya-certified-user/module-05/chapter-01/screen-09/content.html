Module 5 › Chapter 5.1 › Playback & Frame Rate
Process
Playback modes
Real-time Attempts to play at the selected fps; may skip frames on heavy scenes.
Play every frame Evaluates every frame even if playback is slower than real-time — useful for blocking.
Example
If you target a 24 fps film shot, use Real-time for final feel. For checking curve evaluation, use Play every frame to ensure each key and expression is calculated.
How to set
  1. Open Window > Settings/Preferences > Preferences.
  2. Select Time Slider and choose the desired playback speed and fps.
  3. Test both modes to see which reveals timing issues for your scene complexity.
Key Takeaway

Playback mode affects evaluation and perception of timing; choose according to the review stage.
