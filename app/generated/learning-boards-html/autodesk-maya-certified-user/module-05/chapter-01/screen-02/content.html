Module 5 › Chapter 5.1 › Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Locate Core Interfaces
Identify Time Slider, Range Slider, and Channel Box and describe their roles in animation management.
VERIFIED COMPETENCY MILESTONE
Mnemonic: timeline band with a highlighted section shows current time and visible range.
02
Understand Keyframes
Explain how a keyframe stores an attribute value at a frame and how Maya interpolates between keys to make motion.
VERIFIED COMPETENCY MILESTONE
Mnemonic: two dots connected by a smooth curve represent keys and interpolation.
03
Set, Edit, Delete Keys
Practice 's' to set keys and Key Selected in the Channel Box, then move, scale, or remove keys on the Time Slider.
VERIFIED COMPETENCY MILESTONE
Mnemonic: a red tick on a timeline plus red attribute text in the Channel Box.
04
Use Auto Keyframe Wisely
Toggle Auto Key to speed recording, but avoid accidental keys by turning it off during modeling or layout work.
VERIFIED COMPETENCY MILESTONE
Mnemonic: small key icon with a red circle indicates Auto Key is active.
