Module 5 › Chapter 5.1 › Time & Range Slider
Eyebrow: Core Concept
Timeline controls
Use these controls to move through frames, set the current frame, and define which frames play back.
Current Time Indicator — drag or type a frame number to jump exactly to a frame.
Range Slider — set the visible window and loop a segment while refining poses.
Playback Length — set overall animation length to match your shot or loop.
Key Takeaway

Range Slider controls visibility only; keys remain at absolute frame numbers.

Practical Tip

Use Range Slider to loop short segments for faster iterations without changing shot length.

Process — Quick checklist
  1. Drag the Current Time Indicator or enter a number to jump to a frame.
  2. Adjust Range Slider handles to limit playback to a focused section.
  3. Set overall playback length to match your shot or loop count.
  4. Play the range to test timing without scanning the entire timeline.
Example scenario
Animating a 48-frame run: set scene length to 48, then narrow the Range Slider to 1–24 when polishing the first half of the cycle to loop fast and reveal timing issues.
