Module 5 › Chapter 5.1 › Channel Box Indicators
Architecture
Key visual cues
  • Channel Box attribute field turns red when keyed at the current frame.
  • Time Slider shows a red tick at frames with keys for the selected object.
  • Attributes can be keyed independently, creating staggered timing across properties.
Example

Set Translate X at frame 1 and Translate Y at frame 12. You will see red in the Channel Box only for the attributed keyed at the current frame when you scrub.

Quick checks
After moving geometry, confirm the Channel Box color and Time Slider ticks. If you find unexpected red fields, Auto Key may have created keys unintentionally.
Misconception: Red means locked — actually it means keyed for that frame.
Pro tip: Use Key Selected to avoid turning multiple attributes red when you only intend to change one.
Key Takeaway

Channel Box color and Time Slider ticks are your immediate confirmation tools for keyed attributes.
