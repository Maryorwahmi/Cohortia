Module 5 › Chapter 5.2 › Overshoot, undershoot, and clamped tangents
Why overshoot happens

Smoothing algorithms and long tangent handles can pull curves past target values to preserve curvature. This is common with Auto/Spline tangents when the curve must remain smooth.

Intentional overshoot adds energy and bounce.
Unintentional overshoot creates pops, instability, or values outside allowed ranges.
How to prevent or control
  • Apply Clamped tangents to stop overshoot while keeping smoothness where possible.
  • Shorten handles or break tangents and position them manually to control peak values.
  • If bounce is desired, plan and limit overshoot magnitude so it looks intentional.
Key Takeaway

Decide whether overshoot is intentional. If not, clamp or edit handles to keep values within expected ranges.
