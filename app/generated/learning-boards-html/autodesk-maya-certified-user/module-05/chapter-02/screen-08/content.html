Module 5 › Chapter 5.2 › Refining a bouncing ball — step-by-step
Activity steps
  1. Create or open a sphere animated with Translate Y and at least 3–4 keys.
  2. Open Graph Editor and select the Translate Y curve.
  3. At peak key: set tangent type to Flat to create a hang.
  4. At ground keys: set tangent type to Linear for sharp hits.
  5. Break tangents on a contact key and adjust incoming/outgoing handles for impact and rebound.
  6. Playblast or scrub to verify the refined timing and spacing.
Checks and tips
  • Verify the peak flattening actually slows the motion visually.
  • If rebound looks peg-legged, soften the outgoing handle slightly.
  • For looping, make sure first and last keys have identical values and tangents to avoid a pop.
Key Takeaway

The combination of Flat peaks, Linear contacts, and selective tangent breaks produces a convincing bounce with clear weight and timing.
