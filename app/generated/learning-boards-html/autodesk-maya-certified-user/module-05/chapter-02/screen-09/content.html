Module 5 › Chapter 5.2 › Common curve problems and cleaning techniques
Common issues
  • Spikes or micro-keys causing jittery motion.
  • Overshoot or undershoot beyond the target value.
  • Noisy curves from incremental edits making motion unreadable.
  • Mismatched tangents on loop endpoints causing a pop.
Fixes
Delete unintended keys, use Clamped tangents to prevent overshoot, simplify or smooth segments, and ensure loop endpoints match values and tangents.
Practical cleaning checklist
1. Isolate the channel and scrub frame-by-frame to find spikes.
2. Remove accidental micro-keys or merge keys where appropriate.
3. Apply Clamped tangents if Auto causes overshoot.
4. Verify loops by matching first and last key values and tangents.
Common mistake

Over-editing curves can introduce new noise. Prefer targeted minimal edits over many small adjustments.
