Module 5 › Chapter 5.2 › Key Concepts — Part 1
Graph Editor
An editor that displays animation curves and allows precise manipulation of motion.
Animation Curve
A visual representation where horizontal is time and vertical is attribute value.
Keyframe
A point on a curve recording an attribute’s value at a specific frame.
Takeaway
These three concepts frame every edit you make: find the curve, find the key, change the tangent.
