Module 5 › Chapter 5.2 › Break tangents and independent handle control
Step-by-step
1. Select the keyframe you want to edit.
2. Click the Break Tangents icon in the Graph Editor toolbar.
3. Use the Move tool to drag incoming and outgoing handles independently.
4. Scrub to verify the slow-in or quick-out effect.
Example
At a ground contact key, break tangents and steepen the incoming handle to emphasize approach, then shape the outgoing handle to control rebound timing.
Notes and pitfalls
  • Avoid breaking every key — use it where differing in/out behavior is required.
  • When handles are weighted, small movements can have large effects; move incrementally.
  • If curves get noisy after many breaks, consider simplifying or smoothing segments.
Key Takeaway

Use Break Tangents selectively to create asymmetric motion at a keyframe for realistic timing and spacing.
