Module 5 › Chapter 5.2 › Opening and navigating the Graph Editor
Quick steps
  1. Select your animated object in the scene.
  2. Open Window → Animation Editors → Graph Editor.
  3. Pick an attribute from the left list to show its curve.
  4. Zoom and pan to the frame range and isolate the curve for clarity.
Pro tip
Mute or hide unrelated curves to avoid visual clutter; it makes small spikes and handle positions easier to spot.
Supporting checks
  • Confirm the channel name matches the attribute you intend to edit.
  • Count keyframes in the channel to ensure you’re editing the right keys.
  • Use frame range controls to focus on a single action like a bounce or a hit.
Key Takeaway

A consistent navigation workflow prevents accidental edits and speeds up refinement.
