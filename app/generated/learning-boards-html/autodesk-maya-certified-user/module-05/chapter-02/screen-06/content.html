Module 5 › Chapter 5.2 › Tangent types and when to use them
Tangent reference
Auto
General-purpose smoothing for organic motion.
Clamped
Like Auto but prevents overshoots and undershoots.
Linear
Straight interpolation, constant speed — good for mechanical moves.
Spline
Smooth flowing curve for organic arcs.
Flat
Horizontal tangent to create a hold at the key.
Stepped
No interpolation — value jumps between keys. Useful for blocking.
Practical guidance
  • Use Linear for consistent, mechanical motion with no acceleration.
  • Use Flat at peaks to create a hang or pause in a bounce.
  • Use Clamped when Auto causes unwanted overshoot beyond target values.
  • Use Stepped when blocking to study pose-to-pose motion without interpolation.
Check

After changing tangents, scrub the timeline to verify the motion matches your intent and watch for overshoots or abrupt pops.
