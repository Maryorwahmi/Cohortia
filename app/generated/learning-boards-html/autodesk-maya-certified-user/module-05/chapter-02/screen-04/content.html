Module 5 › Chapter 5.2 › What the Graph Editor represents
Definition

The Graph Editor visualizes how numeric attribute values change over time. Reading the curve’s slope tells you about motion speed and change in velocity.

Axes
Horizontal: time in frames. Vertical: attribute value (Translate, Rotate, etc.).
Keyframes
Points on curves that record values at specific frames.
Curve shape
Steep = fast change, flat = hold, gradual slope = smooth acceleration or deceleration.
Concrete example
Bouncing ball — Translate Y
Upward motion: rising slope. Peak: curve flattens. Downward: descending slope. Impact: steep change and possible quick outgoing tangent for rebound.
Key takeaway

Read the curve as motion: you can predict how an object moves by inspecting slopes and plateaus.

Common mistake

Assuming time-only meaning — the Graph Editor also encodes how values change between keys, not just when keys occur.
