How to retime
  1. Select the keys representing the action you want to retime.
  2. Use the Graph Editor scale tool to compress or expand horizontally.
  3. Choose a pivot frame to anchor the scale, often the first or a central key.
  4. Scrub and adjust tangents if motion becomes too sharp or too slow.
Important distinctions
  • Horizontal scaling changes timing (speed), not the value magnitude.
  • Vertical scaling changes the numeric attribute values.
  • Scaling many keys can alter perceived acceleration; check and tweak tangents afterward.
Pro tip

When retiming loops, scale all loop keys equally and then verify the first and last frames match for a seamless loop.
