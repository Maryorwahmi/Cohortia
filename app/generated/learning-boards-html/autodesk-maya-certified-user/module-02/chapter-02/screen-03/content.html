Module 2 › Chapter 2.2 › Practice & Quality
Practice checklist
  • 1. Define loops with Multi-Cut before adding depth.
  • 2. Use Extrude with Offset then Thickness for recessed details.
  • 3. Bevel sharp corners with minimal segments for game assets.
  • 4. Bridge gaps and Merge vertices with a conservative threshold.
Quality checks
  • Inspect edge flow around joints and eye sockets for animation readiness.
  • Use Soft Selection instead of moving single vertices for organic shaping.
  • Delete history and Freeze transforms before exporting or rigging.
Pro tip

When merging, keep the threshold small. A large threshold can accidentally collapse nearby intended vertices and break loops.
