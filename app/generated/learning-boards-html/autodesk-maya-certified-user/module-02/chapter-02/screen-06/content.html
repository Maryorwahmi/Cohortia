Module 2 › Chapter 2.2 › Bridge, Merge & Connect
Tool roles
  • Bridge: Create faces between two open edge loops. Use Divisions to smooth the join.
  • Merge: Weld close vertices. Keep Merge Threshold small to avoid accidental merges.
  • Connect: Insert edges between components to form new loops.
Workflow example: align boundaries, Bridge the loops, then Merge any seam vertices with a careful threshold. Use Connect to add a cross-loop if you need better control over the shape.
Key Takeaway

Join intentionally: Bridge where two boundaries meet, Merge with conservative thresholds, Connect to create topology you control.

Common mistake

Using a large Merge Threshold that collapses loops and creates unwanted topology changes.
