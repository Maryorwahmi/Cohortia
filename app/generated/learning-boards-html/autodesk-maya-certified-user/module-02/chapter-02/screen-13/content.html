Module 2 › Chapter 2.2 › Assessment: Recessed Button
Assessment Task
Create a recessed square button using an efficient tool sequence and preserve clean topology.
Expected sequence
  1. Multi-Cut: add precise loops defining the button.
  2. Extrude: Offset to form the border, then Thickness negative to recess.
  3. Bevel: small Fraction, 1–2 Segments for subtle highlights.
  4. Cleanup: merge or connect any problematic verts, then delete history and freeze transforms.
Grading checklist
  • Loops define the button cleanly with quads around it.
  • Single Extrude handles offset and depth.
  • Bevel softens edges without excess segments.
  • Model cleaned with Delete History and Freeze Transforms.
Instructor note

In your submission, explain the purpose of each parameter you used and why you chose the bevel segment count you did.
