Module 2 › Chapter 2.2 › Edge Flow
What makes good edge flow
  • Loops that circle features like eyes or mechanical openings.
  • Continuous loops that avoid unnecessary poles in deformation zones.
  • Supporting loops placed near bevels or extrusions for crispness under smoothing.
If you see pinching when posing, reroute loops using Multi-Cut and Connect. Aim for quads in deformation areas and keep triangles or n-gons away from joints.
Practical check
Pose or rotate the jointed area. If the surface folds oddly, inspect and move edge loops so they run with the fold, not across it.
Key Takeaway

Edge flow is about alignment with form. Prioritize loop direction over raw polygon count.

Misconception

More loops do not automatically equal better deformation; loops must be placed purposefully.
