Sculpting a Simple Archway
Follow this sequence to create a clean archway and practice tool combinations.
Step-by-step
  1. Create a Polygon Cube and scale it to doorway size.
  2. Select the front face. Extrude with Offset to make a border, then use negative Thickness to push the opening in.
  3. Use Multi-Cut with Ctrl to add horizontal loops across the top, and vertical loops at the sides to shape the curve.
  4. Bevel inner and outer corners with a small Fraction and 1–2 Segments.
  5. Use Soft Selection (B) to lift top vertices into a smooth arch, adjusting falloff as needed.
  6. Delete history and Freeze transformations. Save as simple_archway.ma.
Example outcome
A clean arch with continuous loops around the opening, subtle beveled corners, and a smooth top curve from Soft Selection.
Reflection

Which loop placement made the biggest difference to the arch silhouette? Try removing one loop and compare.
