What Soft Selection does

Soft Selection moves nearby components with a falloff. Press B to enable, hold B and drag to change radius.

Use it to create smooth arcs or gentle bulges quickly, without adding immediate topology. If the result needs permanent control, follow up with Multi-Cut to add supporting loops.
Example
Select top arch vertices, enable Soft Selection, hold B and drag to tune radius, then move selection up to form a smooth arch curve.
Key Takeaway

Soft Selection is a fast sculpting aid; adjust radius to control the influence spread.

Mistake

Using too large a radius can unintentionally deform distant areas. Tune iteratively.
