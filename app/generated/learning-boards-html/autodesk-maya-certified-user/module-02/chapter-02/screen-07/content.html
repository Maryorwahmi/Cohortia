Module 2 › Chapter 2.2 › Multi-Cut Tool
What Multi-Cut does

Insert vertices, create custom edges, and add edge loops. Ctrl inserts full loops; Shift snaps to 50 percent for centered cuts.

Use Multi-Cut early to define where detail belongs. It reduces post-hoc topology fixes and helps maintain clean deformation loops for animation.
Example
To shape an arch, hold Ctrl and insert two horizontal loops across the top, then add two vertical loops at the sides to control the curve and preserve quads.
Practical notes
  • Plan loop placement for areas that will deform.
  • Avoid isolated triangles by pairing cuts across faces.
  • Use Shift for precise centered cuts when symmetry matters.
Key Takeaway

Multi-Cut gives precise loop control; use it before detail extrusions to preserve clean topology.

Misconception

Not every cut creates quads. Think through placement to avoid producing n-gons near deformation areas.
