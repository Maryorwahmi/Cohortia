Module 2 › Chapter 2.2 › Extrude — adding depth
Definition & parameters

Extrude pushes faces to create new geometry. Key parameters: Thickness and Offset. Thickness moves along the normal. Offset scales the face before moving.

Common mistake: performing an extrusion and forgetting to move the result, leaving overlapping faces. Also, avoid chained micro-extrudes when one controlled extrude will do.
Example — archway workflow
1. Select front face. 2. Extrude with small Offset to form a border. 3. Set negative Thickness to push the opening inward. 4. Move the extruded faces if needed to avoid overlap.
Visual: model cards showing an extrusion sequence
Left: original face. Center: Offset creates a border. Right: Thickness applied to push face inward.
Key Takeaway

Use a single controlled Extrude with Offset and Thickness to create consistent borders and depth.

Common mistake

Forgetting to move the extruded faces causes overlapping geometry and shading errors.
