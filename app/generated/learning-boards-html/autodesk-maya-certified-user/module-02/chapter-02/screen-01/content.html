Essential Polygon Editing Tools & Techniques
A practical tour of the tools you will use to sculpt detail, maintain clean topology, and prepare models for export.
Extrude
Push faces to add depth. Use Thickness and Offset for controlled insets and borders.
Bevel
Soften edges, catch highlights, and control segments for performance trade-offs.
Multi-Cut
Insert precise edge loops and custom cuts with Ctrl and Shift modifiers.
In this lesson

You will practice a hands-on archway build, compare good and bad edge flow, and learn cleanup steps that matter before exporting assets to a game engine.
