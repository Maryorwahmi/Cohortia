Module 3 › Chapter 2.3 › Export Readiness
Checklist
  • Confirm model scale matches engine units.
  • Set pivot points for correct placement and rotation.
  • Delete history and Freeze Transformations to reset channels.
  • Inspect for N-gons and fix them before export.
Example actions
For a weapon, move the pivot to the handle base using Insert, then Freeze Transformations so scale reads 1,1,1.
Delete history to remove construction nodes that cause unexpected behavior in the engine.
Key Takeaway

A clean, correctly pivoted, and frozen model imports reliably and behaves predictably in the engine.
