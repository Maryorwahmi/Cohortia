Module 3 › Chapter 2.3 › Quad Draw Workflow
Step-by-step
  1. Prepare a high-res sculpt by smoothing and shaping a polygon sphere.
  2. Select the sculpt and click the Make Selected Object Live magnet icon.
  3. Open Mesh Tools → Quad Draw and place vertices by clicking on the live surface.
  4. Hold Shift to preview and create quads between four vertices; use Ctrl to delete mistakes.
  5. Use Shift+Ctrl drag to relax vertex positions and improve flow.
  6. Exit Live mode and inspect topology for N-gons or stretched faces.
Pro tip

Focus on creating loops around deforming regions; you can reduce poly density on flat areas later.
