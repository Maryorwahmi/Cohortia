Module 3 › Chapter 2.3 › Lab Walkthrough
Starter steps
  1. Create a polygon sphere and apply Mesh → Smooth 2–3 times.
  2. Sculpt simple lumps using Soft Selection and Move.
  3. Select the sculpt and click Make Selected Object Live.
Quad Draw modifiers

Shift to create quads, Ctrl to delete, Shift+Ctrl to relax — use these interactively as you draw.

Finish and save
Exit Live mode when done, inspect for N-gons, correct problematic areas.
Delete history and Freeze Transformations so the scene is clean.
Example file

Save the scene as retopo_rock.ma for reference and future baking.
