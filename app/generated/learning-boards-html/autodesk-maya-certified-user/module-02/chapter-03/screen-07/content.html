Module 3 › Chapter 2.3 › Polygon Types
Quads

Stable for deformation, friendly to subdivision and UVs. Use where animation occurs.

Key Takeaway

Quads are the default choice for organic, deformable geometry.

Triangles

Acceptable for flat, non-deforming surfaces and when you need to reduce polygon count. Engines render triangles directly.

When to use

Tabletops, distant props, or areas that never bend.

N-gons

Allow in blocking and sculpt phases but avoid in final exports because triangulation is unpredictable and can break shading or animation.

Warning

N-gons can triangulate into awkward triangles causing visual artifacts.
