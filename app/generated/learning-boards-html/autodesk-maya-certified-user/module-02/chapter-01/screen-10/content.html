Module 2 › Chapter 2.1 › Table Project
Hands-on Activity
Build a simple table
A compact exercise that practices primitives, transforms, duplication, and freezing.
1. Create tabletop cube and set Channel Box values.
2. Create leg cube with 0.2 dimensions and move under a corner.
3. Duplicate leg with Ctrl+D three times and position remaining legs symmetrically.
4. Select all parts and Apply Modify > Freeze Transformations.
Key Takeaway

Follow measured steps and freeze transforms often. Save the scene as my_first_table.ma to preserve your work.

Concrete Inputs
Example Channel Box values for tabletop and leg
Tabletop (Cube)
Width: 4
Depth: 2.5
Height: 0.2
Subdivisions: 1

Leg (Cube)
Width: 0.2
Depth: 0.2
Height: 0.2
Subdivisions: 1
Common Mistake
Not using numeric values for placement, leading to imprecise alignment and asymmetry.
Reflection: After freezing transforms, the Scale fields should read 1,1,1 and Rotation should read 0,0,0.
