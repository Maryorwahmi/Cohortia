Learning Objectives — Part 1
Foundational knowledge and topology judgement
Bloom: Learn → Understand → Apply → Master
01
Define vertices, edges, faces
Be able to name and describe each mesh component and how they form a polygon mesh.
Mnemonic: Points → Lines → Surfaces
Verified Competency Milestone
02
Judge topology quality
Recognize quads, triangles, and n-gons and assess edge flow for deformation.
Mnemonic: Flow = deformation friendly
Verified Competency Milestone
03
Create and adjust primitives
Use Maya primitives and the Channel Box to set sizes and subdivisions for a controlled start.
Mnemonic: Start simple, add detail later
Verified Competency Milestone
04
Use transform tools precisely
Apply Move, Rotate, Scale and the Freeze Transformations habit to keep assets predictable.
Mnemonic: W E R — move rotate scale
Verified Competency Milestone
