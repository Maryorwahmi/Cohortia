Module 2 › Chapter 2.1 › Freeze Transformations
Definition
Modify > Freeze Transformations
Reset transforms numerically while keeping visual state intact.
What it does
Sets Rotate to 0,0,0 and Scale to 1,1,1 while preserving appearance.
When to use
After non-uniform scaling or before exporting to an engine or creating instances.
Common Mistake
Assuming freeze changes object position. It does not; it keeps the object visually the same.
Key Takeaway

Freeze transforms frequently to keep asset data clean for UVs, rigging, and engine import.

How to verify
Scale an object, freeze transforms, then check Channel Box reads
Before Freeze
Scale: 1.5, 2.0, 1.0
Rotate: 10, 0, 0

After Modify > Freeze Transformations
Scale: 1, 1, 1
Rotate: 0, 0, 0
