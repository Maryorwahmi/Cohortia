Module 2 › Chapter 2.1 › Transform Tools
Process
Move, Rotate, Scale with precision
Combine gizmos, snapping, and numeric input for accurate placement.
Move — W
Arrow gizmo for axis-constrained translation. Hold Ctrl to snap while dragging.
Rotate — E
Circular gizmo rotates around axes. Useful for orienting legs and props.
Scale — R
Boxes for uniform or axis scale. Freeze transforms after non-uniform edits.
Key Takeaway

Master shortcut keys and numeric channels. When in doubt, freeze transforms after scaling to keep data clean.

Scenario
Place duplicated table legs precisely using Move and Channel Box reads
Example steps: select leg, press Ctrl+D to duplicate, press W and type Translate X value in the Channel Box for exact placement, press E to give a slight rotation if needed, press R and drag center cube for uniform scale. After all legs are positioned, select all and run Modify > Freeze Transformations so every object's scale reads 1,1,1.
Common Mistake
Scaling visually then skipping freeze. This can break UVs and instancing later.
Reflective prompt: What numeric translate or rotate value would you use to ensure symmetry for a duplicated part?
