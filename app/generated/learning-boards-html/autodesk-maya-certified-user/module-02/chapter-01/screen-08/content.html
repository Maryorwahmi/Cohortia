Module 2 › Chapter 2.1 › Component Mode
Definition
Object vs Vertex vs Edge vs Face
Learn how each selection type changes the scope of edits.
Object Mode
Transforms the whole mesh as a single unit.
Vertex Mode
Edit points directly; small moves change connected faces.
Edge & Face Modes
Edge loops and face selections let you model creases, extrusions, and local changes.
Key Takeaway

Use right-click marking menu to move between modes quickly. Component edits are where form is made.

Practice Scenario
Bevel a corner and scale an edge loop
Steps: create a cube, right-click > Edge, double-click a corner edge to select the loop, apply bevel in the Modeling Toolkit or Edit Mesh menu to round the corner. Switch to Edge mode, double-click an internal edge to select the loop and scale it slightly to refine silhouette.
Common Mistake
Trying to reshape form only with object transforms. Component edits are essential for nuanced control.
Reflect: Which component selection most directly controls silhouette vs surface detail?
