Module 2 › Chapter 2.1 › Primitives & Channel Box
Process
Create primitives and set attributes
Use exact values and minimal subdivisions for a controlled starting mesh.
Where to find primitives
Polygons shelf or Create > Polygon Primitives.
Channel Box attributes
Width, Height, Depth, Subdivisions Width/Height/Depth control geometry density and size.
Practical rule
Start with subdivisions = 1. Add density only where needed.
Key Takeaway

Primitives give controlled geometry only when you set precise dimensions and avoid excess subdivisions early on.

Concrete Example
Tabletop dimensions and Channel Box snippet
Polygon Cube attributes
Width: 4
Depth: 2.5
Height: 0.2
Subdivisions Width: 1
Subdivisions Height: 1
Subdivisions Depth: 1
Step
Create cube, set values in Channel Box, then create leg cubes with 0.2 dimensions.
Common Mistake
Leaving high subdivision counts on primitives results in dense meshes that are hard to manage.
