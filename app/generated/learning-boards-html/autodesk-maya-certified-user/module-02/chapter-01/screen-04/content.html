Core Concept
Vertices, Edges, Faces
Understand how each element defines geometry and how edits propagate.
Vertex
A coordinate point. Move it to change connected faces.
Edge
Connects two vertices. Edge loops guide deformation and topology flow.
Face
Surface bounded by edges. Prefer quads and triangles for game assets.
Key Takeaway

Think in points, lines, and surfaces. Move vertices to sculpt; use edges to control loops and faces to define visible surfaces.

Interactive Example
Cube anatomy and a vertex edit
Cube example
8 vertices, 12 edges, 6 faces.
Try this: create a Polygon Cube, right-click and choose Vertex, then select a corner vertex and move it along the Y axis. Notice which faces change and how the edge lengths update. This teaches how local edits alter global form.
Common Mistake
Adding many vertices too early. It makes topology hard to manage; start with minimal points and refine.
Reflective question: Which vertex move would change silhouette most efficiently?
