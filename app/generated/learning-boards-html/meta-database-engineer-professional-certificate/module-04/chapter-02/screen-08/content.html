Module 4 › Chapter 4.2 › Junction Tables
Pattern

Create an associative entity that includes foreign keys to both sides and, when necessary, attributes about the relationship itself, such as dates or status.

Enrollment
enrollment_id (PK) or (student_id, course_id) composite PK, student_id (FK), course_id (FK), enrollment_date, grade
Decisions
  • Use composite PK when pair uniqueness is natural and stable.
  • Use surrogate PK when association can repeat or a single ID simplifies references.
  • Store association-specific attributes in the junction table, not in parent tables.
