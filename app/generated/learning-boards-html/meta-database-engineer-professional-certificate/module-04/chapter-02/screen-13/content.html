Module 4 › Chapter 4.2 › Common Mistakes
Frequent Errors
  • Not resolving M:N relationships.
  • Using mutable natural keys as PKs.
  • Putting association attributes on parent entities.
  • Mislabeling optionality and breaking inserts or queries.
Remedies
Use junction tables for M:N, prefer stable identifiers or surrogate keys, store association-specific data in associative entities, and validate rules with example transactions.
