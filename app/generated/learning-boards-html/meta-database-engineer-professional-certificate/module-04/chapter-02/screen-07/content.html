Crow's Foot Symbols
| vertical line = one
< crow's foot = many
o circle = zero (optional)
Combinations: o--< = 0..* ; |--| = 1..1 ; |--< = 1..*
Use examples to confirm rules: ask if an instance can exist without the related one and what the maximum number of matches is.
Example
User (1) —> (0..*) Post
Check
Confirm whether posts can exist without users and whether users must always have posts.
