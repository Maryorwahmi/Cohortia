Module 4 › Chapter 4.2 › Entities & Attributes
Definition

An entity is a distinct collection of objects. Attributes describe each entity instance. Primary keys uniquely identify each instance and are underlined in diagrams.

Example: Book
Book
ISBN (PK), title, author, publication_year
Common Mistake
Using mutable fields as primary keys breaks references when values change.
Practical Guidance
  • Choose keys that are stable and unique across time.
  • List attributes needed by applications and reports; exclude transient calculations.
  • Underline the primary key in sketches and include expected data types where helpful.
Key Takeaway

Model nouns as entities, attributes as their properties, and pick primary keys that remain constant.
