Module 4 › Chapter 4.2 › Social Media ERD
Entities & Attributes (sketch)
User(user_id PK, username, email, registration_date)
Post(post_id PK, user_id FK, content, timestamp)
Comment(comment_id PK, post_id FK, user_id FK, text, timestamp)
Design Decisions
  • Post.user_id is NOT NULL because a post must have an author.
  • Comment.user_id depends on whether anonymous comments are allowed.
  • Index foreign keys used frequently in joins for performance.
Key Takeaway

Model interactions as their own entities when they represent events or history you need to query and preserve.
