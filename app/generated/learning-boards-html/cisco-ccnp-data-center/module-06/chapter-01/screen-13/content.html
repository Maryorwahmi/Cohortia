Automating Operational Data Retrieval

Proactive Monitoring with Python and NX-OS API

The Data Retrieval Process

  1. 1.**Identify Data Needed:** Determine which operational data (e.g., interface status) is required.
  2. 2.**Construct GET Request:** Formulate an HTTP GET request to the relevant NX-OS API endpoint (e.g., /api/mo/sys/intf.json).
  3. 3.**Send Request:** Use Python's requests library to send the GET request.
  4. 4.**Parse JSON Response:** Extract relevant data from the switch's JSON response.
  5. 5.**Action/Store:** Use the data for monitoring, alerting, or storage.
Key Takeaway

Automated data retrieval enables proactive monitoring, faster troubleshooting, and data-driven network management.

# Python snippet to retrieve interface data
import requests
import json

NEXUS_IP = "192.168.1.10"
USERNAME = "admin"
PASSWORD = "password"
URL = f"https://{NEXUS_IP}/api/mo/sys/intf.json"

response = requests.get(
    URL,
    auth=(USERNAME, PASSWORD),
    verify=False # For lab, use True with valid certs in prod
)

response.raise_for_status() # Check for HTTP errors
interface_data = response.json()

print("Interface Data Retrieved:")
# Example: Iterate and print interface IDs and admin states
for intf_mo in interface_data["imdata"]:
    if "l1PhysIf" in intf_mo:
        attributes = intf_mo["l1PhysIf"]["attributes"]
        print(f"  Interface ID: {attributes['id']}, Admin State: {attributes['adminSt']}")
