Introducing Serverless Computing (FaaS)

Deploying functions without managing underlying servers

Core Concept

Serverless computing (Functions-as-a-Service) is a cloud execution model where the cloud provider dynamically manages the allocation and provisioning of servers, allowing developers to deploy functions without managing infrastructure.

What it is

Developers write small, single-purpose code functions. The platform automatically handles server provisioning, scaling, and management.

Key Benefit

Focus on code, faster deployment, automatic scaling, and pay-per-execution cost model, reducing operational overhead.

Key Takeaway

Serverless shifts infrastructure management to the platform, enabling developers to concentrate on application logic and accelerating innovation.

Traditional vs. Serverless
Traditional (VMs/Containers)
  • You manage servers, OS, runtime, and scaling.
  • Resources are always running, even when idle.
  • Higher operational overhead and fixed costs.
  • Full control over the environment.
Serverless (Functions-as-a-Service)
  • Platform manages servers, OS, and scaling.
  • Functions run only when triggered; no idle costs.
  • Reduced operational overhead and variable costs.
  • Less control over underlying infrastructure.
Example Scenario

Imagine an e-commerce site where a function automatically resizes product images upon upload. With serverless, this function only executes when a new image is uploaded, consuming compute resources only during that brief processing time, rather than requiring a dedicated server to be online 24/7.
