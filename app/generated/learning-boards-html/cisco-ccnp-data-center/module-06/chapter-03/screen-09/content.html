Implementing NetFlow on Cisco Nexus

Configure NetFlow on a Cisco Nexus switch to export flow records for detailed traffic analysis. This involves enabling the feature, defining an exporter, a monitor, and applying it to interfaces.

# 1. Enable NetFlow Feature
configure terminal
  feature netflow
exit

# 2. Define Flow Exporter
configure terminal
  flow exporter NetFlow_Collector
    destination 192.168.10.100
    transport udp 2055
    source Vlan1
    version 9
exit
# 3. Define Flow Monitor
configure terminal
  flow monitor My_Monitor
    record netflow ipv4 original-input
    exporter NetFlow_Collector
    cache timeout active 60
    cache timeout inactive 15
exit

# 4. Apply Flow Monitor to Interface
configure terminal
  interface Ethernet1/1
    ip flow monitor My_Monitor input
    ip flow monitor My_Monitor output
exit
Key Takeaway

Proper NetFlow configuration on Nexus switches is critical for exporting traffic data to a collector, enabling deep network analysis.
