NetFlow/IPFIX: Understanding Network Traffic

NetFlow (and its standardized version, IPFIX) offers deep insights into network traffic patterns by exporting detailed flow records from network devices.

  • •Flow Records: Contain information about each unique conversation.
  • •Key Data: Source/destination IP, ports, protocols, timestamps, byte/packet counts.
  • •Analysis: Identify top talkers, traffic spikes, unauthorized usage, security threats.
Example Scenario

NetFlow can reveal if a server, usually communicating with a database, suddenly starts connecting to an unknown external IP, signaling a potential compromise.
