Managing Security with Firepower Access Control Policies

Defining Traffic Rules in Firepower Management Center (FMC)

1. Access Control Policies (ACPs)

ACPs are sets of rules that dictate allowed/denied traffic and required security inspections (IPS, AMP) on Firepower devices.

2. Firepower Management Center (FMC)

The FMC is the centralized console for configuring, managing, and monitoring all Cisco Firepower Threat Defense (FTD) devices.

Key Takeaway

ACPs, managed via FMC, provide a structured and centralized way to enforce security policies and threat inspections across your Firepower deployments.

3. Defining Rules

  • Specify source/destination zones, networks, and ports.
  • Choose 'Allow' or 'Block' action.
  • Apply security inspections (IPS, AMP, URL filtering).

Example: Web Traffic Rule

An ACP rule allows HTTP/HTTPS from an 'Internal_Zone' to a 'DMZ_Zone' web server, applying deep packet inspection and URL filtering to detect threats.

Principle of Least Privilege

Any traffic not explicitly allowed by an ACP rule is typically blocked by a default action, minimizing the attack surface.
