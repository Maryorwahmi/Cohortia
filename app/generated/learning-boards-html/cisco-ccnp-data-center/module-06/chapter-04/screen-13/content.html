DR Networking: Layer 2 Stretch vs. Re-IP
Handling IP addresses and network configurations in a multi-site DR
Layer 2 Stretching

Extends a single Layer 2 broadcast domain across geographically separate data centers, allowing VMs to retain their IP addresses during failover.

  • Simplifies VM mobility (no re-IP).
  • Technologies: Cisco OTV, VXLAN EVPN.
  • Challenges: Larger fault domains, broadcast storms.
Re-IPing Applications

Assigns new IP addresses to VMs and applications when they are recovered at the disaster recovery site.

  • Maintains clear fault domains.
  • Simplifies network design.
  • Requires application awareness and DNS updates.
Key Takeaway

The choice between Layer 2 stretching and re-IPing depends on RTO/RPO, application needs, and operational complexity. Each has distinct advantages and challenges.
