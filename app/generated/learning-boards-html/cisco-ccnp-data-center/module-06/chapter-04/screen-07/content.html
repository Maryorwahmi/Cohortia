Data Replication: Synchronous Strategy
Achieving zero data loss for critical applications
How it Works

Data is written to both the primary and secondary storage simultaneously. The primary application write is not acknowledged until both sites confirm the write.

  • Ensures zero data loss (RPO = 0).
  • Primary application waits for remote acknowledgment.
  • Suitable for extremely critical data.
Key Characteristics
Latency Sensitive

Introduces latency to the primary application due to waiting for remote write confirmation.

Distance Limitation

Typically limited to short distances (e.g., <100km) to keep latency acceptable.

Example Technologies

Cisco MDS-based Fibre Channel replication, storage vendor synchronous replication.

Key Takeaway

Synchronous replication guarantees zero data loss (RPO=0) but requires low-latency links, making it ideal for critical applications over short distances.
