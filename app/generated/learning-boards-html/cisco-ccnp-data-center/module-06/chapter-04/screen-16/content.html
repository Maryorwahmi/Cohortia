Key Concepts
Advanced terms for DR planning and implementation
Synchronous Replication

Data written to primary and secondary storage simultaneously, ensuring zero data loss (RPO=0) but sensitive to latency.

Asynchronous Replication

Data written to primary first, then copied to secondary, allowing longer distances but with potential for data loss (RPO > 0).

Recovery Time Objective (RTO)

The maximum tolerable downtime for a system or application after a disaster.

Recovery Point Objective (RPO)

The maximum tolerable data loss for a system or application after a disaster.

VMware Site Recovery Manager (SRM)

A software solution that automates the orchestration of disaster recovery for virtual machines.

Summary Takeaway

These advanced concepts are crucial for designing, implementing, and managing effective multi-site disaster recovery solutions that meet specific business requirements.
