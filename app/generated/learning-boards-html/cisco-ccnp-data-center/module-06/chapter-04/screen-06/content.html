HA Technologies
Network Redundancy: vPC and HSRP
Achieving active-active and first-hop resilience
Virtual Port Channel (vPC)

A Cisco Nexus technology allowing two switches to act as one logical device, providing active-active Layer 2 redundancy and eliminating STP blocking.

  • Active-active uplinks for bandwidth utilization.
  • Device-level redundancy for Nexus switches.
  • Loop-free Layer 2 topology.
Hot Standby Router Protocol (HSRP)

A Cisco proprietary protocol providing first-hop router redundancy by sharing a virtual IP and MAC address between two or more routers.

  • Ensures continuous default gateway availability.
  • Automatic failover to a standby router.
  • Prevents network isolation due to router failure.
Example Scenario

An application server is connected to two Nexus switches configured with vPC. If one Nexus switch fails, the server's traffic automatically reroutes through the remaining active switch without interruption. Similarly, if the primary router in an HSRP group fails, the standby router takes over the virtual IP, ensuring clients can still reach external networks.

Key Takeaway

vPC and HSRP are critical for building highly available networks, ensuring both Layer 2 and Layer 3 redundancy within the data center.

Misconception

While vPC provides device redundancy, it doesn't protect against a complete site failure. For that, you need multi-site DR solutions, which we'll discuss later.
