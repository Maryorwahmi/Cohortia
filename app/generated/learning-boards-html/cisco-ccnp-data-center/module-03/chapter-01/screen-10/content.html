Core Protocol

iSCSI (Internet SCSI)

A protocol that enables block-level storage access over standard TCP/IP networks, leveraging existing Ethernet infrastructure.

Key Characteristics
  • Standard Ethernet: Uses existing network hardware (NICs, Ethernet switches).
  • Cost-Effective: Lower hardware costs compared to Fibre Channel.
  • Easy Integration: Seamlessly integrates into existing IP networks.
  • Network Dependent: Performance can be affected by IP network congestion.
Important Consideration

Proper network design, including segregation of storage traffic, is crucial to prevent performance degradation due to congestion.

iSCSI SAN Components
Key Takeaway

iSCSI offers a cost-effective way to implement SANs over standard Ethernet, but requires careful network design to ensure optimal performance and avoid congestion.
