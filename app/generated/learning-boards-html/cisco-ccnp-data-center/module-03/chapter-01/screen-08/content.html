Definition

Storage Area Network (SAN)

A dedicated high-speed network that provides block-level access to consolidated, shared storage devices for multiple servers.

Key Characteristics
  • Provides block-level access, not file-level.
  • Storage volumes appear as locally attached disks (LUNs).
  • Bypasses file system abstraction at the network layer.
  • Optimized for high I/O and low latency applications.
Contrast with NAS

Unlike NAS, SANs provide raw block access, allowing servers to manage their own file systems on the shared storage.

SAN Block-Level Access
Key Takeaway

SANs provide high-performance, block-level access to storage, making volumes appear as local disks to servers, ideal for demanding applications like databases and virtualization.
