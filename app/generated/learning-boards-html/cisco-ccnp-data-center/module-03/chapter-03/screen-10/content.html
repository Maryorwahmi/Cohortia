FCoE Hardware Components: CNAs and FCoE Switches

Essential Building Blocks for Convergence

Converged Network Adapter (CNA)

  • Single adapter combining Ethernet NIC and Fibre Channel HBA functionality.

  • Allows server to send both IP and FCoE traffic over one physical cable.

  • Reduces cabling, adapters, and simplifies server connectivity.

FCoE-Capable Switches (FCFs)

Specialized switches (e.g., Cisco Nexus) with hardware/software for FCoE.

  • Process FCoE frames, implement DCB, and act as Fibre Channel Forwarders (FCFs).

  • Provide Fibre Channel services over the Ethernet fabric.

    • Key Takeaway

    FCoE requires CNAs on servers to unify NIC/HBA functions and FCoE-capable switches (FCFs) to provide Fibre Channel services over the converged Ethernet network.

    Practical Benefit

    By using CNAs, you can reduce the number of physical adapters in a server from two (one NIC, one HBA) to one, freeing up PCIe slots and simplifying server provisioning and maintenance.
