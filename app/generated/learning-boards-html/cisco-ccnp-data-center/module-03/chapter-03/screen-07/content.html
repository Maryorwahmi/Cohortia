DCB Protocol

Priority Flow Control (PFC) - IEEE 802.1Qbb

Ensuring Lossless Delivery for FCoE

PFC's Core Function

  • Prevents frame loss due to congestion for specific traffic types.

  • Extends 802.1p priority tagging for granular flow control.

  • Allows a switch to pause traffic on a specific priority queue (e.g., FCoE).

How PFC Works

When a priority queue fills, the switch sends a pause frame for that priority.

Sender temporarily stops transmitting traffic for that specific priority.

Congestion clears, and a resume frame is sent, allowing traffic to flow again.

Key Takeaway

PFC (802.1Qbb) is vital for FCoE, providing granular flow control to prevent frame loss for storage traffic by selectively pausing congested priority queues.

Analogy

Think of PFC as a traffic controller at an intersection with multiple lanes. Instead of stopping all lanes when one is backed up, PFC can signal only the congested lane to pause, allowing other lanes to continue flowing smoothly.
