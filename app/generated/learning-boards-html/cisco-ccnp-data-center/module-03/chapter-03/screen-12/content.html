Configuration Guide

Basic FCoE Configuration on Cisco Nexus

Step-by-Step Setup for a Converged Port

Cisco Nexus FCoE Configuration

// Enter configuration modeNexus_Switch# configure terminal// Enable FCoE featureNexus_Switch(config)# feature fcoe// Enable FIP snoopingNexus_Switch(config)# fip snooping enable// Create dedicated VLAN for FCoE (e.g., VLAN 100)Nexus_Switch(config)# vlan 100Nexus_Switch(config-vlan)# fcoe vsan 10// Map FCoE VLAN to existing FC VSANNexus_Switch(config-vlan)# exit// Configure port for FCoE (e.g., Ethernet 1/1)Nexus_Switch(config)# interface ethernet 1/1Nexus_Switch(config-if)# switchport mode fcoeNexus_Switch(config-if)# switchport access vlan 100// Assign FCoE VLANNexus_Switch(config-if)# priority-flow-control mode auto// Enable PFCNexus_Switch(config-if)# no shutdownNexus_Switch(config-if)# exit// Verify FCoE statusNexus_Switch# show fcoeNexus_Switch# show fcoe databaseNexus_Switch# show interface ethernet 1/1 fcoe

Key Configuration Steps

  • 1.

    Enable FCoE Feature: Activate FCoE capabilities on the switch.

  • 2.

    Enable FIP Snooping: Enhance security for FCoE link establishment.

  • 3.

    Create FCoE VLAN: Isolate FCoE traffic and map to a VSAN.

  • 4.

    Configure Interface: Set mode to FCoE, assign VLAN, enable PFC.

Key Takeaway

Basic FCoE configuration on Cisco Nexus involves enabling the feature, configuring FIP snooping, creating and mapping an FCoE VLAN to a VSAN, and setting up the interface with FCoE mode and PFC.

Common Mistake

Misconfiguring Priority Flow Control (PFC) or incorrect VLAN-to-VSAN mapping are common errors that can lead to FCoE frame drops and severe performance issues. Always verify thoroughly.
