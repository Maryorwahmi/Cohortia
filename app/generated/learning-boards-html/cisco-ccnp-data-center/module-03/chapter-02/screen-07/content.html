Storage Arrays: Data Repositories

Presenting LUNs to Connected Servers

Role of Storage Arrays

  • •Repositories of data, containing controllers and disk shelves.
  • •Interface with the SAN via Fibre Channel ports.
  • •Present Logical Units (LUNs) to connected servers.
  • •LUNs are logical disk volumes seen by servers.
Key Takeaway

Storage arrays are data repositories that present logical disk volumes (LUNs) to servers via FC ports, managed by controllers.

Example: LUN Allocation

An organization has a large storage array. They can create a 1TB LUN for their production database server and a separate 500GB LUN for their development server. Each server sees its allocated LUN as a local disk, allowing for independent storage management and access.

Common Misconception: Just Disks

A storage array is more than just a box of disks. It's an intelligent system with dedicated controllers, caching, and often RAID configurations, all working together to provide high-performance, fault-tolerant storage services to the SAN.
