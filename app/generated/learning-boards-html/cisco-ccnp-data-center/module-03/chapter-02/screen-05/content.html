SAN Components

Host Bus Adapters (HBAs)

Server Interface to the FC SAN

Key Aspects of HBAs

  • •Specialized network interface card for Fibre Channel.
  • •Translates server's SCSI commands into FC frames and vice-versa.
  • •Provides the necessary interface for servers to access SAN storage.
  • •Each HBA port has a unique World Wide Name (WWN).
Key Takeaway

HBAs are specialized network cards that translate SCSI commands to FC frames, identified by a unique World Wide Name (WWN).

Example: WWN Persistence

If a server's HBA is moved from one PCI slot to another, or even to a different physical server, its World Wide Name (WWN) remains constant. This persistence is crucial for maintaining consistent zoning configurations and ensuring the server can still access its assigned storage resources without reconfiguration.

Common Misconception: HBA vs. NIC

An HBA is not a standard Ethernet Network Interface Card (NIC). While both are interface cards, HBAs are purpose-built for Fibre Channel storage communication, handling SCSI-to-FC translation, whereas NICs handle general network traffic using protocols like TCP/IP.
