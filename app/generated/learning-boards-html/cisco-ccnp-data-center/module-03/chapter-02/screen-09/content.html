Switched Fabric: The Enterprise Standard

Scalable, Redundant, and High-Performance

Key Characteristics

  • •Fibre Channel switches form an intelligent network.
  • •Dedicated bandwidth for each connection.
  • •High scalability and redundancy through multiple paths.
  • •Cisco MDS switches excel in building these fabrics.
Key Takeaway

Switched Fabric uses FC switches to create a scalable, redundant, and high-performance network with dedicated bandwidth for each connection.

Example: Dedicated Paths

In a switched fabric, Server A communicating with Storage Array X has a dedicated path, and simultaneously, Server B communicating with Storage Array Y also has its own dedicated path. This prevents performance degradation that would occur if they had to share bandwidth, as in an Arbitrated Loop.

Pro-Tip: Non-Blocking Architecture

Modern FC switches, like Cisco MDS, feature non-blocking architectures. This means that the switch can forward traffic at full line rate on all ports simultaneously without internal bottlenecks, ensuring maximum performance even when all connected devices are actively transmitting data.
