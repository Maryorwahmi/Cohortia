Key Concepts: iSCSI Fundamentals

Essential terms for block storage over IP.

iSCSI

A SAN protocol providing block-level storage access over standard TCP/IP networks.

iSCSI Initiator

Software or hardware on a server that connects to iSCSI targets.

iSCSI Target

A storage device or array that presents LUNs over an IP network.

Summary Takeaway

iSCSI enables cost-effective block storage by allowing server initiators to connect to storage targets over standard IP networks.
