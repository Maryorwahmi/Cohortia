iSCSI Components and Connectivity

Initiators, Targets, and LUNs working together.

iSCSI Initiator

Software/hardware on server that requests storage access.

iSCSI Target

Storage array that presents LUNs over the network.

Logical Unit Numbers (LUNs)

Blocks of storage presented by the target, seen as local disks by the initiator.

Key Takeaway

iSCSI initiators connect to iSCSI targets over TCP to access LUNs, enabling servers to treat network storage as local block devices.
