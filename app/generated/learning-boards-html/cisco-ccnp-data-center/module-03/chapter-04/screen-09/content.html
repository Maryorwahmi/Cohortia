iSCSI Initiator Configuration on Linux

Discovering and logging into iSCSI targets.

# Install iSCSI initiator utilities
sudo apt update
sudo apt install open-iscsi

# Discover iSCSI targets
sudo iscsiadm -m discovery -t sendtargets -p 192.168.10.100

# Log in to the discovered target
sudo iscsiadm -m node -T iqn.2004-04.com.example:storage.target01 -p 192.168.10.100 --login

# Verify logged-in sessions
sudo iscsiadm -m session

# LUNs appear as /dev/sdb, /dev/sdc, etc.
Key Steps Explained

Making Remote Storage Local

The `iscsiadm` command is central to managing iSCSI connections on Linux.

Conceptual Next Steps

After login, the LUNs appear as block devices. You would then partition, format (e.g., `mkfs.ext4`), and mount them to a directory for use by the server.

Key Takeaway

Linux servers use `iscsiadm` to discover and log into iSCSI targets, making remote LUNs available as local block devices for partitioning and mounting.
