Definition

iSCSI: Block-Level Storage Over IP

Encapsulating SCSI commands for network transmission.

Block-Level Access

iSCSI treats storage as raw data blocks, similar to a local hard drive, providing granular control.

TCP/IP Encapsulation

SCSI commands are wrapped in TCP/IP packets, allowing them to traverse standard Ethernet networks.

Cost-Effective SAN

Eliminates the need for specialized Fibre Channel hardware, reducing deployment costs and complexity.

How it works

The iSCSI Protocol Stack

SCSI commands are translated and sent over standard network layers.

Analogy

Imagine sending a traditional letter (SCSI command) inside a modern email (TCP/IP packet) to reach a distant recipient (storage array) using the internet (Ethernet network).

Key Takeaway

iSCSI provides block-level storage access by encapsulating SCSI commands within TCP/IP, enabling SAN capabilities over standard Ethernet networks.
