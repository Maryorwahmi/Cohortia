Bringing a New VDC to Life

Using NX-OS Commands to Instantiate a User-Defined VDC

N7K-1# configure terminal
N7K-1(config)# vdc CustomerA id 2
N7K-1(config)# exit
N7K-1#
Command executed from VDC 1 global config mode.

Command Breakdown

  • `vdc`: Initiates VDC creation.
  • `CustomerA`: The chosen name for the new VDC.
  • `id 2`: Assigns a unique numerical ID to the VDC.

Important Note

The new VDC is created but has no physical interfaces assigned yet. This step must be followed by interface allocation.

Key Takeaway

VDC creation is initiated from VDC 1 using the `vdc id ` command, establishing a new logical partition.
