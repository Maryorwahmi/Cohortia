Navigating and Configuring Within a VDC

Treating Each VDC as an Independent Switch

N7K-1# switchto vdc CustomerA
N7K-1(CustomerA)# configure terminal
N7K-1(CustomerA)(config)# hostname CustomerA-Switch
N7K-1(CustomerA)(config)# exit
N7K-1(CustomerA)# show hostname
CustomerA-Switch
N7K-1(CustomerA)# switchto vdc N7K-1
N7K-1#
Switching contexts and basic configuration.

`switchto vdc` Command

Changes your CLI session to the specified VDC. The prompt will update to reflect the current VDC context.

Independent Configuration

Once inside a VDC, you can configure it as a standalone switch (VLANs, routing, security) without affecting other VDCs.

Key Takeaway

The `switchto vdc` command allows you to manage VDCs independently, enabling isolated network configurations.
