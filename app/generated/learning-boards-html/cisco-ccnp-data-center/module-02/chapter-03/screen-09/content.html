Assigning Physical Interfaces to Your VDCs

Ensuring Exclusive Access to Network Ports

N7K-1# configure terminal
N7K-1(config)# allocate interface ethernet 2/1 group 1
N7K-1(config)# exit
N7K-1#
Command executed from VDC 1 global config mode.

Command Breakdown

  • `allocate interface`: Specifies interface allocation.
  • `ethernet 2/1`: The physical interface to be allocated.
  • `group 1`: The interface group (check documentation for specific line cards).

Interface Exclusivity

Once allocated, an interface becomes exclusive to the target VDC and cannot be shared or configured by other VDCs.

Key Takeaway

Interfaces are allocated from VDC 1 using `allocate interface` and become exclusive to the assigned VDC, ensuring isolation.
