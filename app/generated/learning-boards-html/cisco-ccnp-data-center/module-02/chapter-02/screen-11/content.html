Security Best Practices

Securing Access: User Accounts and AAA

Implementing Authentication, Authorization, and Accounting

Local User Accounts

  • •Configured directly on the switch.
  • •Assign specific privilege roles (e.g., network-admin).
  • •Simple for small, isolated deployments.
Example Command

username admin password <password> role network-admin

Centralized AAA

  • •Authentication, Authorization, Accounting.
  • •Uses external servers (TACACS+, RADIUS).
  • •Enhanced security, simplified management, audit trails.
Key Benefit

Centralizes credentials and provides a comprehensive audit trail for all administrative actions.
