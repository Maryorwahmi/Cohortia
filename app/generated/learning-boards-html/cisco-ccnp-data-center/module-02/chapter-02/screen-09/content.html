Interface Configuration

Connecting End Devices: Access Ports

Assigning Interfaces to a Single VLAN for Server Connectivity

Single VLAN Membership

An access port belongs to and carries traffic for only one specific VLAN.

Untagged Traffic

Untagged frames entering an access port are automatically assigned to its configured access VLAN.

End Device Connectivity

Ideal for connecting servers, workstations, and other devices that don't handle VLAN tagging.

Configuration Commands
N5K-CORE-01(config)# interface ethernet 1/1
N5K-CORE-01(config-if)# description "Connection to Server A"
N5K-CORE-01(config-if)# switchport mode access
N5K-CORE-01(config-if)# switchport access vlan 10
N5K-CORE-01(config-if)# no shutdown
N5K-CORE-01(config-if)# exit
N5K-CORE-01(config)#
Key Takeaway

Access ports provide dedicated VLAN connectivity for end devices, ensuring traffic isolation and proper network segmentation.
