Configuration Management

Persisting Changes: Running vs. Startup Config

Understanding How Nexus Switches Store Your Settings

Running Configuration

  • •Active configuration currently in RAM.
  • •Changes take effect immediately.
  • •Lost upon reboot if not saved.
Volatile Memory

Resides in RAM, meaning it's temporary.

Startup Configuration

  • •Configuration loaded at boot time.
  • •Resides in non-volatile storage (NVRAM).
  • •Persists across reboots.
Persistent Storage

Saved to NVRAM, ensuring changes survive.
