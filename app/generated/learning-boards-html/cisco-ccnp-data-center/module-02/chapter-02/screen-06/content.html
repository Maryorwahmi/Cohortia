Management Connectivity

In-Band Management with SVIs

Configuring a Logical Interface for Network Management

Logical Interface

An SVI is a virtual Layer 3 interface associated with a VLAN, not a physical port.

VLAN Dependency

An SVI requires a corresponding VLAN to be created and active on the switch.

In-Band Access

Management traffic flows through the same physical interfaces as data traffic, within the specified VLAN.

Configuration Commands
N5K-CORE-01(config)# vlan 1
N5K-CORE-01(config-vlan)# exit
N5K-CORE-01(config)# interface vlan 1
N5K-CORE-01(config-if)# ip address 10.0.0.1 255.255.255.0
N5K-CORE-01(config-if)# no shutdown
N5K-CORE-01(config-if)# exit
N5K-CORE-01(config)#
Key Takeaway

SVIs provide flexible in-band management, allowing the switch to be managed over the data network within a specific VLAN.
