Nexus 2000 Series: Fabric Extenders (FEX)

Simplifying cabling and extending the parent switch's fabric to server racks.

What is a Fabric Extender (FEX)?

  • •
    Remote Line Card: Acts as an extension of a parent Nexus switch (e.g., 5K, 7K, 9K).
  • •
    No Local Switching: All traffic is forwarded to the parent switch for processing.
  • •
    Simplified Management: Managed as part of the parent switch, reducing operational overhead.

Key Advantages

  • •
    Reduced Cabling: Consolidates server connections to fewer uplinks to the parent switch.
  • •
    Extended Fabric: Brings parent switch features directly to the server rack.
  • •
    Cost-Effective: Lower cost per port for server access layer connectivity.

FEX Deployment Example

Key Takeaway

FEX devices simplify data center cabling and management by acting as remote line cards for parent Nexus switches, centralizing control.
