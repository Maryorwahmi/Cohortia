Enabling OTV and Overlay Interface

Setting Up the Foundation for Layer 2 Extension

! Enable OTV feature feature otv ! Define the OTV overlay interface interface Overlay1 no shutdown otv join-interface Ethernet1/1 ! Interface connecting to the IP transport network

`feature otv`

Globally enables the OTV functionality on the Cisco Nexus switch, activating necessary processes.

`interface Overlay1`

Creates a logical overlay interface where OTV encapsulation and decapsulation occur, similar to a VTEP.

`otv join-interface`

Specifies the physical or logical interface that connects the OTV Edge Device to the IP underlay network.

Configuration Context

OTV Edge Device

Your Nexus switch acting as the DCI gateway.

Overlay Interface (Logical)

The virtual point where OTV magic happens.

Join Interface (Physical/Logical)

Connects to the IP underlay, carrying encapsulated OTV traffic.

Key Takeaway

The `feature otv` command and correct `join-interface` assignment are the foundational steps for any OTV deployment.
