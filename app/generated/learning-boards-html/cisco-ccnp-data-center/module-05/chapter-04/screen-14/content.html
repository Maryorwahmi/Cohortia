Key Concepts

Deepening Your Understanding

Join Interface

The physical or logical interface on the OTV Edge Device that connects to the IP underlay network.

Adjacency Server

An optional component in OTV that provides a unicast-only control plane for MAC address learning and VTEP discovery.

Site Identifier

A unique identifier configured on each OTV Edge Device to prevent loops and distinguish between different data center sites.

Summary Takeaway

The Join Interface connects to the IP underlay, the Adjacency Server facilitates control plane communication, and the Site Identifier is crucial for OTV's loop prevention mechanisms.
