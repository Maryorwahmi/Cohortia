Site Identification and Site VLAN

Ensuring Loop Prevention and Proper Operation

interface Overlay1 ... otv site-identifier 0x1 ! Unique ID for this data center site (important for loop prevention) otv site-vlan 999 ! A local VLAN used internally by OTV for loop prevention

`otv site-identifier`

A unique hexadecimal ID assigned to each data center site, crucial for OTV's loop prevention mechanisms.

`otv site-vlan`

A locally significant VLAN used internally by the OTV Edge Device for loop prevention, which must NOT be extended across the DCI.

Loop Prevention in Action

Unique Site ID

Prevents traffic from re-entering its originating site via the overlay.

Local Site VLAN

Helps differentiate local vs. remote MACs, enhancing loop prevention.

No STP Across DCI

OTV's mechanisms eliminate the need for STP over the DCI, preventing related issues.

Key Takeaway

Correct `site-identifier` and `site-vlan` configurations are paramount for OTV's robust loop prevention and overall stability.
