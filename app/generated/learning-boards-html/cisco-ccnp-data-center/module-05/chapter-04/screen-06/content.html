Adjacency Server

Edge Devices register with the Adjacency Server for MAC address learning and discovery.

Unicast Control Plane

Provides an alternative to multicast for OTV control plane traffic, ideal for underlays without multicast support.

ISIS Protocol

Uses Intermediate System to Intermediate System (ISIS) as the control plane protocol for MAC reachability exchange.

VTEP Discovery

Helps OTV Edge Devices discover each other and exchange MAC address information efficiently.

Key Takeaway

The Adjacency Server centralizes OTV control plane functions, enabling robust DCI even without multicast in the underlay.
