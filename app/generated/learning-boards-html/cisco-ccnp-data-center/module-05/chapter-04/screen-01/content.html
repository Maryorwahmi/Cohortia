Cisco Overlay Transport Virtualization (OTV)

Extending Layer 2 Networks Across Data Centers

Cisco OTV is a specialized Data Center Interconnect (DCI) technology that allows you to stretch Layer 2 segments (VLANs) between geographically separated data centers over an IP network. This capability is vital for scenarios like data center consolidation, disaster recovery, and seamless workload mobility without requiring IP address changes.

Key Takeaway

OTV provides a robust and efficient way to extend Layer 2 networks across disparate data centers, simplifying network design for critical business needs.
