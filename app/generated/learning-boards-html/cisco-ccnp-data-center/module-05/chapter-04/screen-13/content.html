Key Concepts

Essential Terms to Remember

Overlay Transport Virtualization (OTV)

A Cisco DCI technology that extends Layer 2 segments securely and efficiently over an IP transport network.

OTV Edge Device

A network device (e.g., Cisco Nexus switch) at the edge of a data center that encapsulates and decapsulates OTV traffic.

Overlay Interface

A logical interface on the OTV Edge Device where OTV encapsulation and decapsulation occurs.

Summary Takeaway

OTV provides a robust solution for Layer 2 DCI, leveraging specialized Edge Devices and logical Overlay Interfaces to extend network segments.
