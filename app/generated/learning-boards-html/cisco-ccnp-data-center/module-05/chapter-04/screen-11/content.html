Avoiding OTV Pitfalls

Key Considerations for a Stable Deployment

Incorrect Site Identifier

Each site must have a unique `site-identifier`. Duplicates break loop prevention and can cause loops.

Multicast Misconfiguration

If using multicast, `control-group` and `data-group` must be routable in the underlay; otherwise, OTV won't function.

Missing `extend-vlan`

VLANs not explicitly listed in `otv extend-vlan` will not be stretched across the DCI.

Extending Site VLAN

The `otv site-vlan` is local and must NOT be extended. Doing so can lead to loops and operational issues.

Key Takeaway

Careful attention to `site-identifier`, multicast routing, `extend-vlan` lists, and the `site-vlan`'s local scope is essential for a robust OTV deployment.
