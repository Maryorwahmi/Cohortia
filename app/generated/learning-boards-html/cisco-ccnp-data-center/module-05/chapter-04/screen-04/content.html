What is OTV?

Extending Layer 2 Networks Over IP Transport

Data Center Interconnect (DCI)

OTV's primary role is to connect multiple geographically separate data centers, allowing them to function as a single logical entity.

Layer 2 Extension

It enables VLANs to span across different data centers, facilitating seamless workload mobility and disaster recovery without IP re-addressing.

IP Encapsulation

OTV encapsulates Layer 2 Ethernet frames into IP/UDP packets for transport over the IP underlay network, similar to VXLAN but DCI-focused.

Key Takeaway

OTV is a DCI technology for stretching Layer 2 networks over IP, crucial for multi-site operations and application mobility.
