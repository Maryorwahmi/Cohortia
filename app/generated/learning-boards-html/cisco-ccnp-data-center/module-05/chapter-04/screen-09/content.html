Control and Data Plane Configuration

Defining Multicast Groups and Extended VLANs

interface Overlay1 ... otv control-group 239.1.1.1 ! Multicast group for OTV control plane (MAC address learning) otv data-group 232.1.1.0/24 ! Multicast range for OTV data plane (BUM traffic) otv extend-vlan 10,20,30 ! VLANs to extend over OTV

`otv control-group`

Specifies the IP multicast group for OTV control plane traffic, enabling MAC address learning and VTEP discovery.

`otv data-group`

Defines the IP multicast range used for forwarding Broadcast, Unknown Unicast, and Multicast (BUM) traffic across the overlay.

`otv extend-vlan`

Explicitly lists the VLANs that will be extended across the OTV overlay, ensuring only specified Layer 2 segments span the DCI.

OTV Traffic Flow

Control Plane (MAC Learning)

Uses `control-group` multicast or Adjacency Server.

Data Plane (BUM Traffic)

Uses `data-group` multicast for broadcasts, unknown unicasts, and multicasts.

Extended VLANs

Only specified VLANs (`otv extend-vlan`) traverse the DCI.

Key Takeaway

Proper configuration of multicast groups and extended VLANs is vital for OTV's control plane operations and efficient Layer 2 traffic forwarding.
