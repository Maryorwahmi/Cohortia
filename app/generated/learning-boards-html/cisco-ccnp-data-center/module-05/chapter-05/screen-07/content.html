Implementing VRF-Lite on Cisco Nexus

Step-by-step setup for creating isolated routing domains.

01

Define VRF Instance

Create the logical VRF container with a unique name.

vrf definition Tenant_A
02

Associate Interfaces

Assign physical or logical interfaces to the defined VRF.

interface Ethernet1/1
  vrf member Tenant_A
03

Configure IP Addresses

Assign IP addresses to the VRF-member interfaces within their domain.

ip address 192.168.1.1/24
04

Enable Routing Protocols (Optional)

Configure routing protocols to operate within the VRF context.

router ospf 1 vrf Tenant_A
Key Takeaway

VRF-Lite configuration involves defining the VRF, associating interfaces, configuring IP addresses, and optionally enabling routing protocols within the VRF context.

VRF-Lite Configuration Example

A practical snippet for setting up a VRF instance.

! Define the VRF
vrf definition Tenant_A
  address-family ipv4 unicast

! Assign interface to VRF and configure IP
interface Ethernet1/1
  no shutdown
  vrf member Tenant_A
  ip address 192.168.1.1/24

! Enable OSPF within VRF (optional)
router ospf 1
  vrf Tenant_A
    router-id 1.1.1.1
    network 192.168.1.0/24 area 0
Common Mistake

Forgetting to associate an interface with a VRF, or attempting to use overlapping IP addresses on interfaces not in separate VRFs.
