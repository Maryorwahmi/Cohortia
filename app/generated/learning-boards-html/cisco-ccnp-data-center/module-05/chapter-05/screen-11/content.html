Implementing vPC on Cisco Nexus

Basic steps for configuring active-active redundancy.

01

Enable vPC Feature

Activate the vPC functionality globally on both Nexus switches.

feature vpc
02

Create vPC Domain

Define a unique vPC domain ID to logically group the peer switches.

vpc domain 10
03

Configure Peer-Keepalive Link

Set up the Layer 3 link for heartbeat messages between peers.

peer-keepalive destination 10.0.0.2 source 10.0.0.1 vrf management
04

Configure vPC Peer-Link

Define the dedicated Port Channel between peers for control and data traffic.

interface Port-channel100
  switchport mode trunk
  switchport peer-link
05

Configure vPC Member Port-Channels

Assign Port Channels on access devices to the vPC domain.

interface Port-channel1
  vpc 1
Key Takeaway

vPC configuration involves enabling the feature, defining the domain, setting up peer-keepalive and peer-links, and configuring member Port Channels.

vPC Configuration Example (Nexus1)

A practical snippet for setting up a vPC domain.

! Enable vPC feature
feature vpc

! Configure vPC domain
vpc domain 10
  peer-keepalive destination 10.0.0.2 source 10.0.0.1 vrf management
  peer-link Port-channel100
  role priority 1

! Configure vPC Peer-Link
interface Port-channel100
  description vPC Peer-Link to Nexus2
  switchport mode trunk
  switchport peer-link
  no shutdown
interface Ethernet1/10
  channel-group 100 mode active

! Configure vPC Member Port-channel
interface Port-channel1
  description Server Connection
  vpc 1
  switchport mode trunk
  no shutdown
interface Ethernet1/1
  channel-group 1 mode active
Safety Note

Incorrect vPC configuration can lead to split-brain scenarios, traffic blackholing, or Layer 2 loops, severely impacting network availability.
