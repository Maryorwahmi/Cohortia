Key Concepts

Essential terms for network virtualization (Part 1)

Virtual Routing and Forwarding (VRF)

Allows a single physical device to maintain multiple independent routing and forwarding tables, creating isolated routing domains for network segmentation.

VRF-Lite

VRF implementation without the need for MPLS, typically used within a single device or across directly connected devices.

Virtual Port Channel (vPC)

A Cisco Nexus technology that allows two separate Nexus switches to act as a single logical switch for a connected device, providing active-active redundancy and increased bandwidth.

Summary Takeaway

VRF and vPC are fundamental virtualization technologies on Cisco Nexus, providing robust Layer 3 segmentation and Layer 2 active-active redundancy for modern data centers.
