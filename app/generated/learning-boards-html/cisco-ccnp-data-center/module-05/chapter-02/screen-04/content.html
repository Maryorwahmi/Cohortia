What is VXLAN?

Overcoming VLAN Limitations with Scalable Layer 2 Extension

Overlay Network Protocol

VXLAN encapsulates Layer 2 Ethernet frames within UDP packets, creating virtual networks over a physical Layer 3 infrastructure.

VLAN Scalability Issues

Traditional VLANs are limited to 4094 IDs, insufficient for large-scale multi-tenant cloud environments.

Massive Scalability

VXLAN uses a 24-bit VNI, providing up to 16 million unique Layer 2 segments for multi-tenancy.

Key Takeaway

VXLAN is a critical technology for modern data centers, enabling unprecedented Layer 2 scalability and multi-tenancy over existing Layer 3 infrastructure.

VLAN vs. VXLAN: Scalability

Traditional VLANs

12-bit ID: 4,094 segments

VXLAN (VNI)

24-bit ID: 16 Million segments

VXLAN provides a 4000x increase in logical network segments.
