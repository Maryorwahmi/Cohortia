BGP EVPN for VXLAN

The Modern and Scalable Control Plane

MP-BGP for MAC Learning

Uses Multi-Protocol BGP to distribute MAC address reachability information (MAC-IP bindings) and VTEP IP addresses.

Eliminates Flooding

Removes the need for flooding unknown unicast traffic, significantly improving scalability and efficiency compared to multicast-based methods.

Advanced Features

Supports multi-homing and active-active redundancy, enhancing network resilience and availability.

Key Takeaway

BGP EVPN is the superior control plane for VXLAN, offering unparalleled scalability, efficiency, and advanced features for modern data center networks.

BGP EVPN vs. Multicast

Multicast-based

Flooding for MAC learning, less scalable

BGP EVPN

Control plane learning, highly scalable
