VXLAN Network Identifier (VNI)

The Unique ID for Layer 2 Segments

24-bit Identifier

A VNI is a 24-bit value that uniquely identifies a Layer 2 segment within the VXLAN overlay network.

16 Million Segments

This allows for a massive 16 million unique Layer 2 segments, far exceeding VLAN's 4094 limit.

Analogy: VLAN ID

Similar to a VLAN ID, but for the VXLAN overlay, ensuring logical separation and multi-tenancy.

Key Takeaway

The VNI is the core identifier for VXLAN segments, providing the necessary scale for modern, multi-tenant data center networks.

VNI in Action

VNI 10000

Tenant A's Network Segment

VNI 10001

Tenant B's Network Segment

VNI 10002

Tenant C's Network Segment

Each VNI creates a logically isolated Layer 2 domain.
