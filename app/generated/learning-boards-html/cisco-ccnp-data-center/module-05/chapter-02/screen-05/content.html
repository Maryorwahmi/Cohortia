Underlay and Overlay Networks

The Foundation of VXLAN's Layer 2 Extension

The Underlay Network

The physical Layer 3 IP network responsible for routing packets between devices. It's the transport infrastructure.

The Overlay Network

A virtual Layer 2 network built on top of the Layer 3 underlay, extending connectivity across physical boundaries.

Encapsulation

VXLAN encapsulates Layer 2 frames into UDP packets, allowing them to traverse the Layer 3 underlay as regular IP traffic.

Key Takeaway

The underlay provides the physical IP routing, while the VXLAN overlay creates virtual Layer 2 segments, enabling flexible and scalable network designs.

VXLAN Network Layers

Overlay Network (Virtual Layer 2)

VXLAN Tunnels, VNIs, VTEPs

Underlay Network (Physical Layer 3)

IP Routing, Physical Switches/Routers

VXLAN abstracts Layer 2 services from the physical Layer 3 infrastructure.
