Common VXLAN Configuration Mistakes

Avoiding Pitfalls in Your Deployment

Incorrect Source Interface

Misconfigured or unreachable `source-interface` on the NVE can prevent tunnel establishment.

Multicast Group Mismatch

Inconsistent or unreachable `multicast-group` across VTEPs for the same VNI will break BUM traffic forwarding.

Missing Feature Enables

Forgetting `feature nve` or `feature interface-vlan` prevents VXLAN from functioning at all.

VLAN-VNI Mapping Errors

Not mapping the VLAN to the VNI (`vn-segment`) will prevent Layer 2 extension for that VLAN.

Key Takeaway

Thoroughly verify all VXLAN configuration parameters and ensure the underlying IP network supports the chosen control plane (e.g., multicast) to prevent common deployment issues.

Troubleshooting Checklist

  • Is the VTEP `source-interface` up and reachable?
  • Is IP multicast routing working in the underlay?
  • Are `feature nve` and `feature interface-vlan` enabled?
  • Is the VLAN correctly mapped to the VNI (`vn-segment`)?
  • Are VTEPs in the same VNI using the same multicast group?

A systematic approach to troubleshooting is key for VXLAN.
