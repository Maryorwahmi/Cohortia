VXLAN Packet Decapsulation

Delivering the Original Layer 2 Frame

04

Receive & Decapsulate

The destination VTEP receives the UDP/IP packet, removes the outer IP and UDP headers, revealing the VXLAN header and original Ethernet frame.

Example: VTEP 2 receives packet, strips L3/L4 headers.
05

Forward Original Frame

After decapsulation, the VTEP forwards the original Layer 2 Ethernet frame to the target host connected to it.

Example: Original frame delivered to Host B.
Seamless L2 Extension

The entire process is transparent to the end hosts, providing seamless Layer 2 connectivity across a Layer 3 network.

Benefit: Hosts communicate as if directly connected.
Key Takeaway

Decapsulation completes the VXLAN tunnel, restoring the original Layer 2 frame and delivering it to the intended recipient, enabling transparent Layer 2 communication.
