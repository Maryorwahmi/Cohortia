Key Concepts

Essential terms and ideas from this chapter

VXLAN Network Identifier (VNI)

A 24-bit identifier that uniquely identifies a Layer 2 segment (broadcast domain) within a VXLAN overlay network, allowing for up to 16 million segments.

VXLAN Tunnel Endpoint (VTEP)

A network device (e.g., a switch or router) that encapsulates and decapsulates Ethernet frames into VXLAN/UDP packets, acting as the endpoint for VXLAN tunnels.

Underlay Network

The physical IP network that provides transport for VXLAN encapsulated traffic. It's the underlying Layer 3 infrastructure.

Summary Takeaway

VXLAN leverages VNIs and VTEPs over a Layer 3 underlay to create scalable and flexible Layer 2 overlay networks.
