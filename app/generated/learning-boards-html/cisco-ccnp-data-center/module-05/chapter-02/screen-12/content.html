Basic VXLAN Setup: Features & NVE Interface

Initial Steps on Cisco Nexus Switches (Multicast-based)

Enable Features

Activate `feature nve` and `feature interface-vlan` to enable VXLAN capabilities on the switch.

Configure NVE Interface

Create `interface nve1` and ensure it's active with `no shutdown`.

Source Interface

Define the `source-interface` (e.g., loopback0) as the VTEP's IP address for underlay communication.

Key Takeaway

Properly enabling VXLAN features and configuring the NVE source interface are foundational steps for any VXLAN deployment.

! Enable VXLAN feature
feature nve
feature interface-vlan
! Configure the VTEP interface
interface nve1
  no shutdown
  source-interface loopback0
  host-reachability protocol static
These commands activate VXLAN and define the VTEP's identity and underlay IP.
