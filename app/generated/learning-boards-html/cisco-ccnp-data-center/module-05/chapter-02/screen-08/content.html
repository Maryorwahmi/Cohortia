VXLAN Packet Encapsulation

How Layer 2 Frames Traverse the Layer 3 Underlay

01

Identify VNI

The originating VTEP identifies the VXLAN Network Identifier (VNI) associated with the incoming Layer 2 frame.

Example: Frame from Host A in VNI 10000.
02

Lookup Remote VTEP

The VTEP looks up the destination MAC address to find the remote VTEP responsible for that MAC address.

Example: Destination MAC is on VTEP 2.
03

Encapsulate Frame

The original Ethernet frame is encapsulated with a VXLAN header (including VNI), a UDP header (port 4789), and an outer IP header (source: local VTEP IP, destination: remote VTEP IP).

Example: L2 frame + VXLAN + UDP + Outer IP.
Key Takeaway

Encapsulation transforms a Layer 2 frame into a Layer 3 IP packet, allowing it to be routed across the underlay network to the correct destination VTEP.
