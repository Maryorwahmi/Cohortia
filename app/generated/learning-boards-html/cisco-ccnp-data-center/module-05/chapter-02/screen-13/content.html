VNI and VLAN Mapping

Connecting Virtual Networks to Physical Segments

Configure VNI

Within `interface nve1`, define the VNI (e.g., `vni 10000`) and its associated `multicast-group` for BUM traffic.

Map VLAN to VNI

Create the desired VLAN (e.g., `vlan 10`) and use `vn-segment 10000` to map it to the configured VNI.

Assign Access Port

Configure an access port (e.g., `Ethernet1/1`) to `switchport access vlan 10` to connect end hosts to the VXLAN segment.

Key Takeaway

The VNI-VLAN mapping is crucial for extending Layer 2 segments over VXLAN, ensuring local traffic is correctly identified and encapsulated for the overlay.

! Configure VNI and Multicast Group
interface nve1
  vni 10000
    multicast-group 239.1.1.1
! Map VLAN to VNI
vlan 10
  vn-segment 10000
! Assign access port
interface Ethernet1/1
  switchport
  switchport mode access
  switchport access vlan 10
  no shutdown
These commands link your physical VLAN to the virtual VXLAN segment.
