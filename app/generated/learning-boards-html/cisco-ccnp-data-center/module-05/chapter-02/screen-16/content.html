Key Concepts

Essential terms and ideas from this chapter

Overlay Network

The virtual Layer 2 network created by VXLAN on top of the Layer 3 underlay, providing extended connectivity.

BUM Traffic

Refers to Broadcast, Unknown Unicast, and Multicast traffic within a Layer 2 segment, handled differently by VXLAN control planes.

BGP EVPN (Ethernet VPN)

A modern, scalable control plane for VXLAN that uses MP-BGP to distribute MAC address reachability information and VTEP IP addresses, reducing flooding.

Summary Takeaway

BGP EVPN is the preferred control plane for VXLAN, offering superior scalability and efficiency in handling Layer 2 traffic over the overlay network.
