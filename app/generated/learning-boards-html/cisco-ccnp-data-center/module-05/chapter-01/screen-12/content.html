Building the Underlay: OSPF Configuration Example

Establishing IP reachability between Nexus switches for future overlay tunnels.

Nexus1 Configuration

! Nexus1 Configuration
feature ospf

interface Ethernet1/1
  no switchport
  ip address 10.0.0.1/30
  no shutdown
  ip router ospf 1 area 0

interface Loopback0
  ip address 1.1.1.1/32
  no shutdown
  ip router ospf 1 area 0

router ospf 1
  router-id 1.1.1.1
  ! No network commands needed if interfaces are directly configured with 'ip router ospf'

Nexus2 Configuration

! Nexus2 Configuration
feature ospf

interface Ethernet1/1
  no switchport
  ip address 10.0.0.2/30
  no shutdown
  ip router ospf 1 area 0

interface Loopback0
  ip address 2.2.2.2/32
  no shutdown
  ip router ospf 1 area 0

router ospf 1
  router-id 2.2.2.2
Key Takeaway

A robust IP underlay, configured with efficient routing protocols like OSPF, is the essential foundation for establishing full reachability and supporting overlay network tunnels.
