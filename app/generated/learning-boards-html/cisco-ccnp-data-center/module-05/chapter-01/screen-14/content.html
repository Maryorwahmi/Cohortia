Key Concepts

Essential terms to remember from this chapter

Underlay Network

The physical network infrastructure (switches, routers, cables) that provides IP connectivity and acts as the transport for overlay traffic.

Overlay Network

A virtual network built on top of the underlay, providing logical connectivity and services independent of the physical topology.

Encapsulation

The process of wrapping an original data packet with an additional header (the underlay header) to allow it to traverse the underlay network.

Summary Takeaway

Overlay networks leverage a physical underlay and encapsulation to create flexible, virtual network services that overcome traditional network limitations.
