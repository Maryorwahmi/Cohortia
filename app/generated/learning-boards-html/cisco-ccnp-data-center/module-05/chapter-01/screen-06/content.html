Underlay and Overlay: The Two Pillars of Modern DC Networks

Differentiating the physical transport from virtual services.

Underlay Network

  • •**Physical Infrastructure:** Switches, routers, cables.
  • •**Function:** Provides IP connectivity and routing.
  • •**Protocols:** OSPF, EIGRP, BGP for efficient IP routing.
  • •**Role:** Acts as the transport mechanism for all traffic.
Core Principle

The underlay is the stable, high-performance physical foundation that ensures IP reachability.

Overlay Network

  • •**Virtual Infrastructure:** Logical connections and services.
  • •**Function:** Extends Layer 2/3 services across the underlay.
  • •**Protocols:** VXLAN, NVGRE, MPLS for virtual network creation.
  • •**Role:** Provides logical services independent of physical topology.
Core Principle

The overlay provides agile, flexible virtual networks that are decoupled from the physical infrastructure.

Key Takeaway

The underlay is the physical IP transport, while the overlay is the virtual network layer that provides services, with the underlay remaining unaware of the overlay's internal structure.
