Verifying Underlay Connectivity

Ensuring full IP reachability for a stable overlay foundation.

Essential Verification Commands

  • •`show ip interface brief`: Verify IP addresses and interface status.
  • •`show ip ospf neighbor`: Confirm OSPF adjacency (state should be FULL).
  • •`show ip route ospf`: Check for learned routes to loopback interfaces.
Purpose

These commands confirm the basic health and routing functionality of your underlay network.

Confirming End-to-End Reachability

  • •`ping 2.2.2.2 source 1.1.1.1` (from Nexus1 to Nexus2).
  • •`ping 1.1.1.1 source 2.2.2.2` (from Nexus2 to Nexus1).
  • •Successful pings confirm full IP reachability between loopback interfaces.
Critical Step

End-to-end ping verification ensures the underlay is ready to carry overlay traffic.

Key Takeaway

Thorough verification of the underlay's IP connectivity and routing protocol operation is crucial to ensure a stable and reliable foundation for any overlay network deployment.
