Encapsulation: Tunnelling Through the Underlay

How virtual network packets traverse the physical network transparently.

1. Original Overlay Packet

Data from the virtual network.

2. Encapsulation

Adding an outer underlay header.

3. Underlay Transport

Packet routed as regular IP traffic.

4. Decapsulation & Delivery

Outer header removed, original packet delivered.

Key Mechanism

Encapsulation allows overlay traffic to be treated as standard IP packets by the underlay, simplifying transport.

Analogy

Like putting a letter (overlay packet) into an envelope (underlay header) for postal delivery (underlay network).

Key Takeaway

Encapsulation is the core process that enables overlay networks to create virtual tunnels over the physical underlay, allowing for flexible and scalable service delivery.
