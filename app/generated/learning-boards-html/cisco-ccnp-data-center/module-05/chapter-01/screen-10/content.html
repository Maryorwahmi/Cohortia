Performance Advantage

Maximizing Network Utilization with Overlay Networks

Leveraging all available paths in the underlay for optimal performance.

ECMP Routing in Underlay

  • •Overlay networks operate over a Layer 3 underlay.
  • •Underlay typically uses Equal-Cost Multi-Path (ECMP) routing.
  • •Traffic is distributed across multiple active paths of equal cost.
Benefit

Ensures all available bandwidth in the physical network is actively utilized.

Contrast with Traditional L2

  • •Traditional Layer 2 (STP) blocks redundant paths.
  • •Results in underutilized bandwidth and slower convergence.
  • •Overlays enable full utilization, improving throughput and resilience.
Problem Solved

Eliminates the waste of network capacity inherent in STP-based designs.

Key Takeaway

Overlay networks significantly improve network utilization by leveraging ECMP routing in the Layer 3 underlay, allowing all physical paths to be active and maximizing bandwidth efficiency.
