Configuring BGP EVPN on Nexus Switches (Part 1)

Setting up BGP and the NVE interface for EVPN control plane.

Key Configuration Elements

  • ●

    Feature Enablement: Activate `bgp`, `nve`, and `interface-vlan` for core functionality.

  • ●

    BGP Configuration: Define AS, router-id, and activate `l2vpn evpn` address family.

  • ●

    NVE Interface: Set `source-interface` and crucial `host-reachability protocol bgp`.

Key Takeaway

The initial BGP EVPN configuration involves enabling features, setting up BGP peerings with the `l2vpn evpn` address family, and configuring the NVE interface to use BGP for host reachability.

Nexus1# configure terminal
! Enable features
feature bgp
feature nve
feature interface-vlan

! Configure BGP
router bgp 65000
  router-id 1.1.1.1
  address-family l2vpn evpn
    retain route-target all
  neighbor 2.2.2.2 remote-as 65000
    update-source loopback0
    address-family l2vpn evpn
      send-community extended

! Configure the VTEP interface
interface nve1
  no shutdown
  source-interface loopback0
  host-reachability protocol bgp

  vni 10000
    associate-vrf  ! If doing Layer 3 VXLAN, otherwise omit
    ingress-replication protocol bgp ! Use BGP for BUM traffic replication
Note: `retain route-target all` is important for Route Reflector scenarios to ensure all route targets are kept.
