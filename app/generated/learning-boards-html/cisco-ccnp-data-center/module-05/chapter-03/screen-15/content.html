Key Concepts (Continued)

More essential takeaways from this chapter

Anycast Gateway

Multiple VTEPs share the same Layer 3 gateway IP/MAC for a VNI, providing active-active redundancy and localized routing.

Ingress Replication

Method for handling BUM traffic where the ingress VTEP replicates traffic to all other interested VTEPs based on Type 3 routes.

Route Reflector

A BGP component used in large iBGP deployments to reduce the full mesh peering requirement, reflecting routes between peers.

Summary Takeaway

Anycast Gateway provides redundancy for Layer 3 gateways, Ingress Replication optimizes BUM traffic, and Route Reflectors simplify BGP topologies, all contributing to a robust EVPN-VXLAN solution.
