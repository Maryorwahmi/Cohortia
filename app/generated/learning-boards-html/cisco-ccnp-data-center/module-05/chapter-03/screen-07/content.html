EVPN Route Deep Dive

Type 2 MAC/IP Advertisement Route

Enabling efficient unicast forwarding in VXLAN.

How Type 2 Routes Work

  • ●

    Local Learning: VTEP learns host MAC/IP locally when a host connects.

  • ●

    Proactive Advertisement: VTEP immediately advertises MAC, IP, and its own VTEP IP via a Type 2 route to other VTEPs.

  • ●

    Direct Forwarding: Destination VTEP is known, allowing direct encapsulation and forwarding of unicast traffic without flooding.

Key Takeaway

Type 2 routes are crucial for efficient unicast forwarding by proactively distributing host reachability information, eliminating the need for ARP flooding.

Type 2 Route: Unicast Forwarding

Host A
VTEP 1
Host A connects to VTEP 1. VTEP 1 learns Host A's MAC/IP.
VTEP 1 advertises Host A's MAC/IP via Type 2 route.
VTEP 2
Host B
VTEP 2 learns Host A's MAC/IP from Type 2 route. Host B can now send traffic directly to Host A via VTEP 1.
