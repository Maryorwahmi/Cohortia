Core BGP EVPN Configuration Steps

A high-level overview of enabling EVPN on Cisco Nexus switches.

Essential Configuration Flow

  • ●

    1. Enable Features: Activate `feature bgp`, `feature nve`, and `feature interface-vlan`.

  • ●

    2. Configure BGP: Define BGP AS, establish iBGP peerings (with Route Reflector for scale).

  • ●

    3. Activate L2VPN EVPN: Enable the `l2vpn evpn` address family within BGP configuration.

  • ●

    4. Update NVE Interface: Configure `host-reachability protocol bgp` and `ingress-replication protocol bgp`.

Key Takeaway

Implementing BGP EVPN involves a sequence of enabling features, configuring BGP peerings, activating the EVPN address family, and updating the NVE interface for control plane learning.
