EVPN Fundamentals

Understanding EVPN Route Types

The building blocks of VXLAN overlay reachability.

Why Route Types Matter

  • ●

    Structured Information: Each type carries specific data (MAC, IP, BUM) for different forwarding needs.

  • ●

    Proactive Learning: Enables VTEPs to learn remote host information without flooding.

  • ●

    Optimized Forwarding: Allows for efficient unicast and BUM traffic handling within the VXLAN overlay.

  • ●

    Layer 3 Integration: Facilitates seamless Layer 3 routing across the EVPN domain.

Key Takeaway

EVPN Route Types are specialized BGP messages that define how MAC, IP, and BUM reachability is distributed, forming the intelligence of the VXLAN overlay.
