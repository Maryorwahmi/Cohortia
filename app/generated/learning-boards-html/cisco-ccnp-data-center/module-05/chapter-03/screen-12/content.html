Implementing IRB with Anycast Gateway (Part 2)

Configuring SVIs and Anycast Gateway for Layer 3 VXLAN routing.

Key Configuration Elements

  • ●

    VLAN-VNI Mapping: Associate a VLAN with its corresponding VNI.

  • ●

    SVI Configuration: Create `interface VlanX`, assign IP, and optionally `vrf member`.

  • ●

    Anycast Gateway: Crucial `fabric forwarding mode anycast-gateway` for redundancy.

Key Takeaway

IRB implementation involves mapping VLANs to VNIs, configuring SVIs with IP addresses, and enabling Anycast Gateway for redundant and efficient Layer 3 forwarding.

Nexus1# configure terminal
! Configure VLAN and VNI mapping
vlan 10
  vn-segment 10000

! Layer 3 VXLAN with Integrated Routing and Bridging (IRB)
! This allows routing between different VNIs or between a VNI and a traditional VLAN/routed interface.
! An SVI (Switched Virtual Interface) is created for the VNI.

vrf definition Tenant_A
  address-family ipv4 unicast

interface Vlan10
  no shutdown
  vrf member Tenant_A   ! If using VRFs for multi-tenancy
  ip address 10.0.10.1/24
  fabric forwarding mode anycast-gateway ! Essential for symmetric IRB
Note: The `anycast-gateway` command ensures that multiple VTEPs can share the same gateway IP and MAC, providing active-active redundancy.
