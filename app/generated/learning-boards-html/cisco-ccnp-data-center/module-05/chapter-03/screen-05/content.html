Introducing BGP EVPN as the Control Plane

Leveraging MP-BGP for scalable VXLAN address learning.

How EVPN Transforms VXLAN

  • ●

    Control Plane Learning: Replaces data plane flooding (ARP, unknown unicast) with proactive MAC/IP distribution via BGP.

  • ●

    Scalability: MP-BGP provides a robust and scalable mechanism for distributing reachability information across large networks.

  • ●

    Reduced Flooding: Minimizes BUM traffic, leading to more efficient network utilization and faster convergence.

  • ●

    Simplified Underlay: Removes the need for complex multicast configurations in the underlay network.

Key Takeaway

BGP EVPN shifts VXLAN from a reactive flood-and-learn model to a proactive advertise-and-forward model, significantly enhancing scalability and efficiency.
