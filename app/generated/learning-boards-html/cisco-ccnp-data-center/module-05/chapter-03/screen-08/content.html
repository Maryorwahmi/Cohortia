Type 3 & Type 5 Routes: BUM and IP Prefixes

Handling multicast, broadcast, unknown unicast, and Layer 3 routing.

Key Functions of These Routes

  • ●

    Type 3 (BUM Traffic): Advertises VTEP IP for BUM distribution, enabling ingress replication and avoiding underlay multicast.

  • ●

    Ingress Replication: Ingress VTEP replicates BUM traffic to all remote VTEPs for a VNI, based on Type 3 routes.

  • ●

    Type 5 (IP Prefixes): Carries Layer 3 routing information, essential for inter-VNI routing and external network connectivity.

Key Takeaway

Type 3 routes optimize BUM traffic handling, while Type 5 routes facilitate Layer 3 routing, making EVPN a complete solution for VXLAN.
