Integrated Routing and Bridging (IRB) for Layer 3 VXLAN

Enabling efficient inter-VNI routing within the VXLAN fabric.

IRB Key Concepts

  • ●

    Dual Function: VTEP acts as both Layer 2 bridge within a VNI and Layer 3 router between VNIs.

  • ●

    SVI as Gateway: A Switched Virtual Interface (SVI) is configured for the VNI, serving as the default gateway for hosts.

  • ●

    Anycast Gateway: Multiple VTEPs share the same gateway IP/MAC for a VNI, providing active-active redundancy and optimal routing.

Key Takeaway

IRB with Anycast Gateway is crucial for scalable Layer 3 VXLAN, allowing VTEPs to efficiently route traffic between segments with redundancy and simplified host configuration.
