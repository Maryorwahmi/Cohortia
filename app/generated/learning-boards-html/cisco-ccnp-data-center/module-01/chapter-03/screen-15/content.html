Key Concepts

Advanced terms and principles

Rack Server (UCS C-Series)

Standard rack-mountable servers that can be integrated and managed by UCS Fabric Interconnects.

Stateless Computing

A server's identity and configuration are defined by a software profile rather than its physical hardware.

Service Profile

A software construct in UCS that defines the complete identity and configuration of a server.

Virtual Interface Card (VIC)

A specialized adapter in UCS servers that allows for dynamic creation and allocation of virtual network and host bus adapters.

Summary Takeaway

UCS leverages stateless computing through Service Profiles and VICs to provide dynamic, flexible, and software-defined server management for both rack and blade servers.
