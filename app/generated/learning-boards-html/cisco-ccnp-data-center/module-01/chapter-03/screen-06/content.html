UCS Compute: Blade and Rack Servers

Flexible Compute Options for Data Centers

Blade Chassis

Modular enclosure housing multiple blade servers, sharing power, cooling, and I/O.

Blade Servers

Compact, hot-swappable servers for high-density environments, reducing cabling.

UCS Rack Servers (C-Series)

Standard rack-mountable servers integrated and managed by Fabric Interconnects.

Connectivity

Virtual Interface Cards (VICs)

Specialized adapters in UCS servers.

  • Allow dynamic allocation of network interfaces (vNICs).
  • Enable dynamic allocation of storage interfaces (vHBAs).
  • Connect both blade and rack servers to Fabric Interconnects.
  • Crucial for stateless computing and flexible resource assignment.
VICs abstract physical I/O, enabling software-defined connectivity.
Key Takeaway

UCS offers both blade and rack server options, all centrally managed via Fabric Interconnects and VICs for flexible deployment.
