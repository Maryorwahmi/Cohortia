Key Concepts

Essential terms to remember from this chapter

Cisco UCS

An integrated data center platform combining compute, networking, and storage access into a single system managed by software.

Fabric Interconnect (FI)

The central component of a UCS domain, providing unified network and storage connectivity, and running UCS Manager.

UCS Manager

The web-based management interface for configuring and monitoring all components within a UCS domain.

Blade Chassis

A modular enclosure that houses multiple blade servers, sharing power, cooling, and I/O resources.

Blade Server

A compact, modular server designed to fit into a blade chassis, sharing resources.

Summary Takeaway

Cisco UCS provides a unified, software-defined infrastructure, with Fabric Interconnects as the central management hub for blade and rack servers.
