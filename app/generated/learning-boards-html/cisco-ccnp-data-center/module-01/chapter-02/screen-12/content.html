vPC Common Mistakes and Verification

Ensuring Stable and Resilient vPC Operation

Misconfigured Peer-Link/Keepalive

Incorrect setup can lead to 'split-brain' scenarios where both switches act as primary, causing network instability.

Mismatched Configurations

Parameters like port channel mode or VLANs must be identical on both peers; discrepancies prevent vPC formation.

Verification with `show vpc brief`

Always use this command to quickly check vPC status, peer-link health, and identify any operational issues.

Key Takeaway

Careful configuration and diligent verification are crucial to prevent vPC issues like split-brain and ensure continuous network availability.
