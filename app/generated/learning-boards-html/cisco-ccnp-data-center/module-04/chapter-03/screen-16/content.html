Core Concepts Revisited

Essential terms for understanding UCS Service Profiles.

Service Profile

A logical definition of a server, containing all its identity and configuration information, decoupled from physical hardware.

Stateless Computing

The ability to move a server's identity and configuration between physical hardware without manual reconfiguration.

Policy

A reusable configuration object (e.g., Boot Policy, Firmware Policy) that defines specific attributes for a Service Profile.

Summary Takeaway

Service Profiles are the foundation of UCS's stateless computing, enabling flexible, policy-driven server management by decoupling identity from hardware.
