Key Concepts

Deepening Your UCS Vocabulary

Fabric Extenders (FEXs)

Devices extending the unified fabric from FIs to blade servers.

Cisco UCS Manager

Management software on FIs for configuring and monitoring UCS components.

Service Profile

A logical server representation containing identity and configuration information.

Stateless Computing

Decoupling server identity from physical hardware for rapid redeployment.

Unified Fabric

Convergence of Ethernet and Fibre Channel traffic over a single set of cables.

Summary Takeaway

Key concepts like FEXs, UCS Manager, Service Profiles, and Stateless Computing underpin the agility and efficiency of the Cisco UCS platform, enabled by the Unified Fabric.
