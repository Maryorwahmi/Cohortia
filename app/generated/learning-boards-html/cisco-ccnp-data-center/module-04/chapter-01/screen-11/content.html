Service Profiles

Logical Server Identity Decoupled from Hardware

Definition

What is a Service Profile?

A Service Profile is a logical representation of a server that encapsulates all its identity and configuration information, independent of the physical hardware.

Key Attributes Encapsulated
  • UUID: Unique Universal Identifier.
  • MAC Addresses: Network interface identities.
  • WWN Addresses: Storage interface identities.
  • Boot Order: Defines how the server starts up.
  • Firmware Policies: Ensures consistent firmware versions.
Hardware Abstraction

Service Profiles allow you to define a server's personality once and apply it to any compatible physical server, treating hardware as a pool of interchangeable resources.

Key Takeaway

Service Profiles are fundamental to UCS, enabling logical server definitions that are independent of physical hardware, driving agility.

Example Scenario

A service profile for a web server can be applied to any available blade, ensuring it always has the correct network, storage, and boot configuration.
