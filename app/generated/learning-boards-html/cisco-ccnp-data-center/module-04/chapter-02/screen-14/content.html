Key Concepts
Essential Terms to Remember
UCS Manager GUI

The web-based graphical interface for configuring, monitoring, and managing a Cisco UCS domain.

Cluster IP

A single virtual IP address used to manage a redundant pair of Fabric Interconnects as one logical entity.

Management IP

The individual IP address assigned to each Fabric Interconnect for direct management access.

Summary Takeaway

UCS Manager GUI is the central interface, accessed via a highly available Cluster IP, while individual Management IPs provide direct access to each Fabric Interconnect.
