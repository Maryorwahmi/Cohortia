Key Concepts
Critical Services and System Resilience
Initial Setup Wizard

A guided process for configuring basic parameters of a new UCS domain upon first access to UCS Manager.

Essential Network Services (NTP & DNS)

NTP synchronizes time for logging/security; DNS resolves hostnames for external services.

High Availability (HA) Cluster

Two Fabric Interconnects working in an active/standby configuration to ensure continuous operation.

Summary Takeaway

The Initial Setup Wizard, critical network services like NTP and DNS, and the High Availability Cluster are fundamental for a stable, synchronized, and resilient UCS domain.
