CLI Configuration
Setting Up Fabric Interconnect A
Essential Commands for Initial Domain Setup
  • •Configure Ethernet uplink ports for external network connectivity.
  • •Initiate the cluster creation process.
  • •Define the Cluster IP, subnet mask, and default gateway.
  • •Ensure changes are committed to save the configuration.
Pro-Tip

Always plan your IP addresses and network parameters before starting CLI configuration to avoid errors.

FI-A# scope eth-uplink # Enter Ethernet uplink configuration modeFI-A /eth-uplink # create fc-uplink-port 1/1 # Configure FCoE uplink on port 1/1FI-A /eth-uplink # commit-buffer # Save changes to the uplink configurationFI-A /eth-uplink # scope system # Enter system configuration modeFI-A /system # create cluster # Begin creating the UCS clusterFI-A /system/cluster # set cluster-ip 10.10.10.100 # Assign the virtual Cluster IPFI-A /system/cluster # set cluster-mask 255.255.255.0 # Set the subnet mask for the Cluster IPFI-A /system/cluster # set cluster-gateway 10.10.10.1 # Define the default gateway for the cluster
Key Takeaway

The initial CLI configuration for FI-A establishes essential network connectivity and defines the core cluster IP parameters, which are foundational for the UCS domain.
