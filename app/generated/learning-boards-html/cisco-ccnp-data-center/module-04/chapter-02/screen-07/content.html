Key Distinction
Cluster IP for High Availability
Managing Redundant Fabric Interconnects
Cluster IP
  • •A single virtual IP for the entire FI pair.
  • •Provides a highly available management endpoint.
  • •Used for ongoing UCS Manager GUI access.
  • •Floats between active and standby FIs in case of failure.
Example

10.10.10.100 - The primary address for all UCS management.

Management IP (Individual)
  • •Physical IP assigned to each Fabric Interconnect (FI-A, FI-B).
  • •Used for initial console access or direct troubleshooting.
  • •Not typically used for day-to-day GUI management after clustering.
  • •Essential for cluster communication and synchronization.
Example

FI-A: 10.10.10.101, FI-B: 10.10.10.102 - For direct access to each FI.

Key Takeaway

Always use the Cluster IP for managing your UCS domain to leverage high availability, reserving individual Management IPs for initial setup and direct troubleshooting.
