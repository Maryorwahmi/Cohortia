CLI Configuration
Completing FI-A Network Settings
Defining Management IPs, DNS, and NTP
  • •Set individual management IP for FI-A and its peer FI-B.
  • •Configure primary DNS server for hostname resolution.
  • •Specify NTP server for time synchronization across the domain.
  • •Commit all changes to ensure they are saved and applied.
Common Mistake

Forgetting to configure DNS or NTP can lead to obscure errors later, impacting logging and authentication.

FI-A /system/cluster # set mgmt-ip 10.10.10.101 # Assign FI-A's individual management IPFI-A /system/cluster # set mgmt-mask 255.255.255.0 # Set subnet mask for FI-A's management IPFI-A /system/cluster # set mgmt-gateway 10.10.10.1 # Define default gateway for FI-A's managementFI-A /system/cluster # set peer-mgmt-ip 10.10.10.102 # Specify FI-B's expected management IPFI-A /system/cluster # set dns-primary 8.8.8.8 # Configure primary DNS serverFI-A /system/cluster # set ntp-server 192.168.1.254 # Configure NTP server for time synchronizationFI-A /system/cluster # commit-buffer # Save all pending configurations
Key Takeaway

Properly configuring individual management IPs, DNS, and NTP via CLI on FI-A is crucial for cluster communication, external service resolution, and time synchronization.
