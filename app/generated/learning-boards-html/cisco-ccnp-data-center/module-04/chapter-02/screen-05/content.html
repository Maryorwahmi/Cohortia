Initial Access
Connecting to Your Fabric Interconnects
Establishing Management Plane Connectivity
1
Connect Workstation

Physically connect a management workstation to the management port on FI-A.

2
Configure Temporary IP

Assign a temporary IP address to your workstation in the same subnet as the FI's default setup IP (e.g., 192.168.1.x).

3
Access Web Interface

Open a web browser and navigate to the Fabric Interconnect's default IP address to launch the setup wizard.

Key Takeaway

Initial access requires a direct connection to the FI management port and a temporary IP configuration on your workstation to launch the setup wizard.
