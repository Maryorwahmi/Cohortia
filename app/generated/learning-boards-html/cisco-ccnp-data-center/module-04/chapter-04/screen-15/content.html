UCS Manager: Deploying Your Service Profile

Learn how to instantiate a Service Profile from your template and associate it with a physical server, bringing your automated configuration to life.

1

Instantiate from Template

Right-click your template (e.g., VMware-Host-Template), select Create Service Profiles from Template, specify count (1), and a Naming Prefix (e.g., ESXi-Host-).

2

Associate Service Profile

Navigate to the newly created Service Profile (e.g., ESXi-Host-1), right-click, select Change Server Association, and choose an available physical server.

3

Monitor FSM & Outcome

Observe the FSM (Finite State Machine) tab for the Service Profile. The server will reboot and adopt the new configuration, eventually becoming 'Associated' and 'Operable'.

4

Expected Outcome

The selected blade server will reboot and adopt the identity and configuration defined in the Service Profile, ready for its intended role.

Key Takeaway

Instantiating and associating a Service Profile with a physical server automates the entire configuration process, transforming generic hardware into a role-specific, ready-to-use compute resource.
