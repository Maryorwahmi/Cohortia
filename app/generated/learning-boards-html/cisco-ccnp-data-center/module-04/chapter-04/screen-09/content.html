Initial Templates: Baseline Configuration

Initial Templates create Service Profiles that become independent, meaning changes to the template do not propagate to instantiated profiles.

How it Works

  • 1
    Create from Template: A Service Profile is created using the Initial Template as a blueprint.
  • 2
    Independent Configuration: Once created, the Service Profile's configuration is independent of the template.
  • 3
    No Propagation: Future changes to the Initial Template will NOT affect existing Service Profiles.

Use Case: Baseline with Flexibility

Ideal for deploying servers that need a consistent starting point but are expected to have unique, ad-hoc configurations or tuning over their lifecycle. For example, specific application servers.

Key Takeaway

Initial Templates are best for scenarios requiring a baseline configuration where individual server settings are expected to diverge and be managed independently after initial deployment.
