UCS Manager: Step-by-Step Template Creation

Follow these conceptual steps to create a basic Updating Service Profile Template in Cisco UCS Manager, configuring essential network and boot settings.

1

Log in & Navigate

Access UCS Manager via web browser. Navigate to Servers > Service Profiles > Service Profile Templates and right-click to create a new template.

2

Configure Template Basics

Provide a Name (e.g., VMware-Host-Template), select Updating Template type, and choose a UUID Suffix Pool.

3

Configure Networking (vNIC)

Add a vNIC (e.g., vNIC-A), select an Adapter Policy, assign a MAC Address Pool, and choose a relevant VLAN.

4

Configure Boot Policy

Create a Boot Policy (e.g., Local-Disk-Boot) and add Local Disk as the primary boot device. Select this policy for the template.

Key Takeaway

The template creation process defines the core identity, network, and boot policies, acting as a reusable blueprint for consistent server deployments.
