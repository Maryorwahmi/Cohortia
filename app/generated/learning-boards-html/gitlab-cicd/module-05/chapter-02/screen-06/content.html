Basic Environment Configuration: Name and URL

Define environment names and link directly to deployed applications.

Key Parameters
  • • name: A unique identifier for your deployment environment (e.g., staging, production).
  • • url: The direct URL to the deployed application in this environment. GitLab displays a 'View app' button.
Key Takeaway

Properly configuring name and url provides clear identification and direct access to your deployed applications, enhancing team collaboration and review processes.

.gitlab-ci.yml Example
deploy_staging:
  stage: deploy
  script:
    - echo "Deploying to staging..."
  environment:
    name: staging
    url: https://staging.example.com # Direct link to app

Why the URL matters

The url parameter creates a clickable 'View app' button in GitLab's UI, offering immediate access for testers and stakeholders to review deployed changes without manual navigation.
