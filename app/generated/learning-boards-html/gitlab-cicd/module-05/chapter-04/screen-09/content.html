.gitlab-ci.yml: `stop_review_app` job
stop_review_app:
  stage: cleanup
  script:
    - echo "Stopping review app for branch $CI_COMMIT_REF_SLUG..."
    - # Commands to de-provision resources (e.g., delete cloud instances)
    - echo "Review app for $CI_COMMIT_REF_SLUG stopped and resources cleaned up."
  environment:
    name: review/$CI_COMMIT_REF_SLUG
    action: stop # Explicitly marks this job for stopping an environment
  when: manual # Allows GitLab to offer a stop button on MR closure
  only:
    - branches
  except:
    - main
Resource Management

Cleaning Up Review App Resources

Preventing Resource Leaks with `on_stop`

Purpose of `stop_review_app`

De-provisions cloud resources associated with a Review App, preventing cost overruns.

`environment: action: stop`

Informs GitLab that this job is intended to stop a specific environment.

Key Takeaway

Properly configured `on_stop` and `stop_review_app` jobs are essential for managing cloud costs and ensuring efficient resource utilization.

Safety Note

Always test your cleanup scripts thoroughly to ensure they reliably de-provision all resources and prevent unexpected costs.
