Key Concepts: Workflow & Cleanup

Integrating and Managing Review Apps

Merge Request Widget

A section within a GitLab merge request that displays pipeline status, test results, and a 'View app' button for Review Apps.

Resource De-provisioning

The process of cleaning up and releasing cloud resources (servers, databases, storage) that were allocated for a dynamic environment.

CI/CD Variables

Predefined variables like `$CI_COMMIT_REF_SLUG` are essential for creating dynamic environment names and URLs, ensuring unique deployments.

Chapter Summary

The Merge Request Widget provides a central point for accessing Review Apps, while robust Resource De-provisioning, often automated via `on_stop` jobs, is crucial for cost management and efficient cloud resource utilization.
