Configuring Review Apps with CI/CD Variables

Leveraging Dynamic Names and URLs

The `environment` Keyword

Defines deployment environments, crucial for managing dynamic Review Apps.

`$CI_COMMIT_REF_SLUG` Variable

Provides a URL-friendly version of the branch name (e.g., `feature/new-ui` becomes `feature-new-ui`).

Key Takeaway

Using `$CI_COMMIT_REF_SLUG` with the `environment` keyword is fundamental for creating unique, isolated Review App deployments.

Example: Dynamic Environment Configuration
deploy_review_app:
  stage: deploy
  script:
    - echo "Deploying review app..."
  environment:
    name: review/$CI_COMMIT_REF_SLUG # Dynamic name
    url: https://$CI_COMMIT_REF_SLUG.review.example.com # Dynamic URL
    on_stop: stop_review_app
  only:
    - branches
  except:
    - main
Variable in Action

Branch: feature/new-dashboard

$CI_COMMIT_REF_SLUG: feature-new-dashboard

Resulting URL: https://feature-new-dashboard.review.example.com
