Common Mistakes to Avoid

Be aware of these common misconfigurations that can weaken your deployment security, even with protection features enabled.

Misconfigured Permissions

Users unable to trigger manual jobs due to insufficient permissions for a protected environment.

Relying Only on `when: manual`

Without environment protection, any user with commit access could potentially trigger a manual job.

Key Takeaway

Always verify permissions and combine when: manual with environment protection to create a truly secure and robust deployment workflow.

The Importance of Layered Security

Single Point of Failure

Relying on one security mechanism can leave vulnerabilities.

Comprehensive Control

Multiple layers of protection ensure robust security for critical operations.

Regular Review

Periodically check and update your protection settings and user permissions.
