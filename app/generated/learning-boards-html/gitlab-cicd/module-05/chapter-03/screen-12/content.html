Controlling Deployment Access

When an environment is protected, deployment access is strictly controlled based on user roles and explicit permissions.

Default: Maintainer Role

By default, only users with the 'Maintainer' role (or higher) can deploy to a protected environment.

Explicit User/Group Access

You can explicitly grant deployment permissions to specific users or groups, overriding default roles.

Key Takeaway

Granular permissions for protected environments ensure only authorized individuals can initiate deployments, preventing unintended changes to live systems.
