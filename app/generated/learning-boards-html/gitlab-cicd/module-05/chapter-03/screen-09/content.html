The `only: schedules` Keyword

The only: schedules keyword restricts a job's execution to pipelines triggered specifically by a pipeline schedule.

Exclusive Execution

The job will only run when a pipeline is initiated by a schedule, skipping other trigger types (e.g., push, merge request).

Use Cases

Ideal for maintenance, cleanup, backups, or reporting jobs that are not directly tied to code changes.

Key Takeaway

only: schedules provides precise control over job execution, ensuring scheduled tasks run only when intended, optimizing resource usage.
