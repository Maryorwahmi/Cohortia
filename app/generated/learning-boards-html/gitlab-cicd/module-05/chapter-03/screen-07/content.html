Restricting Manual Deployments

To prevent unauthorized or accidental manual deployments, combine when: manual with branch or tag restrictions.

only: main

Ensures the manual job is only available for pipelines running on the main branch, enforcing a stable source.

only: tags

Limits manual deployments to specific release tags, ideal for formal versioned releases.

Key Takeaway

Combining when: manual with branch or tag rules creates a robust security layer, ensuring only approved code from designated sources can be manually deployed.

Combined Control Flow

Code Commit to main

Only changes on the main branch trigger this path.

Automated Pipeline Runs

Build and test stages complete successfully.

Manual Deployment Job Paused

Awaiting authorized user's trigger.

Production Deployment

Only after human approval and from the main branch.
