How Protections Work Together

Protected branches and protected environments combine to create a powerful, multi-layered security framework for your CI/CD pipeline.

Protected Branches

Control who can push or merge code into critical branches (e.g., main).

Protected Environments

Control who can deploy to specific environments (e.g., production).

Key Takeaway

Layering protected branches and environments creates a robust defense, ensuring only authorized code from approved sources reaches critical deployment targets.

Integrated Security Flow

Code Merge to Protected Branch

Requires approval to merge into main.

Pipeline with Manual Job

Job targets a protected environment.

Authorized User Triggers Deployment

User has both merge rights to branch AND deploy rights to environment.

Secure Production Deployment

Ensures maximum control and safety.
