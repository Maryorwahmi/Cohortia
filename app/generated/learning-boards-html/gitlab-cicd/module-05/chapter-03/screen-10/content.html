Example: Daily Cleanup Job

This .gitlab-ci.yml snippet shows a job configured to run exclusively via a pipeline schedule.

stages:
  - maintenance

daily_cleanup:
  stage: maintenance
  script:
    - echo "Running daily cleanup script..."
    # Commands to remove old logs, clear cache, etc.
  only:
    - schedules # <-- Key configuration for scheduled trigger
Key Takeaway

The only: schedules keyword is essential for isolating and automating routine operational tasks that are not tied to code commits.

Steps to Implement a Scheduled Job

01Define Job in .gitlab-ci.yml

Add the job with only: schedules and your desired script commands.

02Create Schedule in GitLab UI

Navigate to CI/CD > Schedules and create a new schedule.

03Set Interval and Branch

Specify cron syntax (e.g., 0 2 * * * for 2 AM daily) and the target branch (e.g., main).

04Observe Execution

The job will run automatically at the scheduled time, independent of other pipeline triggers.
