Deployment Fundamentals

Interacting with `kubectl` and Manifests

Using the command-line tool to define desired states.

Key Components

  • •`kubectl`: Command-line tool for Kubernetes API interaction.
  • •Kubernetes API: The control plane for your cluster.
  • •Manifests: YAML files describing desired resource states.
  • •Declarative approach: Define 'what' you want, not 'how'.
Example Command

kubectl apply -f my-app-deployment.yaml creates or updates resources based on the manifest.

Key Takeaway

`kubectl` and YAML manifests are fundamental for declaratively managing Kubernetes resources.
