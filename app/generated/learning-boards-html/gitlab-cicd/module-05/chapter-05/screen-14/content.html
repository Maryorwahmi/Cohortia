Key Concepts to Remember

Essential terms for GitLab CI/CD and Kubernetes integration.

Kubernetes (K8s)

Open-source platform for automating deployment, scaling, and management of containerized applications.

`kubectl`

The command-line tool for interacting with a Kubernetes cluster's API server.

Kubernetes Manifest

A YAML or JSON file describing the desired state of Kubernetes resources.

Summary Takeaway

Kubernetes, `kubectl`, and manifests are the foundational elements for declarative and automated container orchestration.
