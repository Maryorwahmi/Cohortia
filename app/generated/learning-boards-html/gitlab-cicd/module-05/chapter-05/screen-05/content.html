Connection Methods

Connecting GitLab to Kubernetes

Securely enabling CI/CD jobs to interact with your cluster.

1. GitLab Kubernetes Agent (Recommended)

Install an agent in your cluster for a secure, outbound connection to GitLab, avoiding public API exposure.

2. Service Account Token

Configure a Kubernetes service account with specific permissions and provide its token as a CI/CD variable.

3. Kubeconfig File

Provide a base64-encoded `kubeconfig` file as a CI/CD variable for authentication.

Key Takeaway

The GitLab Kubernetes Agent offers the most secure and robust method for connecting GitLab CI/CD to your Kubernetes cluster.
