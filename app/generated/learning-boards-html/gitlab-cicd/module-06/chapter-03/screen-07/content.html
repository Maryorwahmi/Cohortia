Optimizing Performance: Caching Strategies

Storing Dependencies Between Runs

What is Caching?

  • •Stores specified directories/files between pipeline runs.
  • •Reduces repeated downloads and installations of dependencies.
  • •Significantly speeds up subsequent pipeline executions.
  • •Commonly used for package manager dependencies (e.g., node_modules, .venv).
Example Use Case

Caching node_modules in a Node.js project to avoid re-running npm install on every pipeline run, saving minutes.

Key Takeaway

Effective caching is a cornerstone of efficient pipelines, but requires careful management to avoid stale data.

Example: Basic Cache Configuration
stages:
  - build
  - test

build_job:
  stage: build
  image: node:16-alpine
  script:
    - npm install
    - npm run build
  cache:
    key: "node_modules" # Simple cache key
    paths:
      - node_modules/
    policy: pull-push # Uploads at end, downloads at start

test_job:
  stage: test
  image: node:16-alpine
  script:
    - npm test
  cache:
    key: "node_modules"
    paths:
      - node_modules/
    policy: pull
