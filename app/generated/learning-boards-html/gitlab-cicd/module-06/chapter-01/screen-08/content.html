Debugging Strategies

Adding Diagnostic Commands

Probing the Environment for Clues

build_job:
  stage: build
  image: node:16-alpine
  script:
    - echo "--- Debugging Info ---"
    - pwd # Print current working directory
    - ls -la # List directory contents
    - env # Show environment variables
    - npm install --prefix ./app # Original command
  artifacts:
    paths:
      - node_modules/
pwd: Current Directory

Verify the working directory to ensure scripts are executed in the expected location.

ls -la: Directory Contents

List files and folders to check for missing dependencies or incorrect file structures.

env: Environment Variables

Display all environment variables to confirm correct CI/CD variable passing and PATH settings.

Key Takeaway

Adding diagnostic commands to your job scripts provides crucial runtime context, helping you uncover hidden environmental or path-related issues.
