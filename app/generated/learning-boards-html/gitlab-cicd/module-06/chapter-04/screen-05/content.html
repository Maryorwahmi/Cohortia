GitLab CI/CD Variable Hierarchy

Understanding Different Variable Types and Their Scopes

Variable Types Explained

  • Predefined CI/CD Variables: Automatic, e.g., `$CI_COMMIT_BRANCH`.
  • Custom Variables: User-defined at project or group level.
  • `.gitlab-ci.yml` Variables: Defined globally or per job.
  • API Variables: Passed when triggering a pipeline, highest precedence.

Key Takeaway

GitLab CI/CD variables operate on a strict hierarchy, with API-triggered variables having the highest precedence, followed by job-level, global, project, group, and predefined variables.
