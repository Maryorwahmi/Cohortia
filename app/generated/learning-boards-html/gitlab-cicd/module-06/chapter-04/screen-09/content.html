Introducing Deployment Environments

Leveraging the `environment` Keyword for Tracking and Review Apps

Benefits of the `environment` Keyword

  • Environment Tracking: GitLab tracks deployments to each environment, showing commit history.
  • Dynamic Environments: Create temporary environments for merge requests (e.g., review apps).
  • Dynamic URLs: Specify a URL to get a 'View app' button in MRs and environment pages.

Key Takeaway

The `environment` keyword in GitLab CI/CD is essential for tracking deployments, creating dynamic review applications, and providing direct access to deployed environments via dynamic URLs, streamlining feedback and management.
