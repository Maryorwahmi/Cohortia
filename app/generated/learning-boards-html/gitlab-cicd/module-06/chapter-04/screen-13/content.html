Advanced Conditional Logic with `rules:if`

Building Highly Flexible and Adaptable Pipelines

Capabilities of `rules:if`

  • Complex Conditions: Combine multiple variables and logical operators.
  • Regular Expressions: Match branch names, commit messages, or other variable patterns.
  • Dynamic Command Generation: Use variable expansion within scripts.

Code Example: Conditional Production Deploy

deploy_production:  stage: deploy  script:    - echo "Deploying to production..."  environment:    name: production    url: https://prod.example.com  rules:    - if: '$CI_COMMIT_BRANCH == "main" && $DEPLOY_TO_PROD == "true"'      when: manual # Only run on main branch AND if DEPLOY_TO_PROD is true

This job will only be available for manual trigger if the branch is `main` AND the `DEPLOY_TO_PROD` variable is set to `true`.

Key Takeaway

Advanced `rules:if` conditions, combining variables and logic, enable highly flexible pipelines that execute jobs only when specific criteria are met, ensuring precise control and preventing unintended actions.
