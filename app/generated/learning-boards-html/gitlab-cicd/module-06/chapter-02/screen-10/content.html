Dependency Scanning: Securing Your Libraries

Identifies known vulnerabilities in your project's third-party dependencies (e.g., npm, pip packages) by checking against vulnerability databases.

# Example .gitlab-ci.yml snippet
include:
  - template: Security/Dependency-Scanning.gitlab-ci.yml

stages:
  - test
  - security

dependency_scanning:
  stage: security
  # This job is automatically added by the template

Why it matters: A single vulnerable library can compromise your entire application, even if your own code is secure.

Container Scanning: Protecting Your Images

Scans your Docker images for known vulnerabilities in the operating system packages and software components they contain.

# Example .gitlab-ci.yml snippet
include:
  - template: Security/Container-Scanning.gitlab-ci.yml

stages:
  - build
  - security

container_scanning:
  stage: security
  # This job is automatically added by the template
Key Takeaway

Regularly scan both your project dependencies and container images to prevent known vulnerabilities from reaching production.
