What are File Type Variables?

For secrets like private keys or certificates, GitLab allows you to define variables that are mounted as temporary files in the runner's environment.

  • •
    Temporary File Creation: The variable's content is written to a temporary file on the runner.
  • •
    Path Injection: An environment variable is set, pointing to the path of this temporary file.
  • •
    Reduced Exposure: Minimizes the risk of the secret being exposed in memory or shell history compared to string variables.

Using File Type Variables in Your Pipeline

Your job scripts can then read the content directly from the provided file path.

# In GitLab Project Settings > CI/CD > Variables
Key: SSH_PRIVATE_KEY
Value: -----BEGIN OPENSSH PRIVATE KEY-----
       ...
       -----END OPENSSH PRIVATE KEY-----
Type: File
Protected: ✓
Masked: ✓

# In .gitlab-ci.yml job script
ssh_job:
  stage: deploy
  script:
    - chmod 600 $SSH_PRIVATE_KEY # Set correct permissions
    - ssh -i $SSH_PRIVATE_KEY user@your-server "ls -la"
    - cat $SSH_PRIVATE_KEY # Content will be visible, but variable name is masked
Key Takeaway

Always use File type variables for private keys and certificates, combined with protected and masked attributes, for maximum security.
