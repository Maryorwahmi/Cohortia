Implementing when: manual for Production Deployments

Human Oversight for High-Stakes Releases

deploy_to_production:
  stage: deploy_production
  script:
    - echo "Deploying to production environment..."
    - # ... production deployment commands
  environment:
    name: production
    url: http://production.example.com
  when: manual # This job will only run when manually triggered
  only:
    - main # Only available on the main branch
  allow_failure: false # Production deployment should not fail silently
  rules:
    - if: '$CI_COMMIT_BRANCH == "main"' # Only show manual job for main branch
Manual Trigger

The when: manual keyword pauses the pipeline, requiring a user to explicitly start the job.

Environment Protection

Combine with Protected Environments to restrict who can trigger this manual deployment.

Branch Specificity

Use only or rules to ensure the manual job is only available on critical branches like main.

Key Takeaway

Manual approval jobs provide a critical human gate for sensitive deployments, enhancing control and security.
