Implementing Quality Gates

Setting criteria to prevent low-quality code from merging.

What is a Quality Gate?

A quality gate is a set of predefined criteria that must be met before a software project can proceed to the next stage of its lifecycle, typically before merging code into a main branch. Examples include 'no new critical bugs' or 'minimum code coverage.'

Steps to Implement a Custom Quality Gate
1

Parse gl-code-quality-report.json

2

Count Issues by Severity

3

Exit with Non-Zero Status if Threshold Exceeded

Example Threshold

A quality gate might be configured to fail the pipeline if any new critical or major code quality issues are introduced by a Merge Request. This prevents significant regressions.

Key Takeaway

Quality gates provide strict enforcement of code standards by programmatically failing pipelines if predefined quality criteria are not met, ensuring a consistent level of code excellence.
