Python Code Quality with Flake8

A practical example of configuring a static analysis job.

stages:
  - build
  - test
  - code_quality

build_job:
  stage: build
  script:
    - echo "Building the application..."
    - pip install -r requirements.txt
  artifacts:
    paths:
      - .venv/

python_unit_tests:
  stage: test
  image: python:3.9-slim-buster
  script:
    - pip install -r requirements.txt
    - pytest --junitxml=junit.xml
  artifacts:
    when: always
    reports:
      junit: junit.xml

code_quality_scan:
  stage: code_quality
  image: python:3.9-slim-buster
  allow_failure: true # Allow this job to fail initially
  script:
    - pip install flake8
    - flake8 . --output-file=flake8_report.txt # Run Flake8
    - pip install gitlab-code-quality # Utility to convert
    - gitlab-code-quality convert --tool flake8 --input flake8_report.txt --output gl-code-quality-report.json
  artifacts:
    reports:
      codequality: gl-code-quality-report.json # GitLab parses this
    paths:
      - gl-code-quality-report.json
Job Breakdown
  • stage: code_quality: Defines where this job runs in the pipeline.
  • image: python:3.9-slim-buster: Specifies the Docker image for the job.
  • allow_failure: true: Allows the pipeline to continue even if this job fails.
  • pip install flake8: Installs the Flake8 linter.
  • flake8 .: Executes Flake8 across the codebase.
  • gitlab-code-quality convert: Converts Flake8's output to Code Climate JSON.
  • artifacts: reports: codequality:: Tells GitLab to process the JSON report.
Key Takeaway

The code_quality_scan job demonstrates how to run a linter, convert its output to a GitLab-compatible format, and configure it for display in Merge Requests, providing automated quality feedback.
