Reporting Code Quality to GitLab

How GitLab consumes static analysis findings.

artifacts: reports: codequality

This GitLab CI/CD keyword is crucial. It specifies that a particular artifact file, typically gl-code-quality-report.json, should be parsed by GitLab as a Code Quality report. Without this, GitLab won't know to display the findings.

Code Climate Format

The Code Climate format is an open-source JSON schema for reporting code quality issues. Many static analysis tools can convert their native output to this format, making it a universal standard for integration with platforms like GitLab.

Key Takeaway
