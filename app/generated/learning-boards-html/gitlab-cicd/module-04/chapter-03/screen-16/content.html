Key Concepts: Scan Types and Integration

Recap the fundamental security scanning methods and their integration in GitLab.

SAST

Analyzes source code or binaries for security vulnerabilities without executing the application.

DAST

Analyzes a running application for security vulnerabilities by simulating external attacks.

Dependency Scanning

Identifies known security vulnerabilities in third-party libraries and dependencies used by the project.

Summary Takeaway

SAST, DAST, and Dependency Scanning are distinct yet complementary security methods, each targeting different aspects of your application, and easily integrated into GitLab CI/CD using templates.
