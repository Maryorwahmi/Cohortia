Customizing SAST and Dependency Scanning

Fine-tuning your static and dependency scans with CI/CD variables.

SAST Customization

Use SAST_EXCLUDED_ANALYZERS or SAST_DEFAULT_ANALYZERS to control which tools run.

Dependency Scanning Customization

Use DS_EXCLUDED_ANALYZERS to fine-tune dependency scanning tools.

Key Takeaway

Leverage CI/CD variables to tailor SAST and Dependency Scanning to your project's specific language and framework requirements, optimizing scan efficiency and relevance.

.gitlab-ci.yml
# Example: Customizing SAST and Dependency Scanning
variables:
  # SAST configuration (optional, can be overridden)
  SAST_EXCLUDED_ANALYZERS: "semgrep" # Exclude specific analyzers if needed
  SAST_DEFAULT_ANALYZERS: "bandit,brakeman" # Specify analyzers for specific languages

  # Dependency Scanning configuration
  DS_EXCLUDED_ANALYZERS: "gemnasium-python" # Exclude specific dependency analyzers
