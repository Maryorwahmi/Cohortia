Dynamic Application Security Testing (DAST)

Simulating attacks on your running application to find runtime flaws.

What it is

Analyzes a running application to find vulnerabilities by simulating external attacks.

What it finds

Misconfigurations, authentication flaws, business logic vulnerabilities, runtime issues.

When it runs

Later in the pipeline, after the application has been deployed to a staging or testing environment.

Key Takeaway

DAST is essential for uncovering runtime vulnerabilities and misconfigurations that static analysis cannot detect, requiring a deployed application.
