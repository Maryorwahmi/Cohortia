Static Application Security Testing (SAST)

Analyzing your code for vulnerabilities before it even runs.

What it is

Analyzes source code, bytecode, or binary code for security vulnerabilities without executing the application.

What it finds

SQL injection, Cross-Site Scripting (XSS), insecure direct object references, hardcoded credentials.

When it runs

Early in the pipeline, typically after the build stage, providing rapid feedback.

Key Takeaway

SAST is crucial for catching code-level vulnerabilities early, acting as a preventative measure before deployment.
