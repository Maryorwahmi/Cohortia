Enabling Security Scans in GitLab CI/CD

Leveraging GitLab's Auto DevOps templates for quick security integration.

Simplified Configuration

Use include: template: to add pre-defined security jobs to your .gitlab-ci.yml.

Automatic Job Creation

GitLab automatically adds jobs for SAST, DAST, and Dependency Scanning based on included templates.

Key Takeaway

GitLab's security templates streamline the integration of essential scans, making it easy to embed security into your CI/CD pipeline.

.gitlab-ci.yml
# Basic inclusion of security templatesinclude:
  - template: Security/SAST.gitlab-ci.yml
  - template: Security/DAST.gitlab-ci.yml
  - template: Security/Dependency-Scanning.gitlab-ci.yml

stages:
  - build
  - test
  - deploy # DAST needs a deployed application
  - dast   # DAST stage, typically after deploy
