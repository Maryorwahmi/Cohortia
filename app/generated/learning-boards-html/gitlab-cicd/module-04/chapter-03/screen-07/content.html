Dependency Scanning

Identifying known vulnerabilities in your project's open-source components.

What it is

Identifies known vulnerabilities in your project's open-source dependencies (libraries, frameworks, etc.).

How it works

Checks manifest files (e.g., package.json) against public vulnerability databases.

When it runs

Early in the pipeline, typically alongside SAST, as it only needs dependency manifest files.

Key Takeaway

Dependency scanning is vital for managing the security risks introduced by third-party components, requiring regular checks against vulnerability databases.

Dependency Scanning: The Librarian

Auditing your project's external components.

Manifest Files

Reads package.json, requirements.txt, etc.

Vulnerability Databases

Compares dependencies against known CVEs and security advisories.
