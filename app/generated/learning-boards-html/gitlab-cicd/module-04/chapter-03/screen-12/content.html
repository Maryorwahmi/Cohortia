Interpreting Vulnerability Reports

Understanding GitLab's security dashboards and the vulnerability triage process.

GitLab UI Integration

Reports are displayed in the Merge Request Widget, Pipeline Security Tab, and Security Dashboard.

Severity Levels

Vulnerabilities are categorized by Critical, High, Medium, Low, and Info severity.

Common Mistake

Ignoring 'Low' or 'Info' severity findings can lead to a growing backlog and increased attack surface.

Key Takeaway

Effective security management relies on understanding GitLab's comprehensive vulnerability reports and establishing a robust triage process for all findings.

Vulnerability Report Flow

From scan to actionable insights.

1. Scan Execution

SAST, DAST, Dependency Scans run in pipeline.

2. Report Generation

JSON artifacts created (e.g., gl-sast-report.json).

3. UI Display

Vulnerabilities visible in MR Widget, Pipeline Security, Security Dashboard.
