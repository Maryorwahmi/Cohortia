`.gitlab-ci.yml` Structure

stages:
  - build
  - test
  - deploy

build_job:
  stage: build
  script:
    - echo "Building..."

unit_tests_job:
  stage: test
  script:
    - echo "Running unit tests..."

integration_tests_job:
  stage: test
  script:
    - echo "Running integration tests..."
Key Takeaway

Define a dedicated `test` stage in `.gitlab-ci.yml` to organize and automate the execution of your unit and integration tests.

Common Mistake

Omitting the `test` stage or placing test jobs in later stages, leading to delayed feedback and inefficient bug detection.
