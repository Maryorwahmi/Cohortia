Essential Setup: Installing Dependencies

Avoiding Common Failures with Proper Dependency Management

Why Dependency Installation is Critical

  • •Fresh Environment: CI jobs start with a clean slate, requiring explicit setup.
  • •Test Runner Access: Test frameworks (Jest, Pytest) must be installed to run.
  • •Project Modules: Application code often relies on installed packages.
Analogy: It's like trying to bake a cake without first buying the ingredients. Your CI environment needs its 'ingredients' (dependencies) before it can 'bake' (run tests).
Key Takeaway

Always include dependency installation commands (e.g., `npm install`, `pip install`) in your CI job's script before running tests to ensure a complete environment.

Common Installation Commands

Node.js Projects

npm install
# or
yarn install

Python Projects

pip install -r requirements.txt

Common Mistake

Forgetting to install development dependencies, leading to 'command not found' errors for test runners like Jest or Pytest.
