CI vs. CD vs. Continuous Deployment

Understanding the Key Distinctions

Continuous Integration (CI)
Continuous Delivery (CD)
Continuous Deployment

Focus: Integrating code frequently.

Automated build and test on every merge.

Focus: Always deployable state.

CI + automated release preparation to staging, with manual approval for production.

Focus: Fully automated production.

CD + automatic deployment to production without human intervention.

Key Takeaway

CI is the foundation, CD ensures readiness with a manual gate, and Continuous Deployment automates the final production step.
