Key Takeaway

CD ensures your software is always ready for release, providing flexibility and control over when changes go live, typically with a manual gate.

Core Principles of CD

  • Extends CI: Builds on the foundation of automated integration and testing.
  • Automated Release Preparation: Packages, tests, and deploys to staging environments automatically.
  • Always Deployable: The codebase is consistently in a state that can be released.
  • Manual Production Gate: A human decision is typically required for deployment to live production.

Example: Staging Environment Validation

After a new feature passes all CI tests, the CD pipeline automatically builds a release candidate and deploys it to a staging environment. Here, QA engineers and product managers can perform final end-to-end testing and user acceptance testing (UAT) in an environment that mirrors production. Once they give their manual approval, the team can then decide to push the changes to live production, knowing it has been thoroughly validated.
