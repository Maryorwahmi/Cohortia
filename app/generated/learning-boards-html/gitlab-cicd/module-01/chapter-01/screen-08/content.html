The Continuous Delivery Pipeline

Preparing for Release with Human Oversight

Key Stages in CD

1Package Application
2Extensive Testing
3Deploy to Staging
4Manual Approval
Key Takeaway

The CD pipeline systematically prepares and validates software for release, with a critical human gate for strategic production deployment decisions.

Detailed Steps

  • Packaging: Creating deployable artifacts (e.g., Docker images, executables).
  • End-to-End Testing: Comprehensive tests simulating user flows across the entire application.
  • Security Scans: Automated checks for vulnerabilities and compliance issues.
  • Staging Deployment: Deploying to an environment identical to production for final validation.
  • Manual Approval: A human decision point to authorize deployment to the live production environment.

Example: Coordinated Release

A new marketing campaign is planned for next Tuesday, requiring a specific set of features to be live. With Continuous Delivery, the features are already built, tested, and sitting in the staging environment, ready to go. The team can simply wait for the marketing team's signal, and then, with a manual approval, trigger the production deployment precisely when needed, ensuring perfect coordination without last-minute scrambling or rushed deployments.
