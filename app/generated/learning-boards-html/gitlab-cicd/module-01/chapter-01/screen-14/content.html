Key Concepts

Essential terms from this chapter.

Continuous Integration (CI)

Developers frequently merge code into a central repository, verified by automated builds and tests to detect errors early.

Continuous Delivery (CD)

Extends CI by ensuring code is always built, tested, and prepared for release to production, often with a manual approval step.

Continuous Deployment

An advanced form of CD where every change passing automated tests is automatically deployed to production without human intervention.

Chapter Summary

CI/CD practices are fundamental to modern software development, enabling faster, more reliable, and higher-quality releases through progressive automation.
