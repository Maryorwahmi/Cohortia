Essential Git Commands

Tracking Your Work: Add and Commit

Creating Snapshots of Your Project's State

Terminal Commands
$ git add . # Stages all changes in the current directory
$ git add path/to/specific/file.js # Stages a specific file

# After staging, commit your changes:
$ git commit -m "Add new user authentication logic"

[main 7a1b2c3] Add new user authentication logic
 2 files changed, 10 insertions(+), 3 deletions(-)
 create mode 100644 src/auth.js

The Staging Area

A temporary area where you collect changes before committing them. It allows you to craft precise snapshots.

Common Mistake

Writing vague commit messages like "fix" or "update." Always explain what and why.

Key Takeaway

`git add` and `git commit` are fundamental for creating a clear, traceable history of your local development.
