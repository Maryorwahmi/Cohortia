Key Concepts

Essential Terms to Remember

Branch

A parallel version of the repository for isolated feature development or bug fixes.

Merge

The process of combining changes from one branch into another, integrating work.

Remote

A version of your repository hosted on a server (e.g., GitLab) for collaboration.

Merge Request (MR)

A GitLab feature to propose changes from one branch to another, facilitating code review and automated testing.

Chapter Summary

Branches enable isolated development, merges combine changes, remotes host shared repositories, and Merge Requests streamline code review and integration.
