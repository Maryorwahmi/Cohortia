Key Concepts

Essential Terms to Remember

Git

A distributed version control system (DVCS) for tracking changes in source code.

Repository (Repo)

A directory where Git stores all project files and their complete revision history.

Commit

A snapshot of your repository at a specific point in time, with a descriptive message.

Chapter Summary

Git provides the fundamental tools for tracking code changes, while a repository stores the project's history, and commits capture specific snapshots of your work.
