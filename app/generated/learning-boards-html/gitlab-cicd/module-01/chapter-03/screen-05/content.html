Getting Started: Cloning Your Project

Creating a Local Copy of a Remote Repository

Terminal Command
$ git clone <repository-url>

# Example:
$ git clone https://gitlab.com/your-username/my-first-gitlab-project.git

Cloning into 'my-first-gitlab-project'...
remote: Enumerating objects: 100, done.
remote: Counting objects: 100% (100/100), done.
remote: Compressing objects: 100% (60/60), done.
remote: Total 100 (delta 30), reused 100 (delta 30), pack-reused 0
Receiving objects: 100% (100/100), 10.23 KiB | 1.02 MiB/s, done.
Resolving deltas: 100% (30/30), done.

What it does:

  • Downloads the entire repository.
  • Includes all files, branches, and history.
  • Creates a new local directory for the project.
  • Establishes a connection to the remote.
Key Takeaway

`git clone` is your entry point to any existing Git project, providing a full local copy for development.

Common Mistake

Thinking `clone` only gets the latest code; it actually downloads the full project history.
