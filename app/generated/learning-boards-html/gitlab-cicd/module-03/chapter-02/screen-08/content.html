Unlocking Parallelism with DAGs

Overriding linear execution for faster feedback

What is a DAG?

A Directed Acyclic Graph (DAG) is a graph data structure where nodes represent jobs and edges represent dependencies, with no circular dependencies. In CI/CD, it defines the execution order of jobs.

  • •Overrides Stage Order: Jobs can define dependencies on other jobs regardless of their stage.
  • •Enables Parallelization: Jobs that don't depend on each other can run concurrently, even across stages.
  • •Faster Feedback: Reduces overall pipeline execution time, providing quicker results.
Key Takeaway

DAGs, implemented with the needs keyword, allow for flexible, parallel job execution across stages, significantly boosting pipeline efficiency.

needs Keyword

Functionality

A job declared with needs will only start after the 'needed' job completes successfully. It also automatically downloads artifacts from the 'needed' job.

Misconception: Just another dependencies

needs is fundamentally different from dependencies. While both handle artifacts, needs breaks the stage barrier, allowing true cross-stage parallelization, unlike dependencies.
