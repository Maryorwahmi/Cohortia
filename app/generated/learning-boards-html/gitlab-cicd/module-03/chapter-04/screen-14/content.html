Key Concepts

Mastering advanced configuration

`include:project`

Imports a YAML file from another GitLab project, enabling shared configurations across an organization.

`include:template`

Imports a predefined GitLab CI/CD template, offering ready-to-use best practices for common tasks.

`extends` keyword

Allows a job to inherit properties from a hidden job template, enabling customization and overriding.

Hidden Job

A job whose name starts with a dot (`.`) and serves as a template for other jobs, not executed directly.

DRY Principle

"Don't Repeat Yourself" - a software development principle that `include` and `extends` help achieve in CI/CD.

Summary Takeaway

By combining `include:project`, `include:template`, and the `extends` keyword with hidden jobs, you can build highly scalable, maintainable, and DRY-compliant CI/CD pipelines.
