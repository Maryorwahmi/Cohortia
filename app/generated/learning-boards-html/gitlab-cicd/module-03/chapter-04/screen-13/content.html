Key Concepts

Essential terms for reusable CI/CD

`include` keyword

Used to import external YAML files into the main `.gitlab-ci.yml`, enabling modularity and reusability.

`include:local`

Imports a YAML file from the same project's repository, ideal for splitting large configurations.

`include:remote`

Imports a YAML file from a public URL, useful for integrating with external CI/CD snippets.

Summary Takeaway

The `include` keyword, with its local and remote options, provides the foundational tools for modularizing your GitLab CI/CD pipelines and improving their organization.
