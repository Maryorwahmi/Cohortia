Core Mechanism

Understanding Configuration Merging

How included files combine with the main pipeline.

Intelligent Merging

GitLab combines all included YAML files into a single configuration before execution, not just concatenating them.

Conflict Resolution

Later definitions (in the main `.gitlab-ci.yml` or subsequent includes) override earlier definitions in case of conflicts.

Key Takeaway

The merging order is crucial: later definitions always take precedence. This allows for flexible customization of base configurations.

Merging Order Example

common_vars.yml
DEFAULT_IMAGE: "ubuntu:latest"
.gitlab-ci.yml (Main)
include: [common_vars.yml]
job_name:
image: "node:16"
Final Merged Configuration
job_name:
image: "node:16" (Overrides 'ubuntu:latest')
