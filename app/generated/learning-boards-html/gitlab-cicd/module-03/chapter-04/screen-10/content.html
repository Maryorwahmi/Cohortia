Extending and Overriding Jobs

Customizing shared job templates with `extends`.

The `extends` Keyword

Allows a job to inherit properties (image, script, variables) from another job, typically a hidden job template.

Hidden Jobs

Jobs prefixed with a dot (`.`) that are not executed directly but serve as reusable blueprints for other jobs.

Key Takeaway

`extends` combined with hidden jobs enables powerful inheritance and customization, drastically reducing boilerplate and promoting the DRY principle.

.gitlab/ci/shared_build.ymlYAML
.base_build_job: # Hidden job template
  image: alpine/git:latest
  stage: build
  script:
    - echo "Starting generic build..."
  artifacts:
    expire_in: 1 day
.gitlab-ci.ymlYAML
include:
  - local: '.gitlab/ci/shared_build.yml'

build_frontend:
  extends: .base_build_job # Inherit from hidden job
  script: # Override script
    - echo "Building frontend assets..."
    - npm install

build_backend:
  extends: .base_build_job
  script: # Override script
    - echo "Building backend services..."
    - mvn clean install
