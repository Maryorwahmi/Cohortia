`include` Type

Including Local Files

Organizing configurations within the same project.

Purpose of `include:local`

Breaks down a single, large `.gitlab-ci.yml` into smaller, more focused YAML files stored in the same repository.

Benefits

  • Improved readability of the main pipeline file.
  • Easier collaboration on specific pipeline parts.
  • Clearer separation of concerns for different job types.
Key Takeaway

`include:local` is the simplest way to modularize your CI/CD configuration, making your pipeline more organized and easier to manage within a single project.

.gitlab-ci.ymlYAML
include:
  - local: '.gitlab/ci/build.yml' # Include local build jobs
  - local: '.gitlab/ci/test.yml'  # Include local test jobs

stages:
  - build
  - test
  - deploy

# Other jobs defined here...
.gitlab/ci/build.ymlYAML
build_frontend:
  stage: build
  image: node:16
  script:
    - npm install
    - npm run build

build_backend:
  stage: build
  image: maven:3.8-jdk11
  script:
    - mvn clean install
