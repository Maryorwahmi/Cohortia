Module 3›Chapter 3.3›`rules:if` Condition
Versatile Condition

Boolean Expressions

Evaluates a boolean expression using CI/CD variables, comparison operators (`==`, `!=`), and logical operators (`&&`, `||`).

Key Use Case

Variable-Driven Logic

Perfect for controlling jobs based on branch names, pipeline sources, custom flags, or environment variables.

Key Takeaway

`rules:if` provides the most granular control, allowing pipelines to react dynamically to various conditions.

Example: Deploy to Staging
deploy_staging:
  stage: deploy
  script:
    - echo "Deploying to staging..."
  rules:
    - if: '$CI_COMMIT_BRANCH == "develop" && $DEPLOY_STAGING == "true"'
      when: on_success
    - when: never

Scenario: Deploy to staging only if on `develop` branch AND a specific variable is set.

This job runs automatically if both conditions are met, otherwise, it is skipped. This ensures controlled deployments to pre-production environments.
