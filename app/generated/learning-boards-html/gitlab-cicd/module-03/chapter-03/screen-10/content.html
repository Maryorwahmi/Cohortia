Module 3›Chapter 3.3›`rules:exists` & `rules:variables`
`rules:exists`

File/Directory Presence

Triggers a job if specific files or directories are present in the repository. Useful for microservices or modular projects.

`rules:variables`

CI/CD Variable State

Checks if a specific CI/CD variable is defined or has a particular value. Offers a concise way to check variable states.

Key Takeaway

These conditions enable jobs to react to the structural and environmental context of your project, enhancing pipeline robustness.

Example: Docker Build & Feature Flag
docker_build:
  stage: build
  script:
    - docker build .
  rules:
    - exists:
        - Dockerfile
      when: on_success
feature_test:
  stage: test
  script:
    - run_feature_tests.sh
  rules:
    - variables:
        - FEATURE_FLAG_ENABLED: "true"
      when: on_success

Scenario: Build Docker image if `Dockerfile` exists; run feature tests if `FEATURE_FLAG_ENABLED` is true.

These rules ensure jobs are only triggered when their specific file or variable conditions are met.
