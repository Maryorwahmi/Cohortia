Module 3›Chapter 3.3›Complex `rules` Example
Rule 1: Main Branch Deployment

`main` + `frontend` changes = Auto Run

Ensures production deployment only happens on `main` when frontend code is modified.

Rule 2: Develop Branch Manual Trigger

`develop` + `frontend` changes = Manual

Allows for controlled, manual deployments to a development environment.

Rule 3: Feature Branch Auto Run

`feature/new-ui` = Auto Run

Automates execution for specific feature branches, regardless of file changes.

Key Takeaway

Combining multiple `rules` with different conditions and `when` clauses allows for highly sophisticated and adaptive pipeline logic.

Example: Frontend Build and Deploy
build_and_deploy_frontend:
  stage: deploy
  script:
    - echo "Building and deploying frontend..."
  rules:
    - if: '$CI_COMMIT_BRANCH == "main"'
      changes:
        - frontend/**/*
      when: on_success
    - if: '$CI_COMMIT_BRANCH == "develop"'
      changes:
        - frontend/**/*
      when: manual
    - if: '$CI_COMMIT_BRANCH == "feature/new-ui"'
      when: on_success
    - when: never
