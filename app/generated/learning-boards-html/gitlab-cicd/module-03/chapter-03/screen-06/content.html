Module 3›Chapter 3.3›`only`/`except` Limitations
Limitation 1

Mutually Exclusive

You cannot use both `only` and `except` within the same job. This forces a choice between inclusion or exclusion logic.

Limitation 2

Cumbersome for Complex Logic

Combining multiple conditions (e.g., AND/OR logic, variable checks, file changes) becomes difficult or impossible. This leads to verbose and hard-to-read configurations.

Key Takeaway

For anything beyond simple branch/tag filtering, `only` and `except` quickly become inadequate, necessitating a more robust solution.

When `only`/`except` Fall Short

Run on `main` AND `$VAR` is true?
Run if `frontend/` changes OR `backend/` changes?
Run on `main` but skip for tags? (Requires `rules`)
These scenarios highlight the need for a more flexible conditional mechanism.
