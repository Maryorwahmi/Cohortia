Defining Custom Variables

Tailoring pipeline configuration to your needs.

What are Custom Variables?

Custom variables are user-defined values that you introduce to manage specific configurations for your application, environment, or deployment targets.

Key Takeaway

Custom variables offer flexibility in pipeline configuration, with UI/group-level definitions providing enhanced security and centralized management for sensitive or environment-specific data.

Where to Define Custom Variables

  • .gitlab-ci.yml: Directly in your pipeline definition file. Best for non-sensitive, pipeline-specific values.
  • GitLab UI (Project/Group Settings): Ideal for environment-specific configurations (e.g., STAGING_URL) or sensitive data. Keeps secrets out of the repository.

Benefit: Environment-Specific Configs

Using UI or group-level variables allows you to manage different configurations for development, staging, and production environments without modifying your code, enhancing security and simplifying maintenance.
