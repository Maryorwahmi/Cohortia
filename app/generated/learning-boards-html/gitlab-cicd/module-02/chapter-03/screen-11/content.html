Common Issues

Diagnosing Pipeline Failures (Part 2)

Advanced causes and how to identify them

Environment Issues

  • •Incorrect environment variables.
  • •Network connectivity problems (e.g., firewall, DNS).
  • •Insufficient permissions on the runner.

Artifacts Issues

  • •Forgetting to declare artifacts for files needed downstream.
  • •Incorrect dependencies leading to missing files in subsequent jobs.
Real-world Connection

A common scenario is a deployment job failing because it can't access a database due to incorrect environment variables or a blocked port.

Key Takeaway

Thoroughly check environment configurations and artifact declarations to prevent subtle but impactful pipeline failures.
