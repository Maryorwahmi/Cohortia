Debugging Essentials

The Job Log: Your Debugging Hub

Unlocking insights from job execution output

Accessing Job Logs

Click on any job in the pipeline graph to navigate to its individual job page, which contains the log.

Detailed Execution Output

The log displays every command executed, including standard output and error messages, crucial for understanding failures.

$ echo "Starting build..."
Starting build...
$ npm install
added 1234 packages in 5s
$ npm test
> my-app@1.0.0 test
> jest

FAIL  src/app.test.js
  ● Test suite failed to run

    ReferenceError: someFunction is not defined
      at Object.<anonymous> (src/app.test.js:5:1)
      at processTicksAndRejections (internal/process/task_queues.js:95:5)
ERROR: Job failed: exit code 1
Key Takeaway

The job log is your most powerful tool for debugging, providing the exact context of what happened during a job's execution.
