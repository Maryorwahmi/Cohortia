Pipeline Triggers: Automatic vs. Manual

Understanding how your CI/CD pipelines are initiated

Automatic Triggers

  • •Initiated by code changes like git push.
  • •Also triggered by new merge requests or tags.
  • •Can be scheduled to run at specific times.
  • •Ensures continuous integration and immediate feedback.
Example Scenario

A developer pushes new code to a feature branch, automatically starting a test pipeline.

Manual Triggers

  • •Explicitly started from the GitLab UI.
  • •Configured using when: manual in .gitlab-ci.yml.
  • •Ideal for sensitive operations like production deployments.
  • •Requires human approval or specific conditions.
Use Case

A release manager manually triggers a production deployment after all tests pass and approvals are met.

Key Takeaway

Choosing the right trigger type ensures pipelines run efficiently and securely, aligning with your project's operational needs.
