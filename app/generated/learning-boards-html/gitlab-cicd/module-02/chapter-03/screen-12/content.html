Debugging Strategies

Effective Troubleshooting with Job Logs

Practical techniques for pinpointing and resolving failures

Read Logs Carefully

Start from the bottom of the log and work upwards; the last few lines often contain the critical error message.

Add Debugging Commands

Use echo to print variable values and ls -la to inspect file paths at different points in your script.

Pro-Tip

For shell scripts, add set -ex at the beginning of your script to exit on error and print commands before execution.

debug_job:
  stage: debug
  image: alpine/git:latest
  script:
    - set -ex # Exit on error, print commands
    - echo "Debugging environment..."
    - ls -la /app # Check if /app directory exists
    - cat /app/config.txt || true # Try to read a file, continue if not found
    - my_non_existent_command # This command will fail and stop the script
    - echo "This line will not be reached."
Key Takeaway

Leverage set -ex and strategic logging to gain deep visibility into script execution and quickly identify failure points.
