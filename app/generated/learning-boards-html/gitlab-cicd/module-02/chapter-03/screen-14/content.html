Key Concepts: Pipeline Management

Essential terms and ideas from this chapter

Pipeline Trigger

The event that initiates a pipeline run, such as a git push, merge request, or manual action.

Manual Job

A job configured with when: manual that requires explicit user action to start from the GitLab UI.

Pipeline States

The various statuses a pipeline can have, such as pending, running, success, failed, or skipped.

Chapter Summary

Mastering pipeline triggers, manual jobs, and understanding pipeline states are foundational for effective CI/CD workflow management.
