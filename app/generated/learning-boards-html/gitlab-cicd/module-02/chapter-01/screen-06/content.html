Pipeline Structure

Defining Pipeline Stages

Organizing Your CI/CD Workflow Sequentially

What are Stages?

  • Logical phases of your CI/CD pipeline (e.g., build, test, deploy).
  • Execute sequentially: all jobs in one stage must complete successfully before the next.
  • Defined as a YAML list, specifying their execution order.
# .gitlab-ci.yml snippet
stages:
  - build
  - test
  - deploy
Example Flow

In this example, all 'build' jobs will run first. Only if they all succeed will 'test' jobs begin. Finally, 'deploy' jobs will execute after all 'test' jobs pass.

Key Takeaway

Stages provide a high-level, sequential structure to your pipeline, ensuring a controlled and ordered progression of tasks.
