YAML Fundamentals

Understanding YAML Syntax

The Language of GitLab CI/CD Configuration

Key YAML Rules

  • Indentation: Uses spaces (2 recommended), never tabs, to define structure.
  • Key-Value Pairs: Defined as key: value.
  • Lists: Represented by hyphens (- item).
# Example YAML Structure
items:
  - item1
  - item2
config:
  name: my_app
  version: 1.0
  enabled: true
Common Mistake

Mixing tabs and spaces or inconsistent indentation will lead to syntax errors and pipeline failures. Always use spaces consistently.

Key Takeaway

YAML's readability comes from its strict indentation rules; master them to avoid common configuration errors in your CI/CD pipelines.
