Job Essentials

Image and Script Keywords

Defining the Environment and Commands for Each Job

Core Job Components

  • image: Specifies the Docker image for the job's execution environment.
  • script: Contains the shell commands the job will execute.
  • Both are mandatory for a functional job.
# Job snippet
my_job:
  image: node:16-alpine
  script:
    - npm install
    - npm test
Why it Matters

The image ensures a consistent, isolated, and reproducible environment, preventing 'works on my machine' issues. The script defines the actual work.

Key Takeaway

image provides the execution context, and script provides the instructions, forming the fundamental definition of any GitLab CI/CD job.
