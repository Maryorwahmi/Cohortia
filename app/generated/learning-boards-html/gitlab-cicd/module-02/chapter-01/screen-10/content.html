Before and After Script Hooks

Managing Setup and Teardown for Robust Jobs

Lifecycle Hooks

  • before_script: Commands run *before* the main script.
  • after_script: Commands run *after* the main script (always, even on failure).
  • Enhance job reliability and maintainability.

Use Cases

before_script is perfect for installing dependencies (e.g., npm ci). after_script is great for cleanup (e.g., removing temporary files) or sending notifications.

Important Note

If before_script fails, the job stops immediately, and script is not executed. after_script will still run.

Key Takeaway

before_script and after_script provide dedicated sections for setup and teardown, making your jobs more robust and predictable.
