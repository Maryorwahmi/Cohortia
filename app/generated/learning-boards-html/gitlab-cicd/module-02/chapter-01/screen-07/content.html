Pipeline Structure

Jobs: The Units of Work

Independent Tasks within Your Pipeline Stages

Job Characteristics

  • Smallest unit of work in a pipeline, executing specific commands.
  • Defined as top-level keys and belong to a specific stage.
  • Jobs within the same stage run in parallel by default.

Parallel Execution

If you have unit_tests and integration_tests jobs in the same test stage, they will run simultaneously, significantly reducing pipeline execution time.

Common Misconception

Jobs in different stages run in parallel. Incorrect! Jobs only run in parallel if they are in the same stage. Stages themselves execute sequentially.

Key Takeaway

Jobs are the independent tasks that perform the actual work, and their parallel execution within stages is key to efficient pipelines.
