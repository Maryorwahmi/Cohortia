Key Concepts: Part 2

Job Execution and Lifecycle Management

Jobs

Smallest unit of work in a pipeline; defined within stages and execute commands in an isolated environment.

Image & Script

image specifies the Docker environment; script contains the shell commands a job will execute.

before_script & after_script

Hooks for job setup (before main script) and teardown/notifications (after main script, always runs).

Summary Takeaway

Jobs are the core execution units, and keywords like image, script, before_script, and after_script provide granular control over their environment and lifecycle.
