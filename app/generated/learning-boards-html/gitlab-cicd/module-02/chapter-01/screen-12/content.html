Key Concepts: Part 1

Foundational Elements of GitLab CI/CD

YAML

Human-friendly data serialization language; indentation (spaces, not tabs) is critical for defining structure.

.gitlab-ci.yml

The configuration file at the root of a GitLab repository that defines the entire CI/CD pipeline.

Stages

Logical, sequential phases of a pipeline (e.g., build, test, deploy); all jobs in one stage must complete before the next.

Summary Takeaway

Mastering YAML syntax, understanding the role of the .gitlab-ci.yml file, and defining pipeline stages are the fundamental steps to building effective CI/CD workflows.
