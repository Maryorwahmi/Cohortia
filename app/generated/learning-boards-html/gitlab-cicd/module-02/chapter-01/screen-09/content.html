First Pipeline

Building a Simple 'Hello World' Pipeline

Your First Automated Greeting

Pipeline Breakdown

  • Stage: greeting - A single phase for our introductory task.
  • Job: hello_world_job - The specific task within the greeting stage.
  • Image: alpine/git:latest - A lightweight Docker environment.
  • Script: echo, hostname, ls -la - Commands to execute.
# .gitlab-ci.yml
stages:
  - greeting

hello_world_job:
  stage: greeting
  image: alpine/git:latest
  script:
    - echo "Hello, GitLab CI/CD!"
    - hostname
    - ls -la
Key Takeaway

This basic pipeline demonstrates the fundamental interaction between stages, jobs, images, and scripts to perform automated tasks.
