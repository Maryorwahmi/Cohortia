Node.js Build Job with Lifecycle Hooks

Ensuring Consistent Setup and Teardown

Job Flow Explained

  • before_script: Installs Node.js dependencies using npm ci.
  • script: Executes the main build command, npm run build.
  • after_script: Logs a completion message, always runs.
# .gitlab-ci.yml for Node.js build
stages:
  - build

node_build_job:
  stage: build
  image: node:16-alpine
  before_script:
    - echo "Installing Node.js dependencies..."
    - npm ci
  script:
    - echo "Running build command..."
    - npm run build
  after_script:
    - echo "Build job finished."
Key Takeaway

before_script ensures a clean, reproducible setup (e.g., npm ci), while after_script guarantees consistent post-execution actions, enhancing job reliability.
