Understanding Stages and Parallelism

How stages define sequential flow and jobs run concurrently by default.

Key Characteristics

  • •

    Sequential Stages: Stages execute one after another in the order they are defined (e.g., `build` then `test`).

  • •

    Parallel Jobs: All jobs within a single stage run concurrently by default, maximizing efficiency.

  • •

    Typical Stages: Common stages include `build` (compilation), `test` (unit/integration tests), and `deploy` (application rollout).
