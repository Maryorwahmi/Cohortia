Implementing Artifacts in `.gitlab-ci.yml`

Saving build outputs and making them available for downstream jobs.

Key Artifacts Directives

  • •

    `paths:`: Specifies which files or directories to save as artifacts. Can be a single file or a list of paths.

  • •

    `expire_in:`: Sets how long artifacts should be retained. Useful for managing storage and cleanup.

  • •

    `dependencies:`: (Used in *downstream* jobs) Declares a dependency on a previous job to automatically download its artifacts.

build_app:
  stage: build
  image: node:16-alpine
  script:
    - npm ci
    - npm run build # This command generates build/index.js
  artifacts:
    paths:
      - build/ # Save the entire 'build' directory
    expire_in: 1 day # Artifacts will be available for 1 day
Common Mistake

Forgetting to declare artifacts for files needed by later stages, leading to 'file not found' errors.
