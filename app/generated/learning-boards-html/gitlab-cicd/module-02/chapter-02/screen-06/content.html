The Role of Artifacts in Pipelines

Passing files and data between jobs and stages for seamless workflows.

Why are Artifacts Essential?

  • •

    Workspace Discarded: By default, a job's workspace is deleted after it completes.

  • •

    Data Persistence: `artifacts` save specified files/directories for later use.

  • •

    Inter-Job Communication: Enables subsequent jobs to access outputs from previous jobs.

  • •

    Efficiency: Prevents redundant work by sharing compiled code, test reports, etc.

Artifacts Flow: Build to Test

Build Job
Artifacts Stored
Test Job

Artifacts act as a bridge, carrying necessary files from one job's environment to the next.

Key Takeaway

`artifacts` are essential for saving and passing files between jobs and stages, ensuring data continuity in complex pipelines.
