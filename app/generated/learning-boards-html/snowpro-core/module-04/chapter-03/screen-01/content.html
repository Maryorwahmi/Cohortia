Data Encryption, Masking, and Tokenization

Explore Snowflake's layered protections: automatic encryption for storage and transport, real-time masking to hide sensitive values based on roles, and tokenization to remove secrets from the platform entirely.

In this lesson
Encryption
AES-256 at rest and TLS in transit provide baseline protection without user action.
Masking
Masking policies hide values at query time based on roles, leaving stored data unchanged.
Tokenization
External tokenization replaces sensitive values before they enter Snowflake for highest data minimization.
