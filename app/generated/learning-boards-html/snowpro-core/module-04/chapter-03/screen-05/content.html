Definition › Dynamic Data Masking

What dynamic masking does

Masking policies transform column results at query time using SQL logic and session context. The table's stored values remain unchanged.

Role-aware masking
Policies commonly check CURRENT_ROLE() or IS_ROLE_IN_SESSION() to determine how to return a value.
Centralized control
Attach one policy to a column and every consumer receives the masked or unmasked result according to the policy logic.
Performance note
Complex masking expressions on frequently filtered or joined columns can change query performance; test before wide rollout.
Key Takeaway

Dynamic masking controls visible data centrally and safely, but requires testing and performance monitoring.

Concrete scenario
Imagine a customer table: ACCOUNTADMIN sees full credit card, DATA_ANALYST sees last four digits only, and BUSINESS_USER sees a fully masked value. No copies of the table are required and the stored data remains the same.
Analogy
Think of masking as a window shade that filters what each viewer sees without altering the room behind the shade.
