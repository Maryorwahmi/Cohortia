What to Remember › Technical Terms
Masking Policy
Schema-level SQL logic that transforms a column's returned value based on session context.
External Tokenization
Replacing sensitive data with tokens before ingestion so originals live in an external vault.
External Function
A Snowflake feature that calls external services, commonly used to integrate tokenization flows.
Quick reminder
A column can have one masking policy; plan policy logic for all roles and keep it simple. Tokenization requires external custody and integration work.
