Learning Objectives

These objectives focus on explanation, implementation, testing, and choice of protection strategies.

01
Explain encryption at rest
Describe AES-256 and hierarchical key management so you can justify baseline data protection.
VERIFIED COMPETENCY MILESTONE
02
Explain encryption in transit
Understand how TLS secures client connections and why no manual config is typically needed.
VERIFIED COMPETENCY MILESTONE
03
Describe dynamic masking
Define how masking applies at query time and why the table's stored data remains unchanged.
VERIFIED COMPETENCY MILESTONE
04
Author masking policies
Write SQL that checks CURRENT_ROLE and returns masked results for protected columns.
VERIFIED COMPETENCY MILESTONE
