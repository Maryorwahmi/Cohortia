Module 5 › Chapter 4.4 › QUERY_HISTORY: inspect past queries
Example query
SELECT
  query_id,
  query_text,
  user_name,
  role_name,
  start_time,
  end_time,
  execution_status
FROM
  SNOWFLAKE.ACCOUNT_USAGE.QUERY_HISTORY
WHERE
  user_name = 'JOHN_DOE'
  AND start_time >= DATEADD(hour, -24, CURRENT_TIMESTAMP())
ORDER BY
  start_time DESC;
Investigation tips
  • Filter by user or role to focus scope.
  • Use ORDER BY start_time DESC to build a timeline.
  • Check execution_status for failures or cancellations.
Interpretation
Concrete example
If a query by JOHN_DOE shows long duration and high credits, correlate the query_id with WAREHOUSE_METERING_HISTORY to find the cost impact.
Common mistake
Using INFORMATION_SCHEMA here can miss older, account-wide entries. Use ACCOUNT_USAGE for full history.
Key Takeaway

QUERY_HISTORY is the forensic starting point; always include timestamps and status to build a clear incident timeline.
