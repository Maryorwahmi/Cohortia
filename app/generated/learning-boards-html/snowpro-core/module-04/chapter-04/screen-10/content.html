Module 5 › Chapter 4.4 › Time Travel: query and restore past states
Commands you will use
-- Query data as it appeared 5 minutes ago
SELECT * FROM my_table AT (OFFSET => -60*5);

-- Restore a dropped table
UNDROP TABLE my_table;

-- Clone a table from a specific timestamp
CREATE TABLE my_table_restored CLONE my_table AT (TIMESTAMP => '2023-10-26 10:00:00'::TIMESTAMP);
When to use
Quick recovery, point-in-time analysis, and safe cloning for testing prior states.
Retention
Default retention is limited; increase it if your policies require longer recoverability.
Misconception
Time Travel is not infinite; do not assume data will always be available without proper retention settings.
