Module 5 › Chapter 4.4 › Key ACCOUNT_USAGE views
Primary views and use cases
QUERY_HISTORY
Details about each executed query: user, role, start/end time, duration, and status. Use it for troubleshooting and cost analysis.
LOGIN_HISTORY
Records login attempts with timestamps, client IPs, client type, and success/failure flags for authentication auditing.
ACCESS_HISTORY
(Enterprise+) Tracks read and write operations on tables and columns to show who accessed which data.
GRANTS_TO_ROLES / GRANTS_TO_USERS
Inventory of privileges to verify RBAC configuration during audits.
TABLE_STORAGE_METRICS & WAREHOUSE_METERING_HISTORY
Storage and credit usage details for cost and capacity investigations.
Usage tip
Correlation
Join QUERY_HISTORY with WAREHOUSE_METERING_HISTORY to map heavy queries to warehouse credit consumption.
Edition note
ACCESS_HISTORY is available in Enterprise Edition and above; plan accordingly if you need row-level access logs.
