Module 5 › Chapter 4.4 › Learning Objectives — Applied

How you'll demonstrate each objective

Practical tasks map directly to the skills you need for auditing, recovery, and compliance.

Task
Audit report
Run QUERY_HISTORY and LOGIN_HISTORY queries, export the results, and annotate suspicious entries with timestamps, user, and IP.
Task
Telemetry checks
Identify failed logins and long-running queries using LIMIT and ORDER BY to focus your investigation window.
Task
Time Travel demo
Create, drop, and UNDROP a table or CLONE it at a timestamp to show point-in-time recovery.
Task
Fail-safe explanation
Write a short note describing why Fail-safe is for catastrophic recovery and not for user-driven restores.
Verified Competency

Deliverables: SQL scripts for history queries, a recovered table, and a short compliance justification document.
