Learning Objectives

Build measurable skills for auditing, recovery, and compliance.

Bloom: Learn → Understand → Apply → Master
01
Explain auditing value
You will describe how audit logs support incident response and compliance. You will be able to cite an example such as finding who modified a table during a window of interest.
Venn: Security + Compliance
VERIFIED COMPETENCY MILESTONE
02
Query ACCOUNT_USAGE
You will run queries against ACCOUNT_USAGE views to retrieve historical query and login data across the account, enabling cross-database investigations and cost analysis.
Mnemonic: Archive icon
VERIFIED COMPETENCY MILESTONE
03
Use Time Travel
You will recover dropped or updated data using Time Travel commands like UNDROP and CLONE AT TIMESTAMP or OFFSET, and understand retention limits.
Timeline mnemonic
VERIFIED COMPETENCY MILESTONE
04
Differentiate Fail-safe
You will explain why Fail-safe is a Snowflake-managed recovery period after Time Travel and not accessible for routine restores.
Contrast: User vs Snowflake
