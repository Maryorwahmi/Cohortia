What 'live' means
Consumers query the provider's current data state. There is no automatic copy; updates and schema changes on the provider are immediately visible.
Implications
  • Providers must coordinate schema changes to avoid breaking consumers.
  • Consumers cannot write to shared objects and should request changes or copy data if writes are needed.
  • Use secure views or masking to protect sensitive columns while sharing.
Scenario
If a provider renames a column, consumers' queries can fail. Use views or a deprecation plan to maintain compatibility.
Pro Tip
Publish a change calendar and test schema changes against consumer queries before applying them in production.
