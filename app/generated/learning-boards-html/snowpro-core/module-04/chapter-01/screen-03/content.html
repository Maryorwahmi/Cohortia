Module 4 › Chapter 4.1 › Learning Objectives
05
Troubleshoot share issues
Identify why a consumer cannot access a shared table, commonly due to missing USAGE on database or schema on the provider side.
Mnemonic: grants must form a path to the object.
VERIFIED COMPETENCY MILESTONE
06
Apply least privilege
Grant only USAGE on containers and SELECT on specific objects to the share. Avoid ALL PRIVILEGES which can expose more than intended.
Mnemonic: minimum access, maximum control.
VERIFIED COMPETENCY MILESTONE
07
Know exchanges and Marketplace
Recognize that data exchanges enable private sharing among ecosystems and the Marketplace enables listing datasets for discovery beyond direct account-to-account shares.
Mnemonic: private exchange vs discoverable marketplace.
VERIFIED COMPETENCY MILESTONE
08
Audit and verify shares
Use SHOW GRANTS OF SHARE and DESCRIBE SHARE to validate what is shared and with which accounts so you maintain compliance.
Mnemonic: check grants regularly.
VERIFIED COMPETENCY MILESTONE
