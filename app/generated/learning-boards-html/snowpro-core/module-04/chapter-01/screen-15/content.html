Provider Controls
Provider creates share and decides what to expose. They retain lifecycle control and can revoke access.
Consumer Experience
Consumers create a database from the share and query live, read-only data as if it were local.
Grant Path
Ensure grants form a path: USAGE on database → USAGE on schema → SELECT on tables/views for consumer visibility.
Final note
Design shares deliberately: limit scope, audit regularly, and communicate changes so consumers can rely on shared, live data safely.
