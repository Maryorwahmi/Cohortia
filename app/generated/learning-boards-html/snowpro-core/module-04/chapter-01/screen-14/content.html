Module 4 › Chapter 4.1 › Key Concepts
Share Object
Defines which objects and which consumer accounts can access provider data; the data itself remains in the provider account.
Shared Database
A read-only database created in the consumer account that provides live access to provider objects defined by the share.
Least Privilege
Grant USAGE on database and schema, and SELECT on specific tables or views. Audit shares and avoid overly broad grants.
One-line takeaway
Use shares to expose live, read-only data while keeping governance and control in the provider account; verify grants and communicate schema changes to keep consumers stable.
