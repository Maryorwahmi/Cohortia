Module 4 › Chapter 4.1 › Create a Share
Step-by-step
  1. Create the share object with CREATE SHARE.
  2. Grant USAGE on the database to the share.
  3. Grant USAGE on the schema to the share.
  4. Grant SELECT on the specific tables or views to the share.
  5. Add consumer accounts to the share with ALTER SHARE ... ADD ACCOUNTS.
Common mistake
Granting SELECT without USAGE on the database/schema prevents consumers from navigating to the objects.
Example SQL
-- As ACCOUNTADMIN or role with CREATE SHARE
CREATE SHARE my_sales_share;

-- Grants to the share
GRANT USAGE ON DATABASE SALES_DB TO SHARE my_sales_share;
GRANT USAGE ON SCHEMA SALES_DB.PUBLIC_SCHEMA TO SHARE my_sales_share;
GRANT SELECT ON TABLE SALES_DB.PUBLIC_SCHEMA.SALES_ORDERS TO SHARE my_sales_share;

-- Add the consumer account
ALTER SHARE my_sales_share ADD ACCOUNTS = 'ORG1.ACCOUNTXYZ';
Tip: run SHOW GRANTS OF SHARE my_sales_share to verify.
