Module 4 › Chapter 4.1 › Learning Objectives
01
Understand secure sharing
Define what a share is and why Snowflake avoids data copying. This helps you reduce ETL and stale copies.
Mnemonic: think of a live window into provider data.
VERIFIED COMPETENCY MILESTONE
02
Identify provider & consumer roles
Recognize who owns data, who consumes it, and their privileges and limits in a sharing relationship.
Mnemonic: owner vs viewer.
VERIFIED COMPETENCY MILESTONE
03
Create and manage shares
Use CREATE SHARE, grant USAGE on database and schema, and grant SELECT on tables or views to the share.
Mnemonic: create, grant, add accounts.
VERIFIED COMPETENCY MILESTONE
04
Consume shared data
Create a database from a share and query it; remember shared data is read-only and always current.
Mnemonic: create database from share = read-only window.
