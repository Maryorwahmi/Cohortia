Module 4 › Chapter 4.1 › Granting Privileges
What to grant
  • USAGE on the provider database to the share.
  • USAGE on the provider schema to the share.
  • SELECT on each table or view to the share.
Pitfall
Granting ALL PRIVILEGES or other elevated rights can unintentionally expose data. Stick to USAGE and SELECT.
Verify and audit
After granting, run SHOW GRANTS OF SHARE my_share and DESCRIBE SHARE my_share to confirm which objects and accounts are associated with the share. If a consumer cannot access a table, first confirm USAGE exists on both the database and schema.
Key Takeaway

Privilege grants must complete a path from database → schema → object for consumers to navigate and query shared data.
