Module 4 › Chapter 4.1 › Add Consumer Accounts
Command example
-- Add a consumer account to the share
ALTER SHARE partner_product_share ADD ACCOUNTS = 'YOUR_PARTNER_ACCOUNT_IDENTIFIER';

-- Verify the share
DESCRIBE SHARE partner_product_share;
SHOW GRANTS OF SHARE partner_product_share;
Tip: request the exact account identifier string from the consumer to avoid typos.
Validation checklist
  • DESCRIBE SHARE shows the consumer account listed.
  • SHOW GRANTS OF SHARE lists the database, schema, and object grants.
  • Consumer can run CREATE DATABASE FROM SHARE and query objects.
Common issue
Consumer gets an error creating the database: often the provider failed to add the exact account identifier or the consumer lacks CREATE DATABASE privileges internally.
