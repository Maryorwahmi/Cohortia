Module 4 › Chapter 4.1 › What is Secure Data Sharing?
Definition
A provider grants read-only, live access to specific objects by creating a share; consumers create a database from that share to query current data.
Why it matters
  • Eliminates ETL and file transfers between accounts.
  • Consumers always query up-to-date rows; no stale copies.
  • Providers maintain data governance and control.
Key Takeaway

Model shares as windows into provider data. Share intentionally and test consumer queries to confirm results and access behavior.

Concrete example
A sales account exposes the SALES_ORDERS table to a marketing account. Marketing runs analytics immediately without any copy. Provider still controls who sees which columns and can revoke access any time.
Misconception
Sharing is not data movement. Consumers do not own or store the shared rows; they only gain read-only visibility to live provider data.
