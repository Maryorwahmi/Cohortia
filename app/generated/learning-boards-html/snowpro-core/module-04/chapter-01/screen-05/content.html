Module 4 › Chapter 4.1 › Provider vs Consumer
Provider (owner)
  • Creates the share object with CREATE SHARE.
  • Grants USAGE on database/schema and SELECT on tables/views to the share.
  • Adds consumer accounts with ALTER SHARE ... ADD ACCOUNTS.
  • Retains control and can revoke access any time.
Example account id: ORGABC.ACCOUNT67890
Consumer (reader)
  • Creates a database from the share with CREATE DATABASE ... FROM SHARE.
  • Queries shared tables as read-only objects.
  • Sees live, current data; provider updates are immediately visible.
  • Cannot perform DML operations on shared objects.
Example account id: ORG1.ACCOUNTXYZ
Common mistake
Assuming consumers can modify shared data. Shared databases are read-only for consumers; any data changes must happen in the provider account.
