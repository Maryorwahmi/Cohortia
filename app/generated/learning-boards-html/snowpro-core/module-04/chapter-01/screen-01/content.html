Secure Data Sharing with Snowflake
Share live, governed data without ETL, keeping control where the data lives.
Orientation

Snowflake shares provide read-only, live access to provider data. Providers define a share object that lists databases, schemas, and tables. Consumers create a database from that share and query it like a local read-only database.

In this lesson: create a share, grant USAGE and SELECT, add accounts, then create a database from the share.
Explore Key Topics
Share Object

Consumer DB

Security
