Module 4 › Chapter 4.1 › Create Database from Share
Example consumer commands
-- As consumer with CREATE DATABASE privilege
CREATE DATABASE sales_data_from_provider FROM SHARE ORG1.ACCOUNT12345.my_sales_share;

-- Query shared table
USE DATABASE sales_data_from_provider;
SELECT * FROM PUBLIC_SCHEMA.SALES_ORDERS LIMIT 10;
Note: queries return current provider data; consumers cannot modify shared objects.
Practical notes
  • Shared databases are read-only in the consumer account.
  • Provider updates are immediately visible to consumers.
  • If performance differs from local tables, coordinate with provider on compute or clustering.
Key Takeaway

Create the shared database, then treat it as a live, read-only source and coordinate changes with the provider.
