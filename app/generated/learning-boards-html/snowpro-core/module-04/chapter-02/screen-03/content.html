Skill progression

From design to SQL to audit — these skills produce reproducible access control that fits teams and compliance needs.

Tip: model roles on org responsibilities rather than individuals.
Assessment link

You will answer questions about future grants and inheritance to verify understanding.

01 — Implement hierarchy
Grant lower-role to higher-role to inherit privileges and reduce repetition.
Example: DATA_ANALYST → DATA_ENGINEER
Benefit: single grant updates many users
VERIFIED COMPETENCY MILESTONE
02 — Use future grants
Apply SELECT to future tables or views so new objects inherit access without manual grants.
Command: GRANT ... ON FUTURE ...
Outcome: consistent access for new objects
VERIFIED COMPETENCY MILESTONE
03 — Audit & verify
Use SHOW GRANTS and SHOW FUTURE GRANTS to confirm effective privileges and to support compliance reviews.
Remember to check both direct grants and inherited grants when auditing.
VERIFIED COMPETENCY MILESTONE
