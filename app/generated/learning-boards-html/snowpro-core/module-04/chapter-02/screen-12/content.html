Module 4 › Chapter 4.2 › Key Concepts — Part 1
Role-Based Access Control
Privileges are associated with roles; users receive access by being granted roles.
System-Defined Roles
Use account and admin roles for platform tasks; avoid using them for daily work.
Custom Roles
Create roles to match organizational functions and reduce per-user grants.
Summary Takeaway

Design roles for reuse, audit with SHOW commands, and use future grants to keep permissions consistent as objects are added.
