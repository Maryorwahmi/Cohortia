What is ownership?

Ownership grants the owning role complete control over an object. The creator role becomes the owner by default.

-- Transfer ownership while preserving grants
GRANT OWNERSHIP ON TABLE SALES_DB.PUBLIC.ORDERS TO ROLE NEW_OWNER COPY CURRENT GRANTS;
Note: COPY CURRENT GRANTS preserves existing privileges so users retain access after transfer.
Common pitfalls
  • Changing ownership without COPY CURRENT GRANTS can revoke existing privileges.
  • Assuming any admin can transfer ownership; only the owner or MANAGE GRANTS can do so.
  • Not auditing ownership changes increases risk of orphaned or inaccessible objects.
Takeaway
Plan ownership transfers and include COPY CURRENT GRANTS to maintain continuity.
