Module 4 › Chapter 4.2 › System-Defined Roles vs Custom Roles
System-Defined Roles
ACCOUNTADMIN
Full account control; use sparingly and only for platform-level tasks.
SYSADMIN
Manage warehouses, databases, and create objects.
SECURITYADMIN
Manage users, roles, and grants.
USERADMIN
Create and manage users and assign roles.
PUBLIC
Automatically assigned; avoid granting sensitive privileges here.
Warning
Do not use ACCOUNTADMIN for daily tasks. Overuse increases security risk and audit scope.
Custom Roles
Purpose
Model business functions and group privileges by job responsibility.
Hierarchy
Grant roles to roles to create inheritance and reduce repetition.
Example
Create DATA_ANALYST with SELECT and grant it to DATA_ENGINEER to inherit read access.
Best practice
Use custom roles for daily operations; reserve system roles for administration.
