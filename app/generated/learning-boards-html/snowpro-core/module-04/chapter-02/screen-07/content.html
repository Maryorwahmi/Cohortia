Module 4 › Chapter 4.2 › Grant Roles & Switch Context
Granting
Use GRANT ROLE to assign roles to users. Set DEFAULT_ROLE on user creation to define the initial session role.
-- As SECURITYADMIN
GRANT ROLE DATA_ANALYST TO USER JOHN_DOE;
GRANT ROLE DATA_ENGINEER TO USER JANE_SMITH;

-- Create user with default role
CREATE USER ANNA_SMITH PASSWORD = 'password123' DEFAULT_ROLE = FINANCE_DEV;
GRANT ROLE FINANCE_DEV TO USER ANNA_SMITH;
Verification: have the user USE ROLE and run a SELECT to confirm read rights, then try a write to check for missing privileges.
Runtime behavior
A user's active role determines the privileges available. Switching roles changes effective permissions immediately for that session.
Concrete scenario
An engineer sets DATA_ENGINEER as default to create tables, then switches to DATA_ANALYST to run read-only reports, preventing accidental writes.
