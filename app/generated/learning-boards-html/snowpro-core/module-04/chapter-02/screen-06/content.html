Module 4 › Chapter 4.2 › Create Roles & Grant Privileges
Process
  1. Create the role as SECURITYADMIN or a role with CREATE ROLE privilege.
  2. Grant USAGE on warehouses, databases, and schemas as required.
  3. Grant object privileges like SELECT or CREATE TABLE to the role.
  4. Grant roles to other roles to form a hierarchy if needed.
  5. Grant roles to users and verify with SHOW GRANTS.
Pitfall: Without USAGE on database and schema, table-level privileges won't let users query data.
Example SQL
-- As SECURITYADMIN or equivalent
CREATE ROLE DATA_ANALYST;
CREATE ROLE DATA_ENGINEER;

-- Inherit analyst privileges in engineer role
GRANT ROLE DATA_ANALYST TO ROLE DATA_ENGINEER;

-- Grants for DATA_ANALYST
GRANT USAGE ON WAREHOUSE COMPUTE_WH TO ROLE DATA_ANALYST;
GRANT USAGE ON DATABASE SALES_DB TO ROLE DATA_ANALYST;
GRANT USAGE ON SCHEMA SALES_DB.PUBLIC TO ROLE DATA_ANALYST;
GRANT SELECT ON ALL TABLES IN SCHEMA SALES_DB.PUBLIC TO ROLE DATA_ANALYST;

-- Additional engineer privileges
GRANT CREATE TABLE ON SCHEMA SALES_DB.RAW_DATA TO ROLE DATA_ENGINEER;
Run verification queries like SHOW GRANTS TO ROLE DATA_ANALYST to confirm the assigned rights.
