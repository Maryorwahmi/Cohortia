Module 4 › Chapter 4.2 › Designing a Role Hierarchy
Approach
1. Identify minimal-privilege base roles for common needs.
2. Create higher-level roles that receive base roles via GRANT ROLE.
3. Assign fewer roles to users to minimize administrative overhead.
Practical tip
Document role purpose and expected users to keep the model maintainable.
Concrete example
Create FINANCE_READER for select-only access. Create FINANCE_DEV and grant FINANCE_READER to it, then grant additional CREATE privileges on the SANDBOX schema to FINANCE_DEV. Grant FINANCE_DEV to users who need both read and dev capabilities.
Check inheritance and effective privileges using SHOW GRANTS OF ROLE and SHOW GRANTS TO ROLE to confirm the chain.
