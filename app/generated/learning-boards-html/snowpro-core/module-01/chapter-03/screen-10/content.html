Module 2 › Chapter 1.3 › Cloud Services Costs
What Cloud Services does
Handles authentication, metadata, query optimization, and coordination. It is the control plane of Snowflake.
Usually
Included in compute costs for most customers.
Rare case
High metadata activity relative to compute may trigger separate billing.
Action
Monitor patterns; reduce millions of tiny operations if Cloud Services usage is high.
Concrete example

An application issuing millions of trivial queries that create metadata work but little compute could push Cloud Services usage up; monitor and refactor such patterns.
