Module 2 › Chapter 1.3 › Cost Optimization Best Practices
Practical controls
  • Right-size warehouses to workload
  • Enable AUTO_SUSPEND and AUTO_RESUME
  • Use zero-copy cloning for dev/test
  • Tune queries and use materialized views where beneficial
Operational routine
Schedule regular usage reviews, set guardrails for warehouse sizes, and include cloning patterns in developer onboarding.
Common mistake: scaling up compute before investigating query inefficiencies. Try tuning first, then scale if needed.
Concrete example

Create a clone for QA instead of copying data. Only changed blocks in the clone consume extra storage, saving TBs of cost for large datasets.
