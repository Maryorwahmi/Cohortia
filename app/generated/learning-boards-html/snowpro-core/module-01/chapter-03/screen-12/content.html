Module 2 › Chapter 1.3 › Monitoring Usage in Snowsight
Steps to inspect usage
  1. Open Admin → Usage in Snowsight.
  2. View Credit Usage by warehouse and time range.
  3. View Storage Usage: Average Storage and Fail-safe.
  4. Identify top-consuming warehouses and retention settings.
Try this SQL to suspend
ALTER WAREHOUSE COHORTIA_WH SUSPEND;
After a few minutes, check Credit Usage to confirm the warehouse stopped consuming credits.
Key Takeaway

Use Snowsight charts to verify actions like suspending warehouses and to identify optimization opportunities.
