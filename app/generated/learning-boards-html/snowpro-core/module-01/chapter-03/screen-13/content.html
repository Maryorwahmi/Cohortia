Module 2 › Chapter 1.3 › Common Cost Mistakes
Top Mistakes
  • Leaving warehouses running (no AUTO_SUSPEND)
  • Over-sizing warehouses to compensate for slow queries
  • Extending Time Travel or failing to account for Fail-safe storage
  • Copying production data instead of zero-copy cloning
Practical guardrails
  • Enable AUTO_SUSPEND and AUTO_RESUME
  • Set default maximum warehouse sizes
  • Require zero-copy clones for dev/test
  • Schedule usage reviews
