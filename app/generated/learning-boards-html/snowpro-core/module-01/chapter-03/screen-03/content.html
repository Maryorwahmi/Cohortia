Module 2 › Chapter 1.3 › Learning Objectives — Implementation
Verify Usage in Snowsight
Open Admin → Usage and inspect the Credit Usage and Storage Usage charts.
Check the time range, identify spikes, and note which warehouses consumed credits. This confirms how compute patterns map to spend.
Test Auto-Suspend
Suspend a test warehouse and observe credit usage stopping shortly after suspension.
This demonstrates compute billing is tied to active warehouse time and validates savings from suspension.
Inspect Storage Retention
Compare Average Storage and Fail-safe usage and reason about Time Travel retention impact.
Longer Time Travel increases stored historical data and monthly storage charges; Fail-safe is non-configurable and billed as well.
Map Requirements to Edition
Practice mapping concurrency, recovery duration, and compliance needs to editions.
This helps avoid picking an underpowered edition or overspending on unnecessary isolation.
