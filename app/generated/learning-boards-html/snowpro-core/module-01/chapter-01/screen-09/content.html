Module 1 › Chapter 1.1 › Storage & Compute
Why decoupling matters
Separate layers let you scale each independently and avoid unnecessary cost or contention.
Independent scaling
Grow storage without adding compute, and increase compute for heavy queries without moving data.
Cost control
Pause or resize compute to match workloads while data remains persistent and available.
Concrete example
Daily dashboards use a small warehouse while nightly analytics use a larger one. Both read the same stored data without copying it.
Misconception
Decoupling adds operational burden. In reality, managed platforms handle storage and surface simple controls for compute provisioning.
Key Takeaway

Separation lets teams optimize cost and performance for different workloads without moving data.
