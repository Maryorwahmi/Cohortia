Sign up and explore
Create a trial account, choose a provider region, and open Snowsight to find Worksheets, Databases, and Warehouses.
UI checklist
  • Worksheets: write and run SQL queries.
  • Databases: view sample datasets like SNOWFLAKE_SAMPLE_DATA.
  • Warehouses: manage compute resources for queries.
Sample query (run in a worksheet)
SELECT
  C_CUSTKEY,
  C_NAME,
  C_NATIONKEY
FROM
  SNOWFLAKE_SAMPLE_DATA.TPCH_SF1.CUSTOMER
LIMIT 10;
Run this to see results and observe which warehouse executed the query. Sample data is read-only unless copied into your account.
Note
When you run queries, watch the warehouse activity meter to connect compute with query latency and cost.
