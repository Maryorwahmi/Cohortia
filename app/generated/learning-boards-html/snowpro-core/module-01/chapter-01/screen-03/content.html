Practice & Verification
Concrete steps to prove each objective in a trial environment.
01 — Traditional limits
Practice: list capital and operational tasks. Verify: estimate cost difference between buying servers and renting cloud compute for one year.
02 — Cloud benefits
Practice: create a usage scenario with peak load. Verify: observe how scaling can be automated and billed per use in the console.
03 — Data Cloud
Practice: draft a secure sharing use case between teams. Verify: see data sharing examples or sample datasets in a trial account.
04 — Architecture
Practice: sketch storage vs compute separation. Verify: run simultaneous simple queries on separate warehouses to observe isolation.
