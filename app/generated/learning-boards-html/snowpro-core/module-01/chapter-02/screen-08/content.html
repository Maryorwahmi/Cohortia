Core Concept

Cloud Services: metadata, security, and features

This layer stores metadata, manages auth and access control, optimizes queries, and coordinates features like cloning and Time Travel without copying raw storage.

Auth & Access
User identities, roles, and permissions are enforced here.
Metadata & Optimization
Stores schemas, partition stats, and drives pruning.
Transactions & Security
Ensures ACID behavior and handles encryption key management.
Feature Spotlight
Zero-copy cloning and Time Travel rely on metadata references tracked by the cloud services layer to provide instant snapshots without copying storage.
Key Takeaway

The cloud services layer makes advanced capabilities possible by managing metadata and coordination, not by replicating data.
