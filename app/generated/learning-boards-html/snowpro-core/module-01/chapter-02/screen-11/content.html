Comparison

Shared-disk, shared-nothing, and Snowflake

- Shared-disk: same storage, server contention for resources and locks.
- Shared-nothing: partitioned data reduces contention but needs redistribution for joins.
- Snowflake: shared data in cloud storage + independent compute clusters for isolation and concurrency.
Concrete effect
Avoids contention and complex data movement, enabling multiple warehouses to query the same data with predictable performance.
Key Takeaway

Snowflake’s hybrid approach provides simplicity and concurrency for many analytic workloads by pairing shared storage with isolated compute.

Common mistake
Thinking Snowflake forces the same trade-offs as older models. It blends advantages to reduce traditional pain points.
