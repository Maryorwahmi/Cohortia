Core Concept

Three-layer claim

Separation enables independent scaling of data and compute and centralizes orchestration in the cloud services layer.

Database Storage
Columnar, compressed, encrypted, micro-partitioned storage.
Query Processing
Virtual warehouses run queries independently on shared storage.
Cloud Services
Metadata, security, optimization, cloning and Time Travel orchestration.
Architecture Diagram (card-first)
Storage: immutable micro-partitions
Data stored once, converted to columnar, and enriched with partition-level statistics for pruning.
Compute: virtual warehouses
Multiple independent clusters connect to shared storage and run work in isolation.
Key Takeaway

Design systems assuming compute can be scaled or suspended independently of stored data to control cost and concurrency.
