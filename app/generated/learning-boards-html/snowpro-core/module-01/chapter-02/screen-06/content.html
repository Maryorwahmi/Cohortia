Virtual warehouses: run, isolate, suspend

Warehouses execute queries and scale independently from storage. Use auto-suspend to control cost and auto-resume for responsiveness.

Sizing tiers
Sizes determine parallelism. Choose a size that balances performance and cost for the workload.
Auto-suspend / Auto-resume
Set short suspend times for bursty workloads to minimize charges and avoid long idle costs.
Scenario
ETL uses a dedicated large warehouse to maximize throughput while analysts use smaller warehouses for ad hoc queries. Neither workload interferes with the other.
Key Takeaway

Assign workloads to dedicated warehouses to achieve predictable performance and control costs via auto-suspend.

Common mistake
Confusing warehouses with databases. Warehouses are compute; databases are storage. Mis-sizing warehouses can lead to unnecessary cost or poor performance.
