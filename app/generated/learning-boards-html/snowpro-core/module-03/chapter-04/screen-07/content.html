Module 4 › Chapter 3.4 › BEFORE & Query ID
Target the moment before a statement
Find the Query ID
Search your query history for the DELETE or UPDATE statement and note its QUERY_ID.
-- Example: find the DELETE statement's Query ID
-- SELECT QUERY_ID, QUERY_TEXT FROM TABLE(INFORMATION_SCHEMA.QUERY_HISTORY()) WHERE QUERY_TEXT LIKE '%DELETE FROM my_table%';

-- Then use BEFORE with that Query ID
SELECT * FROM my_table BEFORE (STATEMENT => 'abcdef12-3456-7890-abcd-ef1234567890');
BEFORE returns the exact table state just before the referenced statement executed.
Practical hints
  • Confirm the statement's timing and ensure it's within retention.
  • Validate the selected rows before re-inserting or replacing live data.
  • If the table was dropped, use UNDROP rather than BEFORE to restore the object.
Common Mistake

Using the wrong Query ID or a Query ID outside retention will return no useful historical state.
