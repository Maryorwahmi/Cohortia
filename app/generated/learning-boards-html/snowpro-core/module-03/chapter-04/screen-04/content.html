Module 4 › Chapter 3.4 › What is Time Travel?
Time Travel explained
Snowflake stores prior micro-partitions so you can query or recover historical data.
Formal definition
When data is changed, Snowflake keeps previous micro-partitions instead of overwriting them. These retained versions allow reconstruction of past table states for the retention window.
Why it matters
  • Quick recovery from accidental deletes or truncates.
  • Historical analysis and auditing without maintaining separate backups.
  • Creating clones from past snapshots for testing or debugging.
Key Takeaway

Time Travel is an operational history layer that supports self-service recovery and auditing within a configurable retention window.

Analogy
Think of Time Travel as a versioned snapshot system built into the storage layer. Each change creates a new version while old versions remain readable for the retention period.
Common misconception
It is not an indefinite archive: retention expires and then Fail-safe may apply. Also, transient tables do not retain history by default.
Concrete example
You update a customer's name, earlier micro-partitions contain the prior value. Querying with an AT timestamp returns that prior name for the retention window.
