Recovering a sample table
Steps
1. Create table and insert rows. Record CURRENT_TIMESTAMP.
2. UPDATE and DELETE to change and remove rows; verify current state.
3. Use AT with your saved timestamp or OFFSET to read the old state and extract needed rows.
4. If table was dropped, run UNDROP TABLE to restore within retention, then validate content.
Starter SQL (visual only)
CREATE TABLE customer_records (
  customer_id INT,
  customer_name VARCHAR(100),
  registration_date DATE
);

INSERT INTO customer_records VALUES
(1, 'Alice', '2023-01-15'),
(2, 'Bob', '2023-02-20');

-- Later
UPDATE customer_records SET customer_name = 'Alicia' WHERE customer_id = 1;
DELETE FROM customer_records WHERE customer_id = 2;

-- Query historical state
SELECT * FROM customer_records AT (OFFSET => -120);

-- If dropped
DROP TABLE customer_records;
UNDROP TABLE customer_records;
