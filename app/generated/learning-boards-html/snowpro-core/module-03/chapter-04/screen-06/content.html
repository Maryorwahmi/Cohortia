Module 4 › Chapter 3.4 › AT clause
Query historical states with AT
Two common forms: OFFSET for relative time, TIMESTAMP for absolute time.
Examples
-- Querying data as it was 1 hour ago
SELECT * FROM my_table AT (OFFSET => -3600);

-- Querying data as it was at a specific timestamp
SELECT * FROM my_table AT (TIMESTAMP => '2023-10-25 12:00:00'::TIMESTAMP_LTZ);
Use your recorded timestamp to target exact moments. Make sure the timestamp is within retention.
Practical workflow
  1. Note CURRENT_TIMESTAMP before making changes.
  2. Perform updates or deletes.
  3. Use AT with your saved timestamp or an OFFSET to read the previous state.
  4. Validate results; INSERT rows back if you need to restore them permanently.
Key Takeaway

AT reads past states. Use it to extract and reinsert rows or to compare prior values for debugging and audits.
