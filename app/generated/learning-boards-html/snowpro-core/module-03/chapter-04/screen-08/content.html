Module 4 › Chapter 3.4 › UNDROP workflow
Recover a dropped table
Typical commands
-- Drop and recover a table
DROP TABLE important_data;

-- Recover the table
UNDROP TABLE important_data;

-- If name is reused, UNDROP with a new name:
-- UNDROP TABLE important_data RENAME TO important_data_old;
UNDROP restores the object as it existed at drop time; confirm schema and rows after recovery.
Safety and pitfalls
  • Do not recreate the same object name if you intend to UNDROP the original.
  • If you must reuse the name, UNDROP the original under a different name and migrate data.
  • UNDROP only works within Time Travel retention; after that Fail-safe may apply and is not user-accessible.
Key Takeaway

Use UNDROP for soft-deleted objects and avoid name collisions to keep recovery simple.
