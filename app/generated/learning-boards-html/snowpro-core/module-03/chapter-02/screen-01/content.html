Optimizing Query Performance
Measure with EXPLAIN, reduce scanned data, and apply best-practice SQL to control cost.
In this lesson
You will learn to run EXPLAIN, interpret partitions and bytes scanned, and apply filters, projection, and clustering wisely to reduce compute.
Why it matters
Faster queries save time and reduce virtual warehouse cost. Small SQL changes often have outsized effects on bytes scanned.
Explore Key Topics
EXPLAIN
Generate an execution plan to observe partitions and bytes scanned before running the query.
Micro-partitions
Snowflake prunes micro-partitions using min/max metadata to skip irrelevant data.
Filter Early
Apply WHERE clauses before joins and aggregations to reduce intermediate data size.
