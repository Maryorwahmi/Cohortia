Module 3 › Chapter 3.2 › Select necessary columns
Anti-pattern
-- Bad
SELECT * FROM large_customer_table WHERE region = 'EMEA';
This reads all columns for matching rows, increasing bytes scanned and downstream data movement.
Best practice
-- Good
SELECT customer_id, customer_name, email
FROM large_customer_table
WHERE region = 'EMEA';
Projection reduces what must be read and transferred. It also makes intent explicit for code reviewers.
When SELECT * is acceptable
Ad-hoc exploration or quick debugging, but avoid in scheduled jobs and shared views.
Key Takeaway
Be explicit about columns in production to shrink scanned bytes and save credits.
