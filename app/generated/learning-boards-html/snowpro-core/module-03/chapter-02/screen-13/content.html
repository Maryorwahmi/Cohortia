Experiment steps
  1. Create sample data and seed enough rows to simulate your table sizes.
  2. Run EXPLAIN on the original query and note partitions/bytes scanned.
  3. Apply a single change, like filtering on sale_date, and re-run EXPLAIN.
  4. Decide next steps: more SQL changes, clustering, or warehouse sizing.
Key Takeaway
Measure before and after every change. Single-change experiments let you attribute improvements reliably.
