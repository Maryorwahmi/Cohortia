Module 3 › Chapter 3.2 › Clustering keys and reclustering
What clustering does
Clustering arranges data so similar values of specified columns are co-located in the same micro-partitions, improving pruning for range queries and correlated filters on very large tables.
Commands
ALTER TABLE sales_data CLUSTER BY (order_date, product_id); ALTER TABLE sales_data RECLUSTER;
Trade-offs
  • Benefit: improved pruning and fewer partitions scanned for targeted queries.
  • Cost: reclustering consumes credits; automatic clustering may add sustained cost.
  • When to use: high-volume tables with repeated queries on correlated columns.
Key Takeaway
Only adopt clustering after EXPLAIN shows persistent large scans on correlated columns and when the expected pruning gain justifies reclustering cost.
