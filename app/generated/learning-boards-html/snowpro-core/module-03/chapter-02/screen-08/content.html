Module 3 › Chapter 3.2 › Join optimization
Rules of thumb
  • Filter large tables before joining to reduce rows participating in the join.
  • Join smaller, filtered tables first to keep intermediates small.
  • Ensure join columns use compatible data types and are appropriate keys.
Scenario
If orders is much larger than customers, filter orders by date first, then join to customers to reduce the join footprint.
Quick fixes
Materialize filtered sets
Use temporary tables for very large filters to avoid repeated scanning during complex joins.
Avoid non-key joins
Joining on high-cardinality non-key columns can blow up intermediate sizes.
Key Takeaway
Reduce the amount of data participating in joins by filtering and ordering joins logically before escalating to structural changes.
