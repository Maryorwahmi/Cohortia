When to extract fields
  • Fields used frequently in WHERE clauses or JOINs should be typed columns.
  • High-cardinality fields that drive pruning are good candidates for extraction.
  • Keep VARIANT for less-used or audit-oriented data.
ETL vs. query-time flattening
If array elements are regularly analyzed, normalize during ETL so queries are simpler and faster. Use FLATTEN in scheduled transformations when necessary.
Operational tips
Monitor query profiles and costs. If certain nested paths create expensive plans, extract them or precompute results. Consider materialized views for repeated heavy aggregations on flattened data.
Key Takeaway

Use VARIANT for flexible ingestion and typed columns for query performance. Balance flexibility with the cost of repeated parsing or full scans.
