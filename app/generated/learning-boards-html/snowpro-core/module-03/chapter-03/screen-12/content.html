Module 3 › Chapter 3.3 › Pitfalls & Debugging
Incorrect pathing
Verify keys and array indices using sample records; wrong paths return null.
Double parsing
Don't call PARSE_JSON on values already stored as VARIANT; it's unnecessary.
Empty arrays
Guard with ARRAY_SIZE or use an OUTER pattern if you need to preserve parent rows for empty arrays.
Debugging checklist
  1. SELECT a few staged records and inspect keys with OBJECT_KEYS and ARRAY_SIZE.
  2. Use TRY_PARSE_JSON on suspect strings to avoid load failures.
  3. Compare row counts and aggregates before and after flattening to spot dropped rows.
