Module 3 › Chapter 3.3 › Loading with COPY INTO
Step-by-step
1. Create a stage and upload files
Use an internal or external stage and upload JSON, AVRO, or XML files for COPY INTO.
2. Create a table with VARIANT
Add VARIANT for raw payloads and typed columns for hot fields you will filter on frequently.
3. COPY INTO using SELECT
Select fields from staged records, cast them, and place the record into the VARIANT column.
4. Validate and handle malformed rows
Use TRY_PARSE_JSON if records may be invalid so COPY INTO completes and problematic rows can be inspected later.
Key Takeaway

Extract and cast hot fields during load to speed filters, while storing the full object in VARIANT for flexibility.

COPY INTO example
-- Create a table with a VARIANT column
CREATE TABLE raw_events (
  event_id INT,
  event_timestamp TIMESTAMP_NTZ,
  event_data VARIANT
);

-- Load JSON and extract fields
COPY INTO raw_events (event_id, event_timestamp, event_data)
FROM (
  SELECT
    $1:user_id::INT,
    $1:timestamp::TIMESTAMP_NTZ,
    $1
  FROM @my_json_stage/events.json
)
FILE_FORMAT = (TYPE = JSON);
This example extracts user_id and timestamp while preserving the entire object. Use TRY_PARSE_JSON when input may be a malformed JSON string.
