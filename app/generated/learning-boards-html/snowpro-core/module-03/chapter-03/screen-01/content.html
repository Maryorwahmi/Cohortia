Working with Semi‑Structured Data

Learn how Snowflake stores JSON, AVRO, and XML in VARIANT columns, how to load files with COPY INTO, and how to query and normalize nested data for analytics.

In this lesson
Store semi-structured payloads in VARIANT and query fields whenever you need them. Avoid rigid schema changes.
Why it matters
APIs, logs, and IoT output often arrive as JSON. VARIANT lets analysts query that data with SQL without losing flexibility.
Outcome
Extract nested fields, flatten arrays to rows, and decide which fields should become typed columns for performance.
Common pitfall
Relying on ad hoc parsing for frequently filtered fields rather than extracting them into typed columns.
Explore Key Topics
VARIANT data type
Parsed, columnar storage for semi-structured payloads enables schema-on-read.
Loading with COPY INTO
Stage files, then COPY INTO to place objects into VARIANT or typed columns during load.
FLATTEN
Explode nested arrays into rows so SQL can analyze each element naturally.
Concept map
VARIANT
One column stores JSON/AVRO/XML in parsed form for fast queries.
Dot & Bracket Notation
Access nested keys and array elements easily in SQL.
FLATTEN
