Module 3 › Chapter 3.3 › Hands-on Activity
Activity steps
1. Create stage and upload file
Create an internal stage and PUT your local sample JSON file.
2. Create table
Create orders_raw with order_data VARIANT.
3. COPY INTO
COPY INTO orders_raw FROM @my_json_stage/sample_data.json FILE_FORMAT = (TYPE = JSON);
4. Query and FLATTEN
SELECT order fields and use LATERAL FLATTEN to expand items for analysis.
Validation

Compare counts and sums before and after flattening. Use TRY_PARSE_JSON if any staged rows fail to parse.
