Practice & Safety

Concrete checks to keep your loads reliable and performant
Bloom: Apply → Master
Staging and COPY INTO
Use an internal or external stage. During COPY INTO, extract fields and cast to SQL types to make filters efficient.
VERIFIED COMPETENCY MILESTONE
TRY_PARSE_JSON
Wrap suspect text with TRY_PARSE_JSON to return null on malformed rows instead of failing the load.
VERIFIED COMPETENCY MILESTONE
Notation choices
Prefer dot notation for simple keys; use bracket notation if keys include special characters or you need numeric indexes.
VERIFIED COMPETENCY MILESTONE
Extract hot fields
For frequently filtered fields, store them as strongly typed columns during load to enable pruning and faster queries.
