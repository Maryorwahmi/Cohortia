FLATTEN example
SELECT
  o.event_id,
  o.event_timestamp,
  item.value:id::INT AS item_id,
  item.value:qty::INT AS quantity
FROM
  raw_events AS o,
  LATERAL FLATTEN(input => o.event_data:items) AS item;
Here item.value is each array element. Cast nested fields to proper types and include the parent id so you can re-link items back to their order or event.
Notes & caveats
  • FLATTEN on empty arrays returns no rows; guard with ARRAY_SIZE or use an OUTER lateral approach.
  • Always include parent keys when flattening so context is preserved for joins and aggregations.
  • Deeply nested arrays may need staged or iterative flattening steps to normalize fully.
Common mistake
Forgetting to re-attach the parent id leads to orphaned rows that are hard to reconcile.
