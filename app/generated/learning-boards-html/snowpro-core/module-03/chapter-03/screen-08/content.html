Module 3 › Chapter 3.3 › Helper Functions
PARSE_JSON / TRY_PARSE_JSON
Convert VARCHAR JSON text to VARIANT. TRY_PARSE_JSON returns null for malformed input so loads can continue.
GET / GET_PATH
Function-style access to object keys or nested paths when you prefer functions over notation.
ARRAY_SIZE / OBJECT_KEYS
Inspect array lengths and object key lists so you can validate structure before flattening or aggregating.
Practical pattern
When ingesting, use TRY_PARSE_JSON on any VARCHAR inputs that may contain JSON. Use ARRAY_SIZE to guard FLATTEN calls and avoid unnecessary lateral joins on empty arrays.
Key Takeaway

Match the function to the input: parse text to VARIANT with TRY_PARSE_JSON, then inspect or extract with GET, GET_PATH, or notation.
