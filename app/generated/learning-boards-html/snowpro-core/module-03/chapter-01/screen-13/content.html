Module 3 › Chapter 3.1 › Key Concepts
Virtual Warehouse
Compute cluster responsible for executing queries, separate from storage.
Warehouse Size
Defines cluster count and compute power; pick based on workload complexity and concurrency needs.
Auto-Suspend
Pauses a warehouse after inactivity to avoid compute costs.
Summary Takeaway

Remember separation, right-sizing, and automated suspend/resume as the foundational controls for efficient Snowflake compute.
