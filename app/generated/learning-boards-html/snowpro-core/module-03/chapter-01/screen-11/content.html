Common Pitfalls
  • Not setting AUTO_SUSPEND or setting it too long.
  • Right-sizing without profiling queries.
  • Using multi-cluster for single heavy queries.
Best Practices
  1. Measure and set AUTO_SUSPEND near job idle times.
  2. Profile queries for CPU/Memory/I/O before increasing size.
  3. Use multi-cluster only when concurrent workloads cause queueing.
Assessment example
For a daily 30-minute transformation, a MEDIUM warehouse with AUTO_SUSPEND around 1800 seconds is often cost-effective because it runs the job and suspends soon after to stop billing.
