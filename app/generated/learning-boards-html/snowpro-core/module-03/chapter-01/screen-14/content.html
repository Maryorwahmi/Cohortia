Module 3 › Chapter 3.1 › Key Concepts
Multi-Cluster Warehouse
Automatically scales out clusters to serve concurrent queries within configured min/max bounds.
Scaling Policy
STANDARD scales aggressively for throughput; ECONOMY reduces rapid cluster churn to save cost.
Result Caching
Caches final query results so identical queries against unchanged data can return instantly without compute.
Final Takeaway

Combine right-sizing, sensible auto-suspend, appropriate multi-cluster settings, and result caching to deliver predictable performance and cost control.
