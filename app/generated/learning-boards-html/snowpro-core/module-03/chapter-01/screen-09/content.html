Common commands
-- Create a warehouse
CREATE WAREHOUSE my_reporting_wh
  WITH WAREHOUSE_SIZE = 'MEDIUM'
  AUTO_SUSPEND = 600
  AUTO_RESUME = TRUE
  MIN_CLUSTER_COUNT = 1
  MAX_CLUSTER_COUNT = 3
  SCALING_POLICY = 'STANDARD';

-- Use it
USE WAREHOUSE my_reporting_wh;

-- Alter size or suspend
ALTER WAREHOUSE my_reporting_wh
  SET WAREHOUSE_SIZE = 'LARGE'
  AUTO_SUSPEND = 300;

-- Suspend and resume
ALTER WAREHOUSE my_reporting_wh SUSPEND;
ALTER WAREHOUSE my_reporting_wh RESUME;

-- Drop when done
DROP WAREHOUSE my_reporting_wh;
Example workflow
1) Create a test XSMALL warehouse with AUTO_SUSPEND set to a small value. 2) Run a simple query to start it. 3) Use SHOW WAREHOUSES to verify status. 4) Wait for suspension and verify SUSPENDED. 5) Run another query to observe automatic resume. This sequence shows how charges start and stop with activity.
Check
Suspending a warehouse stops compute charges but does not delete storage; always clean up test warehouses with DROP when finished.
