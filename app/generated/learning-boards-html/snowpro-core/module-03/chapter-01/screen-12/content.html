Terminal Demo Steps
  1. Create a test XSMALL warehouse with AUTO_SUSPEND = 120.
  2. USE WAREHOUSE and run SELECT CURRENT_TIMESTAMP(); to start it.
  3. SHOW WAREHOUSES LIKE 'my_test_wh'; check status is STARTED.
  4. Wait > 120 seconds and re-run SHOW WAREHOUSES to confirm SUSPENDED.
  5. Run another query to see AUTO_RESUME in action.
Caching Check & Cleanup
Run SELECT COUNT(*) FROM a table twice without updating the table; the second result should come from the result cache if the underlying data hasn't changed. When done, DROP the test warehouse to avoid ongoing charges.
Key Takeaway

Hands-on steps reveal billing and cache behavior — always test in a controlled environment and clean up test objects.
