Learning Objectives
Learn the skills to size, manage, and optimize virtual warehouses using SQL and monitoring.
Bloom: Learn → Understand → Apply → Master
Explain virtual warehouses
State why compute is separate from storage and how that enables elasticity and cost control. For example, a paused warehouse stops incurring compute credits while data remains in storage.
VERIFIED COMPETENCY MILESTONE
Identify sizes & scaling
Choose sizes from X-SMALL to 6X-LARGE and use multi-cluster settings to manage concurrency. Mnemonic: double size = doubling clusters.
VERIFIED COMPETENCY MILESTONE
Describe query lifecycle
Explain parsing, optimization, execution, and result caching and where optimization choices affect cost. Example: caching can skip execution for identical queries.
VERIFIED COMPETENCY MILESTONE
Manage warehouses with SQL
Use CREATE, ALTER, SUSPEND, RESUME, and DROP to control warehouses and costs. Practice with a small test warehouse first.
