Module 3 › Chapter 3.1 › What is a Virtual Warehouse?
Definition
A virtual warehouse is a configurable cluster of compute resources that executes queries while storage remains separate and shared.
Components
CPU, memory and temporary disk used during query execution.
Behavior
Start on demand, suspend when idle, and scale for concurrency.
Misconception
A warehouse is not a single server; sizes map to cluster counts and multi-cluster settings add clusters for concurrency.
Analogy & Example
Analogy: imagine storage as the warehouse building and virtual warehouses as rented forklifts you turn on only while you load or unload. Example: run a medium warehouse for a 30-minute ETL and suspend it afterwards so you don't pay when idle.
Example Card
Scenario: Daily report
A nightly report runs for 20 minutes. Use a MEDIUM warehouse with auto-suspend set to slightly above 20 minutes to avoid paying while idle.
Key Takeaway

Virtual warehouses are elastic compute pools; separate them from storage to scale independently and control costs.
