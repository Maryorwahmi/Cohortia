Module 3 › Chapter 3.1 › Auto-Suspend & Resume
How it works
Auto-suspend pauses a warehouse after inactivity; auto-resume restarts it on the next query. This stops compute billing while preserving stored data.
SQL Example
CREATE WAREHOUSE my_reporting_wh
  WITH WAREHOUSE_SIZE = 'MEDIUM'
  AUTO_SUSPEND = 600 -- suspend after 10 minutes
  AUTO_RESUME = TRUE;
Practical guidance
  • Set AUTO_SUSPEND to slightly exceed expected job duration.
  • For interactive users, favor shorter suspend times to avoid billed idle minutes.
  • Monitor suspend/resume frequency to find the cost/performance sweet spot.
Common mistake
Not setting AUTO_SUSPEND or using a very long interval leads to continuous billing even when no queries run.
