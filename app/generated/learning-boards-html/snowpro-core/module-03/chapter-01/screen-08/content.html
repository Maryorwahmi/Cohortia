Module 3 › Chapter 3.1 › Multi-Cluster & Policies
Configuration
Define MIN_CLUSTER_COUNT and MAX_CLUSTER_COUNT and choose SCALING_POLICY.
CREATE WAREHOUSE my_wh
  WITH WAREHOUSE_SIZE = 'SMALL'
  MIN_CLUSTER_COUNT = 1
  MAX_CLUSTER_COUNT = 3
  SCALING_POLICY = 'STANDARD';
When to use
  • Use multi-cluster for dashboards or BI users that run simultaneous queries.
  • Use STANDARD for responsive scaling, ECONOMY to avoid frequent cluster churn.
  • Monitor cluster start/stop frequency to tune minima and maxima.
Misconception
Multi-cluster improves concurrency; it doesn't reduce the runtime of a single compute-bound query.
