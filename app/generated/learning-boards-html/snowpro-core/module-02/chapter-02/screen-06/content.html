Module 2 › Chapter 2.2 › ON_ERROR Options
Behavior overview
ABORT_STATEMENT
Stops and rolls back on first error. Best for strict integrity.
CONTINUE
Skips bad rows/files and loads valid rows. Errors are logged in COPY_HISTORY.
SKIP_FILE_n / n%
Skip whole files after an error count or percentage threshold.
VALIDATION_MODE
Parse and report errors without loading. Use as a preflight test.
Scenario guide
If data quality is unknown, run VALIDATION_MODE first. If business needs require as-much-data-as-possible, use CONTINUE but monitor COPY_HISTORY closely.
Misconception
CONTINUE hides errors. It records them in COPY_HISTORY — always check the history after a CONTINUE run.
Key Takeaway
Pick the ON_ERROR policy that matches your tolerance for partial loads and use validation to test before committing.
