Module 2 › Chapter 2.2 › COPY_HISTORY
Query the history
SELECT *
FROM TABLE(
  INFORMATION_SCHEMA.COPY_HISTORY(
    TABLE_NAME => 'customers',
    START_TIME => DATEADD(hours, -1, CURRENT_TIMESTAMP())
  )
)
ORDER BY START_TIME DESC;
  • FIRST_ERROR_MESSAGE explains the first detected problem for a run.
  • ERROR_COUNT summarizes how many rows failed during the load.
  • Use the timing and file columns to correlate with staged file names and sizes.
Troubleshooting flow
  1. Run VALIDATION_MODE to preview errors without loading.
  2. Inspect COPY_HISTORY for FIRST_ERROR_MESSAGE and ERROR_COUNT.
  3. Adjust file format or transform with SELECT and re-run.
Key Takeaway
Always check COPY_HISTORY after a load to verify results and find root causes of failures.
