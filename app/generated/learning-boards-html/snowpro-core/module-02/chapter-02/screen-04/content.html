Module 2 › Chapter 2.2 › COPY INTO Basics
What it is
COPY INTO is Snowflake's high-throughput command for loading staged files into tables. It reads files in parallel and applies parsing rules you provide.
Example: minimal form
-- Minimal COPY INTO form
COPY INTO customers
FROM @my_customer_stage;
  • Target table must exist and have a compatible schema.
  • If you don't specify file format, defaults are applied and may not match your file.
  • Use an explicit column list when file column order and table order differ.
Concrete example
If your CSV has a header row or uses a non-comma delimiter, provide FILE_FORMAT to avoid mis-parsed columns. Otherwise columns may shift and casting will fail.
Key Takeaway

Start with the minimal form for matching files, and add file format options when structure differs.

Common mistake
Assuming column names will be matched automatically; COPY INTO maps by position unless you use a SELECT.
