Module 2 › Chapter 2.2 › Live-coding Walkthrough
Step sequence
  1. Create named file format matching your CSV.
  2. Run COPY INTO with ON_ERROR = 'ABORT_STATEMENT' and observe failure.
  3. Query COPY_HISTORY to read FIRST_ERROR_MESSAGE.
  4. Re-run with ON_ERROR = 'CONTINUE' and inspect loaded rows.
  5. Use SELECT in COPY INTO to cast and parse dates during load.
Checkpoints
After each run: query target table rows and COPY_HISTORY entries to confirm behavior and error details.
Key Takeaway
The ABORT then CONTINUE pattern helps you compare strict and tolerant behaviors while preserving evidence in COPY_HISTORY.
