Module 2 › Chapter 2.2 › Transformations with SELECT
Code example
-- Load and transform with SELECT
COPY INTO customers (customer_id, customer_name, registration_date)
FROM (
  SELECT $1::INT, $2::VARCHAR, TO_DATE($3, 'MM/DD/YYYY')
  FROM @my_customer_stage/customers_data.csv
)
FILE_FORMAT = (TYPE = 'CSV' FIELD_DELIMITER = ',' SKIP_HEADER = 1)
ON_ERROR = 'CONTINUE';
  • $1, $2, $3 reference positional columns from each staged file row.
  • Use casts to ensure values match target column types.
  • Apply parsing functions for dates and structured types.
Example scenario
Your source has MM/DD/YYYY dates; you parse them to DATE during COPY INTO so downstream queries can use date functions immediately.
Key Takeaway
SELECT inside COPY INTO is ideal for light, deterministic transformations; keep complex logic outside the load step.
Common mistake
Embedding heavy joins or multi-row logic in COPY INTO makes debugging and replay difficult.
