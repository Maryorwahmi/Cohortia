CSV with named file format
-- Using a named file format
COPY INTO sales
FROM @my_internal_data_stage/sales_data.csv
FILE_FORMAT = (FORMAT_NAME = 'my_csv_format')
ON_ERROR = 'CONTINUE';
Named formats keep COPY INTO statements concise and encourage consistent parsing behavior across jobs.
JSON with PARSE_JSON
-- Parsing JSON objects in staged files
COPY INTO orders (order_id, item_name, order_total)
FROM (
  SELECT
    PARSE_JSON($1):id::INT,
    PARSE_JSON($1):product::VARCHAR,
    PARSE_JSON($1):total::DECIMAL
  FROM @my_internal_data_stage/orders.json
)
FILE_FORMAT = (TYPE = 'JSON')
ON_ERROR = 'ABORT_STATEMENT';
JSON loads let each staged row be a self-contained object; use PARSE_JSON then extract fields with path expressions.
Key Takeaway
Choose the parsing approach that matches your file shape: table-like CSVs or object-like JSON records.
