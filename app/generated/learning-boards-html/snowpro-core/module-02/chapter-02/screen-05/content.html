Create a named file format
A named format stores parsing rules so COPY INTO statements remain concise and consistent.
CREATE OR REPLACE FILE FORMAT my_csv_format
  TYPE = 'CSV'
  FIELD_DELIMITER = ','
  SKIP_HEADER = 1
  NULL_IF = ('', 'NULL')
  ERROR_ON_COLUMN_COUNT_MISMATCH = FALSE;
  • TYPE picks the parser: CSV, JSON, or PARQUET.
  • FIELD_DELIMITER ensures correct column splits for non-standard separators.
  • NULL_IF maps particular strings to NULL values during load.
When to use which
Inline: quick one-off loads or experiments. Named: production workloads, team consistency, and easier maintenance.
Pro tip
Keep sensitive defaults out of named formats; store only parsing rules and not credentials or temporary flags.
Key Takeaway
Named file formats improve reliability and reduce duplication across COPY INTO statements.
