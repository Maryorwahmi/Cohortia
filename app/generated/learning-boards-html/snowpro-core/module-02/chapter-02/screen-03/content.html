Common pitfalls
  • Wrong delimiter or header skip leads to shifted columns and silent type errors.
  • Using ABORT_STATEMENT for noisy data causes full rollbacks; CONTINUE allows partial success.
  • Small files increase task startup overhead and reduce parallelism.
  • Applying heavy transformations in COPY INTO can obscure source data for debugging.
VERIFIED COMPETENCY
Run a load, inspect COPY_HISTORY, and explain one error.
This confirms you can both operate COPY INTO and interpret its diagnostics.
