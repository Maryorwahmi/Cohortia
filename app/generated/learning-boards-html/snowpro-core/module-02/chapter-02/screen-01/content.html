COPY INTO basics, file formats, errors, transforms, and performance

Use COPY INTO to ingest files from a stage into a table. You can declare parsing rules inline or reference a named file format for reuse. Control failure behavior with ON_ERROR and perform validation-only checks before loading. For small transformations, embed a SELECT to cast and reformat columns as you load.
