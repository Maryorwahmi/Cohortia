Sample question
You are loading a pipe-delimited CSV with a header row and want to load valid rows while reporting errors. Which settings do you choose and how do you verify?
Answer
Set FILE_FORMAT = (TYPE = 'CSV', FIELD_DELIMITER = '|', SKIP_HEADER = 1) and ON_ERROR = 'CONTINUE'. After the run, query COPY_HISTORY for FIRST_ERROR_MESSAGE and ERROR_COUNT to inspect failures and confirm valid rows were loaded.
Scoring guide
Award points for correct FILE_FORMAT keys, correct ON_ERROR choice, and demonstrating COPY_HISTORY verification.
Key Takeaway
Translate scenario needs into file format and ON_ERROR settings, then validate using COPY_HISTORY or VALIDATION_MODE.
