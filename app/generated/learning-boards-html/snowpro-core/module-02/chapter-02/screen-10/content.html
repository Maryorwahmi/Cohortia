Module 2 › Chapter 2.2 › Performance Tips
Guideline timeline
Small files
High overhead. Consolidate if you have many tiny files.
Ideal
10–100 MB compressed. Best balance for parallelism and task overhead.
Very large
May limit parallelism. Consider splitting for better concurrency.
  • Compress files when possible; Snowflake detects compression by extension.
  • Measure with COPY_HISTORY to see actual throughput gains from consolidation.
Performance checklist
  • Target 10–100 MB compressed per file.
  • Consolidate many tiny files; split huge ones.
  • Use COPY_HISTORY timing to verify improvements.
Key Takeaway
Optimize for parallel reads: aim for medium-sized compressed files and validate improvements with COPY_HISTORY.
