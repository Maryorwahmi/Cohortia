PUT: client-side uploads
Ensure the file path is correct and that you run PUT from the machine that has the file.
# macOS / Linux
PUT file:///Users/youruser/Desktop/sample_customers.csv @my_customer_stage;

# Windows
PUT file://C:/Users/youruser/Desktop/sample_customers.csv @my_customer_stage;
Note that PUT compresses files automatically, so you will often see sample_customers.csv.gz in the stage listing.
Common mistakes
  • Using an incorrect local path or relative path that doesn’t exist on the client.
  • Running PUT from a remote machine where the file is not present.
  • Forgetting to specify the target stage name after the file URI.
Pro tip
Test with a tiny CSV first. LIST the stage to confirm the compressed filename before attempting large uploads.
