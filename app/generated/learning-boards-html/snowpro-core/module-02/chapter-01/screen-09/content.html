LIST command
Use LIST to see files in a stage and confirm successful uploads and compression.
-- Example: list files in a stage
LIST @my_customer_stage;

-- Typical output will include sample_customers.csv.gz and file metadata
Check filename patterns, sizes, and timestamps. If a file is missing or unusually small, rerun the PUT and re-verify before COPY INTO.
Example flow
  1. PUT file to named stage.
  2. Run LIST to confirm compressed file appears.
  3. Optionally preview or COPY INTO a transient table to validate schema.
Key Takeaway
Always confirm with LIST after PUT; compression and metadata help you detect issues early.
