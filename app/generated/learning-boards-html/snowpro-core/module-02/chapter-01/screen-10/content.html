Module 2 › Chapter 2.1 › File Formats
CSV
Flat, tabular data. Easy to produce from spreadsheets.
Good for simple tables but loses type metadata. Configure delimiters and header options on COPY.
JSON
Semi-structured and nested data.
Preserves nested objects; useful for event or document-like payloads.
Parquet / ORC
Columnar, schema-aware formats for large datasets.
Efficient for analytics and preserves type information, often faster for large loads.
Practical selection steps
  1. Identify whether data is flat or nested.
  2. Prefer columnar formats for large analytic datasets.
  3. Test a sample file through COPY options to ensure parsing behaves as expected.
Key Takeaway

Match file format to data shape: CSV for simple tables, JSON for nested data, Parquet for large, typed datasets.
