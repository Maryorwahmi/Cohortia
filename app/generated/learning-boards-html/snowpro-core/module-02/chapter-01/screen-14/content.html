Module 2 › Chapter 2.1 › Mistakes & Tips
Common mistakes
  • Incorrect local file path or running PUT from the wrong client.
  • Missing USAGE or read privileges on internal stages.
  • Mismatch between file format and COPY settings.
Pro tips
  • Name stages clearly and add comments for discoverability.
  • Script stage creation so automation can rely on predictable objects.
  • LIST after PUT and COPY into a transient table to validate schema.
Quick checklist
1. File present on client. 2. Correct PUT URI. 3. LIST shows .gz file. 4. Validate schema. 5. COPY into production.
Reflective question
Which single check will you add to your pipeline to catch mistakes earlier: path verification, role testing, or transient-table validation?
