Module 2 › Chapter 2.1 › Staging Workflow
Recommended sequence
  1. Prepare DB, schema, and named stage.
  2. PUT local file to the stage from the client.
  3. LIST to verify compressed file exists.
  4. Validate file format or preview content.
  5. COPY INTO target table for production ingestion.
Why this matters
Verification before ingestion prevents bad data from reaching production and makes automation safer.
Concrete example
A nightly job uploads partner files to a named stage, runs LIST and a small validation COPY into a transient table, then schedules a final COPY INTO the production table once checks pass.
Common mistake
Skipping the validation step and running COPY immediately can cause schema mismatches or partial loads.
