CREATE OR REPLACE STAGE
Define a named internal stage and add a comment to document purpose.
-- Example: Creating an internal named stage
CREATE OR REPLACE STAGE my_internal_data_stage
  COMMENT = 'Stage for loading customer data';
Include this statement in deployment scripts so the stage exists for automated upload jobs.
Practical notes
  • Named stages are schema objects and follow RBAC rules for grants.
  • Use clear, descriptive names to help teams discover staging locations.
  • Comments serve as lightweight documentation for pipeline owners.
Key Takeaway

Create named stages for shared pipelines; include comments so the stage purpose is obvious.
