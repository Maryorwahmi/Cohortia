Module 2 › Chapter 2.1 › Activity: Upload CSV
Setup commands
CREATE DATABASE IF NOT EXISTS DATA_LOAD_DB;
USE DATABASE DATA_LOAD_DB;
CREATE SCHEMA IF NOT EXISTS STAGING_SCHEMA;
USE SCHEMA STAGING_SCHEMA;

CREATE OR REPLACE STAGE my_customer_stage
  COMMENT = 'Internal stage for customer data files.';
Run these in your SnowSQL or worksheet to prepare a disposable environment for practice.
Local file and PUT
Create a small CSV locally and upload it with PUT from the same machine.
# sample_customers.csv (create locally)
id,name,email
1,Alice,alice@example.com
2,Bob,bob@example.com
3,Charlie,charlie@example.com

# Example PUT (macOS/Linux)
PUT file:///Users/youruser/Desktop/sample_customers.csv @my_customer_stage;
After PUT, run LIST @my_customer_stage; to see sample_customers.csv.gz listed.
Reflection
How would you automate these steps in a CI job? Consider placing CREATE STAGE and PUT into deployment and upload scripts respectively, and using LIST as an upload verification step.
