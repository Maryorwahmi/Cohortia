Module 2 › Chapter 2.1 › Security & Permissions
Internal Stage Access
Controlled by Snowflake RBAC.
  • Grant USAGE on the stage to roles that need it.
  • Control who can read or write staged files through roles.
  • Test access by switching to a role and performing LIST or GET where appropriate.
External Stage Access
Requires cloud-side permissions and integrations.
  • Configure storage integrations or IAM roles so Snowflake can access the bucket.
  • Avoid broad permissions; limit access to specific buckets and prefixes.
  • Document the cloud role or credentials used by Snowflake to access the data.
Common pitfall
Granting wide cloud permissions can expose a larger set of data than intended. Use explicit roles and minimal scopes for external stages.
