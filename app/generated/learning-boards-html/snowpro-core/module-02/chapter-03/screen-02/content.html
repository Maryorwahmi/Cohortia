Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Execute COPY INTO for unloads
Run COPY INTO @stage FROM <table> or a SELECT to export data. This skill matters for sharing data with external systems or archiving results.
VERIFIED COMPETENCY MILESTONE
02
Configure file formats and sizing
Choose TYPE, HEADER, COMPRESSION, and MAX_FILE_SIZE to control file outputs. Proper settings enable parallel downstream processing and predictable storage use.
VERIFIED COMPETENCY MILESTONE
03
Understand micro-partitions
Recognize micro-partition metadata and size ranges and how pruning reduces scanned data. This reduces query cost and improves performance.
VERIFIED COMPETENCY MILESTONE
04
Manage Time Travel and Fail-safe
Apply appropriate retention to limit storage costs while keeping needed recoverability. Know the difference between Time Travel access and the non-configurable Fail-safe window.
VERIFIED COMPETENCY MILESTONE
