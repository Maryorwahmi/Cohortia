Module 3 › Chapter 2.3 › File Format Options
Common file formats
CSV
Good for relational consumers. Use HEADER = TRUE to include column names and FIELD_DELIMITER to control separators.
JSON
Self-describing, ideal for semi-structured consumers. Consider compression for size reduction.
Parquet
Columnar and compact; best when downstream analytics tools can read Parquet directly.
Options to tune
  • HEADER = TRUE adds column names to CSV exports.
  • COMPRESSION = 'GZIP' or 'SNAPPY' reduces size; 'AUTO' lets Snowflake pick.
  • MAX_FILE_SIZE expects a bytes value to split large results for parallel reads.
  • OVERWRITE = TRUE replaces files with the same prefix; use carefully in production.
Example
Export daily user events as Parquet with compression to minimize storage and speed analytical reads.
Key Takeaway

Format and compression choices should match the downstream tools and network constraints for best performance.
