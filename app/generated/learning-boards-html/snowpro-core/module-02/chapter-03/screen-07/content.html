Overwrite vs Preserve
When to use OVERWRITE = TRUE
Consistent snapshots where a single latest file is required by downstream systems.
When to avoid it
If you need historical exports or audit trails, do not overwrite and instead store run-specific files.
Naming pattern
Include a job identifier or timestamp in the prefix, for example: customers_export/2023-08-01/run_12345_. This avoids accidental deletion when not using overwrite.
Example scenario
Use OVERWRITE for a streaming ETL checkpoint file that consumers read continuously. Use non-overwrite archival exports for compliance logs.
Key Takeaway

Choose overwrite and naming strategy based on whether consumers expect stable paths or a historical archive.
