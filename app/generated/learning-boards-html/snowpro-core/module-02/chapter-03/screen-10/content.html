Module 3 › Chapter 2.3 › Time Travel & Fail-safe
Time Travel (configurable)
Time Travel retains historical micro-partitions for a configured number of days so you can query or restore earlier states. It consumes storage proportional to retained versions.
Transient tables
Use TRANSIENT tables for data that does not require Time Travel or Fail-safe, reducing storage overhead.
Fail-safe (non-configurable)
Fail-safe is a fixed seven-day period after Time Travel expires used by Snowflake for disaster recovery; it is not accessible for normal user queries.
Example commands
-- Set retention to 7 days
ALTER TABLE customers SET DATA_RETENTION_TIME_IN_DAYS = 7;

-- Create a transient table
CREATE OR REPLACE TRANSIENT TABLE temp_staging_data (
  col1 INT,
  col2 VARCHAR
);
Key Takeaway

Pick retention windows to match real recovery needs and use transient tables when historical recovery is not required to save cost.
