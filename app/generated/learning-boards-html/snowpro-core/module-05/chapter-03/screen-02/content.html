Module 05 › Chapter 5.3 › Learning Objectives
01
Explain database replication
Describe continuous, incremental copying of a primary database to secondary accounts and why this supports disaster recovery and read locality.
Mnemonic: two overlapping circles for source and replica with an arrow of updates.
VERIFIED COMPETENCY MILESTONE
02
Differentiate replication and failover groups
Explain that replication copies data, while failover groups manage the primary/secondary role for sets of related objects so applications can switch cleanly.
Mnemonic: a stack of objects with a switch icon for role control.
VERIFIED COMPETENCY MILESTONE
03
Configure a replica database
Use CREATE DATABASE ... AS REPLICA OF and grant appropriate usage and select privileges on the replica to enable read workloads.
Mnemonic: a database icon with a plus arrow.
VERIFIED COMPETENCY MILESTONE
04
Perform failover and failback
Create and replicate failover groups and use ALTER FAILOVER GROUP ... PRIMARY to promote a replica. Understand the short downtime and application connection changes required.
Mnemonic: two arrows swapping positions to show role change.
VERIFIED COMPETENCY MILESTONE
