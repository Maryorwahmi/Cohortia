Module 05 › Chapter 5.3 › Failover Group Replica
Command example
-- In a TARGET_ACCOUNT, as ACCOUNTADMIN
CREATE FAILOVER GROUP my_failover_group_replica AS REPLICA OF <source_account_name>.my_failover_group;
Before running this, ensure each database included in the group already exists as a replica in the target account and required grants exist so ownership and access will be valid after promotion.
Common mistake
Creating the failover group replica before its member databases are available or without verifying grants. This can prevent promotion or cause permission issues during failover.
Verification steps
  • Confirm replicas exist with SHOW REPLICATION DATABASES.
  • Check grants and ownership in target account.
  • Ensure allowed accounts are correct in the primary group's definition.
Key takeaway

Create the failover group replica only after verifying its member databases are replicated and privileges are set, so promotions succeed when needed.
