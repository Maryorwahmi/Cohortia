Module 05 › Chapter 5.3 › Key Concepts
Data Replication
Copying a primary database to secondary, read-only databases kept in sync.
Failover Group
Groups related objects so they fail over together and keep application consistency.
Primary Database
The original, writable database that serves as the source for replication.
Summary takeaway

Use replication to copy data and failover groups to promote replicas together. Monitor, test, and plan for replication lag to keep systems resilient.
