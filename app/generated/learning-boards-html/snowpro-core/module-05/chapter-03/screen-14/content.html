Module 05 › Chapter 5.3 › Mistakes & Checklist
Top mistakes
  • Not testing failover/failback in non-production.
  • Attempting writes to read-only replicas without promotion.
  • Missing privilege or ownership checks in target account.
  • Ignoring replication lag in RPO planning.
Monitoring checklist
  • SHOW REPLICATION DATABASES — check status.
  • Confirm latest rows with SELECT on the replica.
  • Verify grants and ownership in the target account.
  • Run smoke tests after promotion.
Runbook snippet
1) Check replication status. 2) Confirm data parity. 3) Execute ALTER FAILOVER GROUP ... PRIMARY. 4) Update application connections. 5) Run smoke tests and monitor.
Key takeaway

Combine monitoring, privilege checks, and regular drills. Rehearse your runbook so failover is predictable, tested, and safe.
