Learning Objectives

Build and verify governance controls using native Snowflake features and apply best practices for production use.

01
Implement masking policies
Create and apply masking logic to sensitive columns so different roles see appropriate representations. Verified competency milestone: apply a policy and observe masked values for a test role.
02
Configure row access policies
Define conditions that filter rows based on user or role attributes and mapping tables. Verified competency milestone: restrict a user to their region using a mapping table.
03
Use object tagging
Create tags and attach them to objects to support discovery, compliance reporting, and cost allocation. Verified competency milestone: tag a table column as PII.
04
Differentiate and apply best practices
Choose masking versus row policies correctly, avoid over-restrictive policies, and ensure efficient mapping queries. Verified competency milestone: explain when each feature is appropriate.
