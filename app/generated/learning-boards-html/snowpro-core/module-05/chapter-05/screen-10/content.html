Module 6 › Chapter 5.5 › Object Tagging
What tags give you

Classification, discovery, and consistent metadata for automation and cost allocation.

Use cases
  • Mark columns as PII for compliance scans.
  • Tag warehouses by project for cost attribution.
  • Expose tags to a data catalog for discovery.
Best practice
Standardize tag keys and allowed values, apply tags during deployment, and include tag checks in governance reviews.
Tagging examples
CREATE TAG project_tag COMMENT = 'Tag for project cost attribution';
CREATE TAG pii_classification COMMENT = 'Classifies columns as PII or not';

ALTER WAREHOUSE my_etl_wh SET TAG project_tag = 'ProjectX';
ALTER TABLE customer_data MODIFY COLUMN email SET TAG pii_classification = 'Sensitive';
Note
Tags are metadata only; combine them with policies and catalog tooling for automated governance workflows.
