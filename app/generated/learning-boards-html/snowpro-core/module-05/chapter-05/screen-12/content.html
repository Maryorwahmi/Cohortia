Module 6 › Chapter 5.5 › Operational Best Practices
Governance operations
  • Create a policy catalog documenting logic, owners, and test queries.
  • Standardize tag keys and adopt a controlled vocabulary for classification.
  • Apply policies and tags via CI/CD so objects are governed at creation.
Monitoring
Periodically query SNOWFLAKE.ACCOUNT_USAGE.TAG_REFERENCES and run role-switch test batches to detect regressions or incomplete tagging coverage.
Ownership
Assign clear owners for policies and mapping tables, require change reviews, and record rationale for policy logic to support audits.
Quick checklist
  • Policy catalog exists and is updated.
  • Tags applied via deployment pipeline.
  • Role-switch tests automated in staging.
