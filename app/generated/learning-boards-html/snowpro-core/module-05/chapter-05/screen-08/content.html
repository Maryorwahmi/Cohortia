Module 6 › Chapter 5.5 › Row Access Policy Code Walkthrough
Mapping table and policy

Create user_regions, insert mappings, then create and attach the row access policy to customer_info on region.

-- Create mapping table
CREATE TABLE user_regions (user_name VARCHAR, region VARCHAR);
INSERT INTO user_regions VALUES ('your_user', 'East');

-- Create row access policy
CREATE OR REPLACE ROW ACCESS POLICY region_filter_policy
AS (customer_region VARCHAR) RETURNS BOOLEAN ->
    CURRENT_ROLE() = 'SECURITY_OFFICER'
    OR EXISTS (
        SELECT 1 FROM user_regions WHERE user_name = CURRENT_USER() AND region = customer_region
    );

-- Attach to table
ALTER TABLE customer_info ADD ROW ACCESS POLICY region_filter_policy ON (region);
Validation
USE ROLE data_analyst; SELECT * FROM customer_info; should return only East rows. USE ROLE security_officer; SELECT * FROM customer_info; should return all rows.
Checklist
  • Is the mapping table populated and current?
  • Does the policy reference the correct column?
  • Does the applying role have APPLY ROW ACCESS POLICY and ownership?
