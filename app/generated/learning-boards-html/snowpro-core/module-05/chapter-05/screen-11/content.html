Module 6 › Chapter 5.5 › Hands-on Activity
Lab steps
  1. Create governance_db, schema, and customer_info table with ssn and region columns and insert sample rows.
  2. Create roles data_analyst and security_officer, grant usage and SELECT, and assign to your test user.
  3. Create the ssn_mask_policy and apply it to the ssn column; test with both roles.
  4. Create user_regions mapping and region_filter_policy; attach it to customer_info and test row visibility.
  5. Cleanup: remove policies, tables, roles, and database when finished.
Example creation snippet
CREATE DATABASE governance_db;
USE DATABASE governance_db;
CREATE SCHEMA public;

CREATE TABLE customer_info (
  customer_id INT,
  customer_name VARCHAR,
  email VARCHAR,
  phone_number VARCHAR,
  region VARCHAR,
  ssn VARCHAR
);

Safety
Run this lab in a sandbox account. Use test users and roles. Do not run cleanup commands until you have validated behavior and recorded results.
