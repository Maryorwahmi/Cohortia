Module 6 › Chapter 5.5 › Key Concepts
Dynamic Data Masking
Masks column values at query time based on role or session context without altering stored data.
Row Access Policy
Filters which rows a user can see, using role checks or mapping tables for multi-tenant isolation.
Object Tagging
Attach key-value metadata to objects for classification, discovery, and cost attribution.
Summary Takeaway

Use a layered approach: mask values for privacy, filter rows for access isolation, and tag objects to support governance and billing workflows.
