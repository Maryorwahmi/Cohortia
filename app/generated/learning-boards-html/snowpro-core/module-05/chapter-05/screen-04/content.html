Module 6 › Chapter 5.5 › Masking vs Row Access vs Tagging
Comparison

Use the rule: value-level sensitivity → masking. record-level access → row policy. classification/metadata → tags.

Dynamic Data Masking
  • Masks column values dynamically.
  • Same table, different outputs per role.
  • Good for PII like SSN or credit cards.
Row Access Policies
  • Filters which rows are returned.
  • Essential for multi-tenant isolation.
  • Depends on user/role or mapping tables.
Object Tagging
  • Key-value metadata on objects.
  • Used for discovery, compliance, and cost attribution.
  • Does not alter query results by itself.
Example
In a transactions table, mask credit card numbers for analysts while using a row policy to limit reps to their region's rows.
Key Takeaway
Pick the control matching the unit of protection: value vs record vs metadata.
Common Mistake

Avoid using masking to limit rows or tags to imply access control. Each feature serves a distinct purpose and mixing them without design leads to gaps.
