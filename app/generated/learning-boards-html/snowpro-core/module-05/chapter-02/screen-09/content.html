Definition › ACCOUNT_USAGE analysis
Key views
  • WAREHOUSE_METERING_HISTORY — credit consumption by warehouse and time.
  • QUERY_HISTORY — statements, durations, and resource usage per query.
  • STORAGE_USAGE — historical storage totals by database and table.
Combine metering history for totals and query history for root-cause analysis of expensive statements.
Sample query: daily warehouse credits
SELECT
  TO_DATE(START_TIME) AS usage_date,
  WAREHOUSE_NAME,
  SUM(CREDITS_USED) AS total_credits_used
FROM
  SNOWFLAKE.ACCOUNT_USAGE.WAREHOUSE_METERING_HISTORY
WHERE
  START_TIME >= DATEADD(month, -1, CURRENT_TIMESTAMP())
GROUP BY
  1, 2
ORDER BY
  1, 2;
Run this to produce a daily breakdown of credits by warehouse for the last month. Use the results to target monitors or investigate costly queries.
Key Takeaway

Account usage views are the source of truth for consumption analysis; use them to validate monitor settings and to find cost drivers.
