Hands-on Activity › Lab Walkthrough
Steps
  1. Create a small test warehouse as ACCOUNTADMIN.
  2. Create a daily resource monitor with triggers and a small quota.
  3. Assign the monitor to the test warehouse.
  4. Run a long-running query repeatedly to consume credits.
  5. Watch notifications and monitor state, then clean up test objects.
Safety: test suspend immediate only in a sandbox to understand the effect on running queries.
Starter commands
USE ROLE ACCOUNTADMIN;
CREATE WAREHOUSE TEST_RM_WH WITH WAREHOUSE_SIZE = 'XSMALL' AUTO_SUSPEND = 60 AUTO_RESUME = TRUE;

CREATE RESOURCE MONITOR my_daily_monitor
  WITH CREDIT_QUOTA = 5
  FREQUENCY = DAILY
  START_TIMESTAMP = 'IMMEDIATE'
  TRIGGERS
    ON 50 PERCENT DO NOTIFY EMAIL 'your_email@example.com'
    ON 75 PERCENT DO NOTIFY EMAIL 'your_email@example.com'
    ON 100 PERCENT DO SUSPEND;

ALTER WAREHOUSE TEST_RM_WH SET RESOURCE_MONITOR = my_daily_monitor;
Simulation tip

Run an aggregation over the sample TPCH data repeatedly to consume credits. Monitor email for NOTIFY and check SHOW RESOURCE MONITORS to observe effects.
