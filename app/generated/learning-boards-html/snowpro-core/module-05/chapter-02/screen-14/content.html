Module 5 › Chapter 5.2 › Key Concepts
Resource Monitor
An object that tracks and controls credit consumption with quotas and triggers.
Credits
Snowflake's billing unit for compute, storage, and cloud services.
CREDIT_QUOTA
Maximum credits allowed within the monitor's specified FREQUENCY.
Summary takeaway
Use monitors to convert usage visibility into enforceable rules, and use ACCOUNT_USAGE views to validate and tune those rules over time.
