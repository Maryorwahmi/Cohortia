Process Flow › Assigning monitors
Granularity trade-offs
  • Warehouse-level: Targeted quotas for dev, ETL, or reporting.
  • Account-level: Single budget across all warehouses for overall governance.
  • Combined: Use account monitor plus selective warehouse monitors for layered protection.
Communicate assignments to stakeholders and avoid overlapping quotas that block legitimate operations.
Example ALTER commands
ALTER RESOURCE MONITOR my_monitor SET WAREHOUSES = (DEV_WH, ETL_WH);

ALTER RESOURCE MONITOR my_monitor SET LEVEL = ACCOUNT;

SHOW RESOURCE MONITORS;
Use SHOW RESOURCE MONITORS to confirm assignments, current credits, and monitor state after applying changes.
Key Takeaway

Choose assignment granularity to balance protection and operational flexibility, and verify settings with SHOW commands.
