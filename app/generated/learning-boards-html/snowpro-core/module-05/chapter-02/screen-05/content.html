Process › Creating a Resource Monitor
Key properties explained
  • CREDIT_QUOTA: Maximum credits for the chosen FREQUENCY.
  • FREQUENCY: DAILY, WEEKLY, MONTHLY, YEARLY, or ALL_TIME.
  • START/END_TIMESTAMP: Optional bounds for active period.
  • TRIGGERS: Define actions at percentage thresholds.
Pro tip
Test monitor behavior in a non-production role before applying SUSPEND_IMMEDIATE in production.
Example SQL
CREATE RESOURCE MONITOR my_daily_monitor
    WITH CREDIT_QUOTA = 5
    FREQUENCY = DAILY
    START_TIMESTAMP = 'IMMEDIATE'
    TRIGGERS
        ON 50 PERCENT DO NOTIFY EMAIL 'your_email@example.com'
        ON 75 PERCENT DO NOTIFY EMAIL 'your_email@example.com'
        ON 100 PERCENT DO SUSPEND;
This example notifies at 50% and 75%, then suspends at 100%. Use SHOW RESOURCE MONITORS to confirm creation and to view CURRENT_CREDITS and STATE.
Key Takeaway

Define clear quotas and test triggers so monitors act as intended without unintended suspension of critical workloads.
