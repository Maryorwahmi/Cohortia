Module 5 › Chapter 5.1 › Learning Objectives
Inspect parameters
SHOW PARAMETERS IN ACCOUNT; and SHOW PARAMETERS IN SESSION;
Practice: run both commands and compare values. Look for defaults like STATEMENT_TIMEOUT_IN_SECONDS and DEFAULT_WAREHOUSE to understand inherited behavior.
Set session-level values
ALTER SESSION SET ...
Practice: change STATEMENT_TIMEOUT_IN_SECONDS for a temporary increase to allow longer ETL without changing account defaults.
Role safety
Principle of least privilege
Practice: avoid daily use of ACCOUNTADMIN. Create narrower admin roles for warehouse management or user administration.
Region selection
Data residency & latency
Practice: document where your users and primary data sources are to choose an appropriate region that meets compliance needs.
