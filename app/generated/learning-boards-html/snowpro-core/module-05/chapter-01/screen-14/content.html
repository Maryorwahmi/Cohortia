Module 5 › Chapter 5.1 › Key Concepts
Snowflake Account
An isolated environment provisioned in one cloud and region; identified by account identifier and region_id in the URL.
Organization
Top-level entity to manage multiple accounts, consolidate billing, and coordinate cross-account tasks while keeping accounts separate.
Parameter Hierarchy
Account defaults can be overridden by user parameters and temporarily by session parameters. Use the correct scope for changes.
Summary takeaway

Design accounts and Organizations with compliance, performance, and least-privilege administration in mind. Verify parameter changes with SHOW and choose the right scope before changing defaults.
