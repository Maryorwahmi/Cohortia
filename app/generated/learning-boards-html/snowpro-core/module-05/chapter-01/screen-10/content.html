Module 5 › Chapter 5.1 › Inspecting & Setting Parameters
Reference commands
-- View account parameters (requires monitoring/account privileges)
USE ROLE ACCOUNTADMIN;
SHOW PARAMETERS IN ACCOUNT;

-- View current session parameters
SHOW PARAMETERS IN SESSION;

-- Set a temporary session parameter (30 minutes)
ALTER SESSION SET STATEMENT_TIMEOUT_IN_SECONDS = 1800;

-- Reset session parameter to default
ALTER SESSION SET STATEMENT_TIMEOUT_IN_SECONDS = DEFAULT;
Key Takeaway

Use SHOW to inspect effective values and ALTER with the correct scope to change behavior. Session changes are temporary.

Walkthrough scenario
1) As ACCOUNTADMIN, run SHOW PARAMETERS IN ACCOUNT and note STATEMENT_TIMEOUT_IN_SECONDS. 2) Run SHOW PARAMETERS IN SESSION and compare the value. 3) ALTER SESSION SET STATEMENT_TIMEOUT_IN_SECONDS = 1800 and re-run SHOW PARAMETERS IN SESSION to verify the session now shows 1800.
Common mistake
Running ALTER ACCOUNT SET when you intended a temporary session change. Always confirm scope before running ALTER commands.
