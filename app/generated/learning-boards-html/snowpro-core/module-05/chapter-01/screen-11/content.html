Module 5 › Chapter 5.1 › Session Example
Step-by-step
-- Check account default
USE ROLE ACCOUNTADMIN;
SHOW PARAMETERS IN ACCOUNT;

-- Check current session value
SHOW PARAMETERS IN SESSION;

-- Temporarily increase session timeout to 30 minutes
ALTER SESSION SET STATEMENT_TIMEOUT_IN_SECONDS = 1800;

-- Verify session value
SHOW PARAMETERS LIKE 'STATEMENT_TIMEOUT_IN_SECONDS' IN SESSION;

-- Reset to default when done
ALTER SESSION SET STATEMENT_TIMEOUT_IN_SECONDS = DEFAULT;
SHOW PARAMETERS LIKE 'STATEMENT_TIMEOUT_IN_SECONDS' IN SESSION;
Key Takeaway

Session-level changes are ideal for temporary tuning. Always confirm changes with SHOW and reset when finished.

Concrete scenario
An analyst running a complex transform increases session timeout to allow long-running steps, then resets it after completion so other sessions retain safe defaults.
Common mistake
Forgetting to reset a session or relying on session changes for persistent needs. Use ALTER ACCOUNT SET for permanent change when appropriate.
