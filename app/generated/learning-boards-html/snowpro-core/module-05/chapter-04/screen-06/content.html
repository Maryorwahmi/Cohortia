Definition
CREATE EXTERNAL FUNCTION
Map a SQL callable function to your API endpoint and the API_INTEGRATION you created earlier.
-- As a role with CREATE EXTERNAL FUNCTION privilege
CREATE OR REPLACE EXTERNAL FUNCTION my_external_sentiment_analyzer(text VARCHAR)
  RETURNS VARCHAR
  API_INTEGRATION = my_api_integration
  AS 'https://abcdef123.execute-api.us-east-1.amazonaws.com/prod/my_function';
Call it like any UDF: SELECT my_external_sentiment_analyzer('I love this product');
Snowflake serializes the input and deserializes the response for SQL use.
Ensure the AS URL matches an allowed prefix in your integration.
Pro Tip

Start by calling the function on a single test row and inspect returned values and error messages before scaling to many rows.

Example Scenario
You have a product reviews table and want a sentiment label for each row. Define an External Function that calls an existing sentiment API. Test on a small sample to measure latency and accuracy, then consider batched enrichment outside queries if cost is high.
Common mistake
Treating external calls as zero-latency operations. They are network calls with potential failures; design queries and error handling accordingly.
Key Takeaway

An External Function is a SQL facade over an external endpoint. Verify integration prefixes and role permissions, and plan for latency and retries.
