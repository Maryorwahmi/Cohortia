Process Flow
Conceptual Setup Checklist
  1. Identify cloud account ID and gateway region.
  2. Prepare an IAM role for Snowflake to assume.
  3. Record API gateway URL prefixes for API_ALLOWED_PREFIXES.
  4. Create API INTEGRATION with provider, role ARN, and prefixes.
  5. Create EXTERNAL FUNCTION referencing the integration and endpoint.
  6. Run a single-row SELECT to test invocation and response.
Example SQL Templates
-- Conceptual: create integration and external function (placeholders must be replaced)
CREATE OR REPLACE API INTEGRATION my_sentiment_api_integration
  API_PROVIDER = AWS_API_GATEWAY
  API_AWS_ROLE_ARN = 'arn:aws:iam::123456789012:role/snowflake_api_role'
  ENABLED = TRUE
  API_ALLOWED_PREFIXES = ('https://abcdef123.execute-api.us-east-1.amazonaws.com/prod/sentiment');

CREATE OR REPLACE EXTERNAL FUNCTION get_sentiment(input_text VARCHAR)
  RETURNS VARCHAR
  API_INTEGRATION = my_sentiment_api_integration
  AS 'https://abcdef123.execute-api.us-east-1.amazonaws.com/prod/sentiment';
If you can't provision cloud resources in this lab, review the placeholders and test the SQL syntax locally. Ensure your team controls the IAM role and gateway configuration when deployed.
Common mistake

Assuming Snowflake will create or configure cloud resources. Snowflake only stores integration metadata; cloud setup is separate.
