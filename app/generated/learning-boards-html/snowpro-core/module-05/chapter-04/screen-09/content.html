CREATE OR REPLACE PROCEDURE process_customer_data(table_name VARCHAR)
RETURNS VARCHAR
LANGUAGE JAVASCRIPT
AS
$$
var sql_command = "SELECT COUNT(*) FROM " + TABLE_NAME;
var statement = snowflake.createStatement( {sqlText: sql_command} );
var result_set = statement.execute();
result_set.next();
var count = result_set.getColumnValue(1);

if (count > 0) {
    snowflake.execute({sqlText: "UPDATE " + TABLE_NAME + " SET name = UPPER(name)"});
    return "Processed " + count + " rows in " + TABLE_NAME + ". Names uppercased.";
} else {
    return "No data to process in " + TABLE_NAME + ".";
}
$$;

CALL process_customer_data('my_new_table');
Explanation
The procedure constructs and runs SQL, reads results, and conditionally executes further statements.
Use snowflake.createStatement to prepare a statement and execute to obtain a result set.
Avoid inefficient row-by-row loops; prefer single SQL UPDATE statements executed inside the procedure.
Security & performance notes
Validate input identifiers, consider EXECUTE AS settings for privileges, and keep data-heavy processing in set-based SQL for performance.
Key Takeaway

JavaScript procedures give procedural flexibility; use them to orchestrate SQL rather than to iterate large datasets inefficiently.
