Best Practices
Security Checklist
  • Verify API_ALLOWED_PREFIXES and role ARNs before testing.
  • Ensure the gateway enforces auth and input validation.
  • Use EXECUTE AS OWNER only after security review and logging.
  • Prefer binds and validate identifiers against whitelists.
Performance & Operational Guidance
Keep data-heavy work in SQL, avoid per-row JavaScript loops for large datasets.
Measure latency for External Functions and plan retries/timeouts.
Instrument and log procedure and external calls for audit and debugging.
Key Takeaway

Combine input validation, least privilege execution, and monitoring to safely use External Functions and Stored Procedures in production.
