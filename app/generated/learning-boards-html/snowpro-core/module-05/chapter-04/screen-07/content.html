Definition
Stored Procedures in Snowflake
Encapsulate multi-step DDL/DML and control flow inside Snowflake using SQL scripting or JavaScript.
Use SQL scripting for native SQL procedural tasks and DDL constructs.
Use JavaScript when you need variables, loops, or complex control flow and result handling.
Security: choose EXECUTE AS OWNER or CALLER depending on privilege needs; OWNER can grant elevated power.
Why it matters

Stored Procedures let you automate recurring tasks and encapsulate business logic close to the data, reducing extract-transform-load work.

Language choice snapshot
SQL Scripting: native, good for DDL/DML and simple loops.
JavaScript: richer control flow, statement objects, and result handling.
Common misconception
Procedures are not only for DBAs. They are a tool for automation, ETL orchestration, and encapsulating business rules within Snowflake.
Key Takeaway

Pick the language that fits the control flow needs: SQL scripting for native statements, JavaScript for procedural richness.
