Core Concept
External Function Architecture
Snowflake → API Integration → API Gateway → Serverless Function. Each piece enforces security and routing.
API Integration secures Snowflake's access and lists allowed prefixes.
API Gateway routes requests to your function and enforces network access.
Serverless executes custom logic and returns serialized results.
Key Takeaway

Use External Functions for specialized external compute, and measure latency and error handling before broad adoption.

Concrete example
Example: Call a sentiment endpoint for each review row to append a sentiment label during a reporting query. Use sampling to measure latency and error rates before running at scale.
Common mistake: mismatched API_ALLOWED_PREFIXES or wrong IAM role ARN causes authorization errors. Check these values first when troubleshooting.
