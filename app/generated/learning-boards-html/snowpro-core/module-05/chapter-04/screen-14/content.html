Module 5 › Chapter 5.4 › Key Concepts
External Function
A UDF whose implementation runs outside Snowflake, commonly in a serverless function.
API Integration
Snowflake object that authorizes calls by recording role ARNs and allowed prefixes.
API Gateway
Front door for the serverless function; routes requests and enforces access policies.
Summary takeaway
Align integration prefixes, role ARNs, and gateway configuration; validate with single-row tests and monitor for latency and authorization errors.
