Skills You'll Practice
Step-by-step tasks to build a safe, testable extension pattern for Snowflake.
Task Checklist
  • 1. Create test table and insert sample rows to validate logic.
  • 2. Write a JavaScript stored procedure that binds parameters and executes SQL.
  • 3. Conceptually define API INTEGRATION and EXTERNAL FUNCTION SQL with correct placeholders.
  • 4. Verify permissions and test edge cases for latency and authorization.
Verification Steps
Run calls, inspect rows affected, and confirm that misconfigured ARNs or prefix strings produce clear errors. Use small datasets for external calls to measure latency impact.
