Distractor types

  • Partially correct: Contains a true clause but fails another requirement.
  • Technically correct but not best: Valid feature that doesn't meet the prompt's priorities.
  • Outdated or platform-specific: Mentions deprecated features or features from other warehouses.
  • Absolute wording: "Always" or "never" often signal incorrectness.
Quick elimination workflow
1. Cross out impossible answers. 2. Flag partials for re-check. 3. Compare remaining options against every stem constraint. 4. Choose the option that satisfies all constraints.
Misconception
A more detailed answer is not necessarily correct; it must still meet the stem's requirements entirely.
