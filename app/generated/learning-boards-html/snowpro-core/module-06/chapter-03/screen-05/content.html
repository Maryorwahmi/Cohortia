Module 6 › Chapter 6.3 › Multiple-Choice Strategy

Five quick steps

  1. 1. Read for constraints: Spot keywords like "best," "most efficient," or time constraints.
  2. 2. Read all options: Compare before choosing.
  3. 3. Eliminate: Cross out clearly wrong answers to narrow choices.
  4. 4. Compare remaining: Look for subtle completeness vs partial correctness.
  5. 5. Confirm: Re-check the stem to ensure the chosen answer satisfies every constraint.
Misconception check: Don't pick a technically valid answer if the stem asks for the most appropriate solution — choose the best fit for the described constraints.
Worked example
Stem
"A data engineer needs continuous, low-latency JSON loading from an S3 bucket."
Options compared
COPY INTO with scheduled tasks is possible but requires scheduling; Snowpipe provides automated, low-latency ingestion and is therefore the best fit.
Key Takeaway

Use the checklist fast and consistently; it turns uncertainty into a focused comparison of constraints.
