Module 6 › Chapter 6.3 › Command Questions

Approach

  • Identify the command in the stem and the exact aspect being tested.
  • Recall the parameter purpose rather than the command's broad function.
  • Eliminate answers that are syntactically wrong or inconsistent with known behavior.
Practice tip
Make a short command-parameter flash set to rehearse common mappings before the exam.
Example cue
Stem
"Which COPY INTO parameter handles file format errors?"
This question asks for parameter-level recall. Avoid answers that describe overall command behavior but do not name a parameter purpose.
Key Takeaway

Be precise: command name narrows the topic, parameter wording decides the correct answer.
