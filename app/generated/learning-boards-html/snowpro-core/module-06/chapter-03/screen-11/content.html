Module 6 › Chapter 6.3 › Worked MCQ Example

Problem summary

Retrieve data dropped three hours ago from a table with a seven-day retention period.
The keyword to spot is historical retrieval within a retention window. That points directly to Time Travel.
Options analysis
Time Travel — correct (queries data as it existed before the drop within retention)
Fail-safe — related but not the primary, long-term recovery mechanism
Data Cloning — creates a copy at a point in time but not the direct retrieval feature here
Secure Data Sharing — for sharing data across accounts, not retrieval
Key Takeaway

Identify the operative keyword in the stem; map it to the feature whose role matches that keyword exactly.
