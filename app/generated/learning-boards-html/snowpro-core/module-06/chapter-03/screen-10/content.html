Module 6 › Chapter 6.3 › Worked Multi-Select Example
Stem summary
Grant access by job function; mask specific columns for roles; restrict connections to authorized IPs.
Evaluation method
Convert each option to a true/false check and mark only those that directly meet a listed requirement.
Options and verdicts
A. Role-Based Access Control — select (addresses job-function privileges)
B. Network Policies — select (restricts by IP)
C. Row Access Policies — do not select (row-level, not column masking)
D. Data Masking Policies — select (masks columns for roles)
E. Multi-Factor Authentication — do not select (improves login security but does not satisfy listed requirements)
Key Takeaway

Treat each option independently and select only those that directly answer the stem.
