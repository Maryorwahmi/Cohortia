Module 6 › Chapter 6.3 › Key Concepts
Question Analysis
Classify the prompt and extract constraints before evaluating options.
Answer Strategies
Use elimination for single-choice and independent true/false checks for multiple-selects.
Distractors
Partials, non-optimal valid answers, outdated options, and absolutes are common traps.
Summary

Use these three concepts as a quick mental checklist when reviewing every practice question.
