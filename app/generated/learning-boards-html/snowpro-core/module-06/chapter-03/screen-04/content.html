Module 6 › Chapter 6.3 › Question Types
Definition

Three question formats

  • Conceptual: tests purpose or definition. Example cue: "What is the purpose of..."
  • Command-based: tests syntax or parameters. Look for command names like COPY INTO or PUT.
  • Scenario-based: gives a real use case and asks for the best practical fit, e.g., continuous low-latency loading.
Analogy
Think of conceptual as a vocabulary quiz, command-based as spelling, scenario-based as choosing the right tool for a job.
Concrete examples
Conceptual example
"What is the purpose of the Cloud Services Layer?" — recall a definition, not a command.
Command example
"Which COPY INTO parameter handles file format errors?" — precise parameter knowledge matters.
Scenario example
"A data engineer needs continuous, low-latency JSON loading from S3. Which feature should they use?" — Snowpipe is the best fit.
Key Takeaway

Start by classifying the question. The correct analysis method follows directly from that classification.
