Module 6 › Chapter 6.3 › Multiple-Select Evaluation

Step-by-step method

  • 1. Read the stem: Confirm the instruction says select all that apply.
  • 2. Convert each option: Ask "Is this statement true for this prompt?"
  • 3. Mark independently: Don't stop after some correct finds; check all options.
  • 4. Reject partials: If an option mixes true and false clauses, do not select it.
  • 5. Ignore unrelated true facts: Only select options that directly answer the stem.
Worked multiple-select example
Stem
Implement access control that grants access by job function, masks specific columns for some roles, and restricts connections to authorized IP addresses. Select all that apply.
RBAC — true (grants access by job function)
Network Policies — true (restricts by IP)
Row Access Policies — false for this stem (row-level restrictions are not requested)
Data Masking Policies — true (masks columns for roles)
MFA — false for this stem (improves login security but does not address the listed requirements)
Key Takeaway

Evaluate each option independently; select all and only those that directly satisfy the stem.
