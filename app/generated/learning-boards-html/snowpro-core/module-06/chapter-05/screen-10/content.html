Module 6 › Chapter 6.5 › Cost Optimization
Core Practices
  • Set AUTO_SUSPEND and AUTO_RESUME to remove idle costs.
  • Use resource monitors to alert and control credit usage.
  • Right-size warehouses per workload and time-of-day.
  • Use zero-copy clones for testing to avoid extra storage charges.
Scenario

A nightly ETL runs on a MEDIUM warehouse. If it completes in 30 minutes, consider a larger warehouse to shorten runtime only if it reduces overall credits consumed.

Monitoring Example (SQL)
-- Top warehouses by credits used last 7 days
SELECT warehouse_name, sum(credits_used) AS credits
FROM snowflake.account_usage.warehouse_metering_history
WHERE start_time > dateadd(day, -7, current_timestamp())
GROUP BY 1 ORDER BY 2 DESC LIMIT 10;
Common Mistake
Using large warehouses to hide inefficient queries. Instead, optimize queries or materialize results where appropriate.
Quick Audit
  1. List top 5 warehouses by credits.
  2. Confirm purpose and owner for each.
  3. Adjust AUTO_SUSPEND and apply monitors if needed.
