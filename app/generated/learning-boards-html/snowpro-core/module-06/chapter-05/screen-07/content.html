Definition & components

Masking, Row Policies, Tags, and History

Combine dynamic masking for sensitive fields, row access for conditional visibility, object tags for metadata governance, and access history for auditing to achieve enterprise-grade control.

Masking Policy: show partial values based on role.
Row Access Policy: filter rows by role or attribute.
Object Tagging: label resources for lifecycle and ownership.
Access History: record who accessed what and when.
Concrete scenario
Apply a masking policy to emails so analysts see masked values, and a row policy to ensure regional managers only query their assigned region. Verify with audit logs.
Common Pitfall
Assuming role changes take effect immediately for all sessions; test policies under representative roles and document needed role switches or session behavior.
Key Takeaway

Well-designed governance enables safe sharing and reduces business risk while preserving productivity.
