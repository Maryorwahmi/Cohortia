Module 6 › Chapter 6.5 › Snowpark
Definition

Write and run code inside Snowflake

Snowpark lets you author data pipelines and ML preprocessing in familiar languages that run on Snowflake compute, avoiding data egress and separate infrastructure.

Use case: model training and UDFs that access large datasets without exporting them.
Best practice: prototype on small data, then run representative benchmarks.
Governance: runs with executing role—apply least privilege.
Architectural note
Snowpark client code submits processing to Snowflake compute. Data stays in Snowflake storage and micro-partitioning benefits are preserved. This reduces movement, simplifies pipelines, and centralizes governance.
Concrete example
A data engineer converts a multi-stage ETL script into a Snowpark transformation. The new flow runs inside Snowflake, lowering data transfer time and simplifying scheduling because the same platform manages storage and compute.
Key Takeaway

Snowpark brings programmatic power to Snowflake and is ideal where data gravity makes moving data impractical.
