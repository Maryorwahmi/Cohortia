Module 6 › Chapter 6.4 › Vendor System Checks
Definition

What the proctoring check verifies

A pre‑exam automated and manual process that confirms your device and network meet vendor requirements.

Hardware and peripherals
Ensures webcam and mic function for identity checks and live monitoring.
Software and browser
Checks browser compatibility, required plugins, and stops conflicting apps.
Network stability
Measures connection speed and reliability to reduce mid‑exam disconnects.
Key Takeaway

Treat the vendor system check as the first and most important step in exam readiness.

Concrete example

If the system check reports the browser is unsupported, update to the recommended browser and re‑run the check. If webcam access is denied, enable camera permissions in system settings.

Misconception
Assuming your personal settings are fine; many modern OS privacy settings block camera access until explicitly allowed.
Practice tip
Run the check, apply fixes, restart, and run it again to confirm persistent readiness.
