How you will demonstrate each objective

Concrete steps to verify readiness before exam day.

Verified competency milestones
Technical Check

Complete the vendor's system check successfully. Milestone: webcam and mic verified with green status.

Time Management

Run a timed mini‑quiz at ~1.5–2 minutes per question and track flagged items. Milestone: finish first pass with time to review.

Interface Skills

Practice flagging and navigation. Milestone: move between items without losing position or time.

Stress Control

Rehearse a 60‑second reset routine. Milestone: measurable reduction in rushed answers during a practice run.
