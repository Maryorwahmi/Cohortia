Process

Pacing: first pass, flag, and review

A simple structured approach protects time and reduces decision fatigue.

First pass
Answer confidently known items quickly; make educated guesses if unsure and flag for review.
Second pass
Revisit flagged items with the broader context of the entire exam.
Third pass
If time allows, quickly verify answers; change only when you have strong reason.
Key Takeaway

A disciplined pacing plan ensures you see every question and reserve time for review.

Concrete example

For 60 questions and 115 minutes, aim for ~1.5–2 minutes per question on first pass, then use the second pass to focus on flags.

Practice step

Time a 5‑question mini‑quiz at 8 minutes and force the rule: move on if a question exceeds two minutes on first pass.
