Domain Deep Dive
Security
RBAC, network policies, MFA, data masking and row/column security practices.
RBAC essentials
Users get roles; roles get grants on objects. Use ownership sparingly and delegate privileges using roles.
Network & MFA
Network policies restrict allowed IPs; MFA adds a second verification step for users.
Data protection policies
Masking policies and row access policies control visibility; column-level controls restrict sensitive fields to approved roles.
Practice structure
Design a minimal RBAC hierarchy: admin, data_engineer, analyst. For each role list the least privileges needed to perform tasks and one protection policy for sensitive columns.
Key Takeaway

Apply least privilege through RBAC, and use network and data protection policies to secure accounts and data access.
