Domain Deep Dive
Semi-Structured Data
VARIANT, dot/bracket notation, FLATTEN, and query patterns for JSON/Avro/XML.
VARIANT type
Flexible column type for storing JSON-like semi-structured values.
Access patterns
Use dot or bracket notation to navigate nested fields and extract values for processing.
FLATTEN
Converts nested arrays into separate rows so you can aggregate or join nested elements like relational data.
Practice task
Take one nested JSON object with an events array. Describe how you would extract event timestamps, flatten the array, and count events by type. Write the step list and test it against sample data.
Key Takeaway

Treat semi-structured data as a sequence: store in VARIANT, navigate with notation, and FLATTEN arrays for relational analysis.
