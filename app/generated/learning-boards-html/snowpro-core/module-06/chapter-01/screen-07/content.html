Storage and Protection
Time Travel, Fail-safe, cloning, encryption, and staging behavior.
Time Travel
Query or restore historical data within a configured retention period for operational recovery.
Fail-safe
A custodial recovery period for service-level recovery beyond Time Travel; used as a last resort.
Zero-copy cloning
Creates logical clones using metadata pointers to avoid immediate data duplication for tests and dev flows.
Stages & Formats
Understand internal/external stages and supported file formats for ingestion and egress.
Concrete Practice
Write one short scenario: update a row, restore it with Time Travel, then explain when Fail-safe would be required. Use that scenario to test your conceptual understanding.
Key Takeaway
Time Travel is for operational rollback; Fail-safe is a final recovery mechanism. Cloning is logical, not immediate physical copying.
