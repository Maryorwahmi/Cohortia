Domain Deep Dive
Snowflake Architecture
Understand micro-partitions, virtual warehouses, and the cloud services layer.
Storage layer
Micro-partitions store columnar data in immutable segments. They enable data pruning and efficient scans.
Compute layer
Virtual warehouses provide isolated compute resources for queries. Size affects concurrency, throughput, and cost.
Cloud services
Manages metadata, security, query compilation, and optimization independent of storage and compute.
Interactive Explanation
Query flow example
Cloud services compile and optimize; compute executes the plan; storage supplies micro-partitioned data. This separation enables independent scaling.
Common misconception
Compute does not store data. Warehouses compute; storage retains data persistently.
Practice task

Key Takeaway

Knowing the responsibilities of each layer helps you answer performance and scaling questions on the exam.
