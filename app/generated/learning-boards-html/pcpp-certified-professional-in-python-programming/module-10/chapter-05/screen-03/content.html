Module 10 › Chapter 10.5 › Learning Objectives
01
Async debugging
Understand task switching and await points to trace flow.
Practice adding targeted logs and using the debugger while mindful of context switches that change behavior.
Verified Competency Milestone
02
Multi-threaded debugging
Detect race conditions and deadlocks using logs and thread-aware tools.
Learn strategies to reproduce races and capture thread timelines without altering timing inadvertently.
Verified Competency Milestone
03
Systematic debugging
Form hypotheses and design experiments to test causes efficiently.
Use targeted breakpoints and narrow log statements as experiments instead of blind edits.
Verified Competency Milestone
04
Avoid common pitfalls
Recognize when a debugging action can mask a bug, such as pausing threads in a race.
Learn safer alternatives like deterministic logs and controlled experiments to reproduce timing-sensitive issues.
Verified Competency Milestone
