Module 10 › Chapter 10.5 › Multi-threaded debugging
Logging pattern
Log at lock acquisition and release with thread id and a short context string. This produces a timeline you can analyze to find interleavings that lead to inconsistent state.
Avoid
Do not rely on breakpoints to find races because pausing changes timing and may prevent the issue from appearing.
Deadlock diagnosis
Capture stack traces of all threads when the program is stuck to see which locks each thread holds and waits on. This helps identify cycles that cause deadlock.
