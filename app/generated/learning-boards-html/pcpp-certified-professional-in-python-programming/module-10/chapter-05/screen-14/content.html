Module 10 › Chapter 10.5 › Common pitfalls & best practices
Pitfalls
  • Leaving print statements in production.
  • Using breakpoints to debug timing-sensitive concurrency bugs.
  • Opening unsecured remote debug ports.
Best practices
  • Use logging with levels and handlers for production diagnostics.
  • Write minimal tests that reproduce bugs and prevent regressions.
  • Follow a hypothesis-driven experiment cycle for diagnosis.
