Module 10 › Chapter 10.5 › Configuring handlers and levels
Example configuration
import logging
handler = logging.FileHandler('app.log')
handler.setLevel(logging.WARNING)
formatter = logging.Formatter('%(asctime)s %(name)s %(levelname)s: %(message)s')
handler.setFormatter(formatter)
root = logging.getLogger()
root.setLevel(logging.WARNING)
root.addHandler(handler)
This captures warnings and errors to a file while leaving development console printing under a separate handler.
Operational tips
  • Use rotating file handlers for long-running services to avoid unbounded logs.
  • Parameterize log messages to avoid eager formatting overhead.
  • Temporarily increase level remotely to capture extra detail instead of deploying code changes.
