Assessment idea

Demonstrate TDD proficiency

  1. Write a failing test for subtract(5,2) and show the failing output.
  2. Implement minimal code to pass the test and show the passing output.
  3. Add at least one edge-case test and perform a refactor while keeping tests green.
Deliverable: test files and implementation files.
Evidence: test run logs showing transition from failing to passing.
Quality: tests are independent, readable, and focused on behavior.
