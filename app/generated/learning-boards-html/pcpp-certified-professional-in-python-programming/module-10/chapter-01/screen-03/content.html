Skill set

What you'll practice

Write unit tests

Create focused tests for individual functions, assert expected outputs, and run them frequently.

Design integration checks

Verify component interactions, and learn mocking patterns to isolate external services.

Execute E2E flows

Confirm full user journeys including systems and UI where necessary.

Perform TDD

Follow Red-Green-Refactor to drive design and maintain a fast feedback loop.

Visual mnemonic
Unit = small, fast, isolated
Integration = connections between modules
E2E = full scenario, slower but holistic
