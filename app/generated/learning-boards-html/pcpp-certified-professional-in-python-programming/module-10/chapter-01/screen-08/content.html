Module 10 › Chapter 10.1 › add() TDD Example
Test (RED)
# test_adder.py
import unittest

class TestAdder(unittest.TestCase):
    def test_add_two_positive_numbers(self):
        result = add(2, 3)
        self.assertEqual(result, 5)

    def test_add_zero_and_positive(self):
        result = add(0, 7)
        self.assertEqual(result, 7)

if __name__ == '__main__':
    unittest.main()
Run the test now; it should fail because add is undefined. That confirms the test detects missing behavior.
Implementation (GREEN)
# adder.py
def add(a, b):
    # Minimal implementation to satisfy the tests
    return a + b
After adding this file, run the test suite. Both tests should pass. Then consider what edge cases to test next.
Key Takeaway

TDD encourages writing the test that expresses desired behavior before any implementation detail is decided.
