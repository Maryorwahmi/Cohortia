Definition

Tests as design constraints

A test-first habit clarifies interfaces and encourages smaller, single-purpose functions. Tests reveal where dependencies should be injected and where mocks are appropriate, improving modularity.

Tests encourage small functions with well-defined inputs and outputs.
They highlight seams for dependency injection and easier mocking in integration tests.
Check your understanding

If a test asserts only internal state instead of outward behavior, it will break during refactors even when behavior is unchanged. Favor external behavior checks.
