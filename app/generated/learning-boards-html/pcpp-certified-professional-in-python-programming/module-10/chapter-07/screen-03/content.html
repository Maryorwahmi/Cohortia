Practice Objectives

Small, verifiable tasks to confirm you can apply mocking and patching.

Mock an API client

Configure a Mock response.json and assert requests.get was called with the expected URL and params.

Patch builtins.open

Use new_callable=Mock and configure __enter__ to return a file-like mock that has read().

Patch where it's looked up

If module A imports from B, patch A.name so the code under test resolves the mock correctly.

Scoped mocks

Use decorators or context managers so mocks are reset automatically between tests to avoid pollution.
