Example

Patching builtins.open

Use new_callable=Mock so patch returns an object that supports context manager methods; configure __enter__ to return a mock file with read().

from unittest.mock import patch, Mock

# Test for read_config_file
with patch('os.path.exists', return_value=True), \
     patch('builtins.open', new_callable=Mock) as mock_open:
    mock_file = Mock()
    mock_file.read.return_value = 'key=value
'
    mock_open.return_value.__enter__.return_value = mock_file

    content = read_config_file('config.ini')
    assert content == 'key=value
'
    mock_open.assert_called_once_with('config.ini', 'r')
    mock_file.read.assert_called_once()
Why new_callable

new_callable=Mock ensures the patched open exposes magic methods like __enter__ so the with statement works with the mock.

Watch out

If your module aliases or imports open explicitly, patch that module's reference instead of builtins.open.
