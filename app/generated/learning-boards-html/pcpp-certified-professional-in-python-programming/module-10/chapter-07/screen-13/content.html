Simulate an HTTP error

Set raise_for_status.side_effect to a requests.exceptions.HTTPError and assert your service returns None or handles the error as expected.

# Example test snippet
from requests.exceptions import HTTPError

mock_response = Mock()
mock_response.raise_for_status.side_effect = HTTPError('404')
mock_requests.get.return_value = mock_response

service = WeatherService(api_key='dummy')
result = service.get_current_temperature('London')
assert result is None
# Ensure json() was not called because raise_for_status raised
Checks
  1. raise_for_status.side_effect is set
  2. Service returns expected fallback
  3. response.json not called after error
Common error

Setting side_effect on the wrong object or not assigning mock_requests.get.return_value to mock_response will make the test ineffective.
