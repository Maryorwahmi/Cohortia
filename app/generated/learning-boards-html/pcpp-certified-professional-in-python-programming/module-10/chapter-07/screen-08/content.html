Comparison

patch: decorator vs context manager

Decorators provide test-wide patches and automatic cleanup. Context managers limit the patch to a block and improve readability for localized behavior.

Decorator
Use when the entire test relies on the patched object and you want a compact declaration.
Context manager
Use for precise scoping when only part of the test interacts with the dependency.
Examples
# Decorator style
@patch('my_service.requests')
def test_fetch(mock_requests):
    # whole test uses mock_requests
    ...

# Context-manager style
def test_read_config():
    with patch('os.path.exists', return_value=True), \
         patch('builtins.open', new_callable=Mock) as mock_open:
        # only this block uses patched open
        ...
Key Takeaway

Match patch style to scope: prefer narrow, readable patches unless the whole test legitimately needs the replacement.
