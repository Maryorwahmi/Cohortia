Definition

Verifying calls and interactions

Use mock assertions to check your code called dependencies correctly, and to ensure expected side effects occurred.

Common assertions
assert_called_once_with, assert_not_called, call_args_list and call_count are your primary tools.
Focus
Assert the observable contract: the correct request, the correct file write content, or the right sequence of external calls.
Example
# After calling function_under_test(...)
mock_requests.get.assert_called_once_with(
  "http://api.weatherapi.com/v1/current.json",
  params={"key": "dummy_key", "q": "London"}
)

# Inspecting call history
print(mock_logger.call_args_list)
# Use to verify sequence of messages or calls
Mistake

Asserting every internal call over-specifies behavior and makes tests fragile. Keep assertions at the contract level.
