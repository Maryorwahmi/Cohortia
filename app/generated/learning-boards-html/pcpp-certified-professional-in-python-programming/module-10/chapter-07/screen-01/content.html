Mocking and Patching

Learn to isolate units by replacing external calls with controlled mocks, and patch exactly where code resolves names.

In this lesson

Why isolation matters; Mock vs MagicMock; patch decorator and context manager; patch target rule; file and network examples.

Coming up

Hands-on WeatherService test, a file I/O patch example, and common pitfalls to avoid when mocking.

Why it matters

Well-designed mocks make unit tests fast, deterministic, and focused on the logic you care about, not external systems.
