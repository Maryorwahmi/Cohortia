Learning Objectives

Skills to verify by the end of this chapter

Bloom: Learn → Understand → Apply → Master
01
Explain why isolation matters

Describe how external systems cause flakiness and slow tests, and how mocks remove those variables so logic can be verified quickly.

VERIFIED COMPETENCY MILESTONE
02
Use Mock and MagicMock

Configure return_value and side_effect, and use MagicMock when magic methods or context manager behavior is required.

VERIFIED COMPETENCY MILESTONE
03
Apply patch patterns

Use patch as a decorator for entire tests or as a context manager for fine-grained replacement; patch builtins for open and module names for requests.

VERIFIED COMPETENCY MILESTONE
04
Avoid common mistakes

Recognize over-mocking, incorrect patch targets, and stale mocks between tests, and learn patterns to keep tests maintainable.

VERIFIED COMPETENCY MILESTONE
