Module 10 › Chapter 10.6 › TDD in Workflow
Local to CI
  • Run Red-Green-Refactor locally and aim for green commits.
  • Use CI to run the full suite on pull requests to catch regressions early.
  • Keep unit tests fast; separate slower integration tests where necessary.
Team practice
Require passing tests in CI before merging and document testing conventions to keep the workflow consistent.
Practical tips
  1. Configure pytest discovery and markers for fast vs slow tests.
  2. Use fixtures to share setup without coupling tests.
  3. Run a short pre-commit test suite to catch basic issues before pushing.
Consistent habits embed TDD into daily work and make refactors predictable and low-risk for the team.
