Module 10 › Chapter 10.6 › Red Phase
Write a failing test
Create a minimal pytest or unittest case that asserts the behavior you want, then run the test to see it fail.
Common Red failures
  • ModuleNotFoundError when the module isn't created yet.
  • AttributeError when a class or method is missing.
  • AssertionError when the output doesn't match the expected value.
Common mistake
Writing tests that already pass or that couple to internal implementation prevents the Red phase from providing useful guidance.
Example test (Red)
# test_calculator.py
import pytest
from calculator import Calculator

def test_add_two_numbers():
    calc = Calculator()
    assert calc.add(2, 3) == 5
Run pytest now. Expect it to fail with ModuleNotFoundError or AttributeError. That failing output confirms your test is correctly targeted.
Key Takeaway

The Red phase validates your test as a specification; a useful Red test fails for the expected reason.
