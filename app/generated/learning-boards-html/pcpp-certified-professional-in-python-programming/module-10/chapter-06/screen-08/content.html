Module 10 › Chapter 10.6 › unittest vs pytest
unittest (built-in)
  • Part of the standard library; class-based tests and setup methods.
  • Predictable structure suitable for strict environments.
  • More boilerplate compared to pytest for common patterns.
pytest (recommended for TDD)
  • Function-based tests with plain assert statements.
  • Powerful fixtures for reusable setup and isolation.
  • Concise syntax speeds up test-driven iterations.
Example pytest snippet
import pytest
from calculator import Calculator

def test_add_two_numbers():
    calc = Calculator()
    assert calc.add(2, 3) == 5
Pytest's plain assert produces readable failure messages that help you diagnose why Red tests fail, which accelerates the TDD loop.
