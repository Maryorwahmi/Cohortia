Test discovery and naming
pytest finds tests in files named test_*.py or *_test.py and in functions or methods starting with test_. Name tests accordingly to ensure automatic discovery.
VERIFIED COMPETENCY MILESTONE
pytest.raises and markers
Use pytest.raises to assert exceptions and @pytest.mark.NAME to label tests for selective runs. Markers let you run slow tests separately with pytest -m slow.
VERIFIED COMPETENCY MILESTONE
Fixture scope and isolation
Choose function, class, module, or session scope carefully. Function scope gives isolation; session scope shares state across many tests.
VERIFIED COMPETENCY MILESTONE
Migration tips
Prefer plain functions and fixture injection over TestCase classes for cleaner, idiomatic pytest tests.
