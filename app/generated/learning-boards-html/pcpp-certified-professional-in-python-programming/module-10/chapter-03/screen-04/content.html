Module 10 › Chapter 10.3 › pytest vs unittest
unittest
Class-based, explicit setup
Uses TestCase, setUp/tearDown methods, and assertion methods like assertEqual. Good for some structured cases, but adds ceremony for small tests.
Example pattern
import unittest

class TestAccount(unittest.TestCase):
  def setUp(self):
    self.account = BankAccount(100)

  def test_deposit(self):
    self.account.deposit(50)
    self.assertEqual(self.account.balance, 150)
pytest
Function-based, lightweight asserts
Write tests as simple functions, use plain assert, and define fixtures as reusable setup. Less boilerplate and clearer failures.
Equivalent example
def test_deposit():
  account = BankAccount(100)
  account.deposit(50)
  assert account.balance == 150
