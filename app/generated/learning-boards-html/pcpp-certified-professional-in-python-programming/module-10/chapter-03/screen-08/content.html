Module 10 › Chapter 10.3 › Fixture scopes and isolation
Fixture scope comparison
function
Runs per test. Best isolation.
class
Runs once per test class.
module
Runs once per module. Faster when safe.
session
Runs once per test run. Use for costly global resources.
Practical checklist
  • If tests mutate fixture state, prefer function scope for isolation.
  • For expensive, read-only resources, consider module or session scope.
  • When optimizing, measure test runtime and change scope intentionally with clear teardown.
