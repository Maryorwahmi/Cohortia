Test using plain assert
import pytest
from account import BankAccount

def test_deposit():
    account = BankAccount(100)
    account.deposit(50)
    assert account.balance == 150
If this assertion fails, pytest shows the left and right values so you can see the actual balance immediately.
Why this helps
  • Less framework code: write standard Python instead of assertion method calls.
  • Readable failures: pytest expands the expression to show intermediate values.
  • Faster debugging loop: see concrete mismatches immediately and fix the implementation or test.
Common mistake
Using assert with side effects inside complex expressions can make failures harder to interpret. Keep assertions focused and explicit.
