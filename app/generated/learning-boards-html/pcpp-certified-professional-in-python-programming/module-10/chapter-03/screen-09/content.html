Module 10 › Chapter 10.3 › pytest.raises
Example: withdraw error
import pytest
from account import BankAccount

def test_withdraw_insufficient_funds_raises_error():
    account = BankAccount(50)
    with pytest.raises(ValueError):
        account.withdraw(100)
This makes it clear that withdraw is expected to raise a ValueError for insufficient funds.
Advanced: inspect message
def test_error_message():
    account = BankAccount(0)
    with pytest.raises(ValueError) as excinfo:
        account.withdraw(10)
    assert "Insufficient funds" in str(excinfo.value)
Tip: capture the exception to assert on its message or attributes when needed.
