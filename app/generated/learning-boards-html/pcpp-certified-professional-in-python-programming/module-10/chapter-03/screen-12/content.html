Module 10 › Chapter 10.3 › Running pytest
Common commands
pytest
pytest -k "deposit"
pytest -m slow
pytest -q / -vv
When a test assertion fails, inspect the printed values and the stack trace to find the root cause. Use -s to see print statements and increase verbosity for more detail.
Example output
FAILED test_account_pytest.py::test_deposit - assert 149 == 150
E    assert 149 == 150
The output shows the evaluated values so you can quickly see the mismatch.
