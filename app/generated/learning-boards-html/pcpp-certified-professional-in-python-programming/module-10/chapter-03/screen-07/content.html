Module 10 › Chapter 10.3 › Fixtures: setup and teardown
Fixture example
import pytest
from account import BankAccount

@pytest.fixture
def default_account():
    print("Setting up default_account fixture.")
    account = BankAccount(100)
    yield account
    print("Tearing down default_account fixture.")

def test_deposit_with_fixture(default_account):
    default_account.deposit(50)
    assert default_account.balance == 150
Fixture benefits
  • Explicit dependencies: tests declare what they need by name.
  • Reusable setup: one function used by many tests keeps code DRY.
  • Yield-based teardown: cleanup code runs after the test that requested the fixture.
Common mistake
Forgetting to include the fixture name in the test signature prevents injection — pytest will not call the fixture silently.
