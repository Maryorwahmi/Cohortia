Module 10 › Chapter 10.3 › Pitfalls and migration tips
Checklist for migration
  • Install pytest with pip before running tests.
  • Refactor TestCase tests into small functions and fixtures.
  • Name files and functions for pytest discovery.
  • Prefer assert and pytest.raises over unittest constructs.
Common mistakes
Using session scope for mutable fixtures
Placing multiple calls in one pytest.raises block
Keeping unittest assertion methods and extra boilerplate
Pro tip
Convert small modules first, run tests frequently, and adjust fixture scope only after ensuring tests are stable.
