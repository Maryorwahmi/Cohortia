Module 11 › Chapter 10.9 › Handlers & Formatters
Common handlers
  • StreamHandler — console or stdout for human-readable messages.
  • FileHandler — persistent files for audit or debug traces.
  • SMTPHandler — alerting via email for critical conditions.
  • Custom handlers — integrate with external services or APIs.
Formatting choices
Choose plain text with timestamps for human ops and JSON for indexable, machine-parsable logs. Keep consistent keys in structured outputs to support queries.
Example: file handler with detailed formatter
db_file_handler = logging.FileHandler('database.log')
db_file_handler.setLevel(logging.DEBUG)
db_formatter = logging.Formatter('%(asctime)s - %(name)s - %(levelname)s - %(message)s - (%(filename)s:%(lineno)d)')
db_file_handler.setFormatter(db_formatter)
db_logger.addHandler(db_file_handler)
Common mistake
Using the same formatter for all handlers can hide fields needed for auditing or parsing. Tailor formatters to the handler's consumer.
Key Takeaway

Assign formatters that match the handler’s intended usage: human vs machine, verbose vs summary.
