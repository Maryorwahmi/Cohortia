Module 11 › Chapter 10.9 › Custom Filters
Filter anatomy
Subclass logging.Filter and override filter(record). Use record attributes, the message text, or extra context to decide. Keep filters fast and deterministic.
Example: UserFilter
class UserFilter(logging.Filter):
    def __init__(self, user_id=None, name=''):
        super().__init__(name)
        self.user_id = user_id

    def filter(self, record):
        if self.user_id is None:
            return True
        return getattr(record, 'user_id', None) == self.user_id

# Attach to handler:
user_filter = UserFilter(user_id=123)
console_handler.addFilter(user_filter)
Checklist & common mistakes
  • Attach filter to the correct handler or logger.
  • Do not assume filters can inspect which handler the record will use; make the decision from the record itself.
  • Keep filters lightweight to avoid slowing logging paths.
Pro tip
Use 'extra' to attach contextual attributes like user_id or request_id so filters can operate without heavy parsing of the message string.
