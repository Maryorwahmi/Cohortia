Module 11 › Chapter 10.9 › Sensitive Data
Design principles
  • Avoid logging secrets at the call site.
  • Redact sensitive keys in a centralized place (filter or formatter).
  • Let secure, private logs retain details only accessible to authorized personnel.
Pattern: console redaction
Attach a filter to the console handler that detects keywords like 'password' and removes or masks the substring before emitting. Allow file handlers to keep full context only if files are protected and rotated.
Common mistake
Assuming a single global change will secure all outputs. Apply redaction where needed and verify each handler's output.
