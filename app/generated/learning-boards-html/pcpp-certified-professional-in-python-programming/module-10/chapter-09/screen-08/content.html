Module 11 › Chapter 10.9 › The extra parameter
Why use extra
extra places metadata on the LogRecord as attributes. Filters and formatters read these attributes directly. Use consistent keys across modules to simplify queries.
Example call
json_logger.info("User login successful.", extra={'user_id': 'alice123', 'ip_address': '192.168.1.100', 'event_type': 'authentication'})
Handling missing keys
Formatters should use hasattr(record, 'key') checks or safe getters when optional attributes may be absent. This prevents formatter errors in logs without extra context.
Common misconception
Don’t embed key data into the message string. Use extra for structured fields so queries remain robust.
