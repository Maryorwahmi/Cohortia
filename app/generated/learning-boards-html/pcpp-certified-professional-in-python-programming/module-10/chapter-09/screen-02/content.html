Learning Objectives

Skills you'll be able to perform and verify.

Bloom: Learn → Understand → Apply → Master
01
Configure multiple loggers
Set up component loggers with different handlers and formatters so each area of your app produces appropriate outputs. Verified by creating a module logger that writes to its own file.
VERIFIED COMPETENCY MILESTONE
02
Implement custom filters
Write Filter subclasses that accept or reject LogRecord objects based on dynamic criteria like user_id or message content. Verified by attaching filters to handlers and observing filtered output.
VERIFIED COMPETENCY MILESTONE
03
Produce structured logs
Serialize LogRecord fields and extra context into JSON so monitoring tools can query fields like user_id and component. Verified by writing JSON to a file and searching keys.
VERIFIED COMPETENCY MILESTONE
04
Integrate across components
Apply handlers, filters, and formatters consistently in multi-module apps, balancing verbosity and privacy. Verified by configuring auth and order module logs with appropriate routing.
VERIFIED COMPETENCY MILESTONE
