Module 11 › Chapter 10.9 › Debugging Logs
Missing logs?
Check the emitter logger's level and the handler's level. Remember that a parent logger may filter out propagated messages because of its level.
Duplicated logs?
Look for both child and parent handlers accepting the same record. Either remove redundant handlers or set child.propagate = False when isolation is desired.
Secrets leaking?
Verify filters and formatters on every handler that could receive the message. Centralize redaction in a formatter when possible to guarantee uniform masking.
Practical step
Emit a known test message with unique content and trace which handlers wrote it. This reveals propagation and filter effects quickly.
