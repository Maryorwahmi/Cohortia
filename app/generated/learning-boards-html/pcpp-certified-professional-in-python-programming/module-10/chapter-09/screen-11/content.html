Example architecture
Auth logger
Writes debug and info to auth.log. Console handler uses a redaction filter to hide passwords.
Root logger
Handles general application events and pipes CRITICAL messages to a JSON file handler for alerting.
Checklist
  • Assign module-specific loggers and file handlers where needed.
  • Attach redaction filters to shared sinks like console or centralized log streams.
  • Serialize critical events to JSON for alerting and monitoring ingestion.
Key Takeaway
Design handler responsibilities and propagation intentionally to maintain clarity and avoid duplicated records.
