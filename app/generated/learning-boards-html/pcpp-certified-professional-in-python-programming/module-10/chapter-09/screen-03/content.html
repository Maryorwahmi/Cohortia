Practical verification steps

Logger routing check
Emit debug from a sublogger and confirm the component file receives it while console shows only INFO-level messages.
Filter behavior
Attach your Filter to the console handler and confirm messages matching the filter appear or are suppressed as intended.
Structured log parsing
Load the JSON file into a parser or simple script and query by keys like user_id or component to confirm fields were serialized.
Quick checklist
  • Handlers set with correct levels and formatters
  • Filters attached where intended (handler or logger)
  • Sensitive content redacted before console output
  • Critical events serialized to JSON for alerts
