Process Flow › patch as context manager
When to use
  • When only a section of a test needs the mock.
  • When you want to change mock behavior mid-test.
  • To avoid many stacked decorators for readability.
Quick Step
with patch('user_service.UserRepository') as MockRepo: configure mock, create service, call method, assert results
Example
def test_update_user_email_success():
  with patch('user_service.UserRepository') as MockUserRepository:
    mock_user = User(1, 'Alice', 'alice@example.com')
    MockUserRepository.return_value.get_user_by_id.return_value = mock_user
    service = UserService(MockUserRepository.return_value)
    assert service.update_user_email(1, 'alice.new@example.com') is True
    assert mock_user.email == 'alice.new@example.com'
