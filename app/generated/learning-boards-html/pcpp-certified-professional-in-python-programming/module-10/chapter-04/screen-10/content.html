Core Concept › Using side_effect
Patterns
  • Assign an exception class or instance to raise an error.
  • Provide an iterable to return different values across calls.
  • Set a callable to run custom logic on each call.
Example Sequence
mock.get_user_by_id.side_effect = [User(1,'A','a@'), User(2,'B','b@'), ValueError('User not found')]
Code example
mock_repo = MagicMock()
mock_repo.get_user_by_id.side_effect = [
  User(1,'Alice','a@a.com'),
  User(2,'Bob','b@b.com'),
  ValueError('User not found')
]
# Calls return Alice, then Bob, then raise ValueError
