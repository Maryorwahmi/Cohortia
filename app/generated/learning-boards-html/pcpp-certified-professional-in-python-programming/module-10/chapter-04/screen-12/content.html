Definition › Anti-patterns & Practices
Anti-patterns
  • Mocking internal methods rather than external interfaces.
  • Overmocking many collaborators in one test.
  • Patching the wrong module path so mocks never take effect.
If a test requires many mocks, refactor the production code to reduce responsibilities and expose clear boundaries.
Practical tips
  • Patch at the module lookup used by the unit under test.
  • Prefer explicit configuration: set return_value and side_effect clearly.
  • Keep tests small and focused on one behavioral claim.
