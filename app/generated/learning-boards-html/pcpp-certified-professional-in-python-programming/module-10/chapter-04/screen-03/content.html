How verification works
  • Write a test that would fail if it reached the real dependency.
  • Use patch to replace the dependency with a MagicMock configured for the scenario.
  • Assert the method result and that the mock was called with expected arguments.
Checkpoint
Confirm the mock was called once with the expected input.
Tip
If tests require many mocks, consider refactoring to reduce responsibilities.
