Core Concept › Configuring return_value
How to use
  • Assign Mock.method.return_value = value to define a fixed return.
  • Use for repeatable, deterministic responses.
  • Combine with assert_called_with to confirm inputs.
Misconception
Setting return_value to an exception object does not raise it. Use side_effect to raise exceptions.
Example
MockUserRepository.return_value.get_user_by_id.return_value = User(1, 'Alice','a@a.com')
result = service.get_user_details(1)
# result now reflects the configured User instance
Use return_value for the common case when the mock should always provide the same controlled response.
