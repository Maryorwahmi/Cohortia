Process Flow › MagicMock & patch
MagicMock features
  • Automatically creates attributes and callable mocks on access.
  • Configure return_value for methods or attributes.
  • Use side_effect to raise exceptions or return a sequence.
Common Mistake
Relying on MagicMock to enforce real object interface without explicit setup creates false confidence in tests.
patch usage
from unittest.mock import patch, MagicMock

@patch('user_service.UserRepository')
def test_get_user_details(MockUserRepository):
  mock_user = User(1, "Alice", "a@a.com")
  MockUserRepository.return_value.get_user_by_id.return_value = mock_user
  service = UserService(MockUserRepository.return_value)
  assert service.get_user_details(1).startswith('User ID: 1')
Patch replaces the name where user_service looks it up, ensuring your service receives the mock class instance.
