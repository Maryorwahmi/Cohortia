Code Walkthrough › patch as decorator
Step-by-step
  1. Decorate the test with @patch('module.Name').
  2. Configure Mock.return_value method results as needed.
  3. Construct the unit under test with the mock and run assertions.
Example Check
Assert both the function result and Mock.return_value.method.assert_called_once_with(...)
Example test
@patch('user_service.UserRepository')
def test_get_user_details_found(MockUserRepository):
  MockUserRepository.return_value.get_user_by_id.return_value = User(1, 'Alice', 'a@a.com')
  service = UserService(MockUserRepository.return_value)
  assert service.get_user_details(1).startswith('User ID: 1')
  MockUserRepository.return_value.get_user_by_id.assert_called_once_with(1)
