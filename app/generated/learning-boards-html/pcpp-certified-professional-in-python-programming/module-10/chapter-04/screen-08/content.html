Definition › Patch Target
Rule & Rationale
  • Patch where the unit looks up the object at runtime.
  • Inspect import statements to find the lookup path.
  • Incorrect patch location leaves the real object in place.
Example: If my_module does import requests and calls requests.get, patch 'my_module.requests.get' rather than 'requests.get' to intercept calls used by my_module.
Practical check
  1. Read the import in the tested module.
  2. Form the patch string from that module and attribute.
  3. Run the test; if a real call still happens, revisit the patch path.
