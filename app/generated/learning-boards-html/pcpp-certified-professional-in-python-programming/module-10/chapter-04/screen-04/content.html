Core Concept › What is Mocking
Definition & Benefits
  • Isolate unit logic from external dependencies.
  • Simulate success, failures, and edge cases quickly.
  • Assert interactions to verify contracts between components.
Example
Imagine a function that fetches user data from an API; mocking the API lets you test parsing and error handling without a network call.
Key Takeaway
Mock what you do not own or that is slow, unreliable, or outside the unit boundary.
Concrete Code Example
# user_service.py snippet
class UserService:
  def __init__(self, user_repo):
    self.user_repo = user_repo

  def get_user_details(self, user_id):
    user = self.user_repo.get_user_by_id(user_id)
    if user:
      return f"User ID: {user.id}, Name: {user.name}, Email: {user.email}"
    return "User not found."
This service can be tested without a real repository by injecting a mock that returns a fake user or None.
