Lab Walkthrough › Mocking WeatherAPI
Guided steps
  1. Write a test that constructs WeatherService with real WeatherAPI and observe it would call the network.
  2. Patch 'weather_service.WeatherAPI' and configure return values for success and error cases.
  3. Use side_effect to simulate an exception and assert fallback behavior.
  4. Verify fetch_weather_data.assert_called_once_with(city) for correct arguments.
Starter test snippet
@patch('weather_service.WeatherAPI')
def test_get_current_weather_success(MockWeatherAPI):
  MockWeatherAPI.return_value.fetch_weather_data.return_value = {
    'status': 'success', 'temperature': 25, 'condition': 'Sunny'
  }
  service = WeatherService(MockWeatherAPI.return_value)
  assert service.get_current_weather('London') == 'Current weather in London: 25°C, Sunny.'
  MockWeatherAPI.return_value.fetch_weather_data.assert_called_once_with('London')
