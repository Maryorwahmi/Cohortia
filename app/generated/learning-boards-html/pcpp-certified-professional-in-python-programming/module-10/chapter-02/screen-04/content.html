Module 10 › Chapter 10.2 › TestCase and test_ methods
Definition

A TestCase groups related tests. Methods named test_* are executed as separate tests with per-test isolation.

import unittest

class TestBankAccount(unittest.TestCase):
  def test_deposit(self):
    account = BankAccount(100)
    account.deposit(50)
    self.assertEqual(account.balance, 150)
Concrete example
The test_deposit method creates a fresh BankAccount and asserts the expected balance after deposit.
Common mistake
Forgetting to inherit from unittest.TestCase prevents discovery and removes assertion helpers like assertEqual.
Why this matters
  • Each test runs independently, reducing flaky tests caused by shared state.
  • Discovery means you can run many tests with a single command.
  • Assertions provide readable failure messages that help debugging.
Key Takeaway

Write small, focused test_ methods in TestCase classes to get isolated, discoverable tests.
