Module 10 › Chapter 10.2 › Testing exceptions with assertRaises
Example test
def test_deposit_zero_or_negative_amount_raises_error(self):
    account = BankAccount(100)
    with self.assertRaises(ValueError):
        account.deposit(0)
    with self.assertRaises(ValueError):
        account.deposit(-10)
Each with block isolates the statement expected to raise, producing clearer failure locations.
Misconception check
Avoid wrapping multiple operations in one assertRaises block. If multiple statements are in the block, you won't know which line caused the exception when the test fails.
Key Takeaway

Use assertRaises as a narrow context manager and test each error condition independently for precise diagnostics.
