01. TestCase & Discovery

Write classes inheriting from unittest.TestCase and name methods test_* so discovery runs them automatically. VERIFIED COMPETENCY MILESTONE

02. Fixtures

Use setUp and tearDown to prepare and clean resources per test, and setUpClass/tearDownClass for shared resources. VERIFIED COMPETENCY MILESTONE

03. Assertions

Apply assertEqual, assertTrue, assertRaises and others to verify behaviour and edge cases precisely. VERIFIED COMPETENCY MILESTONE

04. Organize & Run

Group tests into suites, use python -m unittest for CLI runs, and use discover-friendly filenames like test_*.py. VERIFIED COMPETENCY MILESTONE

Objective Mnemonics
TestCase → Discover
Remember the naming rule: test_ methods are discovered automatically.
setUp / tearDown
Think: prepare each test, then clean it; prevents cross-test pollution.
Assertions = Contracts
Assertions express the correct behaviour the code must meet.
