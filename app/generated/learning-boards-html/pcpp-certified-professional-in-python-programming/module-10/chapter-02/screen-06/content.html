Common assertions
  • assertEqual(a, b) — compares values and reports both sides on failure.
  • assertTrue(expr) — checks a boolean condition.
  • assertRaises(exc) — verifies an exception is raised.
  • assertIn(member, container) — checks containment.
Diagnostic example
assertEqual produces clearer messages than assertTrue when comparing values, helping you fix the bug faster.
Usage pattern
with self.assertRaises(ValueError):
  account.deposit(0)

self.assertIn('error', log_contents)
self.assertIsNone(result)
Key Takeaway

Prefer specific assertions to improve clarity and failure diagnostics; use assertRaises for exception behaviour.
