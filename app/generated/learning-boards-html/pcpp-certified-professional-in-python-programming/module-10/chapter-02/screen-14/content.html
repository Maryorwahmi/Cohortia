Module 10 › Chapter 10.2 › What to Remember
TestCase & Discovery
Inherit TestCase and use test_ naming so unittest finds and runs your tests.
Assertions
Prefer specific assertions like assertEqual and assertRaises for clear diagnostics.
Fixtures
Use setUp/tearDown for per-test state; use class-level setup only for expensive shared resources.
Summary takeaway

Well-structured unittest code makes behaviour explicit, reduces regressions, and supports CI. Keep tests focused, isolated, and expressive.
