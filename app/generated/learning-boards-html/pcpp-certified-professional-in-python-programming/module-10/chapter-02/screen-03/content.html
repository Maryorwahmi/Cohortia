What success looks like

Concrete examples of passing tests and clean fixtures help you recognise correct test design.

BankAccount fixture
Use setUp to create BankAccount(100) before each test so deposit and withdraw tests run independently.
Mnemonic: fresh state each test = reproducible results.
StringUtilities tests
Cover mixed case, punctuation, empty and non-string inputs; expect TypeError for invalid types.
Mnemonic: cover happy path, edge cases, and invalid inputs.
Assertions selection
Choose assertEqual, assertTrue, assertRaises, assertIn as the most expressive, readable checks for each test.
Mnemonic: assertion is the contract for behaviour.
CLI runs
Use python -m unittest or python -m unittest discover with files named test_*.py for automatic discovery.
Mnemonic: name tests so the tool finds them.
