Module 10 › Chapter 10.2 › setUpClass and tearDownClass
Class-level example
class TestBankAccountAdvanced(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.shared_resource = 'Database connection object'

    @classmethod
    def tearDownClass(cls):
        del cls.shared_resource
Practical guidance
  • Use for expensive initialization run only once per class.
  • Do not rely on setUpClass for per-test mutable state.
  • Combine with setUp to ensure each test has clean state.
Common pitfall

Putting mutable objects in setUpClass without resetting them per test causes cross-test interference.
