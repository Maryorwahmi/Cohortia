Module 10 › Chapter 10.2 › Test discovery and running tests
Quick CLI recipes
Use the following commands to control runs and discovery.
# Run a single file
python -m unittest test_account.py

# Run discovery across project
python -m unittest

# Use discover explicitly
python -m unittest discover -s tests -p "test_*.py"
Naming tests so discovery finds them makes automation and CI integration straightforward. If you need grouped execution, build a TestSuite and run it programmatically.
Lifecycle visual

Key Takeaway

Name tests for discovery, rely on per-test lifecycle for isolation, and use explicit suites when you need grouped runs.
