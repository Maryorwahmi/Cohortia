Module 10 › Chapter 10.2 › setUp and tearDown for fixtures
Fixture example
class TestBankAccountAdvanced(unittest.TestCase):
    def setUp(self):
        self.account = BankAccount(100)
        self.temp_file_name = "temp_test_log.txt"
        with open(self.temp_file_name, 'w') as f:
            f.write("Test started.
")

    def tearDown(self):
        del self.account
        if os.path.exists(self.temp_file_name):
            os.remove(self.temp_file_name)
Why small fixtures help
  • Small setUp makes tests easier to read and reason about.
  • tearDown ensures cleanup even when tests fail, avoiding leftover artifacts.
  • Bulky setUp is a sign the unit may need refactoring or injection of dependencies.
Key Takeaway

Implement focused setUp and tearDown so each test has a clean environment and predictable cleanup.
