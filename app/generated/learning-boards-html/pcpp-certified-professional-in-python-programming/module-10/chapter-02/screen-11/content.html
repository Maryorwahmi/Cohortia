Module 10 › Chapter 10.2 › Organizing tests and test suites
Directory layout
Common layouts: keep tests next to modules or in a top-level tests/ folder using test_*.py naming for discoverability.
Example layout
project/
module.py
tests/test_module.py
Building a TestSuite
import unittest
from test_account import TestBankAccount

suite = unittest.TestSuite()
suite.addTest(unittest.makeSuite(TestBankAccount))
runner = unittest.TextTestRunner()
runner.run(suite)
Use suites for curated runs, integration tests, or long-running checks you don't want in default discovery runs.
