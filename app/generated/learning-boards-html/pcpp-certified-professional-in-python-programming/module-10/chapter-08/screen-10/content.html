Module 10 › Chapter 10.8 › Pitfalls
Inefficient loops
Avoid repeated attribute access and redundant calculations inside tight loops. Use local variables and comprehensions when appropriate.
Excess objects
Creating many temporary lists or strings increases GC pressure. Use generators and streaming processing to limit temporary allocations.
Data structures
Choose sets or dicts for membership tests and lookups to achieve O(1) behavior instead of O(n).
Unnecessary I/O
Read and write only what you need; use batching for network calls and streaming for large files.
GIL misconception
Threads help overlap I/O because the interpreter releases the GIL during blocking calls, but they rarely speed up CPU-bound code. Use multiprocessing or native extensions for CPU parallelism.
Pro Tip

If a micro-optimization complicates code, evaluate whether the speed gain justifies reduced clarity. Prefer algorithmic improvements over micro-tweaks.
