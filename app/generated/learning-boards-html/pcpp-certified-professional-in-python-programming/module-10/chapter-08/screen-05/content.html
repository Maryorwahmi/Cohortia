Module 10 › Chapter 10.8 › timeit
How to use
Call timeit.timeit with the code string and number of iterations. Use setup to prepare data so the timed string focuses on the implementation you want to compare.
Example
import timeit

# Compare list comprehension vs append loop
list_comp_time = timeit.timeit('[x*2 for x in range(1000)]', number=10000)
list_concat_time = timeit.timeit('l = []; for x in range(1000): l.append(x*2)', number=10000)

print(f"List comprehension time: {list_comp_time:.4f} seconds")
print(f"List concatenation time: {list_concat_time:.4f} seconds")
Key Takeaway

Use timeit for microbenchmarks; keep setup separate and run many iterations to reduce noise.

Practical tips
  • Run timeit multiple times to confirm stability.
  • Use realistic input sizes that reflect production scenarios.
  • Don't forget to move setup work into setup parameter so it's not timed.
Misconception check
A faster microbenchmark does not always translate into faster end-to-end behavior; always re-run full-script profiles when possible.
