Five-step cycle
1. Measure
Establish baseline with realistic inputs.
2. Profile
Run cProfile, inspect tottime/cumtime.
3. Hypothesize
Choose a concrete change to test.
4. Change
Make targeted, minimal edits.
5. Validate
Re-run measurements and confirm improvement.
Following these steps keeps optimization work empirical and reversible. If a change doesn't help, the profile tells you where to try next.
