Module 10 › Chapter 10.8 › cProfile
Run from the terminal
Execute: python -m cProfile your_script.py and inspect the table it prints. Look for functions with high tottime and high cumtime as starting points.
Example script
def slow_function_a():
    sum(range(10**6))

def slow_function_b():
    [x*x for x in range(10**5)]

def main():
    for _ in range(5):
        slow_function_a()
        slow_function_b()

if __name__ == '__main__':
    main()

# Run: python -m cProfile my_slow_app.py
Key Takeaway

Use cProfile for end-to-end profiling and inspect both tottime and cumtime before changing code.

How to interpret
  • If tottime is high: optimize the function body or use faster algorithms.
  • If cumtime is high but tottime is low: inspect the callees the function invokes.
  • If ncalls is large: consider caching or reducing call frequency.
Visualization
Exporting profile data to visualization tools can make call relationships and hot spots easier to understand.
