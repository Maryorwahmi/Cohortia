Module 10 › Chapter 10.8 › CPU vs I/O
CPU-bound
Profile shows high exclusive time in computation functions. Strategies: use efficient algorithms, leverage C-optimized libraries, consider compiled extensions or multiprocessing for parallelism where appropriate.
Example
Tight loops performing arithmetic on large arrays; replace with NumPy vectorized operations.
Misconception
Threads will not speed up CPU-bound code in a single process due to the GIL; use multiprocessing or C extensions instead.
I/O-bound
Profile shows waits in network, disk, or database operations. Strategies: use asynchronous I/O to overlap waits, or threads because the GIL is released during blocking I/O, and batch or cache requests where possible.
Example
A function with low tottime but high cumtime because it awaits database queries; consider async requests or query batching.
Misconception
Spawning threads for CPU-heavy work will not usually help in Python; threads shine for I/O-bound concurrency.
