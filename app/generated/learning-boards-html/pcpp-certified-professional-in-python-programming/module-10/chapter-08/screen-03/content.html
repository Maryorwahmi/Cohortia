Module 10 › Chapter 10.8 › Practice & Pitfalls
Practice items
  • Write a timeit comparison for two implementations and run it with multiple iterations.
  • Run cProfile on a script, examine tottime and cumtime, and form an optimization plan.
  • Apply the optimization and re-run your measurements to confirm improvement.
Common pitfalls
  • Premature optimization: changing code without evidence it affects overall performance.
  • Poor data-structure choice leading to higher algorithmic cost.
  • Misattributing I/O waits to CPU work; check cumtime vs tottime first.
Mnemonic
Measure → Profile → Hypothesize → Change → Validate. Repeat until the performance goal is met.
