This card layout represents the architecture without needing a heavy diagram: each element is a role you can implement and unit test independently.
Delegation pattern
Base Decorator forwards method calls to the wrapped component by default. Concrete decorators extend those forwarded methods to introduce behavior.
Checklist for a correct decorator:
  • Implements the same interface as the component.
  • Stores a reference to a component instance.
  • Delegates calls and only augments behavior.
