Base Decorator
The base decorator stores the wrapped component and delegates calls to it by default.
class CoffeeDecorator(Coffee, ABC):
  def __init__(self, decorated_coffee: Coffee):
    self._decorated_coffee = decorated_coffee

  def get_cost(self) -> float:
    return self._decorated_coffee.get_cost()

  def get_ingredients(self) -> str:
    return self._decorated_coffee.get_ingredients()

class MilkDecorator(CoffeeDecorator):
  def __init__(self, decorated_coffee: Coffee):
    super().__init__(decorated_coffee)
    self.milk_cost = 0.5
    self.milk_ingredient = ", Milk"

  def get_cost(self) -> float:
    return super().get_cost() + self.milk_cost

  def get_ingredients(self) -> str:
    return super().get_ingredients() + self.milk_ingredient
Testing decorator composition
Compose decorators like SugarDecorator(MilkDecorator(SimpleCoffee())) and print cost and ingredients to validate layering. The decorator order determines how strings and cost additions accumulate.
Common mistake

Not delegating to the wrapped component or failing to implement the component interface leads to runtime errors and missing behavior.
