Decorator Pattern
Add responsibilities to objects at runtime without changing their classes.

Think of a plain cake that you can add frosting, sprinkles, and a candle to. Each addition wraps the cake and changes how it is presented, but the cake remains the same core item. Decorators work the same way with objects and functions.

We’ll use class-based wrappers for objects and the familiar @ syntax for functions. You will also get a hands-on starter for a message-processing pipeline so you can practice stacking decorators in different orders.
