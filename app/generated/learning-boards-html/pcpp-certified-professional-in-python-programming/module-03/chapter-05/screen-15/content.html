Module 03 › Chapter 3.5 › Key Concepts
Decorator Pattern
Add behavior to objects or functions without changing their classes.
Component Contract
Decorators must implement and preserve the original interface.
Function Decorators
Forward arguments and return values; use wrappers to add timing, logging, or retries.
Summary takeaway

Use decorators to compose behavior at runtime, keep concerns separated, and avoid an explosion of subclasses while maintaining predictable interfaces.
