Component & Concrete Component
Abstract methods define the contract. SimpleCoffee provides the basic behavior that decorators will extend.
from abc import ABC, abstractmethod

class Coffee(ABC):
  @abstractmethod
  def get_cost(self) -> float:
    pass

  @abstractmethod
  def get_ingredients(self) -> str:
    pass

class SimpleCoffee(Coffee):
  def get_cost(self) -> float:
    return 2.0

  def get_ingredients(self) -> str:
    return "Coffee"
How to test quickly
Instantiate SimpleCoffee, call get_cost and get_ingredients, and assert the returned values. This gives a reliable baseline before adding decorators.
Pro tip

Keep the component interface focused on the behavior clients need; avoid adding decorator-only methods here.
