Module 03 › Chapter 3.5 › Comparison
Subclassing
Pros: Simple to reason about for single, global extensions. Cons: combinations multiply quickly and maintenance suffers.
  • Each combination becomes a distinct class.
  • Testing and documentation must cover many types.
  • Hard to add or remove features at runtime.
Decorators
Pros: Compose small responsibilities into pipelines, change behavior per instance, and keep each decorator focused. Cons: Slight runtime indirection and the need to preserve interfaces.
  • Linear number of decorator classes for N features, not exponential.
  • Features can be added or removed dynamically.
  • Order of decorators matters and is an explicit design point.
Pro tip: When in doubt about per-instance needs, prefer decorators for flexibility; when the feature is universal and stable, inheritance might be simpler.
