Timer decorator
A wrapper must accept any call signature and return the wrapped function's result.
import time

def timer_decorator(func):
  def wrapper(*args, **kwargs):
    start_time = time.perf_counter()
    result = func(*args, **kwargs)
    end_time = time.perf_counter()
    print(f"Function '{func.__name__}' executed in {end_time - start_time:.4f} seconds.")
    return result
  return wrapper

@timer_decorator
def calculate_sum(a, b):
  time.sleep(0.1)
  return a + b
Common mistakes
  • Forgetting *args/**kwargs in the wrapper signature.
  • Not returning the wrapped function’s result, producing unexpected None.
  • Not preserving metadata; use functools.wraps when appropriate.
Try applying two function decorators and observe which wrapper runs first. Remember that decorator syntax applies them bottom-up at definition time but calls execute outermost wrapper first.
