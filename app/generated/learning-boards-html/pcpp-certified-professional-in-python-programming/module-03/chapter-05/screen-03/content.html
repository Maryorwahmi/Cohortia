Module 03 › Chapter 3.5 › Learning Objectives
Coding milestones
  • Implement a base decorator that delegates to a wrapped component and implements the same interface.
  • Create concrete decorators that add a single responsibility, like cost or logging.
  • Write a function decorator that handles arbitrary arguments and returns the original function's result.
  • Compose multiple decorators and observe how order affects the final behavior.
Common pitfalls
Decorator must preserve the component interface or client code will break.
Always delegate to the wrapped component unless you intentionally replace behavior.
In function decorators, remember to forward *args and **kwargs and return the wrapped result.
Verification tasks
  1. Write a decorator that wraps a logger and verify prints before and after sending.
  2. Create a stacked decorator chain and confirm the composition order produces expected output.
Why this matters
Using decorators correctly reduces class count, improves separation of concerns, and keeps core components simple. It also enables runtime configuration of behavior per instance or per function call, which is often required in real systems.
