Module 03 › Chapter 3.5 › Best Practice
Interface conformance
Ensure decorators implement the same public methods as the component. Unit test the decorator against the component interface.
Delegation
Call the wrapped component’s method (via super or the stored reference) unless intentionally replacing behavior.
Function wrapper rules
Forward *args and **kwargs and return the wrapped function’s result to avoid breaking call contracts.
Testing strategy
Unit-test each decorator, then test composed chains. Document side effects and preconditions.
