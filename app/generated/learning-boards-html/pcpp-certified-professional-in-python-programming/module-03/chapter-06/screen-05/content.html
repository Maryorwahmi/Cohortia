Module 3 › Chapter 3.6 › Attach, Notify, Detach
Steps
  1. Attach: Add observer if not present. Prevent duplicates.
  2. State change: Use a property setter or method to detect a new value.
  3. Notify: Iterate observers and call update. Consider iterating over a copy.
  4. Detach: Remove safely; ignore missing observers to avoid exceptions.
Pitfall

Modifying the observer list while iterating can skip observers or raise errors. Use list(self._observers) to iterate over a snapshot or queue changes until after notifications complete.

Example: safe notify (concept)
# notify over a shallow copy
for observer in list(self._observers):
  try:
    observer.update(self, symbol, price)
  except Exception:
    # handle or log observer failure without stopping others
    pass
Key Takeaway

Iterate safely and keep attach/detach idempotent; notifications should tolerate observer exceptions so a single failing observer does not block others.
