Composition examples
  • MVC: model as subject, views as observers.
  • Testing: replace observers with mocks to assert notifications.
  • Async: offload heavy observer work to background tasks to avoid blocking the subject.
Mapping to distributed systems
In a distributed context, a message broker fulfills a similar role: publishers send events and subscribers receive them. The in-process Observer pattern is simpler but should be mapped to brokers when components run in separate processes or machines.
Pro tip: Define clear event schemas or interfaces when observers span modules or services.
