Module 3 › Chapter 3.6 › Push vs Pull
Push model

Subject calls observer.update(self, stock_symbol, price). Observers get data directly and can react immediately without additional queries.

Good when observers consistently need the same payload.
Example

StockTicker pushes price and symbol so Investor and Regulator consume values immediately.

Pull model

Subject calls observer.update(self) and observers call subject.get_data() to retrieve only what they need. This reduces payload but increases subject queries.

Good when observers request varied subsets of state or when payloads are large.
Example

A GUI widget may pull only the fields it renders instead of receiving full model payloads.
