Module 3 › Chapter 3.6 › Learning Objectives
01
Choose push vs pull

Explain trade-offs: push sends explicit data; pull lets observers query the subject. Use push when observers always need the data, pull when observers vary in required state.

Mnemonic: Two arrows — push outward, pull inward
Verified Competency Milestone
02
Identify apply scenarios

Recognize event-driven situations—UI components, monitoring systems, or follower notifications—where subject-to-many-observer updates are required.

Mnemonic: Icon cluster
Verified Competency Milestone
03
Avoid iteration mistakes

Understand why mutating the observer list while notifying can skip listeners or crash, and prefer iterating over a copy or deferring changes.

Mnemonic: Timeline with safe checkpoint
Verified Competency Milestone
04
Hands-on sensor lab

Implement a RandomSensor subject and ConsoleDisplay, GraphDisplay, and Logger observers; practice attach, detach and validate notifications.

Mnemonic: Mini lab checklist
