Module 3 › Chapter 3.6 › Common Mistakes
Mutating during iteration

Iterating over and modifying the same list can skip listeners. Solution: iterate over list(self._observers) or collect changes for later.

Observer exceptions

Wrap observer.update calls in try-except so a failing observer doesn't stop notifications to others.

Detachment and memory

Ensure detach removes references to allow garbage collection. Test that removed observers no longer receive updates and that memory usage declines accordingly.

Circular updates

Avoid observer behavior that triggers the subject to notify again in an uncontrolled loop. Use guards or state checks to prevent reentrancy.
