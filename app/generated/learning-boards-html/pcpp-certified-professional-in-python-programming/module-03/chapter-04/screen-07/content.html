Module 3 › Chapter 3.4 › Adapter: Composition vs Inheritance
Object Adapter (Composition)
Holds an instance of the adaptee and translates calls. Easy to test and mock. Preferred in Python when you don't control the adaptee's implementation.
  • Flexible instantiation and dependency injection.
  • Clear separation of translation responsibilities.
  • Less brittle with changing adaptee APIs.
Class Adapter (Inheritance)
Inherits both target interface and adaptee implementation. Can be concise but couples adapter to adaptee internals and constructor semantics.
  • May cause multiple-inheritance complexity.
  • Ties adapter tightly to adaptee lifecycle.
  • Less common in Python; use only with controlled implementations.
Common misconception

Inheritance is not always reuse. Use composition for adaptors unless you truly need to reuse implementation and control the adaptee.

Key Takeaway

Composition keeps adapters predictable and testable in Python.
