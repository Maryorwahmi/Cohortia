Module 3 › Chapter 3.4 › Adapter vs Facade
Decision Steps
  1. Identify the client interface and expectations.
  2. Check if existing components match or can be adapted.
  3. If single-component mismatch → Adapter (composition preferred).
  4. If multi-component workflow → Facade to orchestrate steps.
  5. Keep adapters small and facades focused on sequence and delegation.
Quick checklist
- Can we wrap without changing the adaptee? If yes, adapter is appropriate.
- Does the client need a single, high-level operation across components? If yes, use a facade.
- Is the adapter becoming large? Consider splitting responsibilities.
Key Takeaway

Use the decision steps to pick the right pattern and keep responsibilities narrow.
