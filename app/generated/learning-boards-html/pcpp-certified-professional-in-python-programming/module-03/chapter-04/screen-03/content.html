Practical Tasks
  • Adapt a legacy payment gateway to a new payment processor interface using an object adapter.
  • Implement Celsius-to-Fahrenheit adapter and verify with display code.
  • Create WeatherStationFacade to combine sensor readings into one formatted response.
Remember: tests should exercise translation, not internal implementation details.
Common mistakes
- Modifying the adaptee class instead of wrapping it defeats the adapter purpose.
- Letting the adapter implement new business rules rather than translating inputs and outputs.
- Making facades responsible for domain logic instead of delegating to subsystem services.
Checkpoints
Each exercise ends with a short client call that prints results. Confirm success and failure paths where relevant.
Micro-mnemonic
Adapter = translate. Facade = simplify. Keep them focused and delegating.
