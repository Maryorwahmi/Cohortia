Module 3 › Chapter 3.4 › Key Concepts
Structural Patterns
Patterns that compose classes and objects to form larger, flexible structures.
Adapter
Wraps an adaptee and translates its interface into the target interface clients expect.
Facade
Provides a unified high-level API to a complex subsystem, delegating the detailed steps.
Summary
Adapters translate interfaces; facades simplify client interactions with many components. Prefer composition for adapters and keep facades focused on orchestration.
