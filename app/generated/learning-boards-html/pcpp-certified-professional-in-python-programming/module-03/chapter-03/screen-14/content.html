Module 3 › Chapter 3.3 › Practices & Pitfalls
Avoid exposing internals
Keep product internals private during assembly to prevent accidental misuse.
Common pitfalls
Forgetting return self, reusing builders without reset, and confusing Builder with Factory.
Best practices
Return self consistently, validate inputs, prefer immutability after build, and centralize common sequences in a Director when useful.
Final reflection
Next time you face a constructor with many optional args, try designing a small builder API first and evaluate the readability gains at call sites.
