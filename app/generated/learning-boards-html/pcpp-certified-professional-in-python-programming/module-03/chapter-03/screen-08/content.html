class Report:
  def __init__(self):
    self.title = "Untitled Report"
    self.header = ""
    self.sections = []
    self.footer = ""
    self.page_numbers = False
    self.author = "Unknown"
    self.orientation = "portrait"

  def add_section(self, section_title, content):
    self.sections.append({"title": section_title, "content": content})

  def display(self):
    print(f"--- {self.title.upper()} ---")
    if self.header:
      print(f"Header: {self.header}")
    print(f"Author: {self.author}")
    print(f"Orientation: {self.orientation}")
    print("-" * 30)
    for section in self.sections:
      print(f"Section: {section['title']}")
      print(f"  {section['content']}")
    print("-" * 30)
    if self.footer:
      print(f"Footer: {self.footer}")
    if self.page_numbers:
      print("Page numbers enabled.")
Explanation
  • Defaults: The constructor sets safe defaults to keep the product usable even if parts are omitted.
  • add_section: Product-level method to mutate its own sections in a controlled way.
  • display: A simple verification method to inspect assembled state during testing.
