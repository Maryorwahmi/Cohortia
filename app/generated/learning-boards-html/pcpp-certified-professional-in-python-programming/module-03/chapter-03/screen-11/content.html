Module 3 › Chapter 3.3 › Builder vs Factory
Factory: what it does
Selects and returns a concrete product type based on input parameters. The object is complete when returned.
Use when
You need to choose between different product classes at runtime.
Builder: what it does
Assembles one complex product through a sequence of steps, exposing a fluent API for optional parts.
Use when
A product has many optional parts or assembly steps and readability matters at call sites.
Hybrid approach
Factories can return builders when your system needs both selection of builder type and stepwise assembly. Choose the combination that simplifies client code and keeps responsibilities clear.
