Module 3 › Chapter 3.3 › Builder Anatomy
Product (Report)
Holds title, header, sections, footer, page numbers, author, orientation, and display behavior.
Responsibility
Store state and provide read-only or controlled access after construction.
Abstract & Concrete Builders
Abstract Builder defines interface; Concrete Builder implements methods and returns self for chaining.
Fluent Interface
Returning self keeps call sites expressive: builder.set_title(...).add_section(...).enable_page_numbers()
Director
Encapsulates common sequences like construct_minimal_report or construct_detailed_financial_report.
When to use
Use when many clients need identical configured products so you avoid duplicated assembly calls.
Best practice
Prefer immutability after build, validate inputs, and keep product internals private during construction.
Common pitfall: exposing internal state before build completes.
