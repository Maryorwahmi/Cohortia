Method chaining pattern
FinancialReportBuilder()\
  .set_title("Annual Financial Overview")\
  .set_author("Cohortia Analytics Team")\
  .add_introduction("This report summarizes the financial performance for the year.")\
  .add_data_section("Revenue: $1.2M, Expenses: $800K, Profit: $400K.")\
  .enable_page_numbers()\
  .get_report()
This example demonstrates readable assembly. Each call describes a deliberate step toward the final product.
Common mistake
If a method does not return self, chaining breaks and the API becomes clumsy.
Validation strategy
Choose immediate validation per method for faster feedback, or validate on build for incremental assembly. Document the choice.
Pro tip
Write unit tests that chain builder calls and assert the final product state; include a test that detects missing return self in any builder method.
