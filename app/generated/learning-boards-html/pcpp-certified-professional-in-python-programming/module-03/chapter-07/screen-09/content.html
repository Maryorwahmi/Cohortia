Module 4 › Chapter 3.7 › Strategy vs Template Method
Strategy
Composition: Context delegates to a separate strategy object which implements the full algorithm.
  • Vary whole algorithms.
  • Prefer composition and interfaces.
  • Good for interchangeable behaviors like shipping methods.
Template Method
Inheritance: base class defines the template, subclasses override steps of the algorithm but preserve the skeleton.
  • Vary steps within a fixed algorithm.
  • Uses subclassing to change behavior.
  • Good for algorithms with shared structure and variant steps.
Quick Decision Guide
Ask: Do we need to swap entire algorithms at runtime? If yes, choose Strategy. Is the skeleton fixed and only steps vary? If yes, choose Template Method.
