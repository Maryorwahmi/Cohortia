Module 4 › Chapter 3.7 › Switching Strategies
Typical runtime flow
1. Construct Context with initial strategy.
E.g., Order(weight, StandardShipping())
2. Use the Context to perform operations.
Context delegates to current strategy and returns results.
3. Change strategy via setter.
E.g., order.set_shipping_strategy(InternationalShipping()).
4. Reinvoke operation and observe different results.
Behavior changed without editing Context code.
Practical considerations
  • Validate strategy before assignment if it requires setup.
  • Favor returning values from Context rather than printing to keep logic testable.
  • Use dependency injection patterns to supply strategies in larger applications.
