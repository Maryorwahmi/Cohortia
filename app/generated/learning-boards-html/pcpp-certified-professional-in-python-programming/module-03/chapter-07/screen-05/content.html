Module 4 › Chapter 3.7 › Pattern Structure
Context
Holds a reference to a strategy and delegates the operation. Exposes way to change the strategy at runtime.
  • Constructor or setter accepts a strategy.
  • Does not implement the algorithm itself.
→
Strategy (Abstract)
Declares the common operation, for example calculate_cost(weight).
Can be an abstract base class or a documented callable signature in Python.
Concrete Strategies
Each implements the strategy interface with a different algorithm: StandardShipping, ExpressShipping, InternationalShipping.
StandardShipping: base + per kg
ExpressShipping: higher base and rate
InternationalShipping: base, per kg, and minimum fee
Key Takeaway

Define a clear contract and move each algorithm behind it. The Context only knows the contract, not the implementation.

Pro Tip
When strategies share helper code, factor helpers into separate modules rather than mixing responsibilities into strategies.
Common Mistake
Forgetting to give all strategies the same method signature — this causes runtime errors when swapping strategies.
