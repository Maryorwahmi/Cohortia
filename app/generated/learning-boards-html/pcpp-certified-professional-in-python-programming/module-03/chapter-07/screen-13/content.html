Module 4 › Chapter 3.7 › Assessment & Best Practices
Assessment Scenario
PaymentProcessor delegates to a PaymentStrategy for Credit Card, PayPal, and Crypto processing.
  • Each strategy implements process_transaction with same signature.
  • PaymentProcessor should accept strategy and delegate calls.
  • New payment methods are added as new strategies without changing PaymentProcessor.
Best practices
  • Return values rather than printing for testability.
  • Inject configuration into strategy constructors.
  • Use mocks to test Context behavior independently of external services.
Design Question

How will your Context handle strategy failures so that callers receive clear error information and can retry or log appropriately?
