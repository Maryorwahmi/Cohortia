Module 4 › Chapter 3.7 › Function vs Class
Function-based
Pros: concise, minimal boilerplate, ideal for pure functions.
  • Great for stateless transformations.
  • Easy to pass around as callables.
  • Less ceremony for small utilities.
Class-based
Pros: explicit interfaces, stateful behavior, easier to extend and test when complex.
  • Constructor parameters support configuration.
  • Abstract base classes enforce signatures.
  • Better for caching or stateful algorithms.
Design Rule of Thumb
Start simple with a function if the strategy is stateless. Migrate to a class if you need state, configuration, or clearer interface enforcement as requirements grow.
