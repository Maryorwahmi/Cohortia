Module 4 › Chapter 3.7 › Conditional Logic Problem
What is the smell?
Multiple branches choose different algorithms and duplicate responsibility for selection and execution.
  • Hard to extend: each new option changes the same function.
  • Hard to test: tests must exercise branches inside one function.
  • Violates Open/Closed and Single Responsibility principles.
Example: a calculate_shipping_cost function with many if statements for standard, express, international, etc. Adding economy or regional shipping forces edits across the same function.
Concrete refactoring idea
Extract each branch into a separate strategy with a common operation name. The Context keeps a reference and delegates execution to the current strategy.
Analogy
Think of strategies as interchangeable tools in a toolbox — the client asks the toolbox for a tool and uses it, without needing to know the tool's internals.
Common mistake: extracting strategies without a consistent interface. Ensure every strategy implements the same method signature so the Context can call it uniformly.
Key Takeaway

When conditional branches select algorithms, extract each branch behind a shared interface so you can extend behavior without modifying the client.
