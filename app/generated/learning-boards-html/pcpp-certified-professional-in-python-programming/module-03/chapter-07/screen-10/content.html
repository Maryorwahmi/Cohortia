Module 4 › Chapter 3.7 › When to Use Strategy
Common scenarios
  • Many related classes differing only by behavior.
  • Multiple conditional branches selecting algorithms.
  • Need to swap behavior at runtime or via configuration.
Function vs Class
Use function-based strategies for stateless quick operations. Use class-based strategies for stateful or configurable algorithms.
Decision checklist
  • Will new behaviors be added often? → Strategy helps.
  • Do behaviors need state? → Favor classes.
  • Is the algorithm skeleton fixed? → Consider Template Method instead.
Key Takeaway

Choose Strategy when behavior variants are independent and you need runtime flexibility or better testability; pick functions for simplicity and classes for state.
