Decision factors
  • Scope of variability: single product vs family
  • Maintenance cost: how many concrete factories will you update?
  • Testing needs: can you inject test factories or mocks?
  • Configuration: will factories be selected at runtime?
Patterns can combine

You can use a Factory Method to select which Abstract Factory to use, allowing a two-stage decision: which family, then which product within that family.

Practical tip

Start with the simplest pattern that meets your needs. Refactor to more complex patterns only when families or platform differences demand it.
