Module 3 › Chapter 3.2 › Abstract Factory — Intent
Pattern idea

Abstract Factory defines an interface for creating families of related objects. Concrete factories implement the interface to return theme-consistent products.

Example

GUIFactory.create_button and create_checkbox are implemented by WindowsGUIFactory and MacOSGUIFactory to produce consistent UI sets.

Common Pitfall

Adding a new product type to the abstract factory requires updating every concrete factory, which can be costly. Consider extending the hierarchy instead of changing the interface often.

When to choose
  • Your system needs families of related products that must be used together.
  • Platform or theme differences must be swapped as a whole.
  • Maintaining product consistency is a priority.
Key Takeaway

Abstract Factory is for producing coordinated product families so clients get a consistent set of implementations without referencing concrete classes.
