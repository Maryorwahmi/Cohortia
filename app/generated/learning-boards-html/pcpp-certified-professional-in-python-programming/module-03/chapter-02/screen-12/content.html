Module 3 › Chapter 3.2 › Factory Method vs Abstract Factory

Factory Method

  • Scope: single product hierarchy
  • Structure: abstract creator + factory method
  • Use when subclasses decide concrete classes

Abstract Factory

  • Scope: families of related products
  • Structure: abstract factory interface with multiple creation methods
  • Use when product sets must remain consistent
Concrete examples
Factory Method: DocumentCreator → PdfCreator, WordCreator
Abstract Factory: GUIFactory → WindowsGUIFactory, MacOSGUIFactory
