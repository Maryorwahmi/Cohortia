Verification checklist & common pitfalls

Unit test

Ask a factory for a product and assert it implements required methods.

No direct new

Ensure client code does not use concrete constructors directly after refactor.

Complete factories

Concrete factories must implement all abstract factory methods to maintain family consistency.

When not to use

If a single concrete class will never vary, a factory adds unnecessary indirection. Use judgement.

Pro tip

Favor interfaces or abstract base classes for products so you can substitute mocks in tests easily.
