Module 3 › Chapter 3.2 › Factory Method — Intent
Pattern structure
  • Product interface or abstract base class
  • Concrete products implementing the interface
  • Creator class with a public workflow method
  • Factory method (abstract) overridden by concrete creators
When to use

When a class wants subclasses to decide which concrete product to instantiate, often for a single product hierarchy.

Concrete example

DocumentCreator.create_document calls _create_document implemented by PdfCreator to return a PdfDocument. Client calls create_document and never sees the concrete class name.

Misconception

Avoid mixing creation and business concerns. Leave creation in the factory method and orchestration in the creator's public method.

Quick check

Can you add a new product by only creating a new concrete creator class?
