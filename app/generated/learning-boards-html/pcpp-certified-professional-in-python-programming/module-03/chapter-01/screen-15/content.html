Module 3 › Chapter 3.1 › Remember
Intent first
Confirm a single instance is truly required before enforcing it.
Guard __init__
Use an initialization flag so setup runs only once and state remains stable.
Prefer testable designs
If global state harms testability, favor dependency injection or factories instead of a singleton.
Final takeaway
Use Singleton deliberately, implement guards for init and concurrency, and document its behavior to keep code maintainable.
