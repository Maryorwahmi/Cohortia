Module 3 › Chapter 3.1 › Decorator Singleton
Code example
def singleton_decorator(cls):
    instances = {}
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    return get_instance

@singleton_decorator
class Logger:
    def __init__(self, log_file="app.log"):
        self.log_file = log_file
Note: the decorator replaces the class with a callable that returns the same instance each time.
Trade-offs & tips
Separation
Keep singleton policy outside the class body when you prefer composition over modification.
Argument behavior
Constructor arguments only take effect for the first instantiation.
Common pitfall
Unexpected ignoring of later arguments; document or design a separate configuration API.
