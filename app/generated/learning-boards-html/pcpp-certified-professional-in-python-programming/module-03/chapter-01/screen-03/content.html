Four verification cards
01 Identity
Confirm that repeated construction returns the same object using identity checks.
02 Init Guard
Use an internal flag to ensure initialization code runs only once.
03 Testability
Plan for resets or inject dependencies to keep tests independent.
04 Concurrency
Guard instance creation when multiple threads can race to construct the first object.
Quick mnemonic
Remember: Identity, Initialize once, Isolate for tests, Insulate for threads. These four I’s guide a safe Singleton design.
