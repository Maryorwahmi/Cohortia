Module 3 › Chapter 3.1 › __new__ Singleton
Code example
class Singleton:
    _instance = None  # Class variable to hold the single instance

    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

    def __init__(self):
        if not hasattr(self, '_initialized'):
            self.data = {}
            self._initialized = True
This code stores the instance in _instance and prevents __init__ from re-running via an _initialized attribute.
Explanation cards
Allocation control
__new__ controls allocation. Returning a stored instance prevents creating multiple objects.
Init guard
Use _initialized or similar to avoid re-running expensive initialization in __init__.
Common mistake
Forgetting the init guard causes repeated setup and surprising state changes.
