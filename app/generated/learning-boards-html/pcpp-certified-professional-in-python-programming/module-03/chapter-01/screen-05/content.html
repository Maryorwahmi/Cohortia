Module 3 › Chapter 3.1 › Pattern Categories
Category overview
Creational
Control object creation; includes Singleton, Factory, Builder.
Structural
Compose classes and objects into larger structures; adapters and facades.
Behavioral
Manage object interactions; observers and strategies belong here.
Decision aid: choose by problem
  • If the problem is "how objects are created", look at creational patterns.
  • If the problem is "how objects are organized", prefer structural patterns.
  • If the problem is "how objects collaborate", prefer behavioral patterns.
Concrete example
A configuration manager that must be unique is creational. A logging facade that wraps multiple loggers is structural. A message dispatcher is behavioral.
