Module 3 › Chapter 3.1 › Metaclass Singleton
Code example
class SingletonMeta(type):
    _instances = {}

    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class DatabaseConnection(metaclass=SingletonMeta):
    def __init__(self, host, port):
        if not hasattr(self, '_initialized'):
            self.host = host
            self.port = port
            self._initialized = True
Metaclass stores instances by class and centralizes control for all classes that declare it.
Why use a metaclass?
Apply the same singleton semantics to many classes without repeating code. Useful when class behavior, not instance behavior, should be standardized.
Note
Metaclasses increase complexity. Use when the benefit outweighs the additional abstraction cost.
