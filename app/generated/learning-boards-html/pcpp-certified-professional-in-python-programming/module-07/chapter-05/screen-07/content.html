Core Concept
DictReader & DictWriter
Column-oriented IO for clearer, maintainable code.
Write with DictWriter
import csv

data = [
  {'Name':'Alice','City':'New York','Description':'A vibrant city, known for its culture.'},
]
fieldnames = ['Name','City','Description']
with open('custom_data_dict.csv','w',newline='',encoding='utf-8') as file:
  writer = csv.DictWriter(file, fieldnames=fieldnames, delimiter=',', quoting=csv.QUOTE_MINIMAL)
  writer.writeheader()
  writer.writerows(data)
# custom_data_dict.csv created
writeheader writes the header row so others can read by name. Provide fieldnames to control column order.
Read with DictReader
with open('custom_data_dict.csv','r',newline='',encoding='utf-8') as file:
  reader = csv.DictReader(file, delimiter=',')
  for row in reader:
    print(row['Name'], row['City'], row['Description'])
Accessing row['Name'] is clearer and safer than row[0]. If the file lacks headers, pass fieldnames to DictReader.
Key Takeaway
Prefer DictReader/DictWriter for column-rich files to improve readability and reduce index errors.
