Key Concepts to keep
csv module
Use the csv module for correct parsing and writing according to standard rules.
DictReader / DictWriter
Work with headers as keys to reduce index-related bugs and improve code clarity.
newline & encoding
Always open with newline='' and specify encoding to avoid blank rows and character issues.
Takeaway

Treat CSV as a formal format: pick delimiters and quoting deliberately, stream data when large, and prefer dictionary-based IO for maintainable code.
