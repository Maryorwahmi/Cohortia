Core Concept
csv.reader and csv.writer
Custom delimiter and quoting examples with practical notes on newline and encoding.
Write pipe-delimited CSV
import csv

data = [
  ['Name', 'City', 'Description'],
  ['Alice', 'New York', 'A vibrant city, known for its culture.'],
]
with open('custom_data.psv', 'w', newline='', encoding='utf-8') as file:
  writer = csv.writer(file, delimiter='|', quoting=csv.QUOTE_MINIMAL)
  writer.writerows(data)
# custom_data.psv created
Note the newline='' and encoding parameter. QUOTE_MINIMAL ensures only fields that need quotes are quoted, preserving internal commas.
Read the same file back
import csv
with open('custom_data.psv', 'r', newline='', encoding='utf-8') as file:
  reader = csv.reader(file, delimiter='|')
  for row in reader:
    print(row)
# rows printed with Description intact
Reading with the same delimiter returns the original fields. Misconfiguring delimiter is a common source of mis-parsed columns.
Pro tip
Use writer.writerow when streaming rows one at a time; use writer.writerows when you already hold the data in memory.
