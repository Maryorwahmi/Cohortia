Three compact reminders
Use csv.reader
Respect quoting and embedded newlines — avoid naive splitting.
Prefer Dict IO
Access columns by name and write with explicit fieldnames.
Set newline & encoding
Always open with newline='' and encoding='utf-8' to avoid platform issues.
Final takeaway

Small, consistent defaults and a streaming pipeline prevent most CSV problems and make your code easier to maintain.
