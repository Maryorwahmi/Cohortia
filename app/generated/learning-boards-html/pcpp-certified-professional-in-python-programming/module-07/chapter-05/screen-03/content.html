Hands-on: sensor TSV → CSV transform
05. Efficient streaming
Treat readers as iterators and process rows one at a time. Avoid building large lists; append only filtered results or stream output row-by-row.
Mnemonic: row stream
VERIFIED COMPETENCY MILESTONE
06. newline and encoding safety
Use open(..., newline='') and encoding='utf-8' to avoid extra blank rows and character corruption across platforms.
Mnemonic: newline lock
VERIFIED COMPETENCY MILESTONE
07. Safe delimiter selection
Pick a delimiter unlikely to appear in values. If none exists, rely on robust quoting like QUOTE_ALL to avoid splits inside fields.
Mnemonic: delimiter safety net
VERIFIED COMPETENCY MILESTONE
