Comparison
Delimiter choices and trade-offs
Comma
Standard, broadly supported. Use with quoting when fields contain commas.
Tab (TSV)
Good for programmatic export; tabs seldom appear in prose but may in pasted text.
Pipe or semicolon
Useful when comma is common in values. Semicolons appear in some locales; pipes are visually obvious.
Practical checklist
  • Scan data for candidate delimiters before choosing.
  • If any delimiter occurs inside values, prefer quoting strategies rather than a rare character.
  • Document delimiter and quoting in the file header or metadata file.
Misconception
Choosing an obscure delimiter without scanning data still risks collisions. Quoting is the reliable fallback.
