Checklist
Common mistakes and fixes
Symptom: extra blank rows
Fix: open(..., newline='') so the csv module normalizes line endings and avoids extra blank lines on Windows.
Symptom: wrong column count
Fix: verify the delimiter argument matches the file and that quoting is set correctly.
Symptom: bad characters
Fix: set encoding='utf-8' (or the correct encoding) on open to preserve non-ASCII text.
Symptom: missing headers
Fix: ensure writer.writeheader() is called and fieldnames are provided to DictWriter.
Symptom: fields split inside text
Fix: use an appropriate quoting mode; if the delimiter appears in data, prefer QUOTE_ALL.
Debug tip
Print repr(row) to detect hidden newlines or quotes, and scan a sample of rows for delimiter occurrences before choosing a delimiter.
