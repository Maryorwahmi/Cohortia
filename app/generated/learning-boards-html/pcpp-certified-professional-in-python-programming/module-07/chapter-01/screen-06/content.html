Code Walkthrough › Reading files

Code examples

# Read whole file (small files)
with open('my_notes.txt', 'r') as f:
  content = f.read()

# Read line by line safely
with open('sensor_log.txt', 'r') as f:
  for line in f:
    line = line.strip()
    # parse timestamp and temperature

# Read one line at a time
with open('large_file.txt', 'r') as f:
  while True:
    line = f.readline()
    if not line:
      break
    process(line)
Explanation and tips
  • read() returns full content; avoid for very large files.
  • Iterating over the file object is memory-efficient and idiomatic.
  • readline() is useful when you need manual control over the loop.
  • Use strip() to remove trailing newline characters before parsing.
Concrete scenario
Processing sensor_log.txt line by line avoids high memory use and lets you parse each timestamp and reading as it arrives, making the script resilient for large logs.
Key Takeaway

Prefer iteration for line-based processing and avoid readlines() on very large files.
