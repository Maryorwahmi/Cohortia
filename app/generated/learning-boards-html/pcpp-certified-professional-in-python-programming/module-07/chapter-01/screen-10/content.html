Core Concept › Text vs Binary
Text mode ('t')
Performs encoding/decoding. read() returns a string. write() expects a string. Default mode in many environments is text with UTF-8 encoding.
Binary mode ('b')
No encoding. read() returns bytes. write() requires bytes. Use for images, audio, and other non-text data.
# Binary example from chapter
binary_data = b'\x00\x01\x02\x03\xff\xfe'
with open('binary_example.bin', 'wb') as f:
  f.write(binary_data)
with open('binary_example.bin', 'rb') as f:
  read_data = f.read()
  # read_data is bytes
Misconception check
Encoding issues often appear as UnicodeDecodeError when you read a file with the wrong text encoding; if you control the file, open it with the correct encoding parameter.
Key Takeaway

Binary for bytes, text for strings. Specify encoding when needed to avoid decode errors.
