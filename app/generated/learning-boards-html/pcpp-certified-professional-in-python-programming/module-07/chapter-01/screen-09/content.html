Comparison › Manual close vs with
Manual pattern
f = None
try:
  f = open('my_notes.txt', 'w')
  f.write('Hello
')
finally:
  if f:
    f.close()
Works but is verbose and error-prone if you forget the finally block.
with pattern
with open('my_notes.txt', 'w') as f:
  f.write('Hello
')
Cleaner, shorter, and guarantees close is called on exit. Prefer this for almost all file usage.
Practical tip
If you need to read then append, using two with blocks (one for 'r', one for 'a') avoids confusion with file pointers and is explicit about intent.
