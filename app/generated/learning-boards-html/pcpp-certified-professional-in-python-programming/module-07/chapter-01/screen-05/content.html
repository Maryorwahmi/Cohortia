Mode letters and their meaning

Primary modes
  • r — read (file must exist)
  • w — write (truncates or creates)
  • a — append (creates if missing)
  • x — exclusive create (fails if exists)
Modifiers
  • + — read and write on the same descriptor
  • b — binary mode, returns bytes
  • t — text mode, performs encoding (default)
Example: 'rb'
Open image or binary_example.bin for raw byte reading so no decoding is attempted.
Example: 'wt'
Create or overwrite a text file, letting Python encode strings to bytes using UTF-8 by default.
Example: 'w+'
Open for reading and writing, truncating the file first. Useful when you want a clean writable file you can also read from.
Key Takeaway

Be explicit with mode letters to avoid accidental truncation or encoding mistakes. Match mode to your data type and intent.

Common mistake

Opening with 'w' when you intended to append will erase existing content immediately.
