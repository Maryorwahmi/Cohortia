Common exception patterns

try:
  with open('non_existent.txt', 'r') as f:
    print(f.read())
except FileNotFoundError:
  print("Error: The file was not found.")
except IOError as e:
  print(f"An I/O error occurred: {e}")
Practical guidance
  • Catch the specific exception first to provide a tailored response.
  • Use a broader exception handler for unexpected I/O errors and log details.
  • Avoid empty except blocks that suppress useful diagnostic information.
Key Takeaway

Handle expected errors explicitly and log or re-raise unexpected issues so your program can recover or fail with clear diagnostics.
