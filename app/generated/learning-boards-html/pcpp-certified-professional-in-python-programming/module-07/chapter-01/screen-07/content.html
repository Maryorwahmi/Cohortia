Practical writing patterns

# Writing with explicit newlines
with open('my_notes.txt', 'w') as f:
  f.write('This is the first line.
')
  f.write('And this is the second line.
')

# Appending a line
with open('my_notes.txt', 'a') as f:
  f.write('This line was appended.
')

# Using writelines with explicit newlines
lines = ['one
', 'two
', 'three
']
with open('my_notes.txt', 'w') as f:
  f.writelines(lines)
Why explicit newlines?
Writes are literal. If you need separate lines, include newlines yourself; otherwise text will run together.
Binary vs text when writing
In binary mode, write expects bytes. Attempting to write a string raises TypeError. For example, when writing binary_example.bin use 'wb' and bytes literals.
binary_data = b'\x00\x01\x02\xff\xfe'
with open('binary_example.bin', 'wb') as f:
  f.write(binary_data)
Key Takeaway

Be explicit about newlines and data types; choose 'w' vs 'a' versus 'wb' appropriately.
