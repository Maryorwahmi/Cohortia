Core Concept › open() & file object

What the file object encapsulates

The file object holds the file descriptor, current pointer, buffering state, and exposes methods like read and write. Managing its lifecycle is essential to ensure writes are flushed and resources freed.

Common methods
  • read(): read the whole content as string or bytes
  • readline(): read one line including the newline
  • write(string): write text or bytes as provided
  • close(): flush buffers and release the resource
Common misconception
Creating a file object does not guarantee immediate disk writes; buffering can delay writes until flush or close.
Key Takeaway

Treat the file object as a channel: read, write, and then close or use a context manager to ensure finalization.

Concrete example
# Writing to a text file
f = open('my_notes.txt', 'w')
f.write("This is the first line.
")
f.write("And this is the second line.
")
f.close()

# Note: if an error occurs before close(), writes may not be flushed
Why this example matters
It shows manual lifecycle management where forgetting close can leave buffered data unwritten. Later screens show the safer with pattern.
