Starter script (from chapter)

import os

def register_user():
    filename = 'users.txt'
    existing_users = {}

    if os.path.exists(filename):
        try:
            with open(filename, 'r') as f:
                for line in f:
                    line = line.strip()
                    if line:
                        username, password = line.split(',', 1)
                        existing_users[username] = password
        except IOError as e:
            print(f"Error reading user data: {e}")
            return

    # ... prompts and append follow
Key points
  • Use split with maxsplit=1 to allow commas in passwords.
  • Open in append mode to add users without truncating existing data.
  • Catch IOErrors to surface read/write problems rather than crashing silently.
Key Takeaway

Build scripts that validate input, handle missing files, append safely, and verify results to reduce data corruption risks.
