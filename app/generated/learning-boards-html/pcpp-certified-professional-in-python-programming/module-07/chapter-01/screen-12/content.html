Line-by-line parsing pattern

with open('sensor_log.txt', 'r') as f:
  for line in f:
    line = line.strip()
    if not line:
      continue
    try:
      parts = [p.strip() for p in line.split(',')]
      # Example parts: ['Timestamp: 2023-10-26 10:00:00', 'Temperature: 25.5C']
      ts = parts[0].split(':', 1)[1].strip()
      temp_str = parts[1].split(':', 1)[1].strip()
      temp = float(temp_str.rstrip('C'))
      # process timestamp and temp
    except Exception:
      # log the bad line and continue
      continue
Why this works
Incremental parsing avoids loading the whole file and keeps a single corrupted line from crashing the entire job.
Key Takeaway

Design parsers to tolerate malformed lines, skip empty input, and handle unit stripping before numeric conversion.
