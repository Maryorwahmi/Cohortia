Quick decision checklist
  • Does data need to be consumed by other languages? → Prefer JSON.
  • Do you need full Python object fidelity and control both ends? → Pickle may be suitable.
  • Will the data come from external or untrusted sources? → Avoid pickle.
  • Is long-term portability required? → Prefer explicit formats and migrations.
Pitfall
Attempting json.dumps on custom objects without conversion.
Pitfall
Opening pickle files in text mode instead of binary mode.
Pro Tip
Document any manual conversions (e.g., datetime ISO strings) so future code can reconstruct data reliably.
Key Takeaway

Apply the checklist before serializing: choose the tool that matches your needs for fidelity, portability, readability, and security.
