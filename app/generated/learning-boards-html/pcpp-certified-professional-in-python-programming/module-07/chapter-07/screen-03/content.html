File modes
Pickle requires binary modes: open files with write-binary or read-binary. JSON uses text mode with UTF-8 encoding for portability.

Use-case rules
Pickle for Python-only fidelity; JSON for cross-language exchange, readability, and safer handling of untrusted data.
