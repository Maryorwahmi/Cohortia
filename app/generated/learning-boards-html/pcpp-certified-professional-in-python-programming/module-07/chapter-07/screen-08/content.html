What JSON handles
Dictionaries, lists, strings, integers, floats, booleans, and null map directly between Python and JSON.

JSON is human-readable and language-agnostic, making it ideal for APIs and cross-language storage.

Non-serializable Python objects, like custom classes or datetime objects, require conversion before JSON encoding.

Use json.dumps and json.loads for strings, and json.dump and json.load for files.

Practical note
Use indent for pretty printing during development and encoding='utf-8' when writing JSON files.
Concrete JSON example
import json

data = {
  "name": "Alice",
  "age": 30,
  "isStudent": False,
  "courses": ["Math", "Science"],
  "address": {"street": "123 Main St", "city": "Anytown"}
}

json_string = json.dumps(data, indent=4)
loaded_data = json.loads(json_string)
This snippet shows serialization to a JSON string and parsing it back to Python types. Loaded data will be native dicts and lists.
