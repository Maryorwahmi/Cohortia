Module 07 › Chapter 7.7 › Learning Objectives
Learning Objectives
Learn, understand, apply, and validate serialization skills
Bloom: Learn → Understand → Apply → Master
01
Define serialization
Explain serialize/deserialize for persistence and exchange, and why they enable restoring program state.
VERIFIED COMPETENCY MILESTONE
02
Use pickle for Python objects
Serialize complex Python structures and restore them with pickle.dump/load and dumps/loads.
VERIFIED COMPETENCY MILESTONE
03
Recognize pickle risks
Identify the security hazard of untrusted pickles and learn to avoid them.
VERIFIED COMPETENCY MILESTONE
04
Encode with JSON
Use json.dump(s)/load(s) for text-based exchange and learn to convert non-serializable types like datetime.
VERIFIED COMPETENCY MILESTONE
