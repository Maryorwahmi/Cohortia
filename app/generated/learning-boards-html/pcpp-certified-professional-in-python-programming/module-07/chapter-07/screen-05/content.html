Pickle basics
Python-specific, binary, supports custom classes and complex graphs of objects.

Primary functions: pickle.dump/load for files, and pickle.dumps/loads for byte strings.

Files must be opened with binary modes: write-binary or read-binary.

Resulting deserialized object has the same state but is a new in-memory object.

Common mistake
Using pickle for data received from untrusted sources; deserializing such data can execute code.
Example code
A short pickling example that serializes a simple custom object to a file and restores it.
import pickle

class MyCustomObject:
  def __init__(self, name, value):
    self.name = name
    self.value = value
    self.data = {'key': 1, 'list': [1,2,3]}

obj = MyCustomObject("Example", 123.45)

with open('data.pkl', 'wb') as file:
  pickle.dump(obj, file)

with open('data.pkl', 'rb') as file:
  loaded_obj = pickle.load(file)

print(obj.name, loaded_obj.name)
This example shows dump and load with binary file modes. After loading, the object's state matches the original but the identity is new.
