Module 07 › Chapter 7.7 › Quick Reminders
Pickle = binary
Use 'wb' and 'rb' modes; restrict to trusted environments.
JSON = portable
Prepare data by converting datetimes to ISO strings; use encoding='utf-8'.
Security first
Never load pickle data from unknown or untrusted sources.
Final takeaway
Match the format to your needs: fidelity and Python-only scenarios → pickle; interoperability and safety → JSON. Always be explicit about conversions and provenance.
