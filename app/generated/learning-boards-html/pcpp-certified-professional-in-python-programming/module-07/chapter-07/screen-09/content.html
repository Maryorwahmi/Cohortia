Writing and reading JSON files
Open text files with encoding='utf-8'. Use indent for readable output when appropriate.

Convert datetimes to ISO strings before dumping.

On load, convert ISO strings back to datetime objects explicitly.

Remember that JSON does not carry Python-only types like sets or tuples unchanged.

Code example
import json
from datetime import datetime

session = {
  'user_id': 'user_123',
  'last_login_time': datetime.now().isoformat(),
  'recent_actions': ['view_profile', 'add_item_to_cart']
}

with open('session.json', 'w', encoding='utf-8') as f:
  json.dump(session, f, indent=4)

with open('session.json', 'r', encoding='utf-8') as f:
  loaded = json.load(f)
# Convert last_login_time back: datetime.fromisoformat(loaded['last_login_time'])
This walkthrough shows preparing data for JSON and restoring the datetime after loading. These manual conversions are common practice.
