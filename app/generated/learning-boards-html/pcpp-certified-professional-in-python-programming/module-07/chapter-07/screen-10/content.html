Module 07 › Chapter 7.7 › Pickle vs JSON
Pickle — pros & cons
  • Pros: Serializes arbitrary Python objects and preserves complex state.
  • Cons: Binary, Python-specific, and unsafe for untrusted input.
  • Use when: You control both ends and need exact Python object fidelity.
JSON — pros & cons
  • Pros: Human-readable, language-agnostic, safe for external exchange.
  • Cons: Limited to basic types; requires conversions for custom objects.
  • Use when: Exchanging data with web frontends, APIs, or other languages.
Side-by-side example use cases
Saving a model for quick reload → Pickle
Sending preferences to a web client → JSON
Storing configuration to be human-edited → JSON
