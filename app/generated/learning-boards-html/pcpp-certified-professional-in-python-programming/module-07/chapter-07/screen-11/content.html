Activity steps
  1. Define UserSession with user_id, last_login_time (datetime), recent_actions.
  2. Serialize with pickle.dump to 'session.pkl' using 'wb', then deserialize with 'rb'.
  3. Attempt json.dump on the object and observe the TypeError for non-serializable types.
  4. Create a dict from the object, convert datetime to ISO string, json.dump to 'session.json' with encoding='utf-8' and indent.
  5. json.load from file and convert the ISO string back to a datetime, then reconstruct a UserSession instance.
Starter code (excerpt)
import pickle
import json
from datetime import datetime

class UserSession:
  def __init__(self, user_id, last_login_time, recent_actions):
    self.user_id = user_id
    self.last_login_time = last_login_time
    self.recent_actions = recent_actions

current_session = UserSession('user_123', datetime.now(), ['view_profile','add_item'])

# Pickle
with open('session.pkl','wb') as f:
  pickle.dump(current_session, f)

# JSON preparation
session_data = {
  'user_id': current_session.user_id,
  'last_login_time': current_session.last_login_time.isoformat(),
  'recent_actions': current_session.recent_actions
}
with open('session.json','w', encoding='utf-8') as f:
  json.dump(session_data, f, indent=4)
Key Takeaway

This lab shows the failure mode of JSON on custom objects and the manual conversion pattern to preserve the same information in a portable form.
