Module 07 › Chapter 7.7 › Key Concepts
Serialization
Convert an object's state into a storable or transmittable form.
pickle module
Python-specific binary serializer; supports dump/load and dumps/loads.
json module
Text-based, language-agnostic encoding for basic types; use dump/load and dumps/loads.
Takeaway
Pickle gives fidelity in trusted Python contexts; JSON gives portability and readability. Never unpickle untrusted data.
