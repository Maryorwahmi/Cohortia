dump/load vs dumps/loads
dump/load operate on file-like objects; dumps/loads return or consume bytes objects suitable for network or cache layers.

Always open files in binary mode for pickle: 'wb' for writing, 'rb' for reading.

Use dumps when you need serialized bytes to send over a socket or store in a binary cache.

Be mindful of version compatibility of pickled data between Python releases.

Pro tip
For long-term storage, prefer explicit migrations rather than relying on pickles across major Python upgrades.
Code snippets
# Write to file
with open('cache.pkl', 'wb') as f:
  pickle.dump(obj, f)

# Read from file
with open('cache.pkl', 'rb') as f:
  obj2 = pickle.load(f)

# In-memory bytes
blob = pickle.dumps(obj)
obj3 = pickle.loads(blob)
These examples show common patterns: file persistence, and producing a byte blob for transient transport or caching.
