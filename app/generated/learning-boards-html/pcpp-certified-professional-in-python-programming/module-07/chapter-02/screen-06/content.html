Definition
truncate()
Resize a file to a specific byte length.
When to use
  • Remove unwanted trailing data after edits.
  • Limit file growth for logs or temporary files.
  • Reset or enforce fixed file sizes for downstream consumers.
Cautions
  • truncate is destructive; data beyond the size is removed.
  • Behavior when extending a file can be platform-specific; don't assume content when expanding.
  • Consider backups for important data before truncating.
Example scenario

A process writes incremental log entries; every midnight you want to keep only the first 1 KB of the file. Seek to 0 and call truncate(1024) to preserve the initial region and delete the rest. Use flush before truncating to ensure buffered bytes are on disk.

Quick checklist
  • Confirm pointer position with tell()
  • Call flush() if you previously wrote data
  • Call truncate(size)
  • Verify file size with an OS check
Key Takeaway

truncate is a direct way to enforce file sizes; treat it as a destructive operation and protect important data first.
