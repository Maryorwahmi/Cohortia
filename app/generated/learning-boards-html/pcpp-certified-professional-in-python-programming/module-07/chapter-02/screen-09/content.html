Definition
Path object anatomy
Attributes
  • name — final path component
  • suffix — file extension
  • parent — containing directory Path
Common methods
  • exists(), is_file(), is_dir()
  • read_text(), write_text()
  • iterdir(), mkdir(parents=True)
Practical note

Use iterdir and list comprehensions to quickly gather names: [p.name for p in base.iterdir()]. Use unlink to remove files and rmdir to remove empty directories.

Example
from pathlib import Path
base = Path('my_pathlib_dir')
base.mkdir(parents=True, exist_ok=True)
file = base / 'sample.txt'
file.write_text('hello')
print(file.name, file.suffix, file.parent)
print([p.name for p in base.iterdir()])
file.unlink()
base.rmdir()
Tip: use parents=True and exist_ok=True to ensure intermediate directories are created without errors.
