Core Concept
seek, tell, truncate
Byte-oriented pointer control and safe file resizing.
Explanation
  • tell() returns the current byte offset from the file start.
  • seek(offset, whence) moves the pointer; whence: 0=start, 1=current, 2=end.
  • truncate(size) resizes the file to size bytes; omit size to use current pointer.
  • Prefer binary mode for predictable byte offsets; text mode can be affected by encoding.
Concrete example
# Example of seek(), tell(), and truncate()
with open('sample.txt', 'w+b') as f:
  f.write(b"Hello Cohortia!
")
  f.write(b"This is a test file.
")
  f.write(b"We are learning advanced file I/O.
")

  # Current position after writing
  print(f.tell())  # at end in bytes

  # Move to the beginning to read
  f.seek(0)
  print(f.tell())
  print(f.readline().strip())

  # Move to a specific byte offset
  f.seek(6)
  print(f.tell())
  print(f.read(7))  # reads b'Cohorti'

  # Truncate the file
  f.seek(0)
  f.truncate(16)
  f.seek(0)
  print(f.read())
Key Takeaway

Use binary mode when you require deterministic byte offsets and predictable seek behavior.

Common Mistake

Assuming seek in text mode equals character positions can lead to decoding errors or corrupted reads.
