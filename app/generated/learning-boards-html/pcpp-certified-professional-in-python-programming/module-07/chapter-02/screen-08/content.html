Comparison
os (procedural)
import os
if not os.path.exists('my_directory'):
  os.mkdir('my_directory')
file_path = os.path.join('my_directory', 'file.txt')
with open(file_path, 'w') as f:
  f.write('hello')
print(os.listdir('my_directory'))
Requires careful string handling and calls to os.path utilities.
Comparison
pathlib (object-oriented)
from pathlib import Path
base = Path('my_pathlib_dir')
base.mkdir(exist_ok=True)
file = base / 'file.txt'
file.write_text('hello')
print([p.name for p in base.iterdir()])
Path objects encapsulate behavior and reduce string manipulation errors.
Misconception

Pathlib does not remove the need for shutil or certain os functionality, but it greatly simplifies path and file operations.
