Core Concept
os module operations
Procedural filesystem manipulation.
Example usage
import os
import shutil

if not os.path.exists('my_directory'):
  os.mkdir('my_directory')

file_path = os.path.join('my_directory', 'old_name.txt')
with open(file_path, 'w') as f:
  f.write('This is an old file.
')

new_path = os.path.join('my_directory', 'new_name.txt')
os.rename(file_path, new_path)
print(os.listdir('my_directory'))
os.remove(new_path)
os.rmdir('my_directory')
Note: use shutil.rmtree to remove non-empty directories. Always check existence before removing to avoid exceptions.
Practical tips
  • Prefer os.path.join over manual string concatenation for portability.
  • Confirm a target is a file or directory before applying file-only or dir-only calls.
  • Be cautious: os.remove is irreversible and will delete data immediately.
Common mistake

Calling os.rmdir on a directory with contents raises an error; if you intend to delete recursively, use shutil.rmtree and handle errors carefully.

Key Takeaway

Use os functions for straightforward system-level tasks, but validate paths and contents before destructive operations.
