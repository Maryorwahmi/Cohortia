TemporaryFileManager
Create a temporary file, yield its path, and delete on exit.
import tempfile
import os

class TemporaryFileManager:
  def __init__(self, suffix='.tmp'):
    self.suffix = suffix
    self.filepath = None

  def __enter__(self):
    fd, self.filepath = tempfile.mkstemp(suffix=self.suffix)
    os.close(fd)
    print('Created', self.filepath)
    return self.filepath

  def __exit__(self, exc_type, exc_val, exc_tb):
    if self.filepath and os.path.exists(self.filepath):
      os.remove(self.filepath)
      print('Deleted', self.filepath)
    if exc_type:
      print('An exception occurred:', exc_val)
    return False  # don't suppress exceptions
Usage

Use the context manager in a with block. The file is available inside, and it is guaranteed to be deleted when exiting the block, whether the block completes or an exception is raised.

Design notes
  • Close low-level file descriptors if you open them with mkstemp.
  • Return False from __exit__ to let exceptions propagate unless you deliberately want to suppress them.
  • Test cleanup paths by raising an exception inside the with block.
Key Takeaway

Implementing __enter__ and __exit__ ensures deterministic resource cleanup regardless of how the with block exits.
