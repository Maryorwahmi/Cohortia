Safe patterns and security concerns

Understand trade-offs: convenience versus safety and cross-language compatibility.

Why avoid pickle

Pickle can execute code during unpickling, making it unsafe for untrusted input. It is Python-specific, so it reduces interoperability with other languages and systems.

Safer approach
  • Use JSON with explicit to_json_dict and object_hook reconstruction.
  • Validate types and field values after loading.
  • Use signatures or authenticated storage to prevent tampering.
Example validation checks

After object_hook reconstructs a Product, assert that last_updated is a datetime and price is a Decimal. If checks fail, raise a ValueError rather than silently accepting malformed data.

Key Takeaway
Favor portable, explicit formats and validate reconstructed objects to protect your application and data pipeline from malformed or malicious inputs.
