Custom JSONEncoder: a practical pattern

An encoder centralizes type conversions so json.dumps can serialize complex objects without errors.

Code example
import json
import datetime
from decimal import Decimal

class AdvancedEncoder(json.JSONEncoder):
  def default(self, obj):
    if isinstance(obj, datetime.datetime):
      return obj.isoformat()
    if isinstance(obj, Decimal):
      return str(obj)
    if hasattr(obj, 'to_json_dict'):
      return obj.to_json_dict()
    return json.JSONEncoder.default(self, obj)
This encoder converts datetimes to ISO strings, Decimals to strings, and defers custom objects to their to_json_dict method. Keep the mapping explicit to avoid leaking internals.
Explanation
  • default is called only for objects the base encoder cannot handle.
  • Return primitive types: str, int, float, list, dict, or None for JSON compatibility.
  • Use explicit conversion methods on classes to control shape and fields.
Concrete example
A ProductForJSON instance returns a dict with __class__ = Product, name, price as string, quantity, last_updated ISO string, and tags as a list. That dictionary is safe to include inside larger payloads.
Key Takeaway
Centralize serialization rules in an encoder and prefer explicit to_json_dict methods for custom classes to ensure stable, safe JSON output.
