CSV module basics

Create and parse headered CSV reports using DictWriter and DictReader for reliable interoperability with spreadsheets and analytics tools.

Write CSV
import csv

fieldnames = ['Name', 'Category', 'Price', 'Quantity']
with open('inventory_report.csv', 'w', newline='', encoding='utf-8') as f:
  writer = csv.DictWriter(f, fieldnames=fieldnames)
  writer.writeheader()
  for p in inventory:
    writer.writerow({'Name': p.name, 'Category': p.category, 'Price': p.price, 'Quantity': p.quantity})
Read CSV
with open('inventory_report.csv', 'r', newline='', encoding='utf-8') as f:
  reader = csv.DictReader(f)
  for row in reader:
    # row is a dict: {'Name': 'Laptop', 'Category': 'Electronics', ...}
    print(row)
Key Takeaway
CSV is ideal for simple tabular exports. Use DictWriter/DictReader for headered data and avoid embedding complex nested structures directly; instead serialize them to JSON strings if necessary for downstream parsing.
