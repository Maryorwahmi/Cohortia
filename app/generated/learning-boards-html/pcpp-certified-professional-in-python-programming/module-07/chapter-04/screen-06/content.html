object_hook and reconstructing objects

Use object_hook to map decoded dictionaries back to Python instances when a type marker is present.

Decoder example
import json
import datetime
from decimal import Decimal

def advanced_object_hook(dct):
  if '__class__' in dct and dct['__class__'] == 'Product':
    return ProductForJSON(
      dct['name'],
      Decimal(dct['price']),
      dct['quantity'],
      datetime.datetime.fromisoformat(dct['last_updated']),
      set(dct['tags'])
    )
  if 'created_at' in dct and isinstance(dct['created_at'], str):
    try:
      dct['created_at'] = datetime.datetime.fromisoformat(dct['created_at'])
    except ValueError:
      pass
  return dct
Explanation
  • object_hook runs for each JSON object literal (each dict), not for primitives.
  • Use explicit markers to make reconstruction unambiguous and safe.
  • Convert strings back into datetimes and Decimals within the hook to restore types.
Misconception
If you rely on value patterns only (for example checking for ISO-like strings everywhere) you risk false positives. Prefer object markers where possible.
Key Takeaway
object_hook is powerful for rebuilding objects, but it works best with explicit type markers and careful conversions to avoid ambiguity.
