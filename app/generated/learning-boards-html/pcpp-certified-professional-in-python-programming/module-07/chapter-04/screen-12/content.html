Lab task: extend inventory and CSV export

Implement the encoder, decoder, and CSV export functions and validate round-trip behavior.

Starter checklist
  • Add category and last_updated to Product.
  • Create InventoryEncoder to convert datetimes and Product.
  • Implement inventory_object_hook to rebuild Product and convert strings back.
CSV export notes

Use fieldnames [Name, Category, Price, Quantity], open with newline='', writeheader, and write each product row with raw numeric values as strings for stability.

Pro tip
Add a small test that saves an inventory, loads it back, and asserts type(product.last_updated) is datetime and type(product.price) is Decimal to ensure round-trip integrity.
