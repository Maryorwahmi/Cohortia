Using the default argument in json.dumps

default is a simple function you can provide to convert objects the encoder can't handle.

Step 1
Define custom_default(obj)

Check for datetime, Decimal, set, or objects with to_json_dict and return primitives or dicts with a type marker.

Step 2
Call json.dumps(..., default=custom_default)

Pass the custom_default to dumps or dump so the function is invoked for unrecognized objects.

Step 3
Test and promote

When conversions become numerous or stateful, move this logic into a JSONEncoder subclass for clarity and reuse.

Common mistake
Do not silently swallow unknown types in default. If you return None for unknowns you will lose data; prefer raising TypeError so you can handle unexpected cases explicitly.
Key Takeaway
default is a pragmatic, testable place for simple conversions. Move to a subclass as complexity grows and keep conversions explicit for round-tripping.
