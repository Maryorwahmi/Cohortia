Choosing formats: practical checklist

A quick decision guide to match format to requirements and constraints.

Interoperability needed?

Yes → prefer JSON, Protobuf, or Avro. No → JSON or pickle for Python-only internal caches (but avoid pickle for persistent storage).

Human-editable?

Yes → JSON or YAML. No → binary formats may be more efficient.

Schema evolution?

Yes → Avro or Protobuf with schema management. JSON requires careful versioning and tests.

Key Takeaway
Use this checklist to justify your choice and document trade-offs in design notes so future maintainers understand why a format was selected.
