Inventory example: end-to-end encoder/decoder

A full save/load cycle demonstrates both encoder and object_hook working together for reliable round-trips.

Save (encoder)
def save_inventory_json(inventory, filename='inventory_advanced.json'):
  with open(filename, 'w', encoding='utf-8') as f:
    json.dump(inventory, f, indent=4, cls=InventoryEncoder)
Load (decoder)
def load_inventory_json(filename='inventory_advanced.json'):
  with open(filename, 'r', encoding='utf-8') as f:
    return json.load(f, object_hook=inventory_object_hook)
Example validation
After load, verify that product.last_updated is a datetime and product.price is a Decimal. If not, fail early so bugs are caught in tests or CI.
