Formats compared

Pick a format based on who consumes the data and how it will change over time.

JSON

Human-readable, language-agnostic, great for APIs and debug logs. Requires custom serialization for non-standard types.

YAML

Even more human-friendly for configs, supports richer syntax. Beware of ambiguous parsing rules and security issues in some loaders.

Protocol Buffers

Compact binary, compiled schemas, high performance for inter-service messaging across languages.

Avro

Binary format with schema stored alongside data, enabling easier schema evolution in big data flows.

Parquet

Columnar file format optimized for analytics and large datasets, typically used in data lakes rather than service messages.

Key Takeaway
Match your choice to the requirements: readability, cross-language compatibility, runtime performance, and schema evolution. Binary formats win at size and speed; text formats win at debuggability and simplicity.
