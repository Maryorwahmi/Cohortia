Module 07 › Chapter 7.6 › Write changes
Modify and save

Add sections, update options, write() to disk

After editing the ConfigParser object, call write with an open file to persist changes. Verify by re-reading into a new ConfigParser instance.

# Modify and write
if 'NewSection' not in config:
  config['NewSection'] = {'new_option': 'value'}

config['Server']['port'] = '8081'
config['Server']['max_connections'] = '100'

with open(config_file_path, 'w') as configfile:
  config.write(configfile)

# Verify with a fresh parser
config_verify = configparser.ConfigParser()
config_verify.read(config_file_path)
print(config_verify['Server']['port'])
Example
Add a new API section for a demo key, write the file, and re-open it to confirm the new entry exists.
Gotcha
Forgetting to call write means changes stay only in memory. Automated tests should re-read files to assert persistence.
Practical checklist
  • Update config in memory using assignment.
  • Open the file with mode 'w' and call config.write(file).
  • Re-read using a fresh ConfigParser to verify changes in CI or tests.
Key Takeaway

Persist changes with write() and verify by re-reading; treat the file as a source of truth for other processes.
