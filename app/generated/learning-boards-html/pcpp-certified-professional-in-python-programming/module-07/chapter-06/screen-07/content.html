Module 07 › Chapter 7.6 › Missing values

Graceful handling patterns

Decide which settings are essential and which can use defaults. Prefer get with fallback for non-critical values and fail fast for secrets or mandatory endpoints.

# Check presence
if config.has_section('Network') and config.has_option('Network', 'max_retries'):
  retries = config.getint('Network', 'max_retries')
else:
  retries = 3  # fallback

# Simpler pattern
timeout = config.get('Server', 'timeout', fallback='30')
timeout = int(timeout)
Example
Use fallback for optional tunables like timeout or verbosity so the app uses sensible defaults.
Pitfall
Don't rely on membership checks inside a possibly missing section; check the section first or use get with fallback.
Decision guide
  1. If missing value breaks the program, validate and exit with a clear error.
  2. If missing value has a safe default, use get with fallback to continue.
  3. Document defaults so administrators know what will be applied when options are absent.
Key Takeaway

Plan which settings are critical and treat them accordingly; use fallbacks for recoverable options and explicit checks for required configuration.
