Read, update, and persist INI-style configuration files. Learn practical patterns that keep secrets and settings separate from code.

Reading
Load INI files and access options as strings or with typed helpers.
Writing
Update sections, add options, and persist with write().
Advanced
Use interpolation, ExtendedInterpolation, and control option name transformation.
Coming up: a compact live-coding demo that toggles a feature flag, writes the file, and re-reads it to confirm changes. Keep an eye on string conversion and fallbacks — those are frequent sources of bugs.

Sections → Options → Defaults → Type Conversion

Why this matters
Separating configuration from code simplifies testing, lets ops tune runtime behavior, and reduces accidental leaks of environment-specific values.
