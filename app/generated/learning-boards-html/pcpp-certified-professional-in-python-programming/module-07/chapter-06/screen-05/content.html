Code walkthrough

Create, read, and inspect

Use ConfigParser() then call read('path'). Validate file presence to avoid silent misses and use section checks before indexing.

import configparser
import os

config = configparser.ConfigParser()
config_file_path = 'app_settings.ini'
if not os.path.exists(config_file_path):
  # create a minimal file as an example
  config['DEFAULT'] = {'debug_mode': 'no', 'log_level': 'INFO'}
  config['Server'] = {'host': '127.0.0.1', 'port': '8080'}
  with open(config_file_path, 'w') as f:
    config.write(f)

# Read the file and inspect
read_files = config.read(config_file_path)
print('Read files:', read_files)
print('Server host:', config['Server']['host'])
Example
Use read() and print the list it returns to confirm which files were loaded.
Gotcha
read() ignores missing files silently. Avoid assuming the file was present without checking the return value or filesystem.
Practical tips
  • Check os.path.exists before calling read when you must guarantee a file is present.
  • Prefer config.get with fallback instead of direct indexing when a key may be missing.
  • Load from multiple paths: system-wide, user config, and working directory, in that order.
Key Takeaway

Always verify which files were read and guard access to sections and options to avoid runtime errors.
