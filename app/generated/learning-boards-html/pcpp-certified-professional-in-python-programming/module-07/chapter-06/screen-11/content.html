Module 07 › Chapter 7.6 › Security

Operational guidance

Use configparser for readable defaults and feature flags. For credentials, prefer environment variables or secret managers and protect INI files with file permissions and deployment rules.

Practice
Include a sample config file for developers without secrets, and .gitignore the real file. Use CI-injected environment variables for production secrets.
Pitfall
Committing an INI file with credentials is a common and dangerous mistake. Rotate compromised secrets immediately.
Checklist
  • Keep example config without secrets in repo.
  • Protect actual config with .gitignore and proper file permissions.
  • Use secret management for production credentials.
Key Takeaway
Treat INI files as readable configuration but not secure secret storage; design your deployment to inject secrets securely at runtime.
