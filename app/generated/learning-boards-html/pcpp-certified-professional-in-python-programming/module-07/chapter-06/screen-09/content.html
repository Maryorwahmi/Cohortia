Module 07 › Chapter 7.6 › Type conversion

Strings by default

INI files are textual, so configparser returns strings. Choose typed getters when numeric or boolean behavior is required.

# Manual conversion
port_str = config['Server']['port']
port = int(port_str)

# Typed getter
port = config.getint('Server', 'port', fallback=8080)

enabled = config.getboolean('Features', 'email_notifications', fallback=False)
Example
Use getboolean for feature flags so yes/no strings map to True/False reliably across platforms.
Best practices
  • Centralize conversion logic in a loader function that returns typed settings.
  • Use typed getters to simplify code and handle fallbacks in one call.
  • When testing, assert both value and type to detect faulty parsing early.
Key Takeaway

Prefer getint/getfloat/getboolean to keep configuration loading concise and safe; treat strings as raw input to convert explicitly.
