Assessment idea & troubleshooting

Validate both retrieval patterns and persistence. Tests should re-read files to detect missed writes and verify types where relevant.

Question 1 (from chapter)
Which snippet correctly retrieves an integer with default? Answer: config.getint('Network', 'max_retries', fallback=3).
Question 2 (from chapter)
After modifying a ConfigParser object, what must you do to save changes? Answer: call write() with an open file object in write mode.
Troubleshooting steps
  1. Confirm read() returned a non-empty list of filenames.
  2. After write(), re-open with a fresh parser and assert values.
  3. Use get* typed methods to catch conversion problems early.
Check your understanding
Add a unit test that runs the toggle script, re-reads the file, and asserts the updated feature flag and new API key are present.
Key Takeaway

Design simple read-modify-write tests that re-read configuration files to detect silent failures and ensure persistence.
