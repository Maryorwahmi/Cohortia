Learning Objectives

Bloom: Learn → Understand → Apply → Master
Learn • Apply
01
Understand INI structure and DEFAULT

Recognize sections and key-value pairs, and use DEFAULT for fallbacks. This matters when providing environment-specific overrides without duplication.

VERIFIED COMPETENCY MILESTONE
02
Use ConfigParser.read() and check files

Load INI files, but don't assume success; read() ignores missing files. Check for file existence or handle absence to avoid silent failures in production.

VERIFIED COMPETENCY MILESTONE
03
Convert typed values safely

All values are read as strings. Use getint/getfloat/getboolean or explicit conversion to perform numeric or logical operations correctly.

VERIFIED COMPETENCY MILESTONE
04
Write updates and persist changes

Add or modify sections and options in memory and use write() to save the INI back to disk, preserving readability for administrators.

VERIFIED COMPETENCY MILESTONE
