Interpolation

Use ${SECTION:option} to insert values from other sections or DEFAULT. ExtendedInterpolation enables more complex substitutions.

[DEFAULT]
log_dir = /var/log/myapp

[Server]
log_file = ${DEFAULT:log_dir}/server.log
Example
Define log_dir once and reuse it to keep paths consistent and easy to change.

optionxform

ConfigParser lowercases options by default. Override optionxform to preserve casing when your app requires it.

import configparser
config = configparser.ConfigParser()
# Preserve case
config.optionxform = str
Pro tip

Use optionxform = str early if option case matters to avoid subtle bugs when reading keys.
