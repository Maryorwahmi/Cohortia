Access options

Dictionary-style and typed getters

Use typed getters to combine retrieval and conversion. Fallbacks protect against missing values and sections.

# Dictionary style (may raise KeyError)
host = config['Server']['host']

# Safe getters with fallback and conversion
port = config.getint('Server', 'port', fallback=8080)
enabled = config.getboolean('Features', 'email_notifications', fallback=False)
Example
Use getint with fallback so the app starts even if a numeric option is missing.
Misconception
Values are not typed automatically; calling arithmetic on a retrieved option without conversion will fail or produce incorrect behavior.
Quick checklist
  • Prefer get/getint/getfloat/getboolean when possible.
  • Provide sensible fallback values for robust defaults.
  • Only use dictionary indexing when the section is guaranteed to exist.
Key Takeaway

Typed getters reduce boilerplate and help avoid manual conversion mistakes—use fallbacks to make your startup code resilient.
