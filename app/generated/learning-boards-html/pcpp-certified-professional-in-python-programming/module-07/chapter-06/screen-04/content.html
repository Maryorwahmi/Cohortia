Module 07 › Chapter 7.6 › INI structure
Definition

INI file format & DEFAULT section

INI files are organized into [Section] headers with key = value lines. The special [DEFAULT] section provides fallback values available to all other sections.

Concrete example
A DEFAULT log_level = INFO supplies a fallback so Server or Database sections don't need a log_level unless they must override it.
Common misconception
DEFAULT values are fallbacks, not overrides. If a section defines the same option, the section's value wins.
Check your understanding
Which values should be in DEFAULT: global defaults like log paths, or environment-specific secrets like database passwords? (Answer: prefer non-secret global defaults in DEFAULT.)
INI sample
[DEFAULT]
debug_mode = no
log_level = INFO

[Server]
host = 127.0.0.1
port = 8080

[Database]
type = PostgreSQL
host = db.example.com
port = 5432
user = admin
Key Takeaway

DEFAULT centralizes safe, non-sensitive defaults. Use section-level options to override environment-specific settings.
