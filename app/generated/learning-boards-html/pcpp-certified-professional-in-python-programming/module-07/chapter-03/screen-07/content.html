How Pickle stores objects

Pickle converts Python objects into a stream of bytes that the interpreter can later decode back into object instances with the same attributes and structure.

import pickle

# Serialize to bytes
pickled = pickle.dumps(obj)
# Write to a binary file
with open('obj.pkl', 'wb') as f:
  pickle.dump(obj, f)

# Read back
with open('obj.pkl', 'rb') as f:
  loaded = pickle.load(f)
Notes & risks
  • Pickle can serialize most Python objects, including class instances and recursive structures.
  • Pickles are not human-readable and not compatible with non-Python systems.
  • Always open files in 'wb'/'rb' modes when using pickle.
Security warning
Pickle can execute arbitrary code during deserialization. Never unpickle data from untrusted sources.
