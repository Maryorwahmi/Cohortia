Definition
Unsupported types & strategies

Unsupported types

  • set, bytes, complex, datetime objects, custom class instances.
  • Attempting to dump these directly raises TypeError.
Handling approaches
Convert to primitives (set → list), format datetimes as ISO strings, or implement to_dict and reconstruct on load.
Pro tip
Keep your serialized shape stable. Changing the dictionary keys later makes deserialization brittle for older files.

Example pattern

# Convert a custom object for JSON
class Product:
  def __init__(self, name, price, quantity):
    self.name = name
    self.price = price
    self.quantity = quantity

  def to_dict(self):
    return {"name": self.name, "price": self.price, "quantity": self.quantity}

# Later, reconstruct after json.load
p_dict = {"name":"Laptop","price":1200.0,"quantity":5}
p = Product(p_dict['name'], p_dict['price'], p_dict['quantity'])
Common mistake
Relying on json to preserve object identity or methods. JSON preserves structure and values only.
