Process Flow
json.dumps • json.loads • file I/O
Code walkthrough
import json

data = {
  "name": "Alice",
  "age": 30,
  "is_student": False,
  "courses": ["Python", "Data Science"],
  "address": {"street": "123 Main St", "city": "Anytown"},
  "grades": None
}

# Serialize to a JSON string with pretty print
json_string = json.dumps(data, indent=4)
print(json_string)

# Deserialize back to Python
deserialized = json.loads(json_string)
print(type(deserialized), deserialized)

# File-based operations
with open('data.json', 'w', encoding='utf-8') as f:
  json.dump(data, f, indent=4)

with open('data.json', 'r', encoding='utf-8') as f:
  loaded = json.load(f)
Explanation
  • json.dumps returns a string; json.loads parses a string back into Python values.
  • json.dump and json.load operate on file-like objects and accept indent for readability.
  • Supported types: dict, list, str, int/float, bool, None. Others raise TypeError.
Common mistake
Attempting to json.dumps a custom object without converting it first will raise a TypeError.
Key Takeaway

JSON is ideal for readable, interoperable data composed of basic types; convert complex types before dumping.
