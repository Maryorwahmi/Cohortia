05
Convert custom objects for JSON

You will write a to_dict method and a reconstruction step to move between object instances and JSON-safe structures, preserving only the fields that map to JSON types.

Example
Convert Product objects to dictionaries with name, price, quantity before serializing.
Error to expect
json.dumps raises TypeError for non-serializable objects like datetimes or sets.
06
Binary pickling for fidelity

You will serialize full Python objects with pickle.dump and reload them with pickle.load using file modes 'wb' and 'rb', which preserve type, attributes, and relationships across reloads.

Example
Pickle a Person instance with friends list and restore it intact in a new process.
Security note
Never unpickle data from untrusted networks—pickles can execute code during loading.
