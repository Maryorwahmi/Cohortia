Hands-on Activity
Reflection • Apply • Justify

Scenario A

A JavaScript frontend stores dashboard layouts that must be shared with the browser and inspected by developers. Recommended: JSON for compatibility and readability. Explain how to convert any custom fields to primitives.

Scenario B

A Python-only experiment saves complex object graphs for fast reloading in the same environment. Recommended: Pickle if all data sources are trusted; otherwise implement a secure export format.
Reflection prompt

Write a short justification for each scenario that mentions interoperability, human-readability, and security. Avoid choosing Pickle just for convenience—explain how you would manage conversion or trust boundaries instead.
