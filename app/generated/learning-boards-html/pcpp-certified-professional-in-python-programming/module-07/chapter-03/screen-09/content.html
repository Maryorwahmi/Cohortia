Security implications
How attacks work

Pickle can call arbitrary callables during unpickling via reduce hooks. A malicious payload can therefore run system commands or alter state when loaded.

Illustrative example
A specially crafted object can instruct the loader to call os.system with any shell command, executing code during deserialization.
Safer patterns
  • Use JSON and validate its structure with strict checks when accepting external input.
  • For Python-only internal use, restrict pickle sources to trusted locations and control file permissions.
  • Consider alternative libraries that enforce safe deserialization if you need richer than JSON semantics.
