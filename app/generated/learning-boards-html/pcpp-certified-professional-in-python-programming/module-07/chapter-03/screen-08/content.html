Process Flow
pickle.dumps • pickle.loads • file I/O
Code demo
import pickle

class Person:
  def __init__(self, name, age):
    self.name = name
    self.age = age
    self.friends = []

  def add_friend(self, friend):
    self.friends.append(friend)

p1 = Person('Bob', 25)
p2 = Person('Charlie', 28)
p1.add_friend(p2)

# In-memory pickle
pickled = pickle.dumps(p1)
# Reconstruct
p1_copy = pickle.loads(pickled)
print(p1_copy.name, [f.name for f in p1_copy.friends])

# File-based pickle
with open('person_data.pkl', 'wb') as f:
  pickle.dump(p1, f)

with open('person_data.pkl', 'rb') as f:
  loaded = pickle.load(f)
print(loaded)
Explanation
  • pickle.dumps returns bytes; pickle.loads reads bytes into a new object.
  • Binary file modes 'wb' and 'rb' are required when using pickle.dump and pickle.load.
  • Unpickling requires the same class definitions to exist at load time.
Pitfall
Changing class definitions between serialization and deserialization can cause unpickling to fail or produce unexpected instances.
