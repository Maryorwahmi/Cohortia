Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Custom JSONEncoder
Write an encoder subclass and default() to serialize custom classes and datetime consistently. This centralizes serialization and is reusable across dumps calls.
Verified competency milestone
02
object_hook Deserialization
Implement object_hook to detect tagged dicts and reconstruct objects, and learn why datetime strings sometimes need a second pass.
Verified competency milestone
03
dataclasses + asdict()
Use dataclasses.asdict for clean conversion and reconstruct instances by unpacking dictionaries, handling nested lists and datetimes.
Verified competency milestone
04
Object graph strategies
Decide between IDs and nested objects, validate input in hooks, and avoid insecure dynamic instantiation during deserialization.
Verified competency milestone
