Encoder subclass walkthrough
Centralize serialization in a reusable class.
import json
from datetime import datetime

class Point:
  def __init__(self, x, y):
    self.x = x
    self.y = y

class CustomEncoder(json.JSONEncoder):
  def default(self, obj):
    if isinstance(obj, Point):
      return {'__Point__': True, 'x': obj.x, 'y': obj.y}
    if isinstance(obj, datetime):
      return obj.isoformat()
    return super().default(obj)

p = Point(10, 20)
json_string = json.dumps({'point': p, 'time': datetime.now()}, cls=CustomEncoder, indent=2)
print(json_string)
Notes
  • Tagging with a unique key makes object_hook detection easy on load.
  • Returning dicts preserves attribute structure for reconstruction.
  • Use isoformat for datetime to preserve precision and a standard format.
Supporting blocks
Example
Using cls=CustomEncoder in json.dumps serializes Point objects and datetimes as intended.
Common mistake
Mutating the original object inside default or returning non-serializable values causes subtle bugs.
Key Takeaway

Use encoder subclasses when you need reusable, centralized serialization rules across your application.
