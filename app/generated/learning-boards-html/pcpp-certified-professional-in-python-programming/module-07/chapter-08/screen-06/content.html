default function example
Lightweight inline mapping for a couple of types.
def custom_default_func(obj):
  if isinstance(obj, Point):
    return {'__Point__': True, 'x': obj.x, 'y': obj.y}
  elif isinstance(obj, datetime):
    return obj.isoformat()
  raise TypeError(f"Object of type {obj.__class__.__name__} is not JSON serializable")

json_string = json.dumps(data_to_serialize, default=custom_default_func, indent=2)
  • Keep the function focused; avoid handling too many types here.
  • Maintain consistent tagging so deserialization remains straightforward.
Tradeoffs
Pro
Simple, minimal code change for local serialization needs.
Con
Less reusable and harder to maintain if you support many types across the codebase.
Key Takeaway

Use default functions for targeted, local problems; upgrade to a subclass when rules must be shared.
