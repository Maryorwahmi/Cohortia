Core Concept › Chapter 7.8 › TypeError: Not JSON serializable
What triggers the error
An object outside json's built-in primitives ends up in the structure passed to dumps.
Concrete example
from datetime import datetime
import json

class Point:
  def __init__(self, x, y):
    self.x = x
    self.y = y

p = Point(1, 2)
# This will raise TypeError: Object of type Point is not JSON serializable
json.dumps({'point': p})
Why stringifying is a bad habit
  • It discards type information and makes deserialization ambiguous.
  • Dates turned into strings may lose timezone or format assumptions.
  • It hides structure that your object_hook could use to reinstantiate objects properly.
Alternatives to stringification
Custom JSONEncoder
Subclass JSONEncoder and override default() to return dicts, lists or strings intentionally.
Default function
Pass a single function to json.dumps for small projects to map unknown types to serializable forms.
Pre-conversion
Convert dataclasses via asdict and datetimes via isoformat before dumping for explicit control.
Key Takeaway

Treat TypeError as a prompt to provide a clear, reversible translation for each non-primitive object you want in JSON.
