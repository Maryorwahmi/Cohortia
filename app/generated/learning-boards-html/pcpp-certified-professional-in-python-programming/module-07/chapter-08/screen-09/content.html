Definition › dataclasses.asdict()
dataclass serialization pattern
Convert to dict, handle non-primitives, then dump.
from dataclasses import dataclass, asdict
from datetime import datetime
import json

@dataclass
class Product:
  id: int
  name: str
  price: float
  last_updated: datetime

p = Product(101, 'Mouse', 25.99, datetime.now())
product_dict = asdict(p)
product_dict['last_updated'] = product_dict['last_updated'].isoformat()
json_product = json.dumps(product_dict, indent=2)

# On load
loaded = json.loads(json_product)
loaded['last_updated'] = datetime.fromisoformat(loaded['last_updated'])
product = Product(**loaded)
  • asdict is recursive: nested dataclasses become nested dicts and lists.
  • Handle non-standard leaves (datetime, custom classes) explicitly before dumping.
Hints
Nested dataclasses
Reconstruct inner dataclasses first so outer constructors receive instances, not dicts.
Validation
Validate fields before passing to constructors to avoid runtime errors.
Key Takeaway

asdict simplifies the path to JSON but you must still handle leaf types that aren't JSON-native.
