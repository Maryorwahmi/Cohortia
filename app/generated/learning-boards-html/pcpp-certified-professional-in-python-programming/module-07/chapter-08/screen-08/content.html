ISO serialization and explicit conversion
Choose tagged dicts or a post-load pass to rehydrate datetime strings.
# serialization (in encoder)
if isinstance(obj, datetime):
  return obj.isoformat()

# deserialization (post-load)
if isinstance(loaded['timestamp'], str):
  loaded['timestamp'] = datetime.fromisoformat(loaded['timestamp'])
  • ISO strings are portable and precise; prefer them over custom string formats.
  • object_hook won't touch bare strings; plan for explicit conversion.
  • Always catch parsing exceptions when converting untrusted input.
