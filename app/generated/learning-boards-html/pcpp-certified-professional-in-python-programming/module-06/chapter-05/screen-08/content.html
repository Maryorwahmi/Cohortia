Module 06 › Chapter 6.5 › The visited set — why it matters
Purpose of visited
Visited ensures termination in cyclic graphs and bounds work to unique vertices and edges.
When to mark visited
You may mark when pushing/enqueuing or when popping/dequeuing. Marking early prevents duplicate pushes; marking on pop keeps queue/stack content smaller in some scenarios.
Common Mistake
Forgetting visited entirely leads to infinite loops. Always include tests that run your traversal on cyclic graphs.
Mini example
# Suppose A-B-C-A
graph = {
  'A': ['B'],
  'B': ['C'],
  'C': ['A']
}
# Without visited, traversal loops. With visited set, each node is processed once.
