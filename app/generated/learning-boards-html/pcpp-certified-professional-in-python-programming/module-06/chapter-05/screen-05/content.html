Module 06 › Chapter 6.5 › Depth-First Search (DFS) — Concept
DFS steps
1. Start and mark visited
Add the start node to a visited set to avoid revisiting and cycles.
2. Explore along a neighbor
Follow a neighbor recursively or push it to a stack to continue deep exploration.
3. Backtrack and try other neighbors
When no unvisited neighbors remain, return and continue from previous nodes until all reachable vertices are processed.
Analogy
Walking down a corridor until you hit a wall, then returning to the last junction to try another corridor.
Example and takeaways
# Recursive DFS pattern (pseudocode)
visited = set()
def dfs(node):
  if node in visited: return
  visited.add(node)
  process(node)
  for neighbor in neighbors(node):
    if neighbor not in visited:
      dfs(neighbor)
Key Takeaway

DFS is great for exhaustive exploration and connected components; remember to mark visited to prevent cycles.

Misconception

DFS always uses less memory than BFS — not necessarily; recursion depth can reach V in the worst case.
