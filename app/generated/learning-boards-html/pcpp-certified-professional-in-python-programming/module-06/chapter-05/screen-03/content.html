05
Implement BFS with a queue

Use a deque to visit nodes level by level. Understand why BFS discovers nodes in order of increasing distance from the start in an unweighted graph.

Mnemonic: ripples outward

06
Analyze complexity for DFS and BFS

Explain why both traversals run in O(V + E) time and why space can reach O(V) for recursion stacks or queues, and why that matters for large graphs.

Mnemonic: V plus E
VERIFIED COMPETENCY MILESTONE
07
Find connected components with DFS

Use repeated DFS runs over unvisited nodes to collect connected components and return lists representing each component for testing and analysis.

Mnemonic: start a DFS per component
VERIFIED COMPETENCY MILESTONE
08
Avoid common traversal mistakes

Recognize how forgetting the visited set causes infinite loops in cyclic graphs, and how neighbor ordering affects deterministic outputs across runs.

Mnemonic: always mark visited
