Module 06 › Chapter 6.5 › Key Concepts
Depth-First Search
Deep branch exploration; recursion or stack; not guaranteed shortest path.
Breadth-First Search
Layered exploration with a queue; finds shortest path by edge count in unweighted graphs.
Complexity
Both DFS and BFS run in O(V + E) time; worst-case space is O(V) for stack or queue plus visited set.
Final takeaway
Implement both traversal patterns and apply the visited set consistently; choose BFS for shortest edge-count paths and DFS for exhaustive exploration and components.
