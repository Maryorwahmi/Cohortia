Code
def dfs_recursive(graph, start_node, visited=None):
  if visited is None:
    visited = set()

  visited.add(start_node)
  print(start_node, end=" ")  # Process the node

  for neighbor in graph.get(start_node, []):
    if neighbor not in visited:
      dfs_recursive(graph, neighbor, visited)
  return visited

# Example usage:
print("DFS Traversal (Recursive):")
dfs_recursive(graph, 'A')
Explanation and checks
  • visited is shared across recursive calls so nodes are not revisited.
  • Each neighbor list is iterated once; total work is O(V + E).
  • Recursion depth equals traversal depth; worst-case O(V) space.
