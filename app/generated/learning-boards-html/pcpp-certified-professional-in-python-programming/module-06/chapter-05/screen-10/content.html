Module 06 › Chapter 6.5 › When to use DFS vs BFS
Side-by-side comparison
Breadth-First Search (BFS)
Finds shortest path by edges; uses a queue; explores layer by layer; good for minimum steps and broadcasting.
Depth-First Search (DFS)
Explores deep paths first; uses recursion or a stack; good for connectivity, topological sorts, and exhaustive search.
Example choice
Shortest route by number of edges: BFS. Find any path or list components: DFS.
Complexity reminder
  • Time: both O(V + E)
  • Space: O(V) worst-case for visited + recursion stack or queue
  • Memory pattern differs: BFS stores frontier breadth, DFS stores depth path
Key Takeaway
Match traversal to your goal: distance guarantees favor BFS; exhaustive checks favor DFS.
