Module 06 › Chapter 6.5 › Connected Components with DFS
Process
  1. Collect all nodes including neighbors so isolated nodes are included.
  2. Iterate each node; if unvisited, start a DFS to collect that component.
  3. Append the sorted component list to the components result for deterministic output.

Concrete examples
Example: a graph with two clusters {'A','B','C'} and {'D','E','F'} returns [['A','B','C'], ['D','E','F']]. Include isolated nodes as single-node components.
Key Takeaway
Repeated DFS across unvisited nodes partitions an undirected graph into connected components in O(V + E) time.
