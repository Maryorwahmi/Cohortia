Module 06 › Chapter 6.5 › Quick quiz and pitfalls
Assessment idea
Given the directed graph from the chapter, performing BFS from '0' yields the visitation order 0, 1, 2, 3, 4. This tests understanding of layer-by-layer traversal. Ensure students justify why '3' appears after both '1' and '2'.
Common Pitfalls
  • Forgetting to include neighbor-only nodes in the node set.
  • Expecting DFS to return shortest paths.
  • Not marking visited consistently, causing duplicates or infinite loops.
Reflection prompt
If you only need to know whether a path exists between two cities, which traversal will you pick and why? If you need the fewest number of roads between cities, which traversal is required?
Answer guide
Existence: either DFS or BFS. Fewest edges: BFS.
