Graph basics
Nodes, edges, directed/undirected, weighted/unweighted and cycles are core terms you must use precisely.
Representations
Adjacency matrix: O(V²), O(1) edge checks. Adjacency list: O(V+E), efficient neighbor iteration.
Traversal
BFS finds shortest paths by edge count with a queue. DFS explores deeply using recursion or a stack; use visited to avoid cycles.
Final takeaway

Model your domain correctly, choose representation based on density and operations, and always track visited nodes when traversing graphs.
