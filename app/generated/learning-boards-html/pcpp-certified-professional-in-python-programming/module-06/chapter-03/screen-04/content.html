Core Concept

Graph terminology

Precise definitions make code and reasoning reliable. Use these terms when designing structures or describing algorithms.

Node / Vertex
An entity such as a user or location.
Edge
A connection between two nodes; may be directed or weighted.
Path & Cycle
A sequence of edges; cycle returns to its start node.
Examples & contrasts
  • Directed: follower graph (A follows B) — edges are one-way.
  • Undirected: friendship — edges are symmetric, represented twice in adjacency list or mirrored in matrix.
  • Weighted: road distances, where the edge stores cost instead of just existence.
Key Takeaway

Pick directed or weighted models to reflect real relationships; otherwise algorithm assumptions will be wrong.

Common mistake

Assuming an undirected edge when the domain requires direction leads to incorrect reachability results.
