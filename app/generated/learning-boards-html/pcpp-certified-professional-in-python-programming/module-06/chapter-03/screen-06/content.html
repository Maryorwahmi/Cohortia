Definition

Adjacency List

A mapping from node to a list or set of its neighbors. Space is O(V + E).

Pros & Cons
  • Pros: memory efficient for sparse graphs, neighbor iteration proportional to degree.
  • Cons: membership checks may be O(degree) unless you use sets.
Common mistake
Not initializing entries for nodes leads to key errors or missing isolated vertices.
Code example
# Adjacency List representation (unweighted, undirected)
num_vertices = 4
adj_list = {i: [] for i in range(num_vertices)}  # Initialize with empty lists

def add_edge_list(graph, u, v):
    graph[u].append(v)
    graph[v].append(u)  # For undirected graph

add_edge_list(adj_list, 0, 1)
add_edge_list(adj_list, 0, 2)
add_edge_list(adj_list, 1, 2)
add_edge_list(adj_list, 2, 3)

print("Adjacency List:")
for node, neighbors in adj_list.items():
    print(f"{node}: {neighbors}")
# Expected:
# 0: [1, 2]
# 1: [0, 2]
# 2: [0, 1, 3]
# 3: [2]
Key Takeaway

Adjacency lists are the practical choice for large, sparse graphs; initialize nodes and consider sets for fast membership tests.
