Core Concept

Depth-First Search

Explore a path to its end before backtracking. Use recursion or an explicit stack based on graph size and recursion limits.

When to use
Cycle detection, connected components, and when deep exploration reveals structure you need to analyze.
Common mistake
Forgetting visited set causes infinite recursion on cycles; recursion depth may exceed limits on very large graphs.
Code example (recursive)
def dfs(graph, start_node):
    visited = set()
    traversal_order = []

    def _dfs_recursive(node):
        visited.add(node)
        traversal_order.append(node)
        for neighbor in graph[node]:
            if neighbor not in visited:
                _dfs_recursive(neighbor)

    _dfs_recursive(start_node)
    return traversal_order

# Example: dfs(adj_list, 0)
Key Takeaway

DFS is a depth-first exploration that requires a visited set and careful handling of recursion limits; it is excellent for structural problems but not shortest-path by edge count.
