Exercise

Find connected components

Fill the dfs_helper in the template, run the provided tests, and verify components are returned as lists of node indices.

Hints
  • Add node to current_component then mark visited.
  • Recursively visit unvisited neighbors.
  • Use a new current_component list for each start node.
Test graphs
graph1 = {
    0: [1, 2],
    1: [0],
    2: [0],
    3: [4],
    4: [3, 5],
    5: [4],
    6: []
}
# Expected: [[0,1,2], [3,4,5], [6]]

graph2 = {
    0: [1],
    1: [0],
    2: [3],
    3: [2]
}
# Expected: [[0,1], [2,3]]
Key Takeaway

Correct DFS implementation plus proper initialization yields the connected components for any undirected graph.
