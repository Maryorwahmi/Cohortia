Definition

Adjacency Matrix

A V by V array where entry i,j stores 1 or a weight when an edge exists from node i to node j.

Pros & Cons
  • Pros: O(1) edge check.
  • Cons: O(V²) space, O(V) neighbor iteration.
Common mistake
Using a matrix for a large sparse network wastes memory and slows neighbor loops.
Code example
# Adjacency Matrix representation (unweighted, undirected)
num_vertices = 4
adj_matrix = [[0] * num_vertices for _ in range(num_vertices)]

def add_edge_matrix(matrix, u, v):
    matrix[u][v] = 1
    matrix[v][u] = 1  # For undirected graph

add_edge_matrix(adj_matrix, 0, 1)
add_edge_matrix(adj_matrix, 0, 2)
add_edge_matrix(adj_matrix, 1, 2)
add_edge_matrix(adj_matrix, 2, 3)

print("Adjacency Matrix:")
for row in adj_matrix:
    print(row)
# Expected:
# [0, 1, 1, 0]
# [1, 0, 1, 0]
# [1, 1, 0, 1]
# [0, 0, 1, 0]
Key Takeaway

Matrix gives fast edge checks but costs O(V²) memory; choose it only for dense graphs or small V.
