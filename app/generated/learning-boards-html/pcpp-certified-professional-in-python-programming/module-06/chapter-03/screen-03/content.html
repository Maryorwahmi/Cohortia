When to pick which representation
  • Adjacency Matrix: small dense graphs, constant-time edge checks.
  • Adjacency List: large sparse graphs, efficient neighbor iteration and lower memory.
  • Directed graphs: store directed edges; undirected graphs often mirror edges for both directions.

Traversal applications
  • BFS: shortest path in unweighted graphs, reachable set within k hops.
  • DFS: connected components, cycle detection, and topological preparation.
  • Always use a visited set to avoid infinite loops on cyclic graphs.
