Adjacency Matrix vs Adjacency List

Understand the cost model to make the right representation choice for your application.

Space & Time trade-offs
Adjacency Matrix
  • Space: O(V²)
  • Edge check: O(1)
  • Iterate neighbors: O(V)
Adjacency List
  • Space: O(V + E)
  • Edge check: O(degree) or O(1) with set
  • Iterate neighbors: O(degree)
When matrix wins
Small V and frequent arbitrary edge checks.
When list wins
Large sparse graphs and neighbor iteration operations.
Careful with
Undirected graphs require mirroring; directed graphs do not.
