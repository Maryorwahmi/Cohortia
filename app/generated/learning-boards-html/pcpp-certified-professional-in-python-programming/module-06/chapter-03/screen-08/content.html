Process Flow

Breadth-First Search

Explore level by level using a queue; ideal for shortest path by edges in unweighted graphs.

Steps
  1. Enqueue start node and mark visited.
  2. Dequeue node, visit it, enqueue its unvisited neighbors.
  3. Repeat until queue empty.
Example
Starting at 0 on adjacency list [0:[1,2],1:[0,2],2:[0,1,3],3:[2]], BFS order: 0, then 1 and 2, then 3.
Code example
from collections import deque

def bfs(graph, start_node):
    visited = set()
    queue = deque([start_node])
    visited.add(start_node)
    traversal_order = []

    while queue:
        current_node = queue.popleft()
        traversal_order.append(current_node)

        for neighbor in graph[current_node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    return traversal_order

# Example call: bfs(adj_list, 0)
Key Takeaway

BFS uses a queue and a visited set to find shortest paths by edges; it is not for weighted shortest path problems.
