Representation
Adjacency Matrix: O(V²). Adjacency List: O(V+E). Match to density.
Traversal
BFS: queue, shortest by edges. DFS: recursion/stack, deep exploration.
Implementation
Initialize nodes, mirror undirected edges, and use a visited set.
Keep this snippet in mind: BFS uses a queue and visited set; DFS uses recursion or explicit stack and visited set. These patterns are reusable across many graph tasks.
