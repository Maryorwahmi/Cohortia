Core Concept › Stack — LIFO
Stack definition and pattern
Last-In, First-Out. Push to add, pop to remove the most recent element. Ideal for undo stacks, call stacks, and parsing tasks.
Metaphor
Think of a tidy stack of plates: you place plates on top and remove from the top.
Common mistake
Using list.pop(0) or popping without checking emptiness leads to O(n) behavior or IndexError. Guard state before popping.
Key Takeaway

For LIFO patterns, use list.append and list.pop at the end to preserve average O(1) performance and simplicity.

Code example
# Stack implementation using Python's list
stack = []

# Push elements
stack.append('A')
stack.append('B')
stack.append('C')
print('Stack after pushes:', stack)  # ['A', 'B', 'C']

# Pop elements
if stack:
  popped_item = stack.pop()
  print('Popped:', popped_item)  # 'C'
print('Stack after pop:', stack)  # ['A', 'B']
Example scenario
Browser back history: each visit appends a URL; back removes the top. If the history is empty, back returns None or does nothing.
