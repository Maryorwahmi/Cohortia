Pythonic ADTs: Stack, Queue, Linked List
Practical patterns, common pitfalls, and when to implement custom structures in Python.
Interactive 16:9 Masterclass
Why this chapter matters

Choosing the right ADT affects performance and simplicity. We'll compare Pythonic options and show how a small custom linked list works under the hood so you can reason about pointer updates and complexity.

Target skills
  • Implement and use stack and queue patterns
  • Build a basic singly linked list
  • Analyze time complexity for common operations
Real-world analogies anchor the concepts: a stack of plates for LIFO, a grocery line for FIFO, and a chain of nodes for linked lists.
