Scenario-driven selection
Undo / back stack
Use list.append and list.pop for simple, fast LIFO behavior.
Task queues
Use collections.deque for efficient FIFO processing at scale.
Frequent middle modifications
Consider a linked list when you need pointer-level insert/delete and can accept linear access time by index.
Memory and performance note
Linked lists use extra memory per node for pointers. If memory per element matters and indexed reads are common, prefer arrays or Python lists.
