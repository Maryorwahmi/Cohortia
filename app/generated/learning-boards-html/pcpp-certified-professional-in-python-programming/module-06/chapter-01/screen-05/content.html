Definition › Parentheses validation
How the algorithm works
  1. Iterate characters in the expression.
  2. Push any opening symbol onto the stack.
  3. On a closing symbol, check stack non-empty then pop and compare types.
  4. At the end, ensure the stack is empty to confirm valid nesting.
Common mistake
Popping without checking leads to IndexError. Also, failing to match types allows incorrect nesting like an opening square bracket closed by a parenthesis.
Key Takeaway

Stacks capture nested state; always guard pops and match pairs to ensure correctness.

Code walkthrough
def is_valid(expr: str) -> bool:
  stack = []
  pairs = {'(': ')', '[': ']', '{': '}'}

  for ch in expr:
    if ch in pairs:            # opening
      stack.append(ch)
    elif ch in pairs.values(): # closing
      if not stack:
        return False           # nothing to match
      last_open = stack.pop()
      if pairs[last_open] != ch:
        return False
  return not stack              # valid if stack empty

# Example: is_valid('([{}])') -> True
Example walkthrough
Input '([{}])': push '(' then '[' then '{', then pop and match for each closing character. Final stack is empty and function returns true.
