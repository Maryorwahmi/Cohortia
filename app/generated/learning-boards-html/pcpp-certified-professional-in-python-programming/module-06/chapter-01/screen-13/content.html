Defensive coding checklist
Stacks & Queues
Always check truthiness before pop operations and provide peek/is_empty helpers to simplify client code.
Linked lists
Guard head and current checks, special-case head deletion, and add methods to encapsulate pointer changes.
Prefer built-ins
Use list and deque for common patterns; implement custom linked lists only when you need explicit node control.
Helper methods
Implement is_empty, peek/current_page, and size when helpful to centralize checks and reduce bugs.
