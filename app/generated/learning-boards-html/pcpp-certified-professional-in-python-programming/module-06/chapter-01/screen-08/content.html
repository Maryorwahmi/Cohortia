Process Flow › Append and Prepend
Append — steps
  1. Create new node with data.
  2. If head is None set head to new node.
  3. Otherwise traverse to last node.
  4. Set last_node.next to new node.
Prepend — steps
  1. Create new node.
  2. Set new_node.next to head.
  3. Set head to new_node.
Pro Tip

If you need frequent appends, keep a tail pointer to make append O(1) and avoid repeated traversal.

Code examples
def append(self, data):
  new_node = Node(data)
  if not self.head:
    self.head = new_node
    return
  last = self.head
  while last.next:
    last = last.next
  last.next = new_node

def prepend(self, data):
  new_node = Node(data)
  new_node.next = self.head
  self.head = new_node
Example result
Starting empty, prepend 0 then append 1 and 2 yields 0 -> 1 -> 2 -> None. Append traverses to the end unless you store tail.
