Operation costs at a glance
Python list (stack)
  • append: O(1) average
  • pop() from end: O(1) average
  • pop(0): O(n)
collections.deque (queue)
  • append / appendleft: O(1)
  • pop / popleft: O(1)
  • good for FIFO and double-ended patterns
Singly Linked List
  • insert/delete at known node: O(1)
  • append without tail: O(n)
  • access by index: O(n)
Practical decision rule
List for end-only operations, deque for front/back operations at scale, linked list when pointer-level local updates matter more than indexed access speed.
