Definition › Linked List fundamentals
Nodes and head
Each node stores data and a next reference. The head points at the first node. Traversal follows next references until None.
Strengths
Efficient local insertions and deletions when you have a node reference; low work to update pointers.
Limitations
Random access by index is linear time. Handling None carefully is essential to avoid runtime errors.
Key Takeaway

Use linked lists when frequent pointer-level insertions or removals matter more than indexed access speed.

Node and LinkedList example
class Node:
  def __init__(self, data):
    self.data = data
    self.next = None

class LinkedList:
  def __init__(self):
    self.head = None
Analogy
Think of each node as a link in a chain. If you break the chain at a point, reattaching requires updating only nearby links.
