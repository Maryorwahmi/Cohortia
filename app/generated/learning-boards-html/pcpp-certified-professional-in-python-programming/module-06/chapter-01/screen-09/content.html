Delete node algorithm
  1. If head is None return immediately.
  2. If head.data matches key, set head to head.next and return.
  3. Return if key not found.
Edge cases
Empty list, deleting head, deleting only node, and non-existent key. Always check for None before accessing next or data.

Code snippet
def delete_node(self, key):
  current = self.head
  if current and current.data == key:
    self.head = current.next
    return

  prev = None
  while current and current.data != key:
    prev = current
    current = current.next

  if current is None:
    return  # key not found

  prev.next = current.next
