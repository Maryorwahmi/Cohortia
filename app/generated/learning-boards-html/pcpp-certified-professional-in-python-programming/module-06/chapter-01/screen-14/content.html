Abstract Data Type
Defines behavior independent of implementation; pick the implementation that satisfies the contract.
Stack with list
Use append and pop at the end for idiomatic LIFO with average O(1) operations.
Deque for queues
collections.deque supports O(1) operations at both ends, ideal for FIFO behavior at scale.
Takeaway
Match data structure choice to dominant operations and guard operations with simple helper methods to reduce errors.
