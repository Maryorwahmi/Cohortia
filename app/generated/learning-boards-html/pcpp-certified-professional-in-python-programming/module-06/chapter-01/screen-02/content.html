Learning Objectives
Learn, Understand, Apply, Master — targeted outcomes for this chapter.
Bloom: Learn → Understand → Apply → Master
01
Understand core ADT principles
Define LIFO and FIFO behavior and identify how stacks, queues, and linked lists respond to inserts and removals. Visual mnemonics: plates and grocery line.
VERIFIED COMPETENCY MILESTONE
02
Implement stacks & queues
Use list for stack operations and collections.deque for efficient queues. Mnemonic: append/pop for last-in, popleft for first-out.
VERIFIED COMPETENCY MILESTONE
03
Build a singly linked list
Create Node and LinkedList classes to practice pointer manipulation. Mnemonic: chain links show next references.
VERIFIED COMPETENCY MILESTONE
04
Analyze complexity and use cases
Compare O(1) and O(n) behaviors and decide when linked lists are preferable to arrays or built-ins. Mnemonic: constant vs linear bars.
VERIFIED COMPETENCY MILESTONE
