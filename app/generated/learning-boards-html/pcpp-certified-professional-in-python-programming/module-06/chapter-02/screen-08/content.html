Definition

Min-Heap & Max-Heap

Parent-child ordering and completeness allow fast access to minima or maxima and efficient array storage.

Array mapping
Using zero-based arrays: left = 2*i+1, right = 2*i+2. This mapping keeps the tree compact and avoids explicit pointers.
data = [1, 3, 7, 4] # root is 1
Operations
Insert: append then sift up. Pop root: swap with last, pop, then sift down. Each sift touches at most the tree height.
Concrete example

Adding 2 to [1,3,7,4] yields [1,2,7,4,3] after sifting to maintain the min-heap property.

Misconception

A heap does not maintain full sorted order; repeated pops produce sorted output but destroy the heap unless copied.

Why choose heaps

Heaps are ideal when you need fast access to the current minimum or maximum as the dataset changes frequently.
