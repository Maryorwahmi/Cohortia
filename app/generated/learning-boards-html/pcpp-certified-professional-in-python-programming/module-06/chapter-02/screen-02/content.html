01
Differentiate tree structures

Explain how binary trees, BSTs and heaps differ in shape and ordering. Knowing this distinction helps you select the right tool for search versus priority tasks.

Mnemonic: Think "left smaller, right larger" for BSTs.

02
Implement BST core ops

Write insert and search methods using recursion or iteration, and reason about base cases and pointer updates during traversal. This ensures correct ordering is preserved.

Visual mnemonic: small flowchart of compare → descend.
VERIFIED COMPETENCY MILESTONE
03
Understand Min-Heap and Max-Heap

Learn the heap property and how a complete tree maps to an array so parent/child indices are computed in constant time.

Mnemonic: array indices 2*i+1, 2*i+2 map children.
VERIFIED COMPETENCY MILESTONE
04
Use Python's heapq

Apply heappush, heappop and heapify to create efficient priority queues, and practice the event scheduler lab to solidify the pattern.

Mnemonic: heapq is a min-heap by default; use (priority, item) tuples.
