Enforce BST invariants
Visually confirm pointer updates when inserting or deleting to avoid broken order.
Use index math for heaps
Remember left = 2*i+1 and right = 2*i+2 for array-backed heaps.
Prefer heapq API
heappush/heappop/heapify preserve heap invariants; store priorities as tuples.
Final takeaway

Pair the right structure with the right operations: BSTs for sorted access, heaps for priority extraction, and test small cases to validate your implementations.
