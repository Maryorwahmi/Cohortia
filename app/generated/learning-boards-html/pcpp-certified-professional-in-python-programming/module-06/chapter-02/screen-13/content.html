Module 6 › Chapter 6.2 › Debug & test
BST tests
  • Insert sequence and verify in-order traversal equals sorted list.
  • Delete leaf, delete node with one child, delete node with two children — verify structure each time.
  • Search missing and present keys, including root.
Quick test

A failing in-order traversal after deletes usually points to pointer reassignment bugs in deletion logic.

Heap tests
  • After heapify, check that data[0] is the smallest element.
  • Repeatedly pop and assert the popped sequence is non-decreasing for a min-heap.
  • Ensure all modifications use heapq functions, not direct list changes.
Debugging tip

Printing the heap array after each operation helps visualize sifts and spot where the heap property fails.

Checklist
Include edge-case tests for empty structures, duplicates, and operations that change tree shape. Small, deterministic sequences catch pointer and ordering regressions quickly.
