Module 6 › Chapter 6.2 › BST vs Heap
Binary Search Tree

Ordered storage

  • In-order traversal yields sorted sequence.
  • Efficient membership and range queries when balanced.
  • Worst-case O(n) if degenerated into a chain.
Example

Store user IDs for range queries and membership checks with a BST rather than a heap.

Heap

Priority extraction

  • Complete tree mapped to array; parent-child indices computed directly.
  • O(log n) push/pop, O(1) peek for extreme element.
  • Does not support ordered traversal without repeated pops.
Example

Use a min-heap for an event scheduler to always process the earliest event next.
