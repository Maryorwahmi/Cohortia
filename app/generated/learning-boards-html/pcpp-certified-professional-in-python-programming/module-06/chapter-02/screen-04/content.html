Module 6 › Chapter 6.2 › What is a BST?
Definition

Binary Search Tree

A binary tree with the invariant that left subtree values are smaller and right subtree values are larger than each node. This invariant enables ordered search and traversal.

Why it matters
Maintains sorted order implicitly, so in-order traversal yields a sorted sequence without extra sorting steps.
Common mistake
Inserting sorted input without balancing can create a degenerate tree with O(n) operations instead of O(log n).
Key Takeaway

BST ordering is the property that grants efficient search; preserving it during modifications is essential.

Illustration & Example
Tree snapshot and insertion sequence example.
Insert sequence: 50, 30, 70, 20, 40, 60, 80
In-order result: [20, 30, 40, 50, 60, 70, 80]
Concrete example
Searching for 40 compares 40 to 50, goes left to 30, then right to 40 and finds it—only two comparisons after the root.
Misconception check
Do not assume the tree is balanced. Balanced trees require additional structure or rebalancing strategies not covered here.
