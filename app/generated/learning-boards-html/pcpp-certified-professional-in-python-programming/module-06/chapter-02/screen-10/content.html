Example code
This snippet demonstrates pushes, pops, and heapify. Observe the array representation after each operation.
import heapq

# Min-heap using heapq
min_heap = []
heapq.heappush(min_heap, 4)
heapq.heappush(min_heap, 1)
heapq.heappush(min_heap, 7)
heapq.heappush(min_heap, 3)
print(min_heap)  # root is smallest, e.g. [1, 3, 7, 4]

smallest = heapq.heappop(min_heap)
print(smallest)  # 1
print(min_heap)  # e.g. [3, 4, 7]

# Build a heap from a list
data = [10, 2, 8, 5, 1]
heapq.heapify(data)
print(data)  # transforms into a heap, e.g. [1, 2, 8, 5, 10]

# Priority queue using tuples
pq = []
heapq.heappush(pq, (2, 'Task B'))
heapq.heappush(pq, (1, 'Task A'))
heapq.heappush(pq, (3, 'Task C'))
while pq:
  priority, task = heapq.heappop(pq)
  print(task, priority)
Explanation & tips
  • heapq implements a min-heap; the smallest element is at index zero.
  • Use tuples for priorities: (priority, item). Python compares tuples by first element.
  • To simulate max-heap, push negative priorities or store custom comparison keys externally.
Concrete analogy

Think of heapq as a waiting line where the person with the earliest time always stands at the front automatically.
