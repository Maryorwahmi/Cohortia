Index relationships
Remember these formulas when you implement array-backed heaps:
  • Left child: 2 * i + 1
  • Right child: 2 * i + 2
  • Parent: (i - 1) // 2
Concrete example

For index 3, left child is 7 and parent is 1. Use integer division for the parent formula.

Complexity
Height of a complete binary tree is roughly log base 2 of n, so sifting operations touch at most that many levels, making push/pop O(log n) and peek O(1). Heapify builds in O(n) by sifting down from non-leaf nodes.
Practical note

Prefer heappush/heappop to preserve invariants. If you need a max-heap, invert priorities or store negative values.

Common pitfall

Direct list mutation without heap functions can leave the structure invalid and cause wrong results.
