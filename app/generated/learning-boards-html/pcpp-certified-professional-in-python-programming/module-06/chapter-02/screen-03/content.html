Time complexity

Compare best, average, and worst cases for BST and heap operations and what triggers the degenerate cases.

  • BST: O(log n) average for balanced trees; O(n) worst if tree becomes a chain.
  • Heap: O(log n) push/pop and O(1) peek for min/max at root.
