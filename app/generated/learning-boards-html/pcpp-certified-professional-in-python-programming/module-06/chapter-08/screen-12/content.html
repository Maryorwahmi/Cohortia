Red-Black Trees
Color properties that limit path length
1. Every node is red or black.
2. The root is black.
3. Every leaf (NIL) is black.
4. If a node is red, both its children are black.
5. For each node, all paths to descendant leaves contain the same number of black nodes (black-height).
Why colors help
Colors let the tree use cheap recolorings to fix many violations without rotations, reducing pointer churn during updates.
Black-height
Black-height equality makes sure no path can be more than twice as long as another. This is the core balancing guarantee for RBTs.
Key Takeaway

Red-Black Trees use color invariants and occasional rotations to keep path lengths within a small constant factor of each other.
