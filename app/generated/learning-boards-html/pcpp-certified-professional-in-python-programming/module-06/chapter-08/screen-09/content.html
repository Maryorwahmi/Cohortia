Module 7 › Chapter 6.8 › AVL Rotations: RL & Bookkeeping
Right-Left (RL) Case
Two rotations: right on child, left on parent
After performing pointer updates, recalculate heights for the nodes that moved. Typically compute height(child) first, then height(parent). Correct ordering prevents transient incorrect balance factors from propagating.
Implementation tip
When writing rotation code, return the new subtree root from the rotation function so callers can relink parent pointers cleanly and then update heights in a deterministic order.
Common mistake
Forgetting to update the parent reference or height after a rotation causes later balance checks to be incorrect.
Key Takeaway

Rotation logic must include pointer relinks and bottom-up height updates to reliably restore AVL invariants.
