Self-Balancing Trees
Local fixes, global guarantees
  • Detect a node whose local metric (height or color property) is violated.
  • Apply local transformation(s): rotations, recoloring, or node split/merge.
  • Update local metadata such as height or color and propagate if needed.
Concrete scenario
After inserting a value, a node's balance factor becomes 2 or -2. A rotation fixes the imbalance locally and lowers the height of that subtree, restoring the global O(log N) bound.
Misconception
Balancing does not rebuild the whole tree. Only a few nodes change pointers or colors, keeping cost amortized and local.
Mental model
Think of balance as a local thermostat: small, local actions keep the whole system within a temperature band.
Key Takeaway

Local transformations keep the tree balanced globally and avoid expensive rebuilds.
