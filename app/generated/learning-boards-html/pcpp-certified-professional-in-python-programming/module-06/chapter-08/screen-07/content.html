Left-Left (LL) Case
Single right rotation rebalance
Steps to correct an LL imbalance: identify pivot (left child), perform right rotation around the unbalanced node, move pivot’s right subtree to the unbalanced node’s left, and update heights.
Concrete transformation
# Initial (A is unbalanced, left-heavy)
#       A
#      / \
#     B   T3
#    / \
#   C   T2
#  / \
# T0  T1

# Right rotation around A yields:
#      B
#     / \
#    C   A
#       / \
#     T2  T3
Only nodes A, B and B’s right subtree are relinked. Heights for A and B must be recalculated after the rotation.
Why it works
The rotation moves the heavier branch upward and reduces the difference between left and right heights at the former root.
Key Takeaway

LL uses one right rotation and affects only a small set of nodes, making it an efficient local fix.
