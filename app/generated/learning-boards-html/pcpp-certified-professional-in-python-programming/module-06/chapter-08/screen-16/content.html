Module 7 › Chapter 6.8 › What to Remember
Balance = Height
Height drives complexity; preserve it with local fixes to keep O(log N).
Rotations are local
LL, RR, LR, RL relink a few pointers and update a few heights—practice them conceptually first.
Match structure to workload
AVL: strict reads. RBT: fewer rotations on writes. B-tree: disk I/O minimization.
Final Note

When designing systems, pick the tree whose invariants and costs align with your read/write patterns and storage medium.
