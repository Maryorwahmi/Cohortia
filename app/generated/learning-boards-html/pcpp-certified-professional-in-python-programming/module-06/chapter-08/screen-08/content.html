Module 7 › Chapter 6.8 › AVL Rotations: RR & LR
Right-Right (RR)
Single left rotation fixes right-right imbalance.
When a node is right-heavy because its right child is right-heavy, perform a left rotation around the node so the right child becomes the subtree root and balance is restored locally.
Left-Right (LR)
Double rotation: left on child, then right on parent.
LR transforms the shape into a pure LL case with the first rotation, then resolves it with a second rotation. Two small pointer updates replace many possible re-links if you tried to rebalance globally.
Concrete example (LR)
# Initial (A unbalanced, left-right heavy)
#       A
#      / \
#     B   T3
#    / \
#  T0  C
#      / \
#     T1 T2

# Step 1: left rotate B around C
# Step 2: right rotate A around new pivot
# Final: C becomes subtree root, balanced heights adjusted
Key Takeaway

RR is a single left rotation, LR uses two rotations to transform into and then fix an LL shape; both are local and efficient.
