#    / \

# New node inserted into C's left subtree making B left-heavy and A balance factor 2
Rotation Steps
# Right rotation around A:
# 1. Let pivot = B
# 2. A.left = pivot.right  (A.left = T2)
# 3. pivot.right = A
# 4. Update parent pointers for A and pivot
# 5. Recompute heights: height(A), then height(pivot)

# Resulting tree:
#      B
#     / \
#    C   A
#       / \
#     T2  T3
Key Takeaway

Perform rotations as small, deterministic rewires and recompute heights bottom-up to preserve invariants.
