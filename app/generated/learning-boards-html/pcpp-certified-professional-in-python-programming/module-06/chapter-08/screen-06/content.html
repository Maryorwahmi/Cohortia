AVL: balance factor
Store node heights and keep their difference within [-1, 1]
Each node stores its height so the balance factor can be computed in O(1). When a child changes height, update the parent and check the balance factor. If it is 2 or -2, choose the appropriate rotation pattern to restore the invariant.
Example
If left subtree height is 5 and right subtree height is 3, balance factor is 2 and the node is left-heavy, requiring a rightward correction.
Misconception
AVL’s strictness does not always mean faster overall performance; extra rotations on writes can make it slower for update-heavy workloads.
Mnemonic
Balance factor is left minus right: think left hand minus right hand equals the balance reading.
Key Takeaway

AVL enforces tight height bounds using a numeric balance factor and node heights, trading some write cost for improved worst-case search time.
