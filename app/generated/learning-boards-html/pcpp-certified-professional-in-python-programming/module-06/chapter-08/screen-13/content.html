Module 7 › Chapter 6.8 › RBT Rebalancing
Insert fix overview
Color the new node red and apply recolor/rotate patterns as needed.
  1. If parent is black: done.
  2. If parent and uncle are red: recolor parent and uncle black, grandparent red; repeat upward.
  3. If parent is red and uncle is black: perform rotations with recoloring based on insertion side.
Why fewer rotations
Many conflicts are resolved by recoloring alone, avoiding pointer changes. This reduces rotation frequency on average compared to AVL.
Misconception
Red-Black logic is not trivial; deletions especially require careful case handling even though recoloring often helps for insertions.
Key Takeaway

Red-Black rebalancing favors recoloring first and uses rotations when necessary, often yielding fewer rotations than AVL for updates.
