Comparison › Memoization vs Tabulation
Memoization
Top-down, cache on demand, easy to derive from recursion, watch recursion depth and cache initialization.
Tabulation
Bottom-up, explicit iteration, often lower constants, easy to optimize memory with rolling arrays.
Shared result
Both transform an exponential recursive solution into efficient polynomial-time code when the DP signals are present.
Concrete example
Fibonacci: both approaches are O(n) time and O(n) space; tabulation avoids recursion overhead and is straightforward to reduce to O(1) space using two variables.
Misconception check

Neither method magically reduces space; choose the approach that makes indexing and optimization clearer for your problem.
