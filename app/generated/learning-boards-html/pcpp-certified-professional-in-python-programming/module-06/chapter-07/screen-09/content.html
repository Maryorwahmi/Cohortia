Definition › Longest Common Subsequence
2D dp table and recurrence

State: dp[i][j] = length of LCS for prefixes of length i and j. Base cases are zeros along the top and left edges.

for i in range(1, m + 1):
  for j in range(1, n + 1):
    if text1[i - 1] == text2[j - 1]:
      dp[i][j] = 1 + dp[i - 1][j - 1]
    else:
      dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
This fills the table in O(m*n) time and O(m*n) space. To reconstruct one LCS, backtrack from dp[m][n] and follow the choices where characters matched or which neighbor provided the max.
Concrete example
text1 = "AGGTAB", text2 = "GXTXAYB". Following the recurrence yields length 4 with subsequence "GTAB".
Misconception

Subsequence is not substring. Expect to skip characters and use the choice max to decide which prefix to shorten.
