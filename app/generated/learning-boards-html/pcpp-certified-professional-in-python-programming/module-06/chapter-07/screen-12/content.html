Process Flow › DP workflow
Five steps
  1. Detect optimal substructure and overlapping subproblems.
  2. Define the dp state clearly in one sentence.
  3. Formulate the recurrence relation.
  4. Choose base cases and iteration order.
  5. Implement, test, and optimize space if possible.
Example checklist
For LCS, state: dp[i][j] is LCS length for prefixes; recurrence: match or max of neighbors; base: zeros along edges; iterate i and j increasing.
Key reminder

Don’t code before you can state the dp definition and recurrence in plain English.
