Naive recursion

A function that calls itself twice per non-base case creates a binary tree of calls. Many leaves repeat internal subcalls.

Trace example
# Pseudocode-style trace, not executed here
fib_naive(5)
  fib_naive(4)
    fib_naive(3)
      fib_naive(2)
      fib_naive(1)
    fib_naive(2)
  fib_naive(3)
    fib_naive(2)
    fib_naive(1)
Takeaway

Count repeated calls to see the redundancy before applying caching.

Overlapping calls visualization
fib(3) appears multiple times
Each duplicate is avoidable with a cache
Misconception: recursion is not always slow; sometimes recursion with memoization is fast. The cost comes from recomputation, not recursion itself.
