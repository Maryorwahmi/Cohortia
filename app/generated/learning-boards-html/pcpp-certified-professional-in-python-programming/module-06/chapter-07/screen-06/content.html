Definition › Memoization
Pattern

Check cache, compute if absent, store result, return cached value on later requests.

Python example
def fib_memoization(n, memo=None):
  if memo is None:
    memo = {}
  if n in memo:
    return memo[n]
  if n <= 1:
    return n
  result = fib_memoization(n - 1, memo) + fib_memoization(n - 2, memo)
  memo[n] = result
  return result
Note how memo is initialized safely inside the function to avoid state leaking between calls.
When to choose memoization
  • You prefer a direct translation of a recursive recurrence.
  • The recursion depth is safe for your runtime environment.
  • You need to avoid writing an explicit iteration order for complex state spaces.
Common mistake

Using memo={} as a default argument causes the dictionary to persist across calls. Initialize the cache inside the function instead.
