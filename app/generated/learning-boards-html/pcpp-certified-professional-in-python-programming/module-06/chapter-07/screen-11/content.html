Iterative dp for minimum coins

Define dp[i] as minimum coins for amount i. Initialize with a sentinel and update by trying each coin for each amount.

def coin_change_min_coins(coins, amount):
  dp = [amount + 1] * (amount + 1)
  dp[0] = 0
  for i in range(1, amount + 1):
    for coin in coins:
      if i - coin >= 0:
        dp[i] = min(dp[i], 1 + dp[i - coin])
  return dp[amount] if dp[amount] <= amount else -1
Example: coins [1,2,5], amount 11 returns 3. Be careful to use amount+1 as a sentinel to represent unreachable states.
Edge cases
If amount is 0 return 0. If dp[amount] is still sentinel, return -1 to indicate impossibility.
Pro tip

Iterate amounts as outer loop and coins as inner loop so each dp[i] sees all coin choices.
