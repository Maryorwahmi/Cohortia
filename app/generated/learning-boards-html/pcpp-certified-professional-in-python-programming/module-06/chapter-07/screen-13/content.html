Common Mistakes › Pitfalls & Optimizations
Indexing errors

Choose dp size carefully and map problem indices to dp indices to avoid off-by-one bugs.

Cache initialization

Do not use mutable defaults for memo. Initialize caches on first call or pass explicit caches.

Memory optimization

When dp depends on k previous states, keep a rolling window of size k to cut memory usage.

Validation checklist
  • Test small inputs where brute force is easy to verify.
  • Check base cases and unreachable sentinels explicitly.
  • Measure recursion depth and consider tabulation if stack is a concern.
