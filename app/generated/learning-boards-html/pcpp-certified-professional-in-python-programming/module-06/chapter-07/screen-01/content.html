Dynamic Programming
Solve optimization problems by storing and reusing subproblem results.
Why it matters

DP converts exponential solutions into efficient polynomial-time algorithms. It is essential for algorithmic interviews and performance-critical code.

Analogy

Build a large structure from prefabricated components: compute each component once, then reuse it where needed.

Core properties

Optimal substructure and overlapping subproblems are the two signals that DP applies.

Common pitfall

Confusing memo persistence in default arguments; always initialize caches safely.
