Process Flow › 0/1 Knapsack
Choice-based dp

State dp[i][w] expresses the maximum value using first i items with capacity w. The recurrence encodes the include or skip choice for each item.

for i in range(1, n + 1):
  for w in range(1, capacity + 1):
    if weights[i - 1] > w:
      dp[i][w] = dp[i - 1][w]
    else:
      dp[i][w] = max(dp[i - 1][w], values[i - 1] + dp[i - 1][w - weights[i - 1]])
This table computes the optimal value at dp[n][capacity]. To optimize memory, use a single array and iterate w backward so you do not reuse updated values prematurely.
Concrete example
weights = [10,20,30], values = [60,100,120], capacity = 50 produces max value 220 by choosing items 20 and 30.
Misconception

Greedy by value density is not guaranteed for 0/1 knapsack. DP correctly explores combinatorial options.
