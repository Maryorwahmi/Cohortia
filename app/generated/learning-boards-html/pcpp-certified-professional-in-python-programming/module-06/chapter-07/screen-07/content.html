Process Flow › Tabulation
Bottom-up recipe

Define the state dp[i], choose base cases, and iterate to fill dp in increasing order so each state uses previously computed values.

Python example
def fib_tabulation(n):
  if n <= 1:
    return n
  dp = [0] * (n + 1)
  dp[0] = 0
  dp[1] = 1
  for i in range(2, n + 1):
    dp[i] = dp[i - 1] + dp[i - 2]
  return dp[n]
This implementation is linear in time and space, and can be reduced to constant space by keeping only the last two values when appropriate.
When tabulation wins
  • Recursion depth is a risk or has overhead.
  • Iteration order is easy to determine from the recurrence.
  • Memory can be optimized by discarding unneeded past states.
Pro tip

If dp[i] depends on only k previous states, use a rolling window of size k to cut space to O(k).
