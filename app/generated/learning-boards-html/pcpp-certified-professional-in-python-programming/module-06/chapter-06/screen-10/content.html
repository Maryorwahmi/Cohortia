What is a negative cycle?

A cycle whose edge weights sum to a negative value. Repeated traversals reduce path cost without bound, invalidating any finite shortest-path answer for affected nodes.

Detection
After V-1 relaxation passes, perform a V-th pass. If any distance can still be reduced, report a negative cycle.
Practical handling
  • Return an explicit error or None to indicate detection.
  • List vertices reachable from the negative cycle so callers can isolate affected regions.
  • Design domain rules to prevent infinite reward stacking if appropriate.
Misconception

Negative edges alone do not break shortest paths; only cycles whose total is negative cause the infinite-decrease problem.
