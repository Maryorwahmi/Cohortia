Sample question 1
A self-driving car network has positive travel times and occasional time-saving lanes with negative weights but no negative cycles. Which algorithm do you choose and why?
Answer
Use Bellman-Ford because negative weights may appear; it safely computes shortest paths and detects cycles.
Sample question 2
All flight costs are positive. What complexity can you expect using the best common algorithm?
Answer
Dijkstra with a binary heap: O(E log V). It's efficient for sparse graphs compared with Bellman-Ford's O(V*E).
Exam tip
When justifying answers, always mention weight assumptions, data structure choices, and the algorithmic complexity trade-off to show full understanding.
