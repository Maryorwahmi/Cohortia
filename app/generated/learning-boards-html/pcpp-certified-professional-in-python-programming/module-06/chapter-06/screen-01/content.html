Shortest Path Algorithms

Learn Dijkstra's greedy approach for non-negative weights and Bellman-Ford's relaxation-based method for graphs that may contain negative edges. Implementations and trade-offs are emphasized.

Nodes, weighted edges, and solution strategies
Dijkstra

Explore Key Topics
Shortest Path Problem
Minimize the sum of edge weights between source and destination; not the fewest edges.
Priority Queue
Min-heap stores (distance, node) for fast extraction of the next closest vertex.
Negative Cycles
A cycle with negative total weight breaks the notion of a finite shortest path.
