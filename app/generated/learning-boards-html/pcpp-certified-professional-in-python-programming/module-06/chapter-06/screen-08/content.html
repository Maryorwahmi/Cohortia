Bellman-Ford mechanics
Relax every edge in the graph for V-1 iterations so improvements travel across paths of growing length. This guarantees correctness in the presence of negative edges, as long as no negative cycle is reachable from the source.
Negative cycle detection
After V-1 relaxations, run a V-th pass. If any distance still decreases, a negative cycle exists and shortest paths are undefined for affected vertices.
Key Takeaway

Bellman-Ford is necessary when negative weights matter; expect higher runtime in exchange for safety and cycle detection.

Concrete example
A cost graph where discounts are negative edges: Bellman-Ford finds the true minimal costs across chains of discounts where Dijkstra could be misled.
Misconception check

Thinking Bellman-Ford is always better because it handles negative weights ignores its O(V*E) cost; choose based on constraints.
