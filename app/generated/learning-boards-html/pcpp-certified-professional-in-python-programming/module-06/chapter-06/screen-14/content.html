Module 6 › Chapter 6.6 › Key Concepts
Shortest Path
Path minimizing the sum of weights between vertices.
Dijkstra's Algorithm
Greedy algorithm for non-negative weights using a min-heap.
Priority Queue
Use a min-heap to extract the next closest node efficiently.
Summary takeaway

Match algorithm choice to weight properties: performance for Dijkstra, correctness under negative weights for Bellman-Ford.
