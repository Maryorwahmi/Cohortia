Bellman-Ford
Use when negative weights appear; runs in O(V*E) and detects negative cycles.
Relaxation
The update step: if distance[u] + weight < distance[v], set a new distance and predecessor.
Negative Cycle
A reachable cycle whose total weight is negative makes shortest-path costs undefined.
Final takeaway

Pick the algorithm by weight properties: speed with Dijkstra when safe, or correctness and detection with Bellman-Ford when negative weights may occur.
