Dijkstra process
  1. Initialize distances with infinity except source = 0.
  2. Push (0, source) into a min-heap.
  3. While heap not empty: pop smallest pair.
  4. If popped distance > known distance, skip.
  5. Relax each neighbor: update distance and push new pair if improved.
Concrete scenario
Routing packets by latency where every link latency is non-negative: Dijkstra reliably finds minimum-latency paths.
Key Takeaway

Greedy extraction plus non-negative weights makes Dijkstra both correct and efficient when implemented with a min-heap.

Common mistake

Assuming heap entries are unique. In practice you push updated distances and lazily skip stale entries when popped. Avoid attempting a decrease-key operation manually in Python's heapq.

Pro tip
Keep a predecessors map while updating distances to reconstruct shortest paths after the algorithm completes.
