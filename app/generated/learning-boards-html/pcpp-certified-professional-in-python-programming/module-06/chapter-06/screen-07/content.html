Path reconstruction utility
from collections import deque

def reconstruct_path(predecessors, start, end):
  path = deque()
  current = end
  while current is not None:
    path.appendleft(current)
    if current == start:
      break
    current = predecessors[current]
  return list(path) if path and path[0] == start else []
This returns an empty list when a path does not exist or start was not reached during relaxation.
Example
Given predecessors {'B':'A', 'C':'B', 'D':'C'} and start 'A', end 'D', reconstruction yields ['A','B','C','D'].
Pitfall

If negative cycles exist reachable from the source, predecessors may reflect indefinite decreases; do not trust path length in that case.

Key Takeaway

Always validate that the reconstructed path begins with the start vertex to confirm reachability.
