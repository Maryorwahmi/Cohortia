Module 6 › Chapter 6.6 › Comparison
Dijkstra
  • Applicability: non-negative edge weights.
  • Data structure: min-heap with adjacency list.
  • Complexity: O(E log V) with binary heap.
Bellman-Ford
  • Applicability: negative weights allowed; detects negative cycles.
  • Data structure: edge list; repeated relaxation.
  • Complexity: O(V * E).
Practical guide
If your domain guarantees non-negative costs and you need performance at scale, choose Dijkstra. If negative weights are possible or you must detect cycles that break path semantics, choose Bellman-Ford despite its higher cost.
