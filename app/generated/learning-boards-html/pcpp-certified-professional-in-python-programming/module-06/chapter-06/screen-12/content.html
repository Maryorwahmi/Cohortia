Module 6 › Chapter 6.6 › Hands-on Activity
Activity steps
  1. Implement Dijkstra with heapq and predecessors.
  2. Test on a non-negative delivery graph and reconstruct a path to a destination.
  3. Implement Bellman-Ford using an edge list and test on a negative-weight graph without cycles.
  4. Test Bellman-Ford on a graph containing a negative cycle and confirm detection.
Testing tips
  • Ensure all nodes appear as keys in input graphs to initialize distances.
  • Compare Dijkstra and Bellman-Ford outputs on non-negative graphs for parity.
  • Measure runtimes on larger graphs to observe O(E log V) vs O(V*E) behavior.
