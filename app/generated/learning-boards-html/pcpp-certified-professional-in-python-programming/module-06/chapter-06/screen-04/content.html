Shortest Path Problem

Find a path between two vertices such that the sum of edge weights is minimal. We care about numeric weights, not edge counts.

Relaxation (atomic step)
  • Check if distance[u] + weight(u,v) < distance[v].
  • If yes, update distance[v] and set predecessor[v] = u.
  • Repeat until no improvements occur or algorithm-specific stopping condition.
Concrete example
Warehouse to homes: travel time weights may cause a longer-edge-count route to be faster overall.
Key Takeaway

Always treat edge weight semantics first; use relaxation consistently to build shortest distances.

Common misconception

Applying BFS to weighted graphs because it is 'simpler' will give paths with the fewest edges, not the minimum weight. That mistake appears when weights vary widely across edges.

Why it matters

Routing and optimization systems make decisions based on sums of weights; using the wrong algorithm produces incorrect or suboptimal routes and can cost time and money.
