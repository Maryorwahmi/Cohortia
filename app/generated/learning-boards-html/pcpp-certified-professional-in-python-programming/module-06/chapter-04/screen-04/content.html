Module 6 › Chapter 6.4 › Hash Function
Definition & properties
  • Deterministic: same key → same hash value every run.
  • Fast: computed quickly to keep operations cheap.
  • Uniform distribution: spreads keys to reduce collisions.
  • Fixed-size output: leads to inevitable collisions for large key spaces.
Metaphor
Hashing is like assigning locker numbers from names. The function computes a locker number deterministically so the same name always goes to the same locker.
Concrete example
def _hash(key, capacity):
    # conceptual example - not Python's exact implementation
    hv = hash(key)          # built-in hash for immutable types
    return hv % capacity    # map to bucket index
This shows the common modulo mapping from hash value to array index.
Key Takeaway

Hash functions trade infinite inputs for fixed-size outputs; design or choose them to be fast and uniformly distributing.
