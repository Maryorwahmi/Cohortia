Module 6 › Chapter 6.4 › Pitfalls & Practices
Common mistakes
  • Using mutable objects as keys
  • Implementing __eq__ without __hash__
  • Relying on O(1) in adversarial inputs
Best practices
  • Prefer immutable built-in types as keys
  • Base __hash__ on immutable identity attributes
  • Monitor load factor and allow resizing
Check your understanding
Which of these can be used as keys without extra work: int, str, tuple, list? (Answer: int, str, tuple.)
