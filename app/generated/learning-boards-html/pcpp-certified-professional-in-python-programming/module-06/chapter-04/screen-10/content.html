Minimal safe pattern
class User:
    def __init__(self, id, name):
        self.id = id            # stable, immutable identity
        self.name = name

    def __eq__(self, other):
        return isinstance(other, User) and self.id == other.id

    def __hash__(self):
        return hash(self.id)
This keeps equality and hashing based on the same immutable attribute.
Common mistakes
Using mutable attributes in the hash, implementing __eq__ but not __hash__, or changing identity after insertion into a dict.
Key Takeaway

Ensure equality logic and hash computation rely on the same immutable attributes to make objects safe dict keys.
