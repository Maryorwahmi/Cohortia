Module 6 › Chapter 6.4 › Chained Hash Table
Simplified implementation
class SimpleHashTable:
    def __init__(self, capacity=10):
        self.capacity = capacity
        self.table = [[] for _ in range(self.capacity)]  # each bucket is a list

    def _hash(self, key):
        return hash(key) % self.capacity

    def insert(self, key, value):
        index = self._hash(key)
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index][i] = (key, value)
                return
        self.table[index].append((key, value))

    def get(self, key):
        index = self._hash(key)
        for k, v in self.table[index]:
            if k == key:
                return v
        raise KeyError(f"Key '{key}' not found")
How operations map to steps
  • Insert: hash key → index → update if present else append to bucket.
  • Get: hash key → index → scan bucket for matching key.
  • Delete: hash key → index → locate and remove from bucket.
Pro tip

Use chains when you expect collisions; keep capacity moderate or implement resizing to maintain average constant time.
