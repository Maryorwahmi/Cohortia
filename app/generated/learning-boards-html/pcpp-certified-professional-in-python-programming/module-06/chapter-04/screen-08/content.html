Resizing and rehashing
When a dict grows beyond a threshold, Python creates a larger array and re-inserts each item. This keeps load factor low and probes short.
Benefit: Amortized O(1) operations for most workloads because expensive resizes are rare.
Worst-case considerations
A poor hash function or adversarial input can create many collisions and degrade performance to O(N). Python reduces risk with good built-in hashing and probing techniques.
When writing custom objects, implement __hash__ and __eq__ properly so equal objects hash equally and collisions are minimized.
Key Takeaway

Python dicts balance occasional resizing cost with very fast average operations. Understand resizing to reason about performance spikes.
