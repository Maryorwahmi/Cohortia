Module 6 › Chapter 6.4 › Hash Quality
Good hash checklist
  • Deterministic: same input, same hash.
  • Fast to compute.
  • Uniformly distributes keys across buckets.
  • Compatible with equality semantics.
Pitfalls to avoid
Using mutable fields in __hash__ or mutating an object after insertion.
Complex expensive hashing for small objects, hurting performance.
Assuming unique hash outputs without handling collisions.
Pro tip

For custom classes, base your hash on immutable attributes used for equality and keep the computation simple and stable.
