Average vs worst-case
Average case

Amortized O(1) for insert/get/delete when load factor is controlled and collisions are rare.

Worst case

O(N) when many keys collide into the same bucket or probing sequence is long.

Practical actions: keep load factor reasonable, use built-in hashing for standard types, and design custom hashes from immutable identity fields.
