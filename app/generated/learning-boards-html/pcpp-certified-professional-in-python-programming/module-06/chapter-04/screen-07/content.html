Probe strategies
Linear probing: next slots sequentially. Simple but can cluster keys.
Quadratic probing: steps increase quadratically to reduce primary clustering.
Double hashing: uses a second hash to compute probe steps, reducing correlations.
Note
Deletion must preserve probe sequences; many implementations use tombstones or rehash on deletion to avoid broken searches.
Performance and load factor
As load factor approaches capacity, average probe length increases and operation cost rises. Keep load low enough for your probing strategy to stay efficient.
Pro tip: Open addressing often has better memory locality and cache behavior for read-heavy workloads.
Pitfall: Deleted slots can cause failed lookups if probe sequences are not preserved.
