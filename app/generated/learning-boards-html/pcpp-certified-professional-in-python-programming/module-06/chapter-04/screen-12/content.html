Starter template
def count_word_frequencies(words_list: list[str]) -> dict[str, int]:
    """
    Counts the frequency of each word in a list.
    Args:
        words_list: A list of strings (words).
    Returns:
        A dictionary where keys are words and values are their frequencies.
    """
    word_counts = {}
    for w in words_list:
        word_counts[w] = word_counts.get(w, 0) + 1
    return word_counts
This uses dict.get to provide a default zero count before incrementing.
Test cases
Example: ['apple','banana','apple'] → {'apple':2,'banana':1}. Empty list returns {}. Single element returns count 1.
Key Takeaway

Dictionaries provide a concise, efficient pattern for counting and aggregation when keys are hashable and stable.
