Module 6 › Chapter 6.4 › Collisions
Separate chaining
Each bucket holds a list of pairs. Insert appends, lookup traverses the list. Deletion removes from the list.
Pros: Simple, easy deletion, handles high load factor by growing chains.
Cons: Extra memory for chains, pointer chasing can hurt locality.
Open addressing (linear probing example)
On collision probe successive slots until an empty one is found. Lookup follows the same probe sequence.
Pros: Better memory locality, no extra per-bucket lists.
Cons: Clustering can increase probe lengths, deletion must preserve probe sequences.
Example scenario
Two keys hash to bucket 3. With chaining both are stored in bucket 3's chain. With linear probing the second key goes to the next empty index.
Common misconception
A collision means failure. In reality it is a normal outcome we address with resolution strategies.
Key Takeaway

Choose chaining for simplicity and high load; choose open addressing for memory locality and compact arrays.
