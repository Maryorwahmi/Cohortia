Module 4 › Chapter 4.2 › Creating and running threads
Code example
import threading
import time

def task(name, duration):
    """A function representing a task to be run in a thread."""
    print(f"Thread {name}: Starting...")
    time.sleep(duration)  # Simulate I/O-bound work
    print(f"Thread {name}: Finishing.")

print("Main: Starting threads...")
thread1 = threading.Thread(target=task, args=("One", 2))
thread2 = threading.Thread(target=task, args=("Two", 3))

thread1.start()
thread2.start()

# Wait for both threads to complete
thread1.join()
thread2.join()

print("Main: All threads finished.")
Explanation
  • threading.Thread creates a thread object referencing a target function.
  • start() schedules the thread to run. join() waits for completion.
  • Interleaved prints show concurrency during sleep calls.
Concrete example
Running the snippet produces overlapping start/finish messages. While one thread sleeps, the other continues, demonstrating concurrent I/O-bound behavior.
Key Takeaway

Use threads to manage I/O concurrency; always join when the main program must wait for results.
