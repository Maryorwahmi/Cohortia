Module 4 › Chapter 4.2 › Thread-safe summing
Starter code (key parts)
data = list(range(1, 1000001))
shared_total = 0
data_lock = threading.Lock()

def sum_chunk(chunk):
    global shared_total
    local_sum = sum(chunk)
    with data_lock:
        shared_total += local_sum
Notice how local_sum is computed outside the locked region to avoid unnecessary blocking, then the shared update is protected briefly.
Checklist
  • Use the same Lock instance across threads.
  • Compute per-thread local results before acquiring the lock.
  • Verify shared_total == sum(data) after joins.
Key Takeaway
Minimize lock time by doing heavy work outside the critical section; protect only the shared write with a lock.
