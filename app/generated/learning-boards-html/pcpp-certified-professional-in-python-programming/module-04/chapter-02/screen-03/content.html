Module 4 › Chapter 4.2 › Learning Objectives — Apply
01
Create & manage

Implement two threads that run an I/O-bound task, call start on each, and join to ensure the main program waits for both to finish. Verify output order and main completion.

02
Lock & safety

Refactor a shared counter: run without a lock to observe lost increments, then add lock.acquire/release, and finally use with lock for clarity and guaranteed release.

03
Debugging

Create a deadlock example with two locks and two threads, reproduce it, log the blocking points, and fix by ordering lock acquisition consistently.

04
Daemon vs non-daemon

Mark a logging thread as daemon before start and confirm the program exits without waiting, showing abrupt termination for background tasks.
