Module 4 › Chapter 4.2 › Using Lock
Pattern
with lock:
    shared_counter += 1
Use a context manager for simple, reliable lock handling. It guarantees release even if the block raises an exception.
Acquire / release
lock.acquire()
try:
    shared_counter += 1
finally:
    lock.release()
This explicit form is useful when you need fine control around the lock lifetime, but with is preferred for clarity.
Pro tip
Keep the locked region minimal: move heavy computation outside the lock to reduce contention.
Common mistake
Acquiring multiple locks in an inconsistent order, which can create deadlocks.
Check
Create a test that asserts the final shared value equals the expected total when using locks.
