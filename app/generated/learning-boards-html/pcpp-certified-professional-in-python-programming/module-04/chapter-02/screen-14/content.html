Module 4 › Chapter 4.2 › Key Concepts — Part 1
Thread
A lightweight unit of execution within a process that shares memory with other threads.
threading Module
Provides Thread, Lock, and other primitives to create and coordinate threads in Python.
Race condition
An error caused by unsynchronized concurrent accesses where timing determines the outcome.
Takeaway
Design thread interactions deliberately: choose threading for I/O-bound tasks, and always protect shared state with locks when needed.
