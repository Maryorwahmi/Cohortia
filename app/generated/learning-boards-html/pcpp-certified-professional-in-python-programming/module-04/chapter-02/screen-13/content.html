Question 1
Multiple threads update a shared dictionary and entries are missing. What is the likely cause and primary fix?
Answer: Race condition; protect updates with threading.Lock.
Question 2
You want logging threads to stop when the program exits. How do you configure them?
Answer: Set thread.daemon = True before start so they are terminated on exit.
Self-check exercise
Implement the shared-counter example without locks, observe failure, then add a Lock and verify the final total equals the expected value. Log results to confirm determinism.
