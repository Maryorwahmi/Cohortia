Module 4 › Chapter 4.2 › Learning Objectives
01
Create and manage threads

Instantiate threading.Thread with a target, call start to run concurrently, and join to wait. This matters so your main program can coordinate work across threads reliably.

Mnemonic: lifecycle = create → start → join
VERIFIED COMPETENCY MILESTONE
02
Use Lock to prevent race conditions

Acquire a Lock around critical sections so only one thread updates shared state at a time. Without it, concurrent updates may be lost.

Mnemonic: protect reads & writes with a gate
VERIFIED COMPETENCY MILESTONE
03
Debug deadlocks and data corruption

Learn to detect deadlocks caused by inconsistent lock ordering and use logging to reproduce timing issues that produce corrupted state.

Mnemonic: consistent order avoids cycles
VERIFIED COMPETENCY MILESTONE
04
Distinguish daemon vs non-daemon threads

Mark background threads as daemon when they shouldn't block program exit. Use non-daemon for work that must finish cleanly.

Mnemonic: daemon = background, non-daemon = awaited
