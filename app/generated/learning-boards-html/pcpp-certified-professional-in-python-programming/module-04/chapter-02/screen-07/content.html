Module 4 › Chapter 4.2 › Race condition & fix
Unsafe version (excerpt)
shared_counter = 0

def increment_counter():
    global shared_counter
    for _ in range(100_000):
        # Without lock, this is a race condition
        shared_counter += 1
Run this with multiple threads and the final value will often be less than the expected total.
Fixed with Lock
shared_counter = 0
lock = threading.Lock()

def increment_counter():
    global shared_counter
    for _ in range(100_000):
        with lock:
            shared_counter += 1
The with lock ensures each increment completes before another thread can enter the same critical section.
Check your understanding
Run both versions multiple times. Does the unsafe version ever match the expected total? Why or why not?
Analogy
Think of a ticket counter where two clerks can both read and update the same remaining-tickets number without coordination: mistakes happen.
