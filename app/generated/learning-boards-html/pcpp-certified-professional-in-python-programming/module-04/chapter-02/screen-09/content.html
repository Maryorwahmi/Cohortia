Module 4 › Chapter 4.2 › Deadlocks
Cause

Deadlocks happen when threads hold resources while waiting for others. Two locks acquired in opposite order by two threads create a cycle that blocks progress.

Example pitfall

Thread A: acquire(lock1) then acquire(lock2). Thread B: acquire(lock2) then acquire(lock1). This mismatch commonly deadlocks.

Prevention checklist
  • Define a global lock acquisition order and follow it everywhere.
  • Limit the time you hold locks; move heavy operations out of critical sections.
  • Use timeouts or non-blocking attempts when appropriate and retry safely.
