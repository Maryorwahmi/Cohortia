Module 4 › Chapter 4.2 › Daemon threads
Behavior

Set thread.daemon = True before start to mark a thread as a daemon. On program exit, daemon threads are not joined and are terminated immediately, potentially losing state.

Use daemon threads for non-critical background jobs. Use non-daemon threads and join for work that must finish cleanly.
Concrete example
A logging thread that can be safely dropped at shutdown is a candidate for daemon status. A data-save thread is not.
Key Takeaway
Decide thread type by whether the task needs graceful shutdown. Set daemon before starting the thread.
