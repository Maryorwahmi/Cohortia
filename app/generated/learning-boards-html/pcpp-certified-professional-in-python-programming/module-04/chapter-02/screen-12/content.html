Module 4 › Chapter 4.2 › Debugging strategies
Forgotten locks
Symptom: data corruption or missing updates. Fix: add a lock around read-modify-write sequences and verify consistency.
Too many locks
Symptom: poor performance. Fix: reduce lock scope or use coarser-grained locks only when safe.
Deadlock detection
Symptom: threads block forever. Fix: add logging around acquisitions, check stack traces, and enforce ordering.
Practical steps
  1. Increase workload to reproduce timing-sensitive bugs.
  2. Instrument lock acquire/release with logging and thread ids.
  3. Use try/finally or with to guarantee release.
