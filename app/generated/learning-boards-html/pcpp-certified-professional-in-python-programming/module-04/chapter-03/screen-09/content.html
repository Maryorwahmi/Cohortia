Common Challenge › Pickling limits
What fails to serialize
  • Open file objects and socket connections
  • Local, non-top-level functions or lambda functions
  • Objects from extension modules that do not support pickling
  • Active thread or lock objects
Mitigation strategies
  1. Send simple types: ints, lists, dicts with primitive values.
  2. Reconstruct heavy or complex objects inside each worker.
  3. Use multiprocessing.Value or Array for primitive shared memory.
Concrete scenario
If you need to process images in parallel, avoid sending open image file handles through the queue. Instead send file paths or bytes, and let each process open the file locally or receive a serialized byte array.
Pitfall
Blindly sending large, nested objects can increase serialization time and memory pressure; measure and prefer minimal messages.
Key Takeaway

Design IPC messages to be simple and picklable. Reconstruct larger resources inside each process when necessary.
