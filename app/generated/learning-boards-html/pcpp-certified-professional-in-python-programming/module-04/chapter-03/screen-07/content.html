Queue example
import multiprocessing
import time

def worker_with_queue(q, name):
    print(f"Worker {name}: Waiting for data...")
    data = q.get()
    print(f"Worker {name}: Received: {data}")
    result = data * 2
    q.put(result)

if __name__ == "__main__":
    print("Main: Starting queue example...")
    q = multiprocessing.Queue()

    p1 = multiprocessing.Process(target=worker_with_queue, args=(q, "P1"))
    p2 = multiprocessing.Process(target=worker_with_queue, args=(q, "P2"))

    p1.start()
    p2.start()

    q.put(10)
    q.put(20)

    result1 = q.get()
    result2 = q.get()

    print(f"Main: Received results: {result1}, {result2}")

    p1.join()
    p2.join()
    print("Main: Queue example finished.")
Protocol design tips
  • Decide whether inputs and outputs share a queue or use separate queues for clarity.
  • Use sentinel values to signal worker shutdown or count expected results for the parent.
  • Avoid sending non-picklable objects; test serialization before deploying.
Performance note
Queue operations involve serialization and OS-level synchronization; compare wall-clock times to ensure parallelism wins for your workload size.
Key Takeaway

Queue is a reliable many-to-many IPC primitive. Design the message protocol and expected result counts to avoid blocking forever.
