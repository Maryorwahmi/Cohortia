Shared State › Value, Array, Lock
Shared primitives overview
  • Value: single primitive value shared across processes.
  • Array: fixed-type array shared across processes.
  • Lock: synchronization primitive to avoid races.
Example pattern
from multiprocessing import Process, Value, Lock

counter = Value('i', 0)
lock = Lock()

def worker(n):
    for _ in range(n):
        with lock:
            counter.value += 1
When to use messages instead
If your shared data is complex or you want to avoid tight coupling, use Queue/Pipe to send results and let the parent aggregate. Shared memory is best for small primitives or hot counters where serialization overhead dominates.
Misconception
Using shared memory eliminates the need for synchronization. It does not. Locks are required to avoid race conditions when mutating shared values.
Key Takeaway

Choose Value/Array with Locks for primitive shared data; prefer message passing for richer, decoupled communication.
