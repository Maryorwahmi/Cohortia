Chapter 4.3 › What to Remember
Use processes for CPU-bound work
Processes run truly in parallel on multiple CPU cores because each has its own interpreter and GIL.
Choose IPC carefully
Queue for many producers/consumers; Pipe for a simple two-process channel; messages must be picklable.
Guard and verify
Use if __name__ == '__main__', join processes, and verify results match the sequential baseline.
Takeaway
Parallelism provides real speedups for CPU-bound tasks when used with the right patterns, careful IPC design, and proper process management.
