Chapter 4.3 › Key Concepts
Process
Independent execution unit with separate memory and interpreter.
multiprocessing module
Creates processes and provides IPC and shared-memory primitives.
IPC: Queue & Pipe
Queue for many-to-many FIFO; Pipe for pairwise two-way communication.
Main guard
Use if __name__ == '__main__' to prevent recursive spawning on spawn platforms.
Pickling
Objects must be picklable to travel over Queue or Pipe; simplify messages when needed.
Shared primitives
Use Value, Array, and Lock for primitive shared memory and safe updates.
Summary takeaway
Multiprocessing gives real parallelism; choose the right IPC or shared-memory tool for your topology, guard process startup for portability, and test serialization and shutdown scenarios carefully.
