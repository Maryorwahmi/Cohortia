Best Practices › Pitfalls & mitigation
Checklist of pitfalls
  • Excessive process creation for small tasks (measure overhead).
  • Blocking reads without matching producers (use sentinels or timeouts).
  • Pickling errors on complex objects (test serialization early).
  • Assuming global state is shared (it is not).
Mitigation patterns
  • Batch work into larger chunks to amortize process startup cost.
  • Use sentinels or expected-result counts to manage queue draining.
  • Wrap joins and cleanup in try/finally blocks to ensure shutdown.
  • Use Value/Array with Lock for small, shared primitives; otherwise prefer message passing.
Key Takeaway

Design for clear protocols, measure performance, and always include cleanup and validation steps in your multiprocessing code.
