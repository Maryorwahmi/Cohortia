Pipe example
import multiprocessing
import time

def worker_with_pipe(conn, name):
    print(f"Worker {name}: Waiting for data...")
    data = conn.recv()
    print(f"Worker {name}: Received: {data}")
    result = data * 3
    conn.send(result)

if __name__ == "__main__":
    print("Main: Starting pipe example...")
    parent_conn, child_conn = multiprocessing.Pipe()

    p = multiprocessing.Process(target=worker_with_pipe, args=(child_conn, "P_Pipe"))
    p.start()

    parent_conn.send(15)
    result = parent_conn.recv()

    print(f"Main: Received result from pipe: {result}")

    p.join()
    print("Main: Pipe example finished.")
When to choose Pipe
Pick Pipe for a dedicated two-process channel, synchronous request-response patterns, or when you want minimal coordination overhead between exactly two endpoints.
Pitfall
Using Pipe for many producers/consumers adds complexity. Prefer Queue when you need flexible multi-producer or multi-consumer patterns.
Key Takeaway

Choose the IPC primitive that matches your topology: use Pipe for two-way pairs and Queue for many-to-many exchange.
