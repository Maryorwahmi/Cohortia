Practice checklist
  • Write worker functions with arguments and PID logging to verify separate interpreters.
  • Use Process.start and Process.join to control execution order and completion.
  • Implement both Queue and Pipe examples and confirm results are received as expected.
  • Measure sequential vs parallel execution and reason about process creation overhead.
Common checks
Print PIDs to confirm distinct processes
Aggregate results and compare to single-process expected value
Handle pickling errors by sending simple types or simplifying structures
Use join to avoid orphaned processes
Example cue
Start two processes that each perform a heavy loop, print their PID, and put a numeric result in a Queue; the parent collects results and verifies the sum matches an expected value produced by a single-process run.
Mnemonic: PID + Queue + Join
