Process Creation › Creating Processes
Code example
import multiprocessing
import time
import os

def cpu_intensive_task(name, iterations):
    """A CPU-bound task."""
    pid = os.getpid()
    print(f"Process {name} (PID: {pid}): Starting CPU-intensive work...")
    count = 0
    for _ in range(iterations):
        count += 1
    print(f"Process {name} (PID: {pid}): Finished {count} iterations.")

if __name__ == "__main__":
    print("Main: Starting processes...")
    num_iterations = 50_000_000

    process1 = multiprocessing.Process(target=cpu_intensive_task, args=("One", num_iterations))
    process2 = multiprocessing.Process(target=cpu_intensive_task, args=("Two", num_iterations))

    start_time = time.perf_counter()
    process1.start()
    process2.start()

    process1.join()
    process2.join()
    end_time = time.perf_counter()

    print(f"Main: All processes finished in {end_time - start_time:.4f} seconds.")
Notes
  • Each Process runs the target function in its own interpreter with its own PID.
  • Use join to block the parent until the child finishes to avoid orphaned processes.
  • Large iteration counts make work CPU-bound so parallelism pays off.
Concrete scenario
You have a numeric simulation loop that runs for many iterations. Spawn one process per CPU core, give each worker a disjoint slice of iterations, and collect timing to compare with the single-process run.
Misconception
Processes share memory by default. They do not; you must use IPC or special shared objects to communicate results or share state.
Key Takeaway

Process creation is straightforward: target, args, start, join. Collect results with IPC rather than assuming shared variables will sync.
