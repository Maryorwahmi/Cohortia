Common Pitfalls Troubleshooting

Common mistakes and how to avoid them

Learn the usual errors so you can spot them quickly in real code.

Pitfall summaries
  • Using threads for CPU-bound tasks (GIL causes slowdown).
  • Forgetting if __name__ == "__main__" with process pools.
  • Passing non-picklable objects to processes.
  • Blocking on future.result immediately and losing concurrency benefits.
Key Takeaway

Recognize where your workload is I/O or CPU bound, and apply the correct executor and safeguards.

Debugging checklist
  1. Profile: determine if CPU or I/O bound.
  2. Check arguments: are they picklable for processes?
  3. Guard process entry on Windows/macOS.
  4. Use context manager to ensure shutdown.
