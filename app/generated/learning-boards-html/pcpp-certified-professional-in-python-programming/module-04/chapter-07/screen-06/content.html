Core Concept ProcessPoolExecutor

ProcessPoolExecutor for CPU-bound work

Run CPU-heavy tasks in separate processes to use multiple cores.

Example: sum of squares
with concurrent.futures.ProcessPoolExecutor(max_workers=os.cpu_count()) as executor:
    results = list(executor.map(cpu_intensive_calculation, numbers_to_process))
Using map returns results in submission order and is concise for batch CPU work. Measure total elapsed time to confirm speedup over a serial loop.
Practical considerations
  • Protect process entry with if __name__ == "__main__" to avoid child process re-execution.
  • Arguments and returns must be picklable; avoid passing open sockets or complex local objects.
  • Process startup and IPC add overhead; prefer coarser-grained tasks for processes.
Common mistake

Forgetting the if __name__ guard can cause infinite process spawning on some platforms.
