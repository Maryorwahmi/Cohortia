Definition

Awaitable types

Coroutine object
Returned by calling an async function; needs scheduling to run.
Task
Wraps a coroutine and schedules it on the loop immediately.
Future
Lower-level placeholder for a result, often used in integrations.
Practical notes
  • Call an async def to get a coroutine; use create_task to schedule it right away.
  • Tasks are useful for background operations you don't await immediately.
  • Use Futures for advanced coordination or bridging callbacks into asyncio.
Key Takeaway

Understand the lifecycle difference: coroutine object vs scheduled Task vs result-holding Future.
