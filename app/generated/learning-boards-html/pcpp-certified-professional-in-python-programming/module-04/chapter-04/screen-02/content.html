Learning Objectives

Bloom's ladder: Learn → Understand → Apply → Master

Bloom: Apply
01
Explain core concepts
Describe event loop, coroutine, async/await and how they work together. Verified competency milestone: explain what pauses a coroutine.
02
Write and run async functions
Use async def, await, and asyncio.run to execute coroutines. Verified competency milestone: run a main coroutine that awaits tasks.
03
Choose asyncio for I/O-bound work
Recognize workloads that benefit from cooperative multitasking. Verified competency milestone: classify a task as I/O-bound or CPU-bound.
04
Compare with threads
Understand differences in execution model, GIL impact, and complexity. Verified competency milestone: explain one advantage and one trade-off.
