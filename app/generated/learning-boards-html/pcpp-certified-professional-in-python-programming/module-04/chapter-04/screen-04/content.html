Core Concept

What is asyncio?

Asyncio is a framework for single-threaded concurrency using coroutines. It enables cooperative multitasking by letting functions pause at await points so the event loop can run other work.

Analogy
Think of the event loop as a dispatcher that asks tasks to check back later when they start waiting for a response.
Common misconception
Not parallel CPU work: CPU-bound code will block the event loop and stall all coroutines.
Key Takeaway

Use asyncio for programs that wait on external I/O frequently; it reduces context-switching overhead compared to many threads.

Definition
Event Loop
Schedules and resumes coroutines when awaitables complete.
Coroutine
An async def function that can pause at await points.
Awaitable
A coroutine, Task, or Future that can be awaited to yield control.
asyncio.run
Convenience to create and run the event loop for a top-level coroutine.
Why it matters
For high-concurrency network services, asyncio allows thousands of connections to be managed with a single thread and less overhead than creating many threads or processes.
