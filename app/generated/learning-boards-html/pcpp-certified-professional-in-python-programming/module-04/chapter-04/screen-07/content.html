Definition

asyncio.run

Creates a loop, runs the given coroutine until complete, and closes the loop. It encapsulates loop lifecycle and is recommended for top-level scripts.

Pattern: define async def main(), then call asyncio.run(main()) from the script entry point.
Common pitfall: calling asyncio.run inside an already running loop will raise an error in environments with an active loop.
Process
1. Define main()
Compose tasks and await gather or other awaitables.
2. Call asyncio.run
Entrypoint that handles loop lifecycle for you.
3. Program exits
Loop is closed and resources are cleaned up.
Key Takeaway

Prefer asyncio.run for standalone scripts to avoid manual loop mistakes; be careful in interactive environments.
