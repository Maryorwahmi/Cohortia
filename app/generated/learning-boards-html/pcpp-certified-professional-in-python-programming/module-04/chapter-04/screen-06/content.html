fetch_data walkthrough

Read the code and notice where control returns to the event loop. Predict the total runtime before running.

import asyncio
import time

async def fetch_data(delay, name):
  print(f"Coroutine {name}: Starting fetch (simulated delay {delay}s)...")
  await asyncio.sleep(delay)
  print(f"Coroutine {name}: Finished fetch.")
  return f"Data from {name}"

async def main():
  start = time.perf_counter()
  task1 = fetch_data(2, "A")
  task2 = fetch_data(1, "B")
  task3 = fetch_data(3, "C")
  results = await asyncio.gather(task1, task2, task3)
  print(time.perf_counter() - start)

asyncio.run(main())
Note: calling fetch_data returns a coroutine object. The gather call schedules them and awaits their completion.
Explanation
  • async def defines a coroutine that can pause at await points.
  • await asyncio.sleep yields control to the event loop; other coroutines run while sleeping.
  • asyncio.gather runs multiple awaitables concurrently and returns their results.
Concrete example
Three coroutines with delays 2, 1, and 3 seconds complete in about 3 seconds total, demonstrating overlapping I/O waits.
Misstep to avoid

Do not run blocking CPU work inside a coroutine; it will block the event loop and stall concurrency.
