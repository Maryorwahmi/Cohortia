Process Flow

Event loop flow

1
Register awaitable
A coroutine yields control with await. The loop stores its resume point.
2
Run other ready coroutines
The loop executes coroutines that are ready while others wait for I/O.
3
Resume when awaitable completes
Once I/O completes, the loop schedules the paused coroutine to continue.
Analogy: the event loop is like a call center operator who puts callers on hold and returns to them when an external agent reports a result.
Annotation
Ready queue
Coroutines ready to run are queued until the loop dispatches them.
I/O watchers
Underlying selectors or pollers notify the loop when sockets or timers fire.
Callback scheduling
Completed awaitables schedule callbacks to resume the associated coroutine.
