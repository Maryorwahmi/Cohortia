01 — Practice: Distinguish
Read two scenarios and classify each as concurrency or parallelism, then explain one-sentence reasoning.
Activity
Scenario A: Single process handling many connections by switching between them. Scenario B: Multiple processes running heavy number crunching simultaneously.
Deliverable: State type and one reason why.
02 — Practice: The GIL
Explain how the GIL acts like a mutex protecting Python objects and what it prevents when using native threads for CPU work.
Prompt: Why does threading not give true CPU parallelism for Python bytecode?
03 — Practice: Map use cases
Map the four provided scenarios to workload types and pick a model with justification.
Deliverable: A one-line recommendation per scenario.
04 — Practice: Trade-offs
List overheads introduced by multiprocessing and complexity costs of concurrency coordination.
Deliverable: Two short bullet points of trade-offs you would accept in production.
