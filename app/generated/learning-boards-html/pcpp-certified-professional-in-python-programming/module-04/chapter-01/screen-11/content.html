Module 4 › Chapter 4.1 › Model ↔ Workload
Scenario 1 — Large dataset
Workload type: CPU-bound. Recommendation: multiprocessing to run chunks on separate cores and combine results.
Scenario 2 — Web scraper
Workload type: I/O-bound. Recommendation: asyncio for low overhead or threads with blocking clients for simplicity.
Scenario 3 — ML training on GPU
Workload type: device-bound. Recommendation: rely on the device and libraries; Python threading is not the mechanism for GPU parallelism.
Scenario 4 — Chat server
Workload type: I/O-bound with many connections. Recommendation: asyncio or an evented server to manage thousands of sockets efficiently.
Assessment tip

When recommending a model, state the primary bottleneck and one reason your chosen model reduces that bottleneck.
