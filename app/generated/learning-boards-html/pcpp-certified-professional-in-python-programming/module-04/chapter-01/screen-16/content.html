Module 4 › Chapter 4.1 › Quick Reference
Classify
Decide whether the workload is CPU-bound, I/O-bound, or device-bound; this guides model selection.
Choose
I/O-bound → threading or asyncio. CPU-bound → multiprocessing. Device-bound → use device-native libraries.
Measure
Prototype small, measure bottlenecks, and pick the simplest solution that meets performance goals.
Final takeaway
The GIL shapes how Python threads behave; choose models that align with the real bottleneck rather than intuition alone.
