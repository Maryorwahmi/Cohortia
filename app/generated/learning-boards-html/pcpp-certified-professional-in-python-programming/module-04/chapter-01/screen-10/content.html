I/O-bound example (concept)
# I/O-bound behavior example
import time

def fetch_simulated(url):
  # simulate waiting for network
  time.sleep(0.5)
  return 'content from ' + url

# Many threads or asyncio can issue many fetches
This code spends most of its time waiting; while one task sleeps the interpreter often releases the lock, so other tasks proceed.
CPU-bound example (concept)
# CPU-bound behavior example
def heavy_compute(n):
  total = 0
  for i in range(n):
    total += i * i
  return total

# Running heavy_compute in many threads will still contend for the GIL
This loop keeps the interpreter busy executing bytecode; threads will compete for the GIL and not realize multi-core speedup.
Key Takeaway

Classify code by whether it mostly waits for I/O or mostly computes; that classification determines which concurrency model will be effective.
