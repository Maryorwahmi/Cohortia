Module 4 › Chapter 4.1 › Key Concepts
Concurrency
Managing many tasks by interleaving execution to improve responsiveness when tasks wait for I/O.
Parallelism
Running tasks at the same instant across multiple processing units to speed up CPU-bound work.
Global Interpreter Lock
A mutex that prevents multiple native threads from executing Python bytecode at once, shaping tool choice.
Summary
Classify your workload, measure, and choose threads, processes, or async accordingly. Simplicity and maintainability should guide the final design.
