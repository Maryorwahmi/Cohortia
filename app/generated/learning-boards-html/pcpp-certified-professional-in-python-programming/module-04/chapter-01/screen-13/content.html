Module 4 › Chapter 4.1 › Pitfalls
Mistake: Threads for CPU-bound work
Because of the GIL, threads do not yield true multi-core CPU speedup for Python bytecode-heavy tasks.
Mistake: Too many processes
Spawning many short-lived processes increases overhead; prefer fewer, longer-lived workers with larger chunks.
Mistake: Blocking the event loop
Using blocking libraries inside asyncio without offloading will block the loop and reduce concurrency benefits.
Mistake: Ignoring coordination costs
Concurrency introduces synchronization complexity; locks and shared state can cause bugs and performance regressions.
Advice

Prototype and measure. Use the simplest model that meets requirements and accept coordination costs only when necessary.
