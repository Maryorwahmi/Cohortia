Concurrency, Parallelism, and the GIL
Understand how Python schedules work and when you can use true parallel execution.
What you'll understand
  • How concurrency composes tasks by interleaving execution, with a chef metaphor.
  • Why Python's GIL prevents multiple threads from executing Python bytecode simultaneously.
  • Which Python tools to use for CPU-bound and I/O-bound problems.
In this lesson
Distinguish concurrency and parallelism, see how the GIL affects threads, and match workloads to threading, multiprocessing, or asyncio.
Coming up
Concrete scenario analysis and a hands-on activity to classify workloads.
Concept map
Concurrency
Interleaving of tasks to handle many activities; appearance of simultaneous progress without simultaneous execution.
Parallelism
True simultaneous execution on multiple processing units; requires separate cores or processes.
