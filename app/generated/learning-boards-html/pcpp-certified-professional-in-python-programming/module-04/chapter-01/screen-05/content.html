Module 4 › Chapter 4.1 › What is Parallelism?
Definition
Parallelism runs multiple tasks simultaneously using multiple processing units, giving real time speedup for CPU-bound computation.
Chef metaphor
Multiple chefs can each progress at the same moment; this is true simultaneous work, unlike the single-chef concurrency case.
When to use
When tasks are CPU-bound and independent enough to be split across cores for speed.
Cost to consider
Inter-process communication and memory duplication can be significant; parallelism is not zero-cost.
Concrete example
Divide a large numerical reduction into chunks processed by separate processes on different CPU cores, then combine partial results to obtain the final aggregate.
Misconception check
  • Parallelism requires hardware cores; more processes alone do not guarantee better performance if coordination cost dominates.
  • Splitting work must avoid excessive data copying between processes.
Key Takeaway

Use parallelism for CPU-bound tasks where the computation divides cleanly and coordination overhead is worth the speedup.
