Seven quick questions
  1. What is the primary bottleneck: CPU, I/O, or external device?
  2. Have you measured a prototype to confirm the bottleneck?
  3. If I/O-bound, can you use non-blocking libraries? Prefer asyncio if yes.
  4. If CPU-bound, can you split work into independent chunks for multiprocessing?
  5. Do you have memory headroom for duplicated process state?
  6. How complex will coordination and synchronization be?
  7. Which approach gives clearer observability and maintainability for your team?
Key Takeaway

Answer these questions to reach a defensible, simple design that balances performance gains against coordination and resource costs.
