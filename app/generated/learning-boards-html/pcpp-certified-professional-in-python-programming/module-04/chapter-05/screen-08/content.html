Process Flow
asyncio.wait()
Use wait when you want to react to the first completed task, first exception, or wait for all to complete. It returns two sets: done and pending.
Step 1 — Schedule tasks
Create tasks for each parallel operation using create_task.
Step 2 — wait()
Call await asyncio.wait(tasks, return_when=FIRST_COMPLETED) to get done and pending sets.
Step 3 — process
Process results from done, then optionally await or cancel pending tasks.
Example excerpt
done, pending = await asyncio.wait(tasks, return_when=asyncio.FIRST_COMPLETED)
for t in done:
  print(t.result())
# handle pending tasks next
When to use

When you need to handle first-arriving results, timeouts, or stream processing as tasks complete.

Practical tip
After processing done tasks, await asyncio.wait(pending, return_when=ALL_COMPLETED) or cancel pending tasks if they are no longer needed.
