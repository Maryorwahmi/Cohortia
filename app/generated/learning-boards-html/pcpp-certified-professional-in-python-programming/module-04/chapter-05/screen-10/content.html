Core Concept
asyncio.Semaphore
A semaphore provides a fixed number of tokens. coroutines acquire a token before proceeding and release it when done, preventing too many concurrent operations.
semaphore = asyncio.Semaphore(3)

async def limited_api_call(url, semaphore):
  async with semaphore:
    await asyncio.sleep(random.uniform(1,3))
    return f"Data from {url}"

results = await asyncio.gather(*[limited_api_call(u, semaphore) for u in urls])
Practical guidance
  • Choose a sensible concurrency limit based on the external service capacity.
  • Use async with semaphore to ensure a token is always released, even on errors.
  • Do not rely on internal attributes like semaphore._value for logic; they are implementation details.
Key Takeaway

Semaphores give a clear token-based way to limit concurrency and protect shared resources or remote APIs.

Analogy
Think of a semaphore as a pool of tokens. A coroutine takes a token to start work and returns it when done.
