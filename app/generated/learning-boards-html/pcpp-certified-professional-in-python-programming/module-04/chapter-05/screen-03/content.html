Practice and Assessment
Concrete checks and tasks to verify your skills.
01
Task scheduling exercise
Create tasks that start immediately. Await them later to confirm concurrency and exception behaviour. Measure observed prints to verify order.

Future integration task
Wrap a callback API with a Future and call set_result from the callback to complete the Future, demonstrating manual control.
VERIFIED COMPETENCY MILESTONE
03
Gather and wait scenarios
Run gather to collect ordered results and run wait with FIRST_COMPLETED to observe done and pending sets and process first results early.
VERIFIED COMPETENCY MILESTONE
04
Semaphore rate-limiting
Implement a semaphore-controlled worker pool and measure elapsed time to confirm concurrency limit effectiveness.
