What is a Future?
A Future represents a value that will be available later and can be completed manually with set_result or set_exception. It is the primitive for bridging non-async code and callback APIs into asyncio.
# callback integration example
import asyncio

def callback_done(fut, data):
  fut.set_result(data)

async def wait_for_callback(loop):
  fut = loop.create_future()
  # imaginary_register_callback(lambda data: callback_done(fut, data))
  result = await fut
  return result
Key points
  • Task is a subclass of Future and is used for coroutines.
  • Use Future when you must complete the awaitable manually from callbacks or external events.
  • Always set a result or exception to avoid hanging awaiters.
Pitfall

Never leave a Future unresolved. If a callback is missed or an error occurs before set_result, awaiting code will block indefinitely.

Debug tip
Use future.done() and add_done_callback to inspect completion and observe exceptions when a Future fails.
