Architecture
Orchestrating async components
Coordinator
Schedules tasks, chooses gather or wait, handles cancellations and exceptions.
Worker
Acquires semaphore, performs I/O, may set a Future or return a result.
Bridge / Callback
Uses Future to accept results from callback-based libraries and integrates them into async flow.
Pattern decisions
  • Gather when you need ordered batch results and simple collection.
  • Wait when you want streaming or first-response behaviour.
  • Semaphore when you must limit active I/O operations.
Key Takeaway

Designing clear ownership for tasks and bounding concurrency keeps async systems predictable and easy to debug.
