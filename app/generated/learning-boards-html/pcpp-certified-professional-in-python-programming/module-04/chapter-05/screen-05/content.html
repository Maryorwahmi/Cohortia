Comparison
Await vs Task
Sequential await example
async def main_seq():
  await worker("A", 2)
  await worker("B", 1)
create_task example
async def main_concurrent():
  t1 = asyncio.create_task(worker("A", 2))
  t2 = asyncio.create_task(worker("B", 1))
  await t1
  await t2
Practical notes
  • Awaiting is simple and predictable when order and isolation matter.
  • create_task is required when you want parallelism or background work while performing other actions.
  • Remember to await or otherwise handle Tasks to collect results and exceptions.
  • Combine tasks with semaphores to avoid resource exhaustion when creating many concurrent operations.
Misconception

Creating a Task is not the same as awaiting; it does not block but begins execution. Avoid assuming tasks will finish before later code runs unless you await them.

If two tasks have delays 3s and 1s, which total runtime do you expect for task-based concurrency? (Answer: close to 3s, plus any main work.)
