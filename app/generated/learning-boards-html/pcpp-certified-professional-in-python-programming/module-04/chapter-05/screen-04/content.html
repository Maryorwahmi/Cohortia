Core Concept
What is an asyncio.Task?
A Task schedules a coroutine to run on the event loop and exposes its future result.
import asyncio

async def worker(name, delay):
  print(f"Worker {name}: Starting (delay {delay}s)...")
  await asyncio.sleep(delay)
  print(f"Worker {name}: Finished.")
  return f"Result from {name}"

async def main_tasks():
  task1 = asyncio.create_task(worker("A", 3))
  task2 = asyncio.create_task(worker("B", 1))

  # main can do other work while tasks run
  await asyncio.sleep(0.5)

  result1 = await task1
  result2 = await task2
  print(result1, result2)
Explanation
  • create_task schedules the coroutine immediately on the loop but returns a handle you can await later.
  • Task is a subclass of Future; it supports result(), exception(), and add_done_callback().
  • Awaiting a coroutine directly suspends the caller until completion; creating a Task does not.
Key Takeaway

Use Tasks to run coroutines concurrently and await their results when you need them.

Common misconception
create_task does not copy or clone code; it schedules the provided coroutine. Forgetting to await a Task can leave background errors unobserved.
