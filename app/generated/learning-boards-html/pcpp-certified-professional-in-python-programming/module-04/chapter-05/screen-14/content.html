Module 4 › Chapter 4.5 › Key Concepts
asyncio.Task
Schedules a coroutine and is awaitable for its result or exception.
asyncio.Future
A low-level awaitable you complete with set_result or set_exception.
asyncio.create_task()
Start a coroutine running in the background on the event loop.
asyncio.gather()
Run many awaitables and return results in input order; can return exceptions if requested.
asyncio.wait()
Return done and pending sets; choose FIRST_COMPLETED, FIRST_EXCEPTION, or ALL_COMPLETED.
asyncio.Semaphore
A token pool that limits the number of concurrent acquisitions to a set value.
Summary
Match tools to need: Task for scheduling, Future for manual completion, gather for ordered batch, wait for reactive handling, and Semaphore for rate-limiting.
