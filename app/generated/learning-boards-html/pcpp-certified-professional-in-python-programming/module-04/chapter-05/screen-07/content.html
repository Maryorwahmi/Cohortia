asyncio.gather()
Use gather to run many awaitables concurrently and receive an ordered list of results. Choose return_exceptions when you want to inspect failures rather than abort.
results = await asyncio.gather(task1, task2, task3)
# results order matches (task1, task2, task3)

# collect exceptions instead of raising
results = await asyncio.gather(*tasks, return_exceptions=True)
Practical notes
  • Gather preserves the input order in the returned list even if tasks finish out of order.
  • Default behaviour raises the first exception and cancels pending awaitables unless handled.
  • Use return_exceptions=True to receive exceptions as results and continue processing other outcomes.
Key Takeaway

gather returns ordered results and controls how exceptions are handled via return_exceptions.

Example scenario
When calling several APIs where one failure should abort the whole batch, use gather default behaviour. When partial results are acceptable, use return_exceptions.
