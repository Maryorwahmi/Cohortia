Core Concept
First-completed pattern
Schedule tasks and wait for the first to finish. Process its result, then decide how to treat remaining tasks.
tasks = [asyncio.create_task(limited_worker("X",2)),
         asyncio.create_task(limited_worker("Y",1)),
         asyncio.create_task(limited_worker("Z",3))]

done, pending = await asyncio.wait(tasks, return_when=asyncio.FIRST_COMPLETED)
first_results = [t.result() for t in done]
# optionally cancel pending tasks
for p in pending:
  p.cancel()
Explanation & example
In the example above, the Y task finishes first. done contains Y, pending contains X and Z. Fetch results with .result and cancel pending tasks if you no longer need them.
Key Takeaway

wait returns Task objects in done/pending; call .result() and cancel or await pending tasks intentionally.

Common mistake
Assuming done contains raw results instead of Task objects. Always inspect Task.result() and handle exceptions that .result() may raise.
