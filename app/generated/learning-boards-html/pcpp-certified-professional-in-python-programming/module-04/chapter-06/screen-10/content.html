threading
Primitives block threads. Use threading.Event, threading.Condition and threading.Barrier directly. Protect shared memory with locks. Example: waiter threads blocking on threading.Event.
multiprocessing
Processes have separate memory. Use multiprocessing.Event, multiprocessing.Lock, or Manager objects for shared state. Barriers exist for processes or can be simulated. Remember to use process-safe primitives when crossing process boundaries.
asyncio
Primitives are awaitable; use asyncio.Event and asyncio.Condition within the event loop. Do not call blocking waits in async code. Awaitable waits yield to other coroutines instead of blocking OS threads.
Practical rule
When combining models, prefer message passing or Manager-backed shared objects and avoid calling blocking synchronization from inside the event loop. Design clear boundaries for each model and bridge state explicitly.
