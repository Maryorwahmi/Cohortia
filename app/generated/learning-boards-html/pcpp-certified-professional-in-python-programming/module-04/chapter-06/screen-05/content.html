Definition
Condition — Wait for a predicate
Protect shared state with a lock and block until a condition becomes true.
Producer-Consumer Explanation
  • Producer: acquire condition, while buffer full -> condition.wait(); append item; condition.notify()
  • Consumer: acquire condition, while buffer empty -> condition.wait(); pop item; condition.notify()
  • Always use while loops to re-check the predicate after wake-up.
Code snippet
import threading import time buffer = [] MAX_SIZE = 5 condition = threading.Condition() # Producer and consumer use with condition and while checks as shown in examples
Common mistakes & guidance
Use while, not if: re-check predicates after wait to handle spurious wake-ups and notify_all semantics.
notify vs notify_all: notify wakes one waiter; notify_all wakes all and may cause thundering herd if many re-check.
Protect shared state: the Condition must be used with its lock to avoid race conditions when testing or modifying state.
Asyncio: asyncio.Condition uses awaitable wait and must be used within the event loop with an associated asyncio.Lock.
