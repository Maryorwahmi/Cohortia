Module 4 › Chapter 4.6 › Key Concepts
Event
A simple flag to broadcast readiness; use with locks when shared state is modified.
Condition
Wait for predicates under a lock and use notify or notify_all to wake waiters; always re-check after wake-ups.
Barrier
Rendezvous primitive for fixed participant counts to synchronize phases cleanly.
Takeaway

Remember the mapping: Event = flag, Condition = guarded gate, Barrier = rendezvous. Build safety checks into every design.
