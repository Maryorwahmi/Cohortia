Core Concept
Barrier — Phase synchronization
Wait until a fixed number of participants arrive, then release them all together.
Example Usage
Create a barrier with the participant count and call barrier.wait() at phase boundaries. When the Nth participant calls wait, all are released.
import threading import random import time num_participants = 3 barrier = threading.Barrier(num_participants) def participant(id): print(f"Participant {id}: Starting phase 1...") time.sleep(random.uniform(0.5, 2)) print(f"Participant {id}: Finished phase 1, waiting at barrier.") barrier.wait() print(f"Participant {id}: Barrier passed! Starting phase 2...")
Pitfalls and Mitigations
  • Deadlock if a participant never arrives. Use timeouts or watchdogs.
  • Participant failure leaves barrier blocked; design an abort or replacement strategy.
  • Barrier synchronizes phases but does not protect shared mutable state; use locks where needed.
Key Takeaway

Use Barrier for deterministic phase boundaries among a known set of participants, and handle missing participants with timeouts or fallback logic.
