Learning Objectives — Practical Focus
Hands-on skills and mnemonics to anchor the patterns.
01 — Event: Flag mnemonic
Implement waiter and setter threads/processes/coroutines that block on an Event until another unit calls set, then proceed or reset as needed.
Mnemonic: Flag — set to go.
Verified Competency Milestone
02 — Condition: Gate with lock
Write producer and consumer that acquire the condition's lock, check a predicate in a loop, and call wait or notify appropriately.
Mnemonic: Gate guarded by a lock.
Verified Competency Milestone
03 — Barrier: Rendezvous
Configure barriers for fixed participant counts and structure multi-phase workflows with clear setup, processing, and cleanup phases.
Mnemonic: Rendezvous point for phases.
Verified Competency Milestone
04 — Mitigate failures
Apply lock ordering, bounded retries, and condition re-checks to reduce deadlocks, livelocks and starvation in real systems.
Mnemonic: Design for progress.
Verified Competency Milestone
