Learning Objectives
01
Explore setsockopt and getsockopt

Learn the calls to set and read socket options and why socket.SOL_SOCKET is used for socket-level options. Demonstrate changing and reading values for testing and tuning.

Verified Competency Milestone
02
SO_REUSEADDR and SO_KEEPALIVE

Understand why reuse helps in TIME_WAIT during restarts and how keep-alive probes detect half-open connections. Learn OS-level limits on probe timing.

Verified Competency Milestone
03
Robust error handling

Apply targeted try and except blocks for ConnectionRefusedError, ConnectionResetError, BrokenPipeError, TimeoutError, and socket.error to produce clear logs and graceful shutdowns.

Verified Competency Milestone
04
Inspect addresses and handle partial I/O

Use getsockname and getpeername for logging and design message framing to handle partial sends and receives reliably, such as length prefixes or delimiters.

Verified Competency Milestone
