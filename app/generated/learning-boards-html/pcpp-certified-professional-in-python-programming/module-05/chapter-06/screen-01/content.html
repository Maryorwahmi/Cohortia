Quick Reference
SO_REUSEADDR — reuse ports in TIME_WAIT for quick restarts.
SO_KEEPALIVE — OS-level probes detect dead peers; timing set by OS.
getsockname / getpeername — inspect local and remote addresses for logging.
Key Takeaway

Socket options tune how connections behave; specific, logged error handling keeps network services maintainable and debuggable.
