Module 5 › Chapter 5.6 › getsockname & getpeername
Definition

Inspect socket addresses

Use getsockname to learn the local IP and port and getpeername to learn the connected peer's address. Bind to port zero when you need an ephemeral port and then read the assigned port back for reporting.

Example
s.bind(('127.0.0.1', 0))
print('Local address:', s.getsockname())
# after connect
# print('Peer address:', s.getpeername())
Tips
  • Call getpeername only for connected sockets to avoid errors.
  • Log addresses on connect and on error events for effective troubleshooting.
  • Prefer structured logs with address fields for automated analysis.
Key Takeaway

Address inspection is essential for meaningful logs and access control decisions; use it at connection boundaries and on errors.
