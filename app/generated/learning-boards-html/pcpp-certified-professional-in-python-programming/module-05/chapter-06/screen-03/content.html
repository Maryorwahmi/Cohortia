Module 5 › Chapter 5.6 › Learning Objectives
How you'll demonstrate each objective
01 — Verify setsockopt / getsockopt

Run a short script that sets an option, binds, then reads the option back with getsockopt to confirm behavior. Capture any errors and log them.

Verified Competency Milestone
02 — Exercise reuse and keep-alive

Restart a server quickly to trigger TIME_WAIT, enable reuse, and demonstrate the difference. Enable keep-alive and explain why OS timing matters.

Verified Competency Milestone
03 — Targeted error handling

Run the robust client with server offline to see ConnectionRefusedError, then with delayed server responses to test timeouts. Log messages should be clear and actionable.

Verified Competency Milestone
04 — Address inspection & framing

After connecting, print getsockname and getpeername for both endpoints and implement length-prefixed messages to demonstrate correct partial receive handling.

Verified Competency Milestone
