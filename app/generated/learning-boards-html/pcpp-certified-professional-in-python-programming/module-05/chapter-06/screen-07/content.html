Module 5 › Chapter 5.6 › Buffer Sizes & TCP_NODELAY
Comparison

When to change buffers or disable Nagle

Large file transfer
Increase send and receive buffers to allow larger in-flight windows and higher throughput.
Interactive messaging
Disable Nagle with TCP_NODELAY to reduce latency for many small writes.
Measure first
Always run realistic traffic tests; defaults are tuned for general use and may be best in many environments.
Example
# read buffer sizes
rcv = s.getsockopt(socket.SOL_SOCKET, socket.SO_RCVBUF)
snd = s.getsockopt(socket.SOL_SOCKET, socket.SO_SNDBUF)
print('Rcv', rcv, 'Snd', snd)
# disable Nagle
s.setsockopt(socket.IPPROTO_TCP, socket.TCP_NODELAY, 1)
Key Takeaway

Match buffer and Nagle settings to your traffic pattern and verify performance with measurements.
