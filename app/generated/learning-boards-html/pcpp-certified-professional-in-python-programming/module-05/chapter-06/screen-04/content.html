Module 5 › Chapter 5.6 › Socket Options
Definition

setsockopt and getsockopt

Use these calls to change parameters like buffer sizes, reuse behavior, and keep-alive. Remember to set options before calling bind or connect when the option affects that operation.

Example: confirm option value
# pseudo-example
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
val = s.getsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR)
print('SO_REUSEADDR is', val)
Key points:
  • Use socket.SOL_SOCKET when the option applies to the socket layer.
  • Verify values at startup with getsockopt to avoid surprises.
  • Some low-level timing is controlled by the operating system, not Python.
Example Card
Practical check

Before you call bind in a server process, set options you rely on and then read them back to assert the correct value. This is particularly useful in automated tests.

Common mistake

Assuming a Python call can alter OS probe timing. Keep-alive timing is normally an OS configuration and may not change from Python.

Key Takeaway

Use setsockopt to tune behavior, verify it with getsockopt, and remember OS defaults can override timing-related options.
