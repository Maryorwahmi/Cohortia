Module 5 › Chapter 5.6 › SO_KEEPALIVE
Definition

Enable OS probes for dead peers

Keep-alive helps reclaim resources held by connections where the remote side failed without closing. It is an OS-level mechanism and should be paired with application-level checks when you need faster detection.

Practical guidance
  • Enable keep-alive to allow the OS to detect unreachable peers.
  • Use socket timeouts and application heartbeats for short detection windows.
  • Document OS defaults so operators understand probe frequency.
Example
s.setsockopt(socket.SOL_SOCKET, socket.SO_KEEPALIVE, 1)
Key Takeaway

Keep-alive detects dead peers at OS intervals; combine with app-level pings for fast failure detection.
