Module 5 › Chapter 5.6 › Activity
Lab Instructions
  1. Open the starter robust_tcp_client file and add setsockopt calls for SO_REUSEADDR and SO_KEEPALIVE.
  2. Set a global timeout of five seconds using settimeout.
  3. After connect, print getsockname and getpeername for logging.
  4. Add except blocks for ConnectionRefusedError, TimeoutError, and socket.error with clear messages.
  5. Ensure the socket is always closed in a finally block.
Test cases
  • Server active: observe normal send and receive.
  • Server inactive: see ConnectionRefusedError message.
  • Server delays response: trigger TimeoutError when using a short timeout.
Key Takeaway

This lab cements the pattern: configure options, set timeouts, handle specific exceptions, and always close sockets.
