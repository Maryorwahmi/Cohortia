Module 5 › Chapter 5.6 › Partial Sends/Receives
Problem

recv does not guarantee full messages

Design messages so the receiver can know when the full payload has arrived. Length prefixes are simple and reliable across different transports.

Receive loop pattern
# pseudo
n = read_exactly(4)  # 4-byte length prefix
length = int.from_bytes(n, 'big')
data = b''
while len(data) < length:
  chunk = s.recv(length - len(data))
  if not chunk:
    # graceful close
    break
  data += chunk
Practical notes
  • Use sensible maximum message sizes to defend against malformed input.
  • Tie recv loops to socket timeouts to avoid hanging on slow connections.
  • Treat empty recv as a graceful close and handle it without crashing.
Key Takeaway

Design explicit framing and loop on recv until all bytes arrive; never assume a single recv returns a complete message.
