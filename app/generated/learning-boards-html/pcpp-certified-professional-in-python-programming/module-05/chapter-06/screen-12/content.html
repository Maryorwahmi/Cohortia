Module 5 › Chapter 5.6 › Structured Error Handling
Process

Try → specific excepts → finally

  1. Wrap connect and I/O in try.
  2. Catch ConnectionRefusedError and report server availability.
  3. Catch TimeoutError and decide on retry/backoff.
  4. Catch socket.error for other network issues and log details.
  5. Use finally to close sockets and release resources.
Example logging fields
  • operation: connect, send, recv
  • remote: remote IP and port from getpeername
  • local: local address from getsockname
  • error: exception type and message
Pro tip

Include the socket descriptor and a short operation name in logs to speed triage during incidents.
