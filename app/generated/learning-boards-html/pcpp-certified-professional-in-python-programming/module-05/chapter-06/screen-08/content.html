Module 5 › Chapter 5.6 › Socket Exceptions
Definition

Common socket errors

  • ConnectionRefusedError: server not listening; retry or inform user.
  • ConnectionResetError: peer closed connection abruptly; clean up and consider reconnect.
  • BrokenPipeError: write to closed peer; ensure you close resources and abort further writes.
  • TimeoutError: operation timed out; use sensible retries and backoff.
Best practices
Catch specific exceptions and log remote address, attempted operation, and the exception message.
Reserve a general exception handler only for guaranteed cleanup and re-raising or controlled shutdown.
Test handlers by running the client with the server offline and by introducing artificial delays to trigger timeouts.
Common mistake

Using a wide except Exception without logging will hide socket errors and make debugging difficult.
