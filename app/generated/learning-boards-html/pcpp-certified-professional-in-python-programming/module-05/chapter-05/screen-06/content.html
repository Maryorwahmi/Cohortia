SO_REUSEADDR and binding

Set the reuse-address option on the listening socket to allow immediate port reuse after restarting the server. This is especially helpful during development and iterative testing.

s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
s.bind((HOST, PORT))
s.listen(5)
Why it matters
Avoids address-in-use errors caused by sockets in TIME_WAIT state during rapid restarts.

Handler cleanup and errors

Wrap handler logic in try-except and close the socket in finally. This prevents leaks and ensures the server does not accumulate unusable file descriptors.

Example pitfall
If you leave a disconnected socket in the global clients list, broadcast attempts will fail and resources will remain allocated until process exit.
Practical check
Simulate abrupt client termination and verify that the server removes the socket from shared structures and closes it.
