Select loop example

Below is the chapter's non-blocking server using select. Note setblocking(False) on sockets and how readable sockets are handled in the loop.

# multi_client_select_server.py
import socket
import select

HOST = '127.0.0.1'
PORT = 65432

server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
server_socket.bind((HOST, PORT))
server_socket.listen(5)
server_socket.setblocking(False)

inputs = [server_socket]

while inputs:
    readable, _, _ = select.select(inputs, [], [])
    for sock in readable:
        if sock is server_socket:
            conn, addr = server_socket.accept()
            conn.setblocking(False)
            inputs.append(conn)
        else:
            data = sock.recv(1024)
            if data:
                sock.sendall(data)
            else:
                inputs.remove(sock)
                sock.close()
Key mechanics
  • Select blocks until one or more sockets are ready, avoiding busy-waiting.
  • Accept new connections only when the listening socket is ready.
  • Remove and close sockets on empty reads to release resources.
Testing tip
Run multiple clients and observe that a single process handles interleaved I/O without spawning threads.
Pro tip

Consider using a small timeout in select to allow periodic maintenance or shutdown checks.
