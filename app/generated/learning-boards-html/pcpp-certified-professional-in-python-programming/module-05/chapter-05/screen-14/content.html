Module 5 › Chapter 5.5 › Key Concepts
Concurrency
Ability to serve multiple tasks or clients by interleaving or parallelizing execution.
Threading
Spawn a thread per client to simplify handling; good for I/O-bound workloads but costs more resources.
Non-blocking + select
Use non-blocking sockets and select to monitor readiness so one loop can service many sockets efficiently.
Takeaway

Match your concurrency strategy to expected load: threading for simplicity and moderate scale; multiplexing for high-concurrency, low-traffic workloads.
