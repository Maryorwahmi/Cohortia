Module 5 › Chapter 5.5 › Non-blocking sockets
Definition

What non-blocking means in practice

A non-blocking socket's receive and send calls return immediately; they do not wait for data or buffer space. In a multiplexed server you set sockets to non-blocking and then use select to find which are ready for I/O.

Concrete example
If a client has no data to send, calling receive on a non-blocking socket returns immediately with no data rather than waiting for the next byte.
Misconception check
Non-blocking only changes call behavior. You still need a readiness mechanism like select to avoid inefficient polling loops.
API
Set the socket to non-blocking with a setblocking(False) call and handle immediate return semantics.
When to use
Use for many low-traffic connections where thread-per-client would consume too many resources.
