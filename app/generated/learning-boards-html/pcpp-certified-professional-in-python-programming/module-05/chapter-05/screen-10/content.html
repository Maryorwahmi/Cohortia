Connection lifecycle in select loop

1. Accept
When listening socket is ready, accept a new connection, set non-blocking, and add to inputs.
2. Read
If a client socket is readable, call receive. Non-empty data is processed; empty data signals disconnect.
3. Cleanup
On empty read or error remove the socket from inputs and close it promptly to release resources.
Partial I/O note
Non-blocking writes may accept fewer bytes; production servers maintain per-connection send buffers and monitor write readiness as needed.
Key Takeaway

Maintain a correct monitored set and handle empty reads as disconnects; plan for buffering when upgrading beyond simple echo behavior.
