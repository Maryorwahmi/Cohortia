Activity: Multi-client chat server

Step-by-step guide to extend a threaded echo server into a broadcast chat server with proper locking.

Step 1 — Shared state
Create a connected_clients list and a clients_lock. Add each conn to the list under the lock when accepted.
Step 2 — Broadcast
Implement a broadcast function that sends a message to other clients while holding the lock, removing failing sockets as needed.
Step 3 — Cleanup
Remove the client's socket under lock on disconnect and close it in the finally block of the handler.
Step 4 — Test
Run multiple client instances, send messages, and simulate disconnects to validate the broadcast and cleanup logic.
Example snippet
# broadcast helper (see activity)
with clients_lock:
    for client_conn in connected_clients:
        if client_conn != sender_conn:
            try:
                client_conn.sendall(message)
            except socket.error:
                client_conn.close()
                connected_clients.remove(client_conn)
