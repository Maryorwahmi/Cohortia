Background receive thread

Start a thread that loops on receive and prints messages so the main thread remains responsive to user input.

# tcp_chat_client.py
import socket
import threading
import sys

HOST = '127.0.0.1'
PORT = 65432

def receive_messages(sock):
    while True:
        try:
            data = sock.recv(1024)
            if not data:
                print("
Disconnected from server.")
                break
            print(f"
{data.decode().strip()}
Your message: ", end="")
            sys.stdout.flush()
        except socket.error as e:
            print(f"
Socket error during receive: {e}")
            break
Implementation notes
Make the receive thread daemon if you want quick exit. Ensure you detect server disconnects and close the socket to avoid hanging threads.
Testing
Run multiple client terminals, send messages, and verify broadcasts and graceful disconnect handling.
Key Takeaway

A receiver thread keeps the client responsive and mirrors server-side concurrency patterns for interactive apps.
