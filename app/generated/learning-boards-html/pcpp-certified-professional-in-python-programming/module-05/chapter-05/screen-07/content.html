Architecture

Global clients list with a lock

Use a shared list to track active client sockets and a lock to serialize mutations. Broadcasts iterate under the lock or copy the list under lock then send without holding the lock to reduce contention.

# snippet from activity
connected_clients = []
clients_lock = threading.Lock()

def broadcast_message(sender_conn, message):
    with clients_lock:
        for client_conn in connected_clients:
            if client_conn != sender_conn:
                try:
                    client_conn.sendall(message)
                except socket.error:
                    client_conn.close()
                    connected_clients.remove(client_conn)
Notes
  • Acquire the lock when adding or removing sockets to keep the clients list consistent.
  • To reduce contention, copy the list while holding the lock and release it before sending to avoid blocking other join/leave operations.
  • Test failure paths by simulating send errors and abrupt disconnects to ensure removal logic is correct.
Key Takeaway

Use a lock to protect shared client lists; prefer short critical sections to keep concurrency high.
