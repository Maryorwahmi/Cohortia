UDP socket and methods
Create a datagram socket and use sendto/recvfrom which include addresses directly.
Typical calls
socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
s.sendto(message.encode(), (host, port))
data, addr = s.recvfrom(buffer_size)
Client safeguard
Call s.settimeout(1.0) before recvfrom to avoid indefinite blocking when a server fails to reply.
Quick code panel
import socket

s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
# send a datagram to target
s.sendto(b"hello", ("127.0.0.1", 65432))
# set timeout to avoid hanging when waiting for a reply
s.settimeout(1.0)
try:
  data, addr = s.recvfrom(1024)
  print("Received:", data)
except socket.timeout:
  print("No response received within timeout period.")
s.close()
Note: recvfrom returns a pair of the payload and the sender's address so the server can reply directly.
