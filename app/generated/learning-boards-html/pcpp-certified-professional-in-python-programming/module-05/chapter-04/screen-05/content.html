Module 5 › Chapter 5.4 › UDP vs TCP
TCP
Connection-oriented, ordered, reliable with retransmission.
  • socket.SOCK_STREAM, sendall, recv
  • Use for web requests, file transfer, transactions
  • Higher overhead due to handshake and state
Misconception
Believing TCP is always faster; in fact, TCP's reliability mechanisms add latency compared with UDP.
UDP
Connectionless, datagrams, no ordering or retransmission by default.
  • socket.SOCK_DGRAM, sendto, recvfrom
  • Use for DNS, VoIP, video, gaming, time sync
  • Lower overhead and latency
Key takeaway
Match your application's tolerance for lost or out-of-order data to the protocol properties before choosing UDP.
