Module 5 › Chapter 5.4 › Key Concepts
UDP
Connectionless, unreliable transport for datagrams.
Datagram
A self-contained packet that includes addressing information.
sendto / recvfrom
API calls for UDP: sendto specifies destination; recvfrom returns data and sender address.
Takeaway

Use UDP when timeliness and low overhead are more important than guaranteed delivery; otherwise use TCP or add application-level reliability.
