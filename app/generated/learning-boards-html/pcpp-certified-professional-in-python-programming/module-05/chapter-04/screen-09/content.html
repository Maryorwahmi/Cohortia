Echo workflow
Start server, send datagram, observe server logs, and client receives echo or times out.
Step 1 — Server
Bind and call recvfrom in a loop; print data and addr.
Step 2 — Client
sendto a short message and settimeout before attempting recvfrom.
Step 3 — Observe
Server logs the message; client receives the echoed payload or handles timeout.
Experiment ideas
  • Run client without timeout then kill server to see a blocking recvfrom.
  • Send many short messages and observe occasional loss on congested networks.
  • Add sequence numbers to messages to detect dropped or reordered datagrams.
