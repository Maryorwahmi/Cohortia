Assessment idea
Multiple-choice and practical checks to validate understanding of UDP trade-offs.
Question
Which socket type and method pair is most suitable to broadcast non-critical periodic updates?
Answer: socket.SOCK_DGRAM with sendto()
Question
What happens if recvfrom is called with no timeout and the server never responds?
Answer: The client blocks indefinitely; use settimeout() to avoid this.
Practical checklist

Confirm tolerance for loss, plan retries if needed, set client timeouts, and protect UDP servers from spoofing and rate-based attacks.
