Module 5 › Chapter 5.4 › UDP Client
Client pattern
Create socket, sendto, set timeout, recvfrom, handle exceptions, close socket.
Send
s.sendto(message.encode(), (HOST, PORT)) — address must be provided on each call.
Receive
data, addr = s.recvfrom(1024) — returns payload and sender address.
Timeout example
Call s.settimeout(1.0) and catch socket.timeout to avoid indefinite blocking.
udp_client.py
import socket

HOST = '127.0.0.1'
PORT = 65432

with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as s:
  message = "Hello, UDP Cohortia!"
  s.sendto(message.encode(), (HOST, PORT))
  print(f"Sent: {message}")
  s.settimeout(1.0)
  try:
    data, server_addr = s.recvfrom(1024)
    print(f"Received from {server_addr}: {data.decode()}")
  except socket.timeout:
    print("No response received within timeout period.")
print("Client finished.")
