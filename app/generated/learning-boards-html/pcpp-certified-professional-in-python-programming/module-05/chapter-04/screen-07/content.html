Module 5 › Chapter 5.4 › UDP Echo Server
Server structure
  1. Create socket with socket.SOCK_DGRAM
  2. Bind to (HOST, PORT)
  3. Loop: data, addr = recvfrom(buffer_size)
  4. Process and send reply with sendto(data, addr)
  5. Close socket on shutdown
Server behavior note
No listen or accept calls. recvfrom returns the sender address which you use directly in sendto to reply.
udp_server.py
import socket

HOST = '127.0.0.1'
PORT = 65432

with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as s:
  s.bind((HOST, PORT))
  print(f"UDP Server listening on {HOST}:{PORT}")
  while True:
    data, addr = s.recvfrom(1024)
    print(f"Received {len(data)} bytes from {addr}: {data.decode()}")
    s.sendto(data, addr)
    print(f"Echoed back to {addr}: {data.decode()}")
Run this in a terminal and then send a datagram from a client. Observe the server printing received bytes and echoing them back to the sender address.
