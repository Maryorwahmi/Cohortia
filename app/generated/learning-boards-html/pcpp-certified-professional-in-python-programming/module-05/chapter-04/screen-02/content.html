01
Compare TCP and UDP
Explain the connectionless, unreliable nature of UDP and why it trades reliability for speed. This matters when you need low latency.
VERIFIED COMPETENCY MILESTONE
02
Build a UDP server
Bind a socket with socket.SOCK_DGRAM, use recvfrom to accept datagrams, and echo or respond using sendto. Verify by running locally.
VERIFIED COMPETENCY MILESTONE
03
Build a UDP client
Send datagrams with sendto and optionally await a reply using recvfrom with a timeout to avoid indefinite blocking.
VERIFIED COMPETENCY MILESTONE
04
Choose UDP appropriately
Identify when missing packets are acceptable and the application can handle retransmissions or tolerate loss, such as DNS or media streaming.
VERIFIED COMPETENCY MILESTONE
