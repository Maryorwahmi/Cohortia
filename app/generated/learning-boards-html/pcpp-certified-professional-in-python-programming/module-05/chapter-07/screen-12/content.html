Module 6 › Chapter 5.7 › Pitfalls & Safety
Asyncio pitfalls
  • Forgetting await for coroutines — they won’t run.
  • Using blocking calls like time.sleep inside async code blocks the loop.
  • Omitting await writer.drain can lead to unflushed buffers.
Threaded server pitfalls
  • Shared mutable state needs synchronization with locks.
  • Daemon threads do not guarantee cleanup; call shutdown and server_close explicitly.
  • socketserver does not handle encryption or authentication—add them yourself.
