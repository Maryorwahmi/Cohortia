import asyncio

HOST = '127.0.0.1'
PORT = 65432

async def handle_echo(reader, writer):
    addr = writer.get_extra_info('peername')
    try:
        while True:
            data = await reader.read(1024)
            if not data:
                break
            message = data.decode().strip()
            writer.write(data)
            await writer.drain()
    finally:
        writer.close()
        await writer.wait_closed()
Runtime behaviour
Each incoming connection spawns a coroutine handled by the loop. Await points let other coroutines run while I/O completes, enabling many concurrent handlers on a single thread.
Pitfall
Forgetting await writer.drain prevents backpressure and can cause large write buffers. Always await drain in long-lived servers.
