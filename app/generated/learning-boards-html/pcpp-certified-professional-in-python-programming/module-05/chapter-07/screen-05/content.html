Module 6 › Chapter 5.7 › socketserver
Core idea
A RequestHandler class encapsulates connection logic. The server creates an instance per connection and calls handle(). Mix-ins provide concurrency strategies without manual thread management.
Key classes
  • BaseRequestHandler — base for per-connection handlers.
  • StreamRequestHandler — provides rfile and wfile file-like attributes for TCP streams.
  • TCPServer — base server class for TCP sockets.
Concrete example
This excerpt shows how a ThreadedTCPRequestHandler reads from self.request using recv and echoes with sendall, while ThreadedTCPServer combines ThreadingMixIn with TCPServer to spawn threads.
# handler example (excerpt)
class ThreadedTCPRequestHandler(socketserver.BaseRequestHandler):
  def handle(self):
    while True:
      data = self.request.recv(1024)
      if not data:
        break
      self.request.sendall(data)
Common-mistake
Don’t assume socketserver provides security. Validate and sanitize all input and add TLS or authentication where required.
