Starter task (what to change)
Modify run_asyncio_concurrent_client to accept messages and create tasks via a list comprehension. Then await asyncio.gather(*tasks) to run them concurrently. The chapter's starter code already demonstrates this approach; your modification should generalize it for arbitrary message lists.
Starter pattern
messages = ["A","B","C"]
tasks = [tcp_echo_client(msg, i+1) for i, msg in enumerate(messages)]
await asyncio.gather(*tasks)
Observation checklist
  • Server prints multiple Received/Echoed messages quickly.
  • Elapsed time shows concurrency benefits compared to sequential clients.
  • No blocking calls are present in the async path.
