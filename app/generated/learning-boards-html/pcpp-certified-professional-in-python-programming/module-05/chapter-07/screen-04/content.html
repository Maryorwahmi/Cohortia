Module 6 › Chapter 5.7 › Comparison
Raw sockets
Low-level control, manual accept loops, explicit threading or forking. Best for custom protocols but heavy on boilerplate.
Use case: implementing a non-standard transport or when you need tight socket tuning that higher-level frameworks hide.
socketserver
Handles socket setup and dispatch to handlers. ThreadingMixIn and ForkingMixIn provide per-client concurrency without manual threads.
Use case: simple multi-client services like an echo server or small application servers where per-client threads are acceptable.
asyncio
Single-threaded, non-blocking concurrency using coroutines and an event loop. Reader/writer streams simplify I/O handling.
Use case: high-concurrency I/O-bound services when libraries are async-friendly and you want to avoid thread overhead.
Quick checklist
Boilerplate
Raw sockets high, socketserver low, asyncio moderate.
Concurrency
Raw: manual, socketserver: thread/process per client, asyncio: coroutines on event loop.
Scalability
Asyncio scales best for many I/O-bound connections.
