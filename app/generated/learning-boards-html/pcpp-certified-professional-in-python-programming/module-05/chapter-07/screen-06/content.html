Module 6 › Chapter 5.7 › Server lifecycle
Startup steps
  1. Instantiate server with (HOST, PORT) and RequestHandler.
  2. Set allow_reuse_address = True to ease restarts.
  3. Start serve_forever, often on a daemon thread to keep main responsive.
Per-connection handling
Accept the socket, spawn a thread, instantiate handler, call handle(), loop on recv/send until client disconnects or an error occurs.
Shutdown and cleanup
Call server.shutdown() to stop the serve_forever loop, then server.server_close() to close the listening socket. Avoid relying on daemon threads to perform resource cleanup.
Example pattern
Start server_thread = threading.Thread(target=server.serve_forever, daemon=True). On KeyboardInterrupt call server.shutdown() and server.server_close().
