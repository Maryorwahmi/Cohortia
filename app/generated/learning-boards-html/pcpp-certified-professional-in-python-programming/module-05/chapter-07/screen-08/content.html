Event loop & coroutine lifecycle
An async def function returns a coroutine object. The event loop schedules and runs coroutines, switching when the coroutine awaits an I/O operation. This cooperative pattern avoids blocking the entire process.
Important calls
  • await reader.read(n) — non-blocking read
  • writer.write(data) followed by await writer.drain() — flush write buffer
  • await writer.wait_closed() — ensure writer fully closes
Concrete example
An asyncio echo handler repeatedly awaits reader.read(1024), decodes data for logging, writer.write(data), awaits writer.drain, and finally closes the writer and awaits wait_closed.
Misconception check
asyncio is not a cure for CPU-bound blocking. If your code does heavy computation, schedule it on a separate thread or process using run_in_executor.
