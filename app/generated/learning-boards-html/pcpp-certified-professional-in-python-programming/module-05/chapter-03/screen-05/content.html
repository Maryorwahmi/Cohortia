Module 5 › Chapter 5.3 › Server call sequence
Step-by-step server flow
1. Create: socket.socket(socket.AF_INET, socket.SOCK_STREAM). Allocates a TCP socket.
2. Bind: s.bind((HOST, PORT)). Tie to an IP and port so the OS accepts calls for that port.
3. Listen: s.listen(backlog). Put the socket into listening mode; backlog controls the pending queue.
4. Accept: conn, addr = s.accept(). Blocking call that returns a new socket for the client.
Note: The listening socket remains available to accept more connections while the returned connection socket is used for the single client.
Supporting details
  • HOST choices: 127.0.0.1 restricts to loopback; 0.0.0.0 listens on all interfaces.
  • PORT: choose >1023 to avoid privileged ports and conflicts with well-known services.
  • Backlog: common demo values are 1 or 5; it controls OS queue length before refusing new attempts.
Key Takeaway

Maintain this order to ensure your server is discoverable and able to accept connections reliably.
