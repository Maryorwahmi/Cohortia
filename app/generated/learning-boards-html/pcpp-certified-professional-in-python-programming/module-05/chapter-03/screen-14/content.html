Module 5 › Chapter 5.3 › Key Concepts — Part 1
TCP Server
Listens for incoming TCP connections, accepts and communicates using returned sockets.
TCP Client
Initiates a TCP connection with connect and exchanges bytes with the server.
bind() & listen()
bind associates address/port; listen puts the socket into listening mode with a backlog queue.
Summary: these terms map directly to the server lifecycle you implement in code. Keep them in mind when troubleshooting connection issues.
