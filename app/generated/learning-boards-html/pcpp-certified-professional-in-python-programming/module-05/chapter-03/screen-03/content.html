Error handling & robustness

  • Catch ConnectionRefusedError when the server is not running and report a clear message.
  • Wrap socket operations in try...except to avoid crashes and to close sockets in finally blocks or context managers.
  • Detect b'' from recv as the peer closing the connection and break the receive loop cleanly.

Practice tasks

Start the server, then run the client. Observe the server prints and echoed response.
Modify the client to loop until you type exit. Verify the socket closes after exit.
Enhance the server to keep accepting one new client when the previous client disconnects.
