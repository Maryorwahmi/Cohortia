Module 5 › Chapter 5.3 › Client sequence
Client flow
  1. 1. Create socket: socket.socket(socket.AF_INET, socket.SOCK_STREAM)
  2. 2. Connect: s.connect((HOST, PORT)) — initiates TCP handshake
  3. 3. Send: s.sendall(message.encode()) — send bytes reliably
  4. 4. Receive: response = s.recv(1024) — blocking read
  5. 5. Close: s.close() or let context manager exit
Guidance & examples
Encode text with UTF-8 before sending: message.encode(). Decode after receiving: data.decode().
Don’t bind the client socket unless you need a specific local port; the OS will choose one for client connections.
recv may block — in interactive clients, consider simple loops that break on empty bytes or on an exit command.
Key Takeaway

The client begins the session with connect and must manage encoding, blocking recv, and clean shutdowns.
