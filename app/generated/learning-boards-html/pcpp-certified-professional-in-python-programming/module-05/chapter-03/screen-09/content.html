Module 5 › Chapter 5.3 › sendall() and recv()

sendall()

Sends the entire bytes object, retrying as necessary. Prefer for simple code where you want to ensure the full buffer is transmitted without manual loops.

recv(buffer_size)

Blocks until data arrives, returns up to buffer_size bytes. Returns b'' when the connection has been closed by the peer.

Practical notes
  • Choose a buffer like 1024 or 4096 for simple programs.
  • If your protocol needs exact message framing, include length headers or delimiters.
  • Use b'' from recv as the canonical signal to stop a receive loop.
Key Takeaway

sendall and recv form the reliable data-exchange primitive, but plan for partial reads if you expect large or framed messages.
