Learning Objectives

Bloom goals: Learn → Understand → Apply → Master

Bloom: Learn · Understand · Apply · Master
01
Implement a TCP server

Write a server that creates a socket, binds to an address and port, listens, accepts connections, and communicates over the accepted socket. This skill matters because servers form the persistent endpoint that clients connect to.

VERIFIED COMPETENCY MILESTONE
02
Implement a TCP client

Create a client that connects to a server, sends encoded bytes, receives responses, and closes cleanly. This is critical to verify that your server behaves as expected and to learn the role of connect in establishing a session.

VERIFIED COMPETENCY MILESTONE
03
Understand server and client sequences

Learn the canonical sequences: server uses bind, listen, accept; client uses connect then send/receive. Knowing this order prevents design errors and clarifies when each socket is used.

VERIFIED COMPETENCY MILESTONE
04
Use sendall and recv safely

Practice encoding strings to bytes before sending and decoding bytes after receiving. Also learn blocking behavior of recv and common pitfalls related to buffer size and connection state.

VERIFIED COMPETENCY MILESTONE
