Module 5 › Chapter 5.3 › Key Concepts — Part 2
accept()
Blocks until a client connects and returns a new socket for that client and its address.
sendall() & recv()
sendall transmits the entire bytes buffer; recv returns up to buffer_size bytes and b'' when the peer closed the connection.
Encoding / Decoding
Convert strings to bytes with encode() before sending and decode() received bytes back to strings for processing.
Summary takeaway: these low-level function behaviors are the rules you apply every time you build a TCP client or server in Python. Keep them in your toolkit as you scale to concurrency and non-blocking I/O.
