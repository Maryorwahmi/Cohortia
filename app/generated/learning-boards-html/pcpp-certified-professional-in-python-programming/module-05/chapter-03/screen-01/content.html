Building a Basic TCP Client-Server Application

We will implement a minimal TCP echo server and client in Python, run them in separate terminals, and inspect the exact socket calls that make reliable communication possible.

In this lesson
Create server, bind, listen, accept, then send and receive with sendall and recv.
Coming up
Walkthrough of tcp_server.py and tcp_client.py with run-and-observe terminal outputs.
Why it matters
These sequences are the building blocks for servers that later scale to many clients using threads or non-blocking I/O.
