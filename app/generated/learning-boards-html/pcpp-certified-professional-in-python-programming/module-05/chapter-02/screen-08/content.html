Code walkthrough
import socket

def create_and_inspect_socket(address_family, socket_type, description):
  print(f"--- Creating {description} Socket ---")
  try:
    s = socket.socket(address_family, socket_type)
    print("Socket created successfully!")
    print(f"  Address Family: {s.family} ({'AF_INET' if s.family == socket.AF_INET else 'AF_INET6' if s.family == socket.AF_INET6 else 'Unknown'})")
    print(f"  Socket Type: {s.type} ({'SOCK_STREAM' if s.type == socket.SOCK_STREAM else 'SOCK_DGRAM' if s.type == socket.SOCK_DGRAM else 'Unknown'})")
    s.close()
    print("Socket closed.")
  except Exception as e:
    print(f"Error creating/inspecting socket: {e}")
  print("-" * 40)

if __name__ == "__main__":
  create_and_inspect_socket(socket.AF_INET, socket.SOCK_STREAM, "IPv4 TCP")
  create_and_inspect_socket(socket.AF_INET, socket.SOCK_DGRAM, "IPv4 UDP")

  # create_and_inspect_socket(socket.AF_INET6, socket.SOCK_STREAM, "IPv6 TCP")
Explanation
This code creates sockets with specified address family and type, prints the socket's numeric family and type along with a human-friendly label, and ensures the socket is closed. The optional IPv6 test should only be run if your system supports IPv6.
Concrete example
Creating an IPv4 TCP socket shows family equals AF_INET and type equals SOCK_STREAM. The printed values help map numeric attributes to constants.
Pro tip
Wrap socket creation in try/except and always close sockets to avoid resource exhaustion and address-in-use errors.
