Module 5 › Chapter 5.2 › Learning Objectives — Applied Skills
01
Identify address families and types
Recognize AF_INET for IPv4, AF_INET6 for IPv6, and AF_UNIX for local IPC when available.
VERIFIED COMPETENCY MILESTONE
02
Create and inspect sockets
Write code to create TCP and UDP sockets and read their family and type attributes to verify configuration.
VERIFIED COMPETENCY MILESTONE
03
Make protocol choices
Match application needs to protocol guarantees: use TCP for integrity and UDP for low-latency or stateless messages.
VERIFIED COMPETENCY MILESTONE
04
Manage resources and bindings
Close sockets reliably and be cautious when binding to all interfaces; understand why address-in-use errors occur.
VERIFIED COMPETENCY MILESTONE
