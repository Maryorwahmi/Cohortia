Process Flow

Typical TCP server steps

1. Create socket: socket.socket(AF_INET, SOCK_STREAM)
2. Bind to address and port; consider 0.0.0.0 with care
3. Listen for connections with socket.listen()
4. Accept connections: client_sock, addr = listen_sock.accept()
5. Communicate on client_sock, then close it when done
Practical notes
UDP servers differ: they typically use recvfrom on a single socket without accept since no connection state is created by the transport.
Common mistake
Failing to close accepted sockets or trying to rebind without releasing the old socket leads to 'Address already in use'.
Key Takeaway
Handle both the listening socket and per-connection sockets responsibly and plan for concurrency and cleanup.
