Module 5 › Chapter 5.2 › Transport Layer: TCP and UDP explained
TCP — connection-oriented
Reliable, ordered, and error-checked. Used for HTTP, FTP, and email. Handshake and retransmissions add overhead but preserve integrity.
UDP — connectionless
Fast, low-overhead datagrams with no built-in retransmission or ordering. Good for streaming, games, and DNS where speed beats perfect reliability.
Misconception
UDP is not inherently useless for reliable delivery; applications may add checks and recovery. However, that shifts complexity from the transport to your code.
Comparison
TCP
  • Reliable delivery
  • Ordered stream
  • Higher latency
UDP
  • Unreliable datagrams
  • No ordering guarantees
  • Lower overhead
Concrete example
Real-time voice calls typically use UDP so audio arrives quickly even if a packet is lost; web page transfers use TCP to preserve correctness.
