Question 1 — Protocol selection
A real-time multiplayer game needs low latency and can tolerate occasional packet loss. Which protocol and socket type are appropriate?
Correct answer
UDP with socket.SOCK_DGRAM because it minimizes overhead and delivers updates quickly even if some packets are lost.
Question 2 — Bind failure diagnosis
Your server reports 'Address already in use' when attempting to bind. What is the most likely cause and best practice to prevent it?
Answer
A previously opened socket wasn't closed or the OS still holds the port in a wait state. Ensure sockets are closed (try/finally) and consider socket options responsibly.
