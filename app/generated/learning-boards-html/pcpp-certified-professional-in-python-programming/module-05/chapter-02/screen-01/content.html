TCP/IP Fundamentals & Socket Basics

Understand the four-layer TCP/IP model, compare TCP and UDP, and learn how Python's socket API maps protocols to usable endpoints.

This chapter focuses on practical decisions: choosing reliability or speed, selecting address families, and managing socket resources safely. The included hands-on activity helps you create and inspect sockets to reinforce the concepts.
In this lesson
Practical mapping of TCP/IP layers to sockets, TCP vs UDP trade-offs, and creating sockets in Python.
Practical outcome
You will be able to create IPv4/IPv6 sockets, pick TCP or UDP, and avoid common resource and binding mistakes.
Visual concept
Socket as an endpoint
IP address identifies the host. Port number identifies the process. Together they form a socket address used to route traffic to the correct program.
Explore key topics
TCP vs UDP
Trade-offs between reliability and speed guide protocol choice.
Socket API
Python's socket module maps addresses and transport semantics into objects and methods.
Best practices
Always close sockets and be mindful when binding to public interfaces.
