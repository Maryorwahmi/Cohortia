Module 5 › Chapter 5.2 › TCP vs UDP: trade-offs and use cases
Protocol decision table
When to pick TCP
  • Web pages and APIs
  • File transfers
  • When ordering matters
When to pick UDP
  • Real-time audio/video
  • High-rate telemetry or games
  • Simple query/response like DNS
Concrete scenarios
Web browsing
Use TCP for reliable, ordered page delivery. Retransmission and ordering ensure assets load correctly.
Multiplayer position updates
Use UDP so fresh updates arrive quickly. Occasional loss is acceptable because new updates supersede old ones.
Misconception check
Choosing UDP avoids TCP issues only if the application properly handles packet loss and reordering when required.
