Module 5 › Chapter 5.2 › What is a socket?
Core Concept

Socket as communication endpoint

IP address locates the host. Port number identifies the service. Together they form the socket address your program uses to route traffic.

Server vs Client
  • Listening server socket accepts incoming connections and typically spawns per-connection sockets.
  • Client socket initiates a connection to a server address and port.
Analogy & practical tips
Phone number for IP, extension for port. Remember to close sockets when finished to avoid port conflicts and resource leaks.
Common mistake
Confusing AF_INET with SOCK_STREAM. AF_INET defines address format; SOCK_STREAM defines TCP semantics.
Key Takeaway
Treat sockets as resources and understand their dual role as address and transport handle.
