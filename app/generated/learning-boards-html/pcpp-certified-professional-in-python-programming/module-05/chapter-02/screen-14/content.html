Module 5 › Chapter 5.2 › Key Concepts
TCP/IP Model
A four-layer, practical protocol suite: Application, Transport, Internet, Network Access.
TCP vs UDP
TCP is reliable and ordered; UDP is connectionless and low-overhead — choose by required guarantees.
Socket
An endpoint identified by IP and port; created in Python with the socket module.
Summary takeaway

Always map application needs to transport guarantees, verify address family and socket type when creating sockets, and close sockets to avoid resource and binding errors.
