Module 5 › Chapter 5.2 › Address families and socket types
Address families
  • AF_INET — IPv4 addresses like 192.168.1.1.
  • AF_INET6 — IPv6 addresses for modern networks.
  • AF_UNIX — Unix domain sockets for local IPC where available.
Note: availability of address families is platform-dependent. Test IPv6 support before relying on AF_INET6 in your application.
Socket types
  • SOCK_STREAM — stream-oriented, maps to TCP.
  • SOCK_DGRAM — message-oriented, maps to UDP.
Misconception
Address family governs address format only; transport guarantees are determined by socket type, not AF_INET vs AF_INET6.
Concrete example
Create an IPv4 TCP socket with socket.socket(socket.AF_INET, socket.SOCK_STREAM) or an IPv4 UDP socket with socket.socket(socket.AF_INET, socket.SOCK_DGRAM). Verify by printing s.family and s.type and mapping those to AF_* and SOCK_* constants.
