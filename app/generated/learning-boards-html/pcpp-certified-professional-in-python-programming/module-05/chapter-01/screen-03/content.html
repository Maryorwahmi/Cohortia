Activities that reinforce mapping, diagnostics, and secure design for networked Python apps.

Protocol Identification Activity

For each protocol (HTTP, TCP, IP, Ethernet, DNS, SSH, UDP), state its primary function, map it to an OSI layer, and explain the mapping with the layer responsibilities.

Layer-based Diagnostics

Use the OSI model to reason about a failure scenario and identify likely layers to inspect: application formatting, transport issues, IP routing, or physical link errors.

Security Checklist

Demonstrate basic defensive measures: validate input, use encryption where needed, and apply least privilege when exposing services.
