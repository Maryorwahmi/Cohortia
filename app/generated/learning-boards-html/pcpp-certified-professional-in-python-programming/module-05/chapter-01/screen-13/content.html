Question example

Scenario: Packets arrive out of order and some are missing, but some data is received. Which layer and protocol best explain this?

Answer: Transport layer, UDP. Explanation: UDP is connectionless and does not guarantee order or delivery.
How to justify answers
  • State which layer matches the observed behavior.
  • Give a one-sentence reason linking the symptom to the layer responsibility.
  • Propose a quick test to confirm, such as checking socket type or packet traces.
Practice tip

In assessments, prefer reasoning steps that you can reproduce with a quick test rather than memorized layer numbers.
