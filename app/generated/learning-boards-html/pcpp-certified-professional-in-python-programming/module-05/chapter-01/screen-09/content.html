Architecture

TCP/IP to OSI

TCP/IP: Application
OSI: Application, Presentation, Session
TCP/IP: Transport
OSI: Transport (TCP, UDP)
TCP/IP: Internet
OSI: Network (IP, routing)
TCP/IP: Network Access
OSI: Data Link + Physical
Why this matters for Python

Socket programming typically exposes Transport and Internet behavior. High-level libraries hide Presentation and Session details but you must still ensure data formatting and session policies are consistent.

Example: opening a TCP socket involves transport semantics, but serializing objects before sending is an application-level concern handled separately.
Key Takeaway

Translate OSI ideas into the TCP/IP model when working with real systems and APIs to know which tools to use for diagnosis.
