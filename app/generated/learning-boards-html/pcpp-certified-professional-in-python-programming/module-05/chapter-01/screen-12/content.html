Exercise

Protocol mapping

For each protocol below, write the primary OSI layer and a short justification referencing the layer responsibilities. Protocols: HTTP, TCP, IP, Ethernet, DNS, SSH, UDP.

Template
Protocol: ____ Primary Layer: ____ Why: (one sentence)
Example
HTTP — Application Layer. It defines request/response semantics between browsers and servers at the user-facing level.
Reflection prompts
  • Which mappings were straightforward and which required nuance?
  • Did any protocol span layers? Why might that occur?
  • How would layer mapping change your debugging plan for a failure involving the protocol?
Key Takeaway

Active mapping strengthens your ability to link conceptual layers to protocol behavior during design and debugging.
