Definition

Application, Presentation, Session

These upper layers shape the data and the conversation. Application defines what is exchanged. Presentation formats and secures that data. Session manages dialogs and continuity.

Application
HTTP, FTP, DNS — user protocols.
Presentation
Encryption, compression, encoding.
Session
Auth, session restoration, lifecycle.
Concrete example
A Python web API: the application layer uses HTTP methods; the presentation layer serializes JSON and applies TLS encryption; the session layer verifies tokens and restores user context across requests.
Gotcha
Encrypting only transport without consistent serialization can still leak data through predictable formats.
Practice
Document serialization, character encoding, and session timeout policies for every API you build.
