Transport comparison

TCP

  • Connection-oriented: establishes a session before data transfer.
  • Reliable and ordered delivery via acknowledgments and retransmissions.
  • Used where correctness matters: file transfer, many web services.
Example: A file upload should use TCP to ensure all bytes arrive correctly and in order.
Transport comparison

UDP

  • Connectionless: sends datagrams without a prior handshake.
  • No guarantees for order, delivery, or duplication control.
  • Useful when low latency outweighs guaranteed delivery.
Example: Real-time telemetry can use UDP where occasional packet loss is acceptable.
Misconception
Assuming UDP always outperforms TCP without measuring end-to-end behavior.
Pro tip
When using UDP, design application-level acknowledgments if delivery is important.
