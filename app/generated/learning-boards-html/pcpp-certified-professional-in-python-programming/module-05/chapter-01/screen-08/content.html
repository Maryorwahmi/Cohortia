Hierarchy

Network layer (3)

Manages logical addressing and routing across networks. IP is the primary example of this layer's responsibilities.

Data Link layer (2)

Handles local frames, MAC addressing, and basic error detection on a LAN segment.

Physical layer (1)

Defines cables, connectors, signal voltages, and raw bit transmission rules.

Concrete scenarios & checks
  • If hosts cannot reach each other across routers, check IP addresses, routing tables, and firewall rules (Network layer).
  • If devices on the same switch fail to exchange frames, inspect MAC tables and switch ports (Data Link).
  • If there is no link light or consistent packet loss across devices, test cables and radio signal strength (Physical).
Example: wrong subnet mask prevents proper routing and is a Network layer configuration issue, not an application bug.
Key Takeaway

Use symptom patterns to pick a layer to inspect first and avoid unnecessary code changes when the issue is lower in the stack.
