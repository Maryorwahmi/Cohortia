Module 09 › Chapter 9.8 › Data Model
Term: Document
A JSON-like object, similar to a Python dictionary: keys map to values which can be scalars, arrays, or nested objects.
{ 'name': 'Alice', 'email': 'alice@example.com', 'age': 30, 'interests': ['coding', 'reading'], 'created_at': '2023-09-01T12:00:00' }
When to embed
Embed related data that you read together, like address within a user document.
When to reference
Reference when related data is large or shared across many documents, such as a shared product catalog.
Collections & Databases
Collections group documents. Databases contain collections. Both are created lazily on first insert.
Key Takeaway

Documents are flexible; design them to reflect common access patterns. Collections are organizational, not type-enforced.

Analogy
Think of a collection as a folder of forms; each form can have different fields but serves the same general purpose.
