Insert example
# Insert a single document
user_data = {
  'name': 'Alice',
  'email': 'alice@example.com',
  'age': 30,
  'interests': ['coding', 'reading']
}
result_one = users_collection.insert_one(user_data)
print('Inserted one user with ID:', result_one.inserted_id)

# Insert multiple
many_users = [
  {'name': 'Bob', 'email': 'bob@example.com', 'age': 25},
  {'name': 'Charlie', 'email': 'charlie@example.com', 'age': 35}
]
result_many = users_collection.insert_many(many_users)
print('Inserted IDs:', result_many.inserted_ids)
Remember: insert_many returns a list of inserted_ids. Insert operations are immediate writes unless you configure write concern differently.
Example card
Scenario
Add a new user and store the inserted _id so you can link purchases to that user later.
Key Takeaway

Use result.inserted_id(s) to reference newly created documents and avoid assumptions about automatic merging or id formats.
