Module 09 › Chapter 9.8 › Mistakes
Top mistakes
  • Assuming case-insensitive queries.
  • Using update without $set and losing fields.
  • Running delete_many with an empty filter.
  • Not inspecting result.modified_count or deleted_count.
Remedies
Preview filters with find() before destructive operations.
Use $set/$push/$inc for updates; check operation results.
Log ids and use soft deletes for recoverability when appropriate.
