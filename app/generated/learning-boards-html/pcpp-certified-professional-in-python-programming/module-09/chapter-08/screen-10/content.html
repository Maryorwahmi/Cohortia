Module 09 › Chapter 9.8 › Deletion
Delete examples
# Delete one user named Charlie
delete_result = users_collection.delete_one({'name': 'Charlie'})
print('Deleted count:', delete_result.deleted_count)

# Delete inactive users (dangerous if filter is empty)
delete_many_result = users_collection.delete_many({'status': 'inactive'})
print('Deleted inactive:', delete_many_result.deleted_count)
Always run a find with the same filter first to preview matches and consider soft deletes for safety.
Safety checklist
  • Preview with find() before deleting.
  • Prefer soft deletes when recoverability is needed.
  • Log deleted document ids for audit trails.
Warning
delete_many({}) will remove all documents. Never run it without confirming the filter.
