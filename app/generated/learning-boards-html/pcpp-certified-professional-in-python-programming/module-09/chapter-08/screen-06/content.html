Module 09 › Chapter 9.8 › Connecting
Typical connection code
from pymongo import MongoClient
from pymongo.errors import ConnectionFailure, PyMongoError

try:
  client = MongoClient('mongodb://localhost:27017/')
  db = client.product_catalog
  products = db.products
  print('Connected to MongoDB and accessed products collection')
except ConnectionFailure as e:
  print('Could not connect to MongoDB:', e)
  exit()
except PyMongoError as e:
  print('PyMongo error:', e)
  exit()
Note: Database and collection names create resources only on insert. Client creation may be deferred until first operation.
Checklist
  • Install PyMongo with pip before running code.
  • Use try-except for ConnectionFailure and PyMongoError.
  • Close client when done to release resources.
Pro tip
Use a connection URI for cloud instances. Test connectivity with a small read to validate auth credentials.
Key Takeaway

Create MongoClient safely, access db.collection lazily, and always handle connection exceptions to avoid crashes.
