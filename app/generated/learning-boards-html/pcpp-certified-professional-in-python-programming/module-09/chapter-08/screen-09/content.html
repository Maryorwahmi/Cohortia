Module 09 › Chapter 9.8 › Updates
Update examples
# Update one: set age and status
update_result = users_collection.update_one(
  {'name': 'Alice'},
  {'$set': {'age': 31, 'status': 'active'}}
)
print('Modified:', update_result.modified_count)

# Update many: add default status
update_many = users_collection.update_many(
  {'status': {'$exists': False}},
  {'$set': {'status': 'pending'}}
)
print('Modified many:', update_many.modified_count)
Use upsert=True to create when no match is found, but be mindful of unintended inserts.
Pitfall & remedy
Accidental replacement
Providing an update document without operators replaces the matched document. Always use $set or other operators when intending partial updates.
Key Takeaway

Use update operators for granular changes, check modified_count, and test upsert behavior before using in production.
