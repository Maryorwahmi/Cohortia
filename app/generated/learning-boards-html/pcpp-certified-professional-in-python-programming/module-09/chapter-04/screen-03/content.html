Assessment plan
You will complete a blog system: User and Post models, table creation, session-bound functions for create/read/update/delete, and a CLI or test script to exercise them.
Create
create_user, create_post
Handle IntegrityError and rollback on conflicts.
Read
get_posts_by_user, get_all_posts
Use joinedload for related objects when needed.
Update
update_post_title
Session tracks changes; commit to persist updates.
Delete
delete_post
Use cascade rules for related objects to avoid integrity errors.
Reflection prompt
When would you prefer SQLAlchemy Core over the ORM? Consider bulk performance and explicit SQL control versus domain clarity and relationship navigation.
Key Takeaway

Use ORM for domain-centric code and Core when you need precise SQL or extreme bulk performance.
