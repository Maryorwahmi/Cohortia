Learning Objectives
We will build, query, and manage ORM models, and identify performance pitfalls.
01
Understand ORM vs Core
Grasp the object-oriented approach to persistence and why it improves clarity when working with domain objects.
Mnemonic: Objects > Tables
VERIFIED COMPETENCY MILESTONE
02
Define declarative models
Use declarative_base and Column definitions to map classes to tables and include relationships for navigation.
Mnemonic: Class + Column = Table
VERIFIED COMPETENCY MILESTONE
03
Manage Sessions & transactions
Create a session per unit of work, commit or rollback, and avoid detached object surprises.
Mnemonic: One session, one unit
VERIFIED COMPETENCY MILESTONE
04
Avoid N+1 and eager-load effectively
Use joinedload or selectinload where appropriate to fetch related objects efficiently.
Mnemonic: Load once, use many
VERIFIED COMPETENCY MILESTONE
