Create & Commit
Instantiate model objects, add to session, and commit. Use try/except for IntegrityError to rollback when constraints are violated.
with Session() as session:
  author = Author(name='George Orwell')
  session.add(author)
  session.commit()

# Read and filter
with Session() as session:
  books = session.query(Book).filter(Book.title.like('%Farm%')).all()

# Update
with Session() as session:
  a = session.query(Author).filter_by(name='J.K. Rowling').first()
  if a:
    a.name = 'Joanne K. Rowling'
    session.commit()

# Delete
with Session() as session:
  b = session.query(Book).filter_by(title='Animal Farm').first()
  if b:
    session.delete(b)
    session.commit()
Query laziness
Build complex queries with filters and only execute when you call .all(), .first(), or iterate. This lets you dynamically construct queries before executing them.
Practical note
Prefer filter_by for simple equality checks and filter for expressions like .like() or joins. Understand which generates the SQL you expect by enabling echo=True during debugging and then turning it off.
Key Takeaway
The Session batches changes and emits SQL at flush/commit time; use this to group work into a single transaction for consistency.
