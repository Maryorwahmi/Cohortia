IntegrityError handling
Wrap commit in try/except IntegrityError, call session.rollback() in the except block, and return a clear failure result or message.
try:
  session.commit()
except IntegrityError:
  session.rollback()
  # inform caller or retry as appropriate
Session-per-unit-of-work
Create a session for each logical operation and close it. This reduces identity confusion and connection leaks.
When to use Core
Prefer Core for tight, optimized SQL or large bulk operations where ORM object creation is too expensive.
Key Takeaway
Combine ORM for domain code and Core for specialized SQL; always handle errors and manage sessions explicitly.
