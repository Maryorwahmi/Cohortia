CREATE TABLE example
Use NOT NULL and PRIMARY KEY for important constraints.
cursor.execute('''
CREATE TABLE IF NOT EXISTS products (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  price REAL NOT NULL,
  quantity INTEGER NOT NULL
)
''')
conn.commit()
Practical check: use PRAGMA table_info('products') to inspect columns after creation.
Manifest typing explained
SQLite's typing is guided by value storage classes, not strictly by declarations. That gives flexibility but requires caution.
Example & Misconception
You can insert the number 42 into a TEXT column and SQLite will accept it. If your app needs rigid typing, implement checks in Python.
Key Takeaway

Define constraints to catch obvious problems, but validate important types and business rules in application code.
