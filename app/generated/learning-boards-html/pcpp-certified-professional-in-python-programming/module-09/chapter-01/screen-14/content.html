Module 9 › Chapter 9.1 › Key Concepts
Database / Relational
Data in tables with rows and columns; keys model relationships.
SQLite
A serverless, single-file SQL engine embedded in applications.
Parameterized Query
Placeholders separate SQL from values and prevent SQL injection.
Summary: Model your data with clear keys, prefer SQLite when file-based storage and simplicity fit your use case, and always parameterize queries and manage transactions carefully.
