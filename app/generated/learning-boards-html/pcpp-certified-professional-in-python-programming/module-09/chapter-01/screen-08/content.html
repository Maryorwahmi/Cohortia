Bulk insert example
Use executemany and parameter placeholders to insert multiple rows safely.
products_to_insert = [
  ('Laptop', 1200.00, 10),
  ('Mouse', 25.50, 50),
  ('Keyboard', 75.00, 30)
]

cursor.executemany(
  'INSERT INTO products (name, price, quantity) VALUES (?, ?, ?)',
  products_to_insert
)
conn.commit()
After executemany, you can inspect cursor.rowcount to see affected rows and then run a SELECT to verify inserted rows.
Security contrast
Bad: concatenating user values into SQL strings. Good: use placeholders to keep code robust against injection attacks.
Misconception
Thinking parameterized queries are only about syntax. They are primarily a security control that separates code from data.
Key Takeaway

Always use parameterized queries for any user-supplied values and commit after inserts to persist changes.
