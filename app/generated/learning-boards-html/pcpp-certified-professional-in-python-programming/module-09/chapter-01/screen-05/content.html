What is SQLite?
A serverless SQL database engine stored in a single file for embedded and local use.
Use cases
Local development, small apps, prototypes, tests, and embedded devices.
Strengths
Zero-config, single file, transactional, included in Python standard library.
Limitations
Less suited for multi-host scaling and high write-concurrency workloads.
Key Takeaway

SQLite reduces operational cost for many workflows; pick it when simplicity and local file storage are advantages.

Practical example
Keep a single inventory.db file for local testing and small deployments. When traffic grows, plan a migration to a client-server DB.
Migration thought exercise
  • Start with SQLite for fast iteration.
  • Design schema with keys and constraints to ease migration later.
  • When scaling, export schema and data to a server DB.
