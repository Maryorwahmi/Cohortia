Quick connect example
This code opens inventory.db and creates a cursor for SQL execution.
import sqlite3

conn = sqlite3.connect('inventory.db')
cursor = conn.cursor()

cursor.execute('CREATE TABLE IF NOT EXISTS products (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  price REAL NOT NULL,
  quantity INTEGER NOT NULL
)')
conn.commit()
conn.close()
Explanation
  • sqlite3.connect returns a Connection bound to a file.
  • cursor.execute runs SQL; commit persists changes.
  • Always close the connection to release resources.
Common misconception
Assuming the database file appears only after commit. In fact, SQLite will create the file when connecting, but your DDL/DML changes are not permanent until you commit.
Check your understanding
After creating the table but before commit, what happens if the program crashes? You would lose uncommitted changes — that's why commits matter.
Key Takeaway

Open a connection, use a cursor to execute SQL, commit to persist, and close or use a context manager to auto-manage resources.
