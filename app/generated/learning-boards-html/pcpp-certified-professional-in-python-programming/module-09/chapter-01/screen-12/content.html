Try/Except/Finally pattern
Ensure rollback on error and close the connection in finally.
conn = sqlite3.connect('inventory.db')
cursor = conn.cursor()
try:
  cursor.execute(...)
  conn.commit()
except sqlite3.Error as e:
  print('Database error:', e)
  conn.rollback()
finally:
  conn.close()
Context manager alternative
Using with sqlite3.connect(...) as conn: simplifies commit/rollback and closes the connection automatically.
When to prefer each
  • Use with for short, atomic flows.
  • Use try/finally when you need explicit lifecycle control across multiple operations.
Key Takeaway

Prefer context managers for cleaner code; always ensure rollback and close to maintain integrity and release file locks.
