Module 9 › Chapter 9.1 › Transactions: Commit and Rollback
Transaction steps
  1. Begin by opening a connection (implicit transaction start).
  2. Execute DML/DDL statements via cursor.
  3. On success call conn.commit() to persist.
  4. On error call conn.rollback() and handle the exception.
Context manager pattern
with sqlite3.connect('inventory.db') as conn: cursor = conn.cursor(); ... — commits on success, rolls back on exception.
Concrete example & pitfall
If you insert rows and forget commit, those inserts are lost after the program ends. If an exception occurs mid-transaction, rollback restores the previous consistent state.
Key Takeaway

Treat related database changes as a unit and manage commit/rollback explicitly or via a context manager to avoid partial state.
