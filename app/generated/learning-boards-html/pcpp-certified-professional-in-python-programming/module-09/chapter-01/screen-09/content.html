Select examples
Common patterns for querying and retrieving rows.
# fetch all products
cursor.execute('SELECT id, name, price, quantity FROM products')
rows = cursor.fetchall()
for row in rows:
  print(row)

# fetch a single product safely
cursor.execute('SELECT * FROM products WHERE name = ?', ('Laptop',))
product = cursor.fetchone()
if product:
  print('Found:', product)
else:
  print('Not found')
Iterating the cursor is memory friendly for large result sets: for row in cursor: process(row)
Misconception & Tip
Misconception: fetchall always returns tuples in a predictable order. Tip: use ORDER BY when the row order matters and LIMIT to bound large queries.
Check your understanding
When would you prefer fetchone over fetchall? Use fetchone when you expect a single result or want to test existence without loading all rows into memory.
Key Takeaway

Pick the fetching strategy to match result size and logic needs; parameterize WHERE values for safety.
