Update example
Change the Laptop price safely and confirm the change.
cursor.execute('UPDATE products SET price = ? WHERE name = ?', (1250.00, 'Laptop'))
print(f'Updated rows: {cursor.rowcount}')
conn.commit()

# verify
cursor.execute('SELECT price FROM products WHERE name = ?', ('Laptop',))
print(cursor.fetchone())
Delete example & warnings
Delete by identifier and check rowcount. Avoid running DELETE without a WHERE clause.
Warning
A DELETE without WHERE removes every row. Always scope destructive operations and test on a copy or dev database first.
Key Takeaway

Confirm the intended target before updating or deleting. Use parameters and check rowcount to validate actions.
