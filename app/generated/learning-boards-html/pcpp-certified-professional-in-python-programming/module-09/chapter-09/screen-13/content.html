Module 10 › Chapter 9.9 › Raw SQL vs ORM
ORM advantages
  • Automatic parameterization and safety.
  • Clear mappings and maintainable code.
  • Works well for common relationship patterns.
When to use raw SQL
  • Specialized DB features or highly optimized analytical queries.
  • Administrative operations not exposed by the ORM.
  • When EXPLAIN shows the ORM generates inefficient SQL and a hand-tuned query helps.
Guideline

Prefer ORM for most work; use raw SQL sparingly, document why, and parameterize every input.
