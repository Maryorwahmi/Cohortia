Module 10 › Chapter 9.9 › N+1 Problem
Problem demonstration
authors = session.query(Author).all()
for author in authors:
  for post in author.posts:
    print(post.title)
With lazy relationships this triggers one query for authors and one query per author for posts — N+1 queries total.
Common mistake

Assuming individual queries are cheap; many small round trips add latency, especially across networked DBs.

Fix with eager loading
from sqlalchemy.orm import joinedload
authors_optimized = session.query(Author).options(joinedload(Author.posts)).all()
for author in authors_optimized:
  for post in author.posts:
    print(post.title)
This fetches authors and posts in a single joined query. Alternatively, selectinload issues one extra IN query that can be faster for many parents.
Key Takeaway

Detect N+1 with SQL logs and remove it by eager loading; choose joinedload or selectinload based on result shape.
