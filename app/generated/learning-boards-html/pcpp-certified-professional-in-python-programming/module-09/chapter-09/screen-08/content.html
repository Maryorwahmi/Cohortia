Module 10 › Chapter 9.9 › SQL Injection
Vulnerable pattern
query = f"SELECT * FROM users WHERE username = '{username}' AND password = '{password}'"
This pattern mixes data and structure. An attacker can inject SQL fragments into username to change the query logic.
Safe parameterized form
from sqlalchemy import text
stmt = text("SELECT * FROM users WHERE username = :username AND password = :password")
session.execute(stmt, {"username": username, "password": password})
Here the structure is fixed and values are bound separately, preventing data from being interpreted as SQL.
Key Takeaway

Prefer ORM query methods or parameterized raw SQL; never trust manual sanitization alone.
