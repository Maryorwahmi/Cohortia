Process: Use EXPLAIN to diagnose
1. Reproduce
Capture the exact slow SQL and environment to analyze deterministically.
2. Explain
Run EXPLAIN or EXPLAIN ANALYZE to see plan nodes, row estimates, and timing.
3. Act
Add an index or rewrite joins, then measure again with EXPLAIN.
4. Validate
Confirm reduced cost or runtime; watch for unexpected write costs or plan changes.
Example EXPLAIN snippet
EXPLAIN ANALYZE SELECT * FROM users WHERE email = 'foo@example.com';
-- Look for: Index Scan vs Seq Scan, actual time and rows
Key takeaway

EXPLAIN is diagnostic: it tells you where the database spends time and whether an index is used. Use EXPLAIN ANALYZE to measure real performance.
