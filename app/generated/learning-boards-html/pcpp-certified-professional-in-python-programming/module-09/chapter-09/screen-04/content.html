Module 10 › Chapter 9.9 › Indexing
Definition

An index is a lookup structure that maps values to row locations to reduce scanned rows for common filters, joins, and sorts.

When to add an index
  • Columns frequently used in WHERE or JOIN conditions.
  • Columns used for ORDER BY if sorting large sets.
  • Composite indexes to match multi-column queries.
Common mistakes
Over-indexing every column, indexing low-selectivity boolean flags, or assuming an index will be used without checking the query plan.
Concrete example
CREATE INDEX idx_users_email ON users (email);
Explanation

This index helps queries that filter by users.email. If a query uses that filter frequently and returns a small subset, the index is highly beneficial.

Key Takeaway

Add indexes to speed critical reads, then measure with EXPLAIN and monitor write impact.
