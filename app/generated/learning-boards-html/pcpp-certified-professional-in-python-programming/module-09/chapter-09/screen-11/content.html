Example listeners
from sqlalchemy import event
from sqlalchemy.orm import mapper
import datetime

@event.listens_for(mapper, 'before_insert')
def receive_before_insert(mapper, connection, target):
  target.created_at = datetime.datetime.now()
  target.updated_at = datetime.datetime.now()
This ensures timestamps are set when new objects are persisted without repeating code in many places.
Best practices
  • Keep listeners fast and side-effect free.
  • Use them for validation, defaults, or audit metadata.
  • Unit-test listeners by asserting object state after session flush/commit.
Pro Tip

If a listener must perform heavy work, enqueue a background job instead of executing it synchronously during the transaction.
