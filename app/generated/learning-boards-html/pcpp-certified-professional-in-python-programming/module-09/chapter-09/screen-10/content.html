Module 10 › Chapter 9.9 › Custom Types
Why use custom types?

They let application code work with rich Python objects while persisting them as database-friendly primitives.

Example TypeDecorator
from sqlalchemy import TypeDecorator, String
import uuid

class UUIDType(TypeDecorator):
  impl = String(36)
  cache_ok = True

  def process_bind_param(self, value, dialect):
    if value is None:
      return value
    return str(value)

  def process_result_value(self, value, dialect):
    if value is None:
      return value
    return uuid.UUID(value)
Practical steps
  1. Define TypeDecorator and tests for bind/result processing.
  2. Add Column(UUIDType, default=uuid.uuid4, unique=True).
  3. Recreate schema or use migrations, then verify queries return UUID objects.
Key Takeaway

Custom types let you keep rich Python semantics while storing compatible database values; test both directions.
