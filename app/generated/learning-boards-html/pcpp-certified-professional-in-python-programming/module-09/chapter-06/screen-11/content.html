Module 9 › Chapter 9.6 › Delete: Remove Rows
DELETE example
with Session() as session:
  user_to_delete = session.query(User).filter_by(name='Charlie').first()
  if user_to_delete:
    session.delete(user_to_delete)
    session.commit()
    print(f"Deleted user: {user_to_delete}")
  else:
    print('Charlie not found for deletion.')

  # Verify deletion
  deleted_charlie = session.query(User).filter_by(name='Charlie').first()
  if deleted_charlie is None:
    print('Charlie not found in database (successfully deleted).')
Notes
  • Commit after delete to finalize removal.
  • Verify with follow-up queries to ensure deletion succeeded.
  • Consider soft deletes for auditability instead of permanent deletion.
Key Takeaway

Delete by marking the instance with session.delete and commit. Verify results and be thoughtful about cascading and soft-delete patterns.
