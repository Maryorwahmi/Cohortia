Module 9 › Chapter 9.6 › Create: Add & Commit
CREATE example
with Session() as session:
  new_user = User(name='Alice', email='alice@example.com')
  session.add(new_user)
  session.commit()
  print(f"Created user: {new_user}")

  # add multiple
  bob = User(name='Bob', email='bob@example.com')
  charlie = User(name='Charlie', email='charlie@example.com')
  session.add_all([bob, charlie])
  session.commit()
Notes & checks
  • After commit, auto-incremented IDs are populated on instances.
  • Use add_all to stage many objects for readability.
  • Avoid uncommitted sessions if you expect persistent changes across program runs.
Common mistake
Calling session.close without commit will discard pending changes if transaction not committed. Close only after commit or rollback.
Key Takeaway

Add objects to a session and commit once you are ready. Group related changes to reduce transaction overhead and avoid performance penalties.
