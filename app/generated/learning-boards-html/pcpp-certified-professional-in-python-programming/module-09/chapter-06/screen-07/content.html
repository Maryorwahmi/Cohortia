What is a Session?

A Session tracks object states and translates those changes to SQL. It groups related operations into a transactional unit of work.

Best practice

Create a session factory via sessionmaker and prefer using: with Session() as session: so sessions are closed reliably.

Misconception
An object returned from one session is not automatically attached to another session. Reattach or requery before modifying in a different session.
Session factory example
from sqlalchemy.orm import sessionmaker

Session = sessionmaker(bind=engine)

with Session() as session:
  # work with session: add, query, commit
  new_user = User(name='Alice', email='alice@example.com')
  session.add(new_user)
  session.commit()
Key Takeaway

Treat sessions as short-lived units of work. Use sessionmaker and with blocks to manage lifecycle, commit to persist, and rollback on errors.
