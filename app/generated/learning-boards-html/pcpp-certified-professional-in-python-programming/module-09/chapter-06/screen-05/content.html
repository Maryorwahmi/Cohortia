Module 9 › Chapter 9.6 › Declarative Base
Core concept

declarative_base creates a Base class that stores table mappings and metadata. Models that inherit from Base are registered automatically.

Model anatomy
  • __tablename__: explicit table name string.
  • Column attributes: Column(Integer), Column(String(...)).
  • Optional __repr__ to aid debugging.
Misconception

Defining a model does not modify the database until you run create_all or apply migrations. Model code alone is inert with respect to the DB schema.

Example model
from sqlalchemy.orm import declarative_base
from sqlalchemy import Column, Integer, String

Base = declarative_base()

class User(Base):
  __tablename__ = 'users'
  id = Column(Integer, primary_key=True)
  name = Column(String(50), nullable=False)
  email = Column(String(100), unique=True, nullable=False)

  def __repr__(self):
    return f"<User(id={'{'}self.id{'}'}, name='{'{'}self.name{'}'}', email='{'{'}self.email{'}'}')>"
Call Base.metadata.create_all(engine) to create tables for registered models.
Key Takeaway

declarative_base is the registry for model mappings. Define Column attributes on classes and then explicitly create tables when ready.
