Module 9 › Chapter 9.6 › Detached Objects & Lifecycle
Why detachment happens

When a session closes, objects it returned become detached. Detached objects are not tracked for changes by any active session until reattached or merged.

Solutions
  • Keep read-modify-write in one session where possible.
  • Use session.merge(detached_obj) to attach state to a new session.
  • Use with Session() to scope sessions and avoid leaks.
merge example
detached = get_user_somehow()
with Session() as session:
  merged = session.merge(detached)
  merged.email = 'new@example.com'
  session.commit()
Key Takeaway

Design session boundaries deliberately. Reattach detached objects with merge or keep operations in one session to maintain consistent behavior.
