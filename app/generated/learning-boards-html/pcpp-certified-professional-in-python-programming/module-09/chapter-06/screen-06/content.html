Module 9 › Chapter 9.6 › Model & Create Tables
Starter code
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.orm import declarative_base

engine = create_engine('sqlite:///orm_example.db')
Base = declarative_base()

class User(Base):
  __tablename__ = 'users'
  id = Column(Integer, primary_key=True)
  name = Column(String(50), nullable=False)
  email = Column(String(100), unique=True, nullable=False)

Base.metadata.create_all(engine)
print("Table 'users' created or already exists via ORM model.")
Explanation & check
  • create_engine sets up the DB connection object used for DDL and DML.
  • Base.metadata.create_all(engine) inspects Base's registry and issues CREATE TABLE where missing.
  • create_all will not migrate existing tables — use migrations for schema evolution.
Pro tip
Run create_all in development or tests. In production, prefer migrations to manage schema changes safely.
Key Takeaway

Defining models and calling create_all gives you a quick way to materialize tables during development. For production changes, use migrations.
