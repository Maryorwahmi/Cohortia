Module 9 › Chapter 9.6 › Update: Object State
UPDATE example
with Session() as session:
  user_to_update = session.query(User).filter_by(name='Bob').first()
  if user_to_update:
    user_to_update.email = 'robert@example.com'
    session.commit()
    print(f"Updated Bob's email to: {user_to_update.email}")
  else:
    print('Bob not found for update.')
Notes & checkpoints
  • Session automatically detects attribute changes and generates UPDATE statements on flush/commit.
  • Requery or merge objects if you work across session boundaries.
  • Group related updates into a single commit to maintain atomicity.
Common mistake
Changing attributes on a detached object will not be persisted unless merged into a live session or reloaded from the DB.
Key Takeaway

Update by changing attributes on session-attached instances and commit. Avoid detached-object surprises by keeping clear session boundaries.
