READ examples
with Session() as session:
  user_by_id = session.get(User, 1)
  all_users = session.query(User).all()
  alice = session.query(User).filter_by(name='Alice').first()
  users_with_e = session.query(User).filter(User.email.like('%@example.com%')).all()
  ordered_users = session.query(User).order_by(User.name.desc()).all()
Explanation
  • session.get is optimized for primary key lookups.
  • filter_by is convenient for equality checks; filter accepts SQL expressions for flexibility.
  • Use first when you expect one result or want None if absent; use all to get a list.
Pro tip
When performance matters, inspect generated SQL or use Core for complex sets. For many simple reads, ORM query methods are expressive and efficient.
Key Takeaway

Choose get for single primary-key fetches, filter/filter_by for conditions, and always verify query results rather than assuming existence.
