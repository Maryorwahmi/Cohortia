Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Differentiate Core and ORM

Explain how Core builds SQL expressions while ORM maps Python classes to tables. This matters for choosing the right abstraction for your task.

VERIFIED COMPETENCY MILESTONE
02
Define declarative models

Create classes that inherit from declarative_base, set __tablename__, and declare Column attributes so SQLAlchemy maps them to tables and columns.

VERIFIED COMPETENCY MILESTONE
03
Manage Sessions

Use sessionmaker to create sessions, treat each session as a unit of work, and prefer the with-statement to ensure closure and resource cleanup.

VERIFIED COMPETENCY MILESTONE
04
Perform CRUD safely

Add, query, update, and delete ORM instances and commit to persist changes. Understand flush vs commit and when to rollback on error.

VERIFIED COMPETENCY MILESTONE
