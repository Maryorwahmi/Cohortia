Module 9 › Chapter 9.6 › Key Concepts
Declarative Base
Base collects model metadata so classes map to tables and create_all can materialize them.
Session & sessionmaker
Sessions are units of work; use sessionmaker and with blocks, commit to persist, rollback to recover.
CRUD patterns
Add and commit to create, get/query to read, assign then commit to update, delete then commit to remove.
Summary Takeaway

Master declarative models, sessions, and CRUD patterns now; these fundamentals make later topics like relationships and migrations manageable and predictable.
