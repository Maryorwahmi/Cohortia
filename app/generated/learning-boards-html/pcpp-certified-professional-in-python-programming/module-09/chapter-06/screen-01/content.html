Quick orientation
Why this matters

Working with objects instead of raw SQL brings your business logic and data model into the same language. It reduces boilerplate SQL and makes maintenance easier as your application grows.

Common pitfall

Objects live inside a Session. Expecting object state to persist across different sessions without reattaching is a frequent source of confusion.

Visual concept
Class → Row
A declarative class defines columns and the tablename. Creating an instance means a new row is staged in a session.
