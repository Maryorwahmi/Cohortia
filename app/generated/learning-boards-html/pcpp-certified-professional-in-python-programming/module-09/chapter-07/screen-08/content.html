joinedload vs selectinload
joinedload performs a JOIN; selectinload performs a second IN-based SELECT. Each has pros and cons depending on cardinality.
When to use joinedload
Prefer when the join does not multiply rows excessively (small child collections or single-child relationships).
When to use selectinload
Prefer when parents have many children and you want to avoid large joined result sets; selectinload fetches children in one second query via IN.
Terminal demo snippets
# joinedload example
users = session.query(User).options(joinedload(User.posts)).all()

# selectinload example
posts = session.query(Post).options(selectinload(Post.author)).all()
Reflection
Run both and compare SQL logs. Which strategy produced fewer statements and smaller transmitted row counts for your dataset?
