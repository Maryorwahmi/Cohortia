Definition › N+1 Problem
What causes N+1?
Accessing a lazily-loaded relationship inside a loop over many parent objects triggers an additional query per parent.
Example pattern
For user in session.query(User).all(): print(len(user.posts)) — each user.posts access may trigger a SELECT for that user.
Detection

Look at SQL logs: if you see repeated SELECT statements for the same relationship, you likely have N+1.

Quick scenario
If you need all users with their posts for display, prefer eager loading. If you only need a count of posts per user, consider an aggregate query instead of loading all child objects.
Check your understanding
Ask: will my code access related objects for many parents? If yes, eager load. If no, lazy loading may be appropriate.
