Process Flow › join, group_by, having
Filtering across models
Use join() to reference related columns in WHERE clauses and aggregates in GROUP BY queries.
Example uses
  • Find posts by a user: join and filter on User.name.
  • Count posts per user: use func.count() with group_by(User.name).
  • Filter groups: apply having(func.count(Post.id) >= 2).
Code examples
from sqlalchemy import func

# posts by Alice
alice_posts = session.query(Post).join(User).filter(User.name == 'Alice').all()

# count posts per user
post_counts = session.query(User.name, func.count(Post.id)).join(Post).group_by(User.name).all()

# users with at least two posts
users_with_multiple_posts = session.query(User).join(Post).group_by(User.id).having(func.count(Post.id) >= 2).all()
Prefer letting the DB aggregate when you only need counts. Only load full objects when you need to access their attributes or relationships.
