Common Mistakes › Debugging Tips
IntegrityError or missing joins
Verify ForeignKey is declared on the child column and that table names match in the ForeignKey string. A missing FK breaks referential integrity and joins.
Unexpected lazy loads
Turn on SQL echo to see when relationships are loaded lazily. If you see multiple identical SELECTs, you have an N+1 and should try eager options.
relationship args
Double-check back_populates/backref, cascade, and secondary arguments. Incorrect combos lead to confusing in-memory states.
Testing
Write tests that observe both data correctness and the number of SQL statements for key operations to catch regressions early.
