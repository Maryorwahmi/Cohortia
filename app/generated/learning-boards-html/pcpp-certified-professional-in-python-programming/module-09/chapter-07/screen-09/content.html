Code Walkthrough › Create & Query
Create linked objects
Use constructor assignment or set relationship attributes directly before committing the session.
Example workflow
  1. Create parent and child Python objects and set relationships.
  2. session.add_all([...]) then session.commit()
  3. Query back with eager options when you plan to traverse relationships.
Terminal snippet
with Session() as session:
  user1 = User(name='Alice', email='alice@example.com')
  post1 = Post(title='My First Post', content='Hello world!', author=user1)
  session.add_all([user1, post1])
  session.commit()

# lazy load example
retrieved_user = session.query(User).filter_by(name='Alice').first()
for post in retrieved_user.posts:
  print(post.title)

# eager load example
users_with_posts = session.query(User).options(joinedload(User.posts)).all()
Notice the difference in SQL statements between lazy and eager queries when observing logs in the terminal demo.
