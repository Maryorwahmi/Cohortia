  3. Repeat using selectinload and then joinedload to compare SQL queries and row counts.
Reflection prompt

Which eager strategy reduced round-trips without inflating result size for your dataset?

Sample SQL patterns to watch for
  • Repeated SELECT ... FROM posts WHERE user_id = ? (lazy N+1)
  • SELECT ... FROM posts WHERE posts.user_id IN (...) (selectinload)
  • SELECT users.*, posts.* FROM users JOIN posts ... (joinedload)
