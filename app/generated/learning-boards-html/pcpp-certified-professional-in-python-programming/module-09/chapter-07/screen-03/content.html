Evidence of competency
Capture three artifacts: a code snippet defining relationships, a terminal transcript showing reduced queries after eager loading, and a small DB file demonstrating expected cascade behavior. These artifacts show both correct modeling and performance awareness.
Common misconception
Equating ondelete cascade on the database with ORM cascade semantics. Database cascades differ from relationship cascade options that affect object lifecycle within a session.
Quick tip
When you expect to traverse collections for many parents, try selectinload first; for single-parent detail fetches with small child sets, joinedload may be simpler and faster.
