Module 9 › Chapter 9.5 › Update & Delete
Update example
 from sqlalchemy import update

with engine.connect() as connection:
  stmt = update(users_table).where(users_table.c.name == 'Bob').values(email='robert@example.com')
  result = connection.execute(stmt)
  connection.commit()
  print('Rows updated:', result.rowcount)
Check result.rowcount to confirm the number of rows affected and perform a select to verify the update.
Delete example
 from sqlalchemy import delete

with engine.connect() as connection:
  stmt = delete(users_table).where(users_table.c.name == 'Charlie')
  result = connection.execute(stmt)
  connection.commit()
  print('Rows deleted:', result.rowcount)
Omitting where will delete all rows. Use caution and consider adding safety checks or confirmations in application code.
Common Mistake

Running an update or delete without a where clause can change all rows. Always double-check your where condition before commit.
