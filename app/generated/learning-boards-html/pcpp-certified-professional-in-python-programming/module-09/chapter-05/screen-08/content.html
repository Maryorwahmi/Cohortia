Module 9 › Chapter 9.5 › Insert Patterns
Single insert
 with engine.connect() as connection:
  stmt = insert(users_table).values(name='Bob', email='bob@example.com')
  result = connection.execute(stmt)
  connection.commit()
  print('Inserted id:', getattr(result, 'lastrowid', None))
Check result.lastrowid when supported by the database to find the new row's id.
Bulk insert
 with engine.connect() as connection:
  stmt = insert(users_table).values([
    {'name': 'Charlie', 'email': 'charlie@example.com'},
    {'name': 'Dana', 'email': 'dana@example.com'}
  ])
  connection.execute(stmt)
  connection.commit()
Bulk inserts are parameterized and efficient; keep batch sizes reasonable and use transactions to maintain atomicity.
