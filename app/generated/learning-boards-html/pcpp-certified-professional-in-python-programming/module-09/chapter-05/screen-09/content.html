Select examples
 from sqlalchemy import select

with engine.connect() as connection:
  stmt = select(users_table.c.name, users_table.c.email).where(users_table.c.name == 'Alice')
  result = connection.execute(stmt)
  for row in result:
    print(f"Name: {row.name}, Email: {row.email}")
Use column accessors on returned rows to read named fields instead of indexing by position for clarity.
Filtering & ordering
 stmt = select(users_table).where(users_table.c.quantity < 10).order_by(users_table.c.price.desc()).limit(50)
Filter with where, sort with order_by using .desc() or .asc(), and use limit to bound results. Avoid unbounded selects on large tables.
Misconception

Iterating a result object streams rows instead of loading them all into memory, but calling .fetchall or list(result) will load all rows.
