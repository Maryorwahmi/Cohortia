Module 9 › Chapter 9.5 › Raw SQL vs ORM
Raw SQL (strings)
-- Example: raw SQL as strings query = "SELECT * FROM users WHERE id = %s" % user_id connection.execute(query)
  • Full control over SQL text and DB-specific features.
  • Prone to duplication and string-building mistakes.
  • Requires careful parameterization to avoid injection.
Common Mistake

Interpolating user values into SQL strings instead of using parameters can lead to SQL injection vulnerabilities.

SQLAlchemy Core (programmatic)
from sqlalchemy import select stmt = select(users_table).where(users_table.c.id == 1) result = connection.execute(stmt) for row in result: print(row)
  • Builds expressions from Table and Column objects.
  • Generates parameterized SQL automatically.
  • Schema is defined in Python and reused across code.
Key Takeaway

Prefer programmatic SQL when you want structured, reusable queries and safer parameter handling.
