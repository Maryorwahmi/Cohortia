Module 9 › Chapter 9.5 › Execute & Commit
Typical pattern
 from sqlalchemy import create_engine, insert
engine = create_engine('sqlite:///example.db')

with engine.connect() as connection:
  insert_stmt = insert(users_table).values(name='Alice', email='alice@example.com')
  result = connection.execute(insert_stmt)
  connection.commit()
  print('Inserted, commit complete')
The with block ensures the connection is returned to the pool. Commit finalizes changes so they persist across transactions and sessions.
Checks & feedback
  • Inspect result.lastrowid or result.rowcount where available to confirm operations.
  • Use connection.commit only for mutating operations; selects do not require commit.
  • Avoid long transactions; keep them short to reduce contention.
Warning

Forgetting connection.commit leaves write operations unpersisted. Always commit or use explicit transaction managers when writing data.
