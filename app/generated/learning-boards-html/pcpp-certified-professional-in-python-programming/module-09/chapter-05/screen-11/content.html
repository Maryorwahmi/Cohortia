Module 9 › Chapter 9.5 › Core vs ORM
When Core helps
  • Precise control over generated SQL for complex queries.
  • Smaller runtime abstraction footprint for performance-sensitive code.
  • Easier to audit parameterization and SQL emitted by the library.
When ORM helps
  • Rapid object mapping for domain models and business logic.
  • Automated relationship handling and identity management.
  • Useful when object orientation simplifies application code.
Pro tip

Start with Core to learn patterns and inspect SQL, then layer ORM features where they reduce complexity without hiding important SQL behavior.
