Module 9 › Chapter 9.3 › Update & Delete
Patterns for DML
Construct update and delete expressions, refine with where, execute, and inspect result.rowcount to confirm changes.
Be careful
An update without where updates every row. Always double-check filters in expressions before execution.
Examples from chapter
# UPDATE
update_stmt = update(products_table).where(products_table.c.name == 'Laptop Pro').values(quantity=8)
result = connection.execute(update_stmt)
print(f"Updated {result.rowcount} product(s).")

# DELETE
delete_stmt = delete(products_table).where(products_table.c.name == 'Wireless Mouse')
result = connection.execute(delete_stmt)
print(f"Deleted {result.rowcount} product(s).")
Misconception
Expecting DML to auto-commit when not using a context-managed connection. Commit explicitly or use the with pattern.
