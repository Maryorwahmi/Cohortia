Composing selects
Use select(table) to start, refine with where, and sort with order_by for readable queries that are easy to adapt.
Practical tips
Remember products_table.c.price to reference a column. Use streaming iteration for large datasets to avoid fetching everything into memory.
Concrete example
select_stmt = select(products_table).where(products_table.c.price > 100)
print("--- Products with price > 100 ---")
for row in connection.execute(select_stmt):
    print(f"ID: {row.id}, Name: {row.name}, Price: {row.price}, Qty: {row.quantity}")

# With ordering
select_stmt = select(products_table).where(products_table.c.price > 50).order_by(products_table.c.name)
Misconception
Assuming select immediately runs SQL. It's an expression; only connection.execute(select_stmt) runs the statement.
