Module 9 › Chapter 9.3 › Quick Reminders
Manage connections
Use context managers to commit or roll back and to close connections.
Use migrations
create_all creates new tables only; use migrations to change schemas safely.
Choose Core vs ORM
Decide based on whether you need explicit SQL control or object identity and convenience.
Final takeaway

Mastering Core gives you precise, portable SQL control and forms the solid foundation for using SQLAlchemy’s ORM when you need object mapping.
