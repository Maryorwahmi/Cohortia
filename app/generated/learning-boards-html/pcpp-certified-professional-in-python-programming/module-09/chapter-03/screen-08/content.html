Module 9 › Chapter 9.3 › Insert & Conflict
Insert patterns
Compose an insert expression and execute it. The result exposes rowcount and inserted_primary_key on supported backends.
Example flow
Insert multiple rows, then run a conflict-aware insert to skip duplicates using the index on name.
Concrete code
insert_stmt = insert(products_table).values([
    {'name': 'Laptop Pro', 'description': 'High-performance laptop', 'price': 1500.00, 'quantity': 5},
    {'name': 'Wireless Mouse', 'description': 'Ergonomic wireless mouse', 'price': 35.00, 'quantity': 20}
])
result = connection.execute(insert_stmt)
print(f"Inserted {result.rowcount} products.")

# Conflict handling (PostgreSQL / SQLite)
insert_conflict_stmt = insert(products_table).values(
  name='Laptop Pro', price=1600.00, quantity=10
).on_conflict_do_nothing(index_elements=['name'])
result_conflict = connection.execute(insert_conflict_stmt)
if result_conflict.rowcount == 0:
  print("Skipped inserting 'Laptop Pro' as it already exists.")
Misconception
Don’t assume conflict clauses are identical across databases; choose the clause for your dialect.
