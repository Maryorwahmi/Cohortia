Module 9 › Chapter 9.3 › Define MetaData & Table
Key objects
MetaData holds the collection of Table objects. Each Table defines columns and constraints so schema is explicit and versionable.
Column constraints
Use primary_key, unique, nullable, default, and ForeignKey to enforce integrity at the database level.
Practical note
create_all creates missing tables; it does not modify existing table schemas. For changes, use migrations.
Example: products & orders
from sqlalchemy import MetaData, Table, Column, Integer, String, Float, ForeignKey

metadata = MetaData()

products_table = Table(
  'products', metadata,
  Column('id', Integer, primary_key=True, autoincrement=True),
  Column('name', String(100), nullable=False, unique=True),
  Column('description', String(255)),
  Column('price', Float, nullable=False),
  Column('quantity', Integer, default=0)
)

orders_table = Table(
  'orders', metadata,
  Column('id', Integer, primary_key=True, autoincrement=True),
  Column('product_id', Integer, ForeignKey('products.id')),
  Column('customer_name', String(100), nullable=False),
  Column('order_date', String(50), nullable=False)
)
