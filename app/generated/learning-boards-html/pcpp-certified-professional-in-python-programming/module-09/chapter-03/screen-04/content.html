Module 9 › Chapter 9.3 › Impedance Mismatch
Definition and impact
The impedance mismatch is the conceptual gap between objects and tables. It causes repeated boilerplate SQL and fragile string queries.
Concrete example
Renaming a column when SQL is scattered requires changing many string literals. With schema-as-code, update the Column declaration once.
Common misconception
Thinking ORMs remove the need to understand SQL. Core expects you to reason about SQL but helps you build it safely in Python.
Key Takeaway

Programmatic schema and expressions reduce brittle SQL strings and centralize changes.

Analogy
Think of Core as a typed query builder: it preserves SQL control while giving you Python ergonomics and fewer typos.
Quick contrast
Raw SQL strings: direct, but scattered and error-prone.
SQLAlchemy Core: explicit expressions mapped to backends, safer refactor.
ORM: higher-level object mapping built on Core, with lifecycle management.
