Explain ORM and benefits
Describe how mapping objects to tables reduces raw SQL and centralizes schema changes. This improves maintainability across codebases and teams.

02
Distinguish Core vs ORM
Understand that Core is for expression construction and direct SQL control; ORM maps classes to tables and adds object lifecycle management.
VERIFIED COMPETENCY MILESTONE
03
Define schema with MetaData & Table
Programmatically declare tables and columns so the database structure is part of your codebase, enabling reproducible setups.
VERIFIED COMPETENCY MILESTONE
04
Construct and run expressions
Compose select, insert, update, and delete expressions and execute them with Engine/Connection to perform DML.
