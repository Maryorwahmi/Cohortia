Engine and Connection
Create an Engine with create_engine(database_url). Use engine.connect() as a context manager to run statements and have commits handled automatically.
Best practice
Create one Engine per process and reuse it so connection pooling and dialect behavior are managed centrally.
Transaction safety
Using a Connection as a context manager commits on success and rolls back on exceptions.
Code patterns
from sqlalchemy import create_engine

# SQLite example
engine = create_engine('sqlite:///shop.db')

# PostgreSQL example (format shown in chapter)
# engine = create_engine('postgresql://user:password@host:port/database')

# Materialize tables
# metadata.create_all(engine)
Check this
After calling create_all, inspect the database file or use a client to confirm tables were created. Remember that create_all will not update existing columns.
