Module 9 › Chapter 9.3 › Core vs ORM
SQLAlchemy Core
Programmatic SQL expression language. You control generated SQL and can run the same expression across dialects.
Examples of use
  • Bulk or complex queries where SQL shape matters.
  • Schema defined via MetaData and Table objects.
Misconception check
Core is not low-level SQL strings; it produces expression objects that generate dialect-specific SQL.
SQLAlchemy ORM
Higher-level API mapping classes to tables, offering identity map and unit-of-work for object lifecycle management.
Examples of use
  • When domain code benefits from objects and attribute access.
  • When relationships and lazy loading simplify code.
Practical rule
Mix: use ORM for convenience, and Core when you need explicit SQL or performance tuning.
