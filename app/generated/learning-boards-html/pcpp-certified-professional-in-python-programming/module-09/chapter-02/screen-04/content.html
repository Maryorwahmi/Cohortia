Module 9 › Chapter 9.2 › Embedded vs Server
Comparison
SQLite
  • Embedded file‑based storage, zero configuration.
  • Best for single‑user, portable apps and testing.
  • Limited concurrency and advanced server features.
PostgreSQL / MySQL
  • Client‑server architecture with network connections.
  • Handles many concurrent clients, advanced security, replication.
  • Requires server setup, credentials, and maintenance.
Concrete example
Imagine a notes app: a single user on one device can use SQLite with a local file. Now imagine a team collaboration tool where many users edit notes concurrently. A server RDBMS is required to coordinate concurrent edits and apply ACID guarantees.
Misconception
Server databases are not inherently slower; they manage concurrency and optimize queries for multi‑user loads.
When to switch
Switch when you need multiple clients, stronger security, replication, or advanced SQL features.
Key Takeaway

Pick the storage model that matches your concurrency and operational needs; client‑server RDBMS are for multi‑user, production systems.
