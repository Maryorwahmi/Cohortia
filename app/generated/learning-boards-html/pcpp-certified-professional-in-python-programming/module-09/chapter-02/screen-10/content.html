Module 9 › Chapter 9.2 › User Registration
Schema
CREATE TABLE IF NOT EXISTS users (
  id SERIAL PRIMARY KEY,
  username VARCHAR(50) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL
);
Use a separate db_config.py for DB_CONFIG and avoid hardcoding credentials. Ensure create_users_table commits after executing the DDL.
Function checklist
  • hash_password(password): use a secure hash function (demo uses sha256).
  • register_user: insert with parameterized query, handle UniqueViolation, rollback on error.
  • verify_user: select stored hash and compare; return boolean.
  • list_all_users: select usernames and print them.
