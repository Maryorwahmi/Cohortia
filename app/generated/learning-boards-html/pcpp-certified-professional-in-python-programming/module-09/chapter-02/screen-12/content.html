Module 9 › Chapter 9.2 › Key Concepts
Client‑Server RDBMS
Separate server processes manage shared data, concurrency, and security for multi‑user systems.
Drivers
psycopg2 for PostgreSQL and PyMySQL for MySQL translate Python DB API calls to the server protocol.
Transactions & Safety
Commit to persist or rollback on error; always close resources to avoid leaks.
Summary
Driver + Config + Parameterized SQL + Transactions + Error handling = reliable database applications in Python.
