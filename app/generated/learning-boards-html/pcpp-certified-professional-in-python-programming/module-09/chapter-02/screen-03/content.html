Module 9 › Chapter 9.2 › Learning Objectives
Objective details
  • Parameterized queries: Use %s placeholders and bound parameters to avoid injection.
  • Transaction control: Wrap groups of operations with commit and rollback to preserve integrity.
  • Error handling: Catch adapter errors, rollback on exception, and always close cursors and connections.
  • Troubleshooting: Verify credentials, host/port, and server auth configuration when you see operational errors.
Practice checklist
Install driver and confirm import in a REPL.
Create a DB_CONFIG file and avoid hardcoding in production.
Implement create, insert, select, update, delete with parameterized SQL.
Simulate an error to observe rollback behavior.
