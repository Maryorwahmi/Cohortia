Module 9 › Chapter 9.2 › Parameterized SQL
Example
# psycopg2 parameterized insert
new_user = ('john_doe', 'john.doe@example.com')
cursor.execute(
  "INSERT INTO users (username, email) VALUES (%s, %s) ON CONFLICT (username) DO NOTHING",
  new_user
)
In MySQL you would use AUTO_INCREMENT for the id column and may need different conflict handling logic, such as INSERT IGNORE or INSERT ... ON DUPLICATE KEY UPDATE depending on the desired behavior.
Checklist
  • Never concatenate user input into SQL strings.
  • Pass parameters as a tuple or list to execute.
  • Test dialect‑specific statements when migrating between DBs.
Misconception

The %s placeholder is common but not universal; always verify the adapter's parameter style before migrating code.
