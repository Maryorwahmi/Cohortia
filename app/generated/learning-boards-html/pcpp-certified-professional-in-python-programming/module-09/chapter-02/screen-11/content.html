Module 9 › Chapter 9.2 › Troubleshooting
Common error
FATAL: password authentication failed for user 'app_user' — common causes include wrong username/password or pg_hba.conf not permitting the connection or authentication method.
Troubleshooting checklist:
  1. Verify credentials via psql or mysql client using same host, user, and database.
  2. Check pg_hba.conf entries for allowed hosts and authentication method.
  3. Ensure the DB server is listening on the configured host and port and that firewalls allow access.
  4. Confirm the user has the required privileges on the target database.
Operational tips
  • Do not log passwords in error messages.
  • Use a local client to isolate network vs code issues.
  • After editing pg_hba.conf, reload or restart the PostgreSQL service for changes to take effect.
Key Takeaway

Separate server configuration problems from application logic by validating credentials and network access with standalone client tools first.
