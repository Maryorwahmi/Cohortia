Module 9 › Chapter 9.2 › Connect & Cursor
Code example
import psycopg2

DB_CONFIG = {
  'host': 'localhost',
  'database': 'mydatabase',
  'user': 'myuser',
  'password': 'mypassword',
  'port': '5432'
}

conn = None
cursor = None
try:
  conn = psycopg2.connect(**DB_CONFIG)
  cursor = conn.cursor()
  cursor.execute("SELECT id, username FROM users")
  rows = cursor.fetchall()
  for r in rows:
    print(r)
  conn.commit()
except psycopg2.Error as e:
  if conn:
    conn.rollback()
finally:
  if cursor:
    cursor.close()
  if conn:
    conn.close()
Notes
  • Placeholders: psycopg2 uses %s placeholders for parameters.
  • Transaction boundary: commit and rollback are on the Connection object.
  • Resource safety: always close cursors and connections in finally blocks or use context managers.
Pro tip

Test a simple select after connecting to validate credentials and access before running schema changes.
