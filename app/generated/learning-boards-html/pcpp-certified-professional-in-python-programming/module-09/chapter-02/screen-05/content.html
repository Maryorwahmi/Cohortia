Module 9 › Chapter 9.2 › Install & Configure
Quick commands
# PostgreSQL
pip install psycopg2-binary

# MySQL
pip install PyMySQL
Confirm installation by importing the library in a REPL. If import fails, check Python version and wheel compatibility. For psycopg2, binary wheels simplify installs on systems without a compiler.
Configuration tip
Store connection parameters outside code. Example DB_CONFIG structure helps keep code clear and makes it easy to load settings from environment variables or a secrets manager in production.
DB_CONFIG = {
  'host': 'localhost',
  'database': 'mydatabase',
  'user': 'myuser',
  'password': 'mypassword',
  'port': '5432'
}
Common mistake
Assuming pip install is enough. You still need a running database server and valid credentials. Also avoid hardcoding credentials in source files.
