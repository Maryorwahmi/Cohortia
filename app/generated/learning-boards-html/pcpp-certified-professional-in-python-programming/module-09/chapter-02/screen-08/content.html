Transaction example
try:
  conn = psycopg2.connect(**DB_CONFIG)
  cursor = conn.cursor()
  # multiple related operations
  cursor.execute("UPDATE accounts SET balance = balance - %s WHERE id = %s", (100, 1))
  cursor.execute("UPDATE accounts SET balance = balance + %s WHERE id = %s", (100, 2))
  conn.commit()
except psycopg2.Error:
  if conn:
    conn.rollback()
finally:
  # close resources
  pass
Why it matters
Prevents partial updates and maintains data integrity across multiple statements.
Common mistake
Relying on implicit commits or on closing the connection to commit changes.
Test approach
Force an exception between related operations to verify rollback behavior.
