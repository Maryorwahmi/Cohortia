Error handling pattern
try:
  conn = psycopg2.connect(**DB_CONFIG)
  cursor = conn.cursor()
  cursor.execute("...", params)
  conn.commit()
except psycopg2.Error as e:
  print("Database error:", e)
  if conn:
    conn.rollback()
finally:
  if cursor:
    cursor.close()
  if conn:
    conn.close()
Troubleshooting tips
  • Verify credentials with a client tool like psql to isolate code vs server issues.
  • Check server auth configuration (pg_hba.conf) for PostgreSQL when authentication fails.
  • Confirm the database service is listening on the expected host and port.
Common operational error

Incorrect host/port or wrong credentials typically raise OperationalError; verify server configuration and user privileges.
