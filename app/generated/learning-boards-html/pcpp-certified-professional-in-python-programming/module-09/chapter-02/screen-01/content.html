Orientation

This chapter assumes you have used SQLite. Now you will learn how client‑server databases differ and how to use Python adapters to interact with a running database server. Practical examples use psycopg2 for PostgreSQL and a comparable PyMySQL pattern for MySQL.

Client‑Server Model
Server process accepts network connections. Clients authenticate and run queries.
Connection example
DB_CONFIG = {
  'host': 'localhost',
  'database': 'mydatabase',
  'user': 'myuser',
  'password': 'mypassword',
  'port': '5432'
}
This structure maps to the keyword arguments passed to psycopg2.connect or pymysql.connect.
Key takeaway
Choosing a server RDBMS enables concurrency and advanced features, but requires explicit connection and transaction handling from your Python code.
