Module 11›Chapter 11.1›`setup.py` Anatomy
from setuptools import setup, find_packages

# Read the long description from README.md
with open("README.md", "r", encoding="utf-8") as fh:
    long_description = fh.read()

setup(
    name="my-math-utils-cohortia", # Unique package name
    version="0.1.0", # Semantic versioning recommended
    author="Your Name",
    author_email="your.email@example.com",
    description="A simple utility package for basic mathematical operations.",
    long_description=long_description,
    long_description_content_type="text/markdown",
    url="https://github.com/yourusername/my-math-utils",
    packages=find_packages(), # Automatically find packages
    classifiers=[
        "Programming Language :: Python :: 3",
        "License :: OSI Approved :: MIT License",
        "Operating System :: OS Independent",
    ],
    python_requires='>=3.7',
)

Key `setup()` Arguments

  • `name`: Unique package identifier on PyPI.
  • `version`: Current version of the package (e.g., `1.0.0`).
  • `author`, `author_email`: Contact information.
  • `description`: Short summary of the package.
  • `long_description`: Detailed project description, often from `README.md`.
  • `url`: Project homepage or repository link.
Key Takeaway

The `setup.py` script, calling `setuptools.setup()`, is crucial for defining your package's metadata and configuration, acting as its central blueprint.
