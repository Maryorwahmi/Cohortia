What is an `sdist`?

  • A compressed archive (`.tar.gz` or `.zip`).
  • Contains your package's raw source code.
  • Includes the `setup.py` script and metadata.
  • Requires local building during installation.

Use Cases for `sdist`

  • For developers who want to inspect the source.
  • For specific build environments requiring source compilation.
  • Less preferred for general end-user installation.

Building an `sdist`

Navigate to Project Root

`cd my_package_root` (where `setup.py` is located)

Run Build Command

`python setup.py sdist`

Output

Creates a `.tar.gz` or `.zip` file in the `dist/` directory.

Key Takeaway

Source distributions (`sdist`) bundle your raw code and `setup.py`, requiring local building, making them suitable for inspection but less ideal for quick end-user installation.
