Example Project Layout

my_package/
├── my_package/
│   ├── __init__.py
│   ├── module_a.py
│   └── subpackage/
│       └── __init__.py
│       └── module_b.py
├── tests/
│   └── test_module_a.py
├── setup.py
├── README.md
└── LICENSE

Key Components Explained

  • `my_package/`: The main Python package, containing your modules.
  • `__init__.py`: Essential for Python to recognize directories as packages.
  • `setup.py`: The configuration script for `setuptools`.
  • `README.md`, `LICENSE`: Project documentation and legal information.
  • `tests/`: Separate directory for unit tests, not part of the distribution.
Key Takeaway

A clear and consistent project structure, with `__init__.py` files marking packages, is vital for `setuptools` to correctly identify and bundle your code.
