Distribution and Dependencies

Key Elements of Package Management

Source Distribution (sdist)

A `.tar.gz` or `.zip` file with source code and `setup.py`, requiring local building.

Wheel (`.whl` file)

A pre-built binary distribution for faster, more reliable installation.

`install_requires`

An argument in `setup()` used to specify external package dependencies.

`entry_points`

An argument in `setup()` used to define console scripts or other plugin entry points.

Summary Takeaway

Understanding source vs. wheel distributions and effectively managing dependencies via `install_requires` and `entry_points` are crucial for modern Python packaging.
