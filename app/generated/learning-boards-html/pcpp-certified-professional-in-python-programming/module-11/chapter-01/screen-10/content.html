Module 11›Chapter 11.1›`install_requires`
from setuptools import setup, find_packages

setup(
    name="my_awesome_app",
    version="1.0.0",
    # ... other metadata ...
    packages=find_packages(),
    install_requires=[
        "requests>=2.25.1", # requests version 2.25.1 or newer
        "numpy", # any version of numpy
        "pandas==1.3.0" # exactly pandas version 1.3.0
    ],
    python_requires='>=3.8',
)

Purpose of `install_requires`

  • Declares external package dependencies.
  • Ensures `pip` automatically installs them.
  • Prevents 'missing dependency' errors for users.

Version Specifiers

  • `requests`: Any version.
  • `requests>=2.25.1`: Version 2.25.1 or newer.
  • `pandas==1.3.0`: Exactly version 1.3.0.
Key Takeaway

`install_requires` is vital for specifying external dependencies and their versions, ensuring a smooth and complete installation of your package.
