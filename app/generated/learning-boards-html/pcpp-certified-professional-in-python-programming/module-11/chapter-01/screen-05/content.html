What is `distutils`?

  • Part of Python's standard library since v1.6.
  • Provides basic infrastructure for package building.
  • Introduced the `setup.py` script and `setup()` function.

Key Limitations

  • No automatic dependency management.
  • No support for command-line entry points.
  • No support for pre-built binary distributions (wheels).
  • Required manual compilation for users.

`distutils` Workflow

Source Code + `setup.py`
Source Distribution (sdist)`.tar.gz` or `.zip`

Users would then run `python setup.py install` to build and install locally.

Key Takeaway

`distutils` provided the initial framework for Python packaging, enabling basic source distributions but lacking modern features like dependency management.
