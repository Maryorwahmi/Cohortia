from setuptools import setup, find_packages

setup(
    name="my-math-utils-cohortia",
    version="0.1.0",
    # ... other metadata ...
    packages=find_packages(),
    entry_points={
        'console_scripts': [
            'math-add=my_math_utils.operations:add_cli', # Maps 'math-add' command to a function
            'my-tool=my_package.cli:main_function'
        ],
        'gui_scripts': [
            'my-gui=my_package.gui:start_app'
        ]
    },
    python_requires='>=3.7',
)

Purpose of `entry_points`

  • Defines how your package can be invoked.
  • `console_scripts`: For command-line executables.
  • `gui_scripts`: For graphical user interface applications.
  • Maps a script name to a Python function within your package.

How it Works

  • `setuptools` creates wrapper scripts during installation.
  • These wrappers are placed in the user's PATH.
  • Executing the script name calls the mapped Python function.
Key Takeaway

`entry_points` allows you to define command-line or GUI scripts that directly execute functions from your package, enhancing user accessibility.
