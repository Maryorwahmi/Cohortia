Job Configuration and Python Setup

Defining the execution environment and Python versions

Runner Environment

runs-on: ubuntu-latest specifies the operating system for the job's virtual machine, ensuring a consistent execution environment.

Strategy Matrix

The strategy.matrix allows running the same job across multiple configurations, such as different Python versions (e.g., 3.9, 3.10).

Python Setup Action

actions/setup-python@v4 is a pre-built action used to install and configure the specified Python version for the job.

Key Takeaway

GitHub Actions uses runs-on for the OS and a strategy.matrix to test Python projects across multiple versions, enhancing compatibility.

.github/workflows/python-ci.yml (Excerpt)

jobs:
  build:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ["3.9", "3.10"] # Test against multiple Python versions

    steps:
    - uses: actions/checkout@v3 # Checkout the repository code
    - name: Set up Python ${{ matrix.python-version }}
      uses: actions/setup-python@v4
      with:
        python-version: ${{ matrix.python-version }}
    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r requirements.txt
    - name: Lint with flake8
      run: |
        flake8 . --count --select=E9,F63,F7,F82 --show-source --statistics
        flake8 . --count --exit-zero --max-complexity=10 --max-line-length=120 --statistics
    - name: Test with pytest
      run: |
        pytest
