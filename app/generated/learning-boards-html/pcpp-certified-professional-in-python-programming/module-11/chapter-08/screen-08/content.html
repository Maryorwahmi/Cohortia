GitHub Actions Workflow

YAML Structure and Triggers

Defining when and how your CI pipeline runs

Workflow Name

The name field provides a human-readable identifier for your workflow, visible in the GitHub Actions UI.

Trigger Events (`on`)

The on section specifies which GitHub events (e.g., push, pull_request) will initiate the workflow, often scoped to specific branches.

Jobs Definition

The jobs section contains one or more independent jobs, each with its own configuration and steps.

Key Takeaway

GitHub Actions workflows are YAML files defining a name, event triggers, and a collection of jobs for automation.

.github/workflows/python-ci.yml

name: Python CI

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: [
