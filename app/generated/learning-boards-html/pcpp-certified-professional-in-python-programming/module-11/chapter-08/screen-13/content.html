Key Concepts: Fundamentals

Essential terms for Continuous Integration and Deployment

Continuous Integration (CI)

Developers frequently merge code changes into a central repository, followed by automated builds and tests to detect issues early.

Continuous Deployment (CD)

An extension of CI that automatically deploys all code changes passing automated tests to a production or staging environment.

CI/CD Pipeline

An automated workflow that takes code from version control through building, testing, packaging, and deploying to target environments.

Summary Takeaway

CI/CD streamlines software delivery by automating integration, testing, and deployment, leading to faster, more reliable releases.
