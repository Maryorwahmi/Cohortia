Dependency Installation, Linting, and Testing

Automating code quality and correctness checks

Install Dependencies

The pip install -r requirements.txt command installs all necessary Python packages, including linters and testing frameworks.

Linting with Flake8

flake8 checks for code style violations and potential errors, ensuring consistency and maintainability across the codebase.

Testing with Pytest

pytest executes unit and integration tests, verifying the functionality of the application and catching regressions.

Key Takeaway

Automated dependency installation, linting, and testing are crucial CI steps to ensure Python code quality and functional correctness.

.github/workflows/python-ci.yml (Full)

name: Python CI

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ["3.9", "3.10"]

    steps:
    - uses: actions/checkout@v3
    - name: Set up Python ${{ matrix.python-version }}
      uses: actions/setup-python@v4
      with:
        python-version: ${{ matrix.python-version }}
    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r requirements.txt
    - name: Lint with flake8
      run: |
        flake8 . --count --select=E9,F63,F7,F82 --show-source --statistics
        flake8 . --count --exit-zero --max-complexity=10 --max-line-length=120 --statistics
    - name: Test with pytest
      run: |
        pytest
