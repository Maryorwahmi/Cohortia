Practical Application

Basic CI with GitHub Actions

Setting up your Python project for automated checks

Workflow Definition

GitHub Actions workflows are defined in YAML files located in the .github/workflows/ directory of your repository.

Example Project Structure

A typical Python project includes main.py (application logic), requirements.txt (dependencies), and test_main.py (unit tests).

Key Takeaway

GitHub Actions uses YAML files in a dedicated directory to define automated CI workflows for Python projects, ensuring code quality.

Example Python Files

# main.py

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

# requirements.txt

flake8==4.0.1
pytest==7.0.1

# test_main.py

from main import add, subtract

def test_add():
    assert add(1, 2) == 3
    assert add(-1, 1) == 0
    assert add(0, 0) == 0

def test_subtract():
    assert subtract(5, 2) == 3
    assert subtract(2, 5) == -3
    assert subtract(0, 0) == 0
