Workflow Configuration

GitHub Actions YAML: Steps

Each job consists of a sequence of steps, which can be shell commands or reusable actions.

steps: Task Sequence

A list of tasks to be executed in order within a job. Each step can have a name and use a predefined action or run a shell command.

actions/checkout@v3: Get Code

This action checks out your repository's code onto the runner, making it available for subsequent steps.

actions/setup-python@v4: Python Environment

Sets up the specified Python version. Crucially, always define python-version for consistency across environments.

Key Takeaway

Explicitly defining Python versions and checking out code are foundational for reproducible CI builds.
