.github/workflows/main.yml (final steps)
jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v3

    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.9'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r requirements.txt

    - name: Run tests with pytest
      run: |
        pip install pytest
        pytest
Workflow Configuration

GitHub Actions YAML: Dependencies & Tests

These steps ensure all project dependencies are installed and automated tests are executed to validate code changes.

Install Dependencies

Uses pip to install packages from requirements.txt. Always keep this file updated to avoid build failures.

Run Tests with Pytest

Installs pytest and executes your project's test suite. Immediate feedback on test failures is a core CI benefit.

Common Mistake

Forgetting to include all necessary packages in requirements.txt can lead to 'Module Not Found' errors during CI builds.

Key Takeaway

Automated dependency installation and test execution are critical for ensuring a consistent and validated codebase.
