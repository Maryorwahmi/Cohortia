Chapter Summary

Key Concepts

Tools and strategies for automated pipelines

GitHub Actions & Workflow

A CI/CD service integrated into GitHub, where a workflow defines automated processes via YAML files.

requirements.txt & Pytest

requirements.txt lists Python dependencies, while Pytest is a framework for writing and running unit tests.

Blue/Green & Canary Deployment

Strategies to minimize downtime and risk during deployments, either by switching environments or gradual rollouts.

Summary Takeaway

Effective CI/CD relies on understanding workflow components, testing tools, and strategic deployment methods.
