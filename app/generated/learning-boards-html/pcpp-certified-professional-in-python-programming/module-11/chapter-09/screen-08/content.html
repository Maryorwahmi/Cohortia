Workflow Configuration

GitHub Actions YAML: Structure

The core of a GitHub Actions workflow is a YAML file defining its name, triggers, jobs, and execution environment.

name: Workflow Title

A descriptive name for your workflow, visible in the GitHub Actions tab.

on: Trigger Events

Specifies when the workflow should run (e.g., on push, pull request to specific branches).

jobs: Defined Tasks

A collection of jobs that execute in parallel or sequentially. Each job runs on a fresh virtual environment.

runs-on: Runner Environment

Indicates the operating system and environment where the job will be executed (e.g., ubuntu-latest).

Key Takeaway

The YAML structure clearly defines when and where your automated CI/CD tasks will run.
