def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def test_add():
    assert add(1, 2) == 3
    assert add(-1, 1) == 0
    assert add(0, 0) == 0

def test_subtract():
    assert subtract(5, 3) == 2
    assert subtract(10, 10) == 0
    assert subtract(0, 5) == -5
Testing in Action

Example Pytest Unit Tests

pytest is a popular Python testing framework that makes writing and running tests straightforward and effective.

Test Functions

Functions starting with test_ are automatically discovered and executed by pytest.

Assertions

assert statements are used to check if a condition is true. If an assertion fails, the test fails.

Test Coverage

Good tests cover various scenarios, including positive cases, negative cases, and edge cases, to ensure robustness.

Key Takeaway

Comprehensive unit tests are the backbone of a reliable CI pipeline, providing confidence in every code change.
