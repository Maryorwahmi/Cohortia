Refactoring to `pyproject.toml`: Preparation

Setting up our project for modern packaging

Project Structure Overview

Our starting point for the my_math_utils package:

my_math_utils/
├── my_math_utils/
│   ├── __init__.py
│   └── operations.py
├── README.md
├── LICENSE
└── setup.py  # This will be removed!

This structure is typical for a simple Python package using traditional `setuptools`.

Key Takeaway

The first step in modernizing packaging is to remove the legacy `setup.py` script, clearing the way for `pyproject.toml`.

Step 1: Remove `setup.py`

Navigate to your project's root directory and execute:

cd my_math_utils/
rm setup.py

After removal, your directory should look like this:

my_math_utils/
├── my_math_utils/
│   ├── __init__.py
│   └── operations.py
├── README.md
└── LICENSE
Common Mistake

Forgetting to remove `setup.py` can lead to conflicting configurations and unexpected build behavior. Ensure it's gone!
