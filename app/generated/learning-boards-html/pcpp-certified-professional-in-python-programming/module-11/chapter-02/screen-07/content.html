Build Workflow

The Isolated Build Process

Ensuring consistent and reproducible package creation

Steps in the Modern Build Flow

  • 1. Read `pyproject.toml`: Build tool parses the file for configuration.
  • 2. Identify `requires`: Extracts build dependencies from `[build-system]`.
  • 3. Create Isolated Environment: Sets up a temporary, clean virtual environment.
  • 4. Install Build Dependencies: Installs packages from `requires` into the isolated env.
  • 5. Invoke `build-backend`: Calls the specified backend to perform the actual build.
  • 6. Generate Distributions: Creates sdist and wheel files in `dist/`.
Key Takeaway

The isolated build process, driven by `pyproject.toml`, guarantees consistent and reproducible package creation by managing dependencies in a clean environment.
