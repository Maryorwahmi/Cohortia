Configuration Core

`pyproject.toml` and the `[build-system]` Table

Defining your project's build requirements

What is `pyproject.toml`?

  • Universal configuration file for Python projects.
  • Uses TOML (Tom's Obvious, Minimal Language) format.
  • Configures packaging, linters, formatters, test runners, etc.
  • Declarative: defines *what* rather than *how*.

The `[build-system]` Table

This section is crucial for packaging, specifying how your project should be built.

  • `requires`: List of packages needed in the build environment.
  • `build-backend`: Python module implementing the PEP 517 API.
# pyproject.toml

[build-system]
requires = [
  "setuptools>=61.0.0", # Build tool
  "wheel" # For building .whl files
]
build-backend = "setuptools.build_meta" # The actual builder
Key Takeaway

`pyproject.toml`'s `[build-system]` table is the declarative contract for build tools, specifying necessary dependencies and the build backend.
