The Build Orchestrator

Using the `build` Tool for Distribution

Generating standard sdist and wheel archives

Why Use `build`?

  • Simplicity: Single command to build distributions.
  • Standardization: Adheres to PEP 517/518.
  • Isolation: Automatically creates and uses isolated build environments.
  • Reliability: Ensures consistent sdist and wheel generation.
  • Backend Agnostic: Works with any PEP 517-compliant build backend.
Key Takeaway

The `build` tool is the recommended, straightforward way to generate standard Python distribution archives from `pyproject.toml` projects.

Terminal Commands

1. Install the `build` tool:

pip install build

2. Navigate to your project root and build:

cd my_math_utils/
python -m build

Expected output in `dist/`:

dist/
├── my-math-utils-cohortia-v2-0.2.0.tar.gz
└── my_math_utils_cohortia_v2-0.2.0-py3-none-any.whl
