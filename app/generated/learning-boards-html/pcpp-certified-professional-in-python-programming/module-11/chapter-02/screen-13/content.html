Hands-on Activity

Building `my_math_utils` with `pyproject.toml` and `build`

Generating distribution archives from our new configuration

The Build Process in Action

  • The `build` tool reads `pyproject.toml`.
  • An isolated virtual environment is created.
  • Build dependencies (`setuptools`, `wheel`) are installed.
  • The specified `build-backend` (`setuptools.build_meta`) is invoked.
  • Source distribution (`.tar.gz`) and wheel (`.whl`) files are generated.
  • All distributions are placed in the `dist/` directory.
Key Takeaway

Successfully building with `python -m build` confirms your project is configured correctly with `pyproject.toml` for modern Python packaging.

Step 3: Install `build` and Build

First, ensure `build` is installed:

pip install build

Then, from your project root (`my_math_utils/`), run:

python -m build
