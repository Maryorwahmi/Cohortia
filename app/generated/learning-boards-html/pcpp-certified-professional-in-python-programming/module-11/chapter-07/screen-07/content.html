Module 11›Chapter 11.7›COPY and RUN

Dockerfile Instructions

# Copy the requirements file into the container at /app
COPY requirements.txt .

# Install any needed packages specified in requirements.txt
RUN pip install --no-cache-dir -r requirements.txt

# Copy the rest of the application code into the container at /app
COPY . .
`COPY` Instruction

Transfers files/directories from the host to the container. Copy `requirements.txt` first to leverage build cache.

`RUN` Instruction

Executes commands during the image build. Used for installing dependencies. `--no-cache-dir` reduces image size.

Why Order Matters: Build Cache

Placing `COPY requirements.txt` and `RUN pip install` early means these layers are cached. If only your application code changes, Docker rebuilds fewer layers, speeding up subsequent builds.

Common Mistake: Bloated Images

Forgetting `--no-cache-dir` with `pip install` can leave unnecessary cached packages in your image, increasing its size. Always use it for production images.

Key Takeaway

Strategically use `COPY` to add dependencies early for caching benefits, and `RUN` with `--no-cache-dir` to install them efficiently, minimizing image size.
