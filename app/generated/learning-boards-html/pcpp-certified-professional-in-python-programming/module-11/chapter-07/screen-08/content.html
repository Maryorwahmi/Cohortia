Module 11›Chapter 11.7›EXPOSE, CMD, ENTRYPOINT

Dockerfile Instructions

# Make port 5000 available to the world outside this container
EXPOSE 5000

# Run the application
CMD ["python", "app.py"]

# Example with ENTRYPOINT (CMD becomes arguments)
ENTRYPOINT ["gunicorn"]
CMD ["app:app", "-b", "0.0.0.0:8000"]
`EXPOSE` Instruction

Informs Docker about ports the container listens on. Purely informational; doesn't publish ports.

`CMD` Instruction

Provides default command for an executing container. Can be overridden. Only the last `CMD` is used.

`ENTRYPOINT` vs. `CMD`

`ENTRYPOINT` defines the main executable, making the container run like a command. `CMD` provides default arguments to `ENTRYPOINT` or the default command if no `ENTRYPOINT` is set.

Misconception: `EXPOSE` Publishes Ports

`EXPOSE` only documents the port. To actually make the port accessible from the host, you must use the `-p` flag with `docker run`.

Key Takeaway

Use `EXPOSE` for documentation, `CMD` for default execution commands, and `ENTRYPOINT` to define the container's primary executable behavior.
