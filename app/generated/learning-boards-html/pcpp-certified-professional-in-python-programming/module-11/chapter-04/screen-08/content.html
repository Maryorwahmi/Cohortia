Installing and Managing Packages

Using pip within your active virtual environment

Isolated Installations

When a virtual environment is active, pip installs packages into its dedicated site-packages directory.

  • 1

    Use pip install package-name to add libraries.

  • 2

    Specify versions with package-name==X.Y.Z for precise control.

  • 3

    Use pip freeze to list all installed packages and their versions.

Key Takeaway

Always use pip within an activated virtual environment to ensure project-specific package management.

Terminal: Install & Verify(myenv) pip install requests==2.28.1
# Activate your virtual environment first (e.g., .venv)
$ source .venv/bin/activate

# Install a specific version of the requests library
(.venv) $ pip install requests==2.28.1
Collecting requests==2.28.1
  Downloading requests-2.28.1-py3-none-any.whl (62 kB)
... (other dependencies) ...
Successfully installed certifi-2023.11.17 charset-normalizer-3.3.2 idna-3.6 requests-2.28.1 urllib3-2.1.0

# Verify installed packages
(.venv) $ pip freeze
certifi==2023.11.17
charset-normalizer==3.3.2
idna==3.6
requests==2.28.1
