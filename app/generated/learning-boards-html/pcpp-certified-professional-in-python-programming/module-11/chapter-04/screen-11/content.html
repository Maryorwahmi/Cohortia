Essential Best Practices: requirements.txt

Documenting and recreating project dependencies

The Dependency Blueprint

requirements.txt lists all installed packages and their exact versions, ensuring reproducible environments.

  • 1

    After installing packages, run pip freeze > requirements.txt.

  • 2

    Commit this file to version control (e.g., Git).

  • 3

    Others can recreate the environment with pip install -r requirements.txt.

Key Takeaway

Always generate and commit requirements.txt to ensure consistent project setups.

Terminal: Generate `requirements.txt`(myenv) pip freeze > requirements.txt
# Activate your virtual environment
$ source .venv/bin/activate

# Install some packages
(.venv) $ pip install Flask==2.3.3 requests==2.28.1
... (installation output) ...

# Generate requirements.txt
(.venv) $ pip freeze > requirements.txt

# View the contents of requirements.txt
(.venv) $ cat requirements.txt
blinker==1.6.3
certifi==2023.11.17
...
Flask==2.3.3
requests==2.28.1
...
