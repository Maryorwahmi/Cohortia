Key Concepts

Essential terms to remember

Virtual Environment

An isolated Python environment allowing projects to have their own dependencies without conflicts.

Dependency Hell

A situation where different projects require conflicting versions of the same library, leading to breakage.

venv

The built-in Python 3 module for creating and managing virtual environments.

virtualenv

A third-party tool providing similar functionality to venv, with broader compatibility and more features.

Activate

The process of modifying the shell's PATH to use the Python interpreter and pip from the virtual environment.

Deactivate

The process of exiting a virtual environment and restoring the shell's PATH to the global environment.

Summary Takeaway

Mastering these terms is fundamental for building stable, reproducible, and collaborative Python projects.
