Key Concepts

Essential terms to remember

pip freeze

A pip command used to list all installed packages and their versions in the current environment.

requirements.txt

A file listing a project's dependencies, used to recreate the exact environment.

site-packages

The directory within a Python installation (or virtual environment) where third-party packages are installed.

Summary Takeaway

These tools and files are indispensable for documenting, sharing, and maintaining consistent Python project environments.
