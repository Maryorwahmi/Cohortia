Essential Best Practices: Version Control (.gitignore)

Keeping virtual environments out of your Git repository

Why Ignore?

Virtual environment directories contain system-specific files that should not be committed to version control.

  • 1

    Prevents bloated repositories with unnecessary files.

  • 2

    Avoids platform-specific issues for collaborators (e.g., Windows vs. Linux paths).

  • 3

    Ensures a clean, portable, and reproducible project setup.

Key Takeaway

Always add your virtual environment directory (e.g., .venv/) to your project's .gitignore file.

Terminal: Configure `.gitignore`echo ".venv/" >> .gitignore
# Create or open your .gitignore file
$ nano .gitignore

# Add the virtual environment directory name
# .gitignore content:
# --------------------
.venv/
env/
__pycache__/
*.pyc
# --------------------

# Save and exit (Ctrl+X, Y, Enter for nano)

# Verify Git ignores the directory
$ git status
On branch main
Untracked files:
  (use "git add <file>..." to include in what will be committed)
        .gitignore
        requirements.txt
# Notice .venv/ is not listed!
