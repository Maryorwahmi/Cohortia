Activating Your venv

Switching to the isolated project environment

Why Activate?

Activation ensures your shell uses the Python interpreter and pip from your virtual environment, not the global ones.

  • 1

    The shell's PATH variable is temporarily modified.

  • 2

    Your prompt usually changes to indicate the active environment (e.g., (myenv)).

  • 3

    All subsequent python and pip commands target this isolated environment.

Key Takeaway

Always activate your virtual environment before installing packages or running project code.

Terminal: Activate `venv`source .venv/bin/activate
# Assuming your venv is named '.venv'

# On Linux/macOS (Bash/Zsh)
$ source .venv/bin/activate
(.venv) $ _

# On Windows (Command Prompt)
C:\my_project> .venv\Scripts\activate.bat
(.venv) C:\my_project> _

# On Windows (PowerShell)
PS C:\my_project> .venv\Scripts\Activate.ps1
(.venv) PS C:\my_project> _
