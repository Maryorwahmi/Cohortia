Creating a venv Environment

Using Python's built-in module for isolation

The venv Module

venv is Python's standard library module for creating lightweight virtual environments, available since Python 3.3.

  • 1

    Navigate to your project's root directory in the terminal.

  • 2

    Execute the venv creation command.

  • 3

    A new directory (e.g., .venv) is created, containing the isolated Python environment.

Key Takeaway

venv is the preferred, built-in method for setting up isolated Python environments for your projects.

Terminal: Create `venv`python -m venv myenv
# Navigate to your project directory
$ mkdir my_project
$ cd my_project

# Create the virtual environment named 'myenv'
$ python -m venv myenv

# You can also use a common convention like '.venv'
$ python -m venv .venv

# Verify the directory structure (output may vary)
$ ls -F .venv/
bin/  include/  lib/  pyvenv.cfg
