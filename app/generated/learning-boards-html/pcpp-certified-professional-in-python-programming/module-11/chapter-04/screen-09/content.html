Deactivating and Cleaning Up venv

Exiting the isolated environment and removing it

Exiting the Environment

The deactivate command restores your shell's PATH to its global state, exiting the virtual environment.

  • 1

    Type deactivate to return to your global Python environment.

  • 2

    Your shell prompt will revert to its normal appearance.

  • 3

    To remove a virtual environment, simply delete its directory.

Key Takeaway

Deactivation is temporary; deleting the directory is permanent removal of the virtual environment.

Terminal: Deactivate & Remove(myenv) deactivate
# Assuming you are in an activated virtual environment
(.venv) $ deactivate
$ _

# Verify Python version (should be global now)
$ which python
/usr/bin/python  # Example global path

# Remove the virtual environment directory
$ rm -rf .venv

# On Windows Command Prompt:
C:\my_project> rmdir /s /q .venv

# Verify removal
$ ls -F
requirements.txt  my_script.py  # .venv directory is gone
