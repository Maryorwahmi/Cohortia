Essential Metadata for Public Distribution

Ensuring discoverability and usability with README, LICENSE, and classifiers.

README.md

A comprehensive Markdown file explaining what your package does, how to install and use it, and providing examples. This is prominently displayed on your package's PyPI page.

LICENSE File

A clear license file (e.g., MIT, Apache 2.0) specifying how others can use, modify, and distribute your code. Without it, your code is proprietary by default.

Classifiers

Short strings that categorize your project (e.g., "Programming Language :: Python :: 3", "License :: OSI Approved :: MIT License"). These help users find your package on PyPI based on specific criteria.

long_description_content_type

Specifies the format of your long_description (usually from README.md). For Markdown, set this to "text/markdown" in pyproject.toml to ensure correct rendering on PyPI.

Key Takeaway

Thorough metadata is your package's public face and legal foundation; invest time in it for successful distribution.
