Streamlining Credentials with ~/.pypirc

Storing PyPI and TestPyPI credentials securely for twine.

What is ~/.pypirc?

This optional configuration file, located in your home directory, stores credentials for PyPI and TestPyPI. twine can read this file to authenticate uploads automatically, avoiding manual input of API tokens.

  • Enhances convenience for frequent uploads.
  • Keeps API tokens out of command history.
  • Requires proper file permissions for security.
# ~/.pypirc
[pypi]    # Configuration for main PyPI
    username = __token__
    password = pypi-your-api-token-here

[testpypi] # Configuration for TestPyPI
    repository = https://test.pypi.org/legacy/
    username = __token__
    password = pypi-your-testpypi-api-token-here
Security Note

Ensure your ~/.pypirc file has restricted permissions (e.g., chmod 600 ~/.pypirc) to protect your API tokens.

Key Takeaway

~/.pypirc provides a secure and convenient way to store PyPI credentials, automating authentication for twine uploads.
