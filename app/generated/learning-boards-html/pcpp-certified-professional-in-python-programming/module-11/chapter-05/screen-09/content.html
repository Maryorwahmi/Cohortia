Process › Pitfalls & Best Practices

Common pitfalls

  • Forgetting to activate before pip install installs packages globally.
  • Creating an environment inside another environment causes nested PATH confusion.
  • Committing the environment directory to Git rather than using requirements.txt.

Practical habits

  • Add .venv/ to .gitignore and commit requirements.txt instead.
  • Run which python to confirm the active interpreter during setup.
  • Create environments at project root and re-activate each new terminal session.
Key Takeaway

Simple, repeatable habits prevent most virtual environment issues: activate, verify, export, and ignore the env directory in source control.
