Key Concepts › What to Remember — Part 1
Virtual Environment
An isolated Python environment that keeps project dependencies separate from the system and other projects.
venv
The built-in module for creating lightweight virtual environments on Python 3.3+ installations.
Activation
Temporarily modifies your shell so python and pip point into the environment; check the prompt for confirmation.
Summary takeaway

Habit: always create an env per project, activate before installing, export requirements, and ignore the env directory in source control.
