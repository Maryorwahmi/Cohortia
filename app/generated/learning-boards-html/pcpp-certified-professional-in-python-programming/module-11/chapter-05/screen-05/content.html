Process Flow › Create a venv

Create: exact steps

Use the Python module to create a local environment folder inside the project. Choose a name like .venv to keep it out of sight in many file explorers.
# create and inspect
mkdir my_python_project
cd my_python_project
python3 -m venv .venv
# the .venv folder now contains bin/ or Scripts/, lib/, and pyvenv.cfg
Tip: Use .venv so tools and editors can auto-detect and avoid committing it to git.

Directory outcome

bin/ or Scripts/ — environment executables including python and pip
lib/pythonX.Y/site-packages — where installed packages are placed
pyvenv.cfg — configuration file stating the base interpreter
Misconception

Creating the venv does not install project packages automatically; you must activate it and run pip install or pip install -r requirements.txt.
