Comparison › venv vs virtualenv

venv (built-in)

Included with Python 3.3+. Lightweight and recommended for new projects using modern Python. No extra install step is required.
Create: python3 -m venv .venv
Activation: source .venv/bin/activate or Windows variants

virtualenv (third-party)

Install with pip install virtualenv and create with virtualenv my_project_env. Useful for older Python versions or when you must select a specific interpreter binary explicitly.
Install: pip install virtualenv
Create: virtualenv my_project_env
When to prefer virtualenv

Prefer virtualenv when working with legacy interpreters or when you need advanced environment creation options. Otherwise use venv for simplicity and built-in support.
