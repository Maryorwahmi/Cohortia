Process › Deployment with venv

Server steps

# on the server
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
This workflow guarantees the server uses the same library versions as development, reducing runtime errors due to mismatched dependencies.

Practical checks

After installation run python -c "import requests; print(requests.__version__)" or pip list to confirm versions. Ensure your requirements.txt was generated with pip freeze to capture exact versions.
Key Takeaway

Deploy into a clean venv and install from requirements.txt to mirror development precisely and avoid "works on my machine" issues.
