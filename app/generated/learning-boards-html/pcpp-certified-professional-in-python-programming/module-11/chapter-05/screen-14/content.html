Key Concepts › What to Remember — Part 2
.gitignore
Add .venv/ or your env folder to .gitignore and commit requirements.txt instead of the environment directory.
virtualenv for legacy
Use virtualenv when you must support legacy Python or specify a non-default interpreter explicitly.
Reproduce on servers
Create a venv on the server and run pip install -r requirements.txt to mirror development exactly.
Final takeaway

Make environment creation, activation, and requirements export a routine part of every project to ensure consistent, conflict-free development and deployment.
