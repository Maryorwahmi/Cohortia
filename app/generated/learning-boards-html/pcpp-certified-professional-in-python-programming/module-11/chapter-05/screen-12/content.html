Hands-on › Terminal demo

Commands to run

# create and activate
mkdir my_python_project
cd my_python_project
python3 -m venv .venv
source .venv/bin/activate

# install and verify
pip install requests
pip list

# export and cleanup
pip freeze > requirements.txt
deactivate

# verify global packages
pip list
Expected result: requests appears in pip list while the venv is active, and disappears from the global list after deactivate. requirements.txt records installed versions for deployment.

Check your understanding

Question: You run pip install but don't see the package in pip list after activating. What likely happened? Answer: You installed into the wrong shell; you must confirm activation, or you used a different pip than the venv's pip.
Pro tip

Use which python and which pip to confirm they point inside .venv before running installations.
