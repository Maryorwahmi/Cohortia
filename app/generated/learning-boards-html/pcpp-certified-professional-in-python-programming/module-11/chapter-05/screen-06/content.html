Process Flow › Activate & Deactivate

Activation commands

# macOS / Linux
source .venv/bin/activate

# Windows (Command Prompt)
.venv\Scripts\activate.bat

# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# Deactivate the environment
 deactivate
Note the difference between creation and activation: creating adds files; activation changes your shell for the session only.

Visual confirmation

When active you typically see an indicator like (.venv) at the start of your prompt. Always verify before installing packages so you don't pollute your global environment.
Install while active: pip install requests — this places requests inside the venv's site-packages.
Verify: pip list shows installed packages for the active environment.
Misconception check: activation is not permanent. It only applies to the current shell session and must be re-run in new terminals.
