Each objective maps to a verifiable action: create a venv, run activation, install a package, export requirements.txt, and confirm isolation with pip list.
Assessment idea
Set up two project directories, create distinct venvs, activate them one at a time, install different Flask versions, run pip list in each, and show that global pip list lacks those packages. Explain the venv vs virtualenv choice afterwards.
Instructor tip

Use .venv as the folder name to reduce accidental commits; add it to .gitignore and produce a requirements.txt with pip freeze > requirements.txt for reproducibility on servers.
