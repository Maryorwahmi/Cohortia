Definition › Environment Anatomy

Core folders

bin/ or Scripts/ — environment-specific executables, including python and pip
lib/pythonX.Y/site-packages — where pip places installed packages for this environment
pyvenv.cfg — configuration file recording the base interpreter and metadata

Practical example

After activating and installing requests, files will appear under .venv/lib/python3.9/site-packages/requests. The environment directs the shell to these local files via PATH adjustments during activation.
Safe removal: delete the environment folder when not active; recreating is fast using python3 -m venv.
Misconception: the environment is not a complete copy of system Python; it references system headers and binaries as needed.
