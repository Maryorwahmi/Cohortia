Definition › Install & Verify

Walkthrough commands

# activate, install, verify
source .venv/bin/activate
pip install requests
pip list
# expected in the environment's pip list: requests

deactivate
pip list
# expected in global pip list: requests NOT listed (unless previously installed globally)
If requests appears in global pip list after deactivation, it means it was previously installed globally — the environment still provided isolation for the new install during activation.

Reproducibility

Export your environment with pip freeze > requirements.txt. That requirements file lets others create the same environment with pip install -r requirements.txt on a fresh venv.
Tip: After adding packages, run pip freeze > requirements.txt to capture exact versions.
Check path: run which python or where python to ensure commands target the venv's interpreter.
Misconception check: pip install does not automatically know which project you meant unless the environment is active in the shell where you run it.
