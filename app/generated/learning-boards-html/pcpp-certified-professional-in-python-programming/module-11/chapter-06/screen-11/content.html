Dependency Workflow

Managing Dependencies and Running Code with `Poetry`

Adding packages, locking versions, and executing scripts

Adding Dependencies

  • `poetry add <package>`: Installs package, updates `pyproject.toml` and `poetry.lock`.
  • `poetry add --group dev <package>`: Adds development-only dependencies.

Running Commands

  • `poetry run <command>`: Executes commands within the virtual environment.
  • `poetry shell`: Activates an interactive shell within the environment.
Example Scenario

Use `poetry add django` to install Django, then `poetry run python manage.py runserver` to start your development server.

Key Takeaway

`Poetry` provides intuitive commands for dependency management and environment interaction, ensuring precise control and reproducibility.

# 1. Add a new dependency (e.g., requests)
poetry add requests
# Output (example)
Updating pyproject.toml
Updating poetry.lock
Installing dependencies from lock file
... (installation output) ...
# 2. Add a development dependency
poetry add --group dev pytest
# 3. Create a simple script (main.py)
# my-poetry-app/main.py
import requests

def fetch_data(url):
    response = requests.get(url)
    print(f"Fetched data from {url}: {response.status_code}")

if __name__ == "__main__":
    fetch_data("https://jsonplaceholder.typicode.com/todos/1")
# 4. Run the script using poetry run
poetry run python main.py
# Output (example)
Fetched data from https://jsonplaceholder.typicode.com/todos/1: 200
