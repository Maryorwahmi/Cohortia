Setting Up Projects with `Poetry`

Creating new projects and adding initial dependencies

Poetry Installation & Project Creation

  • Install Poetry via its dedicated installer script.
  • Use `poetry new <project-name>` to create a new project.
  • This generates a standard project structure and `pyproject.toml`.
  • Poetry automatically manages the virtual environment.
Pro Tip

Ensure Poetry is added to your system's PATH after installation for easy command-line access.

Key Takeaway

`Poetry` streamlines project initialization by creating a structured directory and a central `pyproject.toml` file, ready for development.

# 1. Install Poetry (if not already)
curl -sSL https://install.python-poetry.org | python3 -
# 2. Create a new Poetry project
poetry new my-poetry-app
cd my-poetry-app
# 3. Inspect initial pyproject.toml
# my-poetry-app/pyproject.toml
[tool.poetry]
name = "my-poetry-app"
version = "0.1.0"
description = ""
authors = ["Your Name <you@example.com>"]
readme = "README.md"

[tool.poetry.dependencies]
python = "^3.10" # Or your current Python version

[build-system]
requires = ["poetry-core"]
build-backend = "poetry.core.masonry.api"
