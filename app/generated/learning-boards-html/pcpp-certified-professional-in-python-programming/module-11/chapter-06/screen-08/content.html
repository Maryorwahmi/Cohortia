Running Commands and Development Dependencies with `Pipenv`

Executing scripts and isolating development-only packages

`pipenv run`

  • Executes a command within the project's virtual environment.
  • No need to manually activate the environment.
  • Ensures correct Python interpreter and package versions are used.

`pipenv shell`

  • Activates a subshell within the project's virtual environment.
  • All subsequent commands run within the isolated environment.
  • Useful for interactive development and debugging.

Development Dependencies

  • Install with `pipenv install --dev <package>`.
  • Added to `[dev-packages]` in `Pipfile`.
  • Keeps production environment lean.
Key Takeaway

`Pipenv` offers robust commands for executing code and managing development-specific dependencies, enhancing environment control.

# 1. Run a Python script
# my_script.py
# import flask
# print(f"Flask version: {flask.__version__}")

pipenv run python my_script.py
# Output (example)
Flask version: 2.2.5
# 2. Run a testing framework
pipenv install --dev pytest
pipenv run pytest
# 3. Activate the shell
pipenv shell
# Output (example)
(my_pipenv_project-...) $ python
>>> import flask
>>> flask.__version__
'2.2.5'
>>> exit()
(my_pipenv_project-...) $ exit
