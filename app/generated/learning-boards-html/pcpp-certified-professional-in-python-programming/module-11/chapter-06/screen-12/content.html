Distribution Focus

Packaging and Publishing with `Poetry`

Streamlining library distribution to PyPI

Key `Poetry` Publishing Features

  • `poetry build`: Creates source distributions (`sdist`) and wheels (`wheel`).
  • `poetry publish`: Uploads packages directly to PyPI or custom repositories.
  • Centralized metadata in `pyproject.toml` simplifies packaging.
  • Ideal for library authors and maintainers.
Why it matters

Poetry's integrated approach reduces complexity and potential errors in the package release process, making distribution much smoother.

Key Takeaway

`Poetry` excels at packaging and publishing, offering an all-in-one solution for library development and distribution to PyPI.

Poetry's Publishing Workflow

From code to PyPI with ease

Develop Code

Define project in `pyproject.toml`

Build Package

`poetry build` (sdist, wheel)

Publish to PyPI

`poetry publish`
