Getting Started with `Pipenv`

Installing packages and managing your project environment

Initial Setup Steps

  • Install `pipenv` globally: `pip install pipenv`.
  • Navigate to your project directory.
  • Run `pipenv install` to create a virtual environment and `Pipfile`.
  • Use `pipenv install <package>` to add dependencies.
Pro Tip

Always commit your `Pipfile` and `Pipfile.lock` to version control to ensure team members get identical environments.

Key Takeaway

`Pipenv` simplifies environment setup and dependency installation, automatically managing `Pipfile` and `Pipfile.lock` for reproducibility.

# 1. Install Pipenv globally
pip install pipenv
# 2. Navigate to project & initialize
mkdir my_pipenv_project
cd my_pipenv_project
pipenv install
