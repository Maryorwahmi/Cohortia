Key Concepts: Foundations

Reinforcing essential dependency management terms

Dependency Drift

The problem where different installations of a project end up with varying versions of dependencies due to non-specific version constraints, leading to inconsistent behavior.

`Pipenv`

A dependency manager for Python that combines virtual environment management, `pip` installation, and dependency locking using `Pipfile` and `Pipfile.lock`.

`Pipfile`

A TOML-formatted file used by `Pipenv` to declare direct project dependencies and version constraints, replacing `requirements.txt`.

`Pipfile.lock`

A JSON-formatted file generated by `Pipenv` that contains exact versions and cryptographic hashes of all direct and transitive dependencies, ensuring reproducible builds.

Summary Takeaway

`Pipenv` and its associated files (`Pipfile`, `Pipfile.lock`) provide a robust solution to dependency drift, ensuring consistent and reproducible Python environments.
