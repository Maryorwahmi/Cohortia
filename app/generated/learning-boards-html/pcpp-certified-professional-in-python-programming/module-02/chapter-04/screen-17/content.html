Module 2 › Chapter 2.4 › What to Remember
Tuple bases
Bases must be a tuple when calling type; remember the single-element comma.
Prefer closures
Closures and named functions preserve readability and debuggability better than raw code objects or exec.
Avoid exec on untrusted input
Exec allows arbitrary execution. Sanitize, isolate globals, or avoid altogether in production code.
One final thought

Dynamic creation is a specialized tool. Use it to reduce boilerplate and adapt to runtime schemas, but pair it with tests, readable names, and security reviews to keep your codebase healthy.
