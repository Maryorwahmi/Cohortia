Module 2 › Chapter 2.4 › Methods in attrs
Code walkthrough
def real_init(self, name, age):
  # multi-line initializer keeps clarity
  self.name = name
  self.age = age

def full_info(self):
  return f"{self.name} ({self.age}) - status: {self.default_status}"

attrs = {
  'default_status': 'Active',
  '__init__': real_init,
  'full_info': full_info
}
User = type('User', (object,), attrs)

u = User('Sam', 28)
print(u.full_info())
This preserves function names and makes debugging clearer than embedding everything in a lambda.
Concepts & tips
  • Functions become methods through the descriptor protocol and bind self at call time.
  • Lambdas are fine for short single-expression methods like simple getters or transformations.
  • Prefer a named def when you want clear __name__, docstrings, and stack traces.
  • Assigning pre-defined functions into attrs helps tooling and test diagnostics.
Common mistake

Putting a function that closes over external mutable state can produce surprising instance behavior. Prefer explicit parameters or copy values inside __init__.
