Proxies & Adapters
Generate wrapper classes that forward calls to remote services, injecting cross-cutting concerns like logging and retries without hand-coding every adapter.
Serialization helpers

Create classes with (de)serialization methods attached to automate conversion between JSON and Python instances derived from external schemas.

Code generation hybrid

For strong tooling, generate source files during a build step and keep runtime generators for exceptional adaptation. This combines IDE support and runtime flexibility.
