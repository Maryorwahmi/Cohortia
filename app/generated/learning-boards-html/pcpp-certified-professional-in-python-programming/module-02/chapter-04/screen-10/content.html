Module 2 › Chapter 2.4 › Closures as function factories
Example: make_greeter
def make_greeter(greeting_word):
  def _greeter(name):
    return f"{greeting_word}, {name}!"
  return _greeter

hello_greeter = make_greeter("Hello")
print(hello_greeter("Alice"))  # Hello, Alice!
The returned function remembers greeting_word even after make_greeter returns.
When to prefer closures
  • When you need simple parameterized callbacks without changing code objects.
  • When readability and debuggability are priorities.
  • When the generated function's logic is brief and self-contained.
Key Takeaway

Closures are a first-choice dynamic function technique for clarity and safety; reserve FunctionType or exec for special cases.
