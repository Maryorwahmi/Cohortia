Comparison: Dynamic vs Generated Source
Dynamic at runtime
+ Flexible with changing schemas
- Harder for IDEs and static analysis
Generate .py files
+ Strong IDE support and type hints
- Requires generation step and build-time sync
Practical mitigations
  • Attach clear __name__ and __repr__ strings to generated classes.
  • Emit type stubs or generated source in CI so editors can see types.
  • Cache generated classes to avoid runtime overhead in loops.
