Dynamic Class & Function Creation

Learn how to construct classes with type(), make small runtime functions with lambda, and use types.FunctionType when you need a function object from an existing code object.

Quick Orientation

You will practice creating a UserProfile class from a list of fields, inspect created objects, and discuss limitations and security concerns. Keep an eye out for the base-classes tuple requirement and for times when closures are a simpler alternative to types.FunctionType.
