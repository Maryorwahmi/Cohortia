Module 2 › Chapter 2.4 › types.FunctionType in practice
Step example
import types

def template_func(x, y):
  return x + y

code = template_func.__code__
# Create a new function that uses the same code object but has defaults for y
new_fn = types.FunctionType(code, globals(), 'dynamic_adder', (10,))
print(new_fn.__name__)      # dynamic_adder
print(new_fn(5))            # uses y default, returns 15
print(new_fn(5, 7))         # overrides default, returns 12
Observe the new function's __name__ and __defaults__ for verification.
Notes & caveats
  • FunctionType does not change bytecode; it changes the wrapper around an existing code object.
  • Globals passed to FunctionType influence name lookups inside the code object.
  • Closures require careful handling; including a closure argument is advanced.
Misconception

Don't expect to compile new logic by only using FunctionType; to alter behavior you need a different code object or use exec to create new code objects.
