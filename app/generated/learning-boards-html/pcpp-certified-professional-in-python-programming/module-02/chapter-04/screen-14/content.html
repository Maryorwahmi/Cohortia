MCQ example
Which type call is correct to inherit from BaseDocument?
A) type('Report', BaseDocument, {...}) — incorrect, bases must be tuple
B) type('Report', (BaseDocument,), {...}) — correct
C) type('Report', [BaseDocument], {...}) — incorrect, list not allowed
Validation checks
  1. Assert generated_class.__name__ equals expected name.
  2. Assert expected base class in generated_class.__bases__.
  3. Instantiate and assert methods return expected outputs.
