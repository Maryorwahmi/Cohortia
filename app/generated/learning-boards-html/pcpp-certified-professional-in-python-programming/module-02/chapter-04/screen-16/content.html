Module 2 › Chapter 2.4 › Key Concepts
Dynamic Class Creation
Use type(name, bases, attrs) to build classes from runtime schemas or configs.
Dynamic Functions
Choose lambda for short expressions, closures for factories, and FunctionType to rewrap code objects.
Trade-offs
Be mindful of debugging, performance, tooling, and security; mitigate with names, tests, and generated stubs.
Summary takeaway

Dynamic creation is a powerful tool when used intentionally: prefer closures and named functions for clarity, use FunctionType for controlled code-object reuse, and avoid exec for untrusted inputs.
