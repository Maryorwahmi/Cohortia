Lambda and closure examples
# lambda
dynamic_multiply = lambda a, b: a * b

# closure factory
def make_greeter(greeting_word):
  def _greeter(name):
    return f"{greeting_word}, {name}!"
  return _greeter

hello = make_greeter("Hello")
print(hello("Alice"))
types.FunctionType example
import types

def template(x, y):
  return x + y

code = template.__code__
dynamic_add = types.FunctionType(code, globals(), 'dynamic_adder', (10, 20))
print(dynamic_add(5))  # uses default y
FunctionType wraps a code object, new globals, name, defaults, and optionally a closure.
