Module 2 › Chapter 2.5 › eval() Namespaces
Code
# Basic eval with default namespaces
x = 10
y = 20
res = eval("x * y - 5")
print(res)  # 195

# Restricted globals and locals
my_globals = {'a': 10, 'b': 5, 'pow': pow}
my_locals = {'c': 2}
res2 = eval("a * b + c", my_globals, my_locals)
print(res2)  # 52

# Restrict built-ins
safe = eval("pow(2,3)", {'pow': pow}, {})  # OK
Explanation
  • globals defines what top-level names are available during evaluation.
  • locals can provide temporary names and isolate side effects.
  • To remove built-in functions, supply a mapping with '__builtins__': {} or None carefully.
Concrete example
Evaluate only a numeric expression using a restricted set of names, avoiding import and file access.
Key Takeaway

Always pass minimal globals and locals to eval to control what an expression can access.
