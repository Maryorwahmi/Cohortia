Module 2 › Chapter 2.5 › Security Implications
Threat examples
  • Data theft — reading sensitive files using imported modules.
  • System compromise — running system commands to manipulate the host.
  • Denial of Service — infinite loops or heavy resource usage via executed code.
Example attack
A payload can import os and call system to run shell commands if built-ins are available.
Why filters fail
Keyword blocking is brittle; attackers can obfuscate or encode payloads.
Practical defense
Use parsers, disable built-ins, isolate execution, or avoid execution altogether.
Reflection

Before using eval or exec, ask: could an attacker craft a string that accesses files or runs commands in this environment?
