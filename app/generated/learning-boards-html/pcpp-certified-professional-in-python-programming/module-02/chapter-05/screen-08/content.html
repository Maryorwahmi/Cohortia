Module 2 › Chapter 2.5 › ast.literal_eval
Definition
import ast
safe = ast.literal_eval("[1, {'key': 'value'}, True]")
print(safe)  # [1, {'key': 'value'}, True]

try:
    ast.literal_eval("__import__('os').system('ls')")
except ValueError as e:
    print("Rejected non-literal input")
When to use
Parsing literal strings from external sources like config or stored data.
Limitations
Does not handle arbitrary expressions like arithmetic or function calls.
Key Takeaway

Prefer ast.literal_eval for literal data from untrusted sources; it avoids executing code entirely.
