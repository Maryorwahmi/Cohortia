Timeline
1. Classify
Is the string data or executable code?
2. Parse
If data, use JSON, YAML or ast.literal_eval.
3. Restrict
If evaluation required, use minimal globals and no built-ins.
4. Isolate
For untrusted code, use a separate process/container.
