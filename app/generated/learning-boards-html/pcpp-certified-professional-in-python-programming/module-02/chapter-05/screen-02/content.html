Learning Objectives

Foundational skills you will build in this chapter.

Bloom: Learn → Understand → Apply → Master
01
Explain eval() behavior

Describe how eval evaluates expressions and returns a value, with examples such as arithmetic and function calls.

Verified Competency Milestone
02
Differentiate exec() from eval()

Explain that exec executes statements and can define functions, classes, and variables but returns None.

Verified Competency Milestone
03
Use custom globals and locals

Practice passing restricted dictionaries to limit the execution environment and control visibility of names.

Verified Competency Milestone
04
Recognize and mitigate security risks

Identify why executing untrusted strings can leak data or run system commands, and how to avoid it using safer tools.

Verified Competency Milestone
