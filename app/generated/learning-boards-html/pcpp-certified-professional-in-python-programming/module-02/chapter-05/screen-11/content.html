Module 2 › Chapter 2.5 › Alternative Patterns
Architecture patterns
Factories and type()
Programmatically construct classes or objects without executing code strings.
Structured data + parsers
Use JSON/YAML and typed loaders instead of exec for configuration.
Isolated execution
Run untrusted code in a separate process/container with minimal privileges.
Concrete scenario
A plugin system that loads modules from a trusted package repository and validates signatures is safer than executing plugin code supplied as strings from users.
Key Takeaway

Prefer structured creation and isolation over direct execution; treat runtime execution as a last resort.
