Module 2 › Chapter 2.5 › exec() Semantics
Example
exec_globals = {'x': 50}
exec_locals = {}
code = """
y = x * 2
"""
exec(code, exec_globals, exec_locals)
# Value stored in exec_globals
print(exec_globals['y'])  # 100
  • exec can define variables and functions at runtime.
  • Providing separate globals prevents pollution of module globals().
  • Check resulting namespace for created names after exec returns.
Scenario
Use exec when you need to generate functions or classes dynamically inside a controlled plugin system and you fully trust code source.
Misconception
Some developers assume exec isolates scope by default. It does not; you must pass a dedicated namespace mapping for isolation.
Pro Tip

If you need strong isolation, run code in a subprocess or separate interpreter, not just a mapping.
