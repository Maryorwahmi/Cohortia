Process: Safely handle runtime execution
01 Avoid
Prefer data formats and parsers over executing code.
02 Restrict
Provide minimal globals/locals and remove built-ins when possible.
03 Sanitize
Use structural parsing or ast.literal_eval for literal data.
04 Isolate
Run untrusted execution in a sandbox or separate process.
Why each step matters
  • Avoid reduces attack surface by eliminating execution entirely.
  • Restrict limits what executed code can access.
  • Sanitize stops dangerous constructs before they run.
  • Isolate contains damage in case of exploit.
Common Mistake
Blocking keywords is brittle. Rely on proper namespace restriction, parsing, or isolation instead.
