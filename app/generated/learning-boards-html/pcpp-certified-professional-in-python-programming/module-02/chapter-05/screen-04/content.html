Module 2 › Chapter 2.5 › Eval vs Exec
eval()
Evaluates an expression and returns a value
result = eval("10 + 5 * 2")
print(result)  # 20
# eval("if True: print('x')") raises SyntaxError
  • Accepts expressions only
  • Returns the evaluated result
  • Accepts globals and locals to control names
Key Takeaway

Use eval for trusted expressions that must return a value; restrict namespaces for safety.

exec()
Executes statements and creates names at runtime
exec_code = """
my_var = 100
def fn(x):
  return x*2
"""
exec(exec_code)
print(my_var)  # 100
  • Executes blocks: assignments, defs, classes
  • Does not return a value (None)
  • Can populate a provided namespace with new names
Common Mistake

Attempting to use eval to execute statements leads to SyntaxError; use exec for that purpose.
