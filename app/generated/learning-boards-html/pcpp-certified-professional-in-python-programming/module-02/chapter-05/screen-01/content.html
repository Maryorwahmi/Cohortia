Explore Key Topics
Eval vs Exec
Expression returns a value; statements change state.
Namespaces
Provide globals and locals to restrict side effects.
Safer parsing
Use ast.literal_eval for literal data whenever possible.
Concept Map
eval()
Evaluates expressions and returns a result.
exec()
Executes statements; can define names at runtime.
Security
Never run untrusted input without strong sandboxing.
Quick example
result = eval("10 + 5 * 2")  # -> 20
exec("x = 7
print('done')")     # executes, returns None
