Question
You receive user_input = "2 + 3 * 4". Which approach is safest and why?
Option A: ast.literal_eval
Fails because expression is not a literal.
Option B: eval with restricted built-ins
Works for arithmetic and prevents access to __import__ if built-ins are empty.
Recommended
Prefer a dedicated arithmetic parser. If unavailable, eval(user_input, {'__builtins__': {}}) will evaluate simple arithmetic while blocking built-in calls, but it still carries risk and should be used cautiously.
