Module 2 › Chapter 2.2 › What to Remember
Decide first
Prefer decorators or factories unless you need centralized definition-time control.
Use the lifecycle
Alter attrs in __new__; validate and register in __init__.
Document & test
Metaclass code runs at import time; keep it tested, minimal, and clearly documented.
Final thought

Metaclasses are a precise tool for definition-time customization. Use them when they simplify a cross-cutting need; otherwise favor readability.
