Module 2 › Chapter 2.2 › Class creation lifecycle
Process

Steps Python follows to build a class

1
Collect attrs: Python evaluates the class body and builds the attrs dictionary containing methods and variables.
2
Select metaclass: Use metaclass keyword or default to type.
3
Call __new__: metaclass.__new__(mcs, name, bases, attrs) creates and returns the class object.
4
Call __init__: metaclass.__init__(cls, name, bases, attrs) initializes and can validate the created class.
Example
# In __new__ you can add attrs before the class exists
class MyMetaclass(type):
  def __new__(mcs, name, bases, attrs):
    attrs['METACLASS_INJECTED_VAR'] = f"Hello from {name}"
    return super().__new__(mcs, name, bases, attrs)
Misconception
Changing attrs in __init__ will not change how the class was built. __init__ runs after type.__new__ has already created the class object.
Key Takeaway

Use __new__ to inject or alter class attributes; use __init__ to validate or set up the created class object.
