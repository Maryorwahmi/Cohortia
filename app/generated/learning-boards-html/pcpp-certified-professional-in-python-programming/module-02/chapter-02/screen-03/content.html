Practical outcomes

Concrete checks to confirm you implemented metaclass behavior correctly.

Attach a metaclass
Use the metaclass keyword in a class definition so Python uses your custom factory instead of type.
Mnemonic: class is declared with its maker.
Inject attributes in __new__
Modify attrs inside __new__ or edit the class object returned by type.__new__ to add methods or defaults.
Mnemonic: create then configure.
Avoid attrs in __init__
Modifying the attrs mapping in __init__ doesn’t change the already-built class; use __new__ instead.
Mnemonic: __init__ validates, doesn't rewrite.
Choose alternatives carefully
Class decorators and factories are often simpler; prefer metaclasses when you need centralized control during class creation.
