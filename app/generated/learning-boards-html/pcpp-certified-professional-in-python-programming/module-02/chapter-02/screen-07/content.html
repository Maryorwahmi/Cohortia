Module 2 › Chapter 2.2 › __init__ in depth
Pattern
Use __init__ to validate or register the class after it has been constructed. Avoid depending on changing attrs here.
class MyMetaclass(type):
  def __init__(cls, name, bases, attrs):
    print(f"__init__ called for {name}")
    # Validate the class
    if not name.startswith('Base'):
      print(f"INFO: Non-Base class '{name}' initialized.")
    super().__init__(name, bases, attrs)
Cards
Registration
Add cls to a central registry to discover subclasses at runtime.
Validation
Check naming or attribute constraints and raise errors early to guide implementers.
Pitfall
Editing attrs here does not retroactively change the class definition. If you need to add methods, attach them directly to cls.
Key Takeaway

Use __init__ for checks and registration. If you must add behaviour, set attributes on the class object itself.
