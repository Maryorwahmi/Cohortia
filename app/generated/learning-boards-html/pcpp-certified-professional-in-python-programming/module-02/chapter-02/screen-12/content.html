Pitfalls to avoid

  • Import-time side effects: heavy work in __new__ runs at import/definition time and can slow startup.
  • attrs confusion: changing attrs in __init__ does not affect the class that was already created.
  • Metaclass conflicts: incompatible metaclasses on different bases lead to TypeError.
Testing tip
Run class definitions in a REPL to observe printed lifecycle messages and validate behavior before importing into larger codebases.
Documentation
Document metaclass intent and the required attributes and methods it enforces so maintainers can easily understand the contract.
Key Takeaway

Keep metaclass code minimal, predictable, and well-documented. Use them only when central, cross-class control is required.
