Module 2 › Chapter 2.2 › Assigning a metaclass
Pattern

metaclass keyword

Declare the metaclass on the class header or define it on a base class that others inherit from.

class MyCustomClass(metaclass=MyMetaclass):
  version = 1.0

# Or set metaclass on a base class
class Base(metaclass=MyMetaclass):
  pass

class Child(Base):
  pass  # inherits the metaclass behavior
Conflict warning
If two base classes specify incompatible metaclasses, Python raises a TypeError at class creation time.
Key Takeaway

Prefer placing metaclasses on base classes when many subclasses should share behavior; avoid repeating metaclass= everywhere.
