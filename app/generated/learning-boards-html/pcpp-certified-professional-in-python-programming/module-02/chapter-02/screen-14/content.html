Module 2 › Chapter 2.2 › Key Concepts
Metaclass
A class that defines how other classes are created.
type
The default metaclass used by Python to create new-style classes.
__new__ vs __init__
__new__ creates the class object and is the right place to alter attrs; __init__ validates the finished class.
Summary Takeaway

Use metaclasses for definition-time, cross-class concerns; keep implementations small, documented, and predictable.
