Metaclasses: classes that make classes

Learn how Python constructs class objects, when the metaclass intervenes, and how to implement simple custom metaclasses to enforce structure and inject behavior.

Why it matters
Use metaclasses to centralize rules, register classes, or create DSL-style class behavior.
Concept Map
Object model snapshot
object → MyClass → my_instance and type → MyMetaclass → MyClass
This shows that classes are normal objects created by a metaclass. You can swap type with a custom metaclass to change how classes are built.
Starter code snapshot
# Example: default behaviour
class MyClass:
  pass

# Implicitly created by type
# Equivalent low-level: MyClass = type('MyClass', (), {})
Quick uses
  • Central registry of subclasses
  • Inject attributes or placeholder methods
  • Enforce naming or interface rules at definition time
Key takeaway

Metaclasses run when Python builds a class. Use __new__ to alter attributes before the class exists, and __init__ to validate the finished class.

Explore Key Topics
Default metaclass: type
type constructs classes when you use the class statement.
__new__ vs __init__
__new__ creates the class object; __init__ runs after creation for validation.
Practical pattern: Interface enforcement
Inject a placeholder method that raises NotImplementedError when missing.
