Module 2 › Chapter 2.2 › Common use cases
Patterns
Registry
Add classes to a central registry in __init__ for discovery by frameworks.
Singleton
Control instance creation by overriding __call__ in the metaclass to return the same instance.
ORM / DSL
Build mappings or class metadata automatically by inspecting attrs in __new__.
Concrete scenario
An ORM metaclass inspects attribute types during class creation, builds a fields mapping, and registers the model class. This keeps model definitions concise while centralizing the heavy lifting in one place.
Key Takeaway

Choose metaclasses for cross-cutting, definition-time behaviour such as registries, singletons, or automatic metadata generation.
