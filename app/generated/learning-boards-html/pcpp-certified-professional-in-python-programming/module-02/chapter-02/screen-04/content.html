Module 2 › Chapter 2.2 › What is a metaclass?
Definition

Classes as instances of a metaclass

A metaclass receives the class name, bases, and attrs mapping and returns a class object. Use a custom metaclass to control this creation step.

Concrete example

If a metaclass adds METACLASS_INJECTED_VAR, every class created by it will expose that attribute and instances can read it.

Misconception
Metaclasses don’t run on every instance creation; they run once when the class is built.
Why it matters
Centralizing class rules simplifies frameworks, ORMs, and consistent APIs across many classes.
Analogy

Factory metaphor

Think of a metaclass as the factory that makes blueprints. Instances are products made from blueprints. If you want to change the blueprint itself, change the factory.

Key Takeaway

Use metaclasses when you must control or validate how many classes are defined across a codebase at definition time.
