Learning Objectives

Progress from concept to implementation and validation.

Bloom: Learn → Understand → Apply → Master
01
Define metaclass

Explain that a metaclass is the factory that creates class objects and that classes are instances of metaclasses.

VERIFIED COMPETENCY MILESTONE
02
Identify type

Recognize that Python’s built-in type is the default metaclass for new-style classes and see the implicit call to type when defining a class normally.

VERIFIED COMPETENCY MILESTONE
03
Describe lifecycle

Map the order of calls: metaclass.__new__ runs first to create the class, then metaclass.__init__ runs to initialize and validate it.

VERIFIED COMPETENCY MILESTONE
04
Implement a metaclass

Create a custom metaclass by inheriting from type and overriding __new__ to modify attributes and __init__ to validate the created class.

VERIFIED COMPETENCY MILESTONE
