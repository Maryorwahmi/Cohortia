Module 2 › Chapter 2.2 › __new__ in depth
Pattern
Inspect attrs, add defaults or placeholders, then call super().__new__ to create the class. Optionally modify the returned class object before returning.
class MyMetaclass(type):
  def __new__(mcs, name, bases, attrs):
    print(f"__new__ called for {name}")
    # Inject a class attribute
    attrs['METACLASS_INJECTED_VAR'] = f"Hello from {name}"

    # Ensure required_method exists
    if 'required_method' not in attrs:
      def _placeholder(self):
        raise NotImplementedError(f"'{name}' must implement 'required_method'")
      attrs['required_method'] = _placeholder

    cls = super().__new__(mcs, name, bases, attrs)
    # Optionally modify cls directly
    cls._injected_after = True
    return cls
Explanation cards
Inject attributes
Add defaults into attrs so the created class includes them as real class attributes.
Placeholder methods
If a method is required but missing, add one that raises NotImplementedError to prompt implementers.
Preserve bases
Modifying bases is possible but changes the MRO; avoid unless you need to alter inheritance.
Check your understanding

What will happen if __new__ returns an object that is not a class? Try to imagine Python will raise an error at class definition time.
