Module 2 › Chapter 2.2 › Metaclasses vs alternatives
Metaclasses
Central hook at class creation, alter attrs and bases, register classes, enforce interfaces across many classes.
Decorators
Transform a final class object, simpler, more local, and easier to reason about for single-class changes.
Factories
Produce classes programmatically at runtime or when construction needs parameters; flexible but explicit.
Guiding question
Do you need to modify the attrs mapping or bases before the class exists, or do you just want to tweak the final class object? Modify before creation: metaclass. Tweak after creation: decorator or direct assignment.
