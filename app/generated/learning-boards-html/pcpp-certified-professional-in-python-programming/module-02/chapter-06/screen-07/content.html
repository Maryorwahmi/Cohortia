Key decorator pattern
import time
import functools

def timed_if_enabled(func):
  @functools.wraps(func)
  def wrapper(*args, **kwargs):
    if 'enable_timing' in kwargs and kwargs['enable_timing']:
      start_time = time.perf_counter()
      result = func(*args, **kwargs)
      end_time = time.perf_counter()
      wrapper.timing = end_time - start_time
      print(f"Function '{func.__name__}' took {wrapper.timing:.4f} seconds.")
      return result
    else:
      return func(*args, **kwargs)
  return wrapper
Practical notes
  • Use functools.wraps to preserve function name and docstring.
  • Document side effects: wrapper.timing persists and may reflect the last timed call.
  • Test both code paths: timed and non-timed to avoid surprises.
Example scenario
You can instrument expensive operations only when debugging or tracing is explicitly enabled, avoiding overhead in normal runs.
