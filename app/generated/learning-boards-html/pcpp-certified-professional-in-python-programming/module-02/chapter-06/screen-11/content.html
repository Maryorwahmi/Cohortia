Module 3 › Chapter 2.6 › Feature Toggle Metaclass
Starter code
FEATURE_FLAGS = {
  "new_dashboard": True,
  "beta_reports": False,
  "experimental_feature": False
}

class FeatureToggleMeta(type):
  def __new__(mcs, name, bases, attrs):
    def is_feature_enabled(self_obj, feature_name):
      return FEATURE_FLAGS.get(feature_name, False)
    attrs['is_feature_enabled'] = is_feature_enabled
    return super().__new__(mcs, name, bases, attrs)

class ApplicationSettings(metaclass=FeatureToggleMeta):
  pass
Testing hints
  • Assert known flags return expected booleans.
  • Mutate FEATURE_FLAGS and assert instances reflect the change.
  • Ensure unknown feature names default to False.
Learner task
Implement, run the tests, and reason about whether the method should read live globals or snapshot values at class creation.
