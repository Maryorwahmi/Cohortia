Module 3 › Chapter 2.6 › Dynamic Configuration Classes
Factory pattern
def create_config_class(name, attrs):
  def __init__(self_obj, **kwargs):
    for k, v in kwargs.items():
      setattr(self_obj, k, v)
    for k, v in attrs.items():
      if not k.startswith('__') and k not in kwargs:
        setattr(self_obj, k, v)
  def __repr__(self_obj):
    attrs_str = ', '.join(f"{k}={getattr(self_obj, k)!r}" for k in self_obj.__dict__)
    return f"{self_obj.__class__.__name__}({attrs_str})"
  final_attrs = {**attrs, '__init__': __init__, '__repr__': __repr__}
  return type(name, (object,), final_attrs)
Example usage
Create classes from a mapping and instantiate with defaults or overrides. This makes configuration extensible: adding a new section in the data creates a corresponding class automatically.
Analogy
Think of each config section as a template that becomes a typed object at runtime.
Caution
Document the generated attributes so IDEs and teammates know the expected keys.
