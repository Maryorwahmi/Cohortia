Question 1 reasoning
Metaclasses hook into class creation and are the most direct way to register classes automatically with a router. Decorators work but require per-class application; manual registration is error-prone; exec is unsafe and inappropriate.
Question 2 reasoning
When exec is called with a custom globals dictionary, definitions created by the executed string are added to that dictionary. Access the created class through that mapping rather than expecting it to appear in the current module namespace.
Reflective prompt
Which dynamic pattern would you choose for a public plugin API and what conventions would you document to make it easy for contributors?
