Module 3 › Chapter 2.6 › Simplified ORM via Metaclasses
Core steps
  • Collect field definitions from class attributes using the metaclass.
  • Store a _orm_fields mapping on the class and remove markers from attrs.
  • Inject dynamically created __init__, save, and __repr__ methods into the class.
Example
class User(Model):
  username = 'FIELD_STR'
  email = 'FIELD_STR'
  age = 'FIELD_INT'

user1 = User(id=1, username="alice", email="alice@example.com", age=30)
print(user1)
user1.save()
Trade-offs
Generated code reduces repetition but can obscure where attributes come from. Prefer this pattern for frameworks or prototypes and accompany it with documentation and tests.
Pitfall
Relying on string markers for types is brittle; validate and convert types explicitly when necessary.
