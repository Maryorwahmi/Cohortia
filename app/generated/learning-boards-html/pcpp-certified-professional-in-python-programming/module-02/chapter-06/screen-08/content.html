Wraps vs No Wraps
Without wraps
Wrapper masks original name and docstring; tooling is less useful.
With wraps
Preserves metadata so introspection and help utilities work as expected.
State & Signatures
  • Attach state to wrapper only when intentional and documented.
  • Avoid changing the visible signature; prefer explicit kwargs or careful inspect-based rewriting if required.
  • Write tests for concurrency-sensitive decorators to surface persistence bugs.
