Module 3 › Chapter 2.6 › Plugin Registry Walkthrough
Step-by-step
  1. Class definition triggers metaclass __new__.
  2. Metaclass computes service id and checks registry for duplicates.
  3. Metaclass inserts the class into _SERVICE_REGISTRY.
  4. Application iterates registry and instantiates services by id.
Example run
# After classes are defined
print("--- Available Services ---")
for service_id, service_cls in _SERVICE_REGISTRY.items():
  print(f"- {service_id}")

# Instantiate and call
processor = _SERVICE_REGISTRY["data_processor"]()
processor.execute("raw_input_string")
Pro tip
Design a deterministic import path in your app to ensure plugins are discovered predictably.
Test
Reset or isolate the registry between tests to avoid leakage across test cases.
