Practical skill checks

Use these small exercises to verify each objective in a REPL or test file.

01 — Introspection
Call the print function type on a literal and on a class to observe class vs metaclass. Verify the output shows class types.
Mnemonic: Think of type as a label reader for any value.
02 — Dynamic class
Use type with three arguments to create a class and instantiate it. Ensure bases are passed as a tuple.
Mnemonic: name, bases, attrs — the three scaffolding parts for a class.
03 — Inspect dunders
Print __class__, __bases__, __dict__, and __mro__ to see the instance-class mapping, base tuple, namespace entries, and lookup order.
Mnemonic: class, bases, dict, mro — the anatomy of type introspection.
04 — Explain class construction
Describe how Python executes the class body into a temporary namespace, then calls the metaclass to construct the final class object.
Mnemonic: execute body → collect name, bases, attrs → metaclass(name, bases, attrs).
