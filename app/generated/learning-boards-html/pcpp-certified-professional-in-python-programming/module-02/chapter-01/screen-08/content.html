Key attributes

These attributes let you introspect and reason about class and instance structure at runtime.

__class__
An instance attribute referencing the class object that created the instance. Useful for identity checks and reflection.
__bases__
A tuple of immediate base classes for a class. The order matters for MRO and resolution of inherited names.
__dict__
A mapping of names to objects in the class or instance namespace. Methods appear in the class dict; instance state appears in the instance dict.

Example

class Parent:
  x = 1

class Child(Parent):
  def __init__(self, v):
    self.v = v

c = Child(5)
print(c.__class__)
print(Child.__bases__)
print(Child.__dict__.get('x'))
print(c.__dict__)
Common mistake
Expecting methods to be in the instance __dict__. Methods are descriptors stored on the class; instances hold only per-instance data.
