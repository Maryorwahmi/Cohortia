Process Flow

Execute, collect, then construct

Step 1: Execute body
Run function definitions and assignments in a fresh temporary namespace. These entries become the attribute mapping for the new class.
Step 2: Evaluate bases
Evaluate any expressions used as base classes and assemble a tuple of base classes. Even a single base must be a tuple element.
Step 3: Call metaclass
Pass the name, the bases tuple, and the attrs dict to the metaclass to construct the final class object. By default the metaclass is type.
Common misconception
People often think the class is built as the body runs. In reality the body runs first to form attributes; then the metaclass assembles the class object.
Practical note
This ordering is why metaclasses can inspect or transform the attributes after the body runs and before instances are ever created.
