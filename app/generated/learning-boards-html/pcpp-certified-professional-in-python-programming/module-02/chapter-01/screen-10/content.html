Module 2 › Chapter 2.1 › type(name,bases,attrs)

What each argument means

  • Name: the class name string used in representation and debugging.
  • Bases: a tuple of classes that become the immediate parents for inheritance.
  • Attrs: a mapping whose entries become the class namespace — methods and class variables.
Example
def init(self, value):
  self.value = value

MyClass = type('MyClass', (object,), {'class_var': 1, '__init__': init})
inst = MyClass(7)
print(inst.class_var)  # 1
Pitfall
Provide bases as a tuple. Forgetting the comma for a single base produces a TypeError or unexpected behavior.
