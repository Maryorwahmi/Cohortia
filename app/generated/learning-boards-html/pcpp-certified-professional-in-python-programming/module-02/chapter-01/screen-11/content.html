Plain functions become bound methods

Place plain functions into the attrs mapping. When accessed via an instance, the function is bound so the instance becomes the first argument.

def greet(self):
  return f"hello {self.name}"

C = type('C', (object,), {'greet': greet})
inst = C()
inst.name = 'Ana'
print(inst.greet())  # greet bound to inst at call time

Gotchas

  • Do not try to pre-bind functions to instances before placing them in attrs.
  • Inspect the class __dict__ to find the raw function objects; instances hold only state.
  • Wrapping functions may break descriptor binding if the wrapper is not a descriptor-aware callable.
Practical tip
When creating classes programmatically, include methods as plain functions and rely on Python's binding to give instance methods the correct self parameter.
