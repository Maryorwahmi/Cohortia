What __mro__ tells you

The tuple lists classes in the order Python will search for attributes. In multiple inheritance this order ensures consistency and avoids contradictions.

Example
class A: pass
class B(A): pass
class C(A): pass
class D(B, C): pass
print(D.__mro__)
# D, B, C, A, object

Practical notes

  • Always inspect __mro__ when debugging ambiguous method resolution.
  • Changing the order of bases can alter behavior; re-evaluate the MRO after edits.
  • Mixins should be designed to avoid conflicting names, or their placement should be intentional.
Misconception
Assuming leftmost parent always wins without checking the computed MRO. The C3 algorithm produces a specific linearization that should be inspected.
