Question 1

Which statement about type is false? The false choice is that type cannot be used to create classes.

Explanation: type with three arguments builds a class object using name, bases, and attrs. The class statement is syntactic sugar over this mechanism.

Question 2

Given a Dog class inheriting from Animal and an instance my_dog, what do these prints show?

print(my_dog.__class__)
# <class '__main__.Dog'>
print(Dog.__bases__)
# (<class '__main__.Animal'>,)
print(Dog.__mro__)
# (<class '__main__.Dog'>, <class '__main__.Animal'>, <class 'object'>)
Explanation: these outputs show the instance-class mapping, the direct parent tuple, and the MRO used for attribute lookup respectively.
