Module 2 › Chapter 2.1 › Classes as Objects
Definition

Classes are first-class values

Because classes are objects, you can manipulate them at runtime. This unlocks factories, runtime selection, and programmatic modifications.

Concrete example
class Simple:
  pass

Alias = Simple
print(type(Simple))  # shows class is an instance of type
print(Alias is Simple)  # True — assignment copies reference
Misconception
Classes are static declarations. Reality: class objects are live and can be mutated at runtime.
Key takeaway
Treat classes as objects to enable dynamic patterns safely and intentionally.
Analogy
Think of a class as a blueprint object stored in memory rather than a static file. You can pass the blueprint, decorate it, or use a factory to return different blueprints based on runtime conditions.
Why it matters
  • Enables runtime customization and plugin systems.
  • Supports factories that produce classes tailored to configuration.
  • Lets metaclasses and decorators alter class construction centrally.
