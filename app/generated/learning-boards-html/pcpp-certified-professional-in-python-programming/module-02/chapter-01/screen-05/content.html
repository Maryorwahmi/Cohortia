Module 2 › Chapter 2.1 › type() Introspection
Definition

type(object) reveals the class

Use type with a single argument to get the class object that produced that instance. This is a direct runtime inquiry into the object's identity.

# Examples
print(type(10))        # <class 'int'>
print(type('hello'))   # <class 'str'>

class A: pass
a = A()
print(type(a))         # <class '__main__.A'>
Explanation
  • type returns the class object itself, not a string label.
  • Calling type on a class returns its metaclass, commonly type.
  • Use identity checks with type when you want exact class matching; use isinstance for subclass-friendly checks.
Key takeaway
Prefer isinstance for polymorphic checks; use type for exact class identity and debugging.
