Common mistakes

  • Passing a single base class without using a tuple.
  • Mutating class __dict__ unexpectedly at runtime.
  • Expecting methods to appear in an instance's __dict__.
Example error
Forgetting the tuple when calling type can raise a TypeError or produce incorrect inheritance semantics. Always ensure bases is a tuple.

Defensive patterns

- Wrap single bases in a tuple if needed. - Build attrs in a local scope to avoid accidental globals. - Document dynamic class construction so other developers are not surprised.
Key takeaway
Programmatic class creation is powerful but should be guarded with simple validation and clear intent to avoid subtle runtime errors.
