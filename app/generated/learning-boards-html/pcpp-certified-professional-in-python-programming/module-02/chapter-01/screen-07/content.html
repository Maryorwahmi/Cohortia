Module 2 › Chapter 2.1 › Class vs type()
Standard class
class MyClassA:
  class_var = 10

  def __init__(self, value):
    self.instance_var = value

  def greet(self):
    return f"Hello from MyClassA with value {self.instance_var}"
Define, instantiate, and observe the same methods and attributes at runtime.
Dynamic using type
def init_method(self, value):
  self.instance_var = value

def greet_method(self):
  return f"Hello from MyClassB with value {self.instance_var}"

MyClassB = type(
  'MyClassB',
  (object,),
  { 'class_var': 10, '__init__': init_method, 'greet': greet_method }
)
The resulting MyClassB will behave like MyClassA when instantiated and called.
