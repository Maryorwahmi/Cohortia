Code Walkthrough
_PLUGIN_REGISTRY = {}

class PluginMetaclass(type):
  def __new__(mcs, name, bases, attrs):
    if name != 'BasePlugin' and 'plugin_name' not in attrs:
      raise TypeError("Plugin class must define a 'plugin_name' attribute.")

    cls = super().__new__(mcs, name, bases, attrs)

    if name != 'BasePlugin':
      plugin_id = attrs.get('plugin_name', name)
      if plugin_id in _PLUGIN_REGISTRY:
        raise ValueError(f"Duplicate plugin_name '{plugin_id}'.")
      _PLUGIN_REGISTRY[plugin_id] = cls

    return cls

class BasePlugin(metaclass=PluginMetaclass):
  pass

class FileProcessorPlugin(BasePlugin):
  plugin_name = 'file_processor'
  def process(self, data):
    return data.upper()
Explanation
  • Maintain a global mapping like _PLUGIN_REGISTRY to look up classes by id.
  • Validate required attributes in __new__ so errors appear during import or definition.
  • Register concrete classes after calling super().__new__ so the class object exists for storage.
Concrete scenario
A web framework can register request handlers or serializers automatically so plugins are discovered when modules load.
Key Takeaway

Registration via metaclass centralizes discovery and catches missing configuration earlier.
