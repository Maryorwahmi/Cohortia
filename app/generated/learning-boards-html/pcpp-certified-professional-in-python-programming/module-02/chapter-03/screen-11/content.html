Module 2 › Chapter 2.3 › Common mistakes
Mistake
Mutating attrs in __init__
Make changes in __new__ so they are included in the created class. __init__ runs after creation.
Mistake
Forgetting super().__new__
Not calling the parent prevents class construction and results in obscure errors. Always delegate to the parent metaclass.
Mistake
Over-engineering
Use metaclasses only when decorators or inheritance would be too noisy or insufficient to enforce definition-time rules.
Testing tip
Include tests that assert the registry contents, that injected methods exist, and that invalid class definitions raise the expected exceptions during import time.
