Module 2 › Chapter 2.3 › Method injection: AutoReprMetaclass
Code example
class AutoReprMetaclass(type):
  def __new__(mcs, name, bases, attrs):
    if '__repr__' not in attrs:
      def auto_repr(self):
        attrs_str = ', '.join(f"{k}={getattr(self, k)!r}" for k in self.__dict__)
        return f"{self.__class__.__name__}({attrs_str})"
      attrs['__repr__'] = auto_repr
    return super().__new__(mcs, name, bases, attrs)

class MyData(metaclass=AutoReprMetaclass):
  def __init__(self, x, y):
    self.x = x
    self.y = y
Explanation and example
  • The metaclass injects __repr__ only when the class has not provided one explicitly.
  • The injected method formats instance attributes from the object's dictionary for readable output.
  • Be careful about exposing sensitive data via auto-generated representations.
Concrete example
An instance of MyData will print as MyData(x=10, y=20) without the author writing a repr method.
