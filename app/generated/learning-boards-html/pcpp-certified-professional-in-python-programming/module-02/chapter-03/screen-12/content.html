Starter Code
class VersionedClassMeta(type):
  def __new__(mcs, name, bases, attrs):
    if '__version__' not in attrs:
      attrs['__version__'] = "0.0.1"

    if '__doc__' not in attrs or not attrs['__doc__'] or not attrs['__doc__'].strip():
      raise ValueError(f"Class '{name}' must have a non-empty docstring.")

    return super().__new__(mcs, name, bases, attrs)

class MyService(metaclass=VersionedClassMeta):
  """This is a documented service with a custom version."""
  __version__ = "1.2.3"
  def run(self):
    print(f"Running MyService v{self.__version__}")
Activity checklist
  1. Implement the metaclass exactly in __new__.
  2. Test that MyService has the intended __version__ and docstring.
  3. Uncomment the UndocumentedService to verify the ValueError is raised during class definition.
Key Takeaway

This exercise practices both injection of defaults and raising clear errors at definition time for missing documentation.
