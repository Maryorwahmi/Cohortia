Module 2 › Chapter 2.3 › Wrapping methods with metaclasses
Example pattern
class LoggerMeta(type):
  def __new__(mcs, name, bases, attrs):
    if 'log_level' not in attrs:
      attrs['log_level'] = 'INFO'

    def log_message(self, message):
      print(f"[{self.log_level}] {self.__class__.__name__}: {message}")
    attrs['log'] = log_message

    return super().__new__(mcs, name, bases, attrs)
Notes
  • Decide whether to read configuration at call time (instance attribute) or bake defaults during creation.
  • Use functools.wraps when wrapping existing functions to preserve metadata.
  • Wrapping in the metaclass gives consistent behavior across all classes using it.
Common-problem

Ensure wrappers access instance attributes properly. Avoid capturing mutable defaults at class-creation time unless intended.
