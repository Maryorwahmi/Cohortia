Module 2 › Chapter 2.3 › What to Remember
Mutate in __new__
Make attribute and method changes before the class is constructed so they are included in the resulting class object.
Call super().__new__
Delegating to the parent metaclass is required to actually create the class object.
Use sparingly
Reserve metaclasses for definition-time cross-cutting concerns, not for every convenience feature.
Final takeaway

When applied thoughtfully, metaclasses make class creation automated, consistent, and self-validating—improving maintainability for frameworks and libraries.
