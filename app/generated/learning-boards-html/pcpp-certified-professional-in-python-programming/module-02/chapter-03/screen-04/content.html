Module 2 › Chapter 2.3 › Metaclasses: definition and timing
Definition
Metaclass lifecycle
  • __new__: receives attrs; mutate here to affect the class that will be created.
  • super().__new__: actually creates the class object; do not forget to call it.
  • __init__: runs after the class exists; changing the passed attrs does not alter the already-created class.
Common mistake
Modifying attrs in metaclass __init__ expecting the class to change. Apply changes in __new__ instead.
Analogy card
Think of __new__ as the assembly blueprint step: you prepare the parts. Calling super().__new__ builds the product. __init__ inspects the finished product but cannot retroactively change how parts were assembled.
Example claim
If you want to add a method to every subclass, add it to attrs in __new__ before creating the class.
Key takeaway
Make attribute injections in __new__; use __init__ only for post-creation bookkeeping.
