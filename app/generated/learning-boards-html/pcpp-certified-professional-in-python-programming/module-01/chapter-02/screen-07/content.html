Definition
EnforceMethodMetaclass
Check the namespace in __new__ and raise a TypeError if the required method is absent.
class EnforceMethodMetaclass(type):
  def __new__(mcs, name, bases, namespace):
    if 'process_data' not in namespace:
      raise TypeError(f"Class {name} must implement 'process_data' method.")
    return super().__new__(mcs, name, bases, namespace)

class DataProcessor(metaclass=EnforceMethodMetaclass):
  def __init__(self, data):
    self.data = data
  def process_data(self):
    print(f"Processing data: {self.data}")
Explanation
  • __new__ receives the namespace dictionary built from the class body.
  • Raising TypeError prevents the class from being created at import time.
  • Allow the base marker class to be defined by skipping enforcement for that name.
Common mistake
Enforcing in __init__ rather than __new__ lets the invalid class exist and defers the error until later.
Key Takeaway

Use __new__ for structural enforcement to catch design errors early and keep runtime code simpler.
