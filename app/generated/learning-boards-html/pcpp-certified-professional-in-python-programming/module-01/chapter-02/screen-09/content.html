Architecture
Choosing where to place metaclass logic
__new__
Create and transform class object. Enforce structure and add methods now.
__init__
Initialize class-level metadata after creation. Avoid major structural changes here.
__call__
Control instance creation. Implement patterns like Singletons here by caching instances.
Singleton outline
class SingletonMetaclass(type):
  def __init__(cls, name, bases, namespace):
    super().__init__(name, bases, namespace)
    cls._instance = None
  def __call__(cls, *args, **kwargs):
    if cls._instance is None:
      cls._instance = super().__call__(*args, **kwargs)
    return cls._instance
Misconception
Using __call__ to alter construction is powerful but can hide side effects; document intent clearly when you override it.
