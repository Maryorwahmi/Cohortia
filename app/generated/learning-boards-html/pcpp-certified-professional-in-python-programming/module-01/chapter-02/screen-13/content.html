Key Concepts
Three compact cards summarize the chapter.
Metaclass
A class whose instances are classes; default metaclass is type.
</>
type() function
Calling type(name, bases, dict) creates a class dynamically — the same mechanism a metaclass implements.
__new__, __init__, __call__
__new__ creates and shapes the class, __init__ initializes it, __call__ controls instance creation.
Summary

Use metaclasses for cross-cutting class creation concerns, keep them focused, and prefer simpler alternatives when possible.
