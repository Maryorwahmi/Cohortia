Design-time validation & best practices
Ask first
Can a decorator, ABC, or simple runtime check satisfy the requirement? If so, prefer that.
Enforce in __new__
Perform structural changes and raise TypeError to prevent invalid classes from existing.
Test import-time behavior
Write tests that import modules and assert registration and expected exceptions.
Keep side effects minimal
Avoid heavy work at class definition time, such as network calls or filesystem mutations.
Document behavior
Explain what the metaclass enforces and why so future maintainers are not surprised by errors at import time.
Key Takeaway

Use metaclasses only when you need programmatic class creation control across many types; design them for clarity and test their import-time effects.
