class ServiceMetaclass(type):
  def __new__(mcs, name, bases, namespace):
    # Allow the base Service to be defined without start/stop
    if name != 'Service':
      if 'start' not in namespace:
        raise TypeError(f"Class {name} must implement a 'start()' method.")
      if 'stop' not in namespace:
        raise TypeError(f"Class {name} must implement a 'stop()' method.")
    return super().__new__(mcs, name, bases, namespace)

class Service(metaclass=ServiceMetaclass):
  pass

class WebServer(Service):
  def start(self):
    print('Web server starting...')
  def stop(self):
    print('Web server stopping...')

print("Valid class 'WebServer' defined successfully.")
Hints & pitfalls
  • Inspect the namespace passed to __new__; this reflects definitions in the class body.
  • Check class name to allow the base service to be defined without methods.
  • Avoid getattr checks that can inherit methods from bases and hide omissions.
Test suggestion
Uncomment a faulty subclass to confirm TypeError raises during import rather than at runtime.
