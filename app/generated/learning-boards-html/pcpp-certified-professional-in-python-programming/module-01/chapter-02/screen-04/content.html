Core Concept
Metaclass: a class whose instances are classes
Think: classes are objects, and metaclasses construct those class objects. This is where class-level behavior is defined.
Default metaclass: type
Use: validation, registration, automated attributes
Misconception: metaclasses are magical hacks — they are structured hooks used by frameworks.
Key Takeaway

Metaclasses let you program class creation. Use them for class-wide rules and automation, not everyday instance behavior.

Concrete example
MyClass = type('MyClass', (object,), {'x': 10, 'greet': lambda self: print('Hello')})
# MyClass is now a class object created by the type metaclass
Example explanation: calling type with name, bases, and namespace constructs a class object the same way the metaclass does when a class statement runs.
Check your understanding
Why would you validate a class at definition time rather than at instance creation? Think about catching design errors earlier and keeping runtime costs low.
