Comparison
Decorator vs ABC vs Metaclass
Class decorator
Post-creation changes. Good for local augmentation.
Abstract base class
Express contracts for subclasses; integrates with static tools.
Metaclass
Class-creation-time enforcement and registration across many classes.
Concrete contrast
An ABC will prevent instantiation until abstract methods are implemented. A metaclass can prevent the class from existing at definition time.
Rule of thumb
Start with the simplest tool and move to metaclasses only when you need centralized, repeatable enforcement at class creation.
