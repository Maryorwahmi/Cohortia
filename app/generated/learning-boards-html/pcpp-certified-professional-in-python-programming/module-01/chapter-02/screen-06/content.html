Process Flow
Class creation lifecycle
1. Determine metaclass (explicit or inherited)
2. Call __prepare__ to create namespace mapping (optional)
3. Execute class body to populate namespace
4. Call metaclass.__new__(mcls, name, bases, namespace) to create the class
5. Call metaclass.__init__(cls, name, bases, namespace) to initialize the class
Example check
If a required method is missing, raise TypeError in __new__ so the class is never created.
Misconception
Don’t perform structural changes exclusively in __init__; __new__ is the correct place to shape the class object.
