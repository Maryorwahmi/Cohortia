Learning Objectives
Learn, Understand, Apply, Master
Bloom: Learn → Understand → Apply → Master
01
Define ABC contracts
Explain what an Abstract Base Class enforces and why a contract matters in larger codebases.
Mnemonic: plug socket—only approved plugs fit.
VERIFIED COMPETENCY MILESTONE
02
Implement ABCs with abc
Use abc.ABC, @abstractmethod, and abstract properties so subclasses must implement required members.
Mnemonic: mark methods as promises to implement.
VERIFIED COMPETENCY MILESTONE
03
Register virtual subclasses
Recognize and register classes as virtual subclasses so third-party types can be treated as implementing an interface.
Mnemonic: handshake without inheritance.
VERIFIED COMPETENCY MILESTONE
04
Use Protocols for structural typing
Define a Protocol to express required methods and let unrelated classes conform by shape, enabling static checks.
Mnemonic: duck typing with a checklist.
VERIFIED COMPETENCY MILESTONE
