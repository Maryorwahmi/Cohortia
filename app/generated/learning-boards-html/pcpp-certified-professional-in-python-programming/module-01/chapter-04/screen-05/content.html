Module 1 › Chapter 1.4 › DataSource ABC
Code example
import abc

class DataSource(abc.ABC):
  @abc.abstractmethod
  def read_data(self, path):
    """Reads data from the specified path."""
    pass

  @abc.abstractmethod
  def write_data(self, path, data):
    """Writes data to the specified path."""
    pass

  @property
  @abc.abstractmethod
  def is_connected(self):
    """Returns True if the data source is connected."""
    pass

class FileSource(DataSource):
  def read_data(self, path):
    print(f"Reading from file: {path}")
    return f"Data from {path}"

  def write_data(self, path, data):
    print(f"Writing '{data}' to file: {path}")

  @property
  def is_connected(self):
    return True
Explanation & notes
  • The abstract base prevents instantiation if required methods are missing. This catches errors early.
  • Abstract properties combine @property and @abstractmethod so attribute-style access remains consistent.
  • Concrete subclasses must match expected signatures; mismatches lead to the class remaining abstract or instantiation errors.
Common mistake

Forgetting to implement an abstract member or misspelling its name will leave the subclass abstract.

Key Takeaway

ABCs declare required behavior and force concrete classes to provide real implementations before use.
