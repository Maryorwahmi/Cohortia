Expected behaviors
  • SimpleFormatter.format_record returns a string like "INFO: User logged in @ 2023-...".
  • ConsoleSender.send_log prints a console prefix and the formatted message.
  • NetworkSender.send_log simulates sending by printing a network message with the formatted payload.
Misconception

Protocols that are runtime_checkable allow isinstance checks, but they do not add missing behavior. Implementations still must provide the required methods.
