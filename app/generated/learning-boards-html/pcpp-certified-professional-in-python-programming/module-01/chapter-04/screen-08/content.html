Module 1 › Chapter 1.4 › Readable Protocol
Protocol code
from typing import Protocol, runtime_checkable

@runtime_checkable
class Readable(Protocol):
  def read(self) -> str:
    ...

class FileReader:
  def read(self) -> str:
    return "Content from file."

class BadReader:
  def get_data(self) -> str:
    return "Wrong method name."

def process_readable(reader: Readable):
  print(reader.read())
Explanation
  • Readable is a Protocol declaring a read method. Any class with a matching method conforms by shape.
  • @runtime_checkable enables isinstance checks at runtime, but Protocols primarily help static type checkers.
  • A class that does not provide read will not conform and will be flagged by a type checker when used where Readable is expected.
Key Takeaway

Protocols make duck typing explicit and checkable, improving readability and tooling support without changing runtime inheritance.
