Example: Sized recognition
from collections.abc import Sized

class MyCustomCollection:
  def __init__(self, items):
    self._items = list(items)
  def __len__(self):
    return len(self._items)
  def __getitem__(self, index):
    return self._items[index]

print(isinstance(MyCustomCollection([1,2,3]), Sized))  # True
Notes and caution
  • Recognition can be implicit when an ABC inspects expected methods, or explicit via register().
  • Registration affects type checks, not object behavior. The object must implement required methods to behave correctly.
  • Use registration to document that a class should be accepted by APIs expecting the ABC.
Pro tip

Prefer implicit structural checks when available; register only when you need explicit isinstance behavior for readability or compatibility.
