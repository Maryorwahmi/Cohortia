Socket vs Inspector
Use this mental model to choose a strategy. Abstractions protect large systems by making expectations explicit.
ABCs — socket
Require explicit fit via inheritance. Fail fast when methods are missing.
Protocols — inspector
Accept objects that match required methods, without changing their base classes.
Duck typing
Flexible but lacks static guarantees; can be paired with Protocols for safety.
Concrete considerations
  • ABCs fit when you control the class hierarchy or build a framework that requires guaranteed implementations.
  • Protocols are best when you need to accept existing classes or you prefer static analysis without altering inheritance.
  • Misconception: a Protocol is a runtime replacement for ABCs. It is primarily a static tool unless decorated with runtime_checkable.
Key Takeaway

Choose ABCs for strict runtime enforcement. Use Protocols when you want behavior-based acceptance and static checking.
