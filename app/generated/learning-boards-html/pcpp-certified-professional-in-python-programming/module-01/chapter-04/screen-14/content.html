Module 1 › Chapter 1.4 › Key Concepts
Abstract Base Class
A class intended as a blueprint that prevents instantiation until required members are implemented.
Protocol
A typing construct describing required methods by shape; great for static checks and duck typing.
Virtual Subclass
Register an existing class with an ABC so isinstance and issubclass treat it as conforming without inheritance changes.
Takeaway
ABCs give runtime guarantees; Protocols give structural checks for tools and flexibility. Use both intentionally and pair them with tests and documentation.
