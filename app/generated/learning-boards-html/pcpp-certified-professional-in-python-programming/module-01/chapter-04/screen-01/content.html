Abstract Base Classes and Protocols
Formalize interfaces: enforce contracts or describe behavior for static checks.

Why this matters: as systems grow, implicit duck typing can let errors creep in. ABCs give runtime enforcement; Protocols give readable, checkable behavior without inheritance.

You'll see code examples, a live-style walkthrough, and a hands-on starter for a logging interface that practices both approaches.
