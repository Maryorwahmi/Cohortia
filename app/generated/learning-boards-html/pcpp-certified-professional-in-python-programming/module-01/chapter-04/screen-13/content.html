Module 1 › Chapter 1.4 › Best Practices
Rules of thumb
  • Prefer ABCs for frameworks and controlled hierarchies that need runtime enforcement.
  • Prefer Protocols for libraries, public APIs, and when static checking helps collaborators.
  • Document virtual registrations and write tests to validate behavior, not just type checks.
Pitfalls to avoid
Over-registering classes
Registration without testing can hide missing behavior. Register only with tests in place.
Using runtime_checkable everywhere
This blurs the line between static and runtime checks; enable it only when needed for dynamic inspections.
Key Takeaway

Be intentional. Use ABCs for enforcement, Protocols for flexibility, document choices, and cover both with tests.
