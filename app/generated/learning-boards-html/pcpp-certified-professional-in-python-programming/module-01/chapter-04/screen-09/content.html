Module 1 › Chapter 1.4 › Nominal vs Structural
Side-by-side
ABCs (Nominal)
Require inheritance; enforce at runtime; good for frameworks and strict APIs.
Protocols (Structural)
Accept any object by shape; good for libraries and static checks; flexible with third-party code.
Misconception
Protocols replace testing. They do not — they complement static checks but cannot validate runtime side effects or resource behavior.
Decision checklist
  • Do you control the type hierarchy? Prefer ABCs for enforcement.
  • Do you need to accept many existing types? Prefer Protocols for flexibility.
  • Do static tools matter in your workflow? Protocols improve static analysis results.
Key Takeaway

Match the tool to your goals: control and runtime enforcement or flexible, checkable behavior.
