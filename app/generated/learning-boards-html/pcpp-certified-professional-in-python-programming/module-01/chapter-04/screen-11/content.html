Solution sketch
class SimpleFormatter(LogFormatter):
  def format_record(self, record: dict) -> str:
    return f"{record['level']}: {record['message']} @ {record['timestamp']}"

class ConsoleSender:
  def send_log(self, formatted_message: str):
    print(f"Console: {formatted_message}")

class NetworkSender:
  def send_log(self, formatted_message: str):
    print(f"Network: Sending '{formatted_message}' over network.")
Why this design works
  • Formatters produce a single string output so senders have a stable input contract.
  • Senders implement a single responsibility: transmit the formatted message by their chosen transport.
  • Using an ABC for formatters enforces that formatting exists. Using a Protocol for senders allows flexible acceptance of varied transports.
