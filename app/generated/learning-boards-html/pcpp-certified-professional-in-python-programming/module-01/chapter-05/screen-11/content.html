register_class decorator (from chapter)
def register_class(registry):
    def decorator(cls):
        registry[cls.__name__] = cls
        print(f"Registered class: {cls.__name__}")
        return cls
    return decorator

my_registry = {}

@register_class(my_registry)
class MyComponent:
    def __init__(self, name):
        self.name = name

@register_class(my_registry)
class AnotherComponent:
    def __init__(self, id):
        self.id = id

print(my_registry)
The registry now holds class objects keyed by name, which a factory can consult to construct instances dynamically.
When to use
Plugin systems, component registries, or reducing repetitive registration code.
Caveat
Decorators run at import time. Be aware of import order and side-effects during module initialization.
Integration idea
Combine decorators with factories so new classes register automatically and factories consult the registry.
Key Takeaway

Class decorators are a clean way to attach registration or metadata logic at class creation time; use them when they reduce repetition.
