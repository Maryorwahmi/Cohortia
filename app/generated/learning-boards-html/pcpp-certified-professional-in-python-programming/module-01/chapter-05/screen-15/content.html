Module 1 › Chapter 1.5 › Key Concepts
Strategy Pattern
Encapsulates algorithms so you can swap them without changing the client.
Mixin
A focused class that provides a capability to other classes via multiple inheritance.
Class Decorator
A function that receives and returns a class object, useful for registration or augmentation at import time.
Final takeaway
Name your design choices and prefer explicit, testable structures. Use patterns when they clarify intent and reduce duplication.
