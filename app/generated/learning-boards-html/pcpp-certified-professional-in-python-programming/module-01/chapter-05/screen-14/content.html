Design Pattern
A reusable solution to a commonly occurring design problem in software.
Singleton Pattern
Ensures a class has only one instance and provides a global point of access, often via a metaclass.
Factory Pattern
Provides an interface for creating objects and decouples clients from concrete classes.
Takeaway
Use patterns to clarify intent. Prefer explicit, testable solutions in Python unless a pattern adds clear value.
