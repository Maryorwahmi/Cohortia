DocumentFactory (from chapter)
class Document:
    def __init__(self, content):
        self.content = content
    def render(self):
        raise NotImplementedError

class PDFDocument(Document):
    def render(self):
        return f"Rendering PDF: {self.content}"

class HTMLDocument(Document):
    def render(self):
        return f"Rendering HTML: <html><body>{self.content}</body></html>"

class DocumentFactory:
    def create_document(self, doc_type, content):
        if doc_type == "pdf":
            return PDFDocument(content)
        elif doc_type == "html":
            return HTMLDocument(content)
        else:
            raise ValueError("Unknown document type")
Extensibility
Add new document types by registering them with the factory rather than changing callers across the codebase.
Avoid bloat
Keep each factory focused. If creation logic becomes complex, consider a registration approach or a small registry helper.
Integration idea
Combine class decorators to register new document classes with the factory automatically for cleaner extensions.
Key Takeaway

Use factories to hide construction details from callers, and keep factories cohesive to avoid becoming monoliths.
