TypeValidator code
This data descriptor enforces a type and stores the value on the instance.
class TypeValidator:
    def __init__(self, expected_type):
        self.expected_type = expected_type
        self._value = None  # avoid storing here

    def __set_name__(self, owner, name):
        self.public_name = name
        self.private_name = '_' + name

    def __get__(self, instance, owner):
        if instance is None:
            return self
        if not hasattr(instance, self.private_name):
            raise AttributeError(f"'{self.public_name}' has not been set.")
        return getattr(instance, self.private_name)

    def __set__(self, instance, value):
        if not isinstance(value, self.expected_type):
            raise TypeError(f"Expected {self.public_name} to be of type {self.expected_type.__name__}")
        setattr(instance, self.private_name, value)
Concrete scenario
User class with name = TypeValidator(str) and age = TypeValidator(int). Invalid assignment raises TypeError immediately.
Common mistake
Storing the value on the descriptor instance makes the value shared across all objects. Always store per-instance state in the instance.
Example usage
user = User('Alice', 30) triggers __set__ for name and age; accessing user.name triggers __get__ and returns the stored private attribute.
Key Takeaway
Link descriptor configuration (expected type) to per-instance storage via private names constructed in __set_name__.
