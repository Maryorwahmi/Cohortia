Module 1 › Chapter 1.3 › What is a descriptor?
Descriptor Protocol
Implement one or more of: __get__(self, instance, owner), __set__(self, instance, value), __delete__(self, instance).
Definition card
A descriptor is a reusable object that defines how an attribute behaves when accessed, assigned or deleted.
Common misconception
Storing values on the descriptor itself makes that value shared across all instances; instead store per-instance data on instance.__dict__ under a private name.
Concrete example
property is a descriptor that uses __get__ and __set__ to present methods as attributes, enabling validation or computed values while preserving attribute syntax.
Key Takeaway

Descriptors let you encapsulate attribute behavior and reuse it across classes while avoiding shared instance state by storing values on the instance.

Protocol Methods
  • __get__(self, instance, owner)
  • __set__(self, instance, value)
  • __delete__(self, instance)
Quick check
If instance is None inside __get__, the descriptor is being accessed on the class and should probably return itself.
