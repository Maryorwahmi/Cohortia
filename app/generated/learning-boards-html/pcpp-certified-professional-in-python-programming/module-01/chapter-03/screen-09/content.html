cached_property starter
Non-data descriptor: compute once, store result on the instance.
class cached_property:
    def __init__(self, func):
        self.func = func
        self.name = None

    def __set_name__(self, owner, name):
        self.name = name

    def __get__(self, instance, owner):
        if instance is None:
            return self
        if self.name not in instance.__dict__:
            value = self.func(instance)
            instance.__dict__[self.name] = value
        return instance.__dict__[self.name]
Concrete example
ReportGenerator.expensive_report prints when computed once and then returns cached string on later reads.
Misconception
Caching inside the descriptor instance shares the cached value across all instances. Always write cache into the instance.__dict__.
Behavior note
After caching, the descriptor is effectively bypassed for that instance; the instance attribute now holds the computed value.
Key Takeaway
Use cached_property for expensive, immutable-after-first-compute values and store cache on the instance to avoid sharing state.
