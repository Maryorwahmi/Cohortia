Module 1 › Chapter 1.3 › Key Concepts
Descriptor Protocol
__get__, __set__, __delete__ let objects intercept attribute operations.
Data vs Non-Data
Data descriptors (with __set__) beat instance dict; non-data descriptors can be shadowed by instance attributes.
__set_name__
Use it at class creation to compute private storage keys and avoid collisions.
Summary takeaway
Implement descriptors as configuration objects and put per-instance state in the instance. Test class and instance access paths to verify behavior.
