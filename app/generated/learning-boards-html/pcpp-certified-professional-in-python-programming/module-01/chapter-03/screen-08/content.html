Module 1 › Chapter 1.3 › Built-in descriptors
property, staticmethod, classmethod
Map these built-ins to descriptor types and binding behavior.
property (data descriptor)
Provides __get__ and typically __set__, enabling computed attributes with validation and controlled assignment.
staticmethod (non-data)
Returns the underlying function unchanged; it does not bind instance or class as the first argument.
classmethod (non-data)
Returns a function bound to the class, so the first parameter is the class object.
Practical note
Because staticmethod and classmethod are non-data descriptors, assigning an attribute on an instance can hide them on that instance only.
Analogy
Think of property as a gatekeeper with locks for reads and writes; staticmethod and classmethod are signposts that change how a function is presented but can be covered by instance signs.
Key Takeaway
Recognize which built-ins implement data semantics and which do not to predict when instance assignments can shadow behavior.
