Attribute Lookup Process
A short numbered flow clarifies the order Python follows when resolving attributes.
1. Instance dictionary
If the attribute is found in instance.__dict__ and there is no data descriptor, Python returns that value immediately.
2. Class descriptors
If a data descriptor exists on the class, it takes precedence and its __get__ or __set__ will run instead of reading instance.__dict__.
3. Non-data descriptors
Non-data descriptors implementing only __get__ are lower priority; an instance attribute will override them.
4. Class attributes fallback
If none of the above apply, Python returns the raw value found on the class dictionary or raises AttributeError.
Common mistake
Expecting a non-data descriptor to block instance-level assignment. It does not; setting an attribute on the instance will overshadow a non-data descriptor.
Pro tip
When you need strict control over assignment and reads, implement __set__ to make your descriptor a data descriptor so it always wins.
