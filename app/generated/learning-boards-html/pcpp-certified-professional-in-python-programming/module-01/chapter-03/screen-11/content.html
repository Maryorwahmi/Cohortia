Test checklist
Simple tests to assert descriptor contracts and catch common errors.
Class access test
Assert that Owner.attr returns the descriptor when accessed on the class (instance is None).
Instance assignment test
Assign valid and invalid values and assert correct storage or raised exceptions.
Cache test
Access cached_property multiple times and assert the expensive computation runs only once.
Cross-instance isolation
Set different values on two instances and ensure they do not interfere.
Key Takeaway

Unit tests that cover class access, instance writes, and cross-instance interactions prevent descriptor bugs from remaining hidden.

Pitfall
Storing state on the descriptor instance is the most frequent source of surprise; tests should expose shared-state bugs quickly.
Reflection
Which descriptor behaviors will your unit tests assert for every descriptor you write?
