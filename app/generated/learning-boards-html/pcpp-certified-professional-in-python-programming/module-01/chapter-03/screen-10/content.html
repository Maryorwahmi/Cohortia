HashedPassword descriptor
A data descriptor that enforces write-only semantics while hashing on assignment.
import hashlib

class HashedPassword:
    def __init__(self):
        self.private_name = None

    def __set_name__(self, owner, name):
        self.public_name = name
        self.private_name = '_' + name

    def __set__(self, instance, raw_password):
        hashed = hashlib.sha256(raw_password.encode()).hexdigest()
        setattr(instance, self.private_name, hashed)

    def __get__(self, instance, owner):
        if instance is None:
            return self
        raise AttributeError(f"'{self.public_name}' is not directly readable.")
Use case
Store hashed passwords safely and allow check_password methods to compare hashes directly from the private instance attribute.
Warning
Do not expose the hash via __get__ and do not store hashes on descriptor instances to avoid leaking across accounts.
Checklist
  • Use __set_name__ for private storage key
  • Hash on __set__ and store on instance
  • Raise AttributeError on __get__ to prevent reads
Key Takeaway
Descriptor-based write-only fields let your class enforce security policies cleanly and consistently at assignment time.
