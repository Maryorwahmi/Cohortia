Module 2 › Chapter 1.6 › Fibonacci generator
Generator code
def fibonacci_generator(limit):
  a, b = 0, 1
  while a < limit:
    yield a
    a, b = b, a + b

# Usage
fib_gen = fibonacci_generator(10)
print(list(fib_gen))  # [0, 1, 1, 2, 3, 5, 8]
print(list(fib_gen))  # [] generator is exhausted
Why use generators?
  • They produce values on demand and don't allocate full sequences in memory.
  • Generators are simpler to write than full iterator classes for many use cases.
  • They make streaming data processing and pipelines efficient and composable.
Misconception
Treating generators like reusable lists. Always recreate the generator for a new traversal or collect values into a sequence if reuse is required.
Key Takeaway

Use generators for large or streaming data to reduce memory usage; remember generators are single-use and must be recreated for repeated passes.
