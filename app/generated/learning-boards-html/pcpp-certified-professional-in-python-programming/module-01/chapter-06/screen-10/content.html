safe_file_reader code
from contextlib import contextmanager

@contextmanager
def safe_file_reader(filepath):
  f = None
  try:
    f = open(filepath, 'r')
    print(f"Opened file: {filepath}")
    yield f
  finally:
    if f:
      f.close()
      print(f"Closed file: {filepath}")
Explanation
The generator yields the resource and the finally block runs after the with block completes, ensuring cleanup regardless of exceptions.
Pitfall
Omitting the finally block will leak resources when an error occurs. Always place cleanup in finally.
Key Takeaway

Use contextlib.contextmanager for concise resource management; ensure cleanup is guaranteed via finally.
