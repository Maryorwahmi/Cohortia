Module 2 › Chapter 1.6 › Remember
Protect internals
Return copies or same-type objects for slices and avoid exposing mutable internal lists.
Pick iteration pattern
Generators for one-pass streaming; iterator classes for restartable traversals.
Guarantee cleanup
Use __exit__ or contextlib finally blocks so resources are always released, even on exceptions.
Try this

Write a small class that implements len, iterates twice correctly, and closes a resource in a with block to validate all three rules.
