Module 2 › Chapter 1.6 › Key Concepts
Data Model
Special methods define how objects behave with built-ins and operators.
Container Protocol
Implement len, getitem, setitem, delitem, and contains for sequence or mapping semantics.
Iterator Protocol
__iter__ and __next__ make objects iterable; decide on self versus new iterator based on reset needs.
Final takeaway

Design types that follow the data model, prefer clear semantics, protect internals, and test iteration and cleanup paths.
