Module 2 › Chapter 1.6 › Iterator vs Generator
Iterator class
  • Explicit state fields and methods.
  • Can return new iterator instances for multiple traversals.
  • Better when you need additional iterator-specific API.
Generator function
  • Concise and memory-efficient.
  • Single-use generator objects; recreate to iterate again.
  • Ideal for pipelines and streaming data.
Decision checklist
If you need restartable iterators or extra methods, prefer a class. If you need short, memory-light code for one-pass streaming, prefer a generator.
