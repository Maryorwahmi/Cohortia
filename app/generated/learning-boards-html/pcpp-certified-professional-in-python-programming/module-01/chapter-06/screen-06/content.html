Module 2 › Chapter 1.6 › MyRange iterator
MyRange code
class MyRange:
  def __init__(self, start, end):
    self.current = start
    self.end = end

  def __iter__(self):
    return self  # instance is its own iterator

  def __next__(self):
    if self.current < self.end:
      num = self.current
      self.current += 1
      return num
    raise StopIteration

# Usage: for i in MyRange(1,5): print(i)
Explanation
  • Returning self is simple but the instance keeps state and cannot be re-used for a second independent traversal.
  • To allow multiple traversals, __iter__ should return a new iterator that holds its own state, or return iter(self._items).
  • Always raise StopIteration when done; it's the signal that ends loops and list conversions.
Common mistake
Forgetting to reset internal state when __iter__ returns self. This leads to unexpected empty iterations on subsequent for-loops.
Key Takeaway

Decide whether your object should be its own iterator or return a fresh iterator to support multiple independent traversals.
