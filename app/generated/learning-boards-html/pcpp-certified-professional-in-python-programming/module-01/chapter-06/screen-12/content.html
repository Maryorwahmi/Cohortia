Module 2 › Chapter 1.6 › Design patterns
Sequence-like
Implement
  • __len__, __getitem__
  • __setitem__ and __delitem__ for mutability
  • __contains__ for membership
Iteration
Implement
  • __iter__ that returns a fresh iterator or iter(internal)
  • __next__ only for iterator objects
Context
Implement
  • __enter__ and __exit__ for resource control
  • contextlib for concise managers
Documentation and performance
Declare complexity guarantees for length, containment, and common operations. This sets clear expectations for users and informs design choices.
