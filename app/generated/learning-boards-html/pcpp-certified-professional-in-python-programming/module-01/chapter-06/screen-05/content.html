Module 2 › Chapter 1.6 › Container small methods
__len__
Should return an integer size quickly. Use cached lengths only if you maintain them correctly when mutating contents.
Common mistake
Computing length by scanning a generator every time can be costly and surprising to callers.
__contains__
Define membership semantics explicitly. Decide whether containment uses identity, value equality, or a key comparison.
Pro tip
Document containment semantics so users know how in behaves for your type.
__repr__ — informative debugging
Provide a short, machine-oriented representation that aids debugging. Include type and key attributes like name and count.
Example: Playlist('Rock Anthems', 3 songs)
