Frequent errors and defenses

Each mistake below pairs with a defensive practice you can adopt immediately.

eq/hash mismatch
Set __hash__ = None for mutable types; compute hash from immutable identity attributes for immutable types.
NotImplemented
Return NotImplemented for unsupported types in __eq__ to preserve symmetric comparison behavior.
Wrong exceptions
Raise IndexError for bad sequence indices and KeyError for missing mapping keys.
Checklist

Add unit tests for equality/hash consistency, slice support, negative indices, and expected exception types to catch regressions early.
