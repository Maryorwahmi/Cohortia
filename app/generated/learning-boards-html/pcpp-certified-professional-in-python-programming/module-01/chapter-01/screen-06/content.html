What to do in __eq__

Check type compatibility, compare the attributes that determine equality, and return NotImplemented for unsupported operand types.

def __eq__(self, other): if not isinstance(other, Vector): return NotImplemented return (self.x == other.x and self.y == other.y and self.z == other.z) # Behavior: if other is not a Vector, Python will attempt other.__eq__(self) or fall back to False
Concrete example
v1 == v2 True when components match; comparing with unrelated types should return NotImplemented to allow symmetric logic.
Misconception
Returning False for different types prevents the other operand's comparison path and can break symmetric equals with subclasses.
