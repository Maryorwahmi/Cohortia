Learning Objectives
Build correct, Pythonic dunder methods and container behavior.
Bloom: Learn → Understand → Apply → Master
01
Understand dunder purpose

Explain how dunder methods connect objects to built-in operations and why that integration matters for maintainability and debugging.

VERIFIED COMPETENCY MILESTONE
02
Implement repr & eq

Write __repr__ for unambiguous debugging and __eq__ that safely compares instances, returning NotImplemented for unsupported types.

VERIFIED COMPETENCY MILESTONE
03
Handle eq & hash

Ensure objects that compare equal produce equal hashes, or mark mutable objects as unhashable using __hash__ = None.

VERIFIED COMPETENCY MILESTONE
04
Implement container protocols

Support len, indexing, slicing, assignment, and deletion with correct exceptions and canonical behaviors for sequences and mappings.
