Walkthrough: Vector.__repr__
Aim for a constructor-style, unambiguous format including only the attributes that define identity.
class Vector:
  def __init__(self, x, y, z):
    self.x = x
    self.y = y
    self.z = z

  def __repr__(self):
    return f"Vector({self.x}, {self.y}, {self.z})"

# Usage
v = Vector(1, 2, 3)
print(repr(v))  # Vector(1, 2, 3)
Common mistake: including mutable caches or private large fields in repr. Instead, show the small set of attributes that are stable and relevant for debugging.
Quick Checks
  • Is the output concise and unambiguous?
  • Could a developer understand the object's identity from the repr?
  • Does the repr avoid exposing secrets or huge data?
Key Takeaway

Make repr reproducible and focused on the attributes that matter for debugging.
