Module 1 › Chapter 1.1 › Special Methods (Dunder Methods)
In this lesson
Implement readable representations, robust equality and hashing, and Pythonic container behavior.
Representation

Use __repr__ for precise, developer-friendly strings and __str__ for human-readable output.

Equality & Hashing

Ensure __eq__ and __hash__ stay consistent, or mark objects unhashable if they are mutable.

Protocols

Implement __len__, __getitem__, __setitem__, __delitem__ to mimic sequences and mappings.

Common Mistakes

Watch for wrong return types, failing to handle slices, and inconsistent hashes.
