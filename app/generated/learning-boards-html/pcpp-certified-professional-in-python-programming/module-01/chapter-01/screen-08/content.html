Protocol overview

Implement these methods to let users call len(), use indexing and slicing, and mutate your container with familiar syntax.

__len__
Return the non-negative integer count of items.
__getitem__
Accept int and slice for sequences; accept hashable keys for mappings. Raise IndexError or KeyError as appropriate.
__setitem__
Support assignments and slice assignments with consistent behavior.
__delitem__
Remove items by index or key; ensure correct exception types on invalid deletions.
Key Takeaway

Design your container semantics explicitly and follow built-in exception and slicing conventions for predictable behavior.
