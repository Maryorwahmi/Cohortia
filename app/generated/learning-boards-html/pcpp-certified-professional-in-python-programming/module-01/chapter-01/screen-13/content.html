12-minute live-coding plan

Follow these ordered steps to demonstrate dunder behaviors and their practical consequences.

  1. Live-code Vector with __repr__ and __str__; print outputs to show difference.
  2. Implement __eq__; compare separate instances with identical data.
  3. Remove __hash__ or leave it out and show TypeError when adding instances to a set or dict key.
  4. Add __hash__ computed from identity attributes and show correct set/dict behavior.
  5. Implement MyCustomList methods and run indexing, slicing, assignment, and deletion examples and assertions.
  6. End with reflection: when is __hash__ = None appropriate and how does immutability guide that decision?
Validation
Include quick asserts to check repr equality, set membership, len, and expected exceptions for invalid operations.
Reflection Prompt
Ask learners to consider trade-offs of hashability vs mutability for their own domain objects.
