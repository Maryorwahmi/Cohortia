Module 1 › Chapter 1.1 › MyCustomList: len & getitem
Starter implementation
class MyCustomList:
  def __init__(self, initial_data=None):
    self._data = list(initial_data) if initial_data is not None else []

  def __len__(self):
    return len(self._data)

  def __getitem__(self, key):
    if isinstance(key, int):
      if not (-len(self._data) <= key < len(self._data)):
        raise IndexError("Index out of range")
      return self._data[key]
    elif isinstance(key, slice):
      return MyCustomList(self._data[key])
    else:
      raise TypeError("Key must be an integer or slice")

Checks & Examples
Try:
my_list = MyCustomList([10,20,30,40]) len(my_list) # 4 my_list[2] # 30 my_list[-1] # 40 my_list[1:3] # MyCustomList([20,30])
Common Mistake

Returning a plain list for slices breaks the container interface. Return the same custom type for consistency.
