Calling C Functions from Cython

Wrapping C Library Functions with `cdef extern from`

# c_library_wrapper.pyx
# distutils: language=c

# Assume we have a C library 'my_c_lib.h' and 'my_c_lib.c'
# my_c_lib.h:
# int add_two_ints(int a, int b);
# void greet(const char* name);

cdef extern from "my_c_lib.h":
    int add_two_ints(int a, int b)
    void greet(const char* name) # Note: const char* maps to bytes in Python

def call_c_add(int x, int y):
    cdef int result = add_two_ints(x, y)
    return result

def call_c_greet(bytes name_bytes): # Python strings need to be encoded to bytes
    greet(name_bytes)

# setup.py
from setuptools import setup
from Cython.Build import cythonize

setup(
    ext_modules=cythonize(
        "c_library_wrapper.pyx",
        extra_compile_args=["-O3"], # Optional: C compiler optimizations
        extra_link_args=["my_c_lib.c"] # Link against the C source or compiled object
    )
)
C Function Declaration

The `cdef extern from` block declares C functions like `add_two_ints` and `greet` as they appear in the C header, making them callable from Cython.

Type Mapping: `const char*` to `bytes`

A critical detail is mapping C's `const char*` to Python's `bytes`. Python `str` objects must be explicitly encoded to `bytes` before being passed to C functions expecting `const char*`.

Key Takeaway

Successful C library integration requires precise C function declarations in Cython and correct linking in `setup.py`, along with careful Python-to-C type conversions.
