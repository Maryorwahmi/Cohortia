Practical `asyncio`: Concurrent URL Fetching

A practical example of `asyncio` in action.

Synchronous Approach

Fetches URLs one by one. Each request blocks the program until its response is fully received. Total time is the sum of all individual request times.

Asynchronous Approach

Initiates multiple URL fetches concurrently. While one request waits for a response, the event loop handles other requests. Total time is closer to the longest individual request.

Scenario

Imagine building a web scraper that needs to visit hundreds of pages. Synchronous fetching would be prohibitively slow.

The Concurrent Advantage

Instead of sequential waits, tasks overlap, drastically cutting total execution time.

Key Takeaway

`asyncio` allows multiple I/O operations to run concurrently, reducing overall execution time for I/O-bound tasks.
