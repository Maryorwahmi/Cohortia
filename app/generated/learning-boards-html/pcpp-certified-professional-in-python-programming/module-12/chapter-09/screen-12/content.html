Simple uvloop Integration

Boosting performance with minimal code changes.

`uvloop` Integration Example
import asyncio
import aiohttp
import time
import uvloop # Import uvloop

# (fetch_url function remains the same as before)

async def main_uvloop():
    urls = [
        "http://httpbin.org/delay/3",
        "http://httpbin.org/delay/1",
        "http://httpbin.org/delay/2",
        "http://httpbin.org/delay/4",
    ]
    
    start_total = time.time()
    async with aiohttp.ClientSession() as session:
        tasks = [fetch_url(session, url) for url in urls]
        results = await asyncio.gather(*tasks)
    
    print(f"
All fetches completed in {time.time() - start_total:.2f} seconds.")
    for result in results:
        print(result)

if __name__ == "__main__":
    print("--- Running with standard asyncio ---")
    asyncio.run(main_asyncio()) # Run standard version first

    print("
--- Running with uvloop ---")
    uvloop.install() # Install uvloop as default event loop
    asyncio.run(main_uvloop()) # Now uses uvloop

Installation

First, install `uvloop` using pip: `pip install uvloop`. It's a simple package to add to your project dependencies.

`uvloop.install()`

Call `uvloop.install()` once at the start of your application. This sets `uvloop` as the default event loop policy for all subsequent `asyncio` operations.

Key Takeaway

`uvloop` can be integrated with a single `uvloop.install()` call, providing a transparent performance boost to `asyncio` applications.
