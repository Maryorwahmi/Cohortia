Building an Asynchronous Fetcher

Examining the fetch_url coroutine.

`fetch_url` Coroutine
import asyncio
import aiohttp
import time

async def fetch_url(session, url):
    # Simulate network delay and fetch
    start_time = time.time()
    print(f"[{time.time() - start_time:.2f}s] Starting fetch for {url}")
    try:
        async with session.get(url) as response:
            await response.text() # Await I/O, yield control
            print(f"[{time.time() - start_time:.2f}s] Finished fetch for {url}")
            return f"Successfully fetched {url}"
    except Exception as e:
        print(f"[{time.time() - start_time:.2f}s] Error fetching {url}: {e}")
        return f"Failed to fetch {url}"

`async def`

Declares `fetch_url` as a coroutine, meaning it can be paused and resumed by the event loop.

`async with` & `await`

`async with` manages asynchronous resources. `await response.text()` pauses `fetch_url` while waiting for the network response, freeing the event loop.

Key Takeaway

The `fetch_url` coroutine demonstrates how `async def` and `await` enable non-blocking I/O operations, yielding control during network waits.
