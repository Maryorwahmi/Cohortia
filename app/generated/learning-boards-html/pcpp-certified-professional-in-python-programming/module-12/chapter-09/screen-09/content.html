Orchestrating Tasks with asyncio.gather

Running multiple coroutines concurrently.

`main_asyncio` Function
async def main_asyncio():
    urls = [
        "http://httpbin.org/delay/3",
        "http://httpbin.org/delay/1",
        "http://httpbin.org/delay/2",
        "http://httpbin.org/delay/4",
    ]
    
    start_total = time.time()
    async with aiohttp.ClientSession() as session:
        tasks = [fetch_url(session, url) for url in urls]
        results = await asyncio.gather(*tasks) # Run concurrently
    
    print(f"
All fetches completed in {time.time() - start_total:.2f} seconds.")
    for result in results:
        print(result)

if __name__ == "__main__":
    print("--- Running with standard asyncio ---")
    asyncio.run(main_asyncio())

`asyncio.gather`

Takes multiple awaitable objects (coroutines) and schedules them to run concurrently. It waits until all of them are complete.

Key Takeaway

`asyncio.gather` is essential for running multiple coroutines in parallel, significantly reducing the total execution time for I/O-bound tasks.
