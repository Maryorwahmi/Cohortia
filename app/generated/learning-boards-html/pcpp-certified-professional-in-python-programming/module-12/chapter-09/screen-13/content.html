Key Concepts

Essential terms from this chapter.

`asyncio`

Python's standard library for writing concurrent code using asynchronous I/O and cooperative multitasking.

Event Loop

The central component of `asyncio` that manages and schedules coroutines, deciding which one to run next.

`async`/`await`

Keywords used to define coroutines (`async def`) and to explicitly yield control to the event loop (`await`).

Chapter Summary

`asyncio` provides the framework for cooperative multitasking, with the Event Loop orchestrating tasks defined by `async` and managed by `await`.
