Orchestrating Concurrency with async/await

Defining coroutines and yielding control to the event loop.

The `async` Keyword

Used with `def` to define a coroutine: a function that can be paused and resumed. It signals that the function can run asynchronously.

The `await` Keyword

Used inside an `async` function before an `awaitable` object (like another coroutine). It pauses the current coroutine and yields control to the event loop.

Analogy

`async` declares a task that can take breaks; `await` is the explicit instruction to take a break and let others work.

Python Coroutine Example
import asyncio

async def my_coroutine():
    # This task will pause here
    await asyncio.sleep(1) # Yields control for 1 second
    print("Coroutine finished!")

async def main():
    print("Starting main...")
    await my_coroutine() # Pause main, run my_coroutine
    print("Main finished.")

if __name__ == "__main__":
    asyncio.run(main())
Key Takeaway

`async` defines a pausable function (coroutine), and `await` is used to pause execution, allowing the event loop to run other tasks.
