Optimization Strategy

Focusing Your Optimization: tottime vs cumtime

Avoiding common profiling mistakes

Common Mistake: Solely focusing on cumtime can lead to optimizing the wrong functions. High cumtime doesn't always mean the function itself is slow.

Target tottime: Functions with high tottime are the primary candidates for direct optimization, as their internal code is the bottleneck.

Dig Deeper for cumtime: If a function has high cumtime but low tottime, investigate its callees (the functions it calls) to find the actual slowdowns.

Key Takeaway

Always prioritize optimizing functions with high tottime first, as these are the direct sources of inefficiency in your code.

Optimization Focus
High tottime

Function's own code is slow. Directly optimize here.

High cumtime, Low tottime

Function calls other slow functions. Investigate its callees.
