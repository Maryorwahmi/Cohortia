Using line_profiler: Decorators and kernprof.py

Instrumenting functions for line-by-line analysis

Installation: First, install the library using pip install line_profiler.

@profile Decorator: Mark functions you want to profile line-by-line with @profile. This decorator is dynamically added by kernprof.py.

kernprof.py: Run your script using this utility (e.g., kernprof -l -v your_script.py) to activate line profiling and view verbose output.

Key Takeaway

The @profile decorator combined with kernprof -l -v provides a precise way to get line-level performance statistics for specific functions.

# my_script.py
import time

@profile
def my_slow_function():
    total = 0
    for i in range(1000000):
        total += i * 2  # Line 1: Potentially slow
    time.sleep(0.01)    # Line 2: Simulate I/O
    return total

def main():
    my_slow_function()

if __name__ == "__main__":
    main()
To profile my_slow_function, ensure the @profile decorator is present, then run from your terminal: kernprof -l -v my_script.py.
