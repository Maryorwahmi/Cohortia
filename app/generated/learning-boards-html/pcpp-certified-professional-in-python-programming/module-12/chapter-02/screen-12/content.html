Interpreting line_profiler Output

Understanding line-by-line performance statistics

Line #: The line number in the source file, for easy code navigation.

Hits: How many times the line was executed, indicating loop activity.

Time: Total time spent on that line (in timer units, often microseconds).

% Time: Percentage of total function time spent on this line. This is your primary bottleneck indicator.

Key Takeaway

The % Time column in line_profiler output directly shows which lines are the biggest performance culprits, guiding precise optimization.

# line_profiler Output Example
Line #      Hits         Time  Per Hit   % Time  Line Contents
==============================================================
     5                                           @profile
     6     1         10.0      10.0      0.0   def my_slow_function():
     7     1          1.0       1.0      0.0       total = 0
     8 1000001    100000.0       0.1     99.0       for i in range(1000000):
     9 1000000    990000.0       0.9     98.0           total += i * 2
    10     1          1.0       1.0      0.0       time.sleep(0.01)
    11     1          1.0       1.0      0.0       return total
Line 9, total += i * 2, consumes 98% of the function's time, clearly indicating it as the primary bottleneck.
