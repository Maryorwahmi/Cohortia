Key Concepts

Essential terms and ideas from this chapter

Deterministic Profiling

A profiling method that precisely records every function call and its timing, providing a complete and accurate call graph.

cProfile

Python's built-in C-implemented deterministic profiler, used for high-level function-by-function performance analysis.

tottime

The total time spent executing a function's own code, *excluding* time spent in functions it calls. Crucial for identifying self-contained bottlenecks.

Chapter Summary

Profiling provides empirical data to pinpoint performance issues. cProfile offers high-level function analysis, with tottime being key for identifying direct optimization targets.
