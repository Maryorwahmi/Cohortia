Practical Usage

Running cProfile from the Command Line

Generating profiling data for analysis

No Code Changes: Profile entire scripts without modifying their source, ideal for quick checks or existing projects.

Output to File: The -o flag saves profiling results to a binary .prof file for later, detailed analysis.

Analysis Tools: These .prof files can be processed by pstats or visualized with third-party tools like snakeviz.

Key Takeaway

Using python -m cProfile -o <file.prof> <script.py> is the standard way to generate comprehensive profiling data from the command line.

# Command Line Example
python -m cProfile -o profile_output.prof your_script.py
This command executes your_script.py under cProfile, saving all performance data to profile_output.prof.
# Analyzing with pstats
python -m pstats profile_output.prof
Once in the pstats interactive prompt, you can use commands like sort cumtime or stats 10 to analyze the data.
