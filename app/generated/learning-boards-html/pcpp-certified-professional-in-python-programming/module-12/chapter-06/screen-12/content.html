Optimizing with Cython: Sum of Squares

Introducing type declarations for significant speedup.

Key Optimizations

  • `cdef int i`: Declares loop counter as a C integer.
  • `cdef long long total`: Declares accumulator as a C long long to prevent overflow and optimize arithmetic.
  • `distutils: language=c`: Directive for Cython to generate C code.
  • Bypasses Python's dynamic type checking and object overhead.
Key Takeaway

By adding `cdef` type declarations, Cython generates highly efficient C code for performance-critical sections, leading to substantial speed improvements over pure Python.

sum_squares_cy.pyx
# distutils: language=c
def sum_squares_cython(int n):
    cdef int i
    cdef long long total = 0  # Use long long for larger sums
    for i in range(n):
        total += i * i
    return total

# Notice the 'int n' in the function signature
# and 'cdef' for local variables 'i' and 'total'.

Spot the Difference

Compare this code to the pure Python version. The `cdef` keywords and explicit type declarations are the critical changes that enable Cython's optimization.
