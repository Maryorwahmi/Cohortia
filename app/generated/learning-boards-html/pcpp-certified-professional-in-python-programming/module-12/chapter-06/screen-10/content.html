Applying Static Typing

Declaring Types for Performance Gains

Using `cdef` for variables, arguments, and return types.

Where to Apply `cdef`

  • **Local Variables:** Inside functions, e.g., `cdef int i`.
  • **Function Arguments:** In function signatures, e.g., `(cdef int n)`.
  • **Return Types:** Before function name, e.g., `cdef long long my_func(...)`.
  • **Performance-critical loops:** Especially where many arithmetic operations occur.
Key Takeaway

Explicit `cdef` type declarations are the primary mechanism in Cython to enable C-level optimizations, drastically reducing Python object overhead in critical code sections.

optimized_loop.pyx
# distutils: language=c
cpdef long long sum_up_to_n(int n):
    # Declare 'i' as a C integer
    cdef int i
    # Declare 'total' as a C long long to prevent overflow
    cdef long long total = 0
    
    # Loop uses C integer arithmetic
    for i in range(n):
        total += i
    return total

Impact of Typing

By declaring `i` and `total` as C types, Cython generates machine code that performs arithmetic directly, avoiding Python object creation and reference counting for each iteration.
