Benchmarking Performance: Python vs. Cython

Observing the speedup of Cython-optimized code.

Performance Comparison

  • **Pure Python:** Dynamic typing, object overhead, slower execution.
  • **Cython:** Static typing, C compilation, native execution, significantly faster.
  • Expected speedup: Often 10x or more for CPU-bound tasks.
  • Crucial for identifying real-world performance benefits.
Key Takeaway

Benchmarking clearly demonstrates that Cython-optimized code can achieve substantial speedups over pure Python, validating the benefits of static typing and C compilation.

benchmark.py
import time
from sum_squares import sum_squares_python
from sum_squares_cy import sum_squares_cython

N = 100_000_000

start_time = time.perf_counter()
py_result = sum_squares_python(N)
end_time = time.perf_counter()
print(f"Python result: {py_result}, took: {end_time - start_time:.4f} seconds")

start_time = time.perf_counter()
cy_result = sum_squares_cython(N)
end_time = time.perf_counter()
print(f"Cython result: {cy_result}, took: {end_time - start_time:.4f} seconds")

assert py_result == cy_result

Expected Outcome

You will observe a significant speedup with the Cython version, often by 10x or more, demonstrating the effectiveness of C-level optimization.
