Cython Function Declarations

`cpdef`: Bridging Python and C Calls

Balancing performance with accessibility from Python.

Characteristics of `cpdef`

  • Implemented as a C function.
  • Exposes a Python wrapper, making it callable from Python.
  • Callable directly as a C function from other Cython code.
  • Offers a good balance of performance and accessibility.
Key Takeaway

`cpdef` functions are ideal for performance-critical routines that also need to be part of a Cython module's public API, offering both C speed and Python accessibility.

example.pyx
# A hybrid function callable from both Python and Cython
cpdef long long sum_squares_hybrid(int n):
    cdef int i
    cdef long long total = 0
    for i in range(n):
        total += i * i
    return total

# Callable from Python:
import example
print(example.sum_squares_hybrid(1000000))

# Callable from Cython (e.g., another cpdef/cdef function):
cdef void _internal_call():
    sum_squares_hybrid(100)

Use Case

When you need a function to be fast internally but also easily accessible and usable by external Python scripts or users.
