Cython Function Declarations

`cdef`: Maximum C Performance

Functions optimized for internal Cython-to-Cython calls.

Characteristics of `cdef`

  • Declares a pure C function.
  • Not directly callable from Python.
  • Only callable from other `cdef` functions or within the Cython module.
  • Offers the highest possible performance by bypassing Python overhead.
Key Takeaway

`cdef` functions are for internal, performance-critical operations within Cython modules, providing C-level speed without Python interaction.

example.pyx
# A C-level helper function
cdef int _fast_multiply(int a, int b):
    return a * b

# A 'def' function that calls the 'cdef' function
def process_data(list data):
    cdef int total = 0
    cdef int item
    for item in data:
        total += _fast_multiply(item, 2) # Call to cdef function
    return total

When to Use `cdef`

Ideal for internal, performance-critical helper functions that do not need to be exposed directly to the Python runtime.
