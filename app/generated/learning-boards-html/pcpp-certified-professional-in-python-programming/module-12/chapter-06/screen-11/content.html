Baseline: Sum of Squares in Pure Python

Understanding the performance of a simple Python loop.

Python's Overhead

  • Variables are dynamically typed.
  • Each arithmetic operation involves Python object creation.
  • Runtime type checking adds significant overhead in tight loops.
  • Reference counting for objects consumes CPU cycles.
Key Takeaway

Pure Python code, especially in tight loops with many arithmetic operations, can be slow due to dynamic typing and object management overhead.

sum_squares.py
def sum_squares_python(n):
    total = 0
    for i in range(n):
        total += i * i
    return total

# Example usage:
N = 10000000
result = sum_squares_python(N)
print(f"Sum of squares up to {N}: {result}")

Performance Insight

For large values of `N`, this pure Python function will demonstrate noticeable execution time, serving as a clear benchmark for Cython's optimization.
