Cython Function Types and Workflow

Recapping declaration types and the compilation process.

`cpdef`

A hybrid function type implemented in C but also exposing a Python wrapper, making it callable from both Python and Cython code.

`def`

In Cython, these are standard Python functions, callable from Python. Their internal operations can be optimized if variables are statically typed.

C Extension Module

The compiled output of Cython code (e.g., `.so`, `.pyd`), which can be imported and used directly within Python like any other module, built via `setup.py`.

Summary Insight

Cython's `cpdef` and `def` keywords provide flexible function interfaces, while the `setup.py` script orchestrates the compilation into native C extension modules for Python integration.
