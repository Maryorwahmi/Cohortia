Cython Function Declarations

`def`: Python's Familiar Interface

Standard functions with potential for internal optimization.

Characteristics of `def`

  • Standard Python function signature.
  • Directly callable from Python.
  • Maintains Python's dynamic behavior.
  • Internal operations can be optimized with `cdef` variables.
Key Takeaway

`def` functions in Cython provide Python compatibility, allowing for internal C-level optimizations without changing the external Python interface.

example.pyx
# This is a standard Python function in Cython
def calculate_sum(n):
    # 'cdef int i' allows C-level loop optimization
    cdef int i
    cdef long long total = 0
    for i in range(n):
        total += i
    return total

# Callable from Python:
import example
print(example.calculate_sum(1000000))

Pro Tip

Use `def` for functions that need to be exposed to Python, and then optimize their internal logic with `cdef` variables where performance is critical.
