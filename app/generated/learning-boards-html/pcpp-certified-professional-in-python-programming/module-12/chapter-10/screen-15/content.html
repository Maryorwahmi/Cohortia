@jit (Object Mode)

Numba decorator that attempts nopython compilation but falls back to 'object mode' if it fails, allowing some Python object interactions but with less performance gain.

PyPy

An alternative, high-performance implementation of the Python language that includes its own JIT compiler, designed to accelerate general Python code.

CPython

The standard, reference implementation of the Python language, which is an interpreter. It is widely used but can be slower for CPU-bound tasks due to the GIL.

Chapter Summary

While Numba's `@jit` offers flexibility, PyPy provides a whole-application JIT as an alternative interpreter. Both aim to overcome CPython's performance limitations for CPU-bound tasks, but with different approaches and compatibility considerations.
