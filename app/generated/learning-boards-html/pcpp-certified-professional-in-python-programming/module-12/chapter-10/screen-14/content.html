JIT Compilation

A method of compiling code into machine code during runtime, just before execution, to improve performance by optimizing 'hot spots'.

Numba

A specialized JIT compiler for Python that translates numerical functions (especially those using NumPy) into optimized machine code using LLVM.

@njit (No-Python JIT)

Numba decorator that compiles a function into highly optimized machine code that runs completely without the Python interpreter, yielding maximum performance.

Chapter Summary

JIT compilation bridges the performance gap for interpreted languages. Numba is a powerful library for accelerating numerical Python code, with `@njit` being the key to achieving C-like speeds by bypassing the CPython interpreter.
