import numpy as np
from numba import guvectorize, float64

# Example of guvectorize for a custom ufunc
# Signature: (float64[:],) -> (float64[:]) means input is 1D float array, output is 1D float array
@guvectorize([(float64[:], float64[:])], '(n)->(n)')
def apply_threshold_guvectorize(input_array, output_array):
    threshold = 0.5
    for i in range(input_array.shape[0]):
        output_array[i] = input_array[i] if input_array[i] > threshold else 0.0

if __name__ == "__main__":
    input_data = np.array([0.1, 0.6, 0.3, 0.8, 0.2], dtype=np.float64)
    output_data = np.zeros_like(input_data)
    
    apply_threshold_guvectorize(input_data, output_data)
    print(f"Original array: {input_data}")
    print(f"Thresholded array (guvectorize): {output_data}")
Generalized Universal Functions (GUfuncs)

@guvectorize allows you to create custom functions that operate element-wise on arrays, similar to NumPy's built-in ufuncs. They can handle inputs and outputs of varying dimensions, making them highly flexible for custom array transformations.

  • •Element-wise: Applies logic to each element or sub-array.
  • •Flexible Signatures: Defines input/output array shapes (e.g., (n)->(n)).
  • •Parallelizable: Numba can optimize these for parallel execution.
Common Mistake: Non-Numerical Data

Trying to use Numba (especially @njit or @guvectorize) on code that heavily relies on Python lists, dictionaries, or custom object-oriented features will often fail or result in poor performance. Numba excels with primitive types and NumPy arrays.

Key Takeaway

@guvectorize extends Numba's power by enabling custom, flexible ufuncs for element-wise array operations. Always ensure Numba-decorated functions primarily handle numerical data and NumPy arrays.
