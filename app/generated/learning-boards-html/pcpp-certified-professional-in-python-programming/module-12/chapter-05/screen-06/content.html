Operation Flow: Python Loop vs. NumPy Vectorization

Pure Python Loop
1. Iterate
2. Interpret Bytecode
3. Execute Operation (per element)

High overhead due to repeated interpreter interaction for each item.

NumPy Vectorization
1. Dispatch to C/Fortran
2. Execute Optimized Code (entire array)

Minimal overhead, direct execution on data for maximum efficiency.

What is Vectorization?

Performing operations on entire arrays or vectors at once, rather than element by element, by leveraging highly optimized underlying code.

Example: Array Addition

Instead of for i in range(len(a)): c[i] = a[i] + b[i], NumPy uses c = a + b, which is a single, fast C call.

Key Takeaway

Vectorization is NumPy's core mechanism for speed, replacing slow Python loops with fast, pre-compiled C/Fortran routines that operate on entire arrays.
