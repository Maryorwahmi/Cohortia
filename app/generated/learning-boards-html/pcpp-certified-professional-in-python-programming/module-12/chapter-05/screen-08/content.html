import time
import numpy as np

# NumPy approach
array1 = np.arange(1, 10_000_001)
array2 = np.arange(1, 10_000_001)

start_time = time.perf_counter()
result_array = array1 * array2
end_time = time.perf_counter()
print(f"NumPy multiplication took: {end_time - start_time:.4f} seconds")

NumPy: The Vectorized Solution

This code performs the same element-wise multiplication using NumPy arrays, demonstrating the dramatic performance improvement of vectorized operations.

Array Creation

NumPy arrays are created using np.arange. These arrays store elements contiguously in memory, enabling efficient processing.

Vectorized Multiplication

The simple array1 * array2 operation is vectorized, meaning NumPy dispatches it to highly optimized C code, bypassing Python's interpreter.

Expected Result

You will observe that the NumPy multiplication completes in a fraction of the time compared to the pure Python approach, often milliseconds versus seconds.

Key Takeaway

NumPy's vectorized operations leverage optimized C code and contiguous memory, resulting in orders of magnitude faster execution for numerical tasks than pure Python.
