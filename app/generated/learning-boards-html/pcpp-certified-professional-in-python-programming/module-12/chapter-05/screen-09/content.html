Broadcasting: Extending Operations

[[1, 2, 3],
 [4, 5, 6]]
+
10
=
[[11, 12, 13],
 [14, 15, 16]]

A scalar (10) is 'broadcast' across all elements of the 2x3 array for addition.

[[1, 2, 3],
 [4, 5, 6]]
+
[10, 20, 30]
=
[[11, 22, 33],
 [14, 25, 36]]

A 1D array is broadcast across rows of a 2D array, matching dimensions.

Universal Functions (ufuncs)

Element-wise operations (e.g., np.sin(), np.exp()) that are highly optimized and implemented in C for speed.

Broadcasting Rules

Allows operations on arrays of different shapes if their dimensions are compatible, effectively 'stretching' the smaller array without copying data.

Key Takeaway

Ufuncs provide optimized element-wise operations, while broadcasting enables flexible and memory-efficient arithmetic between arrays of different shapes, simplifying complex computations.
