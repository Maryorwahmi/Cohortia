import time

# Pure Python approach
list1 = list(range(1, 10_000_001))
list2 = list(range(1, 10_000_001))

start_time = time.perf_counter()
result_list = [x * y for x, y in zip(list1, list2)]
end_time = time.perf_counter()
print(f"Pure Python multiplication took: {end_time - start_time:.4f} seconds")

Pure Python: The Iterative Way

This code demonstrates element-wise multiplication using standard Python lists and a list comprehension, highlighting the performance characteristics of native Python loops.

List Creation

Two large Python lists are initialized, each containing 10 million integers. These are standard Python objects.

Element-wise Multiplication

A list comprehension iterates through both lists using zip, performing multiplication for each pair. This is where the interpreter overhead occurs repeatedly.

Performance Measurement

time.perf_counter() is used to accurately measure the elapsed time for the multiplication, revealing the cost of Python's interpreted loops.

Key Takeaway

Pure Python's list comprehensions, while concise, still involve significant interpreter overhead for each element, leading to slow performance on large datasets.
