Interpreted
Bytecode interpretation adds per-operation overhead compared to compiled code.
GIL
A mutex inside CPython that restricts bytecode execution to one thread at a time.
Profile
Time your code to find hotspots before optimizing.
Key Takeaway

Prefer measured, targeted changes: fix the real bottleneck, not the assumed one.

Concept Map

GIL
Serializes Python bytecode execution across threads.
