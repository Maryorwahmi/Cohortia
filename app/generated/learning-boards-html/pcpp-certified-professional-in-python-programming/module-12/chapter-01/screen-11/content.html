Module 12 › Chapter 12.1 › I/O Concurrency
Sequential fetch (concept)
for url in urls:
    result += fetch_url(url)
Sequential fetching serializes network waits; total time is roughly the sum of individual latencies.
Concurrent fetch (concept)
with ThreadPoolExecutor(max_workers=5) as e:
    futures = [e.submit(fetch_url, u) for u in urls]
    for f in as_completed(futures):
        total += f.result()
While one thread waits for a response, others can issue requests because the GIL is released during blocking I/O calls.
Measurement advice
  • Measure total elapsed time for the whole batch and the per-request times.
  • Repeat runs and average to reduce network noise.
  • If post-fetch processing is heavy, measure fetch and processing separately.
Key takeaway

Threads can significantly reduce wall-clock time for many short network requests because blocking releases the GIL.
