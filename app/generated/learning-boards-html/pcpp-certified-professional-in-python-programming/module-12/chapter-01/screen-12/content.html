Starter code
def sum_with_loop(n):
    total = 0
    for i in range(n):
        total += i
    return total

def sum_with_builtin(n):
    return sum(range(n))
Measure each function with time.time(), repeat runs, and compare averages. Confirm results match before trusting performance outcomes.
Reflect
Why is the built-in faster? Because the per-iteration work happens in C, avoiding Python-level bytecode per loop iteration.
