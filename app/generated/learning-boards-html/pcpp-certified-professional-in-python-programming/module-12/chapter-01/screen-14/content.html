Module 12 › Chapter 12.1 › Key Concepts
Interpreted Language
Instructions are executed by an interpreter, adding runtime dispatch overhead.
Dynamic Typing
Types are resolved at runtime, adding checks and dispatch for operations.
Global Interpreter Lock (GIL)
A mutex in CPython that serializes Python bytecode execution across threads.
Summary

These concepts explain why per-operation costs exist and guide choices about libraries, threading, and processes.
