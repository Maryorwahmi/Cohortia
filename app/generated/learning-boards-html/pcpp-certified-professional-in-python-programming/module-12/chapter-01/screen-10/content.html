Module 12 › Chapter 12.1 › process_data walkthrough
Slow variant (concept)
def process_data_slow(data_list):
    result = []
    for item in data_list:
        temp_str = str(item) * 1000  # repeated allocation
        for _ in range(1000):
            _ = item * item         # repeated computation
        result.append(len(temp_str))
    return result
This pattern repeatedly creates large temporary strings and performs repeated inner computations, which increases allocation and interpreter work.
Faster variant (concept)
def process_data_fast(data_list):
    result = []
    for item in data_list:
        for _ in range(1000):
            _ = item * item
        result.append(len(str(item) * 1000))
    return result
The second variant reduces repeated temporary work by consolidating the string construction and avoids extra repeated allocations inside inner loops.
Walkthrough notes
  • Measure both functions with the same input and average multiple runs.
  • Inspect allocations and inner-loop work using simple timers to find where time is spent.
  • If allocation dominates, use bulk or C-backed operations where possible.
Key Takeaway

Small changes inside inner loops can yield measurable improvements, but always profile to confirm the real hotspot.
