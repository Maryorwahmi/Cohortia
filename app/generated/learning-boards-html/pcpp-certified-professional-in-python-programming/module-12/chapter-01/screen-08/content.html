Iterative timing process
  1. Measure the complete run to establish a baseline.
  2. Time individual functions suspected to be heavy.
  3. Time inner loops and specific operations until the hotspot is clear.
  4. Average repeated runs to reduce variability.
Remember that wall-clock time includes I/O waits; use CPU-time tools if you need only CPU measurement.
Example timing pattern
start = time.time()
# run a block
end = time.time()
print('Elapsed:', end - start)
Use this pattern at multiple granularities to narrow down the slowest part of a program.
Concrete scenario
If a data-processing run takes minutes, time the whole run, then the function that processes a batch, then the inner loop that transforms items. Often one operation dominates the runtime.
Key Takeaway

Small, focused measurements reduce guesswork and guide effective optimization choices.
