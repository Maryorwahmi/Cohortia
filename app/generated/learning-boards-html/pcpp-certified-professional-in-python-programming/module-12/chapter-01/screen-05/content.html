Module 12 › Chapter 12.1 › Dynamic Typing
Definition
Types are determined at runtime, enabling flexible code but requiring per-operation checks and dispatch.
  • Operations must discover operand types and select the correct behavior at runtime.
  • Repeated conversions, such as str() inside loops, allocate objects that add overhead.
  • Vectorized or C-backed operations process many items with less interpreter overhead.
Analogy
Dynamic typing is like asking the type of each parcel before choosing a delivery method; that check takes time compared to a pre-sorted batch.
Concrete example
If your loop converts every element to string individually, consider converting once or using formats that avoid repeated allocation.
Common mistake
Assuming dynamic typing is always the bottleneck. Often algorithmic choices or allocations matter more.
Pro tip

Profile before changing types. When converting many items, use bulk operations or libraries to reduce per-item overhead.
