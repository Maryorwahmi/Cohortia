Example: attribute lookup hoist
Reduce repeated attribute access inside tight loops.
class MyProcessor:
    def __init__(self, multiplier):
        self.multiplier = multiplier

    def process_items_bad(self, items):
        results = []
        for item in items:
            results.append(item * self.multiplier)  # attribute lookup each iteration
        return results

    def process_items_good(self, items):
        results = []
        local_multiplier = self.multiplier  # hoisted once
        for item in items:
            results.append(item * local_multiplier)
        return results
This micro-optimization is most valuable in tight loops with many iterations. Always validate with a profiler to confirm real impact.
Supporting tips
  • Cache expensive lookups or function results when they are invariant.
  • Avoid allocating objects inside loops when a reusable object suffices.
  • Prefer local variables over repeated global or attribute access.
Key Takeaway

Small per-iteration savings multiply across many iterations; hoist invariants and cache results when safe.
