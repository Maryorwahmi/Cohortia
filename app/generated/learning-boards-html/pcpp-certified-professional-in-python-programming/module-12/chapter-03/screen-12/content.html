Module 12 › Chapter 12.3 › Preserve Correctness
Testing and validation
Write tests before refactor and measure after.
Add regression tests
Capture expected outputs on representative inputs so you can verify behavioral parity post-optimization.
Measure performance
Use realistic files and measure time and memory before and after to confirm gains.
Consider platform variance
Different architectures or Python implementations may behave differently; test where your code runs.
Fallbacks
If an optimization introduces instability, keep a safe fallback and iterate further with tests.
Key Takeaway

Automated tests and measurements are essential guards when you change algorithms or data structures.
