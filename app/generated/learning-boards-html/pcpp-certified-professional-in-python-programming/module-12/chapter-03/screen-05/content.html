Module 12 › Chapter 12.3 › Membership Tests
List membership (O(N))
Linear scan: cost grows with collection size.
# Example worst case check
large_list = list(range(1_000_000))
start = time.time()
(1_000_000 - 1) in large_list
end = time.time()
print(end - start)
Use lists for ordered collections, small sizes, or cases where membership checks are rare.
Set membership (avg O(1))
Hash table lookup gives constant average time.
large_set = set(range(1_000_000))
start = time.time()
(1_000_000 - 1) in large_set
end = time.time()
print(end - start)
Build the set once outside loops. When membership tests are the hotspot, switching to a set is typically the highest payoff change.
Common mistake
Converting to a list inside a loop or recreating a set each iteration loses the asymptotic advantage.
Pro tip
If building the set is expensive and queries are few, measure first; a set is worth it when queries are numerous or repeated.
Key Takeaway

Switching to hash-based containers reduces repeated membership cost dramatically when checks are frequent.
