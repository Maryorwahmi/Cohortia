Algorithmic Complexity
Describes how runtime/space grow with input size.
O(1) vs O(N)
Sets/dicts offer average O(1) membership; lists are O(N).
Generators vs Lists
Generators use lazy evaluation and are memory efficient for large streams.
Summary
Prioritize algorithmic improvements and choose hash-based containers and generators when appropriate to scale Python programs.
