Generator + Counter
Stream words and let Counter handle counting efficiently.
def count_words_efficient(filepath):
    def word_generator(path):
        with open(path, 'r') as f:
            for line in f:
                yield from (word for word in re.findall(r'\b\w+\b', line.lower()))

    word_counts = Counter(word_generator(filepath))
    return word_counts.most_common(10)
Why it works
Generator avoids storing all tokens; Counter is optimized in C for counting.
Verification
Compare outputs and runtimes of both versions to ensure correctness and measure gains.
Key Takeaway
Stream input and leverage optimized library code when possible to get both correctness and speed.
