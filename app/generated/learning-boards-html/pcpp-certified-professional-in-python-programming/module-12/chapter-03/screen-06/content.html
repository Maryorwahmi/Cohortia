Module 12 › Chapter 12.3 › List vs Generator
List comprehension example
Creates the full list in memory.
N = 10_000_000
list_comp = [i * 2 for i in range(N)]
print(sys.getsizeof(list_comp) / (1024*1024), 'MB')
del list_comp
Use when you need random access or multiple passes over the data and memory is adequate.
Generator expression example
Creates an iterator that yields values on demand without holding them all.
gen_exp = (i * 2 for i in range(N))
print(sys.getsizeof(gen_exp) / (1024*1024), 'MB')
# To consume: sum(gen_exp) or iterate in a loop
Analogy: a conveyor belt producing items one by one instead of stacking them in a bin.
When to use generator
Streaming large files, piping to aggregators, or memory-limited environments.
Misconception
Thinking generators are always slower; they often reduce overall time by avoiding heavy allocations.
Key Takeaway

Use list comprehensions for small-to-moderate sequences and generators for very large streams you process once.
