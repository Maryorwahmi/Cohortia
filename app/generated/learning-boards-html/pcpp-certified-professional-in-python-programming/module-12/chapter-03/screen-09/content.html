Module 12 › Chapter 12.3 › Inefficient Word Counter
Starter code pattern
Accumulating all words then counting and sorting.
def count_words_inefficient(filepath):
    all_words = []
    with open(filepath, 'r') as f:
        for line in f:
            words_in_line = re.findall(r'\b\w+\b', line.lower())
            all_words.extend(words_in_line)

    word_counts = {}
    for word in all_words:
        word_counts[word] = word_counts.get(word, 0) + 1

    sorted_counts = sorted(word_counts.items(), key=lambda item: item[1], reverse=True)
    return sorted_counts[:10]
Problem
Creates large intermediate list and manually counts then sorts everything.
Impact
High memory usage and unnecessary work for huge files.
What to do
Stream words and use collections.Counter.most_common to avoid full sorts and reduce memory.
