Supercharging with `@njit`: Sum of Squares

Applying Numba's `@njit` decorator for dramatic performance gains.

import time
import numpy as np
from numba import njit

# Pure Python (for comparison)
def sum_squares_python(n):
    total = 0
    for i in range(n):
        total += i * i
    return total

# Numba JIT compiled version with @njit
@njit
def sum_squares_numba(n):
    total = 0 # Numba infers type as int/long
    for i in range(n):
        total += i * i
    return total

N = 100_000_000

# Call Numba function once to compile it (first call overhead)
_ = sum_squares_numba(1)

start_time = time.perf_counter()
py_result = sum_squares_python(N)
end_time = time.perf_counter()
print(f"Python took: {end_time - start_time:.4f} seconds")

start_time = time.perf_counter()
numba_result = sum_squares_numba(N)
end_time = time.perf_counter()
print(f"Numba took: {end_time - start_time:.4f} seconds")
Performance Boost

The Numba version often runs significantly faster, demonstrating the power of JIT compilation for numerical loops.

Type Inference in Action

Numba automatically infers variable types (e.g., `int`) from usage, eliminating the need for explicit type declarations.

Key Takeaway

`@njit` provides substantial speedups for numerical Python loops by compiling them to efficient machine code, leveraging Numba's type inference.
