Numba `vectorize`: Custom Universal Functions

Transforming scalar Python functions into high-performance NumPy ufuncs.

What are Ufuncs?

NumPy's universal functions (ufuncs) are highly optimized C-implemented functions that perform element-wise operations on arrays.

The `@vectorize` Power

This decorator compiles a Python scalar function into a fast, Numba-optimized NumPy ufunc, enabling C-speed element-wise array processing.

Leveraging SIMD

Numba-vectorized ufuncs can utilize Single Instruction, Multiple Data (SIMD) instructions for parallel processing, maximizing throughput.

Type Signatures

The `@vectorize` decorator requires explicit type signatures to define input and output types for the ufunc, ensuring precise compilation.

Key Takeaway

`@vectorize` enables the creation of custom, high-performance NumPy ufuncs from Python, ideal for element-wise array operations at C speed.
