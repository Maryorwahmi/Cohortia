Accelerating Loops: Sum of Squares

The pure Python implementation as our performance baseline.

import time
import numpy as np

# Pure Python function for sum of squares
def sum_squares_python(n):
    total = 0
    for i in range(n):
        total += i * i
    return total

N = 100_000_000

# Benchmark pure Python version
start_time = time.perf_counter()
py_result = sum_squares_python(N)
end_time = time.perf_counter()
print(f"Python result: {py_result}, took: {end_time - start_time:.4f} seconds")
The Challenge

Python's interpreter overhead makes simple loops over large ranges computationally expensive, limiting performance for numerical tasks.

Why it Matters

Understanding this baseline helps quantify the performance gains Numba provides, highlighting its value in scientific computing and data analysis.

Key Takeaway

Pure Python loops, while clear, are often too slow for large-scale numerical computations, creating a strong case for optimization tools like Numba.
