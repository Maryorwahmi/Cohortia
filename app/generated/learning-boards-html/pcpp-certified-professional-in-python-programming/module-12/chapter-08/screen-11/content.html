Benchmarking Vectorized Ufuncs

Measuring the speed advantage of Numba's `@vectorize` for array operations.

import numpy as np
import time
from numba import vectorize, float64

# Scalar function for vectorize
def _scalar_power_add(x, y):
    return x**2 + y**3

# Numba vectorized ufunc
@vectorize([float64(float64, float64)])
def custom_power_add(x, y):
    return _scalar_power_add(x, y)

ARRAY_SIZE = 10_000_000
arr1 = np.arange(ARRAY_SIZE, dtype=np.float64)
arr2 = np.arange(ARRAY_SIZE, dtype=np.float64) * 0.5

# Call once to compile
_ = custom_power_add(np.array([0.0]), np.array([0.0]))

# Benchmark Numba vectorized ufunc
start_time = time.perf_counter()
result_ufunc = custom_power_add(arr1, arr2)
end_time = time.perf_counter()
print(f"Numba vectorized ufunc took: {end_time - start_time:.4f} seconds")

# For comparison, a pure Python loop would be orders of magnitude slower
# A NumPy expression might be fast, but @vectorize allows custom logic
Dramatic Speedups

Benchmarking reveals that Numba-vectorized ufuncs execute significantly faster, often achieving C-like performance for element-wise array operations.

SIMD Optimization

The compiled ufuncs leverage SIMD instructions, allowing parallel processing of multiple data elements, which boosts throughput.

Key Takeaway

Numba's `@vectorize` is a powerful tool for creating custom, high-performance ufuncs that extend NumPy's capabilities with C-speed for array processing.
