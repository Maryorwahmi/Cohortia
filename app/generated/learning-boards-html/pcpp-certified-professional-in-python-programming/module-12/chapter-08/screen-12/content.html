Numba Limitations: Object Mode & Unsupported Features

Understanding when Numba might not provide the expected performance benefits.

Python Object Mode Fallback (`@jit`)

  • If `@jit` encounters unsupported operations, it falls back to object mode.
  • In object mode, the function runs as pure Python, offering no speedup.
  • This fallback is silent, making it hard to diagnose performance issues.
Recommendation

Always prefer `@njit` to force nopython mode and get an error if compilation fails, ensuring optimization.

Unsupported Python Features

  • Numba's `nopython` mode doesn't support all Python features.
  • Examples: `try-except` blocks, arbitrary Python classes, generators, `yield` statements.
  • Using these can lead to compilation errors with `@njit` or object mode fallback with `@jit`.
Pro Tip

Simplify functions for Numba: focus on numerical operations, loops, and NumPy array manipulations.

Key Takeaway

Be aware of Numba's object mode fallback and unsupported features; use `@njit` to ensure compilation and identify incompatibilities.
