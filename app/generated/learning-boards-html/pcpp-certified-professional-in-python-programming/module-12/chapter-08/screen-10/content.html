Building Custom Ufuncs: `custom_power_add`

Defining a scalar function and vectorizing it for array operations.

import numpy as np
from numba import vectorize, float64

# Define a scalar Python function
def _scalar_power_add(x, y):
    return x**2 + y**3

# Use @vectorize to create a ufunc from the scalar function
@vectorize([float64(float64, float64)]) # Signature: returns float64, takes two float64 args
def custom_power_add(x, y):
    return _scalar_power_add(x, y)

# Example usage with NumPy arrays
arr1 = np.arange(10_000_000, dtype=np.float64)
arr2 = np.arange(10_000_000, dtype=np.float64) * 0.5

result_ufunc = custom_power_add(arr1, arr2)
print(f"First 5 results: {result_ufunc[:5]}")
Type Signature Importance

The type signature `[float64(float64, float64)]` is crucial; it explicitly tells Numba the expected input and output types for compilation.

Element-wise Efficiency

Once vectorized, `custom_power_add` operates directly on entire NumPy arrays, leveraging Numba's compiled speed for each element.

Key Takeaway

`@vectorize` allows you to define complex scalar logic in Python and apply it to large NumPy arrays at C-like speeds by specifying type signatures.
