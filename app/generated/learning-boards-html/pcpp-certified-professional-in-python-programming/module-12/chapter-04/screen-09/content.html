Frequency Counting with Counter

Simplifying Object Tallying

from collections import Counter

# collections.Counter example
words = ["apple", "banana", "apple", "orange", "banana", "apple"]
word_counts = Counter(words)
print(f"Word counts: {word_counts}")
print(f"Most common word: {word_counts.most_common(1)}")

# Output:
# Word counts: Counter({'apple': 3, 'banana': 2, 'orange': 1})
# Most common word: [('apple', 3)]
Explanation

Counter is a specialized dictionary subclass that efficiently counts hashable objects, making it perfect for frequency analysis.

Efficiency Gain

It replaces verbose and less efficient manual dictionary-based counting loops with a concise, C-optimized solution, improving both readability and performance.

Key Takeaway

For any frequency counting task, always reach for collections.Counter to achieve optimal performance and cleaner code.
