Functional Tools

Transforming and Filtering Data

Leveraging map() and filter() Iterators

import time

N = 10_000_000
numbers = range(N)

def square(x):
    return x * x

def is_even(x):
    return x % 2 == 0

# Python loop approach
start_time = time.time()
result_loop = []
for x in numbers:
    if is_even(x):
        result_loop.append(square(x))
end_time = time.time()
print(f"Map/Filter with loop: {end_time - start_time:.6f} seconds")

# Built-in map and filter (returning iterators)
start_time = time.time()
result_builtin = list(map(square, filter(is_even, numbers))) # Convert to list to force evaluation
end_time = time.time()
print(f"Map/Filter with built-ins: {end_time - start_time:.6f} seconds")
Explanation

map() applies a function to all items, and filter() selects items based on a condition. Both return iterators, processing data lazily and efficiently.

Iterator Advantage

Iterators avoid creating large intermediate lists in memory, making them ideal for large datasets and chained operations.

Key Takeaway

For transformations and filtering, prefer map() and filter() over explicit loops to gain C-optimized speed and memory efficiency.
