Performance Example

Summing Numbers Efficiently

Replacing Loops with sum()

import time

N = 10_000_000
numbers = range(N)

# Using a for loop
start_time = time.time()
total_loop = 0
for num in numbers:
    total_loop += num
end_time = time.time()
print(f"Sum with for loop: {end_time - start_time:.6f} seconds")

# Using built-in sum()
start_time = time.time()
total_builtin = sum(numbers)
end_time = time.time()
print(f"Sum with built-in sum(): {end_time - start_time:.6f} seconds")
Explanation

The sum() function is implemented in C, allowing it to iterate and accumulate values much faster than a Python for loop, which incurs interpreter overhead at each step.

Performance Insight

For 10 million numbers, the built-in sum() can be orders of magnitude faster, demonstrating the power of C-optimized operations.

Key Takeaway

Always prefer Python's built-in functions like sum() for common aggregation tasks to achieve optimal performance.
