Specialized Data Structure

Double-Ended Queues with deque

Fast Appends and Pops from Both Ends

from collections import deque

# collections.deque example
my_deque = deque(maxlen=3) # Fixed-size deque
for i in range(5):
    my_deque.append(i)
    print(f"Deque after append {i}: {my_deque}") # Oldest item is automatically removed

# Output:
# Deque after append 0: deque([0])
# Deque after append 1: deque([0, 1])
# Deque after append 2: deque([0, 1, 2])
# Deque after append 3: deque([1, 2, 3])
# Deque after append 4: deque([2, 3, 4])
Explanation

deque (double-ended queue) allows O(1) appends and pops from both ends, unlike list where inserting at the beginning is O(N).

Use Case

Ideal for implementing queues, stacks, or fixed-size rotating buffers where old items are automatically discarded when new ones are added.

Key Takeaway

For efficient operations at both ends of a sequence, collections.deque is the superior choice over a standard Python list.
