Optimization Technique

Caching Function Results with lru_cache

Dramatically Speeding Up Repeated Calls

How `lru_cache` Works

  • •**Memoization:** Stores results of expensive function calls.
  • •**Cache Hit:** If arguments seen before, returns cached result instantly.
  • •**Cache Miss:** Executes function, stores result, then returns it.
  • •**LRU Policy:** Discards Least Recently Used items when cache is full.
Key Takeaway

Use @functools.lru_cache to memoize computationally expensive functions, turning repetitive calculations into fast cache lookups.

Pro Tip

lru_cache works best on pure functions (same input always yields same output) with hashable arguments.

`lru_cache` Flow

Function Call (args)
Check Cache
