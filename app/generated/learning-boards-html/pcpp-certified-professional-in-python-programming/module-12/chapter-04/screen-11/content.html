`itertools` in Action

Combining and Selecting Iterables

Using chain() and islice()

from itertools import chain, islice

# itertools.chain example
list1 = [1, 2, 3]
list2 = ['a', 'b', 'c']
chained_iterator = chain(list1, list2)
print(f"Chained items: {list(chained_iterator)}")

# itertools.islice example (for large iterables without loading all into memory)
large_range = range(1_000_000)
first_100_even = list(islice(filter(lambda x: x % 2 == 0, large_range), 100))
print(f"First 100 even numbers from large range: {first_100_even[:5]}...")

# Output:
# Chained items: [1, 2, 3, 'a', 'b', 'c']
# First 100 even numbers from large range: [0, 2, 4, 6, 8]...
chain() Explained

chain() creates a single iterator from multiple iterables, processing elements sequentially without creating a new combined list in memory.

islice() Explained

islice() allows you to take a slice of an iterator. Crucially, it only processes the requested elements, making it memory-efficient for large iterables.

Key Takeaway

Use chain() to combine iterables and islice() to slice them efficiently, especially when dealing with large or potentially infinite sequences.
