Module 8 › Chapter 8.2 › Scalability & Resilience
Architecture patterns
Combine a lightweight I/O layer with bounded worker pools and resource caps to prevent per-connection exhaustion.
I/O layer
Selector-based accept/read/write, maintain small per-connection buffers.
Worker pool
Offload CPU work to a bounded thread or process pool to avoid blocking the event loop.
Backpressure
Pause reading from a socket or drop messages when buffers exceed limits.
Graceful shutdown
Stop accepting, finish in-flight work, then close sockets and workers cleanly.
Checklist
  • Cap buffers and enforce limits per connection.
  • Use a bounded pool for CPU-bound tasks.
  • Monitor and log connection counts and resource usage under load.
Key Takeaway

Architect for limits: assume clients can misbehave and enforce caps to protect the whole system.
