Module 8 › Chapter 8.2 › Objectives — Practical Skills
Objective tasks
  • Convert blocking echo server to thread-per-client and observe concurrency behavior under multiple clients.
  • Switch to selectors: register listening and client sockets, manage inb/outb buffers, and handle ready events.
  • Implement command parsing in the selector server and ensure messages are delimited and echoed safely.
  • Practice graceful shutdown and port reuse using SO_REUSEADDR.
Why these tasks matter
They teach you to reason about blocking behavior, resource overhead per client, and the simple patterns that keep servers deterministic. You will also learn to avoid data corruption by protecting shared structures when using threads.
