# Inside service_connection after assembling messages:
for msg_bytes in messages:
    msg = msg_bytes.decode().strip()
    response = b''
    if msg == "TIME":
        response = datetime.datetime.now().strftime("%H:%M:%S").encode()
    elif msg.startswith("UPPERCASE:"):
        text_to_upper = msg[len("UPPERCASE:"):]
        response = text_to_upper.upper().encode()
    else:
        response = msg_bytes

    if response:
        data['outb'] += response + b'
'  # Send with newline
Notes for robustness
  • Assume messages may be fragmented; keep incomplete bytes in data['inb'] until a newline is seen.
  • Send responses with a delimiter so clients can read full replies.
  • Test with multiple clients sending commands concurrently to validate selector handling.
