Module 8 › Chapter 8.2 › I/O Multiplexing
Core flow
  1. Create a DefaultSelector instance.
  2. Register listening socket for EVENT_READ.
  3. When select returns, accept new connections or service ready clients.
  4. Use per-connection inb/outb buffers and handle partial sends/receives.
Practical note
Set listening and client sockets to non-blocking. Expect BlockingIOError and handle it by retrying when the selector next signals readiness. Keep state per socket so you can resume partial operations.
Key Takeaway

Multiplexing trades programming complexity for resource efficiency and high connection capacity.
