Module 8 › Chapter 8.2 › Key Concepts
Concurrency
Manage multiple clients so the server remains responsive under concurrent connections.
Threading
Simple per-client logic but needs locks for shared data and has per-thread costs.
I/O Multiplexing
Selectors let one thread monitor many sockets using non-blocking I/O and per-connection buffers.
Final takeaway

Pick the model that fits expected load: threads for simplicity with moderate clients, selectors for large-scale I/O-bound workloads; always manage buffers and errors explicitly.
