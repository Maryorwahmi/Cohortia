Module 8 › Chapter 8.2 › Non-blocking & BlockingIOError
Key ideas
  • Non-blocking sockets raise BlockingIOError instead of blocking.
  • Always maintain per-connection input and output buffers.
  • Handle partial sends by removing the sent portion from outb.
Example strategy
When recv returns data, append to inb and split on a delimiter (like newline) or use a length header. When send returns a number of bytes, remove that slice from outb and leave the rest for the next writable event.
Common mistake

Treating recv results as complete messages or ignoring BlockingIOError. Build your protocol to tolerate fragmentation.
