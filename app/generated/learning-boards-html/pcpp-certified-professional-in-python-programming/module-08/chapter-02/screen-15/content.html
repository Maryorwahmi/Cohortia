Module 8 › Chapter 8.2 › What to Remember
Non-blocking
Expect partial reads/writes and BlockingIOError; use per-connection buffers.
SO_REUSEADDR
Use it to simplify restarts, but still close sockets properly.
Threads vs Selectors
Threads are easy; selectors scale. Match choice to expected concurrency and workload.
One-line summary

Design servers with clear models: manage buffers, handle non-blocking errors, protect shared state, and enforce resource limits.
