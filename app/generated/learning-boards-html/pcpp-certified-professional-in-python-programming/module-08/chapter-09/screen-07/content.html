Module 9 › Chapter 8.9 › Session Login Example
Step-by-step
  1. Instantiate requests.Session and set headers.
  2. Fetch login page if CSRF tokens are required.
  3. Post credentials with session.post.
  4. Use session.get to access protected pages and verify cookies.
Live code (example)
import requests

s = requests.Session()
s.headers.update({"User-Agent": "CohortiaScraper/1.0"})

login_url = "https://example.com/login"
login_payload = {"username":"user","password":"pass"}
resp = s.post(login_url, data=login_payload)
resp.raise_for_status()
print("Login status:", resp.status_code)

dashboard = s.get("https://example.com/dashboard")
print("Dashboard status:", dashboard.status_code)
print(s.cookies.get_dict())
Use print statements to verify cookies or parse returned HTML for expected content.
