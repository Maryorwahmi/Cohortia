Module 9 › Chapter 8.9 › Dynamic vs Static
Static Pages
If the content you need is present in the initial HTML, requests + BeautifulSoup are efficient and robust. They avoid browser overhead and are simpler to maintain.
When to use requests
  • Page contains target data in HTML source.
  • There is an identifiable API endpoint returning JSON you can call directly.
Dynamic Pages
When data is rendered after page load via JavaScript, a headless browser can execute that script and provide the final DOM. Use this only when no direct API is available.
Trade-offs
  • Headless browsers are heavier, slower, and introduce more failure modes.
  • They can be necessary for single-page apps, but always check for underlying APIs first.
