Code Walkthrough
import requests

API_KEY = "your_super_secret_api_key_here"
API_ENDPOINT = "https://api.example.com/data"

headers = {
  "Authorization": f"Bearer {API_KEY}",
  "Content-Type": "application/json"
}

try:
  response = requests.get(API_ENDPOINT, headers=headers)
  response.raise_for_status()
  data = response.json()
  print("Data fetched successfully:", data)
except requests.exceptions.HTTPError as e:
  print(f"HTTP Error: {e}")
  print(f"Response content: {e.response.text}")
except requests.exceptions.RequestException as e:
  print(f"An error occurred: {e}")
This snippet shows header use and specific exception handling for HTTP errors and generic request failures.
Explanation
  • Place the token in Authorization to avoid re-sending credentials.
  • Call raise_for_status to detect 4xx/5xx and inspect the response for debug info.
  • On 401, refresh or re-authenticate; on 429, implement backoff before retrying.
Common Mistake

Hard-coding tokens in source makes leaks likely; use environment variables or secure vaults.
