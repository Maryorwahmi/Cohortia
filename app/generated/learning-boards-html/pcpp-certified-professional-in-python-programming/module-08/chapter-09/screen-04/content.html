Module 9 › Chapter 8.9 › Authentication Patterns
Definition

Basic, Token, and OAuth 2.0

Each method defines how credentials or tokens are exchanged and validated. Consider security, revocation, and delegation when selecting one.

Basic Authentication
Credentials are base64-encoded and sent per request. Use only over HTTPS and preferably for simple internal tooling.
Token-based Authentication
Server issues a token after initial login. Send the token as a Bearer in the Authorization header.
OAuth 2.0 (Conceptual)
An authorization framework for delegating limited access to third-party apps via scoped tokens.
Concrete example
import requests

API_KEY = "your_super_secret_api_key_here"
API_ENDPOINT = "https://api.example.com/data"

headers = {
  "Authorization": f"Bearer {API_KEY}",
  "Content-Type": "application/json"
}

response = requests.get(API_ENDPOINT, headers=headers)
response.raise_for_status()
print(response.json())
Misconception
OAuth is not just "login" — it grants limited access to resources and is about authorization, not simply authentication of a user.
Key Takeaway

Match the authentication method to your needs: risk, revocation, and third-party delegation drive the choice.
