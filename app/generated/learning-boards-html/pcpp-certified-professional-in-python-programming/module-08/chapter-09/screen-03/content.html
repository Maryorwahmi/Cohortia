Practice tasks

Each objective maps to a concrete code task you will perform during the live-coding segment.

Task: Token Header

Send Authorization: Bearer <token> and check for a successful response or 401 to validate your token handling.

Task: Session Login

Use requests.Session to post credentials, then access a protected endpoint to confirm cookies are used correctly.

Task: Ethical Scraper

Respect robots.txt delay, set a descriptive User-Agent, and scrape a single public page for a few elements only.
