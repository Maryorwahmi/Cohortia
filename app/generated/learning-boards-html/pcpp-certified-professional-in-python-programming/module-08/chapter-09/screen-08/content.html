Module 9 › Chapter 8.9 › requests + BeautifulSoup
Example code
import requests
from bs4 import BeautifulSoup
import time

URL = "https://en.wikipedia.org/wiki/Python_(programming_language)"
headers = {"User-Agent": "CohortiaAdvancedScraper/1.0 (contact@example.com)"}

time.sleep(2)
resp = requests.get(URL, headers=headers)
resp.raise_for_status()
soup = BeautifulSoup(resp.text, 'html.parser')
content_div = soup.find('div', class_='mw-parser-output')
if content_div:
  paragraphs = content_div.find_all('p')
  for p in paragraphs[:3]:
    print(p.text[:150])
Best practices
  • Respect robots.txt and Terms of Service before scraping.
  • Limit scope: scrape only the data you need.
  • Set a descriptive User-Agent and implement delays between requests.
  • Handle missing elements defensively to avoid crashes.
Pitfall

Scraping dynamically rendered content with only requests will miss post-load data; look for underlying APIs instead.
