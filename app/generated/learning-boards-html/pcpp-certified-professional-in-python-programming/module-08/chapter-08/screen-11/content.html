import requests

API_BASE = "https://jsonplaceholder.typicode.com"

# 1. Fetch posts with pagination
resp = requests.get(f"{API_BASE}/posts", params={'_page': 1, '_limit': 5})
resp.raise_for_status()
for p in resp.json():
  print(p['id'], p['title'][:40])

# 2. Create a todo
new = {'userId': 1, 'title': 'Learn RESTful API Design', 'completed': False}
resp = requests.post(f"{API_BASE}/todos", json=new)
print('Status:', resp.status_code)
print('Created:', resp.json())

# 3. Patch a todo
resp = requests.patch(f"{API_BASE}/todos/1", json={'completed': True})
print('Updated status:', resp.status_code)

# 4. Delete non-existent
resp = requests.delete(f"{API_BASE}/todos/9999")
print('Delete status:', resp.status_code)
This sample follows the chapter's demo: fetch pages, POST to create, PATCH to update partially, and DELETE while handling statuses.
Explanation & patterns
  • Always call resp.raise_for_status to convert HTTP errors to exceptions you can catch.
  • Inspect resp.status_code for specific flows: 201 → read Location, 204 → nothing to parse.
  • Parse resp.json() for structured error details to display to users.
  • Wrap requests in try/except to handle network and HTTP exceptions gracefully.
