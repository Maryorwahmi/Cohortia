Resource Identification

Name collections with plural nouns

Use /tasks and /tasks/7 to separate collections and items. Keep verb-free paths so clients can rely on methods to indicate actions.

Good
/users, /products, /orders/ORD-001
Bad
/getAllUsers, /createProduct, /deleteOrder/123
Key Takeaway

Design URIs as stable resource identifiers; use query params for filtering and methods for behavior.

Concrete example

Task Management endpoints

GET /tasks?limit=10&offset=20 — list with offset pagination
POST /tasks — create a new task, body contains task JSON
PATCH /tasks/7 — partial update, like marking completed
DELETE /tasks/7 — delete a specific task
Misconception
Putting verbs in URIs duplicates what HTTP methods already express and makes the API less RESTful and harder to cache.
