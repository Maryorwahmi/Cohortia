Learning Objectives

Progress from understanding REST constraints to designing endpoints and consuming APIs robustly.

Bloom: Learn → Understand → Apply → Master
01
Understand REST constraints

Learn client-server separation, statelessness, cache rules, and the uniform interface, and why they improve scalability.

Mnemonic: Four pillars diagram
VERIFIED COMPETENCY MILESTONE
02
Design resource URIs

Use noun-based, plural collection names and avoid verbs in paths so URIs remain predictable and discoverable.

Mnemonic: Plural nouns = predictability
VERIFIED COMPETENCY MILESTONE
03
Map CRUD to HTTP methods

Apply GET, POST, PUT, PATCH, DELETE correctly and understand idempotence to prevent unexpected side effects.

Mnemonic: C-R-U-D → POST, GET, PUT/PATCH, DELETE
VERIFIED COMPETENCY MILESTONE
04
Use correct HTTP status codes

Signal success, client errors, and server errors with 2xx, 4xx and 5xx codes and include Location when resources are created.

Mnemonic: 2xx OK, 4xx client fix, 5xx server fix
VERIFIED COMPETENCY MILESTONE
