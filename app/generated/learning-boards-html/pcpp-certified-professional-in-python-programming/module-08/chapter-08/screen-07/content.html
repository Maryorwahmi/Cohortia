Module 08 › Chapter 8.8 › HTTP Status Codes
Success
200 OK — general success with a response body
201 Created — resource created; include Location header
204 No Content — success with no response body
Example
POST /tasks → 201 Created; Location: /tasks/42
Errors & Redirects
400 Bad Request — malformed input or missing fields
401 Unauthorized — authentication required
403 Forbidden — authenticated but not permitted
404 Not Found — resource absent
405 Method Not Allowed — wrong HTTP method
409 Conflict — resource state conflict
429 Too Many Requests — rate limiting
500 / 503 — server errors and service unavailability
Takeaway
Return the most specific code you can; precise codes let clients handle responses correctly.
