Response handling

Use Retry-After or backoff

def make_api_request(url, headers=None):
  while True:
    response = requests.get(url, headers=headers)
    if response.status_code == 429:
      retry_after = int(response.headers.get('Retry-After', 60))
      print(f"Rate limit hit. Retrying after {retry_after} seconds.")
      time.sleep(retry_after)
      continue
    response.raise_for_status()
    return response
This pattern respects server guidance when provided and prevents immediate retry storms.
Backoff strategy
If Retry-After is missing, implement exponential backoff with jitter. For example, wait 2^n seconds plus a small random jitter per retry attempt. Log repeated rate-limit events so you can improve client usage or request higher limits.
