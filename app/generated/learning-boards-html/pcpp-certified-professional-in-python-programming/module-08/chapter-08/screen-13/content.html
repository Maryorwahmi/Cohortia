Part 1 — API Design (Written)
GET /tasks
List tasks. Params: limit, offset or cursor. Responses: 200, 401, 500.
GET /tasks/{id}
Retrieve a task. Responses: 200, 404, 401.
POST /tasks
Create task. Body: title, userId, completed. Responses: 201 with Location, 400.
PATCH /tasks/{id}
Partial update like completed flag. Responses: 200, 400, 404.
DELETE /tasks/{id}
Delete a task. Responses: 204, 404.
