Comparison

URI vs Header vs Query

URI Versioning
/v1/users — Simple, cache-friendly, but changes the resource identifier.
Header Versioning
X-API-Version: 1 — Keeps URIs stable but less discoverable and may complicate caching.
Query Versioning
/users?version=1 — Simple but mixes version semantics with filtering/query parameters.
Practical Rule
Document your choice and be consistent. If caching is critical, prefer URI versioning; if preserving URIs is essential, consider headers.
