Module 08 › Chapter 8.8 › Pagination
Offset-based

limit & offset

GET /users?limit=10&offset=20 — simple to implement and understand, but can be inconsistent if data changes during paging.

When to use
Small datasets or admin UIs where data is stable.
Cursor-based

opaque cursor tokens

GET /users?after=<cursor> — robust for changing datasets and efficient for deep pages; client passes the cursor returned by the server.

When to use
Feeds, timelines, and large, frequently updated collections.
