Test client example

import requests
BASE = 'http://127.0.0.1:5000'

# GET all
r = requests.get(f"{BASE}/books")
print(r.status_code, r.json())

# POST new book
r = requests.post(f"{BASE}/books", json={'title':'The Python Book','author':'Guido'})
print(r.status_code, r.json())

# PUT update
r = requests.put(f"{BASE}/books/3", json={'title':'Updated','author':'Author'})
print(r.status_code, r.json())

# DELETE
r = requests.delete(f"{BASE}/books/3")
print(r.status_code)
The sample client prints status codes and responses so you can see both the machine signal and the returned payload. Also test error cases intentionally to ensure appropriate 400 and 404 codes.
Curl quick checks
Use curl -i to see headers and status codes, e.g., curl -i -H 'Content-Type: application/json' -d '{"title":"X","author":"Y"}' -X POST http://127.0.0.1:5000/books
Key Takeaway

Automated and manual tests confirm both body content and HTTP status codes. Test success and failure paths to make APIs reliable for clients.
