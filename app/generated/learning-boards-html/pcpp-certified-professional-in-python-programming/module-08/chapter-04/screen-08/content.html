Core Example

GET endpoints

from flask import Flask, jsonify

app = Flask(__name__)

books = [
  {'id': 1, 'title': "The Hitchhiker's Guide to the Galaxy", 'author': 'Douglas Adams'},
  {'id': 2, 'title': 'Pride and Prejudice', 'author': 'Jane Austen'}
]

@app.route('/books', methods=['GET'])
def get_books():
  return jsonify(books)

@app.route('/books/<int:book_id>', methods=['GET'])
def get_book(book_id):
  book = next((b for b in books if b['id'] == book_id), None)
  if book:
    return jsonify(book)
  return jsonify({'message': 'Book not found'}), 404
Test with curl or requests to confirm the JSON structure and status codes for found and not found cases.
Explanation
  • Use next with a generator to find the first matching book or return None.
  • When no match is found, return a JSON message and 404 status.
  • Keep the data shapes consistent so clients can rely on keys like id, title, and author.
Key Takeaway

Return clear JSON and use 404 for missing resources so client code can distinguish not-found from success.
