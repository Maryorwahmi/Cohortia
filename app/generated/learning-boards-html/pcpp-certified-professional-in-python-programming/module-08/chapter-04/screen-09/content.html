Core Example

POST with validation

@app.route('/books', methods=['POST'])
def add_book():
  global next_book_id
  if not request.json or not 'title' in request.json or not 'author' in request.json:
    return jsonify({'message': 'Missing title or author'}), 400

  new_book = {
    'id': next_book_id,
    'title': request.json['title'],
    'author': request.json['author']
  }
  books.append(new_book)
  next_book_id += 1
  return jsonify(new_book), 201
This pattern validates presence and returns helpful messages so clients can correct input. Use schema validators for production-grade checks.
Why validation matters
  • Detect malformed or missing input early and return 400.
  • Provide clear messages so clients can retry with correct payloads.
  • Protect server logic from unexpected types or missing keys.
Pro tip
For more robust validation, consider using a schema library or marshmallow to centralize rules and error messages.
Key Takeaway

Validate request.json for required fields, return 400 when input is invalid, and use 201 to signal successful creation.
