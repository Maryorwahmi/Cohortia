jsonify and status codes

from flask import Flask, jsonify

app = Flask(__name__)

books = [{'id':1,'title':'Hitchhiker','author':'Douglas Adams'}]

@app.route('/books', methods=['GET'])
def get_books():
  return jsonify(books)

@app.route('/books', methods=['POST'])
def add_book():
  new = {'id':2,'title':'New Book'}
  return jsonify(new), 201
jsonify ensures a correct JSON body and Content-Type header. Use explicit tuples to return status codes alongside the body.
Explanation
  • jsonify transforms Python structures into JSON and sets headers.
  • Return tuples like (body, status_code) to communicate outcomes.
  • Consistent codes let clients react: retry, show error, or proceed.
Common mistake
Returning a dict without jsonify can lead to confusing behavior and wrong headers.
Key Takeaway

Always serialize API output with jsonify and return appropriate HTTP status codes so clients can process responses reliably.
