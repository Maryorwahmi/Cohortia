Module 8 › Chapter 8.4 › What to Remember
Resource design
Use nouns for endpoints and HTTP verbs for actions to make APIs intuitive.
Clear responses
Return JSON with jsonify and use correct HTTP status codes consistently.
Production caution
Disable debug mode and use a database and WSGI server instead of global in-memory state for production.
Final Takeaway

These three reminders will guide your design choices and help you move a demo Flask API to a reliable, testable service suitable for integration and deployment.
