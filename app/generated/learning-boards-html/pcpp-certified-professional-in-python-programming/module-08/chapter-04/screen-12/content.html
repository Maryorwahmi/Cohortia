PUT and DELETE example

@app.route('/books/<int:book_id>', methods=['PUT'])
def update_book(book_id):
  book = next((b for b in books if b['id'] == book_id), None)
  if not book:
    return jsonify({'message':'Book not found'}), 404
  if not request.json or not 'title' in request.json or not 'author' in request.json:
    return jsonify({'message':'Missing title or author for update'}), 400
  book['title'] = request.json['title']
  book['author'] = request.json['author']
  return jsonify(book), 200

@app.route('/books/<int:book_id>', methods=['DELETE'])
def delete_book(book_id):
  global books
  original_len = len(books)
  books = [b for b in books if b['id'] != book_id]
  if len(books) < original_len:
    return '', 204
  return jsonify({'message':'Book not found'}), 404
Test update and delete flows with the requests client to confirm status codes and body content. Handle concurrent updates with a persistent database in production.
Concurrency note
In-memory lists and counters are suitable for demos but can produce race conditions under concurrent requests. Use a database and transactional updates for production systems.
Key Takeaway

PUT and DELETE complete CRUD operations; always return clear status codes and avoid global mutable state when reliability and concurrency matter.
