Definition

Minimal app

This minimal file is all you need to start a development server and respond to a request.

from flask import Flask

app = Flask(__name__)

@app.route('/')
def hello_world():
  return 'Hello, Cohortia! This is your first Flask app.'

if __name__ == '__main__':
  app.run(debug=True)
Save as app.py and run python app.py. Visit http://127.0.0.1:5000/ to see the message. Remember to remove debug=True in production.
Breakdown
  • Flask class: entry point for the app instance.
  • @app.route: maps a URL path to a view function.
  • View function: returns the response body; can return strings, tuples, or JSON via jsonify.
Common mistake
Returning a Python dict directly can cause Flask to try and render a template. Use jsonify for API responses.
Key Takeaway

The minimal Flask file demonstrates the required pieces: app, routes, view functions, and how to run the dev server. Keep debug off in production.
