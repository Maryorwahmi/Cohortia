Process Flow

Routing steps

1
Define route pattern
Choose a resource URL such as /books or /books/<int:id>.
2
Specify methods
Use methods=['GET','POST'] to accept non-default verbs.
3
Implement view function
Return data, or (data, status_code) for explicit responses.
Example: dynamic route
@app.route('/books/<int:book_id>', methods=['GET']) def get_book(book_id): # find book or return 404 ...
Misconception: routes are not method-agnostic. You must explicitly allow POST or PUT where needed. If a POST is sent to a GET-only route, Flask returns 405 Method Not Allowed.
Key Takeaway

Map resource URLs to small view functions, capture path variables with typed segments, and always set methods when you expect non-GET traffic.
