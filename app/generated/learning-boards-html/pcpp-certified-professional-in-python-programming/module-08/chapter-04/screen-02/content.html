Learning Objectives

These objectives guide the hands-on lab and checklist for verified competency.

01
Understand web services and REST

Learn what makes an API RESTful and why stateless requests improve scalability. Visual mnemonic: a small Venn of client-server and stateless arrows.

Verified competency milestone
02
Grasp Flask fundamentals

Create a Flask app, use @app.route, and write view functions. Why it matters: these are the building blocks of any Flask API.

Verified competency milestone
03
Build a RESTful books API

Implement GET and POST endpoints, return JSON using jsonify, and use status codes to communicate results. Mnemonic: simple book card with status badge.

Verified competency milestone
04
Validate inputs and handle errors

Detect missing fields, return 400 or 404 as appropriate, and avoid exposing sensitive debug info in production.

Verified competency milestone
