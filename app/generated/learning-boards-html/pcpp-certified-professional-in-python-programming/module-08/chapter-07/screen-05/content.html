# app.py
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/')
def hello_world():
  return "Hello, Cohortia PCPP Web Server!"

@app.route('/greet/<name>')
def greet_user(name):
  return f"Greetings, {name.capitalize()}!"

if __name__ == '__main__':
  app.run(debug=True, port=5000)
Explanation

The Flask instance wires incoming HTTP requests to the functions decorated with @app.route. Path parameters written with angle brackets are passed as function arguments after conversion to strings or typed converters.

Returning a plain string becomes a text response while jsonify returns JSON with the appropriate Content-Type header. Remember to restrict methods for non-GET routes.

Example: Visit /greet/cohortia to see the path parameter in action.
Common mistake: using app.run(debug=True) in production exposes a dangerous interactive debugger.
Tip: Use a WSGI server like Gunicorn for production Flask deployments.
