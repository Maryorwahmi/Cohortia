Design consistent JSON shapes. Include an id or message on creation and avoid sending bodies with 204 responses. Use headers when you need to provide location or caching hints.
Quick checklist
  • Use jsonify for serializing dicts/lists.
  • Return explicit status codes in tuples.
  • Validate objects before serialization.
