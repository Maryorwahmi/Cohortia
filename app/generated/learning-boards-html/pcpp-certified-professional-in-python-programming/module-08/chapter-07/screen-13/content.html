curl examples
# GET all users
curl -i http://127.0.0.1:5000/api/users

# POST create user
curl -i -H "Content-Type: application/json" -d '{"name":"Charlie","email":"c@example.com"}' http://127.0.0.1:5000/api/users

# PUT update user
curl -i -X PUT -H "Content-Type: application/json" -d '{"name":"Alice Updated"}' http://127.0.0.1:5000/api/users/1
What to check
  • HTTP status matches expected action (200, 201, 204, 404, 400).
  • Response Content-Type header is application/json for JSON bodies.
  • Payload fields and types are stable across calls.
