Definition
Web Framework

A toolkit that routes HTTP requests to code, parses request data, and helps produce well-formed HTTP responses without manual socket handling.

Why it matters
  • Saves time by removing repetitive parsing code.
  • Encourages consistent API behavior and status handling.
  • Makes code easier to maintain and test.
Contrast
Raw sockets vs framework
Raw sockets: explicit parsing, error-prone, low-level control
Framework: routing decorators, helpers for request and response, less boilerplate
Misconception: frameworks hide HTTP semantics — false
Best practice: know HTTP methods and status codes even when using a framework
Key Takeaway
Frameworks simplify plumbing but require you to design clear routes and correct responses.
