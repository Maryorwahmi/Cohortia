Module 8 › Chapter 8.7 › Practice Plan
Step-by-step practice
  • 1. Start Flask app and verify root greeting using curl or browser.
  • 2. Add route with path parameter and test substitution in the URL.
  • 3. Read query parameters and confirm default values when missing.
  • 4. Create POST route that requires JSON and returns 201 on success.
  • 5. Implement GET/PUT/DELETE for resources and return appropriate codes.
Tools
curl, Postman, or Insomnia for requests; Gunicorn or Uvicorn for production serving.
