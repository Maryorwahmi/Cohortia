Common mistakes
  • Leaving debug=True in production exposes an interactive debugger.
  • Not specifying methods for non-GET routes causes unexpected failures.
  • Calling get_json without checking request.is_json can produce None or errors.
  • Returning sensitive stack traces or internal data in responses.
Deployment checklist
Use Gunicorn or uWSGI for Flask. Use Uvicorn for FastAPI.
Place a reverse proxy like Nginx for SSL and static files.
Turn off debug and sanitize error responses.
