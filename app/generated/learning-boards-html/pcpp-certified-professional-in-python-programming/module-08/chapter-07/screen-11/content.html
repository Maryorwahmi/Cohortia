from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
  name: str
  price: float

@app.post('/items/')
async def create_item(item: Item):
  return {"message": "Item created", "item": item}
When to use
Use FastAPI for typed validation, automatic docs, and async endpoints for high-concurrency APIs.
Use Flask for simple, synchronous microservices or when you want minimal framework constraints.
Tip: FastAPI’s automatic docs are useful for client integration and quick testing.
