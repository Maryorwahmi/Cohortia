Methods
GET — retrieve data, should not change state
POST — create resources or perform stateful actions
PUT — idempotent update; may create if absent
DELETE — remove resource, often returns 204 on success
Status codes
200 OK — success (read or update)
201 Created — resource created
204 No Content — successful delete with no body
404 Not Found — resource missing
Example: For a PUT to /api/items/3, return 200 if updated, 201 if you created the item. Use 400 for bad input and 404 when the item id does not exist.
