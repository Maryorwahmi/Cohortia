Access patterns
Query params: request.args.get('key', default)
Form data: request.form.get('field')
JSON body: if request.is_json then data = request.get_json()
# Example inside a Flask view
if not request.is_json:
  return jsonify({"error": "Request must be JSON"}), 400

data = request.get_json()
name = data.get('name')
if not name:
  return jsonify({"error": "Missing 'name'"}), 400
Example
A POST to /api/data with a JSON body containing name and value should be checked with request.is_json and then parsed. Return 201 when created and 400 when the body is invalid.
Misconception: request.get_json always works. Always check request.is_json first.
