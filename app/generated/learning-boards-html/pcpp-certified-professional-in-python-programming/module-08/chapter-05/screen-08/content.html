Coroutines and await

async def say(name):
    await asyncio.sleep(0.1)
    print('Hello', name)

async def main():
    await asyncio.gather(say('A'), say('B'))

asyncio.run(main())
In this example, each say coroutine yields during the sleep. The event loop schedules both and they complete without threads.
Notes
  • Calling an async function returns a coroutine object; remember to await it or schedule it.
  • asyncio.run creates and closes the event loop for a script entry point.
Misconception
await is not an implicit thread switch. It yields control to the same thread's event loop.
Key Takeaway

Use async/await to express suspension points, and schedule coroutines with the event loop to achieve concurrency.
