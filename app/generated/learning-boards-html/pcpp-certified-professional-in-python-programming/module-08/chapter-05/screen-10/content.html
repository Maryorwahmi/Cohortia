Architecture › Executors
Pattern
loop = asyncio.get_running_loop()
result = await loop.run_in_executor(None, blocking_function, arg)
# or
result = await asyncio.to_thread(blocking_function, arg)
Both patterns schedule the blocking function on a separate thread and return its result without blocking the event loop. Choose to_thread for convenience when available.
Guidelines
  • Prefer async libraries to avoid executors entirely.
  • Use executors sparingly and size pools appropriately.
  • For CPU-bound tasks, consider process pools.
Key Takeaway

Offload blocking work to keep the loop responsive, but measure and plan thread or process resources carefully.
