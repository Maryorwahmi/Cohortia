Starter client code
async def chat_client():
    reader, writer = await asyncio.open_connection('127.0.0.1', 8888)
    while True:
        message = await asyncio.to_thread(input, 'You: ')
        if not message:
            continue
        writer.write(message.encode())
        await writer.drain()
        if message.lower() == 'quit':
            break
        data = await reader.read(100)
        if not data:
            break
    writer.close()
    await writer.wait_closed()
Scenario
Run server and client in separate terminals. Type messages and observe the echoed responses without blocking.
Checklist
  • Use asyncio.open_connection to get reader and writer.
  • Use asyncio.to_thread for blocking console input.
  • Await writer.wait_closed when closing the connection.
Common mistake
Calling input directly blocks the loop and prevents receiving network data.
