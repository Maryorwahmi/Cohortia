Assessment snippet
async def task_a():
    print('Task A: Starting...')
    await asyncio.sleep(0.5)
    print('Task A: Resuming after 0.5s.')

async def task_b():
    print('Task B: Starting...')
    await asyncio.sleep(0.3)
    print('Task B: Resuming after 0.3s.')
    time.sleep(0.1)  # Synchronous sleep
    print('Task B: Finishing.')
Predict the printed order. Running the code shows how the synchronous sleep delays the loop, changing the interleaving of messages. This demonstrates why blocking calls change expected concurrency behavior.
Hints
  • Mark each await as a potential suspension.
  • Notice that synchronous calls block the whole loop.
  • Compare timings to confirm your prediction.
Key Takeaway

Reading for await boundaries and blocking calls is the fastest way to reason about concurrency in asyncio programs.
