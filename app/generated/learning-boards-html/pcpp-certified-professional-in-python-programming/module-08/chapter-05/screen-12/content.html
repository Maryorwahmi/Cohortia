Hands-on Activity › Chat Client
Starter steps
  1. Save the echo server as echo_server.py and run it in one terminal.
  2. Implement chat_client using asyncio.open_connection and asyncio.to_thread for input.
  3. Write messages, await drain, and handle server disconnects.
  4. Type quit to close the session and await writer.wait_closed.
Starter code preview
reader, writer = await asyncio.open_connection('127.0.0.1', 8888)
message = await asyncio.to_thread(input, 'You: ')
writer.write(message.encode())
await writer.drain()
Testing tips
  • Open two terminals: run server and client separately.
  • Send several messages rapidly to observe concurrency.
  • Introduce a blocking call and observe how responsiveness degrades to see the difference.
Key Takeaway

Practice the client-server loop and observe how await points keep the server responsive even with many clients.
