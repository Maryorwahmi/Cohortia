Common Pitfall › Blocking Calls
Side-by-side comparison
async def a():
    print('start a')
    await asyncio.sleep(0.5)
    print('resume a')
async def b():
    print('start b')
    time.sleep(0.1)
    print('blocked b')
The left example yields control during sleep. The right example blocks the loop and prevents other coroutines from running while time.sleep executes.
Fixes
  • Use asyncio.sleep instead of time.sleep inside coroutines.
  • Offload blocking functions with loop.run_in_executor or asyncio.to_thread.
  • Prefer async-native libraries for I/O-heavy work.
Example fix
result = await loop.run_in_executor(None, blocking_function, arg) will run the blocking function in a thread and return its result without freezing the event loop.
