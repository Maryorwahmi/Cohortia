Process Flow › Echo Server
Code example
async def handle_echo(reader, writer):
    addr = writer.get_extra_info('peername')
    try:
        while True:
            data = await reader.read(100)
            if not data:
                break
            message = data.decode().strip()
            writer.write(data)
            await writer.drain()
            if message == 'quit':
                break
    except asyncio.CancelledError:
        print('handler cancelled')
    finally:
        writer.close()
        await writer.wait_closed()
Explanation
reader.read yields control while waiting. writer.drain is awaited to flush buffers. finally ensures closure.
Scenario
A client sends messages; server echoes them back until the client sends quit or disconnects.
Key points
  • Always await I/O awaitables to yield control.
  • Handle CancelledError for clean shutdowns.
  • Close and await writer.wait_closed to avoid socket leaks.
Key Takeaway

Treat streams as cooperative APIs: await reads and drains, and close writers in finally blocks.
