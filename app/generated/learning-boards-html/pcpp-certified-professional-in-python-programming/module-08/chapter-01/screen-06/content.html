Module 8 › Chapter 8.1 › TCP Server lifecycle
Step-by-step
  1. Create socket: socket.socket(AF_INET, SOCK_STREAM)
  2. Bind: s.bind((HOST, PORT)) to reserve address
  3. Listen: s.listen(backlog) to queue incoming connections
  4. Accept: conn, addr = s.accept() returns a new socket for the client
  5. Communicate: conn.recv and conn.send or conn.sendall
Key Takeaway

Separate accepting from handling; delegate per-client work to avoid blocking the listener.

Blocking points & mitigation
accept() blocks until a client connects. Use threads, processes, or async to avoid halting new accepts.
recv() blocks until data arrives. Use timeouts, non-blocking sockets, or separate workers for heavy operations.
Concrete example
with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
    s.bind((HOST, PORT))
    s.listen()
    conn, addr = s.accept()
    with conn:
        data = conn.recv(1024)
