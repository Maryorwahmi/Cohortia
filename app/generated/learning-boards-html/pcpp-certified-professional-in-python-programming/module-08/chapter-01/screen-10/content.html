Module 8 › Chapter 8.1 › Blocking & Timeouts
Strategies
  • Timeouts: socket.settimeout(seconds) and handle exceptions.
  • Non-blocking: socket.setblocking(False) and poll with select.
  • Delegation: use threads, processes, or async tasks for per-client work.
Example: set a short accept timeout on servers used for graceful shutdowns.
Code snippets
# set timeout
s.settimeout(5.0)

# non-blocking
s.setblocking(False)

# select-based polling
import select
rlist, _, _ = select.select([s], [], [], 1.0)
Choose the approach that matches your concurrency model and failure handling strategy.
