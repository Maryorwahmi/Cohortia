Blocking operations

Accept and recv pause execution until an event arrives. Learn timeouts and non-blocking modes to keep services responsive.

Mnemonic
Think "wait for call" for blocking; set a timer or hand off to another thread to avoid waiting forever.
Common pitfall
Not closing sockets can leave ports in TIME_WAIT, preventing quick restarts.
Error handling & graceful shutdown

Catch socket errors and use context managers to ensure close. Design a shutdown message like 'quit' to terminate chat loops cleanly.

Practical check
Test restart behavior after closing the server to verify no address-in-use errors occur.
Tip
Always encode strings before send and decode after recv to avoid type errors and unreadable output.
