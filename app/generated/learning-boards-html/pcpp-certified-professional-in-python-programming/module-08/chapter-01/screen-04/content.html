Module 8 › Chapter 8.1 › What is a socket?
Definition & core idea

A socket is an endpoint for network communication. It couples an address family and transport type and offers methods for binding, connecting, sending, and receiving bytes.

Analogy
Mailbox: IP and port identify where messages arrive. A listening socket opens the mailbox; an accepted socket is a private channel to a single client.
Common misconception
A listening socket is not the same as a connected socket. accept() returns a new socket for the client; the original keeps listening.
Key Takeaway

Treat sockets as resources you acquire and release; use context managers to ensure closure.

Quick reference
Address family
socket.AF_INET for IPv4; address is (host, port)
Socket types
SOCK_STREAM for TCP, SOCK_DGRAM for UDP
Example code snippet
import socket
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.bind(('127.0.0.1', 65432))
s.listen()
This sequence creates a TCP socket, binds it to localhost:65432, and starts listening for connections.
