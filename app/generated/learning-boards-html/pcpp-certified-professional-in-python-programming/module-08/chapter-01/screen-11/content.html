Module 8 › Chapter 8.1 › Error handling
Exceptions to handle
  • ConnectionRefusedError when peer isn't listening.
  • ConnectionResetError when peer forcibly closes the socket.
  • socket.timeout for operations that exceed set timeouts.
Practice: wrap sends and receives in try/except blocks, and close sockets in finally or use with.
Graceful shutdown pattern
Listen for a shutdown signal or a control message. Stop accepting new clients, tell workers to finish, close connections, and then close the listening socket.
Key Takeaway

Test for resource leaks by restarting servers quickly; use with and explicit closes to avoid address-in-use errors.
