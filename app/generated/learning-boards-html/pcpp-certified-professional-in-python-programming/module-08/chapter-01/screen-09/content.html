Encoding rules
Always call message.encode() before send and data.decode() after recv. Use UTF-8 unless you must interoperate with legacy encodings.
Common error: sending a str instead of bytes raises a TypeError. Encode to bytes to avoid this.
Framing approaches
  • Fixed-size messages
  • Length prefix (send length, then payload)
  • Delimiter-terminated messages (e.g., newline)
Example: recv loop for TCP
def recv_full(conn, length):
    buf = b''
    while len(buf) < length:
        chunk = conn.recv(1024)
        if not chunk:
            raise ConnectionError('peer disconnected')
        buf += chunk
    return buf
This pattern reads until the expected number of bytes is received or the peer disconnects.
