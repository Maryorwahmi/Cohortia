Proxies

Define proxies to route traffic but avoid sending secrets through untrusted intermediaries.

proxies = {
  'http': 'http://10.10.1.10:3128',
  'https': 'http://10.10.1.10:1080',
}
response = requests.get('http://example.org', proxies=proxies)
Timeouts

Always set a timeout to avoid indefinite blocking. Use a single value or a connect/read tuple.

try:
    response = requests.get('http://example.com', timeout=5)
    response.raise_for_status()
except requests.exceptions.Timeout:
    print('Timed out after 5 seconds')
SSL Verification

Keep verification enabled in production. For controlled tests, you can disable it but prefer a custom CA bundle.

# Not recommended in production
response = requests.get('https://self-signed.example', verify=False)
Key Takeaway

Timeouts and SSL verification are essential runtime safety checks; proxies must be trusted before use.
