Module 8 › Chapter 8.6 › POST / PUT / DELETE
POST — Create

Send a JSON body with the json parameter to create resources. The server usually returns a new id.

# Example: create a new post
post_data = {
  "title": "My New Blog Post",
  "body": "This is the content of my new post.",
  "userId": 1
}
# post_response = requests.post(url, json=post_data)
PUT — Update or Replace

Use PUT to update a resource at a known URL. PUT is idempotent: repeating it yields the same state.

# Example: update post id 1
# put_response = requests.put(f"{BASE_URL}/posts/1", json=updated_post_data)
DELETE — Remove

Delete removes the resource. Check the status code to confirm success; some APIs return no content.

# Example: delete post id 1
# delete_response = requests.delete(f"{BASE_URL}/posts/1")
Key Takeaway

Match the method to the intended action and consider idempotency when designing retries.
