Module 8 › Chapter 8.6 › GET & Response
Definition
GET returns resource representations
  • Response includes status code, headers, body.
  • Use raise_for_status to convert bad status codes into exceptions.
  • Parse JSON with the response json method when Content-Type is application/json.
Example
A GET to a public user endpoint returning JSON you parse for name and public repository counts.
import requests

try:
    response = requests.get('https://api.github.com/users/octocat')
    response.raise_for_status()
    print('Status Code:', response.status_code)
    user_data = response.json()
    print('User Name:', user_data.get('name', 'N/A'))
except requests.exceptions.RequestException as e:
    print('Request failed:', e)
Key Takeaway

Always check for HTTP errors before trusting response content and validate fields after parsing JSON.

Common Mistake

Assuming status code 200 means the payload matches your schema. Always check fields and types.

Check Your Understanding
  1. Why call raise_for_status before parsing?
  2. How would you confirm the JSON contains the keys you need?
Analogy
