Status Codes
  • 2xx indicates success; check specifics like 200, 201, 204.
  • 4xx indicates client errors; 401 means authentication issues.
  • 5xx indicates server errors to report and retry cautiously.
Headers & Content

Inspect Content-Type to decide whether to call json. Avoid assuming a payload is JSON without checks.

JSON Parsing
try:
    data = response.json()
except ValueError:
    # fallback: log raw text or handle as non-JSON
    raw = response.text
Key Takeaway

Treat the response as composed of status, headers, and body. Validate each step before use.
