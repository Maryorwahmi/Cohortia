Module 8 › Chapter 8.6 › Authentication
Basic

Basic auth sends credentials with the request. Use it carefully and prefer TLS for transport security.

# Basic Auth example
response = requests.get('https://api.github.com/user', auth=('your_username', 'your_token'))
print(response.status_code)
Token / Header

Place tokens in an Authorization header via a session or per-request headers for bearer token schemes.

OAuth Note

For OAuth flows, use a library that integrates with requests to manage redirects and token refresh. Implement secure storage for tokens.

Key Takeaway

Never embed secrets in code. Use environment-based configuration and rotate tokens when possible.
