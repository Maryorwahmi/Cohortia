Hands-on
POST with form data and JSON
import requests
post_url = 'https://httpbin.org/post'
payload = {'key1': 'value1', 'key2': 'value2'}

# Form-encoded
response = requests.post(post_url, data=payload)
print(response.status_code)
print(response.json()['form'])

# JSON body
json_payload = {'name': 'Cohortia User', 'email': 'user@cohortia.com'}
response = requests.post(post_url, json=json_payload)
print(response.status_code)
print(response.json()['json'])
Concrete example
httpbin echoes your submission so you can confirm whether data or json arrived as expected.
Common mistake
Sending a JSON object with data= will produce a form-encoded body and likely be rejected by an API expecting application/json.
Quick rules
data= sends form-encoded bodies by default
json= serializes and sets Content-Type to application/json
Always check response.status_code for 201 Created after POST
