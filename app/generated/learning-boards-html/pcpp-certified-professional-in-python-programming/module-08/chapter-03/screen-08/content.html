Hands-on
Basic GET example
import requests

response = requests.get('https://api.github.com/users/octocat')
print(f"Status Code: {response.status_code}")
print(f"Headers: {response.headers.get('Content-Type')}")
print(f"Content (raw bytes): {response.content[:50]}...")
print(f"Content (text): {response.text[:50]}...")

if response.status_code == 200:
    user_data = response.json()
    print(f"User Name: {user_data['name']}")
else:
    print(f"Error fetching data: {response.status_code}")
Concrete example
This GET fetches a user's public profile. Checking status avoids trying to parse an error page as JSON.
Common mistake
Calling response.json without verifying status may raise an error or return unexpected content when the server replies with HTML or an error message.
Response fields
response.status_code — integer HTTP status
response.headers — dict-like metadata
response.content — bytes
response.text — decoded string
response.json() — parsed JSON object
