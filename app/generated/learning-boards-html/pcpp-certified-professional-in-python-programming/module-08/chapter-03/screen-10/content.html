Authentication
Basic and token auth examples
import requests
from requests.auth import HTTPBasicAuth

# Basic auth
response = requests.get('https://httpbin.org/basic-auth/user/passwd', auth=HTTPBasicAuth('user','passwd'))
print(response.status_code)

# Bearer token
token = 'YOUR_API_TOKEN_HERE'
headers = {'Authorization': f'Bearer {token}', 'Content-Type': 'application/json'}
# response = requests.get('https://some.api.com/data', headers=headers)
Concrete scenario
When an endpoint returns 401, prompt for re-authentication or refresh the token. For 403, the credentials are valid but not permitted to access the resource.
Security reminders
  • Never hardcode credentials in code.
  • Use environment variables or a secrets manager.
  • Limit token scopes and rotate them regularly.
