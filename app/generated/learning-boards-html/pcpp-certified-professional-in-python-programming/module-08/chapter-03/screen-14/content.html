Wrap-up
Reliable request pattern
  1. Build request: method, URL, headers, auth, payload.
  2. Send with timeout.
  3. Verify status or call raise_for_status.
  4. Parse after confirming Content-Type.
  5. Handle exceptions and retries where appropriate.
Refactor challenge
Wrap repeated request logic into a helper that accepts method, URL and options and returns parsed JSON or raises a clear error.
Example helper sketch
def get_json(url, headers=None, timeout=5):
    response = requests.get(url, headers=headers, timeout=timeout)
    response.raise_for_status()
    if 'application/json' in response.headers.get('Content-Type', ''):
        return response.json()
    raise ValueError('Expected JSON response')
Use this helper to reduce duplication and ensure consistent checks across the codebase.
