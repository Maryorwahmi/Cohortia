Definition
Common headers
Content-Type
Declares the format of the request or response body. Set it explicitly when sending JSON or form data.
Authorization
Contains credentials such as Basic or Bearer tokens. Keep tokens out of source control and logs.
User-Agent
Identifies the client. Useful for debugging and analytics.
Cache-Control
Controls caching. Incorrect caching can cause stale data to be served.
Example header usage
headers = {
  'Authorization': 'Bearer <token>',
  'Content-Type': 'application/json',
  'User-Agent': 'cohortia-client/1.0'
}
Pro tip
Centralize header creation in one helper so sensitive headers are added only where necessary and can be audited or rotated easily.
