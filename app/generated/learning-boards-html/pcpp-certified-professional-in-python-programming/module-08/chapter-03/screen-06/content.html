Comparison
Status code categories
1xx — Informational
Handshake-like signals. Clients rarely act on them.
2xx — Success (e.g., 200, 201)
Proceed to parse the body as expected.
3xx — Redirection (e.g., 301, 302)
Follow Location or update the request URL if appropriate.
Client vs Server errors
4xx — Client errors (400, 401, 403, 404)
Indicates the request must change. Check parameters and auth.
5xx — Server errors (500, 503)
Server-side failure. Consider retry strategies for transient conditions.
Example decision
If you receive 404 when fetching a user, stop and surface the not-found result. If you receive 503, schedule a retry with backoff and log the event for monitoring.
