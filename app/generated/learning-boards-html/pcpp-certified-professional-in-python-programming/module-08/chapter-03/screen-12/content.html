Hands-on Challenge
Interact with JSONPlaceholder
Follow these steps in your local environment and verify each response.
BASE_URL = "https://jsonplaceholder.typicode.com"

# 1) Fetch posts
response = requests.get(f"{BASE_URL}/posts")
response.raise_for_status()
posts = response.json()
print(len(posts))
for post in posts[:5]:
    print(post['title'])

# 2) Create a new post
new_post = {'title': 'My New Cohortia Post', 'body': 'This is a test post from Cohortia.', 'userId': 1}
response = requests.post(f"{BASE_URL}/posts", json=new_post)
response.raise_for_status()
print(response.status_code)
print(response.json())

# 3) Update post 1
updated = {'id': 1, 'title': 'Updated Cohortia Title', 'body': 'This is a test post from Cohortia. Content has been updated.', 'userId': 1}
response = requests.put(f"{BASE_URL}/posts/1", json=updated)
response.raise_for_status()
print(response.status_code)
print(response.json())
Checklist while coding
  • Use response.raise_for_status after each request.
  • Print or inspect response.json to confirm fields.
  • Wrap calls in try/except for network errors.
Key Takeaway

Turn each lab step into a small assertion: successful status and expected JSON fields.
