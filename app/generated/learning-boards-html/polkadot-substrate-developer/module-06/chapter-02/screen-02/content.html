Learning Objectives

Skills to validate once you finish this chapter.

Learn → Understand → Apply → Master
01
Select provider & instance

Choose a cloud provider and instance type; match hardware to whether you run a full or validator node.

Verified competency milestone
02
Configure Linux server

Prepare an Ubuntu/Debian host: update packages and install Substrate build dependencies so you can compile on the instance.

Verified competency milestone
03
Secure SSH and harden server

Use SSH key authentication, restrict root, create non-root users, and configure UFW to allow only required ports.

Verified competency milestone
04
Run as systemd and monitor

Install a systemd unit to run the node persistently, capture logs with journalctl, and send telemetry to observe health and metrics.

Verified competency milestone
