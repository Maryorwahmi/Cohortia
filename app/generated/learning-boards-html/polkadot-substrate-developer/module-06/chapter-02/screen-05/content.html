Module 6 › Chapter 6.2 › SSH & OS Prep
Process

Connect and prepare

Establish SSH access, update packages, and install needed build dependencies.

Terminal commands (example)
ssh -i ~/.ssh/your_key.pem root@YOUR_SERVER_IP

sudo apt update && sudo apt upgrade -y

sudo apt install -y build-essential libssl-dev pkg-config clang curl git llvm
Replace placeholders with your key path and server IP. These commands update the OS and install common Substrate build tools.
Concrete scenario
You connect with your SSH key, run the update and install commands, then create a non-root user for running the node. This reduces the chance of accidental system changes and keeps service processes separate from administrative accounts.
Common mistake

Using password SSH or running the node as root increases security risk. Use key pairs and a dedicated user instead.

Key Takeaway

Secure SSH and install dependencies before you attempt to build or start the node to avoid build failures and exposure.
