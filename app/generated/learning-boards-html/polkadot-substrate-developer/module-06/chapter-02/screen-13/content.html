Module 6 › Chapter 6.2 › Hands-on Activity
Activity Steps
  1. Connect via SSH using your key pair and update the OS.
  2. Install build dependencies and clone the node template repository.
  3. Build the node in release mode or transfer a release binary.
  4. Create the persistent base path and assign permissions to the service user.
  5. Create the systemd service file, reload, enable, and start the service.
  6. Verify status, stream logs, and test local RPC before opening external access.
Example command snippets
sudo mkdir -p /var/lib/substrate-node
sudo chown -R your_user:your_user /var/lib/substrate-node
sudo systemctl daemon-reload
sudo systemctl enable substrate-node.service
sudo systemctl start substrate-node.service
sudo journalctl -u substrate-node.service -f
Reflection

After completing the activity, consider automating these steps with a provisioning script or infrastructure-as-code so deployments are repeatable.
