Telemetry + Metrics

Enable telemetry to publish node health and add Prometheus/Grafana for deeper metric tracking and alerts.

Telemetry flag
Add a telemetry URL to the node start options so telemetry services can collect and show your node entry.
Prometheus & Grafana
Scrape metrics for CPU, memory, disk I/O and node counters to build dashboards and alerts for capacity planning.
Concrete example
Start the node with a telemetry URL to have your node appear in telemetry listings. Combine that with journal logs and a Prometheus scrape to make an alert that triggers on sustained high disk I/O.
Key Takeaway

Logs are instant truth and telemetry plus metrics provide trend and alerting capabilities for stable operations.
