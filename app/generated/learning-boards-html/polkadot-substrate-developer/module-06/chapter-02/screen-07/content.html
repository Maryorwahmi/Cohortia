Module 6 › Chapter 6.2 › Firewall (UFW)
Process

UFW commands you will run

Enable UFW and add rules to allow SSH, P2P, and restricted RPC/WS access.

sudo ufw enable
sudo ufw allow ssh
sudo ufw allow 30333/tcp
sudo ufw allow from 192.168.1.0/24 to any port 9933
sudo ufw allow from 192.168.1.0/24 to any port 9944
sudo ufw status
Replace the CIDR with your trusted IP range. Confirm status before finishing.
Troubleshooting
If SSH is blocked by an incorrect rule, use your cloud provider's console to regain access, or schedule firewall changes during a maintenance window. Test RPC locally from the node before allowing remote access to ensure the service is listening correctly.
Common mistake

Opening RPC publicly makes your node accessible for control or data exfiltration. Always restrict RPC/WS to known IPs.

Key Takeaway

Apply minimal firewall rules: only the ports necessary for operation and only from trusted ranges where appropriate.
