Deploying a Substrate Node to the Cloud

Turn a compiled node into a resilient cloud service: instance selection, Linux setup, firewall rules, systemd service, and monitoring.

In this lesson
  • Choose provider and instance type suitable for full or validator nodes.
  • Prepare a secure Ubuntu/Debian server with SSH keys and firewall rules.
  • Build the node and run it as a persistent systemd service with monitoring.
Why it matters

Nodes must be resilient to reboots and network changes. Proper deployment ensures uptime, predictable logs, and secure RPC access for your dApp clients.
