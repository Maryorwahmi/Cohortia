Module 6 › Chapter 6.2 › SSH & Hardening
Definition

SSH key authentication

Asymmetric keys replace passwords for secure, automated remote access.

Create a non-root user
Operate the node under a dedicated account to reduce risk from user-level mistakes.
Disable root login
Prevent direct root SSH access in your SSH server configuration to force sudo-based elevation.
Scenario & tips
After adding your public key to the server, attempt a connection and confirm you can sudo as the non-root user. Then update SSH daemon settings to disallow password authentication and root login. Finally, verify UFW rules to ensure only expected ports are accessible.
Common mistake

Opening RPC and WebSocket ports publicly for convenience. Restrict these to trusted IPs instead.

Pro tip

Keep a separate admin key and rotate keys periodically; document which IPs require RPC access.
