Process

Create and assign a base path

Create /var/lib/substrate-node and set the service user as owner so the node can persist chain data.

sudo mkdir -p /var/lib/substrate-node
sudo chown -R your_user:your_user /var/lib/substrate-node
Replace your_user with the non-root account created earlier. Use mounted persistent volumes for long-lived data.
Best practice
Use a mounted block device for chain data rather than ephemeral local storage. This protects chain state across instance recreation and enables snapshots for recovery.
Key Takeaway

Ensure data is on a persistent volume and owned by the service user to survive reboots and to be managed by system backups.
