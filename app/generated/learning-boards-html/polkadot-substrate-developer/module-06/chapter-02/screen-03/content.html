Deployment Checklist

Follow these verifiable tasks as you deploy.

1. Instance selection
Match role to resources and provision SSD-backed storage with room to grow.
2. SSH and OS updates
Use SSH keys, update packages, and install Substrate build tools before compiling.
3. Firewall rules
Allow SSH and P2P port; restrict RPC and WebSocket to trusted IP ranges.
4. systemd & monitoring
Install a service unit for automatic restarts and connect telemetry for observability.
Use this checklist during the hands-on activity. Each item is a verification point you can sign off on as the node moves from test to production.
