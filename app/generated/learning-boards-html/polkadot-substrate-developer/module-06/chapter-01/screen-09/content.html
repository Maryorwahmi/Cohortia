Ports to know
Default ports referenced in the chapter: RPC 9933, WebSocket 9944, P2P 30333. Use these as starting points and restrict RPC/WS access.
Example ufw rules
sudo ufw allow 30333/tcp
sudo ufw allow from 10.0.0.0/24 to any port 9933/tcp
sudo ufw allow from 10.0.0.0/24 to any port 9944/tcp
sudo ufw enable
Best practices
  • Expose only P2P publicly. Place RPC/WS behind a proxy or restrict to trusted IPs.
  • Harden the OS: minimal services, regular updates, and SSH key authentication only.
  • Monitor access and log suspicious requests to detect abuse early.
Common mistake

Leaving RPC/WS open for convenience can expose admin endpoints and increase attack surface.
