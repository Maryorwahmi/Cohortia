Module 6 › Chapter 6.1 › Key Concepts
Chain Specification
A Rust file defining genesis state, initial accounts, module configs, and bootnodes.
Bootnodes
Pre-configured addresses used by new nodes to discover peers reliably.
Full Node
A node that stores the chain history and validates transactions and blocks.
Takeaway

These three concepts are the starting point for hardening configuration, coordinating bootstrapping, and sizing nodes for production.
