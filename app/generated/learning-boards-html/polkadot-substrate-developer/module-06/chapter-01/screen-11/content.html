Module 6 › Chapter 6.1 › Common Mistakes
Sudo in genesis
Including a pre-defined sudo key gives unilateral administrative power. Remove it or neutralize it so governance becomes the authority.
Using dev flags
Running with --dev or --tmp is fine for local testing but dangerous in production. Build release binaries and use production chain specs.
No monitoring
Lack of logs and telemetry prevents proactive responses. Integrate telemetry and log aggregation with alerting.
Bootnode misconfiguration
Unreliable or missing bootnodes make bootstrapping brittle. Provide a small set of stable multi-addresses and test them.
Under-provisioning archives
Archive nodes need more disk and backup planning. Treat them separately from full nodes.
Skipping rehearsals
Always test upgrades, load, and restore on a mirror testnet before touching production.
