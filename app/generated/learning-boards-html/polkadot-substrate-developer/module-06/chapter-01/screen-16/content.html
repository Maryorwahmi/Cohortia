Module 6 › Chapter 6.1 › Key Concepts
Archive Node
Retains all historical state. Used for analytics and historical queries, but requires heavy storage and backups.
Validator Node
Participates in consensus. Requires high availability and hardware-backed key security to avoid catastrophic compromise.
RPC / WS / P2P Ports
Default ports: RPC 9933, WS 9944, P2P 30333. Keep only P2P public and restrict RPC/WS to trusted hosts.
Final takeaway

Plan for storage, secure keys, and minimal public surface. Rehearse on a testnet before launching production nodes.
