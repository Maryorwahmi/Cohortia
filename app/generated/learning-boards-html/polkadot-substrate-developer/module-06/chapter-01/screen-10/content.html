Module 6 › Chapter 6.1 › chain_spec.rs Walkthrough
Step 1 — Remove SudoConfig

Locate the SudoConfig block in genesis and remove it or set key: None so no pre-defined sudo key exists in genesis.

Typical snippet to remove
pallet_sudo::GenesisConfig {
    key: Some(root_key),
},
Step 2 — Add bootnodes & adjust balances
Replace boot_nodes: None with a placeholder vector and reduce development balances to realistic amounts in pallet_balances::GenesisConfig.
Bootnode example
boot_nodes: Some(vec!["/ip4/127.0.0.1/tcp/30333/p2p/Qm...".into()]),
Balance example
// from 1 << 60 to a realistic value
("") => 1_000_000_000_000_000_000_000,
Build & run
cargo build --release
./target/release/node-template --chain local --alice --validator
