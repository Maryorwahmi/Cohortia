Executing Upgrade via `polkadot-js/apps`

Dispatching the `set_code` Extrinsic

Steps in `polkadot-js/apps`

  1. 1. Navigate to `Developer -> Sudo`.
  2. 2. Select `system` from the pallet dropdown.
  3. 3. Select `setCode(code)` from the extrinsic dropdown.
  4. 4. Upload your `node_template_runtime.wasm` file.
  5. 5. Click `Submit Sudo Transaction`.
  6. 6. Confirm the transaction.

Important Note:

Using `sudo` is for development only. In a production environment, this action would be initiated and approved through the chain's robust on-chain governance system, not by a single `sudo` account.
