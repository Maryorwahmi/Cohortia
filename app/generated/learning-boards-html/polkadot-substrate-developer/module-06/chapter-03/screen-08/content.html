Practical Step 1

Preparing for Upgrade: Compile Wasm

Generating the New Runtime Binary

The Compilation Command

cargo build --release \  --features runtime-benchmarks \  --target wasm32-unknown-unknown \  --manifest-path ./runtime/Cargo.toml
  • `--release`: Optimizes the build for production performance.
  • `--target wasm32-unknown-unknown`: Specifies WebAssembly as the compilation target.
  • Output: Generates `node_template_runtime.wasm` in `target/wasm32-unknown-unknown/release/`.

Terminal Output Example

   Compiling node-template-runtime v4.0.0-dev (./runtime)    Finished release [optimized] target(s) in 1m 23s

Why it matters:

This Wasm file is the new 'brain' of your blockchain. It contains all the updated logic that will be executed by every node in the network after the upgrade. Without this correctly compiled binary, an upgrade is impossible.

Key Takeaway

Compiling your runtime to Wasm is the foundational step for any forkless upgrade, creating the binary that will be uploaded to the chain and executed by all nodes.
