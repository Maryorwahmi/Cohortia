Governance Fundamentals

On-Chain Governance Overview

Decentralized Decision-Making for Critical Changes

Key Governance Components

  • Referenda: Public proposals voted on by token holders, ensuring broad community input.
  • Council: An elected body representing passive stakeholders, proposing referenda and fast-tracking.
  • Technical Committee: Experts for urgent bug fixes and critical upgrades, capable of fast-tracking proposals.

Governance Flow for Upgrades

Proposal Submission

Anyone can submit a proposal (e.g., new runtime Wasm).

Voting & Approval

Token holders, Council, or TC vote on the proposal.

Execution

Approved proposal is scheduled and `set_code` is dispatched.

Key Takeaway

Polkadot/Substrate governance balances decentralized input (Referenda) with elected representation (Council) and expert oversight (Technical Committee) to manage critical chain changes securely.
