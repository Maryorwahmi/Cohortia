Practical Step 3

Verifying the Upgrade

Confirming the New Runtime is Active

Verification Methods

  • `polkadot-js/apps`: Navigate to `Developer -> Chain state`, then query `system -> runtimeVersion()`.
  • Node Terminal Output: Look for messages indicating a new runtime has been detected and executed.
  • Key Check: Confirm `spec_version` or `impl_version` reflects your intended update.

Example `runtimeVersion()` Output:

{  specName: 'node-template',  implName: 'node-template',  authoringVersion: 1,  specVersion: 100,  implVersion: 2, // <-- This should be updated!  apis: [ ... ],  transactionVersion: 1,  stateVersion: 1}

Node Terminal Confirmation

2023-10-27 10:30:05.123  INFO New runtime: #100-2 (node-template)2023-10-27 10:30:05.123  INFO Executing new runtime at block #123456

Why it matters:

Verification is the final, critical step to ensure that your runtime upgrade was successful and that the blockchain is now operating with the new logic. This confirms the integrity and continuity of your chain's evolution.

Key Takeaway

Verifying the runtime version in `polkadot-js/apps` and observing node logs confirms the successful, instantaneous activation of your new on-chain runtime.
