Key Concepts (Continued)

More Essential Terms from This Chapter

Referendum

A public proposal that token holders can vote on to approve or reject changes to the chain, central to decentralized decision-making.

Council

An elected body of representatives in Polkadot/Substrate governance, responsible for proposing referenda and managing the treasury.

Technical Committee

A group of experienced developers and researchers who can fast-track urgent proposals, typically for critical bug fixes or security patches.

`spec_version`

A number in the runtime version indicating breaking changes to the runtime's storage format, requiring storage migrations.

`impl_version`

A number in the runtime version indicating non-breaking changes to the runtime's logic, such as minor bug fixes.

Chapter Summary

Polkadot/Substrate governance balances democratic input (Referenda, Council) with expert oversight (Technical Committee), while `spec_version` and `impl_version` are critical for managing runtime compatibility and storage migrations during upgrades.
