Upgrade Lifecycle

The Runtime Upgrade Process

From Development to On-Chain Execution

Key Stages of an Upgrade

01

Develop and Test

New runtime developed, thoroughly tested on local chains and testnets.

02

Propose

Compiled Wasm binary submitted as a proposal via governance (referendum, Council, or TC).

03

Vote/Approve

Token holders, Council, or Technical Committee vote on the proposal, ensuring consensus.

04

Schedule/Execute

Approved upgrade scheduled for a specific block; `set_code` dispatched automatically.

Key Takeaway

The runtime upgrade process is a carefully orchestrated sequence of development, proposal, voting, and execution, ensuring secure and community-supported evolution of the blockchain.
