The `set_code` Extrinsic

The Atomic Switch for On-Chain Runtime Updates

How `set_code` Works

  • Special Extrinsic: Exposed by the `System` pallet, it takes a new Wasm runtime as a parameter.
  • State Update: Calling `set_code` updates the chain's state to store the new Wasm blob.
  • Atomic Execution: At the next block, nodes automatically detect and execute the new runtime.
  • Governance Protected: Due to its power, access is always guarded by on-chain governance.

Key Takeaway

The `set_code` extrinsic is the core technical enabler for forkless upgrades, allowing for an atomic, instantaneous switch to new runtime logic, always secured by governance.
