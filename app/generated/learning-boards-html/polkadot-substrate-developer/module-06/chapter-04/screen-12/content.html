Launching Your Local Polkadot Network

Executing `polkadot-launch` and observing the network

The `polkadot-launch` Command

Simply run `polkadot-launch ` to start your local Polkadot Relay Chain and connected parachains.

Observing Terminal Output

Multiple terminal windows will open, showing block production and finalization for both the Relay Chain and your parachain collator.

Key Takeaway

Executing `polkadot-launch` brings your local Polkadot network to life, allowing you to observe real-time block production and verify your parachain's integration.

Terminal Command
polkadot-launch config.json
Expected Output (Simplified)

[polkadot-launch] Starting relaychain...

[polkadot-launch] Starting parachain 2000...

[alice] ✨ Imported #1 (0x...)

[parachain-collator01] ✨ Imported #1 (0x...)

[bob] ✨ Finalized #1 (0x...)

(Multiple terminal windows will open, each showing similar output for its respective node.)
