Configuration Deep Dive

Defining the Local Relay Chain

Understanding the `polkadot-launch` configuration file

`relaychain` Object

Defines the core Polkadot Relay Chain nodes and their configurations for your local network simulation.

Node Definitions

Each node (e.g., Alice, Bob) requires a name, WebSocket/RPC ports, P2P port, and specific flags like `--validator`.

Key Takeaway

The `relaychain` section of `config.json` is crucial for accurately simulating the Polkadot Relay Chain's behavior and validator setup locally.

`config.json` - Relay Chain Section
{
  "relaychain": {
    "defaultCommand": "polkadot",
    "chain": "rococo-local",
    "nodes": [
      {
        "name": "alice",
        "wsPort": 9944,
        "rpcPort": 9933,
        "port": 30333,
        "flags": ["--alice", "--validator"]
      },
      {
        "name": "bob",
        "wsPort": 9945,
        "rpcPort": 9934,
        "port": 30334,
        "flags": ["--bob", "--validator"]
      }
    ]
  },
  // ... parachains section ...
}
