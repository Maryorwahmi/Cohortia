Configuration Deep Dive

Integrating Your Parachain

Configuring your Substrate node as a local parachain

`parachains` Array

Defines each custom Substrate chain to be simulated as a parachain, including its executable path and unique ID.

Collator Node

Each parachain requires at least one collator node, configured with its own ports and the `--collator` flag.

Key Takeaway

Properly configuring the `parachains` section in `config.json` is vital for `polkadot-launch` to correctly spin up and connect your Substrate chain as a local parachain.

`config.json` - Parachains Section
{
  // ... relaychain section ...
  "parachains": [
    {
      "defaultCommand": "/path/to/your/node-template/target/release/node-template",
      "id": 2000,
      "chain": "dev",
      "nodes": [
        {
          "name": "parachain-collator01",
          "wsPort": 9946,
          "rpcPort": 9935,
          "port": 30335,
          "flags": ["--alice", "--collator"]
        }
      ]
    }
  ]
}
