#[weight = 10_000]
pub fn do_something(origin, value: T::Balance) -> DispatchResult {
    let sender = ensure_signed(origin)?;
    ensure!(value >= T::MinTransferAmount::get(), Error::ValueTooLow);
    let current_items = <Items<T>>::get(&sender).len();
    ensure!(current_items < T::MaxItemsPerUser::get() as usize, Error::TooManyItems);
    Ok(())
}
Notice how ensure! uses the Get trait for constants and how types are expressed as T::Balance so they match the runtime's concrete type.
Explanation
  • Ensure checks use T::MinTransferAmount::get() to enforce runtime-provided thresholds.
  • Storage access like <Items<T>> is typed to the pallet's Config so maps carry correct AccountId and item types.
  • If you need mutable parameters after launch, expose storage and a governance-controlled setter rather than baking them into Config alone.
Common mistake
Assuming all chains will use the same numeric width for Balance; rely on the Config trait bounds instead of casting arbitrarily.
