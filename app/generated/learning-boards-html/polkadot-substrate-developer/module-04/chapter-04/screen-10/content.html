construct_runtime! {
    pub enum Runtime where
        Block = Block,
        NodeBlock = opaque::Block,
        UncheckedExtrinsic = UncheckedExtrinsic,
    {
        System: frame_system::{Module, Call, Config, Storage, Event<T>},
        Balances: pallet_balances::{Module, Call, Storage, Config<T>, Event<T>, GenesisConfig},
        Registry: pallet_registry::{Module, Call, Storage, Event<T>, GenesisConfig},
    }
}

pub struct GenesisConfig {
    pub system: system::GenesisConfig,
    pub balances: pallet_balances::GenesisConfig,
    pub registry: pallet_registry::GenesisConfig,
}
The runtime's GenesisConfig includes each pallet's GenesisConfig entry. The Default implementation for the runtime's GenesisConfig typically supplies values used in development and can be adjusted for different deployments.
Deployment tip
For private deployments, edit the runtime's Default GenesisConfig; for public launches, prepare a carefully reviewed genesis specification file.
