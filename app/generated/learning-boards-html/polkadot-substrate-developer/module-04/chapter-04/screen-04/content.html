Definition

Config trait

A contract of associated types and constants the runtime fills in. It is how the pallet declares dependencies on runtime-provided items.

Why it matters
Keeps logic generic, enables reuse across chains, and exposes compile-time guarantees for types.
Misconception
Don't confuse Config constants with mutable on-chain parameters; Config values represent deployment choices, not necessarily governance-controlled storage.
Key Takeaway

Use Config to declare the surface your pallet needs from the runtime and avoid embedding deployment details in logic.

Example
<!-- Escaped Rust example -->
pub trait Config: frame_system::Config {
    type Event: From<Event<Self>> + Into<<Self as frame_system::Config>::Event>;
    type Balance: Parameter + Member + AtLeast32BitUnsigned + Codec + Default + Copy + MaybeSerializeDebug;
    #[pallet::constant]
    type MinTransferAmount: Get<Self::Balance>;
    #[pallet::constant]
    type MaxItemsPerUser: Get<u32>;
}
Use in code
Refer to T::Balance and T::MaxItemsPerUser::get() to access runtime settings.
Pro-tip
Mark items you expect the runtime to expose as #[pallet::constant] when they should be readable across the runtime and UI.
