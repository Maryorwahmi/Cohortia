Objectives — Practical steps

Four applied outcomes that you will practice in the hands-on activity and runtime wiring.

01 — Declare
Define MaxNameLength and type aliases in Config

Mnemonic: plug the type. This keeps the pallet generic and lets different chains choose different limits without changing pallet code.

02 — Enforce
Use T::MaxNameLength::get() in ensure! checks

Mnemonic: runtime guard. This prevents bad inputs and keeps invariants consistent across deployments.

03 — Seed
Create GenesisConfig{ initial_names: Vec<(Vec, T::AccountId)> }

Mnemonic: seed the map. Pre-populate StorageMap entries for deterministic initial state.

04 — Wire
Place your pallet's GenesisConfig into the runtime's GenesisConfig

Mnemonic: connect the builder. This ensures the runtime calls your build_storage at genesis and seeds the chain correctly.
