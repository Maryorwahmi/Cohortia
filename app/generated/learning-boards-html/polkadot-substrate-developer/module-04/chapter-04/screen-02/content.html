Learning Objectives

Learn, understand, apply, and prepare to integrate your configurable pallet with genesis seeding.

01 — Define Config

Declare associated types and constants in a pallet's Config trait so runtime developers plug in concrete types and values. Verified Competency Milestone

02 — Use Config items

Apply T::Type and T::Constant::get() inside dispatchables and storage logic to enforce runtime-provided constraints. Verified Competency Milestone

03 — Define GenesisConfig

Create a GenesisConfig struct to hold initial storage values and implement Default to provide safe defaults. Verified Competency Milestone

04 — Implement Build

Implement GenesisBuild<T> and the build_storage function to insert initial entries into StorageMap and StorageValue at chain genesis. Verified Competency Milestone

Bloom: Learn → Understand → Apply → Master
