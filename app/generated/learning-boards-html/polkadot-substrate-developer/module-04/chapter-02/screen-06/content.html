Module 4 › Chapter 4.2 › Designing Events
Step-by-step
  1. List meaningful state transitions you want to record.
  2. Choose minimal, useful payload fields for each event.
  3. Declare the enum with decl_event! and alias types from Config.
  4. Link type Event = Event; and emit with Self::deposit_event.
  5. Write tests that assert event emission and payload contents.
Example event set
AuctionCreated(creator, auction_id, item_id, starting_bid, end_block)
BidPlaced(auction_id, bidder, bid_amount)
AuctionEnded(auction_id, winner, final_bid)
Mnemonic
Think Create → Update → Close for lifecycle events.
