Module 4 › Chapter 4.2 › What are Events?
Definition & Why it matters
  • Events are on-chain logs that record occurrences without changing storage directly.
  • They are deterministic and included in the block's event list for indexers to consume.
  • Emit events for actions that UIs and off-chain services must react to, like transfers and creations.
Concrete example
A transfer dispatchable updates balances and then emits Transferred(sender, receiver, amount) so explorers and wallets show the action.
Common mistake
Relying on off-chain printouts or node logs provides no permanent audit trail and is not deterministic.
Example: declaring events
// Example of declaring events
decl_event! {
    pub enum Event where AccountId = <T as frame_system::Config>::AccountId,
                            Balance = <T as Config>::Balance {
        /// A token was transferred. (from, to, amount)
        Transferred(AccountId, AccountId, Balance),
        /// A new token was minted. (minter, amount)
        Minted(AccountId, Balance),
    }
}
Key Takeaway

Events make state changes discoverable for off-chain tools; always include them for meaningful state transitions.
