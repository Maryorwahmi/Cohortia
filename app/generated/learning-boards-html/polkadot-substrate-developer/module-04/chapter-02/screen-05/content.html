Module 4 › Chapter 4.2 › Emitting Events
Pattern
type Event = Event;

// After storage updates
Self::deposit_event(RawEvent::AuctionCreated(sender, auction_id, item_id, starting_bid, end_block));

// After updating bid
Self::deposit_event(RawEvent::BidPlaced(auction_id, bidder, bid_amount));
Emit concise, typed events after successful state changes. Tests should assert events to confirm behavior.
Supporting notes
  • Events are included in the block's receipts and are queryable by external tools.
  • Avoid emitting events before an operation that may later fail.
  • Prefer small payloads: include only fields consumers need to process updates.
Example scenario
When a bid succeeds, the UI can listen for BidPlaced to refresh current bid and bidder without re-fetching entire state.
