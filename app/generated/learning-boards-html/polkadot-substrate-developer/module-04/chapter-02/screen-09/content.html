Module 4 › Chapter 4.2 › Guard macros
Pattern examples
// Ensure auction exists
let (owner, item, current_bid, end_block) = <Auctions<T>>::get(auction_id)
    .ok_or(Error::AuctionDoesNotExist)?;

// Prevent bidding on own auction
ensure!(sender != *owner, Error::CannotBidOnOwnAuction);

// Require higher bid
ensure!(bid_amount > current_bid, Error::BidTooLow);

// Checked arithmetic
let new_id = current_id.checked_add(&T::AuctionId::from(1u32)).ok_or(Error::Overflow)?;
Explanation
  • ok_or converts Option into Err(Error) so you avoid unwraps.
  • ensure short-circuits with a clear error when conditions fail.
  • checked arithmetic prevents unchecked overflows and maps them to Overflow error.
Analogy
Think of ensure! as a gate: it either lets execution continue or returns a specific reason why it's stopped.
