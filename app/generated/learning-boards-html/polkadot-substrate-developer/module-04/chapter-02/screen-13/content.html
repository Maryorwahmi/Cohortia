Module 4 › Chapter 4.2 › Mistakes & Best Practices
Avoid
  • panic!, unwrap, expect inside dispatchables.
  • Generic errors like "Failed" without context.
  • Forgetting to emit events for important changes.
Prefer
  • Specific error variants and guard macros.
  • Checked arithmetic converted to errors.
  • Events emitted after successful commits.
Test
Write unit tests to assert both emitted events on success and precise error variants on failure.
