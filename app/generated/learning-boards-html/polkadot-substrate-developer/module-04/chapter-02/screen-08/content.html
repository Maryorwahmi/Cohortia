Module 4 › Chapter 4.2 › Custom Errors
Example declaration
decl_error! {
    pub enum Error for Module<T: Config> {
        AuctionDoesNotExist,
        BidTooLow,
        AuctionAlreadyEnded,
        CannotBidOnOwnAuction,
        Overflow,
    }
}
Best practices
  • Name errors to pinpoint the cause and include no ambiguous variants like Failed.
  • Use ensure! to guard conditions and ok_or to convert Option/Result into errors.
  • Avoid panicking inside runtime code; return DispatchResult::Err instead.
Avoid
Unwraps, expect, and panic inside dispatchables — they are unsafe for the chain.
