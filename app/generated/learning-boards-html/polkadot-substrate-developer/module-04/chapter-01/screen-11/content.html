Common safety idioms

  • Use ensure! to fail early on invalid inputs.
  • Use checked_add/checked_sub for numeric operations and convert None into a clear error.
  • Handle Option returns explicitly with pattern matching or unwrap_or_default only when defaulting is safe.
// safety pattern (pseudocode)
let sender_bal = Self::balances(&sender);
ensure!(sender_bal >= amount, Error::InsufficientBalance);
let new_sender = sender_bal.checked_sub(&amount).ok_or(Error::Overflow)?;
Misconception
Using unwrap in production code or assuming a value exists can cause panics or insecure behavior. Always make absence explicit.
Key Takeaway

Be explicit about missing values and use checked arithmetic for all numeric updates.
