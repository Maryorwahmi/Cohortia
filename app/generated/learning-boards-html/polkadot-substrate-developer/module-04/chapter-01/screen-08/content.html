Process

approve and disapprove

Insert an approval for an owner-spender pair and remove it when needed. Validate ownership and keep operations minimal.

// approve (pseudocode)
let owner = ensure_signed(origin)?;
ensure!(owner == current_owner_of(nft), Error::NotNftOwner);
Self::NftApprovals::insert((&nft_id, &approved_spender), ());
// disapprove
Self::NftApprovals::remove((&nft_id, &disapproved_spender));
Notes
  • Use unit value when presence alone indicates approval.
  • Remove approvals on transfer to avoid stale permissions.
  • Avoid storing many approvals in a single vector under an owner.
Key Takeaway

Direct insert/remove on the double map keeps approvals efficient and auditable.
