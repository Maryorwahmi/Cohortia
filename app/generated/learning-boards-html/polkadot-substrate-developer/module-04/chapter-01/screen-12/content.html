Storage declarations to add

// inside decl_storage!
NftOwner: map hasher(blake2_128_concat) T::NftId => T::AccountId;
NftApprovals: double_map hasher(blake2_128_concat) T::NftId,
                        hasher(blake2_128_concat) T::AccountId => ();
Use unit type for approvals where presence indicates permission. These declarations give you get, insert, remove, and contains_key helpers for concise code in dispatchables.
Function updates
  • create_nft: after increment, call NftOwner::insert(nft_id, sender).
  • transfer_nft: read owner with NftOwner::get and ensure caller is owner or NftApprovals::contains_key.
  • transfer_nft: insert new owner and remove any NftApprovals entry for that nft id and previous spender.
  • approve_nft/disapprove_nft: insert/remove approval pair respectively.
Key Takeaway

Implement per-item ownership and per-item approvals for clear, efficient on-chain queries.
