Declare Allowance and common usage

A double map declaration takes two hashers and two key types, then the value. Use the generated helpers with a pair of keys when reading or writing.

// Example Allowance StorageDoubleMap (rust-like pseudocode)
decl_storage! {
    trait Store for Module<T: Config> as Assets {
        Allowance get(fn allowance): double_map
            hasher(blake2_128_concat) T::AccountId,
            hasher(blake2_128_concat) T::AccountId
            => T::Balance;
    }
}

// Access examples:
let amount = Self::Allowance::get((&owner, &spender));
Self::Allowance::insert((&owner, &spender), new_amount);
Self::Allowance::remove((&owner, &spender));
Why it matters
  • Directly query an owner-spender pair without scanning all approvals.
  • Remove approvals when state changes to avoid leaked permissions.
  • Prefer double map over nested maps for cleaner runtime access and fewer reads.
Key Takeaway

Model dual-key relationships with StorageDoubleMap to keep lookups constant time and code simple.
