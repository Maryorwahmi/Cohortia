Declare Balances and common access pattern

The declaration creates get and insert helpers. Use get to read, contains_key when you only need presence, and insert to write the updated value after safe arithmetic.

// Example Balances StorageMap (rust-like pseudocode)
decl_storage! {
    trait Store for Module<T: Config> as Balances {
        Balances get(fn balances): map hasher(blake2_128_concat) T::AccountId => T::Balance;
    }
}

// In a transfer dispatchable:
let sender_balance = Self::balances(&sender);
ensure!(sender_balance >= amount, Error::InsufficientBalance);
let to_balance = Self::balances(&to);
let new_sender = sender_balance.checked_sub(&amount).ok_or(Error::Overflow)?;
let new_to = to_balance.checked_add(&amount).ok_or(Error::Overflow)?;
Self::Balances::insert(&sender, new_sender);
Self::Balances::insert(&to, new_to);
Explanation
  • Use blake2_128_concat hasher for general keys for safety and range queries.
  • Prefer contains_key when you only need to know if an entry exists.
  • Use checked arithmetic to prevent overflow/underflow and ensure! to validate preconditions.
Key Takeaway

Always handle missing keys and arithmetic safely before writing to storage.
