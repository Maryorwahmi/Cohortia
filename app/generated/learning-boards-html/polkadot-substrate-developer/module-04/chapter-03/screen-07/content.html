Hooks vs Off-chain Workers
A concise comparison to decide where logic should run.
Runtime Hooks
  • Deterministic, executed by every validator.
  • Fast, bound CPU and storage work.
  • Good for scheduled state changes and cleanups.
Example
Expire an offer exactly at block X and update a counter.
Off-chain Workers
  • Run off the Wasm runtime on node threads (std feature).
  • Allow HTTP, heavy compute, and non-deterministic work.
  • Submit signed transactions back to the chain for deterministic effect.
Example
Fetch a price feed, aggregate results, and submit the median price on-chain.
Best practices
Validate OCW data on-chain.
Use aggregation or signatures to reduce trust on one node.
Keep hooks lightweight and bounded.
