Key Concepts — Quick Reference
Three short reminders for design decisions.
Determinism
Hooks must run identically across validators; avoid non-deterministic operations.
Off-chain capabilities
OCWs allow HTTP and heavy compute but operate outside consensus until they submit a transaction.
Verification
Use aggregation, signatures, or challenge windows to defend against malicious reporters.
Final thought

Design your pallet so the runtime handles deterministic state progression and OCWs extend functionality safely with clear verification rules.
