offchain_worker: fetching HTTP and parsing JSON
Use offchain HTTP primitives and robust parsing before submitting a signed call.
Fetch pattern
// Pseudocode for OCW HTTP let request = sp_runtime::offchain::http::Request::get(&url); let pending = request.send().map_err(|_| ...)?; let response = pending.wait().map_err(|_| ...)?; let body = response.body().collect::>(); // Parse JSON and extract numeric field
Remember to handle send() and wait() errors, and respect timeouts and rate limits on external APIs.
Parsing & conversion
Deserialize a simple struct with serde or manually parse bytes. Convert floats to a scaled integer if you want fixed-point on-chain storage (for example multiply by 100 to preserve two decimals). Validate ranges and freshness before preparing the Call.
Key Takeaway

Make HTTP requests and parse responses robustly, then convert values into safe on-chain representations before creating signed transactions.
