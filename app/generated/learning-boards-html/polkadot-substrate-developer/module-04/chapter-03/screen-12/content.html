OCW safety patterns and mitigations
Strategies to validate and harden external data before it affects state.
Aggregation
Require multiple independent OCWs to report and derive a median or consensus before accepting a value on-chain.
Cryptographic proofs
Verify signed data from trusted providers or use threshold signatures so on-chain logic can validate authenticity.
Challenge & reputation
Use delays or disputes to give others time to challenge bad data and track reporter reliability when relevant.
Checklist before accepting OCW data on-chain
  • Can values be verified cryptographically?
  • Can multiple reporters be aggregated?
  • Is there a challenge window for disputes?
  • Is there a fallback if no signer is available?
