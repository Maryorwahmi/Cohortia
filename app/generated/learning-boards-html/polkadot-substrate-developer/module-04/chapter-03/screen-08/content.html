Off-chain Worker basics
Run non-deterministic or heavy tasks off-runtime and submit results via transactions.
OCW lifecycle
  1. Node calls offchain_worker(block_number) at block start (std feature).
  2. OCW checks timing (e.g., every N blocks) and local conditions.
  3. Perform HTTP/local compute; prepare Call and sign it using Signer.
  4. Submit signed transaction; on-chain validation applies the change deterministically.
Safety note
OCWs are not consensus actors; always validate submitted data on-chain through aggregation, signatures, or on-chain checks.

Key Takeaway

OCWs let you gather external information and submit deterministic updates via signed transactions — but on-chain verification is essential.
