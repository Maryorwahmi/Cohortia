Implementing Hooks and Off-chain Workers
When to run logic inside the runtime, and when to move it off-chain for safety and scale.
In this lesson you will compare deterministic block hooks with off-chain workers, implement examples, and discuss security mitigations.
Runtime Hooks
Deterministic, fast, part of block execution
Off-chain Workers
Non-deterministic tasks, HTTP, heavy compute
Explore Key Topics
Hooks
Deterministic functions executed during block processing, must be lightweight.
OCWs
Run on node threads, can call HTTP and prepare signed transactions.
Security
Mitigate bad OCW data with aggregation, proofs or challenge periods.
