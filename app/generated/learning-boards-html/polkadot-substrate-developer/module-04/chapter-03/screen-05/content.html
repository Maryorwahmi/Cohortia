Definition on_initialize
on_initialize — deterministic scheduler
A small, precise hook that runs before any transactions in a block.
Pattern
  • Accept block_number and run only cheap, deterministic checks.
  • Avoid scanning large storage; restrict work to items scheduled for this block.
  • Return a weight representing the actual resource cost.
Misconception
on_initialize is not a place for network calls or heavy computation that could vary between nodes.
Concrete example

Key Takeaway

Design on_initialize for predictable, bounded updates and move heavy or external tasks out of the runtime.
