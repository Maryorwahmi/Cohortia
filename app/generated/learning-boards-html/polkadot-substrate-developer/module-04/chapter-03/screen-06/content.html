Definition on_finalize
on_finalize — summaries and cleanup
Use final block state for summarizing and safe cleanup.
When to use on_finalize
  • Emit final summary events after all transactions applied.
  • Remove temporary storage entries created earlier in the block.
  • Update aggregates that require seeing the post-transaction state.
Practical hint
If the work requires heavy computation, schedule it to an OCW and accept a validated transaction later.
Concrete scenario
A ledger tracks micro-transfers during the block. After all transfers settle, on_finalize computes a compact reward snapshot and emits an event so external indexers can pick it up. Because the computation is bounded and deterministic, it’s safe in the runtime. If calculation would be expensive or require external data, delegate to an OCW instead.
Key Takeaway

Use on_finalize for deterministic final-state updates; avoid heavy computation and I/O.
