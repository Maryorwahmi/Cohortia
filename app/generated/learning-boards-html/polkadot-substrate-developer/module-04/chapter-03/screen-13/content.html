Terminal demo setup and observation
Configure and watch a running node to see OCW activity in real time.
Run commands (example)
# build node with std cargo build --release --features std # run node with offchain logging RUST_LOG=runtime::offchain=debug ./target/release/node-template --dev
Watch for log lines indicating OCW HTTP send/wait calls, signer get/send results, and transaction submission outcomes.
What to look for
  • HTTP request sent and response code received.
  • Parsed payload logs (for demo, the title field).
  • Signer found and transaction submission success or error.
Key Takeaway

The terminal is the most direct feedback loop for OCWs during development; logs reveal network, parse, and signing behavior.
