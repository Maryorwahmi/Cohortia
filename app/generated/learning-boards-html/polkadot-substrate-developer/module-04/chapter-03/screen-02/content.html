Module 4 › Chapter 4.3
Learning Objectives
Master practical patterns for hooks and Off-chain Workers and know when each is appropriate.
01
Runtime Hooks
Explain hook types and lifecycle timing
You will describe on_initialize and on_finalize, when they run, and why determinism matters. This gives you the ability to choose where to place state changes that must be part of consensus.
VERIFIED COMPETENCY MILESTONE
02
Implement Hooks
Write on_initialize and on_finalize
You will implement example hooks that run every N blocks and learn to keep them efficient and safe by returning accurate weight estimates.
VERIFIED COMPETENCY MILESTONE
03
Off-chain Workers
Implement a basic OCW
You will fetch external JSON, parse values, and assemble a signed transaction that can be submitted back to the chain safely.
VERIFIED COMPETENCY MILESTONE
04
Security & Design
Choose hooks vs OCWs correctly
You will identify misuse patterns and mitigation strategies, such as multiple oracle aggregation and signed payload verification to protect on-chain state.
