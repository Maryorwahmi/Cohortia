Enabling OCWs and AppCrypto
Register your OCW key type and implement the AppCrypto glue.
What to add
  • Define KEY_TYPE constant for OCW keys.
  • Use app_crypto! to create concrete Public/Signature types.
  • Implement AppCrypto trait under cfg(feature = "std") for AuthId.
Runtime note
OCWs only run in the std environment. Build and run a node with std support to test them.
Example (sketch)
// KEY_TYPE and app_crypto! macro pub const KEY_TYPE: KeyTypeId = KeyTypeId(*b"ocwp"); app_crypto!(sr25519, KEY_TYPE); #[cfg(feature = "std")] impl frame_system::offchain::AppCrypto for AuthId { type RuntimeAppPublic = Public; type GenericSignature = sp_core::sr25519::Signature; type GenericPublic = sp_core::sr25519::Public; }
Handle missing signer: check Signer::any_account() and log or skip submission when None.
