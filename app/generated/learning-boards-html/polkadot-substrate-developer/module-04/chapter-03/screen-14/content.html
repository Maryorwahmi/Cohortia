Key Concepts
Three compact concept cards and a final takeaway.
Runtime Hooks
Deterministic functions like on_initialize and on_finalize that run in the runtime.
Off-chain Workers
Node-local threads that perform HTTP and heavy work, then submit signed transactions.
Validation & Safety
Aggregate reports, verify signatures, and add challenge periods to trust OCW data before acceptance.
Summary

Design deterministic state changes as hooks and delegate external, heavy, or non-deterministic tasks to Off-chain Workers that submit validated signed transactions back to the chain.
