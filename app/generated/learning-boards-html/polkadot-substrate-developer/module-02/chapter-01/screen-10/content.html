System Dependencies for macOS and Windows

Tailoring dependency installation for different operating systems.

macOS Installation (Homebrew)

brew install cmake pkg-config openssl

Use Homebrew to install cmake, pkg-config, and openssl on macOS.

Windows Recommendation: WSL2

For Windows users, the recommended approach is to use Windows Subsystem for Linux (WSL2). This provides a robust Linux-like development experience, allowing you to follow the Linux installation steps within your WSL2 environment.

WSL2 offers better compatibility and avoids complex native Windows setup issues for Substrate.

Key Takeaway

Leverage platform-specific package managers (Homebrew) or virtualized environments (WSL2) for seamless dependency installation.
