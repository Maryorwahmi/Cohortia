Learning Objectives

What you'll achieve in this chapter.

LearnUnderstandApplyMaster
01

Install Rust & Toolchains

Gain the ability to install the Rust programming language and its essential toolchains, including `rustup`, which is critical for Substrate development. This skill ensures your system has the core language components needed.

VERIFIED COMPETENCY MILESTONE
02

Configure System Dependencies

Learn to set up your development environment with all necessary system dependencies, such as `cmake` and `libssl-dev`. This ensures that your Rust projects can link against required libraries and compile successfully.

VERIFIED COMPETENCY MILESTONE
