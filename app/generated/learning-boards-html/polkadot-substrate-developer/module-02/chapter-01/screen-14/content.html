Key Concepts

Essential terms to remember from this chapter.

Rustup

The primary tool for installing and managing Rust toolchains and compilation targets.

Toolchain

A specific version of the Rust compiler and its associated tools (e.g., stable, beta, nightly).

Nightly Toolchain

An experimental Rust toolchain with the latest features and optimizations, often required by Substrate.

Summary Takeaway

Mastering rustup and understanding the role of different toolchains, especially nightly, is foundational for Substrate development.
