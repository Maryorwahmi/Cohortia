The Heart of Your Blockchain: The `runtime`

Defining State Transition and Wasm Compilation

  • Core Logic: Contains all rules for transaction processing, state storage, and block validation.
  • State Transition Function: Defines how the blockchain's state evolves with each new block.
  • WebAssembly (Wasm): The entire runtime is compiled into a Wasm blob.
  • On-Chain Upgrades: Wasm blob is stored on-chain, enabling forkless runtime upgrades without hard forks.
Key Takeaway

The `runtime` is the definitive rulebook of your blockchain, compiled to Wasm for secure, efficient, and upgradeable on-chain execution.

Runtime Logic Flow

1. Define Transaction Rules

How transactions are structured and validated.

2. Manage State Updates

How data is stored and modified on-chain.

3. Validate New Blocks

Ensure blocks adhere to consensus rules.

4. Compile to Wasm

Generate a WebAssembly blob for execution.

5. On-Chain Storage & Upgrade

Store Wasm on-chain for forkless updates.
