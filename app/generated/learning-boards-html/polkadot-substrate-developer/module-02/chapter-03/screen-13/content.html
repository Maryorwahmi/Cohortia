Avoiding Pitfalls

Navigating Common Substrate Mistakes

Distinguishing Roles and Correct Modification Points

Confusing Node & Runtime

The `runtime` defines *what* the chain does, while the `node` defines *how* it does it (execution, networking).

Modifying Node for Chain Logic

Chain behavior changes should be implemented in `pallets` within the `runtime`, not in the `node` client code.

Incorrect `Cargo.toml` Dependencies

Ensure all new pallets and features have their dependencies correctly declared in the relevant `Cargo.toml` files.

Key Takeaway

A clear understanding of the distinct roles of `node`, `runtime`, and `pallets`, along with proper dependency management, is crucial for avoiding common development pitfalls in Substrate.
