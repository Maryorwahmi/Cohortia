Key Concepts

Essential Terms to Remember

Runtime

The core logic defining a Substrate blockchain's state transition function, compiled into a WebAssembly (Wasm) blob.

Node

The client-side application that executes the runtime, handling networking, RPC, block production, and local database management.

Pallet

A modular, self-contained piece of runtime logic that provides specific functionalities to the blockchain, such as balances or governance.

Summary Takeaway

The Substrate Node Template is structured around the `Runtime` (chain logic), the `Node` (execution environment), and `Pallets` (modular features), enabling a flexible and upgradeable blockchain.
