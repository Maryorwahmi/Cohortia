Key Concepts

Essential Terms to Remember

WebAssembly (Wasm)

A binary instruction format used by Substrate to compile runtimes for efficient, portable, and secure execution.

Forkless Runtime Upgrades

The ability to upgrade a blockchain's runtime logic without requiring a hard fork, enabled by storing the Wasm runtime on-chain.

Cargo.toml

Rust's manifest file used to declare project metadata, dependencies, and build configurations for Substrate components.

Summary Takeaway

Wasm and on-chain runtime storage enable Substrate's unique forkless upgrade capability, while `Cargo.toml` is essential for managing the project's dependencies and build process.
