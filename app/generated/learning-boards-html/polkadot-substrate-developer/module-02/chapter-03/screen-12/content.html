Managing Dependencies with `Cargo.toml`

Rust's Manifest Files for Workspace and Components

  • Rust's Manifest: Similar to `package.json` for managing project metadata.
  • Workspace Definition: Top-level `Cargo.toml` defines the entire project workspace.
  • Component-Specific: `node/Cargo.toml`, `runtime/Cargo.toml`, and `pallets/pallet-template/Cargo.toml` define dependencies for their respective parts.
  • Crucial for Dependencies: Essential for declaring external libraries and other pallets.
Key Takeaway

Correctly configuring `Cargo.toml` files at various levels is fundamental for managing dependencies and ensuring your Substrate project compiles and links correctly.

Cargo.toml Hierarchy
# Top-level Cargo.toml
[workspace]
members = [
    "node",
    "runtime",
    "pallets/template",
]

# runtime/Cargo.toml
[dependencies]
frame-system = { version = "3.0.0", default-features = false }
pallet-balances = { version = "3.0.0", default-features = false }
# ... other runtime dependencies

# pallets/pallet-template/Cargo.toml
[dependencies]
frame-support = { version = "3.0.0", default-features = false }
frame-system = { version = "3.0.0", default-features = false }
# ... pallet-specific dependencies
Different `Cargo.toml` files manage dependencies for the workspace, runtime, and individual pallets.
