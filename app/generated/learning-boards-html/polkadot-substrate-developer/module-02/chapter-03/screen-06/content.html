Runtime Composition

Composing Your Runtime with `lib.rs`

The Main Entry Point for Pallet Integration

  • Central Hub: The primary file for assembling all runtime logic.
  • Pallet Integration: Where individual pallets are declared and configured.
  • `construct_runtime!` Macro: A powerful tool used to compose and order pallets.
  • Defines Chain Features: Directly impacts the entire feature set and behavior of your blockchain.
Key Takeaway

`runtime/src/lib.rs` is where you define the specific combination of pallets that form your blockchain's unique functionality, acting as the blueprint for your chain's behavior.

runtime/src/lib.rs
// Import necessary pallets
use pallet_balances;
use pallet_system;

// ... other configurations ...

construct_runtime!(
    pub enum Runtime where
        Block = Block,
        NodeBlock = opaque::Block,
        UncheckedExtrinsic = UncheckedExtrinsic,
    {
        System: pallet_system,
        Balances: pallet_balances,
        // Add your custom pallets here
        // MyCustomPallet: pallet_my_custom_pallet,
    }
);
This snippet shows how `construct_runtime!` brings together `System` and `Balances` pallets.
