Client-Side Execution

The `node` Client: Executing Your Blockchain

Networking, RPC, and Block Production

  • Network Communication: Manages peer-to-peer connections with other nodes.
  • RPC Interfaces: Exposes APIs for external applications to interact with the chain.
  • Block Production: Handles the creation of new blocks (e.g., mining or staking).
  • Database Management: Stores the local copy of the blockchain state.
  • Runtime Executor: Fetches and executes the `runtime`'s Wasm blob.
Key Takeaway

The `node` is the operational layer of your blockchain, providing the essential services and infrastructure for the `runtime` to function and interact with the wider network.

Node Client Responsibilities

Peer-to-Peer Networking

Connects to and communicates with other nodes.

RPC Interface

Enables external applications to query and send transactions.

Block Production

Creates new blocks based on consensus rules.

Local Database Management

Stores the blockchain's historical data and current state.
