Module 2›Chapter 2.2›Understanding the `--dev` Flag

What `--dev` Does

  • Development Chain Spec: Uses a simplified, pre-configured chain.
  • Fast Block Production: Generates blocks quickly for rapid testing.
  • Pre-funded Accounts: Often includes accounts like 'Alice' with initial tokens.
  • Local Focus: Designed for isolated, single-node development.
Example Scenario

You're building a new pallet and need to test its functionality. Running with --dev allows you to quickly deploy your changes and see them reflected in new blocks without waiting for a slow consensus process.

Key Takeaway

The --dev flag streamlines local development by providing a fast, pre-configured, and isolated blockchain environment.

Benefits for Developers

  • Rapid Iteration: Test code changes almost instantly.
  • Predictable Environment: Consistent state for testing.
  • Simplified Setup: Less configuration needed to get started.
Misconception

The --dev flag is not inherently insecure for local development; it's designed for convenience and speed in a controlled environment, not for public networks.
