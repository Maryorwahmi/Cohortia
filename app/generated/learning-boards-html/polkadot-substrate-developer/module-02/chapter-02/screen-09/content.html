Module 2›Chapter 2.2›Running Your Substrate Node
Terminal Commandbash
# Run the compiled node with development flags
./target/release/node-template --dev --tmp
Command Breakdown
  • ./target/release/node-template: Path to the executable.
  • --dev: Development mode configuration.
  • --tmp: Temporary database usage.

What Happens Next?

  • Node Startup: The Substrate node initializes.
  • Block Production: It begins generating and finalizing blocks rapidly.
  • Log Messages: You'll see a stream of output indicating its activity.
Stopping the Node

You can stop the running node at any time by pressing Ctrl+C in the terminal where it's executing.

Key Takeaway

Running the node with --dev --tmp provides a quick, isolated, and disposable local blockchain environment perfect for development and testing.
