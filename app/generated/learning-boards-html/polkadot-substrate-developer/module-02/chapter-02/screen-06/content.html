Module 2›Chapter 2.2›Navigating to the Project Directory
Terminal Commandbash
# After cloning, change into the new directory
cd substrate-node-template

# You are now inside the project folder
# Your terminal prompt might show the current directory, e.g.,
~/substrate-projects/substrate-node-template$
Command Explained

The cd command changes your current working directory to substrate-node-template, allowing you to execute commands within the project's context.

Why is this important?

  • Cargo Context: Cargo needs to find the project's Cargo.toml file.
  • File Access: Ensures commands operate on files within the project.
  • Organization: Keeps your terminal session focused on the current project.
Common Error

Attempting to run cargo build outside the project directory will result in a "no Cargo.toml found" error.

Key Takeaway

Always navigate into your project directory using cd before running project-specific commands like compilation.
