# Compile the Substrate node in release mode
cargo build --release
Command Explained

cargo build invokes the Rust compiler. The --release flag tells Cargo to build an optimized executable, suitable for performance testing.

Why --release?

  • Performance: Generates a faster, optimized binary.
  • Error Detection: Catches certain types of errors that might not appear in debug builds.
  • Production Readiness: Closer to what you'd deploy in a real environment.
Output Location

The compiled executable, typically named node-template, will be found in the target/release/ directory within your project.

Key Takeaway

cargo build --release is the standard command for compiling an optimized Substrate node executable, essential for efficient operation.
