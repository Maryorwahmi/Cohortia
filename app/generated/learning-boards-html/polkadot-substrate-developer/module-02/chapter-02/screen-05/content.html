Module 2›Chapter 2.2›Cloning the Node Template
Terminal Commandbash
# Navigate to your projects directory (example)
cd ~/substrate-projects

# Clone the official Substrate Node Template repository
git clone https://github.com/substrate-developer-hub/substrate-node-template.git
Command Explained

The git clone command downloads the entire repository, creating a new directory named substrate-node-template in your current location.

Why Clone?

  • Access Source Code: Get all the necessary files for the Node Template.
  • Version Control: Git tracks changes, making updates and collaboration easier.
  • Standard Practice: The common way to start with open-source projects.
Pro Tip

Always clone into a dedicated, organized directory to keep your development environment clean and manageable.

Key Takeaway

git clone is your first step to getting the Substrate Node Template onto your local machine, providing the foundation for your development.
