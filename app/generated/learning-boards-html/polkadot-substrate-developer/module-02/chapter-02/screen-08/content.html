Why Does it Take So Long?

  • Extensive Dependencies: Substrate relies on many Rust crates.
  • First-Time Download: All dependencies must be downloaded and compiled initially.
  • Optimization: Release mode compilation adds extra processing time.
  • System Resources: CPU and internet speed impact overall duration.
Subsequent Builds

After the initial build, Cargo caches dependencies, making subsequent compilations significantly faster as only changed code is recompiled.

Key Takeaway

Be prepared for a long initial compilation; it's a normal part of setting up a Substrate development environment due to numerous dependencies.

Troubleshooting Common Errors

  • Missing `wasm32-unknown-unknown` target: Ensure you've added the WebAssembly target for Rust.
  • Linker errors: Often due to missing system libraries like `libssl-dev` (Ubuntu/Debian) or `cmake`.
  • Network issues: Check your internet connection if dependency downloads fail.
Self-Correction

If you encounter errors, re-verify your Rust toolchain installation and system dependencies as outlined in the environment setup chapter.
