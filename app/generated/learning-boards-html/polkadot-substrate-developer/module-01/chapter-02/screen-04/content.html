Core Concept

What is a Blockchain?

A Distributed, Immutable Ledger

Distributed Ledger

Instead of a single central server, the ledger is replicated and synchronized across thousands of computers (nodes) globally. This decentralization removes single points of failure and control.

Chain of Blocks

Transactions are grouped into 'blocks,' which are then cryptographically linked together in a sequential 'chain.' Each block contains a hash of the previous block, creating an unbreakable link.

Immutability

Once a block is added to the chain, its data cannot be altered or deleted. Any attempt to tamper with an old block would invalidate all subsequent blocks, making changes immediately detectable.

Block N-1

Transactions, Timestamp, Previous Hash

Block N

Transactions, Timestamp, Hash of Block N-1

Block N+1

Transactions, Timestamp, Hash of Block N

Key Takeaway

Blockchain is a decentralized, immutable ledger that uses cryptographic links between blocks to ensure data integrity and transparency, forming the backbone of Web3.
