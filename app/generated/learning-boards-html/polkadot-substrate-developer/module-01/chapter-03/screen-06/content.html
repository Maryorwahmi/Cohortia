Module 2 › Chapter 1.3 › Relay Chain: the Network Anchor
Architecture

Minimal core responsibilities

Consensus & Staking
Runs NPoS to select validators that secure the entire network.
Shared Security
Provides pooled validator protection for Parachains.
Cross-chain Coordination
Facilitates messaging and finality between connected chains.
Concrete contrast
Unlike a general-purpose chain that runs many dApps, the Relay Chain focuses on security and coordination. Heavy application logic belongs on Parachains to avoid bloating the Relay Chain.
Key Takeaway

Keep application runtime on Parachains; use the Relay Chain for security, consensus, and governance primitives.
