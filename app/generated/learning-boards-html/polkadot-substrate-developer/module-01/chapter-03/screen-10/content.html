Module 2 › Chapter 1.3 › Shared Security Explained
Security Model

Pooled validator protection

Benefit
Small chains gain strong security without recruiting their own validators.
Tradeoff
Parachains depend on Relay Chain incentives and governance for network-level security decisions.
Concrete Example
A small Parachain focused on document verification benefits from the same validator security that protects high-value financial Parachains, reducing its attack surface.
Key Takeaway

Shared security lowers startup security costs for specialized chains, but teams must still manage runtime risks and dependency on network governance.
