Web Era 2

Web2: Interactive and Social

User-Generated Content and Centralized Platforms (2004-Present)

Defining Features

  • •User-Generated Content: Blogs, social media posts, videos, wikis.
  • •Rich User Experience: Dynamic interfaces, real-time updates.
  • •Social Interaction: Connecting with friends, sharing, commenting.
  • •Cloud Services: Online storage, collaborative documents.
Key Takeaway

Web2 enabled widespread user participation and dynamic experiences, but its reliance on centralized platforms introduced new challenges related to data control.

Enabling Technologies

  • •JavaScript: For client-side interactivity and dynamic content.
  • •AJAX: Asynchronous JavaScript and XML for background data loading.
  • •Backend Databases: Sophisticated systems for managing vast user data.
  • •APIs: Application Programming Interfaces for connecting services.

Real-world Example

Platforms like Facebook, YouTube, and Wikipedia are prime examples of Web2, thriving on user-generated content and rich interactivity.
