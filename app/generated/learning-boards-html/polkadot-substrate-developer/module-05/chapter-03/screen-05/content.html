Module 5 › Chapter 5.3 › Definitions
Extrinsic

A message originating outside the runtime that can trigger state changes. Most extrinsics that mutate state are signed transactions.

How to construct
Use api.tx.<pallet>.<call>(params) to create a call object representing the extrinsic.
Why sign
Signed extrinsics prove the origin and authorize execution according to on-chain permissions and balances.
Keypair

A cryptographic private and public key pair. The private key signs transactions; the public key is used to derive an address others see on-chain.

Keyring
@polkadot/keyring provides helpers to create and load keypairs, including development seeds like Alice and Bob for testing.
Misconception
An address alone cannot sign; the private key or an external signer is required to produce a valid signature.
Key Takeaway

Never conflate address visibility with signing capability; secure the private material that enables signing.
