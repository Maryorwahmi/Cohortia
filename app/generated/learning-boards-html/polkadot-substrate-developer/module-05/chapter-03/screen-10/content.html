Module 5 › Chapter 5.3 › Common mistakes
Mistakes
  • Stale Nonce: sending multiple txs without updating nonce.
  • Wrong Amount: not scaling by chain decimals leads to tiny values.
  • Hardcoded Keys: embedding secrets in code is insecure.
  • Leaked Subscriptions: not calling unsub() or disconnecting.
Best practices
Nonce queue
Maintain a queue that increments and assigns nonces to avoid collisions for rapid submits.
Verify amounts
Log transferAmount.toHuman() before signing to confirm units.
Secure signers
Use hardware signers or secure key management for production deployments.
Key Takeaway

Small mistakes compound in transaction flows; follow explicit nonce, amount verification, and secure key handling practices to reduce errors.
