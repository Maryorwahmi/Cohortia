Module 5 › Chapter 5.3 › Nonce & accounts
Why read the nonce

The nonce is the per-account sequence number that prevents replay and keeps transactions ordered. Use it when sending multiple transactions rapidly.

Common mistake

Calling signAndSend twice in quick succession without managing nonces often results in a stale nonce error for the second call.

Key Takeaway

When in doubt, read the on-chain nonce and explicitly pass it to signAndSend for sequential submissions.

Code snippet: fetch nonce
const { nonce } = await api.query.system.account(alice.address);
console.log('Alice nonce:', nonce.toNumber());

// Use this nonce explicitly when needed
await transfer.signAndSend(alice, { nonce }, callback);
Example scenario: send two transfers in a row. Either await finalization of the first before sending the second or increment the nonce manually to avoid collisions.
