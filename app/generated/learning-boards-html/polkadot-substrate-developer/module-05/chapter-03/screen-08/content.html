Constructing the call

Use api.tx.balances.transfer(recipient, amount) where amount is the Balance type expected by the chain.

// create a Balance value for 10 units
const transferAmount = api.registry.createType('Balance', 10 * Math.pow(10, api.registry.chainDecimals));
const transfer = api.tx.balances.transfer(bob.address, transferAmount);
console.log('Sending', transferAmount.toHuman());
Misconception: passing a raw number like 10 will send the smallest units unless you scale by decimals. Always convert to the chain's integer representation.
Example and verification

After creating the transfer object, call transfer.toHuman() or transferAmount.toHuman() to confirm the human-readable amount before signing.

Verify
Log transferAmount.toHuman() so you are confident about the value you will send.
Insufficient funds
Ensure the signing account has enough balance to cover both the transfer and fees, otherwise the transaction will fail.
