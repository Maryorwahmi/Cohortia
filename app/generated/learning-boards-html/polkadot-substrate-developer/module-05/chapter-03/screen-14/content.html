Module 5 › Chapter 5.3 › Key Concepts
Extrinsic
A runtime-callable message; construct via api.tx.<pallet>.<call> and pass typed params.
Keypair & Keyring
Keyring manages sr25519 pairs for signing. Use secure signers for production.
Nonce, Amounts, Status
Nonces prevent replay, amounts must be scaled by decimals, and status updates indicate progression to finality.
Takeaway: combine correct construction, secure signing, and careful lifecycle handling to build reliable dApp transaction flows.
