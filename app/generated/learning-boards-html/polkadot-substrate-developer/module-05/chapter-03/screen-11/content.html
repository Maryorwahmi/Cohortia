Module 5 › Chapter 5.3 › Nonce management
Strategy: Sequential finalization

Send the first transaction and wait for finalization before sending the next. This is simple and safe, but higher latency.

When to use

Useful for workflows where order and confirmation matter and where throughput demands are low.

Strategy: Local nonce counter

Fetch the on-chain nonce once, increment locally for each planned submit, and pass nonce option to signAndSend. This allows high throughput but requires careful reconciliation.

Tip: implement a transaction queue that serializes signing, applies retries, and reconciles the local counter with on-chain state periodically to recover from failed requests.
Pro Tip

Log expected vs on-chain nonce and alert on mismatches so operators can intervene before transactions stall.
