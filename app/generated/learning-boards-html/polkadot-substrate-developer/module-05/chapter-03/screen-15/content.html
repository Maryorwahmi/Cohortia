Module 5 › Chapter 5.3 › Quick Reference
Amounts
Scale by api.registry.chainDecimals and create a Balance type to avoid tiny transfers.
Nonces
Read api.query.system.account(address) and manage or increment nonce for sequential submissions.
Signing
Use Keyring for development; use secure signers or KMS for production environments.
Before you run a script: verify balances and nonce, ensure signer security, and plan for unsub() and api.disconnect() after finalization.
