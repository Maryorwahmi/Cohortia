Module 5 › Chapter 5.3 › Custom pallet activity
Checklist
  1. Connect to node with ApiPromise and WsProvider.
  2. Initialize Keyring and load Alice.
  3. Construct the extrinsic: api.tx.<yourPallet>.<yourCall>(...).
  4. Sign and send, watch events and status until finalization.
  5. Decode dispatchError if present, then unsub() and disconnect.
Key Takeaway

This activity practices the full end-to-end flow and confirms runtime effects by observing emitted events.

Starter snippet
// customTx.js (concept)
const { ApiPromise, WsProvider } = require('@polkadot/api');
const { Keyring } = require('@polkadot/keyring');

async function main(){
  const api = await ApiPromise.create({ provider: new WsProvider('ws://127.0.0.1:9944') });
  const keyring = new Keyring({ type: 'sr25519' });
  const alice = keyring.addFromUri('//Alice');
  const custom = api.tx.templateModule.doSomething(123);
  const unsub = await custom.signAndSend(alice, ({ status, events, dispatchError }) => { /* handle as shown earlier */ });
}

main().catch(console.error);
Replace templateModule.doSomething with your pallet and call. Confirm the event emitted by your pallet appears in the callback logs.
