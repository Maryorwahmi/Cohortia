Module 5 › Chapter 5.3 › Keyring setup
Terminal steps
Run npm init and install the packages before running your script. Keep secrets out of version control.
npm init -y
npm install @polkadot/api @polkadot/keyring
Why it matters

Keyring gives typed key support and convenient helpers for common dev seeds. Choose secure alternatives for production signers.

Initialization code
// initKeyring.js
const { Keyring } = require('@polkadot/keyring');

const keyring = new Keyring({ type: 'sr25519' });
const alice = keyring.addFromUri('//Alice');
console.log('Alice address:', alice.address);

// For production, replace addFromUri with secure signer integrations.
Example: addFromUri('//Alice') returns a KeyringPair with .address and signing methods ready for signAndSend. Misconception: adding an address from a public key is not enough to sign.
