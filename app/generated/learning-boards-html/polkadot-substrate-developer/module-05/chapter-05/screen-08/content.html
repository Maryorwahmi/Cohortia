Integrating User Accounts

Enabling the Polkadot-JS Extension and Loading Accounts

Accessing user accounts securely through the browser extension.

Extension Integration Flow

  1. Enable Extension: Call `web3Enable('your-dapp-name')` to prompt user for permission.
  2. Handle No Extension: Provide feedback if the extension is not found.
  3. Retrieve Accounts: Use `web3Accounts()` to get authorized accounts.
  4. Set Default Account: Select an initial account for interaction.

Common Mistake: Forgetting to call `web3Enable` will prevent your dApp from accessing any accounts from the extension.

Key Takeaway

The Polkadot-JS Extension is the secure gateway to user accounts; `web3Enable` and `web3Accounts` are the primary functions for integration.

jsx
// src/App.jsx
import { web3Accounts, web3Enable } from '@polkadot/extension-dapp';

// ... inside useEffect for API connection ...
    const connectToSubstrate = async () => {
      // ... API connection code ...

      // Enable the Polkadot-JS Extension
      const extensions = await web3Enable('my-substrate-dapp');
      if (extensions.length === 0) {
        alert('No Polkadot-JS Extension found. Please install it to interact with accounts.');
        return;
      }

      // Get all accounts from the extension
      const allAccounts = await web3Accounts();
      setAccounts(allAccounts);
      if (allAccounts.length > 0) {
        setSelectedAccount(allAccounts[0]); // Select the first account by default
      }
    };
// ...
