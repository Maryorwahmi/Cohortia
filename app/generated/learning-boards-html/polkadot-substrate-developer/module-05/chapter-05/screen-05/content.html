Project Setup

Initializing Your React dApp with Vite

Setting up the development environment and installing core Polkadot-JS libraries.

Installation Steps

  1. Create React Project: Use Vite to scaffold a new React application.
  2. Navigate to Directory: Change into your newly created project folder.
  3. Install Dependencies: Install core Polkadot-JS libraries for API interaction and extension communication.

Why Vite? Vite offers a lightning-fast development server and optimized build process, making it ideal for modern frontend projects, especially dApps.

Key Takeaway

A Vite-React setup combined with `@polkadot/api` and `@polkadot/extension-dapp` provides a modern and secure foundation for Substrate dApp development.

bash
npm create vite@latest my-substrate-dapp -- --template react
cd my-substrate-dapp
npm install
npm install @polkadot/api @polkadot/keyring @polkadot/extension-dapp
