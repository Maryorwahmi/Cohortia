Sending Extrinsics

Implementing the Transaction Logic

Constructing and preparing a balance transfer extrinsic for signing.

Key Steps in `handleTransfer`

  • •
    Input Validation: Check for filled fields and selected account.
  • •
    Get Injector: Use `web3FromSource(selectedAccount.meta.source)` to get the signing mechanism.
  • •
    Format Amount: Convert human-readable amount to chain's smallest unit (plancks) using `api.registry.chainDecimals`.
  • •
    Create Extrinsic: Construct the transaction, e.g., `api.tx.balances.transfer(recipient, amount)`.
Key Takeaway

Correctly obtaining the `injector` and formatting transaction amounts are crucial steps before signing and sending any extrinsic via the browser extension.

jsx
// src/App.jsx
import { web3FromSource } from '@polkadot/extension-dapp';

// ... inside App function ...
  const handleTransfer = async () => {
    if (!api || !selectedAccount || !transferAmount || !recipientAddress) {
      alert('Please fill all transfer fields and select an account.');
      return;
    }

    setStatus('Sending transaction...');
    try {
      const injector = await web3FromSource(selectedAccount.meta.source);
      const transferValue = api.registry.createType(
        'Balance',
        parseFloat(transferAmount) * Math.pow(10, api.registry.chainDecimals)
      );
      const tx = api.tx.balances.transfer(recipientAddress, transferValue);

      // ... signAndSend will go here ...

    } catch (error) {
      console.error('Error sending transfer:', error);
      setStatus(`Error: ${error.message}`);
    }
  };
// ...
