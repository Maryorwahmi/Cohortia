Running Your dApp

Launching and Testing Your Frontend Application

Steps to run your dApp and interact with your local Substrate node.

Prerequisites & Execution

  1. Start Substrate Node: Ensure your local node is running (`cargo run --release -- --dev`).
  2. Install Extension: Have Polkadot-JS Browser Extension installed.
  3. Import Alice: Import `//Alice` account into the extension.
  4. Run dApp: Execute `npm run dev` in your project directory.
  5. Grant Permission: Approve extension access in your browser.
Key Takeaway

Successful dApp execution requires a running Substrate node, the Polkadot-JS Extension with imported accounts, and granting browser permissions.
