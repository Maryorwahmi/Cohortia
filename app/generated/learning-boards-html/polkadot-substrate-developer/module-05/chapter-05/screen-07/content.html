Connecting to the Chain

Initial `App.jsx` Structure and API Connection

Setting up React state and establishing a connection to your local Substrate node.

Key Steps for API Connection

  • •
    Import Hooks: Bring in `useState` and `useEffect` from React.
  • •
    Initialize State: Declare state variables for `api`, `currentBlock`, `aliceBalance`, etc.
  • •
    Create Provider: Instantiate `WsProvider` with your node's WebSocket URL.
  • •
    Connect API: Use `ApiPromise.create` to establish the connection.
  • •
    Cleanup: Disconnect the API when the component unmounts to prevent leaks.
Key Takeaway

The `useEffect` hook is ideal for managing the lifecycle of your API connection, ensuring it's established on mount and cleaned up on unmount.

jsx
import React, { useState, useEffect } from 'react';
import { ApiPromise, WsProvider } from '@polkadot/api';

function App() {
  const [api, setApi] = useState(null);
  const [currentBlock, setCurrentBlock] = useState(0);
  const [aliceBalance, setAliceBalance] = useState('0');
  // ... other state variables

  useEffect(() => {
    const connectToSubstrate = async () => {
      const provider = new WsProvider('ws://127.0.0.1:9944');
      const api = await ApiPromise.create({ provider });
      setApi(api);
      console.log('Connected to Substrate node.');
    };

    connectToSubstrate();

    return () => {
      api && api.disconnect();
    };
  }, []); // Run once on component mount

  if (!api) {
    return <div>Connecting to Substrate...</div>;
  }

  return (
    <div>
      <h1>My Substrate DApp</h1>
      <p>Current Block: {currentBlock}</p>
      <p>Alice's Balance: {aliceBalance}</p>
    </div>
  );
}
