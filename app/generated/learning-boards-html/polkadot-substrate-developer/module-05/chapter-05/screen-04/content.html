The Frontend dApp Architecture

Understanding how your web application interacts with a Substrate chain.

Key Components of a dApp

  • 1.
    User Interface (UI): Your web application (e.g., React) provides the visual and interactive elements for the user.
  • 2.
    Polkadot-JS API: A JavaScript library that facilitates communication between your frontend and the Substrate chain.
  • 3.
    Substrate Chain: The blockchain backend, hosting your custom logic (pallets) and state.
  • 4.
    Browser Extension: (e.g., Polkadot-JS Extension) Securely manages user accounts and signs transactions.
Key Takeaway

Frontend dApps leverage the Polkadot-JS API and browser extensions to provide a secure and user-friendly interface for interacting with a Substrate blockchain backend.
