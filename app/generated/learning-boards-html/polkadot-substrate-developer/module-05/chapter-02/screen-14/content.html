Polkadot-JS API
A JavaScript library exposing api.query, api.rpc, api.consts, api.tx, and api.events for programmatic interaction.
WsProvider & ApiPromise
WsProvider opens the WebSocket; ApiPromise creates the async API. Always await creation and disconnect cleanly.
Codec & Option types
API returns Codec-wrapped values and Option<T>; use toHuman/toNumber/toHex and check isSome before unwrap.
Summary

These core ideas let you reliably read chain state and prepare for transactions and events by establishing safe connection patterns and data handling conventions.
