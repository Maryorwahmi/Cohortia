Practical Outcomes

These milestones reduce friction when building real dApps: an automated connection, reliable queries, and safe data handling strategies that avoid runtime errors.

Connection script
A simple index.js that creates a WsProvider, awaits ApiPromise.create, logs chain info, and disconnects.
Query examples
Account balances, block number, total issuance, and a custom pallet's storage item as concrete queries.
Safe conversions
Use toHuman, toNumber, toHex, and check isSome before unwrap to avoid errors when reading values.
Logging & metadata
Log only the metadata parts you need to keep outputs readable and useful during debugging.
Coming up
Step-by-step code walk-throughs and a hands-on query activity that you can run locally with a Substrate dev node.
