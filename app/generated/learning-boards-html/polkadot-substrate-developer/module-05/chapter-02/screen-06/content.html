api namespaces explained

This panel defines each major api sub-object with a short example to anchor understanding. Knowing where to look reduces trial-and-error and helps you write concise queries.
api.query
Typed access to runtime storage. Example: api.query.system.account(address) returns the account info Codec.
api.rpc
Node-level JSON-RPC calls such as api.rpc.system.chain() and api.rpc.chain.getBlockHash().
api.consts
Runtime constants defined by pallets like balances.existentialDeposit.
api.tx & api.events
api.tx helps construct and send extrinsics; api.events decodes events from blocks.
Misconception
Runtime constants are not stored under api.query. If you cannot find a value in api.query, check api.consts.
Check your understanding

Ask: Is this data a storage item, a constant, or a node-level property? That determines the api path you use.
