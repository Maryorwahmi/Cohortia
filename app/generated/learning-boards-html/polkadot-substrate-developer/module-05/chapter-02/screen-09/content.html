Node RPC and runtime constants

// parallel fetch example
const [chain, nodeName, nodeVersion] = await Promise.all([
  api.rpc.system.chain(),
  api.rpc.system.name(),
  api.rpc.system.version()
]);
console.log(`Connected to chain ${chain} using ${nodeName} v${nodeVersion}`);

// read a constant
const existentialDeposit = api.consts.balances.existentialDeposit;
console.log(`Existential Deposit: ${existentialDeposit.toHuman()} units`);
Practical note
Reading constants is cheap and stable. Use rpc for dynamic node or chain metadata and when you need raw block-level access.
Checking both areas helps you understand which values are compile-time constants versus runtime storage or node-level properties.
