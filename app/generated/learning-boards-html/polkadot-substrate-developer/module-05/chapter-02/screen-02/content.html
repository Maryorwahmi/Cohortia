Learning Objectives

Bloom: Learn → Understand → Apply → Master
01
Project setup and package install

Create a Node.js project and install @polkadot/api so your scripts can import WsProvider and ApiPromise. This is the foundation for programmatic access.

VERIFIED COMPETENCY MILESTONE
02
Establish and await a node connection

Use WsProvider and await ApiPromise.create to open a reliable WebSocket connection and learn typical connection errors and fixes.

VERIFIED COMPETENCY MILESTONE
03
Query storage, RPC, and constants

Read account balances, block numbers, runtime constants, and metadata using api.query, api.rpc, and api.consts with concrete examples to practice.

VERIFIED COMPETENCY MILESTONE
04
Interpret Codec and Option types

Convert API return types into JavaScript values with toHuman, toNumber, and toHex and handle Option safely using isSome before unwrap.

VERIFIED COMPETENCY MILESTONE
