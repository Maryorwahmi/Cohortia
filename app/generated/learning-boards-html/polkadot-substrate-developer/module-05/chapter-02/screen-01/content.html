Programmatic Interaction with Polkadot-JS API

Interactive 16:9 Masterclass — terminal-first orientation to setup and queries

This chapter teaches how to scaffold a Node.js project, install @polkadot/api, create a WsProvider and ApiPromise connection, and run queries that read chain state and metadata. Practical examples and pitfalls are included.

In this lesson
Code walk-throughs
Queries & types
Setup
Create a Node.js project and install @polkadot/api. This provides the core classes you'll use.
Connect
Use WsProvider and ApiPromise.create to open a WebSocket connection to your node and await readiness.
Query
Use api.query, api.rpc, and api.consts to read on-chain state, node properties, and runtime constants.
Quick demo
Connect and print chain details
const { ApiPromise, WsProvider } = require('@polkadot/api');

async function main () {
  const provider = new WsProvider('ws://127.0.0.1:9944');
  const api = await ApiPromise.create({ provider });
  console.log(`Connected to chain: ${api.genesisHash.toHex()}`);
  await api.disconnect();
}

main().catch(console.error);
Why this matters
Automated access to chain state lets backends and UIs fetch latest balances, block numbers, and custom pallet data without manual inspection.
