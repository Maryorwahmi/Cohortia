Scaffold and install

Use the terminal to create your project and install the package. The terminal commands are the canonical first step for script-based interaction.
Commands
mkdir substrate-api-client
cd substrate-api-client
npm init -y
npm install @polkadot/api
Pro tip
Confirm network access during install and check package.json to ensure @polkadot/api appears under dependencies.
Verification
Create index.js with a console log and run node index.js to verify the project runs. This reduces setup friction before connecting to a node.
Key takeaway

A clean project and a single installed dependency let you rapidly test ApiPromise examples against your node.
