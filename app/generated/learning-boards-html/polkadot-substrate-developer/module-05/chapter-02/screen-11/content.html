Pitfalls and fixes

Quick reference of common errors and how to resolve them with minimal friction.
  • Missing await on ApiPromise.create → await the call.
  • Wrong ws:// URL → verify host and port and include ws:// prefix.
  • Option unwrap without isSome → check isSome first.
  • Logging full metadata → log metadata.version instead.
Debug checklist
Ensure node is running, confirm network reachability, inspect errors from api.create, and use toHuman to inspect Codec shapes during development.
Recovery
Wrap connection code in try/catch and always call api.disconnect in a finally block to keep sockets clean across runs.
