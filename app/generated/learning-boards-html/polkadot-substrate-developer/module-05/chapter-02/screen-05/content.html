Connection code walk-through

This script shows the minimal lifecycle: provider, create, use, disconnect. Note the await which ensures readiness.
// index.js
const { ApiPromise, WsProvider } = require('@polkadot/api');

async function main () {
  const provider = new WsProvider('ws://127.0.0.1:9944');
  const api = await ApiPromise.create({ provider });

  console.log(`Connected to chain: ${api.genesisHash.toHex()}`);
  console.log(`Node name: ${api.runtimeVersion.specName.toString()}`);
  console.log(`Node version: ${api.runtimeVersion.implVersion.toNumber()}`);

  await api.disconnect();
}

main().catch(console.error);
Common mistakes
  • Forgetting await on ApiPromise.create leads to uninitialized metadata errors.
  • Incorrect WebSocket URL or missing ws:// prefix causes timeouts.
  • Not disconnecting leaves open sockets during repeated runs.
Check
Ensure your node is running, then run node index.js and expect a chain genesis hash and node version in the console.
