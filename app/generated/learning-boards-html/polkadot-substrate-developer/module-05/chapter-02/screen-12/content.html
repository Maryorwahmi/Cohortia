Where the API fits

Reuse ApiPromise instances to avoid reinitializing type registries. For server apps create a long-lived connection and add reconnection logic.
Patterns
  • Shared backend ApiPromise with caching and conversion helpers.
  • Frontend proxies to avoid direct node exposure.
  • Careful subscription use for real-time needs.
Security & scale
Centralizing chain reads lets you enforce rate limits, sanitize outputs, and cache expensive conversions so clients remain fast and secure.
Document which api.* namespaces your service uses so teams can reason about state dependencies and operational requirements.
