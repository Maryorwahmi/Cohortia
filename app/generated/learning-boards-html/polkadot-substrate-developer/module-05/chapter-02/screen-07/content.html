Querying an account

Use the system.account storage entry to get nonce and balance. Convert the returned Codec fields to JavaScript-friendly values before using them in UI or calculations.
// inside an async context
const ALICE = '5GrwvaEF5zXb26Fz9rcQpDWS57CtERHpNehXCPcNoHGKutQY';
const { nonce, data: balance } = await api.query.system.account(ALICE);
console.log(`Alice's nonce: ${nonce.toNumber()}, Balance: ${balance.free.toHuman()} ${api.registry.chainTokens[0]}`);
Use toNumber for counters and toHuman for readable token amounts.
Mistake to avoid
Treating the returned value as a raw number will lead to runtime errors. Always use conversion helpers on Codec objects.
Example output
Alice's nonce: 0, Balance: 1000 Unit
