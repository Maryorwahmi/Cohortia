Option<T> handling

When querying custom pallet storage, treat results as Option wrappers. Use isSome to guard unwrap. This prevents uncaught exceptions.
// example after api is ready
const somethingValue = await api.query.templateModule.something();
if (somethingValue.isSome) {
  console.log(`TemplateModule.Something: ${somethingValue.unwrap().toNumber()}`);
} else {
  console.log('TemplateModule.Something is not set.');
}
Developer tip
During debugging, call toHuman() on the Option to reveal its structure; it will show None or Some(value) and help confirm your unwrap logic.
Why it matters

Graceful handling avoids crashes and gives a clearer user experience when runtime state is absent.
