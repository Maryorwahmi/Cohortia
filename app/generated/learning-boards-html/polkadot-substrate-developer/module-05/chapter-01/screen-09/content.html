Peering into Chain State

Querying Storage Items and Constants

01

Navigate to Chain State

Go to 'Developer' and select the 'Chain state' tab.

02

Select Pallet & Item

Choose a pallet (e.g., balances) and then a storage item or constant (e.g., account).

03

Provide Parameters (If Any)

If the item requires an input (like an account address), provide it in the designated field.

04

Execute Query

Click the + button to add the query and observe the displayed on-chain value.

Example: Check Alice's Balance

Select balances pallet, then account storage, and input Alice's address. The UI will display her current token balance.

Key Takeaway

The Chain state tab is indispensable for verifying runtime behavior and understanding the current data stored on your blockchain.
