Key Concepts

Core elements of on-chain interaction

Accounts

Cryptographic identities (keypairs) used to sign transactions and own assets on the blockchain.

Extrinsics

Callable functions (transactions) that modify the chain state, dispatched by accounts.

Chain State

The current data stored on the blockchain, including balances, storage items, and runtime configurations.

Chapter Summary

This chapter equipped you with the skills to manage accounts, execute transactions, and query the chain state using the Polkadot-JS Apps UI.
