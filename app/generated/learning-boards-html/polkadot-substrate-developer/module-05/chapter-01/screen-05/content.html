Establishing Your Connection

Linking Polkadot-JS Apps to Your Node

01

Start Your Substrate Node

Ensure your local or remote Substrate node is running. Use `cargo run --release -- --dev` for local development.

02

Open Polkadot-JS Apps UI

Navigate to https://polkadot.js.org/apps/ in your web browser.

03

Select Network Endpoint

Click the network dropdown (top-left) and choose 'Development' or 'Local Node'.

04

Add Custom Endpoint (If Needed)

If your node is on a different port or remote, select 'Custom endpoint' and enter the full WebSocket URL (e.g., ws://127.0.0.1:9945).

Common Mistake

Forgetting the ws:// or wss:// prefix in the custom endpoint URL. Always use the full WebSocket address.

Key Takeaway

A successful connection relies on a running node and correctly specifying its WebSocket address in the Polkadot-JS Apps UI.
