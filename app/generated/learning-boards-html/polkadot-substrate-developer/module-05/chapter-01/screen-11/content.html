Customizing Your Experience

UI Settings and Connection Troubleshooting

UI Settings

  • •Configure token display units (e.g., DOT, KSM, custom symbols).
  • •Change language and theme preferences for a personalized experience.
Key Takeaway

Customizing UI settings and knowing how to troubleshoot connection issues are vital for an efficient and reliable development workflow.

Troubleshooting Connection Issues

  • •Check your node's console for error messages.
  • •Verify the WebSocket port in the UI matches your node's port.
  • •Ensure no firewall is blocking the connection to your node.
