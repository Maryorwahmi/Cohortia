Event Filtering

Filtering for Specific Events: balances.Transfer

Targeting relevant events for dApp logic

Why Filter Events?

The chain emits many events. Filtering allows your dApp to focus only on the events relevant to its specific functionality, improving efficiency and clarity.

Identifying `balances.Transfer`

A common use case is detecting token transfers. This is achieved by checking if event.section === 'balances' and event.method === 'Transfer'.

Key Takeaway

Filtering events by their section and method is fundamental for building dApps that react intelligently to specific on-chain actions.

// subscribeEvents.js (filtering excerpt)
const { ApiPromise, WsProvider } = require('@polkadot/api');

async function main () {
  // ... API connection ...

  const unsub = await api.query.system.events((events) => {
    events.forEach((record) => {
      const { event, phase } = record;

      // Check if it's a Balances.Transfer event
      if (event.section === 'balances' && event.method === 'Transfer') {
        const [from, to, amount] = event.data;
        console.log(`    >> TRANSFER: ${from.toHuman()} transferred ${amount.toHuman()} to ${to.toHuman()}`);
      }
    });
  });

  // ... setTimeout for unsubscribing ...
}

main().catch(console.error);
