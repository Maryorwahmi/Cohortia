Key Concepts

Advanced takeaways for reactive dApps

`system.events()`

Polkadot-JS API method to subscribe to all system and pallet events in finalized blocks.

`unsub()` Function

The function returned by subscription methods, used to terminate the subscription and clean up resources.

Runtime Call (RPC)

Direct, read-only function calls to the Substrate runtime for complex logic not covered by storage queries.

Summary Insight

Effective event decoding, resource management with unsub(), and strategic use of runtime calls are key to building robust and advanced Substrate dApps.
