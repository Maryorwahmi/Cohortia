Introduction to Runtime Calls (RPCs)

Executing read-only logic directly within the Substrate runtime

What are Runtime Calls?

Direct, read-only function calls to the Substrate runtime. They execute complex logic that doesn't necessarily map to a simple storage lookup, unlike api.query.

Purpose and Use Cases

Used to expose public functions from your pallets that perform computations based on multiple storage items or other complex logic, returning a result without modifying state.

Key Takeaway

Runtime calls provide a flexible way to access and execute sophisticated, read-only logic defined within your Substrate runtime.
