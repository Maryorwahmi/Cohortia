Subscribing to All System Events

Listening for all on-chain activity with api.query.system.events()

Beyond Block Headers

While block headers confirm chain progress, system events provide granular details about what actually occurred within those blocks, such as transactions and state changes.

The `api.query.system.events()` Method

This powerful Polkadot-JS API method allows you to subscribe to a stream of all events emitted by the Substrate runtime and its pallets in newly finalized blocks.

Key Takeaway

api.query.system.events() is essential for building dApps that need to react to specific, detailed changes on the blockchain, not just new blocks.

// subscribeEvents.js (excerpt)
const { ApiPromise, WsProvider } = require('@polkadot/api');

async function main () {
  const provider = new WsProvider('ws://127.0.0.1:9944');
  const api = await ApiPromise.create({ provider });

  console.log('Subscribing to system events...');

  // Subscribe to system events
  const unsub = await api.query.system.events((events) => {
    console.log(`
Received ${events.length} events in new block:`);

    // Loop through the Vec<EventRecord>
    events.forEach((record) => {
      // Extract the phase, event, and event data
      const { event, phase } = record;
      // ... further decoding logic ...
    });
  });

  // ... setTimeout for unsubscribing ...
}

main().catch(console.error);
