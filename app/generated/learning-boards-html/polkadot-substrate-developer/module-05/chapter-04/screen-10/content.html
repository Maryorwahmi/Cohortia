Custom Pallet Integration

Filtering for Custom Pallet Events

Reacting to events from your own Substrate modules

Extending Event-Driven Logic

Your custom pallets can emit unique events. Filtering for these allows your dApp to react to specific, custom logic and state changes defined in your runtime.

Matching `section` and `method`

Similar to system events, you'll filter by matching event.section (your pallet name, e.g., 'templateModule') and event.method (your event name, e.g., 'SomethingStored').

Key Takeaway

Reacting to custom pallet events is crucial for building dApps that are deeply integrated and responsive to your unique blockchain's functionality.

// subscribeEvents.js (custom event filtering)

      // Check for your custom pallet's event (e.g., TemplateModule.SomethingStored)
      if (event.section === 'templateModule' && event.method === 'SomethingStored') {
        const [somethingValue, who] = event.data;
        console.log(`    >> CUSTOM EVENT: SomethingStored: value=${somethingValue.toNumber()} by=${who.toHuman()}`);
      }
    });
  });

  // ... setTimeout for unsubscribing ...
}

main().catch(console.error);
