Common Mistakes with Custom Runtime APIs

Ensuring proper exposure and avoiding 'method not found' errors

The 'Method Not Found' Error

This common error indicates that the custom runtime API you're attempting to call is not recognized or accessible by your Substrate node.

Runtime Definition is Key

Ensure your custom runtime API is correctly defined and implemented within your runtime's src/lib.rs and runtime/src/lib.rs files using impl_runtime_apis!.

Exposure in `chain_spec.rs`

Crucially, the custom API must be explicitly exposed in your node's chain_spec.rs file for it to be callable externally.

Key Takeaway

Always verify both the runtime definition and the chain_spec.rs exposure when troubleshooting 'method not found' errors with custom runtime APIs.
