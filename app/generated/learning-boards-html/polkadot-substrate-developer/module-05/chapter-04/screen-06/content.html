Managing Subscriptions with unsub()

Preventing resource leaks and ensuring efficient dApp operation

Why `unsub()` is Crucial

Subscriptions create persistent connections. Without unsub(), these connections remain open, consuming network bandwidth and node resources unnecessarily.

Preventing Memory Leaks

In long-running applications or single-page applications, unmanaged subscriptions can lead to memory leaks, degrading performance over time.

Integration into Lifecycle

Always integrate unsub() into your application's cleanup logic, such as component unmounts in UI frameworks or script termination.

Key Takeaway

Always call the unsub() function returned by subscription methods to ensure proper resource management and application stability.
