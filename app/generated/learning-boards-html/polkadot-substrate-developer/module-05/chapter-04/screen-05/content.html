Real-time Monitoring

Subscribing to New Block Headers

Monitoring basic chain activity with subscribeNewHeads

The `subscribeNewHeads` Method

This Polkadot-JS API method provides a stream of new block headers as they are produced, offering a basic, real-time view of chain activity.

Crucial `unsub()` Function

The subscription returns an unsub() function. Calling this is vital to terminate the subscription and prevent resource leaks when updates are no longer needed.

Key Takeaway

api.rpc.chain.subscribeNewHeads() is your entry point for real-time chain monitoring, but always remember to call unsub().

// subscribeBlocks.js
const { ApiPromise, WsProvider } = require('@polkadot/api');

async function main () {
  const provider = new WsProvider('ws://127.0.0.1:9944');
  const api = await ApiPromise.create({ provider });

  console.log('Subscribing to new block headers...');

  // Subscribe to new headers
  const unsub = await api.rpc.chain.subscribeNewHeads((header) => {
    console.log(`Chain is at block #${header.number}: ${header.hash.toHex()}`);
  });

  // Keep the connection open for 60 seconds, then unsubscribe
  setTimeout(() => {
    unsub();
    console.log('Unsubscribed from new block headers.');
    api.disconnect();
  }, 60000); // Unsubscribe after 1 minute
}

main().catch(console.error);
