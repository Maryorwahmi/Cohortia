Key Concepts

Essential takeaways from this chapter

Chain Events

Notifications emitted by the Substrate runtime or pallets, signaling specific actions or state changes.

Event Subscription

A mechanism to listen for and receive real-time updates on new blocks or specific events as they happen on the chain.

`subscribeNewHeads()`

Polkadot-JS API method to subscribe to new block headers, providing a basic stream of chain activity.

Summary Insight

Mastering chain events and subscriptions is foundational for building dynamic, responsive, and efficient dApps that truly interact with the blockchain's real-time state.
