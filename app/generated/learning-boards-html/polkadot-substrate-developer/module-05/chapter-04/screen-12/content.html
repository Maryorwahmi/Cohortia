Making a Direct Runtime Call

Querying chain information using api.rpc.system.chain()

The `api.rpc.system.chain()` Call

This is a standard RPC call to retrieve the name of the connected blockchain. It demonstrates the basic pattern for invoking read-only runtime logic.

Custom Runtime API Structure

For custom APIs (e.g., MyCustomApi.myMethod), the call structure is api.rpc.myCustomApi.myMethod(params). Proper runtime definition and exposure are critical.

Key Takeaway

api.rpc allows direct calls to runtime functions. Ensure custom APIs are correctly defined and exposed in your node's configuration.

// runtimeCall.js
const { ApiPromise, WsProvider } = require('@polkadot/api');

async function main () {
  const provider = new WsProvider('ws://127.0.0.1:9944');
  const api = await ApiPromise.create({ provider });

  // Let's use a common RPC call for demonstration purposes, like getting the chain name
  const chainName = await api.rpc.system.chain();
  console.log(`Chain Name via RPC: ${chainName}`);

  // If you had a custom runtime API, it would look like this (conceptual):
  // const customResult = await api.rpc.myCustomApi.myMethod(123);
  // console.log(`Custom runtime API result: ${customResult.toNumber()}`);

  await api.disconnect();
}

main().catch(console.error);
