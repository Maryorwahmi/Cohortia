Module 4 › Chapter 3.4 › Activity
Activity checklist
  1. Start your node locally in development mode.
  2. Create a script that connects with WsProvider and ApiPromise.create.
  3. Load Alice with Keyring and query api.query.<pallet>.accountCounters(alice.address).
  4. Call api.tx.<pallet>.incrementCounter().signAndSend(alice) and wait for finalization.
  5. Re-query to confirm the counter incremented.
Expected result: Alice's counter increases by one after the transaction is included and finalized.
Starter code (interact.js)
const { ApiPromise, WsProvider, Keyring } = require('@polkadot/api'); async function main() { const provider = new WsProvider('ws://127.0.0.1:9944'); const api = await ApiPromise.create({ provider }); const keyring = new Keyring({ type: 'sr25519' }); const alice = keyring.addFromUri('//Alice'); // 1. Query initial counter let aliceCounter = await api.query.templateModule.accountCounters(alice.address); console.log(`Alice's initial counter: ${aliceCounter.toNumber()}`); // 2. Submit increment_counter const incrementTx = api.tx.templateModule.incrementCounter(); const hash = await incrementTx.signAndSend(alice); console.log(`Transaction sent with hash: ${hash.toHex()}`); // 3. Wait and re-query await new Promise(r => setTimeout(r, 5000)); aliceCounter = await api.query.templateModule.accountCounters(alice.address); console.log(`Alice's new counter: ${aliceCounter.toNumber()}`); await api.disconnect(); } main().catch(console.error);
