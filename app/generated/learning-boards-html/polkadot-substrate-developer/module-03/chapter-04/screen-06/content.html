Module 4 › Chapter 3.4 › Send Extrinsic
Steps to submit a transaction
  1. Create provider and await ApiPromise.create so metadata is available.
  2. Load signer keypair using Keyring and the correct curve (sr25519 for Substrate).
  3. Build extrinsic with api.tx.balances.transfer(recipient, amount).
  4. Call transfer.signAndSend(signer) and monitor status for inclusion/finalization.
Misconception: signing is optional — it is required for any extrinsic that modifies state and must use the corresponding private key.
Code example: transfer
const { ApiPromise, WsProvider, Keyring } = require('@polkadot/api'); async function main() { const provider = new WsProvider('ws://127.0.0.1:9944'); const api = await ApiPromise.create({ provider }); const keyring = new Keyring({ type: 'sr25519' }); const alice = keyring.addFromUri('//Alice'); const bob = '5FHneW46xGXap2Few4HEUSRtfAwPCMzrMyGZvou3S85fWkEZ'; const transfer = api.tx.balances.transfer(bob, 10); const hash = await transfer.signAndSend(alice); console.log('Transfer sent with hash', hash.toHex()); await api.disconnect(); } main().catch(console.error);
This example uses development keys; do not expose real private keys in production code.
