JSON-RPC in Substrate
A protocol for remote procedure calls: methods, params, and JSON responses.
  • Exposes node methods for storage reads, extrinsic submission, and event subscriptions.
  • Works over WebSocket (commonly port 9944) or HTTP (9933) in development setups.
  • Is independent of runtime logic; it simply transports requests and responses.
Example transport check
If your client can't connect, verify the node process is running and the WS port is reachable, then confirm the provider URL string matches exactly.
Illustrative call flow
Misconception: RPC is not runtime logic. The RPC channel carries the calls; the node's runtime defines how calls are handled and what storage exists.
