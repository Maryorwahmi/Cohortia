Safety checklist and hands-on goals
Private Keys
Never expose real private keys. Use hardware wallets or secure key management in production.
Provider Endpoint
Confirm your WsProvider URL and that the node is reachable on the expected port.
Transaction Review
Double-check recipient, amount, and pallet call parameters before signing.
Hands-on activity: connect a JavaScript script to your local node, query your custom pallet's accountCounters for Alice, submit increment_counter, then re-query to confirm the change. Use development keys only for testing.
