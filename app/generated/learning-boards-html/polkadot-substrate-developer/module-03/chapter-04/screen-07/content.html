Module 4 › Chapter 3.4 › Troubleshooting
Step-by-step checks
1. Provider: Verify the WsProvider URL and node listening port (default 9944 for WS in dev).
2. Keyring and signing: Ensure Keyring type is sr25519 and keypair is loaded; log its address.
3. Balance: Query system.account to confirm free balance covers transfer plus fees.
4. Transaction lifecycle: Use signAndSend's callback to observe in-block and finalized statuses.
Quick diagnostic commands
Use small scripts to print connection status and account free balance. Logging the returned status objects from signAndSend often reveals whether a transaction was included or merely broadcast.
Pro-tip: Treat hash as broadcast receipt; wait for in-block or finalized events to confirm state changes.
