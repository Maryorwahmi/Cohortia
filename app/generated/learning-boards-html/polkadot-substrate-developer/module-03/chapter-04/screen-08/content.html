Module 4 › Chapter 3.4 › Polkadot-JS Apps
Developer tools inside Apps
  • Accounts: create, import, and manage keypairs for signing transactions in the browser.
  • Chain State: explore runtime storage, test storage queries, and view decoded values.
  • Extrinsics: build and submit calls to any pallet directly from the UI, with immediate feedback.
  • Events and logs: monitor emitted runtime events as transactions are executed.
Practical walkthrough
To test a new pallet, switch the network endpoint to your local node, open Developer → Chain state to read your storage map, then Developer → Extrinsics to call the dispatchable and observe the generated event.
Analogy: Polkadot-JS Apps is like a database admin UI for your runtime — it queries, updates, and shows a live event log without writing code.
