Module 4 › Chapter 3.4 › Security
Private keys
Use secure key storage in production; development URIs are for local testing only.
RPC Endpoint trust
Prefer your own node or verified public endpoints; a compromised node can mislead your application.
Transaction review
Always confirm parameters and fees before signing; add logging and staging steps for critical operations.
Common mistake: believing a UI will prevent signing mistakes. UIs help but you must still inspect the payload and confirm identities.
