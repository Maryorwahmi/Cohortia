What the API does
  • Connects using a provider and retrieves runtime metadata to build typed helpers.
  • Encodes and decodes values using SCALE so you work with readable objects instead of raw bytes.
  • Exposes api.query for reads, api.tx for extrinsics, and subscription helpers for events.
Common mistakes
Trying to use api before ApiPromise.create resolves, or mixing keyring types without realizing the chain expects sr25519.
Code example: connect and query balance
const { ApiPromise, WsProvider } = require('@polkadot/api'); async function main() { const provider = new WsProvider('ws://127.0.0.1:9944'); const api = await ApiPromise.create({ provider }); console.log(`Connected to chain: ${api.genesisHash.toHex()}`); const ALICE = '5GrwvaEF5zXb26Fz9rcQpDWS57CtERHpNehXCPcNoHGKutQY'; const { data: { free: aliceFree } } = await api.query.system.account(ALICE); console.log(`Alice's free balance: ${aliceFree.toHuman()} units`); await api.disconnect(); } main().catch(console.error);
This snippet demonstrates connection, metadata use, and a simple storage query; it is safe to run against a local development node.
