Interacting with the Substrate Runtime
RPC, Polkadot-JS API, and Polkadot-JS Apps — the three layers of runtime interaction
This lesson shows how low-level node RPCs are exposed, how the Polkadot-JS API wraps them for JavaScript programs, and how the Polkadot-JS Apps UI maps those operations for humans. It also previews common mistakes to avoid when querying state or sending transactions.
