Module 4 › Chapter 3.4 › Subscriptions
Why subscribe?
  • Receive push updates for events and storage changes.
  • Avoid polling and reduce load on public RPC providers.
  • Support real-time UI notifications and backend processing.
Usage note
Subscribe to api.query.system.events(callback) and filter events by event.section and event.method to react to only the signals you need. Remember to handle reconnection and cleanup to avoid memory leaks.
Misconception: events equal finalization. Events show execution within a block; for guaranteed finality, consider waiting for finalized status.
