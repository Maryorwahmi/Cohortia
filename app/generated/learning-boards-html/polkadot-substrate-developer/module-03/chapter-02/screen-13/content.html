Implementing Error Handling with ensure!

Validating Conditions in Dispatchable Functions

  • •Definition: Errors are defined using the #[pallet::error] attribute as an enum.
  • •Validation: The ensure! macro checks a condition and returns an error if false.
  • •Security: Essential for validating inputs, permissions, and maintaining state integrity.
Analogy

Think of ensure! as a bouncer at a club: if you don't meet the entry conditions, you're immediately turned away with a clear reason.

Key Takeaway

The ensure! macro is a powerful tool for enforcing pallet logic and providing immediate, specific error feedback.

Error Definition & Usage
#[pallet::error]
pub enum Error<T> {
    /// Sender does not have enough funds.
    InsufficientBalance,
    /// Transfer amount was zero.
    ZeroAmount,
}

// Inside a dispatchable function:
ensure!(sender_balance >= amount, Error::<T>::InsufficientBalance);
ensure!(amount > 0, Error::<T>::ZeroAmount);

This defines two errors and shows how ensure! is used to check conditions and return them.

Pro-Tip

Always provide specific error messages. Generic errors make debugging and user feedback much harder.
