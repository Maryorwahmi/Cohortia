Error Handling

Errors: Precise Failure Conditions

Providing Clear Feedback for Transaction Failures

  • •Purpose: Report specific, expected failure conditions in a structured way.
  • •Benefits: Invaluable for debugging and providing clear feedback to users.
  • •Definition: Declared using the #[pallet::error] attribute, typically as an enum.
Example

A Transfer dispatchable might return an InsufficientBalance error if the sender lacks funds.

Key Takeaway

Proper error handling is essential for a robust, user-friendly, and easily debuggable blockchain application.

Error Reporting Comparison
Generic Failure

"Transaction failed." (Unhelpful, hard to debug)

Specific Error

"InsufficientBalance." (Clear, actionable feedback)

Why it matters

Specific errors improve the developer experience by simplifying debugging and enhance user experience with clear feedback.
