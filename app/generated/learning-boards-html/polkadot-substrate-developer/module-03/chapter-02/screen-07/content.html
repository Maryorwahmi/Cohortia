Storage Type

StorageMap: Flexible Key-Value Storage

Mapping Data Like a Hash Map

  • •Functionality: Stores data as key-value pairs, similar to a hash map.
  • •Common Use: Mapping account IDs to balances, or object IDs to their properties.
  • •Key Choice: Requires careful selection of unique and efficiently hashable key types.
Common Mistake

Using overly complex or large objects as keys, which can lead to increased storage costs and slower lookup times.

Key Takeaway

StorageMap is essential for managing collections of data indexed by a single key, enabling efficient data retrieval.

Example: Account Balances
#[pallet::storage]
#[pallet::getter(fn balances)]
pub type Balances<T: Config> = StorageMap<
    _,
    Blake2_128Concat,
    T::AccountId,
    u128,
    ValueQuery,
>;

// Accessing a balance:
let user_balance = Self::balances(&sender);

This defines a Balances map, associating an AccountId with a u128 balance, using Blake2_128Concat for hashing.

Real-world connection

Most token pallets, like the Balances pallet in FRAME, heavily rely on StorageMap to manage individual user balances.
