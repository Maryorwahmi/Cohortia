Storage Type

StorageValue: Global Configuration

Storing Single, Global Parameters

  • •Purpose: Stores a single, global value for the pallet.
  • •Use Cases: Global counters, configuration settings, total supply of a token.
  • •Default Values: Often used with ValueQuery to ensure a default value is returned if not set.
Common Mistake

Using StorageValue for data that should be associated with specific keys or users, leading to inefficient data management.

Key Takeaway

StorageValue is ideal for simple, global data points, ensuring a consistent state across the chain.

Example: Total Supply
#[pallet::storage]
#[pallet::getter(fn total_supply)]
pub type TotalSupply<T: Config> = StorageValue<_, u128, ValueQuery>;

// Accessing the value:
let current_supply = Self::total_supply();

This defines a storage item TotalSupply of type u128, accessible via the total_supply() getter, defaulting to 0.

Pro-Tip

Use ValueQuery for types with a sensible default (e.g., 0 for numbers, empty for collections) to simplify logic and avoid `Option` handling.
