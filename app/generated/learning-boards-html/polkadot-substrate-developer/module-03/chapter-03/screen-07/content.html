Events

Events are emitted to inform off-chain listeners of state changes. They should include structured data that consumer UIs can use without scanning storage.

#[pallet::event]
#[pallet::generate_deposit(pub(super) fn deposit_event)]
pub enum Event {
  CounterIncremented { who: T::AccountId, new_value: u32 },
}
Errors

Errors are precise failure variants. Use ensure! to validate conditions and return a specific enum variant so callers and UIs know why an extrinsic failed.

#[pallet::error]
pub enum Error {
  InsufficientBalance,
  AlreadyVoted,
}

// usage
ensure!(balance >= amount, Error::::InsufficientBalance);
Tip: Be specific with errors and include enough event fields for on-chain indexing and off-chain efficiency.
