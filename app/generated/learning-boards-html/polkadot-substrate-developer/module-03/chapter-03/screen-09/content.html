Upgrade process (simplified)
1. Build
Compile runtime with updated pallets to a Wasm blob.
2. Migrate
Prepare migration logic if storage layouts changed to keep state consistent.
3. Deploy
Submit the Wasm blob via an upgrade extrinsic and let governance or root apply it.
4. Run
Nodes execute the new runtime; the chain continues without a hard fork if migrations are correct.
Remember: upgrades are powerful but require careful storage design and migration testing. Avoid breaking changes to storage layout where possible and include clear migration steps in your runtime code path.
