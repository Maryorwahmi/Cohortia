Module 3 › Chapter 3.3 › What is a Pallet?
Clear definition

A pallet encapsulates related runtime logic: storage items to persist state, dispatchables to accept transactions, events to notify off-chain systems, and errors to signal specific failures. It is a Rust module using FRAME attributes.

Metaphor
Like an app: own data, expose actions, and emit notifications for UI syncing.
Misconception
Pallets are modular but not isolated; they rely on shared runtime types and FRAME crates. Dependencies must be declared in Config.
Key Takeaway

Pallets provide modularity and composability, lowering development effort and easing upgrades.

Pallet structure
// Simplified pallet skeleton
#[frame_support::pallet]
pub mod pallet {
  #[pallet::config]
  pub trait Config: frame_system::Config { type RuntimeEvent: From> + IsType<::RuntimeEvent>; }

  #[pallet::storage]
  pub type Something = StorageValue<_, u32, ValueQuery>;

  #[pallet::event]
  pub enum Event { SomethingStored { something: u32, who: T::AccountId }, }

  #[pallet::error]
  pub enum Error { NoneValue }

  #[pallet::call]
  impl Pallet { pub fn do_something(origin: OriginFor, something: u32) -> DispatchResult { Ok(()) } }
}
Concrete example

A Balances pallet uses a StorageMap mapping AccountId to balance, exposes transfer as a dispatchable, emits Transfer events, and returns InsufficientBalance on failure.
