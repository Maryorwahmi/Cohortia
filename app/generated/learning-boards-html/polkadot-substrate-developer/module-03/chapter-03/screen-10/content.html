// New event variant
CounterIncremented { who: T::AccountId, new_value: u32 },
Use ValueQuery so absent keys are treated as zero. The getter provides a read API for tests and runtime calls.
Dispatchable snippet
#[pallet::weight(10_000 + T::DbWeight::get().reads_writes(1,1).ref_time())]
pub fn increment_counter(origin: OriginFor) -> DispatchResult {
  let who = ensure_signed(origin)?;
  let mut current = >::get(&who);
  current = current.saturating_add(1);
  >::insert(&who, current);
  Self::deposit_event(Event::CounterIncremented { who, new_value: current });
  Ok(())
}
After implementing, add the pallet to your runtime and run cargo build --release. Test with Polkadot-JS Apps or unit tests to confirm the counter increments and event emits as expected.
