Dispatchable pattern
  • Accept an Origin parameter and ensure it's signed for user actions.
  • Validate the input and state preconditions with ensure! or conditional checks.
  • Read from storage, compute updates, write back with insert or put.
  • Emit events for off-chain observers and return Ok or a precise error.
Pro tip

Use saturating_add when incrementing counters to avoid overflow panics, and declare reads/writes in weight annotations.

Example dispatchable
#[pallet::call]
impl Pallet {
  #[pallet::weight(10_000 + T::DbWeight::get().reads_writes(1,1).ref_time())]
  pub fn increment_counter(origin: OriginFor) -> DispatchResult {
    let who = ensure_signed(origin)?;
    let mut current = >::get(&who);
    current = current.saturating_add(1);
    >::insert(&who, current);
    Self::deposit_event(Event::CounterIncremented { who, new_value: current });
    Ok(())
  }
}
This pattern demonstrates the full lifecycle of a transaction: authorization, state change, event emission, and a clear return value.
