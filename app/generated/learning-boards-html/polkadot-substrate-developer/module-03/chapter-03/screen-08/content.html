Module 3 › Chapter 3.3 › frame_system & frame_support
What they provide
  • frame_system: AccountId, Origin, BlockNumber, and other core runtime types.
  • frame_support: storage helpers, macros like #[pallet::storage], and weight macros.
  • Preludes: pallet_prelude imports common traits and types to reduce boilerplate.
Config wiring example
#[pallet::config]
pub trait Config: frame_system::Config {
  type RuntimeEvent: From> + IsType<::RuntimeEvent>;
}
This trait binding ensures events and types produced by the pallet integrate correctly with the runtime's global types. Forgetting it leads to compile-time type mismatches.
