Runtime Aggregation

The `construct_runtime!` Macro

This macro is where all FRAME pallets are aggregated to form the complete Substrate runtime, defining its overall structure.

  • •Central point for declaring all active pallets.
  • •Ensures pallets are recognized and their logic is integrated.
  • •Crucial for a cohesive and functional blockchain brain.
Common Pitfall

Forgetting to list a new pallet in construct_runtime! will prevent its logic from being included in the blockchain.

Key Takeaway

The construct_runtime! macro is the essential glue that binds individual pallets into a unified and operational blockchain runtime.

// In runtime/src/lib.rsconstruct_runtime!(  pub enum Runtime where    Block = Block,    NodeBlock = opaque::Block,    UncheckedExtrinsic = UncheckedExtrinsic,  {    System: frame_system::{Pallet, Call, Config, Storage, Event<T>},    Timestamp: pallet_timestamp::{Pallet, Call, Storage, Inherent},    Balances: pallet_balances::{Pallet, Call, Storage, Config<T>, Event<T>},    // ... other FRAME pallets ...    // MyCustomPallet: my_custom_pallet::{Pallet, Call, Storage, Event<T>},  });
