Rust Macros for Pallet Structure

FRAME uses Rust's macro system to intuitively define pallet components like storage, events, and errors.

  • •#[pallet::storage] defines on-chain data persistence.
  • •#[pallet::event] declares events for off-chain applications.
  • •#[pallet::error] defines specific error types for transactions.
Pro-Tip

Understanding these macros is key to quickly grasping how a pallet interacts with the blockchain state and external systems.

Key Takeaway

Macros streamline pallet development, ensuring consistency and allowing developers to focus on unique blockchain logic.

#[frame_support::pallet]pub mod pallet {  #[pallet::config]  pub trait Config: frame_system::Config {    type RuntimeEvent: From<Event<Self>> + IsType<<Self as frame_system::Config>::RuntimeEvent>;  }  #[pallet::pallet]  #[pallet::generate_store(pub(super) trait Store)]  pub struct Pallet<T>(_);  #[pallet::storage]  #[pallet::getter(fn something)]  pub type Something<T> = StorageValue<_, u32>;  #[pallet::event]  #[pallet::generate_deposit(pub(super) fn deposit_event)]  pub enum Event<T: Config> {    SomethingStored(u32, T::AccountId),  }  #[pallet::error]  pub enum Error<T> {    TooYoung,  }  #[pallet::call]  impl<T: Config> Pallet<T> {    #[pallet::weight(10_000)]    pub fn do_something(origin: OriginFor<T>, something: u32) -> DispatchResult {      let who = ensure_signed(origin)?;      <Something<T>>::put(something);      Self::deposit_event(Event::SomethingStored(something, who));      Ok(())    }  }}
