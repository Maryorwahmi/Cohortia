Key Concepts

Essential terms to remember

Substrate Runtime

The core business logic of a Substrate blockchain, compiled to WASM, defining the state transition function.

Substrate Node

The executable software that runs the blockchain, handling networking, block production, and interacting with the runtime.

FRAME

A modular framework within Substrate providing reusable modules (pallets) and tools for efficient runtime building.

Summary Takeaway

The Substrate Runtime is the 'brain' of your blockchain, the Node is its 'body,' and FRAME provides the 'LEGO blocks' (pallets) to build that brain efficiently.
