Core Definition

What are Issue Types?

Issue types are classifications of work in Jira that help define the nature and purpose of each work item. They are fundamental for structuring and organizing tasks effectively.

Key Takeaway

Correctly using issue types ensures clarity, proper breakdown of work, and accurate reporting across your project.

Common Pitfall

Misusing issue types (e.g., using a Task for an Epic) leads to confusion, poor tracking, and an unclear project scope.

Issue Type Hierarchy

Epic

Large body of work, major goal

Story

User-centric feature

Task

General work item

Bug

Defect or error

Sub-task

Granular piece of work
