Project Naming

Name & Key

Project Name

A human-readable title for your project (e.g., "Cohortia Learning Platform").

Project Key

A short, unique identifier (e.g., "CLP") used to prefix all issues (e.g., CLP-1).

Key Takeaway

Choose a concise and memorable Project Key, as it becomes a permanent part of every issue's unique identifier.

Project Management Types

Company-managed Projects

Centralized control, consistency across projects, often managed by Jira administrators. Ideal for larger organizations.

Team-managed Projects

Teams have autonomy to configure settings, workflows, and issue types. Simpler for beginners and smaller teams.

Common Misconception

Confusing Project Name with Project Key. The Name is for humans, the Key is a unique system identifier for issues.
