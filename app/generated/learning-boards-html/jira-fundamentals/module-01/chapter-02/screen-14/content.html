Essential Jira Concepts

Reinforcing Your Understanding

Dashboard

A personalized, customizable homepage in Jira providing an at-a-glance overview of project statuses and assigned work.

Gadget

A small, configurable report or display element that can be added to a Jira dashboard to show dynamic information.

Global Navigation Bar

The persistent top bar in Jira providing access to core functionalities like Projects, Dashboards, Filters, and the Create button.

Project Sidebar

The contextual navigation panel on the left side of a project screen, offering links to project-specific components like Boards and Backlogs.

Summary Takeaway

These core components are your foundation for navigating and interacting with Jira effectively, enabling personalized views and quick access to essential tools.
