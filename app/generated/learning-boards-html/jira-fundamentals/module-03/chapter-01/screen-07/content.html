Workflow Schemes: Tailoring Processes

Applying Workflows to Issue Types in Your Project

What is a Workflow Scheme?
Centralized Mapping

Links workflows to specific issue types within a project.

Project-Specific

Each project uses a workflow scheme to define its processes.

Flexible Processes

Allows different issue types to follow distinct workflows.

Scenario: Mixed Issue Types

In a single project, 'Story' and 'Bug' issues might use a 'Software Development Workflow', while 'Change Request' issues use a simpler 'Approval Workflow'. The workflow scheme manages this.

Benefits of Workflow Schemes

  • Tailor processes to specific work types.
  • Avoid creating multiple projects for different processes.
  • Enhance organizational flexibility.
  • Maintain consistency within each issue type's lifecycle.
Key Takeaway

Workflow schemes are crucial for applying the right process to the right type of work within a single Jira project, maximizing flexibility.
