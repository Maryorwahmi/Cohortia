The Importance of Post-Function Order

Ensuring sequential execution for predictable automation.

Execution Flow
1

Assign Issue to QA Lead

Sets the issue's assignee field.

2

Add Comment: "Assigned to {Assignee}"

Uses the assignee set in step 1.

3

Notify Assignee

Sends notification to the newly assigned user.

Common Mistake

Placing a post-function that relies on a field's value (e.g., assignee) *before* another post-function has set that value can lead to errors or incorrect automation.

Key Takeaway

Always configure post-functions in the correct sequential order to ensure dependencies are met and automated actions execute as intended.
