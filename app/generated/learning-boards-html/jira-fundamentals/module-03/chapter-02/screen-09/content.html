Global Transitions: Any Status to One

Simplifying movement from any state to a specific target.

What are Global Transitions?

A global transition allows an issue to move from any status in the workflow to a specific target status, simplifying configuration.

  • •Configuration Simplicity: Reduces the need for many individual transitions.
  • •Quick Status Changes: Ideal for common states like 'On Hold' or 'Cancelled'.
  • •Flexibility: Provides a direct path to a target status from anywhere.
Key Takeaway

Global transitions offer a streamlined way to move issues to a common status from any point, but require careful use with conditions and validators.
