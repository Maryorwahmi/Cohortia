Tracking Development Activities

From branch creation to code commits.

Why Reference Issue Keys?

Ensures automatic linking of code changes to Jira issues, providing a clear audit trail and development context.

Automated Linking: Jira automatically detects and displays linked activities.

Improved Context: Developers and project managers see code changes directly in Jira.

Key Takeaway

Consistent use of Jira issue keys in branch names and commit messages is essential for automated traceability and a unified view of development progress.

01

Branches

Create a new branch directly from a Jira issue, ensuring the branch name includes the issue key.

git checkout -b feature/COHORTIA-123-new-feature
02

Commits

When committing code, include the Jira issue key in the commit message.

git commit -m "COHORTIA-123: Implemented user login API"
