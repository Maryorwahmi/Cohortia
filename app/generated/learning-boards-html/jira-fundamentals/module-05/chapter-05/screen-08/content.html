Project Setup Fundamentals

Choosing the Right Project Configuration

Project Types

Choose between Team-managed (simpler, autonomous) and Company-managed (standardized, shared config) based on team size and organizational structure.

Methodologies

Select Scrum for iterative, sprint-based work or Kanban for continuous flow and work-in-progress visualization.

Key Takeaway

The right project type is foundational; it dictates the flexibility, control, and methodology support available to your team.

Project Type Decision

Aligns Jira with team structure and process.

Team-managed

Simpler, team-specific configuration. Ideal for small, autonomous teams.

Company-managed

Standardized, shared configuration. Best for larger organizations with consistent processes.

Scrum

Fixed sprints, backlog, iterative development. For teams with predictable cycles.

Kanban

Continuous flow, WIP limits, visual board. For teams focused on throughput.
