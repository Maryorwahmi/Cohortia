Using @Mentions to Notify Specific Team Members

Draw Attention and Request Action Efficiently

01

Type '@' Symbol

Begin typing the '@' symbol in any comment or description field within a Jira issue.

02

Select User

Jira will display a list of matching users. Select the team member you wish to notify.

03

Send Notification

The selected user will receive a notification, drawing their attention to your comment.

Example Usage

"@Sarah Smith, could you please review the attached design mockups for the new feature?"

Pro-Tip: Use Judiciously

Avoid overusing mentions to prevent notification fatigue. Reserve them for critical information or direct action requests.

Key Takeaway

@Mentions are a powerful way to ensure specific individuals are alerted to important updates or requests for action, streamlining communication flow.
