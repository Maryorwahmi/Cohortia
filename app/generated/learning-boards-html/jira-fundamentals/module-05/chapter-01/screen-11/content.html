Issue Linking: Connecting Related Work Items

Visualize Dependencies and Context Across Your Project

Purpose of Linking

  • Establish clear relationships between issues.
  • Provide crucial context and visibility into dependencies.
  • Improve planning and risk management.
  • Enable proactive problem-solving when issues are blocked.

Common Link Types

Relates to
Blocks / Is Blocked by
Duplicates / Is Duplicated by
Parent of / Child of
Key Takeaway

Issue linking is vital for explicitly defining relationships and dependencies between work items, providing clarity and aiding in project management.
