Two Dimensional Filter Statistics: Pivot Table for Issues

Visualize issue counts grouped by two different fields.

Key Features
  • •Pivot-Table View: Cross-reference two issue fields for deeper insights.
  • •Distribution Analysis: Quickly identify patterns in workload, status, or priority.
  • •Configurable Axes: Choose any two fields (e.g., Assignee, Status, Priority, Issue Type).
Key Takeaway

This gadget is invaluable for gaining a quick, aggregated view of issue distributions across two dimensions, helping to identify trends, bottlenecks, and workload balance.

Example: Team Workload by Status

1. Define Scope with Filter

Use a filter like "Issues in Current Sprint" to narrow down the data.

2. Set X-Axis

Choose 'Assignee' to see who owns the issues.

3. Set Y-Axis

Choose 'Status' to see the current state of those issues.

Pro Tip

Experiment with different field combinations (e.g., 'Priority' vs. 'Issue Type') to uncover various insights relevant to your project's health.
