The Filter Results Gadget: Your Issue List at a Glance

Display specific lists of issues based on a saved filter.

How it Works
  • •Data Source: Relies entirely on a pre-defined 'Saved Filter' (JQL query).
  • •Dynamic List: Automatically updates as issues change status or assignments.
  • •Configurable Columns: Choose which issue fields to display (e.g., Summary, Assignee, Status).
Key Takeaway

The Filter Results Gadget is crucial for displaying dynamic, filtered lists of issues directly on your dashboard, providing immediate visibility into specific work items.

Configuration Example: My Open Tasks

1. Create Saved Filter

assignee = currentUser() AND statusCategory != "Done" ORDER BY priority DESC

Save this as "My High-Priority Open Tasks".

2. Add Gadget to Dashboard

Select 'Add gadget' and choose 'Filter Results Gadget'.

3. Configure Gadget

Select "My High-Priority Open Tasks" from the filter dropdown. Adjust columns and number of results.

Common Mistake

Using a generic filter. Always create specific, well-defined saved filters to ensure the gadget displays relevant and actionable data.
