Key Concepts

Essential terms from this chapter.

Dashboard

A customizable, at-a-glance overview in Jira that displays key project information using various gadgets.

Gadget

A small, configurable module that displays specific information on a Jira dashboard (e.g., Filter Results, Pie Chart, Burndown Chart).

Saved Filter

A pre-defined JQL query saved for reuse, often used by gadgets to determine which issues to display.

Chapter Summary

Jira dashboards provide customizable, at-a-glance overviews of project status, team performance, and key metrics, acting as a personalized command center.
