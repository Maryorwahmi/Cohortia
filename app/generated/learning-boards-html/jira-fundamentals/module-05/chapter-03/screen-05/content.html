Gadgets: The Building Blocks of Your Dashboard

Small, configurable modules that display specific information.

What are Gadgets?
  • •Modular Displays: Each gadget focuses on a specific data type or report.
  • •Highly Configurable: Tailor data display using filters and settings.
  • •Diverse Functionality: From issue lists to charts and activity streams.
  • •Real-time Updates: Reflects the latest changes in Jira data.
Key Takeaway

Gadgets are the essential, customizable components that allow you to populate a Jira dashboard with diverse, real-time project information, making it a powerful reporting tool.

Common Gadget Categories

Issue Tracking Gadgets

Display lists of issues based on filters (e.g., 'Filter Results').

Statistical & Chart Gadgets

Visualize data distributions (e.g., 'Pie Chart', 'Two Dimensional Filter Statistics').

Progress & Planning Gadgets

Monitor sprint health, roadmaps, and burndown (e.g., 'Sprint Health', 'Jira Road Map').

Activity & Information Gadgets

Show recent changes or static text (e.g., 'Activity Stream', 'Text Gadget').

Misconception Alert

Don't confuse gadgets with full reports. Gadgets are components that *display* report-like data, often based on saved filters, but they are not the reports themselves.
