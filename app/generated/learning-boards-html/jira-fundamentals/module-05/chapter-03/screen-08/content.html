Pie Charts & Activity Streams: Proportions and Updates

Visualize distributions and stay informed on recent project changes.

Pie Chart Gadget
  • •Purpose: Visualizes issue counts as proportions of a whole.
  • •Configuration: Uses a saved filter and groups by a single field (e.g., Priority, Issue Type).
  • •Benefit: Excellent for quickly seeing distributions and relative sizes.
Activity Stream Gadget
  • •Purpose: Shows recent activity across your projects.
  • •Content: Includes comments, status changes, issue creations.
  • •Benefit: Keeps you updated on what's happening in real-time.
Key Takeaway

Pie Charts offer quick visual summaries of data distribution, while Activity Streams provide a continuous feed of project updates, both vital for a comprehensive dashboard.

Example: Bug Priority Distribution

Pie Chart Configuration

Filter: "All Bugs in Current Sprint"

Statistic Type: "Priority"

Visually shows the percentage of Critical, High, Medium, Low priority bugs.

Activity Stream Configuration

Projects: Select relevant projects (e.g., "Project Alpha", "Project Beta")

Max Activities: 10

Displays recent comments, status changes, and new issues across selected projects.

Common Pitfall

Overloading a pie chart with too many categories makes it unreadable. Consolidate or use a different gadget if you have more than 7 distinct slices.
