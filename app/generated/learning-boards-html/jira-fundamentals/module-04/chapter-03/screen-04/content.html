What is a Saved Filter?

A named, persistent JQL query that can be accessed and reused at any time. It's a fundamental building block for effective project management in Jira.

Primary Benefit: Reusability

Eliminates the need to recreate complex queries, saving time, reducing errors, and ensuring consistency in how teams view issue sets.

Powers Jira Features

Filters are integral to dashboards, agile boards, and reports, acting as the data source for these critical project management tools.

Example Scenario

Instead of typing assignee = currentUser() AND statusCategory != "Done" AND type = Bug every day, a saved filter named "My Open Bugs" provides this view instantly.

JQL Query to Saved Filter

project = "X" AND status = "Open"

Complex JQL

"Open Issues in Project X"

Named Filter

This transformation allows for quick, consistent access to specific issue sets, powering dashboards and reports.

Key Takeaway

Saved filters are indispensable for turning dynamic JQL queries into static, reusable views that drive efficiency and consistency across Jira.
