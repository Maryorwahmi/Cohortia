JQL Values: Data Types and Quoting

Handling Text, Numbers, and Dates Correctly

Value Types & Quoting Rules

  • •**Text Values:** Enclose in double quotes, especially if they contain spaces (e.g., `"New Feature"`).
  • •**Numeric Values:** Do not require quotes (e.g., `storyPoints > 5`).
  • •**Date Values (Specific):** Enclose in double quotes (e.g., `"2024-07-15"`).
  • •**Date Values (Relative):** Use quotes for relative dates (e.g., `"-1w"` for last week, `"-4h"` for last 4 hours).
Common Error

Forgetting quotes for text values with spaces, e.g., `project = My Project` instead of `project = "My Project"`.

Practical Examples

project = "Marketing"
status = Open
storyPoints > 5
duedate < "2024-12-31"
created >= "-1d"
Key Takeaway

Always ensure values are correctly formatted and quoted according to their data type to prevent syntax errors and ensure accurate search results.
