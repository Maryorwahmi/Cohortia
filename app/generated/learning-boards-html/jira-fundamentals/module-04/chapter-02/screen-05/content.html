The Building Blocks of a JQL Query

Understanding `field operator value`

Field

The attribute of an issue you want to query (e.g., `project`, `status`).

project

Operator

Defines the relationship between the field and its value (e.g., `=`, `IN`, `~`).

=

Value

The specific data point you're searching for (e.g., `"Website"`, `Open`).

"Website"
Key Takeaway

Every JQL query is built upon the fundamental `field operator value` structure, which defines what you're searching for and how it relates to specific data.
