Dynamic Filtering with JQL Functions (Part 1)

Using `currentUser()` and `membersOf()`

currentUser() Function

  • •**Purpose:** Dynamically refers to the user currently logged in.
  • •**Benefit:** Personalizes queries without hardcoding usernames.
  • •**Example:** `assignee = currentUser()` (Finds issues assigned to you).
  • •**Use Case:** Quickly see your own workload or issues where you are the reporter.

membersOf() Function

  • •**Purpose:** Finds issues related to members of a specified user group.
  • •**Benefit:** Efficiently query for team-wide issues without listing individual users.
  • •**Example:** `assignee IN membersOf("jira-developers")` (Assigned to anyone in the 'jira-developers' group).
  • •**Use Case:** Project managers tracking team workload or group-specific tasks.
Key Takeaway

`currentUser()` and `membersOf()` are powerful JQL functions that enable dynamic, context-aware filtering, making your queries more flexible and efficient for personal and team-based issue tracking.
