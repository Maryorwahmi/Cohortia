Accessing Jira's Basic Search Mode

Building Detailed Queries Without Complex Syntax

Steps to Access Basic Search

  1. Navigate: Click "Issues" in the top navigation bar.
  2. Select: Choose "Search for issues" from the dropdown menu.
  3. Verify Mode: Ensure "Basic" mode is selected (often default).
  4. Start Filtering: Use dropdowns and input fields to add criteria.
Key Takeaway

Basic Search offers an intuitive, form-based interface for building precise queries by selecting criteria from predefined fields.

Basic Search Interface Overview

Common Fields Displayed

You'll typically see dropdowns for Project, Issue Type, Status, Assignee, Reporter, Priority, and Resolution.

Example: Finding 'In Progress' Bugs

Select 'Website Redesign' (Project), 'Bug' (Issue Type), and 'In Progress' (Status) to filter results.
