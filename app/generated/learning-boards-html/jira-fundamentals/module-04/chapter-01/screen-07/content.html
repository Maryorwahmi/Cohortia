Fundamental Fields in Basic Search

Pinpointing Specific Information with Key Attributes

Core Filtering Fields

  • Project: Filters issues by their associated project.
  • Issue Type: Filters by the nature of the work (e.g., Story, Bug).
  • Status: Filters by current workflow stage (e.g., To Do, In Progress).
  • Assignee: Filters by the user currently responsible for the issue.
  • Reporter: Filters by the user who created the issue.
  • Priority: Filters by the urgency level (e.g., Highest, Low).
  • Resolution: Filters by the final outcome of a completed issue.
Key Takeaway

Each fundamental field in Basic Search acts as a distinct filter, allowing you to build highly specific queries by combining issue attributes.

Field Examples & Purpose

Project: Website Redesign (Focus on a specific project's issues)
Issue Type: Bug (Find only defect reports)
Status: In Progress (See what's actively being worked on)
Assignee: Sarah Connor (Identify issues assigned to a team member)
