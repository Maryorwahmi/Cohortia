Implicit Operators and Advanced Filters

Combining Criteria and Expanding Your Search Capabilities

How Criteria are Combined

  • Implicit 'AND': Multiple selected criteria are combined with a logical 'AND'.
  • All Must Match: An issue must satisfy every selected filter to appear in results.
  • '+ More' Button: Expands available filters to include additional standard and custom fields.
  • Enhanced Specificity: Allows for highly detailed and nuanced queries.
Key Takeaway

Basic Search uses implicit 'AND' logic to combine filters, and the '+ More' button unlocks a wider range of fields for highly specific queries.

Combining Filters in Practice

Example: 'AND' Logic

Selecting 'Project: Website' AND 'Issue Type: Bug' AND 'Status: Open' will only show open bugs in the Website project.

Example: Using '+ More'

Add 'Component: User Interface' to find open bugs in the Website project specifically affecting the UI.
