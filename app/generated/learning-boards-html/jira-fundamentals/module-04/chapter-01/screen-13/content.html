Key Concepts

What to Remember from This Chapter

Quick Search

A fast, intuitive search bar for finding issues by key, keyword, or user for immediate lookups.

Basic Search

A user-friendly interface for building complex queries using dropdowns and input fields without special syntax.

Fields

Specific attributes of an issue (e.g., Project, Issue Type, Status, Assignee) used as filters.

Summary Takeaway

Quick Search and Basic Search, combined with an understanding of fundamental fields, are your primary tools for efficient issue discovery in Jira.
