Saved Filters: The Data Source for Your Gadgets

How pre-defined filters power dynamic and up-to-date dashboard displays.

The Crucial Link

Many powerful gadgets don't generate their own data; they rely on a pre-configured and saved filter to define the specific set of issues they will display or analyze.

Key Takeaway

Mastering saved filters is fundamental to creating dynamic and accurate dashboards, as they serve as the essential data source for most gadgets.

Filter-Gadget Workflow
  1. 1. Define Issues: Create a JQL query to specify the exact issues you need.
  2. 2. Save Filter: Save your query as a named filter (e.g., "My Open Tasks").
  3. 3. Add Gadget: Place a relevant gadget (e.g., Filter Results) on your dashboard.
  4. 4. Select Filter: Configure the gadget to use your saved filter as its data source.
  5. 5. Auto-Update: Any changes to the filter or issues automatically reflect in the gadget.
Misconception Check

Some users mistakenly think gadgets can define their own complex queries. In reality, for consistent and powerful data, gadgets rely on *pre-existing saved filters* to ensure data integrity and reusability.
