The Filter Results Gadget: Displaying Issue Lists

A fundamental gadget for showing issues from a saved filter in a table format.

How it Works

This gadget takes a pre-defined saved filter as its data source and displays the resulting issues in a customizable table directly on your dashboard. It's dynamic, updating as issues change.

Key Takeaway

The Filter Results Gadget is essential for displaying specific, filtered lists of issues, providing immediate visibility into critical tasks or problems.

Configuration Options
  • Select Saved Filter: Choose the filter that defines the issues to display.
  • Columns: Specify which issue fields (e.g., Key, Summary, Assignee, Status) appear in the table.
  • Max Results: Set the maximum number of issues to show.
Example Use Case

A team lead creates a filter for "All Open Bugs in Project Alpha." They then add a Filter Results Gadget to their dashboard, selecting this filter to get a real-time list of all active bugs, allowing for quick prioritization and assignment.
