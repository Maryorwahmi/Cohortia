Beyond the Basics: More Powerful Gadgets

Exploring additional gadgets for diverse dashboard needs.

Why Explore More?

Different project roles and reporting needs require a variety of data presentations. Exploring other gadgets allows you to build a more comprehensive and tailored dashboard.

Key Takeaway

Leverage Jira's diverse gadget library to create a truly comprehensive dashboard that addresses all your specific reporting and tracking requirements.

Additional Gadgets
  • Filter Statistics Gadget: Displays issue counts for a single field (e.g., issues by Priority).
  • Assigned to Me Gadget: Shows all issues currently assigned to your user.
  • Activity Stream Gadget: Provides a dynamic feed of recent activity across Jira.
  • Introduction Gadget: Allows adding custom text, instructions, or welcome messages.
Example Application

A team lead adds an 'Assigned to Me' gadget for quick personal task review, alongside an 'Activity Stream' to stay updated on recent project changes, creating a holistic personal workspace.
