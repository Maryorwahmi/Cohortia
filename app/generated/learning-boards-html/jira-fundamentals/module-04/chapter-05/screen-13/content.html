Automated Reporting: Dashboard Subscriptions

Delivering Timely Snapshots to Stakeholders

Automated Dashboard Snapshots

Sends an image or PDF snapshot of the entire dashboard at a specified frequency.

Configurable for Stakeholders

Define recipients, frequency (weekly, monthly), and format to keep non-Jira users informed.

Key Takeaway

Dashboard subscriptions are a powerful tool for effortless, consistent reporting and stakeholder communication.

Subscription Setup Flow
Go to your Dashboard
Click '...' menu > 'Subscribe'
Define Recipients
Set Frequency & Format
Click 'Subscribe'
Common Misconception

Dashboard subscriptions are the same as filter subscriptions. Filter subscriptions notify about issue changes, not dashboard snapshots.
