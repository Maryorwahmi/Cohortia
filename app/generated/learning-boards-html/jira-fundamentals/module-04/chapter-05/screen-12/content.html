Granular Control: Dashboard Sharing Levels

Understanding Different Access Options

Private

  • •Only the creator can view.
  • •Ideal for personal dashboards or highly sensitive information.
Use Case

Your personal task management dashboard.

Public

  • •Everyone in your Jira instance can view.
  • •Use sparingly for general, non-sensitive information.
Caution

Avoid for sensitive data; broad visibility can be risky.

Project

  • •Share with specific projects.
  • •Common for project-specific dashboards.
Benefit

All project members have relevant access.

Group

  • •Share with specific user groups.
  • •Excellent for team-specific dashboards.
Pro Tip

Use for 'Development Team Dashboard' or 'QA Team Dashboard'.

Key Takeaway

Selecting the appropriate sharing level ensures dashboards are accessible to the right audience while maintaining security and control.
