Managing Access: Configuring Dashboard Permissions

Controlling Who Can View and Edit Your Dashboards

Initial Setup & Modification

Permissions are set during creation and can be modified anytime via 'Dashboards' > 'View all dashboards' > '...' menu > 'Edit'.

Balancing Transparency & Security

Ensure the right people have access to relevant data while protecting sensitive information.

Key Takeaway

Proper permission configuration is essential for secure collaboration and effective information dissemination.

Permission Configuration Flow
Create Dashboard
Set Initial Permissions
Navigate to 'View all dashboards'
Click '...' menu > 'Edit'
Modify Sharing Settings
Pro Tip

Be cautious with 'editors' permissions; too many can lead to inconsistent changes.
