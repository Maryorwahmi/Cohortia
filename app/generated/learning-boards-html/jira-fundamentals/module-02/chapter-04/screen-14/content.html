Key Concepts: Issue Relationships

Essential Terms for Connected Workflows

Issue Linking

The process of establishing explicit connections between two or more Jira issues.

Link Type

Defines the nature of the relationship between linked issues (e.g., "blocks," "relates to," "duplicates").

"blocks" Link

A critical dependency indicating that one issue cannot proceed until another is resolved.

Summary Takeaway

Issue linking and its various types are fundamental for defining explicit relationships and managing dependencies, ensuring clear communication and preventing project bottlenecks.
