Linking Issues Effectively

Steps and Pitfalls to Avoid for Clear Dependencies

01

Open Issue & Find Link Option

Navigate to one of the issues you wish to link. Look for the 'Link issue' option, typically in the 'More' menu or issue details panel.

02

Search & Select Target Issue

Use the search bar to find and select the issue you want to establish a relationship with. Ensure you pick the correct one.

03

Choose Correct Link Type

Crucially, select the link type that accurately describes the relationship (e.g., 'blocks', 'relates to', 'duplicates'). This defines the meaning of the connection.

04

Add Optional Comment & Link

Provide a brief comment for additional context if needed, then confirm to create the link. This completes the relationship establishment.

Common Mistake

Misusing 'Relates To'

A frequent error is using the generic 'relates to' link when a stronger dependency, such as 'blocks,' is actually present. This can obscure critical dependencies, leading to missed bottlenecks and project delays because the true relationship isn't clearly communicated.

Key Takeaway

Always choose the most precise link type to accurately represent dependencies and ensure clear communication across your team.

Pro Tip

Visualize Dependencies

Regularly review your linked issues, especially 'blocks' relationships, on boards or in reports. This visual overview helps identify potential bottlenecks and manage critical paths proactively, ensuring smoother project execution.
