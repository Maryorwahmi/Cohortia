Jira's Issue Hierarchy

Epic → Story/Task/Bug → Sub-task

Epic

Large initiative or major feature

Strategic Goal

Story / Task / Bug

Core work items contributing to the Epic

Feature / Work Item / Defect

Sub-task

Smaller, granular pieces of work for a parent issue

Granular Action
Key Takeaway

Jira's hierarchy provides a clear, multi-level structure for organizing work, from high-level strategic initiatives down to individual, actionable tasks.
