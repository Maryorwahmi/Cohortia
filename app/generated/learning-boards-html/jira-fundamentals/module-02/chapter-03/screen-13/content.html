Controlling Field Visibility & Behavior

Field Configurations and Screens

Screens

Define which fields appear on different issue operation dialogs (e.g., Create, View, Edit) for specific issue types and projects.

Field Configurations

Control the behavior of individual fields (e.g., required, hidden, read-only) for specific issue types.

Key Takeaway

Field configurations and screens are crucial administrative tools for tailoring the Jira user experience and ensuring data quality by controlling field relevance.

Field Control in Action
'Steps to Reproduce' field: Mandatory for 'Bug' issue type.
'Due Date' field: Hidden on 'Story' creation screen.
'Customer Impact Score' (Custom Field): Visible only on 'Support Request' issue type.
Example Scenario

When creating a 'Bug', the 'Steps to Reproduce' field is mandatory, ensuring critical information is always captured. For a 'Story', this field might be hidden as it's not relevant.
