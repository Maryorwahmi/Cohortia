Flexible Categorization: Labels

Ad-Hoc Tagging for Cross-Cutting Themes

What are Labels?

Flexible, user-defined tags for ad-hoc categorization of issues. You can add multiple labels to an issue.

Use Cases
  • Quick filtering (e.g., all `frontend` issues).
  • Categorizing cross-cutting themes (e.g., `security`, `performance`).
  • Temporary initiatives or focus areas.
Key Takeaway

Labels are highly adaptable for dynamic categorization, but consistent naming is crucial for effective filtering and reporting.

Labels in Action
frontenddatabaseauthenticationUI/UXbug

An issue can have multiple labels, allowing for multi-dimensional, informal tagging. This flexibility is ideal for quick, evolving categorization needs.

Example Scenario

A bug report might be labeled `bug`, `frontend`, and `critical-path` to quickly identify its type, affected area, and urgency for filtering.
