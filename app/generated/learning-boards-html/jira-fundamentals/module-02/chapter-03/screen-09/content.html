Release Management: Fix Versions & Affects Versions

Tracking Issues Across Product Releases

Fix Versions

Specifies the product version in which an issue is expected to be resolved. Crucial for release planning.

Affects Versions

Indicates which product versions are impacted by a reported defect. Primarily used for bugs to understand scope.

Key Takeaway

Fix Versions and Affects Versions are indispensable for structured release management, ensuring clear communication and tracking of features and defects.

Release Tracking Flow
Bug ReportedAffects: v1.0, v1.1
Feature DevelopmentFix: v1.2
Hotfix ReleaseFix: v1.1.1
Example Scenario

A critical bug found in `v1.0` would have `Affects Versions: v1.0` and `Fix Versions: v1.0.1` if a hotfix is planned, or `v1.1` if it's bundled with the next major release.
