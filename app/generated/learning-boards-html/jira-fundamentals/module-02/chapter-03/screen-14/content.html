Key Concepts: Core Fields

Essential Jira Terminology

Standard Fields

Pre-defined fields in Jira for common issue information (e.g., Summary, Description, Assignee).

Labels

Flexible, informal, user-defined tags for ad-hoc categorization of issues and quick filtering.

Components

Structured categories representing distinct sub-sections of a project, for organizing work by product area.

Summary Takeaway

Standard fields provide the basic structure, while Labels offer flexible tagging and Components enable structured organization by project area.
