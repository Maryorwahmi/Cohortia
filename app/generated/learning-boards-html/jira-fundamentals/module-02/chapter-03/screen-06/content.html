Time-Based Tracking & Iteration

Managing Deadlines and Sprints

Due Date

Specifies a target date for issue completion. Vital for time-sensitive tasks and project planning.

Sprint

Links an issue to a specific sprint in Scrum projects, indicating planned work for that iteration.

Key Takeaway

Due Date and Sprint fields are essential for both long-term project planning and agile iteration management, ensuring work is delivered on time.
