General Work Items: The Task

Essential work that supports project completion but may not deliver direct user value

What is a Task?

A Task is a general piece of work that needs to be done. It's broader than a Story and doesn't necessarily deliver direct user value, but it's crucial for project completion.

  • •General Work: Covers a wide range of activities, from setup to documentation.
  • •Supporting Role: Often supports Stories or Epics without being a user-facing feature itself.
  • •Essential: Critical for the smooth functioning and completion of a project.
Key Takeaway

Tasks ensure that all necessary supporting work, even if not directly user-facing, is tracked and managed for overall project success.

Example: Documentation Task

"Write user guide for new payment gateway." This is a clear piece of work that needs to be done, but it's not a user story because it doesn't describe a direct user interaction with the software itself.

Misconception: Task vs. Story

Don't confuse a Task with a Story. If the work delivers direct, tangible value to the end-user and can be expressed from their perspective, it's likely a Story. If it's internal work supporting the project, it's a Task.
