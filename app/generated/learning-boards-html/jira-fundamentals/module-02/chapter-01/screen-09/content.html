Large Initiatives: The Epic

Organizing significant features and bodies of work across multiple sprints

What is an Epic?

An Epic is a large body of work that can be broken down into a number of smaller Stories, Tasks, and Bugs. It represents a significant feature or initiative, often spanning multiple sprints or releases.

  • •High-Level View: Provides a strategic overview of major project goals.
  • •Container for Work: Groups related smaller issues under a single, larger theme.
  • •Long-Term: Can extend over several sprints, guiding continuous development.
Key Takeaway

Epics are crucial for managing complex projects, providing a strategic roadmap and organizing smaller work items under a cohesive vision.

Example: New User Authentication

An Epic like "Implement New User Authentication System" could contain Stories for "User Login," "Password Reset," and "Two-Factor Authentication," along with Tasks for backend setup.

Misconception: Epic vs. Large Story

An Epic is not just a very large Story. It's a strategic container for multiple Stories and other work types, representing a significant, multi-sprint initiative, whereas a Story is a single, sprint-sized user requirement.
