Initiating Work: The 'Create' Button

The fundamental action to kick off any work item in your Jira project.

The Starting Point

Clicking the 'Create' button is the first step to formally logging any task, bug, or feature into Jira.

Opens 'Create Issue' Dialog

This action brings up a dedicated dialog box where you'll define all the necessary details for your new work item.

Key Takeaway

The 'Create' button is the essential entry point for all new work in Jira, initiating the formal tracking and management process.
