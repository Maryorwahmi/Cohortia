The Description Field & Markdown

Provide comprehensive context and requirements using structured, readable Markdown.

Detailed Information

Elaborate on the summary, providing context, requirements, steps to reproduce, or acceptance criteria.

Markdown for Readability

Use headings, lists, bold/italic text, and code blocks to organize and format your description.

Key Takeaway

A well-structured description using Markdown prevents misunderstandings and ensures all necessary details are clear.

**Acceptance Criteria:**
* User can navigate to "Order History" page.
* Page displays a list of past orders.
* Each order shows date, total amount, and status.
* Clicking an order shows order details.

**Steps to reproduce:**
1. Log in as a registered user.
2. Add item 'Product X' to cart.
3. Proceed to checkout.

**Expected result:**
Product X shows price $10.00.

**Actual result:**
Product X shows price $9.00.
