Editing Issues: The 'Edit' Dialog

Access all editable fields and manage complex updates, including issue type changes.

Access via 'Edit' Button

Click the pencil icon or 'Edit' button on the issue view screen to open the full edit dialog.

Comprehensive Field Access

Modify all editable fields, including descriptions, components, and even issue type.

Issue Type Changes

Be cautious when changing issue types, as it can trigger workflow changes and impact fields.

Key Takeaway

The 'Edit' dialog is for extensive, controlled modifications, especially when changing issue types, requiring careful consideration of workflow impacts.
