Salary grade example
SELECT e.first_name, e.last_name, e.salary, jg.grade_level
FROM employees e
JOIN job_grades jg
  ON e.salary BETWEEN jg.min_salary AND jg.max_salary
ORDER BY e.salary DESC;
This maps each salary to a grade range defined in the lookup table without needing CASE statements.
Important checks
  • Validate that ranges in job_grades do not overlap.
  • Decide how to handle boundary values; BETWEEN includes both ends.
  • Test with edge salaries to confirm single matching grade.
Common pitfall
Overlapping ranges produce duplicate rows in the result; clean or prioritize ranges to ensure unique matches.
Key Takeaway
Non-equi joins are cleaner than complex CASE logic for range matching, but require careful lookup-table design.
