Assessment prompts
  1. List employees in the same department as employee_id 100, excluding that employee (self-join).
  2. Find employees hired before their manager (self-join with hire_date comparison).
  3. Map each employee to a grade level using job_grades and BETWEEN (non-equi join).
Validation: compare counts, test edge salaries, check for null manager rows, and inspect query plans for performance issues.
Grading tip
A correct solution demonstrates correct aliases, handles nulls as required, and avoids duplicate rows from overlapping ranges.
Extend
Add a precedence column to job_grades to deterministically resolve edge overlaps when business rules require it.
Reflection
Which join pattern reduced complexity in your queries and why? Use that insight to guide future schema or lookup design.
