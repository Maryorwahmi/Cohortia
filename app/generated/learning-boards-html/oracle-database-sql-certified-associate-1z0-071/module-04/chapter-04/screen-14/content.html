Module 5 › Chapter 4.4 › Key Concepts
SELF-JOIN
Join a table to itself with aliases to relate rows like employee and manager.
CROSS JOIN
Use only when every combination is required, such as product and color option matrices.
NON-EQUIJOIN
Join on comparisons or ranges, for example mapping salary into grade bands using BETWEEN.
Summary
Aliases, explicit intent, and lookup validation keep advanced joins correct and performant.
