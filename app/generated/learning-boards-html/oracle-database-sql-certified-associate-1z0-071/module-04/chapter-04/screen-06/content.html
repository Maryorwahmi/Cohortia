Module 5 › Chapter 4.4 › Salary comparison
Query example
SELECT e.first_name || ' ' || e.last_name AS Employee,
       e.salary        AS Employee_Salary,
       m.first_name || ' ' || m.last_name AS Manager,
       m.salary        AS Manager_Salary
FROM employees e
JOIN employees m
  ON e.manager_id = m.employee_id
WHERE e.salary > m.salary
ORDER BY Employee_Salary DESC;
Why use this
It surfaces pay inversion inside reporting chains, a frequent audit metric for comp fairness reviews.
Misconception
This does not require nested subqueries; a self-join with a comparative WHERE is often simpler and easier to optimize.
Key Takeaway
Self-joins make intra-table comparisons explicit and extendable; pick join type to control unmatched rows.
