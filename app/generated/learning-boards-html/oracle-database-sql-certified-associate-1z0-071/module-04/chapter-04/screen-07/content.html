Module 5 › Chapter 4.4 › Outer SELF-JOIN
LEFT JOIN pattern
SELECT e.first_name || ' ' || e.last_name AS Employee,
       COALESCE(m.first_name || ' ' || m.last_name, 'No Manager') AS Manager
FROM employees e
LEFT JOIN employees m
  ON e.manager_id = m.employee_id
ORDER BY Employee;
This preserves every employee row; manager fields will be null for top-level positions unless COALESCE supplies a placeholder.
Use case
Generate a directory that includes everyone, making it clear who lacks a manager for follow-up.
Gotcha
If you then apply a WHERE filter against the manager table without guarding for nulls, you may unintentionally convert the outer join back into an inner join.
Key Takeaway
Use LEFT JOIN in self-joins to include unmatched rows and handle nulls explicitly in SELECT or WHERE clauses.
