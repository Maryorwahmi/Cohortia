Module 4 › Chapter 4.3 › Common join mistakes

Accidental Cartesian product

Forgetting the ON or WHERE condition multiplies rows. Always confirm your join condition produces expected record counts.

Quick test
Run an INNER JOIN first to verify matches, then change to outer joins if you need unmatched rows included.

Filtering and NULLs

Applying WHERE to a column from an outer-joined table can remove rows that were preserved. Move such predicates into the JOIN clause or write predicates that allow NULL values when preservation is intended.

Oracle note
Oracle supports an older outer-join operator with a plus sign in the WHERE clause, but prefer ANSI JOIN keywords for portability and clarity.
