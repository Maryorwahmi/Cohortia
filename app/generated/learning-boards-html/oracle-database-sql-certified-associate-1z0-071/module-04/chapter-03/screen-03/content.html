Practical Tasks

  • Compose an inner join to list employees with their department names.
  • Refactor that join to use USING when column names match.
  • Write left, right, and full joins to reveal unmatched rows and NULLs.
  • Interpret NULL results and decide which join best supports a report.
VERIFIED COMPETENCY MILESTONE
Mnemonic
Remember: intersection for matches, preserve left or right for non-matches, and union for everything with NULLs where needed.
Check before expand
Start with INNER JOIN results to validate your matching condition before adding outer joins.
Nulls are signals
A NULL in a joined column means there was no matching partner; treat it as a missing relation, not data corruption.
