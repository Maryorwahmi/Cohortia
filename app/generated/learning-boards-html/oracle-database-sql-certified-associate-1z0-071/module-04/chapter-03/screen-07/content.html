LEFT JOIN semantics

Returns every row from the left table. Matching right-table columns are included; unmatched ones become NULL.

Example SQL
SELECT e.first_name, e.last_name, d.department_name
FROM employees e LEFT JOIN departments d
ON e.department_id = d.department_id;
Use case
Produce a roster listing all staff even when some have no department assigned, so managers can see who needs assignment.
Interpretation tips
  • NULL in department_name signals no match — not a failing of the join syntax.
  • If you want only matched rows, convert to INNER JOIN instead.
  • Switch the table order to change which side is preserved; use RIGHT JOIN only when needed.
Common Mistake

Expecting NULLs to be filtered automatically. If you apply WHERE conditions referencing right-table columns, you may unintentionally remove preserved rows; use conditions in the JOIN clause where appropriate.
