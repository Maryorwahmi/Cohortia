Module 4 › Chapter 4.3 › Cartesian Product vs INNER JOIN

Cross Join (Cartesian Product)

Every row from table A pairs with every row from table B. Often accidental and large.

Example SQL
-- Implicit Cartesian Product (avoid)
SELECT e.employee_id, d.department_name
FROM employees e, departments d;

-- Explicit Cross Join
SELECT e.employee_id, d.department_name
FROM employees e CROSS JOIN departments d;
Misconception
Forgetting the ON clause will not be silently fixed by the engine. You will get a larger, usually wrong, result set.

INNER JOIN

Returns only rows where the join condition matches in both tables.

Example SQL
-- Explicit Inner Join
SELECT e.first_name, e.last_name, d.department_name
FROM employees e INNER JOIN departments d
ON e.department_id = d.department_id;
Quick check
If an employee's department_id is NULL or has no matching department, that employee will not appear in an inner join result.
