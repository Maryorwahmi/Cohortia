Objective visuals
Mnemonic: Link keys
Think of the shared key as a bridge that joins table islands into a single map.
Venn: Matches only vs preserve sides
Inner join is intersection; left and right are one-sided preserves; full is union with NULL fills.
Practice tip
Start with INNER JOIN to verify matches, then add LEFT to reveal missing associations.
