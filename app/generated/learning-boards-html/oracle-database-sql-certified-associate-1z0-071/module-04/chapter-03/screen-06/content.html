Module 4 › Chapter 4.3 › INNER JOIN with ON and USING

ON clause: maximum flexibility

Use ON to express equality between any columns or compose multi-part conditions.

Example
SELECT e.first_name, e.last_name, d.department_name
FROM employees e INNER JOIN departments d
ON e.department_id = d.department_id;
When to use ON
When column names differ, or when you need additional conditions beyond simple equality.

USING shorthand: concise joins

USING works only when the join column has the exact same name in both tables and hides duplicate column names in the output.

Example
SELECT e.first_name, e.last_name, d.department_name
FROM employees e INNER JOIN departments d
USING (department_id);
Limitation
Cannot be used if the join column names differ or when you need compound or non-equality conditions; choose ON then.
