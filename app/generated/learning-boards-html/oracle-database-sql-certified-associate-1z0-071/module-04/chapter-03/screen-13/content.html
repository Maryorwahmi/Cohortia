Module 4 › Chapter 4.3 › Key Concepts
Join
Combine rows from two or more tables using a related column to produce meaningful, composite results.
Cartesian Product
Occurs when no join condition is given; every row pairs with every other row, usually unwanted.
INNER vs OUTER
Inner joins return only matches; outer joins preserve one or both sides and display NULLs for missing partners.
Takeaway
Always state the join condition, choose the preservation side deliberately, and interpret NULLs as missing relationships.
