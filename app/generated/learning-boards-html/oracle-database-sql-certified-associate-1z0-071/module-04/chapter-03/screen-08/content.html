RIGHT JOIN semantics

Returns every row from the right table. Left-table columns are NULL where no match exists.

Example SQL
SELECT e.first_name, e.last_name, d.department_name
FROM employees e RIGHT JOIN departments d
ON e.department_id = d.department_id;

Practical guidance

Many teams prefer left-first queries for readability. To guarantee all departments show up, place departments first and use LEFT JOIN instead of RIGHT JOIN.

Example conversion
employees RIGHT JOIN departments is equivalent to departments LEFT JOIN employees if you swap the FROM order and adjust the SELECT expressions accordingly.
Pitfall

Confusing which table is preserved leads to missing expected rows. Ask: "Which set must appear in full?" and choose LEFT or RIGHT accordingly.
