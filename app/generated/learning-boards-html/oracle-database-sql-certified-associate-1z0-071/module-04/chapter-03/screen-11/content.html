Module 4 › Chapter 4.3 › Deciding which join to use

Step-by-step checklist

  1. 1. Which table must appear completely? Preserve that side.
  2. 2. Start with INNER JOIN to validate matches.
  3. 3. Switch to LEFT or RIGHT to include unmatched rows from one side.
  4. 4. Use FULL to include everything from both sides if needed.
Example
To ensure all employees appear, set employees as the preserved side and apply LEFT JOIN to departments.
Tips & checks
  • Watch where you place filters: filtering a NULL-producing column in WHERE can remove preserved rows.
  • Label your SELECT list to clarify when columns may be NULL for non-matches.
  • Confirm row counts after changing join types to validate expected preservation behavior.
Key Takeaway

A small decision checklist prevents many join-related errors and keeps query intent clear for reviewers.
