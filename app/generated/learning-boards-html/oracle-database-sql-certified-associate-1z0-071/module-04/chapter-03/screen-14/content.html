Module 4 › Chapter 4.3 › What to Remember
USING vs ON
USING is concise for identical column names; ON is flexible for renamed columns or complex conditions.
Start with INNER
Validate matches first with INNER JOIN, then expand to outer joins when you need unmatched rows.
Avoid accidental cross joins
Always confirm a join condition is present; unexpected multiplication of rows usually signals a missing clause.
WHERE vs JOIN filters
Filters on outer-joined columns can remove preserved rows if applied in WHERE; place them in the JOIN when appropriate.
FULL JOIN caution
FULL JOIN returns all rows from both sides; if unsupported, emulate with a union of left and right joins.
