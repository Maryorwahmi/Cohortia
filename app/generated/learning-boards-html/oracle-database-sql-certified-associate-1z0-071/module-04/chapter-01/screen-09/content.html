Module 04 › Chapter 4.1 › Starter Queries

Practice list

  1. Find total number of employees using the all-rows count.
  2. Find the total salary paid with SUM.
  3. Compute the average salary using AVG and note null handling.
  4. Find MIN and MAX for salary and hire date to identify extremes.
  5. Count unique job IDs using COUNT with DISTINCT.
  6. Compute AVG of commission treating NULL as zero using NVL or COALESCE.
Pro Tip

After running each query, ask which rows were included and whether NULLs or DISTINCT changed the intended metric.

-- Starter queries shown for practice (run in your SQL tool)
-- 1 Total employees
SELECT COUNT(*) FROM employees;

-- 2 Total salary
SELECT SUM(salary) FROM employees;

-- 3 Average salary
SELECT AVG(salary) FROM employees;

-- 4 Min/Max salary and hire date
SELECT MIN(hire_date), MAX(salary) FROM employees;

-- 5 Count unique job IDs
SELECT COUNT(DISTINCT job_id) FROM employees;

-- 6 Average commission treating NULL as zero
SELECT AVG(NVL(commission_pct, 0)) FROM employees;
