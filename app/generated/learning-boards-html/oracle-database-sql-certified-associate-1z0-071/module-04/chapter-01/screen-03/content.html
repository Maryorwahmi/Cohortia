Practice Tasks

Use the starter queries to practice each objective and explain the effect of DISTINCT and NULL handling.

Total headcount — COUNT all rows
Total salary — SUM numeric values
Average salary — AVG and NULL behavior
Min/max — earliest hire, highest pay
COUNT DISTINCT — unique job IDs
AVG with NVL — treat NULL as zero
Key Takeaway

Practice both the query and the interpretation. Correct SQL is only half the skill — explaining the result is the rest.

Assessment idea
Run the six starter queries, record results, and explain any differences when DISTINCT or NVL are applied.
