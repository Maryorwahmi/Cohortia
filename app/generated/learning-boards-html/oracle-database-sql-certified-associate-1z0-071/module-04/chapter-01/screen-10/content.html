Frequent pitfalls

Mistake: COUNT(column) ≠ total rows
If the column has NULLs you will undercount. Use COUNT star for total rows.
Mistake: Using DISTINCT indiscriminately
DISTINCT removes duplicates before aggregation and can distort totals or averages.
Mistake: Ignoring NULL semantics
NULLs are excluded from SUM and AVG. Decide if they represent unknowns or zeros and substitute if needed.
Mistake: Expecting aggregates to return rows
Aggregates return values. To get rows that match an extreme value, run a lookup using the aggregate result.
Quick checklist
  • Did you mean total rows or non-null values?
  • Should NULL be treated as zero for your metric?
  • Does DISTINCT match your analytic intent?
