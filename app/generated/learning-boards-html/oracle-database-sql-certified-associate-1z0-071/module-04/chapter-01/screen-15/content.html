Module 04 › Chapter 4.1 › What to Remember
COUNT distinctions
COUNT(*) vs COUNT(column) — know which you need.
NULL handling
Aggregates ignore NULLs by default; substitute when necessary.
DISTINCT use
DISTINCT makes the aggregate consider unique values only — use deliberately.
Final tip

Show both raw and substituted aggregate results when presenting to stakeholders so they can see the impact of NULL handling and DISTINCT.
