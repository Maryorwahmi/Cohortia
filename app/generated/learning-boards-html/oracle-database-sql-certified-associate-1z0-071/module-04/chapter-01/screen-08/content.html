Module 04 › Chapter 4.1 › DISTINCT inside Aggregates
Definition & Guidance

Consider uniqueness before aggregating

DISTINCT filters duplicate values before the aggregate runs. Use it when you need a unique count or average of distinct values, not when you want totals across all rows.

COUNT DISTINCT
Counts unique categories, e.g., unique department IDs.
AVG DISTINCT
Averages only unique values — often not desired for salary averages.
SUM DISTINCT
Sums each distinct value once — rarely the payroll total you want.
Example
SELECT COUNT(DISTINCT department_id) FROM employees returns the number of unique departments with employees.
Key Takeaway

Use DISTINCT when uniqueness is required. Avoid it for totals unless you specifically need to remove duplicate values first.
