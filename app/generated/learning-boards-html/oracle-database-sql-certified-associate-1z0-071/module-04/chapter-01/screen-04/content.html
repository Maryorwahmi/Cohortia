Module 04 › Chapter 4.1 › What are Group Functions?
Definition

Group functions produce a single summary value

They operate on sets of rows to return a count, total, average, minimum, or maximum. Aggregates are essential for reporting and analysis.

• Aggregate query returns one value for the chosen set, not one per row.
• Aggregates ignore NULLs in the column being aggregated unless you replace them.
• Use NVL or COALESCE to substitute values when you must include NULLs in calculations.
Concrete Example
Imagine an employees table with five rows of salary values. A SUM on salary returns one total pay number. If a salary is NULL, SUM ignores that row. If HR expects NULL to mean zero, you must replace NULLs first.
-- Visual starter queries (for reference)
-- Total number of employees
SELECT COUNT(*) FROM employees;

-- Total salary
SELECT SUM(salary) FROM employees;

-- Average salary (ignores NULLs)
SELECT AVG(salary) FROM employees;
Key Takeaway

Group functions summarize rows into one value. Always confirm which rows were included and whether NULLs or DISTINCT changed the result.
