Module 04 › Chapter 4.1 › Interpreting Aggregate Results

Interpretation checklist

  • What selection or filter produced the input rows?
  • Were NULLs excluded or substituted?
  • Did DISTINCT remove duplicates before aggregation?
  • Does the metric reflect the intended business definition?
Validation step
Run a companion COUNT on the same selection to verify how many rows contributed to the aggregate value.
Example comparison
Show both AVG(commission) and AVG after substituting NULL with zero to demonstrate how treating NULLs changes the metric and the story for stakeholders.
