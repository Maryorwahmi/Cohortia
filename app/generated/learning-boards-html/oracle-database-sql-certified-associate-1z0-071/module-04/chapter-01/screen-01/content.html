Introduction to Group Functions

Turn row-level data into single summary values. Learn how COUNT, SUM, AVG, MIN and MAX provide fast answers for reporting and analysis.

In this lesson you will learn what each group function does, how NULLs are treated, and when to use DISTINCT.
Practical examples use an employees table: headcount, total payroll, averages, and extremes.
Visual overview
Counts
COUNT counts rows or non-null values depending on usage.
Sums & Averages
SUM totals numbers; AVG computes the mean and ignores nulls unless replaced.
Extremes
MIN and MAX find smallest and largest values across a set.
Concept Map
COUNT
COUNT star counts rows; COUNT column counts non-null entries.
SUM / AVG
SUM totals numeric values; AVG computes the mean and ignores nulls.
MIN / MAX
Find smallest and largest values; works on dates and text too.
DISTINCT
Applies inside aggregates to consider unique values only.
