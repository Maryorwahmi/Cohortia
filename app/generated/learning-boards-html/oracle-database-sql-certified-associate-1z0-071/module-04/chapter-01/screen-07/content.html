Module 04 › Chapter 4.1 › MIN and MAX: Finding Extremes
Concept

Locate smallest and largest values across a set

These functions return the extreme value itself. Use on dates to find earliest hire or on numeric salary to find the maximum pay.

MIN(hire_date)
Returns the earliest hire date. NULLs are ignored.
MAX(salary)
Returns the highest salary. NULLs are ignored.
Use for thresholds and identifying outliers
Works on numbers, text, dates
Does not return the row — only the value
Example outputs
MIN(hire_date): 1997-06-01 (earliest hire) MAX(salary): 24000 (highest salary)
To fetch the full employee row with the top salary, combine the MAX result with a query that selects the row matching that value.
Key Takeaway

MIN and MAX return value extremes and ignore NULLs. If you need the row that holds an extreme, use an additional lookup step.
