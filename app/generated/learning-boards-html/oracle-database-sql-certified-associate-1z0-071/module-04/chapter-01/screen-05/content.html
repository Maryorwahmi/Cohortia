Module 04 › Chapter 4.1 › COUNT(*) vs COUNT(column)
Scenario

Counting rows or non-null values?

Compare the two forms to choose the correct count for your report: headcount or number of recorded values.

• COUNT star includes every row, so it measures the total number of records.
• COUNT with a column name measures how many rows have a non-null entry in that column.
• Use COUNT(column) when you want the number of valid entries in a field; use COUNT star for total rows.
Concrete Example
Employees sample: five rows, one salary NULL. COUNT star gives five. COUNT salary gives four. When reporting headcount, prefer the all-rows count.
Visual Comparison
COUNT(*)
Counts all rows. Use for total record counts or headcount metrics.
Example result: 5
COUNT(salary)
Counts only non-null salary entries. Use for valid value counts.
Example result: 4
Common Mistake

Assuming COUNT(column) counts rows. Always check for NULLs if you expected the total number of rows.
