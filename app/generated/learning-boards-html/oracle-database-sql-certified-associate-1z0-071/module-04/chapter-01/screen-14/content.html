Module 04 › Chapter 4.1 › Key Concepts
COUNT forms
COUNT star counts all rows; COUNT(column) counts non-null values only.
SUM & AVG
SUM totals numbers; AVG computes the mean. Both ignore NULLs unless substituted.
MIN & MAX
Find smallest and largest values across numbers, text, or dates; NULLs are ignored.
One-line takeaway

Aggregates summarize sets; confirm included rows, NULL handling, and whether DISTINCT was applied before trusting a metric.
