Module 04 › Chapter 4.2 › The HAVING clause
Code example
SELECT department_id, AVG(salary)
FROM employees
GROUP BY department_id
HAVING AVG(salary) > 10000
ORDER BY department_id;
This returns only departments whose average salary is greater than 10000.
Why WHERE won't work
WHERE filters rows before aggregation, so it cannot refer to aggregate results like AVG(salary). Attempting that is a common error for beginners.
Quick rule
Use WHERE for row filters, HAVING for group filters after aggregation.
