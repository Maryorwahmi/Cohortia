Module 04 › Chapter 4.2 › GROUP BY rule
Problem example
SELECT department_id, employee_id, AVG(salary)
FROM employees
GROUP BY department_id;
This query raises an error because employee_id is neither aggregated nor grouped, and many employee_id values exist per department.
Fixes & consequences
  • Remove employee_id from SELECT to get departmental averages.
  • Or add employee_id to GROUP BY, but that changes the grouping granularity to employee-level.
  • Always verify that adding a column to GROUP BY still answers your original question.
Quick check
If a column is only identifying a row, it probably should not appear with aggregates.
