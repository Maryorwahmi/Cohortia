Module 04 › Chapter 4.2 › WHERE + GROUP BY + HAVING
Starter query
SELECT department_id, AVG(salary)
FROM employees
WHERE hire_date > TO_DATE('2005-01-01','YYYY-MM-DD')
GROUP BY department_id
HAVING AVG(salary) > 12000
ORDER BY department_id;
Step-by-step
  1. WHERE: remove rows hired before the date.
  2. GROUP BY: collect remaining rows per department_id.
  3. Aggregate: compute AVG(salary) for each group.
  4. HAVING: keep only groups with AVG(salary) > 12000.
Performance tip
Filter early with WHERE to reduce rows that must be grouped.
