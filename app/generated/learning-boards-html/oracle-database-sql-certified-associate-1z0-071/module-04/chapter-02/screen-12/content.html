ORA-00979: Not a GROUP BY expression
Occurs when a non-aggregated column is in SELECT but not in GROUP BY. Fix by removing the column from SELECT or grouping by it, keeping in mind the change in granularity.
Example error
SELECT department_id, employee_id, AVG(salary) FROM employees GROUP BY department_id; -- raises ORA-00979
Over-granulation
Adding extra GROUP BY columns can reduce the usefulness of summaries. Confirm that added columns are required for the analysis.
Key Takeaway

Check grouping intent before writing SELECT and GROUP BY to avoid errors and misleading results.

Quick checklist
  • What should each output row represent?
  • Are non-aggregated columns included in GROUP BY?
  • Could WHERE reduce rows before grouping?
