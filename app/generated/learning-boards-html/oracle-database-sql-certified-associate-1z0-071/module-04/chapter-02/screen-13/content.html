Demo sequence
  1. Run SELECT AVG(salary) to show overall aggregate.
  2. Attempt SELECT department_id, employee_id, AVG(salary) with GROUP BY department_id to show ORA-00979.
  3. Fix query by removing employee_id or expanding GROUP BY and explain granularity change.
  4. Show WHERE salary > 10000 then GROUP BY; compare with HAVING AVG(salary) > 10000.
  5. Assign a short exercise to find departments with specific criteria and validate results.
Validation checks
  • Confirm non-aggregated columns are grouped.
  • Verify output rows represent intended entity.
  • Compare WHERE-filtered and HAVING-filtered outputs to ensure correct logic.
Instructor tip
Use a small sample dataset so learners see differences quickly and can reason about group membership.
