Module 04 › Chapter 4.2 › Hands-on starter queries
Starter code
-- 1. Total employees per department
SELECT department_id, COUNT(*)
FROM employees
GROUP BY department_id
ORDER BY department_id;

-- 2. Max salary per job
SELECT job_id, MAX(salary)
FROM employees
GROUP BY job_id
ORDER BY job_id;

-- 3. Department average salary > 8000
SELECT department_id, AVG(salary), COUNT(*)
FROM employees
GROUP BY department_id
HAVING AVG(salary) > 8000
ORDER BY department_id;
More examples
-- 4. Total salary for jobs with > 5 employees
SELECT job_id, SUM(salary)
FROM employees
GROUP BY job_id
HAVING COUNT(*) > 5
ORDER BY job_id;

-- 5. Min salary per dept and job for commissioned employees
SELECT department_id, job_id, MIN(salary)
FROM employees
WHERE commission_pct IS NOT NULL
GROUP BY department_id, job_id
ORDER BY department_id, job_id;
Reflection
After running each query, confirm that non-aggregated columns are in GROUP BY and that WHERE filters were applied before grouping where intended.
