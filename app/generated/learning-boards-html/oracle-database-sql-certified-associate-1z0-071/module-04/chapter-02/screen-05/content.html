Module 04 › Chapter 4.2 › AVG per department
Code
-- overall average (not per department)
SELECT AVG(salary) FROM employees;

-- average per department
SELECT department_id, AVG(salary)
FROM employees
GROUP BY department_id
ORDER BY department_id;
Explanation & pitfalls
  • GROUP BY creates one output row per distinct department_id.
  • Any non-aggregated SELECT column must appear in GROUP BY or you get ORA-00979.
  • ORDER BY helps present grouped summaries but does not affect grouping itself.
Analogy
Think of GROUP BY as gathering rows into labeled buckets. Aggregates then summarize each bucket.
