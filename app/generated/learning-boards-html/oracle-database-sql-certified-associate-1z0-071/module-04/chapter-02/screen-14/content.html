Module 04 › Chapter 4.2 › Key Concepts
GROUP BY
Divides rows into groups so aggregate functions compute values for each group.
HAVING
Filters groups after aggregation; can reference aggregate functions like AVG or COUNT.
WHERE vs HAVING
WHERE filters rows before grouping; HAVING filters groups after aggregation.
Summary

Pick grouping columns to match the entity you want summarized, filter rows early with WHERE, and filter aggregates with HAVING.
