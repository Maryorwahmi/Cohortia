Module 04 › Chapter 4.2 › What GROUP BY does
Definition

Partition rows for aggregation

GROUP BY collects rows with the same values into groups. Aggregates then compute one value per group.

Concrete example
SELECT department_id, AVG(salary) FROM employees GROUP BY department_id;
Misconception
Grouping doesn't reorder rows; it collapses them into one result per distinct group key.
Key takeaway
Choose grouping columns to match the entity you want summarized.
Visual
Input rows
dept | emp | salary
101  | 1   | 5000
101  | 2   | 7000
102  | 3   | 12000
102  | 4   | 15000
After GROUP BY dept
dept | avg_salary

102  | 13500
Check your grouping
Ask: should a single output row represent a department, a job, or an employee?
