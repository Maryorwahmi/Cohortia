Module 04 › Chapter 4.2 › Grouping by multiple columns
Example
SELECT department_id, job_id, SUM(salary)
FROM employees
GROUP BY department_id, job_id
ORDER BY department_id, job_id;
This returns one total per department-job combination present in employees.
Guidance
  • Include multiple columns when the analysis asks for intersections of categories.
  • Avoid adding identifiers that create groups too small to be meaningful.
  • ORDER BY the same columns to make results easy to scan.
Misconception
More GROUP BY columns always gives better insight — not true. It depends on the question.
