Module 04 › Chapter 4.2 › WHERE vs HAVING
Row-level filter (WHERE)
Example: WHERE l.city = 'Seattle' filters rows before grouping so only employees in Seattle are considered.
Why
WHERE cannot use aggregate functions such as AVG or COUNT.
Group-level filter (HAVING)
Example: HAVING COUNT(*) > 5 keeps only groups with more than five members after grouping.
Why
HAVING can reference aggregate functions because groups exist at that stage.
Decision rule
If the condition is about a row attribute, use WHERE. If it's about a summary or count, use HAVING.
