Process Flow
COMMIT and ROLLBACK
Use COMMIT to save changes permanently. Use ROLLBACK to undo changes in the current transaction if you find a mistake before committing.
Checklist before commit
  • Run SELECT to confirm inserted rows and sample values.
  • Confirm no constraint violations or unexpected duplicates.
  • Keep transactions short to reduce locking contention.
Hands-on pattern
-- Insert departments for testing INSERT INTO departments (department_id, department_name, manager_id, location_id) VALUES (280, 'Operations', 100, 1700); -- Verify SELECT * FROM departments WHERE department_id = 280; -- If correct: COMMIT; if not: ROLLBACK;
Pro tip
Use SELECT to verify rows before committing. In a learning environment, prefer ROLLBACK after verification to keep the database clean.
