Comparison
INSERT ALL — Unconditional vs Conditional
Unconditional
Every INTO clause inserts for each row produced by the SELECT. Use when duplicating rows to multiple targets.
Conditional (WHEN)
Use WHEN clauses to route rows to different tables based on conditions like salary ranges.
Remember: constraints on target tables still apply. INSERT ALL does not bypass unique, primary key, or foreign key rules.
Conditional example
INSERT ALL WHEN salary < 5000 THEN INTO junior_employees (employee_id, first_name, last_name, salary) VALUES (employee_id, first_name, last_name, salary) WHEN salary >= 5000 AND salary < 10000 THEN INTO mid_level_employees (employee_id, first_name, last_name, salary) VALUES (employee_id, first_name, last_name, salary) SELECT employee_id, first_name, last_name, salary FROM employees;
Misconception
INSERT ALL distributes rows in a single pass; it is not performing joins between target tables or merging them.
Check
After running, SELECT counts from each target table to confirm distribution matched your conditions.
