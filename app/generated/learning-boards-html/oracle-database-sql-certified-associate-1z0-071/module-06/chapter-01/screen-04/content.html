Core Concept
What INSERT does
INSERT adds new rows to a table. You can supply every column's value or list only the columns you want to set.
Key points
  • VALUES form requires a value for every column in table order.
  • Column-list form maps each value to a named column.
  • Data types must match column definitions to avoid errors.
Concrete example
Insert an employee using the table's full column order and a date function for the hire date. Use numeric values for numeric columns and single quotes for text.
Key Takeaway

Match counts and types or list columns explicitly to make INSERT statements robust.

Example code panel
-- Example: INSERT a full employee row INSERT INTO employees VALUES (207, 'John', 'Doe', 'JDOE@example.com', '515.123.4567', SYSDATE, 'IT_PROG', 6000, 60); -- Note: SYSDATE supplies the current date for hire_date. Strings use single quotes; numbers do not.
Misconception
You can reorder values to match any column — incorrect. Order must match table definition unless you name columns.
Pro tip
Prefer the column-list form in production to avoid breakage when schema changes.
