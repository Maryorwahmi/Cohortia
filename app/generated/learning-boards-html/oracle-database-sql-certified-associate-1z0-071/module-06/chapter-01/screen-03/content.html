Module 6 › Chapter 6.1 › Practice Objectives
01 Verify after insert
Run a SELECT to confirm the new row appears before you COMMIT, ensuring the data looks correct.
VERIFIED COMPETENCY MILESTONE
02 Use explicit column lists
List only the columns you are populating to avoid breaking when table definitions change.
VERIFIED COMPETENCY MILESTONE
03 Match types and counts
Ensure the number and data types in VALUES or SELECT match the target columns to avoid ORA- errors.
VERIFIED COMPETENCY MILESTONE
04 Use transactions to control changes
After verifying, choose COMMIT to save or ROLLBACK to undo so you leave the database in a known state.
