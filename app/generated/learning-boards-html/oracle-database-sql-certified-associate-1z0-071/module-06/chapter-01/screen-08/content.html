Common Errors
Why INSERTs fail
  • Data type mismatch: supplying incompatible literal or value.
  • Missing NOT NULL values: omitted required columns cause errors.
  • Incorrect number of values: VALUES must match column count unless columns are named.
  • Constraint violations: UNIQUE, PRIMARY KEY, or FOREIGN KEY conflicts.
Follow a systematic fix: read the error, describe the table, run the SELECT to simulate the inserted values, then correct the statement and retry in a transaction block.
Example diagnostics
If you get a unique constraint error when inserting employee_id 207, it means that ID already exists. Either choose a new ID or remove the conflicting row first. If you get a type conversion error when inserting a hire date string, use a date function or TO_DATE to ensure correct conversion.
Misconception
Oracle silently converts any string to a date — false. Implicit conversions can fail; be explicit with date functions when needed.
Warning
Constraint failures stop the insert. Do not ignore ORA- messages; they tell you what to fix.
