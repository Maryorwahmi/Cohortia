Definition
INSERT with column list
Name the columns you supply values for so unmatched columns use defaults or NULL safely.
Process
  1. Check the table definition for column names, types, and NOT NULL constraints.
  2. Write INSERT INTO table_name (col1, col2, ...) VALUES (val1, val2, ...);
  3. Run a SELECT to verify the inserted row before committing.
Concrete example
INSERT INTO employees (employee_id, first_name, last_name, email) VALUES (208, 'Jane', 'Smith', 'JSMITH@example.com'); This leaves other columns to their defaults or NULL.
Key Takeaway

Prefer column lists when not supplying every value; this reduces future breakage.

Common checks
  • Does any omitted column have NOT NULL without a default? If so, provide a value.
  • Will omitted columns accept NULL or use a default? Confirm by describing the table.
  • Are your provided values in the same order as the column list? They must be.
Misconception
Omitting a column will make the database auto-fill a sensible value — only true if a default exists; otherwise you get NULL or an error for NOT NULL columns.
