Module 6 › Chapter 6.1 › Key Concepts
DML
Data Manipulation Language: commands that change data, including INSERT.
INSERT statement
Adds new rows; supports VALUES, column lists, or INSERT ... SELECT forms.
VALUES clause
Specifies literal values for an inserted row; must match columns positionally unless columns are named.
Summary

Understand DML, choose explicit column lists when appropriate, and verify inserts before committing.
