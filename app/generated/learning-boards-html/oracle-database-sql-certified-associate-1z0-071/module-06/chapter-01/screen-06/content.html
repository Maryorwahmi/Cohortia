Process Flow
INSERT from SELECT
Select rows from an existing table and insert them into a target table in one operation.
Example
INSERT INTO junior_employees (employee_id, first_name, last_name, salary, department_id) SELECT employee_id, first_name, last_name, salary, department_id FROM employees WHERE salary < 5000;
Checks
  • Run the SELECT alone to confirm the rows you will insert.
  • Ensure SELECT columns match INSERT column order and types.
  • Verify the target table structure before running the insert.
Example verification
-- Check rows before inserting SELECT COUNT(*) FROM employees WHERE salary < 5000; -- Then run the INSERT ... SELECT -- After insert, verify SELECT COUNT(*) FROM junior_employees WHERE salary < 5000;
Misconception
INSERT ... SELECT maps by name — false; mapping is positional by the order you list columns.
Pro tip
Run the SELECT alone first and compare row counts before inserting into production targets.
