Insert new department records
Follow the starter code below. Execute each step and verify result with SELECT. Use ROLLBACK after verification to clean up.
-- Task 1: Insert 'Operations' INSERT INTO departments (department_id, department_name, manager_id, location_id) VALUES (280, 'Operations', 100, 1700); -- Task 2: Insert 'Customer Support' with specific columns INSERT INTO departments (department_id, department_name, location_id) VALUES (290, 'Customer Support', 1700); -- Task 3: Verify SELECT * FROM departments WHERE department_id IN (280, 290); -- Task 4: Rollback changes ROLLBACK;
Common pitfall
Omitting the NOT NULL department_name will cause an error. Always confirm required columns first.
Check
After INSERT, run a SELECT and validate values before committing or rolling back.
