Common types
  • VARCHAR2 — variable-length text, for names and short descriptions.
  • NUMBER(p,s) — numeric with precision and scale, for currency and calculations.
  • DATE — date and time values, for timestamps and scheduling.
  • CLOB / BLOB — large text or binary objects, for documents or images.
Concrete example
price NUMBER(10,2)
product_name VARCHAR2(100)
start_date DATE
Pitfalls and checks
  • Avoid using VARCHAR2 to store numbers — numeric queries and indexes will be inefficient.
  • Reducing a VARCHAR2 size that already contains longer data will be blocked or truncate data; review existing rows first.
  • Large CLOB and BLOB columns can impact backups and replication; reserve them for necessary cases.
Pro tip
Choose the smallest type that satisfies business requirements to optimize storage and performance.
