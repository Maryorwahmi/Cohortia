Module 6 › Chapter 6.4 › ALTER TABLE: Modify
Common use cases
  • Increase VARCHAR2 size to accommodate longer entries.
  • Increase NUMBER precision when calculating larger totals.
  • Change NULL to NOT NULL only after verifying existing data.
Example
ALTER TABLE products
MODIFY (description VARCHAR2(1000));
ALTER TABLE products
MODIFY (category_id NUMBER(6));
Strategy
  1. Test the MODIFY on a copy of the table first.
  2. For risky changes, create a new column, copy transformed data, then swap.
  3. Schedule large changes during maintenance to reduce user impact.
