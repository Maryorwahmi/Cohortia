Module 6 › Chapter 6.4 › CREATE TABLE Syntax
Structure

Specify columns and types

Include column name, data type and optional constraints. Use DEFAULT for automatic values and NOT NULL to enforce presence.

Concrete example
CREATE TABLE products (
    product_id      NUMBER(6),
    product_name    VARCHAR2(100) NOT NULL,
    description     VARCHAR2(500),
    price           NUMBER(10,2) NOT NULL,
    category_id     NUMBER(4)
);
Check
Always DESCRIBE and review column sizes and NOT NULL choices after creating a table.
Tips & pitfalls
  • Avoid oversized VARCHAR2 lengths unless needed; it wastes storage.
  • Pick NUMBER precision to match business needs, e.g., currency needs scale for decimals.
  • Use DEFAULT for columns you will later add as NOT NULL to avoid ALTER failures on existing data.
Analogy

Think of CREATE as drafting a blueprint: choose materials (data types) and rules (constraints) before construction.
