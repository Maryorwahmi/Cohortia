Module 6 › Chapter 6.4 › Drop & Rename
Commands
ALTER TABLE products DROP COLUMN description;
ALTER TABLE products RENAME COLUMN product_name TO item_name;
RENAME products TO inventory_items;

Dropping a column or table deletes data; renaming preserves data but requires updates to dependent code and objects.

Dependency checks

Always inspect USER_CONSTRAINTS or ALL_CONSTRAINTS and search for views, triggers, or procedures that reference the object you plan to rename or drop.

Analogy
Think of rename as relabeling a room, and drop as demolishing it. Relabeling requires updating directions; demolishing affects the whole building.
