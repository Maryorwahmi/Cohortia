Module 6 › Chapter 6.4 › DROP TABLE
Standard DROP
DROP TABLE products;

This removes the table and data. If other tables reference it via foreign keys, the DROP will fail unless you explicitly cascade constraints.

Using CASCADE
DROP TABLE departments CASCADE CONSTRAINTS;

CASCADE CONSTRAINTS removes referential constraints that reference the dropped table. This is useful for decommissioning but can have far-reaching effects.

Checklist before drop
  • Export schema or table backup.
  • List dependent constraints and tables from USER_CONSTRAINTS.
  • Communicate with owners and plan a maintenance window.
