Module 6 › Chapter 6.4 › ALTER TABLE: Add
Recommended steps
  1. Add the column allowing NULL and optionally specify DEFAULT.
  2. Backfill existing rows with UPDATE if required.
  3. Alter the column to NOT NULL only after confirming no NULLs remain.
Example
ALTER TABLE products
ADD (last_update_date DATE DEFAULT SYSDATE);

-- Then backfill or verify existing rows before setting NOT NULL
Warnings
  • Adding a NOT NULL column with no default to a table with rows will fail.
  • Large ALTER operations can lock the table and affect availability.
  • Behaviour for defaults applied to existing rows can vary; verify after change.
Common mistake
Attempting to add a NOT NULL column without a default on a populated table causes an error and blocks the operation.
