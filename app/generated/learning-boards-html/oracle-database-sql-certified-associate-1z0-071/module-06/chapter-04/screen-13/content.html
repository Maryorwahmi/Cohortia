Question

You need to add is_active VARCHAR2(1) NOT NULL to customers. All existing rows should default to 'Y'. Which statement is correct?

Correct answer
ALTER TABLE customers ADD (is_active VARCHAR2(1) DEFAULT 'Y' NOT NULL);
Why

The DEFAULT ensures existing rows receive 'Y' and therefore satisfy the NOT NULL constraint when it is added.

Common wrong answers
  • Adding NOT NULL without default on a populated table fails.
  • Using MODIFY is for changing existing columns, not adding new ones.
