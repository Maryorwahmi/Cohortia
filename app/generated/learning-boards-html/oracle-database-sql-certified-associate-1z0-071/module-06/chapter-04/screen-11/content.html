Module 6 › Chapter 6.4 › Common DDL Mistakes
Irreversibility

DDL implicitly commits. Keep backups and change scripts under version control to recover if needed.

Syntax errors

A single missing comma or parenthesis can stop a CREATE or ALTER. Validate statements in development first.

Dependency surprises

Use USER_CONSTRAINTS and ALL_CONSTRAINTS to find objects that reference what you plan to change or remove.

Performance impact

Large ALTERs can lock the table. Schedule these during maintenance windows to avoid service disruption.

NOT NULL additions

When adding NOT NULL to an existing table, always supply a DEFAULT and backfill to avoid errors.
