Module 6 › Chapter 6.4 › Schema Management
Version and review

Keep all DDL scripts under version control and require peer review so changes are auditable and reversible through restore processes.

Staged migrations

Add columns as nullable with defaults, backfill in batches, then enforce NOT NULL to avoid long locks and errors.

Testing and staging

Validate ALTERs on a copy of production data to reveal hidden issues with data conversions or size reduction attempts.

Communication

Announce scheduled schema work to stakeholders and record DESCRIBE outputs for auditing and troubleshooting.
