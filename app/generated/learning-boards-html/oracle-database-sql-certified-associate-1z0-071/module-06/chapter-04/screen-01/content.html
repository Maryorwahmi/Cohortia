Create, Alter, Drop — the schema toolset

Learn how to define tables and evolve their structure safely. Understand implicit commits, constraints, and dependency risks.

In this lesson
CREATE TABLE
Define columns, types, and column constraints such as NOT NULL and DEFAULT.
Coming up
ALTER TABLE
Add, modify, drop, or rename columns. Watch out for existing data and size constraints.
Safety
DROP & Dependencies
DROP TABLE removes structure and data. CASCADE CONSTRAINTS removes related foreign keys — use with care.
Key Idea
DDL changes are structural and permanent. Always confirm dependencies and backups before executing schema changes.
Visual Overview

Throughout this lesson you will create a projects table, evolve it with ALTER TABLE, inspect the structure, insert a sample row, and then clean up with DROP TABLE.
