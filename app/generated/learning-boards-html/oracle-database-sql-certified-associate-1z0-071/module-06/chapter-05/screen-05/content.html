Module 6 › Chapter 6.5 › NOT NULL and UNIQUE
Rule details

NOT NULL

Use when a column must always have a value. The database rejects inserts or updates that set this column to NULL.

Example
CREATE TABLE employees (
  employee_id NUMBER(6),
  first_name VARCHAR2(20) NOT NULL,
  last_name VARCHAR2(25) NOT NULL
);

Common mistake

Assuming NOT NULL is unnecessary because application code validates inputs. Always enforce critical presence rules in the schema too.

Rule details

UNIQUE

Prevents duplicate non-null values. For optional fields, remember UNIQUE still allows multiple NULLs unless NOT NULL is added.

Example
CREATE TABLE employees (
  employee_id NUMBER(6),
  email VARCHAR2(25) UNIQUE
);

-- Multi-column UNIQUE
CREATE TABLE products (
  product_id NUMBER(6),
  product_name VARCHAR2(100),
  category_id NUMBER(4),
  CONSTRAINT un_product_category UNIQUE (product_name, category_id)
);

Pro tip

Use multi-column UNIQUE to enforce uniqueness within a context, such as a name within a category.
