Module 6 › Chapter 6.5 › What is Data Integrity?
Definition

Data integrity explained

  • Completeness: required fields are not missing.
  • Accuracy: values correctly represent the real world.
  • Consistency: related values agree across tables and time.
Analogy

Think of a library catalog where each book must have a valid ISBN and every loan record must reference an existing member. Those catalog rules are constraints in the database.

Key Takeaway

Treat constraints as the final safety net: they protect the whole system when individual validations fail.

Practical examples
NOT NULL
Prevents missing data for required fields like a member's registration number.
UNIQUE
Ensures values like ISBN or email are not duplicated across rows.
CHECK
Enforces domain rules such as price > 0 or credits between fixed ranges.
Example SQL
CREATE TABLE courses (
  course_id NUMBER(4) PRIMARY KEY,
  course_title VARCHAR2(100) NOT NULL UNIQUE,
  credits NUMBER(2,1) CONSTRAINT ck_credits CHECK (credits BETWEEN 0.5 AND 6.0)
);
