Common Oracle errors
  • ORA-00001: unique constraint violated — duplicate values exist.
  • ORA-02291: integrity constraint violated - parent key not found.
  • ORA-02290: check constraint violated — value failed condition.
Diagnostic steps
  1. Note the constraint name from the error message.
  2. Query the table to locate rows that violate the rule.
  3. Decide: fix data, alter constraint, or remove offending rows.
Performance trade-offs
Constraints add work during INSERT/UPDATE. For large loads: disable constraints, load, clean data, then re-enable with validation. Always plan for dependent constraints.
Example troubleshooting query
-- Find orphaned enrollments with no matching course
SELECT e.* FROM enrollments e
WHERE NOT EXISTS (
  SELECT 1 FROM courses c WHERE c.course_id = e.course_id
);

-- Find duplicates that would block a UNIQUE constraint
SELECT email, COUNT(*) cnt FROM employees GROUP BY email HAVING COUNT(*) > 1;
Why it matters
Clear, consistent rules prevent incorrect reports and broken relations across systems.
Quick check
Before enabling a constraint, run a violation query and record the count of bad rows.
Final thought
Treat constraints as living parts of your schema: document them and include checks in CI pipelines.
