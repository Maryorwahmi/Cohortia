Purpose

Primary Key essentials

A primary key uniquely identifies rows and implicitly forbids NULLs. It is the canonical reference used by foreign keys to establish relationships between tables.

Single vs composite
Single-column PK
employee_id NUMBER(6) PRIMARY KEY
Composite PK
CONSTRAINT pk_order_items PRIMARY KEY (order_id, item_id)
Example & caution
CREATE TABLE order_items (
  order_id NUMBER(6),
  item_id NUMBER(6),
  quantity NUMBER(3),
  CONSTRAINT pk_order_items PRIMARY KEY (order_id, item_id)
);

-- Try inserting a duplicate order_id/item_id combination to see the violation.
Misconception

Choosing a mutable natural key as a primary key can cause maintenance headaches. Prefer stable identifiers when possible.

Pro tip

Declare composite keys at table level for clarity and to avoid repeating column specifications.
