Task 2 — Update employee 103
Change email and job identifier in one statement.
UPDATE employees
SET email = 'AHUNOLD_NEW@example.com',
    job_id = 'IT_PROG'
WHERE employee_id = 103;
Verify with SELECT using the employee_id to confirm both fields changed as intended.
Task 3 — Conditional promotion
For sales representatives with salary under 6000, change their job and increase salary by ten percent in one update.
UPDATE employees
SET job_id = 'SA_MAN',
    salary = salary * 1.10
WHERE job_id = 'SA_REP' AND salary < 6000;
After running, select those employees to confirm job and salary updates; roll back if values are unexpected.
