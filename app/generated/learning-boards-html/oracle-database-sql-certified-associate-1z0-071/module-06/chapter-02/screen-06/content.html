Module 6 › Chapter 6.2 › Expressions in SET
Why use expressions?
Expressions preserve the relationship between rows while applying a consistent transformation, such as percentage raises or scaling quantities.
Example: five percent raise for department 60
UPDATE employees
SET salary = salary * 1.05
WHERE department_id = 60;
Checks to perform
  • Confirm salary column precision and data type to avoid truncation.
  • Decide whether to ROUND results if whole units are required.
  • Test the WHERE with SELECT to verify row count before applying.
Concrete scenario
Say department 60 needs an across-the-board lift. Using an expression ensures employees with higher base salaries receive proportionally larger absolute increases while keeping the policy consistent.
Misconception
The misconception is that expressions are applied once globally. Remember, the database evaluates the expression per row so each row's current salary drives its new value.
Key Takeaway

Use expressions to perform safe, row-by-row transformations and always validate numeric types and rounding behavior.
