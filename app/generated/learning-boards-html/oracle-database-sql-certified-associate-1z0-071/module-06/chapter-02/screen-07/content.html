What a subquery does
It provides a value computed by a SELECT that the UPDATE uses to assign a column. The SELECT must return one value per update or one scalar value used for all targeted rows.
Important checks
  • Run the subquery by itself to confirm it produces a single value.
  • If correlated, understand it executes per row and may be slow on large sets.
  • Ensure VALUES returned respect data types and constraints.
Example
Copy a location_id from one department to others managed by a given manager:
UPDATE departments
SET location_id = (
  SELECT location_id FROM departments WHERE department_id = 50
)
WHERE manager_id = 100;
If the inner SELECT can return multiple rows, refine it with an additional WHERE or use aggregation to return a single value.
