Module 6 › Chapter 6.2 › UPDATE Syntax
Statement structure
An UPDATE has three responsibilities: choose a table, compute new values, and limit affected rows. Each responsibility maps to a clause you write and verify.
Key clauses
  • UPDATE table_name — identifies the table to modify.
  • SET column = expression — assigns new values; expression can reference other columns.
  • WHERE condition — filters which rows are changed; omitting it affects all rows.
Common misconceptions
  • SET can only assign literals — false; it accepts expressions and column references.
  • Omitting WHERE is harmless in development — false; it changes every row and is risky even in dev if data is shared.
Key Takeaway

Understand the three roles of UPDATE so you can write changes that are precise and reversible during testing.

Concrete examples
Update a single row by primary key:
UPDATE employees
SET salary = 25000
WHERE employee_id = 100;
Update multiple columns at once:
UPDATE employees
SET salary = 18000,
    email = 'NKOCHHAR@example.com'
WHERE employee_id = 101;
Check your work with SELECT:
SELECT employee_id, first_name, salary
FROM employees
WHERE employee_id = 100;
