Modifying Data: UPDATE Statements
Change existing rows safely using SET, WHERE, expressions, and subqueries
In this lesson
How to write UPDATE, protect data with WHERE and transactions, and use subqueries to compute new values.
Why it matters
Databases change constantly. UPDATE keeps records accurate — salaries, addresses, and classifications — while preserving integrity when used carefully.
Safety focus
Confirm your WHERE with a SELECT, watch constraints and types, and use COMMIT or ROLLBACK to control permanence.
Explore Key Topics
Syntax
SET and WHERE form the core of an UPDATE statement and control assignments and scope.
Expressions
You can use existing column values in arithmetic to increase salaries or adjust quantities.
Subqueries
A subquery in SET supplies values derived from other rows or tables for each update.
Visual Concept
Update flow: Identify rows → compute new values → apply within transaction
Example: single row
UPDATE employees
SET salary = 25000
WHERE employee_id = 100;
Example: bulk change
UPDATE employees
SET salary = salary * 1.10
WHERE department_id = 90;
Key Takeaway

Update intentionally: choose rows with WHERE, verify with SELECT first, and use transactions to make changes reversible until committed.
