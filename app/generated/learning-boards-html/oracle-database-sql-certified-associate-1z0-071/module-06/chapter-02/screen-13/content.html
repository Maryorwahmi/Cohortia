Row-level verification
Reselect the exact rows you updated and confirm each column changed as expected.
SELECT employee_id, salary
FROM employees
WHERE department_id = 60;

-- or for a single employee:
SELECT employee_id, email, job_id
FROM employees
WHERE employee_id = 103;
Aggregate checks
Use COUNT and SUM to confirm the number of changed rows and the total payroll impact.
SELECT COUNT(*), SUM(salary)
FROM employees
WHERE department_id = 60;
If aggregates differ from expectation, rollback and diagnose the WHERE or expression logic.
