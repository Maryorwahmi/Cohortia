Module 6 › Chapter 6.2 › Subquery Walkthrough
Step 1 — Test the subquery
Run the inner SELECT to confirm it returns a single, correct value. This prevents errors and unexpected null assignments.
SELECT location_id FROM departments WHERE department_id = 50;
Step 2 — Update with the scalar
UPDATE departments
SET location_id = (
  SELECT location_id FROM departments WHERE department_id = 50
)
WHERE manager_id = 100;
Step 3 — Verify and commit
After UPDATE, run a SELECT to confirm manager_id 100 departments now have the expected location. If satisfied, COMMIT; if not, ROLLBACK.
SELECT department_id, manager_id, location_id
FROM departments
WHERE manager_id = 100;
Note: If the inner SELECT returns multiple rows, refine its WHERE clause or use aggregation to ensure a single result.
