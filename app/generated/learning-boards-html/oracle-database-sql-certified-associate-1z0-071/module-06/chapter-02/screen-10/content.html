Safe transaction pattern
  1. Run SELECT with the intended WHERE to preview rows.
  2. Begin transaction if your client supports it.
  3. Run UPDATE.
  4. Run SELECT again to verify.
  5. COMMIT to persist or ROLLBACK to undo.
Example verification:
-- begin transaction
-- UPDATE ...
-- SELECT to verify
-- COMMIT or ROLLBACK
Real-world note
Some clients auto-commit each statement; in those tools you must be extra careful and use staging databases to test updates before applying them to production.
Key Takeaway

Treat COMMIT as the point of no return. Use transactions to keep updates reversible during testing.
