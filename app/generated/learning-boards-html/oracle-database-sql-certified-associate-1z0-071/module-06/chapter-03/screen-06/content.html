TRUNCATE: core properties
A DDL command that removes all rows quickly by deallocating storage and resetting the high-water mark.
Basic syntax
TRUNCATE TABLE temp_logs;
Note that TRUNCATE has no WHERE clause and does not fire DELETE triggers.
Implicit commit
TRUNCATE issues implicit COMMITs before and after, making it irreversible via ROLLBACK.
Space reclamation
TRUNCATE resets the high-water mark so the database recognizes freed blocks immediately.
Warning

Do not TRUNCATE if you might need to ROLLBACK, and ensure no foreign key constraints prevent the operation.

Concrete scenario
For a daily temp_logs table that is regenerated, TRUNCATE is ideal: it clears all rows quickly and reclaims space, improving subsequent insert performance. But in production tables with critical data, prefer DELETE with verification and backups.
