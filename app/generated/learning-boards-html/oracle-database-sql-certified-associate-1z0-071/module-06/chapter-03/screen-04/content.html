DELETE: term and purpose
Delete specific rows safely and reversibly using WHERE and transaction control.
Basic syntax
DELETE FROM employees WHERE employee_id = 207;
Test your WHERE with SELECT before deleting to avoid accidental removal of all rows.
Behavior
Row-by-row removal, generates undo/redo, fires DELETE triggers, and can be ROLLBACKed before commit.
Misconception
DELETE immediately reclaims disk space — not true. High-water mark remains until data is overwritten or table is truncated.
Key Takeaway

Use DELETE for targeted, reversible changes and whenever triggers must execute.

Concrete example & verification
Example
-- Verify target rows
SELECT * FROM employees WHERE employee_id = 207;
-- If correct, then delete
DELETE FROM employees WHERE employee_id = 207;
-- If mistake, rollback
ROLLBACK;
