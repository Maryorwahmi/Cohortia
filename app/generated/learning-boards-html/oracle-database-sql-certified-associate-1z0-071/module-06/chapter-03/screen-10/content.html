Cleanup and archive activity
Follow these steps on temp_employees to experience transactional behavior and truncation effects.
Starter code
CREATE TABLE temp_employees AS SELECT * FROM employees;
-- DELETE FROM temp_employees WHERE salary < 3000;
-- DELETE FROM temp_employees WHERE hire_date < DATE '2005-01-01';
-- SELECT COUNT(*) FROM temp_employees;
-- ROLLBACK;
TRUNCATE TABLE temp_employees;
-- DROP TABLE temp_employees;
Step-by-step
  1. Verify target rows with SELECT before deleting.
  2. Execute DELETE and confirm with SELECT COUNT.
  3. If mistake, run ROLLBACK to restore state.
  4. TRUNCATE to remove all rows and confirm that ROLLBACK does not restore them.
Learning checkpoint

After completing the activity, you should be able to decide whether DELETE or TRUNCATE fits a cleanup scenario and execute verification and rollback steps correctly.
