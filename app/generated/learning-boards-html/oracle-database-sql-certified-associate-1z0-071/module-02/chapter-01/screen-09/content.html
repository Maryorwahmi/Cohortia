FROM clause

Specify the source table or view. Columns in the SELECT are resolved against this source. For example: SELECT first_name, last_name FROM employees;

Permissions note

Ensure your user has SELECT privileges on the referenced table; otherwise queries will fail with permission errors.

Statement termination

In Oracle SQL tools, end statements with a semicolon. Missing the semicolon makes the client wait or produce syntax messages.

SELECT first_name FROM employees -- missing semicolon SELECT first_name FROM employees; -- correct
Common mistake

Forgetting the semicolon interrupts execution; always end statements in Oracle clients.
