The DISTINCT keyword

Definition

DISTINCT removes duplicate rows in the result, considering the entire set of selected columns as the unit for uniqueness.

Example
SELECT DISTINCT job_id FROM employees;
Misconception: DISTINCT applies only to the first column listed. It does not; it applies to the whole selected row.
Multiple columns

SELECT DISTINCT department_id, job_id FROM employees; gives unique pairs. If you need unique departments alone, select DISTINCT department_id.

Performance note

DISTINCT can require sorting or hashing to remove duplicates. Use it when the semantics require uniqueness; otherwise consider aggregation or indexes to support performance.

Key Takeaway

DISTINCT filters duplicate result rows across the selected columns; use it purposefully and verify results.
