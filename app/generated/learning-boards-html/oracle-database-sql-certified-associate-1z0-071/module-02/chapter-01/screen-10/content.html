What is DUAL?

DUAL is a built-in single-row table used to select expressions, constants, or system functions in Oracle, without querying application data.

Examples
SELECT SYSDATE FROM DUAL; SELECT (150 * 3) + 25 AS "Calculation Result" FROM DUAL;
Why use it

It provides a predictable single-row context for evaluating expressions and testing functions before integrating them into larger queries.

Misconception: DUAL is for business data. It isn't. It's a utility for testing and evaluation, not for storing transactional records.
Key Takeaway

Use DUAL to evaluate expressions and fetch system values in Oracle without referencing a real table.
