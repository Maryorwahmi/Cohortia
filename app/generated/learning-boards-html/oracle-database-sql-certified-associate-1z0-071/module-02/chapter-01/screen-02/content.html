Learning Objectives

Learn to retrieve, label, de-duplicate, and compute values using SELECT and DUAL.

01
Construct SELECT queries
Build queries that return all columns or an explicit column list, so results are efficient and consistent.
Verified competency milestone
02
Apply column aliases
Use AS or quoted aliases to present readable headers for reports and exports.
Verified competency milestone
03
Use DISTINCT to remove duplicates
Return unique rows for the selected columns and understand when duplicates arise.
Verified competency milestone
04
Use the DUAL table
Run quick calculations or fetch system values like the current date without a data table.
Verified competency milestone
