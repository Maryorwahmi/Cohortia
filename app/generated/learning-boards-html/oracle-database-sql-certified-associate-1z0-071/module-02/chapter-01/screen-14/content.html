SELECT and *

Wildcard returns all columns for quick inspection; prefer explicit lists for production.

Aliases

Use AS and quoted aliases for readable result headers, especially in reports.

DISTINCT & DUAL

DISTINCT removes duplicate rows across selected columns; DUAL returns one row for expressions and system values.

Takeaway: write explicit, readable SELECT statements and test expressions using DUAL. That practice prevents surprises and keeps your queries efficient.
