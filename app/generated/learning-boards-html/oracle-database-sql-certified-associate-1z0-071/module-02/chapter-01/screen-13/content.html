Module 2›Chapter 2.1›Common Mistakes
Missing semicolon

Without the semicolon, Oracle clients may prompt for more input or return an error. Always terminate statements.

Alias quoting errors

Use double quotes for aliases containing spaces or special characters to ensure headers appear as intended.

DISTINCT misunderstandings

DISTINCT applies to the full selected column set. If you want summaries or totals, use GROUP BY and aggregates instead.

Using SELECT *

Don't rely on SELECT * in production: it creates fragile contracts and can fetch unnecessary data.

Pro tip

Run queries in a test schema first. Inspect headers, row counts, and types to catch syntax and logic errors early.
