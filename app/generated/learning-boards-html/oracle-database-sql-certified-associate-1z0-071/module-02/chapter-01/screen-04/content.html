Module 2 › Chapter 2.1 › SELECT *
Definition and guidance

The asterisk returns every column in the table. Use it for quick inspection, schema discovery, or debugging, but prefer explicit column lists in production.

Common reasons to avoid *
  • Unnecessary data transfer and slower queries on large columns.
  • Result order or schema can change when new columns are added.
  • It hides which columns the application depends on.
Key Takeaway

Use SELECT * for exploration only. List explicit columns for stable, efficient queries.

Example and quick refactor
-- Quick inspection
SELECT * FROM employees;
-- Refined for production
SELECT employee_id, first_name, last_name, email FROM employees;
Misconception

Some assume star will always be fast on small tables. Tables grow and schemas change; choose explicit columns for reliability.
