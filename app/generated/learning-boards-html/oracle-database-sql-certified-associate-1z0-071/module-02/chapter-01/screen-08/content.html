Practical examples: SELECT, aliases, and DISTINCT

-- 1. Inspect table
SELECT * FROM employees;
-- 2. Focused columns
SELECT employee_id, first_name, last_name, salary FROM employees;
-- 3. Aliases
SELECT first_name AS "Employee First Name", last_name AS "Employee Last Name" FROM employees;
-- 4. DISTINCT examples
SELECT DISTINCT department_id FROM employees;
SELECT DISTINCT department_id, job_id FROM employees ORDER BY department_id, job_id;
Execution guidance
  • Always end statements with a semicolon in Oracle tools.
  • Use ORDER BY with DISTINCT when you want repeatable output ordering.
  • Verify aliases appear exactly as you expect in exports by using quotes when needed.
Common errors
Missing semicolon causes the client to wait for the statement terminator.
Incorrect alias quoting leads to syntax or unexpected identifier names.
Try this

Run the four examples in a test schema, then remove one column from the SELECT list to see how results and duplicates change.
