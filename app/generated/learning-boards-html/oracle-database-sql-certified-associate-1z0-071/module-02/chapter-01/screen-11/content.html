Module 2›Chapter 2.1›DISTINCT vs GROUP BY
DISTINCT

Returns unique rows for the selected columns. Use when you need just the distinct set.

SELECT DISTINCT department_id FROM employees;
GROUP BY

Groups rows to compute aggregates like counts, sums, averages per group.

SELECT department_id, COUNT(*) FROM employees GROUP BY department_id;
Misconception: using DISTINCT to emulate GROUP BY totals won't produce aggregates. Use the correct tool for the goal.
Key Takeaway

DISTINCT deduplicates; GROUP BY summarizes. Choose based on whether you need aggregates.
