Column aliases and presentation

Alias styles compared
Using AS with quotes: SELECT first_name AS "First Name" FROM employees;
Using AS without quotes: SELECT first_name AS FirstName FROM employees;
Implicit alias: SELECT first_name "First Name" FROM employees;
When to quote

Quote the alias when you need spaces or specific capitalization in the output header. Unquoted identifiers are folded to upper case in Oracle unless quoted.

Example with expression
SELECT salary * 1.10 AS "Adjusted Salary" FROM employees;
Misconception: aliases change the table. They do not — aliases only label the column in the query results.
