Hands-on activity walkthrough

1. Inspect
SELECT * FROM employees; — see columns and sample data.
2. Select specific columns
SELECT employee_id, first_name, last_name, salary FROM employees;
3. Apply aliases
SELECT first_name AS "Employee First Name", last_name AS "Employee Last Name" FROM employees;
4. DISTINCT values
SELECT DISTINCT department_id FROM employees;
5. DISTINCT combinations
SELECT DISTINCT department_id, job_id FROM employees ORDER BY department_id, job_id;
6. DUAL calculation
SELECT (150 * 3) + 25 AS "Calculation Result" FROM DUAL;
Key Takeaway

Work stepwise: inspect, refine columns, label results, deduplicate when needed, and test expressions using DUAL.
