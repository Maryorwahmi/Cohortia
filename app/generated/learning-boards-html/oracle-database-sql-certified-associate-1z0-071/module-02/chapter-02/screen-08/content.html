BETWEEN overview

BETWEEN provides a readable inclusive range check. It simplifies expressions that would otherwise use two comparisons joined by AND.

Example conceptually: salary between three thousand and five thousand returns salaries equal to three thousand, five thousand, or any value in between.
Practical notes
  • BETWEEN is inclusive on both ends.
  • To exclude boundaries, use greater-than and less-than explicitly.
  • NEGATE with NOT BETWEEN to find values outside the range.
Pro-tip: use BETWEEN for date ranges when both endpoints should be included.
