Module 2 › Chapter 2.2 › Key Concepts
BETWEEN
Inclusive range checks; equivalent to two comparisons joined by AND.
IN
Checks membership in a list; preferred over repeated OR comparisons for clarity.
LIKE
Pattern matching with percent and underscore; case-sensitive unless normalized.
Final takeaway

Use special operators deliberately, normalize text when needed, and always test NULLs with IS NULL to ensure correct results.
