Module 2 › Chapter 2.2 › Learning Objectives
Objective details
  • String safety: use single quotation marks and consider UPPER or LOWER for case-insensitive matching.
  • Quoting rule: double quotes are for object names, not string literals; using them for strings is a common error in Oracle.
  • Operator choice: prefer IN for multiple values and BETWEEN for inclusive ranges for readability.
  • NULL checks: use IS NULL or IS NOT NULL; equality comparisons return unknown when NULL is involved.
Practice tasks
Task: find employees with email missing
Task: list employees in departments 50 or 80 using IN
Task: names containing 's' case-insensitively using UPPER
These practice items reinforce safe patterns and readable query style.
