Starter queries (conceptual)
-- Employees with a specific job id: select several columns where job id equals a text literal in single quotes.
-- Salary between two bounds: use BETWEEN to include both endpoints.
-- Departments in a list: use IN to simplify multiple equality checks.
Guided tasks
  1. Find employees with job equal to a particular role, verifying case and quote usage.
  2. Find employees with salary between six thousand and ten thousand to practice BETWEEN.
  3. Find employees in department fifty or eighty using IN and compare with OR results.
  4. Combine a name pattern and a salary threshold with AND to create a focused report.
  5. Find employees without a commission using IS NULL to handle missing values safely.
Run each step, inspect a few rows, and then combine steps. Small, incremental validation prevents logic errors.
