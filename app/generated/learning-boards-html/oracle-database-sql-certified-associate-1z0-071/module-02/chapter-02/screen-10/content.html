Wildcards
  • Percent — matches zero or more characters; use for prefixes, suffixes, or substrings.
  • Underscore — matches a single character at a specific position.
Example: find first names starting with A by matching the prefix with a percent wildcard.
Notes
LIKE is case-sensitive by default; normalize case when needed. To search for a literal percent or underscore, escape the character according to the database rules.
Test patterns on a subset of data before running broad queries to ensure you match the intended rows.
