Module 2 › Chapter 2.2 › What the WHERE Clause Does
Definition
WHERE limits rows based on conditions

It evaluates a boolean condition for each row and only returns rows where the condition is true. This happens before grouping and aggregation.

Concrete example
SELECT first_name, last_name, salary FROM employees WHERE salary greater than five thousand;
This returns only employees whose salary satisfies the numeric condition. Think of it as a gate applied to raw rows.
Misconception: WHERE runs after GROUP BY — false. WHERE runs before aggregation.
Pro-tip: decide whether a condition should act on raw rows or aggregated results; use WHERE for raw rows.
Why it matters
  • Filters reduce returned rows, making results clearer and often faster.
  • Correct placement prevents logic errors when aggregation is involved.
  • Always think whether you filter raw rows or aggregated groups.
Key Takeaway

WHERE is the gate that tests each row; it runs before grouping and aggregation.
