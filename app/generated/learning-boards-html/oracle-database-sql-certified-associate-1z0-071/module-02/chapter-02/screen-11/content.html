Module 2 › Chapter 2.2 › IS NULL and NULL Semantics
NULL basics

NULL means missing or unknown. Equality operators do not behave with NULL; use IS NULL or IS NOT NULL instead.

Example: find employees without a commission by testing that the commission column is NULL.
Practical notes
  • Do not compare NULL with equals: it yields unknown, not true.
  • Document why NULLs exist so you can handle them consistently in filters and reports.
  • Combine IS NULL with other conditions carefully to avoid accidental exclusion.
Correct NULL handling prevents subtle data loss and incorrect report results.
