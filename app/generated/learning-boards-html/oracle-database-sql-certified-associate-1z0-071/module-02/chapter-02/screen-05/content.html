Module 2 › Chapter 2.2 › Comparison Operators
Operator list
  • equals — tests exact equality.
  • not equals — tests inequality; two valid forms exist in SQL.
  • less than / greater than — relational ordering for numbers and dates.
  • less than or equal / greater than or equal — inclusive comparisons.
Example
Find employees with salary greater than five thousand.
Use greater-than or greater-than-or-equal when thresholds include the boundary value.
Practical notes
  • Quote text with single quotation marks and normalize case when needed.
  • Do not compare NULL with equals; use IS NULL instead.
  • When combining comparisons, keep them atomic and readable.
Common mistake

Using double quotes for string literals or trying to test NULL with equality leads to incorrect or unknown results.
