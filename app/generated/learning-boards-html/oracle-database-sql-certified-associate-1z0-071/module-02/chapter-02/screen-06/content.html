Quoting and case
Single quotation marks are required for string literals. Double quotes name objects and will not work for matching text. Oracle compares strings case-sensitively by default.
Example pattern
Find job id equal to IT underscore PROG conceptually: match uppercase literal in single quotes or normalize with a case function.
Practical advice
  • When you need case-insensitive matches, convert both the column and the literal to the same case using built-in functions.
  • If a text match fails, check for accidental double quotes or trailing spaces in fixed-length columns.
Mnemonic
Single quotes for strings; normalize with upper or lower for stable matching.
