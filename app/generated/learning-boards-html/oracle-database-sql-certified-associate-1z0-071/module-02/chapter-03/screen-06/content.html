Module 3 › Chapter 2.3 › Multi-column Sorting
Rule

Primary, then secondary, then tertiary

List columns in ORDER BY from most important grouping to least. Each later column resolves ties from previous ones.

SELECT first_name, last_name, department_id, salary
FROM employees
ORDER BY department_id ASC, salary DESC;
Department groups are ordered A→Z then top earners appear first within those groups.
Misconception
Assuming ORDER BY column order is irrelevant. Swap columns and you change which rows are grouped together before tie-breaking.
Concrete example
Imagine departments 10 and 20. With department_id ASC, department 10's rows appear before 20. Within department 10, salary DESC shows highest-paid first.
Key Takeaway

Order columns by priority and set ASC/DESC for each to precisely control grouping and tie-breaking.
