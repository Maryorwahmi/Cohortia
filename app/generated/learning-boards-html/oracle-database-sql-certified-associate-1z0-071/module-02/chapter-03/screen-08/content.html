Module 3 › Chapter 2.3 › Pagination with OFFSET
Formula

OFFSET = (page - 1) × pageSize

Calculate offsets to retrieve the correct page slice.

-- Page 3, page size 10
OFFSET 20 ROWS
FETCH NEXT 10 ROWS ONLY;
Skip the first two pages (20 rows), then fetch the next ten rows for page three.
Practical notes
  • Large offsets can be inefficient because the database still scans skipped rows.
  • For APIs, consider limiting deep paging or using keyset pagination for better performance.
  • When fewer than FETCH rows remain, the query returns what's available without error.
Key Takeaway

Use the simple page formula for predictable slicing, and be aware of performance trade-offs for large offsets.
