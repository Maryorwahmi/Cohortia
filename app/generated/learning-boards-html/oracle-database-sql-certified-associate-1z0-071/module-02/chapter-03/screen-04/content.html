Module 3 › Chapter 2.3 › ORDER BY — Definition
Definition

ORDER BY sorts the result set

By default ORDER BY applies ascending order. It decides what comes first and last in a predictable way when used correctly.

Quick example
SELECT first_name, last_name
FROM employees
ORDER BY last_name;
This returns names alphabetically because ASC is implicit.
Common misconception
ORDER BY changes only the output order, not the stored row order. Rely on it for display, not physical storage guarantees.
Pro tip
When building APIs, always include ORDER BY if you rely on the top or bottom rows across multiple calls.
Annotated Example
-- List employees alphabetically by last name
SELECT employee_id, first_name, last_name
FROM employees
ORDER BY last_name ASC;
Because ASC is explicit here, the result will list from A to Z. For numbers, ASC lists smallest to largest; for dates, oldest to newest.
Key Takeaway

ORDER BY controls visible ordering; state your ordering explicitly when predictability is required.
