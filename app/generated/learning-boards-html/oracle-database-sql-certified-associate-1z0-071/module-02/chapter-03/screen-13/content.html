Module 3 › Chapter 2.3 › Hands-on Activity

Run these queries

1. Sort by last name
SELECT employee_id, first_name, last_name
FROM employees
ORDER BY last_name ASC;
2. Highest-paid first
SELECT employee_id, first_name, last_name, salary
FROM employees
ORDER BY salary DESC;
3. Department then salary
SELECT employee_id, first_name, last_name, department_id, salary
FROM employees
ORDER BY department_id ASC, salary DESC;
4. Top 3 salaries
SELECT employee_id, first_name, last_name, salary
FROM employees
ORDER BY salary DESC
FETCH FIRST 3 ROWS ONLY;
5. Ranks 4–6 by salary
SELECT employee_id, first_name, last_name, salary
FROM employees
ORDER BY salary DESC
OFFSET 3 ROWS FETCH NEXT 3 ROWS ONLY;
Key Takeaway

Execute each query and inspect edge cases to confirm ordering and paging behavior before using results in reports or APIs.
