Clause order matters

Keep clauses in the expected sequence to ensure correct SQL parsing and semantics.

SELECT employee_id, first_name
FROM employees
WHERE department_id = 10
ORDER BY salary DESC
OFFSET 5 ROWS FETCH NEXT 5 ROWS ONLY;
This returns the 6th–10th highest-paid employees in department 10 in a predictable manner.
Syntax trap
Placing OFFSET before ORDER BY is invalid for pagination semantics and will typically cause errors or wrong behavior.
Style tip
Use FETCH FIRST N for top-N wording or FETCH NEXT N for paging; keep usage consistent in your codebase.
Key Takeaway

Adhere to clause order to avoid syntax errors and ensure predictable query behavior across environments.
