Common errors and fixes

Clause order error
Fix by placing ORDER BY after WHERE and before OFFSET FETCH.
Missing ORDER BY with OFFSET
Add a stable ORDER BY key such as primary key plus a timestamp to avoid inconsistent pages.
Off-by-one offsets
Compute OFFSET = (page - 1) × pageSize to retrieve the intended slice.
Performance with large offsets
Consider keyset pagination or limit maximum page size if OFFSET causes slow queries.
Key Takeaway

Check clause order, include ORDER BY with OFFSET, verify your offset math, and watch performance for deep paging.
