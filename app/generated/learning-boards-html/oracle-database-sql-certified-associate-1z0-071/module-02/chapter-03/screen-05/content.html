Module 3 › Chapter 2.3 › ASC vs DESC
Ascending (ASC)

Default: smallest to largest

Use ASC when you want A to Z, low to high, or oldest first.

-- Alphabetical directory
SELECT first_name, last_name
FROM employees
ORDER BY last_name ASC;
If you omit ASC, the database applies ascending order implicitly.
Descending (DESC)

Reverse: largest to smallest

Use DESC to surface top values like highest salary or newest hire.

-- Top earners first
SELECT first_name, last_name, salary
FROM employees
ORDER BY salary DESC;
DESC must be explicit when you need high-to-low ordering.
Mixed columns
You can specify direction per column: ORDER BY department_id ASC, salary DESC sorts by department first, then highest-paid within each department.
Key Takeaway

Pick ASC or DESC based on what should appear at the top of the result set and test with representative rows.
