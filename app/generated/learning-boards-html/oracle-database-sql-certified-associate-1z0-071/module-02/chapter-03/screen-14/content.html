Module 3 › Chapter 2.3 › Key Concepts
ORDER BY Clause
Sorts rows based on one or more columns to present data in a meaningful order.
Multi-column Sort
Order the columns by priority; each subsequent column resolves ties from the previous.
OFFSET FETCH
Skip rows and return a fixed number for top-N or page slices; must be used with ORDER BY.
One-line takeaway
Always pair ordering with explicit directions and use OFFSET FETCH to return predictable pages or top-N results.
