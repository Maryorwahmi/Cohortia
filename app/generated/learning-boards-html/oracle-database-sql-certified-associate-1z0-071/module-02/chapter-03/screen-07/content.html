Top-N pattern

Fetch first N rows after ordering

-- Top 5 highest-paid employees
SELECT first_name, last_name, salary
FROM employees
ORDER BY salary DESC
FETCH FIRST 5 ROWS ONLY;

This returns the five largest salary values. FETCH FIRST guarantees the maximum rows retrieved.

Skip then take
-- Employees ranked 6 through 10 by salary
SELECT first_name, last_name, salary
FROM employees
ORDER BY salary DESC
OFFSET 5 ROWS
FETCH NEXT 5 ROWS ONLY;
OFFSET 5 skips the first five rows then FETCH NEXT 5 returns the next five.
Warning

OFFSET FETCH without ORDER BY yields unpredictable pages. Always include a stable ORDER BY expression.
