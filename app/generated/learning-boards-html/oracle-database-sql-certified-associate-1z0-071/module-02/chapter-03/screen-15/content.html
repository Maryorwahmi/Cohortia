Module 3 › Chapter 2.3 › What to Remember
1. Specify direction
Use ASC or DESC explicitly when order matters.
2. Column priority
Place primary sort columns first, then secondary columns for tie-breaking.
3. Order before OFFSET
Always include ORDER BY when using OFFSET FETCH for predictable paging.
Final takeaway
These simple rules make your sorted and paged queries reliable for reports and application UIs.
