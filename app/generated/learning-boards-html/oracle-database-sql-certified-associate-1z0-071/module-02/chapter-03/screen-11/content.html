Module 3 › Chapter 2.3 › ROWNUM vs OFFSET

Why OFFSET FETCH beats ROWNUM

ROWNUM is assigned before ORDER BY, which can lead to unexpected top-N results. OFFSET FETCH is standard and predictable.

ROWNUM trap
SELECT * FROM employees WHERE ROWNUM <= 5;
This returns the first five rows the engine finds, not necessarily the top five by salary. Ordering must be done in a subquery to work around this.
Preferred pattern
SELECT first_name, last_name, salary
FROM employees
ORDER BY salary DESC
FETCH FIRST 5 ROWS ONLY;
Clear, standard, and works as expected with ORDER BY.
Key Takeaway

Prefer OFFSET FETCH for clarity and standards compliance; use ROWNUM only when maintaining legacy patterns or after careful testing.
