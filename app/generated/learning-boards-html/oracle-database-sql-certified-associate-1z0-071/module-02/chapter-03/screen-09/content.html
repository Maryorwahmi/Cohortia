Module 3 › Chapter 2.3 › ORDER BY + OFFSET

Undefined ordering without ORDER BY

Relying on implicit order can cause inconsistent pages and data anomalies in applications.

Bad pattern
SELECT * FROM employees
OFFSET 10 ROWS FETCH NEXT 10 ROWS ONLY;
Without ORDER BY the returned slice is arbitrary and can change across runs.
Good pattern
SELECT * FROM employees
ORDER BY employee_id
OFFSET 10 ROWS FETCH NEXT 10 ROWS ONLY;
A stable unique key ensures consistent paging across executions.
Common mistake

Using OFFSET without ORDER BY leads to unpredictable and potentially buggy paging; always order first.
