Practice checks and verifications

Short tests you can run to confirm your queries behave as expected.

Sort Check
Run ORDER BY last_name ASC and confirm the first entry starts with A; reverse with DESC to check last entries.
Hierarchy Check
Use ORDER BY dept_id ASC, salary DESC and find two employees in same department to confirm internal sorting by salary.
Pagination Check
For page 3 with size 10, verify OFFSET 20 FETCH NEXT 10 ROWS ONLY returns the expected slice when ORDER BY is present.
Key Takeaway

Design verification queries for sort direction, multi-column behavior, and pagination before integrating results into apps or reports.
