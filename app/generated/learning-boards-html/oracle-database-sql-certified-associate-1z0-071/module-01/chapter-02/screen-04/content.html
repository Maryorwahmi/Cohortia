Module 1 › Chapter 1.2 › Client Tools
Definition

SQL Developer

A graphical IDE for composing queries, browsing objects, and viewing result grids. Helpful for exploration and building queries interactively.

When to use

Exploring unknown schemas, formatting reports, copying column lists.

GUI benefits

Clickable object trees and inline data preview.

Example

Open a connection to the sample HR schema, expand EMPLOYEES, and copy the column list to compose a focused SELECT.

Definition

SQL*Plus

A command-line client used for running scripts and automating tasks. Favored in CI, scheduled jobs, and quick remote access.

When to use

Scripting, automation, and environments where GUIs are not available.

CLI benefits

Simple output suitable for logs and pipeline parsing.

Scenario

After exploring columns in the GUI, paste a concise SELECT into a script and run it in SQL*Plus for scheduled report generation.
