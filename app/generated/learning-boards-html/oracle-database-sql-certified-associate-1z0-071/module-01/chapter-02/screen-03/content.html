Guided activity: Employee data retrieval

Follow these steps in SQL Developer or SQL*Plus to build confidence with connection and SELECT patterns.

1. Inspect all columns

Use a broad query to learn the table layout, then note column names and types before crafting targeted queries.

2. Select specific columns

Request only the columns you need for the report or script to avoid unnecessary data transfer.

3. Use DISTINCT and compute

Find unique job identifiers and compute annual salary by multiplying monthly salary by twelve, then alias the result for clarity.

Common Mistake

Forgetting the FROM clause or misspelling table names will produce errors; check messages in the client to correct object names or casing.

Pro Tip

Use the graphical schema browser to confirm column names before writing queries, especially when unsure about casing or quoted identifiers.
