Code Walkthrough
-- Compute annual salary and assign a readable alias
SELECT first_name, last_name, salary * 12 AS "Annual Salary"
FROM employees;

-- If you omit AS, the expression still works but the column header is less descriptive.
Practice: try computing quarterly pay by multiplying salary by three and assign the alias "Quarterly Earnings".
Why alias?

Aliases improve readability and are useful for reports and downstream code that consumes query output.

Caution

Division by zero will raise an error. Guard divisors or use defensive functions in later lessons.

Key Takeaway

Use arithmetic to derive values and assign clear aliases so outputs are self-describing.
