Asterisk

Quick inspection

The asterisk returns all columns and is useful when you need a fast view of table content and structure.

When it's OK

Small development tables or one-off exploration queries.

Pitfall

Can reveal unneeded columns and causes larger network payloads.

Explicit Columns

Precise and robust

Listing columns limits output, documents intent, and protects downstream consumers from unexpected schema changes.

When to prefer

Reports, APIs, and production queries where performance and stability matter.

Benefit

Explicit order in results and resilience to new columns being added.

Example

If only first name, last name, and salary are needed for a payroll report, request those columns explicitly to avoid including address or manager identifiers that are irrelevant.

Key Takeaway

Use the asterisk for quick exploration only; list specific columns for production and reporting.
