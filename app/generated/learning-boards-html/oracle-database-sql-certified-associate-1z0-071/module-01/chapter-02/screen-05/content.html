Process Flow

Open a session

Confirm network reachability, target service, and authentication to establish a working session.

1. Host & Port

The network address and listener port route your client to the database server. If unreachable, verify firewall and DNS.

2. Service name / SID

The service identifies the specific database instance. Using the wrong name connects you to the wrong dataset or fails the handshake.

3. Credentials

Username and password authenticate and determine what objects you can query after connecting.

Troubleshooting checklist
  • Ping host and confirm port is listening.
  • Confirm service name matches the intended database.
  • Check that credentials are valid and account is unlocked.
  • Inspect firewall and network restrictions for remote connections.
Example

If connection fails with a network error, test reachability first. If it connects but denies access, verify username and password.
