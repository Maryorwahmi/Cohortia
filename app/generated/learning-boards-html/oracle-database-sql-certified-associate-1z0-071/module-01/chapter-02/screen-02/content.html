Learning Objectives

Build practical skills for connecting and querying an Oracle Database.

Learn → Understand → Apply → Master
01
Choose and use a client tool

Identify when to use SQL Developer for exploration versus SQL*Plus for scripting and automation.

VERIFIED COMPETENCY MILESTONE
02
Establish a stable connection

Provide host, port, service name or SID, and credentials to open a session that targets the intended database instance.

VERIFIED COMPETENCY MILESTONE
03
Retrieve precise columns

List only the columns you need to reduce data transfer and keep queries robust when schemas evolve.

VERIFIED COMPETENCY MILESTONE
04
Use DISTINCT, arithmetic, and aliases

Remove duplicates, compute derived values, and label outputs so results are readable for reports and downstream code.
