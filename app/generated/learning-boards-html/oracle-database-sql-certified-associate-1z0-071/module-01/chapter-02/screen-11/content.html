Live Coding Plan

Basic Employee Data Retrieval

Follow these steps in SQL Developer or SQL*Plus to practice connection and SELECT skills.

Step 1 — Inspect

Run a broad retrieval to view table columns and sample values. Use the result to pick relevant columns.

Step 2 — Select specific columns

Write a SELECT that returns employee_id, first_name, last_name, email, hire_date.

Step 3 — DISTINCT

List distinct job identifiers to see which roles exist in the table.

Step 4 — Compute & Alias

Multiply salary by twelve to compute annual pay and assign a clear alias for the column header.

Reflection

Decide which of these queries belong in automation scripts and which are for interactive exploration. Favor explicit columns and friendly aliases for scripts and reports.
