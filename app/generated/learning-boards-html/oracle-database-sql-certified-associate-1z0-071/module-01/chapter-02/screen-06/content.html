Note: code above is for display. Run these statements in your client to observe results.
Why inspect first

Exploration helps you understand available columns and values before crafting efficient queries.

Example workflow

Explore with a broad retrieval, identify needed fields, and run a refined SELECT that lists those fields in the required order.

Key Takeaway

Use exploration to learn structure, then list specific columns to keep queries efficient and stable.
