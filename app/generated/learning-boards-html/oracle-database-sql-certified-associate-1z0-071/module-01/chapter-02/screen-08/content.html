Module 1 › Chapter 1.2 › DISTINCT
Definition

DISTINCT removes duplicate rows

When you need unique values, DISTINCT filters out repeated rows so each returned value or tuple appears once.

Example

Request unique job identifiers to see the roles present in your employee table, or request department and job pairs to see unique combinations.

When to use

Reporting, lookup lists, and reducing duplicates for downstream processing.

Performance note

DISTINCT can be expensive on large tables, especially with many columns. Consider indexed columns or aggregation alternatives when needed.

Quick Contrast

DISTINCT on one column returns unique values for that column. DISTINCT on multiple columns returns unique combinations of those columns.

Key Takeaway

DISTINCT is for deduplication, but its scope depends on which columns you include; use it thoughtfully on large datasets.
