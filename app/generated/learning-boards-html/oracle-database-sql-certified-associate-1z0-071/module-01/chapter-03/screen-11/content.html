Module 2 › Chapter 1.3 › NULL Handling
IS NULL / IS NOT NULL
Detect missing values
NULL means unknown or absent. Use IS NULL to find missing values; equality comparisons with NULL do not work.
Examples
-- Employees without commission
SELECT first_name, last_name, commission_pct
FROM employees
WHERE commission_pct IS NULL;

-- Employees who do have commission
SELECT first_name, last_name, commission_pct
FROM employees
WHERE commission_pct IS NOT NULL;
Common errors
Do not write commission_pct = NULL; this will never return true. Also be careful when chaining NULL checks with other conditions; use parentheses for clarity.
Key Takeaway

Treat NULL specially with IS NULL or IS NOT NULL; test queries on rows containing NULL to validate behavior.
