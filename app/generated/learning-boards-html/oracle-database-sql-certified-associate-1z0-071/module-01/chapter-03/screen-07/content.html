Module 2 › Chapter 1.3 › Logical Operators
Process
AND, OR, NOT
Combine predicates to express multi-part business rules. Translate requirements to boolean logic then implement in WHERE.
Examples
-- AND: both conditions must be true
SELECT first_name, last_name
FROM employees
WHERE department_id = 90 AND salary > 10000;

-- OR: either condition qualifies
SELECT first_name, last_name
FROM employees
WHERE department_id = 90 OR department_id = 60;

-- NOT: negate a condition
SELECT first_name, last_name
FROM employees
WHERE NOT department_id = 90;
Operator precedence
SQL evaluates NOT then AND then OR. When you mix AND and OR, use parentheses to ensure the correct grouping and avoid unintended results.
Practical tip
Write complex conditions with parentheses even if precedence would yield the same result. Clear grouping avoids mistakes when conditions change.
Quick check
  • Turn your requirement into plain-English clauses.
  • Decide which clauses must all hold and which are alternatives.
  • Apply parentheses to lock the evaluation order.
