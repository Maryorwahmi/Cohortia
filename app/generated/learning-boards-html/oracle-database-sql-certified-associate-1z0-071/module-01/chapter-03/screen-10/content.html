LIKE
% and _ wildcards
Use percent for zero-or-more characters and underscore for exactly one character. Normalize case when needed for consistent results.
Examples
-- Names starting with S
SELECT first_name, last_name
FROM employees
WHERE first_name LIKE 'S%';

-- Names with 'a' as second letter
SELECT first_name, last_name
FROM employees
WHERE last_name LIKE '_a%';
Performance note
Leading percent in a pattern prevents standard index usage and may force a full scan. Use full-text search features for advanced needs.
Common mistake
Overbroad patterns like percent name percent can match unintended substrings; be specific with patterns when possible.
