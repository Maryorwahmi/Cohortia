Filtering Data with the WHERE Clause
Use predicates to restrict which rows a SELECT returns. Learn the operators and safe patterns to write correct filters.
In this lesson
Write filters with comparisons, logical operators, and special predicates to return precise result sets.
Why it matters
Efficient, accurate filters reduce data transferred and avoid incorrect business reports caused by misapplied predicates.
Concept map
Comparisons
=, !=, <, >, <=, >=
Logical
AND, OR, NOT
Special
BETWEEN, IN, LIKE, IS NULL
Coming up: examples using the employees table, operator precedence and safe patterns to avoid common mistakes.
Visual summary
Example filter
SELECT employee_id, first_name, last_name
FROM employees
WHERE department_id = 90;
Find employees assigned to department 90.
Pattern match
SELECT first_name, last_name
FROM employees
WHERE first_name LIKE 'S%';
Names starting with S using wildcard percent.
