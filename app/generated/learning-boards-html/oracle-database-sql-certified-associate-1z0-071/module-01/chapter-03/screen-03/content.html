How objectives translate to practice
Construct WHERE filters
Practice: filter employees by department and verify the count. Tip: without WHERE, you get all rows; with WHERE, you limit I/O.
VERIFIED COMPETENCY MILESTONE
Use comparisons correctly
Remember string literals use single quotes and dates often require a session format. Numeric values do not use quotes.
VERIFIED COMPETENCY MILESTONE
Combine conditions
Exercise: run the same filter with AND and then with OR to see how many rows change. Use parentheses when logic mixes to preserve intent.
VERIFIED COMPETENCY MILESTONE
Special operators
Try BETWEEN for hire date ranges, IN for job lists, LIKE for patterns, and IS NULL to find missing data. Each reduces verbose OR chains.
