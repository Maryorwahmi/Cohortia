Core Concept
WHERE: row-level filtering
The WHERE clause evaluates a condition for each row. Only rows where the condition is true are included in the result set.
Example
SELECT employee_id, first_name, last_name
FROM employees
WHERE department_id = 90;
This returns only employees assigned to department 90.
Common misconception
WHERE does not filter groups created by aggregation. Use HAVING to filter aggregated results instead.
Key Takeaway

Describe the row-level rule in plain English, then implement it with WHERE to ensure your query returns the intended rows.

Teaching visual
Sieve metaphor
Imagine the table as a pile of records and WHERE as a sieve that only lets through rows matching the test. This reduces volume and focuses your results.
Quick check
  • State the condition in plain English.
  • Run the query and inspect a handful of rows.
  • Adjust the predicate until results match expectations.
Try this
Modify the example to filter for a different department or a salary greater than a threshold. Confirm the returned rows meet the rule.
