Step-by-step
  1. Employees in department 50: run a simple WHERE department_id equals the value and inspect rows.
  2. High-earning sales reps: combine job match and salary greater-than with AND and validate returned salaries.
  3. Hired between dates: use BETWEEN with correct date literals and confirm boundary inclusion.
  4. No commission: use IS NULL on the commission column and check a few records for missing values.
  5. Pattern match: find first names where the second letter is 'e' using underscore and percent wildcards.
Try this

Modify the queries to test parentheses by combining OR and AND and observe how the result counts change.

Starter queries
SELECT employee_id, first_name, last_name
FROM employees
WHERE department_id = 50;
SELECT first_name, last_name, job_id, salary
FROM employees
WHERE job_id = 'SA_REP' AND salary > 9000;
SELECT first_name, last_name, hire_date
FROM employees
WHERE hire_date BETWEEN '01-JAN-2005' AND '31-DEC-2007';
SELECT first_name, last_name
FROM employees
WHERE commission_pct IS NULL;

SELECT first_name, last_name
FROM employees
WHERE first_name LIKE '_e%';
Run each query, inspect returned rows, and adjust your predicate when results differ from the plain-English rule. This iterative approach builds reliable filters for real work.
