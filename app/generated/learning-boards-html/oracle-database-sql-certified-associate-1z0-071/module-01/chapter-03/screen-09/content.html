BETWEEN
Inclusive range checks
BETWEEN returns true when a value is between two endpoints, including both endpoints. Use it for dates and numeric ranges.
Example
SELECT first_name, last_name, hire_date
FROM employees
WHERE hire_date BETWEEN '01-JAN-2005' AND '31-DEC-2007';
IN
Check membership against a list
IN is shorthand for multiple OR comparisons and improves readability when checking against a small set of known values.
Example
SELECT first_name, last_name, job_id
FROM employees
WHERE job_id IN ('IT_PROG', 'SA_REP', 'AD_VP');
Tip: For long lists, consider a small lookup table and a join for maintainability and performance.
