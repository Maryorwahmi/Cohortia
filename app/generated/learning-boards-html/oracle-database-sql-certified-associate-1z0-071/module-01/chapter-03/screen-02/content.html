Learning Objectives
Four competencies to practice and verify
Bloom: Learn → Understand → Apply → Master
01
Construct WHERE filters
Write SELECT statements that include WHERE to return only rows matching a condition. This matters because filtering early reduces volume and focuses analysis.
Mnemonic: funnel icon
VERIFIED COMPETENCY MILESTONE
02
Use comparison operators
Apply equals, inequalities and range comparisons to numeric, string, and date values. This ensures you precisely select the target rows you need for reports.
Mnemonic: scale / balance
VERIFIED COMPETENCY MILESTONE
03
Combine conditions with logic
Use AND, OR, and NOT to express compound rules. Understanding how they interact prevents incorrect result sets.
Mnemonic: Venn overlap
VERIFIED COMPETENCY MILESTONE
04
Apply special operators
Use BETWEEN, IN, LIKE, and IS NULL for ranges, lists, pattern matches, and missing values. These give concise, readable filters for common tasks.
Mnemonic: toolbox
