Module 2 › Chapter 1.3 › Comparison Operators
Definition
=, !=, <, >, <=, >=
Use these operators to compare column values to constants or expressions. Pick inclusive or exclusive forms to control boundaries.
Examples
-- Exact match for job code (string uses single quotes)
SELECT first_name, last_name
FROM employees
WHERE job_id = 'IT_PROG';

-- Numeric comparison for salary
SELECT first_name, last_name
FROM employees
WHERE salary > 10000;
Common mistake
Do not compare NULL with equals; use IS NULL. Also ensure you match data types when comparing values.
Guided checks
  • Confirm whether the column is numeric, string, or date before choosing the comparison form.
  • Decide inclusive or exclusive bounds: equals and less-than-or-equal include boundary values.
  • Run sample values near boundaries to verify edge cases.
Key Takeaway

Pick the comparison operator that exactly matches your business rule and test boundary values to avoid off-by-one mistakes.
