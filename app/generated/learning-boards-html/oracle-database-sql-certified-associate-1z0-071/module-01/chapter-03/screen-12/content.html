Common Mistakes & Safety Notes
Equality with NULL
Using equals with NULL returns no rows. Use IS NULL or IS NOT NULL to check for missing data.
String case
String comparisons can be case-sensitive. Normalize case or use case functions when you need case-insensitive matching.
Operator grouping
AND and OR have different precedence. Use parentheses to avoid unintended logic and to document grouping.
Like patterns and performance
Leading wildcards prevent index use and may cause full scans. Consider alternatives for large tables.
Quick safety checklist

Describe the filter, test with sample rows including NULL and edge values, add parentheses for clarity, and prefer concise special operators for readability.
