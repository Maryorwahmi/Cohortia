Module 1 › Chapter 1.1 › Key Concepts
Databases are managed systems
They enforce integrity, concurrency, and security for shared use.
Relational structure and keys
Tables, rows, and columns model entities; keys identify and connect them.
SQL is declarative
Describe the data you want; the DBMS chooses an execution plan.
Summary Takeaway

Keep these three ideas in mind as a quick checklist: managed system, relational structure with keys, and SQL as the tool to express data needs.
