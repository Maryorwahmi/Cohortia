Module 1 › Chapter 1.1 › Assessment & Mistakes
Sample assessment
  1. Which column is the best primary key for EMPLOYEES and why?
  2. List two likely foreign keys in EMPLOYEES and their referenced tables.
  3. Which SQL category creates a table and which retrieves rows?
Common pitfalls
  • Choosing mutable or non-unique fields as primary keys.
  • Confusing DDL for DML operations and accidentally changing structure.
  • Forgetting transaction control when performing multiple related updates.
Study Tip

Work through small schema diagrams and answer assessment questions aloud. That helps solidify identification of keys and command categories.
