Module 1 › Chapter 1.1 › Categories of SQL Commands
DDL
Data Definition Language
Defines and alters structures. Example: CREATE TABLE, ALTER TABLE, DROP TABLE.
DML
Data Manipulation Language
Works with table contents. Example: SELECT, INSERT, UPDATE, DELETE.
DCL
Data Control Language
Manages privileges. Example: GRANT, REVOKE.
TCL
Transaction Control Language
Controls transactions. Example: COMMIT, ROLLBACK, SAVEPOINT.
Practical note

Think DDL for structure changes, DML for content, DCL for security, and TCL when you need to control the atomic boundaries of work. Mistaking one for another can lead to lost changes or permission errors.
