What SQL does

SQL lets you ask for data, change it, define objects, set permissions, and control transactions. It focuses on describing desired results rather than procedural steps.

Query
SELECT retrieves data based on conditions and joins.
Structure
CREATE TABLE defines a schema object and columns.
Control
GRANT and REVOKE manage privileges for users.
Transactions
COMMIT and ROLLBACK manage transactional boundaries.
Why declarative matters

By stating what you want, the database optimizer can find efficient execution plans. This separates intent from performance tuning details.

Misconception
SQL is procedural. In reality you declare the result and the engine chooses how to obtain it.
Key Takeaway

Use SQL to express intent about data. The DBMS translates that intent into an optimized plan.
