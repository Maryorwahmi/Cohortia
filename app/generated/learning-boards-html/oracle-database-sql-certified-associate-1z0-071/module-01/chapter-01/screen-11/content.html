Step-by-step plan
  1. Identify needed columns: first_name, last_name, department_name.
  2. Find join keys: employees.department_id = departments.department_id.
  3. Decide command type: SELECT (DML) to retrieve rows.
  4. Apply filters as required, for example by salary or department.
Design tip
Pick only required columns for clarity and better performance.
Example scenario
To include a manager's name, recognize that manager_id is a self-reference to employees.employee_id and plan an additional join to EMPLOYEES aliased as MANAGER.
Key Takeaway

Work from schema to plan, then to select. Schema reading simplifies query design and avoids guesswork.
