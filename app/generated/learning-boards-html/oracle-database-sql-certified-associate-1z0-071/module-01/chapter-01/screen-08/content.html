Client-server model

Clients send SQL to the Oracle server. The server parses, optimizes, and executes statements, then returns results. The server also manages data files, memory caches, and background processes.

Clients
Tools and apps that submit SQL requests.
Server
Executes SQL, enforces constraints, and manages files and memory.
Files & Processes
Data files, redo logs, and background processes for recovery and performance.
Concrete scenario
When two users edit the same record, the server coordinates locks and transactions to ensure changes do not corrupt data. If a transaction fails, rollback restores a consistent state.
Why centralization helps
Central control simplifies backups, security, and consistent enforcement of business rules.
Key Takeaway

The server is the single source of truth for enforcement and coordination of data operations across clients.
