Module 3 › Chapter 3.2 › LIKE & Wildcards
Definition

Pattern matching with LIKE

% matches zero or more characters, _ matches exactly one. Use ESCAPE to search for these symbols literally.

Starts with
first_name LIKE 'S%'
Second letter
last_name LIKE '_e%'
Performance note
Leading wildcards can force full table scans. Avoid them for indexed columns when performance matters.
Examples
-- Names starting with S
SELECT first_name, last_name
FROM employees
WHERE first_name LIKE 'S%';

-- Second letter is 'e'
WHERE last_name LIKE '_e%';

-- Literal percent using ESCAPE
WHERE description LIKE '%50\%%' ESCAPE '\';
Key Takeaway

LIKE is powerful for flexible string searches; choose patterns carefully to balance correctness and performance.
