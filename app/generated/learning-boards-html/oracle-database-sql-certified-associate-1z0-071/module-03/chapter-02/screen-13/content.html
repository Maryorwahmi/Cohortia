Complex Employee Search — Guided steps

Task 1
Find employees in department 50 OR salary > 12000. Verify each branch first, then the combined count.
Task 2
List employees with salary BETWEEN 7000 AND 9000; confirm boundary values are included.
Task 3
Retrieve job_id IN ('IT_PROG','SA_REP') AND hire_date > TO_DATE('01-JAN-2006',...). Test subqueries then combine.

Task 5
Find employees with commission_pct IS NULL AND salary < 7000. Combine NULL checks with numeric filters.
Final Check
