Module 3 › Chapter 3.2 › BETWEEN for Ranges
Process Flow

Define range, verify boundaries

BETWEEN is inclusive. For dates, always convert to a date type to avoid format errors. Follow a simple test flow to confirm results.
1. Choose bounds
Lower and upper values
2. Ensure types
Numbers or TO_DATE for dates
3. Test boundaries
Verify inclusive behavior
Key Takeaway

BETWEEN is concise and inclusive; confirm boundaries and types to avoid surprises.

Examples
-- Numeric range inclusive
SELECT employee_id, salary
FROM employees
WHERE salary BETWEEN 5000 AND 10000;

-- Date range with explicit conversion
WHERE hire_date BETWEEN TO_DATE('01-JAN-2005','DD-MON-YYYY') AND TO_DATE('31-DEC-2007','DD-MON-YYYY');
Misconception
BETWEEN is exclusive — false. It is inclusive of both endpoints.
Pro tip
Prefer BETWEEN for readability when your bounds are explicit and inclusive.
