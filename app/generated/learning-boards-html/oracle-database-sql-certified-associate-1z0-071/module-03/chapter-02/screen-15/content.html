Module 3 › Chapter 3.2 › Quick Reference
Operator Precedence
AND has higher precedence than OR. Use parentheses to make grouping explicit.
BETWEEN Inclusivity
BETWEEN includes both lower and upper bounds; test boundary values to confirm results.
NULLs & IN
NULL in an IN list does not match NULL values. Add OR column IS NULL to include NULLs intentionally.
Final Tip
Run targeted checks for each part of a WHERE clause, inspect sample rows, and fix grouping or NULL handling before using queries in reports.
