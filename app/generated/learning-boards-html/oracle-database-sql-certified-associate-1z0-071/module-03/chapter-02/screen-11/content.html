Module 3 › Chapter 3.2 › NULLs & Operators
Definition

NULL behavior in filters

NULL is unknown. Comparisons to NULL produce NULL, not true. Use IS NULL and IS NOT NULL for explicit checks.

AND with NULL
If any part is NULL, the AND expression yields NULL and excludes the row.
IN and NULL
value IN (..., NULL) returns NULL for NULL values; explicitly include OR column IS NULL if you want those rows.
Key Takeaway

Always think about unknowns. If NULL values should be included or excluded, state that intent explicitly with IS NULL or IS NOT NULL.

Concrete examples
-- NULL in IN list does not match NULL values
SELECT employee_id
FROM employees
WHERE commission_pct IN (0.1, 0.2, NULL); -- NULL rows yield NULL, not TRUE

-- Include NULL explicitly
WHERE commission_pct IN (0.1, 0.2) OR commission_pct IS NULL;
Check
Query rows where column IS NULL and compare counts when adding or omitting IS NULL in filters.
Misconception
Treating NULL like a value causes missing rows or incorrect logic; always test explicitly for NULLs.
