Module 3 › Chapter 3.2 › OR and Precedence
Definition

OR — one or more conditions

OR returns rows when any of the conditions is true. Carefully group expressions with parentheses when mixing with AND.

Grouping matters
A AND B OR C = (A AND B) OR C, not A AND (B OR C).
NULL interaction
OR can still be true even if one branch is NULL, provided another branch is true.
Key Takeaway

When mixing OR and AND, parenthesize your intent and test results to confirm expected behavior.

Concrete example
-- Employees in department 90 OR 60
SELECT employee_id, first_name, department_id
FROM employees
WHERE department_id = 90 OR department_id = 60;

-- Mixed example where parentheses matter
WHERE (job_id IN ('IT_PROG') AND hire_date > TO_DATE('01-JAN-2006','DD-MON-YYYY')) OR department_id = 60;
Check
Run each branch separately, then the combined expression to ensure grouping matches intent.
Misconception
Assuming parentheses are optional leads to subtle errors in results.
