Module 3 › Chapter 3.2 › Combining Operators
Code Walkthrough

Step-by-step assembly

Test each subcondition individually, then combine with AND/OR and parentheses. Validate by comparing counts and sampling rows.
Step 1
Test job_id membership using IN and confirm returned job families.
Step 2
Test hire_date condition with TO_DATE to ensure correct interpretation.
Step 3
Combine with AND and run counts; add parentheses when adding OR branches.
Key Takeaway

Assemble filters incrementally and verify at each step to catch precedence and NULL issues early.

Combined example
-- Build and verify
SELECT employee_id, first_name, job_id, hire_date
FROM employees
WHERE job_id IN ('IT_PROG', 'SA_REP')
  AND hire_date > TO_DATE('01-JAN-2006','DD-MON-YYYY');

-- Test each branch separately and then combined to confirm counts.
Verification
Compare separate counts for job_id IN(...) and hire_date condition, then compare combined count to ensure intersection.
NULL check
If job_id or hire_date may be NULL, decide whether to include or exclude and add IS NULL checks accordingly.
