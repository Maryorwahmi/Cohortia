Core Concept

Negation with NOT

NOT flips a predicate. Use it to exclude values or ranges, but write clearly and be explicit about NULLs.

NOT with BETWEEN
NOT BETWEEN excludes the inclusive interval defined by the bounds.
NOT with IN
NOT IN excludes listed values; remember NULL handling.
Key Takeaway

Use NOT for readable exclusion, and explicitly check NULLs separately when needed.

Examples & Notes
-- Exclude salaries between 5000 and 10000
SELECT employee_id, salary
FROM employees
WHERE salary NOT BETWEEN 5000 AND 10000;

-- Exclude department 90 explicitly
WHERE NOT (department_id = 90);
Misconception
Assuming NOT removes NULLs — negating a NULL yields NULL; handle NULLs explicitly.
Pro tip
When excluding values, consider whether NULL rows should be included or excluded and add IS NULL checks accordingly.
