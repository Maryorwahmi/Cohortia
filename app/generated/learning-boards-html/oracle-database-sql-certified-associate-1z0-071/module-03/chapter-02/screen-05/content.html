Module 3 › Chapter 3.2 › AND in Practice
Definition

Require all conditions

AND returns rows where every sub-condition is true. Use it to narrow results to the intersection of criteria.

Test pattern
Run each part separately, then run the combined query and compare counts.
NULL caution
If one expression yields NULL, the entire AND yields NULL and excludes the row.
Key Takeaway

AND narrows results. Validate by testing subfilters and checking for NULLs explicitly.

Concrete example
-- Employees in department 90 AND salary > 10000
SELECT employee_id, first_name, salary, department_id
FROM employees
WHERE department_id = 90 AND salary > 10000;
Check
Run WHERE department_id = 90, then WHERE salary > 10000, then combined to confirm intersection.
Common mistake
Using OR instead of AND will dramatically increase results by including rows that meet only one condition.
