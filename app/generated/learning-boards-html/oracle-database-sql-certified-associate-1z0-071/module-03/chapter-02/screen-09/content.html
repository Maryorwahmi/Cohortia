Module 3 › Chapter 3.2 › IN for Sets
Definition

Membership testing with IN

IN checks whether a value belongs to a discrete list. It simplifies readability and is often easier to maintain.

Clean alternative
IN replaces multiple OR comparisons with a single concise list.
NULL caution
If list or value is NULL, handle explicitly with IS NULL when needed.
Key Takeaway

IN improves readability for list membership tests; always consider NULLs separately.

Example
-- Departments 10, 20, 30
SELECT employee_id, first_name, department_id
FROM employees
WHERE department_id IN (10, 20, 30);

-- If you need NULLs too
WHERE department_id IN (10, 20, 30) OR department_id IS NULL;
Check
Compare count of IN against equivalent OR expression to verify behavior.
Note
IN is often easier to refactor into a subquery for dynamic lists.
