Practice checklist

Logical operators
Practice combining department and salary filters, then add parentheses to test precedence. Verify results by checking counts for each subcondition.
BETWEEN safety
Test lower and upper boundary values to confirm inclusivity, and compare with separate >= and <= expressions.
IN and NULLs
Check whether NULL rows should be included and add OR column IS NULL when needed; confirm that NULL in the list does not auto-match NULL values.
LIKE and performance
Avoid leading wildcards for indexed columns when performance matters; use ESCAPE if the pattern contains literal wildcard characters.
