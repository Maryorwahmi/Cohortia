Best Practices
Common mistakes and performance notes
Write clear WHERE clauses, handle NULLs explicitly, and avoid wrapping indexed columns in functions.
1. Check quotes for strings and dates. Missing quotes are a frequent syntax error.
2. Use IS NULL / IS NOT NULL to find missing values; equality won’t work for NULL.
3. Avoid functions on indexed columns unless you have a function-based index; test query performance on large tables.
Concrete checks
-- Wrong: missing quotes
WHERE email = SKING
-- Wrong: comparing to NULL
WHERE department_id = NULL
-- Better: explicit check
WHERE manager_id IS NULL
After changing a WHERE clause, run the query to verify returned rows match your expectation. This small step catches many mistakes early.
Key Takeaway

Clear, type-safe WHERE clauses are both correct and often faster. Test and refine them on real data.
