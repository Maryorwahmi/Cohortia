Definition
NULL values and IS NULL / IS NOT NULL
NULL is absence, not a value like zero or empty string. Test it with IS NULL.
-- Find employees with no commission
SELECT employee_id, first_name, commission_pct
FROM employees
WHERE commission_pct IS NULL;

-- Find employees with a commission
WHERE commission_pct IS NOT NULL;
Common mistake: commission_pct = NULL will never match NULL rows.
Why this matters
Because NULL yields UNKNOWN in boolean logic only TRUE passes the WHERE filter. This means comparisons with NULL silently exclude rows unless handled explicitly.
Key Takeaway

Treat NULL as a special state and use IS NULL / IS NOT NULL to include or exclude those rows intentionally.

Concrete scenario: to find employees without managers use WHERE manager_id IS NULL. That query helps find top-level staff or records needing data entry.
