Module 3 › Chapter 3.1 › Key Concepts — Part 1
WHERE Clause
Filters rows by a condition; only rows evaluating to true are returned.
Comparison Operators
Use =, != or <>, <, >, <=, >= to match and range-filter values.
NULL Value
Represents absence; not equal to zero or empty string and must be tested with IS NULL.
Takeaway: Keep these three concepts at hand when building filters — they are the foundation for accurate SQL queries.
