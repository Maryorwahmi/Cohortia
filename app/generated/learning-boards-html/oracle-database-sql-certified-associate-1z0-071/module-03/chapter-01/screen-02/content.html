Module 3 › Chapter 3.1 › Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Construct WHERE clauses
Compose a condition that filters rows so only matching records are returned. For example, find employees where department_id = 90.
VERIFIED COMPETENCY MILESTONE
02
Use comparison operators
Apply =, !=, <, >, <= and >= to compare columns with literals and expressions. Example: salary > 10000.
VERIFIED COMPETENCY MILESTONE
03
Handle NULL correctly
Identify missing values using IS NULL and IS NOT NULL; equality operators do not work with NULL. Example: manager_id IS NULL.
VERIFIED COMPETENCY MILESTONE
04
Write type-safe comparisons
Use explicit conversions like TO_DATE and TO_CHAR when comparing across different types to avoid ambiguity and rely on Oracle's conversions only when safe.
VERIFIED COMPETENCY MILESTONE
