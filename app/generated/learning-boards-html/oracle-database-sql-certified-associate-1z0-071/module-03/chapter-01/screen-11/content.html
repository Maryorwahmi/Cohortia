Practice queries
Starter queries to run and inspect the results.
SELECT employee_id, first_name, last_name, salary FROM employees WHERE salary = 8000; SELECT employee_id, first_name, last_name, salary FROM employees WHERE salary < 5000; SELECT employee_id, first_name, hire_date FROM employees WHERE hire_date > TO_DATE('01-JAN-2007', 'DD-MON-YYYY'); SELECT employee_id, first_name, manager_id FROM employees WHERE manager_id IS NULL; SELECT employee_id, first_name, commission_pct FROM employees WHERE commission_pct IS NOT NULL;
How to verify
  • Use SELECT COUNT(*) with the same WHERE to confirm expected row counts.
  • If a result is empty, check quotes, NULL handling, and data types.
  • For date filters, confirm the stored format and whether time components exist.
Pro tip: If a query returns no rows, re-run a simpler query to verify the column contains expected values before refining the filter.
Key Takeaway

Small verification steps catch logic and typing mistakes quickly. Build queries iteratively and confirm counts.
