Core Concept
What the WHERE clause does
WHERE evaluates conditions per row and restricts the result set to rows that evaluate to true.
Placement rule: SELECT ... FROM ... WHERE condition; ORDER BY ...
  • It filters rows, not columns.
  • Conditions can use columns, literals, and expressions.
  • Boolean evaluation returns TRUE, FALSE, or UNKNOWN; only TRUE keeps a row.
Key Takeaway

Think of WHERE as the filter that decides which rows you see; it does not alter the data itself.

Concrete example
SELECT employee_id, first_name, last_name, department_id
FROM employees
WHERE department_id = 90;
This query returns only rows where department_id equals 90. Remember: string and date literals must be quoted; numeric literals do not use quotes.
Misconception: WHERE changes data — it does not.
Watch out: using = NULL will never match NULL values.
