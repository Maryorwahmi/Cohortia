Operators
Not-equal and range operators
Express exclusions and ranges with clear relational operators.
-- Exclude department 90
SELECT employee_id, first_name, department_id
FROM employees
WHERE department_id != 90;

-- Salaries greater than 10000
SELECT employee_id, salary
FROM employees
WHERE salary > 10000;
Use parentheses to clarify AND/OR precedence when combining conditions.
Common mistake: using != NULL - this will not match NULL values.
Concrete example and pattern
-- High earners outside a department
SELECT employee_id, first_name, salary, department_id
FROM employees
WHERE salary > 5000 AND department_id != 90;

-- Use parentheses when logic gets complex
WHERE (department_id = 10 OR department_id = 20) AND salary >= 7000;
Parentheses make intent explicit and avoid accidental grouping by operator precedence.
Key Takeaway

Choose operators that clearly express inclusion or exclusion, and use parentheses to avoid logical errors.
