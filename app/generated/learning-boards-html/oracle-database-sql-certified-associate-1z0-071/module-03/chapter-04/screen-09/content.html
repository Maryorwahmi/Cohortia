Nesting Functions and Evaluation Order
Compose small transformations into larger ones by nesting.
Step-by-step example
1) SUBSTR(email,1,3) → take first three characters.
2) UPPER(...) → uppercase that result.
3) LPAD(...,5,'*') → pad to five characters with asterisks.
Try: LPAD(UPPER(SUBSTR(email,1,3)),5,'*') and inspect each intermediate result.
Pitfalls and checks
  • If any inner function returns NULL, the nested expression often becomes NULL.
  • Testing each layer on a single row avoids surprises when applying to full tables.
  • Applying nested functions in WHERE can prevent index use without a function-based index.
