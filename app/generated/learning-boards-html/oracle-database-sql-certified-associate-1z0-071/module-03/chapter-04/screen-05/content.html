Definition
Character Functions: UPPER, LOWER, INITCAP
Standardize letter case and prepare text for display or comparison.
Quick reference
UPPER(string) → convert to uppercase. Example: UPPER('hello') → 'HELLO'.
LOWER(string) → convert to lowercase. Useful for case-insensitive comparison.
INITCAP(string) → capitalize initial letters. Good for proper names.
Example:
SELECT INITCAP('the quick brown fox') FROM dual; — returns 'The Quick Brown Fox'.
Notes and common mistakes
  • These functions expect character input; numeric types may be implicitly converted.
  • INITCAP does not fix extra spaces or punctuation; use TRIM to remove surrounding spaces first.
  • Applying functions in WHERE can prevent index use; consider function-based indexes if needed.
Key Takeaway

Use casing functions to normalize text for display and safe comparisons, and be mindful of spaces and indexing costs.
