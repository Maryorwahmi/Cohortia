NULL Behavior and Type Mismatch
Know how NULLs and types affect function outputs.
NULL propagation
If an argument is NULL, the function often returns NULL.
Example: CONCAT(NULL, 'x') may result in NULL; plan for this with NVL or COALESCE when needed.
Test with DUAL or sample rows to observe behavior before scaling the query.
Type mismatch
Character functions expect character data; numeric functions expect numeric input.
Implicit conversions can hide errors; prefer explicit checks or conversions where possible.
Misconception: implicit conversion always matches developer intent — it does not.
Common mistake

Not checking for NULLs and type mismatches can produce unexpected NULL outputs or runtime errors in large queries.
