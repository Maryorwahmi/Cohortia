ROUND vs TRUNC: Practical Differences
Understand the effect on numeric presentation and when to use each.
Illustration
VALUE = 12345.678
ROUND(VALUE,2) → 12345.68
TRUNC(VALUE,2) → 12345.67
Round for reader-friendly display. Trunc for strict cutoffs or regulatory formats where rounding would be incorrect.
Try this
Run: SELECT salary, ROUND(salary,2), TRUNC(salary,2) FROM employees; and inspect rows where the third decimal is 5 or higher to see divergence.
Key Takeaway

Use ROUND for standard presentation; use TRUNC when exact cut-off without rounding is required.
