Core Concept
Number Functions
Control numeric rounding, truncation, and compute remainders or magnitudes.
Function reference
ROUND(number,decimals) — rounds to precision.
TRUNC(number,decimals) — truncates without rounding.
MOD(a,b) — remainder of a divided by b.
ABS(number) — absolute value; SQRT(number) — square root.
Concrete example
VALUE = 12345.678
ROUND(VALUE,2) → 12345.68
TRUNC(VALUE,2) → 12345.67
MOD(10,3) → 1
Key Takeaway

Use ROUND for human-friendly values and TRUNC when you must avoid rounding. Use MOD and ABS for numeric checks.
