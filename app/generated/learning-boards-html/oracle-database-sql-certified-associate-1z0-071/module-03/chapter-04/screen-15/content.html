Key Concepts
Core ideas to keep front of mind.
Single-Row Functions
Operate per row and return one result per input row.
Character Functions
UPPER, LOWER, INITCAP, SUBSTR, CONCAT/||, LENGTH, INSTR, LPAD, RPAD, TRIM.
Number Functions
ROUND, TRUNC, MOD, ABS, SQRT for numeric formatting and checks.
Summary Takeaway
Use these functions to make data presentation accurate and readable, test expressions on DUAL, and handle NULLs and performance considerations before deploying queries to production.
