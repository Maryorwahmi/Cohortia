Key Concepts — Quick Reference
Three short reminders to keep your queries correct.
Per-row vs Aggregate
Single-row functions return one result per row; aggregations summarize multiple rows.
String quirks
SUBSTR uses 1-based indexing. CONCAT accepts two args; use || for more parts.
Nesting & safety
Test nested layers, handle NULLs, and be mindful of index impacts when using functions in WHERE.
Final takeaway
Apply these rules in small trials on DUAL and sample rows before using transformations across full datasets.
