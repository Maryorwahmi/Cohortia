Definition
Concatenation, SUBSTR, LENGTH, and INSTR
Assemble names, take substrings and locate parts of strings.
Usage Cheatsheet
CONCAT(a,b) — joins two strings. For more parts, use ||.
SUBSTR(str,start,len) — one-based; negative start counts from the end.
LENGTH(str) — returns character count.
INSTR(str,sub,start,n) — position of n'th occurrence; defaults to first occurrence.
Example:
SELECT first_name || ' ' || last_name AS full_name, LENGTH(first_name || ' ' || last_name) FROM employees;
Common pitfalls
  • Assuming CONCAT accepts multiple arguments; it only takes two.
  • For SUBSTR, remember positions start at one; off-by-one errors are common.
  • LENGTH counts characters; be cautious with multibyte or locale-specific cases if present.
