Core Concept
What are Single-Row Functions?
Operate on one row and return one result for that row.
Definition
One input row → one output value
Use in SELECT, WHERE, ORDER BY; not an aggregator like SUM or AVG.
Examples
SELECT UPPER(first_name) FROM employees; — transforms each first name to uppercase.
SELECT ROUND(salary,0) FROM employees; — returns a rounded salary for each employee.
SELECT SUBSTR('Oracle SQL', 1, 6) FROM dual; — returns 'Oracle' for that single expression.
Common misconception
Applying a single-row function does not summarize rows; it only alters values per row. Use aggregations separately when you need a single value for many rows.
Why it matters
  • Formatting output makes reports readable and consistent.
  • Transforming values in WHERE can change which rows match; be careful with indexes.
  • Nesting allows building complex, precise representations from simple primitives.
Key Takeaway

Decide whether you need per-row transforms or group summaries before selecting functions.
