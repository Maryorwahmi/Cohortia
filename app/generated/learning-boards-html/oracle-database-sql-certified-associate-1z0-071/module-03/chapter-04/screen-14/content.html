Performance Considerations and Best Practices
Design queries that are correct and efficient when applied to large tables.
Common performance issue
Applying functions to indexed columns in WHERE can prevent index use and force full table scans.
Example: WHERE UPPER(last_name) = 'SMITH' may not use an index on last_name.
Consider function-based indexes or storing normalized values to preserve indexability.
Optimization checklist
  • Write correct expressions first; then profile with realistic data.
  • If functions in WHERE are necessary, consider function-based indexes.
  • Precompute and store normalized columns when appropriate for frequent queries.
