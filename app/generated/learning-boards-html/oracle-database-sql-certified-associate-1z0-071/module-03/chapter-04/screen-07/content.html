Definition
Padding and Trimming: LPAD, RPAD, TRIM
Control string length and remove surrounding characters.
Examples
LPAD(salary, 10, '*') — left-pad the salary to ten characters using '*'.
RPAD(name, 20, ' ') — right-pad to align in fixed-width reports.
TRIM(' Hello ') — removes surrounding spaces and returns 'Hello'.
TRIM(LEADING '0' FROM '000123') — returns '123'.
Notes and tips
  • Padding is a display technique; avoid padding when numeric calculations are needed later.
  • Use TRIM before LENGTH or SUBSTR to avoid unexpected leading/trailing spaces affecting results.
  • TRIM only affects ends, not interior characters.
Key Takeaway

Use padding for presentation and TRIM to prepare strings for reliable comparison and extraction.
