Define single-row functions
Explain what single-row functions do and how they differ from group functions. Knowing this prevents misuse in aggregation queries.

02
Apply character functions
Use UPPER, LOWER, INITCAP, CONCAT or ||, SUBSTR and TRIM to format text fields for display and comparison.
Mnemonic: clean → format → present
VERIFIED COMPETENCY MILESTONE
03
Use numeric functions
Employ ROUND, TRUNC, MOD and ABS to present numeric values correctly and compute remainders and magnitudes.
Mnemonic: present → compute → report
VERIFIED COMPETENCY MILESTONE
04
Compose and verify nested functions
Combine functions so the inner result feeds the outer function and check for NULLs and type mismatches before using them in WHERE clauses.
Mnemonic: inner to outer → evaluate carefully
