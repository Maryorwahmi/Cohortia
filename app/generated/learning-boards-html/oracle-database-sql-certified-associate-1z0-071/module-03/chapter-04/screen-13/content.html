Definition
DUAL Table and Quick Testing
A tiny sandbox to verify single expressions and nested functions.
Why use DUAL
  • Fast checks of function results without table data.
  • Evaluate nested calls one layer at a time for debugging.
  • Validate edge cases like negative inputs for SQRT or NULLs.
Examples
SELECT SUBSTR('Oracle SQL',1,6) FROM dual; -- 'Oracle'
SELECT LPAD(UPPER(SUBSTR('test@x.com',1,3)),5,'*') FROM dual; -- padded prefix
Key Takeaway

Use DUAL to verify expression logic, then test the same expression on representative rows from employees to confirm behavior at scale.
