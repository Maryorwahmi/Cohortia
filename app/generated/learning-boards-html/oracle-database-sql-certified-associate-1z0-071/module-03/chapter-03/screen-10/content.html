Module 3 › Chapter 3.3 › Explicit NULL Placement: NULLS FIRST and NULLS LAST
Showcase Examples
-- Put NULL commission at the top when sorting ascending
SELECT employee_id, first_name, commission_pct
FROM employees
ORDER BY commission_pct ASC NULLS FIRST;

-- Put NULL salary at the end when sorting descending
SELECT employee_id, first_name, salary
FROM employees
ORDER BY salary DESC NULLS LAST;
Explicit NULL directives remove ambiguity and make downstream processing easier because placement no longer depends on ASC/DESC semantics.
When to use which
  • NULLS FIRST: when unknowns must be visible or prioritized for review.
  • NULLS LAST: when unknowns should be de-emphasized or hidden at the bottom of lists.
  • Document the business reason so future readers know the intent.
Quick check: If you want missing data to always be last regardless of direction, append NULLS LAST to the ORDER BY expression.
