Ordering Query Results with ORDER BY
Sort rows so they tell a story: alphabetical directories, top earners, or grouped department lists.

ORDER BY is always the last clause in a SELECT. Use ASC for ascending (the default) and DESC for descending. You can sort by multiple columns to break ties, refer to aliases, or even use column positions. Oracle treats NULLs specially, and you can control their placement with NULLS FIRST or NULLS LAST.

This lesson uses the employees table and real sorting patterns you'll use in reporting and analysis.
