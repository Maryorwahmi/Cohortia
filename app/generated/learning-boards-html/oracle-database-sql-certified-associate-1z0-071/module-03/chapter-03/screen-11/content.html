Module 3 › Chapter 3.3 › Common Mistakes and Safety Notes
Top Errors
  • ORDER BY placement: must be last in the SELECT statement.
  • Alias misuse: aliases are not available to WHERE.
  • Position volatility: ORDER BY 1,2 can break when SELECT changes.
Performance note
Sorting large datasets can be expensive. Consider indexing frequently sorted columns and avoid unnecessary sorts in large exports.
Fixes and Checks
  1. Verify ORDER BY is last and references existing columns or aliases.
  2. Avoid numeric positions in production code; prefer names or aliases.
  3. Document NULL handling and the reason for specific sort choices.
