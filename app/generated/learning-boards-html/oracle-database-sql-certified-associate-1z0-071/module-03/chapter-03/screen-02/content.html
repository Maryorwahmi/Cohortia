Module 3 › Chapter 3.3 › Learning Objectives
01
Apply ASC / DESC
Use the ORDER BY clause to sort rows ascending or descending. Practically, this lets you create alphabetical lists or rank values like salaries for reports.
Mnemonic: A for Ascend, D for Down — think A→Z and high→low.
VERIFIED COMPETENCY MILESTONE
02
Multi-Column Sorting
Sort by multiple columns to break ties predictably. Choose direction per column so groups are ordered as you intend, for example department then highest salary.
Mnemonic: First key, then tiebreaker.
VERIFIED COMPETENCY MILESTONE
03
Aliases & Positions
Use column aliases in ORDER BY to sort calculated columns. Numeric positions work too, but they are brittle if the SELECT list changes.
Mnemonic: Alias = clear name; Position = short but fragile.
VERIFIED COMPETENCY MILESTONE
04
NULL Placement
Understand Oracle's default NULL sorting and use NULLS FIRST or NULLS LAST to explicitly control where unknown values appear in the order.
Mnemonic: Think explicitly — NULLS FIRST/LAST to avoid surprises.
