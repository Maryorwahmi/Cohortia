Module 3 › Chapter 3.3 › Using Column Aliases in ORDER BY
Why aliases are useful

Aliases give expressions a readable name and can be referenced in ORDER BY because the alias exists after SELECT evaluates.

If you need an expression in WHERE, use a subquery or repeat the expression because WHERE evaluates earlier.

Example and tip are shown next to this text to guide practical use.
Example
SELECT first_name || ' ' || last_name AS full_name, salary
FROM employees
ORDER BY full_name ASC;
This sorts rows by the calculated full_name value. For filtering on full_name you would need a subquery or CTE to use the alias in WHERE.
Misconception check: Trying to use full_name in WHERE will fail because WHERE runs before SELECT assigns the alias.
