Module 3 › Chapter 3.3 › Multi-Column Sorting and Tie-breaking
How It Works
  1. Sort by the first column specified.
  2. For rows with equal values, sort by the second column listed.
  3. Continue to additional columns as needed to break further ties.
Mix directions by specifying ASC or DESC for each column. That flexibility lets you create compound orderings, such as grouping then ranking within groups.
Key Takeaway

Think major key first, then minor keys. Explicit directions per column avoid ambiguity when types differ.

Example
SELECT employee_id, first_name, last_name, department_id, salary
FROM employees
ORDER BY department_id ASC, salary DESC;
This groups employees by department in ascending order; inside each group the highest salaries appear first. It is a common pattern for departmental leaderboards and compact reports.
Check: If two employees in the same department have equal salary, add a third column like hire_date to make ordering deterministic.
