Module 3 › Chapter 3.3 › Referencing Columns by Position
Example and Warning
SELECT first_name, last_name, salary
FROM employees
ORDER BY 2 ASC, 3 DESC; -- sorts by last_name, then salary
This is concise but if you later reorder or add columns the meaning of 2 and 3 will change. Because of that risk, column names or aliases are preferred in production queries.
Best Practice
  • Favor explicit column names or aliases for clarity.
  • Reserve numeric positions for short, throwaway ad-hoc queries.
  • After changing SELECT lists, re-run queries to confirm ORDER BY still sorts intended columns.
Check your understanding: What happens if you insert a new column before the one you referenced numerically? The numeric order will shift and may produce wrong sorting.
