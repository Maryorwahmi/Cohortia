Module 3 › Chapter 3.3 › How Oracle Treats NULL Values in Sorting
Default Behavior
  • ASC: NULLs are treated as highest values and appear last.
  • DESC: NULLs are treated as lowest values and appear first.
Why this matters
Reports that expect unknowns at the end can be incorrect if you sort descending; explicit NULL placement avoids that risk.
Concrete Example
SELECT employee_id, first_name, commission_pct
FROM employees
ORDER BY commission_pct ASC;  -- NULLs appear last by default

-- If using DESC, NULLs would appear first unless overridden
Use explicit NULLS FIRST or NULLS LAST when you need a specific placement independent of ASC/DESC.
