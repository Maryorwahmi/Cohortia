Comparison: ASC (default) vs DESC

ASC: Alphabetical A→Z, numeric low→high, older→newer. The keyword is optional but clear.

DESC: Reverse order: Z→A, high→low, newest→oldest. Use it to surface top values quickly.

Mixing: In multi-column sorts you can specify ASC or DESC for each column independently.

Concrete examples shown to the right illustrate typical uses for each direction.
Example Queries
-- Alphabetical by last name
SELECT employee_id, first_name, last_name, salary
FROM employees
ORDER BY last_name;  -- ASC by default

-- Highest paid first
SELECT employee_id, first_name, last_name, salary
FROM employees
ORDER BY salary DESC;
Common Mistake

Assuming DESC applies to all columns in a multi-column ORDER BY. Specify direction per column to avoid surprises.
