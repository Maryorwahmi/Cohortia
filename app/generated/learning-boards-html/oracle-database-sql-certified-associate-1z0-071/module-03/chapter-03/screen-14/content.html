Multi-Column Sort
Subsequent columns break ties in the exact order you list them; specify direction per column.
Alias Scope
Aliases are available to ORDER BY and GROUP BY but not to WHERE because of processing order.
NULL Placement
ASC places NULLs last by default; DESC places them first. Use NULLS FIRST or NULLS LAST to override.
Final Tip

Prefer explicit names and explicit NULL placement for maintainability. Re-run sorted queries after any SELECT list change to avoid unintended order shifts.
