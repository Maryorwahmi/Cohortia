Assessment snapshot
You will be given queries and asked to choose the correct pattern: a multiple-column IN, a correlated EXISTS, or an inline-view plus join. One task asks you to write a correlated subquery that finds the highest-paid employee per job.
Practical tip
When you see a condition that depends on an outer column, suspect correlation. When you can compute a summary once and reuse it, prefer an inline view and a join.
Mnemonic
Think "tuple match" for multiple columns and "per-row context" for correlated subqueries.
