Module 5 › Chapter 5.4 › Assessment prompt
Prompt
Write a query that returns department names for departments that have no employees. Explain why NOT EXISTS is appropriate and describe when a left join with a NULL filter might be preferred for performance.
Guidance
Include in your justification: NULL behavior, readability, and potential performance differences depending on indexing and optimizer behavior.
Solution (visual)
SELECT d.department_id, d.department_name
FROM departments d
WHERE NOT EXISTS (
  SELECT 1
  FROM employees e
  WHERE e.department_id = d.department_id
);

-- Alternatively: LEFT JOIN departments to employees and filter WHERE employee_id IS NULL
Reflection
Explain which approach you would choose in a large dataset and why. Consider NULLs, optimizer behavior, and available indexes in your justification.
