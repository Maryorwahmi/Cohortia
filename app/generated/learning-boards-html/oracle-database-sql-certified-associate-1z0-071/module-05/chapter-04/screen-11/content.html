Common mistakes and fixes
  • NOT IN + NULLs: Use NOT EXISTS to avoid null-related surprises.
  • Column count mismatch: Ensure outer tuple and subquery select lists match exactly.
  • Type mismatch: Confirm that corresponding positions are compatible or explicitly cast when safe.
  • Performance: Replace heavy per-row aggregates with inline views and joins when possible.

Quick checklist
Before you finalize a query: run the subquery, inspect columns and sample rows, verify no unexpected NULLs, and consider a grouped inline view if the inner computation repeats.
