Module 5 › Chapter 5.4 › Decision guide
Checklist
  1. Do you need to match multiple columns as a single unit? Use tuple IN.
  2. Does the inner logic need the outer row's value? Use a correlated subquery or EXISTS.
  3. Can the inner result be computed once and shared? Use an inline view and join.
  4. Are NULLs possible in absence checks? Prefer NOT EXISTS over NOT IN.
Scenario cards
Scenario: match job+salary
Use a multiple-column IN subquery to compare the pair directly.
Scenario: per-department average
Start with a correlated subquery; refactor to an inline view and join if performance concerns appear.
