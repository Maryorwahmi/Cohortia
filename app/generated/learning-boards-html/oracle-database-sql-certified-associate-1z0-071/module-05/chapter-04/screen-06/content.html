Module 5 › Chapter 5.4 › Correlated subquery
Concept explained
Correlation occurs when the inner query refers to an outer alias, such as e.department_id. That reference ties the subquery's execution to the current outer row, so the inner query computes results specific to that row's context.
Concrete example
To find employees who earn more than their departmental average, the inner query computes the average for the specific department of each outer row. This requires correlation: the inner WHERE clause uses e.department_id from the outer reference.
Visual example
-- Concept: compare salary to department average
SELECT e.employee_id, e.first_name, e.last_name, e.salary, e.department_id
FROM employees e
WHERE e.salary > (
  SELECT AVG(salary)
  FROM employees
  WHERE department_id = e.department_id
);
Takeaway

Use correlation when the inner computation must depend on a value from the outer row. Expect the inner query to run repeatedly for many outer rows.
