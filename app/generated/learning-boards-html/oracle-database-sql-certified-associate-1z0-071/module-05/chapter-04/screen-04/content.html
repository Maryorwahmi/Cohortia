Module 5 › Chapter 5.4 › Multiple-column subquery
Concept
Tuples let you compare multiple columns atomically. Instead of testing job equals X and salary equals Y separately, you test the pair (job, salary) against a set of pairs produced by the subquery. This simplifies logic when the combination matters.
Rules
  • Number of columns must match between outer tuple and subquery.
  • Corresponding positions must have compatible data types.
  • Tuple comparisons are commonly used with IN and NOT IN.
Concrete example
Find employees whose job and salary match any employee in department 80. The inner query returns job and salary pairs restricted to department 80, and the outer query compares each row's pair against that set.
Code (visual)
-- Find employees who have the same job and salary
-- as any employee in department 80.
SELECT employee_id, first_name, last_name, job_id, salary
FROM employees
WHERE (job_id, salary) IN (
  SELECT job_id, salary
  FROM employees
  WHERE department_id = 80
);
Takeaway

Use tuple comparisons when the relationship between columns forms the matching criteria. Verify column counts and type compatibility before running the query.
