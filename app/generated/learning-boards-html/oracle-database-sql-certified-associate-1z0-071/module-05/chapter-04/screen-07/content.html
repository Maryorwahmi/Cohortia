Module 5 › Chapter 5.4 › Correlated example
Step-by-step
  1. Outer query selects each employee row and assigns alias e.
  2. Inner query computes AVG(salary) but is filtered by e.department_id.
  3. For each outer row, the inner AVG is recalculated for that department.
  4. Outer WHERE keeps rows where e.salary is greater than that average.
Analogy
Think of each employee standing on a scale; for each person you ask a local expert for the average for that person's team. The expert's answer varies by team.
Query (visual)
SELECT e.employee_id, e.first_name, e.last_name, e.salary, e.department_id
FROM employees e
WHERE e.salary > (
  SELECT AVG(salary)
  FROM employees
  WHERE department_id = e.department_id
);
Performance hint
If many employees share the same department, computing averages once in an inline view and joining can avoid repeated work and often runs faster.
