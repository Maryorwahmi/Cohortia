Module 5 › Chapter 5.4 › Performance choice
When to refactor
  • If the inner computation is identical for many outer rows, compute it once in a grouped inline view.
  • Join the inline view to the outer table using the grouping key to compare per-row values.
  • Measure in your environment: data size, indexing, and optimizer behavior matter.
Inline view pattern
Compute department averages once and join to employees to avoid repeated AVG calls for each employee row.
Inline view alternative
SELECT e.employee_id, e.first_name, e.last_name, e.salary, e.department_id
FROM employees e
JOIN (
  SELECT department_id, AVG(salary) AS avg_dept_salary
  FROM employees
  GROUP BY department_id
) d_avg
ON e.department_id = d_avg.department_id
WHERE e.salary > d_avg.avg_dept_salary;
Misconception check
Refactoring to an inline view usually reduces repeated work, but only benchmark in your environment to confirm actual gains.
