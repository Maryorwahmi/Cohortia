Module 5 › Chapter 5.4 › Hands-on: highest-paid
Task steps
  1. Alias employees as e in the outer query and select identifying columns and salary.
  2. Write an inner subquery that computes MAX(salary) from employees aliased s where s.job_id = e.job_id.
  3. Compare e.salary to that inner result with equality to find the top earners per job.
  4. Optionally, rewrite using an inline view that groups by job_id and joins once.
Hint
If multiple employees share the max salary in a job, the correlated query will return all of them. That is usually the desired behavior.
Starter code
SELECT e.employee_id, e.first_name, e.last_name, e.job_id, e.salary
FROM employees e
WHERE e.salary = (
  SELECT MAX(s.salary)
  FROM employees s
  WHERE s.job_id = e.job_id
);
