Module 5 › Chapter 5.4 › Key Concepts
Multiple-Column
Compare tuples of columns; counts and types must match.
Correlated Subquery
References outer-row values and runs per outer row for context-specific results.
EXISTS / NOT EXISTS
Use for presence or absence checks; prefer NOT EXISTS over NOT IN when NULLs may occur.
Final takeaway

Write correct queries first, then consider readability, then optimize with inline views and joins when repeated inner computation hurts performance.
