Module 5 › Chapter 5.4 › Tuple rules
Checklist before you run
  • Count columns in the outer tuple and the subquery select list; they must match.
  • Confirm each corresponding column pair is type-compatible (for example, number to number, varchar to varchar).
  • Run the subquery alone to inspect returned columns and sample values.
  • Avoid NOT IN when the subquery may return NULLs; prefer NOT EXISTS.
Example mismatch
If outer tuple uses manager_id and location_id but the subquery selects employee_id and department_id, both the count and the types must align or the database will reject the query.
Visual example
-- Correct: two columns match two columns
WHERE (job_id, salary) IN (
  SELECT job_id, salary
  FROM employees
  WHERE department_id = 80
);

-- Incorrect example: unmatched counts or mismatched types will error
Pro tip
When in doubt, explicitly select column names rather than using wildcard selects inside tuple subqueries so you control order and types.
