Module 6 › Chapter 5.5 › Key Concepts
UNION
Combines results and removes duplicates. Use for distinct lists and reporting.
UNION ALL
Combines results and retains duplicates for raw counts and faster performance.
INTERSECT / MINUS
INTERSECT returns common rows; MINUS returns rows in the first set but not the second.
Remember the rules: matching column count and compatible types by position, and ORDER BY only at the end. Use parentheses to control complex expressions and test parts independently for predictable results.
