Module 6 › Chapter 5.5 › ORDER BY Placement
ORDER BY must sort the final combined result
Only one ORDER BY is allowed and it must come after the last set operator.
Correct pattern
Run SELECTs combined with set operators, then put ORDER BY clauses after the final operator to sort the final output.
SELECT first_name, last_name FROM employees
UNION
SELECT first_name, last_name FROM customers
ORDER BY first_name, last_name;
Incorrect pattern
Placing ORDER BY inside a SELECT that participates in a set operator will cause an error. Ordering must be applied once to the combined result.
Quick checks
  • Place ORDER BY after the last operator.
  • Use column names from the first SELECT to reference ordering columns.
  • Remember that ORDER BY happens after duplicate removal or retention.
Key Takeaway

Sort the final set once. This prevents syntax errors and ensures the sort reflects the combined rows.
