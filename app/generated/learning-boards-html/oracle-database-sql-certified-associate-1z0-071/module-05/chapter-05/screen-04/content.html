Module 6 › Chapter 5.5 › What are Set Operators?
Definition and core idea
Use SELECT outputs as sets and apply mathematical set operations.
Key claim: set operators compare entire rows by position and value. They are list-level tools rather than relational joins that match on keys.
Concrete example
Combine first names from Employees and Customers to get a single list or identify overlap.
Common misconception
Do not confuse set operators with joins. Set operators combine result rows, not relational columns by key.
Key Takeaway

Use set operators when you need to merge or compare whole lists of rows produced by SELECT statements, not for record-by-record joining.

Annotated example tables
Employees
first_name: Olivia, Liam, Emma, Noah
job_id: AD_PRES, IT_PROG, SA_REP
Customers
first_name: Emma, Ava, Liam, Mia
Analogy
Think of each SELECT as a shopping list; set operators let you merge lists, keep all items, or find common vs unique items.
