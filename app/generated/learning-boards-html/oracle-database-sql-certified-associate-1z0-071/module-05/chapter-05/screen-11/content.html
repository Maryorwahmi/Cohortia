Control order with parentheses
Group set expressions to determine which operations run first and to avoid ambiguity.
Example structure
(SELECT ... UNION SELECT ...) INTERSECT (SELECT ...)
Why it helps
Parentheses make intent explicit and keep evaluation predictable when combining different operators with different behaviors.
Pro tip
Test grouped parts independently before composing them. Use parentheses liberally for clarity.
Common pitfall
Assuming the same precedence as arithmetic. Set operators have their own evaluation rules and parentheses remove ambiguity. When mixing MINUS and INTERSECT you may get surprising results without grouping.
Check your results
Break complex expressions into temporary queries and inspect intermediate outputs to ensure the final composition matches your intent.
