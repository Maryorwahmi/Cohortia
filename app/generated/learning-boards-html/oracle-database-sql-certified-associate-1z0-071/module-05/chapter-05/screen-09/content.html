Module 6 › Chapter 5.5 › Rules for Set Operators
Two rules to validate
Always check column count and data type compatibility before combining SELECTs.
Rule 1: Column count
Each SELECT must list the same number of columns in the same order. Mismatches produce errors.
Rule 2: Type compatibility
The first column in each SELECT must be type-compatible with the first column of the others, and so on for each position.
Checklist
  • Count columns in each SELECT.
  • Compare types by position and cast if needed.
  • Confirm column order matches intent.
Example mismatch
Selecting first_name, last_name in one SELECT and only first_name in another will fail because column counts differ. If the first column is a date in one SELECT and text in another, type incompatibility may cause an error or implicit conversion issues.
Common mistake
Relying on column names rather than positions. The engine aligns by position, so order matters even when names differ.
