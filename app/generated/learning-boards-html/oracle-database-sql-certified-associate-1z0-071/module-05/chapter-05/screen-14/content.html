Module 6 › Chapter 5.5 › Hands-on Activity
Activity steps
Find job IDs in employees that are not in jobs using MINUS, then confirm valid IDs with INTERSECT.
  1. Select distinct job_id from employees.
  2. Select job_id from jobs.
  3. Run the first list MINUS the second list to get invalid IDs.
  4. Optionally run INTERSECT to see valid overlaps.
Starter queries (visual)
-- Step 1
SELECT DISTINCT job_id FROM employees;

-- Step 2
SELECT job_id FROM jobs;

-- Step 3: IDs in employees but not in jobs
SELECT DISTINCT job_id FROM employees
MINUS
SELECT job_id FROM jobs;

-- Extension: valid job IDs in both
SELECT DISTINCT job_id FROM employees
INTERSECT
SELECT job_id FROM jobs;
Why this helps
This workflow surfaces data inconsistencies and confirms which job IDs are valid in both systems, enabling targeted cleanup.
Troubleshooting tips
  • Ensure both SELECTs return the same column count—here, a single job_id column.
  • Verify data type compatibility and normalize casing or whitespace if values appear mismatched.
  • Run each SELECT separately to inspect raw values before combining.
Key Takeaway

MINUS is a concise way to find data differences and begin cleaning or reconciling reference data.
