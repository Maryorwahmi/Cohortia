MINUS — Subtract one result from another
Find rows in query A that are not present in query B, commonly used for validation.
Hands-on example
Step: select distinct job_id from employees, then MINUS select job_id from jobs to identify job IDs present in employees but missing from jobs.
Why this matters
Surface outdated or incorrect reference values so you can correct or reconcile them before reporting or enforcing constraints.
Starter SQL (visual)
SELECT DISTINCT job_id FROM employees
MINUS
SELECT job_id FROM jobs;
Checks and notes
  • MINUS removes duplicates in the final result, giving a distinct list of differences.
  • Matching is positional; ensure the SELECT lists align by columns and types.
  • In other SQL dialects the equivalent operator is called EXCEPT; in Oracle it's MINUS.
Common mistake
Forgetting to align column order or types can make MINUS invalid or return unexpected results; always check SELECT lists.
