UNION — Distinct merge
Combine multiple SELECTs and remove duplicates automatically.
Visual result
Employees: Olivia, Liam, Emma, Noah. Customers: Emma, Ava, Liam, Mia. UNION result: Olivia, Liam, Emma, Noah, Ava, Mia.
When to use
When you need a distinct combined list for reporting or selection controls where duplicates would confuse users.
Example SQL (visual)
SELECT first_name FROM employees
UNION
SELECT first_name FROM customers;
Notes and checks
  • UNION removes duplicates and may reduce total row count compared to the sum of inputs.
  • Column names in the final result come from the first SELECT.
  • ORDER BY must appear after the last SELECT to sort the final output.
Misconception
Do not assume UNION preserves duplicates or original ordering; it removes duplicates and leaves ordering undefined unless you sort the final result.
