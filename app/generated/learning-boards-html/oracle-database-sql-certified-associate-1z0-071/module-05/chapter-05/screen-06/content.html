Module 6 › Chapter 5.5 › UNION ALL
UNION ALL — Keep every row
Preserves duplicates so you can count or audit occurrences across sources.
Concrete example
Employees: Emma appears once. Customers: Emma appears once. UNION ALL result includes Emma twice, preserving both occurrences.
When to prefer
Performance-sensitive operations where duplicates are meaningful, such as counting or auditing raw inputs from multiple feeds.
Example SQL (visual)
SELECT first_name FROM employees
UNION ALL
SELECT first_name FROM customers;
Performance and caution
  • Faster than UNION because it skips duplicate elimination and sorting.
  • Results can include repeated rows from the same SELECT if the source contains duplicates.
  • Still requires the same column count and compatible data types.
Misuse risk
If duplicates are not desired, UNION ALL can produce incorrect summaries or mislead users; choose carefully.
