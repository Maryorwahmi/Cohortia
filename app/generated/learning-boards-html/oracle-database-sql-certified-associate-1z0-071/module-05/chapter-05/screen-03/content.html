Module 6 › Chapter 5.5 › Learning Objectives
Checkable skills
  • Same column count across SELECTs — test with a quick COUNT of columns.
  • Compatible data types by position — strings with strings, numbers with numbers.
  • ORDER BY only at the end of the combined query — avoid per-SELECT ordering.
Micro-examples
UNION returns distinct names from both tables.
UNION ALL returns all rows, helpful for counting duplicates.
MINUS finds job IDs in employees not present in jobs.
Verified Competency Milestone
Run a MINUS and an INTERSECT on job_id lists to surface invalid and valid IDs, and explain the difference in a short note.
