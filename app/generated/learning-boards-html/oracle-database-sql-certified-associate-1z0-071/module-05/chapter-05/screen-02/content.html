01 Combine results
Apply UNION and UNION ALL to merge two or more SELECT outputs. This matters when lists are separate but compatible and you need a single report.
Mnemonic: stacked lists -> single list
VERIFIED COMPETENCY MILESTONE
02 Duplicates and performance
Differentiate UNION, which removes duplicates, from UNION ALL, which retains duplicates and performs faster. This choice affects accuracy and runtime.
Visual hint: distinct vs all
VERIFIED COMPETENCY MILESTONE
03 INTERSECT and MINUS
Locate common rows with INTERSECT and find differences with MINUS to validate or clean data across tables.
Mnemonic: intersection vs subtraction
VERIFIED COMPETENCY MILESTONE
04 Rules and ORDER BY
Master the two rules for compatibility and the single ORDER BY placement at the end of the combined query to avoid errors.
Visual hint: two checks, one final sort
