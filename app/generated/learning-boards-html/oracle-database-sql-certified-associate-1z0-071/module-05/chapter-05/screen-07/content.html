INTERSECT — Common rows only
Get rows present in every SELECT used in the operation.
Concrete example
Employees and Customers both contain 'Liam' and 'Emma'; INTERSECT returns those names once each.
When to use
When you need to verify shared membership or confirm records are present in multiple lists.
Example SQL (visual)
SELECT first_name FROM employees
INTERSECT
SELECT first_name FROM customers;
Checks and caveats
  • INTERSECT removes duplicates — result is distinct common rows.
  • Matching is positional: select the same columns in the same order to compare correctly.
  • Consider applying DISTINCT inside SELECTs if source data contains duplicates you want to ignore before intersection.
Pro tip
Use INTERSECT to quickly validate which IDs or keys exist across systems before syncing or reporting.
