Module 05 › Chapter 5.2 › Single-Row Operators vs. Multiple-Row Alternatives
When to use

Single-row operators

  • Use =, >, <, >=, <=, or <> when the subquery returns one scalar value.
  • If the inner query may return multiple values, choose IN, ANY, or ALL instead.
  • Always inspect the subquery output shape before picking the operator.
Operator quick reference
IN
Match any value from a subquery result set. Use when subquery returns multiple rows to match one of them.
ANY
True if the comparison holds for at least one value returned by the subquery.
ALL
True only if the comparison holds for every value returned by the subquery.
Misconception
Using = with a multi-row subquery does not silently match one value; it raises ORA-01427.
