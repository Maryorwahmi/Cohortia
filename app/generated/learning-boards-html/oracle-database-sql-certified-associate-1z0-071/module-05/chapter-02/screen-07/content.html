Module 05 › Chapter 5.2 › ORA-01427 — Cause and Diagnosis
Error cause

Single-row subquery returned many rows

Oracle raises ORA-01427 when an outer comparison expects one value but the inner query produced multiple rows. This is a shape mismatch between the expected scalar and the actual result set.

Diagnosis steps:
  1. Run the subquery alone and count the rows returned.
  2. If multiple rows exist, decide whether to aggregate, filter, or switch operators.
  3. Test the adjusted subquery independently before embedding it.
Example that fails
SELECT employee_id, first_name, last_name
FROM employees
WHERE department_id = (
  SELECT department_id
  FROM employees
  WHERE last_name = 'King'
);
-- Error ORA-01427 if multiple 'King' rows return different department_ids
Fix options
Aggregate, add WHERE filters to make the result unique, or change the outer comparison to IN when multiple department IDs are expected.
