Module 05 › Chapter 5.2 › Data Type Compatibility
Concept

Match types for reliable comparisons

When comparing an outer column to a scalar from a subquery, the types should be compatible. If not, implicit conversions may take place or errors may occur. Use CAST or explicit selection of a numeric expression when needed.

Practical check
Run the inner query and inspect the result. Confirm the type aligns with the column used in the outer comparison.
Misconception
Assuming implicit conversion will always preserve the intended meaning of the value; it can introduce subtle bugs.
Example
If the outer column is NUMBER and the subquery selects a VARCHAR2 column, consider using CAST(subquery_result AS NUMBER) or selecting a numeric expression to guarantee compatibility.
Key Takeaway
Align types or convert explicitly in the subquery to ensure correct comparisons and avoid surprises.
