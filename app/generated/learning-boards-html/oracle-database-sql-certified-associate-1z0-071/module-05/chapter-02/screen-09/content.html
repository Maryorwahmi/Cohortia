Module 05 › Chapter 5.2 › Example: Employees Above Average Salary
Goal

Find employees earning above the company average

-- Step 1: Test the inner query independently
SELECT AVG(salary) FROM employees;

-- Step 2: Use it in the outer query
SELECT employee_id, first_name, last_name, salary
FROM employees
WHERE salary > (
  SELECT AVG(salary) FROM employees
);
Practical tip: run the inner query first to confirm it returns one numeric value. If it does, embed it and run the full query.
Explanation
  • The inner AVG computes a single scalar value representing the company average salary.
  • The outer WHERE compares each row's salary to that scalar and returns matching rows.
  • If the inner query returned multiple values, you would get ORA-01427; always test first.
Key Takeaway
Independent single-row subqueries are evaluated once and supply a reliable comparison value.
