Module 05 › Chapter 5.2 › Using Single-Row Subqueries in HAVING
Pattern

Compare group aggregates to a scalar

-- Find departments where dept average > avg for IT_PROG
SELECT department_id, AVG(salary) AS dept_avg_salary
FROM employees
GROUP BY department_id
HAVING AVG(salary) > (
  SELECT AVG(salary)
  FROM employees
  WHERE job_id = 'IT_PROG'
);
Why this works
The inner AVG returns a scalar reference; HAVING compares each group's aggregate to that reference to filter departments.
Key Takeaway
Validate the inner query returns one value and that group aggregates are computed correctly before comparison.
Common mistakes
  • Using non-aggregated columns in HAVING without grouping.
  • Assuming the inner subquery will collapse duplicates automatically.
  • Neglecting type compatibility between aggregates and the subquery result.
