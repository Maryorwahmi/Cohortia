Module 05 › Chapter 5.2 › Lab: Find the Employee(s) with the Highest Salary
Objective

Retrieve employee details for the highest salary

-- Step 1: Find the maximum salary
SELECT MAX(salary) FROM employees;

-- Step 2: Use it in the WHERE clause
SELECT employee_id, first_name, last_name, email, phone_number, salary
FROM employees
WHERE salary = (
  SELECT MAX(salary) FROM employees
);
Guidance
  • Run the inner MAX query to confirm a single scalar value.
  • Remember equals will return all employees who match that maximum salary.
  • If you need the next highest salary, consider filtering where salary < max and ordering desc with row-limiting techniques.
Key Takeaway
MAX combined with an equals comparison returns all top earners; test the inner query first to confirm the scalar.
