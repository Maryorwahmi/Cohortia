Module 05 › Chapter 5.2 › What to Remember
Shape

Confirm the subquery returns one row and one column when using single-row operators.

Operator

Use = > < etc. only with single scalars; use IN/ANY/ALL for sets.

Type

Ensure returned type matches the outer column or CAST explicitly.

Final Thought

Small checks early prevent ORA-01427 and other surprises. Test inner queries, validate types, pick the right operator, and consider performance for correlated scalars.
