Module 05 › Chapter 5.2 › What is a Single-Row Subquery?
Definition

Single-row subquery

An inner SELECT that returns one row and one column. Because it yields a scalar, it pairs with single-row comparison operators in the outer query.

When to use it
When an outer comparison depends on a single computed value like AVG or MAX.
Common misconception
Assuming multiple rows will be auto-reduced to one; Oracle will raise ORA-01427 instead.
Concrete example
-- Find all employees whose salary is greater than the company's average salary.
SELECT employee_id, first_name, last_name, salary
FROM employees
WHERE salary > (
    SELECT AVG(salary) FROM employees
);
Why it matters
You compute comparison values dynamically, keeping queries accurate as data changes.
Key Takeaway
Validate the inner query returns a single scalar before using single-row operators.
