Single-Row Subquery

Returns one row and one column and can be used with single-row comparison operators.

ORA-01427

Raised when a single-row comparison finds multiple rows; inspect and fix the inner query or operator.

Scalar Subquery

Used in SELECT lists to add contextual values per row; correlated forms may execute per outer row.

Summary Takeaway

Always test the inner query's result shape and type before using single-row operators, and choose IN/ANY/ALL or refine the subquery when multiple values are expected.
