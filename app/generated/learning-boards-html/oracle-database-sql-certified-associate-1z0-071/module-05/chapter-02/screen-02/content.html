Learning Objectives

Progress from building single-value subqueries to diagnosing errors and using scalar subqueries for richer output.

01
Construct and execute
Write SELECT statements where an inner query yields a single value used by an outer comparison. This skill lets queries depend on computed values like averages or maximums.
VERIFIED COMPETENCY MILESTONE
02
Use single-row operators
Apply =, >, <, >=, <=, and <> when a subquery produces one value. Correct operator selection prevents logic errors and unexpected results.
VERIFIED COMPETENCY MILESTONE
03
Diagnose ORA-01427
Recognize and fix the error triggered when a single-row subquery returns multiple rows. Run the subquery independently to inspect its rows and choose a safe operator.
VERIFIED COMPETENCY MILESTONE
04
Apply in WHERE, HAVING, SELECT
Place single-row subqueries in WHERE and HAVING as comparisons or in the SELECT list as scalar subqueries for contextual values per row.
VERIFIED COMPETENCY MILESTONE
