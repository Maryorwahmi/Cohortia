Module 5 › Chapter 5.1 › Multiple-row Subqueries
Operators
  • IN: membership in a returned list.
  • ANY: true if comparison holds for at least one returned value.
  • ALL: true only if comparison holds for all returned values.
Example use: WHERE department_id IN (SELECT department_id FROM departments WHERE location_id = ...)
Example & caution
-- Departments in Seattle, then employees in those departments
SELECT employee_id, first_name, last_name FROM employees
WHERE department_id IN (SELECT department_id FROM departments WHERE location_id = (SELECT location_id FROM locations WHERE city = 'Seattle'));
Caution: if the inner select that finds location_id could return multiple rows, the single-row placement would error. Consider using IN if multiple locations are possible.
Common error

ORA-01427 occurs when a single-row operator is used but the inner query produces multiple rows. Prevent by matching operator to result shape.
