Module 5 › Chapter 5.1 › Hands-on Activity
Steps
  1. Find the location_id for city = 'Seattle' by querying locations.
  2. Use that location_id to select department_id values from departments.
  3. Use the department_id list in the employees select with IN to list matching employees.
Remember to run each step alone to confirm the return shape and then nest them in order when you are confident.
Starter snippets
-- Step 1: location_id for Seattle
SELECT location_id FROM locations WHERE city = 'Seattle';
-- Step 2: departments at that location
SELECT department_id FROM departments WHERE location_id = (/*subquery from step 1*/);
-- Step 3: employees in those departments
SELECT employee_id, first_name, last_name, department_id FROM employees WHERE department_id IN (/*subquery from step 2*/);
Check

If any step may return multiple values use IN. If a step might return null, decide how to handle null comparisons to avoid unexpected exclusions.
