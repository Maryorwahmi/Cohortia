Module 5 › Chapter 5.1 › Types of Subqueries
Type definitions
  • Single-row: returns one row, one column. Use operators like =, >, <.
  • Multiple-row: returns multiple rows, one column. Use IN, ANY, ALL.
  • Multiple-column: returns one or more rows with multiple columns for composite comparisons.
  • Scalar: a single value used in SELECT or expressions.
Misconception: A single-row comparison will accept multiple values; it will not. The database enforces the shape of returned data.
Examples
-- single-row: returns AVG(salary) as one value
WHERE salary > (SELECT AVG(salary) FROM employees)
-- multiple-row: returns department ids
WHERE department_id IN (SELECT department_id FROM departments WHERE location_id = 1400)
The examples show how the operator must match the inner result. The second example demonstrates IN with potentially many department ids.
Pitfall

Using a single-row operator when the subquery produces multiple rows triggers ORA-01427. Always reason about possible row counts.
