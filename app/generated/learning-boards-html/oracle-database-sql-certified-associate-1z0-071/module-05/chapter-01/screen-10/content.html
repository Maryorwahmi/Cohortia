Module 5 › Chapter 5.1 › Correlated Subqueries
Concept

A correlated subquery refers to columns from the outer query, so it evaluates in the context of each outer row. This is useful when the inner calculation depends on that row.

-- Example idea: find employee_id and salary where salary =
-- the minimum salary for that employee's job_id (inner uses outer.job_id)
When to use
  • Per-row minima or maxima tied to the outer row.
  • Situations where expressing the relation as a join is awkward.
Performance note

Because the inner query may execute repeatedly, measure execution time and consider analytic functions or joins as alternatives when needed.
