Module 5 › Chapter 5.1 › Key Concepts — Quick Reference
Verify shape
Run the inner query alone to confirm rows and columns before nesting.
Choose placement
FROM for derived tables, WHERE for filters, SELECT for scalars, HAVING for groups.
Mind performance
Correlated subqueries may execute per row; test and consider joins or analytic functions.
Reflection
Next time you need an intermediate value or set, ask: can a subquery express this simply and safely? If so, build it stepwise and test inner results first.
