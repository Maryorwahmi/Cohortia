Module 5 › Chapter 5.1 › Key Concepts
Subquery runs first
The inner query supplies values or a temporary relation for the outer query to use.
Match operator to output
Single-row vs multiple-row vs multiple-column determines valid operators and semantics.
Placement matters
Use WHERE for filters, FROM for inline views, SELECT for scalar computations, HAVING for group filters.
Summary
Design subqueries with the result shape and placement in mind, test inner queries separately, and measure performance when correlated or large result sets are involved.
