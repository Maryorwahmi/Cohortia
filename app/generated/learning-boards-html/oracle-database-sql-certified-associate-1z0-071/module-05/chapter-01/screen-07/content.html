Module 5 › Chapter 5.1 › Single-row Subquery Example
Query
SELECT employee_id, first_name, last_name, salary
FROM employees
WHERE salary > (SELECT AVG(salary) FROM employees);
Step 1: run the inner select alone to confirm it returns a single numeric value. Step 2: confirm the outer WHERE comparison is valid against that scalar. Step 3: consider nulls and type compatibility.
Explanation
  • Inner query computes AVG(salary) across all rows and returns one value.
  • Outer query evaluates salary > that scalar for each employee row.
  • Verify the inner result is not multi-row; otherwise an error occurs.
