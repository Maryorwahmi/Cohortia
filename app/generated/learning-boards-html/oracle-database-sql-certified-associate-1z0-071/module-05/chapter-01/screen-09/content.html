Module 5 › Chapter 5.1 › Inline Views
Pattern
SELECT department_id, avg_dept_salary
FROM (SELECT department_id, AVG(salary) AS avg_dept_salary FROM employees GROUP BY department_id)
WHERE avg_dept_salary > 7000;
Here the inner subquery computes a summary table with department and average salary. The outer query filters those summary rows. The inline view is a clear separation of aggregation from filtering.
Why use it
  • Encapsulates complex grouping and calculations.
  • Gives a clear name to derived columns for outer processing.
  • Makes queries easier to read and maintain.
Pro tip

When performance matters, compare plans for the inline view and an equivalent join; the optimizer may pick different strategies.
