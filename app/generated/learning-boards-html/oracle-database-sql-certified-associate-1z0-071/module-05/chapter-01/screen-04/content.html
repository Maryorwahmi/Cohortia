Module 5 › Chapter 5.1 › What is a Subquery?
Definition
A select used inside another SQL statement

The inner select runs first and supplies a value, a list of values, or a temporary table to the outer statement. This lets you write concise queries that would otherwise require multiple steps.

Key property: execution order matters — the inner query must complete before the outer query can evaluate conditions that depend on it.
Misconception check: a subquery is not always isolated. If it references outer columns, it is correlated and may run repeatedly.
Concrete example
-- Find employees who earn more than the average salary
SELECT employee_id, first_name, last_name, salary
FROM employees
WHERE salary > (SELECT AVG(salary) FROM employees);
This single-row subquery returns one scalar value — the average salary — and the outer query uses it immediately. The result is compact and easy to reason about.
Key Takeaway

Use a subquery when you need an intermediate computed value or set that the outer query can consume immediately.
