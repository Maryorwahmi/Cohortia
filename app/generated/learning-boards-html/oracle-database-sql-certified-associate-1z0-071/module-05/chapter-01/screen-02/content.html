Module 5 › Chapter 5.1 › Learning Objectives
01
Explain subquery purpose
Define why an inner select is useful as a data supplier for an outer statement.
Mnemonic: think of a data assistant that fetches a value before the main query continues. VERIFIED COMPETENCY MILESTONE
02
Identify subquery types
Single-row, multiple-row, multiple-column, scalar, and inline view distinctions.
Mnemonic: size and shape — rows and columns determine operators. VERIFIED COMPETENCY MILESTONE
03
Describe subquery placement
Know when to use WHERE, FROM, HAVING, or SELECT list subqueries.
Mnemonic: clause map — WHERE filters, FROM becomes an inline view, SELECT returns scalar values. VERIFIED COMPETENCY MILESTONE
04
Understand execution order
Inner query executes first; correlated subqueries may execute per outer row.
Mnemonic: in-before-out. VERIFIED COMPETENCY MILESTONE
