Multiple-Row Subqueries

Compare single values against lists using IN, NOT IN, ANY, and ALL. Practical nested queries and NULL handling are emphasized.

Explore Key Topics
IN membership
Match a column against a returned list of values for clear set filtering.
NULL with NOT IN
A single NULL in the subquery can make NOT IN return no rows; always filter NULLs.
ANY vs ALL
ANY finds values matching at least one element; ALL requires matching every element in the set.
Visual Example
Chained subqueries (concept)
SELECT employee_id, first_name, last_name, department_id
FROM employees
WHERE department_id IN (
  SELECT department_id
  FROM departments
  WHERE location_id IN (
    SELECT location_id
    FROM locations
    WHERE city IN ('London','Oxford')
  )
);
This nested query shows how results flow from locations to departments to employees, selecting employees in specified cities.
Key Takeaway

Choose the operator that matches the required truth condition and guard against NULLs in exclusion queries.
