Skills Checklist

Concrete safety steps to make your multiple-row subqueries reliable.

Run subqueries standalone
Confirm returned rows and detect NULLs before embedding.
Filter NULLs for NOT IN
Add WHERE column IS NOT NULL to subqueries used with NOT IN.
Match data types
Ensure the outer column and subquery column are compatible to avoid implicit conversions.
Mnemonic
Test → Filter → Embed — always confirm results before excluding with NOT IN.
