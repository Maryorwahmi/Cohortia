Module 5›Chapter 5.3›What to Remember
1. Use IN for membership
Clear and idiomatic for equality checks against a set.
2. Guard NOT IN
Filter NULLs or prefer NOT EXISTS to avoid UNKNOWN results.
3. ANY / ALL
Use for relative thresholds; ANY = at least one, ALL = every value.
Final takeaway
Translate requirements to set semantics, validate returned sets, and pick the operator that matches the quantifier.
