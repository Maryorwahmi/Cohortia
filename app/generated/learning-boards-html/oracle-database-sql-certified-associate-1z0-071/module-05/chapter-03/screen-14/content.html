Multiple-Row Subquery
Returns one or more rows and requires set-aware operators.
IN / NOT IN
IN checks membership; NOT IN excludes but must handle NULLs explicitly.
ANY / ALL
ANY = at least one match; ALL = every value must match.
Summary takeaway
Choose the operator that matches the quantifier in the business question and validate subquery outputs for NULLs and empty sets.
