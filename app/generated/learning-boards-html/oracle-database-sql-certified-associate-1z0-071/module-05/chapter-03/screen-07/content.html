Module 5›Chapter 5.3›ANY Operator Explained
Definition

ANY = at least one match

Use with single-row operators like >ANY or =ANY to require a match with at least one inner value.

Misconception
ANY does not compare to every value; it needs only one true comparison.
Example
SELECT employee_id, first_name, last_name, salary
FROM employees
WHERE salary > ANY (
  SELECT salary FROM employees WHERE job_id = 'IT_PROG'
);

-- With IT_PROG salaries of 6000,7000,8000 this matches salary > 6000
Think of >ANY as 'greater than the minimum of the returned set' in practical terms. Use it to express relative thresholds.
Key Takeaway

Use ANY when you mean 'compare to at least one value' — it simplifies threshold logic against sets.
