Troubleshooting

Common mistakes

  • Not filtering NULLs for NOT IN causing UNKNOWN results.
  • Mismatched data types between outer and inner columns.
  • Misreading ANY/ALL quantifiers leading to incorrect comparisons.
  • Not testing subqueries separately and missing empty-set semantics.
Best practice
Validate subquery output and filter NULLs when excluding.
Performance
Compare nested subqueries with joins when optimizing queries on large tables.
