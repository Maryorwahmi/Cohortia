Assessment heuristic

Translate intent to operator

"At least one"
Use ANY with relational operators.
"All"
Use ALL to require every value to satisfy the comparison.
"Membership"
Use IN for equality membership checks.
Key Takeaway

Turn the English quantifier into a SQL quantifier, and verify NULL handling when excluding.
