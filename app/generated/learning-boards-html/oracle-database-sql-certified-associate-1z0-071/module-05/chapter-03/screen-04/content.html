Module 5›Chapter 5.3›What is a Multiple-Row Subquery?
Core definition

Multiple-row subquery

A query that returns one or more rows, typically a single column used for set comparisons.

Why it matters
It lets you filter outer queries based on dynamic sets from related tables without joins in some situations.
Common misconception
Order in the subquery does not affect membership tests; think in sets, not sequences.
Example — membership
-- Find employees in departments located in London or Oxford
SELECT employee_id, first_name, last_name, department_id
FROM employees
WHERE department_id IN (
  SELECT department_id
  FROM departments
  WHERE location_id IN (
    SELECT location_id
    FROM locations
    WHERE city IN ('London', 'Oxford')
  )
);
Run the inner queries alone to verify returned department_ids before embedding them. That reduces errors and clarifies results.
Key Takeaway

Treat the subquery result as a set. Verify its values and types before using IN, NOT IN, ANY, or ALL.
