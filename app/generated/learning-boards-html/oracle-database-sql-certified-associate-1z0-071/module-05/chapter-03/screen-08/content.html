Module 5›Chapter 5.3›ALL Operator Explained
Definition

ALL = every value must match

Use with >ALL or

Edge case
ALL with an empty set is vacuously true. Verify that the subquery returns rows when this semantics matters.
Example
SELECT employee_id, first_name, last_name, salary
FROM employees
WHERE salary > ALL (
  SELECT salary FROM employees WHERE job_id = 'IT_PROG'
);

-- Matches salaries greater than the highest IT_PROG salary
Use ALL when you need strict superiority over an entire reference set. Test the subquery to avoid surprises with empty results.
Key Takeaway

ALL enforces a condition across every returned value; it is a strict comparison often equivalent to comparing against MAX or MIN.
