Tool Demo
reaver & pixiewps (lab only)
Observe how tools probe and how APs respond; use the outputs to tune defenses.
sudo reaver -i wlan0mon -b <target_AP_BSSID> -vv

# If pixiewps is applicable, it analyzes captured handshake material to speed recovery
sudo pixiewps -e <handshake_capture>
In your lab log, record duration, number of attempts, and whether the AP enforced lockouts. Those data points directly inform whether WPS is a viable attack in the field and how urgent the remediation is.
Admin action list
  • Disable WPS across managed APs.
  • Patch AP firmware to remove WPS or to introduce strong lockouts.
  • Create monitoring alerts for WPS negotiation attempts and rate-limit thresholds.
Key Takeaway
Tool outputs in a lab reveal whether WPS is exploitable; use that evidence to mandate configuration changes or firmware upgrades.
