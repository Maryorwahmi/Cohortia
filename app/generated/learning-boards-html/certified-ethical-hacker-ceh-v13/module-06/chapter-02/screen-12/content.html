Activity: Discover with airodump-ng
A reproducible lab sequence for inventory and hidden SSID discovery.
  1. Put your wireless adapter into monitor mode and confirm the monitor interface name.
  2. Run an initial airodump-ng scan and note BSSID, CH, ENC, and any <length: 0> ESSIDs.
  3. Observe station probe behavior and identify clients that may reveal hidden SSIDs.
  4. Restart airodump-ng targeting the discovered BSSID and channel and write output to a capture file.
  5. Collect frames until ESSIDs or handshakes appear; document everything and stop the capture when done.
Documentation
Record interface names, commands used, capture filenames, timestamps, and observed ESSIDs and clients for auditing and repeatability.
Key Takeaway

A careful, documented workflow increases capture quality and ensures your reconnaissance is useful and authorized.

Starter commands (visual)
# Start monitor mode (visual)
sudo airmon-ng start wlan0
# Scan to discover targets
sudo airodump-ng wlan0mon
# Focus on an AP and save capture
sudo airodump-ng --bssid 00:11:22:33:44:55 -c 6 -w target_capture wlan0mon
# Stop capture after you have required frames (Ctrl+C) and exit monitor mode when finished
Use these commands as a template. Replace interface, BSSID, channel, and file name with values you observed and only run active steps when authorized.
