Focused capture workflow
Identify target BSSID and channel and save the capture for offline analysis.
When to use it
Use focused capture after an initial scan finds a promising AP with active clients or traffic volume to capture handshakes or probe exchanges.
Why save captures
Saved packet files are essential for offline analysis, repeatable workflows, and later authorized cracking or forensics.
Key Takeaway

Capture only the traffic you need by filtering channel and BSSID and use the write option to preserve it for later analysis.

Example command (visual only)
# Example workflow (assume monitor interface is wlan0mon)
# Scan to identify the target BSSID and channel
sudo airodump-ng wlan0mon

# Focus on a specific AP and channel, saving output to files named target_capture
sudo airodump-ng --bssid 00:11:22:33:44:55 -c 6 -w target_capture wlan0mon

# Output will produce target_capture-01.cap for later analysis
The visual command shows how to narrow the capture to a single AP and persist the results. Replace the BSSID and channel with values observed in your initial scan.
