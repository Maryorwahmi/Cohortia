Prepare your adapter
Checklist to avoid common reconnaissance setup failures.
  • Start the adapter in monitor mode and confirm the monitor interface name.
  • Stop or adjust network-managing services that can reclaim the radio or change channels.
  • Verify channel stability when focusing captures to avoid missing target frames.
  • Allow adequate capture time; some frames only appear when clients move or reconnect.
Practical tip
If packet counts are low, reposition or move closer to the target AP or client to improve PWR before capturing long enough to obtain handshakes.
Common Mistake

Not stopping conflicting services or assuming the adapter is in monitor mode when it remains in managed mode.

Setup visual checklist
Start monitor mode
Confirm interface name (e.g., wlan0mon)
Stop network managers
Test airodump-ng shows channel and APs
Key Takeaway

A correct and stable monitor setup ensures reliable captures and avoids wasted time and corrupted files.
