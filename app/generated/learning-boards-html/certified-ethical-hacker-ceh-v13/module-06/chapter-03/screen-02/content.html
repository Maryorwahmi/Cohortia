Learning Objectives
Four measurable skills you will practice and verify in this chapter.
01
Explain WEP vulnerabilities
You will describe IV reuse and the small IV space, and why these allow statistical key recovery. This matters because it connects protocol design to exploitability.
Venn: design weakness → easy exploitation
Verified Competency Milestone
02
Execute WEP cracking
You will run monitor mode, capture IVs, perform ARP replay, and run aircrack-ng to recover a WEP key in a lab. This is practical mastery of tool workflows.
Timeline: setup → capture → inject → crack
Verified Competency Milestone
03
Capture WPA/WPA2 handshakes
You will capture the four-way handshake and confirm its completeness for an offline attack. This skill separates capture errors from cracking limitations.
Mnemonic: check for 'WPA Handshake' indicator
Verified Competency Milestone
04
Run offline dictionary attacks
You will perform an offline wordlist attack against a captured handshake and learn why PSK entropy is decisive. This informs secure key policies.
Visual: strength spectrum
Verified Competency Milestone
