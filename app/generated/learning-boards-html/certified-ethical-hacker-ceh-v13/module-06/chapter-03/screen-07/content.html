Definition
Capturing IVs and cracking WEP
Measure #Data and IVs, then run aircrack-ng when thresholds are met.
Checkpoints
  • Confirm the capture file is growing and shows the target BSSID.
  • Watch the #Data column; tens of thousands of IVs are commonly required.
  • Only run aircrack-ng once IV accumulation is sufficient.
Example command
sudo aircrack-ng wep_capture-01.cap
# aircrack-ng will display progress and, on success, the recovered WEP key
If cracking fails, re-check IV counts, confirm injection, and re-run capture until thresholds are reached. Patience and correct measurement are the keys.
