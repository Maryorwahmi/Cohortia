Offline dictionary attack
Run aircrack-ng with a wordlist against the captured handshake file to test candidate PSKs offline.
Example command
sudo aircrack-ng -w /usr/share/wordlists/rockyou.txt wpa_capture-01.cap
# aircrack-ng will try each candidate and report when it finds the PSK
Practical notes
  • Use focused custom wordlists for lab keys to speed testing.
  • GPU or hashcat-style tooling can significantly accelerate brute force, but are beyond this chapter.
  • If aircrack-ng fails, the PSK likely isn’t in the wordlist or is too complex to find within reasonable time.
