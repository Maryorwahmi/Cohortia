Learning Objectives

Bloom progression: Learn → Understand → Apply → Master

Learn → Understand → Apply → Master
01
Differentiate service models
Identify IaaS, PaaS, SaaS differences and why security tasks move between provider and customer. VERIFIED COMPETENCY MILESTONE
02
Compare deployment models
Explain public, private, and hybrid deployment trade-offs and their impact on configuration responsibility. VERIFIED COMPETENCY MILESTONE
03
Explain Shared Responsibility
Map which security layers a provider secures and which layers the customer must secure during assessments. VERIFIED COMPETENCY MILESTONE
04
Identify cloud attack vectors
Detect IAM weaknesses, misconfigurations, exposed APIs, and logging gaps that lead to breaches. VERIFIED COMPETENCY MILESTONE
Mnemonic
Use the acronym SIPL — Service model, Identity, Policies, Logging — to remember assessment priorities.
Quick checklist
  • Classify resource model (IaaS/PaaS/SaaS)
  • Review IAM policies and MFA
  • Inspect public storage and network rules
  • Verify logging and monitoring presence
