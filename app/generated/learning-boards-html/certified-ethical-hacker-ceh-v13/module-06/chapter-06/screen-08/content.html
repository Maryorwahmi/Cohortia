Module 6 › Chapter 6.6 › Network Security Groups
Definition

Security groups and firewalls

These rules control traffic to cloud resources. Unrestricted inbound rules are a frequent and high-risk misconfiguration.

Checklist
  • Find rules with source 0.0.0.0/0 or equivalent
  • Confirm whether remote admin ports should be public
  • Check if DB instances are publicly reachable
Example
SSH opened to the internet
If SSH is open broadly, attackers can attempt credential-based logins or exploit unpatched services. Recommended remediations include limiting source IPs, requiring a bastion host, and enabling host-level MFA or two-step authentication.
Misconception
Assuming internet-facing services are harmless if they use credentials. Internet exposure multiplies attack surface and should be minimized.
Key Takeaway

Audit all inbound rules; require operational justification for public access and prefer private subnets and bastion patterns.
