Module 6 › Chapter 6.6 › Insecure APIs
Process

Assessing API risk

  1. Search for embedded keys or tokens in repos and configs.
  2. Check token scope and rotation policy.
  3. Attempt safe enumeration to validate permissions.
Example
Leaked key in code
If a key in a public repo permits listing buckets, an attacker can discover sensitive storage. Recommend rotating keys immediately and restricting token scopes to minimum privileges.
Misconception
Assuming network protections alone secure APIs. API authentication and least-privilege tokens are core defenses and should be audited.
Key Takeaway

Treat API credentials as highly sensitive; locate, describe the impact, and advise rotation and scope reduction when found.
