Module 6 › Chapter 6.6 › Shared Responsibility Model
Definition

Security of the cloud vs. security in the cloud

Provider secures infrastructure; customer secures what they deploy on it. Use this to scope tests and assign remediation responsibility.

Provider responsibilities
Physical security, host infrastructure, and hypervisor integrity.
Customer responsibilities
OS patching, application security, network rules, IAM, and data protection.
Practice
Ownership mapping exercise
For any resource, label who controls the OS, patching, network access, encryption, identity, and logging. Use that map to prioritize customer-controlled findings.
Misconception
Assuming provider handles all security. In IaaS especially, customers manage crucial layers like the OS and application stack.
Key Takeaway

Always map resource ownership first. That map prevents testing blind spots and misattributed blame for findings.
