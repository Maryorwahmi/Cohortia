Module 7 › Chapter 6.7 › IAM Lab
Objective
Enumerate IAM policies using read-only commands

Use a lab account with read-only credentials. Capture policy documents and flag wildcards in actions or resources.

Commands (read-only)
# Configure CLI with lab read-only credentials
aws configure

# List IAM users
aws iam list-users

# List managed policies attached to a user
aws iam list-attached-user-policies --user-name my-test-user

# Get an inline policy for a user
aws iam get-user-policy --user-name my-test-user --policy-name my-inline-policy

# Retrieve a managed policy document (sanitized)
aws iam get-policy-version --policy-arn arn:aws:iam::123456789012:policy/my-policy-name --version-id v1
Common Pitfall
Do not run destructive commands in the lab that change policies. Your goal is enumeration and analysis only unless the SOW explicitly allows modifications.
Analyzing a policy document
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "*",
      "Resource": "*"
    }
  ]
}
This sanitized policy shows a wildcard action and resource. Flag it as critical and recommend replacing wildcards with least-privilege actions and resources.
Verification
After remediation, rerun the same read-only commands to confirm that wildcard actions and permissive resources were removed and that role trust policies are tightened.
