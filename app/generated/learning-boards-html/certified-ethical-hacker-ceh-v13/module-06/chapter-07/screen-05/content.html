Definition

External reconnaissance & OSINT

Identify public endpoints, domains, and storage that reveal the cloud footprint without credentials.

Practical commands and checks
# DNS enumeration (example)
nslookup target.example.com

# Search for public S3 buckets pattern
curl -I https://my-target-bucket.s3.amazonaws.com

# Use Shodan-like queries to find exposed services
# Use web headers and certificate transparency logs to find cloud assets
Concrete example
A discovered subdomain returned an S3 endpoint header. That pointed to a public bucket containing a config file listing database endpoints. Record and report this evidence rather than downloading or changing files.
Common mistake
Treating cloud endpoints like normal hosts may miss storage patterns or API-only exposure. Look for provider-specific naming and headers.
Checklist
  • Collect domains and certificates
  • Probe for provider-specific endpoints
  • Index public buckets and storage endpoints
  • Log evidence for reporting
Key Takeaway

External recon finds the public surface. Document identifiers and avoid any authenticated probing without explicit permission.
