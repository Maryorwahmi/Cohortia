Terminal Walkthrough — Enabling Monitor Mode

Run these commands in sequence to prepare your adapter and verify Mode:Monitor.

# Identify your wireless adapter
lsusb

# Identify wireless interface
iwconfig

# Stop interfering services
sudo systemctl stop network-manager
sudo systemctl stop wpa_supplicant

# Put the interface into monitor mode
sudo airmon-ng start wlan0

# Verify monitor mode
iwconfig
Concrete result
After airmon-ng, interface may be renamed wlan0mon. iwconfig will show Mode:Monitor when successful.
Common mistake
Not running the commands in a privileged shell or forgetting to stop network services prevents monitor mode activation.
Key Takeaway

Follow the sequence and verify the interface state before attempting captures to avoid incomplete data.
