Module 6 › Chapter 6.1 › Monitor Mode
Definition

Monitor Mode

A passive state that lets an adapter capture all frames on a channel for analysis and handshake collection.

Concrete example
Enable monitor mode and capture a WPA2 four‑way handshake when a client reconnects; use that capture for later offline analysis.
Common mistake
Forgetting to stop interfering services like network-manager or assuming monitor mode implies packet injection support.
Key takeaway
Always confirm both monitor mode and injection before planning capture-based attacks.
Visual — Mode contrast
Managed Mode
Adapter connects to AP and exchanges frames addressed to it.
Monitor Mode
Adapter sees all frames on the channel for analysis.
Pro tip
Test adapter capabilities right after enabling monitor mode so you do not waste time with incompatible hardware.
