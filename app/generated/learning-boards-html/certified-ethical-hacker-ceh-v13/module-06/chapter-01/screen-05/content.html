Comparison

WEP • WPA • WPA2 • WPA3

WEP
RC4, 24‑bit IV reuse. Easy key recovery by capturing IVs.
WPA
TKIP for dynamic keys but still RC4‑based; transitional and still vulnerable in places.
WPA2
AES‑CCMP provides strong encryption; modes: PSK and Enterprise (802.1X + RADIUS).
WPA3
SAE for stronger key establishment and OWE for open network privacy.
Example
WEP: capture IVs and run a statistical attack to recover a key in minutes with common tools.
Misconception
Assuming WPA2 implies secure configuration—weak PSKs and RADIUS misconfigurations are common failure points.
Action
Determine protocol and mode first, then choose whether to test key recovery, credential capture, or configuration checks.
