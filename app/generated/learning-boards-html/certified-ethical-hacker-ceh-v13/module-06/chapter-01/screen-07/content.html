Preparing Kali Linux for Wireless Testing

A concise, reproducible checklist to confirm adapter and services before testing.

Step 1 — Confirm adapter
Run lsusb to confirm the USB adapter is recognized by the host or VM.
Step 2 — Identify interface
Run iwconfig to find the interface name such as wlan0 before changing modes.
Step 3 — Stop services
Stop network-manager and wpa_supplicant to prevent interference.
Step 4 — Enable monitor mode
Use airmon-ng start and verify Mode:Monitor with iwconfig.
Step 5 — Test injection
Run aireplay-ng -9 to test packet injection capability if you have permission.
Tip
If using a VM, pass the USB adapter through and confirm lsusb inside the VM to avoid invisible hardware.
Common mistake
Assuming monitor mode will work without stopping network management services; they commonly reclaim the adapter.
Key takeaway
Verify hardware and software interaction early so time is spent on analysis, not troubleshooting.
