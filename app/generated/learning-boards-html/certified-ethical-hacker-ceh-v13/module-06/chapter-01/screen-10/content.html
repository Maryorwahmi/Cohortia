Core Concept

WPA2 — PSK vs Enterprise

Authentication mode determines attacker focus and test plans for an assessment.

PSK (Personal)
Single shared passphrase. Four‑way handshake capture can enable offline cracking against weak passphrases.
Enterprise (802.1X)
Individual authentication via RADIUS or similar. Attacks target credential systems or misconfigurations rather than the PSK.
Example
On a PSK network a captured handshake can be tested offline against a password list; on Enterprise, examine RADIUS logs and EAP configuration for weaknesses.
Common mistake
Assuming Enterprise removes all risk—weak user credentials and server misconfigurations are still exploitable.
Key takeaway

Identify the authentication mode early and align your assessment to either PSK cracking paths or Enterprise credential and server checks.
