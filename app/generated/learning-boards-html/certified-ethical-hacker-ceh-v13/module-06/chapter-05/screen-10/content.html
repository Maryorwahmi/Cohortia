Module 6 › Chapter 6.5 › API Testing
Safe API checks
Prefer GET requests and vary identifiers to test for IDOR without changing device state.
Example read-only request
curl -i -X GET 'https://api.example.com/api/v1/devices/123/status' -H 'Authorization: Bearer '
Change the device identifier to see if authorization prevents viewing another device's status.
Record the exact requests, response codes, and any differences. If you can access other devices by changing identifiers, document the vulnerability and recommend server-side ownership checks and stronger authentication.
Misconception
Client-side checks are not enough. Always verify server-enforced authorization because clients can be bypassed or tampered with.
