Module 6 › Chapter 6.5 › MQTT Risks
How MQTT works
Publishers send messages to a broker; subscribers receive messages by topic. Authorization is enforced at the broker when configured correctly.
Safe verification pattern
mosquitto_sub -h  -p 1883 -t 'home/status'# subscribe read-only
mosquitto_pub -h  -p 1883 -t 'test/safe' -m 'ping'# benign publish
Use read-only subscriptions and benign test topics; avoid commands that alter device operation.
If anonymous access is allowed, an attacker could subscribe to topic namespaces to monitor devices or publish commands that change state. When reporting, recommend enabling broker authentication, TLS, and topic-level access control to separate telemetry from control channels.
Key Takeaway

Treat misconfigured brokers as high priority: they grant broad influence over connected devices.
