Core Concept Website & System Intelligence
What to collect
  • Web server and framework versions.
  • Directory listings, robots.txt, hidden files.
  • Document metadata revealing tools or authors.
  • Service banners and response behavior.
Example checks
Non-destructive checks include safe version verification and reviewing public error pages for stack traces. Avoid automated exploit attempts unless explicit permission is granted.
Misconception
Banner strings are always accurate. Cross-verify with headers, behaviors, and corroborating evidence.
Key Takeaway

Combine multiple indicators to confirm technologies and plan safe, relevant tests.
