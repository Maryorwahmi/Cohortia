Definition DNS & IP discovery
Key DNS records to check
  • A / AAAA: maps names to IP addresses.
  • MX: mail exchange servers — may indicate provider relationships.
  • NS: authoritative name servers for where DNS is controlled.
  • TXT: verification or configuration data that can be revealing.
Example
An MX record pointing to a third-party mail provider suggests you should include that provider in your reporting and confirm whether it is in-scope for scanning.
Misconception
Assuming DNS reveals all active hosts. Some services sit behind CDNs or use dynamic IPs; corroborate with additional evidence.
Key Takeaway

Treat DNS and IPs as primary leads that must be corroborated and annotated with third-party context.
