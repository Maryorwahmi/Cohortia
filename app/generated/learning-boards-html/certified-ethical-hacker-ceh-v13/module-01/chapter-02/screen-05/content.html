Process Flow Passive Reconnaissance
Passive techniques and sources
Search engines
Press releases, cached pages, file leaks.
WHOIS & DNS
Registrar, name servers, MX and A records.
Social media
Employee roles, org structure, email formats.
Archives & metadata
Document properties, historical site snapshots.
Example scenario
You find an archived page listing subdomains and a WHOIS contact that matches an employee on LinkedIn; combined, these increase confidence for assigning an IP block to the target.
Common-mistake
Treating a single passive source as definitive. Always corroborate with at least one other independent source.
Key Takeaway

Passive recon yields safe, abundant leads — corroborate sources and timestamp your evidence.
