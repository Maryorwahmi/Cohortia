Definition Types of information
Network
IPs, domains, DNS, topology
System
OS versions, open ports, services
Organizational
Employees, roles, contact formats
Website
Tech stack, directories, metadata
Third-party
Vendors, cloud providers, partners
Explanation
  • Network facts focus scanning and limit blast radius.
  • System facts suggest specific checks or known CVEs.
  • Organizational facts enable contextual risk prioritization.
  • Website facts guide web application assessments and content discovery.
  • Third-party facts expose indirect pathways and shared infrastructure.
Key Takeaway

A balanced collection across these categories yields a useful, actionable profile.
