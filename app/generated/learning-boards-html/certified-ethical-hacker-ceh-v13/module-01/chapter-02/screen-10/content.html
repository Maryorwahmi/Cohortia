Hands-on Activity Passive vs Active
Scenario cards
Scenario 1
Search public press releases and directories via a search engine.
Type: Passive. Reason: Uses indexed public content without touching the target's systems.
Scenario 2
Use nmap to scan a public IP range for open ports.
Type: Active. Reason: Sends probes that the target can detect and log.
Scenario 3
Review company LinkedIn to identify key employees.
Type: Passive. Reason: Viewing public profiles does not interact with the target's infrastructure.
Scenario 4
Send ICMP pings to a range of addresses to find live hosts.
Type: Active. Reason: Direct network traffic elicits a response and can be logged.
Reasoning checklist
  1. Ask if the action sends packets to the target that could be logged.
  2. Check whether the data comes from public archives or the target itself.
  3. If active, verify written RoE and scope limits before proceeding.
  4. Record source, timestamp, and confidence for every finding.
Key Takeaway

Classify techniques by their interaction with target systems and use a simple pre-scan checklist to avoid scope errors.
