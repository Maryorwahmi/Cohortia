Code Walkthrough
A safe progression of nmap usage in an authorized test.
nmap -sn 192.168.1.0/24        # Host discovery
nmap -p 1-1024 target.com       # Scan common ports
nmap -sS -p 22,80 target.com    # SYN scan on specific ports
nmap -sV -p 80 target.com       # Service/version detection
Save outputs with timestamps and consider --reason or -oA to keep records. Escalate intensity only with written permission.
Practical Notes
• Limit targets and ports to reduce noise and time. • Use SYN scans for quicker results but know IDS might still detect them. • Use -sV to correlate service versions with vulnerability data when authorized.
Pro Tip

Run scans during approved windows and start with host discovery to avoid scanning empty address space.
