Module 2 › Chapter 1.4 › From WHOIS to Network Range
Process

Steps to derive ranges

  1. Collect IPs from DNS records and web responses.
  2. Group IPs by common prefixes and infer CIDR blocks.
  3. Consult WHOIS or regional registries to verify ownership.
  4. Select subnet(s) within your authorized scope for host discovery.
  5. Document sources and rationale for chosen ranges.
Example
If DNS A records for several hosts resolve to 198.51.100.10, 198.51.100.32 and 198.51.100.200, these belong to 198.51.100.0/24 in many deployments. Verify with WHOIS before scanning.
Common mistake

Assuming one observed IP equals full ownership. Cloud-hosted services often overlap multiple tenants; always verify ownership before scanning.
