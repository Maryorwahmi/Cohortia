Learning Objectives

Learn, Understand, and Apply safe network scanning techniques.

Bloom's Bar
Learn
Understand
Apply
Master
01
Perform basic DNS enumeration
Run dig and nslookup to retrieve A, MX and NS records and identify hosts and mail domains. This reveals potential service endpoints for further assessment.
VERIFIED COMPETENCY MILESTONE
02
Identify network ranges
Derive CIDR blocks from WHOIS or observed addresses so you can plan efficient scans and avoid scanning unused addresses.
VERIFIED COMPETENCY MILESTONE
03
Explain port scanning basics
Understand the difference between TCP and UDP scanning, when each applies, and how open ports map to services attackers might target.
VERIFIED COMPETENCY MILESTONE
04
Use nmap and traceroute safely
Run nmap host discovery and controlled scans, and interpret traceroute to map hop sequences. Always respect time-of-day and scope limits.
VERIFIED COMPETENCY MILESTONE
