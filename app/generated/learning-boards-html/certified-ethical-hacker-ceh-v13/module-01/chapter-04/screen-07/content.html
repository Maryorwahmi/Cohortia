Module 2 › Chapter 1.4 › Host Discovery (Ping Sweep)
Process

nmap -sn for low-impact discovery

Start with non-intrusive host discovery to find live IPs before scanning ports. Record which probes you used and their timestamps.

• Use nmap -sn for a ping sweep.
• Combine ARP, ICMP, and TCP probes if ICMP is filtered.
• Treat non-response as inconclusive, not proof of absence.
Command Example
nmap -sn 192.168.1.0/24
In a lab, this yields a concise list of live hosts. Compare results with DNS-derived hosts to validate your scope and identify unseen devices.
Misconception

A lack of ping replies does not guarantee a host is offline; filters and firewalls commonly block discovery probes.
