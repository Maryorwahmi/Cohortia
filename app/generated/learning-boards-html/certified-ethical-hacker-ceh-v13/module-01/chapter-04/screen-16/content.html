Module 2 › Chapter 1.4 › Key Concepts — Practical Reminders
Confirm Authorization
Get explicit written permission and scoped targets before any active probe.
Start Low-Impact
Use DNS queries, traceroute, and nmap -sn before running port or version scans.
Document Everything
Save command outputs, timestamps, and rationale for every action to maintain auditability.
Final Takeaway

Ethical reconnaissance balances technical skill with strict process: permission, minimal impact, and full documentation.
