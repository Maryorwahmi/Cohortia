Definition

What banners tell you

Banners and probes reveal probable software and versions which guide vulnerability checks. They may be altered, so verify findings.

• Use nmap -sV to attempt version detection. • Expect false positives when proxies or CDNs are present. • Corroborate with other evidence such as headers or documented software inventory.
Example Output
PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 7.4
80/tcp open  http    Apache httpd 2.4.41
If you see a version like the example above, note it and check for corroborating evidence before concluding a vulnerability exists.
