Module 2 › Chapter 1.4 › Common Ports and Service Mapping
Hierarchy

Port → Service → Action

Map common ports to roles and plan verification steps before vulnerability checks.
  • 22 → SSH: banner and auth policy checks.
  • 80/443 → HTTP/HTTPS: banner, version, and web app fingerprinting.
  • 53 (UDP) → DNS: careful UDP probes and query checks.
Example Plan
If host X shows open ports 22 and 443: 1) run banner checks, 2) run nmap -sV on those ports, 3) log outputs and decide if authenticated checks are needed in a lab.
Key Takeaway

Use port findings to create a prioritized verification plan rather than assuming immediate risk.
