Dorking process
Form a search hypothesis, select operators that target document type, URL, or title, run the query, then refine based on results. Use quotes for exact phrases.
Common operators
  • site: restrict to a domain
  • filetype: filter by file extension
  • intitle: search page titles
  • inurl: search URL paths
  • intext: search page body text
  • cache: view search engine cached copy
Concrete example
site:example.com filetype:pdf confidential
Run on a safe domain to see how the query filters results to likely sensitive documents.
Pro tip
If a query returns too few results, remove the most restrictive operator and add a keyword instead to widen the net before refining again.
Pitfall
Never perform targeted dorks against live customer domains without written permission; use example.com or explicit test targets.
Try this safely
site:example.com inurl:admin intitle:login
Reflect: what types of pages are surfaced, and why might they be sensitive? Record your answer in the lab report.
