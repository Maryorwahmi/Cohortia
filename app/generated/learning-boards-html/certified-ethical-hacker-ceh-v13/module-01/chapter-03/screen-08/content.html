Whois and dig examples
Capture both WHOIS registrations and DNS records to map owner and services. Note redactions and privacy services.
Example commands
whois example.com
dig example.com MX
nslookup -type=TXT example.com
Run these on a lab machine and save the raw outputs for your report.
Record types and meaning
  • A: IP address of a host.
  • MX: mail exchange hosts handling email for the domain.
  • NS: authoritative name servers.
  • TXT: miscellaneous text data, including verification tokens.
Reporting tip
Include raw WHOIS and DNS outputs, annotate key fields, and explain what each record implies about mail or hosting providers and potential attack surfaces.
