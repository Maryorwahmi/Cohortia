What is Gaining Access?
Demonstrate that a vulnerability can be used to affect confidentiality, integrity, or availability.
Goal: Show impact while minimizing harm.
Acceptable proof: Non-sensitive indicators like version strings or controlled errors.
Prohibited: Exfiltrating real customer data unless explicitly authorized.
Concrete example
For SQL injection, show a harmless query result such as the database version rather than dumping records.
Pro-tip
Plan proof-of-concept steps in the RoE so the client approves the demonstration level.
Check your understanding: If the RoE forbids modification of data, what non-destructive proof would you use?
