Module 1 › Chapter 1.1 › Ethical vs Malicious
Ethical Hacking
Permission, defensive intent, structured reporting.
  • Authorization: Written RoE required.
  • Proof-of-concept: Show impact safely without exfiltration.
  • Outcome: Remediation and improved security posture.
Example
A pen test that shows a login bypass but does not copy user data, then reports the fix.
Malicious Hacking
No permission, malicious intent, and unlawful outcomes.
  • Authorization: None or illegitimate.
  • Proof-of-concept: Exfiltrate, vandalize, or monetize the breach.
  • Outcome: Data loss, disruption, and legal consequences for the attacker.
Misconception Check
Using the same tools does not change legality. Authorization and reporting do.
