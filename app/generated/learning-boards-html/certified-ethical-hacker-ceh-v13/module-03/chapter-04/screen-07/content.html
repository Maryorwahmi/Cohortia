Module 3 › Chapter 3.4 › Credentialed vs Uncredentialed
Uncredentialed Scan
External attacker view
What an unauthenticated adversary can see: open ports, public services, and exposed web apps.
• Useful for perimeter assessments and compliance checks.
• Prone to false negatives and may miss internal misconfigurations.
Credentialed Scan
Authenticated internal view
Provides the scanner with login access to inspect installed packages, patch levels, and local settings.
• Reveals missing patches and configuration issues not visible externally.
• Requires careful credential management and permission checks.
Example scenario
Start with an uncredentialed scan to map exposed services. Then add SSH or SMB credentials in a lab and run credentialed scans to identify missing OS patches and weak file permissions that the first scan missed.
Takeaway
Both scan types are necessary for a comprehensive assessment.
Common mistake
Relying solely on one scan mode and missing class-specific issues.
