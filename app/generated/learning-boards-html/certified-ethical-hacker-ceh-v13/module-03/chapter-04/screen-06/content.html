Module 3 › Chapter 3.4 › Configuring Scan Policies
Step-by-step
1. Define scope
List targets, confirm permission, and note sensitive roles or maintenance windows.
2. Select policy
Match policy to goal: broad discovery or focused web application testing.
3. Choose credential mode
Credentialed for deep internal checks, uncredentialed to simulate external exposure.
Practical tips
  • • Use narrower plugin sets for fragile systems to reduce risk.
  • • Document scan config and feed versions so results are repeatable.
  • • Schedule credentialed scans when system load is acceptable to avoid timeouts and false negatives.
Example
For a web app assessment, choose a web-focused policy and run uncredentialed scans first to capture external attack surface, then credentialed scans to inspect server-side configurations.
Warning

Never run aggressive or credentialed scans on production systems without explicit authorization and a contingency plan.
