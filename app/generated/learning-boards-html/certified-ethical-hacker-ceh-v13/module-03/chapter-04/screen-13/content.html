Module 3 › Chapter 3.4 › CVE & CWE
CVE
A unique identifier for a publicly disclosed vulnerability. Use it to find vendor advisories and patch details.
CWE
A classification of the underlying weakness, useful for root-cause remediation and developer guidance.
Practical mapping
For each scanner finding note the CVE, then map to a CWE category if listed. Use CVE to patch and CWE to design long-term fixes such as input validation or secure configuration hardening.
