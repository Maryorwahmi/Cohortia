Module 3 › Chapter 3.4 › What a Vulnerability Scanner Is
Definition
Vulnerability Scanner
An automated tool that probes systems and matches responses against known vulnerability checks.
How it works
Sends probes, evaluates responses, and consults plugin or NVD feeds for matches.
Limitations
May produce false positives and lacks full contextual judgement without human review.
Key Takeaway

Treat scanner output as hypotheses to verify, not definitive facts about the environment.

Analogy and Example
Analogy: A scanner is like a metal detector that beeps when it senses metal. The beep tells you where to dig, but you still must dig to confirm whether it's treasure or a bottle cap.
Concrete example
An OpenVAS scan flags an outdated SSH package based on version fingerprints. You then SSH into the host, check /etc/issue or package manager output to confirm.
Common misconception
Assuming every high-severity finding is exploitable in your environment without validation.
Check your understanding
