Module 3 › Chapter 3.4 › OpenVAS Lab Walkthrough
Lab scenario
Target: Metasploitable2 VM at 192.168.1.105. SSH creds: msfadmin / msfadmin.
1. Deploy OpenVAS and reach web UI.
2. Configuration → Targets: create target with IP and SSH credential.
3. Scans → Tasks: create task, select target and "Full and fast" scan config.
4. Start scan; wait until status is Done.
Analysis checklist
  • • Filter results by Critical/High severity.
  • • Open details, note CVE references and scanner evidence.
  • • Verify at least three high-severity findings on the VM (package versions, config files).
Safety note
Run these steps only in a lab environment with explicit permission; aggressive scans can disrupt services.
