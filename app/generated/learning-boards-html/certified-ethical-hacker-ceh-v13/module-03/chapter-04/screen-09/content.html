Module 3 › Chapter 3.4 › True/False Positives & Negatives
True Positive
A reported vulnerability that you can confirm by checking evidence or reproducing the issue.
False Positive
A finding reported by the scanner that does not exist; often caused by ambiguous response data.
False Negative
A real vulnerability the scanner missed, often due to insufficient checks or blocked probes.
Verification steps
  • • Review scanner evidence and reproduce findings in a lab if possible.
  • • Check package manager or configuration files to confirm reported versions.
  • • If missing checks cause false negatives, run credentialed scans or targeted manual tests.
