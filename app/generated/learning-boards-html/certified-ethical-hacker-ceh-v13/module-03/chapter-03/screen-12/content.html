Privilege Escalation

Moving from Low to Elevated Privileges

Why Escalate Privileges?

  • •**Initial Access:** Often grants only limited user privileges.
  • •**Full Control:** Higher privileges (root/admin) are needed for deeper system compromise.
  • •**Impact:** Allows installation of tools, modification of system settings, access to sensitive data.
Key Takeaway

Privilege escalation is essential after initial access to gain higher system control, often by exploiting local vulnerabilities like misconfigurations or unpatched software.

Common Privilege Escalation Vectors

Kernel Vulnerabilities

Misconfigured Services

Weak File Permissions

Scenario: Exploiting a SUID Binary

An ethical hacker finds a SUID (Set User ID) binary with a known vulnerability. By executing this binary with specific parameters, they can trick it into running a shell with root privileges, effectively escalating their access.
