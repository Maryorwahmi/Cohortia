Rainbow Table Attacks

Precomputed Hashes for Speed

How Rainbow Tables Work

  • •**Method:** Precomputed tables of hashes for common passwords.
  • •**Efficiency:** Quickly look up plaintext passwords from obtained hashes.
  • •**Vulnerability:** Highly effective against older, weaker hashing algorithms.
Mitigation

Use strong, salted hashing algorithms (e.g., bcrypt, scrypt) to render rainbow tables ineffective.

Credential Stuffing

Leveraging Password Reuse

How Credential Stuffing Works

  • •**Method:** Uses username/password pairs from other data breaches.
  • •**Assumption:** Users reuse passwords across multiple services.
  • •**Effectiveness:** Bypasses cracking by using already valid credentials.
Key Takeaway

Credential stuffing exploits human behavior of password reuse, making unique passwords and multi-factor authentication crucial defenses.
