John the Ripper (JtR)

Cracking Hashes from Compromised Systems

Key Features of JtR

  • •**Purpose:** Primarily for offline password cracking.
  • •**Target:** Password hashes obtained from compromised systems (e.g., /etc/shadow).
  • •**Methods:** Uses dictionary attacks and brute-force against hashes.
  • •**Advantage:** Bypasses online rate-limiting and account lockout policies.
Important Note

Always ensure you have explicit authorization before attempting to crack passwords or access system files.

# Example: Cracking password hashes with John the Ripper
# First, extract hashes (e.g., from /etc/shadow)
unshadow /etc/passwd /etc/shadow > myhashes.txt
# Then, crack with John
john --wordlist=/usr/share/wordlists/rockyou.txt myhashes.txt
# Explanation:
# unshadow: Combines passwd and shadow files for JtR.
# --wordlist: Specifies a dictionary file to use for cracking.
# myhashes.txt: The file containing the extracted password hashes.

Practical Scenario

After exploiting a web application vulnerability, an ethical hacker gains access to a server and extracts the local user password hashes. They then use John the Ripper on their own machine to crack these hashes and uncover plaintext passwords.
