Gaining Access: The Foothold Phase

Exploiting Weaknesses to Establish Presence

The Goal: Initial Entry

  • •Leverage identified vulnerabilities to establish a presence.
  • •Often the most challenging phase, requiring diverse attack vector knowledge.
  • •Focus on the path of least resistance: weak passwords, misconfigurations.
  • •Objective is to get *onto* the system, even with low-level user privileges.
Key Takeaway

Gaining access is the critical step of establishing a presence on a target system, often starting with minimal privileges before escalating further.

Common Entry Points

Weak Passwords

Misconfigurations

Unpatched Software

Social Engineering

Scenario: Low-Privilege Entry

An ethical hacker gains access to a web server through a vulnerable plugin. Initially, they only have the permissions of the web server process, not root access. This is a common starting point for further privilege escalation.
