Brute-force process
  1. Define character set and maximum length.
  2. Generate each candidate password programmatically.
  3. Submit each candidate until authentication succeeds or you exhaust options.
Mitigations like account lockouts, rate-limiting and long password complexity dramatically reduce feasibility.
Misconception check
Brute-force is not always noisy if throttled, but throttling makes it slow and often impractical to complete within an engagement window.
Illustrative scale
Adding characters multiplies the search space exponentially; defenses focus on increasing complexity and enforcing lockouts.
When to use it
Only for very short or numeric-only passwords, or as a theoretical baseline for defenders to measure resilience.
Key Takeaway

Brute-force provides a completeness guarantee but is usually impractical due to exponential growth and modern defenses.
