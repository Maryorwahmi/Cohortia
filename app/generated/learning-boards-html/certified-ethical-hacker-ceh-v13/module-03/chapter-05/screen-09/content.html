Module 4 › Chapter 3.5 › Hydra & Medusa
Tool overview
Hydra and Medusa automate online guessing across many protocols, using parallel threads to speed attempts.
  • Support many protocols: SSH, FTP, HTTP Basic, Telnet, SMB and more.
  • Sensitivity: high threading increases noise and risk of lockouts.
  • Use-case: scoped lab tests to validate resilience against guessing attacks.
Example command
hydra -l msfadmin -P passwords.txt ssh://192.168.1.105

# -l specifies a single username
# -P specifies a password file
# target is protocol://IP
Inspect output for success lines indicating discovered credentials. Confirm by logging in with the found pair.
Safety Reminder

Always run Hydra in a lab with permission. Understand detection and lockout settings before testing live systems.
