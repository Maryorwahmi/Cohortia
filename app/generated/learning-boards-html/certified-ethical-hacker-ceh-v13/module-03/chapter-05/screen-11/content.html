Common misconfigurations
Default Credentials
Devices and apps often ship with admin/admin or root/toor; unchanged defaults are an immediate risk.
Weak Service Configs
Anonymous FTP write or unauthenticated databases can be abused to read or place files.
Open Shares
SMB/NFS shares with weak permissions can leak credentials and scripts useful for escalation.
Example scenario
If a web admin interface uses default credentials, an attacker can log in immediately and create administrative sessions, planting backdoors or extracting secrets.
Remediation advice includes enforcing unique credentials, disabling anonymous access, and auditing shares and services for unnecessary exposure.
Key Takeaway

Misconfigurations often give immediate, high-impact access and should be high priority for remediation and testing.
