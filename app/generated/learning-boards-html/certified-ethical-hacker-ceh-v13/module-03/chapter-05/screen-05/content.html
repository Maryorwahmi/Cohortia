Module 4 › Chapter 3.5 › Password Attack Types
Attack comparison
Understand speed, coverage, and conditions where each attack is practical.
Brute-force
Tries every combination. Guaranteed given infinite time, but impractical against modern complexity and long passwords.
Dictionary
Uses wordlists and mutations. Fast and effective against weak, human-chosen passwords and leaked lists.
Rainbow Table
Precomputed hash tables to reverse hashes quickly. Effective only when hashes are unsalted or poorly salted.
Practical guidance
  • Start with a targeted dictionary rather than blind brute-force.
  • Mutate common entries to simulate human password patterns.
  • Reserve rainbow tables for older systems where you can obtain raw hashes and no salting is present.
Example
Using a concise list that includes typical passwords such as msfadmin or admin will often succeed quickly against intentionally weak lab VMs like Metasploitable2.
Key Takeaway

Match your method to the environment: dictionaries for humans, brute-force for short unknowns, rainbow tables only for unsalted hashes.
