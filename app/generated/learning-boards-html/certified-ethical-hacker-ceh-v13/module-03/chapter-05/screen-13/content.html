Module 4 › Chapter 3.5 › Privilege Escalation
Why escalate?
Higher privileges let you access protected data, configure services, and persist access. Escalation is often required to meet engagement objectives.
SUID/SGID binaries
Binaries with elevated execution bits may allow unintended root-level actions if misconfigured.
File permissions
Writable config files or scripts in privileged contexts can be modified to run code as a higher user.
Quick enumeration commands
# Find SUID files
find / -perm -4000 -type f 2>/dev/null

# Inspect writable files in /etc
find /etc -writable -type f 2>/dev/null
Use these checks to identify candidates for further safe analysis; do not run exploit code without scope permission.
Key Takeaway

Privilege escalation often relies on misconfigurations and weak permissions; careful enumeration reveals practical paths.
