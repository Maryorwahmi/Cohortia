Module 4 › Chapter 3.5 › Key Concepts
Initial Access
A confirmed presence allowing interaction with the system, such as a shell or valid credentials.
Password Attacks
Brute-force, dictionary and rainbow table approaches each have distinct trade-offs and conditions.
Online Tools
Hydra and Medusa automate online guessing; use them responsibly and in-scoped only.
Summary

Initial access plus careful verification and responsible escalation planning form the core workflow of system hacking and remediation testing.
