Module 4 › Chapter 3.5 › Initial Access — Definition
What is a foothold?
A confirmed presence that allows you to interact with the system and run commands or access resources.
Credential-based Access
Using a discovered username and password, including default credentials, to authenticate to a service.
Remote Code Execution
Exploiting a vulnerability that allows running commands on the target, yielding a shell or command output.
Open Shares
Read or write access to network shares that reveal credentials or configuration files.
Concrete example
An SSH service shows in a scan. Authenticating with msfadmin:msfadmin on a Metasploitable2 VM provides a shell. Running whoami confirms a low-privileged user. This is initial access.
Common misconception
Finding an open port or a vulnerable version does not equal access. Actual login or command execution is required to claim a foothold.
Key Takeaway

Initial access is the actionable step after discovery: confirm, document, and proceed safely to escalation or remediation testing.
