Process › OpenVAS setup
Key commands (lab)
Update feeds, start services, then access the web UI to continue configuration.
# Update GVM feeds (NVTs, SCAP, CERT)
sudo gvm-feed-update

# Start GVM services (if not already running)
sudo gvm-start

# Access the web interface at https://127.0.0.1:9392
# Change default credentials immediately after first login
Notes
Feed updates may take time; wait for NVT synchronization. Ensure your lab VM has internet access or preloaded feeds for offline setups.
Checklist before scanning
  • Confirm NVT feed synchronization and recent update timestamp.
  • Start GVM/OpenVAS services and verify no errors in service logs.
  • Reset default admin credentials and use secure passwords.
  • Test web UI login at the configured address and port.
Common mistake

Rushing to scan before feeds finish syncing leads to outdated results and missed CVEs. Always confirm feed update completion.
