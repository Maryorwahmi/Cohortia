Core Concept › Vulnerability Scanner
Definition
An automated tool that compares responses and configurations to known vulnerability databases and generates prioritized findings.
Capabilities
  • Detects missing patches, default credentials, and open services.
  • Reports CVE references and suggested remediation steps.
  • Supports credentialed scans for deeper visibility.
Limitations
  • Primarily finds known vulnerabilities, misses zero-days and custom logic flaws.
  • Can generate false positives and false negatives requiring manual validation.
Key Takeaway

Use scanners to cover breadth quickly; use manual testing to confirm depth and exploitability.

Concrete example
A scanner reports Apache version X with CVE-XXXX-XXXX and suggests updating. You verify the server version and whether the vendor patched it or if backported fixes negate the reported vulnerability.
Misconception
Not every reported vulnerability is exploitable—assume findings are hypotheses that need verification, not final diagnoses.
Pro tip
When a scanner flags a version issue, cross-check with configuration files or vendor notes to detect backported patches that remove the vulnerability.
