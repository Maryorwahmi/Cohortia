Definition › Credentialed vs Non-credentialed
Credentialed scans
Authenticated checks that can read config files and package versions for higher accuracy.
Benefits
  • Deeper visibility into installed software and missing patches.
  • Lower rate of false positives for version-related findings.
Caution
Authenticated checks can act differently and should be run with conservative settings on fragile systems.
Non-credentialed scans
Unauthenticated scans that simulate an external attacker and may miss internal configuration issues.
Benefits
  • Show exposure visible to the network or internet.
  • Safer initial pass on unknown or production systems.
Misconception
Assuming a non-credentialed scan that reports nothing means the system is secure; it may only mean internal issues are hidden without authentication.
