Hands-on Activity › OpenVAS basic scan
Terminal starters (lab)
Run these commands on your GVM host to update feeds and start services.
# Update GVM feeds
sudo gvm-feed-update

# Start GVM services
sudo gvm-start

# Then open the web UI at https://127.0.0.1:9392 and change default admin password
UI steps
Configuration → Targets: create Vulnerable_VM with 192.168.1.100. Scans → Tasks: create Basic Scan - Vulnerable VM and run it.
Report review
Once the task is Done, open the report, filter by Critical and High, and record CVE IDs and suggested remediation steps for the top findings.
Validation
For each top finding, validate by checking the running version, patch status, and whether the vulnerability is exploitable in the current configuration.
Reflection

Document how you validated or dismissed each finding and how that influenced your remediation priorities.
