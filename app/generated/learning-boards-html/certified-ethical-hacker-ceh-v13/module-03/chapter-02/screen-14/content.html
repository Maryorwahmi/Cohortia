Key Concepts
Three compact concept cards to recall quickly.
Vulnerability Scanner
Automated tool that detects known weaknesses using vulnerability data.
Nessus
Proprietary scanner noted for an extensive, frequently updated plugin database.
OpenVAS / GVM
Open-source vulnerability scanner with daily NVT updates and a web UI for tasks and reports.
Summary

Remember the tools and their roles: use scanners for breadth and manual testing for depth, and always validate critical findings.
