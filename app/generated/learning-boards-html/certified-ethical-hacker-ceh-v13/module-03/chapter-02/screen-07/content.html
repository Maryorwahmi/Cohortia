Process Flow › Create target & task
Step-by-step
1. Create Target
Name the target, enter hosts such as 192.168.1.100, and choose a port list.
2. Create Task
Give the task a clear name, select a scan configuration like 'Full and fast', and link the target.
3. Start and Monitor
Launch the task, watch progress, and wait for 'Done' before viewing the report.
Example

Target: Vulnerable_VM (192.168.1.100). Task: Basic Scan - Vulnerable VM. Scan config: Full and fast.

Guidance & safety
  • Start discovery scans before full scans to reduce noise.
  • Use conservative timing and parallelism settings on fragile targets.
  • Always confirm explicit authorization and scope before launching scans.
