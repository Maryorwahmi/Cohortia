Tools

Port scanners and vulnerability scanners

Active tools probe services to reveal open ports, running software, and potentially exploitable behaviors. They are powerful but must be used judiciously.

Best practices
  • Obtain explicit written permission and define scope.
  • Limit targets and scan rates to avoid outages.
  • Document commands and evidence for reproducibility.
Common mistake
Running aggressive scans across an entire network without notifying owners, causing false alarms or interruptions.
Example commands
# Non-aggressive port discovery (example)
nmap -sS --min-rate 50 --top-ports 100 target.example.com

# Targeted verification of a service banner
nmap -sV -p 80 --script=banner target.example.com
Check your understanding
When you find a potentially critical service, pause and validate it manually rather than running a broad automated exploit. Validation reduces false positives and prevents accidental damage.
