Module 3 › Chapter 3.1 › What is Vulnerability Analysis?
Definition

Vulnerability analysis explained

A systematic mix of automated discovery and manual validation that reveals true security weaknesses and ranks them by risk.

What it includes
Software flaws, misconfigurations, weak policies, and human factors.
Practical outcome
A prioritized list of validated findings with remediation guidance.
Common mistake
Treating raw scanner output as definitive without manual validation.
Key Takeaway

Vulnerability analysis turns noisy scan results into high-confidence, prioritized actions.

Analogy
Think of a building inspector who inspects doors, windows, wiring, and policies. The inspector lists which doors are unlocked and which ones are hazardous to open without repair. Vulnerability analysis is the security inspector's report for an IT environment.
Example
Observation: Server banner shows "Apache 2.4.49"
Hypothesis: Public CVEs for that version may exist.
Validation: Within scope, run a targeted probe to confirm service behavior and exploitability.
Report: Link to CVE, estimate impact, recommend patch or configuration change.
Check your understanding
When is a scanner finding not actionable? When it lacks verification, context, or clear remediation steps.
