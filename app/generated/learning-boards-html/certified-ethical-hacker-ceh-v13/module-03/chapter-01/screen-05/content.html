Module 3 › Chapter 3.1 › Active vs Passive Scanning
Comparison

Active scanning

Direct interaction with the target for accurate, current results but with detection and disruption risk.

Strength
High confidence, current state
Risk
Detectable and sometimes disruptive
Example
Running an authorized port scan to confirm which services accept remote connections and whether banner behavior matches known vulnerable versions.
Comparison

Passive scanning

Observing traffic and public records to form safe hypotheses without changing target state.

Strength
Stealthy, low impact
Limit
May miss live or transient weaknesses
Example
Inspecting HTTP headers from normal browser requests to infer server software and versions, then searching public CVE records for matches without issuing active probes.
