Module 8 › Chapter 8.1 › Key Concepts
Firewall
A system that filters traffic based on rules for addresses, ports, protocols, and sometimes application content.
IDS
Monitors traffic for suspicious patterns and alerts administrators; signature or anomaly approaches exist.
IPS
An IDS that can block or drop detected malicious activity inline.
Summary
Use these definitions to explain test scope and to guide which evasion techniques are appropriate for authorized assessments.
