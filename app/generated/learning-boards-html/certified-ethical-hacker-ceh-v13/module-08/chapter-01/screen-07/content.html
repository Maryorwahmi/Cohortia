Source Port Manipulation
Compare expected behavior when traffic uses normal ephemeral source ports versus spoofed known-service ports.
Normal outbound flow
Client uses ephemeral source port; firewall sees an allowed outbound TCP or UDP session and tracks state.
Spoofed source port
Client forges source port to mimic DNS or HTTP; a naive egress policy may allow it, but state validation can still block it.
Common Mistake
Assuming spoofed ports bypass source address validation. Many networks verify session state and source IP consistency.
Lab example
Change the source port of an outbound TCP or UDP packet in a VM and observe whether the egress filter accepts or drops it. Check firewall logs for port and IP validation messages.
Example Observation
If the firewall accepts the spoofed source port but the target replies to the real source IP, the session will not be established — showing the technique’s limitations.
