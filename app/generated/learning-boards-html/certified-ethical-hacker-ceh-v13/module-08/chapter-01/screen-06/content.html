IP Fragmentation
Use fragmentation to test whether intermediate devices reassemble before inspection.
Sample hping3 command (lab only)
sudo hping3 -c 1 -d 1000 -H 1337 -p 80 -f --rand-source <target_IP>
This sends a single fragmented packet with 1000 bytes of data and a randomized source IP to exercise reassembly behavior.
Example
Capture fragments on the wire and confirm whether an IDS logs only the first fragment or all fragments. Then confirm the target host reassembles and processes the payload.
Caution
Fragmentation can cause instability. Do not run tests on production networks without written authorization and rollback plans.
How to validate
  • Use Wireshark to view fragment offsets and reassembly order.
  • Check IDS/firewall logs for fragment handling and drops.
  • Confirm target host receives and reassembles fragments into the original payload.
Key Takeaway

Fragmentation highlights whether inspection happens before or after reassembly; use it to demonstrate gaps, not to exploit them.
