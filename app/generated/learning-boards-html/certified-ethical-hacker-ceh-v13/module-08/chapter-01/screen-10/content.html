Hands-on Activity
Nmap & Hping3 Walkthrough
Follow these authorized lab steps to compare scan types and fragmentation handling.
Target VM (commands)
sudo apt update && sudo apt install ufw
sudo ufw enable
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw default deny incoming
python3 -m http.server 80
Attacker VM (commands)
nmap -sV <target_IP>
nmap -sS -Pn <target_IP>
nmap -sF -Pn <target_IP>
sudo hping3 -c 1 -d 1200 -H 1337 -p 80 -f --rand-source <target_IP>
What to capture
Wireshark traces showing flags and fragments, UFW and firewall logs, and nmap outputs for each scan type to demonstrate differences.
Safety checklist
Never run tests on production networks. Have written authorization and a rollback plan. Monitor for unintended service disruption.
