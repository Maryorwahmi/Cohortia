Module 08 › Chapter 8.5 › Threat Modeling
Architecture

Modeling steps

  1. Inventory assets from recon: domains, IPs, services, versions.
  2. Identify exposures and likely attackers for each asset.
  3. Map services to known vulnerability classes for prioritization.
  4. Rank attack paths by impact and probability.
Example mapping
Discovery: web server at 203.0.113.10 running an older version of Apache. Threat model: attacker could exploit known remote code vulnerability → high impact for public site. Priority: high.
Misconception
Treating every CVE the same. Prioritize based on exposure and exploitability, not just CVE count.
Key Takeaway
Use recon outputs to rank attack paths. Threat modeling helps you spend test time on the risks that matter most.
