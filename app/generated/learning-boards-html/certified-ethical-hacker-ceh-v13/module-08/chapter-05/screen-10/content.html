Module 08 › Chapter 8.5 › Host Discovery
Commands
# Ping sweep to find live hosts (authorized range)
nmap -sn 192.0.2.0/28

# Traceroute to map path
traceroute 203.0.113.45
Use these only in permitted subnets. Note which hosts respond and whether any hops suggest segmentation or firewalling.
Concrete scenario
After passive recon finds a small DMZ subnet, run a controlled nmap -sn sweep in that range during the agreed window. Record responding hosts and traceroute paths to help plan safe service scans later.
Common mistake
Running wide sweeps at peak hours. Schedule discovery during agreed maintenance or low-traffic windows.
Key Takeaway
Host discovery tells you which machines exist and how the network is laid out. Do it with authorization and small scopes.
