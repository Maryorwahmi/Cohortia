Module 08 › Chapter 8.5 › Passive Tools
Process

Five-step passive sequence

  1. WHOIS — confirm registrant, registrar, and name servers.
  2. DNS (dig/nslookup) — collect A, MX, NS, TXT and enumerate subdomains.
  3. Wayback — check archived pages for removed endpoints or legacy content.
  4. Search operators — simulate Google dorking against example domains to find exposed files.
  5. Device indexes — view historically exposed devices and services without scanning them yourself.
Concrete example
Run whois to note name servers, then use dig to find MX and TXT. If Wayback reveals an old admin page, add that path to your investigation notes for later validation.
Misconception
Assuming device index results are current. They can be historical; always verify relevance before acting on the data.
