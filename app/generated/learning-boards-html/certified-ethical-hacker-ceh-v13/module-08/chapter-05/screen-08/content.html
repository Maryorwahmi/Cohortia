Module 08 › Chapter 8.5 › Passive vs Active
Passive Recon

Low detection risk

  • Uses public records and third-party indexes.
  • Good for initial mapping and finding forgotten assets.
  • Often reveals high-value leads without probing the network.
Active Recon

Higher fidelity, higher risk

  • Direct interaction: port scans, banner grabs, traceroute.
  • Provides service versions and live host status.
  • Can trigger alerts; limit scope, ports, and timing per ROE.
Concrete example
Passive: whois shows old registrant contact. Active: nmap -sV confirms an outdated web server version that maps to known CVEs.
Pro tip
If active scans are allowed, prefer SYN scans and narrow port ranges to reduce noise.
Key Takeaway
Combine passive and targeted active recon only when authorized. Each method answers different questions.
