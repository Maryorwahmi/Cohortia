Module 08 › Chapter 8.5 › Key Concepts
Pre-engagement Phase
Scope and ROE define what is allowed and how to communicate about critical findings.
Passive Recon
Use OSINT, WHOIS, DNS, archives and search operators to build an intelligence baseline safely.
Active Recon
Port scans and banner grabs provide versions and live status but must be limited and authorized.
Summary Takeaway
Authorize activity, gather public intelligence first, validate selectively with active scans, and convert findings into a prioritized test plan.
