Module 08 › Chapter 8.5 › Active Recon
Commands
# Stealthy SYN scan on common ports
nmap -sS -p 1-1000 <target_IP>

# Service/version detection on identified ports
nmap -sV -p 80,443 <target_IP>

# Simple banner grab with netcat
nc <target_IP> 80
Run these only if explicitly allowed. Limit port ranges and use timing options per the ROE.
Interpreting banners
Banners often include product names and versions. Record them with timestamp and source port so you can map to CVEs later.
Misconception
Assuming banners are always accurate. Some services hide or spoof banners; use banners as one data point among others.
Key Takeaway
Active scans reveal service details but must be tightly scoped and timed to avoid detection and disruption.
