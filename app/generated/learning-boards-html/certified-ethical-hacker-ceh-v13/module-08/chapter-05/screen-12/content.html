Module 08 › Chapter 8.5 › Vulnerability Mapping
Definition

Vulnerability Mapping

Match observed services and versions to known vulnerabilities, then prioritize checks and tests based on exposure and impact.

Workflow
  • Collect banner/version evidence.
  • Search vulnerability listings for matching versions.
  • Record likelihood and potential impact.
Practical note
Label findings as "potential" until you can safely validate. Use your threat model to decide whether to attempt verification under the ROE.
Common mistake
Reporting raw CVE matches without context. Always include exposure, evidence, and confidence level when mapping vulnerabilities.
Key Takeaway
Vulnerability mapping converts version evidence into prioritized test targets. Document confidence and only validate when permitted.
