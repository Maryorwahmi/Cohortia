Module 08 › Chapter 8.7 › Linux Privilege Escalation
Checks

Start with basic enumeration: whoami, id, environment variables, and then search for SUID/SGID files and writable configuration files.

Find SUID example
find / -perm -u=s -type f 2>/dev/null
Vectors
  • Writable scripts or config files executed by root (modify carefully in lab).
  • Cron jobs running as root that call writable files.
  • Misconfigured sudo entries allowing command abuse.
  • Kernel exploits when a suitable vulnerability and version match.
Key takeaway

Enumerate comprehensively, verify tools' findings manually, and prefer reproducible proof steps over destructive methods.
