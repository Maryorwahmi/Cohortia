Module 08 › Chapter 8.7 › Windows Privilege Escalation
Techniques
  • Kernel exploits: depend on exact patch level and are high impact.
  • Misconfigured services: services running as SYSTEM that can be modified.
  • Unquoted service paths: allow earlier path binaries to be executed as elevated service.
  • AlwaysInstallElevated: registry misconfiguration enabling MSI elevation.
  • Stored credentials: search config files, browser stores, or memory dumps.
Checks & tools
WinPEAS / PowerSploit

Automate discovery of high‑value checks, then verify findings manually before attempting privilege escalation.

Scenario

Find an unquoted service path. Demonstrate how placing a benign executable in the earlier path would be executed by the service as SYSTEM — but do not leave it in place; remove it and document the condition.

Key takeaway

Identify patterns, verify manually, and always justify a chosen escalation test in your report with safety measures noted.
