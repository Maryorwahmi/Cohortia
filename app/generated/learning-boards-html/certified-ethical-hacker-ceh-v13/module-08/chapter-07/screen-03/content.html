Lab checklist
  1. Start msfconsole and search for the chosen exploit (vsftpd or similar).
  2. Set RHOSTS, verify LHOST/LPORT, choose payload, and run in a test VM.
  3. On success, run getuid/whoami and simple enumeration commands.
  4. Perform privilege escalation checks and simulate persistence safely.
  5. Remove all created artifacts and record exact cleanup steps in your report.
Evidence to collect
  • Exploit module name, options used, and payload selected.
  • Result of exploit: obtained shell type and user context.
  • Privilege escalation paths found and proof-of-concept steps.
  • Persistence changes and cleanup actions performed.
