Module 08 › Chapter 8.7 › Maintaining Access (Persistence)
Common persistence methods
  • Create a new user account with a known password.
  • Add an SSH public key to authorized_keys for passwordless entry.
  • Modify startup scripts or registry Run keys to launch a backdoor at boot.
  • Deploy a persistent agent in test scenarios only.
Simulate safely

Prefer snapshots or isolated VMs. When demonstrating persistence, create reversible artefacts and keep a clear cleanup checklist.

# Example (Linux, simulated)
mkdir -p /root/.ssh
echo "ssh-rsa AAAAB3..." > /root/.ssh/authorized_keys
chmod 700 /root/.ssh
chmod 600 /root/.ssh/authorized_keys
# To cleanup: rm -rf /root/.ssh
Key takeaway

Document persistence steps and cleanup thoroughly so defenders can remove or detect the vector.
