Module 08 › Chapter 8.7 › Payloads & Meterpreter
What is a payload?

Code delivered by an exploit that executes actions on the target: a shell, an agent, or a one‑off command.

Meterpreter highlights
  • Provides an interactive, extensible shell with in-memory operation to reduce disk artifacts.
  • Includes post‑exploit modules: credential gathering, process enumeration, and pivoting helpers.
  • Requires careful use: may be detected and may not perform privileged actions until escalation.
Misconception

A successful Meterpreter session does not imply administrator access; privilege escalation may still be required.

Example session
# after exploit succeeds
meterpreter > sysinfo
Computer        : target-host
OS              : Linux 3.x
meterpreter > getuid
Server username: uid=1000(user)
meterpreter > run post/linux/gather/enum_configs
Concrete example

Use getuid to know context, then run LinPEAS or built‑in enumeration modules to search for escalation vectors.

Key takeaway

Meterpreter is a toolset; combine it with targeted checks to move toward higher privileges safely.
