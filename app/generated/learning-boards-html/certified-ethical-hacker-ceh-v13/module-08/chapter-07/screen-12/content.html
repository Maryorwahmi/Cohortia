Module 08 › Chapter 8.7 › Covering Tracks & Cleanup
Cleanup checklist
  • Remove created user accounts and SSH keys.
  • Delete uploaded tools, scripts, and temporary files.
  • Restore modified configuration or startup scripts.
  • Record every cleanup step so the client can confirm restoration.
Demonstration notes

If you clear logs or histories to show what an attacker could do, do so only with client agreement and never destroy evidence defenders need for real incident response.

Scenario

Use clearev in Meterpreter only when authorized and record the state before and after; prefer snapshots to irreversible log edits.

Key takeaway

Cleanup should restore systems and preserve a reproducible record for defenders — not erase everything attackers might leave behind.
