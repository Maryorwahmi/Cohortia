Module 08 › Chapter 8.7 › Metasploit Workflow
Steps
  1. Select an exploit by matching service and version found during enumeration.
  2. Set options like RHOSTS, LHOST, and LPORT and confirm module-specific flags.
  3. Choose a payload that meets objectives: reverse shell, bind shell, or staged Meterpreter.
  4. Execute and collect evidence: session type, output, and initial commands run.
Pro tip

Prefer staged or low-impact payloads for evidence collection unless full compromise is in scope and allowed.

Example check

After getting a shell, run whoami or getuid to confirm user context and session stability.

Key takeaway

Document module, options, and the exact output that proves access.
