Module 08 › Chapter 8.7 › Lab: Exploit & Basic Post‑Exploitation
Lab timeline
1. Prepare
Start msfconsole and verify VM snapshots and scope.
2. Find module
Search for vsftpd or target exploit and review options.
3. Configure
Set RHOSTS, LHOST, LPORT and verify payload choice.
4. Execute
Run exploit and capture session output and whoami/getuid.
5. Post checks & cleanup
Enumerate escalation paths, simulate persistence on a snapshot, then remove artifacts.
Commands to record
  • Module name and options used.
  • Session output and whoami/getuid results.
  • Any persistence commands simulated and the cleanup commands used.
Key takeaway

Follow a repeatable sequence and collect enough evidence for defenders to reproduce and remediate safely.
