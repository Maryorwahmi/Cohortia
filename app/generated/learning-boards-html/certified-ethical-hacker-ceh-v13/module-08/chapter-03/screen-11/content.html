Module 08 › Chapter 8.3 › Data Exfiltration
Concept

Stealthy data removal

Exfiltration often uses encryption, compression, and small chunked transfers sent over legitimate channels to avoid detection.

Chunking and timing

Many small uploads spread over time blend into normal traffic patterns and escape size-based alarms.

Steganography

Embedding data in innocuous files like images to hide content from casual inspection.

Key Takeaway

Monitor for unexpected destinations, unusual upload cadence, and deviations from normal data transfer behavior.

Practical detection
  • Log and analyze outbound HTTP/HTTPS patterns for frequency anomalies.
  • Inspect DNS request patterns for unusual subdomain lengths or regular intervals.
  • Apply egress rules that restrict which hosts can upload to cloud storage.
In lab tests, label test files clearly and use controlled endpoints so detection rules can be tuned without risk to production data.
