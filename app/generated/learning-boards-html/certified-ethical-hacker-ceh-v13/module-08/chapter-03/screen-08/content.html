Module 08 › Chapter 8.3 › Lateral Movement
Concept

Remote execution and lateral movement

Attackers use valid credentials and admin tools to run commands on remote hosts to move laterally without dropping new binaries that would trigger detection.

Monitoring signals
  • Unexpected remote command sessions using admin tools
  • Credential use from uncommon source hosts
  • Simultaneous logins across multiple systems with same account
Key Takeaway

Correlate remote-execution events with credential origin and timing to spot lateral movement.

Safe walkthrough
Example safe command to verify remote execution in a lab. Replace target values with lab hosts and authorized credentials only.
psexec \\<VM2_IP_Address> -u <VM2_Local_Admin_Username> -p <VM2_Local_Admin_Password> cmd.exe

# After the remote shell opens, run safe checks:
hostname
whoami
When defenders see this pattern outside expected maintenance windows, it should trigger an investigation focusing on the initiating host and credential source.
