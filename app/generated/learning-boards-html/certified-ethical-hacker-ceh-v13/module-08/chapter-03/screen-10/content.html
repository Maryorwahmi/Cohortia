Concept

C2 channels and stealth

Attackers use covert channels to control hosts and stage data. Common choices include DNS tunneling, HTTPS encapsulation, and custom encrypted protocols.

DNS tunneling

Encodes data into DNS requests to hide in normal name resolution traffic; look for unusually long or frequent queries to odd domains.

HTTPS and cloud storage

Attackers mimic normal web traffic and use cloud services for exfiltration, blending with legitimate flows.

Detection cues
  • Many small outbound requests to a single external host.
  • DNS requests with unusual subdomain patterns or lengths.
  • Encrypted connections to new or low-reputation endpoints from multiple hosts.
Key Takeaway

Monitor egress, log DNS activity, and correlate cross-host network patterns to spot covert C2 channels.
