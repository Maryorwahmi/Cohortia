Module 08 › Chapter 8.3 › Lab: Lateral Movement & Persistence
Scenario

Two-VM lab, isolated network

VM1 is the attacker-controlled host with local admin. VM2 is the target. All actions occur in an isolated lab with documented scope and explicit authorization.

Step 1: Record mock credential output rather than running real tools.
Step 2: Use remote execution with authorized lab credentials to run hostname and whoami on VM2.
Step 3: Create a benign scheduled task to write a test file at startup and verify after reboot.
Expected logs to collect

Windows Event logs for task creation, EDR telemetry for remote execution, and network flows for outbound connections. Use these to tune alerts.

Safe commands (example)
# Example remote execution check
psexec \\\<VM2_IP_Address\> -u <AdminUser> -p <AdminPass> cmd.exe
# In remote shell:
hostname
whoami

# Example scheduled task (benign):
schtasks /create /S <VM2_IP> /U <AdminUser> /P <AdminPass> /TN "TestStartup" /TR "cmd.exe /c echo lab-test > C:\\lab_test.txt" /SC ONSTART /RU SYSTEM
After completing the exercise, remove tasks and revert snapshots. Document findings and any detection gaps you observed.
