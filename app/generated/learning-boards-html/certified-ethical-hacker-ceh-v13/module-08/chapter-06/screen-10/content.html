Module 8 › Chapter 8.6 › DNS Enumeration
Zone transfer attempt
dig axfr @<DNS_server_IP> <domain>
If the server allows AXFR, you will receive a full listing of DNS records. If not, note the authoritative server and extract other records like MX, NS, and A records for further enumeration.
What to gather
  • Subdomains and hostnames that may point to internal services.
  • Mail records and service pointers for targeted enumeration.
  • Authoritative servers to target for further DNS queries.
Verification step
After collecting DNS records, verify actual service presence by resolving hostnames and scanning the reported IP addresses.
Key Takeaway

DNS enumeration can reveal network structure; zone transfers are valuable when misconfigured, but always corroborate DNS data with active probes.
