Module 8 › Chapter 8.6 › Vulnerability Scanning vs Manual Analysis
Automated scanners
  • Provide rapid coverage of known vulnerabilities across many hosts.
  • Often generate false positives and miss chained or logic flaws.
  • Useful for baseline assessments and prioritization.
Manual analysis
  • Verifies scanner findings and attempts targeted exploitation or proof-of-concept checks.
  • Discovers complex, multi-step vulnerabilities that automation misses.
  • Requires human judgment and domain knowledge.
Workflow
Scan → Triage → Manual verification → Report
Pitfall
Relying on scanner output as definitive evidence.
Verification
Attempt a safe proof-of-concept to confirm severity before reporting.
Key Takeaway

Scanners give breadth; human analysis gives depth. Use both to create accurate, prioritized findings.
