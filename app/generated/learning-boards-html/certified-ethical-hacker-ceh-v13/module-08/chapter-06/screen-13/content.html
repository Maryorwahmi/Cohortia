Recommended command sequence
# Full Nmap discovery
nmap -sS -sV -O -A -p- <target_IP>

# If SMB found
enum4linux -a <target_IP>

# DNS zone transfer (if DNS server identified)
dig axfr @<DNS_server_IP> <domain>

# SNMP check
snmpwalk -c public -v 1 <target_IP>

# Web directory brute-force
gobuster dir -u http://<target_IP> -w /usr/share/wordlists/dirb/common.txt
Follow the output to build a prioritized verification list: which ports require banner grabs, which services need credential checks, and which findings could cause impact if probed aggressively.
Interpretation checklist
  • Is a reported version actually reachable at that endpoint? Verify with a direct probe.
  • Does an enumerated share permit read or write access? Check with smbclient safely.
  • Could aggressive scanning disrupt services? If yes, document and stop until authorized.
Reflection prompt
Which outputs would you escalate to a safe proof-of-concept and which would you mark as false positives pending further verification?
Key Takeaway

Use this sequence as a template: discover broadly, enumerate protocol-specifically, then validate findings with minimal impact and clear documentation.
