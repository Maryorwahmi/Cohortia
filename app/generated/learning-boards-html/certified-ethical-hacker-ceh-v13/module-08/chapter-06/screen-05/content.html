Scan result meanings
  • Open: service responded; candidate for enumeration.
  • Closed: host reachable but no service on that port.
  • Filtered: packet dropped or blocked; requires alternative probes.
Common Nmap scan types
  • TCP SYN scan (-sS): stealthy, avoids full handshake.
  • TCP Connect (-sT): completes handshake, more visible.
  • UDP scan (-sU): identifies UDP services; responses are inconsistent.
  • FIN/Xmas/Null (-sF, -sX, -sN): flag-based tactics to bypass some filters.
Visual flow
Probe sent → Response
SYN probe → SYN/ACK means open. SYN probe → RST means closed. No reply or ICMP unreachable indicates filtered or UDP behavior.
Concrete example
A SYN scan flags port 22 open. Follow up with version detection or an SSH banner probe to confirm service type and version.
Key Takeaway

Port states guide next steps: choose appropriate enumeration or different scan types to clarify filtered responses.
