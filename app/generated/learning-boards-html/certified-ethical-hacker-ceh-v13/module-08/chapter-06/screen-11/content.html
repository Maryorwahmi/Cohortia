Module 8 › Chapter 8.6 › SNMP, Email & Web Enumeration
SNMP probe example
snmpwalk -c public -v 1 <target_IP>
With default community strings, snmpwalk can return a wealth of infrastructure data. If values are present, record versions and interfaces for later verification.
Web directory brute-force
gobuster dir -u http://<target_IP> -w /usr/share/wordlists/dirb/common.txt
Brute-forcing paths can reveal hidden admin panels, backups, or files containing credentials. Treat discovered items as leads to be validated without downloading sensitive data unnecessarily.
Key Takeaway

Combine protocol-aware enumeration with cautious manual verification to turn raw data into prioritized findings while avoiding unnecessary impact.
