Module 8 › Chapter 8.2 › Attacker Evasion
Evasion techniques
  • • Banner and service fingerprinting to find generic responses.
  • • Latency and TTL checks to detect virtualization.
  • • Command probes to detect missing utilities or sparse file systems.
  • • Low-and-slow scanning to avoid triggering sensors.
Defender countermeasures
Increase realism of decoys, ensure plausible file contents, and carefully tune timing so simulated hosts behave as a real asset would while maintaining containment.
Key Takeaway

Design decoys that are believable to automated tools and casual attackers, and ensure containment to mitigate risk if detected.
