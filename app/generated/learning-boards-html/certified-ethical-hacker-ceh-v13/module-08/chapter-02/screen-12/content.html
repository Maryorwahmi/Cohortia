Setup snippet (illustrative)
sudo apt update
sudo apt install python3-pip python3-dev libssl-dev build-essential
# Create user and environment for Cowrie
sudo useradd -m cowrie
sudo su - cowrie
virtualenv cowrie-env
source cowrie-env/bin/activate
pip install cowrie
# Configure cowrie.cfg to change listen_port = 2222
bin/cowrie start
Run these steps in a controlled lab. Change ports to avoid interfering with production SSH.
Attacker scan
nmap -sV -p- <target_IP>
ssh root@<target_IP> -p 2222
ls -la /
cat /etc/passwd
Expected low-interaction outputs
  • • Limited directory listings.
  • • Small or generic /etc/passwd entries.
  • • Missing system utilities or "command not found" responses.
Safety reminder

Perform this activity only in your lab or when explicitly authorized. Document and report any decoy systems you find during a sanctioned engagement.
