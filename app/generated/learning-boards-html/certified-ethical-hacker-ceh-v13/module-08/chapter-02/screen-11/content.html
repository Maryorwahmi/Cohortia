Module 8 › Chapter 8.2 › Behavioral Indicators
Signals to check
• Timing / latency anomalies compared to expected baselines.
• TTL differences that might indicate virtualization.
• Sparse file system listings and missing common commands on login.
Concrete example
After an SSH login, run ls -la / and cat /etc/passwd. If outputs are unexpectedly small, commands are missing, or binaries return "command not found", these are indicators consistent with a low-interaction honeypot.
Misconception

No single check is proof. Combine multiple behavioral indicators and document them before concluding a honeypot exists.
