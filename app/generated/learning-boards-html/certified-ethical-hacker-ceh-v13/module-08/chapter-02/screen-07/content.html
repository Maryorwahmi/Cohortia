Architecture

Honeynet — realistic, but contained

Multiple decoys present a believable environment that helps capture attacker workflows across hosts and services.

Containment
Isolate traffic, control outbound connections, and centralize logs.
Realism
Use plausible hostnames, service combinations, and decoy data so attackers accept the environment as real.
Example cards
Decoy web app
Fake application pages and credentials to lure attackers into web exploitation paths.
Internal file share
Decoy documents and credentials that appear to be sensitive but are safe to collect.
Key Takeaway

Honeynets reveal attacker movement across hosts when realistic signals are used and containment is enforced.
