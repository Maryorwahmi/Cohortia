Telemetry to collect
  • Process listings and parent-child relationships
  • Network connections and DNS queries
  • Registry startup keys and scheduled tasks
  • Filesystem changes and new executables
Use EDR to automate collection where possible and timestamp everything for timeline reconstruction.
Forensic steps
1. Preserve memory
Capture volatile state to recover in-memory artifacts like keys.
2. Image disks
Collect disk images and registry hives for offline analysis.
3. Correlate logs
Map network flows, authentication logs, and system events to build a timeline.
