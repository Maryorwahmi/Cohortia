Module 4 › Chapter 4.4 › Ransomware Flow
Typical attack timeline
1. Delivery
Phishing, malvertising, or exploitation of unpatched services like remote access.
2. Execution
Ransomware runs and may escalate privileges to access more assets.
3. Encryption
Strong symmetric/asymmetric crypto used to lock files; keys held by attacker.
4. Ransom & Extortion
Ransom note demands cryptocurrency; double extortion may add publication threats.
Test: simulate each stage in a controlled lab using benign artifacts and monitoring to validate detection points.
Encryption mechanics
Common approach: per-file symmetric encryption (e.g., AES) combined with asymmetric encryption (e.g., RSA) to protect the symmetric keys. This design prevents recovery without the attacker’s private keys.
Operational impact
Beyond file loss, attacks cause downtime, reputational damage, and possible data breach liabilities if exfiltrated data is published.
