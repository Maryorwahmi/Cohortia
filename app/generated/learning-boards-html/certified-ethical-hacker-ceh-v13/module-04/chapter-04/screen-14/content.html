Module 4 › Chapter 4.4 › Key Concepts
Trojan
Malware disguised as legitimate software that depends on user execution, often leading to a backdoor.
RAT
A Trojan subtype that provides an attacker full remote control of a compromised host.
Downloader / Dropper
Stages secondary payloads by fetching or dropping them locally; detect via download and write behavior.
Summary

Align detection and response to the malware’s objective: access, extortion, or surveillance.
