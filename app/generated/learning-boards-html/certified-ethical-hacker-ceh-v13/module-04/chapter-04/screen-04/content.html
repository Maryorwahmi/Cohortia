Module 4 › Chapter 4.4 › Trojan Definition
Trojan Horse — core idea
Malware that disguises itself to trick a user into running it and then performs malicious actions.
Metaphor
Like a gift box containing a harmful device: the outside looks useful, the inside is the threat.
Example
A malicious "PDF converter" installer that opens a backdoor after installation.
Common misconception
Trojans do not self-propagate. If you see automatic spreading, you are likely looking at a worm or virus instead.
Key Takeaway

Prevent execution of untrusted installers and use whitelisting to block unknown programs.

Anatomy of a Trojan
Delivery
Phishing email or malicious download that convinces a user to execute the file.
Execution
When run, the Trojan performs its payload: open a backdoor, drop other malware, or spy on the user.
Persistence
Modifies startup or uses scheduled tasks to remain after reboot.
Example tools
Simulate detection in a lab: install a harmless agent packaged like an installer to validate controls.
