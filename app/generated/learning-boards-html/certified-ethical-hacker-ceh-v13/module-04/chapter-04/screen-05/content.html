Subtype comparison
RAT (Remote Access Trojan)
Provides full attacker control: desktop, files, webcam, keystrokes. Look for active remote sessions and command callbacks.
Downloader / Dropper
Fetches or contains secondary payloads. Detect by monitoring unusual downloads and new executable writes.
Backdoor
Hidden entry point that bypasses auth and persists across reboots. Look for unexpected services and startup entries.
Detection signals: outbound connections, new services, scheduled tasks, unusual file writes.
Testing tip: simulate each subtype with safe lab agents to validate EDR and network monitoring.
Example families
  • RAT examples: DarkComet, njRAT, Gh0st RAT
  • Banking Trojans: Zeus, Dridex (specialized theft)
Use known patterns to shape detection but avoid assuming identical behaviors across all samples.
