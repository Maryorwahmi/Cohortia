Viruses — host-dependent replication

Attach to files and require user action to execute, replicate, and spread.

How they work
  • Attach to legitimate executables or documents.
  • Trigger on user action: open, run, or enable macros.
  • Replicate by modifying other files on the local system.
Scenario
A user opens an infected spreadsheet and enables macros. The macro copies itself into startup scripts and other spreadsheets, spreading when colleagues open those files.
Common mistake
Assuming a signature-only antivirus will always detect viruses. Modern variants change signatures; use behavior detection and least privilege.
Detection clues
  • Unexpected file modification timestamps.
  • Multiple similar files with altered sizes.
  • New autorun entries or altered DLLs.
Key Takeaway

Viruses depend on user action and a host. Interrupt execution paths and enforce safe file handling to prevent spread.
