Learning Objectives

Learn, Understand, Apply, Master — build a practical foundation for malware analysis.

01
Define malware and its evolution

Explain what malicious software is, how it changed over decades, and why modern motivations differ from early curiosity-based attacks.

VERIFIED COMPETENCY MILESTONE
02
Categorize primary malware types

Name and distinguish viruses, worms, Trojans, ransomware, spyware, and adware including their defining propagation traits.

VERIFIED COMPETENCY MILESTONE
03
Understand infection mechanisms

Describe how each malware type infects systems, which vulnerabilities or user actions enable that infection, and common signatures of activity.

VERIFIED COMPETENCY MILESTONE
04
Recognize impact and attacker objectives

Identify whether malware aims to disrupt, steal data, extort, or hijack resources and what that implies for response priorities.
