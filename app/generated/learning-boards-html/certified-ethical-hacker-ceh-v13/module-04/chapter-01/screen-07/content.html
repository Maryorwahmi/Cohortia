Trojans and Remote Access Trojans

Malware that depends on deception to get installed and then performs malicious actions silently.

Behavior
  • Masquerades as legitimate software or updates.
  • Requires user installation or execution but does not self-replicate.
  • Often includes backdoors, credential theft, or further payload downloaders.
Concrete example
A downloaded 'utility' installs a background service that opens a persistent remote shell for the attacker to control the machine.
Misconception check
Not all deceptive installers are obvious; well-crafted Trojans may use valid certificates or familiar branding to evade suspicion.
Indicators
  • Unexpected outbound connections to uncommon hosts.
  • New services or scheduled tasks without administrative change records.
  • Unrecognized processes running persistently.
Key Takeaway

Trojans exploit trust. Verify sources, minimize privileges, and monitor for unexpected persistence and connections.
