Module 4 › Chapter 4.1 › Worms vs Viruses
Virus (host-dependent)
Needs host
  • Attaches to legitimate files or macros.
  • Requires user execution to activate.
  • Spreads by modifying local files.
Example
An infected document with macros that runs a payload when macros are enabled by the user.
Worm (autonomous)
Self-replicates
  • Standalone program that scans and infects networked hosts.
  • Exploits vulnerabilities to propagate without user action.
  • Often causes network congestion and rapid outbreaks.
Example
A program that probes network ports, exploits an unpatched service, and copies itself to new hosts automatically.
Key Takeaway

Ask whether human action is required. If yes, treat like a virus; if not, prioritize network containment and patching for worms.
