Rootkits — stealth and persistence

Levels of operation
User-mode
Intercepts API calls and hides processes at the application level.
Kernel-mode
Hooks into the OS kernel to subvert system reporting and security controls.
Boot-level
Alters boot loaders to gain control before the OS loads, making detection extremely difficult.
Indicators & response
  • Inconsistent process or file listings compared to disk images.
  • Drivers or modules that resist unloading or show tampered timestamps.
  • Network connections that persist despite stopping visible processes.
Investigation note
Analyze suspected rootkits in offline or isolated environments. Use integrity comparisons to known-good images and be prepared for full system rebuilds.
Key Takeaway

Rootkits hide and persist; defend with secure boot, limited privileges, and integrity monitoring.
