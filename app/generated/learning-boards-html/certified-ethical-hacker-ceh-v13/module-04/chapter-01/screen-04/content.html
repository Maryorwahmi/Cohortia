Module 4 › Chapter 4.1 › What is Malware?
Definition

Software intentionally created to harm systems, steal data, or control resources without authorization. It is defined by behavior and intent, not by a single signature.

Evolution highlights
  • 1980s: Boot sector viruses and curiosity-driven code.
  • 2000s: Network worms exploiting unpatched services.
  • Modern: Multi-stage, polymorphic, financially motivated attacks.
Key Takeaway

Use precise labels for behavior; that precision drives proper containment and analysis.

Analogy and scenario
Analogy
Think of malware like a toolbox used for harm: each tool has a purpose — copy files, hide processes, or lock data — and the combination determines the threat.
Concrete example
A modern attack may use a small loader delivered by phishing to fetch an encrypted payload that installs a persistent backdoor and later exfiltrates credentials.
Common misconception
Not every unwanted program is a virus. If a program spreads without user action by exploiting a server flaw, it is a worm, not a virus. That distinction affects detection and remediation.
