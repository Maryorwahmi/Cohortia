Module 4 › Chapter 4.2 › Static Tools
Tool comparison
strings — quick, low-effort extraction of readable text; great for IOCs.
PE viewer (PE-bear/dumpbin) — shows imports, exports, and sections for capability inference.
Disassembler / Decompiler (Ghidra, IDA) — inspect control flow, algorithms, and encryption routines.
Concrete example
You run strings and find http://malicious-c2.com/payload. Opening the file in a PE viewer shows imports related to WinHTTP or sockets. This progression strengthens your hypothesis that the sample attempts network communication. If the sample is packed and strings are sparse, the disassembler will initially show little; you should consider unpacking or dynamic analysis to reveal runtime strings.
Pro tip
Save outputs from each tool to separate files and reference them in your notes. This makes your triage repeatable and shareable with responders.
