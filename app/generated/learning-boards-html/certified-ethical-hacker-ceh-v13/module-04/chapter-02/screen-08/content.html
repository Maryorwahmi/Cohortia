Procmon workflow
  1. Start Procmon and clear existing events.
  2. Create a filter for Process Name == sample.exe or for the target PID.
  3. Run the sample and observe CreateFile, WriteFile, RegSetValueEx entries.
  4. Save the capture and export filtered results for reporting.
Example interpretation
A RegSetValueEx call to Run keys indicates persistence; CreateFile of unusual temp files may indicate unpacking or staging.
Process Explorer checks
Use Process Explorer to view loaded DLLs, open handles, and parent processes. Look for injected DLLs or mismatched digital signatures as possible red flags.
Key takeaway
Correlate Procmon events with Process Explorer snapshots and timestamps to build a reproducible timeline of malicious actions.
