Module 4 › Chapter 4.2 › Isolated Analysis Environment
VM setup checklist
  • Host OS: Linux host preferred for experiment isolation.
  • Virtualizer: VirtualBox or VMware; choose host-only networking.
  • Guest OS: Windows 10 for Windows-targeted malware analysis.
  • Network: Host-only or isolated VLAN; no direct internet access.
  • Snapshot: Take a clean snapshot before any execution.
  • Tools: Procmon, Procexp, Wireshark, PE viewers, and debuggers.
Example configuration
Host: Ubuntu, VirtualBox, Guest: Windows 10, Network: Host-only adapter, Take snapshot named Clean-Baseline. Install Procmon and Wireshark inside guest.
Common mistake
Enabling clipboard or shared folders defeats isolation. Disable them before running samples.
