Tools you'll use
  • Static: strings, FLOSS, PE viewers, disassembler/decompiler.
  • Dynamic: VirtualBox/VMware, Procmon, Procexp, Wireshark, debuggers, sandboxes.
  • Automation: Cuckoo or managed sandboxes for high-volume triage.
Safety checklist
Take a clean VM snapshot before each run.
Never connect analysis VM to production network or corporate VPN.
Document every observation with timestamps and tool output.
