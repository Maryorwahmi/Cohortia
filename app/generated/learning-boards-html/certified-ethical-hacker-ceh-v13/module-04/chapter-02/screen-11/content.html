Terminal demo
file sample.exe
strings sample.exe > sample_strings.txt
# Open sample_strings.txt and search for http, www, Version, Copyright
Save outputs to a notes folder and mark strings that look like IOCs. This is the same process you'd use for suspicious samples, but with a benign file for safety.
PE viewer tasks
  • Open sample.exe and list three imported DLLs and functions.
  • Inspect .text, .rdata, and .rsrc sections and note sizes and permissions.
  • Document any unusual section names or suspicious characteristics.
Safety reminder
Do not run unknown binaries on your main system. Use benign samples for practice or run unknown code only inside properly isolated VMs with snapshots.
