Wireshark focus areas
  • DNS queries to suspicious domains.
  • HTTP POST/GET requests and their hosts.
  • TLS connections: SNI, certificate anomalies, and unusual endpoints.
Example filter: http.request.method == "POST" && ip.dst == 192.168.56.101 (use your isolated C2 capture IP). Capture timestamps to correlate with Procmon logs.
Sandbox automation
Cuckoo and commercial sandboxes run samples automatically and report file changes, process trees, and network traces. They are invaluable for high-volume triage but can be detected by anti-analysis malware.
Misconception
Assuming encrypted traffic is opaque. Metadata such as DNS, SNI, and timing patterns still provide useful indicators of C2 behavior.
