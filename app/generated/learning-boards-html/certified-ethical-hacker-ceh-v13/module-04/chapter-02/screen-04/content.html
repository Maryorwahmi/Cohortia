Module 4 › Chapter 4.2 › What is Malware Analysis?
Definition & Purpose
Malware analysis determines functionality, origin, and impact. It supports detection, remediation, and attribution.
Static
Examine files without execution: headers, strings, imports, and code shapes.
Dynamic
Execute inside a controlled VM to observe file, registry, and network activity in real time.
Key Takeaway

Use static analysis to form hypotheses and dynamic analysis to validate them, always in a safe environment.

Concrete example
Imagine an EXE that contains URLs for update endpoints. Static tools show those strings and imported network functions. Running it in an isolated VM with Wireshark shows whether it actually opens HTTP sessions to those domains.
Common misconception
Believing static output equals behavior. Static clues are strong leads but not proof. Always validate critical claims with runtime observation.
