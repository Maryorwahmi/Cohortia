Design simple tests
  1. List static indicators with sources (strings, imports).
  2. For each indicator, define a dynamic check (network capture, Procmon filter, debugger step).
  3. Execute the check in an isolated VM and capture logs with timestamps.
  4. Record results and update detection rules or IOCs accordingly.
Concrete example
Static finding: function imports and an embedded URL. Dynamic check: run sample inside VM, capture Wireshark for DNS and HTTP, and filter Procmon for network-related DLL loads. Confirm whether there are matching timestamps and network sessions.
Key takeaway
Small, repeatable tests validate static leads and produce defensible evidence for incident response teams.
