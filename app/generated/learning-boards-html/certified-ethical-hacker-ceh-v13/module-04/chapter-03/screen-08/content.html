Module 4 › Chapter 4.3 › Polymorphic & Stealth
Polymorphic

Code mutation

Changes its binary signature by encrypting and altering its decryptor, defeating simple signature matching.

Defender action
Deploy heuristics and behavioral analytics that detect self-modification and suspicious routines.
Stealth

Hiding from scanners

Intercepts system calls to show an uninfected version of a file when scanned, delaying detection.

Defender action
Use kernel-level integrity checks and out-of-band verification to reveal inconsistencies.
