Module 4 › Chapter 4.3 › Macro Viruses
Mechanism

Embedded macro code

Macro viruses embed in document macros and execute when a user enables macros. Social engineering convinces users to accept the risk.

Scenario
An invoice document urging 'Enable Content' that runs a macro to copy itself to shared drives.
Mitigations
  • Disable macros by default
  • Use email filtering to block risky attachments
  • Run user awareness simulations
Quick checks
Are macros enabled by default? If yes, change policy.
Does email gateway strip dangerous attachments? Validate rules.
Have you run a phishing simulation recently? Use results to guide training.
