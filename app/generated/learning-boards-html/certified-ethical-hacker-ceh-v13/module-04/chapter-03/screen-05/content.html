Module 4 › Chapter 4.3 › What is a computer virus?
Core idea

Attachment and activation

A virus needs a host file or boot sector and a trigger through user action to begin its replication process.

Common effects
  • File corruption or deletion
  • System instability and crashes
  • Backdoors for remote control
Concrete scenario
An infected installer that executes when run and implants itself into other executables on the host.
Key takeaway
Interrupting the user action or scanning files before execution prevents most virus spread.
Lifecycle visual
Attach
Embed in program or document.
Activate
User opens or runs the host.
Replicate
Insert code into other files or boot sectors.
