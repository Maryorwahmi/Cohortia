Setup

Controlled lab scan

Use a Kali or Ubuntu attacker VM and an isolated target VM. Never scan systems without explicit permission.

Example commands
sudo apt update && sudo apt install nmap
nmap <target_ip_address>
nmap -sV <target_ip_address>
nmap -p 445 --script smb-vuln-ms17-010 <target_ip_address>
Use the version and script scans to identify vulnerable services like SMB. If the script reports MS17-010, that host needs urgent patching.
From scan to action
Map open ports to service owners and patch priority.
Close or firewall unnecessary ports to reduce exposure.
Use segmentation to prevent lateral worm spread even if a host is vulnerable.
