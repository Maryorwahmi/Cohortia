Module 4 › Chapter 4.3 › Viruses vs Worms
Definition

Virus

Attaches to host files or boot sector; needs user action for execution and propagation.

Concrete example
An infected Word document that runs when macros are enabled and then infects other documents on shared drives.
Key takeaway
Focus on endpoint controls, file scanning, and user education to prevent execution.
Definition

Worm

Self-replicating program that probes networks and exploits vulnerabilities to spread without human action.

Concrete example
A worm exploiting an SMB vulnerability to copy itself to other hosts and open backdoors automatically.
Common mistake
Treating any spread as a virus; ask whether propagation required user interaction.
