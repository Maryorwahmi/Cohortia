Boot Sector

MBR / Boot Sector infection

These viruses install into the boot record so they run before the operating system. They were more common historically but still require specialized offline remediation when present.

Defensive note
Perform offline boot-sector scans and verify firmware and boot integrity from trusted media.
File Infector

Executable infection

These attach to executables or libraries. When the binary runs, the virus executes and attempts to infect other files on the system.

Concrete example
An infected program that spreads by copying modified executables to shared folders.
Key takeaway
Restrict execution, monitor binary integrity, and use allowlists to reduce risk.
