Module 3 › Chapter 2.5 › Configure proxychains
Edit the config

Open the configuration file with a text editor and add your SOCKS5 proxy in the [ProxyList] section. Comment out default entries to avoid conflicts.

Example snippet
sudo nano /etc/proxychains4.conf # In [ProxyList] section # socks4 127.0.0.1 9050 socks5 185.199.10.1 8080
Important flags
  • Enable proxy_dns to force DNS through the proxy.
  • Use strict_chain for predictable ordering during tests.
Verification steps
Run the following to check your public IP before and after configuring proxychains and to perform a light Nmap connect scan through the chain.
# Check public IP directly curl ifconfig.me # Check public IP via proxychains proxychains curl ifconfig.me # Light Nmap connect scan via proxychains proxychains nmap -sT -p 80,443,22 192.168.1.105
Key Takeaway

Edit, enable proxy_dns, test incrementally, and prefer socks5 for scanning tools needing TCP/UDP support.
