Module 3 › Chapter 2.5 › Nmap via proxychains
Scan types and compatibility

Use -sT for connect scans through proxies because they use normal TCP connections. SYN scans -sS require raw packets and often won’t work through proxies.

Example commands
# Verify your IP via proxy proxychains curl ifconfig.me # Light Nmap connect scan through proxychains proxychains nmap -sT -p 80,443,22 192.168.1.105 # Avoid using -sS through proxies; it may fail proxychains nmap -sS 192.168.1.105
Performance and interpretation
  • Expect higher latency and slower scans; increase timeouts and limit the port set.
  • If a proxy rewrites responses, scan results may be misleading—always verify with out-of-band checks.
  • Document which proxies were in the chain and timestamps to correlate any unexpected behavior.
Check your assumptions

If an expected open port appears closed through a proxy, test directly from a local network to determine if the proxy is filtering.
