Module 3 › Chapter 2.5 › Anonymity Checklist
Operational hierarchy
Environment

Use a dedicated VM or lab network separate from personal devices to avoid cross-contamination of data or identifiers.

Layering

Combine VPNs, proxy chains or Tor where appropriate. Each added layer increases indirection but also adds latency and potential instability.

DNS & Headers

Force DNS through proxies and inspect tool headers to avoid leaking identifiable information such as user-agent strings or resolver data.

Testing

Verify public IPs and DNS resolution before running scans, then run small, targeted scans and inspect results for proxy-induced anomalies.

Common mistakes

Relying on a single untrusted public proxy or forgetting to enable proxy_dns are frequent causes of leaks.

Documentation

Record proxy list, timestamps, IP checks, and any reliability issues for auditability and reproducibility.

Key Takeaway

Anonymity requires deliberate, documented steps: dedicated environment, layered tools, forced DNS, incremental testing, and clear records.
