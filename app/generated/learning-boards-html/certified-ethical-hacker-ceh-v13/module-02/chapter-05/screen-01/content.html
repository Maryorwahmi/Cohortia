Quick orientation

We will compare VPNs, proxy chains, and Tor, then configure a proxychains example suitable for a light Nmap connect scan. Expect increased latency and possibly blocked exit nodes; these are normal trade-offs when adding anonymity layers.

Visual concept
VPN
Encrypted tunnel, single remote IP.
Proxy chain
Multiple proxies for indirection and anonymity.
Tor
Multi-relay anonymity; can be slow or blocked.
