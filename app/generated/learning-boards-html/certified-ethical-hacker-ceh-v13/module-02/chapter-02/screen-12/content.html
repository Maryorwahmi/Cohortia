Module 2 › Chapter 2.2 › Common Mistakes & Safe Practices
Mistake checklist
  • Running overly aggressive scans before inventorying open ports.
  • Not saving scan outputs for reproducibility.
  • Assuming open|filtered means open without follow-up.
# Good initial scan pattern
sudo nmap -sS 192.168.1.105
# After initial results, add version detection and scripting as needed
sudo nmap -sS -sV -O 192.168.1.105
Practice rule
Start small, document findings, and plan escalation. This reduces noise and helps you learn what each scan reveals.
Key Takeaway

Careful sequencing and documentation are as important as selecting the right scan; they protect target availability and produce reliable results.
