Definition

Nmap: network discovery and auditing

Nmap sends probes and interprets responses to reveal listening services, port states, and sometimes versions or operating systems. Use it as a measured reconnaissance platform, not a blunt instrument.

Concrete example
A TCP response on port 80 indicates a web server and should be followed by version detection to identify likely vulnerabilities.
Common misconception
Assuming one scan type fits all. Different scans reveal different information and have different detectability profiles.
Key Takeaway

Treat Nmap as a toolset: choose the scan and options that match your information goal and operational constraints.

Quick start
# SYN scan with version detection and OS fingerprinting (lab)
sudo nmap -sS -sV -O 192.168.1.105
Why record results?
Saving outputs lets you reproduce findings, compare scans run with different flags, and avoid repeating noisy probing against the same target.
