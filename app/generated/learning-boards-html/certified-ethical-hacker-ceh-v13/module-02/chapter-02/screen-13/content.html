Step 1 — SYN scan with detection
sudo nmap -sS -sV -O 192.168.1.105
Save the output and note open TCP ports and any service versions identified. Consider open ports as primary investigation targets.
Step 2 — UDP scan
sudo nmap -sU 192.168.1.105 -p 53,67,68,123,161
Compare timing and note any open|filtered responses that need lab confirmation.
Step 3 — Stealth scans
sudo nmap -sF 192.168.1.105
sudo nmap -sX 192.168.1.105
sudo nmap -sN 192.168.1.105
Compare results to the SYN baseline. If stealth scans report fewer open ports, filtering or IDS behavior may be present.
