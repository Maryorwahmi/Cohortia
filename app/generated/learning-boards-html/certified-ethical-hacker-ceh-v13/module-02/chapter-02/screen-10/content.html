Module 2 › Chapter 2.2 › Version Detection & OS Fingerprinting
What they do

Version detection sends probes designed to elicit service banners and behaviors. OS fingerprinting compares network response characteristics to known stacks to guess the operating system.

sudo nmap -sS -sV -O 192.168.1.100
Concrete example
A detected service like "OpenSSH 7.4p1" points you to known CVEs for that specific version to prioritize follow-up tests.
Misconception
Treat version strings and OS guesses as leads, not absolutes — false positives and obfuscation are possible.
Practice note
Use detection options to triage services, then confirm in a controlled environment before assuming a vulnerability exists.
Key Takeaway

Detection features give you higher-priority targets but require validation; use them to focus effort, not to declare compromise.
