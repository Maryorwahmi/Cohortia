Module 2 › Chapter 2.2 › TCP SYN Scan (half-open)
How it works
  1. Scanner sends SYN to target port.
  2. Open port replies SYN-ACK; scanner sends RST to tear down.
  3. Closed ports reply with RST; no handshake completes.
Concrete command
sudo nmap -sS 192.168.1.100
Misconception
SYN scans are stealthy but not invisible; IDS systems can still detect SYN traffic patterns.
Visual explanation
This area holds a step-by-step callout of the TCP half-open sequence, examples of expected responses, and guidance for when to escalate to a full connect scan for confirmation.

# Expected quick interpretation

Key Takeaway

Use SYN scans for a fast inventory of responsive TCP services, but verify with other scans if detection is critical.
