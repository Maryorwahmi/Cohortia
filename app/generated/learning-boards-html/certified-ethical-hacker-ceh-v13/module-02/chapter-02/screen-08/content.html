Module 2 › Chapter 2.2 › Stealth Scans: FIN, XMAS, NULL
Flag behavior
FIN (-sF)
Sends only FIN. Closed ports reply with RST; open ports often ignore the packet.
NULL (-sN)
Sends no flags. Same RFC behavior: RST for closed, silence for open.
XMAS (-sX)
Sets FIN, PSH, URG. Called Christmas tree for the flags lit up. Silence indicates possible openness under RFC behavior.
Commands
sudo nmap -sF 192.168.1.105
sudo nmap -sX 192.168.1.105
sudo nmap -sN 192.168.1.105
Modern limitation
Stateful firewalls and IDS may detect or drop these probes. Always verify findings with additional scans in a lab.
Key Takeaway

Stealth scans can reveal ports missed by standard probes on legacy stacks but are less reliable on modern networks; validate results carefully.
