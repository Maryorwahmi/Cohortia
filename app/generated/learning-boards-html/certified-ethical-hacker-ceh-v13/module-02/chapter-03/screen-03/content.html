Practical command set
SMB
enum4linux -U <target_ip> | enum4linux -S <target_ip> | enum4linux -a <target_ip>
SNMP
snmpwalk -v1 -c public <target_ip> — look for system descriptions and interfaces
DNS / LDAP / NTP
dig example.com MX | ldapsearch -x -H ldap://<target_ip> -b "dc=example,dc=com" | ntpq -c peers <target_ip>
Documentation habit
  1. Record the exact command and timestamp.
  2. Capture the relevant output lines that indicate users, shares, peers, or allowed transfers.
  3. Note the security implication and one recommended remediation step.
