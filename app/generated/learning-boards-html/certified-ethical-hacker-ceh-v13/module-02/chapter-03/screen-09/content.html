Module 2 › Chapter 2.3 › LDAP Enumeration
Command
ldapsearch -x -H ldap://192.168.1.50 -b "dc=example,dc=com"
If the server allows anonymous binds, this may return user and group entries. Sanitize findings before reporting.
Interpretation
  • Group membership indicates privilege levels and possible escalation paths.
  • User attributes like email or last logon help prioritize targets and social engineering.
  • Disable anonymous binds or return minimal attributes to reduce exposure.
Misconception
LDAP exposure rarely leaks passwords directly, but the directory structure greatly aids targeted attacks.
