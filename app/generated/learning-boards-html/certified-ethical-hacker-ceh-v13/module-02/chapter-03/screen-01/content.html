Network Enumeration

Extract detailed information from services to build an attack map and verify misconfigurations.

In this lesson
SMB, SNMP, DNS, LDAP, NTP
Concept Map
SMB
Shares, users, groups
SNMP
Device info, community strings
DNS
Zone transfer, subdomains
LDAP / NTP
Directory entries, peers
Quick lab commands
enum4linux -U <target_ip>   # list SMB users
snmpwalk -v1 -c public <target_ip> # query SNMP with default community
ldapsearch -x -H ldap://<target_ip> -b "dc=example,dc=com" # LDAP query
ntpq -c peers <target_ip>   # NTP peers
dig example.com MX
