Module 2 › Chapter 2.3 › SNMP Enumeration
Command
snmpwalk -v 1 -c public 192.168.1.1
Look for sysDescr, ifTable, and routing entries. These indicate device model and internal addressing.
Explanation
  • sysDescr may show vendor and OS version — useful to identify known vulnerabilities.
  • ifTable and routing entries reveal internal interfaces and connected networks.
  • Default community strings like public/private allow unauthenticated reads if unchanged.
Misconfiguration
Leaving default community strings enables wide information disclosure. Change them and restrict SNMP access by IP.
