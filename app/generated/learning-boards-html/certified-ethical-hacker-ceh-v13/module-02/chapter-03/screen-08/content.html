Module 2 › Chapter 2.3 › DNS Enumeration
Techniques
MX: dig example.com MX — finds mail servers.
NS: dig example.com NS — lists name servers.
PTR: dig -x 192.168.1.105 — reverse lookup for IP to hostname.
Zone transfer: dig axfr @ns1.example.com example.com — attempt to download the zone.
Interpretation
  • Successful zone transfers expose complete host-to-IP mappings — treat as critical disclosure.
  • Reverse lookups and PTR records can reveal internal naming conventions and help locate internal services.
  • Brute-forcing subdomains can find staging or internal hosts that should not be publicly resolvable.
Key Takeaway
DNS is a mapping resource — misconfigurations here can leak a complete asset inventory.
