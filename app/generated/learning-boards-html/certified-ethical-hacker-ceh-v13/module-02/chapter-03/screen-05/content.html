Module 2 › Chapter 2.3 › SMB Enumeration
Code Walkthrough
# list users
enum4linux -U 192.168.1.105

# list shares
enum4linux -S 192.168.1.105

# full enumeration (noisy)
enum4linux -a 192.168.1.105
Observe returned usernames and share names. Look for anonymous access markers or permissions showing read/write. Note that -a runs many probes and may be detected by defenders.
Explanation and example
  • Output often includes valid usernames. These can seed password guessing or social engineering.
  • Share names may indicate sensitive locations. Prioritize shares with names like backup, finance, or admin.
  • Anonymous share access is a common misconfiguration; it allows reading without credentials.
Key Takeaway
SMB enumeration reveals both account names and shared resources; pair findings with permission checks before assuming access.
