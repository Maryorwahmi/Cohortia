UDP Scans
Connectionless probes that rely on ICMP responses or application replies for inference.
  • ICMP Port Unreachable → typically closed.
  • No response → open or filtered; ambiguous and needs more probing.
  • Application replies (e.g., DNS response) → port open and service present.
Example
A UDP DNS request to port 53 that receives a DNS response confirms the service; an ICMP Port Unreachable confirms it's closed.
Common mistake
Treating a single no-response packet as proof of openness. Always follow up with additional probes and service-specific requests.
Key Takeaway
Expect ambiguity with UDP; use repeated and application-aware probes to confirm port states.
