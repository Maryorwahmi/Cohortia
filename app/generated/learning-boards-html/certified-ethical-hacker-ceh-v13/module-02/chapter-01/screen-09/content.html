Manual Ping Sweep
A simple loop sends a single ICMP echo request per address to see who replies.
for i in $(seq 1 254); do ping -c 1 192.168.1.$i | grep "bytes from" & done
Notes: This sends one ICMP packet per host. Fast but misses hosts that block ICMP. Use only in an authorized lab.
Nmap Host Discovery
Nmap -sn performs host discovery using ARP and other probes; more comprehensive for local networks.
sudo nmap -sn 192.168.1.0/24
Notes: Nmap chooses ARP for local networks and can use TCP probes when ICMP is blocked. Requires appropriate privileges for some probes.
Reflection
Compare outputs: hosts missing from the ping loop but present in Nmap usually indicate ICMP filtering or ARP discovery differences. Document findings and reasons for discrepancies.
