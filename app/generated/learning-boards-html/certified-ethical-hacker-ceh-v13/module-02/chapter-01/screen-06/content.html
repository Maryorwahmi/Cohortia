ICMP Ping Sweeps
Use echo requests to check reachability; be aware of blocking and false negatives.
How it works
Send ICMP Echo Request and wait for Echo Reply. Replies indicate reachable hosts unless blocked.
Misconception
No ICMP reply does not guarantee a host is down. Firewalls or filtering can drop ICMP selectively.
Alternative probes
Use ARP on local networks or TCP pings to common ports when ICMP is blocked.
Example
If ICMP is blocked at a firewall, a TCP ping to port 80 may elicit a response and reveal the host as live.
Key Takeaway
Use ICMP as a first step but verify results with alternate methods when responses are absent.
