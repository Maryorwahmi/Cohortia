Module 2 › Chapter 2.4 › Credentialed vs Uncredentialed Scans
What credentialed scans reveal
  • Installed packages and exact versions.
  • Local configuration and registry settings.
  • Patch levels and presence of vendor fixes.
When to use
Use credentialed scans for internal assessments, compliance checks, and verifying patch application. Ensure explicit authorization and secure credential handling.
Practical guidance
Benefit
Fewer false negatives and more actionable findings.
Risk
Possible system impact from intrusive checks; handle credentials carefully.
Checklist before running credentialed scans
  • Obtain written authorization and define credential scope.
  • Use least-privilege accounts and consider read-only service accounts.
  • Test on non-production systems if possible to ensure safety.
Key Takeaway

Credentialed scans give deeper insight but require authorization and careful handling; match scan depth to risk and scope.
