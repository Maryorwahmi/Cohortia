Module 2 › Chapter 2.4 › False Positives & False Negatives
Definitions & Examples
False positive: scanner reports Apache 2.2.8 vulnerabilities but the server was patched without updating the banner.
False negative: scanner misses a vulnerability because feeds are outdated or deeper probes were not performed.
Mitigations
  • Keep feeds current and schedule updates.
  • Run credentialed scans when authorized to check local patch levels.
  • Use more than one tool and perform manual verification for high-severity findings.
Triage workflow
1. Identify high-impact findings
Focus verification where impact and exposure are highest.
2. Verify
Attempt controlled checks or consult system patch history.
3. Document outcome
Record verification steps whether confirming or dismissing the finding.
Key Takeaway

Plan for verification: reduce false positives to save time and reduce false negatives to avoid missed risks.
