Module 7 › Chapter 7.1 › Hashing: One-way Functions
Core properties
  • Deterministic: same input yields same digest.
  • Pre-image resistance: hard to recover input from digest.
  • Second pre-image resistance: hard to find another input with the same digest.
  • Collision resistance: hard to find two distinct inputs with same digest.
Use case
Integrity verification and password storage
Compare digests to detect tampering and, for passwords, store salted hashes rather than plaintext.
Misuse
Hashing is not encryption
Hashes do not provide confidentiality. Never use hashing when reversible secrecy is required.
Example check
Generate a SHA-256 digest of a file, change a single character, and re-generate the digest to observe the change. This demonstrates sensitivity to any modification.
Key Takeaway

Use collision-resistant hashes for integrity and always salt password hashes to protect against pre-computed attacks.
