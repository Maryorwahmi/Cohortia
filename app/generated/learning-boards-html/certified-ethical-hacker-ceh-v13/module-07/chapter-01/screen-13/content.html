Module 7 › Chapter 7.1 › Implementation Weaknesses
Patterns to detect
Hardcoded secrets
Secrets in source or configs are discoverable and often reused across environments.
Weak randomness
Predictable RNGs reduce key entropy and make keys guessable.
Exposed private keys
Improper file permissions or backups can leak private keys used for signing or decryption.
Certificate validation
Clients that accept invalid or improperly chained certificates enable man-in-the-middle attacks.
Key Takeaway

Implementation faults are common and testable. Find embedded secrets, assess randomness, inspect key storage and certificate handling, and recommend concrete fixes like vaults and stricter validation.
