Module 7 › Chapter 7.1 › Key Management
Key lifecycle map
Generate
Use strong randomness and appropriate key sizes.
Exchange
Use asymmetric handshakes or secure channels to share symmetric keys.
Store
Protect secrets in hardware modules or encrypted vaults with strict access controls.
Rotate
Regularly change keys to limit exposure windows.
Revoke
Have processes to revoke trust when compromise is suspected.
Testing checklist
Locate generation code, examine key storage protection, verify rotation schedules, and confirm a working revocation mechanism. Try to discover private keys using file permissions or accessible backups.
Key Takeaway

Key management is the system-level control that preserves cryptographic guarantees; neglect here breaks everything else.
