Learning Objectives
Progress from explanation to application and mastery.
Bloom: Learn → Understand → Apply → Master
01
Explain cryptographic primitives
Describe symmetric, asymmetric, hashing and signatures and the security goals they serve. Knowing the purpose helps focus testing and mitigation.
VERIFIED COMPETENCY MILESTONE
02
Differentiate algorithm use cases
Identify when to use AES for bulk data, RSA/ECC for exchange and signatures, and SHA family for integrity checks, so you can recommend the right tools.
VERIFIED COMPETENCY MILESTONE
03
Find implementation weaknesses
Locate insecure key storage, deprecated algorithms, or missing salt, and understand how those faults enable attacks in practice.
VERIFIED COMPETENCY MILESTONE
04
Understand key management
Explain generation, exchange, storage, rotation and revocation practices and why failures here break cryptographic guarantees.
VERIFIED COMPETENCY MILESTONE
