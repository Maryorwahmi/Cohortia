Why salts matter
Salting
Add a unique random string to each password before hashing to ensure identical passwords have different digests.
Slow hashing
Use bcrypt, scrypt or Argon2 so guessing each password requires substantial time and resources.
Check
Inspect the database for salts stored per user and confirm the hashing algorithm used. Look for plain MD5 or unsalted SHA variants as a vulnerability.
Key Takeaway

Unique salts and slow hashing functions together make pre-computed and brute-force attacks far less effective.
