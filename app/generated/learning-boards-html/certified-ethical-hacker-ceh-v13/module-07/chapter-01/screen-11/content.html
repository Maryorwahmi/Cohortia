Module 7 › Chapter 7.1 › Practical: openssl hashing
Step-by-step commands
echo "This is a test file for cryptographic hashing." > test_file.txt
openssl dgst -md5 test_file.txt
openssl dgst -sha256 test_file.txt
openssl dgst -sha512 test_file.txt

# Modify file
echo "This is a slightly modified test file for cryptographic hashing." > test_file.txt
openssl dgst -sha256 test_file.txt
Explanation
The commands compute digests using different algorithms. Observing the change after modification proves that even a small edit alters the digest drastically. Remember MD5 is shown for demonstration but is not recommended for security-critical use.
Key Takeaway

Recomputing file digests is a simple and reliable way to demonstrate file integrity and tampering during an assessment.
