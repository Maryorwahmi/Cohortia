Definition › Brute-Force Attacks

How brute-force works

An exhaustive trial of every possible secret until a match is found. The cost is determined by the size of the search space.

Estimate search space
Calculate the number of possible values from length and character set to understand feasibility.
Prefer offline testing
Crack captured hashes in a lab or controlled environment, not against production logins.
Key Takeaway

Use brute-force tests to validate complexity and throttling; for strong keys, focus on other attack surfaces.

Process steps

  1. Define target scope and get authorization.
  2. Gather constraints: length limits and allowed characters.
  3. Estimate search space and decide if offline cracking is needed.
  4. Run controlled attempts and report time-to-compromise and mitigations.
Concrete example
Testing a forgotten device PIN in a lab: if the PIN is four digits, the search space is small and a brute-force simulation shows the need for lockout or biometric fallback.
Common mistake
Running high-volume online brute-force against production logins without throttling or explicit consent; this risks service disruption and ethical violations.
