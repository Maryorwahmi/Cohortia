Learning Objectives

These objectives focus on practical recognition, ethical use of cracking tools, and actionable defenses you can recommend or implement.

Bloom: Learn → Understand → Apply → Master
01 Identify
Categorize common cryptographic attacks

You will name brute-force, dictionary, rainbow table and known-plaintext attacks and explain the typical weakness each exploits.

Verified Competency Milestone
02 Understand
Principles behind cryptographic weaknesses

You will explain how poor key length, missing salts, or predictable plaintext enable attacks without needing math-level breaks.

Verified Competency Milestone
03 Apply
Use Hashcat and John for ethical testing

You will run controlled, authorized tests that validate whether password policies, salts, and key management hold up under attack.

Verified Competency Milestone
04 Master
Recommend best practices to reduce exposure

You will propose practical defenses like salting, key rotation, rate-limiting and improved key management to reduce attack surface.

Verified Competency Milestone
