Skills & Evidence

This page emphasizes how you prove competence: correct test selection, safe execution, and clear remediation guidance.

Milestone-focused
Test selection

Match observable artifacts — unsalted hashes, short secrets, or known plaintext — to the optimal attack method. Choosing the right test saves time and reduces risk.

Safe execution

Use non-destructive options, keep backups, and prefer offline testing where possible. Always operate inside a signed scope of engagement.

Documentation

Record the hash type, the method used, sample cracked items, and reproducible steps so others can validate and remediate the issue.

Remediation

Translate results into prioritized fixes such as adding salts, increasing key length, or improving password policy and key rotation.

Practical mnemonic
Observe → Select → Test → Document → Remediate. This sequence keeps testing efficient, ethical, and action-oriented.
