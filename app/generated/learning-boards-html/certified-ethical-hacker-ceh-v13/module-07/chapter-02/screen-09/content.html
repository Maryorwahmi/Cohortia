Definition › Password-Cracking Tools Overview

What these tools do

Provide engines for offline attacks: brute-force, dictionary, hybrid, and rule-based transformations across many hash formats.

Hash identification
Identify the hash type before testing so you can select the correct attack mode and prevent wasted effort.
Document hardware
Note whether GPU acceleration was used; performance affects your time-to-compromise estimates and recommendations.
Key Takeaway

Tools are enablers; success depends on correct format identification, sane wordlists, and ethical execution within scope.
