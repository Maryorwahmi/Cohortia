XSS explained

An attacker injects JavaScript that runs in other users’ browsers, leveraging the site’s trust. This can enable data theft, persistent defacement, or phishing redirects.

Attack surfaces
  • URL parameters and fragments
  • Form input and search fields
  • Stored content such as comments or uploaded files
Example payload (display only)
<script>alert('XSS Reflected!');</script>
That alert is a simple proof of concept. Real attackers use scripts to exfiltrate cookies or perform actions on behalf of the user. Proper output encoding prevents the browser from interpreting these characters as executable code.
