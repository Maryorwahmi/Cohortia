-- Adjust NULL placeholders to match the number of columns required by the original query.
When the application prints query rows, the UNION SELECT row appears among results, exposing server details. If the column count is wrong, an error may appear, which can still be useful.
Practical advice
  • Enumerate column count carefully or use tools that do it automatically.
  • Use harmless queries to confirm you can see union rows before extracting sensitive data.
  • Remember to operate only on authorized test targets like DVWA.
Common mistake

Attempting a UNION SELECT without matching column types or count will raise immediate errors; use incremental discovery first.
