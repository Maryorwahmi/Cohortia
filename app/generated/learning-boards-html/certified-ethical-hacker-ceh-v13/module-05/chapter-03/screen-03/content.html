Module 5 › Chapter 5.3 › Practical Objectives
Lab Action
Reproduce the vulnerability

Use DVWA at low security to run payloads that reveal rows, errors, or timing differences and keep detailed notes of each observed response.

Remediation
Fix and validate

Apply parameterized queries or encoding, then re-run proofs to confirm the app no longer treats input as code.

Reporting
Describe and prioritize

Document vulnerable endpoints, payloads used, impact, and the recommended server-side mitigations in clear steps for developers.
