SQL Injection & XSS
Understand how input becomes executable and how to defend both server and client sides.
In this lesson

You’ll see a vulnerable SQL query exploited, learn in-band, error-based and blind techniques, then explore reflected, stored and DOM XSS. Practical DVWA steps show how to test and how to fix vulnerabilities with parameterized queries and output encoding.

SQLi
Data as code

Injecting SQL into inputs to change queries and extract data.

XSS
Client-side scripts

Injecting JavaScript that runs in other users’ browsers.

Defense
Parameterize & Encode

Prepared statements and output encoding separate code and data.
