Module 5 › Chapter 5.3 › What is SQL Injection?
Definition and claim

SQL Injection is when user input changes the intended SQL command. Treating input as code lets attackers read or modify data, bypass auth, or run administrative SQL.

Why this matters
  • Compromise confidentiality by extracting database rows.
  • Possibly escalate privileges or alter data.
  • Authentication bypass can lead to account takeover.
Key Takeaway

If input can change query structure, the attacker controls what the database does. Prevent this by keeping code and data separate.

Concrete example (lab-ready)
-- Vulnerable pseudo-query shown for study
SELECT * FROM users WHERE username = '<user_input>' AND password = '<password_input>';

Misconception check: Length limits or hiding error messages alone do not remove the vulnerability. The fix must ensure the input cannot change the SQL grammar.
