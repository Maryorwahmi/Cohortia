Boolean-based blind

Inject conditions that change the application output when true. Use repeated checks to reconstruct values one character at a time.

Example workflow:
  1. Establish a baseline response for a normal request.
  2. Test a conditional payload that toggles visible content when true.
  3. Iterate over positions and characters to reconstruct the target string.
Time-based blind

Inject conditions that cause the database to pause when true. Measure response time differences to infer truth values when no content changes occur.

Testing tip:

Measure the server’s typical latency first, then choose a sleep duration that stands out from normal fluctuations to avoid false positives.

Common mistake

Not accounting for caching or network jitter when measuring timing. Repeat each timing test multiple times and use averages to reduce noise.
