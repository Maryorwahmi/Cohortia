Module 5 › Chapter 5.3 › SQLi Types
In-band SQLi

The attacker injects and receives data on the same channel. Useful when query results appear in the response. Union queries often extract columns directly.

Signal: rows in response
Error-based SQLi

The attacker forces database errors to reveal structure or values. Dangerous when error details are shown to users. Errors can include table names, column names, or fragments of data.

Signal: SQL error text in page
Blind SQLi

The application does not return data or errors, so attackers infer bits of data via boolean responses or response timing. This is slower but effective against constrained applications.

Signal: subtle response differences or delays
Common mistake

Assuming no visible output means no SQLi. Blind techniques exist to extract information even from silent endpoints. Always observe timing and boolean behavior during tests.
