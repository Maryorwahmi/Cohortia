Module 5 › Chapter 5.3 › DVWA Lab Steps
SQLi Exercises
  1. Set DVWA security to Low and open SQL Injection.
  2. Submit a numeric id to observe normal behavior, then try an input that causes SQL errors.
  3. Test an authentication bypass payload and a UNION SELECT to extract visible values.
XSS Exercises
  1. Use Reflected XSS page to submit a script tag and observe the alert as proof of concept.
  2. Use Stored XSS guestbook to store a script and view it executing for other visits.
  3. After testing, implement parameterized queries and output encoding, then re-test to confirm closure.
Safety reminder

Only test on authorized vulnerable targets such as DVWA. Never perform these tests against live production systems without permission.
