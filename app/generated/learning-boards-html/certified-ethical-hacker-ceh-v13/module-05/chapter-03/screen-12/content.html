Module 5 › Chapter 5.3 › Mitigations
Parameterized Queries

Bind inputs as parameters so the database treats them as values and not executable SQL. This eliminates the root cause of SQLi.

Output Encoding

Escape special characters before inserting user data into HTML. Use the correct encoding for HTML body, attributes, or JavaScript contexts.

Content Security Policy

Add CSP headers to restrict allowed script sources and prevent inline script execution, reducing the impact of injected scripts.

Validation and testing

Validation narrows accepted formats but should not substitute for parameterization or encoding. After fixes, re-run your proof-of-concept payloads to confirm closure.
