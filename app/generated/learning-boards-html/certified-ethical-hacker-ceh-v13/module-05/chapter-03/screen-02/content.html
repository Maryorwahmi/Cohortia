Module 5 › Chapter 5.3 › Learning Objectives
Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Explain SQL Injection

Describe how concatenating user input into SQL queries turns data into executable code and why that matters for confidentiality and authentication. You will give an example login bypass and explain the vulnerable pattern.

Verified Competency Milestone
02
Identify XSS types

Differentiate reflected, stored and DOM-based XSS, with examples showing how a script can be reflected by the server, stored in a database, or generated on the client-side and why each needs a different test approach.

Verified Competency Milestone
03
Construct safe payloads in lab

Run controlled tests on DVWA to demonstrate authentication bypass, error-based data leaks, and simple XSS alerts. Record the app response changes and reflect on why they happen.

Verified Competency Milestone
04
Apply mitigations

Implement parameterized queries or ORMs and enforce output encoding and a Content Security Policy. Explain why these stop injection and which mistakes still leave gaps.

Verified Competency Milestone
