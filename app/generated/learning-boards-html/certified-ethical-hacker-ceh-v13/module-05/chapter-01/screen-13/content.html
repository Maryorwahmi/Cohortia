Module 5 › Chapter 5.1 › Web vs App Server
Web Server
Serves static assets, manages TLS, and routes requests. Check for exposed directories and default pages.
Common issues
Directory listing enabled, misconfigured proxy, or outdated server banners that reveal versions.
Application Server
Executes dynamic code, enforces business rules, and queries databases. Look for debug endpoints and verbose errors.
Common issues
Exposed admin consoles, unsafe default configs, and unhandled exceptions that leak stack traces.
Key Takeaway

Identify whether an issue stems from server configuration or application logic to prescribe an accurate fix.

Pro Tip
Examine response headers, default pages, and any exposed management endpoints to determine the responsible layer.
