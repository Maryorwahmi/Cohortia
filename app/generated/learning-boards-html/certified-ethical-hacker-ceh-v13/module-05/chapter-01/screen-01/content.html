Web Application Concepts and Threats
A practical introduction to how browsers, servers, and databases interact — and where vulnerabilities appear.
In this lesson

You will learn architecture, HTTP behavior, threat categories, and a short hands-on inspection activity using browser developer tools.

Why it matters

Finding a vulnerability depends on understanding where data flows and which components enforce security. This knowledge guides effective testing.

Client-Server Flow
Requests, responses, and state mechanisms such as cookies and sessions.
HTTP vs HTTPS
Transport encryption protects data in transit but not application logic.
Threat Categories
Injection, XSS, broken auth, IDOR, misconfigurations and data exposure.

Database
