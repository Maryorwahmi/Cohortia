Module 5 › Chapter 5.1 › DevTools — Network
Step-by-step
  1. Open browser developer tools and select the Network tab.
  2. Refresh the page to capture requests; click the main document request to inspect headers and status.
  3. Submit a login form and inspect the new POST request's Payload or Form Data.
  4. Check response headers for Set-Cookie and note flags like Secure and HttpOnly.
Example Payload
POST /login HTTP/1.1
Content-Type: application/x-www-form-urlencoded

username=test&password=test
What to observe
  • Request Method and URL to identify the endpoint.
  • Request and Response Headers for authentication and cookies.
  • Response status codes and payloads to detect errors or leakage.
Ethical note
Perform these actions only on sites you control or have explicit permission to test.
Key Takeaway

A captured request with headers and payload is reliable evidence for reporting and helps pinpoint where defenses are missing.
