What is Injection?

When user-controlled data is interpreted as code or part of a query, allowing an attacker to change the intended command.

Example — vulnerable query
query = "SELECT * FROM users WHERE username = '" + input + "'"
Defense
Use parameterized queries or prepared statements so input is treated as data, not code.
Testing & Misconceptions
Not all injection payloads are complex; often unescaped quotes or special characters reveal vulnerabilities.
Where to test
Fields that interact with databases, system commands, or interpreters. Try boundary characters and parameterized attempts.
Common mistake
Assuming length checks or client-side validation prevent injection — they do not if server concatenates input into queries.
Key Takeaway

If input reaches an interpreter, ensure it is passed safely as data. Parameterize queries to prevent injection.
