Process Flow

Nikto: quick reconnaissance

Run a single-host scan to enumerate server information and common misconfigurations; treat results as leads, not confirmed exploits.

Safety Reminder

Only scan systems you own or have explicit authorization to test. Scanning without permission can be considered hostile.

Key Takeaway

Nikto provides fast discovery of potential misconfigurations and outdated components for further manual analysis.

Command and sample output
# Example Nikto commands
nikto -h http://192.168.1.100
nikto -h http://testphp.vulnweb.com

# Typical output lines to review
+ Server: Apache/2.4.41 (Ubuntu)
+ The X-XSS-Protection header is not set
+ /admin/    Possible admin directory found
+ VULNERABILITY: Outdated server component: libX v1.2.3
Analyze output

Note server banners, missing headers, interesting directories, and any VULNERABILITY or WARNING lines.

Follow-up

Verify findings manually to confirm impact and avoid false positives before reporting.
