Core Concept

Cryptographic Failures

Issues resulting from insufficient, incorrect, or missing cryptography that lead to sensitive data exposure.

Example

Payment or PII sent over unencrypted HTTP, or passwords stored with outdated hash functions.

Checks to run
  • TLS enforcement and valid certificates.
  • Strong password hashing with salt.
  • Proper key storage and rotation policies.
Misconceptions and takeaway
Misconception

Assuming any encryption or hashing is sufficient without checking algorithm strength or key handling.

Key Takeaway

Confirm both presence and correctness of cryptography; examine algorithms, configuration, and key management.

Pro tip

Look for cleartext secrets in configuration files and headers that indicate weak protection.
