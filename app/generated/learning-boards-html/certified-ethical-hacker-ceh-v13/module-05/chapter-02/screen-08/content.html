Core Concept

Injection

When untrusted data is interpreted as part of a command, query, or expression, altering program behavior.

Example

A crafted input that changes a SQL WHERE clause to return all rows instead of one.

Where to check

Forms, API parameters, cookies, headers, file inputs—any data reaching an interpreter.

Testing approach
Scanner results

Use scanners to find obvious injection points, then manually confirm and measure impact.

Common Mistake

Assuming that encoding input equals safe handling—parameterization is the reliable defense.

Key Takeaway

Confirm that input reaching interpreters is parameterized or safely handled; don't rely solely on scanners.
