Definition

Broken Access Control

Failures to properly enforce what authenticated or unauthenticated users are allowed to access or do.

Concrete example

Changing a numeric ID in the URL to view or delete another user's profile without authorization checks.

Common checks
  • Horizontal access attempts (user-to-user).
  • Vertical privilege escalation (user to admin).
  • Direct endpoint access and hidden API calls.
Common Mistake

Relying on client-side controls for security or assuming obscured IDs are safe.

Test cases and takeaways
IDOR scenario

Try predictable IDs and attempt actions as another user to verify server-side checks.

Key Takeaway

Always enforce authorization on the server for each sensitive resource and action.

Pro tip

Document each endpoint's expected permissions and verify them systematically during testing.
