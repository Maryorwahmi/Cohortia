Exploiting Session Hijacking via Cookie Manipulation

Follow these steps in an isolated lab to demonstrate cookie-based session takeover.

Step-by-step checklist
  1. 1. Log in as admin and capture the Set-Cookie header in Burp HTTP history.
  2. 2. Log in as guest and capture that token as well.
  3. 3. Open a clean browser session and set admin token manually in cookies.
  4. 4. Reload the site and confirm admin access.
Reporting evidence
Include the captured Set-Cookie with the token, the modified cookie value you injected, and screenshots or server responses proving elevated access. Note whether the token expired or was rotated by the server.
Key Takeaway

Server-side token validation and rotation stop cookie-based hijacks; client-side deletion alone is insufficient.
