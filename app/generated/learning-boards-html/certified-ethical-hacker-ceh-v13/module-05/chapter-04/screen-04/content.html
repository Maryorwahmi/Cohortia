What is Broken Authentication?

Flaws that allow attackers to assume another user's identity or bypass login protections.

Detailed definition
  • Weak password policies enable brute-force and credential stuffing.
  • Predictable or sequential reset tokens allow unauthorized resets.
  • Verbose errors enable username enumeration.
  • MFA absence converts a leaked password into full account access.
Concrete example
If a reset endpoint returns token values like token=1, token=2, an attacker can iterate values until a valid reset link works.
Testing pattern
# Example manual test with Burp
# 1. Request a reset for a known user
# 2. Capture the reset link and note the token
# 3. Increment the token value and request the link
# 4. Observe whether other tokens succeed
Key Takeaway

Treat reset tokens as secrets: make them long, random, single-use, and short-lived.
