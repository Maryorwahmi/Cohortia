Practical and testing objectives

What you must be able to do in a lab and how to report it responsibly.

Use Burp Repeater & Intruder
Intercept, modify, and replay requests to validate IDOR and authentication weaknesses. Repeater proves authorization gaps; Intruder helps test password strength at scale.
Safe lab setup
Run DVWA or Juice Shop in an isolated environment and avoid testing live production systems to prevent unintended harm.
Document proof
Capture modified requests and responses that demonstrate the missing server-side checks needed to reproduce the issue.
Recommend fixes
Propose server-side mitigations like random tokens, MFA, secure cookie flags, session rotation, and authorization checks per resource.
