DVWA IDOR and Session Exercises

Follow this controlled sequence to reproduce IDOR and session hijack issues and prepare remediation guidance.

IDOR steps
  1. Set DVWA security to Low and find profile URLs like id=1.
  2. Change id to another value and observe other users' data.
  3. Use Burp Repeater to modify POST body and prove server accepts unauthorized ids.
Session steps
  1. Login as admin, capture Set-Cookie with PHPSESSID in HTTP history.
  2. Login as guest and capture that token too.
  3. Set admin PHPSESSID manually in a clean browser to confirm hijackability.
Always include captured requests and server responses as evidence and recommend server-side fixes.
