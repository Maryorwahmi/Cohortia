Vertical vs Horizontal Privilege Escalation

Different escalation types imply different impacts and tests.

Vertical Privilege Escalation
A low-privileged user accesses high-privilege functionality, such as admin tools. Test by iterating to known admin endpoints and replaying requests with low-privilege credentials to see if the server enforces role checks.
Impact: configuration changes, user management, or deletion of data.
Horizontal Privilege Escalation / IDOR
A user views or edits another user's data by changing identifiers like user_id or file_id. Test by modifying parameters in captured requests and replaying them to check access control.
Impact: exposure of private user data or unauthorized actions on peers' records.
Pro tip

Always confirm authorization on the server for both role and ownership checks; client-side restrictions are not sufficient.
