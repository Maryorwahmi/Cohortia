Key Concepts — Part 2

Quick references you will use in testing and reporting.

Burp Intruder
Automates repeated requests for brute-force and credential stuffing tests.
Burp Repeater
Modify and replay single HTTP requests to verify access control logic.
HttpOnly & Secure
Cookie flags that reduce script access and ensure cookies travel only over HTTPS.
Credential Stuffing
Reusing leaked credentials against other systems; mitigated with MFA and rate limits.
Session Hijacking
When an attacker obtains a valid session token and reuses it to impersonate a user.
Session Fixation
Attacker forces victim to use a known session id; rotating IDs at login prevents it.
Bottom line

Use the right tool for evidence, and pair each finding with the precise server-side mitigation that closes the gap.
