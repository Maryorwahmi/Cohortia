Using Burp Intruder for Brute-Force and Credential Stuffing

Automate login attempts in a lab to test password strength and reuse of leaked credentials.

Safe Intruder setup
Run against a lab instance, limit request rate, and use targeted credential lists. Monitor for Set-Cookie responses to identify successful logins.
Confirm success by observing an authenticated response rather than relying only on content-length differences.
Defenses and reporting
Recommend rate limiting, progressive delays, MFA, and account lockout. Provide the exact successful request and response as evidence when a credential pair works.
Common mistake

Running Intruder against production systems or not throttling requests can cause service disruption and legal issues.
