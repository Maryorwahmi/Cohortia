Module 6 › Chapter 5.6 › Dynamic Analysis Workflow
Process
Steps to follow
1. Static map
Identify endpoints, secrets, and exported components to target dynamically.
2. Configure proxy
Set emulator proxy and install CA cert to capture traffic when allowed.
3. Instrument
Use Frida to disable pinning or root checks when necessary.
4. Verify & document
Replay requests, confirm impact, and capture reproducible evidence.
Example

After discovering a staging endpoint, you set a proxy, try a request, encounter pinning error, run Frida to bypass pinning, then successfully intercept and replay the request to test server validation.

Common mistake

Starting dynamic tests without a static scan leads to unfocused instrumentation and overlooked code paths.
