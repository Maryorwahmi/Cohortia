Practical checks
  • Extract AndroidManifest and identify exported components and permission requests.
  • Decompile code to find one hardcoded endpoint or credential in resources.
  • Configure a proxy and verify one intercepted HTTPS call after bypassing pinning.
  • Use ADB to list installed packages, pull one file, and read a logcat entry that contains a debug message.
Pro tip

Document commands and environment details for reproducible tests — include emulator ABI, OS image, and Frida version.

Ethics

Always obtain written authorization, limit tests to in-scope apps or test instances, and avoid extracting or sharing production secrets outside of the report.
