Quick command guide
# Install app
adb install app.apk

# Start a shell and inspect files
adb shell
ls /data/data/com.example.app/

# Pull a file
adb pull /data/data/com.example.app/databases/app.db ./

# View logs
adb logcat | grep -i ssl
Example use

Pull the app's preferences or database to validate whether sensitive data is stored unencrypted at rest.

Common mistake

Assuming production apps allow access to /data without proper permissions. Use emulators or authorized test devices where you control the environment.
