Module 6 › Chapter 5.6 › Static Analysis
Definition
What static analysis reveals
  • Permissions and exported components in the AndroidManifest.
  • Hardcoded endpoints, API keys, and insecure storage patterns.
  • Obfuscation markers and presence of native libraries that need deeper analysis.
Example workflow
apktool d app.apk jadx-gui app.apk MobSF scan → report
Key Takeaway

Decompile first to narrow dynamic tests and avoid wasted instrumentation effort.

Annotated example
Inspecting AndroidManifest.xml often finds exported Activities or Services with no permission checks. These are immediate high-priority targets for further testing because they can accept external intents or data.
What to look for
  • exported="true" entries
  • uses-permission for dangerous APIs
  • embedded certificate files or keystore references
Common mistake

Relying on a single decompiler. Use both Smali inspection and Java decompilation to reduce false negatives caused by obfuscation.
