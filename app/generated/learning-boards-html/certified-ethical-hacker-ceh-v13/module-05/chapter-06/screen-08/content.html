Comparison
Unpinned app vs Pinned app
Unpinned app
  • Install CA & see requests in Burp
  • Can modify and replay requests
  • Good for testing input validation server-side
Pinned app
  • Refuses proxy even with CA installed
  • Requires instrumentation such as Frida
  • Often implemented via libraries or custom validators
Quick setup snippet
# Configure emulator Wi-Fi or network proxy to your host IP and Burp port # Install Burp CA on the device via Settings → Security → Install certificate
Common mistake

Expecting traffic immediately after proxying; confirm CA installation and app behavior, and inspect logs for handshake errors to detect pinning.
