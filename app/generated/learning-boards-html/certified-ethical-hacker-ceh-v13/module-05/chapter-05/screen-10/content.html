Module 05 › Chapter 5.5 › Sideloading, Tampering, and Repackaging

How tampering happens

  • Extract the APK, modify resources or Smali, repackage and resign, then distribute.
  • On sideloaded devices, users may install such modified packages without official review.
Example test

Repackage a test app with a minor change in a lab. If it runs unchanged, integrity checks are missing.

Defenses
  • Enforce and verify signatures and perform runtime integrity checks.
  • Detect rooted/jailbroken states and limit functionality on compromised devices.
  • Move critical checks to the server where possible to reduce client-side attack surface.
Misconception

Assuming official store distribution eliminates the need for integrity checks is dangerous — apps can still be tampered with off-store or on compromised devices.
