Android/iOS Security Models
Platform openness and sandboxing change attacker options.
Insecure Data Storage
Unencrypted secrets in SharedPreferences, UserDefaults, or files are recoverable.
Insecure Communication
HTTP or poor certificate validation enables interception and tampering.
Summary

Use these quick definitions as a checklist when triaging mobile app security: platform, storage, transport.
