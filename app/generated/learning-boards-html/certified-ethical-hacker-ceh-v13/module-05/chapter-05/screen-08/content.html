Module 05 › Chapter 5.5 › Client-Side Injection & WebView Risks
Threat

Untrusted content executing within the app

WebViews can render HTML and execute scripts. If a developer loads untrusted HTML or enables JavaScript with exposed native bridges, attackers can call native functionality or exfiltrate data.

Local databases that accept unsanitized input can be subject to SQL injection-like behavior or malformed queries that alter logic.

Detection & Fixes
  • Search for WebView usage and inspect whether JavaScript is enabled or interfaces are added.
  • Sanitize HTML and strip or encode dangerous tags before rendering.
  • Prefer native rendering for untrusted data and disable unnecessary WebView features.
Example

A chat app renders user messages as HTML in a WebView and fails to sanitize script tags, enabling content injection.
