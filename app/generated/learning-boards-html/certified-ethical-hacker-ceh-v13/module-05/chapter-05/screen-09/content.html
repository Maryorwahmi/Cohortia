Module 05 › Chapter 5.5 › Reverse Engineering Mobile Apps
What happens

APKs and IPAs contain code and resources that can be decompiled to reveal logic and static strings. These artifacts often expose endpoints, keys, or insecure calls.

Tools
  • apktool: decompile resources and Smali code
  • jadx: decompile to readable Java source
  • MobSF and similar tools: automate static analysis
Mitigation

Avoid hardcoding secrets; move sensitive keys to servers. Use obfuscation and integrity checks to increase attacker effort and add runtime checks for tampering.

Example finding
Found API key in resource strings or Smali: treat as high risk and remove from the binary.
