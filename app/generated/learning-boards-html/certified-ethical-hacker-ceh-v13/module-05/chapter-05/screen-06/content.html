Module 05 › Chapter 5.5 › Insecure Communication and MitM
Threat

Eavesdropping and tampering via weak TLS or HTTP

Test whether the app uses HTTPS and whether it properly validates server certificates. If it accepts any certificate, a MitM can intercept and modify requests.

An app that downloads content or updates over HTTP risks update injection and remote code/data manipulation.

Mitigation
  • Enforce HTTPS for all endpoints and resources.
  • Perform strict certificate validation and prefer certificate pinning when appropriate.
  • Plan certificate rotation to avoid service disruption with pinning.
Quick check
# In a controlled lab, use an intercepting proxy to test if traffic is visible
# If the app trusts the proxy certificate and you can read JSON responses, validation fails.
Misconception

Simply using HTTPS is not enough if the app bypasses certificate checks. Validation matters as much as encryption.
