Module 05 › Chapter 5.5 › APK Analysis: apktool + jadx Workflow
Workflow
  1. Decompile APK with apktool to inspect AndroidManifest and Smali resources.
  2. Run JADX to generate readable Java-like source for tracing logic paths.
  3. Use grep to search decompiled directories for keywords like password, api_key, SharedPreferences.
  4. Trace where found strings are used to assess impact and exploitability.
Safe lab note

Perform these steps only on authorized apps and isolated machines to avoid accidental misuse of extracted secrets.

Terminal preview
apktool d insecure_app.apk -o insecure_app_decompiled
jadx -d insecure_app_java_src insecure_app.apk
grep -r "getSharedPreferences" insecure_app_decompiled/
grep -r "api_key\|password\|secret" insecure_app_decompiled/
Example finding

A literal API key in resources used directly in HTTP requests is high risk; recommend removal and server-side key handling.
