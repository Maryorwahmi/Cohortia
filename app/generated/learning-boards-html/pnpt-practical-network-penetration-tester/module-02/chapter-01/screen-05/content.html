What is DNS?

The Domain Name System (DNS) is a hierarchical and decentralized naming system for computers, services, or any resource connected to the Internet or a private network. It translates human-readable domain names into numerical IP addresses.

  • Acts as the 'phonebook' of the internet.
  • Essential for connecting domain names to server IP addresses.
  • Distributed database, making it resilient and scalable.
  • Can inadvertently expose network structure.
Why Query DNS?

Querying DNS records helps uncover subdomains, mail servers, and name servers, which can reveal a target's infrastructure and potential attack vectors.

Common DNS Record Types

A Record

Maps domain to IPv4 address

MX Record

Specifies mail servers

NS Record

Lists authoritative name servers

TXT Record

Stores arbitrary text data

Pro Tip

Always enumerate extensively; subdomains often reveal different IP ranges or less-secure configurations than the primary domain.
