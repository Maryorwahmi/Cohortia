What is WHOIS?

WHOIS is a protocol used to query databases that store information about registered domain names and IP address blocks. It's a public record of who owns a particular internet resource.

  • Provides registrant's name, organization, address, email, and phone.
  • Can reveal domain creation, update, and expiration dates.
  • Useful for identifying potential social engineering targets.
  • Information can be obscured by privacy protection services.
Key Information Revealed

Registrant contact details, administrative contacts, technical contacts, and domain lifecycle dates.

Terminal Demo: WHOIS Query
$ whois example.com

Domain Name: EXAMPLE.COM
Registry Domain ID: 2368900_DOMAIN_COM-VRSN
Registrar WHOIS Server: whois.iana.org
Registrar URL: http://www.iana.org
Updated Date: 2023-08-14T07:00:00Z
Creation Date: 1995-08-14T04:00:00Z
Registry Expiry Date: 2024-08-13T04:00:00Z
Registrar: IANA
Registrar IANA ID: 376
Domain Status: clientDeleteProhibited https://icann.org/epp#clientDeleteProhibited
Domain Status: clientTransferProhibited https://icann.org/epp#clientTransferProhibited
Name Server: NS.EXAMPLE.COM
Name Server: NS.EXAMPLE.NET

URL of the ICANN Whois Inaccuracy Complaint Form: https://www.icann.org/wicf/

Output Interpretation

The output shows creation and expiry dates, registrar, and name servers. For real targets, you'd look for registrant contact info (email, phone, address).
