`nslookup` & `host` Overview

These tools provide alternative methods for DNS enumeration. `nslookup` is widely available on Windows, while `host` offers a quick and concise way to retrieve multiple record types.

  • `nslookup`: Interactive and non-interactive modes, common on Windows.
  • `host`: Simple utility for quick lookups, efficient for multiple record types.
  • Both query DNS to resolve domain names to IP addresses and vice versa.
  • Useful for cross-referencing information obtained from `dig`.
When to Use

Use `nslookup` for Windows environments or when `dig` is not available. Use `host` for rapid, multi-record lookups.

Terminal Demo: `nslookup` & `host`
$ nslookup example.com

Server:         127.0.0.53
Address:        127.0.0.53#53

Non-authoritative answer:
Name:   example.com
Address: 93.184.216.34

$ host example.com

example.com has address 93.184.216.34
example.com mail is handled by 0 .
example.com mail is handled by 10 mail.example.com.
example.com name server ns1.example.com.
example.com name server ns2.example.com.
Output Interpretation

nslookup provides the IP address. host gives a concise summary of A, MX, and NS records, showing the IP, mail servers, and name servers.
