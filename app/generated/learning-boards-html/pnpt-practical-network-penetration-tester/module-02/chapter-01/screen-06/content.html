The `dig` Command

`dig` (Domain Information Groper) is a flexible command-line tool for interrogating DNS name servers. It performs DNS lookups and displays the answers that are returned from the name servers that were queried.

  • Primarily used for network troubleshooting and reconnaissance.
  • Provides detailed information about DNS records.
  • Often preferred for its clear and structured output.
  • Available on most Unix-like operating systems.
Key Use Case

Identify the primary IPv4 address (A record) of a target domain to map its public-facing infrastructure.

Terminal Demo: Querying A Record
$ dig example.com A

; <<>> DiG 9.16.1-Ubuntu <<>> example.com A
;; global options: +cmd
;; Got answer:
;; ->>HEADER<<- opcode: QUERY, status: NOERROR, id: 12345
;; flags: qr rd ra; QUERY: 1, ANSWER: 1, AUTHORITY: 0, ADDITIONAL: 1

;; OPT PSEUDOSECTION:
; EDNS: version: 0, flags:; udp: 65494
;; QUESTION SECTION:
;example.com.                  IN      A

;; ANSWER SECTION:
example.com.          86400   IN      A       93.184.216.34

;; Query time: 23 msec
;; SERVER: 127.0.0.53#53(127.0.0.53)
;; WHEN: Mon Oct 26 10:00:00 UTC 2023
;; MSG SIZE  rcvd: 55
Output Interpretation

The ANSWER SECTION clearly shows example.com maps to the IPv4 address 93.184.216.34. This is the public IP of the web server.
