Vulnerability Type

Weak Credentials: An Easy Entry

Exploiting default, guessable, or reused usernames and passwords.

Default Passwords: Many devices and applications ship with easily known default credentials that are often left unchanged.

Guessable & Reused: Simple passwords or those reused across services are vulnerable to dictionary attacks and credential stuffing.

Attack Vectors: Brute-forcing login portals (SSH, FTP, web apps) or credential stuffing using leaked data.

Key Takeaway

Always check for weak credentials first; they are a common and straightforward path to initial access.

Example Scenario

Brute-Forcing an SSH Login

# Using Hydra to brute-force SSH
hydra -L users.txt -P passwords.txt ssh://192.168.1.10

An attacker might use a tool like Hydra with lists of common usernames (users.txt) and passwords (passwords.txt) to try and guess the SSH login credentials for a target system at 192.168.1.10.

User List

admin, root, user, test

Password List

password, 123456, welcome

Common Misconception

"My password is too complex to guess."

While complexity helps, password reuse across different services or exposure in data breaches can still compromise even strong passwords. Unique passwords for each service are crucial.
