Vulnerability Type

Unpatched Software & Misconfigurations

Exploiting known flaws in outdated services and insecure system setups.

Unpatched Software: Outdated applications or OS with known, unaddressed security vulnerabilities (e.g., old web servers, FTP daemons).

Misconfigurations: Insecure system setups, such as publicly exposed admin interfaces, open shares, or weak file permissions.

Correlation is Key: Match reconnaissance findings (service versions, open ports) with known CVEs and attack patterns.

Key Takeaway

Outdated software and insecure configurations are prime targets; always cross-reference identified services with known vulnerabilities.
