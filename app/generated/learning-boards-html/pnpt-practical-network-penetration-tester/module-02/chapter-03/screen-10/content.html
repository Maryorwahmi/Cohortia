Metasploit Workflow

Basic Usage: Search and Use

Finding and selecting the right exploit module within Metasploit.

Launch `msfconsole`: Start the Metasploit console to begin your exploitation session.

`search` for Exploit: Use keywords (e.g., `search vsftpd`) to find relevant modules for your identified vulnerability.

`use` the Module: Load the selected exploit module (e.g., `use exploit/unix/ftp/vsftpd_234_backdoor`) to prepare it for configuration.

Key Takeaway

The `search` and `use` commands are your first steps in Metasploit to identify and load the appropriate exploit module.

Terminal Walkthrough

Searching for `vsftpd` Exploits

msfconsole
msf6 > search vsftpd

Matching Modules
================

   #  Name                                     Disclosure Date  Rank       Check  Description

msf6 > use exploit/unix/ftp/vsftpd_234_backdoor
msf6 exploit(unix/ftp/vsftpd_234_backdoor) >

Command 1: msfconsole - Launches the Metasploit Framework console.

Command 2: search vsftpd - Lists modules related to 'vsftpd'.

Command 3: use exploit/unix/ftp/vsftpd_234_backdoor - Selects the identified exploit module.
