Service Version Detection (`-sV`)

Identifying Specific Software and Their Vulnerabilities

`-sV` Flag

Instructs Nmap to attempt to determine the service and version number running on open ports.

Vulnerability Mapping

Specific versions are often tied to known vulnerabilities (CVEs), providing actionable intelligence.

Practical Example

Scanning for Service Versions

nmap -sS -sV 192.168.1.100
  • •`-sS`: Performs a stealthy SYN scan.
  • •`-sV`: Attempts to detect service versions on open ports.
  • •Output: Reveals services like 'Apache HTTP Server 2.4.X' or 'OpenSSH 7.X'.
Key Takeaway

Service version detection with Nmap's `-sV` flag is crucial for identifying specific software vulnerabilities, transforming basic port data into actionable exploit intelligence.
