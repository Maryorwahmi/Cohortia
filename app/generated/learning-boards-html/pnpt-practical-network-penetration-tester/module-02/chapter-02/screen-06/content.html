TCP SYN Scan (`-sS`): The Stealthy Approach

Performing a 'Half-Open' Scan to Minimize Detection

Half-Open Connection

Sends SYN, receives SYN/ACK, then sends RST without completing handshake.

Faster & Stealthier

Less likely to be logged by target systems compared to a full TCP Connect scan.

Example Command

Scanning a Subnet with SYN

nmap -sS 192.168.1.1/24
  • •`-sS`: Specifies a TCP SYN scan.
  • •`192.168.1.1/24`: The target subnet to scan.
  • •Result: Identifies open ports across the entire subnet with minimal footprint.
Key Takeaway

The TCP SYN scan is a fundamental technique for discreetly discovering open ports, leveraging an incomplete handshake to reduce detection risk.
