Key Takeaway

The `search` command helps locate specific exploit modules, and `use` loads them for configuration, ensuring a targeted approach to exploitation.

Steps to Select an Exploit

  1. Launch `msfconsole`: Start the Metasploit Framework console.
  2. Search for Vulnerability: Use `search [CVE_ID/service]` to find relevant modules.
  3. Review Results: Examine module names, ranks, and descriptions for suitability.
  4. Select Module: Use `use [module_path]` to load the chosen exploit.
Pro Tip

Always check the 'Rank' of an exploit (e.g., 'excellent', 'good') as it indicates reliability and potential impact on the target.
