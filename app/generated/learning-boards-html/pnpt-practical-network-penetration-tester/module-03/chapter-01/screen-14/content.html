Key Concepts

Advanced enumeration and visualization tools for deeper internal network insights.

SMB Enumeration

Gathering information about Server Message Block shares, users, and groups, often revealing sensitive data.

Active Directory (AD) Enumeration

Collecting data about users, computers, groups, and trust relationships within an AD domain.

BloodHound & SharpHound

BloodHound visualizes AD attack paths; SharpHound is its data ingestor, collecting relationship data.

Summary Takeaway

Advanced internal reconnaissance leverages SMB and Active Directory enumeration to uncover deep insights, with BloodHound providing critical visualization for identifying complex attack paths and privilege escalation opportunities.
