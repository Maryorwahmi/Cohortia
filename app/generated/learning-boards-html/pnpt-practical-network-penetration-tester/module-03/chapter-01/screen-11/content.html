Advanced Tooling

Mapping Active Directory with BloodHound

Identifying complex privilege escalation and lateral movement paths.

BloodHound's Core Functionality

  • Relationship Visualization: Maps complex relationships within an Active Directory environment.
  • Attack Path Identification: Automatically identifies paths for privilege escalation and lateral movement.
  • Data Ingestors: Uses SharpHound.exe (C#) or SharpHound.ps1 (PowerShell) to collect AD data.
  • Comprehensive Data: Collects user-to-group, group-to-group, administrative privileges, session info, and GPO links.

BloodHound Workflow

1

Collect Data

Run SharpHound.exe -c All on a compromised domain-joined machine.

2

Import to GUI

Import the collected JSON/ZIP file into the BloodHound graphical user interface.

3

Analyze Graph

Query and analyze the generated graph to pinpoint attack paths and vulnerabilities.

Key Takeaway

BloodHound is a powerful visualization tool that transforms raw Active Directory data into actionable attack paths, significantly simplifying the identification of privilege escalation and lateral movement opportunities.
