Enterprise Recon

Beginning Active Directory Enumeration

Finding domain controllers and trust relationships in enterprise networks.

Initial AD Discovery Steps

  • DNS Queries: Use nslookup to find domain controllers by querying SRV records for LDAP services.
  • Domain Trusts: On a compromised Windows host, use nltest /domain_trusts to identify trust relationships between domains.
  • Visible Domains: Use net view /domain to list domains visible from the current machine.
Terminal Demo: AD Discovery
# Find domain controllers via DNS
nslookup -type=SRV _ldap._tcp.dc._msdcs.yourdomain.local

Server:  UnKnown
Address:  192.168.1.1

_ldap._tcp.dc._msdcs.yourdomain.local SRV service location:
          priority       = 0
          weight         = 100
          port           = 389
          svr hostname   = DC01.yourdomain.local

# List domain trusts (from Windows CMD)
nltest /domain_trusts

List of domain trusts:
  YOURDOMAIN.LOCAL (Primary Domain)
  TRUSTEDDOMAIN.LOCAL (Trusted Domain)
The command completed successfully
Key Takeaway

Initial Active Directory enumeration focuses on locating domain controllers and understanding domain trust relationships using DNS queries and built-in Windows tools, providing a foundational map of the AD environment.
