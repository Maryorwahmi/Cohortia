Deep Dive

Querying Active Directory via LDAP

Extracting user, computer, and group information for deeper analysis.

Key Tools for LDAP Enumeration

  • ldapsearch (Linux): Command-line utility for querying LDAP servers. Essential for non-Windows attack boxes.
  • PowerShell Cmdlets (Windows): Get-ADUser, Get-ADComputer, Get-ADGroup provide powerful, granular querying capabilities from domain-joined machines.
  • Information Harvested: Usernames, descriptions, enabled status, group memberships, computer details, and more.
Terminal Demo: LDAP & PowerShell Queries
# ldapsearch for all users (Linux)
ldapsearch -x -H ldap://DC01.yourdomain.local -b "dc=yourdomain,dc=local" "(objectClass=user)" sAMAccountName

# Example Output:
dn: CN=Administrator,CN=Users,DC=yourdomain,DC=local
sAMAccountName: Administrator
...
dn: CN=John Doe,CN=Users,DC=yourdomain,DC=local
sAMAccountName: jdoe

# Get all AD users with properties (PowerShell on Windows)
Get-ADUser -Filter * -Properties * | Select-Object Name, Description, Enabled

Name        Description Enabled
----        ----------- -------
Administrator             True
Guest                     False
jdoe        IT Staff    True
Key Takeaway

Leveraging LDAP queries with tools like ldapsearch or PowerShell cmdlets provides granular access to Active Directory data, enabling the discovery of critical user, computer, and group information for attack planning.
