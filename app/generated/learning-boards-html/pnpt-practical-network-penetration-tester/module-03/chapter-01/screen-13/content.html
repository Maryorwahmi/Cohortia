Key Concepts

Essential terms to remember from this chapter for effective internal reconnaissance.

Host Discovery

The process of identifying active machines on a network segment, typically using tools like ping or nmap -sn.

Port Scanning

The technique of identifying open ports and the services listening on them on target hosts, typically using nmap.

Service Versioning

Determining the specific software and its version running on an open port, crucial for identifying known vulnerabilities.

Summary Takeaway

Effective internal reconnaissance begins with systematically identifying live hosts, scanning for open ports, and accurately determining service versions to build a comprehensive understanding of the target environment.
