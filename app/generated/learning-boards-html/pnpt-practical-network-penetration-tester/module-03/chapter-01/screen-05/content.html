Process Flow

Identifying Live Hosts with Ping and Nmap

Confirming presence on the internal network segment to narrow your focus.

Step-by-Step Host Discovery

01

Initial Ping Scan

Use ping for a quick check, but be aware ICMP can be blocked. It's a basic confirmation.

02

Nmap Ping Scan

Employ nmap -sn for a more robust host discovery across a subnet without port scanning.

03

Identify Live Hosts

Analyze Nmap output to get a list of active IP addresses for further investigation.

Terminal Demo: Nmap Ping Scan
# Ping a single host (basic check)
ping -c 4 192.168.1.100

# Nmap ping scan for live hosts in a subnet
nmap -sn 192.168.1.0/24

Key Takeaway

Nmap's ping scan (-sn) is the preferred method for reliable host discovery across a subnet, providing a list of live targets for subsequent, more detailed scans.
