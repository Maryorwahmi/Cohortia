Key Concepts

What to Remember from Local Privilege Escalation

Local Privilege Escalation (LPE)

The process of increasing access rights from a low-privileged user to a higher-privileged user on a single compromised machine.

Misconfigured Service Permissions

When a service's executable or configuration files have overly permissive access control lists, allowing low-privileged users to modify them.

Unquoted Service Path

A vulnerability where a Windows service's executable path contains spaces and is not enclosed in quotation marks, potentially leading to malicious binary execution.

Summary Takeaway

Mastering these foundational LPE concepts is crucial for identifying and exploiting common vulnerabilities to gain elevated access on compromised systems.
