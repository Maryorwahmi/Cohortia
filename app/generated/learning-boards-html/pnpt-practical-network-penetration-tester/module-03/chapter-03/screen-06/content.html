Initial Enumeration - Linux

Key Commands for Privilege Assessment

User & Group IDs

The id command reveals your current user and group memberships, indicating potential access rights.

Kernel Version

uname -a provides detailed kernel information, essential for finding specific kernel exploits.

Sudo Permissions

sudo -l lists commands the current user can run with root privileges, often without a password.

Terminal Output
user@linux:~$ id
  uid=1000(user) gid=1000(user) groups=1000(user),27(sudo)

user@linux:~$ uname -a
  Linux linux 5.4.0-42-generic #46-Ubuntu SMP Fri Jul 10 00:24:02 UTC 2020 x86_64 x86_64 x86_64 GNU/Linux

user@linux:~$ sudo -l
  Matching Defaults entries for user on linux:
      env_reset, mail_badpass, secure_path=/usr/local/sbin...

  User user may run the following commands on linux:
      (ALL : ALL) NOPASSWD: /usr/bin/find

user@linux:~$ ls -l /etc/passwd
  -rw-r--r-- 1 root root 2345 Apr 10 2023 /etc/passwd
Key Takeaway

On Linux, focus on user permissions, kernel versions, and especially sudo configurations to uncover exploitable paths to root access.
