Kerberoasting Process Flow

Kerberoasting: Exploiting Service Accounts

Kerberoasting targets Service Principal Names (SPNs) registered to user accounts, allowing attackers to extract and crack NTLM hashes of service accounts.

1

Identify SPN

Locate services running under domain user accounts with registered SPNs.

2

Request Service Ticket (TGS)

Request a Kerberos TGS for the identified SPN from the Domain Controller.

3

Extract Encrypted Hash

The DC encrypts the TGS with the service account's NTLM hash, which is then extracted.

Key Takeaway

Kerberoasting targets service accounts with registered SPNs, allowing attackers to obtain encrypted Kerberos service tickets containing the service account's NTLM hash for offline cracking.
