Key Concepts

Essential Techniques and Privileges

Lateral Movement

The technique of moving through a network from one compromised system to another to gain access to additional resources.

Domain Administrator

The highest level of privilege within an Active Directory domain, granting full control over all domain resources.

Pass-the-Hash (PtH)

An attack where an attacker authenticates to a remote system using a stolen NTLM hash instead of the plaintext password.

Summary Takeaway

Understanding lateral movement, the goal of Domain Administrator, and techniques like Pass-the-Hash are foundational for effective Active Directory penetration testing.
