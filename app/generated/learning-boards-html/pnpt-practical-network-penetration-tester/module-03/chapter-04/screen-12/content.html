Maintaining Access: Persistence in Active Directory

Persistence is the art of maintaining long-term access to a compromised domain, even after initial footholds are removed or detected.

New Domain User Accounts

Create stealthy administrative accounts to ensure continued access, even if other compromised credentials are reset.

Group Policy Modification

Modify GPOs to run malicious scripts or configurations, ensuring persistent code execution on target systems.

Backdoors on Critical Servers

Install custom backdoors or modify system files on Domain Controllers or other critical servers for covert access.

Example: Creating a Stealthy Admin

After gaining Domain Admin, an attacker might create a new user 'svc_backup' with administrative privileges, making it harder to detect than modifying existing accounts.

Key Takeaway

Persistence involves establishing covert mechanisms like new administrative accounts, modifying Group Policy Objects, or installing backdoors on critical servers to maintain long-term access to a compromised Active Directory domain.
