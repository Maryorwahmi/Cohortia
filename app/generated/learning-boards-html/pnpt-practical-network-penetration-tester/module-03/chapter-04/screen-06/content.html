Executing Pass-the-Hash with CrackMapExec

CrackMapExec (CME) is a powerful tool for performing Pass-the-Hash attacks, enabling authentication and command execution using stolen NTLM hashes.

crackmapexec smb 192.168.1.106 -u Administrator -H 31d6cfe0d16ae931b73c59d7e0c089c0 -x "whoami"
Command Breakdown

smb specifies the protocol, -u for username, -H for the NTLM hash, and -x to execute a command.

Pro Tip: Subnet Scanning

CME can target entire subnets (e.g., 192.168.1.0/24) to quickly identify all machines where the hash is valid.

Key Takeaway

CrackMapExec (CME) simplifies Pass-the-Hash attacks, allowing direct authentication and command execution on target systems using stolen NTLM hashes, confirming successful lateral movement.
