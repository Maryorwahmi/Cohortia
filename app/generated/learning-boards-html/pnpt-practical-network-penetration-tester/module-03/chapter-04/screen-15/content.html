Key Concepts

Advanced Attack Methods and Long-Term Access

Kerberoasting

An attack that exploits Service Principal Names (SPNs) to extract and crack NTLM hashes of service accounts.

NTLM Relay

An attack where an attacker intercepts NTLM authentication attempts and relays them to another server to authenticate as the victim.

Persistence

Techniques used by attackers to maintain long-term access to a compromised system or network.

Summary Takeaway

Kerberoasting, NTLM Relay, and Persistence are advanced techniques that allow attackers to exploit Active Directory for privilege escalation and maintain long-term access to compromised environments.
