Finding Details

Clear Identification: Title and Description

The title provides a concise name, while the description offers a detailed, factual explanation of the vulnerability.

  • •Title: Clear, concise, and immediately informative.
  • •Description: Detailed explanation of how it was identified and why it's a problem.
  • •Be factual and objective, avoiding ambiguity.
Key Takeaway

A precise title and a comprehensive description are fundamental for technical teams to quickly understand and address identified vulnerabilities.

Title Examples
  • •Unpatched Critical Vulnerability in Web Server
  • •Weak Active Directory Password Policy
  • •SQL Injection Vulnerability in Login Form
Description Focus
  • •How the vulnerability was identified.
  • •Specific conditions for its existence.
  • •Why it is a problem (technical explanation).
