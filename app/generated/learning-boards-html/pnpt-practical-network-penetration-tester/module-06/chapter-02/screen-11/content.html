Case Study

Crafting a Critical Finding: RCE via Apache Struts 2

Applying the technical finding structure to a real-world Remote Code Execution vulnerability.

Title:

Critical - Remote Code Execution via Unpatched Apache Struts 2 Vulnerability

Description:

Public-facing web server at `[Client_IP_Address]` running Apache Struts 2 vulnerable to CVE-2017-5638. Improper input validation allows RCE via crafted `Content-Type` header with OGNL payload. Confirmed by establishing a reverse shell.

Key Takeaway

A well-structured finding clearly identifies the vulnerability, explains its technical nature, and articulates its severe business impact.

Impact:

Successful exploitation grants unauthenticated RCE, leading to full server control, data manipulation, backdoor installation, and network pivoting. This could result in significant data breaches, system unavailability, and severe reputational damage.

Vulnerability Details:
  • •CVE: CVE-2017-5638
  • •Type: Remote Code Execution (RCE)
  • •Affected Software: Apache Struts 2
  • •Exploitability: Unauthenticated, easily exploitable
