Case Study: Apache Struts 2 - Long-Term Solutions (Part 2)

Enhancing Defenses with Input Validation, Segmentation, and Monitoring

3. Input Validation & Sanitization

Implement strict validation for all user-supplied data (HTTP headers, parameters) to prevent injection attacks.

4. Network Segmentation

Isolate public-facing web servers from critical internal systems to limit lateral movement in case of compromise.

5. Security Monitoring & Alerting

Enhance monitoring for unusual activity (process execution, outbound connections) and configure alerts for incident response.

6. Application Security Testing

Integrate regular SAST/DAST into the SDLC to proactively identify and remediate vulnerabilities before deployment.
