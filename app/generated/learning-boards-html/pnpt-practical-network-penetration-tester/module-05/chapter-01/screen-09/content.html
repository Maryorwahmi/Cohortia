Discovering Hidden Paths: Directory & File Enumeration
Uncovering unlinked but accessible web application resources.
Core Concept

Directory and file enumeration involves systematically searching for hidden or unlinked web application resources that might expose sensitive information or functionality.

How it Works

Tools like gobuster use extensive wordlists to guess common directory and file names, sending requests to the target server and analyzing responses.

Potential Discoveries

This can reveal administrative interfaces, backup files, configuration files, test environments, or old application versions.

Key Takeaway

Hidden directories and files are common sources of vulnerabilities; systematic enumeration is essential for a comprehensive assessment.

Example: Using Gobuster for Directory Enumeration
# Install gobuster if not already present
sudo apt install gobuster

# Run gobuster against a target with a common wordlist
gobuster dir -u http://example.com -w /usr/share/wordlists/dirb/common.txt -t 20

# --- Example Output ---
/admin (Status: 301)
/login (Status: 200)
/backup (Status: 200)
/test (Status: 200)
/robots.txt (Status: 200)
/sitemap.xml (Status: 200)
/assets (Status: 200)
/images (Status: 200)
/css (Status: 200)
/js (Status: 200)
The -t 20 flag specifies 20 threads for faster scanning. Status codes indicate the response from the server.
