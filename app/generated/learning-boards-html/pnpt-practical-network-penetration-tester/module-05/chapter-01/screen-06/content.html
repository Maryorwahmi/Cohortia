Initial Phase

Web Application Reconnaissance

Gathering Intelligence Before the Attack

Passive Reconnaissance

  • •**Definition:** Collecting publicly available information without direct interaction with the target server.
  • •**Sources:** Search engines, public domain registration records, social media, archives.
  • •**Goal:** Understand the target's public footprint and gather initial clues.
  • •**Benefit:** Low risk of detection, provides a broad overview.
Key Takeaway

Passive recon is like observing from a distance, gathering public intelligence.

Active Reconnaissance

  • •**Definition:** Direct interaction with the target web server in a non-intrusive way.
  • •**Activities:** Port scanning, directory enumeration, technology identification.
  • •**Goal:** Discover specific services, hidden paths, and underlying technologies.
  • •**Benefit:** Provides deeper insights, but carries a higher risk of detection.
Key Takeaway

Active recon involves careful probing to reveal more detailed target information.
