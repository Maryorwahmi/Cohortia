Leveraging Publicly Available Data with CLI Tools

Terminal Output: whois & dig
$ whois example.com
   Domain Name: EXAMPLE.COM
   Registry Domain ID: 23456789_DOMAIN_COM-VRSN
   Registrar WHOIS Server: whois.iana.org
   Registrar URL: http://www.iana.org
   Updated Date: 2023-01-01T00:00:00Z
   Creation Date: 1995-08-14T04:00:00Z
   Registry Expiry Date: 2024-08-13T04:00:00Z
   Registrar: IANA
   Registrar IANA ID: 376
   Domain Status: clientDeleteProhibited
   Domain Status: clientTransferProhibited
   Domain Status: clientUpdateProhibited
   Name Server: A.IANA-SERVERS.NET
   Name Server: B.IANA-SERVERS.NET

$ dig example.com A
; <<>> DiG 9.10.6 <<>> example.com A
;; ANSWER SECTION:
example.com.        86400   IN      A       93.184.216.34

$ dig example.com MX
;; ANSWER SECTION:
example.com.        86400   IN      MX      0 .

Understanding the Output

  • •**`whois`:** Reveals domain registration details like creation/expiry dates, registrar, and name servers. This can hint at the age of the domain or the organization managing it.
  • •**`dig A`:** Shows the IP address(es) associated with the domain. Essential for knowing where the web server is hosted.
  • •**`dig MX`:** Identifies mail exchange servers. These can sometimes be targets for email-related attacks or reveal more about the organization's infrastructure.
Key Takeaway

Public records offer a wealth of information for initial target profiling without direct engagement.
