Core Concept

Network vs. Web App Penetration Testing

Understanding Distinct Methodologies and Targets

Network Penetration Testing

  • •**Target:** Underlying infrastructure (servers, routers, firewalls, OS).
  • •**Focus:** Open ports, vulnerable services, network misconfigurations.
  • •**Methodology:** Port scanning, vulnerability scanning, network protocol analysis.
  • •**Example:** Identifying an unpatched operating system or a weak firewall rule.
Key Takeaway

Network PT assesses the foundational hardware and software that supports applications.

Web Application Penetration Testing

  • •**Target:** Application code, web server software, databases, client-side scripts.
  • •**Focus:** Logic flaws, input validation issues, application misconfigurations.
  • •**Methodology:** Input manipulation, authentication bypass, session management testing.
  • •**Example:** Discovering an SQL Injection in a login form or a Cross-Site Scripting (XSS) vulnerability.
Key Takeaway

Web App PT assesses the functionality and code of the application itself.
