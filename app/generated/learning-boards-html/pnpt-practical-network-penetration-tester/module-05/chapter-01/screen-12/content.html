Hidden Clues: robots.txt and sitemap.xml
Discovering sensitive paths and hidden sections intended for search engines.
robots.txt Purpose

Instructs search engine crawlers which parts of the site they should or should not access. Often reveals 'disallowed' sensitive paths.

User-agent: *
Disallow: /admin/
Disallow: /private/
sitemap.xml Purpose

Provides a list of all pages and files on a site that the owner wants search engines to crawl. Can expose unlinked pages.

<url>
  <loc>http://example.com/secret-report.html</loc>
</url>
Reconnaissance Value

These files can inadvertently disclose administrative interfaces, sensitive documents, or hidden application sections not linked from the main site.

Common Mistake

Relying solely on robots.txt for security; it's a suggestion for crawlers, not an access control mechanism. Disallowed paths are still accessible.

Key Takeaway

Always check robots.txt and sitemap.xml early in reconnaissance; they often provide quick insights into a web application's hidden structure.
