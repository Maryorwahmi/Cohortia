Beyond Directories: Scanning for Misconfigurations with Nikto
Identifying dangerous files, outdated software, and common server issues.
Example: Using Nikto for Web Server Scanning
# Install nikto if not already present
sudo apt install nikto

# Run nikto against a target
nikto -h http://example.com

# --- Example Output Snippet ---
+ Server: Apache/2.4.41 (Ubuntu)
+ The anti-clickjacking X-Frame-Options header is not present.
+ The X-XSS-Protection header is not defined. This header can disable some XSS attacks.
+ No 'Content-Security-Policy' header is present.
+ OSVDB-3233: /icons/README: Apache default file found.
+ OSVDB-3092: /manual/: Apache manual found.
+ OSVDB-3268: /phpinfo.php: PHP information file found.
+ Allowed HTTP Methods: GET, HEAD, POST, OPTIONS
+ 8000 requests in 10.00 seconds: 800.00 requests/s
Nikto identifies server versions, missing security headers, and common default files.
What Nikto Finds

Outdated server software, common misconfigurations, default files, missing security headers, and known vulnerabilities.

Why it Matters

These findings often point to easily exploitable weaknesses that can lead to information disclosure, privilege escalation, or remote code execution.

Key Takeaway

Nikto provides a rapid, automated way to uncover a wide range of web server and application misconfigurations, guiding further investigation.
