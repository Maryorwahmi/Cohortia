Module 5.2›Chapter: Injection Flaws›Authentication Bypass
Original Query
SELECT * FROM users WHERE username = '[username]' AND password = '[password]';
Attacker Input
username: admin' OR '1'='1
Resulting Query
SELECT * FROM users WHERE username = 'admin' OR '1'='1' AND password = '[password]';
How the Bypass Works
Step 1: Malicious Input

Attacker enters admin' OR '1'='1 into the username field. The single quote closes the original string.

Step 2: Query Modification

The injected string adds an OR '1'='1' condition, making the entire WHERE clause logically true.

Step 3: Authentication Bypass

The database returns the first user (often 'admin') because the condition is always met, granting unauthorized access.

Key Takeaway

Improper input sanitization allows attackers to manipulate SQL logic, leading to critical security breaches like authentication bypass.
