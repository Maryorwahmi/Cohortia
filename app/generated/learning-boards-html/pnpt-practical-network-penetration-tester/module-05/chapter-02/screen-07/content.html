Revealing Data: Error and Union SQLi

Exploiting database responses for direct information retrieval.

Error-based SQLi

Relies on database error messages that contain information about the database structure or query syntax. Attackers craft queries to intentionally trigger errors and infer data.

SELECT * FROM users WHERE id = 1 AND (SELECT 1 FROM (SELECT COUNT(*),GROUP_CONCAT(table_name) FROM information_schema.tables GROUP BY floor(rand(0)*2))x);

Example: Triggering an error to reveal table names.

Union-based SQLi

Uses the UNION operator to combine the results of a malicious query with the legitimate query, allowing retrieval of data from other tables or databases.

SELECT * FROM products WHERE id = -1 UNION SELECT 1,database(),version()-- -;

Example: Extracting database name and version.

Pro Tip

For Union-based SQLi, always determine the number of columns in the original query first, often using ORDER BY clauses.
