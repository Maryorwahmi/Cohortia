Blind SQLi: Boolean-based Inference

Inferring data by observing subtle changes in application behavior.

What is Blind SQLi?

In Blind SQLi, the application does not return database errors or data directly. Attackers infer information by observing the application's behavior or response times.

Boolean-based Method

Send queries that return either a true or false result, then observe changes in the application's response (e.g., page content, HTTP status code).

Example: True Condition

SELECT * FROM users WHERE username = 'admin' AND 1=1-- -';

Result: Normal page content (condition is true).

Example: False Condition

SELECT * FROM users WHERE username = 'admin' AND 1=2-- -';

Result: Error page or empty content (condition is false).

Key Takeaway

By systematically testing true/false conditions and observing application responses, attackers can extract data character by character, even without direct output.
