Tool Overview

What is `sqlmap`?

`sqlmap` is an open-source penetration testing tool that automates the process of detecting and exploiting SQL injection flaws and taking over database servers. It supports a wide range of DBMS and injection techniques.

Key Features

Automated detection, various injection techniques, DBMS support, database takeover capabilities.

Why Use It?

Significantly reduces manual effort and time required for SQLi assessment, increasing efficiency and coverage.

Basic `sqlmap` Command
sqlmap -u "http://example.com/products.php?id=1" --dbs
Command Breakdown

-u specifies the target URL. --dbs tells sqlmap to enumerate available databases on the target.

Expected Output

sqlmap will test the id parameter for SQLi and, if found, list the names of accessible databases.
