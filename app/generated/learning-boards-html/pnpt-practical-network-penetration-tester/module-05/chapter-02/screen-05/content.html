Definition

What is SQL Injection (SQLi)?

SQL Injection (SQLi) is a web security vulnerability that allows an attacker to interfere with the queries an application makes to its database. It enables them to view data that they are not normally able to retrieve, or even modify database data.

Key Impact

Data theft, data modification, authentication bypass, or full database server control.

Common Scenario

Login forms, search bars, or any input field that interacts with a database.

Vulnerable Query Example
SELECT * FROM users WHERE username = '[username]' AND password = '[password]';
Explanation

The application directly inserts user-supplied [username] and [password] into the SQL query string without proper sanitization.

Risk

An attacker can inject SQL metacharacters to alter the query's logic, bypassing intended security controls.
