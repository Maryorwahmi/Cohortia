Blind SQLi: Time-based Inference

Detecting delays in application responses to extract sensitive information.

What is Time-based Blind SQLi?

This method introduces delays into the query. If a condition is true, the database pauses for a specified duration, causing a noticeable delay in the application's response.

Mechanism

Attackers inject time-delay functions (e.g., SLEEP(), BENCHMARK()) into queries and observe page load times to infer truth.

Example: Delay Confirmation

SELECT * FROM users WHERE username = 'admin' AND SLEEP(5)-- -';

If the page loads 5 seconds slower, the condition username = 'admin' is true.

Challenge

This method is very slow for manual exploitation but highly effective when automated, especially when other methods fail.

Key Takeaway

Time-based blind SQLi is a powerful technique for data extraction when direct output is suppressed, relying on observable time differences to confirm conditions.
