Definition

What is Command Injection?

Command Injection occurs when an application executes operating system commands based on user input, and that input is not properly sanitized. An attacker can inject arbitrary shell commands, which the application then executes on the server.

Key Impact

Remote code execution (RCE), full system compromise, data exfiltration, and network pivoting.

Common Scenario

Network diagnostic tools (ping, traceroute), file operations, or any feature that invokes shell commands.

Vulnerable Command Example
ping -c 4 [user_supplied_IP]
Attacker Input
IP: 127.0.0.1; ls -la /
Executed Command
ping -c 4 127.0.0.1; ls -la /
Shell Metacharacters

Characters like ;, |, &&, ||, & allow chaining of commands, enabling arbitrary execution.
