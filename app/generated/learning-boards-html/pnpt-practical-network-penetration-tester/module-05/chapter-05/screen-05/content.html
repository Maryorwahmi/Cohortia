Core Concept

Local File Inclusion (LFI)

Manipulating Server-Side File Paths

LFI occurs when a web application includes a file based on user-supplied input without proper validation. This allows an attacker to manipulate the file path to include arbitrary local files from the server's file system.

Common Scenario

A web application uses a URL parameter to dynamically load content, like example.com/index.php?page=about. If not properly secured, this parameter can be abused.

Key Takeaway

LFI allows attackers to force a web application to include and potentially execute local files by manipulating user-supplied file paths, often due to insufficient input validation.

Vulnerable PHP Code Example
<?php
  // Insecure: Directly uses user input
  $page = $_GET['page'];
  include($page . '.php');
  // If page=../../../../etc/passwd, it tries to include
  // /var/www/html/../../../../etc/passwd.php
  // which resolves to /etc/passwd.php
  // If /etc/passwd exists, its content might be displayed.
?>
Attacker controls $page variable, leading to arbitrary file inclusion.
