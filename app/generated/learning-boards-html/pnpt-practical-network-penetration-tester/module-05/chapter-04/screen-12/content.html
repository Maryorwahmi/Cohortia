Detecting & Exploiting IDORs

Using Burp Suite Repeater to Uncover Authorization Flaws

The Detection Process

  • Identify requests referencing objects (user IDs, document IDs).
  • Use Burp Suite Proxy to capture these requests.
  • Send the request to Burp Repeater for modification.
  • Systematically change object IDs to other values.
  • Observe responses for unauthorized access or errors.
Example Request
GET /api/v1/orders/123 HTTP/1.1
Host: example.com
Cookie: sessionid=abcXYZ

Modify 123 to 124 to attempt accessing another user's order.

Impact of IDORs

  • Unauthorized viewing, modification, or deletion of data.
  • Compromises data privacy and integrity.
  • Can lead to severe legal and reputational consequences.
Key Takeaway

Systematic testing with tools like Burp Suite Repeater is crucial for uncovering IDORs and preventing severe data breaches.
