Vulnerability Overview

Broken Authentication

Bypassing Login Mechanisms and Impersonating Users

What is Broken Authentication?

Broken Authentication refers to flaws that allow attackers to bypass login mechanisms or impersonate legitimate users. These vulnerabilities undermine the identity verification process.

  • Attackers gain unauthorized access.
  • Can lead to data breaches and account takeovers.
  • Often results from weak implementation of authentication controls.
Key Takeaway

Broken Authentication is a critical vulnerability that compromises user identity and system access.

Common Weaknesses

  • Weak Credentials: Easily guessable passwords.
  • Insecure Session Management: Predictable or exposed session tokens.
  • Brute-Force Attacks: Lack of protection against repeated login attempts.
  • Improper Error Handling: Verbose error messages revealing valid usernames.
Impact Scenario

An attacker steals a session token and impersonates a high-privileged user, gaining full control over their account.
