Core Concept

Authentication vs. Authorization

The Fundamental Pillars of Web Security

Authentication: Who Are You?

  • Verifies the identity of a user or system.
  • Typically involves credentials like username and password.
  • Answers the question: "Are you a legitimate user?"
  • Example: Logging into an online banking portal.
Key Takeaway

Authentication is about identity verification, ensuring only legitimate users can access the system.

Authorization: What Can You Do?

  • Determines what an authenticated user is permitted to do.
  • Controls access to specific resources or actions.
  • Answers the question: "Are you allowed to do that?"
  • Example: An administrator accessing user management tools.
Real-World Connection

Imagine a library: your library card authenticates you, but your membership type authorizes which books you can borrow.
