Selecting the Optimal Penetration Test Type

Matching the test methodology to specific security objectives and threat models.

Black-box

  • •**Knowledge:** None.
  • •**Goal:** Simulate external attacker, find perimeter flaws.
  • •**Use Case:** External web apps, network perimeters.

White-box

  • •**Knowledge:** Full (source code, diagrams).
  • •**Goal:** Deep, comprehensive internal audit.
  • •**Use Case:** Critical applications, internal systems.

Gray-box

  • •**Knowledge:** Limited (e.g., user credentials).
  • •**Goal:** Simulate insider/targeted attacker.
  • •**Use Case:** Authenticated web apps, internal network segments.

Scenario: Client Request

A client wants to know what an unauthenticated user could do to their public website. This points towards a **black-box** test.

Key Takeaway

The best test type aligns with the client's security goals and the specific threat model being simulated.
