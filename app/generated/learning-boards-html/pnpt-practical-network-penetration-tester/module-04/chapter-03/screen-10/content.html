Querying Delegation Settings with PowerView

Using PowerShell to identify vulnerable delegation configurations in Active Directory.

# Find computers with unconstrained delegation
Get-NetComputer -UnconstrainedDelegation
# Find users/computers with constrained delegation
Get-NetComputer -TrustedToAuth | Select-Object Name, PrincipalsAllowedToDelegateToHost
  • •**PowerView.ps1:** Invaluable script for AD reconnaissance and enumeration.
  • •**Unconstrained Delegation:** Identify computers that can capture TGTs.
  • •**Constrained Delegation:** Pinpoint service accounts with restricted impersonation rights.
Key Takeaway

PowerView.ps1 enables efficient enumeration of unconstrained and constrained delegation settings, providing critical data for identifying exploitation targets.
