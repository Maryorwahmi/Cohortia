Learning Objectives

Gain essential skills to understand and perform initial reconnaissance against Active Directory environments.

LearnUnderstandApplyMaster
01

Understand AD Structure

Grasp the core components and hierarchical structure of an Active Directory environment, including domains, forests, and organizational units. This knowledge forms the foundation for mapping target networks.

VERIFIED COMPETENCY MILESTONE
02

Explain AD Services

Articulate the roles of key Active Directory services like DNS, LDAP, and Kerberos in authentication and authorization. This is vital for understanding how AD secures and manages access.
