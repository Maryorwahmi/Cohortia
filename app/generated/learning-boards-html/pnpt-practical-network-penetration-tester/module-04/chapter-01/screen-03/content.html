Learning Objectives

Gain essential skills to understand and perform initial reconnaissance against Active Directory environments.

LearnUnderstandApplyMaster
03

Perform AD Reconnaissance

Execute initial reconnaissance against an Active Directory domain to gather information about its structure, users, and computers. This is the critical first step in identifying vulnerabilities.

VERIFIED COMPETENCY MILESTONE
04

Utilize Command-Line Tools

Effectively use common command-line tools and scripts to enumerate Active Directory services and discover critical domain information. This includes practical application of `nslookup`, `dig`, `nmap`, and `enum4linux`.

VERIFIED COMPETENCY MILESTONE
