Reconnaissance Tools

Locating DCs with DNS Queries

Using nslookup and dig to find Domain Controllers via SRV records.

Why SRV Records?

Active Directory uses SRV (Service) records in DNS to advertise the location of its services, including LDAP provided by Domain Controllers.

Example Query Format

_ldap._tcp.dc._msdcs.<YOUR_DOMAIN_NAME>

Key Takeaway

DNS SRV queries are a non-intrusive and effective way to discover Domain Controllers and map the AD environment.

# Using nslookup to find domain controllers for example.local nslookup -type=SRV _ldap._tcp.dc._msdcs.example.local # Using dig for the same purpose dig SRV _ldap._tcp.dc._msdcs.example.local
Server: dc01.example.local Address: 192.168.1.100 _ldap._tcp.dc._msdcs.example.local SRV service location: priority = 0 weight = 100 port = 389 srv hostname = dc01.example.local srv hostname = dc02.example.local
Output reveals DC hostnames and IP addresses.
