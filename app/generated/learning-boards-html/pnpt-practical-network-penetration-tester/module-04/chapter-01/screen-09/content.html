LDAP & Kerberos: Communication and Authentication

Protocols for querying and securing Active Directory interactions.

LDAP (Lightweight Directory Access Protocol)
  • Primary protocol for querying and modifying AD data.
  • Used to search for users, groups, computers, etc.
  • Essential for AD client-server communication.
Kerberos
  • Default authentication protocol in AD.
  • Ticket-based system for strong authentication.
  • Uses Ticket-Granting Tickets (TGTs) and Service Tickets (STs).
Key Takeaway

LDAP enables data access, while Kerberos secures authentication, both are critical for AD functionality and common targets for exploitation.
