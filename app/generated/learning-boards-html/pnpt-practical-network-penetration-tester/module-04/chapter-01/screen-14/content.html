Reconnaissance Tools

Deep Dive: SMB Enumeration

Discovering users and shares with Nmap scripts and enum4linux.

Nmap SMB Scripts
  • smb-enum-users.nse: Attempts to enumerate users.
  • smb-enum-shares.nse: Lists network shares.
  • Provides initial insights into user accounts and shared resources.
Enum4linux Capabilities
  • Retrieves user lists, group lists, and share lists.
  • Often works without authentication (null sessions).
  • A comprehensive tool for initial AD recon.
Key Takeaway

Tools like Nmap scripts and enum4linux are essential for unauthenticated enumeration of SMB, revealing valuable user and share information.

# Nmap scripts for SMB enumeration nmap --script smb-enum-users.nse,smb-enum-shares.nse -p 445 <DC_IP> # Enumerate users, groups, and shares with enum4linux enum4linux -a <DC_IP>
