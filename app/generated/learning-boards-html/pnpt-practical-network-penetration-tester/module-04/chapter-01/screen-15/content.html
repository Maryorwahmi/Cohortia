Reconnaissance Tools

LDAP Enumeration: Direct AD Queries

Using ldapsearch for domain information, even with anonymous binds.

Why Use Ldapsearch?
  • Directly query and retrieve information from the AD database.
  • Can reveal domain structure, naming contexts, and other details.
  • Useful when other enumeration methods are limited.
Anonymous Bind Example

Even without credentials, an anonymous bind can sometimes retrieve base DSE information, including domain naming contexts.

Key Takeaway

ldapsearch provides a direct method for querying AD, and even anonymous binds can yield valuable domain information for reconnaissance.

# Anonymous LDAP bind to retrieve base DSE information ldapsearch -x -H ldap://<DC_IP> -b "" -s base namingContexts
# extended LDIF # # LDAPv3 # base "" with scope baseObject # filter: (objectclass=*) # requesting: namingContexts # dn: namingContexts: DC=example,DC=local namingContexts: CN=Configuration,DC=example,DC=local namingContexts: CN=Schema,CN=Configuration,DC=example,DC=local namingContexts: DC=DomainDnsZones,DC=example,DC=local namingContexts: DC=ForestDnsZones,DC=example,DC=local # search result search: 2 result: 0 Success # numResponses: 6 # numEntries: 1
Output reveals domain naming contexts.
