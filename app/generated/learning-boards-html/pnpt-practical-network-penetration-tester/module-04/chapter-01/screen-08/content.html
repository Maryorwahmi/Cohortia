Domain Controllers: The Heart of AD

Servers running AD DS, authenticating users and enforcing policies.

What is a DC?

A server running the Active Directory Domain Services (AD DS) role. It stores the AD database and manages authentication.

Why it Matters

DCs are the primary targets for attackers as they hold critical authentication data and control network access. Compromising a DC often grants full domain control.

Key Takeaway

Domain Controllers are the most critical assets in an Active Directory environment, responsible for all authentication and policy enforcement.
