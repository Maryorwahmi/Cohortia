Key Concepts: Active Directory Foundations

Review the essential terms and components that form the basis of Active Directory.

Active Directory (AD)

A directory service by Microsoft for Windows domain networks, providing centralized management and authentication.

Domain

A logical grouping of network objects (users, computers) that share a common database and security policy.

Domain Controller (DC)

A server running Active Directory Domain Services (AD DS) that authenticates users and computers in a Windows domain.

Summary Takeaway

Active Directory, its domains, and domain controllers form the core infrastructure for enterprise network management and security.
