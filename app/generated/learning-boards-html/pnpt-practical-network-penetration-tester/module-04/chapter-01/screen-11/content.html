Reconnaissance Phase

Introduction to AD Reconnaissance

The art of gathering information about the target Active Directory environment.

Goals of AD Recon
  • Map AD structure (domains, OUs).
  • Identify potential entry points.
  • Discover user accounts and computer names.
  • Find Service Principal Names (SPNs).
Starting Points
  • Basic network scanning.
  • Public information gathering.
  • AD-specific enumeration techniques.
Key Takeaway

Thorough Active Directory reconnaissance is the foundational step for identifying vulnerabilities and planning effective exploitation strategies.

Reconnaissance Process Flow
1. Initial Network Scan
Identify live hosts and open ports.
2. Public Information Gathering
Guess domain names, company structure.
3. AD-Specific Enumeration
Use tools to query AD for details.
4. Analyze & Document
Identify vulnerabilities and plan next steps.
