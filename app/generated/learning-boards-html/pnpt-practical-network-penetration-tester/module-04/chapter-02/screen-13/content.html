Key Concepts: Initial Access & Kerberos Attacks

Essential terms and techniques for credential harvesting.

User Enumeration

The process of identifying valid usernames within a target Active Directory domain.

Password Spraying

An attack where a single common password is tried against a large list of usernames to bypass account lockout policies.

AS-REP Roasting

A Kerberos attack targeting user accounts with disabled pre-authentication to obtain NTLM hashes for offline cracking.

Summary Takeaway

These techniques form the initial offensive toolkit for gaining access and harvesting credentials in Active Directory, leveraging both user-centric and protocol-level vulnerabilities.
