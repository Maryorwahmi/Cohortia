Cracking Harvested NTLM Hashes

Turning captured NTLM hashes into plaintext credentials using specialized tools.

The Cracking Process

  • •**NTLM Hash:** Cryptographic representation of a password.
  • •**Tool:** Hashcat (GPU-accelerated password cracker).
  • •**Method:** Dictionary attacks, brute-force against wordlists.
  • •**Outcome:** Recovery of plaintext passwords for further exploitation.
Key Takeaway

Cracking harvested NTLM hashes is essential for converting raw data into usable plaintext credentials, unlocking further access and privilege escalation opportunities.

Hashcat for NTLM Hash Cracking

Using Hashcat with specific modes for different hash types.

# For AS-REP Roasting hashes (Hashcat mode 18200)
hashcat -m 18200 asreproast_hashes.txt /usr/share/wordlists/rockyou.txt --force
# For Kerberoasting hashes (Hashcat mode 13100)
hashcat -m 13100 kerberoast_hashes.txt /usr/share/wordlists/rockyou.txt --force
