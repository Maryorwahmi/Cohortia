Network Poisoning

Responder: Network-Based Hash Capture

Poisoning LLMNR, NBT-NS, and MDNS to intercept NTLMv1/v2 hashes from network traffic.

How Responder Works

  • •**Targets:** LLMNR, NBT-NS, and MDNS protocols.
  • •**Mechanism:** Listens for name resolution requests and spoofs responses.
  • •**Outcome:** Tricks clients into sending NTLM hashes for offline cracking.
Key Takeaway

Responder is a powerful tool for capturing NTLM hashes by exploiting fallback local name resolution protocols, though its effectiveness can vary in modern, hardened environments.

Starting Responder

Command to initiate Responder on your attacking machine.

# Start Responder on your attacking machine
sudo responder -I <YOUR_ATTACKING_INTERFACE> -v
Safety Note

Responder can be noisy and cause network disruptions. Always ensure explicit authorization before deployment. Modern systems may have LLMNR/NBT-NS disabled.
