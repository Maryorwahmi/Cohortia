Executing Kerberoasting with GetUserSPNs.py

Requesting service tickets to capture crackable hashes for service accounts.

Key Steps & Requirements

  • •**Tool:** Impacket's GetUserSPNs.py script.
  • •**Requirement:** Valid (even low-privileged) domain credentials.
  • •**Process:** Requests service tickets, extracts encrypted NTLM hashes.
  • •**Output:** Hashes in a format suitable for offline cracking.
Key Takeaway

GetUserSPNs.py is essential for Kerberoasting, enabling the extraction of service account NTLM hashes from SPN tickets, provided you have valid domain credentials.

Kerberoasting with GetUserSPNs.py

Command to request and capture SPN hashes.

# Kerberoasting with Impacket's GetUserSPNs.py (requires valid domain credentials)
python3 GetUserSPNs.py <DOMAIN.LOCAL>/<USERNAME>:<PASSWORD> -request -dc-ip <DC_IP> -outputfile kerberoast_hashes.txt
Common Mistakes

Forgetting to provide valid credentials for GetUserSPNs.py, or failing to filter out SPNs associated with machine accounts, which are often harder to crack.
