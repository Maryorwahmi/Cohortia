Reconnaissance

Enumerating Service Principal Names (SPNs)

Identifying services registered for Kerberos authentication within an Active Directory domain.

Methods for SPN Discovery

  • •**setspn -L:** Built-in command for authenticated users.
  • •**LDAP Queries:** Programmatic way to search for SPNs.
  • •**PowerShell (PowerView.ps1):** Comprehensive scripting for domain-wide enumeration.
Key Takeaway

Thorough SPN enumeration is a prerequisite for successful Kerberoasting, allowing attackers to pinpoint Kerberos-enabled services and their underlying service accounts.

PowerView.ps1 for SPN Enumeration

Using PowerShell to discover Service Principal Names.

# Enumerate SPNs using PowerView.ps1
Get-NetServicePrincipalName -Domain <DOMAIN.LOCAL> | select ServicePrincipalName, SamAccountName
Pro Tip

Filter out SPNs associated with machine accounts (ending with '$') as these are generally harder to crack and less valuable than user-based service accounts.
