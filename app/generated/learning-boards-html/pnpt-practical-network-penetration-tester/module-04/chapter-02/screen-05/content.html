User Enumeration with Kerberos

Leveraging Kerberos error messages to discover valid usernames in Active Directory.

How Kerberos Helps

  • •**Invalid User:** DC responds with `KDC_ERR_C_PRINCIPAL_UNKNOWN`.
  • •**Valid User, Wrong Pass:** DC responds with `KDC_ERR_PREAUTH_REQUIRED` or `KDC_ERR_WRONG_REALM`.
  • •**Distinction is Key:** This difference allows for precise username identification.
Key Takeaway

Kerberos error messages provide a reliable, unauthenticated method to enumerate valid Active Directory usernames, forming the basis for further attacks.

Nmap Kerberos User Enumeration

Automating user discovery with the krb5-enum-users script.

# Nmap Kerberos user enumeration script
nmap -p 88 --script krb5-enum-users --script-args krb5-enum-users.realm='<DOMAIN.LOCAL>' <DC_IP>
Practical Example

To enumerate users in 'corp.local' with a DC at 192.168.1.10, you'd run: nmap -p 88 --script krb5-enum-users --script-args krb5-enum-users.realm='corp.local' 192.168.1.10
