Executing Password Spraying Attacks

Trying a single common password against many user accounts to bypass lockout policies.

Why it's Effective

  • •**Bypasses Lockouts:** Each account sees minimal failed attempts.
  • •**Common Passwords:** Many users still use weak or default credentials.
  • •**Efficiency:** Quickly identifies multiple compromised accounts.
Key Takeaway

Password spraying is a highly effective, low-risk method to gain initial access by exploiting common weak passwords across an organization's user base.

CrackMapExec for Password Spraying

Automating password spraying over SMB and LDAP protocols.

# Password spraying with CrackMapExec (SMB protocol)
crackmapexec smb <DC_IP_RANGE> -u users.txt -p 'Summer2023!' --continue-on-success
# Password spraying with CrackMapExec (LDAP protocol)
crackmapexec ldap <DC_IP_RANGE> -u users.txt -p 'Summer2023!' --continue-on-success
