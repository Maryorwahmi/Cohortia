Kerberos Abuse

Silver Tickets: Targeted Service Access

Forging a Service Ticket for specific resource control

What is a Silver Ticket?

A forged Kerberos Service Ticket (ST) that grants an attacker access to a *specific service* on a *specific server*. It's more granular than a Golden Ticket.

Why use Silver Tickets?

Useful for bypassing detection on the Domain Controller or when only access to a particular resource (e.g., a file share or SQL database) is needed, rather than full domain control.

Key Takeaway

Silver Tickets provide targeted access to specific services on specific servers, making them a stealthy option when full domain compromise is not required or desired.

Silver Ticket Prerequisites

  • Domain Name: The target Active Directory domain.
  • Domain SID: The Security Identifier of the domain.
  • Service Account NTLM Hash: The NTLM hash of the specific service account running the target service.
  • Target Server FQDN: The Fully Qualified Domain Name of the server hosting the service.
  • Desired Service: The specific service to access (e.g., cifs, mssql).
Distinction

The key difference from Golden Tickets is the reliance on the *service account hash* instead of the krbtgt hash. This means a Silver Ticket's scope is limited to the specific service it's forged for.
