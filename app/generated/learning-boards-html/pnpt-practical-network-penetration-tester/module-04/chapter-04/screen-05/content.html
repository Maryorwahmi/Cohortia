Kerberos Abuse

Golden Tickets: The Master Key to Active Directory

Forging a Ticket Granting Ticket for arbitrary domain privileges

What is a Golden Ticket?

A forged Kerberos Ticket Granting Ticket (TGT) that grants an attacker arbitrary privileges in an Active Directory domain. It acts as a master key, allowing impersonation of any user.

Why is it 'Golden'?

It provides virtually undetectable persistence and full control over the domain, allowing an attacker to act as a Domain Administrator without knowing their password.

Key Takeaway

Golden Tickets are powerful forged TGTs that grant domain-wide arbitrary privileges, making them a critical persistence mechanism in Active Directory.

Golden Ticket Prerequisites

  • Domain Name: The target Active Directory domain (e.g., cohortia.local).
  • Domain SID: The Security Identifier of the domain.
  • krbtgt NTLM Hash: The NTLM hash of the Kerberos service account. This is the most critical piece, usually requiring Domain Admin privileges to obtain.
  • Desired User: The user to impersonate (e.g., Administrator).
Important Note

The krbtgt account hash is the cornerstone of Golden Ticket attacks. Protecting this hash is paramount for Active Directory security. Its compromise grants an attacker the ability to forge tickets for any user in the domain.
