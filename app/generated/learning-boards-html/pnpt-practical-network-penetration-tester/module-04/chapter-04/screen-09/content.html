Persistence Methods

Beyond Kerberos: Alternative Persistence Techniques

Exploring non-ticket-based methods for maintaining access

Skeleton Key

A patch to lsass.exe on a DC allowing any user to authenticate with a master password. Highly intrusive but grants immediate access.

Malicious GPOs

Modifying Group Policy Objects to create new local admin accounts, add startup scripts, or deploy malicious software across the domain.

Key Takeaway

A diverse set of non-Kerberos persistence methods exist, offering attackers various ways to maintain access, each with different levels of intrusiveness and detectability.

DCShadow / DCSync

DCSync mimics DC replication to steal hashes. DCShadow registers a rogue DC to push malicious changes and then unregisters it, leaving minimal traces.

Scheduled Tasks & WMI

Creating persistent scheduled tasks on target machines or using WMI Event Subscriptions to execute code when specific events occur, offering stealthy execution.
