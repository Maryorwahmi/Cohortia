Lateral Movement

Navigating the Network: Pass-the-Hash and Pass-the-Ticket

Leveraging stolen credentials and tickets for network traversal

Pass-the-Hash (PtH)

  • Uses an NTLM hash to authenticate to remote systems.
  • Bypasses the need for the plaintext password.
  • Commonly used over SMB for remote command execution.
  • Tools: pth-winexe, crackmapexec -H.

Pass-the-Ticket (PtT)

  • Uses a Kerberos ticket (TGT or ST) for authentication.
  • Leverages tickets obtained from Golden/Silver Ticket attacks or Mimikatz.
  • Allows authentication to remote systems or services.
Key Takeaway

Both PtH and PtT are powerful lateral movement techniques that enable authentication to remote systems using hashes or tickets, bypassing the need for plaintext passwords.

Common Misconception

It's a common mistake to spend time cracking hashes when Pass-the-Hash or Pass-the-Ticket can often be used directly. These methods are generally faster and more stealthy than brute-forcing passwords.

Real-World Example

Imagine you've compromised a user's workstation and extracted their NTLM hash. Using PtH, you can then authenticate to a file server where that user has access, without ever knowing their actual password, and potentially discover sensitive documents.
