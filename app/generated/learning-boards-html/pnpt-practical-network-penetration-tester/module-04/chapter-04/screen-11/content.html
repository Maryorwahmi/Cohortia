Remote Execution: WMI, PsExec, and Admin Shares

Tools and techniques for executing commands on remote systems

Windows Management Instrumentation (WMI)

Allows for remote execution of commands and queries. Tools like Impacket's wmiexec.py provide a semi-interactive shell. Often stealthier than other methods.

PsExec

A Sysinternals tool (also in Impacket as psexec.py) for executing commands on remote Windows systems. Often creates a temporary service for execution.

Key Takeaway

WMI, PsExec, and administrative shares are versatile tools for remote command execution and file transfer, crucial for effective lateral movement within Windows environments.

Administrative Shares

Hidden shares like C$ or ADMIN$ on Windows systems. Accessible with administrative privileges for remote file access and program execution. Can be accessed via net use or smbclient.

RDP (Remote Desktop Protocol)

If enabled and credentials are valid, RDP allows direct graphical login to a remote system. While simple, it can be easily logged and detected by defenders.
