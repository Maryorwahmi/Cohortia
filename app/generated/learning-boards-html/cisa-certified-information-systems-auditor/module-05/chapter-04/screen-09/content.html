Recovery Strategy

Mobile and Cloud Recovery

Flexible and Scalable Recovery Site Options

Mobile Site: On-Demand Flexibility

  • •Self-contained, transportable unit with IT infrastructure.
  • •Offers flexibility in location deployment.
  • •Can have logistical challenges (transport, power, connectivity).

Cloud Recovery: Scalability & Cost-Efficiency

  • •Leverages public or private cloud infrastructure.
  • •High flexibility, scalability, potentially lower costs.
  • •RTOs from minutes to hours (e.g., pilot light, warm standby).

Auditor's Focus: Cloud Shared Responsibility

When auditing cloud recovery, CISA professionals must understand the shared responsibility model. While the cloud provider manages the 'security of the cloud,' the organization is responsible for 'security in the cloud,' including data, applications, and configurations.

Example: Cloud Warm Standby

An organization uses a cloud warm standby, where a minimal version of their environment is always running. In a disaster, they can quickly scale up resources, achieving a low RTO without the full cost of a hot site, but requiring careful management of cloud configurations.

Key Takeaway

Mobile and cloud recovery offer modern, flexible solutions, but auditors must scrutinize logistical challenges for mobile sites and the shared responsibility model for cloud environments.
