Critical Metric

Understanding WRT: Post-Recovery Setup

The time needed to make a recovered system fully operational for users.

What is Work Recovery Time (WRT)?

WRT is the time required to configure a recovered system, perform data synchronization, and conduct integrity checks to make the system fully operational and ready for users after the RTO has been met. It's the 'post-recovery setup' phase.

  • •Post-RTO Activity: Occurs after the system is technically restored but before it's fully usable.
  • •Ensures Readiness: Includes tasks like configuration, data integrity checks, and user testing.
  • •Critical for Full Operation: Without WRT, the system may be 'up' but not truly functional.
Key Takeaway

WRT is essential for ensuring a recovered system is not just online, but fully functional and reliable for business operations.

Example: Database Server Recovery

RTO Met: A database server is restored and online.

WRT Activities: Re-indexing, integrity checks, applying pending transactions.

User Access: Users can only access the database after WRT is complete.
