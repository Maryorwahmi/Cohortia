Network Strategy

Network Segmentation: Limiting Lateral Movement

Dividing networks into isolated segments to contain threats.

Key Principles of Segmentation

  • Isolation: Create logical boundaries between different network zones.
  • Least Privilege: Restrict communication between segments to only what is necessary.
  • Containment: Prevent attackers from moving freely if one segment is compromised.
  • Enhanced Monitoring: Easier to detect anomalous traffic within smaller, defined segments.

Practical Segmentation Examples

  • DMZ: Public-facing servers (web) isolated from internal networks.
  • Server Segment: Critical application and database servers.
  • User Workstation Segment: Employee computers.
  • Guest Wi-Fi: Completely isolated network for visitors.
  • IoT Devices: Dedicated segment for smart devices.
Key Takeaway

Proper network segmentation is a foundational control that significantly reduces the attack surface and limits the impact of a breach.

Common Mistake

A 'flat network' allows attackers to move freely across all devices once a single point is compromised, making it a major audit concern.
