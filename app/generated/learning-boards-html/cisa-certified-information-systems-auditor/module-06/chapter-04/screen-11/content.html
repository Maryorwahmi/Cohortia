Attribute-Based Access Control (ABAC)

Dynamic Access Decisions Based on Context

  • Dynamic Decisions: Access based on user, resource, and environment attributes.
  • Granular Control: Highly flexible and contextual.
  • Complexity: Increased design and implementation effort.
  • Auditor's Focus: Verify attribute accuracy and policy configuration.
Example Scenario

Allow access to 'Confidential Project Files' only if the 'User Department' is 'Engineering', the 'Resource Sensitivity' is 'High', and the 'Access Time' is 'Business Hours'.

ABAC Decision Flow
User Attributes
Resource Attributes
Environmental Attributes

ABAC evaluates a combination of attributes to make real-time, context-aware access decisions.

Key Takeaway

ABAC offers highly dynamic and granular access control by evaluating attributes of the user, resource, and environment, enabling context-aware decisions but requiring careful implementation and governance.
