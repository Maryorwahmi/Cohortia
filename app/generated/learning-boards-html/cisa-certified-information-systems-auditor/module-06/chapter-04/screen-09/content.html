Discretionary Access Control (DAC)

Owner-Controlled Flexibility

Key Principle

Resource owner grants or denies access to other users. Users have control over their own resources.

  • Flexibility: High, users manage their own permissions.
  • Management: Difficult to scale, inconsistent security.
  • Use Case: Common in personal operating systems.
Example

A user creates a document and decides who can read, write, or execute it.

Mandatory Access Control (MAC)

System-Enforced Rigidity

Key Principle

Access decisions based on security labels (e.g., 'confidential') assigned by a system administrator to subjects and objects.

  • Flexibility: Low, highly rigid and consistent.
  • Management: Centralized, only admins modify labels.
  • Use Case: High-security environments (e.g., military).
Example

A user with a 'Secret' clearance can only access files labeled 'Secret' or below, regardless of file ownership.

Key Takeaway

DAC provides flexibility with owner-controlled permissions but can lead to inconsistency, while MAC offers high security and consistency through system-enforced security labels, ideal for sensitive environments.
