Scenario: Online Banking Application

An organization is developing a new online banking application handling sensitive customer financial transactions. As a CISA, you recommend key controls for this high-risk system.

The goal is to design a set of three key controls (one preventive, one detective, and one corrective) that an auditor would expect to see implemented during development and testing.

Risk Highlight

High-risk systems like online banking require robust, multi-layered controls to protect sensitive data and prevent financial fraud.

Key Takeaway

A balanced approach using preventive, detective, and corrective controls provides comprehensive security for critical applications.

Recommended Controls for Online Banking

1. Secure Coding Guidelines (Preventive)

Prevents vulnerabilities like SQL injection from being coded, protecting customer data and transactions.

2. Vulnerability Scanning & Pen Testing (Detective)

Identifies exploitable security weaknesses in the running application before attackers can find them.

3. Incident Response Plan (Corrective)

Provides documented procedures for responding to security incidents, minimizing impact and ensuring recovery.
