Installation, Configuration, and Security Hardening

After data migration, the physical and logical setup of the new system in its production environment is paramount. This includes rigorous security hardening.

  • • Installation & Configuration: Setting up hardware and software in the production environment.
  • • Security Hardening: Systematically reducing the system's attack surface.
  • • CISA's Focus: Verify adherence to security policies and best practices.
Key Takeaway

Thorough security hardening during installation and configuration is a critical proactive measure to protect the new system from vulnerabilities.

Hardening Checklist (Auditor's View)
  • Apply all security patches and updates.
  • Disable unnecessary services, ports, and default accounts.
  • Configure strong access controls (least privilege principle).
  • Implement robust logging and monitoring for security events.
  • Remove or change all default passwords.
Pro-Tip: Security Baselines

Establish and enforce security baselines for all new systems. These provide a minimum security configuration standard that auditors can use for verification.
