Project Management Methodologies: Waterfall

A Sequential Approach for Stable, Well-Defined Requirements

Waterfall Characteristics

  • •Sequential, linear approach.
  • •Each phase completed before the next.
  • •Well-suited for stable, defined requirements.
  • •Extensive documentation and strict change control.

Example: Building a highly regulated financial system.

Audit Implications

  • •Focus on phase gate reviews and approvals.
  • •Scrutinize comprehensive documentation.
  • •Assess strict change control processes.
  • •Verify adherence to planned sequence.

Misconception: Waterfall is completely inflexible; changes are possible but costly.

Key Takeaway

Waterfall provides a structured, linear path for projects with stable requirements, requiring auditors to focus on phase gates, documentation, and change control.
