Key Concepts

Essential terms to remember

System Development Life Cycle (SDLC)

A structured process for planning, creating, testing, and deploying an information system.

Requirements Gathering/Analysis

The phase where user needs, functional, and non-functional specifications are defined.

Design Phase

The phase where system architecture, database structure, and user interfaces are planned.

Development/Implementation Phase

The phase where code is written and unit tested.

Testing Phase

The phase where the system is evaluated against requirements, including various types of testing.

Deployment/Go-Live Phase

The phase where the system is installed in the production environment and becomes operational.

Summary Takeaway

The SDLC provides a structured, phased approach to system development, from initial requirements to deployment, ensuring systematic and controlled progress.
