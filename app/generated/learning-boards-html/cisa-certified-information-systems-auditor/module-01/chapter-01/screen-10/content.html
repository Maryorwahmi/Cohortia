Distinguishing Audit Activities

Identifying the Correct Audit Type

Understanding the boundaries between IT audits, financial audits, and security assessments is crucial. IT audits focus on controls and governance, not on performing active vulnerability exploitation.

Key Takeaway

A CISA evaluates the effectiveness of controls and risk management processes, rather than conducting hands-on penetration testing.

Scenario: CRM System Audit

Which activity is typically outside a CISA's IT audit scope?

A) Assess Access Controls

Within scope: Evaluating user permissions and authentication.

B) Review Backup & Recovery

Within scope: Verifying data resilience procedures.

C) Perform Penetration Test

Typically OUTSIDE scope: Active vulnerability exploitation is a security assessment task.

D) Evaluate Vendor SLAs

Within scope: Assessing third-party security and availability commitments.
