Key Concepts

Understanding DLP Deployment and Outcomes

Endpoint DLP

DLP solutions that monitor and control data on individual workstations and servers, preventing unauthorized local actions.

Network DLP

DLP solutions that monitor data in transit across network channels (e.g., email, web, FTP) for sensitive information.

Storage/Data at Rest DLP

DLP solutions that scan data stored in databases, file shares, and cloud storage to identify and protect sensitive information.

Summary Takeaway

DLP deployment models provide layered protection, addressing data security across endpoints, networks, and storage locations.
