Chapter Summary

Key Concepts

Core terminology for advanced IAM auditing

Identity and Access Management (IAM)

The framework of policies and technologies that ensures the proper individuals have the proper access to technology resources.

Federated Identity

A system that allows a user to authenticate once with a trusted identity provider and then access multiple service providers without re-authentication.

Single Sign-On (SSO)

An authentication scheme that allows a user to log in with a single ID and password to gain access to multiple related, yet independent, software systems.

Summary Takeaway

Understanding IAM, Federated Identity, and SSO is fundamental for CISA auditors to assess and ensure secure, efficient access management in modern IT environments.
