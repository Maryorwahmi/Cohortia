PAM Audit Focus

Auditing PAM Systems

Verifying secure storage, access enforcement, and activity monitoring.

Key Audit Procedures

  • •**Review Configurations:** Examine PAM system settings and access policies.
  • •**Verify Account Management:** Ensure non-shared accounts and automatic password rotation.
  • •**Enforce JIT Access:** Confirm privileged access is time-limited and task-specific.
  • •**Audit PAM Solution Security:** Verify the PAM system itself is hardened and regularly audited.
Key Takeaway

Auditing PAM involves verifying non-shared accounts, automatic password rotation, JIT enforcement, and securing the PAM solution itself, using tools like `sudoers` and Active Directory commands.

Practical Audit Examples

Linux System: `sudoers` File Review

Examine the `/etc/sudoers` file to ensure that only authorized users or groups have `sudo` privileges, and that these privileges are restricted to specific commands or paths, enforcing least privilege.

# Example sudoers entry
alice ALL=(ALL) /usr/bin/apt update, /usr/bin/apt upgrade
# Ensures Alice can only run specific update commands with sudo

Active Directory: Privileged Group Membership

Review membership of highly privileged Active Directory groups (e.g., "Domain Admins", "Enterprise Admins") to verify that only necessary accounts are members and that no unauthorized users have been added.

# PowerShell command to list members of Domain Admins
Get-ADGroupMember -Identity "Domain Admins" | Select-Object Name
# Audit output to ensure only expected administrators are listed
