Cloud Security

Cloud Computing and Shared Responsibility

Understanding Security Obligations in the Cloud

The Shared Responsibility Model

Cloud providers and customers share security obligations. The customer's responsibility varies significantly based on the service model (IaaS, PaaS, SaaS).

Misconception: Cloud provider handles all security.
Key Takeaway

Auditors must verify that organizations understand and fulfill their security responsibilities within the cloud's shared model.
