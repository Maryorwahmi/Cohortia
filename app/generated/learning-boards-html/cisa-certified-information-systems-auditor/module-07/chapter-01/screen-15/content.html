Symmetric-key Cryptography

Uses a single secret key for both encryption and decryption, ideal for bulk data but challenging for key distribution (e.g., AES).

Asymmetric-key Cryptography

Employs a public/private key pair for encryption/decryption and digital signatures, solving key distribution issues (e.g., RSA, ECC).

Hashing

A one-way function that transforms data into a fixed-size string (hash value) to verify data integrity (e.g., SHA-256).

Summary Insight

Cryptography provides essential tools for confidentiality, integrity, and authenticity, with symmetric, asymmetric, and hashing methods forming its core.
