Log Collection Protocols

Commonly used protocols include Syslog for network devices and Linux systems, and Windows Event Forwarding for Windows events.

Security of Infrastructure

Auditors must assess if logs are encrypted in transit and if access to the log repository is strictly restricted to prevent tampering.

Key Takeaway

Centralized, secure log collection and aggregation are fundamental for maintaining log integrity and enabling efficient security analysis.
