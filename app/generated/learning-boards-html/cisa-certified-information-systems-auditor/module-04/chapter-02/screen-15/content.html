Key Concepts

Advanced Terms for Auditors

Transparent Data Encryption (TDE)

A technology used to encrypt entire database files at rest, protecting data on storage media.

Recovery Time Objective (RTO)

The maximum tolerable duration a system can be down after a disaster or failure.

Recovery Point Objective (RPO)

The maximum tolerable amount of data that can be lost from an IT service due to a major incident.

SQL Injection

A code injection technique used to attack data-driven applications by inserting malicious SQL statements.
