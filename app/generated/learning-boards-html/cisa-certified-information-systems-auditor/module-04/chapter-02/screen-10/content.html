DBA Core Tasks

Ensuring Database Health and Security

Database administrators perform critical tasks to maintain the security, performance, and availability of database environments. Auditors evaluate the effectiveness of these activities.

  • Patch Management: Regular updates to fix vulnerabilities.
  • Vulnerability Management: Identifying and remediating weaknesses.
  • Performance Tuning: Optimizing database operations.
  • Monitoring: Tracking resource utilization and health.
Risk Alert

Neglecting regular patching leaves databases exposed to known vulnerabilities, significantly increasing the risk of security breaches and data compromise.

Key Takeaway

Auditors must verify that DBAs have systematic processes for patching, vulnerability management, and performance monitoring to ensure database security and efficiency.

Monitoring Tools
# Linux: Check CPU, memory, I/O usage
$ top
$ iostat -xz 1 10

# Windows: Performance Monitor (perfmon)
# Open 'perfmon.exe' and add counters for:
#   - Processor(_Total)\% Processor Time
#   - Memory\Available MBytes
#   - PhysicalDisk(_Total)\% Disk Time
#   - SQLServer:Databases(_Total)\Transactions/sec

# Example SQL Query for long-running queries (SQL Server)
SELECT
    session_id,
    start_time,
    command,
    status,
    wait_type,
    wait_time,
    last_wait_type,
    cpu_time,
    total_elapsed_time,
    reads,
    writes,
    logical_reads,
    text
FROM sys.dm_exec_requests der
CROSS APPLY sys.dm_exec_sql_text(der.sql_handle)
WHERE status = 'running'
ORDER BY total_elapsed_time DESC;
Patch Management Process
  • Identify new patches (vendor alerts).
  • Assess impact and criticality.
  • Test patches in a non-production environment.
  • Schedule and deploy patches.
  • Verify successful deployment and functionality.
  • Document the entire process.
