Encryption Fundamentals

Protecting Data with Cryptography

Data encryption is a vital control for protecting data confidentiality. It renders data unreadable to unauthorized parties, even if they gain access to the storage or network.

  • Data at Rest: Encrypts stored data (e.g., database files, backups).
  • Data in Transit: Encrypts data moving across networks.
  • Key Management: Securely generating, storing, and rotating encryption keys.
Concrete Example

Transparent Data Encryption (TDE) encrypts entire database files on disk. SSL/TLS protocols secure the connection between a web application and the database server, encrypting data as it travels.

Key Takeaway

Auditors must verify that encryption is properly configured for data at rest and in transit, and that robust key management practices are in place to maintain data confidentiality.
