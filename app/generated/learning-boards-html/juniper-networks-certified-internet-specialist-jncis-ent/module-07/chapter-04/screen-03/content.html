Module 07 › Chapter 7.4 › Objectives — Details
Objective 1: Import / Export

Practice applying a policy to a BGP neighbor and use show route receive-protocol to see what arrived and show route protocol bgp to see what was installed after import filtering.

Objective 2: Interface/Static

Apply filters for static or direct routes when multiple candidates exist and verify the active route in the routing table after commit.

Objective 3: Policy chaining

Design small policies and chain them using next-policy to continue evaluation only when intended; test chain order in a lab.

Objective 4: Verify & Troubleshoot

Use show policy-options and the advertising/receive protocol commands to compare expected vs actual behavior and run commit check before committing.
