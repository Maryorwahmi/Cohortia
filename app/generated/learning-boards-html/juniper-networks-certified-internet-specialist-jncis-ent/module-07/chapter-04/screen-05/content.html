Process: Group vs Neighbor
Apply shared behavior at the group level and use neighbor-level policies for exceptions. The neighbor-level setting takes precedence over the group setting.
Group-level
Ideal for default filters and common transformations for multiple peers.
Neighbor-level
Use for per-peer exceptions and tighter controls; this overrides the group policy.
Verification commands
show protocols bgp group <group-name> detail • show protocols bgp neighbor <address> detail
Example scenario
set protocols bgp group EXTERNAL_PEER type external
set protocols bgp group EXTERNAL_PEER import GROUP_IN
set protocols bgp group EXTERNAL_PEER neighbor 203.0.113.2 import PEER_SPECIFIC_IN
In this setup GROUP_IN applies to all group peers, but PEER_SPECIFIC_IN overrides for 203.0.113.2 so that peer receives a tighter inbound filter.
Common mistake
Expecting group policies to always take effect. If a neighbor has its own policy, it will replace the group's policy for that neighbor.
