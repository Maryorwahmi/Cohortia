Module 07 › Chapter 7.4 › Static & Direct Routes
When to apply static route policies
Use import policies under routing-options static to pick which configured static routes are installed, especially when multiple candidates exist for the same prefix.
Practical uses
  • Choose a preferred static route among alternatives
  • Prevent accidental static advertisement via redistribution
Verification
Use show route protocol static to confirm installation. Run commit check before committing policy changes to avoid syntax issues.
Analogy
Think of policies as a gatekeeper: static routes exist in config drawers, but the gate decides which ones are allowed onto the stage of the routing table.
Key takeaway
Applying import policies to static routes gives operational control without changing static configuration, simplifying swaps and tests.
