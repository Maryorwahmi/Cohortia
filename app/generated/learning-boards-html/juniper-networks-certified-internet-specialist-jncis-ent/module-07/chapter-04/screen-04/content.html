Module 07 › Chapter 7.4 › Import & Export
Definition and behaviour
Import and export are evaluation points in the route-processing pipeline. Import acts on received routes before they are installed; export acts on local routes before advertisement.
Import — key points
  • Filters or modifies received routes before installation.
  • Used for inbound traffic engineering and security.
Export — key points
  • Controls what local routes are advertised or redistributed.
  • Critical for controlling outbound advertisements and redistribution sets.
Key Takeaway

Import changes what you accept; export changes what others see. Direction matters for troubleshooting.

Concrete example
set protocols bgp group EXTERNAL_PEER neighbor 203.0.113.2 import INBOUND_FILTER
set protocols bgp group EXTERNAL_PEER neighbor 203.0.113.2 export OUTBOUND_ADVERTISE
In this configuration the import policy is applied to routes received from 203.0.113.2, while the export policy filters what is sent to that neighbor.
Common misconception
Confusing import and export is common. If your router is not installing expected prefixes, first check receive-protocol output to confirm what arrived before blaming export filters.
