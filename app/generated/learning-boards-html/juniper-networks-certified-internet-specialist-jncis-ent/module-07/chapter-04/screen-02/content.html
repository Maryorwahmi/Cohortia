Module 07 › Chapter 7.4 › Learning Objectives
Learning Objectives
Build practical skills for applying and validating routing policies across BGP, OSPF, RIP, and static routes.
01
Apply import and export policies

Configure import to filter routes received and export to control advertised routes. This skill prevents unintended route acceptance or advertisement.

Verified competency milestone
02
Interface and static application

Apply policies to static route installation or direct routes when you need fine-grained control over what is installed in the local table.

Verified competency milestone
03
Design policy chaining

Compose modular policies and use next-policy to sequence evaluation. Modularity reduces errors and simplifies audits.

Verified competency milestone
04
Verify and troubleshoot policies

Use show policy-options, show route advertising-protocol, and show route receive-protocol to confirm behavior and find mismatches between expected and actual advertisements.

Verified competency milestone
