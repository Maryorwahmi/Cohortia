Module 07 › Chapter 7.4 › Verification Commands
Common verification commands
  • show policy-options — inspect policy statements and prefix-lists
  • show route receive-protocol bgp <neighbor-address> — routes received before import
  • show route protocol bgp <prefix> detail — installed BGP route attributes
  • show route advertising-protocol bgp <neighbor-address> — routes advertised after export
  • commit check — validate configuration syntax before commit
Walkthrough example
# Inspect policy config
show policy-options

# Compare received vs advertised routes
show route receive-protocol bgp 203.0.113.2
show route advertising-protocol bgp 203.0.113.2

# Check installed attributes
show route protocol bgp 192.0.2.0/24 detail
Compare the three outputs to locate whether a route was blocked on import, modified by a policy, or filtered on export.
