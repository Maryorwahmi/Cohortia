Module 07 › Chapter 7.4 › OSPF & RIP Export
Definition: Redistribution gate
Use export policies to control which direct, static, or BGP routes are redistributed into OSPF or RIP. This prevents uncontrolled flooding of prefixes into the IGP.
Match examples
  • protocol direct
  • protocol static
  • protocol bgp
Key Takeaway

Export to IGPs controls redistribution; always match protocol and prefix to avoid unintended advertisements.

Code example
# Example for OSPF export policy
set protocols ospf export OSPF_REDISTRIBUTION_POLICY

# Policy would match protocol direct, static, or bgp and accept selected routes
Attach this policy to the OSPF process so only the intended routes become LSAs in OSPF or are advertised by RIP.
Common misconception
Believing IGPs automatically share routes between areas or protocols. Redistribution requires explicit export configuration and careful matching.
