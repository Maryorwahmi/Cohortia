What an input filter does

Input filters run on packets entering an interface and are processed before routing decisions are made.

Common use cases
  • Block malicious traffic before it reaches internal hosts.
  • Prevent resource exhaustion on the router by dropping undesired packets early.
  • Filter IPv4 or other families selectively on logical units.
Verification
Use show firewall filter <name> counter and monitor traffic on the ingress interface to confirm matching behavior.
Example scenario

You need to prevent unwanted IPv4 connections from reaching an internal network. Apply an input filter on the external-facing logical unit so those packets are evaluated and dropped before routing.

Common misconception

An input filter on one physical interface does not automatically protect all destinations on the router; it only affects packets arriving on that interface.

Key Takeaway

Use input filters to stop threats early, then verify with counters and traffic monitoring to ensure your terms match expected packets.
