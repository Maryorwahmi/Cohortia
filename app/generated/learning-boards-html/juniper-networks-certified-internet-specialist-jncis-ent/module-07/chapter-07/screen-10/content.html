Module 8 › Chapter 7.7 › Order of operations
Packet processing timeline
1. Input Filter
Applied as packet arrives; can drop early.
2. uRPF
Optional source reachability check on the incoming interface.
3. Routing Lookup
Determines egress interface and next hop.
4. Output Filter
Applied before sending the packet out the egress interface.
Practical implication: if a packet is discarded by an input filter, it never reaches uRPF or routing. If uRPF drops it, you may need to adjust route or interface design rather than the filter. When results are unexpected, check both the filter counters and routing/uRPF state together.
Key Takeaway

Use the processing order to diagnose why a packet was dropped: input check first, then uRPF, then routing, then output.
