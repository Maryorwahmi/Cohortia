Module 8 › Chapter 7.7 › Chaining filters and evaluation order
Sequential evaluation

When you attach multiple filters in a list, they're checked in order. A terminating match stops evaluation immediately.

Step 1
Filter A evaluated first
Step 2
If Filter A accepts or discards, stop
Step 3
Otherwise evaluate Filter B
Verification pattern

Check counters per filter before and after chaining to confirm which filter produced the terminating action.

Design tip

Place cheap rejects or fast checks early to reduce CPU cost, and reserve expensive matches for later filters only if earlier checks pass.

Pitfall

Avoid broad accept terms early in the chain that prevent later, more specific security checks from running.
