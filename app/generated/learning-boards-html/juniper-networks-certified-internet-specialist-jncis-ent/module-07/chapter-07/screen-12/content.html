Module 8 › Chapter 7.7 › Monitor traffic and logs
Using monitor traffic

Start a capture on the interface you expect traffic to arrive on and include match conditions to reduce noise. Observe headers and timestamps for correlation.

Example command
monitor traffic interface <interface-name> detail
Using logs

If your discard term logs, check show log messages to find entries for dropped packets and the term that logged them. Use timestamps to match against captures.

Troubleshooting tip

If captured packets differ from expected values, adjust source-prefix entries or port matches rather than assuming the router misbehaved.

Key Takeaway

Combine monitor traffic captures and log messages with filter counters to pinpoint why packets are accepted or discarded.
