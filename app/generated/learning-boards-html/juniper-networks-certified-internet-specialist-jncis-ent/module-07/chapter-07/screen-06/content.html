Module 8 › Chapter 7.7 › Output filters
When to use output filters

Apply output filters when you need to control traffic leaving the router, or apply an egress policy after routing decisions are made.

Practical examples
  • Block specific TCP flows from being sent to an internal network.
  • Control egress traffic types after routing lookup completes.
Contrast with input filters

Input filters run before routing and can prevent resource usage. Output filters run after routing and act as a final check on packets about to leave.

Layered approach

Combine ingress and egress filters when you need layered defense: stop threats early and enforce egress policies later.

Verification

After applying an output filter, use show interfaces <name> detail and show firewall filter <name> counter to observe hits, and use monitor traffic on the egress interface if needed.
