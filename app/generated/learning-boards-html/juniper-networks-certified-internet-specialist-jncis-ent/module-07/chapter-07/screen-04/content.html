Module 8 › Chapter 7.7 › Applying a filter makes it active
Concept

A filter must be attached to interfaces and a family to inspect packets. Logical units and family context determine which traffic is affected.

Example attachment
interfaces {
    ge-0/0/0 {
        unit 0 {
            family inet {
                filter {
                    input EXAMPLE_FILTER;
                }
                address 192.0.2.1/24;
            }
        }
    }
}
Explanation & checklist
  • Define the filter under firewall family inet filter NAME.
  • Attach using filter input|output FILTER_NAME under the interface family.
  • Confirm family matches the traffic type (inet for IPv4).
  • Use show interfaces <interface> detail to verify attachment.
Key Takeaway

Attachment is the activation step. Always verify that the correct family and unit were used when you apply a filter.
