PROTECT_LO0 filter (exact structure)
firewall {
    family inet {
        filter PROTECT_LO0 {
            term ALLOW_MGMT_SSH {
                from {
                    source-address 192.168.100.0/24;
                    protocol tcp;
                    destination-port 22;
                }
                then accept;
            }
            term ALLOW_BGP_PEERS {
                from {
                    source-address 10.0.0.1/32;
                    source-address 10.0.0.2/32;
                    protocol tcp;
                    destination-port 179;
                }
                then accept;
            }
            term ALLOW_OSPF {
                from {
                    protocol ospf;
                }
                then accept;
            }
            term DISCARD_ALL_OTHERS {
                then {
                    log;
                    discard;
                }
            }
        }
    }
}

interfaces {
    lo0 {
        unit 0 {
            family inet {
                filter {
                    input PROTECT_LO0;
                }
                address 192.168.1.1/32;
            }
        }
    }
}
Annotation & test steps
  1. Commit the filter and apply to lo0 as input.
  2. From 192.168.100.x test SSH to the lo0 IP; it should succeed.
  3. From another IP try SSH; it should fail and be logged to messages if log is configured.
  4. Check show firewall filter PROTECT_LO0 counter to see term hits.
Key Takeaway

Explicit accept terms for known sources and protocols, then an explicit logged discard, give control and an audit trail for control plane traffic.
