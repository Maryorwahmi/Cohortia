Tag and match with communities

Communities let you mark routes and later select them in policies based on those tags.

Config snippet
policy-options {
    community CUSTOMER_A_ROUTES members 65000:100;
}

policy-statement FILTER_AND_TAG {
    term MATCH_BGP_COMMUNITY {
        from { protocol bgp; community CUSTOMER_A_ROUTES; }
        then accept;
    }
}
Practical notes
  • Agree community semantics with peers to ensure consistent tagging.
  • Use communities to selectively export or to prevent advertisement to certain peers.
  • Verify community values in the route table before relying on them in policies.
Key Takeaway

Communities are flexible tags; define, document, and verify before using them as policy selectors.
