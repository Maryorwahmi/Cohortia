Operator comparison

Choose the operator that expresses the prefix set you actually want to match.

exact
Matches only the prefix exactly as written.
orlonger
Matches the prefix and any more specific prefixes beneath it.
prefix-length-range
Specify a mask length window, e.g., /8-/24, to precisely control allowed masks.
Concrete examples
route-filter 10.0.0.0/8 orlonger
route-filter 172.16.0.0/16 prefix-length-range /24-/32
First matches any prefix inside 10.0.0.0/8 of any longer mask. Second matches only /24 to /32 prefixes within 172.16.0.0/16.
Gotcha: upto
upto matches less specific prefixes and is often the opposite of the desired behavior when you want more specific matches.
Key Takeaway

Pick route-filter operators that match the prefix-mask semantics you need; test in a routing table before committing to production.
