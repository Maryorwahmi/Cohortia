Module 7 › Chapter 7.2 › Protocol Matching
When to match by protocol

Control redistribution and exports by explicitly matching the route's origin protocol.

Use case
Advertise only OSPF-learned internal prefixes to a BGP peer while suppressing externally learned BGP prefixes.
Process
  1. Define prefix-list or route-filter for intended prefixes.
  2. Create term with from { protocol ospf; ... } then accept;
  3. Apply as export policy on BGP group and verify advertising output.
Key Takeaway

Protocol matching isolates a route's source, enabling precise redistribution decisions and safer exports.

Example term
set policy-options policy-statement EXPORT_POLICY term OSPF_ADVERTISE from protocol ospf
set policy-options policy-statement EXPORT_POLICY term OSPF_ADVERTISE from prefix-list ADVERTISED_PREFIXES
set policy-options policy-statement EXPORT_POLICY term OSPF_ADVERTISE then accept
After applying this as an export to a BGP peer, only OSPF-learned prefixes listed in ADVERTISED_PREFIXES will be sent.
