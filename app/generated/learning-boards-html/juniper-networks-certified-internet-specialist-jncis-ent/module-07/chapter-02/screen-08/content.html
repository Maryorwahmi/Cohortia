Module 7 › Chapter 7.2 › AS-path Matching
Regex examples and guidance

AS-path matching is applied to BGP routes and uses regex to match AS sequences in the path attribute.

Examples
as-path ".* 65000$"  # ends with 65000
as-path "^64500 ."  # starts with 64500 then at least one more AS
Combine with 'protocol bgp' in the 'from' block for clarity and safety.
Misconception
A regex that is too permissive can match unintended AS sequences. Test against actual AS-path values before committing.
Key Takeaway

AS-path regex gives precise control over BGP route selection. Validate patterns using real AS-path samples to prevent mistakes.

Concrete scenario
You want to accept only routes that originated in AS 64500. Use as-path "^64500$" to match paths that are exactly that AS. If you want routes that passed through 64500 last, use ".* 64500$".
