Module 7 › Chapter 7.2 › Key Concepts
Prefix-list
A named set of exact prefixes for reuse across policies.
Route-filter
Flexible prefix matching with operators like orlonger and prefix-length-range.
AS-path & community
Use regex to match AS paths and named communities to tag and select routes.
Takeaway

Design policies with clear match semantics, use terms to express OR, and always verify in a test environment. These practices keep routing predictable and auditable.
