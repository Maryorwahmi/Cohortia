Module 7 › Chapter 7.2 › Troubleshooting
Debug checklist
  • Confirm list and community names are correct in policy-options.
  • Inspect route entries for protocol, AS-path, and community values used in matches.
  • Test AS-path regex on sample strings to avoid overmatching.
  • Attach policy to a test peer and run show route advertising-protocol to verify effects.
Practical tip
Stage changes: start with narrow accept terms to confirm matches, then add broader rejects. Use an explicit reject term at the end to document denial behavior.
Common Mistake

Putting unrelated match types together expecting OR logic. That yields no matches and unexpected policy results.
