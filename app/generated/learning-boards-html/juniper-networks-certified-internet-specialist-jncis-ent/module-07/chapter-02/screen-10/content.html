Peer and adjacency selectors

These matches are concrete and precise: neighbor matches a specific peer, interface matches routes learned on an interface, next-hop matches the forwarding neighbor.

Use neighbor to
Apply policies that only affect traffic from a particular BGP neighbor IP.
Use interface to
Identify locally attached routes and control them by ingress interface.
Concrete example
A term with from { neighbor 192.0.2.1; route-filter 10.0.0.0/8 orlonger; } then reject; will reject 10.0.0.0/8 prefixes from that specific neighbor only.
Key Takeaway

Neighbor/interface/next-hop matches are precise tools for peer- or link-specific policies. Combine them with other matches for richer intent.
