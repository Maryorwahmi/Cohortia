Policer + count + log example
firewall {
    policer PROTECT_SSH_RATE_LIMIT {
        if-exceeding {
            bandwidth-limit 1m; # 1 Mbps
            burst-size-limit 15k; # 15 KB burst
        }
        then discard;
    }
    family inet {
        filter INGRESS_PROTECTION {
            term PROTECT_MGMT_SSH {
                from {
                    source-address 192.168.100.0/24;
                    protocol tcp;
                    destination-port 22;
                }
                then {
                    policer PROTECT_SSH_RATE_LIMIT;
                    count SSH_MGMT_ACCESS;
                    accept;
                }
            }
        }
    }
}
Explanation: the policer limits SSH traffic to 1 megabit with a small burst. When traffic exceeds the threshold, the policer discards the excess packets. The count increments SSH_MGMT_ACCESS for each matched packet, and accept permits allowed packets. Use 'show firewall filter' to inspect counters and 'show log messages' to see log output if you also add log statements to terms.
Misconfiguration to avoid
Setting if-exceeding too low causes legitimate sessions to be dropped. Tune policers after observing traffic with count and log.
