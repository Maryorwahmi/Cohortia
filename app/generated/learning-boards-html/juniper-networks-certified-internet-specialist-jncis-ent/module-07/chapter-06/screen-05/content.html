Match Types
Addresses, Ports, Protocols, Interfaces
  • Source/Destination address: match IP prefixes, from a single host to an entire network.
  • Source/Destination port: match TCP/UDP ports; specify protocol to make port checks meaningful.
  • Protocol: distinguish tcp, udp, icmp, gre and more to route logic correctly.
  • Interface: bind a term to traffic on a specific physical or logical interface.
Tip
When filtering services, combine destination-address, protocol, and destination-port so only the intended service is affected.
Concrete scenario
Protect a server on ge-0/0/1.0
set interfaces ge-0/0/1 unit 0 family inet filter input SERVER_ACCESS_CONTROL
set firewall family inet filter SERVER_ACCESS_CONTROL term ALLOW_SSH_HTTPS from destination-address 192.168.50.10/32
set firewall family inet filter SERVER_ACCESS_CONTROL term ALLOW_SSH_HTTPS from protocol tcp
set firewall family inet filter SERVER_ACCESS_CONTROL term ALLOW_SSH_HTTPS from destination-port [ 22 443 ]
set firewall family inet filter SERVER_ACCESS_CONTROL term ALLOW_SSH_HTTPS then accept
This example scopes the filter to the server address, limits matches to TCP, and only allows SSH and HTTPS ports.
