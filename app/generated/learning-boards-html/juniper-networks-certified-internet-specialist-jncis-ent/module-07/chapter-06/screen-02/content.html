Learning Objectives
Master match conditions, actions, ordering, and observability for practical firewall filters.

01
Configure 'from' match types
Select source/destination IPs, ports, protocol, interface, TCP flags, and ICMP types to narrow matching packets. Accurate matches reduce false positives and avoid accidental allow rules.
VERIFIED COMPETENCY MILESTONE
02
Combine multiple conditions (AND)
Understand that when you list multiple fields under a single 'from', a packet must match every field. This precision prevents unintended matches from a single broad condition.
VERIFIED COMPETENCY MILESTONE
03
Implement actions
Choose accept, discard, reject, count, log, and policer appropriately. Use discard for silent drops and reject when diagnostic feedback is desired.
VERIFIED COMPETENCY MILESTONE
04
Observe and protect
Combine count and log to measure hits, and apply policers to limit SSH or other management protocols. Verify with show firewall filter and system logs.
