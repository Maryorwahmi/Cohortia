Common Mistakes
Ports without protocol: Add 'protocol tcp' when matching TCP ports.
Term order: Place specific protections before broad accepts.
TCP flags: Include ACK for established sessions when appropriate.
Policer tuning: Observe before enforcing; avoid too-low thresholds.
Missing fallback: Add a catch-all accept if you don't want implicit discard.
Troubleshoot process
  1. 1. Reproduce the traffic from a client to see symptoms.
  2. 2. Use 'show firewall filter <name>' to inspect terms and counters.
  3. 3. Check system logs for entries from log actions.
  4. 4. Adjust protocol, ports, flags or term order and retest.
Key Takeaway

Systematic reproduction and inspection of counters/logs makes fixes precise rather than guesswork.
