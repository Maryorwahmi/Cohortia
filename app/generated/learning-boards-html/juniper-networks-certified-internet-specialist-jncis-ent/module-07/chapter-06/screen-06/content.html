Definition
TCP flags & ICMP types

TCP flags: match syn, ack, fin, rst or combinations to detect new versus established connections.

ICMP type/code: match specific control messages such as echo-request to permit or block pings and other diagnostic packets.

Example
Match established TCP: protocol tcp + tcp-flags '(ack|rst)'. Match ping: protocol icmp + icmp-type echo-request.
Practical caution
If you match only syn and then accept, you might allow connection attempts but not the rest of the session. Conversely, accepting only packets with ack can allow established sessions while blocking new ones. Structure terms to reflect connection lifecycle explicitly.
Check
When testing, try initiating and continuing a session. Verify both the initial SYN and subsequent ACK packets are handled as expected.
