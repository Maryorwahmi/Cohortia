Comparison
next-hop (attribute) vs install-nexthop (forwarding)
Understand whether you need to change the route attribute or the actual forwarding decision.
next-hop: modifies the route's next-hop attribute, e.g., next-hop self, to ensure reachability when advertising.
install-nexthop: specifies a forwarding next-hop, bypassing normal routing lookup for that destination.
Examples
# Next-hop
set policy-options policy-statement SET_NEXT_HOP term T1 then next-hop self

# Install-nexthop
set policy-options policy-statement CUSTOM_FORWARDING term T1 then install-nexthop 10.0.0.254
Use next-hop for advertisement reachability; use install-nexthop when you must force forwarding to a specific address for service chaining.
Warning: install-nexthop changes forwarding behavior directly. Test offline and be conservative in production.
