Objective evidence and verification tasks
Each card below pairs the objective with a concrete verification step.
01
Control acceptance
Task: Apply a term that rejects a test prefix and run show route to confirm it's not installed.
VERIFIED COMPETENCY MILESTONE
02
Manage evaluation flow
Task: Use next-term to set a community then accept in a later term; confirm both actions applied via show route detail.
VERIFIED COMPETENCY MILESTONE
03
Modify BGP attributes
Task: Set local-preference for a neighbor and confirm the route's local preference value in the route detail output.
VERIFIED COMPETENCY MILESTONE
04
Install next-hop
Task: Configure install-nexthop and then verify packet forwarding or the forwarding table to see the override take effect.
VERIFIED COMPETENCY MILESTONE
