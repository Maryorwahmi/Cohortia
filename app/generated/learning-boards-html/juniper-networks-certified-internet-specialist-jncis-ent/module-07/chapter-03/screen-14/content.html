Module 7 › Chapter 7.3 › Key Concepts
Accept / Reject
Accept installs a route; reject discards it. Attribute changes do not install by themselves.
next-term / next-policy
Control evaluation flow; ensure a subsequent accept exists or the route will be implicitly rejected.
Local-preference
BGP attribute that biases egress selection inside your AS; higher is preferred.
Summary: use the right action for the protocol, test changes in lab, and verify attributes with route detail commands before deploying widely.
