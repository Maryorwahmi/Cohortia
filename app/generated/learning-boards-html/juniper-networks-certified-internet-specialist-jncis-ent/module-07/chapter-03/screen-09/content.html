Comparison
community add | set | delete
Choose add to append, set to replace, delete to remove specific entries.
add — appends a new community to any existing tags.
set — replaces all existing communities with the given set.
delete — removes specified communities from the route.
Junos example
set policy-options community NO_EXPORT_COMMUNITY members "no-export"
set policy-options policy-statement ADD_COMMUNITY term T1 then community add NO_EXPORT_COMMUNITY

# To replace:
set policy-options policy-statement REPLACE_COMM term T1 then community set ISP_TAG

# To remove:
set policy-options policy-statement REMOVE_COMM term T1 then community delete OLD_TAG
Common mistake: replacing (set) when you intended to append (add), accidentally removing upstream communities needed by other policies.
Key Takeaway

When in doubt, add to preserve upstream tags. Use set only when overwriting is intentional and coordinated.
