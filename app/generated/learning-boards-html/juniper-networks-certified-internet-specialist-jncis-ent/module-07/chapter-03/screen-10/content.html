as-path-prepend
Prepend your AS to make advertised routes look longer and less preferred.
set policy-options policy-statement PREPEND_AS term T1 then as-path-prepend "65500 65500"
set policy-options policy-statement PREPEND_AS term T1 then accept
Verify what remote peers see by checking show route advertising-protocol bgp or coordinating with the peer to inspect the AS path.
Example scenario
You prefer ISP B for outbound customer traffic, so you prepend your AS toward ISP A to make ISP B's path more likely to be selected by remote networks.
Pitfall: overusing prepend can create unnecessarily long AS paths and complicate path visibility and troubleshooting across multiple peers.
Key Takeaway

Use AS path prepend for outbound de-preferencing. Test effects with advertising-protocol inspections and coordinate with peers when possible.
