Definition
Attribute modification — protocol context
Attributes only influence routing decisions when the protocol uses them; design policies accordingly.
BGP-only
local-preference, as-path-prepend, community
General / MED
metric maps to MED in BGP; influences external AS entry when considered.
Why this matters
  • Applying the wrong attribute wastes operations and can mislead troubleshooting.
  • Protocol semantics determine which attributes influence path selection.
  • Verification must read the route detail to confirm attribute presence.
Quick reference
Use this cheat-sheet when building terms:
local-preference — BGP inbound exit choice
as-path-prepend — lengthen AS path to de-prefer advertised routes
community add/set/delete — metadata tag for routing decisions and export
Common misconception: metric always changes path preference the same way across protocols. It does not; in BGP metric means MED.
