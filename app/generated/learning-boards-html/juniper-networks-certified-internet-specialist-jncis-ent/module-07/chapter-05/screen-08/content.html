Definition
Match Conditions (from)
Use fields like source-address, destination-port, protocol, and interface to identify packets.
  • Addresses: source-address, destination-address.
  • Ports: source-port, destination-port for TCP/UDP.
  • Protocol: tcp, udp, icmp — choose the right protocol family.
  • Interface: scope a filter to traffic coming on a specific physical or logical interface.
Example
Match packets from 10.0.0.0/24 using TCP destined for port 443.
Terminal example and notes
term ALLOW_HTTPS {
  from {
    source-address 10.0.0.0/24;
    protocol tcp;
    destination-port 443;
  }
  then accept;
}

/* All conditions must be true for the term to match */
Misconception
A single match like protocol tcp without ports may be too broad for service-specific rules.
Pro tip
Combine address, protocol, and port to limit surface area for a service.
