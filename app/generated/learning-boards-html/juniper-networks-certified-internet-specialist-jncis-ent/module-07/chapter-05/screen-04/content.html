Core Concept
What is a Firewall Filter?
A stateless rule set that inspects packets and enforces access control.
Quick bullets
  • Operates on the data plane and inspects individual packets.
  • Matches packet attributes via from statements and acts with then statements.
  • Does not track connection state; expects explicit rules for both directions.
  • Implicit discard drops packets not explicitly accepted.
Example
Allow SSH to loopback and implicitly drop other traffic.
Key Takeaway

Filters act on packets. They are essential for protecting device services but require careful rules to avoid accidental denial of legitimate traffic.

Practical Visual — Terminal-style configuration and notes
firewall {
    family inet {
        filter PROTECT_ROUTER_MGMT {
            term ALLOW_SSH {
                from {
                    protocol tcp;
                    destination-port 22;
                }
                then accept;
            }
            /* No other terms: implicit discard applies */
        }
    }
}
Misconception
Filters are stateful. (No: they are stateless on Junos routing platforms.)
Pro tip
During testing add then count or then log before switching to discard.
