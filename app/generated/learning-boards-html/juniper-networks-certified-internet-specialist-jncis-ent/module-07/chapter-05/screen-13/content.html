Block ICMP From a Specific Source
Create a filter that discards ICMP from 192.168.1.10 and allows other traffic.
set firewall family inet filter BLOCK_PING_FROM_SOURCE term BLOCK_ICMP_FROM_HOST from source-address 192.168.1.10/32
set firewall family inet filter BLOCK_PING_FROM_SOURCE term BLOCK_ICMP_FROM_HOST from protocol icmp
set firewall family inet filter BLOCK_PING_FROM_SOURCE term BLOCK_ICMP_FROM_HOST then discard

set firewall family inet filter BLOCK_PING_FROM_SOURCE term ALLOW_ALL_OTHERS then accept

set interfaces ge-0/0/0 unit 0 family inet filter input BLOCK_PING_FROM_SOURCE
commit and-quit
Verification
Ping from 192.168.1.10 should fail. Ping from another source should succeed. Use show firewall filter to inspect term counters.
Notes & safety
Include ALLOW_ALL_OTHERS to prevent implicit discard of unrelated traffic. During testing, replace then discard with then count or then log to confirm matches before enforcing the drop.
Key Takeaway

When blocking a specific source, always include explicit accepts for other traffic or you will trigger the implicit discard.
