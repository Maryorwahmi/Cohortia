Safety Notes
Common Mistakes
  • Forgetting implicit discard and not adding accept terms for legitimate traffic.
  • Incorrect term order: broad accepts before specific rejects.
  • Applying filter to wrong interface, logical unit, or wrong direction (input/output).
  • Expecting stateful behavior on stateless filters.
Best practices
  1. Document intended flows first, then write terms to match those flows.
  2. Test with then count/log, review counters and syslog entries.
  3. Apply filters during maintenance windows and ensure rollback access.
  4. Protect control-plane interfaces; avoid over-restrictive rules on loopback addresses.
Checklist
Intent, test, apply, monitor, rollback ready.
