PROTECT_ROUTER_MGMT
Allows SSH to loopback; implicit discard applies to other traffic.
firewall {
    family inet {
        filter PROTECT_ROUTER_MGMT {
            term ALLOW_SSH {
                from {
                    protocol tcp;
                    destination-port 22;
                }
                then accept;
            }
            /* No other terms: implicit discard applies */
        }
    }
}
Troubleshooting prompt
If SSH fails after applying, check: destination port configured, filter applied to the correct interface and direction, and whether management uses the loopback address specified.
Concrete example and next steps
If you want to also allow SNMP, add a term before the implicit discard that matches SNMP's UDP port and then accept. Always place specific accept terms before any discard or broad accepts used for different purposes.
Key Takeaway

Small, specific accept terms protect services while implicit discard enforces a tight security posture; plan additions deliberately.
