Definition
family → filter → term
Select address family, then name a filter, then add ordered terms.
Family
inet / inet6 / ethernet-switching
Filter
A named set of terms
Term
from { … } then { … }
Tip: keep separate filters per family to avoid accidental mismatches and to make intent clear in configuration audits.
Annotated example
firewall {
  family inet {                        /* IPv4 family */
    filter MY_FILTER {                 /* named filter */
      term T1 {                        /* term 1: evaluated first */
        from { source-address 10.0.0.0/24; }
        then accept;
      }
      term T2 {                        /* term 2: fallback */
        then discard;
      }
    }
  }
}
Common mistake
Applying an inet filter to IPv6 traffic or vice versa renders it ineffective.
Practice
Label filters clearly: the name should reflect intent, such as PROTECT_ROUTER_MGMT or BLOCK_ICMP_FROM_HOST.
