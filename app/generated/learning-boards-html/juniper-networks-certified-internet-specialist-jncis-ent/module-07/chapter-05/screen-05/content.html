Comparison
Routing Policies
Operate on routing updates and route attributes.
  • Control how routes are learned, selected, and advertised.
  • Run in the control plane and affect routing decisions.
  • Not suitable for blocking or permitting specific packets.
Misuse: using policies to protect management traffic.
Comparison
Firewall Filters
Operate on actual data packets and apply immediate actions.
  • Match packet attributes and then apply accept, discard, reject, log, or count.
  • Run in the data plane; can block access to device services.
  • Stateless on Junos routing platforms; require symmetric rules for bidirectional flows.
Practice: choose filters to protect interfaces and services.
