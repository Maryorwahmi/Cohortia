Module 7 › Chapter 7.1 › Where Policies Live
Definition vs application
Define policies under policy-options and reference them from protocol configurations to control import/export behavior.
Example
Define ACCEPT_OSPF_ROUTES under policy-options, then set it as the import policy on a BGP group to only accept OSPF routes into BGP.
Reuse pattern
One policy-statement can be referenced by many protocol contexts, ensuring consistent filtering or attribute modification across the device.
Verification
If a policy seems inert, confirm it's referenced correctly in the protocol configuration and that its logic contains explicit accepts for intended routes.
Application points
Typical application points include BGP import/export, policy for redistribution between protocols, and protocol-specific import lists. Policies themselves are agnostic of where they are applied until referenced.
Lab scenario
Set policy under policy-options, configure a BGP group, and reference the policy with set protocols bgp group NAME import POLICY to observe the effect.
