Learning Objectives
Master the fundamentals of Junos routing policy and practical configuration checks.
Bloom
Learn → Understand → Apply → Master
Progression: know the parts, explain the flow, write policies, verify behavior.
01
Explain policy purpose
Describe why you need policy control for secure and efficient routing. Recognize uncontrolled exchange risks like loops or leaks.
VERIFIED COMPETENCY MILESTONE
02
Identify policy structure
Name policy-statements, write ordered terms, and use from and then clauses to match and act on routes.
VERIFIED COMPETENCY MILESTONE
03
Apply a basic policy
Create a prefix-list, write a term that accepts those prefixes, and apply or import the policy to a protocol context.
VERIFIED COMPETENCY MILESTONE
04
Reason about term order
Predict evaluation using first-match-wins and avoid putting broad accepts before specific rejects.
VERIFIED COMPETENCY MILESTONE
