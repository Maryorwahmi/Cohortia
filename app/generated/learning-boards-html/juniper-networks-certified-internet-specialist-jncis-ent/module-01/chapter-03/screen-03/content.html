Practice each objective

Short practice steps you can run in a lab or simulator.

Distinguish modes — example
Start in operational mode and run show interfaces terse. Then type configure and confirm the prompt becomes a hash. This shows intent: one mode reads state, the other stages changes.
Navigate hierarchy — example
From configuration, edit system then set a description; use up and top to move back. Think of edit like changing directories into a configuration node.
Helpers: tab and ?
Type part of a command and press Tab to complete, or type ? to see valid subcommands and parameters for the current context.
Verify and apply — example
After making changes, run show | compare and commit check. If results look correct, use commit or commit and-quit to apply changes.
