Definition

Rollback, save, and load

Use committed snapshots and file operations to back up and restore configurations safely.

rollback
Revert to a previous committed configuration by index.
save
Write the current or candidate config to a file for backup.
load
Import a configuration file into the candidate configuration for review and commit.
Practical tip
Save a known-good configuration before attempting complex modifications, so you can rollback quickly if needed.
Example
# save current config
user@router# save /var/tmp/myconfig.conf
# load into candidate
user@router# load /var/tmp/myconfig.conf
# if needed, rollback to previous commit
user@router# rollback 1
