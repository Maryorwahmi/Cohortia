Comparison

Review changes safely

Use show | compare to see precise diffs between candidate and last committed configuration so you can spot unintended edits.

Example
user@router# show | compare
# displays only differences between candidate and committed configs

user@router# show | display set
# shows the full candidate as a set of 'set' commands
Practical uses
Use show | display set to export configuration snippets for reuse or automation scripts.
Misconception
Do not assume show | display set is the diff tool; use show | compare specifically to view deltas.
Check your understanding
After making a change, which command shows only what differs from the last commit? Answer: show | compare.
