Core Concept

Tab completion and ? contextual help

Use these tools to discover valid subcommands and parameters for the current context and prevent typing errors.

Tab completion
Type partial text and press Tab to complete or list possible completions. This is useful for long names and interface IDs.
Contextual help (?)
Type ? to see available commands and parameters in the current CLI context. Use it when unsure about the next token.
Examples
user@router> show int?
# suggests interfaces, interface-type
user@router# set interfaces ge-0/0/0 unit 0 family inet address 192.168.1.1/24 ?
# shows next available parameters for an address
Pro tip

When learning a new area, use ? frequently to understand the structure before typing full statements.

Common Mistake
Assuming Tab always completes; when ambiguous, Tab lists choices that you must select explicitly.
Reflective prompt: Which helper would you use if you remember only part of an interface name?
