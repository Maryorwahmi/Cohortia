Module 1 › Chapter 1.3 › Hierarchical Navigation
Definition

Configuration hierarchy

A tree-like structure where each node contains related configuration statements. Use navigation commands to target a specific node.

Navigation commands
  • edit <section> — enter a section
  • up — move one level up
  • top — return to the top-level configuration
Concrete example
user@router# edit interfaces
user@router# edit ge-0/0/0
user@router# set unit 0 family inet address 192.168.1.1/24
user@router# up
user@router# top
Tips and checks
Confirm your location in the hierarchy before running set. The prompt and contextual help help you avoid misplaced statements.
Misconception
Typing set without edit may add entries at top-level if you are not in the intended node. Scope carefully.
Check your change
Use show | display set to view the exact set commands that represent your candidate configuration for clarity.
Reflective prompt: After editing three nested nodes, which command returns you to the configuration root?
