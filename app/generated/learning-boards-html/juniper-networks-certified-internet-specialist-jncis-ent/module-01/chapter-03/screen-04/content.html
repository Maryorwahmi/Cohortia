Core Concept

Operational mode

A monitoring and diagnostic environment. Commands do not change the candidate configuration.

Key commands you will use:
  • show — view interfaces, routes, system info (e.g., show interfaces terse)
  • monitor — live packet capture or event streams (e.g., monitor traffic interface ge-0/0/0)
  • ping, traceroute — connectivity tests
  • request, file — system-level operations and file handling
Example
user@router> show interfaces terse
user@router> show route
user@router> monitor traffic interface ge-0/0/0
Key Takeaway

Use operational mode to inspect live state; nothing you run here commits changes.

Common Mistake
Confusing monitoring commands with configuration — show commands do not modify settings.
Walkthrough: Investigate an interface

If you suspect packet loss or errors on ge-0/0/0, run these commands to inspect state and traffic.

Inspect counters
show interfaces ge-0/0/0 extensive to see error counters and detailed statistics.
Quick summary
show interfaces terse to get a compact state view for all interfaces.
Live capture
monitor traffic interface ge-0/0/0 to capture packets for troubleshooting.
Reflective question: After viewing counters, do you need to edit configuration or only monitor further?
