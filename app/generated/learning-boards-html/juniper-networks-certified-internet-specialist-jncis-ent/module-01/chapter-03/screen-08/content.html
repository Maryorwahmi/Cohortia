Module 1 › Chapter 1.3 › run Command
Definition

run executes operational commands from config mode

Use run to check live state while remaining in the candidate configuration — ideal when you are deep in edit and want a quick status check.

Examples
user@router# run show interfaces terse
user@router# run show system uptime
user@router# run show interfaces ge-0/0/0 extensive
Why it matters

run saves time and prevents context switching by letting you verify operational facts without quitting configuration mode. This avoids accidental edits while checking live status.

Misconception
run does not stage changes or alter the candidate configuration; it reads operational state only.
