Activity

Guided CLI sequence

Follow these steps in a lab or simulator to practice mode switching and safe commits.

Step-by-step
  1. From operational: type configure to enter config mode.
  2. edit system and set description "Cohortia JNCIS-ENT Lab Device".
  3. run show system uptime to check uptime without leaving.
  4. show | compare to review diffs.
  5. commit check, then commit and-quit to apply and exit.
  6. Back in operational mode, run show system description to verify.
Starter command template
# From operational mode
configure
edit system
set description "Cohortia JNCIS-ENT Lab Device"
run show system uptime
show | compare
commit and-quit
# Verify
show system description
Why it matters
This loop ensures you preview and validate before applying changes.
Common Mistake
Forgetting to commit or assuming set applied immediately.
Check
Did show | compare show only intended changes?
Reflection: Which step prevented unwanted changes from being applied immediately?
