Process Flow

Enter configuration mode

Type configure or edit from operational mode. The prompt changes to hash to reflect you are editing the candidate configuration.

1
Edit
Use edit to change your position in the hierarchical configuration tree.
2
Set / Delete / Activate
Use set to add or change statements; delete to remove; deactivate to disable without removal.
3
Commit
After verification, commit makes the candidate configuration active.
Example session
user@router> configure
user@router# edit system
user@router# set description "Cohortia JNCIS-ENT Lab Device"
user@router# show | compare
user@router# commit and-quit
Why staging matters

The candidate approach gives you an isolated workspace to prepare changes, run checks, and review differences before altering the live configuration. This reduces risk in production environments.

Commands to know
set, delete, deactivate, activate, rename, insert
Misconception
Typing set does not immediately apply the change; it prepares the candidate configuration until commit.
Check your understanding
What command would you use to temporarily disable a statement without deleting it?
Reflective prompt: When would you prefer deactivate over delete?
