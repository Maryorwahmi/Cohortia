Junos CLI Operational & Configuration Modes

Learn when to observe device state, when to make changes, and how to use built-in tooling to avoid mistakes.

16:9 HD Classroom

You will learn: how the CLI prompt indicates your mode, how to navigate the configuration hierarchy, how to preview and safely apply changes, and how to use quick helpers like tab completion, the question-mark help, and the run prefix. These skills reduce risk when working on live devices and let you move confidently between viewing state and modifying it.

Operational
Monitor and diagnose. Example: show interfaces terse.
Configuration
Edit candidate config. Commands: set, delete, commit.
Tools
Tab, ?, run, show | compare help you work safely.
Quick example
user@router> configure
user@router# edit system
user@router# set description "Cohortia JNCIS-ENT Lab Device"
user@router# run show system uptime
user@router# show | compare
user@router# commit and-quit
