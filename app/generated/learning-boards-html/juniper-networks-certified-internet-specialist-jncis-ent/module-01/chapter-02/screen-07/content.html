Configure the me0 Interface and Basic Services
Add an IP to me0, enable SSH, and set host and system services before committing.
Configuration template
edit
set interfaces me0 unit 0 family inet address 192.168.100.1/24
set system services ssh
set system host-name JNCIS-Core-R1
set system domain-name cohortia.local
set system name-server 8.8.8.8
set system ntp server 0.pool.ntp.org
set system time-zone America/New_York
commit and-quit
Verify
show interfaces me0 terse show system services
Security note
Prefer SSH over Telnet; if you enable web-management use HTTPS only and restrict access with ACLs.
