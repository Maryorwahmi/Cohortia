Command checklist
These commands are used during initial device setup and verification.
configure
set system host-name JNCIS-Core-R1
set system root-authentication plain-text-password
set interfaces me0 unit 0 family inet address 192.168.100.1/24
set system services ssh
commit and-quit
show system host-name
show interfaces me0 terse
Note: plain-text-password is convenient for initial setup; consider encrypted-password or external auth later.
Verification & safety cards
Verify
Use show commands to confirm hostname, interface state, and service status after commit.
Safety
If a change causes problems, rollback to last commit rather than manually undoing many commands.
