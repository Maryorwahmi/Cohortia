Process Flow › Commit & Rollback
Typical sequence
configure
set system host-name JNCIS-Core-R1
set interfaces me0 unit 0 family inet address 192.168.100.1/24
commit and-quit
If a mistake is found before commit, use rollback 0. If a committed change must be undone, use rollback <number> to restore an earlier commit.
Practical guidance
  • Make small, incremental commits that are easy to test.
  • Use rollback instead of manual reversion to avoid human error.
  • Remember set commands only work in configuration mode; an error may indicate you are still in the operational shell.
