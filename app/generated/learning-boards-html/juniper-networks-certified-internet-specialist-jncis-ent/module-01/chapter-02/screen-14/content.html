What to Remember
Console Port
Initial, out-of-band access to the device for recovery and setup.
me0 / fxp0
Dedicated management Ethernet interfaces used for OOB management.
Commit & Rollback
Apply changes with commit; revert mistakes with rollback to a previous commit.
Summary Takeaway

Start with console access, secure root and user accounts, configure OOB on me0/fxp0, enable SSH, commit carefully, and verify with show commands.
