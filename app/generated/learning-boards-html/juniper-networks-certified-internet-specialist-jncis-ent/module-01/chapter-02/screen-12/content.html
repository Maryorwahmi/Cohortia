Check Your Understanding › Verification & Troubleshooting
Verification commands
show system host-name
show interfaces me0 terse
show configuration | display set
show system services
These commands confirm identity, interface state, full configuration in set format, and enabled services.
Troubleshooting checklist
  • If set is not recognized, switch to configuration mode with configure.
  • If me0 is unreachable, verify IP, mask, cabling, gateway, and ACLs.
  • Use rollback 0 to discard uncommitted errors or rollback <n> to restore earlier commits after a problematic commit.
Scenario
You commit a wrong IP to me0 and lose access. Reconnect via console, run rollback 0 from configuration mode to return to the last commit, correct the address, and commit again.
