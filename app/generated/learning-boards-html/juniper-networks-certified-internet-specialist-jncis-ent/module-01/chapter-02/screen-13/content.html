Lab command template
# From operational mode (>)
configure
set system host-name JNCIS-Core-R1
set system root-authentication plain-text-password
set interfaces me0 unit 0 family inet address 192.168.100.1/24
set system services ssh
commit and-quit

# Verify
show system host-name
show interfaces me0 terse
Reflection
Why is configuring me0 preferred over using a data-plane interface for management?
Safety reminder
Use strong, unique passwords and restrict access to the management network with ACLs or firewalls.
