Learning Objectives
Practice the commands and security steps required to bring a Junos device into service and protect management access.
Bloom: Learn → Understand → Apply → Master
You'll move from a working connection to confident, secure device administration.
01
Console connection
Use serial settings to reach a fresh device and observe the boot sequence. Verified competency milestone: connect and land at the operational prompt.
Mnemonic: physical cable → terminal
02
Root password & commit
Enter configuration mode, set the root password, and use commit to activate changes. Verified competency milestone: secure root and committed config.
Mnemonic: commit = save & apply
03
Out-of-band management
Assign an IP to me0 or fxp0 and configure gateway, DNS and NTP so the device is manageable via the management network. Verified competency milestone: reach device from management host.
Mnemonic: me0 = management ethernet
04
Users & services
Create local users with login classes, enable SSH, and restrict management traffic. Verified competency milestone: least-privilege user exists and SSH is functional.
Mnemonic: least privilege
