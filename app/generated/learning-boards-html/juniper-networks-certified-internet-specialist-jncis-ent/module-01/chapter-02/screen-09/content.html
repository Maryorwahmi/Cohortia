Core Concept › System Identity & Time
Commands to set identity and time
set system host-name JNCIS-Router-1
set system domain-name cohortia.local
set system name-server 8.8.8.8
set system ntp server 0.pool.ntp.org
set system time-zone America/New_York
commit
These settings ensure logs are identifiable and time-synchronized across infrastructure.
Syslog basics and verification
Configure system syslog to collect events and interactive-commands if you need audit trails for operator actions.
Example syslog
set system syslog file messages any notice set system syslog file interactive-commands interactive-commands any
Check
After commit, confirm time with show system uptime or review recent syslogs to ensure timestamps are correct.
