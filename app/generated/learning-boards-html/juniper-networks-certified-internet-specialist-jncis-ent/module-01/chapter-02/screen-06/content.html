Definition › Root Password & Config Mode
What to do
From the > prompt enter configuration mode, set the root password, and commit to apply.
configure
set system root-authentication plain-text-password
# enter and confirm password prompts
commit and-quit
Common mistake
Forgetting to commit leaves the old password active and creates a false sense of security.
Why this matters
The root account controls everything. A weak or default root password is the easiest path for an attacker to gain full control of the device.
Pro tip
Prefer encrypted-password or central auth for long-term security; use plain-text only for initial lab setup when necessary.
Check
After commit, verify by attempting an authenticated session or viewing committed configuration entries.
