Module 2 › Chapter 1.4 › Clearing State
Process Flow

Clear logs and statistics safely

Backup before clearing, then reset counters only when needed to create a new baseline.

Examples
clear log messages
clear interfaces statistics ge-0/0/0
# DANGEROUS: resets device to factory
request system zeroize
Dangerous command

request system zeroize erases all configuration and data. Only use for device disposal or rebuild with explicit authorization.

Key Takeaway

Always archive logs and config backups before any clear or reset, and treat zeroize as irreversible.
