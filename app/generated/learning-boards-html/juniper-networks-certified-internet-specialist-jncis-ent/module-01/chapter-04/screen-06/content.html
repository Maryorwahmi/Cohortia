Process Flow

Logging and real-time monitoring

Capture recent events, filter for relevance, and stream new messages as you reproduce faults.

Commands
show log messages
show log messages | last 10
show log messages | match "error"
monitor start messages
When to use
  • Use last lines to get recent context.
  • Match filters for targeted searches.
  • Stream in real time during recreations.
Example scenario

If a service stops, capture the last 50 lines, filter for service name or error, then start monitor start messages while attempting to restart the service to capture live events.

Key Takeaway

Filtering and streaming logs makes troubleshooting faster and more focused.

Misconception

Assuming logs keep every event forever — implement backups or remote syslog to preserve history.

Quick checklist
  • Capture last lines with show log messages | last N.
  • Filter with match for relevant keywords.
  • Use monitor start messages for live reproduction.
  • Back up logs before clears.
