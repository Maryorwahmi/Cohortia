Core Concept

Operational show commands

Gather non-destructive evidence about hardware, processes, interfaces, and routes.

show chassis environment
Temperatures, fans, power supply readings to detect overheating or failures.
show chassis alarms
Lists active alarms; treat them as clues, not noise.
show system processes extensive
Identify high CPU or memory processes during performance incidents.
Key Takeaway

Use multiple show outputs together to validate hypotheses before any change.

Example workflow
# Check hardware environment
show chassis environment

# Review active alarms
show chassis alarms

# Inspect process CPU and memory
show system processes extensive

# Confirm routing for a problem network
show route 10.0.0.0/8
Common misconception

A single show output proves root cause — instead, cross-check multiple outputs.

Pro tip

Capture outputs to a file before changes for later comparison.
