Learning Objectives

Skills to monitor device health, interpret logs, and run connectivity tests.

Bloom: Learn → Understand → Apply → Master
01
Run show commands for system health

Use commands like show chassis environment and show chassis alarms to detect hardware issues before they cause outages.

VERIFIED COMPETENCY MILESTONE
02
Interpret logs and stream events

Read show log messages and use monitor start messages to gather timely context when troubleshooting.

VERIFIED COMPETENCY MILESTONE
03
Perform ping and traceroute diagnostics

Confirm reachability and identify hop-level failures using ping options and traceroute path listings.

VERIFIED COMPETENCY MILESTONE
04
Monitor interfaces and clear safely

Use show interfaces terse/extensive and monitor interface, and clear statistics only when safe and understood.

VERIFIED COMPETENCY MILESTONE
