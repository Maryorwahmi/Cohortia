Core Concept

Interpreting interface error counters

Learn the likely causes behind CRC, input errors, and discards and how to test them.

CRC / input errors
Often indicate bad cable, transceiver, or electrical interference.
Discards
May indicate congestion, MTU mismatch, or policy drops.
Example diagnostic steps
  1. Run show interfaces <if> extensive and note error counters.
  2. Check physical connectors, replace cable/transceiver if errors persist.
  3. Verify link speed, duplex, and autonegotiation settings.
  4. If counters continue, investigate higher-layer causes like MTU or queue drops.
Key Takeaway

Start troubleshooting at the physical layer when you see CRC and input errors, then work upward.
