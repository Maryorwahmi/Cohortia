Evidence card

Capture outputs to files before clearing counters or making config changes; these records are critical for root cause analysis.

Common mistake

Changing interface configuration before reviewing logs and counters can obscure the original problem.

Key takeaway

Evidence first: alarms, logs, terse, extensive, tests — then controlled action.
