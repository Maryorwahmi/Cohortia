Module 2 › Chapter 1.4 › Ping vs Traceroute
Comparison

Ping

Checks reachability and round-trip time using ICMP echo requests.

Example
ping 8.8.8.8 count 5 source 192.168.1.1
Comparison

Traceroute

Shows each hop toward a destination to locate where packets are dropped or delayed.

Example
traceroute 8.8.8.8
Misconception

Traceroute always reflects full forwarding decisions — in practice, some hops may not respond to probes, so interpret with care.
