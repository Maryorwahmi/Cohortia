Module 2 › Chapter 1.4 › Interfaces & Stats
Definition

Interface status and traffic statistics

Confirm physical and logical status, inspect error counters, and observe live traffic.

show interfaces terse
Quick inventory of interfaces, link states, and addresses.
show interfaces <name> extensive
Detailed counters, media, errors that indicate physical problems.
monitor interface <name>
Live packets/bytes per second to observe traffic flows during tests.
Concrete example
show interfaces terse
show interfaces ge-0/0/0 extensive
monitor interface ge-0/0/0
Mistake to avoid

Resetting counters before you capture a baseline — always capture pre-reset output.

Key Takeaway

High input errors usually indicate physical issues; use extensive and monitor to confirm.
