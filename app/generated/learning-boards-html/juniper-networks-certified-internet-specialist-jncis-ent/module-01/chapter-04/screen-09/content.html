Architecture

Inspecting the routing table

Confirm active routes, next-hops, and preferences to understand forwarding decisions.

Command example
show route 10.0.0.0/8
Key Takeaway

If the route is absent, packets will not be forwarded to the destination regardless of interface state.

Practical checklist
  • Check show route <prefix> to confirm presence.
  • Verify next-hop reachability via ping.
  • If route exists, run traceroute to find hop-level failures.
Misconception

Assuming reachability if an interface is up — the routing table determines actual forwarding paths.
