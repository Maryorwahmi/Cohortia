Module 1 › Chapter 1.1 › Key Concepts
Routing Engine (RE)
Control-plane host that runs routing protocols, builds RIB, and manages the device.
Packet Forwarding Engine (PFE)
Data-plane hardware that forwards packets at line rate using the FIB installed by the RE.
Control Plane vs Data Plane
Control plane handles signaling and routing updates; data plane performs the actual packet forwarding.
Summary: Use these concepts as your first diagnostic filters when investigating network issues: control-plane symptoms suggest RE checks, forwarding symptoms suggest PFE checks.
