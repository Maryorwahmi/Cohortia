Learning Objectives

Master conceptual and operational skills that let you inspect and reason about Junos OS components safely.

01
Describe RE and PFE
Explain the Routing Engine as the control-plane host and the Packet Forwarding Engine as the data-plane hardware. Knowing this distinction helps you isolate slow convergence from forwarding faults.
VERIFIED COMPETENCY MILESTONE
02
Differentiate control & data plane
Map control-plane responsibilities such as routing protocols and management to the RE, and forwarding actions to the PFE. This clarifies why certain problems affect only convergence or forwarding.
VERIFIED COMPETENCY MILESTONE
03
Explain Junos design principles
Describe modularity, stability, and security benefits delivered by process isolation and a unified software image across devices for operational consistency.
VERIFIED COMPETENCY MILESTONE
04
Use the Junos CLI
Run basic operational commands to retrieve version, uptime, and routing-engine state and interpret those outputs to assess device health.
VERIFIED COMPETENCY MILESTONE
