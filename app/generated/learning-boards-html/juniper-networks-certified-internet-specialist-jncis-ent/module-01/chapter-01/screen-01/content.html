Junos OS Architecture and Design Principles

Understand the technical choices behind Junos OS: its FreeBSD base, the split between Routing Engine and Packet Forwarding Engine, and design principles that support scalable, stable operations.

In this lesson
Build a working model of RE vs PFE, see how modular daemons protect availability, and learn CLI practices that reduce operational risk.
Coming up
Hands-on commands to inspect version and routing-engine status, and a checklist for securing management interfaces.
RE
Routing Engine (RE)
Control Plane
FreeBSD UNIX
Provides process isolation, memory protection, and a mature system foundation that Junos leverages for stability and security.
Packet Forwarding Engine
ASICs and network processors using the forwarding table to move packets at line rate without consulting the RE per packet.
RE vs PFE
Dispatcher versus trains — decision logic separate from packet movement.
Modularity
Independent processes reduce blast radius when faults occur.
Transactional CLI
Staged changes and rollback protect running networks during configuration edits.
