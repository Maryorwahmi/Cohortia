Skills & Practices

These objectives tie architecture to hands-on checks and safe operational habits you will use regularly.

Diagnose RE issues
Interpret routing convergence delays by checking routing-engine health and protocol activity rather than assuming link or forwarding failure.
VERIFIED COMPETENCY MILESTONE
Verify PFE forwarding
Confirm that forwarding continues at line rate using forwarding-table checks and packet-based tests when available.
VERIFIED COMPETENCY MILESTONE
Secure management access
Apply strong authentication, prefer SSH, and limit access to the management interface to prevent unauthorized control-plane access.
VERIFIED COMPETENCY MILESTONE
Use transactional CLI
Stage and commit configuration changes, and use rollback to recover from unintended modifications to reduce outage risk.
