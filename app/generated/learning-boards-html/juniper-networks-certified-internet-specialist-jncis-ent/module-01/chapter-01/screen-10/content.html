Operational commands
Run these commands in operational mode to gather version, uptime, and routing-engine details.
show version show system uptime show chassis routing-engine
Example interpretation
If show version reveals a recent kernel build and show system uptime is short, expect recent maintenance. Use show chassis routing-engine to confirm the RE has stable CPU and memory.
Common pitfalls
  • Do not assume uptime alone shows stability; correlate with RE metrics and logs.
  • A spike in RE CPU during routing events suggests control-plane bottlenecks, not PFE forwarding faults.
Try this
Run the three commands and note the RE CPU percentage and memory usage to establish a baseline for future comparisons.
