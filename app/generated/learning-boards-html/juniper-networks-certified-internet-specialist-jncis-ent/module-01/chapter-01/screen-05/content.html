Module 1 › Chapter 1.1 › RE vs PFE
Routing Engine (RE)
Runs Junos software and manages the control plane: routing protocols, RIB, device management, and monitoring.
  • Executes OSPF, BGP, IS-IS and maintains RIB.
  • Handles CLI, SNMP, syslog and administrative functions.
  • Provides system monitoring and software process control.
Example
If BGP updates slow convergence, check RE CPU and routing process logs while confirming forwarding still operates.
Packet Forwarding Engine (PFE)
Specialized ASICs or network processors that apply the FIB for fast packet forwarding without per-packet interaction with the RE.
  • Receives forwarding entries from the RE as FIB updates.
  • Performs rapid lookups, filtering, and forwarding at line rate.
  • Isolated from control-plane load for predictable throughput.
Example
If packets stop forwarding but control-plane logs look healthy, investigate PFE hardware, forwarding table installation, or datapath errors.
Misconception
Do not assume the RE forwards traffic; forwarding is the PFE's responsibility in normal operation.
Check
When diagnosing, separate checks: RIB/process state for RE, forwarding-table and datapath counters for PFE.
Key takeaway
Clear role separation narrows root cause quickly — RE for protocol logic, PFE for traffic movement.
