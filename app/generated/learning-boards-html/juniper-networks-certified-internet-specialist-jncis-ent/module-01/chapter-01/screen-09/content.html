Secure management checklist
  • Set a strong root password and avoid defaults.
  • Use SSH, not Telnet, for remote management.
  • Limit management interface access to trusted hosts and VLANs.
  • Use centralized authentication (RADIUS/TACACS+) where possible.
Common mistake
Leaving management interfaces reachable from broad networks or using weak credentials exposes the RE and ultimately the entire network.
Controls applied to the control plane
Apply firewall filters, limit input to secure protocols, and monitor management-plane logs to detect suspicious activity early.
Why it matters
The RE controls routing and configuration; protecting it prevents attackers from hijacking routing decisions or making harmful changes.
