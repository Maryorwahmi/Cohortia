Process Flow

Post-config verification

Concrete steps to validate summarization
1. Check adjacencies
show ospf neighbor on ABR and peers
2. Inspect Type 3 LSAs
show ospf database area ... type 3 to view summary LSAs
3. Verify remote table
show route protocol ospf on remote area router
4. Confirm discard route
show route for the summary on the ABR to see null0 behavior
5. Validate contiguity & placement
Ensure area-range is under the origin area and prefixes align to the summary mask
Key Takeaway

A short verification sequence catches the majority of misconfigurations: neighbors, LSAs, remote tables, discard route, and summary placement.
