Module 5 › Chapter 5.2 › Key Concepts
Area Border Router (ABR)
Connects areas, keeps separate LSDBs, runs per-area SPF, and enables inter-area routing.
Type 3 Summary LSA
Created by ABRs to advertise inter-area reachability without leaking full LSDBs.
Route Summarization
Aggregate contiguous prefixes into one advertisement to reduce routing table size and LSA flooding.
Takeaway
Use area-range on the ABR for the origin area, verify summaries and discard routes, and weigh scalability benefits against the loss of per-prefix detail.
