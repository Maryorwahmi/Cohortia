Module 5 › Chapter 5.2 › How ABRs advertise inter-area routes
Process Flow

Type 1/2 → Type 3 conversion

ABR computes SPF per area and advertises inter-area reachability as Type 3 Summary LSAs rather than flooding detailed LSDBs.

Step 1: Learn locally
ABR receives Type 1/2 LSAs in Area 1 and populates Area 1 LSDB.
Step 2: Run SPF
ABR runs SPF for Area 1 LSDB to determine best paths to prefixes in that area.
Step 3: Generate Type 3
ABR creates Type 3 Summary LSAs to advertise reachability into other areas, typically into Area 0.
Key Takeaway

Type 3 LSAs carry reachability, not full topology. ABRs protect area boundaries and reduce LSDB visibility.

Concrete example
Area 1 has 172.16.1.0/24, 172.16.2.0/24, 172.16.3.0/24. ABR runs SPF in Area 1, then advertises their reachability into Area 0 using Type 3 LSAs. If summarization is applied, the ABR may send 172.16.0.0/22 instead of three /24s.
Common misconception
Type 3 LSAs do not convey per-link costs inside the originating area. They only indicate reachability and next-hop information from the ABR's perspective.
