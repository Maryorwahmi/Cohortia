Module 5 › Chapter 5.2 › What is an ABR?
Core Concept

Area Border Router

A router with interfaces in multiple OSPF areas and at least one in Area 0. It isolates LSDBs and translates LSAs across area boundaries.

Separate LSDBs
ABRs keep a distinct link-state database for each connected area and run SPF per area.
LSA translation
Type 1/2 LSAs learned in one area are summarized into Type 3 LSAs when advertised into another area.
Key Takeaway

ABRs enable hierarchical OSPF by limiting LSDB scope and translating area-local information into inter-area summaries.

Annotated example
Area 1 LSDB
Contains Type 1/2 LSAs for area-local links and prefixes. SPF runs on this LSDB only.
Area 0 LSDB
Contains Type 1/2 LSAs for backbone and Type 3 summary LSAs injected by ABRs.
