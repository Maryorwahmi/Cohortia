Question

Find the most specific summary

Given four /24s in Area 1, calculate the correct summary and the Junos command to apply it on the ABR.

Correct answer
Most specific summary: 10.0.0.0/22 Junos command: set protocols ospf area 0.0.0.1 area-range 10.0.0.0/22 (apply under Area 1)
Why this works
The component networks share common bits up to the first 22 bits so a /22 covers them without being unnecessarily broad.
Verification
After applying, check show route protocol ospf on a remote router and show ospf database area x type 3 on the ABR.
