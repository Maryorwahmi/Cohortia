Definition

Route Summarization

Combining multiple contiguous prefixes into a single larger prefix to reduce the number of advertised routes.

Contiguity requirement
All component prefixes must fall within the binary range of the summary mask.
Safety mechanism
Junos creates a discard route for a configured summary to prevent unintended forwarding to non-existent subnets.
Analogy

Think of a summary as one mailing address for a block of contiguous houses instead of listing each house separately.

Concrete example
192.168.1.0/24, 192.168.2.0/24, 192.168.3.0/24 → summary 192.168.0.0/22 when contiguous and aligned to /22 boundary.
Common mistake
Choosing a summary that covers addresses not present in the area. This can cause dropped traffic or require a discard route to protect the network.
Check your understanding
If you see a summary route but traffic for a covered subnet fails, what should you check first? Verify component prefixes exist in the originating area and the ABR's discard route behavior.
