Module 5 › Chapter 5.2 › Default vs Summarization
Default Behavior

Per-prefix Type 3 LSAs

ABR advertises each prefix learned in an area as separate Type 3 LSAs when no manual summary is configured.

Pros: Precise reachability, no accidental hiding of routes.
Cons: Many LSAs, larger remote routing tables, more SPF work.
Manual Summarization

area-range aggregation

ABR advertises a single summary prefix for multiple contiguous prefixes, reducing LSAs and routing table size.

Pros: Smaller routing tables, less LSA flooding, improved convergence for remote areas.
Cons: Risk of hiding detail; incorrect summary choices can cause dropped traffic unless safeguarded.
Verification tip: run show route protocol ospf on a remote-area router to confirm it sees the summary prefix rather than individual subnets after configuring area-range on the ABR.
