Definition › Interface Priority
Priority controls DR election
Higher priority wins DR election on broadcast or NBMA segments. Priority 0 prevents a router from becoming DR or BDR.
set protocols ospf area 0.0.0.0 interface ge-0/0/0.0 priority 100
Operational notes
  • Use priority to prevent resource-constrained devices from becoming DR.
  • Router ID breaks ties; priority is the primary control.
  • Change priorities carefully to avoid unnecessary re-elections.
Misconception
Priority 0 eliminates DR role but does not stop the router from participating in OSPF; it only avoids DR/BDR duties.
Key Takeaway

Set interface priorities deliberately to elect capable DRs and reduce broadcast-segment instability.
