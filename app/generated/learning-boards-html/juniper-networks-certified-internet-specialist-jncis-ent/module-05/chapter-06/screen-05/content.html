Definition › Show Commands Walkthrough
Commands to run
show ospf neighbor
Verify neighbor ID, interface, state and priority.
show ospf interface <int> detail
Compare hello, dead, cost, auth, network type, and MTU.
show ospf database [type]
Confirm LSAs exist and propagate as expected.
show route protocol ospf
Check which routes were installed and their metrics.
show ospf statistics
Look for missing hellos or excessive LSAs which indicate flaps or storms.
Code examples
show ospf neighbor
show ospf interface ge-0/0/0.0 detail
show ospf database router
show ospf database summary
show route protocol ospf
show ospf statistics
Pro tip
Capture outputs with timestamps and compare across routers; this creates reliable evidence when troubleshooting intermittent issues.
