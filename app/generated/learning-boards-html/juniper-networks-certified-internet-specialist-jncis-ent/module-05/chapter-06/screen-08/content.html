Comparison › LSA Flooding & LSDB
LSA consistency checks
  • Run show ospf database [type] on multiple routers and compare LSAs and sequence numbers.
  • Look for missing LSAs, lower sequence numbers, or LSAs aged out only on some routers.
  • Check for filters, area type mismatches, and adjacency issues on routers that lack LSAs.
Example
An external LSA from an ASBR appears on the ABR but not on some internal routers — inspect ABR and downstream adjacencies for flood blockage.
Quick commands
show ospf database router
show ospf database network
show ospf database summary
show ospf database external
Misconception
Missing route in the routing table is not proof of LSDB inconsistency; verify the LSDB first before changing policies.
Key Takeaway

Compare LSDBs across routers and use sequence numbers to find where flooding stopped; fix adjacencies or filters accordingly.
