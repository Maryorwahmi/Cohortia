Core Concept › Interface Cost
Reference-bandwidth
Ensure all routers use the same reference-bandwidth so cost derivation from bandwidth is comparable. For high speed cores, increase the reference to reflect the fastest links.
Manual cost
set protocols ospf area 0.0.0.0 interface ge-0/0/0.0 cost 10
Use manual costs for traffic-engineering where simple metrics suffice.
Verification
Use show ospf interface <if> detail to confirm the cost and show route protocol ospf to see installed path and metric. Make changes incrementally and document them.
Misconception
Changing only one side's cost or reference-bandwidth can produce inconsistent decisions; apply settings domain-wide.
Key Takeaway

Consistent reference-bandwidth and deliberate manual costs make OSPF path selection predictable and auditable.
