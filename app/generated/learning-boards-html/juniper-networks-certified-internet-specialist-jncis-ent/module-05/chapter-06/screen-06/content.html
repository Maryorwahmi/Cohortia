Process Flow › traceoptions Workflow
Configure traceoptions
set protocols ospf traceoptions file ospf-debug size 1m files 2
set protocols ospf traceoptions flag hello detail
set protocols ospf traceoptions flag error
set protocols ospf traceoptions flag state
commit
Limit file size and flags to reduce resource usage. Use detail for verbose hello output only when needed.
Inspect and clean up
After reproducing the issue, run:
show log ospf-debug | last 50
delete protocols ospf traceoptions
commit
Common mistake
Leaving traceoptions enabled in production can fill disk and increase CPU; always delete when done.
Key Takeaway

Traceoptions are powerful but must be used briefly and with targeted flags to avoid impacting device resources.
