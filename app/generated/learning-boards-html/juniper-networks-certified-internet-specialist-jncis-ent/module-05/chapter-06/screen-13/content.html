Core Concept › Best Practices
Reference-bandwidth
Configure consistently across all routers so costs are meaningful.
Router ID via loopback
Use loopbacks for stable IDs to avoid unnecessary SPF changes.
Authentication
Enable MD5/SHA in production to prevent unauthorized LSAs.
Minimize ABRs/ASBRs
Too many border routers increase LSDB and SPF overhead.
Avoid virtual links
Use them only as a last resort and document why they exist.
Document changes
Track costs, priorities, timers, and summarization to speed troubleshooting.
Key Takeaway

Preventive design plus careful, documented changes reduce the need for emergency debugging and make incidents easier to resolve.
