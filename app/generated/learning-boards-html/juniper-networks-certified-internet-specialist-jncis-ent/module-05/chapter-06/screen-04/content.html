Core Concept › Adjacency Formation
Adjacency causes
  • Area ID mismatch — routers think they are in different areas and will not form adjacency.
  • Authentication mismatch — differing auth type or keys prevents hello acceptance.
  • Timer mismatch — hello/dead intervals must match or adjacency fails.
  • MTU mismatch — ExStart/DBD exchanges fail if MTU differs.
  • Network type mismatch — broadcast vs point-to-point affects DR election behavior.
Example
R1 hello 5s vs R2 hello 10s causes adjacency to stall; fix by matching timers.
Misconception
Link up at L2 does not guarantee adjacency if OSPF parameters differ.
Diagnosis checklist
show ospf neighbor
Confirm neighbor state, interface, ID and priority.
show ospf interface <if> detail
Compare hello/dead, cost, auth, network type and MTU.
Practical check
Change one parameter at a time, commit, and observe neighbor state transitions.
Key Takeaway

Use show commands to compare configuration and runtime details; mismatches are usually the cause.
