Comparison › Route Calculation
Causes
  • Reference-bandwidth mismatch causing inconsistent default costs on fast links.
  • Manual interface cost misconfiguration altering SPF preferences.
  • Summarization hiding more specific prefixes and changing path selection.
  • Redistribution metrics causing external LSAs to be preferred.
Example
Set reference-bandwidth consistently; otherwise a 10Gb link may have the same cost as a 100Mbps link under default settings.
Fix checklist
  1. Check show ospf interface detail to see interface cost.
  2. Confirm domain-wide reference-bandwidth setting and align it on all routers.
  3. Review ABR summarization ranges and redistribution metrics.
  4. Make one change at a time and verify show route protocol ospf results.
Misconception
Assuming physical bandwidth alone determines path selection; OSPF uses configured cost derived from reference-bandwidth and manual overrides.
Key Takeaway

When routes change unexpectedly, verify costs and summarization before assuming a connectivity fault elsewhere.
