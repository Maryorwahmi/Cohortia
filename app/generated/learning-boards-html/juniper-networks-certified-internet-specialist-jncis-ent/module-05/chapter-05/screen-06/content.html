Comparison › Import vs Export
Export Policy
Used at ASBRs to control which routes are advertised into OSPF. Useful to prevent unwanted static or external routes from entering the OSPF domain.
Example
Redistribute only 172.16.10.0/24 into OSPF and reject others.
Import Policy
Control which routes learned from OSPF are accepted into the routing table. Common when handling external LSAs or when more selective acceptance is required.
When to use
When you need to protect an internal routing table from specific external or redistributed prefixes.
Verification checklist
After applying an export policy on the ASBR, run show route protocol ospf on an internal router and confirm only permitted prefixes are present. For import policies, verify the local routing table and LSA handling.
