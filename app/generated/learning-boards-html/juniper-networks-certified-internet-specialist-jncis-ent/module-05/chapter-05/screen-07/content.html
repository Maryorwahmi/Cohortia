Process Flow › Build & Apply
Step-by-step
  1. Create prefix-list — declare ALLOWED_PREFIXES and add 172.16.10.0/24.
  2. Write policy-statement — term ALLOW: from protocol static and from prefix-list ALLOWED_PREFIXES then accept.
  3. Add explicit reject — term DENY_ALL then reject for clarity.
  4. Apply export — set protocols ospf export FILTER_STATIC_TO_OSPF on the ASBR.
  5. Verify — confirm on downstream router with show route protocol ospf.
Example snippet
set policy-options prefix-list ALLOWED_PREFIXES 172.16.10.0/24
set policy-options policy-statement FILTER_STATIC_TO_OSPF term ALLOW from protocol static
set policy-options policy-statement FILTER_STATIC_TO_OSPF term ALLOW from prefix-list ALLOWED_PREFIXES
set policy-options policy-statement FILTER_STATIC_TO_OSPF term ALLOW then accept
set policy-options policy-statement FILTER_STATIC_TO_OSPF term DENY_ALL then reject
set protocols ospf export FILTER_STATIC_TO_OSPF
Key Takeaway

Follow a repeatable sequence: list prefixes, match protocol, accept intended routes, reject others, then verify externally.
