How to use these objectives
Follow the lab scenario to build, apply, and test a filtering policy on an ASBR, then implement a simple PBR rule that sends a source network to a designated next-hop. Use the verification steps to confirm each change.
Lab checklist
Create prefix-list, policy-statement, apply as OSPF export, confirm route visibility on downstream router.
PBR checklist
Define firewall filter term with from source-address and then next-hop, apply to interface, monitor traffic.
