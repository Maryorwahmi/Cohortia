Protocol match example

Route tag pattern
Tag when redistributing, then filter by tag on the receiving side or before export to control scope.
# Tag at redistribution
set policy-options policy-statement TAG_AND_REDISTRIBUTE term 1 from protocol bgp
set policy-options policy-statement TAG_AND_REDISTRIBUTE term 1 then set tag 100
set policy-options policy-statement TAG_AND_REDISTRIBUTE term 1 then accept
# Later, filter by tag
set policy-options policy-statement FILTER_BY_TAG term ALLOW from route-tag 100
set policy-options policy-statement FILTER_BY_TAG term ALLOW then accept
