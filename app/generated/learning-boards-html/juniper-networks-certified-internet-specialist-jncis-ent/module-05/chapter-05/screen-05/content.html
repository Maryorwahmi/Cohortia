Definition › Policy Anatomy
Terms, matches, and actions
  • From: prefix-list, protocol, route-tag, interface.
  • Then: accept, reject, set next-hop, set metric, set tag.
  • Evaluation is ordered; first match wins.
Practical example
Tagging and specific accepts make policies easier to maintain. Tag routes when redistributing, then create terms that match tags rather than raw prefixes when you have many networks to control.
Misconception check
Don't assume a missing route is a protocol issue; it may be filtered by a policy with no accept term. Explicitly accept what you need.
Pro tip
Test each term incrementally and prefer human-readable tags to large prefix-lists for complex redistributions.
