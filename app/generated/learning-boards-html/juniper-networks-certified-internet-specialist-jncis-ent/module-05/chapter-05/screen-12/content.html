Lab Walkthrough › Hands-on Scenario
Task checklist
  1. Configure R1 as ASBR and add static routes 172.16.10.0/24 and 172.16.11.0/24.
  2. Create prefix-list ALLOWED_PREFIXES with 172.16.10.0/24.
  3. Create policy FILTER_STATIC_TO_OSPF matching protocol static + prefix-list; accept then explicit reject.
  4. Apply set protocols ospf export FILTER_STATIC_TO_OSPF on R1.
  5. On R2 run show route protocol ospf and confirm only 172.16.10.0/24 is present.
  6. On R1 configure firewall filter PBR_REDIRECT matching source 10.0.0.0/24 then next-hop 10.0.0.254 and accept; apply to interface.
  7. Use monitor traffic and show route forwarding-table to confirm PBR behavior and check for asymmetry or loops.
Verification commands
show route static — confirm static routes on ASBR.
show route protocol ospf — verify routes learned on internal router.
show interfaces ge-0/0/0 detail — confirm filter attachment.
monitor traffic interface ge-0/0/0 extensive — observe redirected packets.
show route forwarding-table — confirm forwarding next-hop for PBR matched traffic.
Key Takeaway

Follow the checklist and verification commands exactly; testing in a lab prevents accidental route loss or loops in production.
