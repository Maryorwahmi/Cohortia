Code Walkthrough › PBR Filter Example
Firewall filter for PBR
set firewall family inet filter PBR_POLICY term VOICE_TRAFFIC from source-address 10.0.0.0/24
set firewall family inet filter PBR_POLICY term VOICE_TRAFFIC from destination-port 5060
set firewall family inet filter PBR_POLICY term VOICE_TRAFFIC then next-hop 192.168.1.1
set firewall family inet filter PBR_POLICY term VOICE_TRAFFIC then accept
set firewall family inet filter PBR_POLICY term DEFAULT_TRAFFIC then accept
set interfaces ge-0/0/0 unit 0 family inet filter input PBR_POLICY
Verification steps
  • Confirm filter applied: show interfaces ge-0/0/0.0 detail.
  • Observe redirected traffic: monitor traffic interface ge-0/0/0.0 extensive.
  • Check forwarding decisions: show route forwarding-table to see chosen next-hop for matched flows.
Misconfiguration check
Avoid next-hops that lead back to the same router and ensure other traffic is permitted by the default term.
