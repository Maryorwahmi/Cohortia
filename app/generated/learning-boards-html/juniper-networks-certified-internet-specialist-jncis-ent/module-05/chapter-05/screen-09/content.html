Core Concept › Policy-Based Routing
When to use PBR
  • Traffic engineering for specific applications like voice or video.
  • Directing guest networks to a particular internet uplink.
  • Rerouting suspicious traffic to an inspection device.
  • Fine-grained load-sharing beyond ECMP capabilities.
Risks & checks
Watch for asymmetric routing and routing loops. Validate using monitor traffic and show route forwarding-table to ensure the next-hop is applied and return paths are acceptable.
Quick analogy
Think of OSPF as a GPS choosing the shortest route. PBR is a manual detour you set for certain drivers based on vehicle type or origin.
