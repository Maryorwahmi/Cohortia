Module 5 › Chapter 5.3 › Junos Redistribution Example
Config template
# Define a policy to select static routes
set policy-options policy-statement REDISTRIBUTE_STATIC term 1 from protocol static
set policy-options policy-statement REDISTRIBUTE_STATIC term 1 then accept

# Apply the policy to OSPF and specify metric and metric-type
set protocols ospf export REDISTRIBUTE_STATIC
set protocols ospf export REDISTRIBUTE_STATIC metric 200 metric-type 1

# Interface and area examples
set interfaces ge-0/0/0 unit 0 family inet address 10.0.0.1/24
set protocols ospf area 0.0.0.0 interface ge-0/0/0.0
Concrete example

Configure static 172.16.10.0/24 on R1, create REDISTRIBUTE_STATIC to match protocol static, and export with metric 200 metric-type 1 so internal cost is added.

Common mistake

Creating a policy but not applying it via set protocols ospf export — no redistribution will occur.

Verification
On the ASBR: show ospf database external — confirm Type 5 LSA for redistributed prefix.
On internal router: show route protocol ospf — confirm the external route, metric, and whether it shows Ext1 or Ext2.
Key Takeaway

Policies control what is redistributed; export with metric and metric-type controls how OSPF treats that external route.
