Module 5 › Chapter 5.3 › Verification Commands
Common commands
show ospf neighbor
show route 172.16.10.0/24
show ospf database external
show ospf database nssa
show route protocol ospf
On ASBR: Expect the static route in the routing table and a Type 5 (or Type 7 for NSSA) in the OSPF database.
On ABR: Confirm translation from Type 7 to Type 5 for NSSA-sourced externals.
On internal router: Expect the prefix under OSPF with Ext1 or Ext2 depending on metric-type.
Diagnostic tips
  • If no external LSA appears, check the export policy and whether it is applied.
  • If metrics differ, check metric and metric-type in the export stanza and any policy-set attributes.
  • To trace loops, inspect route tags and history of redistributions between protocols.
Key Takeaway

Use the listed show commands to confirm both LSA presence and how downstream routers learn the external prefix; verification ensures correct behavior before traffic relies on redistributed routes.
