Assessment

Which external type achieves nearest-ASBR preference?

If you want internal routers to choose the nearest ASBR by internal OSPF cost, configure redistributed routes as External Type 1. E1 adds the internal cost to reach the ASBR to the external seed metric so closer routers prefer the closer ASBR.

Assessment task

Create two ASBRs redistributing the same prefix. Configure both to export the prefix as E1 and check which ASBR each internal router prefers based on their OSPF cost.

Reflective question

When might E2 be the better choice? Consider cases where the external seed metric should determine preference regardless of internal topology.

Key Takeaway

Metric-type is a design decision: choose E1 for nearest-ASBR selection; choose E2 when the seed metric alone should determine preference.
