Module 5 › Chapter 5.3 › What is an ASBR?
Definition

Autonomous System Boundary Router

A router that connects an OSPF domain to external routing sources and redistributes routes into OSPF so internal routers can reach them.

Analogy

Like a customs gate: it reports external networks and enforces which ones are allowed into OSPF.

Misconception

Connected to an external link does not auto-make a router an ASBR; explicit redistribution makes it one.

Concrete example

An edge router learns internet prefixes via BGP and you choose to redistribute selected prefixes into OSPF so internal routers can forward traffic toward the edge without running BGP everywhere.

Why it matters

Proper redistribution controls reachability and prevents unstable routing if filters or tags are missing.

Key takeaway

Only configure redistribution where you want OSPF to learn external prefixes and protect against loops with tagging and policies.
