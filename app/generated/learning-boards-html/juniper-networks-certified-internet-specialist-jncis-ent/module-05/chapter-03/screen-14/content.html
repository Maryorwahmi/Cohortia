Module 5 › Chapter 5.3 › Key Concepts
Autonomous System Boundary Router

A router that imports external routes into OSPF so internal routers can reach non-OSPF networks.

Type 5 vs Type 7 LSAs

Type 5 floods externals across areas; Type 7 is used inside NSSAs and is translated by ABRs into Type 5.

E1 vs E2

E2 uses the seed metric only; E1 adds the internal cost to the ASBR so OSPF prefers the nearer ASBR by cost.

Takeaway

Control redistribution with routing-policies, choose metric-type according to design goals, and always verify LSA types and routing table entries after configuration.
