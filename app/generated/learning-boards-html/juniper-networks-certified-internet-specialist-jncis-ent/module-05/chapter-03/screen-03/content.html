Hands-on skills

Configure and verify redistribution on Junos

Export policy creation

Write a policy-statement to match static or BGP routes before exporting to OSPF.

Apply with metric

Use metric and metric-type to set seed metric and whether to add internal cost.

NSSA handling

Observe Type 7 generation inside NSSA and ABR translation to Type 5 for Area 0.

Verification

Run show ospf database external and show route protocol ospf to confirm behavior.

Common pitfalls
  • Export policy too broad or too narrow causing missing or unintended routes.
  • Forgetting metric-type leads to default E2 behavior that may not suit multi-ASBR designs.
  • Redistribution loops if routes are re-imported without tagging or filters.
