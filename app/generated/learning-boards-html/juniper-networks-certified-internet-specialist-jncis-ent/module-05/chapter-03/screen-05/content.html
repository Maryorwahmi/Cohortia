Module 5 › Chapter 5.3 › Type 5 & Type 7 LSAs
Concept

Type 5 vs Type 7

Type 5 LSAs advertise external prefixes throughout the OSPF autonomous system. Type 7 LSAs are generated inside an NSSA and are translated by the ABR into Type 5 for backbone distribution.

Type 5
  • Flooded to areas that accept externals (not stub/TSA)
  • Originated by an ASBR exporting routes
Type 7
  • Used inside NSSA for redistributed prefixes
  • Translated by ABR into Type 5 before entering Area 0
Example scenario

If an ASBR in an NSSA redistributes a static route 172.16.10.0/24, it creates a Type 7 LSA inside that NSSA. When that LSA reaches the ABR, the ABR converts it to a Type 5 LSA so Area 0 and other non-NSSA areas can learn the external prefix.

Key Takeaway

NSSAs allow local redistribution via Type 7 while preventing direct Type 5 flooding into the area; ABR translation is required for backbone visibility.
