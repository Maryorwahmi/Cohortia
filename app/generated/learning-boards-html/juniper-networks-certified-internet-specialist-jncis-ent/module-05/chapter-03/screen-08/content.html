Module 5 › Chapter 5.3 › Redistribution Workflow
Six steps
1
Identify external routes
Locate the static or external prefixes you will redistribute and confirm next-hops.
2
Create routing-policy
Match by protocol or prefix and accept only intended routes to avoid accidental exports.
3
Apply export with metric
Use set protocols ospf export and set metric/metric-type to control E1/E2 behavior.
4
Verify LSAs on ASBR
Run show ospf database external or show ospf database nssa to confirm correct LSA type.
5
Confirm internal routing
On an internal router run show route protocol ospf to check metric and external type.
6
Prevent loops
Use route tags and filters when redistributing bi-directionally to avoid re-injection into the source protocol.
Example check

After export, expect a Type 5 for normal AS or Type 7 for NSSA; the internal router should list the route under OSPF with the chosen external type and metric.

Key Takeaway

A disciplined six-step process reduces configuration errors and helps you validate expected behavior quickly.
