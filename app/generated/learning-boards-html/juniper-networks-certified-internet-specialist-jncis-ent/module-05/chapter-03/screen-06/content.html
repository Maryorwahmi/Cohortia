Module 5 › Chapter 5.3 › E2 vs E1
External Type 2 (E2)

Default: seed metric only

With E2, the internal OSPF cost to reach the ASBR is not added. All routers see the advertised external metric as the total cost. Use this when a consistent external cost is desired.

When to use
  • Single ASBR environments or when external metric determines preference.
  • Simpler, predictable external cost across domain.
External Type 1 (E1)

Seed metric plus internal cost

E1 adds the internal cost to the ASBR to the external seed metric, letting OSPF choose the closest ASBR by total cost when multiple ASBRs advertise the same prefix.

When to use
  • Multiple ASBRs announcing the same external prefixes where closest ASBR should be preferred.
  • When internal topology should influence external path selection.
Misconception

Default E2 always gives optimal results — not true when multiple ASBRs exist and internal cost matters.

Pro tip

When changing metric-type, test with show route protocol ospf on an internal router to confirm expected cost behavior.

Check

If two ASBRs advertise the same prefix with E2, tie-breaking may rely on router ID; E1 explicitly favors the nearer ASBR.
