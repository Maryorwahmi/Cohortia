Module 5 › Chapter 5.3 › NSSA ABR Translation
How it works

An ASBR inside an NSSA generates Type 7 LSAs for redistributed routes. The ABR converts those Type 7 LSAs into Type 5 LSAs before flooding them into Area 0 and other areas that accept external LSAs.

What to verify

On the ASBR: show ospf database nssa to confirm Type 7. On the ABR: show ospf database external to confirm translated Type 5.

Design note

Use NSSA when you need local redistribution but also want to avoid incoming Type 5 LSAs in that area.

Concrete scenario

R1 in NSSA redistributes a static route, creates Type 7. The ABR converts it to Type 5 and floods Area 0 so R2 in Area 0 learns the external prefix.

Key Takeaway

NSSA lets you redistribute locally while ABR translation ensures backbone visibility when needed.
