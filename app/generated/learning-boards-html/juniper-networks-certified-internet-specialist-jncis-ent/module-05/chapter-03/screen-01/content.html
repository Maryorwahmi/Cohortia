Concept map
ASBR → Redistribute → Type 5 / Type 7 → E1 / E2
ASBR

Gateway that injects non-OSPF routes into the OSPF domain.

LSA Types

Type 5 floods the AS; Type 7 is used inside NSSA and translated at the ABR.

Metrics

E2 uses the seed metric only; E1 adds internal cost to the ASBR for shortest-path selection.

Why this matters

Redistribution decisions shape reachability and path selection across an OSPF domain. Picking the wrong metric type or failing to filter redistributed routes can cause suboptimal paths or routing loops. This chapter prepares you to configure Junos ASBRs safely and verify the results from internal routers.
