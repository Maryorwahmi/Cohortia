Comparison Common mistakes vs Best practices
Common mistakes
  • Inconsistent area type settings across routers in the same area.
  • Placing ASBRs inside a stub or TSA.
  • Overreliance on virtual links to bypass proper backbone connectivity.
Best practices
  • Keep Area 0 stable and well-connected; use ABRs for summarization and translation.
  • Use stub/TSA at branches that only need a default route to reduce LSDB size.
  • Use NSSA when local redistribution is required while still limiting external LSA exposure.
Takeaway
Design with consistency and operational verification in mind: configure, verify, document.
