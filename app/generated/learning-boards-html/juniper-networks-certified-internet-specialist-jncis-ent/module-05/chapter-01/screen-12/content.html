Process Flow Verification steps
Step sequence
  1. Run show ospf neighbor on all routers and confirm Full state for expected adjacencies.
  2. On stub routers, run show ospf database extensive to confirm Type 4 and 5 are absent.
  3. On NSSA ASBR, confirm Type 7 LSAs exist for redistributed prefixes.
  4. On ABRs, verify Type 7 to Type 5 translation and presence of Type 3 injected default routes into stub/TSA.
  5. Check show route protocol ospf to validate routing table contents and default routes.
Troubleshooting tips
  • If adjacencies fail, confirm all routers in the area use the same area type.
  • If expected LSAs are missing, re-check export/import policies on the ASBR and ABR.
  • Use LSDB and route checks to isolate whether the issue is area-internal or inter-area.
Check
After verification, document LSDB and route table snapshots so you can compare after future changes.
