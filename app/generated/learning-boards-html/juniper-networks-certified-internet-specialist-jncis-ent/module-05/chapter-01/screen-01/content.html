In this lesson
Understand why single-area OSPF is limited, learn Area 0 rules, and compare standard, stub, totally stubby, and NSSA area behaviors.
Scalability
Segmenting OSPF localizes LSAs and SPF work, improving convergence across a large AS.
Area Types
Use area types to restrict LSA types and reduce routing table size at leaf routers.
When to use
Choose stub or TSA for branches needing only a default route, NSSA when local redistribution is required.
Explore Key Topics
Area 0 rules
All non-backbone areas must connect to Area 0 to ensure loop-free inter-area routing.
Stub & TSA
Use these to block external and summary LSAs and keep LSDBs minimal at spokes.
NSSA
Allow local redistribution as Type 7 LSAs that ABRs translate to Type 5 when needed.
