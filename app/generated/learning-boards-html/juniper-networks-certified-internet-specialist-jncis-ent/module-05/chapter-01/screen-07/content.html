Core Concept Stub Area
Behavior
Blocks Type 4 and Type 5 LSAs. Routers inside learn a default route from the ABR and keep only local and default routes.
Configuration note
On Junos, add the 'stub' statement under the OSPF area on the ABR. All routers in the area must use the same area type.
Common error
Placing an ASBR in a stub area or mismatched area type settings prevents adjacency and external route propagation.
Example and takeaway
Use a stub area for a remote branch that only needs local prefixes and internet access via a default route injected by the ABR.
Concrete example
R3 in Area 0.0.0.2 configured as stub will not see Type 5 LSAs and will learn 0.0.0.0/0 from its ABR.
Check
Verify absence of Type 4/5 LSAs in the LSDB and the presence of a default route injected by the ABR.
