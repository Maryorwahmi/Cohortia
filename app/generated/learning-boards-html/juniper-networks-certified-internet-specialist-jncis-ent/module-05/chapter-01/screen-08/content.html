Core Concept Totally Stubby Area
What is blocked
  • Type 3 LSAs (inter-area summaries) are blocked.
  • Type 4 and Type 5 LSAs are also blocked like a stub area.
  • The ABR advertises only a default route (no summaries).
Configuration
On Junos, configure the ABR area with 'stub no-summaries' to create a TSA.
Use case and caution
TSA is ideal for tiny branches where only a default route is acceptable. Beware that blocking Type 3 removes inter-area route granularity and may prevent optimal path selection for remote prefixes.
Example
A branch with constrained CPU and memory can be TSA to conserve resources and rely solely on the ABR's default route for external reachability.
Misconception
Assuming TSA preserves inter-area routing detail is false; it intentionally removes that detail to minimize routing state.
