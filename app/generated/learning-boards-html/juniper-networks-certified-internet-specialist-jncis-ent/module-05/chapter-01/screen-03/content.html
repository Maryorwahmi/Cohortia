Impact of area types
  • Understand which LSA types are blocked or translated and how that reduces LSDB size.
  • Predict routing table contents for routers in stub or TSA areas: local routes plus a default only.
  • Recognize when NSSA Type 7 LSAs allow local redistribution without exposing external LSAs inside the area.

Verification steps
  • Use neighbor and database commands to confirm LSA types and adjacencies.
  • Check that stub areas show no Type 5 LSAs and that NSSAs show Type 7 on the ASBR.
  • Confirm default route injection on stub and TSA areas via Type 3 LSA from ABR.
