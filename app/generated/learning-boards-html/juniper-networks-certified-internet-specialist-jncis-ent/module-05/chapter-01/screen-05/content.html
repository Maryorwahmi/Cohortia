Definition Backbone Area (Area 0)
Role and requirement
Area 0 is the central hub for inter-area routing. All non-backbone areas must connect to it to ensure consistent inter-area paths and avoid loops.
ABR responsibilities
Maintain separate LSDBs per area, advertise inter-area routes as Type 3 LSAs, and translate Type 7 to Type 5 for NSSAs when needed.
Operational advice
Keep the backbone on stable links. Avoid placing highly dynamic endpoints directly in Area 0 that would force inter-area instability.
Analogy and example
Treat Area 0 like a central highway system. Local roads (non-backbone areas) must connect to the highway to reach other local roads, and the highway should be reliable and well-maintained.
Concrete example
An ABR connecting Area 1 and Area 2 to Area 0 advertises summarized inter-area routes as Type 3 LSAs into each area so routers can reach remote prefixes.
Common mistake
Non-backbone areas not connected to Area 0, or inconsistent area type settings across routers, will break adjacencies or inter-area routing.
