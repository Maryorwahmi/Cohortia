What to Remember
Stub Area
Blocks Type 4 and 5 LSAs; receives a Type 3 default route from the ABR. No ASBR allowed inside.
Totally Stubby Area
Blocks Type 3, 4, and 5 LSAs; routers only learn local prefixes and a single default route injected by the ABR.
NSSA
Allows an ASBR to originate Type 7 LSAs. The ABR translates Type 7 to Type 5 for the backbone while blocking external LSAs from entering the NSSA.
Final takeaway

Choose the least-permissive area type that meets reachability needs, verify LSDBs and routing tables, and document ABR/ASBR responsibilities to maintain predictable OSPF behavior.
