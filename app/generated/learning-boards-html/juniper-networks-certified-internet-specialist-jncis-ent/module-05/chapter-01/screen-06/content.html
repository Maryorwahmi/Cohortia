Definition Standard Area
What a standard area carries
  • Type 1, 2: intra-area router and network LSAs.
  • Type 3, 4: inter-area summaries from ABRs.
  • Type 5: external LSAs from ASBRs (and Type 7 translated when NSSA ABR converts them).
When to use
Deploy standard areas at sites that require full routing visibility, like cores or service aggregation points.
Analogy and example
A standard area is like a full-membership network where everyone receives all updates, suitable where nodes need complete information.
Example
A data center area that hosts ASBRs will likely be standard to accept external Type 5 LSAs and advertise them into the AS.
Misconception
Assuming 'default area' equals 'best for all' is incorrect; leaf routers may benefit from restricted LSA types to conserve resources.
