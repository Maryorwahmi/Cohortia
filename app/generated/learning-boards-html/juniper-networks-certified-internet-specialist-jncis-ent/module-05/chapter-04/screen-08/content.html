Comparison

Plain text vs MD5 vs SHA

Plain Text

Password sent unencrypted. Only reduces accidental misconfigurations. Not for production.

MD5

Shared secret with key ID; packets include a digest. Provides integrity and origin authentication. Supports key rotation via key IDs.

SHA

Stronger hash algorithms such as SHA-1 or SHA-256. Preferred for new deployments where supported.

Operational rule

Authentication type, key ID, and secret must match on both neighbors. Interface-level config overrides area-level config.

Key Takeaway

Choose MD5 or SHA for production and plan key rotation using key IDs to avoid breaking adjacencies.
