Module 5 › Chapter 5.4 › Quick Reference
Configuration snippets
set protocols ospf area 0.0.0.0 virtual-link neighbor-id 1.1.1.1 transit-area 0.0.0.1
set protocols ospf area 0.0.0.0 authentication md5 1 key "cohortia123"
Verification
show ospf virtual-link — confirm State: Up; show ospf neighbor — confirm Full; show ospf interface <if> detail — verify auth on interface; show log messages — check for auth failures.
Mistake: Stub transit
Transit area configured as stub/NSSA blocks required LSAs.
Mistake: Auth mismatch
Different type, key ID, or secret prevents adjacency formation.
Mistake: One-sided config
Virtual link must be configured symmetrically on both ABRs.
Final reminder

Prefer MD5 or SHA, coordinate key rotation with key IDs, and reserve virtual links for constrained topologies rather than normal design practice.
