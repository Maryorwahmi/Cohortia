Scenario

Area 2 reaches Area 0 via Area 1

Follow these steps to implement the virtual link between R1 and R2 and secure Area 0 with MD5 authentication.

  1. Set router IDs on R1, R2, R3 to 1.1.1.1, 2.2.2.2, and 3.3.3.3 respectively.
  2. On R2: set protocols ospf area 0.0.0.0 virtual-link neighbor-id 1.1.1.1 transit-area 0.0.0.1.
  3. On R1: mirror the virtual link to neighbor-id 2.2.2.2 with the same transit-area.
  4. Configure MD5 for Area 0 with key ID 1 and key "cohortia123" on R1 and R3, and on relevant interfaces.
  5. Verify with show ospf virtual-link and show ospf neighbor; confirm Full and State Up.
Configuration snippets
# R1
set routing-options router-id 1.1.1.1
set protocols ospf area 0.0.0.0 virtual-link neighbor-id 2.2.2.2 transit-area 0.0.0.1
set protocols ospf area 0.0.0.0 authentication md5 1 key "cohortia123"

# R2
set routing-options router-id 2.2.2.2
set protocols ospf area 0.0.0.0 virtual-link neighbor-id 1.1.1.1 transit-area 0.0.0.1

# R3
set routing-options router-id 3.3.3.3
set protocols ospf area 0.0.0.0 authentication md5 1 key "cohortia123"
Verification steps

Run show ospf virtual-link on R1 and R2, then show ospf neighbor on all routers. Inspect logs for authentication failure messages if adjacencies do not form.
