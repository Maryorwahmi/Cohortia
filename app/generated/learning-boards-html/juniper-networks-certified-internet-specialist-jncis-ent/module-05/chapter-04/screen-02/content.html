Learning Objectives

Gain configuration and verification competence for virtual links and OSPF authentication.

01
Explain virtual link purpose

Describe why a virtual link is used when a non-backbone area needs connectivity to Area 0 and why it is a logical tunnel rather than a physical interface.

Verified Competency Milestone
02
List requirements & restrictions

Identify ABR endpoints, router ID usage, and why the transit area must be a standard area, not stub or NSSA.

Verified Competency Milestone
03
Configure Junos virtual link

Use the set protocols ospf area virtual-link neighbor-id and transit-area commands and verify configuration on both ABRs.

Verified Competency Milestone
04
Implement OSPF authentication

Configure plain, MD5, or SHA authentication, understand key IDs, and know common causes of mismatched adjacencies.

Verified Competency Milestone
