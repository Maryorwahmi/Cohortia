Module 5 › Chapter 5.4 › Key Concepts
Virtual Link
Logical OSPF connection between ABRs to extend Area 0 across a transit area.
Transit Area
Must be a standard area; stub, totally stubby, or NSSA are invalid as transit areas.
OSPF Authentication
Use MD5 or SHA for integrity and origin verification; interface overrides area settings so check both.
Summary Takeaway

Use virtual links only as a carefully managed workaround for topology constraints, and secure OSPF with MD5 or SHA to prevent unauthorized routing updates.
