Module 5 › Chapter 5.4 › Configuring Virtual Links
Code Walkthrough

Junos configuration example

Add matching virtual-link stanzas on both ABRs. Use the other ABR's router ID as neighbor-id and specify the transit-area.

ABR2 configuration (example)
# Configuration on ABR2 (router-id 2.2.2.2)
set protocols ospf area 0.0.0.0 virtual-link neighbor-id 1.1.1.1 transit-area 0.0.0.1
ABR1 configuration (example)
# Configuration on ABR1 (router-id 1.1.1.1)
set protocols ospf area 0.0.0.0 virtual-link neighbor-id 2.2.2.2 transit-area 0.0.0.1
Pro-tip

Document router IDs and keep commits coordinated. If the transit area flaps, the virtual link will reflect that instability.

Verification
Check virtual link state

Run show ospf virtual-link and confirm State: Up. Look for matching neighbor-id and transit-area values.

Neighbor adjacency

Use show ospf neighbor to ensure neighbors reach Full state across the transit area.

Key Takeaway

Virtual links are configured in area 0 stanzas on both ABRs and identified by neighbor router IDs and transit area ID.
