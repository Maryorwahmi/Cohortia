Module 5 › Chapter 5.4 › Junos Authentication Commands
Examples
Plain text (area-level)
set protocols ospf area 0.0.0.0 authentication simple-password "mysecret"
MD5 (area-level with key ID)
set protocols ospf area 0.0.0.0 authentication md5 1 key "cohortia123"
Key ID 1 allows future rotation without breaking adjacencies when coordinated.
SHA (area-level)
set protocols ospf area 0.0.0.0 authentication-type authentication-sha-1
set protocols ospf area 0.0.0.0 authentication-key "$9$EncryptedKey"
Junos often stores SHA keys encrypted; the authentication-key line shows the encrypted form.
Interface-level override

You can apply authentication directly to an interface. This overrides any area-level authentication and is a common source of mismatches.

set protocols ospf area 0.0.0.0 interface ge-0/0/0.0 authentication md5 1 key "cohortia123"
Key Takeaway

Always verify both area and interface authentication settings, and ensure key IDs and secrets match on each neighbor to establish adjacency.
