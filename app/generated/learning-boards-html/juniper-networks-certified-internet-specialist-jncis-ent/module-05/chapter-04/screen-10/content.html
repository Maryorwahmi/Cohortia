Verification Steps
  1. Confirm virtual-link stanza on both ABRs with correct neighbor-id and transit-area.
  2. Run show ospf virtual-link and look for State: Up.
  3. Run show ospf neighbor to ensure neighbors are Full.
  4. Check authentication: type, key ID, and secret match on both sides.
  5. Inspect transit area stability and logs if the link flaps.
Useful commands
show ospf virtual-link | show ospf neighbor | show ospf interface <if> detail | show route protocol ospf | show log messages
Common Problems
Transit area is stub/NSSA

Stub or NSSA transit areas block required LSAs and prevent the virtual link from carrying backbone LSAs.

Mismatched authentication

Different auth type, key ID, or secret will cause adjacency failure. Check interface overrides too.

Incorrect router ID

Using the wrong neighbor-id or failing to set unique router IDs prevents establishing the virtual-link endpoint pairing.

Key Takeaway

Follow a systematic checklist: symmetric config, neighbor/full checks, matching auth, and transit area health to resolve most issues.
