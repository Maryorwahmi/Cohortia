Module 3 › Chapter 2.5 › Port Security CLI
Junos configuration examples
# Configure port ge-0/0/0 to allow a maximum of 2 MAC addresses
set ethernet-switching-options secure-access-port interface ge-0/0/0 mac-limit 2

# Configure a static MAC address for ge-0/0/1 (only this MAC is allowed)
set ethernet-switching-options secure-access-port interface ge-0/0/1 static-mac-address 00:11:22:33:44:55 vlan VLAN_USERS

# Define the action to take if a violation occurs (e.g., shutdown the port)
set ethernet-switching-options secure-access-port interface ge-0/0/0 violation-action shutdown

commit
Verification

After commit, run show ethernet-switching-options secure-access-port to confirm mac-limit and static entries appear. Check interface counters and logs to see violation events.

Example explanation

mac-limit 2 allows two learned clients. The static MAC on ge-0/0/1 ensures only the specified device is permitted on that VLAN on that port. violation-action shutdown disables the port on violation and must be recovered manually.

Recovery tip

If a port is shutdown, use clear ethernet-switching recovery-mode or review your change window before manually re-enabling the interface.
