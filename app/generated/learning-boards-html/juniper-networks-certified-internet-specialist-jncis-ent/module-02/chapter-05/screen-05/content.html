Module 3 › Chapter 2.5 › Port Security
What it does

Port security limits the number of MAC addresses learned on a port and supports static MAC assignments. It reduces the attack surface by preventing unauthorized devices from appearing as valid endpoints.

Allow only N learned MACs per port with mac-limit.
Define static-mac-address to permanently bind one MAC to the port and VLAN.
Choose violation-action: drop, log, or shutdown.
Analogy

Think of a port as a door with a capacity sign. mac-limit sets the capacity, static MACs reserve a pass for a known person, and violation-action is the guard's response when the limit is exceeded.

Concrete scenario

An office desk has an IP phone and a laptop. Configure mac-limit to 2 so the phone and laptop can work but a hidden wireless router connected at that jack cannot add additional clients.

Key takeaway

Port security reduces unauthorized attachments but requires planning to avoid blocking valid multi-device scenarios.
