How DHCP snooping works

Snooping inspects DHCP packets, marks ports as trusted or untrusted, blocks server messages on untrusted ports, and builds the binding database with client MAC, IP, VLAN, lease time, and port.

Trusted ports: allow all DHCP messages (uplinks, DHCP servers).
Untrusted ports: allow client requests but block DHCP server offers.
Concrete example

A personal travel router plugged into an access port cannot act as a DHCP server because DHCPOFFER messages from that untrusted port are dropped, preventing clients from receiving malicious network settings.

Key takeaway

DHCP snooping is both a filter and a source of trusted bindings for downstream checks like ARP inspection.
