Module 3 › Chapter 2.5 › Violation Actions
Shutdown

Immediately disables the port. Strong enforcement but causes outages if applied incorrectly.

Use when you need decisive blocking and have a recovery plan.
Drop

Silently discards frames from unauthorized MACs while leaving the port up. Less disruptive, suitable for testing phases.

Good balance between security and availability.
Log

Records violation events for auditing without blocking traffic. Best for initial visibility before enforcement.

Use to gather data before tightening controls.
Decision guideline

Map the action to business impact. For high-availability ports, prefer drop or log while you validate settings. For high-risk areas, consider shutdown with documented recovery steps.
