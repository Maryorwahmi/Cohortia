Module 3 › Chapter 2.5 › Layer 2 Threats
Definition & impact

MAC spoofing, rogue DHCP, and ARP poisoning exploit basic Layer 2 behaviors. Each attack can lead to traffic interception, denial of service, or incorrect network configuration for clients.

MAC spoofing: forge a MAC to impersonate a host or duplicate an address.
Rogue DHCP: an unauthorized device answers DHCP requests and hands out bad settings.
ARP poisoning: falsified ARP replies map IPs to attacker MACs.
Misconception check

Segmentation via VLANs reduces exposure but does not validate the identity of devices or the correctness of DHCP and ARP messages. You need protocol-aware controls.

Concrete example

Imagine an employee plugs a travel router into an access port. If that device runs DHCP, it may hand out addresses with an attacker-chosen gateway. Without DHCP snooping, clients accept the offer. With snooping on untrusted ports, the switch blocks server offers and prevents clients from receiving malicious settings.

Key takeaway

Layer 2 defenses are targeted: limit who can join, block unauthorized DHCP servers, and validate ARP using learned bindings.
