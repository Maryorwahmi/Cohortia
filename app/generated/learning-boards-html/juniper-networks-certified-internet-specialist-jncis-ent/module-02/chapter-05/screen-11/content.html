Module 3 › Chapter 2.5 › Binding Database
What the binding contains
  • MAC address: client hardware address.
  • IP address: assigned lease address.
  • VLAN: the VLAN where the lease was observed.
  • Interface: switch port associated with the client.
  • Lease time: remaining time for the binding.
Why it matters

Without an accurate binding database, features that validate traffic against allocations—like ARP inspection—have no trusted reference, causing false positives or allowing attacks to succeed.

Practical checks

Inspect show dhcp-snooping binding frequently after enabling snooping. Watch lease times and confirm the interface column corresponds to your access ports so ARP inspection can reference the correct entry.

Deployment note

In complex topologies ensure DHCP transactions are visible to the switch or use DHCP relay/agent features so bindings are recorded consistently.
