Common mistakes
  • Untrusted uplink: blocks DHCP offers.
  • Low mac-limit: blocks legitimate multi-host ports.
  • DAI without bindings: drops valid ARP.

Recovery pattern

Deploy in monitor or log mode first. Verify bindings and logs. If a port shuts down, clear recovery mode only after confirming the root cause and adjusting limits or static entries as needed.
