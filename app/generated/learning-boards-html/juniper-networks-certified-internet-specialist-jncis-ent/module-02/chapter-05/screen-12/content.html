Module 3 › Chapter 2.5 › Dynamic ARP Inspection
How DAI protects ARP

DAI intercepts ARP messages on untrusted ports and compares the IP/MAC pair to the DHCP snooping binding database. If there is no match, the ARP packet is dropped, preventing attackers from poisoning ARP caches.

Requirement

DAI depends on a populated DHCP snooping database. Enable and verify snooping before enforcing ARP inspection to avoid blocking valid traffic.

Example behavior

If an attacker sends an ARP reply claiming the gateway IP with the attacker's MAC and that pairing is not in the binding database, the switch drops the ARP on the untrusted port and logs the event.

Deployment tip

Enable DAI in monitoring mode first if supported, confirm that legitimate ARP is allowed, then switch to enforcement mode to drop invalid ARP packets.
