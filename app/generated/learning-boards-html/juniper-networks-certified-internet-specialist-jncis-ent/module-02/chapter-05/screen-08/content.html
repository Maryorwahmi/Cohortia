Module 3 › Chapter 2.5 › Static MAC
When to use static MACs
  • Critical printers, cameras, or infrastructure appliances that must always be present.
  • Ports where dynamic learning is undesirable or causes reachability issues.
  • Environments where device replacement is controlled and updates to static entries are manageable.
Practical note

If a NIC is replaced, update the static entry. Keep a central inventory of static MACs to avoid confusion. Static MACs do not prevent dynamic learning of other addresses unless combined with mac-limit settings.

Example

A security camera is assigned static-mac-address 00:11:22:33:44:55 on VLAN CCTV so it cannot be impersonated or displaced by another device.
