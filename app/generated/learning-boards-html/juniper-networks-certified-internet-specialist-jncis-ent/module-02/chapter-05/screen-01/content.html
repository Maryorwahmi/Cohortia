Protecting the access layer

Learn practical Junos commands to limit MACs on ports, prevent rogue DHCP servers, and validate ARP with DAI. Includes verification steps and common pitfalls to avoid outages.

In this lesson

Port security, DHCP snooping, DAI — why they matter and how to configure them safely.

Coming up

Live CLI examples and verification outputs you can run in a lab.

Safety note

Test changes in a lab. Misconfiguration may block legitimate traffic.

Key Idea

Combine port limits, DHCP snooping, and ARP inspection to stop MAC spoofing, rogue DHCP offers, and ARP poisoning while preserving legitimate access.

Explore Key Topics
Port limits: Prevent multiple devices or rogue routers on a single access port by limiting learned MACs.
DHCP snooping: Block DHCPOFFERs from untrusted ports and build a trusted IP-to-MAC mapping table.
ARP inspection: Use the DHCP binding table to validate ARP packets and stop ARP spoofing.
