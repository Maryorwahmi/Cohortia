Module 2 › Chapter 2.2 › Quick Reference
Plan trunks

Limit allowed VLANs and change native VLANs from the default when possible.

Assign RVIs

Give each VLAN an irb with an IP inside the subnet and bind it with l3-interface.

Verify & Test

Use show interfaces irb, show vlans, show route, and host pings as your verification routine.

Final takeaway

A predictable, documented RVI and trunk configuration with routine verification reduces outages and improves network security.
