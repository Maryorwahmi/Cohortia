Module 2 › Chapter 2.2 › Learning Objectives
01
Configure 802.1Q trunks
Set VLAN membership and native VLANs on Junos.

You will set which VLANs a trunk carries and choose a secure native VLAN. This prevents tag mishandling and supports predictable routing.

Verified Competency Milestone
02
Implement RVIs
Create irb interfaces and assign IPs.

You will configure irb units, pick appropriate IPs within each VLAN subnet, and link the irb to the VLAN so devices can use it as their gateway.

Verified Competency Milestone
03
Verify routing
Use show commands to confirm routes and interfaces.

You will run show interfaces irb, show vlans, and show route to confirm direct routes and RVI associations are present.

Verified Competency Milestone
04
Troubleshoot & secure
Identify common pitfalls and apply hardening.

You will diagnose mismatched addresses, gateway errors, misassociated RVIs, and consider simple security steps like avoiding native VLAN 1 or tagging all VLANs.

Verified Competency Milestone
