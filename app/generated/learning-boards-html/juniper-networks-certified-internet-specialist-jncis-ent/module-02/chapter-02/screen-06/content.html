How native VLAN works

Native VLAN frames cross the trunk untagged. By default Junos uses VLAN 1. To avoid improper frame placement, change the native VLAN to an unused ID or tag all VLANs.

Example configuration

set interfaces ge-0/0/2 unit 0 family ethernet-switching native-vlan-id 999

Why change it?
  • Avoid VLAN hopping and accidental untagged traffic on production VLANs.
  • Ensure both trunk ends match to prevent traffic misplacement.
  • Document and standardize native VLAN choices across the design.
