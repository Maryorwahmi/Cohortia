Module 2 › Chapter 2.2 › Set Native VLAN
Example command
set interfaces ge-0/0/2 unit 0 family ethernet-switching native-vlan-id 999
Verification

Use show interfaces ge-0/0/2 extensive or show vlans to confirm the native-vlan-id is applied and to see how frames are handled.

Checklist
  • Choose an unused VLAN ID for native.
  • Apply the same native VLAN on both trunk endpoints.
  • Document the change and verify production traffic.
