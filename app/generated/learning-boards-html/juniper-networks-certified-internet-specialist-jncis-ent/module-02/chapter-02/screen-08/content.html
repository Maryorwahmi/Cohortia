Module 2 › Chapter 2.2 › RVI / IRB
What it is

An irb unit is a logical Layer 3 interface. Assign an IP in the VLAN subnet and bind it under the VLAN config with l3-interface for gateway services.

Role in routing

Traffic between VLANs goes to the source VLAN's RVI, the switch looks up the destination subnet and forwards via the destination RVI if directly connected.

Example analogy

Think of each VLAN as an apartment building and the RVI as the building's doorman who can pass messages between buildings after checking addresses.

Misconception check

An irb is not a physical interface; it does not replace necessary routing to external networks without additional route configuration.
