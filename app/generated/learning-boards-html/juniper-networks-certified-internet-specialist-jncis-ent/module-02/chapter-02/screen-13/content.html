Module 2 › Chapter 2.2 › Common Mistakes
Incorrect IPing

RVI IP must be inside the VLAN subnet and unique. If not, hosts cannot use it as a gateway.

Missing l3-interface

The VLAN must reference the irb unit with l3-interface or hosts will not see that RVI as gateway.

Firewall filters

Filters on irb can block inter-VLAN packets; audit them when traffic is unexpectedly dropped.

Troubleshooting checklist
  1. Verify VLANs and port assignments.
  2. Confirm irb addresses and l3-interface associations.
  3. Check routing table for direct routes to VLAN subnets.
  4. Inspect firewall filters and host gateway settings.
