Module 2 › Chapter 2.2 › Key Concepts
Inter-VLAN Routing

Routing IP packets between VLANs occurs via a Layer 3 device such as a switch with RVIs or a router.

Layer 3 Switch

A switch with routing capability forwards between VLANs using logical interfaces without needing an external router for local traffic.

RVI / IRB

A logical Layer 3 interface assigned to a VLAN; it provides the default gateway IP for hosts in that VLAN.

Summary takeaway

Control trunk membership, set safe native VLANs, create and bind RVIs, then verify with show commands and host tests to ensure inter-VLAN connectivity and security.
