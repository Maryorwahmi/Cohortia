Module 2 › Chapter 2.2 › RVI Configuration Steps
Step-by-step
  1. Ensure VLAN is defined under vlans <name>.
  2. Create the irb unit and assign an IP: set interfaces irb unit 10 family inet address 192.168.10.1/24.
  3. Associate with the VLAN: set vlans VLAN_SALES l3-interface irb.10.
  4. Commit and verify with show interfaces irb, show vlans, and show route.
Quick example
# Create RVI for VLAN_SALES
set interfaces irb unit 10 family inet address 192.168.10.1/24
set vlans VLAN_SALES l3-interface irb.10
commit
