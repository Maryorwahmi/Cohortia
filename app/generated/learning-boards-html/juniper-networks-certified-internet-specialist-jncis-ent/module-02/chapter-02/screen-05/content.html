Module 2 › Chapter 2.2 › Allowed VLANs vs All
Explicit list

Only named VLANs traverse the trunk. This reduces broadcast traffic and limits exposure to only the VLANs you expect.

When to use
  • Access uplinks for servers or VLAN-limited links.
  • When regulation or policy restricts data movement.
Permitting all VLANs

Simpler configuration for links carrying many dynamic VLANs, but increases chance of unintended VLAN travel and exposure.

When to use
  • Core distribution links that must carry many VLANs.
  • Temporary staging when VLAN membership is changing rapidly.
Practical example

If only VLANs 10 and 20 need the uplink, configure the trunk to allow those VLANs explicitly. If the uplink attaches to a virtualization host requiring many VLANs, you may permit all but only after risk assessment.
