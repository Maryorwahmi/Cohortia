Module 2 › Chapter 2.2 › Inter-VLAN Packet Flow
Packet journey
  1. Host sends packet to its default gateway (RVI IP).
  2. Switch receives on the source VLAN, maps to the irb interface.
  3. Routing lookup finds destination subnet; route points to destination irb.
  4. Switch forwards packet out the destination VLAN to the target host.
Example

Host A (192.168.10.10) uses gateway 192.168.10.1. Host B (192.168.20.20) uses gateway 192.168.20.1. A's traffic arrives at irb.10, is routed, and leaves via irb.20 to reach B.

Misconception check

Creating VLANs alone does not permit inter-VLAN traffic. You must create RVIs and ensure routing is present.
