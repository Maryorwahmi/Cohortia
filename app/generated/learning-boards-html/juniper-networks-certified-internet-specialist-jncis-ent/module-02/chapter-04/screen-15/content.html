BPDU Guard
Disables edge ports that receive BPDUs to prevent rogue switches from affecting STP.
Loop Protection
Keeps a port blocking if it stops receiving BPDUs so it won't create a loop by forwarding.
Root Protection
Prevents designated ports from accepting a superior BPDU that could change the Root.
Final takeaway
Pair configuration with verification and recovery planning. Security features protect topology, and show commands confirm that protections and elections behave as intended.
