Module 02 › Chapter 2.4 › Lab Walkthrough
Starter commands (annotated)
# Enter config mode
edit

# 1. Ensure RSTP is enabled (often default)
set protocols rstp

# 2. Make SW1 the Root Bridge
set protocols rstp bridge-priority 4k

# 3. Configure access port ge-0/0/0 for VLAN 10 (VLAN_USERS)
set interfaces ge-0/0/0 unit 0 family ethernet-switching interface-mode access
set interfaces ge-0/0/0 unit 0 family ethernet-switching vlan members VLAN_USERS

# 4. Enable BPDU Guard on the access port
set protocols rstp interface ge-0/0/0 bpdu-block-on-edge

# Apply changes
commit

# Verify
show spanning-tree bridge
show spanning-tree interface ge-0/0/0
After verifying SW1 is Root, test BPDU Guard by injecting a BPDU on the access port; observe the port state and practice recovery steps if it becomes disabled.
Checklist
  • Commit each change and confirm with show commands.
  • Verify Root election on at least two switches.
  • Test BPDU Guard and document recovery steps.
