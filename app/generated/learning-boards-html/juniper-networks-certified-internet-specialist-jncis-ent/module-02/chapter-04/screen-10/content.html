# Protect a designated port from accepting a superior BPDU
set protocols rstp interface ge-0/0/1 root-protection
commit
If the port receives a superior BPDU, it will go into root-inconsistent blocking to prevent the new Root from being accepted via that port.
Operational guidance
Use root protection on ports where you never want the switch to accept a more preferred Root, and pair it with an explicit Root-priority plan for the domain.
Check show spanning-tree bridge after changes to ensure the elected Root remains the device you intended.
