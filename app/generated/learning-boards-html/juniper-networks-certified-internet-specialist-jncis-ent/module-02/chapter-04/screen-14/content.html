Module 02 › Chapter 2.4 › Key Concepts
RSTP Configuration
Enable RSTP to gain faster convergence; always verify after enabling.
Bridge Priority
Set priorities in 4096 steps; lower numeric value wins the Root election.
Port Cost
Lower cost paths are preferred; adjust costs to steer active traffic onto desired links.
Summary takeaway
Use RSTP with deliberate bridge priority and port cost plans. Protect edges and trunks with BPDU Guard, Loop Protection, and Root Protection, and always verify changes with show commands.
