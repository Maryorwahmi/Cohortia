Module 02 › Chapter 2.4 › Port Cost — CLI Walkthrough
Commands
edit
set protocols rstp interface ge-0/0/0 cost 100
commit

# Verify the port role and state
show spanning-tree interface ge-0/0/0

# Review BPDU activity
show spanning-tree statistics
The edit and commit steps apply configuration immediately. Use show commands to confirm how RSTP recalculated roles.
Interpreting interface output
  • Role: indicates Root, Designated, Alternate, or Boundary.
  • State: Forwarding or Blocking tells you whether the port carries traffic.
  • Cost: shows the configured or default cost used in calculations.
Pro tip: If results differ from expectation, inspect neighbor priorities and costs. A remote lower priority can still make a different Root.
