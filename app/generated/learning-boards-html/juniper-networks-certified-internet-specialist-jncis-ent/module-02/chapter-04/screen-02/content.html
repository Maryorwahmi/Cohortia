01
Enable RSTP
Configure RSTP on Junos and confirm it is active. Verifying reduces surprises when making topology changes.
VERIFIED COMPETENCY MILESTONE
02
Influence Root Election
Use bridge priority to force a predictable Root Bridge. This matters to control traffic aggregation and latency.
VERIFIED COMPETENCY MILESTONE
03
Tune Port Cost
Adjust port cost to prefer specific physical links. Cost tuning helps avoid unexpected path selection after topology events.
VERIFIED COMPETENCY MILESTONE
04
Monitor & Protect
Use show commands and enable BPDU Guard, Loop and Root Protection to keep the Layer 2 domain stable and secure.
VERIFIED COMPETENCY MILESTONE
Guided activities
Practice enabling RSTP and run show spanning-tree bridge to confirm Root information.
Set bridge-priority to a lower value and verify the election using the show commands on two switches.
Enable BPDU Guard on an access port, then simulate a rogue BPDU and observe the port state change.
Adjust port cost on a link and predict which port becomes the Root Port; verify with show spanning-tree interface.
