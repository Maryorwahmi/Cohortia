Show command cheat sheet
show spanning-tree bridge — global RSTP info, root and local bridge IDs, timers.
show spanning-tree interface ge-0/0/0 — port role, state, and cost for a specific interface.
show spanning-tree statistics — BPDU sent/received counters useful for detecting missing control traffic.
Interpretation tips
  • Verify Root identity across multiple switches to confirm consistent election.
  • Compare interface roles on both ends of a link; mismatches indicate configuration or link issues.
  • Low BPDU reception may trigger loop protection or indicate a one-way link failure.
Key Takeaway
Always verify topology changes with show commands on both sides of key links and review BPDU statistics for hidden problems.
