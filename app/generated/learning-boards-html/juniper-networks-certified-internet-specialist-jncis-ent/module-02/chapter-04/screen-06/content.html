Module 02 › Chapter 2.4 › Port Cost
Default cost examples
Typical default Juniper costs: 20,000 for 100 Mbps, 2,000 for 1 Gbps, 200 for 10 Gbps. Use manual costs to override defaults where necessary.
Manual cost command
# Set explicit cost for an interface
set protocols rstp interface ge-0/0/0 cost 100
commit
Example: To prefer a 10 Gbps link, ensure it has a lower cost than any competing path. If a competing 1 Gbps uplink has cost 2000, setting the 10 Gbps port to 200 will prefer it.
Misconception check: Do not assume physical speed always wins; configured costs or defaults may change preference.
Comparison — two uplinks
Uplink A
Speed: 10 Gbps
Cost: 200
Uplink B
Speed: 1 Gbps
Cost: 2000
With these costs, the switch will prefer Uplink A to reach the Root. If you manually increase A's cost above B, the preferred path will flip. After changes, run show spanning-tree interface on both ports to confirm role and state.
