Module 02 › Chapter 2.4 › Objectives — Practice
Four action-focused objectives
1. Lab sequence
Execute a two-switch demo to set a Root Bridge and verify topology changes with show commands.
2. Edge protection
Enable BPDU Guard on access ports and observe the port state after receiving a BPDU from a test device.
3. Trunk safety
Use Loop Protection on trunk links so loss of BPDUs does not create accidental forwarding loops.
4. Recovery checks
Practice recovery steps such as clearing recovery mode so you can bring ports back after a BPDU Guard event.
Verification snippets
show spanning-tree bridge — check Root Bridge ID, local bridge ID, timers.
show spanning-tree interface ge-0/0/0 — inspect role, state, and cost for a port.
show spanning-tree statistics — BPDU counts sent and received for troubleshooting.
