Module 02 › Chapter 2.4 › Loop Protection
Command example
# Enable loop protection on a trunk
set protocols rstp interface ge-0/0/2 loop-protection
commit
If a port with loop protection stops receiving BPDUs, it transitions to loop-inconsistent and stays blocking to avoid forming a loop.
Practical notes
Use loop protection on trunks and inter-switch links where BPDU loss could cause an alternate port to start forwarding. Document such settings and monitor interfaces so you can respond if a trunk is intentionally blocked.
Pro tip: If a trunk becomes loop-inconsistent, investigate the reason for missing BPDUs — it may indicate a unidirectional fault or severe congestion affecting control plane traffic.
