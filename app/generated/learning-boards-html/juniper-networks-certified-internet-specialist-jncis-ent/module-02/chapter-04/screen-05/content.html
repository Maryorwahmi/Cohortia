Bridge Priority rules
Priorities are configured in multiples of 4096; lower numerical priority has higher election preference.
Command example
# To make this switch the Root Bridge
set protocols rstp bridge-priority 4k
commit
Default priority is 32768. Setting a lower value like 4096 ensures this switch wins unless another switch has an even lower priority.
Misconception check: The MAC address only breaks ties; do not rely on MAC ordering for predictable topology.
Concrete scenario
Imagine a core pair where you want a specific unit to be the Root to centralize forwarding. Set its priority to 4k, commit, and run show spanning-tree bridge on both switches. Confirm the chosen Root ID and that your planned uplinks are Root Ports on non-root switches.
Common mistake

Changing priority on one switch without checking other switches can cause unintended Root changes during failovers. Always verify across the domain.
