Module 02 › Chapter 2.4 › BPDU Guard
Configuration examples
# Enable on a specific access interface
set protocols rstp interface ge-0/0/3 bpdu-block-on-edge
commit

# Or enable globally for edge ports
set protocols rstp bpdu-block-on-edge
commit
When a protected port receives a BPDU, it is taken out of forwarding to prevent topology changes introduced by a connected device.
Scenario
You have an access port for an employee workstation. Enabling BPDU Guard ensures that if someone plugs in an unmanaged switch, that port will not allow the new device to affect the spanning tree.
Recovery note
After an edge port is disabled due to BPDU reception, you will need to follow recovery steps or clear the recovery-mode state to return the port to service.
