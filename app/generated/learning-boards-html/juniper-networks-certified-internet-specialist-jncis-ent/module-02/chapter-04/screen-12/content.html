Module 02 › Chapter 2.4 › Troubleshooting
Common mistakes
  • Inconsistent bridge priorities leading to unexpected Root election.
  • Misconfigured port costs producing suboptimal paths.
  • Forgetting to enable BPDU Guard on edge ports and Loop Protection on trunks.
Safe troubleshooting steps
1. show spanning-tree bridge — confirm current Root Bridge ID.
2. show spanning-tree interface <port> — inspect role, state, and cost.
3. show spanning-tree statistics — check BPDU counts for anomalies.
Safety reminder: always test changes in a lab and document the original state so you can revert if an unintended topology change occurs.
