Configuration & Verification Trunk Port
Trunk commands
Allow multiple VLANs on the uplink and verify both endpoints match.
# Configure trunk uplink
set interfaces ge-0/0/2 unit 0 family ethernet-switching interface-mode trunk
set interfaces ge-0/0/2 unit 0 family ethernet-switching vlan members [ VLAN_IT VLAN_GUEST ]

# Or allow all VLANs
# set interfaces ge-0/0/2 unit 0 family ethernet-switching vlan members all

commit
Verification checklist
  • Run show vlans to confirm member lists on both switches.
  • Run show interfaces ge-0/0/2 extensive to confirm interface-mode is trunk.
  • Check MAC tables to see VLAN MACs learned across the uplink.
Common mistake

Inconsistent VLAN membership on trunk endpoints causes certain VLAN traffic to be dropped; verify both sides match.
