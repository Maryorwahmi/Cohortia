Native VLAN behavior
Frames for the native VLAN may be sent untagged across an 802.1Q trunk. That makes consistent configuration critical.
Consequences of mismatch
  • Untagged frames assigned to the wrong VLAN on the receiving switch.
  • Connectivity problems or unintended communication between hosts.
  • Potential security exposure via VLAN hopping if untagged traffic is mishandled.
Mitigation
Either tag all VLANs across the trunk, or explicitly align native VLAN IDs and use an unused VLAN for native traffic.
Example mismatch scenario
Switch A native VLAN = 1, Switch B native VLAN = 99. Untagged frames from A appear in VLAN 99 on B, causing hosts to be placed incorrectly.
Common mistake

Relying on default native VLAN IDs without verifying both sides of a trunk is a frequent source of misconfiguration.
