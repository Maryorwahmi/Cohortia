Configuration Junos VLAN Commands
Define VLAN objects
VLANs are created as named objects with numeric IDs and referenced on interfaces.
Commands (example)
# Configure VLANs
set vlans VLAN_SALES vlan-id 10
set vlans VLAN_HR vlan-id 20
set vlans VLAN_SERVERS vlan-id 30

# Commit
commit
Verification
Use show vlans to list VLANs and show interfaces ge-0/0/X extensive to confirm interface mode and membership.
Practical note
Define all VLANs before assigning them to interfaces to avoid missing members on trunks. Be explicit about the VLAN list on uplinks to ensure consistency.
Key Takeaway

Junos uses named VLAN objects. Build them, assign interfaces, commit, then verify with show commands.
