Comparison Access Port vs Trunk Port
Choose the right port type
Match interface mode to the device's VLAN awareness and the intended traffic separation.
Access port
  • Single VLAN membership, untagged to the end host.
  • Used for workstations, single-VLAN servers, and printers.
  • Configured with interface-mode access and vlan members.
Trunk port
  • Carries multiple VLANs between switches or to routers.
  • Uses 802.1Q tagging for non-native VLANs.
  • Configured with interface-mode trunk and a list of vlan members.
Concrete examples
Access: ge-0/0/0 connected to a desktop in VLAN 10. Trunk: ge-0/0/2 uplink carrying VLANs 10, 20, 30 to other switches.
Common mistake
Using trunk mode for endpoints that do not understand tags will prevent connectivity because the host will receive tagged frames.
Key Takeaway

Match port mode to device capability: untagged access for hosts, tagged trunks for multi-VLAN links.
