Configuration Access Port Example
Access port commands
Define VLAN objects, set the interface to access, and add the VLAN member.
# Define VLANs
set vlans VLAN_IT vlan-id 100
set vlans VLAN_GUEST vlan-id 200

# Configure access ports
set interfaces ge-0/0/0 unit 0 family ethernet-switching interface-mode access
set interfaces ge-0/0/0 unit 0 family ethernet-switching vlan members VLAN_IT

set interfaces ge-0/0/1 unit 0 family ethernet-switching interface-mode access
set interfaces ge-0/0/1 unit 0 family ethernet-switching vlan members VLAN_GUEST

# commit
commit
Verification steps
  1. Run show vlans to confirm VLANs and members.
  2. Run show interfaces ge-0/0/0 extensive to check interface-mode and VLAN assignment.
  3. Check the MAC table to ensure the host MAC appears under the correct VLAN and port.
Key Takeaway

Follow define→assign→commit→verify and confirm both VLAN and interface states to avoid access-port misassignments.
