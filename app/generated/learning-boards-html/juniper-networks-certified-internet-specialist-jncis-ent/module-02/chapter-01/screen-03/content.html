Module 2 › Chapter 2.1 › Learning Objectives
01
Source builds the map
Mnemonic: remember that source MACs populate the table. Practice: generate traffic and observe the MAC address table populate with show ethernet-switching table.
02
Group by role, not by cable
VLANs group devices logically. Example: place all servers in a server VLAN so management and security policies apply consistently.
03
Access = untagged | Trunk = tagged
When troubleshooting, confirm the device expects untagged frames on an access port; mislabeling causes reachability issues.
04
Checklist & common pitfall
Define VLANs, set interface mode, assign members, commit, verify. Pitfall: mismatched native VLANs can misclassify untagged traffic.
