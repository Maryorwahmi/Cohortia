Architecture 802.1Q Tagging
How tagging preserves VLAN identity
802.1Q inserts a small tag with the VLAN ID into the Ethernet header so frames can traverse shared links without losing VLAN context.
Key facts
  • The tag is 4 bytes and includes the VLAN ID.
  • Trunks carry tagged frames for most VLANs and may send native VLAN frames untagged.
  • Access ports present untagged frames to end devices and map them to a single VLAN internally.
Mistake to avoid
Mismatched native VLAN IDs on trunk endpoints cause untagged frames to be misclassified and can create connectivity or security problems.
Example packet annotation
An Ethernet frame with an 802.1Q tag shows source, destination, and VLAN ID fields. This ID follows through the network to keep frames in the correct domain.
[ Eth Dest ][ Eth Src ][ 802.1Q Tag: VLAN 10 ][ Eth Type ][ Payload ]
Why it matters

Tags keep multiple VLANs separate on a single physical link, enabling flexible and efficient use of infrastructure.
