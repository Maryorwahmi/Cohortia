Definition VLAN (Virtual LAN)
VLANs let you group devices logically
They create distinct broadcast domains without requiring separate physical switches for each group.
Common uses
  • Isolate servers from user workstations.
  • Separate guest Wi-Fi from internal networks.
  • Group voice devices into a dedicated VLAN for QoS and policy.
Misconception
VLANs do not route traffic between each other; routing requires a Layer 3 device or interface.
Example VLAN layout
VLAN 10: Users, VLAN 20: Voice, VLAN 30: Servers. Each VLAN confines broadcasts and can receive tailored policies.
Key Takeaway

Design VLANs around roles and traffic patterns to minimize broadcast reach and simplify policy application.
