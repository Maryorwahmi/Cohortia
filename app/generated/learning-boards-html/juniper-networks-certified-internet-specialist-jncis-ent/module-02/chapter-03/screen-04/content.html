Module 2 › Chapter 2.3 › Layer 2 Loops
Definition

Layer 2 Loop

A physical redundancy that creates multiple active paths so Ethernet frames can circulate without a stop condition.

Broadcast Storm
Repeated duplication of broadcast frames that consumes bandwidth and renders the network unusable.
MAC Table Instability
Entries flap between ports as the same MAC appears on multiple interfaces, causing incorrect forwarding.
Multiple Frame Copies
End devices receive duplicate frames, confusing applications and degrading performance.
Key Takeaway

Redundancy without loop control creates severe, fast-moving failures at Layer 2; STP is the protocol that prevents that outcome.

Concrete Example
Imagine three switches connected in a triangle. One broadcast enters the triangle and is forwarded by each switch. Without a blocking decision, the frame loops continuously and doubles each transit. Within seconds the triangle’s links carry only duplicates, starving legitimate traffic.
Quick misconception check

Misconception: "More links always improves resilience." Reality: Without a protocol to break loops, more links amplify broadcast storms and instability.

Why STP matters for operations: prevents outages from topology changes.
When to prioritize STP: any network with redundant Layer 2 links.
