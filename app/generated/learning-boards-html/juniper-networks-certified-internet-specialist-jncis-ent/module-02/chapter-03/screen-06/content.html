Module 2 › Chapter 2.3 › BPDU & Root Election
BPDU fields (conceptual)
Bridge ID: [priority : MAC address]
Root ID:   best-known root Bridge ID
Path Cost: cumulative cost to reach the Root Bridge
Flags:     topology change indicators

Switches send BPDUs frequently so every device has a consistent view. The lowest Bridge ID (priority plus MAC) becomes the Root Bridge. Administrators may change priority to control the election.

Root Port
Port with lowest cost path to Root on a non-root switch.
Designated Port
One per segment; chosen by lowest cost to the Root Bridge.
Practical note
If two switches have equal path cost for a segment, the switch with the lower Bridge ID wins the Designated Port election for that segment. Control of priority gives predictable root placement.
Example reasoning
If three switches have default priorities, the switch with the lowest MAC becomes root. Neighbors choose their Root Port toward that root, and the remaining link between neighbors will have one blocked port to break the loop.
