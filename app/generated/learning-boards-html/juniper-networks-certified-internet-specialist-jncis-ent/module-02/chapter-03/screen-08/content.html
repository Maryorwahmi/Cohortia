Module 2 › Chapter 2.3 › Port States
State timeline
Blocking
Does not forward user traffic; listens for BPDUs.
Listening
Processes BPDUs to determine the topology; still does not forward.
Learning
Learns MAC addresses to populate the table; does not forward yet.
Forwarding
Forwards user traffic and continues learning.
Timers:
Forward Delay controls Listening and Learning durations (commonly 15s each). Max Age defines how long root info is considered valid (commonly 20s). These timers make classic STP slow to converge but prevent transient loops during reconfiguration.
Diagnosis cards
If a port stays in Blocking, check BPDU reachability and whether the port is intentionally non-designated.
If convergence is slow, consider RSTP for faster transitions.
Remember: Disabled means administratively down and not in STP.
