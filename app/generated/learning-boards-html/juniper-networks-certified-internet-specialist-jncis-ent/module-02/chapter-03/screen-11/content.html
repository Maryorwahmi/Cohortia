Conceptual BPDU
Root ID: [priority : MAC]
Bridge ID: [priority : MAC]
Path Cost: 
Flags: topology change indicators
Switches compare Root ID first, then path cost and Bridge ID to resolve ties. This comparison is how the network converges to a single root and consistent roles.
Practical tip
When you cannot access command output, reason from MAC addresses and default priorities: the lowest MAC often becomes the root when priorities are equal.
