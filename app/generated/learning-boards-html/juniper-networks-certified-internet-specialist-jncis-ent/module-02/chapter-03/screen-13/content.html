What BLK means

BLK indicates a Non-Designated port intentionally not forwarding to prevent loops. It still participates in BPDU exchange so it can change state if the active path fails.

Verify BPDU reachability across the link.
Confirm Bridge IDs and priorities to explain election results.
Check path costs; cost adjustments can affect which port wins Designated status.
Never force a blocked port to forward without understanding the whole topology.
Quick checklist
  1. Confirm BPDU exchange present.
  2. Identify Root Bridge and Root Ports.
  3. Validate which link is intentionally blocked.
  4. Plan changes via priority or cost if needed, test in maintenance windows.
Final thought

A blocked port indicates STP worked. Treat it as planned redundancy, and diagnose changes methodically.
