Module 2 › Chapter 2.3 › Triangle Scenario
Scenario
SW1: priority 32768, MAC aa:aa:aa:aa:aa:01 SW2: priority 32768, MAC bb:bb:bb:bb:bb:02 SW3: priority 32768, MAC cc:cc:cc:cc:cc:03 All links default cost.
Step 1: Root Bridge
Lowest Bridge ID (default priority + MAC) wins. SW1's MAC is lowest, so SW1 is Root.
Step 2: Root Ports
SW2 and SW3 select ports connected to SW1 as their Root Ports because those are the lowest-cost paths to the Root.
Step 3: Blocked port
On SW2–SW3 segment one port will be blocked. The switch with higher Bridge ID typically blocks; here SW3 likely blocks.
Reflection
If you lowered SW2's priority, SW2 could become Root and the roles would shift: SW1 and SW3 would pick Root Ports toward SW2 and the blocked link would change accordingly. Use this leverage to control active topology during design.
