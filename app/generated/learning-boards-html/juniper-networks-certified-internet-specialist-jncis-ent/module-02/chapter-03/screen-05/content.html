Module 2 › Chapter 2.3 › What STP Does
Claim

Prevent loops, keep redundancy

STP elects a Root Bridge and chooses which ports forward so there is one active path between network segments while blocked ports standby for failover.

BPDU
Frames that carry Bridge ID and path cost to enable election and topology updates.
Root Bridge
The elected reference switch with the lowest Bridge ID.
Blocked Port
A port that does not forward user traffic but listens for BPDUs.
Analogy
Think of STP as a traffic director that closes one lane on a circular street so cars don't loop endlessly, while leaving other lanes available if the main lane is blocked.
Supporting bullets
  • BPDUs are how switches agree on the topology.
  • The lowest Bridge ID becomes Root Bridge.
  • One Designated Port per segment forwards traffic for that segment.
  • Non-designated ports are blocked to prevent loops but will recover if needed.
Key Takeaway

STP trades a single active path for safe redundancy; blocked ports are not failures but insurance for link loss.
