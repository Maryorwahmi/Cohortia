Module 2 › Chapter 2.3 › Key Concepts
Layer 2 Loop
Multiple active paths cause broadcast storms and MAC table flapping.
STP Roles
Root Bridge, Root Port, Designated Port, Non-Designated (blocked).
STP Variants
STP (stable, slow), RSTP (faster), MSTP (multiple instances per VLAN).
Summary takeaway

Prevent loops first. Use Bridge ID and path cost reasoning to predict roles. Choose RSTP or MSTP based on convergence and multi-VLAN needs.
