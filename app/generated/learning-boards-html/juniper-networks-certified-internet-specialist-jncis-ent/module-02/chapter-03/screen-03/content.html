Module 2 › Chapter 2.3 › Practice Plan
Step sequence
  1. Identify loop symptoms: broadcast storm, MAC table instability, duplicate frames.
  2. Elect the Root Bridge by lowest Bridge ID (priority + MAC).
  3. Find Root Ports by lowest cost path to the Root Bridge.
  4. Elect Designated Ports per segment and mark non-designated ports as blocked.
  5. Simulate link failure and observe STP reconfiguration or RSTP rapid transition.
Self-check: Explain why a blocked port still listens for BPDUs.
Tools & tips
Reason from MACs and priorities when you lack command output.
Remember: BPDUs carry Bridge ID and path cost; they enable election.
Note: RSTP often enabled by default on modern Juniper EX switches for faster convergence.
