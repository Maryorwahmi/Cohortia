Module 2 › Chapter 2.3 › STS Protocols
STP (802.1D)
Conservative timing, stable but slow convergence. Useful in simple topologies where stability is prioritized.
RSTP (802.1w)
Introduces Alternate and Backup roles and faster transitions. Good default on modern switches for quicker failover.
MSTP (802.1s)
Maps VLANs to multiple instances so you can load-balance VLAN traffic across physical links.
Practical guidance
If you need faster convergence without VLAN-specific topologies, use RSTP. If you need per-VLAN control for load balancing in a large environment, design MSTP instance mappings carefully. Avoid enabling MSTP without a mapping plan to prevent unpredictable forwarding behavior.
