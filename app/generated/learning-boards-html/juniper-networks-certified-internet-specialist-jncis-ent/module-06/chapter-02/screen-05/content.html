Open Message Contents and Failures
What Open negotiates and how to detect mismatches.
Open message fields
  • Version: BGP protocol version number.
  • Autonomous System number: The sender's AS used for external and internal peering decisions.
  • Hold time: Maximum interval to wait for Keepalive or Update before declaring peer down.
  • Router ID: An IP used to uniquely identify the speaker.
If these do not align, a Notification is sent and the session closes.
Concrete troubleshooting example
Change the configured peer AS on one router. The local router sends an Open with the wrong AS. The remote router detects the mismatch and replies with a Notification. Both neighbors reset the session.
Quick checks
  • Verify neighbor IP and AS configuration matches the peer.
  • Confirm TCP connectivity to port 179 and interface status.
  • Look for asymmetric routing or one-way communication preventing Open delivery.
