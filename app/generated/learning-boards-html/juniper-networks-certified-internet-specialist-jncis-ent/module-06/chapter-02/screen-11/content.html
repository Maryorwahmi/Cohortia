Active and OpenSent — Connectivity vs Parameter Problems
Use simple checks to quickly isolate the problem domain.
Active troubleshooting checklist
  1. Ping the peer IP to confirm basic reachability.
  2. Confirm no firewall or ACL blocks TCP port 179.
  3. Check interface and route status to the peer.
OpenSent checks
If TCP completes but OpenSent persists, verify the configured neighbor AS and any authentication parameters. Also consider packet capture to confirm the peer's Open arrives.
Misconception: OpenSent is rarely a pure BGP implementation bug — it commonly maps to mismatched Open parameters or one-way packet loss.
