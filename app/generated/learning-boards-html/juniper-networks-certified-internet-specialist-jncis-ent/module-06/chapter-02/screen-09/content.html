BGP Finite State Machine (FSM)
Six neighbor states and the events that drive transitions.
State list and intent
  • Idle: Not attempting; waiting for a start event.
  • Connect: Initiating TCP connection to peer.
  • Active: Trying to establish TCP; often indicates connectivity issues.
  • OpenSent: TCP established and Open sent, awaiting peer Open.
  • OpenConfirm: Open received and Keepalive exchanged, awaiting confirmation.
  • Established: Session fully operational and exchanging Updates.
Concrete example
When you start peering, logs will show transition from Idle to Connect to OpenSent to OpenConfirm and finally to Established if all TCP and parameter checks succeed. A transition to Active suggests you need to check reachability and port 179 filtering first.
Key takeaway
Read the neighbor state first to narrow the cause: connectivity, parameter mismatch, or normal operation.
