Learning Objectives
Master the message types, FSM, neighbor states, and practical troubleshooting checks.
01
Identify BGP message types
Describe Open, Update, Keepalive, and Notification and when each is used.
Mnemonic: Message roles as handshake, heartbeat, updates, and errors.

03
Detail neighbor state transitions
Map events that cause transitions between Idle, Connect, Active, OpenSent, OpenConfirm, and Established.
Mnemonic: Connect attempts, Open exchange, Keepalive confirmation.

04
Recognize session failures
Use neighbor states and message observations to identify TCP issues, parameter mismatches, or protocol errors.
Quick checks: ping, interface status, firewall rules, configured peer IP and AS.
