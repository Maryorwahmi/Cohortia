Update Messages and NLRI
How route advertisements and withdrawals change reachability.
What an Update contains
  • NLRI: The prefixes being announced or withdrawn.
  • Path attributes: Metadata such as AS path and next hop that influence selection.
  • Withdrawals: Indicate previously advertised prefixes are no longer reachable.
Updates shape what routes are accepted into the BGP table and potentially into the routing table.
Concrete example
Router A advertises 203.0.113.0/24 with a next hop and AS path. Router B receives the Update and records the NLRI and attributes. If later Router A withdraws that prefix, Router B removes it from its BGP table and withdraws dependent forwarding state.
Key takeaway
Key Takeaway

Watch Update content and frequency: they directly control which prefixes are visible and when they are removed.
