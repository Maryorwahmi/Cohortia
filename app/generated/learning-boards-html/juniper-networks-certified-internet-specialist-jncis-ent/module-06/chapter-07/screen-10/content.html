Module 7 › Chapter 6.7 › BGP Traceoptions
Definition

What traceoptions capture

Traceoptions log BGP message exchanges and FSM transitions in detail. Use flags to focus on state, open, or updates rather than logging everything.

Safety note
Always set small file size and limited files, and deactivate traceoptions after debugging to avoid resource exhaustion.
Configuration Snippet
set protocols bgp traceoptions file bgp-debug size 10m files 5
set protocols bgp traceoptions flag state
set protocols bgp traceoptions flag open
commit
# After debugging
deactivate protocols bgp traceoptions
commit
show log bgp-debug
Concrete workflow
Enable targeted flags, reproduce the issue, inspect the log for Notification or malformed messages, then deactivate traces and commit to clean up.
