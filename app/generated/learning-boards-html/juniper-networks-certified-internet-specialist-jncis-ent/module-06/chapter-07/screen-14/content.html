Question 1
OpenSent state on eBGP — likely cause and best immediate Junos command?
Answer: Parameter mismatch such as incorrect AS numbers or auth. Use run show bgp neighbor <IP> to inspect FSM and last error.
Question 2
Configured network 192.168.20.0/24 but ISP not receiving it — two commands to verify.
Answer: run show route 192.168.20.0/24 to ensure prefix exists, and run show route advertising-protocol bgp <ISP-IP> to verify the prefix is being advertised. If missing, check export policy and family inet unicast.
Exam tip

When answering, describe the command outputs you expect to see and the next action based on that evidence.
