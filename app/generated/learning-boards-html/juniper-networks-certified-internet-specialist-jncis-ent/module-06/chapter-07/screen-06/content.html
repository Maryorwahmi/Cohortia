Module 7 › Chapter 6.7 › OpenSent / OpenConfirm
Comparison

Parameter mismatches vs transport issues

Check AS numbers: Ensure peer-as matches the neighbor's configured autonomous-system.
Authentication: If MD5 or other auth is in use, keys must match exactly.
Capabilities: Some vendors or old devices may not support negotiated capabilities; check last errors.
Hold time: Mismatched timers can cause negotiation or session flaps if misaligned.
Command to run
show bgp neighbor 10.0.0.2
Terminal Output Example
Neighbor: 10.0.0.2, Peer AS: 65002
  State: OpenConfirm
  Last error: Notification received - Unsupported Capability
Concrete fix
Find the capability mismatch or wrong peer-as, correct the configuration, then re-check the neighbor state until it shows Established.
