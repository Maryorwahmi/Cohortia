Module 7 › Chapter 6.7 › Routes Not Advertised
Definition

Prove what you are sending

show route advertising-protocol bgp <neighbor-ip> reveals the routes your router offers. If a route is missing, verify route existence, export policy, and address-family configuration.

  • Confirm prefix exists: show route <prefix>
  • Test export policy: test policy <policy-name> <route-to-test>
  • Check family: ensure family inet unicast is set for the BGP group.
Common mistake
Assuming a network statement advertises a prefix even if the route is absent from inet.0 or blocked by export policy.
Terminal Demo
show route advertising-protocol bgp 10.0.0.2
# If 192.168.20.0/24 not listed
show route 192.168.20.0/24
show policy policy-statement EXPORT-TO-ISP
test policy EXPORT-TO-ISP 192.168.20.0/24
Concrete fix
If route missing from inet.0, ensure network statement or IGP installs it. If export policy denies it, update the policy and re-check advertising-protocol output.
