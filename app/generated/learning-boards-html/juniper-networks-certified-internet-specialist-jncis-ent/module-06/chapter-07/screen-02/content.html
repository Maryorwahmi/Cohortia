Learning Objectives

Master checks and Junos commands to troubleshoot BGP sessions, routes, and path selection.

Bloom: Learn → Understand → Apply → Master
01
Identify common BGP issues

Detect neighbor down, routes not advertised or received, and unexpected path selection using stateful observation. Verified competency milestone: explain causes from a show bgp summary output.

VERIFIED COMPETENCY MILESTONE
02
Use Junos CLI for diagnosis

Run show bgp summary, show bgp neighbor, show route advertising-protocol and receive-protocol to gather evidence. Milestone: produce a short diagnostic checklist for a neighbor in Active state.

VERIFIED COMPETENCY MILESTONE
03
Resolve advertisement/reception failures

Check network statements, family inet unicast, export/import policies, and next-hop reachability to restore expected route exchange. Milestone: demonstrate restoring advertisements in a lab scenario.

VERIFIED COMPETENCY MILESTONE
04
Use BGP traceoptions safely

Enable targeted traceoptions, collect logs, then deactivate traces to avoid resource issues. Milestone: capture and interpret a trace of a session open exchange.

VERIFIED COMPETENCY MILESTONE
