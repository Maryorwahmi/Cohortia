Hands-on Activity

Introduce, diagnose, correct, verify

  1. Set wrong peer-as on R1 and commit to simulate Open mismatch.
  2. Run run show bgp summary and run show bgp neighbor to find errors.
  3. Fix peer-as, commit, and verify Established state.
  4. Deactivate family inet unicast on R1 to simulate no advertisement.
  5. Use run show route advertising-protocol and run show route receive-protocol to confirm missing routes.
  6. Reactivate family, commit, and verify routes exchange.
  7. Enable traceoptions with small file, reproduce, view log, then deactivate traceoptions and commit clean-up.
Commands (on R1)
edit
set protocols bgp group EBGP_PEER neighbor 10.0.0.2 peer-as 65003
commit
run show bgp summary
run show bgp neighbor 10.0.0.2
set protocols bgp group EBGP_PEER neighbor 10.0.0.2 peer-as 65002
commit
# Simulate advertising issue
deactivate protocols bgp group EBGP_PEER family inet unicast
commit
run show route advertising-protocol bgp 10.0.0.2
# Restore
activate protocols bgp group EBGP_PEER family inet unicast
commit
# Traceoptions
set protocols bgp traceoptions file bgp-debug size 1m files 2
set protocols bgp traceoptions flag state
set protocols bgp traceoptions flag open
commit
run clear bgp neighbor 10.0.0.2
run show log bgp-debug
deactivate protocols bgp traceoptions
commit
Key Takeaway

Use these reproducible steps in a lab before applying fixes in production to build confidence and reduce risk.
