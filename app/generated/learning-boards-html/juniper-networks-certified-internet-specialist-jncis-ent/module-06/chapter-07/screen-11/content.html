Process Flow

Stepwise diagnosis for multi-homing

  1. Confirm sessions: show bgp summary for both ISP peers.
  2. Verify received routes: show route receive-protocol bgp <isp-ip> for both peers.
  3. Compare attributes: show route <prefix> detail to inspect LOCAL_PREF, AS_PATH, MED.
  4. Check import policies and test with test policy.
  5. Adjust import policy to set LOCAL_PREF for the preferred link; re-check selected path.
Terminal Demo
show bgp summary
show route receive-protocol bgp 203.0.113.1
show route receive-protocol bgp 203.0.113.2
show route 0.0.0.0/0 detail
show policy policy-statement IMPORT-ISP-A
show policy policy-statement IMPORT-ISP-B
Example outcome
Less-preferred link selected because its import policy assigned a higher LOCAL_PREF. Adjust policy to favor preferred ISP and verify path change with show route detail.
