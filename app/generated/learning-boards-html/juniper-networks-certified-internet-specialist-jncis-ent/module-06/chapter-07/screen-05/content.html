Process Flow

A short checklist for TCP reachability

  1. ping <neighbor-ip-address> to confirm basic connectivity.
  2. show interfaces terse to check link and IP configuration.
  3. show route <neighbor-ip-address> to verify routing to the peer.
  4. For loopback peering, validate local-address is reachable from the peer.
  5. Confirm TCP port 179 is allowed by any ACLs or firewalls in path.
Misconception
A successful ping does not guarantee TCP 179 is permitted. Always test or verify port filtering separately.
Terminal Demo
ping 10.0.0.2
show interfaces terse
show route 10.0.0.2
# For loopback peer
show route 192.0.2.2
Scenario
Ping succeeds but TCP 179 is blocked by an ACL on a transit device. The session stays in Connect. Fix the ACL and re-verify the session advances to Established.
