Module 7 › Chapter 6.7 › Inspecting Path Selection
Core Concept

Compare path attributes to find the best path reason

Look at LOCAL_PREF, AS_PATH, MED, Origin, and Next-Hop. Policies may alter these attributes and change selection.

LOCAL_PREF: higher is preferred and often set by import policy.
AS_PATH: shorter paths are preferred unless local policy overrides.
MED: lower is preferred when comparing paths from the same neighbor AS.
Pro-tip
When multiple ISPs present differing LOCAL_PREF values, audit import policies on both ISP sessions to ensure expected preferences.

Scenario
Two ISP links show different LOCAL_PREF values due to misconfigured import policies. Adjust the import policy for the preferred link to set a higher LOCAL_PREF and re-check the active path.
