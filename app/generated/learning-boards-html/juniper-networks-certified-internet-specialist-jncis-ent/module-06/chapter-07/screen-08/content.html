Module 7 › Chapter 6.7 › Routes Not Received
Core Concept

Was the route sent or dropped locally?

show route receive-protocol bgp <neighbor> lists what the peer sent before import policies. Compare that to show route protocol bgp to see what was accepted.

  • If in receive-protocol but not accepted: inspect import policy or next-hop reachability.
  • Check next-hop with show route <next-hop-ip> for iBGP scenarios.
  • Watch for AS_PATH loops: if local AS present, route is discarded.
Terminal Demo
show route receive-protocol bgp 10.0.0.2
show route protocol bgp
show route 192.0.2.1
show policy policy-statement IMPORT-FROM-ISP
test policy IMPORT-FROM-ISP 203.0.113.0/24
Concrete example
Route present in receive-protocol but absent from protocol. test policy shows import policy denies the prefix. Update import policy to accept the prefix and re-check that the BGP table contains the route.
