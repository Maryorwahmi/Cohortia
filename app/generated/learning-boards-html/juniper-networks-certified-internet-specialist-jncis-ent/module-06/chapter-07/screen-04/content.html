Module 7 › Chapter 6.7 › Diagnosing Neighbor State
Core Concept

Interpret FSM states from show bgp summary

Use the neighbor state to decide whether to check transport or BGP parameters. Active/Connect usually means TCP problems; OpenSent/OpenConfirm suggests parameter mismatch.

  • IP reachability: run ping to the neighbor IP to confirm basic transport.
  • Interface check: show interfaces terse to find administratively down or wrong IP.
  • Routing to neighbor: show route <neighbor-ip-address> ensures a route exists for TCP sessions over loopbacks.
Common mistake
Assuming BGP will form a session without verifying the underlying IP path and the source address used for TCP.
Key Takeaway

Neighbor FSM states point you to either TCP/infrastructure issues or BGP parameter mismatches. Validate reachability first.

Terminal Demo
show bgp summary Neighbor AS Up/Down State 10.0.0.2 65002 never Active # Follow-ups ping 10.0.0.2 show interfaces terse show route 10.0.0.2
Concrete example
Peer stuck in Active. Ping fails. show interfaces terse reveals interface to neighbor is down. Bring interface up and session progresses to Established.
