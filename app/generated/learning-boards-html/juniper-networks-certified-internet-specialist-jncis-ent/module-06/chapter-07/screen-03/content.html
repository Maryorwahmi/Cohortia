Module 7 › Chapter 6.7 › Verification Milestones
Neighbor Failure Milestone
From show bgp summary, identify the FSM state and list two non-disruptive follow-ups that confirm reachability or parameter mismatch.
Advertisement Milestone
Use show route advertising-protocol and show route <prefix> to prove the prefix exists and is being offered to a peer.
Reception Milestone
Compare receive-protocol and protocol outputs to prove whether an import policy or next-hop reachability removed a received route.
Path Selection Milestone
Show route <prefix> detail and explain which attribute decided the best path and why a policy may have changed it.
Traceoptions Milestone
Enable a targeted trace with limited file size and flags, reproduce the event, capture logs, then deactivate traces and show the file output with show log.
Key Takeaway

Verification requires repeatable evidence: prefer show commands, document outputs, and avoid destructive clears until necessary.
