Module 6 › Chapter 6.6 › Lab Walkthrough
Scenario summary
R1 (AS 65000) peers with R2 (ISP A, AS 100) and R3 (ISP B, AS 200). R1 advertises 192.168.100.0/24 to both ISPs. Goal: prefer R2 for outbound, make R3 prefer a less desired path inbound.
Step-by-step
  1. Create import policy PREFER_ISP_A to set local-preference 200 and attach to group from ISP A.
  2. Create export policy PREPEND_AS_TO_ISP_B to as-path-prepend "65000 65000" and attach to group to ISP B.
  3. Announce 192.168.100.0/24 via network or static routing and verify with show commands.
Junos configuration snippets
# Prefer ISP A for outbound
set policy-options policy-statement PREFER_ISP_A term 1 then local-preference 200
set protocols bgp group TO_ISP_A import PREFER_ISP_A

# Make ISP B see a longer path
set policy-options policy-statement PREPEND_AS_TO_ISP_B term 1 then as-path-prepend "65000 65000"
set protocols bgp group TO_ISP_B export PREPEND_AS_TO_ISP_B
Verification
Run show route protocol bgp <prefix> detail on R1 and ask R3 for show route receive-protocol bgp <R1_IP> to confirm the prepended AS_PATH.
