NEXT_HOP reachability
The next-hop IP must be present in the routing table for the BGP path to be considered. This is the first check in Junos' selection algorithm.
eBGP behavior
NEXT_HOP is normally the directly connected peer address and is usually reachable by default.
iBGP behavior
iBGP preserves NEXT_HOP from eBGP peers. Internal routers must have an IGP route to that NEXT_HOP.
Verification commands
show route protocol bgp  detail
show route  detail
Check that the next-hop resolves to an active route before modifying other attributes.
Common mistake
Relying on iBGP without ensuring the IGP knows loopback next-hops. This leads to otherwise valid BGP paths being ignored.
