Module 6 › Chapter 6.6 › Best Path Steps
1. Next-Hop Reachability
Path must have a reachable next-hop in the routing table or it is ignored.
2. LOCAL_PREF
Highest local preference wins; primary control for outbound selection.
3. AS_PATH Length
Shortest AS_PATH preferred when LOCAL_PREFs are equal.
4. ORIGIN
Prefer IGP < EGP < Incomplete.
5. MED
Lower MED preferred; typically compared per-adjacent AS on Junos.
6. eBGP over iBGP
Prefer routes learned from eBGP if attributes are equal.
7–9. IGP Cost, Router ID, Peer IP
IGP cost to BGP next-hop, lowest Router ID, then lowest peer IP are last tie-breakers.
Worked example
Two equal routes with reachable next-hops and equal LOCAL_PREF: compare AS_PATH length. If still equal, prefer IGP origin. If still equal, compare MED only if from same neighbor; otherwise prefer eBGP.
Misconception
Do not assume a single attribute always wins; follow the sequence to reason why a path was chosen.
