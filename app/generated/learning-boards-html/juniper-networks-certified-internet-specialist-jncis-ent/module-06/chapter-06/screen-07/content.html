Module 6 › Chapter 6.6 › LOCAL_PREF
What LOCAL_PREF does
An iBGP-only attribute that determines which path the AS prefers for outbound traffic. Higher is preferred.
Example use
Set LOCAL_PREF 200 for routes from ISP A and 100 for ISP B so the AS prefers ISP A for outbound flows.
Configuration example
set policy-options policy-statement PREFER_ISP_A term 1 then local-preference 200
set protocols bgp group FROM_ISP_A import PREFER_ISP_A

set policy-options policy-statement PREFER_ISP_B term 1 then local-preference 100
set protocols bgp group FROM_ISP_B import PREFER_ISP_B
Apply these as import policies on the groups receiving routes from each ISP.
Misconception
LOCAL_PREF affects outbound selection inside your AS only; it does not directly influence how upstream peers route to you.
