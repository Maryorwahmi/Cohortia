Import vs Export
Import policies shape the attributes of routes you accept; export policies shape attributes you send to peers. Apply LOCAL_PREF on import; MED or prepending on export.
Example: prefer ISP A
set policy-options policy-statement PREFER_ISP_A term 1 then local-preference 200
set protocols bgp group TO_ISP_A import PREFER_ISP_A
Example: make ISP B prefer another path
set policy-options policy-statement PREPEND_AS_TO_ISP_B term 1 then as-path-prepend "65000 65000"
set protocols bgp group TO_ISP_B export PREPEND_AS_TO_ISP_B
This makes your route appear longer to ISP B and remote peers that see that path.
Verification
Use show route protocol bgp <prefix> detail locally and request the neighbor's received-route view to confirm exported attribute changes.
