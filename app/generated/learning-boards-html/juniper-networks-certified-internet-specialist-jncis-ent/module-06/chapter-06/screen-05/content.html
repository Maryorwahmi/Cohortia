Module 6 › Chapter 6.6 › AS_PATH
AS_PATH behavior
Records AS numbers a route passed through. Used to prevent loops and to prefer shorter paths after LOCAL_PREF is evaluated.
Loop prevention
If a router sees its AS in AS_PATH, it rejects the update to avoid a loop.
Path preference
Between equal LOCAL_PREFs, Junos prefers the shorter AS_PATH.
Prepending
Add your AS multiple times on export to make the path less attractive to remote networks.
Configuration snippet (export prepending)
set policy-options policy-statement PREPEND_AS_TO_ISP_B term 1 then as-path-prepend "65000 65000"
set protocols bgp group TO_ISP_B export PREPEND_AS_TO_ISP_B
This makes the advertised AS_PATH look longer to peers of ISP B.
Misconception
Prepending guarantees no diversion. It only changes perceived path length; the remote AS has other attributes and policies that may override your suggestion.
