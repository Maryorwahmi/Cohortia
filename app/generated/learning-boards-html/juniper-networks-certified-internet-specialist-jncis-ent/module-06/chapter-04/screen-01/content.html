Configuring Basic iBGP Peering and Route Reflectors
Understand how internal BGP distributes external routes inside an AS and how Route Reflectors solve the full-mesh problem.
In this lesson

Establish iBGP sessions using loopbacks, verify IGP reachability, and configure a Route Reflector with clients using Junos commands and best practices.

Why it matters

As networks grow, managing many iBGP sessions becomes error-prone. Route Reflectors let you scale while preserving route visibility.

Scenario
Multiple edge routers receive different external prefixes. iBGP is used so internal routers can make forwarding decisions based on a consistent set of external routes.
Practical step
Use loopbacks as BGP local-address and verify loopback reachability via OSPF or another IGP before bringing up iBGP.
Key takeaway
Route Reflectors reduce iBGP session count and simplify operations, but their design must avoid new loops or reachability holes.
