Lab checklist
  1. Create loopbacks on each router and assign /32 addresses used as local-address.
  2. Ensure loopbacks are advertised in OSPF or another IGP so they are reachable.
  3. Configure BGP group with type internal and neighbors pointing to peer loopbacks.
  4. Convert one router to a Route Reflector server and set route-reflector-client flags on neighbors.
  5. Verify sessions with show bgp summary and check route reflection with show route protocol bgp.
Quick verification commands (conceptual)
show bgp summary — confirm Established state for all iBGP neighbors.
show route <peer-loopback-ip> — confirm loopback reachability in the IGP.
show route protocol bgp — confirm reflected routes and origin.
