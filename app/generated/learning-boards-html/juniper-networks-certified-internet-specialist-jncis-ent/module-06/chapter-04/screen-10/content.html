Module 6 › Chapter 6.4 › Common Mistakes
Mistake: IGP not advertising loopbacks
Symptom: BGP stuck in Active. Fix: add loopbacks to OSPF/IS-IS or static routes and confirm with show route <loopback>.
Mistake: Missing local-address
Symptom: TCP source mismatch. Fix: set local-address to the loopback on both peers when using loopback-based peering.
Mistake: Split-horizon violation attempt
Symptom: Routes not forwarded between iBGP peers. Fix: use Route Reflectors or confederations; you cannot advertise iBGP-learned routes to another iBGP peer directly.
Mistake: Client/server flag misplacement
Symptom: RR doesn't reflect routes. Fix: apply route-reflector-client on the RR config for each client; clients require only a normal neighbor statement.
Pro tip

When troubleshooting, start with reachability to the loopback, then local-address, then BGP group settings. These checks solve the majority of lab issues.
