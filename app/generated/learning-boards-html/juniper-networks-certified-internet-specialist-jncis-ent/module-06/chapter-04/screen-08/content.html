Module 6 › Chapter 6.4 › Route Reflector Server
RR server example — R1
# Assume lo0 is configured and AS is set
set protocols bgp group IBGP_CLIENTS type internal
set protocols bgp group IBGP_CLIENTS neighbor 10.0.0.2 family inet unicast route-reflector-client
set protocols bgp group IBGP_CLIENTS neighbor 10.0.0.3 family inet unicast route-reflector-client
set protocols bgp group IBGP_CLIENTS local-address 10.0.0.1
set protocols bgp group IBGP_CLIENTS cluster 10.0.0.1
After applying these lines, confirm the group lists both neighbors and that each session is Established. If sessions remain down, first verify loopback reachability via your IGP.
