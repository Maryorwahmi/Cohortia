Module 6 › Chapter 6.4 › Split-horizon & Full-mesh
Rule
A BGP speaker does not advertise routes learned via iBGP to other iBGP peers. That rule prevents loops but blocks transitive propagation inside an AS.
Full-mesh formula
Sessions = N * (N - 1) / 2
Example: N = 10 → 10 * 9 / 2 = 45 sessions.
Misconception
Establishing an IGP path doesn't change split-horizon semantics. IGP provides reachability for loopbacks, but BGP still enforces its advertisement rules.
Mitigation options
Route Reflectors
Use an RR server to reflect routes between clients and reduce session count dramatically.
Confederations
Split a large AS into sub-ASes to limit full-mesh within each confederation and control policy across boundaries.
Check
If you have eight core routers, how many sessions are required by a full mesh? (Answer: 8 * 7 / 2 = 28.)
