Apply Junos commands to mark neighbors as route-reflector-client and set the cluster identifier. VERIFIED COMPETENCY MILESTONE
How to use these objectives
  • Practice the Junos commands in a three-router lab to connect understanding to operation.
  • Verify loopback reachability in your IGP before attempting iBGP sessions.
  • Use Route Reflectors to reduce session count only after validating cluster reachability and avoiding loops.
Tip: treating loopbacks as stable router IDs avoids session flapping when physical interfaces change.
