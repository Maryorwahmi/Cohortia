Starter Junos snippets (R1, R2, R3)
# R1 (RR) Lo0: 10.0.0.1
set routing-options autonomous-system 65000
set interfaces lo0 unit 0 family inet address 10.0.0.1/32
set protocols bgp group IBGP_RR type internal
set protocols bgp group IBGP_RR local-address 10.0.0.1
set protocols bgp group IBGP_RR neighbor 10.0.0.2 family inet unicast route-reflector-client
set protocols bgp group IBGP_RR neighbor 10.0.0.3 family inet unicast route-reflector-client
set protocols bgp group IBGP_RR cluster 10.0.0.1

# R2 Lo0: 10.0.0.2
set interfaces lo0 unit 0 family inet address 10.0.0.2/32
set routing-options autonomous-system 65000
set protocols bgp group IBGP_TO_RR type internal
set protocols bgp group IBGP_TO_RR local-address 10.0.0.2
set protocols bgp group IBGP_TO_RR neighbor 10.0.0.1

# R3 Lo0: 10.0.0.3 (similar to R2)
Verification: run show bgp summary, show bgp group IBGP_RR on R1, and show route protocol bgp on clients to observe reflected routes. If you succeed, R3 will see prefixes advertised by R2 without a direct R2-R3 BGP session.
Key Takeaway

The lab demonstrates how an RR reduces session count while preserving route visibility. Always verify IGP reachability before troubleshooting BGP sessions.
