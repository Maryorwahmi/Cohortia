Module 6 › Chapter 6.1 › Identify eBGP and iBGP
Activity

Label the peerings and trace the path

Given the diagram of Enterprise A (AS 65001), ISP (AS 100), and Enterprise B (AS 65002), mark eBGP on the inter‑AS links and iBGP on internal links. Then draw arrows showing how a prefix from AS 65001 reaches a host in AS 65002 via AS 100.
Check answers
1) Links between different AS numbers are eBGP. 2) Links between routers with the same AS number are iBGP. 3) Route travels via eBGP to the ISP, through the ISP, then via eBGP to the destination AS and is distributed internally via iBGP.
Mini diagram
[Enterprise A] AS 65001
eBGP → [ISP] AS 100 → eBGP → [Enterprise B] AS 65002
Internal routers in each enterprise connect via iBGP to share external routes.
Pro tip
Always verify AS numbers printed on diagrams when labeling peer types.
