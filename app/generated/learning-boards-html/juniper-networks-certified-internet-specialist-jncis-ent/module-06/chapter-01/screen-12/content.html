Module 6 › Chapter 6.1 › Assessment scenario

Diagnostic exercise

Given a network diagram with two enterprises and one ISP, label eBGP and iBGP, list AS numbers per router, and draw route advertisement arrows for a public prefix. Use the AS number rule to decide peering types and remember to indicate advertisement direction for clarity.
Expected correct answers include
eBGP between different AS numbers; iBGP inside the same AS; local AS values listed next to each router; arrows showing advertisement flow from origin AS through ISP to destination AS.
Reflection prompt
After answering, ask: have I verified next‑hop reachability and considered whether my policy would prefer a different path? Those checks validate operational readiness.
