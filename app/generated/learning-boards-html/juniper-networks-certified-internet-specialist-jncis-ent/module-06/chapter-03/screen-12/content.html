Key Concepts — Part 1
Three compact reminders to keep in mind.
Autonomous System (AS)
Set with set routing-options autonomous-system <AS_number>.
BGP Group
Logical container for neighbors; set type external for eBGP.
Peer-AS
neighbor <ip> peer-as <AS> points to the remote autonomous-system.
Summary

Local AS, external group, and correct peer-as are the minimal, non-negotiable pieces of a working eBGP peering on Junos.
