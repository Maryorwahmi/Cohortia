Module 06 › Chapter 6.3 › BGP Group & type external
BGP group: simplify neighbor config
Group type external signals eBGP peers in different ASes.
What it does

A BGP group collects neighbor definitions and shared parameters such as type, graceful-restart settings, and common policies. For eBGP, set the group type to external so Junos treats the group’s neighbors as remote AS peers.

Why not internal

Type internal is for iBGP inside a single AS. Using internal for an external peering will misclassify the relationship and lead to incorrect behavior.

Rule
Set type external for eBGP
Tip
Use descriptive group names
Example: TO_ROUTER_B
Example configuration
set protocols bgp group TO_ROUTER_B type external
set protocols bgp group TO_ROUTER_B neighbor 10.0.0.2 peer-as 65002
Common mistake

Using type internal when peers reside in different ASes will prevent the expected eBGP behavior.
