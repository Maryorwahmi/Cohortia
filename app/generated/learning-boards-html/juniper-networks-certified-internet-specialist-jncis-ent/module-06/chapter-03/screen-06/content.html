Module 06 › Chapter 6.3 › Router A Configuration
Router A: AS 65001
Ensure interface and local AS are configured before adding BGP neighbors.
set interfaces ge-0/0/0 unit 0 family inet address 10.0.0.1/30
set routing-options autonomous-system 65001
set protocols bgp group TO_ROUTER_B type external
set protocols bgp group TO_ROUTER_B neighbor 10.0.0.2 peer-as 65002
Practical note

After commit, check that the interface is up and that you can ping 10.0.0.2. If ping fails, BGP will not progress beyond TCP connection attempts.

Check
Ping neighbor, then show bgp summary
Misstep
Swapping local and peer AS numbers causes session failures.
Example scenario

Router A is directly connected to Router B via a /30 link. Use the snippet above to configure the link and the eBGP group. After commit, observe the BGP FSM as it progresses toward Established.

Key Takeaway

Match neighbor IP and peer-as to the remote router’s configured address and AS; commit and verify reachability immediately.
