Module 06 › Chapter 6.3 › Hands-on Activity
Lab scenario: R1 ↔ R2
Follow these tasks to practice configuration, verification, and troubleshooting.
Starter configuration templates
# On Router R1 (AS 64501)
edit
set interfaces ge-0/0/0 unit 0 family inet address 192.168.1.1/30
set routing-options autonomous-system 64501
set protocols bgp group EBGP_LINK type external
set protocols bgp group EBGP_LINK neighbor 192.168.1.2 peer-as 64502
commit and-quit

# On Router R2 (AS 64502)
edit
set interfaces ge-0/0/0 unit 0 family inet address 192.168.1.2/30
set routing-options autonomous-system 64502
set protocols bgp group EBGP_LINK type external
set protocols bgp group EBGP_LINK neighbor 192.168.1.1 peer-as 64501
commit and-quit
Lab steps
  1. Apply configuration on both routers and commit.
  2. Ping the neighbor IP from each side to confirm reachability.
  3. Run run show bgp summary and run show bgp neighbor on each router to verify Established.
  4. Introduce an error: change peer-as on R1 to an incorrect AS and commit, observe state changes, then revert.
Expected observations
  • Successful ping before BGP completes.
  • show bgp summary moves to Establ when both sides match AS and reachability is present.
  • An incorrect peer-as results in OpenSent/OpenConfirm or repeated errors until fixed.
Safety note

Perform these changes in a lab or maintenance window. Incorrect BGP configuration can impact routing beyond the test routers.
