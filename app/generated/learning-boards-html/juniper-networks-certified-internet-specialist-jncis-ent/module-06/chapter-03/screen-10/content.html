Module 06 › Chapter 6.3 › Common Mistakes
Four common causes of eBGP failure
Work through these checks in order: reachability, AS mismatch, firewall, and source interface.
IP Reachability
If you cannot ping the neighbor IP, BGP TCP handshake fails. Use ping first.
AS Number Mismatch
peer-as must match the neighbor’s autonomous-system or the session will not reach Established.
Firewall / ACLs
Ensure TCP port 179 is allowed between the peering interfaces.
Incorrect Source Interface
On multi-interface devices, BGP might use a different source address; confirm and correct if needed.
Quick debug sequence
  1. Ping the neighbor IP.
  2. Run show bgp summary to check state.
  3. Use show bgp neighbor for details.
  4. Inspect ACLs and source address if needed.
Pro tip

When testing, introduce only one change at a time so you can isolate the cause if the session fails.
