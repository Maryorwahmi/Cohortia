Why this matters

BGP is how autonomous systems exchange routing information. A single misconfigured AS number or blocked TCP 179 can prevent the session from forming and cause service disruptions. These basics protect your network from routing blackholes and accidental leaks when connecting to an ISP or partner.

Starter tip

Always configure the local autonomous-system before defining BGP groups. It’s required for BGP to run on Junos.
