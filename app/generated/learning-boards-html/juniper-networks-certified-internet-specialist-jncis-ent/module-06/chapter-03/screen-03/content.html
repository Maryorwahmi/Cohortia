Module 06 › Chapter 6.3 › Learning Objectives
How you'll demonstrate competence
Actionable checks, one per objective.
01
Apply routing-options autonomous-system
Action: set routing-options autonomous-system 65001. Verify by checking configuration or BGP activity. Why it matters: BGP will not run without a local AS.
Checkpoint: show configuration | match autonomous-system
VERIFIED COMPETENCY MILESTONE
02
Create external BGP group and neighbor
Action: set protocols bgp group NAME type external and neighbor IP peer-as. Verify the neighbor appears after commit.
Checkpoint: show bgp summary
VERIFIED COMPETENCY MILESTONE
03
Verify session and neighbor details
Action: run show bgp summary and show bgp neighbor . Verify Established state and inspect hold timers and capabilities.
Checkpoint: Established + prefix counts
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot common failures
Action: test ping reachability, validate peer-as numbers, check for TCP 179 blocking and source-interface issues. Observe BGP state transitions when errors are introduced.
Checkpoint: run ping and re-check show bgp summary
VERIFIED COMPETENCY MILESTONE
