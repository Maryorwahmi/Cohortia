Learning Objectives
Practical skills you will demonstrate in a lab or test.
01
Configure local Autonomous System
Set routing-options autonomous-system to declare the router's AS. This is required before BGP runs and identifies your network to peers.
Mnemonic: AS first, BGP follows.
VERIFIED COMPETENCY MILESTONE
02
Establish an eBGP group and neighbor
Create a protocols bgp group with type external and add neighbor peer-as. This pairs the local router with the remote AS.
Mnemonic: group = policy, neighbor = who.
VERIFIED COMPETENCY MILESTONE
03
Verify peering with show commands
Use show bgp summary for state and prefix counts, and show bgp neighbor to inspect capabilities and timers for deeper debugging.
Mnemonic: summary for health, neighbor for detail.
VERIFIED COMPETENCY MILESTONE
04
Identify and troubleshoot common mistakes
Check IP reachability, AS mismatches, TCP 179 reachability, and unintended source-interface issues to restore a failing eBGP session.
Mnemonic: PAST — Ping, AS, Security, Source.
VERIFIED COMPETENCY MILESTONE
