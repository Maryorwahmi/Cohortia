Deep inspection with show bgp neighbor
Use this command when you need capability, timer, or source-interface details.
What to read
  • Remote AS reported during OPEN.
  • Negotiated hold and keepalive timers.
  • Negotiated capabilities and prefix information.
  • Which local address the session is sourced from.
Practical use

If a session repeatedly fails, show bgp neighbor often reveals whether the problem is an AS mismatch, a capability negotiation failure, or an unexpected source address selection.

Quick checklist
  • Confirm remote AS matches expected peer-as.
  • Check hold timer and keepalive agreement.
  • Look for Notification messages or last error text.
Key Takeaway

When summary isn’t enough, use show bgp neighbor to find the exact cause of a failing BGP FSM transition.
