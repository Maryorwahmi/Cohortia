Module 06 › Chapter 6.3 › Router B Configuration
Router B: AS 65002
Symmetry: each router points to the other's IP and AS.
set interfaces ge-0/0/0 unit 0 family inet address 10.0.0.2/30
set routing-options autonomous-system 65002
set protocols bgp group TO_ROUTER_A type external
set protocols bgp group TO_ROUTER_A neighbor 10.0.0.1 peer-as 65001
Verification tip

After commit, ping 10.0.0.1 from Router B. If ping is successful, proceed to show bgp summary. If ping fails, fix IP or interface issues first.

Check
Confirm peer-as matches the remote autonomous-system
Pitfall
Forgetting to set the local AS on Router B prevents proper identification
Scenario note

This mirrored configuration is typical for ISP or partner links and demonstrates the minimal set of commands required to create a functioning eBGP peering on Junos.

Key Takeaway

Both sides must reference the other’s IP and AS. Symmetry reduces configuration mistakes.
