Module 06 › Chapter 6.3 › Autonomous System (AS) Number
Routing-options autonomous-system
Declare the router’s AS before configuring BGP groups and neighbors.
Definition

An Autonomous System (AS) number uniquely identifies your routing domain to remote BGP peers. Junos requires the local AS to be configured under routing-options; without it BGP cannot run.

Why it matters
  • It appears in BGP OPEN negotiation and identifies your network.
  • Peer AS values are compared to this local AS during session establishment checks.
  • Misconfiguration leads to sessions failing before routing exchange begins.
Common misconception

Do not assume protocols bgp entries are sufficient; routing-options autonomous-system must be present so the BGP FSM can proceed.

Concrete example
set interfaces ge-0/0/0 unit 0 family inet address 10.0.0.1/30
set routing-options autonomous-system 65001
Checklist
  • Apply the routing-options statement.
  • Confirm with show configuration or commit confirmation.
  • Only then create BGP groups and neighbors.
Key Takeaway

Set routing-options autonomous-system before any protocols bgp configuration to ensure BGP can start.
