Interpreting show bgp summary
A quick glance tells you the neighbor state and whether prefixes are being exchanged.
user@routerA> show bgp summary
Groups: 1 Peers: 1 Down peers: 0
Table          Tot Paths  Act Paths Suppressed    History Damp State    Pending
inet.0
             0          0          0          0          0          0
Peer                     AS      InPkt     OutPkt    OutQ   Flaps Last Up/Dwn State
10.0.0.2              65002        100        100       0       0 00:05:30 Establ
What to look for
  • State: Establ means the session is up.
  • Prefix counts: ensure In/Received numbers make sense.
  • Packet counters: confirm there is TCP activity between peers.
Troubleshooting hints
  • If state is Active, first test ICMP ping to the neighbor.
  • If state is OpenSent/OpenConfirm, validate peer-as values.
  • If Established but no prefixes, check advertisement policies.
Key Takeaway

show bgp summary is your first stop for BGP health. Interpret the State column to guide your next debug step.
