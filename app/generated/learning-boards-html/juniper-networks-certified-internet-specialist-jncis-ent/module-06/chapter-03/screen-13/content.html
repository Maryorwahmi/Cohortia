Key Concepts — Part 2
Commands and a short debugging flow to remember.
show bgp summary
Quick health check: neighbor state and counts.
show bgp neighbor <ip>
Detailed diagnostics: remote AS, timers, capabilities.
Troubleshooting flow
Ping → show bgp summary → show bgp neighbor → inspect ACLs/source.
Final Takeaway

Use the verification commands and a short debug order to fix most eBGP issues quickly and safely.
