Module 06 › Chapter 6.5 › Export policy walkthrough
Steps
  1. Create a policy-statement matching protocol ospf and any prefix filters you need.
  2. Test the policy with test policy <name> <sample-route> to confirm behavior.
  3. Apply the policy to the BGP group using export <policy-name>.
  4. Verify advertised routes with show route advertising-protocol bgp <neighbor>.
Why test?

Testing avoids unintentionally accepting nothing due to an implicit deny or accepting too many prefixes because of a loose filter.

Example commands
set policy-options policy-statement REDISTRIBUTE_OSPF_TO_BGP term 1 from protocol ospf
set policy-options policy-statement REDISTRIBUTE_OSPF_TO_BGP term 1 then accept
# Test with
run show configuration policy-options policy-statement REDISTRIBUTE_OSPF_TO_BGP
run test policy REDISTRIBUTE_OSPF_TO_BGP route 10.10.10.1/32
# Apply to BGP
set protocols bgp group EBGP_PEER export REDISTRIBUTE_OSPF_TO_BGP
Verification
show route advertising-protocol bgp 10.0.0.2 to confirm exported prefixes.
Pitfall
Do not skip test policy; an untested policy can block all routes due to implicit deny.
