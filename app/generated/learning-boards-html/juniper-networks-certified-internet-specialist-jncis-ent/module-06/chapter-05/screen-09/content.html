Module 06 › Chapter 6.5 › Network vs Redistribution
Network statement
Best for a small number of local prefixes you can ensure exist in inet.0. Exact-match only, simple to reason about.
Example
Advertise a static loopback or summary prefix using network.
Limitation
Requires the exact prefix to exist in the routing table first.
Redistribution with policies
Use when exporting sets of routes learned from other protocols. Policies allow matching, filtering, and attribute changes before export.
Example
Match protocol ospf then export selected prefixes to BGP via an export policy.
Risk
Overly broad policies can leak internal or unstable routes—use route-filter to limit scope.
Key Takeaway

Pick network for a few explicit prefixes; pick policy-based redistribution when you need flexible, filtered exports from other protocols.
