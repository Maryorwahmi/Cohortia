Module 06 › Chapter 6.5 › Learning Objectives

Practice Focus

Concrete, safe lab steps for each objective so you can validate behavior without risking production leakage.

Learn → Understand → Apply → Master
Network statement lab

Create a static route with next-hop discard, add the network statement, then use show route and show route advertising-protocol to confirm the prefix is advertised.

Redistribution lab

Write a policy that matches protocol ospf, test it with test policy, then apply as export to a BGP group to selectively redistribute OSPF routes.

Family testing

Toggle family inet unicast on a BGP group in the lab and observe whether IPv4 routes are exchanged; this confirms the family requirement.

Verification steps

Use show route advertising-protocol bgp and show route receive-protocol bgp to see exactly what is sent and received.
