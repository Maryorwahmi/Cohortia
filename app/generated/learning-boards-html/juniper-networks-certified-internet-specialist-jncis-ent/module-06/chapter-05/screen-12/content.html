Module 06 › Chapter 6.5 › Lab: Advertise and Redistribute
Lab steps (R1)
  1. set protocols bgp group EBGP_PEER family inet unicast
  2. set routing-options static route 172.16.1.0/24 next-hop discard
  3. set protocols bgp group EBGP_PEER network 172.16.1.0/24
  4. set interfaces lo0 unit 0 family inet address 10.10.10.1/32
  5. set protocols ospf area 0.0.0.0 interface lo0.0
  6. set policy-options policy-statement REDISTRIBUTE_OSPF_TO_BGP term 1 from protocol ospf
  7. set policy-options policy-statement REDISTRIBUTE_OSPF_TO_BGP term 1 then accept
  8. set protocols bgp group EBGP_PEER export REDISTRIBUTE_OSPF_TO_BGP
Verification
# On R1
run show route advertising-protocol bgp 10.0.0.2
# On R2
run show route receive-protocol bgp 10.0.0.1
run show route protocol bgp
Expected result

R2 should receive 172.16.1.0/24 and 10.10.10.1/32 if the static route exists and the export policy is applied.
