Module 06 › Chapter 6.5 › Ensure route existence
Process

Make the prefix present

  1. Add a static route with next-hop discard for summaries or non-connected networks.
  2. Or configure the interface with the specific address so the prefix is directly connected.
  3. Or create an aggregate summary route if appropriate for your routing design.
Troubleshooting tips
  • Check for more specific routes that override a static entry.
  • Verify the static route is active with show route.
  • Remember BGP will stop advertising if the route is removed from inet.0.
Example configuration
set routing-options static route 192.168.50.0/24 next-hop discard
set protocols bgp group EBGP_PEER family inet unicast
set protocols bgp group EBGP_PEER network 192.168.50.0/24
Verify
show route 192.168.50.0/24 then show route advertising-protocol bgp 10.0.0.2
Caution
If another route is preferred, the static discard may be inactive. Check route preference and protocols.
Key Takeaway

Create an explicit route in inet.0 before relying on a network statement to advertise it.
