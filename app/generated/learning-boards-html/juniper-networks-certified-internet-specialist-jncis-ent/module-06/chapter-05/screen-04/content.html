Module 06 › Chapter 6.5 › Network statement
Definition

Network statement

Instructs BGP to advertise a specific prefix only when that exact prefix exists in inet.0. It will not create routes.

Why it matters
  • Prevents advertising unreachable prefixes.
  • Clear operational intent: advertise only known prefixes.
  • Works well with a static discard route or connected summary.
Common misconception

Some expect network to add the route automatically; it does not. Always verify the route is in inet.0.

Configuration example
set routing-options static route 172.16.1.0/24 next-hop discard
set protocols bgp group EBGP_PEER family inet unicast
set protocols bgp group EBGP_PEER neighbor 10.0.0.2 peer-as 65002
set protocols bgp group EBGP_PEER network 172.16.1.0/24
Example
Add static discard so the network statement has a route to advertise.
Check
Use show route 172.16.1.0/24 and show route advertising-protocol bgp 10.0.0.2
Key Takeaway

Network statements require an exact-match route in the local routing table; configure reachability or a discard route first.
