Module 06 › Chapter 6.5 › family inet unicast
Definition

Address-family requirement

Enable family inet unicast under the BGP group to permit IPv4 unicast route exchange with that neighbor.

Operational note

This is a per-group setting on Junos. Forgetting to set it is a common reason why IPv4 routes are not advertised, even with correctly configured network statements and policies.

Misconception

Some expect BGP to enable families globally; on Junos it is explicit per group.

Example snippet
set protocols bgp group EBGP_PEER type external
set protocols bgp group EBGP_PEER neighbor 10.0.0.2 peer-as 65002
set protocols bgp group EBGP_PEER family inet unicast
Verification

After enabling family inet unicast, confirm routes with show route protocol bgp and show route advertising-protocol bgp <neighbor> to ensure IPv4 prefixes are exchanged.

Key Takeaway

Explicitly enable the address family for the type of routes you expect to exchange; family inet unicast is required for IPv4.
