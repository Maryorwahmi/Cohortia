Learning Objectives

Each objective links a config pattern to a verification step you can run in the lab.

Learn → Understand → Apply → Master
01
Use network statements

Configure network prefixes so BGP advertises exact-match prefixes that are present in inet.0. This prevents advertising unreachable prefixes.

VERIFIED COMPETENCY MILESTONE
02
Redistribute via policies

Create policy-statements to select OSPF, static, or direct routes you want to export to BGP, giving granular control over redistribution.

VERIFIED COMPETENCY MILESTONE
03
Enable family inet unicast

Always enable the IPv4 unicast family on the BGP group to allow exchange of IPv4 routes; otherwise advertisements won't happen.

VERIFIED COMPETENCY MILESTONE
04
Verify with show route commands

Use show route advertising-protocol and receive-protocol to confirm what you are sending and what you receive from a neighbor.

VERIFIED COMPETENCY MILESTONE
