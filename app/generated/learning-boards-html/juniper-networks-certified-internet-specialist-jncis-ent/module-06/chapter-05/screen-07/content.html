Architecture

Routing policies control redistribution

Policies let you filter and accept routes from OSPF, static, or direct protocols before exporting them into BGP. They provide safety and precision.

Rules of thumb
  • Match by protocol or route-filter to narrow candidates.
  • Test policies with test policy against sample prefixes.
  • Remember implicit deny at policy end — add explicit accept terms.
Example policy and application
set policy-options policy-statement REDISTRIBUTE_OSPF_TO_BGP term OSPF_ROUTES from protocol ospf
set policy-options policy-statement REDISTRIBUTE_OSPF_TO_BGP term OSPF_ROUTES then accept
set protocols bgp group EBGP_PEER export REDISTRIBUTE_OSPF_TO_BGP
Pro tip
Add route-filter or prefix-list clauses to limit which OSPF routes are exported.
Common mistake
Applying a broad policy that accepts all direct or OSPF routes can leak internal prefixes to the internet.
Key Takeaway

Always use routing policies to control redistribution; test them before applying as export to a BGP group.
