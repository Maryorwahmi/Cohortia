Module 3 › Chapter 3.3 › Lab Scenario
Topology
Switch-1 and Switch-2 form a Virtual Chassis. Switch-3 connects to the VC via an LACP LAG using two physical links to the VC (member 0 ports).
VC: member 0 = Switch-1 (priority 255), member 1 = Switch-2 (priority 128)
LAG: ae0 on VC uses ge-0/0/0 and ge-0/0/1; ae0 on Switch-3 uses its two ge ports; both configured lacp active and trunk VLAN 10
Step checklist
  1. Configure VCPs and form the VC, set master and backup.
  2. On VC Master, create ae0, set minimum-links 1 and lacp active.
  3. Assign physical ports to ae0 and set ae0 as trunk for VLAN 10.
  4. On Switch-3, create ae0, enable lacp active, assign ports, configure VLAN 10.
  5. Verify with show commands and test failover scenarios.
Reflect: After testing, document the expected Master and Backup and archive the verification outputs for your configuration baseline.
