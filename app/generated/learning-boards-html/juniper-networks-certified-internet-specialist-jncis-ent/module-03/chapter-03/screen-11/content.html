Module 3 › Chapter 3.3 › Form VC & VCPs
Example CLI steps
# Convert ports to VCPs if needed
# request virtual-chassis vc-port set pic-slot 1 port 0
# request virtual-chassis vc-port set pic-slot 1 port 1

# Assign members and roles with serial numbers
set virtual-chassis member 0 role master serial-number SERIAL_NUMBER_OF_SWITCH_1
set virtual-chassis member 1 role backup serial-number SERIAL_NUMBER_OF_SWITCH_2

# Set mastership priorities
set virtual-chassis member 0 mastership-priority 255
set virtual-chassis member 1 mastership-priority 128

commit and-quit
After committing and connecting VCPs, the chassis should form and you can confirm mapping and roles. If the VC fails to form, re-check cabling and serial-number entries.
Verification
Use show virtual-chassis and show virtual-chassis status to inspect member IDs, roles, and VCP link state. Validate the chosen Master and Backup are as intended.
Key Takeaway

Plan your VCP topology and member priorities before committing to ensure predictable VC behavior.
