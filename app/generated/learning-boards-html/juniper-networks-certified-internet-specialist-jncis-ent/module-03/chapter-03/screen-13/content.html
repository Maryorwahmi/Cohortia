Module 3 › Chapter 3.3 › Common Mistakes
LAG mistakes
  • Both ends passive — LACP never forms.
  • Mismatched VLANs — traffic is dropped or mislearned.
  • No minimum-links — ae goes down when links flap.
Fixes
Set lacp active, configure VLANs on ae unit, and set minimum-links to preserve logical availability.
VC mistakes
  • Incorrect VCP cabling — no redundancy or split topology.
  • No mastership-priority — unpredictable Master election.
  • Mixed incompatible models or JUNOS — failed formation.
Fixes
Plan VCP ring topologies, set priorities, and verify compatibility in a lab before production deployment.
