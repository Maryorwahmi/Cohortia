Module 3 › Chapter 3.3 › Bandwidth vs Redundancy
Aggregate Bandwidth (A)
Multiple active links carry many flows. Total capacity increases roughly proportional to the number of links, improving aggregate throughput for concurrent sessions.
Example: two 1 Gbps links provide up to 2 Gbps for multiple flows.
Misconception: a single TCP flow will not necessarily receive twice the bandwidth.
Key Takeaway

Use LAGs to scale aggregate throughput; verify hashing suits your traffic if you need per-flow scaling.

Link Redundancy (B)
If a physical link fails, LACP and the LAG remove that member and traffic continues on remaining active members when minimum-links allows it.
Example: one cable failure leaves ae0 up if minimum-links is 1, preventing downtime.
Common pitfall: mismatched VLANs or LACP modes can prevent failover or cause traffic loss.
Check: set consistent VLAN membership on ae members and confirm LACP state to ensure redundancy behaves as expected.
