Module 3 › Chapter 3.3 › Configure LAG (Junos)
Starter Junos commands
set interfaces ae0 aggregated-ether-options minimum-links 1
set interfaces ae0 aggregated-ether-options lacp active
set interfaces ae0 unit 0 family ethernet-switching port-mode trunk
set interfaces ae0 unit 0 family ethernet-switching vlan members DATA

set interfaces ge-0/0/0 ether-options 802.3ad ae0
set interfaces ge-0/0/1 ether-options 802.3ad ae0
After committing, use show interfaces ae0 and show lacp interfaces to confirm the bundle status and active members. If VLANs are carried, ensure the ae unit is configured as a trunk and VLAN membership matches the peer configuration.
Pro tip: set minimum-links to the lowest acceptable number to keep service running if member links fail.
Mistake to avoid: mismatching trunk VLANs on member ports which can cause traffic loss or learning issues.
Example scenario
You have two physical links from Switch-3 to the Virtual Chassis. Configure ae0 with LACP active on both sides and assign VLAN 10 as a trunk to carry data across the bundle.
Key Takeaway

Follow the create-enable-assign-verify pattern when building LAGs on Junos.
