Module 3 › Chapter 3.3 › LACP Negotiation
Negotiation steps
  1. Ports exchange LACP frames identifying system and port attributes.
  2. Matching attributes result in bundle membership; incompatible members are excluded.
  3. Active ports initiate negotiation; passive ports reply.
  4. LACP monitors link health and removes failed members automatically.
Troubleshooting tip
If the LAG does not form, check both sides for active/passive settings, speed/duplex mismatches, and VLAN tagging consistency.
Common misconfiguration
Both ends in passive mode will not initiate negotiation, leaving links unbundled. Ensure one or both sides are active to form the LACP bundle.
Check: set interfaces aeX aggregated-ether-options lacp active on at least one side.
Verify: show lacp interfaces and show interfaces aeX to confirm member state.
Reflect: When would you prefer static bundling instead of LACP? Consider link predictability versus automatic recovery.
