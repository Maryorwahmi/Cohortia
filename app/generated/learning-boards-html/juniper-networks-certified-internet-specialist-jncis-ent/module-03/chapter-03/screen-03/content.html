LAG configuration steps
  1. Create ae interface and set minimum-links.
  2. Enable LACP active (at least one side active).
  3. Assign physical interfaces to the ae bundle.
  4. Set ae unit for switching/trunk and assign VLAN members.

Virtual Chassis essentials
  • Convert ports to VCPs if dedicated ports are not present.
  • Assign member IDs and roles using serial numbers for deterministic mapping.
  • Set mastership-priority to control elections and avoid surprises.
