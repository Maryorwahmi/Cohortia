Module 3 › Chapter 3.3 › What is a LAG?
Definition
A LAG bundles multiple physical Ethernet links into a single logical link for bandwidth aggregation and redundancy.
How it helps
  • Aggregate capacity across links to increase throughput for many flows.
  • Provide link redundancy so service continues if a member fails.
  • Allow a single logical interface to carry VLANs and L2/L3 config.
Concrete example
Two 1 Gbps links form ae0. Multiple clients send traffic using different flows; the bundle supports up to 2 Gbps aggregate traffic. A single flow typically remains on one member due to hashing.
Common mistake
Expecting a single TCP session to automatically use the full aggregated bandwidth — most hashing schemes keep a single flow on one physical link.
Key Takeaway

Use LAGs to increase aggregate throughput and provide link redundancy, but design hashing expectations for your traffic.
