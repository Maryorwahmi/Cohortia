Module 3 › Chapter 3.4 › Key Concepts
Firewall Filter

An ordered stateless set of terms that match packet fields and perform actions. Processing stops at the first match.

Application Point

Apply filters to VLANs or interfaces and choose input or output direction carefully to control which packets are inspected.

Class of Service

Classify and map traffic to forwarding classes, then schedule queues so critical traffic gets priority during congestion.

Summary takeaway

Use filters for local access control, always test with count and verify counters, and combine CoS classifiers with forwarding classes to protect real-time services.
