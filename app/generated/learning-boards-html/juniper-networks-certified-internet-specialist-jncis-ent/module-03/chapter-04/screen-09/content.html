CoS Components
Classifier — identifies and marks traffic (802.1p or DSCP)
Forwarding Class — grouping for queues, e.g., expedited-forwarding, best-effort
Scheduler — allocates bandwidth and priority among forwarding classes
Rewrite Rules — modify CoS bits on egress to preserve marking
Why it matters

Without CoS, delay-sensitive traffic competes equally with bulky transfers and user experience degrades during congestion.

Concrete example
Define a classifier that maps VoIP DSCP values to expedited-forwarding. Configure scheduler to give that forwarding class priority and minimum bandwidth so calls remain clear even when other traffic peaks.
Example config snippet (conceptual)
set class-of-service classifiers ieee-802.1p default forwarding-class best-effort loss-priority low code-points [ 000 ]
set class-of-service classifiers ieee-802.1p default forwarding-class expedited-forwarding loss-priority low code-points [ 101 ]
set class-of-service classifiers ieee-802.1p default forwarding-class assured-forwarding loss-priority low code-points [ 010 011 100 ]
set class-of-service classifiers ieee-802.1p default forwarding-class network-control loss-priority low code-points [ 110 111 ]
