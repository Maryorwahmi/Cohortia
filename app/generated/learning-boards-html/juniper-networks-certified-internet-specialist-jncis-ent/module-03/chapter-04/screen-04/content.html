Module 3 › Chapter 3.4 › What is a Firewall Filter?
Core Concept
Stateless packet inspection and immediate actions

A firewall filter inspects packets against match conditions and executes an action on the first matching term.

Match Conditions: source-address, destination-address, protocol, source-port, destination-port, vlan
Actions: accept, discard, reject, count, policer
Stateless behavior: no tracking of connection state. Each packet evaluated independently.
Example
Block Telnet from a guest subnet by matching source-address and destination-port then discard. End with an explicit accept if you want other traffic allowed.
Key Takeaway

Use switch filters for local, low-latency controls. They are efficient but not stateful firewalls.

Annotated Term Example
set firewall family ethernet-switching filter BLOCK_TELNET_FROM_GUEST term BLOCK_TELNET from source-address 192.168.20.0/24
set firewall family ethernet-switching filter BLOCK_TELNET_FROM_GUEST term BLOCK_TELNET from destination-port telnet
set firewall family ethernet-switching filter BLOCK_TELNET_FROM_GUEST term BLOCK_TELNET then discard
set firewall family ethernet-switching filter BLOCK_TELNET_FROM_GUEST term ALLOW_ALL then accept
Misconception

Do not assume filters track sessions. Blocking a reply or related traffic will require explicit match terms if needed.

Create a single-term filter to drop a known service and then add an allow-all term. Verify counters with show firewall filter.
