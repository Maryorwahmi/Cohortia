Module 3 › Chapter 3.4 › Actions Comparison
accept — permit the packet to continue
discard — silently drop the packet
reject — drop and send unreachable notification
count — increment match counter for verification
policer — rate-limit traffic based on configured rate
Practical guidance
  • Start with count to verify you match the intended traffic.
  • Switch to discard when you’re ready to block silently.
  • Use reject sparingly when you want immediate feedback to senders.
  • Use policer when you need to limit rate, not to guarantee priority — that’s CoS’s job.
Example

During testing, count how many HTTP matches come from the USERS subnet. After validation, change that term to discard to block the service.

Misconception

Policers limit rate but do not provide guaranteed priority — use CoS queuing and schedulers for that.
