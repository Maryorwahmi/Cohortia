Module 3 › Chapter 3.4 › Apply Filters
Attachment and Direction

Choose a VLAN or an interface, then choose input or output direction. Input inspects arriving packets; output inspects leaving packets.

Apply to VLAN: set vlans USERS filter input BLOCK_HTTP_TO_SERVERS — affects all VLAN members.
Apply to interface: set interfaces ge-0/0/1 unit 0 family ethernet-switching filter input BLOCK_HTTP_TO_SERVERS — affects single port.
Input vs Output: Input stops packets before switching/routing decisions; output filters on egress may affect forwarded or return packets differently.
Example check

After applying an input filter to USERS, try ping to servers (should pass) and access HTTP (should fail). Use show firewall filter to inspect counters.

Directional Scenarios
Scenario: Block HTTP from USERS
Apply filter as input to USERS VLAN so packets from hosts are dropped before routed to SERVERS.
Mistake: Wrong direction
Applying as output on SERVERS may not prevent users from initiating the connection in the way you expect; think about ingress vs egress behaviors.
Plan the attachment point, predict which packets are inspected, then apply and verify. That habit prevents accidental outages from misapplied filters.
