Module 3 › Chapter 3.4 › Troubleshooting Filters
Common Errors
  • Using source-port instead of destination-port for server services
  • Applying filter to wrong VLAN or physical interface
  • Using wrong direction (input vs output)
  • Forgetting final accept and hitting implicit deny
Diagnostic command

Run show firewall filter FILTER_NAME to inspect per-term counters and confirm what matches. Use show firewall log when available for additional context.

Step-by-step fix
  1. Apply filter with then count and commit.
  2. Generate representative traffic.
  3. Inspect term counters and adjust match conditions.
  4. Change then count to then discard only when confident.
Case study

An admin who only added a deny-SSH term without a final accept saw full connectivity loss because of the implicit deny-all. The solution was to add ALLOW_ALL then accept and use count first for verification.
