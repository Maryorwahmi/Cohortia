Module 3 › Chapter 3.2 › Lab: Triangular topology walkthrough
Topology
Switch-A, Switch-B, Switch-C connected in a triangle. Switch-C has ge-0/0/2 to a PC.
Tasks
  1. Enable RSTP on all switches.
  2. Set Switch-A bridge-priority 4096 and Switch-B 8192.
  3. Apply loop-guard to inter-switch interfaces.
  4. Configure ge-0/0/2 on Switch-C as edge and enable BPDU Guard.
  5. Verify using show spanning-tree bridge and show spanning-tree interface.
Verification and tests
Confirm Switch-A is root, inspect port roles, test BPDU Guard by injecting a BPDU on ge-0/0/2, and simulate link down to observe fast reconvergence.
Starter CLI snippets
# Switch-A
set protocols rstp
set protocols rstp bridge-priority 4096
set protocols rstp interface ge-0/0/0 loop-guard
set protocols rstp interface ge-0/0/1 loop-guard
commit and-quit

# Switch-C edge port
set interfaces ge-0/0/2 unit 0 family ethernet-switching port-mode access edge
set protocols rstp interface ge-0/0/2 bpdu-guard
commit and-quit
