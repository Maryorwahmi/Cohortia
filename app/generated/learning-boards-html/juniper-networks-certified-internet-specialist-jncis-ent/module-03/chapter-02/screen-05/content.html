Module 3 › Chapter 3.2 › Root Bridge, Bridge ID, and path cost
Bridge ID and root election
Bridge ID = bridge priority + MAC address. Lower is better.
  • Configure bridge priority to control which switch becomes root.
  • If priorities match, the lowest MAC address wins the election.
  • Set a primary and secondary root by choosing distinct priorities for core devices.
Mnemonic
Think: 'Priority then MAC' — set low priority on your intended root to win predictably.
Path cost and Designated Port decision
Each switch computes cumulative cost to the root and uses it to pick the best ports.
Short example
If Switch A reaches the root via a single 1 G link (cost X) and Switch B reaches the root via two 100 M links (cost higher), Switch A will be the Designated Port for segments where both connect.
Key Takeaway

Control root election with priority values; understand path cost so you can design preferred forwarding paths to the root.
