Module 3 › Chapter 3.2 › RSTP port types
Edge Ports
Designed for end hosts; immediate forwarding to avoid client boot delays.
Best practice: mark user-facing access ports as edge and enable BPDU Guard to prevent accidental connections of switches to these ports.
Pro Tip
Only configure edge on ports that will never connect to another switch or trunk.
Alternate & Backup Ports
Provide ready backup paths; held in a discarding state until needed.
They allow RSTP to switch forwarding quickly without waiting for long timers.
Common mistake
Enabling edge on a trunk or inter-switch link can create an immediate loop; protect edge ports with BPDU Guard.
