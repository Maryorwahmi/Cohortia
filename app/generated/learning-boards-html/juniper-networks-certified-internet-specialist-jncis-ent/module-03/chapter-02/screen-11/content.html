Module 3 › Chapter 3.2 › Common mistakes and avoidance
Top mistakes
  • Not setting explicit bridge priorities — root chosen by MAC unpredictably.
  • Marking trunk or inter-switch links as edge, creating loops.
  • Skipping BPDU Guard or Loop Guard on critical ports.
Prevention
Standardize a config template for core/root, uplinks, and access ports so mistakes are less likely.
Troubleshooting checklist
  1. Check root with show spanning-tree bridge.
  2. Inspect roles and states with show spanning-tree interface.
  3. Look for root-inconsistent or loop-inconsistent ports for guard triggers.
  4. Reproduce issues in lab before making production changes.
