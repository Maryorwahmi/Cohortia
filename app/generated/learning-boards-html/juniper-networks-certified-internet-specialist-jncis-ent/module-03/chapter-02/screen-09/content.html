Module 3 › Chapter 3.2 › Protection mechanisms
BP
BPDU Guard
Shuts down an edge port on BPDU receipt to prevent rogue switches from joining STP.
LG
Loop Guard
Detects absence of BPDUs on non-edge ports and blocks a port to avoid loops due to unidirectional links.
RG
Root Guard
Prevents a port from becoming a Root Port if superior BPDUs arrive, enforcing a chosen root placement.
Implementation checklist
  • Enable BPDU Guard on user-facing edge ports.
  • Enable Loop Guard on all inter-switch uplinks.
  • Enable Root Guard where you must keep a specific root path.
  • Test each feature in a lab: plug a rogue switch, simulate unidirectional failures, and observe port state changes.
