Learning Objectives
Progress from conceptual understanding to configuration and verification skills on Juniper EX switches.
01
Explain loop risks and STP purpose
Describe how switching loops, broadcast storms, and MAC instability occur and why STP creates a single logical topology to prevent them.
VERIFIED COMPETENCY MILESTONE
02
Describe root election and port roles
Explain Bridge ID composition, path cost, and the meaning of Root Port, Designated Port, and Blocked ports in a tree.
VERIFIED COMPETENCY MILESTONE
03
Differentiate STP, RSTP, and MSTP
Contrast convergence behavior, port types, and when you would use RSTP or MSTP for faster recovery or VLAN distribution.
VERIFIED COMPETENCY MILESTONE
04
Configure and protect RSTP on Juniper EX
Enable RSTP, set bridge priority, mark edge ports, and apply BPDU Guard, Loop Guard, and Root Guard to protect topology integrity.
VERIFIED COMPETENCY MILESTONE
