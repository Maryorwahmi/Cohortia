Module 3 › Chapter 3.2 › STP vs RSTP vs MSTP
STP (802.1D)
Timer-based transitions, slow convergence, port states: Blocking → Listening → Learning → Forwarding.
Use when compatibility is required but expect long reconvergence times.
RSTP (802.1w)
Proposal/Agreement handshake, Edge/Alternate/Backup ports, rapid convergence without long timers.
Preferred for campus networks needing fast recovery.
MSTP (802.1s)
Multiple instances map VLANs to different spanning trees for load balancing across VLANs.
Use when many VLANs require distinct forwarding topologies.
Guidance
For JNCIS-ENT and typical campus designs, RSTP is the primary focus: it gives faster recovery and pragmatic port types to keep user sessions active. Use MSTP only when you need per-VLAN path control and efficient utilization across multiple VLANs.
