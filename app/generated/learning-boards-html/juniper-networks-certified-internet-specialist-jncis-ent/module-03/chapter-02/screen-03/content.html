Practical checks
  • Enable RSTP and confirm the operational mode.
  • Set bridge priority to make a designated root and verify with the show command.
  • Configure edge ports and BPDU Guard, then test that a rogue BPDU shuts the interface.
  • Apply Loop Guard on inter-switch links and simulate a unidirectional failure to see loop-inconsistent behavior.
