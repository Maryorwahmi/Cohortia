Module 3 › Chapter 3.2 › Configuring RSTP on Juniper EX
Starter configuration snippets
Use these lines in configuration mode and commit changes when ready.
# Enable RSTP
set protocols rstp

# Set bridge priority to make Switch-A Root
set protocols rstp bridge-priority 4096

# Apply Loop Guard to inter-switch links
set protocols rstp interface ge-0/0/0 loop-guard
set protocols rstp interface ge-0/0/1 loop-guard

# Configure an edge port and BPDU Guard
set interfaces ge-0/0/2 unit 0 family ethernet-switching port-mode access edge
set protocols rstp interface ge-0/0/2 bpdu-guard

commit and-quit
After commit, run show spanning-tree bridge and show spanning-tree interface to validate roles and the selected root.
Example verification
Expected checks include confirming Switch-A is Root Bridge and access ports configured as edge are forwarding until a BPDU is received when testing BPDU Guard.
Common mistake
Forgetting to apply loop-guard on inter-switch links leaves you vulnerable to unidirectional failures; apply loop-guard consistently on uplinks.
