Common Mistakes and Fixes

Quick mapping of symptoms to likely configuration errors and corrective steps.

Workflow: Reproduce → Inspect → Fix → Verify
Symptom
Clients unable to get DHCP leases.
Likely cause: DHCP server port untrusted.
Fix: Mark server interface trusted.
Symptom
Port disabled unexpectedly after second device connects.
Likely cause: mac-limit with action shutdown.
Fix: Re-enable port and consider action drop.
Symptom
ARP entries being dropped.
Likely cause: DAI without proper DHCP bindings or untrusted static hosts.
Fix: Verify binding table and mark static hosts as trusted.
Pro tip

When in doubt, roll back the most recent change and test sequentially to isolate the cause.
