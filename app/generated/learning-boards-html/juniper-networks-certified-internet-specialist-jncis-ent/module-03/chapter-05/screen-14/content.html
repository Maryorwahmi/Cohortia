Module 4 › Chapter 3.5 › Key Concepts
Port Security
Controls applied to switch ports to prevent unauthorized devices and attacks.
MAC Limiting
Restricts number of MAC addresses learned on a port to stop flooding attacks.
DHCP Snooping
Blocks unauthorized DHCP servers and builds a binding table of legitimate leases.
Dynamic ARP Inspection
Validates ARP against DHCP bindings to prevent ARP spoofing and poisoning.
802.1X Authentication
Port-based authentication using supplicant, switch authenticator, and a RADIUS server.
Trusted vs Untrusted
Mark server and upstream ports trusted; user ports should usually be untrusted for DHCP snooping and DAI.
Summary

Combine these controls, verify with show commands, pilot changes, and monitor to keep the access layer secure without disrupting users.
