Lab plan and verification

A concise checklist you will follow in the hands-on activity for VLAN 10.

Topology

ge-0/0/0 → PC-User (VLAN 10). ge-0/0/1 → Legitimate DHCP server (VLAN 10).

Tasks
  1. Define VLAN 10 and assign interfaces.
  2. Enable DHCP snooping and mark DHCP server port as trusted.
  3. Enable DAI and configure MAC limiting on the user port.
Verification

Use show commands to view secure-access-port and DHCP binding table; test device connectivity and MAC limiting by adding a second device.
