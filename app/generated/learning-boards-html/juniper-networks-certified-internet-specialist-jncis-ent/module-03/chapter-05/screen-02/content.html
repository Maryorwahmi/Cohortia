Learning Objectives

Targeted competencies and verified milestones for port security and 802.1X.

Bloom: Learn → Understand → Apply → Master
01
Explain why port security matters

Describe attack vectors like MAC table overflow, rogue DHCP, and ARP spoofing and how they harm the access layer.

VERIFIED COMPETENCY MILESTONE
02
Configure MAC limiting, DHCP snooping, DAI

Apply commands to limit MACs, enable DHCP snooping on a VLAN and mark trusted ports, and enable ARP inspection.

VERIFIED COMPETENCY MILESTONE
03
Describe the 802.1X flow

Name the supplicant, authenticator, and authentication server and explain EAPOL and RADIUS message exchange behavior.

VERIFIED COMPETENCY MILESTONE
04
Deploy and verify 802.1X safely

Link dot1x to an access profile, point to a RADIUS server, and test to avoid accidental lockouts using controlled lab testing.

VERIFIED COMPETENCY MILESTONE
