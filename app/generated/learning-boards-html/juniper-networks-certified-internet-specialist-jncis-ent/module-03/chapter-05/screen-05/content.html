Module 4 › Chapter 3.5 › MAC Limiting
Definition

MAC Limiting

Restrict the number of learned MAC addresses on a user-facing port to prevent overflow attacks.

set ethernet-switching-options secure-access-port interface ge-0/0/1 mac-limit 2 action drop
Practical example
On a workstation port, set mac-limit 1 action drop so only a single device is allowed. Test by adding a second device: the switch should drop the second device's traffic.
Misconfiguration risk
Applying strict limits to trunks or uplinks can disrupt many users; apply only to access ports.
Check Your Understanding
If a port is configured with mac-limit 1 action shutdown, what happens when a second MAC is seen? Answer: the port will disable itself and require administrative recovery or errdisable recovery depending on configuration.
Pro tip

Use action drop for user ports to avoid large outages; use action shutdown for stricter environments after confirming processes to recover the port.
