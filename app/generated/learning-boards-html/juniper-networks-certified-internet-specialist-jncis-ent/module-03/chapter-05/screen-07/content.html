Dynamic ARP Inspection

DAI validates ARP requests and replies against DHCP snooping bindings to prevent ARP poisoning.

1. DHCP client obtains address; switch records IP, MAC and VLAN in binding table.
2. A host sends an ARP packet; DAI checks mapping against the binding table.
3. If the mapping matches, the packet is forwarded; otherwise it is dropped.
Enable for VLAN
set ethernet-switching-options secure-access-port arp-inspection vlan USERS
Example

If an attacker replies to ARP queries claiming the gateway IP, DAI prevents that forged mapping from being learned if it conflicts with DHCP bindings.

Misconception

DAI alone does not create bindings; it requires DHCP snooping to populate the records used for validation.

Key Takeaway

Enable DHCP snooping and DAI together, and mark non-DHCP hosts or upstream devices as trusted to avoid false positives.
