Deployment Checklist

A stepwise plan to deploy port security with minimal disruption.

  1. Inventory user-facing ports and expected device counts.
  2. Set mac-limit for access ports (start conservative).
  3. Enable DHCP snooping per VLAN and mark server/uplinks trusted.
  1. Enable DAI for DHCP VLANs and configure trusted static hosts.
  2. Pilot 802.1X with fallback VLANs for legacy devices.
  3. Document configuration, add monitoring and rollback steps.
Why this matters

Planned rollouts and monitoring prevent accidental outages while delivering improved edge security through layered controls.
