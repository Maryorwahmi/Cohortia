Definition

802.1X Components and Flow

A port-based authentication framework that gates network access until identity is verified.

Supplicant: the client requesting access, such as a laptop or IP phone.
Authenticator: the Juniper EX switch that enforces access and forwards EAPOL as RADIUS.
Authentication Server: a RADIUS server that validates credentials and returns accept or reject.
Behavioral example
When a laptop connects, the switch allows only EAPOL. If the RADIUS server accepts the credentials, the switch opens the port for normal traffic; if rejected, access remains blocked.
Misconception
802.1X is not a replacement for DHCP snooping or DAI. It controls who can authenticate, while other features validate DHCP and ARP behavior.
Check your understanding

Why must the switch allow EAPOL before authentication? Because EAPOL is needed for identity exchange between supplicant and server via the authenticator.
