Advanced Port Security and 802.1X

A practical, command-driven walkthrough of MAC limiting, DHCP snooping, DAI, and port-based authentication for secure access control.

Duration: 15 minutes
In this lesson
Understand threats and configure port protections.
Coming up
Hands-on VLAN 10 lab and verification commands.
Why it matters
Reduce lateral attack surface and prevent credential interception.
Explore Key Topics
MAC Limiting
Limit learned MACs per port to stop flooding and avoid MAC table overflows.
DHCP Snooping & DAI
Classify trusted ports and validate ARP using DHCP bindings to block spoofing.
802.1X
Port-based authentication with supplicant, authenticator, and RADIUS enforcement.
Visual Overview
Concept cards show how features layer to protect access ports.
Threat
Rogue DHCP servers or ARP spoofers can redirect traffic or intercept credentials.
Result
Combined controls enforce who can join the network and what traffic is trusted.
Commands you'll use
set ethernet-switching-options secure-access-port interface <iface> mac-limit 1 action drop
set ethernet-switching-options secure-access-port dhcp-snooping vlan USERS
set ethernet-switching-options secure-access-port arp-inspection vlan USERS
set protocols dot1x authenticator interface ge-0/0/5
