Definition

DHCP Snooping and the Binding Table

Classify ports and inspect DHCP messages to block rogue servers and populate a binding table for legitimacy checks.

Enable for a VLAN
set ethernet-switching-options secure-access-port dhcp-snooping vlan USERS
set ethernet-switching-options secure-access-port interface ge-0/0/1 dhcp-snooping trusted
Example scenario
If the DHCP server port is untrusted, DHCPOFFER and DHCPACK messages are dropped and clients cannot obtain addresses. Mark the server-facing interface trusted to restore service.
Verification
Use the show commands to view the DHCP snooping binding table and confirm client IP-to-MAC mappings and lease times.
Common Mistake
Forgetting to mark the DHCP server port as trusted blocks legitimate DHCP responses and prevents clients from obtaining IP addresses.
Key Takeaway

Enable DHCP snooping per VLAN and explicitly mark server-facing interfaces as trusted to avoid service outages.
