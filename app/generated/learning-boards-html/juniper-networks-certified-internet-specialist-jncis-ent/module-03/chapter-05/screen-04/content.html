Core Concept

Access Layer Risks and Port Security

Understand the attack surfaces at the access layer and how targeted features reduce risk.

  • MAC table overflow can force a switch to flood traffic and expose data.
  • Rogue DHCP servers can hand out incorrect addresses and gateways.
  • ARP spoofing misdirects traffic by forging IP-to-MAC mappings.
Key Takeaway

Treat port security as layered controls; no single feature is a full solution.

Analogy

Gate and fence metaphor

Imagine each port as a yard behind a fence. MAC limiting limits occupants, DHCP snooping checks who may hand out access cards, and DAI verifies identity cards against a registry.

When this matters
High-density user spaces, guest networks, and any environment with many desktop or IoT devices.
Common misconception
Enabling one control, like MAC limiting, does not prevent rogue DHCP servers or ARP spoofing.
