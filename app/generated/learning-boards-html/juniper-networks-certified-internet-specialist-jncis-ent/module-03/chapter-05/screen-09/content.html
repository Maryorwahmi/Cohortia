Basic 802.1X Junos Commands

Create an access profile, point it to RADIUS, then enable dot1x and bind interfaces.

set access profile default authentication-order radius
set access profile default radius authentication-server 192.168.100.1
set access profile default radius secret "SHARED_SECRET_KEY"

set protocols dot1x authenticator authentication-profile default
set protocols dot1x authenticator interface ge-0/0/5
Real-world checklist
Verify RADIUS reachability, confirm secrets match, test a single port, and have a recovery plan for legacy devices.
Troubleshooting
Authentication failures usually indicate RADIUS IP/secret mismatch or blocked ports; correlate switch logs with server logs and run authentication tests in a lab.
Pro tip

Start with a test port and a test account on the server. Avoid enabling dot1x on many ports until tests are successful.
