Module 3 › Chapter 3.1 › Learning Objectives — Verification
Checks
  • show vlans — confirms VLAN names, IDs, and l3-interface bindings.
  • show interfaces terse — checks whether an interface is configured for ethernet-switching.
  • show route — ensures IRB interfaces appear as local routes for VLAN subnets.
Troubleshooting clues
  • DHCP failures on access ports often mean the VLAN name exists on the interface but the vlan-id was not created globally.
  • Intermittent cross‑VLAN traffic may indicate a native VLAN mismatch on a trunk link.
  • Missing IRB routing means devices in separate VLANs cannot reach each other until gateways are configured.
Quick command examples
show vlans
show interfaces ge-0/0/2 terse
show route protocol direct
