Module 3 › Chapter 3.1 › Key Concepts
VLAN
Logical broadcast domain identified by vlan-id and name.
802.1Q
Tagging method that carries VLAN IDs across trunk links.
IRB
Per‑VLAN logical interface that provides the gateway for inter‑VLAN routing.
Summary

Define VLANs, protect trunks with a deliberate native VLAN, and use IRB interfaces to route between VLANs when needed.
