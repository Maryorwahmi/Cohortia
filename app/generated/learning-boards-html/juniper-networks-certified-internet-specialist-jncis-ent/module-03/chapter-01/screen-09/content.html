Module 3 › Chapter 3.1 › Inter‑VLAN Routing with IRB
IRB configuration example
# Create IRB interfaces with IPs
set interfaces irb unit 10 family inet address 192.168.10.1/24
set interfaces irb unit 20 family inet address 192.168.20.1/24

# Associate VLANs with IRB
set vlans ADMIN vlan-id 10 l3-interface irb.10
set vlans GUEST vlan-id 20 l3-interface irb.20

commit and-quit
Each IRB becomes the default gateway for its VLAN. Devices must be configured with the correct gateway IP. If routing between VLANs should be restricted, apply firewall filters or routing policies instead of relying on default behavior.
Key Takeaway

Bind irb units to VLANs to provide per‑VLAN gateways; verify with show route and show interfaces to confirm reachability.
