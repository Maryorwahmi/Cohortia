Module 3 › Chapter 3.1 › Verification & Tests
1. Confirm VLANs
show vlans should list ADMIN:10 and GUEST:20 and any l3-interface like irb.10.
2. Check interfaces
show interfaces terse confirms access vs trunk and reveals native-vlan-id on trunks.
3. Verify routing
show route should include directly connected networks for IRB addresses.
Practical tests
  • Ping gateway from a host: expect reply from irb.X.
  • Ping across VLANs: expect routing via IRB.
  • Ping across switches in same VLAN: expect trunk to carry tagged frames successfully.
