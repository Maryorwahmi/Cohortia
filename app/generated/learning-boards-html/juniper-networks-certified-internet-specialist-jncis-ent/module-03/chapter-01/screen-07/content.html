Module 3 › Chapter 3.1 › Configure VLANs on Juniper EX
Step-by-step commands
# Create VLANs
set vlans ADMIN vlan-id 10
set vlans GUEST vlan-id 20

# Assign access port for ADMIN
set interfaces ge-0/0/0 unit 0 family ethernet-switching vlan members ADMIN

# Assign access port for GUEST
set interfaces ge-0/0/1 unit 0 family ethernet-switching vlan members GUEST

commit and-quit
After committing, verify with show vlans and show interfaces terse to confirm vlan-ids and port modes are active.
Validation checklist
  • Does show vlans list the new VLAN name and vlan-id?
  • Is the interface in ethernet-switching family per show interfaces?
  • Do hosts in the VLAN receive expected DHCP leases and can they ARP the gateway?
Key Takeaway

Define VLANs first, then assign ports; confirm with show commands to avoid orphaned interface assignments.
