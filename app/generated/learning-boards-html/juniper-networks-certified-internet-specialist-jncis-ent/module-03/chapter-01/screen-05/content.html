Module 3 › Chapter 3.1 › 802.1Q Tagging
The 4-byte tag and VLAN ID range

802.1Q adds a 4-byte field into the Ethernet header. That field contains a 12-bit VLAN ID. Numerically, this gives 0–4095 values; two are reserved and not used for normal VLANs.

Practical ID planning
  • Pick contiguous ranges per function (e.g., 10–19 Admin, 20–29 Guest).
  • Avoid using VLAN 1 for native traffic on trunks.
  • Document name↔ID mappings in your runbook.
Access vs trunk behavior
Access ports carry untagged frames for a single VLAN; trunks carry tagged frames for multiple VLANs. Untagged traffic on a trunk is mapped to the native VLAN.
Misconception
Some assume 4096 usable VLANs; remember the reserved IDs and platform-specific restrictions that may reduce usable space.
Key Takeaway

Tagging identifies VLANs across trunks; pick clear IDs, avoid default native VLANs, and keep the plan consistent across switches.
