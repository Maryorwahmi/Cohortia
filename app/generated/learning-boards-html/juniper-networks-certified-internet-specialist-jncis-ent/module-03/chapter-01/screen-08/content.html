Module 3 › Chapter 3.1 › Configure Trunk Ports
Trunk configuration example
# Set port to trunk
set interfaces ge-0/0/2 unit 0 family ethernet-switching port-mode trunk

# Allow specific VLANs across the trunk
set interfaces ge-0/0/2 unit 0 family ethernet-switching vlan members [ADMIN GUEST]

# Set a secure native VLAN
set interfaces ge-0/0/2 unit 0 family ethernet-switching native-vlan-id 999

commit and-quit
Check that both ends of the trunk have identical allowed VLANs and the same native VLAN to avoid misrouting untagged frames.
Why change native VLAN?
Default native VLANs can be exploited in VLAN hopping attacks. Using an unused native VLAN and keeping it consistent across trunks reduces this risk and prevents accidental untagged traffic mapping to a sensitive production VLAN.
Misconfiguration symptom
If two switches have mismatched native VLANs, untagged traffic may be assigned to different VLANs at each end, producing odd connectivity and security gaps.
