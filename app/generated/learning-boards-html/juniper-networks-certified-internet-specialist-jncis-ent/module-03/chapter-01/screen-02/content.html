Learning Objectives

Understand, configure, verify, and troubleshoot VLANs, trunking, and inter‑VLAN routing on Juniper EX switches.

01
Explain VLAN purpose

Describe logical segmentation to reduce broadcasts and isolate traffic. Example: separating HR and Guest networks on the same switch improves security and privacy.

VERIFIED COMPETENCY MILESTONE
02
Configure VLANs on Juniper

Use set vlans NAME vlan-id ID and assign interfaces. Verify with show vlans to confirm ID and membership.

VERIFIED COMPETENCY MILESTONE
03
Implement 802.1Q trunking

Set port-mode trunk, allow VLAN lists, and set a non-default native VLAN to harden trunks against VLAN hopping.

VERIFIED COMPETENCY MILESTONE
04
Configure IRB for routing

Create irb units with IPs and associate them with VLANs so the switch routes between VLANs when required.

VERIFIED COMPETENCY MILESTONE
