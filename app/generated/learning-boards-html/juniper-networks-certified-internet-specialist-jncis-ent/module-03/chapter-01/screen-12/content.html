Module 3 › Chapter 3.1 › Common Mistakes
Missing VLAN definition
Symptom: host cannot obtain DHCP or reach VLAN peers. Fix: ensure set vlans NAME vlan-id ID exists and commit.
Incorrect port mode
Symptom: VLAN traffic truncated at an uplink. Fix: set port-mode trunk for uplinks carrying multiple VLANs.
Native VLAN mismatch
Symptom: untagged frames appear in the wrong VLAN on the remote switch. Fix: set native-vlan-id identically on both trunk ends.
Quick verification commands
show vlans | show interfaces interface-name | show route
