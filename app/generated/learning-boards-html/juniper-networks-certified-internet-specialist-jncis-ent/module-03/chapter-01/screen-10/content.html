Deployment steps
1. Define VLANs
Create ADMIN (10), GUEST (20), and NATIVE_VLAN (999) on both switches.
2. Configure access ports
Assign ge-0/0/0 on Switch-1 to ADMIN; ge-0/0/1 to GUEST; ge-0/0/1 on Switch-2 to GUEST.
3. Configure trunk
Set ge-0/0/2 on Switch-1 and ge-0/0/0 on Switch-2 to trunk, allow ADMIN and GUEST, set native-vlan-id 999.
4. IRB and routing
On Switch-1 create irb.10 192.168.10.1/24 and irb.20 192.168.20.1/24 and bind to VLANs.
5. Verify
Use show vlans, show interfaces terse, and ping between PCs. Check that inter‑VLAN pings traverse IRB and intra‑VLAN traffic traverses the trunk.
Topology snapshot
Switch-1: ge-0/0/0 ADMIN, ge-0/0/1 GUEST, ge-0/0/2 trunk → Switch-2 ge-0/0/0 trunk, ge-0/0/1 GUEST.
Key Takeaway

Execute configuration in order and verify each step to locate mistakes quickly and avoid service disruption.
