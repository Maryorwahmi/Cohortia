Module 04 › Chapter 4.4 › area-range on ABR
Steps to configure
  1. Identify contiguous subnets inside an area suitable for summarization.
  2. On the ABR, under protocols ospf, set area area-range .
  3. Commit and verify with show route and LSA inspection.
Example
edit protocols ospf
set area 1.0.0.0 area-range 172.16.0.0/22
commit
Verification
Run show route protocol ospf on a router outside the summarized area. You should see the summary 172.16.0.0/22 advertised as a Type 3 route rather than the individual /24s.
Tip
If specifics disappear, the ABR withdraws the summary automatically. Use show route to confirm withdraw behavior when testing.
Pitfall
Do not summarize across unrelated addressing blocks; plan contiguous blocks per area.
Key Takeaway

area-range on ABRs is the operational control for inter-area summarization; verify with routing-table checks.
