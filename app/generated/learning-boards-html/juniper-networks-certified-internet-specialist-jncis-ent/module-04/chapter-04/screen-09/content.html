Module 04 › Chapter 4.4 › Virtual link CLI
R1 configuration
edit protocols ospf
set area 5.0.0.0 virtual-link neighbor-id 2.2.2.2
commit
R1 uses the Router ID of R2 as the neighbor-id. Ensure R1 has an interface in area 5.0.0.0.
R2 configuration
edit protocols ospf
set area 5.0.0.0 virtual-link neighbor-id 1.1.1.1
commit
After commit, verify with show ospf virtual-link and show ospf neighbor to confirm Full state.
Verification
show ospf neighbor
show ospf virtual-link
Troubleshoot
Confirm Router ID reachability inside the transit area and matching authentication if present.
