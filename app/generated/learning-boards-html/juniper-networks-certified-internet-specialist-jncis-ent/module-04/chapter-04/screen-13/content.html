Question 1
Which summary covers 10.0.1.0/24, 10.0.2.0/24, 10.0.3.0/24? What Junos command is used?
Answer
10.0.0.0/22 is the most optimal. Junos command on the ABR: set protocols ospf area 5.0.0.0 area-range 10.0.0.0/22
Question 2
Which routers form a virtual link and what parameters must align?
Answer
Two ABRs connected to the transit area. Parameters: same transit Area ID, neighbor Router IDs correctly set on each side, consistent authentication if used, and Router ID reachability via the transit area.

Answer with both the correct configuration and the reasoning verifying prerequisites for success.
