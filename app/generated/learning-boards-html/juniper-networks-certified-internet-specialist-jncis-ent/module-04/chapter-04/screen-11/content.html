Module 04 › Chapter 4.4 › Lab: R1-R4
Topology summary
  • R1: Area 0, Router ID 1.1.1.1
  • R2: ABR (Area 0 & Area 1), Router ID 2.2.2.2
  • R3: ABR (Area 1 & Area 2), Router ID 3.3.3.3
  • R4: Area 2, provides 192.168.10.0/24 and 192.168.11.0/24
Tasks
  1. Configure area memberships and Router IDs.
  2. Create virtual link between R2 and R3 through Area 1.
  3. On R3 summarize Area 2 networks into a /23.
  4. Verify routes on R1 and R2 show the summary.
Starter configurations
Virtual link and summarization snippets:
# R2: Virtual link
edit protocols ospf
set area 1.0.0.0 virtual-link neighbor-id 3.3.3.3
commit

# R3: Virtual link and summary
edit protocols ospf
set area 1.0.0.0 virtual-link neighbor-id 2.2.2.2
set area 2.0.0.0 area-range 192.168.10.0/23 # summarizes two /24s
commit
After commit, verify: show ospf virtual-link, show route protocol ospf on R1/R2.
Key Takeaway

Follow the sequence: OSPF areas → virtual link → summarization → verification to observe the end-to-end effect.

Verification commands
show ospf neighbor, show ospf virtual-link, show route protocol ospf
