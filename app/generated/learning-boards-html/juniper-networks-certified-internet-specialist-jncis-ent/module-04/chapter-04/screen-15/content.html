Virtual Link Setup
Use neighbor-id of the other ABR and the transit area ID in the set command.
Prerequisites
Transit area must be standard; Router IDs reachable; authentication consistent.
Verification
show ospf virtual-link, show ospf neighbor, show route protocol ospf
Final takeaway
Use virtual links sparingly and always verify behavior with routing and OSPF state commands.
