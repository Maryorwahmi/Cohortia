Module 04 › Chapter 4.4 › ABR summary lifecycle
Step-by-step
1. Monitor specifics
ABR tracks specific routes that fall into the configured area-range.
2. Advertise summary
If any specific exists, ABR generates a Type 3 LSA for the summary.
3. Withdraw when empty
If no specifics remain, the ABR withdraws the summary automatically.
Example scenario
Area 1 has 172.16.1.0/24, .2.0/24, .3.0/24. ABR has area-range 172.16.0.0/22. Remove 172.16.2.0/24 and you still see the /22; remove all three and the /22 is withdrawn.
Verification commands
show route protocol ospf
show ospf database | match 172.16.0.0
Misconception
A summary persists regardless of specifics — false. It reflects current specifics.
Key Takeaway

Summaries are dynamic. Use verification after changes to confirm advertised state.
