Module 04 › Chapter 4.4 › Inter-area vs External
Inter-area summarization (ABR)
Aggregates internal area routes and advertises them into other areas as Type 3 LSAs. Configured on ABRs using area-range.
When to use
  • Multi-area designs with contiguous addressing
  • To protect backbone routers from internal detail
Risk
Poor address planning leads to black holes when specifics are not reachable.
External summarization (ASBR)
Aggregates routes learned from outside OSPF before injecting them as Type 5 LSAs (or Type 7 in NSSA). Done at the ASBR.
When to use
  • Importing many BGP prefixes into OSPF
  • Limit external LSA count inside OSPF domain
Operational check
Verify with LSA type inspection and show route protocol ospf to see whether summaries or specifics are present.
Key Takeaway

Summarize at the route source: ABR for intra-OSPF area content, ASBR for external imports.

Check
Which router created the summary? Inspect LSA types to confirm ABR vs ASBR origin.
