Module 4 › Chapter 4.1 › Verification Commands
Commands
Key Junos show commands
show interfaces terse
show ospf neighbor
show ospf database
show route protocol ospf
Use these commands in sequence to validate physical and protocol state, LSDB contents, and OSPF routes in the RIB.
Interpretation tips
If neighbors are stuck in Init, check Hellos and multicast reachability. If Exchange fails, look for DBD mismatches. If Full but no routes, inspect LSAs and filters.
Example flow: run show ospf neighbor to confirm Full. If not Full, compare hello/dead timers and network types. Use show ospf database to verify LSAs and find missing sequence numbers.
Key takeaway
Verification is a narrow process: interfaces → neighbor states → LSDB → routing table. Each step narrows possible root causes.
