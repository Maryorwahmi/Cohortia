Module 4 › Chapter 4.1 › Link-State vs Distance-Vector
Comparison
Link-State (OSPF)
  • Builds a full topology via LSAs and an identical LSDB per area.
  • Runs Dijkstra's SPF locally to compute shortest paths.
  • Floods only when topology changes, enabling fast convergence.
  • Requires Router ID stability and area design for scalability.
Example
When a link goes down, the originating router floods an LSA and all routers recompute routes quickly using SPF.
Comparison
Distance-Vector (RIP)
  • Sends route metrics to neighbors at intervals rather than flooding topology.
  • Can be slower to converge; may need loop-prevention timers and mechanisms.
  • Simpler configuration but less scalable for large topologies.
Misconception
Complexity doesn't mean unnecessary: link-state requires care, but it yields faster, more predictable recovery in larger networks.
Key takeaway
Use link-state where fast convergence and scalability matter; design areas to control LSDB size.
Try this
In a lab, force an interface down and watch LSAs flood and SPF recompute on all routers in the area.
