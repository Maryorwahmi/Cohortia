Code walkthrough
Minimal Junos OSPF steps
Follow this pattern: configure physical interfaces, create a loopback for Router ID, enable protocols ospf, assign interfaces to Area 0, and commit.
R1 configuration snippet
# R1 Configuration
edit interfaces
set ge-0/0/0 unit 0 family inet address 192.168.10.1/30
set lo0 unit 0 family inet address 1.1.1.1/32
top
edit protocols ospf
set router-id 1.1.1.1
set area 0.0.0.0 interface ge-0/0/0.0
commit and-quit
Common pitfalls
  • Forgetting to assign the interface to the OSPF area prevents Hellos from being sent on that interface.
  • Typo in interface name or area ID results in no adjacency on the expected link.
Verification
After commit run show ospf neighbor and show ospf database. Use show route protocol ospf to view learned routes.
Key takeaway
A small configuration set controls OSPF behavior; the most common errors are omissions or parameter mismatches between neighbors.
