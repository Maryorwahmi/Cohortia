Router ID: stable identity for OSPF
Use a loopback-based Router ID to ensure consistent LSA origination and clearer troubleshooting after interface changes.
Selection precedence
  • Explicit router-id configured in OSPF
  • Highest IP address on a loopback interface
  • Highest IP address on an active physical interface
Practical configuration
set interfaces lo0 unit 0 family inet address 1.1.1.1/32
edit protocols ospf
set router-id 1.1.1.1
Misconception
Don't rely on a physical interface IP for router-id if the interface may go down. That causes RID changes and confusing LSA ownership.
Try this
Configure a loopback and set router-id then bring a physical interface down. Observe that the router-id remains stable while interfaces change.
Key takeaway
Explicit router-id from a loopback reduces ambiguity and aids LSA tracing and debugging.
