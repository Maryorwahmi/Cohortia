Three quick reminders
Use these during configuration and troubleshooting for fast action.
OSPF packet types
Hello, DBD, LSR, LSU, LSAck — map these to neighbor state progression when debugging.
Adjacency states
Down → Init → Two-Way → ExStart → Exchange → Loading → Full. Each state indicates specific exchange progress.
Troubleshooting checklist
Compare timers, network type, area ID, masks, authentication, and ACLs blocking OSPF traffic.
Final takeaway
Use packet and state knowledge together with the troubleshooting checklist to rapidly diagnose and fix adjacency problems.
