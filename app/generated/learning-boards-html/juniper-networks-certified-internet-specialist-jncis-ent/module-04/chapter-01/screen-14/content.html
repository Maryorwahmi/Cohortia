R1 Template
# R1 Configuration
edit interfaces
set ge-0/0/0 unit 0 family inet address 192.168.10.1/30
set lo0 unit 0 family inet address 1.1.1.1/32
top
edit protocols ospf
set router-id 1.1.1.1
set area 0.0.0.0 interface ge-0/0/0.0
commit and-quit
After commit run show ospf neighbor and expect R2's RID with state Full. If not Full, work through the troubleshooting checklist.
R2 Template
# R2 Configuration
edit interfaces
set ge-0/0/0 unit 0 family inet address 192.168.10.2/30
set lo0 unit 0 family inet address 2.2.2.2/32
top
edit protocols ospf
set router-id 2.2.2.2
set area 0.0.0.0 interface ge-0/0/0.0
commit and-quit
Verification steps: show ospf neighbor, show ospf database, show route protocol ospf, then ping 2.2.2.2 source 1.1.1.1 from R1 to validate end-to-end reachability.
Lab troubleshooting hint
If ping fails while adjacency is Full, check show ospf database for missing LSAs, inspect route filters, and confirm the OSPF routes are installed in the routing table using show route protocol ospf.
