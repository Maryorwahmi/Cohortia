Definition

Network Type Definitions

Each network type governs neighbor discovery, adjacency formation, and LSA flooding. Selecting the correct type ensures routers agree on how to form adjacencies.

Broadcast
Multi-access LANs that support multicast; elect DR and BDR to reduce adjacency count and originate Type-2 LSAs for the segment.
Point-to-Point
Exactly two routers on the link. No DR/BDR election; neighbors form full adjacencies directly and exchange LSAs unicast.
NBMA
Multi-access without native multicast. Requires manual neighbor statements for discovery. DR/BDR election still applies.
Key Takeaway

Network type must match on both ends; mismatches prevent OSPF adjacency even when IP is reachable.

Concrete example
Imagine three routers on a switch-based LAN. If all are broadcast, they elect DR and BDR and only form full adjacencies with those two devices. That reduces adjacencies from three full mesh links to two full adjacencies per router. But if one router is configured as point-to-point, it will not agree with the others and an adjacency will not form.
Common mistake
Setting only one end of a link to point-to-point while the other remains broadcast. Even with valid IP routes, OSPF neighbors will not form due to network-type mismatch.
Pro tip: Always verify both sides with the show ospf interface detail command after configuration.
