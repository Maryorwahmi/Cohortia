Interface-type examples

Broadcast (often default)
edit protocols ospf
set area 0.0.0.0 interface ge-0/0/0.0 interface-type broadcast
commit
Point-to-Point
edit protocols ospf
set area 0.0.0.0 interface ge-0/0/1.0 interface-type p2p
commit
NBMA with neighbor
edit protocols ospf
set area 0.0.0.0 interface ge-0/0/2.0 interface-type nbma
set area 0.0.0.0 interface ge-0/0/2.0 neighbor 192.168.20.2
commit
After committing, run the interface detail command to verify the configured type, priority, and DR/BDR state.
Checklist
  • Confirm both ends have the same network-type.
  • For NBMA, add every neighbor IP under the interface stanza.
  • Plan change windows to avoid extended route flaps.
Key Takeaway

Explicitly set interface-type when the physical or logical behavior differs from Junos defaults and verify immediately after commit.
