Code Walkthrough

Priority change example

# R1 Priority Change
edit protocols ospf
set area 0.0.0.0 interface ge-0/0/0.0 priority 200
commit and-quit
Increase priority to prefer R1 as DR. Apply similar commands on other routers for their desired priorities.
Force re-election
To force the new election, clear OSPF neighbors on all routers or restart the OSPF process on the current DR/BDR.
# Verification and clear
show ospf interface detail
clear ospf neighbor all
Operational guidance
  • Plan maintenance when clearing neighbors to force elections.
  • Set priority 0 for devices that must not be DR/BDR.
  • Document priority values and Router IDs for predictable elections.
Key Takeaway

Priority controls election outcome but is non-preemptive; plan a controlled re-election if you change priorities.
