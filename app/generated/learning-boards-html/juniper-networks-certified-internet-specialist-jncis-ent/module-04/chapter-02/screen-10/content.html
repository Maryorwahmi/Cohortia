Lab Walkthrough

R1, R2, R3 Broadcast Segment

Initial R1 config
# R1 Initial Configuration
edit interfaces
set ge-0/0/0 unit 0 family inet address 192.168.1.1/24
set lo0 unit 0 family inet address 1.1.1.1/32
top
edit protocols ospf
set router-id 1.1.1.1
set area 0.0.0.0 interface ge-0/0/0.0
commit and-quit
Priority changes
# R1 Priority Change
edit protocols ospf
set area 0.0.0.0 interface ge-0/0/0.0 priority 200
commit and-quit
Set R2 to 150 and R3 to 0 following the same pattern. Then clear neighbors to force election.
Verification
show ospf interface detail
clear ospf neighbor all
Use these commands to confirm DR and BDR after the controlled re-election.
Topology
R1: 192.168.1.1, lo0:1.1.1.1; R2:192.168.1.2 lo0:2.2.2.2; R3:192.168.1.3 lo0:3.3.3.3. All in Area 0.
