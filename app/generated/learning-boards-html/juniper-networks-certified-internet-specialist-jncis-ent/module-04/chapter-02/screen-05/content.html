Module 4 › Chapter 4.2 › DR / BDR Election
Process Flow

How DR and BDR are chosen

Step 1: Compare priorities
The router with the highest interface priority is preferred for DR. A priority of 0 is excluded from election.
Step 2: Tie-break with Router ID
If priorities are equal, the router with the highest Router ID becomes DR.
Step 3: Non-preemptive behavior
Once DR/BDR are elected they remain until failure or manual reset; a later higher-priority router will not preempt.
Concrete scenario
If three routers join a LAN, the first two to participate trigger an election. Even if a fourth router with a higher priority joins later, it will not replace the current DR unless the election is forced.
Common mistake
Assuming a later higher-priority router will automatically become DR. It will not without an explicit election reset.
Operational tips
  • Set priority 0 on devices that must never be DR/BDR.
  • Use prioritized hosts for control plane centralization when required.
  • Plan maintenance when changing priorities to avoid transient route loss.
Key Takeaway

DR/BDR reduce adjacency growth. Use interface priority and Router ID intentionally; elections are non-preemptive.
