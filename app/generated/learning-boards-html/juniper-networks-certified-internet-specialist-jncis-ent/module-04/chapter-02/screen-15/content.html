Module 4 › Chapter 4.2 › Key Concepts
Designated Router (DR)
Elected by priority then Router ID to centralize LSA exchange on multi-access segments.
NBMA Networks
Require manual neighbor configuration because multicast/broadcast is not available; DR/BDR still used.
OSPF Priority
Range 0–255; higher wins election; 0 prevents DR/BDR candidacy but still allows route exchange.
Final takeaway
Configure network types to match link behavior, control election with priority, and verify with interface detail commands to ensure stable OSPF adjacencies.
