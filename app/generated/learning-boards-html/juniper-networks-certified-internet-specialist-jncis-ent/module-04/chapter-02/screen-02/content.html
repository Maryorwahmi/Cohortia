Learning Objectives

Build the skills you need to design, configure, and troubleshoot OSPF adjacencies on Junos OS.

01
Identify OSPF network types

Recognize Broadcast, Point-to-Point, and NBMA links and explain neighbor discovery differences. This matters so you pick the correct interface type during design.

Mnemonic: LAN = Broadcast, Serial = P2P, FrameRelay = NBMA
VERIFIED COMPETENCY MILESTONE
02
Explain DR and BDR election

Describe how interface priority and Router ID decide DR/BDR and why election is non-preemptive. This prevents surprise changes after a device joins the segment.

Mnemonic: Priority, then Router ID as tiebreaker.
VERIFIED COMPETENCY MILESTONE
03
Configure Junos interface types

Set interface-type to broadcast, p2p, or nbma and know when to add manual neighbors on NBMA links. Correct config ensures adjacency forms as intended.

Mnemonic: Interface-type matches physical behavior.
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot adjacency issues

Use interface detail checks and verify priorities, Router IDs, and IP addressing to resolve adjacency failures caused by misconfiguration.

Mnemonic: Priority, Router ID, Reachability.
