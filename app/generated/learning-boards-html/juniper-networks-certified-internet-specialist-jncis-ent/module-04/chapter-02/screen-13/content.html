Module 4 › Chapter 4.2 › Verification Command
Command

show ospf interface detail

Run the command to view the OSPF network type, interface priority, DR and BDR addresses, and the interface state. Compare that output on all routers sharing the segment to find mismatches.
If you changed priorities or interface-types, run the command both before and after clearing neighbors to see the effect of a re-election.
Do not assume default values; verify explicitly because misaligned defaults across platforms or manual changes are common causes of failure.
Key Takeaway

Use interface detail output as your source of truth when diagnosing adjacency and DR/BDR issues.

Verification flow
  1. Run the interface detail command on each router.
  2. Compare interface-type and priority values.
  3. Confirm DR and BDR fields are reachable.
Common pitfall
Relying on memory or assumed defaults instead of checking the live interface detail output. Always gather facts from the command output.
