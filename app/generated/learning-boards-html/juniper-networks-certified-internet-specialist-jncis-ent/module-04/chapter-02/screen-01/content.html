OSPF Network Types and Adjacency Formation

Understand how Broadcast, Point-to-Point, and NBMA segments change neighbor discovery, the role of DR/BDR, and how to configure Junos interfaces for correct adjacency formation.

Quick reference
  • Broadcast: multi-access, multicast supported, uses DR/BDR.
  • Point-to-Point: two routers, no DR/BDR, direct adjacencies.
  • NBMA: no native multicast, manual neighbors, DR/BDR still used.
Safety note
Changing interface types or priorities in production can reset adjacencies. Plan changes and have rollback steps.
Key Takeaway

Choose the OSPF network type that matches link behavior, set consistent priorities, and verify with interface detail commands to avoid adjacency failures.
