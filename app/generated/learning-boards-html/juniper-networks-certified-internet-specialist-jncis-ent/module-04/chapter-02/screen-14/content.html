Module 4 › Chapter 4.2 › Key Concepts
OSPF Network Types
Classify segments as broadcast, p2p, or nbma to decide neighbor discovery and adjacency behavior.
Broadcast Network
A multi-access LAN that supports multicast and uses DR/BDR to limit adjacencies and LSA flooding.
Point-to-Point
A two-router link where adjacencies are direct and no DR/BDR election occurs.
Summary
Network type determines how neighbors find each other and how LSAs flood. Match configuration to behavior for reliable adjacency formation.
