Module 4 › Chapter 4.2 › Adjacency Troubleshooting
Process

Step-by-step checks

  1. IP reachability: Verify ping and subnet masks to ensure Hellos can traverse.
  2. Network-type match: Confirm both ends use the same type; mismatches block adjacencies.
  3. Priority and Router ID: Check for priority 0, ties, or duplicate Router IDs.
  4. DR/BDR reachability: Ensure the elected DR is reachable; if not, investigate underlying connectivity.
  5. NBMA neighbor lists: Verify all neighbors are configured when using nbma.
Use the interface detail command to gather the information above and then apply targeted fixes rather than broad changes that could cause more disruption.
Common problem
Mismatched network types between two routers on the same segment. Fix: set both interfaces to the correct type and clear neighbors if needed.
Check your understanding
If two routers can ping each other but do not form OSPF adjacency, what is the most likely misconfiguration? Check that both ends have the same OSPF network type and matching area/interface settings.
