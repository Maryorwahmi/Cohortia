Module 4 › Chapter 4.5 › Junos Policy
Configuration example
edit policy-options policy-statement REDISTRIBUTE-STATIC-TO-OSPF
set term 1 from protocol static
set term 1 from route-filter 172.16.0.0/24 exact
set term 1 then metric 20
set term 1 then metric-type 1
set term 1 then accept
commit

edit protocols ospf
set export REDISTRIBUTE-STATIC-TO-OSPF
commit
Explanation
  • Match the exact static prefix to avoid over-redistribution.
  • Set metric and metric-type before accept so OSPF uses E1 with the seed metric.
  • Apply policy under protocols ospf using export to push routes into OSPF LSDB.
Key Takeaway
Explicitly set metric-type and metric in the policy for predictable OSPF behavior.
Common mistake
Missing accept or a route-filter that is too broad leads to unexpected LSAs in OSPF.
Concrete scenario
R1: static 172.16.0.0/24 next-hop 10.0.0.2. Policy redistributes as E1 metric 20. R2 will show route as O E1 after verification.
Verification commands
show ospf database external
show route protocol ospf
detail 172.16.0.0/24
