Module 4 › Chapter 4.5 › Lab Walkthrough
Topology and tasks
R1 (ASBR): ge-0/0/0.0 10.0.0.1/30, lo0.0 1.1.1.1/32, static 172.16.0.0/24 next-hop 10.0.0.2. R2 (internal): ge-0/0/0.0 10.0.0.2/30, lo0.0 2.2.2.2/32.
Step 1 — Default E2
# On R1
set routing-options static route 172.16.0.0/24 next-hop 10.0.0.2
edit policy-options policy-statement REDISTRIBUTE-STATIC-TO-OSPF
set term 1 from protocol static
set term 1 from route-filter 172.16.0.0/24 exact
set term 1 then accept
commit
edit protocols ospf
set export REDISTRIBUTE-STATIC-TO-OSPF
commit
Verify on R2: show route protocol ospf detail 172.16.0.0/24 and confirm O E2.
Step 2 — Convert to E1
# On R1 modify policy
edit policy-options policy-statement REDISTRIBUTE-STATIC-TO-OSPF
set term 1 then metric 50
set term 1 then metric-type 1
set term 1 then accept
commit
Verify on R2: show route protocol ospf detail 172.16.0.0/24 and observe O E1 and the internal cost addition.
Checks
  • show route protocol static on R1
  • show ospf database external on R1
  • show route protocol ospf detail on R2
Why this lab
Seeing the same prefix first as E2 then as E1 clarifies how metric-type influences routing decisions across OSPF.
