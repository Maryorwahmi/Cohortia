External Routes & Redistribution

Understand ASBR roles, OSPF external metric types, and how to use Junos routing policies to export external routes safely.

In this lesson

Define ASBR. Compare E1 and E2 metrics. Configure redistribution using Junos routing policies and verify external LSAs and routes.

Why it matters

Proper redistribution prevents loops, ensures predictable path selection, and lets you shape exit points to external networks such as the internet.

Hands-on

Walk through a Junos policy example that redistributes a static route as E1 with a custom metric and verify on a downstream router.

Caution

Redistribution without filters or tags can create loops. Use precise route-filters and tags when redistributing bidirectionally.

Explore Key Topics
ASBR & Redistribution

How routers inject external routes into OSPF using Type 5/7 LSAs and the role of ASBRs.

E1 vs E2 Metrics

E2 uses a fixed external cost; E1 adds internal path cost to the ASBR. This changes preferred exit points.

Junos Policies

Use policy-statement rules to match routes, set metric, and apply export under protocols ospf for redistribution.
