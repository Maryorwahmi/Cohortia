Definition

What an ASBR does

An ASBR redistributes routes learned from another routing domain into OSPF, generating external LSAs so OSPF routers learn those external prefixes.

Responsibility checklist
  • Has reachability to the external network
  • Matches routes with routing policy before redistribution
  • Sets metric and metric-type appropriately
  • Verifies external LSA advertisement
Concrete example
R1 holds static 172.16.0.0/24 next-hop 10.0.0.2 and exports it into OSPF using a routing policy; R1 acts as ASBR for that network.

Common misconception
Not every router with an external interface is an ASBR—only routers configured to redistribute those routes into OSPF are ASBRs.
