Module 4 › Chapter 4.5 › Troubleshooting
Common issues
  • Policy does not match or missing accept.
  • Export applied in the wrong protocol stanza or forgotten entirely.
  • Bidirectional redistribution without tags causing loops.
  • Unintended metric defaults leading to suboptimal path selection.
  • ASBR lacks reachability to external next-hop.
Quick fixes
  • Inspect and correct policy; narrow route-filters.
  • Place policy under protocols ospf with set export POLICY.
  • Tag redistributed routes and filter tags when importing back to original protocol.
  • Set explicit metric and metric-type in the policy.
  • Verify next-hop reachability and static route presence.
Checklist
1) show configuration policy-options policy-statement 2) show route protocol static 3) show ospf database external 4) show route protocol ospf detail
Final tip
Test redistribution in a lab and use narrow filters and tags before applying in production.
