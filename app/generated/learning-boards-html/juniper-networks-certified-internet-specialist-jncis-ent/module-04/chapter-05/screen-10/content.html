Direction matters

Export under protocols ospf

Apply the redistribution policy with set export POLICY_NAME under edit protocols ospf so OSPF advertises selected routes from the routing table.

Common operator errors
  • Putting an export policy under the wrong protocol stanza
  • Using import where export is required for redistribution
  • Forgetting to commit after configuration
Verification
edit protocols ospf
set export REDISTRIBUTE-STATIC-TO-OSPF
commit

Then on a neighbor: show route protocol ospf | match 172.16.0.0
Concrete example
After applying the export policy, R2 should show the redistributed prefix as O E1 or O E2 depending on metric-type.
Pro Tip
Name export policies clearly: e.g., REDISTRIBUTE-STATIC-TO-OSPF to avoid direction confusion.
