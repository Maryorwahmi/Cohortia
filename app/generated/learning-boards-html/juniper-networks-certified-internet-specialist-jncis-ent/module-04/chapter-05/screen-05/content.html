LSA types

Type 5 vs Type 7

Type 5 LSAs advertise external networks in standard OSPF areas. In NSSA areas redistributed routes appear as Type 7 and may be translated to Type 5 by an ABR.

LSA attributes to check
  • External prefix and mask
  • Seed metric value
  • Metric-type (E1 or E2)
  • Originating ASBR ID
Inspecting LSAs
Verification commands show the LSAs and their attributes. Use this information to confirm the seed metric and metric-type before trusting route selection across the domain.
Concrete verification
show ospf database external
Key takeaway
LSA type and attributes determine how OSPF distributes and compares external reachability.
