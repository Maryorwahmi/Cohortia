Module 4 › Chapter 4.5 › E2 Metrics
Behavior

External Type 2 (E2)

E2 routes compare only the external seed metric when multiple ASBRs advertise the same prefix. Internal cost to reach the ASBR is not part of the comparison.

Concrete example
ASBR-A advertises metric 10, ASBR-B advertises metric 5. OSPF chooses ASBR-B's path regardless of internal distance.
Misconception
Do not assume internal topology will influence E2 selection; only the external metric matters for comparison.
Decision aid
When to use E2
Use E2 when you want redistribution seed metrics to control exit selection irrespective of internal distances. It is simpler when exit cost should be externally determined.
Check your understanding
If two ASBRs advertise the same E2 network with different seed metrics, which wins? The lower seed metric wins regardless of internal cost.
Consider using E2 when you control external metrics centrally at redistribution points.
Key Takeaway
E2 equals fixed external cost comparison; internal path length does not change which ASBR is preferred.
