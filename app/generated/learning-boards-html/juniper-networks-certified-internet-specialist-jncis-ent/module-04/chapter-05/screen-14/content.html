Module 4 › Chapter 4.5 › Key Concepts
ASBR
Router that connects OSPF to external domains and originates external LSAs.
External LSA
Type 5 (or Type 7 in NSSA) LSAs carry external network information, seed metric and metric-type.
Routing Policy
Policy-statement controls which routes are redistributed and sets metric attributes in Junos.
Summary
Control redistribution deliberately: match narrowly, set metric-type, tag when needed, and verify with show commands.
