Using Authentication Key ID and Key Rotation
Step-by-step to rotate keys without outage.
1
Install new key with new ID on both peers
Add authentication-key-id 2 with the new secret while keeping the existing key-id 1 configured.
2
Commit and verify acceptance
Ensure show ospf neighbor detail shows peers accept both IDs or can form adjacencies with either.
3
Switch active key ID
Change authentication-key-id to the new ID and commit on both sides in quick succession.
4
Remove old key once stable
After confirming adjacency stability, remove the old key entry to complete rotation.
Troubleshooting tips
  • If adjacency fails, confirm both key ID and key match.
  • Use monitor protocol ospf to see authentication failures and adjacency state changes.
Key Takeaway

Always stage the new key on both routers before switching IDs to avoid adjacency loss.
