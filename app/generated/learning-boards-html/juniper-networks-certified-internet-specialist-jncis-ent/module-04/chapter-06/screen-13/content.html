Advanced OSPF Troubleshooting with Junos
A practical command sequence to isolate problems.
Command Sequence
  1. show ospf overview
  2. show ospf interface detail
  3. show ospf neighbor detail
  4. show ospf database detail
  5. monitor traffic interface <iface> detail
  6. monitor protocol ospf
Examples & Checks
  • Authentication errors can appear in neighbor detail or system logs.
  • Interface timers or mismatched network type prevent adjacency formation.
  • LSDB inconsistencies show up in show ospf database detail and should be reconciled by checking adjacency states.
Pro Tip

When possible, reproduce the issue in a lab or during a maintenance window and make one change at a time, verifying each result with the commands above.
