Stability Feature
OSPF Graceful Restart
Preserve forwarding while control plane restarts and adjacencies resynchronize.
What happens during graceful restart
  • Restarting router signals neighbors to retain forwarding state.
  • Neighbors keep using last-known routes for a grace period.
  • Restarting router re-establishes adjacencies and resynchronizes LSDB.
Commands & Verification
Enable with set protocols ospf graceful-restart and commit. Use monitor protocol ospf and show ospf neighbor detail to observe graceful restart capability and timers. Perform controlled restarts to validate behavior before using in production.
Key Takeaway

Graceful restart helps prevent traffic loss during control plane restarts, but always verify timers and neighbor behavior through monitoring.
