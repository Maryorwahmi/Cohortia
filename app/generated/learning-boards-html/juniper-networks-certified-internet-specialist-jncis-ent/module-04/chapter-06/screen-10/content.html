OSPF Interface Cost and Path Selection
Understand how metrics affect SPF and routing decisions.
How cost affects SPF
  • SPF computes path using the sum of interface costs.
  • Lower cost → more preferred path; higher cost → less preferred.
  • Manual cost overrides default bandwidth-derived metric.
Concrete scenario: changing R1's interface metric to 100 will increase the path cost to networks learned via that interface and may cause SPF to switch to alternate routes.
Verification
Use show ospf interface detail to inspect the configured metric, and show route protocol ospf <prefix> detail to see the resulting path cost and chosen next-hop.
Pro Tip

Document cost changes and perform them during maintenance windows; audit neighboring configs to avoid asymmetric outcomes.
