Core Feature
OSPF Stub Router Advertisement
Make a router unattractive for transit while still advertising its prefixes.
What it does
Marks the router's LSAs with a maximum metric so neighbors avoid selecting it as a transit path, but leaves directly connected networks advertised.
When to use
  • Planned maintenance or limited forwarding capacity.
  • Service nodes that should not forward transit traffic.
Verification & Example
After set protocols ospf stub-router and commit, inspect the LSDB with show ospf database detail to confirm LSAs use the maximum metric (LSInfinity). Monitor routing to ensure prefixes remain reachable but transit is avoided.
Key Takeaway

Use stub-router to preserve local reachability while intentionally discouraging transit through a router.
