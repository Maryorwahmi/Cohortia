Lab Skills and Verification Steps
Commands and pass/fail criteria for each objective.
Authentication Checklist
  • Configure MD5 with authentication-key-id on both peers.
  • Commit changes on both routers quickly to avoid timeouts.
  • Verify with show ospf neighbor detail for authentication and key-id match.
Cost & Routing Checks
  • Set interface metric and commit.
  • Use show ospf interface detail and show route protocol ospf <prefix> detail to confirm metric propagation.
  • Watch for asymmetric routes after changes.
Restart & Stub Verification
  • Enable graceful-restart and commit.
  • Use monitor protocol ospf and show ospf database detail to confirm LSAs and grace behavior.
  • For stub-router, inspect LSA metrics for LSInfinity values.
