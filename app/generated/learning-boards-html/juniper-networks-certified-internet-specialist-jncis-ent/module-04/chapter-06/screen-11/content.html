Configuration & Verification
Set OSPF Interface Cost and Verify
Example command and verification checklist.
Example
edit protocols ospf
set area 0.0.0.0 interface ge-0/0/0.0 metric 100
commit
This overrides the default bandwidth-derived metric for that interface.
Verification Steps
  • show ospf interface detail — confirms the configured metric for the interface.
  • show route protocol ospf <prefix> detail — shows chosen path and cost.
  • show ospf database detail — inspect LSAs for metric propagation.
Common Mistake

Failing to check the neighbor's perspective; always verify both ends after changing costs.
