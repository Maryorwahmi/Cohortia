Comparison
Plaintext vs MD5 vs IPsec
Understand trade-offs and operational impact.
Plaintext
Sends the key in clear text. Easy to configure but exposes secrets on the wire. Only for isolated labs.
Risk: key capture and impersonation
MD5
Sends a hash computed from the packet and the shared secret. Requires matching auth type, key ID, and key. Recommended for production.
Benefit: integrity without sending the secret
IPsec
Secures the whole IP packet with authentication and optional encryption. Configured outside OSPF; best when confidentiality is required.
Trade-off: higher operational complexity
Operational tip
Always check authentication type and authentication-key-id when adjacencies fail. Mismatched key IDs with identical keys will still fail.
Key Takeaway

Default to MD5 for production OSPF links. Use IPsec where encryption is needed. Avoid plaintext outside labs.
