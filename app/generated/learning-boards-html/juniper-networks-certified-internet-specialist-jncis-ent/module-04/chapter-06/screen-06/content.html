Configuring MD5 Authentication on Junos
Example commands and verification steps.
Junos MD5 Example
edit protocols ospf
set area 0.0.0.0 interface ge-0/0/0.0 authentication md5
set area 0.0.0.0 interface ge-0/0/0.0 authentication-key-id 1
set area 0.0.0.0 interface ge-0/0/0.0 authentication-key "$9$B3P-gJ3.a/A"
commit
Note: authentication-key may appear encrypted by Junos when stored.
Verification Commands
  • show ospf neighbor detail — check authentication and key ID.
  • monitor protocol ospf — observe adjacency events in real time.
  • monitor traffic interface <iface> detail — capture Hello/DBD exchanges.
Key Takeaway

Apply the same MD5 type, key ID, and key on both peers, then verify with neighbor detail to confirm the adjacency is authenticated.
