Type 5, Type 6, and Type 7 LSAs
External routes and NSSA behavior explained to predict how external networks appear in routing tables.
Type 5 — External LSA
Originated by ASBRs to advertise external prefixes; blocked from stub areas.
Type 6 — MOSPF
Used for multicast OSPF; not commonly implemented in enterprise Junos networks.
Type 7 — NSSA external
Originated by ASBRs inside an NSSA and translated into Type 5 by the NSSA ABR for propagation outside the NSSA.
Verification commands
show ospf database area 2.0.0.0  # look for Type 7 in NSSA
show route protocol ospf                 # inspect how routes are learned
