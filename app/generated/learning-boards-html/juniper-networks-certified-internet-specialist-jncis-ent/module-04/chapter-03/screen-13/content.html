Junos Configuration Walkthrough
ABR and NSSA ASBR examples for R1 and R3 from the lab topology.
R1 (ABR) — partial
# R1 Configuration (ABR)
edit protocols ospf
set router-id 1.1.1.1
set area 0.0.0.0 interface ge-0/0/0.0
set area 1.0.0.0 interface ge-0/0/1.0
set area 1.0.0.0 stub no-summaries  # Totally Stubby Area
set area 2.0.0.0 interface ge-0/0/2.0
set area 2.0.0.0 nssa
commit
R3 (NSSA ASBR) — partial
# R3 Configuration (ASBR in NSSA)
edit protocols ospf
set router-id 3.3.3.3
set area 2.0.0.0 interface ge-0/0/0.0
set area 2.0.0.0 nssa
set area 2.0.0.0 nssa default-lsa  # optional: ABR generates default into NSSA
set routing-options static route 172.16.0.0/24 next-hop 10.0.0.2
set policy-options policy-statement static-to-ospf-policy term 1 from protocol static
set policy-options policy-statement static-to-ospf-policy term 1 then accept
set protocols ospf export static-to-ospf-policy
commit
Verification
Use show ospf neighbor, show ospf database area <area-id>, and show route protocol ospf to confirm adjacencies, LSA presence, and how routes are learned across the areas.
