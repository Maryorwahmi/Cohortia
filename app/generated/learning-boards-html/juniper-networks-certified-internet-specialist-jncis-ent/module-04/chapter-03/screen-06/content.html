Area Border Routers (ABRs)
ABRs translate and summarize LSAs between areas while maintaining separate LSDBs per area.
ABR responsibilities
  • Maintain separate LSDBs for each area on which it has interfaces.
  • Originate Type 3 LSAs to advertise inter-area routes.
  • Originate Type 4 LSAs to advertise ASBR reachability.
Operational example
An ABR sees a loopback in Area 2 and summarizes it into a Type 3 into Area 0 so routers in Area 1 learn the route without full Area 2 topology details. If Area 1 is a stub, the ABR may instead inject a default route so Area 1 routers can reach the destination.
Pro tip: Monitor ABR CPU and LSDB size when adding many areas; ABRs do extra SPF work.
