Totally Stubby Areas and NSSA
Understand the trade-offs between maximal state reduction and the need for local external route injection.
Totally Stubby Area
Blocks Type 3, 4, and 5. Routers only learn intra-area routes and a default route. Configure on Junos with: set area X stub no-summaries.
NSSA
Blocks Type 4 and Type 5 from outside but allows ASBRs inside to inject external routes as Type 7. ABR translates Type 7 to Type 5 for other areas.
Design note: Use TSA when device routing tables must be minimal; use NSSA when local external routes must be advertised from inside the area.
