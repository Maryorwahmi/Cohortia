Area 0 — The Backbone
Area 0 is the transit area; keep it contiguous and reachable from all ABRs.
Backbone responsibilities
  • Carry inter-area Type 3 and Type 4 LSAs between areas.
  • Host translated external LSAs (Type 5) from NSSA ABRs after conversion.
  • Serve as the common reference point for all area routing.
Example and misconception
If an ABR lacks an interface in Area 0, it cannot correctly propagate inter-area LSAs. A common design error is chaining areas without Area 0 connectivity. The correct fix is to ensure each non-backbone area directly reaches Area 0 or use a virtual link when necessary.
Design tip: Keep Area 0 contiguous and minimize virtual links for simplicity and faster convergence.
