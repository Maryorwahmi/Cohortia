Type 3 & Type 4 LSAs
ABRs summarize networks and advertise ASBR locations to other areas using Type 3 and Type 4 LSAs.
How Type 3 works
ABR translates intra-area prefixes into summary entries for other areas, reducing the amount of topology carried across Area 0.
How Type 4 works
ABR advertises ASBR reachability so routers in other areas have a path to external routes via that ABR.
Check: On a totally stubby area, Type 3 LSAs are blocked and the ABR provides a default route instead.
