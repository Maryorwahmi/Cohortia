Stub Areas
Stub areas reduce routing state by blocking external LSAs and using a default route supplied by the ABR.
Behavior
  • Blocks Type 4 and Type 5 LSAs.
  • ABR injects default route (0.0.0.0/0) to reach external destinations.
  • All routers in the area must be consistently configured as stub.
Use case
Branch sites or access networks that do not need full knowledge of external routing can use stub areas to conserve router resources and simplify routing tables.
Check: After configuring stub, confirm show route 0.0.0.0/0 exists on area routers.
