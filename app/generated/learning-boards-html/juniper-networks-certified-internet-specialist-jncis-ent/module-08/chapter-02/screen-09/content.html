Module 8 › Chapter 8.2 › Simulate a switchover and monitor
Lab walkthrough
  1. Confirm sync: show chassis redundancy and rpd checks on both REs.
  2. Begin continuous monitoring: show ospf neighbor, show bgp summary, show route.
  3. Trigger switchover: request chassis routing-engine master switch (lab-only).
  4. Observe and record: adjacency states and route table behavior.
  5. Compare logs: pre- and post-switchover outputs to identify any drift.
Monitoring snapshot
Keep separate panes showing continuous outputs so you can spot transient changes immediately. Record timestamps for each significant output to correlate events.
Safety note
Always preserve console access to both REs. If a switchover fails, console access is required to recover safely.
