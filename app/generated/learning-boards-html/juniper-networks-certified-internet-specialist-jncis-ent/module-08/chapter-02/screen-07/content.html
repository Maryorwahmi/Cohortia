Module 8 › Chapter 8.2 › Enable GRES and NSR — CLI steps
Procedure

Configuration checklist

  1. Enter configuration mode: configure
  2. Enable GRES: set chassis redundancy graceful-switchover
  3. Enable NSR: set routing-options nonstop-routing
  4. Commit changes: commit and-quit
  5. Verify synchronization and rpd health on both REs
CLI example
# configure
set chassis redundancy graceful-switchover
set routing-options nonstop-routing
commit and-quit
These commands are global; individual protocols do not require per-protocol NSR config in Junos for supported protocols.
Pro tip
Record the outputs from verification commands immediately after commit so you can compare pre- and post-switchover behavior.
