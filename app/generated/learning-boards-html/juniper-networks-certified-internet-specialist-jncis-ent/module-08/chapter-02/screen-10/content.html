Module 8 › Chapter 8.2 › NSR vs protocol-level graceful restart
Contrast

Internal vs neighbor-signaled

NSR keeps state inside the device synchronized so the backup can immediately continue. Protocol graceful restart asks neighbors to temporarily preserve forwarding state while the router restarts or recovers.
When to prefer NSR
Internal RE switchovers where uninterrupted adjacencies are critical.
When to use protocol graceful restart
For peering with external neighbors to reduce forwarding impact during restarts across devices.
Practical note
If both features are enabled, NSR will typically make internal switchover seamless first. Keep graceful restart enabled for external resiliency, but test interactions carefully.
Key takeaway
Use NSR for internal RE continuity and maintain protocol graceful restart for neighbor-level resilience where it still provides value.
