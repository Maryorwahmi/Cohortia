Module 8 › Chapter 8.2 › What GRES provides
Definition

GRES — kernel & interface sync

GRES ensures the backup Routing Engine's operating system and interfaces are synchronized so a switchover can bring the backup online without lengthy hardware or kernel re-initialization.
Why this matters
  • Reduces time for interfaces to reach operational state after a switchover.
  • Prevents long interface flaps that can cause data-plane interruption.
  • Forms the foundation for preserving higher-level routing state when paired with NSR.
Concrete example
In a lab, enabling GRES lets the backup RE bring up interfaces immediately after a master switch. Without GRES, interfaces might reset and require physical link re-negotiation, causing additional downtime.
Quick verification

Key takeaway
GRES is necessary but not sufficient for routing continuity. Use it as the first layer of redundancy and add NSR for protocol-level continuity.
