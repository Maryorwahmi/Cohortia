Module 8 › Chapter 8.2 › Verify NSR and GRES status
Commands to run
  • show chassis redundancy — confirm graceful-switchover and sync status
  • show ospf neighbor detail | match "State|Nonstop" — expect State: Full and Nonstop routing: Enabled when NSR is active
  • show bgp summary | match "State|Nonstop" — validate BGP session stability
  • show route summary — watch for route churn
  • show system processes extensive | match rpd — ensure rpd is running on both REs
Expected snippet
  State: Full
  Nonstop routing: Enabled
# This indicates OSPF adjacency is intact and NSR is active for that neighbor
If you see adjacency re-establishment or route churn, investigate synchronization status and rpd health on the backup RE.
Common mistake
Checking only one RE or only interface sync can hide protocol-level issues. Always check both REs and protocol outputs.
