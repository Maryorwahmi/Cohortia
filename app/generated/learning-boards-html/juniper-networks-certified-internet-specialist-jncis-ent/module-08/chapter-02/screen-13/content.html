Activity steps
  1. Enter CLI: configure and apply set chassis redundancy graceful-switchover; set routing-options nonstop-routing; commit.
  2. Record baseline: show chassis redundancy; show ospf neighbor detail; show bgp summary; show route summary.
  3. Open monitoring panes: run continuous show commands to watch state in real time.
  4. Trigger switchover: request chassis routing-engine master switch in lab only.
  5. Compare outputs: verify adjacency State and Nonstop routing flags and confirm minimal route churn.
Remember
Do not perform manual switchovers in production without a maintenance window and console access to both REs.
