Module 8 › Chapter 8.2 › Protocols supported by NSR
Supported protocols
OSPF
Adjacencies and LSAs preserved, expect State: Full when successful.
BGP
Session state and learned routes preserved so peers see minimal impact.
IS-IS / RIP
Control plane state synchronized where supported; behavior varies by protocol nuance.
LDP
Label distribution state can be preserved for MPLS control plane continuity.
RSVP
Signaling state carried by rpd may persist across a switchover.
PIM
Multicast control plane state participates where supported by the platform.
Action
Test each protocol in your lab under NSR to verify exact behavior and note any protocol-specific adjustments required.
