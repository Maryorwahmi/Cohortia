Hands-on Activity

Two-member EX2300 build sequence

Sequence
  1. Power off both switches and connect VCP cables.
  2. On EX2300-A: set member 0 role master and serial number, set VCPs, commit.
  3. On EX2300-B: set member 1 role backup and serial number, set VCPs, commit.
  4. After reboot, log into master and run show virtual-chassis to verify.
Checks & Safety
  • Confirm correct transceivers and cables for VCPs.
  • Match VCP configuration on both members.
  • Document serial-to-member ID mapping before commit.
Key Takeaway

Follow the cable‑then‑provision sequence and verify replication state to form a reliable Virtual Chassis.
