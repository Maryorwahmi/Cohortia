EX2300-A (Master) — Example CLI

# Enter configuration mode
# user@switch1> configure

# Set member ID and role
set virtual-chassis member 0 role master
set virtual-chassis member 0 serial-number <SERIAL_NUMBER_OF_SWITCH1>

# Configure VCPs (example: pic-slot 0 ports 0 and 1)
request virtual-chassis vc-port set pic-slot 0 port 0
request virtual-chassis vc-port set pic-slot 0 port 1

# Commit (this will reboot the switch into VC mode)
commit and-quit
# On Switch 2 (Backup)
# user@switch2> configure
set virtual-chassis member 1 role backup
set virtual-chassis member 1 serial-number <SERIAL_NUMBER_OF_SWITCH2>
request virtual-chassis vc-port set pic-slot 0 port 0
request virtual-chassis vc-port set pic-slot 0 port 1
commit and-quit
Note: commit will reboot the switch into VC mode. Ensure serial numbers match physical devices before committing.
Key Takeaway

Provision member IDs and serials before connecting VCPs to keep member identities stable.
