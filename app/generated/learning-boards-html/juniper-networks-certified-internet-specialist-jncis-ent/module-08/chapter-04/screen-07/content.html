Process

Member provisioning steps

  1. Choose member IDs for each physical switch (0–9).
  2. Enter configure mode on each switch and set member ID and role.
  3. Set each member’s serial-number to persist the ID mapping.
  4. Commit; this may reboot the switch into VC mode.
Concrete command pattern
# user@switch1> configure
set virtual-chassis member 0 role master
set virtual-chassis member 0 serial-number <SERIAL_NUMBER_OF_SWITCH1>
commit and-quit
Pitfall
If you omit serial-number assignments, member IDs may be assigned by election and change after reboots. That unpredictability complicates troubleshooting and automation.
Pro Tip

Document serial-to-member ID mappings before deployment so you can quickly identify physical hardware later.
