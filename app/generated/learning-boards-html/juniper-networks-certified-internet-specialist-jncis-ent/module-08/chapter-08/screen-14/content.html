Key Concepts
Three quick definitions to recall during troubleshooting.
VLAN Trunking
Carry multiple VLANs across one link; both ends must define and allow the same VLANs to pass traffic correctly.
Spanning Tree Protocol
Prevents Layer 2 loops by blocking redundant paths. Root bridge selection and port roles determine which links forward.
Firewall Filter
Policy terms evaluate top-down with an implicit deny at the end. Use counters and the session table to confirm which terms match traffic.
Summary

When troubleshooting, verify definitions, check control-plane roles, and gather objective evidence such as MAC entries, sessions, and counters before changing configurations.
