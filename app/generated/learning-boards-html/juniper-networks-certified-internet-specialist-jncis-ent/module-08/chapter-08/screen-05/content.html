Module 8 › Chapter 8.8 › OSPF Routing
Definition & Causes

When routes learned by OSPF do not appear in the routing table, verify the presence of LSAs, unique router IDs, and that interfaces are not passive. Also check for filters or route policies that modify or suppress routes.

Quick command set
show route protocol ospf
show ospf database
show ospf overview
show configuration protocols ospf area
Example scenario
An IRB network is not advertised because the corresponding interface was accidentally marked passive in the area config. Removing passive allows LSAs to be generated and the route to appear in the RIB.
Misconception
Seeing no route in the RIB does not always mean OSPF failed to advertise; it might be filtered or overridden. Correlate outputs across database, routes, and policies.
Interpretation guide
  • If show ospf database lacks an LSA for the prefix, the origin router did not inject it or a filter prevented it.
  • If show ospf overview shows duplicated router IDs, assign a unique router-id under routing-options.
  • If the interface is passive, remove the passive flag so LSAs are generated and Hellos may be exchanged where applicable.
Key Takeaway

Correlate the RIB, the OSPF database, and interface config; that triad reveals the majority of OSPF route problems.
