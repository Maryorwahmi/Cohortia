Comparison: Export vs Import Issues
Export-side problem
A route present in local RIB but not sent to neighbor because export policy denies it. Use show configuration policy-options and add counters to terms to confirm hits.
Import-side problem
Neighbor sends prefixes but the local import policy rejects them. Verify show bgp neighbor <ip> received-routes or policy counters on the receiving side.
Next-hop issue
iBGP peers may receive routes with a next-hop they cannot reach. Use next-hop-self on the advertising neighbor or ensure next-hop is reachable via the IGP.
Commands & example
show route
show route protocol bgp
show bgp summary
show configuration policy-options
set protocols bgp group EBGP_PEER next-hop-self
Practical tip

Add count counters to policy terms and then run show configuration policy-options or show firewall filter <name> counter to see if traffic or route advertisements match the intended terms before assuming a protocol bug.

Key Takeaway

Missing BGP routes are usually a policy or next-hop issue; verify local presence, policy counters, and next-hop reachability before altering routing protocols.
