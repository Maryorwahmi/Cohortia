Diagnosing VLAN access vs trunk problems
Follow an ordered check list to isolate access-port faults from trunk misconfiguration.
Core Concept
Comparison: Access port vs Trunk
Access Port

Carries a single VLAN. Check host IP, VLAN membership and MAC learning on the interface.

Mnemonic: single lane
Trunk

Carries multiple VLANs. Verify allowed VLAN list, native VLAN and physical link state.

Mnemonic: multi-lane
Quick verification commands
show configuration vlans
show configuration interfaces ge-0/0/0
show interfaces ge-0/0/0 terse
show ethernet-switching table
Diagnostic flow and example
Follow these steps, confirm after each step before changing configuration.
  1. Confirm host IP, mask, and gateway on both ends.
  2. Check switch VLAN definition with show configuration vlans.
  3. Verify trunk membership and native VLAN; add missing VLANs if needed.
  4. Confirm MAC learning with show ethernet-switching table.
  5. Check physical link and errors with show interfaces terse.
Key Takeaway

Diagnose in order: addressing, VLAN presence, MAC learning, trunk membership, and physical link. This avoids unnecessary changes.
