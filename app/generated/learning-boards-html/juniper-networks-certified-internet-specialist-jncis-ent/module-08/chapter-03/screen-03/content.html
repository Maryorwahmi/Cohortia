Lab scenario
Create ae0 with two members and enable LACP
  1. Define ae0 and set interface-mode trunk for VLANs.
  2. Enable aggregated-ether-options lacp active.
  3. Assign member ports ge-0/0/0 and ge-0/0/1 to ae0.
  4. Commit and verify show interfaces and show lacp interfaces.
VERIFIED COMPETENCY MILESTONE
Best practices
  • Ensure member interfaces have no conflicting logical units.
  • Match LACP mode and hashing on both ends of the bundle.
  • Set minimum-links thoughtfully to avoid unintended downtime.
Mnemonic: match and simplify
Verification checklist
Show interfaces ae0
Confirm logical interface is up and has expected counters and VLAN membership.
Show lacp interfaces
Confirm LACP state, partner info, and statistics for each member link.
