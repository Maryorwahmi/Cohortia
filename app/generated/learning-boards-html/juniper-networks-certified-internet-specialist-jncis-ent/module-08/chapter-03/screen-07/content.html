Definition › Aggregated Ethernet (AE / LAG)
AE explained

AE bundles multiple physical links into a single logical interface so the network sees one higher-bandwidth, resilient link. If a member link fails, traffic continues on remaining links and the logical interface stays up if minimum-links requirements are met.

Redundancy
Single-link failure does not drop the logical interface.
Bandwidth
Aggregate of active member link rates.
Load balancing
Traffic distributed using hash algorithms.
Design notes
  • Use uniform port speeds and types within a bundle.
  • Enable LACP for automatic and predictable bundle formation.
  • Match hashing and LACP mode on both ends to avoid formation issues.
Pitfall

Setting minimum-links too high can cause the bundle to go down even when some links remain active. Choose a safe minimum based on required redundancy.
