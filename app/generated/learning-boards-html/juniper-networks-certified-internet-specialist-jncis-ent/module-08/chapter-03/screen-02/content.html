Module 8 › Chapter 8.3 › Learning Objectives
01
Explain Nonstop Forwarding
VERIFIED COMPETENCY MILESTONE

Define how NSF lets the PFE continue forwarding using the last-known forwarding entries during a Routing Engine switchover. This matters because it prevents traffic blackholing during brief control-plane transitions.

Mnemonic: PFE memory
02
Describe NSF with GRES and NSR
VERIFIED COMPETENCY MILESTONE

Explain how GRES preserves kernel and interface state, NSR synchronizes routing protocols, and NSF keeps forwarding active to provide coordinated HA. Knowing the interaction helps with design and troubleshooting.

Mnemonic: Three pillars
03
Configure and verify AE (LAG)
VERIFIED COMPETENCY MILESTONE

Create an ae interface, enable LACP, set minimum-links, and add member interfaces. Verification includes show interfaces and show lacp commands to confirm bundle formation and operation.

Mnemonic: ae0 checklist
04
Understand AE benefits and pitfalls
VERIFIED COMPETENCY MILESTONE

Explain link redundancy, aggregate bandwidth, and load balancing. Recognize pitfalls such as mismatched LACP modes, incorrect hashing, and minimum-links set too high.

Mnemonic: bundle rules
