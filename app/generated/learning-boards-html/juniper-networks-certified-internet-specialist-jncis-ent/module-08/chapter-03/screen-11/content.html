Lab Walkthrough › Hands-on Activity: Create ae0 and test failover
Instructions summary
  1. Access the Junos CLI and enter configure mode.
  2. Create ae0 and set it to ethernet-switching trunk, assign VLANs.
  3. Enable aggregated-ether-options lacp active and set minimum-links 1.
  4. Assign ge-0/0/0 and ge-0/0/1 to ae0 with ether-options 802.3ad ae0.
  5. Commit, then verify show interfaces ae0 and show lacp interfaces ae0.
  6. Disconnect one member link and observe ae0 remains up and traffic continues.
Safety note
Ensure physical members have no conflicting logical units prior to bundling to avoid configuration conflicts.
Starter template
# user@switch> configure

# Define ae0
set interfaces ae0 unit 0 family ethernet-switching interface-mode trunk
set interfaces ae0 unit 0 family ethernet-switching vlan members all
set interfaces ae0 aggregated-ether-options minimum-links 1
set interfaces ae0 aggregated-ether-options lacp active

# Add members
set interfaces ge-0/0/0 ether-options 802.3ad ae0
set interfaces ge-0/0/1 ether-options 802.3ad ae0

# commit and verify
commit and-quit
show interfaces ae0
show lacp interfaces ae0
