Configuration › Enabling NSF per-protocol
Concept

NSF is often provided by graceful-restart features of routing protocols. Enabling graceful-restart tells neighbors to preserve adjacencies and allows PFEs to keep forwarding while control-plane state is reestablished.

Common pitfall

Assuming all protocols automatically support NSF. Verify for each protocol and platform whether graceful-restart NSEF semantics are supported.

Code examples
set protocols ospf graceful-restart

set protocols bgp graceful-restart
After commit, watch neighbor messages and run verification commands during a controlled switchover to confirm forwarding continuity and adjacency restoration.
