Link Aggregation Control Protocol (LACP)
Use LACP to negotiate bundles; ensure modes and hashing match across both ends.
Grace Period
The interval PFEs retain forwarding state so NSR and the new RE can recover without disrupting traffic.
Verification commands
Use show interfaces ae0 and show lacp interfaces ae0 to confirm state, counters, and partner info.
Final takeaway

NSF and AE address two different failure domains. Use NSF for control-plane continuity and AE for link-level redundancy; verify both with targeted tests to prove data-plane continuity.
