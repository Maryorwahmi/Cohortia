OSI-based troubleshooting

Map the observed symptom to likely OSI layers and run the common checks for those layers to narrow causes quickly.

L1
Physical
Cables, SFPs, interface state
L2
Data Link
VLANs, MAC table, STP
L3
Network
IP, routing, neighbors
L4
Transport
TCP/UDP ports, sessions
Higher layers (L5-L7)
Session, presentation, application checks: DNS, authentication, application logs, and protocol-level diagnostics such as curl or dig.
Example checks
  • Layer 1: interface counters and link status
  • Layer 3: ping, traceroute, and routing table
  • Layer 7: application logs and DNS queries
Misconception
Treating layers as isolated; failures can cascade from lower layers and present as higher-layer symptoms.
Key Takeaway

Use OSI layers as a repeatable checklist and document results to build a clear evidence trail during incidents.
