Baselines and documentation

Maintain snapshots of known-good configurations and current diagrams so deviations are apparent during an incident.

Baselines
  • Config backups
  • Interface states and counters
  • Performance metrics
Documentation
  • Topology diagrams
  • IP addressing and VLAN plans
  • Change logs and maintenance windows
Operational habit
Automate backups and snapshot configurations regularly; treat documentation as living, not static.
Key Takeaway

Baselines and current documentation are the fastest path from symptom to targeted hypothesis during incidents.
