Scenario: Users in VLAN 20 cannot reach 10.0.0.100

Use a structured workflow: define, select methodology, form hypotheses, test, implement controlled fixes, verify, and document.

Problem definition
Users in VLAN 20 (192.168.20.0/24) cannot reach 10.0.0.100; others can. Note timestamp and recent changes.
Methodology
Divide-and-conquer to isolate VLAN, gateway, routing path, and server behaviors.
Hypotheses
  • H1: VLAN 20 hosts misconfigured (Layer 3)
  • H2: Routing issue between VLAN gateway and server (Layer 3)
  • H3: Firewall blocking traffic from VLAN 20 to server (Layer 4)
Test plan (conceptual)
  1. H1: On host, check IP, mask, gateway; ping gateway.
  2. H2: From gateway, ping server; inspect routing table for a route to 10.0.0.0/24.
  3. H3: Review firewall policies for rules affecting traffic from 192.168.20.0/24 to 10.0.0.100.
Required documentation
Topology diagram, IP addressing scheme, VLAN assignments, routing excerpts, and recent change logs are most helpful for this scenario.
Key Takeaway

Structured tests mapped to OSI layers help you quickly rule out host, routing, or firewall causes and reach a verified fix.
