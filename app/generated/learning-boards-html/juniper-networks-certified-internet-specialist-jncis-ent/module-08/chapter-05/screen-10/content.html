Hypothesis-driven workflow

Write a single, testable hypothesis and design a minimal, reversible test to confirm or refute it. Log results and iterate.

Example hypothesis
"Routing table on gateway lacks route to 10.0.0.0/24."
Minimal test
Ping the server from the gateway or inspect the gateway's routing table to confirm presence or absence of route.
Iterate
If test refutes the hypothesis, write a new one based on observed evidence and test again.
Checklist for tests
  • One hypothesis per test
  • Test should be reversible or non-destructive
  • Record result clearly
Key Takeaway

Focused hypotheses and minimal tests produce clear evidence and a tight path to root cause.
