Bottom-Up methodology

When outages or hardware changes are likely, verify Layer 1 first, then Layer 2, then Layer 3, and continue upward until the issue is resolved.

Layer 1 Checks
  • Link status and LEDs
  • Cable continuity and SFPs
  • Power and hardware logs
Layer 2 Checks

VLAN membership, MAC table, STP state, and link aggregation status.

Layer 3+ Checks

IP configuration, routing table, ACLs, and finally transport/application verification.

Concrete example
After a switch replacement, hosts are unreachable. Validate physical port link, VLAN tagging, and trunk configurations before examining routing.
Pitfall
Assuming physical components are fine without quick checks wastes time chasing higher-layer problems.
Key Takeaway

Bottom-up is efficient when physical issues or recent hardware changes are suspected; validate fundamentals first.
