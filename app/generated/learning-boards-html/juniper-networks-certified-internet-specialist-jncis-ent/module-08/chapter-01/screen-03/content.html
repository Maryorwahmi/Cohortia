Hands-on workflow
  1. Open the Junos CLI and enter configuration mode.
  2. Set graceful-switchover under chassis redundancy and commit.
  3. Run verification commands and confirm kernel and config sync.
  4. Only test manual switchovers in a controlled lab environment.
These steps help you build a checklist to validate RE redundancy and GRES before maintenance. Good verification prevents surprises during a real failover.
Verification checklist
Configuration synchronization: Done
Kernel synchronization: Done
GRES enabled: Yes
Manual switchover: Only in lab
Tip: Add verification to runbooks before change windows.
