Definition › What is GRES?

GRES explained

GRES enables the backup Routing Engine to maintain a synchronized copy of the primary's state and take over without forcing routing protocols to rebuild adjacencies.

Synchronized items: interface states and next-hops
Protocol adjacencies and kernel state
Real example
Planned RE reboot with GRES: backup assumes primary role and routing state persists, reducing outage time significantly.
Verification focus
GRES must be enabled in configuration and synchronization must report Done for config, kernel, and fabric. If any show check reports incomplete, treat GRES as non-functional.
Common mistake

Assuming GRES is present simply because two REs exist. Enable it and verify its status before relying on it in production.
