Process Flow › How GRES Works Internally

Continuous synchronization

  1. Primary pushes configuration and kernel state to backup continuously.
  2. Backup maintains protocol adjacencies and table snapshots where possible.
  3. System reports synchronization status as Done when aligned.
These steps ensure the backup is pre-warmed and ready to assume control without rebuilding state from scratch.

Switchover sequence

  1. Trigger or detect RE failure.
  2. Backup promotes to master using synchronized state.
  3. Control-plane functions resume with minimal reconvergence.
Key Takeaway

GRES reduces the time to restore control-plane functionality by relying on an up-to-date backup that can take over immediately.

Pitfall: a broken synchronization path causes the backup to perform a cold start and forces full reconvergence.
