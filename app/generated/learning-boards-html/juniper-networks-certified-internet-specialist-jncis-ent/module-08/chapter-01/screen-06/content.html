Architecture › Routing Engine Redundancy

Master and Backup RE

The primary RE handles routing and management. The backup RE stays hot and synchronizes state so it can become primary with minimal disruption.

Config sync: ensures identical configurations
Kernel sync: preserves forwarding decisions and table state
Fabric sync: aligns internal fabric and hardware state
Operational note

After enabling redundancy, confirm synchronization and test in a lab. Do not assume the backup will always have current state without verification.

Scenario
If the primary RE reboots during maintenance, a synchronized backup can take over immediately and keep forwarding intact if GRES is enabled and data-plane state is preserved.
Common mistake

Assuming dual REs alone mean automatic graceful recovery. You must enable features that synchronize state, then verify them.
