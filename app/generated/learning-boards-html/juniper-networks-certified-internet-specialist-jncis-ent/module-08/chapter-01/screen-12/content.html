Hands-on Activity › Enabling and Verifying GRES

Scenario

You have a Juniper router with RE0 and RE1. Enable GRES and verify synchronization so a switchover is graceful.

# Enter configuration mode
configure

# Enable GRES
set chassis redundancy graceful-switchover

# Commit
commit and-quit

# Verify
show chassis redundancy
show chassis routing-engine
Follow the expected output template in the chapter and confirm all Done fields and GRES enabled: Yes on both slots before further testing.
Safety checklist
  • - Run in a lab or scheduled maintenance window.
  • - Verify config/kernel/fabric Done before manual tests.
  • - Coordinate with dependent teams before production tests.
Key Takeaway

Practice the exact steps until verification is second nature; this reduces the risk of unexpected outages during real maintenance.
