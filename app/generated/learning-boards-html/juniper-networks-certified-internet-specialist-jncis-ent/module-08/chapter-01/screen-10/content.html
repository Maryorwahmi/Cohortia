Expected command output

The chapter provides a canonical show chassis redundancy output. Look for the fields shown below when you verify your setup.
Routing Engine status:
  Slot 0:
    Current state                 Master
    Election priority             Master
    Manual switchover             Off
    Commit pending                No
    Last switchover reason        None
    Configuration synchronization Done
    Kernel synchronization        Done
    Fabric synchronization        Done
    GRES enabled                  Yes
  Slot 1:
    Current state                 Backup
    Election priority             Backup
    Manual switchover             Off
    Commit pending                No
    Last switchover reason        None
    Configuration synchronization Done
    Kernel synchronization        Done
    Fabric synchronization        Done
    GRES enabled                  Yes
If any of the 'Done' lines are not present or GRES enabled shows No, the backup will not be able to perform a graceful switchover and you must correct synchronization issues.
Checklist
  • - Both slots report Configuration and Kernel synchronization as Done.
  • - GRES enabled equals Yes on both slots.
  • - Roles reported as Master and Backup are expected.
Key Takeaway

Verification output is your definitive indicator of operational readiness for graceful switchover.
