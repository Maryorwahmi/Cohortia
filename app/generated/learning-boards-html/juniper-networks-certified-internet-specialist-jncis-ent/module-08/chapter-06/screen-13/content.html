Command groups

Monitor
monitor interface, monitor traffic with matching filters, monitor log messages
Probe & Collect
ping with source/count, traceroute, request support information, show log messages
Incident checklist
  1. Verify interface state and counters.
  2. Check routing table and protocol adjacencies.
  3. Probe reachability using source-aware ping and traceroute.
  4. Use monitor commands to capture live events if needed.
  5. Collect request support information only after building a timeline.
