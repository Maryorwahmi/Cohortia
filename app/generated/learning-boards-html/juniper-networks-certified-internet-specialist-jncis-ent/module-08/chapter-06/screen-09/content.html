ping & traceroute usage

Use ping for reachability and latency tests and traceroute to discover the sequence of hops and identify where packets are lost or delayed.

user@router> ping 172.16.1.10 source 192.168.1.1 count 5
5 packets transmitted, 5 packets received, 0% packet loss
round-trip min/avg/max = 1/2/4 ms

user@router> traceroute 172.16.1.10
 1 192.168.1.254  1 ms
 2 192.168.2.1    2 ms
 3 172.16.1.10    3 ms
Guidance
  • Always set source when necessary to mirror the path taken by the client.
  • Use a count to validate intermittent problems over multiple probes.
  • Interpret traceroute results considering routers may deprioritize or block ICMP.
Key Takeaway

Ping verifies reachability; traceroute locates the failing hop. Use source options to produce meaningful results.
