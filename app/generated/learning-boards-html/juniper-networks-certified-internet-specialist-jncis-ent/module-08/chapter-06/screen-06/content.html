Inspecting the routing table

Use a focused show route with a prefix or a protocol filter to learn where a route comes from and which next-hop is installed.

user@router> show route 172.16.1.10
inet.0: 10 destinations, 10 routes (10 active)
172.16.1.0/24      *[OSPF/10] 00:01:23, metric 20
  > to 192.168.2.1 via ge-0/0/1.0

user@router> show route protocol ospf | match "172.16.1.0/24"
172.16.1.0/24      *[OSPF/10] 00:01:23, metric 20
Supporting notes
  • Active marker '*' indicates an active route used for forwarding.
  • Protocol label shows source, e.g., OSPF, BGP, or static.
  • Next-hop and outgoing interface identify the forwarding path.
Key Takeaway

If a route exists but reachability fails, compare the route's next-hop and interface state to find the broken segment.
