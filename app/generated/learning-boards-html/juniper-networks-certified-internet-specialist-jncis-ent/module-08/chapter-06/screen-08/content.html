Module 8 › Chapter 8.6 › Monitor
Real-time observation

monitor interface / monitor traffic

Use monitor commands to follow counters, packets, and log lines as they occur to capture transient events and correlate timestamps.

user@router> monitor interface ge-0/0/0
  packets-in: 100 packets-out: 120
  input-errors: 0 -> 1

user@router> monitor traffic interface ge-0/0/0 matching "host 172.16.1.10"
  12:34:56.789 IP 192.168.1.5 > 172.16.1.10: ICMP echo request
  12:34:56.790 IP 172.16.1.10 > 192.168.1.5: ICMP echo reply
Safety notes
  • Do not capture all traffic on busy ports; use matching filters.
  • Limit capture duration to avoid resource exhaustion.
  • Use monitor log messages to correlate events with timestamps.
Pro Tip

Combine monitor traffic with a focused filter and a short sampling window to capture the relevant session without impacting device performance.
