Filters

| match, | except, | find, | count

Pipe modifiers reduce output to the lines you care about or present it in a different form. They are essential for efficient troubleshooting in long outputs.

| match <pattern>
Show only lines that include the pattern.
| except <pattern>
Exclude lines matching the pattern.
| find <pattern>
Jump to the first occurrence of a pattern.
| count
Return the number of lines in the output; useful for quick sizing checks.
Examples
Practical command examples to narrow focus quickly.
show bgp summary | match "192.168.10.1"
show route protocol ospf | match "172.16.1.0/24"
show interfaces | except "up\s+up"  # find non-up interfaces
show log messages | match "ge-0/0/0" | count
Be specific with patterns and validate results; overly broad matches can hide the data you need.
Key Takeaway

Filtering is a habit: craft concise patterns and combine modifiers to focus your investigation and save time.
