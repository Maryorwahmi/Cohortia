Junos OS Troubleshooting Tools

In this lesson you will learn command patterns to diagnose link, routing, and reachability problems and how to gather data for support.

Terminal-first troubleshooting
Overview visualization
SHOW
Inspect state and configuration snapshots used to verify interfaces, routes, and protocol adjacencies.
MONITOR
Observe live events and packet captures to confirm dynamic behavior and transient faults.
TEST
Use ping and traceroute to validate reachability and identify intermediate hops when diagnosing path issues.
Coming up
Live demo: show interfaces extensive
Interpret error counters and link details.
Filtering output
Use | match and | except to find the lines you need.
Explore Key Topics
Interface checks
Use show interfaces extensive to confirm physical and logical health before higher-layer debugging.
Routing verification
show route and protocol filters show you where traffic will be sent and why.
Live monitoring
monitor commands and monitor traffic let you observe events and packets in real time when transient issues occur.
Terminal Demo Preview
user@router> show interfaces ge-0/0/0 extensive
user@router> show route 172.16.1.10
user@router> ping 172.16.1.10 source 192.168.1.1 count 5
user@router> show bgp summary | match "192.168.10.1"
user@router> monitor log messages
These commands form the core demonstration you will follow in the live coding segment, illustrating inspection, testing, and observation patterns.
