Module 8 › Chapter 8.6 › Interface Views
Quick view

show interfaces terse

A compact table of every interface showing administrative and link status. Use this for fast triage across many ports.

user@router> show interfaces terse
Interface               Admin Link Proto    Local
ge-0/0/0                up    up   inet     192.168.1.1/24
ge-0/0/1                up    down
When many interfaces exist, terse helps locate obvious administratively down or physically down ports quickly.
Deep view

show interfaces <name> extensive

Shows media, link details, error counters, MTU, VLAN tagging, and timestamps — use when you suspect physical or link-layer problems.

user@router> show interfaces ge-0/0/0 extensive
Physical link is Up
Input errors: 23, Output errors: 0
Last flapped: 00:05:12
If input errors are incrementing, suspect cables, optics, or duplex issues before assuming routing problems.
Example
Terse shows the port is up. Extensive reveals 1000 input errors, indicating a physical fault to investigate.
Pro Tip
Start with terse, then escalate to extensive on the affected interface for efficiency.
Common mistake
Relying only on terse can hide counters that explain intermittent packet loss.
