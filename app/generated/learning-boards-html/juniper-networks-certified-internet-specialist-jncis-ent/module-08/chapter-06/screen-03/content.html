Mnemonic cards
SEE
show commands
Snapshot device state: interfaces, routes, protocol adjacencies.
WATCH
monitor commands
Live events and logs for timing-sensitive problems.
PROBE
ping & traceroute
Test reachability and trace path hops with source options.
BUNDLE
request support information
Collect a complete snapshot for support analysis.
Common mistakes
  • Assuming a route without checking show route or protocol filters.
  • Capturing full traffic on busy ports without match filters, which can affect performance.
Quick checklist
  1. See: show interfaces / show route
  2. Watch: monitor log messages
  3. Probe: ping/traceroute with source
  4. Bundle: request support information
