Module 8 › Chapter 8.6 › Protocol Checks
OSPF

show ospf neighbor

Shows neighbor IPs, state, and adjacency timings. Full adjacency is required to learn LSA-based routes.

user@router> show ospf neighbor
Neighbor ID     Pri State   Dead Time   Address         Interface
192.0.2.2         1 Full    00:00:33     192.168.2.2     ge-0/0/1.0
If the state is not Full, LSAs and routes may not be exchanged; check timers and authentication.
BGP

show bgp summary

Summarizes BGP peers, session state, and prefix counts so you can spot missing or flapping peers.

user@router> show bgp summary
Peer             AS    State    PfxRcd
192.168.10.1     65001 Estab    120
If BGP is not Established, no routes from that neighbor will be installed and prefix counts will be zero.
Example
Missing OSPF routes; show ospf neighbor reveals neighbor in 2-way state instead of Full, indicating adjacency did not complete.
Misconception
Physical link up ≠ protocol up. Protocol state can fail for configuration mismatches even when the link is ready.
Key Takeaway
Always check protocol neighbor and summary outputs to confirm the actual exchange of routes.
