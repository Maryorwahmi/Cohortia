Module 8 › Chapter 8.6 › Show Commands
Definition

show — read device state

Show commands return a static snapshot of operational data and are used to confirm link status, error counters, routing, and protocol states before any corrective action.

Key examples
show interfaces <name> extensive
Detailed counters, link speed, duplex, and media info — essential for Layer 1/2 diagnosis.
show interfaces terse
Concise status of all interfaces for a quick health check.
show route [prefix] | show bgp summary
Inspect routing table entries and BGP peer states to troubleshoot Layer 3 reachability.
Key Takeaway

Always verify device state with show before making changes. Snapshots reveal counters and states that explain symptoms.

Terminal examples
user@router> show interfaces ge-0/0/0 extensive
Physical interface: ge-0/0/0, Enabled, Physical link is Up
  Link-level type: Ethernet, MTU: 1514
  Input errors: 0, Output errors: 0
  Last flapped: 2d 04:12:33

user@router> show interfaces terse
Interface               Admin Link Proto    Local                 Remote
ge-0/0/0                up    up   inet     192.168.1.1/24
ge-0/0/1                up    down

user@router> show route 172.16.1.10
inet.0: 10 destinations, 10 routes (10 active)
172.16.1.0/24      *[OSPF/10] 00:01:23, metric 20
  > to 192.168.2.1 via ge-0/0/1.0
Concrete example
If the interface shows input errors incrementing, suspect a physical issue before blaming routing.
Misconception
A successful ping does not prove proper device configuration; always confirm routes and interfaces with show commands.
