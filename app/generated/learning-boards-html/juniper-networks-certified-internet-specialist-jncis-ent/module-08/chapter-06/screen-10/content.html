Module 8 › Chapter 8.6 › Diagnostics & Logs
Collect

request support information

Packages device operational data into a file for support. Use when an incident requires deeper analysis by vendor engineers.

Note
Ensure you review for sensitive data and follow your organization's procedures before sending the bundle.
Inspect

show log messages

Read system logs to find events that correlate with user-reported issues and construct a timeline of what changed and when.

user@router> show log messages | match "ge-0/0/0"
Oct 10 12:03:21 router mgd[12345]: Interface ge-0/0/0: link down
Oct 10 12:03:25 router mgd[12345]: Interface ge-0/0/0: link up
Concrete workflow
1) show log messages to get timestamps, 2) show interfaces extensive for counters, 3) request support information if needed for external analysis.
Misconception
Assuming request support information will explain the issue without you building the timeline first delays diagnosis.
Key Takeaway
Collect a bundle for support but build a local timeline from logs and state before submitting it.
