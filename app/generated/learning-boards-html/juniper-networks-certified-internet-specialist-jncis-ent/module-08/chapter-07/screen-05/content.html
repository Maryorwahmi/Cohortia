Definition monitor traffic syntax
Command examples
# Capture all ICMP traffic on ge-0/0/0
monitor traffic interface ge-0/0/0 matching "icmp"

# Capture TCP traffic to/from host 10.0.0.1 on port 80
monitor traffic interface ge-0/0/0 matching "host 10.0.0.1 and tcp port 80"

# Save capture to a file for later analysis
monitor traffic interface ge-0/0/0 matching "host 10.0.0.1" no-resolve write-file /var/tmp/capture.pcap
Practical guidance
  • Always begin with the tightest possible matching expression to limit output.
  • Use no-resolve to prevent DNS lookups and speed up raw output.
  • Prefer write-file and then analyze the pcap in Wireshark for complex protocols.
  • Confirm the interface where the traffic is expected; wrong interface yields no data.
Common mistake

Running an unfiltered capture on a busy interface can flood the CLI and the device. Restrict first, expand only if needed.

Key Takeaway

Compose specific matching filters and save to pcap for offline analysis. Use no-resolve to keep output quick and raw.
