Hands-on Activity HTTP troubleshooting workflow
Step-by-step instructions
  1. Start CLI on the router.
  2. Run a restricted capture and write to a pcap file.
  3. From the client, generate a short HTTP request to the server.
  4. Stop the capture and copy the pcap to your workstation.
  5. Open in Wireshark and inspect handshakes, retransmits, and HTTP payloads.
Starter command
monitor traffic interface ge-0/0/0 matching "host 192.168.1.100 and tcp port 80" no-resolve write-file /var/tmp/web_traffic.pcap
# Generate HTTP request: curl http://192.168.1.100
# Stop capture with Ctrl+C, then transfer the pcap for analysis
Troubleshooting checks

If you see no packets: verify interface and client IP. If handshake starts but stalls: check for firewall rules or asymmetric routing.

Key Takeaway

Work through a tight capture, test, save, and analyze loop to convert packet evidence into corrective action efficiently.
