Process Flow How to build matching filters
Filter examples
Use these expressions as building blocks:
  • icmp
  • host 10.0.0.1 and tcp port 80
  • tcp port 179
  • ip proto 89
Process
  1. Identify suspected source/destination.
  2. Pick protocol or port that defines the traffic.
  3. Run a short, restricted capture and generate test traffic.
  4. If needed, broaden filters incrementally.
Concrete scenario

You suspect SSH failures to 10.0.0.5. Start with matching "host 10.0.0.5 and tcp port 22". If nothing appears, verify the interface and client IP before widening the filter.

Common mistake

Widening filters too quickly creates noise. Instead, confirm interface and client IP if your strict filter returns nothing.

Key Takeaway

Build filters from specific to general. Verify interfaces and hosts if a strict filter yields no packets.
