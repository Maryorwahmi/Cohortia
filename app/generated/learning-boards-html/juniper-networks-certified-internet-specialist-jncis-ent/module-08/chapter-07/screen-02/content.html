Learning Objectives
Build skills for packet capture, filtering, saving, and interpretation.

Operate monitor traffic

Start and stop targeted packet captures and understand command behaviour in Junos. This matters because precise capture avoids CLI overload and gives reliable evidence.

VERIFIED COMPETENCY MILESTONE
02
Apply advanced filters

Compose matching expressions for host, port and protocol to isolate traffic. This reduces noise and speeds diagnosis for specific applications.

VERIFIED COMPETENCY MILESTONE
03
Save and analyze captures

Write capture output to a .pcap file and open in Wireshark for detailed decoding. This matters when payload inspection or protocol reassembly is needed.

VERIFIED COMPETENCY MILESTONE
04
Interpret packet and flow data

Read captures for handshakes, drops, and retransmissions, and read flow records for top talkers and anomalies. This skill ties evidence to corrective actions like firewall or routing fixes.
