Packet Capture and Flow Monitoring
Inspect packets with monitor traffic and aggregate flows with J-Flow for different troubleshooting scales.
In this lesson

Learn targeted packet capture, safe CLI practices, saving pcap files, configuring J-Flow sampling, and interpreting both packet and flow data to diagnose issues.

Coming up

Examples include capturing HTTP traffic to a web server, sampling rate choices, and a hands-on scenario to reproduce and analyze a failed web request.

Core idea

Use packet capture for deep, short investigations and flows for scalable, long-term visibility.

Concept Snapshot
Packet vs Flow
Packet Capture

Full packet headers and payload for each observed packet. Best for protocol debugging, handshakes, and firewall drop analysis.

Example

See a missing SYN-ACK during a TCP handshake to diagnose why a session never starts.

Flow Monitoring

Aggregated flow records derived from sampled packets. Best for trend detection, top talkers, and long-term security monitoring.

Example

Spot a sudden spike in traffic from one host indicating a misbehaving application or attack.
