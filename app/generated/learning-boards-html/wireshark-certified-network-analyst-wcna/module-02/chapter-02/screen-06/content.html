The `host` Primitive

  • •Filters traffic involving a specific IP address.
  • •Captures both source and destination traffic by default.
  • •Essential for isolating a single device's network activity.

Common Mistake: `ip.addr`

Do not confuse the BPF `host` primitive with the Wireshark display filter `ip.addr`. `host` is for capture filters (pre-capture), while `ip.addr` is for display filters (post-capture). Using `ip.addr` in a capture filter will result in an error.

BPF Host Filter Examples
# Capture all traffic involving 192.168.1.100
host 192.168.1.100

# Capture traffic originating FROM 192.168.1.100
src host 192.168.1.100

# Capture traffic destined TO 192.168.1.100
dst host 192.168.1.100
Key Takeaway

Use `host` for bidirectional filtering, `src host` for outgoing, and `dst host` for incoming traffic related to a specific IP address.
