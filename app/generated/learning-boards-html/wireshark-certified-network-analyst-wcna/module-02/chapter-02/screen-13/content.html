Key Concepts

Essential terms to remember from this chapter.

Capture Filter

A filter applied *before* packets are saved, reducing the volume of captured data at the source using BPF syntax.

Display Filter

A filter applied *after* packets are captured, used for analyzing existing trace files by hiding packets from view.

Berkeley Packet Filter (BPF)

A low-level, efficient filtering language used for capture filters, evaluated by the kernel for high performance.

Mastering these filtering mechanisms is key to efficient and targeted network analysis.
