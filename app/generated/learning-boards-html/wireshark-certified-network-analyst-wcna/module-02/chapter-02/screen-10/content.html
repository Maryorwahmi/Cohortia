The `or` Operator

  • •Requires at least one of the specified conditions to be true.
  • •Used to capture multiple types of traffic in a single filter.
  • •Ideal for inclusive filtering when investigating related but distinct activities.

Scenario: Multi-Protocol Diagnostics

When diagnosing general network connectivity or name resolution issues, you might need to observe both DNS queries and ICMP messages. The `or` operator allows you to capture both types of traffic simultaneously, providing a comprehensive view of potential problems without running multiple captures.

BPF `or` Operator Example
# Capture all DNS traffic (UDP port 53)
# OR all ICMP traffic

udp port 53 or icmp
Key Takeaway

Use `or` to capture traffic matching any of the specified conditions, useful for broad but targeted investigations.
