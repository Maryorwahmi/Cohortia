Protocol Primitives

  • •Directly filter for specific network protocols.
  • •Useful for diagnosing issues at different network layers.
  • •Examples include `arp` for discovery and `icmp` for diagnostics.

Real-World Use Cases

Filtering for `arp` packets helps identify duplicate IP addresses or network discovery failures. Filtering for `icmp` is essential when using `ping` to test connectivity or when diagnosing routing problems, as it shows error messages and reachability status.

BPF Protocol Filter Examples
# Capture all Address Resolution Protocol (ARP) packets
arp

# Capture all Internet Control Message Protocol (ICMP) packets
icmp

# Capture all TCP packets
tcp

# Capture all UDP packets
udp
Key Takeaway

Use protocol primitives like `arp` and `icmp` to target specific network layer communications for diagnostic purposes.
