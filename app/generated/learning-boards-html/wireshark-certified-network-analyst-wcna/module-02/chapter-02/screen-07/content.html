The `port` Primitive

  • •Filters traffic by TCP or UDP port number.
  • •Crucial for focusing on specific applications or services.
  • •Can be combined with `tcp` or `udp` for explicit protocol filtering.

Why Protocol Specificity Matters

Explicitly stating `tcp` or `udp` before the port number, like `tcp port 80`, ensures you're capturing exactly what you intend. This avoids ambiguity and prevents capturing unintended traffic if a different protocol happens to use the same port number for a non-standard service.

BPF Port Filter Examples
# Capture all traffic on port 80 (HTTP)
port 80

# Capture all traffic on port 443 (HTTPS)
port 443

# Capture only TCP traffic on port 80
tcp port 80

# Capture only UDP traffic on port 53 (DNS)
udp port 53
Key Takeaway

Use `port` to filter by service, and add `tcp` or `udp` for precise protocol-specific port filtering.
