`tshark`: Wireshark's Terminal Counterpart

Capturing packets without the graphical interface

Purpose of `tshark`

It's the command-line version of Wireshark, enabling packet capture and analysis directly from the terminal.

Key Use Cases

Ideal for remote servers without a GUI, automating captures in scripts, or handling very large data volumes efficiently.

Key Takeaway

`tshark` extends Wireshark's capabilities to headless environments and automated workflows, making it a versatile tool for network professionals.

Basic `tshark` Capture

Capturing traffic on an interface and saving to a file.

# Basic capture command
sudo tshark -i eth0 -w my_capture.pcap

# Explanation:
sudo: Run with root/admin privileges
tshark: The command-line tool
-i eth0: Specify interface 'eth0'
-w my_capture.pcap: Write output to 'my_capture.pcap'
Pro Tip

Press Ctrl+C to stop a running tshark capture.
