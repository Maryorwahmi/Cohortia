Troubleshooting Tips

Confirming Your `tshark` Capture

Ensuring successful data collection and identifying interfaces

Stopping `tshark`

Press `Ctrl+C` in the terminal to gracefully stop a running `tshark` capture.

Verifying Capture File

Open the `.pcap` file in Wireshark GUI to visually confirm captured packets and their relevance.

Key Takeaway

Always verify `tshark` captures and use `tshark -D` or system commands to ensure correct interface selection and prevent errors.

Interface Identification Commands

Ensure you're using the correct interface name.

# List all interfaces with tshark
tshark -D

# Linux: List network interfaces
ip a

# Windows: List network interfaces
ipconfig
Common Issue

An empty capture file often indicates an incorrect interface name or insufficient permissions (missing sudo).
