Key Concept

Promiscuous Mode: Seeing All Traffic

Overriding default adapter behavior for comprehensive analysis

Default Behavior (Non-Promiscuous)

Adapters only process packets addressed to their MAC, broadcast, or subscribed multicast traffic. Other traffic is ignored.

Promiscuous Mode Activated

The adapter captures ALL traffic it sees on the network segment, regardless of the destination MAC address.

Key Takeaway

Promiscuous mode is essential for comprehensive network analysis, but it also has security and performance implications.

Adapter Modes Comparison

How your network adapter processes traffic.

Non-Promiscuous

Filters traffic, only processes intended packets.

Promiscuous

Captures all traffic, regardless of destination.

Security Implication

Enabling promiscuous mode can sometimes trigger security alerts as it's also used by malicious actors.
