Key Concepts

Essential terms to remember

Packet Capture (Pcap)

A recording of network traffic, storing individual data packets for analysis.

Network Interface

The hardware component (e.g., Ethernet, Wi-Fi) through which a computer connects to a network.

Promiscuous Mode

An adapter mode where it captures all traffic it sees, regardless of destination MAC address.

These concepts are the building blocks for effective network analysis.
