Key Concepts

Reinforcing your understanding

Non-Promiscuous Mode

The default adapter mode, processing only packets explicitly addressed to itself, broadcast, or subscribed multicast.

`tshark`

The command-line version of Wireshark, used for capturing and analyzing network traffic from the terminal.

Port Mirroring / Tap

Techniques to duplicate traffic on a switched network to a monitoring port for full capture visibility.

These advanced concepts enable comprehensive network analysis in diverse environments.
