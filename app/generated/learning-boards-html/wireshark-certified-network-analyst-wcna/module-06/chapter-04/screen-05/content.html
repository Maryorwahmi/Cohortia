Key Metric

Measuring Responsiveness with RTT

Round Trip Time (RTT) is the time for a packet to travel from source to destination and back. High RTT directly impacts application responsiveness.

  • •Wireshark calculates RTT for TCP connections (e.g., SYN to SYN-ACK).
  • •Add tcp.analysis.ack_rtt as a custom column for per-segment RTT.
Concrete Example

A web application feels slow. Wireshark shows tcp.analysis.ack_rtt values consistently above 200ms between your client and the server, indicating significant network latency.

Key Takeaway

Consistently high RTT values are a clear sign of network congestion, geographical distance, or slow intermediate devices, directly impacting user experience.
