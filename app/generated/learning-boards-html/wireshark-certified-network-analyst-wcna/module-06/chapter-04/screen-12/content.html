Key Concepts

Essential Terms for Performance Analysis

Round Trip Time (RTT)

The time for a signal to travel from sender to receiver and back, indicating network latency.

Retransmission

Re-sending a TCP segment due to loss or unreceived acknowledgment, indicating packet loss.

TCP Window Size

Advertised buffer space for incoming data, crucial for TCP flow control and throughput.

Summary Takeaway

Mastering these core concepts allows you to effectively diagnose and troubleshoot network performance issues by understanding latency, packet loss, and data flow control.
