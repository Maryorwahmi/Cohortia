Practical Application of 'Decode As'

Follow these steps to correctly interpret traffic on non-standard ports using the 'Decode As' feature.

1
Capture Traffic

Start a Wireshark capture and generate traffic on the non-standard port (e.g., HTTP on 8080).

2
Select Packet

In the Packet List pane, right-click on any TCP packet using the non-standard port.

3
Choose 'Decode As...'

From the context menu, select the 'Decode As...' option.

4
Configure Protocol

In the dialog, ensure 'TCP port(s)' is selected, enter the port (e.g., 8080), and choose 'HTTP' from the protocol list. Click OK.

Key Takeaway

The 'Decode As' feature provides an immediate and effective way to correct Wireshark's protocol interpretation for non-standard traffic.
