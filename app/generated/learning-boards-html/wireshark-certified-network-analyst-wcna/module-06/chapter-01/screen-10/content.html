Lua Dissector Development

Master the practical steps for registering your dissector, extracting data, and ensuring efficient, reliable performance.

1
Script Placement

Place your .lua files in Wireshark's personal plugins directory for automatic loading on startup.

2
Port Registration

Explicitly register your dissector to a specific port using DissectorTable.get("udp.port"):add(port, protocol_object).

3
Data Extraction & Display

Use tvbuf:range(offset, length) to extract bytes and tree:add(field, value) to display parsed data.

Key Takeaway

Correct registration and efficient data handling are crucial for functional and performant Lua dissectors; always test thoroughly.

-- Example: Registering and extracting data

-- Assume p_myproto and its fields are defined as before

-- Get the UDP port table
local my_udp_port_table = DissectorTable.get("udp.port")

-- Register our custom protocol for UDP port 12345
my_udp_port_table:add(12345, p_myproto)

-- The dissector function (simplified for focus)
function p_myproto.dissector(tvbuf, pinfo, tree)
  pinfo.cols.protocol = p_myproto.name
  local subtree = tree:add(p_myproto, tvbuf)

  local offset = 0
  -- Extract a 2-byte command code
  local command_range = tvbuf:range(offset, 2)
  subtree:add(f_command_code, command_range)
  offset = offset + 2

  -- Extract a 4-byte length field
  local length_range = tvbuf:range(offset, 4)
  subtree:add(f_length, length_range)
  offset = offset + 4

  -- Get the actual length value to extract the payload dynamically
  local payload_len = length_range:uint()
  if payload_len > 0 and offset + payload_len <= tvbuf:len() then
    subtree:add(f_payload, tvbuf:range(offset, payload_len))
  else
    -- Handle cases where payload_len might be invalid or exceed buffer
    subtree:add(f_payload, tvbuf:range(offset, tvbuf:len() - offset)):set_text("Malformed Payload (length mismatch)")
  end
end

print("Lua dissector for UDP 12345 registered and ready!")
