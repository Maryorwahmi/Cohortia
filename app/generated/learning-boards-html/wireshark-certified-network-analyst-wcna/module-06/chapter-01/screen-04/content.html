The Role of Protocol Dissectors in Wireshark

Dissectors are specialized components that interpret raw network traffic into structured, human-readable protocol information.

How Dissection Works
  • Raw Packet Capture: Wireshark captures raw bytes from the network interface.
  • Transport Layer Identification: Identifies TCP/UDP based on port numbers (e.g., TCP 80, UDP 53).
  • Application Layer Assumption: Maps common ports to known protocols (e.g., TCP 80 to HTTP, TCP 443 to TLS).
  • Structured Interpretation: Dissectors break down the payload into fields, headers, and values.
Key Takeaway

Dissectors are fundamental to Wireshark's ability to provide deep packet inspection, transforming raw data into meaningful protocol details.

Real-World Example

When you browse a website, Wireshark's HTTP dissector automatically parses the TCP traffic on port 80 or 443, showing you the GET requests, HTTP headers, and server responses in a clear, organized tree structure.
