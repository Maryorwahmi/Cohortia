Building a Basic Lua Dissector

Learn the fundamental components required to create a custom protocol dissector using Lua.

1
Define Protocol

Use Proto("Name", "Description") to create a new protocol object for your custom traffic.

2
Define Fields

Use ProtoField.type("proto.field", "Label", FT_TYPE) to define individual fields within your protocol (e.g., command code, length).

3
Register Dissector

Associate your new protocol with a specific transport layer port (e.g., my_udp_port_table:add(12345, p_myproto)).

Key Takeaway

The core of a Lua dissector involves defining the protocol, its fields, and registering it to a specific port for Wireshark to use.

-- 1. Define a new protocol
local p_myproto = Proto("MyCustomProtocol", "My Custom Protocol Description")

-- 2. Define fields for the protocol
local f_command_code = ProtoField.uint16("myproto.command", "Command Code", base.HEX)
local f_length = ProtoField.uint32("myproto.length", "Payload Length", base.DEC)
local f_payload = ProtoField.bytes("myproto.payload", "Payload Data")

-- Add fields to the protocol
p_myproto.fields = { f_command_code, f_length, f_payload }

-- 3. The dissector function
function p_myproto.dissector(tvbuf, pinfo, tree)
  -- Set the protocol column in the packet list
  pinfo.cols.protocol = p_myproto.name

  -- Create a subtree for our protocol details
  local subtree = tree:add(p_myproto, tvbuf)

  -- Extract and add fields
  local offset = 0
  subtree:add(f_command_code, tvbuf:range(offset, 2))
  offset = offset + 2
  subtree:add(f_length, tvbuf:range(offset, 4))
  offset = offset + 4
  
  -- Assuming payload length is in the field, extract it
  local payload_len = tvbuf:range(2, 4):uint()
  subtree:add(f_payload, tvbuf:range(offset, payload_len))
end

-- 4. Register the dissector for a specific UDP port
local my_udp_port_table = DissectorTable.get("udp.port")
my_udp_port_table:add(12345, p_myproto)

print("MyCustomProtocol Lua dissector loaded!")
