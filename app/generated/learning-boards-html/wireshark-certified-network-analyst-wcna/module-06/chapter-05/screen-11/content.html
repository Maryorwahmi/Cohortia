Extracting Unique User Agents with TShark and Unix Tools

Discover how to identify and count unique HTTP User-Agent strings for web traffic analysis.

Workflow for User-Agent Analysis

  • Filter HTTP User-Agent: Use -Y "http.user_agent" to isolate relevant packets.
  • Extract Field: Use -T fields -e http.user_agent to get the raw strings.
  • Sort and Uniq: Pipe to sort | uniq to get a clean list of unique agents.
Key Takeaway

Analyzing unique User-Agent strings with TShark and Unix tools provides valuable insights into client behavior and can help detect anomalies in web traffic.

user@host:~$_
# Extract unique HTTP User-Agents
tshark -r web_traffic.pcapng -Y "http.user_agent" -T fields -e http.user_agent | sort | uniq

# Example Output:
Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36
Mozilla/5.0 (iPhone; CPU iPhone OS 17_4_1 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/17.4.1 Mobile/15E148 Safari/604.1
curl/7.81.0
This command extracts, sorts, and lists all unique User-Agent strings from HTTP traffic in a capture file.
