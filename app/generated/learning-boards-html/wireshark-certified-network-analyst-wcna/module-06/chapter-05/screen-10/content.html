Combining TShark with Unix Tools: Counting Unique IPs

Leverage standard Unix tools to perform advanced data processing on TShark output.

The Power of Pipelining

  • TShark as Data Source: Extracts raw, structured data from PCAP files.
  • Unix Tools: sort, uniq, grep, awk for manipulation.
  • Pipelining (`|`): Connects commands, feeding output of one as input to the next.
Key Takeaway

Pipelining TShark output to Unix tools like sort and uniq enables powerful, multi-stage data processing for advanced network analysis tasks.

user@host:~$_
# Count unique source IP addresses
tshark -r my_capture.pcapng -T fields -e ip.src | sort | uniq -c | sort -nr

# Example Output:
  150 192.168.1.10
   80 172.16.1.50
   25 10.0.0.1
This command chain extracts source IPs, sorts them, counts unique occurrences, and then sorts by count in descending order.

Misconception: uniq without sort

A common mistake is using uniq directly without first piping to sort. uniq only removes *adjacent* duplicate lines, so unsorted input will not yield correct unique counts.
