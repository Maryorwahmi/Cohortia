Advanced Field Extraction with Display Filters

Combine field extraction with Wireshark-style display filters for highly targeted data.

Using Display Filters (`-Y`)

  • -Y <display_filter>: Applies a Wireshark display filter to the packets.
  • Post-Capture Filtering: Filters packets after they are read from a file or captured.
  • Targeted Extraction: Ensures only relevant packets are processed for field extraction.
Key Takeaway

Using -Y with display filters provides granular control over which packets are processed for field extraction, leading to more precise and cleaner data output.

user@host:~$_
# Extract HTTP host and URI for HTTP requests
tshark -r web_traffic.pcapng -Y "http.request" -T fields -e http.host -e http.request.uri

# Example Output:
www.example.com /index.html
api.example.com /data?id=123
cdn.example.com /styles/main.css
This command filters for HTTP requests and then extracts specific HTTP fields, providing focused web traffic insights.

Capture vs. Display Filters

Remember: Capture filters (-f) reduce the size of the capture file, while display filters (-Y) narrow down the view of packets within an existing file or live stream.
