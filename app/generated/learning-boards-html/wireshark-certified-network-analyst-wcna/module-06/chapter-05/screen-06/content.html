Capture Filtering

Applying Capture Filters and Saving Output

Refine your live captures by applying filters and saving packets to a file.

Key Options

  • -f <filter>: Applies a BPF (Berkeley Packet Filter) capture filter.
  • -w <file>: Writes captured packets to a specified output file (e.g., .pcapng).
  • BPF Syntax: Capture filters use a specific syntax (e.g., port 80, host 192.168.1.1).
Key Takeaway

Combining capture filters with file saving allows for efficient, targeted data collection for later analysis, especially in automated or remote scenarios.

user@host:~$_
# Capture HTTP traffic on eth0 and save to file
tshark -i eth0 -f "port 80" -w http_capture.pcapng

# Verify file creation
ls -lh http_capture.pcapng

# Expected Output:
-rw-r--r-- 1 user user 1.5M May 15 10:30 http_capture.pcapng
This command captures only traffic on port 80 and saves it to a file, preventing your terminal from being flooded with output.

Common Mistake: Filter Syntax

Remember that capture filters (-f) use BPF syntax, which is different from Wireshark's display filter syntax. Forgetting this can lead to syntax errors or unintended capture results.
