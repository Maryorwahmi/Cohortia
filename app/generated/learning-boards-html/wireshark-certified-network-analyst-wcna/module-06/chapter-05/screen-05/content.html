Live Capture

Performing Basic Live Captures

Initiate real-time packet captures directly from your terminal using TShark.

Key Commands & Concepts

  • -i <interface>: Specifies the network interface to capture from.
  • Interface Identification: Use tshark -D, ip a (Linux), or ipconfig (Windows) to find interface names.
  • Real-time Output: TShark displays packet summaries directly in the terminal as they are captured.
Key Takeaway

The tshark -i <interface> command is your entry point for real-time network traffic observation and immediate diagnostics.

user@host:~$_
# Basic live capture on eth0
tshark -i eth0

# Example Output (truncated)
1   0.000000 192.168.1.10 -> 8.8.8.8    DNS 74 Standard query 0x1234 A www.google.com
2   0.000050 8.8.8.8    -> 192.168.1.10 DNS 74 Standard query response 0x1234 A 142.250.190.100
3   0.000100 192.168.1.10 -> 142.250.190.100 TCP 66 54321 > 80 [SYN] Seq=0 Win=64240 Len=0
...
This command will continuously display packet summaries until you stop it with Ctrl+C.

Pro Tip: List Interfaces

If you're unsure of your network interface names, run tshark -D. This command will list all available interfaces that TShark can capture from, along with their numerical identifiers and descriptions.
