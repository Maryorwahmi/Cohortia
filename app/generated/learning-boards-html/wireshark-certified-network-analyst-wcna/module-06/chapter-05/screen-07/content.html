Capture Management

Controlling Capture Size and Duration

Manage the size and duration of your TShark captures to prevent excessive data collection.

Limiting Capture Parameters

  • -c <num_packets>: Stops capture after a specified number of packets.
  • -a duration:<seconds>: Stops capture after a specified time duration.
  • Resource Management: Prevents large files, saving disk space and improving analysis performance.
Key Takeaway

Always use capture limits (-c or -a duration) to ensure your TShark captures are manageable and don't exhaust system resources.

user@host:~$_
# Capture 100 packets and save
tshark -i eth0 -c 100 -w small_capture.pcapng

# Capture for 60 seconds and save
tshark -i eth0 -a duration:60 -w one_minute_capture.pcapng

# Verify file size (example)
ls -lh small_capture.pcapng
These commands demonstrate how to limit captures by packet count or time, ensuring efficient resource use.

Pro Tip: Ring Buffers

For continuous monitoring without filling up disk space, TShark also supports ring buffer captures using options like -b filesize:<size> and -b files:<num> to rotate capture files.
