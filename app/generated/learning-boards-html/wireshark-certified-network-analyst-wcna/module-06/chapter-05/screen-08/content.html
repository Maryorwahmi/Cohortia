Data Extraction

Reading PCAP Files and Basic Field Extraction

Extract specific protocol fields from saved capture files for automated reporting.

Essential Options for Extraction

  • -r <file>: Specifies the input PCAP file to read.
  • -T fields: Sets the output format to display specific fields.
  • -e <field_name>: Extracts the value of a specified protocol field.
  • -E separator=<char>: Customizes the output field separator (default is tab).
Key Takeaway

Field extraction with -r, -T fields, and -e is fundamental for transforming raw packet data into structured, machine-readable output for automation.

user@host:~$_
# Extract source IP, destination IP, and protocol
tshark -r http_capture.pcapng -T fields -e ip.src -e ip.dst -e _ws.col.Protocol

# Example Output:
192.168.1.10    172.16.1.100    TCP
172.16.1.100    192.168.1.10    TCP
192.168.1.10    172.16.1.100    HTTP
This command extracts specific fields, providing a clean, tabular output suitable for further processing.

Pro Tip: Find Field Names

If you're unsure of a field's exact name, use tshark -G fields to list all available fields and their descriptions. This is invaluable for precise data extraction.
