Key Concepts

Essential Takeaways: Part 1

Network Forensics

The process of capturing, recording, and analyzing network traffic to investigate security incidents, identify attackers, and reconstruct events.

Export Objects

A Wireshark feature that allows users to extract and save files (e.g., images, executables) transferred over specific application protocols within a capture file.

Follow TCP Stream

A Wireshark feature that isolates and reassembles all packets belonging to a single TCP connection, displaying the application-level data exchange in readable text.
