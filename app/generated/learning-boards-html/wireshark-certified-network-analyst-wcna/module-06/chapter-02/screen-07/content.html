How it Works

  • Isolates all packets of a specific TCP connection.
  • Reassembles data payloads into a continuous stream.
  • Displays client data (e.g., red) and server data (e.g., blue) separately.
Example Use Case

Understand an attacker's commands to a compromised server.

Key Takeaway

'Follow TCP Stream' is essential for reconstructing the full application-level dialogue, providing a clear narrative of network interactions during an incident.
