Key Concepts

Reinforce your understanding of critical security analysis terms.

Reconnaissance

The initial phase of an attack where an attacker gathers information about a target, often involving port scanning or vulnerability scanning.

Indicators of Compromise (IOCs)

Forensic artifacts found on a network or operating system that indicate a computer intrusion, such as suspicious IPs, domains, or traffic patterns.

Command and Control (C2)

The communication channel used by an attacker to remotely control compromised systems (bots or implants) and issue commands.

Summary Takeaway

Understanding reconnaissance, IOCs, and C2 is fundamental for effectively using Wireshark to detect and analyze malicious network traffic.
