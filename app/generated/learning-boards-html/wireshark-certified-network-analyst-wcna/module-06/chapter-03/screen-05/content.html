Identifying Port Scans

Detecting initial reconnaissance activities by analyzing SYN packets.

Reconnaissance Phase

Port scans are often the first step attackers take to map a network's vulnerabilities.

SYN Scan Mechanics

Attackers send SYN packets to many ports, looking for SYN-ACK responses to identify open services.

Wireshark Filter for SYN Scans
tcp.flags.syn == 1 and tcp.flags.ack == 0

This filter isolates initial TCP SYN packets, which are connection requests. When many such packets originate from a single source to various destinations without corresponding ACKs, it strongly indicates a scan.

Key Takeaway

Monitoring for a high volume of SYN-only packets from a single source to diverse destination ports is a primary method for detecting active port scanning.
