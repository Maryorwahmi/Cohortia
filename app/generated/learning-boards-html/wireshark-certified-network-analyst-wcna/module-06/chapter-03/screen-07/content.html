Unmasking C2 Beaconing

Identifying malware communication patterns to command-and-control servers.

Malware's Lifeline

C2 communication allows attackers to control compromised systems remotely.

Beyond Signatures

Focus on behavioral patterns rather than just known malware signatures.

Key C2 Beaconing Characteristics

Periodic Connections: Fixed intervals (e.g., every 60s) to the same external IP.

Unusual Ports/Protocols: Non-standard ports (8080, 443 for disguise) or DNS/ICMP tunneling.

Low-Volume, High-Frequency: Small packet sizes, but very frequent communication.

Unusual Payload Sizes: Consistent, small, or oddly sized data transfers.

Key Takeaway

C2 beaconing often exhibits distinct, repetitive traffic patterns that can be identified by analyzing connection frequency, ports, protocols, and payload characteristics.
