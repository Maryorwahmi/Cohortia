Spotting Brute-Force Login Attempts

Identifying repeated authentication failures to services like SSH, FTP, or RDP.

Repeated Guesses

Attackers systematically try many credentials to gain unauthorized access.

High Frequency

A large number of login attempts from a single source over a short period is suspicious.

Wireshark Filters for Login Failures
# SSH Authentication Failures:tcp.port == 22 and ssh.auth_attempt.status == 0# FTP Login Failures:tcp.port == 21 and ftp.response.code == 530# RDP Connection Failures (example, may vary):tcp.port == 3389 and rdp.pduType == 0x01 # Connection Confirm PDU with error

These filters help pinpoint specific authentication failure messages within common protocols, indicating a brute-force attempt.

Key Takeaway

Monitoring for a high volume of specific authentication failure codes or patterns is key to detecting brute-force attacks against network services.
