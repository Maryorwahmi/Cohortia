Identifying Data Exfiltration

Spotting unauthorized data transfers from your network using Wireshark.

Theft of Information

Attackers steal sensitive data, often to external cloud storage or FTP servers.

Unusual Outbound Traffic

Look for large uploads or transfers to unexpected external destinations.

Wireshark Tools for Exfiltration Detection
# Identify hosts with high data transfer:Statistics > Conversations > TCP/UDP# Filter for FTP file uploads:ftp.request.command == "STOR"# Filter for large HTTP POST requests (e.g., > 1MB):http.request.method == "POST" and http.content_length > 1000000

Combining conversation statistics with specific protocol filters helps pinpoint hosts and methods used for data exfiltration.

Key Takeaway

Leverage Wireshark's conversation statistics and targeted filters for file transfer protocols to detect and investigate suspicious data exfiltration attempts.
