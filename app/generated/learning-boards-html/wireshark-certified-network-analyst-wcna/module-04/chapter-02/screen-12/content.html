`traceroute` Function

Maps the network path to a destination by sending packets with incrementally increasing Time-to-Live (TTL) values.

Key ICMP Messages
  • Time-to-live exceeded: ICMP Type 11, Code 0. Sent by routers when TTL reaches zero.
  • Destination Unreachable: ICMP Type 3. Indicates host/network inaccessible or port closed.
Troubleshooting with `traceroute`

* * * or missing TTL-exceeded messages often indicate:

  • Firewall blocking ICMP on intermediate routers.
  • Packet loss on a specific segment.
Key Takeaway

`traceroute` uses ICMP TTL messages to reveal the exact path packets take, making it indispensable for diagnosing complex routing and connectivity issues.
