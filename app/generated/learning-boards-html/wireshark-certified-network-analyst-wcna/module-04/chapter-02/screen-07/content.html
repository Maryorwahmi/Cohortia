Wireshark Filter

Use the display filter dns to isolate DNS queries and responses in your capture.

dns
Interpreting Messages
  • Standard query: Client asking for an IP address.
  • Standard query response: Server providing the IP address.
  • No response: Indicates a potential server issue or firewall block.
Common Troubleshooting

If a website is unreachable by name but reachable by IP, check for:

  • Misconfigured DNS server on client.
  • Firewall blocking UDP port 53.
  • Unresponsive DNS server.
Key Takeaway

DNS analysis in Wireshark helps pinpoint if website access issues stem from name resolution failures rather than general connectivity.
