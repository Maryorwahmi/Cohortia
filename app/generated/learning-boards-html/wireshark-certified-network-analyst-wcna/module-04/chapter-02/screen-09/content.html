Wireshark Filter

Use bootp or dhcp to filter for DHCP-related traffic.

bootp
Diagnosing DORA Failures
  • No Offer after Discover: No DHCP server, or firewall blocking server.
  • No Request after Offer: Client issue accepting the offer.
  • No Acknowledge after Request: Server issue confirming the lease.
Common Mistake

Assuming a physical network issue when a device fails to get an IP. Often, it's a DHCP server misconfiguration or a client-side problem.

Key Takeaway

Wireshark provides granular visibility into the DHCP DORA sequence, enabling precise diagnosis of IP address assignment failures.
