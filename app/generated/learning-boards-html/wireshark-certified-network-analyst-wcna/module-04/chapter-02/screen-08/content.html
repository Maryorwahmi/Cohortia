DHCP Purpose

Automatically assigns IP addresses, subnet masks, default gateways, and DNS server information to network devices.

UDP Ports 67 & 68

DHCP clients send requests from port 68 to server port 67. Servers respond from port 67 to client port 68.

Benefits of DHCP

Simplifies network administration, prevents IP address conflicts, and allows for easy network reconfigurations.

Key Takeaway

DHCP is essential for modern networks, automating IP address assignment through a four-step DORA process over UDP.

The DHCP DORA Sequence
1. Discover (Client Broadcast)
2. Offer (Server Unicast/Broadcast)
3. Request (Client Broadcast)
4. Acknowledge (Server Unicast/Broadcast)
