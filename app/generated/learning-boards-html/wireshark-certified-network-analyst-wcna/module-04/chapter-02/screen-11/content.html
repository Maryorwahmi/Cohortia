`ping` Utility

Sends ICMP Echo Request messages to a target host to test basic network connectivity and measure round-trip time.

ICMP Message Types
  • Echo Request: ICMP Type 8 (sent by source).
  • Echo Reply: ICMP Type 0 (sent by destination).
  • Wireshark shows these in the ICMP header's Type field.
Troubleshooting with `ping`

No replies indicate potential issues:

  • Host is down or offline.
  • Firewall blocking ICMP traffic.
  • Routing problems preventing reachability.
Key Takeaway

`ping` provides a quick, essential check of network reachability by leveraging ICMP Echo Request and Reply messages.
