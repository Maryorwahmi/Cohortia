DNS Core Function

Translates human-readable domain names (e.g., www.example.com) into machine-readable IP addresses (e.g., 192.0.2.1).

UDP Port 53

DNS primarily uses UDP port 53 for fast, connectionless queries and responses. TCP port 53 is used for zone transfers and larger responses.

Query-Response Model

A client sends a DNS query to a DNS server, which then returns the corresponding IP address or an error.

Key Takeaway

DNS is fundamental for web browsing, relying on UDP's speed to quickly resolve domain names into IP addresses.
