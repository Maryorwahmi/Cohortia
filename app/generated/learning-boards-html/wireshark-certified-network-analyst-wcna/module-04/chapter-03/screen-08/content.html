The Internet's Phonebook: DNS

The Domain Name System (DNS) is a hierarchical and decentralized naming system for computers, services, or any resource connected to the Internet or a private network. It translates human-readable domain names into numerical IP addresses.

Primary Function

Translates domain names (e.g., example.com) into IP addresses (e.g., 192.0.2.1).

Protocol Usage

Primarily uses UDP on port 53 for queries; TCP on port 53 for zone transfers or large responses.

Key Takeaway

DNS is a critical service that maps domain names to IP addresses, making internet navigation possible. Wireshark helps analyze its queries and responses for troubleshooting.

DNS Query-Response Process
Client (Browser)
DNS Query (What is example.com?)

Query Details:

  • Type: A (IPv4 address)
  • Name: example.com
  • Class: IN (Internet)
DNS Response (example.com is 192.0.2.1)

Response Details:

  • Type: A
  • Name: example.com
  • Address: 192.0.2.1
  • TTL: 3600 seconds
