Key Concepts: TCP Fundamentals

Essential terms for understanding TCP's reliability and flow control.

Three-way Handshake

The process by which TCP establishes a connection (SYN, SYN-ACK, ACK) before data transfer.

Sequence Number

A number assigned to the first byte of data in a TCP segment, used for ordering and reassembly.

Acknowledgment Number

The sequence number of the next byte a receiver expects to receive, confirming successful data receipt.

Summary Takeaway

TCP's core mechanisms—handshake, sequence numbers, and acknowledgment numbers—ensure reliable, ordered, and error-checked data delivery across networks.
