Sequence and Acknowledgment Numbers

Ensuring ordered and reliable data delivery.

Sequence Number

Each byte of data transmitted by the sender is assigned a sequence number. This number tracks the order of bytes within the data stream.

Acknowledgment Number

The receiver sends an ACK number indicating the next byte it expects to receive. This confirms successful receipt of all prior bytes.

How it Works

Sender sends data with sequence numbers. Receiver acknowledges the last successfully received byte + 1. This continuous feedback loop ensures data integrity.

Example Scenario

If a client sends a segment with sequence number 1000 and 500 bytes of data, the server, upon successful receipt, will send an ACK number of 1501.

Misconception

Sequence numbers are not packet numbers. They refer to the byte offset within the entire data stream, not just individual segments.

Key Takeaway

Sequence and acknowledgment numbers are fundamental to TCP's reliable, ordered, and error-checked data delivery, forming the basis for detecting and recovering from packet loss.
