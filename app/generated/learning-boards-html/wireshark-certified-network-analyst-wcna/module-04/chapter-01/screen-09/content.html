Core Protocol

Internet Protocol (IP): The Network Workhorse

Addressing and routing packets across diverse networks.

IP's Core Role

Responsible for addressing and routing data packets between hosts across different networks. It's the foundation for internet connectivity.

Connectionless & Best-Effort

IP does not guarantee delivery, ordering, or error-checking. It simply tries its best to route packets to their destination; reliability is handled by higher layers like TCP.

Unique Addressing

Every device on an IP network has a unique IP address, which serves as its identifier and location for routing purposes.

IPv4 Addresses

32-bit numbers, typically represented in dotted-decimal notation (e.g., 192.168.1.100). Still widely used but facing exhaustion.

IPv6 Addresses

128-bit numbers, represented in hexadecimal (e.g., 2001:0db8:85a3::8a2e:0370:7334). Designed to replace IPv4 with a much larger address space.

Key Takeaway

IP is the fundamental protocol for addressing and routing, ensuring packets can traverse networks. It provides a best-effort, connectionless service, distinct from TCP's reliability.
