Applying "Decode As" in Practice

Re-interpreting HTTP Traffic on a Non-Standard Port

1

Capture Traffic: Start a Wireshark capture on your loopback or primary interface while interacting with the non-standard service (e.g., HTTP on 8080).

2

Locate Packet: Find a packet on the non-standard port (e.g., TCP port 8080) in the packet list pane.

3

Open "Decode As": Right-click the packet and select "Decode As..." from the context menu.

4

Configure & Apply: In the dialog, select "TCP port(s)", enter the port number (e.g., 8080), choose the correct protocol (e.g., HTTP), and click OK.

Key Takeaway

The "Decode As" feature provides an immediate, on-the-fly way to correct Wireshark's protocol identification for specific ports, revealing hidden application-layer details.
