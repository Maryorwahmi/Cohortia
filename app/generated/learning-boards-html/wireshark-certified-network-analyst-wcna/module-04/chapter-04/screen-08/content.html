Configuring Specific Protocol Options

Adjusting HTTP and TCP Dissection Behavior

1

Access Preferences: Go to Edit > Preferences > Protocols.

2

Select Protocol: Choose the protocol you want to configure, e.g., HTTP.

3

Modify Port Assignments: For HTTP, add 8080 to the "TCP port(s)" list to always decode HTTP on that port.

4

Explore Other Options: Investigate settings for TCP (e.g., reassembly) or other protocols to fine-tune their dissection behavior.

Key Takeaway

Configuring protocol preferences allows for persistent, global adjustments to Wireshark's dissection, optimizing it for specific network environments and custom application needs.

Example: HTTP Preferences

Adding a Custom HTTP Port

To make Wireshark always decode HTTP on port 8080:

  1. Open Edit > Preferences.
  2. Go to Protocols > HTTP.
  3. Locate the TCP port(s) field.
  4. Add 8080 to the list (e.g., 80,8080,8000).
  5. Click OK.
Pro Tip

For temporary changes, use "Decode As." For permanent, global changes, use Protocol Preferences. Understand the difference to avoid unintended dissection behavior.
