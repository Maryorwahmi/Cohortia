Identifying Port Scanning Activities

Port scanning is a reconnaissance technique where an attacker probes a network to discover open ports and services, often preceding an attack.

Key Takeaway

A high volume of SYN packets from a single source to many different destination ports, without full TCP handshakes, is a strong indicator of a port scan.

Analogy

Think of a port scan like someone rattling all the doorknobs on a street to find an unlocked door. Each SYN packet is a 'rattle' on a different port.

Port Scan Pattern
Source IP
192.168.1.50
Packet Type
SYN (TCP Flag)
Destination Ports
80, 443, 22, 21, 23, 3389, ... (Many different ports)
Handshake
Incomplete (No SYN-ACK/ACK)

This pattern indicates a systematic probing for open services, a common reconnaissance step.
