Malware Analysis

Investigating Malware Traffic Patterns

Identify malware by recognizing communication with C2 servers, unusual protocol usage, and anomalous traffic patterns.

Key Takeaway

Correlate Wireshark's raw packet data with threat intelligence to confirm malicious activity, especially for C2 communication and suspicious DNS queries.

Common Misconception

Malware doesn't always use obscure ports. It often uses standard ports (like 80/443) to blend in, so focus on content, frequency, and destination anomalies.

Malware Indicators
Command-and-Control (C2)

Communication with known malicious external servers for instructions and data exfiltration.

Unusual Protocol Usage

Traffic on standard ports but with anomalous content, frequency, or non-standard protocol behavior.

Suspicious DNS Queries

Requests for newly registered domains or domains known to be associated with malicious campaigns.
