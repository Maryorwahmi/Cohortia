Wireshark Display Filters
# Filter for SYN packets without ACK
tcp.flags.syn == 1 and tcp.flags.ack == 0

# Filter for SYN packets from a specific source IP
ip.src == 192.168.1.50 and tcp.flags.syn == 1 and tcp.flags.ack == 0

# Filter for ICMP Port Unreachable responses
icmp.type == 3 and icmp.code == 3

These filters help isolate suspicious connection attempts and their responses, crucial for identifying port scans.

Practical Analysis

Analyzing Port Scan Indicators

Combine display filters with Wireshark's statistical tools to confirm port scanning activities.

Key Takeaway

A high count of unique destination ports from a single source in 'Endpoints' statistics, combined with SYN-only packets, strongly indicates a port scan.

Pro Tip

After filtering, check 'Statistics > Endpoints > IPv4' and sort by 'Packets' to quickly identify sources with unusually high packet counts to many destinations.
