Detecting Unauthorized Access Attempts

Unauthorized access attempts leave distinct traces in network traffic, from brute-force logins to suspicious connections.

Key Takeaway

Look for repeated failed authentication responses (e.g., HTTP 401/403, SSH resets) and connections to non-standard ports or from unexpected external IPs.

Safety Note

Always work with a copy of the capture file in an isolated analysis environment to prevent further compromise during incident investigation.

Common Indicators
Brute-Force Logins

Numerous HTTP POST requests to login pages followed by 401/403 responses, or repeated SSH connection resets.

Unusual Port Connections

Traffic directed to non-standard ports that typically do not host legitimate services.

Unexpected Source IPs

Connections originating from external IP addresses that are not authorized or expected to interact with internal resources.
