Interpreting TCP Reset (RST) Packets

Understanding abrupt connection terminations

What is a TCP RST?

An abrupt termination of a TCP connection, indicated by the [RST] flag in the TCP header, unlike a graceful FIN/ACK shutdown.

Common Server-Side Causes

Server receives a connection request on a closed port, server is overloaded, or an application error occurs.

Common Client-Side Causes

Client application abruptly closes, or the client receives unexpected data on an established connection.

Wireshark Filter
  • •
    Use tcp.flags.reset == 1 to quickly identify all RST packets in your capture.
Key Takeaway

TCP RST packets signal an abrupt connection end; their diagnostic value comes from analyzing the packets immediately preceding them.

Warning

An abundance of RST packets can indicate serious underlying problems affecting connectivity and service availability.
