Definition & Diagnosis

Understanding Network Latency

Observing delays in Wireshark

What is Latency?

The time it takes for a packet to travel from a source to a destination and back, often perceived as delay.

Wireshark's Time Fields

Utilize 'Time since previous frame' and 'Time since first frame' for general timing within a TCP stream.

Application-Layer Latency

Filter for specific requests (e.g., http.request) and observe the delta time to their corresponding responses (e.g., http.response).

Key Indicators
  • •
    High delta times between request and response packets.
  • •
    Slow application responsiveness reported by users.
  • •
    Delays visible when following a TCP stream.
Key Takeaway

Consistent high time differences between requests and responses in Wireshark are a strong indicator of network latency.

Example

In an HTTP transaction, a long delay between an HTTP GET request and its 200 OK response indicates latency.
