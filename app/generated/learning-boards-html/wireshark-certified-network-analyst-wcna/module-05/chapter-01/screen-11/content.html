Customizing I/O Graphs for Specific Traffic

Targeting your bandwidth analysis

Adding New Graphs

The I/O Graph interface allows you to add multiple graphs, each with its own display filter.

Filtering by Host

Use ip.addr == [IP_ADDRESS] to plot traffic specifically to/from a particular host.

Filtering by Application/Protocol

Apply filters like http, ftp, or dns to visualize bandwidth consumed by specific applications.

Interpreting Custom Graphs
  • •
    Correlate Spikes: Match traffic spikes with reported performance issues.
  • •
    Identify Bottlenecks: Sustained high utilization near link capacity indicates congestion.
Key Takeaway

Customizing I/O Graphs with targeted display filters enables precise identification of bandwidth consumers and potential network bottlenecks.
