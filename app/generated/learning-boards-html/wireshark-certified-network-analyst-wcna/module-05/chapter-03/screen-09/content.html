DHCP Process

The DHCP DORA Process: Discover & Offer

The initial steps of IP address acquisition

DORA Step 1: Discover

  • Client broadcasts a DHCP Discover message.
  • Purpose: Find available DHCP servers.
  • Wireshark filter: bootp.option.type == 1.
  • Troubleshooting: If sent, but no offer, server is unreachable.

DORA Step 2: Offer

DHCP server(s) respond with DHCP Offer messages, proposing an IP address and configuration. Filter: bootp.option.type == 2.

DHCP DORA Flow (Part 1)

Client: DHCP Discover

Broadcasts to find DHCP servers.

Server: DHCP Offer

Proposes an IP address and configuration.

Key Takeaway

The Discover and Offer steps are crucial for a client to find a DHCP server and receive an IP address proposal.
