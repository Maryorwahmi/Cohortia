DNS Analysis

Identifying DNS Queries and Responses

Distinguishing client requests from server replies in Wireshark

DNS Packet Roles

  • Client Query: Device requests an IP address for a domain name.
  • Server Response: DNS server provides the requested IP or an error.
  • Filtering by dns shows both sides of the conversation.
  • Crucial for understanding the flow of name resolution.

Example Scenario

A user tries to access www.google.com. Wireshark shows a packet from the user's PC with dns.flags.response == 0 for www.google.com, followed by a packet from the DNS server with dns.flags.response == 1 containing Google's IP address.

Wireshark Filter Panel
dns.flags.response == 0 // Client Query
dns.flags.response == 1 // Server Response
dns // All DNS traffic
Pro Tip

Combine filters like dns and dns.flags.response == 0 to see only outgoing DNS queries, or dns and dns.flags.response == 1 for only responses.

Key Takeaway

The dns.flags.response field is your primary indicator for distinguishing between DNS queries (0) and responses (1).
