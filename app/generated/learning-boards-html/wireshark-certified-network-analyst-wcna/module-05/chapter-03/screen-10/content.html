DHCP Process

The DHCP DORA Process: Request & Acknowledge

Finalizing the IP address lease

DORA Step 3: Request

  • Client broadcasts a DHCP Request message.
  • Purpose: Accept an offer and implicitly decline others.
  • Wireshark filter: bootp.option.type == 3.
  • Troubleshooting: If sent, but NAK received, IP might be unavailable.

DORA Step 4: Acknowledge (ACK)

The chosen DHCP server responds with a DHCP ACK, confirming the lease and finalizing configuration. Filter: bootp.option.type == 5.

DHCP DORA Flow (Part 2)

Client: DHCP Request

Accepts an offer, requests the IP.

Server: DHCP ACK

Confirms the IP lease and configuration.

Key Takeaway

The Request and Acknowledge steps finalize the IP address assignment, allowing the client to join the network.
