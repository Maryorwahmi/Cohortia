Learning Objectives

Skills you'll master in this chapter to become a Wireshark expert.

LearnUnderstandApplyMaster
01

Analyze DNS Packets

Identify and analyze DNS query and response packets to understand name resolution flows. This skill is foundational for pinpointing where DNS communication breaks down.

VERIFIED COMPETENCY MILESTONE
02

Interpret DNS Response Codes

Understand DNS response codes like NXDOMAIN and SERVFAIL to diagnose specific resolution issues. This helps you determine if a domain doesn't exist or if the server is failing.

VERIFIED COMPETENCY MILESTONE
03

Diagnose Name Resolution Failures

Diagnose name resolution failures and slow DNS lookups by correlating queries, responses, and timing. This helps identify unresponsive servers or network latency issues.

VERIFIED COMPETENCY MILESTONE
04

Trace DHCP DORA Process

Trace the DHCP DORA process (Discover, Offer, Request, Acknowledge) to understand IP address assignment. This is key to troubleshooting client connectivity issues.

VERIFIED COMPETENCY MILESTONE
