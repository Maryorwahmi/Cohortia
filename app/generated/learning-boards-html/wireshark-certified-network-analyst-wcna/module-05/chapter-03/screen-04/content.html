DNS: Domain Name System

DNS is a hierarchical and decentralized naming system that translates human-readable domain names into machine-readable IP addresses.

  • Enables users to access websites and services using memorable names.
  • Crucial for almost all internet-based communications.
  • Operates primarily over UDP port 53 for queries.
  • Without it, you'd need to remember IP addresses for everything.
Key Takeaway

DNS is the fundamental service that translates domain names into IP addresses, making the internet usable for humans.
