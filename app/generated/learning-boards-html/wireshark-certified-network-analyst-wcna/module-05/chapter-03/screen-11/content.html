DHCP Troubleshooting

Detecting IP Address Conflicts

Identifying when two devices share the same IP address

Signs of IP Conflicts

  • Multiple devices respond to ARP requests for the same IP.
  • Devices sending gratuitous ARP for an IP, then another device claims it.
  • Intermittent connectivity issues for affected devices.
  • Error messages on devices about duplicate IP addresses.

Common Misconception

DHCP always prevents conflicts. Manual configurations or rogue DHCP servers can still cause them.

ARP-Based Detection

Device A: ARP Request

"Who has 192.168.1.10? Tell 192.168.1.50."

Device B & C: ARP Reply

"192.168.1.10 is at MAC:XX:XX:XX:XX:XX:XX." (Both reply)

Key Takeaway

IP address conflicts are detected by observing multiple devices responding to ARP requests for the same IP address.
