Learning Objectives

Advanced troubleshooting skills for network services

LearnUnderstandApplyMaster
05

Troubleshoot IP Assignment

Troubleshoot IP address assignment problems by analyzing the DHCP DORA process. This helps identify failures in obtaining or renewing IP addresses.

VERIFIED COMPETENCY MILESTONE
06

Detect Common DHCP Issues

Detect common DHCP issues such as IP address conflicts, missing DHCP offers, and incorrect lease information. This ensures stable and unique IP assignments.

VERIFIED COMPETENCY MILESTONE
07

Verify DHCP Options

Verify DHCP options like default gateway and DNS servers to ensure clients receive correct network configurations. Incorrect options lead to partial connectivity.

VERIFIED COMPETENCY MILESTONE
08

Apply Wireshark Filters

Apply Wireshark filters to isolate DNS and DHCP traffic for focused analysis. This streamlines troubleshooting by reducing noise in packet captures.

VERIFIED COMPETENCY MILESTONE
