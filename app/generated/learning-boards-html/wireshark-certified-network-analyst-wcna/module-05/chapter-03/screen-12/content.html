DHCP Configuration

Verifying DHCP Options

Ensuring clients receive correct network parameters

Critical DHCP Options

  • bootp.option.router: Default gateway IP address.
  • bootp.option.dns_server: DNS server IP addresses.
  • bootp.option.ip_address_lease_time: Duration of the IP lease.
  • Incorrect options lead to partial or no connectivity.

Common Mistake

Assuming a client has full connectivity just because it received an IP address. Always verify the other DHCP options.

Impact of Incorrect Options

Wrong Default Gateway

Client cannot reach external networks (e.g., internet).

Incorrect DNS Servers

Client cannot resolve domain names, leading to 'website not found' errors.

Correct Lease Time

Ensures IP address is valid for an appropriate duration, preventing premature renewals.

Key Takeaway

Always verify DHCP options like default gateway and DNS servers to ensure complete network functionality.
