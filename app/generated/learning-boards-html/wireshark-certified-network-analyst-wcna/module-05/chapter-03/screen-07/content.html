Performance Analysis

Diagnosing Slow DNS Lookups

Identifying latency and unresponsiveness in DNS resolution

Indicators of Slow DNS

  • High dns.time values: Indicates slow server response or network latency.
  • Multiple unanswered queries: Suggests an unreachable or unresponsive DNS server.
  • Perceived application slowness: Often a symptom of underlying DNS delays.

Client-Side Check

Always verify the DNS servers configured on the client. Incorrect settings or local caching issues can cause delays.

Troubleshooting Flow

1. Check dns.time

Look for high values in the Wireshark packet details, indicating latency.

2. Look for Unanswered Queries

If queries are sent but no responses are received, the server might be unreachable.

3. Verify Client Configuration

Ensure the client is configured with the correct DNS server IP addresses.

Key Takeaway

Monitoring dns.time and observing unanswered queries are key to diagnosing slow or unresponsive DNS resolution.
