Custom Columns: Unveiling Hidden Insights

Displaying critical packet fields directly in the packet list pane.

01

Right-Click Column Header

Initiate the process by right-clicking on any existing column header in the packet list pane.

02

Add New Column

Select 'Column Preferences' from the context menu, then click the '+' button to add a new column entry.

03

Configure Details

Set the 'Title' (e.g., 'HTTP Response Time'), 'Type' to 'Custom', and 'Field name' to http.time. Click 'OK'.

Example Scenario

To quickly identify slow HTTP responses, add a custom column for http.time. This instantly shows the response time for each HTTP packet, making performance issues visible at a glance.

Key Takeaway

Custom columns make relevant data immediately visible, reducing the need to drill into packet details and streamlining analysis.
