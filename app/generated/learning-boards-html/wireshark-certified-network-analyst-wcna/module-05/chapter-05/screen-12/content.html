Advanced Display Filters: Pinpointing Network Events

Leveraging logical and comparison operators for granular data selection.

Filter Components
  • Logical Operators: and, or, not for combining conditions.
  • Comparison Operators: ==, !=, >, <, >=, <= for numerical and string comparisons.
  • Functions: contains, matches for flexible pattern matching.
Key Takeaway

Mastering advanced filters allows for highly specific data isolation, crucial for complex problem-solving and targeted investigations.

Example: Unauthorized Admin Access
http.request.uri contains "admin" and ip.src != 192.168.1.1

Finds HTTP requests to URIs containing "admin" from any source IP address EXCEPT 192.168.1.1.

Example: High Latency TCP Connections
tcp.time_delta > 0.1 and tcp.flags.syn == 1

Identifies TCP SYN packets with a time delta greater than 0.1 seconds, indicating potential high latency connections.

Example: DNS Query Failures
dns.flags.rcode != 0 and dns.flags.response == 1

Filters for DNS response packets that indicate an error (non-zero response code).
