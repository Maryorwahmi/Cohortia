What is TShark?

Command-Line Wireshark

TShark is the command-line version of Wireshark, allowing you to capture and analyze packets without the GUI. It's perfect for scripting, remote capture, and extracting specific data.

Key Use Cases
  • Automated data extraction for reports.
  • Scheduled network monitoring tasks.
  • Analysis on headless servers or remote systems.
  • Integration with custom scripts and tools.
Key Takeaway

TShark enables scripting and remote analysis, making it ideal for automated data extraction and integration.

# Extract HTTP hostnames and URIs from a capture file
tshark -r my_capture.pcapng \
       -Y "http.request" \
       -T fields \
       -e http.host \
       -e http.request.uri

# Explanation:
-r my_capture.pcapng: Reads the specified capture file.
-Y "http.request": Applies a display filter for HTTP requests.
-T fields: Specifies output format as fields.
-e http.host: Extracts the HTTP Host field.
-e http.request.uri: Extracts the HTTP Request URI field.
