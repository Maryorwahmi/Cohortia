Core Feature

Follow TCP Stream

Reassembles and displays all data exchanged within a single TCP connection in chronological order.

Why it's Crucial

Provides a raw, unfiltered view of application data flow, essential for identifying subtle communication issues.

Reveals Bottlenecks

Helps uncover issues like data delivery delays, retransmissions, or application-level protocol errors.

Key Takeaway

TCP Stream analysis is fundamental for understanding the true application data flow and diagnosing underlying performance problems.

Steps to Follow a TCP Stream

1

Select any packet from the desired TCP conversation.

2

Right-click on the selected packet.

3

Choose 'Follow' then 'TCP Stream' from the context menu.

4

View the reassembled data in a dedicated window.
