Measure Response Time

The http.time Field

Wireshark calculates the duration between an HTTP request and its corresponding response, providing direct timing for web transactions.

Filter Example
http.request and http.time > 0.5

Quickly identifies HTTP requests taking longer than 500 milliseconds.

Content Size

http.content_length

Indicates the size of the content being transferred. Large values can point to bandwidth saturation.

Interpreting HTTP Status Codes

2xx

Success (e.g., 200 OK): Ideal, content delivered successfully.

3xx

Redirection (e.g., 302 Found): Adds latency due to extra requests.

4xx/5xx

Client/Server Errors: Indicate application or server-side problems.

Key Takeaway

Combining http.time with status code analysis provides a powerful way to quantify and diagnose web application performance bottlenecks.
