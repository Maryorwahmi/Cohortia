FTP Architecture

Control & Data Connections

FTP uses a separate control connection (commands) and a data connection (file transfer) for its operations.

Control Connection

Handles commands like USER, PASS, RETR, and STOR. Filter with ftp to observe.

Data Connection

Transfers the actual file data. Requires following its specific TCP stream for analysis.

Key Takeaway

Comprehensive FTP analysis requires examining both control and data TCP streams to identify performance bottlenecks.

FTP Transfer Flow

Client Initiates Control (Port 21)
Commands & Responses (USER, RETR)
