Module 5›Chapter 5.2›Avoiding Pitfalls in Performance Diagnosis
Mistake 1

Network-Only Focus

Solely focusing on network layer issues when the problem might be higher up in the application stack (e.g., slow database query).

Mistake 2

Incomplete Context

Not considering the full request-response cycle or the broader implications of TCP windowing (e.g., consistently small windows).

Mistake 3

Irrelevant Capture Point

Capturing traffic at a point not relevant to the application's communication path, leading to incomplete or misleading data.

Key Takeaway

A holistic approach, considering application logic and proper capture points, is essential for accurate performance diagnosis.

Holistic Troubleshooting Mindset

1

Application Logic: Understand how the application works internally.

2

Full Communication Cycle: Analyze the entire request-response flow.

3

Relevant Capture Points: Ensure Wireshark is monitoring the correct traffic path.
