Key Concepts

Essential terms from this chapter.

HTTP Response Time

Wireshark's calculated duration between an HTTP request and its response, crucial for identifying slow web applications.

TCP Stream Analysis

A Wireshark feature that reassembles and displays the payload data of a single TCP connection chronologically.

TCP Window Size

The amount of data a TCP sender can transmit before receiving an acknowledgment, used for flow control.

Summary Takeaway

These core concepts provide the foundation for understanding and diagnosing application performance issues at both the HTTP and TCP layers.
