Comparison Operators for Refined Filtering

Specifying exact matches and value ranges.

==

Equals

Matches packets where the field's value is exactly equal to the specified value.

tcp.dstport == 80
!=

Not Equals

Matches packets where the field's value is not equal to the specified value.

ip.addr != 192.168.1.1
> <

Greater/Less Than

Matches packets where the field's numerical value is greater than or less than the specified value.

frame.len > 1000
Range Example

To find packets with length between 60 and 120 bytes: frame.len >= 60 and frame.len <= 120

Key Takeaway

Comparison operators are essential for creating highly specific filters based on exact values or numerical ranges within packet fields.
