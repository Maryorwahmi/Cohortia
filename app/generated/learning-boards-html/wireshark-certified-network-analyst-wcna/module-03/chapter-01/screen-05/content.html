Module 3›Chapter 1›The Filter Toolbar and Basic Filters
1

Locate the Filter Toolbar

The filter toolbar is prominently located above the packet list pane in Wireshark's main interface.

Visual cue: Green for valid, red for invalid.
2

Leverage Auto-completion

As you type, Wireshark suggests valid protocol fields and operators, aiding in syntax and discovery.

Pro-tip: Start typing a protocol name to see options.
3

Apply Simple Protocol Filters

Type a protocol name (e.g., http, dns, arp) and press Enter to view only packets for that protocol.

Example: Type http to see all web traffic.
Key Takeaway

The filter toolbar and auto-completion are your primary tools for quickly applying basic protocol-based display filters.
