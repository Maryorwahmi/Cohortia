Dot Notation

Wireshark uses protocol.field syntax to refer to specific attributes within a protocol header.

Analogy: Navigating a structured data object.
2

IP Address Fields

ip.addr matches either source or destination IP. Use ip.src or ip.dst for specific directions.

ip.addr == 192.168.1.100
ip.src == 192.168.1.100
3

Port Number Fields

tcp.port matches either source or destination TCP port. Use tcp.srcport or tcp.dstport for specific directions.

tcp.port == 80
tcp.dstport == 80
Key Takeaway

Mastering dot notation for protocol fields is crucial for crafting precise and effective Wireshark display filters.
