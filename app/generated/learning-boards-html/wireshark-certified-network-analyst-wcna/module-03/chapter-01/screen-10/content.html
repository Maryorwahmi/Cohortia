1

The Need for Grouping

Without parentheses, logical operators follow a default precedence, which might not match your intended logic.

Common mistake: Misinterpreting not scope.
2

Incorrect Example

not tcp.port == 22 or tcp.port == 443

This filter would show all packets not on port 22, PLUS all packets on port 443, which is likely unintended.

3

Correct Usage

not (tcp.port == 22 or tcp.port == 443)

This correctly applies the not operator to the entire grouped condition, excluding both ports.

Key Takeaway

Always use parentheses to explicitly group conditions in complex filters, especially with 'not', to ensure correct logical evaluation.
