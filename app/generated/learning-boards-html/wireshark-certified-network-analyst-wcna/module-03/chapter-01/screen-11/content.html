Avoiding Common Display Filter Mistakes

Ensuring accuracy and efficiency in your filtering.

X

ip.addr vs. ip.host

Use ip.addr for numerical IP addresses. ip.host attempts hostname resolution, which can be slow and unreliable.

ip.addr == 192.168.1.100
X

Single vs. Double Equals

Always use == for equality comparisons. A single = will result in a syntax error.

tcp.dstport == 80
Pro-Tip

Leverage Wireshark's auto-completion feature to discover valid fields and ensure correct syntax, reducing errors.

Key Takeaway

Using ip.addr for IP filtering and always using == for comparisons are critical for accurate and efficient display filters.
