Network Troubleshooting
Identifying TCP Retransmissions and Duplicate ACKs
Pinpointing packet loss and congestion indicators.
Retransmissions

Indicate packet loss or network congestion. Filter with tcp.analysis.retransmission.

Duplicate ACKs

Often a precursor to retransmissions, signaling out-of-order segments. Filter with tcp.analysis.duplicate_ack.

Key Takeaway

These specific analysis fields are crucial for quickly diagnosing network reliability issues and performance bottlenecks.

R

TCP Retransmission

A segment is sent again because it was lost or corrupted. Indicates packet loss or congestion.

tcp.analysis.retransmission
D

TCP Duplicate ACK

Receiver acknowledges a segment already received, indicating an earlier segment was missed.

tcp.analysis.duplicate_ack
Common Mistake

Ignoring duplicate ACKs. They are an early warning sign of potential packet loss and should be investigated.
