The 'contains' Operator for Substring Search
Find specific text within protocol fields.
How it Works

The contains operator checks if a specified string field includes a given substring. It's case-sensitive by default.

Why it Matters

Essential for finding partial matches, like keywords in URLs or specific data within payloads, without needing the full field value.

Key Takeaway

Use contains for flexible substring searches when an exact match is not required, enhancing your ability to pinpoint relevant traffic.

Example: HTTP URI Search
# Filter for HTTP requests where the URI contains 'login'
http.request.uri contains "login"

# Filter for DNS queries containing 'google'
dns.qry.name contains "google"

# Filter for SMB traffic containing a specific filename
smb.file contains "report.docx"
Pro Tip

Avoid using == for partial matches; it requires an exact match of the entire field value. Always use contains for substring searches.
