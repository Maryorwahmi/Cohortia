Practical Application
Diagnosing Intermittent Web App Connectivity
A step-by-step approach to connection failures.
The Problem

Users report intermittent access to a web application, indicating potential connection issues.

Why it Matters

Quickly identifying the source of connection failures is critical for maintaining application availability and user satisfaction.

Key Takeaway

Systematically analyze the TCP handshake and look for RST flags to pinpoint where connection failures occur.

Client SYN
tcp.flags.syn == 1 and tcp.flags.ack == 0
Server SYN-ACK
tcp.flags.syn == 1 and tcp.flags.ack == 1
Client ACK
tcp.flags.ack == 1 and not tcp.flags.syn
Connection Reset
tcp.flags.reset == 1
Troubleshooting Tip

If SYN packets lack SYN-ACKs, suspect server/firewall issues. If SYN-ACKs lack ACKs, suspect client issues.
