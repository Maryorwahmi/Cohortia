Regular Expressions
The 'matches' Operator for Advanced Patterns
Leverage regex for flexible and complex string matching.
Regex Power

Allows for complex pattern matching, character classes, quantifiers, and anchors within string fields.

Use Cases

Ideal for identifying API versioning, specific log formats, or dynamic URL structures that 'contains' cannot handle.

Key Takeaway

matches (or ~) provides powerful regex capabilities for intricate pattern recognition, but use judiciously due to performance impact.

Example: API Versioning
# Find API requests to various versions of a user endpoint
http.request.uri matches "^\/api\/v[0-9]\/users"

# Explanation:
# ^        - Start of the string
# \/api\/v - Literal '/api/v'
# [0-9]    - A single digit (for version number)
# \/users  - Literal '/users'

# Filter for HTTP requests containing a specific file extension
http.request.uri matches "\.php$"
Common Mistake

Over-using complex regex when a simpler contains operator would suffice. Regex can be computationally intensive.
