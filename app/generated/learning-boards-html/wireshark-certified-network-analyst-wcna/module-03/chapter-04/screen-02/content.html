Learning Objectives

Skills You'll Master in This Chapter

LearnUnderstandApplyMaster
01

Save Filtered Capture Files

Learn to save specific subsets of capture data in various formats like .pcapng or .pcap. This skill is crucial for creating focused analysis files and securely sharing relevant information without exposing sensitive, unrelated data.

VERIFIED COMPETENCY MILESTONE
02

Extract Specific Objects

Master the extraction of embedded objects, such as HTTP files (images, scripts) or SMB files, directly from a capture file. This feature is invaluable for forensic analysis and content reconstruction, allowing you to retrieve original files from network traffic.

VERIFIED COMPETENCY MILESTONE
