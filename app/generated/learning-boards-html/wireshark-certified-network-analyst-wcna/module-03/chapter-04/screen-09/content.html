Statistics: Conversations and Endpoints

Pinpoint Chatty Hosts and High-Bandwidth Connections

Conversations

Lists all network conversations (Ethernet, IP, TCP, UDP) with packet/byte counts and throughput.

Endpoints

Aggregates traffic for individual network addresses (Ethernet, IP, TCP, UDP), showing total sent/received data.

Layer-Specific Views

Both tools offer views segmented by network layer, allowing for targeted analysis.

Concrete Example

You notice a server is experiencing high CPU usage. Checking Statistics > Conversations > TCP reveals a single client IP address with an extremely high byte count to that server. This immediately points to a specific client-server interaction as the potential cause, allowing you to investigate that connection further.

Key Takeaway

Conversations and Endpoints are vital for identifying the most active communicators and high-bandwidth connections, helping to pinpoint performance bottlenecks or suspicious activity on the network.

Common Pitfall

Focusing only on byte counts can be misleading. A conversation with many small packets might indicate a chatty application or a problem, even if its total byte count isn't the highest. Always consider packet count alongside byte count.
