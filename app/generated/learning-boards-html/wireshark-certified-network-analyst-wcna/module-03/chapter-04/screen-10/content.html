Statistics: I/O Graphs and Packet Lengths

Visualize Traffic Trends and Packet Size Distribution

I/O Graphs

Visualizes traffic rates (packets/bytes per second) over the capture duration, ideal for spotting trends and bursts.

Packet Lengths

Shows the distribution of packet sizes, which can indicate fragmentation or specific application behaviors.

Correlation & Context

These tools provide crucial context, helping to correlate network events with reported issues and prioritize analysis.

Concrete Example

An application is reported to be slow intermittently. You check the I/O Graph and see regular, sharp drops in throughput every 10 minutes. This pattern suggests a scheduled task or a recurring network event causing the slowdown, giving you a specific time window to investigate further.

Key Takeaway

I/O Graphs and Packet Lengths offer powerful visual insights into network performance and application behavior, enabling you to quickly identify trends, anomalies, and potential root causes of issues.

Common Mistake

Misinterpreting I/O Graph spikes: not all spikes are bad. A spike might represent a legitimate large file transfer. Always cross-reference with other statistics and context to determine if it's an anomaly or expected behavior.
