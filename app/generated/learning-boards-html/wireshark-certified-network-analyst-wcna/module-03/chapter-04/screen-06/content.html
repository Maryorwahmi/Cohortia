Deep Dive

Following TCP Streams

Uncover Application-Layer Dialogue with Follow TCP Stream

Select a TCP Packet

Right-click on any TCP packet within the conversation you wish to analyze.

Follow the Stream

Choose Follow > TCP Stream from the context menu.

Analyze Conversation

A new window displays the reconstructed application-layer data, often color-coded for client and server.

Concrete Example

You're debugging a web application where a user reports an error after submitting a form. By following the TCP stream of the HTTP POST request, you can see the exact data sent by the client and the server's response, quickly pinpointing if the issue is with the request format or the server's processing.

Key Takeaway

'Follow TCP Stream' is indispensable for understanding application-layer communication, debugging, and extracting conversational data, providing a complete view of a specific connection.

Safety Note

Be extremely cautious when following streams over unencrypted channels. They can contain sensitive data like credentials or PII. Always ensure proper authorization and handle such data securely.
