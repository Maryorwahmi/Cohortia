BPF Primitives

Filtering by Host and Network

Targeting Specific Devices or Subnets

host Primitive

  • •Filters traffic to or from a specific IP address.
  • •Example: host 192.168.1.100 (any direction).
  • •Directional: src host or dst host .
  • •Useful for isolating a single device's communications.
Scenario

To troubleshoot a client machine, use host 10.0.0.5 to see all its inbound and outbound traffic.

net Primitive

  • •Filters traffic within a specific network subnet.
  • •Example: net 192.168.1.0/24 (CIDR notation).
  • •Alternative: net 192.168.1.0 mask 255.255.255.0.
  • •Ideal for monitoring traffic across an entire network segment.
Example

To capture all traffic on your local subnet, use net 192.168.1.0/24.

Key Takeaway

Use host for individual IP addresses and net for entire subnets, with optional src/dst for directional filtering, to precisely target your capture.
