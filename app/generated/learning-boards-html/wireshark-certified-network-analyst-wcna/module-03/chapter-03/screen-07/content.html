BPF Primitives

Filtering by Port and Protocol

Isolating Application-Specific Traffic

port Primitive

  • •Filters traffic to or from a specific port number.
  • •Example: port 80 (HTTP traffic).
  • •Directional: src port or dst port .
  • •Useful for isolating specific application services.
Scenario

To capture all web traffic, use port 80 or port 443.

proto Primitive

  • •Filters traffic by a specific network protocol.
  • •Common protocols: tcp, udp, icmp, arp, ip.
  • •Example: tcp (all TCP traffic).
  • •Often combined with port for precision.
Example

To capture only DNS queries, use udp port 53.

Key Takeaway

Combine port and proto primitives to create highly specific filters that target application-level traffic, such as tcp port 443 for HTTPS.
