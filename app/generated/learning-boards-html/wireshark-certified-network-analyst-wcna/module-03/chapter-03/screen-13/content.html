Key Concepts

Essential ideas to remember from this chapter

Capture Filter

A filter applied *before* packets are captured, permanently discarding non-matching packets.

Berkeley Packet Filter (BPF)

The low-level syntax used for Wireshark capture filters, designed for efficiency.

host primitive

BPF keyword to filter traffic to or from a specific IP address (e.g., host 192.168.1.1).

Summary Takeaway

Capture filters, using BPF syntax and primitives like host, are essential for efficient, targeted network data collection by discarding irrelevant packets early.
