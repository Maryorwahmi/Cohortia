Capturing Specific Server Traffic

Example: SSH and DNS to a Busy Server

The Challenge

  • •Busy server IP: 172.16.1.10.
  • •Interested in SSH (port 22) and DNS (port 53) traffic.
  • •Traffic must originate from 192.168.1.0/24 subnet.
  • •Server is the destination for this traffic.
Why it matters

Precisely isolating traffic on a busy server prevents overwhelming your capture and focuses analysis on relevant events.

The BPF Filter

(tcp port 22 or udp port 53) and
src net 192.168.1.0/24 and
dst host 172.16.1.10
  • •(tcp port 22 or udp port 53): Targets SSH and DNS.
  • •src net 192.168.1.0/24: Specifies source subnet.
  • •dst host 172.16.1.10: Specifies destination server.
Key Takeaway

Complex troubleshooting scenarios require combining multiple BPF primitives and logical operators with careful grouping to achieve precise and efficient traffic capture.
