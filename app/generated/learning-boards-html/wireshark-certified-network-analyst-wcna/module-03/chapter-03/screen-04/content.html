Capture Filters vs. Display Filters

Understanding When and How to Use Each

Capture Filters

  • •Applied *before* packets are written to the capture file.
  • •Permanently discards non-matching packets.
  • •Reduces capture file size and system resource usage.
  • •Uses Berkeley Packet Filter (BPF) syntax.
Use Case

When you need to capture only specific traffic on a high-volume network to prevent overwhelming your system or storage.

Display Filters

  • •Applied *after* packets are captured and saved.
  • •Hides non-matching packets from view; data is retained.
  • •Does not affect capture file size or initial resource usage.
  • •Uses Wireshark's own display filter syntax.
Use Case

When you want to analyze all traffic but need to quickly isolate specific conversations or protocols for detailed inspection.

Key Takeaway

Capture filters are for efficiency and data reduction at the source, while display filters are for flexible, non-destructive analysis of already captured data.
