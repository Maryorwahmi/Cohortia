Advanced BPF

Filtering by Network and Combining Rules

Leveraging net and logical operators for complex filters.

# Capture traffic for an entire subnet
net 192.168.1.0/24

# Combine filters with 'and' (both conditions must be true)
host 10.0.0.50 and port 80

# Combine filters with 'or' (at least one condition must be true)
port 80 or port 443

# Exclude traffic with 'not'
not port 22
Key Takeaway

The `net` keyword and logical operators (`and`, `or`, `not`) allow for highly specific and efficient capture filtering.

Filtering by Network (`net`)

The net keyword allows you to capture all traffic within a specified IP subnet, using CIDR notation.

Example: net 172.16.0.0/16 captures all traffic in that large network block.

Logical Operators

  • and: Both conditions must be met.
  • or: At least one condition must be met.
  • not: Excludes traffic matching the condition.

Complex Filter Example

To capture all HTTP traffic on a specific subnet, but exclude traffic from a particular host: net 192.168.1.0/24 and port 80 and not host 192.168.1.5.

Common Mistake

Forgetting parentheses for complex logical expressions, which can lead to incorrect filter application due to operator precedence.
