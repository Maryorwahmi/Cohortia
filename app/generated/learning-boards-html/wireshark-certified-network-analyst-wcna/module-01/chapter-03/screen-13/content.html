Key Concepts

Essential terms from this chapter.

Network Interface

A hardware component (e.g., Ethernet, Wi-Fi) connecting a computer to a network.

Promiscuous Mode

NIC captures all traffic on its segment, regardless of destination MAC address.

Capture Filter

A rule applied *before* packets are captured to limit data written to the file.

Summary Takeaway

These foundational concepts are critical for setting up and understanding how Wireshark intercepts and processes network traffic.
