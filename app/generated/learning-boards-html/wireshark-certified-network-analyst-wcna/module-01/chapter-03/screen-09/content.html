Capture Workflow

Executing and Preserving Your Capture

The practical steps for live packet capture.

1. Start Capture

Click the blue shark fin icon or go to Capture > Start.

2. Stop Capture

Click the red square stop icon or go to Capture > Stop.

3. Save Data

Use File > Save As... and choose .pcapng format.

Why .pcapng?

Packet Capture Next Generation (.pcapng) is the recommended format, offering enhanced features like multiple interface records and capture statistics over older .pcap files.

Descriptive Naming

Always give capture files descriptive names (e.g., YYYY-MM-DD_Protocol_Scenario.pcapng) for easy identification and organization.

Key Takeaway

A complete capture workflow involves initiating, terminating, and saving your data in a robust format with clear naming conventions.

Common Mistake

Forgetting to save the capture file before closing Wireshark, leading to loss of all captured data.
