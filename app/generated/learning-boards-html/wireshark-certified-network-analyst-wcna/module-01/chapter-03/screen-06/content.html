Filtering Strategy

Capture Filters: Reducing Data Volume

Applying rules *before* packets are written to disk.

Capture Filter

Applied *before* data is captured. Reduces raw file size.

Display Filter

Applied *after* data is captured. Filters view, not file size.

Why Use Capture Filters?

  • Reduces volume of data captured.
  • Saves significant disk space.
  • Decreases processing overhead on capture machine.
  • Focuses analysis on relevant traffic.

BPF Syntax

Capture filters use Berkeley Packet Filter (BPF) syntax, a powerful and concise language for defining rules.

Example Scenario

To analyze only web traffic, a capture filter like port 80 or port 443 would prevent all other protocol data from being saved.

Key Takeaway

Capture filters are a proactive measure to optimize your Wireshark captures, making them smaller, faster, and more focused.
