BPF Essentials

Targeting Traffic with Host and Port

Using host and port for precise filtering.

# Capture traffic to/from a specific IP address
host 192.168.1.100

# Capture traffic on a specific port (e.g., HTTP)
port 80

# Capture traffic to/from a specific host AND port
host 192.168.1.100 and port 80
Key Takeaway

`host` and `port` are fundamental BPF primitives for filtering traffic by IP address and service, respectively.

Understanding `host`

The host keyword matches packets where either the source or destination IP address is the specified value. It's bidirectional.

Example: host 10.0.0.5 captures all traffic involving that IP.

Understanding `port`

The port keyword filters for traffic using a specific TCP or UDP port number. Useful for isolating application-layer protocols.

Example: port 22 captures SSH traffic.

Practical Scenario

If you're debugging a web server, using host [server_ip] and port 80 allows you to see only HTTP requests and responses to and from that specific server.

Common Mistake

Using display filter syntax (e.g., ip.addr == 192.168.1.1) instead of BPF syntax in the capture filter field.
