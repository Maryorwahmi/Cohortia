IP Addresses: Routing Across Networks

Differentiating IPv4 and IPv6 for global communication.

IPv4 Addresses

32-bit logical addresses. Dotted-decimal notation. Limited address space.

Example: 192.168.1.100

IPv6 Addresses

128-bit logical addresses. Hexadecimal notation. Vastly larger address space.

Example: 2001:0db8::8a2e:0370:7334

Key Takeaway

IP addresses enable global routing, and Wireshark's filtering capabilities are essential for analyzing traffic based on these logical identifiers.

IP Address Comparison

Key differences between IPv4 and IPv6.

IPv4

  • 32-bit
  • Dotted-decimal
  • Limited addresses
  • Manual/DHCP config

IPv6

  • 128-bit
  • Hexadecimal
  • Vast addresses
  • Stateless autoconfig

Subnetting Concept

Dividing a network into smaller, manageable subnetworks. Essential for efficient IP address allocation and routing decisions.
