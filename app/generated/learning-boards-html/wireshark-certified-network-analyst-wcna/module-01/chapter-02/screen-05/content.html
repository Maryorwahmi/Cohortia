The OSI Model: Seven Layers of Network Function

Understanding the theoretical framework for network communication.

L7

Application Layer

User-facing protocols (HTTP, DNS). Wireshark shows application data.

L4

Transport Layer

End-to-end communication, segments (TCP, UDP). Wireshark shows port numbers, flags.

L3

Network Layer

Logical addressing, packets (IP). Wireshark shows source/destination IPs.

L2

Data Link Layer

Physical addressing, frames (MAC). Wireshark shows MAC addresses.

Key Takeaway

The OSI model's layered approach helps isolate and understand specific network functions, making complex data flows more digestible for analysis.
