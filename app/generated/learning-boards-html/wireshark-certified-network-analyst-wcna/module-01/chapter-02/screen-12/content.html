Transport Layer Protocols: TCP and UDP

Reliable vs. unreliable end-to-end communication.

TCP (Transmission Control Protocol)

Connection-oriented, reliable, ordered delivery, error checking, retransmission. Ideal for web, email, file transfer.

UDP (User Datagram Protocol)

Connectionless, unreliable, faster, no error checking or retransmission. Ideal for streaming, gaming, DNS.

Key Takeaway

TCP ensures reliable data delivery, while UDP prioritizes speed over reliability, both critical for different network applications and visible in Wireshark.

TCP vs. UDP

Choosing the right transport for your data.

TCP Characteristics

  • Connection-oriented
  • Guaranteed delivery
  • Flow control
  • Congestion control

UDP Characteristics

  • Connectionless
  • Best-effort delivery
  • No flow control
  • No congestion control

Port Numbers

Both TCP and UDP use port numbers to identify specific applications or services on a host, allowing multiple applications to share a single IP address.
