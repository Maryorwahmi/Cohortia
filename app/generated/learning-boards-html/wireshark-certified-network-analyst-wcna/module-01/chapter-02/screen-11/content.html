Routers: Connecting Diverse Networks

Understanding Layer 3 forwarding and Wireshark's view.

Layer 3 Device

Operates at the Network layer, connecting different networks and forwarding packets based on IP addresses.

Inter-Network Routing

Directs traffic between distinct networks, determining the best path for packets to reach their destination.

Wireshark Visibility

Traffic is only visible if your capture device is on the specific network segment where it originates or terminates.

Key Takeaway

Routers segment networks, meaning Wireshark captures are limited to the local network interface where the capture is performed.

Router Traffic Flow

Routing packets between different networks.

Packet from Network A.

Router receives, checks destination IP.

Forwards packet to Network B.

Wireshark on Network A sees only A-to-Router traffic.
