Application Layer Protocols: HTTP, DNS, FTP

User-facing services and their Wireshark representation.

HTTP (Hypertext Transfer Protocol)

Used for web browsing, fetching web pages and resources. Wireshark shows GET/POST requests and responses.

DNS (Domain Name System)

Translates domain names to IP addresses. Wireshark shows queries and corresponding IP address answers.

FTP (File Transfer Protocol)

Used for transferring files between client and server. Wireshark reveals commands, responses, and file data.

Key Takeaway

Application layer protocols are what users interact with; Wireshark provides deep visibility into their operations, crucial for troubleshooting and security analysis.
