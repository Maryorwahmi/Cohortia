MAC Addresses and ARP: Local Network Identifiers

Understanding physical addressing and its resolution.

MAC Address (Layer 2)

Unique, physical hardware address (48-bit, hexadecimal). Used for local network communication.

Example: 00:1A:2B:3C:4D:5E

ARP (Address Resolution Protocol)

Protocol at Layer 2.5 that resolves an IP address to its corresponding MAC address on a local network segment.

Crucial for local connectivity troubleshooting.

Key Takeaway

MAC addresses identify devices on a local segment, and ARP ensures they can find each other using IP addresses, a key process Wireshark helps visualize.

ARP in Action

How an IP becomes a MAC on the local network.

1. Device A needs MAC for Device B's IP.

2. Device A sends ARP Request (broadcast).

3. Device B replies with its MAC address.

4. Device A caches MAC and sends data.
