Installing Wireshark: macOS and Linux

Installation methods for different operating systems.

macOS Installation

  • •Download `.dmg` from wireshark.org and install.
  • •Alternatively, use Homebrew: brew install wireshark.

Linux Installation

  • •Debian/Ubuntu: sudo apt install wireshark.
  • •Fedora/RHEL: sudo dnf install wireshark.
  • •Add user to wireshark group: sudo usermod -aG wireshark $USER.

Post-Installation Steps

After installing on Linux, ensure you log out and back in (or reboot) for user group changes to take effect, allowing packet capture without root privileges.

Key Takeaway

Wireshark offers flexible installation options across macOS and Linux, with specific commands and permission adjustments for each platform.
