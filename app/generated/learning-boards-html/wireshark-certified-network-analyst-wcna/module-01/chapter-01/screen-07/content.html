Understanding Data Units: Packet, Frame, and Segment

Differentiating data units across the OSI model layers.

Packet (Network Layer)

A generic term for a unit of data at the network layer (OSI Layer 3), like an IP packet, containing source and destination IP addresses.

Frame (Data Link Layer)

A unit of data at the data link layer (OSI Layer 2), such as an Ethernet frame, which encapsulates a packet and includes MAC addresses.

Segment (Transport Layer)

A unit of data at the transport layer (OSI Layer 4), particularly for TCP, responsible for end-to-end communication and flow control.

Key Takeaway

Understanding the distinction between packets, frames, and segments is crucial for accurate network analysis and interpreting Wireshark's decoded traffic.
