Key Concepts: Data Units and Filters

Understanding how data is structured and filtered in network analysis.

Frame

A digital data transmission unit in the data link layer (Layer 2) of the OSI model, encapsulating network layer packets.

Segment

A unit of data at the transport layer (Layer 4) of the OSI model, particularly for TCP, managing end-to-end communication.

Display Filter

A rule applied *after* packets have been captured to selectively show or hide packets in the Wireshark interface.

Summary Takeaway

Frames and segments organize data at different network layers, while display filters are essential for focusing analysis on relevant traffic post-capture.
