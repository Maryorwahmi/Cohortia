Inspecting Dependencies with dotnet list package

A guided walkthrough to analyze direct and transitive dependencies.

Objective

Use a common package manager to inspect the direct and transitive dependencies of a sample .NET project.

Key Steps

  • Create a sample .NET webapp.
  • Add a known dependency (e.g., Newtonsoft.Json).
  • Restore packages using `dotnet restore`.
  • Inspect dependencies with `dotnet list package --include-transitive`.

Why it Matters

Understanding your dependency tree is crucial for identifying potential conflicts, managing security vulnerabilities, and ensuring build reproducibility.

# 1. Create a sample project
dotnet new webapp -n MyWebAppWithDependencies
cd MyWebAppWithDependencies

# 2. Add a known dependency (edit MyWebAppWithDependencies.csproj)
<ItemGroup>
  <PackageReference Include="Newtonsoft.Json" Version="13.0.3" />
  <PackageReference Include="Microsoft.AspNetCore.OpenApi" Version="8.0.0" />
  <PackageReference Include="Swashbuckle.AspNetCore" Version="6.4.0" />
</ItemGroup>

# 3. Restore packages
dotnet restore

# 4. Inspect dependencies
dotnet list package --include-transitive
