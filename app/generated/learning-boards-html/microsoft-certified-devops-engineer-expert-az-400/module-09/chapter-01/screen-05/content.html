Different Flavors of Dependencies

Understanding library, runtime, system, and inter-service components.

Library Dependencies

Reusable code packages directly invoked by your application. E.g., NuGet, npm, Maven, PyPI packages.

Runtime Dependencies

Specific versions of execution environments required for your app. E.g., .NET runtime, JVM, Node.js interpreter.

System-Level Dependencies

Operating system packages, kernel versions, or external services/databases. E.g., specific Linux utilities, database drivers.

Inter-Service Dependencies

One microservice relying on another service's API to function. E.g., an authentication service calling a user profile service.

Key Takeaway

Understanding the distinct characteristics of library, runtime, system, and inter-service dependencies is vital for effective management.
