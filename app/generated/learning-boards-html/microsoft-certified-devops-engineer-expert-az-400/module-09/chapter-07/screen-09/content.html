Tiered Retention: A View-Specific Strategy

Applying different retention policies based on package promotion stages.

Default Feed Policy

Applies to all packages by default (e.g., 10 latest versions, 30 days retention).

@release View Policy

Overrides default for stable, production-ready packages (e.g., all versions, 365 days retention).

@prerelease View Policy

Shorter retention for transient development builds (e.g., 5 latest versions, 14 days retention).
