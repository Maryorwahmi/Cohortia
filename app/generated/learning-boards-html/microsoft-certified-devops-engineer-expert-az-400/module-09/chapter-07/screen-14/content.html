Key Concepts

Essential terms to remember

Artifact Retention Policy

Rules defining how long and how many versions of artifacts should be kept in a repository before automatic deletion.

Feed-level Retention

Retention policies applied to all packages within a specific Azure Artifacts feed, acting as a baseline.

Package-level Retention

More granular retention policies applied to individual packages or package versions, often influenced by package views.

Key Takeaway

Effective artifact retention is a balance of automated rules and strategic decisions, crucial for managing repository health and costs.
