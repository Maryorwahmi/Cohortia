Introducing Artifact Retention Policies

Defining the rules for artifact lifecycle management.

What They Are

Rules defining how long and how many versions of artifacts should be kept before automatic deletion.

Their Purpose

To balance the need for historical traceability and reproducibility with practical considerations like storage efficiency and cost optimization.

Key Benefit

Ensures only necessary artifacts are retained for the required duration, preventing uncontrolled repository growth.
