Configuring Feed-Level Retention in Azure Artifacts

Applying broad retention rules to all packages within a feed.

Rule 1: Versions per Package

Define the maximum number of latest versions to keep for each package. E.g., keep the latest 10 versions.

Rule 2: Days to Retain

Specify the maximum number of days to retain packages. E.g., retain all packages for 30 days.

Benefit: Automated Cleanup

These policies automate the deletion of older, less relevant package versions, preventing uncontrolled repository growth.

Steps to Configure Feed Retention

A simple process to manage your artifact lifecycle.

1

Navigate to Azure Artifacts feed.

2

Click 'Feed settings' (gear icon).

3

Go to the 'Retention' tab.

4

Configure 'Max versions' and 'Max days'.
