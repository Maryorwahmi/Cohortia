Leveraging Package Views for Retention

How views influence artifact lifecycle and retention rules.

Categorize Artifacts

Package views (e.g., @local, @prerelease, @release) categorize artifacts by their quality and stability stage.

Differentiated Rules

Retention policies can be configured to apply differently based on these views, allowing for tailored management.

Optimized Preservation

Ensures valuable, stable artifacts are preserved longer, while transient development builds are cleaned up efficiently.
