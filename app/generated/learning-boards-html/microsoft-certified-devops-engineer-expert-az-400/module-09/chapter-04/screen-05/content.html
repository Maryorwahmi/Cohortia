Configuring Your Local npm Client

Authenticating npm to securely access your Azure Artifacts feed.

The .npmrc File

This configuration file specifies package sources, authentication details, and other settings for your npm client. It's essential for private feeds.

Recommended: Credential Provider

The Azure Artifacts Credential Provider for npm automatically acquires and refreshes authentication tokens, offering the most secure and hassle-free method.

  • Run npm login after setting registry.
  • No manual token management.
Alternative: Personal Access Token (PAT)

You can manually configure a PAT in your .npmrc, but this is less secure. It should be avoided for long-term use or if committed to source control.

Safety Note

Never embed PATs directly in .npmrc files that might be committed to source control. Always use environment variables or the credential provider for production.

.npmrc Configuration Example
# Example .npmrc content for Azure Artifacts# Replace 'YourOrg' and 'MyOrgNpmFeed' with your actual organization and feed name
registry=https://pkgs.dev.azure.com/YourOrg/_packaging/MyOrgNpmFeed/npm/registry/
always-auth=true

# For manual PAT configuration (less secure)
//pkgs.dev.azure.com/YourOrg/_packaging/MyOrgNpmFeed/npm/registry/:_authToken=YOUR_PAT_HERE
