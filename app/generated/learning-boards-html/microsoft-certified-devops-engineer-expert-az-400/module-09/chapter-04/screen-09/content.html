Module 9 › Chapter 9.4 › Consuming npm Packages
Add to package.json

Declare your internal package as a dependency in your project's package.json file.

{  "name": "my-consumer-app",  "version": "1.0.0",  "dependencies": {    "@myorg/my-utility-library": "^1.0.0",    "express": "^4.17.1"  }}
Key Takeaway

Once declared, npm install will fetch packages from your configured Azure Artifacts feed.

Supporting Explanation
  • Automatic Resolution: With a correctly configured .npmrc, npm install automatically pulls from your private feed.
  • Dependency Management: Treat internal packages like any other external dependency, simplifying project setup.
  • Consistency & Reuse: Promotes sharing of common components across multiple projects.
  • Security: Keeps proprietary code private and secure within your organization's ecosystem.
The Consumption Flow
package.json
npm install
Azure Artifacts
Local node_modules
Common Mistake

Forgetting to map scoped packages (e.g., @myorg/mylibrary) to your private registry in .npmrc. Without this, npm will search the public registry, resulting in a 'package not found' error.
