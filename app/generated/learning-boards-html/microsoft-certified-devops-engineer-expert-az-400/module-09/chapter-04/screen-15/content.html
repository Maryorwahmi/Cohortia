Configuring .npmrc for Consumption

The .npmrc in your consumer app must map the scope to your private feed.

# .npmrc in MyConsumerNodeAppregistry=https://pkgs.dev.azure.com/YourOrg/_packaging/MyOrgNpmFeed/npm/registry/always-auth=true@your-org-name:registry=https://pkgs.dev.azure.com/YourOrg/_packaging/MyOrgNpmFeed/npm/registry/
Key Takeaway

Without the correct scope mapping, npm install will fail to find your private package.

Using the Package in app.js

After npm install, you can import and use the functions from your library.

// app.jsconst { greet, multiply } = require('@your-org-name/my-utility-library');console.log(greet('Cohortia Learner'));console.log(`5 * 6 = ${multiply(5, 6)}`);
Step-by-Step Consumption
  • Initialize Project: Create a new Node.js project and run npm init -y.
  • Configure .npmrc: Add the registry and scope mapping.
  • Install Package: Run npm install @your-org-name/my-utility-library@1.0.0.
  • Use in Code: require the package and call its functions.
  • Run Application: Execute your app using node app.js.
