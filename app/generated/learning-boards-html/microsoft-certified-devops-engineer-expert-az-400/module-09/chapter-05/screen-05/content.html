Configuration Guide

Maven Client Configuration: settings.xml

Connecting Maven to Azure Artifacts Feeds

Key Configuration Points

  • settings.xml: Global or project-specific Maven configuration file.
  • <servers>: Defines authentication credentials for repositories.
  • <profiles>: Activates specific repository configurations.
  • <repositories>: Specifies where Maven should look for dependencies.
  • <distributionManagement>: (in pom.xml) Defines where to publish artifacts.
Security Note

Storing PATs directly in settings.xml is not recommended for production. Use environment variables or secure credential management.

~/.m2/settings.xml Example
<settings xmlns="http://maven.apache.org/SETTINGS/1.1.0"> <servers> <server> <id>MyOrgMavenFeed</id> <!-- Matches repository ID in pom.xml --> <username>AzureDevOps</username> <password>YOUR_PAT_HERE</password> </server> </servers> <profiles> <profile> <id>azure-artifacts</id> <activation> <activeByDefault>true</activeByDefault> </activation> <repositories> <repository> <id>MyOrgMavenFeed</id> <url>https://pkgs.dev.azure.com/YourOrg/_packaging/MyOrgMavenFeed/maven/v1</url> <releases> <enabled>true</enabled> </releases> <snapshots> <enabled>true</enabled> </snapshots> </repository> </repositories> </profile> </profiles></settings>

This configuration defines a server for authentication and a profile to activate the Azure Artifacts repository.
