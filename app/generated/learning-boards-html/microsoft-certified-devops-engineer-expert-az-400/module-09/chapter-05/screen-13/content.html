Troubleshooting Guide

Common Issues & Resolutions

Diagnosing Maven/Gradle and Azure Artifacts Problems

Issue 1: 401 Unauthorized

  • Symptom: Pipeline fails with '401 Unauthorized' during artifact transfer.
  • Cause: Insufficient permissions for pipeline build identity on the Azure Artifacts feed.
  • Resolution: Grant 'Contributor' role to the build service identity in Feed Settings > Permissions.
Key Takeaway

Most authentication and artifact resolution issues stem from misconfigurations in permissions, feed URLs, or local client settings.

Issue 2: Could Not Find Artifact

  • Symptom: Consuming project fails with 'Could not find artifact' error.
  • Causes: Incorrect feed URL, missing local authentication (PAT), package view mismatch, or typos.
  • Resolution: Verify feed URL in pom.xml, ensure local settings.xml is configured, check package visibility/promotion in Azure Artifacts, and confirm dependency coordinates.

Troubleshooting Flow

Check Pipeline Permissions
Verify Feed URLs & IDs
Confirm Package Visibility & Version
