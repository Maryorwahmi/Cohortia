Authentication Deep Dive

Maven Authentication & Repository Details

Securing Access to Your Azure Artifacts Feed

Key Elements Explained

  • Server ID: Unique identifier for authentication credentials. Must match repository ID.
  • Username/Password: Typically 'AzureDevOps' and a Personal Access Token (PAT).
  • Repository URL: The specific endpoint for your Azure Artifacts Maven feed.
  • Releases/Snapshots: Controls which artifact types Maven fetches from the feed.
Pro Tip

Always ensure the <server> ID in settings.xml exactly matches the <repository> ID in your pom.xml for seamless authentication.

settings.xml Snippet Focus
<servers> <server> <id>MyOrgMavenFeed</id> <!-- This ID must match the repository ID in your pom.xml --> <username>AzureDevOps</username> <password>YOUR_PAT_HERE</password> </server></servers><profiles> <profile> <id>azure-artifacts</id> <activation> <activeByDefault>true</activeByDefault> </activation> <repositories> <repository> <id>MyOrgMavenFeed</id> <url>https://pkgs.dev.azure.com/YourOrg/_packaging/MyOrgMavenFeed/maven/v1</url> <releases> <enabled>true</enabled> </releases> <snapshots> <enabled>true</enabled> </snapshots> </repository> </repositories> </profile></profiles>

The highlighted sections demonstrate how server credentials are linked to repository definitions via matching IDs.
