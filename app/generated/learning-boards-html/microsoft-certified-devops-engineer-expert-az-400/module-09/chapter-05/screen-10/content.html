Azure Pipelines

Automating Maven Publish: Deployment Task

Building and Deploying Artifacts in Your Pipeline

Maven@4 Task Inputs

  • mavenPomFile: Path to your project's pom.xml.
  • goals: 'deploy': Instructs Maven to build and publish artifacts.
  • publishJUnitResults: Integrates test results into pipeline reports.
  • jdkVersionOption: Specifies the JDK version for the build agent.
Common Mistake

Mismatched server ID in settings.xml and distributionManagement ID in pom.xml, or insufficient pipeline permissions to the feed.

azure-pipelines.yml Deployment Step
steps:- task: MavenAuthenticate@0 displayName: 'Authenticate Maven to Azure Artifacts' inputs: artifactsFeeds: '$(mavenFeedServiceConnections)'- task: Maven@4 displayName: 'Build and Deploy Maven artifact' inputs: mavenPomFile: 'MyJavaLibrary/pom.xml' goals: 'deploy' publishJUnitResults: true testResultsFiles: '**/surefire-reports/TEST-*.xml' javaHomeOption: 'JDKVersion' jdkVersionOption: '1.17' mavenOptions: '-Xmx3072m'

This step shows how to use the Maven@4 task to build and deploy your Maven artifact.
