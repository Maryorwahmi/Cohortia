Key Concepts

Essential terms to remember

pom.xml (Maven)

Project Object Model, defining project configuration, dependencies, and build instructions.

build.gradle (Gradle)

The main build script for Gradle projects, defining tasks, dependencies, and repositories.

mvn deploy

A Maven command that builds a project and publishes its artifacts to a remote repository.

gradle publish

A Gradle task that publishes artifacts to configured repositories.

SNAPSHOT Version

A special version (e.g., 1.0.0-SNAPSHOT) indicating a work-in-progress, non-stable artifact.
