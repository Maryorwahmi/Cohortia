Publishing Generic Build Artifacts

Using PublishBuildArtifacts@1 in Azure Pipelines

# azure-pipelines.yml (Publishing generic build artifact)
steps:
- task: PublishBuildArtifacts@1
  displayName: 'Publish WebApp Artifact'
  inputs:
    pathToPublish: '$(Build.ArtifactStagingDirectory)/WebApp' # Path to your compiled web app
    artifactName: 'drop' # Name of the artifact
    publishLocation: 'Container' # Publish to Azure Pipelines internal storage

Task Inputs Explained

  • pathToPublish: The local path on the agent where the files to be published are located.
  • artifactName: A logical name for the artifact, used for identification.
  • publishLocation: Specifies where the artifact is stored. 'Container' means Azure Pipelines' internal storage.
Key Takeaway

The PublishBuildArtifacts@1 task provides a simple, effective way to store build-specific outputs directly within Azure Pipelines for immediate consumption by linked release pipelines.

Example Scenario

After compiling a web application, you can publish its .zip file as a generic artifact, making it available for a subsequent deployment stage in the same release pipeline.
