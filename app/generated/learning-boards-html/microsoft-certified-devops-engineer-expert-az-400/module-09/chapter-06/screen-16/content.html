Differentiating Artifact Types

Understanding Azure Pipeline Artifacts

Generic File Artifacts

Files or folders published directly from a build pipeline to Azure Pipelines' internal storage.

PublishBuildArtifacts@1

An Azure Pipeline task for publishing files as build artifacts to internal storage.

DownloadPipelineArtifact@2

An Azure Pipeline task for downloading build artifacts published by a previous pipeline.

Summary Takeaway

Generic File Artifacts are build-specific outputs managed by dedicated Azure Pipeline tasks, ideal for immediate consumption within the same pipeline context.
