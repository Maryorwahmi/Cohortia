Automating Universal Package Publishing

Integrating az artifacts universal publish into Azure Pipelines

# azure-pipelines.yml (Publishing Universal Package)
trigger:
- main

pool:
  vmImage: 'ubuntu-latest'

variables:
  universalPackageFeed: 'MyOrgUniversalFeed'
  universalPackageName: 'MyAppInstallers'
  universalPackageVersion: '1.0.$(Build.BuildId)'

steps:
- script: |
    echo "Creating dummy installer files..."
    mkdir -p $(Build.ArtifactStagingDirectory)/installers
    echo "Installer for Windows" > $(Build.ArtifactStagingDirectory)/installers/MyApp_Windows.exe
    echo "Installer for Linux" > $(Build.ArtifactStagingDirectory)/installers/MyApp_Linux.deb
    echo "README.txt" > $(Build.ArtifactStagingDirectory)/installers/README.txt
  displayName: 'Prepare Universal Package content'

- task: AzureCLI@2
  displayName: 'Publish Universal Package to Azure Artifacts'
  inputs:
    azureSubscription: 'YourAzureServiceConnection'
    scriptType: 'bash'
    scriptLocation: 'inlineScript'
    inlineScript: |
      az artifacts universal publish \
        --organization $(System.CollectionUri) \
        --feed $(universalPackageFeed) \
        --name $(universalPackageName) \
        --version $(universalPackageVersion) \
        --path $(Build.ArtifactStagingDirectory)/installers \
        --description "Installer package for MyApp, build $(Build.BuildId)"

Pipeline Breakdown

  • Variables: Define feed, package name, and dynamic version.
  • Prepare Content: A script to create or stage the files for the package.
  • AzureCLI@2 Task: Executes the az artifacts universal publish command.
  • Service Connection: Requires an Azure Resource Manager connection with 'Contributor' role on the feed.
Key Takeaway

Azure Pipelines can automate Universal Package publishing using the AzureCLI@2 task, ensuring consistent versioning and deployment of diverse artifacts.

Real-world Connection

This pattern is ideal for publishing application installers, configuration bundles, or machine learning models directly from your CI pipeline.
