Generic File Artifacts in Azure Pipelines

Simple Build Outputs for Immediate Pipeline Context

Definition

Generic File Artifacts are any files or folders published directly from a build pipeline to Azure Pipelines' internal artifact storage. They are tied to a specific build run and are not stored in an Azure Artifacts feed.

Key Characteristics

  • Build-Specific: Tied directly to the build that produced them.
  • Internal Storage: Stored within Azure Pipelines' internal artifact storage.
  • Simpler Lifecycle: Retention is typically linked to build retention policies.
  • Limited Scope: Primarily for consumption by linked release pipelines or within the same project.

Common Use Cases

  • Compiled application binaries (e.g., .zip of a web app).
  • Test results and code coverage reports.
  • Deployment scripts specific to a single application.
  • Intermediate build outputs for immediate consumption by a release stage.
Key Takeaway

Generic file artifacts are ideal for simple build outputs that are only relevant to the immediate pipeline context, offering a quick way to pass data between stages.
