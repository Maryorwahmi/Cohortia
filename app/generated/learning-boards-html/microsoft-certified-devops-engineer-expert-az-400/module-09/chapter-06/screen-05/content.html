Publishing Universal Packages

Using the Azure CLI for Artifact Uploads

# Azure CLI command to publish a Universal Package
az artifacts universal publish 
  --organization <YourOrgUrl> 
  --feed <FeedName> 
  --name <PackageName> 
  --version <PackageVersion> 
  --path <PathToContentDirectory> 
  --description "Optional package description"
Key Parameters

Understand the essential arguments for the publish command to ensure your package is correctly uploaded and versioned.

Key Takeaway

The az artifacts universal publish command is central to uploading any file or folder structure as a versioned Universal Package to Azure Artifacts.

Parameter Breakdown

  • --organization: Your Azure DevOps organization URL.
  • --feed: The target Azure Artifacts feed name.
  • --name: The unique name for your Universal Package.
  • --version: A semantic version (e.g., 1.0.0) or dynamic (e.g., 1.0.$(Build.BuildId)).
  • --path: Local directory containing files to be packaged.
  • --description: Optional, but recommended for clarity.
Pro Tip

Always use a consistent versioning scheme, often integrating the build number, to ensure traceability and easy retrieval of specific package states.
