Consuming Generic Build Artifacts

Retrieving Artifacts with DownloadPipelineArtifact@2

# azure-pipelines.yml (Consuming generic build artifact)
steps:
- task: DownloadPipelineArtifact@2
  displayName: 'Download WebApp Artifact'
  inputs:
    artifactName: 'drop'
    targetPath: '$(Pipeline.Workspace)/drop'

Task Inputs Explained

  • artifactName: The name of the artifact to download, matching the published name.
  • targetPath: The local directory on the agent where the artifact contents will be extracted.
Key Takeaway

The DownloadPipelineArtifact@2 task enables efficient retrieval of build-specific artifacts, facilitating their use in subsequent stages or release pipelines.

Example Scenario

A release pipeline can download a 'drop' artifact containing a web app, then deploy it to a staging environment, ensuring the correct build is used.
