Feeds: The Containers for Your Packages

A feed is a logical container in Azure Artifacts for storing, organizing, and sharing various package types.

Core Definition

A feed is a repository that holds a collection of packages, acting as a central hub for your software components.

Unique Access Point

Each feed has a unique URL that clients (like NuGet, npm, Maven) use to connect and retrieve packages.

Intelligent Handling

Azure Artifacts intelligently manages the specifics of each package format, ensuring proper indexing and metadata for efficient searching.
