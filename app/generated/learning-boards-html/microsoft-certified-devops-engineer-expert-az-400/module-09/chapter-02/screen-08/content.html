Upstream Sources: Bridging Public and Private Registries

Allows a single Azure Artifacts feed to act as a proxy for multiple public and private package registries, consolidating package access.

Proxy Functionality

Your feed can pull packages from external sources like nuget.org or npmjs.com, and also from other internal feeds.

Package Resolution Order

When a package is requested, Azure Artifacts checks locally first, then queries configured upstream sources in a defined order.

Simplified Client Configuration

Clients only need to connect to your single Azure Artifacts feed, simplifying dependency management.
