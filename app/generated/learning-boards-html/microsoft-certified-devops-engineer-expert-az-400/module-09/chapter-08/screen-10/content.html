YAML Example: Deploying a Web Application

A practical snippet for consuming build artifacts and deploying to Azure App Service.

Download Artifacts: The download: current step fetches all linked artifacts, specifically _WebApp, to the agent.

Unzip WebApp: A PowerShell task extracts webapp.zip from $(Pipeline.Workspace)/_WebApp to a temporary directory.

Deploy to Azure: The AzureRmWebAppDeployment@4 task deploys the prepared content to the specified Azure App Service.

Key Takeaway

This YAML example demonstrates the end-to-end process of consuming a build artifact, preparing it, and deploying it to an Azure Web App using standard tasks and variables.

stages: - stage: DeployToDev   displayName: 'Deploy to Development'   jobs:   - deployment: DeployWebApp     displayName: 'Deploy Web Application'     environment: 'Dev'     strategy:       runOnce:         deploy:           steps:           - download: current             artifact: _WebApp             # This will download _WebApp to $(Pipeline.Workspace)/_WebApp           - task: PowerShell@2             displayName: 'Unzip WebApp'             inputs:               targetType: 'inline'               script: |                 Expand-Archive -Path "$(Pipeline.Workspace)/_WebApp/webapp.zip" -DestinationPath "$(Agent.TempDirectory)/WebAppContent"           - task: AzureRmWebAppDeployment@4             displayName: 'Deploy Azure Web App'             inputs:               azureSubscription: 'YourAzureServiceConnection'               appType: 'webApp'               WebAppName: 'my-dev-webapp'               package: '$(Agent.TempDirectory)/WebAppContent'
