Key Concepts

Continuing with essential terms for artifact integration.

Download Strategy

How artifacts are fetched and placed on the build/release agent (e.g., download all, specific, skip).

$(Pipeline.Workspace)

A predefined variable in Azure Pipelines that points to the working directory on the agent where artifacts are downloaded.

Specific Versioning

The practice of explicitly defining the exact version of an artifact to be consumed, ensuring reproducibility and stability.

Summary Takeaway

Efficient artifact management relies on defining download strategies to the $(Pipeline.Workspace) and using specific versioning for reliable and reproducible deployments.
