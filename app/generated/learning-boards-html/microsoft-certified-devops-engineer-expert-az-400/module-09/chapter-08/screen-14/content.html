Key Concepts

Essential terms for artifact integration in release pipelines.

Release Pipeline

An Azure DevOps pipeline that automates the deployment of applications to various environments, consuming artifacts from build pipelines or other sources.

Artifact Linking

The process of associating build outputs or packages from various sources with a release pipeline, making them available for deployment.

Artifact Alias

A human-readable name assigned to a linked artifact, used to reference its content within the release pipeline's jobs and tasks.

Summary Takeaway

Release pipelines are the core of automated deployments, consuming linked artifacts that are referenced by clear aliases for efficient and reliable delivery.
