YAML Example: Universal Package Consumption

Downloading and using configuration packages with Azure CLI.

Azure CLI Task: Uses AzureCLI@2 to execute an inline Bash script for artifact download.

Universal Download: The az artifacts universal download command fetches the specified package from Azure Artifacts.

Target Path: The package contents are downloaded to $(Pipeline.Workspace)/_ConfigPackage, making them available for subsequent tasks.

Key Takeaway

The Azure CLI's az artifacts universal download command is essential for consuming Universal Packages, providing flexible integration of non-code assets like configurations.

          - task: AzureCLI@2             displayName: 'Download Configuration Universal Package'             inputs:               azureSubscription: 'YourAzureServiceConnection'               scriptType: 'bash'               scriptLocation: 'inlineScript'               inlineScript: |                 az artifacts universal download \                   --organization $(System.CollectionUri) \                   --feed 'MyOrgUniversalFeed' \                   --name 'AppConfigurations' \                   --version '1.0.123' \                   --path '$(Pipeline.Workspace)/_ConfigPackage'           # Now files from _ConfigPackage can be used, e.g., to overwrite config files           # - task: CopyFiles@2           #   inputs:           #     SourceFolder: '$(Pipeline.Workspace)/_ConfigPackage/dev'           #     TargetFolder: '$(Agent.TempDirectory)/WebAppContent/config'
