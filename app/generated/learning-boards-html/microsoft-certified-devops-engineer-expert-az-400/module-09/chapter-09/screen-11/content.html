Holistic Security

Extending Security to Containers and Infrastructure as Code

Scanning Docker images and IaC templates for misconfigurations.

Container Image Security

Docker images can contain vulnerabilities from their base layers or included packages. Scanning tools help identify these, and sourcing images from trusted registries prevents malicious injections.

Infrastructure as Code (IaC) Security

IaC templates (ARM, Bicep, Terraform) define your infrastructure. Misconfigurations in these templates can lead to security vulnerabilities in your deployed environments, making scanning essential.

Key Takeaway

A secure supply chain extends beyond application code and packages to include container images and infrastructure definitions, requiring comprehensive scanning.

Key Areas for Scanning

Docker Images

Scan for vulnerabilities using tools like Azure Security Center, Trivy, or Clair. Ensure images are from trusted registries.

IaC Templates

Scan ARM, Bicep, or Terraform templates for misconfigurations that could lead to security flaws in deployed infrastructure.
