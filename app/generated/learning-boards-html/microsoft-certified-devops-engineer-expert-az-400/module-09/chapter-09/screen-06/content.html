Access Control

Managing Administrative Permissions and Groups

Controlling elevated access and leveraging Azure Active Directory.

Elevated Permissions

Project Collection Administrators and Project Administrators automatically have elevated permissions over Azure Artifacts feeds. These groups must be tightly controlled and regularly audited to prevent unauthorized access.

Leveraging AAD Groups

Use Azure Active Directory (AAD) groups for managing user permissions. Assign roles to groups rather than individuals to simplify management, ensure consistency, and reduce the risk of misconfigurations.

Key Takeaway

Centralized management via AAD groups and strict control over administrative roles are crucial for scalable and secure artifact management.

Best Practices for Admin & Groups

Tightly Control Admin Groups

Ensure Project Collection and Project Administrators are a very small, trusted group.

Use AAD Groups for Users

Simplify management and enforce consistent permissions by assigning roles to AAD groups.

Avoid Individual Contributor/Owner

Never give 'Contributor' or 'Owner' permissions to individual developers for production feeds unless strictly necessary and audited.
