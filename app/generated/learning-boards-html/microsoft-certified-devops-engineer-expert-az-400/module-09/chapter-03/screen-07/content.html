Configuring NuGet in Azure Pipelines

Streamline NuGet feed access for your automated builds.

How Pipelines Authenticate

  • Dedicated Tasks: Use `NuGetAuthenticate@1` or `DotNetCoreCLI@2` to configure the build agent.
  • Service Identity: Authentication uses the pipeline's service identity, not personal credentials.
  • Secure & Automated: Eliminates manual `nuget.config` editing and PAT management in pipelines.
Key Takeaway

Azure Pipelines tasks simplify NuGet configuration and securely authenticate to Azure Artifacts feeds using the pipeline's service identity, ensuring smooth automated builds.

Example: Pipeline Task
steps: - task: DotNetCoreCLI@2 displayName: 'Restore dependencies' inputs: command: 'restore' projects: '**/*.csproj' feedsToUse: 'config' # Uses nuget.config for sources # Alternatively, specify feed directly: # feedsToUse: 'select' # nugetFeedType: 'internal' # feedRestore: 'MyOrgNuGetFeed'
Common Mistake

Forgetting to grant the pipeline's build service identity 'Reader' permissions on the Azure Artifacts feed will lead to authentication failures during restore.
