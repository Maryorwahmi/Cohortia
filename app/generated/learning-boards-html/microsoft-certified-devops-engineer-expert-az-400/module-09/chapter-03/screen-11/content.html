Consuming NuGet Packages: Project Reference

Integrate private NuGet packages into your .NET projects.

How to Reference a Package

  • Add `PackageReference`: Include an `ItemGroup` with `PackageReference` in your `.csproj` file.
  • Specify Package Name & Version: Use the exact name and desired version of your NuGet package.
  • Run `dotnet restore`: This command resolves and downloads the package from your configured feeds.
Key Takeaway

Consuming NuGet packages from Azure Artifacts is done via `PackageReference` in the `.csproj` file, relying on `dotnet restore` to resolve dependencies from configured feeds.

Example: .csproj Reference
<Project Sdk="Microsoft.NET.Sdk.Web"> <PropertyGroup> <TargetFramework>net8.0</TargetFramework> </PropertyGroup> <ItemGroup> <PackageReference Include="MyOrg.MyLibrary" Version="1.0.0" /> <!-- Your internal package --> <PackageReference Include="Newtonsoft.Json" Version="13.0.3" /> <!-- Public package (cached) --> </ItemGroup> </Project>
Common Mistake

Forgetting to configure `nuget.config` with your Azure Artifacts feed will prevent `dotnet restore` from finding your private packages.
