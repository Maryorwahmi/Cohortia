Configuring NuGet Clients Locally

Set up your local environment to access private Azure Artifacts feeds.

Key Steps for Local Configuration

  • Locate/Create `nuget.config`: This file can be in your project root, user profile, or system-wide.
  • Add Feed Source: Use `dotnet nuget add source` or manually add an entry to `packageSources`.
  • Ensure Authentication: The Azure DevOps Credential Provider handles token acquisition for seamless access.
Key Takeaway

Proper `nuget.config` setup with the correct feed URL and authentication mechanism is essential for local NuGet client interaction with Azure Artifacts.

Example: nuget.config
<?xml version="1.0" encoding="utf-8"?> <configuration> <packageSources> <add key="nuget.org" value="https://api.nuget.org/v3/index.json" protocolVersion="3" /> <add key="MyOrgNuGetFeed" value="https://pkgs.dev.azure.com/YourOrg/_packaging/MyOrgNuGetFeed/nuget/v3/index.json" /> </packageSources> <!-- Authentication details are often handled by credential providers --> </configuration>
Command Line Example
dotnet nuget add source "https://pkgs.dev.azure.com/YourOrg/_packaging/MyOrgNuGetFeed/nuget/v3/index.json" --name "MyOrgNuGetFeed"
