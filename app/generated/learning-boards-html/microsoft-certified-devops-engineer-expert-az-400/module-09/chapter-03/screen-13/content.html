Troubleshooting

Common Issue: NuGet Feed Not Found

Diagnose and resolve errors when `dotnet restore` can't find your feed.

Root Causes & Solutions

  • Incorrect `nuget.config`: The feed URL or name is misspelled or missing.
    Solution: Verify `nuget.config` for exact feed name and URL. Use "Connect to feed" in Azure Artifacts for the correct URL.
  • Authentication Failure: Lack of credentials to access the private feed.
    Solution: Install Azure Artifacts Credential Provider (local) or ensure pipeline identity has 'Reader' permissions (pipeline).
Key Takeaway

When a NuGet feed is not found, always check your `nuget.config` for correct feed details and verify that the client or pipeline has proper authentication to access the private feed.
