Publishing Process

Publishing NuGet Packages: Overview

Learn the fundamental steps to share your internal .NET libraries.

The Two-Step Publishing Flow

  • 1. Create the Package (`dotnet pack`): Generates the `.nupkg` file containing your compiled code and metadata.
  • 2. Publish the Package (`dotnet nuget push`): Uploads the `.nupkg` file to your designated Azure Artifacts feed.
Key Takeaway

The `dotnet pack` and `dotnet nuget push` commands are the core tools for publishing your .NET libraries as NuGet packages to Azure Artifacts, typically within a CI pipeline.
