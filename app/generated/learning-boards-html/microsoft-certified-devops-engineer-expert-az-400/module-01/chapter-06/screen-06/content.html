Creating a Basic YAML CI Pipeline
Automating a Node.js Application Build

Let's create a basic CI pipeline for a Node.js application using YAML. This pipeline will automate dependency installation, building, and testing.

Trigger: trigger: - main runs the pipeline on every push to the main branch.

Pool: pool: vmImage: 'ubuntu-latest' specifies a Microsoft-hosted Ubuntu agent.

Stage: stage: Build defines a logical phase for building and testing.

Job: job: BuildJob groups steps that run on a single agent.

Steps: Include tasks like NodeTool@0 for Node.js installation, custom scripts for npm install and npm run build, and npm test.

Artifacts: PublishBuildArtifacts@1 publishes the build output (e.g., from the dist folder) for later use.

Key Takeaway

A YAML pipeline defines triggers, agent pools, stages, jobs, and steps to automate build and test processes for applications.

Example YAML Structure
# azure-pipelines.yml
trigger:
- main

pool:
  vmImage: 'ubuntu-latest'

stages:
- stage: Build
  displayName: Build and Test Application
  jobs:
  - job: BuildJob
    displayName: Build and Test
    steps:
    - task: NodeTool@0
      displayName: 'Use Node.js 18.x'
      inputs:
        versionSpec: '18.x'

    - script: |
        npm install
        npm run build
      displayName: 'Install dependencies and Build'

    - script: |
        npm test
      displayName: 'Run tests'

    - task: PublishBuildArtifacts@1
      displayName: 'Publish Artifacts'
      inputs:
        pathToPublish: '$(System.DefaultWorkingDirectory)/dist'
        artifactName: 'drop'
