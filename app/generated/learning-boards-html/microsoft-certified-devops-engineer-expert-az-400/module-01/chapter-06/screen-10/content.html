Question: A developer pushes code to the main branch, triggering an Azure Pipeline. The pipeline successfully builds the application and runs all unit tests. However, the application is not automatically deployed to the production environment. What type of CI/CD practice is this team most likely implementing?

  • a) Continuous Deployment
  • b) Continuous Integration
  • c) Continuous Delivery
  • d) Manual Deployment

Explanation: Continuous Delivery means code is automatically built, tested, and prepared for release, but the actual deployment to production is a manual step.

Key Takeaway

A pipeline that builds and tests code but requires manual deployment to production exemplifies Continuous Delivery.

Answer & Rationale
Correct Answer: c) Continuous Delivery
Continuous Delivery ensures that code is always in a deployable state, ready for a manual release to production after passing automated builds and tests.
