Assessment: Azure Pipelines Agents
Understanding Agent Configuration

Question: Your Azure Pipeline YAML defines a pool with vmImage: 'windows-latest'. What does this configuration specify?

  • a) The pipeline will only run on self-hosted agents running Windows.
  • b) The pipeline will use a Microsoft-hosted agent with the latest Windows operating system.
  • c) The pipeline requires a specific Azure Virtual Machine to be provisioned for each run.
  • d) The pipeline will deploy the application to a Windows-based Azure App Service.

Explanation: The pool section specifies the agent pool. vmImage indicates a Microsoft-hosted agent image, and 'windows-latest' selects the latest Windows version.

Key Takeaway

Specifying vmImage in the agent pool configuration directs the pipeline to use a Microsoft-hosted agent with the indicated operating system.

Answer & Rationale
Correct Answer: b) Microsoft-hosted agent
This configuration leverages Azure's managed infrastructure for pipeline execution, providing a pre-configured Windows environment.
