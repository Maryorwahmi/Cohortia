Activity: Creating a Basic CI Pipeline
Automating a Node.js Application Build and Test

Let's create a basic CI pipeline for a Node.js application using Azure Pipelines and YAML.

  1. Prerequisites: Azure DevOps project, Azure Repo with a Node.js project (package.json, index.js) committed to main.
  2. Create Pipeline: In Azure DevOps, navigate to Pipelines -> New pipeline. Select 'Azure Repos Git', your repository, and 'Starter pipeline'.
  3. Edit YAML: Replace the default content with the provided azure-pipelines.yml (see previous screen for structure).
  4. Save and Run: Commit the YAML file and trigger the pipeline run.
  5. Monitor: Observe the pipeline execution, check logs for each step (install, build, test).
  6. Verify Artifacts: Confirm the 'drop' artifact containing build outputs is published.
Key Takeaway

Successfully configuring and running a basic CI pipeline is a fundamental skill for automating build and test processes.
