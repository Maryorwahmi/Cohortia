Azure Pipelines Components and Workflow
Orchestrating Your Code Delivery

Azure Pipelines is a service within Azure DevOps that enables you to implement CI/CD for virtually any language, platform, and cloud. It supports both YAML-based pipelines (preferred for their version control and reusability) and a classic visual editor.

Pipeline: The entire workflow, typically defined in a azure-pipelines.yml file.

Stages: Logical divisions in a pipeline, representing major phases like Build, Test, Deploy. Stages run sequentially.

Jobs: Series of steps that run together on an agent. Multiple jobs can run in parallel within a stage.

Steps: The smallest building blocks, representing individual tasks or scripts.

Tasks: Pre-defined scripts or actions provided by Azure DevOps or the marketplace (e.g., DotNetCoreCLI@2, npm@1).

Agents: Compute infrastructure that runs your jobs (Microsoft-hosted or self-hosted).

Triggers: Define when your pipeline should run (e.g., on commit, schedule, manually).

Key Takeaway

Azure Pipelines structure your automation using stages, jobs, steps, tasks, agents, and triggers for efficient CI/CD.
