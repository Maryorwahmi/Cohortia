Core Concept

What are ARM Templates?

ARM templates are JSON files that declaratively define the resources you want to deploy, their configurations, and their dependencies. The ARM service orchestrates the deployment based on this definition.

JSON-based

Standard format for defining resources.

Declarative

Describe the desired state, not the steps.

Key Takeaway

ARM templates provide a blueprint for your Azure infrastructure, allowing for automated, consistent, and dependency-aware deployments.

Example

Defining a Storage Account

A simple ARM template can define an Azure Storage Account, specifying its name, location, SKU (e.g., Standard_LRS), and kind (e.g., StorageV2). The template declares these properties, and ARM handles the provisioning.

How ARM Handles Dependencies

Intelligent Orchestration

If your template defines a virtual network and then a virtual machine that uses that network, ARM automatically understands the dependency. It ensures the virtual network is fully deployed and available before it attempts to create the virtual machine, preventing deployment errors.
