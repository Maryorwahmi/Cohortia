Key Concepts

Essential Terms to Remember

Git

A distributed version control system (DVCS) widely used for tracking changes in source code during software development.

Repository (Repo)

A storage location for a project's files, along with the complete history of changes.

Commit

A snapshot of changes to the repository at a specific point in time, identified by a unique SHA-1 hash.

Branch

A separate line of development that allows developers to work on features or fixes in isolation without affecting the main codebase.

Key Idea

These core concepts form the foundation for effective source control and collaborative development using Git and Azure Repos.
