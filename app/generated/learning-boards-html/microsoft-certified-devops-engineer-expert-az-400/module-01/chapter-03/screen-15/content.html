Key Concepts

Essential Terms to Remember

Merge

The process of combining changes from one branch into another.

Pull Request (PR)

A mechanism in Azure Repos to propose changes, facilitate code review, and discuss modifications before merging them into a target branch.

Branch Policies

Rules enforced on specific branches in Azure Repos to ensure code quality, consistency, and stability (e.g., requiring reviewers, linked work items, successful builds).

Trunk-Based Development (TBD)

A branching strategy where developers commit small, frequent changes directly to a single main branch, often using feature flags.

Key Idea

These core concepts form the foundation for effective source control and collaborative development using Git and Azure Repos.
