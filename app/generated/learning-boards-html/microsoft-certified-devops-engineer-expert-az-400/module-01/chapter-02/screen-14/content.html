Key Concepts: Part 1

Essential SRE terms to remember

Site Reliability Engineering (SRE)

Applies software engineering principles to operations, aiming for highly reliable and scalable systems.

Service Level Indicator (SLI)

A quantitative measure of a service aspect, reflecting user experience (e.g., latency, error rate).

Service Level Objective (SLO)

A target value for an SLI, defining acceptable service performance (e.g., 99.9% requests under 300ms).

Summary Takeaway

SRE provides a structured, engineering-driven approach to reliability, using SLIs to measure and SLOs to define performance targets for services.
