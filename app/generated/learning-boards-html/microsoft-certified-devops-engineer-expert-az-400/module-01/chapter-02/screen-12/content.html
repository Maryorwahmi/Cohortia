Applying SRE: Defining SLIs and SLOs for E-commerce

A practical example of setting reliability targets for a web application.

E-commerce SLI/SLO Definition

  • **Identify Journeys:** Browsing products, adding to cart, checkout.
  • **Propose SLIs:** Page load latency, API success rate, transaction latency.
  • **Define SLOs:** Specific targets for each SLI (e.g., 99% under 1.5s).
  • **Justify:** Explain importance for user experience and business.
Key Takeaway

Defining SLIs and SLOs based on critical user journeys ensures that reliability efforts directly support business goals and user satisfaction.

E-commerce Example
Browsing Products

SLI: Page Load Latency
SLO: 99% of loads < 1.5s

Adding to Cart

SLI: Add-to-Cart API Success Rate
SLO: 99.9% success (HTTP 2xx)

Checkout Process

SLI: Checkout Transaction Latency
SLO: 99.5% complete < 5s

Why it Matters

Clear SLIs and SLOs provide measurable targets that directly correlate with a positive user experience and business revenue, making reliability a tangible goal.
