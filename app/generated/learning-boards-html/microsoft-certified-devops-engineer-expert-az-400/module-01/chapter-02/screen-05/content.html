Key Metric

Measuring Service Health with SLIs

Quantitative measures reflecting user experience and system performance.

What are SLIs?

  • **Definition:** Quantitative measures of a service aspect.
  • **Purpose:** Answer 'What are we measuring?' from a user perspective.
  • **Importance:** Must truly reflect user experience, not just internal system health.
  • **Examples:** Request latency, error rate, system throughput.
Key Takeaway

Effective SLIs are directly tied to user experience, providing clear, measurable insights into service quality.

SLI Examples
Request Latency

Time to respond to a user request.

Error Rate

Percentage of failed requests.

System Throughput

Requests processed per second.

Availability

Uptime percentage of the service.

Concrete Example

For an e-commerce site, 'Page Load Latency' (time for a product page to fully render) is a critical SLI because slow pages directly frustrate users and impact sales.
