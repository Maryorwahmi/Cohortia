Queries: Filtering and Grouping Work Items

Extracting specific data to track progress and identify trends.

What are Queries?

Queries are powerful search mechanisms in Azure Boards that allow you to filter and group work items based on various criteria, such as work item type, state, assignment, priority, and more.

Benefits of Using Queries

  • Targeted Information: Find specific work items quickly.
  • Progress Tracking: Monitor status of tasks, bugs, or features.
  • Reporting Foundation: Serve as data sources for dashboards.
  • Shared Visibility: Save and share queries with your team.
Key Takeaway

Azure Boards Queries are essential for transforming raw work item data into actionable insights, enabling precise tracking, reporting, and informed decision-making across your project.

Building a Simple Query

Clause 1: Work Item Type = 'Task'

Clause 2: State <> 'Closed'

Clause 3: Assigned To = '@Me'

Example: Finding Your Open Tasks

You can create a query to find all tasks where 'Work Item Type = Task', 'State <> Closed', and 'Assigned To = @Me'. This query quickly shows you all the active tasks you are currently responsible for, helping you manage your personal workload.
