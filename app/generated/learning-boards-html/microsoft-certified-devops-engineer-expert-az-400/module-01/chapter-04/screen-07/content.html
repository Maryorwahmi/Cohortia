Work Items: The Fundamental Units of Work

Tracking all types of work with customizable items in Azure Boards.

What are Work Items?

Work Items are the core records in Azure Boards used to track tasks, bugs, user stories, features, and epics. They provide a structured way to define, assign, and monitor all activities within a project.

Process Templates

The available work item types depend on the process template chosen for your Azure DevOps project (e.g., Agile, Scrum, CMMI, Basic). Each template offers a tailored set of work item definitions.

Key Takeaway

Work Items are the foundational elements in Azure Boards for organizing and tracking all project activities, with types varying based on the selected process template.

Common Work Item Types

Epic

Large strategic goal

Feature

Specific functionality

User Story

User-centric requirement

Bug

Defect or issue

Example: Project for Online Store

For an online store, an 'Epic' might be 'Improve Customer Experience'. A 'Feature' under that could be 'User Account Management'. A 'User Story' would be 'As a user, I want to reset my password'. A 'Task' would be 'Implement password reset API'.
