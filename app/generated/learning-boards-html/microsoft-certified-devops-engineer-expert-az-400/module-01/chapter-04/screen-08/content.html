Hierarchy & Planning

Epics and Features: High-Level Strategic Goals

Structuring large bodies of work into manageable, value-driven components.

Epics: The Big Picture

Epics represent large, overarching strategic goals or initiatives. They are typically too big to be completed in a single sprint and are broken down into multiple features.

Features: Delivering Value

Features are smaller than epics and deliver specific functionality or value to the user. An epic can contain several related features, each contributing to the epic's overall goal.

Key Takeaway

Epics and Features form a crucial hierarchy in Azure Boards, enabling teams to align detailed work with high-level strategic objectives and manage large initiatives effectively.

Work Item Hierarchy

Epic: Enhance Customer Engagement

Feature: Personalized Recommendations

Feature: Improved Search Functionality

User Story: As a user, I want to see recommended products.

User Story: As a user, I want to filter search results.

Example: E-commerce Platform

An 'Epic' for an e-commerce platform could be 'Expand International Market'. Under this, a 'Feature' might be 'Support Multi-currency Payments', which then breaks down into 'User Stories' like 'As a user, I want to pay in Euros'.
