Mastering kubectl: Your Command-Line Interface

Essential commands for managing your Kubernetes cluster.

Common kubectl Commands

  • •kubectl get pods: Lists all pods in the current namespace.
  • •kubectl get deployments: Lists all deployments.
  • •kubectl get services: Lists all services.
  • •kubectl describe pod <pod-name>: Shows detailed info about a specific pod.
  • •kubectl apply -f <manifest-file.yaml>: Creates/updates resources from YAML.
  • •kubectl delete -f <manifest-file.yaml>: Deletes resources from YAML.
  • •kubectl logs <pod-name>: Retrieves logs from a container in a pod.
Key Takeaway

kubectl is your primary tool for managing Kubernetes, enabling you to inspect, deploy, and troubleshoot your containerized applications effectively.

kubectl in Action

# List all pods in the current namespace
kubectl get pods

# Output example:
# NAME                           READY   STATUS    RESTARTS   AGE
# my-app-deployment-789c7d4d-abcde   1/1     Running   0          5m

# Describe a specific pod for detailed info
kubectl describe pod my-app-deployment-789c7d4d-abcde

# Output example (truncated):
# Name:         my-app-deployment-789c7d4d-abcde
# Namespace:    default
# Node:         minikube/192.168.49.2
# Start Time:   Thu, 01 Jan 1970 00:00:00 +0000
# Labels:       app=my-app
#               pod-template-hash=789c7d4d
# Status:       Running
# ...

# Get logs from a container in a pod
kubectl logs my-app-deployment-789c7d4d-abcde

# Output example:
# Nginx is running...
# Serving requests...

Pro-Tip: Use `--watch` for Live Updates

Add -w or --watch to kubectl get commands (e.g., kubectl get pods -w) to see real-time updates of your resources, which is incredibly useful for monitoring deployments and troubleshooting.
