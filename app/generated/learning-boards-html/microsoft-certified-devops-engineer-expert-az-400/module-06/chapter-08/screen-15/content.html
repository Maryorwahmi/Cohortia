Essential Security & Governance Terms

Core ideas for containerized workloads

Container Image Scanning

Analyzing Docker images for known vulnerabilities, often integrated into CI/CD and registries like ACR.

Network Policies (Kubernetes)

Firewall rules for Pods that control allowed network communication between Pods and other network endpoints.

Azure Policy for AKS

Azure's governance service extended to Kubernetes, allowing enforcement of security and compliance standards on AKS clusters.

Summary Takeaway

These concepts form the foundational pillars for securing containerized workloads, enabling proactive vulnerability management, granular network control, and consistent compliance enforcement.
