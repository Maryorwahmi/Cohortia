Azure Policy for AKS
Admission Control & Policy Enforcement
OPA Gatekeeper's Role

Intercepts all requests to the Kubernetes API server, validating them against defined Azure Policies before allowing or denying the action.

Enforcement Options

Policies can be configured to either deny non-compliant requests (preventative) or audit them (monitoring) for later review.

Enable Azure Policy for AKS
az aks enable-addons --addons azure-policy --name cohortiaAksCluster --resource-group CohortiaAksRG
