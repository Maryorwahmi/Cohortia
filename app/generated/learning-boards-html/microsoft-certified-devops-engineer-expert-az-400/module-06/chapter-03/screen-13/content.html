Deployment Workflow

Tagging and Pushing Your Image to ACR

Making your container image available for Azure deployments.

1. Tag Your Local Docker Image

The image needs to be tagged with the Fully Qualified Domain Name (FQDN) of your ACR (e.g., myregistry.azurecr.io/my-app:1.0).

2. Push the Image to ACR

Use the docker push command to upload your newly tagged image to your private Azure Container Registry.

Verification

After pushing, verify the image's presence in the Azure portal under your ACR instance's 'Repositories' section, or use az acr repository show-tags.

Docker Commands:
# Assume ACR FQDN is mycohortiaregistry.azurecr.io# 1. Tag your local Docker image for ACRdocker tag my-app:1.0 mycohortiaregistry.azurecr.io/my-app:1.0# 2. Push the image to ACRdocker push mycohortiaregistry.azurecr.io/my-app:1.0
Expected Output (example):
The push refers to repository [mycohortiaregistry.azurecr.io/my-app]...1.0: Pushed...Digest: sha256:...
Key Takeaway

Correctly tagging and pushing your Docker images to ACR is the final step to make them securely available for deployment across Azure services.
