Deployment Workflow

Setting Up and Logging into Azure Container Registry

Preparing your Azure environment for secure image storage.

1. Log in to Azure CLI

Ensure you are authenticated with Azure using az login. This provides the necessary permissions for ACR operations.

2. Create an ACR Instance

Use az group create and az acr create to provision a new Azure Container Registry in your desired resource group and location.

3. Log in to your ACR

Authenticate directly to your ACR using az acr login --name <your-acr-name>. This grants Docker access to your private registry.

Azure CLI Commands:
# 1. Log in to Azureaz login# 2. Create a resource group and ACRaz group create --name myResourceGroup --location eastusaz acr create --resource-group myResourceGroup \           --name myCohortiaRegistry --sku Basic# 3. Log in to your ACRaz acr login --name myCohortiaRegistry
Expected Output:
Login Succeeded
Key Takeaway

Setting up and logging into ACR via Azure CLI is the foundational step to securely store and manage your container images for Azure deployments.
