Process Flow

The Kubernetes@1 Task for AKS Deployment

Applying manifest files and running `kubectl` commands

01

Define Manifests

Create Kubernetes manifest files (e.g., `deployment.yaml`, `service.yaml`) in your source control.

02

Configure Task

Add `Kubernetes@1` task to your pipeline, specifying connection details for AKS.

03

Specify Command

Set `command: 'apply'` to instruct the task to deploy your Kubernetes objects.

04

Provide Arguments

List the manifest files as arguments (e.g., `-f deployment.yaml -f service.yaml`).

05

Execute Deployment

The task executes, applying the manifests to your target AKS cluster.

06

Verify Deployment

Confirm application status on AKS using `kubectl` commands after pipeline completion.

Key Takeaway

The `Kubernetes@1` task is essential for automating AKS deployments, allowing pipelines to apply manifests and run `kubectl` commands.
