# ... (previous build stage) ...

- stage: Deploy
  displayName: Deploy to AKS
  dependsOn: Build
  jobs:
  - job: DeployToAKS
    displayName: Deploy Application to AKS
    pool:
      vmImage: 'ubuntu-latest'
    
    steps:
    - checkout: self # Ensure source code is available in deploy stage

    - task: replacetokens@3
      displayName: 'Replace Image Tag in Manifest'
      inputs:
        rootDirectory: '$(Build.SourcesDirectory)/kubernetes'
        targetFiles: |
          deployment.yaml
        tokenPrefix: '#{'
        tokenSuffix: '}#'
        variables: |
          tag
          acrName
          imageRepository
      condition: succeeded()
Code Walkthrough

Implementing Token Replacement

Using `replacetokens@3` to update image tags in manifests

Targeting Manifests

`rootDirectory` and `targetFiles` specify which Kubernetes YAML files will be scanned and modified.

Defining Placeholders

`tokenPrefix` and `tokenSuffix` establish the unique syntax for your dynamic placeholders (e.g., `#{tag}#`).

Variable Injection

The `variables` input lists the pipeline variables whose values will replace the identified tokens in the manifests.

Key Takeaway

The `replacetokens@3` task is a powerful way to dynamically update Kubernetes manifests with pipeline-specific values like image tags, ensuring accurate deployments.
