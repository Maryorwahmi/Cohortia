Key Concepts

Advanced deployment and management terms

Kubernetes@1 Task

An Azure Pipeline task used to interact with Kubernetes clusters (e.g., apply manifests, run `kubectl` commands).

Continuous Deployment (CD)

The practice of automating the deployment of code changes to production environments after successful testing.

Image Tagging in CI/CD

Using pipeline variables (e.g., `$(Build.BuildId)`) to dynamically tag Docker images for traceability.

Dynamic Manifest Updates

Techniques (e.g., token replacement, Helm, Kustomize) to inject dynamic values into Kubernetes manifest files during a pipeline run.

Summary Takeaway

Mastering Kubernetes deployment tasks, continuous deployment strategies, dynamic image tagging, and manifest updates is crucial for robust containerized CI/CD.
