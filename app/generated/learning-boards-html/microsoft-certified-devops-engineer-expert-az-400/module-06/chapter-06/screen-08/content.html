stages:
- stage: Build
  displayName: Build and Push Docker Image
  jobs:
  - job: BuildAndPush
    displayName: Build and Push to ACR
    pool:
      vmImage: 'ubuntu-latest'

    steps:
    - task: Docker@2
      displayName: Build Docker Image
      inputs:
        containerRegistry: 'YourACRServiceConnection' # Name of your Docker Registry Service Connection
        repository: '$(imageRepository)'
        command: 'build'
        Dockerfile: '$(dockerfilePath)'
        tags: |
          $(tag)

    - task: Docker@2
      displayName: Push Docker Image
      inputs:
        containerRegistry: 'YourACRServiceConnection'
        repository: '$(imageRepository)'
        command: 'push'
        tags: |
          $(tag)
Code Walkthrough

Building and Pushing with Docker@2

Implementing the build and push commands in YAML

Build Command

The first `Docker@2` task uses `command: 'build'` to create the Docker image from your specified Dockerfile.

Push Command

The second `Docker@2` task uses `command: 'push'` to upload the newly built and tagged image to your Azure Container Registry.

Service Connection & Tags

Both tasks rely on the `containerRegistry` input for authentication and `tags` (e.g., `$(Build.BuildId)`) for versioning.

Key Takeaway

The `Docker@2` task efficiently handles both building and pushing Docker images, making them available in ACR for deployment.
