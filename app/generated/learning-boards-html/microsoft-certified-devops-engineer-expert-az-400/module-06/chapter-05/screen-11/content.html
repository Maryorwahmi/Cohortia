Advanced External Exposure: Ingress Controllers

Managing complex HTTP/S routing for multiple services.

What is an Ingress Controller?

An Ingress Controller is a specialized load balancer that provides HTTP/S routing for external access to services within a Kubernetes cluster.

  • •Enables path-based and host-based routing.
  • •Supports SSL/TLS termination at the edge of the cluster.
  • •Consolidates external access for multiple services.
  • •Requires an Ingress resource to define routing rules.
Key Takeaway

Ingress Controllers offer flexible and powerful Layer 7 routing for complex application architectures in AKS.

# ingress.yaml (requires an Ingress Controller deployed)apiVersion: networking.k8s.io/v1kind: Ingressmetadata:  name: dotnet-api-ingress  annotations:    kubernetes.io/ingress.class: nginx # Or azure/application-gatewayspec:  rules:  - host: api.yourdomain.com    http:      paths:      - path: /        pathType: Prefix        backend:          service:            name: dotnet-api-service            port:              number: 80
Ingress vs. LoadBalancer

Ingress provides Layer 7 (HTTP/S) routing for multiple services, while LoadBalancer provides Layer 4 (TCP/UDP) routing for a single service.
