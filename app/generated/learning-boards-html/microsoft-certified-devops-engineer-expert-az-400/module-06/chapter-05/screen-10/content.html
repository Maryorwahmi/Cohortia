Exposing Applications with LoadBalancer Service

Making your services accessible from outside the cluster.

How it Works

A LoadBalancer Service type automatically provisions an external cloud load balancer (Azure Load Balancer) with a public IP address.

  • •Provides a public IP address for external access.
  • •Distributes incoming traffic across healthy Pods.
  • •Ideal for exposing a single service directly to the internet.
  • •Each LoadBalancer Service typically incurs a cost.
Key Takeaway

The LoadBalancer Service type is the simplest way to get a public, external IP for your application in AKS.

LoadBalancer Service Flow
External User
Azure Load Balancer (Public IP)
Kubernetes Service (dotnet-api-service)
Application Pods (dotnet-api)
Cost Consideration

Be mindful that each LoadBalancer Service provisions a dedicated Azure Load Balancer and public IP, which can add to your cloud costs.
