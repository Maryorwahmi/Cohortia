AKS Networking Fundamentals

Understanding communication paths within and outside your cluster.

Service Types Recap

Different Service types dictate how your application is exposed, both internally and externally.

  • •ClusterIP: Internal-only access, stable internal IP.
  • •NodePort: Exposes on a static port on each node's IP.
  • •LoadBalancer: Provisions an external cloud load balancer with a public IP.
  • •Ingress: Layer 7 routing for HTTP/S traffic, often for multiple services.
Key Takeaway

A solid understanding of AKS networking is essential for designing scalable, secure, and accessible applications.

AKS Network Models
Azure CNI
  • •Each Pod gets VNet IP
  • •Better VNet integration
  • •Advanced networking
Kube-net
  • •Pods share node IP
  • •NAT for external access
  • •Simpler, less scalable
Misconception

Assuming all Services are externally accessible by default. Only LoadBalancer and Ingress types provide public access.
