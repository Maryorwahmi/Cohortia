Deploying Manifests with kubectl apply

Bringing your application definitions to life in AKS.

The kubectl apply Command

kubectl apply -f <filename> is used to create or update Kubernetes resources defined in a manifest file.

  • •Declaratively applies changes defined in YAML files.
  • •Creates resources if they don't exist, updates them if they do.
  • •Idempotent: running it multiple times has the same effect.
  • •Essential for CI/CD pipelines and automated deployments.
Key Takeaway

kubectl apply is your primary tool for deploying and managing the lifecycle of your applications in AKS.

# Deploy the Deployment manifestkubectl apply -f deployment.yaml# Deploy the Service manifestkubectl apply -f service.yaml# Check deployment statuskubectl get deployments# Check Pod status for your applicationkubectl get pods -l app=dotnet-api# Check service status (look for EXTERNAL-IP)kubectl get services
Monitoring Tip

Use kubectl get services -w to watch for the EXTERNAL-IP of your LoadBalancer Service to become available, as it can take a few minutes.
