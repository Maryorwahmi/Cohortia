Multi-Stage Builds in Action: .NET Example (Part 2)

Creating the final, lean runtime image for production.

Dockerfile: Final Runtime Stage

# Stage 2: Publish and create the final runtime image
FROM mcr.microsoft.com/dotnet/aspnet:6.0 AS final
WORKDIR /app
COPY --from=build /app/build .
ENTRYPOINT ["dotnet", "MyApp.dll"]

Explanation of Final Stage

  • •FROM ... AS final: Starts a new stage using the smaller .NET ASP.NET runtime image.
  • •COPY --from=build: Crucially, copies *only* the compiled application from the 'build' stage.
  • •Discards all build-time dependencies and tools, resulting in a minimal image.
  • •ENTRYPOINT: Defines the command to execute when the container starts.
Key Takeaway

The final stage of a multi-stage build ensures your production image is as small and secure as possible by only including essential runtime components.
