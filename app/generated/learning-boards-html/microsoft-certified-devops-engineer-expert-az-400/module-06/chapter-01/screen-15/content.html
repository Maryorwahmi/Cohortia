Key Concepts (Continued)

More essential terms to remember from this chapter

Docker Image

A read-only template used to create Docker containers, built from a Dockerfile. It's a snapshot of an application and its environment.

Docker Container

A runnable instance of a Docker image, an isolated process on the host machine with its own filesystem, network, and process space.

Docker Engine

The client-server application that builds and runs Docker containers, managing the entire Docker lifecycle on a host machine.

Summary

Images are templates, containers are runnable instances, and the Docker Engine orchestrates their creation and management.
