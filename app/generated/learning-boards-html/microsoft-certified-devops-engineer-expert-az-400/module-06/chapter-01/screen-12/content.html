Basic Docker Commands: Running and Managing Containers

Launching, listing, stopping, and removing your containerized applications.

Terminal
# Run a container from the image, mapping host port 8080 to container port 80
docker run -p 8080:80 cohortia-web-app:1.0

# Expected Output (application logs)
Server running at http://localhost:80/

# In a new terminal, list running containers
docker ps

# Expected Output
CONTAINER ID   IMAGE                  COMMAND                  CREATED         STATUS         PORTS                    NAMES
a1b2c3d4e5f6   cohortia-web-app:1.0   "npm start"              5 seconds ago   Up 4 seconds   0.0.0.0:8080->80/tcp   vigilant_goldberg

# Stop the running container
docker stop a1b2c3d4e5f6

# Expected Output
a1b2c3d4e5f6

# Remove the stopped container
docker rm a1b2c3d4e5f6

# Expected Output
a1b2c3d4e5f6

`docker run`

Creates and starts a new container from a specified Docker image. The `-p` flag maps ports.

`docker ps`

Lists all currently running Docker containers, providing details like ID, image, and status.

`docker stop` & `docker rm`

`stop` gracefully shuts down a running container; `rm` removes a stopped container instance.

Key Takeaway

Mastering `docker run`, `ps`, `stop`, and `rm` is essential for effective container management and application deployment.
