Basic Docker Commands: Building an Image

Using docker build to create a container blueprint from a Dockerfile.

Terminal
# Navigate to your application directory
cd my-web-app

# Build the Docker image
docker build -t cohortia-web-app:1.0 .

The `docker build` Command

Instructs Docker to construct an image based on the instructions in a Dockerfile.

The `-t` Flag (Tag)

Assigns a name and optional version (e.g., `my-app:1.0`) to the newly built image for easy identification and management.

Build Context

The `.` at the end of the command specifies the current directory as the build context, where Docker looks for the Dockerfile and other files.

Key Takeaway

`docker build` is fundamental for creating images, using Dockerfiles as instructions and tags for organization.
