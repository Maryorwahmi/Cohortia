Enabling Azure Monitor and Exploring Insights

Activating monitoring and navigating performance dashboards in the Azure portal.

Steps to Enable and Explore

  1. •Enable Add-on: Use az aks enable-addons --addons monitoring command.
  2. •Navigate to AKS Cluster: In Azure portal, find your AKS cluster.
  3. •Access Insights: Select 'Monitoring' > 'Insights' to view data.
  4. •Explore Dashboards: Review 'Cluster', 'Nodes', 'Controllers', 'Containers' tabs.
Key Takeaway

Enabling Azure Monitor for containers is a simple step that unlocks powerful, centralized dashboards for deep performance and health insights into your AKS environment.

Azure CLI: Enable Monitoring

az aks enable-addons --addons monitoring \
  --name cohortiaAksCluster \
  --resource-group CohortiaAksRG
After enabling, navigate to AKS cluster > Monitoring > Insights in Azure portal.
