Configuration

Configuring Liveness and Readiness Probes in YAML

Implementing health checks using HTTP GET, TCP sockets, or command execution.

Probe Configuration Parameters

  • •httpGet: Specifies an HTTP GET request to a path and port.
  • •initialDelaySeconds: Time before first probe check.
  • •periodSeconds: How often to perform the probe.
  • •timeoutSeconds: How long to wait for a response.
  • •failureThreshold: Number of consecutive failures before action.
Key Takeaway

Properly configured probes with appropriate delays and thresholds are fundamental for ensuring Kubernetes accurately manages application lifecycle and traffic routing.

Example: Probe Configuration

# ... inside container spec ...
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
          initialDelaySeconds: 15 # Give app time to start
          periodSeconds: 20      # Check every 20 seconds
          timeoutSeconds: 5
          failureThreshold: 3    # Restart after 3 consecutive failures
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
          initialDelaySeconds: 5 # App might be ready faster than live
          periodSeconds: 10
          timeoutSeconds: 3
          failureThreshold: 2
