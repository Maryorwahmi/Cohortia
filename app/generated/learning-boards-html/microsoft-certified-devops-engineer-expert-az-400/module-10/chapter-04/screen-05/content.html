Metrics: Real-time Performance Snapshots

Numerical values for quick insights and alerting.

Key Characteristics
  • Numerical Values: Quantify system aspects (e.g., CPU, requests).
  • Near Real-time: Collected frequently for immediate monitoring.
  • Lightweight: Efficient for storage and querying.
  • Ideal for Alerting: Quickly detect thresholds and anomalies.
Key Takeaway

Metrics provide a high-level, real-time view of system health, making them perfect for quick checks and triggering immediate alerts based on thresholds.
