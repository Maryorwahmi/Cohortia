Configuration Guide

Routing Telemetry with Diagnostic Settings

Directing logs and metrics to their optimal destinations.

Key Steps for Configuration
  • Navigate to 'Diagnostic settings' for an Azure resource.
  • Select specific log categories and metrics to collect.
  • Choose one or more destinations for the collected data.
  • Save the diagnostic setting to apply changes.
Key Takeaway

Diagnostic settings are the gateway to collecting and routing critical telemetry data, enabling advanced analysis, archival, and real-time streaming.

Telemetry Data Destinations
Log Analytics Workspace

For advanced querying with KQL and integration with Azure Monitor features.

Azure Storage Account

For cost-effective, long-term archival and compliance.

Event Hub

For streaming logs to external systems or custom analytics platforms.

Each destination serves a specific purpose for your telemetry data.
