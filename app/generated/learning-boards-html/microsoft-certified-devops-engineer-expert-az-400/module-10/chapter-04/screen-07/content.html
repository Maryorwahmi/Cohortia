Activity vs. Diagnostic Logs

Understanding subscription-level events and resource-specific details.

Activity Logs (Control Plane)
  • Scope: Subscription-level events.
  • Content: Resource creation, updates, deletions, role assignments.
  • Purpose: Auditing, security, understanding changes to Azure resources.
  • Example: 'User X created VM Y in Resource Group Z'.
Key Takeaway

Activity Logs track management operations on resources, while Diagnostic Logs provide granular operational details from within resources.

Diagnostic Logs (Data Plane)
  • Scope: Resource-specific operational data.
  • Content: Web server logs, query logs, container logs, application traces.
  • Purpose: Deep troubleshooting, performance analysis, application health.
  • Example: 'HTTP 500 error on /api/users endpoint in App Service'.
Common Misconception

Activity Logs do NOT contain application-level details. They focus solely on resource management operations.
