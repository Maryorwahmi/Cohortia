Core Concept

Service Level Objectives (SLOs)

Setting Measurable Targets for Reliability

What are SLOs?

Service Level Objectives (SLOs) are specific targets set for Service Level Indicators (SLIs). They define the desired level of service reliability that customers can expect over a given period.

  • •Target-Oriented: A specific goal for an SLI (e.g., 99.9%).
  • •Customer-Focused: Reflects user expectations for service quality.
  • •Decision-Making Tool: Guides trade-offs between features and stability.
Key Takeaway

SLOs translate raw SLI data into clear, actionable reliability targets, enabling objective management of service health and stakeholder communication.

SLI to SLO Example

SLI: HTTP 200 Response Rate

Measures the percentage of successful HTTP requests.

SLO: 99.9% HTTP 200 Rate

Target: 99.9% of HTTP requests must return a 200 status code over a 30-day period.

Impact: Clear Expectations

This SLO provides a clear, measurable target for the service's availability and success rate.
