Enabling Auto-Instrumentation in Azure

For Azure-hosted applications, Application Insights can often be enabled directly from the Azure portal, leveraging auto-instrumentation for quick setup.

01

Navigate to Azure Service: Open your Azure App Service, Azure Function, or AKS resource in the Azure portal.

02

Find Monitoring Section: In the resource's menu, locate and click on 'Application Insights' under the 'Monitoring' category.

03

Turn On Application Insights: Click the 'Turn on' button. This will automatically inject necessary SDKs and configurations.

04

Start Telemetry Collection: Your application will immediately begin collecting performance and usage data without code changes.

Benefits & Considerations

Why Auto-Instrumentation is Powerful

Auto-instrumentation offers a quick and easy way to gain initial observability, especially for standard Azure deployments.

Minimal Effort: Requires no code changes for basic monitoring.

Rapid Deployment: Get monitoring up and running quickly for new services.

Broad Support: Works across various Azure compute services.

Key Takeaway

Auto-instrumentation is the fastest way to enable Application Insights for Azure-hosted applications, providing immediate telemetry without code changes.
