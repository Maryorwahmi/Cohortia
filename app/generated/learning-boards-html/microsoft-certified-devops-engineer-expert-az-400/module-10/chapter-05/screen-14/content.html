Automated Anomaly Detection

How Smart Detection Works

Smart Detection uses machine learning to proactively identify and warn about potential performance problems and failure anomalies.

  • •
    Baseline Establishment: Learns your application's normal behavior over time.
  • •
    Continuous Analysis: Monitors incoming telemetry for deviations from the established baseline.
  • •
    Anomaly Identification: Detects unusual spikes in error rates, performance degradation, or memory leaks.
  • •
    Proactive Alerts: Triggers warnings with diagnostic information without requiring manual alert configuration.
Example Anomaly

A sudden, unpredicted increase in failed requests or a significant slowdown in a critical dependency call.

Benefits for SRE

Why Smart Detection is Crucial

Smart Detection provides an essential layer of proactive monitoring, enhancing an SRE team's ability to maintain reliability.

  • •
    Reduced MTTD: Significantly lowers the Mean Time To Detect issues by catching them automatically.
  • •
    Unanticipated Issues: Identifies problems that might not have explicit alert rules configured.
  • •
    Operational Efficiency: Frees up SREs from constantly tuning alert thresholds.
  • •
    Enhanced User Experience: Proactive detection helps resolve issues before they severely impact users.
Key Takeaway

Smart Detection is a powerful, AI-driven feature that provides proactive, automated warnings about application anomalies, significantly improving an SRE team's ability to maintain application health and user experience.
