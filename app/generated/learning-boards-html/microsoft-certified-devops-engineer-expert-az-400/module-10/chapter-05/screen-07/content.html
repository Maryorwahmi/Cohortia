Initializing Application Insights in Node.js

Add the Application Insights SDK to your Node.js application to enable monitoring and distributed tracing.

// At the very top of your main application file
const appInsights = require("applicationinsights");
appInsights.setup(process.env.APPLICATIONINSIGHTS_CONNECTION_STRING)
    .setDistributedTracingMode(appInsights.DistributedTracingModes.AI_AND_W3C)
    .start();
Best Practice

Place the Application Insights initialization code at the very top of your main application file to ensure it can capture all possible telemetry from your application's startup.

Explanation

Understanding Node.js SDK Configuration

The Node.js SDK setup ensures proper telemetry collection and distributed tracing for your services.

  • •
    `require("applicationinsights")`: Imports the Application Insights module, making its functionalities available in your code.
  • •
    `setup(connectionString)`: Initializes the SDK with your Application Insights connection string, linking your application to the Azure resource.
  • •
    `setDistributedTracingMode(AI_AND_W3C)`: Configures the SDK to use both Application Insights' native distributed tracing and the W3C Trace Context standard. This is crucial for correlating requests across different services and languages in a distributed system.
  • •
    `start()`: Activates the Application Insights SDK, beginning the collection of telemetry data from your Node.js application.
Key Takeaway

For Node.js, ensure the SDK is initialized early and configured for distributed tracing to get a complete picture of your application's performance in a microservices environment.
