Feature Overview

Failures Blade: Understanding Application Errors

Provides a detailed breakdown of failed requests, exceptions, and dependency failures, accelerating debugging.

  • •
    Error Aggregation: Groups similar failures, showing top failing operations and exception types.
  • •
    Detailed Diagnostics: Drill down to view sample requests, stack traces, and associated events for each error.
  • •
    Dependency Failures: Identifies if external services or databases are causing application errors.
Use Case

Investigate a spike in HTTP 500 errors by examining stack traces and dependency calls to pinpoint the root cause.

Feature Overview

Transaction Search: Tracing Individual Requests

Search for and examine individual requests, traces, or events across your application to follow user journeys or diagnose specific issues.

  • •
    End-to-End Tracing: Follow a single request through all its components and dependencies.
  • •
    Event Correlation: Link related events, logs, and traces to understand the full context of an operation.
  • •
    User Journey Analysis: Diagnose specific user-reported issues by tracing their exact interactions.
Key Takeaway

The Failures Blade provides aggregated error insights, while Transaction Search offers granular, end-to-end tracing for precise issue diagnosis and user journey analysis.
