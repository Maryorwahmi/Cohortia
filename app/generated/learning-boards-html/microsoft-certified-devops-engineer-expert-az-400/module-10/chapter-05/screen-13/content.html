Tracking Custom Events in .NET

Use the TelemetryClient to send custom events with properties and measurements for business-specific insights.

// Example: Tracking a custom event in .NET
using Microsoft.ApplicationInsights;

public class MyService
{
    private readonly TelemetryClient _telemetryClient;

    public MyService(TelemetryClient telemetryClient)
    {
        _telemetryClient = telemetryClient;
    }

    public void ProcessOrder(Order order)
    {
        // ... order processing logic ...
        _telemetryClient.TrackEvent("OrderProcessed",
            new Dictionary<string, string> { { "OrderId", order.Id.ToString() } },
            new Dictionary<string, double> { { "OrderValue", order.TotalAmount } });
    }
}
Conceptual Example

Track a 'UserLoggedIn' event with properties like 'UserId' and 'LoginMethod' to understand user authentication patterns.

Explanation

Understanding Custom Telemetry Components

Custom telemetry allows you to capture specific data points relevant to your application's unique logic.

  • •
    `TelemetryClient`: The primary class used to send telemetry to Application Insights. It's typically injected via dependency injection.
  • •
    `TrackEvent()`: Used to track discrete business events, such as 'UserRegistered', 'ItemAddedToCart', or 'CheckoutCompleted'.
  • •
    Properties: Key-value pairs (strings) that provide context to an event, e.g., `OrderId`, `UserId`, `LoginMethod`.
  • •
    Measurements: Key-value pairs (doubles) for numerical values associated with an event, e.g., `OrderValue`, `LoginDurationMs`.
Key Takeaway

Custom telemetry empowers you to collect specific business-level data, providing insights into user behavior and application logic that go beyond standard performance metrics.
