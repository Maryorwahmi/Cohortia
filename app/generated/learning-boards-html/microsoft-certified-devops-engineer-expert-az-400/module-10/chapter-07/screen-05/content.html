Definition

Health Checks: Application Status Endpoints

The Foundation for Orchestrator Management

  • An endpoint within your application that reports its operational status.
  • Fundamental for orchestrators like Kubernetes to manage application lifecycles.
  • Allows orchestrators to decide when to restart, route traffic, or remove instances.
Key Takeaway

Health checks are self-reporting mechanisms that enable orchestrators to make intelligent decisions about application instances, ensuring stability and availability.

Analogy: The Application's Pulse

Think of a health check as taking your application's pulse. A simple check might just confirm a heartbeat (process running), while a more advanced check might also verify blood pressure (database connection) and oxygen levels (external API reachability).

Example: Simple HTTP Health Check
GET /healthz
Host: myapp.com

HTTP/1.1 200 OK
Content-Type: application/json

{
  "status": "Healthy"
}

This basic example shows an application responding to a `/healthz` endpoint, indicating it's operational. Orchestrators interpret this 200 OK status as a sign of health.
