Analyzing Performance and Aggregating Errors

Identifying bottlenecks and summarizing issues.

// Find the top 10 slowest requests in Application Insights data
requests
| where TimeGenerated > ago(1h)
| order by DurationMs desc
| take 10
| project TimeGenerated, Name, DurationMs, Url
// Count 5xx errors per hour for a specific API endpoint
requests
| where TimeGenerated > ago(24h)
| where Url contains "/api/v1/products"
| where ResultCode startswith "5"
| summarize ErrorCount = count() by bin(TimeGenerated, 1h)
| render timechart
Key Takeaway

KQL enables powerful performance analysis to find slow requests and aggregate error trends, providing critical insights for maintaining application health.
