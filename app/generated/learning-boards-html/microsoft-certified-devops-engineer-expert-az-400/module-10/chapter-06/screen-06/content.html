Process Flow

Tracing the Request Journey

Correlation IDs and telemetry stitching.

01
Request Enters Service A

A unique Correlation ID is generated.

02
Service A Calls Service B

Correlation ID is propagated in HTTP headers.

03
Service B Calls Service C

ID continues to propagate across services.

04
Telemetry Stitched Together

All related telemetry is linked by the shared ID.

Key Takeaway

Correlation IDs are crucial for linking individual operations (spans) across services into a complete, traceable request journey.
