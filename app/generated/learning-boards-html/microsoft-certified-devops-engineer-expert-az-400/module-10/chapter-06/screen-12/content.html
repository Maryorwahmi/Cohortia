Querying App Service Logs and Traces

Finding errors and correlating operations.

// Find all errors in App Service logs for a specific app
AppServiceConsoleLogs
| where TimeGenerated > ago(1h)
| where AppName == "my-microservice-api"
| where Level == "Error"
| project TimeGenerated, Message, AppName
// Correlate requests and dependencies across services using operation_Id
union requests, dependencies, exceptions
| where TimeGenerated > ago(1h)
| where operation_Id == "a_specific_operation_id_from_application_insights"
| order by TimeGenerated asc
| project TimeGenerated, ItemType, Name, DurationMs, ResultCode, Message, AppRoleName
Key Takeaway

KQL allows precise filtering of service-specific errors and powerful correlation of distributed tracing data using operation IDs across multiple telemetry tables.
