Key Roles and Tools

Expanding Your SRE Vocabulary

Incident Commander (IC)

The individual responsible for leading and coordinating the entire incident response effort, ensuring clear communication.

Action Items

Specific, measurable tasks identified during a post-mortem to prevent recurrence of an incident or improve processes.

Azure Monitor Action Groups

A collection of notification preferences and actions triggered by Azure Monitor alerts (e.g., emails, SMS, webhooks).

Chapter Summary

Effective SRE relies on clear roles like the Incident Commander, actionable follow-ups via Action Items, and robust alerting tools such as Azure Monitor Action Groups.
