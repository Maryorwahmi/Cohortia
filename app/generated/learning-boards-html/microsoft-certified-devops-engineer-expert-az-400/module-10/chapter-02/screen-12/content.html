Implementing SLIs and SLOs with Azure Monitor
Practical example using Kusto Query Language (KQL)
Scenario

Track 'Percentage of successful invocations' for an Azure Function App API.

Proposed SLO

"The SuccessRate for the Function App must be >= 99.9% over a 30-day rolling window."

Why KQL?

Kusto Query Language in Azure Log Analytics provides powerful, flexible data analysis for SLIs.

KQL Query for Success Rate SLI
FunctionAppLogs| where TimeGenerated > ago(30d)| summarize SuccessCount = countif(ResultCode == "Success"), TotalCount = count() by bin(TimeGenerated, 1h)| extend SuccessRate = todouble(SuccessCount) / TotalCount * 100| project TimeGenerated, SuccessRate| render timechart
