Throughput SLI

Measures the number of requests a service can handle per unit of time. Crucial for understanding capacity and identifying bottlenecks.

  • •Examples: Requests per second, messages processed per minute.
  • •Indicates service capacity and scalability.
  • •Trackable in Azure Monitor for various resources.
Key Insight

High throughput without good quality can be misleading; always pair with error rate.

Error Rate SLI

The percentage of requests that result in an error. A direct indicator of service quality and user frustration.

  • •Example: (Total HTTP 5xx errors) / (Total HTTP requests).
  • •Directly impacts user satisfaction and trust.
  • •Azure Monitor tracks various error types for deep insights.
Key Insight

A low error rate is paramount for a reliable and trustworthy user experience.
