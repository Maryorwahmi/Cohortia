Avoiding Pitfalls

Be aware of common mistakes and implement safety measures for robust artifact and package management.

  • Incorrect Feed Permissions: Ensure pipeline service principal has 'Contributor' (publish) or 'Reader' (consume) roles.
  • Authentication Issues: Use dedicated authentication tasks (`NpmAuthenticate@0`, `NuGetAuthenticate@0`).
  • Package Conflicts: Manage naming and versioning carefully; `allowPackageConflicts` for pre-release.
  • Security: Never embed credentials in YAML; use Azure DevOps Service Connections.
  • Cleanup Policies: Configure retention for feeds to manage storage and prevent accumulation.
Pro-Tip: Feed Views

Use feed views (e.g., `@releases`, `@prerelease`) to control which package versions are visible to consumers, promoting stability and controlled access.

Key Takeaway

Proactive management of permissions, authentication, versioning, and security is vital for a reliable and secure package management system.
