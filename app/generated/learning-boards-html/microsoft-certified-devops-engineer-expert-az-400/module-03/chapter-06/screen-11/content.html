Consuming npm Packages

To consume npm packages from Azure Artifacts, you must first authenticate your npm client with the feed.

  • The `NpmAuthenticate@0` task sets up the necessary credentials on the build agent.
  • It generates a `.npmrc` file with authentication tokens for your feed.
  • After authentication, standard `npm install` commands will successfully resolve packages from your private feed.
  • Crucial for installing private dependencies in your Node.js projects.
How it Works

The `NpmAuthenticate@0` task leverages Azure DevOps service connections to securely inject credentials into the agent's environment, making them available to npm.

Key Takeaway

Always include `NpmAuthenticate@0` before `npm install` to ensure your Node.js pipelines can securely access private npm packages from Azure Artifacts.

azure-pipelines.yml (npm Restore)
- task: NpmAuthenticate@0
  displayName: 'Authenticate npm to Azure Artifacts'
  inputs:
    # This task generates a .npmrc file with credentials for your feed
    # It automatically finds feeds in your project/organization
    # Or specify customFeed: 'YourProject/YourFeedName'

- script: |
    npm install # Now npm install will use the authenticated feed
  displayName: 'Install npm Dependencies'
