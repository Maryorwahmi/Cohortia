Key Concepts

Essential terms and ideas from this chapter.

Build Artifact

The output of a build process, such as compiled code or deployable packages, stored for later use.

`PublishBuildArtifacts@1`

An Azure Pipeline task to publish general build artifacts to Azure DevOps's internal artifact store.

`DownloadBuildArtifacts@0`

An Azure Pipeline task to download previously published build artifacts for use in subsequent stages.

Summary Takeaway

Effectively managing build artifacts through publishing and downloading tasks is fundamental for ensuring consistency and traceability in your CI/CD pipelines.
