`DownloadBuildArtifacts@0` Task

This task is used to retrieve artifacts that have been previously published by a `PublishBuildArtifacts` task.

  • `artifactName`: The logical name of the artifact to download (must match the published name).
  • `downloadPath`: The local directory on the agent where the artifact files will be placed.
  • Enables subsequent jobs or stages to access the exact build outputs.
  • Ensures consistency between build and deployment environments.
Scenario

A release pipeline needs the 'WebApp' artifact from a build pipeline. The `DownloadBuildArtifacts@0` task fetches it to the release agent for deployment.

Key Takeaway

Consuming artifacts ensures that your deployment process always uses the exact, verified output from your CI build, maintaining integrity.

azure-pipelines.yml
- task: DownloadBuildArtifacts@0
  displayName: 'Download WebApp Artifact'
  inputs:
    artifactName: 'WebApp'
    downloadPath: '$(System.DefaultWorkingDirectory)/downloaded-artifacts'
