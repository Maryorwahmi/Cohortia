Consuming NuGet Packages

To consume NuGet packages from Azure Artifacts, you need to configure your build agent's package manager to use your feed.

  • The `NuGetCommand@2` task with `command: 'restore'` handles this configuration automatically.
  • Specify `restoreSolution` (e.g., `**/*.sln`) to target your project.
  • Use `feedsToUse: 'select'` and `vstsFeed` to point to your Azure Artifacts feed.
  • Ensures your .NET projects can resolve and download private and proxied public packages.
Behind the Scenes

This task generates a temporary `NuGet.config` file on the agent, configuring the feed for the duration of the pipeline run.

Key Takeaway

`NuGetCommand@2` with 'restore' is the simplest and most reliable way to consume NuGet packages from Azure Artifacts in your pipelines.

azure-pipelines.yml (NuGet Restore)
- task: NuGetCommand@2
  displayName: 'Restore NuGet Packages from Azure Artifacts'
  inputs:
    command: 'restore'
    restoreSolution: '**/*.sln'
    feedsToUse: 'select'
    vstsFeed: 'YourProject/YourFeedName' # Specify your feed
