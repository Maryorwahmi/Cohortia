npm Package Publishing

Publishing npm packages to Azure Artifacts requires the `Npm@1` task and often an authentication step.

  • `Npm@1` (publish): Publishes the npm package from the specified `workingDir`.
  • `publishRegistry: 'useFeed'`: Indicates publishing to a custom feed.
  • `customFeed`: Your Azure Artifacts feed (e.g., `YourProject/YourFeedName`).
  • Authentication: Often requires an `npm authenticate` task beforehand to set up credentials.
Common Mistake

Forgetting the `npm authenticate` task before `npm publish` will lead to authentication errors when trying to push to a private feed.

Key Takeaway

Always ensure proper authentication with `NpmAuthenticate@0` before attempting to publish npm packages to a private Azure Artifacts feed.

azure-pipelines.yml (npm)
# ... (after build and test)
- task: Npm@1
  displayName: 'Publish npm Package to Azure Artifacts'
  inputs:
    command: 'publish'
    workingDir: 'src/my-npm-package' # Directory containing package.json
    publishRegistry: 'useFeed'
    customFeed: 'YourProject/YourFeedName' # Format: ProjectName/FeedName or FeedID
    # Ensure .npmrc is configured for authentication, usually handled by 'npm authenticate' task or service connection
