Key Concepts

More essential terms and ideas from this chapter.

Azure Artifacts

A package management service in Azure DevOps for hosting private feeds for various package types.

Feed

A repository within Azure Artifacts that stores packages, acting as a centralized hub for your components.

Upstream Sources

Configured sources in an Azure Artifacts feed that proxy and cache packages from public repositories.

Semantic Versioning (SemVer)

A widely adopted versioning scheme (MAJOR.MINOR.PATCH) for software, indicating change types.

Feed Views

Mechanisms in Azure Artifacts to filter which package versions are visible to consumers (e.g., only stable releases).

`NpmAuthenticate@0`

An Azure Pipeline task to configure npm to authenticate with Azure Artifacts feeds for publishing or consuming.

Summary Takeaway

Azure Artifacts, with its feeds and versioning capabilities, provides a robust and secure solution for managing all your organization's reusable package dependencies.
