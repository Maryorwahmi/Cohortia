Artifact Management

Storing Deployable Outputs as Build Artifacts

Packaging compiled applications for subsequent pipeline stages or external systems.

What are Build Artifacts?

The compiled application, deployable packages, or any other output needed for later stages.

The `PublishBuildArtifacts@1` Task

This task saves specified files from the agent to Azure DevOps's internal artifact storage.

Key Takeaway

Artifacts provide a reliable hand-off of validated, deployable code between build and release processes.

Artifact Staging Process

Build/Publish Step

Your build task generates compiled output (e.g., dotnet publish).

Staging Directory

Files are copied to $(Build.ArtifactStagingDirectory) on the agent.

Publish Artifacts Task

PublishBuildArtifacts@1 uploads the staged files to Azure DevOps.
