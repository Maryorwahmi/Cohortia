Key Concepts

Essential terms and ideas from this chapter.

Build Task

A specific operation within an Azure Pipeline to compile, package, or prepare application code.

Test Task

An operation to execute automated tests (unit, integration) and often generate reports.

`DotNetCoreCLI@2`

Azure Pipeline task for interacting with the .NET Core CLI, used for restoring, building, testing, and publishing .NET projects.

Summary Takeaway

Build and Test Tasks are the foundational elements for automating code compilation and quality assurance in Azure Pipelines, with `DotNetCoreCLI@2` being a versatile tool for .NET projects.
