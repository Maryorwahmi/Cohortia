.NET Test Execution

Running .NET Unit Tests

Executing automated tests and generating TRX results for Azure DevOps.

The `test` Command

Use DotNetCoreCLI@2 with command: 'test' to execute your automated test projects.

TRX Format & Directory

Use --logger trx and --results-directory to output results in a format Azure DevOps understands.

Key Takeaway

Generating TRX test reports in a specified directory is crucial for Azure DevOps to display and analyze your test outcomes.

YAML Configuration
- task: DotNetCoreCLI@2
  displayName: 'Run Unit Tests'
  inputs:
    command: 'test'
    projects: '**/*Tests.csproj' # Targets test projects
    arguments: '--configuration Release --logger trx --results-directory $(Agent.TempDirectory)/TestResults'

Pro-Tip: Test Project Naming

Consistent naming conventions (e.g., *.Tests.csproj) simplify targeting test projects in your pipeline.
