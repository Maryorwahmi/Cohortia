Artifact Management

Publishing .NET Artifacts to Staging Directory

Using dotnet publish to prepare deployable components directly for artifact publishing.

The `publish` Command

DotNetCoreCLI@2 with command: 'publish' prepares your application for deployment.

Output to Staging Directory

Use --output $(Build.ArtifactStagingDirectory)/WebApp to direct output to the artifact staging area.

Key Takeaway

Directly publishing to the staging directory streamlines artifact creation and ensures only deployable components are packaged.

YAML Configuration
- task: DotNetCoreCLI@2
  displayName: 'Publish Web Project'
  inputs:
    command: 'publish'
    projects: 'src/MyWebApp/MyWebApp.csproj'
    publishWebProjects: true
    arguments: '--configuration Release --output $(Build.ArtifactStagingDirectory)/WebApp'
    zipAfterPublish: true # Optionally zip the output

Pro-Tip: `zipAfterPublish`

Using zipAfterPublish: true can create a single, compact artifact file, simplifying storage and transfer.
