Core Concept

The Role of Tasks in CI Pipelines

Tailoring your build and test process with specific, automated operations.

Atomic Operations

Each task performs a single, well-defined action, like compiling code or running tests.

Language & Framework Specific

Tasks are tailored to different technologies (e.g., .NET, Node.js, Python) for optimal integration.

Built-in & Marketplace

Leverage a rich set of pre-built tasks or extend functionality with marketplace extensions.

Task Flow Example

Source Code Checkout

Retrieve the latest code from your repository.

Build & Test Tasks

Compile code, resolve dependencies, run tests (e.g., DotNetCoreCLI@2, NodeTool@0).

Publish Artifacts

Save compiled outputs for deployment (e.g., PublishBuildArtifacts@1).
