Node.js Build Process

Configuring Node.js Environment and Dependencies

Setting the Node.js version and installing npm packages for a consistent build.

Node.js Version Control

The NodeTool@0 task ensures a specific Node.js version is used, preventing environment inconsistencies.

Install Production Dependencies

Use npm install --production in a script task to install only necessary runtime dependencies.

Key Takeaway

Always specify the Node.js version and install production dependencies to ensure a lean and consistent build environment.

YAML Configuration
- task: NodeTool@0
  displayName: 'Use Node.js 18.x'
  inputs:
    versionSpec: '18.x'

- script: |
    npm install --production
  displayName: 'Install Node.js Dependencies'

Common Mistake: Skipping `NodeTool`

Omitting NodeTool@0 can lead to builds failing due to unexpected Node.js versions on the agent.
