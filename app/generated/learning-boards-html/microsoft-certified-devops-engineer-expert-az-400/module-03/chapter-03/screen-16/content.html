Key Concepts

Essential terms and ideas from this chapter.

`NodeTool@0`

Azure Pipeline task to install a specific version of Node.js and npm/yarn on the agent.

`PublishTestResults@2` & `failTaskOnFailedTests`

Task to publish test results to Azure DevOps; `failTaskOnFailedTests` causes pipeline failure on test failures.

Build Artifact & `PublishBuildArtifacts@1`

The output of a build process, stored using `PublishBuildArtifacts@1` with `$(Build.ArtifactStagingDirectory)`.

Summary Takeaway

Effective CI pipelines rely on precise environment setup (`NodeTool@0`), robust quality gates (`PublishTestResults@2` with `failTaskOnFailedTests`), and efficient artifact management (`PublishBuildArtifacts@1` and `$(Build.ArtifactStagingDirectory)`).
