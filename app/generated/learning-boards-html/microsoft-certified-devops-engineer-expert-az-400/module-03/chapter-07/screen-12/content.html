GitHub Actions: Caching & Path Filters

Apply dependency caching and path filters in GitHub Actions workflows for optimized CI performance.

Key Takeaway

Leverage `actions/cache` and path filters in GitHub Actions to significantly reduce build times and ensure relevance.

Practical Application

This walkthrough demonstrates configuring these essential optimizations within a GitHub Actions workflow.

Example Walkthrough

GitHub Actions Configuration

on:
  push:
    branches: [ main ]
    paths:
    - 'src/**'
    - '!docs/**'

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
    - name: Cache npm dependencies
      uses: actions/cache@v3
      with:
        path: ~/.npm
        key: ${{ runner.os }}-npm-${{ hashFiles('**/package-lock.json') }}
        restore-keys: | 
          ${{ runner.os }}-npm-

    - name: Install Dependencies
      run: npm ci
