Hands-on Practice

Implementing Caching & Path Filtering

Optimize your pipeline by adding dependency caching and path filters, using practical examples for Azure Pipelines and GitHub Actions.

Key Takeaway

Applying caching and path filters directly reduces build times and ensures pipelines run only when relevant code changes.

Practical Application

This hands-on approach demonstrates how to configure these optimizations in common CI/CD platforms.

Example Walkthrough

Azure Pipelines Configuration

# Trigger section for path filtering
trigger:
  branches:
    include:
    - main
  paths:
    include:
    - src/*
    exclude:
    - docs/*

# Cache task for npm dependencies
- task: Cache@2
  displayName: 'Cache npm dependencies'
  inputs:
    key: 'npm | "$(Agent.OS)" | **/package-lock.json'
    path: '$(npm_config_cache)'
    cacheHitVar: 'NPM_CACHE_HIT'

- script: |
    npm install
  displayName: 'Install npm dependencies'
  condition: ne(variables.NPM_CACHE_HIT, 'true')
