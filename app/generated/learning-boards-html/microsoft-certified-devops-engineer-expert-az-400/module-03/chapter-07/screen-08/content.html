Selective Task Execution

Implement conditional logic to ensure steps, jobs, or stages run only when specific criteria are met, optimizing pipeline flow.

Key Takeaway

Conditional execution prevents unnecessary operations, saving resources and reducing the risk of errors by ensuring tasks run only when relevant.

Practical Significance

This is crucial for implementing safe deployment strategies, such as deploying to production only from the main branch after successful testing.

Example

Azure Pipelines Condition

- script: echo "Running production deployment"
  condition: and(succeeded(), eq(variables['Build.SourceBranch'], 'refs/heads/main'))

GitHub Actions Condition

- name: Deploy to Production
  if: success() && github.ref == 'refs/heads/main'
  run: ./deploy-prod.sh
