PR and Scheduled Triggers

Automate pipeline runs based on pull request events or predefined schedules for continuous quality and maintenance.

Key Takeaway

PR triggers ensure code quality before merging, while scheduled triggers automate regular maintenance and batch tasks.

Misconception Check

Don't confuse scheduled triggers with event-driven triggers; scheduled runs happen regardless of code changes, useful for periodic checks.

Example

Azure Pipelines Triggers

# Azure Pipelines Example
pr:
  branches:
    include:
    - main

schedules:
- cron: "0 0 * * *" # Daily at midnight UTC
  displayName: "Daily midnight build"
  branches:
    include:
    - main
  always: true

GitHub Actions Triggers

# GitHub Actions Example
on:
  pull_request:
    branches: [ main ]
    types: [ opened, synchronize, reopened ]
  schedule:
    - cron: '0 0 * * *' # Daily at midnight UTC
