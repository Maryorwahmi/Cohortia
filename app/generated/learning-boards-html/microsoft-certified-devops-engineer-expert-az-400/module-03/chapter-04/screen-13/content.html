Key Concepts

Essential Terms from GitHub Actions

GitHub Actions

A CI/CD platform that automates software workflows directly within GitHub repositories.

Workflow

A configurable automated process defined in a YAML file that runs in response to an event.

Event

A specific activity in a repository (e.g., push, pull_request) that triggers a workflow.

Chapter Summary

GitHub Actions provides a powerful, integrated platform for automating CI/CD, with workflows defined by YAML files and triggered by specific repository events.
