Jobs and Runners: Where Your Code Runs

A workflow run is made up of one or more jobs, each executing on a dedicated runner environment.

GitHub-hosted Runners

Virtual machines provided and managed by GitHub. They come pre-installed with common software and are automatically scaled.

  • •Convenient and easy to use, no infrastructure management.
  • •Examples: ubuntu-latest, windows-latest, macos-latest.
  • •Limited customization for specific hardware or software.
jobs:
  build:
    runs-on: ubuntu-latest

Self-hosted Runners

Machines you set up and manage yourself. They offer greater control over the environment.

  • •Useful for specific hardware, custom software, or private network access.
  • •Full control over the operating system and installed tools.
  • •Requires manual setup, maintenance, and scaling.
jobs:
  deploy:
    runs-on: self-hosted
Key Takeaway

Selecting the appropriate runner type is crucial for balancing convenience, cost, and environmental control in your CI/CD workflows.
