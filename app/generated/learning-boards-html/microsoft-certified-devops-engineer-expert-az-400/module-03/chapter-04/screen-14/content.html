Key Concepts

Essential Terms from GitHub Actions

Job

A set of steps that executes on a single runner, typically in parallel with other jobs in a workflow.

Step

An individual task within a job, which can be a shell command (run) or an action (uses).

Runner

The server that runs your workflow. Can be GitHub-hosted (managed by GitHub) or self-hosted (managed by you).

Chapter Summary

Jobs define units of work, steps are individual tasks within jobs, and runners provide the execution environment, whether GitHub-managed or self-managed.
