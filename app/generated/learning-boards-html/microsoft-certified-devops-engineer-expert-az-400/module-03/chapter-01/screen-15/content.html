Key Concepts

Essential terms to remember

Automated Build

The process of automatically compiling, linking, and packaging software without manual intervention.

Automated Tests

Tests (unit, integration, etc.) that are executed automatically as part of the CI pipeline to validate code changes.

Continuous Delivery & Deployment

CD ensures software is always releasable (manual prod deployment). Continuous Deployment automates every successful change to production.

Summary Takeaway

Automated builds and tests are the engine of CI, which then serves as the essential foundation for achieving Continuous Delivery and Continuous Deployment.
