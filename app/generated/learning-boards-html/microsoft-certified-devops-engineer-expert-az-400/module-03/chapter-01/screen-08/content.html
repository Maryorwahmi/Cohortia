The Role of Automated Tests

Tests (unit, integration, end-to-end) that are executed automatically as part of the CI pipeline to validate code changes and ensure functionality.

  • Unit Tests: Verify individual components in isolation.
  • Integration Tests: Check interactions between different system parts.
  • End-to-End Tests: Simulate user flows across the entire application.
  • Self-Testing Build: A build is considered broken if any test fails.
Key Takeaway

Automated tests are the quality gate of CI, providing immediate feedback on code health and preventing regressions.
