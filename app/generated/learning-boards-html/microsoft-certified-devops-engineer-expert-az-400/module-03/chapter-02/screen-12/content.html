Module 3›Chapter 3.2›Microsoft-Hosted vs. Self-Hosted Agents: A Comparison

Microsoft-Hosted Agents

  • Pros: Zero setup/maintenance, always up-to-date, wide software range, auto-scales.
  • Cons: Limited customization, no private network access, shared environment.
  • Use Cases: Most common CI, open-source, cloud-native apps.

Self-Hosted Agents

  • Pros: Full environment control, custom software, private network access, dedicated resources.
  • Cons: Requires setup/maintenance, responsible for scaling/security/updates.
  • Use Cases: Legacy apps, on-premises deployment, specific hardware, strict network security.
Key Takeaway

Choose Microsoft-hosted for convenience and scalability, or self-hosted for custom environments and private network access, aligning with project-specific needs.
