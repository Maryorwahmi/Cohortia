What are Self-Hosted Agents?

  • Machines (physical or virtual) that you set up and manage.
  • You install the Azure DevOps agent software.
  • Provides full control over the environment.

Key Advantages

  • Custom Software: Install specific versions or proprietary tools.
  • Private Network Access: Reach internal resources (databases, file shares).
  • Dedicated Resources: Utilize specific hardware (e.g., GPUs) or ensure consistent performance.
  • Security: Maintain strict control over the build environment.
Key Takeaway

Self-hosted agents offer unparalleled control and private network access, making them ideal for specialized, legacy, or highly secure build environments.

# azure-pipelines.yml
pool:
  name: 'MyPrivateAgentPool'
  demands:
    - MSBuild
    - VisualStudio

# Example: Using a self-hosted agent pool named 'MyPrivateAgentPool'
# with specific capabilities (demands) like MSBuild and VisualStudio.
# Self-hosted agents provide custom environments.
# Use 'name' to specify your custom agent pool.
