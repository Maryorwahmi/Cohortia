Module 3›Chapter 3.2›Building a .NET Core CI Pipeline (Part 2)

Build and Test Steps

  • Build Project: DotNetCoreCLI@2 with command: 'build' and --configuration Release.
  • Run Unit Tests: Another DotNetCoreCLI@2 task with command: 'test', targeting *Tests.csproj and outputting --logger trx.

Publish Test Results

  • Task: PublishTestResults@2.
  • Configuration: Looks for **/*.trx files, merges results.
  • Critical Setting: failTaskOnFailedTests: true ensures pipeline failure on test failures, providing immediate feedback.
Key Takeaway

After building, running unit tests and publishing their results with a fail-on-failure policy is crucial for maintaining code quality and rapid feedback.

# ... (previous steps)

    - task: DotNetCoreCLI@2
      displayName: Build Project
      inputs:
        command: 'build'
        projects: '**/*.csproj'
        arguments: '--configuration Release'

    - task: DotNetCoreCLI@2
      displayName: Run Unit Tests
      inputs:
        command: 'test'
        projects: '**/*Tests.csproj'
        arguments: '--configuration Release --logger trx'

    - task: PublishTestResults@2
      displayName: Publish Test Results
      inputs:
        testResultsFormat: 'VSTest'
        testResultsFiles: '**/*.trx'
        mergeTestResults: true
        failTaskOnFailedTests: true
