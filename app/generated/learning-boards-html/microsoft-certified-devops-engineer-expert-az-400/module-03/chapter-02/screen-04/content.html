What are Azure DevOps Pipelines?

A cloud-hosted CI/CD solution that automates build, test, and deployment processes. It integrates with source control systems like Azure Repos and GitHub.

Why YAML? Pipeline as Code

  • Version Control: Pipeline definitions are stored with your code.
  • Collaboration: Teams can review and contribute to pipeline changes.
  • Consistency: Ensures identical build processes across environments.
  • Recommended Approach: More powerful and flexible than the Classic editor.
Key Takeaway

Azure Pipelines automate CI/CD, with YAML as the preferred method for defining version-controlled, collaborative, and consistent workflows.

# azure-pipelines.yml
trigger:
  - main

pool:
  vmImage: 'ubuntu-latest'

stages:
  - stage: Build
    jobs:
      - job: BuildJob
        steps:
          - script: echo "Hello, CI!"
# YAML structure for a basic CI pipeline
# Defines triggers, agent pool, stages, jobs, and steps.
