Common Mistakes

  • Incorrect YAML Indentation: YAML is whitespace-sensitive. Use linters!
  • Non-existent Tasks/Inputs: Verify task names and parameters against documentation.
  • Mismatched Agent Pool: Ensure the agent's OS and tools match project requirements.
  • Self-hosted Agent Issues: Verify agent software is running, and it has correct permissions/network access.

Safety Considerations

  • Least Privilege: Agent service accounts should have only necessary permissions.
  • Security & Updates: Keep self-hosted agents secure and regularly updated.
Key Takeaway

Validate YAML, match agents to project needs, and prioritize security with least privilege and regular updates to build robust and reliable pipelines.

Troubleshooting Checklist

  • Is your YAML syntax valid? (Check indentation!)
  • Are all tasks and their inputs correctly spelled and configured?
  • Does your agent pool have the required OS and software?
  • For self-hosted agents, is the service running and does it have network access?
  • Are agent permissions restricted to only what's necessary?
