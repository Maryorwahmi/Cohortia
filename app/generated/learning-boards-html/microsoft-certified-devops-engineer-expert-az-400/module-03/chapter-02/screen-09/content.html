Module 3›Chapter 3.2›Building a .NET Core CI Pipeline (Part 1)

Pipeline Configuration

  • Trigger: - main (runs on pushes to the main branch).
  • Agent Pool: vmImage: 'windows-latest' (Microsoft-hosted Windows agent).
  • Stage: Build (main phase for application build).
  • Job: BuildJob (compiles and tests the application).

Initial Steps

  • Checkout Code: checkout: self retrieves source from the repository.
  • Restore NuGet Packages: DotNetCoreCLI@2 with command: 'restore' downloads all project dependencies.
Key Takeaway

A robust CI pipeline starts with clear triggers and agent selection, followed by essential steps like code checkout and dependency restoration.

# azure-pipelines.yml
trigger:
- main

pool:
  vmImage: 'windows-latest'

stages:
- stage: Build
  displayName: Build Application
  jobs:
  - job: BuildJob
    displayName: Compile and Test
    steps:
    - checkout: self
      displayName: Checkout Code

    - task: DotNetCoreCLI@2
      displayName: Restore NuGet Packages
      inputs:
        command: 'restore'
        projects: '**/*.csproj'
# Trigger on main branch pushes.
# Use a Windows-latest agent.
# Checkout code and restore dependencies.
