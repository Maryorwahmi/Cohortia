5. `steps` Section

  • Purpose: Individual tasks or scripts executed by a job.
  • Smallest Building Blocks: Where the actual work of the pipeline occurs.

Types of Steps

  • Scripts: Inline shell commands (script: echo Hello) or references to script files.
  • Tasks: Pre-built, versioned operations from Azure DevOps or Marketplace.
    • Example: DotNetCoreCLI@2 for .NET, Npm@1 for Node.js.
    • Recommended for robustness and ease of use.
Key Takeaway

Steps are the fundamental actions in a pipeline, executed as custom scripts or robust, pre-built tasks for efficient and reliable automation.

# azure-pipelines.yml
steps:
  - checkout: self
    displayName: 'Checkout Code'

  - task: DotNetCoreCLI@2
    displayName: 'Restore NuGet Packages'
    inputs:
      command: 'restore'
      projects: '**/*.csproj'

  - script: echo "Custom build step"
    displayName: 'Run Custom Script'
# 'checkout' is a special step to get source code.
# 'task' uses pre-built operations.
# 'script' runs inline commands.
