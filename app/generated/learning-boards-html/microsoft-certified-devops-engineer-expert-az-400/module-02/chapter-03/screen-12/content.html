Choosing the Right Strategy

When to use LFS, Submodules, or alternatives for effective repository management.

Decision Guide
  • Large Binary Assets (versioned with code): Use Git LFS. (e.g., game assets, datasets).
  • External Code Repositories (precise versioning): Use Git Submodules. (e.g., libraries, frameworks).
  • External Code Libraries (simpler dependency): Use Package Managers (npm, NuGet, pip).
  • Large Assets (independent versioning): Use Cloud Storage (Azure Blob, S3) with references.
  • Multiple Related Projects: Consider a Monorepo strategy.
Key Factors

File Type & Size: Binary vs. code, large vs. small.

Update Frequency: How often do files or dependencies change?

Versioning Needs: Precise commit pinning vs. latest version.

Team Workflow: Complexity tolerance, collaboration patterns.

Infrastructure: Availability of LFS servers, cloud storage, CI/CD.

Key Takeaway

The optimal repository management strategy balances technical requirements with workflow efficiency and project architecture.
