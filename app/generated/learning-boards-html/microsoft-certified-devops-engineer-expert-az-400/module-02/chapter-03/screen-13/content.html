Practical: Git LFS and Submodules

Implementing LFS and Submodules in a project scenario.

Demonstration Steps
  • Initialize main Git repository.
  • Create dummy large files (e.g., `.csv`, `.h5`).
  • Install and configure Git LFS (`git lfs install`, `git lfs track`).
  • Commit large files and `.gitattributes`.
  • Create a separate repository for a utility library.
  • Add the utility library as a submodule (`git submodule add`).
  • Simulate update in utility library, pull into submodule, commit parent reference.
Key Learnings

Observe how `git lfs ls-files` reports tracked files.

Understand the role of `.gitmodules` and submodule directories.

Experience the workflow for updating submodule references.

Reinforce the practical application of LFS and Submodules in managing project complexity.

Key Takeaway

Hands-on practice solidifies understanding of Git LFS and Submodule commands and workflows for effective repository management.
