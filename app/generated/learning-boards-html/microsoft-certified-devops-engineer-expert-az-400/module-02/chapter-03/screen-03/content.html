Bloom's Taxonomy: Repository Management

From Understanding Challenges to Mastering Solutions

01

Understand

Recognize the challenges Git faces with large files and external dependencies, and their performance implications.

02

Apply Git LFS

Implement Git LFS to track and manage large binary assets, keeping your core repository lean and fast.

03

Apply Git Submodules

Use Git Submodules to embed and manage external Git repositories as subdirectories, linking to specific commits.

04

Master & Analyze

Identify optimal use cases for LFS and Submodules, and evaluate their limitations against alternatives.
