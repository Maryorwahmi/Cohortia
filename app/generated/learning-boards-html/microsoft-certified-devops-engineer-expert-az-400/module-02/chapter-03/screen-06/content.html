Configuring and Using Git LFS

Steps to set up LFS and manage large files effectively.

Key Steps
  • Install Git LFS globally: `git lfs install`
  • Track file types: `git lfs track "*.ext"`
  • Commit the `.gitattributes` file: `git add .gitattributes`
  • Add and commit large files as usual.
  • Push changes: `git push` (LFS client uploads content).
Common Mistake

Forgetting to run `git lfs track` before adding and committing large files. This results in the large file being stored directly in Git history. Correcting this requires complex history rewriting (e.g., using `git filter-repo`), which is risky on shared repositories. Always track files first!

Key Takeaway

Properly configuring `.gitattributes` and tracking files *before* committing is crucial for effective Git LFS implementation and avoiding history rewriting.
