Learning Objectives

Master the management of large repositories and external dependencies.

01

Identify Challenges

Understand the difficulties Git faces with large binary files and external dependencies, and their impact on repository performance.

02

Implement Git LFS

Learn to use Git Large File Storage to efficiently track and manage large binary assets, keeping your repository lean.

03

Utilize Git Submodules

Incorporate and manage external Git repositories as subdirectories within your main project, linking to specific commits.

04

Choose Appropriate Solutions

Identify when Git LFS and Submodules are suitable, and recognize their limitations and alternative strategies like monorepos or package managers.
