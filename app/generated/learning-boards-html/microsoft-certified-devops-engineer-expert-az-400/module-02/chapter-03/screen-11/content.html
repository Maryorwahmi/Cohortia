Considerations

Beyond LFS and Submodules

Exploring other strategies and their trade-offs.

Alternatives
  • For Large Files: Cloud Storage (Azure Blob, AWS S3) with references in Git.
  • For Dependencies: Package Managers (npm, NuGet, Maven, pip).
  • For Codebases: Monorepos (single large repository for multiple projects).
Limitations & Complexities

LFS: Requires LFS server availability; potential issues if server is down.

Submodules: Can complicate branching, merging, and cloning; requires careful initialization and updates.

Monorepos: Can lead to slow build times and complex tooling; requires robust CI/CD.

Key Takeaway

Evaluate the trade-offs of LFS, Submodules, cloud storage, package managers, and monorepos to select the most suitable strategy for your project's unique needs.
