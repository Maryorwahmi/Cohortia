Key Concepts: Git Hooks

Essential Terms for Local Automation

Git Hooks

Executable scripts that Git runs automatically before or after events like committing, pushing, or receiving commits.

Client-side Hooks

Git hooks that run on the developer's local machine (e.g., pre-commit, prepare-commit-msg) for local automation.

Server-side Hooks

Git hooks that run on the Git server (e.g., pre-receive, post-receive), often for repository-wide policy enforcement.

Summary Takeaway

Git hooks provide powerful automation points within your repository, categorized by their execution location: client-side for local developer workflows and server-side for repository-wide governance.
