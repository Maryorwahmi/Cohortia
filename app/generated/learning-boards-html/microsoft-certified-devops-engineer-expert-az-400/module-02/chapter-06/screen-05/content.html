Definition

Understanding Git Hooks

Scripts Triggered by Git Events

  • •

    Automated Scripts: Executable scripts that Git runs automatically before or after specific events.

  • •

    Location: Reside in the .git/hooks/ directory of your local repository.

  • •

    Activation: Remove .sample extension from example scripts and make them executable.

  • •

    Purpose: Enable custom validations, notifications, and workflow orchestrations.

Key Takeaway

Git hooks are powerful, customizable scripts that automate actions at critical points in your Git workflow, categorized by where they execute.

Git Hook Categories

Client-Side Hooks

Run on the developer's local machine. Used for personal workflow automation, local policy enforcement, or preparing commit messages. Examples: pre-commit, prepare-commit-msg.

Server-Side Hooks

Run on the Git server. Ideal for enforcing repository-wide policies, performing logging, or triggering external systems after a push. Examples: pre-receive, post-receive.
