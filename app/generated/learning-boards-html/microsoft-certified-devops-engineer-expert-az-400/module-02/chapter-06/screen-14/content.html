Configuring an Azure DevOps Webhook

Triggering External Services on Code Push

  • •

    Prerequisite: Obtain a temporary HTTP endpoint (e.g., from webhook.site) to receive the payload.

  • •

    Navigation: In Azure DevOps, go to Project Settings > Service Hooks and create a new subscription.

  • •

    Configuration: Select Web Hooks service, choose Code pushed event, specify repository and main branch.

  • •

    URL & Test: Paste your webhook.site URL and use the 'Test' button to verify payload reception.

Key Takeaway

Configuring an Azure DevOps Webhook involves defining the trigger event and target URL, with crucial testing to ensure the external service correctly receives and processes the event payload.

Webhook Setup Steps
1. Get Webhook URL (e.g., webhook.site)
2. Create Service Hook in Azure DevOps
3. Configure Event (Code pushed to main)
4. Test & Verify Payload
