Key Concepts: Webhooks & Specific Hooks

Integrating with Azure DevOps

pre-commit hook

A client-side hook that runs before a commit is finalized, commonly used for linting, formatting, or testing.

prepare-commit-msg hook

A client-side hook that runs before the commit message editor is launched, used for pre-populating commit messages.

Azure DevOps Webhooks

An Azure DevOps feature that sends HTTP POST requests to a specified URL in response to specific events in Azure Repos.

Service Hooks (Azure DevOps)

The general term for integrations in Azure DevOps that allow events to trigger actions in external services, including Webhooks.

Summary Takeaway

Specific Git hooks like pre-commit and prepare-commit-msg enhance local workflows, while Azure DevOps Webhooks and Service Hooks enable powerful remote, event-driven integrations with external systems.
