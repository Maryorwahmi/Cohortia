Branching Model

GitHub Flow: The Always-Deployable Main

Embracing continuous delivery with a streamlined approach.

Single Main Branch

`main` is always deployable and represents the latest stable code.

Short-Lived Feature Branches

Developers create branches for features, merging back into `main` quickly.

Continuous Delivery Focus

Designed for rapid, frequent deployments and fast feedback loops.

Key Takeaway

GitHub Flow simplifies the branching model to enable continuous integration and rapid deployment, making `main` the single source of truth for deployable code.
