Key Concepts

Essential takeaways from this chapter

Draft Pull Request

A PR marked as work-in-progress, allowing early feedback and builds without formal review pressure.

Merge (no fast-forward)

Creates a new merge commit, preserving the full history of the feature branch, potentially complexifying the graph.

Squash Commit Strategy

Combines all commits from a feature branch into a single new commit on the target branch for a clean, linear history.

Summary Takeaway

Mastering these core PR features allows for flexible workflow management and precise control over your repository's history.
