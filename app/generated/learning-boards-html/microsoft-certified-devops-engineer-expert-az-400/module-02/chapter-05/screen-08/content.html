Clean, Atomic Commits

Consolidating changes with Squash Commit

How it Works

All commits from the feature branch are combined into a single new commit that is then applied to the target branch.

Pros & Cons

  • Pro: Creates a very clean, linear history.
  • Pro: Each feature appears as one atomic change.
  • Con: Loses individual commit history of the feature branch.
Key Takeaway

Ideal for smaller features or bug fixes where a detailed feature branch history isn't critical for the main branch.
