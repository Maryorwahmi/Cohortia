Recovery Tool

Unlocking git reflog

Recovering lost commits and understanding repository actions.

Your Personal Time Machine

`git reflog` records every action that modifies the tip of a branch in your local repository, including commits, merges, and resets.

Recover Lost Work

If you accidentally delete a branch or perform a hard reset, `reflog` can show you previous states, allowing you to recover.

Local Only

This command is specific to your local machine and does not affect the remote repository, making it a safe tool for personal recovery.

`git reflog` Output Example
HEAD@{0}: commit: feat: Some temporary work
HEAD@{1}: reset: moving to HEAD~1
HEAD@{2}: commit: fix: Critical bug fix
HEAD@{3}: checkout: moving from feature/login to main

Each entry shows a HEAD movement and its associated action.

Key Takeaway

`git reflog` is a local log of all HEAD movements, providing a safety net to recover lost commits or branches by showing previous repository states.
