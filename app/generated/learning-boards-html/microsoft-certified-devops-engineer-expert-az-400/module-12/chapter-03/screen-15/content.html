Pipeline Integration with Key Vault and Variable Groups

Securely Retrieving Secrets at Runtime

Create YAML Pipeline

Define a new Azure DevOps YAML pipeline that will utilize the Key Vault secret.

Link Variable Group

Create an Azure DevOps variable group linked to your Key Vault to expose secrets as pipeline variables.

Retrieve & Mask

Use the `AzureKeyVault@2` task to retrieve the secret, which will be masked in pipeline logs.

Azure DevOps: Key Vault Integration

# azure-pipelines.yml
trigger:
- main

pool:
  vmImage: 'ubuntu-latest'

variables:
  - group: 'MyKeyVaultSecrets' # Link to Variable Group

steps:
- task: AzureKeyVault@2
  inputs:
    azureSubscription: '<Your-Azure-Service-Connection-Name>'
    KeyVaultName: '$(KEY_VAULT_NAME)'
    SecretsFilter: 'MySuperSecret'
    RunAsPreJob: true

- script: |
    echo "The secret value is: $(MySuperSecret)" # Masked in logs
  displayName: 'Use Key Vault Secret'
Key Takeaway

The combination of Azure Key Vault, Azure DevOps Variable Groups, and the `AzureKeyVault@2` task provides a robust and secure method for managing and consuming secrets in CI/CD pipelines.
