Retrieving Secrets in Pipelines

Using the Azure Key Vault Task and Variable Groups

Azure Key Vault Task

The `AzureKeyVault@2` task retrieves secrets from Key Vault and injects them as pipeline variables.

Masked in Logs

Retrieved secrets are automatically masked in pipeline logs, preventing accidental exposure.

Variable Groups

Azure DevOps variable groups can link to Key Vault secrets or store encrypted 'secret' variables directly.

Secure Secret Flow in Azure Pipelines

Azure Key Vault
Azure DevOps Variable Group
Azure Pipeline (AzureKeyVault@2 Task)
Example YAML Snippet
- task: AzureKeyVault@2
  inputs:
    azureSubscription: 'MyServiceConnection'
    KeyVaultName: 'mySecureVault'
    SecretsFilter: 'MySecret'
    RunAsPreJob: true

- script: |
    echo "The secret is: $(MySecret)" # Masked in logs
  displayName: 'Use Secret'
