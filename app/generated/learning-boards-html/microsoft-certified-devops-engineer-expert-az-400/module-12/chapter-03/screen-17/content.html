Key Concepts: Pipeline & Agent Security

Advanced Measures for CI/CD Protection

Service Connections

Secure connections from Azure DevOps pipelines to external services (e.g., Azure subscriptions, GitHub), typically using Service Principals or OAuth.

Service Principal

A security identity used by applications, services, and automation tools to access specific Azure resources with defined permissions.

Agent Pools

Collections of build and deployment agents (either Microsoft-hosted or self-hosted) that execute pipeline jobs, requiring careful security management.

SAST & DAST

Static Analysis Security Testing (SAST) analyzes source code, while Dynamic Analysis Security Testing (DAST) analyzes running applications for vulnerabilities.

Summary Takeaway

Securing pipelines involves careful configuration of service connections and agents, complemented by integrated static and dynamic security testing to identify and mitigate vulnerabilities.
