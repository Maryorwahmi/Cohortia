Hardening Your Agent Pools

Securing Self-Hosted and Microsoft-Hosted Agents

Self-Hosted Agent Responsibility

You are responsible for patching, minimal privileges, and isolating self-hosted agents from critical systems.

Separate Agent Pools

Use distinct agent pools for different environments (e.g., production vs. development) or sensitive workloads.

Untrusted Code Warning

Never run untrusted code on any agent, especially self-hosted ones, to prevent malicious execution.

Agent Pool Security Considerations

Self-Hosted Agents

  • Patching
  • Isolation
  • Least Privilege

Microsoft-Hosted Agents

  • Code Trust
  • Inherited Permissions
  • Service Connections
Example Scenario

A self-hosted agent for production deployments is placed in a dedicated network segment with strict firewall rules, limiting its outbound access to only necessary endpoints.
