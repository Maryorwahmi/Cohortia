Setting Up Azure Key Vault

Storing Your First Secret with Azure CLI

Create Resource Group

Organize your Azure resources by creating a dedicated resource group for the Key Vault.

Provision Key Vault

Use Azure CLI to create a new Azure Key Vault instance with a unique name.

Add a Secret

Securely store a sensitive value, like an API key, within the newly created Key Vault.

Azure CLI: Key Vault Setup

# Log in to Azure CLI
az login
# Set variables
RESOURCE_GROUP="az400-security-rg"
LOCATION="eastus"
KEY_VAULT_NAME="az400kv$(openssl rand -hex 4)"

az group create --name $RESOURCE_GROUP --location $LOCATION
az keyvault create --name $KEY_VAULT_NAME --resource-group $RESOURCE_GROUP --location $LOCATION --sku Standard
# Add a secret
SECRET_NAME="MySuperSecret"
SECRET_VALUE="ThisIsMySecureValue123!"
az keyvault secret set --vault-name $KEY_VAULT_NAME --name $SECRET_NAME --value $SECRET_VALUE
Key Takeaway

Azure Key Vault provides a robust, encrypted storage solution for secrets, easily managed via Azure CLI, forming the first step in secure secrets management.
