Integrating IaC Deployments into Azure Pipelines: CD Stage

Automating IaC deployments with idempotency, drift detection, approval gates, and secure secrets management.

Idempotency & Drift Detection

Leverage IaC's idempotency and implement periodic checks to detect configuration drift (manual changes).

Approval Gates & Permissions

Use manual approval gates for critical environments and ensure service connections have least-privileged permissions.

Secure Secrets Management

Always use Azure Key Vault for sensitive parameters, never hardcoding them in your pipeline.

Key Takeaway

The CD stage for IaC ensures automated, consistent, and secure infrastructure delivery through idempotency, drift detection, and robust security practices.

Example: Azure Pipeline CD Stage (YAML)
stages:
  - stage: DeployIaC
    displayName: 'Deploy Bicep IaC'
    dependsOn: ValidateIaC
    condition: succeeded() # Only deploy if validation passed
    jobs:
    - deployment: DeployBicep
      displayName: 'Deploy Azure Resources'
      environment: 'Dev'
      strategy:
        runOnce:
          deploy:
            steps:
            - task: AzureCLI@2
              displayName: 'Deploy Bicep Template'
              inputs:
                azureSubscription: '$(azureServiceConnection)'
                scriptType: 'bash'
                scriptLocation: 'inlineScript'
                inlineScript: |
                  az deployment group create \
                    --resource-group $(resourceGroupName) \
                    --template-file $(System.DefaultWorkingDirectory)/bicep/main.bicep \
                    --parameters location=$(location) resourceGroupName=$(resourceGroupName)
                failOnStandardError: true
Pro Tip

Use `dependsOn` and `condition: succeeded()` to ensure the CD stage only runs if the CI validation stage passes successfully.
