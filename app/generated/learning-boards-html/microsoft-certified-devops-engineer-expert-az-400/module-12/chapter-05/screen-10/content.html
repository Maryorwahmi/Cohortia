Post-Deployment Testing

Integration Testing for Deployed IaC Resources

Verifying that deployed resources are configured correctly and are accessible after deployment.

Functional Verification

Confirms that all deployed resources are working together as intended in the live environment.

Configuration Validation

Checks specific resource properties, network connectivity, and service availability post-deployment.

Tools for Integration Testing

Utilize frameworks like Pester (PowerShell) or Serverspec to write and execute post-deployment tests.

Key Takeaway

Integration testing provides crucial post-deployment assurance, verifying that your IaC has correctly provisioned and configured operational infrastructure.

Example: Verifying Web App Status with Pester
Describe "Web App Deployment" {
    It "should have a running web app" {
        $appName = "my-test-webapp"
        $resourceGroup = "my-iac-rg"

        $status = az webapp show --name $appName --resource-group $resourceGroup --query "state" -o tsv

        $status | Should Be "Running"
    }

    It "should have a reachable database" {
        # Simulate database connection check
        $dbConnectionResult = Test-NetConnection -ComputerName "mydbserver.database.windows.net" -Port 1433
        $dbConnectionResult.TcpTestSucceeded | Should BeTrue
    }
}
