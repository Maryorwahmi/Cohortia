Diagnosing Permission and Dependency Errors

Two frequent culprits in pipeline failures are access rights and missing components.

Permission Errors

Occur when the pipeline's identity lacks necessary authorization to access resources or perform actions.

  • Symptoms: 401 Unauthorized, 403 Forbidden, Access denied.
  • Cause: Service connection or agent identity missing RBAC roles.
  • Resolution: Verify and assign correct RBAC roles to the service principal or managed identity.
Key Takeaway

Always check RBAC roles for permission errors; for dependencies, scrutinize project files and network access.

Dependency Issues

Arise from missing packages, incorrect versions, or failed installations required by the application or build process.

  • Symptoms: package not found, npm install failed, compilation errors.
  • Cause: Missing `package.json` entries, incorrect versions, network blocks.
  • Resolution: Check dependency files, ensure agent network access to repositories.
Example Scenario

A Python pipeline fails with 'ModuleNotFoundError'. Check `requirements.txt` for the missing module and ensure `pip install -r requirements.txt` runs correctly.
