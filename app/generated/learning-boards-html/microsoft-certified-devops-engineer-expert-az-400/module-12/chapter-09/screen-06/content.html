Tackling Configuration and Network Problems

Incorrect YAML or connectivity issues can halt your pipelines unexpectedly.

Configuration Errors

Problems arising from incorrect variable names, malformed YAML, or invalid task parameters.

  • Symptoms: Pipeline validation failures, unexpected task behavior, runtime errors.
  • Cause: Typos, incorrect syntax, missing required parameters.
  • Resolution: Use pipeline editor validation, carefully review YAML, check variable scope.
Key Takeaway

Leverage validation tools for config errors; for network, verify firewalls, VNets, and proxy settings.

Network Connectivity

Agent unable to reach external services, package repositories, or target deployment environments.

  • Symptoms: connection refused, timeout, `DNS resolution failed`.
  • Cause: Firewall rules, VNet peering, proxy issues, incorrect DNS.
  • Resolution: Check network security groups, VNet configurations, proxy settings for self-hosted agents.
Example Scenario

A self-hosted agent fails to pull Docker images. Check if the agent's subnet has outbound access to Docker Hub or your private registry.
