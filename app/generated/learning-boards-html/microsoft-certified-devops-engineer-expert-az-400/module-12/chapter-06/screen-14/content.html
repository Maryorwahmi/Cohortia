Key Concepts

Essential terms for hybrid DevOps.

GitHub Actions

An event-driven CI/CD platform integrated directly into GitHub repositories, allowing automation of software workflows.

Workflow

A configurable automated process defined in a YAML file that runs in response to specific events.

Job

A set of steps that execute on the same runner within a workflow, representing a logical unit of work.

Step

An individual task within a job, which can be a command, script, or a pre-built action.

Action

A reusable unit of code (e.g., actions/checkout@v4) that performs a specific task within a workflow.

Summary Takeaway

GitHub Actions provides a flexible, event-driven CI/CD platform, built upon workflows, jobs, steps, and reusable actions, enabling powerful automation directly within your repository.
