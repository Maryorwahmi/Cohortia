Setting Up OIDC: Azure AD Application Registration

Representing your GitHub Actions workflow in Azure Active Directory.

Workflow Identity

The application registration acts as the identity for your GitHub Actions workflow within Azure AD.

Client ID (App ID)

A unique identifier generated for the application, used by GitHub Actions to identify itself to Azure AD.

Security Principle

Establishes a secure boundary, ensuring only authorized workflows can request tokens and access Azure.

Azure CLI Command
# Set variables for your GitHub repository
GITHUB_REPO="MyGitHubWebApp"

# Define a unique name for your Azure AD application
APP_NAME="github-oidc-app-${GITHUB_REPO}"

# Create the Azure AD application registration
APP_ID=$(az ad app create --display-name $APP_NAME --query appId --output tsv)

# Output the generated Application ID (Client ID)
echo "Azure AD App ID: $APP_ID"
Key Takeaway

Creating an Azure AD Application Registration is the first step to OIDC, providing a unique identity (Client ID) for your GitHub Actions workflow within Azure.
