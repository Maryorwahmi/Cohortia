Common Scenario

Bridging GitHub and Azure: Deployment Targets

Deploying code from GitHub to various Azure services.

Unified Experience

Keep your source code and CI/CD definitions together in GitHub for streamlined development.

Leverage Azure Infrastructure

Utilize Azure's scalable and robust cloud services as your deployment environment.

Pre-built Azure Actions

Access a rich ecosystem of GitHub Actions specifically designed for Azure integration.

Key Azure Actions
azure/login@v1

Authenticates your GitHub Actions workflow to Azure, establishing a secure session.

azure/webapps-deploy@v2

Deploys web applications to Azure App Service instances.

azure/aks-set-context@v1

Sets the Kubernetes context for interacting with Azure Kubernetes Service (AKS).

azure/k8s-deploy@v1

Deploys applications to a Kubernetes cluster, often used with AKS.

Key Takeaway

GitHub Actions provides a robust set of Azure-specific actions, enabling seamless and automated deployments from your GitHub repository to various Azure cloud services.
