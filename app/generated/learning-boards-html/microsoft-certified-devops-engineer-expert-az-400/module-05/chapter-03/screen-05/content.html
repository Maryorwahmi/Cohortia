Implementing Nested Templates

Define templates directly within a parent for tightly coupled components.

Definition

A template defined directly within the resources section of a parent template.

Deployment Type

Deployed as a resource of type Microsoft.Resources/deployments within the parent.

Use Case

Ideal for encapsulating related infrastructure components that are part of a larger, single deployment unit.

{
  "$schema": "https://schema.management.azure.com/schemas/2019-04-01/deploymentTemplate.json#",
  "contentVersion": "1.0.0.0",
  "resources": [
    {
      "type": "Microsoft.Resources/deployments",
      "apiVersion": "2021-04-01",
      "name": "nestedTemplateDeployment",
      "properties": {
        "mode": "Incremental",
        "template": {
          "$schema": "https://schema.management.azure.com/schemas/2019-04-01/deploymentTemplate.json#",
          "contentVersion": "1.0.0.0",
          "resources": [
            {
              "type": "Microsoft.Storage/storageAccounts",
              "apiVersion": "2021-09-01",
              "name": "[concat('nestedstorage', uniqueString(resourceGroup().id))]",
              "location": "[resourceGroup().location]",
              "sku": { "name": "Standard_LRS" },
              "kind": "StorageV2"
            }
          ]
        }
      }
    }
  ]
}
Key Takeaway

Nested templates embed sub-templates directly, ideal for grouping related resources within a single, larger deployment file.
