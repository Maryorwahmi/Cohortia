Mastering Functions and Expressions

Generate dynamic values for flexible and adaptable ARM Templates.

Functions

Built-in operations (e.g., concat, resourceId) to manipulate data and retrieve information.

Expressions

Enclosed in [], they combine functions, parameters, variables, and literals to produce dynamic content.

Key Categories

String manipulation, logical operations, array/object manipulation, resource lookups, and deployment context.

// Example: Dynamic Storage Account Name
"name": "[concat('storage', uniqueString(resourceGroup().id))]"

// Example: Conditional Value
"sku": {
  "name": "[if(equals(parameters('env'), 'Prod'), 'Standard_LRS', 'Standard_ZRS')]"
}

// Example: Resource ID Lookup
"id": "[resourceId('Microsoft.Network/virtualNetworks', parameters('vnetName'))]"

// Example: Array Construction
"tags": "[json('{"environment":"dev", "project":"web"}')]"
Key Takeaway

Functions and expressions enable dynamic value generation, making ARM Templates highly flexible and responsive to deployment parameters.
