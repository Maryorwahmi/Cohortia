Deploying with Copy Loops

Efficiently create multiple instances of resources or properties.

Purpose

Avoid manual duplication of resource definitions when deploying multiple identical or similar resources.

Key Elements

Requires name, count, and optionally mode (serial/parallel) and batchSize.

Dynamic Naming

Use copyIndex() function to get the current iteration's index for dynamic naming and property setting.

{
  "copy": {
    "name": "vmLoop",
    "count": "[parameters('vmCount')]",
    "mode": "parallel",
    "batchSize": 1
  },
  "type": "Microsoft.Compute/virtualMachines",
  "apiVersion": "2021-07-01",
  "name": "[concat('webvm-', copyIndex())]",
  "location": "[resourceGroup().location]",
  "properties": {
    "hardwareProfile": {
      "vmSize": "Standard_DS1_v2"
    },
    "osProfile": {
      "computerName": "[concat('webvm-', copyIndex())]",
      "adminUsername": "cohortiaadmin"
    }
  }
}
Key Takeaway

Copy loops automate the deployment of multiple resource instances, using copyIndex() for dynamic naming, greatly improving scalability and maintainability.
