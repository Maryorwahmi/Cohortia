Incremental Deployment

The default and safer mode for updating existing Azure environments.

Behavior

Adds new resources and updates existing ones defined in the template. Leaves other existing resources untouched.

Use Case

Ideal for making targeted modifications or additions to an existing resource group without affecting unrelated resources.

Safety

Considered safer as it avoids accidental deletion of resources not explicitly managed by the current template.
