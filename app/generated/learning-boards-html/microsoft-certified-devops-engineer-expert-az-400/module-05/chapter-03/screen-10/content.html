Conditional Resource Deployment

Provision resources based on specific criteria using the condition property.

Mechanism

The condition property takes a boolean expression to determine if a resource is deployed.

Example Scenario

Deploy a public IP address only if the environment type is 'Prod', or a monitoring agent if a parameter is true.

Benefit

Creates highly flexible templates that adapt to different deployment contexts without needing multiple template versions.

{
  "condition": "[equals(parameters('environmentType'), 'Prod')]",
  "type": "Microsoft.Network/publicIPAddresses",
  "apiVersion": "2021-02-01",
  "name": "[concat('myPublicIp-', parameters('environmentType'))]",
  "location": "[resourceGroup().location]",
  "sku": {
    "name": "Standard"
  },
  "properties": {
    "publicIPAllocationMethod": "Static"
  }
}
Key Takeaway

Conditional deployments use a boolean 'condition' property to control resource provisioning, making templates adaptable to varying criteria.
