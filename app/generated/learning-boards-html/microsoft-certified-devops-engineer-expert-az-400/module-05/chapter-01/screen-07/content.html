Core Concept

Imperative vs. Declarative IaC

Understanding the two fundamental approaches to defining your infrastructure.

Imperative IaC

  • Focus: How to achieve the desired state (step-by-step commands).
  • Examples: Shell scripts, Ansible playbooks.
  • Control: High control over execution flow.
  • Challenge: Can be complex to manage state and ensure idempotence.
Key Distinction

Imperative is like giving directions; Declarative is like providing a map of the destination.

Declarative IaC

  • Focus: What the desired end-state should be.
  • Examples: ARM Templates, Bicep, Terraform.
  • Automation: Tool determines execution steps.
  • Benefit: More readable, maintainable, and inherently idempotent.
Desired State
Current Infra

Declarative tools reconcile the desired state with the current infrastructure.

Key Takeaway

Declarative IaC defines the desired end-state, while imperative IaC specifies the steps to get there. Declarative is generally preferred for cloud.
