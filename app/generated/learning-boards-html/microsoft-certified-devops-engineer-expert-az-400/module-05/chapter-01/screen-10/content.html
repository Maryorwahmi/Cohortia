Terraform: Cross-Cloud Infrastructure

Defining and provisioning infrastructure across multiple cloud providers.

Key Characteristics

  • Multi-Cloud Support: Manages resources across Azure, AWS, GCP, etc.
  • HCL (HashiCorp Configuration Language): Declarative, human-readable syntax.
  • State File: Tracks deployed resources to manage drift.
  • Open Source: Large community and ecosystem.
Infrastructure Drift

When manual changes are made to deployed infrastructure, causing it to deviate from the IaC definition. Terraform's state file helps detect and correct this.

Key Takeaway

Terraform is a powerful multi-cloud IaC tool using HCL, ideal for hybrid environments and managing infrastructure drift with its state file.
