Detecting and Remediating Drift

Use Terraform to identify and correct infrastructure deviations

Drift Detection with terraform plan
  • Compares desired state (IaC + remote state) with actual Azure state.
  • Highlights discrepancies and proposed changes to align.
Remediation with terraform apply

Running terraform apply will execute the changes identified by plan, bringing the drifted resource back into compliance with your IaC definition.

Key Takeaway

Terraform's plan and apply commands are powerful tools for detecting and automatically correcting infrastructure drift, ensuring consistency.

# Step 1: Detect Drift with terraform plan
terraform plan
# Observe output showing min_tls_version needs update.
# Example plan output snippet:
  # azurerm_storage_account.example will be updated in-place
  ~ resource "azurerm_storage_account" "example" {
        id                                = "/subscriptions/..."
      ~ min_tls_version                   = "TLS1_0" -> "TLS1_2"
        name                              = "cohortiatfsa001"
        # (19 unchanged attributes hidden)
# Step 2: Remediate Drift
terraform apply -auto-approve
# Terraform will apply the change, bringing the resource back to desired state.
