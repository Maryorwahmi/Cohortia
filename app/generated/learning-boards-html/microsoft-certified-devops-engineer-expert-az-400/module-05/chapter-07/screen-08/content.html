Initializing Terraform and Deploying Infrastructure

Migrate your state and apply your IaC configuration

Key Commands
  • terraform init: Initializes the working directory, detects backend, and prompts for state migration.
  • terraform apply -auto-approve: Deploys or updates infrastructure based on the configuration.
Verification Step

After terraform apply, navigate to your Azure Storage Account in the portal, then to the Blob Service > Containers > tfstate container. You should see your devops-expert.tfstate file listed there.

Key Takeaway

terraform init with a backend migrates state, and terraform apply deploys infrastructure, centralizing state management.

# Step 1: Re-initialize Terraform to migrate state
terraform init
# Terraform will detect the backend and prompt for migration. Type 'yes'.
# Step 2: Deploy your infrastructure
terraform apply -auto-approve
# This will create or update resources defined in your .tf files.
# Example output after init:
Initializing the backend...
Successfully configured the backend "azurerm"! Terraform will now
persist this state in Azure Storage.

Do you want to copy existing state to the new backend? (yes/no)
