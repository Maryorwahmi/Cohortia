Modifying Terraform for Remote State

Integrate the Azure backend into your main.tf configuration

Configuration Details
  • The backend "azurerm" block specifies Azure as the state storage.
  • Ensure resource_group_name, storage_account_name, and container_name match your Azure setup.
  • The key parameter defines the name of your state file.
Verification Tip

Before running terraform init, carefully review the backend block parameters to ensure they precisely match the Azure resources you created. Mismatches will prevent successful state migration.

Key Takeaway

Adding the backend block correctly configures Terraform to use Azure Storage for its state, enabling remote state management.

# main.tf (example snippet)
terraform {
  required_providers {
    azurerm = {
      source = "hashicorp/azurerm"
      version = "~>3.0"
    }
    random = {
      source  = "hashicorp/random"
      version = "~>3.0"
    }
  }
  backend "azurerm" {
    resource_group_name  = "tfstate-rg"
    storage_account_name = "cohortiatfstate001" # Your globally unique name
    container_name       = "tfstate"
    key                  = "devops-expert.tfstate"
  }
}
