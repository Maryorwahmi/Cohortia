Configuring Terraform Remote State in Azure

Setting up your backend block for secure state storage

Key Parameters
  • resource_group_name: Azure Resource Group for the storage account.
  • storage_account_name: Globally unique name for the storage account.
  • container_name: Blob container to store the state file.
  • key: The name of the state file within the container.
Important Note

The Azure Storage Account, Resource Group, and Blob Container must exist *before* you run terraform init with the backend configuration. These are typically provisioned manually or via a separate, initial IaC deployment.

Key Takeaway

The backend block directs Terraform to store its state in a specified Azure Storage Blob, requiring pre-existing Azure resources.

# backend.tf or main.tf
terraform {
  backend "azurerm" {
    resource_group_name  = "tfstate-rg"
    storage_account_name = "cohortiatfstate001" # Must be globally unique
    container_name       = "tfstate"
    key                  = "devops-expert.tfstate"
  }
}
# After adding this block, run:
terraform init
# This will migrate your local state or initialize a new remote state.
