Understanding Infrastructure Drift

When actual infrastructure deviates from your IaC definition

Causes of Drift
  • Manual changes in the Azure portal.
  • Out-of-band scripts or automation.
  • Bugs in IaC templates or deployment pipelines.
  • Emergency fixes bypassing IaC workflows.
Consequences

Drift can lead to inconsistent environments, unexpected application behavior, security vulnerabilities, and deployment failures, undermining the reliability of your IaC.

Desired State vs. Actual State

IaC defines the desired state of your infrastructure. When manual changes occur, the actual state diverges, creating drift.

Key Takeaway
