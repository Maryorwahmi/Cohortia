Setting Up Azure for Remote State

Prepare your Azure environment for Terraform state storage

Prerequisites
  • Terraform CLI installed.
  • Azure CLI installed and logged in.
  • An Azure subscription with appropriate permissions.
Why a Dedicated Storage Account?

Using a separate storage account for Terraform state isolates it from your application data, enhancing security and making it easier to manage access controls specifically for state files.

Key Takeaway

Properly setting up Azure resources for remote state is the foundational step for secure and collaborative Terraform deployments.

# Step 1: Create a dedicated resource group
az group create --name "tfstate-rg" --location "eastus"
# Step 2: Create a globally unique storage account
az storage account create \
  --name "cohortiatfstate001" \
  --resource-group "tfstate-rg" \
  --location "eastus" \
  --sku Standard_LRS \
  --encryption-services blob
# Step 3: Create a blob container for state files
az storage container create \
  --name "tfstate" \
  --account-name "cohortiatfstate001"
