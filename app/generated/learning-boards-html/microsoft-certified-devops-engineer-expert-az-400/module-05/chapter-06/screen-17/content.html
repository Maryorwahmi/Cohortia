Key Concepts

Core components and state management

Resource

A block in HCL that defines an infrastructure object to be managed by Terraform, such as a VM or storage account.

Terraform State File

The terraform.tfstate file that maps real-world infrastructure to your Terraform configuration, tracking its current state.

Remote State

Storing the Terraform state file in a shared, secure location (e.g., Azure Storage Blob) for team collaboration and pipeline integration.

Summary Takeaway

Defining resources and managing Terraform state, especially with remote backends, are crucial for consistent and collaborative IaC deployments.
