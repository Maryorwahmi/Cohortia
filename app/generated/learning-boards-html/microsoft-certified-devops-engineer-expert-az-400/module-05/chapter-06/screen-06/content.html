Data Sources and Variables: Dynamic and Reusable IaC

Fetch existing data and parameterize your configurations.

Data Sources

Allow Terraform to fetch information about existing infrastructure or query data from a provider, without creating new resources.

Example: Look up an existing Azure Resource Group by name to use its ID in a new resource.

Variables

Parameterize your Terraform configurations, making them reusable across different environments and reducing hardcoded values.

Example: Define a location variable to easily deploy resources to different Azure regions.

Key Takeaway

Data sources fetch existing infrastructure details, while variables allow for flexible, reusable configurations by externalizing parameters.

# Data Source Example: Fetching an existing Resource Group
data "azurerm_resource_group" "existing_rg" {
  name = "my-existing-resource-group"
}

# Variable Example: Defining a location
variable "location" {
  description = "Azure region for resources"
  type        = string
  default     = "East US"
}

# Using the variable in a resource
resource "azurerm_resource_group" "new_rg" {
  name     = "new-resource-group"
  location = var.location
}
