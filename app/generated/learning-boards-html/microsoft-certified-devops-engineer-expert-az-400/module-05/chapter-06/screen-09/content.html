Anatomy of a Terraform Configuration

Understand the terraform and provider blocks.

The terraform Block

Defines global settings, including `required_providers` with source and version constraints for stability.

The provider Block

Configures the specific cloud provider (e.g., `azurerm`). The `features {}` block is required for newer versions.

Key Takeaway

The terraform and provider blocks are essential for declaring and configuring the necessary plugins to interact with your cloud environment.

# main.tf

terraform {
  required_providers {
    azurerm = {
      source  = "hashicorp/azurerm"
      version = "~>3.0" # Specify a version constraint
    }
    random = { # Required for random_string resource
      source  = "hashicorp/random"
      version = "~>3.0"
    }
  }
}

provider "azurerm" {
  features {} # Required for AzureRM provider 2.x and later
}
