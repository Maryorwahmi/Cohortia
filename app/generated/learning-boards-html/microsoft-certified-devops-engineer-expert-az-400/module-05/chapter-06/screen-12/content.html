Deployment Workflow

Initializing and Planning Your Deployment

Prepare your workspace and preview infrastructure changes.

Step 1

terraform init

Initializes the working directory, downloads required provider plugins, and sets up the backend for state management.

Command: terraform init

Step 2

terraform plan

Generates an execution plan, showing what changes Terraform will make to your infrastructure without actually performing them.

Command: terraform plan

$ terraform init
Initializing the backend...
Initializing provider plugins...
- Reusing previous version of hashicorp/azurerm from the dependency lock file
- Reusing previous version of hashicorp/random from the dependency lock file
Terraform has been successfully initialized!

Key Takeaway

Always run terraform init first to prepare your workspace, and critically review the output of terraform plan before applying any changes.
