Providers and Resources: Building Blocks of IaC

Connect to cloud platforms and define infrastructure components.

Providers

Plugins that Terraform uses to interact with cloud platforms (e.g., Azure, AWS) or other services. They define the resources Terraform can manage.

Example: The azurerm provider enables Terraform to manage Azure resources like Virtual Machines and Storage Accounts.

Resources

The infrastructure components you want to create, such as virtual machines, storage accounts, or virtual networks. Each block describes a single object.

Example: resource "azurerm_resource_group" "rg" { ... } defines an Azure Resource Group.

Key Takeaway

Providers are the bridge to cloud platforms, while resources are the specific infrastructure components defined and managed by Terraform.
