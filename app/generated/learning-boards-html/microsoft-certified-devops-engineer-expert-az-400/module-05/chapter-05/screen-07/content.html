Azure CLI and ARM Template Deployment Tasks

Executing IaC deployments within your YAML pipeline

Task Comparison

AzureCLI@2 Task
  • **Versatile:** Executes any `az` command.
  • **Ideal for Bicep:** Direct `az bicep build` and `az deployment group create`.
  • **Flexible scripting:** Inline or file-based scripts.
AzureResourceManagerTemplateDeployment@3 Task
  • **Specialized for ARM:** Streamlined ARM template deployments.
  • **Built-in features:** Parameter handling, deployment modes.
  • **Simplified YAML:** Often less verbose for ARM.
Key Takeaway

Choose `AzureCLI@2` for Bicep and general Azure CLI commands, and `AzureResourceManagerTemplateDeployment@3` for streamlined ARM Template deployments, always referencing your service connection for authentication.

Task Usage Flow

YAML Pipeline Definition
Select Task: `AzureCLI@2` or `AzureResourceManagerTemplateDeployment@3`
Reference `azureSubscription` (Service Connection)
Execute Azure Deployment
Pro Tip

For Bicep, always use `az bicep build` first to compile your Bicep files into ARM JSON before deployment, even if `az deployment group create` can do it implicitly. This helps catch syntax errors earlier.
