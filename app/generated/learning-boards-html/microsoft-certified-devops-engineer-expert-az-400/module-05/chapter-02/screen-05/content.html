Template Structure
Anatomy of an ARM Template

Every ARM Template is a JSON file with a predefined structure, essential for Azure's interpretation. It typically includes six main top-level sections:

  • $schema: Defines the template language version.
  • contentVersion: Tracks template changes.
  • parameters: Customizable deployment values.
  • variables: Reusable internal values.
  • resources: Azure services to deploy.
  • outputs: Values returned from deployment.
Key Takeaway

A well-structured ARM Template with all six core sections ensures proper interpretation and deployment by Azure Resource Manager.

Basic Template Outline
{  "$schema": "https://schema.management.azure.com/schemas/2019-04-01/deploymentTemplate.json#",  "contentVersion": "1.0.0.0",  "parameters": {    // Values provided at deployment time  },  "variables": {    // Reusable values derived within the template  },  "resources": [    // Azure resources to deploy  ],  "outputs": {    // Values returned from the deployment  }}
Understanding Metadata

The $schema and contentVersion properties provide essential metadata, guiding both the Azure Resource Manager and template authors on how to interpret the template's language and version.
