Deployment Control
Managing Resource Dependencies

Dependencies ensure resources are provisioned in the correct order. ARM handles some implicitly, but dependsOn provides explicit control.

  • Implicit Dependencies: Handled when one resource references another's output or property.
  • Explicit Dependencies: Use the dependsOn array for complex or critical sequencing.
  • Ensures Order: Guarantees a resource is fully deployed before its dependents start.
  • Prevents Failures: Avoids errors due to missing prerequisite resources.
Key Takeaway

Correctly managing dependencies, especially with dependsOn, is crucial for successful and reliable ARM Template deployments of interconnected Azure services.

Example: Web App Depends on SQL Database
{  "resources": [    {      "type": "Microsoft.Sql/servers",      "apiVersion": "2021-11-01",      "name": "mySqlDatabase",      "location": "[parameters('location')]",      "properties": { /* ... */ }    },    {      "type": "Microsoft.Web/serverfarms",      "apiVersion": "2021-03-01",      "name": "myAppServicePlan",      "location": "[parameters('location')]",      "sku": { "name": "F1" }    },    {      "type": "Microsoft.Web/sites",      "apiVersion": "2021-03-01",      "name": "myWebApp",      "location": "[parameters('location')]",      "dependsOn": [        "[resourceId('Microsoft.Sql/servers', 'mySqlDatabase')]",        "[resourceId('Microsoft.Web/serverfarms', 'myAppServicePlan')]"      ],      "properties": {        "serverFarmId": "[resourceId('Microsoft.Web/serverfarms', 'myAppServicePlan')]",        "siteConfig": {          "appSettings": [            {              "name": "ConnectionStrings:DefaultConnection",              "value": "[concat('Server=tcp:', 'mySqlDatabase', '.database.windows.net;...')]"            }          ]        }      }    }  ]}
Common Mistake

Forgetting to define explicit dependencies for resources that rely on others, leading to 'resource not found' errors during deployment.
