Resource Declaration
Resources: Defining Your Azure Services

The resources section is the core of an ARM Template, where you declare all the Azure services you intend to deploy.

  • Resource Type: Identifies the Azure service (e.g., Microsoft.Storage/storageAccounts).
  • API Version: Specifies the resource provider API version to use.
  • Name & Location: Unique identifier and geographical region for the resource.
  • Properties: Configuration specific to the resource type (e.g., SKU, access tier).
Key Takeaway

The resources section is where you declaratively define all Azure services, specifying their type, API version, name, location, and properties.

Example: Storage Account Resource
{  "resources": [    {      "type": "Microsoft.Storage/storageAccounts",      "apiVersion": "2021-09-01",      "name": "[variables('storageAccountName')]",      "location": "[parameters('location')]",      "sku": {        "name": "[variables('storageSku')]"      },      "kind": "StorageV2",      "properties": {        "accessTier": "Hot",        "supportsHttpsTrafficOnly": true      }    }  ]}
Azure Documentation is Key

Always refer to the official Azure documentation for the correct resource types, API versions, and available properties for each service.
