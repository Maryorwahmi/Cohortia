Extracting Information with Outputs

Accessing resource properties and deployment results

Outputs (`output`)

  • Define values to be returned from a Bicep deployment.
  • Consumed by other Bicep files, scripts, or CI/CD pipelines.
  • Syntax: `output = `.
Direct Property Access

Bicep allows direct access to resource properties using symbolic names (e.g., `storage.id`), a significant improvement over ARM's `reference()` functions.

Key Takeaway

Outputs are crucial for integrating Bicep deployments with other systems, providing easy access to deployed resource information.

output storageAccountEndpoint string = storage.properties.primaryEndpoints.blob
output storageAccountResourceId string = storage.id

// `storage` refers to the symbolic name of the resource defined earlier.

// Access properties using dot notation: `storage.properties.primaryEndpoints.blob`.

// This is much cleaner than ARM's `reference(resourceId('Microsoft.Storage/storageAccounts', storageAccountName), '2021-09-01').primaryEndpoints.blob`.
