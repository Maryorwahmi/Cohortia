Seamless Deployment with Azure CLI

Leveraging existing tools for Bicep deployments

Deployment Process

  • Use `az deployment group create` command, similar to ARM Templates.
  • Specify the Bicep file directly with `--template-file`.
  • Azure CLI automatically compiles Bicep to ARM JSON before sending to Azure.
  • Pass parameters using `--parameters` for dynamic configuration.
Transparent Compilation

The automatic compilation means you get Bicep's authoring benefits without losing ARM's robust deployment capabilities.

Key Takeaway

Bicep integrates smoothly into existing Azure CLI workflows, making deployment simple and efficient.

az deployment group create \
  --resource-group "myIaCResourceGroup" \
  --template-file main.bicep \
  --parameters storageAccountName=cohortiabicep

// `az deployment group create` is the core command.

// `--resource-group` specifies the target resource group.

// `--template-file` points directly to your Bicep file.

// `--parameters` allows passing values to your Bicep parameters.
