Metrics: Quantifying System Behavior

Tracking trends and identifying anomalies with numerical data

What are Metrics?

  • •Numerical measurements collected over time.
  • •Often aggregated (e.g., average, sum, percentile).
  • •Used for tracking trends, identifying anomalies, and triggering alerts.
  • •Answers: "How much?" or "How often?"

Common Metric Examples

  • •**Request Rate:** Number of requests per second.
  • •**Error Count:** Number of failed requests or exceptions.
  • •**Latency:** Time taken for a request to complete (e.g., P99 latency).
  • •**Resource Utilization:** CPU, memory, disk I/O, network bandwidth.

Azure Context

Azure automatically collects platform metrics for most resources (e.g., App Service, Virtual Machines, Storage Accounts).

You can view these in the Azure portal under the 'Metrics' blade for each resource, allowing you to visualize historical data and set up alerts based on thresholds.

Key Takeaway

Metrics are essential for high-level system health monitoring and trend analysis, providing quick answers to 'how much' and 'how often' issues occur.
