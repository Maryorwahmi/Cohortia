Action Groups: Orchestrating Responses

Bundling notifications and automation for effective incident management.

Definition

An Action Group is a collection of notification preferences and automation actions that can be triggered by an Azure Monitor alert, enabling reusable and coordinated responses.

Key Takeaway

Action Groups are crucial for defining comprehensive, automated responses to alerts, transforming simple notifications into powerful incident management workflows.

Common Action Group Actions
Email/SMS/Push

Direct messages to individuals or groups.

Webhook

Call HTTP endpoints for custom systems, Teams, Slack.

Azure Function

Trigger serverless code for custom logic (e.g., restarting a service).

Logic App

Orchestrate complex workflows across services.
