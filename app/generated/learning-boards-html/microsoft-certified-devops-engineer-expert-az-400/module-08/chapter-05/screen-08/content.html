Configuration Steps

Configuring Alerts: Scope and Conditions

Defining what to monitor and when to trigger an alert.

01

Select the Scope

Choose the specific Azure resource, resource group, or subscription to monitor. This defines the boundaries of your alert's observation.

Example

A single VM, an App Service Plan, or a Log Analytics Workspace.

02

Define the Condition

Specify the criteria that must be met for the alert to trigger. This is where you set thresholds for metrics or write KQL queries for logs.

Metric Alert

CPU > 90% for 5 minutes.

Log Alert

exceptions | count > 0

Key Takeaway

Accurate scope selection and precise condition definition are foundational to creating effective and noise-free Azure Monitor alerts.
