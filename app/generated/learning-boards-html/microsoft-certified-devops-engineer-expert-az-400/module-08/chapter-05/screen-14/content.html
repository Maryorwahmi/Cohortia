Key Concepts

Essential terms from this chapter

Alerts

Proactive notifications triggered by Azure Monitor when specific conditions (metrics or logs) are met.

Metric-based Alerts

Alerts triggered when a numerical metric (e.g., CPU usage) crosses a defined threshold for a certain period.

Log-based Alerts

Alerts triggered by the results of a Kusto Query Language (KQL) query against log data in a Log Analytics Workspace.

Summary Takeaway

Azure Monitor provides both simple metric-based and powerful log-based alerts to proactively detect and respond to issues across your Azure environment.
