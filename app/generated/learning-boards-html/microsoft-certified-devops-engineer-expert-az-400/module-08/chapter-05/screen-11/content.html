Practical Alerting: Metric Alert with Azure CLI

Implementing a CPU usage alert using command-line tools.

Key Steps
  • Create Action Group: Define notification preferences.
  • Define Scope: Target the specific resource (e.g., App Service Plan).
  • Set Condition: Specify metric, threshold, and evaluation frequency.
  • Link Action Group: Connect the alert to its defined responses.
Key Takeaway

Using Azure CLI for alerts enables repeatable, version-controlled monitoring configurations, aligning with Infrastructure as Code principles.

Azure CLI Code Walkthrough
# Create an Action Group for email notifications
az monitor action-group create \
--resource-group YourResourceGroup \
--name "EmailAdminsAG" \
--short-name "EmailAdmins" \
--actions email YourEmail "Admin Email"

# Create a metric alert for an App Service CPU usage
az monitor metrics alert create \
--resource-group YourResourceGroup \
--name "HighCpuAppServiceAlert" \
--scopes /subscriptions/YOUR_SUBSCRIPTION_ID/resourceGroups/YourResourceGroup/providers/Microsoft.Web/serverFarms/YourAppServicePlanName \
--condition "avg Microsoft.Web/serverFarms/CpuPercentage > 80" \
--description "Alerts when App Service Plan CPU exceeds 80%" \
--severity 2 \
--action EmailAdminsAG \
--window-size 5m \
--evaluation-frequency 1m
Important Note

The --scopes parameter requires the resource ID of the App Service Plan, not the App Service itself, for CPU percentage metrics.
