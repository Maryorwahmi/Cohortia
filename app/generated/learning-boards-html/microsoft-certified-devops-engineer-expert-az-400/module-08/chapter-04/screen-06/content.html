Collecting Azure Resource Logs

Sending diagnostic data directly from Azure services to Log Analytics.

How it Works
  • Configure Diagnostic Settings on Azure resources.
  • Select specific log categories (e.g., 'Audit', 'Requests').
  • Choose Log Analytics Workspace as the destination.
  • Data streams automatically to the workspace.
Key Takeaway

Leveraging Diagnostic Settings is crucial for automatically feeding rich, resource-specific telemetry into Log Analytics, providing immediate visibility into Azure service operations.

Example: App Service Web Logs

For an Azure App Service, you can enable diagnostic logging to send detailed HTTP request logs, application logs, and deployment logs directly to Log Analytics. This allows you to analyze web traffic patterns, identify application errors, and track deployment success rates all from a single query interface.
