Collecting Azure VM Agent Logs

Leveraging the Log Analytics agent for operating system and custom logs.

What the Agent Collects
  • OS Performance Counters: CPU, memory, disk I/O.
  • Windows Event Logs: System, Application, Security events.
  • Syslog (Linux): Standard Linux system logs.
  • Custom Text Logs: Application-specific log files.
Key Takeaway

The Log Analytics agent is essential for deep OS-level visibility, extending centralized logging to your virtual machines and hybrid environments.

Hybrid Cloud Support

The Log Analytics agent isn't limited to Azure VMs. By integrating with Azure Arc, you can deploy the same agent to your on-premises physical servers or virtual machines running in other clouds. This allows you to bring their operational data into your Azure Log Analytics Workspace, providing a truly unified view across your entire hybrid infrastructure.
