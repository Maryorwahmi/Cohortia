Data Ingestion

Application Insights & Custom Logs

Seamless application telemetry and flexible custom data ingestion.

Application Insights Integration
  • Automatically sends application telemetry to Log Analytics.
  • Includes requests, dependencies, exceptions, traces.
  • Enables correlation with infrastructure logs.
Custom Log Capabilities
  • Define custom tables for unique log formats.
  • Ingest via Data Collector API or Log Analytics agent.
  • Ideal for legacy apps or specific business process logs.
Key Takeaway

Combining Application Insights with custom log ingestion ensures that all application-level and unique business data contribute to your centralized observability.
