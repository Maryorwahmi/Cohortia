KQL Fundamentals

Basic Queries: Filtering and Projection

Learning to select specific data and columns from your logs.

Key Operators
  • take N: Retrieves the first N records.
  • where [condition]: Filters rows based on a boolean expression.
  • project [columns]: Selects specific columns to display.
  • order by [column] [asc/desc]: Sorts results.
Key Takeaway

Mastering basic KQL operators like take, where, project, and order by is crucial for efficient data exploration and targeted log analysis.

Pro-Tip: Use ago() for Time

Instead of hardcoding specific dates, always use the ago() function for time-based filtering (e.g., TimeGenerated > ago(1h)). This makes your queries dynamic and reusable, always showing data relative to the current time.

KQL Code Walkthrough: Filtering Errors

Find error responses from a specific App Service.

AppRequests
| where TimeGenerated > ago(1h) // Last 1 hour
| where CloudRoleName == "YourWebAppName" // Filter by application name
| where ResultCode >= 400 // Filter for error responses
| project TimeGenerated, Url, ResultCode, DurationMs // Select specific columns
| order by TimeGenerated desc
