Aggregation: Summarizing Log Data

Using summarize to count, average, and group your log entries.

The summarize Operator
  • Calculates aggregate values (e.g., count(), avg(), sum(), max()).
  • Uses the by clause to group results by one or more columns.
  • Transforms raw data into statistical summaries.
Key Takeaway

The summarize operator is essential for high-level monitoring, allowing you to quickly identify trends and anomalies by condensing vast log data into meaningful metrics.

Common Aggregation Functions

Beyond count(), KQL offers functions like avg() for average values, sum() for total sums, min() and max() for extreme values, and percentile() for statistical distribution. Experiment with these to get a deeper understanding of your data.

KQL Code Walkthrough: Counting Requests

Count requests by their HTTP result code.

AppRequests
| summarize RequestCount = count() by ResultCode
| order by RequestCount desc
Output Example

Imagine the output showing:

ResultCode | RequestCount
-----------|-------------
200        | 1500
404        | 300
500        | 50

This quickly highlights that most requests are successful, but there's a significant number of 'Not Found' errors and some 'Internal Server Errors' that warrant further investigation.
