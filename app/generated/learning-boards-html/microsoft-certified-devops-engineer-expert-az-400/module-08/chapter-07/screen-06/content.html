Essential Components for Dynamic Reports

01

Add Text

Provide context, explanations, and titles using markdown. This guides users and clarifies data, ensuring numbers are always understood within their operational context.

02

Add Query Blocks (KQL)

Execute KQL queries against Log Analytics or Application Insights. Visualize results as tables, charts (line, bar, area), or grids to transform raw logs into visual trends.

03

Add Metric Blocks

Directly display platform metrics from Azure resources. These blocks provide immediate, high-level performance indicators like CPU usage or network activity, offering quick health checks.

04

Add Parameters

Enable user interaction by adding parameters for filtering data by time range, resource, or custom values. This makes Workbooks dynamic, reusable, and highly adaptable to different analytical needs.

05

Add Links

Integrate links to other Workbooks, alerts, or external documentation. This creates a seamless navigation experience, allowing users to dive deeper or access related information effortlessly.

Interactive & Reusable

Combine these elements to build powerful, dynamic reports that adapt to your analytical needs.

Key Takeaway

Workbooks are built from modular blocks—text, queries, metrics, parameters, and links—allowing for rich customization and dynamic data presentation, making them highly adaptable for various operational needs.
