A Step-by-Step Guide to Visualizing Key Application Metrics

01

Create Workbook & Time Parameter

Start a new blank Workbook in Application Insights. Add a 'Time range picker' parameter (e.g., TimeRange) to enable dynamic filtering across all blocks.

02

Add Title & Metrics Block

Add a text block for the title (e.g., # Application Health Dashboard). Then, add a metrics block to display total Requests from your Application Insights resource, linked to TimeRange.

03

KQL: Failed Requests Trend

Add a KQL query block targeting your Log Analytics Workspace. Query requests, filter for success == false, summarize by time, and render as a time chart for 'Failed Requests Trend'.

04

KQL: Top 5 Exceptions

Add another KQL query block. Query exceptions, summarize by Type, take the top 5 by count, and render as a pie chart for 'Top 5 Exception Types'.

Interact & Observe

Change the 'Time Range' parameter at the top of the Workbook. Observe how all the blocks dynamically update, providing a powerful, interactive view of your application's health over different periods.

Key Takeaway

Building an Azure Workbook involves combining various blocks and parameters to create a dynamic, interactive view of application health, enabling guided troubleshooting and comprehensive monitoring.
