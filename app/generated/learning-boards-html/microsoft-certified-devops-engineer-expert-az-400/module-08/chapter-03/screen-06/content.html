Diagnosing Issues

Exceptions and Traces

Exceptions Telemetry

  • Records unhandled exceptions and errors in your application.
  • Provides stack traces, exception types, and contextual information.
  • Essential for debugging and understanding application failures.
  • Helps prioritize and fix critical bugs quickly.
Example: A database connection error causes an unhandled exception. Application Insights captures the full stack trace.
Key Takeaway

Exceptions provide immediate error context, while traces offer custom logging for detailed flow analysis.

Traces (Custom Logs)

  • Allows sending arbitrary log messages from application code.
  • Invaluable for understanding execution flow and debugging specific logic.
  • Supports different severity levels (Info, Warning, Error).
  • Can include custom properties for enhanced filtering.
Example: Log a message when a complex calculation starts or finishes, with relevant input parameters.
Common Mistake

Over-logging with traces can lead to high data volume and costs. Be selective and use appropriate severity levels.
