Instrumenting a .NET Core Web App

Step-by-Step SDK Integration

Installation & Configuration

  • Install NuGet Package: Add `Microsoft.ApplicationInsights.AspNetCore` to your project.
  • Configure Services: Use `builder.Services.AddApplicationInsightsTelemetry()` in `Program.cs`.
  • Connection String: Set `options.ConnectionString` from `appsettings.json` or environment variables.
  • Optional: Add custom `ITelemetryInitializer` for advanced scenarios.
Best Practice: Always use environment variables for connection strings in production to enhance security.
Key Takeaway

Properly adding the NuGet package and configuring the connection string in `Program.cs` is essential for .NET Core telemetry.

Program.cs.NET 6+
using Microsoft.ApplicationInsights.Extensibility;

var builder = WebApplication.CreateBuilder(args);

// Add Application Insights services
builder.Services.AddApplicationInsightsTelemetry(options =>
{
    // Configure with Connection String from appsettings.json or environment variables
    options.ConnectionString = builder.Configuration["APPLICATIONINSIGHTS_CONNECTION_STRING"];
});

// Optional: Configure custom telemetry processors or initializers
builder.Services.AddSingleton<ITelemetryInitializer, MyCustomTelemetryInitializer>();

// ... other services ...

var app = builder.Build();

// ... other middleware ...

app.Run();
