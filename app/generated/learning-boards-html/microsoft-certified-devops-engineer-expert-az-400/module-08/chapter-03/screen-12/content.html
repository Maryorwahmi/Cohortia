Common Troubleshooting Scenarios

Diagnosing Application Insights Issues

Configuration & Connectivity

  • Incorrect Connection String: Verify `APPLICATIONINSIGHTS_CONNECTION_STRING` in app settings.
  • Network/Firewall Blocks: Ensure outbound access on port 443 to `dc.services.visualstudio.com`.
  • SDK Initialization: Confirm SDK is properly initialized and `TelemetryClient` is used.
Always check Azure App Service Configuration settings for correct environment variables.
Key Takeaway

Proactive troubleshooting of configuration, network, sampling, and data privacy ensures reliable Application Insights telemetry collection.

Data Collection & Privacy

  • Aggressive Sampling: Adjust sampling rate in Azure Portal if data points are missing.
  • Telemetry Processors: Review custom processors that might filter out data.
  • Sensitive Data (PII): Avoid sending PII; implement data sanitization/redaction.
  • High Data Volume: Optimize custom telemetry to balance insights with cost.
Never send sensitive user data directly to Application Insights without proper anonymization.
