Instrumenting a Node.js Application

SDK Setup and Basic Telemetry

Installation & Usage

  • Install npm Package: Use `npm install applicationinsights`.
  • Initialize SDK: Call `appInsights.setup(connectionString).start()`.
  • Default Client: Access `appInsights.defaultClient` for custom telemetry.
  • Track Methods: Use `trackEvent()`, `trackMetric()`, `trackTrace()` for custom data.
Remember to set `APPLICATIONINSIGHTS_CONNECTION_STRING` as an environment variable for secure deployment.
Key Takeaway

The Node.js SDK provides a straightforward way to initialize Application Insights and send various types of telemetry, including custom data.

app.jsNode.js
const appInsights = require('applicationinsights');

// Configure with Connection String
appInsights.setup(process.env.APPLICATIONINSIGHTS_CONNECTION_STRING)
    .setSendLiveMetrics(true) // Optional: Enable Live Metrics Stream
    .start();

const client = appInsights.defaultClient;

// Example: Track a custom event
client.trackEvent({ name: "UserLoggedIn", properties: { userId: "user123", method: "OAuth" } });

// Example: Track a custom metric
client.trackMetric({ name: "ItemsProcessed", value: 100 });

// Example: Log a trace message
client.trackTrace({ message: "Processing started for batch ABC", severity: appInsights.Contracts.SeverityLevel.Information });
