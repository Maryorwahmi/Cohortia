Tracking Application Flow

Requests and Dependencies

Requests Telemetry

  • Captures incoming HTTP requests to your web app.
  • Includes URL, response time, success/failure status, response code.
  • Fundamental for understanding application throughput and latency.
  • Helps identify slow endpoints and user experience issues.
Example: A user loads a webpage, triggering an HTTP GET request to your server. Application Insights records its duration and status.
Key Takeaway

Requests provide insight into user-facing performance, while dependencies reveal external service bottlenecks.

Dependencies Telemetry

  • Tracks calls made by your application to external services.
  • Covers databases (SQL, Cosmos DB), other APIs, external HTTP services.
  • Crucial for identifying bottlenecks caused by slow external components.
  • Provides visibility into third-party service performance.
Example: Your application queries an Azure SQL Database. Application Insights tracks the query duration and success.
Pro Tip

Correlate requests and dependencies to trace an entire transaction flow and pinpoint exact performance culprits.
