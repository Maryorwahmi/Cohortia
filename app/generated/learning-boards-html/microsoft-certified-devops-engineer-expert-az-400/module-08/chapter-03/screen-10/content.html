Capturing Business Logic

Custom Events and Metrics

Custom Events (`TrackEvent()`)

  • Records discrete occurrences or user actions.
  • Ideal for tracking specific business logic flows (e.g., checkout steps).
  • Can include custom properties for rich contextual data.
  • Helps understand user behavior and feature adoption.
Example: A user successfully adds an item to their shopping cart. Track this event with item ID and user ID.
Key Takeaway

Custom telemetry allows you to monitor application-specific business logic, providing insights beyond standard performance metrics.

Custom Metrics (`TrackMetric()`)

  • Captures numerical values for application-specific performance indicators.
  • Useful for tracking durations, counts, or sizes (e.g., processing time, queue depth).
  • Provides quantitative data for performance analysis and trending.
  • Can be aggregated and visualized in Azure Monitor.
Example: The duration of a complex report generation process. Track the time in milliseconds.
Pro Tip

Combine custom events and metrics to get a holistic view of business operations and their performance.
