Essential Application Insights Concepts

Core Definitions for APM

Application Insights

An APM service within Azure Monitor for monitoring live web applications, providing deep insights into performance and health.

Instrumentation Key/Connection String

Unique identifiers used to configure your application's SDK to send telemetry to a specific Application Insights resource.

Requests

Telemetry data tracking incoming HTTP requests to your web application, including URL, response time, and status.

Summary Takeaway

Application Insights provides the foundation for APM, using unique identifiers to collect and analyze incoming requests for performance monitoring.
