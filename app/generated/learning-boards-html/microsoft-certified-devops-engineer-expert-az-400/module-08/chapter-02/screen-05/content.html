What are Platform Metrics?

Numerical values that describe the performance and health of Azure resources. Automatically collected by Azure.

Key Characteristics

  • •Automatic Collection: No configuration needed.
  • •Time-Series Data: Stored with timestamps for trending.
  • •Lightweight: Optimized for near real-time monitoring and alerting.
Key Takeaway

Platform Metrics provide immediate, quantitative insights into resource health, crucial for real-time performance monitoring.

Common Platform Metric Examples

Virtual Machine

CPU Utilization (%), Network I/O (bytes/sec)

Storage Account

Inbound/Outbound Bytes, Transaction Count

App Service

HTTP Request Count, Average Response Time

Azure SQL Database

DTU Percentage, Log I/O, Connections

Use Case Scenario

You notice a sudden spike in CPU utilization on your Virtual Machine. By checking the platform metrics, you can quickly confirm the spike and set up an alert to notify you if it exceeds a certain threshold, allowing for proactive scaling or investigation.
