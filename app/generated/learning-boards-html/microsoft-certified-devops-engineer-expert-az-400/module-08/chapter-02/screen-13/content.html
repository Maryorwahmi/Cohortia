Module 8›Chapter 8.2›CLI: Diagnostic Settings

Command Overview

The az monitor diagnostic-settings create command configures logs and metrics to be sent to a destination.

  • •--resource: The ID of the target Azure resource.
  • •--name: A unique name for the diagnostic setting.
  • •--workspace: The ID of the Log Analytics Workspace destination.
  • •--logs / --metrics: JSON arrays specifying categories to enable.
Key Takeaway

Automating diagnostic settings with Azure CLI ensures comprehensive and consistent telemetry collection for all critical resources.

Azure CLI Code Example

# Get App Service ID
APP_SERVICE_ID=$(az webapp show --resource-group YourResourceGroup --name YourAppService --query id --output tsv)

# Get Log Analytics Workspace ID
WORKSPACE_ID=$(az monitor log-analytics workspace show --resource-group YourResourceGroup --name YourLogAnalyticsWorkspace --query id --output tsv)

# Create diagnostic settings
az monitor diagnostic-settings create \
  --resource $APP_SERVICE_ID \
  --name "SendAppServiceLogsToLA" \
  --workspace $WORKSPACE_ID \
  --logs '[{"categoryGroup": "allLogs", "enabled": true}]' \
  --metrics '[{"category": "AllMetrics", "enabled": true}]'
Common Mistake

Not configuring diagnostic settings for all critical resources, leading to monitoring blind spots and incomplete data for troubleshooting.
