Advanced Concepts Recap

Deepening your understanding of Azure Monitor components.

Activity Log

A subscription-level log providing a record of events that occurred in Azure, detailing who performed what action, when, and on which resource.

Log Analytics Workspace

A unique Azure resource that acts as a centralized repository for storing, querying, and analyzing log data from various sources using Kusto Query Language (KQL).

Application Insights

An Application Performance Management (APM) service within Azure Monitor, specializing in monitoring live web applications for performance, availability, and usage.

Summary Takeaway

The Activity Log tracks control-plane events, while Log Analytics Workspaces and Application Insights provide specialized log storage and APM, all powered by KQL for deep analysis.
