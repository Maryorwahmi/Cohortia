What is a Log Analytics Workspace?

A unique Azure resource that serves as a centralized repository for storing, querying, and analyzing log data from various sources.

Data Sources

  • •Azure Resources: Logs from App Services, VMs, Key Vaults, etc.
  • •Virtual Machines: Using the Log Analytics agent.
  • •Custom Applications: Via SDKs or data collectors.
Key Takeaway

Log Analytics Workspaces centralize diverse log data, enabling powerful analysis and correlation using KQL for distributed systems.

The Power of Kusto Query Language (KQL)

What KQL Enables
  • •Complex Searches: Find specific events across vast log volumes.
  • •Aggregations: Summarize data (e.g., count errors per hour).
  • •Correlations: Link events from different sources to understand end-to-end flows.
  • •Visualizations: Create charts and graphs from query results.
Example KQL Query
AzureActivity
| where OperationNameValue == "Microsoft.Compute/virtualMachines/restart/action"
| summarize count() by Caller, ResourceGroup
| order by count_ desc

This query counts VM restarts by caller and resource group.
