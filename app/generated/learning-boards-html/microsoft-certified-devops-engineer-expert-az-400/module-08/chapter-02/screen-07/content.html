What is the Activity Log?

A record of subscription-level events, detailing who performed what operation, when, and on which resource.

Key Purposes

  • •Auditing: Track changes for security and accountability.
  • •Compliance: Meet regulatory requirements for activity logging.
  • •Troubleshooting: Understand unexpected configuration changes.
Key Takeaway

The Activity Log is vital for auditing, compliance, and understanding all control-plane changes within your Azure subscription.

Common Activity Log Events

Resource Management

Create/Delete Resource Group, Deploy Web App

Virtual Machine Operations

Start/Stop VM, Resize VM, Apply Updates

Security & Identity

Role Assignment Changes, Policy Deployments

Network Configuration

NSG Rule Changes, VNet Peering Setup

Use Case Scenario

An unexpected virtual machine reboot occurs. By checking the Activity Log, you can quickly identify if a user initiated the reboot, when it happened, and from where, helping to pinpoint the cause of the outage.
