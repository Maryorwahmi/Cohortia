Module 8›Chapter 8.2›CLI: Create Workspace

Command Overview

The az monitor log-analytics workspace create command provisions a new Log Analytics Workspace.

  • •--resource-group: The resource group to contain the workspace.
  • •--workspace-name: A unique name for your new workspace.
  • •--location: The Azure region for deployment.
Key Takeaway

Automating Log Analytics Workspace creation with Azure CLI ensures consistent, repeatable, and efficient provisioning of your central log repository.

Azure CLI Code Example

az monitor log-analytics workspace create \
  --resource-group YourResourceGroup \
  --workspace-name YourLogAnalyticsWorkspace \
  --location eastus
Pro-Tip

Always use meaningful names for your resource groups and workspaces. Consider naming conventions that reflect the environment (e.g., 'prod-monitor-rg') or application (e.g., 'webapp-logs-workspace').
