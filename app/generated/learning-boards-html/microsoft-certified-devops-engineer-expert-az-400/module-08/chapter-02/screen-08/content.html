Accessing Azure Monitor

  • •Global Search: Type 'Monitor' in the Azure portal search bar.
  • •Services Menu: Select 'Monitor' from the left-hand navigation pane.

Key Sections

  • •Metrics: View performance data.
  • •Logs: Query detailed log data.
  • •Alerts: Manage notifications and automated actions.
  • •Workbooks: Create interactive reports and dashboards.
Key Takeaway

The Azure portal provides an intuitive, contextual interface for quickly accessing and navigating all your Azure Monitor data.

Contextual Navigation Example

Scenario: Investigating an Azure Function App
  • •Navigate to your Azure Function App resource.
  • •In the left-hand menu, under 'Monitoring', you'll find direct links to:
  • ›Application Insights: For application performance data.
  • ›Metrics: For function execution counts, errors, etc.
  • ›Log Stream: For real-time function logs.
  • ›Diagnostic Settings: To configure where logs are sent.
Pro-Tip

Always start your troubleshooting from the specific resource's monitoring blade to leverage contextual links and quickly narrow down the problem area.
