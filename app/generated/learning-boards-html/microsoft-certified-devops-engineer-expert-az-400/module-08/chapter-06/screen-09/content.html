Post-Mortem Debugging

Debugging Live Exceptions with Snapshot Debugger

Snapshot Debugger automatically collects a debug snapshot of executing code when an exception occurs in production, providing the full call stack and local variables for post-mortem analysis.

Automatic Snapshot Capture

Triggers automatically when an unhandled exception occurs in your live application, without manual intervention.

Full Debug Context

Includes the complete call stack and local variables at the exact moment of the exception.

Safety Note

Snapshots can contain sensitive data. Implement data redaction and ensure strict Azure RBAC for access control.

Example: Debugging a NullReferenceException

A snapshot reveals a NullReferenceException in UserService.GetUserProfile(). Inspecting local variables shows that the userId parameter was unexpectedly null, leading to the error.

// Snapshot View (Conceptual)
Call Stack:
  UserService.GetUserProfile(userId: null)
  ProfileController.Get(id: null)
Local Variables:
  userId: null
  requestHeaders: { ... }
  ...
Key Takeaway

Snapshot Debugger enables powerful post-mortem debugging of production exceptions, eliminating the need to reproduce issues locally.
