Identifying 'Hot Paths' with Performance Profiler

Application Insights' Performance Profiler automatically collects detailed performance traces from live applications, capturing call stacks to identify code-level bottlenecks and 'hot paths'.

Automatic Trace Collection

Profiler automatically collects traces when performance issues like high CPU usage are detected in your live application.

Detailed Call Stacks

Captures full call stacks, showing which methods are consuming the most CPU time or memory.

Safety Note

Ensure no sensitive data is inadvertently captured in stack traces. Configure data redaction and restrict access via RBAC.

Example: Identifying a Hot Path

A profiler trace reveals that MyService.ProcessData() spends 70% of its time in DataConverter.SerializeComplexObject(). This pinpoints the exact method needing optimization.

// Example Call Stack Snippet
MyService.ProcessRequest()
  MyService.ProcessData()
    DataConverter.SerializeComplexObject()  // <-- High CPU usage
      System.Text.Json.JsonSerializer.Serialize()
        ...
Key Takeaway

Performance Profiler provides code-level insights to precisely identify and optimize resource-intensive methods in live applications.
