Operational Awareness

Instant Insights with Live Metrics Stream

Live Metrics Stream provides a real-time, minute-by-minute view of your application's performance and health directly from the Azure portal, without any delay.

Real-time Data Flow

See incoming requests, failed requests, dependency calls, and exceptions as they happen, with minimal latency.

Immediate Verification

Crucial during deployments or for immediate post-incident verification of fixes.

Example: Monitoring a Deployment

During a new deployment, Live Metrics Stream shows a sudden spike in failed requests and exceptions. This immediate feedback allows the team to quickly identify and roll back the problematic deployment before widespread user impact.

// Live Metrics Stream (Conceptual View)
Requests: 120/min (Normal)
Failed Requests: 5/min (Spike!)
Dependency Calls: 80/min
Exceptions: 3/min (Spike!)
CPU Usage: 45%
Memory: 600MB
Key Takeaway

Live Metrics Stream provides essential real-time visibility for proactive monitoring and rapid response during critical operational events.
