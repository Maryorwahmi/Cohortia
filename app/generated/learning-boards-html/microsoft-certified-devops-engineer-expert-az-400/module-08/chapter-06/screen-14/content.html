Key Concepts

Essential terms for Distributed Tracing and Performance Monitoring.

Distributed Tracing

The process of tracking a single request or transaction as it flows through multiple services and components in a distributed system.

Correlation ID

A unique identifier that links all telemetry items belonging to the same logical operation across different services.

End-to-end Transaction Details

A visualization in Application Insights that shows the complete path and timing of a single request through all its dependencies.

Application Map

A visual representation of your application's topology and communication between services in Application Insights.

Summary Takeaway

Distributed tracing and correlation IDs are fundamental for understanding complex microservices, visualized through Transaction Details and the Application Map.
