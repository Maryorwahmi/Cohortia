Implementing Health Checks: Mapping Endpoints

Expose health check results via dedicated API endpoints for monitoring systems.

var app = builder.Build();

// Map the health check endpoint
app.MapHealthChecks("/healthz"); // Basic health check
app.MapHealthChecks("/healthz-detailed", new HealthCheckOptions
{
    Predicate = _ => true, // Show all checks
    ResponseWriter = UIResponseWriter.WriteHealthCheckUIResponse // Requires HealthChecks.UI.Client NuGet package
});

// ... other middleware ...

app.Run();
Explanation
  • •MapHealthChecks("/healthz") creates a basic health endpoint.
  • •/healthz-detailed provides a comprehensive JSON report.
  • •Predicate = _ => true ensures all registered checks are included.
  • •UIResponseWriter formats the output for readability.
Integration
  • •Load balancers use these endpoints for health probes.
  • •Azure Monitor availability tests can target them.
Key Takeaway

Properly mapped health check endpoints are the gateway for external systems to understand your application's internal health.
