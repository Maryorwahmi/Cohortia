Implementing Availability Tests in Azure Portal

A straightforward process to configure and deploy your monitoring tests.

01

Navigate to Application Insights

Go to your Application Insights resource in the Azure portal.

02

Select Availability

Under 'Investigate', choose 'Availability' to manage tests.

03

Add a New Test

Click 'Add standard test' for URL ping or 'Add multi-step test' for complex scenarios.

04

Configure Test Details

Set URL, frequency, locations, success criteria, and alert settings.

05

Create and Monitor

Click 'Create' and observe the results in the Availability blade.

Key Takeaway

Azure portal provides an intuitive interface for quickly setting up and managing proactive availability tests.
