Configuring Alerts for Availability Tests

Ensure immediate notification of outages and performance degradations.

Alert Configuration

  • •Alert rules are automatically created with availability tests.
  • •Customize these rules to fit specific operational needs.
  • •Integrate with Action Groups for notifications (email, SMS, webhooks).
  • •Ensures immediate notification of external outages.
Importance

Rapid response to issues minimizes downtime and maintains service reliability.

Common Alert Triggers

  • •Test fails from a certain number of locations (e.g., 3 out of 5).
  • •Response time exceeds a defined threshold (e.g., > 2 seconds).
  • •Specific string not found in the response content.
  • •HTTP status code is outside the expected range (e.g., not 200-399).
Pro Tip

Regularly review and fine-tune your alert thresholds to avoid alert fatigue and ensure meaningful notifications.
