Implementing Health Checks: Registering Services

Use Microsoft.Extensions.Diagnostics.HealthChecks to define dependency checks.

var builder = WebApplication.CreateBuilder(args);

// Add health checks
builder.Services.AddHealthChecks()
    .AddSqlServer(builder.Configuration.GetConnectionString("DefaultConnection"),
                  name: "sqlserver",
                  failureStatus: HealthStatus.Degraded) // Degraded if SQL fails
    .AddAzureQueueStorage(builder.Configuration.GetConnectionString("AzureQueueStorage"),
                          name: "azurequeue",
                          failureStatus: HealthStatus.Unhealthy); // Unhealthy if Queue fails

// ... other services ...
Explanation
  • •AddHealthChecks() registers the health check service.
  • •AddSqlServer() checks database connectivity.
  • •AddAzureQueueStorage() verifies queue access.
  • •failureStatus defines the reported health state on failure.
Health Status Levels
  • •Healthy: All checks pass.
  • •Degraded: Some non-critical issues, but app still functional.
  • •Unhealthy: Critical issues, app is not functional.
Key Takeaway

Registering specific health checks allows your application to report granular dependency health, crucial for robust monitoring.
