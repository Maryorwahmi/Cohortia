Essential Deployment Concepts

Core ideas from this chapter.

Rolling Update

Gradually replaces old application instances with new ones, ensuring continuous availability during the update process.

Immutable Infrastructure

Servers are never modified after deployment; any change requires building and deploying a new, replacement server or image.

Kubernetes Deployment

A Kubernetes resource that manages a set of identical Pods and ensures a specified number of replicas are running, supporting rolling updates.

Summary Takeaway

Mastering these deployment patterns is crucial for building resilient, consistent, and continuously available applications in modern cloud environments.
