Understanding Rolling Updates

Gradual, Controlled Application Releases.

What is a Rolling Update?

A deployment strategy where new versions of an application are gradually rolled out by replacing instances of the old version with instances of the new version, one by one or in small batches. Both versions run concurrently.

Key Characteristic

Ensures continuous availability and allows for traffic to be slowly shifted to new instances.

Benefits & Risk Mitigation

  • •Zero downtime during deployment.
  • •Reduced risk: issues affect only a small user subset.
  • •Easy rollback: revert to previous version quickly.
  • •Allows for gradual traffic shifting and monitoring.
Example Scenario

Updating a critical API service without interrupting client applications by slowly replacing old API instances.

Key Takeaway

Rolling updates are a strategic approach to deployments, ensuring high availability and minimizing user impact by managing updates incrementally.
