Feature Flags (Feature Toggles)

Controlling feature visibility independent of deployments

What are Feature Flags?

Feature Flags are a technique to control the visibility and availability of specific features within an application dynamically, without requiring a new code deployment.

  • Code for multiple features can be deployed simultaneously.
  • Features are initially 'off' by default, hidden behind a flag.
  • Flags can be toggled on/off dynamically, often without redeploying.
Key Takeaway

Feature Flags decouple feature release from code deployment, providing dynamic control over feature visibility and accelerating release cycles.

Why Use Feature Flags?

  • Decouple Deployment from Release: Deploy code anytime, release features when ready.
  • Reduce Risk: Turn off problematic features instantly without a full rollback.
  • Enable Experimentation: Facilitate A/B testing and gradual rollouts to specific user segments.
  • Trunk-Based Development: Allow incomplete features to be merged to main branch, hidden by flags.
Example Scenario

A new checkout flow is deployed but only enabled for internal testers via a feature flag before a public rollout.
