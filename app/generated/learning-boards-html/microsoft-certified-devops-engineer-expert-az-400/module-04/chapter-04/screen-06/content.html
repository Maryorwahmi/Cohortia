ARM Template Example: App Service Deployment

Understanding parameters and resource definitions in JSON

Parameters Section

Defines customizable values like appName, skuName, and location, making the template reusable across environments.

Resources Section

Declares the Azure resources to be deployed, such as Microsoft.Web/serverfarms (App Service Plan) and Microsoft.Web/sites (App Service).

Key Takeaway

ARM templates use JSON to define parameters for flexibility and resources with explicit dependencies for ordered deployment.

{
  "$schema": "https://schema.management.azure.com/schemas/2019-04-01/deploymentTemplate.json#",
  "contentVersion": "1.0.0.0",
  "parameters": {
    "appName": {
      "type": "string",
      "metadata": { "description": "The name of the Azure Web App." }
    },
    "appServicePlanName": {
      "type": "string",
      "defaultValue": "myAppServicePlan"
    },
    "skuName": {
      "type": "string",
      "defaultValue": "F1",
      "allowedValues": [ "F1", "D1", "B1", "S1" ]
    },
    "location": {
      "type": "string",
      "defaultValue": "[resourceGroup().location]"
    }
  },
  "resources": [
    {
      "type": "Microsoft.Web/serverfarms",
      "apiVersion": "2020-12-01",
      "name": "[parameters('appServicePlanName')]",
      "location": "[parameters('location')]",
      "sku": { "name": "[parameters('skuName')]" },
      "kind": "AppServicePlan"
    },
    {
      "type": "Microsoft.Web/sites",
      "apiVersion": "2020-12-01",
      "name": "[parameters('appName')]",
      "location": "[parameters('location')]",
      "dependsOn": [
        "[resourceId('Microsoft.Web/serverfarms', parameters('appServicePlanName'))]"
      ],
      "properties": {
        "serverFarmId": "[resourceId('Microsoft.Web/serverfarms', parameters('appServicePlanName'))]",
        "siteConfig": {
          "appSettings": [
            { "name": "WEBSITES_ENABLE_APP_SERVICE_STORAGE", "value": "false" }
          ]
        }
      }
    }
  ]
}
