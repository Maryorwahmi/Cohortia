Azure Pipeline Snippet for Bicep Deployment

A practical look at automating Bicep deployments

Build Bicep

The az bicep build command compiles your Bicep file (e.g., main.bicep) into an ARM JSON template (main.json).

Deploy ARM JSON

The az deployment group create command then deploys the compiled ARM JSON template to the specified Azure resource group, using dynamic parameters.

Key Takeaway

Azure Pipelines automate Bicep deployments by first building to ARM JSON, then deploying the JSON via Azure CLI, ensuring robust IaC integration.

# Example Azure Pipeline snippet for Bicep deployment
- task: AzureCLI@2
  displayName: 'Deploy Bicep Template'
  inputs:
    azureSubscription: 'YourAzureServiceConnection'
    scriptType: 'bash'
    scriptLocation: 'inlineScript'
    inlineScript: |
      az bicep build --file $(System.DefaultWorkingDirectory)/infra/main.bicep
      az deployment group create \
        --resource-group $(resourceGroupName) \
        --template-file $(System.DefaultWorkingDirectory)/infra/main.json \
        --parameters appName=$(appName) appServicePlanName=$(appServicePlanName) skuName=$(skuName)
    failOnStderr: true
