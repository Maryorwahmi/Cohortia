Bicep vs. ARM: A Side-by-Side View

Comparing syntax for App Service deployment

ARM Template (JSON)
{
  "$schema": "...deploymentTemplate.json#",
  "contentVersion": "1.0.0.0",
  "parameters": {
    "appName": { "type": "string" },
    "appServicePlanName": { "type": "string", "defaultValue": "myAppServicePlan" },
    "skuName": { "type": "string", "defaultValue": "F1", "allowedValues": [ "F1", "D1", "B1", "S1" ] },
    "location": { "type": "string", "defaultValue": "[resourceGroup().location]" }
  },
  "resources": [
    {
      "type": "Microsoft.Web/serverfarms",
      "apiVersion": "2020-12-01",
      "name": "[parameters('appServicePlanName')]",
      "location": "[parameters('location')]",
      "sku": { "name": "[parameters('skuName')]" },
      "kind": "AppServicePlan"
    },
    {
      "type": "Microsoft.Web/sites",
      "apiVersion": "2020-12-01",
      "name": "[parameters('appName')]",
      "location": "[parameters('location')]",
      "dependsOn": [
        "[resourceId('Microsoft.Web/serverfarms', parameters('appServicePlanName'))]"
      ],
      "properties": {
        "serverFarmId": "[resourceId('Microsoft.Web/serverfarms', parameters('appServicePlanName'))]",
        "siteConfig": {
          "appSettings": [
            { "name": "WEBSITES_ENABLE_APP_SERVICE_STORAGE", "value": "false" }
          ]
        }
      }
    }
  ]
}
Bicep Code
param appName string
param appServicePlanName string = 'myAppServicePlan'
param skuName string = 'F1'
@allowed([
  'F1'
  'D1'
  'B1'
  'S1'
])
param location string = resourceGroup().location

resource appServicePlan 'Microsoft.Web/serverfarms@2020-12-01' = {
  name: appServicePlanName
  location: location
  sku: {
    name: skuName
  }
  kind: 'AppServicePlan'
}

resource webApp 'Microsoft.Web/sites@2020-12-01' = {
  name: appName
  location: location
  dependsOn: [
    appServicePlan
  ]
  properties: {
    serverFarmId: appServicePlan.id
    siteConfig: {
      appSettings: [
        {
          name: 'WEBSITES_ENABLE_APP_SERVICE_STORAGE'
          value: 'false'
        }
      ]
    }
  }
}
Bicep's Conciseness

Bicep significantly reduces boilerplate, making parameter definitions and resource declarations more direct and easier to read compared to ARM JSON.

Simplified Dependencies

Dependencies are expressed by simply referencing the symbolic name of the resource (e.g., appServicePlan), eliminating complex resourceId functions.

Key Takeaway

Bicep offers a more readable and concise syntax for defining Azure resources, simplifying parameterization and dependency management over ARM JSON.
