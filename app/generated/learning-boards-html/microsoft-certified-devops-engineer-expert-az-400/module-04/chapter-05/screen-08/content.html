Linking Key Vault to Azure DevOps Variable Groups

Connecting your secure Key Vault secrets to be consumed as variables in your pipelines.

Step-by-Step Linking Process

  • Navigate to Library: In Azure DevOps, go to Pipelines -> Library.
  • Create Variable Group: Click + Variable Group and give it a descriptive name.
  • Enable Key Vault Link: Check Link secrets from an Azure key vault as variables.
  • Select Key Vault: Choose your Azure subscription and the specific Key Vault.
  • Add Secrets: Click + Add to select the specific secrets to expose.
  • Save Group: Save the variable group to finalize the link.
Variable Group Purpose

Variable groups centralize variables for reuse across multiple pipelines, promoting consistency and reducing duplication. Linking to Key Vault adds a layer of security for sensitive values.

Security Feature: Automatic Masking

When secrets are linked from Azure Key Vault to a variable group, Azure DevOps automatically marks them as 'secret' variables. This ensures their values are masked in all pipeline logs, preventing accidental exposure and maintaining the confidentiality of your sensitive data throughout the deployment process.

Key Takeaway

Linking Key Vault to Azure DevOps Variable Groups is the standard method to securely expose secrets to pipelines, with automatic masking protecting values in logs.
