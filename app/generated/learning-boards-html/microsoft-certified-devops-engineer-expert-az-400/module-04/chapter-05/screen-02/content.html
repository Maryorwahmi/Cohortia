Learning Objectives

What you'll achieve in this chapter.

Bloom's Taxonomy:
LearnUnderstandApplyMaster
01

Identify Security Risks

Recognize the vulnerabilities introduced by hardcoding secrets and configuration data in source control or pipelines. Understanding these risks is the first step to preventing security breaches.

VERIFIED COMPETENCY MILESTONE
02

Implement Secure Storage

Learn to use Azure Key Vault for secure storage and retrieval of secrets within Azure Pipelines. This skill is crucial for protecting sensitive credentials from unauthorized access.

VERIFIED COMPETENCY MILESTONE
03

Utilize Variable Groups

Master the use of Azure DevOps variable groups to manage environment-specific configuration and secrets. This enables flexible deployments across different stages without code changes.

VERIFIED COMPETENCY MILESTONE
