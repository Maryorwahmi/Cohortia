Key Concepts

Essential terms and definitions from this chapter.

Secrets

Sensitive information like passwords, API keys, and connection strings that must be protected from unauthorized access.

Configuration Data

Non-sensitive settings and parameters that vary between environments, such as API endpoints or feature flag states.

Azure Key Vault

A cloud service for securely storing and managing cryptographic keys, secrets, and SSL/TLS certificates.

Summary Takeaway

Securely managing secrets and configuration data is fundamental to building robust and resilient Continuous Delivery pipelines, with Azure Key Vault as a central component.
