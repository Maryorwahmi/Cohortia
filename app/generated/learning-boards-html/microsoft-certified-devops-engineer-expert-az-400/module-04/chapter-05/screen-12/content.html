Secure Files: Handling Sensitive Files in Pipelines

Managing sensitive files like certificates and SSH keys securely within Azure DevOps.

Key Features of Secure Files

  • Encrypted Storage: Files are encrypted at rest within Azure DevOps.
  • Controlled Access: Access policies define which pipelines can use them.
  • Temporary Availability: Downloaded to agent, used, then cleaned up.
Usage with DownloadSecureFile@1

The DownloadSecureFile@1 task is used in your YAML pipeline to fetch a secure file. It makes the file available at a temporary path on the agent, which can then be referenced by subsequent tasks that require the file.

Example: Code Signing Certificate

To sign an application package, you need a PFX certificate file. This file is uploaded to Secure Files in Azure DevOps. During the pipeline, DownloadSecureFile@1 retrieves it, and a code signing task then uses the downloaded certificate to sign the package, ensuring its authenticity and integrity.

Key Takeaway

Secure Files provide a robust mechanism for managing and temporarily accessing sensitive files like certificates and SSH keys within Azure Pipelines, ensuring their security and controlled usage.
