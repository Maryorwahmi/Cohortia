Key Concepts

Reinforce your understanding of the core elements that constitute a CD pipeline.

Artifact

A deployable component produced by a build process, such as a Docker image or compiled binary.

Pipeline

An automated workflow that orchestrates the steps from code commit to deployment across environments.

Quality Gates

Automated or manual checks within a pipeline that must pass before a release can proceed to the next stage.

Summary Takeaway

These components work in concert to automate, validate, and control the flow of software through the delivery process.
