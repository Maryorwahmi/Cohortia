Key Concepts

Reinforce your understanding of the foundational terms in Continuous Delivery.

Continuous Integration (CI)

Frequent code merges into a central repository, followed by automated builds and tests.

Continuous Delivery (CD)

Extends CI, ensuring software is always deployable to production, often with manual approval.

Continuous Deployment

Extends CD, automatically deploying every change that passes all tests to production.

Summary Takeaway

These three practices form a progressive spectrum of automation, each building upon the last to accelerate and secure software releases.
