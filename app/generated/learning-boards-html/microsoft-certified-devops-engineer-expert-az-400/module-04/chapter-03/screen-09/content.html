Ensuring Completeness and Security with Gates

Integrating Work Item Status and Security Tooling

Work Items Gate

A pre-deployment gate that checks if all associated work items (bugs, features) for the release are in a 'Closed' or 'Done' state in Azure Boards.

Purpose

Ensures all planned development work is complete before deployment.

Security Scans Gate

Integrates with security tools (e.g., Azure Security Center, SonarCloud) to check for vulnerabilities or code quality issues.

Purpose

Prevents deployments with critical security flaws or low code quality.

Key Takeaway

Automated gates for work items and security scans ensure that releases are both functionally complete and free from critical vulnerabilities.
