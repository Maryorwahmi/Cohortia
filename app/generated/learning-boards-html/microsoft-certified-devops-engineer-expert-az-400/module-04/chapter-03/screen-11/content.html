Setting Up Automated Checks in Environments

Defining Parameters for Programmatic Validation

Key Takeaway

Automated gates are configured on environments by selecting a check type and defining specific parameters like evaluation intervals and timeouts.

Example Scenario

After deploying to Staging, automatically check Azure Monitor for critical alerts for 5 minutes before proceeding.

1

Navigate to Environments

Go to Pipelines > Environments and select your target environment (e.g., Staging).

2

Add Automated Check

Click '...' (More options) > 'Approvals and checks', then '+ Add a check' and choose the desired type (e.g., 'Query Azure Monitor alerts').

3

Configure Parameters & Timings

Define specific parameters for the check, 'Time between evaluations', and 'Timeout' for the gate.
