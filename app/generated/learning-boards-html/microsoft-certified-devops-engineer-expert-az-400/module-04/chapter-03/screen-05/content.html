Approvals: Human Intervention in Deployments

Requiring Sign-off at Critical Pipeline Stages

Manual Gate

Specific Individuals/Groups

Release managers, security officers, product owners.

Pre/Post-Deployment

Can be configured before a stage starts or after it completes.

Timeout Settings

Automatically rejects deployment if no action within a set period.

Key Takeaway

Manual approvals provide essential human oversight, especially for production deployments, with flexible approver policies and timeout controls.
