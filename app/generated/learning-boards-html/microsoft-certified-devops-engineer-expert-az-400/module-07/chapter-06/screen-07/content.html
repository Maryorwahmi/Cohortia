Variable Groups: Sharing Secrets Across Pipelines

Enhancing reusability and management of shared credentials

How it Works

Centralizing Shared Secrets

Variable groups allow you to define and share variables, including secrets, across multiple pipelines. This centralizes management and improves consistency.

variables: - group: MySharedSecrets # Link to a variable group

Secrets within a variable group are marked as secret and are encrypted at rest and masked in logs, similar to pipeline variables.

Key Takeaway

Variable groups allow sharing of secrets across multiple pipelines, improving reusability and management, with the most secure option being a link to Azure Key Vault.

Comparison

Pipeline Variables vs. Variable Groups

Pipeline Variables
  • Scoped to single pipeline.
  • Manual updates per pipeline.
Variable Groups
  • Shared across pipelines.
  • Centralized updates.

For secrets that need to be consumed by multiple pipelines, variable groups are the preferred method over individual pipeline variables, especially when linked to Key Vault.

Best Practice

Link to Azure Key Vault

The most secure and recommended approach is to link a variable group to an Azure Key Vault. This way, secrets reside in Key Vault, and the variable group acts as a proxy, fetching them at runtime, combining reusability with robust security.
