SCA in Azure DevOps with WhiteSource Bolt

Implementing dependency scanning for .NET projects in Azure Pipelines.

Tool Spotlight

WhiteSource Bolt: A free Azure DevOps extension for lightweight SCA, integrating directly into the build process.

  • •Seamless Integration: Adds a dedicated task to your `azure-pipelines.yml`.
  • •Automated Scanning: Analyzes direct and transitive dependencies during the build.
  • •Report Generation: Publishes vulnerability reports directly within Azure DevOps.
Key Takeaway

WhiteSource Bolt simplifies SCA for Azure DevOps, embedding security analysis directly into your automated build workflows for continuous protection.

azure-pipelines.yml
# azure-pipelines.yml for WhiteSource Bolt SCA
trigger:
- main

pool:
  vmImage: 'windows-latest'

steps:
- task: UseDotNet@2
  displayName: 'Install .NET SDK'
  inputs:
    version: '6.x'

- task: DotNetCoreCLI@2
  displayName: 'Restore NuGet Packages'
  inputs:
    command: 'restore'
    projects: '**/*.csproj'

- task: DotNetCoreCLI@2
  displayName: 'Build Project'
  inputs:
    command: 'build'
    projects: '**/*.csproj'
    arguments: '--configuration Release'

- task: WhiteSource Bolt@2 # Scans for open source vulnerabilities
  displayName: 'Run WhiteSource Bolt Scan'
  inputs:
    # No explicit inputs usually needed; auto-detects dependencies.
    # Configure service connection if applicable.
