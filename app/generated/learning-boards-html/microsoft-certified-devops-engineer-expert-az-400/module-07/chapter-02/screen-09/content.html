Self-Hosted Security

Implementing Secure Practices for Agents

Protecting your self-managed execution environments.

Network Isolation: Place agents in a dedicated subnet within a VNet with strict Network Security Group (NSG) rules.

Restrict Connections: Only allow necessary outbound connections and strictly restrict all inbound connections to the agent.

Credential Management: Ensure the agent's user account has only the minimum necessary permissions on the host machine.

Key Takeaway

Self-hosted agents offer control but demand rigorous security measures, especially concerning network access and the agent's operating identity.
