Key Concepts

Essential ideas from this chapter

Service Connection

A secure way for Azure DevOps pipelines to connect to external services using encapsulated authentication details.

Principle of Least Privilege

The security principle of granting only the minimum permissions necessary to perform intended functions.

Microsoft-hosted Agents

Agents managed and hosted by Microsoft, offering convenience and a clean environment per job.

Summary Takeaway

Securing pipelines starts with understanding how connections work, applying least privilege, and choosing the right agent environment.
