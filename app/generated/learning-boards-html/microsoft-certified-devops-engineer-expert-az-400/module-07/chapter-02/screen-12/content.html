Dynamic Secret Retrieval with Key Vault

Fetching secrets at runtime for enhanced security.

Key Vault Integration: Use Azure Key Vault for centralized, highly secure storage of secrets, keys, and certificates.

Runtime Retrieval: Secrets are fetched dynamically at runtime, never stored in plain text in pipeline definitions or source code.

Secure Handling: Fetched secrets are treated as secure variables, masked in logs, but still require careful handling to prevent accidental exposure.

Key Takeaway

Azure Key Vault integration provides a robust, centralized solution for managing and dynamically injecting secrets into pipelines, minimizing exposure risks.

YAML Example

Fetching Secrets from Key Vault

variables:
  - group: MySecretVariableGroup # Link a variable group to Key Vault secrets
  # Or fetch directly in a task
steps:
- task: AzureKeyVault@1
  inputs:
    azureSubscription: 'MyAzureServiceConnection' # Your service connection to Azure
    keyVaultName: 'MySecureKeyVault'
    secretsFilter: 'MyDatabasePassword' # Name of the secret in Key Vault
    # Optional: You can specify a prefix for the output variables
    # secretPrefix: 'KV_'
  displayName: 'Fetch secrets from Key Vault'

- script: |
    echo "The secret is: $(MyDatabasePassword)" # Access the fetched secret
    # IMPORTANT: In a real scenario, never echo secrets. Use them directly in tasks.
  displayName: 'Use the secret (example)'
  env:
    DB_PASSWORD: $(MyDatabasePassword) # Pass as environment variable to script
