Self-Hosted Security

Maintaining Agent Pool Integrity

Patching, image management, and access control for self-hosted agents.

Regular Patching

  • •Keep the operating system and all installed software on agents up-to-date with security patches.
  • •Neglecting patches leaves agents vulnerable to known exploits.
Best Practice

Automate patching processes to ensure consistent and timely updates.

Image Management & RBAC

  • •Use hardened images for VMs/containers and regularly rebuild them with latest security updates.
  • •Control who can create, manage, and use agent pools using Azure DevOps RBAC.
  • •Restrict agent pool access to authorized teams/individuals, especially for production.
Consideration

Automate image building with tools like Azure Image Builder for consistent security.

Key Takeaway

Continuous maintenance and strict access control are vital for self-hosted agents to prevent vulnerabilities and unauthorized use.
