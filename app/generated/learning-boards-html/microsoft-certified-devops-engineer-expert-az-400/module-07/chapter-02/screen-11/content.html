Protecting Pipeline Variables & Secrets

Never store sensitive information in plain text.

Critical Rule: Sensitive data (API keys, passwords) must never be stored directly in plain text within pipeline definitions (YAML).

Secure Variables: Azure DevOps provides secure variables, which are encrypted at rest and masked in logs.

Implementation: Mark variables as 'secret' in the UI or use isSecret: true in YAML definitions.

Key Takeaway

Pipeline variables holding sensitive data must be explicitly marked as secret to prevent exposure in logs and ensure encryption at rest.
