Best Practice

Interpreting Scan Results

Failing Builds on Critical Vulnerabilities

Build Docker Image

Image is built and ready for scanning.

Scan with Trivy

--exit-code 1 for critical/high severity.

Push to ACR

Only if scan succeeds (condition: succeeded()).

Pipeline Failure

continueOnError: false ensures the pipeline stops if critical vulnerabilities are found.

Shift-Left Security

Catching and fixing vulnerabilities early reduces cost and risk significantly.

Key Takeaway

Configuring your CI pipeline to fail on critical vulnerabilities detected by Trivy enforces a robust security gate, preventing insecure images from reaching production.
