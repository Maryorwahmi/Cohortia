Key Concepts: Container & Kubernetes Security

Essential Terms to Remember

Container Image Scanning

Analyzing container images for known vulnerabilities in their layers, dependencies, and configurations.

Trivy

An open-source, comprehensive vulnerability scanner for container images, file systems, and Git repositories.

Azure Container Registry (ACR)

A managed, private Docker registry service in Azure, offering integrated vulnerability scanning via Microsoft Defender for Cloud.

Summary Takeaway

Proactive container image scanning with tools like Trivy and integrated services like ACR is fundamental to detecting and mitigating vulnerabilities early in the CI/CD pipeline.
