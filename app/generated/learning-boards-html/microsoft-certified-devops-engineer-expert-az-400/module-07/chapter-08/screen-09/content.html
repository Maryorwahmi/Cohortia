Key Concepts

Pod Security Standards & Network Policies

Enforcing Least Privilege in Kubernetes

Pod Security Standards (PSS)

PSS define a set of security configurations for pods, preventing them from running with excessive privileges or accessing sensitive host resources. They enforce security at the pod level.

  • Restricts capabilities like running as root.
  • Prevents access to host namespaces.
  • Ensures secure volume mounts.
Example

A PSS policy can prevent a pod from using hostPath volumes, mitigating risks of host filesystem access.

Kubernetes Network Policies

Network Policies define rules for how pods communicate with each other and external endpoints, enforcing a 'least privilege' network access model.

  • Controls ingress and egress traffic.
  • Isolates sensitive workloads.
  • Prevents unauthorized lateral movement.
Example

A network policy can restrict a database pod to only accept connections from specific application pods.

Key Takeaway

PSS and Network Policies are critical for enforcing granular security controls in Kubernetes, limiting pod capabilities and controlling network flow to achieve a strong least-privilege posture.
