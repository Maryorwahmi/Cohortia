DAST Automation with GitHub Actions

Setting up an OWASP ZAP Baseline Scan workflow.

# .github/workflows/dast.yml for GitHub Actions
name: DAST Scan with OWASP ZAP

on:
  workflow_dispatch: # Manual trigger
  release:
    types: [published] # Trigger on release publication

jobs:
  dast:
    runs-on: ubuntu-latest
    steps:
      - name: Deploy Application (Placeholder)
        run: |
          echo "Simulating deployment to a test environment..."
          echo "Application URL: http://my-test-webapp.azurewebsites.net"
        env:
          APP_URL: 'http://my-test-webapp.azurewebsites.net'

      - name: Run OWASP ZAP Baseline Scan
        uses: docker://owasp/zap2docker-stable
        with:
          args: zap-baseline.py -t ${{ env.APP_URL }} -g zap-baseline-report.html -r zap-baseline-report.xml
        continue-on-error: true

      - name: Upload ZAP Baseline Report
        uses: actions/upload-artifact@v3
        with:
          name: zap-baseline-report
          path: zap-baseline-report.html
Workflow Triggers & Environment

The workflow is triggered manually or on release publication, running on an Ubuntu runner. The APP_URL environment variable defines the target for the DAST scan.

ZAP Docker Action

The docker://owasp/zap2docker-stable action executes the ZAP baseline scan, with arguments specifying the target and report formats.

Artifact Upload

The actions/upload-artifact@v3 action publishes the generated HTML report, making it available for review directly within GitHub.

Key Takeaway

GitHub Actions can automate OWASP ZAP baseline scans using Docker actions, providing continuous security feedback and publishing reports as artifacts for easy access and review.
