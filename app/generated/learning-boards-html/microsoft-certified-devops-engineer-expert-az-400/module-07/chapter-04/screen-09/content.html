Deep Dive: ZAP Full Scan and Report Evaluation

Extending DAST for comprehensive vulnerability detection.

# For a more thorough Active Scan, which takes longer:
- task: Docker@2
  displayName: 'Run OWASP ZAP Full Scan (Active Scan)'
  inputs:
    containerRegistry: 'dockerhub'
    command: 'run'
    container: 'owasp/zap2docker-stable'
    arguments: '-cmd zap-full-scan.py -t $(WebAppUrl) -g $(Build.ArtifactStagingDirectory)/zap-full-report.html -r $(Build.ArtifactStagingDirectory)/zap-full-report.xml -P 8080'
  continueOnError: true

- task: PublishBuildArtifacts@1
  displayName: 'Publish ZAP Full Scan Report'
  inputs:
    pathToPublish: '$(Build.ArtifactStagingDirectory)/zap-full-report.html'
    artifactName: 'ZAPFullReport'
    artifactType: 'Container'

# Optional: Add a custom script to parse the XML report and fail the build if critical issues are found

  displayName: 'Evaluate ZAP Report for Critical Issues'

Full Scan Execution

The zap-full-scan.py script performs a more extensive active scan, identifying a wider range of vulnerabilities compared to a baseline scan.

Report Evaluation Script

A custom script can parse the generated XML report to check for specific alert types (e.g., 'High' risk) and fail the pipeline if critical issues are found.

Quality Gate Implementation

By conditionally failing the pipeline based on report findings, you establish a security quality gate, preventing insecure applications from progressing.

Key Takeaway

Implementing OWASP ZAP full scans in Azure Pipelines, combined with a report evaluation script, creates a robust security quality gate that can automatically halt deployments with critical vulnerabilities.
