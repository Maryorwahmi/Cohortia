Core Principle 3

Run Experiments in Production

Uncovering Real-World Dependencies and Behaviors

Real-World Insights

The most valuable insights come from experiments conducted in production environments, where real traffic, data, and dependencies exist.

  • •Non-production environments rarely replicate production complexity.
  • •Uncovers hidden dependencies and race conditions.
  • •Requires extreme caution and robust safety mechanisms.
Why Production Matters

Unique Production Characteristics

  • •**Real Traffic Patterns:** Actual user load and behavior.
  • •**Complex Data:** Live data sets and their interactions.
  • •**External Dependencies:** Integrations with third-party services.
  • •**Monitoring Fidelity:** Validation of actual alerting and observability.
Key Takeaway

While risky, production experiments provide unparalleled insights into system resilience, revealing vulnerabilities that only manifest under real-world conditions.
