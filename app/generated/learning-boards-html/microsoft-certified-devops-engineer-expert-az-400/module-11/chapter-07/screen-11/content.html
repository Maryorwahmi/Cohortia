SAST & SCA in CI/CD Pipelines

Catching code and dependency vulnerabilities early in the build process.

SAST (Static Analysis)

Analyzes source code for vulnerabilities (e.g., SQL injection, XSS) without execution. Tools: SonarQube, Microsoft Security Code Analysis.

SCA (Software Composition Analysis)

Identifies known vulnerabilities in open-source components and libraries. Tools: WhiteSource, Mend, Trivy.

Key Takeaway

Integrating SAST and SCA as automated gates in your CI pipeline provides immediate security feedback, enabling developers to fix issues proactively and preventing vulnerable code from progressing.

Conceptual Azure DevOps YAML for SAST/SCA
stages:- stage: BuildAndScan  displayName: 'Build and Security Scan'  jobs:  - job: SecurityChecks    displayName: 'Code and Dependency Scans'    pool:      vmImage: 'ubuntu-latest'    steps:    - checkout: self    # SAST Scan (example with SonarQube)    - task: SonarQubePrepare@5      displayName: 'Prepare SonarQube Analysis'      inputs:        SonarQube: 'MySonarQubeServiceConnection'        scannerMode: 'CLI'        configMode: 'manual'        cliProjectKey: 'my-webapp'        cliProjectName: 'My Web App'    - task: DotNetCoreCLI@2      displayName: 'Build Application'      inputs:        command: 'build'        projects: '**/*.csproj'    - task: SonarQubeAnalyze@5      displayName: 'Run SonarQube Analysis'    - task: SonarQubePublish@5      displayName: 'Publish SonarQube Results'    # SCA Scan (example with Trivy for .NET dependencies)    - script: |        curl -sfL https://raw.githubusercontent.com/aquasecurity/trivy/main/contrib/install.sh | sh -s -- -b /usr/local/bin        trivy fs --format json --output trivy-results.json .      displayName: 'Run Trivy SCA Scan'      continueOnError: true # Allow build to continue but log findings    - task: PublishBuildArtifacts@1      displayName: 'Publish Trivy Results'      inputs:        pathToPublish: 'trivy-results.json'        artifactName: 'TrivyScanResults'
This YAML snippet shows how SonarQube (SAST) and Trivy (SCA) can be integrated into an Azure DevOps pipeline.
