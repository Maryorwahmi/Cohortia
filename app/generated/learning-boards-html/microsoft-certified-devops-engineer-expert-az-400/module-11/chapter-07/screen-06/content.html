Implementing Azure Policy: Defining Rules

Crafting JSON definitions to specify allowed or denied resource configurations.

Policy Definition Structure

Azure Policy definitions are JSON objects with an if block (conditions) and a then block (effect).

Common Use Cases
  • Enforce specific VM sizes.
  • Require HTTPS for web apps.
  • Mandate encryption for storage accounts.
  • Control resource locations.
Pro Tip

Start with Audit effects to understand compliance impact before switching to Deny for stricter enforcement.

Conceptual Azure Policy Definition
{  "if": {    "allOf": [      {        "field": "type",        "equals": "Microsoft.Storage/storageAccounts"      },      {        "field": "Microsoft.Storage/storageAccounts/supportsHttpsTrafficOnly",        "notEquals": true      }    ]  },  "then": {    "effect": "Deny"  }}
This policy denies creation of Storage Accounts if HTTPS is not enforced.
