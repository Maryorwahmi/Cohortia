Practical Example

Enforcing HTTPS for Storage Accounts

A real-world Azure Policy to prevent insecure storage configurations.

Policy Goal

Ensure all Azure Storage Accounts require HTTPS for secure data transfer, preventing unencrypted access.

How it Works

The policy checks the supportsHttpsTrafficOnly property. If it's not true, the Deny effect blocks the resource creation.

Impact

This policy proactively prevents a common security misconfiguration, enhancing the overall security posture of your storage resources.

Azure Policy: Deny Storage Accounts without HTTPS
{  "if": {    "allOf": [      {        "field": "type",        "equals": "Microsoft.Storage/storageAccounts"      },      {        "field": "Microsoft.Storage/storageAccounts/supportsHttpsTrafficOnly",        "notEquals": true      }    ]  },  "then": {    "effect": "Deny"  }}
This JSON snippet defines a policy that will block the deployment of any new storage account that does not enforce HTTPS traffic.
