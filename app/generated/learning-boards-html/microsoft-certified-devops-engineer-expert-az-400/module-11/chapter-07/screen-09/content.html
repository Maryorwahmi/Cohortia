Practical Example

Auditing VM Managed Disk Usage

Identifying non-compliant virtual machines with Azure Policy.

Policy Goal

Identify Azure Virtual Machines that are not utilizing managed disks, which are a more secure and reliable storage option.

How it Works

The policy checks for the absence of a managed disk ID in the VM's storage profile. If not found, the Audit effect flags the VM as non-compliant.

Benefit of Audit Effect

Allows you to discover existing non-compliant resources without immediately blocking deployments, providing valuable insights for planned remediation.

Azure Policy: Audit VMs without Managed Disks
{  "if": {    "allOf": [      {        "field": "type",        "equals": "Microsoft.Compute/virtualMachines"      },      {        "field": "Microsoft.Compute/virtualMachines/storageProfile.osDisk.managedDisk.id",        "exists": "false"      }    ]  },  "then": {    "effect": "Audit"  }}
This JSON snippet defines a policy that will audit (report) any virtual machine that is not configured to use a managed disk for its OS.
