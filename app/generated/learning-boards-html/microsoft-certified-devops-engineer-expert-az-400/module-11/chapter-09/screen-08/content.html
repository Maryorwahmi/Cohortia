Process Flow

Initiating the ALM Workflow: Development to Unmanaged Export

Building components and preparing for source control

01

Development

Developers build components within a Power Platform development environment, all contained within a managed Solution.

Key Detail

All work is done inside a Power Platform Solution to ensure logical grouping.

02

Export Solution (Unmanaged)

The Solution is exported from the development environment as an 'unmanaged' solution, containing raw source files.

Key Detail

Unmanaged solutions are editable and ideal for source control integration.

Key Takeaway

The initial ALM steps involve structured development within a Solution and exporting it as unmanaged to prepare for version control.
