Establishing Source Control and Building Managed Solutions

Transforming unmanaged artifacts into deployable units

03

Source Control

Unpacked unmanaged solution files are committed to a Git repository (Azure Repos/GitHub) as the 'source of truth'.

Key Detail

Power Platform CLI or Build Tools unpacks proprietary formats into readable files.

04

Build & Pack Solution (Managed)

An Azure DevOps pipeline packs unpacked files into a 'managed' solution, running Solution Checker analysis.

Key Detail

Managed solutions are designed for production, preventing further customization in target environments.

Key Takeaway

Source control for LCNC involves unpacking solutions to Git, followed by a CI pipeline to pack them into managed solutions with static analysis.
