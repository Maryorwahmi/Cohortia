Azure Implementation

Canary with Azure Traffic Management

Configuring routing rules for gradual traffic distribution.

Azure Front Door

Global entry point with advanced routing rules for percentage-based traffic distribution.

Azure Application Gateway

Web traffic load balancer capable of configuring percentage-based routing to backend pools.

Service Meshes (e.g., Istio)

For Kubernetes, provide fine-grained traffic control based on headers, user segments, or percentages.

Conceptual Flow

Deploy new version to a 'canary' backend. Configure Front Door/Application Gateway to send 5% of traffic to 'canary', 95% to 'production'. Monitor, then gradually increase 'canary' traffic.

App Service Limitation

While App Service slots have 'Swap with Preview', true percentage-based Canary routing often requires an external traffic manager like Front Door or Application Gateway.

Key Takeaway

Azure Front Door and Application Gateway are key services for implementing Canary releases, enabling sophisticated, percentage-based traffic routing to control the gradual rollout of new features.
