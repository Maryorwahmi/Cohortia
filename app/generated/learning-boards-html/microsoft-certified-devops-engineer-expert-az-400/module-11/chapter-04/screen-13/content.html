Azure DevOps Pipeline: Model Deployment

Automating model deployment to managed endpoints

Dependent Deployment Stage

The deployment stage is configured to run only after the model training and registration stage has successfully completed.

Managed Endpoint Deployment

Uses Azure ML CLI to deploy the registered model to a scalable and secure Azure ML Managed Online Endpoint for real-time inference.

Key Takeaway

This CD pipeline stage automates the deployment of validated models to production, supporting controlled rollouts and manual verification for safety.

Conceptual Azure DevOps YAML: Deployment Stage
- stage: DeployModel
  displayName: 'Deploy ML Model'
  dependsOn: TrainAndRegisterModel
  jobs:
  - deployment: Deploy
    displayName: 'Deploy to ACI/AKS'
    environment: 'ModelDeployment'
    pool:
      vmImage: 'ubuntu-latest'
    strategy:
      runOnce:
        deploy:
          steps:
          - task: AzureCLI@2
            displayName: 'Deploy Model to Managed Endpoint'
            inputs:
              azureSubscription: '$(azureMLSubscription)'
              scriptType: 'bash'
              scriptLocation: 'inlineScript'
              inlineScript: |
                MODEL_NAME=$(registeredModelName)
                MODEL_VERSION=$(registeredModelVersion)
                ENDPOINT_NAME="my-ml-endpoint"
                DEPLOYMENT_NAME="v$(MODEL_VERSION)"

                az ml online-endpoint create --name $ENDPOINT_NAME --resource-group $(azureMLResourceGroup) --workspace $(azureMLWorkspace) --query name -o tsv || true
                az ml online-deployment create --name $DEPLOYMENT_NAME --endpoint $ENDPOINT_NAME \
                  --model $MODEL_NAME:$MODEL_VERSION --environment azureml:AzureML-sklearn-1.0-ubuntu20.04-py38-cpu:1 \
                  --instance-type Standard_DS3_v2 --instance-count 1 \
                  --resource-group $(azureMLResourceGroup) --workspace $(azureMLWorkspace)

                az ml online-endpoint update --name $ENDPOINT_NAME --traffic "$DEPLOYMENT_NAME=100" \
                  --resource-group $(azureMLResourceGroup) --workspace $(azureMLWorkspace)

          - task: ManualValidation@0
            displayName: 'Verify Model Deployment'
            inputs:
              instructions: 'Verify the model endpoint is accessible and returning correct predictions. Review monitoring dashboards for initial performance.'
