The MLOps Workflow: Data to Validation

The initial steps of an integrated ML pipeline

Data Ingestion & Preparation

Data is pulled from sources, cleaned, transformed, and potentially versioned, forming the foundation for model training.

Model Training

Prepared data is used to train the ML model, often involving experiments and hyperparameter tuning, with Azure ML tracking these runs.

Model Evaluation & Validation

The trained model is evaluated against a test dataset, calculating performance metrics and ensuring it meets predefined thresholds.

Key Takeaway

The MLOps workflow starts with robust data preparation and versioning, followed by iterative training and rigorous evaluation to ensure model quality.

MLOps Workflow Stages (Part 1)
1

Data Ingestion: Collect data from various sources.

2

Data Preparation: Clean, transform, and version data.

3

4
