Deploying a Cost-Optimized VM with Bicep

Practical Bicep snippet for efficient Azure Virtual Machine deployment.

// Example Bicep template snippet for a cost-optimized VM
resource vm 'Microsoft.Compute/virtualMachines@2023-03-01' = {
  name: 'myCostOptimizedVM'
  location: resourceGroup().location
  properties: {
    hardwareProfile: {
      vmSize: 'Standard_B2s' // Using a B-series VM for burstable workloads, often cost-effective
    }
    storageProfile: {
      imageReference: {
        publisher: 'MicrosoftWindowsServer'
        offer: 'WindowsServer'
        sku: '2019-Datacenter'
        version: 'latest'
      }
      osDisk: {
        createOption: 'FromImage'
        managedDisk: {
          storageAccountType: 'Standard_LRS' // Standard HDD for cost savings on OS disk
        }
      }
      dataDisks: [
        {
          lun: 0
          createOption: 'Empty'
          diskSizeGB: 128
          managedDisk: {
            storageAccountType: 'Standard_LRS' // Standard HDD for data disk
          }
        }
      ]
    }
    osProfile: {
      computerName: 'myCostOptimizedVM'
      adminUsername: 'azureuser'
      adminPassword: 'Password123!' // In real scenarios, use Key Vault or managed identities
    }
    networkProfile: {
      networkInterfaces: [
        {
          id: nic.id
        }
      ]
    }
  }
}

Cost-Saving Elements Explained

VM Size: Standard_B2s

B-series VMs are burstable, offering a cost-effective solution for workloads that don't require consistent high CPU performance, ideal for dev/test environments.

Storage Account Type: Standard_LRS

Utilizing Standard HDD (Locally Redundant Storage) for OS and data disks significantly reduces storage costs compared to SSDs, suitable for non-performance-critical data.

Pro Tip

Always integrate with Azure Key Vault for secure password management in production deployments, rather than hardcoding credentials.

Key Takeaway

Bicep allows you to define infrastructure with cost-optimized configurations, making financial accountability an inherent part of your deployment process.
