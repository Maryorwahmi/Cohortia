Federated DevOps in Azure DevOps

Organizations, Projects, and Shared Resources

Azure DevOps Organizations

Top-level containers for centralized user management, security, and shared extensions across multiple projects.

Azure DevOps Projects

Provide logical isolation for repositories, pipelines, and work items, empowering individual product teams.

Shared Templates & Variable Groups

Central teams create reusable YAML templates and variable groups to ensure consistency and reduce duplication across projects.

Shared Service Connections

Central teams manage secure connections to Azure, granting product teams access with least privilege for controlled deployments.

Concrete Example

A large financial institution uses a single Azure DevOps organization for all its business units, with separate projects for each application team, sharing common build templates and Azure service connections.

Key Takeaway

Azure DevOps provides the structural components to effectively implement and manage a federated DevOps model at enterprise scale.
