Module 3 › Chapter 3.3 › Common Mistakes
Indentation errors
YAML is indentation-sensitive. Always align keys under the correct parent and avoid tabs. A quick way to spot errors is ansible-lint or an editor with YAML support.
# bad indentation example
vars:
 nginx_port: 8080
app_version: 1.2.3
Jinja typos and scope
A misspelled variable renders as a literal or errors. Use debug to print the variable and confirm the expected value and scope.
- name: Debug user variable
  ansible.builtin.debug:
    msg: "user is {{ new_username }}"
Quick check
Run the setup module to inspect facts before writing conditionals against them.
