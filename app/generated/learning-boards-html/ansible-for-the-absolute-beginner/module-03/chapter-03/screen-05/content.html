Module 3 › Chapter 3.3 › Play vs Group vs Host
Three scopes compared
Play variables
Defined in a play using vars. Accessible to tasks in that play. Use for values consistent across the play.
Group variables
Defined in group_vars or inventory. Apply to all hosts in the group. Great for shared configuration like ports.
Host variables
Defined in host_vars or inline in inventory. Specific to one host. Use for unique connection strings or overrides.
Precedence tip
More specific definitions win. If a host var and a group var both define the same name, the host var takes effect.
Example inventory
# inventory.ini
[webservers]
webserver1.example.com app_env=dev db_host=devdb.example.com
webserver2.example.com app_env=prod db_host=proddb.example.com

# group_vars/webservers.yml
---
http_port: 80
max_clients: 150
Common mistake
Placing a value in group_vars when only one host needs it leads to accidental overrides; prefer host_vars for unique cases.
