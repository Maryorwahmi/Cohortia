Module 3 › Chapter 3.3 › Practical tips
Naming and scope
  • Pick descriptive names: default_user_shell, app_version, http_port.
  • Use group_vars for common defaults and reserve host_vars for true exceptions.
  • Avoid deeply nested or confusing Jinja expressions repeated across tasks.
Testing and debugging
Small test runs
Run against a single target to confirm variable resolution before broad rollout.
Temporary debug
Insert ansible.builtin.debug tasks to print variables and facts while developing.
Key Takeaway

Clear names, proper scope, and small tests save time and reduce errors when using variables and facts.
