Module 3 › Chapter 3.3 › Jinja2 Templating
Code example
- name: Install {{ package_name }}
  ansible.builtin.package:
    name: "{{ package_name }}"
    state: present
Notes
  • Always quote templated values in module arguments to avoid parsing surprises.
  • Keep expressions simple; use conditional expressions where helpful to choose values based on facts.
  • Spell variable names consistently; typos become literal strings or errors.
Example: conditional package selection
- name: Install appropriate web server package
  ansible.builtin.package:
    name: "{{ 'httpd' if ansible_os_family == 'RedHat' else 'nginx' }}"
    state: present
Misconception
Using long Jinja expressions directly in many tasks makes playbooks hard to read. Prefer small helper variables for repeated logic.
Key Takeaway

Templating connects variable values and facts to tasks; keep it readable and test it on sample hosts.
