Module 3 › Chapter 3.3 › Ansible Facts
What setup returns
# run locally to inspect facts
ansible webservers -m setup -i inventory.ini

# common facts you may use
ansible_os_family
ansible_distribution
ansible_hostname
ansible_default_ipv4.address
Practical tip
Run the setup module once when writing playbooks to learn which facts exist on your managed hosts and their exact names.
Using facts in conditionals
- name: Install Nginx on Debian-based systems
  ansible.builtin.package:
    name: nginx
    state: present
  when: ansible_os_family == "Debian"

- name: Install Apache on RedHat-based systems
  ansible.builtin.package:
    name: httpd
    state: present
  when: ansible_os_family == "RedHat"
Gotcha
Some minimal or containerized hosts may not provide all facts. Confirm gather_facts isn't disabled if you expect facts to be present.
