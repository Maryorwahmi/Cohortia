Variables and Facts
Make playbooks flexible, conditional, and reusable across environments.

Hardcoding package names, paths, or usernames ties a playbook to one environment. Variables let you centralize those values.

Facts are automatically gathered host data. Use them to make conditional choices like installing different packages per operating system family.

In this lesson
Understand variable scopes, use Jinja2 templating, read facts with the setup module, and apply set_fact.
