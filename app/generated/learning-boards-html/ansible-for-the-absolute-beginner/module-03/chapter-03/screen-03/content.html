Practical verification steps
Edit group_vars
Change default_user_shell then run the playbook to confirm the created user's shell matches the variable.
Run ansible setup
Use the setup module to inspect ansible_os_family and verify conditional tasks run as expected.
Check host-specific values
Place a host variable in host_vars and confirm it overrides the group value for that host.
Confirm conditional directories
Verify that /home/ansibleuser/projects exists only when ansible_os_family indicates Debian.
Quick check
After changes, re-run the playbook with a small target group to see behavior before rolling out widely.
Common pitfall
Forgetting to clear cached facts or not understanding variable precedence can make verification confusing.
