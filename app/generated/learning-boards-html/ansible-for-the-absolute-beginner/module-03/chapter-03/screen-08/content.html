Module 3 › Chapter 3.3 › set_fact
Example: set a custom fact
- name: Set a custom fact for application environment
  ansible.builtin.set_fact:
    app_environment: "production"
  when: inventory_hostname == "prodserver.example.com"

- name: Display custom fact
  ansible.builtin.debug:
    msg: "The application environment is {{ app_environment }}"
Key points
  • set_fact values are host-local and available for the remainder of the play run.
  • They are ideal for storing runtime calculations or decisions you want to reuse.
  • They are not persisted to the host after the playbook completes unless you explicitly write them out.
Common uses
Set runtime flags, compute files or paths, or capture results of a discovery task so later steps behave consistently.
Key Takeaway

Use set_fact to store decisions during a run and keep later tasks simple and deterministic.
