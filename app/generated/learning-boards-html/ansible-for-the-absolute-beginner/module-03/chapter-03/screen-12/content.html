Variables
Placeholders for values that make playbooks reusable and easier to change.
Jinja2 Templating
Use double-curly expressions to insert variables and simple expressions into tasks.
Ansible Facts
Automatically gathered host data that enable conditional logic and adaptation.
Summary takeaway
