CLIENT LIST

Use CLIENT LIST to inspect connection metadata and buffers to find slow or misbehaving clients.

id=3 addr=10.0.0.5:6379 fd=7 name= age=123 idle=5 flags=N db=0 sub=0 psubs=0 multi=-1 qbuf=0 qbuf-free=0 obl=0 oll=0 omem=0 events=r cmd=get
Look for large qbuf, idle times, or repeated expensive commands from the same client id.
MONITOR vs SLOWLOG
  • MONITOR streams every command in real-time — high overhead when left running.
  • SLOWLOG records commands above a threshold — safer for production troubleshooting.
Common mistake
Leaving MONITOR active in production can magnify performance problems; prefer SLOWLOG for ongoing slow command detection.
