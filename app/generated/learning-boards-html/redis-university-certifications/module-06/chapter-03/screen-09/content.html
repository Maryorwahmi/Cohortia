Module 6 › Chapter 6.3 › Memory Usage
Command
MEMORY USAGE mybigkey

Use this to measure an individual key's footprint and compare it to the server's overall memory allocation.

If a single key accounts for a large fraction of used_memory, consider trimming or sharding that value.
Investigation steps
  1. Run INFO memory and note used_memory_human.
  2. Sample candidate keys with MEMORY USAGE.
  3. For heavy keys, inspect type and consider structural changes or archiving.
Key Takeaway
Large keys are frequent causes of memory spikes; measuring them directly allows targeted remediation.
