Instructions
  1. redis-cli
  2. INFO
  3. INFO memory; record used_memory_human and mem_fragmentation_ratio
  4. INFO stats; record instantaneous_ops_per_sec and hits/misses
  5. CONFIG SET slowlog-log-slower-than 100; CONFIG SET slowlog-max-len 100
  6. DEBUG SLEEP 0.1 or simulate heavy command
  7. SLOWLOG GET; LATENCY DOCTOR
Guided questions
  • Is mem_fragmentation_ratio high and does it justify a restart?
  • Are slowlog entries frequent or isolated to a single command or client?
  • What alerts would you configure based on these observations?
Key Takeaway
This activity trains you to combine snapshots and recorded events to form an actionable remediation plan.
