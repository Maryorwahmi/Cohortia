Module 6 › Chapter 6.3 › SLOWLOG & LATENCY
Process
# configure CONFIG SET slowlog-log-slower-than 100 CONFIG SET slowlog-max-len 100
# simulate slow DEBUG SLEEP 0.1 KEYS *
# inspect SLOWLOG GET LATENCY DOCTOR
How to interpret
  • SLOWLOG entries point to exact commands and execution timestamps.
  • LATENCY DOCTOR summarizes recurring latency events and recommends checks.
  • Always correlate with INFO stats and CPU values to understand whether latency is load-driven.
Key Takeaway

SLOWLOG finds slow commands; LATENCY DOCTOR helps interpret latency patterns. Use both while correlating with stats.
