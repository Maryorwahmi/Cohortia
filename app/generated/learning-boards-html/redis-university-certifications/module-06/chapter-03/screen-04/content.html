Module 6 › Chapter 6.3 › INFO Command
Core Concept

The INFO command

INFO returns categorized server metrics you can use for quick health checks and focused diagnostics.

redis-cli INFO redis-cli INFO memory redis-cli INFO stats
When to run
After alerts, before deployments, or during manual health checks.
Follow-up
Use MEMORY USAGE or CLIENT LIST based on what INFO reveals.
Sections to know
  • Memory — used_memory, used_memory_rss, mem_fragmentation_ratio, maxmemory.
  • Clients — connected_clients and buffer sizes.
  • Stats — total_commands_processed and keyspace hits/misses.
  • Persistence — rdb and AOF times and pending I/O.
Key Takeaway
INFO is the fastest way to form a hypothesis about Redis health; then confirm with targeted commands.
