Module 6 › Chapter 6.3 › Memory Metrics
Definition

used_memory vs RSS vs fragmentation

Compare internal allocations with OS-reported resident size and watch the fragmentation ratio for signs of wasted memory.

used_memory: Redis reported allocation used_memory_rss: OS resident set size mem_fragmentation_ratio: used_memory_rss / used_memory
Practical signals
  • If fragmentation ratio > 1.5, watch closely; > 2.0 often means fragmentation-driven wasted RAM.
  • Check maxmemory to know your configured limit and plan eviction or scaling before hitting it.
  • Use MEMORY USAGE on large keys to find producers of high memory usage.
Key Takeaway

High fragmentation increases RSS without reflecting useful data size. Plan restarts and key audits to reclaim memory efficiently.
