Core Concept

What are Redis Modules?

Dynamic libraries that extend Redis's core capabilities beyond simple key-value pairs.

Key Characteristics

  • Dynamic Libraries: Loadable at runtime, adding new commands and data structures.
  • Extensibility: Transforms Redis into a versatile data platform without bloating the core.
  • Specialized Functionality: Enables use cases like full-text search, JSON document storage, and graph databases.
  • Performance: Maintains Redis's speed and efficiency for complex operations.
Key Takeaway

Redis Modules allow you to tailor Redis to specific application needs, making it a powerful multi-model database.

Popular Redis Modules

RediSearch

Full-text search, secondary indexing, aggregations.

RedisJSON

Native JSON document storage and manipulation.

RedisTimeSeries

Optimized storage and querying for time-series data.

RedisGraph

Graph database capabilities using Cypher queries.
