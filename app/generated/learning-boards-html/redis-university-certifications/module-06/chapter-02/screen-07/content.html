Defining a RediSearch Index Schema

Structuring your data with field types for efficient and targeted search operations.

Key Field Types

  • TextField: For full-text search on general string content (e.g., descriptions). Supports weighting.
  • TagField: For exact matches and filtering on categorical data (e.g., categories, tags).
  • NumericField: For numerical values, enabling range queries and filtering (e.g., prices, quantities).
Key Takeaway

A well-designed schema is fundamental for RediSearch to perform fast, relevant, and accurate searches.

Python Example: Schema Definition

from redis.commands.search.field import TagField, TextField, NumericField

# Define fields for our product index
schema = (
    TextField("product_name", weight=5.0), # Higher weight for name
    TextField("description"),
    TagField("category"),
    NumericField("price"),
)

# Create the index (assuming search_client is initialized)
search_client.create_index(schema)

Why Schema Matters

The schema guides RediSearch on how to parse, store, and query your data. Incorrect field types can lead to poor search performance or inability to perform certain queries, such as range filters on text fields.
