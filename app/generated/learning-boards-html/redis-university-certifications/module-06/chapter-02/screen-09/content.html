Executing Searches with RediSearch

Performing basic text searches and applying filters for precise results.

Types of RediSearch Queries

  • Basic Text Search: Search for keywords across `TextField`s.
  • Filtered Search: Combine text search with conditions on `TagField`s and `NumericField`s.
  • Range Queries: Filter numeric fields within a specified range (e.g., prices `[0 100]`).
Key Takeaway

RediSearch's query language allows for highly specific and efficient data retrieval by combining full-text and structured filters.

Python Example: Performing Searches

from redis.commands.search.query import Query

# Assuming search_client is initialized

# Basic text search
print("--- Searching for 'headphones' ---")
res = search_client.search(Query("headphones"))
for doc in res.docs:
    print(f"ID: {doc.id}, Name: {doc.product_name}")

# Search with filters
print("--- Searching for 'smart' in 'Electronics' with price < 100 ---")
res = search_client.search(Query("smart @category:{Electronics} @price:[0 100]"))
for doc in res.docs:
    print(f"ID: {doc.id}, Name: {doc.product_name}, Price: {doc.price}")

Query Syntax Tip

Use @field:{value} for tag fields and @field:[min max] for numeric range queries. Combining these with keywords provides powerful filtering.
