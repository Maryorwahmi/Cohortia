Adding Documents to the RediSearch Index

Storing data as Redis Hashes for automatic indexing by RediSearch.

How Indexing Works

  • Store as Hashes: Each document is stored as a standard Redis Hash.
  • Automatic Indexing: RediSearch automatically indexes the fields of these Hashes based on your defined schema.
  • No Duplication: Data remains in its native Redis Hash format; RediSearch builds a secondary index.
Key Takeaway

RediSearch seamlessly integrates with existing Redis data, indexing Hashes to provide search capabilities without requiring separate data storage.

Python Example: Adding Products

import redis

r = redis.Redis(host='localhost', port=6379, db=0)

products = [
    {"id": "prod:1", "product_name": "Wireless Headphones", "description": "High-quality sound.", "category": "Electronics", "price": 79.99},
    {"id": "prod:2", "product_name": "Ergonomic Chair", "description": "Adjustable lumbar support.", "category": "Furniture", "price": 249.00},
]

for product in products:
    r.hset(product["id"], mapping=product)
    # RediSearch automatically indexes these hash fields

Common Misconception

Some might think RediSearch requires a separate data store. In reality, it builds an index over your existing Redis data, specifically Redis Hashes, making it highly integrated and efficient.
