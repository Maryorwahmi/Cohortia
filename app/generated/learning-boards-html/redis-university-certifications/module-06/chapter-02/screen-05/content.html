Loading Redis Modules

Integrating modules into your Redis server for extended functionality.

Module Loading Methods

1. `redis.conf` Directive (Recommended)

Add loadmodule /path/to/module.so to your configuration file for persistent loading on startup.

2. `MODULE LOAD` Command (Temporary)

Use MODULE LOAD /path/to/module.so in CLI for runtime loading; module is lost on restart.

Key Takeaway

Always use the loadmodule directive in redis.conf for production environments to ensure modules are loaded reliably.

Example: `redis.conf`

# redis.conf
# ... other configurations ...

# Load RediSearch module
loadmodule /usr/lib/redis/modules/redisearch.so

# Load RedisJSON module
loadmodule /usr/lib/redis/modules/rejson.so

# ...

Module Command Prefixes

  • RediSearch: Commands start with FT. (e.g., FT.CREATE, FT.SEARCH)
  • RedisJSON: Commands start with JSON. (e.g., JSON.SET, JSON.GET)
  • RedisGraph: Commands start with GRAPH. (e.g., GRAPH.QUERY)
