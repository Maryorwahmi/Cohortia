Module 6 › Chapter 6.5 › TLS & ACLs
TLS protects data in transit
Use TLS for any traffic crossing untrusted networks.
Enable TLS on servers and configure clients to connect via TLS. Avoid mixing encrypted and unencrypted endpoints for the same keyspaces.
ACL example (grant limited access)
# Create a user with scoped keys and denied dangerous commands
# Using ACL SETUSER (or redis.conf equivalent)
ACL SETUSER myapp +@all -FLUSHALL -CONFIG ~mydata:* on >my_app_password
Checklist
  • Enable TLS when traffic leaves a trusted network boundary.
  • Create ACL users per application with minimum commands and key patterns.
  • Store user credentials securely and rotate them periodically.
  • Test ACLs by attempting forbidden commands with the limited user.
Key Takeaway

TLS secures the channel; ACLs control what authenticated clients may do. Use both.
