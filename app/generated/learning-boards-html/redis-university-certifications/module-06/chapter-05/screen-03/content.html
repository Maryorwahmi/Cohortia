Objective Checks

Each card below pairs a short action with why it matters and a verification step you can run locally.

Key Naming
Pattern: object:id:field. Verify with SCAN and grouping tools.
Expiration
Use SETEX. Verify TTL decreases and key disappears after expiry.
Authentication
Set requirepass and show unauthenticated connections fail.
Operational
Set maxmemory and confirm eviction behavior under load.
Lab Prep

You will edit redis.conf, restart the server, and run redis-cli tests. Keep a copy of the original config so you can revert changes.

Quick Commands
# Set a key with expiry
SETEX session:token:abc 3600 "user-data"

# Add authentication in redis.conf
requirepass myStrongRedisPassword123!

# Bind to localhost
bind 127.0.0.1

# Rename a dangerous command
rename-command FLUSHALL my_secret_flush_all
