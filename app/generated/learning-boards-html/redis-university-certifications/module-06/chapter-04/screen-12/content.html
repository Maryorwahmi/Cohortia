Module 6 › Chapter 6.4 › Terminal Lab
Run these steps
1. Verify Redis is running locally and note server metrics with INFO.
2. Run PING benchmark to get a baseline. Record RPS and latency.
3. Run SET/GET with -d 10, -d 1024, -d 10240 and compare results.
4. Run LPUSH/LPOP and HSET/HGETALL scenarios to simulate different data structures.
5. Use --latency-dist to analyze P99 and P99.9 tail values.
Starter commands
echo "--- Benchmarking PING ---"
redis-benchmark -n 100000 -c 50 -t PING

redis-benchmark -n 100000 -c 50 -t SET,GET -d 10
redis-benchmark -n 100000 -c 50 -t SET,GET -d 1024
redis-benchmark -n 100000 -c 50 -t SET,GET -d 10240

redis-benchmark -n 100000 -c 50 -t LPUSH,LPOP
redis-benchmark -n 100000 -c 50 -t HSET,HGETALL -r 1000000

redis-benchmark -n 100000 -c 50 -t SET --latency-dist
After each run, save the output to a file with the command and timestamp. Compare RPS and P99 to see which dimension changed most.
