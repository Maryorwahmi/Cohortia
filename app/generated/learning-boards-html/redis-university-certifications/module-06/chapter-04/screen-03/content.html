Practical Skills
Flags, latency distribution, safe experiments
redis-benchmark flags
-n requests, -c clients, -t command list, -d data size. Practice changing one flag at a time.
Latency distribution
Use --latency-dist to understand tail values like P99 and P99.9; these often reveal rare expensive operations.
Staging experiments
Run benchmarks in staging with similar dataset sizes and network topology to production before applying changes.
Rollback planning
Change one parameter at a time and keep a clear rollback path for configurations like appendfsync or maxmemory-policy.
