Module 6 › Chapter 6.4 › redis-benchmark Usage
Common commands
Examples to run in your terminal
# Basic benchmark: 100,000 requests, 50 clients, PING
redis-benchmark -n 100000 -c 50 -t PING

# SET/GET with 1KB data size
redis-benchmark -n 100000 -c 100 -d 1024 -t SET,GET

# LPUSH/LPOP test
redis-benchmark -n 100000 -c 50 -t LPUSH,LPOP

# Latency distribution for SET
redis-benchmark -n 100000 -c 50 -t SET --latency-dist
Best practices
  • Run in a controlled environment with similar dataset size and network topology.
  • Vary one parameter at a time: concurrency, payload size, or command mix.
  • Use --latency-dist to capture tail percentiles such as P99 and P99.9.
  • Save outputs for comparison and document the exact command used.
Key Takeaway

Use representative workloads and consistent flags so you can trust comparisons between runs.
