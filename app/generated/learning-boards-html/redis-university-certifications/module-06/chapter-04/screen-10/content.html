Module 6 › Chapter 6.4 › Data Structure Costs
Command complexity
Know whether a command grows with N and test at scale.
O(1): GET, SET, HGET on small hashes — predictable and fast.
O(N): LRANGE on long lists, SMEMBERS on large sets, or KEYS * — avoid on large datasets.
Use SCAN, HSCAN, SSCAN, ZSCAN to iterate without blocking the server.
Example and mitigation
If SMEMBERS on a set of millions blocks, replace it with SSCAN and page results, or shard the set into smaller keyed buckets so each fetch is bounded.
Key Takeaway

Avoid full-scan O(N) operations on large collections. Iterate with SCAN and model data to keep per-operation cost small.
