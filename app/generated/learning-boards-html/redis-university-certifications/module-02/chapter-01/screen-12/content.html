Activity Steps

Page counter (Strings)

# Start Redis CLI
redis-cli

# Initialize a daily counter and increment
SETEX product:123:daily_views 86400 0
INCRBY product:123:daily_views 1
GET product:123:daily_views

SETEX initializes the key with an expiration so the counter resets daily; INCRBY updates it atomically.

User profile (Hash)

HSET user:456 name "John Doe" email "john.doe@example.com" age 30 city "New York"
HGET user:456 name
HMGET user:456 email city
HSET user:456 login_count 0
HINCRBY user:456 login_count 1
HGETALL user:456
HDEL user:456 city
HGETALL user:456

Practice atomic field increments and field deletions to confirm behavior without rewriting the whole record.
