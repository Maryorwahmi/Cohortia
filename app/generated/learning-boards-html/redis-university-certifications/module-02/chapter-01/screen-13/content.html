Module 2 › Chapter 2.1 › Key Concepts
Redis String

Binary-safe value up to 512 MB, good for whole-value operations and tokens.

Atomic Operations

INCR/INCRBY and HINCRBY update values atomically to keep counters correct under concurrency.

Redis Hash

Store object fields under a single key and perform atomic field-level reads and writes.

Summary

Pick the type that matches access patterns: Strings for whole-value use, Hashes for frequently-updated fields. Use multi-key and TTL commands to improve performance and correctness.
