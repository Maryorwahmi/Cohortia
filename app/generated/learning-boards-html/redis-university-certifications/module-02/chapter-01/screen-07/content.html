Module 2 › Chapter 2.1 › Partial String Ops
Definition

Edit parts of strings and set expirations

Use APPEND to grow values, GETRANGE/SETRANGE to read or write byte ranges, and SETEX to atomically set a value with TTL.

When to use
  • Small in-place edits to large values.
  • Setting expiring values in a single atomic step.
  • Avoid frequent large rewrites to reduce memory churn.
CLI examples
APPEND log:today " - user signed in"
GETRANGE large:key 0 99
SETRANGE blob 10 "XYZ"

SETEX product:123:daily_views 86400 0

Use SETEX when you must both initialize a value and assign an expiration atomically.

Pro tip

If you find yourself doing many partial edits on the same large value, consider a different data model to reduce in-memory copying.
