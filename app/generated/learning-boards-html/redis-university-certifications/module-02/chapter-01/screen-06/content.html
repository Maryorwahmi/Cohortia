Module 2 › Chapter 2.1 › Atomic Counters
Core Concept

INCR, INCRBY, DECRBY provide atomic updates

These commands update numeric string values atomically so counters remain correct under concurrent updates.

Behavior to note
  • If the key is missing, Redis initializes it to zero before changing it.
  • Atomicity applies per-key for the increment command.
  • Use SETEX to set an expiring initial value when you need a reset interval.
Misconception

INCRBY does not group multiple keys into a single atomic transaction; it only guarantees the single-key update is atomic.

CLI demo
INCRBY homepage:views 1
GET homepage:views

SETEX product:123:daily_views 86400 0
INCRBY product:123:daily_views 1
GET product:123:daily_views

The second sequence shows initializing an expiring daily counter in one atomic command, then incrementing it safely.

Key Takeaway

Use INCR/INCRBY for safe concurrent counting; combine SETEX to create expiring counters that reset automatically.
