Field-level operations for objects

HINCRBY supports atomic numeric changes inside a hash; HSET/HGET operate on individual fields efficiently.

Best practices
  • Use HINCRBY for counters inside hashes to avoid read-modify-write races.
  • Use HMGET to fetch a small subset of fields instead of HGETALL.
  • Use HDEL to remove fields without deleting the entire object key.
CLI examples
HSET product:123 name "Widget" price "9.99" stock_quantity 100
HINCRBY product:123 stock_quantity -1
HGET product:123 name
HMGET product:123 price stock_quantity
HDEL product:123 discontinued
HGETALL product:123

These commands let you manage product attributes and change numeric fields atomically without rewriting the whole object.

Key Takeaway

Field-level commands make hashes efficient for mutable object attributes and for counters embedded in objects.
