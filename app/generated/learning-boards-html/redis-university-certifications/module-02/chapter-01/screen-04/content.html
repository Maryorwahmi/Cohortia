Module 2 › Chapter 2.1 › Redis Strings
Definition

Binary-safe values up to 512 MB

A String can hold text or binary data. Use it when the whole value is the unit of work.

Key behaviors
  • Supports SET and GET as primary commands.
  • Holds binary data and large blobs up to 512 MB.
  • Efficient for whole-value read/write patterns.
Example

Store a theme flag or an authentication token as a String for fast reads and simple updates.

Common mistake

Storing deeply nested, frequently-updated objects as a single String causes expensive rewrites and memory churn.

Concrete scenario
SET user:token:1234 "eyJhbGci..."
GET user:token:1234

A secure token fits well as a string and is read/written as a single unit.

Key Takeaway

Choose Strings when you perform whole-value operations and avoid frequent multi-field updates.
