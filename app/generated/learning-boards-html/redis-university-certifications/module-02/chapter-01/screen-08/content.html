Module 2 › Chapter 2.1 › Redis Hash
Definition

Map of fields to values

Use a Hash to represent objects with several attributes stored under one Redis key.

Benefits
  • Reduces total number of keys in Redis.
  • Enables atomic updates on individual fields.
  • Efficient for objects where single fields change often.
Caveat

HGETALL on a very large hash can be expensive; fetch only needed fields when possible.

Concrete example
HSET user:456 name "John Doe" email "john.doe@example.com" age 30 city "New York"
HGET user:456 name
HMGET user:456 email city
HGETALL user:456

All related attributes are stored under user:456 and accessed without parsing a document string.

Key Takeaway

Prefer Hashes when you need fast, field-level access to object attributes with atomic updates.
