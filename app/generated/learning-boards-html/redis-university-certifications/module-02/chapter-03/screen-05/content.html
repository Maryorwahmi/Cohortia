ProcessCommands

Command walkthrough

Run these in redis-cli to practice the common patterns.
ZADD global:leaderboard 100 "player:alice" 150 "player:bob" 75 "player:charlie"
ZADD global:leaderboard 120 "player:alice"
ZINCRBY global:leaderboard 20 "player:bob"
ZREVRANGE global:leaderboard 0 2 WITHSCORES
ZSCORE global:leaderboard "player:alice"
ZRANGEBYSCORE global:leaderboard 100 150 WITHSCORES
ZREM global:leaderboard "player:charlie"
ZCARD global:leaderboard

Explanation & best practices

  • Use ZADD to add or overwrite a member's score in one call; it is atomic for that member.
  • ZINCRBY is ideal for high-concurrency increments because it avoids read-modify-write races.
  • Prefer ZREVRANGE WITHSCORES to fetch top N with scores in a single round trip.
  • Use ZRANGEBYSCORE to filter by numeric ranges instead of scanning all members in application code.
Common mistake: calling ZSCORE repeatedly inside a loop instead of using range queries that return scores.
Pro tip: use prefixes in member strings, e.g., player:123, to avoid key collisions and to identify entity types.
