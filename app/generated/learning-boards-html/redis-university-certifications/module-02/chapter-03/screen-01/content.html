Sorted Sets and Streams

Learn how Sorted Sets deliver fast, ordered scoring for leaderboards and priorities, and how Streams provide append-only event logs with consumer groups for reliable message processing.

In this lesson
Core commands and patterns for rankings and logs
Coming up
Leaderboards, priority queues, and event-driven processing
Why this chapter matters

Choosing between a Sorted Set and a Stream affects ordering, replayability, and processing semantics. Use the right tool to keep your real-time features correct and efficient.

Explore Key Topics
Sorted Sets (ZSET)
Unique members with numeric scores, ideal for leaderboards and priority queues.
Streams
Append-only event logs with IDs and field-value entries for durable messaging.
Consumer Groups
Scale processing with groups that track progress and allow message acknowledgements.
