ComparisonDecision guide
List
Use for FIFO queues, ordered by insertion time. Allows duplicates. Lightweight when replay is not required.
Example: simple job queue consumed by a single worker.
Set
Use when uniqueness is required but ordering is not important. Fast membership checks.
Example: tracking seen user IDs in a session.
Sorted Set (ZSET)
Use when one unique member has a numeric score and you need ordered retrieval by rank or score.
Example: leaderboard or priority queue selecting highest scores.
Decision checklist
  • Do you need replay and multiple independent consumers? Choose Streams.
  • Do you need numeric ranking and uniqueness? Choose Sorted Sets.
  • Is insertion order sufficient and duplicates allowed? Choose Lists.
