ProcessConsumer Groups

Basic commands

XGROUP CREATE user:activity:stream analytics_group 0-0 MKSTREAM
XREAD GROUP analytics_group consumer_1 COUNT 1 STREAMS user:activity:stream >
XACK user:activity:stream analytics_group 1678881234567-0
XGROUP DESTROY user:activity:stream analytics_group

Operational notes

  • Start groups at 0-0 to process history; use > to receive new messages only for that group.
  • Always XACK messages after successful processing to remove them from the pending list.
  • If a consumer dies, other consumers can claim pending messages and finish them.
Warning

Unused consumer groups create metadata; destroy groups you no longer need to avoid resource buildup.
