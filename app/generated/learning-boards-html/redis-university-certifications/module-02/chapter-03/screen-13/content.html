Atomic updates
Use ZINCRBY to avoid race conditions when incrementing scores.
Fetch top N
Use ZREVRANGE key 0 N WITHSCORES for descending top results with scores in one call.
Consumer groups
Create per-service groups, use XREAD GROUP and XACK, and destroy groups you no longer need.
Final takeaway
Match tools to requirements: Sorted Sets for numeric ranking, Streams for durable event pipelines. Practice the CLI patterns and manage consumer-group lifecycle to build reliable, maintainable systems.
