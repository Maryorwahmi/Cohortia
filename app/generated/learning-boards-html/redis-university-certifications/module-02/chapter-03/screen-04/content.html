Core Concept Definition

What is a Sorted Set?

A Sorted Set stores unique members with floating-point scores. Redis orders members by score and allows rank and score-based retrieval.

Uniqueness: members are unique strings; adding updates score.
Ordering: queries like ZRANGE or ZRANGEBYSCORE return ordered slices efficiently.
Use cases: leaderboards, priority queues, ranked search.
Key Takeaway

Sorted Sets combine uniqueness with numeric ordering — pick them when numeric ranking matters.

Concrete example

ZADD leaderboard 1000 "player:alice" 1200 "player:bob"
ZINCRBY leaderboard 20 "player:bob"
ZREVRANGE leaderboard 0 2 WITHSCORES
Explanation: ZADD adds or updates scores. ZINCRBY increments atomically so concurrent updates don't lose increments. ZREVRANGE returns highest scores first.
Misconception: "Lists provide ranking" — Lists keep insertion order, not score order.
Pro tip: Store member IDs like player:123 to avoid collisions with other keys.
