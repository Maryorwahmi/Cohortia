Understand Sorted Set properties
Explain uniqueness, scores, and ordered retrieval and why numeric scoring matters for leaderboards.

Perform Sorted Set operations
Use ZADD, ZRANGE, ZRANGEBYSCORE, ZINCRBY, and ZSCORE to manage scores and retrieve rankings.
Mnemonic: ZADD adds, ZINCRBY increments atomically.
VERIFIED COMPETENCY MILESTONE
03
Grasp Redis Streams
Describe append-only entries, stream IDs, and why Streams are durable and replayable for events.
Mnemonic: Streams are logs; IDs are monotonic timestamps plus sequence numbers.
VERIFIED COMPETENCY MILESTONE
04
Use Consumer Groups
Create a consumer group, read with XREAD GROUP, and acknowledge with XACK so services process events safely.
Mnemonic: each service gets its own group to receive every event once per service.
