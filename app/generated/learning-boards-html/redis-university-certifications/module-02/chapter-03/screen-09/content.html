Process FlowReading Streams

Reading modes explained

XRANGE user:activity:stream 0-0 +
XRANGE user:activity:stream - + COUNT 2
XREAD COUNT 1 STREAMS mystream 0
XREAD STREAMS mystream $
XRANGE is for historical reads or audits. XREAD allows multi-stream reads and supports blocking for live consumption. Use $ to start from future entries only.

Entry IDs and timing

Auto-generated IDs are timestamp-sequence numbers. If producers on different machines add entries, Redis ensures monotonic IDs, but the timestamp portion may not exactly match wall-clock order. Treat IDs as ordering tokens, not precise timestamps.
Pro tip: persist the last-read ID for each consumer so you can resume exactly where you left off after a restart.
