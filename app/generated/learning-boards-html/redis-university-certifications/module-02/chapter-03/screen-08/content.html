Core ConceptStreams

Stream entries

Each entry has a unique ID and a set of field-value pairs. Stream IDs are monotonic and typically generated by Redis when you use an asterisk.

XADD mystream * sensor_id 123 temperature 25.5
XRANGE mystream - + COUNT 10
XREAD COUNT 1 STREAMS mystream 0
Explanation: XADD appends, XRANGE reads a historical slice, and XREAD can be used to poll or block for new entries. The ID format is a timestamp-sequence number allowing deterministic ordering.

When to use Streams

  • Event sourcing where you need the ability to replay events.
  • Sensor ingestion where each reading must be stored with an ID.
  • Message queues requiring multiple independent services to receive the same events.
Misconception

Don't treat Streams simply as Lists — they provide IDs, replay, and consumer-group semantics that Lists do not.
