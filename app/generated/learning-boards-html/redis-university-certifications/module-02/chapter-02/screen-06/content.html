Module 2 › Chapter 2.2 › LRANGE & Maintenance
Definition

LRANGE, LLEN, LREM, LTRIM

Use these commands to query slices, count items, remove occurrences, and enforce size limits on lists.

LRANGE complexity
Complexity scales with the number of elements returned. Paginate to avoid heavy requests.
LTRIM pattern
After LPUSH, call LTRIM key 0 N-1 to keep only the newest N items and prevent unbounded growth.
Common Mistake

Avoid LRANGE 0 -1 on extremely long lists. Paginate or use shorter ranges to stay responsive.

Examples & usage
LRANGE mylist 0 9    # first 10 elements
LRANGE mylist 0 -1   # entire list (use with caution)
LLEN mylist          # get list length
LREM mylist 2 "item"  # remove first 2 occurrences
LPUSH mylist "x"
LTRIM mylist 0 9     # keep newest 10 items
Use LTRIM immediately after pushes in your producer logic to make trimming predictable and reduce the chance of runaway memory usage.
