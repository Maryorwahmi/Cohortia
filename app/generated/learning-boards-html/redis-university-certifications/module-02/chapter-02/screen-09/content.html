Comparison

Add, read, check, remove and count

SADD, SMEMBERS, SISMEMBER, SREM and SCARD form the basic CRUD surface for sets. Use them together to implement membership systems and tag stores.

SADD
Add one or more members. Duplicates are ignored.
SISMEMBER
Fast boolean check for membership. Ideal for checking unique visits or likes.
Pro tip: combine SCARD with business logic to show counts without scanning elements. Use SREM to remove stale members when necessary.
Examples
SADD article:1:tags "redis" "database" "cache"
SMEMBERS article:1:tags
SISMEMBER article:1:tags "cache"
SREM article:1:tags "mongodb"
SCARD article:1:tags  # unique tag count
Misconception
SMEMBERS is convenient but can be expensive for large sets; use SSCAN to iterate in production.
