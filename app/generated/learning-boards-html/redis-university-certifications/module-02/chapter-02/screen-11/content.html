Feed simulation and blocking worker

Run these commands in the CLI to simulate a feed and a worker that waits for tasks.

redis-cli
# Producer: add posts to Alice's feed
LPUSH user:alice:feed "post:100: Alice posted about Redis"
LPUSH user:alice:feed "post:101: Alice shared a new article"
LPUSH user:alice:feed "post:102: Alice liked a photo"
LTRIM user:alice:feed 0 9   # keep newest 10
LRANGE user:alice:feed 0 4  # retrieve 5 newest

# Worker pattern (open another window)
BLPOP user:bob:tasks 10
# In first window
LPUSH user:bob:tasks "task:clean_cache"
Observe how the blocked client receives the new task instantly. Use LTRIM on the producer side to keep the feed bounded.
Tag management (Sets)
SADD article:1:tags "redis" "database" "nosql" "cache"
SADD article:2:tags "redis" "database" "performance"
SADD article:3:tags "nosql" "mongodb" "database"

SMEMBERS article:1:tags
SISMEMBER article:2:tags "cache"
SINTER article:1:tags article:2:tags
SUNION article:1:tags article:3:tags
Practice SINTER to find common tags and SUNION to list all unique tags across articles. Use SSCAN for iterative retrieval on large sets.
