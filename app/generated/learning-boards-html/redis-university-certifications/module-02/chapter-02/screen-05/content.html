Module 2 › Chapter 2.2 › List Commands
Process

LPUSH / RPUSH and LPOP / RPOP

Add or remove at either end. Use multi-argument LPUSH for batching. Commands are O(1) at ends.

Common pattern
LPUSH new items; RPOP to consume oldest for FIFO. Or LPUSH + LPOP for stack-like behavior.
Key Takeaway

Use end-focused operations to maintain performance. Batch pushes when possible and trim if needed.

CLI walkthrough
redis-cli
LPUSH user:alice:feed "post:102: Alice liked a photo" "post:101: Alice shared an article"
LRANGE user:alice:feed 0 4  # get 5 newest
RPOP user:alice:feed       # process oldest
LLEN user:alice:feed      # length check
Example
LPUSH accepts multiple values so you can enqueue many items in one call.
Misconception
LPUSH does not trim the list automatically; use LTRIM after pushes if you need a fixed size.
