Module 04 › Chapter 4.2 › Watch Hygiene
Safe control flow
  1. WATCH keys you care about.
  2. Read values and evaluate preconditions quickly.
  3. If preconditions fail, call UNWATCH and exit or reset the pipeline.
  4. If proceeding, call MULTI, queue commands, and call EXEC.
  5. On abort or exception, reset the pipeline in a finally block to ensure fresh state.
Using context managers that call reset on exit is a practical way to avoid leaving watches active. Keep the code between WATCH and EXEC minimal to lower the probability of concurrent modification and repeated retries.
Common mistake
Forgetting UNWATCH or not resetting the pipeline after early returns increases aborts and contention.
Pro tip
Use small randomized backoff before retrying to reduce contention in hot keys.
Try
Wrap pipeline usage in a context manager to ensure reset is always called.
