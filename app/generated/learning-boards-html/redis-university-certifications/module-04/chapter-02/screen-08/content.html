transfer_funds example (Python)
import redis

r = redis.Redis(host='localhost', port=6379, db=0, decode_responses=True)

user_balance_key = "user:101:balance"
r.set(user_balance_key, 100)  # Initial balance

def transfer_funds(from_user, to_user, amount):
    with r.pipeline() as pipe:
        while True:
            try:
                pipe.watch(from_user, to_user)
                from_balance = int(pipe.get(from_user))
                to_balance = int(pipe.get(to_user))

                if from_balance < amount:
                    pipe.unwatch()
                    return False

                pipe.multi()
                pipe.set(from_user, from_balance - amount)
                pipe.set(to_user, to_balance + amount)

                results = pipe.execute()
                if results is None:
                    continue
                else:
                    return True
            except redis.exceptions.WatchError:
                continue
            finally:
                pipe.reset()
This code watches the two accounts, reads balances, and queues the updates inside MULTI. If another client modifies a watched key, execute aborts and the loop retries.
Retry logic
Detect None or WatchError and retry with small delays to avoid busy-waiting.
Danger
Long processing between WATCH and EXEC increases the chance of aborts. Keep the window minimal.
Key Takeaway
Use WATCH for check-and-set patterns and always implement retry on abort.
