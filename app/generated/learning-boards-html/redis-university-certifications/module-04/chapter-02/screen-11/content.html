Module 04 › Chapter 4.2 › Common Mistakes
No rollback assumption
Errors inside a transaction appear in the results array; they do not trigger rollback of earlier commands.
Long WATCH window
Keep logic between WATCH and EXEC minimal to reduce aborts and retries.
Over-watching keys
Only WATCH keys critical to the transaction to avoid unnecessary contention.
Forgot to UNWATCH/reset
Release watches on early exit and reset pipelines in finally blocks to avoid stale state.
No retry on abort
If EXEC returns None or WatchError occurs, you must retry the transaction; otherwise updates are lost.
Use Lua when needed
For complex conditional logic or iteration, prefer server-side Lua scripts for stronger atomicity and fewer round trips.
Checklist

Validate inputs, watch only essentials, keep windows short, reset pipelines, and implement retry/backoff strategies.
