Quiz: Inventory DECR inside MULTI/EXEC
If DECR targets a key holding a non-integer string, the DECR fails at execution time. What happens to other queued commands?
Correct explanation
The DECR error appears in the EXEC results array, but other queued commands are still executed. There is no automatic rollback.
Mitigation strategies include validating types before queuing commands, adding compensating actions after EXEC, or moving logic into a Lua script when atomic conditional checks are required.
Key Takeaway

MULTI/EXEC groups execution but does not provide rollback; plan for errors and validation accordingly.
