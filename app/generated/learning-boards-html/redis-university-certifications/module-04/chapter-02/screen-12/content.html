When to escalate to Lua
Choose Lua when your logic requires server-side iteration, conditional branching based on intermediate states, or when high retry rates with WATCH hurt performance. Lua runs atomically on the server and avoids the multiple round trips that create race windows.
Use case: complex conditional update across many keys
Benefit: single atomic server-side execution, fewer retries
Keep Lua scripts small and test them carefully. Scripts that run too long can block the server, so measure execution time and avoid heavy loops where possible.
Misconception
Lua does not remove the need for correctness checks; it centralizes logic to run atomically on the server.
Key Takeaway
Prefer Lua for complex, frequently retried transactions to reduce contention and round trips.
