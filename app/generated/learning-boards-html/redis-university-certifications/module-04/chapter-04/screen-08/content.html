Module 5 › Chapter 4.4 › Rate Limiting
Fixed-window flow
  1. On request, INCR the counter key for the client.
  2. If the key is new, set EXPIRE to the window length (e.g., 60 seconds).
  3. If the counter > limit, reject the request and return 429 with Retry-After.
Concrete example
# Key: rate_limit:client:web_app:60s
INCR rate_limit:client:web_app:60s
EXPIRE rate_limit:client:web_app:60s 60 NX
Use a pipeline to group these commands so that EXPIRE is set only when appropriate and avoid missing TTLs on new keys.
