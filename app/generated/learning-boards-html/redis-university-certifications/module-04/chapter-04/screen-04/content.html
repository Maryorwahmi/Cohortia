What is a Sorted Set?
A Sorted Set keeps unique members ordered by a double-precision score. It supports fast range queries and rank lookups without client-side sorting.
Key commands
ZADD, ZINCRBY, ZSCORE, ZREVRANGE, ZREVRANK
When to use
Leaderboards, activity rankings, or any feature needing maintained numeric ordering.
Common misconception
People sometimes try to keep separate score tables and sort on read. ZSET keeps the order server-side, avoiding expensive client-side sorting and extra bandwidth for large result sets.
Visual example
Sorted set 'game:leaderboard'
(playerD:1800)
(playerB:1500)
(playerA:1350)
(playerE:1100)
(playerC:900)
Key Takeaway

Sorted Sets are the right choice when you need low-latency, server-maintained numeric ordering and efficient top-N queries.
