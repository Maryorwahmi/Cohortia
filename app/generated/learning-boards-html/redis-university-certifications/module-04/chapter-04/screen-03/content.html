Module 5 › Chapter 4.4 › Practice & Safety
Practice checklist
  • Run the provided Python starter code to populate a ZSET and view ranks.
  • Call ZINCRBY to simulate concurrent score updates and confirm atomic behavior.
  • Simulate requests to the rate limiter and observe when INCR+EXPIRE blocks requests.
Safety reminders
  • Paginate large ZREVRANGE queries to avoid network and client processing spikes.
  • Use pipelines or Lua to ensure INCR and EXPIRE are not separated by failure windows.
  • Choose keys with the right granularity to avoid over- or under-limiting traffic.
