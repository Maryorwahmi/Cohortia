Best practices
  • Fetch only the top N players needed for immediate display.
  • Provide 'near player' queries using ZREVRANK and offset ranges.
  • For analytics, stream ZREVRANGE results in batches server-side.
Concrete UI pattern
Show top 20 on the public leaderboard and show a focused 5-item window around the current player via rank lookup and a small range read.
Cache top-N
Key Takeaway

Avoid giant ZREVRANGE calls. Paginate, cache the most-read slices, and use rank-based local ranges for player-centered views.
