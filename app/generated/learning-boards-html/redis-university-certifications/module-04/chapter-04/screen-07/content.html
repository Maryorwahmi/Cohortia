Module 5 › Chapter 4.4 › Player Rank & Score
Commands to use
  • ZSCORE key member → numeric score or null.
  • ZREVRANK key member → 0-based rank with highest score at 0.
Pipeline example (conceptual)
pipe = r.pipeline()
pipe.zscore(KEY, 'Alice')
pipe.zrevrank(KEY, 'Alice')
score, rank = pipe.execute()
Concrete example
If ZSCORE returns 1350 and ZREVRANK returns 2, display "Rank 3 — 1350 points". If either value is null, show a friendly message that the player is not yet on the leaderboard.
Key Takeaway

Use both commands together and format rank for users. Pipelines reduce network round trips when fetching both values.
