Starter code (annotated)
import redis

r = redis.Redis(host='localhost', port=6379, db=0, decode_responses=True)
LEADERBOARD_KEY = "game:highscores"

# ZADD sets absolute totals
r.zadd(LEADERBOARD_KEY, {"PlayerA": 1200, "PlayerB": 1500})

# ZINCRBY for earned points
r.zincrby(LEADERBOARD_KEY, 150, "PlayerA")

# Read top 3 players
top = r.zrevrange(LEADERBOARD_KEY, 0, 2, withscores=True)
print(top)
Example output
Returns a list of pairs like [("PlayerA", 1350.0), ("PlayerB", 1500.0)]. Convert or format scores for display.
Concrete scenario
Use the starter code in a game server: on each scoring event call ZINCRBY. Periodically refresh a cached top-N for the UI to reduce read frequency.
Key Takeaway

Practical demo: the Python snippet shows how to add, increment, and retrieve top players; always think about display formatting and pagination.
