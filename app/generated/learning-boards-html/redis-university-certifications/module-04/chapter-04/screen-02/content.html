Learning Objectives
Learn, Understand, Apply, Master — practical milestones for leaderboards and rate limiting.
LearnUnderstandApplyMaster
01 — Build a leaderboard
Design and implement a real-time leaderboard using Sorted Sets, and understand why they stay ordered.
VERIFIED COMPETENCY MILESTONE
02 — Update and query scores
Use ZINCRBY and ZREVRANGE efficiently and learn how to fetch a member's score and rank on demand.
VERIFIED COMPETENCY MILESTONE
03 — Implement rate limiting
Create a fixed-window limiter using INCR and EXPIRE and learn how to use pipelines to reduce races.
VERIFIED COMPETENCY MILESTONE
04 — Recognize trade-offs
Differentiate fixed-window and sliding-window limiters and know when Lua or Sorted Sets are appropriate for accuracy.
VERIFIED COMPETENCY MILESTONE
