def is_rate_limited(user_id, limit=5, window_seconds=60):
    key = f"rate_limit:{user_id}:{window_seconds}s"
    pipe = r.pipeline()
    pipe.incr(key)
    pipe.expire(key, window_seconds, nx=True)
    count, _ = pipe.execute()
    return count > limit
This pipeline increments and attempts to set TTL only when key is new. If count exceeds limit, the request should be rejected with a 429 status and Retry-After header.
Concrete test scenario
Simulate requests in a loop to observe when requests start being blocked and watch the counter TTL expire to allow new requests after the window.
Common mistake

Calling INCR and EXPIRE separately without piping can leave a counter without TTL if a crash occurs between calls, causing permanent blocks.
