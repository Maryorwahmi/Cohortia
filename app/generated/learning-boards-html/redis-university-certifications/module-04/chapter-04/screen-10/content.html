Module 5 › Chapter 4.4 › Windowing Comparison
Fixed-window
  • Counts requests in discrete time buckets.
  • Fast and low overhead with INCR + EXPIRE.
  • Vulnerable to burst behavior at window edges.
Simple
Sliding-window
  • Considers a continuous interval for fairness.
  • Often implemented with Sorted Sets storing timestamps.
  • More accurate but higher memory and compute cost.
Fairer
Concrete sliding example
Store each request timestamp in a Sorted Set. Remove timestamps older than the window and count remaining members to decide allowance. This prevents a burst at bucket edges but requires more operations per request.
Key Takeaway

Pick fixed-window for low-cost policing. Use sliding-window when you need smoother rate enforcement across boundaries.
