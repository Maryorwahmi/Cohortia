Testing & validation
  • Call get_product_details twice: first is a miss, second is a hit.
  • Wait for TTL expiration or r.delete(key) to force a miss again.
  • Simulate a DB update, then r.delete to invalidate and confirm new data is fetched.
Negative caching tip
Cache a short-lived null for missing products to prevent repeated database hits for non-existent IDs.
Key Takeaway

Test both hits and misses and use manual invalidation to verify correctness after updates.
