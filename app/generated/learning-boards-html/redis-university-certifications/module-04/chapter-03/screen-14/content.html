Module 04 › Chapter 4.3 › Quick Reference
Pattern
Cache-Aside: GET → DB on miss → SETEX with TTL.
Eviction
Start with allkeys-lru; use volatile-lru if only TTL keys should be evicted.
Mitigations
Invalidation, locks/SETNX, early expiry, negative caching, and Bloom filters.
One-line takeaway

Design caching to trade freshness for speed intentionally, and instrument everything so you can tune the trade-offs with data.
