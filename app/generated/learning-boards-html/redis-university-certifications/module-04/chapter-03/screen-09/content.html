Module 04 › Chapter 4.3 › Eviction Policies
allkeys-lru
Evict least recently used keys from the entire dataset. Good default for caches where recency indicates value.
volatile-lru
Evict LRU keys among those with TTLs. Use when some keys must not be evicted automatically.
allkeys-lfu
Evict least frequently used across all keys. Useful when frequency is a better signal than recency.
volatile-lfu
Evict LFU among keys with TTLs.
volatile-ttl
Evict keys with the shortest remaining TTL first. Prioritizes TTL-based removal.
noeviction / random
noeviction rejects writes; random evicts arbitrary keys. Use when simplicity is preferred over predictability.
Practical guidance

Start with allkeys-lru for general caches. If you only set TTLs on cache items, volatile-lru will prevent eviction of keys without TTL. Monitor metrics and adjust if hot items are unexpectedly evicted.
