Module 04 › Chapter 4.3 › Time-To-Live (TTL)
TTL mechanics
Use SETEX to store a value and its TTL in one call, or use EXPIRE to add TTL to an existing key. Keys are removed automatically when TTL expires.
Long TTL
Good for infrequently changing, expensive-to-compute data.
Short TTL
Better for frequently changing values to reduce staleness.
Practical rules
  • Prefer short TTLs for dynamic data, and immediate invalidation on updates when possible.
  • Use negative caching with a short TTL for missing items to prevent penetration.
  • Combine TTLs with locking to avoid stampedes when many keys expire at once.
