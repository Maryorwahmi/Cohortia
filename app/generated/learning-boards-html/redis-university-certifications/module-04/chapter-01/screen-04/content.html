Module 4 › Chapter 4.1 › Client-Server Model
Definition and behavior
A client opens a TCP connection to a Redis server. Commands are sent, the server processes them, and responses return over the same connection.
Example
A web worker starts, creates a client, issues PING to confirm connectivity, then serves requests that use SET and GET.
Common misconception
Redis is not an in-memory object inside your process; it is a separate server that must be reached over the network.
Key takeaway
Design your code to handle network latency and failures and to reuse connections when possible.
Visual callout
Annotated connection: client name, TCP socket, hostname:port, server with optional authentication.
Connection components
  • Hostname/IP — network address of the Redis instance.
  • Port — default 6379 unless configured otherwise.
  • Authentication — provide a password if the instance requires it.
