Module 4 › Chapter 4.1 › Secure Connection Lab
Step 1 — Secure Redis
  1. Edit redis.conf and set requirepass to a strong password, then restart the server.
  2. Verify the server rejects unauthenticated requests by attempting a client PING without credentials.
Outcome: you should observe an authentication failure when connecting without the password.
Step 2 — Verify from Python
Set REDIS_PASSWORD in your environment and create a small script that constructs a redis.Redis client with the password, runs PING, SET, and GET, and captures AuthenticationError when missing or wrong.
Tip: keep the starter code with TODO markers and do not hardcode the password into the file.
Step 3 — Verify from Node.js
Create an ioredis client with the password option and run the same PING, SET, and GET checks. Observe the error event if authentication fails.
Final checks
  • Attempt a connection without a password to confirm AuthenticationError behavior.
  • Call quit or disconnect during shutdown to release pooled sockets.
  • Reflect: how would you rotate credentials without outage?
