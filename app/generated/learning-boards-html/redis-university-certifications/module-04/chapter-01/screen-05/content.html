Module 4 › Chapter 4.1 › Connection Parameters
What to set
Provide host, port, and password (if required). For production, prefer secure retrieval of secrets.
Concrete example
In development: host=localhost, port=6379. In production: host points to a managed Redis endpoint and password is read from an environment variable.
Pitfall
Hardcoding credentials makes them hard to rotate and exposes secrets if the repo is shared. Use environment variables or a secrets manager instead.
Quick verification steps
  • Check server process is listening on the expected host and port.
  • Run a client PING; a successful PONG shows connectivity and authentication status.
  • If authentication fails, expect an AuthenticationError or similar from the client library.
Key takeaway
Verify host, port, and credentials early; failing fast avoids confusing runtime errors later.
