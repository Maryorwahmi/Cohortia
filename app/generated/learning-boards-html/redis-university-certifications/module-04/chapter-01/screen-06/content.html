Python starter (read-only example)
import redis

try:
    r = redis.Redis(host='localhost', port=6379, db=0, decode_responses=True)
    r.ping()
    print('Connected to Redis!')

    r.set('mykey', 'Hello Cohortia!')
    value = r.get('mykey')
    print(f"Value for 'mykey': {value}")

except redis.exceptions.ConnectionError as e:
    print(f'Could not connect to Redis: {e}')
except Exception as e:
    print(f'An unexpected error occurred: {e}')
Note: decode_responses=True ensures the client returns native strings instead of byte strings.
Pool awareness and tips
  • redis-py uses a ConnectionPool by default for each Redis instance.
  • You can explicitly create a ConnectionPool to share among clients or tune max_connections.
  • During shutdown, allow the pool to release sockets or call disconnect on the pool to close resources.
Concrete takeaway
Instantiate Redis with decode_responses when you want strings, and rely on the built-in pool unless you need custom sizing.
