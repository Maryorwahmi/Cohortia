Module 3 › Chapter 3.3 › Key Concepts
Persistence
Durable storage so Redis data survives restarts and crashes.
RDB Snapshots
Point-in-time binary snapshots created by a forked child; compact and fast to load.
AOF
Append-only log of write commands; replayed on restart for greater durability. Use appendfsync to tune safety vs performance.
Takeaway
Match persistence configuration to the acceptable data-loss window and test recovery procedures regularly.
