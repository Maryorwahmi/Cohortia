Module 3 › Chapter 3.3 › Objectives: Validation
Hands-on validation

These objectives teach you to verify that persistence is functioning by observing files, running BGSAVE and BGREWRITEAOF, simulating crashes, and confirming data integrity after restart.

Check 1
Confirm dump.rdb exists and notice its timestamp after BGSAVE.
Check 2
Tail the appendonly.aof file to see appended write commands as you perform operations.
Competency milestone

You will be able to reproduce the lab sequence: configure short save intervals, enable AOF with every-second fsync, write keys, force a crash, and verify recovery using redis-cli commands.
