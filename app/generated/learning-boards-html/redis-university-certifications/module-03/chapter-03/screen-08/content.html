Rewrite process

Fork child → write compact AOF → replace

BGREWRITEAOF compacts the append-only file by creating a new file with the minimal commands necessary to rebuild the current dataset.

The child process reads memory and writes a new optimized AOF file that removes redundant commands.
On success, Redis atomically replaces the old AOF with the new file. This reduces disk usage and speeds replay at restart.
Practical tip
Trigger BGREWRITEAOF during low traffic periods. Monitor CPU and I/O because forks and rewrites use resources.
Command example
# Trigger a manual AOF rewrite
BGREWRITEAOF
Use BGREWRITEAOF to prevent appendonly.aof from growing without bound and to keep recovery time reasonable.
