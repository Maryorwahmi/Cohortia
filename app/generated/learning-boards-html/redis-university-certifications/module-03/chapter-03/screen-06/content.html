Config example
# Example RDB configuration in redis.conf
save 900 1    # Save if 1 key changed in 900 seconds
save 300 10   # Save if 10 keys changed in 300 seconds
save 60 10000 # Save if 10000 keys changed in 60 seconds

# Manual commands
BGSAVE
SAVE
After saving, check for dump.rdb in the configured dir and validate timestamps. Use BGSAVE for background saves to avoid blocking.
Key Takeaway

Save directives define automated snapshots. Use BGSAVE to avoid service interruption.

Walkthrough
  1. Edit redis.conf and set save directives for your testing window.
  2. Start Redis with the modified config using the server path to the file.
  3. Use redis-cli and run BGSAVE. Watch for a new dump.rdb file.
  4. Inspect the file timestamp to confirm the snapshot time.
Remember: SAVE blocks the server during the write. Use it only when you can halt traffic.
