Terminal demo steps
  1. Edit redis.conf: save 5 1, appendonly yes, appendfsync everysec, dir ./testdir
  2. Start Redis with the custom config and connect using redis-cli
  3. Run: SET mykey "hello"; LPUSH mylist "item1" "item2"
  4. Run BGSAVE and observe dump.rdb timestamp; open appendonly.aof to inspect commands
  5. Simulate crash with a forced stop and restart Redis with the same config
  6. Verify recovery: GET mykey and LRANGE mylist 0 -1
These steps let you verify whether AOF or RDB preserved your changes and how quickly recovery completes.
Example redis.conf snippet
# RDB configuration
save 5 1
dbfilename dump.rdb
dir ./testdir

# AOF configuration
appendonly yes
appendfilename appendonly.aof
appendfsync everysec
After restart, redis-cli commands will show whether the writes survived. Practice this to make persistence decisions for your systems.
