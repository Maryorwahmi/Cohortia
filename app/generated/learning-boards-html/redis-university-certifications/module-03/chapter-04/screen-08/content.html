Process Flow › AOF Restore

Restore steps

  1. Stop Redis cleanly.
  2. Copy appendonly.aof into Redis dir.
  3. Start Redis and wait for command replay to finish.
  4. Verify data integrity using client checks.
Misconception: AOF always restores faster than RDB — not necessarily; replay time can be significant.
Example commands
# Stop Redis
systemctl stop redis

# Replace the AOF file
cp /tmp/redis_backup/appendonly-2023-07-01.aof /var/lib/redis/appendonly.aof

# Start Redis
systemctl start redis

# Verify a sample key
redis-cli GET user:1:name
Key Takeaway

AOF restores replay all writes. Test replay time and plan maintenance windows accordingly.
