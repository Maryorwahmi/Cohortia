Process Flow › RDB Restore

Step-by-step restore

  • Stop Redis: Ensure a clean shutdown to avoid write conflicts.
  • Place dump.rdb: Move your backup file into the configured dir.
  • Start Redis: The server will load the snapshot on startup.
  • Verify: Use redis-cli to check critical keys and data integrity.
Misconception: Replacing files while Redis runs is safe — it is not. Always stop first.
Example commands
# Stop Redis (systemd example)
systemctl stop redis

# Copy backup into Redis dir
cp /tmp/redis_backup/dump-2023-07-01.rdb /var/lib/redis/dump.rdb

# Start Redis
systemctl start redis

# Verify data
redis-cli GET user:1:name
Key Takeaway

Always stop before replacing persistence files and verify restored keys after restart.
