Why compact AOF?

AOF records every write. Over time this accumulates redundant operations. BGREWRITEAOF produces a compact file that reduces restore time and disk use.

Common-mistake
Copying the AOF before compaction creates unnecessarily large backups and slow replays.
Terminal example
# Trigger AOF rewrite
BGREWRITEAOF

# After rewrite, copy the file
cp /var/lib/redis/appendonly.aof /tmp/redis_backup/appendonly-2023-07-01.aof
Key Takeaway

Run BGREWRITEAOF to compact before copying and expect replay time during AOF restore.
