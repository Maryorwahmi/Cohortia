What to Remember › Ops & Scale
Failover
Automatic promotion of a replica to master when the master fails.
Quorum
Minimum number of Sentinels that must agree before initiating failover.
Cluster & Sharding
Redis Cluster shards data across multiple masters to scale memory and throughput horizontally.
Final takeaway

Combine backups for data safety with Sentinel for availability, and adopt Cluster only when you need sharding and horizontal scale.
