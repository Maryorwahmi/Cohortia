Redis Backups, Restores, and High Availability

Learn repeatable, production-safe steps to back up Redis data with RDB and AOF, restore reliably, and keep services running using Redis Sentinel. We also introduce when Redis Cluster is appropriate.

In this lesson
  • Backups: Create safe copies of dump.rdb and appendonly.aof with BGSAVE and BGREWRITEAOF.
  • Restores: Stop Redis, replace persistence files, and restart to recover state.
  • HA with Sentinel: Monitor, notify, promote replicas, and provide master info to clients.
Concept Map
RDB / AOF
Persistence files on disk used for backups and restores.
Sentinel
Monitors instances, triggers failover, serves master address to clients.
Coming up
Backups
Use BGSAVE and BGREWRITEAOF, then copy files off-server.
Restores
Stop Redis, replace files, restart to recover data.
HA
Sentinel automates failover; Cluster provides sharding and scale.
