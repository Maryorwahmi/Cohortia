Process Flow › RDB Backup
  1. Verify save directives: Ensure redis.conf has the desired snapshot intervals.
  2. Trigger snapshot: Run BGSAVE to create a background dump.
  3. Confirm completion: Check LASTSAVE or logs to ensure dump finished.
  4. Copy with timestamp: Move dump.rdb off-server for retention.
Pro tip: automate BGSAVE and the file copy so manual steps are not missed.
Terminal commands (example)
# Trigger a fresh snapshot in redis-cli
BGSAVE

# After completion, copy the file with a timestamp
cp /var/lib/redis/dump.rdb /tmp/redis_backup/dump-2023-07-01.rdb
Key Takeaway

Always confirm BGSAVE completion and copy dump.rdb to off-server storage with a timestamp.
