Definition › Redis Sentinel

Core functions

  • Monitoring: Constant health checks on master and replicas.
  • Notification: Alert operators or systems when issues occur.
  • Automatic failover: Elect and promote a replica when master fails.
  • Configuration provider: Give clients the current master address.
Example: failover sequence
  1. Sentinel marks master as subjectively down.
  2. Quorum of Sentinels agree and mark it objectively down.
  3. Sentinels elect a leader to coordinate failover.
  4. Leader promotes the best replica and reconfigures others.
Key Takeaway

Use Sentinel to reduce downtime. Combine it with backups to protect both availability and data integrity.
