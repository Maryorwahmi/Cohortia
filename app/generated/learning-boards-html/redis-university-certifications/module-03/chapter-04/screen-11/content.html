Comparison › Sentinel vs Cluster
Sentinel
  • Provides automatic failover for one master and its replicas.
  • Clients ask Sentinel for the current master address.
  • Does not shard data.
Cluster
  • Automatically shards data across multiple masters.
  • Provides high availability for each shard with replicas.
  • Clients are redirected to the correct node for a key.
Key Takeaway

Use Sentinel for availability in single-master setups; use Cluster when you need sharding and horizontal scale. They solve complementary but distinct problems.
