Module 3 › Chapter 3.2 › Key Concepts
Publish/Subscribe

A decoupled messaging pattern where publishers send messages to channels and current subscribers receive them.

Commands

PUBLISH to send, SUBSCRIBE/UNSUBSCRIBE to manage exact channels, PSUBSCRIBE/PUNSUBSCRIBE for patterns.

Fire-and-forget

Messages are not persisted by Pub/Sub. If no subscribers are active, published messages are lost.

Summary Takeaway

Use Redis Pub/Sub for low-latency, ephemeral broadcasts like chat or dashboards. For durability, replay, or guaranteed processing, choose Streams or a persistent messaging system.
