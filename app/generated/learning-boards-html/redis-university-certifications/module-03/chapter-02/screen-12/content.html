Fan-out costs

Each published message is delivered to every subscriber. Multiply message size by subscriber count to estimate bandwidth and server load.

Practical steps
  • Use narrow channels for selective subscriptions.
  • Keep payloads small and encode efficiently.
  • Shard topics when subscriber counts grow very large.
Connection hygiene

Avoid many short-lived subscription connections. Prefer long-lived clients with robust reconnection and re-subscription handling.

When to choose alternatives

If you need guaranteed delivery, replay, or consumer groups, choose Redis Streams or a dedicated messaging system instead of Pub/Sub.

Checklist

Estimate fan-out, plan for small messages, use separate connections, and pick Streams for durability.
