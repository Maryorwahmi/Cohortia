Module 3 › Chapter 3.2 › UNSUBSCRIBE
Command

UNSUBSCRIBE [channel ...]

Stop receiving messages from specified channels or from all channels if no arguments are provided. When no subscriptions remain, the connection exits subscription mode.

# Stop listening to a channel
UNSUBSCRIBE news:sports

# Stop all subscriptions
UNSUBSCRIBE
Lifecycle notes
  • Unsubscribe explicitly when a client needs to repurpose its connection for other commands.
  • Handle reconnection and re-subscription in client code to survive network interruptions.
  • Avoid leaving many transient subscription connections open without cleanup.
Key Takeaway

Manage subscriptions intentionally. Use UNSUBSCRIBE and reconnection logic so subscription clients remain healthy and predictable.
