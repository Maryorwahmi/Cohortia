Module 3 › Chapter 3.2 › Key Concepts
Channel naming
Design channel names to support selective subscription and pattern matching.
Pattern matching
PSUBSCRIBE captures groups of channels using glob wildcards; use it to reduce subscription management.
Ephemeral delivery
Pub/Sub does not persist messages. Persist critical events if you need replay or guaranteed delivery.
Final takeaway

Redis Pub/Sub is a simple, fast mechanism for real-time broadcasts. Use it when immediacy matters and persist elsewhere when durability is required.
