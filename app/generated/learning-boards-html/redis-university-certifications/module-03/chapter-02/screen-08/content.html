Pattern matching

PSUBSCRIBE news:*

Use glob wildcards to subscribe to groups of channels. The asterisk matches any sequence, and the question mark matches a single character.

# Pattern subscriber
PSUBSCRIBE news:*

# This will receive messages published to news:sports and news:politics, etc.
Practical tip

Design channel naming carefully so patterns match the intended set without accidental overlap with other domains.

Warning

An overly broad pattern can increase bandwidth and CPU usage on subscribers. Audit patterns in production to avoid surprises.

Message metadata

When Redis pushes a pattern-matched message, it includes the pattern and the originating channel name, enabling the subscriber to route or filter further if needed.

Key Takeaway

PSUBSCRIBE simplifies subscribing to hierarchical channels, but use precise patterns to avoid unintended fan-out.
