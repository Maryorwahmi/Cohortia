Module 3 › Chapter 3.2 › Three-session demo
Session 1
# Session 1 (Specific Subscriber)
SUBSCRIBE app:updates:critical

# waits and receives messages for this channel
Session 2
# Session 2 (Pattern Subscriber)
PSUBSCRIBE app:updates:*

# receives messages from app:updates:critical and app:updates:info
Session 3
# Session 3 (Publisher)
PUBLISH app:updates:critical "Maintenance starting in 5 minutes"
PUBLISH app:updates:info "New feature released"
PUBLISH app:alerts:security "Unauthorized login detected"
Observation

app:updates:critical is delivered to both subscribers; app:alerts:security is delivered to none in this demo because it was not subscribed.

Pro Tip

Record important events in a persistent store if you need clients to see them after reconnecting.
