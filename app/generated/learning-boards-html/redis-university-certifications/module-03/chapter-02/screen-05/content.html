Module 3 › Chapter 3.2 › PUBLISH
Command

PUBLISH channel message

Send a message to a named channel. Redis returns how many clients were delivered the message, not whether it was persisted.

# In redis-cli (publisher)
PUBLISH news:sports "Local team wins championship!"

# Redis returns an integer reply showing how many subscribers received it.
Practical tip

Keep messages small to reduce bandwidth when publishing to many subscribers. The server sends the message to every subscriber, so size matters.

Misconception

The integer reply is not an acknowledgement of processing — only an indication of how many clients were connected at publish time.

Scenario

A monitoring service publishes critical alerts to app:updates:critical. Connected dashboards receive alerts in real time. If a dashboard is offline when the alert is published, it will miss that alert.

Key Takeaway

PUBLISH is immediate and ephemeral. Use it when speed matters and you accept possible loss for offline subscribers.
