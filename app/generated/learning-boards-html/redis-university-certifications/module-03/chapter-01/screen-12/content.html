Module 3 › Chapter 3.1 › Pipelining in Python
Starter code
import redis
r = redis.Redis(decode_responses=True)

# Pipelined SETs
pipe = r.pipeline()
for i in range(100):
  pipe.set(f"key:{i}", f"value:{i}")
pipe.execute()

# Pipelined GETs
pipe = r.pipeline()
for i in range(100):
  pipe.get(f"key:{i}")
results = pipe.execute()
print(f"Fetched {len(results)} keys.")
Measurement advice
Run sequential and pipelined variants and measure elapsed wall-clock time. The pipeline should substantially reduce time where network latency is non-trivial. Monitor memory when increasing batch sizes.
Practical tip
Start with batches of 100–1000 commands. Tune based on latency, memory, and server/client resource limits.
