Module 3 › Chapter 3.1 › Pitfalls & Best Practices
Validate before queuing
Check types, ranges, and expected state so errors don’t appear only at EXEC time.
Keep transactions small
Minimize work between WATCH and EXEC to reduce retry windows and contention.
Batch pipelines carefully
Use moderate batch sizes to balance latency reduction and memory usage.
Combine when needed
Wrap MULTI/EXEC inside a pipeline to get both atomicity and fewer round-trips.
Retry responsibly
On nil EXEC, retry with backoff and a limited number of attempts to avoid hot loops.
Monitor & measure
Instrument latency and memory when using pipelines or heavy transactional traffic and tune accordingly.
