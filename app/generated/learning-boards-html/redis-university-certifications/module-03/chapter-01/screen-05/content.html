Module 3 › Chapter 3.1 › MULTI → EXEC process
Step-by-step
1. MULTI — switch to queued mode and start collecting commands.
2. Queue commands — DECRBY, INCRBY, HSET, etc.; they are not executed yet.
3. EXEC — run all queued commands sequentially and return results as a batch.
4. DISCARD — cancel queued commands and return to normal mode.
Tip: Treat queued commands as tentative until EXEC completes.

If WATCH was used on a key and that key changed before EXEC, the final response will be nil and no commands are applied. If a queued command is invalid, it will still be executed and an error for that command will be returned alongside successful results for others.
Mistake to avoid
Don’t assume EXEC rolls back other commands on error. Validate inputs before queuing to avoid partial failures.
