Module 3 › Chapter 3.1 › Pipelining
Why it helps
Network latency per command is the enemy of throughput. Batch many commands into a single network exchange to reduce cumulative latency and increase throughput.
Python pipeline pattern
pipe = r.pipeline()
for i in range(100):
  pipe.get(f"key:{i}")
results = pipe.execute()
Expected effect
The pipeline reduces 100 round-trips to 1, lowering elapsed time dramatically over high-latency networks. Responses include individual results; errors are flagged per-command.
Caution
Very large pipelines can consume significant memory on client and server. Batch reasonably and measure.
