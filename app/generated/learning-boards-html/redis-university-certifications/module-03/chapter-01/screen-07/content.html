Module 3 › Chapter 3.1 › Funds transfer example
Context and steps
1. Read and validate source balance in application logic.
2. Optionally WATCH the balance if concurrent writers exist.
3. MULTI, queue DECRBY and INCRBY, then EXEC.
4. If EXEC returns nil when using WATCH, retry from step 1.
Key consideration
Do not assume queued commands executed until EXEC returns success. Validate before queueing to avoid command errors at commit time.
redis-cli sequence
MULTI
DECRBY user:100:balance 50
INCRBY user:200:balance 50
EXEC
If you expect concurrent updates to the same balance, precede this with WATCH user:100:balance and re-read the balance to decide whether to queue the DECRBY.
