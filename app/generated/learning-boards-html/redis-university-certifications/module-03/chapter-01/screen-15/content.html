Pipelining
Batch commands to cut network round-trips and increase throughput; watch memory usage when batching.
DISCARD
Use DISCARD to cancel a queued transaction before EXEC and return to normal mode.
Combine patterns
Wrap MULTI/EXEC inside a pipeline to achieve atomicity with fewer network calls, but batch responsibly.
Final takeaway

Choose transactions for correctness, pipelining for throughput, and combine them carefully while monitoring memory and retry behavior.
