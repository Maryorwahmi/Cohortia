Module 3 › Chapter 3.1 › Practice Targets
01 — Atomic transfer
Wrap DECRBY and INCRBY inside MULTI/EXEC to ensure both succeed or both fail to commit. This prevents inconsistent balances if a client fails between commands.
02 — Optimistic retry
Use WATCH before reading the key, re-read and retry the transaction if EXEC returns nil due to concurrent modification.
03 — Pipelined throughput
Measure the difference between 100 sequential GETs and a pipeline of 100 GETs; expect much fewer round-trips with the pipeline.
04 — Pipeline + MULTI
Queue a MULTI/commands/EXEC inside a pipeline to combine atomic commit with reduced network overhead.
