Process

BGREWRITEAOF: compacting the AOF

Rewriting reads the dataset and emits a minimal command sequence to recreate it, removing redundant writes.

Rewrite triggers: auto-aof-rewrite-percentage and min-size settings. Example: percentage 100 triggers when AOF doubles.
Rewrite runs asynchronously by forking a child; the parent continues serving requests.
Requires disk space for temporary file and additional I/O during rewrite.
Common mistake
Not reserving disk space for the temporary rewritten AOF, which can cause rewrite failure and data risk.
Config snippet
auto-aof-rewrite-percentage 100
auto-aof-rewrite-min-size 64mb
Concrete example
If your AOF was 50 megabytes, with percentage 100 a rewrite will be triggered when it grows to 100 megabytes since the last rewrite.
Key Takeaway

Use BGREWRITEAOF to control AOF size, but monitor disk space and I/O to avoid rewrite failures.
