Hands-on and Decision Objectives

These objectives focus on configuration edits, manual commands, and operational safety checks you will perform.

Config
Find and interpret save, appendonly, appendfsync, appendfilename, and dir in redis.conf and predict behavior after restart.
Commands
Use SAVE, BGSAVE and BGREWRITEAOF and know which block or do not block the server.
Safety
Check disk space and permissions for the persistence directory to avoid corruption during writes.
Practice task
Edit redis.conf to enable appendonly and set appendfsync everysec, then restart and test persistence with a key write and restart.
Final milestone
Be able to pick RDB or AOF or both based on data loss tolerance and restart performance needs.
