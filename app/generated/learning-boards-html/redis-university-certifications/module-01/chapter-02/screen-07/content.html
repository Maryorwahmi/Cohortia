Module 1 › Chapter 1.2 › INCR / DECR
Definition & Guarantee

INCR increments a numeric string by one atomically. DECR decrements by one. Atomicity prevents race conditions that occur when multiple clients read and write concurrently.

Common mistake

Attempting INCR on a key holding non-numeric text will raise an error. Validate or initialize numeric keys before incrementing.

Example
SET page:views:homepage 0
INCR page:views:homepage     # returns 1
INCR page:views:homepage     # returns 2
DECR page:views:homepage     # returns 1
Application

Use these commands for counters, unique ID generators, and distributed rate limiters where correctness under concurrency is required.
