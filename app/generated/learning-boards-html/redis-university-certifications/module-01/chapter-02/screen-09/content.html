Network efficiency

Use MGET to fetch several keys in a single request and MSET to set several keys at once. This minimizes round trips and improves throughput for grouped fields.

Behavior note

MGET returns values in the order of requested keys. Missing keys appear as nil values in the result array so you can align them back to the requested keys reliably.

Example
MSET product:1:name "Laptop Pro" product:1:price "1200.00" product:1:category "Electronics"
MGET product:1:name product:1:price product:1:category product:2:name  # product:2:name -> (nil)
Mapping results

When building application models, handle nil placeholders by using defaults or conditional logic to avoid null reference issues.
