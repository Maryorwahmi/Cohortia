Definition

Binary-safe strings

Strings can contain any sequence of bytes. They do not impose character encoding or interpret contents, so you can store text, JSON, binary blobs, or images.

Maximum size: 512 MB per string.
Use case example: cache a rendered HTML fragment or serialized session token.
Misconception: strings are not limited to readable text; they are byte arrays.
Concrete Examples
SET user:session:abc "{\"user_id\":123, \"username\":\"alice\"}"
GET user:session:abc
Decision guide
  • Use Strings: single opaque values, binary blobs, or cached payloads.
  • Use Hashes: structured fields you need to read or update individually.
  • Use GETRANGE/SETRANGE for small partial edits when a Hash isn't suitable.
Key Takeaway

Strings are flexible binary containers; select them when the value is naturally a single blob and size fits within 512 MB.
