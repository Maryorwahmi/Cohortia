Module 1 › Chapter 1.2 › GETRANGE / SETRANGE
GETRANGE

Retrieve a substring by specifying start and end offsets. Offsets are 0-indexed and inclusive.

SET mylongstring "This is a very long string."
GETRANGE mylongstring 0 3   # returns "This"
GETRANGE mylongstring 10 14 # returns "very "
SETRANGE

Overwrite bytes starting at a given offset. If the target is short, Redis pads with null bytes before writing.

SET greeting "Hello World"
SETRANGE greeting 6 "Redis"   # greeting becomes "Hello Redis"
GET greeting
Be careful with multi-byte encodings; offsets operate on bytes, not characters.
