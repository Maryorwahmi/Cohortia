Module 1 › Chapter 1.2 › PEXPIRE / PTTL
When to use
  • Short-lived one-time tokens under one second.
  • Fine-grained rate limiting windows measured in milliseconds.
  • High-frequency systems where second rounding changes behavior.
Misconception

Millisecond precision is always better — not true. Prefer it only when needed to avoid complexity.

Examples
SET token:one_time "xyz"
PEXPIRE token:one_time 1500   # expires in 1500 milliseconds
PTTL token:one_time           # returns milliseconds remaining
Why care

Small differences in expiry can affect token validity and rate limit accuracy in tight windows; choose the correct granularity for your use case.
