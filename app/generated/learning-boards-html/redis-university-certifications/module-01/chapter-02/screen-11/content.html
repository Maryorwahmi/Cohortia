Module 1 › Chapter 1.2 › Hands-on: Counter & Session
Terminal Demo
# 1. Initialize page view counter
SET page:views:/products/1 0

# 2. Simulate 5 page views
INCR page:views:/products/1
INCR page:views:/products/1
INCR page:views:/products/1
INCR page:views:/products/1
INCR page:views:/products/1

# 3. Retrieve current page view count
GET page:views:/products/1

# 4. Set a user session with expiration
SET user:session:abc "{\"user_id\": 123, \"username\": \"testuser\", \"login_time\": \"2023-10-27T10:00:00Z\"}"
EXPIRE user:session:abc 60

# 5. Check TTL immediately
TTL user:session:abc
# Wait 10 seconds, then TTL again

# 6. Use MSET for product details
MSET product:1:name "Laptop Pro" product:1:price "1200.00" product:1:category "Electronics"

# 7. Use MGET to retrieve values
MGET product:1:name product:1:price product:1:category product:2:name
Explanation & Checks
  • Initialize counters to numeric values to avoid INCR errors.
  • Observe TTL decreasing after waiting; -2 indicates a missing key, -1 indicates no TTL.
  • MGET preserves the order of returned values and uses (nil) for missing keys.
Check your understanding

After running the sequence, confirm the page view count equals the number of INCR commands and that TTL decreased as expected. Think about how you would refresh a session TTL on user activity.
