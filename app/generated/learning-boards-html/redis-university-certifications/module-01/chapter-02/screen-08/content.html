Why use INCRBY
  • Reduces network round-trips for batch changes.
  • Preserves atomicity for multi-unit updates.
  • Useful for bulk event processing or reversing deltas.
Edge cases

Be cautious with negative results if your application requires counters to remain non-negative. Validate the returned value and implement guard logic if needed.

Example in redis-cli
SET views 0
INCRBY views 10    # returns 10
DECRBY views 3     # returns 7
Design question

Prefer INCRBY when applying grouped updates; prefer single INCR calls when events arrive individually and immediate consistency per event matters.
