Module 1 › Chapter 1.2 › EXPIRE and TTL
Flow
  1. SET key value to store data.
  2. EXPIRE key seconds to assign a TTL.
  3. Use TTL key to inspect remaining lifetime in seconds.
  4. Optionally use PERSIST key to remove the expiration.
Common mistakes
  • Not setting expiry for session-like keys leads to memory growth.
  • Assuming TTL returns 0 instead of -1 for keys without expire.
Command examples
SET user:session:123 "user_data_serialized"
EXPIRE user:session:123 3600
TTL user:session:123  # returns remaining seconds
PERSIST user:session:123  # remove expiration
Why it matters

Expirations keep Redis memory bounded and make cached and session data self-healing without manual cleanup jobs.

Key Takeaway

Use EXPIRE/TTL/PEXPIRE/PTTL and PERSIST to manage and debug lifetimes for temporary data like sessions and caches.
