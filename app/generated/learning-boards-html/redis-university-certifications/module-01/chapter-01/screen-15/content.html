Key Concepts
Three compact cards to remember.
Redis (In-Memory)
An in-memory data structure store used as a database, cache, and message broker for low-latency needs.
Key-Value Store
Data stored as string keys mapping to typed values like strings, lists, sets, hashes, and sorted sets.
Caching Pattern
Check cache first, fallback to DB on misses, then populate Redis with expiry to reduce load and latency.
Summary takeaway
Redis provides fast, in-memory primitives that simplify many real-time and low-latency patterns; use clear key naming and TTLs to keep data manageable.
