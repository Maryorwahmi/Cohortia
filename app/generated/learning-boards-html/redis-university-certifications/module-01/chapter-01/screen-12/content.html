Hands-on Activity
Practice SET and GET
A step-by-step terminal walkthrough to make these commands second nature.
Steps
  1. Start the server: redis-server (if not running).
  2. Open redis-cli and confirm the prompt appears.
  3. SET my_name "Your Name Here" and expect OK.
  4. GET my_name and confirm the returned string.
  5. SET my_city "New York City" and GET it back to test quoting.
  6. GET a non-existent key and observe (nil).
Try this
# redis-cli
SET my_name "Your Name Here"
GET my_name
SET my_city "New York City"
GET my_city
GET favorite_color  # expect (nil)
Key Takeaway

This short lab teaches environment verification, the SET/GET loop, quoting rules, and handling missing keys, which are the building blocks for more advanced Redis usage.
