Best Practice
Key naming conventions
Use predictable, colon-separated namespaces for clarity and maintainability.
Pattern
namespace:entity-id:attribute — e.g., user:123:profile
Benefits
Discoverability, consistent access patterns, and easier debugging in operations.
Pitfalls
Avoid embedding frequently changing values in keys and keep key lengths reasonable.
Concrete examples
Session
session:abc123 → small JSON or token with TTL.
Counter
product:456:views → integer incremented on each view.
Profile
user:123:profile → JSON or hash fields storing profile attributes.
Key Takeaway

Design keys for people and code: consistent, readable namespaces help your team operate and reason about data quickly.
