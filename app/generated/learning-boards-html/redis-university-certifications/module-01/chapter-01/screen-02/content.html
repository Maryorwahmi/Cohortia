Learning Objectives
Learn, understand, apply, and build confidence with Redis fundamentals.
Bloom
Learn
Understand
Apply
Master
Each objective maps to a measurable milestone for hands-on practice.
01
Explain Redis
Describe Redis as an in-memory data structure store and when to choose it over a relational DB. This matters for architecture decisions.
VERIFIED COMPETENCY MILESTONE
02
Identify Use Cases
Recognize when caching, sessions, leaderboards, pub/sub, or rate limiting are good fits. Map each use case to Redis features.
VERIFIED COMPETENCY MILESTONE
03
Understand Key-Value Model
Explain that every item is a string key mapping to a typed value, such as strings, lists, sets, hashes, and sorted sets.
VERIFIED COMPETENCY MILESTONE
04
Run Redis Locally
Install or start redis-server, open redis-cli, and perform SET and GET commands to verify behavior in your terminal.
VERIFIED COMPETENCY MILESTONE
