Setup & Tools
Install and run Redis locally
Install with your system package manager and verify the server is running before using redis-cli.
Linux (Debian/Ubuntu)
# sudo apt update
# sudo apt install redis-server
# sudo systemctl status redis-server
macOS (Homebrew)
# brew install redis
# redis-server   # run in foreground for testing
# redis-cli
Verification
Open a new terminal and run redis-cli. If you see a prompt like 127.0.0.1:6379>, you are connected to the local server and ready to run commands.
Quick troubleshooting
  • If redis-cli fails to connect, ensure redis-server is running.
  • Check firewall or port conflicts if listening fails on 6379.
  • Run redis-server in the foreground during testing to view logs.
Key Takeaway
Install, start the server, and use redis-cli to confirm connectivity before executing commands.
