What to Remember
Commands, tools, and quick fixes to keep top of mind.
redis-cli
Use the CLI to connect and execute commands; the prompt indicates successful connection to 127.0.0.1:6379 by default.
SET & GET
SET stores strings and returns OK; GET returns the stored value or (nil) for absent keys. Practice these to confirm your setup.
Quoting & Keys
Quote multi-word values and adopt colon-separated keys like user:123:profile for clarity and consistency.
Final thought
Practice the SET/GET loop and think about where Redis could improve latency in an app you use daily. That reflection connects the tool to real design decisions.
