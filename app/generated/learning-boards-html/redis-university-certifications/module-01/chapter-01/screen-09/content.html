Hands-on
SET and GET in redis-cli
Store and retrieve simple string values using the command-line client.
SET mykey "Hello Redis!"
OK

GET mykey
"Hello Redis!"

GET non_existent_key
(nil)
Notes
Keys are case-sensitive. Quote values containing spaces or special characters. (nil) is returned for missing keys.
Common mistake
Running redis-cli before starting the server causes a connection error. Start redis-server first.
Concrete exercise
  1. Start redis-server if needed.
  2. Open redis-cli and run SET my_name "Your Name Here".
  3. GET the key to verify your value appears.
Key Takeaway

Mastering SET and GET is the first concrete step to interacting with Redis and validating your environment.
