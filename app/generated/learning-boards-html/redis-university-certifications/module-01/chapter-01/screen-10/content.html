Tip
If you see a syntax error, check for unquoted multi-word values or verify that the server is running.
Common mistakes
  • Forgetting to start redis-server before using redis-cli.
  • Omitting quotes for values with spaces, producing syntax errors.
  • Confusing (nil) with an empty string; handle both cases in your app logic.
Misconception check

(nil) does not mean an error; it means the key is absent, which is a normal and testable condition in caching and lookup logic.
