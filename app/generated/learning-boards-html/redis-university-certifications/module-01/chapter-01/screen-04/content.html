Core Concept
What is Redis?
An in-memory store exposing typed values for ultra-fast operations.
Dictionary metaphor
Think of Redis as a super-fast dictionary: every unique key maps to a value stored in RAM. Keys are strings and values can be several data types for different needs.
Example
Store a user's profile: key = user:123:profile, value = JSON string. Or keep a view counter: key = product:456:views, value = integer you increment.
Misconception
Redis is not only a cache. Its native operations and data types support patterns beyond short-term caching, such as leaderboards and pub/sub messaging.
Key Takeaway

Redis stores typed values in RAM for extremely fast operations and supports multiple roles in application architectures.

Value types
String
Basic text or number stored under a key.
List
Ordered collection you can push and pop from ends.
Set
Unordered unique collection for membership checks.
Hash
Field-value map, useful for structured objects like profiles.
Sorted Set
Unique members with a score for ranking, great for leaderboards.
Concrete scenario
For a game leaderboard, use a sorted set where member IDs map to scores. Increment scores atomically to keep rankings accurate under high load.
