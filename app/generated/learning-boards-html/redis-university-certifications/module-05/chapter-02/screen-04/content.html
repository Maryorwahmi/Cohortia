Module 5 › Chapter 5.2 › What is Redis Sentinel?
Redis Sentinel in a sentence
A distributed supervisor that monitors Redis instances and automates failover without storing application data.
Core responsibilities
  • Monitoring: check master and replicas for reachability and health.
  • Notification: report events to administrators or programs.
  • Automatic failover: elect leader and promote a replica when necessary.
Concrete example
With three Sentinels, two must agree that the master is down if the quorum is set to two. The remaining Sentinels can continue monitoring if one fails.
Key Takeaway

Sentinel is about supervision and coordinated action, not about data replication.

Misconception Check
People sometimes run a single Sentinel and assume monitoring is highly available. A single Sentinel creates a monitoring single point of failure and cannot guarantee coordinated failover if it itself is unreachable.
Analogy
Think of Sentinels as a council: they vote and act together. One missing council member should not prevent the council from making decisions.
