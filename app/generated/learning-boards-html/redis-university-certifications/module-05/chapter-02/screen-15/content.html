Module 5 › Chapter 5.2 › Operational Checklist
1. Multiple Sentinels
Deploy at least three Sentinels on separate hosts so quorum can be reached if one fails.
2. Network rules
Open required ports and ensure bi-directional connectivity among Sentinels and Redis nodes.
3. Test failover
Simulate master shutdown and verify sdown → odown → promotion and client discovery of the new master.
Final thought

Automated failover reduces manual work but requires careful deployment, network configuration, and testing to be effective in production.
