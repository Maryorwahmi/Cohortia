Module 5 › Chapter 5.2 › Client Discovery
Discovery pattern
Clients register one or more Sentinel endpoints and ask for the current master's address under a service name like mymaster.
Example behavior
After failover, clients that query Sentinels learn the new master's IP and reconnect automatically without manual changes.
Deployment advice
Provide clients with multiple Sentinel endpoints so the client can still discover the master if a Sentinel host is unreachable.
Pitfall
If Sentinels are blocked by firewall rules, clients cannot discover the master and will fail to reconnect after a promotion.
