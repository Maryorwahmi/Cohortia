Module 5 › Chapter 5.2 › Key Concepts
Redis Sentinel
Distributed monitoring and automatic failover supervisor, not a data replica.
Quorum
Minimum Sentinels that must agree on failure before failover proceeds.
Client Discovery
Clients query Sentinels for the current master address to reconnect after failover.
Takeaway

Design Sentinel deployments with quorum and network reliability in mind, test failovers, and let clients use Sentinel for master discovery to achieve resilient Redis services.
