Minimal sentinel.conf
port 26379
daemonize yes
pidfile /var/run/redis-sentinel.pid
logfile "/var/log/redis-sentinel.log"
dir /tmp
sentinel monitor mymaster 127.0.0.1 6379 2
sentinel down-after-milliseconds mymaster 5000
sentinel failover-timeout mymaster 60000
sentinel parallel-syncs mymaster 1
The sentinel monitor line sets service name, IP, port and quorum. The other parameters tune detection and failover timing and synchronization.
Parameter guide
sentinel monitor
Defines monitored master name, address and quorum count used for objective down decisions.
down-after-milliseconds
How long a node must be unreachable for an individual Sentinel to mark it subjectively down.
failover-timeout
Upper bound for failover operations; prevents infinite or overly long elections.
Key takeaway

A small sentinel.conf is enough to get started, but test the values and quorum in your environment before relying on automatic failover.
