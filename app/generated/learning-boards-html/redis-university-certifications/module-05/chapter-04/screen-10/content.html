Redistributing Data with Resharding

Balancing hash slots across master nodes for optimal performance and capacity.

1

Initiate Resharding

Run `redis-cli --cluster reshard :` to start the interactive process.

2

Define Slot Movement

Specify the number of slots to move, source nodes, and the target node (e.g., a new master).

3

Execute Migration

Redis handles the actual data migration slot by slot, ensuring consistency during the process.

Key Takeaway

Resharding is an interactive process that allows you to dynamically redistribute hash slots and data across your master nodes, crucial for scaling and balancing.
