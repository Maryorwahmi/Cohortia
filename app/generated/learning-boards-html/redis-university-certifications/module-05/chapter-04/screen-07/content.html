Using `redis-cli --cluster create`

The command to initialize and assign roles within your new cluster.

Command Structure

Provide a list of all initial master nodes (IP:port) followed by the `--cluster-replicas` option.

`--cluster-replicas `

Specifies how many replicas each master node should have. The `redis-cli` tool will automatically assign available nodes as replicas.

Automated Slot Assignment

The tool handles the complex process of distributing hash slots across masters and associating replicas.

Example: Creating a 3-Master, 3-Replica Cluster

# Start 6 Redis instances (e.g., 7000-7005) in cluster mode first.

redis-cli --cluster create \
    127.0.0.1:7000 127.0.0.1:7001 127.0.0.1:7002 \
    127.0.0.1:7003 127.0.0.1:7004 127.0.0.1:7005 \
    --cluster-replicas 1

# Output will prompt for confirmation:
# >>> Performing hash slots allocation on 6 nodes...
# ...
# Can I set the above configuration? (type 'yes' to accept): yes
Key Takeaway

The `create` command streamlines cluster initialization, handling complex slot and replica assignments automatically.
