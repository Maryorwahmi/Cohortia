Expanding Your Cluster: Adding a New Master

Increasing capacity by integrating a new master node.

Command Syntax

Use `redis-cli --cluster add-node <new_node_ip>:<new_node_port> <existing_node_ip>:<existing_node_port>`.

Initial State

A newly added master node will initially have no hash slots assigned to it, meaning it won't store any data yet.

Next Step: Resharding

After adding a master, you must use `redis-cli --cluster reshard` to move hash slots from existing masters to the new one.

Example: Adding a Master on Port 7006

# 1. Start the new Redis instance (e.g., on port 7006) in cluster mode.
redis-server redis-7006.conf

# 2. Add the new node to the cluster, using an existing node (e.g., 7000) as reference.
redis-cli --cluster add-node \
    127.0.0.1:7006 \
    127.0.0.1:7000

# Output will confirm the node has joined.
# >>> Adding node 127.0.0.1:7006 to cluster 127.0.0.1:7000
# >>> Performing Cluster Check (using node 127.0.0.1:7000)
# ...
Key Takeaway

Adding a new master node is a two-step process: first, add the node, then reshard slots to it to distribute data.
