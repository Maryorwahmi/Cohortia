Key Concepts

Continuing our review of essential takeaways.

`--cluster-replicas`

Option used during cluster creation to specify the number of replicas per master node.

`redis-cli --cluster add-node`

Command to add a new master or replica node to an existing Redis Cluster.

`redis-cli --cluster reshard`

Command to redistribute hash slots and data between master nodes in a cluster.

Summary Takeaway

Effective Redis Cluster management involves using specific `redis-cli` commands for scaling, data rebalancing, and continuous health monitoring to ensure robust and efficient operations.
