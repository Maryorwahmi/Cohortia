Safely Removing Nodes from Your Cluster

Steps to decommission master or replica nodes without data loss.

`redis-cli --cluster del-node`

The command used to remove a node from the cluster. It requires the cluster's IP:port and the node's unique ID.

Removing a Replica

A straightforward process; the cluster automatically adjusts after the replica is removed.

Removing a Master (Critical Step)

Before removing a master node, you must first reshard all its hash slots to other master nodes. Attempting to remove a master with slots will fail.

Example: Removing a Replica Node

# 1. Get the node ID of the replica to be removed (e.g., 127.0.0.1:7007)
redis-cli -p 7000 cluster nodes
# Example output: 
# 1a2b...3c4 replica 9d7c...c2e 0 1678234567000 1 connected
# (Let's assume replica ID is '1a2b...3c4')

# 2. Remove the replica node.
redis-cli --cluster del-node \
    127.0.0.1:7000 \
    1a2b...3c4

# Output will confirm removal.
# >>> Removing node 1a2b...3c4 from cluster 127.0.0.1:7000
Key Takeaway

Always reshard a master's slots before attempting to remove it; replicas can be removed directly.
