Monitoring Redis Cluster Health

Tools and commands to verify the operational status and data distribution.

`redis-cli --cluster check`

Provides a comprehensive overview of the cluster's health, including node status and hash slot distribution.

`CLUSTER INFO`

Returns general information and statistics about the cluster's state, such as `cluster_state:ok`.

`CLUSTER NODES`

Lists all nodes in the cluster, their roles, IDs, and assigned hash slots, crucial for detailed inspection.

Example: Checking Cluster Status

# Check overall cluster health
redis-cli --cluster check 127.0.0.1:7000

# Get detailed cluster information from a node
redis-cli -p 7000 CLUSTER INFO

# List all nodes and their details
redis-cli -p 7000 CLUSTER NODES

# Example output for CLUSTER INFO:
# cluster_state:ok
# cluster_slots_assigned:16384
# cluster_known_nodes:6
# ...
Key Takeaway

Regularly using `redis-cli --cluster check`, `CLUSTER INFO`, and `CLUSTER NODES` is vital for proactive cluster health monitoring and troubleshooting.
