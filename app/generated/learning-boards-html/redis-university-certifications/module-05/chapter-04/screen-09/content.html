Enhancing Redundancy: Adding a New Replica

Strengthening fault tolerance by assigning a new replica to a master.

Command Syntax

Use `redis-cli --cluster add-node <new_replica_ip>:<new_replica_port> <existing_node_ip>:<existing_node_port> --cluster-slave --cluster-master-id <master_node_id>`.

`--cluster-slave`

Designates the new node as a replica, rather than a master.

`--cluster-master-id`

Specifies the unique 40-character ID of the master node this new replica should follow. Obtain this ID using `CLUSTER NODES`.

Example: Adding a Replica to Master 7000

# 1. Start the new Redis instance (e.g., on port 7007) in cluster mode.
redis-server redis-7007.conf

# 2. Get the node ID of the master (e.g., 127.0.0.1:7000)
redis-cli -p 7000 cluster nodes
# Example output: 
# 9d7c...c2e master - 0 1678234567000 1 connected 0-5460
# (Let's assume master ID is '9d7c...c2e')

# 3. Add the new node as a replica to master 7000.
redis-cli --cluster add-node \
    127.0.0.1:7007 \
    127.0.0.1:7000 \
    --cluster-slave \
    --cluster-master-id 9d7c...c2e
Key Takeaway

Adding a replica requires specifying its master's node ID to ensure correct replication and failover capabilities.
