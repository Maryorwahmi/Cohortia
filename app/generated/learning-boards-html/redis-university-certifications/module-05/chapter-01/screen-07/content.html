Module 5 › Chapter 5.1 › Configuring Replicas
Command example
# On the replica's redis-cli
REPLICAOF 127.0.0.1 6379
This tells the running instance to connect to the master and begin synchronization immediately.
Configuration file example
# redis-replica1.conf
port 6380
replicaof 127.0.0.1 6379
daemonize yes
Putting replicaof in redis.conf makes the replica join automatically on restart.
Misconception
Don't assume REPLICAOF will configure persistence or network rules; those are separate concerns.
Pro tip
Script your configs so each instance has predictable ports, data dirs, and replicaof settings for reproducible labs.
Key Takeaway
REPLICAOF and replicaof are the primary mechanisms to attach a replica to a master; verify the connection with INFO replication.
