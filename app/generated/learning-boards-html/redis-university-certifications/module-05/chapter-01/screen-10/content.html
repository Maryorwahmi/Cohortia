Module 5 › Chapter 5.1 › Monitoring Replication
Sample INFO replication (master)
# role:master
connected_slaves:2
slave0:ip=127.0.0.1,port=6380,state=online,offset=102400,lag=0
slave1:ip=127.0.0.1,port=6381,state=online,offset=102400,lag=0
master_repl_offset:102400
Sample INFO replication (replica)
# role:replica
master_host:127.0.0.1
master_port:6379
master_link_status:up
master_repl_offset:102000
Interpretation
Compare master_repl_offset values to estimate bytes of lag. Use this with load patterns to understand real impact.
Misconception
Offset difference is not a direct time measure; it should be correlated with observed delays and throughput.
Key Takeaway
INFO replication is the first-line tool to detect replication lag and link problems; monitor offsets and link status regularly.
