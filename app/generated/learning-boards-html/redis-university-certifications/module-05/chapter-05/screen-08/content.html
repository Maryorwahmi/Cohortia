Essential Redis Metrics to Track

Understanding the vital signs of your Redis instances and clusters.

Resource Utilization

  • **Memory Usage:** `used_memory_rss` (actual RAM consumed), `used_memory_peak`.
  • **CPU Utilization:** System and user CPU usage.
  • **Connected Clients:** `connected_clients`, `blocked_clients`.

Data & Replication

  • **Keyspace Statistics:** Number of keys, expires.
  • **Replication Lag:** `master_repl_offset` vs `replica_repl_offset`.
  • **Persistence Status:** AOF/RDB enabled, rewrite status.

Deployment Specifics

  • **Sentinel:** Sentinel instance status, view of Redis instances.
  • **Cluster:** Node health, slot distribution, `CLUSTER FAILOVER_STATE`.
  • **Alerts:** Critical thresholds for proactive issue resolution.
Key Takeaway

A holistic view of Redis health requires monitoring resource usage, data characteristics, replication status, and deployment-specific metrics.
