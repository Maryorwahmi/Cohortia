Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Explain sharding and scaling
Describe why a single master cannot scale and how sharding partitions the dataset across nodes. This skill helps you plan capacity growth for memory and write throughput.
VERIFIED COMPETENCY MILESTONE
02
Describe Redis Cluster architecture
Explain hash slots, master and replica roles, and how nodes own ranges of slots. This helps in planning topology and failover strategies.
VERIFIED COMPETENCY MILESTONE
03
Map keys to hash slots
Use the CRC16(key) modulo 16384 calculation to determine slot assignment and reason about distribution. This matters for even data spread and predictable routing.
VERIFIED COMPETENCY MILESTONE
04
Identify trade-offs and limitations
Recognize limits like multi-key operations across slots and unsupported global commands. Learn data-modeling techniques like hash tags to work around constraints.
VERIFIED COMPETENCY MILESTONE
