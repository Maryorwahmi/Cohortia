Final Notes
What to Remember
Three concise reminders for operating Redis Cluster effectively.
Replicas
Provide failover for a shard; they do not increase writable capacity of the cluster.
Clients
Must be cluster-aware to compute slots and follow MOVED responses for correct routing.
Key design
Use hash tags to co-locate related keys and avoid global commands by maintaining targeted indexes.
Final takeaway

Redis Cluster lets you scale horizontally but requires deliberate client and key design. Apply these reminders to avoid common pitfalls during scaling and operations.
