Definition
What is Redis Cluster?
Distributed sharding plus per-shard replication for availability and scaling.
Cluster components
  • • Masters: own one or more hash slot ranges and serve writes for those slots.
  • • Replicas: mirror a master’s data and can be promoted if the master fails.
  • • Cluster-aware clients: compute the key’s slot and send commands to the correct node.
Cluster combines sharding and replication: each shard is a master with its own replica set, so failure of one master affects only its slots, not the whole dataset.
Operational notes
Adding or removing nodes requires moving slot ownership and migrating data. Clients should handle MOVED redirections during topology changes. Because nodes own ranges of slots, many operations are local to a node if the key’s slot is known.
Example: Master A owns slots 0–5000, Master B 5001–10000, Master C 10001–16383
Key Takeaway

Redis Cluster is a sharded Redis with per-shard replication, enabling larger datasets and fault recovery per shard rather than cluster-wide downtime.
