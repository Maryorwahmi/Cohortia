Module 5 › Chapter 5.3 › Learning Objectives
How you'll apply these skills
Trace client routing
Understand how a cluster-aware client computes a slot and connects directly to the node owning it. This prevents unnecessary hops and improves latency.
Handle MOVED redirections
Learn how clients receive a MOVED response and retry on the indicated node automatically, keeping operations consistent.
Use hash tags
Force related keys into the same slot using curly braces so multi-key commands can succeed. This shapes your data model.
Choose the right pattern
Decide between clustering and master-replica with Sentinel based on multi-key needs and capacity growth plans.
