Comparison
Benefits and trade-offs compared to Sentinel
Pick the deployment pattern that matches capacity and data-model needs.
Master-replica + Sentinel
  • • Simpler semantics: single master holds full dataset.
  • • Supports global commands and multi-key ops across the dataset.
  • • Limited by single server memory and write capacity.
Redis Cluster
  • • Shards data across nodes for larger storage and higher write throughput.
  • • Provides per-shard replication and automatic failover.
  • • Restricts multi-key ops across slots and disallows certain global commands.
Key Takeaway

Choose Sentinel if your workload needs global operations and you cannot shard; choose Cluster to scale capacity and writes, and design keys around slot rules.
