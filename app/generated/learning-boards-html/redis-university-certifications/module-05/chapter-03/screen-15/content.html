What to Remember
Key Concepts
Three compact concept cards and a summary takeaway.
Sharding
Partitioning the dataset across multiple nodes to increase total storage and throughput.
Hash Slots
16,384 logical slots map keys to nodes using CRC16(key) modulo 16384.
Hash Tags
Use curly braces to force multiple keys to the same slot for multi-key operations.
Summary

Redis Cluster shards data across 16,384 slots with per-shard replication for availability. Clients must be cluster-aware and keys must be modeled to respect slot constraints when multi-key operations are required.
