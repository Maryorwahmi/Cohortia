Hash slots and key mapping
Deterministic formula that routes keys to nodes.
The mapping rule
CRC16(key) % 16384
This computation yields a number between 0 and 16383. Clients and nodes use that slot number to determine ownership. The deterministic nature means the same key always hashes to the same slot until slot ownership changes in the cluster.
Misconception: hashing instantly balances load for any key naming. In practice, choose key names with sufficient entropy across the full string to avoid hotspots.
What clients do
  • • Compute slot from the key using the CRC16 formula.
  • • Send the command directly to the node that owns that slot.
  • • If they receive MOVED, update topology and retry on the correct node.
Key Takeaway

The CRC16 modulo 16384 mapping makes slot assignment deterministic, enabling direct routing and predictable partitioning of keys across the cluster.
