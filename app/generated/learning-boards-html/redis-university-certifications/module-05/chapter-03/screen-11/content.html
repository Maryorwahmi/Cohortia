Definition
Hash tags: forcing keys into the same slot
Curly braces let you pick which substring is hashed for slot assignment.
How it works
user:{100}:profile
user:{100}:cart
order:{ABC}:items
order:{ABC}:details
Keys that share the same inner braces content hash to the same slot and can be used together in multi-key commands.
Design guidance
  • • Use tags for related records that require multi-key operations.
  • • Avoid overusing the same tag value across large datasets to prevent hotspots.
  • • Tags do not change replication or failover behavior, only slot mapping.
Key Takeaway

Hash tags let related keys be co-located in one slot so multi-key operations succeed; use them judiciously to avoid creating hotspots.
