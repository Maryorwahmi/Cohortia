Definition
Unsupported commands and single-database model
Cluster avoids commands that require a global dataset view.
Not supported
  • • KEYS — not supported cluster-wide because keys live on different nodes.
  • • SELECT — Cluster only uses database 0; multiple logical DBs aren’t supported.
Design alternatives
Maintain application-level indexes or metadata keys co-located with hash tags for group lookups. Replace global scans with targeted queries and careful key modeling.
Common mistake

Trying to run KEYS on a single node will produce incomplete results because other nodes own other slots.
