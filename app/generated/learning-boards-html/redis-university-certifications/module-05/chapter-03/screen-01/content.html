Redis Cluster
Sharding with 16,384 hash slots for horizontal scaling
Interactive 16:9 Masterclass
This chapter explains how sharding enables Redis to store and serve datasets larger than one server can hold. You will see how hash slots partition the keyspace, how nodes claim slot ranges, and what client libraries must do to route commands correctly. Practical limits and data-modeling patterns like hash tags are covered so you can design cluster-friendly keys.
