Command Walkthrough

SET stores, GET retrieves

These commands show the simplest read/write loop in Redis and are ideal for first experiments in the CLI.

Example
SET my_name "Your Name Here" then GET my_name returns the stored string.
127.0.0.1:6379> SET mykey "Hello Redis!"
OK
127.0.0.1:6379> GET mykey
"Hello Redis!"

# Incorrect (missing quotes, will error)
127.0.0.1:6379> SET greeting Hello World!
(error) ERR wrong number of arguments for 'set' command

# Non-existent key
127.0.0.1:6379> GET favorite_color
(nil)
Common mistake
Leaving out quotes for multiword values produces syntax errors; always use quotes for strings with spaces.
