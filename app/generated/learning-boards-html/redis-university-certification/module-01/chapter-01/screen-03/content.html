Hands-on Objectives

Step-by-step confidence with local Redis and the CLI.

Terminal demo mode
Install & run
Use apt or brew to install and verify the redis-server process is running with system tools.
Mnemonic: install → verify → connect
Connect with redis-cli
Open redis-cli and confirm the prompt shows 127.0.0.1:6379 before issuing commands.
Mnemonic: host:port prompt
SET and GET
Practice storing values with SET mykey "value" and retrieving them with GET mykey.
Mnemonic: set → get → confirm
Common mistakes
Forgetting to start the server and not quoting multiword values are frequent beginner errors to watch for.
Mnemonic: server first, then quotes
