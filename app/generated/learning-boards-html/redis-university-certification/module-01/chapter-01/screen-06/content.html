Definition

Keys and naming

Keys are strings used to uniquely identify values. Use colons to form readable namespaces like user:42:profile for maintainability.

Example
product:456:views -> integer counter incremented on each view.
Misconception
Key-value stores do not mean only strings in Redis; several native value types are supported.
Takeaway
Naming conventions and the variety of value types make the key-value model both simple and powerful.
Common value types
  • Strings for plain text or JSON payloads.
  • Lists for ordered sequences such as message queues.
  • Sets for unique collections and membership checks.
  • Hashes for small objects with field lookup.
  • Sorted sets for leaderboards with scores.
Practical tip
Use descriptive keys and keep values focused — large blobs belong in a primary database, with Redis used for hot access to references or summaries.
