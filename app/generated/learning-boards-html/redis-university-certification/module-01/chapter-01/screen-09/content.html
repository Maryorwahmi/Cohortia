Tooling

Connect and interpret replies

The prompt confirms connection and replies like OK or (nil) tell you the server state. Learn to read them correctly.

Quick checks
  • Prompt shows host:port on success.
  • OK means a write was accepted.
  • (nil) means the key was not found.
CLI examples
127.0.0.1:6379> SET mykey "Hello Redis!"
OK
127.0.0.1:6379> GET mykey
"Hello Redis!"
127.0.0.1:6379> GET non_existent_key
(nil)
Common mistake
Do not treat (nil) as a crash — it simply signals a missing key. Quoting multiword values avoids syntax errors.
