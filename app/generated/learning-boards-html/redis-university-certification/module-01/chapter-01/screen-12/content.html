Module 1 › Chapter 1.1 › Key Concepts
In-memory store
Redis keeps data in RAM for very low-latency operations.
Key-value model
Unique string keys map to values; values can be multiple native types.
CLI basics
Use redis-cli to SET and GET strings and interpret replies like OK and (nil).
Summary takeaway

Redis gives you memory-speed access via keys; use it for hot data and learn the CLI basics to verify and experiment safely.
