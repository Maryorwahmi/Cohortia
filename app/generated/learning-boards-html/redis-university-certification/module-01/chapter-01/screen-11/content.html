Hands-on activity

Set and get three keys

Follow these steps in your terminal to practice basic CLI commands and error handling.

# Ensure server is running
# redis-server

# In another terminal, open CLI
redis-cli

# 1. Set your name
SET my_name "Your Name Here"
GET my_name

# 2. Set your age as a string
SET my_age "30"
GET my_age

# 3. Set your city (use quotes if needed)
SET my_city "New York City"
GET my_city

# 4. GET a non-existent key
GET favorite_color

# 5. Incorrect SET to observe error
SET greeting Hello World!
# then correct it
SET greeting "Hello World!"
GET greeting
What to observe
  • OK reply after a successful SET.
  • Quoted values returned exactly by GET.
  • (nil) when requesting missing keys.
  • Syntax error when quotes are omitted for multiword values.
