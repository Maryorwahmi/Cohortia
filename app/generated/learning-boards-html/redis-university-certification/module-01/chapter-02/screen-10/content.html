Module 1 › Chapter 1.2 › GETRANGE / SETRANGE
Examples
SET mylongstring "This is a very long string."
GETRANGE mylongstring 0 3    # -> "This"
GETRANGE mylongstring 10 14  # -> "very "

SET greeting "Hello World"
SETRANGE greeting 6 "Redis"
GET greeting                   # -> "Hello Redis"
Notice SETRANGE overwrites bytes starting at an offset. If the target offset is larger than the current length, Redis pads the value with null bytes. This behavior is important when manipulating binary chunks.
When to prefer hashes
If you find yourself routinely replacing different fields inside a serialized value, a hash structure that stores each field separately may be easier to work with than repeated SETRANGE edits.
Check your understanding
Does SETRANGE insert or replace? It replaces at the offset and may extend the string with padding, it does not shift bytes.
