Module 1 › Chapter 1.2 › SET/GET vs MSET/MGET
Single vs Bulk
# Single requests (3 round trips)
GET product:1:name
GET product:1:price
GET product:1:category

# Bulk request (1 round trip)
MGET product:1:name product:1:price product:1:category
Mapping results
MGET returns values in the same order as keys. If a key is missing, its slot is nil. Map by position, not by key name.
When to use
  • Use MGET when you need several related values at once to reduce latency.
  • Use MSET when setting multiple keys together, for atomic multi-key writes.
  • For independent keys that are rarely fetched together, single GETs may be fine.
Key Takeaway

Bundle related reads and writes with MGET and MSET to reduce network trips and simplify client logic; handle nils for missing keys.
