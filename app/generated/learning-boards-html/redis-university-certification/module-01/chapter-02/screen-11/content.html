Module 1 › Chapter 1.2 › Hands-on Activity
Starter commands
# 1. Initialize page view counter
SET page:views:/products/1 0

# 2. Simulate 5 page views
INCR page:views:/products/1
INCR page:views:/products/1
INCR page:views:/products/1
INCR page:views:/products/1
INCR page:views:/products/1

# 3. Retrieve current page view count
GET page:views:/products/1

# 4. Set a user session with expiration
SET user:session:abc "{\"user_id\": 123, \"username\": \"testuser\", \"login_time\": \"2023-10-27T10:00:00Z\"}"
EXPIRE user:session:abc 60

# 5. Check TTL
TTL user:session:abc
# Wait 10 seconds then TTL user:session:abc

# 6. Use MSET for product details
MSET product:1:name "Laptop Pro" product:1:price "1200.00" product:1:category "Electronics"

# 7. MGET product details
MGET product:1:name product:1:price product:1:category product:2:name
Expected observations & checks
  • After five INCR calls the GET should return "5". This proves atomic increments worked.
  • TTL should return a value near 60 immediately, and about 50 after waiting 10 seconds, confirming expiry counts down.
  • MGET returns values in the requested order; product:2:name returns nil when missing, indicating (nil) slots in the response.
Common gotcha
Remember to escape quotes in JSON strings inside your shell, or use single quotes outside the JSON to avoid syntax errors in the terminal.
