Module 1 › Chapter 1.2 › INCR / DECR family
Atomic numeric ops
# Initialize counter
SET page:views:/products/1 0

# Simulate views
INCR page:views:/products/1
INCR page:views:/products/1
DECR page:views:/products/1
INCRBY page:views:/products/1 10
DECRBY page:views:/products/1 5

# Read final value
GET page:views:/products/1
Example use
Page view counter: INCR is perfect because it avoids race conditions from concurrent requests.
Common mistake
Trying to INCR a non-numeric value will error. Validate or initialize values as integers before incrementing.
Checklist
  • Ensure the key is an integer or initialize it with SET key 0.
  • Use BY variants for batched increments to reduce repeat calls.
  • Prefer INCR family to read-modify-write sequences to avoid race conditions.
Key Takeaway

Use atomic commands for counters so multiple clients cannot produce incorrect values.
