Module 1 › Chapter 1.2 › PEXPIRE / PTTL
Millisecond timeout
# Set a very short lock for 250 milliseconds
SET resource:lock "locked"
PEXPIRE resource:lock 250
PTTL resource:lock   # returns remaining milliseconds
Use PEXPIRE when you need sub-second control. PTTL mirrors TTL but returns milliseconds. This helps reduce tiny race windows in short-lived operations like ephemeral locks or micro-batching windows.
Pitfalls & practical notes
  • Network latency can affect perceived expiry; the value stored is precise but your client may observe small delays.
  • When combining with INCR counters or rate limiting, ensure your token-bucket windows account for boundary cases.
  • Use PERSIST to cancel millisecond expirations when a key must be promoted to permanent storage.
