Module 2 › Chapter 1.3 › Manual Persistence
Commands explained
  • SAVE — synchronous RDB save; blocks Redis until complete.
  • BGSAVE — asynchronous RDB save; forks a child and continues serving clients.
  • BGREWRITEAOF — asynchronous AOF rewrite to compact the file.
Example workflow
redis-cli
SET testkey "rdb_value"
BGSAVE
SHUTDOWN
# restart redis-server
GET testkey
Operational tips
  • Prefer BGSAVE for manual snapshots to avoid blocking client traffic.
  • Inspect appendonly.aof in your data dir to verify AOF writes after enabling appendonly.
  • Run BGREWRITEAOF during lower load periods to reduce performance impact.
Key takeaway
Use non-blocking commands for routine maintenance and verify results by restarting and checking keys.
