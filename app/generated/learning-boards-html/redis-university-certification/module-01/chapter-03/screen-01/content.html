Explore Key Topics
RDB Snapshots
Compact binary backups created at intervals. Good for fast restarts and backups when some data loss is acceptable.
AOF Logging
A command journal of every write. Offers finer durability guarantees at the cost of larger files and longer restarts.
Configuration
Control persistence behavior using redis.conf directives like save, appendonly and appendfsync.
Concept Map
R
RDB Snapshot
Forks a child, writes a temporary RDB file, then replaces the old snapshot when complete.
A
AOF Log
Appends every write command; replayed on restart to rebuild the dataset.
C
Configuration
redis.conf controls save schedules, appendonly, appendfsync, and storage directory.
Key Takeaway

Combine RDB for compact backups and AOF for near-real-time durability in most critical deployments.
