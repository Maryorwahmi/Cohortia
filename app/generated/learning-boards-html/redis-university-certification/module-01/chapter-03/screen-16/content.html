Module 2 › Chapter 1.3 › Key Concepts
RDB snapshot
Point-in-time binary backups that are compact and fast to load; may lose recent writes.
AOF logging
Appends every write command for replay; tune appendfsync to balance durability and performance.
Combine for resilience
Use RDB for fast recovery and AOF for near-real-time durability; keep both backed up and tested.
Final takeaway

Practice configuration changes, run non-blocking saves, and verify restores so your persistence choices deliver the durability you expect.
