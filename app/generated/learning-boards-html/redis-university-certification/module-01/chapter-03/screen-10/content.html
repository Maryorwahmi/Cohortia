Common directives
  • save <seconds> <changes> — configures snapshot triggers.
  • appendonly yes/no — enables or disables AOF.
  • appendfsync always/everysec/no — controls fsync frequency for AOF.
  • appendfilename "appendonly.aof" — AOF filename.
  • auto-aof-rewrite-percentage — threshold for AOF rewrite.
  • dir /var/lib/redis — storage directory for RDB and AOF.
Config snippet
# RDB: save if at least 1 change in 60 seconds
save 60 1

# Disable AOF for test
# appendonly no

# Enable AOF and fsync every second
appendonly yes
appendfsync everysec

# Where files are stored
dir /var/lib/redis
appendfilename "appendonly.aof"
Practical tip
After changing redis.conf restart the Redis server and verify that files appear in the configured dir and that persistence behavior matches your expectations.
