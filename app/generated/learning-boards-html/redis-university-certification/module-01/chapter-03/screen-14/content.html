Module 2 › Chapter 1.3 › Common Mistakes
Blocking saves
Running SAVE in production blocks the server. Use BGSAVE to avoid downtime.
Disk full
If the persistence directory runs out of space during a save, the operation can fail—monitor capacity and clean up or expand storage.
AOF size and restarts
Long AOFs can slow restart. Use BGREWRITEAOF and tune auto-aof-rewrite-percentage to control growth.
Quick recovery checklist
  1. Check Redis logs and disk usage immediately.
  2. Free disk space if full and re-run BGSAVE or BGREWRITEAOF as appropriate.
  3. If restart is too slow from AOF, consider restoring the latest RDB snapshot then investigate AOF in a test environment.
