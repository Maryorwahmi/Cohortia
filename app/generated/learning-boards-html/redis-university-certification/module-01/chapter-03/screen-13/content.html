RDB test steps
# Edit redis.conf
save 60 1
appendonly no
# Restart redis

# Test
redis-cli
SET testkey "rdb_value"
BGSAVE
SHUTDOWN
# restart redis-server
GET testkey
Expect: testkey persists after restart if snapshot completed.
AOF test steps
# Edit redis.conf
appendonly yes
appendfsync everysec
# Restart redis

# Test
redis-cli
SET anotherkey "aof_value"
SHUTDOWN
# restart redis-server
GET anotherkey
# Inspect file in dir: appendonly.aof
Expect: anotherkey persists and appendonly.aof contains the SET command.
Final step: BGREWRITEAOF
Run BGREWRITEAOF to create a compact AOF. Verify the file size before and after the rewrite and confirm the dataset remains correct on restart.
