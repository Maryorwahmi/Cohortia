Module 2 › Chapter 2.1 › Atomic counters
How it works
INCR and INCRBY treat the stored string as an integer, incrementing it atomically. If the key is absent, Redis initializes it to zero first. This avoids race conditions even under heavy concurrent traffic.
Misconception check
Don't assume INCRBY can be mixed with non-numeric string content. If the value is not a valid integer, Redis will respond with an error.
When to use
  • Page views, likes, counters in web applications.
  • Rate limiter token buckets (combined with expiry).
  • Simple numeric metrics where atomicity matters.
Rapid CLI demo
redis-cli> INCRBY homepage:views 1
(integer) 1
redis-cli> INCRBY homepage:views 1
(integer) 2
redis-cli> GET homepage:views
"2"
Because increments are atomic, two clients issuing INCRBY simultaneously will receive distinct, ordered integer responses without lost updates.
