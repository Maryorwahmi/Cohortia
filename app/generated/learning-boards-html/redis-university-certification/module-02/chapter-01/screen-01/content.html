Module 2 › Chapter 2.1 › Strings & Hashes Overview
Strings and Hashes — The foundation of key-value stores
Practical rules for choosing between single-value Strings and field-mapped Hashes.
What you'll learn
How Strings support counters and multi-key operations, and how Hashes let you store objects with field-level updates.
Why this matters
Choosing the right type reduces memory, network overhead, and makes updates safe under concurrency.
In this lesson

We’ll compare commands, show atomic counters, and model a product profile using a Hash. Expect brief live-callout demos and a short hands-on activity to practice.

Concept snapshot
Interactive 16:9 Masterclass
String (single value)
Binary-safe, up to 512 MB. Good for counters, tokens, and compact blobs.
Hash (field map)
Multiple fields under one key for objects like user:1 {name,email,age} with atomic field updates.
