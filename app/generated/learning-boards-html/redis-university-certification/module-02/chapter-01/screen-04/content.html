Module 2 › Chapter 2.1 › Redis Strings
Definition
A binary-safe value up to 512 MB. Stores numbers, text, or blobs. Supports multi-key commands and atomic numeric ops.
Properties
  • Binary-safe — stores raw bytes unchanged.
  • Max size 512 MB — suitable for large blobs but consider memory costs.
  • Supports MSET/MGET, SETEX, APPEND, GETRANGE, SETRANGE.
  • Numeric operations: INCR, INCRBY, DECRBY are atomic.
Common misconception
Storing complex mutable objects as one JSON string is simple but inefficient when you need field-level updates; you'll rewrite the entire value each time.
Key Takeaway

Use Strings for single, often-fully-read or fully-written values and atomic numeric counters. Prefer other types when you need frequent partial updates.

Concrete examples
Session token
Store a serialized token that you read and verify as a whole.
Page view counter
Keep a numeric string and use INCRBY to update atomically under load.
Configuration blobs
Small static blobs that you always read and write entirely can be strings.
