Product as a hash
Use a single hash key per product to group fields and perform atomic stock updates.
Example fields:
  • name, description, price, stock_quantity, category
  • Use HINCRBY product:123 stock_quantity -1 to reduce stock atomically
  • Keep very large descriptions as separate keys if they are rarely changed
For high-traffic read paths, fetch only the fields needed for the UI to reduce bandwidth. For batch admin tasks, HGETALL remains convenient.
CLI pattern
HSET product:123 name "Phone" price 499 stock_quantity 10 category "mobile"
HINCRBY product:123 stock_quantity -1  # atomic decrement on purchase
HGET product:123 price stock_quantity
Design note
If temporary overrides are needed (like sale price for 1 hour), implement the override as its own key with TTL and merge values at read time.
