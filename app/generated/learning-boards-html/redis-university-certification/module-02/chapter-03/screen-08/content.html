Module 3 › Chapter 2.3 › Intro to Streams
Concept
Append-only, replayable log
Each entry contains field-value pairs and receives a monotonic ID. Streams are ideal for event sourcing and audit logs.
Durability
Streams persist entries and allow consumers to replay history, making them suitable for analytics and archiving workflows.
Example XADD
XADD user:activity:stream * event_type login user_id 101 ip_address 192.168.1.10
Why use Streams
They let producers write events without coordinating with consumers. Consumers can be added later to process history, making systems flexible and resilient.
