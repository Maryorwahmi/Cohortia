Module 3 › Chapter 2.3 › Range Queries
Rank-based
ZRANGE / ZREVRANGE
Request positions like top 10 or a slice by rank. Use when position matters, not absolute score.
Score-based
ZRANGEBYSCORE
Fetch members within numeric score bounds. Use for filters and thresholds based on value ranges.
Commands
ZRANGE leaderboard 0 9 WITHSCORES
ZREVRANGE leaderboard 0 4 WITHSCORES
ZRANGEBYSCORE leaderboard 100 150 WITHSCORES
Example scenario
A homepage shows the top five players by rank. A filter page shows all players with scores between 100 and 150. Both queries are efficient thanks to the skip list index.
