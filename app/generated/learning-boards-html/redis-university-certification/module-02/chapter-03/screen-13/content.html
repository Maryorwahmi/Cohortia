Module 3 › Chapter 2.3 › When to Use Which
Choose Sorted Set
Leaderboards, score-based rankings, priority queues where items are unique and numeric scores drive ordering.
Choose Stream
Event logging, audit trails, sensor data, and systems requiring replay or multiple independent services consuming the same events.
Common pitfalls
  • Using Sorted Sets when duplicates are needed.
  • Expecting XREAD to manage group acknowledgements without using consumer groups.
  • Forgetting to manage consumer group metadata after decommission.
Design tip
Model early: map your domain objects to either ordered unique items (Sorted Set) or immutable events (Stream) and validate with sample queries.
