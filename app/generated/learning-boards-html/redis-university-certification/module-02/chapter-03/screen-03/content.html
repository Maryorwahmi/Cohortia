Module 3 › Chapter 2.3 › Learning Objectives
Practical drills
Sorted Set drill
Add players, increment scores atomically, and show top three players. Practice ZINCRBY to avoid race conditions during concurrent updates.
Streams drill
Append user events, create a consumer group, and run two simulated consumers that XREAD GROUP and XACK messages to mark completion.
Visual mnemonic
Four boxes: Add, Query, Update, Delete for Sorted Sets; Append, Read, Group, Acknowledge for Streams. Map these boxes to commands during practice.
Starter commands
ZADD global:leaderboard 100 "player:alice" 150 "player:bob"
ZINCRBY global:leaderboard 20 "player:bob"
ZREVRANGE global:leaderboard 0 2 WITHSCORES

XADD user:activity:stream * event_type login user_id 101
XGROUP CREATE user:activity:stream analytics_group 0-0 MKSTREAM
