Module 3 › Chapter 2.3 › Simulate Stream & Group
Append events
XADD user:activity:stream * event_type login user_id 101 ip_address 192.168.1.10
XADD user:activity:stream * event_type page_view user_id 102 page_url /dashboard
Use automatic IDs so Redis generates unique, monotonic identifiers for each entry.
Create group & read
XGROUP CREATE user:activity:stream analytics_group 0-0 MKSTREAM
XREAD GROUP analytics_group consumer_1 COUNT 1 STREAMS user:activity:stream >
Consumers read new messages assigned to the group. Acknowledge processed items with XACK so the group knows they are complete.
Acknowledge example
XACK user:activity:stream analytics_group 1678881234567-0
If a consumer crashes before XACK, another consumer can claim pending entries to continue processing.
