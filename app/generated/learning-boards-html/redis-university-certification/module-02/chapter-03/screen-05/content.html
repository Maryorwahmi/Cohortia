Module 3 › Chapter 2.3 › Adding and Updating Scores
Step 1
Seed the leaderboard
Add initial members with ZADD before active scoring begins to establish baseline ranks.
Step 2
Increment during play
Use ZINCRBY to add points atomically so concurrent updates do not conflict.
Step 3
Query top players
Use ZREVRANGE with WITHSCORES to present the leaderboard in descending order.
Commands in practice
ZADD global:leaderboard 100 "player:alice" 150 "player:bob" 75 "player:charlie"
ZINCRBY global:leaderboard 20 "player:bob"
ZREVRANGE global:leaderboard 0 2 WITHSCORES
Common misconception
Calling ZADD to add what you think of as a delta will replace the score rather than increment. Use ZINCRBY for deltas to ensure atomicity.
