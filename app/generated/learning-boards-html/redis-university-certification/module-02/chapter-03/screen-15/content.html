Module 3 › Chapter 2.3 › Key Concepts
Redis Sorted Set (ZSET)
Unique strings with numeric scores, ordered by score for leaderboards and priority queues.
ZADD / ZINCRBY
Add or set scores with ZADD; increment atomically with ZINCRBY to avoid race conditions.
Redis Stream
Append-only, replayable entries with unique IDs. Use consumer groups for distributed, reliable processing.
Key Takeaway

Pick Sorted Sets when numeric ordering and uniqueness matter; pick Streams when you need durable events, replayability, and per-service processing via consumer groups.
