Module 3 › Chapter 2.3 › What is a Sorted Set (ZSET)?
Definition

Unique members with scores

Each member is unique. Each member also has a float score used for ordering and range queries. This is ideal for leaderboards and priority queues.
Internal structure
Hash table for direct member lookup, skip list for ordered operations and range queries.
Concrete example
Player IDs as members, points as scores. When a player finishes a match, increment their score atomically so the leaderboard stays correct under concurrency.
Example commands
ZADD leaderboard 1000 "player:alice" 1200 "player:bob"
ZINCRBY leaderboard 50 "player:alice"
ZRANGE leaderboard 0 9 WITHSCORES
Key takeaway
Sorted Sets give ordered access while enforcing member uniqueness. Don’t use them when duplicate entries are required.
