Sorted Set mistake
Using Sorted Sets when identical duplicate events are required. Sorted Sets overwrite the member, so you lose earlier duplicates.
Stream operational note
Monitor pending entries and periodically claim or reprocess them. Remove unused consumer groups to prevent metadata growth.
Clock skew
Stream IDs include timestamps but Redis enforces monotonic increasing IDs internally. Don’t rely on the timestamp portion for exact real-world ordering across unsynchronized machines.
Maintenance
Plan group lifecycle, housekeeping commands, and monitoring so Streams and Sorted Sets remain performant and manageable in production.
