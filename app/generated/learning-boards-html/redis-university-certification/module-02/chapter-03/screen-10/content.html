Module 3 › Chapter 2.3 › Consumer Groups
Create group
XGROUP CREATE user:activity:stream analytics_group 0-0 MKSTREAM
Read with group
XREAD GROUP analytics_group consumer_1 COUNT 1 STREAMS user:activity:stream >
Acknowledge & claim
After processing send XACK to mark the message done. If a consumer fails, other consumers can claim pending messages so work continues.
XACK user:activity:stream analytics_group 1678881234567-0
Operational note
If consumer groups are no longer needed, delete them with XGROUP DESTROY to avoid unnecessary metadata retention.
