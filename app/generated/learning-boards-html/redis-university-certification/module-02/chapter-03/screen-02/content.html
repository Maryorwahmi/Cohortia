Verified Competency Milestone
01
Use Sorted Sets
Add unique members with scores and retrieve top N efficiently for leaderboards and priority queues.
VERIFIED COMPETENCY MILESTONE
02
Query by rank or score
Use rank-based or score-range queries to get slices of ordered data and filter by score brackets.
VERIFIED COMPETENCY MILESTONE
03
Write Streams
Append structured events with auto-generated IDs for replayable logs and observability pipelines.
VERIFIED COMPETENCY MILESTONE
04
Run consumer groups
Create consumer groups to let services independently process every event while ensuring single delivery per group.
VERIFIED COMPETENCY MILESTONE
Mnemonic
Think: Sorted Sets = Score + Uniqueness. Streams = Append + Replay. Use this to choose the right structure quickly during design reviews.
Common mistake to avoid
Don’t use Sorted Sets when multiple identical events are required; use Streams instead. Don’t rely on unsynchronized timestamps for ordering in distributed writes.
