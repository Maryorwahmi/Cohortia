Module 3 › Chapter 2.3 › Build a Leaderboard
Seed players
ZADD global:leaderboard 100 "player:alice" 150 "player:bob" 75 "player:charlie"
Seeding makes initial ranks predictable so UI tests and queries behave consistently.
Increment score
ZINCRBY global:leaderboard 20 "player:bob"
Atomic increments prevent lost updates when multiple scoring events race at the same time.
Inspect and display
ZSCORE global:leaderboard "player:alice"
ZREVRANGE global:leaderboard 0 2 WITHSCORES
Use ZSCORE to show a single player’s score and ZREVRANGE WITHSCORES to render the top leaderboard entries.
Try this
Add a new player, increment them past another player, and observe how ranks update deterministically.
