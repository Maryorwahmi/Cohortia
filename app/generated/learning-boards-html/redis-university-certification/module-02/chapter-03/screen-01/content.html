Sorted Sets and Streams

Understand ordering and scores with Sorted Sets, and durable append-only logs with Streams for event-driven systems.

In this lesson
How Sorted Sets store scores and return top N efficiently.
Coming up
Streams, XADD, consumer groups, and replayable event processing.
Why it matters
Design patterns for leaderboards, real-time analytics, and reliable queueing.
Concept Snapshot
Sorted Sets order by score • Streams append events with IDs
Example: Use a Sorted Set for a top-10 leaderboard where scores change frequently. Use a Stream to record every user action so multiple services can consume and replay events independently.
Quick demo starter
redis-cli

ZADD global:leaderboard 100 "player:alice" 150 "player:bob"
XADD user:activity:stream * event_type login user_id 101
