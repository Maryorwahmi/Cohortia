Module 3 › Chapter 2.3 › Reading Streams
Historical
XRANGE
Fetch entries between two IDs or from the beginning to reconstruct state or backfill a consumer.
XRANGE user:activity:stream - + COUNT 2
Live tailing
XREAD
Read new entries, optionally blocking until new data arrives for near-real-time processing.
XREAD COUNT 1 STREAMS user:activity:stream 0
Practical tip
Combine XRANGE for recovery with XREAD for normal operation. This lets you catch up on missed events after downtime and continue with live processing.
Misconception
XREAD is useful but does not provide per-consumer-group acknowledgement and ownership semantics. Use consumer groups for that behavior.
