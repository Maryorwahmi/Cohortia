Step-by-step terminal demo
Follow these commands in redis-cli to simulate a feed and tag system.
# Simulate user feed
LPUSH user:alice:feed "post:102 Alice liked a photo"
LPUSH user:alice:feed "post:101 Alice shared an article"
LPUSH user:alice:feed "post:100 Alice posted about Redis"
LRANGE user:alice:feed 0 4    -- view five most recent
LTRIM user:alice:feed 0 99    -- keep recent 100 items

# Tags for articles
SADD article:1:tags "redis" "database" "cache"
SADD article:2:tags "redis" "performance"
SINTER article:1:tags article:2:tags   -- common tags
Hints and checks
  • After LPUSH, immediately LTRIM to bound length and control memory.
  • Use BLPOP in a separate consumer window to observe blocking behavior during the demo.
  • For large tag sets, use SSCAN instead of SMEMBERS to iterate safely.
Key Takeaway

The CLI demo teaches practical patterns: bounded feeds with trimming, blocking consumers for low CPU, and set algebra for tag queries. Try combining them in a small script.
