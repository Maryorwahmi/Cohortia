Common retrieval and maintenance commands
  • LRANGE key start stop — returns a slice; cost proportional to number of elements returned.
  • LLEN key — returns the length in O(1).
  • LTRIM key start stop — truncates list server-side to the specified range; useful for bounding history.
  • LREM key count element — removes occurrences and is O(N) with respect to list length.
CLI snippets
LRANGE user:alice:feed 0 4   -- show five most recent
LLEN user:alice:feed           -- get current feed length
LTRIM user:alice:feed 0 99     -- keep recent 100 items
Common mistake

Using LRANGE 0 -1 on a very large list moves many elements over the network and can block your application; paginate or trim instead.

Example scenario

For a feed UI request the most recent page only, and maintain the list size on write using LTRIM after each LPUSH so the server never retains unnecessary history.

Key Takeaway

Read small windows with LRANGE and use LTRIM to bound list growth. Treat LREM as a heavier operation that scans for matches.

Pro tip

Apply LTRIM right after LPUSH to keep storage predictable: push then trim is an efficient pattern.
