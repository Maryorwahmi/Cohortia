Lists and Sets — quick map

Understand when you need ordered sequences with predictable head and tail semantics versus unordered unique collections with set algebra. We focus on practical commands and production patterns.

Redis Lists
Ordered, linked-list storage for fast head/tail ops.
Use-case examples: message queues, feeds, stacks. Commands: LPUSH, RPUSH, LPOP, RPOP, LRANGE.
Redis Sets
Unordered, unique members with set operations.
Use-case examples: unique visitors, tags, membership lists. Commands: SADD, SISMEMBER, SUNION, SINTER.

Lists: Queues & Feeds
Fast push/pop from ends, used for timelines and worker queues.
Sets: Unique Membership
Automatic uniqueness and powerful set algebra for filtering.

Blocking pops, trimming, and scanning to avoid blocking Redis on large collections.
