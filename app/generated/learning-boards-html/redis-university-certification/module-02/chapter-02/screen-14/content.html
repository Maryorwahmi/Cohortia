Module 2 › Chapter 2.2 › Key Concepts
Redis List
Ordered, O(1) head/tail insertions and removals.
Redis Set
Unordered unique members and fast set algebra.
Production Tips
Trim lists, use blocking pops, scan large sets, and monitor sizes.
Summary takeaway

Pick Lists for ordered streams and Sets for unique membership. Combine patterns, avoid full scans, and prefer server-side trimming and blocking primitives for resilient systems.
