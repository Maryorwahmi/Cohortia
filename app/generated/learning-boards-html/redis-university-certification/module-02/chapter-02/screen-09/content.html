Essential set commands
  • SADD key member [member ...] — add unique members.
  • SMEMBERS key — return all members; avoid on huge sets.
  • SISMEMBER key member — check membership fast.
  • SREM key member [member ...] — remove members.
  • SCARD key — return the unique member count.

Best practices
  • Use SSCAN for large sets to iterate incrementally and avoid blocking the server.
  • Keep inverted indices for frequent multi-tag queries: tag:name -> set of item IDs.
  • Use SREM to maintain accuracy when items are deleted or untagged.
Common misconception

Treating SMEMBERS as always safe. It is convenient for small sets, but assume SSCAN or paged access for large production collections.
