What is a Redis Set?

An unordered collection of unique strings. Duplicates are rejected automatically and order is not preserved.

When to use Sets
  • Track unique visitors or likers for a resource.
  • Maintain tags for articles and compute related items via intersections.
  • Create inverted indices like tag to product ID mappings for fast filtering.
Common mistake

Do not depend on Sets for order. If you require a ranking or sorted ordering, use a Sorted Set instead.

Concrete example
SADD article:1:tags "redis" "database" "cache"
SADD article:2:tags "redis" "performance"
SISMEMBER article:2:tags "cache"   -- checks membership
SCARD article:1:tags                -- cardinality of the set
Key Takeaway

Use Sets when uniqueness matters and set operations can express your queries more simply and efficiently than scanning other structures.
