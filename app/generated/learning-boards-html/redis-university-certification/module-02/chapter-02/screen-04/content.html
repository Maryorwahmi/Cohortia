What is a Redis List?

An ordered collection of strings implemented as a linked list, making head and tail operations extremely fast.

Complexity Profile
  • LPUSH / RPUSH and LPOP / RPOP are O(1) — constant time regardless of list size.
  • LRANGE is O(N) where N is number of elements returned; retrieving very large ranges can be costly.
  • LLEN is O(1) to get list length, LREM is O(N) relative to elements scanned.
Key Takeaway

Use Lists when you need ordered streams with frequent head or tail changes; avoid LRANGE on entire massive lists.

Common misconception

Lists are not arrays optimized for random access. Pulling large ranges is linear in the output size and can impact performance.

Concrete example
LPUSH user:alice:feed "post:102 Alice liked a photo"
LPUSH user:alice:feed "post:101 Alice shared an article"
LRANGE user:alice:feed 0 4  -- show five most recent posts
RPOP user:alice:feed        -- process oldest post
Explanation bullets
  • LPUSH inserts at the head; the newest items appear first when you LRANGE from zero.
  • RPOP removes the tail, which is useful to process oldest items in FIFO producer/consumer patterns.
  • Combine LRANGE with LTRIM to show recent entries while keeping list size bounded.
