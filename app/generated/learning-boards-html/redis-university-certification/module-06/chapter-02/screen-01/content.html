Redis Modules: Extending Functionality
Use modules to add commands, data structures, and search or JSON support without changing Redis core.
In this lesson

You will learn how modules are loaded, what RediSearch and RedisJSON provide, and how to apply them from Python to build searchable JSON-backed product catalogs.

Why this matters
Modules let you keep logic and data together at Redis speed, avoiding extra infrastructure and reducing latency for search and document operations.
