RediSearch indexes data and you query with FT.SEARCH or the python search_client.search API that returns documents with fields like product_name and price.
Search examples
Combine keywords with filters to narrow results.
# Basic keyword search
res = search_client.search(Query("headphones"))

# Keyword plus filters: example in query language
res = search_client.search(Query("smart @category:{Electronics} @price:[0 100]"))
Key Takeaway

Use text queries for relevance and Tag/Numeric fields for precise filtering to keep work server-side and efficient.
