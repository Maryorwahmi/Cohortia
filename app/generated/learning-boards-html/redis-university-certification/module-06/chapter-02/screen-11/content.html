Module 6 › Chapter 6.2 › Product Catalog Activity
Starter steps
  1. Start Redis with RediSearch and RedisJSON loaded.
  2. Create a RediSearch index that targets JSON paths and specify prefix product:.
  3. Store products using r.json().set with a product id like product:101.
  4. Run search_client.search queries for keywords and filters.
  5. Use r.json().get to retrieve specific specs paths.
Starter code excerpt
search_client = r.ft("product_catalog_idx")

# Define schema indexing JSON paths
schema = (
  TextField("$.product_name", as_name="product_name", weight=5.0),
  TextField("$.description", as_name="description"),
  TagField("$.category", as_name="category"),
  NumericField("$.price", as_name="price"),
)
search_client.create_index(schema, definition=redis.commands.search.commands.IndexDefinition(
  prefix=["product:"], index_type=["JSON"]
))

# Store a product as JSON
r.json().set("product:101", Path.root_path(), {"product_name": "Ultra HD Monitor", "price": 499.99, "specs": {"resolution": "3840x2160"}})
Run searches and use JSON.GET to fetch a nested spec such as .specs.resolution to validate your stored documents and index mapping.
