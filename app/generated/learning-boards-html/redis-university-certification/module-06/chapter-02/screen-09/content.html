Example operations
from redis.commands.json.path import Path

user_profile = {
  "name": "Alice Wonderland",
  "email": "alice@example.com",
  "address": {"street": "123 Rabbit Hole","city": "Wonderland","zip": "90210"},
  "interests": ["reading","gardening","chess"]
}

r.json().set("user:101", Path.root_path(), user_profile)
retrieved = r.json().get("user:101")
city = r.json().get("user:101", Path(".address.city"))
r.json().set("user:101", Path(".email"), "alice.w@newdomain.com")
r.json().arrappend("user:101", Path(".interests"), "painting")
These calls set the document, read the whole document or a path, update one path atomically, and append to an array without rewriting the full document.
Practical notes
  • Use JSON.GET to retrieve a specific path and avoid full document transfer.
  • JSON.SET with a path updates only that path atomically.
  • Append operations like arrappend modify arrays without rewriting the document.
Key Takeaway

RedisJSON enables efficient, path-based JSON manipulation so applications can update small parts of large documents quickly.
