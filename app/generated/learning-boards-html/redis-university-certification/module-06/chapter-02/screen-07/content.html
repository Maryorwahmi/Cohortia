Python example: creating a RediSearch index
This code shows schema fields and an index creation guard.
import redis
from redis.commands.search.field import TagField, TextField, NumericField
from redis.commands.search.query import Query

r = redis.Redis(host='localhost', port=6379, db=0)
search_client = r.ft("my_products_idx")

try:
  search_client.info()
  print("RediSearch index 'my_products_idx' already exists.")
except Exception:
  print("Creating RediSearch index 'my_products_idx'...")
  schema = (
    TextField("product_name", weight=5.0),
    TextField("description"),
    TagField("category"),
    NumericField("price"),
  )
  search_client.create_index(schema)
  print("Index created successfully.")
Note how the product_name field gets higher weight to increase match relevance. TextField for content, TagField for categorical filters, NumericField for ranges.
Explanation bullets
  • Check index existence to avoid recreate errors.
  • Choose field types to match query patterns and filters.
  • Weights affect relevance scoring; use higher weight for important fields.
Key Takeaway

Design your schema to reflect how users will search and filter your data for best performance and relevance.
