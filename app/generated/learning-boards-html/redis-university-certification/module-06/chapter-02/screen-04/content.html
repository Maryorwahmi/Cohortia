Module 6 › Chapter 6.2 › What are Redis Modules?
Modules: a clear definition
Dynamic libraries loaded into the Redis server that add new commands and data structures which clients can call like native Redis commands.
They extend Redis without bloating the core server. Modules can provide search, JSON, graph, or time-series features.
Commands appear native to clients once the module is loaded. Example prefixes: FT. for RediSearch, JSON. for RedisJSON.
Misconception check: Modules are not client-side libraries. They run inside the Redis process as server-side shared libraries.
Analogy: plugins in an application
Think of Redis as an application that loads plugins at startup to extend behavior. Modules are those plugins, adding commands and structures.
Example modules
  • RediSearch — full-text search and secondary indexing
  • RedisJSON — native JSON documents and path updates
  • RedisGraph, RedisTimeSeries — specialized data models
Key Takeaway

Modules let Redis gain new capabilities while keeping performance and a single command surface for clients.
