Require Authentication
Set a strong password and verify clients authenticate before executing commands.
Core Concept
Definition

requirepass is a redis.conf directive that requires clients to authenticate using AUTH before executing commands. Use a unique, high-entropy password and protect the config file.

  • Why it matters: prevents anonymous command execution and protects data from open connections.
  • Misconception: a password alone is not a full defense; combine with network controls.
  • Operational tip: manage the secret in your deployment system; avoid committing redis.conf into public repos.
Concrete Example
# redis.conf
requirepass myStrongRedisPassword123!
Then test with your client using AUTH or redis-cli -a.
Common Mistake

Using weak or default passwords. Attackers scan open ports and try defaults first.

Key Takeaway

Require authentication to stop unauthenticated access, and treat the password as a secret managed by your operations toolchain.

Terminal: verify auth
# Try connect without auth (should be rejected)
redis-cli
# (server replies with error: NOAUTH)

# Connect with password
redis-cli -a myStrongRedisPassword123!
# Then run: PING  -> PONG
Operational Check
After changing redis.conf, restart Redis and validate that unauthenticated connections fail and authenticated clients succeed. Rotate the password periodically and avoid plain-text backups of the config.
