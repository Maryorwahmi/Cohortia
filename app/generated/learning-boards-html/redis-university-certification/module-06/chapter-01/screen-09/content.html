Rate limiting pattern
Increment a per-minute key and set expiration to window length. Reject when count exceeds limit.
Key form: user:ID:requests:minute_timestamp. Expire set to 60 seconds.
Atomicity: use a pipeline to increment and set expiry in one go for efficiency.
Distributed safety: Redis centralizes counters so multiple app instances see the same counts.
Starter logic
# Pipeline pseudo-steps
pipe = r.pipeline()
pipe.incr(key)
pipe.expire(key, 60)
count, _ = pipe.execute()
Key Takeaway

Use a short-lived counter per window and pipeline increment plus expire for efficient, consistent rate limiting.
