Common Redis roles inside apps
Redis is more than cache: it's useful for sessions, counters, leaderboards, queues, and streams.
Strings + TTL — caches and sessions with expirations.
Sorted Sets — leaderboards, scoring, top-N queries.
Lists — simple queues and worker pipelines.
Streams — time-ordered events and reliable consumers.
Operational note
Different structures have different memory characteristics. Use expirations or trimming where data should not grow without bound.
Key Takeaway

Match the Redis data structure to the problem for clarity, performance, and predictable memory use.
