Module 6 › Chapter 6.1 › Thundering Herd
How the herd forms
Many clients observe a missing cache entry and simultaneously fetch the backing store, creating a spike in load.
Single-writer repopulation: allow one request to fetch and repopulate while others wait or retry.
Request coalescing: aggregate concurrent misses to one backend call using in-process or distributed locks.
Randomized TTLs: jitter expirations to avoid synchronized key expirations.
Practical check
Simulate concurrent requests to a missing key. If your DB sees N times the single request load, add coalescing or a single-writer lock.
Key Takeaway

Avoid trusting TTL alone. Use coalescing, locks, or stale-while-revalidate patterns to keep your primary store resilient under bursts.
