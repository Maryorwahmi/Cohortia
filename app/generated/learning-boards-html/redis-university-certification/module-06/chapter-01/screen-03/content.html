Practical lab tasks
Each task is short, testable, and focused on safety and performance.
  • Create a single shared connection pool and reuse it across handlers. Verify fewer open sockets.
  • Implement cache-aside for slow data: check cache, fetch on miss, set with expiration to avoid unbounded growth.
  • Build a rate limiter: increment a per-minute key, set expire=60, and reject when the count exceeds your limit.
  • Add connection error handling and configure Redis host and credentials via environment variables for safe deploys.
Quick mnemonic
POOL + CACHE + EXPIRE = reliable performance. Replace any one and watch issues reappear.
