Module 6 › Chapter 6.3 › SLOWLOG hands-on
Configure and run
# Temporary demo config
redis-cli CONFIG SET slowlog-log-slower-than 100
redis-cli CONFIG SET slowlog-max-len 100

# Simulate a slow command
redis-cli DEBUG SLEEP 0.1

# Retrieve entries
redis-cli SLOWLOG GET 5
Interpreting entries
Each slowlog entry contains id, timestamp, duration in microseconds, and the command. Use these to find which commands exceed thresholds and correlate with client ids from CLIENT LIST.
Misconception
SLOWLOG records server-side command duration only; it does not include network latency or client processing time.
Key Takeaway

Use SLOWLOG to capture slow commands with low overhead, then correlate with client and application context for remediation.
