Module 6 › Chapter 6.3 › Alerting and practical thresholds
Memory
Alert at 80–90% of maxmemory. Correlate with fragmentation and large key findings before scaling up.
Fragmentation
Alert when mem_fragmentation_ratio exceeds a workload-specific threshold (commonly 1.5–2.0).
Cache hit ratio
Alert when keyspace_hits / (hits+misses) drops below your SLA target, e.g. 90%.
Composite alerts
Combine signals like high memory plus increasing fragmentation or declining hit rate. Composite alerts reduce false positives and focus action on real problems.
Key Takeaway

Alert early with sensible thresholds, and combine signals to create meaningful, actionable alerts that prevent outages.
