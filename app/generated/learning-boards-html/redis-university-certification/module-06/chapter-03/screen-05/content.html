Module 6 › Chapter 6.3 › Memory metrics explained
Memory fields
  • used_memory: Redis-reported allocation for data and overhead.
  • used_memory_rss: Resident set size reported by the OS.
  • mem_fragmentation_ratio: used_memory_rss / used_memory.
  • maxmemory: Configured limit controlling eviction behavior.
Find large keys
redis-cli MEMORY USAGE mybigkey
Concrete scenario
You see mem_fragmentation_ratio ~ 2.0 while used_memory is stable. Use MEMORY USAGE to identify large keys and consider a rolling restart or memory allocator tuning if fragmentation persists.
Misconception
Evictions and fragmentation are separate: evictions occur when you hit maxmemory; fragmentation is about how RAM is laid out.
Key Takeaway

Monitor memory metrics over time and use MEMORY USAGE for key-level inspection before changing capacity.
