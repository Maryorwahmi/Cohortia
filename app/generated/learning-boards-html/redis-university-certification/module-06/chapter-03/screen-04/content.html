Module 6 › Chapter 6.3 › INFO: the Redis snapshot command
Definition
INFO returns categorized server metrics for health checks and automation. Use section names to limit output.
Example commands
redis-cli INFO
redis-cli INFO memory
redis-cli INFO stats
Key notes
  • used_memory — memory reported by Redis.
  • used_memory_rss — resident set size the OS reports.
  • mem_fragmentation_ratio — rss / used_memory, watch > 1.5.
Interpretation cards
Concrete example
If used_memory is 500 MB and used_memory_rss is 1,200 MB, fragmentation ≈ 2.4. Consider restart or inspect allocator behavior.
Common mistake
Adding RAM before investigating fragmentation or large keys may mask the real issue.
Key Takeaway

INFO is the single-source snapshot for Redis state; use sectioned INFO calls for targeted checks and automation.
