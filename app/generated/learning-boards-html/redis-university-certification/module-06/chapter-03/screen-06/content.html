Module 6 › Chapter 6.3 › CLIENT LIST and client diagnostics
What CLIENT LIST shows
  • id — client id for tracing.
  • addr — address and port.
  • idle — seconds since last command.
  • obuf or output list fields — show client output buffer sizes.
Example
redis-cli CLIENT LIST
Concrete scenario
You spot several clients with large output buffers and high idle times. These are likely slow consumers that should be throttled or fixed in the application.
Misconception
Seeing many clients isn't necessarily bad; focus on buffer sizes and idle times rather than client count alone.
Key Takeaway

Use CLIENT LIST to find resource-hungry or slow clients, then correlate with app logs before taking action.
