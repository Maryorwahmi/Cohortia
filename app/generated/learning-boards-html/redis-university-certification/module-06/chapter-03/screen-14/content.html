Module 6 › Chapter 6.3 › Security and safety when monitoring
Safety checklist
  • Require authentication for monitoring endpoints and dashboards.
  • Use encrypted connections when exporting metrics off-host.
  • Limit MONITOR usage and cap SLOWLOG length.
  • Place exporters behind network controls and avoid public exposure.
Concrete scenario
When integrating with Prometheus, run the exporter in a private network and configure TLS between Prometheus and the exporter to avoid exposing metrics on the open internet.
Misconception
Assuming monitoring is harmless. Unrestricted tracing can expose data and increase load dramatically.
Key Takeaway

Implement authentication, encryption, and usage limits for monitoring to keep observability both useful and safe.
