Module 6 › Chapter 6.3 › MEMORY USAGE to find large keys
Code walkthrough
Iterate suspected keys and inspect their memory footprint. Here is a short terminal-style example you can run locally.
# Check server memory
redis-cli INFO memory

# Measure a specific key
redis-cli MEMORY USAGE mybigkey

# Script idea (pseudo): iterate a pattern and print top offenders
# for k in $(redis-cli KEYS 'user:*'); do redis-cli MEMORY USAGE "$k"; done
Concrete example
You discover a cache key storing thousands of items in a list; its MEMORY USAGE shows it consumes 700 MB. Consider paging or splitting into multiple keys.
Misconception
Large datasets are not always many keys; a single key with many fields can be the main consumer.
Key Takeaway

Measure keys directly with MEMORY USAGE and prioritize refactors for the largest consumers.
