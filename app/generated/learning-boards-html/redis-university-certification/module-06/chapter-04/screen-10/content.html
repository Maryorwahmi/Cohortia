Complexity examples
  • O(1): GET, SET (small hash fields)
  • O(N): LRANGE on long lists, SMEMBERS on large sets, KEYS *
  • Safe iteration: SCAN / HSCAN / SSCAN / ZSCAN
Design tip
Break very large collections into smaller shards or use cursors to iterate without blocking the server.
Concrete migration pattern
If you need to process a large set, use SSCAN with a cursor and process in fixed-size batches, committing progress externally so a restart resumes safely.
Misconception
Assuming SCAN returns ordered, complete results in one call. SCAN is incremental and may return duplicates; your code must handle cursor semantics.
Key Takeaway

Choose data structures and iteration patterns that keep per-operation work bounded even as dataset size grows.
