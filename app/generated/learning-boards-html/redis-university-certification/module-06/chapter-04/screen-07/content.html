Why RTT matters

Each client-server round trip adds latency. For many small commands, RTT accumulates and limits throughput; the server may be idle while waiting for network transmission to finish.

Pipelining pattern
  1. Batch commands in the client into a single send.
  2. Send the batch over the socket without waiting for each reply.
  3. Read replies in sequence after the batch is processed.
Concrete example
# Python redis-py pipelining pattern
pipe = r.pipeline()
for i in range(1000):
  pipe.set(f"key:{i}", f"value:{i}")
pipe.execute()
Use pipelining for batches where atomicity is not required. For atomic groups, use MULTI/EXEC but expect similar RTT behavior.
Misconception
Pipelining fixes all latency problems. It helps most when RTT dominates; it does not reduce raw transfer time for large payloads.
