Module 6 › Chapter 6.4 › Memory & Eviction
Key settings
  • maxmemory caps Redis memory use
  • maxmemory-policy chooses eviction or noeviction
  • Monitor used_memory and fragmentation stats
Example choices
Use allkeys-lru for cache-like behavior; use noeviction for critical datasets where writes must not be silently dropped.
Testing guidance

In benchmarks, load the dataset to near maxmemory and observe eviction events and write errors. Ensure application behavior remains correct under evictions.

Pitfall
Choosing noeviction without headroom can cause writes to fail at peak traffic. Always test write failure modes in staging.
Key Takeaway

Match maxmemory and eviction policy to your tolerance for data loss and test under load.
