Module 6 › Chapter 6.4 › Tuning Strategies
Network-focused
Use pipelining or batch APIs to reduce RTT. Verify improvements by comparing runs with identical -n and -c values.
CPU-focused
Simplify heavy commands, break large operations, or move complex computation out of Redis and re-evaluate.
Memory & Persistence
Set maxmemory and a policy, prefer appendfsync everysec for AOF to reduce fsync latency, and tune save rules for RDB snapshots.
Data modeling
Use hashes for many small fields; avoid KEYS * and large SMEMBERS; use SCAN variants to iterate safely.
Validation checklist
  • Baseline with exact flags
  • Apply single change in staging
  • Re-run benchmarks and compare RPS and P99
  • Have rollback and monitor SLOWLOG for problematic commands
