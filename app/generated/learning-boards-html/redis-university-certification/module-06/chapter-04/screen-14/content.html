Module 6 › Chapter 6.4 › Key Concepts
redis-benchmark
A command-line tool to measure Redis throughput and latency under controlled loads.
Throughput vs Latency
RPS measures capacity; P99 and P99.9 reveal tail latency that affects users more than averages.
Pipelining
Batch commands to reduce network round trips and improve small-command throughput and tail latency.
Summary takeaway

Design tests, measure tail latency, and validate single changes in staging with a rollback plan.
