Module 6 › Chapter 6.4 › Throughput vs Latency
What to compare
  • RPS across identical test flags
  • P50, P99, P99.9 latency distributions
  • System counters: CPU, memory, persistence I/O, network RTT
Concrete scenario
If SET with 1KB shows 30% lower RPS and 3× higher P99 than 10B, network transfer size is likely the dominant factor even if CPU looks idle.
Supporting notes
Key takeaway
Tail latency drives user impact. Solve high P99s before chasing marginal RPS improvements.
Common pitfall
Relying on average latency alone hides rare but harmful spikes. Capture distributions with --latency-dist.
Reflect: if your service must satisfy a P99 SLA, optimize for the tail first and use throughput to size instances appropriately.
