Starter commands to run
echo "--- Benchmarking PING ---"
redis-benchmark -n 100000 -c 50 -t PING

echo "--- SET/GET 10B ---"
redis-benchmark -n 100000 -c 50 -t SET,GET -d 10

echo "--- SET/GET 1KB ---"
redis-benchmark -n 100000 -c 50 -t SET,GET -d 1024

echo "--- SET/GET 10KB ---"
redis-benchmark -n 100000 -c 50 -t SET,GET -d 10240

echo "--- LPUSH/LPOP ---"
redis-benchmark -n 100000 -c 50 -t LPUSH,LPOP

# Latency distribution
redis-benchmark -n 100000 -c 50 -t SET --latency-dist
After each run, note RPS and P99. Then run INFO and SLOWLOG to correlate server metrics with benchmark output.
Checkpoints
  • Record exact command flags and environment
  • Run warm-ups before measurement
  • Compare P99 across payload sizes to find network impact
  • Inspect INFO for CPU and memory usage
