Module 6 › Chapter 6.4 › Mistakes & Diagnostics
Frequent mistakes
  • Benchmarking over WAN instead of representative network
  • Changing multiple config variables before re-testing
  • Using averages instead of percentiles
  • Not checking SLOWLOG and INFO
Diagnostic checklist
  1. Record baseline with exact flags
  2. Capture INFO and SLOWLOG snapshots during benchmarks
  3. Change one variable and re-run tests
  4. Compare RPS and P99 to validate impact
Rule of thumb
If P99 spikes without CPU or memory change, inspect persistence and network RTT first.
