Module 6 › Chapter 6.4 › Definitions
maxmemory
A configuration limit that caps Redis memory usage and triggers eviction or write failures.
O(N) complexity
Commands whose cost grows with collection size; avoid on large datasets to prevent blocking behavior.
SCAN
A cursor-based, incremental iteration command that avoids blocking the server like KEYS * would.
Final thought

Use benchmarks to guide tuning; validate each change with reproducible tests and a rollback plan.
