Core Concept › Definition › What is Redis Sentinel?
Definition
Sentinel is a distributed supervisor that monitors Redis instances, issues notifications, elects leaders, and performs automatic failover when necessary.
Monitoring: check master and replicas for reachability
Notification: emit events when state changes
Automatic Failover: elect leader and promote replica
Common misconception
Sentinel does not replace replication or backups. It supervises failover but depends on replicas for data continuity.
Concrete example
You run one master on port 6379 and two replicas on 6380 and 6381. Three Sentinel processes monitor the master. If the master stops responding, at least two Sentinels must agree before a promotion occurs.
Key Takeaway

Use Sentinel to supervise replication and orchestrate failover; it increases availability but does not change how data is replicated.
