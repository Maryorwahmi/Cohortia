Terminal demo commands
# Start Sentinel 1
redis-sentinel sentinel1.conf &
# Start Sentinel 2
redis-sentinel sentinel2.conf &
# Start Sentinel 3
redis-sentinel sentinel3.conf &
# Connect to Sentinel CLI
redis-cli -p 26379
# Inspect sentinel state
INFO sentinel
SENTINEL masters
What to expect
You will see the master listed and connected Sentinels. During a simulated shutdown, states move from sdown to odown and then to a new master address once promotion completes.
Common outputs
SENTINEL masters output contains keys like name, ip, port, flags and number of replicas. Flags show odown or sdown states.
Practice reading the flags to know when promotion is in progress.
Lab tip
Run the SENTINEL masters command in a loop to watch transitions when you shut down the master.
