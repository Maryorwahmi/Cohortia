Comparison › Client discovery › Sentinel vs hardcoded
Hardcoded master
  • Simple configuration but brittle on failover.
  • Requires manual update after promotion.
  • Higher downtime and operational burden.
Misconception
Some teams believe DNS can be used instead; DNS caches and propagation can still cause delays unless managed carefully.
Sentinel-based discovery
  • Client queries Sentinel for the current master address by service name.
  • Clients with Sentinel support reconnect automatically after failover.
  • Configure multiple Sentinels in client settings for resilience.
Recommendation
Use client libraries' Sentinel support and list multiple Sentinel endpoints to avoid single-point lookup failures.
