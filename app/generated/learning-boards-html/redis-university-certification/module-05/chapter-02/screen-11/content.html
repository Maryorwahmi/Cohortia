Diagnostics › Commands › Interpret outputs
Command examples
# List monitored masters
redis-cli -p 26379 SENTINEL masters

# Show Sentinel internal info
redis-cli -p 26379 INFO sentinel

# List replicas for a master
redis-cli -p 26379 SENTINEL replicas mymaster
How to read flags
Look for flags such as sdown and odown. Compare outputs from multiple Sentinels to ensure the master is objectively down before taking action or trusting an automated failover report.
Operational tip
Record sentinel outputs during a test failover so you can review leader selection and replica offsets for post-mortem analysis.
