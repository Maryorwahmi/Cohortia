Minimal sentinel.conf
port 26379
daemonize yes
pidfile /var/run/redis-sentinel.pid
logfile "/var/log/redis-sentinel.log"
dir /tmp
sentinel monitor mymaster 127.0.0.1 6379 2
sentinel down-after-milliseconds mymaster 5000
sentinel failover-timeout mymaster 60000
sentinel parallel-syncs mymaster 1
Note the monitor line's last number is the quorum required to trigger failover.
Parameter meanings
  • sentinel monitor: which master to watch and quorum.
  • down-after-milliseconds: time before marking SDOWN.
  • failover-timeout: upper bound for failover operations.
  • parallel-syncs: replicas allowed to resync in parallel.
Practical note

Start each Sentinel with a unique port and unique pid/log files. Use three Sentinels and quorum 2 for laboratory setups.
