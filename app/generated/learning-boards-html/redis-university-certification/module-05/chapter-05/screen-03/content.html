Practical Objectives
Run INFO & interpret metrics

Inspect used_memory_rss, connected_clients and replication offsets to find memory pressure and replication lag.

Backup & Restore test

Enable AOF, perform writes, simulate crash and restart to confirm recovery behavior matches expectations.

Alerting exercises

Create alerts for high memory, master down, and replication lag, then trigger them in controlled tests.

Client failover handling

Use Sentinel/Cluster-aware client libraries and test reconnect, retry, and read routing behavior during failover.
