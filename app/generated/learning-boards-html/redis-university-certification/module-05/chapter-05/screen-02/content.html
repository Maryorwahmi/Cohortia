Learning Objectives
Bloom: Learn → Understand → Apply → Master
Learn → Understand → Apply → Master
01
Select HA & scaling

Evaluate replication, Sentinel, and Cluster for availability, capacity and complexity. Learn to pick the simplest adequate approach for your workload.

VERIFIED COMPETENCY MILESTONE
02
Monitor and alert

Implement monitoring for memory, CPU, connections and replication lag, and configure alerts for critical thresholds to catch issues early.

VERIFIED COMPETENCY MILESTONE
03
Backup & restore

Configure RDB or AOF persistence, take backups from replicas, and test restores so you can recover from corruption or catastrophic failures.

VERIFIED COMPETENCY MILESTONE
04
Secure & optimize clients

Apply password and network restrictions, enable TLS where needed, and use Sentinel/Cluster-aware clients with pooling and retries for resilience.

VERIFIED COMPETENCY MILESTONE
