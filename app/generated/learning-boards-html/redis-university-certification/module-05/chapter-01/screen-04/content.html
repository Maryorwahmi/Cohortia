Module 5 › Chapter 5.1 › What is Redis Replication?
Definition

Master-replica copying

Replication copies a master's dataset to one or more replicas. After an initial sync, the master streams subsequent writes to replicas in real time.

Concrete example
SET user:123 "profile" on the master is applied and streamed. A read from a replica may briefly miss it if the replica hasn't applied the write yet.
Common misconception
Replication is not automatic failover. Replicas mirror data but promotion requires another tool or manual action.
Key takeaway
Replication improves read capacity and provides redundancy but is asynchronous by default, so monitor offsets and enable persistence on the master.
Quick visual
Master
Receives writes; streams commands to replicas.
Replica
Applies streamed writes, serves reads, read-only by default.
Why this matters

Replication is the simplest building block for high availability. It is efficient and lightweight, but requires monitoring and correct configuration to avoid surprises in production.
