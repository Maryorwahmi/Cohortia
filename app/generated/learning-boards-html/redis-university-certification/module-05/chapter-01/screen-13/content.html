Module 5 › Chapter 5.1 › Testing Replication
Step-by-step verification timeline
Start servers
Start master then replicas and wait for initial syncs to complete.
Write test
On master: SET mykey "Hello Redis!".
Read test
On replica: GET mykey should return the value after sync.
Replica write
Attempt SET on replica and confirm it fails due to read-only mode.
Finish by running INFO replication on master and replicas. Compare master_repl_offset and replica offsets to quantify any lag and investigate causes if gaps are large or growing.
