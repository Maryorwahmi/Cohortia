Quick Commands

REPLICAOF and redis.conf

Use REPLICAOF at runtime for immediate configuration or add replicaof to redis.conf for persistent startup configuration. Always verify after configuring.

Example runtime command
REPLICAOF 192.168.1.100 6379
Example redis.conf line
replicaof 192.168.1.100 6379
port 6380
replica-read-only yes
Verification
Run INFO replication to check role, master link status, and connected replicas. Look for role:replica and master_link_status:up on a configured replica.
Operational note
To stop replication and make an instance a master, use REPLICAOF NO ONE. Keep replica-read-only yes to avoid accidental writes.
