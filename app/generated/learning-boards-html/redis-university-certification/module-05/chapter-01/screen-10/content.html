Start master and replicas locally

Create three config files and start each server, then verify replication and test commands.

Master config (redis-master.conf)
port 6379
daemonize yes
pidfile /var/run/redis_6379.pid
logfile "/var/log/redis_6379.log"
dbfilename dump-6379.rdb
dir ./data/6379
Replica config snippets
# redis-replica1.conf
port 6380
replicaof 127.0.0.1 6379

# redis-replica2.conf
port 6381
replicaof 127.0.0.1 6379
Verification commands
Start each server with redis-server . Then: 
redis-cli -p 6379
INFO replication

redis-cli -p 6380
INFO replication

# Test data sync
redis-cli -p 6379
SET mykey "Hello Redis!"
redis-cli -p 6380
GET mykey
