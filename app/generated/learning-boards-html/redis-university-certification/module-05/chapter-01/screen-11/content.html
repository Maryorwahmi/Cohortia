Read replication state with INFO

INFO replication surfaces role, connected replicas, master link status, and offsets. Use it frequently to monitor health.

Example output (master)
# Replication
role:master
connected_slaves:2
slave0:ip=127.0.0.1,port=6380,state=online,offset=1498000
slave1:ip=127.0.0.1,port=6381,state=online,offset=1497990
master_repl_offset:1500000
Interpreting offsets
Offset gap equals master_repl_offset minus replica offset. A growing gap signals lag; stable small gaps are normal under load.
Actionable checks
  • Alert on master_repl_offset - replica_offset exceeding a threshold.
  • Investigate network, CPU, or disk IO if offsets grow consistently.
  • Check master_link_status on replicas; if down, replication is broken and requires reconnection or investigation.
