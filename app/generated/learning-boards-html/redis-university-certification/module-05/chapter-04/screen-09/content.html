Process

Reshard using redis-cli --cluster reshard

Start an interactive reshard operation. Specify the number of slots to move and choose the source masters. The helper migrates slots one at a time to preserve consistency.

# start resharding (interactive)
redis-cli --cluster reshard 127.0.0.1:7000

# follow prompts: how many slots, source node ids, target node id
Operational caution

Resharding can be resource-intensive. Perform during off-peak hours and monitor replication lag and CPU to avoid unexpected impact.

Reshard checklist
  1. Decide how many slots to move
  2. Identify source and target master node ids via CLUSTER NODES
  3. Run redis-cli --cluster reshard and confirm prompts
  4. Monitor replication lag and run redis-cli --cluster check when finished
Misconception

Resharding is not instantaneous and can take time proportional to moved keys. Treat it like a maintenance window when possible.
