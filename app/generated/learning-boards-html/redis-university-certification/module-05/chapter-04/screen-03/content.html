Practice checkpoints

Concrete lab tasks and what to verify as you go.

Topology Check

List three master node ports and their replicas. Confirm that each replica follows a different master and explain how failover will work.

Cluster Create

Start six instances with cluster-enabled yes and unique nodes files. Run redis-cli --cluster create with addresses and --cluster-replicas 1, then accept the proposed layout.

Add & Reshard

Use add-node to join a master or replica, then run redis-cli --cluster reshard to move slots and confirm new slot ownership with CLUSTER NODES.

Health Checks

Run redis-cli --cluster check and CLUSTER INFO. Look for reachable nodes and correct slot allocation before and after maintenance.
