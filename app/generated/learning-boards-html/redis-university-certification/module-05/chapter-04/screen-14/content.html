Minimum Cluster Size

Three masters required for quorum; pair with replicas for HA.

Cluster Config

Set cluster-enabled yes and unique cluster-config-file per instance.

redis-cli helpers

Use --cluster create, add-node, reshard, del-node, and --cluster check for lifecycle operations.

Summary Takeaway

Follow configuration and operation sequences, validate with checks, and perform resharding during planned windows.
