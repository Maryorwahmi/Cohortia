Module 5 › Chapter 5.4 › Key Concepts — Commands
Create

redis-cli --cluster create <nodes> --cluster-replicas N

Add Node

redis-cli --cluster add-node <new> <existing> [--cluster-slave --cluster-master-id <id>]

Reshard & Remove

redis-cli --cluster reshard <node> — reshard slots; use del-node only after slots are moved.

Final Checklist

Three masters, unique node files, create with replicas, reshard before removal, and always run cluster checks after changes.
