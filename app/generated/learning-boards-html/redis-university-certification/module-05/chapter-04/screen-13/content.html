Lab Steps
  1. Create directories: mkdir -p cluster-data/{7000,7001,7002,7003,7004,7005}
  2. Make redis-700X.conf files with cluster-enabled yes and unique nodes-700X.conf
  3. Start instances: redis-server redis-7000.conf ... redis-server redis-7005.conf
  4. Create cluster: run redis-cli --cluster create ... --cluster-replicas 1 and type yes
  5. Verify: redis-cli -p 7000 CLUSTER NODES and redis-cli --cluster check 127.0.0.1:7000
Terminal snippets
# create directories and sample config
mkdir -p cluster-data/{7000,7001,7002,7003,7004,7005}
# start each server

# create the cluster

  127.0.0.1:7003 127.0.0.1:7004 127.0.0.1:7005 --cluster-replicas 1
Test commands

Guided check: redis-cli --cluster check 127.0.0.1:7000
Key Takeaway

Follow the checklist, verify node roles and slots, and test key operations with redis-cli -c to observe automatic routing.
