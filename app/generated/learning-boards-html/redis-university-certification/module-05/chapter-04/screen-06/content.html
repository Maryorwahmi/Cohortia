Module 5 › Chapter 5.4 › Create Cluster
Code Walkthrough

Start instances and run create

Start each server with its redis.conf and run the cluster create command with all node addresses and --cluster-replicas to assign replicas automatically.

# start each instance
redis-server redis-7000.conf
redis-server redis-7001.conf
...

# create the cluster
redis-cli --cluster create 127.0.0.1:7000 127.0.0.1:7001 127.0.0.1:7002 \
  127.0.0.1:7003 127.0.0.1:7004 127.0.0.1:7005 --cluster-replicas 1
# type yes when prompted
Verification
redis-cli -p 7000
> CLUSTER NODES
redis-cli --cluster check 127.0.0.1:7000
Key Takeaway

Provide all instance addresses to the create command and use --cluster-replicas to control replica assignment.

Practical notes
  • Include both master and replica addresses during create for a smooth layout.
  • Type yes to accept slot and replica assignments proposed by the helper.
  • After create, nodes will exchange gossip and persist nodes-PORT.conf files.
Misconception

Do not assume redis-cli --cluster create performs live data movement beyond initial slot assignment — it sets the initial distribution so your cluster starts with each master owning a set of slots.
