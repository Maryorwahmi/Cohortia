Architecture

Add master or replica to cluster

Use add-node to join, then reshard slots to give the new master data. For replicas include --cluster-slave and the master's node id.

# add a new master
redis-cli --cluster add-node 10.0.0.10:7006 127.0.0.1:7000

# add a replica for a specific master (escape angle brackets)
redis-cli --cluster add-node 10.0.0.11:7007 127.0.0.1:7000 --cluster-slave --cluster-master-id <master_node_id>
Practical note

Obtain the master node id via CLUSTER NODES before adding a replica so you can point the replica to the right master.

Example scenario

You want to expand capacity. Add a new master process, then reshard roughly equal slot ranges from current masters to the new master to spread load.

Checkpoints
  • Run add-node and confirm CLUSTER NODES shows joined node.
  • Run redis-cli --cluster reshard to move slots to the new master.
  • Use redis-cli --cluster check to confirm balanced slots.
