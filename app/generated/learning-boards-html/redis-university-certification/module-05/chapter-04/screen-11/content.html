Module 5 › Chapter 5.4 › Health Checks
Definition

Verify cluster status and slots

Use CLUSTER INFO for a quick summary, CLUSTER NODES for per-node roles and slot assignment, and redis-cli --cluster check for a thorough verification.

# summary
redis-cli -p 7000 CLUSTER INFO

# detailed node list
redis-cli -p 7000 CLUSTER NODES

# guided check
redis-cli --cluster check 127.0.0.1:7000
What to watch for
  • Unreachable nodes or FAIL flags
  • Masters owning unexpected slot ranges
  • Replicas with high replication lag
Troubleshooting steps
  1. Run redis-cli --cluster check to detect configuration issues
  2. Run CLUSTER NODES to inspect node ids and slot ownership
  3. If slots are missing, inspect logs and node config files
Quick Tip

After any topology change, immediately run a cluster check to detect mismatches early.
