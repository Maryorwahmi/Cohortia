Architecture
Hash slots: 16,384 partitions
How it works
The keyspace is divided into 16,384 slots. Each key deterministically maps to a slot so clients and nodes agree on ownership without a central coordinator.
Slot ranges are assigned to nodes. Moving slots moves groups of keys.
Replicas mirror the slots owned by a master for failover.
Clients compute slots locally using the same hashing rule.

Misconception

Slots are logical labels, not separate physical databases. The actual data lives on nodes that own those slots.
