Node Roles
Masters and replicas
Master responsibilities
  • • Owns a set of hash slots and the keys mapped to them.
  • • Handles write commands for those keys.
  • • May be paired with replicas for redundancy.
Replica responsibilities
  • • Mirrors its master's slots and data.
  • • Can be promoted to master during failover.
  • • Should be placed in different failure domains from its master.
Operational cards
Add masters to increase capacity. Each new master can take ownership of additional slot ranges.
Add replicas per master for failover. Replicas don’t expand write capacity.
Misconception: replicas increase write throughput. They do not; writes still go to the master.
Key Takeaway

Shard by adding masters; protect each master with replicas for automatic failover.
