Definition
Hash tags: forcing keys into the same slot
Use {...} in key names so the bracketed substring is the only input to the slot hash.
Examples to run
redis-cli CLUSTER KEYSLOT product:1:name
redis-cli CLUSTER KEYSLOT product:2:price

redis-cli CLUSTER KEYSLOT product:{1}:name
redis-cli CLUSTER KEYSLOT product:{1}:price
You will observe that untagged keys usually map to different slots, while tagged keys with the same content inside braces map to the same slot.
When to use tags
  • • When related keys must be accessed or updated together with multi-key commands.
  • • When you can accept the performance trade-off that those keys concentrate on one node.
  • • Avoid tags when they would create a hotspot that overloads a single server.
Pro tip: use tags sparingly and intentionally to enable only those multi-key operations that truly need co-location.
