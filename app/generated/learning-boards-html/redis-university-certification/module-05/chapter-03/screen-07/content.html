How keys map to slots
Deterministic rule used by clients and nodes.
Formula
CRC16(key) % 16384
You can verify slots locally with redis-cli CLUSTER KEYSLOT. This makes the mapping easy to test when you design keys.
Concrete example
redis-cli CLUSTER KEYSLOT mykey
redis-cli CLUSTER KEYSLOT user:1:profile
redis-cli CLUSTER KEYSLOT product:2:price
Why deterministic mapping helps
  • • Clients compute the slot locally and send commands straight to the owner node.
  • • If a node is queried for a key it doesn’t own, it returns a MOVED response to redirect the client.
  • • Rebalancing moves whole slot ranges, making slot-based rebalancing simpler than per-key moves.
Common-mistake
Assuming keys with similar text map to the same slot. They often won't unless you use hash tags to force locality.
