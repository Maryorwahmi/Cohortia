Definition
Sharding: partitioning the keyspace
Split a dataset into shards so each server holds part of the data and the write load is distributed.
Why it matters
  • • Increases total memory capacity by using many machines.
  • • Distributes write throughput so no single CPU is the bottleneck.
  • • Requires thought about operation locality and design of multi-key commands.
Analogy
A library split into sections lets multiple visitors be served at once. Sharding splits keys into sections so nodes serve requests in parallel.
Design considerations
Plan key names for locality to enable multi-key operations when needed.
Avoid relying on global commands like KEYS and SELECT in Cluster mode.
Give each master replicas for availability — sharding plus replication is common.
