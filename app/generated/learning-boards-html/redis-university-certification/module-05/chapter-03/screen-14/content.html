Understanding slot mapping and hash tags
Commands to run
redis-cli CLUSTER KEYSLOT mykey
redis-cli CLUSTER KEYSLOT product:1:name
redis-cli CLUSTER KEYSLOT product:2:price

redis-cli CLUSTER KEYSLOT product:{1}:name
redis-cli CLUSTER KEYSLOT product:{1}:price
Observe the slot numbers and note when keys share the same slot thanks to the tag inside braces.
Reflection cards
Would an MGET across those keys work? Only if they share a slot.
If keys land on different slots, design either tags or application-level aggregation to perform multi-key work.
Record your slot numbers and use them to inform key naming decisions.
