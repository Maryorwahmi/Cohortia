Limitations to plan for
Multi-key operations
Operations like MGET, MSET, or multi-key DEL require all keys to be in the same slot to succeed. Hash tags are the mechanism to achieve that when needed.
Common mistake: expecting cluster to transparently run multi-key commands across nodes. It will not.
Unsupported global features
  • • KEYS is not practical for cluster mode since keys are distributed.
  • • SELECT is unsupported; Cluster uses only database 0.
  • • Use node-level scans and aggregate results client-side if you must inspect the whole dataset.
Key Takeaway

Design your data model to avoid wide multi-key dependencies or use hash tags for related keys that must be accessed together.
