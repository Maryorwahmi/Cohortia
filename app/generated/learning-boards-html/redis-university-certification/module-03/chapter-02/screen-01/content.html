Redis Pub/Sub Messaging

Publish messages to channels, subscribe with exact names or patterns, and deliver real-time updates to active clients.

In this lesson
Commands: PUBLISH, SUBSCRIBE, PSUBSCRIBE
Why it matters
Use Pub/Sub for low-latency, ephemeral messaging like chat and live dashboards.
Limitations
Messages are not persisted; offline clients miss messages.
Visual concept
Publishers tag messages with channel names. Subscribers register interest. Redis delivers messages to active subscribers only.
Explore Key Topics
PUBLISH
Send a message to a named channel; delivered instantly to active subscribers.
SUBSCRIBE / PSUBSCRIBE
Listen for messages by name or by pattern; pattern subscriptions use glob-style wildcards.
Fire-and-forget
If no subscriber is present, a published message is dropped and not stored.
Orientation

Follow the chapter to learn commands, pattern subscriptions, practical use cases, and when to choose a persistent alternative like Redis Streams.
