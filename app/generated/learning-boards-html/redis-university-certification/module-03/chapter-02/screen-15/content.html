Module 3 › Chapter 3.2 › What to Remember
Exact vs Pattern
Use SUBSCRIBE for specific channels, PSUBSCRIBE for groups of channels that share naming patterns.
Dedicated connections
Keep subscribing connections separate from regular Redis command connections to avoid blocking.
Persist critical events
If messages cannot be lost, write them to a persistent structure such as Redis Streams as well as publishing them.
Final takeaway

Pub/Sub is an efficient real-time broadcast tool. Use it for ephemeral updates and combine it with persistence for reliability when needed.
