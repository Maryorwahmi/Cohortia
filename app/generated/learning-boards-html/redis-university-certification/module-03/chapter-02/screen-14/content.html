Module 3 › Chapter 3.2 › Key Concepts
Publish/Subscribe
Decoupled broadcast from publishers to active subscribers via channels.
PSUBSCRIBE / PUNSUBSCRIBE
Pattern subscriptions use * and ? to match many channel names.
Fire-and-forget
Messages are not persisted; late subscribers do not receive past messages.
Summary

Pub/Sub is fast and simple. Use it when low latency matters and temporary loss is acceptable; use Streams for persistence.
