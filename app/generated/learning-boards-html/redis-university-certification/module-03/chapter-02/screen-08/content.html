Command

PSUBSCRIBE and glob patterns

Use PSUBSCRIBE pattern to register interest in many channels with a single command. * matches any sequence and ? matches a single character.

# Pattern subscriber
PSUBSCRIBE news:*

# Publisher
PUBLISH news:sports "Team update!"
PUBLISH news:politics "Election results!"
Returned frames
Redis sends pmessage frames that include the pattern, the actual channel, and the message content.
Design caution
Broad patterns increase delivery traffic and may deliver messages you did not intend to process.
Example scenario
Subscribe to app:updates:* to receive all update-related messages. Messages for app:alerts:security will not match and therefore are not delivered to this subscription.
Key Takeaway

PSUBSCRIBE is a flexible way to reduce subscription overhead, but test patterns to avoid unexpected message volume.
