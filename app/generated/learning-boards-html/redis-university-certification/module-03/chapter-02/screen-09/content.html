Module 3 › Chapter 3.2 › message vs pmessage

message (exact)

Delivered when subscriber used SUBSCRIBE channel. Frame includes type, channel, payload.

Format example: ["message", "news:sports", "Team update!"]

pmessage (pattern)

Delivered when subscriber used PSUBSCRIBE pattern. Frame includes type, pattern, channel, payload.

Format example: ["pmessage", "news:*", "news:sports", "Team update!"]
Practical advice
Write subscriber code that checks frame type first, then extracts channel and payload using the correct indices to avoid off-by-one errors when patterns are present.
Common mistake

Parsing frames without checking type leads to extracting the wrong element as the channel when handling pmessage frames.
