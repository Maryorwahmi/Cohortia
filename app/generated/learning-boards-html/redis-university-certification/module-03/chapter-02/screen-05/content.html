Command

PUBLISH & practical notes

PUBLISH channel message — returns number of recipients. Use the return value to detect zero receivers and handle accordingly.

# In a redis-cli publisher session
PUBLISH news:sports "Manchester United won the league!"
Redis returns an integer showing how many subscribers were delivered the message. Zero means no active subscribers at publish time.
Monitoring tip
Log the return count from PUBLISH to detect dropped broadcasts.
Misconception
PUBLISH is not a queue operation—it does not persist messages for future subscribers.
Example
A stock price service publishes updates to a per-symbol channel. Subscribers receiving the update update their UI in real time.
Key Takeaway

Use PUBLISH for instant delivery and read the returned recipient count to detect when no clients were available.
