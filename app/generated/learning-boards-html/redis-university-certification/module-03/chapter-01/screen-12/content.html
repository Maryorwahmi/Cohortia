Module 3 › Chapter 3.1 › Key Concepts
Transactions (MULTI/EXEC)
Queue commands and run them atomically at EXEC time.
WATCH (Optimistic Locking)
Detects concurrent changes; EXEC returns nil on conflict so you can retry.
Pipelining
Batch many commands to reduce network round trips and improve throughput.
Summary Takeaway

Pick transactions for correctness, pipelining for speed, and combine them only when batch sizes remain manageable and inputs are validated.
