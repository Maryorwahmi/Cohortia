Module 3 › Chapter 3.1 › Pitfalls & Best Practices
Pitfalls
  • Expecting transaction rollback on command errors.
  • Relying on WATCH to lock keys instead of detect changes.
  • Creating oversized pipelines that exhaust memory.
Best practices
  • Validate inputs and types before queuing commands.
  • Keep transactions short and retry attempts bounded.
  • Measure pipeline sizes and tune for memory vs latency tradeoffs.
Monitoring checklist
Log EXEC nil responses to find contention hot spots.
Track average pipeline sizes and memory usage.
Alert on repeated retries for the same key pattern.
Try this
Run the inventory scenario with two clients to observe EXEC returning nil, then implement a retry loop with a small backoff to resolve contention in practice.
