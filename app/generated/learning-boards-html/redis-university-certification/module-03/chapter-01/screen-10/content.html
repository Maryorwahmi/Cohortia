Module 3 › Chapter 3.1 › Pipeline + MULTI
Pattern
Open pipeline, queue a MULTI block with its commands, include EXEC, then execute the pipeline. Server executes the MULTI atomically; client receives batched responses.
# conceptual pseudocode
pipe = client.pipeline()
pipe.multi()
pipe.decr('stock:123')
pipe.lpush('cart:user', 'item')
pipe.exec()
pipe.execute()
When to use
Use this when both atomicity and reduced RTTs matter, and the total queued size is modest and predictable.
Operational note
Each queued command consumes memory until the pipeline executes. Monitor client and server memory if you combine large pipelines and long transactions.
Check your design
If your combined batches are large, consider splitting operations into smaller commits or executing critical atomic updates separately from bulk non‑atomic work.
