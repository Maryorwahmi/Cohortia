Validate before queuing
Ensure commands are valid to avoid failed commands in EXEC that won't roll back the rest.
VERIFIED COMPETENCY MILESTONE

Validation tips
Treat transactions as a commit phase, validate data earlier, and keep pipelines to manageable sizes so your server and clients remain responsive.
