Module 3 › Chapter 3.1 › Limits & Error Behavior
What Redis guarantees
  • Queued commands are executed sequentially as a single block when EXEC runs.
  • No other client commands interleave into that execution block.
What Redis does not guarantee
  • Automatic rollback of other commands on per‑command errors.
  • Exclusive locks when using WATCH; WATCH only detects changes.
Practical checklist
Validate commands and types before queuing to avoid EXEC-time failures.
Keep transactions short and queues small to limit memory pressure.
Implement retry policies for WATCH aborts with bounded attempts.
