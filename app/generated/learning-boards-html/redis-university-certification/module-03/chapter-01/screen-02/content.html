Module 3 › Chapter 3.1 › Learning Objectives
01
Use MULTI / EXEC / DISCARD
Queue commands as one atomic operation and cancel safely before commit.
VERIFIED COMPETENCY MILESTONE
Demonstrate a transfer using DECRBY and INCRBY inside MULTI/EXEC.
02
Implement WATCH optimistic locking
Monitor keys and abort if another client changes them before EXEC.
VERIFIED COMPETENCY MILESTONE
Retry pattern after EXEC returns nil in a concurrent update scenario.
03
Explain pipelining
Batch commands into a single network request to reduce RTTs for many keys.
VERIFIED COMPETENCY MILESTONE
Show a Python pipeline that fetches 100 keys in one execute call.
04
Differentiate and combine
Know when atomicity is required versus when performance batching suffices; combine when needed.
VERIFIED COMPETENCY MILESTONE
Demonstrate wrapping MULTI/EXEC in a pipeline to reduce overhead while keeping atomicity.
Why these objectives
Each skill maps directly to real problems: protecting money or inventory transfers, preventing lost updates, and making bulk reads fast over networks. Practicing these patterns reduces bugs and improves latency.
