Core Concept › RDB pros & cons

Advantages

  • Compact binary files ideal for backups and transfers.
  • Fast restart because dataset loads from a single optimized file.
  • Lower runtime overhead when snapshots are infrequent.

Disadvantages

  • Data-loss window between snapshots.
  • Frequent snapshots increase CPU and disk I/O from forks.
  • Not designed for continuous durability guarantees.
Example use cases

Backups, disaster recovery, migrations, and caches where occasional loss is acceptable.

Pro tip

Store dump.rdb on reliable, fast storage and monitor timestamps to confirm successful snapshots.

Final thought

RDB is not a replacement for application-level backups. Use it as part of a broader recovery plan.
