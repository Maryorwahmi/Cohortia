Lab Walkthrough › Hands-on activity
Quick configuration snippet for testing
# RDB configuration
save 5 1
dbfilename dump.rdb
dir ./

# AOF configuration
appendonly yes
appendfilename "appendonly.aof"
appendfsync everysec
Steps
  1. Edit redis.conf and start Redis with it.
  2. Run SET and LPUSH commands to add data.
  3. Run BGSAVE and check dump.rdb timestamp.
  4. Check appendonly.aof content by reading the file.
  5. Simulate crash with a forceful stop and restart server.
  6. Verify data with GET and LRANGE commands.
What to observe
  • Does dump.rdb timestamp update after BGSAVE?
  • Does appendonly.aof contain your commands?
  • After restart, which data returns and from which file?
Key Takeaway

This lab demonstrates persistence in action: configuration, snapshot timing, AOF logging, and real recovery behavior after a crash.
