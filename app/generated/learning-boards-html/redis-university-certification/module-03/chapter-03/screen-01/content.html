Redis Persistence: RDB and AOF

Understand how Redis writes durable state to disk, configure snapshot rules, control AOF behavior, and choose the right persistence strategy for your application.

In this lesson
Snapshots • Command logging • Rewrites • Recovery
Snapshot preview
RDB is a compact binary file representing a point-in-time view of the dataset. It is ideal for backups and fast restarts.
Example: dump.rdb (binary snapshot)
Command log
AOF appends each write command. On restart Redis replays the commands to rebuild state, offering better durability.
Example: appendonly.aof (text of write commands)
Why this matters

Choosing the right persistence balances recovery speed, disk usage, and acceptable data loss. We'll practice configuring both and simulating recovery.

Hands-on preview

You will enable both methods, write data, force a crash, and verify recovery from files on disk.
