What to Remember › Key Concepts
Persistence
Saving memory state to non-volatile storage so it survives restarts.
RDB Snapshot
Point-in-time binary snapshot created by forking a child process.
AOF
Append-only log of write commands; replayed to rebuild dataset on restart.
Summary takeaway

RDB and AOF are complementary: RDB for compact backups and fast loads, AOF for minimal data-loss. Configure both when you need both capabilities.
