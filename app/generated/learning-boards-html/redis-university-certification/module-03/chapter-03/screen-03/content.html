Practice & Assessment

Concrete lab tasks you'll perform and what you'll be evaluated on.

Hands-on checklist
Edit redis.conf

Add save directives, enable appendonly, set file names and dir so you can inspect outputs.

Run and observe

Use redis-cli to set keys, run BGSAVE and BGREWRITEAOF, and inspect files on disk.

Simulate crash

Force-stop the server and restart to verify whether data comes back from dump.rdb or appendonly.aof.

Assessment idea

Explain which persistence mode you'd recommend for a system that cannot tolerate seconds of data loss and why. Demonstrate configuring appendfsync and justify the choice.

Common pitfall

Do not assume the default persistence settings match your application's durability needs; always verify and test recovery.
