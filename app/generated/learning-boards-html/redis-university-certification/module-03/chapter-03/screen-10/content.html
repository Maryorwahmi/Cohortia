Process › Configuring AOF

Key config entries

# Example AOF configuration in redis.conf
appendonly yes
appendfilename "appendonly.aof"
appendfsync everysec # Or 'always' or 'no'
  • appendonly yes turns on AOF logging.
  • appendfilename sets the file name on disk.
  • appendfsync controls fsync frequency and durability.
Concrete example

For many systems, appendfsync everysec is a balanced starting point: you get near-real durability with reasonable performance.

Operational warning

Ensure disk space and throughput are sufficient; a full or slow disk will impair Redis performance and risk corruption if uncontrolled.

Monitoring

Track appendonly.aof size and fsync latency. Schedule BGREWRITEAOF when growth exceeds desired multiples of original size.
