Comparison
Sentinel vs Redis Cluster
Sentinel (High Availability)
Monitors a single master and replicas, performs automatic failover, and tells clients the master address.
Cluster (Sharding & HA)
Shards data across multiple masters, provides high availability per shard, and scales memory and write throughput horizontally.
Remember: Sentinel helps availability for one logical dataset on one master; Cluster spreads keys across many masters and requires clients to follow redirections or use cluster-aware clients.
Key Takeaway

Choose Sentinel for availability of a single node, choose Cluster when you need sharding and horizontal capacity; still backup nodes in either case.
