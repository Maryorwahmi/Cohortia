Definition
Backups and Restores for Redis

Backups: copy dump.rdb and/or appendonly.aof to a secure location. Restores: stop Redis, replace files in the configured dir, and restart to load data.

Why it matters
  • Protects against accidental deletes, disk failures, or faulty deployments.
  • Ensures you can recover to a known point in time and resume operations.
Comparison
RDB Snapshot
Point-in-time snapshot. Fast to load. Possible recent data loss between snapshots.
AOF Log
Append-only operations log. Replayed on startup. More precise recovery; can grow large.
Example
# Trigger a snapshot
BGSAVE
# Compact AOF
BGREWRITEAOF
Key Takeaway

Use RDB for fast restarts and AOF for finer-grained recovery; always test restores to confirm backups work.
