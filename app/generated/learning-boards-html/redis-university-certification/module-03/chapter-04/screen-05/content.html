Create an RDB snapshot
  1. Confirm RDB is enabled in redis.conf using save directives.
  2. Run BGSAVE and wait for completion in the server logs.
  3. Locate dump.rdb using the configured dir and dbfilename.
  4. Copy the file to a secure off-server location and add a timestamp to the filename.
  5. Record the backup in your inventory and verify file integrity.
Common mistake: copying the file before BGSAVE finishes. Always confirm completion in Redis logs or via INFO persistence.
Terminal demo snippet
# Trigger a background save and check status
redis-cli BGSAVE
# After completion copy to backup dir with a date
cp /var/lib/redis/dump.rdb /tmp/redis_backup/dump-2023-09-15.rdb
Key Takeaway

Automate BGSAVE and the off-site copy, and always validate that the backup file completed correctly before relying on it.
