Definition
What Sentinel does
  • Monitoring: health checks for master and replicas.
  • Notification: alerting operators or systems when failures occur.
  • Automatic failover: elect a new master from replicas when needed.
  • Configuration provider: clients query Sentinels for the master address.
Production guidance
Run at least three Sentinel processes on separate hosts or containers so a quorum can be reached. Configure sensible down-after-milliseconds and failover-timeout to balance sensitivity and stability.
Key Takeaway

Sentinel provides automated availability through monitoring and quorum-based failover; configure and test it carefully in staging.
