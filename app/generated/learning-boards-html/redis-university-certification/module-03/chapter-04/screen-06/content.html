Restore Runbook
Restore from RDB
  1. Stop Redis with a clean shutdown to flush state: SHUTDOWN.
  2. Copy your backed-up dump.rdb into the configured dir.
  3. Ensure ownership and permissions match the Redis user and restart the service.
  4. After startup, validate critical keys and sample values with redis-cli.
Tip: run this in staging first and measure how long loading takes for capacity planning.
Verification Checklist
  • Check a set of known keys for expected values.
  • Confirm memory usage and eviction policy are acceptable.
  • Ensure no unexpected AOF replay is occurring if you restored only RDB.
Key Takeaway

A successful restore requires testing, verification, and an understanding of memory and disk impacts before putting the instance back into production.
