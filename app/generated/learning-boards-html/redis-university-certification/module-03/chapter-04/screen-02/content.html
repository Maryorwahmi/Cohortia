Learning Objectives
Steps and concepts you will practice and explain
01
Create RDB and AOF backups
You will run BGSAVE and BGREWRITEAOF, locate dump and AOF files, and copy them off-server for safekeeping.
VERIFIED COMPETENCY MILESTONE
02
Restore from backups
You will stop Redis, replace persistence files, and restart to verify data is loaded correctly from RDB or AOF.
VERIFIED COMPETENCY MILESTONE
03
Understand Sentinel
You will explain monitoring, quorum, automatic failover, and how clients discover the current master via Sentinels.
VERIFIED COMPETENCY MILESTONE
04
Know when to use Cluster
You will contrast Sentinel's HA role with Redis Cluster's sharding and horizontal scalability for large datasets.
VERIFIED COMPETENCY MILESTONE
