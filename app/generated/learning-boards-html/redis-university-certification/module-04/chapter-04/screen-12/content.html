Module 5 › Chapter 4.4 › Limiter Simulation
Simulation pattern
Run repeated requests, sleep short intervals, and log results.
for i in range(1, 10):
  if not is_rate_limited(user, limit=3, window_seconds=10):
    print(f"Request {i} processed")
  else:
    print(f"Request {i} BLOCKED")
  time.sleep(1)
Observations to record
  • Timestamp and request number.
  • Counter value returned by INCR.
  • Whether the request was allowed or blocked and window resets after expiry.
Key takeaway
Simulations reveal burst behaviors and help tune limits and window lengths for real traffic patterns.
