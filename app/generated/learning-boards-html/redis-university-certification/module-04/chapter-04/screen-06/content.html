Top-N and per-player
Commands for retrieving leaders and ranks, and how to present them.
Common queries
  • ZREVRANGE key 0 N-1 WITHSCORES → top N members with scores.
  • ZREVRANK key member → 0-based rank with highest first.
  • ZSCORE key member → numeric score or null if not present.
Presentation note
Add one to Redis rank for human-readable 1-based ranking.
Example & pagination
# Top 3 players
r.zrevrange('game:leaderboard', 0, 2, withscores=True)

# Player rank and score
score = r.zscore('game:leaderboard', 'Alice')
rank = r.zrevrank('game:leaderboard', 'Alice')  # 0-based
if score is not None:
  print('Rank', rank + 1, 'Score', int(score))
Gotcha
Avoid returning entire large sets; use offsets and limits to paginate top-N results.
Key takeaway
Use ZREVRANGE for leaderboards and convert 0-based ranks to human-friendly values.
