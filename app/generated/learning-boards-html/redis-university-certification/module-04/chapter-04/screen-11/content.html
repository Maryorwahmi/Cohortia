Pipeline example
Atomic-ish increment + expire using a pipeline; practical and common.
def is_rate_limited(user_id, limit=5, window_seconds=60):
  key = f"rate_limit:{user_id}:{window_seconds}s"
  pipe = r.pipeline()
  pipe.incr(key)
  pipe.expire(key, window_seconds, nx=True)
  count, _ = pipe.execute()
  return count > limit
Testing guidance
  • Simulate repeated requests to observe when the function blocks.
  • Log both count and whether the key had an expiry set to verify EXPIRE behaviour.
  • Consider Lua when you must guarantee both operations succeed atomically on the server.
Common mistake
Calling INCR and EXPIRE in separate client calls without a pipeline can leave a key without TTL if the client fails between calls.
