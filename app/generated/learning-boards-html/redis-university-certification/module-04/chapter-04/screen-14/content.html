Sliding-window strategies
Use timestamps or counters to create a continuous window of recent requests.
Sorted Set approach
Store request timestamps in a ZSET and ZREMRANGEBYSCORE to evict old entries; count members in the window to enforce the limit.
Sliding counter
Interpolate counts across two adjacent fixed windows to approximate a sliding behavior with less storage cost.
When to use
Choose sliding-window when protecting sensitive resources from short bursts is more important than keeping implementation minimal.
