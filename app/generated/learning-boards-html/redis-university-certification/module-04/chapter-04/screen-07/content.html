update_score and get_top_players
Example uses Redis client to increment scores and print top players.
import redis

r = redis.Redis(host='localhost', port=6379, db=0, decode_responses=True)
LEADERBOARD_KEY = 'game:leaderboard'

def update_score(player_id, score_increase):
  new_score = r.zincrby(LEADERBOARD_KEY, score_increase, player_id)
  print(f"Player {player_id} score updated. New score: {new_score}")
  return new_score

def get_top_players(num_players):
  top_players = r.zrevrange(LEADERBOARD_KEY, 0, num_players - 1, withscores=True)
  for rank, (player, score) in enumerate(top_players):
    print(f"Rank {rank + 1}: {player} (Score: {int(score)})")
  return top_players
Supporting notes
  • ZINCRBY is atomic; use it for concurrent increments.
  • Cast scores when you expect integers. Redis stores scores as floats.
  • Handle missing members: ZSCORE returns null if member absent.
Key takeaway
Use these functions to keep leaderboard state consistent and readable in your app.
