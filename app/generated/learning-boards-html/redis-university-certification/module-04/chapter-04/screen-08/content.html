Per-player lookup
How to fetch a player's score and place after updates.
def get_player_rank_and_score(player_id):
  score = r.zscore(LEADERBOARD_KEY, player_id)
  rank = r.zrevrank(LEADERBOARD_KEY, player_id)
  if score is not None and rank is not None:
    return {"score": int(score), "rank": rank + 1}
  else:
    return None
Explanation
  • ZSCORE may return null; treat missing members gracefully.
  • ZREVRANK provides highest-first 0-based rank; convert to 1-based for display.
  • For nearby context, fetch a small range around rank rather than many single lookups.
Key takeaway
Combine ZSCORE and ZREVRANK to present accurate player context and avoid making many small round trips when possible.
