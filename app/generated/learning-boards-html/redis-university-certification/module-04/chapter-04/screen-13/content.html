Module 5 › Chapter 4.4 › Races & Fixes
Why races happen
Separate client calls can fail in between, leaving inconsistent state.
Mitigation options
  • Use pipelines to send INCR and EXPIRE together.
  • Use MULTI/EXEC for transactional execution if needed.
  • Use Lua scripting for true server-side atomicity.
Example Lua idea
A Lua script that increments the key, sets expiry if needed, and returns the new count in a single atomic call removes client crash concerns entirely.
Gotcha
Pipelines lower the chance of a race but do not provide server-side atomicity in the face of mid-client failures.
