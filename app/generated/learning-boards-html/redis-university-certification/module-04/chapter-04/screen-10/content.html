Fixed-window rate limiter
INCR + EXPIRE per client key enforces request limits per time window.
How it works
  1. Create a key per client and window, e.g., api_limit:{client}:{window}.
  2. INCR the key when a request arrives.
  3. Set EXPIRE for the key to the window length if the key is new.
  4. Reject if count > limit.
Trade-offs
  • Simple to implement and low overhead.
  • Can allow bursts at window edges.
  • Use pipelines or Lua to avoid missing EXPIRE on crashes.
Example key
api_limit:client:web_app:60s — INCR and set EXPIRE 60 seconds if not present.
