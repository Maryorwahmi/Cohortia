Module 5 › Chapter 4.4 › Sorted Sets
Definition & Properties
Unique members, numeric scores, ordered by score. Ideal for top-N and rank queries.
Why it matters
  • Maintains sorted order automatically as scores change.
  • Supports efficient rank retrieval and ranged queries.
  • Score updates are atomic with ZINCRBY, avoiding inconsistent states.
Analogy
Think of a Sorted Set as a ranked scoreboard where each player has a single line showing their current points and place.
Example
ZADD game:leaderboard 150 player:Bob ZADD game:leaderboard 120 player:Alice ZINCRBY game:leaderboard 30 player:Alice ZREVRANGE game:leaderboard 0 2 WITHSCORES
Key takeaway
Use Sorted Sets when you need ranked lists and atomic score updates that scale.
Common mistake
Avoid fetching the entire set for large leaderboards; paginate top ranges.
