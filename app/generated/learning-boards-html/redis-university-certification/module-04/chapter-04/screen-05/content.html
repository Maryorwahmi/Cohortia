ZADD and ZINCRBY
Insertion, updates, and atomic increments for leaderboards.
Step-by-step
  1. Use ZADD to seed the leaderboard with initial scores.
  2. Use ZINCRBY for frequent score changes — it returns the new score.
  3. Optionally call ZREVRANK or ZSCORE to show rank and score after update.
Pro tip
Prefer increments where possible to reflect event deltas and keep intent clear in your code.
Concrete example
# Seed and update
r.zadd('game:leaderboard', {'PlayerA':1200, 'PlayerB':1500})
r.zincrby('game:leaderboard', 200, 'PlayerA')  # PlayerA now 1400
Misconception
Treating ZADD updates as non-atomic is incorrect; a single ZADD call is atomic, but separate read-modify-write patterns risk races.
Key takeaway
Use ZINCRBY for frequent increments and ZADD for seeding or setting absolute scores.
