Module 4 › Chapter 4.2 › Practice Objectives
Practical skills
  • Write retry loops that re-read keys after an abort and re-attempt the transaction.
  • Call UNWATCH or reset the pipeline when aborting to release optimistic locks.
  • Keep WATCH blocks short and fast to reduce retry frequency.
  • Watch only critical keys, not large unrelated sets of keys.
Safety reminders
Avoid type errors: a failing command inside EXEC will not roll back others.
Avoid long external calls between WATCH and EXEC; keep the window small.
Prefer Lua when conditional logic and iteration must run atomically on the server.
