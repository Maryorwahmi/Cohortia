Comparison
Relational DB transaction
Typically supports rollback: if a statement fails, the whole transaction can be undone.
Redis MULTI/EXEC
Executes queued commands atomically relative to other clients, but does not rollback if a command fails during execution.
Type errors still produce side effects in the same EXEC.
WATCH aborts require explicit retry logic.
Lua scripting avoids these multi-round-trip problems by running server-side atomically.
Key Takeaway

Expect to handle partial failures manually: validate earlier, check results, and design retry strategies or use Lua when rollback semantics are required.
