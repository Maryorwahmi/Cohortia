Question
If DECR fails because the key is a non-integer string, will MULTI/EXEC roll back other commands?
Answer
No. EXEC will report the failing command's error in the results array, but other commands will still be executed successfully.
Mitigation: validate the key type before queueing DECR or use server-side Lua to implement full all-or-nothing logic.
