Module 4 › Chapter 4.2 › Key Concepts
Atomicity
Either single commands succeed entirely, or MULTI/EXEC executes queued commands together without interleaving from other clients.
WATCH
Optimistic lock: monitor keys, and if they change before EXEC the transaction aborts and must be retried.
Lua Scripting
Server-side scripts run atomically and are ideal when complex conditional logic or iteration is needed without many round trips.

Takeaway: use the right tool—MULTI/EXEC for grouped commands, WATCH for optimistic checks and retries, Lua when server-side atomic logic is required.
