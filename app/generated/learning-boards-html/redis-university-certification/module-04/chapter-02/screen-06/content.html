Starter code (Python)
import redis

r = redis.Redis(host='localhost', port=6379, db=0, decode_responses=True)

item_id = "product:123"
user_id = "user:abc"

r.set(f"{item_id}:stock", 10)  # Initialize stock

# Start a transaction
pipe = r.pipeline()
pipe.decr(f"{item_id}:stock")
pipe.lpush(f"{item_id}:purchases", user_id)

# Execute all commands atomically
results = pipe.execute()
print(f"Transaction results: {results}")  # [9, 1] - new stock, list length

print(f"Current stock for {item_id}: {r.get(f'{item_id}:stock')}")
print(f"Purchases for {item_id}: {r.lrange(f'{item_id}:purchases', 0, -1)}")
What to watch for
  • Check the results array: each queued command produces a reply or an error entry.
  • Validate types before queueing to avoid runtime errors in EXEC.
  • Use pipelines and MULTI when commands must be applied together for consistency.
Concrete example
Decrement stock and push purchaser ID together so inventory and purchase logs stay in sync after a successful EXEC.
Common mistake
Assuming EXEC will rollback on a failing command. It will not — handle errors explicitly.
