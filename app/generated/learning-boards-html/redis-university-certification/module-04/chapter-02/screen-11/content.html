Architecture decision

When to pick Lua

Use Lua when
  • You need conditional checks and updates that must be atomic.
  • You must iterate or compute over server data without many round trips.
Use WATCH/MULTI when
  • Updates are simple and validations are inexpensive.
  • Retries on conflicts are acceptable and cheap.
Lua is a powerful escalation: it provides full atomicity with conditional logic server-side and avoids complex client retry loops at the cost of moving logic into the Redis server.
