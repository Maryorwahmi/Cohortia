Module 4 › Chapter 4.1 › Connection Errors
Common Errors
ConnectionError / error event
Indicates socket open failed; check service status and network reachability.
ECONNREFUSED
Server refused the connection — verify Redis is running and listening on the right port.
AuthenticationError
Password missing or incorrect; attempt a connection without password to observe the failure mode safely.
Troubleshooting Steps
  1. Confirm redis-server is running and listening on the expected host and port.
  2. Try redis-cli from the same host or namespace as the application.
  3. Check firewall rules and cloud security groups for port 6379.
  4. Verify credentials are provided securely, not hardcoded in source control.
Warning

Do not log passwords. Use safe diagnostics and controlled retry strategies for transient network errors.
