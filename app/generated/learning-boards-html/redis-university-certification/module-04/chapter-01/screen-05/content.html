Module 4 › Chapter 4.1 › Connection Parameters
Parameters

Host, Port, DB, Password

Provide the server hostname or IP and the port, default 6379. Optionally include the database index and password when needed.

Verify with PING

Always perform a ping after connecting to confirm authentication and reachability.

Misconception

Assuming localhost means reachable — containers or remote hosts can change accessibility.

Concrete Example
In Python, pass host, port, db, and password to redis.Redis. In Node.js, pass the same options to ioredis. After creating the client call PING to confirm the connection and authentication succeeded.
Example check

If PING fails with an AuthenticationError, verify the password is supplied via environment variables and not hardcoded in source control.
