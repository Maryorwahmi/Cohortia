Module 4 › Chapter 4.1 › Graceful Shutdown
Recommended pattern

Shutdown handlers

Hook into termination signals to call quit or disconnect and ensure open sockets are closed before exiting. This prevents resource leaks and keeps Redis connection counts stable.

Test
Send a termination signal to your app and verify that the Redis server shows the connection closed. If not, add explicit quit/disconnect calls in your shutdown sequence.
Example steps
  1. Register a shutdown handler for SIGINT/SIGTERM.
  2. Call client.quit() or pool.disconnect() inside the handler.
  3. Await completion before exiting the process.
Key Takeaway

Graceful shutdown prevents resource leaks and makes rolling deployments safer and more predictable.
