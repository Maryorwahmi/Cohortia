Principles

Secrets and access control

  • Do not hardcode passwords in source code.
  • Use environment variables or secret stores for credentials.
  • Restrict access to port 6379 to trusted hosts or networks.
Hands-on guidance
Set requirepass in redis.conf, restart the server, and then connect using a password read from an environment variable. Attempt an unauthenticated connection to observe the AuthenticationError behavior and handle it in code.
Operational note
Rotate credentials periodically and update your environment or secret store configuration during deployments.
