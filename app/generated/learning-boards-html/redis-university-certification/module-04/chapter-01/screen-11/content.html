Definition

Client decoding behavior

redis-py returns bytes by default. decode_responses=True converts byte responses into native Python strings, avoiding common type errors in application code.

Concrete example
If you call r.get('key') without decode_responses you receive b'value'. Concatenating that directly with a normal string raises a type error unless you decode it manually.
Checklist
  • Decide whether your app expects text or raw bytes.
  • Set decode_responses=True when working with strings in Python.
  • Document decoding choices for team clarity.
Key Takeaway

Align client decode behavior with application expectations to avoid subtle type bugs.
