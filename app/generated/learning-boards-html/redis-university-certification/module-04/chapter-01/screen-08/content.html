Explicit ConnectionPool

import redis

pool = redis.ConnectionPool(host='localhost', port=6379, db=0, decode_responses=True, max_connections=20)
r = redis.Redis(connection_pool=pool)

r.set('anotherkey', 'Pooled connection works!')
print(r.get('anotherkey'))

# On shutdown
pool.disconnect()
Explicitly creating a pool allows you to tune max_connections. Use pool.disconnect() at shutdown to release sockets.
Notes
  • redis-py uses pooling by default but explicit pools give tuning control.
  • Set max_connections according to expected concurrency and OS limits.
  • Disconnect the pool on graceful shutdown to free resources.
Pro tip
Measure pool utilization under load to choose a sensible max_connections value rather than guessing.
