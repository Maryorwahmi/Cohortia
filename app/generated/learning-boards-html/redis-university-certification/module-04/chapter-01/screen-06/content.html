redis-py example

import redis
import os

REDIS_PASSWORD = os.getenv('REDIS_PASSWORD')

try:
  r = redis.Redis(host='localhost', port=6379, db=0, password=REDIS_PASSWORD, decode_responses=True)
  r.ping()
  print('Connected to Redis!')

  r.set('mykey', 'Hello Cohortia!')
  value = r.get('mykey')
  print(f"Value for 'mykey': {value}")

except redis.exceptions.AuthenticationError as auth_err:
  print('Authentication failed:', auth_err)
except redis.exceptions.ConnectionError as conn_err:
  print('Could not connect:', conn_err)
except Exception as e:
  print('Unexpected error:', e)
This code uses decode_responses so get returns a string. The try-except pattern demonstrates graceful handling of connection and authentication failures.
Explanation
  • r = redis.Redis(...) opens a client using provided parameters.
  • r.ping() validates connectivity and authentication.
  • r.set and r.get are synchronous requests with immediate responses.
Key Takeaway

A simple ping and set/get verify both connectivity and expected data types when decode_responses is set.
