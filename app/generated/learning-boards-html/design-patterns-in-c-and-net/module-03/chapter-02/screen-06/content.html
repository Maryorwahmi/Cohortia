Structure
Pattern hierarchy
Component interface → Concrete Component; Abstract Decorator → Concrete Decorators. The abstract decorator holds and delegates to a Component reference.
Component Interface
Defines contract (e.g., GetDescription, GetCost). Both components and decorators implement it.
Abstract Decorator
Implements the interface and stores a reference to a Component. Delegates by default to the wrapped object.
Annotation cards
Concrete Component
Provides base behavior. Example: SimpleCoffee returns "Simple Coffee" and base cost.
Concrete Decorator
Overrides methods to add to description or cost, while delegating other calls to the wrapped component.
Pro tip
Keep each decorator focused on a single responsibility. If it grows complex, consider splitting it into multiple decorators or refactoring responsibilities elsewhere.
Key Takeaway

The abstract decorator is the thin wrapper that makes transparent, stackable composition possible while preserving client expectations.
