Notification decorator starter code
using System;

// 1. Component Interface
public interface INotificationService
{
  void Send(string message);
}

// 2. Concrete Component
public class BaseNotification : INotificationService
{
  public void Send(string message)
  {
    Console.WriteLine($"Base Notification: {message}");
  }
}

// 3. Abstract Decorator
public abstract class NotificationDecorator : INotificationService
{
  protected INotificationService _notificationService;

  public NotificationDecorator(INotificationService notificationService)
  {
    _notificationService = notificationService;
  }

  public virtual void Send(string message)
  {
    _notificationService.Send(message);
  }
}
Starter hints
  • Implement SmsDecorator and EmailDecorator to call base.Send then print their own message.
  • Chain decorators in Main to observe combined output.
  • Remove NotImplementedException in the sample Email method and replace with concrete logic.
Key Takeaway

Use this exercise to practice delegation, constructor injection, and verifying decorator chain side effects via console output or unit tests.
