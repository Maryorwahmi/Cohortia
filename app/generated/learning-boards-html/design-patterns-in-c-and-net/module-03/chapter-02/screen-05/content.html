Process Flow
Step-by-step: Coffee decorators
1
Define component interface
Operations: GetDescription(), GetCost(). Clients program to this interface only.
2
Create concrete component
SimpleCoffee implements the interface and returns base values.
3
Implement abstract decorator
Implements the interface and holds an inner component reference, delegating by default.
4
Create concrete decorators
MilkDecorator adds cost and description, calling the wrapped component's methods then adding its contribution.
5
Compose at runtime
Wrap the base with decorators as needed and call the interface methods to get combined behavior.
Concrete example
Compose: new SugarDecorator(new MilkDecorator(new SimpleCoffee())). Calling GetDescription returns a concatenated description that reflects each decorator's addition. GetCost returns the sum of each cost contribution.
Common misconception
Assuming decorators are identical to subclasses. They are composition wrappers and allow runtime assembly rather than compile-time subclassing.
Key Takeaway

Follow the five steps to structure decorator code and test composed chains to verify behavior and order sensitivity.
