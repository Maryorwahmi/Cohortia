Runtime Composition
Compose and reason about order
Each decorator receives the wrapped object's output and may modify it. Order therefore influences behavior for non-commutative operations.
Example: Coffee order
Milk then Sugar yields description "Simple Coffee, with Milk, with Sugar". Costs add in any order. String concatenation is order-sensitive but harmless here.
Example: Data chain
Compression then encryption differs from encryption then compression. These operations are not commutative and order impacts correctness and efficiency.
Practical checks
  • Write tests for representative chains.
  • Document decorator preconditions and ordering rules.
  • Profile chains if used in performance-critical code paths.
Check your understanding
Name a pair of operations where order matters and explain why. Consider compression, encryption, formatting, and logging as candidates.
Key Takeaway

Think beyond composition: ordering and preconditions can change correctness and performance. Test the chains you create.
