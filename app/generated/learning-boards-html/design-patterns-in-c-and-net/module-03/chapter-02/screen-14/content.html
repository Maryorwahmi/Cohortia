Module 3 › Chapter 3.2 › Key Concepts
Decorator Pattern
Adds responsibilities to objects dynamically via wrapping and a common interface.
Component Interface
Clients program to the interface so decorated and plain objects are interchangeable.
Dynamic Extension
Compose decorators at runtime to build feature combinations without new subclasses.
Summary Takeaway

Decorators enable flexible, testable extensions. Use them when features are optional and combinable, and keep each decorator small and well-documented.
