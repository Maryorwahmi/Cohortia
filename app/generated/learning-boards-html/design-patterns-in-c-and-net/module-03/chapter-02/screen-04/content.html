Core Concept
Decorator pattern — definition
A composition-based approach to add responsibilities to objects dynamically while preserving a uniform interface for clients.
Key properties
  • Uses a common component interface.
  • Concrete decorators wrap a component and enhance behavior.
  • Supports runtime combinations without new subclasses.
Concrete example (conceptual)
A SimpleCoffee implements ICoffee. A MilkDecorator implements ICoffee and holds an ICoffee reference. MilkDecorator adds cost and description while delegating other calls.
Analogy: Coffee order
Start with a base coffee. Add milk, sugar, caramel in any order. Each topping decorates the base and changes taste and cost. No need for a specific subclass for every topping combination.
Key Takeaway
Decorator favors composition over inheritance to keep behavior modular and combinable at runtime.
