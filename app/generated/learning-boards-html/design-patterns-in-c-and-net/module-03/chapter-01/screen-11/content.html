Question 1: Integrate ThirdPartyAnalytics
Explain why Adapter fits and outline the structure: Target = IAnalyticsService, Adaptee = ThirdPartyAnalytics, Adapter = ThirdPartyAnalyticsAdapter implementing TrackEvent and calling SendMetric with mapped values.
Question 2: Shape drawing
When adapting shapes to LegacyDrawingTool, prefer Object Adapter to extract drawing parameters from a Shape instance and call RenderGraphics, ensuring testability via composition.
Sample solution structure
  • Define Target interface matching client expectations.
  • Implement Adapter using constructor injection for the Adaptee.
  • Translate call parameters and call the Adaptee method(s).
  • Write unit tests that mock the Adaptee and integration tests that run the real Adaptee.
Key Takeaway

In assessments, show the mapping rules, explain why composition is chosen, and include tests to prove correct translation and integration safety.
