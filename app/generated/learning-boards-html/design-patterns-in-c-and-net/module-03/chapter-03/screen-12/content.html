Architecture
When to Apply Composite
Composite fits when parts and wholes should be treated uniformly and the structure is inherently tree-shaped, such as file systems, UI trees, and org charts. If the cost of runtime checks is unacceptable, prefer safer interfaces and explicit type checks when mutating structure.
Good fit
File browsers, nested UI containers, organizational hierarchies.
Consider alternatives
If elements differ greatly in behaviour or you need many unrelated operations, combine with Visitor or use specialized managers.
Real-world mapping
Map domain concepts to Component, Leaf, and Composite deliberately. Only expose child-management where it makes sense for clients and your safety model.
Design checklist
  • Are operations uniform across parts and wholes?
  • Will structural mutations be frequent or rare?
  • Are deep hierarchies expected?
