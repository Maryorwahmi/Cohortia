Traversal and Aggregation
Composites perform an operation, then iterate children and delegate the same operation. Leaves return primitive results, and composites combine child results to compute aggregates such as total size or employee count.
Recursive traversal
Composite.Display(indent) { print; foreach child call Display(indent+2); }
Aggregation example
GetEmployeeCount in Department sums children counts; Employee returns one.
Performance tip
Cache aggregates if you frequently query totals and update caches on structure changes to avoid repeated full traversals.
Example: GetEmployeeCount
Employee.GetEmployeeCount returns 1. Department.GetEmployeeCount iterates all children, calling GetEmployeeCount and summing the results. This recursive contract is simple and testable.
Common pitfall

Deep recursion can overflow the stack. For very deep or unbounded hierarchies, implement iterative traversal using an explicit stack.
