Assembling the File System
// Build a root folder
Folder root = new Folder("My Drive");
Folder documents = new Folder("Documents");
Folder photos = new Folder("Photos");
Folder projects = new Folder("Projects");
documents.Add(new File("Report.docx", 1024));
photos.Add(new File("Vacation.jpg", 2048));
Folder webApp = new Folder("WebApp");
webApp.Add(new File("index.html", 256));
projects.Add(webApp);
root.Add(documents);
root.Add(photos);
root.Add(projects);
root.Display(0);
Test idea
Assert that Display output contains a line for each file and folder in the expected order and that GetEmployeeCount or size calculations match expected totals.
Practical warnings
  • Removing by constructing a new object with the same name will not remove the stored instance unless equality is implemented.
  • Recursive traversal is simple but can fail for extremely deep trees; consider iterative approaches for those cases.
  • Concurrent modifications to a composite's child list require synchronization to avoid race conditions.
Pro tip

Use identity or unique IDs for elements you will remove frequently to avoid equality pitfalls.
