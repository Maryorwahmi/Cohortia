Identifying Code Smells

Surface indications that hint at deeper design problems.

Definition

A code smell is a surface indication that usually corresponds to a deeper problem in the system, often hinting at the presence of an anti-pattern.

Examples of Code Smells
  • Long Methods / Large Classes
  • Duplicate Code
  • Feature Envy (a class uses more methods of another class than its own)
  • Shotgun Surgery (a single change requires many small changes in many classes)
Why They Matter

They are warning signs that your code might be difficult to understand, maintain, or extend, allowing for proactive refactoring.
