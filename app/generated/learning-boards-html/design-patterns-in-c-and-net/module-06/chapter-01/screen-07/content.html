Magic Strings and Numbers

Hardcoded literal values that reduce readability and introduce errors.

Definition

The use of literal strings or numbers directly in code to represent important values without being defined as named constants or enums.

Risks

Makes code difficult to read, highly prone to typos, and extremely hard to refactor consistently across a codebase.

Example Scenario

Using if (order.Status == "Pending") in multiple places, where "Pending" is a magic string.

Hardcoded Values

"Admin", "Pending", 42, "C: emp"
