Module 6 › Chapter 6.4 › Unit Tests vs Integration Tests
Unit test characteristics
  • Isolated from external systems using mocks or stubs.
  • Fast to run and easy to diagnose when failures occur.
  • Ideal for verifying delegation, algorithms, and small behaviors.
Integration test characteristics
  • Verify multiple components together, including persistence and configuration.
  • Slower, but necessary for critical end-to-end validation.
  • Use for critical flows like payment processing with faked external services or an in-memory database.
Guideline
Favor many unit tests for quick feedback and a few targeted integration tests for confidence where composition or environment affects correctness.
