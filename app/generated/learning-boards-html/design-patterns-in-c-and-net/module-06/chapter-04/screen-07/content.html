Module 6 › Chapter 6.4 › Mocking and Stubbing Techniques
Decision process (steps)
1
Do you need to verify calls?
If yes, use a mock and Verify. If no, a stub or fake is faster and simpler.
2
Is the dependency external or slow?
Replace it with a test double to keep unit tests deterministic and fast.
3
Avoid over-mocking
Mock only where behavior must be observed. Favor simple fakes for predictable data.
Moq tips
  • Use Setup to return values for stubs: mock.Setup(m => m.GetValue()).Returns(value);
  • Use Verify to assert interactions: mock.Verify(m => m.Send(It.IsAny<string>()), Times.Once());
  • Prefer It.Is<T> to assert argument shapes rather than exact instances when appropriate.
Example
Use a stub for a repository that returns static test data, and use a mock for a payment gateway where you must verify the call and amount passed.
Key Takeaway

Pick the simplest double that satisfies the assertion you care about. Keep tests fast and focused.
