Module 6 › Chapter 6.4 › Learning Objectives
Skill outcomes
  • Interaction verification: Learn to assert calls, arguments, and call counts with Moq to confirm delegation.
  • Factory assertions: Test returned concrete types, expected messages, and exception paths to avoid silent failures.
  • Mock vs stub choice: Use stubs for simple returns, mocks when behavior and argument verification matter.
  • Test scope judgment: Choose unit tests for speed and isolation; reserve integration tests for critical end-to-end paths.
Common pitfall
Avoid tests that check "the pattern works" — instead check that your PaymentContext delegates correctly and that your factory returns the expected type for given inputs.
