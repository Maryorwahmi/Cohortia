Comparison
Fat interface vs Segregated interfaces
Fat interface
public interface IMultiFunctionDevice
{
  void Print(string document);
  void Scan(string document);
  void Fax(string document);
  void Copy(string document);
  void Staple(string document);
}
BasicPrinter must implement methods it doesn't support, which leads to NotSupportedException and brittle code.
Segregated interfaces
public interface IPrinter { void Print(string document); }
public interface IScanner { void Scan(string document); }
public interface IFaxMachine { void Fax(string document); }
public interface IStapler { void Staple(string document); }
After segregation, each device implements only the interfaces it actually supports, making client dependencies explicit and safe.
Pro‑Tip

Group behaviors by role, not by implementation convenience. This creates interfaces that reflect real client usage.
