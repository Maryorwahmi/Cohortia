Process Flow
Refactor for LSP
A short, safe sequence to move optional behavior into interfaces.
1. Detect optional methods
Find base methods that not all subclasses can implement.
2. Extract interface
Create a focused interface for the optional behavior, e.g., IFlyable.
3. Implement selectively
Only types that can perform behavior implement the new interface.
4. Update clients
Change client signatures to accept the focused interface when needed.
5. Test
Add unit tests to assert correct substitutability and no regressions.
Example client adjustments
// Before
public void MakeBirdsFly(List<Bird> birds)
{
  foreach (var bird in birds) bird.Fly();
}

// After
public void MakeFlyablesFly(List<IFlyable> flyables)
{
  foreach (var f in flyables) f.Fly();
}
Pro‑Tip
Run small focused tests for each behavior to ensure new interfaces meet expectations.
Pitfall
Avoid creating an interface per method; group closely related operations.
