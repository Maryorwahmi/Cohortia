Starter code (violates DIP)
// PaymentGateway constructs CreditCardProcessor directly
public class PaymentGateway
{
  private CreditCardProcessor _creditCardProcessor;

  public PaymentGateway()
  {
    _creditCardProcessor = new CreditCardProcessor(); // Direct instantiation
  }

  public void InitiatePayment(PaymentRequest request)
  {
    if (request.PaymentMethod == "CreditCard")
    {
      _creditCardProcessor.Process(request);
    }
    else
    {
      Console.WriteLine($"Payment method '{request.PaymentMethod}' not supported by this gateway version.");
    }
  }
}
Refactor steps
  1. Extract IPaymentProcessor with Process method.
  2. Make CreditCardProcessor implement IPaymentProcessor.
  3. Create PayPalProcessor implementing IPaymentProcessor.
  4. Change PaymentGateway to accept IPaymentProcessor in constructor.
  5. Wire concrete implementations in Program.cs.
Why this helps
PaymentGateway no longer knows about payment types. Tests can inject a mock processor to simulate transactions without external calls.
