Module 2 › Chapter 1.3 › Key Concepts
Liskov Substitution
Subtypes must honor the base type's behavioral contract so clients can substitute safely.
Interface Segregation
Prefer small interfaces grouped by client needs to avoid NotSupportedExceptions.
Dependency Inversion
High-level modules depend on abstractions. Wire concrete implementations at the composition root.
Summary Takeaway

Design small interfaces, keep base classes honest, and inject dependencies to make systems maintainable and testable.
