ISP heuristic
If implementers throw NotSupportedException, split the interface.
LSP heuristic
If any subtype can't honor a method, that method shouldn't be on the base type.
DIP heuristic
If a class constructs a dependency, consider extracting an interface and injecting it.
Final Prompt

Before refactoring, ask: can this dependency be replaced by an abstraction and a test double without changing the high-level logic?
