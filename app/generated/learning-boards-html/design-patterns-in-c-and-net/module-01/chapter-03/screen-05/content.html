Violation example
Failing code
public class Bird
{
  public virtual void Fly()
  {
    Console.WriteLine("Bird is flying.");
  }
}

public class Penguin : Bird // Penguin cannot fly
{
  public override void Fly()
  {
    throw new NotSupportedException("Penguins cannot fly!");
  }
}

public class Aviary
{
  public void MakeBirdsFly(List<Bird> birds)
  {
    foreach (var bird in birds)
    {
      bird.Fly(); // Crashes if a Penguin is present
    }
  }
}
Why this breaks substitution
  • Base type promises Fly; clients rely on that promise.
  • Pigeon or Sparrow honor Fly; Penguin cannot, so substitution fails.
  • Runtime exceptions reveal the contract mismatch late.
Safe refactor
public interface IFlyable { void Fly(); }

public class Sparrow : Bird, IFlyable { public void Fly() { /* ... */ } }
public class Penguin : Bird { public void Swim() { /* ... */ } }
After the refactor, Aviary should only call Fly on IFlyable collections, and Bird remains the common, substitutable abstraction for non-flying behaviors.
