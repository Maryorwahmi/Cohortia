Architecture
Constructor Injection
public class OrderProcessor
{
  private readonly ILogger _logger;
  public OrderProcessor(ILogger logger)
  {
    _logger = logger; // Injected dependency
  }
}
This approach makes OrderProcessor easy to test because you can pass a mock ILogger from your unit test harness.
Property Injection
Useful for optional dependencies but less explicit. Example: public ILogger Logger { get; set; }
Method Injection
Pass dependency only to the method that needs it: void Process(ILogger logger) — good for transient collaborators.
Composition Root
Centralize object creation at startup. This is where you decide which concrete implementations satisfy abstractions for the whole application.
