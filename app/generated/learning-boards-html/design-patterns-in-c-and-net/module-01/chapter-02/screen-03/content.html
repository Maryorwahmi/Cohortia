Demonstrable outcomes

Each objective maps to a concrete refactor or testable behavior in a small C# program.

SRP Example
Extract persistence into IUserRepository, validation into IUserValidator, and email into IEmailService. Compose via a UserService.
OCP Example
Replace category-based conditionals with IDiscountStrategy implementations and a calculator that accepts strategies.
Verification
You will show a small program where a DocumentSaver is refactored to accept different savers via an interface. The client code remains unchanged when a new saver is added.
Pro tip
Apply OCP where you expect new variants. Avoid premature abstraction when requirements are stable.
