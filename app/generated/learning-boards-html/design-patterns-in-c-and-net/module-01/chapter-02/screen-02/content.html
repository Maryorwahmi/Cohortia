Learning Objectives

Bloom: Learn → Understand → Apply → Master

Bloom's Progression
01
Explain SOLID's role

Describe how SOLID guides C# design and why these rules improve maintainability and team clarity.

VERIFIED COMPETENCY MILESTONE
02
Apply SRP

Refactor classes so each has one reason to change; extract repositories, validators, and services as needed.

VERIFIED COMPETENCY MILESTONE
03
Implement OCP

Use interfaces and strategy implementations so new behavior is added by new classes instead of modifying existing ones.

VERIFIED COMPETENCY MILESTONE
04
Identify violations

Spot common SRP and OCP anti-patterns and propose refactors that reduce coupling and increase extensibility.
