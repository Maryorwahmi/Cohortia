Module 1 › Chapter 1.2 › Key Concepts
SRP
Keep a single responsibility per class to limit reasons for change.
OCP
Add new functionality via new implementations rather than editing stable code.
Abstraction
Interfaces and small implementations are the mechanisms to achieve SRP and OCP.
Summary

Apply SRP to isolate reasons to change and OCP to add behavior via extension points; do so pragmatically and incrementally.
