Process

Introduce a notification interface

  1. Define a small INotifier interface that expresses the send intent.
  2. Create a ConsoleNotifier that implements the interface to keep current behavior.
  3. Inject the notifier into ProductService so it depends on an abstraction.
  4. Add new notifier implementations as needed and configure them centrally.
Concrete example
INotifier, ConsoleNotifier, EmailNotifier
Start with a simple interface and one implementation. Later you can add other implementations without touching ProductService.
Pro tip

Prefer constructor injection for testability and clear ownership of dependencies.
