Module 4 › Chapter 4.2 › Mistakes & Guidance
Overuse
Don't wrap calls that will never be queued, logged, or undone — use direct calls for simplicity.
Complex Commands
Keep domain logic in receivers; commands should orchestrate, not implement heavy algorithms.
Undo Safety
Capture required state at Execute time and handle cases where undo is impossible gracefully.
Design Checklist
Ask: Will I need to queue, log, or undo this action? If yes, command is appropriate. If no, prefer a direct call.
