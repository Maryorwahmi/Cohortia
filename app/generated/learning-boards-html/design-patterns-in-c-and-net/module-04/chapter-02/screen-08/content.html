RemoteControl Essentials
// Set an on/off command for a slot
remote.SetCommand(0, livingRoomLightOn, livingRoomLightOff);
// Execute
remote.OnButtonWasPushed(0);
// Undo last
remote.UndoButtonWasPushed();
Using a NoCommand default avoids nulls and keeps invocation simple: every slot always responds to Execute and Undo.
Invoker Safety
  • Wrap Execute calls in try/catch to maintain consistent undo state.
  • Decide how failed Execute affects the undo history — do not push failed commands.
  • Consider thread-safety if commands may be executed from multiple threads.
Example Outcome
Sequence: TurnOn, OpenGarage, TurnOff; Undo will reverse the most recent command first.
