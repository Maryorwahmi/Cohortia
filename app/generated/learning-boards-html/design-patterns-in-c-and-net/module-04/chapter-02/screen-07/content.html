LightOnCommand (example)
public class LightOnCommand : ICommand
{
  private Light _light;
  public LightOnCommand(Light light) { _light = light; }
  public void Execute() { _light.TurnOn(); }
  public void Undo() { _light.TurnOff(); }
}
Note how the command delegates the real operation to the Light receiver without implementing the domain logic itself.
Guidelines
  • Store small snapshots for Undo, not full object copies when possible.
  • Keep commands focused: one responsibility per command.
  • Share receivers between commands rather than duplicating state.
Check
Can this command call only receiver methods and store minimal undo state? If yes, the design is clean.
