ICommand Contract
Expect Execute() for action and Undo() to reverse it. Implementations must store any data needed to undo.
C# Snippet
public interface ICommand
{
  void Execute();
  void Undo(); // Optional but recommended for undo/redo
}
Misconception
Undo is not always a simple inverse of Execute; it often needs captured state to restore faithfully.
Example: DeleteTextCommand
When deleting, the command should store the deleted substring during Execute so Undo can re-add it. Without storing that state, Undo cannot restore the original content.
Design Tip
If commands may be long-running, consider adding ExecuteAsync or running Execute inside a Task so the UI thread remains responsive.
