Activity
Text Editor with Undo
Convert AddText and DeleteText to ICommand implementations, push executed commands to a Stack, and implement UndoLastAction by popping and calling Undo.
Safety Checklist
  • Use NoCommand to avoid null slot errors.
  • Catch exceptions in Execute to keep invoker stable.
  • Decide when to batch small commands into MacroCommand.
  • Consider async execution for heavy commands.
Verification
Write unit tests: execute an Add, check document content; delete, check content; undo, verify restoration.
Tip
If many commands are heavy, mark them 'heavy' and schedule them on a background queue rather than executing on the UI thread.
