Module 4 › Chapter 4.2 › NoCommand & Macro
NoCommand
A harmless default that implements ICommand with empty Execute/Undo to avoid null checks in invoker slots.
NoCommand Example
Return a NoCommand for unassigned slots so the invoker can call Execute without branching.
MacroCommand
Holds a list of commands. Execute calls Execute on each subcommand; Undo calls Undo in reverse order.
Design Note
Decide failure semantics: roll back completed steps or report partial completion and require manual recovery.
