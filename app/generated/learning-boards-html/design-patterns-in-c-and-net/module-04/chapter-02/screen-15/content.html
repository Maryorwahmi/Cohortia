Module 4 › Chapter 4.2 › Key Concepts
Command Pattern
Encapsulates requests as objects for queuing, logging, and undo.
ICommand Interface
Defines Execute and often Undo; concrete commands implement it.
Invoker & Receiver
Invoker triggers commands; receiver contains the domain implementation.
Takeaway

Use the Command pattern when you need decoupling, undo/redo, queuing, or logging. Keep commands focused and handle heavy work asynchronously.
