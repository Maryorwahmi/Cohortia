Module 4 › Chapter 4.2 › Performance Considerations
Common Issue
Executing heavy operations synchronously inside Execute blocks the UI and degrades user experience.
Mitigations
  • Execute asynchronously or provide ExecuteAsync.
  • Report progress for long tasks so users see activity.
  • Batch small commands into MacroCommands to reduce overhead.
  • Checkpoint or prune undo history to save memory.
Practical Example
If applying an image filter takes seconds, schedule it on a background thread and push a lightweight command to the UI that tracks the job and updates state when complete.
Check
Would running this command on a background queue preserve required ordering and undo semantics? If not, consider compensating commands.
