Undo / Redo Stacks
Push command on execute. Undo pops and calls Undo. For redo, pop from redo stack back onto undo.
Example: Text Editor
AddTextCommand stores the added text. On delete, DeleteTextCommand stores deleted substring. Undo uses stored data to restore content.
Limitations
  • Commands with external side effects may not be fully undoable.
  • Large histories cost memory; consider checkpointing or pruning.
  • Long-running operations may need compensating commands rather than strict undo.
