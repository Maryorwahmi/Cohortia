Module 4 › Chapter 4.2 › Invoker, Command, Receiver
Layered Architecture
Keep invoker, commands, and receivers separate so responsibilities stay focused and changes are localized.
Invoker (RemoteControl)
Stores commands, calls Execute, and can keep an undo reference.
Command (LightOnCommand)
Holds receiver reference and implements Execute and Undo.
Receiver (Light)
Performs the concrete actions.
Example: Remote Slots
A RemoteControl may hold arrays of onCommands and offCommands and a field to reference the last executed command for undo. No change to RemoteControl is needed when adding new device types.
Design Notes
  • Keep each command focused on one operation to respect single responsibility.
  • Use NoCommand to avoid null checks for empty slots.
