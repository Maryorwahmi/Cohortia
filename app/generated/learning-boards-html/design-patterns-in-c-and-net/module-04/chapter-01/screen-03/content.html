Practice and Pitfalls
What to practice and what to avoid when applying Strategy.
Practice
Write an interface, implement each strategy, inject into a context, and write tests that validate each algorithm independently.
Pitfall
Avoid letting a context decide which concrete strategy to create based on strings or flags; that couples the context and defeats the pattern’s purpose.
Use dependency injection or factories to provide strategies. If strategies share behavior, consider factoring common code into a base class or using Template Method instead. These choices keep your code maintainable and testable as requirements change.
Quick Tip
If adding a strategy means only adding a branch in a switch and nothing else, Strategy may be overkill until the behavior grows in complexity.
