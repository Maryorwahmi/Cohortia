Essential C# snippets you will use and test.
// Strategy interface
public interface IShippingStrategy
{
  double CalculateCost(Order order);
}

// USPS strategy
public class USPSStrategy : IShippingStrategy
{
  public double CalculateCost(Order order)
  {
    return 5.00 + (order.WeightInKg * 1.50);
  }
}

// FedEx strategy
public class FedExStrategy : IShippingStrategy
{
  public double CalculateCost(Order order)
  {
    return 8.00 + (order.VolumeInCubicMeters * 2.20);
  }
}
Testing tip
Create a sample Order and assert the cost returned by each strategy. This isolates algorithm logic from the context.
Null-safety
Check constructor and setter arguments in the context and throw ArgumentNullException if a null strategy is supplied.
Key Takeaway
Small, focused classes are easier to test and extend than a single monolithic conditional implementation.
