Module 4 › Chapter 4.1 › Swapping Strategies
Changing algorithms at runtime
Examples, safety, and DI lifetimes.
var order = new Order { OrderId = 101, WeightInKg = 2.5 };

var service = new ShippingService(new USPSStrategy());
Console.WriteLine(service.GetShippingCost(order));

service.SetStrategy(new UPSStrategy());
Console.WriteLine(service.GetShippingCost(order));
Swapping supports runtime configuration changes and feature flags. Ensure strategies do not capture mutable external state unless intended. For thread safety, prefer immutable data and stateless strategies or adjust DI lifetimes accordingly.
Pro Tip
Prefer transient registration for stateful strategies and singletons for stateless ones when using an IoC container.
Warning
Avoid sharing stateful strategy instances across threads to prevent subtle concurrency bugs.
