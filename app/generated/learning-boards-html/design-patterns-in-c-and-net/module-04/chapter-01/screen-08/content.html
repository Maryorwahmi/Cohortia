Step-by-step Refactor
Follow these concrete steps to modernize the discount system.
1
Define IDiscountStrategy with ApplyDiscount(Order, double basePrice).
2
Implement NoDiscount, Seasonal, Loyalty, and FirstTime strategies using the previous switch logic.
3
Create NewDiscountCalculator that accepts an IDiscountStrategy and delegates ApplyDiscount.
4
Refactor Order to use strategy injection or let the client supply the strategy when calculating the final price.
5
Write unit tests for each strategy to validate discount percentages and edge conditions.
Key Takeaway

Refactoring to Strategy isolates behavior and makes adding new discounts safe and testable without modifying the calculator core.

Starter code hint
Remove AppliedDiscountType and introduce IDiscountStrategy. Pass concrete strategies to NewDiscountCalculator from Main to demonstrate swapping.
Common Mistake
Do not let the NewDiscountCalculator create strategies from strings; inject them to keep the calculator decoupled.
