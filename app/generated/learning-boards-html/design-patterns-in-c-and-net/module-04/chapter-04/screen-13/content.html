Avoiding Iterator Pitfalls

Protecting Against Concurrent Modifications

Common Mistake: Exposing Internals

Directly exposing the internal collection (e.g., List<T>) defeats the pattern's purpose, leading to tight coupling and fragility.

Concurrent Modification

Modifying the underlying collection (adding/removing items) while an iterator is active can lead to an InvalidOperationException.

List<string> items = new List<string> { "A", "B", "C" };
foreach (string item in items)
{
    if (item == "B")
    {
        items.Remove(item); // Throws InvalidOperationException
    }
}
Key Takeaway

Always interact with collections via their iterator interfaces and avoid structural modifications during active enumeration to prevent runtime errors.
