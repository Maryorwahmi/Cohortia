CHAPTER SUMMARY

Advanced Iterator Terminology

Deepening Your Pattern Vocabulary

Concrete Iterator

Implements the Iterator interface and tracks the current position in the traversal of a Concrete Aggregate.

`IEnumerable`

The .NET interface representing an aggregate that can be enumerated, with a single GetEnumerator() method.

`IEnumerator`

The .NET interface representing an iterator, defining Current, MoveNext(), and Reset().

Concurrent Modification

A common issue where the underlying collection is modified while an iterator is in use, potentially causing errors.

Summary Takeaway

C# leverages IEnumerable<T> and IEnumerator<T> to implement the Iterator pattern, but developers must be cautious of concurrent modifications.
