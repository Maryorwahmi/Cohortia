IEnumerator<T>: The Iterator Interface

Controlling the Traversal State

Interface Definition

public interface IEnumerator<out T> : IDisposable, IEnumerator
{
    T Current { get; }
    bool MoveNext();
    void Reset();
}

This interface defines the methods for traversing a collection.

`Current` Property

Gets the element at the current position of the enumerator.

`MoveNext()` Method

Advances the enumerator to the next element. Returns true if successful, false if at the end.

`Reset()` Method

Sets the enumerator to its initial position, before the first element.

`Dispose()` Method

Releases any resources held by the enumerator (often a no-op for simple collections).

Key Takeaway

IEnumerator<T> is C#'s Iterator interface, providing the core methods to control and access elements during collection traversal.
