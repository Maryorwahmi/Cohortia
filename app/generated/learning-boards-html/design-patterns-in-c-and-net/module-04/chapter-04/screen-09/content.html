The Magic of foreach Loops

C#'s Implicit Iterator Power

`foreach` Loop Example

List<string> names = new List<string> { "Alice", "Bob", "Charlie" };
foreach (string name in names)
{
    Console.WriteLine(name);
}

A simple, readable way to iterate over collections.

Compiler Translation

The C# compiler translates foreach into calls to GetEnumerator(), MoveNext(), and Current on the collection's underlying enumerator.

Key Takeaway

foreach loops provide a high-level abstraction over the Iterator pattern, simplifying collection traversal in C#.
