PATTERN ADVANTAGES

Putting the Iterator to Work

Decoupling and Flexibility in Action

Client Code Example

DinerMenu dinerMenu = new DinerMenu();

// Using foreach (implicit iterator)
foreach (MenuItem item in dinerMenu)
{
    item.Print();
}

// Manual iteration (explicit iterator)
IEnumerator<MenuItem> dinerIterator = dinerMenu.GetEnumerator();
while (dinerIterator.MoveNext())
{
    MenuItem item = dinerIterator.Current;
    if (item.IsVegetarian) { item.Print(); }
}
dinerIterator.Dispose();

Both foreach and manual iteration work seamlessly.

Separation of Concerns

DinerMenu manages items, DinerMenuIterator handles traversal.

Flexible Traversal

Easily add new iterators (e.g., VegetarianMenuIterator) without changing DinerMenu.

Key Takeaway

The Iterator pattern enables clients to traverse collections generically, promoting decoupling and supporting diverse traversal strategies.
