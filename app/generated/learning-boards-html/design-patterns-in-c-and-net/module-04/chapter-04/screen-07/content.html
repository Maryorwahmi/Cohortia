IEnumerable<T>: The Aggregate Interface

Making Collections Enumerable

Interface Definition

public interface IEnumerable<out T> : IEnumerable
{
    IEnumerator<T> GetEnumerator();
}

This interface declares that an object can provide an enumerator.

The `GetEnumerator()` Method

The sole method of IEnumerable<T>. It returns an instance of IEnumerator<T>, which is the actual iterator object responsible for traversal.

Key Takeaway

IEnumerable<T> is C#'s Aggregate interface, enabling objects to be iterated over by providing an enumerator.

Role of IEnumerable<T>
Custom Collection (Aggregate)
Implements IEnumerable<T>
Returns IEnumerator<T>

This abstraction allows for flexible and decoupled iteration.
