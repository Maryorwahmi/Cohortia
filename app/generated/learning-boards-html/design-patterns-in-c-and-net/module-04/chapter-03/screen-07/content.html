Abstract LogHandler
Core fields: successor reference and configured level. Core methods: SetNext and HandleRequest.
public abstract class LogHandler
{
    protected LogHandler _successor; // next handler
    protected LogLevel _level;       // threshold

    public LogHandler(LogLevel level)
    {
        _level = level;
    }

    public LogHandler SetNext(LogHandler successor)
    {
        _successor = successor;
        return successor; // fluent wiring
    }

    public void HandleRequest(LogLevel level, string message)
    {
        if (level >= _level)
        {
            WriteMessage(message);
        }

        if (_successor != null)
        {
            _successor.HandleRequest(level, message);
        }
    }

    protected abstract void WriteMessage(string message);
}
Explanation and choices
This implementation processes if level meets threshold, then forwards regardless. That lets multiple handlers act. If you need only one handler to process, change forwarding to be conditional when not processed.
Concrete example
Sending Critical will trigger ConsoleLogger, FileLogger, and EmailLogger if each writes and still forwards.
Key Takeaway

Decide whether handlers should forward after processing or only when they skip processing; align the choice with system requirements.
