Definition
Pattern structure
Minimal parts you must implement to build a working chain.
Abstract Handler
Declares SetNext and HandleRequest. Stores configuration such as the level it handles.
Concrete Handler
Implements WriteMessage or handling logic for the request it is responsible for.
Successor
A reference to the next handler; SetNext returns the successor to allow fluent wiring.
Request details
A request carries the data the handlers need. Examples: a log level and message, or an Expense with amount and description.
Concrete example
LogHandler stores a LogLevel threshold and passes the message to successor regardless, or conditionally depending on desired behavior.
Misconception
Handlers are not responsible for knowing the whole chain. They only need to know their successor to forward requests.
Key Takeaway

Keep handler APIs small: configuration, SetNext, and HandleRequest are sufficient for most uses.
