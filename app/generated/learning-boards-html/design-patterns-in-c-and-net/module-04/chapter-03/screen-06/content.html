Building the chain with SetNext
Use SetNext to link handlers; return the successor to allow fluent chaining.
Steps to build a chain
  1. Instantiate handlers with their configuration (levels, names).
  2. Call SetNext to assign the successor and return it for chaining.
  3. Send requests to the first handler only; it will forward as needed.
Runtime reconfiguration
You can reorder or replace handlers at runtime to change processing order without modifying handler code.
Key Takeaway

Keep chain wiring in a single startup location and use SetNext for clear, maintainable configuration.

Example wiring
// Pseudocode-style C# wiring (conceptual)
var consoleLogger = new ConsoleLogger(LogLevel.Info);
var fileLogger = new FileLogger(LogLevel.Warning);
var emailLogger = new EmailLogger(LogLevel.Critical);

consoleLogger.SetNext(fileLogger).SetNext(emailLogger);

// Send messages to consoleLogger.HandleRequest(level, message);
This example shows fluent chaining. The client only calls HandleRequest on the entry handler.
