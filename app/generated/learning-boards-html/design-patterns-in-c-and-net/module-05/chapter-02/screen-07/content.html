Built-in Language Support

C#'s foreach loop implicitly leverages the Iterator pattern.

The foreach Loop's Secret

When you use foreach in C#, you're implicitly using the Iterator pattern. It works on any type that implements IEnumerable or IEnumerable<T>.

  • •IEnumerable<T>: The contract for a collection to be enumerable.
  • •IEnumerator<T>: The actual object that performs the traversal.
Core Principle

C# provides powerful abstractions that make the Iterator pattern a natural and seamless part of working with collections.

How it Works

// Implicit Iterator usage
List<string> items = new List<string> { "A", "B", "C" };
foreach (string item in items)
{
    Console.WriteLine(item);
}

// What foreach implicitly does:
IEnumerator<string> enumerator = items.GetEnumerator();
try
{
    while (enumerator.MoveNext())
    {
        string item = enumerator.Current;
        Console.WriteLine(item);
    }
}
finally
{
    if (enumerator is IDisposable disposable)
        disposable.Dispose();
}

The foreach loop abstracts away the manual interaction with IEnumerator<T>, making iteration simple.

Key Takeaway

C#'s built-in IEnumerable<T> and IEnumerator<T> interfaces are the foundation for the Iterator pattern, enabling seamless foreach loop functionality.
