Building a Custom Enumerable Collection

Implementing IEnumerable<T> for our BookCollection.

BookCollection Class

using System.Collections;
using System.Collections.Generic;

public class BookCollection : IEnumerable<Book>
{
    private List<Book> _books = new List<Book>();

    public void AddBook(Book book)
    {
        _books.Add(book);
    }

    public int Count => _books.Count;

    // Implements IEnumerable<Book>
    public IEnumerator<Book> GetEnumerator()
    {
        return new BookCollectionIterator(this); // Returns our custom iterator
    }

    // Non-generic IEnumerable implementation
    IEnumerator IEnumerable.GetEnumerator()
    {
        return GetEnumerator();
    }

    // Internal method for iterator to access books
    internal Book GetBook(int index)
    {
        if (index >= 0 && index < _books.Count)
        {
            return _books[index];
        }
        throw new ArgumentOutOfRangeException(nameof(index));
    }
}

Key Implementation Details

  • •IEnumerable<Book>: The interface that makes our collection enumerable.
  • •GetEnumerator(): The method required by IEnumerable<T>, which instantiates and returns our custom iterator.
  • •Internal Access: GetBook(int index) allows the iterator to access elements without exposing the internal List<Book> directly.
Key Takeaway

Implementing IEnumerable<T> on a custom collection requires providing a GetEnumerator() method that returns an instance of a custom iterator.
