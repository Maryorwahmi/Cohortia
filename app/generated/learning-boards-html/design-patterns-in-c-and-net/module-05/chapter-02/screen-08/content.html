The Aggregate: The Collection Itself

Defining the contract for enumerable collections.

Aggregate (IEnumerable<T>)

This is the interface for the collection of objects. It declares a method (GetEnumerator()) that returns an Iterator object.

  • •Contract: Defines that a collection can be enumerated.
  • •Method: GetEnumerator() returns an IEnumerator<T>.
Role

The Aggregate's primary responsibility is to manage its elements and provide a way to obtain an iterator for traversal.

ConcreteAggregate

This is the actual collection class (e.g., List<T>, Dictionary<TKey, TValue>, or your custom collection) that implements IEnumerable<T>.

  • •Implementation: Provides the concrete collection structure.
  • •Factory: Responsible for creating and returning a suitable ConcreteIterator.
Key Takeaway

The Aggregate defines *what* can be iterated, while the ConcreteAggregate provides the *actual* collection and its specific iterator factory.
