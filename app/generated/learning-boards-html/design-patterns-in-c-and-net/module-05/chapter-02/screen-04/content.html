Inconsistent Collection Traversal

Different collections demand different iteration approaches.

The Problem: Varied Access

Working with diverse collections like List<T>, Dictionary<TKey, TValue>, or custom data structures often requires unique code for traversal.

  • •List<T>: Simple for or foreach loop.
  • •Dictionary<TKey, TValue>: Iterating over KeyValuePair objects.
  • •Custom Tree: Requires knowledge of internal node structure.
Common Pitfall

Writing specific traversal logic for each collection type leads to duplicated code and tight coupling, making systems harder to maintain.

Code Example: Varied Traversal

// List<string> traversal
List<string> names = new List<string> { "Alice", "Bob" };
foreach (string name in names)
{
    Console.WriteLine(name);
}

// Dictionary<int, string> traversal
Dictionary<int, string> ages = new Dictionary<int, string> { {1, "Alice"}, {2, "Bob"} };
foreach (KeyValuePair<int, string> entry in ages)
{
    Console.WriteLine($"Key: {entry.Key}, Value: {entry.Value}");
}

// Custom Binary Tree traversal (hypothetical)

Each collection type requires specific knowledge of its structure to iterate, leading to inconsistent client code.

Key Takeaway

Without a pattern, iterating over different collections creates tightly coupled, non-uniform code that is difficult to manage and extend.
