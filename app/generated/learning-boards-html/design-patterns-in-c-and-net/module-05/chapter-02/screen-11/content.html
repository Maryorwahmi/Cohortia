Implementing the Custom Iterator Logic

Defining MoveNext(), Current, and Reset() for BookCollectionIterator.

BookCollectionIterator Class

using System.Collections;
using System.Collections.Generic;

public class BookCollectionIterator : IEnumerator<Book>
{
    private readonly BookCollection _collection;
    private int _currentIndex = -1; // Initial position: before first element

    public BookCollectionIterator(BookCollection collection)
    {
        _collection = collection;
    }

    public Book Current
    {
        get
        {
            if (_currentIndex < 0 || _currentIndex >= _collection.Count)
            {
                throw new InvalidOperationException("Iterator is not at a valid position.");
            }
            return _collection.GetBook(_currentIndex);
        }
    }

    object IEnumerator.Current => Current;

    public bool MoveNext()
    {
        _currentIndex++;
        return _currentIndex < _collection.Count;
    }

    public void Reset()
    {
        _currentIndex = -1;
    }

    public void Dispose()
    {
        // No unmanaged resources to dispose in this simple example
    }
}

Key Iterator Methods

  • •_currentIndex: Tracks the iterator's current position.
  • •Current: Provides the element at _currentIndex, with validation.
  • •MoveNext(): Increments _currentIndex and checks if there are more elements.
  • •Reset(): Resets the iterator to its starting position.
Key Takeaway

A custom iterator explicitly manages its position and provides methods to move through the collection and access its current element.
