Avoiding Iterator Pitfalls

Handling collection modifications and resource management.

Modifying During Iteration

Modifying the underlying collection (adding/removing elements) while iterating can lead to InvalidOperationException.

  • •Problem: Iterator state becomes invalid, leading to runtime errors.
  • •Example: Adding an item to a List<T> inside a foreach loop.
Pro Tip

For custom iterators, ensure the Current property throws an InvalidOperationException if the iterator is not positioned correctly.

Mitigation Strategies

  • •Iterate over a copy: foreach (var item in originalList.ToList()).
  • •Collect changes: Store modifications in a temporary list and apply them after iteration.
  • •Resource Management: Implement IDisposable for custom iterators managing unmanaged resources.
Key Takeaway

Always be mindful of concurrent modifications and resource management when working with iterators to prevent runtime errors and memory leaks.
