Concise Iteration with yield return

Refactoring BookCollection for simplicity.

BookCollectionYield Class

using System.Collections;
using System.Collections.Generic;

public class BookCollectionYield : IEnumerable<Book>
{
    private List<Book> _books = new List<Book>();

    public void AddBook(Book book)
    {
        _books.Add(book);
    }

    // No separate iterator class needed!
    public IEnumerator<Book> GetEnumerator()
    {
        foreach (Book book in _books)
        {
            yield return book; // Each yield return produces the next element
        }
    }

    IEnumerator IEnumerable.GetEnumerator()
    {
        return GetEnumerator();
    }
}

Benefits in Practice

  • •Conciseness: Significantly less code compared to manual implementation.
  • •Readability: The intent of iteration is clearer and easier to follow.
  • •Maintainability: Fewer lines of code mean fewer potential bugs and easier updates.
Key Takeaway

yield return provides an elegant and efficient way to implement custom iterators, drastically simplifying the code required for enumerable collections.
