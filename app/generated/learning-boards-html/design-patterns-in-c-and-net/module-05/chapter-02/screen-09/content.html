The Iterator: The Traversal Engine

Encapsulating traversal logic and current position.

Iterator (IEnumerator<T>)

This is the interface for the iterator. It declares methods for accessing and traversing elements.

  • •MoveNext(): Advances to the next element.
  • •Current: Gets the element at the current position.
  • •Reset(): Resets the iterator to its initial state.
Role

The Iterator's primary responsibility is to manage the traversal state and provide access to elements one by one.

ConcreteIterator

This is the specific implementation of the Iterator interface. It keeps track of the current position and knows how to move to the next element.

  • •State Management: Holds the current position within the collection.
  • •Traversal Logic: Implements the specific algorithm to move through the collection.
Key Takeaway

The Iterator interface defines the traversal contract, while the ConcreteIterator provides the specific implementation for a given collection.
