Definition

The lock Keyword

A C# language construct that provides a simple way to achieve mutual exclusion for a block of code, ensuring only one thread can execute it at a time. It's syntactic sugar for Monitor.Enter and Monitor.Exit.

How it Works
  • A thread attempts to acquire a lock on a specified object.
  • If the lock is available, the thread acquires it and enters the critical section.
  • If the lock is held by another thread, the current thread blocks until the lock is released.
  • The lock is automatically released when the thread exits the lock block (even if an exception occurs).

Pro-Tip

Always use a dedicated, private, readonly object for locking to prevent external code from inadvertently locking on the same object.
