Definition

The Mutex Class

A synchronization primitive used for mutual exclusion across process boundaries (inter-process synchronization), typically used to ensure only one instance of an application runs.

Key Characteristics
  • Inter-Process: Synchronizes threads across different applications.
  • Named: Can be given a name, allowing processes to refer to the same object.
  • System-Wide: A resource managed by the operating system.
  • Heavier: Incurs more overhead than lock due to OS-level nature.
Comparison: Intra- vs. Inter-Process
Intra-Process (lock/Monitor): Threads within the SAME application. Fast, lightweight.
Inter-Process (Mutex): Threads across DIFFERENT applications. Slower, system-level.
Common Use Case

Ensuring only one instance of a specific application is running on a machine at any given time.

Key Takeaway

Mutex is the go-to primitive when you need to coordinate access to resources or control application instances across multiple, independent processes on a system.
