The Command Pattern

Encapsulating Actions as Objects for Flexible Control

This pattern transforms a request into a standalone object, enabling powerful features like undo/redo, request queuing, and logging. You'll learn how to decouple senders from receivers, making your applications more robust and extensible.

In this lesson, you'll master encapsulating actions.
