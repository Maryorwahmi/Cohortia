Encapsulating Requests

Turning actions into first-class objects.

Definition

The Command Pattern

Encapsulates a request as an object, allowing you to parameterize clients with different requests, queue or log requests, and support undoable operations.

Problem

Tight Coupling

UI elements directly invoke methods on specific service objects, leading to rigid dependencies and difficult maintenance if services change.

Solution

Command Object

Transforms a request into a standalone object, containing the method to call and its parameters. This abstracts the operation, making it a manipulable entity.

Key Takeaway

The Command pattern decouples the sender of a request from its receiver by encapsulating the request itself as an object, enabling greater flexibility and extensibility.

Benefit

Enhanced Features

Enables easy implementation of complex features like undo/redo, request queuing, and logging without modifying core logic.
