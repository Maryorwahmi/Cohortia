Key Concepts

Essential terms from the Command Pattern.

Command Pattern

Encapsulates a request as an object, enabling parameterization, queuing, logging, and undoable operations.

ICommand

An interface or abstract class declaring an Execute() method (and optionally Undo()) for all concrete commands.

ConcreteCommand

An implementation of ICommand that binds a Receiver to a specific action and its parameters.

Chapter Summary

The Command pattern provides a flexible way to handle requests by treating actions as objects, enabling powerful features and promoting loose coupling in your applications.
