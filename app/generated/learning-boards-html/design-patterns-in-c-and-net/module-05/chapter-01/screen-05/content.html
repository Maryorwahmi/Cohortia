The Command Interface

Defining the `Execute()` and `Undo()` contract.

ICommand

The Contract for Actions

An interface (or abstract class) that declares an Execute() method, and often an Undo() method for reversible operations. All concrete commands implement this.

public interface ICommand{    void Execute();    void Undo(); // For undoable operations}
Key Takeaway

The `ICommand` interface standardizes how all actions are performed and potentially reversed, providing a consistent API for the Invoker.

ConcreteCommand

Specific Action Implementations

These classes implement ICommand. Each binds a Receiver object with a specific action, storing the Receiver and any necessary parameters. Its Execute() method calls the corresponding operation(s) on the Receiver.

Example: A TurnOnLightCommand would store a Light object and call its TurnOn() method when executed.

Pro-Tip

Keep Commands Lightweight

ConcreteCommand objects should primarily delegate to the Receiver. Avoid placing complex business logic directly within the command itself; that belongs in the Receiver.
