Remote Control Scenario

Setting up our `Light` and `RemoteControl` for action.

Receiver Code
public class Light{    private bool _isOn;    public void TurnOn()    {        _isOn = true;        Console.WriteLine("Light is ON");    }    public void TurnOff()    {        _isOn = false;        Console.WriteLine("Light is OFF");    }    public bool IsOn => _isOn;}
Receiver Role

The Light Class

The Light class is our Receiver. It contains the actual logic for turning the light on and off. It's the object that performs the requested action.

Invoker Concept

The Remote Control

Initially, a RemoteControl might directly call Light.TurnOn(). We will refactor this to use commands, making the remote (Invoker) independent of the specific appliance.

Key Takeaway

The `Receiver` holds the core logic, and our goal is to decouple the `Invoker` (RemoteControl) from directly knowing these specific operations.
