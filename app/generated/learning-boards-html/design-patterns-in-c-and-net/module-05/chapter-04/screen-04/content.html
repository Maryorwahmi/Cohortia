Core Concept
Concurrency vs. Parallelism
Understanding how tasks make progress in modern systems.

Concurrency

Managing multiple tasks *at the same time* but not necessarily *simultaneously*. It's about making progress on more than one task by interleaving their execution.

  • •Single-core CPU can achieve concurrency via context switching.
  • •Analogy: A single-lane road where cars take turns moving forward.
Key Takeaway

Concurrency focuses on task management and responsiveness, allowing a system to appear to do many things at once.

Parallelism

Executing multiple tasks *simultaneously*. This requires multiple processing units to truly run different parts of a program at the exact same instant.

  • •Requires multi-core CPUs or GPUs for true simultaneous execution.
  • •Analogy: A multi-lane highway where multiple cars move forward at the same time.
Pro Tip

Parallelism is a form of concurrency, but not all concurrency is parallelism. Concurrency is about structure, parallelism is about execution.
