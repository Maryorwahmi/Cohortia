Asynchronous Programming
The Async/Await Pattern
Building blocks for non-blocking operations in C#.

Task

Represents an asynchronous operation that can be awaited. It's a promise to produce a result or complete an action in the future.

async keyword

Used to mark a method as asynchronous. An `async` method can use the `await` keyword to pause its execution until an awaited `Task` completes.

await keyword

Can only be used inside an `async` method. Pauses the current method and returns control to the caller until the awaited `Task` completes.

Key Takeaway

`Task`, `async`, and `await` work together to enable non-blocking operations, crucial for responsive applications, especially with I/O-bound tasks.
