Key Concepts
Essential ideas from this chapter.

Concurrency

Managing multiple tasks over time, making progress on more than one task seemingly at once.

Parallelism

Executing multiple tasks *simultaneously* using multiple processing units.

Race Condition

Outcome depends on non-deterministic order of operations when multiple threads modify shared data.

Chapter Summary

Concurrency and parallelism are vital for modern applications, but introduce challenges like race conditions, deadlocks, livelocks, and starvation. Understanding these is key to building robust systems.
