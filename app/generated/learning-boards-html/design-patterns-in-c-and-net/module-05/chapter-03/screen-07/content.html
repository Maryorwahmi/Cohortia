Key Roles: Colleague and ConcreteColleague

Objects that communicate through the mediator.

Role Definition

3. Colleague (IColleague)

This is an interface or abstract class for objects that interact with the mediator.

  • Each Colleague holds a reference to its Mediator.
  • Communicates with other colleagues only through the Mediator.
Key Takeaway

The Colleague interface defines how objects interact with the mediator, ensuring they remain unaware of other specific colleagues.

Role Definition

4. ConcreteColleague

These are specific implementations of the Colleague interface.

  • Send messages to the mediator when their state changes or an event occurs.
  • Receive messages from the mediator when other colleagues trigger actions.
  • Do not know about other ConcreteColleagues directly.
Example

In a chat application, a ChatUser class would be a ConcreteColleague, sending and receiving messages via the ChatRoom mediator.
