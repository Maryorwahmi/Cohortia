Chat Application: Client Usage & Benefits

Demonstrating interaction and highlighting decoupling.

Client Code (Program.Main)
public class Client
{
    public static void Main(string[] args)
    {
        ChatRoom chatRoom = new ChatRoom();

        ChatUser john = new ChatUser(chatRoom, "John");
        ChatUser jane = new ChatUser(chatRoom, "Jane");
        ChatUser mike = new ChatUser(chatRoom, "Mike");

        chatRoom.AddUser(john);
        chatRoom.AddUser(jane);
        chatRoom.AddUser(mike);

        Console.WriteLine("
--- Chat Session ---");
        john.Send("Hi everyone!");
        jane.Send("Hello John!");
        mike.Send("What's up?");

        // Notice that users don't directly know about each other.
        // All communication goes through the chatRoom (Mediator).
    }
}

This client code demonstrates how users interact by sending messages through the ChatRoom mediator.

Key Observation

Users are unaware of each other; all communication is orchestrated by the ChatRoom, showcasing loose coupling.

Simulated Output
John has joined the chat room.
Jane has joined the chat room.
Mike has joined the chat room.

--- Chat Session ---
John sends: Hi everyone!
Jane receives: [John]: Hi everyone!
Mike receives: [John]: Hi everyone!
Jane sends: Hello John!
John receives: [Jane]: Hello John!
Mike receives: [Jane]: Hello John!
Mike sends: What's up?
John receives: [Mike]: What's up?
Jane receives: [Mike]: What's up?

The output clearly shows messages being sent by one user and received by others, all facilitated by the mediator.

Benefit Highlight

Centralized communication logic simplifies modifications; adding new features like private messaging only requires changes to the mediator.
