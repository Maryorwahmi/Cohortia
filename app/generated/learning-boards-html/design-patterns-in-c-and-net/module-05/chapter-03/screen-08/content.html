Mediator in Action: Chat Application

Simplifying communication in a multi-user environment.

Problem Without Mediator

Direct User-to-User Communication

Each user would need to know about and directly send messages to every other user in the chat room.

  • Impractical for many users.
  • High coupling: each user knows about all others.
  • Difficult to add new features (e.g., private messages).
Consequence

A tightly coupled system that is fragile and hard to extend, leading to 'spaghetti code'.

Solution With Mediator

Centralized ChatRoom Communication

Each user sends their message to the ChatRoom (the mediator), which then distributes it to all other participants.

  • Users only know about the mediator, not other users.
  • Communication logic is centralized in the ChatRoom.
  • Easier to manage and extend features.
Benefit

Achieves loose coupling, making the system more flexible, reusable, and maintainable.
