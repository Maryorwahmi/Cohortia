Chat Application: Concrete Mediator & Colleague

Implementing the chat room and specific user behavior.

ChatRoom (ConcreteMediator)
public class ChatRoom : IChatMediator
{
    private List<User> _users = new List<User>();

    public void AddUser(User user)
    {
        _users.Add(user);
        Console.WriteLine($"{user.Name} has joined the chat room.");
    }

    public void SendMessage(string message, User sender)
    {
        foreach (User user in _users)
        {
            if (user != sender)
            {
                user.Receive($"[{sender.Name}]: {message}");
            }
        }
    }
}

This class manages the list of users and orchestrates message distribution, ensuring messages are broadcast to all but the sender.

Centralized Logic

All message routing and distribution logic is contained within the ChatRoom, simplifying management.

ChatUser (ConcreteColleague)
public class ChatUser : User
{
    public ChatUser(IChatMediator mediator, string name) : base(mediator, name) { }

    public override void Receive(string message)
    {
        Console.WriteLine($"{Name} receives: {message}");
    }
}

This class represents a specific chat participant, implementing how a user receives and displays messages.

Decoupled Behavior

ChatUser only knows about its mediator and its own behavior, not other ChatUser instances.
