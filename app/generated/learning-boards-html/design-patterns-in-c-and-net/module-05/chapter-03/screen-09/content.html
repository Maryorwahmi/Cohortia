Chat Application: Mediator Interface & Colleague Base

Setting up the communication contract and abstract user.

IChatMediator Interface
public interface IChatMediator
{
    void SendMessage(string message, User sender);
    void AddUser(User user);
}

This interface defines the methods that User objects will use to communicate with the chat room. It's the contract for our mediator.

Purpose

Establishes a clear, consistent way for colleagues to interact with any concrete mediator implementation.

User Abstract Class (Colleague Base)
public abstract class User
{
    protected IChatMediator _mediator;
    public string Name { get; }

    public User(IChatMediator mediator, string name)
    {
        _mediator = mediator;
        Name = name;
    }

    public void Send(string message)
    {
        Console.WriteLine($"{Name} sends: {message}");
        _mediator.SendMessage(message, this);
    }

    public abstract void Receive(string message);
}

This abstract class provides the common structure for all chat users, including a reference to the mediator and methods for sending/receiving messages.

Key Insight

Users communicate only through the _mediator, ensuring they remain decoupled from other specific user implementations.
