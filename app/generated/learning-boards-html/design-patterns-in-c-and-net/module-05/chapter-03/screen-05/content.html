Introducing the Mediator Pattern

Centralizing communication to untangle dependencies.

The Solution

Encapsulated Interactions

The Mediator pattern introduces a central object, the Mediator, that encapsulates how a set of objects (Colleagues) interact.

  • Colleagues communicate only with the Mediator.
  • The Mediator forwards requests to appropriate recipients.
  • Transforms many-to-many into one-to-many/one-to-one.
Key Takeaway

The Mediator pattern centralizes communication logic, drastically reducing direct dependencies and promoting loose coupling between objects.

Analogy

Air Traffic Control

Imagine an airport where planes (colleagues) need to coordinate their movements. Without a control tower (mediator), each plane would have to directly communicate with every other plane, leading to chaos.

Pro-Tip

Use the Mediator pattern when a set of objects interact in complex, interdependent ways, and you want to avoid direct coupling between them.
