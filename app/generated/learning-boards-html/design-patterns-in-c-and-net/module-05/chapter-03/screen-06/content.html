Key Roles: Mediator and ConcreteMediator

Defining the central communication hub.

Role Definition

1. Mediator (IMediator)

This is an interface or abstract class that defines the contract for communication between Colleague objects.

  • Declares methods (e.g., Notify(Colleague sender, string event)) for colleagues to inform the mediator of events.
  • Establishes the communication protocol.
Key Takeaway

The Mediator interface defines the communication contract, ensuring all colleagues interact with the mediator consistently.

Role Definition

2. ConcreteMediator

This is the concrete implementation of the IMediator interface.

  • Responsible for knowing and maintaining relationships between Colleague objects.
  • Receives notifications from colleagues and orchestrates communication.
  • Decides which colleagues should be affected and how.
Example

In a chat application, the ChatRoom class would be the ConcreteMediator, managing all users and message distribution.
