Module 3 › Chapter 2.2 › Factory Method Definition
Roles and responsibilities
  • Product: contract the client uses.
  • Concrete Product: specific implementation.
  • Creator: declares factory method and uses returned Product.
  • Concrete Creator: overrides factory method to instantiate a Concrete Product.
If Concrete Products diverge too much, the Creator cannot operate polymorphically, signaling a design smell.
Metaphor
Think of a main shop that processes orders and calls a create function. Different machines (subclasses) implement that create function to produce brochures, cards, or banners without changing the shop logic.
Example check
Does your Creator need to know the concrete type? If no, Factory Method may be appropriate.
Common mistake
Confusing Factory Method with Simple Factory; the latter centralizes creation in a static method and must be modified for each new product.
When to avoid
If there is only a single product and no foreseeable need to extend, using the pattern adds unnecessary classes.
Key Takeaway

Factory Method preserves client stability by delegating concrete creation to subclasses that implement a shared Product contract.
