Module 3 › Chapter 2.2 › Logger Refactor Steps
Step-by-step
  1. Define ILogger with Log(string message).
  2. Implement ConsoleLogger : ILogger.
  3. Create abstract LoggerCreator with abstract CreateLogger() returning ILogger and PerformLogging helper.
  4. Implement ConsoleLoggerCreator overriding CreateLogger to return ConsoleLogger.
  5. Refactor Application to accept LoggerCreator and call PerformLogging.
  6. Instantiate Application with ConsoleLoggerCreator in Program.Main.
Starter result
[Console Log] Application started.
[Console Log] Application finished.
Checklist & pitfalls
  • Ensure ILogger matches what Application needs.
  • Don't forget to change Application's constructor to accept a Creator.
  • Avoid unnecessary indirection if you never expect variants.
Try this
After refactor, add a FileLogger and FileLoggerCreator to verify no changes were needed in Application.
Common mistake
Leaving creation sites unchanged — if Application still new's ConsoleLogger, the refactor is incomplete.
Key Takeaway

Follow the extraction sequence and update construction sites to complete the Factory Method refactor successfully.
