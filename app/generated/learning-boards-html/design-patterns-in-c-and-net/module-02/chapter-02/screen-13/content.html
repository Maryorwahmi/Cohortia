Module 3 › Chapter 2.2 › Key Concepts
Factory Method
An interface in a Creator to create objects, allowing subclasses to decide the concrete type.
Product
Interface or abstract class defining the common contract implemented by Concrete Products.
Creator / Concrete Creator
Creator declares the factory method and uses returned products; Concrete Creators override it to instantiate specific products.
Summary
Delegate creation to preserve client stability. Add new products by creating new Concrete Creators rather than editing existing code.
