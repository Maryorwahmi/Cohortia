Module 3 › Chapter 2.2 › Logger Refactor Starter
Starter Code
// Current simple logger
public class ConsoleLogger
{
    public void Log(string message)
    {
        Console.WriteLine($"[Console Log] {message}");
    }
}

// Application that uses the logger
public class Application
{
    private ConsoleLogger _logger;

    public Application()
    {
        _logger = new ConsoleLogger(); // Direct instantiation
    }

    public void Run()
    {
        _logger.Log("Application started.");
        _logger.Log("Application finished.");
    }
}
Expected Changes
  1. Define ILogger and implement it in ConsoleLogger.
  2. Create LoggerCreator with CreateLogger and PerformLogging.
  3. Implement ConsoleLoggerCreator.
  4. Pass ConsoleLoggerCreator into Application.
Expected Output
[Console Log] Application started.
[Console Log] Application finished.
Test step
Run Program.Main after refactor. Confirm the console output matches the expected lines above.

Key Takeaway

A successful refactor keeps output identical while moving creation responsibility into creators that can be extended later.
