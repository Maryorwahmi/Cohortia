Creator: NotificationCreator
// Creator Abstract Class
public abstract class NotificationCreator
{
  // The factory method
  public abstract INotification CreateNotification();

  // Other business logic that uses the notification
  public string NotifyUser(string recipient, string message)
  {
    INotification notification = CreateNotification(); // Calls the factory method
    return notification.Send(recipient, message);
  }
}
The CreateNotification method is the extension point subclasses override to change product types.
Design notes
  • Keep CreateNotification focused on returning a Product.
  • Creator can include reusable steps that call the product's methods.
  • Factory method is usually an instance method overridden by subclasses.
Concrete Creator example
EmailNotificationCreator would override CreateNotification to return an EmailNotification.
Misconception
Avoid making the factory method static; subclassing polymorphism is the mechanism that enables extension without modification.
Key Takeaway

Creator defines the algorithm and uses the Product; Concrete Creators supply the specific product types by overriding the factory method.
