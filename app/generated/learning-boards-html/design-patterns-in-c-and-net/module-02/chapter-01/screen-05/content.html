Process

Three-step recipe

1. Private constructor
Prevents external code from calling new and enforces controlled instantiation.
2. Static instance field
Holds the single instance at the type level so it's shared across the application.
3. Public static accessor
Provides a global point of access and controls lazy or eager creation of the instance.
Concrete Example
public sealed class ConfigurationManager
{
  private static ConfigurationManager _instance;
  private ConfigurationManager() { /* load settings */ }
  public static ConfigurationManager Instance
  {
    get
    {
      if (_instance == null)
      {
        _instance = new ConfigurationManager();
      }
      return _instance;
    }
  }
}
Key Takeaway

These three structural elements enforce uniqueness and provide controlled global access when used together.
