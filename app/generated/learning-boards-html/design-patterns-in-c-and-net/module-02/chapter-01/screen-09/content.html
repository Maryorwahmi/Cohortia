Starter code (excerpt)
public sealed class Logger
{
  private static readonly Lazy<Logger> _lazyInstance = new Lazy<Logger>(() => new Logger());

  private Logger()
  {
    Console.WriteLine("Logger instance initialized.");
  }

  public static Logger Instance => _lazyInstance.Value;

  public void LogMessage(string message)
  {
    string logEntry = $"{DateTime.Now:yyyy-MM-dd HH:mm:ss} [{Thread.CurrentThread.ManagedThreadId}] {message}";
    Console.WriteLine(logEntry);
  }
}
Activity steps
  1. Implement the Logger using the provided Lazy<T> field and private constructor.
  2. Start multiple threads that call Logger.Instance.LogMessage concurrently.
  3. Confirm the initialization message appears exactly once and all messages are logged.
Real-world note
In production, loggers may also perform file I/O, rotation, and buffering. Keep those concerns separate from Singleton instantiation when possible.
Check

If you see the initialization line more than once, your Singleton is not thread-safe or multiple application domains are creating instances.
