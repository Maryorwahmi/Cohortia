Module 2 › Chapter 2.1 › What the Singleton Is
Definition

Singleton: single instance and global access

A class enforces a single instance, preventing multiple constructions and offering a single point of access across the app.

Everyday examples
Configuration manager, logging service, connection pool controller.
Common misconception
Singleton is not just a global variable; it controls instantiation and lifecycle.
Why it matters
Prevents duplicate resource initialization and ensures consistent shared state when used correctly.
Visual summary
Responsibilities
  • Private constructor to block external new.
  • Static field to hold the instance.
  • Public static accessor to return the instance.
Concrete scenario
A ConfigurationManager loads settings once at initialization and serves read access to many modules, avoiding repeated file reads.
Key Takeaway

Singleton centralizes ownership of a single instance; use it when application-wide uniqueness is required and manage concurrency carefully.
