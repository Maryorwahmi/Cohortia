Module 2 › Chapter 2.3 › What Abstract Factory Solves
Definition
An interface for creating families of related or dependent objects without specifying concrete classes.
• Define an abstract product interface for each product type you need.
• Create an abstract factory that declares creation methods for all abstract products.
• Implement concrete factories that return concrete products of a single family.
Key Takeaway

Abstract Factory enforces product compatibility by providing a single entry point for creating related products.

Concrete example
Cross-platform UI: IButton and ICheckbox are abstract products. WindowsGUIFactory returns WindowsButton and WindowsCheckbox so both controls match visually and semantically.
Common misconception
People sometimes use Abstract Factory when only one product needs variation. In that case Factory Method is simpler.
Why it matters
Consistency across product sets reduces integration bugs.
