Module 2 › Chapter 2.3 › Abstract Factory vs Factory Method
Factory Method
Creates one product. Uses subclassing so subclasses decide which concrete product to create. Simpler for single product variation.
When to use
One product varies by subclass behavior.
Abstract Factory
Creates many related products. Uses a factory object that exposes creation methods for each product. Best when you need compatible product families.
When to use
Multiple product types must be consistent within families.
