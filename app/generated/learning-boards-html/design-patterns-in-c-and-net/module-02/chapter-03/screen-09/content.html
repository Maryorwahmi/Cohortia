Module 2 › Chapter 2.3 › Benefits vs Trade-offs
Benefits
  • Ensures consistency among related products.
  • Makes switching product families straightforward.
  • Supports platform-independent client code and easier testing.
Design win
Ideal when families need to be kept coherent.
Trade-offs
  • Adding new product types requires changes across the factory hierarchy.
  • Introduces many small interfaces and classes to maintain.
  • Can be overkill for simple single-product variability.
Pitfall
Use the pattern only when family compatibility justifies the added complexity.
