Factory interfaces and classes
The abstract factory groups creation methods so clients can request a suite of products from a single object.
// Abstract Factory: Declares an interface for operations that create abstract product objects.
public interface IGUIFactory
{
    IButton CreateButton();
    ICheckbox CreateCheckbox();
}

// Concrete Factories: Implement the factory methods to create concrete product objects.
public class WindowsGUIFactory : IGUIFactory
{
    public IButton CreateButton() => new WindowsButton();
    public ICheckbox CreateCheckbox() => new WindowsCheckbox();
}

public class MacGUIFactory : IGUIFactory
{
    public IButton CreateButton() => new MacButton();
    public ICheckbox CreateCheckbox() => new MacCheckbox();
}
Notes
  • Concrete factories create all products in one family, ensuring compatibility.
  • Factories are usually injected so configuration drives which family is active.
  • Adding a new factory for another platform requires implementing the factory and concrete products only.
Pro tip
Keep factory methods coarse-grained to reduce interface churn when adding types.
