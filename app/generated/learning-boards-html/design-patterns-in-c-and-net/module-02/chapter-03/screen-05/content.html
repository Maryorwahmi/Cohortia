Role hierarchy
Think of roles as two hierarchies: one for products and one for factories. The abstract factory groups product creation methods that return abstract products from the product hierarchy.
• Abstract Product: contract that all concrete products for a given type must satisfy.
• Concrete Product: a platform-specific implementation of that contract.
• Abstract Factory: declares factory methods for each abstract product.
• Concrete Factory: implements the methods to produce a consistent family.
• Client: composes with the abstract factory and abstract products only.
