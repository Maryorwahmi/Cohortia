Module 4 › Chapter 3.4 › BlocListener: side effects
Example listener
BlocListener(
  listener: (context, state) {
    if (state == 10) {
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('Count reached 10!')),
      );
    }
  },
  child: Container(),
)
Best practices
  • Keep listeners focused on effects, not rendering.
  • Use listenWhen to avoid unnecessary invocations.
  • Combine with BlocBuilder via BlocConsumer when both are needed.
Try: show a SnackBar only when a specific flag flips to true to avoid repeated messages.
