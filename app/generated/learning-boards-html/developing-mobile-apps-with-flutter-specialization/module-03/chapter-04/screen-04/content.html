Module 4 › Chapter 3.4 › What is the BLoC pattern?
Definition
BLoC separates inputs from outputs so logic is decoupled from UI rendering.
Input → Logic → State: a pipeline metaphor for predictable flows.
Benefit: test logic without widgets.
Misconception: BLoC is not always heavy; Cubit is a light, stream-backed alternative.
Concrete example
Authentication flow: button press becomes an event; logic calls API; states represent loading, success, or failure and drive navigation.
Key takeaway
Try this: pick a feature that combines user input and async network calls — that is a strong candidate for Bloc.
