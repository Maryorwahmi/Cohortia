Counter Cubit (code)
// lib/cubits/counter_cubit.dart
import 'package:flutter_bloc/flutter_bloc.dart';

class CounterCubit extends Cubit {
  CounterCubit() : super(0); // Initial state is 0

  void increment() => emit(state + 1); // Emit a new state
  void decrement() => emit(state - 1); // Emit a new state
}
This Cubit shows how simple operations map directly to new states. Tests can call increment and assert the state change.
Notes & example
  • Emit new values directly; Cubit manages the state stream for you.
  • For list state, maintain immutability: use emit([...state, item]).
  • Use context.read().increment() from a button to trigger it.
Key Takeaway

Cubit is concise and effective for direct state changes; guard against mutating complex state.
