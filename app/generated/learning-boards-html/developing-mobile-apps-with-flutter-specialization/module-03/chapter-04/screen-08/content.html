Module 4 › Chapter 3.4 › BlocBuilder: rebuilding
Usage example
BlocBuilder(
  builder: (context, count) {
    return Text('$count', style: Theme.of(context).textTheme.headlineMedium);
  },
)
Use buildWhen to restrict rebuilds when needed.
Tips & mistakes
  • Keep BlocBuilder focused on UI rendering only.
  • Do not perform navigation or SnackBars inside builder.
  • Scope BlocBuilder narrowly to avoid rebuilding large subtrees.
Ask: which widget needs the freshest state? Put BlocBuilder there, not at the app root.
