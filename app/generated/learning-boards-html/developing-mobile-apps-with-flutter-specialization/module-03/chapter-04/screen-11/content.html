Module 4 › Chapter 3.4 › Triggering state changes
Dispatch examples
// To trigger Cubit method
context.read().increment();

// To add an event to Bloc
context.read().add(CounterIncrement());
Use read for one-off dispatches. Avoid reading state directly for UI — use BlocBuilder or BlocConsumer instead.
Common mistakes
  • Using context.read inside build for side effects.
  • Not calling emit or add — leaving the UI static.
  • Relying on instance.state for rendering instead of subscribing.
Try: wire a button that calls context.read().addTask() and verify the UI updates via BlocBuilder.
