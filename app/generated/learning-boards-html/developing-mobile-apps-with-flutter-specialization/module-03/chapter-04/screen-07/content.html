Example: provide a Cubit
void main() {
  runApp(
    BlocProvider(
      create: (context) => CounterCubit(),
      child: const MyApp(),
    ),
  );
}
This places the CounterCubit above the app; descendants can call context.read().
Guidance
  • Scope providers near the feature needing them.
  • Use MultiBlocProvider for multiple, related providers.
  • Provider disposes the Bloc/Cubit when removed — mind lifecycle.
Try: wrap only the screen that needs the state first, then lift the provider if sharing is required.
