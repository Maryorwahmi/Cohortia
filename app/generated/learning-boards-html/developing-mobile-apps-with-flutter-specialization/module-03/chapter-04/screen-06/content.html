Counter Bloc (code)
// lib/blocs/counter_bloc.dart
import 'package:flutter_bloc/flutter_bloc.dart';

abstract class CounterEvent {}
class CounterIncrement extends CounterEvent {}
class CounterDecrement extends CounterEvent {}

class CounterBloc extends Bloc {
  CounterBloc() : super(0) {
    on((event, emit) => emit(state + 1));
    on((event, emit) => emit(state - 1));
  }
}
Why use events?
  • Events let you name intent and centralize handling for many triggers.
  • Perfect for debounce, throttling, retries, and combining streams before emitting.
  • Test sequences by adding events and asserting emitted states.
Key Takeaway

Bloc adds structure for complex flows; design events to capture user intent and asynchronous triggers.
