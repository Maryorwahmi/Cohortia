Module 4 › Chapter 3.4 › BlocConsumer: build + listen
Example
BlocConsumer(
  listener: (context, state) {
    if (state % 5 == 0) print('Count is multiple of 5: $state');
  },
  builder: (context, count) {
    return Text('Current count: $count');
  },
)
When to use
  • Use when a state change requires both UI and an effect.
  • Keep the scope narrow to avoid coupling too many concerns.
Try: combine a small UI update with a short-lived SnackBar using BlocConsumer.
