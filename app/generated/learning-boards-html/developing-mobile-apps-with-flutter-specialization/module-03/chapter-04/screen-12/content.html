Module 4 › Chapter 3.4 › Common mistakes & immutability
Top mistakes
  • Mutating list or map state instead of emitting new instances.
  • Reading state for rendering instead of subscribing with BlocBuilder.
  • Placing providers at the wrong scope causing lifetime issues.
  • Performing side effects inside builders rather than listeners.
How to fix
Adopt immutable patterns, write unit tests for Cubit/Bloc logic, scope providers intentionality, and separate effects from rendering.
Pro Tip

Write small logic tests that emit and assert state transitions to catch mutation bugs early.
