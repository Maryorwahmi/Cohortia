Hands-on Activity › Shopping List with provider

Starter model

// class ShoppingListModel extends ChangeNotifier
final List _items = [];
List get items => _items;

void addItem(String item) {
  _items.add(item);
  notifyListeners();
}

void removeItem(String item) {
  _items.remove(item);
  notifyListeners();
}
Provide this with ChangeNotifierProvider at app root and use Consumer to render the list.

UI pattern

  • TextField to type an item and a button that calls Provider.of(..., listen:false).addItem(text).
  • Consumer with ListView.builder to show items.
  • Trailing delete icon calls removeItem via Provider.of(listen:false).

Add and remove items and ensure the list updates without rebuilding unrelated widgets.
