Selector pattern

// Example usage
Selector(
  selector: (context, counter) => counter.count,
  builder: (context, count, child) {
    return Text('$count');
  },
)
Selector watches only the returned int; unrelated fields do not trigger this builder.

When to use

  • When your model contains multiple properties and widgets need only one.
  • When unrelated changes would otherwise trigger unnecessary rebuilds.
Performance note
Selector adds a selector function; use it when the cost of extra rebuilds outweighs this check.
