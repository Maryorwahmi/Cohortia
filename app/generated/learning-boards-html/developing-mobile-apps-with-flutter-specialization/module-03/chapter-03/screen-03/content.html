Consume and optimize

Four focused skills for consuming provided models and avoiding wasted rebuilds.

05
Use ChangeNotifierProvider

Provide models near the app root so many widgets can access the same instance. This prevents ancestor lookup errors and simplifies wiring.

Mnemonic: Provide up high
VERIFIED COMPETENCY MILESTONE
06
Consumer

Use Consumer to rebuild only the widget subtree within its builder when notifyListeners() fires. This helps keep rebuilds narrow and efficient.

Mnemonic: Consume locally
VERIFIED COMPETENCY MILESTONE
07
Provider.of(..., listen:false)

Call methods on a model without subscribing the calling widget to changes. Ideal for button handlers or one-off actions.

Mnemonic: Call-only access
VERIFIED COMPETENCY MILESTONE
08
Selector

Listen to a specific part of a model so widgets rebuild only when that slice changes. Use it to avoid unnecessary updates.

Mnemonic: Select a slice
VERIFIED COMPETENCY MILESTONE
