CounterModel

A simple ChangeNotifier with a private counter and two mutators.
// lib/models/counter_model.dart
import 'package:flutter/foundation.dart';

class CounterModel extends ChangeNotifier {
  int _count = 0;

  int get count => _count;

  void increment() {
    _count++;
    notifyListeners(); // Inform listeners the state changed
  }

  void decrement() {
    _count--;
    notifyListeners(); // Inform listeners the state changed
  }
}
Misconception
Extending ChangeNotifier does not add heavy overhead; it simply provides a notifyListeners hook used by provider.

Explaining the code

  • Keep fields private and expose only necessary getters.
  • Call notifyListeners() after any state mutation so listening widgets update.
  • Avoid placing UI logic in the model; models should be pure state and methods.
Key Takeaway

Make state changes explicit and call notifyListeners — forgetting it is the most common bug.
