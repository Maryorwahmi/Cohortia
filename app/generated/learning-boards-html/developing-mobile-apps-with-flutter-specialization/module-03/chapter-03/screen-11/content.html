Common Mistakes › Debugging tips
Forgot notifyListeners()
If UI doesn't change, confirm that your mutator calls notifyListeners after state updates.
Quick check: add a debug print inside the method to see if it runs.
Provider placement
Ensure the provider is an ancestor of widgets that call Provider.of or Consumer.
Fix: move ChangeNotifierProvider higher or provide at route-level for narrower scope.
Over-listening
Avoid wrapping big widgets with Consumer or using listen:true when you only need action access.
Pro tip: use Provider.of(..., listen:false) for button callbacks and Selector for small slices.
