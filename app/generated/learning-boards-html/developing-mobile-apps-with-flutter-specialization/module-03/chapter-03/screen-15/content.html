What to Remember › Key Concepts
State
Any data that can change and affects UI. Choose local or global based on sharing needs.
provider + ChangeNotifier
Use ChangeNotifier to expose state and provider to expose the model to descendants; call notifyListeners after changes.
Efficient consumption
Use Consumer, Provider.of(listen:false), and Selector appropriately to limit unnecessary rebuilds.
Summary

These patterns help you scale from simple widgets to full apps while keeping code testable and efficient.
