Process Flow › Consumer and Provider.of

Consumer example

Consumer(
  builder: (context, counter, child) {
    return Text('${counter.count}', style: Theme.of(context).textTheme.headlineMedium);
  },
)
Place Consumer around the specific widget subtree that needs to rebuild with model changes.

Provider.of for actions

// in onPressed
Provider.of(context, listen: false).increment();
Misconception
Using Provider.of with listen:true in a button handler will cause the button widget to rebuild unnecessarily.
Key Takeaway

Use Consumer for value display and Provider.of(listen:false) for event handlers to avoid rebuilding the handler widget.
