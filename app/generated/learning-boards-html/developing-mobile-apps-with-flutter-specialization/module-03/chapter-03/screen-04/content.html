Core Concept › What is State in Flutter?

Definition

State is any mutable data that affects UI appearance or behavior during a widget's lifetime.

Local (ephemeral): use setState() for widget-scoped values like text input or toggle flags.
Global (shared): use provider for app-wide values like authentication or a cart.
Key Takeaway

Ask whether other widgets need the data before promoting state from local to global.

Concrete examples

Counter in one screen
Local state inside a StatefulWidget. Use setState to rebuild when the number changes.
Shopping cart
Global state shared across product pages and checkout. Use provider or MultiProvider to expose it.
Common misconception
Not all changing data must be global. Making everything global increases complexity and unnecessary rebuilds.
Analogy
Think of local state as a notebook in a desk drawer; global state is a whiteboard everyone can read.
