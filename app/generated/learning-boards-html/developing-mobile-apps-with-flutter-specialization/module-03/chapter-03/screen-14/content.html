Mini Demo › Counter app flow

Flow summary

  1. Create CounterModel with notifyListeners in mutators.
  2. Provide with ChangeNotifierProvider above MyApp or at route scope.
  3. Use Consumer to display count and Provider.of(listen:false) for button actions.
Common mistake
Placing provider inside a screen when multiple screens need the same instance causes inconsistent state after navigation.

Try this variant

Replace Consumer with Selector to observe only the selected primitive. This helps when the model expands and you want very narrow rebuild triggers.
// Consumer shows CounterModel
Consumer(builder: (ctx, counter, child) => Text('${counter.count}'))

// Selector selects the count only
Selector(selector: (ctx, c) => c.count, builder: (ctx, count, child) => Text('$count'))
