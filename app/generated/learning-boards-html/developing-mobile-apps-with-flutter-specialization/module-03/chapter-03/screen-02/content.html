Learning Objectives

Bloom bar: Learn → Understand → Apply → Master
01
Explain state

Define what mutable UI state is and why it determines the app's appearance. This skill helps you decide if data belongs in a widget or at app level.

Mnemonic: State = Snapshot
VERIFIED COMPETENCY MILESTONE
02
Local vs Global

Differentiate ephemeral widget state from app-wide state used by many widgets. This helps avoid unnecessary prop drilling and complexity.

Mnemonic: Local = Inside, Global = Across
VERIFIED COMPETENCY MILESTONE
03
Introduce provider

Learn why provider is a recommended, simple wrapper over InheritedWidget for sharing app state. It simplifies providing and consuming models.

Mnemonic: Provider = Pass-down
VERIFIED COMPETENCY MILESTONE
04
Implement ChangeNotifier

Create observable data models that call notifyListeners() after updates so consumers rebuild predictably. This is the basic reactive pattern.

Mnemonic: Notify → Rebuild
