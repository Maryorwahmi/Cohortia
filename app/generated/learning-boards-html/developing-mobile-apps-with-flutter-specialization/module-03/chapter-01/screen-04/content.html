Core Concept What is Responsive UI?
Definition & rationale
Responsive UI combines global breakpoints, local constraints, and proportional sizing to make apps usable on many devices. It reduces overflow, wasted space, and visual inconsistencies.
Concrete scenario
A product list shows one column on phones and two columns on tablets using a global width check. A card inside that list adapts to its grid cell using local constraints.
Common mistake
Using full-screen MediaQuery values inside a nested widget causes brittle layouts that don't respect parent sizes.
Key Takeaway

Design components to adapt to their own constraints, and use global checks only for top-level breakpoints.

Quick checklist for responsive design
  • Identify which elements need global breakpoints (lists, major layout changes).
  • Identify which elements must adapt to parent space (cards, buttons, mini-widgets).
  • Decide where to use Flexible or Expanded to distribute leftover space in rows or columns.
  • Test on multiple widths and orientations to catch edge cases.
