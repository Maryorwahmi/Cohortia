Hands-on Activity Adaptive Product Card
Task
Replace the placeholder Column with a LayoutBuilder that checks constraints.maxWidth and returns Column for < 600 or Row with Expanded text for ≥ 600.
Starter hints
  • Keep image sizing reasonable in both modes.
  • Wrap the text area with Expanded when using Row.
  • Test with different SizedBox widths during development.
// Inside ProductCard.build
return LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth < 600) {
      return Column(children: [ImagePlaceholder(), TextBlock()]);
    } else {
      return Row(children: [ImagePlaceholder(), Expanded(child: TextBlock())]);
    }
  },
);
Testing tip
Wrap ProductCard in SizedBox(width: 500) and SizedBox(width: 700) to confirm both layouts.
Check
Does the card respond to parent width changes? If yes, you used LayoutBuilder correctly.
