How to decide inside LayoutBuilder
Check constraints.maxWidth and choose structure: stack vertically on narrow widths, arrange horizontally on wider widths.
LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth < 600) {
      return Column(children: [Image(), TextBlock()]);
    } else {
      return Row(children: [Image(), Expanded(child: TextBlock())]);
    }
  },
)
  • Use LayoutBuilder for components that may be nested or resized by parents.
  • Extract non-adaptive children out of the builder to reduce rebuild cost.
  • Prefer constraints checks for layout-switching, not global width values inside nested widgets.
Example
A ProductCard uses LayoutBuilder to choose Column when its parent cell is narrow, and Row with Expanded text when wide.
Pro tip
Test by wrapping the component in different SizedBox widths to simulate parent constraint changes during development.
Key Takeaway

Use LayoutBuilder to make components that responsibly adapt to the space they receive, keeping layout logic local.
