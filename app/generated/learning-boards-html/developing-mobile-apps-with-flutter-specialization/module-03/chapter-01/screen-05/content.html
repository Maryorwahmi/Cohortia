Definition MediaQuery
MediaQuery usage
Access global screen metrics for top-level layout decisions and accessibility adjustments.
// Example: check width and switch layout
final width = MediaQuery.of(context).size.width;
if (width < 600) {
  // show single-column ListView
} else {
  // show GridView with 2 columns
}
Practical uses
  • Global breakpoints for lists vs grids.
  • Choosing larger image assets on tablets.
  • Respecting textScaleFactor for accessibility.
Concrete example
Use MediaQuery.of(context).size.width to choose between a ListView and GridView for article layouts at a 768 pixel threshold.
Misconception
Don't use MediaQuery inside a small card that needs to adapt to its parent. That causes mismatch between component size and decision logic.
Key Takeaway

MediaQuery is ideal for page-level breakpoints and accessibility settings; use it thoughtfully.
