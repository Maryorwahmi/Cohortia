Code Walkthrough Expanded & Flexible in a Row
Example code
Row(
  children: [
    Expanded(
      child: TextField(
        decoration: InputDecoration(hintText: 'Type your message...'),
      ),
    ),
    SizedBox(width: 8),
    Flexible(
      child: ElevatedButton(onPressed: () {}, child: Text('Send')),
    ),
  ],
)
  • Expanded forces the TextField to claim remaining width.
  • Flexible allows the button to remain its natural size unless more space is available.
  • Use SizedBox for predictable gaps instead of padding inside children.
Scenario
Chat input in portrait should keep the button compact and let the text field scale; on tablets the same code adapts naturally.
Check your understanding
What happens if you wrap both the text field and button with Expanded and give them flex 1? They will split remaining space evenly.
Key Takeaway

Choose Expanded for forced fill and Flexible for components that should keep intrinsic size when practical.
