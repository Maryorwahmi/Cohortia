Core Concept OrientationBuilder
When to use orientation-aware layouts
Swap major widget arrangements to better leverage the screen's shape. Landscape often benefits from grids or side-by-side content.
OrientationBuilder(
  builder: (context, orientation) {
    if (orientation == Orientation.portrait) {
      return ListView(...);
    } else {
      return GridView.count(crossAxisCount: 4, ...);
    }
  },
)
  • Use for screen-level rearrangements, not micro-adjustments.
  • Combine with MediaQuery to tune breakpoints and with LayoutBuilder for nested adaptivity.
  • Keep stable UI parts outside the builder to limit rebuilds.
Concrete example
Show ListView in portrait and a dense GridView in landscape to present more items when there's extra width.
Performance note
Limit expensive rebuilds by moving non-orientation-dependent widgets out of the OrientationBuilder scope.
Key Takeaway

OrientationBuilder is ideal for swapping whole layouts between portrait and landscape to enhance usability.
