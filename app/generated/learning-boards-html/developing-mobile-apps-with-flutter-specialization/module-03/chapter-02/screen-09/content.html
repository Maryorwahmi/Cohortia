Module 3 › Chapter 3.2 › Drawer Navigation Pattern
Drawer example
Scaffold(
  appBar: AppBar(title: const Text('Drawer Demo')),
  drawer: Drawer(
    child: ListView(
      padding: EdgeInsets.zero,
      children: <Widget>[
        const DrawerHeader(
          decoration: BoxDecoration(color: Colors.blue),
          child: Text('App Menu', style: TextStyle(color: Colors.white, fontSize: 24)),
        ),
        ListTile(
          leading: const Icon(Icons.home),
          title: const Text('Home'),
          onTap: () {
            Navigator.pop(context); // Close the drawer
            // Navigator.pushNamed(context, '/');
          },
        ),
      ],
    ),
  ),
  body: Center(child: Text('Main Content')),
);
Close the drawer first, then navigate. This keeps the UI transitions clean and avoids overlapping animations.
UX considerations
  • Use Drawer for secondary destinations, not the primary tab switcher.
  • Keep important navigation in BottomNavigationBar for quick access.
  • Always close Drawer before pushing a named route to ensure a consistent animation sequence.
Key Takeaway
Use Drawer for secondary navigation and always close it with Navigator.pop before routing to a new screen.
