Module 3 › Chapter 3.2 › Passing Arguments and onGenerateRoute
Pattern: pushNamed with arguments
Example: Navigator.pushNamed(context, '/details', arguments: 'Product ID 123'). The receiving screen should cast safely and handle null values.
Why validate
  • Arguments come through an untyped slot. Casting without checks can crash the app.
  • onGenerateRoute lets you centralize parsing and return a fallback or typed route with clear errors.
onGenerateRoute outline
onGenerateRoute: (settings) {
  final args = settings.arguments;
  if (settings.name == '/details') {
    if (args is String) {
      return MaterialPageRoute(builder: (_) => DetailScreen(id: args));
    }
    return MaterialPageRoute(builder: (_) => ErrorScreen());
  }
  return null; // fallback to routes map
},
Use this approach for complex argument shapes, required parameters, or when you need to convert route strings into typed page objects.
