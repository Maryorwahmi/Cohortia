Module 3 › Chapter 3.2 › Named Routes and routes map
routes map example
MaterialApp(
  title: 'Named Routes Demo',
  initialRoute: '/',
  routes: {
    '/': (context) => const HomeScreen(),
    '/details': (context) => const DetailScreen(),
    '/settings': (context) => const SettingsScreen(),
  },
);
Once declared, navigate with Navigator.pushNamed(context, '/details'). Keep argument passing simple or move parsing to onGenerateRoute for complex scenarios.
Pros and pitfalls
  • Pros: Centralized map, easier refactor, concise calls.
  • Pitfall: Loose typing for arguments if you rely on ModalRoute without checks.
  • Tip: Use onGenerateRoute to construct routes with typed arguments when needed.
Key Takeaway
Named routes centralize navigation. Use onGenerateRoute when you need runtime parsing or stronger type safety for arguments.
