Module 3 › Chapter 3.2 › Hands-on Activity
Starter checklist
  1. Add '/products' and '/settings' to MaterialApp routes.
  2. Implement Drawer in HomeScreen with ListTile items for Products and Settings.
  3. In each onTap: Navigator.pop(context) then Navigator.pushNamed with the route string.
  4. Change the ElevatedButton to Navigator.pushNamed(context, '/products').
  5. Test returning by calling Navigator.pop from child screens.
Testing tips
Confirm argument passing by sending a string id to Products and reading it safely with a null check and a cast. If you see runtime type errors, refactor argument parsing into onGenerateRoute.
Completion check
You are done when Drawer navigation closes then opens a named route, and when returning from a child screen restores the parent UI state.
