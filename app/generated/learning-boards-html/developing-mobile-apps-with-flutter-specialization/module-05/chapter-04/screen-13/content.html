Article query (last 7 days)
final DateTime sevenDaysAgo = DateTime.now().subtract(Duration(days: 7));
final Timestamp sevenDaysAgoTs = Timestamp.fromDate(sevenDaysAgo);

QuerySnapshot querySnapshot = await FirebaseFirestore.instance.collection('articles')
  .where('status', isEqualTo: 'published')
  .where('publishedAt', isGreaterThanOrEqualTo: sevenDaysAgoTs)
  .orderBy('publishedAt', descending: true)
  .limit(5)
  .get();

Tip: since the range filter and orderBy use publishedAt, a single-field index is usually sufficient. If you order by a different field you may need a composite index.

Purchase transaction (conceptual)
await _firestore.runTransaction((transaction) async {
  DocumentSnapshot itemSnapshot = await transaction.get(itemRef);
  if (!itemSnapshot.exists) throw Exception('Item not found');
  int currentStock = (itemSnapshot['stock'] as num).toInt();
  if (currentStock < quantity) throw Exception('Insufficient stock');
  transaction.update(itemRef, {'stock': currentStock - quantity});
  transaction.set(userHistoryRef, { 'itemId': itemId, 'quantity': quantity, 'purchaseDate': FieldValue.serverTimestamp() });
});

Remember: transactions read and validate before writing and will retry if concurrent updates change the data during the operation.
