Comparison › Transactions vs Batched Writes
Transactions
  • Read documents, then decide and write.
  • Automatic retries on conflicts.
  • Use for conditional updates like counters or transfers.
Example
// transferFunds uses runTransaction to read balances and update both accounts.
Batched Writes
  • Group multiple writes and commit together.
  • No reads inside the batch; can't retry based on reads.
  • Efficient for bulk deletes or updates where current values aren't needed.
Example
WriteBatch batch = _firestore.batch();
for (String id in todoIds) {
  DocumentReference todoRef = _firestore.collection('todos').doc(id);
  batch.delete(todoRef);
}
await batch.commit();

Tip: prefer batches for non-dependent bulk operations and transactions for conditional correctness when reads matter.
