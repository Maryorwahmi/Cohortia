Module 5 › Chapter 5.4 › where() Patterns
Example: users older than 25
QuerySnapshot querySnapshot = await _firestore.collection('users')
  .where('age', isGreaterThan: 25)
  .orderBy('age', descending: false)
  .limit(10)
  .get();

for (var doc in querySnapshot.docs) {
  print('User: ${doc['name']}, Age: ${doc['age']}');
}

This example uses a range filter with orderBy on the same field, which usually does not require a composite index. If you change the orderBy field to something else, Firestore may prompt you to create a composite index for that combination.

Example: published posts with a tag
QuerySnapshot querySnapshot = await _firestore.collection('posts')
  .where('status', isEqualTo: 'published')
  .where('tags', arrayContains: 'flutter')
  .get();

for (var doc in querySnapshot.docs) {
  print('Post: ${doc['title']}, Tags: ${doc['tags']}');
}

Array queries match exact elements. arrayContains looks for a single element inside an array field. If you need to match documents that contain any of several tags, consider arrayContainsAny or a whereIn pattern depending on your data shape.

Common mistake
Treating arrayContains like a substring search. It checks array members for equality, not partial matches.
