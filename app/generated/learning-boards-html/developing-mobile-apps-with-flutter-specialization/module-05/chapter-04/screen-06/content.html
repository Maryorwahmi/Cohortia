Process › Cursor-based Pagination
Step-by-step
  1. Query collection with an orderBy and limit(n) to get the first page.
  2. Save the last document from the page as the cursor.
  3. For next page, issue the same query and call startAfterDocument(cursor).
  4. Repeat until returned docs < page size, then stop loading more.

Remember to use a stable ordering field such as a timestamp. When ordering by multiple fields include them in the same sequence every page query.

Example check
If page size is 10 and the query returns 10 docs, assume there may be more pages; if fewer, you've reached the end.
Concrete code pattern
Query query = FirebaseFirestore.instance.collection('posts')
  .orderBy('timestamp', descending: true)
  .limit(10);

if (lastDocument != null) {
  query = query.startAfterDocument(lastDocument);
}

QuerySnapshot querySnapshot = await query.get();
if (querySnapshot.docs.isNotEmpty) {
  lastDocument = querySnapshot.docs.last;
  // append docs to list
}

Note: use the same ordering and page size for every page. Changing either will break the cursor logic and can lead to duplicate or skipped documents.
