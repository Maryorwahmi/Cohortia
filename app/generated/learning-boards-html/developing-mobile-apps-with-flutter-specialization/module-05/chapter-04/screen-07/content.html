Module 5 › Chapter 5.4 › Infinite Scroll
State shape
  • List _posts — collected documents
  • DocumentSnapshot? _lastDocument — cursor for next page
  • bool _isLoading, bool _hasMore — loading and end detection
  • int _postsPerPage — page size constant
UI pattern

ListView.builder with controller; when index reaches length show a loading indicator if _hasMore is true. Prevent concurrent loads by checking _isLoading.

Starter fetch code
Query query = FirebaseFirestore.instance.collection('posts')
  .orderBy('timestamp', descending: true)
  .limit(_postsPerPage);

if (_lastDocument != null) {
  query = query.startAfterDocument(_lastDocument!);
}

QuerySnapshot querySnapshot = await query.get();
if (querySnapshot.docs.isNotEmpty) {
  _posts.addAll(querySnapshot.docs);
  _lastDocument = querySnapshot.docs.last;
  _hasMore = querySnapshot.docs.length == _postsPerPage;
} else {
  _hasMore = false;
}

Tip: add a small delay or check ScrollController position consistently to avoid duplicate fetches. For production, consider error handling and retries for network failures.
