Lab › Todo App: Pagination & Rules
Steps to implement
  1. Make TodoScreen a StatefulWidget and add pagination state variables.
  2. Write _fetchTodos that queries todos where userId == currentUser.uid, orderBy(createdAt), limit(_todosPerPage), and startAfterDocument when needed.
  3. Use a ScrollController to trigger _fetchTodos at the end of the list.
  4. Replace StreamBuilder with ListView.builder and include a loading indicator when _hasMoreTodos is true.
  5. Write and publish Security Rules that validate request.auth.uid against todo.userId on create/read/update/delete.
Starter rule snippet
match /todos/{todoId} {
  allow read, create: if request.auth != null && request.resource.data.userId == request.auth.uid;
  allow update, delete: if request.auth != null && resource.data.userId == request.auth.uid;
}
Test: create more than five todos for a user, scroll to load more, then sign in as another user to verify isolation. Use the Rules Playground for additional checks.
