Module 5 › Chapter 5.3 › Delete Documents
Delete example
// Delete a document
Future<void> deleteUser(String userId) async {
  try {
    await _firestore.collection('users').doc(userId).delete();
    print('User $userId deleted successfully!');
  } on FirebaseException catch (e) {
    if (e.code == 'not-found') {
      print('Document with ID $userId not found for deletion.');
    } else {
      print('Error deleting user: $e');
    }
  }
}
Practical considerations
  • Deleting a document does not delete its subcollections automatically.
  • Use batched deletes or server-side functions to remove large nested datasets.
  • Consider soft-deletes if you need undo or audit history.
Pro tip
When deleting user data, be deliberate: you may need to remove references and subcollection documents to avoid leaks and orphaned data.
