Module 5 › Chapter 5.3 › Collections & Documents
Hierarchy snapshot
- Collection: named container of documents (e.g., posts)
- Document: record with fields like content, userId, timestamp
- Field: key-value pair; types include map, array, timestamp
- Subcollection: collection under a document for growing related items
Quick model example
posts (collection)
· postDocId: { userId, content, timestamp }
· postDocId/comments (subcollection) → comment documents
Design guidance
  • Prefer subcollections for items that grow without bound.
  • Add query-friendly fields (like userId) to enable where() filtering.
  • Avoid deep nesting of maps if they can grow past document size limits.
Check your understanding
How would you fetch only room metadata without the messages list? Answer: store room fields in the room document and messages in a messages subcollection, then query the room document directly.
