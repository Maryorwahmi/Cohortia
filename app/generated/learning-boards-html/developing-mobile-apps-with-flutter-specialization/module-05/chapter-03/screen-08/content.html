Module 5 › Chapter 5.3 › Update Documents
Update example
Future<void> updateUserAge(String userId, int newAge) async {
  try {
    await _firestore.collection('users').doc(userId).update({
      'age': newAge,
      'lastUpdated': FieldValue.serverTimestamp(),
    });
    print('User $userId age updated to $newAge!');
  } on FirebaseException catch (e) {
    if (e.code == 'not-found') {
      print('Document with ID $userId not found for update.');
    } else {
      print('Error updating user age: $e');
    }
  }
}
Notes & pitfalls
  • update() will throw if the document doesn’t exist.
  • Use set(..., SetOptions(merge:true)) to update-or-create behavior.
  • For counters, use FieldValue.increment inside update or a transaction for correctness.
Pro tip
When updating user-visible timestamps, use serverTimestamp() to avoid client clock drift between devices.
