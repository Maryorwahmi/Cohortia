Module 5 › Chapter 5.3 › Pitfalls & Rules
Security rules caution
Test mode is fine for development but must be replaced with rules before production. A minimal rule example to restrict access to authenticated users is: allow read, write: if request.auth != null. Review rules in the Firebase Console under Firestore Database → Rules.
Data size & deletion
Documents have a 1MB limit. Avoid huge arrays and use subcollections for lists. Deleting a document does not remove subcollections; use batched deletes or server-side cleanup for cascading removal.
