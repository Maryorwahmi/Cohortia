pubspec.yaml snippet
dependencies:
  flutter:
    sdk: flutter
  firebase_core: ^2.x.x
  firebase_auth: ^4.x.x
  cloud_firestore: ^4.x.x # Add this (use latest stable version)
Run flutter pub get after updating dependencies and initialize Firebase at app start.
Enable Firestore
- Open Firebase Console → Firestore Database → Create database.
- Choose test mode for development, then secure with rules before production.
- Verify by writing a document from your app and observing it in the Console.
Common mistake
Forgetting to call Firebase.initializeApp() in main can cause calls to FirebaseFirestore.instance to fail at runtime.
