FirebaseAuth
Managed identity service used by createUserWithEmailAndPassword and signInWithEmailAndPassword.
authStateChanges
Stream that emits a User? when the sign-in state changes; pair with StreamBuilder for reactive UI.
Google Sign-In
Use google_sign_in to obtain tokens, then sign in to Firebase with signInWithCredential.
Summary
Initialize Firebase, enable providers in the Console, implement auth calls with try-catch, and use authStateChanges to keep the UI synchronized with the user session.
