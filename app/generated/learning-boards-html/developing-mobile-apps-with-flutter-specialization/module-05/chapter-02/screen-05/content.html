Module 5 › Chapter 5.2 › Enable Providers
Console steps
Navigate to Authentication → Sign-in method and enable Email/Password. For Google, set a support email and confirm OAuth configuration when prompted.
Step 1: Toggle Email/Password to "Enabled".
Step 2: Enable Google; add support email and client IDs if required.
Step 3: Re-run flutterfire configure or check firebase_options.dart contains client IDs.
Checklist
  • Provider toggled to enabled
  • Support email set for Google
  • OAuth client IDs present for Android/iOS when needed
Concrete scenario
If createUserWithEmailAndPassword returns 'Operation not allowed', check the Email/Password toggle in the Console. Toggling fixes the error without code changes.
Key takeaway
Treat Console configuration as part of implementation. A small toggle there can be the difference between working and failing sign-ins.
