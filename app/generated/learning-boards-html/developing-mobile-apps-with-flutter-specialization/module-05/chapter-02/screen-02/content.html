Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Implement Email/Password
Build registration and login flows using createUserWithEmailAndPassword and signInWithEmailAndPassword so users can create accounts and sign in securely.
VERIFIED COMPETENCY MILESTONE
02
React to Auth State
Use authStateChanges with StreamBuilder to transition automatically between AuthScreen and HomeScreen when the user's session changes.
VERIFIED COMPETENCY MILESTONE
03
Add Google Sign-In
Integrate google_sign_in to obtain tokens, exchange them for Firebase credentials, and provide single-tap login for users with Google accounts.
VERIFIED COMPETENCY MILESTONE
04
Manage Sessions & Errors
Implement signOut and clear provider sessions. Catch FirebaseAuthException codes and present clear feedback to users.
VERIFIED COMPETENCY MILESTONE
