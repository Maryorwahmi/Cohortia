Module 5 › Chapter 5.2 › Auth State
AuthWrapper pattern
return StreamBuilder(
  stream: FirebaseAuth.instance.authStateChanges(),
  builder: (context, snapshot) {
    if (snapshot.connectionState == ConnectionState.waiting) {
      return const CircularProgressIndicator();
    }
    if (snapshot.hasData) {
      return const HomeScreen();
    }
    return const AuthScreen();
  },
);
This structure avoids manual navigation when users sign in or out, and centralizes the decision of which top-level screen to show.
Common mistakes & fixes
  • Don't use FutureBuilder with currentUser; it won't update on sign-out.
  • Initialize Firebase before listening to authStateChanges to avoid race conditions.
  • Show a loading state while the stream connection is waiting to avoid flicker.
Key takeaway
StreamBuilder with authStateChanges is the dependable way to present the correct top-level screen for the user's session state.
