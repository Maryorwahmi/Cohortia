Activity Steps (Terminal-first)
Run these commands in sequence inside your terminal.
flutter create my_firebase_app
cd my_firebase_app
npm install -g firebase-tools
flutterfire configure
Follow CLI prompts to select the Firebase project and platforms.
# Add dependency
# edit pubspec.yaml then:
flutter pub get

# Run the app
flutter run
Verification
Confirm the app shows the expected initialization message or the console indicates Firebase initialized successfully when launched in the emulator.
Check your work

If errors appear, re-run flutterfire configure and ensure your package identifiers match the Firebase Console entries.
