Service Comparison
Match service to data and access patterns.
Authentication
Use for sign-in, provider integrations, and secure identity tokens used by other Firebase services.
User identity
Cloud Firestore
Store documents and collections, support offline sync and real-time updates for active clients.
Structured data
Storage
Host large files and serve them with secure download URLs controlled by security rules.
Binary files
Concrete example
In a chat app, Authentication verifies who posts messages, Firestore stores each message document with sender, text, and timestamp, and Storage holds any attached images. References in Firestore point to Storage objects.
Misconception
Treating Firestore like a relational database leads to inefficient queries. Instead, model data denormalized for fast reads and predictable billing.
Key Takeaway

Choose services by data type: identity, documents, or files, and model data for mobile access patterns.
