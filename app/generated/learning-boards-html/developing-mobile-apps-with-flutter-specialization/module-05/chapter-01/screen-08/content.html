Install and Configure
Terminal-first commands to prepare your project.
Install Firebase CLI
npm install -g firebase-tools
Run flutterfire configure
cd my_flutter_project
flutterfire configure
Select your Firebase project and the platforms you want configured when prompted.
What flutterfire creates
It generates platform configs and lib/firebase_options.dart which your app will import to initialize Firebase.
Checklist
  • Run install command once per developer machine.
  • Run flutterfire configure in the project root where pubspec.yaml lives.
  • Inspect generated firebase_options.dart and platform files.
