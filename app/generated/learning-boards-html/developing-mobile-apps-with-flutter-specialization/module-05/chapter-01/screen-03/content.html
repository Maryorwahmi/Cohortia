Module 5 › Chapter 5.1 › Learning Objectives
01
Manage platform config files
Identify google-services.json and GoogleService-Info.plist and how firebase_options.dart replaces manual edits.
Practice locating these files and see how flutterfire generates the unified Dart configuration so you avoid misplacing files across Android and iOS folders.
VERIFIED COMPETENCY MILESTONE
02
Add firebase_core dependency
Update pubspec.yaml and run flutter pub get to make Firebase packages available.
This ensures your code can import Firebase packages and that future service packages like authentication or Firestore can be added smoothly.
VERIFIED COMPETENCY MILESTONE
03
Avoid initialization mistakes
Recognize missing ensureInitialized or not awaiting initialization as common errors.
You will practice initializing in main correctly so platform channels and native services are available and you avoid crashes at app start.
VERIFIED COMPETENCY MILESTONE
04
Verify app run and status
Run the app and confirm the expected initialization message or behavior in the emulator.
A quick verification step reduces debugging time: if the sample home text appears without Firebase errors, you’ve completed the setup correctly.
VERIFIED COMPETENCY MILESTONE
