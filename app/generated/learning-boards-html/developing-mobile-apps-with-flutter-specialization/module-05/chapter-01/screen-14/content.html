Module 5 › Chapter 5.1 › Run & Verify
Run the App
Use emulator or device to verify initialization succeeds.
flutter run
# Look for logs showing successful Firebase initialization
If you added a confirmation text to the home screen, confirm it appears. Otherwise check the debug console for a successful initialization message or absence of Firebase startup errors.
Troubleshoot

If you see errors, verify main is async with ensureInitialized, confirm firebase_options.dart matches the project, and re-run flutterfire configure if needed.

What success looks like
App launches, no Firebase-related exceptions, and your debug message or home text confirms initialization.
