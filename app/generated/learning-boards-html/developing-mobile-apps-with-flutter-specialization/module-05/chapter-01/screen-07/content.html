Platform configuration files
Understand which files are native and which are generated for Dart.
google-services.json
Android platform config read by Gradle to wire Firebase into the app at build time.
GoogleService-Info.plist
iOS plist containing project identifiers used at runtime by iOS builds.
firebase_options.dart
Generated by flutterfire CLI; contains per-platform option objects you pass into Firebase.initializeApp.
Example import
// lib/main.dart
import 'firebase_options.dart';

// Pass DefaultFirebaseOptions.currentPlatform to initializeApp
Pro tip

Treat firebase_options.dart as generated; re-run flutterfire configure when you change console settings or platform identifiers.

Common error
Placing google-services.json in the wrong Android folder or using a mismatched package name will cause configuration failures at build time.
Why firebase_options.dart
It centralizes platform values for Dart, avoiding manual native file edits and reducing setup errors across Android and iOS.
