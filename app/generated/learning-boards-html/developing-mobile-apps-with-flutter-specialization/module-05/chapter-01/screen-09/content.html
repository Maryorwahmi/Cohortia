Inspect firebase_options.dart
This generated file maps console settings into Dart options.
What to look for
  • A DefaultFirebaseOptions symbol exposing per-platform options.
  • Platform API keys, project IDs, and other identifiers mapped for Dart use.
  • A currentPlatform getter often used in initialization calls.
Use example
// main.dart import
import 'firebase_options.dart';

// Pass options when initializing Firebase
// await Firebase.initializeApp(
//   options: DefaultFirebaseOptions.currentPlatform,
// );
Key takeaway

Rely on the generated file rather than copying keys across multiple files to avoid drift.

Misconception
Editing the generated file manually is fragile. Regenerate when console settings change.
Verify
If the app connects to the wrong Firebase project, re-run flutterfire configure and inspect DefaultFirebaseOptions for mismatches.
