Add firebase_core to pubspec.yaml
Install the package that enables initialization and core functionality.
dependencies:
  flutter:
    sdk: flutter
  firebase_core: ^2.x.x
After editing pubspec.yaml run flutter pub get in the terminal to fetch the dependency and make imports available to the analyzer and runtime.
Checklist
  • Add firebase_core under dependencies.
  • Run flutter pub get.
  • Restart IDE analysis server if imports fail to resolve.
Common issue
Using an incompatible package version for your Flutter SDK may prevent pub get from completing successfully. Check compatibility if you hit errors.
Why this matters
firebase_core provides the bridge between your Dart code and Firebase native SDKs; without it initialization and service usage will fail.
