Create a Firebase Project
Follow these steps in the Firebase Console.
1
Add project
Choose a descriptive name and continue through the prompts.
2
Analytics option
Enable or skip Google Analytics depending on your needs.
3
Add platform apps
Register Android and iOS apps to generate platform config files.
Files produced
Adding apps yields these configuration artifacts you will use or inspect later.
google-services.json — Android platform config file
GoogleService-Info.plist — iOS platform config file
Console Dashboard — enable services and view keys
Pro tip

Double-check package and bundle identifiers when adding apps to avoid configuration mismatches later.
