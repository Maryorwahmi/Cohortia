Module 5 › Chapter 5.1 › Initialize Firebase
main.dart Initialization
Call ensureInitialized and await Firebase.initializeApp before runApp.
// lib/main.dart
import 'package:flutter/material.dart';
import 'package:firebase_core/firebase_core.dart';
import 'firebase_options.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
  runApp(const MyApp());
}
Key takeaway

Initialize Firebase before creating widgets that depend on it to avoid runtime errors.

Common mistake
Omitting ensureInitialized or not awaiting initialization often causes exceptions when platform channels are accessed.
Check
If you see Firebase errors at startup, verify main is async, ensureInitialized is called, and initializeApp is awaited.
