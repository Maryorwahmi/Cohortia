Module 6 › Chapter 5.5 › Enable & Setup
Console: enable Storage
  1. Open Firebase Console → Storage → Get started.
  2. Choose default bucket location and confirm.
  3. Review initial security rules and prepare to tighten them after testing.
Flutter: add packages
# pubspec.yaml
firebase_storage: ^11.x.x
image_picker: ^1.x.x
cloud_functions: ^4.x.x
Run flutter pub get, then initialize Firebase in main before using Storage APIs. Ensure firebase_core is configured.
Checklist & common mistake
  • Firebase initialized before Storage calls.
  • User authentication available when rules expect request.auth.
  • Don't leave rules open after testing; tighten them promptly.
Try this
Initialize Firebase, sign in a test user, and confirm you can list or upload to your test folder using the Storage console inspector or a small test app.
