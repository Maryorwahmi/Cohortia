Module 6 › Chapter 5.5 › Mistakes & Practices
Mistakes
  • Leaving Storage rules permissive during development.
  • Using file listings as the primary way to find a user's photo.
  • Not enabling billing when functions require Blaze plan, causing deployment failures.
Best practices
  • Store canonical download URLs in user records in Firestore or Auth profile.
  • Use path-based rules that match ownership and deny by default.
  • Monitor function logs and set quotas to avoid unexpected billing.
Check question

Which folder paths will you create and what rule will enforce ownership for each?
