Module 6 › Chapter 5.5 › Learning Objectives
01
Upload & download files

Pick images or files in Flutter, use putFile to upload, and getDownloadURL to retrieve URLs. This skill is necessary for any app that stores user media.

VERIFIED COMPETENCY MILESTONE
02
Write secure Storage Rules

Define rules that limit read/write to authenticated users and user-scoped folders to prevent data leaks and abuse. Test rules before publishing.

VERIFIED COMPETENCY MILESTONE
03
Understand Cloud Functions

Know when to use HTTP-triggered or event-triggered functions for tasks like resizing images, sending notifications, or validating data server-side.

VERIFIED COMPETENCY MILESTONE
04
Deploy & integrate functions

Initialize a functions project, deploy code with the Firebase CLI, and call functions from Flutter using callable or HTTP endpoints.

VERIFIED COMPETENCY MILESTONE
