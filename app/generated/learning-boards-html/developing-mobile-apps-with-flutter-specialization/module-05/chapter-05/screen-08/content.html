Module 6 › Chapter 5.5 › ProfileScreen walkthrough
Essential behavior
  1. Load currentUser.photoURL or list the user's storage folder for a fallback.
  2. Pick an image and set an uploading flag to show a spinner.
  3. Upload to profile_pictures/{uid}/{timestamp}.jpg and await the task.
  4. Get download URL and update the user's profile with updatePhotoURL.
  5. Reload the user and update UI state.
Key takeaway
Store the returned URL in a single place such as the Auth profile or Firestore to keep UI logic simple.
Code excerpt (UI behaviors)
// After upload completes
String downloadUrl = await snapshot.ref.getDownloadURL();
await currentUser.updatePhotoURL(downloadUrl);
await currentUser.reload();
setState(() { _profileImageUrl = downloadUrl; _isUploading = false; });
Show success feedback and handle FirebaseException to surface errors to the user via SnackBar or inline error messages.
