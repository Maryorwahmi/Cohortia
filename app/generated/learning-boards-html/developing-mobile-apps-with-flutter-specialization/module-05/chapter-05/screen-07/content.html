Monitor UploadTask

Subscribe to snapshotEvents to compute percentage progress and update a progress bar in your UI.

// Example listener
uploadTask.snapshotEvents.listen((TaskSnapshot snapshot) {
  final progress = snapshot.bytesTransferred / snapshot.totalBytes;
  // update progress bar with progress value
});
After await uploadTask, call snapshot.ref.getDownloadURL() and store that URL with your user record in Firestore or Auth profile.
Download considerations
  • Use the returned download URL directly in image widgets if rules allow public reads.
  • For private files, you may use authenticated requests to fetch bytes and save locally.
  • Store URLs persistently unless you will regenerate them later.
