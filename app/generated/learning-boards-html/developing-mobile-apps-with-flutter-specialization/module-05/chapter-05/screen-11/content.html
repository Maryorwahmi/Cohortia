Module 6 › Chapter 5.5 › Cloud Functions
Concept

Functions run in a managed Node.js environment and can be triggered by Firebase features like Firestore, Storage, Auth, or via HTTP. They are ideal for operations that must run on a trusted backend.

Use cases
  • Send push notifications when a new message arrives.
  • Resize uploaded images after Storage onFinalize events.
  • Perform server-side validation or aggregation after Firestore writes.
Limitations & checks
  • Not for long-running background processes; prefer other compute options when needed.
  • Check billing plan requirements for certain triggers and networking features.
  • Monitor logs with the Firebase Console to diagnose failures.
