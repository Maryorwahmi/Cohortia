Module 6 › Chapter 5.5 › What is Firebase Storage?
Definition

Managed object store built on Google Cloud Storage that handles file upload reliability and public URLs.

Why use it?
  • Scales automatically for user media.
  • Resumable uploads and retries reduce client complexity.
  • Works with Firebase Security Rules for access control.
Key Takeaway
Store binary files here, keep searchable metadata in Firestore. Design folder paths for secure rules.
Concrete example — Profile picture flow
User picks an image, app uploads with putFile, then stores the returned download URL with the user profile so the UI can display it.
Common misconception

Storage is not a queryable database. Avoid treating filenames as structured data; instead, store metadata in Firestore if you need queries or indexing.
