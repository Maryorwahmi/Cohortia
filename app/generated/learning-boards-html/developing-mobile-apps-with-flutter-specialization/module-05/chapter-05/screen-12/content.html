functions/index.js
const functions = require('firebase-functions');

exports.helloWorld = functions.https.onRequest((request, response) => {
  functions.logger.info("Hello logs!", {structuredData: true});
  response.send("Hello from Firebase!");
});
Deploy with firebase deploy --only functions. After deployment, use the console to find the function URL and call it from your app or the browser to verify it responds.
Calling from Flutter
import 'package:http/http.dart' as http;

Future callHelloWorldFunction() async {
  final String functionUrl = 'YOUR_CLOUD_FUNCTION_HTTP_URL';
  final response = await http.get(Uri.parse(functionUrl));
  if (response.statusCode == 200) {
    print('Cloud Function response: ${response.body}');
  }
}
Or use FirebaseFunctions.instance.httpsCallable for callable functions that manage auth context automatically.
