Module 6 › Chapter 6.1 › Test environment
Process Flow

Set up and run tests

Directory structure
Organize tests under test/unit, test/widget, and test/integration for clarity and targeted runs.
Commands
Use flutter test to run all tests or supply a path to run a single file or folder.
Auto-generated example
New projects include widget_test.dart to demonstrate the basic widget test structure.
CI tip
Run unit tests in fast parallel jobs and schedule slower integration tests less frequently to save pipeline time.
Try
Run flutter test and then run flutter test test/unit to compare speeds.
Safety
Never commit API keys in tests. Use environment variables or test emulators for services like Firebase.
