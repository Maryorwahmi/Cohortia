Module 6 › Chapter 6.1 › Integration tests
Definition

Integration tests

Run full app flows on a device or emulator to validate end-to-end behavior and integration with services.

• Validate navigation, persistence, and backend interactions in realistic conditions.
• Use emulators or test projects when interacting with services like Firebase to avoid production side effects.
• Keep them limited to critical journeys due to execution time.
Example
A test that signs in a user, adds an item to cart, and completes checkout while verifying persistence in a test backend.
Safety note
Use separate test projects, environment variables, or emulators when tests interact with real services to protect production data.
Common pitfall
Running integration tests against production backends that cause data pollution or require manual cleanup.
