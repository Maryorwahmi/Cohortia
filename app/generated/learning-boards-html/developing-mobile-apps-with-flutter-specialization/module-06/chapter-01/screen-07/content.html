Calculator utility

Create a small library and a matching test file under test/unit to run with flutter test.

// lib/utils/calculator.dart
int add(int a, int b) {
  return a + b;
}

int subtract(int a, int b) {
  return a - b;
}


// test/unit/calculator_test.dart
import 'package:flutter_test/flutter_test.dart';
import 'package:your_app_name/utils/calculator.dart'; // replace with your package name

void main() {
  group('Calculator', () {
    test('add function should correctly add two numbers', () {
      expect(add(2, 3), 5);
      expect(add(-1, 1), 0);
      expect(add(0, 0), 0);
    });

    test('subtract function should correctly subtract two numbers', () {
      expect(subtract(5, 2), 3);
      expect(subtract(10, 10), 0);
      expect(subtract(0, 5), -5);
    });
  });
}
Run the test
Open a terminal at the project root and run:
flutter test test/unit/calculator_test.dart
Expected outcome
The terminal shows results and a summary such as all tests passed. If an import fails, check package name and file paths.
Common pitfall
Using the wrong import path for your app package causes tests to fail to resolve symbols. Replace your_app_name with your actual package name.
