Key Concepts

Unit Test
Tests a single function or class in isolation without UI.
Widget Test
Renders a widget in a test harness and simulates interactions.
Integration Test
Runs the full app or flows on a device or emulator to validate end-to-end behavior.
Summary

Start with unit tests, add widget tests for UI behavior, and use integration tests sparingly to keep feedback fast while ensuring end-to-end confidence.
