Learning Objectives

Bloom levels: Learn → Understand → Apply → Master

Bloom bar
01
Understand importance of testing

Explain why tests improve stability and reduce time spent debugging. Verified competency milestone: run a sample test and read its output.

02
Differentiate test types

Identify when to use unit, widget, and integration tests with examples. Verified competency milestone: pick the correct test type for a given task.

03
Set up and run tests

Use the test folder and run flutter test for a file or folder. Verified competency milestone: run the calculator unit test successfully.

04
Avoid common pitfalls

Recognize scope mistakes and protect sensitive data in tests. Verified competency milestone: explain one pitfall and a mitigation strategy.
