Testing Pyramid

A practical guide for test volume and scope.

Unit tests (base)
Many fast tests that validate single functions or classes in isolation.
Speed: fastest • Scope: tiny
Widget tests (middle)
Render widgets in a test harness to check UI behavior and interactions.
Speed: medium • Scope: component
Integration tests (top)
Run full app flows on emulator or device to validate end-to-end behavior.
Speed: slowest • Scope: end-to-end
Example
Sign-up flow: validation logic (unit), field error display (widget), complete sign-up with navigation (integration).
Misconception
Relying only on integration tests makes the suite slow and fragile; unit tests catch many errors earlier.
Try this
Write one unit test for a pure function and one widget test for a small component to compare execution time.
