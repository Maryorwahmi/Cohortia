Definition

Unit tests in Flutter

Fast tests for single functions or classes that run without a Flutter renderer.

• Run in plain Dart environment for speed.
• Ideal for utility functions and deterministic logic.
• Keep them isolated from network or file system dependencies.
Example
A calculator function that adds two integers should have unit tests that assert outputs for several inputs.
Best practice
Mock or isolate any side effects and keep unit tests deterministic.
Common mistake
Including network calls directly in unit tests, which makes them slow and flaky.
