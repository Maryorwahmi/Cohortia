Module 6 › Chapter 6.1 › Widget tests
Definition

Widget tests

Render widgets in a test harness and simulate user interactions like taps and text entry.

• Use testWidgets and pumpWidget to render a widget subtree.
• Verify visual state, accessibility labels, and interaction outcomes.
• Faster than integration tests but slower than unit tests.
Example
Test a button that shows a spinner on press or a form that displays validation errors.
Best practice
Mock or stub external services used by the widget to keep tests reliable.
Check
When a widget reacts to input, write a widget test that pumps the widget, simulates the input, and asserts the visible change.
Common mistake
Testing complex business logic inside widget tests instead of unit tests leads to slow and brittle suites.
