Module 6 › Chapter 6.1 › Learning Objectives

Practice plan

Concrete milestones and practical checks to verify each objective.

Objective 1
Run a unit test before and after a refactor

Verify that tests catch regressions and document the expected behavior for future changes.

Objective 2
Map tasks to test types

Use the pyramid rule: many unit, some widget, few integration tests to balance speed and confidence.

Objective 3
Organize tests under test/

Create test/unit, test/widget, and test/integration folders so test runs and CI are predictable.

Objective 4
Protect sensitive data

Use environment variables or emulators for backend services to avoid leaking keys or polluting production data.
