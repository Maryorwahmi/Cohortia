Practice

Organize tests and CI strategy

Directory layout
Use test/unit, test/widget, test/integration to keep suites targeted and discoverable.
CI scheduling
Run unit tests on every push, widget tests on pull requests, integration tests nightly or for releases.
Grouping
Group tests by feature inside folders for discoverability and context.
Developer tip
Run relevant tests locally before pushing to save CI cycles and get faster feedback.
Document
Keep a README with commands and environment notes so teammates can reproduce test runs.
