Module 3 › Chapter 2.3 › Lab: SafeArea & ListView.builder
Starter pattern (concept)
Wrap main content with SafeArea, then create a ListView.builder with itemCount and an itemBuilder that returns a Card containing an Image.network and a Text widget.
Lab checklist:
  • SafeArea wraps the ListView
  • ListView.builder has itemCount set to 20
  • Each Card contains an Image.network and a Text showing the index
  • Images use fixed height and BoxFit.cover for consistent layout
Starter code (expected structure)
SafeArea(
  child: ListView.builder(
    itemCount: 20,
    itemBuilder: (context, index) {
      return Card(
        margin: const EdgeInsets.all(8.0),
        child: Column(
          children: [
            Image.network(
              'https://via.placeholder.com/100',
              height: 100,
              width: double.infinity,
              fit: BoxFit.cover,
            ),
            Padding(
              padding: const EdgeInsets.all(8.0),
              child: Text('Item $index'),
            ),
          ],
        ),
      );
    },
  ),
)
Reflection

Compare how the top item appears with and without SafeArea. Did padding change? Was any content clipped by the status bar?
