Module 3 › Chapter 2.3 › Single-child vs Multiple-child
Single-child widgets
Examples: Container, Center, Padding, Align, SizedBox. Use these to style, size, or position one widget.
When to use: wrap a single image to add padding and a background color, or center a single text block.
Multiple-child widgets
Examples: Row, Column, Stack, ListView, GridView. These accept a children list and arrange multiple widgets.
When to use: compose toolbars, lists, or grids where multiple items must be shown together.
Analogy
Single-child is a frame for one painting; multiple-child is a gallery wall.
Concrete example
A Card containing a Column with image, title, and price — Card is single-child, Column is multiple-child.
Mistake to avoid
Putting a Column inside a Row without Expanded or Flexible can cause overflow errors.
