Module 3 › Chapter 2.3 › ListView.separated
How it works
You provide two builders. The itemBuilder returns list children and the separatorBuilder returns a widget inserted between items.
Benefits:
  • Cleaner item widgets without embedded dividers.
  • Consistent spacing and divider styling from a single place.
  • Better accessibility when separators are semantic and consistent.
Concrete example
Imagine contacts where each entry is a Card. Use separatorBuilder to return a Divider or SizedBox to add space—no need to change each Card when you adjust the gap.
Key Takeaway

Separated keeps presentation consistent and items focused on content rather than layout chrome.
