Module 3 › Chapter 2.3 › GridView variants
Constructors at a glance
  • GridView.count(): fixed number of columns via crossAxisCount.
  • GridView.extent(): specify max cross-axis extent; Flutter fits as many tiles as possible.
  • GridView.builder(): lazy builder for large or dynamic grids using a gridDelegate.
Example builder delegate shown on the right illustrates fixed cross-axis count for square tiles.
Example: GridView.builder snippet
GridView.builder(
  gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 2, // 2 columns
    crossAxisSpacing: 10,
    mainAxisSpacing: 10,
    childAspectRatio: 1.0, // Make items square
  ),
  itemCount: 20,
  itemBuilder: (BuildContext context, int index) {
    return Card(
      color: Colors.teal[100 * (index % 9)],
      child: Center(
        child: Text('Grid Item $index'),
      ),
    );
  },
)
Common pitfall: selecting an inappropriate crossAxisCount for small screens can make tiles too cramped; consider adapting the count with MediaQuery.
