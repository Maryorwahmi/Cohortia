Module 3 › Chapter 2.3 › Key Concepts
ListView / ListView.builder
One-dimensional scrolling; builder builds items lazily for performance.
GridView variants
Use count, extent, or builder to control columns and tile sizing for galleries and grids.
Single vs multiple child
Single-child widgets style one element; multi-child widgets compose lists and layouts.
Chapter takeaway

Match constructors and widget types to data size and device characteristics to build responsive, performant UIs.
