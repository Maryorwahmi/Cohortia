Constructors
Default ListView for few children. Builder for lazy construction of many items. Separated to inject separators without modifying each child.
Example: ListView.builder
ListView.builder(
  itemCount: 100, // Imagine 100 data items
  itemBuilder: (BuildContext context, int index) {
    return Card(
      margin: const EdgeInsets.all(8.0),
      child: Padding(
        padding: const EdgeInsets.all(16.0),
        child: Text('List Item $index'),
      ),
    );
  },
)
Practical notes
  • Always provide itemCount for builders to avoid index errors.
  • Use separated when you need consistent dividers between items.
  • Default constructor is fine for short, static lists like settings or forms.
Common Mistake

Forgetting itemCount in builder leads to infinite construction or index out of bounds when your itemBuilder references a data source by index.
