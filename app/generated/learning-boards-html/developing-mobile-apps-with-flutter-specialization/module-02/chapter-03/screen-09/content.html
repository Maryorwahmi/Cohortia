Module 3 › Chapter 2.3 › Adaptive layouts
Pattern
Query the device with MediaQuery.of(context) and branch layout code by orientation or width breakpoints.
Example logic:
  • If orientation is portrait: use Column to stack content.
  • If orientation is landscape: use Row to make use of horizontal space.
  • Adjust grid crossAxisCount based on available width for galleries.
Concrete example
Use an orientation check to return either a Column or a Row. For a GridView, compute crossAxisCount from MediaQuery.size.width or the current orientation so tiles remain readable and balanced.
Pro tip

Use breakpoints relative to width instead of absolute pixels so your layout scales across a range of devices.
