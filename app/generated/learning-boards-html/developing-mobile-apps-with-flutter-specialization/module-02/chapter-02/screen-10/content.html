Process Flow

Event handling

  1. User interacts with a widget (tap or type).
  2. Widget invokes its callback (onPressed, onChanged).
  3. Your callback updates state or triggers logic.
  4. If state changed, call setState to rebuild and reflect the update.
Pro tip
Keep callbacks small. For heavier tasks, call a separate async function and present loading state to the user.
Concrete examples
ElevatedButton(
  onPressed: () {
    // update state and call setState if necessary
    print('Elevated Button Pressed!');
  },
  child: const Text('Submit'),
),

TextField(
  onChanged: (value) {
    // live validation or update
    print('Text field value: $value');
  },
),
Common misconception: Changing a variable without setState will not update UI. Always call setState when the change should be visible.
