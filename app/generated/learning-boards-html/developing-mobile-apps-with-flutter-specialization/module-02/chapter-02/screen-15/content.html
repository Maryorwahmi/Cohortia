Module 2 › Chapter 2.2 › Key Concepts — Quick Reference
Controller lifecycle
Init controllers in State, add listeners for live updates, and always dispose them.
Button emphasis
Use Elevated for primary, Outlined for secondary, Text for subtle actions; ensure non-null callbacks.
Constrain media
Give images explicit sizes and placeholders; centralize text styles via theme for consistency.
Quick Summary
These core practices — manage lifecycle, choose controls by emphasis, and constrain media/text — will make your UIs predictable, accessible, and easier to debug.
