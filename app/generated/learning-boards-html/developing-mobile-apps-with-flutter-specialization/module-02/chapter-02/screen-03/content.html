Task checklist
  1. Style a header with Text and TextStyle (fontSize, fontWeight, color).
  2. Load Image.network and show a CircularProgressIndicator while loading.
  3. Add three button types wired to onPressed that log a message.
  4. Create two TextFields with controllers; show typed text live in a Text widget.
Pitfall checks
  • Is onPressed null? If so the button is disabled.
  • Do controllers get disposed in dispose()? If not, memory leaks can occur.
  • After updating state, is setState called so the UI rebuilds?
Mini-mnemonic: S-A-F-E
Style, Attach, Forward events, Ensure dispose. Use this as a checklist before moving to production.
Quick verification
Run the small demo and confirm console output for button presses, live text updates on input, and no errors when navigating away from the page (controller disposed).
