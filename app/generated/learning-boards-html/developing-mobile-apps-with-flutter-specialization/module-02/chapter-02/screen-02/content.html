Learning Objectives
Each objective includes a short verification task so you can show competency after the lesson.
01
Display content widgets
Use Text, Image, and Icon to present information clearly. Verify by styling a title and loading a network image with a placeholder.
VERIFIED COMPETENCY MILESTONE
02
Implement button types
Add Elevated, Text, Outlined, and FloatingActionButton appropriately. Verify by wiring onPressed that prints to the debug console.
VERIFIED COMPETENCY MILESTONE
03
Capture text input
Use TextField with a TextEditingController to read and set text. Verify by showing typed text in a Text widget that updates live.
VERIFIED COMPETENCY MILESTONE
04
Update UI via setState
Call setState inside StatefulWidget when state changes so the framework rebuilds affected widgets. Verify by toggling a state value and observing the UI update.
VERIFIED COMPETENCY MILESTONE
