Core Concept

StatefulWidget lifecycle

  • initState: initialize controllers and listeners.
  • setState: mutate state and schedule a rebuild.
  • dispose: remove listeners and dispose controllers to free resources.
Practical pattern
Keep state as local as possible. If only a small widget depends on a value, make that widget stateful instead of its entire parent to reduce rebuild work.
Key Takeaway

Call setState when state changes and always dispose controllers. Localize state to avoid expensive rebuilds.
