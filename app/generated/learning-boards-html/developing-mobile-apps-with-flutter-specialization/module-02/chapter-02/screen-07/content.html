Button families

Understand visual prominence and pick the family that matches your action’s importance.
ElevatedButton — Primary
Filled and elevated; use for primary commit actions like Save or Login.
OutlinedButton — Secondary
Thin border, no elevation; good for secondary or alternative actions.
TextButton — Subtle
Flat, minimal; ideal for low-emphasis actions or inline links.
Concrete example
ElevatedButton(
  onPressed: () { print('Elevated Button Pressed!'); },
  child: const Text('Submit'),
),
TextButton(
  onPressed: () { print('Text Button Pressed!'); },
  child: const Text('Cancel'),
),
OutlinedButton(
  onPressed: () { print('Outlined Button Pressed!'); },
  child: const Text('Learn More'),
),
Common mistake
Leaving onPressed null disables the button. If you want an enabled-looking action, pass an empty closure rather than null when appropriate.
