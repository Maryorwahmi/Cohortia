Warning

Common mistakes

  • Disabled buttons: onPressed is null.
  • Memory leaks: controllers not disposed in dispose().
  • Stale UI: changed variable without setState.
  • Layout shifts: unconstrained network images without placeholders.
Quick fixes
  1. Assign a non-null closure to onPressed to enable the button.
  2. Dispose controllers in dispose to prevent leaks.
  3. Wrap state changes in setState to update UI.
  4. Use loadingBuilder and errorBuilder for network images.
Pro-tip
Use small reproducible examples when debugging: isolate the widget and add prints to callbacks to confirm control flow.
