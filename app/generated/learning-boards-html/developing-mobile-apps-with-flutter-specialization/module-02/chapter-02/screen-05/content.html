Definition

Image widget

Use Image.asset, Image.network, Image.file, or Image.memory depending on where the image comes from. Always plan for loading and errors.

Why placeholders matter
Showing a loading indicator or a static placeholder avoids sudden layout jumps when the remote image arrives and provides feedback that content is on its way.
Example code
Image.network(
  'https://via.placeholder.com/150',
  width: 150,
  height: 150,
  fit: BoxFit.cover,
  loadingBuilder: (context, child, loadingProgress) {
    if (loadingProgress == null) return child;
    return Center(child: CircularProgressIndicator(value: loadingProgress.expectedTotalBytes != null ? loadingProgress.cumulativeBytesLoaded / loadingProgress.expectedTotalBytes! : null));
  },
  errorBuilder: (context, error, stackTrace) => const Icon(Icons.error),
)
Checklist
  • Constrain width and height explicitly for predictable layout.
  • Choose BoxFit to preserve aspect ratio and composition.
  • Use loadingBuilder and errorBuilder for network images.
Key Takeaway

Plan for latency and failures; placeholders and explicit sizes keep the UI stable and performant.
