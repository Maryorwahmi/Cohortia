Module 2 › Chapter 2.2 › Key Concepts
Material Design
Consistent visual and interaction guidelines powering Flutter widgets.
Text & TextStyle
Primary text display that reads from state and applies styling via TextStyle.
Image
Supports assets, network, file; use placeholders and explicit sizes for reliability.
Icon
Symbols for actions; always ensure discoverability with labels.
Buttons
Elevated, Outlined, Text — pick by emphasis and wire onPressed to enable interaction.
TextField
Use TextEditingController and onChanged; always dispose controllers to prevent leaks.
Summary
Choose widgets intentionally, wire callbacks, manage controller lifecycle, and call setState to reflect changes in the UI.
