Core Concept

Text widget

Use Text with a TextStyle object to control fontSize, fontWeight, and color for readable hierarchy.

Definition & Notes
  • Text reads a string and displays it using the current theme by default.
  • TextStyle customizes appearance; combine with Theme.of(context).textTheme for consistency.
  • For dynamic text, change state and let Flutter rebuild the Text widget.
Key Takeaway

Keep style centralized via Theme and update only via state changes so Text reflects app data correctly.

Concrete example
Text(
  'Welcome to Cohortia App',
  style: TextStyle(
    fontSize: 28,
    fontWeight: FontWeight.bold,
    color: Colors.deepPurple,
  ),
)
Common misconception
Text is not a mutable surface. If the string changes, update the state variable and trigger a rebuild. Trying to 'change' a Text directly will not work.
