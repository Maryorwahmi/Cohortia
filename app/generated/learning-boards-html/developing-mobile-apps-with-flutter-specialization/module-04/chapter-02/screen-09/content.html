Boolean conversion
Convert booleans to integers for storage and back when reading.
// toMap
'isCompleted': isCompleted ? 1 : 0,

// fromMap
isCompleted: map['isCompleted'] == 1,
This conversion prevents mismatches and ensures consistent queries and model reconstruction.
Other common mistakes
  • Not awaiting database open or CRUD Futures, causing race conditions.
  • Forgetting a primary key, which prevents precise updates or deletes.
  • Mixing UI logic into the DatabaseHelper; keep separation of concerns.
  • Not testing onUpgrade migrations before shipping updates to users.
Pro tip
Wrap db calls in try-catch and log failures so you can recover or surface errors rather than silently losing data.
