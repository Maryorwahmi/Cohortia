Singleton pattern
A shared instance prevents multiple open connections and centralizes schema management.
class DatabaseHelper {
  static final DatabaseHelper _instance = DatabaseHelper._internal();
  static Database? _database;

  factory DatabaseHelper() => _instance;
  DatabaseHelper._internal();

  Future<Database> get database async {
    if (_database != null) return _database!;
    _database = await _initDatabase();
    return _database!;
  }
}
_initDatabase responsibilities
Compute path, call openDatabase, handle onCreate and onUpgrade for migrations.
  • Use getDatabasesPath and join to build the file location.
  • Pass a version number and implement onCreate to execute CREATE TABLE statements.
  • Implement onUpgrade to alter schemas when releasing new app versions.
