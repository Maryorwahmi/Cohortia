onUpgrade pattern
Run conditional SQL to evolve your schema when the version increases.
onUpgrade: (db, oldVersion, newVersion) async {
  if (oldVersion < 2) {
    await db.execute("ALTER TABLE todos ADD COLUMN dueDate TEXT");
  }
  if (oldVersion < 3) {
    await db.execute("CREATE TABLE tags(id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT)");
  }
}
Steps to follow:
  1. Increment database version when you release schema changes.
  2. Write conditional migration code for each version step.
  3. Test migrations against real sample databases before shipping.
