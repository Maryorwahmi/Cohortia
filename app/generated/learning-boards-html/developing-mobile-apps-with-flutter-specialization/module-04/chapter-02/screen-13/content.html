Module 4 › Chapter 4.2 › Key Concepts
SQLite
A lightweight file-based relational database ideal for mobile apps that need structured, queryable storage.
sqflite
The Flutter plugin that provides async APIs to open and operate on SQLite databases from Dart code.
Model & CRUD
Use model classes with toMap/fromMap and implement insert, query, update, delete in a DatabaseHelper for clear separation of concerns.
Summary Takeaway

Structured local storage via sqflite is robust and lightweight; organize code into models and a DatabaseHelper, convert booleans to integers, and plan migrations to protect user data.
