Practical checks for your refactor
Concrete steps you will complete during the hands-on exercise
Dependency setup
Add sqflite and path_provider to pubspec and run flutter pub get. Verify no errors when importing packages in Dart files.
Model serialization
Implement toMap and fromMap for your Todo model, converting boolean flags to integers and back.
Database helper
Create a singleton DatabaseHelper that opens a database file, creates tables on first run, and exposes CRUD methods.
Integration check
Refactor the To-Do app to persist todos and ensure the ListView loads items using getTodos and updates after inserts/updates/deletes.
Pitfall to avoid
Do not forget to await asynchronous db calls and convert boolean fields to integers for storage.
