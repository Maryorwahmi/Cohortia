Learning Objectives
Understand the skills you'll practice and why they matter
Bloom: Learn → Understand → Apply → Master
01
When key-value storage fails
Identify scenarios where shared_preferences is insufficient and a relational database is needed. This matters for apps with lists of objects, queries, and relationships.
Mnemonic: small Venn — settings vs structured data
VERIFIED COMPETENCY MILESTONE
02
Add and open sqflite
Integrate the sqflite and path_provider packages, open a file-based database, and initialize your schema using onCreate. This prepares the storage layer for structured data.
Mnemonic: timeline — add, get, open
VERIFIED COMPETENCY MILESTONE
03
CRUD with model classes
Design a Dart model with toMap and fromMap for serialization and implement insert, query, update, and delete methods in a DatabaseHelper. This ensures reliable persistence and mapping between database rows and app objects.
Mnemonic: map in / map out
VERIFIED COMPETENCY MILESTONE
04
Migrations and pitfalls
Understand onUpgrade for schema evolution and common mistakes like not awaiting asynchronous calls or storing booleans without conversion. This keeps user data safe across app versions.
Mnemonic: small checklist
VERIFIED COMPETENCY MILESTONE
