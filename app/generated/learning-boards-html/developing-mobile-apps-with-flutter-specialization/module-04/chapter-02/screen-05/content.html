Dependency & path
Add these entries to pubspec.yaml and run flutter pub get to install the packages.
dependencies:
  flutter:
    sdk: flutter
  sqflite: ^2.3.0
  path_provider: ^2.1.1
Then in code, compute the path and open the database. Always await the returned Database instance before using it.
Open and initialize
Example pattern for opening a file database and creating tables.
// inside a helper
String documentsDirectory = await getDatabasesPath();
String path = join(documentsDirectory, 'todo_app.db');

return await openDatabase(
  path,
  version: 1,
  onCreate: (db, version) async {
    await db.execute(
      '''
      CREATE TABLE todos(
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        description TEXT NOT NULL,
        isCompleted INTEGER NOT NULL
      )
      '''
    );
  },
);
Note the onCreate callback defines your initial schema. Treat this as the canonical place to run CREATE TABLE statements for a fresh database file.
