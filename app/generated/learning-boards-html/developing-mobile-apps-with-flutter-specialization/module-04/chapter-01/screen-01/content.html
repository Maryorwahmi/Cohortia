Introduction to Local Data Storage

Practical patterns for storing small, persistent values on-device using shared_preferences in Flutter.

In this lesson

Understand when to use local persistence, add shared_preferences, read and write primitive data, and avoid common mistakes.

Why it matters

Small persistent values make apps feel personal and reliable even offline, while keeping complexity low compared to full databases.

Explore Key Topics
Purpose
Store user settings and small caches without a database.
shared_preferences
A simple key-value API for primitive types.
Async
Reads and writes return futures; always await to avoid race conditions.
Concept Map

Key pieces of local persistence

Use cases

Remember preferences, store last-viewed item, cache small results for offline use.

Limitations

Not for large datasets, relational queries, or unencrypted secrets.

Types

String, int, bool, double, and List are supported directly.

Async behavior

Get instance and set operations return futures—await them to ensure completion.

This slide orients you to what we'll cover: dependency setup, reading and writing, handling async, serialization, and practical examples.
