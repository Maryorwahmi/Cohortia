02 • Get instance

Use SharedPreferences.getInstance() and await its future before using set or get methods to avoid race conditions.

03 • Fallbacks

When a key is missing, use the null-coalescing operator to provide safe defaults and prevent null errors.

04 • Serialization

Serialize complex objects to JSON strings and store them as strings. Deserialize when reading back into objects.
