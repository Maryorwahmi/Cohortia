Module 4 › Chapter 4.1 › Best practices and pitfalls
Key practices
  1. Centralize keys as constants.
  2. Use null-coalescing defaults when reading.
  3. Serialize complex objects to JSON strings.
  4. Await set operations when necessary.
  5. Avoid storing secrets unencrypted.
Pitfalls
  • Not awaiting writes and risking data loss.
  • Using vague keys that collide across features.
  • Storing large or binary data that slows the app.
Check your understanding

If you need to persist a small list of strings, use setStringList; for complex models consider JSON or a database.
