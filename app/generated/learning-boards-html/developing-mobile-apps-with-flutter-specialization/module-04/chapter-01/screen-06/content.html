Module 4 › Chapter 4.1 › Add dependency and get package
Step-by-step
  1. Edit pubspec.yaml and add the dependency with a recent version.
  2. Run flutter pub get to fetch the package.
  3. Import package in your Dart file and call SharedPreferences.getInstance() when needed.
Example pubspec snippet
dependencies:
  flutter:
    sdk: flutter
  shared_preferences: ^2.2.2
Common mistakes
  • Forgetting to run flutter pub get after editing pubspec.yaml.
  • Not using a current package version, which may lack bug fixes.
  • Assuming imports will work before fetching packages.
Pro tip

Keep your dependency versions in source control and run pub get during CI to catch missing packages early.
