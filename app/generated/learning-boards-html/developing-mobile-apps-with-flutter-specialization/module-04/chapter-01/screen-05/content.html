Supported value types
  • String
  • int
  • bool
  • double
  • List
Practical tip

Keep keys descriptive and centralized to avoid collisions and make refactoring easier.

When you need objects

For custom objects, serialize to JSON and store the JSON string. Deserialize when loading. If your object grows complex, migrate to a database instead.

Serialization example

Convert a small settings object to JSON, store the string, then parse it back when needed.

Warning

shared_preferences is not encrypted by default. Do not store passwords or tokens here without encryption.
