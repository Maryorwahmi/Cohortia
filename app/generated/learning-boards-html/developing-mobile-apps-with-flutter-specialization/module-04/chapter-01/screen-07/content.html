Module 4 › Chapter 4.1 › Getting and using SharedPreferences
Minimal pattern
Future _loadSettings() async {
  final prefs = await SharedPreferences.getInstance();
  final isDark = prefs.getBool('isDarkMode') ?? false;
  setState(() => _isDarkMode = isDark);
}

Future _toggleDarkMode(bool value) async {
  setState(() => _isDarkMode = value);
  final prefs = await SharedPreferences.getInstance();
  await prefs.setBool('isDarkMode', value);
}
Notice getBool returns null when the key is missing, so we use ?? false to provide a safe default. Also notice we await setBool to ensure the write completes.
Explanation bullets
  • getInstance is async; await it to get the singleton tied to persistent storage.
  • Typed getters can return null; provide defaults with the null-coalescing operator.
  • Always await set calls to avoid race conditions and potential data loss.
Key Takeaway

Treat shared_preferences calls as asynchronous and provide defaults for missing keys to keep UI consistent.
