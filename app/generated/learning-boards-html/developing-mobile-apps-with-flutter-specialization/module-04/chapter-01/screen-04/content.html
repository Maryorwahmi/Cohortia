Module 4 › Chapter 4.1 › What is local data persistence?
Definition

Storing small pieces of state on the device so they persist across app restarts and can be used offline.

Example: Weather app

Remember temperature unit or last-viewed city so the app shows relevant data immediately on launch.

Example: Game

Persist a high score locally so it remains available offline and after restarts.

Common misconception

Local storage must be a database. In fact, for simple pairs a key-value store is faster and much simpler to maintain.

Key Takeaway

Use local persistence for small, non-sensitive values that improve UX and work offline.

When not to use it
  • Large datasets or complex relationships that require queries.
  • Sensitive secrets like passwords unless encrypted with secure storage.
  • When you need server-wide consistency or centralized sync.
Quick checks
Is it small?
Yes: key-value is fine.
Is it sensitive?
Yes: do not use shared_preferences alone.
