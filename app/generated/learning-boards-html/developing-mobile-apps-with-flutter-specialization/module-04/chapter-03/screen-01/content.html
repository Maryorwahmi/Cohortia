Consuming RESTful APIs
Understand HTTP methods, JSON encoding, and async UI patterns used in Flutter development.
In this lesson: GET, POST, Futures
Tools: http package, FutureBuilder
Outcomes: parse JSON, handle errors
Interactive 16:9 Masterclass
Orientation

This chapter focuses on practical steps: installing the http package, modeling JSON responses, making requests, and wiring results into widgets using FutureBuilder. Examples use a public test API that returns posts and users so you can test without a backend.

Explore Key Topics
HTTP Methods
GET retrieves, POST creates, PUT updates, DELETE removes. Status codes tell success or failure.
JSON & Models
Decode JSON to Dart maps, then convert to model classes with factory constructors.
Async UI
Use FutureBuilder to show loading, error, and data states without blocking the UI thread.
Visual Concept
Flow: request → decode → display
1. Build request with Uri and headers
2. Await http response and check status code
3. jsonDecode and map to models
4. FutureBuilder updates UI for loading, error, data
Hands-on Preview
Try a small task: add the http package, write a fetch function that returns a list of users, and display name, email, and city using a FutureBuilder.
