Module 4 › Chapter 4.3 › Learning Objectives
Objective Tasks
Implement fetchPosts()
Call the test API, check for a 200 status, jsonDecode the response, and map to Post model objects using a factory constructor.
Use FutureBuilder
Attach the returned Future to FutureBuilder to present loading, error, and data states without blocking the UI thread.
Send JSON with POST
Use jsonEncode and set Content-Type to application/json to create resources and handle the 201 Created response code.
Verification
Each objective includes a coding check: run the app, confirm loading spinner, inspect a ListView of items, and simulate a network error to see your error UI.
