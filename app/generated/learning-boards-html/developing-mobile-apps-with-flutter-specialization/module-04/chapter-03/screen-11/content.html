PUT Example
final response = await http.put(
  Uri.parse('https://jsonplaceholder.typicode.com/posts/1'),
  headers: {'Content-Type': 'application/json; charset=UTF-8'},
  body: jsonEncode({'id': 1, 'title': newTitle, 'body': newBody}),
);
if (response.statusCode == 200) {
  // parse updated object or refresh list
} else {
  throw Exception('Failed to update: ${response.statusCode}');
}
DELETE Example
final response = await http.delete(
  Uri.parse('https://jsonplaceholder.typicode.com/posts/1'),
);
if (response.statusCode == 200 || response.statusCode == 204) {
  // remove item from UI
} else {
  throw Exception('Failed to delete: ${response.statusCode}');
}
Key Takeaway

Confirm server responses before changing local UI state; repeated PUT/DELETE should be safe to retry if server respects idempotency.
