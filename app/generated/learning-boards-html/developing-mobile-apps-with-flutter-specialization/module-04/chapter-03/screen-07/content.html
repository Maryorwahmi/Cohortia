User Model Example
Access nested keys and return a simple, testable object shape.
class User {
  final int id;
  final String name;
  final String email;
  final String city;

  User({required this.id, required this.name, required this.email, required this.city});

  factory User.fromJson(Map<String, dynamic> json) {
    final address = json['address'] as Map<String, dynamic>;
    return User(
      id: json['id'],
      name: json['name'],
      email: json['email'],
      city: address['city'],
    );
  }
}
Guidelines
  • Inspect the JSON structure and map nested objects explicitly.
  • Use casts like as Map<String, dynamic> to safely work with nested objects.
  • Guard against missing keys to avoid FormatException; consider default values.
Test Tip
Write small unit tests that call User.fromJson with sample JSON to validate behavior when fields are missing or types differ.
Key Takeaway

Keep parsing logic explicit and test factories with sample JSON to catch format issues early.
