POST Example
Encode the request body and set headers correctly.
Future<Post> createPost(String title, String body) async {
  final response = await http.post(
    Uri.parse('https://jsonplaceholder.typicode.com/posts'),
    headers: <String, String>{
      'Content-Type': 'application/json; charset=UTF-8',
    },
    body: jsonEncode(<String, String>{
      'title': title,
      'body': body,
      'userId': '1',
    }),
  );

  if (response.statusCode == 201) {
    return Post.fromJson(jsonDecode(response.body));
  } else {
    throw Exception('Failed to create post: ${response.statusCode}');
  }
}
Notes & Tips
  • Always set the Content-Type header when sending JSON.
  • Check for 201 Created on success and decode the response into a model.
  • Sanitize and validate data client-side before sending to avoid server errors.
Common Mistake
Sending a Dart Map directly as body will result in form-encoded data rather than JSON. Use jsonEncode to produce a proper JSON string.
