Module 4 › Chapter 4.3 › Handling Network Errors
Common error types
  • Connectivity: SocketException when device is offline.
  • Timeouts: Server too slow; use timeouts and backoff.
  • Status codes: 4xx and 5xx errors require different responses.
  • Format errors: malformed JSON causing FormatException.
Example
Wrap calls in try-catch and display a retry button after logging details for debugging. For unauthorized responses, guide the user to sign in again.
Retry & Backoff
For transient failures use exponential backoff. Avoid immediate repeated retries which can worsen server load or cause duplicate operations for non-idempotent methods.
Key Takeaway

Differentiate between connectivity, server, and parsing errors. Log details, inform users clearly, and design safe retry strategies.
