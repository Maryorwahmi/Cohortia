01
Explain RESTful APIs
Describe resource-based design and why HTTP methods map to CRUD operations. This matters because correct semantics affect caching, security, and developer expectations.
Mnemonic: resource verbs venn
VERIFIED COMPETENCY MILESTONE
02
Use the http package
Add the package, construct Uri objects, and make GET/POST/PUT/DELETE calls. You will practice forming headers and using jsonEncode for request bodies.
Mnemonic: package → request → response
VERIFIED COMPETENCY MILESTONE
03
Parse JSON safely
Write factory constructors to convert nested JSON into Dart models and avoid common FormatException pitfalls by validating keys and types.
Mnemonic: decode → validate → map
VERIFIED COMPETENCY MILESTONE
04
Build resilient async UI
Use FutureBuilder to show loading, error, and data states. Handle network errors with try-catch and show user-friendly messages.
Mnemonic: wait → show → recover
