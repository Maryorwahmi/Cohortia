Collection
A grouping of documents, used as the primary query target.
Document
A record with fields; identified by a document ID and optionally containing subcollections.
Security Rules
Server-side policies that control read and write access to Firestore data.
Final takeaway

Keep these definitions front of mind as you implement real-time features and secure your app for production.
