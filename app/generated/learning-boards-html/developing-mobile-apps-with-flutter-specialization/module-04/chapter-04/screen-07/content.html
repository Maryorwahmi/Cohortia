main.dart initialization

Use the Firebase options generated by the FlutterFire CLI and await initialization.

import 'package:firebase_core/firebase_core.dart';
import 'package:flutter/material.dart';
import 'firebase_options.dart'; // Generated by FlutterFire CLI

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
  runApp(const MyApp());
}
Ensure firebase_options.dart exists and matches your configured project.
Checklist
  • Place platform config files correctly.
  • Run flutterfire configure to generate firebase_options.dart when required.
  • Await Firebase.initializeApp before using Firestore instance.
Key Takeaway

Initialization must complete before any Firestore calls. Missing this step causes runtime failures.
