Code Example

ProductService: add and set

import 'package:cloud_firestore/cloud_firestore.dart';

class ProductService {
  final CollectionReference productsCollection =
      FirebaseFirestore.instance.collection('products');

  Future addProduct(String name, double price, bool inStock) async {
    await productsCollection.add({
      'name': name,
      'price': price,
      'inStock': inStock,
      'timestamp': FieldValue.serverTimestamp(), // Useful for ordering
    });
    print('Product added!');
  }

  Future setProductWithId(String id, String name, double price, bool inStock) async {
    await productsCollection.doc(id).set({
      'name': name,
      'price': price,
      'inStock': inStock,
      'timestamp': FieldValue.serverTimestamp(),
    });
    print('Product with ID $id set!');
  }
}
Use merge:true with set() to avoid overwriting fields when appropriate.
Explanation & tips
  • add(): quick, auto-ID. Good for chat messages and events.
  • set(): explicit ID. Good for predictable keys or idempotent writes.
  • set(overwrite): will replace unless merge:true is passed.
Key Takeaway

Choose add() for autogenerated IDs and set() when you need control. Prefer update() for partial changes.
