Module 5 › Chapter 4.4 › Build a simple real-time chat or notes feature
Hands-on Activity

Create messages collection and UI

Steps
  1. Ensure Firebase initialized and cloud_firestore added to pubspec.
  2. Create a messages collection with fields: text, sender, timestamp.
  3. Use snapshots().orderBy('timestamp', descending:true) and map to models.
  4. Use StreamBuilder and ListView.builder to display messages.
  5. Add a TextField to send messages using add() and FieldValue.serverTimestamp().
Hints
  • Reverse list order for chat with reverse:true so newest appears at bottom.
  • Guard sends with simple validation (non-empty text).
  • Simulate multiple devices or emulators to observe real-time sync.
