Module 5 › Chapter 4.4 › Firestore data model
Definition

Collections • Documents • Fields

Think of a collection as a folder, a document as a file, and fields as key-value entries inside the file.

Collection
A named grouping of documents. Example: products
Document
A record with an ID and fields like name, price, inStock.
Field
A key-value pair inside a document. Types include strings, numbers, booleans, timestamps.
Concrete example
Collection: products → Document: product_id_1 → Fields: name: "Laptop Pro", price: 1200.00, inStock: true
Modeling guidance
  1. Design structure to match queries you will perform frequently.
  2. Denormalize where it saves reads (duplicate small pieces of data when it reduces queries).
  3. Avoid extremely deep nesting if you must query across many documents.
Key Takeaway

Use a collection-per-entity approach and design documents with the queries and costs you expect.
