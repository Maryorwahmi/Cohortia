Module 5 › Chapter 4.4 › Project setup and FlutterFire plugins
Step-by-step

Create project • Add apps • Add deps

  1. In the Firebase Console create a new project and register Android/iOS apps.
  2. Download google-services.json or GoogleService-Info.plist and add them to platform folders.
  3. Add packages to pubspec.yaml and run flutter pub get.
Dependencies example
dependencies:
  flutter:
    sdk: flutter
  firebase_core: ^2.24.2 # Core Firebase functionality
  cloud_firestore: ^4.13.6 # Firestore database
Run flutter pub get after editing pubspec.yaml
Common mistakes
  • Misplacing platform config files prevents SDK initialization.
  • Forgetting to run flutterfire configure when required for firebase_options.dart.
  • Skipping WidgetsFlutterBinding.ensureInitialized before Firebase.initializeApp.
Pro tip

Keep a copy of your platform config files outside your project until CI and release setup is finalized.
