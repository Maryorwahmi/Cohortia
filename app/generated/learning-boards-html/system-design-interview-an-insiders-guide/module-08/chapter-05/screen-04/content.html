Counter
A cumulative metric that only increases and is used to compute rates.
Definition

Counters measure the total number of occurrences since process start. They are not suitable for values that go down.

Example

http_requests_total incremented with labels for method, endpoint, and status. Use rate(http_requests_total[5m]) to compute requests per second.

Key Takeaway

Convert counters into rates for meaningful alerting and SLOs. Don't decrement a counter to indicate a current state.

Concrete scenario

Imagine a payment API that increments payments_total on success and errors_total on failures. A sudden spike in errors_total per minute triggers an investigation that points to a downstream database timeout. The counter-to-rate conversion makes the spike visible.

Common mistake

Using counters for current counts. For example, decreasing the counter to reflect active sessions will break rate-based queries.
