Module 8 › Chapter 8.5 › Summaries
Summary
Client-side computed quantiles over a sliding window.
Use case

Direct per-instance quantiles for local dashboards or debugging.

Do not aggregate summaries across instances for fleet-level percentiles.
Concrete example

An instance exposes rpc_duration_seconds_quantile with quantiles 0.5, 0.9, 0.99. This helps the instance owner but cannot be summed to produce correct cluster quantiles.

Misconception

Aggregating per-instance quantiles to claim a fleet p99 is incorrect; use histograms instead for accurate aggregation.
