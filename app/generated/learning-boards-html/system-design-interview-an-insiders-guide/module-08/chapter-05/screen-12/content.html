Alert rule (YAML)
groups:
- name: web_service_alerts
  rules:
  - alert: HighErrorRate
    expr: |
      sum(rate(http_requests_total{endpoint="/data", status=~"5.."}[5m]))
      /
      sum(rate(http_requests_total{endpoint="/data"}[5m]))
      > 0.05
    for: 1m
    labels:
      severity: critical
    annotations:
      summary: "High 5xx error rate for /data endpoint"
      description: "The /data endpoint is experiencing a 5xx error rate above 5% for the last 5 minutes."
Why this works

We compute the error rate by dividing the rate of 5xx responses by the rate of all responses. A for: clause prevents brief spikes from firing alerts.

Common mistake

Using unmatched labels in queries or missing annotations leaves responders without context. Always include summary and description annotations.
