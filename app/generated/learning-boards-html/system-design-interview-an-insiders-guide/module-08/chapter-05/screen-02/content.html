Learning Objectives
Skills you'll develop and why they matter.
01
Recognize metric types

Identify counters, gauges, histograms, and summaries in code and logs. Knowing the type guides queries and alert semantics.

VERIFIED COMPETENCY MILESTONE
02
Choose collection model

Decide between pull and push based on service lifetime, network topology, and operational control. Each model changes discovery and resilience trade-offs.

VERIFIED COMPETENCY MILESTONE
03
Write actionable alerts

Create alerts that include context and severity, use burn rates when tied to SLOs, and avoid noisy symptom-only alerts.

VERIFIED COMPETENCY MILESTONE
04
Instrument a service

Add counters and histograms to a web endpoint and export /metrics. Then write a Prometheus-style alert for a high 5xx rate.
