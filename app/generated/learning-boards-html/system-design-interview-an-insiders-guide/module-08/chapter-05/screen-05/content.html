Gauge
A metric representing a current value that can go up or down.
Use cases
  • CPU and memory usage.
  • Queue length and active connections.
  • Temperature or other instantaneous sensor values.
Alerting guidance

Alert on sustained deviation or anomalous jumps; pair with runbooks explaining what to check when a gauge exceeds a threshold.

Concrete example

A message queue exposes queue_length as a gauge. If queue_length is > 1,000 for more than 10 minutes, alert as warning; if it stays > 5,000 for 5 minutes, escalate to critical. This distinction prevents noisy alerts from short bursts of load.

Misconception

Do not express a current count with a counter. That will mask decreases and make current state monitoring impossible.
