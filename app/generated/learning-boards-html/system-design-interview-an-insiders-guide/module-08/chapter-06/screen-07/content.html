Common ELK pipeline
Logs → Shippers → (Kafka buffer) → Logstash → Elasticsearch → Kibana
Logstash
Parses unstructured logs, enriches records, and redacts sensitive fields before indexing.
Elasticsearch
Distributed index for high-speed search and aggregations on log fields.
Kibana
UI for queries, dashboards, and alerts built on top of Elasticsearch indices.
Supporting pieces
Log shippers like Filebeat or Fluentd collect logs locally and forward them. Kafka or a message queue can buffer spikes to avoid data loss when downstream processors are slow. Agents should support local buffering and retries to increase pipeline reliability.
Production tip
Centralize redaction rules in Logstash so you don't rely solely on developers to avoid logging PII. Logging policies should be enforced at collection and pipeline stages.
Common misconception

Pointing shippers directly to storage without processing makes you lose a centralized place to normalize and redact data.
