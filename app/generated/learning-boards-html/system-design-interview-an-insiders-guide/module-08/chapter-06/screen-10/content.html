Example cURL commands
# Successful request
curl -H "X-Correlation-ID: 123-abc" -H "X-User-ID: user-1" http://localhost:5000/product/1

# Failed request (product_id % 5 == 0)
curl -H "X-Correlation-ID: 456-def" -H "X-User-ID: user-2" http://localhost:5000/product/5

# Another successful request
curl -H "X-Correlation-ID: 789-ghi" -H "X-User-ID: user-3" http://localhost:5000/product/2
Include X-Correlation-ID and X-User-ID headers to test propagation through the logger.extra_context mechanism in the app.
Sample structured log output
{
  "timestamp": "2023-10-27T10:30:05.123Z",
  "level": "ERROR",
  "service_name": "product-service",
  "correlation_id": "456-def",
  "user_id": "user-2",
  "product_id": 5,
  "error_type": "database_error",
  "message": "Failed to retrieve product details for ID 5"
}
This record shows how correlation_id and user_id let you find all related entries across services and time.
Example queries to run in Kibana-like UI
  • level: ERROR AND service_name: "product-service" — find all errors from the product service.
  • correlation_id: "456-def" — view the entire request journey for this request ID.
  • service_name: "product-service" AND user_id: "user-1" AND product_id: 1 — investigate a specific user and product interaction.
