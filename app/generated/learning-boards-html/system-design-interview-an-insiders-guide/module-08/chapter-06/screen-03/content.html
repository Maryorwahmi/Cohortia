Deepen and Practice
Each objective comes with a small practical experiment to reinforce the skill.
Experiment: Centralized search
Collect logs from three microservices and search for an error message using a correlation ID to reconstruct the request path.
Mnemonic: Trace the ID → Reconstruct events → Fix root cause.
Experiment: Structured fields
Emit JSON logs with service, level, user_id, and correlation_id. Verify you can filter by user_id without regex.
Mnemonic: Keys not phrases — query fields, not text.
Experiment: Pipeline reliability
Add a shipper with local buffering and place a Kafka topic before processing to observe behavior during spikes.
Mnemonic: Buffer to survive bursts.
Experiment: Safe logging
Implement application-level redaction for emails and test a Logstash filter to remove sensitive fields before indexing.
Mnemonic: Mask early, filter centrally.
