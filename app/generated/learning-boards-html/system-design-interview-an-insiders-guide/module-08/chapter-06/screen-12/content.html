Field filtering and aggregation
Use field filters (service_name, level, user_id) to narrow results. Then use aggregations to count errors, group by error_type, or compute percentiles on latency fields.
Filter example
level: ERROR AND service_name: "product-service"
Aggregation example
Count by error_type over 15-minute buckets to see spikes.
Alerting patterns
  • Error rate increase above threshold.
  • Critical message appears in logs.
  • Missing expected heartbeat logs from a service.
Avoid over-alerting; tune thresholds and use composite conditions to reduce noise. Always provide a correlation ID example in the alert to help triage quickly.
Drill-down workflow
  1. Set time window for the incident.
  2. Filter by relevant service and level.
  3. Aggregate by error type to find top causes.
  4. Pick a correlation ID from a sample error and search across services.
