Module 8 › Chapter 8.6 › Correlation ID
Definition & practice
A correlation ID is a request-scoped identifier propagated through services. Generate at the edge and include it in all logs and request headers.
Concrete example
Client sends a header X-Correlation-ID: 123-abc. Every service uses that value when emitting logs. A single query for correlation_id: "123-abc" returns the whole flow.
Common mistakes
  • Not propagating the header in internal service-to-service calls.
  • Using user ID or session ID as a correlation key—these do not map to single requests.
Quick checklist
  • Generate at the gateway if missing.
  • Pass via headers for synchronous calls and include in metadata for async work.
  • Log it in every emitted record.
Test: query by correlation_id
After sending a request with a known ID, search for it and confirm entries from each service appear in chronological order.
