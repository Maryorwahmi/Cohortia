Starter code (excerpt)
from flask import Flask, request, jsonify, g
import logging
import json
import uuid
import random

app = Flask(__name__)

class JsonFormatter(logging.Formatter):
  def format(self, record):
    log_entry = {
      "timestamp": self.formatTime(record, self.datefmt),
      "level": record.levelname,
      "message": record.getMessage(),
      "service_name": getattr(record, 'service_name', 'unknown-service'),
      "correlation_id": getattr(record, 'correlation_id', 'N/A'),
      "user_id": getattr(record, 'user_id', 'anonymous'),
      **getattr(record, 'extra_context', {})
    }
    return json.dumps(log_entry)
Note how extra_context is merged so middleware can inject correlation_id and user_id for every record.
Operational notes
  • Ensure the formatter is attached to your handler and handlers are added to the app logger.
  • Generate or propagate correlation_id at the entry point and add it to logger context.
  • Avoid logging sensitive fields; mask them before they reach the formatter.
Misconception

Adding a JSON formatter without injecting request context yields structured logs but limited traceability; include correlation and user fields for full value.
