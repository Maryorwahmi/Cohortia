Terminal Demo

Commands

# Terminal 1: run backend
python backend_service.py

# Terminal 2: run frontend
python frontend_service.py

# Terminal 3: trigger request
curl "http://localhost:5000/hello?name=Cohortia"
Expected Console Output (example)
# frontend console prints span
Span: name=hello_frontend_endpoint trace_id=0xabc123 parent_id=0xdef456
# backend console prints child span with same trace
Span: name=greet_backend_endpoint trace_id=0xabc123 parent_id=0xghi789

# The important check: trace_id matches across services and parent_id shows linkage
If trace_id differs, inspect propagator configuration and outgoing header injection. If spans are missing, verify exporters and that auto-instrumentation is active for Flask and requests.
