How it works

Trace lifecycle summary

1. Request arrives and root span created
2. Downstream calls inherit context via headers
3. Each service emits spans with attributes
4. Spans exported to tracing backend
5. Backend reconstructs and visualizes the trace
Practical checks
  • Confirm trace_id and parent_span_id appear on outgoing requests.
  • Verify all services export spans to a common backend or collector.
  • Check that proxies or gateways forward tracing headers intact.
  • Sample traces when volume is high, but ensure representative sampling for debugging.
Key Takeaway

A complete trace requires consistent instrumentation and faithful propagation. Without both, the backend cannot reconstruct the journey.
