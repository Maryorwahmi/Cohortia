Core Concept

Trace and Span

A trace groups spans that represent operations. Spans record timing and attributes and link via parent-child relationships.

Trace: unique trace ID ties all related spans for one request.
Span: name, start/end, attributes, span ID, parent span ID.
Root span: initial entry point. Child span: downstream operation.
Definition — Example

Login request trace

Root span: api-gateway.handleLogin — duration 250ms
Child span: auth-service.validateToken — 50ms
Child span: db.queryUser — 120ms
Child span: external-idp.call — 60ms
Key Takeaway

A trace gives the complete timeline. Spans expose which operation consumed time so you can target optimizations.
