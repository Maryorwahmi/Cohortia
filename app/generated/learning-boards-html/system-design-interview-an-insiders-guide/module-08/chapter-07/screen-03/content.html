Practice & Tools

This screen lists the practical skills and toolset you'll use during the hands-on activity.

01
Instrument Flask services
Add OpenTelemetry SDK, FlaskInstrumentor, and RequestsInstrumentor so incoming and outgoing HTTP calls become spans.
VERIFIED COMPETENCY MILESTONE
02
Verify context propagation
Confirm trace IDs and parent span IDs are carried as headers or message metadata so the trace remains continuous.
VERIFIED COMPETENCY MILESTONE
03
Observe console and backend
Use a simple console exporter or a tracing backend like Jaeger to visualize reconstructed traces and timings.
VERIFIED COMPETENCY MILESTONE
04
Interpret traces
Compare span durations and parent-child relationships to locate the primary bottleneck in a request path.
VERIFIED COMPETENCY MILESTONE
