Learning Objectives

These objectives pair what you should know with a practical skill you can perform when operating or instrumenting microservices.

01
Explain tracing problems
Describe why distributed systems obscure request flow and how tracing restores end-to-end visibility. This matters because it reduces guesswork when debugging latent or intermittent failures.
VERIFIED COMPETENCY MILESTONE
02
Define traces and spans
State the difference between a trace and a span, including root and child spans, and how attributes provide contextual metadata for analysis.
VERIFIED COMPETENCY MILESTONE
03
Implement context propagation
Instrument code so trace IDs and span IDs propagate across HTTP or messaging boundaries to keep traces continuous.
VERIFIED COMPETENCY MILESTONE
04
Use OpenTelemetry and backends
Set up OpenTelemetry instrumentation and export to a tracing backend like Jaeger or Zipkin to visualize reconstructed traces and analyze latency.
VERIFIED COMPETENCY MILESTONE
