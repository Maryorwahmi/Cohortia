Comparison

OpenTelemetry vs Backends

OpenTelemetry: specification and SDKs for instrumenting apps and exporting telemetry.
Jaeger / Zipkin: collect, store, and visualize spans so you can inspect traces and timings.
Cloud tracing: managed offerings that integrate with platform metrics and logs.
When to choose
  • Use OpenTelemetry for vendor-neutral instrumentation and portability.
  • Run Jaeger/Zipkin when you need an open-source backend for visualization and control over retention.
  • Use managed tracing when you prefer integrated platform services over managing storage and UI.
Practical tip

Instrument with OpenTelemetry, start with a simple console exporter, then plug in Jaeger or a managed backend when you need visualization and search.
