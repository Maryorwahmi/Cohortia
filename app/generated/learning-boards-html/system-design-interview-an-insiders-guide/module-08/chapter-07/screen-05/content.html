Definition

Span attributes & relationships

Attributes provide structured context. Parent-child links show causality and let you compute aggregate timing.

Key attributes: http.method, http.route, db.statement, status_code, error
Identifiers: trace_id ties spans; span_id identifies the operation; parent_span_id links to the parent
Performance tip: avoid high-cardinality attributes like raw user IDs unless masked or sampled.
Hierarchy

Parent → Child example

OrderService.createOrder (trace_id=abc)
Child: PaymentService.processPayment — parent_span_id points to the createOrder span
Child: InventoryService.reserveItems — another child; both children explain where time is spent
Common mistake

Treating every attribute as free. High-cardinality attributes make querying and storage expensive and can hide the signal you need.
