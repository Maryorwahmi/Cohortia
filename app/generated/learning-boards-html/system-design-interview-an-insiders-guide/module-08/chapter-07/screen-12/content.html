Safety Notes

Mistakes and concerns

  • Incomplete instrumentation fragments traces — instrument all critical services.
  • Broken propagation in async systems breaks continuity — include context in message headers.
  • High-cardinality attributes increase costs — avoid unbounded values like full user identifiers.
  • Performance overhead exists — measure and apply sampling strategies.
  • Privacy: redact PII in span attributes and names before exporting.
Common-Mistake
Logging sensitive attributes in spans
Traces are searchable and retained; any attribute with PII should be masked or removed to prevent exposure. Treat tracing attributes like logs when it comes to privacy.
Pro tip

Start with a console exporter to validate propagation. Then add sampling and a backend once you confirm instrumentation and header preservation.
