Process Flow

Context propagation steps

1. Source creates trace_id and root span
2. Source injects headers (traceparent / B3) into outgoing request
3. Receiver extracts headers and starts child span linked to parent
Examples
Synchronous HTTP
Inject trace headers on the outgoing HTTP call; downstream service extracts them and creates a child span.
Asynchronous messaging
Include trace context in message headers or payload metadata so the consumer continues the trace when processing the message.
Common pitfall

Missing header injection or extraction breaks traces and produces fragmented, hard-to-interpret telemetry.
