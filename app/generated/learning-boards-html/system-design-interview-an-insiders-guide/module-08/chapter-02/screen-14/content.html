Key Concepts — Core Set

High Availability
System stays operational through failures, minimizing downtime.
Single Point of Failure
A component whose failure stops the system; identify and eliminate it.
Redundancy
Duplicate components or data so failures can be covered by spares.
Summary takeaway
Always pair redundancy with detection and automated failover. The right combination depends on acceptable downtime and operational complexity.
