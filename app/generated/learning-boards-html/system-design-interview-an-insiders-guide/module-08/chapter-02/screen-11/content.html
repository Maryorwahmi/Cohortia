Definition

Synchronous vs Asynchronous

Understand the consistency-latency trade-off to choose replication mode by data criticality.

Synchronous
Write acknowledged only after replicas confirm; strong consistency, higher latency.
Asynchronous
Primary acknowledges write immediately; lower latency but potential for data loss on failure.
When to choose
Synchronous for financial or critical operations with zero tolerance for loss; asynchronous for high-throughput, latency-sensitive workloads.
Common-mistake

Enabling synchronous replication across distant regions without accounting for network latency, which can dramatically slow writes.

Key Takeaway

Map data to RPO requirements and choose replication mode so critical data uses stronger durability while less-critical data favors performance.
