Process Flow

Load Balancer Choices

Pick L4 or L7 and an algorithm based on connection patterns and session needs.

Algorithms
Round-robin, least-connections, IP-hash. Match algorithm to request type and connection lifetime.
Health checks
Use readiness and liveness checks to ensure only healthy backends receive traffic. Include dependency verification when necessary.
Example
An API gateway uses least-connections because requests are long-lived, while a static content service can use round-robin for even distribution.
Common-mistake

Using health checks that only verify network reachability, not application readiness. This sends traffic to servers that are not ready to serve requests.

Key Takeaway

Align load-balancer behavior and health checks with how your application handles connections and dependencies to maintain availability.
