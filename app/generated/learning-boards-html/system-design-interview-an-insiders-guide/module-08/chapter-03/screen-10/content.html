Module 8 › Chapter 8.3 › Failover Checklist
Step-by-step
  1. Detect: health checks and multi-source alarms.
  2. Confirm: cross-check and avoid false positives.
  3. Initiate: trigger runbook with clear roles.
  4. Prepare data: verify replication and promote if needed.
  5. Activate infra: scale services and run smoke tests.
  6. Reroute traffic: update global load balancer or DNS.
  7. Validate: run end-to-end checks and user flows.
  8. Postmortem: document lessons and update runbook.
Operational tips
  • Define clear failover criteria to reduce accidental triggers.
  • Automate scaling and promotion steps where possible to meet RTO.
  • Include rollback criteria if failover produces unacceptable side effects.
