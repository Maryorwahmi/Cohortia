Module 08 › Chapter 8.1 › Service Level Objective (SLO)
What is an SLO?
An internal target on an SLI, defined with a value and a measurement window to drive alerts and prioritization.
Example
"99% of checkout requests succeed within 300 ms over a 30-day rolling window." This SLO shapes cadence for capacity and reliability work.
Decision points
  • Value: percentage or percentile you target (e.g., 99%, p95).
  • Window: rolling duration for evaluation (days, weeks, months).
  • Inclusions: what counts as a request and what responses are classified as success.
Why SLOs matter
They create actionable thresholds for alerts and help teams decide when to invest in reliability vs. new features by tracking error budgets tied to the SLO.
Misconception
An SLO is not an SLA. SLOs are internal guideposts; SLAs are promises that may include penalties if missed.
Key Takeaway

Set SLOs that reflect user expectations and system capability, and be explicit about measurement rules so responses are reliable.
