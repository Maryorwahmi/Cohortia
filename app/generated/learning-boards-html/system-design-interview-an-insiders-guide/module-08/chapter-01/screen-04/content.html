Module 08 › Chapter 8.1 › Service Level Indicator (SLI)
Definition
An SLI is a precise numeric measurement that reflects user-visible behavior. It must be consistently measurable and directly tied to a user journey.
How to choose an SLI
  • Pick user-centric events: API responses, checkout success, login completion.
  • Define inclusions/exclusions: which status codes or retries count as success.
  • Prefer edge or gateway measurements for end-to-end visibility.
Concrete example
SLI: Fraction of login requests completing with 200 OK within 300 ms, measured at the API gateway, counting first attempt only.
Why not internal metrics?

CPU or memory usage are important for operations but they don’t directly say whether a user could complete a purchase or sign in, so they are poor SLIs alone. Use them for diagnostics but not as primary service quality indicators.

Key Takeaway

SLIs must map to user impact and be computed consistently so teams can trust alerts and decisions driven by them.
