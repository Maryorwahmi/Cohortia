Verified Competency Milestone
01
Explain observability
Define observability and contrast it with monitoring so you can ask arbitrary questions about system state.
02
Identify the three pillars
Name metrics, logs, and traces and state the role each plays in triage and diagnosis.
03
Use tools effectively
Recognize tools commonly used for metrics, logs, and tracing and why each suits its purpose.
04
Instrument with purpose
Plan metrics, structured logs and traces to give actionable insights while controlling cost and noise.
VERIFIED COMPETENCY MILESTONE
Expanded Objectives
Explain trade-offs
Describe costs of high-cardinality metrics and log volume, and explain sampling strategies for traces.
Debug with the triad
Given a metric spike, outline how you would use traces and logs to locate and explain the root cause.
