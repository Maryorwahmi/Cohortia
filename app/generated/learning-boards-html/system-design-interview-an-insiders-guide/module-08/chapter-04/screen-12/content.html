Module 8 › Chapter 8.4 › Key Concepts
Observability
Inferring internal state from external outputs so you can ask ad-hoc questions about system behavior.
Metrics
Numerical time-series for trends, alerting, and health overview; watch label cardinality.
Logs & Traces
Logs explain what happened for individual events; traces show request journeys and bottlenecks across services.
Summary
When a metric alerts, use a trace to narrow which service or span is problematic, then inspect logs for detailed context to fix the root cause.
