Module 8 › Chapter 8.4 › Hands-on Activity
Task breakdown
  1. Add Prometheus counters: registration_success_total and registration_failure_total.
  2. Record request latency with a gauge or histogram labeled by endpoint.
  3. Emit structured JSON logs with event, status, and correlation id.
  4. Outline tracing spans for the request and child operations.
Verify by making test requests and checking the metrics endpoint, the log aggregator, and trace viewer for span relationships.

Key Takeaway

Work incrementally: start with a small set of actionable metrics, consistent structured logs, and basic spans to link the pieces together.
