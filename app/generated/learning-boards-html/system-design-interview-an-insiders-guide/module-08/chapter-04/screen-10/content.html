Module 8 › Chapter 8.4 › Mistakes & Trade-offs
Common Mistakes
  • Collecting everything without intent, creating observability noise.
  • High-cardinality labels on high-frequency metrics that explode time-series.
  • Not propagating correlation ids, making traces and logs hard to link.
  • Sampling without strategy so rare failures are lost.
Avoid these by planning instrumentation around the questions you need to answer, not raw curiosity. Instrument incrementally and evaluate cost versus benefit.
Trade-off examples
Cardinality cost
High unique label values create many time-series and increase storage and query costs.
Trace sampling
Sample more during incidents or capture a percentage of all traces for baseline analytics.
Pro tip

Start with a core set of metrics and structured logs, add trace sampling gradually, and refine when incidents demand deeper data.
