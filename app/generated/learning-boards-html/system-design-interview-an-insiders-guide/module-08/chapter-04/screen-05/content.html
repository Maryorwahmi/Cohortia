Module 8 › Chapter 8.4 › Metrics
Core Idea

Counters & Gauges

Counters count events over time. Gauges measure instantaneous values like CPU or memory usage. Use aggregation to make queries fast and dashboards readable.

When to use metrics
For trends, service-level alerts, and capacity planning.
Common mistake
Adding user-level labels to many metrics creates high cardinality and costly storage without proportionate benefit.
Example
Checkout API latency
A Grafana-style graph shows average response time per minute. When the metric spikes, alerts fire and you start diagnosis.
Design tips
  • Pick stable, actionable dimensions for labels.
  • Prefer aggregation for dashboards and keep raw high-cardinality metrics rare.
  • Set appropriate windows for averages and percentiles.
Key Takeaway

Metrics detect and summarize; design them to surface meaningful trends without incurring runaway cost.
