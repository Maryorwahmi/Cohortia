Module 8 › Chapter 8.4 › Using the Three Pillars
Process

Detect → Locate → Explain

Detect (Metrics)
Use aggregated metrics to trigger alerts for spikes or drops.
Locate (Traces)
Follow a trace to see which service or span added latency or returned errors.
Explain (Logs)
Inspect structured logs for the failing service to get error messages and request context.
Scenario
User Service 5xx spike
Metrics show HTTP 5xx up; traces reveal an upstream dependency returns null; logs show a NullPointerException while parsing. The triad quickly points to the dependency as the cause.
Check your understanding
Which pillar identifies the affected user IDs for the failing requests? (Answer: Logs, when correlated with trace ids.)
Key Takeaway

Use metrics to find problems fast, traces to narrow the scope, and logs to explain the exact cause.
