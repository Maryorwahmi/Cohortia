Core Idea

Spans & Parent-Child Links

Each span records an operation's start, duration, and attributes. Parent-child relationships let you see the causal chain and measure where time is spent.

Why traces help
They localize latency and failures to a specific service or operation in the request path.
Common mistake
Sampled traces may miss rare failures; choose sampling appropriately when root cause investigation requires rare events.
Concrete Example
Checkout request trace
A trace shows gateway→auth→profile→order→db spans with timings. If the order service span is long, traces point you where to look next.
Tools
Jaeger, Zipkin, OpenTelemetry, AWS X-Ray are common choices for collecting and visualizing traces.
Key Takeaway

Traces show the how and where of latency and errors, making them essential for microservices diagnosis.
