Module 8 › Chapter 8.8 › Probe Types
Type comparison
HTTP GET
Best for web services. Example: GET /healthz returns 200 ok.
TCP Socket
Use for non-HTTP listeners. Success = port accepts connection.
Exec Command
Runs inside container. Use for custom, fast checks of internal state.
Choose the simplest probe that truthfully reflects the condition you care about. Keep probes fast to avoid timeouts that confuse orchestration.
Example scenarios
  • HTTP: REST API with a lightweight /healthz returning 200 for event loop alive.
  • TCP: gRPC server exposing a listening port; TCP success indicates listener present.
  • Exec: container writes a local file when ready; exec cat file returns 0 if present.
Pro Tip

When using exec probes, ensure the command exits quickly and cannot block; otherwise the probe itself can create resource pressure.
