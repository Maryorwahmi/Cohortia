Module 8 › Chapter 8.8 › Kubernetes Probes
Configuration fields
  • initialDelaySeconds: wait before first check.
  • periodSeconds: how often to check.
  • timeoutSeconds: probe timeout.
  • failureThreshold: consecutive failures required to act.
Manifest snippet
# liveness: simple HTTP check
livenessProbe:
  httpGet:
    path: /healthz
    port: 8080
  initialDelaySeconds: 10
  periodSeconds: 5
  timeoutSeconds: 2
  failureThreshold: 3

# readiness: dependency-aware check
readinessProbe:
  httpGet:
    path: /readyz
    port: 8080
  initialDelaySeconds: 15
  periodSeconds: 10
  timeoutSeconds: 3
  failureThreshold: 2
This example uses a faster liveness cadence and a longer readiness initial delay to give dependencies time to become available.
