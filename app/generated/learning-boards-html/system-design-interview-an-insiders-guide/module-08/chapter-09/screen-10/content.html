Resource exhaustion experiments
Pressure-test CPU, memory, and I/O to validate graceful degradation and autoscaling.
Common methods
  • CPU hogs to simulate heavy computation.
  • Memory allocation to test OOM handling and limits.
  • Disk I/O saturation to test queueing and timeouts.
What to watch
  • Latency percentiles and tail behavior.
  • Autoscaler reaction time and scaling limits.
  • Retries causing increased downstream load.
Pitfall
Assuming autoscaling alone solves resource issues; observe warm-up and scale lag.
Analogy
Like pressurizing a single engine to ensure the plane still flies safely on others.
Key Takeaway

Tune resource limits, autoscaling, and graceful degradation after measured resource tests.
