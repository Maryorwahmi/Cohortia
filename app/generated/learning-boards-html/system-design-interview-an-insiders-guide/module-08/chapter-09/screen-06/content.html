Five principles of Chaos Engineering
A disciplined process to design and run experiments safely.
01
Hypothesize steady-state
Define the metric you will watch.
02
Vary events
Inject realistic faults.
03
Run in production-like
Start small, increase fidelity.
04
Automate
Make tests repeatable and continuous.
05
Minimize blast radius
Target small subsets and have rollback.
Example
Run a 30-second network delay on 10% of pods, measure P99 and error rate, then stop and analyze.
Common pitfall
Automating experiments without safe defaults or active monitoring is dangerous.
Key Takeaway

Follow the hypothesis → inject → observe loop and automate only with safeguards.
