Learning Objectives
Build practical skills to run safe, measurable chaos experiments.
01
Form a steady-state hypothesis
Define a measurable baseline for normal behavior so experiments have a clear success condition and stopping criteria.
Mnemonic: baseline = measurable output
VERIFIED COMPETENCY MILESTONE
02
Vary realistic failure modes
Choose experiments like pod termination or network delay that mirror production faults you care about.
Mnemonic: mirror production faults
VERIFIED COMPETENCY MILESTONE
03
Minimize blast radius
Target a small subset of users or pods, automate rollback, and keep experiments short and observable.
Mnemonic: small, observable, reversible
VERIFIED COMPETENCY MILESTONE
04
Integrate experiments and tooling
Use tools like Chaos Mesh, LitmusChaos, or Gremlin and integrate tests into CI/CD when appropriate for ongoing validation.
Mnemonic: tool + automation = continuous confidence
VERIFIED COMPETENCY MILESTONE
