Network latency and packet loss
Test degraded connectivity to tune timeouts and fallbacks.
When to use it
  • External API calls that may slow during peak traffic.
  • Cross-region calls with variable latency.
  • Database calls sensitive to network jitter.
What to measure
  • P99 latency and tail latency shifts.
  • Error rate increase and retry counts.
  • Queue lengths and thread pool saturation.
Pro tip
Pair latency injection with realistic load to reveal queueing effects.
Analogy
Like adding traffic lights on a highway to see how congestion forms upstream.
Key Takeaway

Tune timeouts and circuit breakers using realistic latency experiments under production-like load.
