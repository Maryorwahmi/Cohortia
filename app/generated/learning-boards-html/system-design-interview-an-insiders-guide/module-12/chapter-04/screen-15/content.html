Schema
Map the hottest queries to keys and indexes; document the reason for each denormalization.
API
Use correct HTTP verbs, idempotency for safe retries, and a consistent error format.
Auth
Authenticate at the edge and authorize each operation; keep ownership checks explicit.
Final Thought

When in doubt, write the query first, then choose the storage and API shape that makes that query simple and fast.
