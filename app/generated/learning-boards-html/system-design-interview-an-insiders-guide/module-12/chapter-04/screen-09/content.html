Module 12 › Chapter 12.4 › Example REST Endpoints
Endpoint list
GET /users/{user_id}           -> Get a user's profile
POST /users                    -> Create a new user
PUT /users/{user_id}           -> Update a user's profile
DELETE /users/{user_id}        -> Delete a user

POST /posts                    -> Create a new post
GET /posts                     -> List posts (paginated, sorted)
GET /posts/{post_id}           -> Get a specific post
PUT /posts/{post_id}           -> Update a post
DELETE /posts/{post_id}        -> Delete a post
GET /users/{user_id}/posts     -> Get all posts by a user

POST /tags                     -> Create a tag
GET /tags                      -> List tags
GET /tags/{tag_id}/posts       -> Posts for a tag
Sample curl commands
# Create a user
curl -X POST https://api.example.com/v1/users \
  -H "Content-Type: application/json" \
  -d '{"username":"alice","email":"alice@example.com"}'

# Get recent posts for a user
curl https://api.example.com/v1/users/1234/posts?limit=5

# Create a post (requires auth token)
curl -X POST https://api.example.com/v1/posts \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"title":"Hello","content":"My post body"}'
Note how methods and status codes convey intent. Document which endpoints require the authenticated user to be the resource owner for write and delete operations.
