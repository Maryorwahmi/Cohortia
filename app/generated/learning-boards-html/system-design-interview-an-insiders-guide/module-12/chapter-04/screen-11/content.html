Module 12 › Chapter 12.4 › When to Use GraphQL
GraphQL query example
query GetUserAndPosts($userId: ID!) {
  user(id: $userId) {
    id
    username
    posts {
      id
      content
      createdAt
    }
  }
}
Trade-offs and considerations
  • Benefit: single request for nested data avoids multiple REST calls.
  • Cost: more work on the server for resolvers, validation, and per-field auth.
  • Caching: response-level caches are harder; consider persisted queries and query complexity limits.
Key Takeaway

Choose GraphQL when client flexibility and reduced round trips outweigh server complexity and caching challenges.
