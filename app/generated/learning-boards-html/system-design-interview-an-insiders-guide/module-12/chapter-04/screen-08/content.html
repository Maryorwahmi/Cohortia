Module 12 › Chapter 12.4 › RESTful API Principles
Core REST principles
  • Resources are nouns: /users, /posts/{id}.
  • Use HTTP methods semantically: GET, POST, PUT/PATCH, DELETE.
  • Stateless requests simplify scaling and caching.
Status codes and idempotency
Use 200 for OK, 201 for created, 400 for bad request, 404 for not found, and 500 for server errors. Design idempotent endpoints for safe retries and document expectations clearly.
Key Takeaway

Follow HTTP semantics and document idempotency and versioning to keep clients and servers aligned as the API evolves.
