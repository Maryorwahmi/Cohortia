Process Flow
Structured questioning
1. Core functionality

Identify primary user actions and target users.

2. Scale

Get DAU, peak QPS, data volume, and growth rates.

3. Latency

Ask for acceptable response times in milliseconds for key flows.

4. Availability & Durability

Clarify uptime targets and data loss tolerance.

5. Consistency

Which operations require strong guarantees?

6. Scope & Integrations

Confirm clients, third-party services and admin needs.

Concrete example

Prompt: design a photo-sharing service. Ask: "What are the primary photo interactions?" then "What's the expected peak photo uploads per second?" and "What is the acceptable time for a new photo to appear in followers' feeds?"

Common mistake

Only asking functional questions or only scale questions. Both are required to guide architecture.

Key Takeaway

Use the sequence as a checklist in the first two minutes to avoid missed constraints.
