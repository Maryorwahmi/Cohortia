Cache layers

Client → CDN → App → Distributed

Client-side
Browser caches static assets and can cache API responses using HTTP headers.
CDN
Geographically distributed caches reduce latency for static and some dynamic content, relieving origin servers.
Application memory
Per-node caches are fast but can become inconsistent across instances.
Distributed cache
Centralized stores like Redis provide shared hot data for horizontally scaled services and ease invalidation logic.
Example
Cache user profile JSON in Redis with a one-hour TTL and evict on profile update events so reads are under 100ms while writes trigger invalidation.
Common mistake

Caching highly dynamic or sensitive data without invalidation leads to stale or insecure results.
