Definition

Scalability and performance explained

Scalability is about capacity growth; performance is about latency and throughput. Treat them as distinct design goals and state both in proposals.

Concrete example
A single large server can be fast until concurrency rises; adding nodes spreads load but does not remove inefficient queries.
Common misconception
Scaling out is not a substitute for profiling and removing hotspots. Always measure before adding capacity.
Visual comparison
Vertical scaling
Add CPU, RAM to a single machine. Simple but limited and can be a single point of failure.
Horizontal scaling
Add more servers behind a load balancer. Enables elasticity and fault tolerance but requires coordination across nodes.
Key Takeaway

Define both capacity and latency goals. Profile to find hotspots, then pick scaling and caching strategies that address root causes.
