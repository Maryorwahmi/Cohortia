Learning Objectives

A Bloom progression to measure mastery

Learn → Understand → Apply → Master
01
Scaling modes
Explain vertical vs horizontal scaling and when each applies. Verified competency milestone: justify a scaling choice in a design interview.
VERIFIED COMPETENCY MILESTONE
02
Identify bottlenecks
Detect common system limits and propose mitigation plans. Milestone: list top three bottlenecks and solutions for a given traffic profile.
VERIFIED COMPETENCY MILESTONE
03
Caching strategies
Design multi-layer caches and invalidation rules. Milestone: propose a cache layout for a read-heavy service with invalidation rules.
VERIFIED COMPETENCY MILESTONE
04
DB scaling & async
Describe replication, sharding, connection pooling and message queues. Milestone: sketch a sharded read/write pattern and queue-based worker pipeline.
VERIFIED COMPETENCY MILESTONE

Progress checklist

  • Explain scale up vs scale out with limits and failure modes.
  • Design a cache invalidation strategy for user profile updates.
  • Propose a sharding key and explain hot-spot risks.
  • Use message queues to decouple long-running work from request paths.
