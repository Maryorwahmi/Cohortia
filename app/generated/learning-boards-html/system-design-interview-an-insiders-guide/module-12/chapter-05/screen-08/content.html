Cache-first read pattern

import redis

# Connect to Redis
r = redis.Redis(host='localhost', port=6379, db=0)

def get_user_profile(user_id):
  # Try to fetch from cache
  cached_profile = r.get(f"user:{user_id}")
  if cached_profile:
    print("Fetched from cache!")
    return json.loads(cached_profile)

  # If not in cache, fetch from database
  profile_data = fetch_from_database(user_id)  # Assume this function exists
  if profile_data:
    # Store in cache for 1 hour (3600 seconds)
    r.setex(f"user:{user_id}", 3600, json.dumps(profile_data))
    print("Fetched from DB, cached.")
    return profile_data
  return None
Note: escape sensitive fields and use explicit invalidation on profile updates to avoid serving stale or unauthorized data.
Invalidation strategies
  • Delete the cache key on write success.
  • Use a version number in the cached value and check it after writes.
  • Short TTLs for frequently changing data to reduce stale window.
Key Takeaway

Use distributed cache for shared hot data and always design explicit invalidation for writes.
