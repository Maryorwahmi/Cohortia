Module 12 › Chapter 12.5 › Key Concepts
Vertical / Horizontal
Scale up adds resources; scale out adds nodes and resilience.
Caching Layers
Client, CDN, app-memory, and distributed caches reduce latency when invalidation is managed.
Replication
Leader-follower replication offloads reads but requires monitoring for lag.
Sharding
Partition data to distribute writes and reads; choose keys to avoid hot spots.
Message Queue
Decouple heavy work from requests; make workers idempotent and monitor backlog.
Monitoring
Track latency percentiles, cache hit rate, replication lag, and queue length to validate changes.
Keep these concise patterns ready to explain with examples and metrics when designing systems under load.
