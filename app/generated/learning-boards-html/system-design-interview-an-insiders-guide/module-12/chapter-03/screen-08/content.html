Process Flow

Where and what to cache

Cache placements
  • CDN for static assets
  • Client-side cache for short-lived UI assets
  • Application-level / distributed cache for hot reads
Invalidation strategies
TTL-based eviction, explicit invalidation on writes, or write-through depending on consistency needs.
Concrete example
For a product catalog: product metadata cached in Redis with a TTL of a few minutes. Images served from a CDN. On product update, evict the cache and push the updated metadata to warm caches if needed.
Common mistake
Caching write-heavy data without an invalidation plan causes inconsistent user views.
Pro tip
Document TTLs and eviction triggers on your sketch so reviewers know you considered staleness.
Key Takeaway

Place caches where they reduce latency most and always state invalidation rules.
