Module 12 › Chapter 12.3 › CDN
Definition

Edge caching for static content

A CDN caches static files globally to serve users from nearby edge locations, improving latency and reducing origin bandwidth.

When to include a CDN
If you serve images, video or large static assets to a global audience, add a CDN to your sketch.
Access control
Use signed URLs or cache-control headers to manage caching and private content.
Concrete example
Serve user-uploaded photos from object storage and front them with a CDN. The CDN caches popular images and reduces repeated origin reads during traffic spikes.
Common mistake
Assuming a CDN replaces origin durability — it caches, but origin storage remains authoritative.
Pro tip
Annotate which endpoints use the CDN and how you control cache lifetime on the sketch.
Key Takeaway

Add a CDN when static assets or global latency matter, and state caching policies on the diagram.
