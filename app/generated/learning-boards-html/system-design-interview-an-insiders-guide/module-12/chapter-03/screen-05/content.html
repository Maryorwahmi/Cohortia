Architecture

Two-layer entry pattern

Separate infrastructure-level load distribution from application-level request handling to scale and secure each layer independently.

Load Balancer
Handles TLS termination, health checks and distributes traffic across instances for availability.
API Gateway
Central entry for auth, rate limiting, logging and routing to backend services.
Example flow

Client → Load Balancer → API Gateway → Appropriate service. The gateway enforces quotas and authenticates requests before routing.

Trade-offs and decisions
  • Combining layers simplifies topology but couples auth and infra concerns.
  • Separating layers allows independent scaling and clearer failure domains.
  • Use a gateway when you need routing rules, versioning and cross-cutting policies.
Common mistake
Putting complex business logic in the gateway instead of keeping it stateless and focused on routing and policies.
Pro tip
Declare which policies belong to the gateway and which belong to downstream services in your sketch.
