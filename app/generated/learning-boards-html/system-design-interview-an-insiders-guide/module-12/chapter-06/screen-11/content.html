Module 12 › Chapter 12.6 › Bulkheads & Degradation
Bulkhead pattern
Reserve separate resource pools for independent components or external calls to limit blast radius.
  • Separate thread or connection pools for different downstream services.
  • Rate-limit expensive jobs so they cannot starve user traffic.
  • Combine with circuit breakers so failing services don’t consume headroom.
Graceful degradation example
If write paths are failing, offer read-only views and cached content rather than full functionality, keeping the user experience useful while protecting core operations.
Common mistake
Creating too many isolated pools without planning capacity leads to wasted resources and complexity.
Key Takeaway

Use bulkheads to contain failures and plan fallbacks that preserve essential user experience under stress.
