Retry pattern
Retry with exponential backoff to reduce load on failing dependencies while still attempting recovery.
import requests
import time

def call_service_with_retry(url, max_retries=3, initial_delay=1):
  for i in range(max_retries):
    try:
      response = requests.get(url, timeout=5)
      response.raise_for_status()
      return response.json()
    except requests.exceptions.RequestException as e:
      print(f"Request failed (attempt {i+1}/{max_retries}): {e}")
      if i < max_retries - 1:
        sleep_time = initial_delay * (2 ** i)
        print(f"Retrying in {sleep_time} seconds...")
        time.sleep(sleep_time)
      else:
        raise
Pro tip
Add randomized jitter to backoff to avoid synchronized retries across many clients.
Combine with
Circuit breaker pattern to fail fast after repeated errors, protecting resources.
Concrete scenario
A payment service calling a bank API can use retries with backoff for transient timeouts, while a circuit breaker prevents long queues when the bank is down.
Key Takeaway

Backoff reduces harm during outages; pair with jitter and circuit breakers to be robust at scale.
