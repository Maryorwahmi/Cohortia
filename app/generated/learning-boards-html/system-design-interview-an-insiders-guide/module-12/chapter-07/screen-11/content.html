Module 12 › Chapter 12.7 › Structured Logs
What to include
  • Timestamp, level, service, method, path, status, duration_ms.
  • Correlation ids such as request_id or trace_id for cross-service linking.
  • User or resource identifiers when relevant, avoiding sensitive fields.
Centralize logs to a system that supports indexing and retention, and protect access to logs since they can contain sensitive information.
Example structured log entry
{
  "timestamp": "2023-10-27T14:30:00Z",
  "level": "INFO",
  "service": "user-service",
  "method": "GET",
  "path": "/users/123",
  "status": 200,
  "duration_ms": 50,
  "user_id": "user_abc",
  "message": "User profile fetched successfully"
}
This JSON shows a compact, consistent schema that supports search and correlation across services.
