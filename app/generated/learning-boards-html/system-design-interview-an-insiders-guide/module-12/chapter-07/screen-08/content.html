Layered protections
  1. Edge: DDoS protection absorbs traffic spikes and filters known attack patterns.
  2. WAF: Inspect and block web-level exploits like SQL injection and XSS.
  3. API Gateway: Enforce authentication, rate limiting, and request validation.
  4. Internal: Security groups, service mesh policies, and IAM roles implement least privilege.
Concrete example
Route public traffic through a DDoS service and WAF, then to an API gateway that checks JWTs and applies scopes before traffic reaches internal services protected by security groups and IAM roles.
Checklist
  • Remove open all ports rules; restrict by need.
  • Enable WAF rulesets and tune them to reduce false positives.
  • Apply rate limits and quotas at gateway to mitigate abuse.
Pro tip

Test WAF and firewall rules in a staging environment to avoid disrupting legitimate traffic when rules are too strict.
