Module 12 › Chapter 12.7 › Payment Service Design
Security design checklist
  • Authorization: RBAC with roles Admin and CustomerService enforced at API gateway and service layer.
  • Encryption: TLS for APIs and encryption at rest for the database; tokenize card data.
  • Secrets: store keys in a vault and plan key rotation and revocation processes.
Monitoring design checklist
  • Logging: structured logs with request_id and redaction of sensitive fields; centralize to a secure index.
  • Metrics: expose RED metrics per endpoint and USE metrics for resources.
  • Alerting: error_rate > 5% for 1 minute → Critical → PagerDuty with runbook.
