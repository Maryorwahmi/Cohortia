RED method for services
  • Rate: requests per second for each endpoint.
  • Errors: fraction of failed requests.
  • Duration: latency percentiles such as p95 or p99.
USE for resources: track utilization, saturation, and errors to monitor CPU, memory, disk, and network.
Alerting practice
Define thresholds, duration windows, severity levels, and notification channels. Example alert: error_rate > 5% for 1 minute → Critical → PagerDuty.
Avoid alert fatigue
Tune thresholds, use aggregation windows, and create runbooks so alerts are actionable and responders know next steps.
