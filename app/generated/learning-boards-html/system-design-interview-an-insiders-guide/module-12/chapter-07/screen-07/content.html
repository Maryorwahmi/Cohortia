Module 12 › Chapter 12.7 › Data Protection
Encryption patterns
Encryption in transit: Use TLS/HTTPS for all client and service endpoints to prevent eavesdropping.
Encryption at rest: Enable disk and database encryption so stored records remain protected if storage is compromised.
Tokenization/masking: Replace highly sensitive values with tokens and avoid storing raw values or writing them to logs.
Common mistake
Logging plain-text sensitive data or storing keys in source code defeats encryption controls. Use secure secret management and rotate keys regularly.
Concrete scenario
For the Payment Service: always use HTTPS, enable encryption for the database and object storage, redact card numbers in logs, and store token-to-card mappings in a dedicated, auditable vault service.
Key Takeaway

Match protection level to sensitivity and manage keys and tokens outside application code.
