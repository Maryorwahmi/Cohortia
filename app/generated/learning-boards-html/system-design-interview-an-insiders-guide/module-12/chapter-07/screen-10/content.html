Logs
Collect structured logs with fields like timestamp, service, method, path, status, duration_ms, user_id, and request_id. Centralize logs for search and audit. Use them for security investigations and postmortems.
Store logs in a central system that supports indexing and retention policies.
Mask or redact sensitive fields before storing logs.
Metrics & Tracing
Collect metrics using the RED method for service requests and USE for resource health. Use tracing to follow single requests and identify latency hotspots or error propagation across services.
RED example: monitor rate, errors, and duration for each service endpoint.
Tracing example: instrument requests with a trace id so you can find the path of a failing transaction through microservices.
Practical tip
Instrument from the start. It is much harder to add meaningful traces and structured logs after a system is in production.
