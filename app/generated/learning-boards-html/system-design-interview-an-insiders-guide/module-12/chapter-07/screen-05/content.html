Module 12 › Chapter 12.7 › Authentication Patterns
Authentication methods
  • User: username/password, MFA, SSO via OAuth 2.0/OpenID Connect.
  • Service: API keys, client certificates, IAM roles for cloud services.
  • Token patterns: JWT for stateless auth; short-lived tokens + refresh tokens reduce exposure.
Misconception
Do not treat tokens as permanent identity. Always validate signature and expiry, and keep secrets out of source code.
Conceptual JWT verification (illustrative)
# Conceptual example of token verification
import jwt
from fastapi import Header, HTTPException

SECRET_KEY = "your-secret-key"

async def verify_token(authorization: str = Header(...)):
  if not authorization or not authorization.startswith("Bearer "):
    raise HTTPException(status_code=401, detail="Invalid authorization header")
  token = authorization.split(" ")[1]
  try:
    payload = jwt.decode(token, SECRET_KEY, algorithms=["HS256"])
    return payload
  except jwt.ExpiredSignatureError:
    raise HTTPException(status_code=401, detail="Token expired")
  except jwt.InvalidTokenError:
    raise HTTPException(status_code=401, detail="Invalid token")
Note: This code is conceptual and shows the verification flow. In production, manage SECRET_KEY outside source and support key rotation.
