High-Level Sketch
Use consistent shapes and labels to show responsibilities and flow.
Standard shapes
  • Box: service or component
  • Cylinder: database or durable store
  • Cloud: external system or third-party API
  • Arrow: data flow and direction
Annotations
Label arrows with request type, frequency, or consistency needs to make the flow meaningful.
Concrete scenario
For a URL shortener, sketch: API → Shortening service → Database and Cache; label the redirect path as high QPS and the write path as lower volume.
Avoid clutter. If asked to dive in, frame the area you will expand before drawing details.
Teaching Visual — Component Cards
API / Gateway
Handles client requests and routes to services.
Service
Business logic, validation, and short-lived state.
Storage / Cache
Durable store for canonical data and cache for read heavy paths.
Key takeaway
Design for boundaries and data contracts rather than internal implementation detail.
