Five-minute script
A concise checklist to guide your spoken walkthrough.
  1. Clarify: Ask read/write ratios, latency, and retention.
  2. Estimate: Quick QPS and storage to justify caching and sharding.
  3. Sketch: Load Balancer → API → Shortening Service → DB + Cache.
  4. Deep Dive: Short code generation/collision handling or cache strategy.
  5. Edge Case: DB outage plan and cache behavior.
  6. Invite feedback: Ask which area to expand.
Teaching Visual — Scenario Cards
