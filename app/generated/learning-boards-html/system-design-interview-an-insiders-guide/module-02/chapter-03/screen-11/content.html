Process Flow
Failover Mechanisms
Detect, promote, redirect — and test each step frequently.
Detection
Health checks, heartbeats, and monitoring with tuned thresholds to balance speed and false positives.
Promotion
Ensure the promoted replica has the latest safe state; use quorum and fencing to avoid split-brain.
Testing and common mistakes
Failover is often untested. Run planned failure drills to verify detection, promotion, and client reconnection behavior.
Split-brain example
If network partitions separate nodes and both become leaders, conflicting writes lead to corruption. Quorum and fencing prevent simultaneous leadership.
