Definition
Fault Tolerance vs Fault Avoidance
Why anticipating failure is the practical approach.
Fault Avoidance
Invest in high-quality parts, exhaustive tests, and conservative change policies to reduce failure rate. Effective at small scale but expensive at web scale.
Fault Tolerance
Design for continued operation when components fail: automate recovery, add redundancy, and accept degraded service modes when needed.
Example
Multiple web servers behind a load balancer continue to serve traffic when one instance crashes.
Practice Question
If transient failures are common, reducing MTTR often yields immediate availability gains compared with marginally higher-quality hardware.
Operational checklist for fault tolerance
  • Redundancy for critical components
  • Health checks and monitoring to detect failures
  • Automated failover and recovery procedures
  • Graceful degradation strategies for partial failures
Misconception
Avoid the false trade-off that fault avoidance eliminates the need for redundancy. Even the highest-quality components fail eventually; redundancy and automation are still needed.
