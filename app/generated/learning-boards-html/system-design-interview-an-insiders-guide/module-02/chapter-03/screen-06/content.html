Comparison
Redundancy Strategies
Match pattern to component state and consistency needs.
Component Replication
Run multiple identical instances so a failed instance does not stop service. Pairs well with load balancers.
Data Replication
Keep multiple data copies across nodes or regions to tolerate storage failures. Replication mode affects consistency and latency.
Active-Passive (Primary-Replica)
Primary handles requests; passive replica is continuously updated and promoted on failure. Simpler consistency for writes but requires reliable failover and detection.
Active-Active
All nodes process requests simultaneously. Good for stateless services; harder for stateful systems since you must reconcile concurrent state updates.
Example
Web servers: active-active. Databases: often active-passive for writes.
Pitfall
Forgetting to discuss data consistency or replication lag when proposing replication strategies.
