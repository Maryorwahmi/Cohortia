Module 2 › Chapter 2.1 › Photo-sharing analysis
Component list
Common distributed components for a modern photo app.
Auth Service
Characteristic: independent failures and low-latency needs. Mitigation: token caches and replicated auth nodes.
Photo Storage
Characteristic: high concurrency and heterogeneity (object store). Mitigation: replication across nodes and regions.
Metadata DB
Characteristic: consistency concerns for queries. Mitigation: versioned updates and read-repair procedures.
Benefit vs Drawback
Benefit: storage and traffic scale independently, supporting massive user growth. Drawback: keeping metadata and objects consistent across replicas requires coordination and operational effort.
Practice prompt
Pick one component and write: its primary failure mode and one mitigation. Example: Storage node disk failure → replication and auto-recovery from healthy replicas.
Key Takeaway
Translating system requirements into component responsibilities exposes where distributed patterns and trade-offs are needed.
