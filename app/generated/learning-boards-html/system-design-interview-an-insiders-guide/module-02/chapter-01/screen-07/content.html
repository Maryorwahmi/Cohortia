Independent failures explained
Nodes fail independently; the whole system should remain functional when parts fail.
Detection
Use health checks and heartbeats to detect failing nodes quickly.
Replication
Keep copies of critical data so another node can serve requests when one fails.
Graceful degradation
Return reduced functionality rather than a full outage when parts are unavailable.
Concrete example: photo retrieval
If an image store is offline, serve cached thumbnails or metadata and show a placeholder for full-resolution images while a background process repairs replicas.
Operational patterns
  • Retries with exponential backoff to avoid rapid repeated failures.
  • Circuit breakers to isolate failing nodes and prevent cascading issues.
  • Monitoring and alerts to surface partial problems quickly.
Common mistake
Treating partial failures as total outages and not providing degraded modes causes poor user experience and fragility.
