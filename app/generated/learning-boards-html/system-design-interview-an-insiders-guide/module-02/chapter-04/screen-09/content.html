Module 2 › Chapter 2.4 › Read-Your-Writes & Monotonic Reads
Read-your-writes
Guarantees the writer sees their own updates immediately. Improves perceived correctness for interactive workflows.
Monotonic reads
Ensures a client's subsequent reads never return older data than previously observed, preventing regressions.
Implementation notes
Often implemented with session metadata, sticky routing to recent replicas, or lightweight vector clocks to route reads appropriately.
Concrete scenario
You post a comment and immediately refresh. With read-your-writes you must see your comment; with monotonic reads you won't be shown an older page that hides your post. These improve UX without forcing global consensus.
Pro tip

Apply these guarantees where they directly affect a single user's workflow — they are a small UX-focused cost with big payoff.
