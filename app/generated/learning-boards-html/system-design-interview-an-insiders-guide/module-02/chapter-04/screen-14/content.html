Module 2 › Chapter 2.4 › Key Concepts
Consistency
Guarantees about what reads return across replicas.
CAP Theorem
You can only have two of C, A, and P during a partition.
Linearizability
Strongest real-time ordering guarantee.
Eventual Consistency
Replicas converge over time if updates stop.
Read-Your-Writes
A client sees its own updates immediately.
CRDTs
Conflict-free types that deterministically merge concurrent updates.
Summary takeaway

Map guarantees to user-visible outcomes: decide per data element whether correctness, latency, or availability is the priority.
