Module 2 › Chapter 2.4 › Causal Consistency
Core idea

If one operation influences another, any client seeing the later operation must see the earlier one. This preserves logical order for related updates.

Example
A reply must never appear without the original comment it references.
Implementation hint
Track causal dependencies with vector clocks or dependency lists; use them to order apply operations without full consensus.
Trade-offs
  • Preserves important user-visible ordering without global real-time coordination.
  • Requires metadata tracking and careful propagation of dependencies.
