Module 3 › Chapter 2.6 › Learning Objectives — Skills
Practice tasks
  • Outline an e‑commerce Saga with local transactions and compensating actions for inventory or payment failures.
  • Trace a 2PC prepare/commit sequence and identify where participants can remain blocked when the coordinator fails.
  • Write an optimistic update using a version column and describe retry logic on conflict.
  • Explain trade‑offs in a short paragraph: why choose Saga over 2PC in a high‑availability service.
Assessment idea
A three-part exercise: diagram a Saga, explain a stuck 2PC case, and show an optimistic SQL update with version checking. Each part demonstrates understanding and practical reasoning.
Mnemonic & Tip
When you explain patterns, always name the trade‑off: consistency vs availability, simplicity vs compensation complexity, locks vs retries.
