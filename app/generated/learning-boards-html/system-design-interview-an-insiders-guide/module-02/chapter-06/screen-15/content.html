Module 3 › Chapter 2.6 › Key Concepts — Part 2
Saga Pattern
Sequence local transactions; on failure run compensating transactions to restore invariants and reach eventual consistency.
Compensating Transaction
An explicit undo action that restores a business invariant; must be idempotent and well-scoped.
Concurrency Control
Pessimistic locks prevent conflicts by blocking; optimistic control detects conflicts at commit using versions and retries.
Final takeaway
Trade-offs are central. State clearly which guarantees your design preserves and which trade‑offs you accept for availability and scalability.
