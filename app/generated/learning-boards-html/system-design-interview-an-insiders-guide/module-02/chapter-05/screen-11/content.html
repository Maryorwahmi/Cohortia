Ring-based mapping to minimize movement

Place keys and servers on a hash ring. Each key belongs to the next server clockwise. Adding or removing servers only forces nearby keys to move.

How it works
  1. Hash servers and keys to positions on the ring.
  2. Assign each key to the first server clockwise.
  3. When servers change, only neighboring key ranges remap.
Use virtual nodes — place each physical server multiple times — to smooth out uneven distributions and reduce variance between server loads.
Concrete example
Servers A and B host most keys. Add C between A and a set of keys and only those keys between A and C move to C, leaving other keys untouched.
Key Takeaway
Consistent hashing drastically reduces rebalancing scope, but combine it with virtual nodes and monitoring for best results.
