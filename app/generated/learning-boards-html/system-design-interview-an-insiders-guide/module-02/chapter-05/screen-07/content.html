Module 2 › Chapter 2.5 › Hash-based Sharding
Definition

Hash-based sharding

Apply a hash function to the sharding key and map the result to a shard. This evens distribution across shards and supports efficient point lookups.

Pros
  • Even distribution when keys are well-distributed.
  • Simple and fast routing for point queries.
Cons
  • Poor support for range queries.
  • Rebalancing is costly when node count changes with simple modulo schemes.
Key Takeaway

Hash-based sharding is great for even load and point lookups but plan rebalancing or use consistent hashing for dynamic clusters.

Example & code
// simple modulo example
shard_id = hash(user_id) % num_shards
If num_shards changes, most shard_id values shift. Consistent hashing addresses this problem.
Misconception
Modulo hashing makes rebalancing painful; don't assume reassigning num_shards is free in production.
