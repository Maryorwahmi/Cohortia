Module 2 › Chapter 2.5 › Directory-based Sharding
Definition

Directory or lookup-based mapping

Instead of calculating a shard, look up the shard in a directory service that holds explicit mappings of keys to shards. This allows controlled migrations and fine-grained placement decisions.

When to use
Use when placement requires explicit control for compliance, locality, or staged migrations with minimal application changes.
Operational cost
The directory must be replicated and highly available; caching can reduce lookup latency and load.
Misconception

Directory-based sharding removes complexity — it typically centralizes complexity and requires reliability engineering for the directory itself.

Example flow
  1. Client asks directory for key → returns shard endpoint.
  2. Client queries the shard directly for data.
  3. To migrate, update directory mapping and copy data asynchronously.
Key Takeaway
Directory mapping enables flexible placement and live migrations but creates a critical dependency that must be managed carefully.
