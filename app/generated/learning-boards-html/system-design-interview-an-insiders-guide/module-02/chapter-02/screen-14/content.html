Interview Task
Explain the failure of vertical scaling and propose a horizontal scaling design for a game server.
Describe load balancer role and how it distributes player connections.
Explain health checks, connection affinity needs for game sessions, and autoscaling triggers.
State the trade-offs: operational complexity vs resilience and capacity.
Answer structure hint
Start with the problem, list limitations of vertical scaling, sketch the horizontal architecture, and finish with operational details like health checks and autoscaling policy.
Sample checklist
  • Identify scaling type and limits
  • Propose load balancer and instance pool
  • Address session state and health checks
  • Suggest autoscaling metric and cooldowns
