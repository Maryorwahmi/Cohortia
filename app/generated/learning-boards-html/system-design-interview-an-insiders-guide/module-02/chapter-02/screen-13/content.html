Stateless vs Stateful
Stateless services don’t keep session state locally; state lives outside the instance.
Bad: sessions stored in an in-memory map on each instance. Scaling leads to lost sessions.
Good: sessions stored in Redis or encoded as signed tokens that any instance can verify.
When unavoidable: use sticky sessions deliberately and accept the availability trade-offs.
