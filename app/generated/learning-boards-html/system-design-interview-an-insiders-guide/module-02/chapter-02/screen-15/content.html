Module 2 › Chapter 2.2 › Key Concepts
Scalability
Adding resources so the system handles more work without performance loss.
Vertical vs Horizontal
Scale up for simplicity, scale out for resilience and elasticity.
Load Balancer
Distributes traffic, performs health checks, and enables scaling out.
Summary

Choose a scaling strategy that balances short-term simplicity and long-term resilience; design stateless services and automate capacity changes with health-aware load balancing and autoscaling policies.
