Module 2 › Chapter 2.2 › L4 vs L7
Layer 4
Transport-level routing based on IP and port. Fast and efficient.
Use L4 for raw TCP/UDP services where payload inspection isn't needed.
Lower latency and lower resource usage than L7.
Layer 7
Application-level routing using headers, paths, and cookies. Enables content-based decisions.
Use L7 when you need routing by URL path, headers, or to terminate SSL at the balancer.
More features but slightly more overhead than L4.
Example
An L7 balancer sends '/admin' to an admin pool and '/api' to production runners; an L4 balancer forwards all traffic by connection address.
Misconception
Assuming L7 is always needed. If you only need basic routing at wire level, L4 is lighter and faster.
