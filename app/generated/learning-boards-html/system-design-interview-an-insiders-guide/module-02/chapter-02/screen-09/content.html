Module 2 › Chapter 2.2 › Balancing Algorithms
Round Robin
Sequential distribution to each server.
Good for homogeneous instances and short requests. Risk: uneven load for variable request sizes.
Least Connections
Send to server with fewest active connections.
Best for long-lived requests or mixed instance sizes. Requires accurate connection tracking.
IP Hash
Map client IP to a server for affinity.
Useful for session stickiness but can cause uneven distribution with skewed client IPs.
Operational tip
Combine algorithms with health checks and weights to reflect instance capacity and avoid hotspots.
Common error
Relying on IP hash for affinity without addressing NAT or mobile clients can break routing assumptions.
