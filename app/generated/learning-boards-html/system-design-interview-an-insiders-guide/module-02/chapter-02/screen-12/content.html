Auto-scaling Policies
Define metrics and durations to add or remove instances automatically.
Metric
Average CPU, request queue length, latency, or custom app metrics.
Scale-out Policy
Add an instance if average CPU > 70% for 5 minutes.
Scale-in Policy
Remove an instance if average CPU < 30% for 10 minutes to avoid flapping.
Example
Set min and max instance counts, tune policies by observing real traffic patterns, and prefer application-aware metrics when possible.
Pitfall
Using the wrong metric leads to wrong scaling behavior—pick metrics tied to the real bottleneck.
