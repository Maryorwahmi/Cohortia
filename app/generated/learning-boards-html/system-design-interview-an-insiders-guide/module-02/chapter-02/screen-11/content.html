Health Checks
Probe backends to ensure they are ready to serve traffic.
Types: TCP, HTTP status check, or application-specific ping endpoints.
Tuning: check frequency, timeout, and threshold to avoid oscillation.
Combine checks with monitoring to detect persistent failures early.
Connection Draining
Stop new requests and allow existing ones to complete before removing a server.
Use draining during deployments and scale-in events to prevent errors.
Ensure backends implement graceful shutdown to honor in-flight work.
Example
An autoscaler removes an instance only after the load balancer drains connections and health checks stop failing.
Common mistake
No draining during deploys causes user-facing errors from abruptly terminated requests.
