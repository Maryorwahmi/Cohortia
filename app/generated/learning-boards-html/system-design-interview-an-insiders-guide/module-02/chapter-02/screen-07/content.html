Module 2 › Chapter 2.2 › Load Balancer Role
What a load balancer does
Routes traffic to healthy backends and enforces distribution policies.
Health checks: remove unhealthy backends automatically to avoid routing to failing servers.
Routing policies: round robin, least connections, IP hash, or content-based routing for application needs.
Operational tasks: SSL termination, connection draining during deploys, and metrics emission.
Scenario
An external load balancer receives client traffic, checks which backends are healthy, and forwards requests. If one backend returns errors, it is removed until it recovers.
Example
Use connection draining so existing requests complete when removing a server from rotation during deployment.
Common mistake
Skipping health checks leads to traffic being routed to unhealthy servers and poor user experience despite many instances.
