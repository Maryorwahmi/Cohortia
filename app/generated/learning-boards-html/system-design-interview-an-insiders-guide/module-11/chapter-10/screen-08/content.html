Graceful degradation

Design degradations that preserve main user flows while disabling or simplifying secondary features.

Core first
Deliver posts and essential metadata before enrichment calls complete.
Fallbacks
Return cached or default values for enriching services when they fail.
Testing degradations
Run failure injection tests that disable secondary services and verify the feed still returns within SLOs.
Misconception
Degradation is not the same as ignoring failures; it must be observable and reversible.
