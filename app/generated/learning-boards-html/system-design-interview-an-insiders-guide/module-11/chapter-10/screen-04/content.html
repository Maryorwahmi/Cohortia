Core Concept

Resilience & Fault Tolerance

Definitions and practical consequences for a social feed architecture.

Why it matters
Users expect feeds to load even when parts of the system fail. Resilience reduces downtime and user impact.
Common pitfalls
  • Redundancy without failover automation.
  • Retries that cause cascading load increases.
  • Neglecting regional outages in planning.
Concrete example: DB failover
Imagine the primary write database fails. With replicas, an automated failover promotes a standby, clients reconnect via DNS or proxy, and the application continues serving writes with short disruption. If this process is manual, downtime grows significantly.
Takeaway
Design both redundancy and automation for failover.
Misconception
More replicas without orchestration does not equal higher availability.
