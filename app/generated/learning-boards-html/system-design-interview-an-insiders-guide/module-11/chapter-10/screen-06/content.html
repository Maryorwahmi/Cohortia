Definition

Circuit Breaker pattern

Open the circuit after repeated failures. Provide a clear fallback and emit an alert when the breaker trips.

Common misuse
Using a circuit breaker without a sensible fallback or without alerting can hide systemic problems.
Conceptual code example
<!-- Conceptual Java circuit breaker example --> @CircuitBreaker(name = "postService", fallbackMethod = "getPostsFallback") public List<Post> getPostsFromPostService(List<String> postIds) { // Call Post Service } public List<Post> getPostsFallback(List<String> postIds, Throwable t) { // Log error, return empty list or cached data return Collections.emptyList(); }
Example
When User Service timeouts increase, the breaker in Post Service opens and Post Service returns cached metadata while emitting an alert for investigation.
