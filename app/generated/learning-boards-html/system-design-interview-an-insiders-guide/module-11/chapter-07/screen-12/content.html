Template
{
  "to": "FCM_DEVICE_TOKEN_HERE",
  "notification": {
    "title": "New Comment on Your Post!",
    "body": "Jane Doe commented: 'Great post!'"
  },
  "data": {
    "notification_type": "new_comment",
    "post_id": "...",
    "comment_id": "...",
    "commenter_id": "..."
  }
}
Use the notification block for user-facing text and the data block for routing and internal handling.
Guided checklist
  • Include a concise title and body that make sense on a lock screen.
  • Put post and comment identifiers in the data map for deep linking.
  • Send to all tokens for the user's devices and deduplicate client-side if needed.
  • Handle invalid tokens returned by FCM and remove them from your store.
Key Takeaway

Separate display text from routing data and validate tokens to keep push delivery efficient and private.
