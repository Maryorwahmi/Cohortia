Module 11 › Chapter 11.7 › Troubleshooting
Web not receiving notifications?
Check WebSocket connection health, gateway mapping for the user id, and that the Notification Service published to the gateway topic. Verify client auth token validity and reconnect logic.
Checklist
  • Is the WebSocket connected and authenticated?
  • Did the gateway receive the notification from the Notification Service?
  • Are there pub/sub or routing errors in gateway logs?
Mobile push issues?
When a user logs out, remove tokens for that user. Inspect push gateway responses to identify invalid tokens and prune them. Ensure you handle multiple devices per user.
Checklist
  • Are device tokens stored and up-to-date in the User Service?
  • Does the push gateway report invalid token errors?
  • Is the app correctly sending its device token after reinstall or login?
