Module 11 › Chapter 11.7 › Learning Objectives
I - Ingest
Events from Post, Comment, or Like services enter a durable message queue so notifications start from a reliable stream. This prevents lost signals when downstream systems are busy.
VERIFIED COMPETENCY MILESTONE
G - Generate
The Notification Service consumes events, resolves recipients, and formats a human-friendly message like 'Jane liked your post'. This step decides fan-out and personalization.
VERIFIED COMPETENCY MILESTONE
P - Persist
Store notifications in a user-partitioned table so history and pagination are cheap. Use time-ordered clustering for efficient recent-first reads.
VERIFIED COMPETENCY MILESTONE
D - Deliver
Deliver in real time via WebSockets for online browsers and via APNS/FCM for mobile devices when the app may be inactive.
VERIFIED COMPETENCY MILESTONE
