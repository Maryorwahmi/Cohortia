Module 11 › Chapter 11.8 › Generate Pre-signed URL
Server-side example

Python (boto3) pre-signed URL

import boto3
s3_client = boto3.client('s3', region_name='us-east-1')
object_name = f"user_uploads/{user_id}/{uuid.uuid4()}.jpg"
response = s3_client.generate_presigned_url('put_object',
                                            Params={'Bucket': 'my-media-bucket',
                                                    'Key': object_name,
                                                    'ContentType': 'image/jpeg'},
                                            ExpiresIn=3600)
# Client receives this URL and uploads directly
Notes
  • Choose a clear object naming convention so processed assets can be matched back.
  • Set ContentType to help the storage service validate content at upload.
  • Use multipart upload for large files and short-lived credentials for stronger control.
Key Takeaway

The server issues the pre-signed URL after authentication; the client then uploads directly to object storage, reducing backend bandwidth and CPU use.
