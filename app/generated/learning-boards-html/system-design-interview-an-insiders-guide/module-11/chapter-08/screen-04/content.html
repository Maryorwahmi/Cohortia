Module 11 › Chapter 11.8 › Object Storage for Media
Definition

Object storage

A RESTful storage model for objects identified by keys, optimized for scale and durability.

• Scalability & Durability: designed for massive scale and multiple replicas.
• Cost-effective: lifecycle policies move cold data to cheaper tiers.
• API Access: simple REST APIs for put, get, and list operations.
Concrete example
Store images under keys like user_uploads/{user_id}/{uuid}.jpg and enable lifecycle rules to archive originals after thirty days.
Key Takeaway

Object storage is the durable, API-driven backbone for media at scale; design keys and lifecycle rules carefully.

Misconception

Treating object storage like a traditional file system will create operational surprises; there are no POSIX locks or in-place edits.

Why it matters

Designs that assume file-system semantics may attempt in-place updates or rely on directory-like consistency, which mismatches object semantics and can lead to race conditions or inefficiencies.

Quick checklist
  • Choose naming conventions for keys.
  • Enable server-side encryption and versioning if needed.
  • Set lifecycle rules to control costs.
