Design for backlog: autoscale workers based on queue depth and control maximum parallel transcodes per machine to avoid resource contention.
Operational checklist
  • Use durable queue to preserve events.
  • Implement idempotency for processing jobs.
  • Provide DLQ and alerts for repeated failures.
Common Mistake

Chaining many synchronous transforms can exhaust limits; prefer queued, parallel workers for heavy CPU work.
