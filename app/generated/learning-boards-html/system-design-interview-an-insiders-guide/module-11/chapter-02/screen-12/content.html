Media upload flow
  1. Client uploads media to Media Service via API Gateway.
  2. Media Service stores file in object storage and returns a CDN-ready URL.
  3. Post references the CDN URL; clients request media from CDN edges.
Example
Uploads go to object storage; the CDN caches content near users for low-latency delivery.
Pitfall
Putting binary blobs in the primary database increases storage and backup costs and hurts performance.
Key Takeaway
Use a Media Service plus object storage and CDN to scale media storage and delivery efficiently.
