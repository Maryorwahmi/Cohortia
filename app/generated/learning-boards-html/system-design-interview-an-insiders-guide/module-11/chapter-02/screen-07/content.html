Module 11 › Chapter 11.2 › Posting Flow
Step-by-step
1
Client → API Gateway
Authenticate and forward the POST to the Post Service.
2
Post Service processing
Moderation, metadata extraction, media upload coordination.
3
Persist and publish event
Store post, then publish "New Post" to a message queue for async consumers.
4
Consumers process event
Feed Service fans out and Notification Service emits alerts.
Example event payload
{
  "type": "NewPost",
  "postId": "p-998",
  "authorId": "u-123",
  "timestamp": "2024-01-01T12:00:00Z"
}
Key Takeaway

Use queues to decouple and keep the write path fast; consumers can scale independently for distribution.
