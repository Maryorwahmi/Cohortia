Module 11 › Chapter 11.2 › Definition
Claim

High-level design maps components and major flows so you can reason about scale, failure, and evolution without locking into low-level choices.

Analogy
City map analogy
You draw main roads and districts first, then design buildings. Components are districts; services are buildings.
Key takeaway
Produce a map that supports clear trade-off discussion and failure reasoning, not a one-line component list.
Common mistake
Designing a monolith because it's simpler; this hides scaling and maintenance trade-offs.
Concrete example
Separate Post Service handles writes and publishes a "New Post" event. Feed Service consumes the event and performs fan-out. This separation allows write latency to stay low while asynchronous systems handle distribution.
