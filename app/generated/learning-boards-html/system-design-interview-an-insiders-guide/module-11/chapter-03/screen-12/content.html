Task
Design posts_by_hashtag
Efficiently return posts for a given hashtag ordered by time.
CQL template
CREATE TABLE posts_by_hashtag (
  hashtag TEXT,
  post_id TIMEUUID,
  user_id UUID,
  created_at TIMESTAMP,
  post_content_snippet TEXT,
  media_thumbnail_url TEXT,
  PRIMARY KEY ((hashtag), post_id)
) WITH CLUSTERING ORDER BY (post_id DESC);
Guidance
  • Partition by hashtag for direct lookups of posts with that tag.
  • Cluster by TIMEUUID post_id to return recent posts first without sorting.
  • Store a content snippet and thumbnail to avoid fetching the full post row.
  • Shard popular hashtags by adding a numeric suffix to the partition key when needed.
Example flow
On post creation, for each hashtag insert a row into posts_by_hashtag. For reads, query the hashtag partition and return top N post summaries.
Key Takeaway

Design hashtag tables for the lookup pattern and protect against hot partitions by sharding popular keys.
