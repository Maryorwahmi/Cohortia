How to show competency
Concrete checks and schema examples you can present
Users — SQL check
Show CREATE TABLE users with UUID primary key and indexes on username/email to prove login and uniqueness.
Posts — NoSQL check
Show posts_by_user and posts_by_id, explain partition key user_id and clustering TIMEUUID for ordering.
Followers & Likes
Demonstrate mirrored follower/following tables and per-post vs per-user like tables; discuss atomicity limits.
