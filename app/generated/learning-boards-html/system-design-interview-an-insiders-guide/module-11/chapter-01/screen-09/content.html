What notifications require
  • Low delivery latency (seconds).
  • Durable event persistence and retry mechanisms.
  • Scalable fan-out or batching for bursts.
  • Separation of notification SLAs from feed SLAs.
Concrete Flow
1.
User action generates event → persisted to durable queue.
2.
Notification service consumes events, formats payload, and dispatches to push gateway or in-app stream.
3.
Backpressure handling: batch, throttle, or store for retry on downstream failures.
Common Mistake
Tightly coupling notification delivery to main write path which increases end-to-end latency and failure blast radius. Use async pipelines instead.
