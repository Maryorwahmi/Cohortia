Module 11 › Chapter 11.1 › Functional Requirements
Definition & Examples

Functional requirements specify the behaviors users expect. They become the primary acceptance tests for your feed system.

  • User Registration: create account, secure credentials, session tokens.
  • Posting Content: text, image, video storage and metadata like timestamp and author.
  • Following: directed social graph to determine who sees which posts.
  • Liking/Commenting: interactions that update counts and show on feeds.
  • Feed Generation: produce a personalized ordered stream for each user.
Concrete Example
When Alice posts, Bob must see the post in his feed within defined staleness limits. Preconditions: Bob follows Alice and has an active session.
Testable Acceptance Criteria
  1. Given a new post from a user, followers should see it within X seconds.
  2. Given a like action, the displayed count should update within Y seconds.
  3. Given account creation, the user can authenticate and access their feed securely.
Key Takeaway

Capture functional needs as user stories with preconditions and measurable success criteria before choosing infrastructure.
