Module 11 › Chapter 11.1 › From Post to Feed
Process Steps
1.
Client submits post → API validates and persists Post object.
2.
Media saved to durable object store; Post stores media reference.
3.
Social graph lookup finds followers or delivery targets.
4.
Feed delivery: push to timelines or record for on-demand aggregation.
Comparison: Push vs Pull
Push (Fan-out)
Writes expensive; reads cheap and fast. Good for heavy-read, low-write scenarios.
Pull (Fan-in)
Writes cheap; reads aggregate at query time. Better when followers are many or writes are frequent.
Concrete Scenario
If a celebrity posts, pushing to millions of timelines is costly. A pull model with caching may be more cost-effective for that edge case.
