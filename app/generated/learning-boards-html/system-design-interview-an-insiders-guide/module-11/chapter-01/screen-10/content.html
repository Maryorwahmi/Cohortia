Module 11 › Chapter 11.1 › Scope & Flows
Primary User Flows
  1. Login: auth checks and profile read (strong consistency).
  2. Create post: write to Post store, media upload, queue propagation.
  3. Follow/unfollow: update social graph, possibly update timelines.
  4. View feed: aggregate or read precomputed timeline, apply ranking.
  5. Interact (like/comment): write interaction and update counters/notifications.
Hotspot Matrix
Write-heavy: Post creation, media storage.
Read-heavy: Feed retrieval, search.
Latency-sensitive: Feed reads, notifications.
Example Decision
Prioritize caching for feed reads in markets with most active users, and use background fan-out for less-active users.
