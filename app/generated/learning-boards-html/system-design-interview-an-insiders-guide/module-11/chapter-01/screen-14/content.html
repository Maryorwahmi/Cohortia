Module 11 › Chapter 11.1 › Key Concepts
Functional Requirements
Behavioral features like login, posting, following, and feed display.
Non-functional Targets
Scalability, availability, latency, durability, consistency, and cost constraints.
Entity & Flow Modeling
Model users, posts, follows, interactions and map flows to uncover hotspots.
Summary

Start with clear requirements and measurable targets. Use entity models and flow maps to expose scaling levers and make trade-offs explicit.
