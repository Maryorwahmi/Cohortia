Module 11 › Chapter 11.1 › Core Entities
Entity Cards
User
id, username, hashed credentials, profile metadata, privacy flags. Index by id and username.
Post
id, author_id, timestamp, media_refs, text, like_count, comment_count. Index by author and time.
Follow
follower_id, followee_id, created_at. Optimize reads for followee's followers and follower's followees.
Like / Comment
interaction records and counters. Counters may be eventually consistent to avoid hotspots.
Design Decisions
  • Estimate per-entity QPS/TPS to identify bottlenecks.
  • Plan sharding by author id or geographic region where necessary.
  • Use denormalized timelines for heavy-read users and on-demand aggregation for sparse users.
Common Mistake
Designing a single table for all posts without considering hot rows for popular authors, which causes write contention and uneven load.
