Module 11 › Chapter 11.1 › Security & Privacy
Checklist
  • Encryption at rest and in transit for sensitive fields.
  • Sanitization to prevent XSS for user-supplied content.
  • Authentication and session security for user access.
  • Retention and deletion policies for privacy compliance.
Design Impact
Privacy rules can restrict which data is replicated to analytics clusters.
Security SLAs can require stronger consistency for auth flows, influencing the authentication architecture.
Scenario
If users can request deletion, your system must propagate deletes to caches and replicas or keep soft-deletes until fully purged, which affects storage and operations.
