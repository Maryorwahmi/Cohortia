Module 11 › Chapter 11.1 › Learning Objectives
Practice Tasks
  1. Estimate peak post writes and feed read QPS for an MVP audience.
  2. Map entities and mark which fields must be strongly consistent.
  3. Produce a prioritized features list with estimated cost drivers.
  4. Create one clarifying question set to reduce ambiguity in requirements gathering.
Mnemonic: Ask, Measure, Map, Prioritize.
Verification Checklist
  • Entity diagram with primary relationships and cardinality.
  • Numeric targets: expected peak QPS/TPS, acceptable latency.
  • Priority classification for features: Critical, High, Medium, Low.
  • One paragraph justification for trade-offs chosen.
Follow this checklist to make requirements defensible and design decisions traceable.
