Module 11 › Chapter 11.5 › Post Storage Service
Architecture
Consumer responsibilities
Enrich, moderate, batch, write, and publish stored events reliably.
Enrichment & moderation
Extract hashtags, check policies, and tag posts before storage to support search and compliance.
Batching for writes
Group multiple post writes into a single bulk operation to reduce latency and overhead against the database.
Idempotency and retries
Design consumers so repeated processing due to retries does not create duplicates or corrupt counts.
Concrete Example
During a 10-minute storm, consumers scale to many instances, aggregate messages into batches of 200, and perform fewer, larger writes to reduce node load.
Pro-tip
Tune batch size to balance write throughput and acceptable latency for a typical post acknowledgment-to-visibility window.
