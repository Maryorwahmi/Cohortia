Operational Monitoring
Which metrics matter and how to act on them during a post storm
Queue Lag
Primary indicator of backpressure
Scale consumers, increase partitions, or raise batch throughput when lag grows.
Write Latency
Shows database stress
Tune consistency, add nodes, or adjust batching to reduce latency.
DLQ Rate
Errors in processing
Investigate message content or processing logic; DLQs are for triage, not silent failure.
Playbook snippet
If queue lag > threshold, auto-scale consumers and increase batch sizes. If write latency spikes, throttle producers and investigate node health.
Key Takeaway
Correlate lag, latency, and error counts and map them to concrete mitigations in an incident runbook.
