Producer script (concept)
# Pseudocode example: produce messages at target rate
from kafka import KafkaProducer
producer = KafkaProducer(...)
for i in range(N):
  msg = {"post_id": generate_timeuuid(), "user_id": user, "content": "..."}
  producer.send('posts', value=serialize(msg))
  sleep(inter_message_delay)
Run the producer at increasing rates and watch consumer lag grow if consumers can't keep up.
Consumer script (concept)
# Pseudocode example: consumer with batching
from kafka import KafkaConsumer
consumer = KafkaConsumer('posts', ...)
batch = []
for msg in consumer:
  batch.append(deserialize(msg))
  if len(batch) >= batch_size:
    write_batch_to_db(batch)
    consumer.commit()
    batch = []
Try increasing batch_size or adding more consumer instances to reduce lag; use consumer group tools to monitor lag during the run.
