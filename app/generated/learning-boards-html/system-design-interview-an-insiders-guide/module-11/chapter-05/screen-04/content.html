Module 11 › Chapter 11.5 › Ingestion Pipeline Overview
Process Flow
Client → Gateway → Post Service → Queue
Each step reduces coupling and improves resilience during spikes.
API Gateway: auth, routing, rate limiting, small validation.
Post Service: lightweight validation, assign time-based id, produce to queue.
Message Queue: durable buffer, decoupling, persists until consumers process.
Example
During a flash spike, the Post Service enqueues 50k messages per second and returns success to users while the queue smooths backend writes.
Common mistake
Writing directly from the Post Service couples availability to database performance and risks cascading failures.

Key Takeaway

Keep the critical path short: persist to a durable queue, then perform expensive operations asynchronously.
