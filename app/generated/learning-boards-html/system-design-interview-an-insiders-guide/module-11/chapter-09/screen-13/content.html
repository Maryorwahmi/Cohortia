Module 11 › Chapter 11.9 › Pitfalls & Safety
Common mistakes
Using operational DB for search
Operational stores are not optimized for tokenization or relevance; prefer a search engine for full-text queries.
Underestimating operational cost
Clustering search engines and running large-scale stream processing requires capacity planning and expertise.
Data quality & schema
Validate event schemas at ingestion and add checks to prevent corrupt or incomplete events from entering downstream systems.
Privacy
Pseudonymize or anonymize sensitive user fields in analytics, and apply strict access controls for analysts and dashboards.
Key Takeaway
Plan for operations, monitoring, privacy, and cost before rolling out advanced features. These non-functional requirements are critical to long-term success.
