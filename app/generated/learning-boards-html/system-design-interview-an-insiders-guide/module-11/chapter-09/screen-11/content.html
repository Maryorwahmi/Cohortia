Module 11 › Chapter 11.9 › Analytics Pipeline
Event collection flow
  1. Clients and services send events to an Event Ingestion Endpoint.
  2. Events stream into Kafka for durable, ordered delivery.
  3. Streams are written to a raw data lake (S3) for long-term storage.
  4. Batch and stream jobs transform raw events into warehouse tables for BI.
Example: every post view, like, search, and ad click is captured as an event with a schema, streamed through Kafka, landed into S3, and then loaded into a warehouse like BigQuery for dashboards.
Processing modes
Batch processing
Historical aggregations and daily reports using Spark or EMR.
Stream processing
Real-time dashboards and low-latency metrics using Flink or Kafka Streams.
Key Takeaway
Treat the message queue and data lake as durable anchors. They let you reprocess and correct analytics without changing producers.
