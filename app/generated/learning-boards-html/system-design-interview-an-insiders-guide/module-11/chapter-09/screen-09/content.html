Module 11 › Chapter 11.9 › Sliding Window Algorithm
Algorithm outline
Maintain a list of active windows (e.g., last 3 windows of 5 minutes). For each incoming post event, extract hashtags and increment counts for the current window. Rotate windows periodically and subtract the oldest window's counts when it expires. Sum across active windows to compute top-K trending hashtags.
Pseudocode
// windows: list of hashmaps for active windows
// currentWindow is windows[last]
onPostEvent(post) {
  hashtags = extractHashtags(post)
  for (h in hashtags) {
    currentWindow[h] = (currentWindow[h] or 0) + 1
  }
}
rotateWindows() {
  // push new empty window, pop oldest
  windows.push(new HashMap())
  if (windows.length > maxWindows) {
    windows.shift()
  }
}
computeTrending() {
  totals = new HashMap()
  for (w in windows) for (h,count in w) totals[h] = (totals[h] or 0) + count
  return topK(totals)
}
Example
If '#coffee' appears 50 times in the most recent windows and passes filters, it rises into the top-K list stored in Redis for quick retrieval.
Common Mistake

Using a single cumulative map will favor historically popular hashtags and not surface emergent spikes. Use sliding windows instead.
