Apply & Assess

Practical checkpoints
Search Checklist
  • Event stream from Post/User services to indexer
  • Flatten and tokenize documents before indexing
  • Plan shards, replicas and TTL for older data
Trending Checklist
  • Sliding windows (e.g., 5m, 1h) for counts
  • Use stream frameworks to maintain low-latency state
  • Filter stop words and spam before ranking
Analytics Checklist
  • Capture client and server events to an ingestion endpoint
  • Stream into Kafka then into raw data lake (S3)
  • Transform for the warehouse and BI tools
Trade-off Checklist
  • Avoid using operational DBs for search or analytics
  • Define retention and sampling to control costs
  • Apply anonymization and strict access controls
