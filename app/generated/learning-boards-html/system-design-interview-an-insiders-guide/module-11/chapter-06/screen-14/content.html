Module 11 › Chapter 11.6 › Key Concepts
Feed Cache
A Redis sorted set storing post_ids per user, ordered by timestamps for efficient slicing.
Post Cache
Full post objects keyed by post_id to avoid repeated database reads.
Cache Hit / Miss
A hit returns cached IDs or objects; a miss requires generation or DB access, increasing latency.
Summary

Use these building blocks to design a feed read path that balances freshness, latency, and backend load.
