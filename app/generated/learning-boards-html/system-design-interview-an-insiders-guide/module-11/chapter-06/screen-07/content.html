Module 11 › Chapter 11.6 › Feed Cache Operations
Commands
# Add a post ID with timestamp score
redis_client.zadd(f"user:feed:{user_id}", {post_id: timestamp_score})
# Get latest 20 post IDs
redis_client.zrevrange(f"user:feed:{user_id}", 0, 19)
# Trim old posts beyond max size
redis_client.zremrangebyrank(f"user:feed:{user_id}", 0, -(max_size + 1))
Keep these operations instrumented and bounded. Trimming prevents unbounded growth.
Common pitfalls
  • Not trimming sorted sets leading to memory pressure.
  • Using overly-long TTLs and serving stale content.
  • Forgetting to ZREM when posts must be removed for unfollows or deletions.
