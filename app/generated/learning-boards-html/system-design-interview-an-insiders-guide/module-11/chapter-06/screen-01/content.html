Feed Retrieval & Ranking

Design read paths that return personalized content with minimal latency using cache layers and initial ranking.

Feed Cache

Sorted sets of post IDs, trimmed and TTL'd for freshness.

Post Cache

Full post objects keyed by post_id to avoid DB hits.

Architecture snapshot
API Gateway routes to Feed Service which checks feed cache, post cache, then DB if needed.
Two-level caching reduces database load and keeps tail latency low.
Short TTLs or explicit invalidation prevent long-lived stale feeds.
