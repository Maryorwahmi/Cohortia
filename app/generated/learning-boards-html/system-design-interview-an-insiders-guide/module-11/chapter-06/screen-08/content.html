Example store
post_data = {
  "user_id": str(post.user_id),
  "content": post.content,
  "media_url": post.media_url,
  "likes_count": post.likes_count
}
redis_client.hmset(f"post:{post_id}", post_data)
redis_client.expire(f"post:{post_id}", POST_TTL_SECONDS)
Invalidation patterns
  • Emit events on updates and have a handler delete or refresh the cache entry.
  • Update caches lazily after a write, but ensure eventual consistency.
  • Use idempotent handlers so repeated messages do not cause errors.
Common mistake

Failing to invalidate post objects or using inconsistent TTLs leads to user-visible stale counts or content.
