Module 11 › Chapter 11.6 › Two-Level Caching Pattern
Feed Cache (IDs)
Stored as Redis Sorted Set: members are post_id, scores are timestamps. Efficient to slice most recent N items.
ZADD and ZREVRANGE are primary operations for this layer.
Post Cache (Objects)
Store full post objects keyed by post_id, often a Redis hash, with an independent TTL to limit staleness.
HMSET/HGETALL and EXPIRE are common operations here.
Trim feed lists to control memory usage and keep reads fast.
Use different TTLs for ID lists and post objects to balance freshness and hit ratio.
On an update, invalidate the post object and update scores in ID lists if engagement changes.
