Module 11 › Chapter 11.6 › Basic Feed Ranking
Reverse chronological
Order posts by creation time, newest first. Simple, low-cost, and predictable for users.
Supported naturally by TIMEUUID and Redis sorted sets using timestamps as scores.
Simple engagement score
Combine timestamp with recent engagement: score = timestamp + likes*weight_L + comments*weight_C. Update cached scores on interaction events.
Careful: updating many feed caches on every like can be expensive unless the system updates scores lazily or for a bounded set of users.
