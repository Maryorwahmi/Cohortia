Module 11 › Chapter 11.6 › Cache Miss: Feed Generation
Generation steps
  1. Query follower list for user to get source accounts.
  2. Fetch recent posts per source from the feed DB or celebrity cache.
  3. Merge IDs, deduplicate, and sort by timestamp or score.
  4. Apply initial ranking and populate feed cache for future reads.
Operational notes
Cap the number of sources and candidate posts to keep generation latency bounded. Consider background pre-computation for heavy users and cache warming for critical times.
Measure generation latency separately and set alerts for high rates of cache misses.
