Architecture Hybrid approach
Threshold-driven logic
If follower_count ≤ FOLLOWER_THRESHOLD, perform fan-out on write. If follower_count > FOLLOWER_THRESHOLD, store post in a celebrity feed store for pull retrieval.
Implementation notes
  • Check follower_count in fan-out consumer to decide route.
  • Cache celebrity posts to reduce repeated pulls.
  • Merge pre-generated and pulled posts at read time, then rank.
Example threshold
Start with 100,000; adjust dynamically based on traffic and cost.
At read time
Feed Service retrieves pre-generated feed entries for pushed authors, identifies any super-followed authors the user follows, fetches recent celebrity posts from cache or celebrity store, merges both sets, applies ranking, and returns the combined feed.
Key practice
Ensure merge preserves chronological and ranking order and that celebrities' posts are cached to reduce read load.
Monitoring: track write amplification, feed DB latency, celebrity cache hit rate, and follower distribution to refine thresholds.
