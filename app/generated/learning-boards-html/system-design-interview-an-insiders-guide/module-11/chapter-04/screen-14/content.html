Module 11 › Chapter 11.4 › Key Concepts
Fan-out on Write
Immediate push to followers; optimizes read latency, increases write amplification and storage.
Fan-out on Read
Generate feeds at read time; lowers write cost but increases read-time aggregation and latency without caching.
Hybrid Approach
Push for ordinary authors, pull for celebrities using a FOLLOWER_THRESHOLD; merge at read time and use caching.
Final summary
Design choices should be driven by follower distributions, read patterns, and product priorities. Use queues, idempotency, rate limits, and caches to make your chosen model reliable and scalable.
