Core Concept The fan-out challenge
What is fan-out?

Fan-out is the work of distributing a new post to the set of followers so their personalized feeds show new content. It can be done at write time or read time, and the choice affects system cost and latency.

Write amplification
How many writes a single post triggers across follower feeds.
Read amplification
How many reads are necessary to assemble a feed at request time.
Misconception
There is no universally best model; each forces trade-offs you must manage with operational controls.
Concrete scenarios
Example: 100 followers (push)
Pushing a post writes to ~100 feeds; low read latency and straightforward retrieval.
Example: 1,000 followed authors (pull)
Assembling a feed requires fetching recent posts from many authors, increasing read latency and DB load.
Key takeaway
Measure follower distributions and activity to choose or tune the fan-out strategy.
Key Takeaway

Fan-out strategy maps directly to where cost appears: write cost, read cost, or a managed blend. Choose based on follower scale and desired freshness.
