Process Flow Fan-out on Write
Push process steps
  1. User posts; Post Service stores the post.
  2. Post Service publishes a "New Post" event to a message queue.
  3. Feed Fan-out Service consumes the event and queries follower list.
  4. For each follower, insert post ID/snippet into their feed database.
  5. Feed Service reads pre-generated feed for fast retrieval.
Pro-tip
Batch follower writes, use background workers, and make fan-out idempotent to handle retries from the queue safely.

Materialized feeds (Redis sorted sets or Cassandra)
Common mistake
Pushing blindly for super-followed accounts without thresholding leads to severe write storms and storage blow-up.
