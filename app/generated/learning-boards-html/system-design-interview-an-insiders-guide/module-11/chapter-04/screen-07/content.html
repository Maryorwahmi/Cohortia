Process Flow Fan-out on Read
Pull process steps
  1. User requests feed; Feed Service retrieves follow list.
  2. For each followed author, query Post Database for recent posts.
  3. Aggregate, sort, and apply ranking before returning results.
Benefits
Low write amplification, single source of truth for posts, efficient for dormant followers.
Challenges & optimizations
High read latency
Aggregation across thousands of authors can be slow and must be optimized with caching and prefetching.
Database load
The Post Database becomes a bottleneck when many feed requests trigger many reads.
Mitigations
Use caches for hot authors, precompute partial feeds for active users, and shard reads.
Common Mistake

Assuming pull will always save cost; without caching it can create unacceptable user latency for active readers.
