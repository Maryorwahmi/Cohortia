Designing the Fan-out Mechanism for Feed Generation

Explore push, pull, and hybrid models and the operational controls you need to scale a social feed: queues, caching, thresholds, and idempotency.

Why this matters
Users expect fast feeds; choosing the wrong fan-out strategy creates latency, cost, and storage problems at scale.
In this lesson
Compare push vs pull, design a hybrid, and examine implementation notes like message queues, caches, idempotency, and threshold logic.
Visual summary
Push · Pull · Hybrid
Fan-out on Write
Pre-generate feeds. Low read latency. High write amplification.
Fan-out on Read
Aggregate on demand. Low write cost. Higher read latency.
Hybrid
Push for regular users, pull for super-followed authors; use cache and thresholding to balance load.
Example
100 followers → push. 1M followers → pull.
