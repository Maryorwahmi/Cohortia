Monitoring & Ops

Key metrics to watch

  • Cache hit ratio (global and per-path).
  • Origin requests per second and burst rates.
  • Edge 4xx/5xx error rates and purge frequency.
  • Shield hit/miss rates if using Origin Shield.
Troubleshooting checklist
  1. Confirm recent deploys or URL changes.
  2. Check query string forwarding and cookie rules.
  3. Inspect purge history and shield behavior.
  4. Rollback or adjust rules one at a time and observe metrics.
Concrete example
A sudden hit ratio drop for /static/images. Steps taken: check asset URL scheme for lost version hashes, review query parameter policies that may have started being forwarded, and verify whether a large purge was issued. Result: identify an analytics parameter now forwarded; change rule to ignore it and restore hit ratio.
Key Takeaway

Observability and single-change rollouts prevent configuration churn and allow you to see the real effect of tuning steps.
