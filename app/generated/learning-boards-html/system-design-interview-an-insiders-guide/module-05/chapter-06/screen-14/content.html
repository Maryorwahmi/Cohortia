Module 5 › Chapter 5.6 › Key Concepts
Cache Hit Ratio
Percent of requests served from CDN cache; break down by path for insight.
Origin Shield
An intermediate cache that reduces simultaneous origin fetches from many edge PoPs.
Custom Rules
Map TTLs and cache keys to content semantics; ignore irrelevant parameters to preserve hit ratio.
Summary Takeaway

Combine measurement, conservative rollouts, and rule discipline to keep CDNs efficient, reliable, and secure.
