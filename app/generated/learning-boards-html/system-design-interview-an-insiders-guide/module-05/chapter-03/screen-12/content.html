Layer examples
Local cache
Ultra-low latency, short TTL, may need coherent invalidation with distributed cache.
Distributed cache
Shared hits across nodes; use explicit invalidation for critical updates.
Origin store
Authoritative data; coordinate invalidation messages to clear caches.
Key Takeaway

Layered caches let you tune latency and freshness independently; ensure invalidations reach every layer reliably.

Coordination pattern
Publish invalidation events to a durable queue after writes. Cache subscribers consume and apply deletes to stay coherent across layers. Make invalidation idempotent so retries are safe.
Scenario
Use write-through for permissions, TTL for feeds, and explicit invalidation for profile edits to get a balanced result.
