Module 5 › Chapter 5.3 › Choosing a TTL
Heuristics
  1. Measure median update interval and set TTL as a fraction of that interval.
  2. Add jitter to expirations to avoid synchronized misses.
  3. Monitor hit rates and backend load, then adjust TTL.
Pitfall
Short TTLs can negate caching benefits and create high backend load; long TTLs risk prolonged staleness for critical keys.
Example scenario
User profile updates
If profiles change infrequently, a moderate TTL plus explicit invalidation on update gives both performance and immediate correctness when needed.
Mitigation
Combine TTL with targeted deletes for the small set of keys that must be fresh post-update.
