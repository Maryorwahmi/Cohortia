Module 5 › Chapter 5.3 › Cache stampede
What happens
Many clients miss a cache entry at once and request the backend simultaneously, risking overload.
Mitigations
  • Single-flight: allow one fetch and let others wait for the result.
  • Soft expiry: serve stale data while revalidating in background.
  • Jitter/staggered expirations to avoid synchronized misses.
Example
Popular product page expiry causes thousands of users to fetch from DB; single-flight prevents a surge by serializing the refresh.
Implementation note
Single-flight requires coordination in the cache layer. Many cache libraries or in-process utilities provide this pattern, but distributed caches need centralized or token-based coordination.
Misconception
Assuming TTL jitter alone solves stampedes; jitter helps but coalescing the actual refetch is often necessary for very high concurrency.
