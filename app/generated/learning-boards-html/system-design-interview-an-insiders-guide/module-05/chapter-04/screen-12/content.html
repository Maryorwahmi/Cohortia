Module 5 › Chapter 5.4 › Implementing & testing LRU
Starter checklist
  1. Implement get and put that update recency.
  2. Create three traces: hot-set, scan, and mixed.
  3. Replay traces, record hit ratio and evicted keys.
  4. Compare results across policies.
Tip: Keep trace lengths modest for quick iteration, then scale up once the logic is correct.
Example trace
[1,2,1,3,4,1,5,6,1] — this mixes repeated accesses to key 1 with occasional scans. Replay it and observe which keys are evicted under capacity 3.
Check your understanding: After replaying this trace with capacity 3 under LRU, which key is evicted when inserting key 5? Consider the recency order at that point.
