Module 5 › Chapter 5.2 › TTLs & Invalidation
Practical rules
Static content: long TTL + ETag/versioned URLs.
Dynamic user data: short TTL or explicit invalidation on write.
Aggregates: event-driven invalidation or background recompute.

When you describe a design, state exactly how keys are invalidated or how TTLs are chosen so reviewers can evaluate freshness guarantees.

Key Takeaway

Make invalidation explicit: choose TTLs and document events that trigger evictions to maintain correctness.
