Practice tasks and assessments

Design a multi-layered caching strategy for an online learning platform and answer targeted assessment questions.

Hands-on Activity
Use the template to recommend cache placement and TTL for Course Modules, User Progress, Popular Course List, and User Session Data.
Assessment Ideas
Multiple-choice and design explanation questions on consistency and placement trade-offs. Expect scenario-based justification.
Common Mistake
Relying exclusively on client caching for dynamic user-specific data, which breaks cross-device consistency.
Pro Tip
Match TTL to update frequency; prefer short TTLs or explicit invalidation for highly dynamic, user-specific data.
