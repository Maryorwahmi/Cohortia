Module 5 › Chapter 5.2 › Mini-Quiz
Question 1

Where should a shopping cart that must be consistent across devices be stored?

Answer: Distributed cache like Redis. Rationale: shared state and strong cross-server visibility.
Question 2

How to serve static assets globally with reduced origin load?

Answer: CDN + HTTP caching headers and ETag/versioning. Rationale: edge caching + client caching minimizes latency and origin hits.
Reflection

When answering design questions, list requirements first, then propose placement, TTL, and invalidation to support your choice.
