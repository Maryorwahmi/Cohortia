Module 5 › Chapter 5.2 › Design Activity

Activity: pick placements and TTLs

Course Modules (text/images)
Recommended: Client-side + CDN + ETag. TTL: long with revalidation or asset versioning on update.
User Progress (quiz scores)
Recommended: Distributed cache or direct DB with cache. TTL: short; use explicit invalidation on update to keep correctness across devices.
Popular Course List
Recommended: Distributed cache + client TTL. TTL: moderate (hours); regenerate nightly or on notable events.
User Session Data
Recommended: Distributed cache like Redis. TTL: tied to session expiry; invalidate on logout.
Instruction

For each item, explain why consistency, sensitivity, and update frequency led you to the chosen placement and TTL.
