Module 5 › Chapter 5.2 › HTTP Caching Headers
Example response headers
HTTP/1.1 200 OK
Content-Type: image/png
Cache-Control: public, max-age=86400
ETag: "img-v1-202409"
Last-Modified: Tue, 20 Apr 2024 10:00:00 GMT
Expires: Wed, 21 Oct 2025 07:28:00 GMT
  • • Cache-Control controls how long clients may reuse the resource.
  • • ETag provides a validator for conditional requests.
  • • Last-Modified is a simpler validator for resources that change rarely.
Practical guidance

Use long max-age and ETag for static assets that rarely change. When you need immediate updates, change asset names or ETags so clients fetch new versions instead of relying on TTL expiry.

Key Takeaway

Headers reduce bandwidth and latency, but versioning or ETag changes are needed to force immediate refreshes.
