Module 6 › Chapter 5.7 › Safety Notes
Over-caching
Caching low-value or high-volatility data wastes resources and increases invalidation surface area.
Stale data
Define acceptable staleness per data type; use explicit invalidation for critical fields.
Security note

Never cache sensitive data on insecure client layers. Encrypt transport and consider per-tenant caches for isolation.

Operational recommendations
Use message queues for invalidation, make events idempotent, and document key versioning to reduce accidental stale reads.
Common mistake
Relying on implicit invalidation across services without a clear event pipeline — this causes subtle consistency bugs.
