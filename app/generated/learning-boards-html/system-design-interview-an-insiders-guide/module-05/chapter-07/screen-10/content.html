Module 6 › Chapter 5.7 › Feed Service Cache
Personalized feed
Short TTL (5–10 minutes) or fan-out on write. Use LRU eviction. Explicit invalidation when users post.
Popular posts
Longer TTL (e.g., 1 hour), LFU eviction to retain frequently accessed items.
Key Takeaway

Treat personalized and global content differently: TTL, eviction and invalidation should reflect access shape and freshness needs.

Example: new post write flow
User posts → write to DB → push to followers' feed caches or invalidate their feed keys → update global trending cache if applicable.
Common mistake
Trying to cache every personalized view at long TTLs to save compute — this leads to stale personalized experiences and high invalidation costs.
