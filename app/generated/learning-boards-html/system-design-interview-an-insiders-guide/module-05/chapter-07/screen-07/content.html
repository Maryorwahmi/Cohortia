Module 6 › Chapter 5.7 › Cache Comparison
Client / CDN
Scope: global. Latency: lowest. Consistency: eventual via TTL/versioning. Use for images, static pages.
Distributed Cache
Scope: cross-instance. Latency: low. Consistency: medium (single source). Use for sessions, popular API results.
Local In-Memory
Scope: single instance. Latency: lowest. Consistency: weak unless invalidated. Use for per-instance hot results.
Practical rule
Default to distributed cache for shared mutable data. Use local caches only when you can reliably propagate invalidation events or accept some inconsistency temporarily.
Key Takeaway

Match cache type to scope and consistency needs. Reserve local caches for strict performance needs and plan invalidation pipelines.
