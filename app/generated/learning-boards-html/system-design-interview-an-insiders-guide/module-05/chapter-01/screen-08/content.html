Core Challenge

Cache Coherence and Data Staleness

Ensuring cached data remains up-to-date

The Consistency Problem

How do you ensure that data in the cache is always synchronized with the primary source of truth (e.g., database)?

Data Staleness

Occurs when the cache holds an outdated version of data that has been updated in the primary source. This can lead to users seeing incorrect information.

Trade-offs

Achieving strong consistency often comes at the cost of performance, as more complex mechanisms are needed to keep caches synchronized.

Example: User Profile Update

A user changes their email. If the old email is still in the cache, other parts of the system or other users might see the outdated information, causing confusion.

Key Takeaway

Cache coherence is a critical design challenge; failing to manage data staleness can undermine the reliability and trustworthiness of your system.
