Module 5 › Chapter 5.5 › What to Cache
Hierarchy of cache suitability
Static (best)
Images, videos, fonts, and versioned CSS/JS. Use long TTLs and immutable headers when files are versioned.
Semi-static (use with care)
Content that changes occasionally, like news articles. Use short TTLs and invalidate on major edits.
Dynamic (cautious)
Personalized pages generally should not be cached globally. Cache only safe fragments or use revalidation.
Example scenarios
  • All product thumbnails: cache aggressively with long TTLs and version filenames on change.
  • A blog homepage that updates hourly: use short TTLs or cache with max-age of a few minutes and purge on major content updates.
  • User dashboards: avoid global caching; cache per-session fragments only if safe.
Key Takeaway
Cache when content is widely shared and stable; otherwise choose short TTLs or selective caching strategies to avoid staleness.
