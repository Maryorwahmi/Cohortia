Module 5 › Chapter 5.5 › PoPs & Edge Servers
Core components
Point of Presence (PoP)
A regional edge location that receives user traffic and contains caching servers and routing logic.
Edge / Cache Server
Servers inside a PoP that store cached object copies, serve hits, and fetch misses from the origin.
Routing & Health
Traffic steering and health checks send requests to healthy PoPs and enable failover when needed.
How caches populate
Caches are demand-driven. When a regional PoP receives a request for an object it doesn't have, the edge server fetches it from the origin and stores it. Over time, frequently requested objects replicate across more PoPs based on regional popularity and cache capacity.
Pitfall
Assuming every PoP contains every object. Edge caches are finite and populate based on requests, so some objects might be available only in certain regions.
Key Takeaway
PoPs and edge servers bring popular content closer, but caching is demand-driven and regional visibility depends on usage patterns.
