Module 5 › Chapter 5.5 › Assessment Scenarios
Question 1
A global e-commerce company serves all content from a single North American data center. Which solution most improves delivery speed for worldwide users?
Answer: Deploy a CDN to serve static assets from edge locations.
Rationale: A CDN caches content near users to reduce geographic latency. Upgrading bandwidth does not solve distance-related latency.
Question 2
After deploying a critical bug fix to app.js, users still see the old version. What should you do?
Answer: Purge or invalidate the CDN cache for app.js so edges fetch the new file.
Rationale: Edge servers may be serving a stale cached copy; purging forces a fresh origin fetch.
