Activity: headers for common file types
Fill or explain these Cache-Control headers based on update frequency and whether files are versioned.
// index.html
Cache-Control: public, max-age=60, must-revalidate

// style.v1.css (versioned)
Cache-Control: public, max-age=31536000, immutable

// logo.png
Cache-Control: public, max-age=31536000, immutable

// api.js (frequent changes)
Cache-Control: no-cache, must-revalidate
Explanation
  • index.html: short max-age keeps structure fresh while revalidation ensures updates propagate.
  • Versioned files: long max-age and immutable are safe because filenames change on deploy.
  • Images: rarely changing images get long caching to save bandwidth and reduce origin egress.
  • Frequent scripts: use no-cache to force revalidation so users get the latest behavior during active development.
Pitfall
Long caching on non-versioned assets causes stale content; prefer versioning or shorter lifetimes.
