Module 5 › Chapter 5.5 › Glossary
Point of Presence (PoP)

Regional edge location that serves nearby users.

Edge Server

Cache server within a PoP that stores and serves objects.

Origin Server

Authoritative source of content fetched on cache misses.

Quick Summary
Use these terms to explain CDN designs clearly: PoP, edge server, origin, caching rules, and invalidation strategies.
