Module 5 › Chapter 5.5 › Invalidation & Versioning
Invalidation methods
Purge API
Programmatic removal of cached objects. Use for critical fixes but plan for cost and latency of purge operations.
Versioned URLs
Include version tokens in filenames so updated assets are treated as new by the CDN, avoiding purges.
Short TTLs
Use short max-age for content that updates frequently to rely on expiry rather than manual invalidation.
Example decision flow
  1. If file is versionable (CSS/JS/images), prefer versioned URLs and long TTLs.
  2. If file cannot change name, plan purge API usage for urgent updates and short TTL otherwise.
  3. For large fleets of files, schedule targeted purges or use cache-busting for bundles to limit the blast radius.
Key Takeaway
Plan for freshness: version when possible, purge for emergencies, and use TTLs to control typical freshness windows.
