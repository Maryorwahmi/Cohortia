Module 5 › Chapter 5.5 › Monitoring & Failover
Key metrics
  • Cache hit ratio: percentage of requests served by edge caches.
  • Regional latency: client-to-edge and edge-to-origin times.
  • Origin egress: bandwidth leaving origin when misses occur.
  • Error rates and HTTP 5xxs: indicate PoP or origin issues.
Practical safeguards
Test PoP failover behavior and measure latency when routing to alternate PoPs.
Stagger large purges or use versioned deployments to avoid origin traffic spikes.
Set alerts for sudden drops in hit ratio or surges in origin egress to catch misconfigurations quickly.
Pro tip
Simulate a purge in a staging environment to see origin impact before running it in production.
