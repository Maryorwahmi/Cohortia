Module 5 › Chapter 5.5 › What is a CDN?
Core definition

A CDN is a geographically distributed set of proxy servers that cache and serve copies of web content closer to end-users to reduce latency and improve reliability.

Analogy
Think of regional warehouses storing popular items so customers receive shipments faster than from a single factory.
Common misconception
CDNs don't replace the origin server. They cache copies; the origin remains authoritative and is contacted on cache misses.
Concrete examples
  • Product images and thumbnails delivered from an edge cache near the user.
  • Versioned CSS and JavaScript bundles cached aggressively to reduce repeat downloads.
  • Short-lived caching of news pages that update hourly, with a purge on important edits.
Key Takeaway

A CDN is a system of regional caches that speeds delivery and improves reliability while leaving the origin as the single source of truth.
