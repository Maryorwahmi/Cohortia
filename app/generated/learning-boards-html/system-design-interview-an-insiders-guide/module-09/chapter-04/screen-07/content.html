Comparison: A vs B
Group A
Original experience. Baseline metrics collected for comparison.
Group B
New variant. Measure the same metrics and compare lift or regression.
Design rules
  • Define a primary metric before starting.
  • Persist user assignment to avoid crossover noise.
  • Run the test until statistical significance or a predefined time limit.
Example: Add to Cart color test

Toggle between green and blue button across cohorts, track conversion rate as the key metric, and compare cohorts after the test window completes.

Pitfall

Changing targeting or mixing experiments can invalidate results—keep tests isolated and stable.
