Targeting patterns
Selectors
  • User ID or account ID
  • Geography or region
  • Named segments (beta, internal)
  • Percentage buckets
Rollback design

Predefine metric thresholds and ensure the control plane disables flags quickly and consistently across services.

Example: hash-bucket percent rollout

Hash user ID to a number between 0 and 99. If hash < 5, user is in the 5% cohort. This keeps assignment stable and reproducible.
