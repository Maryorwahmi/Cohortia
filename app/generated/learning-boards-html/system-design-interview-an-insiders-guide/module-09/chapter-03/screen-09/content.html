Module 09 › Chapter 3 › Choreography example: Travel booking
Sequence
  1. BookFlightCommand → FlightBookingService reserves flight and emits FlightReservedEvent.
  2. FlightReservedEvent → HotelBookingService attempts hotel reservation and emits HotelReservedEvent or HotelReservationFailedEvent.
  3. On failure, FlightBookingService listens for HotelReservationFailedEvent and executes CancelFlightReservation compensation.
Design tip
Implement compensation as a business operation and ensure handlers are idempotent and well-instrumented.
Starter pseudo-code (conceptual)
# Service: FlightBookingService
on BookFlightCommand:
  begin local transaction
  reserve_flight_in_db()
  commit
  publish Event('FlightReservedEvent', {booking_id, user_id})

on HotelReservationFailedEvent:
  // compensation handler
  begin local transaction
  cancel_flight_reservation()
  commit
  publish Event('FlightReservationCancelledEvent', {booking_id})

# Service: HotelBookingService
on FlightReservedEvent:
  begin local transaction
  try_reserve_hotel()
  if success:
    commit
    publish Event('HotelReservedEvent', {booking_id})
  else:
    rollback
    publish Event('HotelReservationFailedEvent', {booking_id, reason})
Note: This is conceptual code showing event handlers and compensation handlers. Make operations idempotent and log events for tracing.
