Module 09 › Chapter 3 › Saga pattern overview
Saga process
1
Local transaction commits
2
Publish event or respond to orchestrator
3
If failure occurs, run compensations in reverse
Design checklist
  • List local transactions and their compensations.
  • Ensure operations are idempotent where possible.
  • Decide retry policies and failure notifications.
Concrete example

Checkout: Order created, payment processed, inventory reserved. If inventory reservation fails, compensations include refunding payment and cancelling the order. Notice compensation is a business step, not a DB rollback.

Key Takeaway

Design both forward steps and reversing steps; eventual consistency is the desired end state.
