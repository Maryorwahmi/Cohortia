Module 09 › Chapter 3 › Learning Objectives
Applied Skills

Practice converting business flows into Saga sequences, enumerate compensations, and choose the coordination style that best matches observability and coupling requirements.

Skill
Compose Saga sequences
Write the steps and the event/command flow that carry state between services.
Skill
Design compensations
Define how each local change can be logically reversed on failure.
Skill
Select coordination style
Decide between choreography’s low coupling and orchestration’s centralized visibility.
Skill
Plan recovery
Anticipate coordinator failures, retries, and user-facing notifications.
Mini mnemonic
Sequence → Event → Compensate

Remember: perform local work, publish an event or respond to a command, and if later steps fail, run compensations to restore invariants.
