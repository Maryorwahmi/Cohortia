Objective practice
  • Choose Token Bucket for controlled bursts like photo uploads; justify why bursts improve user experience.
  • Choose Sliding Window Counter when edge bursts must be avoided and memory must remain bounded.
  • Describe Redis INCR + EXPIRE sequence to atomically count and expire per-window keys.
Common assessment prompts
Explain why fixed windows allow double bursts and propose a better alternative. Sketch a Redis sequence for a fixed window counter and explain race condition avoidance.
Verifier
Checklist you can use: name algorithm, state storage, placement, and one safety mitigation. Deliver a short reasoning for the chosen limits.
