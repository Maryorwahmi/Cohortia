Module 9 › Chapter 9.5 › Rate Limiting vs Throttling
Definition

Rate Limiting

Enforce how many requests a client can make in a time window. Measured per user, IP, or key.

Concrete example
An API allows 60 requests per minute per API key. Extra requests are denied until the window allows more.
Key takeaway
Use rate limiting to protect throughput and shape traffic over time.
Definition

Throttling

A broader control that limits concurrency or resource usage, such as number of active jobs or CPU use per tenant.

Concrete example
Limit to three concurrent image-processing jobs per user to avoid spikes in CPU and memory usage.
Common misconception
Throttling is not only about request counts—it's about protecting resources and concurrency as well.
