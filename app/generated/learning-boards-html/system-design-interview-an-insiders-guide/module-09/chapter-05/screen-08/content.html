Module 9 › Chapter 9.5 › Sliding Window Log
How it works

Timestamp log per request

Store timestamps for each request and trim older entries outside the window to compute the current count. This avoids window-edge bursts.

When to use
Use when precise enforcement is required, such as security-sensitive endpoints or strict quotas.
Costs and trade-offs
  • High memory usage per active client; can be expensive at scale.
  • Accurate, avoids artifacts from fixed windows; higher operational overhead.
Key Takeaway
Choose Sliding Window Log where correctness is more important than memory and complexity cost.
