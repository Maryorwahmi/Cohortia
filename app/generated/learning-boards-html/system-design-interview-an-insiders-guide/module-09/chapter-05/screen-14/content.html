Module 9 › Chapter 9.5 › Combining Algorithms and Layers
Pattern overview
Use Token Bucket at the gateway for user-friendly burst allowance. Inside services, enforce concurrency throttles and queue limits to bound resource use. For high-accuracy needs, use sliding-window checks.
Gateway
Per-key Token Buckets in Redis to control volume and permit bursts.
Service
Concurrency caps and worker pools to protect CPU and memory.
Example flow
Client request → Gateway Token Bucket check (Redis) → Forward if allowed → Service concurrency throttle → Background processing or rejection.
Key Takeaway
Layered controls yield better protection without sacrificing legitimate bursts; always monitor and tune.
