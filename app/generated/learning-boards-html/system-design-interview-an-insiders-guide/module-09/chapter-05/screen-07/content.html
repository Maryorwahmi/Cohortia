How it works

Fixed windows with counters

Maintain a counter keyed by the window for each client. Increment and compare to the allowed limit; reset when the window ends.

Example
Limit 10 per 60 seconds. A user can make 10 requests at second 59 and 10 at second 61, causing a rapid burst.
Corner case
Edge bursts double the effective rate within a short interval; this can overload heavy endpoints.
Mitigations and alternatives
  • Use Sliding Window Counter for a smoother, approximate sliding window.
  • Use Sliding Window Log for precise counting at the cost of memory.
  • Combine with Token Bucket when burst allowance is desirable.
Key Takeaway
Fixed Window is easiest, but watch out for edge bursts when request timing matters.
