Module 9 › Chapter 9.5 › Sliding Window Counter
Mechanics

Two counters + interpolation

Keep counters for current and previous fixed windows, and estimate the rolling count by time-weighted interpolation between them.

When it helps
  • When memory is constrained and exact per-request logs are impractical.
  • When you need better edge behavior than fixed windows, but full precision is not necessary.
Example interpolation
If the previous window has 40 requests and the current window has 20, and you are halfway through the current window, estimate the last-window count as 0.5*20 + 0.5*40 = 30 for the rolling period.
Key Takeaway
Sliding Window Counter is a practical middle ground: better accuracy than fixed windows while remaining memory-efficient.
