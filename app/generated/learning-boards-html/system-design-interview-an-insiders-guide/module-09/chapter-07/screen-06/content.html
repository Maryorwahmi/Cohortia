Core Concept › Paxos: Roles and Two-Phase Agreement
Paxos roles
  • Proposer: suggests a value with a proposal number.
  • Acceptor: promises and accepts proposals, forming the durable quorum.
  • Learner: learns the chosen value once a quorum accepts.
Two phases
1) Prepare: proposer asks for promises. 2) Accept: proposer sends accept request and acceptors accept if they promised.
Example walkthrough
// P1 proposes X with number 5
P1 -> Acceptors: prepare(5)
Acceptors -> P1: promise(5, lastAccepted?)
P1 -> Acceptors: accept(5, X)
Acceptors -> Learners: accepted(5, X)
Common mistake
Treating Paxos as a single leader protocol. Paxos's generality allows many variants and leader election is layered on top in implementations.
Key Takeaway
Majority promises cause overlapping quorums so later proposers must honor previously accepted values, preserving safety.
