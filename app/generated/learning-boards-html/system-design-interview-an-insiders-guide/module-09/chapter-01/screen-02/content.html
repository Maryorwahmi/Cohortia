Learning Objectives

Build competence in designing and reasoning about event-driven systems and event-sourced data models.

01
Explain EDA benefits

Describe how publishing events creates loose coupling and scales independent services. Recognize when async communication improves resilience.

VERIFIED COMPETENCY MILESTONE
02
Differentiate messaging patterns

Distinguish publish-subscribe from queue patterns and explain when each fits system needs like fan-out versus point-to-point work.

VERIFIED COMPETENCY MILESTONE
03
Use Event Sourcing

Explain how storing immutable events creates an append-only history and supports auditability and temporal state reconstruction.

VERIFIED COMPETENCY MILESTONE
04
Apply CQRS patterns

Identify how separating reads and writes through CQRS pairs with events to scale and optimize projections for queries.

VERIFIED COMPETENCY MILESTONE
