Module 9 › Chapter 9.1 › Key Concepts
Event-Driven Architecture
Services publish facts as events so others can react without direct coupling.
Event Sourcing
All changes stored as immutable events; replay events to rebuild state and audit history.
CQRS & Projections
Separate writes (events) from reads (projections) to scale and optimize query paths.
Summary takeaway
EDA and Event Sourcing grant auditability, flexibility, and scale but require operational practices like idempotent handlers, snapshotting, versioning, and observability to remain reliable.
