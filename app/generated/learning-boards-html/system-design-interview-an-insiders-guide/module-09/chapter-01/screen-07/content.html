Definition

Commands

A command is a request to perform an action. It may be validated or rejected and is not an immutable fact.

Example
PlaceOrderCommand validates input and either produces events or returns errors.
Definition

Events

An event is a fact: OrderCreated means the order was created. Events are immutable and suitable for an append-only store.

Misuse to avoid
Publishing commands as events breaks replay semantics and couples producers to specific actions.
