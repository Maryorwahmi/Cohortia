Core Concept

Event Sourcing

Store every change as an event. Rebuild aggregates by replaying events. Use snapshots to avoid long replays.

Why it helps
  • Complete audit trail and temporal queries.
  • Natural integration by publishing stored events.
  • Supports complex business logic and compensation flows.
Reconstruction pattern
OrderAggregate.load_from_events(order_id, event_stream): order = OrderAggregate(order_id) for event in event_stream: order.apply(event) return order # Use snapshots to store state periodically and only replay events after the last snapshot.
Key Takeaway
Events are the source of truth; read models are projections rebuilt from those events.
