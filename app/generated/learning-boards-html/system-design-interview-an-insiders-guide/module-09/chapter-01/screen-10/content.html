Snapshots & Replay

Take snapshots periodically so rebuild starts from the latest snapshot and replays only newer events.

When to snapshot
Based on event count, rebuild time, and acceptable recovery latency.
Event versioning
Include version fields and transformation handlers so older events can be interpreted safely.
Checklist
  • Decide snapshot cadence and retention.
  • Implement migration handlers for old event versions.
  • Test replay paths in staging regularly.
Common mistake
Ignoring versioning until it breaks replays. Plan versioning from day one.
