Core Concept

What is EDA?

Events are immutable facts. Producers publish, brokers route, consumers subscribe and react asynchronously.

Key bullets
  • Loose coupling: producers do not call consumers directly.
  • Asynchronous communication improves responsiveness and throughput.
  • Design handlers to be idempotent for safe retries and replays.
Key Takeaway

Treat events as facts, not instructions. That preserves replayability and decouples services.

Publish-subscribe example
OrderCreated publishes to topic orders.created
InventoryService, FulfillmentService, and NotificationService subscribe and react independently.
Misconception
Do not use events as commands. Events represent past facts; commands request future actions.
