Module 9 › Chapter 9.8 › What is Serverless and FaaS?
Definition
Serverless & FaaS
Serverless abstracts provisioning and operations to the provider. FaaS runs small, stateless functions on demand, triggered by events and billed per execution.
Concrete example
An upload event triggers a function that resizes images and writes thumbnails to storage.
Common misconception
Serverless does not remove servers; it changes who manages them.
Key Takeaway

Focus on functions and externalize state; accept provider ownership of runtime and scaling.

Illustration
Event source
S3 upload, HTTP, or stream message
FaaS function
Stateless handler that runs briefly
Storage / DB
Externalize state to scale reliably
Use this definition as a lens: when you design, choose serverless if the workload benefits from on-demand execution, automatic scaling, and reduced ops effort.
