Module 9 › Chapter 9.8 › Key Concepts — Terms to Master
Cold Start
Initialization latency when a new instance is created for a function.
Vendor Lock-in
Dependence on provider-specific features that complicates migration.
Statelessness
Functions should not rely on in-memory state between invocations; use external storage for durability.
Final takeaway

Explain serverless choices by weighing operational gains against latency, portability, and observability trade-offs.
