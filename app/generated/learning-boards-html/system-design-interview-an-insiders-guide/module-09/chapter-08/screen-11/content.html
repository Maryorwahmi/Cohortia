Module 9 › Chapter 9.8 › Designing the Serverless Image Pipeline (Conceptual Task)
Task steps
1. Identify components: S3, Lambda functions, DynamoDB, event notifications.
2. Define event flow: upload → object-created → resize → thumbnail stored → image-resized event → metadata update.
3. Assign responsibilities: validation and transformation to resize function; persistent records to metadata function.
4. Plan retries: dead-letter queues and idempotent handlers.
Design check: ensure each function is idempotent and has clear failure semantics for retries and dead-lettering.
Example responsibilities
resizeImageFunction
Download original, resize to thumbnail, upload thumbnail, emit a resized event or invoke next function.
updateMetadataFunction
Consume resized events, write original and thumbnail URLs and timestamps to DynamoDB, implement retries.
Error handling
Use DLQs, logs, and alerts for manual remediation of failed images.
Reflection: if the batch job runs for hours, serverless may be unsuitable without orchestration; split work into short functions or use an orchestrator for long workflows.
