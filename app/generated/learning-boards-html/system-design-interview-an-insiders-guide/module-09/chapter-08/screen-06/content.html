Module 9 › Chapter 9.8 › Benefits vs Trade-offs
Benefits
Reduced operational overhead
Provider handles servers, patching, and availability.
Automatic scaling
Scale from zero to many instances automatically.
Cost efficiency
Pay only for execution time, often in 100-millisecond increments.
Use benefits to justify serverless for bursty workloads, fast prototyping, and event-driven pipelines.
Trade-offs & Mitigations
Cold starts
Initial invocation latency when the platform provisions a new execution environment.
Vendor lock-in
Provider-specific APIs and event models make migration effortful.
Debugging & state
Ephemeral functions require tracing and external state services.
Design tip: match workload and risk tolerance — use mitigation patterns like provisioned concurrency, orchestrators, and standardized event contracts where needed.
