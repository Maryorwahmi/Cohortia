Process steps
1

HTTP, object create, stream record, or timer
2
Provision or reuse instance

3
Handler executes
Stateless execution, calls external services as needed
4
Scale as traffic grows
Platform creates parallel instances automatically
Key Takeaway

Expect automatic scaling but design to reduce initialization work and externalize state.

Example scenario
API request via gateway
API Gateway forwards request to a function. The function reads data from a database and returns a response. If traffic spikes, the platform creates more instances to handle concurrent requests.
Misconception
Scaling is automatic but not free or instantaneous. New instances take time and incur cost during the ramp-up.
Design tip: minimize heavy startup logic and use lazy initialization so warm instances serve the majority of requests with lower latency.
