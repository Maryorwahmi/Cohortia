Module 9 › Chapter 9.8 › Observability & Debugging
Principles
Use structured logs and attach a correlation ID to each event so traces can be assembled across functions. Emit metrics for invocation counts, latencies, error rates, and queue depth.
Tracing
Correlate spans across functions to measure end-to-end latency.
Logging
Centralize logs for replay and forensic analysis of failures.
Alerting
Set thresholds on retries, error spikes, and queue depth.
Debugging tip: make events replayable and keep handler logic testable so you can reproduce and isolate faults outside the provider runtime.
Example checklist
Correlation ID
Propagate a consistent ID across functions and logs.
Centralized logs
Aggregate logs for search and replay of events.
Replay capability
Store events so you can reprocess them after fixing bugs.
Operational question: how will you trace a request from API Gateway through multiple functions to the database and back?
