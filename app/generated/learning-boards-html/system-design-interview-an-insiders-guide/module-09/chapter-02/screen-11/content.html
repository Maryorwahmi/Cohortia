Module 9 › Chapter 9.2 › Mutual TLS and Authorization
Mutual TLS (mTLS)
mTLS ensures both sides of a connection authenticate each other using certificates. Sidecars automate certificate lifecycle and handshake so services communicate securely by default.
Operational advantage
Automatic certificate provisioning and rotation removes a major source of manual security errors across many services.
Authorization policies
Control plane policies declare which service identities can call which endpoints. This enforces least privilege across the mesh at the network level.
Misconception check
Network-level authorization is powerful, but application-level business authorization is still required for fine-grained rules tied to user data or roles.
