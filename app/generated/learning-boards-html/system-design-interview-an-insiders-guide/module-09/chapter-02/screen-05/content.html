Module 9 › Chapter 9.2 › What is a Service Mesh?
Core definition
Dedicated layer for service-to-service communication

It provides traffic control, security, and automatic telemetry without modifying application code.

Why it matters
Centralizing policy enforcement reduces inconsistency and makes it faster to introduce platform-wide changes like mutual TLS or new routing rules.
Feature cards
Traffic management
Supports routing rules, canary releases, and weighted splits to control who sees new versions.
Observability
Automatically collects metrics, logs, and traces for service communication.
Security
Enforces mTLS and authorization policies between services without code changes.
Key takeaway
A service mesh standardizes how services communicate, enabling consistent policies across many services with minimal application changes.
