Module 9 › Chapter 9.2 › Data Plane vs Control Plane
Data Plane (Sidecars)
  • Intercepts and routes traffic between services in real time.
  • Enforces retries, load balancing, timeouts, and TLS.
  • Collects telemetry for each request.
Operational note
Because sidecars run per instance, policy changes propagate immediately across the fleet when the control plane updates configuration.
Control Plane
  • Distributes routing and security policies to the data plane.
  • Aggregates telemetry and exposes configuration interfaces for operators.
  • Does not carry user traffic but coordinates enforcement.
Concrete behavior
Update a VirtualService in the control plane and the sidecars will immediately start routing new traffic according to the updated weights.
