Module 9 › Chapter 9.2 › Key Concepts
Service Mesh
An infrastructure layer that handles service-to-service communication, providing routing, security, and observability without code changes.
Sidecar Pattern
A proxy deployed alongside each app instance to intercept and manage traffic in the same network namespace.
Data Plane
The network proxies (sidecars) that intercept and route traffic, enforcing policies at runtime.
Takeaway
Use a mesh to centralize cross-cutting concerns when you need consistent retries, TLS, and telemetry across many services; introduce it only when the operational benefits outweigh added complexity.
