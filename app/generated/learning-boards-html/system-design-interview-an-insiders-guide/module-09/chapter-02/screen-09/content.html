Module 9 › Chapter 9.2 › Traffic Management: Canaries and Routing
Core capabilities
  • Weighted routing for canaries and A/B testing.
  • Traffic shifting to new versions without redeploying code.
  • Fault injection and request mirroring for advanced testing.
Concrete example
Route 90% of traffic to v1 and 10% to v2 to validate stability under production load while limiting user impact.
Monitoring & rollback
During a canary, watch error rates, p95 latency, and resource usage for the v2 subset. If any signal crosses thresholds, revert traffic weights to return all users to the stable version.
Why it matters
Traffic control minimizes blast radius and lets you validate real-world behavior before a full release.
