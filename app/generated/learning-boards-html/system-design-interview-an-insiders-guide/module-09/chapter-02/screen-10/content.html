Module 9 › Chapter 9.2 › Observability through the Mesh
What the mesh records
  • Request counts, error rates, and latency percentiles per route.
  • Distributed traces that connect calls across services for per-request timing.
  • Logs and metadata emitted by sidecars for policy enforcement events.
Concrete monitoring
Track p95 latency and error rate for the canary subset. Use traces to find which downstream service added unexpected delay.
Best practices
Correlate mesh telemetry with application business metrics. Use alerting on service-level SLOs derived from mesh signals, and instrument only business-critical code paths inside services.
Misconception check
Mesh telemetry simplifies service-level visibility but is not a substitute for application-specific metrics like user actions or revenue events.
