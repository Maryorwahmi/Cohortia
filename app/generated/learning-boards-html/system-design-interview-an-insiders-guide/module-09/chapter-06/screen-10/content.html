Module 9 › Chapter 9.6 › Bulkhead Implementation
Thread pool bulkheads
Allocate dedicated thread pools per external dependency. Each pool caps concurrent outbound calls and prevents one slow dependency from blocking others.
Example allocation: Payment 10 threads, Notification 5, Reporting 5.
When a pool is full, requests should fail fast or use a bounded queue and fallback paths.
Connection and instance bulkheads
Separate connection pools per dependency to avoid socket exhaustion. For stronger isolation, run critical services on dedicated instances so resource contention does not cross service boundaries.
Tradeoff: isolation uses more memory and threads; measure and balance costs against outage risk.
Monitor: pool saturation, queue length, and rejected request counts to decide when to resize.
