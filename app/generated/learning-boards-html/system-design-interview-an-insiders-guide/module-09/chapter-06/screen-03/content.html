Design checklist
  1. Map external dependencies and risk levels.
  2. Wrap costly calls with a circuit breaker to fail fast.
  3. Partition resources with bulkheads for high-risk integrations.
  4. Monitor breaker states and resource saturation in real time.
Tuning notes
  • Too low a failure threshold → false opens; too high → no protection.
  • Reset timeout gives the dependency time to recover before probing.
  • Success threshold in Half‑Open avoids flipping closed on a single successful call.
  • Bulkheads reduce blast radius but increase resource footprint; use for critical paths.
