Module 9 › Chapter 9.6 › State Transitions
Transition steps
Closed
Allow calls, increment failure counts, and trip to Open when threshold is met.
Open
Reject immediately for the reset timeout and preserve local resources.
Half‑Open
Allow controlled test requests. Close if tests meet success threshold, otherwise return to Open.
Pro tip

Log timestamps for transitions and emit metrics for failure_count, reset_timeout, and success_count for debugging and alerts.

Visual process
Use these metrics to decide thresholds: failures per minute, sliding window, reset timeout, and success threshold. Adjust them based on observed failure modes and service recovery time.
Design choice: failure window — short windows react quickly but are noisy; long windows are stable but slower to protect.
Design choice: reset timeout — give the downstream a chance to recover without trying too early.
Design choice: success threshold — require multiple good probes so the service is reliably back.
