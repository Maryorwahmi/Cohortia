Module 9 › Chapter 9.6 › Design Checklist
Step-by-step
  1. Map synchronous, critical dependencies and their SLAs.
  2. Wrap expensive calls with a circuit breaker to fail fast.
  3. Partition resources with bulkheads for high-risk integrations.
  4. Provide fallbacks: cache, degrade gracefully, or user-friendly errors.
  5. Instrument state and resource metrics; alert on saturation and frequent transitions.
Concrete example
OrderProcessingService: add a circuit breaker around InventoryService calls, allocate a dedicated thread pool for those calls, and return cached inventory or a retryable error when the breaker is open. Monitor inventory pool saturation and breaker state to tune parameters.
Practical tip

Start with conservative protection and increase availability if metrics show false positives. Use libraries for production-grade behavior and focus on observation and iteration.
