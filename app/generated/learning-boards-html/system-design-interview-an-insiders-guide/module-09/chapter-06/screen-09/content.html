Module 9 › Chapter 9.6 › Bulkhead Pattern
What it is
Bulkheads isolate resources like threads and connections so a failure or blocking call in one area cannot deplete resources used by others.
Use cases: external APIs, long-running tasks, or components with variable latency.
Forms: dedicated thread pools, connection pools, or separate instances.
Key Takeaway

Bulkheads contain failures by isolating resources; apply them where the tradeoff in resources is justified by criticality.

Concrete allocation example
Allocate one thread pool of 10 threads for PaymentGateway, 5 threads for NotificationService, and 5 for ReportingService. If PaymentGateway blocks, only its 10 threads are impacted.
Benefit: other critical paths continue to function despite isolated failure.
Pitfall: too many small pools increases memory and management overhead.
