Apache Druid

Druid stores time-segmented data and separates ingestion, historical storage, and query brokering. This enables sub-second queries on high-cardinality data and makes it suitable for interactive dashboards.

When to pick Druid
  • Interactive, sub-second OLAP queries over recent data.
  • High-cardinality dimensions and fast ingestion pipelines.
ClickHouse

ClickHouse is a high-performance columnar DB optimized for aggregations at scale. MergeTree engines and ORDER BY clauses guide data layout to accelerate queries like group-bys and time-bucketed aggregates.

When to pick ClickHouse
  • Very large append-only datasets with heavy aggregation needs.
  • SQL-first workflows requiring extreme query throughput.
Example ClickHouse schema and query
CREATE TABLE website_events (
    timestamp DateTime,
    user_id String,
    event_type LowCardinality(String),
    page_url String
) ENGINE = MergeTree()
ORDER BY (timestamp, user_id);

-- Count unique users per minute
SELECT
    toStartOfMinute(timestamp) AS minute,
    count(DISTINCT user_id) AS unique_users
FROM website_events
WHERE timestamp >= now() - INTERVAL 1 HOUR
GROUP BY minute
ORDER BY minute;
