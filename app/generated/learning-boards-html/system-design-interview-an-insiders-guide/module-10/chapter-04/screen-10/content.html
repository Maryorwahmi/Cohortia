ClickHouse table and query
CREATE TABLE website_events (
    timestamp DateTime,
    user_id String,
    event_type LowCardinality(String),
    page_url String
) ENGINE = MergeTree()
ORDER BY (timestamp, user_id);

-- Query: Count unique users per minute
SELECT
    toStartOfMinute(timestamp) AS minute,
    count(DISTINCT user_id) AS unique_users
FROM website_events
WHERE timestamp >= now() - INTERVAL 1 HOUR
GROUP BY minute
ORDER BY minute;
  • ORDER BY (timestamp, user_id) clusters data by time then user, reducing scanned blocks for time-window queries.
  • Denormalize page metadata into the event row to avoid joins during aggregation.
  • For very large datasets, consider partitioning by time ranges at ingestion to keep recent segments small.
Key Takeaway

Align physical ordering with common time-window and grouping queries to dramatically improve query speed.
