Why choose a search engine

When you need flexible queries over semi-structured data, fast text search, and exploratory dashboards, inverted indexes make Elasticsearch a powerful tool.

Use cases
  • Log analysis and operational monitoring.
  • Exploratory filtering and ad-hoc text queries.
Elasticsearch indexing example
POST /log_events/_doc
{
  "timestamp": "2023-03-15T10:00:00Z",
  "service": "web-app",
  "level": "INFO",
  "message": "User login successful",
  "user_id": "U456",
  "ip_address": "192.168.1.100"
}

GET log_events/_search
{
  "query": {
    "bool": {
      "must": [
        { "match": { "service": "web-app" }},
        { "range": { "timestamp": { "gte": "now-1h" }}}
      ]
    }
  },
  "aggs": {
    "events_by_level": { "terms": { "field": "level.keyword" }}
  },
  "size": 0
}
Watch out

Inverted indexes can increase storage usage for high-cardinality fields; plan mappings and storage accordingly.
