Module 10 › Chapter 10.4 › Key Concepts
Columnar Database
Stores data by column to speed aggregations and compression.
Time-Series DB
Optimized for time-indexed writes, retention, and windowed aggregation.
Search Engine
Uses inverted indexes for fast filtering and flexible queries over logs.
Summary Takeaway

Always start from the queries: choose columnar for aggregations, TSDB for windowed metrics, and search engines for log exploration. Plan indexing and retention accordingly.
