Learning Objectives

Each objective is actionable: design, implement, or evaluate a specific non-functional requirement for real-time analytics pipelines.

01
Scale components horizontally and vertically
Decide when to add nodes versus increase capacity. For example, add Kafka partitions and worker nodes to raise throughput while avoiding single-machine limits.
VERIFIED COMPETENCY MILESTONE
02
Design for high availability and disaster recovery
Specify redundancy, failover, and cross-region replication so services stay online and data is recoverable after an outage.
VERIFIED COMPETENCY MILESTONE
03
Implement fault-tolerance across layers
Use checkpointing, retries, dead-letter queues, and automatic task restarts to prevent data loss and enable recovery.
VERIFIED COMPETENCY MILESTONE
04
Evaluate CAP trade-offs for real-time use cases
Decide when to favor availability and partition tolerance for dashboards, or when strong consistency is required for critical counters.
VERIFIED COMPETENCY MILESTONE
