Fault Tolerance Mechanisms

Layered defenses keep the pipeline running and make failures observable and recoverable.

Producer retries
Retry transient network errors. Use exponential backoff to avoid amplifying load during outages.
Dead-Letter Queues
Move permanently failing messages to a DLQ for later inspection to keep the primary stream flowing.
Checkpointing & state restore
Persist processor state periodically so tasks can restart from the last consistent point and avoid data loss.
Worker failover
Frameworks restart failed tasks on healthy nodes. Measure restart time and plan for increased lag during recovery.
