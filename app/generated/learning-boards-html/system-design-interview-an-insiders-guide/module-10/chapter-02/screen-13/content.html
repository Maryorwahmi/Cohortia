Module 10 › Chapter 10.2 › Durability and Fault Tolerance
Key durability mechanisms
  • Disk persistence so messages survive broker restarts.
  • Replication across brokers to tolerate node failures.
  • Consumer offsets so reading progress is recoverable.
Operational considerations
Set replication factors and retention based on recovery time objectives and acceptable storage costs. Ensure monitoring alerts for under-replicated partitions.
Key Takeaway

Durability requires disk-backed storage, replication, and careful consumer commit semantics to balance duplicate processing and lost progress.
