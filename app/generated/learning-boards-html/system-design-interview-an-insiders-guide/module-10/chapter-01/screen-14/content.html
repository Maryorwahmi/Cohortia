Module 10 › Chapter 10.1 › Common Mistakes
Process

Avoid these pitfalls

Follow a four-step pattern that interviewers expect: clarify, quantify, design, and justify.

Mistake
Jumping to technology choices without numerical requirements for latency and throughput.
Fix
Ask targeted questions and state explicit metric targets before selecting components.
Mistake
Ignoring retention and reprocessing needs.
Fix
Specify retention windows and propose tiered storage when appropriate.
Final tip

Present a minimal viable architecture first, then show an upgrade path for stricter metrics. This demonstrates both pragmatism and depth.
