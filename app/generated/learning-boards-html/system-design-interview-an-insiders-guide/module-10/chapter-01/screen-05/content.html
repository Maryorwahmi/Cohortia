Use cases and drivers

Associate each use case with the primary non-functional priorities and a brief justification.

Fraud Detection
Freshness: sub-second. Priority: latency & accuracy. Example: stop a fraudulent charge before completion.
E-commerce Personalization
Freshness: a few seconds. Priority: throughput and individual session state. Example: recommend products while user browses.
IoT Monitoring
Freshness: seconds to tens of seconds. Priority: throughput, resilience. Example: trigger device alerts on anomalies.
Practical prompt
For each use case name the single most important non-functional metric and explain why it drives architecture.
Misconception
Not all "real-time" use cases demand the same latency—designs should match the use case's specific tolerance for freshness and cost.
Quick mapping
When asked, respond with: use case → freshness target → approximate event scale → key trade-offs.
