Module 10 › Chapter 10.1 › Functional Requirements
Core Concept

Events, Aggregations, Queries

Define the events to capture, the transformations required, and the query patterns users will run.

Event Types
List required fields, cardinality, and whether order matters for processing logic.
Transformations
Windowing semantics, enrichment, joins, or sessionization that must run in streaming.
Example

Requirement: "Show active users in last 5 minutes by region." This implies sliding or tumbling windows, grouped aggregates, and timely state management.

Misconception
Assuming all aggregates can be computed cheaply at low latency — joins and large-group aggregations often increase latency and memory needs.
Quick Template
Event: type, schema. Transformation: window size, keys. Query: expected filters and groupings.
Takeaway
Write functional requirements as concrete statements that connect directly to processing and storage choices.
