Module 10 › Chapter 10.7 › Minimize Data Transfer
Workflow
  1. Define the metric and required fields.
  2. Implement server-side projection and filtering.
  3. Use pagination or virtual scroll for tables.
  4. Cache small, frequently-used results and indicate freshness.
Example
<!-- Request: top error counts -->
GET /errors/top?start=now-5m&limit=10
Response: [{"code":500,"count":42},{"code":404,"count":9}]

<!-- No raw logs sent unless user drills down -->
Client-side aggregation tips
  • Cache results with TTL and freshness metadata.
  • Limit client aggregation to small datasets to avoid memory pressure.
  • Display freshness indicators so users trust the data.
Key Takeaway

Reduce payloads by sending only what answers the question and use client aggregation only when datasets are small and stable.
