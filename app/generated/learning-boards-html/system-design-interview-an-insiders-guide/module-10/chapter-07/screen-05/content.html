Module 10 › Chapter 10.7 › Low Latency Interaction
Latency optimization flow
1. Identify critical panels
2. Add caching or short materialized views
3. Optimize queries and indexes
4. Measure perceived latency and iterate
Example
For a Kafka producer rate chart, serve recent 10s-aggregates from a fast store or cache, and let the chart fetch finer-grained data only on zoom or drilldown.
Common mistake
Optimizing client rendering while leaving slow backend queries is ineffective when the data must be recomputed each request.
Supporting details
  • Use caches with short TTLs for highly dynamic panels.
  • Index columns used in filters and group-bys to speed queries.
  • Consider a two-tier approach: fast recent store + archival queries for history.
Key Takeaway

Perceived responsiveness is achieved by reducing backend work for the common interactions and serving pre-computed or cached responses.
