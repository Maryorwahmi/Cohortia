Module 10 › Chapter 10.7 › Interactivity and Dynamic Queries
Interaction architecture
Filter / time range
Uses cached aggregates when available; falls back to query for custom ranges.
Drilldown
May require higher resolution data; label operations that are heavy and provide feedback to users.
Example scenario
A dashboard shows a 5-minute moving average of messages/sec. When a user changes the time range to the last 30 seconds, the dashboard requests a higher-resolution aggregate. If that view is not precomputed, the UI displays a loading hint and optionally a message that higher resolution data is slower to generate.
Pro tip
Design default interactions to hit precomputed endpoints and offer an explicit action for deeper, slower queries.
Key Takeaway

Map frequent interactions to fast endpoints, and make heavy queries explicit so users understand any delay.
