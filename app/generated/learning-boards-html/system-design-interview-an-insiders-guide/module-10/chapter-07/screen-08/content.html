Module 10 › Chapter 10.7 › Clarity and Chart Selection
Chart types and when to use them
Line chart
Time-series trends, e.g., messages/sec
Bar chart
Category comparisons
Single stat / Gauge
Current state, thresholds, and alerts
Design rules for clarity
  • One clear purpose per visualization.
  • Label axes and units; avoid ambiguous colors.
  • Use color for meaning, not decoration; reserve red for critical thresholds.
Example mapping
Producer rate → line chart. Consumer lag → gauge with thresholds. Error rate → single stat with alert. Broker disk usage → per-broker gauge or bar chart.
Key Takeaway

Pick chart types that answer the user’s question directly; avoid exotic visuals that obscure the message.
