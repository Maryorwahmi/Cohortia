Rendering choices
SVG: great for interaction and small charts
Canvas / WebGL: better for many points and high-update rates
Virtualization: crucial for long tables and many panels
Performance tips
  • Batch updates and avoid full-dashboard re-renders on small changes.
  • Prefer canvas for dense time-series with many points.
  • Use virtualization for long lists and tables.
Example decision
A high-frequency line chart showing 1-second samples is a candidate for canvas rendering to avoid DOM overhead on every tick.
Key Takeaway

Select rendering approaches that match update frequency and data density; measure before optimizing.
