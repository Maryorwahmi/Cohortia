Table & upsert
-- Example: Materialized view table
CREATE TABLE daily_unique_users_by_country (
  report_date DATE,
  country VARCHAR(255),
  unique_user_count BIGINT,
  last_updated TIMESTAMP,
  PRIMARY KEY (report_date, country)
);

Key point: write the computed value as the new stored aggregate. Avoid incremental DB-side increments without coordination.
Stream logic summary
  • Maintain state per key (for example, a set or a sketch for uniques).
  • Periodically compute the current aggregate for the key.
  • Emit an upsert that writes the computed value to the MV.
Misconception: "UPSERT equals incremental counter updates." UPSERT replaces the stored value with the computed value from processor state, which makes retries safe.
