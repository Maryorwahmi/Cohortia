Module 10 › Chapter 10.5 › Incremental updates
Stream-to-MV process
1. Consume
Read events from the topic and extract key fields like user_id, country, and timestamp.
2. Aggregate
Update stateful counters or sketches keyed by (date, country).
3. Emit
Periodically compute the current aggregate and prepare an UPSERT payload.
4. Upsert
Write the computed value into the materialized view table using an upsert to replace or insert rows.
Idempotency
Write the full computed aggregate rather than applying deltas so retries produce the same final state.
Common mistake
Incrementing a DB counter per event without state in the processor leads to double counts on retries.
Practical tip
Batch updates and emit periodically to reduce DB write amplification while keeping freshness acceptable.
