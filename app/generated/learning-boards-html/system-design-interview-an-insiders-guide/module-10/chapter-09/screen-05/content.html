Module 11 › Chapter 10.9 › Key Metrics
Metrics by layer
Ingestion (Kafka/Kinesis)
  • Producer throughput (messages/sec, bytes/sec)
  • Consumer lag (messages behind head)
  • Broker health: CPU, memory, disk I/O
  • Error rates from producers
Stream Processing (Flink/Spark)
  • Processing throughput (events/sec)
  • Event latency (arrival → completion)
  • Backpressure and checkpoint success/duration
  • Task health: CPU, memory, GC
Storage (Druid/ClickHouse/ES)
  • Ingestion rates (records/sec)
  • Query latency P95/P99 and throughput
  • Disk usage, replication status
API Layer
  • Request rate, error rate, latency P95/P99
  • Cache hit ratio, active connections
Practical guidance
  • Always include percentiles (P95, P99) — averages hide tail behavior.
  • Label metrics with topic, job, partition, or node for targeted queries.
  • Correlate metrics with logs and traces when diagnosing anomalies.
Key Takeaway

Pick metrics that expose throughput, latency, resource health, and replication. Percentiles and labels make them actionable.
