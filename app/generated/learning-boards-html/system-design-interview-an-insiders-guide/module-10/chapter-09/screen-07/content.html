Module 11 › Chapter 10.9 › Distributed Tracing
What tracing gives you
  • End-to-end timing for an individual request or event.
  • Span-level breakdown to see which service consumed time.
  • Context tags to link spans to topics, jobs, or request IDs.
Implementation hints
Use OpenTelemetry to instrument services, propagate trace IDs over Kafka messages, and visualize traces with Jaeger or Zipkin. Sample traces to control volume.
Concrete scenario

An API call to build a feed shows high P99 latency. A trace reveals 80% of time spent in a storage query span. The fix: optimize query or add a cache for that query pattern.

Misconception check
Tracing doesn't remove the need for metrics; it provides per-request context when metrics point to a problem.
Key Takeaway

Use tracing to find which span causes latency; instrument high-value flows and propagate IDs through async boundaries like Kafka.
