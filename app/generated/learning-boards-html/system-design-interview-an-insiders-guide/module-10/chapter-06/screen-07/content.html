Module 10 › Chapter 10.6 › gRPC for internal communication
Definition

gRPC and streaming

Use gRPC for efficient internal RPCs and streaming telemetry between services. It offers compact serialization and built-in streaming patterns.

When to use
Internal aggregators, streaming updates, and high-throughput service calls.
When not to use
Public dashboard integrations or tooling that expect human-readable HTTP APIs.
Design tip: combine gRPC internally with a REST/GraphQL facade for external clients to get both performance and accessibility.
