Module 10 › Chapter 10.6 › RESTful APIs for analytics
Definition

REST for predefined metrics

Model metrics as resources and use standard HTTP methods. Best when clients request fixed aggregates frequently.

  • Simple shape: one metric per endpoint makes caching straightforward.
  • Stateless requests mean horizontal API scaling is easy.
  • Include auth tokens and rate limits at the gateway for safety.
Key Takeaway

REST endpoints are ideal for high-frequency, fixed-shape metrics where caching reduces load.

Code Example
GET /api/v1/metrics/page_views?interval=5m&page=/homepage HTTP/1.1
Host: analytics.example.com
Authorization: Bearer <token>

Response 200 OK
{
  "metric_name": "page_views",
  "interval": "5m",
  "page": "/homepage",
  "value": 12345,
  "timestamp": "2023-03-15T10:05:00Z"
}
Caching note
Cache key: metric:page_views:interval:5m:page:/homepage. TTL chosen to be slightly less than aggregation window to balance freshness.
