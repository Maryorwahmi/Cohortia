API Endpoint Structure
GET /api/v1/campaigns/{campaign_id}/metrics?interval=10m&metric_type=clicks
Params: interval, metric_type, limit (optional)
This structure keeps requests predictable and easy to cache by metric and time window.
Caching & Security
Cache key: campaign:{campaign_id}:clicks:10m:current_minute_bucket. TTL: 60s. Auth: Bearer token. Authorization: RBAC mapping token claims to allowed metric sets.
Avoid accepting arbitrary SQL or exposing raw DB clients. Use controlled parameters and curated metrics only.
