Module 10 › Chapter 10.6 › Indexing & Query Rewriting
Indexing
Ensure columns used in WHERE, ORDER BY, and GROUP BY are indexed or part of the table's sort keys for fast scans.
  • Columnar DBs use sort and partition keys rather than classic B-tree indexes.
  • Measure with explain plans to confirm index effectiveness.
Query Rewriting
Rewrite long-range queries to target pre-aggregated tables or daily materialized views to avoid scanning raw events.
Example
Request: last 6 months of DAU. Rewritten to query daily_dau_aggregates instead of raw events for a 180x improvement in scan size.
Tip: combine both approaches — index the high-cardinality filters and rewrite queries that span large windows to aggregated tables.
