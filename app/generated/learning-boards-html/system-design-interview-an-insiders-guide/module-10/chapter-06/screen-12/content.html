Module 10 › Chapter 10.6 › Integrating with visualization tools
Integration Patterns
Direct DB connection
Tools query ClickHouse or Elasticsearch directly; easy but bypasses API controls like caching and RBAC mapping.
Curated API endpoints
Expose endpoints shaped for the tool: time-series endpoints for Grafana, tabular endpoints for Superset, with auth enforced.
Recommendation
Prefer curated API endpoints when you need to control freshness, transform results, enforce RBAC, or apply caching for heavy dashboards.
