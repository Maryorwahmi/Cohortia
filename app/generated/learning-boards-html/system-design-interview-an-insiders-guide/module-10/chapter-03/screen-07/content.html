DefinitionTime Semantics & Watermarks
Time semantics
Event time: timestamp from the event source.
Processing time: when the system processes the event.
Ingestion time: when the event enters the pipeline.
Watermarks & lateness

Watermarks indicate the progress of event time. Pair watermarks with allowed lateness to accept reasonably late events and update windows when needed.

Example: 30s late event

If an event arrives 30 seconds after its window closed, a watermark strategy with a 1-minute lateness window can still include it; otherwise the event is dropped or routed to a late-data sink.
