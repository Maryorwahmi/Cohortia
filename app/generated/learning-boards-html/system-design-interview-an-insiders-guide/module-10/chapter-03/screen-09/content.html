Tumbling Window (Java)
// Flink Tumbling Window for counting events
import org.apache.flink.streaming.api.environment.StreamExecutionEnvironment;
import org.apache.flink.streaming.api.windowing.time.Time;

public class FlinkTumblingWindow {
    public static void main(String[] args) throws Exception {
        final StreamExecutionEnvironment env = StreamExecutionEnvironment.getExecutionEnvironment();

        env.fromElements(
                "event1", "event2", "event3", "event4", "event5"
            )
            .keyBy(value -> "fixed_key")
            .timeWindow(Time.seconds(5))
            .sum(1)
            .print();

        env.execute("Flink Tumbling Window Example");
    }
}
Why this matters

KeyBy groups state, timeWindow defines finite slices, and checkpointing lets Flink restore state consistently after failures.

Pro tip

Tune watermark strategies to balance latency and completeness when events arrive out of order.
