Hands-onDesign: Unique-User Metric
Implementation Steps (High-level)
  1. Read from Kafka topic user_events and parse JSON events.
  2. Extract event_time and assign watermarks for event-time progress.
  3. Define a 1-minute tumbling window based on event_time.
  4. Maintain per-window state of user_ids (deduplicate) or use approximate sketches.
  5. Emit the unique user count when the window closes and persist the result.
Late arrival strategy
Use watermarks with allowed lateness >30s, update windowed results on late arrivals, or route very late events to a late-data sink for offline reconciliation.
State sizing tip
Bound state using TTLs or approximate structures like HyperLogLog if cardinality is very large.
