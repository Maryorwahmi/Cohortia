Core Concept Events, Streams, Windowing, State
Annotated primitives
Event
Atomic record, e.g. { user_id, event_type, timestamp } used to drive computation.
Stream
Unbounded sequence of events arriving over time; continuous processing required.
Windowing
Tumbling, sliding, and session windows provide finite scopes for aggregation on a stream.
State
Persistent local data (counts, sets) used to compute across multiple events in a stream.
Window types
Tumbling: fixed, non-overlapping windows.
Sliding: overlapping windows with a slide interval.
Session: grouped by inactivity gaps for flexible sessions.
Example: unique users

For a 1-minute tumbling window, maintain a set of user_ids in state for each window key, deduplicate incoming events, and emit the set size when the window closes.
