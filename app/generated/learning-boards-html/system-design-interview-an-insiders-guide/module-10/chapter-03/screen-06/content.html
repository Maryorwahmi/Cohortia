Process FlowWindowing Patterns
Numbered patterns
1.
Tumbling windows
Fixed, non-overlapping intervals. Use for simple periodic aggregates: e.g., 1-minute unique-user counts that align to minute boundaries.
2.
Sliding windows
Fixed-size windows that move by a slide interval. Use for running averages or dashboards updated more frequently than the window size.
3.
Session windows
Dynamic windows that group events by inactivity gaps. Use for sessionization and user activity grouping.
Example mapping
Requirement: update average response time every 5s over last 30s → Sliding window of 30s with 5s slide.
Common mistake
Choosing session windows when metrics are periodic increases complexity and state churn. Prefer simple tumbling or sliding windows if your metric cadence is fixed.
