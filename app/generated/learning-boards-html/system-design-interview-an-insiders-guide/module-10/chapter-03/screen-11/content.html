DefinitionKafka Streams
What it provides
  • Client library for building stream apps on Kafka topics.
  • Local state stores backed by Kafka changelogs for recovery.
  • Good fit for embedding processing into services.
Example use

A microservice that updates per-user counters in response to events and writes results back to Kafka topics.

Deployment note

Kafka Streams runs as part of your application — scale by scaling the app processes and rely on Kafka for durability.
