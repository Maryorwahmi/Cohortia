Security Misconfiguration
Defaults and extra features create unnecessary attack surface.

Audit defaults: credentials, storage access, and public endpoints. Remove features you don't need and close open storage.

Return generic client errors while logging details internally so attackers cannot learn about internals from responses.

Least Privilege
Scope permissions to the minimum required for each role and service account.
  • Define roles narrowly and assign service accounts only the permissions needed.
  • Automate role creation and include permission reviews in CI/CD to avoid drift.
  • Rotate credentials and use secret managers rather than embedding secrets in code.
