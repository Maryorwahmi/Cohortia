Preventing Injection
A short process to handle input safely.
1. Validate
Enforce types, length, and formats for all inputs.
2. Sanitize
Apply encoding where user content is rendered in clients.
3. Parameterize
Use prepared statements and driver parameters for DB access.
4. Test
Add injection attack cases to automated tests and scans.
Concrete example
Instead of building SQL with string concatenation, pass variables as parameters so the database treats them as data not code.
Check
Do your tests include crafted payloads that try to change query structure?
