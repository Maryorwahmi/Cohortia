Module 7 › Chapter 7.5 › Learning Objectives
01 — Compare mechanisms

Describe API keys, Basic Auth, OAuth 2.0 and OIDC and when each is appropriate. Knowing this prevents poor protocol choices in distributed systems.

VERIFIED COMPETENCY MILESTONE
02 — Map OAuth roles

Understand resource owner, client, authorization server, and resource server so you can defend design decisions in interviews.

VERIFIED COMPETENCY MILESTONE
03 — Read and validate JWTs

Inspect header, payload, and signature; validate claims like exp, iss, and aud to ensure tokens are valid for the context.

VERIFIED COMPETENCY MILESTONE
04 — Avoid common mistakes

Recognize insecure secret storage, missing HTTPS, and deprecated flows; plan mitigations such as short token lifetimes and secure refresh mechanisms.
