Scenario 2: Client Credentials (curl)
Simulate obtaining an access token from the Authorization Server using the client credentials flow. Use the template below as a concept demonstration to explain the exchange during an interview.
curl -X POST \
  https://auth.example.com/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials&client_id=my_service_client&client_secret=super_secret_password"
The Authorization Server will return a JSON with access_token, token_type, expires_in, and scope. Explain how you will validate and store the token, and how you would revoke it if needed.
Key Takeaway

Hands-on practice reinforces that decoding is for inspection; cryptographic validation and claim checks are what make tokens trustworthy in production systems.
