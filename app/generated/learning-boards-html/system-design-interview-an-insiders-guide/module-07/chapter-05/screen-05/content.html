API Keys
A secret string issued to a client. Sent with each request and used to identify the calling application.
Pros
  • Easy to implement
  • Works well for machine-to-machine calls
Cons
  • No user context
  • Hard to revoke at scale without state
  • Often stored insecurely
Concrete scenario
A logging pipeline exposes an API for ingest; each partner gets an API key. Use IP restrictions and a central registry so compromised keys can be rotated quickly.
Implementation notes
  • Store keys in a secrets manager, not in source control.
  • Log usage and implement automated rotation where possible.
  • Consider short-lived keys or exchange for short-lived tokens at a gateway.
Key Takeaway

Use API keys for simple app identity but design for secure storage, rotation, and revocation to limit damage from leaks.
