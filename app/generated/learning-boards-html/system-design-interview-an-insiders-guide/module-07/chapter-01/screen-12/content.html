Module 7 › Chapter 7.1 › Error Handling
Status codes
Use standard codes to communicate class of error: 4xx for client, 5xx for server.
400 Bad Request — malformed input
401 Unauthorized — missing or invalid credentials
404 Not Found — resource absent
Structured errors
Provide machine-readable codes and human messages so clients can react and show helpful UI.
Example: { "code": "USER_NOT_FOUND", "message": "User 123 not found" }
