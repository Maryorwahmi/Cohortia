Module 7 › Chapter 7.1 › Key Concepts
REST
Resource-based, HTTP methods, cache-friendly.
GraphQL
Client-specified queries reduce round trips but complicate caching.
gRPC
Protobuf + HTTP/2 for efficient, typed internal RPCs.
Key Takeaway

Choose the style that fits client control, performance needs, and operational complexity. Design endpoints to be idempotent where retries happen, and keep servers stateless to scale reliably.
