Module 7 › Chapter 7.1 › API Versioning
Common strategies
URI: /v1/users — visible and straightforward, but couples version with resource identity.
Header: X-API-Version: 1 — cleaner URIs, less discoverable for simple clients.
Query: /users?api-version=1 — easy but can affect caching unless queries are normalized in caches.
Content negotiation: Accept: application/vnd.myapi.v1+json — RESTful but implementation-heavy.
Guidance
Choose a strategy that suits your clients and caching layer, and document deprecation and migration steps.
Example decision: Use URI versioning for public, visible changes and header negotiation for minor format changes.
