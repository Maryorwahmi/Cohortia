Idempotency defined
An operation producing the same result whether called once or multiple times with same inputs.
DELETE /items/123 → idempotent: item removed or already absent.
POST /orders → non-idempotent by default; repeated calls create duplicates.
Implementation: support idempotency keys or use PUT with client IDs.
Concrete example
Bank transfer example using idempotency key.
PUT /transfers/{idempotencyKey}
{
  "fromAccount": 12345,
  "toAccount": 67890,
  "amount": 100.00
}
Server stores the idempotencyKey and returns existing transfer for repeated calls.
