Module 7 › Chapter 7.1 › Payload Trade-offs
Over-fetching
Clients receive fields they don’t use, wasting bandwidth and processing.
REST example: GET /users returns full profiles but mobile app only needs names and avatars.
Under-fetching
Clients must make multiple requests to compose the needed data.
REST example: client must call /users then /users/{id}/posts; GraphQL can fetch both in one query.
Design note
If clients’ needs vary widely and you can manage schema complexity, GraphQL reduces round trips. Otherwise, design targeted REST endpoints or opt-in expansions to balance caching and simplicity.
