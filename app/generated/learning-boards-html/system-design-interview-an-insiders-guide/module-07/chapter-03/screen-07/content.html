Module 7 › Chapter 7.3 › Aggregation vs BFF
Comparison

Shared Aggregation

Gateway composes responses from multiple services into one. Best for common shared views across clients.

Pros
Fewer client round trips; centralized caching and logging.
Cons
May become overloaded if aggregation logic is heavy and universal.

Backend for Frontend (BFF)

A client-specific gateway that shapes payloads, auth, and caching for one client type, minimizing over-fetching and tailoring performance characteristics.

Pros
Fine-grained control per client; reduces client-side logic.
Cons
Requires managing multiple gateway layers and more deployment artifacts.
