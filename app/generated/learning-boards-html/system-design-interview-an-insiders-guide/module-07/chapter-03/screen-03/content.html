Routing example to present

Show a mapping: GET /api/v1/products → Product Service; POST /api/v1/users → User Service. Explain how path and method guide routing rules.

Auth offloading demo

Describe token validation at the gateway, then header injection of user id for downstream services to consume without revalidating.

Rate limit policy

Sketch a per-client quota: anonymous 60 requests/min, authenticated 500 requests/min, with early rejection and informative response codes.

High-availability plan

Point to redundancy: multiple gateway instances across zones, load balancer fronting them, health checks and auto-scaling policies.
