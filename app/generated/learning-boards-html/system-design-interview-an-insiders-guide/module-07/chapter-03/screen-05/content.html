Process Flow

Core functions

  1. Request routing — map path/method/headers to services.
  2. Auth & authorization — validate tokens and apply initial checks.
  3. Rate limiting — enforce per-client quotas to protect backends.
  4. Caching — store frequently-read responses to cut load.
  5. Transformation — adapt payloads and strip sensitive fields.
  6. Aggregation — combine multiple responses for a single client view.
Key Takeaway

Enable only the functions you need at the gateway to minimize added latency. Push business-heavy transformations to services when appropriate.

Example: mobile storefront

A product page needs listing, inventory, and reviews. The gateway aggregates responses from three services into a single JSON object so the mobile client performs one request and renders faster.

When to cache
Cache immutable or slowly changing data at the gateway to avoid frequent backend hits, but avoid caching personalized or highly dynamic data.
Common mistake
Enabling heavy payload transformation for every request can turn the gateway into a performance bottleneck. Measure processing cost first.
