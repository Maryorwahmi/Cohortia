Module 7 › Chapter 7.3 › What is an API Gateway?
Core Concept

API Gateway — definition

A reverse proxy and single entry point that centralizes routing and cross-cutting concerns for microservices, simplifying client integration.

Traffic-cop analogy
Inspects incoming requests and directs them to the correct destination while enforcing rules.
Misconception check
It does not replace business logic; it coordinates and protects services.
Key Takeaway

Gateway = boundary + coordinator. Keep business logic inside services; use the gateway for cross-cutting policies and client optimization.

Concrete example
A mobile app needs product details and recommendations. Instead of three separate calls, the gateway can return a single composed response with product, inventory, and suggestions, reducing round trips and client logic.
What the gateway does
  • Routes requests by path and method.
  • Validates tokens and injects user context.
  • Applies rate limits and caches responses.
Check your understanding

If a service must own authentication decisions, the gateway should still perform initial token validation and forward verified context rather than duplicating identity checks in every service. Why is that more reliable?
