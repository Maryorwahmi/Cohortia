Mock services and Nginx config

Run two simple mock services and route by path in Nginx. Below is the configuration snippet to test locally.

http {
    upstream user_service {
        server localhost:8081;
    }

    upstream product_service {
        server localhost:8082;
    }

    server {
        listen 80;
        server_name localhost;

        location /api/users {
            proxy_pass http://user_service/users;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
        }

        location /api/products {
            proxy_pass http://product_service/products;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
        }

        location / {
            return 404 "Not Found from Gateway";
        }
    }
}
Steps to validate
  1. Start mock User and Product services on ports 8081 and 8082.
  2. Place the Nginx snippet in your nginx.conf and test syntax.
  3. Reload Nginx and run curl to /api/users and /api/products to see proxied JSON.
Misconception check
This demonstrates routing and header forwarding but lacks policy engine, discovery, and HA features needed in production.
Practice task
After verifying routing, add a simple rate-limiting directive and observe rejected requests to understand throttling behavior.
