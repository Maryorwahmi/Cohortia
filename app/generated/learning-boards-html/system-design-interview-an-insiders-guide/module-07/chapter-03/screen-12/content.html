Hierarchy

Typical deployment hierarchy

  1. Load balancer (global edge)
  2. Multiple Gateway instances (across zones)
  3. Service discovery integration (Kubernetes DNS, Consul, etc.)
  4. Backend service instances
Health and discovery
Discovery gives instance locations; health checks and circuit breakers prevent routing to unhealthy instances. Use short TTLs for discovery caches when instances scale frequently.
Example: Kubernetes
Gateways integrate with the cluster service DNS to resolve service names. When deployments scale, DNS records and endpoints update automatically.
Misconception check
Don't assume discovery equals reliability; always combine discovery with active health checks and graceful failover logic.
