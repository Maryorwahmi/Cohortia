Module 7 › Chapter 7.3 › Products & Trade-offs
Nginx / Envoy
High throughput, flexible, often used with custom plugins. Good for teams that run their own infra.
Managed Clouds
AWS API Gateway, Azure API Management provide managed policies, monitoring, and reduced ops burden at potential cost and lock-in.
Kong / Spring Cloud
Plugin ecosystems and extensibility for teams that want richer policy integration with familiar stacks.
Selection criteria
  • Performance and latency overhead.
  • Policy features needed: auth, WAF, rate limiting, transformation.
  • Integration with service discovery and platform tooling.
  • Operational cost and team expertise.
