Module 7 › Chapter 7.3 › Key Concepts
API Gateway
A single, intelligent entry point that centralizes routing and policies.
Core Functions
Routing, auth, rate limiting, caching, transformation, aggregation.
Trade-offs
SPOF, added latency, complexity, operational cost; mitigate with redundancy and lightweight policies.
Summary

Treat the gateway as a programmable boundary: centralize cross-cutting concerns, design for high availability, and choose patterns such as BFF or shared aggregation based on client needs.
