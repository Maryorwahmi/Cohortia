Module 8 › Chapter 7.8 › Pattern Comparison
Polling
Simple, firewall-friendly, but wastes bandwidth and increases latency between updates.
Example:
IoT device that cannot accept inbound requests.
Webhooks
Low-latency server-to-server push; requires client endpoint, retries, signing.
Example:
Payment gateway notifying merchants of transaction state.
Server-Sent Events
Browser-friendly unidirectional streaming; supports reconnection and works over HTTP.
Example:
Live scoreboards and stock tickers.
Fallback strategy
Combine approaches: use webhooks for server integrations, SSE for browsers, and fall back to polling when long-lived connections or public endpoints are not available.
