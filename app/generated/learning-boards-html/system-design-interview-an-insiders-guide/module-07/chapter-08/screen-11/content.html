Module 8 › Chapter 7.8 › Logging & Metrics
Structured log fields
  • timestamp, level, service, request_id, trace_id
  • context: user_id, resource_id, operation
  • error details: error_code, message, stack when safe
Ensure logs are centralized and searchable so a trace_id quickly yields related log lines across services.
Key metrics to collect
  • Request rate and error rate per endpoint.
  • Latency histograms (p50/p95/p99) for user-facing endpoints.
  • Resource metrics: CPU, memory, queue depth.
Tie alerts to SLOs: alert when error rate or p99 latency breaches thresholds that impact customers.
