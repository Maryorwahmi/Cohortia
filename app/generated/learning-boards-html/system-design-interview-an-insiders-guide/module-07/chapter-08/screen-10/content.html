Trace anatomy
  • Trace ID: a unique identifier for the request across services.
  • Span: an operation with start/end time, service name, and tags.
  • Critical path: the longest sequence of spans determining request latency.
Example: a feed request shows a cache lookup span, database read span, and fan-out queue publish span. If the DB read dominates, traces point you there for optimization.
When presenting in an interview, show how you correlate a trace id to logs and metric spikes to build a complete incident timeline.
Operational notes
Sample traces to reduce cost while keeping tail latency visibility.
Propagate trace ids in HTTP headers and RPC metadata.
Use distributed tracing tools to visualize the critical path.
