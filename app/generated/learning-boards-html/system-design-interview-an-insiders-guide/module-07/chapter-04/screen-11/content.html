Core Concept › Gateway Caching
Benefits
  • Reduced backend load — fewer origin requests.
  • Faster response times for clients.
  • Lower network traffic and improved resilience during origin outages.
Cacheable example
Public product catalog responses are good candidates for full response caching, yielding significant performance improvement.
Cache-Control & validation
Use Cache-Control headers like max-age and s-maxage to control TTL. Use ETag and Last-Modified to validate cache entries with conditional requests.
Caveat

Avoid caching sensitive or rapidly changing data unless you implement strong invalidation guarantees.
