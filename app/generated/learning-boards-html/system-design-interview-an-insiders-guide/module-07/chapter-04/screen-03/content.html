Module 7 › Chapter 7.4 › Objectives — Lab Steps
01 — Rate limiting check
Simulate rapid requests for a single user; count accepted versus rejected and confirm a 429 response is returned when the limit is exceeded. This verifies gateway-level enforcement.
Mnemonic: request meter that flips to red when full.
VERIFIED COMPETENCY MILESTONE
02 — Algorithm comparison
Switch between fixed window and token bucket and observe how bursts are handled differently. Note memory costs and burst allowance when tokens are available.
Mnemonic: compare two dials — one tight, one with a small reserve.
VERIFIED COMPETENCY MILESTONE
03 — Distributed limit
Run multiple gateway processes that use Redis INCR and EXPIRE to coordinate a global counter, ensuring consistent enforcement across instances.
Mnemonic: all gateways reading from a shared scoreboard.
VERIFIED COMPETENCY MILESTONE
04 — Cache validation
Configure Cache-Control and TTL, add a product, and validate that event-driven invalidation or TTL expiry keeps clients seeing fresh data when required.
Mnemonic: a freshness tag on cached responses.
