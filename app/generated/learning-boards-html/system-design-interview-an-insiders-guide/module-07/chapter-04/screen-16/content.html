Distributed Rate Limiting
Coordinate counters across instances using Redis so the limit is global, not local to one gateway.
Gateway Caching
Store responses to reduce backend load, but design keys, TTL, and invalidation carefully to avoid stale or incorrect data.
Common Pitfalls
Over-aggressive caching, insufficient invalidation, caching error responses, and misconfigured limits that harm legitimate users.
Final takeaway

Combine algorithm choice, distributed coordination, and careful caching policies to make APIs both reliable and fast under real-world load patterns.
