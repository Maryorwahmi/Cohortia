Starter script (concept)
import redis
import time

r = redis.Redis(host='localhost', port=6379, db=0)

RATE_LIMIT_PER_WINDOW = 5
WINDOW_SIZE_SECONDS = 10

def check_rate_limit(user_id):
  key = f"rate_limit:{user_id}"
  pipe = r.pipeline()
  pipe.incr(key)
  pipe.expire(key, WINDOW_SIZE_SECONDS)
  current_count, _ = pipe.execute()
  if current_count > RATE_LIMIT_PER_WINDOW:
    print(f"User {user_id}: Rate limit exceeded ({current_count}/{RATE_LIMIT_PER_WINDOW}). Request rejected.")
    return False
  else:
    print(f"User {user_id}: Request allowed ({current_count}/{RATE_LIMIT_PER_WINDOW}).")
    return True

# Simulation loop omitted for brevity
This script uses a Redis pipeline to atomically increment and set the expiration so the window resets automatically.
Lab steps
  1. Start Redis locally.
  2. Run the script and observe the first five requests succeed and later ones return rejected within the window.
  3. Wait for the window to reset and confirm the counter resets.
  4. Run two instances of the script to confirm Redis enforces a global count across processes.
Extension

Modify the script to implement a simple token bucket using DECRBY and EXPIRE or a Lua script to atomically check and deduct tokens.
