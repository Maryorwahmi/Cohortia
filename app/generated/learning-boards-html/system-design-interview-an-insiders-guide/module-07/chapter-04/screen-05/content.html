Comparison › Fixed Window Counter
How it works
Maintain one counter per client for each fixed window. Increment on request, reset when window expires.
  • Pros: simple, low memory.
  • Cons: bursty behavior at window borders.
Concrete scenario
Limit of 100/minute allows bursts of nearly 200 across a window boundary if the client times requests to both windows.
Visual
Common mistake

Assuming fixed window enforces a strict per-second average. It can permit short bursts that violate short-term expectations.
