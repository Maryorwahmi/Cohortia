Comparison › Sliding Windows
Sliding Window Log
Store a timestamp per request. On new requests remove timestamps older than window and count remaining entries for enforcement.
  • Pros: highly accurate, handles bursts cleanly.
  • Cons: high memory and storage operations for large volumes.
When to use
Use when accuracy is critical and request volume per client is manageable for storing timestamps.
Sliding Window Counter
Keep counts for current and previous fixed windows and weight them to approximate a sliding window. Lower memory than log, better smoothing than fixed window.
  • Pros: lower memory footprint, smoother than fixed window.
  • Cons: approximation, not perfectly precise.
Pro tip

When memory is a concern, sliding counter offers a practical balance between correctness and operational cost.
