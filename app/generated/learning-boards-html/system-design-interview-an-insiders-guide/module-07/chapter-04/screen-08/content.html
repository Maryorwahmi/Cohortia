Leaky bucket explained
Incoming requests queue up and are processed at a fixed leak rate. Overflow results in dropped requests.
Example
Backend accepts 2 requests/second; the bucket leaks at that rate. Bursts are smoothed but may experience added latency while queued.
When to use
Use when you need strict output pacing and can tolerate queuing or dropping when capacity is exceeded.
Visual
Common mistake

Confusing leaky bucket with token bucket; remember leaky bucket enforces output pacing while token bucket allows bursts up to stored tokens.
