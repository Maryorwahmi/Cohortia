Lab Walkthrough › Token Bucket & Caching Exercises
Token bucket hints
Use a Redis key for tokens, initialize to capacity, and refill at intervals. Prefer Lua scripts to check-and-decrement tokens atomically to avoid race conditions under concurrency.
Test
  1. Implement atomic decrement or Lua script.
  2. Run bursts and observe how tokens allow short spikes.
  3. Adjust refill rate and capacity to match desired burst tolerance.
Caching exercises
Set Cache-Control headers: e.g., Cache-Control: public, max-age=300 and return ETag. Use curl to request and then conditional request with If-None-Match to observe 304 responses. Implement event-driven invalidation by sending a cache clear call from the backend when data changes.
Common mistake
Do not cache 5xx responses and ensure Vary headers are respected for per-header variants.
Key Takeaway

Hands-on experimentation with token buckets and caching headers is the fastest way to internalize trade-offs and tuning choices.
