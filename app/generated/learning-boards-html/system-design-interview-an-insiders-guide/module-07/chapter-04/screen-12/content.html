Process Flow › Caching Strategies
Strategies
  • TTL: simple expiry after max-age.
  • Event-driven invalidation: origin notifies gateway to invalidate keys on change.
  • Stale-while-revalidate: serve stale content while fetching fresh data asynchronously.
Storage choices: in-memory for speed, distributed (Redis/Memcached) for consistency across instances. Key design: include URL path, relevant query params, and Vary headers such as Accept-Language.
Common mistakes
  • Caching 5xx errors accidentally.
  • Not invalidating when data changes.
  • Failing to vary on headers and serving wrong variants.
Key Takeaway

No single strategy fits all. Combine TTLs with event-driven invalidation and thoughtful key design to keep caches useful and correct.
