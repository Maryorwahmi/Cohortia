Module 7 › Chapter 7.6 › Common Mistakes
Trusting client input
Always re-verify authorization server-side; clients can be tampered with.
Only gateway checks
Gateways lack data context. Services must perform final checks for resource ownership.
Hardcoded permissions
Keep policies configurable to reduce redeploy cycles and improve audits.
Insufficient logging
Log failures with context for detection and post-incident analysis, but avoid logging secrets.
Role explosion
If role counts grow, evaluate ABAC or PBAC to express context without many roles.
Service account excess rights
Give service identities minimal permissions and use separate accounts for high-risk tasks.
