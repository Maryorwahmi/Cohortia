Role

Coarse-grained filtering at the edge

Gateway validates tokens, checks role-based routes, and rejects obvious violations early to save backend work.

It can also add a signed user context to the request to reduce repeated identity lookups.

Example
Allow only requests with role 'admin' to hit /admin/*; otherwise return 403.
Limits
Gateways can't evaluate ownership or data-sourced conditions. Those checks require service context.
Design tip
Use gateway checks to reduce noise and add signed contexts, but keep the final decision where the data lives.
