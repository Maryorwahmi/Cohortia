Module 7 › Chapter 7.6 › Service Layer Checks
Why here

Accurate decisions using local context

Services know resource ownership, sensitivity, and workflow state and therefore can apply exact rules that gateways cannot.

Pattern: gateway authenticates and forwards signed context; service validates and applies fine-grained rules.

Code example (pseudocode)
// Service receives user context
if resource.owner_id == user.id:
  allow 'edit'
else if 'admin' in user.roles:
  allow 'edit'
else:
  deny 'edit'
Key Takeaway
Place business-rule authorization inside the owning service and make authorization logic testable and auditable.
