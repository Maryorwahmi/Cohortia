Module 7 › Chapter 7.6 › Key Concepts
Authorization
Determines what an authenticated user or service is allowed to do.
RBAC
Roles map to permissions. Best for stable organizational roles.
ABAC
Attribute-driven decisions that allow per-instance rules.
Takeaway
Match the model to your needs: RBAC for stable roles, ABAC/PBAC for dynamic, contextual access and auditing.
