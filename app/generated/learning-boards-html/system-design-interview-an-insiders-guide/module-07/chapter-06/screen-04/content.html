Module 7 › Chapter 7.6 › Authentication vs Authorization
Definition

Authentication proves identity. Authorization decides allowed actions.

Authentication methods: passwords, tokens, certificates. Authorization uses roles, attributes, and policies.

Example: JWT proves identity; a separate check must verify if deletion is permitted for that JWT holder.

Misconception: a successful login is not permission to perform all actions.

Key Takeaway

Treat authentication and authorization as separate stages; enforce authorization on the server where context is trustworthy.

Concrete Example
User logs in, receives JWT with roles. A document service checks whether JWT subject equals document owner before allowing edits.
Common Mistake
Trusting client claims or relying solely on gateway checks leads to unauthorized access.
Pro Tip
Keep authorization logic near the data owner for final decisions; use gateway checks only for broad filtering.
