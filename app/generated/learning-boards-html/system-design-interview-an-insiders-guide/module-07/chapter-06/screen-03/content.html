Module 7 › Chapter 7.6 › Skills You'll Practice
Practice tasks
  1. List permissions for document and user resources and map them to roles.
  2. Write an ABAC policy that allows edits only when the user owns the resource.
  3. Sketch an enforcement plan: gateway for coarse checks, service for fine-grained checks.
  4. Design a JWT claim structure for passing role or limited permissions to services.
Assessment
Short design review
Have your design evaluated for least privilege, audibility, and separation of concerns.
