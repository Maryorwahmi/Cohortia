Definition
HATEOAS
Server includes links that tell the client what actions are possible next. This can decouple clients from hardcoded URIs.
When to consider
Public APIs, hypermedia-driven clients, or systems that require high resilience to path changes.
Example _links
{
  "id": "SKU123",
  "name": "Laptop Pro",
  "_links": {
    "self": { "href": "/products/SKU123" },
    "update": { "href": "/products/SKU123", "method": "PUT" },
    "delete": { "href": "/products/SKU123", "method": "DELETE" }
  }
}
Trade-off: discoverability vs payload size and parsing complexity.
Key Takeaway

HATEOAS is valuable for discoverability but should be used when its benefits outweigh added complexity.
