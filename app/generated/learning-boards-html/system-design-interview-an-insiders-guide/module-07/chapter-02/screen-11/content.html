Common mistakes & fixes
Wrong method use
Fix: map operations to GET/POST/PUT/PATCH/DELETE semantically to preserve caching and retry behavior.
Leaky abstractions
Fix: return business entities, not raw DB rows or internal IDs.
Inconsistency
Fix: enforce naming, date format, and error structure conventions.
Over-/under-fetching
Fix: support fields selection or specialized endpoints; paginate large collections.
Pro tip

Document conventions in an API style guide and include examples for common client workflows.
