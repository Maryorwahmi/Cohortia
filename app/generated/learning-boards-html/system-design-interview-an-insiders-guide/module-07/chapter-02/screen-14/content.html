Module 7 › Chapter 7.2 › Key Concepts
Resource & URI
Name resources as nouns and use hierarchical URIs.
HTTP Methods
Respect GET/POST/PUT/PATCH/DELETE semantics and idempotency.
JSON & Status Codes
Return business-focused JSON and use appropriate 2xx/4xx/5xx codes.
Pagination
Offset for simplicity, cursor for scale and correctness.
Filtering & Sorting
Whitelist fields, validate inputs, and document parameters.
HATEOAS
Embed links to guide clients, used selectively due to complexity.
Takeaway
Design predictable resources, use correct methods, structure JSON sensibly, paginate results, validate queries, and choose HATEOAS only when its discoverability is worth the complexity.
