Process Flow
HTTP Methods → CRUD
GET — Read
Safe, idempotent, cacheable. Use for retrieval only.
POST — Create
Creates resources, not idempotent by default.
PUT / PATCH — Update
PUT replaces whole resource (idempotent). PATCH applies partial updates (idempotent if patch is idempotent).
DELETE — Remove
Idempotent removal; repeated deletes lead to the same final state.
Examples & status codes
# Create a product (expect 201 Created)
POST /products
{ "id": "SKU123", "name": "Laptop Pro", "price": 1200.00 }

# Retrieve a product (expect 200 OK)
GET /products/SKU123

# Partial update (expect 200 OK)
PATCH /products/SKU123
{ "price": 1100.00 }

# Delete (expect 204 No Content)
DELETE /products/SKU123
Key Takeaway

Match HTTP verbs to their intended semantics. Idempotency and safety affect retries and caching.
