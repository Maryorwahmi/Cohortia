Comparison
2xx Success
  • 200 OK: General success with body.
  • 201 Created: New resource created.
  • 204 No Content: Success with no body.
Comparison
4xx & 5xx Errors
  • 400 Bad Request — invalid input.
  • 401 / 403 — auth & authorization.
  • 404 Not Found; 409 Conflict; 429 Rate limit.
  • 500 / 503 — server side problems.
Key Takeaway

Always map outcomes to correct status codes and include structured error details so clients can react programmatically.
