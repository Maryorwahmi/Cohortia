Definition
JSON payloads
Structure responses to reflect client needs. Nest logically, and keep fields consistent across endpoints to reduce surprises.
Good pattern
Use nested objects for related data (price with amount and currency) and omit internal-only fields.
Mistake to avoid
Exposing raw DB schema or returning 200 OK for every response, including errors.
Concrete example
{
  "id": "SKU123",
  "name": "Laptop Pro",
  "description": "Powerful laptop for professionals.",
  "price": { "amount": 1200.00, "currency": "USD" },
  "category": "Electronics",
  "stock": 50,
  "imageUrl": "https://example.com/images/laptop-pro.jpg"
}
Key Takeaway

Keep JSON focused on business data, choose consistent naming and date formats, and align payloads with status codes.
