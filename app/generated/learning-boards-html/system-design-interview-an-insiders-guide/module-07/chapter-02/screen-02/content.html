Learning Objectives
Skills to demonstrate in a design discussion
Bloom: Learn → Understand → Apply → Master
01
Design resourceful URIs
Name resources as nouns and use hierarchical paths so URIs are human readable and predictable.
VERIFIED COMPETENCY MILESTONE
02
Choose correct HTTP methods
Apply GET/POST/PUT/PATCH/DELETE with correct semantics and idempotency expectations.
VERIFIED COMPETENCY MILESTONE
03
Structure JSON & status codes
Return clear JSON representations and use 2xx/4xx/5xx codes to communicate outcomes.
VERIFIED COMPETENCY MILESTONE
04
Pagination, filtering & HATEOAS
Support offset/cursor pagination and know when to include hypermedia links versus simple docs.
VERIFIED COMPETENCY MILESTONE
