User Management Endpoints
Endpoints
GET  /v1/users?offset=20&limit=10&status=active&sort_by=createdAt&order=desc
GET  /v1/users/{id}
POST /v1/users
PATCH /v1/users/{id}
DELETE /v1/users/{id}
Create & Patch examples
POST /v1/users  → 201 Created
{ "firstName": "Alice", "lastName": "Johnson", "email": "alice@example.com", "password": "securepassword123", "role": "viewer" }

PATCH /v1/users/user-003  → 200 OK
{ "status": "active", "role": "admin" }
Key Takeaway

A clear base URI and consistent query parameters make listing, filtering, sorting and paging predictable for clients.
