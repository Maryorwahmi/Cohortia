Choosing the Focus
Select the component tied to key non-functional needs.
Decide based on which component most impacts the clarified metrics. State the scope, list the metrics, and outline scaling strategies before diving into low-level details.
Deep-Dive Checklist
  • Define API surface and critical operations
  • Show data model at a glance
  • Explain scaling strategy and bottlenecks
  • Summarize trade-offs
Concrete Example
Sharding image metadata
If you expect very high write rate to metadata, propose partitioning by user id or by time window. Explain how partition keys affect hot partitions and how consistent hashing or virtual node strategies mitigate hotspots.
Pro Tip

State the metrics you will optimize, then show one concrete algorithm or pattern that meets those metrics.
