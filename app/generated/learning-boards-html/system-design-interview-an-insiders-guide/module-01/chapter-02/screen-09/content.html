Minimal API Contracts
Show only the endpoints needed for core flows.
<!-- Upload -->
POST /upload
Request: { userId, imageBlob }
Response: { imageId, storageUrl }

<!-- Get -->
GET /images/{imageId}
Response: { imageId, storageUrl, metadata }

<!-- List -->
GET /users/{userId}/images?limit=20
Metadata Shape
Keep fields minimal: imageId, userId, uploadedAt, storagePath, size, visibility.
Indexing & Access Patterns
Index what you query frequently, denormalize when reads dominate.
If listing by user is common, index userId. If feeds require sorting by time, design for time-based partitions or reversed timestamps for efficient scans.
Key Takeaway

Make API contracts explicit and minimal; explain how data shape supports the access patterns you expect.
