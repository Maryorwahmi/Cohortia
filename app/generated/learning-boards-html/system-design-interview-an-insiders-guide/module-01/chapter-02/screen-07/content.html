Decision Template
Option — Benefit — Cost — Requirement mapping.
Use a consistent template when explaining choices. For example: "Option: Use CDN for reads. Benefit: Lowers latency for global users. Cost: Increased caching invalidation complexity. Requirement: Matches the low-latency read requirement for public images."
Comparison Axes
Latency · Consistency · Cost · Complexity · Operability
Concrete Contrast
Relational vs NoSQL for metadata
Relational DB: strong consistency, complex scaling. NoSQL: easier horizontal scale, weaker transactional guarantees. Tie the choice to whether transactional consistency across multiple operations is required.
Key Takeaway

Always link a trade-off back to a clarified requirement and state mitigations for the downsides.
