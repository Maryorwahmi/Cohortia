Component Roles
Name each block and why it exists.
  • API gateway: accept requests and enforce auth or rate limits
  • Service layer: validate and orchestrate operations
  • Object storage: durable binary storage for images
  • Database: metadata and indexing for retrieval
  • Cache and CDN: reduce latency for reads
Interaction Notes
Explain how data flows and where you expect bottlenecks. Point out which components are stateful and which are stateless.
Concrete Example
Image upload flow
Client uploads to gateway → service stores image in object store → service writes metadata to DB → CDN caches image for reads. Identify where you would scale horizontally and why.
Key Takeaway

A clear, well-justified component diagram shows how requirements map to architecture without premature detail.
