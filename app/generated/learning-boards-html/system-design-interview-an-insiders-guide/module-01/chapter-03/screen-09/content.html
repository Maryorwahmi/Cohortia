Performance: Latency and Throughput
How fast and how much a system can work.
Latency
Time for a single request to complete. Track median and tail percentiles because long tails hurt user experience.
Technique: Move blocking work to background jobs; use caching and CDNs to reduce roundtrips.
Throughput
Operations per second a system can handle. Scale horizontally and tune bottlenecks to increase throughput.
Technique: Partition workloads, increase parallelism, and optimize data access patterns.
Concrete example
An enrichment call added 150 ms to request latency. By making the enrichment asynchronous and returning cached results immediately, median latency fell from 200 ms to 35 ms while throughput increased because threads were freed faster.
Key Takeaway

Measure percentiles and choose the most direct technique to reduce the metric that matters to users.
