Non-functional Requirements (NFRs)
Quality attributes that guide architecture and operations.
Definition
NFRs define how well a system performs under specific conditions. They include scalability, reliability, availability, performance, maintainability, and security. Each should be tied to measurable targets or service-level objectives.
Example
A feed API that is functionally correct but responds in five seconds under moderate load fails performance NFRs and drives users away.
Common mistake
Confusing NFRs with features. NFRs are constraints on behavior, not capabilities to add.
Key Takeaway

Define measurable SLOs for each NFR before choosing architecture techniques; instrument to verify them.
