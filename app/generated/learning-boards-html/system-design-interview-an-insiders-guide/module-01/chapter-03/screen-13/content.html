Pillar Prioritization – Streaming Service
Rank pillars, justify priorities, and identify one trade-off.
Instructions
  1. Rank the top three pillars you would prioritize for an initial streaming launch.
  2. For each ranked pillar, write 2–3 sentences explaining the consequences of neglecting it.
  3. Identify one trade-off between two of your chosen pillars and propose a mitigation.
Example ranking
1) Availability — users expect on-demand access. 2) Performance — low latency and smooth playback. 3) Scalability — serve many concurrent viewers efficiently.
Key Takeaway

Make priorities explicit and tie each to a measurable outcome and one mitigation for the accepted trade-off.

Hints
For availability: consider multi-region failover. For performance: use CDNs and adaptive bitrate streaming. For scalability: use horizontal autoscaling and sharded metadata stores.
