Module 2 › Chapter 1.6 › NoSQL Families
Key-Value
Fast lookups. Use for caches and simple mappings.
Document
Flexible schema. Use for user profiles and semi-structured records.
Column-Family
High write throughput and horizontal scale for time-series data.
Graph
Efficient relationship traversal for social or recommendation graphs.
Practical note
Large systems often use multiple stores for different data types; justify each choice by access patterns and consistency requirements.
