API Example
POST /send_notification { recipient, channel, templateId, payload }
Key Takeaway

Decouple delivery using a queue so the API stays responsive and workers own retries and provider failures.

Justify the queue
The queue buffers bursts, lets you scale each sender independently, and isolates retry logic. Monitor queue depth and sender success rates as primary metrics.
