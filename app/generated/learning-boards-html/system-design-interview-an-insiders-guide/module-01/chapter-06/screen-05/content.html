Module 2 › Chapter 1.6 › Load Balancer
Core responsibilities
  • Distribute incoming network traffic across multiple servers to avoid overload.
  • Perform health checks and route around unhealthy instances.
  • Optionally offload SSL termination and implement routing rules.
Example
In a URL shortener, the load balancer handles redirect traffic and spreads the lookup load across the API servers to keep latency low.
Key Takeaway

Choose a load balancer and health checks that reflect failure modes and maintenance patterns in your system.

Common mistakes & pro tip
Mistake
Assuming the load balancer alone solves availability when backups and data replication are also necessary.
Pro tip
Use health checks that validate application-level readiness, not only TCP port openness.
