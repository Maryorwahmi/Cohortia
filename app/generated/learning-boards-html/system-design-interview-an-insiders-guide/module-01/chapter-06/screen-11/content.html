Module 2 › Chapter 1.6 › URL Shortener Architecture
Block view
Client
Browser or app issues POST and GET requests.
Load Balancer → API Servers
Stateless servers generate codes and serve redirects.
Cache + Database
Redis serves hot lookups; DB stores durable mappings and can be sharded.
Optional Analytics
Publish redirect events to a queue consumed by analytics workers to count clicks without blocking redirects.
Example endpoints
POST /api/v1/urls
Accepts JSON {"longUrl": "https://..."}, returns shortUrl and 201 Created.
GET /{short_code}
Returns 302 Found with Location header pointing to the original URL, usually served after cache lookup.
Key Takeaway

Map each endpoint to the components it touches so you can argue scalability and latency trade-offs in interviews.
