Cache types
  • Client-side: browser or app caches for quick retrieval.
  • CDN: geographic distribution for static assets and edge caching.
  • Server-side: Redis/Memcached for application lookups and sessions.
Example
Caching redirects in Redis reduces database reads for a URL shortener under high load.
Key Takeaway

Design a clear invalidation and fallback path to prevent stale reads when using caches.

Common pitfalls
Pitfall
Caching write-heavy or highly volatile data without careful invalidation causes stale or incorrect behavior.
Design note
Prefer caches for read-mostly flows and ensure a database fallback when cache misses occur.
