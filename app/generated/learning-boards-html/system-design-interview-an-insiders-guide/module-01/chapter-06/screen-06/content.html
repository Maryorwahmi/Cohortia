Module 2 › Chapter 1.6 › Web Servers & Stateless Services
Role

Web servers execute business logic for incoming requests. Keep them stateless so instances can be replaced or scaled without migrating user session data.

Pattern
When state exists, place it in caches or databases that are independent of any single server.
Example
API servers for a URL shortener store mappings in a DB and use Redis for fast redirect lookups.
Key Takeaway

Stateless services simplify scaling and allow easy horizontal growth under load.

Anti-patterns & guidance
Anti-pattern
Storing session state in local server memory, which prevents elastic scaling and complicates failover.
Guidance
Use external session stores or stateless tokens and keep APIs focused and idempotent where possible.
