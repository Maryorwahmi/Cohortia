Module 2 › Chapter 1.6 › What to Remember
Justify with metrics
Always tie components to measurable requirements like latency or RPS.
Stateless servers
Keep application servers stateless and place state in services that scale independently.
Use caches & queues
Employ caches for read-heavy paths and queues to decouple heavy processing from user flows.
Final thought
When you present a high-level design, walk through one user request and state how each component helps meet a measurable target.
