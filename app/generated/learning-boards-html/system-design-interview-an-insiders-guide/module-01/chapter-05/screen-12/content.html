Video streaming capacity example
Structured calculation (show on whiteboard)
// Given
DAU = 500,000,000
hours_per_user = 2
bitrate = 1 Mbps

// Total viewing hours per day
total_hours = DAU * hours_per_user = 1,000,000,000 hours

// Convert to seconds and bits
total_bits = total_hours * 3600 * 1,000,000 = 3.6e15 bits

// Convert to bytes and then to PB (1000-based)
bytes = total_bits / 8 = 4.5e14 bytes
petabytes = bytes / (1000**5) ≈ 450 PB

// Average bandwidth (bits/sec)
avg_bps = total_bits / 86400 ≈ 4.16e13 bps ≈ 41,600 Gbps
Note: state whether you use 1000 or 1024 base and keep units consistent throughout.
Interpretation
A multi-hundred-petabyte daily egress and tens of thousands of Gbps average bandwidth indicate global CDN egress, peering contracts, and large origin capacity. Mention cost and operational implications briefly to show trade-off awareness.
Misconception

Inconsistent unit conversions cause wildly different answers. Publish conversions explicitly and round deliberately.
