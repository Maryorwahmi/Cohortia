Core Concept
Bandwidth & CDN
Peak QPS × payload → bytes/sec → Gbps
Worked bandwidth example
If peak QPS for photo views ≈ 13,888 and each photo ≈ 1 MB, peak download bandwidth ≈ 13,888 MB/s ≈ 13.8 GB/s. This magnitude typically justifies CDN offload and edge caching to reduce origin egress and improve latency.
Conversion tip
When converting to Gbps, multiply GB/s by 8 to get Gbit/s and be explicit about using 1000 or 1024 bases. State your choice in the interview.
Why CDNs help
  • Serve cached objects near users to reduce origin bandwidth and latency.
  • Absorb traffic spikes and reduce the number of origin servers required.
  • Allow origin to focus on dynamic or authenticated content while edge handles static assets.
Key Takeaway

Peak bandwidth often dictates CDN use; express bandwidth in Gbps and justify edge caching from the peak number.
