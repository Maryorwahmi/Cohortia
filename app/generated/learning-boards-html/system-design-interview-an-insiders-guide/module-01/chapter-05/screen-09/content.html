Use these anchors to argue for caches and locality during interviews.
Concrete design consequence
If user profile reads are frequent, an in-memory cache reduces latency and database load by orders of magnitude. If writes are less frequent, consider cache invalidation or write-through strategies. Avoid designs that require cross-region syncs for every interactive operation.
Common Mistake

Choosing storage solely on durability without considering access latency leads to poor user experience. State access patterns first.
