Process Flow
From DAU to QPS
A reproducible sequence for average and peak rates
1
Estimate DAU
Convert total users to Daily Active Users using an interview assumption. State the percentage you use and why.
2
Multiply actions per DAU
Actions per DAU per day gives you daily request volume for the feature in question.
3
Convert to QPS
Divide daily requests by 86,400 seconds to get average QPS, then compute peak QPS using window scaling and fraction of traffic.
Worked Example — photo upload
Assume 1B users, 10% DAU = 100M. One upload per DAU → 100M uploads/day. Average QPS = 100M / 86,400 ≈ 1,157. If 20% of uploads happen in a 4-hour peak window, peak QPS = average × (24/4) × 0.20 ≈ 1,388. That peak number is the operational target for the upload path.
Common Mistake

Applying the traffic fraction without scaling for the shorter window underestimates peak QPS. Always expand to the short window first, then apply the fraction.
