Module 1 › Chapter 1.1 › Scalability
What is scalability?
Ability to handle growth by adding resources. Vertical scale increases power of a node; horizontal scale adds more nodes.
Make services stateless where possible.
Shard data by stable keys to spread writes.
Use read replicas and caches for read-heavy workloads.
Common mistake
Assuming adding servers fixes all bottlenecks without addressing shared state like databases.
Example
An API becomes stateless, runs multiple instances behind a load balancer, uses Redis to cache hot lookups, and shards user data by user ID to support write scale.
Key Takeaway
Identify bottlenecks early and match scaling strategy to the specific resource under pressure.
