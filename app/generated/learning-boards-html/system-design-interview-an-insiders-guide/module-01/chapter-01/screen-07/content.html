Module 1 › Chapter 1.1 › Core Components
Database
Durable state and queries
Choose based on consistency, query patterns, and scale. Relational for transactions; NoSQL for flexible schemas and high write rates.
Cache
Fast reads and latency reduction
Caches reduce database load but require invalidation strategies to avoid stale data problems.
Queue
Decoupling and asynchrony
Queues buffer spikes and allow background processing for tasks like notifications or batch jobs.
CDN
Global content delivery
A CDN caches static or streamable assets near users to lower latency and bandwidth costs.
Example
Streaming service: object storage for files, CDN for playback, metadata DB for catalog, cache for hot queries, queue for transcoding jobs.
