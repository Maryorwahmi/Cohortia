Module 1 › Chapter 1.1 › Functional vs Non-functional
Functional
Features the system provides
  • Examples: stream video, search catalog, manage profiles.
  • Drive APIs and data models.
  • Often stable but evolve with product needs.
Non-functional
Operational guarantees
  • Examples: latency, throughput, availability, security.
  • These constraints determine cache, replication, and partitioning choices.
  • Rank NFRs to resolve trade-offs.
Design Process
1. List functions
2. Rank NFRs
3. Map components
4. Validate trade-offs
