Module 1 › Chapter 1.1 › Performance
Latency
Time to respond. Impacted by network hops, compute time, and cache effectiveness.
Use caches and CDNs for common requests.
Optimize critical code paths and reduce serial work.
Pitfall
Focusing on averages while ignoring tail latency that impacts real users.
Throughput
Requests per second the system handles. Address by parallelism, sharding, and batching.
Scale stateless workers horizontally.
Use queues and batching to smooth spikes.
Key Takeaway
Measure both metrics and choose remedies that directly address the dominant constraint.
