Module 1 › Chapter 1.1 › Reliability
Core idea
Reliability is the chance a system keeps working over time; fault tolerance keeps parts failing without total outage.
Redundancy and replication
Graceful degradation and fallbacks
Circuit breakers and backoff for retries
Common misconception
Blind retries without backoff can amplify failures and increase downtime.
Scenario
If a primary database becomes slow, failover to replicas for reads, queue writes for replay, and use cached data to preserve user experience.
Key Takeaway
Plan for realistic failures: detect, isolate, and recover with minimal user impact.
