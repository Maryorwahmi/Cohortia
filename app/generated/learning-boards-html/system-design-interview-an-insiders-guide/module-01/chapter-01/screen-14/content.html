Module 1 › Chapter 1.1 › Key Concepts
System Design
Architecture and components aligned to requirements.
Distributed Systems
Networked components that coordinate by message passing.
Scalability
Add resources horizontally or vertically to meet growth.
Reliability
Design for failures with redundancy and graceful degradation.
Performance
Latency and throughput are distinct metrics with different remedies.
NFRs
Non-functional requirements determine architecture and component choices.
Final takeaway

Make NFRs explicit, map them to components, and communicate trade-offs; these skills define strong system designers.
