Brainstorm — Functional Questions
  • Should users be able to schedule rides in advance?
  • Do we support multiple vehicle types and surge pricing?
  • Is payment handled in-app or via third-party gateways?
  • Are driver ratings, trip history, and cancellations required?
  • Is real-time driver location tracking mandatory?
Brainstorm — Non-Functional Questions
  • What's the expected number of concurrent drivers and riders?
  • What's acceptable latency for driver matching?
  • What is the expected peak traffic multiplier during events?
  • Is global or regional operation required?
  • How long must trip and financial records be retained?
Edge cases / Assumptions to confirm
  • How do we handle cancellations and partial refunds?
  • Do we need to handle offline drivers and queuing of assignments?

Write these questions on a notepad, ask them in a mock interview, and then map answers to architectural components like matching service, geospatial indices, and messaging.
