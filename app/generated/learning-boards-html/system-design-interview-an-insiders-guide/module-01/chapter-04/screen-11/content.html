Mapping examples
RequirementDesign response
High read QPSAdd CDN and edge caches to serve reads and reduce origin load
Low read latencyUse in-memory caches and local replicas for fast reads
Strong consistencyUse leader-based writes or distributed consensus for critical paths
High durabilityReplicate data across regions and use durable object storage for large files
Interview technique
Present the mapping table and ask the interviewer which items to prioritize in the design. This shows you make component choices from validated constraints.
Example
If the feed must be personalized and real-time for millions, the mapping will include fast caches, streaming updates, and specialized databases rather than a single relational store.
Key Takeaway

Always show the causal chain from a confirmed requirement to the architectural pattern that satisfies it.
