Module 1 › Chapter 1.4 › Functional Requirements
Definition

Functional requirements are the system's behaviors

Write each requirement as a one-line, testable feature and confirm priority with the interviewer.

Common items
  • Authentication: sign up, sign in, sessions.
  • Content: create, read, update, delete posts or items.
  • Interaction: search, comment, like, follow.
  • Administration: moderation, reporting, analytics.
Example — URL Shortener (functional)
Generate a unique short URL for a long url. Redirect short URL to the original when accessed. Optional: custom aliases and click analytics.
Pitfall
Don't conflate a feature with its implementation. Saying 'store images in S3' is an implementation choice that depends on non-functional constraints like scale and durability.
Key Takeaway

State functional requirements as user-facing behaviors, prioritize them, and confirm scope with the interviewer.
