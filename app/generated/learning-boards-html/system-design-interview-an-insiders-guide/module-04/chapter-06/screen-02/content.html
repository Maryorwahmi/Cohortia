Explain caching purpose

Describe how caching reduces latency and offloads primary data stores. This matters because it directly affects user-perceived performance and DB cost.

Identify cache placement

Locate caches at client, CDN, proxy, app process, distributed cache, or DB layer and explain typical trade-offs for each placement.

Implement or reason about Cache-Aside, Write-Through, and Write-Back patterns with their pros and cons and use cases.
