Module 4 › Chapter 4.6 › Write Strategies
Write-Through
Synchronous writes to cache and database

Writes wait for cache and DB persistence, ensuring consistency between layers at the cost of write latency.

Pros
  • Cache remains consistent with DB
  • Predictable read-after-write behavior
Cons
  • Slower writes due to synchronous DB persistence
Write-Back
Asynchronous writes from cache to database

Writes return immediately after updating cache; the cache flushes to the DB later. This maximizes write performance but risks data loss on failure.

Pros
  • Very fast write acknowledgement
  • High write throughput
Cons
  • Risk of data loss if cache fails before persistence
  • Higher implementation complexity for durability guarantees
Quick decision guide: pick Write-Through if immediate consistency is required; pick Write-Back if write throughput is the dominant requirement and some data loss is acceptable.
