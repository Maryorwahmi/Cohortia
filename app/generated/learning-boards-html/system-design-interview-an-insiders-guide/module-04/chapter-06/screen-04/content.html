Core Concept

Caching: definition and purpose

Caching stores copies of data in a faster layer to reduce latency and database load. It brings frequently-requested data closer to the consumer.

Primary goals
  • Reduce request latency
  • Offload the primary database
Real-world example
User profiles cached to avoid repeated slow database reads for every page view.
Key Takeaway

Cache where it provides meaningful latency or cost savings, and pair it with invalidation and eviction policies.

Placement
Client-side
Browser and mobile caches reduce network hops for UI assets and small responses.
CDN & Proxy
Static assets cached geographically closer to users; proxies cache responses at the edge.
Application & Distributed
In-process caches for microsecond access; Redis or Memcached for shared, in-memory storage across servers.
Misconception check: Caching is not a free performance win. Measure hit rates and understand when caching adds operational cost without benefit.
