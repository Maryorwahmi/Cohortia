Placement

Where to put a cache

Client-side
Fast UI interactions; limited control and size.
CDN
Best for static assets and geographic proximity.
Proxy
Caches HTTP responses at the network edge or in front of origin servers.
Distributed & App
Application-level caches live inside a process for microsecond access; distributed caches such as Redis or Memcached provide shared access across processes and servers.
Use case: sessions
Store session state in a distributed cache to allow any app server to serve user requests.
Use case: hot data
Cache hot or frequently-read rows in Redis for rapid access in read-heavy services.
Common mistake: pick placement by convenience rather than access pattern; that leads to suboptimal hit rates or consistency gaps.
