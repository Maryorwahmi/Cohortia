Designing for a Social Media Feature

Apply topology and consistency choices to user profiles and a global news feed.

User Profile Updates

Choose leader‑follower for predictable writes and use read‑your‑writes routing so the user sees their updates immediately. Document failover and replication lag tolerances.

Why
Profiles are user‑centric; correctness for the updating user matters more than global immediacy.
News Feed

Use eventual or multi‑master approaches for geographic write availability and read scale. Accept small ordering and staleness variances and design the UI to tolerate them.

Why
Feeds prioritize availability and scale; slight delays are usually acceptable to users.
