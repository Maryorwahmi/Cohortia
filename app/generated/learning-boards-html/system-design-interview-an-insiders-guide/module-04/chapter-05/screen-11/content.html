Read‑Your‑Writes: Conceptual Code

A simplified illustrative example to show the routing pattern for read‑your‑writes.

<class ReplicatedDatabase:> <def __init__(self, num_replicas):> <self.replicas = [{} for _ in range(num_replicas)]> <self.last_write_replica_idx = -1> <self.next_replica_for_read = 0> <def write(self, key, value):> <for i in range(len(self.replicas)):> <self.replicas[i][key] = value> <self.last_write_replica_idx = 0 # assume replica 0 handled the write> <def read(self, key, client_id):> <if client_id == 'user_A' and self.last_write_replica_idx != -1:> <return self.replicas[self.last_write_replica_idx].get(key)> <else:> <replica_idx = self.next_replica_for_read> <self.next_replica_for_read = (self.next_replica_for_read + 1) % len(self.replicas)> <return self.replicas[replica_idx].get(key)>
Concrete insight
Per‑client routing provides immediacy while leaving global convergence to replication mechanics.
Caveat
This pattern requires handling preferred replica failure and will not enforce others seeing the write immediately.
