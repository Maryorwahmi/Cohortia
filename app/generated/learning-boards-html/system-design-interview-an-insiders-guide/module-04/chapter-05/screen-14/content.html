Assessment: Shopping Cart vs Inventory

Use case mapping shows the practical difference between client experience guarantees and global correctness requirements.

Shopping Cart Display
Use read‑your‑writes so the customer immediately sees added items. This improves UX without requiring global write coordination.
Inventory Update
Require strong consistency for the inventory decrement so only one purchase succeeds when stock is limited.
Explain
Justify each choice by connecting user expectations to the consistency and operational mechanisms needed.
Edge case
Discuss network partitions and how the system degrades under failure for each guarantee.
