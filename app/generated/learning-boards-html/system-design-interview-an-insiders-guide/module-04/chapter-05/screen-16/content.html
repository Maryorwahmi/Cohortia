Replicate for availability
Replicas keep data available and improve read throughput.
Match topology to writes
Leader‑follower for simpler writes; multi‑master for regional write availability.
Tune consistency
Use the weakest model that satisfies user expectations and document behavior under failure.
Memory strip

Trade‑offs are explicit: availability, latency, and correctness cannot all be maximized at once; choose and test accordingly.
