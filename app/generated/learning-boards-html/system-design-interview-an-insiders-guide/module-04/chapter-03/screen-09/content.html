Module 4 › Chapter 4.3 › Graph Fundamentals
Node
Represents an entity such as a user, product, or account. Nodes can have properties that describe attributes.
Example: User node with name and id properties.
Edge (Relationship)
Connects two nodes and can be directed. Edges often carry properties like timestamps or amounts.
Example: FRIENDS_WITH or TRANSFERRED edges with a timestamp property.
Properties
Key-value pairs on nodes and edges that provide contextual data used in queries and filtering.
Example: edge property amount=500 and timestamp=2023-10-26T10:00Z.
Key Takeaway

If queries require exploration across multiple hops or pattern matching, graph models are often the most direct and efficient representation.
