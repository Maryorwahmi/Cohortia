Create nodes and relationships
// Create nodes for users
CREATE (alice:User {name: 'Alice'})
CREATE (bob:User {name: 'Bob'})
CREATE (charlie:User {name: 'Charlie'})

// Create relationships
CREATE (alice)-[:FRIENDS_WITH]->(bob)
CREATE (bob)-[:FRIENDS_WITH]->(charlie)
CREATE (charlie)-[:WORKS_AT {company: 'Acme Corp'}]->(alice)
Friends-of-friends query
// Find recommended friends for Alice
MATCH (alice:User {name: 'Alice'})-[:FRIENDS_WITH]->(friend)-[:FRIENDS_WITH]->(recommended_friend)
WHERE NOT (alice)-[:FRIENDS_WITH]->(recommended_friend) AND alice <> recommended_friend
RETURN DISTINCT recommended_friend.name
Why it matters

Multi-hop traversals are expressed naturally and executed efficiently by graph engines.

Common mistake

Using a graph when relationships are shallow and rare adds unnecessary complexity.

Key Takeaway

Express relationship patterns with Cypher and justify graph choice by required traversal depth and frequency.
