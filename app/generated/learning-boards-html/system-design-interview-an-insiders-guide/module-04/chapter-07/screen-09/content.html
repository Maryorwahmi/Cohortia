Module 5 › Chapter 4.7 › Lake vs Warehouse
Comparison Summary
Schema
Lake: schema-on-read; Warehouse: schema-on-write.
Use case
Lake: raw ingestion, ML; Warehouse: BI and reporting.
Storage cost
Lake: low-cost object storage; Warehouse: optimized query storage and compute costs.
Performance
Warehouse: predictable fast queries; Lake: may require processing for performance.
Pipeline Pattern
Operational DB → Data Lake (raw) → Transform (Spark/ETL) → Data Warehouse (curated).
Practical Note
Keep lineage and catalogs so datasets moved into the warehouse are reproducible and trusted.
