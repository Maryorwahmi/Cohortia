HDFS Fundamentals
Block Storage
Files are split into blocks and stored across nodes to enable parallel reads.
Replication
Blocks are replicated across nodes for fault tolerance; replication factor balances durability and cost.
Throughput-oriented
Designed for large, sequential I/O rather than low-latency single-record reads.
Commodity hardware
Assumes node failures are common and handles them via replication and rebalancing.
Example
Store multi-terabyte log archives across many nodes with replication factor three.
Misconception
HDFS is not optimized for transactional workloads requiring random, low-latency access.
Takeaway
Use HDFS-style or object storage for durable, high-throughput data used in large batch jobs.
