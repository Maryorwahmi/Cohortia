Module 5 › Chapter 4.7 › Data Lake
What a Data Lake Provides
  • Schema-on-Read: Define structure when reading data.
  • Cost-Effective Storage: Use object stores for large volumes.
  • Supports Variety: Logs, images, JSON, and sensor data.
Concrete Scenario
Stream clickstream logs to storage, then run Spark to extract sessions and build user behavior features.
Governance Musts
Catalogs and Metadata: Make data discoverable and traceable.
Access Controls: Enforce security and compliance across raw datasets.
Quality Checks: Validate data to avoid unusable datasets.
Misconception
A lake is not a landfill; governance and catalogs are required to keep it useful.
