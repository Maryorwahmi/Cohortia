Module 5 › Chapter 4.7 › Pipeline Design
Conceptual Pipeline
Map components for an e-commerce analytics pipeline.
OLTP
PostgreSQL for orders and users, ACID and low-latency transactional operations.
Ingestion
Kafka for clickstream to decouple producers and consumers and buffer high-volume events.
Data Lake
Object storage for raw JSON logs and media, schema-on-read for flexible analysis.
Processing
Spark to transform raw logs into partitioned Parquet and feature tables.
Key Takeaway

Use the lake for raw capture and Spark to prepare curated datasets for the warehouse where analysts run BI queries.

Governance
Catalog datasets, enforce access controls, and run data quality tests to prevent a data swamp.
