Module 5 › Chapter 4.7 › Apache Spark
Spark Capabilities
  • In-memory processing: Faster for iterative jobs compared to disk-based approaches.
  • APIs: Spark SQL, DataFrames, Streaming, MLlib, GraphX.
  • Data sources: HDFS, S3, Cassandra, HBase, and more.
Example
Use Spark to convert raw JSON logs into partitioned Parquet tables and compute nightly aggregates for a data warehouse.
Design Notes
Shuffle costs: Minimize wide transformations that cause heavy network traffic.
Memory sizing: Right-size executors for in-memory workloads to avoid spill and GC issues.
Cluster size: Match cluster resources to workload parallelism and data size.
