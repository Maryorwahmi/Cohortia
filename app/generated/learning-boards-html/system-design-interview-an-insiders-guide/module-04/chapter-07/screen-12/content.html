Module 5 › Chapter 4.7 › Design for Big Data
Ingestion and Storage
Ingestion: Choose streaming for near-real-time, batch for predictable windows.
Formats: Use Parquet/ORC for columnar analytics and smaller scan costs.
Partitioning: Partition by date or common filters to prune data.
Compute, Queries, and Cost
Compute vs Storage: Separate to control cost and scale independently.
Query Optimization: Use clustering, indexes, and materialized views where supported.
Cost Management: Archive cold data and monitor query spend.
Pro Tip
Start with partitioning and proper file sizes before adding compute power — it often yields better ROI.
Example
Store daily Parquet files partitioned by date, compact small files nightly, and run MPP queries for reports.
Warning
Dumping data without metadata leads to a data swamp; enforce catalogs and quality checks early.
