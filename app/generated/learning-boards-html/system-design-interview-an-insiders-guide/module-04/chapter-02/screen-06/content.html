CAP Theorem

Understand the forced trade-off and how to map it to application needs.

Consistency (C)
All nodes see the same data at the same time; reads reflect latest writes.
Availability (A)
Every request receives a response, even if it's not the latest state.
Partition tolerance (P)
The system continues to operate despite message loss or node failure.
Concrete scenario
When a network split isolates two replica sets, a CP system will stop serving some operations until consistency is restored; an AP system will continue serving writes and reconcile later.
Practical pattern
Use hybrid designs: treat money transfers as CP, and feed generation or analytics as AP, documenting the acceptable inconsistency windows.
Key Takeaway

Because partitions will happen, design systems by selecting consistency guarantees per operation and by preparing reconciliation mechanisms where you prioritize availability.
