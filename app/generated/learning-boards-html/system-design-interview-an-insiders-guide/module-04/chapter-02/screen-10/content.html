Core Concept

Document Databases

Flexible, nested documents enable rich queries and denormalized reads optimized for common access patterns.

Advantages
Flexible schema, efficient single-document reads, and powerful aggregation tools for analytics and transformation.
Modeling advice
Model by read patterns: embed small, commonly-read related data; reference large or shared entities to avoid oversized documents.
Key Takeaway

Use document databases when your data is naturally hierarchical and you want flexible schemas and efficient reads of nested data.

MongoDB example
// Insert a user document
db.users.insertOne({
  _id: "user1001",
  name: { first: "Alice", last: "Smith" },
  email: "alice@example.com",
  addresses: [
    { type: "home", street: "123 Main St", city: "Anytown", zip: "12345" },
    { type: "work", street: "456 Oak Ave", city: "Otherville", zip: "67890" }
  ],
  preferences: { newsletter: true, theme: "dark" },
  tags: ["premium", "active"]
})

// Query nested field
db.users.find({ "addresses.city": "Anytown" })
