Definition

Key-Value Stores

A simple mapping from a unique key to an opaque value designed for extreme read/write performance.

When to use
Caching, session storage, user lookups by ID, and configuration storage where queries are by key.
Pitfall
Avoid using key-value stores for attribute-based queries unless you maintain external indices or secondary maps.
Key Takeaway

Use key-value stores for predictable, high-speed single-key operations and caching; plan for additional layers when you need searchability across fields.

Compact example
# Conceptual Redis commands
SET user:123:name "Alice"
SET user:123:theme "dark"
RPUSH user:123:favorite_categories "sports" "news" "tech"
GET user:123:name
Because values are opaque, retrieving users by city or tag requires either additional indices or a document model that exposes those fields to queries.
