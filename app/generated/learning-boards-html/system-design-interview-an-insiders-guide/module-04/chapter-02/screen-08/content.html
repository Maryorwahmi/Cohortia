Redis example

Namespaced keys, string values, and storing serialized JSON.

Python example (conceptual)
import redis
import json

# Connect to Redis
r = redis.Redis(host='localhost', port=6379, db=0)

# Set a key-value pair
r.set('user:1001:name', 'Alice Smith')
r.set('user:1001:email', 'alice@example.com')

# Store a more complex object as JSON
user_profile = {
  "id": 1002,
  "name": "Bob Johnson",
  "email": "bob@example.com",
  "last_login": "2023-10-26T10:30:00Z"
}
r.set('user:1002:profile', json.dumps(user_profile))

# Retrieve and deserialize
retrieved = json.loads(r.get('user:1002:profile').decode('utf-8'))
print(retrieved)
What this shows
Use clear key naming conventions and client-side serialization. Redis returns the stored blob; parsing happens on the client. This preserves speed but limits server-side queryability.
When to avoid
If you need to run queries over nested fields or indexes across fields, prefer a document store or maintain auxiliary indices.
Key Takeaway

Redis is excellent for low-latency single-key operations; store structured objects as serialized blobs and plan separate systems for complex search.
