Module 3 › Chapter 3.6 › Deadlocks & Livelocks
Deadlock
Cycle of waiting for resources held by others. No one can proceed.
Example
Process A locks resource 1 then waits for resource 2. Process B locks resource 2 then waits for resource 1. Both wait forever.
Prevention
Impose a global lock ordering, use try-lock plus rollback, and set timeouts to recover from unexpected waits.
Livelock
Processes keep changing state in response to each other but never make progress.
Example
Two services repeatedly back off and retry at the same time, continuously adjusting but not completing the operation.
Mitigation
Add randomized backoff, jitter, or change retry logic to break synchronous reaction patterns and allow eventual progress.
