Module 3 › Chapter 3.4 › Shard Routing
Concept

Routing ensures requests consistently reach the correct shard for a given key so reads and writes are co-located.

Example function
def get_shard_id(user_id, num_shards):
  # Simple illustrative hash-based routing
  return hash(str(user_id)) % num_shards

# Example usage
shard = get_shard_id(12345, 100)  # e.g., shard 42
# Subsequent reads/writes for user 12345 use shard 42
Practical notes
  • Use a strong hash or consistent hashing to ease shard count changes.
  • Consider a directory mapping for manual control or uneven distributions.
  • Plan for data movement and re-routing when adding or removing shards.
Common mistake

Using a naive modulus and then increasing the shard count without consistent hashing produces massive data reshuffle and operational pain.
