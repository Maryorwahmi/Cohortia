Interview-ready framing
Diagnosis
Metric-driven choice

Describe the metric that shows the bottleneck: tail latency, connection saturation, or storage limits.

Mitigation
Operational plan

Say how you'll monitor, fail over, rebalance, or propagate updates when you introduce replicas, shards, or redundancy.

Example
Short concrete case

E.g., add read replicas for a posts table to handle browse traffic; shard user profiles by user_id when writes exceed a single node.
