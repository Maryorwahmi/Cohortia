Module 3 › Chapter 3.4 › Choose the right lever
Replication
Best when reads dominate. Adds availability and read throughput but not write capacity.
Sharding
Best when writes or dataset size exceed a single node. Adds operational complexity and limits cross-shard transactions.
Denormalization
Best for hot read paths where joins dominate latency. Introduces redundancy and write-side update work.
Decision flow
Measure the bottleneck, try replicas for reads, optimize queries and cache, denormalize selectively for hotspots, and adopt sharding only when a single node’s write or storage limits are reached.
