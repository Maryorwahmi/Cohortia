Module 3 › Chapter 3.1 › What is Scalability?
Definition

Scalability

The ability of a system to handle growing work or be enlarged to accommodate that growth.

Common signals
  • Throughput and latency percentiles
  • CPU, memory, and disk I/O saturation
  • Network bandwidth and error rates
Concrete example

An API endpoint shows increasing 95th percentile latency while CPU is low but disk I/O is high. That points to a storage bottleneck rather than compute, so simply adding more app servers won't help.

Diagnosis flow
Measure metrics
Identify bottleneck
Choose scaling lever
Misconception

Adding more app servers fixes everything. Not true if the database or disk I/O is the real bottleneck.

Key takeaway

Always diagnose the exhausted resource before applying a scaling strategy.
