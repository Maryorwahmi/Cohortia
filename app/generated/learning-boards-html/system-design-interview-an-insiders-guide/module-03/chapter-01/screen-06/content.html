Module 3 › Chapter 3.1 › Horizontal Scaling
Definition

Scaling out: add more machines

Distribute the workload across multiple nodes and coordinate them to behave as a logical unit. This supports fault tolerance and growth limited mainly by budget and architecture.

Fault tolerance
Auto-scaling
Concrete example

A web fleet behind a load balancer increases instances during traffic spikes and reduces them afterward, preserving stability and cost-efficiency.

Misconception

Adding nodes without handling state and data distribution does not automatically solve scaling or reliability problems.

Operational items
  • Stateless services or external session stores
  • Load balancer and health checks
  • Replication, partitioning, and consensus mechanisms
Key Takeaway

Horizontal scaling unlocks resilience and capacity but demands careful design for state and data distribution.
