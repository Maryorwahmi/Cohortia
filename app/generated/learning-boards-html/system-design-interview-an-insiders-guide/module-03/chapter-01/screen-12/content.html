Starter stack (conceptual)
Cloud provider: AWS
Service: EC2
Instance: t3.medium (example)
OS: Ubuntu Server 20.04 LTS
Software: Nginx, Gunicorn, Flask/Django, PostgreSQL (local or managed)

This configuration minimizes early complexity and keeps the full stack on a single, vertically scaled host for simplicity.

Why choose vertical now?

Lower operational overhead, simpler data consistency, and fast iteration when load is limited.

Watch for these signals
  • Sustained high CPU, memory, or disk I/O.
  • Database connection saturation or rising query latency.
  • Frequent deployments causing long maintenance windows.
