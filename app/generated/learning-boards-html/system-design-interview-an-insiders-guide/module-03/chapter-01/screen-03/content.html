Module 3 › Chapter 3.1 › Practice Objectives

Practice & Interview Focus

Prepare concrete steps and talking points for system design conversations.

Bottleneck Signals
  • CPU & memory metrics suggest vertical wins short-term.
  • High I/O or unpredictable spikes suggest horizontal scaling.
Incremental Plan
  • Start vertical, prepare to refactor services to be stateless.
  • Introduce load balancer, autoscaling, managed DB, and cache.
Data Tier Trade-offs

Explain replicas, sharding, and consistency trade-offs when moving to distributed data stores.

Operational Checklist

Monitoring, autoscaling policies, state externalization, and cost modelling.
