Module 3 › Chapter 3.1 › Hybrid Strategies
Architecture pattern

Mix vertical and horizontal scaling

Choose vertical for complex, hard-to-distribute components and horizontal for stateless, parallelizable services.

Vertically scale DBs
Horizontally scale APIs
Concrete example

A managed relational DB on a large instance with read replicas, while API servers run in an autoscaling group behind a load balancer and share sessions via Redis.

Key Takeaway

Hybrid designs buy simplicity and time while you plan the longer-term distributed solution for stateful pieces.
