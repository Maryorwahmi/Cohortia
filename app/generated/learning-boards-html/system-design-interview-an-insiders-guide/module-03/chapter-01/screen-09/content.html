Module 3 › Chapter 3.1 › Single Point of Failure
Definition & Problem

Single Point of Failure (SPOF)

A component whose failure makes the whole system unavailable. Concentrated resources in one node increase SPOF risk.

Mitigation techniques
  • Introduce replicas and automated failover for critical services.
  • Use managed services with built-in high availability.
  • Design for graceful degradation when non-critical subsystems fail.
Concrete scenario

A single vertically scaled database handles all writes. Under load it fails; the entire application loses write capability. Introducing replicas and a promotion mechanism removes the primary SPOF.

Key Takeaway

Identify SPOFs early and plan redundancy and tested failover for each critical path.
