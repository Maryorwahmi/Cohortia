Module 3 › Chapter 3.1 › Key Concepts
Scalability

Ability to handle growing work; diagnose the exhausted resource first.

Vertical Scaling

Scale a single server up for early simplicity; limited by hardware and creates SPOF.

Horizontal Scaling

Add nodes and distribute work; offers resilience but requires distributed design.

Summary takeaway

Choose the scaling approach based on measured bottlenecks, availability goals, and operational capacity. Plan migrations and tests before you scale out.
