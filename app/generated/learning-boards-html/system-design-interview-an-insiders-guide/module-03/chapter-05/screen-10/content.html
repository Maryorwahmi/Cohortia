Designing an Asynchronous Workflow for a Long-Running Task
A timeline of checkpoints and safety measures.
Timeline
Step 1
Persist request
Create the canonical record in the database so tasks reference a durable id.
Step 2
Enqueue reference
Publish a small message containing the record id and minimal metadata.
Step 3
Worker processing
Worker fetches the record, checks idempotency, processes, and updates status.
Step 4
Publish completion
Emit success events and update the original record with results or artifacts.
Safety checklist
  • Use idempotency keys or status checks to avoid duplicate side effects.
  • Limit retries and route failures to a DLQ for manual repair.
  • Instrument queue depth, process time, and DLQ counts to detect issues early.
