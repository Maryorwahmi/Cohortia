Architecture Design Checklist
Designing a Basic Load Balancing Setup
A stepwise checklist to align algorithm and features with requirements.
Stepwise checklist
  • Classify traffic patterns: stateless, long-lived, or sessionful.
  • Choose algorithm: Round Robin, Weighted, Least Connections, or IP Hash.
  • Configure health checks verifying dependencies.
  • Plan session handling and consider external stores for state.
Concrete scenario
For a stateless REST API with variable request time, use Least Connections or Least Response Time. For an older stateful app, consider IP Hash for stickiness but also propose a migration to move sessions to Redis to enable stateless scaling.
Why it matters

Design choices affect resilience and maintenance. Be explicit about trade-offs when explaining your design in interviews.
