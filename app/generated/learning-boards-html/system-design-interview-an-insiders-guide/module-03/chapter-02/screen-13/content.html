Interview Scenarios and Assessment Questions
Practice structuring answers with choice, rationale, trade-offs, and mitigations.
Scenario 1
Least Connections used; one backend fails due to a DB issue but process runs. With health checks, the balancer detects failures and stops new traffic. Immediate effect: new requests unaffected, some existing connections or sticky sessions may fail.
Scenario 2
Stateful app requires session persistence. IP Hash preserves sessions but risks uneven load from concentrated IP sources. Propose external session store as mitigation.
How to answer
  1. Choose an algorithm that matches the traffic pattern.
  2. Explain the primary trade-offs and possible failure modes.
  3. Offer mitigations and a migration plan, such as moving sessions to Redis.
