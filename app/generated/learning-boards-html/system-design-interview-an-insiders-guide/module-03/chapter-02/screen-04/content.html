What is a Load Balancer?
A short conceptual definition and why it matters.
Traffic-cop analogy

The load balancer selects which server gets each request so the overall system stays fast and available. It is responsible for distribution policy and observing server health.

Why this matters
  • Enables horizontal scaling to be effective.
  • Masks server failures from clients.
  • Allows you to apply routing policies for different traffic types.
Key Takeaway

A load balancer coordinates traffic; it enables reliable, scalable use of multiple servers but does not replace capacity planning.

Concrete example
Imagine three identical web servers behind a load balancer. During peak traffic, requests are distributed so nodes share work. If one node fails health checks, the balancer stops sending it traffic and the remaining nodes carry the load.
