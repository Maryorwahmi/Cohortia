Hands-on Activity Nginx Exercise
Practical Task: Configure Round Robin, Weighted, and Health Checks
A guided walkthrough to implement and test the three example configurations.
Step-by-step
  1. Write an upstream block listing web1, web2, web3 and set proxy_pass to it.
  2. Change the upstream to add weight=2 for web1, leaving others default.
  3. Add max_fails and fail_timeout entries to test passive failure handling.
  4. Simulate a server failure and confirm traffic reroutes to healthy servers.
When describing this in an interview, narrate each change and its effect on routing, and note limitations: Nginx open-source has basic passive checks; consider external active probes for more advanced scenarios.
Example checklist
  • Config syntax passes nginx -t.
  • Requests reach backend servers as expected.
  • Fail a backend and confirm redistribution.
Key Takeaway

Hands-on testing reveals practical limits and lets you explain trade-offs confidently in interviews.
