Module 4 › Chapter 3.7 › Key Concepts
Prometheus & Grafana
Prometheus stores metrics; Grafana visualizes and alerts on them.
ELK & Log Search
Centralized, structured logs allow fast root-cause queries when combined with trace ids.
Tracing & Profiling
Use tracing to see per-service latency and profiling to find expensive code paths.
Final Reflection

When you see a P99 spike, run three steps: check resource metrics for saturation, open traces for the slow requests, and filter logs by trace id to confirm errors. That sequence turns an incident into a diagnosable problem.
