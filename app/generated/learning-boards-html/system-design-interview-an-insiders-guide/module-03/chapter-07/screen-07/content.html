Instrumentation → Collection → Visualization
Design the pipeline with cardinality and cost in mind.
Instrument
Expose counters, gauges, and histograms from services. Limit label cardinality to avoid storage explosion.
Collect
Use a pull (scrape) or push model into a time-series store. Configure scrape intervals and retention policies based on needs.
Visualize
Create dashboards for key KPIs and add annotations for deploys and incidents to give context to spikes.
Practical checklist
Instrument key endpoints, define scrape cadence, set retention and downsampling, and create three dashboard panels: latency percentiles, throughput, and error rate.
Concrete Example: Prometheus + Grafana
Instrument a histogram named request_duration_seconds and expose it at /metrics. Scrape every 15s and create Grafana queries for P95 using histogram_quantile.
Example metric names
request_count_total
in_flight_requests
request_duration_seconds_bucket{le="0.1"}
request_duration_seconds_sum
request_duration_seconds_count
Common mistake
Collecting high-cardinality labels per request without aggregation leads to storage and query slowdowns.
