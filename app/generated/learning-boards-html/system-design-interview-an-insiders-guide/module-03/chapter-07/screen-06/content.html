Throughput and Availability
Design visualizations and alerts that surface user-impacting conditions.
Throughput
Requests per second. Visualize with a line or area chart and compare to capacity limits.
Availability
Percent uptime. Use gauges and uptime timelines to show service reliability over windows.
Error Rate
% of failing requests. Break down by 4xx vs 5xx to identify client errors vs server issues.
Example Scenario
A background job consumer processes 300 jobs/s. If error rate rises to 10% and queue depth grows, throughput may remain steady briefly while availability of downstream processing degrades. Investigate consumer logs and processing errors first.
Alerting suggestions
  • Alert if 5xx error rate > 1% for 5 minutes.
  • Alert if throughput drops by >30% while error rate increases.
  • Alert if availability in the last hour drops below agreed SLA.
Common mistake
Firing alerts on absolute values without considering normal baselines causes noise and missed real incidents.
