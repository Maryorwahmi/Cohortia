KPIs: Definitions & Meaning
Precise definitions help you pick the right visualization and alert.
Latency (Response Time)
Time between request and response. Track P50/P95/P99 to surface outliers affecting users.
Throughput
Requests per second or transactions per minute; used to understand capacity and scaling needs.
Availability & Error Rate
Availability measures uptime; error rate shows the percent of failed requests. Both are critical for SLAs.
Resource Utilization
CPU, memory, disk, and network metrics help map performance issues to resource saturation.
Key Takeaway

Combine percentiles with resource metrics to locate issues quickly; averages are misleading when tails exist.

Next steps
  • Check resource utilization on services handling /checkout.
  • Correlate request rates and error spikes to see if a dependency is failing.
  • Open traces for slow requests to identify which downstream call adds the extra latency.
Common mistake
Alerting only on average latency will miss tail latency problems affecting a subset of users.
