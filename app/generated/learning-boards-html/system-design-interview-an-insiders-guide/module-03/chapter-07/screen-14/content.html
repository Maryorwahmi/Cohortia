Activity: System Health Dashboard
Plan a dashboard for Auth, Product, Order, and DB services.
Key Metrics
  • P99 overall request latency
  • Total request throughput (rps)
  • Error rate (4xx vs 5xx)
  • DB CPU utilization
  • App server CPU
  • Message queue depth
Visualizations
Latency: line chart with P50/P95/P99. Throughput: area chart. Errors: stacked area for 4xx/5xx. CPU: gauge + line. Queue: line for backlog trend.
Alert thresholds
  • P99 latency > 500ms for 10 minutes → High severity
  • 5xx error rate > 1% for 5 minutes → High severity
  • DB CPU > 85% for 15 minutes → Critical for scaling
Interview tip
When describing your dashboard, justify the visualization choice and explain how alerts correlate to the first three steps of your investigation playbook.
