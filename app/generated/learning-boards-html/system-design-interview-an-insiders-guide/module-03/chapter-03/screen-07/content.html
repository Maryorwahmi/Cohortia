Eviction Policies Explained
Which entries to evict when memory is full—and why.
Least Recently Used (LRU)
Evicts the least recently accessed item—good when recency predicts future access.
Least Frequently Used (LFU)
Evicts items with the fewest accesses—tracks long-term popularity via counters.
First-In, First-Out (FIFO)
Removes the oldest entry by insertion time; simple but may evict hot items.
Random Replacement
Evicts a random item; trivial to implement but often inefficient compared to LRU/LFU.
Example: session cache
Use LRU when recent activity drives reuse.
Example: trending content
LFU fits workloads where long-term popularity matters.
Cost trade-off
LFU bookkeeping is heavier than LRU; justify overhead when access patterns require it.
