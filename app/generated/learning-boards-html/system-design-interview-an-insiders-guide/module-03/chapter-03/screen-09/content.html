Cache Stampede
Many concurrent cache misses overwhelm the origin—mitigate with locking or smoothing techniques.
Why it happens
A hot key expires and many clients simultaneously request it, causing a surge of origin queries.
Mitigation patterns
  • Distributed mutex so only one rebuilds the cache.
  • Probabilistic early expiration to stagger refreshes.
  • Stale-while-revalidate: serve stale data while background refresh occurs.
  • Pre-warm hot keys proactively.
Concrete example
When a product page goes viral, a single cache expiry can send thousands of requests to the database. Use a distributed lock or serve stale content while one process refreshes the cache.
Key Takeaway

Plan for hot keys: choose a mitigation that balances freshness, availability, and implementation complexity for your service-level goals.
