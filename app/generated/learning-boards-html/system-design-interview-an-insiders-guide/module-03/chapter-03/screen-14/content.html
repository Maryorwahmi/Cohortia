Module 3 › Chapter 3.3 › Key Concepts
Cache / Hit / Miss
Temporary storage; hit serves fast; miss fetches origin.
TTL / Invalidation
TTL auto-expires; invalidation updates or removes stale entries.
LRU / LFU / FIFO
Eviction by recency, frequency, or insertion order.
Write-Through / Write-Back
Write-through is consistent; write-back is faster but risky on failure.
Cache Stampede
Many simultaneous misses on a hot key overwhelm the origin.
Negative caching
Cache not-found responses briefly to reduce repeated origin hits.
Summary

Remember these concise definitions and trade-offs so you can explain choices quickly and accurately under interview pressure.
