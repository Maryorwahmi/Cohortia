Chapter 6.8 › Key Metrics
Queue signals
  • Queue Depth / Consumer Lag — backlog indicator
  • Production Rate — incoming load
  • Consumption Rate — processing throughput
Worker & broker metrics
  • Processing Latency — end-to-end consumer duration
  • Error Rates & DLQ Counts — quality of processing
  • CPU, Memory, Disk I/O — resource health for workers/brokers
Key Takeaway

Use a small correlated metric set and map them to precise actions like autoscale, alert, or failover to keep the system healthy.
