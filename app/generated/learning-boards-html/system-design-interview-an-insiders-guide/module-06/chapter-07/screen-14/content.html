Module 6 › Chapter 6.7 › Key Concepts
Idempotency
Repeatable operations that produce the same final state when applied multiple times.
Idempotency Key
A unique transaction id stored durably to detect and ignore duplicates.
Exactly-Once Limits
Achievable inside bounded systems; end-to-end guarantees require stronger distributed coordination.
Summary
Build idempotent consumers with durable keys and atomic writes. Treat at-least-once as the norm and design to make duplicates harmless.
