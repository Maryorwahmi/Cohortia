Hands-on

Starter code concept

The producer enqueues messages and exits. Consumers run until a stop event is set. To ensure all messages are processed before shutdown, call the queue method that waits for all tasks to complete.
Concrete fix
After producer_thread.join() add: message_queue.join() so the main thread waits until consumers called task_done() for every message.
Misconception: Checking queue.empty() is sufficient — it can lead to race conditions; use join for correctness.
Key Takeaway

Use queue.join() combined with task_done() to coordinate producers and consumers for a reliable shutdown sequence.

Starter Code Excerpt
# Wait for all messages to be processed
producer_thread.join()
message_queue.join()  # ← ensure all task_done() calls received
# Signal consumers to stop
stop_event.set()
Explanation: join blocks until every item put() into the queue has a matching task_done() call from consumers, ensuring no work is lost on shutdown.
