Module 6 › Chapter 6.5 › Exchange Types
Exchange quick reference
Direct: Exact routing-key match. Use for commands and targeted delivery.
Fanout: Broadcast to all bound queues. Use for notifications and pub/sub.
Topic: Pattern matching with '*' and '#'. Use for hierarchical routing like logs or sensor data.
Headers: Match on message headers. Use when routing needs multiple attributes.
Examples & Tips
Direct: printer.nyc.floor1 → routes to that printer's queue.
Fanout: user.registered → all services needing the event receive a copy.
Topic: logs.error.auth or sensor.room2.temperature → use patterns like 'logs.error.#' or 'sensor.#'.
Headers: Match tenant='acme' and severity='high' when routing depends on several attributes.
Misconception check: Exchanges are not interchangeable — choosing incorrectly adds complexity to consumers.
