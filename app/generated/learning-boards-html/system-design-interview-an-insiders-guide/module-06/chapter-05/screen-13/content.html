Module 6 › Chapter 6.5 › Broker vs Kafka
Feature comparison
Model: RabbitMQ = smart broker, Kafka = log-based stream.
Routing: RabbitMQ rich exchanges; Kafka topic/partition keys only.
Retention: RabbitMQ removes on ack; Kafka persists for configured retention.
Throughput: Kafka excels at extremely high throughput and horizontal scaling.
Use cases
RabbitMQ/ActiveMQ: Task queues, RPC, enterprise adapters, complex routing.
Kafka: Event sourcing, stream processing, log aggregation, analytics pipelines.
Interview tip: justify the trade-off in terms of routing needs, retention, and throughput rather than vendor familiarity.
