Module 6 › Chapter 6.5 › Key Concepts
Exchange
Routes messages from producers to queues according to exchange type and bindings.
Binding
Connects an exchange to a queue and specifies a routing key or pattern for delivery.
Routing Key
A message attribute used by exchanges to decide which bindings match and which queues receive the message.
Summary

Master these terms and you can design and explain broker topologies clearly in interviews and architecture discussions.
