Component responsibilities
Producer: Creates messages and publishes to an exchange with a routing key.
Exchange: Routes messages using its type and binding rules.
Binding: Connects exchange to a queue and provides a key or pattern for matching.
Queue: Stores messages until a consumer processes them.
Consumer: Receives and acknowledges messages, enabling at-least-once delivery.
Example
Topic routing for logs
Producer tags messages 'logs.error.auth'. A queue bound with 'logs.error.#' gets all error logs across components.
Common mistake
Binding mismatch
If binding keys use different separators or patterns, messages may never reach intended queues.
Key Takeaway

Design bindings consciously: they are the language the exchange uses to decide delivery.
