Module 6 › Chapter 6.5 › Practical Objectives
Hands-on mini checklist
  • Declare exchanges of types direct, fanout, and topic.
  • Declare queues and bind them with correct binding keys or patterns.
  • Run producer and at least two consumers to observe routing behaviors.
  • Use durable queues and message persistence when delivery guarantees are required.
Verification
Run and Explain
You are ready when you can run the producer, start multiple consumers, and explain why each consumer received or did not receive a message.
