Wildcard rules
'*' matches exactly one token. Example: 'sensor.*.temp' matches 'sensor.room1.temp'.
'#' matches zero or more tokens. Example: 'sensor.#' matches 'sensor', 'sensor.room1', and 'sensor.room1.temp'.
Use consistent separators (dots) and document the token scheme to avoid mismatch.
Examples
Binding: 'logs.error.#' → receives 'logs.error' and 'logs.error.auth'
Binding: 'animal.#' → receives 'animal.cat.cute' and 'animal.dog.bark'
Design tip: Start narrow and widen patterns only when needed.
Misconception: '#' is not a catch-all excuse — overly broad patterns cause noise and resource cost.
