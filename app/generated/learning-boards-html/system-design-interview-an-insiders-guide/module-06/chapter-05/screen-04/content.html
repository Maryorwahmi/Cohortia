Module 6 › Chapter 6.5 › AMQP & JMS
Core definitions
  • AMQP: Protocol standardizing exchanges, routing, and broker behavior.
  • JMS: Java API for message-oriented middleware; commonly used with ActiveMQ.
  • RabbitMQ: AMQP broker focused on exchanges, bindings, and flexible routing.
  • ActiveMQ: Enterprise broker with JMS support and multiple protocol adapters.
Analogy
Think of the broker as a post office where exchanges are distribution centers and bindings are addressing rules.
Misconception
These brokers are not the same as Kafka; they emphasize smart routing and per-message controls rather than log-based streaming.
Example
Payment event flow
A payment service publishes a transaction event; exchanges route it to fraud, accounting, and notification queues based on bindings.
Key Takeaway

Choose AMQP/JMS brokers when message routing logic and delivery guarantees matter more than raw append-only throughput.
