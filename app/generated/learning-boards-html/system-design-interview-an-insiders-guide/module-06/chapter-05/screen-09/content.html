connection = pika.BlockingConnection(pika.ConnectionParameters('localhost'))
channel = connection.channel()
channel.exchange_declare(exchange='direct_logs', exchange_type='direct')

result = channel.queue_declare(queue='', exclusive=True)
queue_name = result.method.queue

# Bind for 'error' and 'warning'
# channel.queue_bind(exchange='direct_logs', queue=queue_name, routing_key='error')
# channel.queue_bind(exchange='direct_logs', queue=queue_name, routing_key='warning')

channel.basic_consume(queue=queue_name, on_message_callback=callback, auto_ack=True)
channel.start_consuming()
Guidance
Exclusive queues: Tied to a single connection and deleted when it closes — ideal for per-consumer temporary subscriptions.
Acknowledgements: Use explicit basic_ack for at-least-once processing when message loss is unacceptable.
Binding keys: Add or remove bindings to control which messages reach this consumer.
Misconception: auto_ack=True makes processing simpler, but it removes safety when consumers crash during work.
