Tracing and Correlation
  • Attach a correlation id to the initial request and carry it through messages and logs.
  • Use structured tracing so you can reconstruct the causal path across services.
  • Expose job states so operators and users can see progress and failures.
State and Errors
Favor immutable messages and idempotent handlers to avoid shared mutable state conflicts. Route permanent failures to a dead-letter store and design compensating transactions to revert partial effects where necessary.
Misconception: eventual consistency is always unacceptable. In many business flows, brief inconsistencies are tolerable if you provide user feedback and recovery paths.
