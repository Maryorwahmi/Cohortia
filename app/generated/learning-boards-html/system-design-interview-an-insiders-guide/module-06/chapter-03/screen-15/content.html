Module 06 › Chapter 6.3 › Key Concepts — Part 1
Decoupling
Services publish events and do not depend on consumer availability, enabling independent evolution.
Fan-Out
One event is broadcast to multiple consumers so different workflows can run in parallel.
Load Leveling
A queue smooths bursts so consumers process at a sustainable rate and the system stays responsive.
Bottom summary: These patterns help you design systems that are resilient, scalable, and easier to evolve when coupled with operational controls such as monitoring, idempotency, and DLQ handling.
