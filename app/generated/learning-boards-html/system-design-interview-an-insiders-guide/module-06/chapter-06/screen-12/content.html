Beyond Simple Addition: Complex Tasks and Result Retrieval

Implementing Image Processing and Querying Task Outcomes

# 1. Define a complex task in proj/tasks.py
import time
from proj.celery import app

@app.task
def process_image(image_id, transformations):
    """A more complex task simulating image processing."""
    print(f"Processing image {image_id} with transformations: {transformations}")
    time.sleep(5) # Simulate heavy image processing
    processed_url = f"https://cdn.example.com/processed/{image_id}-{'-'.join(transformations)}.jpg"
    print(f"Image {image_id} processed. URL: {processed_url}")
    return {"image_id": image_id, "status": "completed", "url": processed_url}
Task Complexity

Tasks can accept multiple arguments and return complex data structures, which are then serialized and stored by the result backend.

# 2. Send task and retrieve result from client.py
from proj.tasks import process_image
import time

print("Sending image processing task...")

async_result_image = process_image.delay("user_upload_123", ["resize_lg", "watermark"])
print(f"Image processing task sent. Task ID: {async_result_image.id}")

print("
Waiting for results...")

# Retrieve result (blocks until ready, with timeout)
image_result = async_result_image.get(timeout=20)
print(f"Image task result: {image_result}")

Key Method: `.get()`

The `.get()` method on an `AsyncResult` object allows the client to retrieve the task's return value from the result backend, optionally with a timeout.

Key Takeaway

Celery tasks can handle complex logic and return structured results, which clients can retrieve using the `AsyncResult.get()` method from the configured result backend.
