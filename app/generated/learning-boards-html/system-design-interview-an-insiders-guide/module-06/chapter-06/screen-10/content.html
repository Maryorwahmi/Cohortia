Initializing Celery and Defining Your First Task

From Installation to `@app.task` Decoration

# 1. Install Celery and Redis
pip install celery redis
# 2. Create proj/celery.py
from celery import Celery

app = Celery(
    'my_app',
    broker='redis://localhost:6379/0',
    backend='redis://localhost:6379/0',
    include=['proj.tasks']
)

app.conf.timezone = 'UTC'
Explanation

The `Celery` instance is configured with Redis as both the message broker (for tasks) and the result backend (for task outcomes). `include` tells Celery where to find your task definitions.

# 3. Define Tasks in proj/tasks.py
import time
from proj.celery import app

@app.task
def add(x, y):
    """A simple task that adds two numbers."""
    print(f"Executing add task: {x} + {y}")
    time.sleep(2) # Simulate long-running work
    result = x + y
    print(f"Add task finished: {result}")
    return result
Key Concept: `@app.task`

The `@app.task` decorator registers a Python function as a Celery task, making it eligible for asynchronous execution by workers.

Pro-Tip

Use `time.sleep()` to simulate network delays or heavy computation during development, helping you observe asynchronous behavior.

Key Takeaway

Setting up Celery involves installing dependencies, configuring the `Celery` app with a broker and backend, and defining tasks using the `@app.task` decorator.
