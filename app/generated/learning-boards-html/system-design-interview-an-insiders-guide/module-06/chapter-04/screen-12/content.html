Module 06 › Chapter 6.4 › Hands-on: Create, Produce, Consume, and Observe
Task steps (copy these into terminals)
# 1. Create the topic
kafka-topics.sh --create --topic my_interview_topic --bootstrap-server localhost:9092 --partitions 2 --replication-factor 1

# 2. Verify
kafka-topics.sh --list --bootstrap-server localhost:9092
kafka-topics.sh --describe --topic my_interview_topic --bootstrap-server localhost:9092

# 3. Produce messages (open a new terminal)
kafka-console-producer.sh --topic my_interview_topic --bootstrap-server localhost:9092
# Type: Message One [Enter]
# Message Two [Enter]
# Message Three [Enter]

# 4. Consume all messages
kafka-console-consumer.sh --topic my_interview_topic --bootstrap-server localhost:9092 --from-beginning

# 5. Consume with a group (open another terminal)
kafka-console-consumer.sh --topic my_interview_topic --bootstrap-server localhost:9092 --group interview_group_1 --from-beginning

# 6. Open YET ANOTHER terminal and run the same group
kafka-console-consumer.sh --topic my_interview_topic --bootstrap-server localhost:9092 --group interview_group_1 --from-beginning
Expected observation
When two consumers share the same group id, partitions are split among them so new messages are load-balanced. Replaying from the beginning shows the entire historical stream in each separate group, but within a single group each message is processed once by one instance.
Troubleshooting
If consumers do not receive messages, confirm the bootstrap address, topic existence, and check for network or Docker port mappings blocking connectivity.
