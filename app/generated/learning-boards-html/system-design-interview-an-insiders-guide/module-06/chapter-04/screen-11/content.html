Module 06 › Chapter 6.4 › Basic Kafka CLI Commands
Common commands
The following are console examples to create, list, describe topics, produce messages, and consume from topics.
# Create a topic with 3 partitions and replication factor 2
kafka-topics.sh --create --topic my_new_topic --bootstrap-server localhost:9092 --partitions 3 --replication-factor 2

# List topics
kafka-topics.sh --list --bootstrap-server localhost:9092

# Describe a topic
kafka-topics.sh --describe --topic my_new_topic --bootstrap-server localhost:9092

# Produce messages
kafka-console-producer.sh --topic my_new_topic --bootstrap-server localhost:9092
# Type messages and press Enter

# Consume from the beginning
kafka-console-consumer.sh --topic my_new_topic --bootstrap-server localhost:9092 --from-beginning

# Consume with a group
kafka-console-consumer.sh --topic my_new_topic --bootstrap-server localhost:9092 --group my_group --from-beginning
Practical tips
  • Verify the cluster is reachable at the bootstrap-server address.
  • Describe the topic to inspect partition leaders and replicas before producing traffic.
  • Use consumer groups to observe load balancing across instances for testing.
Key Takeaway
CLI tools are reliable for local validation and debugging; treat them as the first step before integrating clients into your applications.
