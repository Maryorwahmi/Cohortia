Module 07 › Chapter 7.4 › What is a DAO?
Definition & Core Idea

A DAO is an organization whose rules are encoded as smart contracts and whose members make decisions by voting. This makes governance transparent and permissionless while relying on code to execute decisions.

Analogy
Like a constitution implemented in code: proposals are legislative acts, voting is the parliament, and contracts execute laws.
Concrete example
A protocol treasury DAO votes to fund a bug bounty; passed proposal transfers funds after a timelock delay.
Common misconception
DAOs remove governance complexity. In truth, they reframe it into contract and token design, which require testing and careful parameter choices.
Key Takeaway

DAOs make governance code-visible and enforceable on-chain, but safe DAO design requires explicit trade-offs and security measures.

Quick architecture callout
Governance Token
Holds voting power via delegation.
Governor
Proposes and counts votes.
Timelock
Delays execution for safety.
