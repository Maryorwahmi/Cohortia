Module 07 › Chapter 7.4 › OpenZeppelin Blocks
Key Components
ERC20Votes
Token with voting snapshots and delegation support. It lets the Governor read voting power at a historical block.
TimelockController
Holds execution power and enforces a minimum delay between queueing and execution.
Governor
Creates proposals, counts votes, and schedules successful proposals on the timelock for execution.
Role wiring
Correct role assignment is essential. Grant the Governor proposer and admin roles on the Timelock when appropriate, and revoke deployer admin privileges to avoid centralized control.
Quick checklist
  • Deploy token and delegate votes.
  • Deploy timelock with minDelay and initial roles.
  • Deploy governor with voting parameters and grant it proposer role.
  • Revoke deployer admin roles and grant governor timelock admin if required.
Key Takeaway
OpenZeppelin modules reduce risk, but incorrect wiring of roles and delays is a frequent source of vulnerabilities.
