Module 7 › Chapter 7.2 › View vs State-changing
View / Pure
  • Read-only calls that don't alter state.
  • Executed locally by a node, cost no gas.
  • Use a Provider to call these functions.
Concrete example
contract.count() returns a numeric value without creating a transaction.
State-changing
  • Modify contract state and create transactions.
  • Require a Signer to sign and send, consume gas.
  • Return a transaction response that needs tx.wait().
Common mistake
Calling a state-changing function with a Provider-only contract raises a signer missing error.
