Module 7 › Chapter 7.2 › Instantiate
Pattern
// Instantiate with a provider for reads
const provider = new ethers.JsonRpcProvider(SEPOLIA_RPC_URL);
const counter = new ethers.Contract(address, abi, provider);

// Instantiate with a signer for writes
const wallet = new ethers.Wallet(PRIVATE_KEY, provider);
const counterWithSigner = new ethers.Contract(address, abi, wallet);
Notice the contract object exposes the contract's functions. Read calls return values; write calls return a transaction response that you must await and confirm.
Example
If counter.count() returns a BigNumber, convert to string for logging. When calling counter.increment(), capture the returned tx and await tx.wait() to ensure it was mined.
Key Takeaway

The signerOrProvider argument determines whether functions perform free reads or signed writes; handle transaction responses explicitly.
