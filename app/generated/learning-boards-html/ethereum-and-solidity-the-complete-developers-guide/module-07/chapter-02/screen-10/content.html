Transaction flow
  1. Call a state-changing function with a Signer: const tx = await contract.increment();
  2. Get an immediate transaction response that includes tx.hash.
  3. Await confirmation: await tx.wait() to receive the receipt.
  4. Inspect receipt.status, gasUsed, and logs for events.
Why wait?
Waiting ensures the transaction was included in a block and that state changes are final for your application logic.
Example
After await tx.wait(), copy tx.hash into a public explorer to see confirmations, gas used, and any events your contract emitted.
Common mistake

Treating the immediate tx response as success without awaiting confirmation leads to race conditions and wrong UI state.
