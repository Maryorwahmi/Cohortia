Module 7 › Chapter 7.2 › Locate & Store
Step-by-step
  1. Run your deploy script and copy the printed address.
  2. Add the address to .env as COUNTER_CONTRACT_ADDRESS for scripts and frontends.
  3. Open artifacts/contracts/Counter.sol/Counter.json and extract the abi array.
  4. Import that ABI into your frontend or bundle it alongside your client code.
Pro Tip
Keep the ABI in source control or produce it as part of your build so frontend and contract remain in sync.
Common Mistake
Hardcoding addresses in multiple locations leads to confusion after redeploys. Use one canonical env entry.
Example
Add to .env: COUNTER_CONTRACT_ADDRESS="0xYourDeployedContractAddress" and in scripts read process.env.COUNTER_CONTRACT_ADDRESS so your interact script always targets the same deployed contract.
Key Takeaway

One source of truth for address and ABI prevents mismatches and simplifies deployments and client interactions.
