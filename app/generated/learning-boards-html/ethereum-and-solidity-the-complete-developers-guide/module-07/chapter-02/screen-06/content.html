What a Provider does

A Provider connects to a node and allows read-only operations such as calling view or pure functions and querying chain data. These calls are free because they do not create transactions.

Concrete example
Using a JsonRpcProvider for Sepolia, instantiate the contract with the provider and call contract.count() to read the current value without gas.
Misconception
A Provider cannot sign transactions. Attempting to call a state-changing function with only a Provider results in an error about missing signer or private key.
Key Takeaway

Use a Provider for reads. If you need to write, attach a Signer or Wallet so the call can be signed and broadcast.
