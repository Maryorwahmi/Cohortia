Configuration and artifacts

Save the deployed contract address from your deploy script into a configuration file or .env. Load the ABI from artifacts/contracts/.../MyContract.json to get the abi array.

Mnemonic
Address = location, ABI = function blueprint
Provider and Signer setup

Connect to Sepolia with a JsonRpcProvider. For transactions, use a Wallet with a private key or get a Signer from the browser wallet so calls can be signed.

Mnemonic
Provider = read-only node; Signer = account able to sign writes
Call flow

Call view functions directly through a Provider to read state. For state-changing functions, use the Signer, send the transaction, then await confirmation via tx.wait().

Verification and debugging

After tx.wait(), use the transaction hash in a public explorer to inspect gas usage and events. This makes debugging and support straightforward.
