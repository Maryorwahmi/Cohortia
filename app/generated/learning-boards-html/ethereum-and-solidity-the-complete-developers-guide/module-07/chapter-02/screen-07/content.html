What a Signer is

A Signer holds the authority to sign and submit transactions. Use a Wallet with a private key in scripts or obtain a Signer from the browser wallet for frontends.

Security note
Do not commit private keys to source control. Use environment variables or secure browser wallets to protect keys.
Common Error
Attempting to call a state-changing function with a Provider-only contract will produce a signer missing error.
Key Takeaway

Attach a Signer to your contract instance when you need to modify chain state, and protect private keys outside of code repositories.
