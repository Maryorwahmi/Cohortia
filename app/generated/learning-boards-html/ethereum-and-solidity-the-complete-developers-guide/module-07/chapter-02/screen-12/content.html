Module 7 › Chapter 7.2 › Common Mistakes
Signer vs Provider
Mistake: calling a write with a Provider-only instance. Fix: instantiate contract with a Wallet or get a signer from the provider.
ABI mismatch
Mistake: using an outdated ABI. Fix: extract abi from the exact artifact produced by the current compilation.
Security & Confirmations
Mistake: committing private keys to code or not awaiting tx.wait(). Fix: use .env variables, secure wallets, and await transaction receipts before assuming success.
Check
When you see an error, first confirm signer presence, verify the ABI source, and look up the transaction hash on the explorer to understand what happened.
