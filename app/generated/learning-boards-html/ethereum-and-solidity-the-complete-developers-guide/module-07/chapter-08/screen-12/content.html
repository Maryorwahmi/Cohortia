Storage Collision
If the new implementation inserts or reorders state variables, storage slots will map to different fields and data becomes corrupt. Never change variable order or types in incompatible ways.
Function Selector Clash
Transparent proxies separate owner-only proxy functions from implementation functions to avoid selector clashes. Still, careful naming and avoiding duplicate selectors prevents accidental call routing to the proxy instead of the implementation.
How OpenZeppelin Helps
  • Storage layout compatibility checks during upgrade time.
  • Secure proxy implementations and helper utilities in plugins for Hardhat and Truffle.
  • Warnings and errors that block unsafe upgrades until you resolve layout problems.
Common Mistake
Relying solely on manual inspection. Tooling reduces human error but does not replace a disciplined storage plan and strong access control policies.
