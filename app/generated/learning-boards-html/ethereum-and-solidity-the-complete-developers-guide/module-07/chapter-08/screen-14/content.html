Module 7 › Chapter 7.8 › Key Concepts
Proxy Pattern
Separation of storage (proxy) and logic (implementation) enables upgrades while preserving state.
Initializers
Constructors don't run in proxy context; use initialize functions and disable implementation initializers.
Access Control
Protect upgrade functions; with UUPS, implement _authorizeUpgrade to restrict who can upgrade.
Summary
Upgradeability is practical but increases complexity. Use initializers, strict access control, testing, and OpenZeppelin tooling to manage risk and keep user state safe.
