Deploy script essentials
Use your signer to deploy, then call the contract to fetch and format the feed's price for verification.
Security notes
Keep RPC URLs and private keys in .env; parameterize feed addresses per network to avoid mistakes.
Automation tip
Add an assertion that formatted price falls into an expected numeric window before promoting to production.
Script excerpt (illustrative)
const PriceConsumer = await ethers.getContractFactory('PriceConsumerV3');
const priceConsumer = await PriceConsumer.deploy(PRICE_FEED_ADDRESS);
await priceConsumer.waitForDeployment();
const latestPrice = await priceConsumer.getLatestPrice();
console.log('Formatted price', formatUnits(latestPrice, 8));
Key Takeaway
Validate the feed immediately after deploy to ensure the contract is wired to the intended network address.
