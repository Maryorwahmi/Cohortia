Module 7 › Chapter 7.3 › Integrating Price Feeds
Step-by-step integration
A deployable workflow to read a Chainlink feed and verify the output.
1. Setup Hardhat
Install dependencies and add @chainlink/contracts to dev dependencies.
2. Implement contract
Create PriceConsumer.sol, import AggregatorV3Interface, and write getLatestPrice.
3. Choose feed address
Select the correct network-specific ETH/USD feed address for Sepolia or your target net.
4. Deploy script
Write a script that deploys and then calls the contract to fetch and print the price.
5. Format units
Remember price feeds usually use fixed decimals; format with the feed's decimals when showing values.
6. Verify
Run the deploy and confirm raw and formatted prices. Add a test that asserts reasonable value ranges for the network.
