Module 7 › Chapter 7.3 › PriceConsumerV3
What the contract does
Instantiate the AggregatorV3Interface and call latestRoundData to read an aggregated price and metadata.
Key fields from latestRoundData
roundID, price, startedAt, timeStamp, answeredInRound — use timeStamp and answeredInRound to check freshness.
Common mistake
Returning the raw price without checking answeredInRound or timeStamp can expose you to stale data.
Code excerpt (illustrative)
import AggregatorV3Interface;
priceFeed = AggregatorV3Interface(_priceFeedAddress);
(..., int price, ..., uint timeStamp, uint80 answeredInRound) = priceFeed.latestRoundData();
// Check timestamp and answeredInRound for freshness
Pro tip
Format units off-chain when printing, but enforce freshness checks on-chain before critical actions.
