Module 7 › Chapter 7.3 › Chainlink Network
Network architecture
Independent nodes fetch data, an off-chain aggregation process computes a single answer, and the result is posted on-chain.
Node responsibilities
Each node queries its configured sources, signs its response, and submits to the aggregation layer.
Aggregation & posting
Aggregation reduces variance among sources and the aggregated answer is recorded on-chain for any contract to read.
Practical note
Feeds are updated periodically. Do not assume updates every block; check answeredInRound and timestamps.
Visual flow
Request sent by contract or scheduled node
Multiple nodes fetch from their sources
Aggregation computes a single answer
Answer posted on-chain for contracts to read
Key Takeaway
Designed redundancy and vetting reduce single-node risk, but application checks remain necessary.
