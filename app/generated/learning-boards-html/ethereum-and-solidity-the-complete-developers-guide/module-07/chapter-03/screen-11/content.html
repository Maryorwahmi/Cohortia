Module 7 › Chapter 7.3 › VRF Implementation
Practical steps
Inherit VRF base, subscribe, fund with LINK, request randomness, and implement the callback to consume the value.
Fund subscription
Use network-specific LINK token addresses to fund the VRF subscription so requests can be fulfilled.
Track request IDs
Store the returned request ID and map it to the requester state so you only act on the verified callback.
Asynchronous pattern
Request randomness → wait for coordinator → fulfillRandomWords called with verified numbers → update state and emit event.
Key Takeaway
Design state transitions around the asynchronous VRF callback and ensure subscriptions are funded on the correct network.
