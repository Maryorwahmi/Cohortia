Common mistakes & fixes
Short checklist to avoid the most frequent errors when using Chainlink services.
Stale price checks
Require timeStamp to be within an acceptable window or compare answeredInRound to roundID.
Wrong network address
Use environment configuration and tests to ensure feed/coordinator addresses match the target network.
Unfunded VRF requests
Fund subscription with LINK; verify balances before requesting randomness.
Assessment prompts
1) Explain why smart contracts cannot call external HTTP APIs directly. 2) Describe why block-based values are insecure for randomness. 3) Outline how you would validate a price feed before acting on it.
