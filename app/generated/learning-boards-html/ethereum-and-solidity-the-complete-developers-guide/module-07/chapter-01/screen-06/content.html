Code Walkthrough › hardhat.config.js
Why dotenv?
Loading secrets at runtime prevents accidental exposure in source control. It keeps API keys and private keys out of your committed files.
Accounts behavior
If PRIVATE_KEY is undefined the accounts array is empty and Hardhat cannot sign deployments. Always verify the environment variable before deploying.
Pro tip: test your config by calling getSigners and printing the balance.
Snippet
require("@nomicfoundation/hardhat-toolbox");
require("dotenv").config();

const SEPOLIA_RPC_URL = process.env.SEPOLIA_RPC_URL;
const PRIVATE_KEY = process.env.PRIVATE_KEY;

module.exports = {
  solidity: "0.8.20",
  networks: {
    sepolia: {
      url: SEPOLIA_RPC_URL,
      accounts: PRIVATE_KEY ? [PRIVATE_KEY] : [],
      chainId: 11155111
    }
  },
  etherscan: { apiKey: process.env.ETHERSCAN_API_KEY }
};
Check: correct RPC, presence of PRIVATE_KEY, and etherscan API key before deploying.
