Key Concepts › Core Terms
Testnet
A public blockchain for testing that uses test Ether and mirrors mainnet behavior.
Sepolia
The primary public Ethereum testnet used in this chapter for realistic deployments.
RPC URL
The HTTP endpoint provided by an RPC provider that your tools use to interact with the network.
Summary

These terms govern your deployment workflow: obtain an RPC URL, fund a deployer with test Ether, deploy to Sepolia, then verify the contract on the explorer.
