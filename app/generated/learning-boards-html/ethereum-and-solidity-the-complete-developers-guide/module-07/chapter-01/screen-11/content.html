Process Flow › Deployment Command
Command
npx hardhat run scripts/deploy.js --network sepolia
Lifecycle
  1. Compile contracts into artifacts.
  2. Connect to RPC using SEPOLIA_RPC_URL.
  3. Sign transaction with PRIVATE_KEY and broadcast.
  4. Wait for mining, then log the deployed address.
Console outputs to watch
  • Deployer address and balance
  • Transaction hash for the deployment
  • Final deployed contract address
Troubleshooting
Out-of-gas or connection errors indicate a need to increase gasLimit or check your RPC/API key and balance.
Key Takeaway

Observe the transaction hash and confirm it on the explorer; on Sepolia, patience is part of the workflow.
