Process › Configuring Hardhat
Checklist
  • Get an RPC URL from an RPC provider and store it as SEPOLIA_RPC_URL.
  • Place your wallet PRIVATE_KEY into a .env file and add .env to .gitignore.
  • Set chainId to Sepolia's numeric id when defining the network.
Common mistake
Hardcoding private keys or committing .env to source control.
Key Takeaway

Always use environment variables for secrets and confirm connectivity with a quick balance check before deploying.

Example Hardhat snippet
// hardhat.config.js snippet
require("@nomicfoundation/hardhat-toolbox");
require("dotenv").config();

const SEPOLIA_RPC_URL = process.env.SEPOLIA_RPC_URL;
const PRIVATE_KEY = process.env.PRIVATE_KEY;

module.exports = {
  solidity: "0.8.20",
  networks: {
    sepolia: {
      url: SEPOLIA_RPC_URL,
      accounts: PRIVATE_KEY ? [PRIVATE_KEY] : [],
      chainId: 11155111
    }
  }
};
Run a quick script that prints the deployer address and balance to verify the RPC and secrets are loaded.
