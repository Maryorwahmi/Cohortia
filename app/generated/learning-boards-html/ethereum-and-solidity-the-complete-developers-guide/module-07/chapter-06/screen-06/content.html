Module 7 › Chapter 7.6 › Burn‑and‑Mint
Mechanism

Burn → Verify → Mint

In burn-and-mint flows the source token is destroyed. The bridge must reliably prove that the burn occurred before minting on the destination, which shifts the security model from custody to verification integrity.

Benefit
No centralized custody of original tokens.
Risk
Minting without correct burn verification creates inflation risk.
Concrete example
If a protocol burns a native token on Chain A, it must present provable evidence before minting the corresponding token on Chain B to avoid duplicating supply.
Developer note
Design robust verification: use cryptographic proofs or a secure validator set. Treat verification as the critical attack surface, not just custody.
