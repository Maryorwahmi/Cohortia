Module 7 › Chapter 7.6 › Exploit Categories
Smart Contract Bugs
Code defects that allow attackers to alter state or extract funds. Mitigate with audits, tests, and conservative upgrade patterns.
Examples
  • Authorization flaws
  • Logic errors enabling double withdrawals
Trust Model Failures
Operator compromise, signer collusion, and oracle manipulation. Mitigate with governance transparency and defense-in-depth in key management.
Examples
  • Private key theft
  • Majority signer collusion
