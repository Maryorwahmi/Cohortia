Process Flow

IPFS CLI workflow

Follow these repeatable steps to move files into IPFS and confirm retrieval.

1 Initialize & run node
Create a local node and start the daemon so it can add and serve content on the network.
2 Add files
Use the add command to produce a CID for a file or root CID for a folder containing your build.
3 Retrieve & verify
Use a gateway or the cat command to fetch the bytes and confirm the CID matches the file.
4 Persist via pinning
If you need long-term availability, pin the content on one or more nodes or use a pinning service.
Concrete example
Add a small site folder, note the root CID, open index.html through a gateway to confirm rendering, then cat the file to verify bytes match your source.
Check your understanding
  • Why might a gateway stop serving your CID?
  • What does the cat command prove about a file?
Key Takeaway

Practice adding, retrieving, and verifying CIDs locally before integrating them into contracts to ensure the workflow is reliable.
