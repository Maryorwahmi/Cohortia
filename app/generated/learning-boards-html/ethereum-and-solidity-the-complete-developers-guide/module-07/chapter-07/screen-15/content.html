Module 7 › Chapter 7.7 › Key Concepts
CID (Content Identifier)
A cryptographic fingerprint that names content and guarantees integrity.
Pinning
Tell nodes to retain a CID so the content is preserved and not garbage collected.
IPFS Gateway
An HTTP bridge for browser access; useful but not a replacement for pinning.
Final takeaway

Treat CIDs as authoritative, pin important content for persistence, and use gateways for compatibility while maintaining decentralization.
