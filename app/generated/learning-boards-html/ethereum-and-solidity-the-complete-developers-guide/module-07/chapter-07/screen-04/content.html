Core Concept

Why centralized storage breaks decentralization

Centralized hosts create single points of failure and enable content changes without cryptographic verification. That undermines a DApp's guarantees.

Definition
Centralized storage serves content by location. If the host removes or alters files, references in contracts can no longer guarantee the original content.
Common mistake
Putting a provider URL in a smart contract and assuming immutability. Location-based URLs can change.
Pro tip
Classify assets: which must be immutable? Those should be content-addressed and pinned.
Analogy

Think of a URL-based file as a rented billboard: the landlord can repaint it. A content-addressed CID is like an archival print stored in multiple libraries — the content is verifiable and immutable.

Scenario
If your NFT metadata points to https colon slash slash my-server dot com slash art one dot png, the server owner can replace that file. If the token instead stores a CID, any auditor can fetch and verify the exact bytes associated with ownership.
Key Takeaway

Design assets that require permanence using content-addressed storage rather than single-host URLs.
