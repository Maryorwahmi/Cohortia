Pitfalls

Common mistakes and troubleshooting

Not pinning
If only your local node hosts the content, it can be garbage collected when nodes free space. Use pinning services for production assets.
Wrong CID format
A truncated or mistyped CID will fail resolution. Always use the exact string returned by the add operation.
Diagnostic step
Try retrieving the CID from another node and use the cat command to confirm the bytes. If retrieval fails across nodes, the CID likely wasn't pinned anywhere.
Checklist
  • Is the CID exactly as returned when you added the file?
  • Is the CID pinned on one or more nodes?
  • Can you cat the file locally and does it match the source?
Key Takeaway

Treat persistence as part of deployment. Pin critical assets and confirm resolution from multiple peers to avoid surprises.
