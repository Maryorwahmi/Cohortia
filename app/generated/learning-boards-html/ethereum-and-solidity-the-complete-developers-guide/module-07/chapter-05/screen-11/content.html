Example hardhat.config.js pattern
// network setup using env variables
module.exports = {
  solidity: "0.8.20",
  networks: {
    arbitrumSepolia: {
      url: process.env.ARBITRUM_SEPOLIA_RPC_URL,
      accounts: process.env.PRIVATE_KEY ? [process.env.PRIVATE_KEY] : [],
      chainId: 421614,
    },
  },
};
This pattern keeps keys out of source control. Replace the RPC and chainId with your chosen L2's values and use the appropriate native gas token when funding test accounts.
Quick checklist
  • Find RPC URL and chain ID in L2 docs.
  • Get test tokens from the faucet.
  • Update hardhat.config.js and run deploy with --network.
  • Verify contract on the L2 explorer.
