Module 7 › Chapter 7.5 › Hands-on Activity
Steps
  1. Pick an L2 testnet and find RPC URL and chain ID in docs.
  2. Acquire test tokens from the L2 faucet for gas.
  3. Add the network to hardhat.config.js using env vars.
  4. Run npx hardhat run scripts/deployL2Counter.js --network <name> and verify on the explorer.
Checks
  • Wallet has L2 native gas token
  • Correct chain ID used
  • Explorer shows the contract address
