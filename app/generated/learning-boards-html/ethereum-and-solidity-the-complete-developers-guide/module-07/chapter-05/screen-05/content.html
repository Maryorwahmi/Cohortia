Module 7 › Chapter 7.5 › Rollups: the basic pattern
Process
1
Sequencer collects transactions.
2
Sequencer executes and batches them.
3
Batch summary or proof posted to Layer 1.
What L1 needs
  • Minimal calldata or compressed data for state reconstruction.
  • Either a validity proof to instantly accept the batch, or calldata plus a challenge window to allow fraud proofs.
Key Takeaway

Rollups reduce L1 load by batching. The posted material determines whether verification is instant or challenge-based.

Concrete example

A token transfer batch includes sender, recipient, and amount entries compressed into a state update and either a cryptographic proof or calldata. L1 stores the proof or the data needed to reconstruct the new state root.

Common mistake
Assuming the sequencer is always trusted. Even with sequencers, rollups include mechanisms — proofs or challenges — that protect users when the sequencer misbehaves.
