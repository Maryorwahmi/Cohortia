Module 2 › Chapter 1.4 › Key Concepts
Node.js
A runtime that executes tooling and scripts outside the browser.
npm & package.json
Package manager and manifest for dependencies and scripts.
Hardhat
Framework that scaffolds projects and provides a local network for testing.
Takeaway

Verify Node/npm, initialize with npm init, install and require Hardhat and plugins, then use the local Hardhat Network to iterate quickly.
