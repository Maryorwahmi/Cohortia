Set up Node, npm and Hardhat

Create a dependable local toolchain using Node and npm, scaffold a Hardhat project, add ethers.js and testing plugins, and run a local Hardhat Network for fast, isolated testing.

In this lesson
From installation to local deployment: a practical, repeatable setup.
Prerequisite
A recent LTS of Node.js installed and terminal familiarity. Verify with the terminal commands shown.
Outcome
A scaffolded Hardhat project with plugins configured and a local node ready for deploys and tests.
Concept Map
Node & npm
Install and verify versions with the terminal.
Hardhat
Scaffolds projects, runs a local network, and integrates plugins.
ethers.js & Tests
Libraries for interacting with contracts and asserting behavior in tests.
Explore Key Topics
Install & Verify — Check node -v and npm -v to confirm your runtime.
Scaffold — Run npx hardhat to create contracts, scripts, and tests.
Local Node — Use npx hardhat node, then deploy to localhost for rapid feedback.
