Initialize a Node project

Follow a small set of commands to create a project and a package.json manifest that tracks dependencies and scripts.

mkdir my-first-hardhat-project
cd my-first-hardhat-project
npm init -y
The -y flag accepts defaults so you get a package.json quickly.
Why: package.json makes installs repeatable and supports scripts.
Tip: name the directory clearly to reflect the project.
Practical example

After npm init -y, install Hardhat so you have the dev toolchain recorded as a devDependency.

npm install --save-dev hardhat
Installing as a dev dependency keeps production bundles clean.
Key Takeaway

Initialize npm early and record devDependencies so your environment can be reproduced across machines.
