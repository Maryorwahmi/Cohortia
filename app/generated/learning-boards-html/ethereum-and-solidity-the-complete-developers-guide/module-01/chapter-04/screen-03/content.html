Module 2 › Chapter 1.4 › Learning Objectives
01
Run Hardhat Network

Start a local blockchain with npx hardhat node to get pre-funded accounts for testing and fast iterations.

Mnemonic: local sandbox for quick experiments.
VERIFIED COMPETENCY MILESTONE
02
Deploy & Test Locally

Use a second terminal to run npx hardhat run scripts/deploy.js --network localhost after starting the node.

Mnemonic: two terminals, local deploy.
VERIFIED COMPETENCY MILESTONE
03
Troubleshooting

Check Node/npm versions, re-run npx hardhat if scaffold is missing, and inspect terminal errors for missing plugins or typos.

Mnemonic: read the terminal output.
VERIFIED COMPETENCY MILESTONE
04
Secrets & Safety

Never hardcode private keys in config files. Use environment variables and exclude .env from version control.

Mnemonic: secrets belong outside code.
VERIFIED COMPETENCY MILESTONE
