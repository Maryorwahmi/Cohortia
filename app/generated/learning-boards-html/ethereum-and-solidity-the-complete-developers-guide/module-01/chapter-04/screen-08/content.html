Install

Core packages to add

npm install --save-dev @nomicfoundation/hardhat-ethers@^3.0.0 
@nomicfoundation/hardhat-chai-matchers@^2.0.0 
@nomicfoundation/hardhat-network-helpers@^1.0.0 
chai ethers@^6.0.0
These modern packages replace older plugin names and provide integrated APIs.
Why each matters
  • ethers.js: high-quality library to sign and send transactions.
  • Chai & matchers: expressive assertions for contract behavior.
  • Network helpers: utilities to manage snapshots and time in tests.
Misconception
Installing the packages without requiring them in the config means tests won't load plugin features automatically.
Key Takeaway

Install and require these libraries so your scripts and tests can use a consistent API for blockchain interactions and assertions.
