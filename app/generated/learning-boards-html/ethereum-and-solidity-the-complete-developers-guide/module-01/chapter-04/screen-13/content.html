Deployment Walkthrough

Start node and deploy sample contract

Terminal A: start node
npx hardhat node
You will see a list of test accounts and their private keys for local testing.
Terminal B: deploy script
npx hardhat run scripts/deploy.js --network localhost
The script compiles and deploys, then prints the deployed contract address to the terminal.
Misconception
Deployment output to a local node does not indicate mainnet publishing; it's a local, ephemeral environment for testing.
Key Takeaway

Run the node and the deploy script in separate terminals to validate the full toolchain and get fast feedback on deployments.
