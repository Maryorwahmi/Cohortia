Hierarchy

Typical scaffolded files and folders

  • hardhat.config.js — main configuration for compiler and plugins.
  • contracts/ — Solidity smart contract files like Greeter.sol or Lock.sol.
  • scripts/ — JavaScript deployment or interaction scripts.
  • test/ — test files using the installed testing framework.
Mnemonic: config + code + scripts + tests.
Concrete example
// hardhat.config.js (excerpt)
require("@nomicfoundation/hardhat-ethers");
/** @type import('hardhat/config').HardhatUserConfig */
module.exports = { solidity: "0.8.20" };
This example sets the compiler and includes the ethers plugin.
Misconception
Editing the config without understanding plugin requires can break tasks; add plugin requires at the top as shown by examples.
Key Takeaway

Familiarize yourself with the scaffolded folders and the config file; they are the control center for your project.
