Definition

Node.js and npm

Node.js executes JavaScript on your machine, while npm installs and manages packages. These tools let you install and run Hardhat, ethers.js, and test frameworks.

Verification example
node -v
npm -v
If these return versions, proceed. If not, install or reconfigure Node.
Why it matters
  • Hardhat and many libraries are distributed as npm packages; npm installs them into node_modules.
  • Build scripts, deployments, and tests are run with Node, so a working runtime is essential.
  • Package versions affect compatibility; prefer recent LTS releases of Node to avoid install errors.
Common mistake
Using an outdated Node version can cause install failures or runtime errors with modern packages.
Key Takeaway

Verify Node and npm first. They are the bedrock for everything that follows.
