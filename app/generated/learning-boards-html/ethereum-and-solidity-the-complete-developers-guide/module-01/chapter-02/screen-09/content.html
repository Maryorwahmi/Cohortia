Module 1 › Chapter 1.2 › Wallet Key Architecture
Components
Key generation → secure storage → signing
Wallets generate or import a private key, derive the public key and address, and securely store the private key in an encrypted file or a hardware device.
Software wallet
Private key stored encrypted on the device. Convenient but vulnerable to malware if the host is compromised.
Hardware wallet
Private key never leaves the device. Higher assurance for signing at the cost of user steps.
User action
Always verify addresses before approving a transaction and back up seed phrases offline in a secure location.
Concrete scenario
When you sign in MetaMask, the extension computes the hash and asks for a local signature. For high-value transactions, using a hardware wallet ensures the signature operation occurs inside the device where the private key is protected.
Key Takeaway

Prefer hardware wallets for significant assets and always back up seed phrases securely to recover access if a device is lost.

Misconception
Assuming a hardware wallet makes you immune to all attacks. It reduces risk but users still must guard seed phrases and check addresses.
