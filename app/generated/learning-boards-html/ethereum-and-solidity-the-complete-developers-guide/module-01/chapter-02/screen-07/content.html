Module 1 › Chapter 1.2 › Public-Key Cryptography
Concept
Private key and public key
A private key is a secret large random number. A public key is derived from it via a one-way function and can be shared.
Private key
Grants control over funds. Must never be exposed or typed into unknown sites.
Public key and address
Can be shared. Used to derive addresses and verify signatures.
Analogy
Think of the private key as the only physical key to a lockbox; the public key is the description of the lock that others can inspect to confirm the box matches the key's lock.
Concrete example (conceptual)
Simulated output: Private Key (KEEP SECRET): a1b2c3...; Public Key (derived): 04...; Ethereum Address (derived): 0x1234... This shows the derivation chain without exposing a usable key.
Key Takeaway

A private key controls funds; a public key and address provide a verifiable identity that others can use to send funds or check signatures.

Common mistake
Sharing your private key or seed phrase is equivalent to handing over access to all assets. Keep secrets offline when possible.
