Module 1 › Chapter 1.2 › Hashing & Key Pair Activity
Step-by-step
Safe conceptual exercise
1) Open an isolated SHA-256 calculator. 2) Type "Hello Cohortia!" and record the digest. 3) Change a single character and observe a different digest. 4) Re-type the original to confirm determinism.
Key generation (conceptual)
Use an offline or testnet generator to simulate private key creation and derive a public key and address. Do not use outputs for real funds.
Reflection
After these steps, list where you would store a seed phrase and how you would verify a hardware wallet's address display before approving a transaction.
Safety reminder
Never paste a private key or seed phrase into an online form. Use offline generation and hardware wallets for anything of value.
Key Takeaway

Practice the concepts with ephemeral keys and testnets, and adopt a strict checklist to keep production secrets safe.

Common pitfall
Using the same key material across environments or storing secrets in cloud-synced notes can lead to irreversible loss.
