Module 1 › Chapter 1.2 › Key Concepts
Cryptographic Hash Function
Fixed-size digest with determinism, one-way function, collision resistance, and avalanche effect.
Public-Key Cryptography
Private key (secret) and public key (derived) enable ownership and verification; addresses are derived from the public key.
Digital Signature
Signing a hash binds the signer to specific data and lets anyone verify authenticity and integrity using the public key.
Summary

These primitives form the security foundation: detect tampering with hashes, establish ownership with key pairs, and authorize actions with digital signatures.
