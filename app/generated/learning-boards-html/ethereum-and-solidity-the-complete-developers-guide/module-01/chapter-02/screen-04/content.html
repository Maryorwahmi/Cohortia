Module 1 › Chapter 1.2 › Cryptographic Hash Functions
Definition
Hash function
A mathematical algorithm that maps input data of any size to a fixed-size output called a hash or message digest.
Deterministic
Same input always produces the same hash, enabling reliable verification.
One-way
Computationally infeasible to reverse a hash to its original input.
Collision resistance
Practically impossible to find two different inputs with the same hash.
Avalanche effect
A single-bit change yields a drastically different hash, revealing tampering.
Analogy
Think of a hash as a sealed envelope fingerprint: you can confirm the envelope content hasn't changed without opening it by checking the fingerprint.
Common mistake
Confusing theoretical possibility of collisions with practical vulnerability. Use established strong functions like SHA-256 for safety.
Concrete example
Try hashing the words Cohortia and cohortia with a SHA-256 calculator. The outputs are completely different despite small input change, demonstrating the avalanche effect. Repeating the same input yields the same digest, demonstrating determinism.

Key Takeaway

Hashes let you check integrity cheaply: recompute a digest and compare it to the stored value to detect any change.
