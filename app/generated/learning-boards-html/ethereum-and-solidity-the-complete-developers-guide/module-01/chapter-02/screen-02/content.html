Module 1 › Chapter 1.2 › Learning Objectives
01
Explain hash properties
Identify determinism, one-way, collision resistance, avalanche effect
You will describe why each property matters for block integrity, and give an example showing how a small input change alters the digest.
Verified Competency Milestone
02
Hashing practice
Conceptual steps to hash a message and confirm determinism
You will conceptually walk through hashing a message and observing consistent output across repeated computations.
Verified Competency Milestone
03
Describe key pairs
Explain private vs public key roles and address derivation
You will explain how a private key yields a public key and how that public key is used to derive an Ethereum address for receiving funds.
Verified Competency Milestone
04
Sign & secure
Create and verify signatures; protect private keys
You will trace the signing flow: hash the transaction, sign with the private key, and verify with the public key, and learn best practices for safeguarding secrets.
Verified Competency Milestone
Bloom's ladder
Learn → Understand → Apply → Master
These objectives guide practical tasks: test hashing, simulate signing, and adopt secure habits so you can interact with testnets and wallets safely.
