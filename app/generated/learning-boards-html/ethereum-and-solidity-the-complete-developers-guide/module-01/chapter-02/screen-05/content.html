Module 1 › Chapter 1.2 › SHA-256 in Practice
Technical note
SHA-256 produces a 256-bit (64-hex) hash
Regardless of input size, SHA-256 always outputs a fixed-length digest, which makes storage and verification efficient across nodes.
Determinism example
Input: "Ethereum is awesome!" → compute SHA-256 twice; both outputs match exactly, proving determinism.
Misconception
A digest does not reveal the original input. It is a verifier, not a reversible encoding.
Use case
Verify large files or blocks by comparing short stored digests instead of retransferring data.
Concrete check
If you download a blockchain snapshot or a binary, compute its SHA-256 and compare to the published digest. A mismatch indicates corruption or tampering.
Quick example (conceptual)
Input: "Hello Cohortia!" → SHA-256 → 64-char hex. Repeat the input to confirm the same hex appears.
Key Takeaway

Use fixed-size hashes to perform inexpensive integrity checks across distributed systems.
