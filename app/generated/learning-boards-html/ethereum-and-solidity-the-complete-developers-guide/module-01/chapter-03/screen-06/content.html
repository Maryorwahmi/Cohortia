Process Flow

From Source to Deployed Contract

Compilation produces EVM bytecode which a creation transaction stores at the new contract address.

1
Write & Compile
Solidity source is compiled to bytecode and ABI metadata.
2
Create Transaction
Bytecode placed in data field of a transaction with empty "to" address.
3
Block Inclusion
EVM executes creation code and stores runtime bytecode at the new address.
Example
Deploying a token contract writes code and initial storage like total supply to chain. Later token transfers call the stored code to update balances.
Misconception
Deployment doesn't allow the contract to run unrelated initialization later; only the creation code executes on deploy.
Design Tip
Minimize on-chain initialization and heavy storage writes to reduce deployment gas costs.
Key Takeaway

Compilation and creation are distinct steps; the runtime bytecode written at deploy is what later calls execute under the EVM.
