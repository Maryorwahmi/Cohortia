Module 1 › Chapter 1.3 › Gas
Definition

Gas: Metered Computation

A unit that measures computational effort to prevent spam and compensate validators.

Security
Gas makes attacks expensive by tying computation to real cost.
Economic Incentives
Fees collected are paid to validators who process transactions.
Design Implication
Optimize for gas: storage and complex loops increase cost significantly.
Concrete Example
A function that writes many storage slots will consume far more gas than a function that only reads values. That extra cost is paid by the transaction sender.
Calculation
Transaction fee = gasUsed × gasPrice. If execution reverts, gasUsed is still charged.
Pitfall
Running out of gas reverts state but still consumes the gas already used by execution.
Key Takeaway

Gas links execution to economics: it enforces resource limits, deters abuse, and directly shapes contract design choices.
