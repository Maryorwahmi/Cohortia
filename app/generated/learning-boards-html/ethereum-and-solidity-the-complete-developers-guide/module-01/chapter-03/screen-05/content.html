Definition

Ethereum Virtual Machine (EVM)

A sandboxed, deterministic virtual machine that runs contract bytecode and manages state changes.

Deterministic Execution
Every node executes the same bytecode to reach the same state transitions.
Sandboxed Environment
No external I/O ensures predictability but requires oracles for off-chain data.
Gas-priced Operations
Every opcode consumes gas; complexity maps directly to cost.
Architecture Card
Nodes run an EVM instance. Contracts are compiled to bytecode. Transactions supply input data for bytecode execution and cause state changes when included in a block.
Example
A token transfer compiles to bytecode executed by the EVM which updates on-chain balances deterministically.
Misconception
The EVM is not an environment for arbitrary network access; external data needs trusted interfaces like oracles.
Key Takeaway

Understand opcode costs and sandbox boundaries to design efficient, secure contracts.
