Hands-on Activity

Explore a public block

Locate and read the block height, timestamp, transaction count, block hash, and parent hash to validate the chain linkage.

Step-by-step
  1. Find a recent block and note its block height and timestamp.
  2. Open the block details and copy the block hash and parent hash fields.
  3. Navigate to the parent block and compare its hash with the parent hash value to confirm they match.
  4. Inspect one transaction inside the block: find its hash, from and to addresses, and gas metrics.
Reflection and Tips
  • Matching parent and child hashes shows the chain link at that point.
  • Timestamps are set when a block is mined or validated and are part of the block header.
  • Public explorers make transparency tangible; think about what off-chain data is needed to map addresses to real identities.
Key Takeaway
Explorer fields are protocol fields you can use to verify the chain and observe transparency in action.
Common Mistake
Assuming on-chain data reveals identities directly; mapping addresses to real people often requires off-chain linkage.
