Module 2 › Chapter 2.3 › State mutability
Mutability types
view
Reads state but does not modify it. Free off-chain.
pure
Does not read or modify state. Pure computations only.
payable
Allows the function to receive Ether via msg.value.
Example: deposit
function deposit() public payable {
  balance += msg.value;
}
Deposit must be payable to accept Ether. msg.value contains the amount sent.
Best practices & pitfalls
  • Mark view and pure whenever possible to document intent and enable free off-chain inspection.
  • Only use payable when a function must accept Ether; otherwise revert accidental transfers by omitting payable.
  • Remember: view and pure are only free when called off-chain; on-chain calls still consume gas.
Key Takeaway
Use mutability specifiers to communicate behavior, prevent accidental Ether acceptance, and reduce cost for readers.
