Starter code (annotated)
contract SimpleWallet {
    address public owner;
    uint public balance;

    constructor() {
        owner = msg.sender;
        balance = 0;
    }

    function deposit() public payable {
        balance += msg.value;
    }

    function getContractBalance() public view returns (uint) {
        return address(this).balance;
    }

    function withdraw(uint _amount) public {
        // TODO: Implement access control and safe transfer
    }
}
This code demonstrates constructor initialization, a payable deposit handler, and a view getter that returns the contract's Ether balance. Your task is to implement withdraw robustly using require checks and safe sequencing of state updates and transfers.
Example checklist
  • Add require(msg.sender == owner, "Only owner can withdraw.").
  • Ensure address(this).balance >= _amount before transfer.
  • Perform state update before external calls to reduce reentrancy risk.
Common mistake
Transferring Ether and then updating internal balance; this can leave state inconsistent if the transfer fails or reentrancy occurs.
Key Takeaway
Require checks first, update state before external calls, and test from multiple accounts to validate access control.
