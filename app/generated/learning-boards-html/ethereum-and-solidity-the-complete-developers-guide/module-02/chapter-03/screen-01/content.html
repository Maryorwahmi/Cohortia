Functions, Visibility, and State Variables

Learn the rules that control who can call your code, when Ether can enter a function, and how persistent state is managed.

In this lesson
Define functions · Set visibility · Control state
Visibility
public, private, internal, external — choose access carefully.
Mutability
view, pure, payable — controls gas and state changes.
State
Variables declared outside functions persist on-chain.
Right side visual shows example cards that connect: a public getter, an external setter, an internal helper, and a private helper. These demonstrate how access and mutability combine to produce secure behavior and predictable gas use. You'll build a SimpleWallet later that uses owner checks and payable functions. Keep an eye out for common mistakes: leaving admin functions public, missing payable on deposit handlers, and unnecessarily writing to state inside loops.
