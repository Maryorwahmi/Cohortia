Module 2 › Chapter 2.3 › What is a function?
Definition

A function encapsulates a task and its inputs/outputs, plus visibility and mutability that govern access and state effects.

Concrete example
function calculateTax(uint amount) public pure returns (uint) {
    return amount / 10; // 10% tax
}
This function is pure because it only computes from its input and doesn't read or modify contract state.
Misconception
view or pure always free — clarify: they are free off-chain, but cost gas when called within on-chain transactions.
Key Takeaway
Mark intent with mutability to communicate behavior and optimize gas when possible.
Anatomy of a function
  • Signature: name and parameter types control how callers pass data.
  • Returns: specify return types so callers can use outputs directly.
  • Visibility: who can call this function externally or internally.
  • Mutability: whether it reads, writes, or receives Ether.
