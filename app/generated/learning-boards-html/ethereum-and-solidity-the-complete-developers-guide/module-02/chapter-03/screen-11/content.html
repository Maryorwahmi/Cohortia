Module 2 › Chapter 2.3 › SimpleWallet lab
Lab checklist
  1. Create SimpleWallet.sol and paste the starter code.
  2. Compile and deploy to JavaScript VM; record owner address.
  3. From a different account, call deposit and send Ether.
  4. Confirm getContractBalance and balance reflect the deposit.
  5. Implement withdraw with require checks, update balance, and transfer Ether.
  6. Test withdraw from owner (should succeed) and non-owner (should revert).
Reflection prompt
Why is updating internal state before making external transfers a safer pattern? Consider reentrancy and failure handling.
Hints
  • Use require with clear error messages for easier debugging.
  • Test deposit and withdraw with small Ether amounts first in the JavaScript VM.
  • Remember that msg.sender is the caller and msg.value is the Ether sent.
Key Takeaway
Walk through the entire deposit-to-withdraw flow and test both success and failure cases to validate access control and state updates.
