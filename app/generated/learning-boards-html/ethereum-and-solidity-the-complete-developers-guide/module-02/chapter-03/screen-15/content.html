Module 2 › Chapter 2.3 › Final reminders
Restrict access
Use private/internal for helpers and require checks for admin functions.
Signal mutability
Use pure/view for utilities and read-only queries, payable only when accepting Ether.
Guard state changes
Validate early, update storage before external calls, and test both success and failure cases.
Closing question
Where in your current project would changing a public setter to external or private reduce risk or gas? Try that in a small experiment in Remix.
