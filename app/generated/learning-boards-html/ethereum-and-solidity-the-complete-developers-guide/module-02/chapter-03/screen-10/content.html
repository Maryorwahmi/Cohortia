Module 2 › Chapter 2.3 › Mutability comparison
Examples
pure: calculateSum(uint a,uint b) public pure returns (uint)
view: getContractBalance() public view returns (uint)
payable: deposit() public payable { balance += msg.value; }
state-changing: increment() public { counter++; }
Practical notes
  • Prefer pure for deterministic utilities and view for read-only queries.
  • Mark deposit handlers payable and inspect msg.value to confirm expected transfers.
  • Remember off-chain calls to view/pure are free; on-chain calls still cost gas.
Key Takeaway
Pick the narrowest mutability that reflects the function's behavior to communicate intent and enable cost savings for off-chain inspection.
