Module 2 › Chapter 2.3 › Access control process
Step-by-step
  1. Set owner in constructor: owner = msg.sender.
  2. At function start, check require(msg.sender == owner, "Only owner can ...").
  3. Validate preconditions, e.g., sufficient balance.
  4. Update state to reflect the change before external calls.
  5. Execute safe transfer to the owner.
Concrete example
function withdraw(uint _amount) public {
    require(msg.sender == owner, "Only owner can withdraw.");
    require(address(this).balance >= _amount, "Insufficient balance.");
    balance -= _amount;
    payable(msg.sender).transfer(_amount);
}
Warnings & checks
  • Update state before transfer to reduce reentrancy exposure.
  • Ensure require messages are descriptive to ease debugging.
  • Test from non-owner accounts to confirm reverts and from owner to confirm success.
Key Takeaway
Use msg.sender checks with require to gate sensitive functions and validate state before making changes or sending Ether.
