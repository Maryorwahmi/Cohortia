Overview

What reference types are

They store pointers to data. Assigning copies the pointer, so multiple references may point to the same storage location.

Arrays
Fixed-size and dynamic. State arrays default to storage; local arrays require memory/storage annotation.
Strings & bytes
Strings are dynamic byte arrays and manipulation is gas-heavy. Use abi.encodePacked for concatenation.
More reference types
Structs
Group fields into a single custom type. Can be storage or memory depending on usage.
Mappings
Key-value lookups that live in storage and are efficient. Note: mappings cannot be iterated directly.
Key Takeaway

Reference types are powerful for complex state but require careful data location choices to avoid unintentional state changes and gas costs.
