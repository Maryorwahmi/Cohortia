Structs

Grouped fields for complex data

Use structs to encapsulate related properties. They can be stored in state or used as memory copies inside functions.

Example
struct Product { uint id; string name; uint price; bool available; }
Product public myProduct; // storage
Mappings

Efficient key-value storage

Mappings map a key type to a value type and are stored in contract storage. They provide efficient lookup but are not iterable.

Example
mapping(address => uint) public balances; // persistent balance lookup
Key Takeaway

Combine structs and mappings for organized persistent state, and be explicit about copies to avoid unintended storage mutations.
