Module 2 › Chapter 2.2 › Strings
Definition

Strings are dynamic bytes

They are reference types and may require memory annotation inside functions. Manipulation tends to be gas-heavy.

Common pattern
Use abi.encodePacked to concatenate and return a memory string when needed, but prefer off-chain processing if possible.
Practical advice
  • Avoid heavy string operations on-chain.
  • Use bytes for lower-level binary handling.
  • Pass strings as memory parameters for temporary use.
Key Takeaway

Minimize string work in critical on-chain paths; favor hashes and off-chain processing for heavy text tasks.
