Data Types & Variables

Understand what you store, where you store it, and how assignments behave.

16:9 HD Classroom
Value Types

Store data directly. Copy on assignment. Examples: uint, bool, address.

Reference Types

Store pointers to data. Assignments copy references. Examples: arrays, structs, mappings.

Orientation

Why types and locations matter

Solidity is deployed to a shared ledger and every storage write costs gas. Choosing types carefully makes your contract safer and cheaper. Small types can reduce gas; wrong locations can cause accidental state modification.

Example
Use uint8 for age and address payable when you intend to send Ether.
Misconception
Reference assignment copies the pointer, not the data — changes can affect the original storage.
Visual Concept
Value box
Contains actual data. Copying creates independent value.
uint myNumber = 42;
Reference pointer
Contains a location pointer. Multiple refs can point to the same storage.
uint[] storage arr = myArray;
