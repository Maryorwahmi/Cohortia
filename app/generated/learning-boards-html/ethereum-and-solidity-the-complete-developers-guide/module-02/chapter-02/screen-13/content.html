Safety checklist for common mistakes

Apply these checks during coding and reviews to avoid costly errors.

Overflow / underflow
Since 0.8.0, arithmetic overflows revert; avoid unchecked unless you intend wrap behavior and have tests to match.
Storage vs memory errors
Declare local reference types explicitly. If you need a local independent copy, use memory; if you need to persist changes, use storage.
String costs
Avoid heavy on-chain string manipulation. Store hashes or process text off-chain when feasible.
address vs address payable
Use payable for transfer targets to avoid accidental send failures. The type documents intent and enforces safety.
Pro tip

Add type and location checks to unit tests. Verifying storage vs memory and integer ranges in tests prevents subtle runtime failures.
