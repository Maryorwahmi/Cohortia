Fixed-size bytes

bytes1 ... bytes32

Use for fixed-length binary data such as hashes and IDs. They store raw bytes and are copied on assignment.

Example
bytes32 public documentHash; // ideal for cryptographic hashes
Enums

Constrained named states

Enums restrict values to a small, readable set and improve code clarity when representing finite states.

Example
enum State { Pending, Approved, Rejected }
State public currentState;

constructor() { currentState = State.Pending; }
Key Takeaway

Use bytesN for fixed binary values and enums for stable, finite states. Avoid reordering enum entries after deployment.
