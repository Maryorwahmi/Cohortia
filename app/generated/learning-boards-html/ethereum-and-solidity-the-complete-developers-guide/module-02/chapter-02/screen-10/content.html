Arrays at a glance

Fixed-size and Dynamic

Fixed-size arrays reserve a compile-time length. Dynamic arrays grow with push and shrink with pop. State arrays default to storage.

State example
uint[] public ages;

function addToArray(uint _value) public {
  ages.push(_value);
}
Memory arrays

Temporary arrays inside functions

You create memory arrays with new and return them to callers as memory copies. This is cheaper than persistent writes and required for safe returns of reference types.

Example
function getRecentAges(uint _count) public view returns (uint[] memory) {
  uint[] memory recent = new uint[](_count);
  // populate recent
  return recent;
}
Key Takeaway

Persist only when needed. Use memory for computation and return copies to callers to avoid exposing storage pointers.
