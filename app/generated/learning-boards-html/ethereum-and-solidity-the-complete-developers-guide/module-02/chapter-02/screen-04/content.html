Module 2 › Chapter 2.2 › Value Types
Definition

Value Types store data directly

When you assign a value type variable, you copy the underlying value. Later changes do not affect the original.

Example
uint public tokenSupply = 1_000_000_000;
uint copy = tokenSupply; // copy is independent
Misconception
Using smaller integer types always reduces gas. Reality: slot packing helps storage, but computation and external interfaces may still use 256-bit words.
Key Takeaway

Choose value types for primitive data that should not share state. Copying produces independent values.

Common Value Types
Booleans
Used for flags and conditions. Example: bool public isActive = true;
Integers
Signed and unsigned with bit sizes from 8 to 256. Default is int256/uint256.
Address & bytesN
Address holds a 20-byte account; bytesN stores fixed raw bytes, e.g., bytes32 for hashes.
Concrete example
bool public isActive = true;
uint8 public age = 30;
bytes32 public documentHash;
