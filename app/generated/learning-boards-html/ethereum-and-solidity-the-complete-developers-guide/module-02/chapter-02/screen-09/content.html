Module 2 › Chapter 2.2 › Storage vs Memory
Process

Decision flow

  1. Do you need persistence across transactions? If yes, use storage.
  2. Is the data temporary for computation or return values? If yes, use memory.
  3. Are you assigning a reference inside a function? Be explicit: storage or memory.
  4. When returning reference types, return a memory copy to the caller.
Concrete example
// storage reference - mutates state
User storage u = users[msg.sender];
u.isActive = false; // changes storage

// memory copy - safe local use
User memory copy = users[msg.sender];
copy.isActive = false; // does not change storage
Key Takeaway

Always specify memory or storage for local reference types and choose based on persistence needs to avoid accidental state writes and extra gas.
