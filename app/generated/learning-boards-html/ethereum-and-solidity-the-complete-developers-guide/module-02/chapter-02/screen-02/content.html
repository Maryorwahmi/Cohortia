Learning Objectives

Bloom: Learn → Understand → Apply → Master

Bloom's taxonomy
01
Differentiate value vs reference

Explain copy versus pointer semantics and why assignments may or may not mutate state. Visualize an example array reference change.

VERIFIED COMPETENCY MILESTONE
02
Identify common value types

Recognize practical uses for uint, int, bool, address, and bytesN and pick types based on constraints like non-negativity or size limits.

VERIFIED COMPETENCY MILESTONE
03
Work with arrays

Handle fixed and dynamic arrays, know how to push elements, and create in-memory arrays for temporary processing.

VERIFIED COMPETENCY MILESTONE
04
Choose storage vs memory

Decide when to keep data in contract storage and when to use memory for ephemeral data to control gas and side effects.

VERIFIED COMPETENCY MILESTONE
