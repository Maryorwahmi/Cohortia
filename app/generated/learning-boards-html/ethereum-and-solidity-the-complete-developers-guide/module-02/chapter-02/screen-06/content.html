Module 2 › Chapter 2.2 › Address Types
Definition

address and address payable

Address holds a 20-byte account identifier. address payable signals that the address can receive Ether and is used where transfers will occur.

Code example
address public owner;
address payable public recipient;

constructor(address _owner, address payable _recipient) {
  owner = _owner;
  recipient = _recipient;
}
Why it matters
Using address payable clarifies intent and avoids accidental transfers. When executing send or transfer operations, the EVM requires a payable address to accept Ether. This prevents mistaken transfers that would otherwise revert or fail silently depending on context.
Misconception
Assuming all addresses accept Ether. Use payable typing to make the intent explicit and safe.
Key Takeaway

Declare payable addresses when you plan to send Ether; otherwise use plain address for identity-only roles.
