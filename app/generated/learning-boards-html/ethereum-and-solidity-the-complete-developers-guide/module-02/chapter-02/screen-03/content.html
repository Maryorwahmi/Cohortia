Objectives — Code Checklist

Turn learning aims into habits while you write or review contracts.

Range check
Use the smallest uint that fits your domain. Example: uint8 for ages up to 120. Small widths reduce storage and can reduce gas cost when packed.
Payable intent
Declare address payable when you plan to send Ether. This prevents accidental transfers to non-payable addresses.
Return location
When returning arrays, return a memory copy. Solidity requires the return type to specify memory so callers receive a snapshot, not a storage pointer.
Storage side effects
Avoid assigning storage references for temporary edits. Use memory copies unless you intend to update persistent state.
