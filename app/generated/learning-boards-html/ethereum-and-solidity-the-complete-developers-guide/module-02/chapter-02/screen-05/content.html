Sizing and examples

// Unsigned and signed examples
uint public tokenSupply = 1_000_000_000; // good for large positive counts
int public temperature = -5;             // signed for negative values
uint8 public age = 30;                   // compact storage for age
Solidity defaults to 256-bit, but you can pick smaller widths to pack storage. Confirm packing by checking how variables lay out in storage slots.
Safety notes
Overflow/Underflow
Since Solidity 0.8.0 arithmetic that exceeds limits will revert. If you use unchecked blocks you lose that protection and must manage wrap behavior carefully.
Concrete decision example
For a counter up to one million, uint32 or uint40 would suffice. Use the smallest type that fits and consider slot packing with adjacent variables.
Key Takeaway

Match integer types to domain constraints and avoid micro-optimizations without measuring gas impact.
