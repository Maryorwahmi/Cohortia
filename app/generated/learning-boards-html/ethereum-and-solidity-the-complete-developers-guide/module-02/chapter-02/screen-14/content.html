Key Concepts

Value Types
Store data directly; copying creates independent values.
Reference Types
Variables hold pointers; multiple refs can point to the same data.
Storage vs Memory
Storage persists and costs more gas; memory is temporary and cheaper for computations.
Summary

Types and locations shape correctness, cost, and security. Apply the checklist and make choices explicit in your code.
