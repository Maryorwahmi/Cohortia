Module 2 › Chapter 2.1 › Deploy: JavaScript VM
Deployment steps
  1. Compile the contract with a matching compiler.
  2. Open Deploy & Run Transactions and pick Environment: JavaScript VM.
  3. Select your contract and click Deploy.
  4. Interact with the deployed contract and observe console logs.
Observations
View calls return instantly without gas. State changes appear as simulated transactions with gas metrics in the console.
Note: The JavaScript VM state is ephemeral and resets on reload.
Concrete example
Deploy HelloWorld, then invoke getMessage. The console will show the returned string and a simulated transaction record if the call was state-changing.
Key Takeaway

Use the JavaScript VM to iterate quickly and confirm behavior before switching to persistent networks.
