Module 2 › Chapter 2.1 › Pragma Directive
What it is
A compiler compatibility hint inside the source file
It tells the compiler which versions are acceptable. Using a matching compiler avoids syntax or semantic mismatches that lead to errors.
Best practice
Select the nearest compiler version in Remix that satisfies the pragma
If your pragma allows 0.8.x, choose a 0.8.x release in the Compiler panel rather than a 0.7.x or 0.9.x version.
Common mistake
Compiling code written for 0.7.x with a 0.8.x compiler can fail because of language changes. Always match ranges; if you need to move versions, refactor and test carefully.
Key Takeaway
Pragma is a safety control. Use it deliberately and pick a matching compiler to reduce surprises.
