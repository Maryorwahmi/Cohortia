Module 2 › Chapter 2.1 › Key Concepts
Solidity Compiler
Translates Solidity to bytecode and generates the ABI used to interact with the contract.
ABI
A JSON description of functions and events that external code uses to call the contract.
JavaScript VM
An in-browser simulated blockchain for quick testing without real gas or network delays.
Final takeaway
Keep the compile-deploy-interact chain clear: choose matching compiler versions, inspect ABI and bytecode, then test in the JavaScript VM before moving to persistent environments.
