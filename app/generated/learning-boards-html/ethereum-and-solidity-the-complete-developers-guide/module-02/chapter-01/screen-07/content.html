pragma solidity ^0.8.0;

contract HelloWorld {
    string public message;
    constructor() {
        message = "Hello, Cohortia!";
    }
    function getMessage() public view returns (string memory) {
        return message;
    }
}
This code shows license, pragma, contract, a public state variable, constructor, and a view function.
State variable
Declared once and stored on the contract; public variables get an automatic reader function generated by the compiler.
Constructor
Runs once at deployment to initialize state, such as setting the initial message string.
View function
A read-only function that returns state immediately without creating a transaction.
Key Takeaway

This compact structure is the canonical starting point for learning how state and functions interact in Solidity.
