Module 2 › Chapter 2.1 › ABI & Bytecode
ABI
A JSON contract interface for external callers
Use the ABI in applications to encode calls, decode results, and subscribe to events. It does not execute code; it describes function signatures.
Bytecode
The compiled executable payload deployed to the EVM
This is what gets deployed in a transaction. Verification tools and explorers compare deployed bytecode to compiled bytecode to confirm authenticity.
Concrete example
Compile HelloWorld in Remix. The compiler panel shows the ABI listing getMessage as a callable function. The bytecode is shown as the contract payload used when you hit Deploy.
Key Takeaway
Both ABI and bytecode are needed: ABI for interaction and bytecode for deployment. Keep them together when building apps that call contracts.
