Starter code (visual)
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract Counter {
    uint public count;
    constructor() { count = 0; }
    function increment() public { count = count + 1; }
    function decrement() public { count = count - 1; }
    function reset() public { count = 0; }
}
Your task: modify decrement to prevent count from going below zero, using a conditional or a require check.
Steps
  1. Create Counter.sol in the explorer.
  2. Paste starter code and save.
  3. Compile with a 0.8.x compiler and fix any errors.
  4. Deploy to JavaScript VM and test functions.
Testing checklist
  • Read count after deploy; it should be zero.
  • Call increment and verify count increases.
  • Implement safeguard in decrement and verify it never goes negative.
Challenge

Try enforcing count >= 0 using a conditional or a require statement. Think about gas cost and readability when choosing your approach.
