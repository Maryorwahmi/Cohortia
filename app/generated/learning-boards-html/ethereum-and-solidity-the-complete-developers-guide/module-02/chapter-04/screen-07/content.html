Definition
require()
Validate inputs and external conditions. Reverts and refunds remaining gas when false.
require(msg.sender == owner, "Only owner allowed");
require(address(this).balance >= _amount, "Insufficient balance");
Key Takeaway
Use require for expected validation failures and include helpful messages.
revert() and assert()
revert stops execution like require and refunds gas; assert checks invariants and consumes gas on failure.
// revert with custom error (Solidity 0.8.4+)
error InsufficientFunds(uint requested, uint available);
if (balance < _amount) {
    revert InsufficientFunds(_amount, balance);
}

// assert for invariants
assert(total >= processed);
Misconception
Do not use assert for input validation; it signals a bug and will consume gas on failure.
