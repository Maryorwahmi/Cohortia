Comparison
Bounded loop
Predictable iteration count. Suitable for small or fixed-size datasets.
Example
Summing a short memory array in a helper function used off-chain.
Takeaway
Prefer bounded loops for on-chain operations.
Unbounded loop
Iterates over storage that can grow. Risk of exceeding block gas limit as data grows.
Risk
Transaction reverts when gas limit is exceeded, rendering the function unusable.
Mitigations
  • Pagination: process slices with start and count.
  • Pull payments or per-user actions.
  • Off-chain aggregation with on-chain commits.
