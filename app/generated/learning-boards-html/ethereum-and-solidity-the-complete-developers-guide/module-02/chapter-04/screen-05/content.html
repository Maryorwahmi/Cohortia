For loop example
Sum an array using a for loop. Works for bounded arrays.
function sumArray(uint[] memory _arr) public pure returns (uint) {
    uint total = 0;
    for (uint i = 0; i < _arr.length; i++) {
        total += _arr[i];
    }
    return total;
}
Why this matters
Every iteration costs gas. Large arrays make calls expensive or impossible.
Mitigation
Use pagination: process a slice per transaction with start index and count parameters.
While loop note
A while loop executes while a condition remains true. It is less common for state-changing operations because ensuring termination is critical to avoid infinite gas consumption.
function countdown(uint _start) public pure returns (uint) {
    uint current = _start;
    while (current > 0) {
        current--;
    }
    return current; // returns 0
}
Common mistake
Iterating a dynamic, growing array in a public function. If the array gets large, the transaction can become unusable.
Key Takeaway
Plan loops with clear bounds and alternatives like chunking or off-chain aggregation to keep functions usable.
