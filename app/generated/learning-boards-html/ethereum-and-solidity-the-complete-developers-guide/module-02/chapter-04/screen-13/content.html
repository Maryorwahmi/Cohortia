Question 1
If processData iterates through an array that can grow to thousands of elements, what is the primary concern and which pattern mitigates it?
Model Answer
Primary concern: gas cost and hitting the block gas limit. Mitigation: pagination or chunking to process a limited number of elements per transaction.
Question 2
Which error primitive for owner check and which for an internal MAX_LIMIT invariant?
Model Answer
Use require for the owner check because it's an expected external condition. Use assert for MAX_LIMIT invariant because it signals a bug if violated.
Key Takeaway
When justifying answers, include gas behavior and intent: refund vs. bug signal.
