Question

Best way to signal a new order in a DEX?

Correct choice
Emit OrderPlaced(trader indexed, tokenAmount, price). Index trader for fast account queries; keep numbers in data.
Why not state?
Storing every order in state is expensive and unnecessary for off-chain consumers that can read logs.
Practical prompt
Decide which fields you will query by and index them; otherwise, keep them in data to save gas.
