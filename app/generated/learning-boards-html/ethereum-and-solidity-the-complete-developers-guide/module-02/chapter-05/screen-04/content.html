Module 3 › Chapter 2.5 › What is an Event?
Definition

Event as a log record

Events emit a permanent log entry during a transaction. Logs are cheaper than on-chain state and intended for off-chain consumption.

Concrete example
A Deposit event includes the depositor address and amount. When the contract emits it, wallets and UIs can update balances without reading contract storage.
Common misconception
Events are not a substitute for state: contracts cannot read logs and you must not rely on events for on-chain logic.
Teaching visual
Transaction Log
Append-only, indexed topics and data payloads. Cheaper than storing everything in state.
When to use
  • Notify UIs of state changes
  • Emit audit trails and analytics events
  • Trigger off-chain services
Key Takeaway
Use events to broadcast contract actions to off-chain listeners; keep sensitive data out of logs.
