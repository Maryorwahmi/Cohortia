Module 3 › Chapter 2.5 › Use Cases
Use cases
UI updates
Subscribe to events like Deposit to update user balances in real time without polling the contract state.
Analytics & explorers
Aggregate Transfer events to produce charts, volume reports, and transaction histories.
Off-chain triggers
Trigger email notifications, database writes, or server-side workflows when events occur.
Scenario
OrderPlaced(trader indexed, tokenAmount, price): index trader for quick account lookup; keep tokenAmount and price in data for cost reasons.
Misconception
Events do not trigger on-chain behavior automatically. They must be read and acted on by off-chain systems or subsequent transactions.
Key Takeaway
Map each event field to its consumer: index searchable keys, keep bulky details in data.
