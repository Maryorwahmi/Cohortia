Module 3 › Chapter 2.5 › Transfer & Approval
Event declarations
// Declare events
event Transfer(address indexed from, address indexed to, uint value);
event Approval(address indexed owner, address indexed spender, uint value);
Add these near the top of the contract. Index owner/from/to addresses for efficient filtering by wallets and explorers.
Emit statements
// In transfer()
balances[msg.sender] -= _value;
balances[_to] += _value;
emit Transfer(msg.sender, _to, _value);

// In approve()
// set allowance logic here
emit Approval(msg.sender, _spender, _value);
Key Takeaway
Emitting standard events helps wallets and explorers automatically display transfers and approvals.
