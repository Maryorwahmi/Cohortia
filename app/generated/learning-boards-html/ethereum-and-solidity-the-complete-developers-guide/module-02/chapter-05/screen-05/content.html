Module 3 › Chapter 2.5 › Declare & Emit
Syntax
// Declare events
event Deposit(address indexed sender, uint amount);
event OwnershipTransferred(address indexed previousOwner, address indexed newOwner);

// Emit inside a function after checks and state updates
emit Deposit(msg.sender, msg.value);
emit OwnershipTransferred(oldOwner, _newOwner);
Keep declarations concise and place larger or private fields in non-indexed parameters or avoid logging them entirely.
Patterns
Emit after state change
Perform require checks and update state before emitting to avoid misleading logs.
Index only keys you need
Limit indexed parameters to those you will realistically filter by.
Common mistake
Emitting sensitive user data in logs is public and irreversible.
Key Takeaway
Design events for efficient queries and emit them only when the transaction succeeds.
