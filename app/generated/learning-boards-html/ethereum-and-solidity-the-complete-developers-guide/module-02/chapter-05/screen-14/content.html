Module 3 › Chapter 2.5 › Key Concepts
Event
A log entry emitted by a contract to communicate off-chain actions efficiently.
Indexed parameter
Marked with indexed to become a topic, enabling fast filtering by nodes.
Transaction log
Append-only storage of topics and data where event information is recorded.
Summary
Design events to broadcast essential, non-sensitive signals; index only fields you will search often; and verify logs with the Remix console during development.
