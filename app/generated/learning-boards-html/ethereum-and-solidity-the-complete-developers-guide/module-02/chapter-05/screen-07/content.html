Module 3 › Chapter 2.5 › Indexed vs Non-indexed
Indexed (Topics)
Stored as hashed topics enabling fast node-side filtering. Up to three indexed params per event.
Example
Deposit(address indexed sender, uint amount) lets dApps query all Deposit events for a specific sender.
Trade-off
Indexed fields cost more gas. Index only what you will filter by.
Non-indexed (Data)
Stored in the event data payload. Cheaper but not directly searchable; clients must fetch logs then parse the data to filter by those fields.
Example
If amount is non-indexed, a dApp must retrieve Deposit logs and inspect the amount field to find large deposits.
Key Takeaway
Balance index use against gas cost: index identifiers, not every field.
