Module 3 › Chapter 2.5 › Key Concepts
Emit after state change
Ensure events reflect committed state to avoid misleading logs.
Index sparingly
Limit indexed params to ones you will actually filter on.
Use topics
Topics enable fast node-side filtering by event signature and indexed parameters.
Save bulky data for data payload
Keep large or rarely-filtered fields in the non-indexed data section to control gas.
Don't log secrets
Event logs are public; never emit private information or secrets.
Events ≠ on-chain state
Contracts cannot read logs; persist values in state if contracts must access them later.
Final note
Use events to bridge on-chain actions to off-chain systems, thoughtfully balancing searchability and cost.
