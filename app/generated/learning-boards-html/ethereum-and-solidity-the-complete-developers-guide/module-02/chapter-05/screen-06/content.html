Module 3 › Chapter 2.5 › Emit Events Safely
Pattern

Validate → Mutate → External → Emit

Follow the sequence to ensure emitted logs describe a committed change.

function withdraw(uint _amount) public {
    require(msg.sender == owner, "Only owner can withdraw.");
    require(address(this).balance >= _amount, "Insufficient balance.");

    // mutate state first
    balances[msg.sender] -= _amount;

    // external action
    payable(msg.sender).transfer(_amount);

    // then emit
    emit Withdrawal(msg.sender, _amount, block.timestamp);
}
Explanation & Example
Concrete example
In withdraw, emitting after transfer prevents false logs when the transfer reverts.
Pitfall
Emitting before state change risks recording actions that never completed if the transaction later fails.
Key Takeaway
Order your function steps so events always reflect the final contract state.
