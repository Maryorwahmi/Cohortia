Module 3 › Chapter 2.5 › Common Mistakes
Mistakes
  • Logging private data — logs are public and immutable.
  • Indexing every field — unnecessary indexed params raise gas costs.
  • Relying on events for on-chain logic — contracts cannot read logs.
  • Emitting before state changes — leads to inconsistent or misleading logs if a revert occurs later.
Guidance
Audit your events: ensure they provide necessary info for consumers but avoid excess detail that raises cost or leaks data.
Key Takeaway
Events should be minimal, public-safe, and focused on off-chain consumers; use state for anything contracts must read.
