Module 3 › Chapter 2.5 › Topics & Log Structure
Architecture
An event log contains the event signature as topic[0], up to three indexed parameter topics, and the ABI-encoded non-indexed data payload. Nodes can filter on topics efficiently.
Topic 0
Event signature hash. Always present for that event type.
Topics 1–3
Hashed indexed parameters used for fast filtering by RPC methods.
Data section
ABI-encoded non-indexed parameters. Clients fetch and decode these after topic-based filtering.
Practical note
Filter by topic for efficiency. To search a non-indexed value requires downloading logs and decoding the data section, which is slower.
Key Takeaway
Design events to expose searchable identifiers in topics and put large payloads in data to control gas cost.
