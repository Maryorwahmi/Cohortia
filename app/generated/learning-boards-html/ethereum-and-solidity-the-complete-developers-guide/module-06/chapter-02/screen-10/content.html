Running tests and interpreting results

Run tests and use failure messages and receipts to debug contract behavior.

Command
npx hardhat test

This runs compilation and test execution on Hardhat Network, printing passes and failures with helpful messages.

Debugging checklist
  • Read the failing it description and assertion message for expected vs actual values.
  • Ensure you awaited transactions and calls.
  • Isolate the failing test and add logs or examine the transaction receipt.
  • Check constructor args and deployment timing in beforeEach.
Safety note

Never include real private keys or mnemonics in tests. Use Hardhat's ephemeral accounts for local testing.
