Learning Objectives

Grow a reliable Hardhat testing workflow: install, author, assert, and run tests with clear expectations.

01
Initialize a Hardhat project

Install hardhat and run npx hardhat to scaffold a JavaScript project. This sets up the directories and config used for testing.

VERIFIED COMPETENCY MILESTONE
02
Understand test file structure

Use describe and it blocks, and await contract calls. Recognize hooks like beforeEach to prepare state before each test.

VERIFIED COMPETENCY MILESTONE
03
Use Chai and Waffle matchers

Install @nomicfoundation/hardhat-chai-matchers and use expect to assert values, events, and reverts in a readable way.

VERIFIED COMPETENCY MILESTONE
04
Deploy and assert initial state

Write tests that deploy a new contract instance and verify constructor-initialized values with expect(...).to.equal(...).

VERIFIED COMPETENCY MILESTONE
