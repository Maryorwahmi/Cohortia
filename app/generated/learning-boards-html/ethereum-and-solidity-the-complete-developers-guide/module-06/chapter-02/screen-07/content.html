Definition

SimpleStorage.sol — a minimal contract to test

A compact contract that illustrates constructor initialization, state changes, and getters.

Contract (visual)
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract SimpleStorage {
    uint256 public storedData;

    constructor(uint256 initialData) {
        storedData = initialData;
    }

    function set(uint256 x) public {
        storedData = x;
    }

    function get() public view returns (uint256) {
        return storedData;
    }
}
Testing implications
  • Constructor arguments determine initial assertions in your first test.
  • set is a transaction: await it, then call the getter to assert updated state.
  • get is a view that returns a promise you must await in tests.
Example assertion
expect(await simpleStorage.get()).to.equal(100)
Common mistake

Forgetting to await a transaction or a call can return a pending promise and cause false test behavior.
