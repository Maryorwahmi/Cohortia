Definition

Install testing helpers and ethers

Add Chai matchers and ethers to make tests expressive and able to deploy contracts.

Install these packages
npm install --save-dev @nomicfoundation/hardhat-chai-matchers @nomiclabs/hardhat-ethers ethers

These packages give you Solidity-aware assertions and the ability to deploy and interact with contracts through ethers.js.

Example assertion
expect(await simpleStorage.get()).to.equal(100)
Why the matchers help
  • They provide event and revert checks tailored for Solidity.
  • They produce clearer failure messages than generic assertions for contract interactions.
  • They reduce manual decoding or receipt checks in many common cases.
Key Takeaway

Install testing plugins early so your assertions are idiomatic and maintainable.
