Write your first test file

A code walkthrough that shows the common deployment and assertion pattern.

Test file (visual)
const { expect } = require("chai");
const { ethers } = require("hardhat");

describe("SimpleStorage", function () {
  let SimpleStorage;
  let simpleStorage;

  beforeEach(async function () {
    SimpleStorage = await ethers.getContractFactory("SimpleStorage");
    simpleStorage = await SimpleStorage.deploy(100);
  });

  it("Should deploy with the correct initial value", async function () {
    expect(await simpleStorage.get()).to.equal(100);
  });
});
Explanations & tips
  • beforeEach: Deploy a fresh contract instance before each it block to avoid shared state.
  • await: Await both deployment and subsequent contract calls or transactions.
  • expect: Use expect(...).to.equal(...) for exact checks; use matchers for events or reverts.
Common mistake

Forgetting to await deployment or calls leads to unresolved promises and incorrect assertions.
