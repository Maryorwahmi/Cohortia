Activity: Implement tests for Counter.sol

Write tests that verify constructor initialization, increment, and decrement behavior.

Starter test template
const { expect } = require("chai");
const { ethers } = require("hardhat");

describe("Counter", function () {
  let Counter;
  let counter;
  const initialValue = 5;

  beforeEach(async function () {
    Counter = await ethers.getContractFactory("Counter");
    counter = await Counter.deploy(initialValue);
  });

  it("Should deploy with the correct initial count", async function () {
    expect(await counter.getCount()).to.equal(initialValue);
  });
});
Activity checklist
  • Deploy with a known initial value in beforeEach.
  • Write tests for increment and decrement that await transactions and assert the resulting state.
  • Run npx hardhat test and fix any await or setup errors that appear.
Key Takeaway

Small, repeatable tests build a foundation for testing more complex contract logic later.
