Core Concept

What is Hardhat and the testing stack?

Understand the role of Hardhat, Mocha, Chai, Waffle matchers, and ethers in unit testing.

Definitions
  • Hardhat: Local Ethereum network and toolchain for compiling, running scripts, and testing.
  • Mocha: Test runner providing describe and it structure.
  • Chai: Assertion library used with expect style for readable checks.
  • ethers.js: Library to deploy and interact with contracts in tests.
Example
Use ethers.getContractFactory and call deploy(100) to construct a SimpleStorage with an initial value in a beforeEach hook.
Why this composition matters

Combined, these tools let you create reproducible test environments, deploy fresh contract instances for isolation, and write clear assertions about behavior and events.

Common misconception: "My tests can share one deployed contract across many it blocks." That often hides stateful interactions and causes flakiness; prefer beforeEach for isolation.

Key Takeaway

Treat the stack as roles: environment, structure, assertions, and RPC layer; use each for its purpose to write robust tests.
