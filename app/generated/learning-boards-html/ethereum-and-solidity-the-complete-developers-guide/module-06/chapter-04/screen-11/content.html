Module 06 › Chapter 6.4 › Complex Interactions
State machine mapping
List states and transitions, then write focused tests for each transition with clear actor roles.
Scenario card: Auction cycle — bid, outbid with refund, fast-forward, endAuction, settle to beneficiary.
Scenario card: Vault lifecycle — deposit, attempt early withdraw, fast-forward, withdraw and emit event.
Testing tactics
  • Script realistic actor behavior in tests using multiple signers.
  • Use snapshots to return to configured states between scenarios.
  • Assert events, storage, and balances, accounting for gas where necessary.
Pro tip
Break long flows into smaller tests that validate a single transition; combine them in integration tests where appropriate.
