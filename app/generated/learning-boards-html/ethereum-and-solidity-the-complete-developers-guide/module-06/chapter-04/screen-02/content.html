Learning Objectives
Practical outcomes and verified milestones to guide your tests.
01
Time-dependent tests
Use EVM time controls and mining to validate time-locked behavior and auctions. VERIFIED COMPETENCY MILESTONE
Mnemonic: Time → Mine. Remember to mine a block after increasing time.
02
EVM snapshotting
Save and revert state for fast isolated tests around a costly initial setup. VERIFIED COMPETENCY MILESTONE
Mnemonic: Snapshot → Revert. Use before/after hooks to manage IDs.
03
Gas cost analysis
Capture transaction receipts and assert gas usage to detect regressions. VERIFIED COMPETENCY MILESTONE
Mnemonic: Measure Gas. Use reasonable thresholds and closeTo for balance assertions.
04
Mocking external deps
Use lightweight mocks to control tokens or oracles and keep tests focused. VERIFIED COMPETENCY MILESTONE
Mnemonic: Mock for Focus. Mock what you need to control and assert deterministically.

These objectives are arranged so you first learn the mechanisms, then apply them in tests, and finally use them together for robust integration-style test scenarios.
Verified Competency
Complete the activity tests and pass assertions for time behavior, snapshot isolation, gas thresholds, and a mocked external call.
