Module 06 › Chapter 6.4 › EVM Snapshotting
What is a snapshot?
A snapshot stores the entire in-memory EVM state so you can return to it quickly using evm_revert.
before(async function () {
  // expensive global setup
  // deploy factory, preload assets
});

beforeEach(async function () {
  snapshotId = await ethers.provider.send("evm_snapshot", []);
});

afterEach(async function () {
  await ethers.provider.send("evm_revert", [snapshotId]);
});
Use snapshots to speed up test suites where the initial configuration is costly to create but identical across many tests.
Guidelines & pitfalls
  • Take a new snapshot for each test run to avoid reusing old IDs incorrectly.
  • Reverting restores balances, storage, and deployed contracts to the saved state.
  • Snapshots are testing conveniences only; they don't exist in production networks.
Misconception
Snapshots are not a substitute for good test isolation design; they are a performance optimization for heavy setups.
