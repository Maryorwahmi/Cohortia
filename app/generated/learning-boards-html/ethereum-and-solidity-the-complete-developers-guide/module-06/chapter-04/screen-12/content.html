Module 06 › Chapter 6.4 › Auction Activity
Activity checklist
  1. Deploy Auction with 1-hour bidding time and beneficiary.
  2. Test revert when bidding after end by fast-forwarding time and mining.
  3. Test revert when ending auction too early.
  4. Simulate a full auction: addr1 bids, addr2 outbids, fast-forward, endAuction, assert event and balances.
Tip: Use ethers.getSigners() for multiple actors and ensure they have funds before bidding. Use snapshots to reuse a configured deployment for multiple scenario tests.
Starter test template
beforeEach(async function () {
  [owner, addr1, addr2] = await ethers.getSigners();
  Auction = await ethers.getContractFactory("Auction", owner);
  auction = await Auction.deploy(BIDDING_TIME, owner.address);
});

it("Should simulate a full auction cycle", async function () {
  await auction.connect(addr1).bid({ value: ethers.utils.parseEther("1") });
  await auction.connect(addr2).bid({ value: ethers.utils.parseEther("2") });
  await ethers.provider.send("evm_increaseTime", [BIDDING_TIME + 1]);
  await ethers.provider.send("evm_mine");
  const tx = await auction.connect(owner).endAuction();
  await expect(tx).to.emit(auction, "AuctionEnded");
});
