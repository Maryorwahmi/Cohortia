Module 06 › Chapter 6.4 › Snapshot Usage
Pattern
Use before for expensive one-time setup, beforeEach to snapshot, afterEach to revert.
before(async function () {
  // heavy setup only once
});

beforeEach(async function () {
  snapshotId = await ethers.provider.send("evm_snapshot", []);
});

afterEach(async function () {
  await ethers.provider.send("evm_revert", [snapshotId]);
});
Practical tips
  • Take snapshots after all mocks and configs are in place so each test inherits them.
  • Track snapshot ids carefully if nested snapshots are used inside tests.
  • Use snapshotting to speed up suites that would otherwise redeploy identical state repeatedly.
Pitfall
Reverting to the wrong snapshot id can hide test failures. Always reassign snapshotId in beforeEach.
