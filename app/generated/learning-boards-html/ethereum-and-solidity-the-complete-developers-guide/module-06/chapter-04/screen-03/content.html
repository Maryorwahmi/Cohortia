From objective to test
Concrete test tasks that demonstrate each objective in practice.
Time Tests
Write tests that fast-forward the EVM, mine a block, and assert time-locked withdrawals revert before unlock and succeed after.
Snapshots
Use evm_snapshot in beforeEach and evm_revert in afterEach to return to a known state quickly.
Gas checks
Capture the receipt gasUsed and assert it stays within a threshold to detect regressions.
Mocks
Deploy minimal mocks for tokens or oracles to control responses and avoid heavy dependencies.
Verified Milestone
Complete a set of tests that cover time behavior, snapshot isolation, a gas assertion, and a mocked external call. All assertions should be deterministic and fast.
Quick mnemonic
Time → Snapshot → Measure → Mock
This sequence helps you choose the right tool when a test needs more control, isolation, or performance checks.
Try this
When a test is slow or flaky, ask: can I change time, snapshot state, measure gas, or mock an external call?
