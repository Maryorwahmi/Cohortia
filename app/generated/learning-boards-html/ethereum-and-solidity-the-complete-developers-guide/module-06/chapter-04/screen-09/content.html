Module 06 › Chapter 6.4 › Gas Cost Analysis
How to measure
Send tx, await receipt, read gasUsed, optionally multiply by effectiveGasPrice for cost.
const tx = await contract.doSomething();
const receipt = await tx.wait();
console.log("Gas used:", receipt.gasUsed.toString());
expect(receipt.gasUsed).to.be.lt(ethers.BigNumber.from("100000"));
Best practices
  • Establish a baseline by logging gas in local runs before setting thresholds.
  • Use conservative thresholds and avoid asserting exact numbers to account for minor variance.
  • Combine gas checks with profiling for deeper optimizations.
Watch out
Gas depends on prior state and storage layout. Ensure tests set consistent conditions to make comparisons meaningful.
