Module 06 › Chapter 6.5 › Checks-Effects-Interactions
Pattern

Checks → Effects → Interactions

Checks

Validate balances, permissions and return early on failure.

Effects

Update storage to reflect the operation before any external call.

Interactions

Call external contracts or transfer funds after state is final.

Key Takeaway

Order matters. CEI reduces reentrancy windows and makes reasoning about state easier during audits.

Example Transformation
// Effect before interaction
uint256 amount = balances[msg.sender];
require(amount > 0);
balances[msg.sender] = 0; // Effect
(bool success, ) = msg.sender.call{value: amount}(""); // Interaction
require(success);
Misconception: CEI is sufficient for all cases. In multi-step functions or when calling third-party contracts that depend on multiple state variables, add a mutex to be safe.
