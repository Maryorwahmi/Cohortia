Module 06 › Chapter 6.5 › SafeMath vs Compiler Checks
SafeMath (pre-0.8.0)
Use SafeMath library

Replace x = x.add(1) and x = x.sub(1) to ensure operations revert on wrap.

Useful when project cannot upgrade compiler due to dependencies. Adds explicit safety at the call site.
Solidity 0.8.0+
Built-in checked arithmetic

Arithmetic operations revert automatically on overflow or underflow, simplifying code and reducing library use.

When upgrading, validate existing contracts and tests, and still include boundary tests to document behavior for auditors.
