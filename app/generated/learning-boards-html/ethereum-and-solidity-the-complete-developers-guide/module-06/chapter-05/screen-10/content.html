Test Template
// Test 1: Exploit
// 1. Deploy VulnerableWallet (pragma ^0.7.0)
// 2. Deposit balances for owner and attacker
// 3. Attacker calls withdraw(amount > balance)
// 4. Assert attacker wallet balance in contract becomes very large (underflow)

// Test 2: Patch
// 1. Update contract to use SafeMath or pragma ^0.8.0
// 2. Deploy patched contract
// 3. Repeat withdraw with too-large amount
// 4. Expect revert
Practical tips
  • Seed attacker with a small deposit so withdraw is plausible
  • Use precise asserts: expect(balance).to.be.gt(initial) for underflow exploit
  • After patch, expect transaction to revert or the balance to remain unchanged
Key Takeaway

Testing the exploit before the fix makes the vulnerability obvious and gives you a regression test to prevent reintroduction.
