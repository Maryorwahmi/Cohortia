Module 06 › Chapter 6.5 › Learning Objectives
01
Identify reentrancy and DAO-style attacks

Detect external calls that happen before state updates, and understand how repeated reentry drains funds in practice.

VERIFIED COMPETENCY MILESTONE
02
Implement Checks-Effects-Interactions

Apply the CEI ordering to ensure state updates occur before external calls, reducing reentrancy risk and making code auditable.

VERIFIED COMPETENCY MILESTONE
03
Recognize integer overflow and underflow

Understand how unsigned integers wrap and why operations may produce unexpected large or small values in older Solidity versions.

VERIFIED COMPETENCY MILESTONE
04
Apply SafeMath or upgrade Solidity and test fixes

Use SafeMath for versions before 0.8.0 or rely on built-in checks in 0.8.0+, and write tests that reproduce and then prevent exploits.

VERIFIED COMPETENCY MILESTONE
