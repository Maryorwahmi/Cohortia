Module 06 › Chapter 6.5 › VulnerableCounter
Vulnerable code (Solidity < 0.8.0)
pragma solidity ^0.7.0;

contract VulnerableCounter {
    uint8 public count = 0;

    function increment() public {
        count++; // overflow if count == 255
    }

    function decrement() public {
        count--; // underflow if count == 0
    }
}
Patch options
Option A: Upgrade pragma to ^0.8.0 so arithmetic reverts on wrap. Option B: Use SafeMath and call add/sub functions that revert on unsafe arithmetic.
After patch: write tests that attempt the same out-of-range operation and expect a revert.
Note: switching to a larger integer type only postpones the wrap; explicit checks or SafeMath are the correct fix for logic safety.
Check your understanding

Write a test that increments to 255 and then increments once more. Observe whether the counter wraps or reverts depending on your Solidity version or SafeMath usage.
