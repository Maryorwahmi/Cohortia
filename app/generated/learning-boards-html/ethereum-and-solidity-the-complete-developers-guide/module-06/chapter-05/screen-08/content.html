Module 06 › Chapter 6.5 › Overflow & Underflow
Definition

Overflow and underflow

Example: uint8 x = 255; x++; // wraps to 0 in older Solidity
Example: uint8 x = 0; x--; // wraps to 255 in older Solidity
Attackers exploit wrapping to bypass checks or to inflate balances. Always test boundary arithmetic and choose the correct protections for your compiler version.
Defenses
  • Solidity 0.8.0+: arithmetic reverts on overflow/underflow
  • Solidity < 0.8.0: use SafeMath for checked operations
  • Write boundary tests that add to max or subtract from zero
Common mistake

Assuming modern compiler behavior when your project uses an older pragma can leave you exposed; confirm the pragma and test boundaries.
