// 4. Attacker triggers attack

Assertion checklist
  • Assert pre-condition balances
  • Assert immediate post-attack storage values
  • After patch, assert revert or preserved invariants
Key Takeaway

Make tests precise and repeatable; they are the ultimate proof that a vulnerability was not only found but removed.
