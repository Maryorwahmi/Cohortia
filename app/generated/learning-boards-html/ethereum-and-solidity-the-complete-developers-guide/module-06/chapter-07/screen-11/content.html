Proxy Patterns
Two common designs: Transparent Proxy and UUPS.
Transparent Proxy
Proxy handles admin vs user calls and delegates to implementation; common and well-tested.
UUPS
Upgrade logic lives in implementation for lower gas, but requires careful access control inside the implementation.
Risks & Mitigations
Primary vulnerabilities and how to reduce them.
Upgrade Mechanism Bugs
Ensure upgrade functions are minimal, audited, and protected by strong access control.
Storage Collisions
Test storage layout compatibility between versions; use reserved storage slots to avoid collisions.
Test Upgrade Paths
Simulate upgrades in staging and verify invariants and balances remain correct post-upgrade.
