# : - High - Reentrancy vulnerability - explanation...
Key Tip
Use Slither output as a prioritization map for manual review; note the file and line references it prints.
Triage Pattern
How to evaluate a finding from Slither.
1. Read the Finding
Understand the condition Slither identifies and where it occurs.
2. Reproduce in Context
Check the function’s full code path and external calls for exploitability.
3. Classify
Decide if it’s high-severity, a false positive, or informational, and document that decision.
4. Remediate & Test
Apply fixes, add unit tests, and rerun tools to verify resolution.
