Install & Run
# Install Solhint
npm install -g solhint

# Run Solhint on a file
solhint contracts/SampleContract.sol

# Example warnings may include:
# 17:9  warning  Expected 'onlyOwner' modifier.  (security/no-missing-require)
# 22:12 warning  Local variable 'x' is not initialized.  (compiler-warnings/uninitialized-variables)
Practice
Run Solhint, collect warnings, and write a short remediation plan for each high-severity item.
Interpretation & Example
What the sample warnings mean and how to fix them.
Missing Access Control
If transferOwnership is public without onlyOwner, anyone can steal control. Fix by adding a proper access modifier.
Uninitialized Variable
Local variables should be explicitly initialized to avoid logic errors; set a default before returning or using the value.
Key Takeaway
Treat linter warnings as actionable prompts: fix, test, and re-run before requesting an audit.
