Module 6 › Chapter 6.1 › Integration Testing: Contracts Working Together
Integration Goals
Verify that multiple contracts interact correctly and that composed operations behave as a whole.
Approve flow: ensure allowances allow exchange to call transferFrom successfully.
Failure propagation: if a token transfer reverts, the composite operation must revert safely.
Gas composition: assert that the combined gas of both contracts fits acceptable budgets.
Misconception: unit correctness guarantees integration correctness — integration exposes differences in assumptions and return behaviors that unit tests do not cover.
Concrete example
Token + exchange integration: deploy both, set balances and allowances, perform swap, and assert final token balances and event logs across both contracts.
Setup: deploy token and exchange in a single test fixture.
Act: approve and execute swap or transferFrom.
Assert: check balances, allowances, and that failed transfers revert overall operation.
Key Takeaway

Integration tests catch mismatched expectations and ensure composed behavior is safe and gas-feasible.
