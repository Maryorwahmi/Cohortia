Module 6 › Chapter 6.1 › End-to-End Testing: Simulating Users
Full user flows
End-to-end tests verify the complete journey from UI to chain and back to UI state.
Connect wallet and prepare approvals.
Submit transactions and wait for confirmations.
Assert UI reflects on-chain state and correct event propagation.
Misconception: end-to-end tests are redundant — they uniquely validate user-facing expectations and recovery from failed transactions.
Concrete e2e scenario
User connects wallet, approves exchange, executes swap, receives tokens, and UI updates. Test failure paths such as insufficient allowance or gas estimation errors.
Simulate slow confirmations and ensure UI handles pending state.
Assert that refunds or rollbacks leave on-chain state consistent.
Verify final balances and emitted events match UI messaging.
Key Takeaway

End-to-end tests ensure the system works for real users and that UI and contracts agree on expected results.
