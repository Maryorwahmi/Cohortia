Module 6 › Chapter 6.1 › Identify Testable Components in SimpleStorage
SimpleStorage — Test Targets
Deployment state
Verify storedData is zero and owner is deployer.
set(x) valid path
Assert storedData updates and DataStored event contains the new value and setter address.
set(x) invalid path
Call with x ≥ limit and assert revert with the require reason and unchanged storedData.
increment/decrement
Assert increments and decrements change storedData by one and consider underflow edge cases.
Example test descriptions
Test A: Deploy and assert initial state values.
Test B: set(100) updates storedData and emits DataStored(caller).
Test C: set(1000) reverts with require message; storedData unchanged.
Practical tip: after fuzz or property tests find a counterexample, add a deterministic unit test reproducing that failure so it never regresses.
