Caller Identity
Explain msg.sender vs tx.origin and why authorizing with tx.origin is unsafe. This matters because a malicious contract can trick an EOA into initiating a chain that bypasses checks.
Verified Competency Milestone
02
Front-running
Identify mempool race conditions and describe commit-reveal, batching, trusted sequencers, and slippage limits as mitigations.
Verified Competency Milestone
03
Denial-of-Service
Recognize gas-limit and blocking-call DoS, and apply pagination, batching, or pull-over-push to preserve availability.
Verified Competency Milestone
04
Testing Defenses
Write tests that simulate malicious relays, unauthorized callers, and large arrays to prove functions revert or behave safely.
Verified Competency Milestone
How to use these objectives
  • Reference these objectives while auditing contracts to prioritize fixes.
  • Use the testing ideas to create automated checks for regressions.
  • Adopt pattern-based fixes so you don’t rely on ad-hoc authorizations later.
