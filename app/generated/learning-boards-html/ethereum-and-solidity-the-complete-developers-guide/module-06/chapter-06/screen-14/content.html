Module 6 › Chapter 6.6 › Quick Reference
Authorization Rule
Use msg.sender-based checks and a single modifier for sensitive functions. Never use tx.origin for auth.
Front-running Check
If an action depends on secret or time-sensitive input, apply commit-reveal, batching, or slippage limits.
Availability Check
Avoid unbounded loops and push payments; prefer pull withdrawals and batch processing.
Action
Add attacker-style tests to CI: malicious relay tests for tx.origin, mempool front-running thought experiments, and stress tests for gas limits.
