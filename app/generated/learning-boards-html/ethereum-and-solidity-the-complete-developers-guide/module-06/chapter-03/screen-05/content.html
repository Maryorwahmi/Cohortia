Module 6 › Chapter 6.3 › contract.connect()
Two-step pattern
  1. Get signers: const [owner, addr1] = await ethers.getSigners();
  2. Deploy with owner: Factory = await ethers.getContractFactory("Contract", owner);
  3. Send transaction: await contract.connect(owner).set(500);
  4. Assert state: expect(await contract.get()).to.equal(500);
Transient instance note
connect returns a new contract instance bound to that signer; it does not change the original instance globally.
Example test card
it("Only owner can set a value", async function () {
  await advancedStorage.connect(owner).set(500);
  expect(await advancedStorage.get()).to.equal(500);
  await expect(advancedStorage.connect(addr1).set(501))
    .to.be.revertedWith("Only owner can call this function");
});
Pro tip

When deploying, pass the intended owner to getContractFactory so constructor owner matches the test expectation.
