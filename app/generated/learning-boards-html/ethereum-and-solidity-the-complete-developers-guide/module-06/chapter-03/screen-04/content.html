Module 6 › Chapter 6.3 › Signers
What is a Signer?
A Signer is an ethers object that can sign transactions and messages. Use it to simulate an account sending a transaction so msg.sender in the contract matches the expected caller.
Code snippet
const [owner, addr1, addr2] = await ethers.getSigners();
// owner, addr1, and addr2 are Signer objects
Concrete example
Use owner to deploy and grant rights, then simulate addr1 attempting a privileged operation to ensure it reverts as expected.
Common mistake
Using only address strings and not Signer.connect for transactions means the call will not originate from the intended account.
Practical checks
  • Always destructure getSigners in beforeEach so tests share the same signer fixtures.
  • Use signer.address when you need the raw address for assertions or event arg checks.
  • Use contract.connect(signer) when sending transactions to set msg.sender correctly.
Key Takeaway

Signers let your tests impersonate accounts; use connect to ensure msg.sender is accurate and simulate both allowed and denied calls.
