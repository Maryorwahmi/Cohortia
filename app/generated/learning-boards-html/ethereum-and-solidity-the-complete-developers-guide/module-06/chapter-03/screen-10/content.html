Module 6 › Chapter 6.3 › Activity: MyToken
Test plan
  1. Deploy: assert totalSupply === 0 and owner is set.
  2. Owner mints: call connect(owner).mint(addr1, amount); assert totalSupply and balanceOf, and assert Mint event.
  3. Non-owner mint: expect connect(addr1).mint(... ) to.be.revertedWith("Only owner can call this function").
  4. Mint to zero address: expect revert with "Cannot mint to zero address".
Starter test template
beforeEach(async function () {
  [owner, addr1, addr2] = await ethers.getSigners();
  MyToken = await ethers.getContractFactory("MyToken", owner);
  myToken = await MyToken.deploy();
});

// Then implement the four tests described above
Example assertion
await expect(myToken.connect(owner).mint(addr1.address, 1000))
  .to.emit(myToken, "Mint").withArgs(addr1.address, 1000);
After asserting the event, check totalSupply and balanceOf for full coverage.
