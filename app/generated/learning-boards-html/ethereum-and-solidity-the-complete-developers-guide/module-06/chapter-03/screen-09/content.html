Module 6 › Chapter 6.3 › Common Mistakes
Mistake: Missing await
Always await both transactions and expect matcher chains to ensure the test waits for the network action and assertion to complete.
Example failure mode: a test appears green but actually never awaited the promise that would reveal the revert.
Mistake: Generic revert checks
Using to.be.reverted does not prove which guard triggered. Use revertedWith to be explicit about intent.
Checklist to avoid mistakes
  • Await transactions and expect assertions.
  • Use connect(signer) for non‑deployer callers.
  • Assert state and events, not only call success.
  • Deploy with intended signer when ownership matters.
