Module 6 › Chapter 6.3 › AdvancedStorage Walkthrough
Test structure
beforeEach sets signers and deploys with owner. Each it block then uses connect to simulate callers and asserts state or reverts.
beforeEach(async function () {
  [owner, addr1, addr2] = await ethers.getSigners();
  AdvancedStorage = await ethers.getContractFactory("AdvancedStorage", owner);
  advancedStorage = await AdvancedStorage.deploy();
});

it("Should allow only owner to set a value", async function () {
  await advancedStorage.connect(owner).set(500);
  expect(await advancedStorage.get()).to.equal(500);
  await expect(advancedStorage.connect(addr1).set(501))
    .to.be.revertedWith("Only owner can call this function");
});
Note how both state assertions and revert assertions appear together. This combination documents expected behavior and failure modes clearly.
Event test snippet
await expect(advancedStorage.connect(owner).set(newValue))
  .to.emit(advancedStorage, "DataChanged")
  .withArgs(oldValue, newValue, owner.address);
Confirm both the event and the state. If the event args differ, the withArgs assertion will fail and point to the mismatch.
