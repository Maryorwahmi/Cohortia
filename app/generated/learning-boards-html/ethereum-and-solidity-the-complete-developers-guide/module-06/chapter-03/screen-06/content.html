Module 6 › Chapter 6.3 › Reverts
What is a revert?
A revert undoes state changes and indicates a failed precondition. Tests should assert both occurrence and specific reason.
Example: onlyOwner fallback
await expect(advancedStorage.connect(addr1).set(100))
  .to.be.revertedWith("Only owner can call this function");
Testing multiple failure reasons
Write distinct tests for each require condition to ensure every guard works as intended, for example new-data versus only-owner.
Common mistake

Do not use a generic revert check. Be explicit about the expected message so the test documents intent and catches the right guard.

Quick checklist
  • Use await expect(...).to.be.revertedWith("message").
  • Write tests for each precondition separately.
  • Avoid swallowing asynchronous errors by forgetting await.
