Module 6 › Chapter 6.3 › Edge Cases
Zero-address validation
Try minting to the zero address and expect the specific revert message to ensure the guard works.
await expect(myToken.connect(owner).mint(ethers.constants.AddressZero, 100))
  .to.be.revertedWith("Cannot mint to zero address");
Multiple event checks
If a function emits several events, assert the ones critical to your off‑chain flows and consider verifying order when it matters.
Example: assert Mint and Transfer during minting to match ERC20 behavior.
Practical tip
Keep edge-case tests separate and descriptive so CI failures clearly point to the missing guard or incorrect event emission.
