Interacting with Contracts & Events
Simulate signers, enforce access control, and confirm event logs.
In this lesson
You will practice getSigners, connect, revertedWith, and to.emit assertions using a token minting scenario.
// Example: connect a signer to send a transaction
const [owner, addr1] = await ethers.getSigners();
await myContract.connect(owner).mint(addr1.address, 100);
await expect(myContract.connect(addr1).mint(addr1.address, 1))
  .to.be.revertedWith("Only owner can call this function");
await expect(myContract.connect(owner).mint(addr1.address, 50))
  .to.emit(myContract, "Mint").withArgs(addr1.address, 50);
Why it matters
Tests that precisely simulate accounts and events prevent regressions and protect user funds in production.
Key takeaway
Assert both permitted and blocked paths, and verify events for off‑chain listeners.
