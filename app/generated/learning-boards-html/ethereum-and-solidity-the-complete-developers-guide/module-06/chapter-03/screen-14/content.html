Module 6 › Chapter 6.3 › Key Concepts
Signer
Object representing an account; use getSigners to access them in tests.
connect(signer)
Bind a contract call to a specific signer so msg.sender is set for that transaction.
revertedWith
Assert that a transaction reverted for the exact expected reason.
Summary Takeaway

Combine signer simulation, explicit connect calls, precise revert checks, and event assertions to make tests that are both protective and expressive.
