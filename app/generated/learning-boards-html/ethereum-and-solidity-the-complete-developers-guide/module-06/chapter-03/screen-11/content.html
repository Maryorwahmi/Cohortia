Module 6 › Chapter 6.3 › Test Structure
beforeEach pattern
Centralize signer retrieval and contract deployment so each test starts from a known state.
beforeEach(async function () {
  [owner, addr1] = await ethers.getSigners();
  Token = await ethers.getContractFactory("MyToken", owner);
  token = await Token.deploy();
});
Arrange → Act → Assert
Keep each test small: set up preconditions, perform the transaction, then assert only the expected outcomes.
Naming
Use explicit test names so CI failure messages tell the story without opening the file.
Key Takeaway

Organized tests save debugging time. Favor simple, specific tests over large multi‑assert specs.
