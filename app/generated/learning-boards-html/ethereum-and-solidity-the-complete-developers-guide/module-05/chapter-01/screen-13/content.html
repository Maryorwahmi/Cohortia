Module 5 › Chapter 5.1 › Local Connection
Starter code
import { ethers } from 'ethers';
async function connectToLocalNetwork(){
  const provider = new ethers.JsonRpcProvider('http://127.0.0.1:8545');
  const blockNumber = await provider.getBlockNumber();
  const accounts = await provider.listAccounts();
  // if accounts[0] has an address property:
  const first = accounts[0]?.address || accounts[0];
  const balance = await provider.getBalance(first);
  console.log(blockNumber, first, ethers.formatEther(balance));
}
connectToLocalNetwork();
Run this with node after ensuring Anvil or Ganache is running. You should see a block number and a balance printed.
Debug checklist
  • Is the local node running on port 8545?
  • Are accounts returned by listAccounts? Inspect the returned structure.
  • Are balances returned in wei? Use formatEther to convert for readability.
Key Takeaway

Local nodes are essential for quick iteration; verifying block number and balances proves your provider setup is correct.
