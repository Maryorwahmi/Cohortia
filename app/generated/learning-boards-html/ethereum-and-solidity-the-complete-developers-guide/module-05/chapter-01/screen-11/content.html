Module 5 › Chapter 5.1 › Sepolia Example
Starter script
import { ethers } from 'ethers';
const INFURA_PROJECT_ID = 'YOUR_INFURA_PROJECT_ID';
const sepoliaUrl = `https://sepolia.infura.io/v3/${INFURA_PROJECT_ID}`;
async function main(){
  const provider = new ethers.JsonRpcProvider(sepoliaUrl);
  const blockNumber = await provider.getBlockNumber();
  console.log('Connected. Block:', blockNumber);
}
main();
Run node index.js and confirm a printed block number. If you see errors, check your project ID and network status.
Troubleshooting
Incorrect project ID: the endpoint will reject requests.
Rate limits: you may be temporarily limited if too many requests are sent.
Network issues: check local connectivity and DNS resolution for the endpoint.
