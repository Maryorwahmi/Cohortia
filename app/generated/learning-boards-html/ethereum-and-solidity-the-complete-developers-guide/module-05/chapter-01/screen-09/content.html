Module 5 › Chapter 5.1 › Local Providers
Start and connect
  1. Run Anvil or Ganache locally.
  2. Create an ethers.JsonRpcProvider pointing at http://127.0.0.1:8545.
  3. List accounts and read balances to verify.
Example verification
After connecting, call getBlockNumber and listAccounts to confirm the node is running and accounts are available for testing.
Tip
Use local nodes for automated tests and UI flows. Always re-test on a public testnet before release.
