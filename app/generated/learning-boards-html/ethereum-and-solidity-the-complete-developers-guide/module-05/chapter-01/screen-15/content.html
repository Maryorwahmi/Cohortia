Module 5 › Chapter 5.1 › Quick Reference
Provider
Network connection to query or relay blockchain requests.
Signer
An account object that signs transactions and messages.
Ethers.js / Web3.js
Libraries that provide providers, contract helpers, and utilities for frontends.
Final Tip

When debugging, ask: is the provider reachable? does the signer exist? are secrets exposed? These questions map directly to the concepts you learned.
