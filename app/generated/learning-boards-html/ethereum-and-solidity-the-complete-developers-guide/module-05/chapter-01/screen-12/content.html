Module 5 › Chapter 5.1 › Signer
What a signer does
Produces cryptographic signatures for transactions and messages using private keys. Wallets provide signers that never expose private keys to the page.
Example
Request a signer from MetaMask and attempt to send a transaction; the wallet prompts the user to confirm each signing action.
Security note
Never hardcode a private key in frontend code. Use wallets or secure backends and environment variables for any server-side signing.
Common mistake

Embedding private keys in client-side scripts exposes funds. Always keep signing material offline or in wallet-managed environments.
