Provider role

Provides network access, JSON-RPC relay, and methods to read chain state such as balances, blocks, and logs.

Example call
const provider = new ethers.JsonRpcProvider(URL); const block = await provider.getBlockNumber();
Not a signer
A provider alone cannot sign transactions; use a signer for state changes.
Provider types
Browser-based
Injected by wallets like MetaMask for user accounts and signing requests.
JSON-RPC services
Infura or Alchemy provide hosted endpoints for read-heavy operations.
Local nodes
Anvil or Ganache for fast development and deterministic accounts.
Key Takeaway

Pick the provider type that matches your read and signing needs: wallet for user signing, hosted for public reads, local for testing.
