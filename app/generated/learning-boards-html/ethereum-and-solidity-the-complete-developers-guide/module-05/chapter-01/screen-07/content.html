Module 5 › Chapter 5.1 › Browser Wallets
Step-by-step
  1. Detect injected provider (e.g., window.ethereum).
  2. Request account access from the user.
  3. Get a signer from the provider for transaction signing.
  4. Use signer to send transactions; provider for reads.
Concrete Tips
Always ask for permission; wallets will prompt the user to approve account access.
Do not attempt to access private keys. Use the signer object provided by the wallet to sign requests.
Handle network changes: the user may be on a different chain than your app expects.
