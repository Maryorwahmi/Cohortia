Module 5 › Chapter 5.1 › Library Comparison
Ethers.js — Modern
  • Smaller bundle size and cleaner API.
  • Explicit provider and signer separation.
  • Utilities for formatting and contract interactions.
Example
const provider = new ethers.JsonRpcProvider(SEPOLIA_URL);
const block = await provider.getBlockNumber();
Web3.js — Established
  • Broad functionality and early ecosystem adoption.
  • Different API shape; many projects still rely on it.
  • Concepts overlap: providers, signers, and contracts exist in both.
Misconception
Choosing based solely on popularity can ignore bundle and security implications. Match the library to your app needs.
Key Takeaway

Ethers.js is often preferred for modern dApps for its clarity and compactness, but both libraries teach the same provider and signer model.
