Module 5 › Chapter 5.1 › Learning Objectives
01
Explain why a JS library is necessary

Describe how Ethers.js or Web3.js translates UI actions into blockchain requests and why direct RPC calls from raw DOM are not practical.

Verified Competency Milestone
02
Differentiate provider vs signer

Explain that a provider connects to a network while a signer represents an account that can sign transactions, typically via a wallet.

Verified Competency Milestone
03
Set up and install Ethers.js

Initialize an npm project and add Ethers.js so your frontend can import the library and create providers.

Verified Competency Milestone
04
Connect using MetaMask, Infura or local node

Demonstrate connecting to a browser wallet for signing, a JSON-RPC provider for reads, and a local Anvil or Ganache instance for testing.

Verified Competency Milestone
