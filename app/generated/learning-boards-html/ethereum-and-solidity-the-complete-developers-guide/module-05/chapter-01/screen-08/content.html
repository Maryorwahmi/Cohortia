Module 5 › Chapter 5.1 › JSON-RPC Providers
How they fit

Hosted JSON-RPC providers act as remote nodes you can query for blockchain data. They are ideal for public reads and backend services that do not require user signatures.

Example code
import { ethers } from 'ethers';
const sepoliaUrl = `https://sepolia.infura.io/v3/YOUR_PROJECT_ID`;
const provider = new ethers.JsonRpcProvider(sepoliaUrl);
const blockNumber = await provider.getBlockNumber();
Practical notes
Use read-only project IDs in public frontends when possible and avoid exposing write secrets.
Hosted providers are useful as fallbacks when a user has no wallet connected.
Rate limits may apply; design caching and backends accordingly.
Key Takeaway

Hosted providers are reliable for reads and server tasks; keep sensitive credentials off the client and prefer backends for write operations.
