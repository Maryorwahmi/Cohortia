Introduction to Web3.js / Ethers.js

Connect your frontend to Ethereum using providers and signers so users can read state and submit transactions safely.

Orientation

This chapter explains why you need a JavaScript library, the difference between provider and signer, and how to initialize Ethers.js. You'll practice connecting to a testnet and a local node, and learn common safety practices for keys and API tokens.

Getting started

By installing Ethers and choosing the right provider for your use case, you enable both read-only queries and user-signed transactions. This chapter shows how to do both safely.
