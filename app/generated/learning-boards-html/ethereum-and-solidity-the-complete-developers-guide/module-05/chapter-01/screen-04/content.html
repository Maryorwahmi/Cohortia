Module 5 › Chapter 5.1 › Why libraries?
Definition

A library abstracts JSON-RPC details and offers helpers for providers, contracts, and formatting so your UI can call blockchain functions safely and reliably.

Provider
Handles network connection and JSON-RPC requests.
Contract helper
Encodes and decodes function calls and events for you.
Utilities
Formatting values, unit conversion, and common helpers.
Key Takeaway

Use a maintained library to avoid raw RPC boilerplate and to gain wallet compatibility and safer helpers.

Concrete Example
When a user requests their token balance, the library encodes the balanceOf call, sends it via the provider, and returns a parsed number in ether units. You avoid hand-encoding the ABI and parsing hex responses.
Common Mistake
Attempting to call contracts with handcrafted JSON-RPC payloads increases error surface and makes wallet signing more complex.
Try this
Open a library's contract helper and compare a coded call to a balance function with the manual ABI encoding steps. Notice the simplification.
