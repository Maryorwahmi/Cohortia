Module 5 › Chapter 5.3 › Contract Instance
Definition

A contract instance binds an ABI to a specific address so your library can encode requests and decode responses against a deployed contract.

  • Address: unique identifier on-chain.
  • ABI: JSON blueprint of functions, inputs, outputs.
  • Instance: the runtime object you call methods on.
Analogy
Address is the house number; ABI is the house blueprint telling you where each room is and what it contains.
Key Takeaway

Always pair the current deployed address with the matching ABI to avoid function lookup errors.

Instantiation examples
// Web3.js
const myContract = new web3.eth.Contract(CONTRACT_ABI, CONTRACT_ADDRESS);

// Ethers.js
const myContract = new ethers.Contract(CONTRACT_ADDRESS, CONTRACT_ABI, provider);
Common mistake
Using an ABI from a different contract version leads to "function not found" errors.
Pro tip
Store ABI alongside the deployed address in your deployment artifacts so the frontend can pick the correct pair automatically.
