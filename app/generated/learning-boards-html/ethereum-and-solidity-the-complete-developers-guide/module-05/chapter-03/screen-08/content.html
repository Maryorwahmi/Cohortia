Module 5 › Chapter 5.3 › view vs pure
view

Reads contract state but does not change storage. Use for getters and queries dependent on stored values.

Example: function getMessageLength() public view returns (uint) { return bytes(message).length; }
When to use: Any function that reads variables to compute answers for the UI.
pure

Does not read or write contract state. It performs computations solely on inputs and returns results.

Example: function multiplyByTwo(uint _num) public pure returns (uint) { return _num * 2; }
When to use: Utility functions and deterministic calculations independent of storage.
Key Takeaway

Both are gas-free for frontend reads via provider, but their contract-level guarantees differ: view may read state; pure cannot touch state at all.
