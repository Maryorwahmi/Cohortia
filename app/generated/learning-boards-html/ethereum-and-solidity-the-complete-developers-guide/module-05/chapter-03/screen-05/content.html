Code walkthrough
// Assuming web3 is initialized
const myContract = new web3.eth.Contract(CONTRACT_ABI, CONTRACT_ADDRESS);

async function readDataWeb3(){
  try{
    const message = await myContract.methods.message().call();
    const counter = await myContract.methods.counter().call();
    const doubled = await myContract.methods.multiplyByTwo(10).call();
    console.log(message, counter.toString(), doubled.toString());
  } catch (err){
    console.error('Web3.js Read Error:', err.message);
  }
}
Example
Calling multiplyByTwo(10) returns 20 immediately from the node.
Common mistake
Expecting call() to mutate state. It only reads.
Why it matters
Using .call() keeps your DApp responsive and avoids gas costs while showing current on-chain values.
Key Takeaway

Web3.js exposes methods via .methods and .call() runs a local node execution. Convert numeric returns for UI use.

Check your understanding
If you see function not found, confirm the ABI contains the function signature and the address points to the expected contract.
