Convert before display
// Ethers.js result
const counter = await myContract.counter();
console.log(counter.toString());

// Avoid: console.log(counter + 1) on a BigNumber
Tip: Use libraries like BN or BigNumber when you need arithmetic. For UI, use toString() to render values safely.
Decimal tokens: Remember to divide by 10**decimals to present human-readable balances.
Key Takeaway

Always inspect returned types. Convert BigNumber to string for display; use safe math libraries for calculations.

Common mistake
Performing native JS arithmetic on BigNumber leads to incorrect results or errors.
