Ethers.js example
const provider = new ethers.providers.JsonRpcProvider(GANACHE_RPC_URL);
const myContract = new ethers.Contract(CONTRACT_ADDRESS, CONTRACT_ABI, provider);

async function readDataEthers(){
  try{
    const message = await myContract.message();
    const counter = await myContract.counter();
    const doubled = await myContract.multiplyByTwo(10);
    console.log(message, counter.toString(), doubled.toString());
  } catch(err){
    console.error('Ethers.js Read Error:', err.message);
  }
}
Example
Awaiting myContract.getMessageLength() returns a number from the node via provider.
Pro tip
Call toString() on BigNumber returns to presentable strings for UIs.
Misconception
Using a signer with the same contract object will permit transactions; ensure provider-only when you only want reads.
Key Takeaway

Ethers reads look like normal async calls; they are executed locally via the provider and require conversion of BigNumber values for display.

Check
If a call errors, compare the ABI and address to the deployed contract and verify the provider URL is correct.
