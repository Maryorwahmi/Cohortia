Module 5 › Chapter 5.3 › Hands-on Activity
Step-by-step
  1. Compile SimpleData and deploy to Ganache; copy the deployed address.
  2. Copy the compiled ABI JSON into readContract.js CONTRACT_ABI placeholder.
  3. Set GANACHE_RPC_URL and CONTRACT_ADDRESS in the script.
  4. Run node readContract.js and inspect outputs for message and counter.

Key Takeaway

Running the script end-to-end validates ABI, address, and provider settings, and helps you spot mismatches quickly.
