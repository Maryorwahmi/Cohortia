Module 5 › Chapter 5.3 › Key Concepts
Contract Address
Unique on-chain location used to address deployed contracts.
ABI
JSON blueprint describing functions, inputs, outputs, and events for encoding and decoding calls.
view / pure
Read-only functions: view can read state, pure cannot read state. Both are gas-free when called off-chain.
Summary takeaway
Use the correct ABI/address pair, call view and pure functions through a provider, convert numeric returns, and handle errors gracefully to build dependable read-only DApp features.
