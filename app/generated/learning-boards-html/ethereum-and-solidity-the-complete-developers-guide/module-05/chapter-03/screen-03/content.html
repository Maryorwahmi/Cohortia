Apply and verify

This slide focuses on hands-on checks and diagnostics you should perform when reading data from a contract.

  • Instantiation check: Confirm ABI and address match the deployed contract before calling functions.
  • Provider-only reads: Use provider to avoid signing requirements and keep calls gas-free.
  • Data conversion: Convert BigNumber results to strings for UI display or number formats.
  • Error handling: Wrap calls in try catch and present clear user messages on failure.
Quick checklist
Compile and copy ABI, deploy and copy address, paste both into your read script, run and verify outputs. If you see function not found, update the ABI.
