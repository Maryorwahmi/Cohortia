Module 5 › Chapter 5.3 › Public Variables
How it works

When a variable is declared public, the compiler generates a view function with the same name that returns its value. That function appears in the ABI and can be invoked from the frontend.

Example: message and counter in SimpleData are accessible through message() and counter() getters.
Limitations: mappings and nested arrays need specific accessors for efficient reads.
Misconception: public does not mean writable by external callers; it only provides visibility and a getter.
Concrete example
Call myContract.methods.message().call() in Web3.js or await myContract.message() in Ethers.js to retrieve the message string stored in the contract.
Why it matters

Auto-generated getters reduce Solidity code and make common frontend reads straightforward and reliable.

Check your understanding
If you need aggregated data, write a view function that computes the result rather than relying on several auto-getters in the frontend.
