Module 6 › Chapter 5.7 › Transactions & Gas
Transaction steps
  1. Validate input and disable the control.
  2. Estimate gas and add a safety buffer.
  3. Send transaction and show pending status with tx hash.
  4. Await receipt and update UI on success or failure.
Example
const estimatedGas = await greeter.estimateGas.setGreeting(newGreeting); const gasLimit = estimatedGas.add(20000); const tx = await greeter.setGreeting(newGreeting, { gasLimit }); const receipt = await tx.wait();
UI notes
Show a short hash snippet for traceability and explain that confirmations may take time. When a transaction is pending, prevent duplicate submissions and explain next steps to the user.
Error case
If a transaction reverts, parse the revert reason and display it. Remember the user still paid gas up to the revert point.
Key Takeaway

Estimate gas, disable inputs during pending operations, show a concise pending message, and await receipts to confirm completion.
