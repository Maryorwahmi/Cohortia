Module 6 › Chapter 5.7 › Reading State
Read pattern
Call view functions with a provider-backed contract and handle errors. Offer a Refresh control and reconcile state when events arrive.
Example
const greeting = await greeterContract.getGreeting(); setGreetingText(greeting);
Misconception
Assuming a read will reflect a pending transaction. Reads only show mined state; use events and receipts to confirm changes.
Example UI block
"Hello, World!"
Show a short success or error line when fetch completes. If fetch fails, include an action like "Check network or contract address."
Key Takeaway

Read contract state via provider, use try…catch, and refresh after events or receipts to keep the UI accurate.
