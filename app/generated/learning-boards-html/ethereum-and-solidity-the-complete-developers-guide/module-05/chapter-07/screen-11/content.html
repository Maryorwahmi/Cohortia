Module 6 › Chapter 5.7 › Error Handling
Common error shapes
  • User rejection — short code, show friendly cancel message.
  • RPC/network error — suggest checking network and RPC endpoint.
  • Transaction revert — parse revert reason and show it clearly.
UI strategy
Display concise messages, re-enable controls after failures, and log technical details to console for developers. Avoid exposing raw stack traces to users.
Example
If a revert includes 'Only owner can set greeting', display: "Transaction reverted: Only owner can set the greeting. Ensure you are connected with the owner's account." Offer a short next step rather than raw data.
