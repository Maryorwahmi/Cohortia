Module 6 › Chapter 5.7 › Events & UI
Event handler pattern
Register a listener for GreetingUpdated that updates the greeting display and shows a confirmation message. Remove or reattach listeners during reinit to avoid multiple firings.
Example Listener
greeterContract.on('GreetingUpdated', (updater, oldGreeting, newGreeting) => { setGreetingText(newGreeting); showStatus(`Greeting updated by ${updater.substring(0,6)}...`); });
UI behavior
When an event arrives, update the UI and optionally animate the change. Use idempotent updates so duplicate events do not cause flicker or inconsistent state.
Misconception
Treating events as a replacement for receipts. Use both: receipts confirm inclusion, events communicate content.
Key Takeaway

Use events to update the UI in near real-time, but reconcile with receipts to ensure on-chain confirmation and avoid race conditions.
