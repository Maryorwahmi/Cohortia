Module 6 › Chapter 5.7 › Provider & Contract
Initialization Pattern
Create provider, then signer, then contract. Keep a small helper that returns fresh instances so you can call it on account/chain change.
Pattern
  1. Create Web3Provider with window.ethereum.
  2. Get signer via provider.getSigner().
  3. Instantiate new Contract(address, ABI, signer) for writes.
Concrete example
// Pseudo code
const provider = new ethers.providers.Web3Provider(window.ethereum);
const signer = provider.getSigner();
const greeter = new ethers.Contract(CONTRACT_ADDRESS, CONTRACT_ABI, signer);
// Use greeter.getGreeting() for reads and greeter.setGreeting() for writes
Pro tip
Keep a reinit function that tears down old listeners and recreates provider, signer, and contract on chain or account events.
