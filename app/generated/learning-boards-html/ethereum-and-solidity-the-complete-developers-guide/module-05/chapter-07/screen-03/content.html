Module 6 › Chapter 5.7 › Implementation Focus
Implementation Tasks
Replace ABI/address, connect wallet, read state, send transactions, and handle events.
Provider & Signer

Create Ethers.js Web3Provider from window.ethereum, then call getSigner for write methods. This ensures transactions are signed by the connected account.

Contract Instance

Instantiate new Contract with ABI, address, and signer for state-changing calls; use provider for read-only calls when no signer is needed.

Event Listeners

Attach listeners for events like GreetingUpdated to refresh UI without polling, and remove listeners on disconnect to avoid duplicates.

Defensive UX

Disable controls during transactions, show concise messages, and parse revert reasons to provide actionable feedback instead of vague errors.
