Module 6 › Chapter 5.7 › Wallet Connection
Detect Wallet
Show an instructional message if no wallet is found. If present, explain why permission is required before trying to read accounts.
Check
if (typeof window.ethereum !== 'undefined') { /* wallet present */ }
Request
Call eth_requestAccounts and handle user rejection code 4001 with a friendly message.
Pitfall
Automatically assuming approval leads to silent failures. Always request explicit consent before creating a signer.
Example UI text
Display wallet status, account address shorthand, and network name. If disconnected, show: "Wallet not connected — click connect to continue." If MetaMask is not installed, suggest installation with a short instruction.
Key Takeaway

Request explicit wallet permission and listen for account and chain changes to keep your app in sync with the user's wallet state.
