Activity: Deploy & Test
Follow these steps to validate the full DApp lifecycle locally.
Deployment
  1. Start Ganache and deploy Greeter.sol.
  2. Copy the deployed address and ABI into index.html placeholders.
Local testing
  1. Open index.html in a browser with MetaMask connected to Ganache.
  2. Connect wallet, refresh greeting, submit new greeting, and confirm transactions.
Error tests
  • Submit empty greeting to trigger client validation.
  • Use a non-owner account to provoke a revert and observe the message.
Reflect
Note which messages helped you debug and refine wording to be concise and actionable for real users.
Key Takeaway

Use this lab to validate lifecycle, event handling, gas estimation, and error messaging until the DApp behaves predictably under normal and failure scenarios.
