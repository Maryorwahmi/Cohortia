Learning Objectives
Skills to build and ship a minimal Greeter DApp frontend.
Bloom: Learn → Understand → Apply → Master
01
Integrate Ethers.js

Wire a provider and signer to the UI so the app can read and write contract state. This matters because it forms the connection between browser wallets and your contract.

Verified Competency Milestone
02
Manage Wallet Lifecycle

Request accounts, react to accountsChanged and chainChanged, and reinitialize provider/contract. This prevents stale or misleading UI when the user switches networks or accounts.

Verified Competency Milestone
03
Implement Transaction Flow

Estimate gas, disable controls during pending state, wait for confirmation, and refresh state after mining. This gives users confidence and prevents duplicate transactions.

Verified Competency Milestone
04
Error Handling & UX

Catch revert reasons, display user-friendly messages, and use event listeners to keep the UI consistent. Good feedback reduces confusion and wasted gas.

Verified Competency Milestone
