Module 6 › Chapter 5.7 › Transaction UX
Message pattern
  • Pending: show short hash and an explanation.
  • Confirmed: show event data or updated state.
  • Failed: show revert reason and next steps.
Example messages
Pending: "Transaction sent: 0xabc... Waiting for confirmation."
Confirmed: "Greeting updated to 'Hi!' by 0x123..."
Failed: "Transaction reverted: Only owner can set greeting. Switch to the owner's account and try again."
Key Takeaway

Keep messaging simple, actionable, and stateful. Disable controls during pending and re-enable only after a final state is known.
