Module 5 › Chapter 5.4 › Transaction Parameters
Parameter reference
  • from: signer address that pays fees and signs the tx.
  • to: recipient or contract address.
  • value: Ether to transfer, in Wei for transmission.
  • gasLimit: maximum gas units allowed for execution.
  • gasPrice: Wei per gas unit to influence miners/validators.
  • data: ABI-encoded function call and parameters.
Tip: always ensure from has balance >= gasLimit * gasPrice + value.
Concrete scenario
You want to call deposit on a contract and send 0.05 Ether. Convert 0.05 Ether to Wei, set the value field to that Wei amount, and provide a gasLimit sufficient for the function. If deposit is payable, it will accept Ether; if it's not, the transaction reverts.
Common mistake
Sending value to a non-payable function causes a revert. Validate function mutability before adding value.
Key Takeaway

Double-check value units and gas math before sending a transaction to avoid costly mistakes.
