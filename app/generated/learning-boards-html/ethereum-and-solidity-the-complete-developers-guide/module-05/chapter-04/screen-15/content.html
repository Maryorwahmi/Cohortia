Module 5 › Chapter 5.4 › Key Concepts
Transaction Receipt
Contains gas used, block number, and logs you can use to update the application state.
Reverts & Costs
A revert stops state change but still consumes gas; handle reverts in catch blocks and inform the user.
Signer & Security
Use a wallet-provided signer in production. Never hardcode private keys or expose them in the client or logs.
Final takeaway
Combine reliable gas estimation, clear UX for pending/confirmed states, and robust error handling to build dependable transaction flows in your DApps.
