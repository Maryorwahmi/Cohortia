Module 5 › Chapter 5.4 › Ethers.js & Signer
Essential flow
Create a provider, build or obtain a Signer, and attach it to a Contract. Call the function, receive a tx response, then await tx.wait() to get the receipt and confirm the state change.
// Connect wallet to provider
const wallet = new ethers.Wallet(privateKey, provider);
const contract = new ethers.Contract(ADDRESS, ABI, wallet);
const tx = await contract.updateMessage('Hello', { gasLimit: 300000 });
console.log('Tx hash:', tx.hash);
const receipt = await tx.wait(); // confirmed here
Notes
  • tx.hash is available immediately; it does not equal confirmation.
  • Use tx.wait to ensure the transaction was included.
  • Wrap sending and waiting in try...catch for robust error handling.
Warning
Do not hardcode private keys in production. Use an injected provider so the user signs locally.
Key Takeaway

Ethers splits send and confirmation into tx response and wait; use both for clear UX.
