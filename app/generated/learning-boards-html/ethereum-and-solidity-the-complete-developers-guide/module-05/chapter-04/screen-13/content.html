Safe signing practices
  • Use injected providers (browser wallets) so users sign locally without exposing keys to your app.
  • For local scripts, keep private keys out of source control and never log them.
  • If a key is exposed, rotate accounts and invalidate compromised credentials immediately.
  • Explain signing to users so they can recognize legitimate wallet prompts and avoid phishing attacks.
Warning

Never hardcode a private key in production. The example in this chapter uses Ganache keys only for local development.
