Progressive status UI
  1. Show tx hash immediately after send so user has reference.
  2. Await receipt via tx.wait() or .send() Promise to confirm inclusion.
  3. Extract gasUsed, blockNumber and logs to verify effects and update state.
  4. Optionally wait for extra confirmations depending on risk tolerance.
Receipt example fields
  • transactionHash: identifier for the tx.
  • gasUsed: actual gas consumed during execution.
  • blockNumber: the block that included the tx.
  • logs: emitted events to trigger UI changes.
Why it matters
Using the receipt to confirm state avoids premature assumptions and improves user trust.
