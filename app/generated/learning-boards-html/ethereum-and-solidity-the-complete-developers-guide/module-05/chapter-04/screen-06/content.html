Module 5 › Chapter 5.4 › Web3.js: .send()
Code (illustrative)
// Instantiate contract with ABI and address
const myMutable = new web3.eth.Contract(ABI, ADDRESS);
const newMessage = "Hello from Cohortia!";
try {
  const receipt = await myMutable.methods.updateMessage(newMessage).send({
    from: sender, gas: 300000
  });
  // receipt contains transactionHash, gasUsed, events
} catch (error) {
  // handle revert or insufficient funds
}

// Deposit Ether (convert to Wei first)
const amountWei = web3.utils.toWei('0.05', 'ether');
await myMutable.methods.deposit().send({ from: sender, value: amountWei, gas: 100000 });
Highlights
  • Use .send and await the Promise for the receipt.
  • Provide a from address and any value in Wei.
  • Wrap calls in try...catch to handle reverts or funding errors.
Pro tip
Test transactions on Ganache to inspect receipts and event logs locally before production.
Key Takeaway

With Web3.js, .send handles broadcasting and returns the mined receipt; always await and validate it.
