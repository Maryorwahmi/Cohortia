Provider — definition
A client abstraction that uses JSON-RPC to query a node for block and contract data.
Providers let you call methods like getBlockNumber, getBalance, and call a contract’s view methods. They do not hold private keys or sign transactions.
Common misconception
Confusing a Provider with a wallet. Only a Signer or wallet can sign. Using a Provider alone for write operations will fail or require pre-signed transactions.
Key takeaway
Providers are essential for reads. Pair with a Signer when you need to send transactions or sign messages.
Example: connect to Ganache
// Ethers.js JsonRpcProvider example
const { ethers } = require('ethers');
const provider = new ethers.providers.JsonRpcProvider('http://127.0.0.1:7545');
const block = await provider.getBlockNumber();
console.log('Local block number:', block);

// Web3.js equivalent
const Web3 = require('web3');
const web3 = new Web3('http://127.0.0.1:7545');
const accounts = await web3.eth.getAccounts();
console.log('Accounts:', accounts);
Replace the RPC URL if your Ganache uses a different port. These examples demonstrate read calls only.
