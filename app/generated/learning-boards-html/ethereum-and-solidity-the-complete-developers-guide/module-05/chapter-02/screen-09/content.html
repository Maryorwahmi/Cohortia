Step 1 — Detect and request accounts
Check for window.ethereum and call eth_requestAccounts to prompt the user to connect their wallet.
Step 2 — Create provider and signer
// Client-side (browser)
const provider = new ethers.providers.Web3Provider(window.ethereum);
await provider.send('eth_requestAccounts', []);
const signer = provider.getSigner();
Step 3 — Send transaction and await receipt
const tx = await signer.sendTransaction({
  to: '0xRecipientAddress',
  value: ethers.utils.parseEther('0.001')
});
await tx.wait();
console.log('Transaction confirmed:', tx.hash);
Handle user rejection and payments failures; inform the user of pending confirmations.
Common mistake
Calling getSigner without requesting accounts first can return an undefined account. Always request accounts, handle account switches, and watch for user rejections.
