Signer roles
  • Sign messages and transactions
  • Represent an account with a private key
  • Can be a Wallet, hardware wallet, or injected wallet signer
Ethers.js example
// Wallet with provider (server-side or secure environment)
const { ethers } = require('ethers');
const provider = new ethers.providers.JsonRpcProvider('https://...');
const wallet = new ethers.Wallet('YOUR_PRIVATE_KEY', provider); // server-side only
await wallet.sendTransaction({ to: '0x...', value: ethers.utils.parseEther('0.01') });
Injected provider (MetaMask) pattern
When the user has a wallet extension, window.ethereum becomes available and you can create an Ethers provider from it and obtain a Signer via getSigner. The wallet handles the private key and displays approval prompts.
// Example (client-side)
const provider = new ethers.providers.Web3Provider(window.ethereum);
await provider.send('eth_requestAccounts', []);
const signer = provider.getSigner();
Misconception check
Do not create wallets with private keys in client-side applications for real funds. Use injected signers for user transactions.
