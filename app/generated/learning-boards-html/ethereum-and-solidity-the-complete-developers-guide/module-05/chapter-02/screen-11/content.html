API key guidance
  • Use read-only keys for client-side use.
  • Restrict keys by domain or origin when possible.
  • Rotate keys and monitor usage to detect abuse.
Private key guidance
  • Never hardcode private keys in frontend code.
  • Use server-side signing or injected wallets for user-initiated transactions.
  • Consider hardware wallets or secure key management for production.
Practical checklist
Audit where keys live, classify keys by capability, enforce least privilege, and schedule rotations. If a key is exposed, revoke and rotate immediately.
