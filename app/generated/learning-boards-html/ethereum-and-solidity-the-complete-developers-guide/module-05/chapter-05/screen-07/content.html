Module 5 › Chapter 5.5 › Web3.js Listener
Terminal-style snippet
const web3Ws = new Web3(new Web3.providers.WebsocketProvider('ws://127.0.0.1:7545'));
const eventfulContract = new web3Ws.eth.Contract(CONTRACT_ABI, CONTRACT_ADDRESS);

eventfulContract.events.ValueChanged()
  .on('data', event => { console.log(event.returnValues); })
  .on('error', error => console.error('ValueChanged Error', error));

const sub = eventfulContract.events.OwnershipTransferred({ filter: { newOwner: specificNewOwner } })
  .on('data', event => console.log('Filtered:', event.returnValues));

// Later: sub.unsubscribe();
Notes
  • Use a WebSocket provider for real-time streams; HTTP does not stream events.
  • Handle errors on the subscription and unsubscribe when done.
  • Filtered subscriptions rely on indexed parameters; non-indexed filters require client-side checking.
Example output
When ValueChanged emits, the listener logs the setter address and the old and new values, which your UI can use to update an input or notification.
