Event Handling and Real-time Updates
How contracts emit logs and how frontends subscribe and react instantly.
Why this matters
Events let your DApp receive near-instant notifications of on-chain changes, enabling responsive UX while avoiding costly polling.
This chapter's demo
Deploy EventfulContract that emits ValueChanged and OwnershipTransferred, then run a terminal listener using Web3.js and Ethers.js over WebSocket to observe real-time logs.
Key Takeaway

Use events and WebSocket subscriptions for efficient, real-time UI updates; index parameters you expect to filter by.
