Module 5 › Chapter 5.5 › What is a Solidity event?
Definition and meaning
A compact definition and practical implications for DApps.
Formal claim
Events record structured data in transaction logs that external nodes index and expose to clients.
Concrete example
ValueChanged(address indexed setter, uint oldValue, uint newValue) — emitted when the owner updates a stored value.
Key Takeaway

Use events as notifications for listeners; verify state with on-chain reads if you need authoritative values.

Annotated example
event ValueChanged(address indexed setter, uint oldValue, uint newValue);

function setValue(uint _newValue) public {
  require(msg.sender == owner);
  emit ValueChanged(msg.sender, value, _newValue);
  value = _newValue;
}
Indexed parameter
setter is indexed so nodes can filter by this address efficiently.
Non-indexed data
oldValue and newValue are in the event data but not in topics if unindexed.
Common misconception
Events are not a substitute for contract storage. They provide historical logs and are great for notifications, but you must read storage for authoritative state.
