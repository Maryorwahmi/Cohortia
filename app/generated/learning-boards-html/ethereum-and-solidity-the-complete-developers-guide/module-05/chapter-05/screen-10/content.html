Module 5 › Chapter 5.5 › Error Handling
Lifecycle steps
  1. Start provider and attach single listener instance.
  2. On provider error or close, log and trigger reconnect logic with backoff.
  3. Before reattaching, remove existing listeners to avoid duplication.
  4. After reconnect, query past events from lastKnownBlock to head to replay missed items.
  5. Expose unsubscribe so UI components can call cleanup when unmounting.
Quick checklist
  • Implement exponential backoff for reconnection.
  • Keep a lastSeenBlock to replay events.
  • Remove listeners before reattaching.
Key Takeaway

Treat subscriptions as managed resources: start, stop, and recover them explicitly and replay missed events after reconnecting.
