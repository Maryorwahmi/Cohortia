Module 5 › Chapter 5.5 › Key Concepts
Event (Solidity)
A mechanism for contracts to log information that external applications can listen to and query.
Indexed parameter
Marks up to three event fields as topics so nodes can efficiently filter matching logs.
WebSocketProvider
A persistent provider that enables real-time subscriptions to events and new blocks from an Ethereum node.
Summary

Use events and indexed parameters with a WebSocket provider, convert types for display, and manage subscriptions to build responsive, reliable DApps.
