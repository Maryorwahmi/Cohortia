EventfulContract.sol (excerpt)
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract EventfulContract {
    address public owner;
    uint public value;

    event ValueChanged(address indexed setter, uint oldValue, uint newValue);
    event OwnershipTransferred(address indexed previousOwner, address indexed newOwner);

    constructor() { owner = msg.sender; value = 0; }

    function setValue(uint _newValue) public {
        require(msg.sender == owner, "Only owner can set value");
        emit ValueChanged(msg.sender, value, _newValue);
        value = _newValue;
    }
}
Annotations
  • Indexed addresses: used for node-level filtering and appear in topics.
  • Emit order: emitting before storage updates can show prior state in an event.
  • Ownership event: index both previous and new owner to filter transfers by either address.
Concrete example
When the owner calls setValue(10), the contract emits ValueChanged with the setter and the old and new values, then writes the new value to storage. A listener will receive the event and can update the displayed value quickly.
Key Takeaway

Design events intentionally: pick which parameters to index and decide whether emitting occurs before or after storage changes.
