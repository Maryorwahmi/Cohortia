Module 5 › Chapter 5.5 › UI Processing
Parsing pipeline
1) Receive raw event object. 2) Convert BigNumber types to strings or numbers. 3) Normalize addresses. 4) Update UI state with optimistic or confirmed strategy. 5) Handle parse errors gracefully.
Example transform
{ setter: event.returnValues.setter,
  oldValue: event.returnValues.oldValue.toString(),
  newValue: event.returnValues.newValue.toString()
}
UI strategies
  • Optimistic: show the event value immediately, confirm later with a read.
  • Conservative: show a pending indicator until on-chain state is re-read.
  • Batch updates: group frequent events to reduce re-renders.
Error handling
If parsing fails, log the issue and display fallback UI. Never trust raw event data without conversion and sanity checks.
