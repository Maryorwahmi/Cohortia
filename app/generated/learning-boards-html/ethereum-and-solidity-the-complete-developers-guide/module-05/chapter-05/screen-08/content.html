Module 5 › Chapter 5.5 › Ethers.js Listener
Example snippet
const providerWs = new ethers.providers.WebSocketProvider('ws://127.0.0.1:7545');
const contract = new ethers.Contract(CONTRACT_ADDRESS, CONTRACT_ABI, providerWs);

contract.on('ValueChanged', (setter, oldValue, newValue, event) => {
  console.log('ValueChanged:', setter, oldValue.toString(), newValue.toString());
});

const filter = contract.filters.OwnershipTransferred(null, specificNewOwner);
contract.on(filter, (prevOwner, newOwner, event) => {
  console.log('Filtered transfer:', prevOwner, newOwner);
});

providerWs.on('error', err => console.error('Provider Error', err));
providerWs.on('close', (code, reason) => console.log('WebSocket closed', code, reason));
Notes & best practices
  • Convert BigNumber types with toString() before display.
  • Use filter objects to leverage node-side indexing.
  • Remove listeners with contract.off(filter, handler) or contract.removeAllListeners for cleanup.
Example scenario
If your app needs only events where a particular account is the recipient, create a filter for that account and listen with contract.on(filter) to reduce noise and latency.
