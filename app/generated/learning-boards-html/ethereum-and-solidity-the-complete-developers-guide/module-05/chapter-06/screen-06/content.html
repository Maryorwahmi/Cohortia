Module 5 › Chapter 5.6 › Handling accountsChanged
Event
accountsChanged
React to new account arrays by updating active account and refreshing account-specific data.
Empty array → disconnected
If newAccounts.length === 0, clear UI state and prevent signing flows until reconnected.
Non-empty → switch active account
Set the active account to newAccounts[0], refresh balances and contract reads that depend on the signer.
Misconception
Don't assume accounts won't change. Users switch accounts frequently for separation of concerns and testing.
Key Takeaway

Subscribe to accountsChanged and make account updates explicit: clear state on disconnects and refresh data on account switches.

Terminal-style handler
window.ethereum.on('accountsChanged', (newAccounts) => {
  console.log('MetaMask accounts changed:', newAccounts);
  if (newAccounts.length === 0) {
    // handle logout / UI reset
  } else {
    // set active account to newAccounts[0] and refresh data
  }
});
