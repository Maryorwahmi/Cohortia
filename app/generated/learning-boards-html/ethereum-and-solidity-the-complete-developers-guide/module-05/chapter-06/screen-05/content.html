Module 5 › Chapter 5.6 › Request Accounts & Signer
Process
Request accounts and get a signer
Follow this user-initiated flow to obtain an Ethers.js signer without touching private keys.
1
Detect provider
Check typeof window.ethereum !== 'undefined' before proceeding.
2
Request accounts
Call eth_requestAccounts in response to a gesture to trigger the wallet consent prompt.
3
Create provider & signer
new ethers.providers.Web3Provider(window.ethereum) then provider.getSigner() to request signatures.
Key Takeaway

Only request accounts after a clear user action and always use a provider wrapper like Ethers.js to request signing while keeping private keys in the wallet.

Code walkthrough
// Example flow (concept)
if (typeof window.ethereum !== 'undefined') {
  const accounts = await window.ethereum.request({ method: 'eth_requestAccounts' });
  const provider = new ethers.providers.Web3Provider(window.ethereum);
  const signer = provider.getSigner();
  const userAddress = await signer.getAddress();

}
