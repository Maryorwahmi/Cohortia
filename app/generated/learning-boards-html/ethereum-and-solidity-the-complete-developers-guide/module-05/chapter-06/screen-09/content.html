Module 5 › Chapter 5.6 › WalletConnect
Definition
WalletConnect protocol
A bridge that connects web DApps to mobile wallets using QR codes or deep links to establish a signed session for JSON-RPC calls.
Concrete example
User scans a QR code, the session is established, and the wallet handles signing prompts on the mobile device.
Lifecycle events
WalletConnect providers support accountsChanged, chainChanged, and disconnect. Handle them just as you would with an injected provider.
Security note
The private key stays in the mobile wallet. WalletConnect only relays the signing request and signed response.
Why it matters

WalletConnect expands your DApp's audience to mobile wallets without changing the signing model. Plan for session lifecycle handling and RPC configuration.
