Module 5 › Chapter 5.6 › Switching networks
API
wallet_switchEthereumChain
Request a wallet to switch to a provided chain id. If the chain is missing use wallet_addEthereumChain or show guidance.
Handle error 4902
4902 indicates the chain isn't added to the wallet. Offer to add the chain or explain manual steps.
Handle error 4001
4001 indicates the user rejected the request. Provide fallback instructions rather than retrying aggressively.
UX tip
Explain why you need the network and show clear steps so users understand what will change in their wallet.
Key Takeaway

Programmatic network switching improves reliability but requires careful error handling and user-friendly messaging for missing chains and rejections.

Code example (concept)
const sepoliaChainId = '0xaa36a7';
try {
  await window.ethereum.request({ method: 'wallet_switchEthereumChain', params: [{ chainId: sepoliaChainId }] });
} catch (switchError) {
  if (switchError.code === 4902) {
    // prompt to add chain
  } else if (switchError.code === 4001) {
    // user rejected
  }
}
