Module 5 › Chapter 5.6 › Activity: Connect & Monitor
Activity steps
  1. Create a Connect control that triggers a user action.
  2. Check for window.ethereum and call eth_requestAccounts on click.
  3. Wrap provider with new ethers.providers.Web3Provider(window.ethereum) and getSigner.
  4. Display accounts[0], network name, and chain id.
  5. Listen for accountsChanged and chainChanged and update UI accordingly.
Key result

By following these steps you will observe real-time updates as the wallet state changes and learn how to make the UI resilient to those changes.

Starter code (index.html excerpt)
// On Connect click
const accounts = await window.ethereum.request({ method: 'eth_requestAccounts' });
