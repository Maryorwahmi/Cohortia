Module 5 › Chapter 5.6 › MetaMask vs WalletConnect
MetaMask (injected)
Detect window.ethereum, call eth_requestAccounts, wrap with Ethers.js Web3Provider. Best for desktop browser extension users.
Pros
Immediate provider access and simple event handling.
Cons
Requires extension; limited reach to mobile users without injected wallets.
WalletConnect (bridge)
Establish a session via QR or deep link to mobile wallets. Requires RPC config and session handling for disconnects.
Pros
Supports a wide range of mobile wallets and keeps keys in the mobile app.
Cons
Requires QR/deep link UI and session lifecycle handling; needs RPC endpoints configured.
Shared responsibilities
  • Signing always occurs in the wallet; keys are never exposed to the DApp.
  • Both emit accountsChanged and chainChanged events that must be handled.
  • Implement error handling for user rejections and missing chains.
