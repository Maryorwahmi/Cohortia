Wallet Integration — MetaMask & WalletConnect
In this lesson you will learn the APIs and UX patterns required to connect your DApp to browser and mobile wallets so users can sign transactions safely.
In this lesson
Detect window.ethereum, request accounts, wrap provider with Ethers.js.
Coming up
Handle accountsChanged and chainChanged. Support WalletConnect for mobile.
Why it matters
Good integration keeps user funds safe and prevents inconsistent app state when wallets change.
Visual concept
Browser Wallet
MetaMask injects window.ethereum → EIP-1193 provider
DApp
Requests eth_requestAccounts, wraps provider for Ethers.js signer
Mobile Wallets
WalletConnect bridges QR/deep links for signing
Key Takeaway

Treat the wallet as the authority for signing and chain identity. Detect provider, request user consent, and adapt to account or chain changes.

Terminal demo (concept)
// Example: request accounts & create provider
if (typeof window.ethereum !== 'undefined') {
  const accounts = await window.ethereum.request({ method: 'eth_requestAccounts' });
  const provider = new ethers.providers.Web3Provider(window.ethereum);
  const signer = provider.getSigner();
  // listen for events: accountsChanged, chainChanged
}
Use this pattern inside a user-initiated action. For mobile support, integrate WalletConnect as a bridge that presents a QR or deep link to a mobile wallet.
