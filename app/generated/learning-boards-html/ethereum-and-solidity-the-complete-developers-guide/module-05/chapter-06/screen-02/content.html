Learning Objectives
From detection to WalletConnect: measurable developer outcomes.
01
Detect window.ethereum
Recognize MetaMask's injected provider and know EIP-1193 behaviors. This is required so your DApp can call provider methods reliably.
Mnemonic: provider → injected object → standard API
VERIFIED COMPETENCY MILESTONE
02
Request accounts & create signer
Use eth_requestAccounts to prompt the wallet, then create an Ethers.js Web3Provider and getSigner to request transaction signing without accessing private keys.
Mnemonic: request → provider → signer
VERIFIED COMPETENCY MILESTONE
03
Handle account & network events
Listen for accountsChanged and chainChanged and reinitialize or prompt the user to switch networks to keep state consistent.
Mnemonic: listen → react → re-init
VERIFIED COMPETENCY MILESTONE
04
Add WalletConnect and error handling
Integrate a WalletConnect client for mobile wallets and handle common errors like user rejections and missing chains (codes 4001, 4902).
Mnemonic: bridge → support → handle errors
VERIFIED COMPETENCY MILESTONE
