Fix common migration failures

Could not connect to network
Ensure Ganache is running and that truffle-config targets the correct host and port.
Changes not visible after migrate
Run truffle migrate --reset to force all migrations to run and deploy updated bytecode.
Migration script errors
Syntax or naming errors cause migration failures — compile first and check contract names used in artifacts.require.
Scenario
You changed SimpleStorage by adding a new variable, but the UI still shows the old contract. Running truffle migrate will not update the deployed contract at the same address. Use truffle migrate --reset to redeploy.
Warning

Resetting migrations creates new addresses. Update any code that referenced the old address after a reset redeploy.
