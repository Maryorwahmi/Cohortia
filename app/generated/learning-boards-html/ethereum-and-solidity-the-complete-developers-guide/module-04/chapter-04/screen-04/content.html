Core Concept

Migrations explained

Migrations are scripts that run once in order and are tracked on-chain to prevent duplication.

Ordering
Numbered filenames like 1_ and 2_ determine execution sequence.
Persistence
Truffle records which migrations ran so they are not re-run unintentionally.
Use case
Useful for multi-contract projects and staged upgrades.
Analogy
Think of migrations as commit history for deployments. Each script is a step that can be replayed and tracked so everyone deploys the same set of contracts in the same order.
Key Takeaway

Use numbered migrations to keep deployments ordered and reproducible across environments.
