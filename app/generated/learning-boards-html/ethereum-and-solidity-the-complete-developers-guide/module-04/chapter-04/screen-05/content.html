Process Flow

Naming drives execution order

Use numeric prefixes so Truffle runs migrations deterministically.

1
Deploy Migrations.sol
First step: register migration history on-chain.
2
Deploy SimpleStorage
Second step: application contract is deployed and address is recorded.
Pro tip
When adding a migration later, give it the next number instead of renaming older files.
Common mistake
Assuming timestamp or editor order controls migrations. Always use numbered prefixes to ensure deterministic runs across machines.
Example

1_initial_migration.js then 2_deploy_simplestorage.js — Truffle runs 1 then 2 when you execute truffle migrate.
