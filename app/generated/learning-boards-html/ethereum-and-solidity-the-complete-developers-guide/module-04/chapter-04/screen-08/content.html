Module 4 › Chapter 4.4 › Deployer object
Core Concept

What the deployer does

deployer.deploy sends contract creation transactions and records results in Truffle’s artifacts.

Transaction orchestration
Handles gas, account selection, and confirmation waits.
Recording
Saves the deployed address and writes migration progress.
Example
deployer.deploy(SimpleStorage) sends the creation transaction and after mining you will see a contract address logged in the terminal and saved by Truffle.
Common misconception

deployer.deploy does not instantly return an address; it completes after the transaction is mined and Truffle records the artifact.
