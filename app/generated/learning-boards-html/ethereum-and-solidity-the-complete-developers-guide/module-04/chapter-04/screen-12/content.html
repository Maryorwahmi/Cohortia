Hands-on Activity

Deploy SimpleStorage to Ganache

Follow this checklist in your project to complete the lab.

Step 1
Start Ganache Desktop and note the network details.
Step 2
Create migrations/2_deploy_simplestorage.js with artifacts.require and deployer.deploy.
Step 3
Run truffle migrate from the project root and watch for contract address output.
Verify

Open Ganache’s Blocks and Transactions tabs to confirm the deployment and account balance change.

If something fails

Check for syntax errors, ensure Ganache is running, and use truffle migrate --reset if you need a fresh redeploy.
