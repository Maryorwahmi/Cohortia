Module 4 › Chapter 4.4 › Migration script
Definition

Minimal migration pattern

Load the artifact, export a deployer function, and call deployer.deploy.

// migrations/2_deploy_simplestorage.js
const SimpleStorage = artifacts.require("SimpleStorage");

module.exports = function (deployer) {
  deployer.deploy(SimpleStorage);
};
Concrete example
This file tells Truffle to deploy SimpleStorage and save the deployed address in its migration history.
Common mistake
Using a file path or wrong contract name in artifacts.require will prevent Truffle from locating the compiled abstraction.
Key Takeaway

Keep migrations simple: require the contract by name and call deployer.deploy for a predictable deployment.
