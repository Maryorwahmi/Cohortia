Module 4 › Chapter 4.4 › artifacts.require
Definition

What it returns

An abstraction with ABI, bytecode, and deployment metadata used by Truffle.

ABI and bytecode
Needed to encode constructor arguments and send the creation transaction.
Naming
Pass the contract name exactly as declared in Solidity, not a file path.
Concrete scenario
You compile SimpleStorage, then in the migration you call artifacts.require("SimpleStorage") and pass that abstraction to deployer.deploy. Truffle then sends a transaction that creates the contract and records its address.
Key Takeaway

Use artifacts.require with the contract name to bridge compilation output and runtime deployment.
