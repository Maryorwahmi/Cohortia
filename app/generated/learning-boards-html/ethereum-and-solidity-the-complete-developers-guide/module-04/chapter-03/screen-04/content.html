Why this matters
Truffle's conventions make compilation predictable and make it easy to find the artifact you need for deployment and front-end calls.
Common mistake
Saving a .sol file outside contracts/ will not be compiled unless imported from within contracts/.
Concrete example
// File: contracts/SimpleStorage.sol // SPDX-License-Identifier: MIT pragma solidity ^0.8.19; contract SimpleStorage { uint256 public storedData; constructor() { storedData = 0; } function set(uint256 x) public { storedData = x; } function get() public view returns (uint256) { return storedData; } }
Key Takeaway

Keep source files in contracts/ and name them clearly so Truffle compiles and produces a matching artifact in build/contracts/.
