ABI (Application Binary Interface)
A JSON array describing functions, events, and parameter types. Front-ends use it to encode calls and decode results.
"abi": [ { "inputs": [], "name": "get", "outputs": [ { "internalType": "uint256", "name": "", "type": "uint256" } ], "stateMutability": "view", "type": "function" }, ... ]
Why ABI matters
Without the ABI a web or script cannot format calls to contract functions correctly.
Bytecode
Bytecode is the compiled machine code that the EVM executes. It appears as a long hex string in the artifact.
"bytecode": "0x6080604052..."
Misconception
The ABI is not executable code; it only describes the interface. The bytecode is what gets deployed.
Key Takeaway

Open the artifact and confirm an abi array and bytecode string exist. Use the ABI for integration and bytecode for deployment.
