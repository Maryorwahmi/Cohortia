Module 4 › Chapter 4.3 › Hands-on Activity
Activity steps
Follow these steps to complete the lab and verify the artifact.
1. Create file
Save SimpleStorage.sol into contracts/ and confirm the pragma line matches your intended compiler.
2. Compile
Run truffle compile from the project root and watch for success or error messages.
3. Inspect artifact
Open build/contracts/SimpleStorage.json and verify the abi array and bytecode string are present.
Check your understanding
Which artifact field will you pass to a front-end to encode function calls? (Hint: it's the interface description.)
Key Takeaway

Follow the create-compile-inspect loop until you can reliably open the JSON and point to abi and bytecode as the pieces for integration and deployment.
