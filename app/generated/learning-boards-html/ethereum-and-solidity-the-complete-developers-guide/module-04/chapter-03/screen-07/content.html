Module 4 › Chapter 4.3 › truffle compile
Terminal demo (example)
$ cd my-first-truffle-app
$ truffle compile
Compiling your contracts...
===========================
> Compiling SimpleStorage.sol
> Artifacts written to build/contracts/SimpleStorage.json
> Compilation successful
Truffle reports which files were compiled and where artifacts were written. Use these lines to verify success.
Checklist after compile
  • Open build/contracts/SimpleStorage.json and confirm abi and bytecode exist.
  • If errors appear, read file and line numbers from Truffle's output to locate syntax issues.
  • Run compile again after each fix to ensure no new errors are introduced.
Key Takeaway

Treat the terminal output as your primary feedback: success lines confirm artifacts exist; errors point to the exact file and line to fix.
