Concrete scenario
If you call set(42) in a transaction, storedData becomes 42; calling get afterwards returns 42 without gas when executed as a call.
Common misconception
Marking a variable public does not make writes free. Public exposes a getter; write operations still require transactions and gas.
Practical checks
  • Confirm the pragma version is compatible with Truffle's solc setting.
  • Ensure functions that change state will be invoked via transactions in tests or migrations.
  • Use view functions for reads to avoid unnecessary gas consumption.
Key Takeaway

Reading code line by line ties each Solidity construct to its runtime behavior: storage, gas, and visibility.
