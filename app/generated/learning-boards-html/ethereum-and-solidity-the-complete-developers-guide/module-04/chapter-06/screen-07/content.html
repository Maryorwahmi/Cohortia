Module 5 › Chapter 4.6 › Test Isolation
What beforeEach does
beforeEach runs before every it test case. When you call Contract.new() inside it, Truffle deploys a new contract instance for each test so state does not carry between tests.
Anti-pattern
Using Contract.deployed() in beforeEach shares an instance across tests and causes state leakage.
Benefit
Fresh instances mean tests are independent, easier to reproduce, and quicker to debug when they fail.
Check your understanding
If two tests modify the same contract state, what will happen when you use Contract.deployed() in beforeEach? The second test may observe the first test's changes, causing flaky, order-dependent failures.
Mini example
beforeEach(async () => {
  // good
  simpleStorageInstance = await SimpleStorage.new();
});

// vs
beforeEach(async () => {
  // bad: shares instance
  simpleStorageInstance = await SimpleStorage.deployed();
});
Deploying new instances ensures each it block begins from a blank, known state.
Pro tip

If a test fails intermittently, check for shared state and missing await calls first — those are common root causes.
