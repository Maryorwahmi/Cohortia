Checklist to avoid flaky tests
  • Await every asynchronous deployment, transaction, or call.
  • Use Contract.new() in beforeEach to deploy fresh instances for each test.
  • Convert BigNumber values to primitives before assertions.
  • Write negative and edge-case tests as well as happy paths.
  • Be mindful of gas for heavy operations and adjust test strategy if needed.
Reflex
When a test fails intermittently, first check for missing await and shared instance usage; those are the most likely causes.
Example failure
Two tests that set a value will conflict if they share the same instance; the second test might read the first test's update and fail its assertions.
Pro tip

Add small, focused tests that assert a single behavior each. They are faster, clearer, and easier to debug than large tests that cover many interactions.
