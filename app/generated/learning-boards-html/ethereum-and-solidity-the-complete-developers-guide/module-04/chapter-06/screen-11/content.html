Module 5 › Chapter 4.6 › Hands-on Activity
Activity steps
  1. Create test/SimpleStorage.test.js and load artifacts.require("SimpleStorage").
  2. Use contract(...) to get accounts and declare a contract instance variable.
  3. Deploy a fresh instance in beforeEach with SimpleStorage.new().
  4. Add it tests for initial value, set+get, and multiple updates, remembering to await and convert results.
  5. Run truffle test and fix any failing assertions by inspecting failure messages.
Debug routine
If a test fails, run it alone, check for missing await, ensure beforeEach uses Contract.new, and confirm BigNumber conversions before assertions.
// Quick starter (paste into test/SimpleStorage.test.js) const SimpleStorage = artifacts.require("SimpleStorage"); contract("SimpleStorage", (accounts) => { let simpleStorageInstance; beforeEach(async () => { simpleStorageInstance = await SimpleStorage.new(); }); it("should retrieve initial value as 0", async () => { const initial = await simpleStorageInstance.get(); assert.equal(initial.toNumber(), 0); }); });
Success check

If your tests pass locally, you have a reproducible verification step you can run before migrations to main networks.
