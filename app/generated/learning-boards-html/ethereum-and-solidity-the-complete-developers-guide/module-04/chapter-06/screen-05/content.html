Stack overview
Mocha: test runner and structure for suites and cases.
Chai: assertion library for checking outcomes.
Truffle: provides artifacts, config, and an EVM to run tests locally.

Common mistake
Not awaiting asynchronous calls. If you forget await on a transaction, assertions can run before the state change completes, causing false failures.
Process diagram (cards)
1. Load abstraction
Use artifacts.require("ContractName") to access the compiled contract.
2. Deploy per test
Use beforeEach and Contract.new() to get a fresh instance for each it block.
3. Assert outcomes
Call functions, await results, and use Chai assertions to verify behavior.
Concrete tip

Always convert blockchain numeric types using toNumber() or toString() before asserting equality with JavaScript primitives.
