Module 5 › Chapter 4.6 › Assertions & BigNumber
Why conversion matters

BigNumber objects are not equal to primitive numbers. Convert with toNumber() or toString() before comparing to avoid type-based assertion failures.

Recommended
Use actualValue.toNumber() for typical small integers in tests and assert.equal against a JavaScript number.
When to use toString()
For very large integers near numeric limits, compare strings to avoid precision loss in JavaScript numbers.
Misconception
Relying on weak equality conversions can hide type issues. Convert explicitly to a primitive and assert deterministically.
Concrete example
const actualValue = await simpleStorageInstance.get();
// Convert before asserting
assert.equal(actualValue.toNumber(), 100, "The value was not stored correctly.");
This explicit conversion prevents object-vs-primitive mismatches and makes your assertion reflect numeric equality.
Key Takeaway

Always convert blockchain numeric types to a comparable primitive before asserting equality in tests.
