Module 4 › Chapter 4.2 › Configuring the Development Network
What to set
  • host: the RPC address Ganache exposes, commonly 127.0.0.1 or localhost.
  • port: the RPC port Ganache listens on; confirm via the Ganache UI or logs.
  • network_id: use "*" for flexibility or the exact number for strict matching.
Quick connectivity check: start Ganache, confirm RPC details, then run a non-destructive Truffle command to confirm Truffle can reach the network.
Troubleshooting
If migrations fail with a connection error, verify Ganache is running and that the host/port match exactly.
If you get an unexpected network id error, switch from a numeric ID to a wildcard to allow flexible local testing.
Key Takeaway
Always match the network connection details in truffle-config.js to the active Ganache RPC values before migrating or running tests.
