Setting Up Your Development Environment with Truffle

Install Truffle, scaffold the standard project structure, and configure truffle-config.js to connect to your local Ganache instance for fast iteration.

In this lesson
Install, init, inspect folders, and configure networks for Ganache.
Explore Key Topics
Installation · Project Layout · Configuration
Install
Get Truffle via npm so you can run the CLI and scaffold projects quickly.
Scaffold
truffle init produces contracts, migrations, and tests that follow a predictable workflow.
Configure
Edit truffle-config.js to point the development network at Ganache’s RPC host and port.
Key Takeaway

Truffle pairs with Ganache to provide a repeatable local environment for writing, compiling, deploying, and testing smart contracts.
