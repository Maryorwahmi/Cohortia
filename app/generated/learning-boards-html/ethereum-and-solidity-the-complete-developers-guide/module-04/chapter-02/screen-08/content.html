Module 4 › Chapter 4.2 › Inspecting truffle-config.js
Networks section
Find the development network configuration and ensure the host and port match the RPC server that Ganache is running. Setting network_id to a wildcard is common for local development.
Example values (visual only)
development: {
  host: "127.0.0.1",
  port: 7545,
  network_id: "*",
}
Common Mistake
Using an incorrect port or host will cause connection failures when attempting to migrate or run tests against Ganache.
Compilers section
Specify a Solidity compiler version that matches the pragma in your contracts. Pinning a specific version avoids unexpected compilation issues caused by incompatible language versions.
Example visual
compilers: {
  solc: {
    version: "0.8.19",
  }
}
Key Takeaway
Edit both networks and compilers sections so Truffle compiles with the expected solc version and connects to the correct RPC endpoint.
