Module 4 › Chapter 4.2 › Global vs Local Installation
Global install
Convenient for interactive development. The truffle command is on your path and can be run from any folder without extra commands.
Benefit
Fast local iteration and exploration.
Pitfall
Global versions vary across machines and are not part of project metadata.
Local install
Declared in package dependencies so the project specifies the tool version used by CI and collaborators. Requires invoking via a package runner or npm script unless added to path by tooling.
Benefit
Reproducible environments and CI parity.
Resolution Pattern
Use global for convenience, pin local in CI or when reproducibility is required, and document the team preference.
