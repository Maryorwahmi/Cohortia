Module 4 › Chapter 4.2 › Truffle Project Structure
Directory overview
contracts/
Your Solidity source files, each containing contract code and version pragmas.
migrations/
JavaScript files run in sequence to deploy and link contracts. Order matters for dependent deployments.
test/
Place automated tests here to assert contract behavior after deployment.
truffle-config.js
Central configuration: networks, compilers, and project-level options that affect compile and deploy steps.
Concrete scenario
Imagine a token contract deployed in migration 1 and a marketplace deployed in migration 2 that requires the token address. If migrations run out of order, the marketplace would not be linked correctly. Ordered migrations prevent this class of error.
Misconception
Do not treat migration scripts as throwaway. They are part of your project’s reproducible deployment history and should be maintained like source code.
Key Takeaway
A clear folder hierarchy maps directly to developer responsibilities: source, deployment scripts, tests, and config.
