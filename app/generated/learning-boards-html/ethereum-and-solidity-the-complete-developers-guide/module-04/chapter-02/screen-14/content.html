Module 4 › Chapter 4.2 › Key Concepts — Part 1
Truffle
A comprehensive framework for compiling, deploying, testing, and interacting with smart contracts.
npm
Node package manager used to install Truffle globally or locally; installation location affects command invocation.
truffle init
Scaffolds the standard project layout so you can start compiling and testing immediately.
Summary
These three concepts form the minimum mental model you need to scaffold, run, and verify local smart contract development with Truffle and Ganache.
