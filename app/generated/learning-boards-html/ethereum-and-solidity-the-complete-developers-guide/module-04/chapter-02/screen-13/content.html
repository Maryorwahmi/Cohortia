Module 4 › Chapter 4.2 › Testing and the Truffle Console
Automated testing
Write JavaScript or Solidity tests in the test folder to assert contract behavior after migrations run. Automated tests catch regressions when you change compiler settings or refactor code.
Visual command
truffle test
Interactive console
Use the console to call functions, inspect contract state, and manually verify behavior during development. This is useful for quick checks before formalizing tests.
Misconception
Interactive checks are helpful, but they do not substitute for a committed test suite that runs automatically and consistently.
Key Takeaway
Combine the console for fast checks with an automated test suite for reliable, repeatable verification across changes.
