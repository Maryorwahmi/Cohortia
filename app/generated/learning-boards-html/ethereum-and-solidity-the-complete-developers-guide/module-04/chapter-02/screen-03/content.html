Module 4 › Chapter 4.2 › Learning Objectives — Verification
Milestone 1: Explain Truffle

Name the framework features: project structure, compilation, migrations, testing, and console, and explain how they reduce manual steps.

Milestone 2: Install & verify

Confirm the CLI reports a version and the Solidity compiler information. If you see an error, check whether the package was installed globally.

Milestone 3: Initialize

Run the init command in an empty directory and list the generated contracts, migrations, and test files to confirm the scaffold.

Milestone 4: Configure

Open truffle-config.js, set the development network values to match Ganache, and set a specific solc version to match your contracts.

Practical Reminder
When verifying, look for three outputs from the truffle version command: the truffle CLI, the Solidity compiler version, and the Node.js version. These confirm the toolchain is available and aligned.
Common Mistake
Installing without the global flag can make the truffle command unavailable globally. If you prefer local installs, use the package runner to invoke the tool.
