What migrations do
Migrations are numbered scripts that Truffle runs to deploy contracts and perform setup tasks in a reliable order. They are part of your project’s deployment history.
Example flow
1_initial_migration.js
2_deploy_token.js
3_deploy_marketplace.js
Best practices
  • Commit migration scripts with source control as part of the project.
  • Write scripts to be repeatable and avoid embedding secrets or environment-specific data.
  • Use migrations to wire deployed addresses so later steps can reference them.
Misconception
Migrations are not disposable. Treat them like code — they document and reproduce the deployment order for the project.
Key Takeaway
Keep migration scripts ordered, idempotent when practical, and committed so deployments are reproducible across environments.
