Module 4 › Chapter 4.2 › Installing Truffle
Prerequisites
  • Node.js and npm must be installed and available in your terminal.
  • Decide between global CLI install for convenience or local install for reproducible project-level control.
Verification
After installation, run the version check to confirm Truffle and the bundled Solidity compiler information are visible to the environment.
Common Mistake
Installing without the global option makes truffle unavailable globally. In that case, use the package runner to execute Truffle commands inside the project.
Terminal Demo (visual)
npm install -g truffle
truffle version
The version output confirms Truffle and shows the default Solidity compiler version available to the CLI.
Pro tip
If you prefer local tools for CI parity, install Truffle as a project dependency and invoke it through the package runner when needed.
