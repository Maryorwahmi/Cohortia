Module 4 › Chapter 4.5 › Common Mistakes
Mistake vs Fix
Forgetting await — returns Promise. Fix: use await before calls.
Calling abstraction directly — not an instance. Fix: await Contract.deployed().
Ganache restart — migrations lost. Fix: truffle migrate --reset, then reopen console.
Debugging checklist
  1. Is Ganache running and on the expected port?
  2. Have migrations been run on this network?
  3. Did you await Contract.deployed() and store the instance?
  4. Are you using the correct account for transactions?
