Truffle Console
Interactive runtime for direct contract calls and quick testing.
Contract.deployed()
Returns a promise resolving to a deployed instance bound to an address.
Transaction Receipt
Contains tx hash, receipt details, logs, and gasUsed for cost analysis.
Summary Takeaway

Use the console as your rapid feedback loop: load instances, read state with view calls, change state with transactions, and inspect receipts to validate behavior and measure cost.
