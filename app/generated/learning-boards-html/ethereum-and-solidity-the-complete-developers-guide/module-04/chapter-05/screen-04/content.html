Module 4 › Chapter 4.5 › Launching the Truffle Console
Command and quick checks
$ truffle console
truffle(development)> web3.eth.getAccounts().then(a => console.log(a))
// Expected: array of local accounts from Ganache
  • • Confirm Ganache is running. If Ganache restarts, deployed contracts may be lost and require migrations to run again.
  • • The console connects to the network specified as development in truffle-config.js.
  • • The console exposes contract abstractions and web3, which you will use to interact with contracts.
Key Takeaway

The Truffle console is a live JavaScript prompt connected to your network — use it to confirm connectivity and view accounts before interacting with contracts.

Example scenario
Imagine you restarted Ganache. Running truffle console will seem normal, but calling deployed() may fail if migrations haven't been re-run. The correct flow is to restart Ganache, run truffle migrate --reset, then open truffle console so deployed() can find your contracts on the new chain.
Common mistake
Forgetting to start Ganache or re-migrate after a restart leads to missing deployed addresses and confusing errors.
