Module 4 › Chapter 4.5 › Hands-on Activity
Step-by-step
1. Ensure Ganache is running. If restarted run truffle migrate --reset.
2. Run truffle console in the project root.
3. const SimpleStorage = artifacts.require("SimpleStorage"); const instance = await SimpleStorage.deployed();
4. await instance.get(); // expect <BN: 0>
5. await instance.set(42); // inspect receipt
6. await instance.get(); // expect <BN: 42>
Verification and tips
Check receipt.gasUsed to understand cost. If a write fails, inspect error messages and confirm the sending account has sufficient funds and correct permissions. Use accounts from web3.eth.getAccounts() to simulate different users.
Key Takeaway

This loop — deploy, load, read, write, inspect — is the core development rhythm when working with Truffle and Ganache locally.
