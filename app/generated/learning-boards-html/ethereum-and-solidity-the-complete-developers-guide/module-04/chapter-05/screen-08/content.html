Receipt fields
• tx: transaction hash identifying the transaction.
• receipt: block inclusion details such as blockNumber and gasUsed.
• logs: events emitted by the contract during execution.
Use these fields to confirm the transaction mined correctly, to measure gas cost, and to validate that expected events were emitted.
Concrete example
{
  tx: '0xabc...',
  receipt: { blockNumber: 5, gasUsed: 21000 },
  logs: [ /* event objects */ ]
}
Why gasUsed matters
GasUsed lets you estimate ETH cost and identify expensive operations. If gasUsed grows unexpectedly, review your Solidity logic for inefficiencies.
