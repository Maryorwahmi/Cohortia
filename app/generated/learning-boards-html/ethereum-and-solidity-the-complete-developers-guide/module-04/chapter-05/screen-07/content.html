Module 4 › Chapter 4.5 › Sending Transactions
Command example
truffle(development)> await instance.set(25)
// → transaction receipt object with tx, receipt, logs
  • • State-changing calls create a transaction and consume gas from the sending account.
  • • The return is a rich object; to see the updated value, call a view function after the transaction completes.
  • • On Ganache transactions are mined quickly, providing immediate receipts for inspection.
Example and pitfall
If you run await instance.set(25) and expect the console to print 25, you will be surprised. The call returns a receipt; to confirm the change you must run await instance.get() afterwards. Treat the receipt as metadata about the transaction, not the new state value.
Pro Tip

Run the write call and then a read call in sequence: await instance.set(25); await instance.get() to observe the updated BigNumber.
