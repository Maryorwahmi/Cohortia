Learning Objectives

Master the console workflow for quick contract testing and inspection.

Learn
Understand
Apply
Master
01
Launch and navigate the Truffle console
You will run truffle console, connect to the development network and use the JavaScript prompt to enter commands. Being comfortable with this runtime speeds up debugging.
VERIFIED COMPETENCY MILESTONE
02
Load deployed instances
You will use Contract.deployed() to get an instance that knows its on-chain address and ABI so you can call functions directly on that instance.
VERIFIED COMPETENCY MILESTONE
03
Read state with view calls
You will call view functions like get() that return BigNumber objects and do not consume gas. This is the fastest check for correctness.
VERIFIED COMPETENCY MILESTONE
04
Send transactions and read receipts
You will call state-changing functions like set() and interpret the returned receipt, including gasUsed and logs, to measure cost and behavior.
VERIFIED COMPETENCY MILESTONE
