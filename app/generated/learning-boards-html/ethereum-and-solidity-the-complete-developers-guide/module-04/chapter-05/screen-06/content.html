Module 4 › Chapter 4.5 › Calling View Functions
Example call
truffle(development)> await instance.get()
<BN: 0>
  • • View calls do not create transactions and therefore consume no gas.
  • • Results are often BigNumber objects; convert using toNumber() or toString() when needed.
  • • Forgetting await returns a Promise instead of the resolved BigNumber.
Key Takeaway

Use await for view calls and handle BigNumbers deliberately; view calls are the fastest way to confirm state.

Practical tip & misconception
If you need to compare a returned value, call (await instance.get()).toNumber() or toString() before using standard JavaScript operators. A common error is treating the BigNumber as a plain number and seeing unexpected type behavior in conditionals.
Try this
Call await instance.get(), then run (await instance.get()).toNumber() to confirm you can safely use the value in JavaScript logic.
