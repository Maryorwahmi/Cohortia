Module 4 › Chapter 4.5 › Specifying the Sending Account
Commands
truffle(development)> const accounts = await web3.eth.getAccounts()
truffle(development)> await instance.set(50, { from: accounts[1] })
This pattern lets you choose which account pays gas and acts as msg.sender so you can test permissioned behavior.
Concrete scenario
If set is protected by an onlyOwner modifier, sending from accounts[1] will fail if that account is not the owner. This lets you confirm access control without deploying separate contracts or building a UI.
Common mistake
Passing a non-existent account index or omitting accounts retrieval will cause errors. Always retrieve accounts before using them.
