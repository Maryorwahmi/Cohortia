Module 4 › Chapter 4.5 › Loading a Deployed Contract Instance
Typical console commands
truffle(development)> const SimpleStorage = artifacts.require("SimpleStorage")
truffle(development)> const instance = await SimpleStorage.deployed()
// instance now refers to the deployed contract at its address
  • • Use artifacts.require or the environment-provided contract abstraction to access the contract class.
  • • Contract.deployed() automatically finds the deployed address for the currently connected network.
  • • Store the resolved instance in a variable for repeated calls during the session.
Concrete example
If SimpleStorage was migrated to network id 5777 by Truffle, deployed() finds its address on that network. After assigning the instance variable, calls such as instance.get() or instance.set(25) will execute against that address and return either a value or a transaction receipt.
Misconception
Calling SimpleStorage.get() directly will fail because the abstraction does not represent a specific on-chain instance; you must call the method on the resolved instance.
Key Takeaway

Always get an instance via deployed() and use await to receive the usable contract object that knows its address.
