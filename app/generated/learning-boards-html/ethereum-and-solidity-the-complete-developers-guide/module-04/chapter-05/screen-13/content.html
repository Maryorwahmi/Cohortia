Module 4 › Chapter 4.5 › Quick Quiz
Scenario 1
ReferenceError: instance is not defined. Check that you ran const instance = await SimpleStorage.deployed() and that deployed() resolved successfully.
Scenario 2
Revert on set call. Check the sending account, function preconditions, and argument types; simulate with another account using from.
Scenario 3
deployed() cannot find contract. Likely Ganache restarted; run truffle migrate --reset and then reopen the console.
Reflection
These diagnostic habits convert error messages into concrete next steps instead of guesswork: check instance, check network/migrations, check accounts, and check arguments.
