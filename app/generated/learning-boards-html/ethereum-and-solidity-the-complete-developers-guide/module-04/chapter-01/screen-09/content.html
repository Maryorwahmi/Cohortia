Transaction logging for debugging

Use the logs to inspect gas, event output, and transaction traces that explain why calls succeed or fail.

What the log shows
  • Gas used and gas limit information.
  • Transaction hash and status (success or revert).
  • Emitted events and return values, when available.
Debugging pattern
  1. Trigger the failing transaction locally.
  2. Open Ganache's transaction log to read the trace and events.
  3. Identify the failing internal call or revert reason and iterate on the contract logic.
Concrete example

If a token transfer reverts, check the log for a revert status and any emitted approval events to see if allowance or balances were incorrect before the call.
