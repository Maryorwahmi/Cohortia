Pre-funded accounts

Ganache creates multiple accounts loaded with test ether so you can deploy and transact without delays.

Practical usage

Select an account shown by Ganache, use it in your development wallet or framework, and perform deployments and calls immediately.

Ephemeral nature

If you reset the chain, accounts and balances typically reset too. This is useful for reproducible tests but means local keys are not permanent unless you export them.

Analogy
Think of these accounts as disposable test wallets in a developer sandbox — handy for experimentation but not for production use.
Example task

Deploy a simple contract with one pre-funded account, call a function that transfers tokens, and confirm balances update instantly.

Misconception

Do not assume these balances exist outside Ganache; they are local and meant only for development.
