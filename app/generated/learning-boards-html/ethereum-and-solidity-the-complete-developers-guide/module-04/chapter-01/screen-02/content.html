Learning Objectives

Learn, understand, apply, and master local development with Ganache.

Learn → Understand → Apply → Master
01
Why local dev matters

Explain why using a local blockchain reduces latency and risk when developing smart contracts. This knowledge helps you choose the right testing environment for each stage.

VERIFIED COMPETENCY MILESTONE
02
Install and configure Ganache

Set up Ganache Desktop or the CLI, start a local chain, and note the RPC address and network ID your tools will use to connect.

VERIFIED COMPETENCY MILESTONE
03
Identify Ganache features

Recognize pre-funded accounts, transaction logging, and the interface details that help you inspect transactions and events during debugging.

VERIFIED COMPETENCY MILESTONE
04
Iterate and debug rapidly

Use resetting, configurable block times, and forking to test scenarios quickly and isolate bugs before going to a public testnet.

VERIFIED COMPETENCY MILESTONE
