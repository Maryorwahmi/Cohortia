Fixing connection errors

Follow a short checklist to resolve the most common causes of "could not connect" messages.

Checklist
  1. Confirm Ganache is running.
  2. Copy RPC address and port shown by Ganache into your config.
  3. Ensure network ID matches the value Ganache displays.
  4. Restart your framework or terminal session after changes.
Common pitfalls
  • Running multiple Ganache instances on different ports.
  • Assuming default ports when another process has claimed them.
  • Forgetting to update the network ID after a custom configuration.
Example fix

If you get a connection error, open Ganache, copy the RPC server and network ID, paste them into your project's network settings, then restart your deploy command.
