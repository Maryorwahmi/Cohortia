Critical startup values

RPC server: The local address and port your tools call to send transactions and queries.

Network ID: A numeric identifier that helps tools ensure they connect to the intended chain.

Example
Ganache shows a local address and port on launch and a network ID. Copy these into your project's network configuration precisely to avoid errors.

Troubleshooting checklist

  • Is Ganache running? If not, start the desktop app or CLI.
  • Does the RPC address match the one in your project's config?
  • Is the network ID set correctly in your framework configuration?
  • Restart the tooling after changing network settings to clear cached connections.
Check your config

These three values are the first things to validate when your project cannot connect to Ganache.
