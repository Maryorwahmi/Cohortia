Install options

Choose Desktop for a visual, guided start or the command-line package when you need automation.

Desktop app

Best for beginners: visual lists of accounts, blocks, and transaction logs that simplify debugging.

Command-line

Ideal for scripting and CI. Use it when you need repeatable, automated local chains for tests.

Configuration check

After starting, check the RPC server address and network ID and copy them into your project's network settings.

Pro-tip

Use the Desktop when learning and switch to CLI for automated test pipelines to keep builds reproducible.

Common mistake

Trying to connect to an old port or network ID; always read the current RPC details after launch.
