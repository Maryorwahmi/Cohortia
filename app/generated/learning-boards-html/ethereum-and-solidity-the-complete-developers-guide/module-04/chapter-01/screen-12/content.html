Advanced Ganache features

Configure block times, supply custom accounts, or fork a public chain snapshot for realistic local testing.

Block time
Slow down block mining to observe time-dependent behavior without needing network delays.
Custom accounts
Provide specific private keys and balances to model particular actor roles in tests.
Forking
Create a local snapshot of a public chain to test interactions with deployed contracts without touching the live network.
Example use

Fork a recent mainnet state to test how your contract will interact with an existing deployed protocol, then iterate locally until behavior is stable.
