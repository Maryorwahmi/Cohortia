Module 4 › Chapter 3.5 › CEI Pattern
Process

Checks → Effects → Interactions

A simple ordering discipline that makes state predictable before any external calls.

Checks
Validate balances, approvals, and paused state with require statements.
Effects
Update mappings and pools so the contract's state reflects the action.
Interactions
Perform transfers or call external contracts only after state changes are recorded.
Key Takeaway

Applying CEI reduces reentrancy risk by ensuring callbacks see updated state and cannot repeat effects on stale data.

Example code excerpt
// Checks
require(balances[msg.sender] >= amount);
// Effects
balances[msg.sender] -= amount;
// Interactions
(bool ok, ) = payable(msg.sender).call{value: amount}("");
require(ok);
Misuse to watch for
Updating state in multiple scattered places or calling external hooks before all state changes are applied.
