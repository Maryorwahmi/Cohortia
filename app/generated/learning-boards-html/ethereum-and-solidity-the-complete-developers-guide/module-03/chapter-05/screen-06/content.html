Module 4 › Chapter 3.5 › Reentrancy Guard
Pattern

nonReentrant mutex

Lock a function during execution so callbacks cannot re-enter it and repeat critical effects.

Minimal modifier structure
Check lock is false, set it true, run function code, then set it false on exit. Revert if already locked.
When to use
Apply to functions that update state and make external calls, such as withdrawals or multi-step transfers.
Example modifier
bool private locked;
modifier nonReentrant() {
  require(!locked);
  locked = true;
  _;
  locked = false;
}
Test idea
Attempt the same attack against a guarded function and confirm it reverts with the guard condition.
