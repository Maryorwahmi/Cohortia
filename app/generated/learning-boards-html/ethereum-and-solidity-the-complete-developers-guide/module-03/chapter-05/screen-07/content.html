Integer overflow and underflow

Arithmetic wrap-around used to be a frequent vulnerability; recent compiler behavior changes reduce this risk.

Before Solidity 0.8.0
Overflows silently wrapped values, requiring libraries or checks to prevent exploitation.
Since Solidity 0.8.0
Arithmetic operations revert on overflow/underflow by default, making many issues fail fast.
Caution
Using unchecked blocks for gas savings removes these checks and should only be done after careful analysis and tests of boundary behavior.
Key Takeaway

Prefer default checked arithmetic. Only use unchecked arithmetic where necessary and include boundary tests.
