Proxy pattern: state vs logic

Use a stable proxy to store state and swap implementation contracts that contain business logic.

Proxy contract
Holds storage and delegates all calls. Implementation pointer can be updated to change behavior.
Implementation contract
Contains the logic. Deployed separately and replaceable by changing the proxy's implementation address.
Storage layout caution
Ensure variable ordering remains compatible between versions or use reserved storage gaps to prevent collisions when swapping implementations.
Key Takeaway

Upgradeable proxies enable fixes without migrating user state, but they increase complexity and require strict storage and governance discipline.
