Pausable circuit breaker

Add a paused flag and conditional modifiers to prevent critical functions from running during incidents.

Typical modifiers
whenNotPaused prevents operations during pause; whenPaused allows emergency-only operations.
Governance caution
Control of pause/unpause should be protected by multisig or transparent governance to avoid misuse.
Example
bool public paused;
modifier whenNotPaused() { require(!paused); _; }
function pause() public onlyOwner { paused = true; }
function unpause() public onlyOwner { paused = false; }
Key Takeaway

Pausable controls provide time to respond to incidents but must be governed carefully to avoid centralization risk.
