Deployment checklist
  1. Compile and deploy ArrayUtils (if public/external).
  2. Deploy Marketplace, linking library address if needed.
  3. Call addProduct twice and inspect ProductAdded events.
  4. Call removeProduct and confirm array update and ProductRemoved event.
Automated tests
Write unit tests to assert events, mapping state, and array contents after each operation.
Terminal demo style
Show compilation, deployment transactions, emitted events, and state reads in the console for a clear narrative.
Key Takeaway
Scripted deploy-and-test sequences reveal both correctness and gas patterns, and validate library linkage choices.
