Module 3›Chapter 3.3›Dynamic arrays of structs
When to use arrays
Use arrays for ordered lists and small collections. Remember that on-chain iteration is expensive and can exceed gas limits for large arrays.
Push pattern
activeUsers.push(User(msg.sender, "Bob", 100)); creates and stores the struct in the array.
Best practice
Emit events for new entries and use off-chain indexing for heavy enumeration.
Design pattern
Combine mapping for direct access and an array of keys for enumeration; prefer pagination and off-chain reads to looping on-chain.
Performance note
Avoid full-array loops in functions that run in transactions; they can be exploited or simply revert due to gas limits.
Key Takeaway
Choose arrays for order and mappings for direct reads; use events and off-chain processing for heavy enumeration.
