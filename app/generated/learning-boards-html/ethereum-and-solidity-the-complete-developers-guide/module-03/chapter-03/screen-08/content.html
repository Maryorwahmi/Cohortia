Module 3›Chapter 3.3›Structs & Nested Mappings
Pattern
Use mapping(address => mapping(uint256 => Product)) to give each seller direct access to their products by ID with constant-time lookup.
Mutating storage
Acquire a storage reference like Product storage p = sellerProducts[msg.sender][id]; then set fields to persist changes.
Event guidance
Emit ProductAdded and ProductRemoved events so off-chain indexers can avoid on-chain enumeration when building lists.
Concrete snippet
sellerProducts[msg.sender][productId].name = newName; // ensure this is storage reference mutation
Common mistake
Reading a struct into memory, changing it, and not writing it back will not alter stored state.
Key Takeaway
Nested mappings provide fast direct access to items; combine them with arrays or events for list operations.
