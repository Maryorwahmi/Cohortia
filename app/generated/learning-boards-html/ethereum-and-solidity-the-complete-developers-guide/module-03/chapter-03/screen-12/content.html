Module 3›Chapter 3.3›Add Product Flow
Step-by-step
  1. Increment global nextProductId to get a unique id.
  2. Assign Product storage p = sellerProducts[msg.sender][id]; set fields.
  3. Push id to sellerProductIds[msg.sender] for enumeration.
  4. Emit ProductAdded event for off-chain indexing.
Why events?
Events let off-chain indexers build lists without expensive on-chain enumeration and keep client UIs performant.
Example verification
After addProduct, check sellerProductIds[msg.sender] contains the new id and getProduct returns the populated struct.
Key Takeaway
Keep product storage and enumeration separate: mapping for direct access, array+events for lists.
