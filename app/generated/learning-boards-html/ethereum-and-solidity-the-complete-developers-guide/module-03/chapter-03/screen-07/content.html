Remove helper
Swap the last entry into the deleted index and pop to shrink. Include bounds checks to guard against invalid indices.
// behavior: index check, swap with last, pop
Contains helper
Linear scan to find a value. Suitable for short arrays; consider mapping for large sets.
Example call
After attaching the library with using for, call productIds.remove(index) from Marketplace to update the seller's list.
Misconception
Swap-and-pop preserves element order. It does not; use it only when order is irrelevant or can be reconstructed off-chain.
Key Takeaway
Small, focused library helpers keep your contract logic readable and centralize array operations for reuse.
