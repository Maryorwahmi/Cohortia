Module 3›Chapter 3.3›Using for directive
Pattern
using ArrayUtils for uint256[]; attaches ArrayUtils functions as methods on uint256 arrays, enabling clearer calls like ids.remove(i).
Design note
Helpers that mutate state should accept storage references; read-only helpers can be pure or view.
Concrete example
Attach remove and contains to uint256[] to make sellerProductIds management concise and reusable across contracts.
Code panel
// attach helpers
using ArrayUtils for uint256[];

// call style
productIds.remove(index);
productIds.contains(id);
Pitfall
Using for won't work with library functions that are external-only; prefer internal or public signatures for attachment.
Key Takeaway
Use using for to make code expressive, but ensure helper signatures and storage behavior are correct before attaching.
