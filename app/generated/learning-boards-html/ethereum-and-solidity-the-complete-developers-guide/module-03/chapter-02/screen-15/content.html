Module 3 › Chapter 3.2 › Quick Reference
Interfaces: external only
No state, no constructors, no function bodies. Use for public APIs.
Abstract: virtual + override
Provide shared logic and state. Implement abstract functions in derived contracts to deploy.
Clients: cast addresses
Instantiate an interface with an address to make safe external calls, and handle possible reverts due to implementation rules.
Last thought
Design APIs with interfaces first. Introduce abstract contracts only when you need shared implementation across a controlled family of contracts.
