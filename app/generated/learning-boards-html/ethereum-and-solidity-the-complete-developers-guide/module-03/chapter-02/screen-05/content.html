Module 3 › Chapter 3.2 › Using an Interface
Step-by-step
  1. Declare the interface with the required external signatures.
  2. Instantiate the interface with the deployed address to create a typed reference.
  3. Make calls on the typed reference; the compiler checks signatures and types.
Example scenario
A DataStore client connects to either SimpleDataStore or AdvancedDataStore by passing the implementation address in its constructor. The client calls retrieveData without needing to know internal storage.
Client code pattern
contract DataStoreClient {
    IDataStore public myDataStore;

    constructor(address _dataStoreAddress) {
        myDataStore = IDataStore(_dataStoreAddress);
    }

    function clientStoreData(uint256 _value) public {
        myDataStore.storeData(_value);
    }
}
Pitfall
Interfaces don't protect you from implementation-side reverts or access control. Always consider the implementation's modifiers and expected caller contexts.
