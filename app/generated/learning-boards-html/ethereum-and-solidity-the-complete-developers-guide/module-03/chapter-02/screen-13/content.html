Question 1
Would you use an interface or an abstract contract for a DEX aggregator requiring a swap function?
Answer: Interface
An interface enforces the swap signature without forcing shared state or implementation. It enables plug-and-play compatibility across independently implemented DEXs.
Question 2
Why can't an abstract contract be deployed while a concrete contract can?
Answer: Missing implementations
Abstract contracts contain at least one function without a body, so the compiled bytecode would be incomplete. Only after overriding all abstract functions does a contract become concrete and deployable.
Closing reflection
When you design a public API, start with an interface. Use abstract contracts later to factor shared behavior for related implementations you control.
