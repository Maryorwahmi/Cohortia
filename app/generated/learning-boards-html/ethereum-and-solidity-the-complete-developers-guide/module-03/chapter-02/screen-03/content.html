  • Deploy DataStoreClient with different addresses to confirm interchangeable behavior.
Common Mistake Reminder
Declaring interface functions as public or internal will fail compilation. Interface functions must be external.
Use the client pattern to keep your code modular: the client only needs the interface type, not the implementation details.
