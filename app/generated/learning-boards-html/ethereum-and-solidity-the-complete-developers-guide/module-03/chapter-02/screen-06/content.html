Module 3 › Chapter 3.2 › What is an Abstract Contract?
Capabilities
  • May include state variables and constructors.
  • May provide fully implemented helper functions.
  • Contains at least one unimplemented function marked virtual.
  • Inheritors must override abstract functions or remain abstract.
Usage example
An ERC20Base abstract contract implements most token mechanics but leaves minting rules as an abstract function so derived tokens can control supply behavior.
Abstract snippet
abstract contract BaseToken {
    uint256 internal totalSupply;
    function _mint(address to, uint256 amount) internal virtual;
    function totalSupply() public view returns (uint256) { return totalSupply; }
}
Misconception
Because abstract contracts can contain code, developers sometimes try to deploy them directly. Deployment requires all functions to have concrete implementations in the deployed bytecode.
