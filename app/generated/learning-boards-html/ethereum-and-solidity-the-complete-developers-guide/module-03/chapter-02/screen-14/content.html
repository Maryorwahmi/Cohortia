Module 3 › Chapter 3.2 › Key Concepts
Interface
Defines function and event signatures only. No state or implementations.
Abstract Contract
May include state and partial code. Contains at least one unimplemented function marked virtual.
External Calls
Cast an address to an interface type to call external functions with compile-time checks, but handle reverts in implementations.
Summary
Use interfaces for interoperability and abstract contracts for intentional shared implementations. Clients typed to interfaces increase composability.
