Module 3 › Chapter 3.2 › Choosing a Pattern
Questions to ask
  • Will implementations need to share state or helper code?
  • Are implementations developed by independent teams?
  • Do you need compile-time checks for external calls?
Practical recommendations
  • Use interfaces for public, cross-project APIs.
  • Use abstract contracts for internal families that share logic.
  • Keep interfaces minimal; keep abstract contracts focused.
Reflection prompt
When building a plugin system where unknown third parties will implement features, prefer an interface to maximize flexibility and safety.
