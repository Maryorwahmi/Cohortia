ControlledVault Deployment & Tests
  1. Deploy ControlledVault from Account A.
  2. Assert owner() == Account A.
  3. From Account B call deposit with value and check balances.
  4. From Account B call withdraw and expect revert "Ownable: caller is not the owner".
  5. From Account A call withdraw and confirm transfer works.
  6. Call transferOwnership to Account C and repeat withdrawal checks.
Quick Test Snippet (pseudocode)
// Deploy ControlledVault as A
assert(vault.owner() == A)
// B deposits
vault.deposit({ from: B, value: 1 ether })
assert(vault.balances(B) == 1 ether)
// B withdraw -> expect revert
expectRevert(vault.withdraw(1 ether, { from: B }), "Ownable: caller is not the owner")
// A withdraw -> success
vault.withdraw(1 ether, { from: A })
assert(vault.getContractBalance() == 0)
