Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Implement Single & Multiple Inheritance
Write contracts using the is keyword so children inherit public and internal members. This reduces duplication and centralizes logic like ownership.
Mnemonic: nested boxes
VERIFIED COMPETENCY MILESTONE
02
Use virtual and override for Polymorphism
Mark base functions virtual and implement override in derived contracts. This gives you control over which code executes and lets you call super when needed.
Mnemonic: layered shadows
VERIFIED COMPETENCY MILESTONE
03
Manage Constructor Inheritance
Learn how child constructors delegate to parent constructors and the two accepted patterns for passing arguments to initialize parent state correctly.
Mnemonic: chained keys
VERIFIED COMPETENCY MILESTONE
04
Reason About C3 Linearization
Identify correct listing order for multiple parents and understand how Solidity resolves conflicting function definitions deterministically.
Mnemonic: left-to-right precedence
