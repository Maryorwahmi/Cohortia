Pattern
Use virtual on base, override on child, and call super to compose results.
contract Ownable { function getVersion() public view virtual returns (string memory) { return "Ownable v1"; } }
contract Pausable { function getVersion() public view virtual returns (string memory) { return "Pausable v1"; } }
contract ControlledVault is Ownable, Pausable {
    function getVersion() public view override(Ownable, Pausable) returns (string memory) {
        return string(abi.encodePacked(Ownable.getVersion(), " | Vault"));
    }
}
Check & Misconception
super calls the next implementation in linearization, not necessarily the immediate parent. In multiple inheritance, document the expected order and test the composed output.
Try: Add logging strings in each contract and call getVersion on child to confirm ordering.
