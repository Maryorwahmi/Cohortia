Syntax Steps
Step 1: Declare using is: contract Child is Parent { ... }
Step 2: For multiple parents list them comma-separated: contract C is A, B { ... }
Step 3: Provide parent constructor args either inline or in child's constructor.
Step 4: Test compile errors when arguments are missing and fix order for C3 linearization.
Examples
// Simple single inheritance
contract Parent { uint public x; constructor(uint _x) { x = _x; } }
contract Child is Parent { constructor() Parent(42) {} }

// Multiple parents with inline args
contract A { constructor(uint) {} }
contract B { constructor(address) {} }
contract C is A, B { constructor(uint _a, address _b) A(_a) B(_b) {} }
Check
If compilation fails with missing constructor args, supply them in one of the two forms shown above.
