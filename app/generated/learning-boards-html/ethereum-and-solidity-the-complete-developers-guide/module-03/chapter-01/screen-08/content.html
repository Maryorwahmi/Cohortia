Steps to Override Multiple Bases
  1. Identify all base contracts that implement the function.
  2. Declare the overriding function with override(Base1, Base2).
  3. Optionally call super.functionName() to include parent logic.
  4. Run the compiler and adjust parent order if linearization errors occur.
Misconception: override without listing bases will not compile when multiple parents define the function.
Example
contract BaseA { function foo() public virtual returns (string memory) { return "A"; } }
contract BaseB { function foo() public virtual returns (string memory) { return "B"; } }
contract Derived is BaseA, BaseB {
    function foo() public override(BaseA, BaseB) returns (string memory) {
        // Optionally include parent behavior
        return string(abi.encodePacked(super.foo(), " -> Derived"));
    }
}
Run this and observe which parent's implementation super calls after C3 linearization. Adjust parent order to change linearization where necessary.
