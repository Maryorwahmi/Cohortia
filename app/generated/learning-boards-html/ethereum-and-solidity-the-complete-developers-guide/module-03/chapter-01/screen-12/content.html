Design Guidelines
  • Keep base contracts small and focused (single responsibility).
  • Use explicit visibility for state and helper functions.
  • Prefer forwarding parent constructors from child when values are dynamic.
  • Document parent order and override decisions to aid audits.
Testing Checklist
  1. Assert owner equals deployer after child deployment.
  2. Test onlyOwner reverts when called by non-owner.
  3. Verify overridden functions return expected outputs for each parent order.
  4. Check parent constructor state variables after deployment.
Key Takeaway
Design for clarity, mark virtual/override deliberately, and cover inheritance behaviors with focused tests before production deployment.
