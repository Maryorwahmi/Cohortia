Module 3 › Chapter 3.4 › Variable Packing
Packing illustration
Original struct might spread values across more slots. Reordering groups smaller types into one slot and places large types in separate slots.
// Original
struct UserData {
  uint256 id;
  uint128 lastLogin;
  bool isAdmin;
  uint64 reputation;
}

// Optimized ordering
struct UserData {
  uint64 reputation;
  uint128 lastLogin;
  bool isAdmin;
  uint256 id;
}
Why it saves gas
Fewer storage slots means fewer SSTORE operations when updating packed fields, lowering transaction gas.
Caveat
Packing can be fragile if you later add large types. Re-check compiler layout after changes.
Key Takeaway

Reorder fields to group smaller types. Always validate the compiled storage layout to confirm slot usage.
