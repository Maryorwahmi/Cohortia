Module 3 › Chapter 3.4 › Loop & Short-circuit
Loop optimization checklist
  1. Limit iterations per transaction with pagination or bounded loops.
  2. Copy storage values into memory if accessed repeatedly inside the loop.
  3. Avoid loops over large dynamic arrays stored on-chain; prefer mappings and indices.
Short-circuit tip
Order boolean conditions so cheap checks run first. This prevents expensive function calls when earlier checks already determine the result.
Misconception
Assuming a single loop over a large array is OK. On-chain iteration multiplies storage cost and can run out of gas.
Key Takeaway

Design for bounded work, use memory caches for repeated reads, and leverage short-circuiting to skip expensive checks when possible.
