Module 3 › Chapter 3.4 › Hands-on Activity
Activity steps
  1. Deploy GasOptimizedWallet as owner.
  2. Call deposit with 1 Ether; observe Deposit event and packed balance update.
  3. Call withdraw(0.5 Ether); observe Withdrawal and lastWithdrawalTime change.
  4. Call withdraw(2 Ether); capture InsufficientFunds custom error and its encoded values.
  5. Set active status to false and attempt deposit; observe require revert for inactive wallet.
  6. Optional: swap a string revert for a custom error and compare gas with a profiler.
Assessment prompt
Implement subscription checks using custom errors and explain why assert is inappropriate for those checks.
Expected artifact
A deployed contract, event logs, a gas comparison report, and a short refactor note showing the custom error change.
Key Takeaway

Practical tests and gas measurements are the final proof that your error handling and packing choices produce real savings and clearer failure data.
