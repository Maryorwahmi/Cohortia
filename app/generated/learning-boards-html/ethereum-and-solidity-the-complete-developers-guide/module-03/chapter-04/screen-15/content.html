Module 3 › Chapter 3.4 › Gas Patterns
Events over storage
Emit events for off-chain logs to avoid expensive SSTOREs when contract logic doesn't need the data.
Calldata & Memory
Use calldata for immutable external inputs and memory for temporary mutable work to reduce copying costs.
Pack variables
Group small types to fit multiple values in a single slot and reduce SSTORE frequency and cost.
Final takeaway

Apply one optimization at a time, measure with a profiler, and balance gas savings with clarity and correctness.
