What a custom error looks like
error InsufficientFunds(uint256 available, uint256 requested);

// Usage:
if (balance < amount) { revert InsufficientFunds(balance, amount); }
Custom errors pack a selector and typed arguments. They are especially useful when you need to return numeric context alongside the failure reason.
When to use
Replace long string messages used in require or revert with typed errors when you want to save gas and provide structured data.
Example
In GasOptimizedWallet: revert InsufficientFunds(balance, _amount); returns both values so the UI can display them precisely.
Misconception
Custom errors are not only for clarity; they are primarily a gas optimization over strings.
