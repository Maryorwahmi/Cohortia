Policy Implementation

Creating and Assigning Policies via Azure CLI

Automating policy deployment and assignment.

# 1. Create the policy definition from a JSON file
az policy definition create --name "Deny-Missing-CostCenter-RG-Tag" \
--display-name "Deny Resource Group creation without CostCenter tag" \
--description "Denies creation of RGs missing CostCenter tag" \
--rules "deny-missing-costcenter-tag.json" \
--mode All \
--subscription $SUBSCRIPTION_ID

# Expected Output (truncated):
{
"displayName": "Deny Resource Group creation without CostCenter tag",
"id": "/subscriptions/.../providers/Microsoft.Authorization/policyDefinitions/Deny-Missing-CostCenter-RG-Tag",
"mode": "All",
"name": "Deny-Missing-CostCenter-RG-Tag",
"policyType": "Custom",
"type": "Microsoft.Authorization/policyDefinitions"
}

# 2. Assign the policy to a specific resource group
az policy assignment create --name "Assign-Deny-Missing-CostCenter-RG-Tag" \
--display-name "Deny RG without CostCenter Tag Assignment" \
--scope "/subscriptions/$SUBSCRIPTION_ID/resourceGroups/policy-test-rg" \
--policy "Deny-Missing-CostCenter-RG-Tag" \
--params "{ \"tagName\": { \"value\": \"CostCenter\" } }"

# Expected Output (truncated):
{
"displayName": "Deny RG without CostCenter Tag Assignment",
"id": "/subscriptions/.../providers/Microsoft.Authorization/policyAssignments/Assign-Deny-Missing-CostCenter-RG-Tag",
"name": "Assign-Deny-Missing-CostCenter-RG-Tag",
"scope": "/subscriptions/.../resourceGroups/policy-test-rg",
"type": "Microsoft.Authorization/policyAssignments"
}
Azure CLI Commands
Create Definition

Use az policy definition create to upload your custom JSON policy rule to Azure, specifying its name, description, and mode.

Assign Policy

Use az policy assignment create to apply the defined policy to a specific scope (e.g., resource group, subscription) and pass any required parameters.

Automated Deployment

Automating these steps via CLI ensures consistent and scalable policy implementation across your Azure environment.

Safety Note

Always test custom policies in a development or sandbox environment before deploying them to production to avoid unintended disruptions.

Key Takeaway

Azure CLI provides robust commands for creating and assigning policies, enabling efficient and automated governance at scale.
