Understanding Policy Definitions

JSON-based rules for evaluation and action.

{
  "properties": {
    "displayName": "My Custom Policy",
    "policyType": "Custom",
    "mode": "All", // <-- Defines resource types to evaluate
    "parameters": { // <-- For reusability
      "allowedLocations": {
        "type": "Array"
      }
    },
    "policyRule": { // <-- The core logic
      "if": { // <-- Conditions for evaluation
        "allOf": [
          {
            "field": "location",
            "notIn": "[parameters('allowedLocations')]"
          }
        ]
      },
      "then": { // <-- Effect if conditions are met
        "effect": "Deny"
      }
    }
  }
}
JSON Structure
JSON-Based Rule

A policy definition is a JSON document specifying what to evaluate and the action to take.

Mode Property

Defines which resource types the policy applies to, e.g., 'All' for all resources or 'Indexed' for resources with tags.

Parameters for Reusability

Allows you to define variables (like allowed locations) that can be configured when the policy is assigned, making definitions flexible.

Policy Rule (If/Then)

The core logic: 'if' conditions are met (e.g., resource type and location), 'then' a specific 'effect' is applied (e.g., Deny).

Key Takeaway

Policy Definitions are the blueprints for governance, using JSON to specify conditions and effects for resource compliance.
