Policy Effects

Controlling Resource Behavior with Effects

Monitoring and blocking non-compliant actions.

Audit Effect

Monitor Compliance

Creates a warning event in the activity log without stopping the resource request. Useful for monitoring without blocking deployments.

Example: Audit VMs without managed disks.
Deny Effect

Prevent Non-Compliance

Prevents the resource request from going through. A strong enforcement mechanism for critical security or cost control policies.

Example: Deny public IP creation.
Key Takeaway

'Audit' provides visibility into non-compliance, while 'Deny' actively blocks non-compliant actions, offering different levels of enforcement.
