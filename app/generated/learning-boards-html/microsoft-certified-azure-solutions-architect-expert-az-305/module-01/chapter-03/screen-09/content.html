Policy Effects

Modifying Resources with Modify and Append

Enforcing naming conventions and adding required properties.

Modify Effect

Alter Resource Properties

Modifies a resource or subscription by adding, updating, or removing properties or tags. Useful for enforcing naming conventions or adding required tags.

Example: Add 'CostCenter' tag if missing.
Append Effect

Add Fields to Request

Adds a defined set of fields to the resource request during creation or update. Specifically for injecting new properties.

Example: Ensure specific NSG rules are added.
Key Takeaway

'Modify' and 'Append' effects enable proactive enforcement by altering resource properties or injecting new fields to ensure compliance.
