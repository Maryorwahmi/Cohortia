Core Concept

Understanding Blueprint Artifacts

The building blocks of your environment definitions.

A blueprint definition is composed of various artifacts, each representing a specific component of your desired environment.

  • Resource Groups: Define structured containers for resources.
  • ARM Templates: Deploy and define Azure resources like VMs and databases.
  • Policy Assignments: Enforce governance rules and standards.
  • Role Assignments (RBAC): Manage access control for users and groups.
Key Takeaway

Artifacts are the core components of a blueprint, enabling the definition and deployment of resource groups, infrastructure via ARM templates, governance via policies, and access control via RBAC.

Example Scenario

A blueprint for a secure web application might include a resource group, an ARM template for the App Service and SQL Database, a policy to enforce HTTPS, and an RBAC assignment for the development team.
