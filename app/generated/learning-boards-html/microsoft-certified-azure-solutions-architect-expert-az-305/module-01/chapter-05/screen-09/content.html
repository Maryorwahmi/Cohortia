Blueprint Definition JSON Structure

Examining the components of a blueprint definition file.

Blueprint definitions are JSON files that describe the desired environment configuration.

  • Properties: `displayName`, `description`, `targetScope`.
  • Parameters: Define customizable inputs for flexibility.
  • Resource Groups: Structure the deployment containers.
  • Artifacts: An array defining resource groups, ARM templates, policy assignments, and role assignments.
Key Takeaway

The JSON structure of a blueprint definition precisely outlines its properties, parameters, resource groups, and the specific artifacts to be deployed.

Example Snippet

The `artifacts` array contains objects, each specifying a `kind` (e.g., `policyAssignment`) and its `properties`, including references to policy definitions and parameters.
