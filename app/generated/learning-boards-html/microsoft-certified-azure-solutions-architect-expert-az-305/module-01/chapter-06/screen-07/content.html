Comprehensive Data Collection

Azure Monitor and Log Analytics Workspaces

These services unify audit and diagnostic data, providing a comprehensive view beyond the Activity Log.

  • •Azure Monitor: Overarching service collecting metrics and logs from all Azure resources, other clouds, and on-premises.
  • •Log Analytics Workspaces: Central repository for ingesting, storing, and querying vast amounts of operational data.
  • •Kusto Query Language (KQL): Powerful language used to query and analyze data within Log Analytics.
  • •Unified Platform: Consolidates Activity Log, diagnostic logs (e.g., NSG flow logs, database audit logs), and application logs.
Advanced Auditing

Correlation and Custom Alerting

Routing all relevant logs to Log Analytics enables advanced auditing, correlation of events, and custom alerting based on complex queries.

Concrete Example

By routing network security group flow logs and application logs to Log Analytics, you can correlate a failed login attempt with network traffic patterns, identifying potential intrusion attempts that individual logs might miss.

Key Takeaway

Azure Monitor and Log Analytics provide the foundation for a unified, queryable log platform, essential for deep auditing and security insights.
