Key Concepts

Essential terms for Azure monitoring and auditing

Azure Policy Compliance Dashboard

A centralized view in the Azure portal showing the compliance status of resources against assigned Azure Policies.

Azure Activity Log

A historical record of management plane operations performed on Azure resources, useful for auditing and troubleshooting.

Azure Monitor

A comprehensive monitoring service that collects, analyzes, and acts on telemetry data from your cloud and on-premises environments.

Summary Takeaway

These foundational Azure services provide the essential visibility and control needed to manage compliance and audit activities effectively.
