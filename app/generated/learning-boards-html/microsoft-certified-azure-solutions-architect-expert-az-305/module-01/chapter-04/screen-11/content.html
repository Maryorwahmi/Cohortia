RBAC's Foundation: Azure Active Directory

Unifying identity and resource access management.

Azure AD: The Identity Provider

Azure Active Directory (Azure AD) is Microsoft's cloud-based identity and access management service. It manages all security principals (users, groups, service principals) that can be granted access to Azure resources.

Integration with RBAC

When an RBAC role is assigned, it links an Azure AD identity (the Security Principal) to a set of permissions (the Role Definition) over Azure resources (the Scope). This creates a single control plane for identity and resource access.

Key Takeaway

Azure AD provides the 'who' for RBAC, centralizing identity management and enabling a unified approach to access control across Azure.

Azure AD Roles vs. Azure RBAC Roles

Azure AD Roles

Manage permissions within Azure AD itself (e.g., Global Administrator, User Administrator).

Azure RBAC Roles

Control access to Azure resources (e.g., Contributor, Reader, Virtual Machine Contributor).
