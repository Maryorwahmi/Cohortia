The Three Pillars of Azure RBAC

Understanding Security Principal, Role Definition, and Scope.

1. Security Principal

The 'who' that is being granted access (user, group, service principal, managed identity).

2. Role Definition

The 'what' that defines a collection of permissions (e.g., Contributor, Reader, custom roles).

3. Scope

The 'where' the access applies (Management Group, Subscription, Resource Group, Resource).

Key Takeaway

Every RBAC assignment is a combination of a Security Principal, a Role Definition, and a Scope, forming a clear 'who can do what, where' rule.
