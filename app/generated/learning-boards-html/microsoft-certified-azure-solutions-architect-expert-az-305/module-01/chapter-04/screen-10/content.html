Assigning Roles with Azure CLI

Granting access programmatically.

Why Use Azure CLI for RBAC?

  • Automation: Integrate into scripts and CI/CD pipelines.
  • Consistency: Ensure uniform role assignments across environments.
  • Efficiency: Manage multiple assignments quickly.
  • Auditing: Commands are easily logged and reviewed.

Prerequisites for Assignment

The identity executing the az role assignment create command must have sufficient permissions, such as User Access Administrator or Owner, at the scope where the assignment is being made.

Key Takeaway

Azure CLI is essential for programmatic and scalable RBAC management, enabling automation and consistent application of access policies.

Azure CLI: Assign Contributor Role

# Define variables for clarity
USER_EMAIL="user@contoso.com"
RESOURCE_GROUP_NAME="my-app-resource-group"
ROLE_NAME="Contributor"

# Assign the 'Contributor' role to a user for a specific resource group
az role assignment create --assignee $USER_EMAIL \
                          --role $ROLE_NAME \
                          --resource-group $RESOURCE_GROUP_NAME
