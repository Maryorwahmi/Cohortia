What Can They Do? Built-in Roles

Predefined permissions for common job functions.

Definition: Built-in Role

A predefined collection of permissions provided by Azure that grants specific access to resources. These roles are designed to cover common scenarios and job functions.

Example: Virtual Machine Contributor

This role allows users to create, manage, and delete virtual machines, but it explicitly excludes managing virtual networks or storage accounts, adhering to least privilege for VM administrators.

Key Takeaway

Built-in roles are a convenient starting point for RBAC, but always verify their permissions to ensure they meet least privilege requirements.

Common Built-in Roles

RoleDescription
OwnerFull access to manage all resources, including delegating access.
ContributorManages all resources, but cannot delegate access.
ReaderViews all resources, but cannot make any changes.
User Access AdministratorManages user access to Azure resources.
