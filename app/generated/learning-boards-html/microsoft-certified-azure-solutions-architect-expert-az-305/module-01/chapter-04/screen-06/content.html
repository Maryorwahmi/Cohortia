Who is Accessing Resources? Security Principals

Users, Groups, Service Principals, and Managed Identities.

Definition: Security Principal

An object that represents an entity (user, group, application, or Azure resource) that can request access to Azure resources. These identities are typically managed in Azure Active Directory.

Best Practice: Use Groups

Always prefer assigning RBAC roles to Azure AD groups rather than individual users. This simplifies management, especially as team members join or leave, and reduces the chance of 'privilege creep'.

Key Takeaway

Properly identifying and managing security principals is the first step in establishing effective and scalable access control in Azure.

Types of Security Principals

Users

Individual human identities in Azure AD.

Groups

Collections of users in Azure AD for simplified management.

Service Principals

Identities for applications and automated services.

Managed Identities

Azure-managed identities for Azure resources.
