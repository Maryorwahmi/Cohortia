Where Does Access Apply? Understanding Scope

Management Group, Subscription, Resource Group, and Resource levels.

Definition: Scope

The set of resources to which an access permission applies. Permissions assigned at a higher level in the Azure hierarchy are inherited by all child resources.

Best Practice: Least Scope

Always assign permissions at the lowest possible scope. For example, if a user only needs to manage resources in one resource group, assign the role at that resource group level, not the subscription level.

Key Takeaway

Understanding scope and inheritance is crucial to prevent over-privileging and ensure precise access control in Azure.

Azure Resource Hierarchy & Scope

Management Group

Highest level, applies to multiple subscriptions.

Subscription

Applies to all resource groups and resources within it.

Resource Group

Applies to all resources within that specific group.

Resource

Most granular level, applies to a single resource.
