Deep Dive: Subscriptions & Resource Groups

Organizing resources for billing and lifecycle management

Azure Subscriptions

  • Logical container for Azure resources.
  • Serves as a billing boundary.
  • Used to segment environments (Prod, Dev, Test).
  • Enables management of different cost centers.

Azure Resource Groups

  • Logical container for related Azure resources.
  • Resources share the same lifecycle (deployed, updated, deleted together).
  • Simplifies management of application components.
  • Facilitates consistent policy application at a granular level.
Concrete Example

A 'Production Web App' Resource Group contains the web app service, its SQL database, and an associated storage account, allowing them to be managed as a single unit.

Key Takeaway

Subscriptions define billing and environment boundaries, while Resource Groups logically organize resources for simplified lifecycle management.
