CAF Governance Pillars

Cost Management & Security Baseline

Optimizing spending and enforcing security standards

Cost Management

Ensures cloud spending is optimized and controlled, maximizing value while minimizing unnecessary expenditure.

  • Budgeting and cost allocation.
  • Resource optimization (right-sizing, deletion).
  • Cost tracking and reporting.

Security Baseline

Defines and enforces security standards, ensuring resources are configured securely and vulnerabilities are minimized.

  • Secure configuration enforcement.
  • Access control policies (RBAC).
  • Vulnerability management.
Concrete Example

Implementing Azure Policy to automatically tag resources for cost allocation and enforcing network security group rules to restrict public access to databases.

Key Takeaway

These pillars ensure financial responsibility and a strong security posture, foundational for any successful cloud deployment.
