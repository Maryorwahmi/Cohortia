Key Concepts

Essential terms from this chapter

Cloud Governance

The framework of policies, processes, and tools used to manage, monitor, and control cloud resources for compliance, security, and cost optimization.

Cloud Adoption Framework (CAF)

Microsoft's guidance for organizations to adopt and implement Azure effectively, including a dedicated governance model.

Management Group

A logical container in Azure that allows you to organize subscriptions and apply policies and access control at a level above individual subscriptions.

Summary Takeaway

These core concepts provide the foundational understanding for designing and implementing effective governance strategies in Azure.
