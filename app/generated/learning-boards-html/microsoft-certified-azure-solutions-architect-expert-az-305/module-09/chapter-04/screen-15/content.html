Chapter Summary

Key Concepts

Deepening your understanding of scaling in Azure

Horizontal Pod Autoscaler (HPA)

A Kubernetes feature that automatically scales the number of pods based on observed CPU utilization or custom metrics.

Cluster Autoscaler

A Kubernetes feature that automatically adjusts the number of nodes in your AKS cluster based on the resource requirements of pending pods.

Azure Functions

A serverless compute service that runs event-driven code without managing infrastructure, scaling automatically based on events.

Key Takeaway

HPA scales application instances, Cluster Autoscaler scales underlying VMs in AKS, and Azure Functions provides fully managed, event-driven serverless scaling.
