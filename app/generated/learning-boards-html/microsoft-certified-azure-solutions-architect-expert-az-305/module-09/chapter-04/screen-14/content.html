Chapter Summary

Key Concepts

Essential terms for scalable compute

Virtual Machine Scale Sets (VMSS)

An Azure compute resource for deploying and managing a set of identical, auto-scaling virtual machines.

Auto-Scale Rules

Conditions and actions defined to automatically increase or decrease the number of instances in a VMSS based on metrics or schedules.

Azure Kubernetes Service (AKS)

A managed Kubernetes service for deploying, managing, and scaling containerized applications.

Key Takeaway

VMSS provides auto-scaling for identical VMs, auto-scale rules automate capacity adjustments, and AKS orchestrates containerized applications.
