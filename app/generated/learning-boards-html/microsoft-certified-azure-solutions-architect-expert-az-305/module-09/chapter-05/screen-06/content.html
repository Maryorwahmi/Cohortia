Data Durability

Understanding Intra-Region Redundancy

Protecting data within a single Azure region against various failure scenarios.

Locally-Redundant Storage (LRS)

Data is replicated three times within a single data center. Offers basic protection against hardware failures.

  • Lowest cost option.
  • No protection against datacenter outage.

Zone-Redundant Storage (ZRS)

Data is replicated synchronously across three Azure Availability Zones in the primary region. Provides resilience against data center outages.

  • Protects against datacenter failure.
  • Higher availability for critical workloads.
Key Takeaway

LRS offers basic protection within a single datacenter, while ZRS provides enhanced resilience against datacenter outages by replicating data across multiple Availability Zones in the primary region.
