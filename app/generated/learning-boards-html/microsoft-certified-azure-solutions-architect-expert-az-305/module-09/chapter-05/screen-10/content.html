High scalability, low latency, and multi-model flexibility for modern applications.

Key Features for Scalability

  • Global Distribution: Replicate data across any Azure region with ease.
  • Multi-master Replication: Write data to any region, automatically replicated globally.
  • Throughput Provisioning: Scale Request Units (RUs) independently of storage.
Code Example: Create Cosmos DB Account
RESOURCE_GROUP="myCosmosDBRG"
LOCATION="eastus"
COSMOSDB_ACCOUNT_NAME="mycosmosdbaccount001"

az group create --name $RESOURCE_GROUP --location $LOCATION

az cosmosdb create \
  --name $COSMOSDB_ACCOUNT_NAME \
  --resource-group $RESOURCE_GROUP \
  --locations RegionName=eastus FailoverPriority=0 \
  --locations RegionName=westus FailoverPriority=1 \
  --default-consistency-level Session \
  --kind GlobalDocumentDB
Key Takeaway

Cosmos DB provides a globally distributed, multi-model NoSQL database with multi-master replication and independent throughput scaling, essential for low-latency, high-availability applications.
