Implementing Geo-Redundant Storage

Ensuring data availability and disaster recovery across geographically distant Azure regions.

Geo-Redundant Storage (GRS)

Data replicated three times in the primary region (LRS) and asynchronously to a secondary, distant Azure region. Provides regional disaster recovery.

  • Protects against regional outages.
  • No direct read access to secondary region.

Read-Access Geo-Redundant Storage (RA-GRS)

Similar to GRS, but also provides read access to the data in the secondary region. Enables read-only access during a primary region outage.

  • Read-only access to secondary region.
  • Higher availability for read-heavy apps.
Key Takeaway

GRS provides regional disaster recovery, while RA-GRS extends this by allowing read access to the secondary region, crucial for maintaining application availability during primary region outages.
