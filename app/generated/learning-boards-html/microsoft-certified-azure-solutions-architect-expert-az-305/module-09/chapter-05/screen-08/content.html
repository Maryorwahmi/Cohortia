Achieving Maximum Data Resilience with GZRS

Combining zone-redundancy with geo-disaster recovery for unparalleled data protection.

GZRS Replication Flow

Primary Region (ZRS)

Data replicated across 3 Availability Zones

Secondary Region (GRS)

Asynchronous replication to distant region

GZRS combines the best of ZRS and GRS for maximum resilience.

Key Features of GZRS

  • Zone-level protection: Resilient against datacenter failures in the primary region.
  • Regional disaster recovery: Protects against entire region outages.
  • RA-GZRS option: Provides read access to the secondary region.
Code Example: Create GZRS Storage Account
RESOURCE_GROUP="myScalableStorageRG"
LOCATION="eastus2" # GZRS supported region
STORAGE_ACCOUNT_NAME="mystorageaccountgzrs001"

az group create --name $RESOURCE_GROUP --location $LOCATION

az storage account create \
  --name $STORAGE_ACCOUNT_NAME \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION \
  --sku Standard_GZRS \
  --kind StorageV2 \
  --allow-blob-public-access false
Key Takeaway

GZRS provides the highest level of data resilience by combining synchronous zone-redundancy in the primary region with asynchronous geo-replication to a secondary region.
