Creating a Private Endpoint for Azure Storage (Part 1)

Setting up private access to an Azure Storage Account.

Private Endpoint Parameters

  • 1. Resource Group & Name: Standard Azure resource identification.
  • 2. VNet & Subnet: The network where the private endpoint will reside.
  • 3. Private Connection Resource ID: The target PaaS service's resource ID (e.g., Storage Account).
  • 4. Group ID: Specifies the sub-resource of the PaaS service (e.g., 'blob' for Storage Account blob service).
Important Note

Ensure your Storage Account is configured to deny public access to fully leverage the security benefits of Private Link.

Azure CLI: Create Private Endpoint 

# Example: Create a Private Endpoint for an Azure Storage Account (conceptual)
# Assumes you have a Storage Account and a VNet/Subnet already created.
RESOURCE_GROUP="myNetworkingRG"
LOCATION="eastus"
STORAGE_ACCOUNT_NAME="mystorageaccount123"
VNET_NAME="VNet1"
SUBNET_NAME="Subnet1"
PRIVATE_ENDPOINT_NAME="myStoragePrivateEndpoint"

# Create a private endpoint
az network private-endpoint create \
  --resource-group $RESOURCE_GROUP \
  --name $PRIVATE_ENDPOINT_NAME \
  --location $LOCATION \
  --vnet-name $VNET_NAME \
  --subnet $SUBNET_NAME \
  --private-connection-resource-id $(az storage account show -g $RESOURCE_GROUP -n $STORAGE_ACCOUNT_NAME --query id -o tsv) \
  --group-id blob \
  --connection-name "myStorageConnection"
