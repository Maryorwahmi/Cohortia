Azure Network Watcher: Monitoring and Troubleshooting

Gain insights and diagnose issues across your Azure network.

Key Capabilities

  • Connection Monitor: Proactively checks connectivity and latency between endpoints.
  • NSG Flow Logs: Captures detailed information about traffic through Network Security Groups.
  • Packet Capture: Allows for deep analysis of network traffic.
Pro-Tip

Enable Network Watcher features proactively to gain historical data and quickly diagnose issues when they arise, rather than reactively.
