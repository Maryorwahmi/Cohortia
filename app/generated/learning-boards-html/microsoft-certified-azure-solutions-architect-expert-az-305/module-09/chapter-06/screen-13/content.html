Network Access Control

Network Security Groups (NSGs) and Application Security Groups (ASGs)

Scalable and granular network access control for Azure resources.

Key Differences & Benefits

  • NSGs: Filter traffic based on IP, port, and protocol. Applied to subnets or network interfaces.
  • ASGs: Group VMs by application workload. NSG rules refer to ASGs, simplifying management.
  • Scalability: ASGs allow rules to scale with your application, not individual VMs.
Common Mistake

Ignoring NSG default rules. Always be aware of implicit deny rules and explicitly allow necessary traffic for your applications.
