Building an Event-Driven Workflow
Azure Event Grid and Azure Function Integration

This lab demonstrates a practical event-driven workflow. We'll use Azure CLI to create an Event Grid custom topic and an Azure Function that subscribes to it.

By publishing a test event and observing the function's execution, you'll see firsthand how Event Grid enables decoupled, reactive communication between services.

Key Takeaway

Integrating Event Grid with Azure Functions provides a scalable and efficient way to build reactive, event-driven microservices.

Lab Steps Overview
  1. Create Azure Resource Group.
  2. Create Event Grid Custom Topic.
  3. Create Azure Function App.
  4. Deploy Event Grid Trigger Function.
  5. Create Event Grid Subscription for the Function.
  6. Publish a Test Event via Azure CLI.
  7. Verify Function Execution in Azure Portal.
