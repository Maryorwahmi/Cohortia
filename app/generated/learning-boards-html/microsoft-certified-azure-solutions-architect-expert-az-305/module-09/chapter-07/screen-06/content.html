Implementing Cache-Aside with Redis

Retrieving and Storing Data Efficiently

using StackExchange.Redis;
using System;
using System.Threading.Tasks;

public class RedisCacheService
{
    private readonly ConnectionMultiplexer _redis;
    private readonly IDatabase _db;

    public RedisCacheService(string connectionString)
    {
        _redis = ConnectionMultiplexer.Connect(connectionString);
        _db = _redis.GetDatabase();
    }

    public async Task<string> GetOrSetDataAsync(
        string key, Func<Task<string>> dataFetcher, TimeSpan expiry)
    {
        // Try to get data from cache
        string cachedData = await _db.StringGetAsync(key);

        if (cachedData != null)
        {
            Console.WriteLine($"Data retrieved from cache for key: {key}");
            return cachedData;
        }

        // Data not in cache, fetch from source (e.g., database)
        Console.WriteLine($"Data not in cache, fetching from source for key: {key}");
        string liveData = await dataFetcher();

        // Store data in cache with expiry
        await _db.StringSetAsync(key, liveData, expiry);
        Console.WriteLine($"Data stored in cache for key: {key} with expiry {expiry}");

        return liveData;
    }

    public async Task RemoveDataAsync(string key)
    {
        await _db.KeyDeleteAsync(key);
        Console.WriteLine($"Data removed from cache for key: {key}");
    }
}

Cache-Aside Pattern

The application first checks the cache. If data is not found (cache miss), it retrieves it from the data source, stores it in the cache, and then returns it.

Key Code Highlights

  • ConnectionMultiplexer.Connect: Establishes connection to Azure Cache for Redis.
  • _db.StringGetAsync(key): Attempts to retrieve data from the cache.
  • dataFetcher(): Invoked only on a cache miss to get fresh data.
  • _db.StringSetAsync(key, liveData, expiry): Stores newly fetched data in cache with a Time-to-Live.
Key Takeaway

The GetOrSetDataAsync method effectively implements the Cache-Aside pattern, ensuring data is retrieved from the fastest available source and cached for future efficiency.
