Core Component

Update Domains (UDs)

Update Domains are logical groups of VMs that can be rebooted at the same time during planned Azure maintenance. They ensure that not all VMs are offline simultaneously.

Purpose

Minimizes application downtime during planned Azure platform maintenance events.

Staggered Updates

Azure updates one update domain at a time, ensuring other VMs remain available.

Configuration

Typically 5 UDs per AS, configurable up to 20, to control maintenance impact.

Key Takeaway

Update Domains enable staggered maintenance, ensuring that a portion of your application remains available during planned Azure updates.
