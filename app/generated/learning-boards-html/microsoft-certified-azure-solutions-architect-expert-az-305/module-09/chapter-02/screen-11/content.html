Core Component

Fault Domains (FDs)

Fault Domains represent isolated groups of hardware within an Azure data center, sharing common power sources and network switches. They protect VMs from localized hardware failures.

Isolation Scope

Protects against failures of shared hardware components like power, cooling, and network switches.

Distribution

Azure typically assigns 2 or 3 fault domains per Availability Set to distribute VMs.

Benefit

Ensures that a single hardware failure does not impact all VMs within an Availability Set.

Key Takeaway

Fault Domains ensure that VMs within an Availability Set are physically isolated to prevent a single point of failure from impacting all instances.
