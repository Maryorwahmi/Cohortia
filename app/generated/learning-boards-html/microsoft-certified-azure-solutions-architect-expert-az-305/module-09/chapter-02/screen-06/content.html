Architecture Pattern

Leveraging AZs for Virtual Machines

To maximize resilience, deploy multiple instances of your Virtual Machines across different Availability Zones within an Azure region. This distributes your application across physically isolated data centers.

Key Principle

Distribute VM instances across 2 or 3 AZs for redundancy.

Load Balancer Role

An Azure Load Balancer distributes traffic across healthy VM instances in different zones.

Benefit

Ensures application remains accessible even if an entire Availability Zone goes offline.
