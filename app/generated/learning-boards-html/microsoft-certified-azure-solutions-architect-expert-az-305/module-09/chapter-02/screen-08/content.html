Deploying a VM into an Availability Zone (Part 1)

This section demonstrates how to prepare your Azure environment and deploy a public IP address into a specific Availability Zone using Azure CLI.

Step 1: Login & Region

Ensure you are logged in (`az login`) and set a region that supports AZs.

Step 2: Resource Group

Create a resource group to contain all your HA resources.

Step 3: Public IP

Create a Standard SKU public IP and deploy it into a specific Availability Zone.

Azure CLI Commands
# Ensure you have logged in to Azure: az login
# Set your desired region that supports Availability Zones, e.g., 'eastus2'
REGION="eastus2"
RESOURCE_GROUP="myHAResourceGroup"
VM_NAME="myHAWebAppVM"

# Create a resource group if it doesn't exist
az group create --name $RESOURCE_GROUP --location $REGION

# Create a public IP address for the VM
az network public-ip create \
  --resource-group $RESOURCE_GROUP \
  --name ${VM_NAME}PublicIP \
  --sku Standard \
  --zone 1 # Deploy public IP into Zone 1 for zone-redundancy
Key Takeaway

A Standard SKU public IP deployed to a specific zone is crucial for enabling zone-redundancy for your VMs and associated resources.
