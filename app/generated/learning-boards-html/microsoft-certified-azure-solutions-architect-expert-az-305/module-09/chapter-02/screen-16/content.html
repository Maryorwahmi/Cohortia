Essential Concepts for HA Design

Recap of Core Azure High Availability Features

Azure Availability Zone (AZ)

A physically separate data center within an Azure region, providing protection against data center-level failures.

Azure Availability Set (AS)

A logical grouping of VMs within a single data center to provide fault tolerance and protect against hardware failures or planned maintenance.

Fault Domain (FD)

A group of VMs that share common power and network switches within an Availability Set, isolating them from hardware failures.

Summary Takeaway

Azure's Availability Zones and Availability Sets, along with Fault Domains, are fundamental for building resilient cloud architectures.
