Defining an Availability Set with ARM Template

This ARM template snippet demonstrates how to define an Azure Availability Set, configuring its Fault Domain and Update Domain counts for automated deployment.

Fault Domain Count

`platformFaultDomainCount` specifies the number of physical fault domains (2 or 3).

Update Domain Count

`platformUpdateDomainCount` specifies the number of logical update domains (5 to 20).

SKU for Managed Disks

Use `"name": "Aligned"` for compatibility with Azure Managed Disks.

ARM Template Snippet
{
  "$schema": "https://schema.management.azure.com/schemas/2019-04-01/deploymentTemplate.json#",
  "contentVersion": "1.0.0.0",
  "parameters": {
    "availabilitySetName": {
      "type": "string",
      "metadata": {
        "description": "Name of the Availability Set."
      }
    },
    "location": {
      "type": "string",
      "defaultValue": "[resourceGroup().location]",
      "metadata": {
        "description": "Location for the Availability Set."
      }
    }
  },
  "resources": [
    {
      "type": "Microsoft.Compute/availabilitySets",
      "apiVersion": "2021-07-01",
      "name": "[parameters('availabilitySetName')]",
      "location": "[parameters('location')]",
      "properties": {
        "platformFaultDomainCount": 2,  // Number of fault domains (2 or 3)
        "platformUpdateDomainCount": 5 // Number of update domains (5 to 20)
      },
      "sku": {
        "name": "Aligned" // Use 'Aligned' for managed disks, 'Classic' for unmanaged
      }
    }
  ],
  "outputs": {
    "availabilitySetId": {
      "type": "string",
      "value": "[resourceId('Microsoft.Compute/availabilitySets', parameters('availabilitySetName'))]"
    }
  }
}
Key Takeaway

ARM templates provide a declarative and repeatable way to define Availability Sets, ensuring consistent HA configuration for your VM deployments.
