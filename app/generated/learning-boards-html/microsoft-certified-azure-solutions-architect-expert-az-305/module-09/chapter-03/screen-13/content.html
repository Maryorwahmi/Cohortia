Key Concepts

Essential Terms to Remember

Azure Load Balancer

Layer 4 (transport) load balancer for distributing traffic within a single Azure Virtual Network to VMs or VMSS.

Azure Application Gateway

Layer 7 (application) load balancer for web applications, offering WAF, SSL termination, and URL-based routing within a single region.

Azure Front Door

Global Layer 7 load balancer for web applications, providing WAF, CDN, global routing, and multi-region failover capabilities.

Summary Takeaway

Azure offers a spectrum of load balancing services, from regional Layer 4 distribution to global Layer 7 web acceleration, each tailored for specific architectural needs.
