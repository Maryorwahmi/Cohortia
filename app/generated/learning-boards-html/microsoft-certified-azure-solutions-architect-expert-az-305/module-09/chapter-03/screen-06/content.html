# Example: Create an Azure Standard Load Balancer with a public IP
RESOURCE_GROUP="myLBResourceGroup"
LOCATION="eastus"
LB_NAME="myStandardLB"
PUBLIC_IP_NAME="myLBPublicIP"
FRONTEND_IP_CONFIG_NAME="myFrontendIP"
BACKEND_POOL_NAME="myBackendPool"

az group create --name $RESOURCE_GROUP --location $LOCATION

az network public-ip create \
  --resource-group $RESOURCE_GROUP \
  --name $PUBLIC_IP_NAME \
  --sku Standard \
  --allocation-method Static \
  --zone 1 # For zone-redundancy, if desired

az network lb create \
  --resource-group $RESOURCE_GROUP \
  --name $LB_NAME \
  --sku Standard \
  --frontend-ip-name $FRONTEND_IP_CONFIG_NAME \
  --public-ip-address $PUBLIC_IP_NAME \
  --backend-pool-name $BACKEND_POOL_NAME

# Create a health probe (e.g., HTTP on port 80)
az network lb probe create \
  --resource-group $RESOURCE_GROUP \
  --lb-name $LB_NAME \
  --name "httpProbe" \
  --protocol Http \
  --port 80 \
  --interval 5 \
  --threshold 2

# Create a load balancing rule
az network lb rule create \
  --resource-group $RESOURCE_GROUP \
  --lb-name $LB_NAME \
  --name "httpRule" \
  --protocol Tcp \
  --frontend-port 80 \
  --backend-port 80 \
  --frontend-ip-name $FRONTEND_IP_CONFIG_NAME \
  --backend-pool-name $BACKEND_POOL_NAME \
  --probe "httpProbe" \
  --disable-outbound-snat true # Recommended for Standard LB
Step 1: Resource Group & Public IP

Create a resource group and a Standard SKU public IP for external access and zone redundancy.

Step 2: Create Load Balancer

Deploy the Standard Load Balancer, linking it to the public IP and defining frontend/backend configurations.

Step 3: Health Probe

Configure an HTTP health probe to monitor backend instance availability and ensure traffic is only sent to healthy servers.

Step 4: Load Balancing Rule

Define the rule to map frontend traffic to the backend pool, incorporating the health probe and disabling outbound SNAT for Standard LB.

Key Takeaway

Properly configuring a Standard Azure Load Balancer with health probes and rules is fundamental for resilient Layer 4 traffic distribution.
