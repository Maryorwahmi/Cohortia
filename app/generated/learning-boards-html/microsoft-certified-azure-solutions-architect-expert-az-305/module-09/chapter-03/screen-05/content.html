Azure Load Balancer: Transport Layer Distribution

High-Performance Traffic Management within a Virtual Network

Layer 4 Operation

Distributes TCP/UDP traffic based on IP address and port. Ideal for non-HTTP/HTTPS workloads.

Within a VNet

Distributes traffic to VMs or VM Scale Sets within the same Azure Virtual Network.

Standard SKU

Recommended for production; offers zone redundancy, high availability, and Availability Zone integration.

Health Probes

Monitors backend instance health, ensuring traffic is only sent to healthy resources for continuous availability.

Common Misconception

Azure Load Balancer does not inspect HTTP headers or URLs; it's a 'dumb' packet forwarder. For application-level routing, you need Layer 7 services.

Scenario Example

You have a backend API service running on three VMs within a VNet. Azure Load Balancer distributes incoming API requests evenly. If one VM fails, the Load Balancer automatically detects it and redirects traffic to the two healthy instances, ensuring continuous API availability.

Key Takeaway

Azure Load Balancer is essential for internal, high-performance Layer 4 traffic distribution, critical for microservices and backend applications within a VNet.
