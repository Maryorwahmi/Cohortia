Spot Instances for Fault-Tolerant Workloads

Deep discounts for interruptible compute capacity

What are Azure Spot VMs?

Spot Virtual Machines allow you to utilize unused Azure compute capacity at significantly reduced prices. The trade-off is that Azure can reclaim this capacity with short notice, leading to VM eviction.

Pricing: Deep discounts compared to pay-as-you-go rates.

Interruption: VMs can be evicted when Azure needs the capacity.

Ideal Workloads for Spot VMs

Spot VMs are best suited for fault-tolerant workloads that can gracefully handle interruptions and resume processing. This makes them excellent for non-critical, flexible compute needs.

Use Cases: Batch processing, data analytics, rendering, dev/test environments.

Example: A large-scale image processing job that can checkpoint progress.

Key Takeaway

Identify fault-tolerant workloads to leverage Spot VMs, significantly reducing compute costs without impacting overall job completion.
