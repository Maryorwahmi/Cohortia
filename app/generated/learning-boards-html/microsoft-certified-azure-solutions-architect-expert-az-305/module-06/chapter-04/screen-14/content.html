Data Operations

Performing Basic Data Operations (CRUD) with CLI

Interacting with Cosmos DB using Azure CLI

# Create a container with a partition key
az cosmosdb sql container create \
    --resource-group MyCosmosDbRG \
    --account-name mycosmosdbaccount123 \
    --database-name MyDatabase \
    --name Products \
    --partition-key-path /category \
    --throughput 400

# Insert a document
az cosmosdb sql item create \
    --resource-group MyCosmosDbRG \
    --account-name mycosmosdbaccount123 \
    --database-name MyDatabase \
    --container-name Products \
    --partition-key "Electronics" \
    --body '{ "id": "product1", "name": "Laptop", "price": 1200, "category": "Electronics" }'

# Read a document by ID and Partition Key
az cosmosdb sql item show \
    --resource-group MyCosmosDbRG \
    --account-name mycosmosdbaccount123 \
    --database-name MyDatabase \
    --container-name Products \
    --id product1 \
    --partition-key "Electronics"

# Update a document
az cosmosdb sql item replace \
    --resource-group MyCosmosDbRG \
    --account-name mycosmosdbaccount123 \
    --database-name MyDatabase \
    --container-name Products \
    --id product1 \
    --partition-key "Electronics" \
    --body '{ "id": "product1", "name": "Gaming Laptop", "price": 1500, "category": "Electronics", "stock": 50 }'

# Delete a document
az cosmosdb sql item delete \
    --resource-group MyCosmosDbRG \
    --account-name mycosmosdbaccount123 \
    --database-name MyDatabase \
    --container-name Products \
    --id product2 \
    --partition-key "Books"
Key Takeaway

The Azure CLI enables direct execution of CRUD operations on Cosmos DB documents, with the partition key being essential for targeting specific data and optimizing requests.

Pro-Tip: Point Reads

Retrieving a document by its ID and partition key (a 'point read') is the most efficient operation in Cosmos DB, consuming minimal RUs.

Why it Matters: Automation

Using the Azure CLI for CRUD operations is excellent for scripting administrative tasks, automating deployments, and quick debugging without writing application code.
