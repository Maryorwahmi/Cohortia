Consistency Deep Dive

Session and Consistent Prefix Consistency

Client-centric and ordered guarantees

Session Consistency

Guarantees monotonic reads, monotonic writes, read-your-writes, and write-follows-reads within a single client session.

  • Most common for single-client apps
  • High availability, low latency

Consistent Prefix

Guarantees that reads will never see out-of-order writes. If writes are A, B, C, a reader sees A, A,B, or A,B,C.

  • Order of writes preserved
  • Can tolerate some staleness
Key Takeaway

Session consistency provides strong guarantees for an individual user's interaction, while Consistent Prefix ensures the order of writes is always preserved, even if data is slightly stale.

Example: User Profile Updates

When a user updates their profile, Session consistency ensures they immediately see their changes, even if other users might see the old profile for a brief moment.

Use Case: IoT Telemetry Streams

Consistent Prefix is suitable for IoT telemetry where the sequence of sensor readings is crucial, but a small delay in processing is acceptable.
