Chapter Summary

Key Concepts: Core (SQL) API Fundamentals

Essential terms for Cosmos DB mastery

Azure Cosmos DB

Microsoft's globally distributed, multi-model database service, offering high availability and low-latency access.

Core (SQL) API

The native API for Cosmos DB, using a flexible JSON document model and SQL-like query language.

Request Unit (RU)

A performance currency that abstracts the system resources required to perform database operations.

Mastering these core concepts is essential for designing efficient and scalable data solutions with Azure Cosmos DB.
