Decision Framework

Scalability and Throughput

Matching Performance Needs to Azure Non-Relational Services

Massive Scale Requirements

  • Petabytes of Data: Designed for extremely large data volumes.
  • Millions of Ops/sec: Handles incredibly high transaction rates.
  • Global Distribution: Supports data replication across regions.
Suitable Services
  • Azure Cosmos DB
  • Azure Data Lake Storage Gen2
  • Azure Blob Storage

High Scale Requirements

  • Terabytes of Data: Supports significant data volumes.
  • Thousands of Ops/sec: Handles substantial transaction rates.
  • Regional Availability: Typically deployed within a single region.
Suitable Services
  • Azure Table Storage
  • Azure Cache for Redis
Key Takeaway

Accurately assessing your application's scalability and throughput needs is vital to select the most appropriate Azure non-relational service, preventing both over-provisioning and performance bottlenecks.
