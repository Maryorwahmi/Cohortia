Decision Framework

Choosing by Data Model

Matching Data Structures to Non-Relational Stores

Document (JSON)

Flexible, semi-structured data, often denormalized.

Azure Services
  • Azure Cosmos DB (Core SQL, MongoDB API)

Key-Value

Simple lookups by key, high throughput.

Azure Services
  • Azure Table Storage
  • Azure Cosmos DB (Table API)
  • Azure Cache for Redis

Column-Family

High-throughput writes, time-series, wide-column data.

Azure Services
  • Azure Cosmos DB (Cassandra API)

Graph

Highly connected data, relationship traversals.

Azure Services
  • Azure Cosmos DB (Gremlin API)

Object/File

Unstructured blobs, large files, data lakes.

Azure Services
  • Azure Blob Storage
  • Azure Data Lake Storage Gen2
Key Takeaway

Aligning your application's data model with the native capabilities of Azure's non-relational services is the foundational step for efficient and performant data storage.
