Primary Key

Row Key: Unique ID within a Partition

The Row Key uniquely identifies an entity within its specific partition, completing the primary key.

  • •Uniqueness: Must be unique within a given Partition Key.
  • •Sorting: Entities are sorted by Row Key within a partition.
  • •Range Queries: Enables efficient retrieval of a range of entities within a single partition.
Key Takeaway

Design Row Keys to support your most frequent lookup and range query patterns for optimal performance.

Example Scenario

Sensor Data Retrieval

Storing sensor readings where you need to query by device and time.

Design Choice

  • •Partition Key: DeviceID (e.g., "Sensor001")
  • •Row Key: Timestamp (e.g., "202310271000")

Query Benefit

To retrieve all readings for "Sensor001" between 10:00 and 10:30, you can query PartitionKey = "Sensor001" and RowKey ge "202310271000" and RowKey lt "202310271030". This is highly efficient as it's a single-partition range scan.

Important Note

Row Keys are case-sensitive and sorted lexicographically, so ensure consistent formatting for timestamps or sequential IDs.
