Querying Data with Azure CLI

Retrieve entities using Partition Key and Row Key filters.

# Query entities for a specific device (PartitionKey)az storage entity query 
    --table-name SensorData 
    --partition-key DeviceA 
    --account-name $STORAGE_ACCOUNT_NAME 
    --account-key $STORAGE_KEY 
    --output table# Query entities for a specific device and a range of timestamps (RowKey)# Note: RowKey filtering is done using OData filter syntaxaz storage entity query 
    --table-name SensorData 
    --partition-key DeviceA 
    --filter "RowKey ge '202310271000' and RowKey lt '202310271006'" 
    --account-name $STORAGE_ACCOUNT_NAME 
    --account-key $STORAGE_KEY 
    --output table
Explanation

Understanding Query Operations

  • •az storage entity query: This is the primary command for retrieving entities.
  • •--partition-key: Specifying the Partition Key directs the query to a single partition, making it highly efficient.
  • •--filter: This parameter allows you to apply OData filter syntax to refine your query. It's crucial for filtering on Row Key ranges or other properties.
  • •OData Filter Syntax: Use operators like ge (greater than or equal), lt (less than), eq (equal), etc., for powerful filtering.
  • •--output table: Formats the output for readability in the terminal.
Important Note

Queries on non-key properties without a Partition Key can be slow as they may require scanning multiple partitions or the entire table.
