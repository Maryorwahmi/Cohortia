Append & Page Blobs: Specialized Storage
Optimizing for Logging and Random Read/Write Operations
Append Blobs
  • Optimized for append operations.
  • New blocks are added to the end of the blob.
  • Ideal for logging data, audit trails, and IoT telemetry.
  • Existing blocks cannot be modified or deleted.
Page Blobs
  • Optimized for random read/write operations.
  • Allows byte-range writes to modify specific parts.
  • Primarily used for Virtual Hard Drive (VHD) files for Azure VMs.
  • Fixed-size up to 8 TB.
Key Takeaway

Choose append blobs for sequential logging and page blobs for random access, especially for Azure VM disks, to match your data access patterns.

Common MistakeUsing wrong type for workload
Scenario: IoT Device Telemetry

An IoT solution collects sensor data every few seconds. Storing this data in an append blob is ideal, as new readings are continuously added to the end of the file, creating a chronological log.
