Shared Access Signatures (SAS)
Delegated, Time-Bound Access to Blob Storage Resources
What is a SAS?

A Shared Access Signature (SAS) is a URI that grants restricted access rights to Azure Storage resources. It allows you to grant temporary, granular access to clients without sharing your storage account keys.

SAS Control Parameters
  • Permissions: Read, Write, Delete, List.
  • Services: Blob, Queue, Table, File.
  • Resource Types: Service, Container, Object.
  • Validity Period: Start and expiry times.
Key Takeaway

SAS tokens are essential for securely granting limited, temporary access to Blob Storage resources for external clients or applications, avoiding exposure of master keys.

Resource URI

Scenario: User Uploads

A web application allows users to upload profile pictures. The backend generates a short-lived SAS token with write permissions to a specific container, which the client-side code uses to upload the image directly to Blob Storage.
