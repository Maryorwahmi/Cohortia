Key Concepts: Part 2
Access Tiers and Security Mechanisms
Hot Access Tier

For frequently accessed data; higher storage costs, lower access costs.

Shared Access Signature (SAS)

A URI that grants restricted access rights to Azure Storage resources for a specified period.

Azure Role-Based Access Control (RBAC)

A system for managing who has access to Azure resources and what they can do with them.

Summary Takeaway

Effective Blob Storage design balances cost optimization through access tiers (Hot, Cool, Archive) with robust security using SAS for delegated access and RBAC for internal control.
