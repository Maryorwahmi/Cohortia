Blob Access Tiers: Hot, Cool, and Archive
Balancing Cost and Data Access Frequency
Overview of Access Tiers

Azure offers three tiers (Hot, Cool, Archive) to optimize storage costs based on how frequently data is accessed. Each tier has different pricing for storage and data access.

Hot Access Tier Details
  • Cost: Highest storage costs, lowest access costs.
  • Latency: Immediate access.
  • Use Cases: Actively used data, current website content, frequently accessed documents, application data.
Key Takeaway

Selecting the correct access tier is crucial for cost optimization; Hot tier is for frequently accessed data with immediate availability and lower access costs.

Access Tier Spectrum
Hot Tier
(Frequent Access)
Cool Tier
(Infrequent Access)
Archive Tier
(Rare Access)
Common Mistake: Cost Misalignment

Storing rarely accessed data in the Hot tier leads to unnecessarily high storage costs. Always match your data's access frequency to the appropriate tier.
