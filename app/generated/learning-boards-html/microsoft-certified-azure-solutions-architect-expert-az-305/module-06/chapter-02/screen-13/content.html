Basic Blob Operations with Azure CLI
Creating, Uploading, and Managing Blobs Programmatically
Azure CLI Commands Overview
  • `az group create`: Create a resource group.
  • `az storage account create`: Provision a new storage account.
  • `az storage container create`: Create a container within the storage account.
  • `az storage blob upload`: Upload a file as a blob.
  • `az storage blob download`: Download a blob to a local file.
  • `az storage blob list`: List blobs in a container.
Important Note on Security

For production applications, avoid using storage account keys directly. Prefer Shared Access Signatures (SAS) for delegated client access or Azure RBAC for internal service access.

Key Takeaway

The Azure CLI provides essential commands for programmatic management of Blob Storage, from account creation to blob manipulation, crucial for automation.

# Create a resource groupaz group create --name MyBlobResourceGroup --location eastus# Create a storage account (globally unique name)az storage account create \--name myuniqueblobstorage001 \--resource-group MyBlobResourceGroup \--location eastus \--sku Standard_LRS \--kind StorageV2# Get the connection string (for demo purposes)STORAGE_ACCOUNT_NAME="myuniqueblobstorage001"STORAGE_KEY=$(az storage account keys list \--resource-group MyBlobResourceGroup \--account-name $STORAGE_ACCOUNT_NAME \--query "[0].value" --output tsv)# Create a containeraz storage container create \--name mycontainer \--account-name $STORAGE_ACCOUNT_NAME \--account-key $STORAGE_KEY \--public-access blob # Or Off for private# Upload a fileecho "Hello, Azure Blob!" > hello.txtaz storage blob upload \--container-name mycontainer \--file hello.txt \--name hello.txt \--account-name $STORAGE_ACCOUNT_NAME \--account-key $STORAGE_KEY# Download a fileaz storage blob download \--container-name mycontainer \--name hello.txt \--file downloaded_hello.txt \--account-name $STORAGE_ACCOUNT_NAME \--account-key $STORAGE_KEY# List blobsaz storage blob list \--container-name mycontainer \--output table \--account-name $STORAGE_ACCOUNT_NAME \--account-key $STORAGE_KEY
