Connecting to Cosmos DB MongoDB API

Setting up a Node.js application and inserting data.

const { MongoClient } = require('mongodb');

async function run() {
    // Replace with your Cosmos DB MongoDB connection string
    const uri = "mongodb://yourcosmosdbaccount:YOUR_PRIMARY_KEY@yourcosmosdbaccount.mongo.cosmos.azure.com:10255/?ssl=true&replicaSet=globaldb&retrywrites=false&maxIdleTimeMS=120000&appName=@yourcosmosdbaccount@";
    const client = new MongoClient(uri);

    try {
        await client.connect();
        const database = client.db("productsdb");
        const collection = database.collection("products");

        // Insert a document
        const doc = { name: "Smart TV", category: "Electronics", price: 899.99 };
        const result = await collection.insertOne(doc);
        console.log(`A document was inserted with the _id: ${result.insertedId}`);

        // ... (rest of the code)

    } finally {
        await client.close();
    }
}

run().catch(console.dir);

Code Breakdown: Connection

  • `MongoClient` Import: Standard MongoDB driver for Node.js.
  • Connection URI: Points to your Cosmos DB account, formatted for MongoDB compatibility.
  • `client.connect()`: Establishes the connection to Cosmos DB.
  • `client.db()` & `collection()`: Selects the target database and collection.

Code Breakdown: Insert Operation

  • `doc` Object: A standard JSON document representing the data to be inserted.
  • `collection.insertOne(doc)`: Inserts the document into the specified collection.
  • `result.insertedId`: Returns the unique ID generated for the new document.
Key Takeaway

The MongoDB API allows existing MongoDB client drivers to connect to Cosmos DB using a familiar connection string, enabling standard CRUD operations with minimal code changes.
