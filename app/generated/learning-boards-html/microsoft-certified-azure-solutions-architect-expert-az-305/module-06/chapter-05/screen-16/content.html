Key Concepts (Continued)

Deepening your understanding of Cosmos DB terminology.

Table API

A premium, globally distributed version of Azure Table Storage, compatible with existing SDKs.

Vertex

An entity in a graph database, representing a data point like a user or a product.

Edge

A relationship between two vertices in a graph database, indicating a connection.

Wire-Compatible

Means the API behaves like the original open-source database, allowing existing client drivers and tools to connect.

Summary Takeaway

Understanding the Table API's premium key-value capabilities, along with graph database concepts like vertices and edges, and the principle of wire-compatibility, is crucial for comprehensive Cosmos DB solution design.
