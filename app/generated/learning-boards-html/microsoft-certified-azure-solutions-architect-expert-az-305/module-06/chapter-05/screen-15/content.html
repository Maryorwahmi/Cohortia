Key Concepts

Essential terms and ideas from this chapter.

MongoDB API

A wire-compatible endpoint for MongoDB, allowing migration of existing MongoDB applications.

Cassandra API

A wire-compatible endpoint for Apache Cassandra, suitable for migrating Cassandra workloads.

Gremlin (Graph) API

An API for storing and querying graph data using Apache TinkerPop's Gremlin query language.

Summary Takeaway

Azure Cosmos DB's multi-model APIs provide flexible, wire-compatible endpoints for popular NoSQL databases, enabling architects to choose the best data model for migration or new development while leveraging Cosmos DB's global scale and performance.
