Performing CRUD Operations with MongoDB API

Querying, updating, and deleting documents in Cosmos DB.

const { MongoClient } = require('mongodb');

async function run() {
    const uri = "mongodb://..."; // Connection string from previous screen
    const client = new MongoClient(uri);

    try {
        await client.connect();
        const database = client.db("productsdb");
        const collection = database.collection("products");

        // 1. Insert a document (already covered)
        // ...

        // 2. Find documents
        console.log("
Finding Electronics products:");
        const query = { category: "Electronics" };
        const products = await collection.find(query).toArray();
        console.log(products);

        // 3. Update a document
        const updateResult = await collection.updateOne(
            { name: "Laptop Pro" },
            { $set: { price: 1450, stock: 8 } }
        );
        console.log(`
Updated ${updateResult.matchedCount} document(s).`);

        // 4. Delete a document
        const deleteResult = await collection.deleteOne({ name: "The Art of Cloud" });
        console.log(`
Deleted ${deleteResult.deletedCount} document(s).`);

    } catch (err) {
        console.error("An error occurred:", err);
    } finally {
        await client.close();
        console.log("Connection closed.");
    }
}

run().catch(console.dir);

Code Breakdown: Find Operation

  • `collection.find(query)`: Retrieves documents matching the specified query filter.
  • `.toArray()`: Converts the result cursor into a JavaScript array.
  • Example: Finding all products with `category: "Electronics"`.

Code Breakdown: Update & Delete

  • `collection.updateOne(filter, update)`: Modifies a single document. Uses `$set` to update fields.
  • `collection.deleteOne(filter)`: Removes a single document matching the filter.
  • `matchedCount`/`deletedCount`: Properties on the result object indicating operation success.
Key Takeaway

The MongoDB API fully supports standard CRUD operations (Create, Read, Update, Delete) using familiar MongoDB query language and methods, ensuring a seamless development experience.
