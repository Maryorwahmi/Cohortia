Key Innovation

Understanding the Hierarchical Namespace

Transforming Object Storage into a File System

What HNS Enables:

  • •Organizes objects into a true directory and file structure.
  • •Allows atomic operations: move, rename, delete directories and files.
  • •Crucial for big data processing engines like Apache Spark.
  • •Significantly improves performance for analytics workloads.
Performance Impact

Operations on directories are much faster with HNS, which is vital for the iterative nature of big data analytics.

Flat Object Store vs. Hierarchical Namespace

Flat Object Store

No true directories; all objects at the same level.

• /data/fileA.csv• /data/folder1/fileB.txt• /data/folder1/fileC.txt• /data/folder2/fileD.json

Inefficient directory operations (e.g., listing, deleting).

Hierarchical Namespace

True directory structure with atomic operations.

• /data/- /data/folder1/-- fileB.txt-- fileC.txt- /data/folder2/-- fileD.json

Fast, atomic directory operations.
