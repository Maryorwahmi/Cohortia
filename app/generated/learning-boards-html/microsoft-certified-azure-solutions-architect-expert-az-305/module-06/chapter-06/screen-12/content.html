Managing ADLS Gen2 with Azure CLI

Creating File Systems and Directories

Key CLI Commands:

  • •`az storage fs create`: Creates a new file system (container).
  • •`az storage fs directory create`: Creates directories within a file system.
  • •Requires `--hns true` during storage account creation.
  • •Use Azure AD authentication for better security than account keys.
Common Mistake

Forgetting to enable the hierarchical namespace (`--hns true`) during storage account creation. This cannot be changed later and results in a standard Blob Storage account.

# Create a file system (container equivalent for ADLS Gen2)
az storage fs create \
    --name rawdata \
    --account-name $STORAGE_ACCOUNT_NAME \
    --account-key $STORAGE_KEY
# Create directories within the file system
az storage fs directory create \
    --name rawdata/sales \
    --file-system rawdata \
    --account-name $STORAGE_ACCOUNT_NAME \
    --account-key $STORAGE_KEY

az storage fs directory create \
    --name rawdata/marketing \
    --file-system rawdata \
    --account-name $STORAGE_ACCOUNT_NAME \
    --account-key $STORAGE_KEY
