Azure RBAC for Data Lake Storage Gen2

Controlling Access at the Account and Container Level

Key Aspects of Azure RBAC:

  • •Manages access to the storage account and its data plane.
  • •Roles like 'Storage Blob Data Contributor' grant broad permissions.
  • •Permissions apply at storage account, container, or resource group level.
  • •Ideal for service principals and large user groups.
Example Role

Granting 'Storage Blob Data Contributor' to an Azure Databricks workspace allows it to read, write, and delete data across all containers in the storage account.
