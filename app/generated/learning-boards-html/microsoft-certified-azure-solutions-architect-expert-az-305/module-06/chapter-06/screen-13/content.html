File Operations and ACL Management with CLI

Uploading Data and Inspecting Permissions

Key CLI Commands:

  • •`az storage fs file upload`: Uploads a local file to a directory.
  • •`az storage fs directory list`: Lists contents of a specified directory.
  • •`az storage fs access show`: Displays POSIX ACLs for a file or directory.
  • •Always use Azure AD authentication for applications, not account keys.
Pro Tip

When working with ACLs, remember that the 'execute' permission on a directory is crucial for users to traverse into it, even if they don't have read access to the directory's contents.

# Upload a file to a directory
echo "Sales data entry 1" > sales_data_01.csv
az storage fs file upload \
    --source sales_data_01.csv \
    --path rawdata/sales/sales_data_01.csv \
    --file-system rawdata \
    --account-name $STORAGE_ACCOUNT_NAME \
    --account-key $STORAGE_KEY
# List directory contents
az storage fs directory list \
    --name rawdata/sales \
    --file-system rawdata \
    --account-name $STORAGE_ACCOUNT_NAME \
    --account-key $STORAGE_KEY \
    --output table
# Get ACLs for a directory
az storage fs access show \
    --path rawdata/sales \
    --file-system rawdata \
    --account-name $STORAGE_ACCOUNT_NAME \
    --account-key $STORAGE_KEY
