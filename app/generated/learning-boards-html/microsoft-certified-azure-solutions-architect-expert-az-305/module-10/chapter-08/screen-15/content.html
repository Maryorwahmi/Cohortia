Key Concepts

Expanding your Azure Arc vocabulary

GitOps

An operational framework that uses Git as the single source of truth for declarative infrastructure and application configuration, enabling automated deployments.

Azure Policy for Kubernetes

Extends Azure Policy to Arc-enabled Kubernetes clusters to enforce security and compliance settings for pods, deployments, and other Kubernetes resources.

Custom Locations

An Azure Arc feature that allows you to extend Azure's resource provisioning capabilities to your Arc-enabled Kubernetes clusters, enabling deployment of Azure services directly onto that infrastructure.

These advanced features empower architects to implement sophisticated automation, robust governance, and flexible service deployment across hybrid Kubernetes environments.
