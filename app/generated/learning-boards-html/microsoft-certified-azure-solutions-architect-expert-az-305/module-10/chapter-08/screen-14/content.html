Key Concepts

Essential terms for Azure Arc solutions

Azure Arc

A set of technologies that extends Azure management, governance, and services to any infrastructure, anywhere (on-premises, edge, multi-cloud).

Azure Arc-enabled servers

Allows you to manage non-Azure physical and virtual machines as if they were native Azure resources, by installing the Azure Connected Machine agent.

Azure Arc-enabled Kubernetes

Connects any CNCF-certified Kubernetes cluster to Azure, enabling Azure management, governance, and services for hybrid Kubernetes environments.

These core components form the foundation for extending Azure's powerful control plane to your entire IT landscape, unifying management and operations.
