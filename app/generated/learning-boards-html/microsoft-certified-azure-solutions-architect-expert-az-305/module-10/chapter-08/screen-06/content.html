Azure Arc-enabled Servers: Overview

Bringing On-Premises and Multi-Cloud VMs into Azure Management

  • •Unified View: Manage physical and virtual machines outside Azure as native Azure VMs.
  • •Connected Machine Agent: A lightweight agent installed on non-Azure servers enables connection.
  • •Azure Portal Integration: Servers appear and are manageable directly within the Azure portal.
  • •No Migration Required: Extend Azure's control plane without moving workloads.
Key Takeaway

Azure Arc-enabled servers provide a unified management experience for hybrid server fleets by installing a connected machine agent, treating them as native Azure resources.

Example Scenario

A company with hundreds of on-premises Linux servers can use Azure Arc to centralize their management, monitoring, and security patching through the Azure portal.
