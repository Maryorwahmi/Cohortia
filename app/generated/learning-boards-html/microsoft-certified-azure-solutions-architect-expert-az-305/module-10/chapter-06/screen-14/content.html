Key Concepts

Essential terms for Azure Container Apps

Azure Container Apps (ACA)

A fully managed serverless container service for building and deploying modern apps and microservices at scale.

Container Apps Environment

A secure boundary for a collection of container apps, providing shared VNet, Dapr integration, and observability.

Revisions

Immutable versions of a container app. New deployments create new revisions, allowing for traffic splitting and controlled rollouts.

Summary Takeaway

ACA provides a managed, Kubernetes-backed platform for microservices, with environments for shared resources and revisions for safe deployments.
