Understanding the ACA Environment

The secure boundary for your containerized microservices.

  • Secure Boundary: Provides isolation and a shared context for multiple container apps.
  • Shared VNet: All apps within the environment communicate privately and securely.
  • Dapr Integration: Enables consistent Dapr usage across all microservices.
  • Unified Observability: Centralized logging and metrics via a shared Log Analytics workspace.
Key Takeaway

The ACA Environment simplifies networking, Dapr integration, and observability for a collection of microservices.
