Dynamic Scaling

Scaling Container Apps with KEDA

Responding to events and variable demand, scaling from zero.

  • Event-Driven: Scales based on metrics from various event sources (queues, topics).
  • Scale to Zero: Cost-effective for intermittent workloads, only pay when active.
  • Flexible Scalers: Supports Azure Service Bus, Kafka, Event Hubs, Redis, and more.
  • Optimized Resources: Ensures applications have the right amount of compute for demand.
Key Takeaway

KEDA provides intelligent, event-driven autoscaling for ACA, optimizing performance and cost for variable workloads.
