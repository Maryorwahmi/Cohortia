Authentication & Authorization with Easy Auth

Simplifying user identity management for your applications.

What is Easy Auth?

Built-in authentication/authorization capabilities in App Service, allowing configuration against various identity providers without writing code.

Supported Providers

Azure Active Directory (AAD), Google, Facebook, Microsoft Account, Twitter.

Key Takeaway

Easy Auth simplifies user authentication by integrating with various identity providers, offloading complexity to Azure.

Easy Auth Flow

Azure handles the authentication handshake.

User Request

Accesses App Service App

App Service Easy Auth

Redirects to Identity Provider

Identity Provider

Authenticates User (e.g., AAD, Google)

Authenticated Access

User granted access to App Service App
