Persistent Data

Persistent Storage for Stateful Applications

Leveraging Persistent Volumes and CSI drivers in AKS.

The Need for Persistent Storage

Containerized applications are often designed to be stateless. However, many real-world applications require data to persist beyond the life of a pod. Without persistent storage, data generated by a pod would be lost upon its termination or rescheduling.

Kubernetes Storage Abstractions

  • Persistent Volume (PV): A cluster resource representing a piece of storage provisioned in the cluster.
  • Persistent Volume Claim (PVC): A request for storage by a user, consuming a PV.
  • Storage Class: Defines the type of storage and its properties (e.g., performance tier, access mode).
Common Mistake

Failing to plan for persistent storage for stateful applications in AKS leads to data loss and operational instability.
