Key Concepts: Connectivity & Security

Essential terms for networking, storage, and security in AKS.

Azure CNI

An advanced networking model where pods get IP addresses directly from the Azure Virtual Network subnet.

Ingress Controller

A Kubernetes resource that manages external access to services in a cluster, providing HTTP/S routing and load balancing.

Persistent Volume (PV) / PVC

Kubernetes resources used to provision and consume persistent storage for stateful applications.

Summary Takeaway

Designing AKS solutions requires careful consideration of networking models like Azure CNI, external access via Ingress Controllers, persistent storage for stateful applications, and robust access control through Kubernetes RBAC.
