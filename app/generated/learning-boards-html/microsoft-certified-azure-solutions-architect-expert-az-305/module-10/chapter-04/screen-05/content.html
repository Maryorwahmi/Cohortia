High Availability & Scaling

Ensuring AKS Resilience and Elasticity

Leveraging Availability Zones and Auto-scaling for robust clusters.

Availability Zones for Resilience

  • Distributes nodes across physically separate data centers.
  • Protects against zone-wide failures (power, network, cooling).
  • Requires region support and configuration during cluster creation.
  • Crucial for mission-critical applications to maintain uptime.

Cluster Autoscaler (CA)

Automatically adjusts the number of nodes in your node pools based on pending pods. It ensures there are enough nodes to run all your workloads efficiently.

Node ScalingInfrastructure

Horizontal Pod Autoscaler (HPA)

Scales the number of pods for a deployment based on CPU utilization or custom metrics. It ensures your application can handle varying request loads.

Pod ScalingApplication

Combined Auto-Scaling Flow

1. Application Load Increases

CPU utilization rises, more requests.

2. HPA Scales Pods Up

New pods are created to handle demand.

3. Cluster Autoscaler Adds Nodes

If new pods can't be scheduled, new VMs are provisioned.

4. Workload Handled Efficiently

Resources match demand, optimizing performance and cost.

Common Mistake

Manually scaling node pools often leads to over-provisioning or insufficient capacity during peak loads, impacting cost and performance.
