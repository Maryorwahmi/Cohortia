Storage Options

Selecting Azure Storage for AKS Workloads

Matching storage types to application access modes and performance needs.

Azure Disk: Block Storage

  • Purpose: Block storage, typically mounted by a single pod.
  • Access Mode: ReadWriteOnce (RWO).
  • Tiers: Standard HDD, Standard SSD, Premium SSD.
  • Use Cases: Databases, single-instance applications requiring dedicated storage.

Azure Files: Shared File Storage

  • Purpose: Shared file storage, accessible by multiple pods.
  • Access Mode: ReadWriteMany (RWX).
  • Tiers: Standard, Premium.
  • Use Cases: Content management systems, shared configuration, logging.

Azure NetApp Files: High-Performance File Shares

  • Purpose: Ultra-high performance, low-latency file shares.
  • Access Mode: ReadWriteMany (RWX).
  • Tiers: Standard, Premium, Ultra.
  • Use Cases: HPC, demanding enterprise applications, SAP workloads.
