Azure Hybrid Benefit

Leverage your existing on-premises Windows Server and SQL Server licenses with Software Assurance to get significant discounts on Azure compute services like Virtual Machines and Azure SQL Database.

Key Takeaway

Maximize savings by applying your existing license investments to Azure resources.

Requirement

Requires active Software Assurance on eligible Windows Server and SQL Server licenses.

Savings

Substantial

vs. Pay-as-you-go with Azure licenses

Azure VMs

Azure SQL Database
