Durable Functions: Orchestrating Stateful Workflows

Overcome statelessness with code-defined, long-running orchestrations.

Core Concepts

  • Stateful Orchestration: Write long-running workflows in code, managing state, checkpoints, and restarts.
  • Reliable Execution: Handles retries, error handling, and versioning automatically.
  • Patterns: Supports chaining, fan-out/fan-in, async HTTP APIs, human interaction, and monitoring.
Key Takeaway

Durable Functions enable the creation of robust, stateful serverless workflows, simplifying complex orchestrations and long-running processes.

Durable Function Patterns

Function Chaining

Execute functions in a specific sequence.

Fan-out/Fan-in

Parallel execution and aggregation of results.

Async HTTP APIs

Long-running operations initiated via HTTP.

Human Interaction

Orchestrations waiting for human input.

Common Misconception

Durable Functions are not a separate service, but an extension of Azure Functions, leveraging the same serverless benefits with added state management.
