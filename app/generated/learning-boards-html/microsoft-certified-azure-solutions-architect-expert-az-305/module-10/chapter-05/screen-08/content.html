Hosting Plans

App Service Plan: Dedicated Resources

Run Function Apps on existing or dedicated App Service Plans.

Key Characteristics

  • Dedicated VMs: Functions run on dedicated virtual machines, providing consistent resources.
  • Predictable Cost: You pay for the underlying VMs, regardless of function execution, offering predictable billing.
  • Consolidation: Ideal for running Function Apps alongside other App Service applications on shared infrastructure.
Key Takeaway

The App Service Plan provides predictable resources and cost, suitable for consolidating Function Apps with other App Service workloads or when specific App Service features are needed.

App Service Plan Scenario

Existing Infrastructure: Utilize an already provisioned App Service Plan.

Function App Deployment: Deploy Function Apps to the existing plan.

Shared Resources: Functions run alongside other App Service apps.

Cost Implication

You pay for the underlying VMs 24/7, regardless of function execution, which can be less cost-efficient for low-usage scenarios.
