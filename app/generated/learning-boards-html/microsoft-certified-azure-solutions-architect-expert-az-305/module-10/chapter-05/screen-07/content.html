Hosting Plans

Premium Plan: Enhanced Performance

Pre-warmed instances, VNet connectivity, and longer execution.

Key Advantages

  • No Cold Starts: Pre-warmed instances ensure immediate response times, crucial for latency-sensitive applications.
  • VNet Connectivity: Securely integrate with resources inside your Azure Virtual Network.
  • Longer Execution: Supports function execution durations beyond the Consumption Plan limits.
Key Takeaway

The Premium Plan is ideal for production workloads requiring consistent low latency, VNet integration, and longer execution times, at a predictable minimum cost.

Premium Plan Benefits

Always-On Instances: Resources are kept warm.

Event Triggered: Function executes immediately.

No Cold Start: Consistent, low-latency performance.

Cost Implication

The Premium Plan has a minimum cost due to always-on instances, making it less suitable for extremely infrequent workloads.
