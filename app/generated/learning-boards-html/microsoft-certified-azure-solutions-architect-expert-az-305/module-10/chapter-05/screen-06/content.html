Hosting Plans

Consumption Plan: True Serverless

Pay only for execution, scale to zero, ideal for spiky workloads.

Key Features

  • Pay-per-execution: You are billed only for the compute time and memory consumed during function execution.
  • Scales to zero: When idle, functions automatically scale down to no running instances, minimizing costs.
  • Automatic Scaling: Dynamically scales out to handle increased demand without manual intervention.
Key Takeaway

The Consumption Plan is the most cost-effective for unpredictable, spiky workloads, offering true serverless billing and automatic scaling, despite potential cold starts.

Consumption Plan Dynamics

Idle Period: Function scales to zero instances.

Event Triggered: Platform provisions resources.

Cold Start: Initial delay as resources warm up, then execution.

Consideration

Cold starts can impact latency-sensitive applications. Evaluate if the cost savings outweigh potential delays for your specific workload.
