Running Parallel Jobs and Tasks with Azure Batch CLI

Defining compute pools, jobs, and submitting tasks for execution.

Job Execution Flow

  1. 1.Create a Batch Pool: Define the VM size, image, and target number of nodes for your compute resources.
  2. 2.Create a Batch Job: A container that holds all the tasks you want to run on the pool.
  3. 3.Add Tasks to the Job: Individual commands or applications to be executed in parallel.
  4. 4.Monitor Job and Task Status: Track the progress and completion of your parallel workload.
  5. 5.Get Task Output (Optional): Retrieve the standard output or results from completed tasks.
Key Takeaway

Azure Batch simplifies the execution of parallel jobs by abstracting away infrastructure management, allowing you to define compute pools, jobs, and tasks programmatically.

Azure CLI Commands
# 5. Create a Batch Pool
#    (This will take a few minutes to provision VMs)
az batch pool create \
  --id mylinuxpool \
  --vm-size Standard_D2_v3 \
  --target-dedicated-nodes 2 \
  --image canonical:ubuntuserver:18.04-LTS:latest \
  --node-agent-sku-id "batch.node.ubuntu 18.04" \
  --resource-group batch-hpc-rg

# 6. Create a Batch Job
az batch job create \
  --id mybatchjob \
  --pool-id mylinuxpool \
  --resource-group batch-hpc-rg

# 7. Add Tasks to the Job
#    (In a real scenario, these would be your application commands)
az batch task create \
  --job-id mybatchjob \
  --task-id task1 \
  --command-line "/bin/bash -c 'echo Hello from Task 1 on node \$AZ_BATCH_NODE_ID'" \
  --resource-group batch-hpc-rg

az batch task create \
  --job-id mybatchjob \
  --task-id task2 \
  --command-line "/bin/bash -c 'echo Hello from Task 2 on node \$AZ_BATCH_NODE_ID'" \
  --resource-group batch-hpc-rg

# 8. Monitor Job and Task Status
az batch job show --job-id mybatchjob --query state
az batch task list --job-id mybatchjob --query "[].{id:id, state:state}"

# 9. Get Task Output (Optional)
az batch task show \
  --job-id mybatchjob \
  --task-id task1 \
  --query 'executionInfo.stdOut' -o tsv
