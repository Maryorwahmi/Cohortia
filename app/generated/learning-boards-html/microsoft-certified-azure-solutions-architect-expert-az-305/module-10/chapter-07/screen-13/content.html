Setting Up Azure Batch Resources via CLI

Creating resource group, storage, and Batch account for parallel jobs.

Setup Steps

  1. 1.Create a Resource Group: A logical container for all your Azure Batch resources.
  2. 2.Create an Azure Storage Account: Used by Batch jobs for input and output data. Must be globally unique.
  3. 3.Create an Azure Batch Account: The central service for managing Batch pools and jobs. Must be globally unique and linked to the storage account.
  4. 4.Log in to the Batch Account: Authenticate your CLI session to interact with the Batch service.
Key Takeaway

Proper initial setup of a resource group, storage account, and Batch account is foundational for running any parallel HPC workload in Azure Batch.

Azure CLI Commands
# 1. Create a Resource Group
az group create --name batch-hpc-rg --location eastus

# 2. Create an Azure Storage Account
#    (Replace 'mybatchstorageacc12345' with a globally unique name)
az storage account create \
  --name mybatchstorageacc12345 \
  --resource-group batch-hpc-rg \
  --location eastus \
  --sku Standard_LRS \
  --kind StorageV2

# 3. Create an Azure Batch Account
#    (Replace 'mybatchaccount12345' with a globally unique name)
az batch account create \
  --name mybatchaccount12345 \
  --resource-group batch-hpc-rg \
  --location eastus \
  --storage-account mybatchstorageacc12345

# 4. Log in to the Batch Account
az batch account login \
  --name mybatchaccount12345 \
  --resource-group batch-hpc-rg
