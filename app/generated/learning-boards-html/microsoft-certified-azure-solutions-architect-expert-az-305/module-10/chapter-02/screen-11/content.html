Network Security

Network Security Groups (NSGs) as Virtual Firewalls

Filtering network traffic to and from Azure resources in a Virtual Network.

What is an NSG?

A virtual firewall that filters network traffic to and from Azure resources in an Azure Virtual Network based on defined rules.

NSG Rule Components

  • Source/Destination (IP address, CIDR block)
  • Source/Destination Port Range
  • Protocol (TCP, UDP, Any)
  • Direction (Inbound/Outbound)
  • Priority (lower numbers processed first)
  • Access (Allow/Deny)
Key Takeaway

NSGs are your primary tool for implementing virtual firewall capabilities in Azure, enabling precise control over network traffic flow.

NSG Rule Evaluation Flow

Traffic Initiated

Inbound or Outbound

Rules Processed by Priority

Lowest number first

First Match Wins

Traffic Allowed or Denied

Concrete Example: Web Server Access

An NSG rule allows inbound TCP traffic on port 80 from the internet to your web server subnet, while implicitly denying all other inbound traffic.

Common Mistake

Creating overly permissive NSG rules (e.g., allowing 'Any' source/destination) can expose VMs to unnecessary security risks. Always apply the principle of least privilege.
