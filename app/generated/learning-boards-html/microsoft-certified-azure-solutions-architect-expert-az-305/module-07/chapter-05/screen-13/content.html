Real-time Temperature Alerting with ASA

Implementing a 10-second Tumbling Window Average

-- Azure Stream Analytics Query (SAQL)
-- Define input (IoT Hub)
WITH IoTInput AS (
    SELECT
        IoTHub.ConnectionDeviceId AS DeviceId,
        CAST(Temperature AS FLOAT) AS Temperature,
        EventEnqueuedUtcTime AS EventTime
    FROM
        IoTHubInput -- Assuming 'IoTHubInput' is the name of your IoT Hub input in ASA
    WHERE
        Temperature IS NOT NULL AND IS_NUMBER(Temperature) = 1
)

-- Calculate 10-second tumbling window average temperature per device
SELECT
    System.Timestamp AS WindowEndTime,
    DeviceId,
    AVG(Temperature) AS AverageTemperature
INTO
    TemperatureAveragesOutput -- Output to a temporary stream or storage for further analysis
FROM
    IoTInput
GROUP BY
    DeviceId,
    TumblingWindow(Second, 10)
HAVING
    AVG(Temperature) > 30 -- Filter for devices exceeding 30 degrees Celsius
Scenario Overview
  • Goal: Calculate 10-second avg temperature per device.
  • Alert: If avg temperature exceeds 30°C.
  • Ingestion: Azure IoT Hub.
  • Processing: Azure Stream Analytics.
  • Alerting: Azure Functions/Logic Apps (triggered by ASA output).
Query Explanation
  • WITH IoTInput: Defines a CTE for input data selection and validation.
  • TumblingWindow(Second, 10): Groups events into non-overlapping 10-second windows.
  • System.Timestamp: Represents the end time of the aggregation window.
  • HAVING AVG(Temperature) > 30: Filters the aggregated results to trigger alerts only for high temperatures.
Key Takeaway

SAQL's windowing and filtering capabilities in Azure Stream Analytics are powerful for implementing real-time aggregations and conditional alerting from streaming data.
