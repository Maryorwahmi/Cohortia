Databricks Structured Streaming: Batch on Stream

Flexible and Fault-Tolerant Stream Processing with Spark

# Conceptual Structured Streaming Code
from pyspark.sql import SparkSession

spark = SparkSession.builder.appName("RealtimeStream").getOrCreate()

# Define a streaming DataFrame from Event Hubs
event_hub_df = spark.readStream \
    .format("eventhubs") \
    .option("eventhubs.connectionString", "...") \
    .load()

# Apply transformations (e.g., parse JSON, filter, aggregate)
processed_df = event_hub_df.selectExpr("CAST(body AS STRING) AS json_data") \
    .filter("json_data IS NOT NULL") \
    .withColumn("event_payload", from_json("json_data", schema))

# Write the processed stream to a sink (e.g., ADLS Gen2, Delta Lake)
query = processed_df.writeStream \
    .format("delta") \
    .outputMode("append") \
    .option("checkpointLocation", "/mnt/delta/checkpoint") \
    .start()

query.awaitTermination()
Core Paradigm

"Batch on Stream": Treats a live data stream as an unbounded table, simplifying development by applying batch-like operations.

Key Advantages
  • Fault-Tolerant: Built-in recovery from failures.
  • Flexibility: Supports complex custom transformations.
  • ML Integration: Seamlessly integrates with Spark MLlib.
  • Diverse Sources: Event Hubs, Kafka, ADLS Gen2, etc.
Key Takeaway

Azure Databricks Structured Streaming offers unparalleled flexibility and fault tolerance for complex, custom real-time processing, leveraging the power of Spark SQL.
