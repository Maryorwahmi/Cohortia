Star Schema

Central Fact Table Surrounded by Dimensions

The **star schema** is a common pattern with a central fact table containing quantitative measures, surrounded by multiple dimension tables providing descriptive context. The fact table stores foreign keys linking to the dimension tables' primary keys. For example, `FactSales` links to `DimDate`, `DimProduct`, and `DimCustomer`. Its simplicity and denormalized dimensions minimize joins, leading to better query performance in MPP systems like Synapse.

Key Takeaway

A central fact table (measures) linked to surrounding dimension tables (attributes), optimized for analytical queries.
