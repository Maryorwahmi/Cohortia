Key Concepts: Real-time & Advanced Principles

Crucial services and design considerations.

Activity (ADF)

A processing step within an Azure Data Factory pipeline (e.g., Copy Data, Data Flow, Stored Procedure).

Azure Event Hubs

A highly scalable data streaming platform and event ingestion service for collecting millions of events per second.

Azure IoT Hub

A managed service for bidirectional communication between millions of IoT devices and a cloud-hosted solution.

Data Flow (ADF)

A code-free transformation capability within Azure Data Factory, powered by Spark, for designing complex data transformations.

Idempotency

A property of an operation that ensures executing it multiple times has the same effect as executing it once. Crucial for reliable data ingestion.

Summary Takeaway

Choosing between Event Hubs and IoT Hub depends on device management needs, while ADF Data Flows enable visual transformations, and idempotency ensures data consistency.
