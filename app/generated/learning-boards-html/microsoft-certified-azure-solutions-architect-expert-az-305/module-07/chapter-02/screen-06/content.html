ADF Pipelines and Activities

Building blocks for data movement and transformation.

Pipelines: Workflow Orchestration

A pipeline is a logical grouping of activities that performs a unit of work. It defines the sequence and flow of data operations, such as copying data, running a stored procedure, or executing a data flow.

Activities: Processing Steps

  • Copy Data Activity: Efficiently moves data between various data stores.
  • Data Flow Activity: Provides code-free data transformations at scale, powered by Spark.
  • Other Activities: Execute stored procedures, run custom code, invoke Azure Functions, etc.

Power of Data Flow Activities

Data Flow activities in ADF allow architects to design complex data transformations visually, without writing code. This simplifies the process of cleansing, enriching, and shaping data, making it accessible to a wider range of data professionals and accelerating development cycles.

Key Takeaway

ADF pipelines orchestrate activities, with Copy Data for movement and Data Flow for powerful, visual, code-free data transformations at scale.

Example: Transforming Sales Data

An ADF pipeline extracts raw sales data. A Data Flow activity then:

  • Joins sales records with product information.
  • Filters out canceled orders.
  • Aggregates sales by region and month.
  • Loads the transformed data into a data warehouse.

This prepares the data for immediate business intelligence reporting.
