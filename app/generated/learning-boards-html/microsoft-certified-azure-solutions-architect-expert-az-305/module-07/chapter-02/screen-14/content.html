ADF Pipeline Walkthrough: On-premises to ADLS Gen2

Steps to ingest daily customer order data with filtering.

Scenario Overview

Ingest daily customer order data from an on-premises SQL Server database into Azure Data Lake Storage Gen2. Data must be filtered for the last 24 hours and stored as Parquet files.

Key Steps

  • Linked Services: Connect ADF to SQL Server (via Self-Hosted IR) and ADLS Gen2.
  • Datasets: Define source (SQL table) and sink (ADLS Gen2 Parquet with dynamic path).
  • Copy Data Activity: Use a SQL query to filter data.
  • Schedule: Set up a daily trigger for automation.

SQL Query for Filtering

SELECT OrderID, CustomerID, OrderDate, TotalAmount
FROM [dbo].[Orders]
WHERE OrderDate >= DATEADD(day, -1, GETDATE());

This query dynamically selects orders from the last 24 hours, ensuring only recent data is ingested.

Dynamic File Path in ADLS Gen2

orders/{{formatDateTime(utcnow(), 'yyyy/MM/dd')}}/orders.parquet

Using dynamic content ensures data is partitioned by date, making it easier to manage and query in ADLS Gen2.

Key Takeaway

ADF enables robust hybrid data ingestion by combining secure linked services, dynamic datasets, and powerful activities with custom queries and scheduling.
