Data Ingestion: Bringing Data In

Reliably Collecting Data from Diverse Sources

What is Data Ingestion?

The process of collecting and importing data from various sources into a storage system, ensuring reliability and efficiency.

ETL vs. ELT

  • ETL (Extract, Transform, Load): Data is transformed before loading into the target.
  • ELT (Extract, Load, Transform): Data is loaded raw, then transformed within the target system (common with data lakes).

Key Azure Services

  • Azure Data Factory (ADF): Cloud-based data integration service for orchestrating data movement and transformation.
  • Azure Event Hubs: Highly scalable data streaming platform for ingesting millions of events per second, ideal for real-time.
  • Azure IoT Hub: Specifically for ingesting data from IoT devices.
Key Takeaway

Effective data ingestion, using patterns like ELT and services like Azure Data Factory or Event Hubs, is foundational for feeding diverse data into your analytics platform.
