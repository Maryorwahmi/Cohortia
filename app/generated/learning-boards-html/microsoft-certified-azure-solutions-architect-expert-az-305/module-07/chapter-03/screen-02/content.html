Learning Objectives

Master the art of designing efficient and scalable data storage for analytics on Azure.

01

Evaluate & Select Services

Assess analytical data requirements and choose the optimal Azure storage services, balancing performance and cost.

02

Design Data Lake Structures

Create effective data lake layouts using ADLS Gen2, implementing logical folder hierarchies and partitioning strategies.

03

Understand File Formats

Grasp the benefits and use cases of Parquet, ORC, CSV, and JSON for analytical data processing.

04

Implement Lifecycle & Security

Apply data lifecycle management and robust security measures for analytical data storage.
