Designing a Data Lake Structure

Structuring raw and curated data for analytics.

Raw Layer: Organize by source, type, and date for easy batch access.

Example: raw/customer_interactions/{{year}}/{{month}}/{{day}}/interaction_data_{{timestamp}}.json

Curated Layer: Convert to optimized columnar format (Parquet) and maintain partitioning.

Example: curated/customer_interactions_parquet/{{year}}/{{month}}/{{day}}/

This structure enables efficient data pruning and faster analytical queries.

Example Folder Paths

raw/customer_interactions/2023/10/26/interaction_data_143000.json

curated/customer_interactions_parquet/2023/10/26/

(Files within curated path are Parquet format)

Optimized for Spark analytics via partitioning and columnar format.
