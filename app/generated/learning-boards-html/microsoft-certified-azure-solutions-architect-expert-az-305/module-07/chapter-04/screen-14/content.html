# 4. Aggregate data: count unique user actions per customer per day
# Assuming 'action_type' column in clickstream data
df_aggregated = df_joined.groupBy(col("customer_id"), to_date(col("timestamp")).alias("activity_date")) \
                         .agg(count(col("action_type")).alias("total_actions")) \
                         .orderBy("activity_date", "customer_id")
print("
Aggregated data schema:")
df_aggregated.printSchema()
df_aggregated.show(5)
# 5. Write the aggregated data as Parquet, partitioned by date
try:
    df_aggregated.write.mode("overwrite").parquet(current_output_path)
    print(f"
Successfully wrote aggregated data to: {current_output_path}")
except Exception as e:
    print(f"Error writing aggregated data: {e}")
    exit(1)
# spark.stop() # Only if you manually created the SparkSession
Code Explanation
  • Aggregate: Groups data by customer and date, then counts `action_type` to get `total_actions`.
  • Schema Check: Verifies the schema and content of the aggregated DataFrame.
  • Write Parquet: Writes the aggregated data to ADLS Gen2 in Parquet format.
  • Overwrite Mode: Uses `mode("overwrite")` for idempotency, replacing data for the specific date.
  • Partitioning: The output path is structured to partition data by date, optimizing future queries.
Pro-Tip: Data Partitioning

Partitioning your output data by date or other relevant keys significantly improves query performance and reduces costs for downstream consumers, as they only scan necessary data.

Key Takeaway

PySpark's aggregation functions and efficient Parquet writing capabilities are key for producing curated, optimized datasets.
