Data Governance & Security: Row-Level Security (RLS)

Restricting data access based on user identity in Power BI

RLS Implementation Steps

  • •**Define Roles:** Create roles in Power BI Desktop (e.g., `SalesManager`).
  • •**Apply DAX Filters:** Use DAX expressions to filter data for each role (e.g., `[Region] = USERPRINCIPALNAME()`).
  • •**Publish Report:** Publish the report to Power BI Service.
  • •**Assign Users:** Assign Azure AD users/groups to roles in Power BI Service security settings.
Key Takeaway

RLS is a fundamental security feature in Power BI, enabling granular data access control to ensure users only see authorized information.

DAX Filter Example for RLS

[ProductCategory] = USERPRINCIPALNAME()

Example Scenario

A sales manager logs into a Power BI report. RLS filters the data so they only see sales figures for product categories assigned to their user principal name (email address).
