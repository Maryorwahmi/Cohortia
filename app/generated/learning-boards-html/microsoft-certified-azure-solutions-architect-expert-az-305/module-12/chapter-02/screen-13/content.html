Sending Messages to an Azure Service Bus Queue

Implementing the Producer Side of Asynchronous Communication

Key Steps
  • Initialize ServiceBusClient with connection string.
  • Create ServiceBusSender for the target queue.
  • Construct ServiceBusMessage with your payload.
  • Use SendMessageAsync to dispatch the message.
  • Implement robust error handling and resource cleanup.
Pro-Tip

Always use await using or `try-finally` to ensure Service Bus client and sender resources are properly closed, preventing connection leaks.

Key Takeaway

The C# SDK provides a straightforward way to send messages reliably, abstracting away the complexities of network communication and message persistence.

using Azure.Messaging.ServiceBus;
using System;
using System.Threading.Tasks;

string connectionString = "YOUR_SERVICE_BUS_CONNECTION_STRING";
string queueName = "orders";

await using var client = new ServiceBusClient(connectionString);
ServiceBusSender sender = client.CreateSender(queueName);

string messageBody = "{\"OrderId\": \"ORD-001\", \"CustomerId\": \"CUST-123\", \"Item\": \"Laptop\", \"Quantity\": 1}";
ServiceBusMessage message = new ServiceBusMessage(messageBody);

try
{
    await sender.SendMessageAsync(message);
    Console.WriteLine($"Sent a single message to the queue: {queueName}");
}
catch (Exception ex)
{
    Console.WriteLine($"Error sending message: {ex.Message}");
}
finally
{
    await sender.CloseAsync();
}
