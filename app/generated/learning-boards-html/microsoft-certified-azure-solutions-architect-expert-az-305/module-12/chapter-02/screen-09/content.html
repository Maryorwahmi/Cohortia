Ensuring Order: Message Sessions

Processing Related Messages Sequentially by a Single Receiver

What are Message Sessions?

A feature that groups related messages and ensures they are processed by the same receiver instance in the order they were sent (FIFO).

Why They Matter
  • Crucial for stateful workflows where message sequence is vital.
  • Prevents race conditions and maintains data consistency.
  • Ensures all messages for a specific entity (e.g., customer order) are handled together.
Example

All messages for a customer's order (e.g., 'Order Placed', 'Payment Received', 'Item Shipped') are sent with the same SessionId to ensure sequential processing.

Key Takeaway

Use Message Sessions to guarantee FIFO processing for related messages, which is essential for maintaining state and consistency in complex distributed workflows.
