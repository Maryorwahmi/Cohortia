Key Concepts

Essential Terms for Azure Service Bus Integration

Azure Service Bus

A fully managed enterprise integration message broker for reliable asynchronous messaging.

Queue

A Service Bus entity for one-to-one asynchronous communication, processed by a single consumer.

Topic

A Service Bus entity for one-to-many (publish/subscribe) asynchronous communication.

Subscription

A mechanism associated with a topic that allows consumers to receive filtered copies of messages.

Message Session

Groups related messages, ensuring they are processed by the same receiver in order.

Summary Takeaway

Azure Service Bus provides queues for one-to-one and topics with subscriptions for one-to-many communication, enabling robust and decoupled enterprise integration.
