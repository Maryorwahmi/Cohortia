Key Concepts

Essential Terms for Rehost Migration

Rehost (Lift and Shift)

A cloud migration strategy moving applications and infrastructure to Azure IaaS with minimal changes.

Azure Migrate: Server Assessment

A tool for discovering, assessing, and right-sizing on-premises servers for migration to Azure.

Azure Site Recovery (ASR)

An Azure service enabling disaster recovery and migration by continuously replicating on-premises VMs to Azure.

Summary Takeaway

Rehost migrations provide a fast track to cloud benefits, relying on Azure Migrate for planning and Azure Site Recovery for execution, targeting Azure IaaS VMs.
