Execution Phase

Executing Migration with Azure Site Recovery (ASR)

Preparing Azure and On-Premises for VM Replication

1. Prepare Azure Environment

  • Create a Recovery Services vault.
  • Configure replication policies (frequency, retention).
  • Set up target Azure VNet and storage accounts.

2. Prepare On-premises Environment

  • Install ASR provider and agent on machines or vCenter.
  • Ensure connectivity to Azure.
Key Takeaway

Thorough preparation of both Azure and on-premises environments is crucial for enabling continuous, efficient VM replication with Azure Site Recovery.

3. Enable Replication

  • Configure replication for selected VMs.
  • ASR performs initial full replication.
  • Continuously replicates delta changes to Azure Blob Storage.

Example: Creating Recovery Services Vault

az backup vault create \--resource-group Az305MigrationRG \--name Az305RecoveryVault \--location eastus

This command creates the Recovery Services Vault, the management entity for ASR.
