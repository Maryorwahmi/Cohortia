Discovery and Assessment with Azure Migrate

Understanding Your On-Premises Environment for Cloud Readiness

Azure Migrate: Server Assessment

  • Discover: Automatically finds on-premises VMs (VMware, Hyper-V, physical).
  • Analyze: Collects performance data and identifies application dependencies.
  • Right-size: Recommends optimal Azure VM series and sizes based on actual usage.
  • Estimate Costs: Provides a financial projection for running workloads in Azure.
Key Takeaway

Azure Migrate is indispensable for gaining deep insights into your on-premises environment, enabling data-driven decisions for efficient and cost-effective cloud migration.

Why This Step Matters

Without proper assessment, you risk:

  • Over-provisioning resources, leading to higher costs.
  • Under-provisioning, causing performance bottlenecks.
  • Missing critical application dependencies, resulting in downtime.
  • Inaccurate cost estimations, impacting budget.

Example: Right-Sizing

An on-premises VM is configured with 8 vCPUs and 32GB RAM. Azure Migrate's assessment reveals it rarely uses more than 2 vCPUs and 12GB RAM. It recommends an Azure VM size that matches this actual usage, saving significant compute costs post-migration.
