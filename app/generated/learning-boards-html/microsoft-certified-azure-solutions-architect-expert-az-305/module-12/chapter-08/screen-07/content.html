Designing Your Azure Network for Rehost

Establishing Connectivity and Security in the Cloud

Key Network Components

  • Azure Virtual Network (VNet): Define IP ranges and segment into subnets.
  • Network Security Groups (NSGs): Filter traffic to/from VMs and subnets.
  • Hybrid Connectivity: VPN Gateway or ExpressRoute for on-premises connection.
  • DNS Resolution: Ensure proper name resolution for internal and external services.
Key Takeaway

A well-designed Azure network is the backbone of a successful rehost, ensuring secure communication, proper segmentation, and hybrid connectivity where needed.

Example: Multi-Tier Application

For a three-tier application, you would create separate subnets for the web, application, and database tiers. Each subnet would have an NSG to restrict traffic, for example, allowing only web traffic to the web subnet, application traffic from web to app, and database traffic from app to database, enhancing security.

Common Mistake

Simply replicating the on-premises network without optimizing for cloud best practices. This can lead to inefficient routing, security vulnerabilities, and missed opportunities for cloud-native network features.
