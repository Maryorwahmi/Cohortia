Core Concept

The Six R's of Cloud Migration

A Strategic Framework for Your Cloud Journey

1. Rehost (Lift & Shift)

Move applications to cloud IaaS with minimal changes.

2. Refactor (Replatform)

Optimize applications for PaaS with minor code changes.

3. Rearchitect

Modify code to fully leverage cloud-native capabilities.

4. Rebuild

Completely re-write the application from scratch for the cloud.

5. Replace (Repurchase)

Discard existing app and adopt a commercial SaaS solution.

6. Retire

Decommission applications that are no longer needed or used.

Key Takeaway

The '6 R's' provide a common framework to categorize and plan application migrations, guiding strategic decisions based on effort, cost, and cloud optimization goals.
