Rehost: The 'Lift and Shift' Approach

Moving Applications to IaaS with Minimal Changes

What is Rehost?

Moving applications to the cloud with minimal or no changes to their architecture. Essentially, taking existing VMs, databases, and applications from on-premises and 'shifting' them to Azure IaaS (e.g., Azure VMs, Azure SQL on VMs).

Pros

  • Quick wins, low complexity
  • Minimal application changes
  • Good for strict licensing

Cons

  • Limited cloud-native benefits
  • Potential for 'cloud sprawl'
  • Less cost optimization
Key Takeaway

Rehosting offers rapid migration to Azure IaaS, suitable for legacy systems or quick proofs of concept, but with limited cloud-native optimization.
