Key Concepts: Hybrid Data & Management

Essential terms for data synchronization and unified resource management.

Azure Service Bus

A reliable message broker for asynchronous communication between on-premises and cloud applications.

Azure Data Factory (ADF)

A cloud-based data integration service for orchestrating data movement and transformation across hybrid sources.

Self-Hosted Integration Runtime (SHIR)

An agent installed on-premises to enable Azure Data Factory to securely connect to on-premises data sources.

Azure SQL Managed Instance

A fully managed SQL Server database engine compatible with on-premises SQL Server, deployable into an Azure VNet.

Azure File Sync

Extends on-premises file servers to Azure Files, centralizing file services while maintaining local access.

Azure Arc

Extends Azure management capabilities to resources running on-premises, at the edge, or on other cloud providers.

Summary Takeaway

These services provide the tools for robust data integration, migration, and unified management across complex hybrid cloud environments.
