Azure Arc: Extending Azure Management

Managing resources anywhere – on-premises, at the edge, or across other clouds.

Manage Servers

Onboard on-premises Windows and Linux servers to Azure Arc for unified management with Azure policies, Monitor, and Security Center.

Manage Kubernetes

Connect any Kubernetes cluster (on-premises, other clouds) to Azure Arc for centralized management, GitOps deployments, and Azure policy application.

Run Azure Data Services

Deploy Azure SQL Managed Instance and Azure PostgreSQL Hyperscale on your own infrastructure, managed by Azure Arc, bringing cloud benefits on-premises.

Key Takeaway

Azure Arc provides a single control plane for managing diverse resources across hybrid and multi-cloud environments, simplifying governance, security, and operations.
