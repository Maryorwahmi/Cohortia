Azure SQL Managed Instance

Cloud-Native SQL Server Compatibility

Offers near 100% compatibility with the latest SQL Server (on-premises) database engine. Provides a migration path for existing SQL Server applications with minimal changes.

  • •Deployed into an Azure VNet.
  • •Seamlessly connects to on-premises networks via VPN/ExpressRoute.
  • •Fully managed service with built-in high availability.
Key Takeaway

SQL Managed Instance and File Sync enable seamless extension of on-premises SQL databases and file shares to Azure, balancing cloud benefits with local access needs.

Azure File Sync

Centralized File Services with Local Performance

Extends on-premises file servers to Azure Files, centralizing file services in the cloud while maintaining local access and performance. Caches frequently accessed files locally.

  • •Tier less frequently accessed files to Azure Files.
  • •Provides cloud backup, disaster recovery, and multi-site sync.
  • •Reduces on-premises storage footprint and costs.
Hybrid Scenario

Migrating a Legacy App

A company has a legacy application that relies on a SQL Server database and local file shares. They can migrate the database to Azure SQL Managed Instance and use Azure File Sync to extend the file shares, allowing the application to run in Azure or on-premises with minimal changes, leveraging cloud benefits.
