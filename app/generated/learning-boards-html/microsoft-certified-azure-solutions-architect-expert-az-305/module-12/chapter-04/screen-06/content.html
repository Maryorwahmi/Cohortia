Core Process

API Publishing Steps

  1. 1. Import API Source: Bring in APIs from OpenAPI (Swagger), WSDL, or Azure services like Function Apps.
  2. 2. Define API Operations: Specify endpoints, parameters, and responses for each API.
  3. 3. Consolidate (Optional): Group multiple backend APIs into a single, unified API product.
  4. 4. Expose via Gateway: Make the API discoverable and consumable through the APIM facade.
