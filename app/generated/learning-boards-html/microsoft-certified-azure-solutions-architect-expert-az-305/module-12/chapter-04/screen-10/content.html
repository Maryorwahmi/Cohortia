Rate Limiting Policy Example

This policy limits a subscriber to 100 calls per 60 seconds, preventing abuse and protecting backend services.

<policies>
  <inbound>
    <base />
    <rate-limit-by-key calls="100" renewal-period="60" counter-key="@(context.Subscription.Id)" />
  </inbound>
  <outbound>
    <base />
  </outbound>
</policies>
Policy Breakdown

Understanding the Attributes

  • calls="100": Sets the maximum number of allowed API calls.
  • renewal-period="60": Defines the time window (in seconds) for the rate limit.
  • counter-key="@(context.Subscription.Id)": Specifies the unique identifier used to track calls (e.g., per subscription).
  • Behavior: If the limit is exceeded, APIM returns a 429 Too Many Requests status.
Key Takeaway

Rate limiting policies are essential for protecting backend services from overload and ensuring fair usage by API consumers.
