Security Focus

APIM's Security Capabilities

  • Subscription Keys: Basic access control and usage tracking.
  • OAuth 2.0: Industry-standard protocol for delegated authorization.
  • JWT Validation: Verifies JSON Web Tokens issued by identity providers.
  • Client Certificates: Mutual TLS authentication for enhanced trust.
  • Azure AD Integration: Seamlessly integrate with Azure Active Directory for identity management.
Example & Misconception

Enforcing Access with Policies

You can enforce that all API calls must include a valid subscription key in the request header. APIM will validate this key before forwarding the request. For more granular control, APIM can validate a JWT token to ensure the caller is authorized for specific operations.

Common Mistake

Relying solely on subscription keys for security is a common pitfall. While useful for basic access control and analytics, they are not a substitute for robust authentication and authorization mechanisms like OAuth 2.0 or JWT, which provide stronger identity verification and granular access control.

Key Takeaway

APIM provides a comprehensive suite of security features, from subscription keys to OAuth 2.0 and JWT validation, to protect your APIs and offload security concerns from backends.
