Integration Patterns

Combining Event Grid and Event Hubs

Leveraging both services for comprehensive event processing.

Event Grid Triggering Event Hubs Actions

Event Grid can react to events from Event Hubs (e.g., Capture file created in Blob Storage) to trigger downstream actions like a Logic App processing the file.

Event Grid Routing to Event Hubs

Event Grid can act as a flexible front-end, routing events from various sources (Azure services, custom apps) into a high-throughput Event Hub for stream processing.

Key Takeaway

Combine Event Grid for discrete event routing and Event Hubs for high-throughput streaming to build comprehensive, scalable, and flexible event-driven solutions.
