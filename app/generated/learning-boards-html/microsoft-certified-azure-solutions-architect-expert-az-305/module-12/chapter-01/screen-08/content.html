Module 12›Chapter 1›Event Grid & Event Hubs

Azure Event Grid

A fully managed event routing service that simplifies event-driven application development. It routes events from various sources to different handlers.

Use Case

Reacting to changes in Azure Blob Storage, processing custom events, or building serverless event-driven architectures.

Concrete Example

When a new image is uploaded to Blob Storage, Event Grid triggers an Azure Function to resize it and store a thumbnail.

Azure Event Hubs

A highly scalable data streaming platform capable of ingesting millions of events per second. Ideal for big data and real-time analytics scenarios.

Use Case

Ingesting telemetry data from IoT devices, capturing application logs, or processing real-time clickstream data from websites.

Key Takeaway

Event Grid is for routing discrete events to reactive handlers, while Event Hubs is for high-throughput ingestion of data streams, both crucial for modern event-driven architectures.
