Workflow Overview

  • •Trigger: New file uploaded to Azure Blob Storage.
  • •Orchestration: Azure Logic App initiates the workflow.
  • •Custom Processing: Logic App calls an Azure Function to process file content (e.g., word count).
  • •Notification: Logic App sends an email with the processing results.

Why this pattern?

This pattern leverages Logic Apps for robust event handling and integration, and Azure Functions for efficient, scalable custom code execution, creating a powerful and flexible solution.

Key Takeaway

This hands-on scenario demonstrates how Logic Apps and Azure Functions seamlessly integrate to automate complex, event-driven file processing workflows.

Simplified Logic App Definition

{
  "definition": {
    "actions": {
      "Call_Azure_Function": {
        "inputs": {
          "body": {
            "blobUrl": "@triggerBody()?['url']"
          },
          "method": "POST",
          "uri": "https://az305fileprocessorfunc.azurewebsites.net/api/WordCounter?code=YOUR_FUNCTION_KEY"
        },
        "type": "Http"
      },
      "Send_an_email_(V2)": {
        "inputs": {
          "body": {
            "Body": "File processed: @{body('Call_Azure_Function')?['wordCount']} words.",
            "Subject": "New File Processed",
            "To": "admin@example.com"
          }
        },
        "runAfter": {
          "Call_Azure_Function": ["Succeeded"]
        },
        "type": "ApiConnection"
      }
    },
    "triggers": {
      "When_a_blob_is_added_or_modified_(properties_only)": {
        "inputs": {
          "queries": {
            "folderId": "/azureblob/v2/datasets/default/containers/documents"
          }
        },
        "recurrence": {
          "interval": 3,
          "unit": "Minute"
        },
        "type": "ApiConnection"
      }
    }
  }
}

This JSON snippet illustrates how a Logic App is triggered by a blob event, then makes an HTTP POST call to an Azure Function, passing the blob URL. After the function returns, it sends an email with the results.
