Key Concepts

Reinforce your understanding of the core ideas from this chapter.

Azure Logic Apps

A serverless, low-code/no-code platform for building automated workflows and orchestrating business processes using a visual designer and extensive connectors.

Azure Functions

A serverless compute service for running small, event-driven pieces of custom code without managing infrastructure.

Connectors (Logic Apps)

Pre-built integrations that allow Logic Apps to interact with hundreds of Azure services, Microsoft services, and third-party SaaS applications.

Summary Takeaway

Azure Logic Apps and Azure Functions are complementary serverless services that enable powerful, flexible, and scalable workflow automation and event-driven computing.
