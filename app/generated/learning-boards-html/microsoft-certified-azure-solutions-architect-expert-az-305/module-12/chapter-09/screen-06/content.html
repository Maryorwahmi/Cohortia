Module 12 › Chapter 12.9 › Refactoring Databases to Azure SQL
Scenario

Migrating an on-premises SQL Server database to Azure SQL Database or Azure SQL Managed Instance.

Key Steps & Tools
  • Assess database compatibility and dependencies.
  • Utilize Azure Database Migration Service (DMS) for migration.
  • Update application connection strings and configurations.
  • Perform thorough testing post-migration.
Key Takeaway

Migrating databases to Azure SQL offloads administrative tasks, enhances availability and security, and allows applications to leverage managed PaaS capabilities.

PaaS Benefits Leveraged
  • Automated Backups and Patching
  • High Availability and Disaster Recovery
  • Managed Security Features
  • Scalability (compute and storage)
  • Reduced DBA operational burden
Potential Challenges
  • Application code changes for T-SQL compatibility.
  • Choosing the right Azure SQL service tier and configuration.
  • Ensuring minimal downtime during migration.
