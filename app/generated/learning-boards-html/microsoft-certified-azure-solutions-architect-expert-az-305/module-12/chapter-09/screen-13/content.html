Module 12 › Chapter 12.9 › Live Demo: Replatforming to Azure App Service
Demo Overview

Demonstrate deploying a simple Node.js web application to Azure App Service using the Azure CLI, showcasing a Refactor (Replatform) strategy.

Key Azure CLI Commands
az appservice plan create \
  --resource-group Az305MigrationRG \
  --name Az305WebAppPlan \
  --sku B1 \
  --is-linux

az webapp create \
  --resource-group Az305MigrationRG \
  --plan Az305WebAppPlan \
  --name az305replatformedapp \
  --runtime "NODE|18-lts"

az webapp up \
  --resource-group Az305MigrationRG \
  --name az305replatformedapp \
  --runtime "NODE|18-lts"
Demo Steps
  • Show local Node.js app (Express, package.json).
  • Execute `az appservice plan create`.
  • Execute `az webapp create`.
  • Execute `az webapp up` for deployment.
  • Verify deployment in browser.
  • Briefly show App Service portal features (scaling, slots).
Key Takeaway

Azure CLI simplifies the process of deploying applications to managed PaaS services like App Service, demonstrating a practical refactoring approach.
