Module 12 › Chapter 12.9 › Refactoring Web Apps to Azure App Service
Scenario

Migrating a standard web application (e.g., .NET, Node.js) from an on-premises server to Azure App Service.

Key Steps
  • Create Azure App Service Plan and Web App.
  • Adjust application configurations (connection strings, environment variables).
  • Deploy application code using Azure CLI or other deployment methods.
Key Takeaway

Refactoring to Azure App Service provides a managed, scalable, and resilient platform, reducing operational burden while keeping the core application architecture intact.

PaaS Benefits Leveraged
  • Managed Hosting & OS Patching
  • Built-in Auto-Scaling
  • Deployment Slots for Zero-Downtime Deployments
  • Integrated Monitoring and Logging
Potential Challenges
  • Configuration management for PaaS environment.
  • Ensuring compatibility with App Service runtime constraints.
  • Understanding scaling limits and pricing tiers.
