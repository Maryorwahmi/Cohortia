Geo-Redundant Storage (GRS)

Asynchronous Replication to a Paired Region

GRS provides robust protection against regional disasters. Data is replicated three times within the primary region (like LRS) and then asynchronously replicated three times to a geographically separate, paired Azure region.

  • •Protects against region-wide outages.
  • •Asynchronous replication to secondary region.
  • •RPO: Minutes (potential data loss during failover).
  • •RTO: Hours (requires manual failover to secondary region).
  • •Higher cost than LRS/ZRS due to cross-region replication.
Use Case Example

Critical archival data, backup storage, or primary data for applications that can tolerate some data loss and longer recovery times during a regional disaster.

Key Takeaway

GRS is a strong choice for disaster recovery, ensuring data survival even if an entire Azure region fails, but involves a non-zero RPO and manual failover.
