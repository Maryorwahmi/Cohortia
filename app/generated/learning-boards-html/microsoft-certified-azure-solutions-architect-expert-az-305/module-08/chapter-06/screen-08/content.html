Read-Access Geo-Redundant Storage (RA-GRS)

Enhancing Read Availability with Geo-Redundancy

RA-GRS is similar to GRS but provides read-only access to the data in the secondary region, even when the primary region is operational. This is ideal for applications that can tolerate slightly stale data for reads.

  • •Offers all benefits of GRS (regional disaster protection).
  • •Read-only access to secondary region data during normal operations.
  • •Improves read availability and can offload read traffic.
  • •RPO: Minutes, RTO: Hours (same as GRS for writes/failover).
  • •Highest cost among the core redundancy options.
Use Case Example

Global applications, analytics/reporting workloads, or content delivery networks where read availability and performance are critical.

Key Takeaway

RA-GRS is the premium choice for geo-redundancy when read availability from the secondary region is a key requirement, even during normal operations.
