Locally Redundant Storage (LRS)

Protection within a Single Data Center

LRS is the most basic and cost-effective redundancy option. It replicates your data three times within a single data center in the primary region. This protects against common hardware failures like disk or server issues.

  • •Lowest cost option for Azure Storage.
  • •Protects against local hardware failures (e.g., disk, server).
  • •Does NOT protect against data center or region-wide outages.
  • •RPO: Minutes (potential data loss).
  • •RTO: Hours (for recovery in major data center event).
Use Case Example

Ideal for temporary data, development/test environments, or non-critical data that can be easily regenerated.

Key Takeaway

LRS is suitable when cost is paramount and data loss tolerance is high, but it offers limited protection against broader failures.
