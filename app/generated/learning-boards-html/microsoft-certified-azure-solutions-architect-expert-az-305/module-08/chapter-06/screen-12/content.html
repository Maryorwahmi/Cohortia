Configuring Object Replication

Preparing Source and Destination Accounts with Azure CLI

Setting up object replication requires two Azure Storage (General-purpose v2) accounts: a source and a destination. We'll use Azure CLI to create these resources and their respective containers.

  • •Define variables for resource groups, accounts, and containers.
  • •Create source resource group and StorageV2 account.
  • •Create a container in the source account.
  • •Repeat for destination resource group, StorageV2 account, and container.
Safety Note

Ensure both storage accounts are of type StorageV2 (General-purpose v2) as this is a prerequisite for object replication.

Key Takeaway

The initial setup involves creating two StorageV2 accounts and their containers in different regions to serve as the source and destination for replication.

# Azure CLI: Prepare Storage Accounts
# Variables
SOURCE_RG="SourceBlobRG"
SOURCE_ACCOUNT="sourcelogsacct$(head /dev/urandom | tr -dc a-z0-9 | head -c 8)"
SOURCE_CONTAINER="applogs"
DEST_RG="DestBlobRG"
DEST_ACCOUNT="destlogsacct$(head /dev/urandom | tr -dc a-z0-9 | head -c 8)"
DEST_CONTAINER="applogs-replica"
SOURCE_LOCATION="eastus"
DEST_LOCATION="westus"

# 1. Create Source Resource Group and Storage Account
az group create --name $SOURCE_RG --location $SOURCE_LOCATION
az storage account create \
    --name $SOURCE_ACCOUNT \
    --resource-group $SOURCE_RG \
    --location $SOURCE_LOCATION \
    --sku Standard_LRS \
    --kind StorageV2 \
    --allow-blob-public-access false

# 2. Create Source Container
az storage container create \
    --name $SOURCE_CONTAINER \
    --account-name $SOURCE_ACCOUNT \
    --auth-mode login
