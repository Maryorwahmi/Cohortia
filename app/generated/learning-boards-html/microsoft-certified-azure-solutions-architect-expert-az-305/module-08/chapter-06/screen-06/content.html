Zone-Redundant Storage (ZRS)

Synchronous Replication Across Availability Zones

ZRS replicates data synchronously across three Azure Availability Zones within the primary region. Each zone is a physically separate location with independent power, cooling, and networking.

  • •Protects against data center failures within a region.
  • •Synchronous replication ensures data consistency.
  • •RPO: 0 (zero data loss).
  • •RTO: Minutes (for automatic failover within the region).
  • •Higher cost than LRS, but significantly improved availability.
Use Case Example

Primary storage for mission-critical applications, databases, or virtual machines requiring high availability within a region.

Key Takeaway

ZRS is ideal for critical workloads needing high availability and zero data loss within a region, offering robust protection against localized outages.
