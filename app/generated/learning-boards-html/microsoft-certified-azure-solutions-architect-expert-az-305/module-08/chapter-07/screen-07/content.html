Traffic Manager Routing: Performance and Geographic

Optimizing user experience and meeting data residency requirements.

Performance Routing

Routes users to the endpoint with the lowest network latency from their location. Excellent for global applications needing optimal speed.

Geographic Routing

Routes users to specific endpoints based on the geographic location of their DNS query. Useful for data residency or localized content.

Example Scenario

Localized Content Delivery

A media company wants to serve region-specific content to its users. By using Geographic routing, Traffic Manager ensures that users in North America are directed to servers hosting North American content, while users in Asia are directed to Asian content servers, optimizing relevance and compliance.

Key Takeaway

Performance routing optimizes for lowest latency, crucial for global applications, while Geographic routing supports data residency and localized content delivery based on user location.
