Specialized Routing

Traffic Manager Routing: Multivalue and Subnet

Enhancing client-side resilience and IP-based traffic control.

Multivalue Routing

Returns multiple healthy endpoints in a single DNS response, allowing clients to retry if one fails. Enhances client-side resilience.

Subnet Routing

Maps end-user IP address ranges to specific endpoints. Useful for directing traffic from specific networks or for compliance.

Example Scenario

Corporate Network Access

A company needs to ensure that employees accessing an internal application from the corporate network (specific IP range) are routed to a dedicated, secure endpoint, while external users access a different public endpoint. Subnet routing allows this precise control, enhancing security and compliance.

Key Takeaway

Multivalue routing enhances client-side resilience by offering multiple healthy IPs, while Subnet routing provides granular control by directing traffic based on source IP address ranges.
