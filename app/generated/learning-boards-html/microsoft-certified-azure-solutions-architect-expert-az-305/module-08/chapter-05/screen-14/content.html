Advanced HA Terminology

Understanding Cosmos DB and Flexible Server HA

Multi-Master (Cosmos DB)

Allows write operations from any configured region in a globally distributed Cosmos DB account, enabling active-active deployments.

Consistency Model (Cosmos DB)

Defines the trade-off between consistency, availability, and latency for Cosmos DB data, with options like Strong, Session, and Eventual.

Zone-Redundant HA (Flexible Server)

Deploys primary and standby servers in different Availability Zones within a region with synchronous replication, ensuring RPO 0.

Summary Takeaway

Understanding these specialized HA features for Cosmos DB and Flexible Servers is crucial for architecting resilient and performant database solutions tailored to specific workload requirements.
