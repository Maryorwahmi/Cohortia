Flexible Server HA: PostgreSQL and MySQL

Zone-Redundant HA and Cross-Region Read Replicas

HA Capabilities

  • •
    Zone-Redundant HA: Primary and standby servers in different Availability Zones (same region).
  • •
    Synchronous Replication: Ensures zero data loss (RPO 0) within the region.
  • •
    Automatic Failover: Standby takes over in 60-120 seconds (low RTO).
  • •
    Read Replicas: Asynchronous replication to another region for cross-region DR.
Key Takeaway

Azure Database for PostgreSQL/MySQL Flexible Servers offer robust zone-redundant HA within a region and support cross-region DR via read replicas, balancing RPO, RTO, and cost.
