Setting Up Auto-Failover Groups: CLI Walkthrough (Part 1)

Creating the Failover Group Resource

# Azure CLI Command: Create an Auto-Failover Group
az sql failover-group create \
    --name <FAILOVER_GROUP_NAME> \
    --resource-group <RG_NAME> \
    --server <PRIMARY_SERVER> \
    --partner-server <SECONDARY_SERVER> \
    --partner-resource-group <RG_NAME> \
    --failover-policy Automatic \
    --grace-period 60 # Grace period in minutes

Command Breakdown

  • •
    --name: Unique name for your failover group.
  • •
    --server: The primary SQL server's name.
  • •
    --partner-server: The secondary SQL server's name.
  • •
    --failover-policy Automatic: Enables automatic failover to the secondary.
  • •
    --grace-period: Time (in minutes) before automatic failover is triggered.
Key Takeaway

The az sql failover-group create command establishes the cross-region relationship between your primary and secondary SQL servers, defining the automated failover behavior.
