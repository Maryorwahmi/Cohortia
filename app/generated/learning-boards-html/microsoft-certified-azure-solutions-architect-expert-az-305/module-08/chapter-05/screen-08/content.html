Setting Up Auto-Failover Groups: CLI Walkthrough (Part 2)

Adding Databases and Retrieving Listener Endpoints

# Azure CLI Command: Add database to Failover Group
az sql failover-group database add \
    --name <FAILOVER_GROUP_NAME> \
    --resource-group <RG_NAME> \
    --server <PRIMARY_SERVER> \
    --database <PRIMARY_DB>
# Azure CLI Command: Get Read/Write listener endpoint
az sql failover-group show \
    --name <FAILOVER_GROUP_NAME> \
    --resource-group <RG_NAME> \
    --server <PRIMARY_SERVER> \
    --query 'readWriteEndpoint.fullyQualifiedDomainName' \
    --output tsv

Post-Creation Steps

  • •
    Add Database: Integrate your specific database into the failover group for protection.
  • •
    Listener Endpoint: This is the FQDN your applications should use for connection.
  • •
    Application Update: Update application connection strings to use the listener endpoint.
  • •
    Testing: Crucially, test failover scenarios to validate your setup.
Key Takeaway

Adding databases to the failover group and configuring applications to use the listener endpoint are vital for achieving automated and seamless disaster recovery.
