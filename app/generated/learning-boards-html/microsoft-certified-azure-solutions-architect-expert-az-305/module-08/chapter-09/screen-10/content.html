Executing a DR Test Scenario

A step-by-step walkthrough of a simulated disaster

01

Announce Drill & Initiate VM Failover

Inform stakeholders. Use ASR for test failover of Azure VMs to an isolated network in the DR region.

02

SQL DB & AKS Failover/Restore

Initiate manual failover for Azure SQL DB Auto-Failover Group. Restore AKS cluster using Velero in DR region.

03

Update Global Traffic Routing

Update Azure Front Door or Traffic Manager to point to the DR endpoints.

04

Application Validation & RTO Measurement

Perform application-level validation and user acceptance testing. Measure time taken for each step and overall RTO.

Key Takeaway

A structured DR test scenario involves sequential failover of services, traffic redirection, thorough validation, and meticulous measurement to ensure the plan's effectiveness and identify areas for improvement.
