Key Concepts

Essential terms for AKS Disaster Recovery

Velero

An open-source tool for backing up and restoring Kubernetes cluster resources and persistent volumes.

etcd

The distributed key-value store that serves as Kubernetes' backing store for all cluster data.

Persistent Volume (PV)

A piece of storage in the cluster that has been provisioned by an administrator or dynamically.

Summary Takeaway

These core concepts form the foundation for designing and implementing effective disaster recovery strategies for AKS.
