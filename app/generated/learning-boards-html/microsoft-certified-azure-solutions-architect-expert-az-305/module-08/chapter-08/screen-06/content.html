Velero Installation Workflow

Setting up Velero on your primary AKS cluster.

1

Provision Azure Storage

Create an Azure Blob Storage account and container to store Velero backups.

2

Grant Permissions

Assign a Service Principal or Managed Identity with 'Storage Blob Data Contributor' role.

3

Install Velero on AKS

Deploy the Velero server to your primary AKS cluster, configuring it with the storage account.

Key Takeaway

A successful Velero installation requires careful preparation of Azure storage, proper permission assignment, and correct deployment to AKS.
