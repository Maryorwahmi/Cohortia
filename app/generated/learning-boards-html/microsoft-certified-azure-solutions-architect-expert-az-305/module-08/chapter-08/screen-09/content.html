Creating and Managing Velero Backups

Capturing your AKS cluster state and persistent data.

Velero allows you to create both on-demand and scheduled backups, targeting specific namespaces or the entire cluster, ensuring comprehensive data protection.

Key Takeaway

Regularly verify backup status using `velero backup get` and `describe` to ensure successful completion and readiness for restoration.

Pro Tip

For recurring backups, use `velero schedule create` to automate your RPO requirements.

Velero Backup Commandsbash
# Backup a specific namespacevelero backup create my-app-backup --include-namespaces my-app-namespace# Backup the entire cluster (excluding system namespaces)velero backup create full-cluster-backup --exclude-namespaces kube-system,velero# Monitor backup statusvelero backup getvelero backup describe my-app-backup# Schedule a daily backupvelero schedule create daily-backup --schedule="@every 24h" --include-namespaces my-app-namespace
