High Availability vs. Disaster Recovery

Understanding their distinct goals and applications.

High Availability (HA)

  • •Scope: Within a single operational environment (e.g., Azure region or Availability Zone).
  • •Goal: Prevent downtime and minimize service interruptions.
  • •Focus: Eliminate single points of failure through redundancy, automatic failover, and load balancing.
  • •Impact: Handles localized failures (e.g., VM crash, network switch failure).
  • •Measurement: Continuous operation, often in 'nines' of availability (e.g., 99.99%).
Example

Deploying two VMs in an Azure Availability Set within the same region to ensure uptime if one VM fails.

Disaster Recovery (DR)

  • •Scope: Across geographically separate locations (e.g., different Azure regions).
  • •Goal: Recover from large-scale, catastrophic events.
  • •Focus: Replicate data and applications to a secondary location and plan for failover.
  • •Impact: Handles widespread disasters (e.g., regional outage, natural disaster).
  • •Measurement: Recovery within acceptable RTO/RPO, potentially with some data loss.
Example

Using Azure Site Recovery to replicate VMs from one Azure region to another, enabling failover in case of a regional outage.
