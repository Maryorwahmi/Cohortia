Workload Coverage

Protecting Diverse Workloads with Azure Backup

From VMs to On-Premises Data

Azure Virtual Machines

  • Application-consistent backups for Windows VMs.
  • File-consistent backups for Linux VMs.
  • Snapshots transferred to Recovery Services Vault.
Benefit

Ensures data integrity for running applications.

Azure SQL Databases & PaaS DBs

  • Automated backups with configurable retention.
  • Supports point-in-time restore.
  • Covers SQL DB, PostgreSQL, MySQL.
Benefit

Enables precise recovery for critical database states.

Azure Files & Blobs

  • Back up entire Azure File shares to RSV.
  • Blobs leverage soft delete, versioning, object replication.
  • Azure Backup for Blobs offers centralized management.
Benefit

Secures shared file data and object storage.

On-Premises Workloads

  • Azure Backup Server for larger workloads.
  • MARS agent for files, folders, system states.
  • Extends cloud protection to your local data.
Benefit

Seamlessly integrate on-premises data into your cloud backup strategy.
