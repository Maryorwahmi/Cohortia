Key Concepts: Part 1

Essential terms for cost optimization and monitoring.

Right-sizing

Adjusting database resources (vCores, DTUs) to match actual workload demands, avoiding over or under-provisioning.

Serverless Compute

An Azure SQL Database option that automatically scales compute and pauses during inactivity, billed per second, ideal for intermittent workloads.

Reserved Instances (RIs)

Pre-purchasing Azure resources for 1 or 3 years to receive significant cost discounts for stable, long-running workloads.

Summary Takeaway

Effective cost optimization for Azure relational databases relies on intelligently matching resources to demand, leveraging flexible billing models, and committing to long-term usage when appropriate.
