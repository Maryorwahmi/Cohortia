Cost Governance

Managing Dev/Test Environments and Unused Resources

Preventing accidental spend and eliminating orphaned resources.

Key Strategies

  • •Cheaper Tiers for Non-Prod: Use serverless, basic, or free tiers for development and testing.
  • •Strict Governance: Implement policies to prevent deploying expensive production-grade resources in dev/test.
  • •Regular Identification: Periodically scan for databases or servers that are no longer in use.
  • •Automated Cleanup: Use scripts or Azure Automation to delete identified orphaned resources.

Example: Orphaned Resource

A project is completed, and the application is decommissioned. However, the Azure SQL Database and its server are forgotten and continue to run, incurring monthly costs for several months before being noticed. Regular audits could have prevented this.

Pro-Tip: Tagging

Implement a robust tagging strategy (e.g., 'Project', 'Owner', 'Environment') to easily identify and manage resources, especially for cleanup purposes.

Key Takeaway

Proactive management of non-production environments and diligent cleanup of unused resources are critical for cost-effective cloud operations.
