Reserved Instances and Elastic Pools

Commitment-based savings and resource sharing for predictable workloads.

Reserved Instances (RIs)

  • •Significant Discounts: Up to 72% savings compared to pay-as-you-go.
  • •Commitment: Requires 1-year or 3-year term commitment.
  • •Ideal For: Stable, long-running, predictable workloads.
  • •Availability: Azure SQL DB, Managed Instance, open-source engines.

Elastic Pools

  • •Resource Sharing: Multiple databases share a set of provisioned resources.
  • •Cost-Effective: Efficiently manages databases with fluctuating individual demands.
  • •Prevents Over-provisioning: Avoids allocating peak capacity to each database.
  • •Ideal For: SaaS applications with many databases, each with varying usage.
Key Takeaway

RIs provide deep discounts for consistent usage, while Elastic Pools optimize costs by sharing resources among databases with variable demands.
