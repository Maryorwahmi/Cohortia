Securing Data in Transit and Client-Side Encryption

TLS 1.2 and Always Encrypted for End-to-End Protection

Encryption in Transit (TLS 1.2)

All connections to Azure relational databases are encrypted by default using TLS 1.2, protecting data during transmission.

Always Encrypted (Client-Side)

Encrypts sensitive data columns within the database, ensuring data is never revealed in plaintext to the database engine. Encryption/decryption happens client-side.

Separation of Duties

With Always Encrypted, DBAs can manage the database without ever seeing sensitive data, enhancing security for PII.

Encryption Layers
Application Client
Decrypts Data
Database Engine
Encrypted Data

Always Encrypted keeps data encrypted even in the database.

Key Takeaway

Combine TLS for transit with Always Encrypted for client-side protection to achieve robust end-to-end data security.
