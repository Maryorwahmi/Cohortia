Sizing & Scaling

Serverless Compute

An Azure SQL Database compute option that automatically scales compute resources based on workload activity and pauses the database during inactive periods, billing only for used compute per second.

Key Takeaway

Excellent for cost savings on intermittent workloads, but requires careful consideration of potential cold-start latency.

Consideration

Not suitable for latency-sensitive production workloads that require constant availability and immediate response times.

Characteristics
  • Automatic compute scaling
  • Automatic pausing and resuming
  • Pay-per-second billing for compute
  • Cost-effective for intermittent workloads
  • Potential cold-start latency
Example Use Case

A development database used only during business hours, or a proof-of-concept application with infrequent user access.
