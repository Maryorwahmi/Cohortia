Deployment Model

Elastic Pools

A shared resource pool for multiple Azure SQL Databases, designed for multi-tenant applications or scenarios with many databases having varying and unpredictable resource demands. This model optimizes resource utilization and cost-effectiveness.

Key Takeaway

Ideal for managing fleets of databases with fluctuating usage, offering significant cost savings and simplified resource management.

Common Misconception

Elastic Pools are not suitable for databases with consistently high, predictable resource needs, as they might not get dedicated resources when needed most.

Characteristics
  • Shared compute and storage resources
  • Dynamic resource allocation
  • Cost-effective for many databases with fluctuating demands
  • Simplified management for large fleets
  • Suitable for multi-tenant applications
Example Use Case

A SaaS provider managing hundreds of customer databases, each with unique and varying usage patterns throughout the day.
