Deployment Model

Hyperscale

A service tier designed for extremely large databases, offering highly scalable storage (up to 100 TB) and the ability to scale compute and storage independently and non-linearly.

Key Takeaway

The optimal choice for applications with massive data growth and variable workloads requiring independent scaling of compute and storage.

Consideration

Hyperscale is currently only available for Azure SQL Database, not Azure SQL Managed Instance.

Characteristics
  • Supports up to 100 TB of storage
  • Independent scaling of compute and storage
  • Multi-tier architecture (compute, page servers, log service)
  • Rapid backup and restore capabilities
  • Ideal for large-scale data warehousing and analytics
Example Use Case

A financial services firm managing historical transaction data for regulatory compliance, requiring petabytes of storage and rapid data retrieval.
