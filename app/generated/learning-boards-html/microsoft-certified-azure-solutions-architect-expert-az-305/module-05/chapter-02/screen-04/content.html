Deployment Model

Single Database

An isolated Azure SQL Database with its own dedicated set of resources, ideal for individual applications with predictable performance needs or for development and testing environments.

Key Takeaway

Provides maximum isolation and control for individual databases, simplifying management and cost tracking.

Common Misconception

Thinking a single database is always the cheapest option. For many small, fluctuating databases, an Elastic Pool can be more cost-effective.

Characteristics
  • Fully isolated database
  • Dedicated compute and storage resources
  • Predictable performance
  • Granular control over resources and cost
  • Ideal for single applications or dev/test
Example Use Case

A small e-commerce website with a dedicated database for its product catalog and order management.
