Assessment Process

Steps to Identify Migration Blockers

1. Source DB

On-premises database.

2. DMA Scan

Analyze compatibility.

3. Review Report

Identify issues & recommendations.

4. Remediate

Address identified blockers.

Why Assess?
  • •Identify compatibility issues early.
  • •Estimate migration effort accurately.
  • •Prevent unexpected runtime problems.
Common Issues Found
  • •Unsupported SQL features (e.g., CLR, Service Broker).
  • •Deprecated syntax or functions.
  • •Performance bottlenecks in existing queries.
Key Takeaway

Pre-migration assessment, especially with tools like DMA, is a critical proactive step to ensure compatibility, estimate effort, and mitigate risks before data transfer begins.
