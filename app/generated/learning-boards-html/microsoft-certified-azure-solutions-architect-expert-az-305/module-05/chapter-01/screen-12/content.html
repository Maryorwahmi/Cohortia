Simulating Database Creation in Azure Portal

Explore key configuration options for Azure SQL Managed Instance and Azure Database for PostgreSQL (Flexible Server).

1Navigate to Azure Portal

Access the Azure Portal and search for 'Azure SQL Managed Instance'.

2Simulate Managed Instance Creation

Fill in details, focusing on 'Compute + Storage' and 'Networking' tabs. Note pricing tiers and VNet integration.

3Simulate PostgreSQL Creation

Search for 'Azure Database for PostgreSQL servers', select 'Flexible server', and explore its 'Compute + storage' and 'Networking' tabs.

Key Takeaway

Hands-on exploration of the Azure Portal's creation blades is essential for understanding the practical implications of architectural decisions for different database services.

Key Configuration Differences
Azure SQL Managed Instance
  • Deployment in a VNet for private IP.
  • Specific service tiers (General Purpose, Business Critical).
  • SQL Server Agent, CLR, cross-DB queries.
Azure DB for PostgreSQL (Flexible)
  • Flexible server deployment options.
  • Compute tiers (Burstable, General Purpose, Memory Optimized).
  • PostGIS support, open-source extensions.
Scenario Context

Migrating & Greenfield Projects

Your organization is migrating an on-premises SQL Server app and starting a new microservices project with PostgreSQL. This simulation helps you understand the distinct setup processes and options for each, informing your design choices for both scenarios.
