Understanding Vertical Scaling

Increasing resources of a single database instance

What is Vertical Scaling?

Vertical scaling, or 'scaling up,' involves adding more resources like CPU, memory, and IOPS to a single database server. This enhances its capacity to handle more workload.

How it Works in Azure

For Azure SQL Database and open-source engines, this means increasing DTUs, vCores, or upgrading the pricing tier. It's often the simplest first step for performance bottlenecks.

Limitations & Costs

While easy, vertical scaling has inherent limits based on maximum instance resources and incurs higher costs as you provision more powerful machines.

Scale Up: Adding Resources

Example: Upgrading from 4 vCores to 8 vCores.

Key Takeaway

Vertical scaling is a quick fix for performance but has finite limits and becomes increasingly expensive for sustained growth.
