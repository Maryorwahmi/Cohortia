Key Concepts

Essential terms from this chapter

Vertical Scaling

Increasing the resources (CPU, memory, IOPS) of a single database instance to handle more load.

Horizontal Scaling

Distributing the workload across multiple database instances to achieve greater scalability.

Read Replicas

Asynchronously replicated copies of a primary database used to offload read-heavy workloads.

Summary Takeaway

Mastering vertical and horizontal scaling, including read replicas, is fundamental for designing resilient and high-performing Azure database solutions.
