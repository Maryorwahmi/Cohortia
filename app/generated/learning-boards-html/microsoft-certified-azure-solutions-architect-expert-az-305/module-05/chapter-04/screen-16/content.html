Key Concepts

Continuing your review of essential terms

Sharding

Partitioning a single logical database into multiple independent physical databases (shards) for extreme scalability.

Sharding Key

The column or set of columns used to determine which shard a row of data belongs to.

Indexing

Creating data structures to improve the speed of data retrieval operations on a database table.

Summary Takeaway

Sharding, sharding keys, and indexing are advanced techniques crucial for achieving extreme scalability and optimizing database performance in Azure.
