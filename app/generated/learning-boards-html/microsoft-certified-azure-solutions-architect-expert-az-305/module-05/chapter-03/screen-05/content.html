Azure SQL HA

HA in Azure SQL: General Purpose Tier

How Azure ensures resilience for compute and storage.

Key Principles

  • •Compute-Storage Separation: Database engine (compute) is distinct from data files (storage).
  • •Highly Available Storage: Data is stored on Locally Redundant Storage (LRS) or Zone-Redundant Storage (ZRS).
  • •Automatic Compute Failover: If a compute node fails, Azure automatically provisions a new one.
  • •Seamless Reattachment: The new compute node quickly reattaches to the existing, healthy storage.
Why it Matters

This architecture minimizes downtime by allowing rapid recovery from compute failures without data loss, as storage remains intact.

General Purpose HA Flow

Compute Node (VM)
Highly Available Storage (LRS/ZRS)
Failure Detected!
New Compute Node Provisioned
New Compute Node
Reattached Storage
Key Takeaway

Azure SQL General Purpose tier provides built-in HA through automatic compute failover and highly available storage.
