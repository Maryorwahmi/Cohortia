DR Strategy

Geo-replication for Regional Resilience

Asynchronously replicating data across Azure regions.

Active Geo-replication Overview

  • •Asynchronous Replication: Transactions replicated from primary to secondary.
  • •Cross-Region Deployment: Secondary databases in different Azure regions.
  • •Up to Four Secondaries: Supports multiple readable secondary replicas.
  • •DR & Read Scaling: Used for disaster recovery and offloading read workloads.
Failover Mechanism

Initiate a planned or unplanned failover to a secondary region manually or programmatically during a regional outage.

Geo-replication Flow

Primary DB (Region A)
Secondary DB (Region B)
Asynchronous Replication
Regional Outage (Region A)
Failover to Secondary (Region B)
Key Takeaway

Geo-replication provides cross-region DR, enabling recovery from regional outages with RTO/RPO dependent on replication lag.
