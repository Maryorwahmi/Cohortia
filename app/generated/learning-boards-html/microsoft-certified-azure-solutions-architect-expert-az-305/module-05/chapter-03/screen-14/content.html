Chapter Summary

Key Concepts: Part 1

Essential terms for High Availability and Disaster Recovery.

High Availability (HA)

Ensures continuous operation within a single region despite component failures.

Disaster Recovery (DR)

Strategies to recover from catastrophic events rendering an entire region unavailable.

Availability Zones

Physically separate locations within an Azure region, protecting against zone-level failures.

Active Geo-replication

Asynchronous replication of Azure SQL DB/MI to a secondary region for DR and read scaling.

Failover Groups

Manages geo-replication and failover for a collection of databases as a single unit.

Summary Takeaway

HA ensures intra-region resilience, while DR provides inter-region recovery, both crucial for business continuity.
