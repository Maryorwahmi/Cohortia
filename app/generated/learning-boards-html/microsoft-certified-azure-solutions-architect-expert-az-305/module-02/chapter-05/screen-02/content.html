Learning Objectives

Mastering Privileged Identity Management Fundamentals

LearnUnderstandApplyMaster
01

Explain JIT and JEA Principles

Understand Just-In-Time and Just-Enough-Access, and their critical role in securing privileged roles. This knowledge forms the foundation for minimizing the attack surface.

VERIFIED COMPETENCY MILESTONE
02

Design PIM for Azure AD & Resource Roles

Learn to design comprehensive PIM solutions that cover both Azure Active Directory roles and Azure resource roles. This ensures consistent security across your cloud environment.

VERIFIED COMPETENCY MILESTONE
03

Configure PIM Activation Settings

Gain expertise in configuring PIM activation settings, including crucial elements like approval workflows and multi-factor authentication requirements. These controls are vital for secure elevation.

VERIFIED COMPETENCY MILESTONE
04

Implement Time-Bound Access

Master the implementation of time-bound access and access reviews for privileged role assignments. This ensures permissions are always current and aligned with the principle of least privilege.
