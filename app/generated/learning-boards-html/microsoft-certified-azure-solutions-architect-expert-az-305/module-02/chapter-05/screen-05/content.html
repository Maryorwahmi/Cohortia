PIM Role Eligibility and Scope

Transitioning from Permanent to Eligible Assignments

Key Steps in PIM Design

  • Identify Privileged Roles: Pinpoint all high-risk roles across Azure AD and Azure resources.
  • Convert to Eligible: Change standing, permanent assignments to eligible assignments.
  • Define Activation Controls: Configure settings for how users activate their eligible roles.

Eligible vs. Permanent Assignments

Eligible: Activate when needed, time-bound.
Permanent: Always active, high risk.

PIM's core function is to shift from permanent, 'always-on' privileged access to eligible, 'just-in-time' access, significantly reducing the attack surface.

PIM Scope: Azure AD & Resource Roles

  • Azure AD Roles: Global Administrator, User Administrator, Application Administrator.
  • Azure Resource Roles: Owner, Contributor, User Access Administrator for subscriptions/resource groups.
Key Takeaway

PIM enables you to manage and monitor access for both Azure AD and Azure resource roles, converting standing assignments to eligible ones for enhanced security.
