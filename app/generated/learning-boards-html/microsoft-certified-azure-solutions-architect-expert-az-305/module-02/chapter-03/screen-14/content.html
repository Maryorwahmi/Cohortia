Key Concepts

Essential terms for external identity solutions

Azure AD B2B Collaboration

A feature for inviting external users (guest users) from other organizations or identity providers to access your internal Azure AD-protected resources.

Guest User

An external user invited to an Azure AD tenant via B2B collaboration, maintaining their original identity and credentials.

Azure AD B2C (Business-to-Consumer)

A separate, highly customizable identity service designed for customer-facing applications, allowing customers to sign up and sign in using local accounts or social identity providers.

Summary Takeaway

Azure AD B2B facilitates partner access with existing identities, while B2C provides a dedicated, customizable identity solution for customer-facing applications.
