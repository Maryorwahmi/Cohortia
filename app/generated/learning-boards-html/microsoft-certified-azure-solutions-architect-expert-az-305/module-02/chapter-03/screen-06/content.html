Designing B2B Invitations

Controlling how guest users join your tenant

B2B Invitation Methods

1

Direct Invitation

Administrators or authorized users send direct invitations via Azure portal or PowerShell.

2

Self-Service Sign-up

External users can sign up for applications, often requiring approval workflows.

3

Microsoft Graph API

Programmatic invitation for automated onboarding and large-scale scenarios.

Example Scenario

A project manager invites a partner to a Teams channel, while a separate self-service portal handles broader vendor registrations.

Governance Controls

  • Who can invite guests: Restrict invitation permissions to specific administrative roles or users.

  • Invitation restrictions: Allow or deny invitations from specific domains (e.g., only @partnercompany.com).

  • Self-service sign-up settings: Configure custom user flows for external users to request access.

Key Takeaway

Choose appropriate invitation methods and apply strict governance controls to manage who can invite guests and from which domains.
