Configuring B2C User Flows

Defining the customer journey for sign-up and sign-in

What are User Flows?

User flows are pre-built, configurable policies in Azure AD B2C that define the user experience for various identity tasks. They guide customers through processes like sign-up, sign-in, and profile editing.

Common User Flow Types

  • Sign-up and Sign-in: Combines both processes into a single, seamless experience.

  • Password Reset: Guides users through recovering access to their accounts.

  • Profile Editing: Allows users to update their personal information.

Integration & Branding

  • Standard Protocols: Integrate applications using OpenID Connect or OAuth 2.0.

  • Custom Branding: Customize the UI of user flows to match your application's look and feel.

Example User Flow

A sign-up user flow collects first name, last name, and email, then requires email verification before account creation.

Key Takeaway

B2C user flows define the customer's identity journey, offering extensive customization and integration options for a branded experience.
