Key Concepts

Advanced concepts for managing external access

User Flow (B2C)

Pre-built, configurable policies in Azure AD B2C that define the user experience for sign-up, sign-in, password reset, and profile editing.

Cross-Tenant Access Settings

Azure AD settings that allow organizations to manage how external Azure AD tenants collaborate, defining inbound and outbound trust relationships for B2B.

Identity Provider (IdP)

A service that authenticates users and provides identity information to other services (e.g., Google, Facebook, Azure AD).

Summary Takeaway

User Flows customize B2C experiences, Cross-Tenant Access Settings govern B2B relationships, and Identity Providers authenticate users across various services.
