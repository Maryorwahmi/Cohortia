Access Control

Azure AD Group Types

Azure AD offers different group types to streamline access management and facilitate collaboration across your organization.

Security Groups

  • Used for granting access to resources.
  • Can be static or dynamic.

Microsoft 365 Groups

  • For collaboration (shared mailbox, calendar, etc.).
  • Also provide access to resources.
Example Scenario

A dynamic group for 'Sales Team' automatically includes all users with user.department -eq "Sales". New hires in Sales automatically get access to sales applications without manual intervention.

Dynamic Groups

Automated Membership Management

1. Define Rule

Set criteria based on user attributes (e.g., Department, Location).

2. Automatic Population

Azure AD continuously evaluates users against the rule.

3. Dynamic Access

Users automatically gain/lose access based on attribute changes.

Key Takeaway

Dynamic groups automate membership based on user attributes, significantly reducing administrative overhead and ensuring consistent access control.
