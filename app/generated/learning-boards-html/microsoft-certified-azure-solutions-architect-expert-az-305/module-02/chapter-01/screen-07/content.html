Identity Management

Understanding Azure AD User Types

Azure AD accommodates various user identities, each with distinct origins and management considerations, crucial for a flexible access control strategy.

  • Cloud-Only Users: Managed directly in Azure AD.
  • Synchronized Users: From on-premises AD via Azure AD Connect.
  • Guest Users: External identities for collaboration.
Scenario Card

A company uses Azure AD for cloud apps but still has an on-premises file server. Synchronized users allow employees to use one set of credentials for both cloud and on-premises resources, simplifying their experience.

User Lifecycle

Managing User Identities

1. Provisioning

Creating new user accounts (manual, sync, or self-service).

2. Management

Updating attributes, password resets, role assignments.

3. Deprovisioning

Disabling or deleting accounts upon departure.

Key Takeaway

Effective user management in Azure AD involves understanding cloud-only, synchronized, and guest users, and managing their lifecycle from provisioning to deprovisioning.
