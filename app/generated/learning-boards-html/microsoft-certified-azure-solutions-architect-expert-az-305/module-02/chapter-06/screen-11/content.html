Module 2 › Chapter 6 › Creating an Access Review for a Group
1. Prepare

Create a test Azure AD group (e.g., `Review_Group_Finance`) and add test users. Ensure you have Azure AD Premium P2 license.

Example: Add yourself and a few test accounts.
2. Configure Settings

Set Frequency (Quarterly), Duration (7 days), Reviewers (e.g., Group Owners), and enable Auto-apply results with 'Remove access' for non-responders.

Enable recommendations and justification.
3. Create Review

Navigate to Azure AD > Identity Governance > Access reviews. Click '+ New access review,' select 'Groups,' choose your test group, and configure the settings as outlined.

Example: Name it 'Finance Group Quarterly Review'.
Key Takeaway

Creating an access review involves defining the scope, configuring settings like frequency and reviewers, and setting up automated actions for efficient governance.
