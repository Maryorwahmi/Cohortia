Module 2 › Chapter 6 › Automating Access Review Actions
Auto-Apply Results

When enabled, Azure AD automatically removes access for users denied during a review or those who don't respond. This streamlines remediation but requires careful initial testing.

Recommendation: Test with 'Take recommendations' first.
If Reviewers Don't Respond

Define the action to take if reviewers fail to complete their task. Options include 'Remove access,' 'Take recommendations,' or 'No change.' For security, 'Remove access' is often preferred.

Example: Automatically remove access for non-responsive reviewers.
Recommendations

Azure AD can provide recommendations based on user activity (e.g., sign-in frequency) to help reviewers make informed decisions. Enabling this feature enhances review accuracy.

Example: Use 'user hasn't signed in for 90 days' recommendations.
Key Takeaway

Automating access review actions significantly improves efficiency and security, but requires careful planning and testing to prevent unintended consequences.
