Module 2 › Chapter 6 › Defining the Scope of Access Reviews
Scope: Azure AD Groups

Reviewing membership of Azure AD security and Microsoft 365 groups is vital for controlling access to resources like file shares, SharePoint sites, and applications granted via group membership.

Example: Review 'Finance Department Access' group.
Scope: Enterprise Applications

Reviewing access to enterprise applications is crucial for sensitive data or applications with broad permissions, preventing unauthorized access and ensuring only necessary users are assigned.

Example: Review access to 'HR Management System'.
Scope: PIM Eligible Assignments

Reviewing eligible assignments for Azure AD PIM roles ensures that only individuals who genuinely need privileged access are assigned, and that their eligibility remains justified.

Example: Review eligibility for 'Global Administrator' role.
Key Takeaway

Accurately defining the scope of your access reviews—whether groups, applications, or PIM roles—is the foundational step for effective access governance.
