Module 2 › Chapter 6 › Access Review Assessment Scenario
Scenario

An organization requires quarterly reviews for guest user access to sensitive applications. Access must be automatically revoked if denied or if the reviewer doesn't respond.

Focus: Automated revocation for guest users.
Key Settings

To ensure automatic revocation, two settings are critical: 'Auto apply results to resource' must be enabled, and 'If reviewers don't respond' must be set to 'Remove access.' The frequency must also be set to 'Quarterly.'

These settings ensure automatic action in all cases.
Assessment Question

Which two Azure AD access review settings are crucial for automatically revoking access for guest users if their access is denied or their reviewer doesn't respond?

  • A) Frequency: Quarterly & If reviewers don't respond: Take recommendations
  • B) Auto apply results to resource: Enable & If reviewers don't respond: Remove access
  • C) Frequency: Quarterly & Auto apply results to resource: Enable
  • D) Auto apply results to resource: Enable & If reviewers don't respond: No change
Correct Answer: B
Key Takeaway

Automated revocation requires careful configuration of both the auto-apply results setting and the action for non-responsive reviewers.
