Security

Security Considerations

The Azure AD Connect server is a critical component. Protecting it and its associated processes is essential for the security of your entire hybrid identity environment.

Server Hardening

Install Azure AD Connect on a dedicated, domain-joined member server (never a domain controller). Follow Microsoft's security hardening guidelines.

Least Privilege

Use a dedicated service account with the minimum necessary permissions for synchronization. Regularly audit its permissions.

Access Control & Auditing

Implement strict access controls to the server. Consider MFA for administrators and regularly audit configurations and synchronization rules.

Security Posture

Member Server

Service Account

Secure the server, use least privilege, and implement strict access controls for administrators.
