Check Your Understanding

An organization requires all cloud authentication to be validated directly against their on-premises Active Directory due to strict security mandates. Which authentication method should be recommended?

Scenario Analysis

The core requirement is that authentication must occur on-premises, preventing password hashes from leaving the network. This immediately points towards methods that keep validation local.

Key Takeaway

For strict on-premises validation, Pass-through Authentication (PTA) is the recommended method, as it ensures credentials are checked against local domain controllers.

Recommended Method

Pass-through Auth (PTA)

On-Prem DC

PTA agents forward authentication requests to on-premises DCs for validation.
