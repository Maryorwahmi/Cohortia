Federation with ADFS

Federation, typically using Active Directory Federation Services (ADFS), provides the most control and flexibility, but introduces significant operational complexity.

How it Works

When a user signs in, Azure AD redirects them to the on-premises ADFS server. ADFS authenticates the user against on-premises AD and issues a security token. Azure AD trusts this token to grant access.

Key Takeaway

Federation offers advanced control and integration capabilities but requires managing a dedicated ADFS infrastructure, making it more complex than PHS or PTA.
