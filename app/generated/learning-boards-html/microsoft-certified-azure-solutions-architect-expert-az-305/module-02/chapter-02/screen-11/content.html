Assessing Identity Protection Strategy

Understanding risk-based access control.

Scenario

An organization wants to block 'High' risk sign-ins and require MFA for 'Medium' risk sign-ins.

Essential Features
  • Azure AD Identity Protection: Detects user and sign-in risks.
  • Conditional Access: Enforces policies based on detected risks (e.g., block, require MFA).
Key Takeaway

Azure AD Identity Protection and Conditional Access are the essential services for implementing risk-based access control.
