Configuring a Risk-Based Conditional Access Policy

Hands-on: Enforcing MFA for risky sign-ins.

Policy Steps
  • Prerequisites: Azure AD Premium P2 license.
  • Policy Creation: Name, include/exclude users, select all cloud apps.
  • Conditions: Set 'Sign-in risk' to 'High' and 'Medium.'
  • Grant Controls: Require 'Multi-Factor Authentication.'
  • Deployment: Start with 'Report-only' mode, then enable for enforcement.
Key Takeaway

Configuring a Conditional Access policy to require MFA for risky sign-ins demonstrates the practical integration of Identity Protection features.
