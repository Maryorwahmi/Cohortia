Multi-Factor Authentication (MFA)

The non-negotiable security layer.

Verification Factors
  • Something you know: Password, PIN.
  • Something you have: Mobile app (Authenticator), hardware token, FIDO2 key.
  • Something you are: Biometrics (fingerprint, facial scan).
  • Azure AD Supported Methods: Microsoft Authenticator app, FIDO2, hardware tokens, phone call/SMS.
Key Takeaway

MFA is a critical security control requiring multiple verification factors, significantly reducing the risk of account compromise even if passwords are stolen.
