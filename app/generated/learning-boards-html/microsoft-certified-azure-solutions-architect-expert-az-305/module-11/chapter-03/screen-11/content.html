ExpressRoute Peering

Understanding Peering Types

Connecting to different Azure services over ExpressRoute.

Peering Types Explained

  • **Azure Private Peering:** Access Azure IaaS (VMs) and private PaaS (e.g., private endpoints) in VNets using private IPs.
  • **Azure Microsoft Peering:** Access Azure PaaS (Storage, SQL DB) and Microsoft 365 services using public IPs. Requires NAT and filtering.
  • **Azure Public Peering (Deprecated):** Previously for all Azure public services; replaced by Microsoft Peering.
Key Takeaway

Properly configuring Private and Microsoft Peering is essential for comprehensive and secure ExpressRoute connectivity to Azure services.

ExpressRoute Peering Types
Private Peering: IaaS & Private PaaS
Microsoft Peering: Public PaaS & M365
Public Peering: Deprecated
Important Note

Microsoft Peering requires careful NAT configuration and route filtering to prevent unintended traffic routing and security risks.
