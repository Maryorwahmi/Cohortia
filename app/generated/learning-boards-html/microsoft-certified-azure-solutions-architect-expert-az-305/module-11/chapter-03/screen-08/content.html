Setting Up Site-to-Site VPN: Part 2

Creating the Local Network Gateway and VPN Connection.

Steps Overview

  • **Local Network Gateway:** Represents your on-premises VPN device and network.
  • **VPN Connection:** Links Azure VPN Gateway to Local Network Gateway.
  • **Shared Key:** Critical for authentication; must match on both sides.
  • **Verification:** Check connection status in Azure portal or CLI.
Key Takeaway

The Local Network Gateway and the VPN Connection with a matching shared key complete the Site-to-Site VPN tunnel setup.

Azure CLI
# Create a Local Network Gateway (represents your on-premises VPN device)
az network local-gateway create -g MyHybridRG -n MyOnPremisesGateway \
  --gateway-ip-address <Your_OnPrem_Public_IP> \
  --address-prefixes <Your_OnPrem_CIDR1> <Your_OnPrem_CIDR2> \
  --location eastus

# Create the VPN Connection
az network vnet gateway connection create -g MyHybridRG -n MyS2SConnection \
  --vnet-gateway1 MyVpnGateway --local-gateway2 MyOnPremisesGateway \
  --connection-type IPsec --shared-key <Your_Shared_Secret> \
  --no-wait
Important Note

The `gateway-ip-address` and `address-prefixes` must accurately reflect your on-premises network configuration.
