Setting Up Site-to-Site VPN: Part 1

Creating the Public IP and Azure VPN Gateway.

Steps Overview

  • **Prerequisites:** Ensure `MyHubVNet` with `GatewaySubnet` exists.
  • **Create Public IP:** Provision a static Standard SKU Public IP for the VPN Gateway.
  • **Create VPN Gateway:** Deploy the Route-Based VPN Gateway into `GatewaySubnet`.
  • **Wait for Deployment:** Gateway creation can take 30-45 minutes.
Key Takeaway

The Public IP and VPN Gateway form the Azure-side endpoint for your secure Site-to-Site VPN connection.

Azure CLI
# Create a Public IP for the VPN Gateway
az network public-ip create -g MyHybridRG -n VpnGwPIP -l eastus --sku Standard --allocation-method Static

# Create a VPN Gateway in GatewaySubnet
az network vnet gateway create -g MyHybridRG -n MyVpnGateway \
  --location eastus --public-ip-address VpnGwPIP \
  --vnet MyHubVNet --gateway-type Vpn --sku VpnGw1 --vpn-type RouteBased \
  --no-wait
Pro Tip

Use `--no-wait` for gateway creation, then monitor status with `az network vnet gateway show --query provisioningState`.
