Network Watcher Tools

Packet Capture & VPN Diagnostics

Specialized tools for deep-dive network analysis and troubleshooting hybrid connectivity issues.

Packet Capture

Captures network traffic to and from a VM, enabling deep-dive analysis of network communications, similar to Wireshark.

Use Case: Application Debugging

Crucial for debugging complex application-level issues or identifying unexpected traffic patterns at the protocol level.

Misconception

Packet capture is for low-level analysis, not a general connectivity check. Use IP Flow Verify first for NSG issues.

VPN Diagnostics

Provides detailed information about VPN Gateway connections, specifically designed for diagnosing hybrid connectivity issues.

Why it Matters

Essential for maintaining robust hybrid cloud architectures by quickly identifying and resolving VPN tunnel failures or performance bottlenecks.

Key Takeaway

Packet Capture offers granular traffic analysis for VMs, while VPN Diagnostics is critical for troubleshooting hybrid VPN connections.
