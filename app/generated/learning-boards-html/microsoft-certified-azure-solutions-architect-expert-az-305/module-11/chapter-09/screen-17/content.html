Key Concepts

Advanced Visibility and Optimization Terms

NSG Flow Logs

Logs of IP traffic flowing through an NSG, stored in a Storage Account, providing detailed traffic information.

Traffic Analytics

A solution that processes NSG Flow Logs to provide visualizations, identify hot spots, and uncover security threats.

Accelerated Networking

A feature for supported VMs that provides ultra-low network latency and higher throughput.

Proximity Placement Groups

An Azure feature to co-locate VMs as close as possible to minimize inter-VM latency.

Azure Monitor

The primary monitoring service in Azure, used for collecting, analyzing, and acting on telemetry data.

Summary Takeaway

Advanced network visibility and optimization tools are crucial for maintaining high-performing, secure, and cost-efficient Azure environments.
