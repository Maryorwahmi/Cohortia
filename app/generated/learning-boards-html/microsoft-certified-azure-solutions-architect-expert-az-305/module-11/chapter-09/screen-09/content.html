NSG Flow Logs: Capturing Network Traffic Data

Records detailed information about IP traffic flowing through an NSG, stored in an Azure Storage Account.

What is Recorded

Source/destination IP, port, protocol, traffic direction, applied NSG rule, and whether traffic was allowed or denied.

Storage Location

Logs are stored in an Azure Storage Account, providing a durable and auditable record of network activity.

Common Mistake

Not enabling flow logs on critical NSGs, leading to blind spots in network visibility and security auditing.

Security & Compliance

Crucial for security auditing, investigating incidents, and meeting compliance requirements for network traffic records.

Traffic Pattern Analysis

Helps identify unexpected communication flows, bandwidth-intensive applications, and overall network behavior.

Key Takeaway

NSG Flow Logs provide essential, detailed records of network traffic for security, compliance, and pattern analysis.
