Network Watcher Tools

Connection Troubleshoot & Monitor

Two distinct tools for assessing end-to-end connectivity and continuously tracking network performance.

Connection Troubleshoot

Provides a point-in-time check of connectivity between a source VM and a destination (VM, FQDN, or IP).

Key Insights

Offers detailed information on latency, packet loss, and identifies any blocking components like NSGs or firewalls.

Reactive Diagnostic

Best used for immediate, on-demand troubleshooting when a connectivity issue is actively occurring.

Connection Monitor

Continuously monitors connectivity and latency between source and destination over extended periods.

Alerting Capabilities

Can be configured to alert on performance degradation or failures, enabling proactive problem resolution.

Key Takeaway

Use Connection Troubleshoot for immediate diagnostics and Connection Monitor for continuous, proactive network performance tracking.
