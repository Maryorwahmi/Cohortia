Azure Application Gateway: Intelligent Web Traffic Management

Advanced Layer 7 capabilities for HTTP/HTTPS applications

Azure Application Gateway is a Layer 7 (application layer) load balancer. It provides advanced traffic management capabilities specifically for web applications (HTTP/HTTPS) by understanding the structure of HTTP requests.

Key Takeaway

Application Gateway is ideal for publicly exposed web applications requiring WAF, SSL offloading, and intelligent Layer 7 routing within a region.

Example Scenario

A regional e-commerce website needing to protect against web attacks and offload SSL encryption from its backend web servers.

Application Gateway Core Function

Layer 7 Operation

Inspects HTTP/HTTPS requests for intelligent routing.

WAF & SSL Offloading

Enhances security and performance for web apps.

URL/Host-based Routing

Directs traffic based on URL paths or hostnames.
