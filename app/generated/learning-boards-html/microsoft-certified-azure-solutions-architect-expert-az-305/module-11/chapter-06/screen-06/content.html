Feature Spotlight

Load Balancer: Distribution, Health, and Persistence

Exploring hash-based distribution, health probes, and session persistence

  • Hash-based distribution: Traffic is distributed based on a 5-tuple hash (source IP, port, destination IP, port, protocol).

  • Health Probes: Monitors backend instance health, ensuring traffic only goes to healthy servers.

  • Session Persistence: Configurable for client IP affinity, routing requests from the same client to the same backend.

Common Mistake

Trying to use Azure Load Balancer for Layer 7 features like URL-based routing or SSL offloading, which it cannot do.

Load Balancer Feature Cards

Hash-based Distribution

Ensures even traffic spread using 5-tuple hash.

Health Probes

Monitors backend health to ensure reliability.

Session Persistence

Maintains client-to-server affinity.

Port Forwarding

Direct access to specific backend VM ports.

Pro Tip

For non-HTTP/S applications requiring basic load balancing within a VNet, Azure Load Balancer is the most cost-effective and performant choice.
