Chapter Review

Key Concepts: Core Services

Essential terms to remember from this chapter

Azure Load Balancer

A Layer 4 (transport layer) service that distributes network traffic among healthy backend instances.

Azure Application Gateway

A Layer 7 (application layer) service providing advanced HTTP/HTTPS load balancing, WAF, and SSL offloading.

Azure Front Door

A global Layer 7 entry-point service offering global load balancing, WAF at the edge, and web acceleration.

Summary Takeaway

Azure's load balancing solutions provide a spectrum of capabilities from regional Layer 4 distribution to global Layer 7 web acceleration and security, each tailored for specific architectural needs.
