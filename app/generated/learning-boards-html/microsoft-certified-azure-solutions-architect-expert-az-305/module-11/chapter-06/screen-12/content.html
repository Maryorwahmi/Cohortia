Traffic Manager: Diverse Routing Methods

Choosing the right method for performance, priority, or geography

Traffic Manager routing methods allow you to control how client requests are directed to the most appropriate service endpoint based on various criteria. This flexibility is crucial for optimizing performance, ensuring high availability, and meeting specific business requirements.

Key Takeaway

Selecting the appropriate Traffic Manager routing method is vital for achieving desired global traffic distribution, failover, and user experience goals.

Example Application

A global SaaS platform using 'Performance' routing for daily operations and 'Priority' routing for disaster recovery across regions.

Traffic Manager Routing Methods

Priority

Active/passive failover.

Weighted

Distributes traffic by assigned weights.

Performance

Routes to lowest latency endpoint.

Geographic

Routes based on user location.

Multivalue

Returns multiple healthy endpoints.

Subnet

Maps IP ranges to endpoints.
