Azure Load Balancer: The Layer 4 Workhorse

Distributing TCP/UDP traffic within a Virtual Network

Azure Load Balancer is a Layer 4 (transport layer) load balancer. It distributes incoming network traffic among healthy virtual machines or instances within a backend pool. It operates at the IP address and port level, forwarding traffic based on source IP and port, destination IP and port, and protocol.

Key Takeaway

Azure Load Balancer is ideal for simple, high-performance Layer 4 load balancing of TCP/UDP traffic, providing high availability for internal and external services.

Example Use Case

Load balancing a cluster of database servers or gaming servers that require direct TCP/UDP connections without HTTP-specific routing.

Load Balancer Core Function

Layer 4 Operation

Distributes TCP/UDP traffic based on IP address and port.

Backend Pool Distribution

Forwards traffic to healthy VMs or instances.

Non-HTTP/S Specific

Suitable for any TCP/UDP application, not just web traffic.
