Mandating NSG & Private Link Usage

Ensuring secure network communication with policy enforcement

Policy-Driven Security Enhancements

  • Mandate NSG Association: Require all subnets to have an associated Network Security Group for traffic filtering.
  • Require Private Link/Service Endpoints: Mandate private connectivity for specific PaaS services (e.g., Azure SQL, Storage).
  • Audit Network Configurations: Continuously identify and report non-compliant network resources.
Key Takeaway

Policies requiring NSGs and Private Link ensure robust, private network communication, significantly bolstering your Azure network's security posture.

Why these policies matter

Enhanced Security

NSGs act as virtual firewalls, while Private Link removes public internet exposure for PaaS services.

Compliance Assurance

Helps meet regulatory requirements by ensuring secure data handling and network segmentation.

Example Scenario

A policy ensures all subnets hosting critical application VMs have an NSG attached, and all connections to Azure Storage accounts from these VMs use Private Link.
