Load Balancers & NVA HA

Distributing traffic and ensuring continuous service for network appliances

Leveraging Azure Load Balancers

  • Use Azure Load Balancer or Application Gateway to distribute traffic.
  • Distributes traffic across multiple backend instances for high availability.
  • Ensures that if one instance fails, others can continue to serve requests.
Key Takeaway

Load balancers are critical for distributing application traffic and ensuring NVA high availability, preventing single points of failure in your network.

Network Virtual Appliance (NVA) High Availability

Active-Passive or Active-Active

Deploy NVAs in redundant configurations to ensure continuous operation.

Failover Mechanisms

Utilize Azure Load Balancer or custom scripts for automatic failover.

Example Scenario

Two Azure Firewall NVAs deployed in an active-active configuration behind an Azure Load Balancer, ensuring traffic continues to flow even if one firewall fails.
