How Service Endpoints Work

VNet Subnet Extension

Extends your Virtual Network's private address space and identity to Azure PaaS services.

Azure Backbone Routing

Traffic from the enabled subnet to PaaS services traverses the secure Azure backbone, not the public internet.

Enhanced Security

Removes public internet exposure for specific traffic and allows VNet/subnet-based access filtering.

Example Scenario

A VM in an enabled subnet accesses Azure Storage privately over the Azure backbone, even though the storage account retains its public IP.

Definition

Azure Service Endpoints

Securely connect your VNet to Azure PaaS services over the Azure backbone.

Direct Connectivity

Traffic bypasses the public internet, flowing directly over Microsoft's network.

PaaS Firewall Integration

Allows you to restrict PaaS access to specific VNets and subnets.

Key Takeaway

Service Endpoints provide a cost-effective way to secure PaaS access by leveraging the Azure backbone and VNet-level filtering.
