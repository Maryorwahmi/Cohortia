Key Features

Understanding Service Endpoint Mechanics

Exploring the core attributes and behavior of Service Endpoints.

VNet-level Security

Access restricted to specified VNets and subnets.

Public IP Retained

PaaS service keeps public IP, but traffic from enabled subnet routes privately.

No Private IP for PaaS

The PaaS service itself does not get a private IP within your VNet.

Free of Charge

No additional cost for using Service Endpoints.

Service-Specific

Enabled for specific Azure services (e.g., Microsoft.Storage, Microsoft.Sql).

Key Takeaway

Service Endpoints offer VNet-level security and private routing over the Azure backbone without assigning private IPs to PaaS services, and they are free to use.
