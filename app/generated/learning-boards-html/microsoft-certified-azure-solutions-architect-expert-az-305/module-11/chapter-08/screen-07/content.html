Example CLI Commands for Service Endpoints
# Enable a service endpoint for Azure Storage on a subnet
az network vnet subnet update -g MyVnetRG -n AppSubnet --vnet-name MyVNet \
  --service-endpoints Microsoft.Storage

# Configure Azure Storage account firewall to allow access only from that subnet
STORAGE_ACCOUNT_ID=$(az storage account show -g MyStorageRG -n mystorageaccount --query id -o tsv)
VNET_ID=$(az network vnet show -g MyVnetRG -n MyVNet --query id -o tsv)
SUBNET_ID=$(az network vnet subnet show -g MyVnetRG -n MyVNet --vnet-name MyVNet --query id -o tsv)

az storage account network-rule add -g MyStorageRG --account-name mystorageaccount \
  --vnet $VNET_ID --subnet $SUBNET_ID
Command Explanation

The first command enables the Service Endpoint for Storage on a specific subnet. The subsequent commands retrieve IDs and then add a network rule to the storage account's firewall, restricting access to only that VNet and subnet.

Practical Application

Common Scenarios for Service Endpoints

Securing PaaS access for VMs and App Services within Azure.

VM to Azure Storage

Securely connect Virtual Machines to Azure Storage accounts over the Azure backbone.

App Service to Azure SQL DB

Enable private and secure communication between Azure App Service and Azure SQL Database.

Key Takeaway

Service Endpoints are ideal for securing PaaS access from within Azure VNets by leveraging PaaS firewall rules to block public internet access.
