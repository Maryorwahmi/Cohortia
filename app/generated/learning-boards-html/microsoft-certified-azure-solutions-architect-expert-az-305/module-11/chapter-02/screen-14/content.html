Advanced Connectivity Concepts

Reinforcing advanced routing and design patterns

Non-transitive Routing

If VNet A peers with B, and B peers with C, VNet A cannot directly communicate with VNet C without explicit routing.

Hub-Spoke Topology

A network design where a central 'hub' VNet hosts shared services and connects to multiple 'spoke' VNets for application workloads.

User-Defined Routes (UDRs)

Custom routing rules applied to subnets to override Azure's default routing, often used to force traffic through NVAs or VPN Gateways.

Gateway Transit Settings

'Allow Gateway Transit' (hub) and 'Use Remote Gateways' (spoke) enable spokes to utilize the hub's VPN/ExpressRoute gateway.

Chapter Summary

Mastering non-transitive routing, hub-spoke designs, UDRs, and gateway transit settings is crucial for building robust and scalable Azure network architectures.
