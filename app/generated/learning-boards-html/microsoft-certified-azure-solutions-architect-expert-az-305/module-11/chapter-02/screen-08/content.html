Core Concept

User-Defined Routes (UDRs)

UDRs are custom routing rules applied to subnets to override Azure's default routing behavior, enabling transitive routing in peered networks.

  • •Purpose: Force traffic through NVAs (e.g., Azure Firewall) or VPN Gateways in the hub.
  • •Mechanism: Direct traffic destined for specific IP ranges to a 'next hop' IP address within the hub.
Key Peering Settings

Allow Gateway Transit (Hub): Permits spoke VNets to use the hub's VPN/ExpressRoute gateway.
Use Remote Gateways (Spoke): Allows the spoke VNet to utilize the remote gateway in the peered hub VNet.

Key Takeaway

UDRs are essential for directing traffic from spokes through the hub, enabling connectivity to on-premises networks or other spokes, overcoming peering's non-transitive nature.
