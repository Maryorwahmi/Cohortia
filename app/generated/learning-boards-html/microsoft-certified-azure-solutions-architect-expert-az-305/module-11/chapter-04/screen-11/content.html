Real-World Example

Securing a Three-Tier Application with ASGs

Practical Implementation for Complex Architectures

Web Subnet NSG

  • Inbound:Allow HTTP/HTTPS from Internet to WebServers ASG.
  • Outbound:Allow from WebServers ASG to AppServers ASG on port 8080.

App Subnet NSG

  • Inbound:Allow from WebServers ASG to AppServers ASG on port 8080.
  • Outbound:Allow from AppServers ASG to DatabaseServers ASG on port 1433.

Data Subnet NSG

  • Inbound:Allow from AppServers ASG to DatabaseServers ASG on port 1433.
  • Outbound:Deny All (default override).
Key Insight

ASGs abstract away individual VM IPs, making NSG rules for multi-tier applications highly readable, scalable, and maintainable.

Key Takeaway

By using ASGs, you can define clear, application-level communication policies that automatically apply to all members of a group, simplifying complex security architectures.
