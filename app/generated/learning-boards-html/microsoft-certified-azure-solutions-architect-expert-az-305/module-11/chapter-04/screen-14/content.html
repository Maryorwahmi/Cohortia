Key Concepts

Essential Terms to Remember

Network Security Group (NSG)

A virtual firewall that filters inbound and outbound network traffic to Azure resources based on rules.

Security Rule

A component of an NSG that specifies traffic parameters (source, destination, port, protocol, direction, priority, action).

Priority

A number (100-4096) assigned to NSG rules; lower numbers have higher precedence, determining rule evaluation order.

Summary Takeaway

NSGs, with their detailed security rules and priority system, form the core of network traffic control in Azure.
