Managing NSGs and ASGs with Azure CLI

Command-Line Operations for Network Security

# Create an NSGaz network nsg create -g MyNetworkRG -n WebTierNSG --location eastus# Create an Inbound rule for HTTPaz network nsg rule create -g MyNetworkRG --nsg-name WebTierNSG -n AllowHTTP \  --priority 100 --direction Inbound --access Allow --protocol Tcp \  --source-address-prefixes Internet --source-port-ranges '*' \  --destination-address-prefixes '*' --destination-port-ranges 80# Create an Application Security Groupaz network asg create -g MyNetworkRG -n WebServersASG --location eastus# Associate a VM's NIC with an ASG (assuming a VM 'MyWebServer' exists)# First, get the NIC IDNIC_ID=$(az vm show -g MyNetworkRG -n MyWebServer --query 'networkProfile.networkInterfaces[0].id' -o tsv)ASG_ID=$(az network asg show -g MyNetworkRG -n WebServersASG --query id -o tsv)az network nic ip-config update \  --resource-group MyNetworkRG \  --nic-name $(basename $NIC_ID) \  --name ipconfig1 \  --application-security-groups $ASG_ID
Key Takeaway

Azure CLI provides a robust and scriptable way to create, configure, and manage NSGs and ASGs, enabling automation of network security policies.
