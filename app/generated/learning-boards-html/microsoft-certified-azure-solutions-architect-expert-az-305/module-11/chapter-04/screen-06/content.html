Understanding Azure's Default NSG Rules

The Baseline for Network Security

Inbound Rules

  • 65000:AllowVnetInbound - Allows VNet to VNet traffic.
  • 65001:AllowAzureLoadBalancerInbound - Allows traffic from Azure Load Balancer.
  • 65500:DenyAllInbound - Denies all other inbound traffic.

Outbound Rules

  • 65000:AllowVnetOutbound - Allows VNet to VNet traffic.
  • 65001:AllowInternetOutbound - Allows outbound traffic to the internet.
  • 65500:DenyAllOutbound - Denies all other outbound traffic.
Important Note

These default rules cannot be removed but can be overridden by custom rules with lower priority numbers (e.g., 100).

Key Takeaway

Azure's default NSG rules establish a baseline security posture, allowing internal VNet communication and outbound internet access, while denying other inbound traffic.
