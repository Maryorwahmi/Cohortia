Core Concept

Network Security Groups (NSGs)

Your Virtual Firewall in Azure

What is an NSG?

  • Acts as a virtual firewall, filtering inbound and outbound network traffic.
  • Allows or denies traffic based on defined security rules.
  • Applies to Azure resources within a Virtual Network.
Key Takeaway

NSGs are essential for controlling network access, acting as the primary security layer for your Azure virtual networks and resources.

NSG Association Points

Subnet Level

Rules apply to all resources within the subnet.

NIC Level

Rules apply only to a specific VM's network interface.

Combined Evaluation:

If both are associated, inbound traffic is evaluated by Subnet NSG, then NIC NSG. Outbound traffic is evaluated by NIC NSG, then Subnet NSG. Both must allow traffic.
