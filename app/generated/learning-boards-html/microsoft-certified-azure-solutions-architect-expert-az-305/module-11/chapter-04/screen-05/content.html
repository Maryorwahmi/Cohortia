Anatomy of an NSG Rule

Defining Traffic Flow with Precision

1. Source/Destination

IP addresses, IP ranges, Service Tags, or ASGs.

2. Port Range

Specific ports or ranges (e.g., 80, 443, 1024-65535).

3. Protocol

TCP, UDP, ICMP, or Any.

4. Direction

Inbound or Outbound traffic.

5. Priority

Number from 100 to 4096; lower numbers take precedence.

6. Action

Allow or Deny the traffic.

Rule Processing Order

Rules are processed by priority (lowest number first). Once a match is found, processing stops.

Key Takeaway

Understanding rule components and priority is vital to prevent unintended traffic blocks and ensure precise network control.
