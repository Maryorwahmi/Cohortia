Application Security Groups (ASGs)

Grouping Workloads for Simplified Security

What ASGs Provide

  • Logically group VMs (NICs) by application workload.
  • Specify ASGs as source/destination in NSG rules instead of IPs.
  • Dramatically simplifies management and improves scalability.
Key Takeaway

ASGs abstract away individual VM IPs, allowing NSG rules to be defined based on application roles, leading to more manageable and scalable security policies.

ASG in Action: Simplified Rule Definition

Application Security Group: WebServers

Contains NICs of VM1, VM2, VM3

Application Security Group: AppServers

Contains NICs of VM4, VM5, VM6

NSG Rule Example:

Allow traffic from WebServers ASG to AppServers ASG on port 8080.

No need to list individual VM IPs!
