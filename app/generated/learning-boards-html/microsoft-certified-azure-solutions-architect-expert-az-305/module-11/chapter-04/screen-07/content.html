Customizing Security

Custom Rules and Overriding Defaults

Tailoring Traffic Control to Your Needs

Default Behavior (Deny)

  • Priority 65500:DenyAllInbound - Blocks all inbound traffic from the internet by default.
  • Impact:Your web server is unreachable from public internet for HTTP/HTTPS.

Custom Override (Allow)

  • Priority 100:AllowHTTPInbound - Allows HTTP (port 80) from Internet.
  • Configuration:Source: Internet, Destination: Any, Dest Port: 80, Protocol: TCP, Action: Allow.
Key Principle

Custom rules with lower priority numbers (e.g., 100) will always be evaluated and applied before default rules (e.g., 65500), effectively overriding them.

Key Takeaway

To enable specific traffic flows, create custom NSG rules with lower priority numbers than the default 'Deny' rules, explicitly allowing the desired communication.
