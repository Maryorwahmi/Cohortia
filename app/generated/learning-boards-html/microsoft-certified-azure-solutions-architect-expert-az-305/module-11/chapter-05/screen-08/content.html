DEPLOYMENT PATTERN

Hub-Spoke with Azure Firewall

Integrating Azure Firewall into a dedicated subnet.

Hub VNet

A central VNet hosting shared services, including the Azure Firewall in its dedicated AzureFirewallSubnet. This is the security inspection point.

Spoke VNets

Separate VNets where application workloads reside. These VNets peer with the hub and route their traffic through the firewall for inspection.

Routing with UDRs

User-Defined Routes (UDRs) are configured in spoke VNet subnets to force traffic (e.g., 0.0.0.0/0 for internet-bound) through the Azure Firewall's private IP address in the hub. This ensures all relevant traffic is inspected.

Key Takeaway

The hub-spoke topology with Azure Firewall in the hub, combined with UDRs in spokes, provides a scalable and centralized security model for Azure networks.
