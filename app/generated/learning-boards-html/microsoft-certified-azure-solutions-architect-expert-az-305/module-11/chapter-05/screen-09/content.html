CORE CONCEPT

Network Virtual Appliances (NVAs)

Third-party network functionality in Azure.

What are NVAs?

Network Virtual Appliances are third-party virtual machines that provide specialized network functionality like firewalls, WAN optimizers, or intrusion detection/prevention systems (IDS/IPS) in Azure.

Common Examples

Popular NVAs include firewalls from vendors like Palo Alto Networks, Fortinet FortiGate, or Cisco ASAs, deployed from the Azure Marketplace to offer rich feature sets.

Why Use NVAs?

NVAs offer specialized features not always available in native Azure services, deeper integration with existing on-premises security solutions, and greater control over the underlying configuration.

Key Takeaway

NVAs provide specialized, vendor-specific network functions in Azure, offering rich features and integration but requiring more management overhead than native services.
