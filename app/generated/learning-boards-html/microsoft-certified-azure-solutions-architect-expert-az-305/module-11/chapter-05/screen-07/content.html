Network Address Translation (NAT) Capabilities

Controlling inbound and outbound traffic flows.

SNAT (Source Network Address Translation)

All outbound traffic from VNet resources processed by Azure Firewall has its source IP translated to the Firewall's public IP address. This provides a single, identifiable egress point for your VNet.

Purpose: Unify outbound traffic source, simplify external access control.

DNAT (Destination Network Address Translation)

Allows inbound traffic from the internet to be translated to private IP addresses of resources behind the firewall. This enables secure exposure of internal services to the public internet.

Purpose: Securely expose internal services to the internet.
Key Takeaway

SNAT centralizes outbound traffic's source IP, while DNAT enables secure inbound access to private resources, both critical for Azure Firewall's traffic management.
