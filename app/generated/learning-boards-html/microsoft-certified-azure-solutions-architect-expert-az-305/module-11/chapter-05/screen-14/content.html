CHAPTER RECAP

Key Concepts

Essential terms to remember

Azure Firewall

A cloud-native, stateful network security service providing centralized policy management, FQDN filtering, and threat intelligence for Azure VNets.

Network Virtual Appliance (NVA)

A virtual machine from a third-party vendor that provides network functionality (e.g., firewall, IDS/IPS, WAN optimizer) in Azure.

FQDN Filtering

The ability to filter network traffic based on Fully Qualified Domain Names (e.g., www.microsoft.com) rather than just IP addresses.

Summary Takeaway

Azure Firewall and NVAs are critical for advanced network security, offering centralized control, specialized features, and granular traffic management beyond basic NSGs.
