Key Concepts

Deepening your understanding

Threat Intelligence-based Filtering

Automatic blocking of traffic from known malicious IP addresses and domains, leveraging Microsoft's threat intelligence feed.

SNAT (Source NAT) & DNAT (Destination NAT)

SNAT modifies outbound source IPs to the firewall's public IP; DNAT translates inbound destination IPs to private IPs behind the firewall.

User-Defined Routes (UDRs)

Custom routing rules used to force traffic through a specific next hop, such as an NVA or Azure Firewall, overriding default Azure routing.

Summary Takeaway

Proactive threat defense, flexible address translation, and custom routing are advanced capabilities for fine-grained network security control in Azure.
