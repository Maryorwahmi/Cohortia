Avoiding Asymmetric Routing with NVAs

Ensuring consistent traffic flow through stateful devices.

What is Asymmetric Routing?

Asymmetric routing occurs when the inbound and outbound traffic for a network session takes different paths. This is problematic for stateful devices like firewalls, which need to see both directions of traffic.

Impact on Stateful NVAs

If return traffic bypasses the NVA, the stateful firewall will not recognize it as part of an established session and will drop the packets, leading to intermittent connectivity issues and dropped connections.

Ensuring Symmetric Routing

Meticulous UDR configuration and NVA design are essential to prevent asymmetric routing. Ensure both inbound and outbound traffic for a session flows through the same NVA instance. Tools like Network Watcher can help verify routing paths.

Key Takeaway

Symmetric routing is critical for stateful NVAs; carefully configure UDRs to ensure all traffic for a session passes through the same NVA instance to avoid connectivity issues.
