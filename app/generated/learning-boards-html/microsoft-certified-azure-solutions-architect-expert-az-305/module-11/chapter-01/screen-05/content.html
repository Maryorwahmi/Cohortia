VNet Address Space & CIDR

Allocating Your Private IP Range

Defining the Address Space

The VNet address space is a private IP address range, specified in CIDR notation, that defines all available IP addresses for resources within that VNet.

Example: 10.0.0.0/16 provides 65,536 IP addresses.

Crucial: Avoid IP Overlap

  • No Overlap: Ensure your VNet address space does not overlap with any other connected networks (other Azure VNets, on-premises networks).
  • Routing Conflicts: Overlapping ranges lead to severe routing conflicts and connectivity issues that are hard to troubleshoot.
Key Takeaway

A unique, non-overlapping VNet address space is fundamental for stable and scalable network connectivity in Azure.

CIDR Notation Explained

What is CIDR?

Classless Inter-Domain Routing is a method for allocating IP addresses and routing IP packets. It's denoted by an IP address followed by a slash and a number (e.g., 10.0.0.0/16).

/16 vs /24

10.0.0.0/1665,536 IPs
10.0.1.0/24256 IPs

How it Works

The number after the slash indicates how many bits are used for the network prefix. A smaller number means a larger IP range (fewer bits for host addresses).
