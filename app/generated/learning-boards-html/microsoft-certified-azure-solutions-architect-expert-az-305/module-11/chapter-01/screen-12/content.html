Designing a Three-Tier Application VNet

Layered Security with Subnets and NSGs

Application Tiers & VNet Setup

For a three-tier application (Web, App, Data), create a single VNet (e.g., 10.1.0.0/16) and define dedicated subnets for each tier.

  • WebSubnet: 10.1.1.0/24
  • AppSubnet: 10.1.2.0/24
  • DataSubnet: 10.1.3.0/24

Applying Granular NSG Rules

  • WebSubnet NSG: Allow HTTP/HTTPS from Internet.
  • AppSubnet NSG: Allow App Port (e.g., 8080) from WebSubnet only.
  • DataSubnet NSG: Allow DB Port (e.g., 1433) from AppSubnet only.
Key Takeaway

Layered security through subnet segmentation and targeted NSG rules is fundamental for protecting multi-tier applications in Azure.

Three-Tier Application Architecture

Azure VNet (10.1.0.0/16)

Web Subnet (10.1.1.0/24)

Internet ↔ HTTP/HTTPS ↔ Web Servers

App Subnet (10.1.2.0/24)

Web Subnet ↔ App Port ↔ App Servers

Data Subnet (10.1.3.0/24)

App Subnet ↔ DB Port ↔ Database Servers
