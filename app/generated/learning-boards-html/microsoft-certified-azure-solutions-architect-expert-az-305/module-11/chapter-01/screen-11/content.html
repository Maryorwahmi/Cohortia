VNet Security Defaults

Controlling Inbound and Outbound Traffic

Default Behaviors

  • Intra-VNet: Resources within the same VNet can communicate with each other by default.
  • Internet Inbound: Communication from the internet to your VNet is denied by default.
  • Internet Outbound: Communication from your VNet to the internet is allowed by default.

Overriding Defaults with NSGs

Network Security Groups (NSGs) are used to enforce granular traffic filtering. They allow you to define specific rules to permit or deny traffic at the subnet or individual network interface level.

Example: Allow inbound HTTP/HTTPS to a web subnet, block all other inbound.

Key Takeaway

Understanding VNet security defaults and leveraging NSGs are critical for establishing a secure and controlled network environment in Azure.
