Deploying VNets and Subnets

Using Azure CLI for Network Configuration

Scenario: Two-Tier Application VNet

Deploy a VNet with address space 10.20.0.0/16. It needs two subnets: FrontendSubnet and BackendSubnet, both /24.

Goal: Configure VNet and subnets using Azure CLI commands.

Deployment Steps Overview

  • 1. Define Subnet CIDRs: Allocate /24 ranges for Frontend and Backend.
  • 2. Create Resource Group: Organize your network resources.
  • 3. Deploy VNet & Subnets: Use az network vnet create and az network vnet subnet create.
  • 4. Verify Deployment: Confirm configuration with az network vnet show.
Key Takeaway

Azure CLI provides powerful, scriptable commands for efficiently deploying and managing your VNet and subnet infrastructure.

Azure CLI Commands
# Create Resource Groupaz group create --name MyNetworkRG --location eastus# Create the VNetaz network vnet create \  --resource-group MyNetworkRG \  --name MyTwoTierVNet \  --address-prefix 10.20.0.0/16 \  --location eastus# Add FrontendSubnetaz network vnet subnet create \  --resource-group MyNetworkRG \  --vnet-name MyTwoTierVNet \  --name FrontendSubnet \  --address-prefix 10.20.1.0/24# Add BackendSubnetaz network vnet subnet create \  --resource-group MyNetworkRG \  --vnet-name MyTwoTierVNet \  --name BackendSubnet \  --address-prefix 10.20.2.0/24# Verify deploymentaz network vnet show \  --resource-group MyNetworkRG \  --name MyTwoTierVNet \  --query '{name: name, addressSpace: addressSpace.addressPrefixes, subnets: subnets[].{name: name, addressPrefix: addressPrefix}}' \  -o json
