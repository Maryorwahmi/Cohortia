Chapter 11.1

Key Concepts

Essential Terms to Remember

Azure Virtual Network (VNet)

An isolated network in Azure enabling secure communication for resources, the internet, and on-premises networks.

Address Space

A private IP address range (e.g., 10.0.0.0/16) assigned to a VNet, defining all available IP addresses within it.

Subnet

A logical division of a VNet's address space, used for segmentation and applying granular security controls.

Summary Takeaway

Azure VNets, their address spaces, and subnets are the foundational elements for designing secure, scalable, and well-organized cloud networks.
