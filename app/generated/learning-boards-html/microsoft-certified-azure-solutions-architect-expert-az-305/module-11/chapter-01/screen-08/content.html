Subnet Allocation Example

Web, App, and Data Tiers

Scenario: Three-Tier Application

You have an Azure VNet with address space 10.0.0.0/16. You need to segment it for a web, application, and data tier.

Goal: Create distinct subnets for each tier to enhance security and organization.

Subnet Allocation Details

  • Web Subnet: 10.0.1.0/24 (for front-end web servers)
  • App Subnet: 10.0.2.0/24 (for application logic)
  • Data Subnet: 10.0.3.0/24 (for database servers)
Key Takeaway

Allocating specific CIDR blocks to subnets for different application tiers is crucial for logical organization and applying targeted security policies.
