Azure Reserved IP Addresses

Azure's Internal Subnet Allocations

The 5 Reserved IPs

Azure reserves the first four and the last IP address in every subnet for internal use. This reduces the number of usable IPs for your resources.

Impact: A /24 subnet (256 IPs) provides only 251 usable IP addresses.

Why They Are Reserved

  • Network Address: Identifies the subnet itself.
  • Default Gateway: For routing traffic out of the subnet.
  • Azure DNS: For name resolution within the VNet.
  • Future Use: Reserved for potential future Azure services.
  • Broadcast Address: For network-wide communication.
Key Takeaway

Always factor in Azure's 5 reserved IP addresses per subnet when planning your subnet sizes to avoid unexpected IP exhaustion.

Example: 10.0.1.0/24 Subnet
10.0.1.0Network Address
10.0.1.1Default Gateway
10.0.1.2Azure DNS
10.0.1.3Future Use
...Usable IPs (251)
10.0.1.255Broadcast Address
