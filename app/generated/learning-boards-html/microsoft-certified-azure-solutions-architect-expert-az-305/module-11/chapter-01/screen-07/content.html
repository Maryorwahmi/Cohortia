Subnets for Segmentation

Dividing Your VNet for Isolation

What are Subnets?

Subnets are logical divisions of a VNet's address space. They create smaller, isolated segments within your larger virtual network.

Each subnet is allocated a portion of the VNet's address space using CIDR notation.

Why Segment with Subnets?

  • Organizational: Group similar resources or application tiers together.
  • Security: Apply granular network security controls (e.g., Network Security Groups) to restrict traffic flow between segments.
  • Manageability: Easier to manage and troubleshoot network policies for specific resource groups.
Key Takeaway

Subnets are essential for creating logical boundaries within your VNet, enabling enhanced security and simplified management through targeted policy application.
