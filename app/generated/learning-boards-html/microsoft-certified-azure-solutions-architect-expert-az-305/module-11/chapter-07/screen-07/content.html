Azure Public DNS: CLI Example & Best Practices

Hands-on Configuration and Avoiding Common Pitfalls

# Example CLI commands for Azure Public DNS

# 1. Create a public DNS zone
az network dns zone create -g MyDnsRG -n contoso.com

# 2. Get the name servers for the zone (update your registrar with these)
az network dns zone show -g MyDnsRG -n contoso.com --query nameServers -o tsv

# 3. Add an A record for www.contoso.com pointing to a public IP
az network dns record-set a add-record -g MyDnsRG -z contoso.com -n www -a 20.1.2.3
Common Mistakes
  • Incorrect name server delegation at registrar.
  • Typos in DNS record values.
  • Forgetting about DNS caching and TTLs.
TTL (Time-To-Live)

Defines how long DNS resolvers should cache a record. Lower TTLs mean faster propagation but more queries.

Key Takeaway

Always verify name server delegation and set appropriate TTLs to balance DNS change propagation speed with query load.
