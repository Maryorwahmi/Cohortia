Troubleshooting Guide

Troubleshooting Common DNS Issues in Azure

Diagnosing and Resolving Resolution Problems

01

Verify VNet Link

Ensure the Private DNS Zone is correctly linked to all necessary Virtual Networks for resolution.

02

Check Auto-Registration

Confirm auto-registration is enabled and VM records are appearing in the Private DNS Zone.

03

Custom DNS Servers

Ensure custom DNS servers in VNet forward Azure-specific queries to 168.63.129.16.

04

On-premises Forwarders

For hybrid, verify on-premises DNS forwards queries to Azure DNS forwarders or Private Resolver.

05

Use `nslookup` / `dig`

Utilize these tools from Azure VMs and on-premises to diagnose resolution paths and identify issues.

06

Review Activity Logs

Check Azure Activity Logs for any DNS-related configuration changes or errors that might indicate a problem.

Key Takeaway

Systematic troubleshooting, starting with VNet links and auto-registration, and using diagnostic tools, is essential for resolving DNS issues in Azure.
