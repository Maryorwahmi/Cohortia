Hybrid Connectivity

Hybrid DNS Resolution with Private DNS Zones

Connecting On-Premises to Azure Internal DNS

Challenge

On-premises machines need to resolve names in Azure Private DNS Zones, and vice-versa.

Older Approach: DNS Forwarders

Deploy IaaS DNS servers in Azure to forward queries for private zones to 168.63.129.16, then configure on-premises DNS to forward to these VMs.

Key Takeaway

Azure DNS Private Resolver is the modern, fully managed solution for seamless hybrid DNS resolution, eliminating the need for IaaS DNS forwarders.
