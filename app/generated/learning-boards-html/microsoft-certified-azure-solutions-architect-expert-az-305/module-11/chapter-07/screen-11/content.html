Azure Private DNS Zones: CLI Example

Configuring Private DNS for Your Virtual Network

# Example CLI commands for Azure Private DNS Zone

# 1. Create a private DNS zone
az network private-dns zone create -g MyDnsRG -n internal.contoso.com

# 2. Get VNet ID (assuming MyVNet exists in MyNetworkRG)
VNET_ID=$(az network vnet show -g MyNetworkRG -n MyVNet --query id -o tsv)

# 3. Link the private DNS zone to a VNet with auto-registration enabled
az network private-dns link vnet create -g MyDnsRG -n MyVNetLink \
--zone-name internal.contoso.com --virtual-network $VNET_ID --registration-enabled true
Hub-Spoke Scenario

Link a Private DNS Zone to a hub VNet and all spoke VNets to enable resolution across the entire topology.

Auto-Registration

Setting --registration-enabled true ensures VMs automatically register their hostnames and IPs.

Key Takeaway

The CLI provides a powerful way to automate the creation and linking of Private DNS Zones, especially with auto-registration for dynamic environments.
