Core Feature

Azure Disk Encryption (ADE)

ADE encrypts OS and data disks for Azure Virtual Machines. It uses industry-standard DM-Crypt for Linux and BitLocker for Windows, providing whole-disk encryption.

  • Encrypts entire disk volume.
  • Keys stored in Azure Key Vault.
Key Management

Centralized Key Vault Integration

ADE leverages Azure Key Vault to store encryption keys and secrets, offering a secure and centralized management solution. This simplifies key rotation and access control for multiple VMs.

Secure Key Storage
Common Misconception

Offline Encryption

ADE encrypts the entire disk volume, but it requires the VM to be running to access the encrypted data. It does not encrypt data while the VM is deallocated or offline, as key retrieval happens during runtime.

Runtime Requirement
Key Takeaway

ADE provides comprehensive whole-disk encryption for Azure VMs, integrating with Key Vault for secure key management, but requires the VM to be running for operation.
