Key Management

Customer-Managed Keys (CMK)

CMK allows you to bring your own encryption keys, securely stored and managed in Azure Key Vault. This provides full control over key lifecycle, including rotation, revocation, and access policies.

  • Keys stored in Azure Key Vault.
  • Essential for strict compliance (GDPR, HIPAA, PCI DSS).
Mechanism

Envelope Encryption

The storage account uses your Key Vault key (Key Encryption Key - KEK) to encrypt and decrypt its Data Encryption Keys (DEKs). The DEKs then encrypt the actual data. This creates a layered security model.

Layered Security
Example

Healthcare Data Storage

A healthcare provider storing patient records in Azure Blob Storage might use CMK to meet HIPAA requirements, ensuring they have auditable control over the keys protecting sensitive health information.

Key Takeaway

CMK for Azure Storage provides enhanced control and auditability over encryption keys via Azure Key Vault, crucial for stringent compliance and highly sensitive data.
