Core Concept

What is Data at Rest?

Data at rest refers to data that is physically stored in persistent storage, such as files on a disk, data in a database, or objects in a storage account. It's static data, not actively in transit.

Persistent Storage
Why It Matters

The Goal of Encryption

The primary goal is to ensure that if an unauthorized party gains access to the underlying storage, the data remains unreadable without the decryption key. This maintains confidentiality.

Data Confidentiality
Real-World Example

Stolen Laptop Scenario

Imagine a laptop containing sensitive customer data is stolen. If the hard drive is encrypted, the data on it is unreadable to the thief, preventing a data breach. Without encryption, the data is immediately exposed.

Preventing Breaches
Key Takeaway

Data at rest encryption is a critical defense layer, ensuring data confidentiality even if physical storage is compromised. It's fundamental for compliance and trust.
