Core Feature

Transparent Data Encryption (TDE)

TDE encrypts data files, log files, and backups at rest for Azure SQL Database. It uses a symmetric Database Encryption Key (DEK), protected by a certificate or asymmetric key (AK).

  • Enabled by default for new databases.
  • Encrypts entire database.
Key Benefit

Transparency to Applications

TDE is 'transparent' because applications do not need to be modified to handle encryption or decryption. The database engine handles these processes automatically, simplifying implementation.

No Application Changes
Example

Legacy Application Protection

A legacy application that cannot be easily refactored can still benefit from TDE. By enabling TDE on the Azure SQL Database, its data at rest is encrypted without any changes to the application's code or connection strings.

Simplified Security
Key Takeaway

TDE provides transparent, whole-database encryption for Azure SQL Database, protecting data files, logs, and backups at rest without requiring application modifications.
