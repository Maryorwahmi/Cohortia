Enhanced Control

TDE with Customer-Managed Keys (CMK)

Azure SQL Database can use CMK for TDE, storing encryption keys in Azure Key Vault. This provides centralized key management and control, aligning with stringent compliance requirements.

  • Keys in Azure Key Vault.
  • Meets GDPR, HIPAA, PCI DSS.
Critical Consideration

Key Lifecycle Impact on Availability

When using CMK for TDE, consider the implications of key rotation and revocation on database availability. If a key becomes unavailable, the database will be inaccessible. Proper testing and failover mechanisms are essential.

Plan for Key Rotation & Revocation
Example Scenario

High-Availability Database

For a mission-critical database using TDE with CMK, implement automated key rotation with Azure Functions and monitor Key Vault health. Ensure a disaster recovery plan includes steps for key restoration and database failover in case of key unavailability.

Business Continuity
Key Takeaway

TDE with CMK provides superior control for Azure SQL Database encryption, but demands careful planning for key lifecycle management to prevent availability issues.
