Scenario

Enable CMK for Azure Storage Account

Your organization requires all sensitive data in Azure Blob Storage to be encrypted using customer-managed keys for enhanced control and compliance.

  • Create Key Vault and RSA key.
  • Configure Storage Account with CMK.
  • Grant Storage Account managed identity access to Key Vault.
Key Steps

Azure CLI Commands Overview

We'll use a sequence of Azure CLI commands to:

  • Create a resource group and Key Vault.
  • Generate an RSA key in Key Vault.
  • Create Storage Account with managed identity.
  • Grant Key Vault permissions to the managed identity.
  • Update Storage Account to use CMK.
# 1. Define variables (replace with your desired names and location)RESOURCE_GROUP_NAME="DataEncryptionRG"LOCATION="eastus"KEY_VAULT_NAME="MyCMKKeyVault$(openssl rand -hex 4)" # Unique nameKEY_NAME="StorageCMKKey"STORAGE_ACCOUNT_NAME="cmkstorage$(openssl rand -hex 4)" # Unique name# 2. Create a resource groupaz group create --name $RESOURCE_GROUP_NAME --location $LOCATION# 3. Create an Azure Key Vaultaz keyvault create --name $KEY_VAULT_NAME --resource-group $RESOURCE_GROUP_NAME --location $LOCATION \    --enabled-for-disk-encryption true --sku standard# 4. Generate an RSA key in the Key Vaultaz keyvault key create --vault-name $KEY_VAULT_NAME --name $KEY_NAME --kty RSA --size 2048# 5. Get the Key Vault URI and Key URIKEY_VAULT_URI=$(az keyvault show --name $KEY_VAULT_NAME --query vaultUri --output tsv)KEY_URI=$(az keyvault key show --vault-name $KEY_VAULT_NAME --name $KEY_NAME --query key.kid --output tsv)KEY_VERSION=$(echo $KEY_URI | cut -d '/' -f 6) # Extract key version from URI# 6. Create a Storage Account with System-Assigned Managed Identityaz storage account create --name $STORAGE_ACCOUNT_NAME --resource-group $RESOURCE_GROUP_NAME --location $LOCATION \    --sku Standard_LRS --kind StorageV2 \    --assign-identity # Enable System-Assigned Managed Identity# Wait a moment for the identity to propagateecho "Waiting for managed identity to propagate..."sleep 30# 7. Get the Principal ID of the Storage Account's Managed IdentitySTORAGE_PRINCIPAL_ID=$(az storage account show --name $STORAGE_ACCOUNT_NAME --resource-group $RESOURCE_GROUP_NAME --query identity.principalId --output tsv)echo "Storage Account Principal ID: $STORAGE_PRINCIPAL_ID"# 8. Grant the Storage Account's Managed Identity permissions to Key Vaultaz keyvault set-policy --name $KEY_VAULT_NAME --resource-group $RESOURCE_GROUP_NAME \    --object-id $STORAGE_PRINCIPAL_ID \    --key-permissions get unwrapKey wrapKey# 9. Update the Storage Account to use Customer-Managed Keysaz storage account update --name $STORAGE_ACCOUNT_NAME --resource-group $RESOURCE_GROUP_NAME \    --encryption-key-source Microsoft.Keyvault \    --encryption-key-vault-properties key-name=$KEY_NAME key-vault-uri=$KEY_VAULT_URI key-version=$KEY_VERSIONecho "Storage Account $STORAGE_ACCOUNT_NAME configured with CMK from Key Vault $KEY_VAULT_NAME."echo "Verify settings in Azure Portal under Storage Account -> Encryption."
