Regional Key Vaults or global KMS

Logical Separation

Deploying Key Vaults per application environment (Dev, Test, Prod) or subscription limits the 'blast radius' in case of a breach, containing potential impact.

Built-in Geo-Redundancy

Key Vault automatically replicates its contents within the region and to a paired region for high availability and data durability. This is for resilience, not cross-region application access.

Multi-Region Application Access

For applications spanning multiple regions, consider deploying a Key Vault in each region or designing a global key management system that integrates with Key Vault to manage cross-region key access effectively.

Key Takeaway

Design Key Vaults with logical separation per environment and plan for multi-region access carefully.
