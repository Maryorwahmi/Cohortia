Azure CLI: Key Vault Creation and Access Configuration

A Step-by-Step Guide to Setting Up Your Key Vault

Walkthrough Steps

  • Define Variables: Set up names for resources.
  • Create Resource Group: Organize Azure resources.
  • Create Key Vault: Provision with soft-delete and purge protection.
  • Enable Managed Identity: Assign to an Azure VM.
  • Get Principal ID: Retrieve the unique ID of the Managed Identity.
  • Set Access Policy: Grant 'Get' and 'List' secret permissions.
  • Add Secret: Store a sample secret in the vault.
Key Takeaway

The Azure CLI enables programmatic creation and secure configuration of Key Vaults and their access policies.

Azure CLIbash
# 1. Define variablesRESOURCE_GROUP_NAME="KeyVaultDemoRG"LOCATION="eastus"KEY_VAULT_NAME="MySecureKeyVault$(openssl rand -hex 4)"VM_NAME="MySecureVM" # Replace with your VM name# 2. Create a resource group (if not exists)az group create --name $RESOURCE_GROUP_NAME --location $LOCATION# 3. Create a Key Vault (Standard SKU for demonstration)echo "Creating Key Vault: $KEY_VAULT_NAME"az keyvault create --name $KEY_VAULT_NAME --resource-group $RESOURCE_GROUP_NAME --location $LOCATION    --sku standard --enable-soft-delete true --enable-purge-protection true# 4. Enable System-Assigned Managed Identity on an existing VMecho "Enabling System-Assigned Managed Identity for VM: $VM_NAME"az vm identity assign --name $VM_NAME --resource-group $RESOURCE_GROUP_NAME# 5. Get the Principal ID of the VM's Managed Identityecho "Retrieving Principal ID for VM's Managed Identity..."VM_PRINCIPAL_ID=$(az vm identity show --name $VM_NAME --resource-group $RESOURCE_GROUP_NAME --query principalId --output tsv)echo "VM Principal ID: $VM_PRINCIPAL_ID"# 6. Grant the VM's Managed Identity access to Key Vault using Key Vault Access Policyecho "Setting Key Vault access policy for VM Managed Identity..."az keyvault set-policy --name $KEY_VAULT_NAME --resource-group $RESOURCE_GROUP_NAME    --object-id $VM_PRINCIPAL_ID    --secret-permissions get list# 7. Add a secret to Key Vaultecho "Adding a secret to Key Vault..."az keyvault secret set --vault-name $KEY_VAULT_NAME --name "MyApplicationSecret" --value "SuperSecureValue123!"echo "Key Vault $KEY_VAULT_NAME created and access policy configured for VM $VM_NAME."echo "VM can now retrieve 'MyApplicationSecret' from Key Vault."
