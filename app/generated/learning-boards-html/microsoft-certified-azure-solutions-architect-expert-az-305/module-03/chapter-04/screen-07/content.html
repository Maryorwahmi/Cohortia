Policy Design

Defining DLP Policies with Microsoft Purview

Craft rules to identify sensitive information types (SITs) and apply protective actions across your data estate.

Key Components
  • Sensitive Info Types (SITs): Pre-built or custom patterns (e.g., credit card numbers).
  • Trainable Classifiers: ML-based identification for specific content.
  • Locations: Azure Storage, Azure SQL, Microsoft 365 services.
  • Actions: Block, audit, encrypt, notify users/admins.

Key Takeaway

Effective DLP policies in Purview rely on accurate sensitive data identification and carefully chosen protective actions tailored to organizational needs and compliance requirements.
