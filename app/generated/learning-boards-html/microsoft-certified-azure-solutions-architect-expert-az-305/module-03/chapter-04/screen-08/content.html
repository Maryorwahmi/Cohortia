AIP and Purview DLP: A Powerful Combination

AIP (now MPIP) focuses on data classification, labeling, and encryption, complementing Purview DLP's prevention capabilities.

AIP/MPIP Capabilities
  • Classification: Assign sensitivity levels (e.g., Public, Confidential).
  • Labeling: Apply metadata that triggers protection.
  • Encryption: Scramble data to restrict unauthorized access.
  • Visual Markings: Add headers, footers, watermarks.
  • Usage Restrictions: Prevent printing, forwarding, etc.

Purview DLP

Prevents data exfiltration

AIP / MPIP

Classifies & encrypts data

Layered Data Protection

Data is protected both in transit/at rest and if exfiltrated.

Key Takeaway

AIP/MPIP and Purview DLP create a robust, layered defense, ensuring data is classified, encrypted, and prevented from unauthorized sharing, even if it leaves the organization.
