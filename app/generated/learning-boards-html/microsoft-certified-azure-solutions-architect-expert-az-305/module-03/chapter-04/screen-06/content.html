Microsoft Purview: Your Data Governance Hub

Purview provides a unified solution to discover, classify, and map sensitive data across your entire data estate, including Azure, on-premises, and multi-cloud environments.

Key Capabilities
  • Data Discovery: Automatically scans and maps data sources.
  • Classification: Identifies sensitive information types (SITs).
  • DLP Policy Enforcement: Applies protective actions based on policies.
  • Data Estate Insights: Provides a holistic view of data risks.
