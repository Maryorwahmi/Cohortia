Anonymization Technique

Core Anonymization Methods: Shuffling, Substitution, Generalization

Transforming data to remove PII while preserving utility.

Shuffling

Randomly reordering values within a column (e.g., shuffling names or addresses).

Substitution

Replacing sensitive values with random, non-sensitive ones (e.g., fictional names).

Generalization/Aggregation

Replacing specific values with broader categories or aggregated data (e.g., age ranges, average salaries).

Key Takeaway

These methods are crucial for creating privacy-compliant datasets, allowing data to be used for analysis without exposing individual identities.
