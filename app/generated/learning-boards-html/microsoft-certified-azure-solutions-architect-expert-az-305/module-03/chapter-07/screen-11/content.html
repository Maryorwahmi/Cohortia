Azure Storage Account Auditing Configuration

Configuring diagnostic settings to send Blob service logs to Log Analytics.

# 1. Define variables
RESOURCE_GROUP_NAME="StorageAuditRG"
LOCATION="eastus"
STORAGE_ACCOUNT_NAME="auditedstorage$(openssl rand -hex 4)"
CONTAINER_NAME="sensitive-customer-data"
LOG_ANALYTICS_WORKSPACE_NAME="StorageAuditWorkspace$(openssl rand -hex 4)"

# 2. Create a resource group
az group create --name $RESOURCE_GROUP_NAME --location $LOCATION

# 3. Create an Azure Storage Account (StorageV2)
az storage account create --name $STORAGE_ACCOUNT_NAME \
    --resource-group $RESOURCE_GROUP_NAME --location $LOCATION \
    --sku Standard_LRS --kind StorageV2

# 4. Create a Blob Container
az storage container create --name $CONTAINER_NAME \
    --account-name $STORAGE_ACCOUNT_NAME --public-access off

# 5. Create a Log Analytics Workspace
az monitor log-analytics workspace create \
    --resource-group $RESOURCE_GROUP_NAME \
    --name $LOG_ANALYTICS_WORKSPACE_NAME --location $LOCATION

# 6. Get the Log Analytics Workspace ID
LOG_ANALYTICS_WORKSPACE_ID=$(az monitor log-analytics workspace show \
    --resource-group $RESOURCE_GROUP_NAME \
    --name $LOG_ANALYTICS_WORKSPACE_NAME --query id --output tsv)

# 7. Configure Diagnostic Settings for Storage Account
az monitor diagnostic-settings create \
    --name "SendBlobLogsToLA" \
    --resource $STORAGE_ACCOUNT_NAME \
    --resource-group $RESOURCE_GROUP_NAME \
    --resource-type Microsoft.Storage/storageAccounts \
    --workspace $LOG_ANALYTICS_WORKSPACE_ID \
    --logs '[{"categoryGroup": "allLogs", "enabled": true}]'

Step 1: Resource Setup

Define variables and create a resource group, storage account (StorageV2), and a blob container for sensitive data. This sets up the target for auditing.

Step 2: Log Analytics Workspace

Create an Azure Log Analytics Workspace. This workspace will centralize all the diagnostic logs from your storage account for easy querying and analysis.

Step 3: Configure Diagnostic Settings

Enable diagnostic settings for the storage account. Configure it to send all Blob service logs (read, write, delete, list operations) to the Log Analytics Workspace.

Verification

Perform sample blob operations (upload, download) to generate logs. Then, query the Log Analytics Workspace using KQL to verify log ingestion and visibility.

Key Takeaway

Configuring diagnostic settings for Azure Storage to Log Analytics provides detailed audit trails for blob operations, crucial for monitoring and security analysis.
