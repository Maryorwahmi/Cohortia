Azure SQL Database Auditing Configuration

Enabling comprehensive auditing for your Azure SQL Database to Log Analytics.

# 1. Define variables
RESOURCE_GROUP_NAME="SQLAuditRG"
LOCATION="eastus"
SQL_SERVER_NAME="mysqldbserver$(openssl rand -hex 4)"
SQL_DB_NAME="MyAuditedDatabase"
LOG_ANALYTICS_WORKSPACE_NAME="SQLAuditWorkspace$(openssl rand -hex 4)"

# 2. Create a resource group
az group create --name $RESOURCE_GROUP_NAME --location $LOCATION

# 3. Create a Log Analytics Workspace
az monitor log-analytics workspace create \
    --resource-group $RESOURCE_GROUP_NAME \
    --name $LOG_ANALYTICS_WORKSPACE_NAME --location $LOCATION

# 4. Create an Azure SQL Server and Database
az sql server create --name $SQL_SERVER_NAME \
    --resource-group $RESOURCE_GROUP_NAME --location $LOCATION \
    --admin-user "sqladmin" --admin-password "StrongPassword123!"
az sql db create --resource-group $RESOURCE_GROUP_NAME \
    --server $SQL_SERVER_NAME --name $SQL_DB_NAME --service-objective S0

# 5. Enable SQL Database Auditing
LOG_ANALYTICS_WORKSPACE_ID=$(az monitor log-analytics workspace show \
    --resource-group $RESOURCE_GROUP_NAME \
    --name $LOG_ANALYTICS_WORKSPACE_NAME --query id --output tsv)

az sql server audit-policy update \
    --resource-group $RESOURCE_GROUP_NAME --name $SQL_SERVER_NAME \
    --state Enabled \
    --log-analytics-workspace-resource-id $LOG_ANALYTICS_WORKSPACE_ID \
    --is-azure-monitor-target-enabled true

Step 1: Resource Setup

Define variables for unique resource names and create a dedicated resource group. This organizes your Azure assets and simplifies management.

Step 2: Log Analytics Workspace

Create an Azure Log Analytics Workspace. This will serve as the centralized repository for all your SQL audit logs, enabling powerful querying and analysis.

Step 3: SQL Server & Database

Provision an Azure SQL Server and the specific database you intend to audit. This is the target resource for which we'll be collecting access and operation logs.

Step 4: Enable Auditing

Update the SQL server's audit policy to 'Enabled' and specify the Log Analytics Workspace ID as the destination. This ensures logs are sent to Azure Monitor.

Key Takeaway

Automating SQL Database Auditing to Log Analytics provides a scalable and centralized solution for monitoring database activities and ensuring compliance.
