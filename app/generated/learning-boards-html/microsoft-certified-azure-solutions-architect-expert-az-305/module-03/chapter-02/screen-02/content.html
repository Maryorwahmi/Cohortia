Learning Objectives

What you'll achieve in this chapter.

Bloom's Taxonomy:
LearnUnderstandApplyMaster
01

Explain Importance of Encryption

Articulate why encrypting data in transit is critical for protecting against eavesdropping, tampering, and man-in-the-middle attacks. Understand the specific vulnerabilities data faces when in motion.

Verified Competency Milestone
02

Design TLS/SSL Solutions

Design solutions for securing network traffic between Azure resources and external endpoints using TLS/SSL. This includes proper configuration and certificate management.

Verified Competency Milestone
03

Implement VPNs for Hybrid Connectivity

Implement Virtual Private Networks (VPNs) to establish secure, encrypted tunnels over the public internet for hybrid connectivity between on-premises and Azure networks.

Verified Competency Milestone
04

Implement Azure ExpressRoute

Implement Azure ExpressRoute for secure, high-bandwidth, and low-latency private connectivity between on-premises infrastructure and Azure, bypassing the public internet.
