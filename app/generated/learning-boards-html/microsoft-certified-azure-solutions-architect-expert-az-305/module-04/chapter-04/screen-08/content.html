Understanding Usage and Live Metrics

Tracking user behavior and real-time application pulse

Live Metrics Stream
Real-time Pulse
Usage Monitoring

Understand user sessions, page views, and custom events to analyze user interactions.

Immediate Feedback

See the impact of changes or incidents as they happen, without aggregation delays.

Concrete Example

During a new feature rollout, Live Metrics Stream shows an immediate spike in failed requests, allowing the team to roll back before widespread user impact. Usage monitoring later confirms user adoption rates and popular features.

Key Takeaway

Usage monitoring provides insights into user behavior, while Live Metrics Stream offers real-time application performance data for immediate operational awareness.
