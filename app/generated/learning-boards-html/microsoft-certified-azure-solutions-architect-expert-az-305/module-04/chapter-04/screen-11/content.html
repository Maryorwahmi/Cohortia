Implementing Custom Events in Code

Tracking business actions with TelemetryClient

// Example: Tracking a custom event in .NET
telemetryClient.TrackEvent("CheckoutCompleted",
    new Dictionary<string, string> { { "PaymentMethod", "CreditCard" } },
    new Dictionary<string, double> { { "OrderTotal", 123.45 } });

Explanation

  • •TrackEvent Method: Records a custom event with a name, custom dimensions (string properties), and custom measurements (numeric values).
  • •Contextual Data: Attach relevant business context to events, such as payment method or order total, for richer analysis.
  • •Business Funnels: Use custom events to track progress through critical user flows and identify drop-off points.

Concrete Example

A gaming application might track a 'LevelCompleted' event with 'LevelName' (dimension) and 'TimeTakenSeconds' (measurement) to analyze player engagement and difficulty across different game stages.

Key Takeaway

Implementing custom events with `TelemetryClient.TrackEvent` allows you to capture rich, business-specific data, providing deeper insights into application usage and outcomes.
