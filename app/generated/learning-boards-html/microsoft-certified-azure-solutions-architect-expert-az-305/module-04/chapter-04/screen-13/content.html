Common Mistakes in Application Insights - Part 2

Leveraging custom telemetry and ensuring data security

Lack of Custom Telemetry

Relying solely on out-of-the-box metrics, missing valuable business insights specific to your application's unique logic and user journeys.

Security Risks

  • •Sending sensitive data (e.g., PII, passwords) to Application Insights through custom events or properties.
  • •Always sanitize data before sending it to prevent accidental exposure of confidential information.

Concrete Example

An architect fails to implement custom events for user sign-ups, missing a critical business conversion metric. Later, a developer accidentally logs a user's full email address in a custom property, creating a PII compliance risk and potential data breach.

Key Takeaway

Leverage custom telemetry for business insights and rigorously sanitize all data to prevent security risks and ensure compliance.
