Creating Custom Dashboards and Workbooks

A practical guide to building visual operational views

  • •

    Dashboards: Click 'New dashboard' in Azure portal, then add and arrange tiles.

  • •

    Workbooks: Start from 'Workbooks' blade, select template or scratch, add 'Query', 'Metrics', 'Text' steps.

  • •

    Interactivity: Use parameters in Workbooks for dynamic filtering (e.g., time pickers).

Key Takeaway

Both tools offer intuitive interfaces for combining diverse data sources into meaningful, customizable visual reports.
