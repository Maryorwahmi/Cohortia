The Fundamentals of Querying Log Analytics Data

Purpose-Built for Logs

KQL is a read-only query language optimized for large-scale log data, enabling efficient filtering, aggregation, and analysis.

Chained Operators

Queries are built by chaining operators with the pipe (|) symbol, passing results from one step to the next for sequential processing.

Key Capabilities

Filter data by time and conditions, aggregate metrics (count, sum, avg), join tables, and visualize results in charts.

Basic KQL Query Structure

A KQL query starts with a table name, followed by a series of operators that refine and transform the data. This sequential approach makes complex analysis manageable.

TableName
| where TimeGenerated > ago(1h)
| where Level == "Error"
| project TimeGenerated, Message
Key Takeaway

KQL is the expressive language for Log Analytics, enabling efficient data exploration through chained operators, starting with a table name and progressively refining results.
