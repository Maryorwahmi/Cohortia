Querying Log Analytics Data with KQL

A Step-by-Step Lab Walkthrough

01

Navigate to Workspace

In the Azure portal, find your Log Analytics Workspace and open the 'Logs' query editor. This is your primary interface.

02

Explore Tables

In the left pane, expand 'Tables' to see available log tables like Heartbeat, Perf, Event, and SigninLogs.

03

Write Basic Queries

Execute queries like Heartbeat | take 10 to retrieve recent records and understand basic KQL syntax.

04

Analyze Performance Data

If you have VM data, use Perf table queries to chart CPU usage over time, e.g., Perf | where ObjectName == "Processor" ... | render timechart.

05

Investigate Sign-ins

Query SigninLogs to identify failed Azure AD sign-in attempts by IP address and user, e.g., SigninLogs | where ResultType != 0 ....

06

Experiment & Optimize

Modify queries, change time ranges, add filters, and try different aggregation functions to deepen your KQL mastery.

Key Takeaway

Hands-on practice with KQL in the Log Analytics query editor is essential for developing proficiency in data exploration, analysis, and troubleshooting.
