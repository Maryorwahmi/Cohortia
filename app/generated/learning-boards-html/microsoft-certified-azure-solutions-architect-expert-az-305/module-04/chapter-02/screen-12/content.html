Configuring a VM CPU Alert

Creating a metric alert to monitor virtual machine performance.

Prerequisites

  • •An active Azure subscription.
  • •An existing Azure Virtual Machine (any size, running).
  • •The VM-HighCPU-Alerts action group created in the previous step.

Step-by-Step: Create a Metric Alert Rule

  1. 1In Azure portal, navigate to your Azure Virtual Machine.
  2. 2Under "Monitoring", select "Alerts" and click "Create alert rule".
  3. 3Under "Condition", click "Add condition".
  4. 4For Signal name, search for and select "Percentage CPU".
  5. 5Configure: Threshold: Static, Operator: Greater than, Aggregation type: Average, Threshold value: 80, Aggregation granularity (Period): 5 minutes, Frequency of evaluation: 1 minute. Click "Done".
  6. 6Under "Actions", click "Add action groups" and select VM-HighCPU-Alerts. Click "Select".
  7. 7Under "Details", set Alert rule name: VM-HighCPU-Alert and Severity: Sev 2 (Warning). Ensure "Enable rule upon creation" is checked.
  8. 8Click "Review + create" and then "Create".

Testing the Alert

  • •You can simulate high CPU usage using tools like stress-ng on Linux VMs or by running CPU-intensive tasks on Windows VMs.
  • •Monitor your email for notifications from the action group.
Key Takeaway

Successfully creating a metric alert and linking it to an action group establishes a proactive monitoring system that notifies you of critical performance issues, such as high CPU usage.
