Setting Up Alert Notifications

Step-by-step guide to creating an action group in the Azure portal.

Prerequisites

  • •An active Azure subscription.
  • •Access to the Azure portal.

Step-by-Step: Create an Action Group

  1. 1In Azure portal, search for "Monitor" and select it.
  2. 2Navigate to "Alerts" > "Action groups" and click "Create".
  3. 3Enter Action group name: VM-HighCPU-Alerts and Short name: VMCPU.
  4. 4Under "Notifications", click "Add notification".
  5. 5Set Notification type: Email/SMS/Push/Voice, Name: EmailOpsTeam, and enter your Email address. Click "OK".
  6. 6Click "Review + create" and then "Create".

Understanding the Configuration

  • •Action Group Name: A descriptive name for your group of actions.
  • •Short Name: A concise identifier used in alert payloads.
  • •Notifications: Defines how and to whom alerts are communicated (e.g., email, SMS).
  • •Resource Group: Logical container for your action group.
Key Takeaway

Creating an action group is the first step in defining automated responses to alerts, ensuring that the right people are notified through chosen channels when an issue arises.
