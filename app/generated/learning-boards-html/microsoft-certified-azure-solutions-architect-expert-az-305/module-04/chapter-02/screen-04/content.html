The Pillars of Azure Observability

Exploring Azure Monitor's foundational data sources and platforms.

Azure Monitor Overview

Azure Monitor is the central service for collecting, analyzing, and acting on telemetry from your Azure and hybrid environments. It provides a unified view of your application and infrastructure health.

Key Components

  • Data Sources: Where telemetry originates (resources, applications, OS).
  • Data Platforms: Metrics (numerical) and Logs (structured text).
  • Analysis & Alerting: Tools for visualization, querying, and proactive notifications.
Key Takeaway

Azure Monitor provides a comprehensive, unified platform for collecting, analyzing, and acting on telemetry data from all your Azure resources, ensuring full observability.

Common Data Sources

  • Platform Metrics: Automatically collected numerical data (e.g., CPU, network I/O).
  • Activity Logs: Control plane operations (e.g., resource creation, deletion).
  • Diagnostic Logs: Resource-specific logs for deeper insights (e.g., web server logs, query logs).
  • VM Agents: Collect guest-level performance and event logs from virtual machines.
Common Misconception

Many assume all logs are automatically collected. In reality, detailed diagnostic logs often require explicit configuration to be sent to a persistent store.
