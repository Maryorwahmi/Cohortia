Data Sources

Platform Metrics, Activity Logs, and Diagnostic Logs

Understanding the unique insights each data type provides.

Platform Metrics

Numerical data automatically collected by Azure for most services, providing real-time performance indicators.

  • •Purpose: Real-time performance monitoring.
  • •Examples: CPU usage, network latency, disk I/O.
  • •Use Case: Alerting on high CPU utilization.

Activity Logs

Records control plane operations (create, update, delete) performed on resources in an Azure subscription.

  • •Purpose: Auditing, security, change tracking.
  • •Examples: VM creation, resource group deletion.
  • •Use Case: Identifying who deleted a resource.

Diagnostic Logs

Resource-specific logs providing granular data about the internal operations of an Azure service.

  • •Purpose: Deep troubleshooting, application insights.
  • •Examples: HTTP request logs, database query logs.
  • •Use Case: Debugging application errors.
Why it matters

Choosing the correct data source for your monitoring needs prevents 'blind spots' and ensures you have the right information for effective analysis and troubleshooting.

Key Takeaway

Differentiating between Platform Metrics, Activity Logs, and Diagnostic Logs is fundamental for designing a precise and efficient Azure monitoring strategy.
