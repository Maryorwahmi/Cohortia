Optimizing Data Ingestion: Selective Collection

The most effective way to reduce ingestion costs is to be highly selective about what data you collect from your Azure resources.

Filter Verbose Logs

In production, filter debug logs to warnings and errors only. Full verbosity is rarely needed and costly.

Configure Agent Collection

For VMs, collect only necessary performance counters and event logs, not every available metric.

Choose Diagnostic Categories

Select only essential log categories for Azure resources, avoiding 'allLogs' unless critical.

Example: App Service Logs
AppServiceHTTPLogs (Essential)
AppServiceConsoleLogs (Essential)
AppServicePlatformLogs (Conditional)
AllLogs (Avoid in Production)

Focus on critical categories for daily operations; enable verbose logs only for targeted troubleshooting.

Key Takeaway

Being selective about data collection at the source is the most direct way to control Azure Monitor ingestion costs.
