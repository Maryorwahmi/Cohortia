Key Concepts

Essential terms and ideas from this chapter.

Data Ingestion Costs

The primary cost driver in Log Analytics, based on the volume of data sent to the workspace.

Data Retention Costs

Costs associated with storing logs beyond the initial free period in Log Analytics.

Data Collection Rules (DCRs)

Configurations used with Azure Monitor Agent to define what data to collect and how to transform it before ingestion.

Summary Takeaway

Effective cost management in Azure monitoring begins with a clear understanding of data ingestion, retention, and collection rules.
