Key Concepts: Core Auditing Tools

Essential services for monitoring your Azure environment.

Azure Activity Log

A platform log providing insight into subscription-level events, such as administrative operations and service health.

Azure AD Audit Logs

Records changes made within Azure Active Directory, such as user and group management, and application registrations.

Azure AD Sign-in Logs

Records all sign-in attempts to Azure AD, including user, application, device, and location information.

Summary Takeaway

Leveraging Azure's native Activity Log and Azure AD logs provides foundational visibility for auditing resource changes and identity-related activities.
