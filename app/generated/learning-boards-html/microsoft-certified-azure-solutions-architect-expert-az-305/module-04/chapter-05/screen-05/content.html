Understanding the Azure Activity Log

Your primary source for control plane operations and resource changes.

What the Activity Log Records

  • •**Resource Management Events:** Creation, updates, and deletions of Azure resources.
  • •**Service Health Events:** Incidents and planned maintenance affecting your services.
  • •**Role Assignments:** Changes to Azure Role-Based Access Control (RBAC).
  • •**Security Events:** Specific security-related actions and alerts.

Key Attributes of Logged Events

Who

User or service principal.

What

Operation performed.

When

Timestamp of the event.

Where

Resource and location.

**Example:** If a critical VM is deleted, the Activity Log shows the user, the deletion operation, the time, and the VM's resource ID.

Key Takeaway

The Azure Activity Log is essential for auditing all control plane operations, providing critical details for accountability and incident investigation.
