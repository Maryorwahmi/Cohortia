Summary Key Concepts — Part 2

What to Remember

EBS
Persistent block volumes with snapshot backups.
Instance Store
Host-attached and ephemeral; for temporary caches and scratch space.
S3
Object storage for highly durable, internet-accessible assets and backups.
Summary Takeaway

Decide using three tests: will data persist beyond instance life, can the workload tolerate interruption, and is workload predictable? Those answers map to pricing and storage decisions that control cost and availability.
