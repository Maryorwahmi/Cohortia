Application Hands-on Scenarios

Scenario Practice

Apply pricing and storage decisions to example workloads and validate your recommendations.

Workload A — 24/7 production web app
Recommendation: Reserved Instances or Savings Plans for predictable, always-on compute; EBS for database storage.
Workload B — Dev/Test (9–5 weekdays)
Recommendation: On-Demand to pay only for actual usage and retain agility during development cycles.
Workload C — Interruptible batch processing
Recommendation: Spot Instances with checkpointing; Instance Store for temporary logs; persist outputs to EBS or S3 as needed.
Storage mapping
  • OS and application files for a database server: EBS (persistent block storage).
  • Temporary log files discardable after processing: Instance Store (ephemeral).
  • Static images and videos for a website: Amazon S3 (object storage).
Reflective question

Which workload in your own environment could immediately benefit from a Savings Plan or Spot deployment, and what safeguards would you add?
