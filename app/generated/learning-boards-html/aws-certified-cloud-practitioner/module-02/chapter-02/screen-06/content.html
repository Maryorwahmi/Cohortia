Reserved Instances (RIs)

A billing discount applied to matching On-Demand usage when you commit for 1 or 3 years.

How RIs work
  • Not physical instances — a billing construct that discounts matching usage.
  • Match attributes such as instance type, region, and tenancy to apply the discount.
  • Offer up to large percentage discounts compared to On-Demand for long-term commitments.
Pro tip: Track your instance attribute usage to ensure RI coverage aligns with deployments.
Decision factors
Choose RIs when you have predictable, long-running workloads and you can commit to a specific instance family and region.
Concrete example: a database server running 24/7 can use RIs to lower steady-state costs.
Misconception: RIs lock you into a single instance ID — they actually match by attributes, not instance identity.
Key Takeaway

Use RIs for big, predictable costs you can commit to; confirm your instance attributes align with the RI scope.
