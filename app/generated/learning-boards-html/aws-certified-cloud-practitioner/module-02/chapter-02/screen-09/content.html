Amazon Elastic Block Store (EBS)

Network-attached, persistent block storage for EC2. Data persists independently of instance lifecycle within an AZ.

Core properties
  • Persistent: volumes survive instance stops and terminations unless deleted.
  • AZ-scoped: volumes are available in a single Availability Zone.
  • Snapshots: incremental backups stored in S3 for recovery and migration.
Operational note
Plan snapshots and restore procedures to recover from failure and enable cross-AZ or cross-region recovery when needed.
When to use EBS
Use for OS disks, databases, and applications needing low-latency block storage and persistence beyond instance lifetime.
Concrete example
Attach an EBS volume to a database server; take periodic snapshots for backups and restore when needed.
