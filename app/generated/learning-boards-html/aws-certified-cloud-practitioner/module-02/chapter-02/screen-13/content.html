Auto Scaling Groups (ASG)

Define min, desired, and max capacity and use scaling policies to adjust instance count automatically.

ASG components
  • Desired, minimum, and maximum instance counts.
  • Scaling policies tied to metrics or schedules.
  • Health checks and instance replacement for fault tolerance.
Example
Scale out when average CPU exceeds a threshold; scale in when it falls below the threshold for a sustained period.
Design tips
  • Use load balancers so new instances receive traffic immediately.
  • Set sensible warm-up and cooldown periods to avoid flapping.
  • Combine with reserved capacity for baseline reliability and Spot for scaling bursts when appropriate.
Key Takeaway

ASGs provide automated elasticity and instance replacement; tune policies, health checks, and provisioning to balance responsiveness and cost.
