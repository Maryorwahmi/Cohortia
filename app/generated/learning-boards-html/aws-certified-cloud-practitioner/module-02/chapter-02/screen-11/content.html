Definition Instance Store

Instance Store

Temporary, host-attached storage whose data is lost when instances stop or terminate.

Key properties
  • Physically attached to the host; very low latency.
  • Ephemeral: data does not survive instance stop/termination or host failure.
  • Appropriate for caches, scratch files, and temporary intermediates.
Best practices
  • Never store critical or long-term data on Instance Store.
  • Replicate important state to EBS or S3 and use Instance Store for performance-only needs.
Concrete example
Using Instance Store for temporary cache files in a distributed processing cluster while the canonical data lives in S3 or EBS-backed storage.
