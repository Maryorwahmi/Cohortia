Introduction to Amazon EC2
Elastic Compute Cloud: rent virtual servers that scale with demand
What EC2 provides
Resizable virtual servers called instances, configurable with AMIs and instance types so you pay only for what you use.
Security basics
Key pairs for admin access and security groups as instance-level firewalls. Follow least privilege when opening ports.
Why it matters
EC2 underpins many architectures. Choosing the right AMI and instance type controls cost and performance.

Quick scenario
An Amazon Linux 2 AMI plus a t2.micro instance type can host a small web server. You’d generate a key pair, configure a security group to permit HTTP and SSH from trusted IPs, then launch and connect via SSH using your private key.
