SSH connection checklist
Prepare key permissions and confirm network access
Checklist
  • Private key (.pem) is stored locally and permissioned (read-only for owner).
  • Security group allows SSH from your source IP.
  • Instance has a public IP or an accessible network path.
  • Username matches the AMI (ec2-user for Amazon Linux 2).
Common error
Permissions too open on the private key will prevent SSH from using it; adjust permissions before connecting.
Terminal example
ssh -i my-webserver-key.pem ec2-user@ec2-12-34-56-78.compute-1.amazonaws.com
Concrete note
Do not share the .pem file. Use strict file permissions and restrict SSH access in the security group to trusted IPs.
