Key Concepts
Three compact reminders
EC2 Instance
A virtual server running an OS and applications.
AMI
Template for launching consistent instances.
Security
Key pairs for SSH; security groups for traffic control.
Takeaway
EC2 building blocks shape performance, cost, and security. Use AMIs, right-size instance types, secure keys, and restrict traffic with security groups.
