Instance type families
Compare capacity trade-offs to choose the best fit
General purpose
Balanced CPU and memory for a wide range of workloads, useful for small web servers and microservices.
Compute optimized
High CPU performance for batch processing or compute-bound tasks.
Memory optimized
Extra RAM for in-memory databases and analytics workloads.
Concrete example
A t2.micro is suitable for a low-traffic website because it provides a small amount of CPU and memory at low cost. For a CPU-heavy worker you would consider a compute-optimized instance that gives better throughput per dollar for that workload.
Misconception
Bigger always better is false. Oversizing costs more and may not improve throughput if the workload is I/O bound or limited by other resources.
Pro tip
Profile actual CPU and memory usage before choosing a production instance type. Consider horizontal scaling as an efficient alternative to a single large instance.
