Module 2 › Chapter 2.1 › What is an EC2 Instance?
Definition
EC2 instance
A virtual server in AWS that runs an operating system and your applications and can be started, stopped, and resized.
Analogy
Think of an instance as a rented virtual computer. You select its template and resources, similar to choosing a laptop model and preinstalled software.
Key Takeaway
Instances act like full virtual machines: they carry OS, apps, identity, and network access, and decisions affect cost and performance.
Primary teaching area
Behavior
  • Runs a full OS and applications.
  • Has a network identity and IP address.
  • Can be resized or replaced as demand changes.
Common uses
  • Web servers, application servers, dev environments.
  • Batch processing and ephemeral compute tasks.
  • Part of larger architectures behind load balancers.
Concrete example
Launch Amazon Linux 2, install a web server, and allow HTTP traffic in a security group. The instance serves web pages and can be stopped to avoid charges when idle.
