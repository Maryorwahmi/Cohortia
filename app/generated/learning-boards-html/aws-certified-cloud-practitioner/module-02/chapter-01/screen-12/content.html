Scenario: Launch a web server
Choose components and explain the rationale
AMI
Amazon Linux 2 — Linux OS ideal for web apps and the default Amazon-provided image.
Instance type
t2.micro — small, general-purpose instance suitable for low-traffic web servers and dev environments.
Key pair
my-webserver-key with a .pem private key kept locally and permissioned strictly.
Security group rules (inbound)
HTTP: TCP 80, Source: 0.0.0.0/0 (public). HTTPS: TCP 443, Source: 0.0.0.0/0. SSH: TCP 22, Source: your home IP (e.g., 203.0.113.42/32).
Key takeaway
Make deliberate choices that balance accessibility and security: allow only the traffic necessary for the server to function.
