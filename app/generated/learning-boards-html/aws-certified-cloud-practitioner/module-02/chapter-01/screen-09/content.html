Module 2 › Chapter 2.1 › Launching an EC2 Instance
Launch sequence
A repeatable set of steps to start a running instance
Step 1
Choose an AMI (e.g., Amazon Linux 2).
Step 2
Select an instance type (t2.micro for small workloads).
Step 3
Configure details: count, network, IAM role.
Step 4
Add storage volumes (EBS) for persistence.
Step 5
Add tags for organization and identification.
Step 6
Configure a security group to permit required traffic.
Concrete example
Pick Amazon Linux 2, t2.micro, single instance, add an EBS root volume, tag Name:web-server, add inbound rules for HTTP and SSH from your IP, then launch with a new key pair.
