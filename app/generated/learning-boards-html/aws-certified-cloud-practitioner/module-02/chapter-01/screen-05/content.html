Module 2 › Chapter 2.1 › Amazon Machine Image (AMI)
What is an AMI?
Pre-configured instance template
Contains an OS and optional application components so new instances start in a known state.
When to create one
Create custom AMIs after configuring an instance to include application code and dependencies for repeatable deployments.
Key Takeaway
Use AMIs to standardize instance creation and reduce setup time when scaling or replacing servers.
AMI examples and notes
Public AMI
Provided by AWS, e.g., Amazon Linux 2, ready for general use.
Custom AMI
Created from a configured instance to capture software, settings and optimizations.
Maintenance
Version and update AMIs to include patches; avoid running long-lived unpatched images in production.
Concrete example
Create a custom AMI from a web server with application code preinstalled. Launch new instances from that AMI to scale horizontally with identical configuration.
