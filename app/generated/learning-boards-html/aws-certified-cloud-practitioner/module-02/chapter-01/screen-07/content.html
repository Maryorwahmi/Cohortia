What is a key pair?
Cryptographic public/private keys used for secure SSH access to instances.
Process
  1. Generate key pair in console or tool.
  2. Download private key (.pem) and keep it secure.
  3. Associate the key with the instance at launch.
Concrete example
Generate my-webserver-key, store my-webserver-key.pem locally with strict permissions, and use it with SSH to connect to your Linux instance.
Common mistakes
Losing the private key prevents SSH access; sharing or exposing the private key allows unauthorized access.
Warning
Never leave SSH open to the world and never store private keys in public locations.
Takeaway
Key pairs are central to secure instance management. Protect the private key and control SSH access via security groups.
