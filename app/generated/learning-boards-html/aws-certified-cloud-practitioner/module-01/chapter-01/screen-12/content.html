Service Models — IaaS, PaaS, SaaS
IaaS
You control OS, middleware, and apps; provider manages physical resources.
Example: virtual machines and raw object storage for your app stack.
PaaS
Provider manages platform; you deploy code and data.
Example: managed app platforms that handle runtime, scaling, and patches.
SaaS
Complete applications managed by provider; you are an end user.
Example: hosted email or collaboration tools where you only configure users and data.
Layered cake
Visualize responsibilities as layers: infrastructure, platform, application. Move up to reduce operational work.
Key Takeaway
Pick a service model that fits your need for control versus speed of delivery.
