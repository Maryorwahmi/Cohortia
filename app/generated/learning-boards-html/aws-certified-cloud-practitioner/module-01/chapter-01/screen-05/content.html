Definition
On-demand self-service
Provision compute or storage automatically without human provider interaction.
• Automate requests through a console or API and receive resources in minutes.
• Enables faster testing, CI pipelines, and ephemeral environments.
• Governance tip: use identity and quotas to avoid runaway costs.
Example
A script requests a VM and storage to run integration tests and then destroys them on completion.
Definition
Broad network access
Services are reachable over standard networks using common clients and protocols.
• Accessible from laptops, mobile devices, or thin clients using standard APIs.
• Encourages platform-agnostic architectures and global collaboration.
• Misconception: network access does not eliminate the need for secure connections and identity controls.
Scenario
A developer in one region triggers a build that provisions resources in another region using the provider API.
Key Takeaway
Speed and reach are powerful but must be paired with access controls and network security.
