Practice Scenario
Your company runs a web application with:
5 physical servers (approx. m5.large each)
10 TB storage
One IT staff member spending 20% time
Annual costs:
  Hardware (amortized): $10,000
  Software licenses: $2,000
  Data center, power, cooling: $5,000
  IT staff cost (20% of $80,000): $16,000
  Backup/recovery: $3,000
Use this scenario to list on-premises cost categories and map them to AWS services such as compute, storage, and managed backup.
How to map costs
  • • Hardware amortization → Compute (EC2) and instance billing or managed compute alternatives.
  • • Storage and backups → Object or block storage services and snapshot/backup charges.
  • • Data center utilities → Eliminated by provider, replaced by service fees.
  • • Staff time → Shifts from maintenance to higher-value cloud operations and engineering.
  • • Software licenses → Either migrated, replaced by managed services, or continued as licenses hosted on cloud instances.
Key Takeaway

A simple scenario helps expose where costs move and which qualitative benefits to highlight, such as faster deployment and fewer maintenance tasks.
