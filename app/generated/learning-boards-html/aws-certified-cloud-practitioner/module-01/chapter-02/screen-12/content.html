Shared Responsibility Model
Understand which security tasks are handled by the provider and which remain with you.
• Provider is responsible for the security of the cloud infrastructure and global facilities.
• You are responsible for security in the cloud: data, applications, OS, and access controls.
• Misconfigurations on the customer side are common causes of security incidents.
Operational checklist
  • • Configure network controls, access policies, and encryption.
  • • Patch managed operating systems and maintain backups.
  • • Monitor logs and set alerts for suspicious activity.
Misconception

Believing the cloud provider handles all security. In reality, many controls and configurations remain the customer's responsibility.
