Module 2 › Chapter 1.3 › Gaming platform scenario
Task mapping
1. Primary Region

Choose us-east-1 to serve North American users and access a broad set of services.

2. Multi-AZ design

Deploy web servers across at least two AZs and replicate databases across those AZs for failover.

3. European data residency

Store European user profiles in eu-west-1 or eu-central-1 to meet residency requirements.

Performance

Use CloudFront and Regional Edge Caches to deliver game assets quickly to players in Asia and Europe while keeping authoritative data in chosen Regions.

Misconception

Caching assets globally is not the same as storing private user data globally; keep sensitive data in-region for residency compliance.
