Layered architecture
Region

Choose for compliance and primary user base.

AZs

Distribute compute and replicate data across AZs for local failover.

Edge caching

Use CloudFront Edge Locations and Regional Edge Caches for global assets.

Automation & DR

Automate recovery with IaC and plan cross-Region DR if required.

Architecture card
Example pattern

Primary Region with services across AZ A and B, asynchronous cross-Region backups, CloudFront for global asset delivery, and IaC for automated rebuilds.

Why it matters

Combining these patterns reduces downtime, meets compliance, and improves global user experience.
