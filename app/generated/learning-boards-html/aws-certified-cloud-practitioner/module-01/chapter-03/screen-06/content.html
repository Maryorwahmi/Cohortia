Module 2 › Chapter 1.3 › Availability Zone
Definition & properties
  • AZs are isolated physical locations inside a Region with independent power and networking.
  • AZs are interconnected with low-latency fiber to enable synchronous replication and failover.
  • Design across AZs for high availability and disaster tolerance.
Concrete example

Run application servers across us-east-1a and us-east-1b and place database replicas so that an AZ outage still leaves a healthy replica operational.

Design guidance
Stateless tiers

Distribute across AZs behind a load balancer for horizontal availability.

Stateful tiers

Use replication or managed multi-AZ services to keep data available if an AZ fails.

Key takeaway

Distribute components and plan replication; AZs are the primary local fault domains.
