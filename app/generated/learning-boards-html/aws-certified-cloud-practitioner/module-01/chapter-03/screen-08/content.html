What Edge Locations do

Cache copies of frequently requested content to reduce latency and offload origin servers.

Use cases
  • Delivering images, videos, and static website assets globally.
  • Reducing origin load and bandwidth costs for popular assets.
Behavior

If an Edge Location lacks an item, it checks a Regional Edge Cache, then the origin, minimizing repeated long trips to the Region.

Concrete example

A video stored in us-east-1 is delivered to an Australian user through an Edge Location in Sydney, reducing buffering and improving start time.

Misconception

Edge caching does not change where the authoritative copy of data resides; it improves delivery speed for cached assets only.
