Module 2 › Chapter 1.3 › What is an AWS Region?
Definition

A Region is a physical geographic area that contains AWS infrastructure and serves as an isolated unit for resilience and compliance.

Why choose a Region
  • Data residency and legal compliance.
  • Lower latency by placing resources near users.
  • Service availability and cost considerations.
Concrete example

If most customers are in Europe, use eu-west-1 or eu-central-1 to keep user data in-region and reduce access time.

Key takeaway

Regions set the scope for where resources live; choose them based on compliance and latency first.

Common misconceptions
  • Thinking a Region is one data center. It contains multiple AZs and data centers.
  • Assuming all services are available in every Region. Service availability varies.
Scenario card
Selecting a Region for EU privacy

Requirement: user profiles for EU residents must be stored in the EU. Action: choose a European Region such as eu-west-1 or eu-central-1 to meet residency rules.
