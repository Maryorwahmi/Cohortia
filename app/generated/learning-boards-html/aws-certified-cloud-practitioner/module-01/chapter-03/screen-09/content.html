Module 2 › Chapter 1.3 › Regional Edge Caches
Role and behavior

Regional Edge Caches are larger caching locations positioned between Edge Locations and the origin. They store more content and reduce the number of requests that reach your origin Region.

Flow

Client → Edge Location → Regional Edge Cache → Origin Region.

When to use

Global distribution of moderate-popularity assets benefits from Regional Edge Caches to increase hit ratio.

Analogy

Edge Locations are neighborhood caches; Regional Edge Caches are regional libraries that keep a wider selection, reducing trips to the origin library.

Misconception

Regional Edge Caches reduce origin hits but do not replace the need for resilient and scalable origin servers.
