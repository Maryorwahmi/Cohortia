Quick start commands
Run these in psql connected to project_alpha_db.
-- Connect
psql -U postgres -d project_alpha_db

-- Insert customers and return ids
INSERT INTO customers (first_name, last_name, email, phone_number) VALUES
('John','Doe','john.doe@example.com','111-222-3333'),
('Jane','Smith','jane.smith@example.com','444-555-6666')
RETURNING customer_id, email;
Safety step
Before UPDATE or DELETE, run SELECT with the same WHERE to confirm affected rows.
Follow-up actions
-- Update and return results
BEGIN;
UPDATE customers
SET email = 'johndoe@newdomain.com', loyalty_status = 'silver'
WHERE customer_id = 1
RETURNING *;
-- If OK: COMMIT; else: ROLLBACK;

-- Truncate a temporary table and restart identity
TRUNCATE TABLE temp_logs RESTART IDENTITY;
Key takeaway
Combine explicit columns, RETURNING, and transactions to perform verifiable, safe DML operations.
