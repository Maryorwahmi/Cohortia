Module 2 › Chapter 2.3 › Quick Reference
INSERT
Explicit columns. Omit serials. Use RETURNING to get ids.
UPDATE / DELETE
Preview with SELECT. Always use WHERE. Wrap in transactions for safety.
TRUNCATE
Fast reset. RESTART IDENTITY to reset sequences. Use CASCADE when necessary.
Final takeaway

Apply explicitness, preview, and transactional safety to make DML predictable and recoverable.
