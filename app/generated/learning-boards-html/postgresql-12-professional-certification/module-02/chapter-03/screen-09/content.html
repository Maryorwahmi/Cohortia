Module 2 › Chapter 2.3 › TRUNCATE vs DELETE
DELETE
Row-by-row removal, triggers fire, full logging, granular and auditable.
-- Delete all rows (dangerous)
DELETE FROM customers;

-- Delete by condition
DELETE FROM orders WHERE status = 'cancelled' RETURNING order_id;
When to use
Use DELETE when you need triggers, audit logs, or selective removal.
TRUNCATE
Fast reset of table storage; can restart identity sequences and optionally cascade to dependents.
-- Truncate a table and restart its sequence
TRUNCATE TABLE temp_logs RESTART IDENTITY;

-- Truncate multiple tables and cascade
TRUNCATE TABLE orders, order_items RESTART IDENTITY CASCADE;
When to use
Use TRUNCATE for test data resets or administrative cleanup when full table clearing and sequence reset is desired.
