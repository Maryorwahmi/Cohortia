Learning Objectives
Learn the commands and safety habits for DML
Bloom: Learn → Understand → Apply → Master
01
Insert rows safely
Add new data with explicit column lists and defaults. This keeps inserts robust when schemas change.
VERIFIED COMPETENCY MILESTONE
02
Update with precision
Use WHERE clauses to target rows. Practice rolling back changes in a transaction to avoid mistakes.
VERIFIED COMPETENCY MILESTONE
03
Delete with care
DELETE removes rows per your WHERE clause. Know how foreign keys will allow or block deletions.
VERIFIED COMPETENCY MILESTONE
04
TRUNCATE vs DELETE
Understand when to use TRUNCATE for speed and how RESTART IDENTITY and CASCADE affect dependent tables.
VERIFIED COMPETENCY MILESTONE
