Common ALTER operations
-- Add a new column
ALTER TABLE products
ADD COLUMN weight_kg NUMERIC(5, 2);

-- Change the data type (may fail if data doesn't conform)
ALTER TABLE products
ALTER COLUMN description TYPE VARCHAR(1000);

-- Rename a column
ALTER TABLE products
RENAME COLUMN stock_quantity TO available_stock;

-- Add a CHECK constraint
ALTER TABLE products
ADD CONSTRAINT chk_weight_positive CHECK (weight_kg >= 0);

-- Drop a constraint
ALTER TABLE products
DROP CONSTRAINT chk_weight_positive;
Operational guidance
When adding NOT NULL to existing tables, add as nullable, backfill in batches, then set NOT NULL. Test ALTERs on staging first.
Concrete example
Changing description to VARCHAR(1000) is a narrowing operation and can fail or require validation of existing rows before altering the type.
Key Takeaway
Plan ALTER operations, anticipate table rewrites, and use backfills to make non-disruptive changes on production systems.
