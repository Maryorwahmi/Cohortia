Module 02 › Chapter 2.2 › Quick Reference
Types
NUMERIC for money, TIMESTAMP WITH TIME ZONE for global events, TEXT for flexible strings.
Constraints
PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK — apply to enforce invariants.
Schema changes
Use staged ALTER patterns, backfills, and validate with psql before applying to production.
Final tip: treat the database schema as the canonical policy engine for data correctness — it prevents many classes of bugs early.
