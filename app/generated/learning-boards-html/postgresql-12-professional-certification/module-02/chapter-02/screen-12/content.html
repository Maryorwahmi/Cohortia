Module 02 › Chapter 2.2 › DROP & CASCADE
Commands to be cautious with
-- Drop a table (destructive)
DROP TABLE table_name;

-- Drop table and dependents (use with extreme caution)
DROP TABLE table_name CASCADE;

-- Drop a column (may need cascade)
ALTER TABLE table_name DROP COLUMN column_name;
Warning
CASCADE will remove dependent objects. Confirm dependencies first and always take backups before destructive operations.
Practical step
If you must remove a column, consider deprecating it first and monitoring code paths before executing DROP COLUMN.
Key Takeaway
Treat DROP and CASCADE as irreversible operations; validate dependencies and back up before proceeding.
