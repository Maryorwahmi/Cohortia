Module 02 › Chapter 2.2 › NUMERIC vs FLOAT
Comparison snapshot
NUMERIC
Exact decimal storage, use for money and fixed-precision values.
FLOAT / REAL
Approximate binary floats, useful for large-scale scientific computations where small errors are acceptable.
Concrete example
For order totals, use NUMERIC(10,2) so cents are exact. Using FLOAT risks small rounding differences in sums and comparisons.
Misconception
Don't assume FLOAT is okay just because values look correct on small samples; edge cases will reveal rounding anomalies.
Key Takeaway
Match numeric type to your accuracy needs. For financial accuracy, NUMERIC is the safer choice.
