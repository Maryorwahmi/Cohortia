Module 02 › Chapter 2.2 › Data Types
Common types and uses
  • INT, BIGINT — integer counters and ids.
  • NUMERIC(precision, scale) — exact decimals for money and measured quantities.
  • VARCHAR(n), TEXT — variable-length strings; TEXT has no length limit.
Time and semi-structured data
TIMESTAMP WITH TIME ZONE for global events; JSONB for document-like payloads with indexing options.
Performance notes
Smaller types can reduce storage and index size. But premature narrowing can force costly migrations later.
Concrete example
Choose NUMERIC(10,2) for price to store two decimal places reliably. Avoid FLOAT for financial calculations where exact cents matter.
Misconception
VARCHAR(255) is not always a safe default. If you later need longer text, you'll perform a narrowing or type change that can fail or be costly.
Key Takeaway
Pick types that reflect business rules and long-term needs; prefer precision for money and global-aware timestamps for user events.
