Module 02 › Chapter 2.2 › Add NOT NULL Safely
Step-by-step
  1. Add the column nullable: ALTER TABLE ... ADD COLUMN new_col TYPE;
  2. Backfill existing rows in batches with UPDATE statements.
  3. Optionally set a DEFAULT value for new rows.
  4. Alter column to set NOT NULL once all rows are valid.
Concrete example
Add loyalty_status as nullable, UPDATE customers SET loyalty_status = 'bronze' WHERE loyalty_status IS NULL, then ALTER TABLE to set NOT NULL.
Pitfall
Trying to add a NOT NULL column without a default on a populated table will fail. Don't risk downtime — backfill first.
Key Takeaway
A staged approach — add, backfill, default, then enforce — ensures safe changes for production tables.
