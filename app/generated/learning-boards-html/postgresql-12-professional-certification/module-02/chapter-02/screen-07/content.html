Foreign key example
-- Add the foreign key constraint to the products table
ALTER TABLE products
ADD CONSTRAINT fk_category
FOREIGN KEY (category_id) REFERENCES categories(category_id) ON DELETE RESTRICT;
Explanation
The FK ensures category_id on products refers to an existing categories row. ON DELETE RESTRICT prevents removing a category in use.
When to use CASCADE
Use CASCADE only when the child rows are owned entirely by the parent and should not exist independently, for example comments owned by a deleted post.
Key Takeaway
Model referential actions to match ownership semantics; review dependencies before destructive deletes.
