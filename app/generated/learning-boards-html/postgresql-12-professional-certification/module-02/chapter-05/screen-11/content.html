Comparison › Index Trade-offs
Read benefit vs write cost
Each index speeds some queries but increases the work performed during writes. The impact grows with write volume and index width. Favor indexes that provide the most benefit per maintenance byte.
When to add
High-frequency read patterns that materially reduce latency or CPU when indexed.
When to remove
Indexes with low idx_scan counts, high size, and measurable write overhead.
Quick checklist
  • • Measure read benefit with EXPLAIN ANALYZE before and after adding an index.
  • • Measure write latency under realistic load.
  • • Prefer targeted indexes to broad ones when possible.
