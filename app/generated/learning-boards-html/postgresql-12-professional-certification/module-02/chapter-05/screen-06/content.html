Definition › Expression Index
Examples
-- Case-insensitive uniqueness and lookup
CREATE UNIQUE INDEX idx_customers_email_lower ON customers (lower(email));

EXPLAIN ANALYZE
SELECT * FROM customers WHERE lower(email) = 'john.doe@example.com';

-- Index on extracted year
CREATE INDEX idx_orders_order_year ON orders (EXTRACT(YEAR FROM order_date));

EXPLAIN ANALYZE
SELECT * FROM orders WHERE EXTRACT(YEAR FROM order_date) = 2023;
• The query must use the same expression so the planner can match the index entry.
• Expression indexes are ideal for commonly-used transformations like lower, date parts, and computed flags.
• Avoid indexing expressions with nondeterministic or volatile functions.
Concrete Analogy
Think of an expression index as pre-sorting a photocopy of a document where certain values are already highlighted. A matching search finds highlights instantly instead of scanning and calculating highlights on the fly.
Pro Tip

When you need uniqueness on a transformed form, use an expression index combined with UNIQUE to enforce the rule at index level.

Misconception
Building many expression indexes for rare transformations increases maintenance cost; index only those you actually query frequently.
