Process Flow › Validate with EXPLAIN ANALYZE
Command sequence
-- Refresh planner stats for accurate decisions
ANALYZE orders;

-- Representative query for pending orders
EXPLAIN ANALYZE SELECT * FROM orders
WHERE status = 'pending' AND order_date < '2023-10-01';

-- Look for 'Index Scan using idx_orders_pending_date' in the plan output
• ANALYZE updates table statistics so the planner has accurate cardinality estimates.
• Run EXPLAIN ANALYZE rather than EXPLAIN alone to see the actual plan chosen at runtime.
• Use realistic parameter values; different parameters can cause different plan choices.
Interpreting results
  • • 'Index Scan' or 'Index Only Scan' indicates the planner used the index; the index name will be shown.
  • • High cost estimates with a sequential scan may mean the index is not selective enough.
  • • If the partial index is unused, confirm the query predicate exactly matches the index WHERE clause.
Example Output Marker
You should see a line like: Index Scan using idx_orders_pending_date on orders (cost=... rows=...)
Misconception
Seeing an index in the planner without ANALYZE or without representative parameters is not proof of consistent use.
