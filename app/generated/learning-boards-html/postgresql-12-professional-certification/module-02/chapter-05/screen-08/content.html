Definition › Index Bloat
Causes
  • • Frequent UPDATE/DELETE operations create dead index tuples that remain until vacuumed or rebuilt.
  • • Large transactions and lock delays can prevent timely reclamation.
  • • Ineffective autovacuum configuration can let bloat accumulate.
Misconception: VACUUM always fixes index bloat. VACUUM reuses space but does not always compact the index structure; REINDEX rebuilds the index layout.
Detection
Look for disproportionately large index files, rising index scan costs, and many dead tuples. Use pg_stat_user_indexes and catalog functions to compare index size to expected row counts.
Quick diagnostic query (illustrative): compare idx_scan and index size to table characteristics to find heavy, rarely-used indexes.
Try This
Check indexes on hot tables after a period of heavy DML and consider a targeted REINDEX if size or performance has degraded.
