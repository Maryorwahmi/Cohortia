Learning Objectives

Skills you will practice and verify in a lab.

Bloom: Learn → Understand → Apply → Master
01
Implement partial indexes

Create indexes that include only rows matching a condition to save space and speed scans. This is useful when queries target a small subset of rows frequently.

VERIFIED COMPETENCY MILESTONE
02
Use expression indexes

Index a computed value so the planner can match queries that use functions or expressions directly and avoid computation at runtime.

VERIFIED COMPETENCY MILESTONE
03
Understand multicolumn ordering

Choose column order by selectivity and query patterns. A composite index is most useful when its leading columns match common filters.

VERIFIED COMPETENCY MILESTONE
04
Detect and fix index bloat

Identify bloat, use VACUUM where possible, and run REINDEX or REINDEX CONCURRENTLY to rebuild indexes safely when needed.
