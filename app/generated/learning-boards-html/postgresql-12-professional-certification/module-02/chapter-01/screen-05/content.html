Introducing CREATE DATABASE

Defining new data containers with essential options.

CREATE DATABASE database_name
    WITH OWNER = role_name
    ENCODING = 'UTF8'
    LC_COLLATE = 'en_US.UTF-8'
    LC_CTYPE = 'en_US.UTF-8'
    TABLESPACE = tablespace_name
    CONNECTION LIMIT = -1;
Owner

Assigns a specific role as the database owner, controlling initial permissions.

Encoding

Defines the character set for the database (e.g., UTF8). Crucial for international data.

Connection Limit

Sets the maximum number of concurrent connections allowed to the database. -1 means no limit.

Key Takeaway

Always specify `ENCODING` and `OWNER` when creating a database to ensure proper data handling and security from the start.
