Key Concepts: Management Commands

Essential SQL commands for modifying and deleting databases and schemas.

`ALTER DATABASE`

SQL command to modify properties of an existing database (e.g., owner, name, connection limit).

`DROP DATABASE`

SQL command to permanently delete a database and all its contents. Highly destructive.

`CREATE SCHEMA`

SQL command to create a new schema within the current database, often with an owner.

Chapter Summary

`ALTER DATABASE` and `ALTER SCHEMA` allow modification of properties, while `DROP DATABASE` and `DROP SCHEMA` are used for deletion. The `CASCADE` option for `DROP SCHEMA` is powerful but requires extreme caution due to its destructive nature.
