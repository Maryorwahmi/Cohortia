PostgreSQL Cluster

The entire running instance of the PostgreSQL server software on a machine, managing all databases.

Database

An isolated collection of data, tables, indexes, and other objects within a cluster, serving a specific application or purpose.

Schema

A logical grouping of database objects (tables, views, functions) within a database, acting like a namespace or directory.

Key Takeaway

Understanding the Cluster > Database > Schema hierarchy is fundamental for effective PostgreSQL data organization and management.
