Adjusting Database Properties with ALTER DATABASE

Renaming, reassigning ownership, and managing connection limits.

-- Rename a database
ALTER DATABASE old_db_name RENAME TO new_db_name;

-- Change database owner
ALTER DATABASE my_app_db OWNER TO new_owner_role;

-- Adjust connection limit
ALTER DATABASE my_app_db SET CONNECTION LIMIT 50;
Rename Database

Changes the database name. Requires updating all applications that reference it.

Change Owner

Transfers ownership to another role, impacting permissions and administrative control.

Set Connection Limit

Configures the maximum number of concurrent connections. Adjust based on traffic needs.

Key Takeaway

`ALTER DATABASE` provides flexibility, but changes, especially renaming, require careful planning and coordination with dependent applications.
