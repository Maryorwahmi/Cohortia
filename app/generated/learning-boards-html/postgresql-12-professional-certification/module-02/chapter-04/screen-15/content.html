Quick memory
Index types
Hash for equality, GiST for spatial, GIN for JSONB/arrays.
EXPLAIN
Use EXPLAIN for a plan preview and EXPLAIN ANALYZE to measure real runtime and scan types.
Trade-offs
Every index speeds reads but costs storage and write performance; measure to decide.
Final takeaway
Design indexes for actual query patterns, validate with EXPLAIN ANALYZE, and monitor their maintenance cost over time.
