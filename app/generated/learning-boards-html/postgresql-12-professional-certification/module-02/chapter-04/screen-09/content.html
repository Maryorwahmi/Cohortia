Example
Create a GIN index on JSONB
Add a JSONB column, populate data, create the index, then validate with EXPLAIN ANALYZE.
-- Add JSONB column and populate
ALTER TABLE products ADD COLUMN tags JSONB;
UPDATE products SET tags = '{"colors": ["red", "blue"], "materials": ["plastic"]}' WHERE product_id = 4;

-- Create GIN index
CREATE INDEX idx_products_tags_gin ON products USING GIN (tags);

-- Query that can use the GIN index
EXPLAIN ANALYZE
SELECT product_name, tags FROM products WHERE tags @> '{"colors": ["red"]}';
After running EXPLAIN ANALYZE, expect to see Bitmap Index Scan or Index Scan referencing idx_products_tags_gin. If you still see a Sequential Scan, check selectivity and sample size; GIN helps when the query filters on contained keys or values frequently.
Key Takeaway
GIN is powerful for multi-valued columns like JSONB, but consider maintenance cost before adding it to large rapidly-changing datasets.
