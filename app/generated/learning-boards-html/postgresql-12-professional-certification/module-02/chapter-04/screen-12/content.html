Mistakes
What to avoid
  • Indexing every column without evidence of use.
  • Creating composite indexes with wrong column order for common queries.
  • Assuming indexes help when queries return most rows.
Maintenance
Keep indexes healthy
  • Monitor index size and write overhead after deployment.
  • Run VACUUM and maintain statistics so the planner estimates correctly.
  • Reindex or drop unused indexes that hurt write throughput.
Pro tip
Create partial indexes for frequent but selective predicates to reduce index size and maintenance cost.
Key Takeaway

Index intentionally, maintain them, and remove those that no longer serve measured query improvements.
