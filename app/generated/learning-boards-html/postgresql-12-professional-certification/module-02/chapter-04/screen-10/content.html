Definition
EXPLAIN and EXPLAIN ANALYZE
Use EXPLAIN to see the planned operations. Use EXPLAIN ANALYZE to run the query and capture actual times and row counts.
-- Before creating index
EXPLAIN ANALYZE
SELECT * FROM customers WHERE email = 'email500@example.com';

-- After creating index
EXPLAIN ANALYZE
SELECT * FROM customers WHERE email = 'email500@example.com';
What to inspect in a plan
  • Operation type: Index Scan, Bitmap Index Scan, or Sequential Scan.
  • Estimated cost vs actual time and rows to detect planner misestimates.
  • Whether an explicit sort was avoided because the index supplied ordering.
Common pitfall
The planner may choose Sequential Scan if an index is not selective or if estimates suggest a full scan is cheaper.
Key Takeaway

Always compare EXPLAIN ANALYZE output before and after index changes; look for Index Scan and lower actual times to confirm benefits.
