CREATE INDEX examples
Run these in psql to add B-tree indexes used in many examples.
-- Single-column B-tree index
CREATE INDEX idx_customers_email ON customers (email);

-- Composite index: customer then date
CREATE INDEX idx_orders_customer_date ON orders (customer_id, order_date);

-- Index supporting descending order
CREATE INDEX idx_products_price_desc ON products (price DESC);
Tip: use descriptive names that indicate table and column usage to make maintenance easier.
Practical checklist
  • Choose the column order in composite indexes to match common WHERE and ORDER BY patterns.
  • Test performance before and after with EXPLAIN ANALYZE to measure real effect.
  • Consider concurrent index creation on very large production tables to minimize locking.
Key Takeaway

CREATE INDEX is simple; the harder part is matching index structure to query patterns and validating the result.
