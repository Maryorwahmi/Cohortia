Module 1 › Chapter 1.3 › Learning Objectives
Bloom Progress
Learn → Understand → Apply → Master
01
Complete EDB Installer Setup
Run the installer with admin rights and accept or set directories so the server and tools install cleanly. Verified competency: confirm a running service.
02
Identify Installer Components
Name the role of the server, pgAdmin, Stack Builder, and CLI tools so you install only what the environment requires.
03
Configure Password & Port
Set a strong postgres superuser password and choose the port. This matters for authentication and avoiding port conflicts.
04
Locate PGDATA & Manage Service
Find postgresql.conf and pg_hba.conf in PGDATA, restart the Windows service to apply changes, and open firewall rules only as needed.
