Process Flow Windows Firewall
Create a safe inbound rule for PostgreSQL
Step-by-step
  1. Open Windows Defender Firewall with Advanced Security.
  2. Select Inbound Rules → New Rule → Port → TCP → 5432.
  3. Allow the connection; choose the profiles to apply.
  4. Name the rule clearly and finish.
Security guidance
Prefer restricting the rule to specific IP ranges or Private/Domain profiles. Avoid opening the port broadly on Public networks unless you have additional protections.
Check: After adding the rule, test remote connectivity and confirm the server’s listen_addresses and pg_hba.conf allow the client address.
