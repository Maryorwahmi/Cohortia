EDB Installer: purpose and trade-offs
Definition

A guided graphical setup that installs PostgreSQL server plus pgAdmin 4, Stack Builder, and command-line tools into standard Windows locations, and registers the server as a Windows Service.

Benefit: Quick, consistent setup with sensible defaults.
Trade-off: Defaults may need adjustment for production or custom paths.
Misconception: Not just for beginners; it reduces human error for any user.
Concrete Example
Run the installer, accept the default install path C:\\Program Files\\PostgreSQL\\12, choose all components, set a postgres password, and complete the wizard. You should then see pgAdmin 4 in the Start Menu and a running Windows Service named "postgresql-x64-12".
Key Takeaway

Use the EDB installer for a fast, reliable Windows install; change defaults only when you have a reason and record credentials and paths.
