What to Remember
Key Concepts
EDB Installer
Bundles server, pgAdmin, Stack Builder and CLI tools for straightforward Windows setup.
PGDATA & Configs
postgresql.conf and pg_hba.conf live in PGDATA; edit them and then restart the service.
Service & Firewall
PostgreSQL runs as a Windows Service and Windows Firewall must allow the chosen port for remote access.
Summary: Use the installer for speed, know where PGDATA lives for configuration, and control access through service and firewall settings.
