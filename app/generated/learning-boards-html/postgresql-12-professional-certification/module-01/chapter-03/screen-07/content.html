Definition PGDATA & config files
Locate and manage configuration safely
Typical locations
PGDATA (default): C:\\Program Files\\PostgreSQL\\12\\data
Files of interest:
  • postgresql.conf — server parameters
  • pg_hba.conf — client authentication rules
Example edit for remote access
# in postgresql.conf
listen_addresses = '*'
# in pg_hba.conf
host all all 0.0.0.0/0 md5
After editing, restart the PostgreSQL service so the new listen and authentication rules take effect.
