Choose components based on usage
PostgreSQL Server
Core engine required for any database activity. Installs the server binaries and registers the Windows Service.
pgAdmin 4
Graphical admin and query tool. Great for exploration and learning; optional for headless setups.
Stack Builder
Installer for add-ons, drivers, and extensions. Install when you need additional components later.
Command Line Tools
psql, pg_dump, and pg_restore support automation, backups, and recovery. Best practice: include them for administration and scripting.
