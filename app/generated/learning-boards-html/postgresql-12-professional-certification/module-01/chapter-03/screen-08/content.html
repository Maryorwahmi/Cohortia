Process Flow Restarting the server
Service and pg_ctl restart methods
Using Services (GUI)
Open Services, find "postgresql-x64-12", then Start / Stop / Restart. Use this when you prefer a visual check and when the service is healthy.
Using pg_ctl (CLI)
pg_ctl restart -D "C:\\Program Files\\PostgreSQL\\12\\data"
Run from an elevated prompt. Quotes around the path are required when spaces are present.
Troubleshoot: If restart fails, check PGDATA log files for syntax errors and confirm the postgres account has file read permissions.
