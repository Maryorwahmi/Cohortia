Hands-on Activity pgAdmin & Services verification
Connect, explore, and confirm
pgAdmin quick checks
  1. Launch pgAdmin 4 and connect to the server using your postgres password.
  2. Open Query Tool and run: SELECT version();
  3. Confirm default DBs: postgres, template0, template1 are visible.
Service verification
Open Services, find "postgresql-x64-12", ensure it is Running and Startup type is Automatic. Start or restart the service if needed.
If connection fails: confirm listen_addresses and pg_hba.conf entries, then check firewall rules and restart the service.
