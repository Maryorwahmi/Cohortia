Installation Checkpoints
  • Run installer with admin rights and finish without errors.
  • Confirm components: Server, pgAdmin 4, Stack Builder, CLI tools.
  • Accept default installation paths unless specific constraints exist.
Post-install Checks
  • Verify the "postgresql-x64-12" service is running and set to Automatic.
  • Locate PGDATA: typically C:\\Program Files\\PostgreSQL\\12\\data.
  • Ensure you can open postgresql.conf and pg_hba.conf with an editor if you need to change them.
