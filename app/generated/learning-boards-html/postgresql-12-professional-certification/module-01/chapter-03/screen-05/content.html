Process Flow Run the installer
Step-by-step installer flow
  1. Download the PostgreSQL 12 EDB installer for your Windows architecture.
  2. Run as Administrator so the installer can write to Program Files and register services.
  3. Choose Install Directory, default: C:\\Program Files\\PostgreSQL\\12 unless you have a reason to change it.
  4. Select Components: PostgreSQL Server, pgAdmin 4, Stack Builder, Command Line Tools.
  5. Set PGDATA, default under the install path (e.g., C:\\Program Files\\PostgreSQL\\12\\data).
  6. Set postgres superuser password — choose a strong, memorable credential.
  7. Confirm Port, default 5432, then finish the wizard and allow it to complete installation.
Common mistake: Not running the installer as admin prevents service registration and can silently fail.
Quick verification
Open Services and confirm "postgresql-x64-12" is running and Startup type is Automatic. Launch pgAdmin 4 and connect using the postgres password you set.
Why this order matters: running as admin and choosing correct directories prevents permission and startup issues later.
