Common Mistake Password & port pitfalls
Choose and record credentials and port
Password guidance
Use a strong password for the postgres superuser. If forgotten, a password reset interrupts work. Store it in a password manager and avoid weak phrases.
Port guidance
Default port is 5432. Change it only if necessary and then update firewall rules and client connection strings to match.
Pro Tip

Record installation choices in a short notes file: installation path, PGDATA, postgres password hint, and port. This solves most post-install surprises.
