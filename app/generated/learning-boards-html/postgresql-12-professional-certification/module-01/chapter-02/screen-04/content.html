Module 1 › Chapter 1.2 › Why use PGDG?
Definition

PGDG is the official PostgreSQL APT repository that delivers current PostgreSQL builds and security updates for Debian and Ubuntu. It is signed and intended to be the authoritative upstream source for PostgreSQL versions.

Why it matters
  • Provides PostgreSQL 12 packages when distro repos are older.
  • Offers timely security updates and consistent package names.
  • Enables reproducible installs across Debian and Ubuntu releases.
Analogy

Think of PGDG as the vendor-supplied installer for PostgreSQL. The distribution repo is like the operating system's bundled app — convenient but possibly older.

Command walkthrough
# Update package lists and install prerequisites
sudo apt update
sudo apt install -y wget ca-certificates lsb-release

# Import the PostgreSQL signing key and add PGDG
wget --quiet -O - https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo apt-key add -
echo "deb http://apt.postgresql.org/pub/repos/apt/ $(lsb_release -cs)-pgdg main" | sudo tee /etc/apt/sources.list.d/pgdg.list
sudo apt update

# Install the server and client packages
sudo apt install -y postgresql-12 postgresql-client-12
Example
On Ubuntu 20.04, adding PGDG lets you install postgresql-12 even if the distro defaults to an earlier minor release.
Common mistake
Forgetting to import the signing key causes apt to reject packages from the new repository.
Key Takeaway

Add PGDG and its signing key before installing to ensure you receive PostgreSQL 12 and its updates reliably.
