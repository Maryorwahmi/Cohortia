Module 1 › Chapter 1.2 › Add PGDG repo
Step-by-step
Step 1
Update apt and install prerequisites: wget, ca-certificates, lsb-release.
Step 2
Import the PostgreSQL signing key so packages are trusted by APT.
Step 3
Add the repo line with your distribution codename and run sudo apt update again.
Key Takeaway

Run the steps in order and verify with apt policy; failing to add the signing key or re-run apt update are the most common causes of package not found.

Commands
sudo apt update
sudo apt install -y wget ca-certificates lsb-release

wget --quiet -O - https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo apt-key add -
# If automatic substitution fails, replace $(lsb_release -cs) with your codename
echo "deb http://apt.postgresql.org/pub/repos/apt/ $(lsb_release -cs)-pgdg main" | sudo tee /etc/apt/sources.list.d/pgdg.list
sudo apt update

# Verify candidate
apt-cache policy postgresql-12
Example Check
Run apt-cache policy postgresql-12; its candidate should show apt.postgresql.org as the origin.
Common mistake
Forgetting to run the second sudo apt update after adding the new sources leaves apt unaware of new packages.
