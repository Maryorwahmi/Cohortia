Installation on Linux (Debian / Ubuntu)

Follow a robust, repeatable install: add PGDG, import the signing key, install postgresql-12, verify initdb ran, and perform initial psql setup.

In this lesson
  • Add PGDG repo and signing key and install packages.
  • Understand initdb, default PGDATA, and the postgres system user.
  • Manage systemctl service and perform first psql tasks.

Quick Notes
  • initdb runs automatically during package install to create /var/lib/postgresql/12/main by default.
  • The postgres OS user owns the data directory and runs server processes — do not run as root.
  • Edit pg_hba.conf and postgresql.conf to allow remote connections and then reload the service.
Key Takeaway

Use PGDG for reproducible PostgreSQL 12 installs, verify initdb created the cluster, and always use the postgres user for admin tasks.
