Module 1 › Chapter 1.2 › Troubleshooting
Quick diagnostic checklist
  1. Validate the repository and signing key: apt-cache policy postgresql-12.
  2. Check PGDATA ownership and contents: ls -ld /var/lib/postgresql/12/main.
  3. Inspect service logs: sudo journalctl -u postgresql.service --no-pager | tail -n 100.
Example error
If initdb fails with permission denied, ensure the postgres user owns PGDATA and that SELinux or AppArmor profiles are not blocking writes.
Commands to gather evidence
apt-cache policy postgresql-12
ls -ld /var/lib/postgresql/12/main
sudo -i -u postgres ls -la /var/lib/postgresql/12/main
sudo journalctl -u postgresql.service --no-pager | tail -n 100
sudo systemctl status postgresql
Key Takeaway

Diagnose in order: repository and keys, file system ownership, then logs. This order quickly narrows the root cause of installation failures.
