Learning Objectives

Learn, Understand, Apply, Master

Bloom: Learn → Understand → Apply → Master
01
Install from PGDG

Add the official PGDG APT repository and signing key so apt installs PostgreSQL 12 packages that receive security updates.

VERIFIED COMPETENCY MILESTONE
02
Understand initdb & cluster

Know how initdb initializes PGDATA, where the default cluster is placed on Debian/Ubuntu, and the role of system catalogs and template databases.

VERIFIED COMPETENCY MILESTONE
03
Manage the service

Use systemctl to inspect, start, stop, restart, enable, and reload PostgreSQL so it behaves correctly on boot and after config changes.

VERIFIED COMPETENCY MILESTONE
04
Initial psql tasks

Switch to the postgres OS user, connect with psql, list databases and roles, and create a role and database for an application.

VERIFIED COMPETENCY MILESTONE
These four objectives form the core tasks of the lab. Complete them in order to ensure a secure and operational PostgreSQL 12 installation on Debian/Ubuntu.
