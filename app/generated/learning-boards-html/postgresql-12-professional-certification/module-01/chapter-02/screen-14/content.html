Module 1 › Chapter 1.2 › Key Concepts
PGDG repository
Official APT source for up-to-date PostgreSQL packages on Debian/Ubuntu.
apt
Package manager used to add repos, update indexes, and install PostgreSQL packages.
initdb
Utility that initializes PGDATA and creates the default cluster and system catalogs.
Takeaway

Keep these core concepts in mind as you install and verify PostgreSQL 12; they map directly to the commands and files you'll use every day.
