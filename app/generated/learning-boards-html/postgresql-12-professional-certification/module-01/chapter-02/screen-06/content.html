Module 1 › Chapter 1.2 › Install packages
Install command and what to watch for
sudo apt install -y postgresql-12 postgresql-client-12

# During installation you should see maintainer scripts invoke initdb
# and create the data directory. After install, check:
ls -ld /var/lib/postgresql/12/main
sudo -i -u postgres ls -la /var/lib/postgresql/12/main

# Verify ownership and cluster structure
sudo stat -c '%U %G' /var/lib/postgresql/12/main
# Confirm presence of system catalogs and template databases inside the cluster using psql once running.
Expected outcome
Postgres OS user exists, PGDATA at /var/lib/postgresql/12/main, and service files created for systemd.
Common mistake
Attempting to inspect or change PGDATA as root without using the postgres user causes permission errors and is insecure.
Cluster defaults
  • Default PGDATA: /var/lib/postgresql/12/main
  • Default port: 5432
  • Service user: postgres
Pro Tip

If initdb fails during package install, check the systemd journal for detailed errors and ensure the postgres user can write to the intended PGDATA path.
