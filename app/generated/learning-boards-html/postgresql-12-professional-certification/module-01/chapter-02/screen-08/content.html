Module 1 › Chapter 1.2 › psql & postgres user
Shell sequence
sudo -i -u postgres
psql
-- Inside psql
\l       -- list databases
\du      -- list roles
CREATE ROLE cohortia_admin WITH LOGIN PASSWORD 'SecureP@ssw0rd!';
CREATE DATABASE cohortia_db OWNER cohortia_admin;
\l
\q
exit
Notes & checks
  • Always run psql as postgres or a superuser account to create roles and DBs.
  • Use strong passwords and avoid using simple literals in shared environments.
  • createdb and createuser shell wrappers also work when run as postgres.
Common misconception
Creating a database as root or a non-postgres OS user can leave files with wrong ownership and break server startup.
Key Takeaway

Switch to postgres, use psql to verify cluster contents, and create roles/databases from within psql to ensure correct ownership and permissions.
