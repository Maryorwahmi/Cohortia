Module 1 › Chapter 1.2 › pg_hba.conf & listen_addresses
Key configuration lines
# postgresql.conf
# Default: listen_addresses = 'localhost'
listen_addresses = '*'

# pg_hba.conf example (testing only; restrict in production)
host    all             all             0.0.0.0/0               md5
Example
To allow a specific subnet, replace 0.0.0.0/0 with 192.0.2.0/24 and use md5 for password authentication.
Security warning
Do not use 0.0.0.0/0 in production without strict firewall rules protecting port 5432.
Checklist after edits
  • Save file changes and run sudo systemctl reload postgresql.
  • Test remote connection with psql from the client machine.
  • Ensure OS firewall allows 5432/tcp only from trusted IPs.
Key Takeaway

listen_addresses opens interfaces, pg_hba.conf authorizes clients; always restrict access and reload the server after changes.
