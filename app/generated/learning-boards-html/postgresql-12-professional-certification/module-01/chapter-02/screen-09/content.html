Module 1 › Chapter 1.2 › initdb & cluster
What initdb does
  • Creates PGDATA directory structure and system catalogs.
  • Creates template databases from which new databases are cloned.
  • Sets file ownership to the postgres OS user and initializes WAL directories.
Check after install
ls -ld /var/lib/postgresql/12/main
sudo -i -u postgres ls -la /var/lib/postgresql/12/main
sudo stat -c '%U %G %n' /var/lib/postgresql/12/main
Typical directory contents
  • base — database file contents
  • global — cluster-wide catalogs
  • pg_wal — write-ahead logs
  • postgresql.conf and pg_hba.conf — runtime configuration
Common misconception
In this context, "cluster" refers to a single server's databases, not a multi-server HA cluster.
Key Takeaway

Confirm initdb created PGDATA and that ownership and directory layout are correct before proceeding to run-time configuration.
