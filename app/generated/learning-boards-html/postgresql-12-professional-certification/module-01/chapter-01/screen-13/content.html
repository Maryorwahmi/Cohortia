Module 1 › Chapter 1.1 › Inspecting PGDATA and processes
Step 1 — find PGDATA
-- inside psql
SHOW data_directory;
This returns the filesystem path of PGDATA for the running server instance.
Step 2 — list contents
cd /path/to/PGDATA
ls -l
ls -l pg_wal
ls -l base
head postgresql.conf
head pg_hba.conf
Confirm directories like base and pg_wal exist and view the first lines of configuration files to validate settings.
Step 3 — observe processes
ps aux | grep postgres
# look for postmaster and postgres backends; note PIDs and owners
Use these outputs to correlate processes with clients and to spot unexpected owners or processes started as root.
Safety note

Run inspection commands as the postgres system user and avoid changing ownership or permissions on production systems without a maintenance window.
