Module 1 › Chapter 1.1 › WAL and walwriter
What is WAL?
An ordered log of all changes. WAL ensures that commit records exist on disk so the database can recover to a consistent state after a crash.
walwriter role
Moves WAL from wal_buffers to the filesystem under pg_wal so transactions become durable even if data pages are still in memory.
Misconception
WAL is not a substitute for base backups; it is a recovery mechanism that, together with backups, enables point-in-time recovery and supports replication.
Example
A transaction writes a row; WAL entry is buffered. walwriter flushes it to pg_wal. The commit is durable even if checkpointer has not flushed the data page yet.
# inspect pg_wal directory
ls -l pg_wal
Key Takeaway

WAL plus walwriter ensure commits are durable; monitor pg_wal and wal activity when commit latency or disk usage is a concern.
