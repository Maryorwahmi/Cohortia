Module 1 › Chapter 1.1 › PGDATA structure and key directories
Key directories
  • base: per-database files for tables and indexes.
  • pg_wal: WAL segments for durability and replication.
  • pg_xact: transaction status files recording commit/abort state.
  • global, pg_tblspc, pg_stat_tmp, pg_replslot, pg_logical: supporting catalogs, tablespaces and replication state.
Config files
postgresql.conf, pg_hba.conf and pg_ident.conf live in PGDATA and control server behaviour, authentication rules, and user mapping respectively.
Terminal checks
-- inside psql
SHOW data_directory;

# at the shell, after locating PGDATA
ls -l pg_wal
ls -l base
head postgresql.conf
head pg_hba.conf
Key Takeaway

PGDATA contains everything a cluster needs; always verify ownership and restrictive permissions before starting the server.
