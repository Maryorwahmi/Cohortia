Learning Objectives
What you should be able to do confidently after this chapter.
01
Verify service and version
Check that the server is active using system tools and psql --version. This confirms a usable installation and avoids wasted debugging when services are stopped.
VERIFIED COMPETENCY MILESTONE
02
Connect with psql and pgAdmin 4
Use psql for fast administrative commands and pgAdmin 4 for visual exploration. Both tools let you confirm databases, roles, and run SQL safely.
VERIFIED COMPETENCY MILESTONE
03
Create roles and databases safely
Create users with LOGIN and strong passwords, create databases owned by those roles, and avoid using the postgres superuser for application tasks.
VERIFIED COMPETENCY MILESTONE
04
Configure network and authentication
Edit postgresql.conf and pg_hba.conf with backups, prefer specific IP ranges, and understand when reloads vs restarts are required.
VERIFIED COMPETENCY MILESTONE
