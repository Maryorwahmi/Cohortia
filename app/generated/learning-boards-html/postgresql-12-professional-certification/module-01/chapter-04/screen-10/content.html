Module 2 › Chapter 1.4 › listen_addresses & port
Edit safely
Locate postgresql.conf in the PGDATA directory, backup the file, then change the listen_addresses and port values. Prefer a specific IP when possible instead of '*'.
# Listen on all interfaces (use with care)
listen_addresses = '*'
# Default port
port = 5432
Checklist after edit
  • Backup the original postgresql.conf.
  • Add pg_hba.conf entries for client IP ranges before reloading.
  • Reload or restart PostgreSQL as required and test with psql -h server_ip -U user -d db.
Warning

Don't leave a permissive 0.0.0.0/0 pg_hba entry in production without firewall protections.
