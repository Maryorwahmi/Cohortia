Key parameters
listen_addresses: controls network interfaces. Default: 'localhost'. Change to '*' to listen on all interfaces.
port: server TCP port, usually 5432.
max_connections: maximum concurrent clients. Increase cautiously relative to RAM.
shared_buffers: data page cache. Start around 25% of RAM; changing it requires a restart.
work_mem: per-operation memory for sorts and hashes; tune per session as needed.
Safety notes
  • Always backup postgresql.conf before editing.
  • Know which changes require a restart; shared_buffers is a restart change.
  • Prefer conservative values and test under load before production tuning.
Common misconception

Not all settings apply on reload. Memory and shared resource settings often need a full restart; reloading only applies certain parameters.
