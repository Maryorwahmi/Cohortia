Process Flow
Connect with psql
Use the OS postgres account for local admin access or provide credentials via the SQL Shell on Windows.
Common meta-commands
  • \l — list databases
  • \dt — list tables in the current database
  • \du — list roles (users) and attributes
Remember: backslash commands are client helpers, not standard SQL statements. They are processed by psql itself.
Live command walkthrough
sudo -i -u postgres
psql

\l

\dt
\q
If you encounter authentication errors on remote connections, check pg_hba.conf rules and ensure the user has LOGIN privilege. Use \q to exit psql.
