Setup Checklist
Service status, psql login, user and DB creation, secure pg_hba rules.
Verify the server is active and respond to psql --version.
Create roles and databases and grant ownership.
Edit postgresql.conf and pg_hba.conf safely; reload or restart as needed.

Roles & Ownership

Network & Auth
