Definition
Graphical administration with pgAdmin 4
Add a server, authenticate, and use the object tree to browse databases, schemas, tables, and roles.
pgAdmin is ideal for exploring object relationships, running ad hoc queries, and visually confirming ownership and privileges without memorizing psql meta-commands.
Quick checklist
  • Add server with host, port, maintenance DB, and postgres credentials.
  • Expand Databases → your_db → Schemas to inspect tables and privileges.
  • Use the Query Tool for test SQL; remember GUI access still requires correct pg_hba and listen settings.
Pro Tip

When testing remote GUI access, confirm the server host and port are reachable and a matching pg_hba.conf rule exists for your client IP.
