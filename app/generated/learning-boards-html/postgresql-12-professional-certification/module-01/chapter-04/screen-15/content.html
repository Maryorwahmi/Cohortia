pg_hba.conf
Controls which clients may attempt to connect and the authentication method; make rules specific and secure.
Reload vs Restart
Use reload to apply many changes (including pg_hba.conf); restart is required for shared memory and some performance settings.
Backup configs
Always back up postgresql.conf and pg_hba.conf before editing so you can revert quickly if a change causes connectivity issues.
Bottom line

Secure connectivity and measured configuration changes are the keys to a stable PostgreSQL deployment.
