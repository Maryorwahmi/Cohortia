Activity: Configure remote access and basic DB setup
Follow these concise steps on your server and a remote client to validate a safe, minimal remote setup.
Server steps
  1. Connect as postgres and run \l and \du to inspect state.
  2. Create role and DB, assign owner, and GRANT required privileges.
  3. Backup postgresql.conf and pg_hba.conf.
  4. Edit listen_addresses and add a targeted pg_hba host line.
  5. Reload PostgreSQL configuration and check logs for errors.
Client test
From a remote machine:
psql -h <SERVER_IP_ADDRESS> -p 5432 -U app_user -d app_db
# enter the password when prompted
\conninfo
Reflection

Consider whether your pg_hba entries are as narrow as they can be and whether firewall rules provide an additional safety layer.
