Module 2 › Chapter 1.4 › Practice Flow
How you’ll practice these skills
A short verify → create → configure loop to make a server ready for an application.
Step 1
Verify service & version
Use system tools to confirm the service is running and psql --version to verify the client/server baseline.
Step 2
Create role & database
Create a role with LOGIN and a database owned by that role. Test connection as that user to avoid permission errors later.
Step 3
Configure network & auth
Back up postgresql.conf and pg_hba.conf, change listen_addresses and add a targeted pg_hba host line, then reload or restart as needed.
