Module 2 › Chapter 1.4 › Verify Service
Definition
Verify the server is running
Confirm the PostgreSQL process is active and the client is the expected version before making configuration changes or creating roles.
Checks to run
  • On Linux: sudo systemctl status postgresql — look for active (running).
  • On Windows: check Services for postgresql-x64-12 and confirm status.
  • Confirm client: psql --version to ensure expected toolchain.
Common misconception
Just because the server files are installed doesn't mean the service started. Always verify the running state.
Key Takeaway

Confirm service health and client version first; it prevents wasted troubleshooting on configuration edits.

Terminal examples
sudo systemctl status postgresql
# look for 'active (running)'

psql --version
# confirms the psql client version
If the service is inactive, start it with the system's service manager. If the client reports a different major version, test basic commands before proceeding to role creation.
