Module 2 › Chapter 1.4 › Memory & Connections
shared_buffers
Caches data pages. Start at ~25% of RAM. Requires a full restart after change.
work_mem
Memory per sort/hash operation. Tunable per session; large values multiplied by concurrency can exhaust RAM.
max_connections
Maximum concurrent clients. Increasing without capacity planning risks out-of-memory errors.
Key Takeaway

Tune memory and connection settings conservatively, monitor resource use, and prefer connection pooling when concurrency is high.
