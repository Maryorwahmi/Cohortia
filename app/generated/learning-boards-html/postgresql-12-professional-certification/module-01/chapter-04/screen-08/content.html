Module 2 › Chapter 1.4 › Ownership vs Privileges
Owner
The role recorded as the database owner has full control over that database and is typically used when the role should manage all objects inside it.
Privileges (GRANT)
GRANT provides fine-grained rights such as CONNECT or object-level privileges without giving full ownership. Use this for tighter security models.
Quick troubleshooting steps
  1. Connect as the role and run a simple query to reproduce the error.
  2. Confirm ownership: SELECT datname, pg_catalog.pg_get_userbyid(datdba) FROM pg_database;
  3. If missing, set OWNER with CREATE DATABASE ... OWNER or run ALTER DATABASE ... OWNER TO role.
  4. Alternatively, GRANT specific privileges required by the application.
Key Takeaway

Authentication confirms identity; privileges and ownership determine what that identity can do inside the database.
