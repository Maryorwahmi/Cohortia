Module 2 › Chapter 1.4 › Key Concepts
psql
The command-line interface for administration; use \l, \dt, and \du to inspect the server quickly.
CREATE ROLE / CREATE DATABASE
Create application users and databases; assign OWNER or GRANT privileges to avoid permission errors.
postgresql.conf
Main server configuration. Know which parameters need restart (shared_buffers) and which accept reload (some network changes).
Summary

Use these concepts as quick mental checks when you configure a new PostgreSQL instance: verify, create safely, and configure with backups.
