Module 2 › Chapter 1.4 › pg_hba.conf Editing
Format
# TYPE  DATABASE        USER            ADDRESS                 METHOD
host    myapp_db        myapp_user      192.168.1.0/24          md5
This line allows myapp_user to connect to myapp_db from the 192.168.1.0/24 network using MD5 password authentication.
Best practices
  • Back up pg_hba.conf before editing.
  • Prefer specific database and user entries and narrow IP ranges.
  • Use md5 or scram-sha-256 for password-based authentication; avoid trust in non-test environments.
After edit

Reload the server configuration (systemctl reload postgresql or pg_ctl reload) to apply pg_hba changes before testing client connections.
