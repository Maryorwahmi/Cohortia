Learning Objectives
Skills you will demonstrate with checks and commands in PostgreSQL 12.
Learn → Understand → Apply → Master
01
Distinguish failover vs switchover
Explain triggers, risks, and guarantees for each role change. Knowing the difference prevents accidental data loss.
Venn: Unplanned vs Planned • Availability vs Consistency
VERIFIED COMPETENCY MILESTONE
02
Perform a manual failover
Select the freshest standby using LSN checks and promote it with pg_ctl promote to restore service quickly.
Mnemonic: Check LSN → Promote → Re-route
VERIFIED COMPETENCY MILESTONE
03
Re-integrate primaries and standbys
Use pg_basebackup, or pg_rewind when timelines permit, to bring a recovered server back as a standby.
Timeline awareness is essential.
VERIFIED COMPETENCY MILESTONE
04
Identify risks and pitfalls
Recognize split-brain, outdated standbys, connection update failures, and misuse of pg_rewind.
Safety-first checklist included.
VERIFIED COMPETENCY MILESTONE
