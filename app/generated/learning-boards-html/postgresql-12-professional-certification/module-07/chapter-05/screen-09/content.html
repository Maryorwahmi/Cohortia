Options
Reconfigure remaining standbys
Rebuild from pg_basebackup
Stop standby, clear data, take pg_basebackup from new primary, then start as standby.
Use pg_rewind (advanced)
If timelines haven't diverged much, pg_rewind can avoid a full base backup. Use cautiously.
Key Takeaway

Rebuild is safest. pg_rewind can save time but requires the correct timeline state and careful validation.

Command patterns
# Example: rebuild standby
sudo systemctl stop postgresql
sudo rm -rf /var/lib/postgresql/12/main/*
sudo -u postgres pg_basebackup -h  -D /var/lib/postgresql/12/main -U replicator_user -P -v -R -W
