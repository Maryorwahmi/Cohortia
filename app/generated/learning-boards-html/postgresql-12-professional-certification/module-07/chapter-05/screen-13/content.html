Part 1 — Simulate and Promote
# On primary: simulate crash
sudo systemctl stop postgresql
echo "Primary server is now down." 

# On standby: check LSNs
sudo -u postgres psql -c "SELECT pg_last_wal_receive_lsn(), pg_last_wal_replay_lsn();"

# Promote standby
sudo pg_ctl -D /var/lib/postgresql/12/main_standby promote
Part 2 — Verify and Re-integrate
# Verify new primary
sudo -u postgres psql -c "SELECT pg_is_in_recovery();"  -- expect 'f'
sudo -u postgres psql -c "CREATE TABLE new_primary_test (id INT);"

# On old primary: prepare for re-integration
sudo rm -rf /var/lib/postgresql/12/main/*
sudo -u postgres pg_basebackup -h  -D /var/lib/postgresql/12/main -U replicator_user -P -v -R -W
sudo systemctl start postgresql

# Confirm standby
sudo -u postgres psql -c "SELECT pg_is_in_recovery();"  -- expect 't'
sudo -u postgres psql -c "SELECT * FROM new_primary_test;"
Safety First
During the lab keep the old primary offline until re-integration is complete to avoid split-brain. Time each step and capture logs for review.
