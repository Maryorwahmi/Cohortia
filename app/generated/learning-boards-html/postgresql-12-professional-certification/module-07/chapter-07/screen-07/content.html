Geographic Redundancy
Protect against region-wide outages while balancing latency and RPO.
Pattern: local HA + remote DR
  1. Primary in Region A with 1–2 local standbys using synchronous replication for RPO=0.
  2. Remote standby(s) in Region B using asynchronous replication to avoid high latency.
  3. WAL archives replicated offsite to durable storage for PITR.
Considerations and examples
  • Network latency: synchronous cross-region replication can slow commits—prefer async for remote standbys.
  • Security: use VPNs, private peering, and firewall rules for replication connections.
  • Application routing: ensure client redirection and connection pooling work with promotions.
Concrete scenario
Primary in DC1 with two local synchronous standbys for low RTO; one remote asynchronous standby in DC2 for disaster recovery.
