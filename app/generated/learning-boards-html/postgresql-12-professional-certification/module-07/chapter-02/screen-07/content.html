Module 07 › Chapter 7.2 › pg_basebackup
Prepare standby directory
# On standby
sudo systemctl stop postgresql
sudo rm -rf /var/lib/postgresql/12/main/*
sudo mkdir -p /var/lib/postgresql/12/main
sudo chown -R postgres:postgres /var/lib/postgresql/12/main
sudo chmod 700 /var/lib/postgresql/12/main
Ensure the postgres OS user owns and can write to the data directory before running pg_basebackup.
Run pg_basebackup
# From the standby as postgres
pg_basebackup -h <primary_ip> -D /var/lib/postgresql/12/main -U replicator_user -P -v -R -W
# Enter the replication user's password when prompted
The -R option adds standby.signal and primary_conninfo so the standby will know how to contact the primary on startup.
Key Takeaway

pg_basebackup -R simplifies standby initialization by creating the necessary recovery files automatically.
