Module 07 › Chapter 7.2 › standby.signal & primary_conninfo
standby.signal

An empty file placed in the standby data directory that tells PostgreSQL to start in recovery mode. Created automatically when you use -R with pg_basebackup.

Without this marker, PostgreSQL starts as a normal server and will not attempt to stream WAL from the primary.
Check file presence:
ls -l /var/lib/postgresql/12/main/standby.signal
primary_conninfo

A connection string stored in postgresql.auto.conf that describes how the standby connects to the primary, including host, port, user, and optionally password.

Example snippet that pg_basebackup writes for you: primary_conninfo = 'host=<primary_ip> port=5432 user=replicator_user'. If a password is required, ensure the standby can supply it via .pgpass or add it cautiously to the connection string.
Misconception

Having standby.signal alone is not enough if primary_conninfo is missing or incorrect; both must be correct for successful streaming.
