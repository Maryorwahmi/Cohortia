Module 07 › Chapter 7.2 › Learning Objectives
01
Configure primary server

Adjust wal_level, archive_mode, archive_command, and max_wal_senders, then restart to apply changes. This ensures the WAL contains sufficient information for standbys to replay changes.

VERIFIED COMPETENCY MILESTONE
02
Perform base backup

Use pg_basebackup with a replication role to copy data files. The -R option writes standby.signal and primary_conninfo to simplify standby setup.

VERIFIED COMPETENCY MILESTONE
03
Set up standby

Initialize standby data directory, ensure standby.signal exists, and confirm primary_conninfo is correct for streaming connections.

VERIFIED COMPETENCY MILESTONE
04
Start and verify replication

Start the standby, check pg_is_in_recovery(), and query pg_stat_replication on the primary to confirm the standby state and LSN progress.
