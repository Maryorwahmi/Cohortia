Module 07 › Chapter 7.2 › Key Concepts
pg_basebackup
Creates a consistent base backup for initializing standbys; -R auto-writes recovery files.
wal_level = replica
Enables WAL output needed by standbys to replay changes; requires restart to take effect.
max_wal_senders
Limits concurrent WAL streaming connections; size it for number of standbys and backup clients.
Takeaway

These core settings and tools are the minimal checklist to get streaming replication running and testable.
