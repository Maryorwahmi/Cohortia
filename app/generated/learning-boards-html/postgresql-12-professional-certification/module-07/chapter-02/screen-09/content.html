Module 07 › Chapter 7.2 › Start standby & verify
Start commands
# Systemd managed
sudo systemctl start postgresql

# Or with pg_ctl
sudo -u postgres pg_ctl -D /var/lib/postgresql/12/main start
Confirm recovery mode:
# On standby
sudo -u postgres psql -c "SELECT pg_is_in_recovery();"
Troubleshooting tips
  • If you see "fe_sendauth: no password supplied", add the password to primary_conninfo or use .pgpass.
  • Check the standby's postgresql logs for walreceiver connection errors.
  • Verify the standby is pointing at the correct data directory and that standby.signal exists.
Check

pg_is_in_recovery() should be true; then watch pg_last_wal_replay_lsn() to confirm replay progress.
