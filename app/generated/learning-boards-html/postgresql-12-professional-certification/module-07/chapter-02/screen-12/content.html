Module 07 › Chapter 7.2 › Common mistakes
Authentication error
Error: fe_sendauth: no password supplied. Cause: primary_conninfo missing password or .pgpass not configured. Fix: add password or set up .pgpass on standby with correct permissions.
WAL generation
If wal_level isn't replica, the primary won't produce sufficient WAL. Restart required after changing this setting.
Missing -R
Forgetting -R with pg_basebackup means you must manually create standby.signal and write primary_conninfo, which is error-prone.
Permissions
Ensure postgres owns the standby data directory and permissions are 700; otherwise PostgreSQL may refuse to start.
Troubleshooting approach

Check logs, then system views (pg_stat_replication, pg_is_in_recovery()) to narrow failures; change one thing at a time and re-test.
