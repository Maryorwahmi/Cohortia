Module 07 › Chapter 7.2 › Read-only test
Commands on the primary
sudo -u postgres psql -c "CREATE TABLE test_replication (id SERIAL PRIMARY KEY, data TEXT);"
sudo -u postgres psql -c "INSERT INTO test_replication (data) VALUES ('Hello from primary');"
Wait briefly for the standby to replay WAL and then query the standby for the inserted row.
Commands on the standby
sudo -u postgres psql -c "SELECT * FROM test_replication;"
# Attempting a write will fail
sudo -u postgres psql -c "CREATE TABLE should_fail (id int);"
Expected: SELECT returns the row; CREATE TABLE returns an error about read-only transactions.
Misconception

Standbys are read-only while in recovery. They do not accept DDL or data changes until promoted.
