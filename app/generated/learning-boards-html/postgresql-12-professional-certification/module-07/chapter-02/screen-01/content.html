Setting Up Streaming Replication

Create a standby from a primary using pg_basebackup, WAL streaming, and verification tools.

Duration: ~15 minutes lab
In this lesson
Prepare primary WAL and auth, perform base backup, start standby, verify streaming.
Key tools
postgresql.conf, pg_hba.conf, pg_basebackup, pg_stat_replication, pg_is_in_recovery()
Goal
A standby that streams WAL and is ready for read-only queries and failover.
Explore Key Topics

Three immediate topics you'll use in the lab: primary configuration, base backup flow, and verification queries.

Primary config
Set wal_level, archive_mode, and max_wal_senders, then restart.
Base backup
Use pg_basebackup -R to capture a consistent base and auto-create recovery settings.
Verification
Query pg_stat_replication and check pg_is_in_recovery on the standby.
At a glance
You will perform server config edits, create a replication user, run pg_basebackup from the standby, and then start the standby so it connects back to the primary and streams WAL.
Quick checklist
  • Set wal_level = replica and restart primary.
  • Add replication line to pg_hba.conf for replicator_user.
  • Create replicator_user with REPLICATION privilege.
  • Run pg_basebackup -R and start standby.
