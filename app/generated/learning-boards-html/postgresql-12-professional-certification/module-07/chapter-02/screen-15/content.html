Module 07 › Chapter 7.2 › Operational checks
pg_hba.conf
Must include a replication entry for the replicator_user and standby IP to allow streaming connections.
standby.signal & primary_conninfo
These tell the standby to run in recovery and how to reach the primary for WAL streaming.
Monitoring
Use pg_stat_replication, pg_is_in_recovery, and LSN functions to detect lag and replay health.
Final takeaway

Combining correct configuration, secure authentication, tested base backups, and active monitoring gives you a reliable streaming replication setup ready for operational use.
