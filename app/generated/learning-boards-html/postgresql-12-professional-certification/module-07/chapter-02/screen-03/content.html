Module 07 › Chapter 7.2 › Practice & Verify
01
Allow replication in pg_hba.conf

Add a line permitting the replicator_user from the standby IP to connect to the pseudo-database "replication" with md5, then reload configuration.

VERIFIED COMPETENCY MILESTONE
02
Create replicator_user

Create a user with REPLICATION LOGIN and set an encrypted password to use with pg_basebackup and streaming.

VERIFIED COMPETENCY MILESTONE
03
Run pg_basebackup -R

Perform a base backup from the standby to capture a consistent dataset and auto-generate standby.signal and primary_conninfo for startup.

VERIFIED COMPETENCY MILESTONE
04
Monitor replication health

Use pg_stat_replication on the primary and pg_last_wal_replay_lsn on the standby to confirm LSN positions are advancing and lag is acceptable.

VERIFIED COMPETENCY MILESTONE
