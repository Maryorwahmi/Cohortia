Module 07 › Chapter 7.4 › Publications and Subscriptions
Publisher
Create publication with FOR TABLE table1, table2 or FOR ALL TABLES. Optionally restrict to certain DML with WITH (publish = 'insert').
Subscriber
Create subscription with a connection string pointing to the publisher and the publication name. The subscriber pulls initial data and applies changes.
Tip
Ensure pg_hba and a replication-capable user permit the subscriber connection to the publisher.
Step sequence
1 • Publish
CREATE PUBLICATION my_publication FOR TABLE users, products;
2 • Prepare subscriber
Create tables with compatible schemas and primary keys before subscribing.
3 • Subscribe
CREATE SUBSCRIPTION ... CONNECTION 'host=... user=... dbname=...' PUBLICATION my_publication;
Example scenario
A reporting database subscribes to a products publication to receive only product updates and avoid replicating unrelated tables like sessions or temp data.
Key Takeaway

Publication selects; subscription pulls. The subscriber must have compatible tables and network access to the publisher.
