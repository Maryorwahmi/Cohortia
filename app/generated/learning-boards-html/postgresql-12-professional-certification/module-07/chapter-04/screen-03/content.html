Module 07 › Chapter 7.4 › Practical Outcomes
Lab verification tiles
Config
Set wal_level=logical, configure slots and workers, restart and confirm WAL contains logical data.
Publication
CREATE PUBLICATION for chosen tables; verify with system views.
Subscription
CREATE SUBSCRIPTION on the subscriber and verify initial data sync and ongoing DML replication.
Why this order?
Configuration must come first because logical decoding must be enabled before publications can be created. Publications define what will flow; subscriptions pull and apply, and monitoring confirms health.
Lab tip
Ensure tables on the subscriber have compatible column names and types and an appropriate primary key before creating the subscription.
