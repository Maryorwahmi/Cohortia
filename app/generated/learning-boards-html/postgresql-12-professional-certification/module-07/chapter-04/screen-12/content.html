Module 07 › Chapter 7.4 › Troubleshooting
Mistake
wal_level not set to logical. Fix: set wal_level = logical and restart the server.
Mistake
Missing/incompatible schemas on subscriber. Fix: create or ALTER tables on subscriber to match publisher columns and types, ensure primary keys.
Mistake
DDL changes not replicated. Fix: apply schema changes manually to subscribers as part of deployment workflow.
Diagnostic checklist
  1. Confirm wal_level = logical and server restarted.
  2. Verify pg_hba and replication user permissions.
  3. Check pg_replication_slots and pg_stat_replication for slot and walsender status.
  4. Inspect pg_stat_subscription for substate and sublasterror.
