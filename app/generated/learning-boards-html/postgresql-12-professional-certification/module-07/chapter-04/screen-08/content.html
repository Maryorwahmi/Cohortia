Module 07 › Chapter 7.4 › CREATE SUBSCRIPTION
Subscriber preparation
Create database and tables on the subscriber with compatible schemas and a primary key before creating the subscription.
-- On subscriber: create table
CREATE TABLE employees (
  id SERIAL PRIMARY KEY,
  name TEXT NOT NULL,
  department TEXT
);

-- Then create subscription
CREATE SUBSCRIPTION emp_subscription CONNECTION 'host=<publisher_ip> port=5432 user=logical_repl_user password=logical_pass dbname=your_database' PUBLICATION emp_publication;
Operational notes
  • The subscription performs an initial copy of published tables.
  • A replication slot is created on the publisher when the subscription connects.
  • Subscriber must be able to connect to publisher; configure pg_hba and user privileges accordingly.
If an initial copy fails, inspect the subscription's last error in pg_stat_subscription and correct schema or permission issues before retrying.
Quick checklist
Table exists on subscriber · Primary key present · pg_hba allows connections · replication user has REPLICATION and CONNECT privileges.
