Module 07 › Chapter 7.4 › Logical vs Physical
Logical replication
  • Replicates DML operations.
  • Selective table-level replication.
  • Supports cross-version replication and read-write subscribers.
  • Does not replicate DDL automatically.
Physical streaming replication
  • Replicates WAL bytes for an identical cluster image.
  • Typically higher performance for heavy writes.
  • Requires matching major PostgreSQL versions.
  • Standbys are often read-only; not suitable for writeable replicas.
Decision example
If you need to replicate only a small set of tables to a reporting cluster running an older major version, logical replication is the right choice. If you need a hot standby that is an exact copy for failover and performance is critical, use physical streaming replication.
