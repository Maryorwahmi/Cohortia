Learning Objectives
Develop config, deployment, and monitoring skills for logical replication.
01
Explain logical replication
Describe how DML-based replication enables selective and cross-version replication.
VERIFIED COMPETENCY MILESTONE
02
Configure server settings
Set wal_level, replication slots, and worker processes to support logical replication load.
VERIFIED COMPETENCY MILESTONE
03
Create publications & subscriptions
Define what to publish and how subscribers pull initial data and ongoing changes.
VERIFIED COMPETENCY MILESTONE
04
Monitor and troubleshoot
Use pg_replication_slots, pg_stat_replication and pg_stat_subscription to verify slot state and apply progress.
VERIFIED COMPETENCY MILESTONE

These objectives are sequenced so that configuration and verification support the hands-on activity later in the chapter. Completing them prepares you to operate logical replication reliably.
