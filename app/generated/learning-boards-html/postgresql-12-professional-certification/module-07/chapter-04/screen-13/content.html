Module 07 › Chapter 7.4 › Lab: Single Table Replication
Publisher steps
  1. Edit postgresql.conf: set wal_level = logical, max_replication_slots and max_worker_processes, then restart.
  2. Create test table and insert sample rows.
  3. Create publication for the table.
  4. Create replication user and update pg_hba to allow subscriber connection.
Subscriber steps
  1. Create database and compatible table with primary key.
  2. Create subscription using a connection string to the publisher and the publication name.
  3. Verify initial data copy and then test INSERT, UPDATE, DELETE on the publisher.
  4. Inspect pg_stat_subscription and verify changes on the subscriber.
Validation checks
On publisher: check pg_replication_slots and pg_stat_replication. On subscriber: check pg_stat_subscription and table contents. If replication lags or errors occur, inspect logs and sublasterror for actionable messages.
