Module 07 › Chapter 7.4 › Inspecting Replication State
Publisher checks
-- On publisher
SELECT slot_name, active, restart_lsn, confirmed_flush_lsn
  FROM pg_replication_slots WHERE slot_name = 'emp_subscription';

SELECT client_addr, application_name, state, sync_state
  FROM pg_stat_replication WHERE application_name = 'emp_subscription';
pg_replication_slots shows whether WAL retention is blocking cleanup. pg_stat_replication shows the walsender connection and state.
Subscriber checks
-- On subscriber
SELECT subname, subenabled, subconninfo, subpublications, subslotname, substate, sublasterror
  FROM pg_stat_subscription;
Look at substate for streaming/apply status and sublasterror if any failures occurred during apply.
Troubleshooting steps
If WAL retention grows, consider removing stale subscriptions or increasing slot management. If sublasterror shows authentication issues, verify replication user and pg_hba settings.
