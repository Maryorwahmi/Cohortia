Verification tasks

Concrete actions you will perform to verify configuration and behavior.

Configure
Edit postgresql.conf, set synchronous_commit=on and synchronous_standby_names, restart primary.
Standby
Set primary_conninfo application_name to match the primary’s synchronous_standby_names entry and restart standby.
Monitor
Query pg_stat_replication to confirm sync_state = sync and compare sent_lsn to replay_lsn for lag insight.
Hands-on test
Run two concurrent transactions, stop the standby, and observe commit blocking and recovery when standby returns.
Pitfall
sync_state = sync alone doesn’t guarantee timely replay; check LSN progress to detect performance issues.
