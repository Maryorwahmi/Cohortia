Module 7 › Chapter 7.3 › Quorum-Based Synchronous Replication
Concept

FIRST N behavior

The primary waits for confirmations from any N of the listed standbys. This keeps synchronous durability while reducing single-standby dependency.
Example: synchronous_standby_names = 'FIRST 1 (s_a, s_b)' means either s_a or s_b can provide the needed confirmation. If one fails, the other keeps the system available.
Trade-off: larger N increases assurance but also raises the probability that commits will block due to multiple failures or lagging standbys.
Operational checklist
  • Set application_name on each standby to match the listed names.
  • Ensure max_wal_senders allows all candidate standbys to connect.
  • Monitor pg_stat_replication for which standby is providing sync_state = sync.
Quick config
synchronous_standby_names = 'FIRST 1 (standby_a, standby_b)'
