Module 7 › Chapter 7.3 › Configure the Primary
Key parameters

synchronous_commit

Controls commit strictness. For synchronous replication use on to ensure remote confirmation is required before returning success.

synchronous_standby_names

Specifies standbys and quorum behavior, for example FIRST N (name1, name2).
Restart required
Changing these settings requires a full PostgreSQL restart on the primary to take effect.
Example snippet
# On the primary's postgresql.conf
synchronous_commit = on
synchronous_standby_names = 'FIRST 1 (standby_server_a, standby_server_b)'
This configuration requires any one of the two named standbys to confirm a write for the commit to succeed, improving availability compared to a single named standby.
Verification
After restart, run: SELECT client_addr, state, sync_state FROM pg_stat_replication; and confirm sync_state = 'sync' for the chosen standby.
