Module 7 › Chapter 7.3 › Common Mistakes and Fixes
Troubleshooting checklist
Misconfigured names
Symptom: primary waits for a standby name that never registers. Fix: set application_name on standby and restart it.
Low max_wal_senders
Symptom: new standbys can’t connect. Fix: raise max_wal_senders and restart primary.
Standby lag
Symptom: replay_lsn far behind sent_lsn. Fix: check I/O, decrease standby read load, or upgrade resources.
Single point of failure
Symptom: primary halts when single synchronous standby fails. Fix: use FIRST N to add redundancy.
Operational reminder
After each fix, validate with pg_stat_replication and a short controlled test to confirm commits behave as expected.
