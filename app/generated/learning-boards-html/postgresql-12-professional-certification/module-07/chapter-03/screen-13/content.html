Module 7 › Chapter 7.3 › Hands-on: Convert to Synchronous
Part 1 — Primary
# Edit primary_db postgresql.conf
synchronous_commit = on
synchronous_standby_names = 'FIRST 1 (my_standby)'
# Restart primary
sudo systemctl restart postgresql
Restart is required for these parameters to take effect. Confirm pg_stat_replication after restarting.
Part 2 — Standby
# On standby_db
primary_conninfo = 'host=<primary_ip> port=5432 user=replicator_user password=mysecretpassword application_name=my_standby'
# Restart standby
sudo systemctl restart postgresql
Make sure the application_name matches exactly. Then verify sync_state = sync on the primary.
Test steps
  1. Open session A on primary: BEGIN; INSERT ... (do not commit).
  2. Open session B on primary: attempt another INSERT and observe blocking.
  3. Stop the standby: sudo systemctl stop postgresql — observe session A blocks if waiting for confirmation.
  4. Start the standby again and watch blocked statements complete; then COMMIT in each session and verify replication.
