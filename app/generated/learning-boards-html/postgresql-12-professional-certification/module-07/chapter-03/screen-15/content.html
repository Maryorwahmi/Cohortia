Module 7 › Chapter 7.3 › Key Concepts
Asynchronous Replication
Commits return before WAL reaches standby; faster but small data-loss window.
Synchronous Replication
Primary waits for standby flush confirmation before acknowledging commit; RPO=0 for acknowledged transactions.
synchronous_standby_names
Use names or FIRST N to select which standbys provide confirmations; application_name on standbys must match.
Summary takeaway

Pick the mode that matches your durability and latency requirements, configure names carefully, and monitor LSN progress to avoid unexpected blocking.
