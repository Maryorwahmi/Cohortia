Module 7 › Chapter 7.1 › Inspecting WAL Configuration
Starter commands
Open psql as postgres and run these checks to understand WAL state.
psql -U postgres -d postgres
SHOW wal_level;
SHOW archive_mode;
SHOW max_wal_senders;
SHOW wal_log_hints;
SHOW full_page_writes;
If wal_level returns 'replica', streaming is supported. If it returns 'minimal', you cannot stream WAL.
Interpreting results
  • archive_mode = on → WAL segments are archived for PITR.
  • max_wal_senders numeric → number of concurrent standby connections allowed.
  • full_page_writes = on → safer base backups and crash recovery behavior.
Concrete reflection
If you plan three standbys, consider setting max_wal_senders to 5 to leave room for backup processes. If wal_level is minimal, prepare to change it to replica and restart the server.
Key Takeaway

Knowing these settings bridges replication strategy and actual server readiness; inspect before you attempt to create standbys.
