Inspect WAL settings
Use simple SQL to validate whether a server is ready for streaming replication.
psql -U postgres -d postgres
SHOW wal_level;
SHOW archive_mode;
SHOW max_wal_senders;
SHOW wal_log_hints;
SHOW full_page_writes;
Interpret: wal_level must be replica or logical; max_wal_senders must allow desired standbys.
Configuration implications
  • Change wal_level to enable streaming and restart the server.
  • Archive mode supports point-in-time recovery and complements replication.
  • full_page_writes protects against partial page writes during crashes.
