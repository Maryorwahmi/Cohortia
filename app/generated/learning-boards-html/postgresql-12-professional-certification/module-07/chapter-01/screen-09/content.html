Module 7 › Chapter 7.1 › Streaming Replication Architecture
Components
Primary: WAL senders
Sends WAL to standby receivers and handles writes.
Standby: WAL receiver & replay
Receives WAL and applies changes to match primary.
Base backup
Initial copy used to bootstrap standbys before continuous streaming.
WAL archive
Optional storage of WAL files for PITR and recovery beyond live stream.
Concrete scenario
Set max_wal_senders to 3 if you plan three concurrent standbys; use pg_basebackup to create the initial data copy before connecting WAL streams.
Monitoring focus
  • WAL send/receive status.
  • Replay lag on standbys.
  • WAL archive success if enabled.
Key Takeaway

Design the pipeline from base backup to continuous WAL streaming and monitor send/receive/replay to ensure replicas are viable.
