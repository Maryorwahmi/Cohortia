Module 7 › Chapter 7.1 › Choosing a Replication Strategy
Step-by-step
1. Define RPO/RTO
Decide acceptable data loss and recovery time.
2. Choose replication type
Physical for exact copies; logical for selective replication or cross-version migration.
3. Select sync mode
Synchronous for zero data loss; asynchronous for better primary performance.
4. Configure WAL and senders
Set wal_level, max_wal_senders, and archive_mode as needed.
Concrete example
If RPO = 0 and write latency tolerance exists, pick synchronous physical replication and ensure network latency is minimized between primary and standby.
Key Takeaway

Follow a requirements-first flow: requirements → replication type → sync mode → configuration → monitoring.
