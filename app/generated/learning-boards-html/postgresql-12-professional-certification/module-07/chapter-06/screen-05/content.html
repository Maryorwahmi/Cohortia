What Patroni does

Runs health checks, writes cluster state to a consensus store, elects a single leader, promotes standbys, and reconfigures other nodes to follow the new primary.

Why consensus matters
  • Consensus store acts as an authoritative state to avoid conflicting promotions.
  • Only the node that acquires the leader key can become primary.
  • This eliminates split-brain risk when network partitions occur.
Practice tip

Simulate a primary failure in staging and inspect the consensus store to observe the leader key change and an automatic promotion.
