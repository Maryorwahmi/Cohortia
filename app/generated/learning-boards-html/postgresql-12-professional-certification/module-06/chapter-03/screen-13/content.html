Systematic testing workflow
A single-change, measure-driven approach prevents accidental regressions.
1. Backup
Copy postgresql.conf with timestamp.
2. Baseline
Record SHOW values and EXPLAIN ANALYZE outputs.
3. Change
Modify one parameter and reload or restart as required.
4. Validate
Re-run the same tests and compare metrics.
Key Takeaway: Make small, reversible changes and validate them with the same workload to ensure improvements are real.
