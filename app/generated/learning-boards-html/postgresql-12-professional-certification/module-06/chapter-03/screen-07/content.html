Module 6 › Chapter 6.3 › work_mem & maintenance_work_mem
work_mem
Memory for internal sorts and hash tables; allocated per operation per connection.
Example setting
# postgresql.conf
work_mem = 64MB
Note: many concurrent complex queries can multiply work_mem allocations; set conservatively for busy systems.
maintenance_work_mem
Used by VACUUM, CREATE INDEX and other maintenance tasks; allocated per session performing the task.
Example setting
# postgresql.conf
maintenance_work_mem = 512MB
Tip: increase it for index creation sessions only with SET maintenance_work_mem TO '1GB'; to avoid affecting other workloads.
Concrete scenario
You need to create an index on a very large table during off-hours. Use SET maintenance_work_mem in your session and CREATE INDEX CONCURRENTLY to avoid blocking traffic and to speed the operation without globally increasing memory usage.
Key Takeaway: Use session-level increases for one-off heavy tasks; keep global defaults conservative.
