Simulate a sort-heavy query
Follow these steps in a safe environment and compare EXPLAIN ANALYZE outputs.
CREATE TABLE large_data (
  id SERIAL PRIMARY KEY,
  value TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

INSERT INTO large_data (value)
SELECT md5(random()::text) FROM generate_series(1, 1000000);

ANALYZE large_data;

-- Baseline
EXPLAIN ANALYZE SELECT * FROM large_data ORDER BY value LIMIT 100;

-- Increase work_mem for this session and re-run
SET work_mem = '256MB';
EXPLAIN ANALYZE SELECT * FROM large_data ORDER BY value LIMIT 100;
What to look for
If the Sort node previously showed Disk, after increasing work_mem it should run in memory and total time should drop. Also compare Buffers values to confirm reduced disk reads.
Key Takeaway: Use session SET for validation before changing global defaults.
