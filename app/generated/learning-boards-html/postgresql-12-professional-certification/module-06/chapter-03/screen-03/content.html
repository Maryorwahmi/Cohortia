Session-level safety tip
Use SET maintenance_work_mem TO '1GB'; inside your session when building an index to avoid global memory shifts, and use CREATE INDEX CONCURRENTLY when you need minimal locking.
Why this helps
It speeds the operation while keeping server-wide memory usage predictable, preventing accidental exhaustion of RAM.
Testing workflow
  1. Record baseline CPU, I/O, memory, and query times.
  2. Change one parameter and apply reload or restart as required.
  3. Run representative queries and compare EXPLAIN ANALYZE outputs.
  4. Document and revert if regressions appear.
Verified milestone
Can run a controlled parameter experiment and report results.
