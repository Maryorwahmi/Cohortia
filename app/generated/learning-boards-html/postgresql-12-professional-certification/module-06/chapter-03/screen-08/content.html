Module 6 › Chapter 6.3 › EXPLAIN & SHOW
Command walkthrough
Capture settings, run a representative query with EXPLAIN ANALYZE, and compare before/after outputs.
Inspect current parameters
SHOW shared_buffers;
SHOW work_mem;
SHOW maintenance_work_mem;
SHOW effective_cache_size;
SHOW random_page_cost;
Run a representative query
ANALYZE large_data;
EXPLAIN ANALYZE SELECT * FROM large_data ORDER BY value LIMIT 100;
Interpretation tips
  • If you see "Disk:" next to Sort, the sort spilled to disk—consider increasing work_mem for that operation.
  • If Buffers: reads is high, increase caching via shared_buffers or improve indexing to reduce random reads.
  • Lower random_page_cost on SSDs to encourage index scans when random access is cheap.
Key Takeaway: Use EXPLAIN ANALYZE, not EXPLAIN alone, to measure actual buffer and disk behavior and validate changes.
