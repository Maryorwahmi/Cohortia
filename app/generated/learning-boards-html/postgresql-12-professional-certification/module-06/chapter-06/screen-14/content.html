Module 6 › Chapter 6.6 › Key Concepts
Table Partitioning

Divide a logical table into physical partitions to improve manageability and query performance.

Partition Pruning

Planner excludes partitions that cannot contain matching rows when queries reference the partition key.

Maintenance

Attach, detach, create, and drop partitions. DETACH is a fast metadata operation useful for archiving.

Summary takeaway

Design partitioning around query patterns and retention needs, automate partition lifecycle, and validate with EXPLAIN.
