Module 6 › Chapter 6.6 › Practical Objectives
Hands-on tasks
  • Create RANGE parent and monthly child partitions.
  • Insert rows and confirm routing into child tables.
  • Run EXPLAIN to verify partition pruning.
  • Detach an old partition for fast archiving.
Operational notes
  • Always consider a DEFAULT partition to avoid insert errors.
  • Create partitions ahead of time to avoid runtime failures.
  • Indexes are per-partition; unique constraints propagate to children.
