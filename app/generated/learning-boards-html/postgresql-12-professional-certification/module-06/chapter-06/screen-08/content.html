Partition pruning and EXPLAIN

How it works
  • Planner inspects WHERE clauses for partition key predicates.
  • Partitions that cannot satisfy the predicate are excluded.
  • EXPLAIN shows only the scanned partition children when pruning occurs.
Example EXPLAIN
EXPLAIN SELECT * FROM daily_sales
WHERE sale_date BETWEEN '2023-02-01' AND '2023-02-28';
-- Plan shows only daily_sales_2023_02 being scanned
Misconception

Pruning happens only when the partition key is present and can be analyzed; otherwise scanning occurs.

Pro-tip

Use simple comparisons and constants in filters to maximize pruning opportunities.

Key Takeaway

Always validate pruning with EXPLAIN for representative queries before rolling out partitioning.
