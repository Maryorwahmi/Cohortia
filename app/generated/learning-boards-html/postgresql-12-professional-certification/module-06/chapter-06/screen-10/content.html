Indexes and constraints across partitions

Per-partition indexes

Each child has its own indexes. A parent-level unique constraint will create child indexes only when defined correctly and when the constraint includes the partition key.

Example note
-- Indexes on children must be created or will be missing
CREATE INDEX ON daily_sales_2023_02 (region);
Operational tip

Automate index creation as part of partition creation scripts to avoid uneven performance.

Pitfall

Assuming a parent index protects you — it doesn’t become a global index over children.

Key Takeaway

Plan index and constraint creation for every new partition to maintain consistent query performance.
