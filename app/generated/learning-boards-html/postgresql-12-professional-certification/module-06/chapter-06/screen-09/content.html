Process Flow

Add, attach, detach

Add partition
CREATE TABLE daily_sales_2023_04 PARTITION OF daily_sales
FOR VALUES FROM ('2023-04-01') TO ('2023-05-01');
Detach for archive
ALTER TABLE daily_sales DETACH PARTITION daily_sales_2023_01;
-- daily_sales_2023_01 is now a standalone table
Why it matters

DETACH is fast, enabling efficient archiving without expensive row deletes.

Caveat

Ensure the detached table has the indexes and constraints you need before dropping it.

Pro-tip

Automate creation of future partitions and monthly detaches in staging first to validate behavior.
