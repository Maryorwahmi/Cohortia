Partial Index
Index only rows that match a WHERE predicate to reduce size and speed targeted queries.
Expression Index
Index the result of a function or expression, e.g., lower(column), to match transformed queries.
REINDEX & Bloat
REINDEX reclaims space from bloat. Prefer REINDEX CONCURRENTLY in production to avoid exclusive locks.
Mnemonic summary
Target indexes to common queries, measure with EXPLAIN ANALYZE, and reindex safely when bloat appears.
