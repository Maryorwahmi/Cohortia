Hands-on tasks

Follow concrete steps to create and verify indexes. Use EXPLAIN ANALYZE to compare plans before and after each index.
Partial index task
Create an index that only covers rows matching a WHERE clause and measure plan changes.
Expression index task
Create an index on a function result like lower(column) for fast case-insensitive lookups.
Monitoring & reindex
Query pg_class and pg_relation_size to find size vs expected row counts, then plan reindexing when needed.
Quick reference
  • Use B-tree for equality and range.
  • Use GIN for arrays and JSONB element searches.
  • Use BRIN for very large append-only ordered data.
