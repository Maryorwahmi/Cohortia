Starter SQL (setup)
CREATE TABLE sales (
  sale_id SERIAL PRIMARY KEY,
  product_id INT NOT NULL,
  sale_date DATE NOT NULL,
  amount NUMERIC(10,2) NOT NULL,
  status VARCHAR(50) NOT NULL DEFAULT 'completed'
);

-- Populate with representative rows (example from chapter)
-- then run: ANALYZE sales;
Index commands to run
CREATE INDEX idx_sales_completed_date ON sales (sale_date) WHERE status = 'completed';
CREATE INDEX idx_sales_lower_status ON sales (lower(status));
ANALYZE sales;
Verification steps
  1. Run EXPLAIN ANALYZE for query filtering status and date; record plan and time.
  2. Create the partial and expression indexes, then run ANALYZE.
  3. Re-run EXPLAIN ANALYZE and compare: index scans should appear for matching predicates and times should decrease.
Key Takeaway

Hands-on verification with EXPLAIN ANALYZE is essential: create, analyze, and confirm the planner choices.
