B-tree Index
Default index for equality, range, ORDER BY, and DISTINCT operations.
GIN
Inverted index for arrays, JSONB, and multi-valued columns to find elements quickly.
BRIN
Block range summaries for very large, naturally ordered tables such as time-series.
Summary
Pick the index type that matches your data shape and query patterns to gain maximum benefit with minimal cost.
