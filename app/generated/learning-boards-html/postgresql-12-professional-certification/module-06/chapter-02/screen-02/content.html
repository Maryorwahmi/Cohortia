Learning Objectives

Learn, Understand, Apply, Master
Bloom: Learn → Understand → Apply → Master
01
Explain index types
Describe B-tree, Hash, GiST, GIN, SP-GiST and BRIN and why each is useful. VERIFIED COMPETENCY MILESTONE
Mnemonic: matrix of type → query
02
Targeted indexes
Create partial and expression indexes for focused query patterns. VERIFIED COMPETENCY MILESTONE
Mnemonic: filter or transform
03
Index trade-offs
Measure read gains vs write overhead and avoid low-selectivity indexes. VERIFIED COMPETENCY MILESTONE
Mnemonic: benefit vs cost
04
Maintenance & bloat
Detect bloat, schedule REINDEX and prefer REINDEX CONCURRENTLY for production. VERIFIED COMPETENCY MILESTONE
Mnemonic: monitor → reindex
How to use
Refer to this checklist when reviewing schema changes: pick index type, evaluate selectivity, create minimal indexes, and schedule maintenance windows for reindexing.
Assessment link
You will be asked to choose an index type for sample queries and provide CREATE INDEX statements for partial and expression cases.
