Module 6 › Chapter 6.2 › Partial indexes
Process

Create a partial index and verify

Create an index with a WHERE clause that matches your frequent query filters to reduce index size and improve scan speed for those queries.

Example commands
CREATE INDEX idx_sales_completed_date ON sales (sale_date) WHERE status = 'completed';
ANALYZE sales;
EXPLAIN ANALYZE SELECT * FROM sales WHERE status = 'completed' AND sale_date >= '2023-01-01';
Concrete scenario
If 90% of queries filter for completed sales, indexing only completed rows reduces index size by excluding irrelevant states and speeds those queries.
Misconception
Partial indexes do not help queries that do not match the predicate. They are not global speed-ups.
Key Takeaway

Use partial indexes to focus index storage and scans on the rows that matter most to your frequent queries.
