Module 6 › Chapter 6.2 › GiST, SP-GiST and GIN
Comparison

Which specialized index to choose

GiST
Use for geometric, range, and full-text needs that benefit from flexible tree operators like overlaps.
SP-GiST
Best when data partitions into non-overlapping subspaces such as quadtrees for spatial indexing.
GIN
An inverted index for multi-valued columns: arrays, JSONB, and full-text element searches.
B-tree (contrast)
Not suitable for indexing elements inside arrays or JSON documents; choose GIN instead.
Concrete example
For documents with tags stored as TEXT[] use GIN: CREATE INDEX idx_documents_tags_gin ON documents USING GIN (tags); This indexes each tag element so lookups using ANY or containment operators are fast.
Misconception: trying to model arrays as single values and indexing with B-tree will not speed element lookups.
