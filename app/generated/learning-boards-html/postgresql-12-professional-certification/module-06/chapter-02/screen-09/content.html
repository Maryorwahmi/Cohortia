Module 6 › Chapter 6.2 › Expression indexes
Definition

Indexing computed values

When queries apply a function, create an index on that expression so the planner can use it directly.

Commands
CREATE INDEX idx_sales_lower_status ON sales (lower(status));
ANALYZE sales;
EXPLAIN ANALYZE SELECT * FROM sales WHERE lower(status) = 'pending';
Concrete example
Case-insensitive searches on email or status benefit from expression indexes that match the exact expression used in queries.
Misconception
If a query uses a different function or additional operations, the index will not match and will not be used.
Pro tip

Ensure expression equivalence: the planner matches the exact expression text when choosing the index.
