Module 7 › Chapter 6.7 › Load Balancing & Replicas
Read replica pattern
Primary handles writes; replicas handle reads. This offloads read-heavy workloads and improves read throughput.
Routing strategies
  • DNS round robin — simple but no health checks
  • External load balancer — health checks and smarter routing
  • Proxy like Pgpool-II — built-in read/write routing
Replication lag caution
Replicas can lag. Applications needing strong consistency should direct critical reads to the primary or implement freshness checks.
Concrete example
An analytics dashboard performs many SELECTs; configuring it to use replicas reduces load on the primary and improves response times for users viewing reports.
Check
Verify replica freshness during peak write periods to ensure the dashboard does not display stale results.
