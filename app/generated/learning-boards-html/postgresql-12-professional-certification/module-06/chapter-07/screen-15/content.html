Session State
Verify app does not rely on session-scoped settings if using non-session pooling modes.
Replication Lag
Expect eventual consistency on replicas; avoid routing critical reads without freshness checks.
File Security
Protect auth_file and config files with proper filesystem permissions to prevent credential exposure.
Final takeaway

Start with safe pooling, measure effects in staging, and add load balancing only after validating replica freshness and operational readiness.
