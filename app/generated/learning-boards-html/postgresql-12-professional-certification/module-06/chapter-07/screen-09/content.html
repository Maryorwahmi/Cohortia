Module 7 › Chapter 6.7 › Testing Pooling
Direct connection check
psql -h localhost -p 5432 -U your_db_user -d your_db_name
-- then in psql
SELECT datname, usename, client_addr, state FROM pg_stat_activity WHERE datname = 'your_db_name';
Note the number of rows representing active backends on port 5432.
Pooled connection check
psql -h localhost -p 6432 -U your_db_user -d your_db_name
-- open many sessions to 6432, then run the same pg_stat_activity query
You should see that backend connections to the server remain bounded by pool_size even when many client sessions to the pooler exist.
Pro tip
Automate a small script to open N concurrent pooled sessions and compare pg_stat_activity snapshots to validate pool behavior under load.
