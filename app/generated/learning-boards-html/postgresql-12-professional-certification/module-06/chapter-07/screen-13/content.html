Module 7 › Chapter 6.7 › Hands-on Checklist
1. Install
sudo apt update && sudo apt install pgbouncer
2. Configure pgbouncer.ini
Set database mapping, listen address, pool_size, and pool_mode=session to begin safely.
3. Create userlist
Generate md5 hashes and place them in /etc/pgbouncer/userlist.txt, then chmod 600.
4. Restart service
sudo systemctl restart pgbouncer && sudo systemctl enable pgbouncer
5. Verify
Open many psql sessions to the pooler port and compare pg_stat_activity outputs to confirm backend count respects pool_size.
