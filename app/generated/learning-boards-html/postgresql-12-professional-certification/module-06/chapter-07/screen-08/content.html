Generate password hash (example)
# In psql, run a concatenation trick and MD5 to get the correct format
SELECT 'your_db_user' || MD5('your_password' || 'your_db_user');
-- output: your_db_usermd5abcdef1234567890abcdef1234567890
Place entries in /etc/pgbouncer/userlist.txt as: 
"your_db_user" "md5abcdef1234567890abcdef1234567890"
Then secure permissions with chmod 600.
Service control
Restart and enable the service so the pooler listens on its configured port.
sudo systemctl restart pgbouncer
sudo systemctl enable pgbouncer
Testing tip
If connecting to the pooler fails, re-check auth_type, the hash format, and userlist.txt permissions. Incorrect hashes or loose permissions are common causes of authentication errors.
