Example pgbouncer.ini
; pgbouncer.ini example
[databases]
mydb = host=127.0.0.1 port=5432 dbname=mydb pool_size=20 pool_mode=session

[pgbouncer]
listen_addr = *
listen_port = 6432
auth_type = md5
auth_file = /etc/pgbouncer/userlist.txt
admin_users = postgres
This mapping tells PgBouncer to accept connections on port 6432 and reuse up to 20 backends for mydb using safe session pooling.
What each key controls
  • listen_addr/listen_port: where clients connect
  • auth_type/auth_file: authentication method and credentials file
  • pool_size: max backends PgBouncer opens for that mapping
  • pool_mode: session, transaction, or statement pooling
Permission note
Ensure userlist.txt is readable only by the pgbouncer user: e.g., chmod 600 /etc/pgbouncer/userlist.txt to avoid credential exposure.
