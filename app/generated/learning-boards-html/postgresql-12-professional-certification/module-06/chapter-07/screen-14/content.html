Module 7 › Chapter 6.7 › Key Concepts
Connection Overhead
CPU and memory used to authenticate and create a new backend for each connection.
Connection Pooling
An intermediary reuses a set of server connections rather than creating one per client.
PgBouncer
Lightweight pooler supporting session, transaction, and statement modes focused on reuse and performance.
Summary

Poolers reduce connection churn; proxies and balancers distribute reads. Use the simplest tool that meets your needs and always test in staging.
