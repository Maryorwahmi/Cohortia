Module 7 › Chapter 6.7 › Learning Objectives
Install and configure PgBouncer
Follow steps to install, edit pgbouncer.ini, and create an auth file. Verify permissions and service enablement.
Mnemonic: "Install → Configure → Secure → Test"
Verify connection reuse
Open multiple client sessions to PgBouncer and confirm the number of backend connections stays within pool_size using pg_stat_activity.
Milestone: Active backend connections ≤ pool_size
Understand Pgpool-II features
Explore Pgpool-II for read balancing, replication control, and high availability—trade-offs include extra complexity and configuration effort.
Mnemonic: "More features → More care"
Watch for replication lag and session state issues
Test reads on replicas for freshness and avoid pooling modes that break session-scoped behavior. Always stage test changes before production rollouts.
Milestone: Staging tests pass for reads and session state
