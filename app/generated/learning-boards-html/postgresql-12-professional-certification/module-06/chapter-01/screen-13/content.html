Module 6 › Chapter 6.1 › Safe practices
Checklist before running EXPLAIN ANALYZE
  • Prefer EXPLAIN for initial inspection to avoid executing the statement.
  • Run EXPLAIN ANALYZE in a test environment for heavy queries or DML.
  • Account for cache effects when comparing runs.
Common pitfalls
Treat costs as comparative, not wall-clock. If an index doesn't help, check selectivity and distribution before assuming the index or query is wrong.
Warning
EXPLAIN ANALYZE executes the query — do not run it on destructive DML in production without planning.
