Module 6 › Chapter 6.1 › Index and re-evaluate
Create index and analyze
CREATE INDEX idx_products_category_price ON products (category, price);
ANALYZE products;
After creating the index, re-run EXPLAIN ANALYZE to see whether the planner chooses an index-based path and whether buffers and time decrease.
Compare outputs
-- Before: Seq Scan, many buffer reads, higher time
-- After: Index Scan or Bitmap Index Scan, fewer buffer reads, lower time
Key Takeaway
Use measured reductions in buffers and time to justify index cost for your workload.
