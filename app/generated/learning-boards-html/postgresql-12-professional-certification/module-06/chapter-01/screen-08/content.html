Module 6 › Chapter 6.1 › EXPLAIN ANALYZE
What EXPLAIN ANALYZE adds
  • Actual time: measured startup and total time for each node.
  • Actual rows and loops: how many rows were produced and how many times the node ran.
  • Buffers: if requested, shows hits and reads to reveal I/O activity.
Concrete lab step
Run EXPLAIN ANALYZE on the products query without an index, observe Seq Scan actual times and buffer reads, then create an index and re-run to compare.
Sample EXPLAIN ANALYZE fragment
Seq Scan on products  (cost=0.00..1000.00 rows=10000 width=128) (actual time=12.345..12.800 rows=2300 loops=1)
  Buffers: shared hit=200 read=500
Total runtime: 12.950 ms
Interpretation: actual time and buffer reads show I/O cost; if buffer reads are high, consider indexes or reducing scanned rows.
