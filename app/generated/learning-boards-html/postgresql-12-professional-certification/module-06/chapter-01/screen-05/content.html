Module 6 › Chapter 6.1 › Node metrics explained
Metrics you will use
  • Estimated rows: planner's expected output rows; affects join and scan choice.
  • Width: average row size in bytes; influences memory and sort cost.
  • Startup cost: time before first row; matters for top-N and index seeks.
  • Total cost: planner's work to finish the node; rank nodes by this to prioritize.
Practical step
List nodes by total cost and inspect the top one with EXPLAIN ANALYZE next to confirm impact.
Annotated plan sample
Index Scan using idx_products_category_price on products  (cost=10.00..50.00 rows=200 width=128)
  Index Cond: (category = 'Books' AND price > 500)
Example interpretation
Planner expects 200 rows and low total cost; if actual rows are much higher, the index path may be suboptimal.
Key Takeaway
Use estimates to compare alternatives and confirm with measured runs.
