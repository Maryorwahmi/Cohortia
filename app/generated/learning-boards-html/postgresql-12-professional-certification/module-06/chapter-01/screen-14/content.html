Module 6 › Chapter 6.1 › Key Concepts
Query Execution Plan
A tree of operations the planner intends to run, with cost and row estimates.
EXPLAIN vs EXPLAIN ANALYZE
EXPLAIN shows estimates; EXPLAIN ANALYZE executes and reports actual timings and buffers.
Buffers and I/O
Buffer hits vs reads show whether work was served from cache or disk, guiding index or memory decisions.
Summary takeaway
Interpret estimates, measure with EXPLAIN ANALYZE, and prioritize fixes that reduce buffer reads and node-level actual time.
