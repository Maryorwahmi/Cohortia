Run the lab
Set up a products table, insert sample rows, run ANALYZE, then compare EXPLAIN ANALYZE with and without an index.
CREATE TABLE products (
  product_id SERIAL PRIMARY KEY,
  product_name VARCHAR(255),
  category VARCHAR(100),
  price NUMERIC(10,2),
  stock_quantity INT
);

-- Insert statements generate rows for testing
ANALYZE products;
