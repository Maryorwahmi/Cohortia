Module 6 › Chapter 6.1 › Buffer statistics
Buffer types
shared hit, read, dirtied, written convey whether pages were read from memory or disk and whether pages were modified.
Interpretation
  • High reads => disk I/O bottleneck; consider indexes or reducing scanned rows.
  • High hits => data served from cache; further gains may be CPU or plan-based.
  • Dirtied/written => heavy writes and checkpoint activity to consider.
Sample EXPLAIN ANALYZE buffers line
Buffers: shared hit=200 read=500 dirtied=0 written=0
Actionable insight
If reads dominate, target reducing scanned pages via indexes or filtering. If hits dominate, confirm plan efficiency and CPU usage.
