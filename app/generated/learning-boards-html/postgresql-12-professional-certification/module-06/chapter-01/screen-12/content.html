Module 6 › Chapter 6.1 › Statistics and ANALYZE
Why estimates go wrong
  • Outdated statistics after heavy DML.
  • Skewed distributions that default statistics miss.
  • Columns with many nulls or very low cardinality.
Investigation steps
Run ANALYZE, inspect pg_stats for the predicate column, and consider raising STATISTICS target if skew is present.
Query pg_stats example
SELECT most_common_vals, n_distinct, null_frac
FROM pg_stats
WHERE tablename = 'products' AND attname = 'category';
If most_common_vals shows a dominant value and the planner underestimates its frequency, increase statistics target or redesign queries to reflect distribution.
