Learning Objectives

Four measurable skills that map to the labs and assessments.

Bloom: Learn → Understand → Apply → Master
01
Inspect live sessions with pg_stat_activity

Run targeted queries to find who is connected, what each backend is doing, and when a query began. Useful for stopping blocking issues fast.

VERIFIED COMPETENCY MILESTONE
02
Enable and read pg_stat_statements

Aggregate statement patterns to find high-impact queries by total time or call count. Learn how to enable the extension safely.

VERIFIED COMPETENCY MILESTONE
03
Query pg_stat_* views for object stats

Use pg_stat_user_tables and pg_stat_user_indexes for table/index usage and pg_stat_database for aggregate health metrics.

VERIFIED COMPETENCY MILESTONE
04
Read logs and integrate external tools

Configure log_min_duration_statement and review server logs; plan integration with exporters and dashboards for alerts and history.

VERIFIED COMPETENCY MILESTONE
