Module 6 › Chapter 6.4 › Enable pg_stat_statements
Configuration
# postgresql.conf
shared_preload_libraries = 'pg_stat_statements'

-- After restart, in the target database:
CREATE EXTENSION pg_stat_statements;
How aggregation works

The extension normalizes statement patterns so that the same query shape with different literals is counted together. This reduces noise and surfaces patterns that matter most by total time or call volume.

Practical notes
  • Requires server restart because it is a shared library preload.
  • Consumes some memory and CPU; enable judiciously in production during investigation or permanently if needed.
  • Run representative load after enabling to collect meaningful metrics.
Key Takeaway

Enable the extension correctly, let it collect data, then query for top consumers to guide optimization.
