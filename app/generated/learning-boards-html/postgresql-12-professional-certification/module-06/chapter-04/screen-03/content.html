Hands-on checklist

Steps and safety checks you'll use in the lab walkthrough.

Enable
Add pg_stat_statements to shared_preload_libraries and restart Postgres; then run CREATE EXTENSION in the database.
Reproduce
Generate representative queries so aggregated stats are meaningful before drawing conclusions.
Inspect
Use pg_stat_activity to find long-running backends and note their pid before canceling or terminating safely.
Safety tip

Avoid sharing raw query text from monitoring outputs without masking sensitive data and use monitoring roles with least privilege.

Mnemonic

Think: Inspect, Aggregate, Act — where inspect is pg_stat_activity, aggregate is pg_stat_statements, act is targeted cancellation or optimization.
