Module 6 › Chapter 6.5 › Thresholds & Scale Factors
How triggers are calculated
Use threshold plus a fraction of table size to define when autovacuum acts.
Vacuum example
Trigger when n_dead_tup > autovacuum_vacuum_threshold + table_rows * autovacuum_vacuum_scale_factor.
# example configuration
autovacuum_vacuum_threshold = 50
autovacuum_vacuum_scale_factor = 0.2

# 10000-row table triggers at: 50 + (10000 * 0.2) = 2050 dead tuples
Analyze example
ANALYZE uses its own threshold and scale factor. Set lower scale factors for tables where statistics must be frequently refreshed.
# example configuration
autovacuum_analyze_threshold = 50
autovacuum_analyze_scale_factor = 0.1
Practical tip
For very large tables, lower the scale factor so autovacuum runs earlier. For small tables, the defaults are often fine.
Key Takeaway

Tune thresholds and scale factors per table based on update/delete patterns to balance cleanup responsiveness and IO cost.
