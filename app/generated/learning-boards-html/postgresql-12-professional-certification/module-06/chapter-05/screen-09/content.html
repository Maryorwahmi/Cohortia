Cost delay and cost limit
Control how aggressively autovacuum consumes I/O by adjusting pauses and limits.
autovacuum_vacuum_cost_delay
Pause duration after the worker accrues cost equal to the limit. Lower values make autovacuum more aggressive.
# example
autovacuum_vacuum_cost_delay = 20ms
autovacuum_vacuum_cost_limit
Total I/O cost before taking a pause. Raising it lets autovacuum do more work between pauses.
# example
autovacuum_vacuum_cost_limit = 200
Practical caution
Aggressive cost settings speed cleanup but may increase latency for user queries. Measure I/O and latency impact before broad changes.
Key Takeaway

Only tune cost delay and limit after understanding your IO capacity and testing the effect on query latency in staging.
