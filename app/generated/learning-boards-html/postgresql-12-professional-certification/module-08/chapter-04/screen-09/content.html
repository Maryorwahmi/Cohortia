pg_isready usage
pg_isready -h <host> -p 5432 -d <db> -U <user>
# Exit codes: 0=accepting, 1=no response, 2=invalid conn string, 3=unavailable
Use pg_isready when you want a quick liveness check without credentials. It’s often the first tool to run in automation and monitoring checks.
psql flags to isolate problems
# Connect by IP to bypass DNS
psql -h <server_ip> -p 5432 -U <user> -d <db>
# Force TLS modes
psql "host=<host> port=5432 dbname=<db> user=<user> sslmode=disable"
If hostaddr connection succeeds but hostname fails, investigate DNS. If disabling sslmode allows auth, review TLS configuration and client certificates.
