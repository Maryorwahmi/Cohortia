pg_hba.conf ordering
First matching rule controls access and method; order matters.
Network reachability
Use telnet or nc to confirm port 5432 is reachable before changing server configs.
Connection limits
Check pg_stat_activity and max_connections; terminate idle in transaction sessions when appropriate.
Summary

Diagnose by layer, make one minimal change, verify with tools and logs, and document the remediation for future incidents.
