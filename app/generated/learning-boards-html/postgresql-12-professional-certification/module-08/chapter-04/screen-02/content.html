Module 8 › Chapter 8.4 › Learning Objectives
01
Diagnose pg_hba.conf
Read and interpret rules, understand rule order, and identify entries blocking a client. This prevents misapplied rejects and wrong auth methods.
VERIFIED COMPETENCY MILESTONE
02
Network & Firewall Checks
Use ping, telnet, and netcat to verify reachability and confirm port access before changing DB configs.
VERIFIED COMPETENCY MILESTONE
03
Identify resource exhaustion
Query pg_stat_activity to find max_connections pressure and idle in transaction sessions that consume slots.
VERIFIED COMPETENCY MILESTONE
04
Client diagnostic tools
Use pg_isready and psql connection options like hostaddr and sslmode to differentiate DNS, TLS, and auth problems.
VERIFIED COMPETENCY MILESTONE
How to use these objectives
  • Run a quick network port test first to avoid unnecessary server edits.
  • Check pg_hba.conf order and methods; reload after edits but restart only when necessary.
  • Monitor connection count and idle in transaction sessions to avoid surprises.
Mnemonic
Think: Reach, Authenticate, Resources. Reachable network, correct authentication rules, and available connection slots.
