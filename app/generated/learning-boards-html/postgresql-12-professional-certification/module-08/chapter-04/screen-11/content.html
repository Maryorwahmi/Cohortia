Sample log snippets
2024-01-01 12:00:12 UTC ERROR:  no pg_hba.conf entry for host "10.0.0.50", user "app_user", database "app_db", SSL off
2024-01-01 12:01:00 UTC FATAL:  password authentication failed for user "dev_user"
2024-01-01 12:05:34 UTC FATAL:  remaining connection slots are reserved for non-replication superuser connections
Use the error type to guide your next step: HBA errors → inspect pg_hba.conf; password failures → check auth method and user password; connection slot errors → inspect pg_stat_activity and max_connections.
Log-based workflow
  1. Find matching timestamp for the client failure.
  2. Read the error level and message to classify the failure.
  3. Take the smallest necessary remediation and retest to observe the log change.
