Queries to inspect connections
-- Current active connections
SELECT count(*) FROM pg_stat_activity;

-- Find idle in transaction sessions
SELECT pid, usename, datname, state, query_start, query
FROM pg_stat_activity
WHERE state = 'idle in transaction';

-- Terminate a backend
SELECT pg_terminate_backend(12345);
Use these queries to identify problematic sessions and terminate them when safe. Document and coordinate with app teams before killing connections in production.
When to increase max_connections
  • Only after verifying that connections are legitimate and not leaked by bad client behavior.
  • Plan for a restart and increased memory usage per connection.
  • Consider connection pooling as a scalable alternative.
