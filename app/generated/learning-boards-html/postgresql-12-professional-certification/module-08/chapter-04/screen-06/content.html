Module 8 › Chapter 8.4 › Auth Methods
Method comparison
trust
Allows connection without a password when matched. Use only for local, controlled environments.
md5
Password-based authentication using MD5 hash. Widely supported by clients.
scram-sha-256
More secure password hashing. Prefer for modern deployments if clients support it.
Misconfiguration example
If pg_hba.conf contains 'trust' for a client but the team expects password auth, connections succeed without passwords when allowed, or if they send a password the server may still accept but this creates security risk. Conversely, if the server requires scram-sha-256 and the client only supports md5, authentication fails.
Checks and fixes
  • Confirm client capability for scram or md5.
  • Match auth method in pg_hba.conf to client requirements.
  • Reload config and retest; watch for log messages describing failed auth attempts.
