Module 8 › Chapter 8.4 › Practical Checks
Four remediation tasks
A. Edit pg_hba.conf
Add or reorder rules, set methods to md5 or scram-sha-256, then reload to apply.
B. Adjust firewall
Open inbound port 5432 for allowed networks or remove accidental DROP rules, then retest connectivity.
C. Fix listen_addresses
Set listen_addresses to an interface IP or '*' for remote clients and reload or restart when required.
D. Free connections
Identify idle in transaction sessions and terminate backends or increase max_connections with restart if safe.
Verification steps
  • Use pg_isready to confirm server responds without auth.
  • Telnet or netcat to confirm port reachability.
  • Attempt a psql connection using hostaddr to bypass DNS.
