Module 8 › Chapter 8.4 › listen_addresses
Confirm where PostgreSQL is listening
# Check listen_addresses via server
sudo netstat -tulpn | grep 5432
# In psql
SHOW listen_addresses;
SHOW port;
Look for 127.0.0.1:5432 (local only) vs 0.0.0.0:5432 (all interfaces). If you change listen_addresses to allow remote access, plan for a restart if required by your distribution or version.
Checklist before allowing remote clients
  • Set listen_addresses to '*' or the server IP.
  • Open firewall ports and verify network reachability.
  • Add specific pg_hba.conf rules for allowed client IPs and methods.
Pro tip

Prefer explicit interface IPs in production rather than '*' when possible, then document the change.
