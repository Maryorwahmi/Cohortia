Module 8 › Chapter 8.5 › Autovacuum tuning
Key parameters
  • autovacuum_vacuum_scale_factor & autovacuum_vacuum_threshold — when vacuums trigger.
  • autovacuum_analyze_scale_factor & autovacuum_analyze_threshold — when to analyze.
  • autovacuum_vacuum_cost_delay & autovacuum_vacuum_cost_limit — throttle autovacuum I/O.
Per-table tuning
ALTER TABLE my_busy_table
  SET (
    autovacuum_vacuum_scale_factor = 0.001,
    autovacuum_vacuum_threshold = 1000
  );

Use table-level settings to ensure very active tables are vacuumed more aggressively than defaults.

Concrete example

If autovacuum_vacuum_scale_factor = 0.2 on a table with 10 million rows, vacuum triggers after 2 million updates; for a busy table you may want 0.001 so vacuum runs after 10,000 updates instead.

Misconception check

Disabling autovacuum to avoid resource usage is dangerous. Tune thresholds and costs to balance I/O with bloat prevention instead of turning it off.
