Module 8 › Chapter 8.5 › Learning Objectives
01
Measure disk usage

Run pg_database_size, pg_relation_size and pg_total_relation_size to quantify where bytes live and prioritize cleanup.

VERIFIED COMPETENCY MILESTONE
02
Detect table and index bloat

Interpret n_dead_tup, size ratios and bloat queries to decide if VACUUM is enough or VACUUM FULL is required.

VERIFIED COMPETENCY MILESTONE
03
Apply VACUUM strategies

Use VACUUM, VACUUM FULL and autovacuum settings appropriately to reclaim space or optimize reuse without unnecessary downtime.

VERIFIED COMPETENCY MILESTONE
04
Monitor temporary files and XID age

Log temp files, tune work_mem, and check age(datfrozenxid)/age(relfrozenxid) to prevent performance and safety issues.
