Module 8 › Chapter 8.5 › Monitoring & Maintenance
Daily
  • Check disk free space and autovacuum log entries.
  • Alert on large temp-file creation events.
Weekly
  • Run the top-20 pg_total_relation_size report and inspect pg_stat_user_tables.
  • Identify candidates for reindexing, VACUUM, or VACUUM FULL.
Emergency
  • Check age(datfrozenxid) and relfrozenxid; run VACUUM FREEZE if necessary.
  • Schedule VACUUM FULL only if space must be returned immediately and downtime is planned.
Runbook verification

For each maintenance action, record pre- and post- sizes and tuple counts so you can prove effectiveness and refine thresholds over time.
