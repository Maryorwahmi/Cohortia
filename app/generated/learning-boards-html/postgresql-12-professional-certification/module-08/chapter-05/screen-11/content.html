Module 8 › Chapter 8.5 › XID wraparound
What to monitor
  • SELECT datname, age(datfrozenxid) FROM pg_database ORDER BY age(datfrozenxid) DESC;
  • SELECT relname, age(relfrozenxid) FROM pg_class WHERE relkind = 'r' ORDER BY age(relfrozenxid) DESC;
Autovacuum role

Autovacuum automatically freezes old XIDs. Tune autovacuum_freeze_max_age and other settings if your workload ages XIDs quickly.

Urgent action

If warnings approach the threshold, run VACUUM FREEZE on the affected tables or the whole database to prevent wraparound and possible forced read-only state.

Concrete example

If age(datfrozenxid) approaches autovacuum_freeze_max_age, increase autovacuum aggressiveness and run manual VACUUM FREEZE on critical tables as an immediate mitigation.

Misconception check

Do not ignore XID warnings because regular queries still succeed. Wraparound risk is a safety issue that must be addressed before it becomes imminent.
