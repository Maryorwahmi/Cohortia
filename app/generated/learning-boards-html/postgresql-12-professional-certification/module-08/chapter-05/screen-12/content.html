Module 8 › Chapter 8.5 › Hands-on lab
Lab steps overview
  1. Create a bloated table and insert many rows.
  2. Run repeated UPDATE and DELETE statements to generate dead tuples.
  3. Measure sizes and dead/live tuple counts.
  4. Run VACUUM VERBOSE, measure, then VACUUM FULL VERBOSE and measure again.
Starter SQL snippets
CREATE TABLE bloated_table (
  id SERIAL PRIMARY KEY,
  data TEXT DEFAULT repeat('X', 100),
  value INT
);

INSERT INTO bloated_table (value)
SELECT i FROM generate_series(1, 100000) AS i;

-- generate bloat
UPDATE bloated_table SET value = value + 1 WHERE id % 2 = 0;
DELETE FROM bloated_table WHERE id % 7 = 0;

-- measure
SELECT pg_size_pretty(pg_total_relation_size('bloated_table'));
SELECT n_live_tup, n_dead_tup FROM pg_stat_user_tables WHERE relname = 'bloated_table';

-- reclaim
VACUUM VERBOSE bloated_table;
VACUUM FULL VERBOSE bloated_table;
What to observe
  • n_dead_tup should rise after updates/deletes and fall after VACUUM.
  • pg_total_relation_size may not fall after VACUUM, but will after VACUUM FULL.
  • Use these observations to choose routine VACUUM or schedule VACUUM FULL when necessary.
Safety note

Run the heavier VACUUM FULL only during maintenance windows because it takes an exclusive lock and can block application activity.
