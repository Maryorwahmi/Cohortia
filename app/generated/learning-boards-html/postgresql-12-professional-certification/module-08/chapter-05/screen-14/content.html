Module 8 › Chapter 8.5 › Key Concepts
Bloat (Table/Index)

Dead tuples and dead index entries increase storage and reduce performance; detect with n_dead_tup and size ratios.

VACUUM vs VACUUM FULL

VACUUM reclaims space for reuse; VACUUM FULL rewrites files and returns space to the OS but is blocking.

Autovacuum & XID

Tune autovacuum thresholds and monitor datfrozenxid/relfrozenxid to prevent XID wraparound and freezing issues.

Takeaway

Measure carefully, prefer non-blocking fixes first, tune autovacuum, and only use blocking operations when you must return space to the OS.
