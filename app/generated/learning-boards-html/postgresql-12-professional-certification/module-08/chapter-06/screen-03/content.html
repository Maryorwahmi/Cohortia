Module 8 › Chapter 8.6 › Learning Objectives — Skills
Monitor and interpret
You will run queries that return age(datfrozenxid) and age(relfrozenxid), then compare values to autovacuum_freeze_max_age. High values indicate autovacuum is falling behind.
Example queries
SELECT datname, age(datfrozenxid) FROM pg_database ORDER BY age(datfrozenxid) DESC;

SELECT relname, age(relfrozenxid) FROM pg_class WHERE relkind = 'r' ORDER BY age(relfrozenxid) DESC LIMIT 20;
Emergency and recovery
You will learn the conditions that justify VACUUM FREEZE and the steps to stop a server and run pg_checksums and pg_dumpall when corruption is suspected.
Quick commands
VACUUM FREEZE VERBOSE my_table;
SHOW data_checksums;
pg_checksums -D /var/lib/postgresql/data --check
