Module 8 › Chapter 8.6 › Diagnosing Corruption
Diagnosis

Safe, ordered steps

Step 1 — Stop the server
Prevent further writes to preserve the current on-disk state for inspection.
Step 2 — Verify checksums
If data checksums were enabled, run pg_checksums to detect corrupted pages at block level.
Step 3 — Attempt logical dumps
Use pg_dump or pg_dumpall to salvage readable tables. Logical dumps may succeed for some objects even when others fail.
Commands to run
-- Check checksums (requires DB stopped)
pg_checksums -D /var/lib/postgresql/data --check

-- Logical dump to salvage readable data
pg_dump -Fc -f mydatabase_backup.dump mydatabase
pg_dumpall -f all_databases.sql
Common Pitfall

Do not try to edit data files directly; always work on copies and prefer logical extraction where possible.
