Hands-on Activity

Safe simulation on a test DB

CREATE TABLE xid_test (
  id SERIAL PRIMARY KEY,
  data TEXT
);

ALTER TABLE xid_test SET (autovacuum_enabled = off);

-- Insert initial data
INSERT INTO xid_test (data) SELECT md5(random()::text) FROM generate_series(1, 10000);

-- Perform many updates inside a DO block to simulate transactions
DO $$
BEGIN
  FOR i IN 1..10000 LOOP
    UPDATE xid_test SET data = md5(random()::text) WHERE id = (random() * 9999 + 1)::int;
  END LOOP;
END;
$$ LANGUAGE plpgsql;

-- Emergency corrective action
VACUUM FREEZE VERBOSE xid_test;

-- Cleanup
ALTER TABLE xid_test SET (autovacuum_enabled = on);
DROP TABLE xid_test;
Observation
After the updates, relfrozenxid age should rise. After VACUUM FREEZE, relfrozenxid age should return to a small value, showing the freeze effect.
Safety Note

Do not perform this simulation on production. The exercise demonstrates behavior and tools, not a production procedure.
