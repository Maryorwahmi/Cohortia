Definition

Symptoms and common causes

Example log messages
"invalid page header in block 12345 of relation base/..." or "could not read block"
Likely root causes
  • Hardware failures: disk or memory errors.
  • OS or filesystem problems preventing fsync.
  • Power loss with full_page_writes disabled or failing fsync.
  • Rare bugs or manual file tampering.
Immediate action
If you suspect corruption, stop the database immediately to avoid further writes and preserve state for diagnostics.
Key Takeaway

Corruption is typically environmental; protective settings like full_page_writes and checksums reduce risk and improve detection.
