Module 8 › Chapter 8.6 › Monitoring XID Age
Monitoring

Key queries to run regularly

-- Monitor XID age for all databases
SELECT datname, age(datfrozenxid) AS xid_age,
       (SELECT setting FROM pg_settings WHERE name = 'autovacuum_freeze_max_age')::int - age(datfrozenxid) AS remaining_xids_to_freeze_max_age
FROM pg_database
ORDER BY xid_age DESC;

-- Monitor XID age for tables
SELECT relname, age(relfrozenxid) AS xid_age,
       (SELECT setting FROM pg_settings WHERE name = 'autovacuum_freeze_max_age')::int - age(relfrozenxid) AS remaining_xids_to_freeze_max_age
FROM pg_class
WHERE relkind = 'r'
ORDER BY xid_age DESC
LIMIT 20;
Interpretation tips
  • If remaining_xids_to_freeze_max_age becomes small, schedule corrective action.
  • Focus on tables with the highest relfrozenxid ages; global averages hide hot tables.
  • Use pg_stat_activity to confirm autovacuum processes are running and finishing.
Concrete example
If age(relfrozenxid) returns 190,000,000 and autovacuum_freeze_max_age is 200,000,000, there's only a small window left. Tune autovacuum or run manual vacuum freeze quickly.
Common Mistake

Ignoring long-running autovacuum or assuming one worker will keep up. Increase workers if many tables need attention.
