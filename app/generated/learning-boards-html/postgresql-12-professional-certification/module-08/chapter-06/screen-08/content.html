Emergency Procedure

Planning and execution

Before running VACUUM FREEZE, pick a maintenance window and ensure backups exist. VACUUM FREEZE marks tuples as frozen and is blocking on the tables it touches.

Command example
VACUUM FREEZE VERBOSE my_critical_table;
-- Or from a superuser for the whole database (blocking):
-- VACUUM FREEZE VERBOSE;
  • Run during maintenance to avoid application impact.
  • Verify relfrozenxid is reset after completion.
  • Retune autovacuum so this is not repeatedly required.
Checklist
  1. Confirm backups and notify stakeholders.
  2. Choose maintenance window and target tables.
  3. Run VACUUM FREEZE VERBOSE and monitor logs.
Warning

VACUUM FREEZE can block queries; do not run it on production hot paths without coordination.
