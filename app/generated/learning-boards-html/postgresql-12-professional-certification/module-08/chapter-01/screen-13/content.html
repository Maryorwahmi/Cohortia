Hands-on Activity
Configure, generate, analyze
A terminal-first walkthrough to validate your logging changes.
Step 1 — Configure
Set logging_collector = on, a timestamped log_filename, and log_min_duration_statement = 100. Restart PostgreSQL to apply changes.
Step 2 — Generate activity
Create a large table, insert many rows, then run SELECT pg_sleep(0.2) and full table scans to produce slow entries.
Step 3 — Inspect logs
Tail the latest postgresql-*.log and confirm entries show timestamp, PID, user, and the slow SQL text.
Starter commands
-- Sample config lines for postgresql.conf
logging_collector = on
log_directory = 'log'
log_filename = 'postgresql-%Y-%m-%d_%H%M%S.log'
log_min_duration_statement = 100
log_connections = on
log_disconnections = on

-- Sample SQL to generate slow logs
CREATE TABLE large_data (id SERIAL PRIMARY KEY, value TEXT, created_at TIMESTAMP DEFAULT NOW());
INSERT INTO large_data (value)
SELECT md5(random()::text) FROM generate_series(1, 100000);
SELECT pg_sleep(0.2);
SELECT count(*) FROM large_data WHERE value LIKE '%abc%';
After the exercise, revert thresholds if needed and archive the generated logs for later study.
