Log Files
pg_log, rotation, and retention
Use rotation settings to control file sizes and prevent a single huge log file.
Rotation parameters
log_rotation_age = 1d, log_rotation_size = 256MB, log_truncate_on_rotation (controls truncation when using fixed filenames).
Operational tips
Monitor free disk space, archive rotated files externally, and ensure file permissions are correct for write and archival processes.
Key Takeaway
Rotation plus monitoring is essential to prevent logs from filling disk and to keep archives usable for analysis.
Example
# Timestamped filenames
log_filename = 'postgresql-%Y-%m-%d_%H%M%S.log'
log_rotation_age = 1d
log_rotation_size = 256MB

# Or use truncation with a fixed name if required
# log_truncate_on_rotation = on
# log_filename = 'postgresql.log'
Be mindful that using time-based filename escapes disables truncation behavior. Choose the naming and rotation strategy that fits your archival and monitoring tools.
