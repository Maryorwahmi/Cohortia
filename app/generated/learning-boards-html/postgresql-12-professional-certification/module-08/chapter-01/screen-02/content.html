Learning Objectives
Understand and apply logging settings to make PostgreSQL diagnostics reliable.
01
Configure logging parameters
Edit postgresql.conf to enable collectors, destinations, and rotation so logs are captured reliably.
VERIFIED COMPETENCY MILESTONE
02
Capture slow statements
Use log_min_duration_statement to record queries exceeding a threshold without logging everything.
VERIFIED COMPETENCY MILESTONE
03
Contextualize log lines
Define log_line_prefix tokens to include timestamp, PID, user, and database for faster tracing.
VERIFIED COMPETENCY MILESTONE
04
Manage rotation and security
Configure rotation age/size and secure log directories to prevent data leaks and disk exhaustion.
VERIFIED COMPETENCY MILESTONE
