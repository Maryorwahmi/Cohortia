Context & Traceability
log_line_prefix
Choose tokens that help you tie a log entry back to a user, database, and time.
Common tokens
%m = timestamp with milliseconds; %p = process ID; %u = user; %d = database; %r = remote host and port; %l = line number; %i = command tag.
Recommended example
log_line_prefix = '%m [%p] %q%u@%d ' to show time, PID, and quoted user@database context on every line.
Key Takeaway
A well-chosen prefix makes searching and correlating log lines fast and precise.
Example prefixes
# Include timestamp, pid, quoted user@db
log_line_prefix = '%m [%p] %q%u@%d '

# If you need client IP
log_line_prefix = '%m [%p] %u@%d %r '
Security note
Including client IPs and user names improves auditing but increases sensitivity of log files; restrict access accordingly.
