Performance
log_min_duration_statement
Log statements taking longer than a configured threshold in milliseconds.
How it works
Set a millisecond threshold; statements longer than that are recorded with their duration and text.
Best practice
Choose a threshold that captures problem queries but avoids logging routine fast operations.
Key Takeaway
Use duration-based logging to focus on the queries that matter for performance tuning.
Example: cause a slow log entry
# Set threshold to 100 ms
log_min_duration_statement = 100

-- This will be logged because it sleeps for 200ms
SELECT pg_sleep(0.2);
Misconception
Logging everything with log_statement = 'all' may seem easier, but it produces massive logs and can hurt performance; prefer targeted duration-based logging.
