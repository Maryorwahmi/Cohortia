Configuration
postgresql.conf: logging essentials
Enable the collector, set destinations, and design filenames for rotation and analysis.
Parameters to set
  • logging_collector = on
  • log_destination = 'stderr' (or csvlog for structured parsing)
  • log_directory = 'log' (relative to data directory)
  • log_filename = 'postgresql-%Y-%m-%d_%H%M%S.log'
  • log_rotation_age and log_rotation_size
Why it matters
Without the collector and clear filenames, logs may be scattered or overwritten, and automated rotation becomes unreliable.
Example configuration
# Enable logging collector
logging_collector = on

# Log destination and directory
log_destination = 'stderr'
log_directory = 'log'
log_filename = 'postgresql-%Y-%m-%d_%H%M%S.log'

# Rotation policy
log_rotation_age = 1d
log_rotation_size = 256MB
Key Takeaway
Decide where logs live and how often they roll over before you need them for diagnosis.
