Safe EXPLAIN ANALYZE for DML

Use transactions to gather runtime stats without committing changes.
BEGIN;
EXPLAIN ANALYZE UPDATE products SET price = price * 1.05 WHERE category = 'Electronics';
ROLLBACK;
Common mistakes
Running DML without rollback
Can cause side effects, long locks, and WAL growth; always avoid on production data.
Trusting EXPLAIN alone
EXPLAIN shows estimates which depend on statistics; confirm with EXPLAIN ANALYZE.
Skipping BUFFERS when diagnosing I/O
Add BUFFERS to see whether disk reads are the limiting factor.
Warning

Never run unverified DML EXPLAIN ANALYZE against production without safeguards; use transactions or dev clones.
