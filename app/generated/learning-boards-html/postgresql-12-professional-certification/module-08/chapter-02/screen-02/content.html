Learning Objectives

These objectives map to reading plans, running experiments, and applying index or statistics fixes.

Bloom: Learn → Understand → Apply → Master
01
Read EXPLAIN output

Learn to parse cost, rows, and width so you can form a precise hypothesis about where work occurs.

VERIFIED COMPETENCY MILESTONE
02
Interpret EXPLAIN ANALYZE

Use actual time, rows, and loops to validate or refute the optimizer's plan and spot stale statistics.

VERIFIED COMPETENCY MILESTONE
03
Spot plan-node red flags

Recognize Seq Scan, excessive Sorts, or nested loops that indicate missing indexes or poor statistics.

VERIFIED COMPETENCY MILESTONE
04
Apply index and ANALYZE fixes

Create composite or trigram indexes and run ANALYZE to improve plans, then verify with EXPLAIN ANALYZE.

VERIFIED COMPETENCY MILESTONE
