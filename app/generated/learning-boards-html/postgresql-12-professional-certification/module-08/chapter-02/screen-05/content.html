Definition

EXPLAIN ANALYZE metrics

Actual time, rows, and loops quantify what happened during execution and let you spot discrepancies with the optimizer's estimates.
actual time
Elapsed milliseconds for startup and total time of the node; helps locate where time is spent.
rows & loops
Actual rows processed and number of times the node executed; loops expose repeated inner scans.
Buffers & WAL
Optional details revealing I/O and WAL generation when BUFFERS or WAL are requested.
Concrete example
EXPLAIN (ANALYZE, BUFFERS) SELECT * FROM products WHERE product_name LIKE 'Laptop%';

Look for actual time and buffers. If actual time is high and buffers show many reads, then I/O is the bottleneck and an index on product_name (or a change in access pattern) may help.

Misconception
Running EXPLAIN alone can mislead you; estimates depend on statistics and are not a substitute for actual measurements.
Pro tip
Use BEGIN; EXPLAIN ANALYZE for DML and ROLLBACK to avoid permanent changes in production-like tests.
