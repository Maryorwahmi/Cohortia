Incident checklist

A short, repeatable set of steps to identify and remediate replication problems.

1. Logs
Search primary and standby logs for archive or subscription errors.
2. Metrics
Collect pg_stat_replication, pg_stat_wal_receiver, pg_replication_slots.
3. OS checks
Run iostat, htop, iperf or tcpdump to find resource limits.
4. Config & privileges
Verify wal_level, max_wal_senders, slots and REPLICATION role for users.
5. Remediate
Tune, fix archive_command, consider dropping inactive slots only after review.
6. Verify
Monitor pg_wal size and replay_lag until metrics return to normal.
Pro tip
Record the exact LSN and slot state before making destructive changes so you can plan resynchronization if needed.
