Module 8 › Chapter 8.7 › Network vs Storage

Network indicators

  • sent_lsn lags behind pg_current_wal_lsn on primary.
  • Use ping for latency, iperf for throughput, tcpdump for packet flow.
  • Look for retransmits or slow sockets that delay WAL send.
Command hints
ping, iperf3, tcpdump -s 0 -w sample.pcap host port

Storage indicators

  • write_lsn or replay_lsn lags while sent_lsn is current.
  • Run iostat -x 1 and watch %util and await; high await suggests disk latency.
  • Check for swapping or high iowait in htop.
Command hints
iostat -x 1, htop or top, dstat
Analogy
Think of WAL as freight: if the truck leaves slowly, it's a network problem; if the warehouse can't unload fast enough, it's a storage problem.
