WAL archiving failures

Symptoms, checks and recovery steps for archive_command issues.

Symptoms
  • archive command failed messages in logs
  • pg_wal directory grows in size
  • standby cannot fetch archived WAL segments
Root causes
  • permission or path errors
  • network or remote storage outages
  • insufficient disk space on archive target
Remediation steps
  1. Examine primary logs for archive_command errors.
  2. Verify archive_command works as postgres user and destination is writable.
  3. Check network and disk space; copy unarchived WALs to the archive if needed.
Common mistake
Assuming restart resolves past failed archive attempts; you may need to manually place old WALs into archive storage.
