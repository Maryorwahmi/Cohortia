Module 8 › Chapter 8.7 › Replication types
Definition

Physical streaming

Streams WAL records; standby replays the same WAL so it remains an exact copy.

Symptoms
LSN gaps, growing pg_wal, slow replay_lsn
Common checks
pg_stat_replication, pg_stat_wal_receiver, iostat, htop
Definition

Logical replication

Sends logical changes; subscriber applies DML statements and may diverge if local writes exist.

Symptoms
Subscription errors, conflict messages, stopped apply
Common checks
pg_stat_subscription, subscriber logs, replication slots
Concrete example
A primary sends WAL quickly but replay_lsn on the standby is far behind; this indicates apply or I/O issues, not a network sending problem.
Common mistake
Treating a logical conflict as an I/O problem. Logical conflicts are data-level and must be resolved on the subscriber.
