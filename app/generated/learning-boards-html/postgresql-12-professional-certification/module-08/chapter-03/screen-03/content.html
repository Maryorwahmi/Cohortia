Module 8 › Chapter 8.3 › Practical Skills
Terminal Commands
htop / top — check per-process CPU, iowait and memory usage.
iostat -x 1 — observe %util, await, r/s and w/s for disks.
vmstat 1 — monitor swap in/out and memory cache behavior over time.
ss -tunap | grep 5432 — inspect active PostgreSQL connections and network stats.
PostgreSQL Views
pg_stat_activity — detect long-running or idle-in-transaction queries holding resources.
pg_stat_statements — find heavy queries by time, calls, and blocks read (if enabled).
pg_locks — identify blocking and waiting transactions to diagnose contention.
