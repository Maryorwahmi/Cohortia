Comparison

Differentiate CPU/I/O waits from lock waits by inspecting pg_locks and session states.

SELECT a.pid, a.usename, a.query, a.query_start, l.granted,
       pg_blocking_pids(a.pid) AS blocking_pids
FROM pg_locks l
JOIN pg_stat_activity a ON l.pid = a.pid
WHERE l.granted = false
ORDER BY a.query_start;

-- Use pg_blocking_pids to find the blockers
Remediation patterns
  • Use pg_cancel_backend() to stop a running query when appropriate.
  • Use pg_terminate_backend() only when you need to force cleanup.
  • Fix application behavior to avoid long transactions and idle-in-transaction states.
Common Mistake

Killing OS processes can corrupt state; prefer database-level cancellation or termination functions for a safe cleanup.
