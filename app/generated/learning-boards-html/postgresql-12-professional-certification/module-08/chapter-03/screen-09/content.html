Code Walkthrough
-- Top queries by total time
SELECT query, calls, total_time, mean_time, rows, shared_blks_hit, shared_blks_read
FROM pg_stat_statements
ORDER BY total_time DESC
LIMIT 10;

-- Then run EXPLAIN ANALYZE on the identified SQL to inspect the plan
Interpretation tips
  • High shared_blks_read means reads from disk; consider indexing or caching.
  • High total_time with low calls indicates an expensive single query.
  • Cross-check with iostat/vmstat if I/O or swapping are suspected.
Key Takeaway

pg_stat_statements points you to heavy SQL; combine it with EXPLAIN ANALYZE and OS metrics for a complete diagnosis.
