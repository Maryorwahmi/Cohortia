Module 8 › Chapter 8.3 › Network Impact & Visibility
Network
Inspect sockets and bandwidth when you suspect remote latency is dominating query time.
ss -tunap | grep 5432
# Shows active TCP/UDP sockets connected to the PostgreSQL port
iftop -P -i eth0
# Measure bandwidth usage between hosts (requires iftop)
Checklist
  • Confirm client and DB are in the same network region if latency matters.
  • Look for retransmits, high RTT, or saturated NIC during slow periods.
  • For replication, ensure stable bandwidth and low packet loss between nodes.
Why it matters

Network issues can mimic slow database behavior and lead to incorrect fixes if not checked early.
