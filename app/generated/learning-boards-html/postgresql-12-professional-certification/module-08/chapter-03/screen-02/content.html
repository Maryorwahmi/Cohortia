Learning Objectives
Bloom bar: Learn → Understand → Apply → Master
01
Identify OS metrics

Read CPU, memory, I/O and network metrics and explain why each affects database latency. Verified Competency Milestone

02
Use Linux tools

Run top, iostat, vmstat and ss to gather live data and interpret the relevant columns. Verified Competency Milestone

03
Correlate OS and PG

Match OS events to pg_stat_activity and pg_stat_statements entries to identify root causes. Verified Competency Milestone

04
Diagnose bottlenecks

Differentiate disk, CPU, memory, and network issues and choose immediate remediation steps. Verified Competency Milestone

Visual Mnemonics
CPU: Meter
User vs system vs iowait — high iowait suggests disk waits.
Memory: Cache vs Swap
OS page cache helps reads; swapping harms performance.
I/O: Throughput & Await
%util and await show saturation and queuing.
