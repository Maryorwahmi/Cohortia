Module 8 › Chapter 8.3 › Disk I/O with iostat
Process

Run iostat -x 1 to watch device metrics over time

# Example
$ iostat -x 1
Device:         rrqm/s  wrqm/s     r/s     w/s   rkB/s   wkB/s  avgrq-sz  avgqu-sz  await  svctm  %util
sda               0.00    0.30   10.50  120.80   256.0  4096.0     67.2     5.34   42.1   3.50  45.6
# Watch %util for saturation and await for request latency
Key metrics
  • %util — percent time device busy; near 100% means saturated.
  • await — average I/O wait time in ms; high values show latency.
  • r/s w/s, rkB/s wkB/s — throughput in operations and bytes.
Pro Tip

Capture iostat during expected peak workloads and compare to a healthy baseline to identify abnormal patterns.
