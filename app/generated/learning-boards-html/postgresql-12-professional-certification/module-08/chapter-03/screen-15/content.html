Module 8 › Chapter 8.3 › Quick Reference
1. Quick inspect
Run htop/top to view CPU, iowait, memory and process activity immediately.
2. Disk & Memory
Run iostat -x 1 and vmstat 1 to capture storage latency and swap behavior.
3. DB correlation
Query pg_stat_activity and pg_stat_statements to find the sessions and statements active during the observed window.
Final Tip

Always capture timestamps and store snapshots. That evidence makes post-incident analysis and remediation far more effective.
