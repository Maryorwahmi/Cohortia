Module 8 › Chapter 8.3 › Memory, OS Cache, and Swapping
Definition

Memory roles: shared buffers, work_mem, and OS cache

Understand what memory does for PostgreSQL and how OS caching complements database buffers.

The OS page cache serves repeated reads from RAM rather than disk, improving read latency.
Work_mem is per-operation; many operations multiply memory usage, potentially causing overallocation.
Swapping (si/so in vmstat) signals memory pressure that needs immediate remediation.
Terminal example
vmstat 1
# Look for non-zero 'si' and 'so' columns indicating swap in/out
free -m
# Inspect total, used, and available memory
Common Mistake

Treating free RAM as waste; instead use it for cache and size PostgreSQL memory settings to avoid swapping.
