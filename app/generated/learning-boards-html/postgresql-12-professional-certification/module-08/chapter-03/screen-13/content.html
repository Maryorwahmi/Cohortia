Assessment
Given the metric snapshot, decide bottleneck and actions.
Primary bottlenecks: Disk I/O saturation and memory swapping.
Immediate mitigations: reduce concurrency, pause large writes, lower memory settings to stop swapping.
Medium-term: upgrade storage, add RAM, tune checkpoint and autovacuum to smooth writes.
Self-check
