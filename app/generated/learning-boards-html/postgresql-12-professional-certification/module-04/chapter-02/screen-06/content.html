Module 04 › Chapter 4.2 › DO NOTHING vs DO UPDATE
DO NOTHING
INSERT INTO products (sku, name)
VALUES ('SKU001', 'Wireless Mouse')
ON CONFLICT (sku) DO NOTHING;

Use when an insert attempt should be skipped if the row already exists. This avoids extra updates and can be efficient when duplicates are harmless.

DO UPDATE
INSERT INTO products (sku, name, price)
VALUES ('SKU001', 'Wireless Mouse', 28.00)
ON CONFLICT (sku)
DO UPDATE SET price = EXCLUDED.price;

Choose this when incoming data should overwrite or merge with stored values. Be careful to update only necessary columns.

Decision guide
  • DO NOTHING: when existing record is trusted and incoming insert is optional.
  • DO UPDATE: when incoming insert contains authoritative changes you must apply.
  • Test concurrent scenarios to ensure updates do not undesirably overwrite newer values.
