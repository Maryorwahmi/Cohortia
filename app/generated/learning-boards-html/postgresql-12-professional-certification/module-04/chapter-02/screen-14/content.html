Module 04 › Chapter 4.2 › Compose multi-step upsert-and-log
Example: upsert incoming SKUs and log price changes
WITH old AS (
  SELECT product_id, sku, price
  FROM products
  WHERE sku IN ('SKU001','SKU003')
),
upserted AS (
  INSERT INTO products (sku, name, price, stock_quantity)
  VALUES
    ('SKU001', 'Wireless Mouse', 28.00, 160),
    ('SKU003', 'Gaming Headset', 79.00, 200)
  ON CONFLICT (sku)
  DO UPDATE SET price = EXCLUDED.price, stock_quantity = EXCLUDED.stock_quantity
  RETURNING product_id, sku, price AS new_price
),
audit AS (
  INSERT INTO product_audit_log (product_id, action_type, old_price, new_price)
  SELECT o.product_id, 'PRICE_CHANGE', o.price, u.new_price
  FROM old o
  JOIN upserted u ON o.product_id = u.product_id
  RETURNING *
)
SELECT * FROM upserted;
This single statement inserts or updates multiple SKUs, returns their new prices, and writes audit rows for those where an old price existed. All changes occur together.
