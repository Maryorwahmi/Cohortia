Module 04 › Chapter 4.2 › CTEs in DML
Typical pattern
WITH new_order AS (
  INSERT INTO orders (customer_id, total)
  VALUES (42, 199.95)
  RETURNING order_id
),
insert_items AS (
  INSERT INTO order_items (order_id, product_id, qty)
  SELECT order_id, product_id, qty FROM new_order JOIN ...
  RETURNING *
)
SELECT * FROM insert_items;
The first CTE inserts and returns the order id, which is then used to insert order items in the next CTE. All steps run in one statement and one transaction.
When to use
  • Creating parent and child records atomically.
  • Capturing old values and writing audit logs in the same statement.
  • Passing values between steps without extra round trips.
Why it matters
Writeable CTEs let you keep related write logic together, making it atomic and easier to reason about during failures.
