Module 04 › Chapter 4.2 › UPSERT syntax and EXCLUDED
Key elements
  • Specify the conflict target: a unique column or constraint.
  • Choose DO UPDATE to merge incoming values, or DO NOTHING to ignore the attempt.
  • Use EXCLUDED.column to reference the incoming value inside DO UPDATE.
Common mistake

Mistaking EXCLUDED for the old row. EXCLUDED holds the attempted insert values only.

Code walkthrough
INSERT INTO products (sku, name, price, stock_quantity)
VALUES ('SKU001', 'Wireless Mouse', 28.00, 160)
ON CONFLICT (sku)
DO UPDATE
SET price = EXCLUDED.price,
    stock_quantity = EXCLUDED.stock_quantity;
This statement will insert the row when sku is new, or update the existing product's price and stock from the incoming values when a conflict occurs.
Pro tip
Pick the conflict target carefully. Use the constraint or column(s) that reflect your uniqueness rule for the table.
