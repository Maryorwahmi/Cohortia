Advanced Data Manipulation

Use UPSERT, RETURNING, and writeable CTEs to make DML statements atomic and expressive.

This lesson focuses on real SQL patterns you will use in production: conflict handling on insert, retrieving generated values immediately, and composing multi-step writes inside a single statement.

Interactive 16:9 Masterclass
Visual Summary
UPSERT

Insert new row or update existing row if a unique constraint conflicts.

RETURNING

Return affected rows or generated values from INSERT, UPDATE, or DELETE.

CTEs in DML

Compose multi-step, atomic operations using WITH ... AS and data-modifying CTEs.

Key Takeaway

Use these server-side features to make writes atomic, reduce application logic, and fetch the exact data you need in a single round trip.

In this lesson
We will practice UPSERT, explore RETURNING, and build writeable CTEs that chain DML steps together. Examples use a products table and an audit log.
Explore Key Topics
UPSERT — insert or update atomically when a unique key conflicts.
RETURNING — get generated IDs or changed rows without extra queries.
CTEs in DML — chain writes and pass returned values between steps.
