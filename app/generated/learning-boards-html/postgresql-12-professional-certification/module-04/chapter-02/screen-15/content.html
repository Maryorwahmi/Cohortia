Module 04 › Chapter 4.2 › Key Concepts
UPSERT

INSERT ... ON CONFLICT: insert a row or update an existing row when a unique constraint conflict occurs.

ON CONFLICT DO UPDATE

Specify how to update the existing row when a conflict on the target occurs, often using EXCLUDED for incoming values.

EXCLUDED

An alias inside DO UPDATE that represents the values that would have been inserted if no conflict occurred.

Summary
Use UPSERT with a clear conflict target and EXCLUDED references to resolve duplicates; use RETURNING and CTEs to capture results and chain writes atomically.
