Module 04 › Chapter 4.2 › Data-modifying CTE for audit
Hands-on pattern
WITH old AS (
  SELECT product_id, price
  FROM products
  WHERE sku = 'SKU003'
),
upd AS (
  UPDATE products
  SET price = 79.00
  WHERE sku = 'SKU003'
  RETURNING product_id, price AS new_price
),
audit AS (
  INSERT INTO product_audit_log (product_id, action_type, old_price, new_price)
  SELECT o.product_id, 'PRICE_CHANGE', o.price, u.new_price
  FROM old o
  JOIN upd u USING (product_id)
  RETURNING *
)
SELECT * FROM audit;
This single statement captures the old price, updates the product, and writes an audit row using the returned new price. Everything is atomic and consistent.
Misconception check
Do not assume RETURNING gives historical values; explicitly capture the old row first if you need it.
