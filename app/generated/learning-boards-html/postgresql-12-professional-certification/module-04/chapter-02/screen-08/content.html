Module 04 › Chapter 4.2 › RETURNING for UPDATE and DELETE
UPDATE example from chapter
UPDATE products
SET price = price * 1.05
WHERE category = 'Electronics'
RETURNING product_id, name, price AS new_price, price * 1.05 AS old_price;
This example demonstrates returning computed columns. Note how expressions are evaluated against the updated row; plan accordingly if you need the pre-update value.
DELETE with RETURNING
DELETE FROM orders
WHERE order_id = 123
RETURNING *;
Returning * on DELETE is useful for recording the entire deleted row into an audit table or for undo flows.
Practical note

If you need both old and new values reliably, capture old values in a CTE before the UPDATE or use a data-modifying CTE pattern that returns needed columns for subsequent inserts.
