Module 5 › Chapter 4.6 › Monitoring
Useful views
  • pg_stat_activity — active sessions and their queries.
  • pg_locks — active locks and waiting relationships.
  • pg_stat_statements — slow or frequent queries that create contention.
Troubleshooting steps
  1. Use pg_stat_activity to find long-running transactions.
  2. Inspect pg_locks to find blockers and waiters.
  3. Check pg_stat_statements to optimize offending queries.
Example check
-- Find long transactions
SELECT pid, now() - query_start AS runtime, state, query
FROM pg_stat_activity
WHERE state <> 'idle'
ORDER BY runtime DESC
LIMIT 10;
Misconception
Killing the waiter is usually ineffective; identify and act on the session that holds the lock instead.
Key Takeaway

Use a combined view of sessions, locks, and statements to locate root causes and apply focused remediation.
