Module 04 › Chapter 4.5 › Handling serialization errors
Process

Retry strategy and conflict reduction

Why rollback happens

SSI detects dependency cycles that would break serial equivalence and aborts one transaction to avoid an invalid result.

Retry pattern
  1. Catch the serialization error in application code.
  2. Back off briefly if contention is high.
  3. Retry the transaction with the same logic.
Conflict reduction

Keep transactions short, touch fewer rows, perform reads before writes, and move non-critical work outside the critical section.

Key Takeaway

Treat serialization errors as expected behavior under SERIALIZABLE; design transactions to minimize them and implement robust retry logic.
