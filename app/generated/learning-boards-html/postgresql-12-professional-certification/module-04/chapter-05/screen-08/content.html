Architecture

Serializable Snapshot Isolation (SSI)

PostgreSQL enforces serializability by tracking dependencies between transactions and aborting those that would create non-serializable outcomes.

How SSI works

It observes read-write dependencies and detects cycles; when a problematic cycle is detected, one transaction is rolled back to maintain a serial order.

When to prefer SERIALIZABLE

Use it for audit-level reports or financial tasks that require a view consistent with some serial execution.

Practical trade-off

Stronger guarantees increase the chance of serialization errors and require retry logic, which can reduce throughput under contention.

Key Takeaway

SERIALIZABLE preserves serial equivalence using SSI; prepare for retries when conflicts are likely.
