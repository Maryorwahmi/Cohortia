Scenario

Place order and update stock atomically

Follow this pattern to avoid partial writes. Capture returning ids so subsequent inserts reference the same transaction scope.
BEGIN;
INSERT INTO orders (customer_id, total_amount) VALUES (1, 1620.00) RETURNING order_id;
-- assume returned order_id = 101
INSERT INTO order_items (order_id, product_id, quantity, item_price) VALUES (101, 1, 1, 1500.00);
INSERT INTO order_items (order_id, product_id, quantity, item_price) VALUES (101, 2, 1, 120.00);
UPDATE products SET stock_quantity = stock_quantity - 1 WHERE product_id = 1;
UPDATE products SET stock_quantity = stock_quantity - 1 WHERE product_id = 2;
COMMIT;
Check your work
After commit, run queries to validate that the orders and stock changes are present and that product stock values decreased by the expected amounts.
Key Takeaway

Combine related DML in one transaction so the commit reflects the complete business operation.
