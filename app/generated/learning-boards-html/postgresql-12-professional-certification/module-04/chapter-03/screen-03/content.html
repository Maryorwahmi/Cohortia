Practice goals

Hands-on verification builds confidence. Each objective maps to a concrete task you'll run in psql.

01
Build a safe order transaction
Insert order and order_items, update stock, and COMMIT only if all steps succeed.
VERIFIED COMPETENCY MILESTONE
02
Trigger and observe rollback
Attempt an invalid update and confirm that prior inserts are not persisted after ROLLBACK.
VERIFIED COMPETENCY MILESTONE
03
Use SAVEPOINTs
Set a marker, attempt risky steps, and roll back only the failed portion using ROLLBACK TO SAVEPOINT.
VERIFIED COMPETENCY MILESTONE
04
Diagnose transactional needs
Identify operations that represent one business action and require explicit transactions to avoid data anomalies.
VERIFIED COMPETENCY MILESTONE
