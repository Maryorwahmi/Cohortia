Module 4 › Chapter 4.4 › Key Concepts
Concurrency Control
Mechanisms that coordinate multiple users to keep data consistent.
MVCC
Each update creates a new row version; readers see snapshots determined by xmin/xmax visibility.
Row-level locks
Locks that protect individual rows, used for safe read-modify-write operations.
Quick Takeaway

Favor MVCC for reads; use explicit locks when you must serialize updates; use pg_locks to inspect blocking.
