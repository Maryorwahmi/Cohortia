Module 4 › Chapter 4.4 › Key Concepts
SELECT FOR UPDATE
Acquire exclusive row locks for safe read-modify-write cycles.
pg_locks
System view that shows granted and waiting locks to help diagnose blocking and deadlocks.
VACUUM
Cleans up obsolete row versions created by MVCC to reclaim storage and maintain performance.
Final takeaway

Design for MVCC-first reads, use explicit locks only when necessary, keep transactions short, and use pg_locks and pg_stat_activity to diagnose and resolve blocking or deadlocks.
