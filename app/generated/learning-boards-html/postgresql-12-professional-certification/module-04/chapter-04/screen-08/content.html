Using advisory locks

Advisory locks are explicit, application-defined locks acquired with functions such as pg_advisory_lock and pg_advisory_unlock.

Exclusive advisory lock
SELECT pg_advisory_lock(item_id); -- blocks until lock acquired
Try-lock
SELECT pg_try_advisory_lock(item_id); -- returns false immediately if not available
Example

Queue worker pattern

Worker A acquires pg_advisory_lock for item 42, processes the item and then releases it. Worker B calling pg_try_advisory_lock sees the lock is held and moves to another item or retries later.
Misconception
Advisory locks are not a replacement for proper transactional updates. Combine them with transactions that modify database state to maintain consistency.
