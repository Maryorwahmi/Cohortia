Multi-row INSERT

Batch inserts with VALUES

INSERT INTO products (product_name, price)
VALUES ('Laptop', 1200.00), ('Mouse', 25.00);

-- Efficient for seeding many rows in one statement
Benefit

Reduces network round trips and log overhead for many small inserts.

Pitfall

Large multi-row statements can still hit memory or statement-size limits; batch if necessary.

INSERT ... SELECT

Populate from a query

INSERT INTO archived_customers (customer_name, email, balance)
SELECT customer_name, email, balance FROM customer_accounts
WHERE status = 'Inactive';

-- Preview SELECT first to ensure correct rows
Key Takeaway

Always run the SELECT component first and ensure targets satisfy constraints before inserting in bulk.
