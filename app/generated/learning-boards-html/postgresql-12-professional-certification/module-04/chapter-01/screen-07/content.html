Module 4 › Chapter 4.1 › UPDATE syntax
Syntax
UPDATE employees
SET salary = 60000.00
WHERE employee_id = 101;

-- Multiple columns
UPDATE products
SET price = 1250.00, last_updated = NOW()
WHERE product_name = 'Laptop';
Tip

Use expressions like column = column + 100 for relative updates, and run SELECT to preview rows first.

Concrete example

Increase John Doe's balance

UPDATE customer_accounts
SET balance = balance + 100.00
WHERE customer_name = 'John Doe';

-- Verify
SELECT customer_name, balance FROM customer_accounts WHERE customer_name = 'John Doe';
Common Mistake

Omitting WHERE updates all rows. Always preview affected rows with SELECT before running UPDATE.
