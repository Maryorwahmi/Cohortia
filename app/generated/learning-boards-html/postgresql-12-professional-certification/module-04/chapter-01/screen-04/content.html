Syntax

INSERT with explicit columns

INSERT INTO customer_accounts (customer_name, email, balance)
VALUES ('Alice Brown', 'alice.brown@example.com', 500.25);

-- Verify
SELECT * FROM customer_accounts WHERE email = 'alice.brown@example.com';
Why list columns?

Explicit column lists prevent errors if the table adds columns or changes order, and they document intent for future readers.

Common mistake

Using INSERT without columns risks misaligned values if schema changes or if default-bearing columns are added.

Concrete example

Add a single customer

This example inserts one customer and then verifies the row exists. Use the SELECT to confirm email and balance.

Key Takeaway

Prefer explicit column lists and immediate verification queries after INSERT.

Check your understanding

If a column is NOT NULL and you omit it without a default, the INSERT will fail. Always confirm required columns first.
