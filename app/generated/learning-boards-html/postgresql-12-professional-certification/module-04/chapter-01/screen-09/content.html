Module 4 › Chapter 4.1 › DELETE
Definition

DELETE removes matching rows

DELETE FROM customer_accounts
WHERE customer_name = 'Peter Jones';

-- Use a transaction if you may need to rollback
Why choose DELETE?

It executes row-level triggers and supports rollback, so use it when per-row logic or transactional safety is needed.

Concrete example

Delete a specific out-of-date product or a single account identified by account_id. Always confirm with SELECT afterwards.

Common Mistake

Running DELETE without WHERE clears the table and may be irreversible without a backup. Use transactions and previews.

Key Takeaway

Prefer DELETE when you need triggers, foreign key cascades, or the ability to rollback.
