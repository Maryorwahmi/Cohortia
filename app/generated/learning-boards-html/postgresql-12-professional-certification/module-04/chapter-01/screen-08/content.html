Module 4 › Chapter 4.1 › Safe UPDATE workflow
Process Flow

Preview → Transaction → Update → Verify

1. Preview

Run SELECT with intended WHERE to inspect rows and counts.

2. Begin transaction

Start a transaction so you can ROLLBACK if needed.

3. Perform UPDATE

Run the UPDATE statement you prepared.

4. Verify & commit

Run SELECT to confirm changes and COMMIT if correct, otherwise ROLLBACK.

Example sequence
BEGIN;
SELECT * FROM customer_accounts WHERE balance < 100;
UPDATE customer_accounts SET status = 'Inactive' WHERE balance < 100;
SELECT count(*) FROM customer_accounts WHERE status = 'Inactive';
-- If OK: COMMIT; else: ROLLBACK;
