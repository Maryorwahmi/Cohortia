Starter tasks — solution pattern

Use these commands as model answers and be sure to preview with SELECT when you run them yourself.

1. Insert Alice Brown
INSERT INTO customer_accounts (customer_name, email, balance)
VALUES ('Alice Brown', 'alice.brown@example.com', 500.25);
SELECT * FROM customer_accounts WHERE email = 'alice.brown@example.com';
2. Increase John Doe's balance
UPDATE customer_accounts
SET balance = balance + 100.00
WHERE customer_name = 'John Doe';
SELECT customer_name, balance FROM customer_accounts WHERE customer_name = 'John Doe';
3. Set status for low-balance accounts
UPDATE customer_accounts
SET status = 'Inactive'
WHERE balance < 100.00;
SELECT customer_name, balance, status FROM customer_accounts WHERE status = 'Inactive';
4. Delete Peter Jones
DELETE FROM customer_accounts
WHERE customer_name = 'Peter Jones';
SELECT * FROM customer_accounts;
Key Takeaway

Follow each DML with a SELECT to verify results, and use transactions when practicing on production-like data.
