Practice & Safety

Concrete verification steps you will use when performing DML in a terminal.

Preview changes

Run a SELECT with the same WHERE as your planned UPDATE or DELETE to confirm affected rows first.

Use transactions

Wrap risky operations in a transaction so you can ROLLBACK if the result is unexpected during practice.

Verify with SELECT

After DML, run SELECT to confirm row counts and values, not just visual checks of terminal output.

Key Takeaway

Treat verification as part of every DML action. It turns accidental wide-sweeps into controlled updates and deletions.
