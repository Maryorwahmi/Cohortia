01
Explain the PITR workflow

Describe how base backups and archived WAL files combine to reconstruct database state and why each is required.

VERIFIED COMPETENCY MILESTONE
02
Configure recovery.conf parameters

Set restore_command, recovery_target_time/xid/name, and recovery_target_action to control how far and how recovery proceeds.

VERIFIED COMPETENCY MILESTONE
03
Execute a PITR run

Perform the full lab: stop server, clear PGDATA, restore base backup, start recovery and verify the recovered state.

VERIFIED COMPETENCY MILESTONE
04
Troubleshoot common PITR failures

Identify missing WALs, incorrect restore_command, and space issues, and apply corrective actions during recovery attempts.
