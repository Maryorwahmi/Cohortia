Checklist
  1. Confirm WAL archiving and locate the most recent valid base backup.
  2. Record TIMESTAMP_BEFORE_DELETE and TIMESTAMP_AFTER_DELETE for the test.
  3. Stop PostgreSQL and clear PGDATA safely.
  4. Restore base backup files and set ownership to postgres.
  5. Create recovery.conf with a tested restore_command and set recovery_target_time to TIMESTAMP_BEFORE_DELETE.
  6. Start PostgreSQL and monitor WAL replay in server logs.
  7. Verify recovered rows and check for recovery.done; promote if you need write access.
  8. Document the run, errors, and elapsed time for your runbook.
After-action review
Record missing WALs, restore_command corrections, and time to recovery. Use this to tighten your archive and retention policies.
