Module 6 › Chapter 5.6 › Recovery target options
Option
recovery_target_time
Specify a timestamp such as '2023-10-27 10:24:59 UTC' to stop at a wall-clock time.
recovery_target_xid
Recover to a specific transaction ID when you know the exact transaction boundary to stop at.
recovery_target_name
Use a named restore point created earlier for a precise, reproducible recovery target.
Practical note
Named restore points are best for planned maintenance because they remove ambiguity about ordering; timestamps are useful for accidental changes when you recorded the event time.
Example settings
recovery_target_time = '2023-10-27 10:24:59 UTC'
recovery_target_xid = 123456
recovery_target_name = 'before_maintenance'
recovery_target_inclusive = true
Key Takeaway

Pick the recovery target that matches the evidence you have: timestamp for event times, xid for transaction boundaries, or name for planned restore points.
