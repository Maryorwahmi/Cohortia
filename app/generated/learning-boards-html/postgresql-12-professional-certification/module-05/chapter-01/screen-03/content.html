Practice checklist
Run pg_dump and inspect SQL output
Use pg_dumpall for global objects
Take a pg_basebackup and verify consistency
Archive WAL files and attempt a PITR
Run a restore into a sandbox and validate roles and data
Verification tips
  • Confirm pg_dump captures expected schema and data for the targeted database.
  • Ensure pg_dumpall is used when you must preserve roles, tablespaces, or cluster-wide objects.
  • When using pg_basebackup, validate the restore boots and WAL replay moves the cluster to a consistent state.
  • Regularly schedule restore drills to detect missing WAL archives, permission issues, or misconfigured archive commands.
