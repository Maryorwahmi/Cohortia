What it copies
  • All on-disk data files for tables and indexes
  • Configuration files present in PGDATA
  • WAL segments when archived or streamed
Benefit: Fast backup and restore for very large datasets; suitable as disaster-recovery foundation.
Tool: pg_basebackup

pg_basebackup coordinates with the server to produce a consistent base backup and supports streaming WAL for coverage during the backup.

pg_basebackup -U postgres -D /tmp/test_db_physical_backup -F tar -X stream -P
Remember: a file-system copy of PGDATA without coordination is unsafe if the server is running.
Key Takeaway

Use pg_basebackup for fast, consistent base backups. Combine base backups with archived WAL files to achieve point-in-time recovery.
