Module 5 › Chapter 5.5 › Plain-format pg_basebackup
Command walkthrough
Use a timestamped directory and show progress.
pg_basebackup -h localhost -U postgres -D /mnt/pg_backups/base_backup_$(date +%Y%m%d_%H%M%S) -P
Notes: destination must be empty or not exist; creating a timestamp avoids accidental overwrites. The user needs REPLICATION privilege.
Explanation of flags
  • -h host: target server address.
  • -U user: the connecting user with REPLICATION privilege.
  • -D destination: directory to create and populate.
  • -P: show progress during the backup.
Key Takeaway

Plain format is ready-to-restore into PGDATA; always use a unique destination and check permissions beforehand.
