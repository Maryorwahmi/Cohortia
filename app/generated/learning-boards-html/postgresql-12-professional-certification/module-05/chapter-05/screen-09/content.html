WAL options
Choose how pg_basebackup includes the WAL segments required for recovery.
-X stream
Streams WAL segments from the server while the backup runs and places them in the backup. Recommended for a self-contained PITR starting point.
-X fetch
Fetches required WAL files after the backup completes. Useful when sender slots are limited but may be slower.
-X none
No WALs included. Use only if you have a reliable external WAL archive and are confident nothing will be missing.
Example: stream
pg_basebackup -h localhost -U postgres -D /mnt/pg_backups/base_backup_stream -P -X stream
Why stream

Streaming ensures WALs produced during the backup are captured immediately, preventing gaps in the recovery chain.
