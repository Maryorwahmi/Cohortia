Module 5 › Chapter 5.5 › Hands-on Activity
Prepare the host
Create and assign ownership to the backup destination before running pg_basebackup.
sudo mkdir -p /mnt/pg_backups
sudo chown -R postgres:postgres /mnt/pg_backups
These commands ensure the postgres user can create timestamped backup directories without permission errors.
Run the backup
pg_basebackup -h localhost -U postgres -D /mnt/pg_backups/base_backup_plain_$(date +%Y%m%d_%H%M%S) -P -X stream
You will be prompted for a password unless other authentication is in place. Monitor progress for completion.
Inspect the results
ls -l /mnt/pg_backups/base_backup_plain_*/
ls -l /mnt/pg_backups/base_backup_plain_*/pg_wal
# Look for base.backup and WAL segment files
Confirming files exist gives confidence the base backup and WALs were captured successfully.
