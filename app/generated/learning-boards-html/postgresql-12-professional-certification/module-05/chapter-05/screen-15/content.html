Module 5 › Chapter 5.5 › Key Concepts
pg_basebackup
Utility to take consistent physical backups from a running server using the replication protocol.
Format: plain vs tar
Plain produces a directory ready to restore; tar is a single archive better for transport.
WAL inclusion
Use -X stream to include WALs during backup; fetch or none have trade-offs and risks for PITR.
Summary takeaway
Combine server configuration, the correct pg_basebackup options, and operational checks to create backups that are both successful and restoreable.
