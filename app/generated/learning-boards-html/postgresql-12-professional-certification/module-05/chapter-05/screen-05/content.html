Key server settings
These settings enable replication protocol access and WAL streaming.
wal_level = replica
Enables required WAL detail for streaming and archiving.
max_wal_senders
Provide enough senders for -X stream backups and other replication clients.
pg_hba.conf entry
Add host replication USER ADDR METHOD and reload Postgres to apply changes.
Command example (pg_hba.conf)
# pg_hba.conf
host    replication     postgres        192.168.1.0/24          md5
After editing, reload with pg_ctl reload or the system service equivalent so the server accepts replication connections immediately.
Misconception

Editing only the client command without setting wal_level to replica will not enable streaming WAL delivery; the server must be configured.
