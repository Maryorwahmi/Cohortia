Performing a Base Backup with pg_basebackup
A practical walkthrough to produce consistent physical backups and include the WAL chain required for PITR.

Why this matters: A base backup alone is only useful when it links to the required WAL segments. Using pg_basebackup with streaming ensures the backup and WALs form a continuous recovery chain.

Use cases: disaster recovery, creating standby servers, and preparing a restore point for maintenance testing.

In this lesson
Configure replication prerequisites, run plain and tar backups, include WALs with -X stream, and inspect backup contents for PITR readiness.
