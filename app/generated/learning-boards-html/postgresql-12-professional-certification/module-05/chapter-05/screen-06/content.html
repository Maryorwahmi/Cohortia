Module 5 › Chapter 5.5 › pg_hba.conf and reload
Edit, then reload
Add a host replication line, save, and reload to apply without restart.
Example pg_hba.conf line
host    replication     postgres        192.168.1.0/24          md5
Reload example: pg_ctl reload or sudo systemctl reload postgresql@12-main depending on your platform.
Process checklist
  • Back up current pg_hba.conf before editing.
  • Add precise host/CIDR, avoid 0.0.0.0/0 for replication.
  • Reload Postgres to apply the change immediately.
  • Test a replication-capable connection before running pg_basebackup.
Common mistake

Forgetting to reload after changing pg_hba.conf causes confusing authentication errors during backup attempts.
