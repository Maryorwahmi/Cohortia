Module 5 › Chapter 5.5 › Key Concepts — Checklist
Configure replication
Set wal_level and add replication pg_hba entries, then reload the server.
Prepare destination
Use timestamped directories and set ownership so pg_basebackup can write files.
Include WALs
Prefer -X stream so WALs generated during the backup are captured and included.
Final takeaway
A reliable physical backup requires correct server configuration, careful destination management, and preserved WALs to be useful for recovery.
