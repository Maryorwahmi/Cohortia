Learning Objectives
Skills and checks to perform safe, restorable base backups
Bloom: Learn → Understand → Apply → Master
01
Execute pg_basebackup
Run pg_basebackup with appropriate destination and progress flags, ensuring the destination is empty and writable. This skill matters because a correct invocation produces a usable physical snapshot for PITR.
VERIFIED COMPETENCY MILESTONE
02
Understand output formats
Distinguish plain directory output from tar archives and pick the one that fits restore and transport needs. A tar archive is portable; plain is ready to restore into PGDATA.
VERIFIED COMPETENCY MILESTONE
03
Use WAL options
Choose -X stream to include WAL segments during the backup, or -X fetch to retrieve them afterwards. Including WALs avoids recovery gaps.
VERIFIED COMPETENCY MILESTONE
04
Validate and inspect backups
List backup contents, verify base.backup and pg_wal entries, and test restoring to ensure the backup is usable.
VERIFIED COMPETENCY MILESTONE
