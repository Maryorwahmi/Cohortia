Module 5 › Chapter 5.5 › Role of checkpoints
What is a checkpoint?
A point when dirty pages are flushed to disk and the WAL records the consistent state.
  • Ensures the backup starts from a known consistent state.
  • pg_basebackup waits for the checkpoint to complete before copying files.
  • Check the restore chain: checkpoint + WALs = recoverable backup.
Practical note
On busy systems, a checkpoint can cause additional I/O; schedule backups when checkpoints will not impact peak workloads.
Key Takeaway

Checkpoints align on-disk files with WAL records; both are necessary to make a base backup recoverable.
