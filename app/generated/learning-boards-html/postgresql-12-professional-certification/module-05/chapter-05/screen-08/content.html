Module 5 › Chapter 5.5 › Plain vs Tar formats
Plain (default)
Creates directory structure identical to PGDATA for direct restore.
  • Restore: copy files into PGDATA and start server.
  • Use when you have the same filesystem layout and want immediate file-level access.
Tar (-F tar)
Produces a single tar archive file, which is convenient for transport and compression.
  • Good for moving backups between sites or storing in object storage.
  • Requires extraction into an empty PGDATA target for restore.
pg_basebackup -h localhost -U postgres -D /mnt/pg_backups/base_backup_20210930.tar -F tar -P
