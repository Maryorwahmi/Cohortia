Module 5 › Chapter 5.4 › pg_wal & Segments
pg_wal contents
Active WAL segment files created as the server runs. Completed segments are candidates for archiving.
Segment naming
Files are named by timeline and position — long hex sequences that identify order.
Capacity risk
If archiving fails, pg_wal retains segments and can fill disk, halting the server eventually.
Operational checks
  • Monitor pg_wal directory size and file count.
  • Review PostgreSQL logs for archive_command failures.
  • Ensure archive target has adequate free space and permissions.
Common mistake
Archiving into a directory inside PGDATA can be blocked or cause confusing behavior; always use external storage.
Key Takeaway

Keep pg_wal small by reliably archiving completed segments to an external, permissioned store.
