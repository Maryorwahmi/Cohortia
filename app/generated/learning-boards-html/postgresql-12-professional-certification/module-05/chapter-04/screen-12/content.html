Module 5 › Chapter 5.4 › Hands-on Activity
Steps to perform
  1. Create an external archive directory and set ownership to postgres.
  2. Edit postgresql.conf: set wal_level, archive_mode, and archive_command.
  3. Restart PostgreSQL, generate activity, and verify files in the archive.
Manual test tip
Run your archive_command as the postgres user to confirm it returns zero and copies the file where expected.
Commands (illustrative)
sudo mkdir -p /mnt/pg_wal_archive sudo chown -R postgres:postgres /mnt/pg_wal_archive # Edit postgresql.conf: # wal_level = replica # archive_mode = on # archive_command = 'test ! -f /mnt/pg_wal_archive/%f && cp %p /mnt/pg_wal_archive/%f' sudo systemctl restart postgresql@12-main # Generate activity with psql and then: ls -l /mnt/pg_wal_archive
If no WAL files appear, check PostgreSQL logs for archive_command errors and confirm path and permissions.
