Module 5 › Chapter 5.4 › Key Concepts
Physical Backup
A binary copy of PGDATA that serves as the starting point for recovery.
WAL
Write‑Ahead Log records every change first so the server can replay to a consistent state.
WAL Archiving
archive_mode and archive_command copy completed WAL segments to external storage for PITR.
Summary takeaway
A reliable recovery chain needs a recent base backup and a continuous, verified WAL archive; test and monitor both regularly.
