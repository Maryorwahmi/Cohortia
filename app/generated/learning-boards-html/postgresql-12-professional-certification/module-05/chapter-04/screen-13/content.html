Module 5 › Chapter 5.4 › Mistakes & Monitoring
Common mistakes
  • Archiving into a path inside PGDATA.
  • archive_command overwriting files or returning incorrect exit codes.
  • Insufficient permissions or space on the archive target.
Consequence
Failed archiving causes retries and pg_wal growth that can halt the server when disk fills.
Monitoring checklist
  • Alert on unexpected growth of pg_wal directory.
  • Alert on archive_command errors found in PostgreSQL logs.
  • Regularly verify archived WAL file presence and integrity.
Key Takeaway

Monitoring and testing archive_command as the postgres user prevent blocked archiving and ensure a usable PITR chain.
