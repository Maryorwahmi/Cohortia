Module 5 › Chapter 5.4 › WAL Archiving Flow
Steps
  1. Transaction writes are recorded in WAL segments.
  2. When a segment is complete, PostgreSQL runs archive_command with %p and %f.
  3. If the command succeeds (exit 0), the segment is archived; if not, PostgreSQL retries.
Operational tip
Monitor both archive directory contents and database logs for archive_command failures to avoid pg_wal backlogs.
Concrete scenario
During heavy DML, multiple segments complete quickly. A robust archive_command copies them to external storage; if the external network is slow, archive_command must still indicate failure clearly so the DBA can intervene before disk fills.
Key Takeaway

Archiving is a lifecycle: complete segment → copy → confirm success. Reliability and monitoring keep the pipeline healthy.
