Module 5 › Chapter 5.3 › Verification & troubleshooting
Quick verification
psql -U postgres -d mydb -c "\dt" psql -U postgres -d mydb -c "SELECT COUNT(*) FROM products;" psql -U postgres -d postgres -c "\du"
Key Takeaway
Verification queries are quick and provide confidence that restores succeeded.
Common errors & fixes
  • table already exists → use --clean or drop/recreate database
  • permission denied → ensure restoring role has create/drop privileges
  • out of disk space → provision more disk and retry
Pro tip
Always run a full test restore on a staging server before a production recovery to exercise the entire workflow and detect environmental gaps.
