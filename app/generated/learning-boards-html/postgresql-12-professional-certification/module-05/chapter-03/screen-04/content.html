Module 5 › Chapter 5.3 › Which tool to use
Definition

psql and pg_restore: what they do

psql executes plain SQL scripts. pg_restore reads archive formats and reconstructs objects selectively or in parallel.

When to use psql
Plain-text dumps from pg_dump or pg_dumpall; you replay SQL statements directly.
When to use pg_restore
Custom, tar, or directory format backups created with -F c, -F t, or -F d.
Key Takeaway

Match tool to backup format: psql for SQL scripts, pg_restore for archives with selective and parallel features.

Terminal examples
createdb -U postgres mydb_restore psql -U postgres -d mydb_restore -f /tmp/mydb_dump.sql # For archive formats createdb -U postgres mydb_restore pg_restore -U postgres -d mydb_restore /tmp/mydb.custom
Common misconception
psql cannot unpack custom/tar/directory archive formats; those require pg_restore.
Check your backup format
If unsure, try pg_restore -l on the file. If it lists objects, use pg_restore; otherwise, psql can run the SQL file.
