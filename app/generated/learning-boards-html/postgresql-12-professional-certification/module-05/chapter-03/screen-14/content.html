Module 5 › Chapter 5.3 › Key Concepts
psql client
Executes plain-text SQL backups created by pg_dump or pg_dumpall.
pg_restore utility
Restores backups in custom, tar, and directory formats with selective options.
--clean option
Drops existing objects before recreating them to prevent conflicts during restore.
Summary takeaway
Match the restore tool to the backup format, plan whether to drop or recreate objects, and verify with quick queries. Test restores on staging before production recovery.
