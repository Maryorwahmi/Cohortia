Module 5 › Chapter 5.3 › Selective restoration
Quick example
# Create database createdb -U postgres sales_db_restore_selective # Restore only the products table pg_restore -U postgres -d sales_db_restore_selective --table=products /tmp/sales_db_custom.dump # Verify psql -U postgres -d sales_db_restore_selective -c "\dt" psql -U postgres -d sales_db_restore_selective -c "SELECT COUNT(*) FROM products;"
When to use
Recover a single corrupted table, or move only the data needed for a patch or test environment.
Use the contents list
For fine-grained control, list archive contents and build a use-list that pg_restore can apply.
pg_restore -l /tmp/sales_db_custom.dump
Misconception
Restoring a table alone may miss dependent objects. Check and include constraints, indexes, and related sequences if needed.
