Module 5 › Chapter 5.3 › Learning Objectives
Objective focus
These objectives turn commands into safe procedures. You will run global restores, create and drop databases, and verify restored data counts with quick queries.
Restore pg_dumpall global objects
Execute the cluster-level SQL to recreate users and tablespaces. Run as a superuser against the postgres database.
VERIFIED COMPETENCY MILESTONE
Verify with queries
Use SELECT COUNT(*) and \dt to confirm expected objects and row counts after restore.
VERIFIED COMPETENCY MILESTONE
Risk reduction
Practice stop-application and disconnect steps before full restores. Test on staging to reduce surprises in production.
Handle permissions and disk space
Ensure the restoring user can create databases, roles, and write files; confirm enough disk space before starting.
VERIFIED COMPETENCY MILESTONE
Drop-and-create vs. --clean/--create
Learn when to drop databases first and when to let pg_restore manage recreation with --create and --clean options.
VERIFIED COMPETENCY MILESTONE
