Module 5 › Chapter 5.3 › Hands-on activity
Activity steps
Scenario 1: Plain-text full restore
dropdb -U postgres sales_db createdb -U postgres sales_db_restore_plain psql -U postgres -d sales_db_restore_plain -f /tmp/sales_db_plain.sql Verify: SELECT COUNT(*) FROM products;
Scenario 2: Custom format with --clean/--create
pg_restore -U postgres --clean --create -d sales_db_restore_custom /tmp/sales_db_custom.dump Verify: SELECT COUNT(*) FROM customers;
Scenario 3: Selective table restore
createdb -U postgres sales_db_restore_selective pg_restore -U postgres -d sales_db_restore_selective --table=products /tmp/sales_db_custom.dump Verify: \dt and SELECT COUNT(*) FROM products;
Scenario 4: List and use-list
pg_restore -l /tmp/sales_db_custom.dump > mylist.txt Edit mylist.txt to include IDs you want, then: pg_restore -U postgres -d mydb --use-list=mylist.txt /tmp/sales_db_custom.dump
Verification checklist
  • Confirm tables exist (\dt)
  • Run row counts on key tables
  • Check roles and tablespaces
Reflection
When did a selective restore save time? When did a full restore make more sense? Note your answers for later discussion.
