Module 5 › Chapter 5.3 › Global restore
Definition

A pg_dumpall global dump contains cluster-level SQL for roles, tablespaces, and the CREATE DATABASE statements for every database in the cluster.

Recommended command
psql -U postgres -f /tmp/full_cluster_global.sql postgres
Why stop applications first?
Active sessions can block role creation or interfere with tablespace operations, causing the restore to fail or be inconsistent.
Verification
After the script runs, confirm global state and one sample database.
# List roles psql -U postgres -d postgres -c "\du" # Check a restored database psql -U postgres -d example_db -c "SELECT COUNT(*) FROM products;"
Misconception check
Global restore is not limited to single-database objects. Roles and tablespaces must be applied in the cluster context before restoring individual databases.
