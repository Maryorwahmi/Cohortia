Module 5 › Chapter 5.3 › pg_restore basics
Full restore example
# Create database createdb -U postgres sales_db_restore # Restore from custom format pg_restore -U postgres -d sales_db_restore /tmp/sales_db_custom.dump # Or let pg_restore create the DB pg_restore -U postgres --clean --create -d sales_db_restore /tmp/sales_db_custom.dump
When to use --create
Use --create when the archive includes a CREATE DATABASE entry and you want pg_restore to handle creation for you.
Options at a glance
  • --clean: drop objects before recreating them to avoid conflicts.
  • --create: create the database from the archive's metadata.
  • --table/--schema: restrict restoration to specific objects.
  • --jobs=N: run parallel workers to speed up restore.
Misconception
Using --create with an existing database name may not drop the prior database. Understand whether you need to drop first or rely on pg_restore's options.
