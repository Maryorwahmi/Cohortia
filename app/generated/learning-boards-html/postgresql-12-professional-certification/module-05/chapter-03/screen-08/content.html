Module 5 › Chapter 5.3 › --clean and --create
Option: --clean

When you pass --clean, pg_restore drops objects it will recreate. This prevents conflicts but requires appropriate privileges.

Example: pg_restore -U postgres --clean -d mydb /tmp/mybackup.custom
Warning
--clean will remove objects. Ensure you don't accidentally delete data you need.
Option: --create

--create tells pg_restore to create the database before restoring its contents, using the archive's metadata when available.

Example: pg_restore -U postgres --create -d mydb /tmp/mybackup.custom
Pro tip
Combine --clean and --create to drop existing objects and create the database if the archive includes creation metadata.
