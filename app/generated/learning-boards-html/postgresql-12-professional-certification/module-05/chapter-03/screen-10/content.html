Module 5 › Chapter 5.3 › Listing archive contents
List the archive
pg_restore -l /tmp/mybackup.custom > content.list # Edit content.list to keep only the IDs you want # Then restore using the edited list pg_restore -U postgres -d mydb --use-list=content.list /tmp/mybackup.custom
Why use a list
A list gives deterministic control over exactly which objects are restored, including object IDs and order.
Best practice

Always test your edited list on staging. Confirm dependent objects such as constraints and sequences are included or restored separately if needed.

Misconception
A list doesn't automatically resolve object dependencies for you. Verify and include related objects manually when necessary.
