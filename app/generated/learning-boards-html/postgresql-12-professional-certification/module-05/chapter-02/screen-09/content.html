Module 05 › Chapter 5.2 › Limits of pg_dump
Definition

Global objects are not in pg_dump

  • Roles and users (CREATE ROLE statements)
  • Tablespaces (CREATE TABLESPACE statements)
  • Database definitions (CREATE DATABASE statements)

pg_dump focuses on a single database; missing globals must be captured separately for full recovery.

pg_dumpall Example
pg_dumpall -U postgres > full_cluster_backup.sql
This single plain-text file includes global CREATE ROLE and CREATE TABLESPACE statements followed by per-database dumps.
Why it matters

Without a pg_dumpall export, restores may miss critical roles and tablespace configurations, causing operational errors after recovery.
