Logical Backups with pg_dump and pg_dumpall

Create portable SQL scripts or archive formats that let you restore, inspect, and selectively recover database objects.

In this lesson

Learn formats, options, and cluster-level backups, plus practical storage and test guidance.

Coming up

Hands-on commands for plain, custom, and directory backups and a demonstration of pg_dumpall for global objects.

Explore Key Topics
pg_dump
Back up a single database to script or archive.
Formats
Plain, custom, tar, directory — tradeoffs of readability vs parallelism.
pg_dumpall
Capture roles and tablespaces for full instance recovery.
Visual concept
A single database backup is portable and scriptable; cluster backups capture global objects. Use the archive formats when you need selective restore or parallelism.
Quick commands
pg_dump -U postgres mydatabase > mydatabase_backup.sql
pg_dump -U postgres -F c -f mydb.custom mydatabase
pg_dumpall -U postgres > full_cluster.sql
Note: Always store backups off the primary server and test restores in a separate environment.
