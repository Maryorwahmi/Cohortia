Module 05 › Chapter 5.2 › Practical Objectives

Practical Skills

Execute, store, and validate backups with repeatable steps.

Storage & Permissions

Keep backup files on separate disks or remote storage and set strict permissions to limit access.

Test Restores

Regularly restore backups to a test server to ensure files are usable and processes are correct.

Combine Tools

Use per-database pg_dump archives with a pg_dumpall global dump for full recovery capability.
