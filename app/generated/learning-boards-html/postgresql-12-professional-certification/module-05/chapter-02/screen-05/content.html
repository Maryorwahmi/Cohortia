Plain-text SQL dump

A readable script suitable for small databases and audits.

pg_dump -U postgres mydatabase > mydatabase_backup.sql
Check the file to see CREATE TABLE and INSERT or COPY statements that recreate schema and data.
Key points
  • -U specifies the connection user; authentication still applies.
  • Redirection writes standard output to a file you can restore with psql.
  • pg_dump backs up one database only; global objects are not included.
Pro tip

Use plain format for small test databases and audits, not for large production restores.
