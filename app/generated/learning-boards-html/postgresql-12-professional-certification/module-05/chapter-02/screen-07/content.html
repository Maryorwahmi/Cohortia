Module 05 › Chapter 5.2 › Custom & Directory
Create
pg_dump -U postgres -F c -f /tmp/sales_db_custom.dump sales_db
pg_dump -U postgres -F d -f /tmp/sales_db_dir sales_db
Custom is a single compressed archive. Directory is a folder structure with separate files for each table and a TOC file.
Restore
pg_restore -U postgres -d targetdb /tmp/sales_db_custom.dump
pg_restore -U postgres -j 4 -d targetdb /tmp/sales_db_dir
Use -j with custom or directory formats to restore in parallel. Test restores to ensure dependencies resolve in your target environment.
Key Takeaway

Custom or directory formats give you the flexibility and speed needed for large datasets and selective recovery.

Pitfall

Expect lower wall-clock time with jobs but ensure your storage I/O can sustain parallel operations.
