Comparison

Plain vs Custom vs Tar vs Directory

Plain (default)
SQL script, human-readable, easy to inspect. Use for small DBs or audits.
Custom (-F c)
Compressed archive, flexible for selective restore with pg_restore and parallel restore support.
Tar (-F t)
Tar archive with separate files per object; somewhat less flexible than custom but usable with pg_restore.
Directory (-F d)
Directory with one file per table and a TOC; excellent for parallel dumps and restores using --jobs.
When to pick custom

Choose custom for selective restore, compressed storage, and good cross-version behavior with pg_restore tools.

When to pick directory

Use directory for very large databases where parallelism across many jobs significantly speeds up dumps and restores.
