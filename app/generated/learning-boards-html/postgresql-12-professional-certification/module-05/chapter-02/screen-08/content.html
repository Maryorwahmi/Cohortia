Module 05 › Chapter 5.2 › pg_dump Options
Options
  • --schema-only: dump DDL only.
  • --data-only: dump table data without DDL.
  • --clean: include DROP statements before CREATE.
  • --create: include CREATE DATABASE for full recreate.
  • --inserts / --column-inserts: dump using INSERT statements.
  • --exclude-table / --exclude-schema: omit patterns from the dump.
Examples
pg_dump -U postgres --schema-only sales_db > sales_schema.sql
pg_dump -U postgres --data-only sales_db > sales_data.sql
pg_dump -U postgres --exclude-table=logs_* -F c -f /tmp/sales_custom.dump sales_db
Test schema-only restore to ensure procedural code and extensions are available before loading data-only dumps.
Pro tip

When migrating schema, restore schema-only first, verify extensions and privileges, then load data-only dumps.

Misconception

Using --inserts slows restore significantly; prefer COPY where performance matters.
