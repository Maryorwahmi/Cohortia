Module 05 › Chapter 5.2 › Key Concepts
pg_dump
Back up a single database to a script or archive for selective restores.
pg_dumpall
Exports roles, tablespaces, and database definitions for full instance recovery.
Formats
Plain, custom, tar, directory — balance readability, flexibility, and parallelism.
Takeaway
Combine per-database archives with a pg_dumpall export, secure and store backups off-host, and test restores regularly.
