Module 3 › Chapter 3.4 › SCRAM Configuration
Server-side steps
1) Ensure postgresql.conf contains password_encryption = 'scram-sha-256'. 2) ALTER USER to set a new password so PostgreSQL records a SCRAM hash. 3) Update pg_hba.conf to require scram-sha-256 for the intended host entries and reload.
-- Ensure server uses SCRAM by default
-- in postgresql.conf: password_encryption = 'scram-sha-256'

-- Create role or reset password to produce SCRAM hash
CREATE ROLE web_app_user WITH LOGIN PASSWORD 'YourWebAppSecurePass!';
-- or
ALTER USER web_app_user PASSWORD 'YourWebAppSecurePass!';

-- Reload config after pg_hba.conf edits
SELECT pg_reload_conf();
Client compatibility
Before enforcing scram-sha-256, verify client libraries support SCRAM. Older libpq or drivers may need upgrades. Test connections from your application environment with an allowed rule and confirm success.
Key Takeaway

You must set user passwords after enabling SCRAM; simply changing the server default does not re-hash existing passwords.
