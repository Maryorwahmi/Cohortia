Avoid trust
Do not use trust for networked hosts in production; it grants passwordless access.
Reload not restart
Use pg_ctl reload or SELECT pg_reload_conf(); to apply pg_hba.conf changes without dropping connections.
Test both allow & deny
Validate successful logins and confirm explicitly rejected attempts behave as intended.
Final takeaway

Rule specificity, safe edits, and testing are the core practices that keep authentication secure and reliable.
