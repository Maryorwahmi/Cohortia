Hands-on outcome mapping
Action, verify, and rollback plan for safe edits.
Backup
Copy pg_hba.conf before edits. If something goes wrong, restore the copy and reload.
Add specific rules first
Place app_user hostssl scram-sha-256 entry before broader rules to ensure it matches.
Test and reload
Use SELECT pg_reload_conf(); then run psql tests for success and expected denials.
Verification checklist
  • Local peer connection as OS user postgres succeeds for administrative tasks.
  • Remote application connection with SSL and scram-sha-256 succeeds only for specified IPs.
  • Other remote attempts are explicitly rejected by a later rule.
Keep one recovery route such as a local superuser peer or local trust entry until you confirm all remote rules work.
