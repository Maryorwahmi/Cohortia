Module 3 › Chapter 3.4 › Safe Editing
Step-by-step
  1. Backup: cp pg_hba.conf pg_hba.conf.bak
  2. Edit: add specific allow rules above general ones
  3. Reload: pg_ctl reload -D /path/to/data or SELECT pg_reload_conf();
  4. Test: psql local and remote attempts to confirm expected results
  5. Cleanup: remove temporary recovery rules
Testing examples
# Test local peer as postgres
psql -U postgres -d postgres

# Test remote SCRAM (ensure SSL configured for hostssl)
psql -h <your_db_host> -U web_app_user -d app_db

# Test a denied connection (should fail)
psql -h <your_db_host> -U postgres -d app_db
Common mistake

Editing remotely without a recovery entry can lock you out. Keep a local peer or temporary superuser trust rule until verified.
