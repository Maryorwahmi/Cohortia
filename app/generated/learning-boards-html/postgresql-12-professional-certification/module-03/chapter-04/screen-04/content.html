Module 3 › Chapter 3.4 › What is pg_hba.conf
Core definition

pg_hba.conf contains rules that map connection attempts to authentication methods based on type, database, user, and address. The first matching rule is applied.

Common file paths
Examples include data directory paths such as /var/lib/pgsql/12/data or /etc/postgresql/12/main. Confirm with your server's configuration.
Reload vs Restart
Use pg_ctl reload or SELECT pg_reload_conf(); to apply pg_hba.conf changes without dropping existing connections.
Concrete example: locate & reload
# Find the data directory from the server process (example)
ps aux | grep postgres
# Backup before edit
cp /var/lib/pgsql/12/data/pg_hba.conf /var/lib/pgsql/12/data/pg_hba.conf.bak
# Reload config after edit
pg_ctl reload -D /var/lib/pgsql/12/data
-- or as SQL
SELECT pg_reload_conf();
Key Takeaway

Always confirm the file location and create a backup before editing. Reload to apply authentication changes safely.
