pg_hba.conf
Host-based authentication rules that control connection authentication.
Entry fields
TYPE, DATABASE, USER, ADDRESS, METHOD define scope and method for each rule.
scram-sha-256
Preferred secure password method; requires SCRAM-stored passwords and client support.
Takeaway

Order rules carefully, back up before editing, reload the configuration, and test both allowed and denied connections.
