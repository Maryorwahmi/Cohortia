Module 3 › Chapter 3.4 › Authentication Methods
Method comparison
trust
No password required
Use only for tightly controlled local development. Never place trust for remote hosts in production.
peer / ident
OS-based verification
Peer is for local Unix sockets; ident works over TCP with an ident server. Good for local admin tasks.
md5
MD5 hashed passwords
Widely supported but cryptographically weaker; use only when legacy clients require it.
scram-sha-256
Recommended modern password auth
SCRAM provides salted challenge-response authentication and stronger protection than MD5. Ensure users have SCRAM-stored passwords.
Concrete scenario
For an externally reachable application user, require hostssl and scram-sha-256 from specific IPs. For local administration, allow peer for the postgres OS user.
Pro tip

When migrating from md5 to scram-sha-256, reset user passwords or ensure password_encryption is set so passwords are stored for SCRAM.
