pg_hba.conf snippet
# TYPE  DATABASE    USER            ADDRESS             METHOD

# Rule 1: Local admin via peer
local   all         postgres                            peer

# Rule 2: Remote app user via SSL + SCRAM-SHA-256 from a single IP
hostssl app_db      web_app_user    192.168.1.10/32     scram-sha-256

# Rule 3: Deny all other remote attempts to app_db
host    app_db      all             0.0.0.0/0           reject
This pattern narrows access, enforces encryption for remote app connections, and provides a safe administrative fallback.
Rationale & checks
  • Peer keeps local admin convenient and secure by relying on OS identity.
  • hostssl + scram-sha-256 enforces encrypted, strong password auth for the app.
  • Reject entry ensures no other remote host can connect to app_db.
Key Takeaway

Specific allow rules plus explicit rejects form a safe ordering strategy when protecting an application database.
