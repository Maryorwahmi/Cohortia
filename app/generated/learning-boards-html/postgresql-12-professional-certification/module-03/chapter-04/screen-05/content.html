Module 3 › Chapter 3.4 › Entry Structure
Fields at a glance
  • TYPE — local, host, hostssl, hostnossl
  • DATABASE — specific name, all, or sameuser
  • USER — role names, all, or samegroup
  • ADDRESS — client IP or CIDR (omitted for local)
  • METHOD — trust, peer, md5, scram-sha-256, etc.
Quick mnemonic
Think T-D-U-A-M: Type, Database, User, Address, Method — read left to right when composing a rule.
Annotated example
# Enforce SSL + SCRAM for a single app IP
hostssl  my_app_db   app_user   192.168.1.10/32   scram-sha-256

# Local admin via OS user mapping
local    all         postgres                      peer

# Reject other remote attempts to app_db
host     app_db      all         0.0.0.0/0       reject
Common mistake
Placing a permissive rule like host all all 0.0.0.0/0 trust above specific entries defeats more secure rules below.
Check
After a change, reload and test both allowed and denied connections to verify behavior.
