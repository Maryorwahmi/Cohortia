Lab Walkthrough

15-minute interactive plan

Part 1 — Attributes table
List each attribute and the associated risk for quick reference during the lab.
Part 2 — CREATE / ALTER
Apply LOGIN, NOLOGIN, VALID UNTIL, and administrative flags and observe behavior.
Part 3 — Inheritance demo
Family-tree analogy: group role as parent, users as children; toggle NOINHERIT to require SET ROLE.
Part 4 — GRANT / REVOKE
Verify membership effects with failed-then-successful queries and record results.
Finish by cleaning up roles and recording any changes to production-like policies as part of a post-lab review. This solidifies both the commands and the security rationale behind each choice.
