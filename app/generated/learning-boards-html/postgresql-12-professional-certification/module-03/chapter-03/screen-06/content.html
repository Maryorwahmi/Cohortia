Process Flow

LOGIN, NOLOGIN, VALID UNTIL

A repeatable process to build identities and privileges safely.

1
Create NOLOGIN group roles
Define shared privileges centrally for teams or services.
2
Create LOGIN accounts
Assign passwords and set VALID UNTIL for temporary accounts.
3
GRANT group TO login
Members inherit group privileges, unless NOINHERIT is set.
Details & Example
Example commands for a temporary account:
CREATE ROLE temp_user WITH LOGIN PASSWORD 'TempPass' VALID UNTIL '2024-12-01';
CREATE ROLE reporting_group WITH NOLOGIN;
GRANT SELECT ON public.sensitive_data TO reporting_group;
GRANT reporting_group TO temp_user;
Misconception: setting VALID UNTIL is a substitute for revoking membership — it only expires the password, not the membership. Use both when stricter removal is needed.
Key Takeaway

Design identity and privilege separately: groups for privileges, logins for access.
