Core Concept

What are role attributes?

Attributes give roles specific operational capabilities; set them at CREATE ROLE or ALTER ROLE time.

SUPERUSER — bypasses permission checks and RLS. Use very sparingly.
CREATEDB / CREATEROLE — allow creating databases or roles, for higher-tier administration.
REPLICATION — needed for replication connections and managing slots.
NOLOGIN — role acts as a group; cannot be used to connect.
Key Takeaway

Treat attributes as risk-bearing choices: match each attribute to the minimum capability required for the job.

Definition
Attribute
What it does
  • SUPERUSER: bypasses permissions and RLS.
  • CREATEDB: create databases.
  • CREATEROLE: manage roles.
  • REPLICATION: replication connections and slots.
Management
Why it matters
  • Attributes determine what actions are possible for the role.
  • Assign only what is necessary to reduce attack surface.
  • Use NOLOGIN for group roles to avoid direct logins.
Example
A monitoring agent might need REPLICATION but not CREATEDB or SUPERUSER. Provide only replication access.
Common mistake
Granting SUPERUSER by default to convenience accounts because it appears to 'fix' permission errors.
