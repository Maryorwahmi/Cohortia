Definition

Role inheritance and INHERIT

Membership grants a role the privileges of its parent role when INHERIT is present.

Behavior: A member automatically gains privileges from roles it belongs to.
Example: Grant read_only_analyst to analyst_john → analyst_john can SELECT.
Audit: Changing the group changes members instantly.
Key Takeaway

Use inheritance to centralize grants; use membership to manage who receives them.

Annotated Example
Group role:
CREATE ROLE read_only_analyst; GRANT SELECT ON public.table1 TO read_only_analyst;
Grant to user:
GRANT read_only_analyst TO analyst_john;
Misconception check: membership is not a copy. If you revoke SELECT from the group, members lose it immediately. If you REVOKE membership, access is removed without touching other privileges.
Example
Use a department role to hold shared schema privileges; add users to that role for instant access.
Pro Tip
Keep sensitive groups small and use NOINHERIT for roles that should require explicit elevation.
