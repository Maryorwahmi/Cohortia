Module 3 › Chapter 3.2 › Learning Objectives
01
Understand object-level privileges

Describe permissions like SELECT, EXECUTE and their target objects. Knowing these reduces over-permission risks.

Verified Competency Milestone
02
Use GRANT to assign permissions

Write GRANT statements for specific tables, schemas or all tables in a schema and know when to use ALTER DEFAULT PRIVILEGES.

Verified Competency Milestone
03
Revoke privileges safely

Use REVOKE carefully, understand inheritance and dependent grants to avoid unexpected access removal.

Verified Competency Milestone
04
Delegate and apply least privilege

Explain WITH GRANT OPTION and WITH ADMIN OPTION and assign only needed permissions to reduce risk.

Verified Competency Milestone
