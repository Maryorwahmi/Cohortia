Process Flow › ALL TABLES & Defaults
Step-by-step
1. Grant on existing tables: GRANT SELECT ON ALL TABLES IN SCHEMA app_data TO reporting_user;
2. Set defaults for future objects: ALTER DEFAULT PRIVILEGES FOR ROLE deployer IN SCHEMA app_data GRANT SELECT ON TABLES TO reporting_user;
3. Verify by creating a table as the deployer role and checking privileges.
Remember: ALTER DEFAULT PRIVILEGES applies to objects created by a specific role. If objects are created by different roles, set defaults for each creator role.
Example
GRANT SELECT ON ALL TABLES IN SCHEMA app_data TO reporting_user;

ALTER DEFAULT PRIVILEGES FOR ROLE deployer IN SCHEMA app_data
  GRANT SELECT ON TABLES TO reporting_user;
Pitfall
ALL TABLES affects existing tables only. Always use ALTER DEFAULT PRIVILEGES for future objects.
