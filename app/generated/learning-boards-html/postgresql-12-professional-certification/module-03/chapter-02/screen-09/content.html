Definition › WITH ADMIN OPTION
What it does

Granting a role WITH ADMIN OPTION lets the grantee add or remove other members of that role and to SET ROLE to use it. The grantee effectively becomes an administrator for that role's membership.

Use this option only for trusted administrators and prefer narrow admin roles to reduce blast radius in case of misuse.
Example
GRANT analytics_team TO analyst_john WITH ADMIN OPTION; Now analyst_john can add or remove members of analytics_team and set role to adopt its privileges.
Tip
Prefer a separate admin role with limited scope if you need delegated membership management for many users.
