Comparison › Common Mistakes
ALL PRIVILEGES shortcut
Dangerous: often grants more than needed. Use explicit privilege lists instead.
Forgetting inheritance
REVOKE won't remove privileges inherited via parent roles. Check memberships first.
Schema vs table
USAGE on a schema is needed to reference objects; it doesn't grant table data access by itself.
Practical checklist
  • Map roles to job functions and minimal privileges.
  • Grant schema USAGE plus explicit table privileges when needed.
  • Use ALTER DEFAULT PRIVILEGES for future objects.
  • Always verify by testing as the target role.
