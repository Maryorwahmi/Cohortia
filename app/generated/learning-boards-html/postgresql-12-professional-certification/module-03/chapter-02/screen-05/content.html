Process Flow › GRANT Syntax
Common GRANT forms
-- Grant SELECT on a table to a role
GRANT SELECT ON TABLE app_data.products TO reporting_user;

-- Grant multiple privileges to an app role
GRANT SELECT, INSERT, UPDATE, DELETE ON app_data.orders TO app_backend;

-- Grant SELECT on all existing tables in a schema
GRANT SELECT ON ALL TABLES IN SCHEMA app_data TO reporting_user;
Note: these examples affect existing objects. To cover future tables, use ALTER DEFAULT PRIVILEGES.
Practical tips
  • Always qualify objects with schema to avoid ambiguous grants.
  • Grant schema USAGE before expecting table access inside that schema.
  • Prefer explicit privilege lists over ALL PRIVILEGES to avoid accidental admin rights.
Check your understanding

After granting, connect as the target role and attempt the action to verify permissions behave as intended.
