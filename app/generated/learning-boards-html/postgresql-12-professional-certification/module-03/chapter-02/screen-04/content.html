Core Concept › Object-level Privileges
What they are

Object-level privileges are explicit grants that allow a role to perform certain actions on a particular object type. They are the building blocks of secure access control in PostgreSQL.

  • Tables: SELECT, INSERT, UPDATE, DELETE, TRUNCATE.
  • Schemas: CREATE, USAGE.
  • Databases: CONNECT, CREATE, TEMPORARY.
  • Sequences: USAGE, UPDATE.
  • Functions: EXECUTE.
Key Takeaway

Map each role to the smallest set of privileges needed; prefer narrow grants over ALL PRIVILEGES.

Analogy & Example
Analogy
Think of the database as a building, schemas as rooms, and tables as cabinets. Give keys only to the cabinets a person needs.
Concrete example
Grant SELECT to a reporting role on sales tables only instead of ALL PRIVILEGES on the database.
Common mistake
Using ALL PRIVILEGES for convenience. That often grants create, drop, or administrative rights that are unnecessary for day-to-day tasks.
