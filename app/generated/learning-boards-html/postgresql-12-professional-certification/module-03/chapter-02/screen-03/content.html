Module 3 › Chapter 3.2 › Applied Skills
Skills you will practice
  • Grant USAGE on a schema, then table-level CRUD for an application role.
  • Grant SELECT to a reporting role and verify that only reads are allowed.
  • Use ALTER DEFAULT PRIVILEGES to ensure future tables inherit SELECT for a role.
  • Grant a privilege WITH GRANT OPTION and observe downstream grants and revocation behavior.
Mnemonic
Database → Schema → Table
Think of permission flow from broad to narrow; grant the least necessary at the narrowest level.
