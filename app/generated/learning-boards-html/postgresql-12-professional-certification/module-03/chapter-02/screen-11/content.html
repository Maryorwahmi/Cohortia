Process Flow › Verification
Verification steps
  1. List explicit grants with catalog queries or psql meta-commands.
  2. Inspect role memberships to identify inherited privileges.
  3. Open a session as the role and run allowed operations.
  4. Attempt denied operations to confirm they fail as expected.
Example checks
Connect as reporting_user and run SELECT against app_data.products to confirm read access.
Attempt INSERT as reporting_user to confirm write is denied.
After revoking, retest to ensure access is removed and verify no parent role re-granted it.
Key Takeaway
Testing as the role is the only reliable way to observe effective privileges.
