Process Flow

CREATE ROLE examples

Create group roles without LOGIN, then create login roles and make them members. Always use strong passwords and explicit attributes.

Code examples
-- Create a group role (no login)
CREATE ROLE analytics_team;

-- Create a login user and add to analytics_team
CREATE ROLE analyst_john WITH LOGIN PASSWORD 'YourSecurePassword123!' VALID UNTIL 'YYYY-MM-DD' IN ROLE analytics_team;

-- Create an application user
CREATE ROLE app_user WITH LOGIN PASSWORD 'strong_password_here';
Notes
  • Prefer explicit CREATE ROLE WITH LOGIN rather than relying on CREATE USER aliasing.
  • Use IN ROLE or GRANT to add membership after creation if preferred.
Practical cards
Common mistake
Using weak passwords or reusing passwords across roles increases systemic risk.
Pro tip
Create group roles first, grant privileges once, and add members to avoid duplicate grants.
Key Takeaway

Write clear CREATE ROLE statements with explicit attributes; verify outcomes by listing roles and attributes.
