Using VALID UNTIL for temporary access

Set an expiry date on a role's password to limit access automatically and reduce lingering accounts.

Step 1
Create with expiry
Include VALID UNTIL in CREATE ROLE to set the expiry timestamp at creation time.
Step 2
Monitor expiry
Track expiration dates so you can rotate or re-provision access before it becomes disruptive.
Key Takeaway

VALID UNTIL automates time-bounds for passwords; combine it with runbook monitoring to avoid unexpected outages.

Example
CREATE ROLE analyst_john WITH LOGIN PASSWORD 'YourSecurePassword123!' VALID UNTIL 'YYYY-MM-DD';
