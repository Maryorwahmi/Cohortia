Analytics team lab

Follow the template to create analytics_team, then analyst_john as a login member with an expiry, verify, and rotate the password.

Starter commands
-- Create the analytics team role (no login)
CREATE ROLE analytics_team;

-- Create a login user and add to analytics_team
CREATE ROLE analyst_john WITH LOGIN PASSWORD 'YourSecurePassword123!' VALID UNTIL 'YYYY-MM-DD' IN ROLE analytics_team;

-- Verify roles
\du

-- Rotate analyst_john's password
ALTER ROLE analyst_john WITH PASSWORD 'NewSecurePassword456!';

-- To lock quickly
ALTER ROLE analyst_john NOLOGIN;
Checks and tips
Verify
Confirm analytics_team has NOLOGIN and analyst_john has LOGIN and the correct VALID UNTIL date.
Common mistake
Using weak temporary passwords or forgetting to set VALID UNTIL for temporary users.
Key Takeaway

Follow the create-verify-rotate sequence and use NOLOGIN for quick containment when necessary.
