Test plan checklist
  • 1) Create roles representing typical users and managers, grant them minimal privileges, then test SELECT visibility.
  • 2) Try INSERT and UPDATE that violate WITH CHECK; confirm database rejects them.
  • 3) Test a role with BYPASSRLS to observe full visibility, then remove BYPASSRLS and re-test.
  • 4) Apply ALTER TABLE ... FORCE ROW LEVEL SECURITY and verify table owner is filtered by policies.
  • 5) Review logs for rejected operations and failed authentications to detect misconfigurations.
Misconception
GRANT alone does not negate RLS; policies still filter rows.
Pro tip
Automate tests that switch roles and run representative queries to catch regressions.
Quick Commands
ALTER TABLE customer_data ENABLE ROW LEVEL SECURITY;
ALTER TABLE customer_data FORCE ROW LEVEL SECURITY;
ALTER ROLE some_admin BYPASSRLS;
