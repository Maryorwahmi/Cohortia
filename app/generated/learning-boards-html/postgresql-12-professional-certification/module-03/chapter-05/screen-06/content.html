Module 4 › Chapter 3.5 › CREATE POLICY
Policy example
This policy allows users to SELECT only their own rows using current_user.
CREATE POLICY user_orders_policy ON orders
  FOR SELECT
  USING (user_id = current_user);

CREATE POLICY self_edit ON employees
  FOR UPDATE
  USING (employee_id = current_user_id())
  WITH CHECK (employee_id = current_user_id());
When WITH CHECK is present, inserts or updates that would result in rows failing the condition are rejected before write.
Breakdown
  • FOR: limits the command types, such as SELECT or ALL.
  • TO: restricts which roles the policy applies to.
  • USING: predicate that must be true for visibility and some modifications.
  • WITH CHECK: ensures writes produce rows that meet the condition.
Misconception
A single policy can be used for many commands, but separating policies by command makes intent explicit and testing simpler.
