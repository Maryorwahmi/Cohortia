Module 4 › Chapter 3.5 › USING vs WITH CHECK
USING (visibility)
Evaluated for SELECT, UPDATE, DELETE to decide if a row is visible or modifiable.
Example: USING (csr_id = current_user) makes SELECT only return rows for that CSR.
WITH CHECK (write validation)
Evaluated during INSERT and UPDATE to ensure the resulting row meets the condition.
Example: WITH CHECK (csr_id = current_user) prevents a CSR from assigning a record to someone else.
Interaction notes
  • - If WITH CHECK is absent, USING is used for validation implicitly for INSERT/UPDATE, but being explicit is safer.
  • - USING does not stop INSERTs unless the inserted row is immediately invisible after insert; prefer explicit WITH CHECK for clarity.
  • - Test attempted writes that would violate WITH CHECK to see the expected failures.
Misconception
Assuming WITH CHECK affects SELECT visibility — it does not; it only validates writes.
Check your understanding
If an INSERT violates WITH CHECK, will the row be written? No — the database rejects it.
