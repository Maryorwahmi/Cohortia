Module 4 › Chapter 3.5 › Assessment Scenario
Scenario: employee_salaries
Goal: employees see only their own salary; managers see all.
Correct commands include enabling RLS and creating two policies: one for employee SELECT using employee_id = current_user_id(), and one for managers_role using (TRUE) to allow full visibility.
Test by connecting as an employee and manager, run SELECT queries, and attempt prohibited writes to confirm WITH CHECK enforcement.
Common pitfalls
  • - Relying on GRANT alone after enabling RLS.
  • - Overusing BYPASSRLS instead of targeted policies.
  • - Omitting WITH CHECK for write validation.
Final Question

How will you document policies and tests so future teams can validate RLS after schema changes?
