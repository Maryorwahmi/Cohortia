Module 4 › Chapter 3.5 › Key Concepts
Row-Level Security (RLS)
Filters or restricts access to individual rows based on policies.
ALTER TABLE ... ENABLE ROW LEVEL SECURITY
Activates RLS enforcement for a table; no policies means deny all for non-exempt users.
CREATE POLICY
Defines FOR, TO, USING, and optional WITH CHECK predicates to control rows per command and role.
Summary Takeaway

RLS centralizes row-level rules in the database. Enable, policy, and test — in that order — to safely lock down sensitive rows.
