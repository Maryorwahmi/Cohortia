01
Install and configure Nix
Run the official installer, verify nix --version, and restart your shell to load Nix into PATH. This ensures reproducible packages for Plutus builds.
VERIFIED COMPETENCY MILESTONE
02
Clone the Plutus starter repo
Use git clone to fetch the plutus-starter project so you get the shell.nix and example contracts to inspect and build.
VERIFIED COMPETENCY MILESTONE
03
Enter the nix-shell
Run nix-shell in the project directory and watch the environment prepare GHC and libraries at pinned versions. Confirm your prompt changes.
VERIFIED COMPETENCY MILESTONE
04
Build with cabal and troubleshoot
Run cabal build inside the shell, interpret build output, and apply cleanup with nix-collect-garbage if storage grows too large.
VERIFIED COMPETENCY MILESTONE
