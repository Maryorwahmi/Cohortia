Install Nix
Run the official installer, then verify the binary is in your PATH and that nix --version outputs a version string.
Step-by-step
  1. Run the installer command provided by Nix maintainers.
  2. Follow prompts and choose multi-user mode when appropriate.
  3. Restart your terminal or source your shell profile.
  4. Run nix --version to verify installation.
Common pitfalls
Not restarting the shell, insufficient disk space, or permission errors during a multi-user install.
Installer example (terminal)
curl -L https://nixos.org/nix/install | sh
# Follow prompts, then restart your terminal or source your shell profile
nix --version
If nix --version does not print, re-open your terminal and check your shell profile for the Nix initialization line.
Example result
A successful install prints a Nix version and makes the nix command available globally for your user.
Takeaway
Install carefully, verify PATH changes, and ensure enough disk space before long builds.
