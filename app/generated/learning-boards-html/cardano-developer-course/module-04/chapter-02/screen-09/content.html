Inside vs outside nix-shell
Compare how commands resolve between your normal shell and the nix-shell to avoid confusion.
Quick check commands
# outside shell
which ghc
# inside nix-shell
nix-shell
which ghc
ghc --version
Example contrast
Outside: ghc -> /usr/bin/ghc (system version). Inside: ghc -> /nix/store/.../bin/ghc (pinned version). This difference explains many build issues.
Common mistake
Running cabal build outside the nix-shell and wondering why dependencies are missing.
Key Takeaway

Treat nix-shell as the canonical environment. Always confirm tool versions inside it before compiling.
