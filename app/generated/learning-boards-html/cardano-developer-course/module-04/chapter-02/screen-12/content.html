Module 4 › Chapter 4.2 › Disk maintenance
Manage Nix store size
Reclaim space with nix-collect-garbage -d and inspect store usage before deleting artifacts.
Commands
# see free space
df -h
# run garbage collection
nix-collect-garbage -d
# advanced: see roots
nix-store --gc --print-roots
Warning
Running garbage collection deletes unreferenced artifacts permanently. Only run when you understand the consequences.
Scenario
After months of development you hit low disk space. Running nix-collect-garbage -d frees large amounts of storage by removing old build outputs.
Takeaway
Schedule occasional garbage collection and monitor disk use during big builds.
