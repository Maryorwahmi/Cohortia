Troubleshooting checklist
Check permissions, shell PATH, disk space, and whether you're inside nix-shell when builds fail.
Permission errors
Ensure you followed the correct installer mode and have appropriate privileges for multi-user installs.
PATH not updated
Restart your terminal or source your profile so Nix init lines take effect.
Long or stalled builds
Check network, disk usage, and let Nix run — it often builds large components the first time.
Example commands
# verify nix is available
nix --version
# check disk usage on Unix
df -h
# reclaim old Nix store artifacts
nix-collect-garbage -d
If builds fail, copy the first error block and search or consult the repo README for version notes.
Misconception
A long build is always broken. Often it is normal; only investigate when there is no disk or network activity for a long time.
Takeaway
Use the checklist: permissions, PATH, disk, and shell state to diagnose most setup problems quickly.
