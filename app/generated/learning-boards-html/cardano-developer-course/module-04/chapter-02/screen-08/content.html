Compile with cabal build
Run cabal build inside the nix-shell to compile Plutus and off-chain code with the pinned toolchain.
Terminal walkthrough
nix-shell
# once inside the shell
cabal build
# observe configuration, compilation, and linking output
# on success, artifacts appear in the build/dist directory
Common error
Running cabal outside nix-shell yields missing cabal or GHC errors; re-enter nix-shell and retry.
Pro tip
Search build logs for 'error' and 'warning' to quickly locate real issues in long output.
Example outcome
On success you'll see package build summaries and created build artifacts. If the build fails, copy the first error block to diagnose the cause.
Key Takeaway

Always run cabal build inside nix-shell. Confirm the correct GHC and Cabal versions with --version checks inside the shell.
