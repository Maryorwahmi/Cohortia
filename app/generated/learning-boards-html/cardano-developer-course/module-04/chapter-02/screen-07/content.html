Enter the nix-shell
Run nix-shell to create an environment with pinned GHC and Cabal. Expect long initial builds.
What to expect
  • Downloading and building dependencies, possibly including GHC.
  • Long terminal output; be patient — it is usually working.
  • Final prompt indicates you are inside the shell with correct PATH.
Quick checks
Run ghc --version and cabal --version inside the shell to confirm pinned versions.
Terminal example
nix-shell
# lengthy download and build output...
# after completion, prompt changes
ghc --version
cabal --version
If the build seems stuck, check your internet connection and disk usage; Nix may still be compiling in the background.
Misconception
nix-shell always downloads prebuilt binaries. In practice, Nix may build from source depending on derivations and caches.
Takeaway
Be patient on first run; caching makes later shells fast and predictable.
