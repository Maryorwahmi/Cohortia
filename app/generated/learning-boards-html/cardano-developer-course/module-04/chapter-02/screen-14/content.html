Module 4 › Chapter 4.2 › Key Concepts
Nix
Functional package manager that ensures reproducible builds by isolating inputs and outputs.
nix-shell
A temporary shell that loads pinned toolchain versions for reliable building and testing.
cabal
The Haskell build tool you run inside nix-shell to compile Plutus contracts.
Summary Takeaway

Follow the install, verify, clone, shell, build flow and run periodic garbage collection to maintain a reproducible Plutus development environment.
