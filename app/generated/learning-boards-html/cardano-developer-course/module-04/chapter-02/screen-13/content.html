Full setup walkthrough
Run the commands in order and confirm at each checkpoint so you catch issues early.
# install Nix (run once)
curl -L https://nixos.org/nix/install | sh
# restart terminal
nix --version

# clone starter
git clone https://github.com/input-output-hk/plutus-starter.git
cd plutus-starter

# enter environment
nix-shell
# once shell is ready
ghc --version
cabal --version

# build
cabal build

# when finished
exit
# reclaim space later
nix-collect-garbage -d
Verification
  • nix --version prints a version string.
  • ghc and cabal inside nix-shell match pinned versions.
  • cabal build completes without missing-dependency errors.
Takeaway
Follow the flow and verify each small command; small checks prevent larger failures later.
