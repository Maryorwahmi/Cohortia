Clone the Plutus starter project
Fetch the official repository to get a pre-built project with environment definitions and example contracts.
Commands
git clone https://github.com/input-output-hk/plutus-starter.git
cd plutus-starter
ls -la
Open shell.nix and cabal.project to inspect pinned packages and build targets.
What to inspect
  • shell.nix: pinned GHC and libraries.
  • cabal.project: build targets and package paths.
  • README: repo-specific instructions and possible submodules.
Example scenario
Cloning to a path with spaces may break scripts. Choose a clean path like ~/dev/plutus-starter.
Takeaway
Cloning gives you a reproducible scaffold; inspect shell.nix before entering the shell.
