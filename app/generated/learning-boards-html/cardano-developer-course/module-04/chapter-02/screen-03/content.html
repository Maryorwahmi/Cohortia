How you'll use these skills
Concrete checkpoints and a simple mnemonic to keep you on track.
Checkpoint 1: Nix installed
Run nix --version and restart your shell. If the command prints a version, Nix is available.
Checkpoint 2: Repo cloned
After cloning, inspect shell.nix to see pinned packages and environment definitions.
Checkpoint 3: Enter nix-shell
Run nix-shell. Confirm by checking ghc --version within the shell.
Checkpoint 4: Build success
Inside the shell, run cabal build. Successful package builds confirm a working toolchain.
Mnemonic
PATH-GC — PATH checks for shell changes, G for GHC verification, C for cabal build, GC for periodic garbage collection.
