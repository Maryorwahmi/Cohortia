Design the deposit transaction
Deposit transaction sketch
  1. Consume user public-key UTXO for amount + fee.
  2. Create a request UTXO locked by the pool script with datum = { depositor, amount }.
  3. Create change output back to user if needed.
  4. No redeemer needed for simple deposit; operator will use redeemers when aggregating.
Example rationale
Reason: creating request UTXOs avoids many users attempting to consume one pool UTXO. Later a batch transaction aggregates requests, minimizing failed attempts and gas waste.
