Core Concept State Management
Evolving state by UTXO transitions
Hierarchy: state snapshots
State UTXO #1: datum = { phase: "collect", total: 50 }
Transaction consumes UTXO #1 and request UTXOs, producing State UTXO #2 with updated total.
State UTXO #2: datum = { phase: "finalize", total: 120 }
Practical checklist
  1. Define all state shapes and valid transitions.
  2. Ensure validators enforce transition rules strictly.
  3. Design off-chain components to batch or sequence requests if contention will be high.
  4. Always attach correct datums to new outputs when persisting state.
Takeaway
Model state transitions explicitly and test validator logic for each transition to prevent stuck states.
