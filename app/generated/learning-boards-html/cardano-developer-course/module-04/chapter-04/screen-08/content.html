Definition Validator Script
A pure function that decides if a spend is allowed
What the validator sees
  • Redeemer — user-supplied action or proof for this transaction.
  • Datum — the on-chain state attached to the consumed UTXO.
  • Script Context — full transaction info: signers, inputs, outputs, validity interval, and more.
Illustrative pseudocode
-- Pseudocode: validator(redeemer, datum, ctx)
-- returns true when conditions are met
validate(redeemer, datum, ctx) =
  -- check deadline
  if currentTimeIn(ctx) >= datum.deadline then
    return false
  -- check signer
  if datum.sender not in ctx.signers then
    return false
  -- check that an output pays the receiver
  if not exists output in ctx.outputs where output.address == datum.receiver and output.value >= datum.amount then
    return false
  return true
This code shows the three checks: time, signer, and output payment. Validators combine datum, redeemer and script context assertions to produce a single deterministic decision.
