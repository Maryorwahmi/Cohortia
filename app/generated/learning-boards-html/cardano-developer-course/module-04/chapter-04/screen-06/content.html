Definition Outputs & Datums
Where state is kept and how it changes
Comparison: final payout vs persisted state
Final payout
Output sends ADA to a public key address. No datum required because state does not continue here.
Persisted state
Output is script-locked with an attached datum representing the new state snapshot for future interactions.
Example
Escrow release
Input: escrow UTXO with EscrowDatum. If conditions pass, outputs: one ADA output to receiver and optionally a change output to sender. The escrow datum is not carried forward if the state is finished.
Key takeaway
Always confirm that new outputs include the correct datum when state must persist; forgetting it breaks the contract flow.
