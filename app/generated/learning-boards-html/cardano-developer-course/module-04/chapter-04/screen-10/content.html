Release funds transaction
Transaction items
Input: escrow UTXO (EscrowDatum).
Input: sender's public-key UTXO for fees.
Redeemer: { action: "release" }.
Validator checks: deadline, signer, and correct output payment to receiver.
Outputs: 100 ADA to receiver; change to sender if applicable.
Annotated scenario
EscrowDatum = { sender: A, receiver: B, amount: 100 ADA, deadline: T }
Validator inspects script context to ensure A signed and the transaction's validity interval meets the deadline. If validation fails the inputs remain unspent and the transaction is rejected; if it succeeds the state transition is atomic and final.
