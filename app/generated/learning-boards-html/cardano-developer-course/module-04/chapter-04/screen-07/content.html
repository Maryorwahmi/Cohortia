Core Concept Redeemers
Supply the action or proof when spending a script UTXO
What a redeemer is
A small data object included in the transaction that signals the user's intent or carries required proof. It is visible to the validator during this single validation pass and not persisted with the UTXO.
Example
Redeemer: { action: "release" } for escrow, or { guess: 42 } for a game. The validator checks it against datum and script context.
Design and pitfalls
Design tip
Keep redeemers minimal and explicit so validators can make deterministic checks with minimal surface area for error.
Misconception
Redeemers are not persistent permissions; they are per-transaction inputs that must be validated.
