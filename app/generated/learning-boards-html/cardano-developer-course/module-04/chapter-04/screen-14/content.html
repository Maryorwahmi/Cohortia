Practice Lab Owner Withdrawal
Design the withdrawal transaction
Withdrawal transaction elements
Inputs: canonical pool UTXO (with aggregated total datum) plus any fee UTXO.
Redeemer: { action: "withdraw" } if the script requires an explicit instruction.
Validator checks: deadline passed, owner in signers, outputs include payment to owner equal to the datum's total.
Risk and mitigation
Risk: relying on off-chain aggregation without on-chain verification can allow discrepancies. Mitigation: validator verifies output totals and uses the datum's recorded total as ground truth before allowing withdrawal.
Reflection
How will your validator ensure the amount claimed for withdrawal matches the on-chain record in the datum?
