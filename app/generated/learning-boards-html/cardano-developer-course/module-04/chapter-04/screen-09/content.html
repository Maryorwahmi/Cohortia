Core Concept Script Context
Transaction-level data the validator can inspect
Architecture: fields available
tx hash
Identifier for the transaction being validated.
validity interval
When the transaction is allowed to be processed; used for deadline checks.
signers
Public keys that signed the transaction; validators check presence of required signers.
inputs
All inputs in the transaction; validators can inspect other inputs if needed.
outputs
All outputs with datums and values; used to verify payouts or state propagation.
purpose
Why the script is invoked — validating an input or minting tokens.
Design tips
  • Explicitly check signers rather than trusting redeemer claims.
  • Use validity interval for time-based logic; do not assume wall-clock time off-chain.
  • Confirm required outputs exist and carry correct values or datums.
