Key Concepts Quick Reference
Three short definitions
Datum
On-chain data attached to a script-locked output representing that output's state snapshot.
Redeemer
The action or proof supplied by the transaction submitter for a single validation pass.
Script Context
Transaction facts like signers, inputs, outputs and validity interval validators use to check correctness.
Final takeaway

Keep these concise definitions handy when designing validators and composing transactions to avoid common mistakes and design secure flows.
