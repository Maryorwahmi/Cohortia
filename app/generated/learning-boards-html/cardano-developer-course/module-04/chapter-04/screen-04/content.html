Core Concept EUTXO Anatomy
Transaction parts and their meaning
Concrete labels you will use in transaction design and validator checks.
Definitions
Inputs
UTXOs consumed by the transaction. Example: a script-locked UTXO that holds escrow funds.
Outputs
New UTXOs created. Example: a new script-locked UTXO with updated datum representing new state.
Datum
On-chain state attached to a script-locked UTXO. Example: EscrowDatum holding sender, receiver, amount, and deadline.
Redeemer
Action or proof supplied by the transaction creator. Example: a release action object for escrow.
Validator Script
Pure function that checks redeemer, datum, and script context and returns true to allow spending.
Quick example
Escrow snapshot
Datum: { sender: A, receiver: B, amount: 100 ADA, deadline: T } — Redeemer: { action: "release" } — Validator inspects the script context to confirm signature and deadline.
Key takeaway
State in EUTXO is explicit and moves by replacing old UTXOs with new ones carrying updated datums.
