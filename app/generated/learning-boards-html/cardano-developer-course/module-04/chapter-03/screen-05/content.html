Definition

Pure functions and immutability

Determinism and no reassignment make reasoning and auditing practical.

Example: calculateArea
calculateArea :: Integer -> Integer
calculateArea radius =
  let piVal = 314159 -- integer approximation
      area = piVal * radius * radius
  in area
piVal and area are fixed in this scope and cannot be reassigned.
Common mistake

Trying to update a binding like in imperative languages. Instead, create a new binding that represents the transformed value.

Try in ghci
-- load ghci and paste calculateArea
calculateArea 2
-- Expect: computation using the bound values
Why it matters
Immutable bindings ensure intermediate values are stable, making contract logic auditable and easier to test. Side effects hidden in state changes are a frequent source of bugs in financial code; immutability avoids that class of bugs entirely.

What would change if you could reassign bindings freely? How would that affect verification and testing?
