Process Flow

Recursion pattern: base and recursive cases

Define a stopping condition and a step that reduces the problem size.

factorial :: Integer -> Integer
factorial 0 = 1
factorial n = n * factorial (n - 1)

processList :: [Integer] -> Integer
processList [] = 0
processList (x:xs) = x + processList xs
Debug tip
Trace small inputs in ghci to see the recursive unfolding and ensure termination.
Example evaluation
processList [10,20,30] evaluates to 60 by summing head and recursively processing tail until the empty list base case returns zero.
Common mistake
Omitting a base case or recursing without reducing the problem size. Always verify convergence for the inputs you expect.
Key Takeaway

Structure recursion with a clear base case and step that reduces input size. Pair with pattern matching for readable list processing.
