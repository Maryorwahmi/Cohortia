Module 4 › Chapter 4.3 › Common Data Types
Definition

Integer, Bool, List, Char, String, Maybe

Pick types that express intent and let the compiler enforce consistency.

Integer
Arbitrary-precision whole numbers for contract calculations.
Bool
True or False decisions used in guards and conditions.
List
Homogeneous sequences: all elements share the same type, e.g., [Integer].
Maybe a
Represents an optional value: Just a or Nothing. Use for safe failure handling.
Concrete example
myNumbers :: [Integer]
myNumbers = [1, 2, 3, 4, 5]

isEven :: Integer -> Bool
isEven n = n `mod` 2 == 0
Common misconception
Trying to mix types inside a list or using error for missing values instead of Maybe. Prefer explicit Maybe for optional results to make failure cases visible.
Key Takeaway

Choose specific, consistent types; use Maybe to express an optional or failing computation safely.
