Code Walkthrough

add and calculateArea

-- add two integers
add :: Integer -> Integer -> Integer
add x y = x + y

-- calculate area with let bindings
calculateArea :: Integer -> Integer
calculateArea radius =
  let piVal = 314159 -- integer approximation
      area = piVal * radius * radius
  in area
Try and observe
Type these in ghci, call add 2 3, call calculateArea 2, and note consistent outputs and scope for let bindings.
Example calls in ghci
ghci> add 2 3
5

ghci> calculateArea 2
1256636 -- with the integer piVal approximation
Misconception
Let bindings are not variables you can reassign. They are scoped names for expressions. To change a value, define a new binding based on the old one.
Key Takeaway

Small functions plus explicit bindings create clear, testable building blocks for larger contract logic.
