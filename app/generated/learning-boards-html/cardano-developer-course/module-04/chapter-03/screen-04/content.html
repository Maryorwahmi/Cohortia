Core Concept

Why Haskell is a fit for Plutus

Purity, types, and composability improve safety and support formal verification for financial logic.

Purity (no side effects)
Deterministic outputs ease testing and proofs. Pure functions simplify reasoning about contract outcomes.
Strong static typing
The compiler catches mismatched types early, preventing runtime surprises on-chain.
Composability
Small functions compose into larger logic blocks, which is helpful for auditing and testing.
Key Takeaway

Haskell's features directly map to the needs of secure, verifiable smart contracts—determinism, safety, and composability.

Concrete example
-- simple pure add function
add :: Integer -> Integer -> Integer
add x y = x + y
This function always produces the same result for the same inputs and has no side effects.
Common misconception
Beginners often try to write code that mutates variables as in imperative languages. Haskell prefers creating new values and composing transformations. Expect compile-time feedback rather than runtime changes.
Try this in ghci
Load add and call it with different numbers. Notice identical inputs produce identical outputs—this is the heart of purity.
