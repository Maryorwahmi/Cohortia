Activity: isPositive and headMaybe

Follow these steps in ghci and observe results for edge cases.

Step 1 — isPositive
-- Type signature
isPositive :: Integer -> Bool
-- if/else
isPositive n = if n > 0 then True else False

-- Guards (idiomatic)
-- isPositive n | n > 0 = True
--              | otherwise = False
Step 2 — headMaybe
headMaybe :: [Integer] -> Maybe Integer
headMaybe []    = Nothing
headMaybe (x:_) = Just x
Test cases to try
isPositive 5, isPositive (-3), isPositive 0; headMaybe [1,2,3], headMaybe [], headMaybe [99]
Key Takeaway

Small, well-typed functions with tests build confidence. Use guards and pattern matching for idiomatic, auditable code.
