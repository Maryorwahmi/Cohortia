Module 4 › Chapter 4.3 › Maybe & Safe Ops
Definition

Maybe a: Just a | Nothing

Model optional results to handle failure explicitly and safely.

safeDivide :: Integer -> Integer -> Maybe Integer
safeDivide _ 0 = Nothing
safeDivide x y = Just (x `div` y)

-- headMaybe example
headMaybe :: [Integer] -> Maybe Integer
headMaybe []    = Nothing
headMaybe (x:_) = Just x
Why this helps
Callers must handle Nothing explicitly, making failure paths visible to reviewers and tests.
Consume safely
case safeDivide 10 0 of
  Nothing     -> "Division failed"
  Just result -> "Result: " ++ show result
Common misconception
Treating Maybe as optional syntactic sugar. It's a contract-level decision to represent failure; ignore it only at your own risk.
Key Takeaway

Prefer Maybe for operations that can fail; it promotes explicit handling and safer contract logic.
