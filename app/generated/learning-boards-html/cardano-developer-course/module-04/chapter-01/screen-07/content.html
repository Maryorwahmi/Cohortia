Module 4 › Chapter 4.1 › Datums, Validator Scripts, and Redeemers
The trio that enables EUTXO logic
Each element has a single responsibility and together they form a pure validation process.
Datum
Holds local state for the UTXO, visible when building transactions.
Validator
Script that verifies the redeemer against the datum and transaction context.
Redeemer
The proof or parameters supplied by the spender at transaction time.
Example scenario
An NFT listing UTXO stores seller and price in its datum; the buyer's transaction includes payment and a redeemer proving purchase intent; the validator ensures price and recipient match before releasing the NFT.
Design tip
Make datums concise and explicit. Treat them as part of your contract's state machine and plan how transactions will replace or update them.
Pitfall
Relying on hidden off-chain data instead of embedding required state in datums makes transactions brittle and unpredictable.
