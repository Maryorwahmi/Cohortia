Key Terms to Keep Handy
Three concise definitions for quick recall.
Datum
Arbitrary data attached to a UTXO used to represent local state for a contract.
Validator Script
Plutus code that checks whether a UTXO may be spent given datum, redeemer, and transaction context.
Redeemer
Data supplied by the spender that the validator uses as proof or parameters for the spend.
Quick mnemonic: Datum holds state, Validator enforces rules, Redeemer supplies proof. Use it to map your designs into EUTXO flows.
