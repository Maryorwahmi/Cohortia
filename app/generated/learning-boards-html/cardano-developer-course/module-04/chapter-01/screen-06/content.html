EUTXO transaction steps
A clear, ordered process from input selection to output creation.
1. Select inputs
Choose UTXOs to consume. Note datums and locks.
2. Build redeemers
Attach redeemers with proofs or parameters for each validator.
3. Simulate off-chain
Verify validation using known inputs and budgets.
4. Submit & create outputs
If validators accept, new UTXOs with datums are created.
Concrete example
Escrow: consume escrow UTXO with datum, provide redeemer proving condition, produce output to recipient with new datum or change back to sender.
Key Takeaway
Every consumed datum must be replaced if you intend to carry forward state; plan outputs explicitly.
Quick checklist
  • Are all required UTXOs included as inputs?
  • Do redeemers carry the necessary proofs?
  • Do outputs include updated datums where needed?
Common mistake
Forgetting to create an output that preserves or updates state results in lost information or unmet contract expectations.
