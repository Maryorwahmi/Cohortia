Parallelism through UTXO locality
Independent UTXOs allow independent transactions to be processed in parallel.
  • Independent UTXOs → independent validation paths.
  • Design: map per-user or per-position state to separate UTXOs.
  • Beware: a single shared UTXO becomes a serialization point.
Key Takeaway
Model state as multiple UTXOs to enable many users to act without contention and to improve throughput.
Concrete scenario
A DEX can represent each liquidity share as a UTXO with a datum; swaps that touch different liquidity UTXOs can proceed simultaneously without conflict.
Pitfall
Packing many unrelated users into a single UTXO centralizes contention and reduces parallelism benefits.
