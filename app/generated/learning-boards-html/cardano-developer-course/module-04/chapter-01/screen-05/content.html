Module 4 › Chapter 4.1 › Account-based Model vs EUTXO
Account-based model
Contracts live in accounts with mutable internal state. Transactions send messages that change that state. Concurrency can cause unpredictable results if state changes between simulation and execution.
  • Mutable global state inside contracts
  • Message calls change state sequentially
  • Vulnerable to race conditions and reentrancy
Misconception
Assuming an off-chain simulation will always match on-chain behavior in an account model with many interleaving calls.
EUTXO model
State is distributed across UTXOs as datums. Transactions explicitly consume known inputs, so validation depends only on those inputs and the provided redeemer, improving determinism.
  • Local state per UTXO via datums
  • Transactions declare all consumed inputs
  • Independent UTXOs allow parallel processing
Key Takeaway
Design for explicit state transitions and local contention rather than a single shared state to enable predictable outcomes.
