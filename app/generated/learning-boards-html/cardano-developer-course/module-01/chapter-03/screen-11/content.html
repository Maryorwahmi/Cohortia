Hands-on Activity

Set up Nami on Testnet and Send tADA

Follow these steps carefully to practice secure setup and transaction verification.

Install & Create
Install Nami extension, choose Create New Wallet, write down the 24-word seed, and verify words.
Switch to Testnet
Open network settings and select Testnet, then copy your addr_test1... address.
Request tADA
Paste your address into the testnet faucet and request funds. Wait for the transaction to appear.
Send Test ADA
Enter recipient address and amount, confirm with your spending password, and broadcast.
Check

Copy the transaction hash from Nami and paste it into a testnet explorer to confirm inputs, outputs, fee, and confirmations.

Activity Notes
Keep your seed offline. Use testnet for practice and verify each transaction on an explorer to build good habits.
