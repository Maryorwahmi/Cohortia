Module 2 › Chapter 1.3 › Sending ADA, Fees, and Metadata
Process

Construct, Sign, and Broadcast

Provide recipient, amount, and sign. Wallet builds inputs and outputs and calculates fees.

Fee structure
Calculated from a fixed minimum plus a small amount per byte of transaction size. A typical transaction might cost around 0.17 ADA.
Metadata
Attaching metadata increases transaction size and therefore increases the fee slightly.
Common error
Sending to the wrong address. Always double-check long address strings before confirming.
Example Transaction
Inputs: UTXO1, UTXO2
Outputs: recipient_addr -> 5.0 ADA
Change: my_addr -> 4.83 ADA
Fee: ~0.17 ADA
Metadata: optional small note
Key Takeaway

Understand inputs, outputs, change, and that fees scale with transaction size and optional metadata.
