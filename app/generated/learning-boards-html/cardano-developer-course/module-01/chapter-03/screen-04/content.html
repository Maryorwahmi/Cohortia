Core Concept

Wallet: Key Manager and Signer

Wallets hold private keys and create signed transactions that the network accepts.

Quick definition
The wallet stores keys used to sign transactions; it generates public addresses for receiving ADA.
Concrete example
A light client like Yoroi creates addresses and signs transactions locally without downloading the full chain.
Common mistake
Treating a wallet like a bank account. The ledger stores funds; the wallet stores authorization to spend them.
Analogy & Example
Analogy
Think of the wallet as the keyring; the blockchain is the safe where the valuables sit. Losing the keyring means losing access.
Example address format
addr1... (mainnet example)
addr_test1... (testnet example)
Key Takeaway

A wallet manages keys and signs transactions; protect the seed phrase since it derives your private keys.
