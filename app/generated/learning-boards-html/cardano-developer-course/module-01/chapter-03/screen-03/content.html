Module 2 › Chapter 1.3 › Learning Objectives — Practical Outcomes

Demonstrable Outcomes

Clear steps you will perform during the lab.

Wallet Selection
Explain why you would pick a light client for speed or a hardware wallet for security.
Secure Setup
Create a wallet, write down the seed phrase, and complete verification prompts.
Transaction Flow
Send test ADA, confirm the fee, and observe the confirmation sequence on-chain.
Explorer Use
Locate a transaction hash and verify inputs, outputs, fee, and block confirmations.
Quick Mnemonic
Record seed, verify words, set password, request tADA, send, verify.
Safety Reminder
Never enter your seed phrase into a website or share it. Physical backups only.
