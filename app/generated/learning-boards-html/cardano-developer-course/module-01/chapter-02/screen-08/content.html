Module 1 › Chapter 1.2 › Native Tokens
Definition

Native tokens are first-class ledger assets

Mint and transfer tokens directly via transactions. Native tokens benefit from the same core ledger guarantees as ADA and do not require a running contract for basic issuance or transfer.

When to use native tokens
  • Fixed-supply fungible tokens for simple distribution.
  • Single-owner NFTs or simple collectibles that need low-cost transfers.
  • When you want minimal complexity and ledger-level security.
Policy ID & Example
A token's policy ID determines who can mint or burn it. Conceptually you might draft a command like: mint MyProjectCoin 1000000 --policy-id <POLICY_ID> to record the intent to mint one million units under that policy.
Key Takeaway

Prefer native tokens for simple asset needs to minimize cost and reduce security surface area; reserve Plutus when tokens require program logic.
