Definition

CSL: secure ledger & native tokens

The CSL handles ADA transfers and native tokens using the Extended UTXO model for deterministic transaction validation.

Why EUTXO matters
  • Inputs are known at submission time, so contract validation is predictable.
  • Transactions that use disjoint inputs can be processed in parallel, aiding scalability.
  • UTXOs can hold tokens and data and be locked by scripts for conditional spending.
Concrete example
Minting a simple native token like MyProjectCoin and transferring it uses a ledger transaction, not a contract, which makes minting and sending cheaper and inheriting ADA-level security.
Key Takeaway

CSL keeps value logic compact and secure; native tokens are first-class ledger assets, and EUTXO gives predictable validation.
