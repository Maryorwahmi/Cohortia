Module 1 › Chapter 1.2 › Marlowe
Definition

Marlowe for financial contracts

Marlowe offers a constrained language and visual tools to compose common financial patterns, making contract creation accessible and less error-prone.

  • Good for escrow, swaps, scheduled payments and simple financial flows.
  • Compiles to Plutus, so the EUTXO execution model still applies.
  • Reduces custom validator surface area by using domain primitives.
Scenario
Design an escrow where Party A deposits funds, Party B performs a condition, and funds release when both parties signal completion. Marlowe offers primitives to express this flow without hand-crafting validators.
Key Takeaway

Choose Marlowe for repeatable financial patterns to reduce development effort while keeping Plutus-level on-chain guarantees.
