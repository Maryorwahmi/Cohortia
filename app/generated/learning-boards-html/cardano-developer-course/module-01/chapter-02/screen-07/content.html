Example

Conceptual transaction structure

This example is a simplified, conceptual view to illustrate inputs and outputs and how native tokens appear inside UTXOs.

Transaction:
Inputs:
  - utxo: abc123
    value: 10 ADA, 200 MyProjectCoin
Outputs:
  - address: recipientA
    value: 6 ADA, 150 MyProjectCoin
  - address: recipientB
    value: 3.9 ADA, 50 MyProjectCoin
Fee: 0.1 ADA
Metadata: optional note or reference
Notice how inputs list exact UTXOs and contain both ADA and the native token. The outputs specify how value is redistributed. A validator checks the correctness of spending the input utxo before the outputs exist.
Check
On a block explorer, find Inputs and Outputs for a transaction. Identify a UTXO ID and see the assets it carries. This maps directly to the example above.
Key Takeaway

EUTXO transactions enumerate UTXOs; real explorers expose this structure so you can trace exactly how assets moved.
