Core Concept

CSL: Settlement, CCL: Computation

The settlement lane securely handles ADA and native assets while the computation lane runs programmable logic like Plutus contracts. Each layer can be optimized independently.

Security: isolate critical ledger code to reduce attack surface.
Flexibility: evolve smart contract capabilities without disturbing the settlement rules.
Scalability: tune each layer for its workload and allow parallel improvements.

Key Takeaway

Place simple asset logic in CSL and complex, programmable logic in CCL to balance safety with capability.
