Core Concept

Immutability and Cryptographic Security

How hashes and digital signatures work together to secure ledger history.

Hash linking
Each block stores a fingerprint of the previous block, so any change is immediately visible.
Digital signatures
Signatures prove transaction origin and prevent unauthorized spending.
Tamper evidence
Together, links and signatures make unauthorized changes detectable and impractical without large-scale collusion.
Design implication
Because history is preserved, error handling favors compensating actions and governance for upgrades rather than silent edits.
Example
Signed transfer

A user signs a transfer with their private key. Validators verify the signature against the public key before accepting it into a block.

Misconception
Immutability depends on protocol security and honest-majority assumptions; it's not an absolute guarantee without considering attack vectors and governance.
Key Takeaway

Hashes and signatures create strong tamper-evidence, shaping how you audit and correct operations in a blockchain system.
