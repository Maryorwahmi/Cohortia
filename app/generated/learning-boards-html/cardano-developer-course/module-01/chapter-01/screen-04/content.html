Core Concept

What is a Blockchain?

A concise, practical definition and how it shapes system design.

Block
A container of transactions or state changes packaged together.
Cryptographic Link
A hash that ties each block to the previous block to detect tampering.
Replication and Validation
Nodes verify blocks and keep copies, enabling consensus without a central authority.
Illustration & Example
Notebook analogy

Each participant keeps a copy of a notebook. When someone adds a page they include a fingerprint of the previous page. If a page is changed later, the fingerprints no longer match and all participants see the discrepancy.

Common misconception
Not all blockchains are public or anonymous. Permissioned ledgers can restrict access while still providing immutability and auditability.
Key Takeaway

Treat the ledger as authoritative history; design systems so that corrections are appended, not silently overwritten.
