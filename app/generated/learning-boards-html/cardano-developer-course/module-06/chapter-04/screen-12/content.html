Ogmios and Kupo: Powering Backend Data Access

Essential tools for real-time chain state and efficient UTXO querying.

Ogmios: Real-time Node Bridge

A lightweight, WebSockets-based bridge to a Cardano node, providing a real-time, low-latency interface.

  • Real-time Data: Query chain state and submit transactions with minimal delay.
  • Low Latency: Ideal for DApps and backend services requiring quick responses.

Kupo: Efficient UTXO Indexer

A lightweight, fast, and scalable UTXO indexer for Cardano, enabling efficient querying of UTXOs.

  • Efficient Querying: Find UTXOs by address, asset, or `Datum` hash quickly.
  • Smart Contract Critical: Essential for DApps interacting with the UTXO model.
Key Takeaway

Ogmios and Kupo are foundational backend tools, providing real-time node access and efficient UTXO indexing, critical for building high-performance Cardano DApps.
