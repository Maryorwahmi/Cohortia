Explorer Deep Dive

CardanoScan and Cexplorer: Debugging with Precision

Leveraging popular explorers for detailed transaction analysis.

CardanoScan (cardanoscan.io)

A widely used block explorer providing detailed information on blocks, transactions, addresses, and staking.

  • Detailed Data: Blocks, transactions, addresses, epochs, staking.
  • Script Debugging: Crucial for inspecting `Datum` and `Redeemer` values on script UTXOs.
  • Testnet Support: Available for mainnet, preprod, and preview testnets.

Cexplorer (cexplorer.io)

Another comprehensive block explorer offering similar functionality, often with different visualizations and data presentations.

  • Alternative View: Provides different perspectives on blockchain data.
  • Cross-Verification: Useful for comparing data or finding information not immediately obvious on one explorer.
  • Familiarity is Key: Being comfortable with multiple explorers enhances your debugging capabilities.
Key Takeaway

CardanoScan and Cexplorer are indispensable for detailed transaction analysis and debugging, especially for inspecting script data like `Datum` and `Redeemer` values.
