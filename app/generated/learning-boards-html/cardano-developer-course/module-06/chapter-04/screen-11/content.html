Oracle Solutions

Decentralized Oracles: Charli3 and Custom Relayers

Exploring methods for reliable data feeds to Plutus contracts.

Charli3 Network

A decentralized oracle network built specifically for Cardano, providing reliable and tamper-proof data feeds.

  • Cardano-Native: Optimized for the Cardano ecosystem.
  • Decentralized: Reduces single points of failure for data integrity.

ErgoDex (Price Feeds)

While a DEX, platforms like ErgoDex can serve as a source for on-chain price data through their liquidity pools.

  • On-Chain Data: Leverages existing liquidity pool data.
  • Decentralized Price Feeds: A form of oracle for specific asset prices.

Off-chain Code/Relayers

Custom backend servers fetch data from traditional APIs, process it, and place it on-chain for Plutus scripts.

  • Custom Solutions: Tailored data feeds for specific DApp needs.
  • API Integration: Connects traditional APIs to the blockchain.
Key Takeaway

Cardano offers diverse oracle solutions, from dedicated networks like Charli3 to leveraging DEX data and custom off-chain relayers, providing flexibility for DApp data needs.
