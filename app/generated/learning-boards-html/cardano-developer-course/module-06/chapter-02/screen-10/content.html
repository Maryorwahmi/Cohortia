Unlocking Funds: The Redeemer

Providing Off-Chain Data to Satisfy Script Logic

-- redeemer.json
{
  "constructor": 0,
  "fields": [
    {
      "int": 123
    }
  ]
}
What is Redeemer?

Redeemer is off-chain data provided during a transaction to unlock a script UTXO. It's used by the script for validation, alongside the on-chain Datum.

Interaction with Datum

The Redeemer and Datum work together. The script's logic evaluates these two pieces of data to determine if the spending conditions are met.

Example: Gift Validator

For our Gift validator, the redeemer.json contains the secret integer 123, which must match the Datum's value for the script to pass.

Key Takeaway

The Redeemer is the dynamic input that allows you to interact with and unlock funds from a script address, provided it satisfies the contract's predefined logic.
