Hashing Datum & Building the Funding Transaction

Preparing the Transaction Output with the Datum Hash

# Calculate the hash of your Datum
cardano-cli transaction hash-script-data --script-data-file datum.json
# Output will be something like: 947137f8849b380d0d826a7f1a9a8f2c7b5d1a8e1b0c0f0a0d0e0f0a0d0e0f0a

# Assume DATUM_HASH is obtained from the above command
DATUM_HASH="947137f8849b380d0d826a7f1a9a8f2c7b5d1a8e1b0c0f0a0d0e0f0a0d0e0f0a"

# Build the raw transaction to fund the script address
cardano-cli transaction build-raw \
  --tx-in ${UTXO_IN} \
  --tx-out "${SCRIPT_ADDR} + 1000000 lovelace + ${DATUM_HASH}" \
  --tx-out "${WALLET_ADDR} + 9000000 lovelace" \
  --fee 0 \
  --out-file tx.draft \
  --alonzo-era # or --babbage-era, etc.
Hashing the Datum

For Plutus V1 scripts, the Datum content is hashed using cardano-cli transaction hash-script-data to produce a unique identifier for the on-chain UTXO.

Transaction Output Structure

When funding a script, the --tx-out for the script address must include the ADA amount and the calculated DATUM_HASH, separated by a plus sign.

Drafting the Transaction

The cardano-cli transaction build-raw command creates a draft transaction body, allowing you to specify inputs, outputs, and a temporary fee of 0 for later calculation.

Key Takeaway

Correctly hashing the Datum and including its hash in the transaction output is fundamental for locking funds at a script address under specific, verifiable conditions.
