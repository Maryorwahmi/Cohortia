Funding Your Script: The Role of Datum

Attaching On-Chain Data to a Locked UTXO

-- datum.json
{
  "constructor": 0,
  "fields": [
    {
      "int": 123
    }
  ]
}
What is Datum?

Datum is on-chain data attached to a UTXO at a script address, used by the script for validation. It defines the conditions for unlocking funds.

Datum Serialization

For Plutus V1, the hash of the Datum is included in the transaction output. For V2, inline datums can be used, attaching the full Datum directly.

Example: Gift Validator

Our datum.json locks funds with a secret integer (123). This value will be checked by the Gift validator when someone attempts to spend the UTXO.

Key Takeaway

The Datum is essential for locking funds at a script address, providing the on-chain context that your smart contract needs to validate future spending attempts.
