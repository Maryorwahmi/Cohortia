Key Concepts

Essential Terms for Smart Contract Deployment

Testnet

A live, public blockchain network that mimics the mainnet but uses valueless tokens, ideal for testing deployments.

cardano-cli

The command-line interface for interacting with a Cardano node, used for building, signing, and submitting transactions.

Script Address

A unique address derived from the hash of a Plutus script, where UTXOs controlled by the script are held.

Summary Takeaway

These foundational concepts—Testnet, cardano-cli, and Script Address—are the bedrock for successfully deploying and interacting with Plutus smart contracts in a live environment.
