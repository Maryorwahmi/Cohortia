Signing and Submitting the Spending Transaction

Executing the Script to Retrieve Locked Funds

# Calculate fee and update change output (not shown, but implied)

# Sign with your wallet's signing key (for collateral and change)
cardano-cli transaction sign \
  --tx-body-file spend.draft \
  --signing-key-file payment.skey \
  ${TESTNET_MAGIC} \
  --out-file spend.signed

# Submit the signed transaction
cardano-cli transaction submit \
  --tx-file spend.signed \
  ${TESTNET_MAGIC}
Script Execution Outcome

If the Redeemer and Datum satisfy the script's logic, the script passes, and funds are unlocked. Otherwise, the script fails, and the transaction is invalid.

Collateral Forfeiture

In case of script failure, the collateral UTXO provided by your wallet is forfeited, compensating the network for processing the invalid transaction.

Wallet Signing Key

Your wallet's signing key is required to authorize the transaction, as it provides the collateral and receives the unlocked funds.

Key Takeaway

The final submission of a spending transaction is the moment of truth for your smart contract, where its logic is executed on-chain to determine the fate of the locked funds.
