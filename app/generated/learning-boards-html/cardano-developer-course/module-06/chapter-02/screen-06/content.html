Deriving the Script Address

Creating a Unique On-Chain Identity for Your Contract

# Define your testnet magic (e.g., preprod testnet)
TESTNET_MAGIC="--testnet-magic 1" # Replace with your actual testnet magic

# Generate the script address
cardano-cli address build \
  --payment-script-file gift.plutus \
  ${TESTNET_MAGIC} \
  --out-file gift.addr
Script Address vs. Wallet Address

Unlike regular PubKeyHash addresses, script addresses are derived from the hash of the compiled Plutus script, making them unique to the contract.

Using cardano-cli

The cardano-cli address build command is used with the --payment-script-file flag to specify your compiled .plutus script.

Testnet Magic

The --testnet-magic flag is crucial for specifying which testnet you are targeting, ensuring your address is valid for that network.

Key Takeaway

Generating the script address creates the on-chain location where your smart contract will hold and manage funds, acting as its unique identifier on the blockchain.
