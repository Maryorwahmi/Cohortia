Signing and Submitting the Funding Transaction

Finalizing the Lock of Funds to Your Script

# Get current protocol parameters for fee calculation
cardano-cli query protocol-parameters \
  ${TESTNET_MAGIC} \
  --out-file protocol.json

# Calculate the minimum fee
cardano-cli transaction calculate-min-fee \
  --tx-body-file tx.draft \
  --tx-in-count 1 \
  --tx-out-count 2 \
  --witness-count 1 \
  ${TESTNET_MAGIC} \
  --protocol-params-file protocol.json

# Update --tx-out for change and rebuild with actual fee (not shown, but implied)

# Sign the transaction with your wallet's signing key
cardano-cli transaction sign \
  --tx-body-file tx.draft \
  --signing-key-file payment.skey \
  ${TESTNET_MAGIC} \
  --out-file tx.signed

# Submit the signed transaction to the testnet
cardano-cli transaction submit \
  --tx-file tx.signed \
  ${TESTNET_MAGIC}
Fee Calculation

The calculate-min-fee command determines the exact ADA required for transaction processing, which must be accounted for in your change output.

Transaction Signing

Signing with your payment.skey cryptographically authorizes the transaction, proving ownership of the input UTXOs and allowing the transaction to be validly submitted.

Submission to Testnet

The transaction submit command broadcasts your signed transaction to the network, where it will be processed and included in a block.

Key Takeaway

Successfully signing and submitting the funding transaction locks your ADA at the script address, making it available for future interactions governed by your smart contract's logic.
