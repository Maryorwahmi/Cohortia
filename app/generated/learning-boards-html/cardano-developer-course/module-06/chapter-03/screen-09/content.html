Connecting User Wallets with Lucid

Enabling Secure Interaction with Nami, Eternl, and Lace

Wallet Connection Flow

  • •**Access `window.cardano`:** Browser wallets inject their API into the global `window` object.
  • •**`enable()` method:** Prompts the user to grant DApp access to their wallet.
  • •**`selectWallet()`:** Configures Lucid to use the connected wallet's API for all subsequent operations.
Security Note

Wallets handle private keys securely; DApps only receive an API for interaction, never direct access to sensitive credentials.

Common Mistake

Attempting to interact with the wallet before `enable()` has successfully returned an API, or if the user rejects the connection request.

Lucid Wallet Connection
async function connectWallet(
  walletName: string // e.g., "nami", "eternl"
): Promise<void> {
  try {
    // Check if the wallet is available
    if (!window.cardano || !window.cardano[walletName]) {
      throw new Error(`Wallet ${walletName} not found.`);
    }
    // 1. Enable the user's wallet
    const api = await window.cardano[walletName].enable();

    // 2. Select the wallet in Lucid
    lucid.selectWallet(api);
    console.log(`Connected to ${walletName} wallet.`);
    // Update UI to reflect connection status
  } catch (error) {
    console.error("Wallet connection error:", error);
    // Implement user-friendly error display
  }
}
Pro Tip

Always wrap wallet interactions in `try-catch` blocks to handle user rejections or wallet-related errors gracefully.

Key Takeaway

Connecting user wallets via Lucid's `selectWallet` method, after `window.cardano[walletName].enable()`, is fundamental for DApp functionality, enabling secure transaction signing and blockchain interaction.
