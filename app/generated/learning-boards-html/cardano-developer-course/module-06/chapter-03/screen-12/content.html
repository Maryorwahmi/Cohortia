Transaction Logic

Finalizing Transaction Outputs and Signers

Adding Collateral, Outputs, and Completing the Transaction

Transaction Completion Steps

  • •**`addSignerKey()`:** Adds the user's wallet key as a signer, typically for collateral.
  • •**`payToAddress()`:** Defines transaction outputs, specifying recipient and assets.
  • •**`complete()`:** Finalizes the transaction, calculates fees, and adds change.
  • •**`sign().complete()`:** Sends to wallet for signing.
  • •**`submit()`:** Broadcasts the signed transaction to the Cardano network.
Collateral Importance

Collateral ensures that if a script transaction fails, the network can still process it without halting, covering the execution costs.

Common Mistake

Forgetting to include `addSignerKey()` for collateral, which can lead to transaction failures, especially with complex script interactions.

Transaction Building (Part 2)
// 5. Build the transaction (continued)
const tx = await lucid
  .newTx()
  // ... collectFrom and attachSpendingValidator ...
  .addSignerKey(await lucid.wallet.getChangeAddress()) // Add wallet's key for collateral
  .payToAddress(await lucid.wallet.getChangeAddress(), {
    lovelace: scriptUtxo.assets.lovelace!, // Send unlocked ADA back to wallet
  })
  .complete(); // Finalize the transaction

// 6. Sign and submit the transaction
const signedTx = await tx.sign().complete();
const txHash = await signedTx.submit();

console.log(`Transaction submitted: ${txHash}`);
return txHash;
Key Insight

The `complete()` method is essential for Lucid to calculate fees and prepare the transaction for signing, ensuring it's valid for submission.

Key Takeaway

The final stages of transaction building involve defining outputs, adding signers for collateral, completing the transaction, and then securely signing and submitting it to the Cardano network.
