Preparing for Script Spending

Loading Plutus Scripts and Finding Locked UTXOs

Script & UTXO Discovery

  • •**Load Plutus Script:** Convert the compiled script's hex string into a `Script` object using `fromHex()`.
  • •**Find Locked UTXO:** Use `lucid.utxosAt(scriptAddress)` to query for UTXOs at the contract's address, then identify the specific UTXO to be spent.
Why it matters

These steps provide the DApp with the necessary on-chain context and validation logic to correctly build a transaction that interacts with the smart contract.

Common Mistake

Providing an incorrect script hex or failing to find the target UTXO, which will prevent the transaction from being built or validated correctly.

Script Loading & UTXO Query
// 3. Load the Plutus script
// For this example, we'll assume you have the raw hex
const giftScript: Script = {
  type: "PlutusV1",
  script: fromHex("58..."), // Replace with actual script hex
};

// 4. Find the UTXO at the script address
// In a real DApp, you'd query the chain for UTXOs at `scriptAddress`
// For this example, we're passed `lockedUtxo` directly.
const utxos = await lucid.utxosAt(scriptAddress);
const scriptUtxo = utxos.find(
  (u) => u.txHash === lockedUtxo.txHash && u.outputIndex === lockedUtxo.outputIndex
);

if (!scriptUtxo) {
  throw new Error("Locked UTXO not found at script address.");
}

// Ensure the datum is present and matches expectations
if (!scriptUtxo.datum) {
  throw new Error("UTXO at script address has no datum attached.");
}
Pro Tip

Always include robust checks for `scriptUtxo` and `scriptUtxo.datum` to prevent runtime errors if the expected UTXO or its datum is missing.

Key Takeaway

Successfully loading the Plutus script and accurately identifying the target locked UTXO are essential prerequisites for building a valid transaction that interacts with a smart contract.
