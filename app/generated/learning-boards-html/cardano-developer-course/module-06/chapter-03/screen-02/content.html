01

Understand DApp Interaction

Grasp how decentralized applications initiate and manage interactions with deployed Plutus smart contracts on the Cardano blockchain. This skill is vital for designing effective DApp architectures.

VERIFIED COMPETENCY MILESTONE
02

Construct Transactions with Mesh/Lucid

Learn to use client-side libraries like Mesh or Lucid to programmatically build complex transactions that spend from Plutus script addresses. This is essential for creating dynamic DApp functionalities.

VERIFIED COMPETENCY MILESTONE
03

Serialize & Deserialize Plutus Data

Gain proficiency in converting `Datum` and `Redeemer` values between their JavaScript/TypeScript representations and the Plutus `BuiltinData` format. This is crucial for correct contract validation.

VERIFIED COMPETENCY MILESTONE
04

Integrate Wallet Connectors

Learn to seamlessly integrate browser-based wallets like Nami or Eternl into your DApp, enabling users to sign and submit transactions securely. This is covered in the next section.
