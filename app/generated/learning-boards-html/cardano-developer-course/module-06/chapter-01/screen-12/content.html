Executing Your Plutus Test Suite

Verifying Contract Logic with cabal test

Run Command

Use cabal test or stack test in your project's root directory to execute the test suite.

Interpreting Output

The terminal output will clearly show which test cases passed and which failed, providing immediate feedback.

Purpose

Verifies that your validator logic behaves as expected under the conditions defined in your test cases.

Key Takeaway

Executing your test suite with cabal test provides essential feedback, allowing you to quickly verify and iterate on your Plutus smart contract logic.
