The Simple Gift Validator

Unlocking Funds with a Secret

Gift Validator Logic

Locked Funds

Assets held by the smart contract.

Secret Datum

The predefined secret number stored on-chain.

Secret Redeemer

The secret number provided by the user to unlock.

Unlock Condition

Funds are released if Redeemer == Datum.

IF
Concept

A simple validator that unlocks funds based on a matching secret number.

Components

Utilizes Datum to store the expected secret and Redeemer to provide the secret for validation.

Key Takeaway

The Gift validator serves as a clear example of how Plutus contracts use Datum and Redeemer to implement conditional logic for asset management.
