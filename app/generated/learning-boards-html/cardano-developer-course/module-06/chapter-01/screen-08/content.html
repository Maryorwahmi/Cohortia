-- The validator script logic
{-# INLINABLE mkGiftValidator #-}
mkGiftValidator :: GiftDatum -> GiftRedeemer -> ScriptContext -> Bool
mkGiftValidator (GiftDatum expectedSecret) (GiftRedeemer providedSecret) _ =
    traceIfFalse "Incorrect secret!" (expectedSecret == providedSecret)

The mkGiftValidator Function

Core Logic for Secret Matching

Input Parameters

Takes GiftDatum (expected secret), GiftRedeemer (provided secret), and ScriptContext (transaction info).

Core Logic

Compares the expectedSecret from Datum with the providedSecret from Redeemer.

Outcome

Returns True if secrets match (transaction passes), False otherwise (transaction fails).

Key Takeaway

The mkGiftValidator function encapsulates the core conditional logic, using Datum and Redeemer to determine if a transaction is valid.
