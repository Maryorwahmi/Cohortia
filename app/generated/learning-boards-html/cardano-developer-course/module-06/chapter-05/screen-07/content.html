Reentrancy & Double Satisfaction in UTXO

Protecting against unintended state changes and unfair resource consumption in Plutus contracts.

Reentrancy (UTXO Context)

Less common due to UTXO model, but complex multi-stage contracts can still have subtle reentrancy-like issues. Design state transitions carefully.

Double Satisfaction

A single input cannot satisfy multiple conditions or unlock multiple outputs unfairly. UTXO helps, but Redeemer logic must prevent unintended multi-unlocks.

Key Takeaway

While UTXO mitigates some risks, careful design is needed to prevent reentrancy-like issues and ensure inputs are not double-satisfied.

Double Satisfaction: UTXO Flow
UTXO Advantage

Each UTXO can only be consumed once, which inherently prevents many forms of double-spending. However, complex Redeemer logic can still introduce subtle double satisfaction risks.
