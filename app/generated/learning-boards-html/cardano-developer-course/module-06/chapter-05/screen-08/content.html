Arithmetic Security

Guarding Against Integer Overflow/Underflow

Ensuring arithmetic operations in Plutus produce expected and safe results, even with arbitrary precision integers.

Integer Overflow

When a calculation results in a number larger than the maximum value a data type can hold, potentially wrapping around to a small or negative number.

Integer Underflow

When a calculation results in a number smaller than the minimum value a data type can hold, potentially wrapping around to a large positive number.

Key Takeaway

Always validate inputs and intermediate calculation results to ensure they remain within expected logical bounds, preventing unintended arithmetic outcomes.

Number Line: Overflow/Underflow
Plutus Integer Advantage

Plutus uses arbitrary precision Integer, which means it doesn't have fixed min/max values like many languages. However, logical errors in your contract can still lead to results outside expected business bounds.
