Module 2 › Chapter 2.2 › Mistakes & Security
Node sync
Ensure your node is fully synced and CARDANO_NODE_SOCKET_PATH is set. Unsynced nodes return incomplete or empty queries.
Testnet magic
Use the same testnet magic for address building, faucet funding, and queries to avoid cross-network confusion.
Signing key safety
Never publish .skey files. Use encrypted or offline storage and backups to prevent permanent loss.
UTxO mistakes
Do not assume a single balance; select inputs by TxHash and TxIx and account for fees and change.
Token handling
When consuming inputs with tokens, plan change outputs to return tokens you wish to keep.
Key Takeaway

Small operational checks prevent most problems: verify node sync, network magic, file contents, and treat .skey as sacrosanct.
