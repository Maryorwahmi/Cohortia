Module 2 › Chapter 2.2 › Query UTxOs
Ensure node socket is set
Set CARDANO_NODE_SOCKET_PATH to your node socket before running queries.
export CARDANO_NODE_SOCKET_PATH=~/cardano-dev/preview-node/node.socket

cardano-cli query utxo \
  --address $(cat base.addr) \
  --testnet-magic 2
Read the output table carefully: each row corresponds to a TxHash and TxIx pair and lists amounts including lovelace and native tokens. These rows are the inputs you can reference when building transactions.
Interpreting output
TxHash and TxIx uniquely identify an output. Amount shows ADA in lovelace and any attached tokens.
Common mistake
Running the query before node sync or with the wrong socket will show no UTxOs. Verify the node is fully synced.
Key Takeaway

Use the TxHash and TxIx values from the utxo query as inputs for transaction building and confirm amounts before spending.
