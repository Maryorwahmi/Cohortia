Module 2 › Chapter 2.2 › Key Generation
Terminal Commands
Run these steps to create key files used later for addresses and signing.
mkdir wallet-keys
cd wallet-keys

cardano-cli address key-gen \
  --verification-key-file payment.vkey \
  --signing-key-file payment.skey

cardano-cli stake-address key-gen \
  --verification-key-file stake.vkey \
  --signing-key-file stake.skey
Inspect files safely with a local text editor. Never publish .skey contents.
File roles
payment.vkey — public verification key used in address construction. payment.skey — private signing key used for transaction authorization.
Safety checklist
  • Back up signing keys securely.
  • Do not commit signing keys to version control.
  • Use verification keys when sharing an address publicly.
Key Takeaway

Generate four files: payment.vkey, payment.skey, stake.vkey, stake.skey. Protect the .skey files as the secret that controls funds.
