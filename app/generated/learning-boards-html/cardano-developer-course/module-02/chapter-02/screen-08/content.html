What is a UTxO?
An unspent transaction output tied to a specific address, amount, and optional tokens. Each line in a utxo query represents one spendable output.
Example scenario
Address has UTxOs: 1 ADA and 5 ADA. To send 2 ADA, use the 5 ADA UTxO as input and create a change output back to the original address.
Why it matters
Input selection determines which tokens and how much ADA are consumed, and it interacts with fees and minimum UTxO values when building transactions.
Misconception

Treating the address as a single balance will lead to incorrect input selection and failed transactions.

UTxO Analogy
Think of UTxOs as coins in your wallet of fixed denominations; you choose which coins to use to pay an amount and get change back.
Key Takeaway

Plan input selection and be aware of minimum UTxO constraints when combining outputs and tokens.
