Wallet Management and Querying the Blockchain
Generate keys, build addresses, and use cardano-cli to inspect UTxOs and protocol parameters.
What you'll do
Generate payment and stake keys, build a base address, fund it on preview testnet, and query UTxOs and protocol parameters.
Why it matters
Understanding keys and UTxOs is essential for constructing correct transactions and protecting funds. You will repeatedly use these skills in development and testing.
Explore Key Topics
Key Generation
Use cardano-cli to create .vkey and .skey files; these files are managed locally and must be kept secure.
Address Types
Base addresses combine payment and stake credentials; enterprise addresses omit stake credentials.
UTxO Queries
Query utxo and protocol-parameters to inspect spendable outputs and transaction constraints.
Visual Concept
Keys → Addresses
Payment.vkey + Stake.vkey → Base address file (base.addr)
UTxO view
Queries return TxHash, TxIx, Amount and optional tokens for each unspent output.
Safety
Keep signing keys offline and backed up; losing them means losing funds.
