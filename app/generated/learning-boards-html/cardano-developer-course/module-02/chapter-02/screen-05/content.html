Module 2 › Chapter 2.2 › Payment vs Stake
Payment Keys
Used to sign transactions and consume UTxOs. Files: payment.skey and payment.vkey.
Enterprise Address
Built with a payment verification key only; cannot delegate stake.
Stake Keys
Used for delegation and registering stake addresses. Files: stake.skey and stake.vkey.
When to use each: enterprise addresses for one-off payments or custodial deposit flows; base addresses when you plan to delegate.
Base Address
Combine payment.vkey and stake.vkey to produce a base.addr. This address supports both spending and staking activities.
Example
cardano-cli address build \
  --payment-verification-key-file payment.vkey \
  --stake-verification-key-file stake.vkey \
  --out-file base.addr \
  --testnet-magic 2
Common mistake

Building an enterprise.addr when you intended to delegate stake will prevent delegation and reward accrual.
