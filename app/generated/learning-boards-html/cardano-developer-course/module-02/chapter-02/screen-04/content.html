Module 2 › Chapter 2.2 › Keys Overview
Definition
Signing key vs verification key
Signing key (.skey)
Private file used to authorize transactions. Must be kept secret and backed up.
Verification key (.vkey)
Public file used to derive addresses and verify signatures. Safe to share.
Analogy
Verification key is like a mailbox address where others send mail; signing key is the private mailbox key that opens and moves mail out.
Example files
payment.vkey, payment.skey, stake.vkey, stake.skey
Safety tip
Never store signing keys in public repos; use offline or encrypted backups.
Misconception
Verification keys are not secret even though they derive addresses.
Quick Example
cardano-cli address key-gen \
  --verification-key-file payment.vkey \
  --signing-key-file payment.skey
Key Takeaway

Treat .skey as the single sensitive secret for spending; .vkey lets others send funds by deriving addresses.
