Module 2 › Chapter 2.2 › Address Building
Build Commands
Create a base address by supplying both verification keys. Omit stake to build an enterprise address.
cardano-cli address build \
  --payment-verification-key-file payment.vkey \
  --stake-verification-key-file stake.vkey \
  --out-file base.addr \
  --testnet-magic 2

# Enterprise address (no stake key)
cardano-cli address build \
  --payment-verification-key-file payment.vkey \
  --out-file enterprise.addr \
  --testnet-magic 2

cat base.addr
After building, cat the .addr file to copy the string you will use at a faucet. Verify the testnet magic matches the network you intend.
Example
base.addr contains the address; copy it to request test ADA from a preview faucet.
Pitfall
Using the wrong testnet magic or funding an enterprise address when you expected staking will cause confusion; double-check before funding.
Key Takeaway

Choose base or enterprise based on whether you want stake delegation. Always verify the address string before requesting funds.
