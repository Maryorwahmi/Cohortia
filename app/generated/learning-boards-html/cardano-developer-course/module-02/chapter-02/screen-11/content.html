Module 2 › Chapter 2.2 › Protocol Parameters
Fetch current values
Protocol parameters affect fees and minimum UTxO values; fetch them before building transactions.
cardano-cli query protocol-parameters \
  --out-file protocol.json \
  --testnet-magic 2
Include the resulting protocol.json when estimating fees and building transactions so estimates match the current network rules.
Why refresh
Testnet parameters can change; stale parameters lead to miscalculated fees or invalid outputs.
Key Takeaway

Always obtain a fresh protocol.json before estimating fees or building transactions to ensure conformity with network constraints.
