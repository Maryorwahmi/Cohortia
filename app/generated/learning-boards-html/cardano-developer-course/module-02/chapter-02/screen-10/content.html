Module 2 › Chapter 2.2 › Reading UTxO Output
Sample UTxO Output
TxHash                                 TxIx        Amount
----------------------------------------------------------------------------------------------------
a1b2c3...                                 0           1000000 lovelace + 10 NFT.TokenName
x9y8z7...                                 1           5000000 lovelace
Use the TxHash and TxIx shown to reference inputs. Note token bundles appear after lovelace; if you consume an output with tokens, include them in outputs as needed.
Which UTxO to use?
To send 2 ADA, the 5 ADA UTxO provides enough lovelace. Using the 1 ADA UTxO alone is insufficient.
Token handling
If an input contains tokens, plan outputs to return tokens as change if you intend to keep them.
Key Takeaway

Select inputs by TxHash#TxIx, sum lovelace against desired outputs and fees, and account for token bundles and minimum UTxO rules.
