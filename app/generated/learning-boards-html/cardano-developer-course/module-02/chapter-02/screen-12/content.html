Module 2 › Chapter 2.2 › Hands-on Activity
Checklist
  1. Generate payment and stake key pairs and confirm four files exist.
  2. Build base.addr with both verification keys using testnet magic 2.
  3. Copy address and request test ADA from the preview faucet.
  4. Set CARDANO_NODE_SOCKET_PATH and run cardano-cli query utxo against base.addr.
Verification
You have succeeded when utxo output shows at least one line with TxHash, TxIx and an amount corresponding to your faucet funds. If not, check node sync and faucet transaction status.
Key Takeaway

Hands-on practice consolidates the difference between files, addresses, and spendable UTxOs. Keep signing keys secure while you experiment.
