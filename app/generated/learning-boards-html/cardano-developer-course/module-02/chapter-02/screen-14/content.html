Payment Keys
Private signing keys authorize spends; protect them and back them up securely.
Address Types
Base addresses include stake credentials; enterprise addresses do not and cannot be delegated.
EUTxO Model
Funds are UTxOs. Query them and pick TxHash#TxIx pairs as inputs when you construct transactions.
Takeaway

Master key handling, address construction, and UTxO inspection to build correct transactions and protect funds during development.
