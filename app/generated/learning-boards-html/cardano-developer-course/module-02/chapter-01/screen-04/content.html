Module 2 › Chapter 2.1 › Roles & Relationship

cardano-node

Runs continuously, connects to peers, downloads and validates every block, and stores the database. It creates a socket file that other tools use to communicate.

• Persistent database for blocks and chain state.
• Exposes node.socket for local IPC.
• Must be running for CLI operations that query or submit transactions.

cardano-cli

A command-line interface for asking the node for data and constructing actions like transactions, queries, and address management. The CLI requires the node's socket path and the correct network magic.

• Sends requests over the socket to the running node.
• Builds raw transactions that the node can submit.
• Does not maintain chain data itself.
Example

Run cardano-cli query tip after starting a node to see syncProgress and the current block number returned by the node.

Common Mistake

Trying to use CLI commands without a running node or without setting the CARDANO_NODE_SOCKET_PATH leads to connection errors.

Key Takeaway

The node is the source of truth; the CLI is the tool that controls and queries it. Both are required for development.
