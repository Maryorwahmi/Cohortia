Module 2 › Chapter 2.1 › Start Command

Command

cardano-node run \
  --topology ~/cardano-node-preview/topology.json \
  --database-path ~/cardano-node-preview/db \
  --socket-path ~/cardano-node-preview/node.socket \
  --host-addr 127.0.0.1 \
  --port 3001 \
  --config ~/cardano-node-preview/config.json
This explicit command ensures the node uses the intended config and stores its database and socket where you expect them.

Parameter meanings

  • --topology: peer list used for initial connectivity.
  • --database-path: where blocks are written and validated.
  • --socket-path: IPC file other tools use to talk to the node.
  • --config: runtime and protocol settings that shape node behavior.
Misconception

Defaults may vary across environments; prefer explicit paths when running nodes for development to avoid accidental overlaps.

Check

Confirm node.socket appears in the given path and that the terminal shows peers and syncing progress after start.
