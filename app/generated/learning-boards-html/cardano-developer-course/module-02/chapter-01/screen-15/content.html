Module 2 › Chapter 2.1 › Key Concepts
Network Magic

Numeric network identifier; must match across node and CLI to avoid mismatches.

Config Files

genesis.json, topology.json and config.json define the network, peers and runtime settings; keep them consistent.

Socket Path

The node's IPC file; set CARDANO_NODE_SOCKET_PATH to this file so CLI can connect to the node.

Final Summary

Before running development workflows, confirm binaries, configs, network magic and socket path are aligned and the node is fully synced. Keep your node protected from public exposure unless properly firewalled.
