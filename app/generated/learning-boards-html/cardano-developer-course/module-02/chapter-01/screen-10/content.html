Module 2 › Chapter 2.1 › Verify Sync

Verification command

export CARDANO_NODE_SOCKET_PATH=~/cardano-dev/preview-node/node.socket
cardano-cli query tip --testnet-magic 2
# Look for: "syncProgress": "100.00"
Run this in a new terminal while the node continues running. The socket environment variable is required so the CLI can find the node's IPC file.

Reading the output

The returned JSON includes block number and syncProgress. If syncProgress is 100.00, the node is fully synced and ready for CLI operations that depend on the current chain state.
Troubleshoot

If you see a network magic mismatch error, ensure the --testnet-magic value matches the network configured in the node's config.json and genesis.json.

Key Takeaway

A single CLI command gives a reliable sync verification. Always confirm syncProgress before building further workflows.
