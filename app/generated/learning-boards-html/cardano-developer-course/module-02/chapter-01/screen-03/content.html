Module 2 › Chapter 2.1 › Practical Outcomes

How you'll demonstrate readiness

Practical checks • Repeatable
Install

Binaries are executable and invoke cardano-node --version and cardano-cli --version successfully.

Config

Directory contains genesis.json, topology.json, and config.json matching the chosen network magic.

Sync Verify

cardano-cli query tip returns syncProgress: 100.00 when your node is fully synced.

Key Takeaway

Concrete checks — version, config files, socket present, and a verified tip — show your node is usable for development.
