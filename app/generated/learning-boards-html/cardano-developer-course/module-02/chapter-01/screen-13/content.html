Module 2 › Chapter 2.1 › Activity

Steps

1. Create directory: mkdir -p ~/cardano-dev/preview-node
2. Place binaries and mark executable: chmod +x cardano-node cardano-cli; move to /usr/local/bin
3. Put genesis.json, topology.json, config.json into ~/cardano-dev/preview-node
4. Start the node using explicit --topology, --database-path, --socket-path, --host-addr, --port and --config flags

Verification

# In a new terminal
export CARDANO_NODE_SOCKET_PATH=~/cardano-dev/preview-node/node.socket
cardano-cli query tip --testnet-magic 2
# Expect syncProgress: 100.00 when done
If something goes wrong

Check for network magic mismatches, disk space issues, socket presence and peer connectivity using the node logs and the topology.json file.

Key Takeaway

Follow this repeatable sequence to set up and verify a preview node; the same pattern applies to other networks with their respective config files and testnet magic.
