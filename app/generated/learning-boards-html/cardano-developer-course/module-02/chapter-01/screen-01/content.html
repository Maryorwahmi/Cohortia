Setting Up Your Development Environment

Install and configure the node and CLI, prepare the network files, and begin synchronization to a testnet.

16:9 HD Classroom

This chapter shows how the cardano-node maintains a local blockchain and how the cardano-cli sends commands to that node. You will learn how to place binaries, prepare genesis.json, topology.json and config.json, start a node with a socket path, and check sync progress with the CLI.

Why it matters: without a synced node you cannot construct valid transactions, query on-chain state reliably, or test integrations. A local node gives you an authoritative, programmable view of the blockchain for development and testing.

Visual Concept — Local Node Topology
cardano-node

Maintains and validates the blockchain. Stores the database and opens a Unix socket for CLI communication.

Database: db/ • Socket: node.socket • Runs: daemon process
cardano-cli

Command-line tool that constructs transactions, queries tips, and manages addresses by talking to the node over the socket path.

Usage: cardano-cli query tip --testnet-magic <magic>
Key Takeaway

Run a local node and use the CLI to interact with a synced, authoritative blockchain state before building wallets or contracts.
