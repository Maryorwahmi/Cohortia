Recommended layout

Organize one folder per network to avoid mixing files. Keep binaries in a PATH-visible folder and the node data under a db subfolder.
~/cardano-dev/preview-node/
  ├─ config.json
  ├─ genesis.json
  ├─ topology.json
  ├─ node.socket  (created when node runs)
  └─ db/
Environment

Set CARDANO_NODE_SOCKET_PATH to the node.socket path before running CLI commands in a new terminal session.

Quick shell example

export CARDANO_NODE_SOCKET_PATH=~/cardano-dev/preview-node/node.socket
cardano-cli query tip --testnet-magic 2
# Expected: syncProgress: 100.00 when fully synced
Common Mistake

Starting CLI in a shell without the environment variable set leads to socket-not-found errors even when the node is running.

Key Takeaway

A consistent directory and an exported socket path make CLI commands reliable across terminal sessions.
