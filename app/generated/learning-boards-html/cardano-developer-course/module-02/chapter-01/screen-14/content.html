Module 2 › Chapter 2.1 › Key Concepts
cardano-node

Core software that connects to the network, validates blocks and stores the blockchain locally.

cardano-cli

Command-line interface used to query the node, build transactions and manage keys by connecting via the socket.

Synchronization

The node downloads and validates all historical blocks until it reaches the current tip; necessary for authoritative queries.

Summary

Keep a running node, use the CLI pointed at the socket, and confirm syncProgress before building on top of the node.
