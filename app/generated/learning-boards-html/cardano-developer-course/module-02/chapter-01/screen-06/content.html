Module 2 › Chapter 2.1 › Config Files
genesis.json

Defines the network's initial state and parameters. It identifies the correct chain history for the node to validate.

Must match the intended network.
topology.json

Lists peers the node will attempt to connect to. Healthy peers speed up synchronization; stale peers can stall it.

Update to include reachable, healthy peers for better sync.
config.json

Contains runtime parameters like slot length and logging. It controls operational behavior and protocol details.

Use the config provided for the same network as the genesis file.
Practical Example

Place all three files into your node directory (for example ~/cardano-dev/preview-node) and reference them when running cardano-node. Mismatched files are the usual cause of network identity errors.

Common Mistake

Mixing files from different networks causes network magic mismatches and connection failures.

Pro Tip

Keep a separate directory per network (preview, preprod, mainnet) to avoid accidental file mixing.
