Learning Objectives

Skills you will demonstrate by the end of the chapter.

Bloom: Learn → Understand → Apply → Master
01
Identify components

Recognize cardano-node and cardano-cli and describe their roles in development and testing.

VERIFIED COMPETENCY MILESTONE
02

Place binaries in PATH, prepare a node directory, and set a socket path so the CLI can connect to the node.

VERIFIED COMPETENCY MILESTONE

Sync a testnet

Start cardano-node run with topology, database, socket and config to synchronize to preview; monitor until it reaches 100%.

VERIFIED COMPETENCY MILESTONE

Troubleshoot common issues

Diagnose network magic mismatches, disk space shortages, and peer connectivity problems and apply straightforward fixes.
