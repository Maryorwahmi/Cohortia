Module 2 › Chapter 2.1 › Network Magic

What it is

A numeric identifier that marks a network instance. It must be consistent across node configuration and CLI commands.

• If CLI uses a different magic than the node, queries fail with a mismatch error.
• Always check the network magic in the config files before running CLI commands.

Practical alignment

Checklist: ensure config.json and genesis.json match the intended network, pass the same numeric value to --testnet-magic, and check node logs for the declared network name.
Example Error

A mismatched magic typically reports that the CLI and node disagree about network identity. The fix is to use the correct numeric magic that matches your config files.

Key Takeaway

Network magic is a small but critical identifier. Keep the numeric value consistent across your node and CLI usage.
