Module 2 › Chapter 2.1 › Troubleshooting

Common issues

• Disk space: node cannot write new blocks if disk is full.
• Peer connectivity: stale or unreachable peers slow sync.
• Socket path & permissions: CLI cannot connect without access to node.socket.
• Network magic mismatch: CLI and node disagree on network identity.

Troubleshooting steps

  1. Check disk free space and node logs for write errors.
  2. Verify topology.json peers and update to healthy peers if needed.
  3. Confirm CARDANO_NODE_SOCKET_PATH points to an existing node.socket and permissions allow access.
  4. Ensure the CLI --testnet-magic value matches the node's network magic.
  5. Restart the node to recover from transient network issues.
Example

If sync stalls at 85%, first free disk space, then check topology.json peer health, then review logs for specific error messages before making config changes.
