Installation Steps

1. Choose binary or source
Binaries: faster. Build from source: more control and up-to-date commits.
2. Make executable & place in PATH
chmod +x cardano-node; mv cardano-node /usr/local/bin or add your bin to PATH.
3. Confirm versions
Run cardano-node --version and cardano-cli --version to ensure binaries are callable.

Quick Terminal Example

chmod +x cardano-node
chmod +x cardano-cli
mv cardano-node cardano-cli /usr/local/bin
cardano-node --version
cardano-cli --version
Misconception

Installing binaries alone is not enough — ensure the binaries match the network configuration files you will use when running the node.

Key Takeaway

Get binaries into your PATH and confirm their versions. Mismatched versions often cause runtime errors.
