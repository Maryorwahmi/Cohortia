Module 3 › Chapter 2.3 › Common transaction submission errors
Errors: Insufficient funds vs Invalid witness
Compare symptoms and remedies for common failures.
Insufficient funds
Symptom: Submission rejected citing insufficient funds. Root cause: inputs do not equal outputs plus fee. Likely mistake: change set to 0 in final tx. Fix: recompute CHANGE_LOVELACE = INPUT_LOVELACE - AMOUNT_TO_SEND - MIN_FEE and rebuild.
Invalid witness
Symptom: Transaction has invalid signature(s). Root cause: wrong signing key used (e.g., stake key instead of payment key). Fix: identify the payment key corresponding to the input address and re-sign with that payment.skey.
Debug checklist
1) Confirm UTxO amounts and TxHash#TxIx. 2) Verify protocol.json is current. 3) Recalculate fee with correct witness-count. 4) Re-sign using correct payment keys. 5) Re-submit.
