EUTxO accounting: consume inputs, create outputs
Each UTxO is referenced by TxHash#TxIx; outputs are new UTxOs created by the transaction.
UTxO query example
export CARDANO_NODE_SOCKET_PATH=~/cardano-dev/preview-node/node.socket
cardano-cli query utxo --address $(cat wallet-keys/base.addr) --testnet-magic 2
# Output: TX_HASH#TX_IX   AMOUNT_LOVELACE
Copy the TxHash#TxIx and the lovelace amount to use as input values in your draft transaction.
Practical advice
When selecting inputs, prefer a single UTxO that covers the spend to reduce witness and fee complexity. If you use multiple inputs, increase witness-count accordingly when calculating fees.
Remember: inputs are not a running balance—each is an individual box you must reference precisely in the transaction body.
