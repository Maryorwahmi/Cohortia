Safety checklist before signing
Small habit checks prevent big mistakes.
Check 1
Inputs sum equals outputs plus fee.
Check 2
Change address is controlled by you and not empty.
Check 3
Signing keys correspond to input addresses; witness count matches keys.
Pro tip

Log numerical values for inputs, outputs, fee, and change in your script so you can audit the numbers before signing and keep an immutable record for debugging.
