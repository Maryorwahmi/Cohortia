Constructing and Submitting Simple Transactions
In this guided lab you will build a raw transaction, calculate fees, sign it, and submit it using cardano-cli.
In this lesson
Build raw tx, calculate fee, sign, submit and verify.
Common pitfalls
Missing change output or wrong signing key cause rejection.
Why it matters
Deterministic control ensures security and auditability of transfers.
Transaction flow
Inputs → Build → Fee calc → Sign → Submit
Example commands are shown in later steps. You will follow a pre-funded testnet address and verify results by querying UTxOs after submission.
