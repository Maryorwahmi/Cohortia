Module 3 › Chapter 2.3 › The multi-step transaction workflow
Process: Inputs → Build → Fee → Sign → Submit
A step-by-step checklist keeps transactions deterministic and auditable.
Process Steps
  1. Query UTxOs and choose inputs (TxHash#TxIx).
  2. Build a draft transaction with --fee 0 and a placeholder change output.
  3. Query protocol parameters and calculate the minimum fee.
  4. Rebuild the transaction with the calculated fee and correct change.
  5. Sign the transaction with payment signing keys to create tx.signed.
  6. Submit the signed transaction to your node.
Key Takeaway

Break the workflow into discrete checks: inputs, draft, fee, change, sign, submit to avoid costly mistakes.

Common-mistake & Example
Mistake: Setting change output to zero and expecting the node to auto-return leftover ADA. Example calculation: if you have 10 ADA input and send 2 ADA with fee 0.17 ADA, change must be 10 - 2 - 0.17 = 7.83 ADA (7,830,000 lovelace).
Check your understanding
Question: If your inputs total 5 ADA and you send 4 ADA with a fee of 0.2 ADA, what should the change be? (Answer: 0.8 ADA = 800,000 lovelace.)
