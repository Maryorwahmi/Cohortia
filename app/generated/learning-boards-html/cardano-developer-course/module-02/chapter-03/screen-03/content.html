Bloom Progression & Practice Tasks
Structured checkpoints and concrete tasks to verify each skill level.
Learn
Explain inputs, outputs, fee roles. Task: query UTxO and record TxHash#TxIx.
Understand
Run build-raw with fee 0 to create a draft and inspect the outputs and placeholders.
Apply
Calculate minimum fee and compute change. Task: rebuild raw tx with real fee and change.
Master
Sign with payment.skey and submit. Verify balances and interpret errors when they occur.
Checkpoint
Complete the hands-on activity in the chapter to move from draft to a verified submitted transaction on testnet.
