Module 3 › Chapter 2.3 › Submitting the signed transaction
Submit and verify
Broadcast your signed tx and confirm the result on testnet.
Submit command
cardano-cli transaction submit \
  --tx-file tx.signed \
  --testnet-magic 2
After submission, query your base address UTxOs to confirm the change output is present and check the recipient address for the transfer.
Post-submit checks
  • Query your address to confirm change UTxO.
  • Query recipient address to confirm receipt.
  • Inspect error messages for insufficient funds or invalid witness.
If rejected, re-run fee calculation and validation steps. Only submit a signed tx when you are certain of the inputs and outputs.
