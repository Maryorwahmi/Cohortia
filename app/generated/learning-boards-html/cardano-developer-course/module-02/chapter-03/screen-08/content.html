Module 3 › Chapter 2.3 › Signing the transaction
Sign tx.raw with your signing keys
Signing command
cardano-cli transaction sign \
  --tx-body-file tx.raw \
  --signing-key-file wallet-keys/payment.skey \
  --testnet-magic 2 \
  --out-file tx.signed
Use the payment signing key(s) that control the UTxOs used as inputs. Keep keys secure and verify witness count alignment.
Misconception & Tip
Misconception: Any key signs a spending transaction. Correction: only the payment signing key for the input UTxO authorizes spending. Tip: confirm which vkey corresponds to the address that holds the UTxO before signing.
Example check
After signing, ensure tx.signed exists and then use transaction submit. Do not publish tx.signed before you are ready to broadcast.
