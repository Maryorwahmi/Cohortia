Lab: Construct and submit an ADA transfer
Complete the hands-on activity step-by-step and verify results.
Step checklist
  1. Query UTxO and pick input TxHash#TxIx.
  2. Create or confirm recipient address and desired amount.
  3. Get protocol parameters to protocol.json.
  4. Build raw draft with --fee 0 and placeholder change.
  5. Calculate MIN_FEE and compute change.
  6. Rebuild transaction with MIN_FEE and change and write tx.raw.
  7. Sign with payment.skey to produce tx.signed and submit.
  8. Verify balances by querying addresses.
Hands-on hints
Use a single input UTxO if possible to keep witness-count and fee calculation simple. Echo variables in your shell to avoid copy/paste errors and always check protocol.json freshness before fee calculation.
After submission, allow a short propagation window then re-query addresses to confirm on-chain results. Keep tx.draft and tx.raw files as artifacts for learning and debugging.
