Calculate minimum fee
Use calculate-min-fee with protocol.json to determine MIN_FEE.
Key command sequence
cardano-cli query protocol-parameters --out-file protocol.json --testnet-magic 2

MIN_FEE=$(cardano-cli transaction calculate-min-fee \
  --tx-body-file tx.draft \
  --tx-in-count 1 \
  --tx-out-count 2 \
  --witness-count 1 \
  --byron-witness-count 0 \
  --protocol-params-file protocol.json \
  --testnet-magic 2)
Extract the numeric value and use it to compute your change. Confirm witness-count equals number of signing keys you will supply.
Example calculation
If INPUT_LOVELACE = 10000000, AMOUNT_TO_SEND = 2000000 and MIN_FEE = 170000 then CHANGE = 10000000 - 2000000 - 170000 = 7830000 lovelace.
Common error
Using wrong witness-count or old protocol.json can understate the required fee and cause rejection as low fee. Refresh protocol parameters if in doubt.
