What to Remember
Transaction Construction
Define inputs, outputs, fee, and change explicitly so the transaction balances and is auditable.
Minimum Fee Calculation
Use protocol parameters and calculate-min-fee; fee depends on size and witness count.
Signing & Submission
Sign with payment signing keys and submit via your node. Verify results by querying UTxOs after submission.
Summary Takeaway

Practice the full build → fee → sign → submit loop until you can reproduce it reliably and debug common errors quickly.
