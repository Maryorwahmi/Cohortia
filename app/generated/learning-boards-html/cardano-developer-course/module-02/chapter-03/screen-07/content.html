Rebuild with MIN_FEE and CHANGE
Compute change and rebuild the final transaction body for signing.
Compute change
CHANGE_LOVELACE=$((INPUT_LOVELACE - AMOUNT_TO_SEND - MIN_FEE)) Use this value in --tx-out for your change address.
Rebuild command
cardano-cli transaction build-raw \
  --tx-in "$UTXO_IN" \
  --tx-out "$RECEIVER_ADDR+$AMOUNT_TO_SEND lovelace" \
  --tx-out "$SENDER_ADDR+$CHANGE_LOVELACE lovelace" \
  --fee "$MIN_FEE" \
  --out-file tx.raw
Validation checklist
  • Confirm total_inputs = total_outputs + MIN_FEE.
  • Ensure tx-in set equals the UTxOs used for fee calculation.
  • Verify change is non-negative and sent to your address.
If change is negative, you must adjust outputs or include additional inputs. Never rely on the node to auto-correct imbalance.
