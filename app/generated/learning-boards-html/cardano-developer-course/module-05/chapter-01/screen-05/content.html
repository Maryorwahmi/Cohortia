Module 5 › Chapter 5.1 › Mesh vs Lucid
Mesh SDK

SDK-style integration

  • Offers wallet connectors and utility helpers for quick integration into React apps.
  • Good for teams that prefer ready-made hooks and conventions.
  • Simplifies common tasks like UTXO selection and wallet connection state.
Mnemonic: "SDK = batteries included"
Lucid

Builder-style, type-safe

  • Emphasizes an expressive transaction builder and strong type-safety.
  • Appeals to developers who want explicit, chainable control.
  • Great for inspecting and composing low-level transaction parts.
Mnemonic: "Lucid = clear, step-by-step building"
Key Takeaway

Choose Mesh for quick integration and hooks, choose Lucid for explicit builder control. Know both to match your project's needs.
