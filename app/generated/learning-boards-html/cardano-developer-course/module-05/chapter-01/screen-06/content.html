Architecture

How the pieces connect

Frontend UI — gathers user intent and composes actions.
Wallet — holds keys and signs transactions locally.
Provider — queries chain data and submits signed transactions.
Plutus Script — validates locked funds and enforces on-chain logic.
  • Frontend uses Mesh/Lucid to build a transaction and gather metadata.
  • Wallet signs locally; never expose private keys to the frontend.
  • Provider submits signed transactions and enables status queries.
Example flow

User clicks Deposit → frontend builds tx via Mesh/Lucid → wallet signs → provider submits → frontend monitors confirmation.

Key Takeaway

Map every user action to the component responsible for it. This clarifies security and debugging paths.
