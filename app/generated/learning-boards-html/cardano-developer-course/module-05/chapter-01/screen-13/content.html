Module 5 › Chapter 5.1 › Challenges & Best Practices
Async states
Define and surface: validating, waiting-for-wallet, submitting, pending-confirmation, confirmed. Disable actions during pending states.
Error handling
Differentiate user declines from network or UTXO conflicts. Provide clear, actionable messages and safe retry paths.
Security
Never store private keys in client code. Use wallets for signing and keep provider keys off the client when possible.
Testing checklist
Simulate fragmented UTXOs, wallet rejections, and concurrent spends. Verify your UI recovers and explains outcomes to users.
