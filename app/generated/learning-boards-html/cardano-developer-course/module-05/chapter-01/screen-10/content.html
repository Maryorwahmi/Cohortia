What is collateral?

An extra UTXO provided for a transaction that calls a Plutus script. If script evaluation fails, the collateral can be consumed to cover costs.

- Must meet protocol size and value constraints.
- Wallets mark and reserve collateral UTXOs for the transaction.
- Libraries help add collateral but you must surface it in the UI.
UX note
Inform users that a collateral UTXO will be reserved and may be consumed only if the on-chain validation fails. This reduces confusion about temporary locking.
Key Takeaway

Always request and display collateral details for script interactions. Proper collateral selection prevents submission failures.
