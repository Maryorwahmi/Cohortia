Selection heuristics

  • Select fewest UTXOs that cover amount+fee when possible.
  • Consider token composition when selecting inputs carrying native assets.
  • Avoid creating many tiny change outputs to reduce future costs.
Common mistake
Not surfacing change to the user and surprising them with unexpected return amounts or many small UTXOs.

Concrete example

You want to send 3 ADA. Wallet UTXOs: 1.5, 1.7, 5 ADA. The library may choose 5 ADA and return 2 ADA as change. Show this summary and fee before signing.
Key Takeaway

Understand and display selection results. Use library helpers but validate outcomes to keep UX predictable.
