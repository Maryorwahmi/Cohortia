Module 5 › Chapter 5.1 › Transaction Building
Process
  1. Gather user intent and validate inputs.
  2. Query wallet for UTXOs and provider for protocol parameters and fees.
  3. Assemble transaction: select inputs, outputs, fee, change, and collateral if needed.
  4. Request wallet signature; wallet signs locally after user approval.
  5. Submit signed transaction via provider and monitor confirmations.
Example: lottery deposit
User inputs deposit → DApp queries wallet UTXOs → builds tx that locks funds to Plutus address and returns change → adds collateral → asks wallet to sign → submits and monitors status.
Pro tip
Show fee and change estimates before asking for a signature. This reduces user surprises and rejected signatures.
Key Takeaway

Follow a clear build→sign→submit→monitor lifecycle and surface fees, change, and collateral to users early.
