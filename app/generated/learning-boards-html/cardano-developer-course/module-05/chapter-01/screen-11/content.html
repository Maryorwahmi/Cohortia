Module 5 › Chapter 5.1 › Wallet Signing
Connection steps
  1. Detect wallet and request connection/permission.
  2. Query addresses and UTXOs needed for the transaction.
  3. Build transaction and show fee/change/collateral summary.
  4. Request wallet to sign; handle approval or rejection.
UX checklist
  • Present fee and change before the wallet prompt.
  • Explain collateral when needed for scripts.
  • Handle declines and UTXO collisions by offering retry and clear error messages.
Key Takeaway

Treat wallet prompts as user-critical moments: be transparent and resilient to declines and network delays.
