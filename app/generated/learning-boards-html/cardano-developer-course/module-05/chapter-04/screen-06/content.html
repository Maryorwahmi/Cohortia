Transaction Lifecycle

Completing, Signing, and Submitting with Lucid

From draft to on-chain confirmation

import { Lucid } from 'lucid-cardano';

const sendAda = async (recipientAddress, amountAda) => {
  // ... transaction initiation ...

  try {
    const lovelaceAmount = BigInt(amountAda * 1_000_000);

    const tx = await lucid
      .newTx()
      .payToAddress(recipientAddress, { lovelace: lovelaceAmount })
      .complete(); // Handles UTXO selection, fees, change

    const signedTx = await tx.sign().complete(); // Request wallet to sign
    const txHash = await signedTx.submit(); // Submit to blockchain

    console.log(`Transaction submitted! Tx Hash: ${txHash}`);
    alert(`Transaction successful! Tx Hash: ${txHash}`);
    return txHash;
  } catch (error) {
    console.error("Error sending ADA:", error);
    alert("Transaction failed: " + error.message);
    return null;
  }
};
Key Takeaway

Lucid's `complete()`, `sign().complete()`, and `submit()` methods streamline the entire transaction lifecycle, from automatic UTXO management to secure wallet signing and blockchain broadcast.

Lucid's Automated Steps

  • 01

    .complete(): Automatically selects UTXOs, calculates fees, and creates change outputs.

  • 02

    .sign().complete(): Prompts the user's connected wallet to sign the transaction securely.

  • 03

    .submit(): Broadcasts the fully signed transaction to the Cardano network.

Common Misconception

Many developers assume they need to manually select UTXOs. Lucid's .complete() method handles this automatically, significantly reducing complexity and potential errors.
