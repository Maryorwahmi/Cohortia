Attaching Custom Metadata to Transactions with Lucid

Storing arbitrary data on-chain

import { Lucid } from 'lucid-cardano';

const sendAdaWithMetadata = async (recipientAddress, amountAda, message) => {
  // ... wallet connection check ...

  try {
    const lovelaceAmount = BigInt(amountAda * 1_000_000);
    const metadata = {
      0: { // Metadata label 0 for general messages
        msg: message,
        app: "Cohortia DApp"
      }
    };

    const tx = await lucid
      .newTx()
      .payToAddress(recipientAddress, { lovelace: lovelaceAmount })
      .attachMetadata(721, metadata) // Attach metadata with label 721
      .complete();

    const signedTx = await tx.sign().complete();
    const txHash = await signedTx.submit();
    console.log(`Transaction with metadata submitted! Tx Hash: ${txHash}`);
    return txHash;
  } catch (error) {
    console.error("Error sending ADA with metadata:", error);
    alert("Transaction with metadata failed: " + error.message);
    return null;
  }
};
Key Takeaway

Lucid's `attachMetadata()` method allows developers to include arbitrary JSON data in a transaction under a specified numerical label, enhancing on-chain data storage capabilities.

Metadata Components

  • 01

    Metadata Label: A numerical identifier (e.g., 0 for general, 721 for NFTs).

  • 02

    JSON Object: The actual data to be stored, structured as a standard JSON object.

  • 03

    Immutability: Once on-chain, metadata cannot be altered.

Use Case: DApp Messaging

A DApp could use metadata to embed a public message or a link to off-chain content directly within a transaction, making it permanently verifiable.
