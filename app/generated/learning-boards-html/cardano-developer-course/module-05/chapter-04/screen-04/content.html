The Anatomy of a Cardano Transaction

Inputs, Outputs, and the EUTXO Model

EUTXO Transaction Flow

1. Select UTXO Inputs

Existing unspent transaction outputs are chosen.

2. Define New Outputs

Specify recipients, amounts, and assets for new UTXOs.

3. Calculate Fees & Change

Fees are deducted, and remaining funds returned as change.

Key Takeaway

Cardano's EUTXO model provides a secure and predictable transaction environment, where every transaction is a deterministic transformation of UTXOs.

Why EUTXO Matters

  • Enhanced Security: Predictable transaction outcomes prevent common smart contract vulnerabilities.
  • Parallel Execution: Multiple transactions can be processed simultaneously without conflicts.
  • Deterministic Costs: Transaction fees are known before submission, improving user experience.
  • Clarity: Explicit inputs and outputs make transaction auditing straightforward.

Real-World Analogy

Imagine paying for groceries with exact change. You hand over specific bills (inputs), and the cashier gives you your items and any change (outputs). The original bills are 'spent', and new ones are 'created'.
