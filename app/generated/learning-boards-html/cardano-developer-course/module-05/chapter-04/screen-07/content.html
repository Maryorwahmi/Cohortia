Sending ADA with Mesh SDK: The Transaction Class

An alternative approach to ADA transfers

import { Transaction, MeshWallet } from "@meshsdk/core";

const sendAdaMesh = async (meshWalletInstance, recipientAddress, amountAda) => {
  // ... wallet connection check ...

  try {
    const lovelaceAmount = (amountAda * 1_000_000).toString(); // Mesh expects string

    const tx = new Transaction({ initiator: meshWalletInstance })
      .sendAssets(recipientAddress, [
        { unit: "lovelace", quantity: lovelaceAmount },
      ]);

    const unsignedTx = await tx.build(); // Build the transaction
    // ... signing and submission ...

  } catch (error) {
    console.error("Error sending ADA with Mesh:", error);
    alert("Transaction failed: " + error.message);
    return null;
  }
};
Key Takeaway

Mesh SDK's `Transaction` class and `sendAssets()` method offer a fluent API for defining ADA transfers, with a key difference in expecting string quantities for amounts.

Mesh Transaction Steps

  • 01

    Instantiate: Create new Transaction({ initiator: meshWallet }).

  • 02

    Define Output: Use .sendAssets(address, [{ unit: "lovelace", quantity: amount }]).

  • 03

    String Amounts: Remember to convert numeric amounts to strings for Mesh SDK.

Comparison: Lucid vs. Mesh

Both SDKs offer fluent APIs. Lucid uses BigInt for amounts and .complete() for auto-handling. Mesh uses strings for amounts and requires .build() before signing.
