Sending ADA with Lucid: The Builder Pattern

Initiating your first ADA transfer

import { Lucid } from 'lucid-cardano';

const sendAda = async (recipientAddress, amountAda) => {
  // ... wallet connection check ...

  try {
    const lovelaceAmount = BigInt(amountAda * 1_000_000); // ADA to Lovelace

    const tx = await lucid
      .newTx() // Start a new transaction
      .payToAddress(recipientAddress, { lovelace: lovelaceAmount })
      .complete(); // Auto UTXO selection, fees, change

    // ... signing and submission ...

  } catch (error) {
    console.error("Error sending ADA:", error);
    alert("Transaction failed: " + error.message);
    return null;
  }
};
Key Takeaway

Lucid's `newTx()` and `payToAddress()` methods provide a clear, chainable way to define the core components of an ADA transfer transaction.

Lucid Transaction Steps

  • 01

    Initialize: Call lucid.newTx() to start building.

  • 02

    Define Output: Use .payToAddress(address, { lovelace: amount }) to specify the recipient and ADA amount.

  • 03

    Convert to Lovelace: Always convert ADA to Lovelace (1 ADA = 1,000,000 Lovelace) using BigInt for precision.

Pro Tip: Lovelace Conversion

Always use BigInt for Lovelace amounts to prevent precision issues with large numbers. For example, BigInt(amountAda * 1_000_000) ensures correct conversion.
