Chapter Summary

Key Concepts: Transaction Lifecycle & Assets

Crucial elements for on-chain interactions

build() (Mesh)

A Mesh method that prepares a transaction for signing by the wallet, structuring it for network submission.

sign() / signTx()

Methods that prompt the connected user wallet to securely sign the constructed transaction using their private keys.

submit() / submitTx()

Methods that send the fully signed transaction to the Cardano blockchain via the configured provider.

Transaction Hash (Tx Hash)

A unique identifier for a submitted transaction, used to track its status on the blockchain via a block explorer.

Native Tokens

Custom tokens issued on Cardano, distinct from ADA, which can be sent alongside ADA in transactions.

Metadata

Arbitrary data (in JSON format) that can be attached to a Cardano transaction and stored on-chain under a specific label.

Chapter Summary

The transaction lifecycle involves building, signing, and submitting, with a unique transaction hash for monitoring. Native tokens and metadata extend transaction capabilities beyond simple ADA transfers, enabling rich on-chain interactions.
