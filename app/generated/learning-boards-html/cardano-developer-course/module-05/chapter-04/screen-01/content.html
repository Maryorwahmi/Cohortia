Chapter Introduction

Crafting Cardano Transactions

Empowering Your DApp with On-Chain Actions

Key Idea

Cardano transactions consume existing UTXOs as inputs and create new UTXOs as outputs, defining asset transfers and on-chain actions.

In this chapter, you will learn how to build, sign, and submit transactions on the Cardano blockchain. We'll explore how to send ADA, include native tokens, and attach custom metadata, all while leveraging the powerful abstractions provided by Mesh SDK and Lucid. This knowledge is fundamental for creating dynamic and interactive decentralized applications.
