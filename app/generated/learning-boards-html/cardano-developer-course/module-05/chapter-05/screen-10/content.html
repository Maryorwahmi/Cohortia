// Example: Locking 1 ADA at a script address with a datum
import { Data, applyParamsToScript, fromHex, toHex } from 'lucid-cardano';

// Your compiled Plutus script in hex format
const myScript = {
  type: "PlutusScriptV2",
  description: "A simple locking script",
  cborHex: "58..." // Replace with actual CBOR hex
};

// Derive script hash and address
const scriptHash = lucid.utils.scriptHash(myScript);
const scriptAddress = lucid.utils.scriptAddress(myScript);

// Define the datum (e.g., a secret code)
const myDatum = Data.to("my_secret_code");

// Build the transaction to lock funds
const txLock = await lucid
  .newTx()
  .payToContract(scriptAddress, { inline: myDatum }, { lovelace: 1000000n }) // Lock 1 ADA
  .complete();

const signedTxLock = await txLock.sign().complete();
const txHashLock = await signedTxLock.submit();

console.log(`Funds locked at script address: ${scriptAddress} with datum: ${myDatum}. Transaction ID: ${txHashLock}`);

Script & Address Derivation

The compiled Plutus script (`myScript`) is used to derive the unique `scriptAddress` where funds will be locked.

A `myDatum` (e.g., 'my_secret_code') is created using `Data.to()`. This datum is crucial for the script's validation logic.

Key Takeaway

The `payToContract` method with an `inline` datum is the primary way to lock funds and initialize a Plutus contract's state.
