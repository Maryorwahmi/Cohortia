Integrating User Wallets with Lucid

Enable your DApp to interact with user wallets for transaction signing.

Browser Wallet Support

Lucid seamlessly supports popular browser-based Cardano wallets like Nami, Eternl, and Lace, allowing for broad user compatibility.

User Permission & API

Users are prompted to grant DApp access to their wallet. Upon approval, the wallet provides an API for Lucid to request addresses and sign transactions.

Key Takeaway

Wallet integration is essential for DApps, enabling users to securely authorize transactions and interact with smart contracts.

// Enable Nami wallet and select it in Lucid
// Assuming Nami wallet is installed and connected
// window.cardano.nami is injected by the Nami browser extension
const api = await window.cardano.nami.enable();
lucid.selectWallet(api);

const walletAddress = await lucid.wallet.address();
console.log(`Connected wallet address: ${walletAddress}`);

// You can now use lucid.wallet to interact with the user's wallet
// e.g., get UTXOs, sign transactions, etc.
Pro Tip

Always handle potential errors when enabling wallets, as users might decline access or not have a wallet installed.
