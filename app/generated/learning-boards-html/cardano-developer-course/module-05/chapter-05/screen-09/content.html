Locking Funds at a Script Address with Datum

Construct a transaction to secure assets under Plutus script control with specific conditions.

1

Identify Script Address

First, obtain the derived script address from your compiled Plutus contract. This is the destination for the locked funds.

2

Define the Datum

Prepare the datum, which is the data that the Plutus script will evaluate. This could be a secret code, a hash, or any relevant information.

3

Construct Transaction Output

Use Lucid's `payToContract` method to create a transaction output sending ADA to the script address, crucially including the defined datum.

The Role of Datum

The datum is a critical piece of information for Plutus smart contracts:

  • It's arbitrary data attached to a UTXO locked at a script address.
  • It serves as the 'state' or condition that the Plutus script evaluates.
  • Without a datum, the script has no external context to validate spending conditions.
Example Scenario

For a simple gift card contract, the datum could be a unique secret code. Only by providing this exact code later can the funds be unlocked.

Key Takeaway

Locking funds with a datum is how you initialize the state of a Plutus smart contract on Cardano.
