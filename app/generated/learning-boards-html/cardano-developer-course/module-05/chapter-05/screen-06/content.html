Connecting Your DApp to the Cardano Network

Establish a connection to the blockchain using Lucid and a provider like Blockfrost.

Choosing a Provider

Lucid supports connecting to a full Cardano node, Blockfrost, or Dandelion. Blockfrost is recommended for development due to its ease of use and free tier.

Blockfrost API Key

You'll need an API key from Blockfrost. Always keep this key secure and never expose it in client-side code for production applications.

Key Takeaway

Connecting Lucid to a network provider like Blockfrost is the first step for any DApp, enabling communication with the Cardano blockchain.

// Initialize Lucid with Blockfrost provider
import { Lucid, Blockfrost } from 'lucid-cardano';

const lucid = await Lucid.new(
  new Blockfrost(
    "https://cardano-preview.blockfrost.io/api/v0", // Or Preprod/Mainnet
    "YOUR_BLOCKFROST_API_KEY"
  ),
  "Preview" // Or Preprod/Mainnet
);

console.log("Lucid connected to Cardano network.");
Security Warning

Never hardcode sensitive API keys directly into your client-side code. Use environment variables or server-side proxies for production.
