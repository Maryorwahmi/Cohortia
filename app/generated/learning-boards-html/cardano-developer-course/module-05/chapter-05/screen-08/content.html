Understanding Plutus Script Addresses and Deployment

Learn how Plutus scripts are represented and how their addresses are derived on Cardano.

Compiled Plutus Script

A Plutus script is compiled into a `.plutus` file or a JSON object (with `cborHex`). This represents the immutable contract logic.

Deriving the Script Address

From the compiled script, a unique script address is derived. This address is where UTXOs will be locked, governed by the Plutus script's logic.

Key Takeaway

Cardano's 'deployment' means locking a UTXO at a script address with a datum, making the UTXO itself the contract's state.

'Deployment' in Cardano's UTXO Model

In Cardano, a Plutus contract isn't deployed as a standalone entity. Instead, 'deployment' refers to:

  • Creating a UTXO (Unspent Transaction Output) that is locked by the script's address.
  • This UTXO must include an associated datum, which serves as the initial state or condition for the script.
  • Subsequent interactions consume and create new UTXOs, effectively modifying the contract's state.
Example

A 'gift card' contract is 'deployed' by locking ADA at its script address with a datum representing a secret code. This UTXO is the active gift card.
