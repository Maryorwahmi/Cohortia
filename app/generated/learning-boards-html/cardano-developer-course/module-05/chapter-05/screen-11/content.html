Unlocking Funds from a Script UTXO with Redeemer

Construct a transaction to spend assets governed by a Plutus script by providing the correct redeemer.

1

Find Script UTXO

Locate the specific UTXO locked by your Plutus script at its address, often by checking its associated datum.

2

Provide Redeemer

Supply the correct redeemer, which is the argument the Plutus script uses to validate the spend against the UTXO's datum.

3

Build & Submit Transaction

Construct a transaction using `collectFrom` to consume the script UTXO with the redeemer, then sign and submit it.

Redeemer's Role in Validation

The redeemer is the dynamic input that allows a Plutus script to make a spending decision:

  • It's an argument provided when spending a script UTXO.
  • The Plutus script uses the redeemer (and the UTXO's datum) to validate the transaction.
  • If the script logic evaluates the datum and redeemer as valid, the transaction proceeds; otherwise, it fails.
Common Mistake

Providing an incorrect redeemer will cause the Plutus script execution to fail, resulting in a failed transaction and potential loss of collateral.
