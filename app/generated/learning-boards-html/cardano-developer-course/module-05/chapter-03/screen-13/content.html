Best Practices

Handling Asynchronous Operations & Common Mistakes

Ensuring robust and error-free blockchain interactions.

Key Principles
  • Asynchronous Operations: Always use `async/await` or `.then().catch()` for Promises.
  • Configuration Accuracy: Double-check Blockfrost Project IDs and API URLs for network consistency.
  • User Consent: Clearly communicate wallet access requests and permissions to users.
Common Pitfalls

Forgetting `await` leads to `Promise { }`. Mismatched network configurations (e.g., mainnet URL with testnet ID) cause connection failures.

Key Takeaway

Diligence in handling asynchronous code and meticulous configuration are vital for building stable and secure Cardano DApps.

javascriptasyncExample.js
// Incorrect: Will log Promise { <pending> }
const badCall = () => {
  const result = someAsyncFunction();
  console.log(result);
};

// Correct: Will log the resolved value
const goodCall = async () => {
  try {
    const result = await someAsyncFunction();
    console.log(result);
  } catch (error) {
    console.error("Error:", error);
  }
};
