Blockchain Data

Querying General Blockchain Information

Accessing network-wide data like current slot and latest block with Lucid.

Lucid Blockchain Methods
  • `lucidInstance.currentSlot()`: Retrieves the current slot number on the blockchain.
  • `lucidInstance.provider.getLatestBlock()`: Fetches details about the most recently minted block.
  • These methods provide real-time insights into the blockchain's state and progress.
  • All operations are asynchronous.
Use Cases

Useful for DApps that need to display network status, track transaction confirmations, or implement time-sensitive logic based on blockchain progression.

Key Takeaway

Lucid allows DApps to easily query fundamental blockchain metrics, providing a comprehensive view of the network's current state.

javascriptgetBlockchainInfo.js
const getBlockchainInfo = async (lucidInstance) => {
  if (!lucidInstance) return;
  const currentSlot = await lucidInstance.currentSlot();
  console.log("Current Slot:", currentSlot);

  const latestBlock = await lucidInstance.provider.getLatestBlock();
  console.log("Latest Block Hash:", latestBlock.hash);
};
