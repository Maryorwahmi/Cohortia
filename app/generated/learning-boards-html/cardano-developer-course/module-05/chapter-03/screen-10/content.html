Querying Wallet Information with Lucid

Accessing addresses, UTXOs, and assets from a connected wallet.

Key Query Methods
  • `lucidInstance.wallet.address()`: Retrieves the connected wallet's change address.
  • `lucidInstance.wallet.getUtxos()`: Fetches all Unspent Transaction Outputs (UTXOs) held by the wallet.
  • `lucidInstance.wallet.getAssets()`: Gets the total balance of ADA and native tokens.
  • All methods are asynchronous and require `await`.
Why it Matters

Understanding UTXOs and assets is crucial for building transactions and accurately displaying a user's on-chain holdings within your DApp.

Key Takeaway

Lucid provides straightforward asynchronous methods to access comprehensive information about a connected user's wallet.

javascriptgetWalletInfo.js
const getWalletInfo = async (lucidInstance) => {
  if (!lucidInstance || !lucidInstance.wallet) {
    console.error("Lucid not initialized or wallet not connected.");
    return;
  }
  const address = await lucidInstance.wallet.address();
  console.log("Change address:", address);

  const utxos = await lucidInstance.wallet.getUtxos();
  console.log("Wallet UTXOs:", utxos);

  // To get total balance (ADA + native tokens)
  const assets = await lucidInstance.wallet.getAssets();
  console.log("Wallet Assets:", assets);
};
