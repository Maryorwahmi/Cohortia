Key Concepts: Foundations

Essential terms for connecting to Cardano.

Blockchain Provider Initialization

Setting up Mesh or Lucid to connect to a specific Cardano network (e.g., Preprod) using a service like Blockfrost.

`window.cardano`

A global JavaScript object injected by Cardano browser wallets, providing an API for DApps to interact with the wallet.

`enable()`

A method on the `window.cardano` object that prompts the user to grant the DApp permission to connect to their wallet.

Summary Takeaway

Connecting your DApp to Cardano involves initializing a provider, accessing the `window.cardano` object, and using `enable()` to get user consent for wallet interaction.
