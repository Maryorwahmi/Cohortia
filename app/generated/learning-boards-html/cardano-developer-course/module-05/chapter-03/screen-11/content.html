Querying Wallet Information with Mesh SDK

Utilizing `useWallet` and `useAssets` hooks for React DApps.

Mesh Hooks for Data
  • `useWallet()`: Provides access to the connected `wallet` object for methods like `getChangeAddress()` and `getUtxos()`.
  • `useAssets()`: Automatically fetches and provides the connected wallet's assets (ADA, native tokens).
  • Simplifies reactive UI updates based on wallet data.
Convenience & Reactivity

Mesh hooks abstract away much of the manual data fetching, providing a reactive and declarative way to integrate wallet information into your React components.

Key Takeaway

Mesh SDK's `useWallet` and `useAssets` hooks are powerful tools for efficiently querying and displaying user wallet data in React DApps.

javascriptWalletInfo.js
import { useWallet, useAssets } from "@meshsdk/react";

function WalletInfo() {
  const { wallet, connected } = useWallet();
  const assets = useAssets(); // This hook fetches assets automatically

  if (!connected) return <p class="text-slate-300">Please connect your wallet.</p>;

  // Example of how these functions would be called in an interactive app
  // const getAddress = async () => {
  //   if (wallet) {
  //     const address = await wallet.getChangeAddress();
  //     console.log("Change address:", address);
  //   }
  // };

  return (
    <div>
      <p class="text-slate-300">Wallet connected: {connected ? 'Yes' : 'No'}</p>
      {assets && (
        <div>
          <h3 class="text-slate-200">Wallet Assets:</h3>
          <p class="text-slate-300">ADA: {assets.lovelace / 1_000_000} ADA</p>
        </div>
      )}
    </div>
  );
}
