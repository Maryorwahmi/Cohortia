Core Concept

DApp to Blockchain Communication

Understand the two primary interaction types for your DApp to function on Cardano.

Key Interaction 1

Blockchain Provider Connection: Your DApp connects to a service (e.g., Blockfrost) to query on-chain data and submit transactions. This is the DApp's 'eyes and mouth' to the blockchain.

Key Interaction 2

User Wallet Connection: Your DApp connects to a user's browser wallet (e.g., Nami) to request transaction signing. This keeps private keys secure on the user's device.

Key Takeaway

Successful DApp operation relies on establishing both a blockchain provider connection and a secure user wallet connection.
