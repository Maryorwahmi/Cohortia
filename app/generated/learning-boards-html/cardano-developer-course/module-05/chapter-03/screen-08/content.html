Lucid Wallet Integration

Selecting a Wallet with Lucid

Integrating the enabled wallet API into your Lucid instance.

How `selectWallet` Works
  • After `window.cardano.enable()` returns the wallet `api`.
  • `lucidInstance.selectWallet(api)` tells Lucid to use this specific wallet.
  • Lucid then routes all wallet-related calls through this connected API.
  • This is essential for fetching wallet data and signing transactions.
Common Pitfall

Attempting to call `selectWallet` before `lucidInstance` is fully initialized or if `window.cardano.enable()` fails will lead to errors.

Key Takeaway

`lucid.selectWallet()` is the bridge that connects your DApp's Lucid instance to the user's securely enabled browser wallet.

javascriptconnectWallet.js
import { Lucid } from 'lucid-cardano';

const connectWallet = async (lucidInstance) => {
  if (!window.cardano) {
    alert("Cardano wallet not found! Please install Nami, Eternl, or Lace.");
    return null;
  }

  try {
    const api = await window.cardano.enable();
    lucidInstance.selectWallet(api); // Tell Lucid to use this wallet API
    console.log("Wallet connected:", await lucidInstance.wallet.address());
    return lucidInstance.wallet;
  } catch (error) {
    console.error("Failed to connect wallet:", error);
    return null;
  }
};
