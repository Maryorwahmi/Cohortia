Mesh SDK Implementation

Connecting to a Blockchain Provider with Mesh SDK

Configure MeshProvider with Blockfrost for React applications.

MeshProvider Configuration
  • Wrap your DApp components with `MeshProvider`.
  • Specify `networkId` (e.g., `0` for testnet, `1` for mainnet).
  • Pass a `BlockfrostProvider` instance with your Project ID to `blockchainProvider`.
  • Mesh hooks within this context will automatically use this connection.
Pro Tip

Mesh SDK's `MeshProvider` simplifies global state management for blockchain interactions, making it ideal for complex React DApps by centralizing connection logic.

Key Takeaway

Mesh SDK provides a React-friendly, declarative way to connect your DApp to a blockchain provider, streamlining development.

javascriptApp.js
import { MeshProvider } from "@meshsdk/react";
import { BlockfrostProvider } from "@meshsdk/core";

function App() {
  return (
    <MeshProvider
      networkId="0" // 0 for testnet, 1 for mainnet
      blockchainProvider={
        new BlockfrostProvider(process.env.VITE_BLOCKFROST_PROJECT_ID_PREPROD)
      }
    >
      {/* Your DApp content and wallet connector components go here */}
    </MeshProvider>
  );
}
