Wallet Interaction

Connecting to a User's Browser Wallet

Leveraging `window.cardano` for DApp-wallet communication.

Key Concepts
  • `window.cardano` object: Injected by browser wallets (Nami, Eternl, Lace) for DApp interaction.
  • `enable()` method: Prompts the user to grant DApp permission to connect to their wallet.
  • Asynchronous operation: `enable()` returns a Promise, requiring `await` for the wallet API.
Security Note

The `enable()` method ensures user consent, keeping private keys secure within the wallet and never exposed to the DApp.

Key Takeaway

The `window.cardano` object and its `enable()` method are the standard for securely initiating wallet connections in Cardano DApps.

javascriptconnectWallet.js
const connectWallet = async (lucidInstance) => {
  if (!window.cardano) {
    alert("Cardano wallet not found! Please install Nami, Eternl, or Lace.");
    return null;
  }

  try {
    // Request permission to connect
    const api = await window.cardano.enable();
    lucidInstance.selectWallet(api); // Tell Lucid to use this wallet API
    console.log("Wallet connected:", await lucidInstance.wallet.address());
    return lucidInstance.wallet;
  } catch (error) {
    console.error("Failed to connect wallet:", error);
    return null;
  }
};
