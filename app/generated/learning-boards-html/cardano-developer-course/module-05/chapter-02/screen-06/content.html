Initializing Your Project

Creating the basic structure for your Cardano DApp.

Why `package.json` Matters

This file is your project's manifest, listing dependencies, scripts, and metadata. It's essential for project management and collaboration.

Key Takeaway

The `npm init -y` command is your starting point, generating the `package.json` file that defines your DApp's structure and dependencies.

# 1. Create a new project directory
mkdir my-cardano-dapp

# 2. Navigate into the directory
cd my-cardano-dapp

# 3. Initialize a new npm project
npm init -y
