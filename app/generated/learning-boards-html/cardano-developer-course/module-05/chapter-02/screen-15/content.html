Key Concepts

Connecting to the Cardano Ecosystem

Blockfrost

A blockchain provider offering API endpoints for DApps to interact with the Cardano blockchain.

Testnet

A separate Cardano blockchain instance (e.g., Preprod) used for development and testing with valueless assets.

Faucet

A service that dispenses free test ADA on a testnet, allowing developers to test DApps without real funds.

Summary Takeaway

Blockchain providers, testnets, and faucets are fundamental components for connecting your DApp to Cardano and conducting risk-free development and testing.
