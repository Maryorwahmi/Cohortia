Navigating a Frontend DApp's Basic Structure

Familiarizing yourself with the typical layout of a Cardano DApp.

`src/` Directory

Contains your main application logic, components (e.g., `App.js`), and entry points (e.g., `index.js`).

`node_modules/` & `.env`

`node_modules/` holds installed libraries; `.env` stores environment variables like API keys.

Key Takeaway

A clear project structure, separating source code, static assets, and configuration, is vital for DApp maintainability and scalability.

# Basic Frontend DApp Structure
my-cardano-dapp/
├── node_modules/ # Installed libraries
├── public/
│   └── index.html # Main HTML entry point
├── src/
│   ├── App.js (or App.tsx) # Main application component
│   ├── index.js (or index.tsx) # Application entry point
│   └── components/ # Reusable UI components
│       └── WalletConnect.js
├── .env # Environment variables
├── package.json # Project manifest
├── package-lock.json (or yarn.lock) # Exact dependency versions
└── README.md
