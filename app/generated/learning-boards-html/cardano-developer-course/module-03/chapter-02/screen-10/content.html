Sign
cardano-cli transaction sign \
  --tx-body-file matx.raw \
  --signing-key-file payment.skey \
  --script-file policy.script \
  --testnet-magic 1 \
  --out-file matx.signed
If your policy requires a separate policy signing key, include it as an additional --signing-key-file argument. Signing produces matx.signed, the file you will submit to the network.
Security
Never commit .skey files to version control. For production, use hardware wallets or secure key management.
Check
Confirm matx.signed exists before attempting submission. The signing step must match your earlier witness-count.
