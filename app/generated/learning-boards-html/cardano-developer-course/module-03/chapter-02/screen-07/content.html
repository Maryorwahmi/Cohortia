Build Draft
TOKEN_NAME="4d79546f6b656e"
ASSET="$POLICY_ID.$TOKEN_NAME"
AMOUNT_TO_MINT=1000

cardano-cli transaction build-raw \
  --fee 0 \
  --tx-in $TX_IN \
  --tx-out "$(cat payment.addr) + 100000000 lovelace + $AMOUNT_TO_MINT $ASSET" \
  --mint "$AMOUNT_TO_MINT $ASSET" \
  --minting-script-file policy.script \
  --out-file matx.draft
The draft contains the mint instruction but not the correct fee or change. Use it to compute fees and MinUTXO before rebuilding the final raw transaction.
Checklist
  • Use the same ASSET string for --mint and --tx-out.
  • Keep fee at 0 for the draft build.
  • Include --minting-script-file with the policy script.
Warning
Do not reuse a different token hex between draft and final build. Mismatches will break the final transaction identity.
