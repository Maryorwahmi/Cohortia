Step
Generate policy ID
Run cardano-cli transaction policyid --script-file policy.script > policyID and read POLICY_ID=$(cat policyID).
Token name hex
Convert a readable name to hex and keep it consistent. Example: "MyToken" → 4d79546f6b656e.
Pro Tip

Store both policyID and token name hex in environment variables to avoid accidental string mismatches when building transactions.

Concrete example
# Generate Policy ID
cardano-cli transaction policyid --script-file policy.script > policyID
POLICY_ID=$(cat policyID)
echo "Your Policy ID is: $POLICY_ID"

# Token name hex
TOKEN_NAME="4d79546f6b656e"  # "MyToken" in hex
ASSET="$POLICY_ID.$TOKEN_NAME"
AMOUNT_TO_MINT=1000
Common mistake
Using an outdated policyID or a mismatched token hex between draft and final build causes asset identity errors at submission.
