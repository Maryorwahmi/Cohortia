# Then verify UTXO
cardano-cli query utxo --address $(cat payment.addr) --testnet-magic 1
Search the returned UTXO list for an output that contains your POLICY_ID.TokenHex and confirm the ADA amount meets MinUTXO.
What to check
  • Transaction inclusion or returned error on submit.
  • Presence of POLICY_ID.TokenHex in a UTXO line.
  • ADA amount is at least the MinUTXO you computed.
Key Takeaway
Successful minting is validated by seeing the asset in your UTXO set along with the required ADA; use the tx hash to trace progress.
