Definition
Minting policy script
A JSON document that lists conditions required for minting or burning tokens. It does not contain private keys, only key hashes or rules.
Analogy
Treat the policy as a law: transactions must satisfy the law to create or remove assets.
Key Takeaway

Policies declare the rules for minting; choose signatures or time locks depending on whether you want fixed supply or future minting ability.

Example policy.script
{
  "type": "all",
  "scripts":
  [
    {
      "type": "sig",
      "keyHash": "$(cat payment.vkey.hash)"
    }
  ]
}
Why it matters
Without a correct policy, the mint step will fail or leave tokens unburnable.
Common mistake
Embedding the key instead of the key hash or using an out-of-date key hash will invalidate the script.
