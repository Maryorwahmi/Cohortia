Terminal
cardano-cli query utxo --address $(cat payment.addr) --testnet-magic 1 > utxo.out
# Parse utxo.out to find a UTXO with enough lovelace
# Example line:
# 9a8b7c6d...     0     100000000 lovelace + 1000000 MyToken
# Use: TX_IN="9a8b7c6d...#0"
# ADA_IN="100000000"
Why it matters
A single UTXO must cover fees plus the minimum ADA attached to the token output; otherwise the build or submit will fail.
Selection checklist
  • Confirm lovelace amount in candidate UTXO.
  • Account for MinUTXO increase when adding native assets.
  • Reserve enough for estimated fee before building final tx.
Common mistake
Trying to combine many tiny UTXOs without consolidating; pick or consolidate into one UTXO that meets the minima.
