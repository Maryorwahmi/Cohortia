Minting Policy
Script that defines who and when tokens can be minted or burned.
Policy ID & Token Hex
Policy ID is the script hash; token names must be hex-encoded as POLICY_ID.TokenHex.
MinUTXO & Fees
Compute minimum ADA for token outputs and calculate fees from the draft transaction before finalizing.
