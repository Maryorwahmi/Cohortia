Fee Calculation
Estimate the network fee
cardano-cli transaction calculate-min-fee \
  --tx-body-file nft_matx.draft \
  --tx-in-count 1 \
  --tx-out-count 1 \
  --witness-count 2 \
  --byron-witness-count 0 \
  --protocol-params-file protocol.json \
  --testnet-magic 1 > nft_fee.txt
FEE_NFT=$(cat nft_fee.txt | awk '{ print $1 }')
echo "Calculated NFT fee: $FEE_NFT lovelace"
Adjust witness-count to reflect the signing keys and scripts you will use when signing. Save and inspect nft_fee.txt to ensure the fee looks reasonable.
Compute change
Derive the change output so the transaction balances before final build.
CHANGE_ADA_NFT=$(( $ADA_IN - $FEE_NFT - $MIN_ADA_REQUIRED_NFT ))
if [ $CHANGE_ADA_NFT -lt 0 ]; then echo "Error: Insufficient ADA for NFT transaction."; exit 1; fi
Key Takeaway
Always validate CHANGE_ADA_NFT is non-negative before building the final transaction to avoid failed builds or insufficient funds at sign time.
