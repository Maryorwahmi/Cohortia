Calculation
Compute minimum ADA for the NFT output
MIN_ADA_REQUIRED_NFT=$(cardano-cli transaction calculate-min-required-utxo \
  --tx-out "$(cat payment.addr) + 0 lovelace + 1 $NFT_FULL_ASSET" \
  --protocol-params-file protocol.json)
echo "Minimum ADA required for NFT UTXO: $MIN_ADA_REQUIRED_NFT"
Use the returned MIN_ADA_REQUIRED_NFT value in your final --tx-out so the UTXO contains both the NFT and the required lovelace.
Why this matters
If you underfund an output, the transaction will be invalid or the resulting UTXO may be unusable by wallets expecting min ADA. Always recompute after adding metadata, since metadata size influences required lovelace when assets are present.
Key Takeaway
Include MIN_ADA_REQUIRED_NFT in the final tx-out to ensure the NFT UTXO is valid and wallet-friendly.
