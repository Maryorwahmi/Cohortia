Learning Objectives
Bloom band: Learn → Understand → Apply → Master
01 Prepare Metadata
Create CIP-25 JSON, include ipfs:// URI and files array so explorers display your media and attributes.
Mnemonic: 721 namespace maps policy → hex asset name → metadata object.
VERIFIED COMPETENCY MILESTONE
02 Mint a Single NFT
Build a transaction with --mint "1 POLICY.HEXNAME" and supply the metadata JSON via --metadata-json-file.
Mnemonic: Quantity 1 equals non-fungible.
VERIFIED COMPETENCY MILESTONE
03 Verify on Explorer
Search the payment address or tx to confirm the CIP-25 metadata is parsed and image displays.
Mnemonic: explorer parsing reveals name, image, and attributes.
VERIFIED COMPETENCY MILESTONE
04 Send and Receive
Use the same build-raw, sign, submit flow. Include the NFT and required min ADA in the tx-out for the recipient.
Mnemonic: NFT moves as a native asset with quantity one.
VERIFIED COMPETENCY MILESTONE
