Process Flow
Send an NFT using cardano-cli
1. Query your address to find the UTXO containing the NFT.
cardano-cli query utxo --address $(cat payment.addr) --testnet-magic 1
# Identify NFT_TX_IN="nft_txhash#nft_txix" with the 1 $NFT_FULL_ASSET entry
2. Compute MIN_ADA for the recipient address when sending an NFT to a fresh address.
3. Build a raw transaction that consumes NFT_TX_IN and produces two outputs: recipient + NFT and change back to you.
cardano-cli transaction build-raw \
  --fee 0 \
  --tx-in $NFT_TX_IN \
  --tx-out "$(cat recipient.addr) + $MIN_ADA_REQUIRED_FOR_NFT_UTXO lovelace + 1 $NFT_FULL_ASSET" \
  --tx-out "$(cat payment.addr) + $CHANGE_ADA_AFTER_FEE lovelace" \
  --out-file send_nft.draft
Misconception
No special NFT transfer command exists; it is the same cardano-cli transaction flow as ADA and native tokens.
Key Takeaway
Identify the NFT UTXO, compute recipient min ADA, build draft, calculate fee, sign, and submit — the familiar steps apply.
