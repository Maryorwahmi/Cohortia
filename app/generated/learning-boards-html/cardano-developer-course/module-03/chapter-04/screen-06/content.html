Command Walkthrough
Hex-encode and build NFT identifier
# Example assignments
NFT_ASSET_NAME_HEX="436f686f7274696147656e657369734e46542331"  # "CohortiaGenesisNFT#1"
POLICY_ID=$(cat policyID)  # From Chapter 3.2
NFT_FULL_ASSET="$POLICY_ID.$NFT_ASSET_NAME_HEX"

echo "$NFT_FULL_ASSET"
Keep NFT_FULL_ASSET as the single source of truth used in both --mint and --tx-out. Validate the metadata 721 object keys match exactly.
Example Check
Open your metadata JSON and confirm the 721 object has a key equal to POLICY_ID and inside it a key equal to NFT_ASSET_NAME_HEX. If either differs, explorers won't link the metadata to the asset.
Common mistake
Hex string copied with whitespace or newlines. Strip whitespace and use exact hex characters only.
Key Takeaway
One canonical NFT_FULL_ASSET variable prevents mismatches between the mint operation and metadata entries.
