Process Flow
Build a draft transaction for minting
cardano-cli transaction build-raw \
  --fee 0 \
  --tx-in $TX_IN \
  --tx-out "$(cat payment.addr) + 0 lovelace + 1 $NFT_FULL_ASSET" \
  --mint "1 $NFT_FULL_ASSET" \
  --minting-script-file policy.script \
  --metadata-json-file metadata.json \
  --out-file nft_matx.draft
This draft collects inputs, outputs, minting and metadata so you can compute cost. It is not signed or submitted yet.
Checklist
  • Confirm $TX_IN points to a UTXO you control and has enough ADA.
  • Confirm metadata.json contains the literal policy id and hex asset name.
  • Confirm policy.script and policyID are consistent with your signing key.
Misconception
Many think draft signing mints the asset; only submission of a fully signed tx writes to the ledger.
