Final Build
Build raw, sign, and submit
cardano-cli transaction build-raw \
  --fee $FEE_NFT \
  --tx-in $TX_IN \
  --tx-out "$(cat payment.addr) + $CHANGE_ADA_NFT lovelace + 1 $NFT_FULL_ASSET" \
  --mint "1 $NFT_FULL_ASSET" \
  --minting-script-file policy.script \
  --metadata-json-file metadata.json \
  --out-file nft_matx.raw

cardano-cli transaction sign \
  --tx-body-file nft_matx.raw \
  --signing-key-file payment.skey \
  --script-file policy.script \
  --testnet-magic 1 \
  --out-file nft_matx.signed

cardano-cli transaction submit --tx-file nft_matx.signed --testnet-magic 1
Signing requires the keys that satisfy the minting policy as well as the input owner's payment key. If your policy uses time-locks or other conditions, ensure they are satisfied at submission time.
Checks & Troubleshooting
  • Confirm nft_matx.signed exists and lists required witnesses.
  • If submission fails, check insufficient fee, missing witness, or stale TX_IN references.
  • Inspect metadata parsing on explorer after the tx is included.
Key Takeaway
The mint completes only after a valid signed tx is submitted and included in a block; ensure all signing keys and conditions are present before submission.
