Verification Steps
Confirm metadata and media render correctly
  1. Search your payment address or transaction hash on a testnet explorer.
  2. Inspect the transaction outputs and find the minted asset entry equal to POLICY_ID.HEX_ASSET_NAME.
  3. Confirm the explorer parsed the 721 metadata and displays the name, image and attributes.
  4. If the image is missing, verify the IPFS CID is accessible and pinned.
Troubleshoot
If metadata is present but not linked, the policy id or hex asset name likely differs between metadata.json and your --mint argument.
Concrete check
Confirm the 721 object key equals the policy id string and nested key equals the hex asset name used in the minted asset. Only then will wallets and explorers associate the metadata with the token.
Key Takeaway
Verification ensures the metadata you authored is the one users will see; it validates both on-chain attachment and off-chain media availability.
