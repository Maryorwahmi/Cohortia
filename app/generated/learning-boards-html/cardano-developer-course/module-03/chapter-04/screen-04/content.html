Core Concept
NFT = Native Asset (1) + CIP-25 Metadata
Understand the exact mapping in the 721 JSON and why hex-encoding matters.
• 721 namespace: top-level key that maps policy ID → hex asset name → metadata object.
• Image: use ipfs://CID so the media is content-addressed and discoverable by explorers.
• Quantity: mint with "1" to keep the asset non-fungible; more than one unit makes it fungible.
• Common mistake: mismatching policy or hex asset name between metadata and mint command.
Analogy
Think of the policy id as a collection address and the hex asset name as the token's serial number — both must match the label in the metadata.
Example Metadata Snippet
{
  "721": {
    "YOUR_POLICY_ID_HERE": {
      "YOUR_HEX_ASSET_NAME_HERE": {
        "name": "Cohortia Genesis NFT #1",
        "image": "ipfs://QmYh7M.../genesis_nft_1.png",
        "mediaType": "image/png",
        "description": "The very first NFT minted by a Cohortia student!"
      }
    }
  }
}
Check
Ensure the policy id string and hex asset name are identical between the JSON and the --mint flag.
Key Takeaway
Correct mapping is required for wallets and explorers to associate metadata with the minted token.
