Module 3 › Chapter 3.3 › Inspect NFT metadata
Step-by-step
  1. Open the NFT's details page and find the transaction metadata.
  2. Locate the 721 object and expand the policy id entry.
  3. Find the hex asset name and the asset's name/image fields inside it.
  4. Confirm the mint transaction shows quantity of one for that asset.
  5. Follow the image URI (IPFS recommended) to verify media availability.
Concrete example
You discover a metadata object where 721 -> a1b2... -> 4d795... holds name: "Ape #1234" and image: "ipfs://QmHash/ape.png". The mint transaction mints 1 unit under policy a1b2..., and the IPFS link resolves. You can now say with confidence: this token is unique (quantity 1) under policy a1b2... and is owned by the address holding the UTXO that received it.
Quick check

If the IPFS link fails, flag durability risk even though metadata is on-chain.
