Introduction to NFTs on Cardano

Learn how Cardano represents NFTs as native assets, why CIP-25 metadata matters, and how ownership and uniqueness are proven on-chain.

Native Asset
A first-class ledger asset. Quantity controls fungibility.
CIP-25
Standard JSON metadata that makes an asset recognizable as an NFT.
Ownership
NFTs live in UTXOs; private keys control transfers.
Why start here

Understanding the native-asset approach is essential before building or inspecting Cardano NFTs. It explains cost, security, and interoperability differences.

NFT Concept Map
Policy ID → Asset Name → CIP-25 metadata
In this lesson
Identity
Policy ID plus Asset Name form a unique asset fingerprint used to link on-chain metadata and enforce minting rules.
Metadata
CIP-25 metadata stored in the mint transaction makes attributes immutable and discoverable by wallets.
Media
Image links are usually IPFS URIs. The link is on-chain; the file itself is typically off-chain.
Ownership
The UTXO that holds the NFT determines who controls it; private keys control UTXOs.
