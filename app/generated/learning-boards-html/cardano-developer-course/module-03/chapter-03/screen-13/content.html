Module 3 › Chapter 3.3 › Assessment: explain NFT non-fungibility
How to structure your answer
  1. Define non-fungibility in Cardano terms: supply 1 + Policy ID.Asset Name uniqueness.
  2. Show on-chain evidence: cite the mint transaction and metadata 721 object.
  3. Explain ownership: the UTXO holding the token and key control.
  4. Discuss media: point to image URI and storage scheme (IPFS vs centralized).
Example answer snippet
"This token is non-fungible because the mint transaction shows a single unit minted under policy a1b2..., and the CIP-25 metadata under 721 → a1b2... → asset_name contains the name and an ipfs:// image link, which confirms the asset's identity. Ownership is given to the address holding the UTXO containing the token."
Assessment tip

Always include a specific policy id or metadata field to make your answer verifiable.
