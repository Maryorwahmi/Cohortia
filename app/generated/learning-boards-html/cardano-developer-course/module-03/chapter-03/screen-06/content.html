Module 3 › Chapter 3.3 › Uniqueness & Ownership
Five-step flow
1
Policy ID
Scopes the collection and minting rules.
2
Asset Name
Unique key under the policy that identifies the asset.
3
Quantity = 1
Minting policy enforces a single unit for non-fungibility.
4
On-chain metadata
CIP-25 object in the mint transaction stores identity and attributes.
5
UTXO custody
The token lives in a UTXO; the private key for the address controls transfer.
Concrete scenario
Imagine minting "Ape #123" under policy a1... with a minting script that allows a single mint. The mint transaction includes CIP-25 metadata naming the ape and linking to IPFS. The minted token is sent to an address you control. That UTXO now contains the NFT; selling it requires spending that UTXO to a new address.
Misconception

Policy ID controls minting rules but not ownership. Ownership is determined by who can spend the UTXO holding the token.
