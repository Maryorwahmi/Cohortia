Module 3 › Chapter 3.3 › Common Mistakes
Top mistakes and fixes
Missing policy link: Ensure the policy id in metadata matches the mint policy hash. Fix: double-check hashes before publishing.
Unpinned media: Use IPFS with pinning and redundant files to avoid broken images.
Policy vs ownership confusion: Policies only govern mint/burn. Ownership is UTXO-based.
Accidental multi-mints: Test policies on testnet to ensure quantity limits behave as intended.
Unreadable asset names: Include a human-readable name inside the asset metadata so wallets can display it.
Concrete action
Before mainnet mint: run a test mint, verify CIP-25 object, confirm IPFS pins, and document where files are stored. This prevents common failures and preserves collector trust.
