Verification Milestones
Locate 721: Identify the 721 top-level key inside the transaction metadata and find the policy id object beneath it.
Confirm asset link: Find the asset name hex key and the associated name, image, and attributes entries.
Check supply rule: Inspect the minting policy or transaction to verify that only one unit was minted.
Assess media storage: Note whether the image URI is an IPFS link or a centralized URL and consider durability risk.
Mnemonic & Quick Tips
PAT — Policy, Asset, Token metadata. Use it as a checklist when inspecting NFTs.
Remember: the link in metadata is on-chain; the file is usually on IPFS. Always check both.
