Module 3 › Chapter 3.3 › Media storage & durability
Storage options
IPFS: decentralized, content-addressed, use pinning for persistence.
Decentralized hosts: similar benefits when multiple nodes retain the content.
Centralized hosting: easier but introduces single-point-of-failure risk.
Practical checklist
  • Include IPFS hash in metadata where possible.
  • Pin content with at least one trusted pinning service.
  • Provide multiple file sizes or mirrored URIs in the files array.
Concrete example
Add a files array to CIP-25 with entries for original, thumbnail, and alternate CDN mirror. Each entry includes a URI and mediaType so wallets can choose appropriate resolution.
Misconception
Putting a URL in metadata without pinning is not a guarantee of long-term availability even though the URL is recorded on-chain.
