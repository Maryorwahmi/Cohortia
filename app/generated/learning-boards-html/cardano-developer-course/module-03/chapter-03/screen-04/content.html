Module 3 › Chapter 3.3 › What is an NFT on Cardano?
Definition

Native asset + metadata = NFT

On Cardano, non-fungibility comes from a ledger-native combination: a quantity of one for a unique Policy ID.Asset Name pair, plus structured metadata that names and describes the token.

Concrete example
A collectible "Ape #1234" minted under policy a1b2... with quantity 1 and CIP-25 metadata linking to ipfs://Qm...
Common misconception
The metadata link is on-chain; the image file usually lives off-chain. Treat the link as the token's pointer, not the media container itself.
Key Takeaway

An NFT's identity is ledger-native: supply 1 and metadata together create the collectible's verifiable identity.

Try this

When you inspect an NFT, read the policy id and asset name, then locate the CIP-25 object to confirm name and image URI. This confirms the asset's on-chain identity.
