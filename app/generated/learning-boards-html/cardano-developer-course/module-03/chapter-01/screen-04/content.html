Module 3 › Chapter 3.1 › Native assets
Definition

A native asset is a token treated by the ledger similarly to ADA. Transfers and balances are enforced by ledger rules instead of contract code.

Why this matters
Reduced attack surface for simple transfers and lower fees because no contract execution is required for basic token movement.
Common misconception
Native assets are not incompatible with smart contracts — you can layer contracts on top for advanced logic.
Concrete example

When Alice sends 10 units of a native token, the transaction consumes a UTXO that holds that token and produces a new UTXO for the recipient plus change UTXOs as needed. The ledger enforces the movement.

Key Takeaway

Treat native assets as ledger-native values that simplify transfers and reduce contract dependency.
