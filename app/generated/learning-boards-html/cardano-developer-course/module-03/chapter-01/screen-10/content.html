Module 3 › Chapter 3.1 › Multi-asset Transactions
Why bundle assets?
  • Atomicity: all asset movements occur in one transaction or not at all.
  • Lower overhead: fewer separate transactions reduce fees and complexity.
  • Simpler UX: wallets ask for one approval rather than many.
Concrete scenario
A swap can transfer ADA and two different tokens simultaneously. If any output fails validation, the whole transaction is rejected, preventing partial state changes.
Developer note
Plan outputs carefully to include required ADA "dust" and ensure wallet compatibility when bundling multiple asset types in an output.
