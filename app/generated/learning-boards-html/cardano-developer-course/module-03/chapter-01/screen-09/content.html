Steps to inspect a token
  1. Search the explorer for a known token name like SundaeSwap.
  2. Open the token detail page and find the Asset ID or fingerprint.
  3. Copy the Policy ID and check the Asset Name field and supply statistics.
  4. Review recent transactions for evidence of additional minting or burning.

Quick tip
If supply changes unexpectedly, check whether the policy allows further minting and whether keys are still active.
