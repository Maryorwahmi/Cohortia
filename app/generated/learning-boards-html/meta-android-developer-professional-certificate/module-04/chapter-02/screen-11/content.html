Work Management

Handling Existing Work with enqueueUniquePeriodicWork

Preventing Duplicate Background Tasks and Managing Policies

Unique Work Naming

Assign a unique name to your periodic work to prevent multiple instances of the same task from running concurrently.

ExistingPeriodicWorkPolicy

Defines how WorkManager handles a new request if work with the same unique name already exists.

Key Takeaway

Use enqueueUniquePeriodicWork with an appropriate ExistingPeriodicWorkPolicy to manage recurring tasks and prevent unintended duplicate executions.

ExistingPeriodicWorkPolicy Options

KEEP: If work exists, keep it and ignore the new request.

REPLACE: Cancel existing work and replace with the new request.

UPDATE: Update existing work with new parameters (if supported).
