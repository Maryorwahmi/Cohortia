Defining Your Work: The Worker Class

Encapsulating Background Logic with doWork() and Result Types

The Worker Class

An abstract class that defines the actual background work. You extend it to implement your custom logic.

doWork() Method

The main entry point for your background task. It runs on a background thread and returns a Result.

Key Takeaway

The Worker class is where your background logic lives, with doWork() returning a Result to inform WorkManager of the task's outcome.

doWork() Result Types

Result.success(): Work completed successfully.

Result.failure(): Work failed permanently; no retries.

Result.retry(): Work failed temporarily; retry later.
