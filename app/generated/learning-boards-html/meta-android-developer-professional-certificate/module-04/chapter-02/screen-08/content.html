Scheduling Work

Types of WorkRequests

Defining How and When Your Background Task Should Run

Key Takeaway

Choose OneTimeWorkRequest for single, non-repeating tasks and PeriodicWorkRequest for tasks that need to run repeatedly at defined intervals.

WorkRequest Comparison

OneTimeWorkRequest

  • Runs only once.
  • Suitable for single events.
  • Example: Image upload.

PeriodicWorkRequest

  • Repeats at intervals.
  • Ideal for recurring tasks.
  • Example: Data sync.
