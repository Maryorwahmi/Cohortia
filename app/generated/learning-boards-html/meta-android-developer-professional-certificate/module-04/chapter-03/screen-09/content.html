Building a Basic Started Service (Part 1)

Setting up onCreate and onStartCommand

import android.app.Service
import android.content.Intent
import android.os.IBinder
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.delay
import kotlinx.coroutines.launch

class MyBackgroundService : Service() {

    private val serviceScope = CoroutineScope(Dispatchers.IO)

    override fun onCreate() {
        super.onCreate()
        println("MyBackgroundService: Service created.")
    }

    override fun onStartCommand(
        intent: Intent?, flags: Int, startId: Int
    ): Int {
        println("MyBackgroundService: Service started with ID $startId.")

        // Perform long-running operation on a background thread
        serviceScope.launch {
            for (i in 1..10) {
                delay(1000) // Simulate work
                println("MyBackgroundService: Task running... $i seconds.")
            }
            println("MyBackgroundService: Task finished.")
            stopSelf(startId) // Stop the service when work is done
        }

        // START_STICKY: Recreate service if killed, call onStartCommand with null intent.
        return START_STICKY
    }

    // ... other methods ...
}
Explanation: onCreate()

The onCreate() method is called once when the service is first created. It's used for initial setup, like initializing resources or setting up coroutine scopes. Our println helps confirm creation.

Explanation: onStartCommand()

This method is invoked every time a client calls startService(). It's where the service receives the Intent and begins its main work. We launch a coroutine on Dispatchers.IO to ensure background execution, preventing ANRs.

Return Value: START_STICKY

Returning START_STICKY from onStartCommand() tells the system that if the service is killed, it should be recreated and onStartCommand() called again with a null intent. This is suitable for services that explicitly manage their own work.

Key Takeaway

onCreate() handles setup, while onStartCommand() initiates the service's work, which must be offloaded to a background thread to prevent ANRs.
