Defining Your API Service

The Retrofit interface declares your API endpoints, HTTP methods, and expected responses using annotations. This creates a clear contract for your network interactions.

  • •Annotations: @GET, @POST, etc., specify HTTP methods.
  • •Suspend Functions: Enable coroutine support for asynchronous calls.
  • •Type-Safe Returns: Define expected data structures (e.g., Response<List<Post>>).
Key Takeaway

The API service interface is your app's blueprint for interacting with the server, ensuring all network calls are well-defined and type-checked.

Example: BlogApiService Interface

import retrofit2.Response
import retrofit2.http.GET

interface BlogApiService {
    @GET("posts") // Relative path to the API endpoint
    suspend fun getPosts(): Response<List<Post>> // Coroutine support
}
@GET("posts") maps to an HTTP GET request.
suspend keyword for asynchronous execution.
Important Note

The suspend keyword is vital for ensuring network operations run on a background thread, preventing UI freezes. We'll explore coroutines in more detail later.
