What is JSON?

JSON (JavaScript Object Notation) is a lightweight, human-readable data interchange format. It's widely used for sending data between a server and a web application.

  • •Key-Value Pairs: Data is represented as attribute-value pairs (e.g., "name": "Alice").
  • •Ordered Lists: Arrays are used to store ordered collections of values.
  • •Language Independent: Easy to parse and generate in any programming language.
Key Takeaway

JSON's simplicity and efficiency make it the preferred format for API responses, crucial for mobile app performance.

Example JSON Structure

{
  "id": 101,
  "title": "My First Blog Post",
  "author": {
    "name": "Jane Doe",
    "email": "jane@example.com"
  },
  "tags": ["android", "kotlin", "api"],
  "published": true
}
