HTTP Methods: Interacting with Resources

Standard verbs for performing actions on API resources.

GET

Retrieve Data

Used to request data from a specified resource. It should only retrieve data and have no other effect on the data.

Example: Fetching a list of blog posts.
POST

Create New Resource

Used to send data to a server to create a new resource. The data is included in the request body.

Example: Submitting a new user registration.
PUT

Update Resource

Used to update an existing resource with new data. The entire resource representation is typically sent.

Example: Modifying a user's profile information.
DELETE

Remove Resource

Used to delete a specified resource from the server. This is a destructive operation.

Example: Deleting a specific blog post.
