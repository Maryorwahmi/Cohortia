Robust Error Handling & Common Pitfalls

Strategies to prevent crashes and provide a better user experience.

Missing Internet Permission

Issue: App crashes with SecurityException when trying to access network.

Solution: Add <uses-permission android:name="android.permission.INTERNET" /> to AndroidManifest.xml.

NetworkOnMainThreadException

Issue: App becomes unresponsive or crashes if network calls are on UI thread.

Solution: Always perform network operations asynchronously (e.g., using Kotlin Coroutines).

Incorrect JSON Parsing

Issue: Mismatch between JSON field names and Kotlin data class properties.

Solution: Use @Json(name = "api_field") (Moshi) or @SerializedName("api_field") (Gson).

Graceful User Feedback

Best Practice: Always show loading indicators, error messages, and retry options.

Benefit: Improves user experience and app perceived reliability.
