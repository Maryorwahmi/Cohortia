Understanding Coroutine Dispatchers

Controlling Where Your Coroutines Execute

Dispatcher Roles
  • Dispatchers.Main: For UI updates and fast main-thread operations.
  • Dispatchers.IO: For disk and network I/O operations.
  • Dispatchers.Default: For CPU-intensive work like sorting or heavy calculations.
Common Pitfall

Performing long-running or blocking operations on Dispatchers.Main will inevitably lead to ANRs. Always ensure heavy work is offloaded to IO or Default.

Key Takeaway

Choose Dispatchers.Main for UI, Dispatchers.IO for network/disk, and Dispatchers.Default for CPU-intensive tasks to optimize performance and prevent ANRs.

Dispatchers.Main

The primary UI thread. Use for UI updates and quick, non-blocking operations.

Dispatchers.IO

Optimized for network and disk operations (e.g., database access, file reading).

Dispatchers.Default

Designed for CPU-intensive tasks (e.g., heavy computations, large list processing).
