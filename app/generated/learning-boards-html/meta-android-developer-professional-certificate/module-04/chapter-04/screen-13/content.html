Parallel Execution

Running Tasks in Parallel with async

Fetching Multiple Data Streams Concurrently

Key Concepts
  • async: Coroutine builder that starts a new coroutine and returns a Deferred result.
  • Deferred: A non-blocking future representing a promise of a result.
  • await(): A suspend function to get the result from a Deferred, suspending until available.
  • Parallelism: Multiple async blocks can run concurrently, speeding up total execution time.
Performance Benefit

If fetching posts takes 3 seconds and comments takes 2 seconds, running them sequentially would take 5 seconds. With async, they run in parallel, completing in approximately 3 seconds (the duration of the longest task).

Key Takeaway

async and await() enable parallel execution of tasks, returning Deferred results, which significantly speeds up fetching multiple independent data streams.

import kotlinx.coroutines.async
import kotlinx.coroutines.awaitAll
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.launch
import kotlinx.coroutines.withContext

fun fetchMultipleData() {
    viewModelScope.launch(Dispatchers.IO) { // Launch on IO if multiple network calls
        val postsDeferred = async { RetrofitClient.apiService.getPosts().body() }
        val commentsDeferred = async { RetrofitClient.apiService.getComments().body() }

        // Await both results in parallel
        val posts = postsDeferred.await()
        val comments = commentsDeferred.await()

        withContext(Dispatchers.Main) {
            // Update UI with both posts and comments
            println("Fetched posts: $posts, comments: $comments")
        }
    }
}
