Core Building Block

The suspend Function

Pausing and Resuming Execution

Key Characteristics
  • Non-Blocking: Pauses execution without blocking the underlying thread.
  • Context-Aware: Must be called from another suspend function or a coroutine builder.
  • Efficient: Frees up threads for other work during I/O or long computations.
Example: Network Call

Consider a suspend fun fetchUserData(): User. When this function makes a network request, it suspends. The thread is free to handle other tasks. Once the network response arrives, the function resumes to process the data, all without blocking the UI.

Key Takeaway

A suspend function can pause and resume without blocking its thread, enabling efficient non-blocking operations and preventing ANRs in coroutines.

import kotlinx.coroutines.delay

suspend fun fetchDataFromNetwork(): String {
    // Simulate a network request that takes time
    delay(2000L) // This is a suspend function itself
    return "Data fetched successfully!"
}

/*
  You can only call 'fetchDataFromNetwork()' from:
  1. Another suspend function
  2. A coroutine builder (e.g., launch, async)
*/

fun main() {
    // This would cause a compilation error:
    // val data = fetchDataFromNetwork()
}
