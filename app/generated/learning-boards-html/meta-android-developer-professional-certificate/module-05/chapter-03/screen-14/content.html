Module 5 › Chapter 5.3 › Key Concepts
Unit Test
A fast, isolated test of a single class or method, run on the JVM for pure logic.
Test Doubles
Mocks record interactions to verify calls; stubs return predefined data to control inputs.
Deterministic Execution
Use InstantTaskExecutorRule for LiveData and a TestDispatcher with runTest for coroutine determinism.
Summary
Combine isolation, appropriate test doubles, and deterministic concurrency control to build fast and trustworthy unit tests that support safe refactoring and clear documentation of behavior.
