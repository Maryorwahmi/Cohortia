Module 5 › Chapter 5.3 › What is a Unit Test?
Definition

A unit test checks a single unit in isolation from its dependencies. It runs on the JVM and focuses on observable behavior through public methods and properties.

Example
Mock a repository to emit a list of tasks; assert the ViewModel's LiveData has that list.
Misconception
Testing private helpers is brittle. Test public behavior instead.
Pro tip
Arrange, act, assert. Keep tests short and focused on one behavior each.
Concrete checklist
  • Does the class have clear inputs and outputs?
  • Can its dependencies be replaced with mocks or stubs?
  • Will the test run quickly on the JVM?
Key Takeaway

Prefer tests that exercise public behavior, isolate external resources, and fail only when the unit is incorrect.
