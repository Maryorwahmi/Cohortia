Module 5 › Chapter 5.3 › Coroutine Testing
Setup pattern
private val testDispatcher = StandardTestDispatcher()

@Before
fun setup() {
  Dispatchers.setMain(testDispatcher)
}

@After
fun tearDown() {
  Dispatchers.resetMain()
}
runTest and advancing
runTest {
  // trigger behavior
  testDispatcher.scheduler.advanceUntilIdle()
  // then assert results
}
runTest gives a test coroutine scope and works with the test dispatcher to control execution deterministically.
Common mistake
Not replacing Dispatchers.Main or not advancing the test dispatcher. Both cause coroutines to remain pending and tests to fail or hang.
Key Takeaway

Always set a test dispatcher as Main and use runTest with explicit advances to make coroutine work deterministic in tests.
