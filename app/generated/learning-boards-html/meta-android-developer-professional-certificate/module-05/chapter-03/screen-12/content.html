Module 5 › Chapter 5.3 › Repository Tests
Test examples
val mockTaskDao: TaskDao = mock()
val repository = TaskRepository(mockTaskDao)

@Test
fun `getAllTasks returns flow from DAO`() = runTest {
  val tasks = listOf(Task(1, "Repo Task 1", "Desc 1"))
  whenever(mockTaskDao.getAllTasks()).thenReturn(flowOf(tasks))

  val resultFlow = repository.getAllTasks()
  var actualTask: Task? = null
  resultFlow.collect {
    actualTask = it
    cancel()
  }

  assertEquals(tasks, actualTask)
  verify(mockTaskDao).getAllTasks()
}
Helper note
Collect only the first value from a Flow in tests to avoid hanging. The chapter's collectForValue helper cancels collection after one emission.
Practical checklist
  • Mock the DAO and stub returns for Flows.
  • Collect one value and assert equality.
  • Verify DAO methods are called for mutation operations.
Key Takeaway

Repository tests confirm delegation to data sources while remaining fast by mocking external components.
