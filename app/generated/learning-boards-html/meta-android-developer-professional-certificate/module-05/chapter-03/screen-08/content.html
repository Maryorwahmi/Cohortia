Module 5 › Chapter 5.3 › LiveData in Tests
Rule example
@get:Rule
val instantTaskExecutorRule = InstantTaskExecutorRule()
This rule forces LiveData to run synchronously and is necessary when using observeForever in tests.
Why it matters
Without it, LiveData updates may be posted asynchronously and assertions can see null or stale values.
Test pattern
  1. Set InstantTaskExecutorRule in the test class.
  2. Observe LiveData with observeForever to capture values.
  3. Advance test dispatchers for coroutines then assert the captured value.
Key Takeaway

Combine InstantTaskExecutorRule with coroutine test dispatchers to make LiveData and coroutine behavior deterministic in unit tests.
