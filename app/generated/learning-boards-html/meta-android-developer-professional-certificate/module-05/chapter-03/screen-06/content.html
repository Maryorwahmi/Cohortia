Module 5 › Chapter 5.3 › Local vs Instrumented
Local Unit Tests (JVM)
Fast, run on developer machine, used for pure Kotlin/Java logic that doesn’t need Android APIs.
Good for:
  • ViewModels, Repositories that can be mocked
  • Utility classes and use cases
Instrumented Tests (Device)
Run on an emulator or device and required when code uses Context, Resources, or UI components directly.
Good for:
  • UI interactions, Android framework behavior, resource access
Decision guide
  1. Can the Android dependency be mocked or injected? If yes, prefer a local test.
  2. If the behavior depends on Android internals, write an instrumented test.
Key Takeaway

Choose the fastest environment that still gives you reliable verification of the behavior you care about.
