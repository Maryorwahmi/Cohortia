Module 5 › Chapter 5.3 › Verify insert & delete
Insert test
@Test
fun `insertTask calls repository insertTask`() = runTest {
  val newTask = Task(title = "New Task", description = "New Desc")
  viewModel.insertTask(newTask)
  verify(mockRepository).insertTask(newTask)
}
Delete test
@Test
fun `deleteTask calls repository deleteTask`() = runTest {
  val taskIdToDelete = 1
  viewModel.deleteTask(taskIdToDelete)
  verify(mockRepository).deleteTask(taskIdToDelete)
}
Notes
  • Always verify after advancing the test dispatcher if the method is invoked in a coroutine.
  • Keep the assertion focused on delegation, not implementation order unless order matters.
Key Takeaway

Interaction tests confirm responsibilities: that one component delegates work to another as intended.
