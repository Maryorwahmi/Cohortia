Learning Objectives

Gain measurable competencies in performance, security, maintainability, and accessibility.

Bloom: Learn → Understand → Apply → Master
01
Optimize UI rendering

Identify frame budget issues, reduce overdraw, and flatten view hierarchies to keep animations smooth. Practice: profile a scrolling list to find jank.

VERIFIED COMPETENCY MILESTONE
02
Harden app security

Use encrypted storage, enforce HTTPS, request minimal permissions, and apply input validation to protect users and backend services.

VERIFIED COMPETENCY MILESTONE
03
Write maintainable code

Adopt MVVM or MVI, use DI with Hilt, follow Kotlin style, and rely on linting to keep codebase healthy and testable.

VERIFIED COMPETENCY MILESTONE
04
Scale and include

Modularize features for faster builds, and apply accessibility and i18n practices to reach more users across devices and languages.

VERIFIED COMPETENCY MILESTONE
