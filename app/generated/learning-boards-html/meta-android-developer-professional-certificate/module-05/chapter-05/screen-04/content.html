Module 6 › Chapter 5.5 › Frame Budget
Definition

The frame budget is the time available to render a single screen refresh. At 60fps this is about 16ms; staying inside it keeps animations and scrolling smooth.

Why it matters

Exceeding the budget causes dropped frames, visible stutters, and poor user experience, leading to uninstalls.

Common mistake

Doing heavy work on the main thread and assuming the system will parallelize UI tasks for you.

Pro tip

Profile a scrolling session and find the longest frames, then optimize the operations listed in the trace.

Key Takeaway

Measure frame times, then reduce or move work off the main thread to restore the 16ms budget.

Example scenario

A list that decodes full-size images on bind will push layout and draw time over 16ms. Solution: downsample images and decode off the main thread with an image library.
