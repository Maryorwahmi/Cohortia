Checklist: Permissions, Validation, Obfuscation
  • Request only required permissions and explain why to users at runtime.
  • Validate input on both client and server to avoid injection attacks.
  • Enable ProGuard/R8 in release builds to shrink and obfuscate bytecode and reduce APK size.
  • Avoid enabling JavaScript bridges in WebView unless necessary and sandbox content.
Example

If an app only needs location when navigating, request location permission at the moment navigation starts rather than at install or app launch.
