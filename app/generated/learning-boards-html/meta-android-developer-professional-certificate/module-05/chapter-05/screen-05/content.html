Process: Find and fix overdraw
  1. Enable the GPU overdraw overlay and capture a scrolling trace.
  2. Inspect views marked as multiple-overdraw and identify repeated backgrounds or layered views.
  3. Flatten nested layouts using ConstraintLayout and remove redundant backgrounds or use ViewStub for rarely used sections.
  4. Test again and measure frame times to confirm improvement.
Misconception

Hiding a view does not always remove it from layout; invisible views may still contribute to layout passes unless removed or swapped out.

Example: Background layers

A card with an ImageView, a semi-transparent overlay, and a background color can cause triple-draw. Replace layered backgrounds with a single drawable, or merge overlay effects into the image during load.

Quick Fix Checklist
  • Remove redundant backgrounds
  • Use ConstraintLayout to flatten hierarchy
  • Defer heavy layout work off the main thread
