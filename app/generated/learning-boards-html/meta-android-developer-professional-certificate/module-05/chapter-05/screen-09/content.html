Comparison: SharedPreferences vs EncryptedSharedPreferences
SharedPreferences

Plain XML storage. Easy for settings, but not safe for secrets. Vulnerable on rooted devices.

EncryptedSharedPreferences

Automatically encrypts keys and values using keystore-backed keys, protecting sensitive data at rest.

Best practice: store tokens and API keys with EncryptedSharedPreferences, and never embed secrets in the APK or plain resources.
Network Security

Always use HTTPS for network communication and configure Network Security Configuration to block cleartext traffic and restrict trusted certificates where appropriate.

Practical step

Add a network_security_config.xml that denies cleartext and apply it in the manifest to ensure secure transport across the app.
