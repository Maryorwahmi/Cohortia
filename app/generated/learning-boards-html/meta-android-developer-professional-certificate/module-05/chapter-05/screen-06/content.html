Code Pattern: Lightweight onBind
class TaskViewHolder(val binding: ItemBinding): RecyclerView.ViewHolder(binding.root) {
  fun bind(task: Task) {
    binding.title.text = task.title
    binding.dueDate.text = task.formattedDate // precomputed
    imageLoader.load(task.imageUrl).into(binding.image)
  }
}
Note: date formatting and other heavy transformations should happen before the adapter receives the list. Use DiffUtil for efficient updates and let your image loader handle decoding and caching.
Explanation & Example
  • Precompute display strings to avoid work in onBind.
  • Use libraries like Glide or Coil to handle images off the main thread and to cache results.
  • Use DiffUtil to update only changed items instead of redrawing the whole list.
Key Takeaway

Make the adapter the cheapest possible path from model to view and delegate heavy work elsewhere.
