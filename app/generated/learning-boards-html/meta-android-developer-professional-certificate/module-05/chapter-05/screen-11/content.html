Layered architecture
UI layer: Activities/Fragments and ViewModels — observe state, handle user events.
Domain layer: business logic, use cases, and validation.
Data layer: repositories, DAOs, remote sources, and caching.
Benefit

Clear separation makes unit testing and parallel feature development easier for teams.

Hilt advantages
  • Automatically generates DI code for Android components.
  • Makes tests simpler by replacing modules with test bindings.
  • Defines scopes and lifecycles cleanly for singletons and per-Activity/Fragment bindings.
