Module 6 › Chapter 5.5 › Coroutines & WorkManager
Coroutine Example
viewModelScope.launch {
  val result = repository.fetchTasks() // suspend function
  _uiState.value = UiState.Success(result)
}

Use lifecycle-aware scopes to avoid leaks and cancel work when views are destroyed.

WorkManager Example
// Build a one-off work request with network constraint
val uploadWork = OneTimeWorkRequestBuilder<UploadWorker>()
  .setConstraints(Constraints.Builder().setRequiredNetworkType(NetworkType.CONNECTED).build())
  .build()
WorkManager.getInstance(context).enqueue(uploadWork)

Use WorkManager for tasks that must complete even if the app exits or the device restarts.

Key Takeaway

Coroutines for immediate, lifecycle-tied async work; WorkManager for guaranteed, constraint-aware background tasks.
