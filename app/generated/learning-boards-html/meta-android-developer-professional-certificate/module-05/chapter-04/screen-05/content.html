Module 5 › Chapter 5.4 › Unit vs Instrumented
Comparison

Local Unit Tests

Run on the JVM. Fast and focused on business logic and pure functions.

When to use
Testing repositories, viewmodels, and domain logic where Android UI is not required.
Benefits
Fast feedback, easy to run in CI without device/emulator.
Comparison

Instrumented UI Tests (Espresso)

Run on device/emulator and interact with views, input and navigation.

When to use
Validate that the UI behaves correctly when the Android framework and input methods are involved.
Benefits
Catch rendering, keyboard and navigation issues that unit tests cannot see.
Concrete scenario

Verify that pressing Add after typing shows a new item in a RecyclerView — requires Espresso, not a unit test.

Misconception

Believing unit tests eliminate the need for UI tests will miss visual and input-related defects.
