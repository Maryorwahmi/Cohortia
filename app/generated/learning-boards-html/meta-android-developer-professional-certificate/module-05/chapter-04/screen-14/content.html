Module 5 › Chapter 5.4 › Key Concepts
UI Testing
Tests that simulate user interactions on device/emulator to validate visible behavior.
Instrumented Test
Runs on an Android device or emulator and interacts with the Android framework.
Espresso
A concise framework that synchronizes with the UI thread and offers onView, actions, and assertions.
Summary

Use Espresso tests to validate visible user flows, add androidTestImplementation dependencies, and keep unit tests for fast logic verification.
