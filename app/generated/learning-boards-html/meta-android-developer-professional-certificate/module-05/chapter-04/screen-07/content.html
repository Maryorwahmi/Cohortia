Add Espresso Dependencies

Add androidTestImplementation dependencies to enable instrumented testing and RecyclerView actions.

dependencies {
    // ... other dependencies

    // Instrumented UI Testing with Espresso
    androidTestImplementation 'androidx.test.ext:junit:1.1.5'
    androidTestImplementation 'androidx.test.espresso:espresso-core:3.5.1'
    androidTestImplementation 'androidx.test.espresso:espresso-contrib:3.5.1'
    androidTestImplementation 'androidx.test:runner:1.5.2'
    androidTestImplementation 'androidx.test:rules:1.5.0'
    androidTestImplementation 'org.mockito.kotlin:mockito-kotlin:3.2.0'
    androidTestImplementation 'androidx.navigation:navigation-testing:2.7.7'
}

After syncing, create tests under src/androidTest. Remember that espresso-contrib is needed for RecyclerViewActions and navigation-testing helps when asserting navigation components.

Pro tip

Keep test-only dependencies in androidTestImplementation so they don’t inflate release APKs.

Checklist
  • Add dependencies and sync Gradle.
  • Create src/androidTest/java or kotlin structure.
  • Use ActivityScenarioRule to launch activities in tests.
Common mistake

Forgetting espresso-contrib when testing RecyclerView leads to missing RecyclerViewActions support at runtime.
