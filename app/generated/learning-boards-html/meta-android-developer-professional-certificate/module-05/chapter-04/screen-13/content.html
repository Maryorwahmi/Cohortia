Activity: Implement TaskDetailFragmentTest

Follow these instructions to build a test that validates editing a task’s details and propagating changes back to the list.

Step 1
Create TaskDetailFragmentTest and add ActivityScenarioRule for TaskListActivity.
Step 2
Add a new task by typing title and description and clicking Add.
Step 3
Use RecyclerViewActions to click the item and navigate to TaskDetailFragment.
Step 4
Verify the title and description fields match the original values.
Step 5
Edit the description, call closeSoftKeyboard(), click Save, then press back.
Step 6
Assert the updated description appears in the list using onView(withText(...)).check(matches(isDisplayed())).
Key Takeaway

This exercise ties adding, navigation, editing and verification into a single end-to-end UI test to validate user-visible behavior.
