Module 5 › Chapter 5.4 › Patterns to Use
ActivityScenarioRule
Launches and tears down the activity for each test method.
onView & matchers
Combine with withId, withText or withContentDescription for precise matching.
RecyclerViewActions
Use actionOnItemAtPosition or actionOnItem with a matcher to interact with list items.
Takeaway

Structure tests as find → act → assert, manage the activity lifecycle with ActivityScenarioRule, and avoid brittle sleeps by using Espresso synchronization or IdlingResource.
