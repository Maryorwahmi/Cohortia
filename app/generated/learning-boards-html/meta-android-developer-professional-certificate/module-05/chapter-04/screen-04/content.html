Core Concept

What is UI Testing and Why it Matters

Instrumented tests run on device and validate visible behavior that unit tests cannot reproduce.

Definition
Tests that interact with the Android UI framework on a device or emulator to simulate real user interactions.
Concrete example
Typing a task title, tapping Add, and verifying the text appears in a RecyclerView on screen.
Misconception
They are not always flaky; Espresso’s synchronization reduces many timing failures when used properly.
Key Takeaway

Use instrumented UI tests to validate user-visible flows that depend on Android framework rendering and input behaviour.

Analogy

Think of unit tests as checking each appliance in a smart home individually, and instrumented UI tests as walking through the house to make sure the lights, doors, and thermostat interact correctly when you follow a real routine.

Why this matters
  • Find regressions that only surface when views compose and input methods change layout.
  • Validate navigation and list rendering end-to-end.
  • Complement unit tests to raise overall confidence in releases.
