Testing RecyclerView Interactions

Use espresso-contrib's RecyclerViewActions to click items by position or by matching content.

onView(withId(R.id.recyclerView_tasks))
    .perform(RecyclerViewActions.actionOnItemAtPosition< TaskAdapter.TaskViewHolder >(0, click()))

// or
onView(withId(R.id.recyclerView_tasks))
    .perform(RecyclerViewActions.actionOnItem< TaskAdapter.TaskViewHolder >(hasDescendant(withText("Task 1")), click()))
Note
Remember to add test data so the RecyclerView contains predictable items for the position-based action.
Explanation
  • actionOnItemAtPosition targets a specific adapter position.
  • actionOnItem with a matcher targets a specific item by content, which is more robust across data changes.
  • Ensure espresso-contrib is included to access RecyclerViewActions.
Common pitfall

Assuming adapter positions are stable across runs. Prefer content matchers when possible.
