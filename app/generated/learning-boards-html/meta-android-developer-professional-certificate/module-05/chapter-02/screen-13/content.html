Common Mistakes and Safety Notes
Prevent freezes, leaks, and brittle tests by following lifecycle-aware patterns.
Direct DB/Network in UI
Move these operations into the Repository and call them from ViewModel coroutines so the UI stays responsive.
Holding view refs in ViewModel
Avoid storing references to Views or Contexts in ViewModels; use application context cautiously or better, DI for resources.
Not observing with LifecycleOwner
Always observe with an Activity or viewLifecycleOwner in fragments to ensure correct delivery and automatic cleanup.
Missing error handling
Expose error states via LiveData and handle them in the UI instead of letting exceptions crash the app.
Actionable checklist
Use viewModelScope, convert Flow to LiveData for UI observation, inject repositories with a factory, and centralize database creation in a singleton.
