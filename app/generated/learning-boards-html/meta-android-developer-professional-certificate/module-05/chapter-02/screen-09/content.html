TaskViewModelFactory
Provide a factory that constructs TaskViewModel with a TaskRepository parameter.
// ViewModelFactory for injecting repository
class TaskViewModelFactory(private val repository: TaskRepository) : ViewModelProvider.Factory {
  override fun  create(modelClass: Class): T {
    if (modelClass.isAssignableFrom(TaskViewModel::class.java)) {
      @Suppress("UNCHECKED_CAST")
      return TaskViewModel(repository) as T
    }
    throw IllegalArgumentException("Unknown ViewModel class")
  }
}
Design note: factories are boilerplate but they make dependency graphs explicit. For larger projects consider using a DI framework to reduce manual factories.
Example
Use by passing factory to viewModels delegate to get a ViewModel instance that has the repository injected.
Common mistake
Avoid creating ViewModels with direct constructors in Activities; prefer a factory to keep lifecycle integration correct.
Key Takeaway

Use a ViewModelFactory to supply dependencies and make unit testing feasible.
