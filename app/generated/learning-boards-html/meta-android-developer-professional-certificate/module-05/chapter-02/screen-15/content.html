Key Concepts
Three compact reminders to check as you code.
DAO
Defines database operations; use suspend for writes and Flow for reads.
Flow → LiveData
Convert Flow to LiveData with asLiveData for lifecycle-aware observation.
viewModelScope
Use it to run suspend work tied to the ViewModel lifecycle and avoid leaks.
One-sentence checklist
Verify DAO returns Flow, convert with asLiveData in ViewModel, and run suspend calls inside viewModelScope.
