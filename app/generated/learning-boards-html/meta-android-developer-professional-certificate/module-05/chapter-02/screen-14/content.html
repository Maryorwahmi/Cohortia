Key Concepts
Three compact concept cards to remember.
ViewModel
Preserves UI-related data and exposes lifecycle-aware state.
Room Database
An abstraction over SQLite using entities and DAOs for safe persistence.
Repository
Abstracts DAOs and other sources, providing a clear API to ViewModels.
Summary
Combine these parts to build features that are testable, lifecycle-aware, and resilient to configuration changes.
