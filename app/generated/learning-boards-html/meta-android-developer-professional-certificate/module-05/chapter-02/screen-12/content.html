Extend the Task app: TaskDetailFragment
Steps to implement single-item fetch and edit flow.
1. Create fragment_task_detail.xml and TaskDetailFragment.kt to display title, description, and completion.
2. Add navigation action that passes taskId as an argument from the list screen to the detail screen.
3. Add getTaskById(taskId: Int): Flow to TaskDao and implement repository.getTaskById.
4. In TaskViewModel add getTaskById(taskId) that returns LiveData using asLiveData on the repository Flow.
5. In the fragment, observe LiveData, populate fields, and call updateTask on Save.

Starter code notes
The chapter provides the exact signatures to add to TaskDao, TaskRepository, and TaskViewModel for single-item observation.
Pitfall
Forgetting to observe with a LifecycleOwner in fragments can lead to updates not being delivered at the right time; use viewLifecycleOwner when observing in fragments.
Key Takeaway

Extend features by reusing Repository and ViewModel patterns; convert Flows to LiveData to observe safely from the UI.
