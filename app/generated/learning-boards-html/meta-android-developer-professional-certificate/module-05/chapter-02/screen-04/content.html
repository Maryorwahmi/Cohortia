Task data class as Room entity
Define the persisted schema for tasks using Entity and a primary key.
// data/model/Task.kt
package com.cohortia.taskapp.data.model

import androidx.room.Entity
import androidx.room.PrimaryKey

@Entity(tableName = "tasks")
data class Task(
  @PrimaryKey(autoGenerate = true)
  val id: Int = 0,
  val title: String,
  val description: String,
  val isCompleted: Boolean = false
)
Bulleted explanation:
  • Use @Entity to declare a table mapping for Room.
  • autoGenerate primary keys to let Room assign ids safely.
  • Keep the entity focused on persisted fields only.
Example
Creating and inserting a new Task with title and description will get an auto-generated id once persisted.
Key Takeaway

Entities represent persisted state. Keep them simple and stable for migrations and testing.

Common mistake
Avoid storing UI formatting or view refs inside an entity; that creates tight coupling between persistence and presentation.
