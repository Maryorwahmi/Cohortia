Auto-linking
Modern React Native versions auto-link native modules during the build, reducing manual installation steps for many libraries.
Check the library README for any additional setup steps like manifest edits or Gradle configuration.
Expo-managed workflow
Expo often provides pre-linked expo-* libraries so you can use device features with minimal native changes; this simplifies development if you stay within Expo capabilities.
If you eject from Expo, you may need to follow native install steps similar to React Native CLI projects.
Debugging linking issues
  • Rebuild the native app after changes.
  • Check that the native module appears in Gradle build output and that the package is registered.
  • Inspect the library documentation for manual steps if auto-linking didn’t cover them.
