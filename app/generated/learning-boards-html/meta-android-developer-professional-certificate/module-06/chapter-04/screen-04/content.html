Module 6 › Chapter 6.4 › The React Native Bridge
Core Concept

Bridge: message-based communication

The bridge marshals calls between JS engines like Hermes and platform-native modules. Calls are asynchronous, so Promises and callbacks are the usual pattern.

Example
Request camera permission using a built-in module. JavaScript requests, the native dialog appears, then the result resolves a Promise back in JS.
Common misconception
The bridge does not expose arbitrary native APIs automatically; only methods explicitly exposed by native modules can be called.
Annotated call flow
JavaScript Engine → Bridge → Native Module → Platform API → Bridge → JavaScript
JS code calls request() and returns a Promise.
Bridge serializes the message and forwards it to native code.
Native module runs platform API, e.g., show system permission dialog.
Native returns result to JS via bridge; Promise resolves.
Key Takeaway

The bridge is the controlled channel for JS-native interaction; design calls thoughtfully and prefer existing modules where possible.
