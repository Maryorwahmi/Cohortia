Module 6 › Chapter 6.4 › Key Concepts
React Native Bridge
Communication channel between JavaScript and native code enabling calls and events.
Native Module
Platform code exposed to JavaScript, typically a Kotlin/Java class on Android or Swift/Objective-C on iOS.
PermissionsAndroid
Android-specific API in React Native for runtime permission requests from JavaScript.
Summary

Use the bridge to access device features, prefer built-in modules and libraries, and fall back to custom native modules only when necessary.
