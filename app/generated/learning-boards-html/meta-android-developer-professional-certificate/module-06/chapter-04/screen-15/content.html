Module 6 › Chapter 6.4 › Implementation Reminders
@ReactMethod
Annotation used to expose Java/Kotlin methods to JavaScript through the bridge.
ReactContextBaseJavaModule
Base class on Android for native modules. Subclass and implement getName for your module.
AndroidManifest.xml
Declare permissions, services, and activities your native code depends on; runtime requests are still required for dangerous permissions.
Final takeaway

Combine careful permission UX, correct manifest declarations, and the bridge’s capabilities to integrate device features responsibly and reliably.
