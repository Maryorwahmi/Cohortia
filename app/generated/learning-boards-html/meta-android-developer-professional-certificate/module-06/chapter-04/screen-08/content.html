Module 6 › Chapter 6.4 › Custom Native Module
1. Create module class
Subclass ReactContextBaseJavaModule and override getName to provide the module name that JS will import.
2. Expose methods
Annotate methods with @ReactMethod. Use callbacks or Promises to return results asynchronously.
3. Register module
Add the module to your React package in MainApplication.java or MainApplication.kt so the bridge can find it.
Example scenario
Suppose you need a custom image decoder for performance. Implement decoding in Kotlin, expose decodeImage as a @ReactMethod that returns a Promise, and register the module for use from JavaScript.
Common mistake

Forgetting to register the module or to declare required AndroidManifest entries will make the native method unreachable from JavaScript.
