Module 6 › Chapter 6.4 › Decision Checklist
Functional fit
Does the API/library provide the exact behavior and stability you need?
Compatibility & maintenance
Is the library actively maintained and compatible with your RN version?
Native changes required
Will using it require manifest edits, Gradle changes, or manual linking?
When to write custom native code
Only when performance, security, or missing platform APIs justify the increased maintenance cost of native modules.
