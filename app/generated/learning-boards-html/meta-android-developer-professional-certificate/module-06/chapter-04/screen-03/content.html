Module 6 › Chapter 6.4 › Practical Objectives

Practice tasks

Implement Permission Flow
Build a screen that requests a permission, updates state, and shows granted/denied messages. This proves you handle runtime requests and UI updates.
Integrate a Device Library
Install and test a camera or location library, noting whether auto-linking worked or manual steps were necessary.
Sketch Native Module
Draft the Java/Kotlin class name, methods with @ReactMethod, and registration steps to demonstrate understanding without deep implementation.
Fix Common Errors
Identify missing AndroidManifest entries or linking failures and describe the steps to resolve them.
