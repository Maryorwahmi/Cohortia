Module 6 › Chapter 6.4 › AndroidManifest & Permissions
Manifest declaration example
<uses-permission android:name="android.permission.CAMERA" />

<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
Place these lines in android/app/src/main/AndroidManifest.xml and rebuild your app after changes.
Checklist when permissions fail
  • Confirm manifest entries exist in the correct manifest file path.
  • Use PermissionsAndroid.check to see current status before requesting.
  • Request at runtime and handle RESULTS.GRANTED, denied, and errors.
  • Rebuild the native app after changing manifest entries, especially on Android.
Pro tip

When testing, simulate both acceptance and denial flows so your app degrades gracefully if the user refuses a permission.
