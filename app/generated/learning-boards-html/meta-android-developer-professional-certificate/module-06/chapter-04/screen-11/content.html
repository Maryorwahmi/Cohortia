Module 6 › Chapter 6.4 › Common Mistakes
Missing manifest entries
Declare permissions and any services or activities used by native code, then rebuild the app to apply changes.
Incorrect linking
Verify auto-linking output or manually register the package in MainApplication if needed.
Version mismatches
Confirm library compatibility with your React Native version to avoid build-time failures.
Async handling & errors
  • Use try/catch around async native calls and present a clear error state in the UI.
  • Check native logs when JavaScript errors are insufficient for diagnosis.
Follow a sequence: manifest, linking, compatibility, then logging for effective debugging.
