Integrating Native Modules & Device Features

Understand the bridge between JavaScript and native code, practice Android permission requests, and learn when to use libraries or author native modules.

Why this matters
Device features are often platform-specific. The bridge is what lets your JavaScript call the native APIs that implement those features.
How you'll use it
Request runtime permissions, use camera or location libraries, or write a small native module when performance or capability requires it.

Concept sketch
Bridge: JavaScript ↔ Native
Messages flow across the bridge so JS can invoke native methods and receive results. Use built-in modules first, libraries next, and custom modules as an escape hatch.
Tip: keep permission requests contextual and explain why you need access to gain user trust.
