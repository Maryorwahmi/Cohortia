Module 6 › Chapter 6.4 › Built-in vs Third-Party
Built-in modules
Examples: PermissionsAndroid. Pros: stable, minimal install effort. Cons: limited feature surface for advanced device integration.
When to use
  • Simple permission checks or system dialogs.
  • When cross-platform parity is available.
Third-party libraries
Examples: react-native-camera, expo-camera, react-native-geolocation-service, expo-location. Pros: richer APIs and device features. Cons: installation, linking, and maintenance considerations.
Consider
  • Whether you use Expo managed workflow or React Native CLI.
  • Library compatibility and auto-linking support in your React Native version.
Quick checklist before adding a library
Check compatibility
Read install steps
Test grant/deny flows
If a library lacks features or has breaking incompatibilities, plan for a custom native module or another maintained alternative.
