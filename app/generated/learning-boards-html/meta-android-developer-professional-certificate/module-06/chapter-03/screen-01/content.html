State Management & Navigation
Manage interactive data with hooks and move between screens with React Navigation’s Stack.

You will see how props carry immutable values into components, how state is owned and updated using useState, and how useEffect schedules side effects such as network requests. We’ll also show the minimal Stack setup and how to pass parameters when navigating.

In this lesson
State & Props
Why components re-render and how data flows.
Hooks
useState for local data, useEffect for side effects.
Navigation
Stack Navigator and passing params between screens.
Visual Concept
Props
Immutable inputs from the parent. Example: a Button gets title and onPress.
State
Owned by the component and updated with useState to trigger re-render.
Starter pattern
const [value, setValue] = useState('');
// controlled input
<TextInput value={value} onChangeText={setValue} />
Explore Key Topics
useState

useEffect
