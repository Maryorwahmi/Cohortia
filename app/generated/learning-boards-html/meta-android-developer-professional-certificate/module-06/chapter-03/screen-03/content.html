Controlled Component Pattern
A controlled input uses both a value from state and an onChange handler that updates that state. This ensures a single source of truth for the input value.
Mnemonic
Value + Setter → Controlled
useEffect Dependency Checklist
  • Empty array [] → run once after initial render.
  • Omit array → runs after every render (rarely desired).
  • Include variables → runs when those variables change.
