Module 6 › Chapter 6.3 › Props vs State
Props (Immutable)
Passed from parent to child. Use props to configure a component’s behavior or display without allowing the child to change them directly.
Example: <Button title="Save" onPress={handleSave} />
Common mistake
Trying to mutate a prop inside a child instead of asking the parent to change it.
State (Mutable)
Owned by component and changed with useState. Changing state triggers a re-render to update the UI.
Example: const [text, setText] = useState('');
Pro tip
Lift state up when multiple sibling components need the same data.
Quick comparison
Props: Read-only
State: Read/Write via setters
Flow: Parent → Child
