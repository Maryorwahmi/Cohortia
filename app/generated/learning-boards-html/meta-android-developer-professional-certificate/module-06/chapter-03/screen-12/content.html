Module 6 › Chapter 6.3 › Common Mistakes
State Errors
Avoid mutating arrays or objects; use setState with new copies: setTodos([...todos, item]).
Effect Errors
Check dependency arrays and return cleanup functions for subscriptions or timers.
Navigation Errors
Ensure NavigationContainer wraps the navigator and validate route.params before use.
Debug Checklist
  • Console warnings about controlled inputs?
  • Does useEffect run when expected? Add logs.
  • Are navigation props present on the screen component?
