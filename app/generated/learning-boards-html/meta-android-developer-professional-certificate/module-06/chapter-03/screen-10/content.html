Starter snippet (HomeScreen)
function HomeScreen({ navigation }) {
  const [todoText, setTodoText] = useState('');
  const [todos, setTodos] = useState([]);

  const addTodo = () => {
    if (todoText.trim().length > 0) {
      setTodos([...todos, todoText.trim()]);
      setTodoText('');
    }
  };

  // Render FlatList and navigate with todos.length
}
Notes & Checks
  • Use setTodos([...todos, newItem]) to avoid mutating state.
  • Clear the input after adding to improve UX.
  • Pass totalItems: todos.length when navigating to Details.
