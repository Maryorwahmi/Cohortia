useEffect Example (fetch once)
useEffect(() => {
  const fetchData = async () => {
    const response = await fetch('https://jsonplaceholder.typicode.com/todos/1');
    const json = await response.json();
    setData(json);
    setLoading(false);
  };

  fetchData();
  return () => { /* cleanup */ };
}, []);
Best Practices
  • Use empty array for component-mount effects like initial data fetch.
  • List dependencies that the effect uses; omit none intentionally.
  • Return cleanup to cancel subscriptions or timers.
Misconception Check
Do not use useEffect to compute derived state synchronously during render. Derived values should be computed directly or memoized. useEffect is for tasks that are intentionally performed after render and are allowed to be asynchronous.
