DetailScreen pattern
function DetailScreen({ route, navigation }) {
  const totalItems = route.params ? route.params.totalItems : 0;

  return (
    <View>
      <Text>To-Do List Details</Text>
      <Text>Total items: {totalItems}</Text>
      <Button title="Go back" onPress={() => navigation.goBack()} />
    </View>
  );
}
This defensive pattern ensures your screen renders sensibly when params are absent. Prefer small primitive params and re-fetch larger data when necessary.
