Fetch pattern (excerpt)
const [data, setData] = useState(null);
const [loading, setLoading] = useState(true);

useEffect(() => {
  let mounted = true;
  const fetchData = async () => {
    try {
      const resp = await fetch('https://jsonplaceholder.typicode.com/todos/1');
      const json = await resp.json();
      if (mounted) setData(json);
    } catch (e) {
      console.error(e);
    } finally {
      if (mounted) setLoading(false);
    }
  };
  fetchData();
  return () => { mounted = false; };
}, []);
UI states
  • Show loading indicator while loading is true.
  • Show data when available; show an error message when fetch fails.
  • Guard state updates if the component unmounts before fetch completes.
Concrete example output
Fetched Data: use the json response's title or id to render a summary. This gives a predictable user experience during asynchronous loads.
