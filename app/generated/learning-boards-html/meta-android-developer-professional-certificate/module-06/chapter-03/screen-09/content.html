Module 6 › Chapter 6.3 › Stack Navigator Patterns
Common Methods
  • navigation.navigate('ScreenName', params) — push a screen and pass params.
  • navigation.goBack() — pop one level.
  • navigation.popToTop() — return to the first screen.
Parameter Passing Example
Call: navigation.navigate('Details', { itemId: 86, otherParam: 'anything' }); Destination reads: const { itemId, otherParam } = route.params;
Design advice
Use stack navigation for hierarchical flows. Keep navigation simple: avoid passing large objects as params; pass IDs or small payloads and fetch larger data on the destination if needed.
