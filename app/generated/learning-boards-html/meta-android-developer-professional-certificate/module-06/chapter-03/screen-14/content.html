Module 6 › Chapter 6.3 › Key Concepts
Props
Immutable configuration passed from parent to child.
State & useState
Component-owned mutable data; changes trigger re-renders.
useEffect
Perform side effects after render and control them via dependencies.
Takeaway

Use props for configuration, use state for changing data, and use effects for outside interactions. These three patterns give you a predictable mental model for component behavior.
