Example: Login Form (excerpt)
import React, { useState } from 'react';
import { View, TextInput, Button } from 'react-native';

export default function Login() {
  const [username, setUsername] = useState('');
  const [password, setPassword] = useState('');

  const handleLogin = () => {
    if (username === 'user' && password === 'pass') {
      // success
    } else {
      // failure
    }
  };

  return (
    <View>
      <TextInput value={username} onChangeText={setUsername} placeholder="Username" />
      <TextInput value={password} onChangeText={setPassword} placeholder="Password" secureTextEntry />
      <Button title="Login" onPress={handleLogin} />
    </View>
  );
}
Explanation & Tips
  • Pass the setter directly to onChangeText for concise code.
  • Keep inputs controlled by always providing value prop tied to state.
  • Validate before submitting to avoid accidental empty submissions.
Common Mistake

Mixing controlled and uncontrolled inputs causes inconsistent state and warning messages. Always provide value and onChangeText for controlled fields.

Quick Exercise
Add inline validation: if username.trim() === '' show a small message and disable the submit action until both fields are non-empty.
