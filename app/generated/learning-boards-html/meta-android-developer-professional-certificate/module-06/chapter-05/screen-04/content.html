Module 6 › Chapter 6.5 › Signing & Keystore
Definition

What signing does

Signing assigns an unforgeable identity to your app and ensures the Play Console can verify the origin of future updates.

  • • Digital signature proves authenticity and integrity of a release artifact.
  • • Keystore contains the private key used to create signatures; protect it carefully.
  • • Play Console accepts updates only if they are signed with the same key recorded for that package name.
Common misconception

Using a debug key or committing a keystore to version control is unsafe and will break future updates.

Example & Commands
Generate a keystore with Java keytool as an example command. This creates a private key you will use to sign releases.
keytool -genkeypair -v -storepass <store_password> -keystore my-upload-key.keystore -alias my-key-alias -keypass <key_password> -keyalg RSA -keysize 2048 -validity 10000
Pro tip

Back up your keystore to a secure location outside the project directory and record passwords in a secure secrets manager.

Key takeaway

Keystores protect app identity. Losing them prevents updates — treat them like production credentials.
