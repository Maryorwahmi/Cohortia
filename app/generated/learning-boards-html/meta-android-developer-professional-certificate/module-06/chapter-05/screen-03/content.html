Pre-deployment skills to verify

These skills are practical checks you will apply to every release build.

01 Versioning

Increment versionCode for every release and update versionName for user-facing clarity. This is required for Play Console updates.

Mnemonic: bump the code
VERIFIED COMPETENCY MILESTONE
02 Assets

Provide high-resolution icons, screenshots, and splash images for multiple densities. Poor assets reduce installs and may delay approvals.

Mnemonic: pixel-perfect assets
VERIFIED COMPETENCY MILESTONE
03 Privacy & Content

Declare privacy policy, data collection, and ad usage in Play Console. Many apps are blocked for missing these items.

Mnemonic: policy ready
VERIFIED COMPETENCY MILESTONE
04 Testing & Builds

Test release builds on devices and emulator variants. Release optimizations like R8 can reveal issues absent from debug builds.

Mnemonic: test release
VERIFIED COMPETENCY MILESTONE
