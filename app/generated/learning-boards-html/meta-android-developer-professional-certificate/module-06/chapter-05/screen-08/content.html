Module 6 › Chapter 6.5 › Pre-deployment Checklist
Definition

Checklist for a successful release

Versioning

Bump versionCode and update versionName in build files. Play Console requires a higher versionCode for updates.

Assets

Provide high-res icon, screenshots, and feature graphic. Poor visuals hurt discovery and may delay approval.

Privacy & Declarations

Publish a privacy policy URL and complete content/ad declarations in the Play Console.

Testing

Install and run release builds on multiple devices and use testing tracks before production rollout.

Common mistakes
  • • Forgetting to increase versionCode before uploading a new release.
  • • Committing keystore files or passwords to version control.
  • • Leaving required Play Console fields blank, blocking publishing.
Key Takeaway

A short pre-upload checklist prevents common rejections. Test release builds and protect signing credentials before uploading.
