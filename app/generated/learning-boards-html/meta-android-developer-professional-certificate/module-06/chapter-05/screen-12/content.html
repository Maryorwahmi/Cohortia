Module 06 › Chapter 6.5 › ProGuard & R8
Definition

What ProGuard and R8 do

They shrink unused code, rename symbols, and optimize resources to reduce APK/AAB size and harden the app.

Why this matters: smaller downloads, lower storage usage.
What to watch: reflection and libraries that depend on class names.
Release-test checklist
  1. Generate a signed release AAB and install it on real devices.
  2. Test features that use reflection, serialization, or dynamic loading.
  3. If crashes occur, build mapping files and consult them to decode stack traces.
  4. Temporarily disable minify to isolate the problematic rules, then add explicit keep rules.
Common mistake

Assuming debug testing is enough. Release builds must be validated because of optimizations like R8.

Key Takeaway

Always include signed release builds in test plans and keep proguard rules under source control.
