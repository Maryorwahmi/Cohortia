Module 6 › Chapter 6.5 › Generate Signed AAB
Process

Steps to create a signed AAB

  1. 1
    Update versionCode and versionName in app/build.gradle.
  2. 2
    In Android Studio choose Build → Generate Signed Bundle / APK and pick Android App Bundle.
  3. 3
    Select or create a keystore; choose a secure path and strong passwords.
  4. 4
    Choose the release build variant and click Create. Locate the produced .aab via the IDE link.
Quick checklist

versionCode bumped, keystore path secured, release variant selected, artifact located and backed up.

Command callout
While Android Studio provides the GUI, you may also script gradle tasks. Example gradle commands illustrate building the bundle locally.
./gradlew bundleRelease
# This will produce an unsigned or signed AAB depending on your signing configuration in build.gradle or Gradle properties
Example

If you create a new keystore via the Android Studio dialog, record its path and passwords. Then run the bundle build and confirm a locate link appears in the IDE notifications.

Key Takeaway

Android Studio streamlines signing. Verify versioning and keystore before building to avoid blocked Play Console uploads.
