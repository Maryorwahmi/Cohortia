Typical setup failures
Identify and fix the environment issues that prevent your app from running.
Node/npm version
Verify with a version command. Use LTS and a single node manager to avoid conflicts.
Permissions
Global installs may need elevated privileges or a node version manager to avoid permission errors.
Network & QR
Ensure device and machine share a network and check firewall rules that could block the bundle requests.
Quick diagnostics
  1. Read terminal logs for explicit errors.
  2. Restart Metro and clear caches if behavior is inconsistent.
  3. Confirm emulator runs in Android Studio and ADB is discoverable.
