Definition › Native Components & Bridge
Native primitives
View, Text, Image map to the platform's UI building blocks so behavior and appearance match native apps.
Architecture overview
  • JavaScript thread: runs your app logic and component lifecycle.
  • Native thread: performs rendering and platform UI operations.
  • Bridge: asynchronous channel for commands and data between JS and native modules.
Misconception
The bridge is invisible cost-free plumbing — actually, heavy or synchronous bridge use can degrade performance.
Example: invoking a native API
When a JavaScript call requests the camera, the command goes over the bridge to a native module that presents the camera UI. The image result is sent back across the bridge to JavaScript.
Performance guidance
  1. Minimize frequent synchronous calls across the bridge.
  2. Batch updates and use native animations for smooth visuals.
  3. When heavy processing is needed, consider a native module.
Key Takeaway

The bridge enables powerful native integration, but design to reduce crossing it for best app responsiveness.
