Hands-on Activity › Initialize & Run
Step-by-step
  1. Confirm Node and npm are installed.
  2. Run the global install for Expo CLI.
  3. Initialize a blank project and cd into it.
  4. Start the development server and preview via Expo Go or emulator.
Terminal snippet
npm install -g expo-cli
expo init MyFirstReactNativeApp
cd MyFirstReactNativeApp
npm start
Verification: the app should display the default message about editing App.js. Save a change to see hot reload push the update to your device or emulator.
Key Takeaway

Follow terminal output and verify the default screen loads. Hot reload is the primary feedback loop for fast iteration.
