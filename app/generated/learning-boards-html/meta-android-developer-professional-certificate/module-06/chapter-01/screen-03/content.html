Run, Test, Troubleshoot
Practical milestones: emulator, Expo Go, Metro Bundler, and hot reload verification.
01 — Run on Android
Ensure Android Studio is installed and an emulator is configured or install Expo Go on a phone to scan the Metro QR code.
Mnemonic: Device-ready checklist — Android Studio, emulator image, USB debugging, same Wi-Fi.
VERIFIED COMPETENCY MILESTONE
02 — Metro Bundler & hot reload
Start the bundler with the start command. Confirm the QR code appears and that code edits update in the running app without a full rebuild.
Mnemonic: Edit → Save → See change.
VERIFIED COMPETENCY MILESTONE
03 — Troubleshoot common issues
Check Node and npm versions, inspect terminal output, and confirm firewall or network settings if device cannot fetch the bundle.
Mnemonic: Terminal first — errors are explicit.
VERIFIED COMPETENCY MILESTONE
04 — Know when to use native
When deep access to platform APIs or the highest possible performance is required, native Android or iOS may be preferable despite the cross-platform benefits.
Mnemonic: Trade-offs — ease vs deep native control.
