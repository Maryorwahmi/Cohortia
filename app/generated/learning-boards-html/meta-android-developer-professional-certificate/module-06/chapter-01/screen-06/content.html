Comparison › Expo CLI vs React Native CLI
Expo CLI (managed)
  • Simplifies setup and native linking for many common APIs.
  • Use Expo Go to preview without building native binaries.
  • Great for rapid prototyping and beginner workflows.
Misconception: Expo cannot be used for production — in many cases it can, but very specialized native features may require ejecting.
React Native CLI (bare)
  • Generates native Android and iOS projects you can open in platform IDEs.
  • Required when adding custom native modules or deep native SDKs.
  • Requires installing Android Studio and Xcode for full native builds.
Use case example: integrating a platform SDK with native-only bindings.
When to pick Expo
Prototype quickly, preview on devices, and avoid native build complexity.
When to pick CLI
Need custom native modules or deep integrations with platform SDKs.
Practical tip
Start with Expo. Move to CLI when you outgrow the managed workflow.
