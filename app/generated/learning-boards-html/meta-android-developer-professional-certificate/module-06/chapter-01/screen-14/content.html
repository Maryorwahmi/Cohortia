React Native
JavaScript components render as native UI elements across platforms.
Expo CLI
Managed workflow that speeds setup and preview via Expo Go.
Metro & Hot Reload
Dev server that serves your JS and pushes changes to running apps for fast iteration.
Summary

React Native gives a high-productivity path to native apps; choose Expo for speed, use CLI for custom native needs, and rely on Metro for fast feedback.
