Process Flow › Run on Expo Go or Emulator
Expo Go (physical device)
Install Expo Go from your app store. With Metro running, scan the QR code and your project loads instantly with hot reload.
Checklist
  • Device and dev machine on same Wi-Fi network for QR preview.
  • Expo Go running on the device while scanning the QR.
  • Check terminal output for bundler status.
Android emulator
Open Android Studio, start a virtual device, and then select 'Run on Android device/emulator' in Metro or trigger adb to install the bundle.
Common pitfalls
  • ADB not on PATH or emulator not running.
  • Firewall blocking bundle requests for physical device preview.
  • Not enabling USB debugging for a connected device.
Key Takeaway

Expo Go is the fastest preview route. Emulators are essential when you need to simulate device variants and debug native behaviors.
