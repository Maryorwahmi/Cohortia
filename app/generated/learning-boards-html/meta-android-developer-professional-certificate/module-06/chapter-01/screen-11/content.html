Definition › Metro Bundler & Hot Reload
Metro: the development server
Metro watches files, bundles JavaScript, and serves it to the running app with hot reload support.
Timeline of a change
Edit
You save a change in App.js.
Recompile
Metro rebuilds the affected module bundle.
Push
Hot reload applies the update to the running app.
Troubleshooting hints
  • Inspect terminal logs for bundler errors.
  • Confirm the device can reach the bundler (network or USB debug).
  • Restart Metro if stale caches cause inconsistent updates.
