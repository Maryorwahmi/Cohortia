Core Concept › What is React Native?
React Native — core idea
A framework that compiles your JavaScript and React components into native UI elements on each platform.
How it works
  • Write components with primitives like View and Text that map to native widgets.
  • JavaScript logic runs and communicates with native modules via a bridge when needed.
  • Metro Bundler serves your JavaScript during development and enables hot reload for fast iteration.
Common misconception
Not a web app inside a shell — native rendering is used, though the JS-to-native bridge must be managed for heavy data flows.
Metaphor
Think of React Native as a translator: your JavaScript describes UI and behavior, and React Native speaks the platform's native UI language for each device.
Concrete example
A simple label
When you render a Text component, Android uses native text rendering and iOS uses its own text control. Styling looks consistent but behaves like a native control on each platform.
Key Takeaway

React Native gives native UI performance while letting you build in JavaScript, but assess bridge costs for heavy data operations.
