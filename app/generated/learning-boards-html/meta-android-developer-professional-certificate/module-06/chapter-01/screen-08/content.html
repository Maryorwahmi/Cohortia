Process › Install Expo CLI & init
Commands (example)
Run these in your terminal. If you use yarn, substitute the package manager commands accordingly.
npm install -g expo-cli
expo init MyFirstReactNativeApp
cd MyFirstReactNativeApp
npm start
If global install fails due to permissions, consider using a node version manager or run with appropriate elevated permissions on your OS.
What Metro Bundler shows
  • A QR code to scan with Expo Go.
  • Options to run on Android emulator, web, or to publish.
  • Terminal output with errors and dependency warnings.
Common mistake
Running start in the wrong directory or missing node modules — always cd into the project folder before starting the server.
Key Takeaway

The terminal guides you: follow its instructions, address permission or dependency warnings, and then scan the QR code to preview.
