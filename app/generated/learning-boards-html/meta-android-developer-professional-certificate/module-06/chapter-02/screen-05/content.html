Example App.js

import React from 'react';
import { StyleSheet, Text, View } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Hello, Cohortia Learners!</Text>
      <Text>This is our first React Native UI.</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#fff',
    alignItems: 'center',
    justifyContent: 'center',
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    marginBottom: 10,
    color: '#333',
  },
});
Explanation
  • The exported function App returns a JSX tree composed of View and Text components.
  • StyleSheet.create defines style objects referenced by the style prop, not CSS classes.
  • Container uses flex one to fill available space and center children via justifyContent and alignItems.
  • Text is required for any visible string; plain strings outside Text will not render properly.
Common Mistake

Expecting HTML class names or forgetting to wrap strings in Text are frequent issues for newcomers.
