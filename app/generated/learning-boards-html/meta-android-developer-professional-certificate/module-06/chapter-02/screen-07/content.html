Image Examples

// Local image
<Image source={require('./assets/logo.png')} style={{ width: 100, height: 100 }} />

// Network image
<Image source={{ uri: 'https://reactnative.dev/img/tiny_logo.png' }} style={{ width: 50, height: 50 }} />
Text rules
Always wrap strings inside a Text component. Text components support nested styling and are required for accessibility and correct layout. Combine Text and Image inside a View when building composite items like a labeled avatar.
Common Mistake

Using raw strings or web tags like img will not behave as expected in React Native.
