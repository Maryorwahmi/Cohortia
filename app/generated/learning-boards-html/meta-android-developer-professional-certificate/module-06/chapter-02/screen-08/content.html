Simple Button

<Button title="Press Me" onPress={() => alert('Button Pressed!')} />
Button is straightforward but limited in styling. For richer controls, use touchable primitives.
Custom touchable
Wrap a View with TouchableOpacity or Pressable to include text, images, and custom layouts. These provide full styling control and press feedback hooks.
Pro tip

Use Pressable when you need granular press-state callbacks; use TouchableOpacity for a simple fade effect.
