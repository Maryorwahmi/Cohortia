Controlled TextInput Example

import React, { useState } from 'react';
import { View, Text, TextInput, Button, StyleSheet } from 'react-native';

export default function App() {
  const [name, setName] = useState('');

  return (
    <View style={styles.container}>
      <Text style={styles.label}>Enter your name:</Text>
      <TextInput
        style={styles.input}
        placeholder="e.g., Jane Doe"
        onChangeText={text => setName(text)}
        value={name}
      />
      <Button title="Greet Me" onPress={() => alert(`Hello, ${name || 'Guest'}!`)} />
      <Text style={styles.greeting}>Your name is: {name}</Text>
    </View>
  );
}
Explanation
  • useState stores the current text value and keeps the input controlled.
  • onChangeText receives the changed text and updates state immediately.
  • value binds the TextInput appearance to the state variable so it stays in sync.
Common Mistake

Setting a value without an onChangeText handler prevents user edits and makes the field appear read-only.
