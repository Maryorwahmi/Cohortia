Interaction Summary
  • onPress runs a function when a button or touchable is activated.
  • onChangeText receives the new input string each time the user types.
  • Keep inputs controlled by binding value to state so UI stays in sync.
Scenario
Use onChangeText to validate input as the user types, and use onPress to submit or navigate. Controlled patterns let you reuse the same value across components, such as showing a live preview of typed text.
Check your understanding

How would you show typed text instantly elsewhere in the UI? Use onChangeText to update state, then read that state from another Text element.
