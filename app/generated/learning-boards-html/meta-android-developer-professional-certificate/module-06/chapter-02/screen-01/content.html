Building User Interfaces with React Native

You will learn to describe mobile UI with JSX, compose native-mapped components, style using JavaScript objects, and arrange layouts with Flexbox so your app adapts cleanly to different screens.

This chapter prepares you to build a simple, native-feeling profile card and wire basic interactions like button presses and text updates.

Explore Key Topics
JSX
Write UI using JavaScript XML to describe component trees.
Core Components
Use View, Text, Image, Button, and TextInput as the building blocks.
Flexbox & Interaction
Flexbox positions items; props like onPress and onChangeText handle user input.
UI composition
Compose View and Text to form a native layout.
View
A flexible container that maps to native layout primitives on each platform.
Text
Always wrap visible text in the Text component for correct rendering.
StyleSheet
Create immutable style objects to improve readability and performance.
Flex
A single number that controls how a view grows to fill available space.
