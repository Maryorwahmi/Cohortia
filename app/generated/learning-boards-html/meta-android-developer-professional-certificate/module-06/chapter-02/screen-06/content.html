StyleSheet Pattern

const styles = StyleSheet.create({
  container: {
    flex: 1,
    flexDirection: 'column',
    justifyContent: 'center',
    alignItems: 'center',
    backgroundColor: '#f0f0f0',
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#333',
  },
});
Notes & Examples
  • Property names use camelCase: backgroundColor, marginBottom, fontSize.
  • Use numeric values for dimensions and spacing where appropriate; colors are strings.
  • Inline styles are fine for dynamic values, but keep most rules in StyleSheet for clarity.
When to use inline
When a style depends on runtime values such as a computed width or a dynamic color variable, apply an inline object merged with a StyleSheet entry.
