Module 6 › Chapter 6.2 › Troubleshooting
Debugging Steps
  1. Confirm the outermost container has flex set so it can expand.
  2. Visualize container bounds with temporary backgroundColor values.
  3. Check flexDirection to know which axis justifyContent controls.
  4. Simplify nested views and reapply styles incrementally.
Example Fix
If children sit at the top, add flex one to the parent container and set justifyContent to center. If centering only horizontally, ensure alignItems is center as well. Small visual checks often reveal the missing flex property.
Pro tip

Use temporary borders or background colors to quickly see which container is restricting layout space.
