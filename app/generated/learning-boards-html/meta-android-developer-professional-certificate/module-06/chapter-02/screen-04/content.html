Module 6 › Chapter 6.2 › Component Model
Definition

Core components are small, purpose-built primitives that render to native widgets. Treat each component as the correct semantic choice for content and interaction.

View
Container and layout primitive. Maps to ViewGroup or UIView depending on platform.
Text
Used for all visible text. Always wrap strings in a Text component.
Image, Button, TextInput
Image displays images, Button handles simple presses, TextInput collects user text input.
Concrete Example
A profile card composes an Image for the avatar and Text for the name and title, all wrapped inside a View that controls layout. Because these components map to native widgets, the card will behave like a native view on both Android and iOS.
Scenario
Imagine showing a photo, a bold name, and a subtitle. Use Image for the photo, Text for both strings, and a View to align them with Flexbox.
Key Takeaway

Choose the component by role: layout uses View, text uses Text, images use Image, inputs use TextInput, and simple actions use Button or touchables.
