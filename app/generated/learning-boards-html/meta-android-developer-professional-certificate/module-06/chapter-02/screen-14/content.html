Module 6 › Chapter 6.2 › Key Concepts
JSX
Write UI as a tree of components with HTML-like syntax inside JavaScript.
Core Components
Use View, Text, Image, Button, and TextInput as building blocks for UI.
StyleSheet
Define styles as JavaScript objects and prefer immutable StyleSheet entries for performance.
Takeaway

Compose screens from core components, style them clearly, and use Flexbox to build responsive layouts that behave like native UI.
