Key Properties
  • flex: a number controlling how a view grows to fill space.
  • flexDirection: main axis direction, column or row.
  • justifyContent: distribution along the main axis.
  • alignItems: alignment along the cross axis.
Common Pitfalls
Forgetting flex on the outer container prevents children from filling the screen. Also, mixing main and cross axis expectations leads to alignment surprises when switching flexDirection.
Centering Example

const styles = StyleSheet.create({
  container: {
    flex: 1, // fills screen
    flexDirection: 'column',
    justifyContent: 'center', // centers vertically
    alignItems: 'center', // centers horizontally
  },
});
Key Takeaway

Visualize the main axis and cross axis, and use flex on the outer container to let children adapt to available space.
