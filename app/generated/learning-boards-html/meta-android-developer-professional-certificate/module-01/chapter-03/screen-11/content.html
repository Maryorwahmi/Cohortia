Code Walkthrough
Single-expression examples
Short functions can be written with equals and no braces for clarity.
fun subtract(a: Int, b: Int) = a - b
fun multiply(a: Int, b: Int) = a * b

println("Difference: ${subtract(10, 4)}") // Difference: 6
When to expand
If you need multiple statements, exception handling, or early returns, prefer a full function body for clarity and debuggability.
Key Takeaway

Prefer single-expression functions for trivial transforms; expand to blocks when logic grows or explicit types are helpful.
