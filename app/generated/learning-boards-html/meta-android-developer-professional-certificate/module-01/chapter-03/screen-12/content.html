Default and named args
Provide defaults in the signature and use named args to skip or reorder parameters at call sites.
fun sendMessage(
  message: String,
  recipient: String = "User",
  priority: Int = 1
) {
  println("Sending '$message' to $recipient with priority $priority")
}

sendMessage("Welcome")
sendMessage("Urgent update!", "Admin")
sendMessage(message = "Reminder", priority = 3)
Best Practice
Use named arguments for clarity when skipping defaults. Favor small parameter lists or option objects for many settings.
Key Takeaway

Defaults and named arguments simplify calls and document intent. Use them thoughtfully to keep APIs readable and unambiguous.
