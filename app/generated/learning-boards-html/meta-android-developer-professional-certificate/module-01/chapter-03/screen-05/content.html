Definition
when expression
A versatile multi-branch expression that can match values, ranges, and types, and can return a value when exhaustive.
Example
val dayOfWeek = 3
val dayType = when (dayOfWeek) {
  1, 7 -> "Weekend"
  in 2..6 -> "Weekday"
  else -> "Invalid day"
}
println(dayType) // Prints "Weekday"
Variants
  • when with argument: matches the value against branches.
  • when without argument: evaluates boolean expressions in each branch.
  • use is for type checks inside when branches.
Common Misconception
Thinking when is limited to constants. It can handle ranges and type checks and even arbitrary conditions when used without an argument.
Concrete Scenario
Detect an object's runtime type and print its detail: when (obj) { is String -> println("Length ${obj.length}") is Int -> println("Value $obj") else -> println("Unknown") }.
Key Takeaway

Use when for clear multi-case logic and prefer exhaustiveness for safety; use else to cover unknown inputs.
