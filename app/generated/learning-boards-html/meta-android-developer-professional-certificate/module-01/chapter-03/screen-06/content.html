when with type checks
Smart casts let you use the checked type inside the branch without explicit casts.
val obj: Any = "Hello"
when (obj) {
  is String -> println("It's a String of length ${obj.length}")
  is Int -> println("It's an Int with value $obj")
  else -> println("Unknown type")
}
Why this helps
  • Reduces boilerplate casting code.
  • Combines type checks with handling logic in one place.
  • When without subject supports complex boolean conditions per branch.
Example
when without subject
val x = 5
val parity = when {
  x % 2 == 0 -> "even"
  x % 2 == 1 -> "odd"
  else -> "unknown"
}
Misconception
Assuming smart cast works outside branches. Smart casts apply only where the compiler can prove the type after the check.
