Definition
break and continue behavior
Use break to stop a loop and continue to skip the current iteration.
for (i in 1..5) {
  if (i == 3) continue // skip 3
  if (i == 5) break    // stop loop at 5
  println("Loop value: $i") // Prints 1, 2, 4
}
When to avoid them
  • Avoid deep nesting with many breaks; it reduces clarity.
  • Consider extracting logic into functions and using return instead of labeled breaks.
Pro Tip
If you need to break out of multiple nested loops, refactor into a helper function and use return to exit early instead of complex labels.
Key Takeaway

Use break and continue for local loop control, but prefer simple loop conditions and small helper functions for complex flow.
