Definition
while and do-while
A while checks before each iteration; a do-while checks after, guaranteeing one execution.
// While example
var x = 0
while (x < 3) {
  println("While loop: $x")
  x++
}

// Do-while example
var y = 0
do {
  println("Do-While loop: $y")
  y++
} while (y < 0) // executes once
Common Mistake
Infinite loops from failing to update the loop variable are frequent. Check that each iteration progresses state toward the stopping condition.
Guided Check
  • Identify the loop variable and its range.
  • Confirm the body updates that variable toward the end condition.
  • Consider edge cases where the condition is initially false or true indefinitely.
