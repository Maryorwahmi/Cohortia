Definition
Function signature and return
Define inputs and outputs clearly so callers know what to pass and expect back.
fun calculateSum(a: Int, b: Int): Int {
  return a + b
}

fun printMessage(message: String) { // returns Unit
  println(message)
}
Common Pitfall
Not declaring a return type for non-Unit functions makes intent unclear. Prefer explicit types for public APIs and library code.
Key Takeaway

Write clear function signatures. When in doubt, state the return type to document behavior and help the compiler catch mistakes.
