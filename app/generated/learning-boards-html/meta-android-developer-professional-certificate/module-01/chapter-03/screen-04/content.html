Definition
if as an expression
An if expression evaluates conditions and returns the chosen branch value. Branches must yield compatible types when assigned.
Explanation
  • An if can return a value directly to a variable.
  • Use else to ensure an expression returns a value on every path.
  • If branches include blocks, the last expression in the block is the branch value.
Example
val a = 7
val b = 5
val max = if (a > b) a else b
println("Max: $max") // Prints Max: 7
Key Takeaway

Use if expressions to compute values concisely; ensure each branch produces a compatible type and include else when needed.

Common Pitfall
Omitting an else when the expression needs a value causes a compile-time error. Another mistake is mixing incompatible branch types.
Analogy
Think of an if expression as asking a question that hands back an answer you can store; the answer must be the same kind no matter which path answers.
