Comparison
for with ranges vs collections
Ranges are numeric sequences; collections iterate elements directly. Choose the form that communicates intent.
// Inclusive range
for (i in 1..5) println(i) // 1,2,3,4,5

// Exclusive end
for (i in 1 until 5) println(i) // 1,2,3,4

// Backwards with step
for (i in 10 downTo 0 step 2) println(i) // 10,8,6,4,2,0
Best Practices
  • Prefer for-each over manual indices for collections when you only need values.
  • Use withIndex when you need the index.
  • Remember until excludes the upper bound; use .. when inclusive behavior is required.
Key Takeaway

Use range helpers to express sequence direction and step clearly instead of manually adjusting indices.
