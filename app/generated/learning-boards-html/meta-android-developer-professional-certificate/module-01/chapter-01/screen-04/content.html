Core Concept
What is Android?
A Linux-based, open-source mobile OS that provides APIs for device features and a layered runtime for apps.
Definition
An OS built on a modified Linux kernel with a stable API surface used by apps and system services.
Concrete example
A simple camera app uses the same framework calls across device models while drivers differ at the kernel/HAL level.
Common misconception
Open-source doesn’t mean unstable; API levels and platform releases enforce compatibility for apps.
Key Takeaway

Treat Android as layered and API-driven: choose API levels consciously to balance reach and features.

Why this matters
  • Open source + large market reach makes Android a strategic target for many apps.
  • APIs let you access device features without dealing with drivers directly.
  • Device diversity means you must test across API levels and form factors.
