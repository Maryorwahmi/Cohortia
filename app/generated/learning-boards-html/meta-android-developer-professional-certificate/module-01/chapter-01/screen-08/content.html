Core Concept
Application Framework
Framework services provide the patterns and interfaces you call to manage UI, data, and notifications without low-level code.
Activity Manager
Handles screens and their lifecycle events.
Content Providers
Share structured data between apps securely.
Notification Manager
Deliver user-visible notifications and control behavior.
Concrete example
When rotating the device, the Activity lifecycle triggers callbacks; handling them properly keeps the UI state intact without crashes.
Common mistake
Assuming Activities are permanent. The system may destroy and recreate them; save state in onSaveInstanceState or ViewModel.
Key Takeaway

Use framework services correctly to manage lifecycle and data; this prevents leaks and ensures consistent user experiences.
