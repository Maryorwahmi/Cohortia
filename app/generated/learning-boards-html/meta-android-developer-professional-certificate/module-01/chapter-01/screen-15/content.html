API Level
Numeric platform identifier that controls available APIs and compatibility.
AVD
Emulator configuration to test on virtual devices; mirror target devices for accuracy.
Gradle
Build automation used to compile and package your app; dependencies and versions matter.
Summary Takeaway
Set up Android Studio and the SDK carefully, choose API and AVD configurations that match your goals, and verify your toolchain by building and running a simple app. Use Run and Logcat to diagnose issues and progress to more advanced features once the environment is stable.
