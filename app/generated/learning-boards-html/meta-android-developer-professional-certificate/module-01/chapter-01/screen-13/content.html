Use the template to scaffold MainActivity and a layout, then modify the TextView to verify the run cycle.
Starter layout (activity_main.xml)
<?xml version="1.0" encoding="utf-8"?>
<androidx.constraintlayout.widget.ConstraintLayout xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto"
    xmlns:tools="http://schemas.android.com/tools"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    tools:context=".MainActivity">

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Hello World!"
        app:layout_constraintBottom_toBottomOf="parent"
        app:layout_constraintEnd_toEndOf="parent"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintTop_toTopOf="parent" />

</androidx.constraintlayout.widget.ConstraintLayout>
Edit the TextView android:text to 'Hello, Cohortia Learner!' either in Design or Code view, then run on an emulator or device to confirm the greeting appears.
Run checklist
  • Confirm SDK Platform and Platform-Tools are installed.
  • Select an AVD or connect a device with USB debugging enabled.
  • Click Run and monitor the Run and Logcat tabs for deployment output.
If something fails
Check Gradle sync, SDK Manager for missing components, and ensure virtualization is enabled for emulator acceleration.
Key Takeaway

A small UI edit and successful run confirm your development pipeline, enabling faster iterations on app features.
