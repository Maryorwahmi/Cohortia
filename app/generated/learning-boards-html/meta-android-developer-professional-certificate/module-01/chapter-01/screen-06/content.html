Definition
Kernel & HAL
The kernel provides drivers and system services; HAL exposes standardized C interfaces the framework uses to access hardware.
Kernel tasks
Security, memory and process management, low-level drivers.
HAL tasks
Standard device interfaces ensuring framework calls work across models.
Scenario
If an app’s camera fails only on one phone model, suspect the HAL or driver. If it fails across devices, the issue likely lives in the app or framework usage.
Diagnostic checklist
  • Test on another device or emulator image.
  • Check Logcat for HAL or driver errors.
  • Confirm permissions and framework API usage are correct.
Pro Tip

Use an emulator to isolate app logic, then test on a physical device to validate HAL or driver behavior.
