Definition
Layered Architecture
Linux Kernel
Core services: drivers, security, process and memory management.
Hardware Abstraction Layer (HAL)
Standard interfaces letting framework talk to hardware without device-specific code.
Android Runtime (ART) & Libraries
Executes app code; compiles bytecode to native code and provides core libraries.
Application Framework
High-level APIs like Activity Manager and Notification Manager used by apps.
Applications
System and third-party apps that provide user-facing features.
Flow example
When an app requests camera access, the request uses framework APIs, which call into HAL; HAL uses kernel drivers to talk to the hardware. A permission denial could occur at the framework level; a hardware failure may be traced to HAL or kernel.
Common misconception
ART is not a generic Java VM. It’s optimized for Android with ahead-of-time compilation and libraries tuned for mobile performance.
Key Takeaway

Knowing the layers helps you decide whether a bug is in your code, the runtime, or the hardware path.
