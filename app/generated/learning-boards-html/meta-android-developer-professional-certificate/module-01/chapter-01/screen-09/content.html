Tooling
Android Studio
An integrated environment with editor, Gradle build system, profilers, and the AVD Manager to compile, deploy, and debug Android apps.
Templates & Scaffolding
Use Empty Activity to start quickly and learn structure.
Profilers & Debuggers
Measure CPU, memory, and network to optimize ART behavior.
Installation note
During setup, permit Android Studio to download the Android SDK. Missing components are a frequent cause of project creation issues.
Concrete example
Create a New Project, pick Empty Activity, choose Kotlin, and let Android Studio scaffold MainActivity and a layout so you can run right away.
Common pitfall

Not installing SDK Platforms or Platform-Tools will prevent build or emulator tasks from working; always check the SDK Manager after install.
