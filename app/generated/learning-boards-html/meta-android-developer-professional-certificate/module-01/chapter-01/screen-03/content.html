How we'll prove competence
Sketch the Android layers
Draw or list kernel, HAL, ART/libraries, framework, and apps. Note where permissions are checked and where native code runs.
Identify platform advantages
Name three reasons to target Android and give a concrete app idea that uses device APIs.
Confirm SDK installation
Open SDK Manager, ensure Platform and Platform-Tools are installed, and run a Gradle sync to confirm build readiness.
Create AVD and run app
Create a virtual device, allocate adequate RAM, build an Empty Activity, modify the text, and observe the 'Hello' message on the emulator.
