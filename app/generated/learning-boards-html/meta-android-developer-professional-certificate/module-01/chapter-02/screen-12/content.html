Module 1 › Chapter 1.2 › User Profile Activity
Starter Code
fun main() {
  // 1. Declare variables
  val userName: String = "Jane Doe"
  var userAge: Int = 28
  val isPremiumUser: Boolean = true
  var lastLoginDate: String? = null
  val accountBalance: Double = 1234.56

  // 2. Simulate login
  lastLoginDate = "2023-10-27"

  // 3. Use Elvis for display value
  val displayLoginDate = lastLoginDate ?: "Never logged in"

  // 4. Compute bonus and print summary
  val balanceWithBonus = accountBalance * 1.10
  println("--- User Profile ---")
  println("Name: $userName")
  println("Age: $userAge")
  println("Premium: $isPremiumUser")
  println("Last Login: $displayLoginDate")
  println("Balance (with 10% bonus): $${balanceWithBonus}")
}
Expected Output (Simulated)
--- User Profile --- Name: Jane Doe Age: 28 Premium: true Last Login: 2023-10-27 Balance (with 10% bonus): $1358.016
Common Pitfall

If lastLoginDate is null and you forget Elvis, displayLoginDate will be null and your UI may show an unintuitive blank or error. Provide a clear fallback.
