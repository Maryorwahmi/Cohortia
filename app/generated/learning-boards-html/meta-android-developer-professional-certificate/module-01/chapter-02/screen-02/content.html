Learning Objectives

Bloom's bar: Learn → Understand → Apply → Master

Verified Competency Milestone
01 • val vs var
Choose immutability or mutability

Understand why preferring val reduces bugs and how var enables changing state like a live high score.

VERIFIED COMPETENCY MILESTONE
02 • Data Types
Use Int, Double, Boolean, Char, String

Know when to declare types explicitly and when to rely on type inference for clearer code.

VERIFIED COMPETENCY MILESTONE
03 • Null Safety
Nullable ?, safe calls, Elvis

Adopt nullable types and operators to avoid NullPointerExceptions at runtime and provide safe defaults.

VERIFIED COMPETENCY MILESTONE
04 • Operators & Templates
Compute and format values

Apply arithmetic and logical operators and use string templates to produce readable output messages.
