fun main() {
  val appName: String = "MyAwesomeApp"
  // appName = "NewApp" // Compiler error: Val cannot be reassigned

  var userScore: Int = 100
  userScore = 150 // allowed

  val list = mutableListOf("Alice")
  list.add("Bob") // allowed: reference is val but object mutated
}
The editor shows the exact lines that a compiler would flag for reassignment of val. Fixes usually involve switching to var only when reassignment is required by design.

Misconception

Thinking val prevents all mutation is incorrect. It prevents reassigning the variable to a new object, not modifying the object itself.

Pro Tip

If you must mutate, document why and keep changes localized. Prefer immutable models for shared state.
