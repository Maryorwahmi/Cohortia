Process

Arithmetic & Assignment

  1. Use +, -, *, /, % for numerical computations.
  2. Use = for assignment and +=, -=, *=, /= for compound updates.
  3. Watch operand types: Int / Int -> Int; convert to Double for floating results.
  4. Use parentheses to enforce specific evaluation order.
Example
fun main() {
  var counter = 0
  counter += 5 // counter is now 5

  val num1 = 10
  val num2 = 3
  println("Integer division: ${num1 / num2}") // prints 3
  println("Floating division: ${num1 / 3.0}") // prints 3.3333333333333335

  var balance = 100.0
  balance *= 1.1 // apply 10% bonus
  println("Balance: $${balance}")
}
Misconception

Assuming division always yields a float can lead to logic errors. Confirm operand types when precise values matter.
