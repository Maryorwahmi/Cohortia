Mini-Quiz

Question 1

Given val message: String? = "Items available" then message = null. Which line causes a compilation error and why?

Answer: Reassigning the val causes error; val is immutable even if nullable.
Question 2

What prints for println(10 / 3)? Explain why and how to get a fractional result.

Answer: Prints 3 due to integer division. Use a Double operand like 10.0 / 3 to get a fractional result.
Practical fix

If you need a value to change, declare it as var. If null may appear, use safe calls or Elvis to supply a fallback and avoid runtime errors.
