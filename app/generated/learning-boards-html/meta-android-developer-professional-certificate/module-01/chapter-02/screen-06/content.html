Definition

Common Kotlin Types

  • Int — common whole numbers, default integer type.
  • Double — higher-precision decimal numbers.
  • Boolean — true or false flags.
  • Char — single characters in single quotes.
  • String — sequences of characters in double quotes.
Misconception

Assuming inference always picks the type you expect can lead to integer division surprises. Be explicit if required.

Example & Tip
fun main() {
  val integerNumber: Int = 42
  val decimalNumber: Double = 3.14159
  val inferredInt = 100 // inferred as Int
  val inferredDouble = 20.5 // inferred as Double

  println(10 / 3)    // 3 -> integer division
  println(10.0 / 3)  // 3.3333333333333335 -> floating-point division
}
Key Takeaway

Know your types and when to annotate. Use floating operands to force floating division.
