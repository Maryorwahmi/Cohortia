Module 1 › Chapter 1.2 › Final Reminders
Default to val
Immutability reduces accidental state changes and simplifies reasoning.
Handle nulls explicitly
Use ?., ?: and avoid !! unless you are certain the value is non-null.
Be type-aware
Operand types affect results; format outputs intentionally when presenting values.
Final Tip

Practice these patterns in small functions and profiles so the rules become natural when writing app logic.
