fun main() {
  var lastLoginDate: String? = null
  val displayLoginDate = lastLoginDate ?: "Never logged in"
  println("Display: $displayLoginDate")

  // Simulate login
  lastLoginDate = "2023-10-27"
  println("After login: ${lastLoginDate?.length} characters")
}
Console Output (Simulated)
Display: Never logged in After login: 10 characters
Why it matters

Providing a default value for display avoids UI blanks and reduces conditional logic in the view layer.
