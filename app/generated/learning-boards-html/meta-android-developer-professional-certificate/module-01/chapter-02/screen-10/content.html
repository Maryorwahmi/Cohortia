Operators
  • == / != — structural equality (values).
  • === / !== — referential equality (same object).
  • < > <= >= — relational comparisons for numbers.
  • &&, ||, ! — logical AND, OR, NOT with short-circuiting.
Misconception

Using === for value comparison of strings will lead to unexpected results; prefer == for structural equality.

Example
fun main() {
  val a = "hello"
  val b = String("hello".toCharArray())
  println(a == b)  // true (structural equality)
  println(a === b) // false (different references)

  val isSunny = true
  val isWarm = false
  println(isSunny && isWarm) // false
  println(isSunny || isWarm) // true
}
