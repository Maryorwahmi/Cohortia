Definition

Nullable types & operators

  • String? — nullable type allowing null values.
  • ?. — safe call, returns null if the receiver is null.
  • ?: — Elvis, supplies a default when left side is null.
  • !! — non-null assertion, throws if null; use sparingly.
Example
fun main() {
  var nullableString: String? = "I am not null"
  println(nullableString?.length) // prints 13

  nullableString = null
  println(nullableString?.length) // prints null

  val nameLength = nullableString?.length ?: 0
  println("Length of name (defaulting to 0 if null): $nameLength") // prints 0

  // val definitelyNonNull: String = nullableString!! // DANGEROUS: throws if null
}
Common Mistake

Overusing !! defeats Kotlin's safety. Prefer safe calls and Elvis for predictable behavior.
