Managing the Database: The AppDatabase Class

The Central Hub for Room Persistence

Database Configuration
  • @Database(entities = [...], version = 1, exportSchema = false): Lists entities, sets version, and controls schema export.
  • Extends RoomDatabase and declares abstract DAO methods.
Singleton Pattern

A companion object with a getDatabase method ensures only one instance of the database is created, preventing resource leaks.

Key Takeaway

The AppDatabase class is the central orchestrator for Room, providing a single, managed access point to your entire database and its DAOs.

AppDatabase.ktKotlin
import android.content.Context
import androidx.room.Database
import androidx.room.Room
import androidx.room.RoomDatabase

@Database(entities = [Task::class], version = 1, exportSchema = false)
abstract class AppDatabase : RoomDatabase() {
    abstract fun taskDao(): TaskDao

    companion object {
        @Volatile
        private var INSTANCE: AppDatabase? = null

        fun getDatabase(context: Context): AppDatabase {
            return INSTANCE ?: synchronized(this) {
                val instance = Room.databaseBuilder(
                    context.applicationContext,
                    AppDatabase::class.java,
                    "task_database" // Database name
                ).build()
                INSTANCE = instance
                instance
            }
        }
    }
}
