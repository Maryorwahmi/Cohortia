The Three Pillars of Room

Understanding Entity, DAO, and Database Components

Entity

Represents a table in the SQLite database. Each field in the Entity class corresponds to a column in that table.

DAO (Data Access Object)

An interface or abstract class defining methods for database interactions (e.g., insert, query, update, delete). Room generates the SQL.

Database

An abstract class extending `RoomDatabase` that serves as the main access point for the underlying database connection and provides access to DAOs.

Key Takeaway

Entity, DAO, and Database are the foundational components of Room, each playing a distinct role in defining, interacting with, and managing your application's persistent data.
