Interacting with Data: The DAO Interface

Defining CRUD Operations for Your Entities with @Dao

DAO Annotations
  • @Dao: Identifies an interface/abstract class as a Data Access Object.
  • @Insert, @Update, @Delete: For common Create, Update, Delete operations.
  • @Query("SELECT * FROM tasks"): For custom SQL queries.
Asynchronous & Reactive

Use suspend for Coroutines to perform operations asynchronously and Flow to observe database changes reactively.

Key Takeaway

DAOs are the primary mechanism for interacting with your Room database, providing a clear, type-safe, and asynchronous way to perform all necessary data operations.

TaskDao.ktKotlin
import androidx.room.Dao
import androidx.room.Insert
import androidx.room.Query
import androidx.room.Update
import androidx.room.Delete
import kotlinx.coroutines.flow.Flow

@Dao
interface TaskDao {
    @Insert
    suspend fun insertTask(task: Task) // Use suspend for coroutines

    @Update
    suspend fun updateTask(task: Task)

    @Delete
    suspend fun deleteTask(task: Task)

    @Query("SELECT * FROM tasks ORDER BY id DESC")
    fun getAllTasks(): Flow<List<Task>> // Flow for observing changes

    @Query("SELECT * FROM tasks WHERE id = :taskId")
    suspend fun getTaskById(taskId: Int): Task?
}
