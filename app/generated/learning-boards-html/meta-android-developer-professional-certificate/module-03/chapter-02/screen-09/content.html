Module 3 › Chapter 3.2 › Navigation Editor
Steps to design your graph
  1. Sketch the user flow: start, list/detail, settings, etc.
  2. Create fragment layouts and classes for each screen.
  3. Open New → Navigation Resource File and name nav_graph.xml.
  4. Use the Navigation Editor to add destinations and draw actions.
  5. Define arguments on destinations with types, defaults, and nullability.
Practical checks
Confirm startDestination matches the intended entry screen.
Give actions meaningful ids so generated Directions are readable.
Keep nav_graph.xml under version control for team review.
Key Takeaway
Use the editor to speed design, but verify the underlying XML and argument definitions for correctness.
