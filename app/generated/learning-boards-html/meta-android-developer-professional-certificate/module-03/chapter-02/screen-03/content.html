Implementation Checklist
Dependencies
Add navigation-fragment-ktx and navigation-ui-ktx and apply safeargs plugin in Gradle.
NavHost
Embed NavHostFragment in your activity layout and set app:navGraph.
Safe Args
Apply safeargs.kotlin plugin and use generated Directions/Args classes for navigation and retrieval.
Troubleshooting
Ensure navigation occurs after NavHost is active; avoid passing very large objects via arguments.
Quick code reference
// build.gradle (Module: app)
dependencies {
  implementation("androidx.navigation:navigation-fragment-ktx:2.7.7")
  implementation("androidx.navigation:navigation-ui-ktx:2.7.7")
}
// apply plugin in app-level build.gradle
apply plugin: 'androidx.navigation.safeargs.kotlin'
