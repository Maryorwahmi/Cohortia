Multiple choice — key idea
Which is most robust to pass an Int userId from FragmentA to FragmentB? Define an <argument> in nav_graph and use FragmentADirections.actionAToB(id). This uses Safe Args to be type-safe and compile-checked.
Code check
Implement the navigation call and confirm ProfileFragmentArgs is generated and provides typed accessors. If unresolved, confirm safeargs plugin is applied and rebuild.
Key Takeaway
Safe Args is the intended, straightforward, and type-safe approach for simple argument passing in navigation flows.
