Module 3 › Chapter 3.2 › Deep Links & Global Actions
Deep link example
Declare a deepLink element in the destination and map URI placeholders to destination arguments so external URIs can open specific screens with parameters.
Global actions
Define actions at the graph root to reuse across multiple destinations. Useful for common screens like settings or help.
Practical note
Test deep links to ensure required data or authentication is present, and consider guard destinations if state must be enforced before showing content.
