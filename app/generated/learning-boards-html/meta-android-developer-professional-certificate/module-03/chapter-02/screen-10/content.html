Module 3 › Chapter 3.2 › Hands-on Activity
Starter steps
  1. Add navigation dependencies and apply safeargs plugin.
  2. Create WelcomeFragment and ProfileFragment with simple layouts.
  3. Create main_nav_graph.xml, add both fragments, and set WelcomeFragment as startDestination.
  4. Add arguments userName:String and userEmail:String (nullable) to ProfileFragment.
  5. In WelcomeFragment, call generated directions and navigate.
  6. In ProfileFragment, use navArgs to read and display values.
Starter code snippets
// Example navigate call in WelcomeFragment
val action = WelcomeFragmentDirections.actionWelcomeFragmentToProfileFragment("Alex", "alex@example.com")
findNavController().navigate(action)

// Example retrieval in ProfileFragment
private val args: ProfileFragmentArgs by navArgs()
val name = args.userName
val email = args.userEmail
