Module 3 › Chapter 3.2 › Key Concepts
Navigation Graph
XML map of destinations, actions, and arguments that defines app navigation paths.
NavHostFragment & NavController
The host displays destinations; the controller executes navigation and manages the back stack.
Safe Args
Gradle plugin-generated classes that provide type-safe argument passing between destinations.
Summary takeaway

Design flows in the nav_graph, host them in NavHostFragment, drive navigation with NavController, and pass typed data with Safe Args for predictable multi-screen apps.
