Host and Controller
The host displays destinations; the controller performs navigation actions and handles the back stack.

Practical notes
  • Call findNavController() in onViewCreated or later to avoid null references.
  • Use app:defaultNavHost="true" so the NavHost handles system back presses automatically.
  • NavController methods include navigate(), popBackStack(), and popUpTo for advanced flows.
Common mistake
Attempting to navigate before the NavHost is attached leads to unresolved NavController or null pointer exceptions.
