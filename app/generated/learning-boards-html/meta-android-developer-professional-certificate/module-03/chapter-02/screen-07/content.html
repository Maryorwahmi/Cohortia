Add dependencies
// build.gradle (Module: app)
dependencies {
  // Kotlin
  implementation("androidx.navigation:navigation-fragment-ktx:2.7.7")
  implementation("androidx.navigation:navigation-ui-ktx:2.7.7")
}

// In your app-level build.gradle, apply the plugin
apply plugin: 'androidx.navigation.safeargs.kotlin'
Checklist & Tips
  • After applying safeargs, do a clean build so generated classes appear.
  • Keep navigation artifact versions aligned across modules to avoid compatibility issues.
  • If generated classes are missing, confirm the plugin was applied to the app module, not only the project-level build file.
Common mistake
Forgetting to apply safeargs in the app-level build.gradle causes unresolved references for HomeFragmentDirections and Args classes.
