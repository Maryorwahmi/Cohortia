Click listeners and delegation

Install listeners in the ViewHolder and call a host-provided lambda to react to taps.

Pattern
// Pass lambda to adapter
val adapter = UserAdapter(users) { user ->
  // Host handles navigation or toast
}

// Inside ViewHolder.bind
itemView.setOnClickListener { onItemClick(user) }
Pitfalls
Avoid performing navigation or heavy work directly inside the Adapter. Use the adapterPosition at click time to avoid off-by-one when the list changes.
Concrete use
Click shows a toast with the user's name, or launches a details Activity from the host.
Check
If clicks map to wrong items after updates, verify you use adapterPosition at click time and update the underlying list correctly.
Pro tip
Make listener wiring lightweight and idempotent so recycled ViewHolders behave predictably.
