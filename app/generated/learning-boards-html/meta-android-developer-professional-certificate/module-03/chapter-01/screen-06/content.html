Definition

Simple item XML

A single-row layout should be readable and fast to inflate and bind.

<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:orientation="vertical"
    android:padding="16dp">

    <TextView
        android:id="@+id/userNameTextView"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:textSize="18sp"
        android:textStyle="bold" />

    <TextView
        android:id="@+id/userEmailTextView"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:textSize="14sp"
        android:textColor="@android:color/darker_gray" />

</LinearLayout>
Example
Two TextViews: one for name, one for email. That maps directly to data model fields.
Pro tip
Keep layouts shallow and avoid heavy widgets to reduce measure/layout cost during recycling.
Practical check

ViewHolder cache

What to cache
Store references to the TextViews in the ViewHolder constructor so onBindViewHolder only assigns text.
Avoid
Do not perform synchronous network or heavy decoding in onBindViewHolder; use async loaders that handle recycling.
Key Takeaway

Design item XML for quick inflation and fast binding; cache child views in ViewHolder.
