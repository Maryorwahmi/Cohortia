Do's and Don'ts for binding

Small changes to where work happens have large effects on smoothness.

Don't
Synchronous network calls, heavy decoding, or layout inflation inside onBindViewHolder. These cause frame drops during fast scrolling.
Do
Use async image loaders, precompute expensive transforms, and keep bind to simple assignments to cached views.
Concrete example
Use Glide or Coil for avatar loading. These libraries cancel prior requests for recycled views and avoid displaying wrong images.
Common mistake

Placing heavy decode or network work in binding leads to visible jank while scrolling. Move work off the main thread or precompute before binding.
