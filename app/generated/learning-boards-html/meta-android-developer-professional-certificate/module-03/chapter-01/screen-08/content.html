Attach LayoutManager and Adapter

A few lines in onCreate wiring the RecyclerView make the list visible and interactive.

// In MainActivity.onCreate
val recyclerView: RecyclerView = findViewById(R.id.recyclerView)

// Sample data
val userList = listOf(
  User(1, "Alice Smith", "alice@example.com"),
  User(2, "Bob Johnson", "bob@example.com"),
  // ... more users
)

recyclerView.layoutManager = LinearLayoutManager(this)
val adapter = UserAdapter(userList) { user ->
  Toast.makeText(this, "Clicked on ${user.name}", Toast.LENGTH_SHORT).show()
}
recyclerView.adapter = adapter
Example
Set LinearLayoutManager for a simple vertical list and pass a click lambda to show a toast.
Common mistake
Forgetting to call setLayoutManager causes an empty view with no runtime error explaining the missing manager.
Tip
Prepare data off the main thread for real apps; only set adapter on the main thread after data is ready.
