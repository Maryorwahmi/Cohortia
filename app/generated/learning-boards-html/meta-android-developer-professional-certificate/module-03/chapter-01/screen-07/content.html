UserAdapter example

This adapter takes a list of users and a click lambda. ViewHolder caches TextViews and binds quickly.

class UserAdapter(private val users: List<User>, private val onItemClick: (User) -> Unit) :
    RecyclerView.Adapter<UserAdapter.UserViewHolder>() {

  inner class UserViewHolder(itemView: View) : RecyclerView.ViewHolder(itemView) {
    val userNameTextView: TextView = itemView.findViewById(R.id.userNameTextView)
    val userEmailTextView: TextView = itemView.findViewById(R.id.userEmailTextView)

    fun bind(user: User) {
      userNameTextView.text = user.name
      userEmailTextView.text = user.email
      itemView.setOnClickListener { onItemClick(user) }
    }
  }

  override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): UserViewHolder {
    val view = LayoutInflater.from(parent.context).inflate(R.layout.item_user, parent, false)
    return UserViewHolder(view)
  }

  override fun onBindViewHolder(holder: UserViewHolder, position: Int) {
    val user = users[position]
    holder.bind(user)
  }

  override fun getItemCount(): Int = users.size
}
Concrete example
Pass a lambda that shows a toast. The Adapter doesn't handle navigation directly.
Misconception
Avoid doing heavy bitmap decoding or network calls inside bind; they cause jank.
Check
If clicks don't fire, ensure you set the listener inside bind and pass the correct lambda from the host.
