Notify and update strategies

Choose the right notify method to preserve animations and minimize redraw work.

Specific calls
Use notifyItemInserted, notifyItemRemoved, notifyItemChanged when you know the affected index for efficient updates.
DiffUtil
Calculate differences between old and new lists on a background thread and dispatch minimal updates for smooth animations.
// Less efficient
adapter.notifyDataSetChanged()

// Better when inserting at position
adapter.notifyItemInserted(position)

// Best for large diffs
// use DiffUtil to compute and dispatch updates
Common mistake

Relying on notifyDataSetChanged causes unnecessary redraws and loses built-in animations. Use specific notify calls or DiffUtil when possible.
