Module 3 › Chapter 3.3 › Internal Storage
Definition
Internal storage

Private, app-specific storage. No extra permissions required; removed when the app is uninstalled.

filesDir
Persistent private files for your app.
cacheDir
Temporary files the system may clear to reclaim space.
Why it matters

Choosing filesDir or cacheDir affects file lifetime, user privacy, and how you handle cleanup. Temporary downloads belong in cache; persistent user content belongs in files.

Common mistake
Storing large user files in SharedPreferences or assuming cache files won't be removed. Use the right directory for your file's expected lifetime.
Key Takeaway

Use filesDir for persistent private data and cacheDir for temporary files that may be reclaimed by the system.
