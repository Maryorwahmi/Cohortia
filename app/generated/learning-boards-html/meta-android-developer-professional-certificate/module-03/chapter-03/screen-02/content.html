Learning Objectives

Master practical storage patterns and safe defaults for Android apps.

01
Choose between SharedPreferences and files
Decide when small key-value pairs are enough versus when files are required for larger or structured data. This choice affects privacy, persistence, and permissions.
VERIFIED COMPETENCY MILESTONE
02
Save and retrieve values with SharedPreferences
Implement saving a string and a boolean, and use the asynchronous write method so the UI remains responsive.
VERIFIED COMPETENCY MILESTONE
03
Understand internal and external storage
Learn which storage is private, which requires permissions, and where temporary files belong.
VERIFIED COMPETENCY MILESTONE
04
Perform file I/O and follow security best practices
Read and write internal files with proper exception handling and avoid storing secrets in plain text.
VERIFIED COMPETENCY MILESTONE
Bloom: Learn → Understand → Apply → Master
Practice mnemonic
Think of storage as three buckets: tiny settings, private files, public files. Map your data to the smallest secure bucket that meets sharing and lifetime needs.
Assessment example
You will save a theme preference and a note file, then verify persistence after app restart.
