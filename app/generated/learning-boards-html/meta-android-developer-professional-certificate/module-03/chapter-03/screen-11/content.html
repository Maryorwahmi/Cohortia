Starter layout
The layout includes a multi-line edit area and two controls: Save Note and Load Note. You will wire the controls to file I/O functions that wrap openFileOutput and openFileInput in try-catch blocks.
Steps
  1. Find the EditText and Save/Load views in onCreate.
  2. On Save: read text, call writeToFile in a background coroutine, and show a confirmation on success.
  3. On Load: call readFromFile in a background coroutine and update the EditText on the main dispatcher.
