Module 3 › Chapter 3.3 › Security
Why it matters
Protect secrets correctly
Internal storage protects from casual access but not from a rooted device. Encryption and platform keystore provide stronger guarantees for sensitive data.
Practical steps
  • Do not store plaintext passwords or long-lived API keys in files or preferences.
  • Use the Android Keystore for keys and encrypt sensitive blobs before writing them.
  • Limit permission requests and keep tokens short-lived.
Check your understanding
If a token must be stored, ask whether it can be short-lived and encrypted, and whether the keystore can manage the encryption key rather than embedding secrets in code or files.
