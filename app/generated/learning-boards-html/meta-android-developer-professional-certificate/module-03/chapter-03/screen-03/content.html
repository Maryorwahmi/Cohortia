Module 3 › Chapter 3.3 › Practice & Milestones
Milestone 1
Map scenarios to storage
  • Save UI theme and onboarding flag → SharedPreferences (private, fast).
  • Store downloaded images for use only by the app → internal files or cache.
  • Share a photo with other apps or keep after uninstall → external storage with MediaStore.
Milestone 2
Implement save & load
Write code to save a string theme and a boolean flag, use the asynchronous commit method for non-blocking writes, and verify after restart.
Milestone 3
File I/O checks
Write and read a text file from internal storage using try-catch and confirm behavior when the file is absent.
Milestone 4
Security & threads
Avoid storing secrets in plain text and always perform I/O off the main thread to keep the UI responsive.
