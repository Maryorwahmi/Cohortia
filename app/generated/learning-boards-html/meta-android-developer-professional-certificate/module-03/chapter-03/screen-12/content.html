Module 3 › Chapter 3.3 › Decision Checklist
Is it a single small value?
If yes, use SharedPreferences to keep things simple and fast.
Is it a document or image?
Use internal files for private storage, cache for temporary data, or external if it must be shared.
Does it need encryption?
Treat any secret as requiring encryption or keystore-backed protection, regardless of internal or external location.
Common pitfall
Avoid stuffing complex or large blobs into SharedPreferences. It complicates updates and harms performance. Use files or a database for structured data.
