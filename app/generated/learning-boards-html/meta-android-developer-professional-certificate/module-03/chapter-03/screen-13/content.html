Module 3 › Chapter 3.3 › Key Concepts
SharedPreferences
Small primitives and settings stored as key-value pairs. Use apply() for non-blocking writes.
Internal Storage
Private app files and cache. No permissions required; files are removed on uninstall.
External Storage
Use for shareable, long-lived files. Respect runtime permissions or use MediaStore on modern Android.
Final takeaway
Map data characteristics to storage choices, avoid blocking the UI, and protect sensitive data with encryption or keystore-backed storage.
