Module 3 › Chapter 3.3 › What is SharedPreferences?
Definition
SharedPreferences

A simple API for storing small, primitive values in key-value pairs that persist between app restarts.

Uses
Theme choice, onboarding flag, last sync timestamp.
Limitations
Not for large blobs, images, or structured data.
Pitfall
Using synchronous commits can block the UI thread and cause jank.
Concrete example
Save and load a theme preference
// Save preference (conceptual)
val sharedPref = context.getSharedPreferences("user_settings", Context.MODE_PRIVATE)
with(sharedPref.edit()) {
  putString("theme_preference", "dark")
  putBoolean("onboarding_complete", true)
  apply() // asynchronous write
}

// Retrieve preference (conceptual)
val theme = sharedPref.getString("theme_preference", "light") ?: "light"
val seen = sharedPref.getBoolean("onboarding_complete", false)
Key Takeaway

SharedPreferences is the right tool for small, private configuration data. Use apply() to avoid blocking the UI.
