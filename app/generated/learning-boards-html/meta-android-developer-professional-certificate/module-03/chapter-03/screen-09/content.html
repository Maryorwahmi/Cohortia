Module 3 › Chapter 3.3 › Internal vs External
Internal Storage
Private to the app
  • No runtime permissions required.
  • Files deleted on uninstall.
  • Use for sensitive or app-only data.
External Storage
Public and shareable
  • Accessible by other apps and the user.
  • Requires runtime permissions or use of MediaStore on modern Android.
  • Good for photos or files that should outlive uninstall.
Quick decision guide
Ask: Do I need the file shared or persistent beyond uninstall? If yes, consider external storage and MediaStore; if no, choose internal storage for privacy.
