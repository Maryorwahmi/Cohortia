Module 3 › Chapter 3.3 › Quick Reminders
Prefer SharedPreferences
Small settings and flags belong here, written with apply() for responsiveness.
Use internal files for private content
Files in filesDir and cacheDir are private and removed on uninstall.
Protect sensitive data
Encrypt secrets or use the keystore; do not store plaintext passwords or API keys.
Final reflection
Which storage will you choose for a login token, a temporary download, and a user note? Explain why to solidify the choice.
