Module 2 › Chapter 2.2 › Buttons and OnClickListener
Process Flow

From tap to action

Declare a Button in XML, find it in Kotlin, and set an OnClickListener. Keep the listener focused and fast.

// In your Activity or Fragment
val myButton: Button = findViewById(R.id.myButton)
myButton.setOnClickListener {
  // runs on the UI thread
  Log.d("UI_DEMO", "Button clicked!")
  Toast.makeText(this, "Button was tapped!", Toast.LENGTH_SHORT).show()
}
Common mistake

Starting network or heavy computation directly in the click listener, which can freeze the UI.

Example scenario
A Submit button validates input, then either shows a Toast on success or launches a coroutine for a server call and shows progress elsewhere.
Pro tip
If you need immediate UI feedback, show a Toast or change a View immediately, then do longer work in background.
Key Takeaway

Use setOnClickListener for tappable actions and keep handlers short; offload heavy tasks to background threads or coroutines.
