Module 2 › Chapter 2.2 › Toast messages
Process

Show a short, non-interactive message

Create a Toast to confirm small actions. Keep messages short and avoid using Toasts for critical errors or required confirmations.

Toast.makeText(this, "Username: maria, Remember Me: true", Toast.LENGTH_SHORT).show()
When to use
Brief confirmations like save success or simple feedback after a tap.
When not to use
For urgent errors that require user action or for long messages that won't fit the short duration.
Key Takeaway

Use Toasts to confirm brief actions. Keep messages concise and avoid using them for anything that requires user interaction.
