Common UI Widgets and User Input

Understand how Android shows text, accepts typed input, responds to taps, and gives quick feedback. Learn both XML attributes and Kotlin listeners so widgets are accessible and robust.

Text & Labels
TextView: display and style text using sp-sized fonts and color attributes.
Input
EditText: typed input with inputType and TextWatcher for live validation.
Actions & Feedback
Buttons trigger listeners; Toasts provide brief, ephemeral feedback.
Visual Concept
Widget stack
A form usually combines TextView labels, EditText inputs, selection controls and a Button. A Toast confirms actions.
<TextView android:text="Enter your name:" android:textSize="18sp" />
<EditText android:hint="Name" android:inputType="textPersonName" />
<Button android:text="Submit" />
In the full lesson we will wire these to Kotlin listeners and show safe validation patterns.
Explore Key Topics
Three practical focuses you'll practice in this chapter.
Text & Styling
Use sp for sizes, textColor, and dynamic updates from Kotlin.
Input Types
Choose inputType to tune the keyboard and validation strategy.
Feedback
Use Toasts for ephemeral messages and avoid them for critical confirmations.
