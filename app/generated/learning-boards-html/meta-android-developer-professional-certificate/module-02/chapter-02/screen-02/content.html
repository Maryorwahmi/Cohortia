Learning Objectives

Learn, understand, apply, and gain confidence using Android widgets and user input patterns.

01
TextView: display & style
Set android:text, android:textSize (use sp), and android:textColor, then update text from Kotlin for dynamic UIs.
Verified competency milestone
02
Button & OnClickListener
Attach an OnClickListener in Kotlin to perform actions; avoid long tasks on the UI thread inside listeners.
Verified competency milestone
03
EditText & inputType
Choose inputType like textPersonName, number or textPassword to optimize keyboards and validation.
Verified competency milestone
04
Selection & feedback controls
Use CheckBox, RadioButton (with RadioGroup), Switch, and Toast messages to collect choices and provide short confirmations.
Verified competency milestone
