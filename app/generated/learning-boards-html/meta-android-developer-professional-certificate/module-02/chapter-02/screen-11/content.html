Code Walkthrough
nameEditText.addTextChangedListener(object : TextWatcher {
  override fun beforeTextChanged(s: CharSequence?, start: Int, count: Int, after: Int) { }

  override fun onTextChanged(s: CharSequence?, start: Int, before: Int, count: Int) {
    // lightweight reaction, e.g., enable/disable a Button
    submitButton.isEnabled = !s.isNullOrBlank()
  }

  override fun afterTextChanged(s: Editable?) { }
})
Best practices
  • Keep logic light inside the watcher; avoid heavy formatting.
  • Debounce network or expensive checks triggered by typing.
  • Use onTextChanged for quick enable/disable logic and afterTextChanged for final edits.
Key Takeaway

Use TextWatcher for responsive forms, but keep it efficient and move slow work off the UI thread.
