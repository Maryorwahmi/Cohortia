Module 2 › Chapter 2.2 › Selection controls
CheckBox
Allows selecting one or more options. Read state using isChecked and listen with setOnCheckedChangeListener.
<CheckBox android:id="@+id/rememberMe" android:text="Remember Me" />
RadioButton + RadioGroup
Use for a single choice among options. Group them in RadioGroup to enforce exclusivity.
<RadioGroup>
  <RadioButton android:text="Option A" />
  <RadioButton android:text="Option B" />
</RadioGroup>
Switch
Toggle control for binary settings that often take immediate effect, like enabling notifications.
<Switch android:id="@+id/notificationsSwitch" android:text="Enable Notifications" />
Key Takeaway

Choose the control based on whether the choice is multi-select, exclusive, or an immediate toggle setting.

Common mistake
Using a CheckBox for an option set that should be exclusive; it confuses the user and complicates validation.
