Module 2 › Chapter 2.2 › Validation and safe conversions
Process

From text to typed values safely

Read text, use safe conversion helpers, validate results, and show concise feedback when input is invalid.

val ageText = ageEditText.text.toString()
val age = ageText.toIntOrNull()
if (age == null) {
  Toast.makeText(this, "Please enter a valid age", Toast.LENGTH_SHORT).show()
} else {
  // proceed with age
}
Why this matters
Avoid crashes and provide clear guidance to the user when input is invalid.
Common mistake
Calling toInt on an empty string or malformed input leads to exceptions and app crashes.
Key Takeaway

Use toIntOrNull and validate before using converted values; guide users to correct input with short messages.
