Module 2 › Chapter 2.2 › TextView — display and dynamic updates
Definition

TextView attributes and runtime updates

TextView shows static labels and dynamic content. Use android:text, android:textSize with sp, android:textColor, android:textStyle, and android:gravity to control appearance.

Best practice
Use sp for font sizes so accessibility settings apply.
Runtime update
Call myTextView.text = "..." from activity/fragment code to change text.
Common mistake

Using dp for textSize or performing large string formatting on the UI thread.

Example
<TextView
  android:id="@+id/greetingTextView"
  android:layout_width="wrap_content"
  android:layout_height="wrap_content"
  android:text="Hello, Android!"
  android:textSize="18sp" />
Kotlin: updating a TextView
val greetingTextView: TextView = findViewById(R.id.greetingTextView)
greetingTextView.text = "Welcome back, Maria!"
Why it matters
Dynamic text keeps the UI responsive to user actions and remote data without rebuilding layouts.
Key Takeaway

Prefer sp for font sizes and update TextView.text from Kotlin for dynamic content.
