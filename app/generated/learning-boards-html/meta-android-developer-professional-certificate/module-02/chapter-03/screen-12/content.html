Notification methods
  • notifyItemInserted(position) — add an item and animate insertion.
  • notifyItemRemoved(position) — remove and animate removal.
  • notifyItemChanged(position) — refresh a single item.
  • notifyDataSetChanged() — forces full rebind; use only when necessary.
Performance pitfalls
  1. Heavy work in onBindViewHolder (synchronous decoding, complex layout calculations).
  2. Not using granular notify methods, causing unnecessary rebinds.
  3. Forgetting to update the backing list before notifying the adapter.
Pro tip

Use DiffUtil or ListAdapter when data changes frequently to compute minimal updates automatically.

Check your understanding

If inserting an item at position 0 causes no animation and the whole list appears to refresh, which notification is likely being used? You are probably calling notifyDataSetChanged() instead of notifyItemInserted(0).
