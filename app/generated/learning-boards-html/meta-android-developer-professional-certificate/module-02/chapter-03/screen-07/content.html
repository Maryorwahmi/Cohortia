Module 3 › Chapter 2.3 › ViewHolder
Pattern

Cache subviews once

Store references to TextView and ImageView in the ViewHolder constructor so findViewById is not called during every bind.

Example: ViewHolder holds userNameTextView and userEmailTextView and exposes a bind(user) method to set their values.
Code
class UserViewHolder(itemView: View) : RecyclerView.ViewHolder(itemView) {
  val userNameTextView: TextView = itemView.findViewById(R.id.userNameTextView)
  val userEmailTextView: TextView = itemView.findViewById(R.id.userEmailTextView)

  fun bind(user: User) {
    userNameTextView.text = user.name
    userEmailTextView.text = user.email
    itemView.setOnClickListener { /* optional click handling */ }
  }
}
Key Takeaway

ViewHolder reduces repeated view lookup overhead and is essential for smooth scrolling.
