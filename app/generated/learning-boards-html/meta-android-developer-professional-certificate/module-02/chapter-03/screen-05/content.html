Module 3 › Chapter 2.3 › RecyclerView & Recycling
Claim

Recycle views to bound memory

  • RecyclerView holds a pool of detached views for reuse.
  • Adapter creates ViewHolders only when pool is empty.
  • Binding replaces data in cached views for newly visible items.
Misconception: recycled views guarantee fresh state — false. Always bind every visible property to avoid leaked values.
Analogy
Theater seats versus building new seats

A limited number of physical seats are reused by different attendees; similarly, RecyclerView reuses views so the app doesn't need a separate view for every data item.

Check your understanding

If an item sometimes shows stale text after scrolling, what likely happened? You forgot to fully bind all fields in onBindViewHolder.
