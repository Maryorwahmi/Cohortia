Verification Exercise

Build a profile screen that combines RelativeLayout and LinearLayout. Validate layout_weight usage and ensure ids are unique for relative positioning.

Example
Two buttons share horizontal space using layout_weight values 1 and 1 inside a horizontal LinearLayout placed at the bottom of a RelativeLayout root.
Misconception
Relying only on the Layout Editor can hide XML issues. Always inspect the XML to confirm attribute values and ids.
Tip
Start with simple containers, then flatten the hierarchy to reduce layout passes. Later you will meet ConstraintLayout for more advanced layouts.
