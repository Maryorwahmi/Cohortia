Introduction to Android UI and Layouts
How Views, ViewGroups, and XML shape every Android screen
In this lesson

Learn the View vs ViewGroup distinction, write simple XML layouts, and use LinearLayout and RelativeLayout to compose screens. See practical examples and common mistakes to avoid.

Why it matters

A well-structured layout improves performance and maintainability and makes it easier to support different device sizes and accessibility needs.

View
Smallest UI element that draws itself and handles events, e.g., TextView, Button.
ViewGroup
Container that arranges child Views. Examples: LinearLayout, RelativeLayout.
XML Layout
Declarative file parsed at runtime to inflate the view hierarchy. Stored in res/layout.
