Practical accessibility checks
  • Add android:contentDescription for ImageView so assistive tech can describe images.
  • Use scalable text sizes and sufficient contrast for readability.
  • Prefer proportional layouts (weights) over many fixed dp values to adapt to varying widths.
Example
In the profile screen, the ImageView has a contentDescription and the two bottom buttons use equal weights so they remain usable on narrow screens.
Quick test
Preview the layout in landscape and smaller widths. Use a screen reader or accessibility inspector to confirm descriptions and focus order.
