Module 2 › Chapter 2.1 › Key Concepts
View
A drawable element that can handle events, such as TextView or Button.
ViewGroup
A container that holds children and controls layout; examples include LinearLayout and RelativeLayout.
XML Layout Files
Declarative files in res/layout that Android parses and inflates into real View objects at runtime.
One-line takeaway

Keep layouts simple, validate XML attributes, and use Layout Editor previews as a fast iteration tool while trusting XML as the source.
