How layout_weight works

Weights divide leftover space. Use 0dp in the measured dimension and remember margins and padding reduce the available area that weight distributes.

Concrete example
In a horizontal LinearLayout, child A width=0dp weight=1 and child B width=0dp weight=2 yields child B twice as wide as A after fixed siblings take space.
Debug tip
Apply temporary backgrounds to children in the Layout Editor to see exact widths while you tune weights and margins.
Quick checklist
  • Set measured dimension to 0dp when using weight.
  • Account for padding and margins before assigning weights.
  • Prefer weights for proportional layouts, not for deeply nested alignment.
