Activity steps
  1. Create an Empty Activity project and open activity_main.xml.
  2. Replace root with RelativeLayout and add ImageView with contentDescription and id.
  3. Add username and email TextViews below the image with unique ids.
  4. Add bottom LinearLayout with two Buttons using 0dp widths and equal layout_weight.
  5. Preview on different devices and test accessibility descriptions.
Assessment Questions

Q1. Which ViewGroup stacks three TextViews vertically and how do you center the middle TextView horizontally?

Answer: LinearLayout with android:orientation="vertical" and set android:layout_gravity="center_horizontal" on the middle TextView.

Q2. Why prefer XML layouts to programmatically creating UI in Kotlin?

Answer: XML separates UI structure from logic, simplifies maintenance, and supports alternative layouts for different device configurations without conditional code.
