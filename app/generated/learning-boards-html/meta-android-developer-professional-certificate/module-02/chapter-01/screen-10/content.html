XML as the source of truth

Edit XML for exact attributes, then use the Layout Editor to preview device sizes and orientation. Keep both in your workflow.

Practical tip
When adjusting layout_weight or padding, change XML then refresh the preview to ensure expected behavior across devices.
Accessibility
Add contentDescription for ImageView and test color contrast when using the editor previews for different themes.
Workflow
  1. Write XML layout and assign ids and attributes.
  2. Preview in Layout Editor across devices.
  3. Tweak XML for precision and test on real devices or emulators.
