Measure → Layout → Draw passes

Each ViewGroup participates in measurement and positioning. More nested ViewGroups cause more work during those passes, which can slow rendering.

Concrete scenario
Multiple nested LinearLayouts used for spacing cause repeated measurement of children. Replacing some containers with layout_weight or flattening reduces passes.
Common mistake
Excessive nesting to achieve alignment. It’s better to use container attributes or a flatter layout strategy.
Key Takeaway

Design layouts to minimize nesting and unnecessary containers; this improves rendering performance.
