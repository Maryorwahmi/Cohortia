DNS Tunneling Process

Compromised Host
Encode Data
DNS Query (e.g., data.attacker.com)
Attacker DNS Server

How it Works

  • DNS Queries: Data is encoded into subdomain names (e.g., chunk1.secret.attacker.com).
  • Firewall Bypass: DNS traffic (port 53) is almost always allowed outbound.
  • Attacker Server: Attacker's authoritative DNS server receives queries and reconstructs data.
  • Two-way: Can also send data back to the compromised host via DNS responses.

Tools & Trade-offs

  • Tools: dnscat2, iodine.
  • Stealth: Very high, blends with normal traffic.
  • Speed: Generally slow, not ideal for large files.
  • Detection: Can be detected by DNS anomaly detection systems.
Key Takeaway

DNS tunneling is a highly stealthy exfiltration method for restricted networks, but its slow speed makes it better suited for small, critical data payloads.
