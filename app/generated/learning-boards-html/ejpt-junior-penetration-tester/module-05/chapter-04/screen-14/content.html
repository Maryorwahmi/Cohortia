# On Compromised Linux System - Modify file timestamps
user@target:~$ ls -l /tmp/malicious_tool
-rw-r--r-- 1 user user 123456 May 15 10:30 /tmp/malicious_tool

user@target:~$ touch -at 202201011200.00 /tmp/malicious_tool
user@target:~$ ls -l /tmp/malicious_tool
-rw-r--r-- 1 user user 123456 Jan  1  2022 /tmp/malicious_tool

# On Compromised Windows System (PowerShell) - Modify file timestamps
PS C:\> (Get-Item C:  emp\malicious.exe).CreationTime = '2022-01-01 12:00:00'
PS C:\> (Get-Item C:  emp\malicious.exe).LastWriteTime = '2022-01-01 12:00:00'

# On Compromised Linux System - Remove temporary files and tools
user@target:~$ rm /tmp/chisel /dev/shm/mimikatz.exe

# On Compromised Windows System - Remove temporary files and tools
PS C:\> Remove-Item C:  emp\* -Recurse -Force

Timestamp Manipulation

  • Metadata: Files have access (atime), modification (mtime), and change (ctime) timestamps.
  • Blending In: Altering these makes malicious files appear older or less recently used.
  • Tools: touch on Linux, Set-ItemProperty in PowerShell on Windows.

Removing Temporary Files & Tools

  • Uploaded Tools: Delete any binaries (e.g., Mimikatz, chisel) or scripts.
  • Temporary Data: Remove any copies of exfiltrated data or staging files.
  • Common Locations: /tmp, /dev/shm on Linux; C: emp, user profile directories on Windows.
Key Takeaway

Timestamp modification and thorough removal of temporary files and tools are essential for obscuring your presence and making forensic analysis significantly more challenging.
