Key Concepts: Windows Focus

Essential terms and techniques for Windows privilege escalation.

Unquoted Service Path

Service path with spaces not in quotes, allowing arbitrary code execution.

Weak Service Permissions

Insufficiently restricted permissions on Windows services or their executables.

Kernel Exploit

A vulnerability in the operating system kernel that can be exploited to gain elevated privileges.

Summary Takeaway

Windows privilege escalation often leverages service misconfigurations like unquoted paths and weak permissions, with kernel exploits reserved for advanced scenarios.
