Exploiting Unquoted Service Paths

Placing malicious executables in vulnerable service paths.

Exploitation Steps

  • •Identify an unquoted service path (e.g., `C:\Program Files\Vulnerable App\service.exe`).
  • •Check for write permissions in parent directories (e.g., `C:\Program Files\`).
  • •Create a malicious executable (e.g., `Vulnerable.exe`) in the writable parent directory.
  • •Restart the service to execute your payload with elevated privileges.
Example: `VulnerableService`
# Original service path (unquoted):C:\Program Files\Vulnerable App\service.exe

# Windows attempts to execute:1. C:\Program.exe
2. C:\Program Files\Vulnerable.exe
3. C:\Program Files\Vulnerable App\service.exe

# If you place malicious 'Vulnerable.exe' in 'C:\Program Files\',# it will be executed with service privileges (e.g., SYSTEM).
Common Mistake

Assuming you need write access to the final service executable. Write access to any directory in the unquoted path is sufficient to place a malicious file.
