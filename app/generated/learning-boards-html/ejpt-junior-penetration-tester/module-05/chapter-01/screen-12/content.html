Weak Service Permissions: Modifying Service Behavior

Gaining control by altering service executables or configurations.

Vulnerable Permissions

  • •Write permissions on the service executable file itself.
  • •Permissions to modify service configuration (e.g., `BinaryPathName`).
  • •Specific permissions like `GENERIC_WRITE` or `WRITE_DAC` on the service object.
Identify Weak Service Permissions
# Query service configurationsc qc ServiceName

# Show service security descriptorsc sdshow ServiceName

# Using accesschk.exe (Sysinternals)accesschk.exe -uwcqv "ServiceName"

# Look for 'RW' (Read/Write) or 'WD' (Write DAC) permissions for low-priv users.
Key Takeaway

Always check service permissions. If you can modify the service's binary or configuration, you can likely achieve SYSTEM-level privilege escalation.
