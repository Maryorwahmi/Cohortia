Unquoted Service Paths: A Windows Weakness

Exploiting how Windows resolves service executable paths.

How Unquoted Paths Work

  • •Service executable path contains spaces but no quotes.
  • •Windows attempts to execute each path segment as an executable.
  • •Example: `C:\Program Files\My App\service.exe` becomes `C:\Program.exe`, then `C:\Program Files\My.exe`, etc.
Enumerate Unquoted Service Paths
# Using WMIC to find unquoted pathswmic service get name,displayname,pathname,startmode | findstr /i "auto" | findstr /i /v "c:\windows\\"

# Using PowerShellGet-WmiObject win32_service | Where {$_.StartMode -eq "Auto" -and $_.PathName -notlike "C:\Windows\*" -and $_.PathName -notmatch '"'} | Format-List Name,PathName
Key Takeaway

Identify services with unquoted paths and check for write permissions in any of the directories in the path. This is a common and effective Windows escalation vector.
