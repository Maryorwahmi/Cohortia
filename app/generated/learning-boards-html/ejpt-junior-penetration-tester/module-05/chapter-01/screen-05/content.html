SUID/SGID Binaries: Understanding Special Permissions

How executables can run with elevated user or group privileges.

What are SUID and SGID?

  • •SUID (Set User ID): Executable runs with the permissions of the file's owner.
  • •SGID (Set Group ID): Executable runs with the permissions of the file's group owner.
  • •These permissions allow low-privileged users to perform tasks requiring higher privileges.
Enumerate SUID/SGID Binaries
# Find SUID/SGID binaries owned by rootfind / -perm -4000 -o -perm -2000 -type f 2>/dev/null

# Example output:/usr/bin/sudo/usr/bin/passwd/usr/bin/find# ... and many more system utilities
Key Takeaway

Always enumerate SUID/SGID binaries. If a root-owned binary has these bits set, it's a prime candidate for privilege escalation.
