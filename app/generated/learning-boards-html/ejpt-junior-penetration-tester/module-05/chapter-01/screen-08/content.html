Exploiting `sudo` Misconfigurations

Turning permissive `sudo` rules into root access.

Exploitation Scenarios

  • •NOPASSWD for scripting languages: Python, Perl, Ruby, etc., can execute shell commands.
  • •NOPASSWD for text editors: `vi`, `less`, `more` can escape to a shell.
  • •Wildcard entries: `sudo /usr/bin/*` can allow execution of malicious scripts.
Example: `sudo python NOPASSWD`
# If 'python' is allowed with NOPASSWDsudo python -c 'import os; os.execl("/bin/sh", "sh", "-p")'

Key Takeaway

When `sudo -l` shows `NOPASSWD` for a binary, always check GTFOBins for a direct exploit string. This is often the quickest path to root.
