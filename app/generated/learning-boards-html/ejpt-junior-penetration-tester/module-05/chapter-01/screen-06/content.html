Exploiting SUID/SGID Binaries

Leveraging common tools for root access.

Common Exploitable Binaries

  • •find: Can execute arbitrary commands via its -exec option.
  • •nmap: Older versions had an interactive mode that could spawn a shell.
  • •vim/less/more: Can execute shell commands from within the editor/pager.
Example: Exploiting SUID 'find'
# If 'find' is SUID root, execute a root shellfind . -exec /bin/sh -p \; -quit
