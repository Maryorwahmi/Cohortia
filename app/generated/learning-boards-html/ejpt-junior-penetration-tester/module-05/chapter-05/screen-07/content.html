Phase 3: Pivoting and Lateral Movement

Expanding Reach to Internal Networks

5. Pivoting

Discover a second network interface on the compromised server, allowing access to an internal network segment. Use SSH dynamic port forwarding (-D) or chisel to set up a SOCKS proxy.

6. Lateral Movement

Use the SOCKS proxy and stolen credentials (e.g., Pass-the-Hash) to move to a domain controller or a critical database server within the internal network.

Concrete Example

Using chisel to create a SOCKS proxy through a compromised web server, then using proxychains with crackmapexec to enumerate shares on an internal Windows server.
