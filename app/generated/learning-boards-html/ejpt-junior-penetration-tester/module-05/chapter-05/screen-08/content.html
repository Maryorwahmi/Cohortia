Achieving Objectives and Erasing Traces

7. Data Exfiltration & Impact

Extract sensitive data (e.g., NTDS.DIT from a DC, database contents) and exfiltrate it using stealthy methods like DNS tunneling or encrypted channels.

8. Covering Tracks

Clean up logs, command history, temporary files, and remove deployed persistence mechanisms to minimize detection and forensic evidence.

Concrete Example

After compromising a database, using a custom Python script to compress and encrypt sensitive data, then exfiltrating it over a covert channel like ICMP tunneling.
