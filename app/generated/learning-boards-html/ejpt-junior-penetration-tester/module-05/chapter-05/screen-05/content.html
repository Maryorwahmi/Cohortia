Attack Flow

Phase 1: Initial Access and Foothold

Gaining Entry and Establishing a Presence

1. Initial Access

Exploit a public-facing vulnerability, such as SQL Injection leading to Remote Code Execution (RCE) on a web application, to gain a low-privileged shell.

2. Foothold & Enumeration

Establish a stable, low-privileged shell. Use enumeration scripts like linPEAS.sh (Linux) or PowerSploit (Windows) to gather system and network information.

Concrete Example

Using a SQL Injection vulnerability on a login page to execute commands and obtain a reverse shell on a Linux web server.

Key Takeaway

Initial access and thorough enumeration are foundational for any multi-stage attack, providing the necessary intelligence for subsequent phases.
