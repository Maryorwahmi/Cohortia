Phase 2: Privilege Escalation and Persistence

Elevating Privileges and Maintaining Access

3. Privilege Escalation

Discover misconfigurations (e.g., sudo on Linux, unquoted service paths on Windows) or vulnerabilities to escalate to root/SYSTEM privileges.

4. Persistence

Establish a backdoor or mechanism (e.g., cron job, scheduled task, SSH key) to maintain access to the compromised system, even after reboots.

Concrete Example

Exploiting a misconfigured SUID binary on Linux to gain root access, then adding an SSH public key to the root user's authorized_keys for persistent access.

Key Takeaway

Privilege escalation grants necessary control, while persistence ensures continued access, both vital for advancing an attack.
