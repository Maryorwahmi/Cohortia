Key Concepts

More essential terms to remember from this chapter.

Startup Folder (Windows)

A directory where executables or shortcuts placed within it will run automatically when a user logs in.

Registry Run Keys

Specific registry keys (HKCU\...\Run, HKLM\...\Run) that Windows checks to execute programs automatically on user login.

Scheduled Tasks (Windows)

A Windows utility (schtasks.exe) that allows administrators to schedule programs or scripts to run at predefined times or in response to specific system events.

Backdooring

Modifying legitimate system files or applications to include malicious functionality for persistent access.

Key Takeaway

Windows persistence can be achieved via Startup folders, Registry Run keys, and Scheduled Tasks, with backdooring offering advanced, stealthy options.
