Windows Persistence

Simple Persistence: The Startup Folder

Executing payloads on user login via designated Windows directories.

How it Works

  • Windows automatically executes programs or shortcuts placed in these folders.
  • Payloads run every time the associated user logs in.
  • No complex configuration required, making it very accessible.

Discoverability

This method is simple but also easily discoverable by users or security software. It's often one of the first places to check for suspicious activity.

Key Takeaway
