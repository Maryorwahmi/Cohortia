Key Concepts

Essential terms to remember from this chapter.

Persistence

The ability to maintain access to a compromised system across reboots, disconnections, and other system changes.

Backdoor

A hidden method of bypassing normal authentication or security controls to gain access to a system.

Cron Job

A time-based job scheduler on Linux/Unix systems used to execute commands or scripts automatically at specified intervals.

SSH Keys

Cryptographic keys used for authentication in the SSH protocol; adding a public key to authorized_keys grants passwordless access.

Key Takeaway

Persistence and backdoors are crucial for maintaining access, with Linux methods like cron jobs and SSH keys providing automated and stealthy control.
