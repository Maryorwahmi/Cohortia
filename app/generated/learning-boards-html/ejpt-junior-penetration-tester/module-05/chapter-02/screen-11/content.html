Backdooring System Components

Replacing or injecting malicious code into legitimate applications for stealthy, persistent access.

Techniques Involved

  • **Executable Replacement:** Swapping a legitimate binary with a malicious one.
  • **Code Injection:** Injecting malicious code into existing processes or libraries.
  • **DLL Hijacking:** Placing a malicious DLL that a legitimate application loads.

The Sethc.exe Example

Replacing C:\Windows\System32\sethc.exe (Sticky Keys) with cmd.exe allows an attacker to get a SYSTEM shell by pressing Shift five times at the login screen.

Key Takeaway

Backdooring legitimate system components offers highly stealthy and persistent access, but requires careful execution to avoid detection and system instability.
