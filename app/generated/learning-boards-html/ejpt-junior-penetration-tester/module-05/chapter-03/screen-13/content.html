Lateral Movement

Linux: Expanding Control

Common Techniques for Moving Between Linux Systems

Why Linux Lateral Movement?

  • Linux servers are common in backend infrastructure.
  • Exploiting misconfigurations or weak credentials.
  • Often leads to critical data or infrastructure control.
  • Requires familiarity with Linux administration and common services.
Key Takeaway

Linux lateral movement relies on exploiting SSH credentials, vulnerable services, and accessible shared filesystems to gain further access.

Linux Lateral Movement Techniques

SSH

Use found SSH keys (`id_rsa`) or credentials to log into other Linux servers.

Service Exploitation

Exploit vulnerable services (e.g., outdated web servers, unpatched databases) running on other Linux machines.

Shared Filesystems

Access NFS or SMB shares with appropriate permissions to gain access to files on other machines.
