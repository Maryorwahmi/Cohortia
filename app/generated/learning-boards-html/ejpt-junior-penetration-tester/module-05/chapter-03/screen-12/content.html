Lateral Movement

Windows: Expanding Control

Common Techniques for Moving Between Windows Systems

Why Windows Lateral Movement?

  • Windows is a prevalent OS in corporate environments.
  • Many built-in features can be abused for lateral movement.
  • Often leads to higher-value targets like Domain Controllers.
  • Requires understanding of Windows authentication and networking.
Key Takeaway

Windows environments offer diverse lateral movement opportunities by exploiting authentication mechanisms, remote services, and administrative shares.

Windows Lateral Movement Techniques

Pass-the-Hash (PtH)

Use extracted NTLM hashes to authenticate to other machines without plaintext passwords (e.g., `Mimikatz`, `Impacket`).

Remote Desktop Protocol (RDP)

Directly connect to another machine if RDP credentials are obtained.

SMB / Admin Shares

Access administrative shares (`C$`, `ADMIN$`) to copy and execute payloads remotely.

Windows Remote Management (WinRM)

Execute commands remotely via PowerShell Remoting (`Invoke-Command`, `Enter-PSSession`).
