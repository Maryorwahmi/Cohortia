Dynamic Port Forwarding

Creating a SOCKS Proxy with SSH -D

Key Advantages

  • Flexibility: Access multiple services and hosts through one tunnel.
  • SOCKS Proxy: Creates a local SOCKS5 proxy on your attacker machine.
  • Network Exploration: Ideal for exploring unknown internal network segments.
  • Tool Integration: Compatible with tools like `proxychains` for broader use.
Key Takeaway

Dynamic port forwarding provides a versatile SOCKS proxy, enabling broad access to internal network resources through a single pivot.

Command Example: Establishing a SOCKS Proxy
# Attacker machine: Create a SOCKS proxy on local port 1080 via PivotHost
ssh -D 1080 user@PivotHost

# Explanation of parameters:
-D: Specifies dynamic port forwarding (SOCKS proxy).
1080: The local port on your attacker machine for the SOCKS proxy.
user@PivotHost: The SSH connection details for the compromised host.

# After establishing the tunnel, configure your tools (e.g., browser, proxychains)
# to use SOCKS5 proxy at localhost:1080.
