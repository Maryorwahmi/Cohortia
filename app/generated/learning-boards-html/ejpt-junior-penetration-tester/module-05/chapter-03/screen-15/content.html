Key Concepts

Essential Terms for Network Penetration

Pivoting

Using a compromised system as an intermediary to access other systems or networks not directly reachable from the attacker's machine.

Lateral Movement

The process of moving from one compromised system to another within the same network to expand control and reach higher-value targets.

Port Forwarding

Redirecting network traffic from one port to another, often across different machines, to create a tunnel.

Local Port Forwarding (SSH -L)

Forwards a remote port on the pivot host to a local port on the attacker's machine, typically for a single service.

Dynamic Port Forwarding (SSH -D)

Creates a local SOCKS proxy, allowing all traffic routed through it to be forwarded via the pivot host to multiple internal resources.

Summary Takeaway

Pivoting and lateral movement are fundamental post-exploitation techniques that enable attackers to extend their reach into internal networks using various port forwarding methods.
