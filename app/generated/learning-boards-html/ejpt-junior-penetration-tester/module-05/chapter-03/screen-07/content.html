Local Port Forwarding

Accessing Remote Services Locally with SSH -L

How it Works

  • You connect to a local port on your attacker machine.
  • SSH tunnels this traffic through the PivotHost.
  • The PivotHost then forwards it to the specified internal target.
  • Ideal for accessing a single service (e.g., a web server, database).
Key Takeaway

Local port forwarding creates a direct, one-to-one tunnel for a specific service from an internal network to your local machine.

Command Example: Accessing an Internal Web Server
# Attacker machine: Forward local port 8080 to internal web server 192.168.1.100:80 via PivotHost
ssh -L 8080:192.168.1.100:80 user@PivotHost

# Explanation of parameters:
-L: Specifies local port forwarding.
8080: The local port on your attacker machine.
192.168.1.100:80: The target IP and port on the internal network.
user@PivotHost: The SSH connection details for the compromised host.

# After establishing the tunnel, on your attacker machine:
curl http://localhost:8080
# This will show the content of 192.168.1.100:80
