Advanced DNS

Deeper DNS Insights: Zone Transfers and CNAMEs

Exploring advanced DNS queries for comprehensive infrastructure mapping.

Zone Transfer (AXFR)

A DNS mechanism where a primary DNS server transfers a copy of its entire zone file to a secondary server. If misconfigured, an attacker can request this transfer to obtain all DNS records for a domain.

dig @ns1.example.com example.com axfr

Example: Attempting a zone transfer from a name server.

Warning

Successful zone transfers are rare on well-secured systems, but if found, they are a 'goldmine' for attackers, revealing extensive network details.

CNAME Records (Canonical Name)

CNAME records create an alias from one domain name to another. Identifying these can reveal underlying services or infrastructure that are aliased, providing further clues about the target's network.

dig www.example.com CNAME

Example: Discovering if 'www.example.com' is an alias.

Key Takeaway

Advanced DNS techniques like zone transfers and CNAME queries can uncover hidden infrastructure and provide a more complete picture of the target's network.
