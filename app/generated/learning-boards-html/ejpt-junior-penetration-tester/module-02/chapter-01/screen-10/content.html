Practical DNS Enumeration with `dig`

Querying A, MX, and NS records to understand domain configuration.

1. Querying A Records (Address)

The A record maps a domain name to its IPv4 address. This tells you the primary IP address associated with the domain.

dig example.com A

Example: Find the IPv4 address for example.com.

2. Querying MX Records (Mail Exchange)

MX records specify the mail servers responsible for accepting email messages on behalf of a domain. Essential for understanding email infrastructure.

dig example.com MX

Example: Discover mail servers for example.com.

3. Querying NS Records (Name Server)

NS records delegate a domain or subdomain to a set of authoritative name servers. These servers handle DNS queries for the domain.

dig example.com NS

Example: Identify the name servers for example.com.

Key Takeaway

Basic `dig` queries for A, MX, and NS records provide fundamental insights into a target's web, email, and DNS infrastructure.
