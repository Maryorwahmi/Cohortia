Core Concept

Passive vs. Active: Two Approaches to Information Gathering

Differentiating between non-intrusive and direct interaction methods.

Passive Reconnaissance

  • •Definition: Gathering information without direct interaction with the target system or network.
  • •Method: Observing from a distance, using publicly available resources.
  • •Trace: Leaves no trace on the target's logs.
  • •Examples: Public records, social media, company websites, search engines like Google Dorking or Shodan.

Active Reconnaissance

  • •Definition: Gathering information through direct interaction with the target system or network.
  • •Method: Directly engaging the target's systems.
  • •Trace: Carries the risk of being detected by security systems.
  • •Examples: Pinging hosts, performing port scans, querying DNS servers directly.
Key Takeaway

Start with passive techniques to build a foundational understanding, then transition to controlled active methods to minimize detection risk.

Misconception

Active reconnaissance is not always 'better' because it provides more data; the risk of detection must always be carefully weighed against the information gained.
