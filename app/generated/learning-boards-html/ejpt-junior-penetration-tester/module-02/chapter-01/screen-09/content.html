DNS Enumeration: Mapping the Domain Name System

Translating domain names to IP addresses to reveal network infrastructure.

What is DNS Enumeration?

DNS enumeration is the process of discovering information about a target's DNS records. This helps map out their network infrastructure by translating human-readable domain names into IP addresses.

Information Uncovered

  • •Subdomains: Discovering services like `mail.example.com` or `vpn.example.com`.
  • •Mail Servers (MX): Identifying email infrastructure.
  • •Name Servers (NS): Understanding domain delegation.
  • •Internal IP Ranges: Potentially exposed if misconfigured.

Key Tools for DNS Enumeration

Command-line tools are essential for querying DNS servers directly. They provide detailed control and output for various record types.

Windows & Linux
nslookup
Linux/Unix
dig
Key Takeaway

DNS enumeration is a powerful active technique to uncover a target's network topology and critical services.
