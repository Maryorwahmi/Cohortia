How -sV Works: Probes and Signatures

Nmap's Intelligent Service Identification

1. Identify Open Port
2. Send Service Probes
3. Analyze Responses
4. Match to Signatures
Nmap's nmap-service-probes database contains thousands of signatures for known services and their versions, enabling accurate identification.
Explanation

Nmap sends specific data packets (probes) to open ports. These probes are designed to trigger unique responses from different services, allowing Nmap to gather identifying information.

Example

A probe might send an HTTP GET request to port 80. If it receives an HTTP 200 OK response with server headers, Nmap knows it's a web server and can often extract its version.

Key Takeaway

The `-sV` flag's effectiveness stems from its intelligent probe-response mechanism, comparing observed behaviors against a comprehensive database of service signatures.
