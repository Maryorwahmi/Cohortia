Exploring NSE Script Categories

Organizing Scripts for Targeted Use

Default (`-sC`)

Generally useful and non-intrusive scripts, safe for common reconnaissance. A good starting point for comprehensive scans.

Discovery

Scripts for advanced information gathering, uncovering more details about services, devices, and network configurations.

Vuln

Scripts that check for known vulnerabilities. Use with caution as they can be intrusive and potentially disruptive to target systems.

Auth

Scripts designed to test for authentication bypasses or weak credentials on various services.

Brute

Scripts for brute-forcing credentials against various network services. Highly intrusive and should be used with extreme caution.

Exploit

Scripts that attempt to exploit identified vulnerabilities. These are highly dangerous and should only be used in authorized environments.

Key Takeaway

Selecting the right NSE script category is crucial for balancing reconnaissance depth with operational safety and ethical considerations.
