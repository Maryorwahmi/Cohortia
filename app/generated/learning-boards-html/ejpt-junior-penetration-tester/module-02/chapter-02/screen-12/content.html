Decoding Port States: Open, Closed, Filtered

What Each Nmap Status Means for Penetration Testers

Open

An application is actively listening for connections on this port. This indicates a running service.

Example: Port 80 (HTTP)

Closed

No application is listening on this port, but the port is accessible. It received a response indicating it's closed.

Example: Port 1000 (No Service)

Filtered

A firewall or network obstacle is blocking the port, preventing Nmap from determining its true state.

Example: Port 22 (Firewall)
Key Takeaway

Accurately interpreting port states is fundamental for understanding a target's attack surface and security defenses.
