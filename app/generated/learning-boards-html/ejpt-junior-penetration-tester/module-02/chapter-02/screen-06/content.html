Identifying Live Hosts with Ping Sweeps

Using nmap -sn for Initial Reconnaissance

# Basic Nmap Ping Scan
nmap -sn 192.168.1.0/24
# The -sn flag means 'no port scan', only host discovery.

Purpose

Quickly identifies active IP addresses within a specified network range.

Limitation

Many firewalls block ICMP echo requests, rendering simple ping sweeps ineffective.
