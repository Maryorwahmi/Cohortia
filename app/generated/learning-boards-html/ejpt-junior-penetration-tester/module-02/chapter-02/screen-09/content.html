The Stealthy Half-Open: TCP SYN Scan

Understanding nmap -sS and its Advantages

# Perform a TCP SYN scan
nmap -sS <target_IP>
# Replace <target_IP> with the actual IP address.

Mechanism

Sends SYN, receives SYN/ACK (if open), then sends RST without completing handshake.

Advantage

Stealthier than a full connect scan, as it avoids completing the TCP handshake, making it less likely to be logged.

TCP SYN Scan Flow

The 'half-open' connection.

1. Nmap sends SYN

To target port.

2. Target responds SYN/ACK

If port is open.

3. Nmap sends RST

Resets connection without completing handshake.

Common Misconception

SYN scans are not entirely invisible; advanced IDS/IPS can still detect them.
