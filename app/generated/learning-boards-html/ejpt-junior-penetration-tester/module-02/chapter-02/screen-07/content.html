Beyond Ping: TCP SYN and ARP Requests

Adapting to Blocked ICMP Environments

TCP SYN Probes

Nmap sends SYN packets to common ports (e.g., 80, 443). A SYN/ACK response indicates a live host.

ARP Requests

On local networks, Nmap sends ARP requests. A response confirms the host's presence by mapping its IP to MAC address.

Key Takeaway

Nmap's ability to use multiple host discovery methods ensures it can find live targets even when ICMP is blocked.

Host Discovery Flow (Advanced)

Adapting to network defenses.

1. Try ICMP Ping

Fastest initial check.

2. If Blocked, Try TCP SYN

Send SYN to common ports (80, 443).

3. On Local Net, Try ARP

Map IP to MAC addresses directly.
