Activity: Starting GVM Services on Kali

Initializing and launching the Greenbone Vulnerability Manager.

Prerequisite

Ensure your Kali Linux VM is running and you have terminal access.

Command Execution

Run sudo gvm-start in your Kali terminal to initiate all GVM services.

Monitor Startup

Wait for all services to report as 'started.' This may take a few minutes.

Key Takeaway

The sudo gvm-start command is essential to prepare your OpenVAS environment for scanning, providing the web interface URL and admin credentials.

kali@kali:~$ sudo gvm-start
Starting Greenbone Vulnerability Manager...
_gvm_start_daemon: Checking if Greenbone Security Assistant is running...
