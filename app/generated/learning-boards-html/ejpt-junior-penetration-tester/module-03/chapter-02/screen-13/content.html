Key Concepts

Essential terms from this chapter.

Automated Vulnerability Scanner

Software designed to identify security weaknesses in systems, applications, and networks automatically.

OpenVAS (GVM)

An open-source vulnerability scanning framework, commonly included in Kali Linux, also known as Greenbone Vulnerability Manager.

Nessus

A proprietary, widely-used vulnerability scanner developed by Tenable, offering comprehensive security assessments.

Summary Takeaway

Automated scanners like OpenVAS and Nessus are indispensable for efficient vulnerability identification, forming the initial layer of a robust security assessment.
