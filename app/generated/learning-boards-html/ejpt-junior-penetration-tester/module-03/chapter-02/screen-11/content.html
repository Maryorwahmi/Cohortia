Activity: Defining a Target and Creating a Scan Task

Configuring your scan for Metasploitable2 in OpenVAS.

1. Access Web Interface

Navigate to https://127.0.0.1:9392 in your Kali browser and log in with admin credentials.

2. Define a Target

Go to Configuration > Targets, click 'New Target', name it (e.g., Metasploitable2_Target), and enter Metasploitable2's IP address.

3. Create a New Task

Navigate to Scans > Tasks, click 'New Task', name it (e.g., Metasploitable2_Full_Scan), select your target, and choose 'Full and fast ultimate' as the Scan Config.

Key Takeaway

Accurate target definition and appropriate scan policy selection are crucial for effective vulnerability scanning.
