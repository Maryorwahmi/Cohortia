Key Concepts

Critical terminology for effective vulnerability management.

Scan Policy/Configuration

A set of rules and parameters that dictate how a vulnerability scan is performed (e.g., types of checks, intensity).

Credentialed Scan

A vulnerability scan performed with valid authentication credentials for the target system, allowing for deeper internal inspection.

False Positive / Negative

A reported vulnerability that doesn't exist (positive) or an existing one that is missed (negative) by the scanner.

Summary Takeaway

Effective vulnerability management relies on understanding scan policies, leveraging credentialed scans, and critically evaluating results to differentiate true threats from scanner limitations.
