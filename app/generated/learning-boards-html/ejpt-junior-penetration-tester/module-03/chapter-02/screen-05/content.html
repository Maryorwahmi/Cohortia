OpenVAS (GVM): Architecture and Initialization

Exploring the client-server model and basic setup for Greenbone Vulnerability Manager.

Client-Server Model

OpenVAS operates with a server (GVM) managing scans and a client (web interface) for user interaction.

GVM Components

The server handles the scanning engine, vulnerability feeds, and report generation.

Key Takeaway

Understanding the GVM client-server architecture is crucial for effective setup and troubleshooting of OpenVAS scans.
