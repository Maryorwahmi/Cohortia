Analysis & Prioritization

Deciphering OpenVAS Scan Reports

Understanding severity, remediation, and identifying false positives.

Severity Levels

Reports categorize vulnerabilities as Critical, High, Medium, or Low, but context is key for prioritization.

Remediation Suggestions

Each finding typically includes advice on how to fix or mitigate the identified vulnerability.

False Positives

Scanners may flag non-existent vulnerabilities; manual verification is essential to confirm actual threats.

Key Takeaway

Prioritize vulnerabilities based on their real-world impact and verify scanner findings to avoid chasing false positives.

Report Interpretation Flow
Review Report

Examine listed vulnerabilities.

Assess Severity & Context

Prioritize based on actual impact.

Verify Findings

Manually confirm true vulnerabilities.

Example: Scanner flags Apache vulnerability, but server runs Nginx. This is a false positive.
