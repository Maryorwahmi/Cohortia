# User, File System, and Process Enumeration
$cat /etc/passwd
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
www-data:x:33:33:www-data:/var/www:/usr/sbin/nologin
msfadmin:x:1000:1000:metasploitable:/home/msfadmin:/bin/bash
$ls -laR /var/www/html
/var/www/html:
total 20
drwxr-xr-x 5 root root 4096 Apr 23 2018 .
drwxr-xr-x 3 root root 4096 Apr 23 2018 ..
-rw-r--r-- 1 root root 177 Apr 23 2018 index.html
drwxr-xr-x 2 root root 4096 Apr 23 2018 dvwa
-rw-r--r-- 1 root root 120 Apr 23 2018 config.php
$ps aux | grep root
root 1 0.0 0.1 123456 456 ? Ss Apr23 0:01 /sbin/init
root 123 0.0 0.0 1234 567 ? S Apr23 0:00 [kworker/0:1]
$find / -perm -4000 2>/dev/null
/usr/bin/passwd
/usr/bin/sudo
/usr/bin/nmap
Command Breakdown
  • •cat /etc/passwd: Lists system users.
  • •ls -laR /var/www/html: Explores web directories for sensitive files.
  • •ps aux: Shows running processes, especially those by root.
  • •find / -perm -4000: Locates SUID binaries for privilege escalation.
Practical Use

Finding a config.php file in a web directory might contain database credentials, allowing access to sensitive data. An SUID nmap binary could be exploited to run commands as root, granting full system control.

Key Takeaway

Detailed enumeration of users, files, and processes uncovers deeper vulnerabilities and sensitive information, paving the way for privilege escalation and data exfiltration.
