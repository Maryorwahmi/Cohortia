Kernel Exploits

These exploit vulnerabilities in the operating system kernel itself. A successful kernel exploit can grant immediate root privileges, making it a highly impactful method.

  • •Identification: Use uname -a to get kernel version.
  • •Research: Search public databases (e.g., Exploit-DB) for known exploits.
  • •Impact: Often leads to full root access.

SUID/SGID Binaries

Programs with the SUID (Set User ID) bit set run with the permissions of their owner (often root), not the user executing them. If exploitable, they can be used to run commands as root.

  • •Identification: Use find / -perm -4000 2>/dev/null.
  • •Examples: passwd, sudo, older nmap versions.
  • •Exploitation: Manipulate the binary to execute arbitrary commands with elevated privileges.
Example: SUID Nmap

If nmap is found with the SUID bit, you could run nmap --interactive and then use the !bash command within Nmap's interactive shell to spawn a root shell.

Key Takeaway

Kernel exploits and vulnerable SUID binaries are powerful vectors for privilege escalation, requiring careful identification and exploitation techniques to gain root access.
