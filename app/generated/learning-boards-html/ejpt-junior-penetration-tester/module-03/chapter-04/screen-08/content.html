What is Privilege Escalation?

Privilege escalation is the act of gaining higher-level access permissions on a system than initially obtained. This typically means moving from a low-privileged user (e.g., a web user) to a high-privileged user (e.g., root on Linux or Administrator on Windows).

  • •Goal: Achieve full control over the compromised system.
  • •Necessity: Many critical system operations and sensitive data are protected by higher privilege levels.
  • •Impact: Demonstrates the maximum potential damage or control an attacker could gain.
Common Misconception

Initial access does not always mean full control. Many penetration tests start with low-privileged access, making privilege escalation a necessary step to achieve deeper objectives.

Why it's Essential

Without elevated privileges, access to critical system files, configuration settings, and the ability to install persistent backdoors is often restricted, limiting the scope of a penetration test.

Example Scenario

A web application vulnerability grants you a shell as the 'www-data' user. To read the /etc/shadow file or modify system startup scripts, you would need to escalate privileges to 'root'.

Key Takeaway

Privilege escalation is a fundamental post-exploitation goal, enabling full system control and access to restricted resources to fulfill penetration test objectives.
