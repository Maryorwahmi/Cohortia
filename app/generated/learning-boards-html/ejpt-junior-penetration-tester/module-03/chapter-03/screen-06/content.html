Exploits and Payloads

The attack vector and its post-exploitation action

Exploits

Code that targets a specific vulnerability to gain initial access to a system. It's the mechanism that breaches the defense.

  • Leverages flaws like buffer overflows or misconfigurations.
  • Creates an entry point for further actions.
  • Example: `vsftpd_234_backdoor` targets a specific FTP server vulnerability.
Key Insight

Exploits are the 'how' of gaining access, focusing on the vulnerability itself.

Payloads

Small pieces of code that run on the target system *after* a successful exploit. Their purpose is to perform a specific action.

  • Delivers a shell, creates a backdoor, or migrates processes.
  • Executed once the exploit has created an entry point.
  • Example: A reverse shell payload connects back to the attacker.
Key Insight

Payloads are the 'what' of post-exploitation, defining the desired outcome.
