Executing the Exploit

Launching the attack and gaining initial access

1. Launching the Attack

Use the `run` or `exploit` command to initiate the attack. Metasploit will attempt to leverage the vulnerability with the configured options.

  • `run` and `exploit` are interchangeable.
  • The framework handles the exploit delivery.

2. Verifying Shell Access

Upon success, you'll receive a message like "Command shell session X opened." You can then interact with the target via the shell.

  • Run `whoami` to check user context.
  • Run `ls -la /` to list directories.
Key Takeaway

A successful exploit grants you a shell, providing command-line control over the compromised system.
