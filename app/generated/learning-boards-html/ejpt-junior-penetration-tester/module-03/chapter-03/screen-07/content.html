MSF Components

Supporting Modules

Enhancing your capabilities beyond direct exploitation

Auxiliary Modules

Tools for various tasks not directly exploits, such as scanning, fuzzing, or information gathering. Essential for reconnaissance.

Use Case

Port scanning a target to identify open services.

Encoders

Used to obfuscate payloads to evade antivirus detection and intrusion prevention systems. Helps maintain stealth.

Use Case

Making a shellcode payload undetectable by common AV signatures.

Post-Exploitation

Modules used to perform actions on a compromised system, such as privilege escalation, data exfiltration, or lateral movement.

Use Case

Dumping password hashes from a compromised Windows machine.
