Essential Concepts to Remember

Core definitions from our journey.

Vulnerability

A flaw or weakness in a system that can be exploited by an attacker to violate security policy.

Vulnerability Assessment (VA)

The process of identifying, quantifying, and prioritizing vulnerabilities in a system or network.

Penetration Testing (PT)

A simulated cyberattack against a system to check for exploitable vulnerabilities and demonstrate impact.

Summary Takeaway

Vulnerability assessment is a proactive approach to identify weaknesses, while penetration testing actively exploits them to prove real-world risk.
