Temporal Metrics: Time-Sensitive Vulnerability Data

How Vulnerability Scores Evolve Over Time

These metrics reflect characteristics of a vulnerability that change over time, providing a more current assessment of its real-world threat level.

Key Takeaway

Temporal metrics adjust a vulnerability's score based on factors like exploit availability and patch status, reflecting its current real-world threat level.

Real-world Connection

A vulnerability's urgency increases significantly once public exploit code is available, even if its base score remains the same.

Exploit Code Maturity (E)

The availability and maturity of exploit code (Unproven, Proof-of-Concept, Functional, High).

Remediation Level (RL)

The existence and availability of a fix (Official Fix, Temporary Fix, Workaround, Unavailable).

Report Confidence (RC)

The confidence in the technical details of the vulnerability report (Unknown, Reasonable, Confirmed).
