Applying CVSS: A Remote Code Execution Example

Constructing a CVSS Vector String and Interpreting Severity

Let's walk through a scenario to build a CVSS v3.1 Base Vector string for a critical vulnerability and understand its implications.

Key Takeaway

Building a CVSS vector string systematically translates vulnerability characteristics into a standardized, quantifiable severity score.

Scenario

Unauthenticated RCE on a public-facing e-commerce web server.

CVSS v3.1 Base Vector Construction
CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H
Resulting Severity: Critical (e.g., 9.8)

Exploitability Metrics

  • AV: Network
  • AC: Low
  • PR: None
  • UI: None
  • S: Unchanged

Impact Metrics

  • C: High
  • I: High
  • A: High
