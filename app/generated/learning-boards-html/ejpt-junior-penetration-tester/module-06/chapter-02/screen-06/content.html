Base Metrics: Exploitability Factors

Assessing How a Vulnerability Can Be Exploited

These metrics describe the characteristics of a vulnerability that are constant over time and across user environments, focusing on the ease of exploitation.

Key Takeaway

Exploitability metrics like Attack Vector and Privileges Required determine how easy or difficult it is for an attacker to leverage a vulnerability.

Example

A vulnerability requiring no user interaction and network access to exploit would have a higher Base Score.

Attack Vector (AV)

How an attacker exploits the vulnerability (Network, Adjacent, Local, Physical).

Attack Complexity (AC)

The difficulty of exploiting the vulnerability (Low, High).

Privileges Required (PR)

Level of privileges an attacker needs (None, Low, High).

User Interaction (UI)

Whether a user must participate for the exploit to succeed (None, Required).

Scope (S)

Whether the vulnerability can impact components beyond its security authority (Unchanged, Changed).
