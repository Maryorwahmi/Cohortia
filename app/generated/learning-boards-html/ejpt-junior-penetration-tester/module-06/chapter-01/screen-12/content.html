Drafting a Vulnerability Finding: XSS Example

Apply the structured format to document a Cross-Site Scripting vulnerability.

Scenario: XSS on Search Page

You've found an XSS vulnerability allowing arbitrary JavaScript execution when viewing search results for a crafted query.

Example Payload to Use
<script>alert('XSS')</script>
Your Task

Draft a detailed finding including ID, Name, Severity, Affected Component, Description, Steps to Reproduce (PoC), Impact, and Recommendation.

Vulnerability Finding Template
Finding ID & Name
Severity & Affected Component
Description & Steps to Reproduce
Impact & Recommendation
Key Takeaway

Practice drafting findings to internalize the structure and ensure all critical details are consistently included.
