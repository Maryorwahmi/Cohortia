Technical Phase 4

Exploitation: Gaining Unauthorized Access

Leveraging identified vulnerabilities to compromise systems.

Step 1Identify Target Vulnerability
Step 2Select/Craft Exploit
Step 3Execute Exploit
Step 4Gain Unauthorized Access

Exploitation Methods

  • Publicly available exploits.
  • Custom-crafted exploits.
  • Exploitation frameworks (e.g., Metasploit).

Example: Metasploit

If an outdated Apache server with a known RCE vulnerability is found, a Metasploit module can be used to deliver a payload, granting a shell on the server.

Key Takeaway

Exploitation is the act of leveraging vulnerabilities to gain access, demonstrating the real-world impact of security flaws while strictly adhering to the RoE.
