Technical Phase 1

Intelligence Gathering: Active Reconnaissance

Directly interacting with the target to gather specific details.

What is Active Reconnaissance?

This involves direct interaction with the target system to gather specific information. While it carries a higher risk of detection, it yields more precise and actionable data.

Key Information Gained

  • Open ports and running services.
  • Specific software versions (e.g., web server, database).
  • Operating system identification.
  • Network topology insights.
Risk vs. Reward

Active reconnaissance provides highly specific data but increases the chance of detection. It must be carefully planned and executed within the scope of the Rules of Engagement (RoE).

Tools & Techniques

  • Nmap (Network Mapper): Used for port scanning to identify open ports, services, and OS. Example: nmap -sV 192.168.1.100
  • Banner Grabbing: Connecting to a service (e.g., HTTP, FTP) to read its identifying banner, which often reveals software versions.
  • Traceroute: Mapping the network path to a target, revealing routers and hops.
Key Takeaway

Active reconnaissance uses direct interaction with tools like Nmap to gain precise, actionable data about a target, accepting a higher detection risk for more detailed insights.
