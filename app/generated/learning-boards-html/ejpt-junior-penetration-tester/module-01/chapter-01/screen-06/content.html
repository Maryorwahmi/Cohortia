Identifying Weaknesses: Vulnerability Assessment

Passive Scanning for Known Security Flaws

Passive Discovery

Uses automated tools and manual reviews to scan for known weaknesses and identify potential issues.

Output: List of Vulnerabilities

Provides a comprehensive list of identified vulnerabilities, often including CVEs (Common Vulnerabilities and Exposures).

Key Takeaway

Vulnerability assessments are essential for broad-spectrum weakness identification but do not prove exploitability or real-world impact.

Example: Outdated Web Server Software

A vulnerability scanner might report that your web server is running an outdated version of Apache with known CVEs. This identifies a potential weakness but doesn't confirm if it can be exploited.

Pro Tip

Always start with a vulnerability assessment to get a broad overview of potential issues before diving into targeted penetration testing.
