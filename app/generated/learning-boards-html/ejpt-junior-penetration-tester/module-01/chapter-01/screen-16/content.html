Key Concepts

Essential Terms from This Chapter

Penetration Testing

A simulated cyberattack to identify exploitable vulnerabilities proactively.

Vulnerability Assessment

A passive process of identifying and cataloging security weaknesses without exploitation.

Black Box Testing

A pen test where the tester has no prior knowledge, simulating an external attacker.

Summary Takeaway

Penetration testing is a proactive, ethical hacking practice distinct from vulnerability assessments, with Black Box testing simulating external threats.
