Bypass Techniques

Advanced File Upload Bypasses

Circumventing common file validation mechanisms.

Common Bypass Methods

  • **Double Extension:** `shell.php.jpg` to trick extension checks.
  • **Null Byte:** `shell.php%00.jpg` to truncate filename on server.
  • **Content-Type Bypass:** Modify `Content-Type` header in Burp Suite.
  • **Magic Byte Bypass:** Alter file headers to mimic allowed types.
Key Takeaway

Attackers use various techniques like double extensions, null bytes, and Content-Type manipulation to bypass file upload restrictions and deploy malicious files.

Content-Type Bypass

Intercept the upload request and change the Content-Type header (e.g., from application/x-php to image/jpeg) to trick the server's validation.

Original: Content-Type: application/x-php
Modified: Content-Type: image/jpeg

Double Extension & Null Byte

Rename shell.php to shell.php.jpg (double extension) or shell.php%00.jpg (null byte) to bypass extension checks that only look at the last part of the filename.

Filename: shell.php.jpg
Filename: shell.php%00.jpg
