Practical Use

Analyzing and Modifying Requests with Burp Proxy

Intercepting, viewing, and manipulating web traffic in real-time.

Key Actions

  • **Intercept:** Pause requests and responses for inspection.
  • **Modify:** Alter headers, parameters, or body content.
  • **Forward:** Send modified requests to the server.
  • **Repeater:** Manually resend and fine-tune individual requests.
Key Takeaway

Burp Suite's Proxy and Repeater tools provide granular control over web traffic, enabling precise testing and exploitation of web application vulnerabilities.

Intercepting Requests

With 'Intercept is on' in Burp's Proxy tab, all browser requests are paused, allowing for real-time examination and modification.

GET /login.php?user=admin&pass=password HTTP/1.1
Host: example.com
User-Agent: Mozilla/5.0
Cookie: PHPSESSID=abc123def456

Using Repeater for Fine-Tuning

Send intercepted requests to the Repeater tab to manually adjust parameters and resend them repeatedly, observing server responses for exploit development.

Modified Request in Repeater:
GET /login.php?user=admin&pass=' OR '1'='1 HTTP/1.1
Host: example.com
