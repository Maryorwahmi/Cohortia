Setup Guide

Configuring Burp Suite for Interception

Step-by-step process to set up your browser and Burp Suite.

Key Setup Steps

  • Launch Burp Suite and note the Proxy listener (e.g., `127.0.0.1:8080`).
  • Configure your browser's network settings to use Burp's proxy for HTTP/S.
  • Install Burp's CA certificate in your browser to handle SSL/TLS traffic.
  • Ensure 'Intercept is on' in Burp's Proxy tab.
Key Takeaway

Properly configuring both Burp Suite and your browser is crucial for enabling effective interception and analysis of web traffic.

Browser Proxy Settings

Direct your browser's HTTP and HTTPS traffic to Burp's local listener (e.g., 127.0.0.1:8080) via manual proxy configuration.

Firefox Settings > Network Settings > Manual Proxy Configuration
HTTP Proxy: 127.0.0.1 Port: 8080
SSL Proxy: 127.0.0.1 Port: 8080

Install CA Certificate

To decrypt and inspect HTTPS traffic, you must install Burp's Certificate Authority (CA) certificate in your browser's trust store.

Navigate to: http://burp/cert
Download and install the CA certificate.
