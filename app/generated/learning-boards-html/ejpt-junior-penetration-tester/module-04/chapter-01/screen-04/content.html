Core Concept

The Client-Server Model: Web's Foundation

Understanding how browsers and servers interact

Key Components

  • •
    Client: Typically your web browser (e.g., Chrome, Firefox) that initiates requests.
  • •
    Server: A remote computer that stores web resources and responds to client requests.
  • •
    Request: An action initiated by the client to retrieve or send data to the server.
  • •
    Response: The server's reply to a client's request, containing requested data or status.
Concrete Example

When you visit google.com, your browser (client) sends a request to Google's servers, which then send back the HTML, CSS, and JavaScript to render the search page.
