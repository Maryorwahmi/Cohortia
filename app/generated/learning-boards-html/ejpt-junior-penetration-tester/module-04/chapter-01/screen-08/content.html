Web Servers: The Frontline Gatekeepers

Serving static content and routing requests

Primary Functions

  • •
    Serve Static Content: Deliver HTML, CSS, JS, images directly to clients.
  • •
    Reverse Proxy: Forward dynamic requests to application servers.
  • •
    Load Balancing: Distribute traffic across multiple application servers (often).
Concrete Example

Nginx serves a website's logo image directly from disk, then forwards a request for /api/users to a Node.js application server.

Key Takeaway

Web server misconfigurations are common attack vectors; always check for outdated versions, default credentials, and exposed directory listings.
