Avoiding Common Web Testing Mistakes

Crucial considerations for effective penetration testing

Mistakes to Avoid

  • •
    Ignoring HTTP Headers: Missing critical info like Server, Set-Cookie, X-Powered-By.
  • •
    Neglecting Client-Side: Assuming server-side validation is foolproof; client-side logic is easily bypassed.
  • •
    Unauthorized Testing: Conducting tests without explicit permission can lead to severe legal consequences.
Concrete Example

A website uses client-side JavaScript to validate email format. An attacker can easily disable JavaScript in their browser and submit an invalid email, bypassing the validation.

Key Takeaway

A diligent penetration tester examines all layers, including client-side logic and HTTP headers, and always operates within a clearly defined and authorized scope.
