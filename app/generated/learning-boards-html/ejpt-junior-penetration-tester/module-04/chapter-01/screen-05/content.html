Anatomy of an HTTP Request

Deconstructing the client's message to the server

Key Request Components

  • •
    Method: The action to be performed (e.g., GET, POST, PUT, DELETE).
  • •
    URI: Identifies the resource being requested (e.g., /login.html).
  • •
    Headers: Additional info about the request or client (e.g., User-Agent, Accept).
  • •
    Body (Optional): Data sent to the server, typically for POST requests (e.g., form data).
Concrete Example

A login form submission often uses a POST method, sending username and password in the request body to a URI like /auth, with headers specifying content type.

POST /login HTTP/1.1
Host: example.com
User-Agent: Mozilla/5.0 (Browser)
Accept: text/html,application/xhtml+xml
Content-Type: application/x-www-form-urlencoded
Content-Length: 30

username=testuser&password=pass123
Key Takeaway

Each part of an HTTP request provides valuable information; understanding them helps in identifying how to manipulate web application behavior.
