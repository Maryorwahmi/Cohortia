Decoding HTTP Responses

Interpreting the server's reply to client requests

Key Response Components

  • •
    Status Code: A 3-digit number indicating the request's outcome (e.g., 200, 404, 500).
  • •
    Headers: Additional info about the response, server, or content (e.g., Server, Set-Cookie).
  • •
    Body: The actual content requested by the client (e.g., HTML, JSON, image).
Concrete Example

A successful request for a web page might return a 200 OK status, with Content-Type: text/html header, and the page's HTML in the body.

HTTP/1.1 200 OK
Date: Tue, 15 Nov 2023 10:00:00 GMT
Server: Apache/2.4.41 (Ubuntu)
Content-Type: text/html; charset=UTF-8
Set-Cookie: sessionid=abc123def456; Path=/; HttpOnly
Content-Length: 1234

<!DOCTYPE html>
<html>
<head><title>Welcome</title></head>
<body><h1>Hello, World!</h1></body>
</html>
Key Takeaway

Response headers, especially Server and Set-Cookie, can reveal crucial information about the underlying technologies and session management, aiding in targeted attacks.
