Client-Side Attack

Cross-Site Scripting (XSS): Injecting Malicious Scripts

When an attacker injects client-side scripts into web pages

Core Mechanism

Attacker injects malicious client-side scripts (usually JavaScript) into a web page viewed by other users.

Potential Impact

Steal session cookies, deface websites, redirect users, or perform actions on behalf of the victim.

Key Takeaway

XSS attacks exploit trust between a user's browser and the website, executing malicious scripts client-side.

XSS Attack Flow
1. Attacker crafts malicious script

e.g., ``

2. Script injected into web page

Via URL, database, or DOM manipulation.

3. Victim's browser executes script

Leading to cookie theft, defacement, etc.
