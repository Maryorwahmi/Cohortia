Injection Type

SQL Injection (SQLi): Database Manipulation

Exploiting database queries with malicious SQL code

How it Works

Attacker inserts malicious SQL code into input fields, which is then directly concatenated into a database query.

Impact

Bypass authentication, retrieve sensitive data, or modify/delete database contents.

Key Takeaway

Always use parameterized queries (prepared statements) to prevent SQLi by separating code from user data.

SQLi Login Bypass Example
-- Vulnerable Query StructureSELECT * FROM users WHERE username = 'input_username' AND password = 'input_password';-- Attacker Input: admin' OR '1'='1-- Resulting Malicious QuerySELECT * FROM users WHERE username = 'admin' OR '1'='1' AND password = 'input_password';-- '1'='1' is always true, bypassing password check.
Pro Tip

Test for SQLi by injecting single quotes, comments (`--`), or boolean-based conditions (`OR 1=1`) into input fields.
