Key Concepts: Part 1

Essential terms from OWASP Top 10

OWASP Top 10

A list of the most critical web application security risks.

Injection

Untrusted data sent to an interpreter as part of a command or query.

SQL Injection (SQLi)

Attacker inserts malicious SQL code to manipulate database queries.

Command Injection

Attacker injects OS commands into input, executed on the server.

Cross-Site Scripting (XSS)

Attacker injects client-side scripts into web pages viewed by others.

Reflected XSS

Malicious script immediately returned by the web server in its response.

Summary Takeaway

Injection and XSS are critical vulnerabilities that exploit how applications process and display user-supplied data, leading to severe security risks.
