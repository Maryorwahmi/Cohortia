XSS Types

Reflected and Stored XSS

Understanding how malicious scripts are delivered

Reflected XSS

Malicious script is immediately 'reflected' back to the user from the web server, typically in an error or search result. Payload is part of the request URL.

Stored XSS

Malicious script is permanently stored on the target server (e.g., database, comment section) and delivered to all users visiting the affected page.

Key Takeaway

Reflected XSS is transient and URL-based, while Stored XSS is persistent and affects multiple users.

XSS Delivery Comparison
Reflected XSS
  • •Payload in URL.
  • •Immediate execution.
  • •Requires user interaction (click link).
Stored XSS
  • •Payload stored on server.
  • •Persistent, affects all visitors.
  • •No direct user interaction needed.
Common Misconception

XSS is not a server-side attack; it targets the client's browser, exploiting its trust in the web page content.
