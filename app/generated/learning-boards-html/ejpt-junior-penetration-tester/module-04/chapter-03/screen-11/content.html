Authentication Flaws

Broken Authentication and Session Management

Weaknesses in user login and session handling

Common Issues

  • •Weak or default credentials.
  • •Insecure password recovery.
  • •Weak or predictable session IDs.
  • •Improper session expiration.

Impact

Bypass authentication, impersonate users, or gain unauthorized access.

Key Takeaway

Robust authentication and secure session management are critical to prevent unauthorized access and user impersonation.

Session ID Vulnerability Example
Predictable Session IDs

If session IDs are sequential (e.g., `session=1001`, `session=1002`), an attacker can easily guess other users' active session IDs and hijack their accounts.

Common Mistake

Not invalidating session tokens upon logout or after a period of inactivity, allowing stolen cookies to remain active.
