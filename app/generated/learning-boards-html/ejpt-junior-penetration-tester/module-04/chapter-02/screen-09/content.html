Tool Walkthrough

Directory and File Enumeration with Gobuster

Tools like Dirb or Gobuster are designed to brute-force directories and files on a web server using wordlists.

Gobuster Command Breakdown

gobuster dir -u http://example.com -w /usr/share/wordlists/dirb/common.txt -x php,html,bak,zip
  • dir: Specifies directory enumeration mode.
  • -u: Target URL (e.g., http://example.com).
  • -w: Path to the wordlist (e.g., /usr/share/wordlists/dirb/common.txt).
  • -x: Common file extensions to append (e.g., php,html,bak,zip).
Key Takeaway

Gobuster automates the discovery of hidden paths, but effective use requires careful wordlist and extension selection.

Interpreting Gobuster Output

Gobuster will show discovered paths along with their HTTP status codes:

/admin (Status: 200)
/backup.zip (Status: 200)
/config.php.bak (Status: 200)
/secret (Status: 403)
  • 200 OK: Resource exists and is accessible.
  • 403 Forbidden: Resource exists but access is denied (still valuable!).
  • 404 Not Found: Resource does not exist.
Common Mistakes
  • Using too small a wordlist, missing potential paths.
  • Not considering different file extensions (e.g., .old, .txt).
  • Ignoring 403 Forbidden responses, which indicate existing but protected resources.
