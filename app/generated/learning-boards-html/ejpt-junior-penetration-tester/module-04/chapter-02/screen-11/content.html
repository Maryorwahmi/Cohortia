Tool Walkthrough

Subdomain Enumeration with Subfinder

Tools like Subfinder or Amass automate subdomain discovery by querying various public data sources.

Subfinder Command Example

subfinder -d example.com -o subdomains.txt
  • -d: Specifies the target domain (e.g., example.com).
  • -o: Specifies an output file to save the discovered subdomains.

Subfinder queries public sources like DNS records, search engines, and certificate transparency logs.

Key Takeaway

Automated tools like Subfinder are crucial for efficiently discovering a wide range of subdomains from public sources.

Post-Enumeration Steps

Once subdomains are found, the reconnaissance process continues:

  • Verify Active Services: Check if each subdomain hosts an active web application.
  • Technology Fingerprinting: Run whatweb or similar tools on each active subdomain.
  • Directory Enumeration: Use gobuster on each subdomain to find hidden paths.
  • Manual Inspection: Browse each subdomain to understand its functionality.
Safety Note

Subdomain enumeration is generally passive, but always ensure you are within the scope of any engagement. Never proceed to active scanning or exploitation without explicit permission.
