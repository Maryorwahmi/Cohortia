Open-Source Intelligence (OSINT): Beyond the Website

OSINT involves gathering information from publicly available sources to gain additional context about a web application and its infrastructure.

Key OSINT Sources

  • Search Engines (Google Dorking): Advanced operators to find hidden files, login pages, sensitive documents.
  • Social Media: Employee profiles, company announcements, technology discussions.
  • Public Code Repositories: GitHub, GitLab for exposed source code, credentials, or API keys.
  • Archive Services: Wayback Machine for historical versions of websites.
  • Public Registries: WHOIS records for domain ownership details.
Key Takeaway

OSINT provides invaluable context, helping to identify logical flaws and understand the human element behind the application.

Google Dorking Examples

  • site:example.com inurl:admin (Find admin login pages)
  • filetype:pdf site:example.com confidential (Find sensitive PDF documents)
  • intitle:"index of" site:example.com (Find directory listings)
  • intext:"password" site:example.com (Find pages containing the word 'password')
Safety Note

Only access publicly available information. Do not attempt to gain unauthorized access to private accounts or data. Respect privacy and legal boundaries.
