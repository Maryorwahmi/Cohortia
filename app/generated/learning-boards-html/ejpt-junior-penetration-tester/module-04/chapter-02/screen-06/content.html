Practical Tools

Technology Fingerprinting: Tools and Techniques

Identify underlying technologies using a mix of automated tools and manual inspection methods.

Automated Tools Overview

  • Wappalyzer: Browser extension for quick, high-level tech identification.
  • BuiltWith: Online service offering detailed technology profiles.
  • WhatWeb: Command-line tool for comprehensive web technology scanning.

Example: Using WhatWeb

whatweb example.com

Provides a summary of identified technologies.

Key Takeaway

Combine automated tools with manual checks for the most accurate and complete technology fingerprint.

Manual Inspection Techniques

  • HTTP Response Headers: Look for Server, X-Powered-By, Set-Cookie headers.
  • File Extensions: Observe .php, .asp, .jsp in URLs.
  • HTML Source Code: Search for framework-specific comments, meta tags, or library references.
  • JavaScript Files: Examine JS files for library names and version numbers.
  • Error Messages: Sometimes reveal server or application details.

Example: Inspecting Headers

Using a browser's developer tools or curl -I example.com can reveal:

HTTP/1.1 200 OK
Server: Apache/2.4.41 (Ubuntu)
X-Powered-By: PHP/7.4.3
Content-Type: text/html; charset=UTF-8

This immediately tells us the web server and PHP version.
