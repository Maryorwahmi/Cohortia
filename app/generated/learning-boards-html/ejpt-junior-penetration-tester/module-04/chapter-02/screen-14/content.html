Key Concepts: Reconnaissance Fundamentals

Essential Terms to Remember for Web Penetration Testing

Technology Fingerprinting

Identifying web servers, frameworks, languages, and CMS platforms used by a target web application.

Wappalyzer

A browser extension and online service used for quickly identifying technologies on websites.

WhatWeb

A command-line tool for identifying web technologies, providing detailed summaries.

Directory & File Enumeration

The process of discovering hidden or unlinked directories and files on a web server.

Dirb/Gobuster

Command-line tools used for directory and file brute-forcing with wordlists.

Subdomain Enumeration

The process of discovering subdomains associated with a target domain, expanding the attack surface.

Chapter Summary

Mastering these foundational reconnaissance techniques is crucial for building a comprehensive understanding of your target and conducting effective penetration tests.
