Control Type

Preventive Controls

These controls are designed to stop a risk event from occurring in the first place, acting as proactive barriers to threats.

Key Examples
  • Firewalls (block unauthorized traffic)
  • Multi-Factor Authentication (MFA)
  • Encryption (data at rest/in transit)
Common Mistake

Relying solely on preventive controls. No single control is foolproof; attackers constantly seek bypasses.

Proactive Protection: Preventive Controls

Stopping Risk Events Before They Occur

How They Work

Firewalls filter network traffic.

MFA requires multiple verification factors.

ACLs restrict user permissions.

Encryption protects data confidentiality.

Scenario Example

A company implements strong MFA for all remote access. This prevents 90% of credential-stuffing attacks from succeeding, even if user passwords are leaked online.

Key Takeaway

Preventive controls are the first line of defense, proactively stopping threats and significantly reducing the likelihood of incidents.
