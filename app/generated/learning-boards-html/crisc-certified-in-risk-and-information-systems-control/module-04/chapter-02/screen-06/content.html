Control Type

Detective Controls

These controls are designed to identify and alert an organization when a risk event has occurred or is in progress, providing crucial visibility.

Key Examples
  • Intrusion Detection Systems (IDS)
  • Security Information and Event Management (SIEM)
  • Vulnerability Scans & Pen Tests
Common Pitfall

Alert fatigue: too many non-critical alerts can lead to legitimate threats being overlooked. Regular tuning is essential.

Early Warning Systems: Detective Controls

Identifying Incidents in Progress

How They Work

IDS monitors network for suspicious patterns.

SIEM aggregates and analyzes security logs.

Vulnerability scans identify system weaknesses.

Security cameras monitor physical access.

Scenario Example

A SIEM system detects 50 failed login attempts from an unknown IP address to a critical server within 5 minutes, triggering an immediate high-priority alert to the security team.

Key Takeaway

Detective controls are crucial for timely incident identification, enabling rapid response and minimizing potential damage.
