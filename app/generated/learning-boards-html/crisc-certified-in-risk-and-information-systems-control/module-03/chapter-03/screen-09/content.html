Identifying Weaknesses with Vulnerability Scanning

Automated Tools for Broad Coverage

What is it?

Automated process using specialized software to identify known vulnerabilities in systems, networks, and applications.

Common Tools

  • Nmap (network discovery, port scanning)
  • Nessus, OpenVAS, Qualys (comprehensive vulnerability assessment)

Limitations

Identifies potential vulnerabilities but doesn't confirm exploitability or assess business impact.

$ nmap -sV 192.168.1.100
Starting Nmap 7.80 ( https://nmap.org ) at 2023-10-27 10:00 EDT
Nmap scan report for 192.168.1.100
Host is up (0.00070s latency).
Not shown: 998 closed ports
PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 8.2p1 Ubuntu 4ubuntu0.5 (Ubuntu Linux; protocol 2.0)
80/tcp open  http    Apache httpd 2.4.41 ((Ubuntu))
Analysis: Open ports 22 (SSH) and 80 (HTTP) indicate active services. Potential vulnerabilities if software is outdated or misconfigured.
Key Takeaway

Vulnerability scanning is a fast, automated way to find known weaknesses, but it's a preliminary step that needs further validation.
