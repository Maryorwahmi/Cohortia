Definition of SLE

The monetary loss expected each time a specific threat materializes. It represents the direct financial impact of a single incident.

Formula: SLE = AV × EF

  • Asset Value (AV): The monetary worth of the asset at risk.
  • Exposure Factor (EF): The percentage of loss to the asset if the threat occurs (0.0 to 1.0).
Key Takeaway

SLE provides a clear, immediate financial cost for each instance of a risk event, guiding initial impact assessments.

SLE Calculation Examples

Example 1: Server Destruction

  • Asset Value (AV): $10,000 (server)
  • Exposure Factor (EF): 1.0 (100% loss from fire)
  • SLE: $10,000 × 1.0 = $10,000

Example 2: Data Breach

  • Asset Value (AV): $500,000 (customer database)
  • Exposure Factor (EF): 0.2 (20% records impacted)
  • SLE: $500,000 × 0.2 = $100,000

Pro Tip

Accurately determining Asset Value and Exposure Factor requires thorough asset inventory and business impact analysis.
