Module 5 › Chapter 5.2 › Practical Outcomes
Hands-on outcomes
Prepare, apply, activate, and verify static IP configurations safely in a lab.
Lab mode: terminal_demo
Create or modify profiles
Use conn_name, ifname, ip4 (CIDR), gw4, dns4, state: present, autoconnect: yes in your nmcli tasks.
Activation strategy
Prefer configuring then explicitly activating with a separate task when changing remote host networking to reduce surprise disconnections.
Verification built-in
Add commands like ip -4 addr show, nmcli connection show, and ping checks to confirm success in your playbook outputs.
Fallback planning
Keep console or hypervisor access ready, or stage a secondary address to prevent lockout when testing changes remotely.
