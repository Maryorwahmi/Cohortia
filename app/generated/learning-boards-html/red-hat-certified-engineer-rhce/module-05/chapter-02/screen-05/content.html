Definition
NetworkManager + Ansible
Ansible uses nmcli to manage NetworkManager connection profiles declaratively, avoiding direct and fragile edits to legacy ifcfg files.
Profile-centric: You manage connection profiles instead of low-level device settings.
Declarative approach: Ansible describes the desired state; NetworkManager applies it.
Safer runtime: NetworkManager remains the authority for activation and device state.
Pro tip
Prefer nmcli tasks in Ansible rather than templating ifcfg files to avoid conflicts with NetworkManager.
Architecture snapshot
Ansible
Declares connection profiles via community.general.nmcli.
NetworkManager
Creates and activates the runtime connection using the profile's settings.
System Networking
Network interfaces operate under NetworkManager's control, following profile definitions.
Example task
# Ansible task snippet
- name: Configure static IP for my-static-eth0
  community.general.nmcli:
    conn_name: my-static-eth0
    ifname: eth0
    type: ethernet
    ip4: 192.168.1.100/24
    gw4: 192.168.1.1
    dns4:
      - 8.8.8.8
      - 8.8.4.4
    state: present
    autoconnect: yes
