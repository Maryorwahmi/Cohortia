Troubleshooting
Common mistakes and fixes
Incorrect CIDR: Convert dotted masks to /prefix form; replace 255.255.255.128 with /25.
Unreachable gateway: Ensure gateway IP lies within the subnet defined by your CIDR.
DNS failures: Test by pinging an external IP first to separate routing from DNS issues.
Activation problems: Add an explicit activation step and verify with nmcli connection show.
Quick remediation commands
ip -4 addr show dev eth0
nmcli connection show my-static-eth0
nmcli connection up my-static-eth0
ping -c 3 192.168.1.1
If SSH is lost after a change, use console or hypervisor access to inspect and recover the configuration.
