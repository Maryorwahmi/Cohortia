Process
nmcli parameters you will use
conn_name
Identifier for the connection profile stored by NetworkManager.
ifname
Device name such as eth0 or enp0s3.
ip4
CIDR address like 192.168.1.100/24.
gw4
Gateway for routing outside the local subnet.
dns4
List of DNS server IPs for name resolution.
state: present
Ensures the profile exists and matches the declared settings.
Example
- name: Configure static IP for my-static-eth0
  community.general.nmcli:
    conn_name: my-static-eth0
    ifname: eth0
    type: ethernet
    ip4: 192.168.1.100/24
    gw4: 192.168.1.1
    dns4:
      - 8.8.8.8
      - 8.8.4.4
    state: present
    autoconnect: yes
Common mistake
Forgetting to ensure the gateway is within the subnet defined by your CIDR will prevent routing outside the local network.
