Lab Guidance
Safety measures for remote changes
Plan recovery before you perform network changes on remote hosts.
Console access
Keep hypervisor, IPMI, or serial console access ready to recover the host.
Secondary IP
Stage a fallback address you can use if the primary configuration fails.
Test environment
Run playbooks in a lab before production to validate behavior and avoid surprises.
Verification
Include ip and ping checks in your playbook and capture outputs for debugging.
Playbook safety snippet
- name: Ensure connection is down
  community.general.nmcli:
    conn_name: "{{ connection_profile_name }}"
    state: absent
  ignore_errors: yes
Removing an old profile first is optional but helps avoid leftover conflicting settings. Use ignore_errors to continue if the profile does not exist.
