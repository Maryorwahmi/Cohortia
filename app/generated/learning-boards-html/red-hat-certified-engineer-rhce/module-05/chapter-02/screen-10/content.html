Comparison
ifcfg files vs nmcli automation
ifcfg files are historical and show how static addresses were configured before NetworkManager became the standard controller.
When to prefer nmcli
  • Automating with Ansible under NetworkManager control
  • Maintaining idempotency and avoiding file conflicts
  • Allowing NetworkManager to manage runtime activation
Reference: ifcfg example
# TYPE="Ethernet"
# NAME="eth0"
# DEVICE="eth0"
# ONBOOT="yes"
# IPADDR="192.168.1.100"
# PREFIX="24"
# GATEWAY="192.168.1.1"
# DNS1="8.8.8.8"
# DNS2="8.8.4.4"
Note: Use this for historical understanding only; prefer nmcli tasks in automation to avoid conflicts with NetworkManager.
