Definition
CIDR and ip4
Provide your ip4 in CIDR format, for example 192.168.1.100/24. Convert dotted masks to prefix lengths before adding them to a playbook.
Conversion examples
  • 255.255.255.0 → /24
  • 255.255.255.128 → /25
  • /32 is a single-host address, not a network prefix for a multi-host subnet.
Misconception
Supplying a dotted mask where the module expects CIDR will fail or produce unexpected behavior; always use prefix length.
Concrete lab check
# Correct
ip4: 172.16.5.10/25

# Incorrect
ip4: 172.16.5.10/255.255.255.128
Key Takeaway

CIDR is required for ip4 entries. Convert subnet masks to prefix lengths to avoid mistakes and routing issues.
