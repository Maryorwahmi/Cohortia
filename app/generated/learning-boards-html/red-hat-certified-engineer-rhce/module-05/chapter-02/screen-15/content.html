Module 5 › Chapter 5.2 › Key Concepts
Gateway
Router IP used for outbound traffic; must be inside your configured CIDR to enable routing.
DNS Servers
IP addresses for name resolution; bad DNS prevents hostname access even if routing works.
community.general.nmcli
Ansible module used to declare NetworkManager connection profiles including ip4, gw4, dns4, and activation state.
Final takeaway

Automate static IPs with nmcli, verify with ip and ping checks, and always plan recovery to protect remote hosts from lockout.
