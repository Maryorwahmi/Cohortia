Module 5 › Chapter 5.1 › Learning Objectives
01
Identify devices vs connection profiles
Recognize device names like enp0s3 and connection profile names used by NetworkManager. Knowing this prevents you from targeting the wrong object in automation.
Mnemonic: Device ≠ Profile
VERIFIED COMPETENCY MILESTONE
02
Inspect state with nmcli and ip
Use ip a and ip route show for device and routing details, and nmcli device status and nmcli connection show for NetworkManager views and active profiles.
Mnemonic: ip for low-level, nmcli for profiles
VERIFIED COMPETENCY MILESTONE
03
Interpret Ansible network facts
Find primary addresses in ansible_facts.default_ipv4 and list interfaces in ansible_facts.interfaces to drive playbook logic and conditional tasks.
Mnemonic: default_ipv4 = primary
VERIFIED COMPETENCY MILESTONE
04
Manage profiles with community.general.nmcli
Use the nmcli Ansible module for idempotent creation, modification, activation, and deletion of connection profiles, and include verification steps to avoid lockout.
Mnemonic: nmcli module = idempotent changes
VERIFIED COMPETENCY MILESTONE
