Module 5 › Chapter 5.1 › Ansible facts
Key network facts
The most useful variables are ansible_facts.interfaces and ansible_facts.default_ipv4 for primary address and gateway information.
- name: Show network facts
  ansible.builtin.debug:
    var: ansible_facts.default_ipv4

- name: Show interfaces
  ansible.builtin.debug:
    var: ansible_facts.interfaces
How to use these facts
  • Drive conditional tasks based on default_ipv4.address.
  • Map playbook variables to actual interface names from interfaces list.
  • Audit and report network inventory programmatically.
Concrete example
Use default_ipv4.gateway to verify the expected route before changing DNS or static address in a profile, preventing accidental loss of connectivity.
Key Takeaway

Always inspect ansible_facts with debug to understand the structure before writing logic that depends on network facts.
