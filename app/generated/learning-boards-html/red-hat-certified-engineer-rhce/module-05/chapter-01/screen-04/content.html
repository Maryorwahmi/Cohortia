Module 5 › Chapter 5.1 › NetworkManager overview
What NetworkManager does
Manages interfaces, applies named connection profiles, handles activation and deactivation, and integrates with higher-level tooling.
Profiles hold configuration
IP addresses, DNS, routes and more are stored in connection profiles applied to devices.
Devices are hardware
The device name identifies the physical or virtual interface; the profile configures it.
Analogy
Think of a device as a phone and a connection profile as a contact. The phone exists independently. The contact tells the phone which number to dial and which ringtone to use.
Example
A server with enp0s3 may have a profile named "System enp0s3" with static IPv4 settings. Use nmcli to view and activate that profile rather than editing legacy scripts.
Common misconception
Editing /etc/sysconfig files assumes those files control the interface directly. On NetworkManager-managed systems, changes there may be ignored unless NetworkManager reads or re-applies them.
Key Takeaway

Treat profiles as the source of truth. Use nmcli or Ansible's nmcli module to manage them idempotently.
