Example playbook
This playbook gathers facts and lists active NetworkManager connections using the nmcli module.
---
- name: Gather and display network information
  hosts: webservers
  become: yes
  gather_facts: yes

  tasks:
    - name: Display all gathered network facts
      ansible.builtin.debug:
        var: ansible_facts.network_resources

    - name: List active NetworkManager connections
      community.general.nmcli:
        command: connection show --active
      register: active_connections

    - name: Display active connections output
      ansible.builtin.debug:
        var: active_connections.stdout_lines
Key points
  • gather_facts: yes collects network facts.
  • Use debug to inspect the facts structure.
  • Register nmcli output for later checks.
Common misconception
Do not assume debug output keys are identical across systems; inspect them before using in conditionals.
Key Takeaway

Use gather_facts and debug to learn the exact network facts shape before writing automation that depends on them.
