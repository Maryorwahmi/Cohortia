Module 5 › Chapter 5.1 › Practical tips
Use UUIDs
Prefer a connection's UUID in automation to avoid ambiguity when multiple profiles share similar names.
Staged rollouts
Apply changes to a test host first and verify connectivity before rolling out broadly.
Verification checks
Include nmcli and ip checks and a ping to a known host as part of any network change playbook.
Avoid legacy edits
Do not edit /etc/sysconfig network-scripts on NetworkManager systems; use nmcli instead to keep the manager consistent.
Document runbooks
Record expected outputs and verification steps so you or your team can recover quickly if issues occur.
Key Takeaway

Small safeguards make network automation robust. Treat verification and staged rollouts as non-optional practices.
