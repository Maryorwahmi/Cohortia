ip a and ip route show
Use ip a to view interfaces and addresses. Use ip route show to inspect default gateway and routing decisions.
Command examples
$ ip a
2: enp0s3: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc fq_codel state UP
    link/ether 52:54:00:12:34:56 brd ff:ff:ff:ff:ff:ff
    inet 192.168.1.10/24 brd 192.168.1.255 scope global dynamic enp0s3

$ ip route show
default via 192.168.1.1 dev enp0s3 proto dhcp src 192.168.1.10
What to look for
  • Interface state flags (UP, DOWN).
  • inet lines for configured IP addresses and CIDR.
  • Default route and gateway in ip route output.
Example scenario
If nmcli shows a profile with a static IP but ip a lacks that address, NetworkManager may not have applied the profile or the device is down. Investigate link state and service logs.
Key Takeaway

Always cross-check nmcli's intended configuration with ip's kernel-level state before changing automation logic.
