Useful nmcli commands
Use these commands to map profiles to devices and to check active configuration.
$ nmcli device status
$ nmcli connection show
$ nmcli connection show --active
Interpreting output
Look for the device column to see which profile maps to which interface and note UUIDs when scripting changes to avoid ambiguous names.
Example
If nmcli shows "Wired connection 1" on enp0s3, pass conn_name: "Wired connection 1" to the Ansible nmcli module to change settings safely for that profile.
Key Takeaway

nmcli shows NetworkManager's perspective. Use UUIDs or exact conn_name values when automating to avoid ambiguity.
