Inventory and playbook
Create an inventory and run the provided playbook to gather facts and list active connections.
# inventory.ini
[webservers]
server1 ansible_host=192.168.1.10

# Run:
ansible-playbook -i inventory.ini network_info.yml
What to observe
  • MAC and IP entries for interfaces in ansible_facts.network_resources.
  • Which conn_name is active for each device in nmcli output.
  • Any mismatch between nmcli and ip outputs.
Common mistake
Forgetting become: yes may result in incomplete facts. Also avoid running against production without testing rollback plans.
Key Takeaway

Collect facts, inspect them, then plan idempotent changes referencing conn_name or UUIDs verified from nmcli output.
