Module 5 › Chapter 5.1 › community.general.nmcli
What the module does
Manage NetworkManager connection profiles idempotently: create, update, delete, activate, and deactivate profiles.
- name: Ensure connection profile exists
  community.general.nmcli:
    conn_name: my-static-connection
    state: present
    ipv4.method: manual
    ipv4.addresses: 192.168.1.50/24
    ipv4.gateway: 192.168.1.1
    dns: 8.8.8.8
Idempotency explained
Idempotency means the module will not change a profile if it already matches the declared state. This ensures predictable automation runs.
Practical tip
Prefer conn_name or UUID over device names in playbooks to avoid ambiguity when multiple profiles exist for a single device.
Key Takeaway

The nmcli module manipulates profiles, not low-level kernel devices. Use verification tasks after applying changes.
