Learning Objectives
Learn, Understand, Apply, Master
01
Explain DNS and NTP importance
Describe how name resolution and time sync affect updates, certificates, and authentication. This matters because undetected failures can break production services.
Mnemonic: Name+Time = Reachability + Trust
VERIFIED COMPETENCY MILESTONE
02
Automate DNS with nmcli
Use community.general.nmcli to set dns4 and dns4_search on a connection profile so resolv.conf reflects desired servers persistently.
Mnemonic: Profile-first DNS
VERIFIED COMPETENCY MILESTONE
03
Deploy chrony via template
Use ansible.builtin.template to push a chrony.conf and notify a handler to restart chronyd, ensuring consistent NTP configuration.
Mnemonic: Template then restart
VERIFIED COMPETENCY MILESTONE
04
Verify and troubleshoot
Run commands like dig, host, cat resolv.conf, and chronyc sources. Check firewall rules and service states when results are unexpected.
Mnemonic: Verify, then fix
VERIFIED COMPETENCY MILESTONE
