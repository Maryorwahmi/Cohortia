Module 5 › Chapter 5.5 › Deploying chrony with Ansible
Playbook flow
  • Install chrony package.
  • Deploy chrony.conf.j2 via ansible.builtin.template and set owner, group, mode.
  • Notify handler to restart chronyd.
  • Ensure chronyd service is enabled and started.
  • Verify with chronyc sources.
Remember to allow a few minutes for synchronization and to check firewall rules if no sources appear.
Playbook snippet
- name: Ensure chrony package is installed
  ansible.builtin.package:
    name: chrony
    state: present

- name: Deploy chrony.conf from template
  ansible.builtin.template:
    src: chrony.conf.j2
    dest: /etc/chrony.conf
    owner: root
    group: root
    mode: '0644'
  notify: Restart chronyd

- name: Ensure chronyd service is running and enabled
  ansible.builtin.systemd:
    name: chronyd
    state: started
    enabled: yes

handlers:
  - name: Restart chronyd
    ansible.builtin.systemd:
      name: chronyd
      state: restarted
      daemon_reload: yes
