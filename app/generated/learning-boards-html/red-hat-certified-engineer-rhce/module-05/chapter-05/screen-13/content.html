Scenario exercises
  1. Resolv.conf correct but dig fails: check firewall and DNS server reachability.
  2. chronyd running but no sync: check chrony.conf server entries and UDP 123 reachability.
  3. resolv.conf overwritten: prefer NetworkManager profile edits instead of direct file edits.
Practice question
If cat /etc/resolv.conf shows correct servers but dig fails, which of the following is most likely: firewall blocking UDP 53, chronyd not running, wrong file permissions on chrony.conf, or missing dns4_search in nmcli? The correct quick-check is firewall blocking UDP 53 or network reachability of DNS servers.
Answer with step-by-step checks: verify resolv.conf, run dig, inspect firewalld, then ping DNS servers to isolate the cause.
