Configuring DNS and NTP Services
Automate client DNS resolvers and chrony to keep your RHEL systems reachable and synchronized.
What you'll understand
How DNS and NTP affect services, how to declare DNS in NetworkManager profiles, how to deploy chrony with Ansible and verify synchronization.
How we'll practice
Hands-on playbook snippets and verification commands: cat resolv.conf, dig or host, chronyc sources and service checks.
In this lesson

Start with DNS automation using nmcli, then deploy chrony, verify services, and troubleshoot common issues like firewall blocks and incorrect server entries.
