Module 5 › Chapter 5.5 › Hands-on playbook walkthrough
Timeline: 5 steps
  1. Prepare templates and variables: chrony.conf.j2 and playbook variables for ntp_servers and connection_name.
  2. Apply DNS task with community.general.nmcli and install chrony.
  3. Deploy chrony.conf via ansible.builtin.template and notify a restart.
  4. Verify DNS with dig/host and resolv.conf; verify NTP with chronyc sources.
  5. Troubleshoot firewall, service status, and configuration errors as needed.
Playbook example reminder
ansible-playbook -i inventory.ini configure_dns_ntp.yml
Run against a single test host first, check registered outputs such as dig_output and chrony_status from the playbook to confirm success before wide deployment.
