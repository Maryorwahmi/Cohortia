Module 5 › Chapter 5.5 › Automate DNS with nmcli
Task structure
Declare variables, call community.general.nmcli with conn_name, dns4, and dns4_search. Optionally activate the connection to apply immediately.
Operational notes
  • Ensure connection_name matches an existing profile.
  • Verify resolv.conf and run host or dig to test resolution.
  • Consider firewall rules if queries still fail.
Key Takeaway

Bind DNS to a connection profile to make settings persistent and suitable for automation across many hosts.

Example task (YAML)
---
- name: Configure DNS resolvers for a network connection
  hosts: webservers
  become: yes

  vars:
    connection_name: System eth0
    dns_servers:
      - 192.168.1.1
      - 8.8.8.8
    dns_search_domains:
      - example.com

  tasks:
    - name: Set DNS servers for the specified connection
      community.general.nmcli:
        conn_name: "{{ connection_name }}"
        dns4: "{{ dns_servers }}"
        dns4_search: "{{ dns_search_domains }}"
        state: present
After running, check resolv.conf and use a DNS query tool. If resolution fails, inspect firewall and network path for UDP 53 traffic.
