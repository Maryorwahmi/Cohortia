DNS vs NTP: Symptoms and causes
DNS
Symptoms: name lookup fails, services can't resolve backends. Causes: wrong DNS IPs, firewall blocking UDP 53, missing search domains, transient edits to resolv.conf.
NTP
Symptoms: clock drift, authentication failures, chronyc shows no synced sources. Causes: incorrect server entries, chronyd not enabled, firewall blocking UDP 123.
Quick checks
  • Confirm connection profile DNS entries and resolv.conf.
  • Run dig/host for DNS checks and chronyc sources for NTP.
  • Inspect firewalld and network ACLs for UDP 53 and 123.
If you find the configuration correct but queries fail, escalate to packet captures and service logs to identify where packets are dropped or responses lost.
