Objective Evidence
DNS Automation
Connection profile shows dns4 entries and dns4_search. /etc/resolv.conf reflects these values after NetworkManager applies the profile.
Check: Run dig or host to confirm resolution for a known hostname.
Chrony Deployment
chrony package installed, template deployed to /etc/chrony.conf, notify handler restarts chronyd and service is enabled.
Check: Run chronyc sources and wait a few minutes for synchronization.
Common Pitfalls
  • Editing /etc/resolv.conf directly instead of configuring NetworkManager profiles.
  • Firewall blocking UDP port 53 or 123 prevents DNS or NTP queries.
  • Incorrect server or pool entries in chrony.conf cause no sync.
