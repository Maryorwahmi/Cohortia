Module 5 › Chapter 5.5 › chrony and NTP on RHEL
What is chrony?
chrony is an NTP implementation that synchronizes system clocks reliably, even on systems with intermittent network connectivity.
Configuration
Define server or pool directives in /etc/chrony.conf, for example pool 0.rhel.pool.ntp.org iburst, and deploy via ansible.builtin.template for consistency.
Verification
Run chronyc sources to confirm active NTP sources, and allow a few minutes after starting the service for synchronization to converge.
Troubleshooting
If chronyd runs but shows no sources, check chrony.conf entries and firewall rules blocking UDP 123.
chrony.conf template snippet
# Use public NTP servers from the pool project.
{% for server in ntp_servers %}
server {{ server }}
{% endfor %}

driftfile /var/lib/chrony/drift
rtcsync
logdir /var/log/chrony
Deploy this template with ansible.builtin.template, then notify a handler to restart chronyd so the new servers are used.
