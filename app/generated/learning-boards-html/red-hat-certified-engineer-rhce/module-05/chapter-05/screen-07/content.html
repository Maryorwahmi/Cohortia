Module 5 › Chapter 5.5 › Verify DNS Resolution
Verification Steps
  1. Run cat /etc/resolv.conf to confirm configured servers and search domains.
  2. Run dig +short google.com or host google.com to test resolution.
  3. If queries time out, check firewall rules for outgoing UDP port 53 and network ACLs.
  4. Ping the DNS server IPs to confirm reachability, or capture traffic to see whether queries leave the host.
Remember: a correct resolv.conf is only the first step. A successful DNS query proves the server is reachable and responding.
Example troubleshooting scenario
You applied a connection profile with two DNS servers and resolv.conf shows them, but dig fails. Next, inspect firewalld for blocked outgoing UDP 53. If firewalld allows, try pinging the DNS server. If ping works but dig still times out, capture packets to confirm DNS queries are sent and responses received.
Common mistake

Assuming resolv.conf equality equals functional DNS. Always run a DNS query to confirm end-to-end visibility.
