Module 5 › Chapter 5.5 › Key Concepts — Quick Reference
Persist DNS
Use community.general.nmcli to set dns4 and dns4_search on connection profiles instead of editing resolv.conf directly.
Template chrony
Deploy /etc/chrony.conf with ansible.builtin.template and notify a Restart chronyd handler when it changes.
Verify quickly
Run dig or host for DNS checks and chronyc sources for NTP. If config looks right but tests fail, check UDP 53 and 123 in firewall rules.
Closing prompt

When you next automate a host, which verification command will you run first and why? Use it to validate your automation immediately.
