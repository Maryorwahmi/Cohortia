Module 5 › Chapter 5.4 › Common mistakes & best practices
Common mistakes
  • Applying rules to the wrong zone because the interface wasn't assigned.
  • Forgetting permanent: yes so rules are lost after reboot.
  • Enabling broad services in public zones without restrictions.
Best practices
  • Open SSH only for controller IP before other changes.
  • Use rich rules for specific source restrictions.
  • Automate verification with Ansible command and debug tasks.
Key Takeaway

Plan changes, verify zones and runtime state, and automate verification to reduce accidental lockouts and insecure configurations.
