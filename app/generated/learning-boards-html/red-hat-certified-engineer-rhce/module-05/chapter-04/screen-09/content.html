Module 5 › Chapter 5.4 › Ensure firewalld service
Playbook snippet
- name: Ensure firewalld service is running and enabled
  ansible.builtin.systemd:
    name: firewalld
    state: started
    enabled: yes
Run this before any ansible.posix.firewalld tasks to ensure that runtime operations succeed and the service is persistent.
Safety tip

Open SSH access for your controller's IP before making bulk changes. This prevents accidental lockout if a later task restricts SSH.

Example SSH allow
- name: Allow SSH from controller subnet
  ansible.posix.firewalld:
    zone: public
    rich_rule: 'rule family="ipv4" source address="192.168.1.0/24" port port="22" protocol="tcp" accept'
    state: present
    permanent: yes
    immediate: yes
