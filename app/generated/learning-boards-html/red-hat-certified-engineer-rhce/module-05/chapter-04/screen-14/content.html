Module 5 › Chapter 5.4 › Lab: Step-by-step checklist
Checklist
  1. Inspect active zones and map interfaces to zones.
  2. Ensure firewalld is started and enabled.
  3. Open SSH from the controller IP with a rich rule as a safety net.
  4. Enable services and open ports with permanent and immediate when needed.
  5. Add rich rules for narrow source-based exceptions like ICMP or admin SSH.
  6. Verify runtime and permanent using firewall-cmd and perform connectivity tests.
Key Takeaway

Work in small steps, verify after each action, and keep an SSH recovery path open until you confirm connectivity.
