Module 5 › Chapter 5.4 › Verify firewall state
Ansible verification tasks
- name: Verify firewalld rules in the public zone
  ansible.builtin.command: "firewall-cmd --zone=public --list-all"
  register: firewall_status
  changed_when: false

- name: Display current firewalld public zone configuration
  ansible.builtin.debug:
    var: firewall_status.stdout_lines
Connectivity tests
  • SSH from administrative IP to confirm access.
  • Attempt access from an untrusted IP to confirm denial.
  • Validate application ports with a network client.
Key Takeaway

Automate verification steps in playbooks to ensure changes applied as intended and reduce surprises after deployment.
