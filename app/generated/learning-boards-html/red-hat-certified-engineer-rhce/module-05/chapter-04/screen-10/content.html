Module 5 › Chapter 5.4 › Enable services & ports
Playbook tasks
- name: Allow SSH service in the public zone
  ansible.posix.firewalld:
    zone: public
    service: ssh
    state: enabled
    permanent: yes
    immediate: yes

- name: Allow HTTP service in the public zone
  ansible.posix.firewalld:
    zone: public
    service: http
    state: enabled
    permanent: yes
    immediate: yes

- name: Open custom port 8080/tcp
  ansible.posix.firewalld:
    zone: public
    port: 8080/tcp
    state: enabled
    permanent: yes
    immediate: yes
Why this matters

Explicit declarations avoid drift and ensure that re-running the playbook keeps the firewall in the intended state. This supports reproducible deployments across many hosts.

Common mistake
Enabling services in the wrong zone or forgetting immediate, leading to unexpected lack of runtime exposure.
Key Takeaway

Use the module to declare services and ports. Verify with firewall-cmd after the play to confirm runtime and permanent states match.
