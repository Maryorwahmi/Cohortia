Module 5 › Chapter 5.4 › Key Concepts
Zones
Named policy sets applied to interfaces based on trust level.
Runtime vs Permanent
Runtime is immediate; permanent is persisted across reboots. Keep both aligned.
Ansible Automation
Use ansible.posix.firewalld with state, permanent, and immediate and include verification steps.
Summary
Design zones around trust, apply changes safely, automate declaratively, and verify runtime and persistent states after each change.
