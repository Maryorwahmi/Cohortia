Module 5 › Chapter 5.4 › firewall-cmd essentials
Commands
# Show active zones
firewall-cmd --get-active-zones

# Show full configuration for a zone
firewall-cmd --zone=public --list-all

# Permanently add http to public and apply immediately
firewall-cmd --zone=public --add-service=http --permanent
firewall-cmd --reload
Tip: adding without --permanent affects runtime only. Adding with --permanent writes the config but requires a reload to affect runtime unless you also add to runtime concurrently.
Example walkthrough

Run get-active-zones to confirm which zone is bound to your interface, then list-all for that zone to see services and ports. Make precise changes and verify after each step.

Common misconception
--permanent alone does not apply to the runtime. People expect permanent to be live immediately, but you must reload or use immediate options when automating.
Key Takeaway

Inspect before changing. Know whether you need runtime or permanent change, and verify after reloads.
