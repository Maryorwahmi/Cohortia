Module 6 › Chapter 5.6 › Learning Objectives
01
Leverage Ansible facts

Collect interface details and default route data automatically to avoid manual host inspection. This reduces time to identify misconfigured IPs or missing gateways across many hosts.

Mnemonic: Venn of interfaces + default route
VERIFIED COMPETENCY MILESTONE
02
Run diagnostic commands remotely

Execute ip, ss, ping, and traceroute via ansible.builtin.command or shell and capture their output. This lets you verify routes, ports, and reachability without manual SSH sessions.

Mnemonic: Timeline of command checks
VERIFIED COMPETENCY MILESTONE
03
Automate checks and scans

Compose playbooks that test connectivity and listening ports across hosts, producing consistent reports and reducing manual variance in troubleshooting.

Mnemonic: Checklist card with green ticks
VERIFIED COMPETENCY MILESTONE
04
Deploy tcpdump safely

Install and run tcpdump with specific filters via Ansible, fetch captures, and consider resource cost before running on production systems.

Mnemonic: Shield icon + filter funnel
