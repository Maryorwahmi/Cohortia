Core Concept

Ansible Facts for Network Introspection

Gather structured network data automatically with ansible.builtin.setup
What facts give you
  • Interfaces list with addresses, MACs, and state via ansible_facts.interfaces.
  • Primary route and gateway in ansible_facts.default_ipv4.
  • Structured resources under ansible_facts.network_resources for deeper inspection.
Example
ansible_facts.default_ipv4: { address: 10.0.1.5, gateway: 10.0.1.1 }
Common misconception
Assuming facts always reflect real-time changes; re-run setup or gather_facts when you change interfaces in the same playbook.
Key Takeaway

Use Ansible facts as your baseline for network state before running higher-impact diagnostics or changes.

Inspecting facts: quick checklist
Interfaces
List names, IPs, and state
Default IPv4
Primary IP and gateway
Network Resources
Structured view for advanced checks
Freshness
Re-run setup when you need current state
Practical step
- name: Gather network facts ansible.builtin.setup: gather_subset: '!all', 'network'
