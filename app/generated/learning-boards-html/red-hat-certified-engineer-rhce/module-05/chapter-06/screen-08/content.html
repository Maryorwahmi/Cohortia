Using tcpdump with Ansible

Deploy, run filtered captures, and fetch pcap files safely
Safe capture example
- name: Ensure tcpdump is installed
  ansible.builtin.package:
    name: tcpdump
    state: present

- name: Capture network traffic on eth0 for 10 seconds
  ansible.builtin.shell: "timeout 10 tcpdump -i eth0 -w /tmp/capture.pcap 'port 80' || true"
  args:
    creates: /tmp/capture.pcap
  register: tcpdump_capture
  changed_when: true
Use creates to avoid repeated captures and timeout to limit duration.
Fetch pattern
- name: Fetch the captured pcap file
  ansible.builtin.fetch:
    src: /tmp/capture.pcap
    dest: /tmp/ansible_captures/{{ inventory_hostname }}/
    flat: yes
  when: tcpdump_capture.rc == 0
Safety note
Filtered, timeboxed captures reduce resource use. Avoid running tcpdump without explicit filters in busy production environments.
Key Takeaway

Automate packet captures safely: install tcpdump, run with filters/timeouts, and fetch captures only when successful.
