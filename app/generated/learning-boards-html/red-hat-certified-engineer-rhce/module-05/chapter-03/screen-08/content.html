Module 5 › Chapter 5.3 › Adding Slave Interfaces
Looped slave tasks
- name: Add slave interfaces to the bond
  loop: "{{ slave_interfaces }}"
  community.general.nmcli:
    conn_name: "{{ item }}-slave"
    ifname: "{{ item }}"
    type: ethernet
    master: "{{ bond_name }}"
    state: present
    autoconnect: yes

Note the important master parameter; it ensures these connections act as slaves. Clean up old connections before this step to avoid residual IPs.

Cleanup example

Run a prior task that removes existing slave connections to avoid conflicts: loop the slave list with state: absent and ignore_errors for robustness in labs.

Misconfiguration to avoid
If slaves retain IPs, traffic will not flow through the master as intended. Always verify slaves show no IPs with ip a after configuration.
