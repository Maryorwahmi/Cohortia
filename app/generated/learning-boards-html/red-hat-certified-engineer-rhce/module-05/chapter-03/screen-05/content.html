Modes at a glance
balance-rr (mode=0)
Transmits packets in round-robin order across slaves for load distribution. Pros: potential higher throughput. Cons: possible out-of-order packets; depends on switch behavior.
active-backup (mode=1)
Only one slave active; another takes over upon failure. Pros: predictable failover and safe default. Cons: no bandwidth aggregation for active link.
802.3ad (mode=4)
Uses LACP to form aggregated groups with switch coordination. Pros: robust aggregation and redundancy. Cons: requires switch support and consistent link settings.
Practical checks and pitfalls
  • Verify switch supports LACP before enabling 802.3ad.
  • Use active-backup if you do not control the switch or need guaranteed failover.
  • Check for out-of-order packet sensitivity in applications before using balance-rr.
Misconfiguration example
Enabling 802.3ad on the host while the switch is unconfigured can leave all member links down or prevent aggregation. Always match host and switch settings.
