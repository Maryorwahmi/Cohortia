Module 5 › Chapter 5.3 › Lab: Active-Backup Bond
Step-by-step checklist
  1. Identify two unused NICs: run ip a and nmcli device status.
  2. Create playbook vars for bond_name, bond_mode=active-backup, slave_interfaces, bond_ip, bond_gw.
  3. Cleanup: loop slave_interfaces and remove existing connections with state: absent.
  4. Create bond master with community.general.nmcli and mode active-backup.
  5. Add slaves with master set and autoconnect: yes.
  6. Activate master and verify using /proc/net/bonding and ip commands.
Example check: After playbook, run ip -4 addr show dev bond0 to confirm the IP is on bond0.
Fallback: If network is lost, use console or IPMI to revert to previous network config.
