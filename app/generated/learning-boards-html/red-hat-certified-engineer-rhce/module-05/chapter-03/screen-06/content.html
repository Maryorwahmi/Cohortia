What teamd provides

Teamd runs in userspace and allows dynamic runner configuration, advanced link monitoring, and more extensible failure handling than kernel bonding modes in some cases.

Runner example: activebackup
Works like bonding's active-backup but can be adjusted at runtime and supports different health probes.
Operational note
Use teamdctl team0 state to inspect the team's view of links and current active port.
Analogy

Think of bonding as a kernel-enforced bundle and teaming as a programmable manager that supervises the bundle and can change its rules while running.

Pro Tip
Choose teaming to adjust link health checks or to update runner behavior without downtime in many cases.
