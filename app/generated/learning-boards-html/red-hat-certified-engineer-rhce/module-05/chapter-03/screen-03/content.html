Hands-on Check: Active-backup bond

Create a bond master that holds the IP and two slaves with master set. Run the playbook and confirm via ip a and /proc/net/bonding.

Mnemonic: Master holds the address — slaves are silent.

Safety check

Ensure console or IPMI access before applying network changes. Use verification commands via Ansible to detect failures quickly.

Mnemonic: Always keep a safety rope.

Cleanup step

Remove or reset existing connections for slave interfaces before adding them to a master to avoid conflicting IPs or autoconnect behavior.

Mnemonic: Clean slaves first.
