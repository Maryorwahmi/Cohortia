Module 5 › Chapter 5.3 › Verification Commands
Commands to run
  • cat /proc/net/bonding/bond0 — bonding details and active slave.
  • teamdctl team0 state — teamd's runtime port state and runner details.
  • ip -4 addr show dev bond0 — confirms IP on master.
Interpreting output

If /proc/net/bonding shows a different active slave than expected, check physical link LEDs and switch port statuses. If slaves still have IPs, you likely didn't remove their original connections. Use these outputs to guide automated remediation before critical changes.

Misconception
Seeing a connection listed by nmcli doesn't guarantee the link is operational. Cross-check with ip and /proc or teamdctl for runtime health.
