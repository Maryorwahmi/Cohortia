Module 5 › Chapter 5.3 › Learning Objectives
01 Explain bonding vs teaming
Describe core concepts and practical use cases.

You will articulate differences such as kernel-managed bonding versus teamd-managed teaming, and when each fits operational needs. A clear mental model helps you choose the simpler bonding for predictable behavior, or teaming for runtime flexibility.

VERIFIED COMPETENCY MILESTONE
02 Identify bonding modes
Understand active-backup, balance-rr, and 802.3ad.

You will name the implications of each mode, for example the safety of active-backup versus the throughput benefits and switch dependencies of 802.3ad. Knowing these trade-offs prevents outages caused by incompatible switch settings.

VERIFIED COMPETENCY MILESTONE
03 Automate with Ansible
Use community.general.nmcli to create masters and slaves.

You will author tasks that create a bond or team master, set mode or runner, and then add slave interfaces in a loop. Automation reduces human error and ensures consistent outcomes across servers.

VERIFIED COMPETENCY MILESTONE
04 Verify and recover safely
Use verification commands and plan for fallback access.

You will verify with commands like checking /proc/net/bonding or teamdctl, and understand the need for console access or IPMI before making network changes to avoid lockouts.
