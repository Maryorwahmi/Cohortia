What 'Performance-Based' Means
Demonstrate tasks by doing them in a live RHEL environment.
Definition
Complete practical objectives in a live system where the outcome is verified by the grader.
Example Task
Install and enable a web server across host group
You must configure packages, services, firewall rules, and verify accessibility on the required port.
Misconception
Memorization is enough
In practice, automation, verification, and problem solving are what determine success.
Key Takeaway

Treat each exam task as a small automation project: plan, execute, and verify the desired state with Ansible.

Practical Preparation
  • Practice entire tasks end-to-end in your lab rather than isolated commands.
  • Use playbooks to make changes reproducible and idempotent.
  • Validate outcomes with checks: service status, ports, file contents, and permissions.
  • Time-box practice runs to build both speed and accuracy.
