Frequent Mistakes
Identify and prevent common point-losing errors.
Misreading Requirements
Always rewrite key constraints into a checklist to avoid missing small but critical details.
YAML & Indentation
Validate YAML structure before executing playbooks to prevent parser or logic errors.
Privilege Escalation
Include become: yes when tasks require root-level actions like package installation or service control.
Pre-flight Checklist
  • Read the task and list exact requirements: ports, users, permissions.
  • Validate SSH connectivity and sudo permissions for the user you will use.
  • Lint and sanity-check YAML, and prefer modules to shell commands.
  • Run verification checks immediately after changes.
Common Consequence

Small oversights can cost you points despite correct intent; adopt preventive checks to protect your score.
