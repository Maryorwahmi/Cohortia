Activity: RHCE Study Plan & Lab Setup
A stepwise exercise to build and measure your readiness.
  1. Review official objectives and list the five weakest areas.
  2. Design and provision two VMs: control node and managed node with RHEL 8 or 9.
  3. Configure SSH keys and create a sudo-enabled non-root user on the managed node.
  4. Implement and time a playbook for one objective, then verify results.
  5. Reflect: note recurring errors and plan a targeted practice session.
Example: Create a User Playbook
---
- name: Create deploy user
  hosts: all
  become: yes
  tasks:
    - name: Ensure deploy user exists
      ansible.builtin.user:
        name: deploy
        groups: deploygroup
        state: present
    - name: Ensure home directory has correct permissions
      ansible.builtin.file:
        path: /home/deploy
        owner: deploy
        mode: '0750'
Verification
  • Check user exists and belongs to the correct group.
  • Confirm home directory ownership and permission bits match the requirement.
