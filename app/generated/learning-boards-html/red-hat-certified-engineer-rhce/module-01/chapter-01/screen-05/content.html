Control Node vs Managed Node
Roles, SSH, and inventories that make automation possible.
Control Node
Runs Ansible, stores playbooks, and initiates SSH connections to targets.
Managed Node
Receives tasks over SSH; no agent needed if SSH and Python are present.
Example
Install web package on a host group
Create an inventory group webservers and run a play targeting that group to install and start the service.
Connectivity & Verification
Before making changes, verify SSH access and group membership.
Checklist
  • SSH keys exchanged for passwordless login from control to managed nodes.
  • Non-root user with sudo is present on managed nodes.
  • Inventory groups map cleanly to your VM topology.
  • Run a simple ping to confirm connectivity before making changes.
Key Takeaway

Reliable SSH and clear inventories are prerequisites for predictable automation and exam success.
