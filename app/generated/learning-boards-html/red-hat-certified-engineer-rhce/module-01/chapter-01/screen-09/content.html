Minimal Lab Plan
Steps to create a reproducible test environment for practice.
  1. Provision two VMs with RHEL 8 or 9: one control node and one managed node.
  2. Install Ansible on the control node and create a project directory for playbooks.
  3. Create a non-root user on both machines and grant sudo on the managed node.
  4. Exchange SSH keys to enable passwordless authentication from the control node.
  5. Verify connectivity and run a simple ping or a module check.
Command Callouts
Sample commands and verification patterns for lab setup.
# On control node: generate key and copy to managed node
ssh-keygen -t rsa -b 2048 -f ~/.ssh/id_rsa
ssh-copy-id user@managed-node

# Verify passwordless SSH
ssh user@managed-node 'echo OK'

# Run a simple Ansible ping from control node
ansible all -i inventory.ini -m ansible.builtin.ping -u user --become
Watchouts
  • Check .ssh directory and authorized_keys permissions; too-permissive or too-restrictive permissions can prevent key auth.
  • Ensure the sudoers entry allows the non-root user to run required tasks with become.
