SSH Setup Steps
Commands and file checks to secure passwordless access.
# Generate key on control node
ssh-keygen -t rsa -b 2048 -f ~/.ssh/id_rsa

# Copy public key to managed node
ssh-copy-id user@managed-node

# Verify SSH connection
ssh user@managed-node 'echo connection-ok'

# Verbose debug
ssh -vvv user@managed-node
Troubleshooting Checklist
  • Confirm the public key is present in managed node ~/.ssh/authorized_keys for the intended user.
  • Ensure ~/.ssh has 700 and authorized_keys has 600 permissions.
  • Use ssh -vvv to inspect which keys are offered and why authentication fails.
Common Mistake

Copying the key to the wrong user or wrong home directory is a frequent cause of failures. Double-check user names and paths.
