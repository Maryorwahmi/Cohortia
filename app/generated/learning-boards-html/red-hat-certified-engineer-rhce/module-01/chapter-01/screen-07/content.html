YAML Syntax Essentials
Common sources of playbook failures and how to prevent them.
Best practices
  • Use two-space indentation consistently and never use tabs.
  • Always include hosts: and necessary become: yes where privileged tasks are required.
  • Validate YAML with a linter before running on managed nodes.
Misconception
Formatting is cosmetic
Formatting mistakes are functional errors in YAML; they can prevent a playbook from running or produce unexpected behavior.
Code Walkthrough
---
- name: Install and start httpd
  hosts: webservers
  become: yes
  tasks:
    - name: Ensure httpd is installed
      ansible.builtin.yum:
        name: httpd
        state: present
    - name: Ensure httpd is started
      ansible.builtin.service:
        name: httpd
        state: started
Checklist
  • Confirm indentation aligns module arguments under the module name.
  • Use the correct module name for your RHEL version (for example, dnf or yum variation may be tested).
  • Validate before running and run with increased verbosity when troubleshooting.
