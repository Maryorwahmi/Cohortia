Module 1 › Chapter 1.2 › Key Concepts
Agentless
No special agents on managed nodes; uses SSH or native protocols.
Control Node
Where Ansible runs and orchestrates tasks.
Inventory
A file listing hosts and variables to target automation runs.
Summary
These three concepts are the foundation for using Ansible: how it connects, where it runs, and what it manages. Keep your inventory accurate and test connectivity before automating.
