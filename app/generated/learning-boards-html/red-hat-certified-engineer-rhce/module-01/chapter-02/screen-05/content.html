Roles
Control node vs Managed node
  • Control node: runs Ansible, stores inventory and playbooks.
  • Managed nodes: targets where modules execute over SSH or platform-specific protocols.
  • Control node gathers output and reports status back to the operator.
Concrete example
Imagine a control node with an inventory listing three web servers and two database servers. When you request a package update, the control node opens SSH to each managed node, runs the package module there, and collects success or failure results. You do not install Ansible on those managed nodes.
Pro tip
Keep the inventory and any key files for the control node under version control so team members reproduce the environment.
Key Takeaway

The control node orchestrates actions and should have network connectivity and credentials to managed nodes; managed nodes need only standard remote access configured.
