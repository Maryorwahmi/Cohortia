What an inventory contains
  • Groups that logically collect hosts.
  • Host identifiers: hostnames or IP addresses.
  • Group or global variables such as SSH user or private key path.
Common formats: INI for static lists, YAML or dynamic scripts for more advanced environments.
Example inventory (INI)
# ~/my_inventory.ini
[webservers]
web1.example.com
web2.example.com

[databases]
db1.example.com
db2.example.com

[all:vars]
ansible_user=devops
ansible_ssh_private_key_file=/home/devops/.ssh/id_rsa
Replace hostnames and paths with your environment values when you test connectivity.
Common mistake
Incorrect hostname, wrong SSH user, or wrong key path are the most frequent causes of failed connections from the control node.
Key Takeaway

Keep inventories accurate and versioned; test each host with a connectivity check before running larger automation jobs.
