Module 1 › Chapter 1.2 › Lab Activity
Activity checklist
  1. Install Ansible using the package manager with elevated privileges.
  2. Run the Ansible version check to confirm installation.
  3. Create ~/my_inventory.ini with a servers group and the managed node entry.
  4. Run a connectivity check using the ping module against the servers group.
  5. Run a simple command module to get hostname or uptime from the managed node.
Inventory example
[servers]
your_managed_node_ip ansible_user=your_ssh_username ansible_ssh_private_key_file=/home/your_ssh_username/.ssh/id_rsa
Ad-hoc examples
ansible servers -i ~/my_inventory.ini -m ping
ansible servers -i ~/my_inventory.ini -m command -a "uptime"
Key Takeaway

Complete the checklist to ensure your control node can reach managed nodes; this foundation prevents common playbook failures later.
