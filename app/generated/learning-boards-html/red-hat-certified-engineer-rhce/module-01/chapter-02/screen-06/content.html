Module 1 › Chapter 1.2 › Installing Ansible
Step-by-step
  1. Confirm your RHEL subscription and repository access.
  2. Use the package manager to install the ansible package from AppStream.
  3. Run the Ansible version check to confirm the install and paths.
Verification
The version output confirms executable location, Python runtime, and default configuration search paths.
Terminal demo panel
# Example commands shown for reference in the UI
sudo dnf install ansible -y
ansible --version
Note: Run commands on the control node with appropriate privileges and confirm repository access first.
Key Takeaway

Install via the RHEL package manager and always confirm the installation with a version check before proceeding to inventory configuration.
