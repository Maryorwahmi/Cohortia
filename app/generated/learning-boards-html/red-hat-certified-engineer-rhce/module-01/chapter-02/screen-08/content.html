Module 1 › Chapter 1.2 › Creating a Basic INI Inventory
Template
# ~/my_inventory.ini
[servers]
your_managed_node_ip ansible_user=your_ssh_username ansible_ssh_private_key_file=/home/your_ssh_username/.ssh/id_rsa
Replace placeholders with your managed node IP and SSH user. Keep permissions on the key file correct.
Checklist
  • File path is accessible to the control node user.
  • Hostnames or IPs are correct and resolvable.
  • SSH key paths point to readable private keys.
Try this
Create the file in your home directory and run a connectivity check to validate that the control node can reach the managed node using the provided credentials.
Key Takeaway

A minimal INI inventory is an easy, versionable way to declare targets and credentials for your control node to use during ad-hoc checks and later playbook runs.
