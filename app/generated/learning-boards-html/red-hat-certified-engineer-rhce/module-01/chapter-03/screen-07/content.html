Only restart services when needed

Handlers run when tasks notify them, ensuring actions like service restarts happen only after real changes.

Process
Task runs and reports whether it changed a resource. If changed and it includes a notify directive, a handler is queued.
Handlers run after the task list completes for that play. They are idempotent tasks in their own right; a handler should use a module like service with the desired state.
Concrete example
- name: Ensure Nginx configuration file is present
  ansible.builtin.copy:
    src: files/nginx.conf
    dest: /etc/nginx/nginx.conf
  notify: restart nginx

handlers:
  - name: restart nginx
    ansible.builtin.service:
      name: nginx
      state: restarted
The copy task only triggers the handler when it makes a change. Run the playbook twice to observe the handler running only once.
Key Takeaway

Handlers minimize disruption by running only when notified; use them for restarts, reloads, and finalization steps.
