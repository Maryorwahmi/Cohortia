Avoid parsing and parameter errors

Use consistent spaces, validate YAML, and check module docs to resolve errors quickly.

Quick checklist
  • Use spaces not tabs and keep indentation consistent.
  • Ensure module parameters are nested under the module name.
  • Quote file modes and other ambiguous values as strings.
  • Install required collections for non-core modules.
Debugging steps
  1. Read the parser error and note the indicated line number.
  2. Open the playbook and check indentation around that line.
  3. Confirm module parameter names using module documentation.
  4. Run with increased verbosity to see where execution stops.
Example fix

If a copy task shows a parser error because mode is unquoted, change mode: 0644 to mode: '0644' to avoid numeric interpretation issues.
