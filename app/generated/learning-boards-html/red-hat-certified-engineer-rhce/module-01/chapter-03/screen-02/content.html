Learning Objectives

Progress through practical milestones that let you author, run, and debug basic automation safely.

01 Explain playbooks
Describe playbook structure and why plays, tasks, and handlers exist. This helps you design predictable workflows and share recipes with team members.
Verified Competency Milestone
02 Use modules
Identify modules like the package, service, and copy modules and use them to perform system tasks reliably across hosts.
Verified Competency Milestone
03 Write a playbook
Compose a simple playbook that installs packages, manages services, and uses handlers. This converts understanding into repeatable actions.
Verified Competency Milestone
04 Debug & idempotency
Recognize YAML indentation errors and incorrect module parameters, and reason about idempotency to avoid unintended changes.
Verified Competency Milestone
Learning Map

Follow these four objectives in sequence: explain structure, learn modules, author a playbook, then run and debug it in a test environment.
