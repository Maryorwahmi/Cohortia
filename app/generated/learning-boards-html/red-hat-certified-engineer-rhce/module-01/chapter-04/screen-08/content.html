Precedence Example
Consider these definitions:
  • [all:vars] max_connections: 50
  • group_vars/webservers.yml max_connections: 100
  • host_vars/server1.example.com.yml max_connections: 200

Effective value for server1.example.com is 200 because host_vars take precedence over group and global vars.

Practical debugging

If a variable does not behave as expected, use inventory inspection and a debug play to print the resolved value. Extra vars passed on the command line can also override other sources, so include them in your checks.

Misconception

Believing group_vars always apply. In reality, more specific definitions — host_vars or command-line extra vars — take precedence.

Key Takeaway

Always check the specific scope where a variable is defined when results differ; specificity overrides broader defaults.
