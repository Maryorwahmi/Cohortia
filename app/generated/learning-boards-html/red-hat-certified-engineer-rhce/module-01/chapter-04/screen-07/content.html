Module 2 › Chapter 1.4 › Host & Group Variables
Variable Locations
  • Inventory file inline or under group:vars / all:vars.
  • inventory_dir/group_vars/groupname.yml
  • inventory_dir/host_vars/hostname.yml
Example files
# group_vars/webservers.yml
---
http_port: 80
welcome_message: "Welcome to our web server!"

# host_vars/db1.example.com.yml
---
db_name: main_database
welcome_message: "Welcome to the database server!"
Behavior & Tips
  • Host variables override group or global variables for that host.
  • Keep variable files under inventory_dir so Ansible loads them automatically.
  • Use descriptive names and comments to avoid confusion during troubleshooting.
Pro tip

When testing precedence, use a display_vars playbook to print values and confirm which source provided each variable.

Key Takeaway

Group vars set defaults for many hosts; host vars are for specific overrides — organize them near the inventory for clarity.
