Module 2 › Chapter 1.4 › Inspect Variables
Inventory inspection
ansible-inventory -i my_advanced_inventory.ini --list
ansible-inventory -i ~/ansible_projects/aws_ec2.yml --list
Use --list to get JSON-like structure that reveals groups and variables generated by plugins or files.
Debug playbook

Run a small playbook that prints inventory_hostname and variables of interest to confirm what Ansible will use during a run.

Workflow tip

Always inspect inventory after edits and before running larger playbooks. This reduces surprises and speeds troubleshooting.

Key Takeaway

Confirm both the inventory structure and the resolved runtime values — together they show the exact state Ansible will use.
