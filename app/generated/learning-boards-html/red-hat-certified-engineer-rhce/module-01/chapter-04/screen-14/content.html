Credential safety
  • Avoid hardcoding API keys in inventory files.
  • Use environment variables, SDK credential chains, or a secrets store.
  • Keep inventory config out of version control when it references secrets.
Filter and group carefully

Filter on instance-state-name: running to avoid terminated instances and use keyed_groups to group by tags so playbooks target intended hosts.

Reflection

Consider how you will deliver credentials at runtime so inventory plugins can authenticate without leaving secrets in files or logs.
