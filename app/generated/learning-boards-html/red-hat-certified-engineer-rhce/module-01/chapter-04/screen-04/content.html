Module 2 › Chapter 1.4 › What is an Inventory?
Definition

Inventory as directory and profile

An inventory lists hosts, organizes them into groups, and attaches variables so playbooks know how to connect and what values to use.

Key points
  • Hosts are grouped logically for batch operations.
  • Variables may be attached at host, group, or global scope.
  • Static inventory is manual; dynamic inventory is generated at runtime.
Key Takeaway

Inventory determines both which hosts are managed and the configuration context used by playbooks.

Analogy & Example

Analogy: a phonebook where each entry also stores preferences for how to call. Example scenario: one host requires a nondefault SSH port; this is stored as a host variable so playbooks connect correctly.

Common mistake

Assuming inventory is only hostnames. Missing variables or wrong file locations often cause connection or configuration errors.

Check your understanding

If a host has a host_vars file that sets a value and the inventory all:vars sets another, which wins? (Answer: host_vars.)
