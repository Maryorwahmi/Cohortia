Module 2 › Chapter 1.4 › Key Concepts
Static Inventory
Manually created INI or YAML files that list hosts and variables.
Variable Precedence
Host variables override group and global variables; inspect resolved values when unsure.
Dynamic Inventory
Plugins query external sources and build an up-to-date inventory grouped by metadata.
Summary

Choose INI for quick lists, YAML for structured data. Use group_vars for defaults, host_vars for overrides, and verify with ansible-inventory and a debug playbook. Use dynamic inventory for cloud environments but protect credentials.
