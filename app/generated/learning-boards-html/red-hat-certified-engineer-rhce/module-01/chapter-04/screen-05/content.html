INI Example
# INI format example: /etc/ansible/hosts
[webservers]
web1.example.com
web2.example.com

[databases]
db1.example.com ansible_port=2222
db2.example.com

[all:vars]
ansible_user=devops
ansible_ssh_private_key_file=/home/devops/.ssh/id_rsa
Note the inline host variable for db1.example.com. It overrides broader port settings.
Walkthrough & Tips
  • Brackets denote groups. Use [groupname:vars] for group-scoped variables.
  • Inline host variables set connection parameters per host.
  • INI is less suitable for nested complex data types.
Common mistake

Forgetting that a host_vars file will override inline host variables can lead to confusion; verify with inventory inspection commands when unsure.

Key Takeaway

INI works well for simple static lists and explicit inline host variables; use YAML when you need structure.
