Module 2 › Chapter 1.4 › aws_ec2 Plugin
Plugin config example
# ~/ansible_projects/aws_ec2.yml
plugin: aws_ec2
regions:
  - us-east-1
filters:
  instance-state-name: running
keyed_groups:
  - key: tags.Environment
    prefix: env_
  - key: tags.Role
    prefix: role_
This config instructs the aws_ec2 plugin to return running instances in us-east-1 and create groups based on tags.
How to use

Run: ansible-playbook -i ~/ansible_projects/aws_ec2.yml playbook.yml. Or inspect generated inventory with: ansible-inventory -i ~/ansible_projects/aws_ec2.yml --list

Security reminder

Avoid placing credentials in this file. Use environment credentials or a secure credential provider for the plugin to use at runtime.

Key Takeaway

Inventory plugins create live inventories from external sources and can group hosts by metadata like tags for targeted automation.
