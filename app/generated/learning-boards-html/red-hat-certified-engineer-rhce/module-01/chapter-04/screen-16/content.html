Module 2 › Chapter 1.4 › What to Remember
INI vs YAML
INI is compact; YAML is structured for nested variables.
Variable Scope
Host > Group > All. Use host_vars for per-host overrides.
Dynamic Plugins
Use plugins to query external sources and group hosts by metadata; secure credentials carefully.
Final Tip

Adopt a create-inspect-verify workflow: write inventory, inspect with ansible-inventory, then verify runtime values with a debug playbook.
