Module 2 › Chapter 1.4 › display_vars Playbook
Playbook content
---
- name: Display host and group variables
  hosts: all
  tasks:
    - name: Print variables
      ansible.builtin.debug:
        msg: |
          Hostname: {{ inventory_hostname }}
          Ansible User: {{ ansible_user }}
          Default Message: {{ default_message }}
          HTTP Port (if webserver): {{ http_port | default('N/A') }}
          DB Name (if database): {{ db_name | default('N/A') }}
          Welcome Message: {{ welcome_message }}
Note the use of default filters so missing values display as N/A rather than causing an error.
Run & Observe
Execute: ansible-playbook -i my_advanced_inventory.ini display_vars.yml and compare output for each host to the file definitions. Look for where welcome_message differs to see host override.
Common mistake

Expecting files to match runtime values without running the playbook. Always verify with a live run when troubleshooting precedence.

Key Takeaway

A debug playbook is a lightweight, reliable way to inspect resolved variables and confirm inventory behavior.
