Module 2 › Chapter 1.4 › Learning Objectives
01
Configure static inventories

Create INI or YAML inventory files and understand when each format is appropriate. Verified competency milestone: you can write both formats and run a playbook against them.

Mnemonic: file icons with brackets for INI, nested tree for YAML
VERIFIED COMPETENCY MILESTONE
02
Define host and group variables

Place host_vars and group_vars to customize behavior. Verified competency milestone: a playbook uses both group and host variables to produce different outputs for two hosts.

Mnemonic: Venn overlap showing host inside group
VERIFIED COMPETENCY MILESTONE
03
Understand variable precedence

Learn the resolution order and how host-level variables override group or all:vars. Verified competency milestone: predict effective value from conflicting definitions.

Mnemonic: layered stack with host on top
VERIFIED COMPETENCY MILESTONE
04
Explain and use dynamic inventory

Describe benefits and configure a basic plugin or script such as an aws_ec2 inventory file. Verified competency milestone: run ansible-playbook with a plugin-based inventory and observe generated groups.

Mnemonic: cloud node with arrows returning inventory
VERIFIED COMPETENCY MILESTONE
