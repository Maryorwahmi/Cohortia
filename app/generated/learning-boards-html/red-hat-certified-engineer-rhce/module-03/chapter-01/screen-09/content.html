A step-by-step troubleshooting flow

Follow these steps when a service task fails to identify and fix the root cause.

1. Confirm service name
Use systemctl list-unit-files --type=service to avoid typos.
2. Check package/unit presence
Ensure the package is installed and the unit file exists on the host.
3. Inspect logs
Run journalctl -xeu <service> to see why systemd failed the unit.
4. Reload and retry
If you changed unit files, run systemctl daemon-reload then re-run the Ansible task.
Scenario
Ansible fails to start nginx after a deploy. You check unit names, confirm the package installed, then run journalctl -xeu nginx and see a configuration syntax error. Fix the config, reload or restart the service, and re-run the playbook.
Pro tip: include logging commands in your runbook so others can reproduce your troubleshooting steps.
