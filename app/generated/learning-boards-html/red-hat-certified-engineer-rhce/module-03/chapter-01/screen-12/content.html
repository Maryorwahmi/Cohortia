Starter playbook template

Use this template as the basis for the lab. Save as manage_web_services.yml and run against your webservers inventory group.

---
- name: Configure Web Services
  hosts: webservers # Assuming you have a 'webservers' group in your inventory
  become: yes

  tasks:
    - name: Ensure nginx package is installed
      ansible.builtin.dnf:
        name: nginx
        state: present

    - name: Ensure nginx service is started and enabled
      ansible.builtin.service:
        name: nginx
        state: started
        enabled: yes

    - name: Ensure firewalld service is started and enabled
      ansible.builtin.service:
        name: firewalld
        state: started
        enabled: yes

    - name: Restart nginx service
      ansible.builtin.service:
        name: nginx
        state: restarted
Run: ansible-playbook manage_web_services.yml Observe changed status and then verify with systemctl status nginx and systemctl status firewalld on a target host.
Verification checklist
  • systemctl status nginx
  • systemctl status firewalld
  • systemctl list-unit-files --type=service | grep nginx
If a service fails, inspect journalctl -xeu <service> and correct configuration or dependencies before re-running the playbook.
