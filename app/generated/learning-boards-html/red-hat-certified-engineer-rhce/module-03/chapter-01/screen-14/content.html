Module 3 › Chapter 3.1 › Key Concepts
systemd

Service manager on RHEL that executes unit behavior; Ansible drives it by declaring states.

ansible.builtin.service

Declare name, state, and enabled so Ansible can ensure the service reaches the desired operating condition.

Idempotency & safety

Run playbooks repeatedly without unintended side effects; test in staging, use check mode, and verify health.

Takeaway

Combine correct service names, explicit package installs, enabled flags, and verification to create dependable automation.
