Module 4 › Chapter 3.5 › Assessment
Assessment question
Create devops group and devops_user with a home directory, /bin/bash shell, and add their public SSH key without storing password in plain text. Use Ansible modules and verify the result.
Correct tasks (fragments)
- name: Create 'devops' group
  ansible.builtin.group:
    name: devops
    state: present

- name: Create 'devops_user' with home directory and shell
  ansible.builtin.user:
    name: devops_user
    state: present
    shell: /bin/bash
    home: /home/devops_user
    groups: devops
    append: yes
    # password: "{{ 'your_hashed_password_here' | password_hash('sha512') }}"

- name: Add SSH public key for devops_user
  ansible.builtin.authorized_key:
    user: devops_user
    state: present
    key: "ssh-rsa AAAAB3NzaC... devops_user@workstation"
Verification
  • id devops_user
  • getent group devops
  • cat /home/devops_user/.ssh/authorized_keys
Key Takeaway
When answering the assessment, demonstrate verification steps as part of your solution.
