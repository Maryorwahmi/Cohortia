Module 4 › Chapter 3.5 › Removing users safely
Comparison
state: absent
Removes the user account record but leaves home directory and files. Use this when you want to disable an account but preserve data.
state: absent + remove: yes
Removes account and deletes home directory and mail spool. This is destructive and irreversible without backups.
Safe workflow
  1. Backup important data owned by the user.
  2. Disable login (e.g., set shell to /sbin/nologin).
  3. Confirm no running processes or critical file ownership.
  4. Run state: absent, verify, then remove: yes if needed.
Warning

Deleting a user's home directory is irreversible. Always confirm backups and ownership before using remove: yes.
