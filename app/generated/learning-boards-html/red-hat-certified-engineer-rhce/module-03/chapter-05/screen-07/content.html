Module 4 › Chapter 3.5 › Sudo rules and validation
Example task with validate
- name: Grant 'developers' group NOPASSWD sudo access
  ansible.builtin.copy:
    content: '%developers ALL=(ALL) NOPASSWD: ALL'
    dest: /etc/sudoers.d/developers
    owner: root
    group: root
    mode: '0440'
    validate: /usr/sbin/visudo -cf %s
Concrete check: After the copy task, run sudo -l as the user or sudo whoami to confirm privileges.
Common error: forgetting validate; a syntax error can break sudo for all users.
Safety checklist
  • Use validate with visudo.
  • Use mode 0440 and owner root:root.
  • Prefer group-based rules for manageability.
Pro Tip

Keep sudoers files small and well-commented. Validate locally before automating the deployment.
