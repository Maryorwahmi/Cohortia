Module 4 › Chapter 3.5 › Common mistakes
Frequent issues
  • Storing plain-text passwords instead of using hashed values and Vault.
  • Omitting append when adding supplementary groups.
  • Malformed SSH keys or incorrect permissions on .ssh directories.
  • Not validating sudoers files before writing them.
  • Using remove: yes without backups or verification.
Prevention checklist
Vault for secrets, append for groups, authorized_key for keys, validate for sudoers, test inventories for removals.
Pro Tip
Create a small CI job that runs your playbook against a disposable VM and runs id and getent checks to catch regressions early.
