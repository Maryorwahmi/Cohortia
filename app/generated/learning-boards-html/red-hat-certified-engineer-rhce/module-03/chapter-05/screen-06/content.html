Module 4 › Chapter 3.5 › SSH key deployment
Example task
- name: Add SSH public key for ansible_admin
  ansible.builtin.authorized_key:
    user: ansible_admin
    state: present
    key: "ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAACAQDQ... ansible_admin@control"
Concrete check: After running, confirm the key is present with cat /home/ansible_admin/.ssh/authorized_keys and then attempt ssh authentication from the key owner host.
Common mistake: multi-line or wrapped keys. Keep the public key as a single line and verify no extra whitespace.
Permissions to check
  • ~/.ssh directory should be 700
  • ~/.ssh/authorized_keys should be 600 or 644 depending on policy
  • Owner must be the user, not root
Key Takeaway

authorized_key provides idempotent, auditable SSH key management. Always verify key format and permissions after deployment.
