Module 4 › Chapter 3.5 › Ansible group & user modules
ansible.builtin.group
Use name and state to ensure groups exist or are removed. Set gid when you need a numeric Group ID.
ansible.builtin.user
Manage the entire account: uid, primary group, supplementary groups, home, shell, and hashed password. Use append to preserve other memberships.
Common mistake: forgetting append when adding supplementary groups; this will remove existing memberships.
Example: create jdoe
- name: Create user 'jdoe'
  ansible.builtin.user:
    name: jdoe
    state: present
    shell: /bin/bash
    home: /home/jdoe
    group: developers
    groups: developers,sudo
    append: yes
    password: "{{ 'your_hashed_password_here' | password_hash('sha512') }}"
Key Takeaway
Know each parameter's effect before applying tasks to production systems.
