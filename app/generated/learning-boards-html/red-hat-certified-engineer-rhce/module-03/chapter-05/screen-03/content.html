Practice steps and verification
Group verification
Create group with gid and check: getent group <groupname> to confirm the GID and membership.
User verification
Use id <username> and ls -ld /home/<user> to verify UID, groups, shell, and home directory ownership.
SSH key test
After authorized_key deploy, attempt an SSH connection from the key holder to validate passwordless access and permissions.
Sudo validation
Include validate: /usr/sbin/visudo -cf %s with copy tasks so files only deploy if syntax is correct.
Quick checklist
  • Always test playbooks in non-production.
  • Use Ansible Vault for hashed passwords in production.
  • Validate sudoers files to avoid lockouts.
