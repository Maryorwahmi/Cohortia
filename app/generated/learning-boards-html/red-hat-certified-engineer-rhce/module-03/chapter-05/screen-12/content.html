Module 4 › Chapter 3.5 › Lab: Create ops_team & ansible_admin
Lab steps
  1. Ensure group: ansible.builtin.group with name ops_team and gid 3000.
  2. Create user ansible_admin with uid 3001, shell /bin/bash, home /home/ansible_admin, primary group ops_team.
  3. Add provided SSH public key with ansible.builtin.authorized_key.
  4. Grant NOPASSWD sudo by copying a file into /etc/sudoers.d and validating with visudo.
Verification: id ansible_admin, getent group ops_team, and ssh to test the key and sudo whoami to confirm privileges.
Starter checklist
  • Run playbook against a test inventory.
  • Inspect /home/ansible_admin/.ssh/authorized_keys for the key.
  • Confirm sudoers file mode 0440 and owner root.
