User and Group Management with Ansible
Automate account lifecycle, SSH keys, and sudo rules safely and idempotently.
In this lesson
Manage groups and users, deploy SSH keys, and create validated sudo rules. Follow safety best practices for passwords and deletions.

Explore Key Topics
Groups
Use ansible.builtin.group to ensure presence or absence and set specific GIDs for consistent group IDs.
Users
Use ansible.builtin.user to set UID, home, shell, supplementary groups, and hashed passwords stored with Ansible Vault.
Sudo & SSH
Manage authorized_keys with ansible.builtin.authorized_key and place sudo rules in /etc/sudoers.d validated by visudo.
