Module 3 › Chapter 3.2 › Troubleshooting
Checklist
  1. Confirm exact package name with dnf list available or dnf info.
  2. Ensure .repo file exists in /etc/yum.repos.d and is correct.
  3. Verify network connectivity to the repository base URL.
  4. Check that the repository GPG key is imported or configured.
Diagnostic commands
# On the target host
sudo dnf list available 
sudo dnf info 
# Check installed packages
sudo dnf list installed
Increase Ansible verbosity to inspect dnf module output and use check mode to verify intended changes without applying them.
