Module 3 › Chapter 3.2 › Learning Objectives
01
Handle GPG key verification
Import repository GPG keys or configure gpgkey and gpgcheck so packages are verified. Avoid disabling checks in production; it risks installing untrusted packages.
Mnemonic: key first, install second
VERIFIED COMPETENCY MILESTONE
02
Use check mode for dry runs
Run playbooks with a dry run to preview changes. This helps avoid surprises when updating many hosts at once and is a simple test before production runs.
Mnemonic: preview before change
VERIFIED COMPETENCY MILESTONE
03
Enable repos per task
Use enablerepo on individual tasks to avoid enabling third-party repositories globally unless you intend to keep them available.
Mnemonic: enable only when needed
VERIFIED COMPETENCY MILESTONE
04
Adopt staging and reboot planning
Test updates in staging and plan for reboots when kernel or core libraries are changed to avoid unintended service disruptions.
Mnemonic: test, then update
VERIFIED COMPETENCY MILESTONE
