Module 3 › Chapter 3.2 › GPG Verification
Common cause of failures
If the repository key is not imported, dnf will fail package installs. Import the key into the RPM database or configure gpgkey in the .repo file.
Temporary bypass (not recommended)
- name: Install package from custom repo (temporarily disabling GPG check)
  ansible.builtin.dnf:
    name: my_custom_package
    state: present
    enablerepo: my_custom_repo
    disable_gpg_check: yes # WARNING: security risk
Proper solution
  • Obtain and import the legitimate GPG key with rpm --import.
  • Configure gpgkey and set gpgcheck=1 in the .repo file to enable verification automatically.
Warning
Disabling checks makes systems vulnerable to malicious or corrupted packages and should be avoided in production.
