Module 3 › Chapter 3.2 › ansible.builtin.dnf basics
Example: single package
- name: Ensure htop is installed
  ansible.builtin.dnf:
    name: htop
    state: present
You can replace name with a YAML list to install multiple packages in one task, or include a version string to pin a version.
Examples: list and version pin
- name: Install multiple packages
  ansible.builtin.dnf:
    name: ["nginx","php-fpm"]
    state: present

- name: Install specific version of git
  ansible.builtin.dnf:
    name: "git-2.39.1"
    state: present
Misconception
state: present does not upgrade an already installed package. Use state: latest when you want the newest available version.
