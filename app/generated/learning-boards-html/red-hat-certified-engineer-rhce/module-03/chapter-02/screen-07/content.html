Module 3 › Chapter 3.2 › Full vs targeted updates
Full update example (use with caution)
- name: Update all packages (use with caution in production)
  ansible.builtin.dnf:
    name: "*"
    state: latest
Run this in staging first and schedule maintenance for production. Expect possible reboots or service restarts for kernel or core library updates.
Safer alternative
  • Target only critical packages that need updating.
  • Use check mode to preview changes before applying them.
  • Stage updates on a small group of hosts, then roll out gradually.
Small checklist: staging test, check-mode dry run, scheduled maintenance window.
