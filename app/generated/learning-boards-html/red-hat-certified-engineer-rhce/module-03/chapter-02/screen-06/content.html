Module 3 › Chapter 3.2 › States
state: present
Installs the package if missing but does not upgrade an installed package. Use when you want stability.
state: latest
Installs and upgrades to the newest available version. Good for keeping systems patched, but test first in staging.
state: absent
Removes the package from the system. Useful for decommissioning software across hosts.
state: reinstalled
Forces a reinstall of a package that is already installed. Useful to repair corrupted installs.
Concrete example
- name: Ensure wget is at the latest version
  ansible.builtin.dnf:
    name: wget
    state: latest

- name: Ensure tmux is installed without changing its version
  ansible.builtin.dnf:
    name: tmux
    state: present
Misconception
Using state: latest everywhere avoids drift. In reality, it can introduce breaking changes. Prefer targeted updates for critical services and use staging tests.
