Use check mode to preview
# Preview changes without applying
ansible-playbook manage_packages.yml --check
Check mode helps you see which tasks would change state. It is useful but not a perfect substitute for testing in a real staging environment.
Plan for reboots
Major updates may require a reboot. Schedule maintenance windows and roll out updates gradually to limit blast radius.
Checklist
  • Run check mode.
  • Test in staging.
  • Schedule and notify for reboots.
