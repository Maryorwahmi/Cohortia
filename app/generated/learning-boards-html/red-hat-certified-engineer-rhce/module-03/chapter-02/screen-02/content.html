Module 3 › Chapter 3.2 › Learning Objectives
01
Use ansible.builtin.dnf
Compose tasks with name and state to install, update, remove, or reinstall packages. This matters because repeatable tasks remove manual drift across servers.
Mnemonic: name + state = desired state
VERIFIED COMPETENCY MILESTONE
02
Automate install/update/remove
Implement tasks to ensure specific packages are present, kept latest, or removed cleanly. Knowing which state to choose avoids accidental upgrades or deletions.
Mnemonic: present, latest, absent, reinstalled
VERIFIED COMPETENCY MILESTONE
03
Manage repositories
Place and configure .repo files using modules like ansible.builtin.copy and ensure packages are available from desired sources such as EPEL.
Mnemonic: file + enablerepo = source control
VERIFIED COMPETENCY MILESTONE
04
Implement version pinning
Install exact package versions to avoid regression and maintain application compatibility by specifying the package name with version in the name parameter.
Mnemonic: package-1.2.3 = pinned
VERIFIED COMPETENCY MILESTONE
