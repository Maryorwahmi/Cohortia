Module 3 › Chapter 3.2 › Key Concepts
dnf
Default package manager on RHEL 8+, responsible for resolving dependencies and executing installs and updates.
ansible.builtin.dnf
Module for package management; key parameters are name and state to declare desired package outcomes.
State: present/latest/absent
Choose the state that matches your stability and update policy; present avoids upgrades, latest applies them.
Key Takeaway

Automate package tasks against dnf, manage repositories as code, and keep GPG verification enabled to maintain secure, repeatable deployments.
