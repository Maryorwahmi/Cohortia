Module 3 › Chapter 3.2 › dnf on RHEL 8+
Definition

dnf is the default package manager on RHEL 8+. It resolves dependencies and performs package transactions for installs, updates, and removals.

Common misconception

Do not assume yum and dnf are identical in behavior; treat dnf as the authoritative tool on RHEL 8+.

Key Takeaway
Automate against dnf to get consistent dependency resolution and reliable package operations.
Terminal example
# List installed packages on a RHEL host
sudo dnf list installed

# Get package details
sudo dnf info htop
Why this matters
  • dnf provides the behavior Ansible relies on when managing packages.
  • Understanding dnf output helps you validate automation results.
