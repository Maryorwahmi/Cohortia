Module 3 › Chapter 3.2 › Repository Management
Add a repo file using copy
- name: Add EPEL repository
  ansible.builtin.copy:
    src: files/epel.repo
    dest: /etc/yum.repos.d/epel.repo
    owner: root
    group: root
    mode: '0644'
Treat this repo file as code: keep it in your repo and deploy it with Ansible so targets are consistent.
Install from the repo
- name: Install cowsay from EPEL
  ansible.builtin.dnf:
    name: cowsay
    state: present
    enablerepo: epel
Using enablerepo lets you keep third-party repositories disabled by default and only consult them for specific installs.
