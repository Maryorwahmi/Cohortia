Module 3 › Chapter 3.4 › What to Remember
Map zones intentionally
Assign interfaces and sources to zones that reflect trust levels to avoid accidental exposure.
Set permanent & immediate
Use both flags so rules apply now and survive reboots.
Protect SSH & verify
Allow SSH from control IP, use check mode, and confirm with firewall-cmd and live tests.
Final thought
Automation scales security when paired with safe practices and clear verification; your playbooks should make intended behavior explicit and testable.
