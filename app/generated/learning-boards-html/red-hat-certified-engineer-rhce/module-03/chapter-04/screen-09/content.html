Module 3 › Chapter 3.4 › Runtime vs Permanent
Layer comparison
Runtime
Applied now, lost on restart unless saved.
Permanent
Written to disk; needs reload to apply to runtime unless immediate is used.
Best practice
Set both permanent: yes and immediate: yes for production changes.
Validation checklist
  1. Apply with both flags to avoid gaps.
  2. Restart firewalld on a test host to confirm persistence.
  3. Document expected behavior in playbook comments.
