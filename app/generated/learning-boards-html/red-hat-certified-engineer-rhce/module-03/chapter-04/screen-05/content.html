Module 3 › Chapter 3.4 › ansible.posix.firewalld
Key parameters
zone
Target zone for the rule (example: public).
service
Enable a predefined service like http, https, or ssh.
port
Open specific ports such as 8080/tcp or 53/udp.
Behavioral flags
permanent
Write change to disk so it persists across reboots.
immediate
Apply change to runtime immediately without a reload.
Pitfall
Forgetting permanent: yes will lose rules after reboot.
