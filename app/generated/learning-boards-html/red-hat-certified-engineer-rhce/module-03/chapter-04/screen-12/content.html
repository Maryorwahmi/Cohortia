Module 3 › Chapter 3.4 › Common mistakes
Forgetting permanent
Result: rules active now but lost after reboot. Fix: set permanent: yes.
Incorrect names
Result: expected access not available. Fix: verify service and port names on the host.
Blocking SSH
Result: remote lockout. Fix: allow SSH from control IP early and keep recovery access methods.
Troubleshooting
Use firewall-cmd --list-all --zone=<zone_name> and test from allowed and denied sources. Use check mode to preview playbook actions before applying.
