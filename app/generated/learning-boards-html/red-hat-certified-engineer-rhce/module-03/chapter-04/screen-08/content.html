Module 3 › Chapter 3.4 › Open ports
Playbook example
- name: Allow TCP port 8080 in public zone
  ansible.posix.firewalld:
    zone: public
    port: 8080/tcp
    state: enabled
    permanent: yes
    immediate: yes
Validation
Test connectivity from another host using curl or a protocol-specific client, and run firewall-cmd --list-all --zone=public.
Misconception
Opening a port is not the same as enabling a named service; they are separate concepts in firewalld.
