Module 3 › Chapter 3.4 › Ensure firewalld
Playbook task
Use ansible.builtin.service to start and enable firewalld before making changes.
 - name: Ensure firewalld is running and enabled
   ansible.builtin.service:
     name: firewalld
     state: started
     enabled: yes
Why this matters
  • Ensures runtime and permanent operations are applied to the active daemon.
  • Prevents silent failures when applying rules with the firewalld module.
  • Use check mode to preview enabling without changing the service.
Quick Validation
Run firewall-cmd --state on the host to confirm the service is running.
