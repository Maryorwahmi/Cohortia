Module 3 › Chapter 3.4 › Rich rules
Example rich rule
- name: Allow SSH only from specific IP using a rich rule
  ansible.posix.firewalld:
    zone: public
    rich_rule: 'rule family="ipv4" source address="192.168.1.100" service name="ssh" accept'
    state: enabled
    permanent: yes
    immediate: yes
Guidance
  • Use rich rules to enforce source-based restrictions.
  • Verify precedence: a rich rule may override general service allowances.
  • Test from both allowed and disallowed IPs to confirm behavior.
Misconception
Rich rules are not just advanced: they are necessary when source-based control is required.
