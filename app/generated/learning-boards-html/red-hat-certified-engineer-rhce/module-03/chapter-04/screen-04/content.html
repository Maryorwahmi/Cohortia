Module 3 › Chapter 3.4 › What is firewalld?
Definition & model
firewalld uses zones to apply rule sets to interfaces and sources. Zones reflect trust.
Example
Assign DMZ interface to public zone, allow only HTTP/HTTPS there.
Misconception
Zones apply to interfaces and sources; they are not only physical NIC labels.
Key Takeaway
Pick a zone per interface based on trust and review assignments after changes.
Common zones
public
internal
trusted
Use firewall-cmd --list-all --zone=zone_name to inspect active rules for a zone. Pair this with interface assignments to ensure your intended access is in place.
