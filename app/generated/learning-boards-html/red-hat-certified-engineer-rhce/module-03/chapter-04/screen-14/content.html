Module 3 › Chapter 3.4 › Operational best practices
Recovery plan
  • Always include an SSH allow for control IP as an early task.
  • Have out-of-band console access ready before applying changes.
  • Keep a rollback playbook to revert recent firewall tasks.
Change management
Document why a rule exists, test in staging, and deploy incrementally to reduce blast radius.
Audit tip
Periodically inspect persistent zone files in /etc/firewalld/zones and reconcile with runtime state.
