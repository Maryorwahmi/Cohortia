Module 3 › Chapter 3.3 › Cron schedule fields
Five fields
Minute
0–59, supports step values like */5 for every five minutes.
Hour
0–23, specify the hour of day.
Day of month / Month / Weekday
Use numbers, ranges, and lists. Beware mixing day-of-month and weekday — test behavior when both fields are constrained.
Use special_time in Ansible for readability when appropriate, for example @hourly or @daily, instead of writing explicit fields.
Examples
Every day at 2:00 AM
0 2 * * *
Every five minutes
*/5 * * * *
Using special_time in Ansible
special_time: "@hourly"
Key Takeaway

Write schedules intentionally, prefer special_time for common intervals, and test ambiguous day fields to avoid unexpected runs.
