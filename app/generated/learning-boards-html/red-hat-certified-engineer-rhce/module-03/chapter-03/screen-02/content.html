Learning Objectives
Practical milestones and verified competencies
Bloom: Learn → Understand → Apply → Master
01
Interpret cron schedules

Read and write the five-field cron schedule to express precise intervals. This is foundational because every job schedule depends on correct field placement.

Mnemonic: five slots = time wheel
VERIFIED COMPETENCY MILESTONE
02
Use ansible.builtin.cron

Create, update, and remove cron jobs idempotently with Ansible parameters like name, job, user, and schedule fields. Idempotence avoids duplicate entries across runs.

Mnemonic: name = single source
VERIFIED COMPETENCY MILESTONE
03
Manage user & system crons

Place user jobs in crontabs and system jobs in /etc/cron.d using cron_file. This distinction helps with permissions and separation of concerns.

Mnemonic: user vs system files
VERIFIED COMPETENCY MILESTONE
04
Capture output & env

Redirect stdout and stderr to a log file, and set environment variables with environment: so jobs run with the expected context.

Mnemonic: redirect, then inspect
VERIFIED COMPETENCY MILESTONE
