Module 3 › Chapter 3.3 › Create • Modify • Remove
Create or modify
- name: Schedule daily backup script
  ansible.builtin.cron:
    name: "Daily Backup"
    minute: "0"
    hour: "3"
    job: "/opt/scripts/daily_backup.sh >> /var/log/daily_backup.log 2>&1"
    user: root
    state: present
Ansible will create or update the entry with name Daily Backup. The name is the lookup key used to ensure there are no duplicates.
Remove
- name: Remove the cron job
  ansible.builtin.cron:
    name: "Daily Backup"
    state: absent
Only the name is required to remove a job. This avoids needing to reconstruct the exact cron line when cleaning up.
Key Takeaway

Design descriptive names and rely on state present/absent to manage entries safely. Test changes in stages to avoid surprises.
