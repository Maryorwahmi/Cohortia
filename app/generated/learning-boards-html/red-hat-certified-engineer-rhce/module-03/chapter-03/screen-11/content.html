Module 3 › Chapter 3.3 › Troubleshooting
Step-by-step checks
  1. Inspect redirected job output files for errors and stack traces.
  2. Check system cron logs: journalctl -xeu cron or /var/log/cron for reported execution issues.
  3. Verify script permissions and shebang; ensure executable bit is set.
  4. Confirm absolute paths for interpreters and binaries used in the job.
  5. Dump cron's environment with a temporary job to inspect PATH and other variables.
  6. Ensure the cron user has necessary permissions and file access.
Debug job example
- name: Log cron environment for debugging
  ansible.builtin.cron:
    name: "Cron Env Dump"
    minute: "*/5"
    job: "env > /tmp/cron_env.log"
    user: root
    state: present
Key Takeaway

Work methodically: logs and env dumps reveal the majority of silent failures. Fix paths, permissions, or variables based on observed errors.
