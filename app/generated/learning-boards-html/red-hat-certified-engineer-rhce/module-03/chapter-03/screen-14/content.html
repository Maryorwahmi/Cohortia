Module 3 › Chapter 3.3 › Key Concepts
cron
Time-based job scheduler that runs non-interactive commands on a schedule.
crontab
The file format and command for per-user cron entries; each user has a separate crontab.
ansible.builtin.cron
Ansible module to create, update or remove cron jobs declaratively and idempotently.
Summary Takeaway

Manage schedules with clear names and absolute paths, set environment variables when needed, use cron_file for system jobs, and always capture output for troubleshooting.
