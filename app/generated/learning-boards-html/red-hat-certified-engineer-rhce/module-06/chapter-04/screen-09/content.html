Module 6 › Chapter 6.4 › SELinux booleans and ansible.posix.seboolean
Code example
- name: Allow HTTPD to connect to network (if needed)
  ansible.posix.seboolean:
    name: httpd_can_network_connect
    state: yes
    persistent: yes # Make the change persist across reboots
Why persistent
If persistent: yes is omitted, the boolean resets at boot. Document booleans to avoid surprise behavior changes.
Misconception
Booleans are not policy rewrites; they enable controlled exceptions and are safer than disabling SELinux.
Key Takeaway
Use ansible.posix.seboolean with persistent: yes to safely enable required behavior across reboots.
