Module 6 › Chapter 6.4 › Managing SELinux mode with Ansible
Code example
- name: Set SELinux to enforcing mode
  ansible.posix.selinux:
    state: enforcing
    policy: targeted # Common policy
  • Use state: permissive during diagnostics but plan to return to enforcing.
  • Do not assume this task changes the on-disk config that applies after reboot; plan for persistence if needed.
  • After the task, verify runtime with getenforce.
Pro tip
Combine this module with a configuration management task that edits /etc/selinux/config if you need persistent changes across reboots.
Key Takeaway
Use Ansible to orchestrate runtime toggles and verify with system commands to avoid surprises.
