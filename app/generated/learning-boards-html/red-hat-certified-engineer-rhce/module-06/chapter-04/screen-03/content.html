Verification Tasks
  • Run ls -Z on the target directories to confirm the correct SELinux file type is set.
  • Check getsebool for boolean values and ensure persistent changes were applied.
  • Inspect /var/log/audit/audit.log for denials and use sealert to interpret suggestions conservatively.
  • Use changed_when: true with restorecon so playbooks report intended changes.
Common pitfall
Forgetting persistent: yes on seboolean causes booleans to revert after reboot. Make persistence explicit.
