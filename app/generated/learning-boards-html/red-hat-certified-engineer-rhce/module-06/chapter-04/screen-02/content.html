Learning Objectives

Concrete automation skills to manage SELinux with Ansible.

Bloom: Learn → Understand → Apply → Master
01
Understand SELinux fundamentals

Define modes, types and contexts so you can read denials and select the right fix instead of guessing.

Mnemonic: Venn of Process vs File labels
VERIFIED COMPETENCY MILESTONE
02
Manage SELinux modes with Ansible

Use ansible.posix.selinux to toggle enforcing and permissive modes safely and plan reboots for disabled-to-enforcing changes.

Mnemonic: Traffic light (enforcing=red, permissive=yellow)
VERIFIED COMPETENCY MILESTONE
03
Automate file contexts and restorecon

Create persistent sefcontext rules and apply them so custom directories work without manual relabeling after reboots.

Mnemonic: Map + Apply (sefcontext then restorecon)
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot SELinux denials

Inspect audit.log, use sealert output, and translate fixes into Ansible tasks without overusing audit2allow.

Mnemonic: Log → Interpret → Automate
VERIFIED COMPETENCY MILESTONE
