Module 6 › Chapter 6.2 › Deploying sudoers with ansible.builtin.copy
Task anatomy
This task copies a prebuilt sudoers file and runs visudo -cf to check syntax before placing it in /etc/sudoers.d.
- name: Deploy sudoers file for 'devops' group
  ansible.builtin.copy:
    src: files/devops_sudoers
    dest: /etc/sudoers.d/devops
    owner: root
    group: root
    mode: '0440'
    validate: /usr/sbin/visudo -cf %s
Checklist before deploy
  • Confirm group exists on target hosts or create it with ansible.builtin.group.
  • Lint the src file locally where possible.
  • Use validate so visudo runs before the file is installed.
Check your understanding

If validate fails during the copy task, the candidate file is not installed. Investigate the syntax, correct the src, and re-run the playbook or fix manually via a safe console.
