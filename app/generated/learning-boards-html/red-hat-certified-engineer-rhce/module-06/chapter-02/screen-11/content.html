Module 6 › Chapter 6.2 › Principle of least privilege
Minimal grants
  • Prefer specific commands over ALL.
  • Use full paths like /usr/bin/chown to avoid PATH confusion.
  • Limit arguments where possible to reduce attack surface.
Practical checks
  • Ensure the group exists before granting rights.
  • Test commands with a non-privileged test user added to the group.
  • Review sudo logs to confirm only intended commands are executed.
