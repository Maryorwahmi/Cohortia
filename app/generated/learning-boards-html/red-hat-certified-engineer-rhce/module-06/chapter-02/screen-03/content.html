Practice Checklist
  • Create files/web_admins_sudoers with focused commands and full paths.
  • Ensure web_admins group exists using ansible.builtin.group.
  • Copy the file to /etc/sudoers.d with owner root, group root, mode 0440, and validate with visudo.
  • Add a test user to web_admins and verify allowed commands work as expected.
Common mistakes
  • Omitting validate, which risks applying invalid syntax.
  • Using package names or relative commands instead of full binary paths.
  • Setting wrong permissions — files must be 0440 in sudoers.d.
  • Granting ALL when only a few commands are needed.
