Module 6 › Chapter 6.2 › lineinfile vs drop-in files
lineinfile example
- name: Ensure 'wheel' group has NOPASSWD sudo access
  ansible.builtin.lineinfile:
    path: /etc/sudoers
    regexp: '^%wheel\s+ALL=\(ALL\)\s+ALL$'
    line: '%wheel ALL=(ALL) NOPASSWD: ALL'
    validate: /usr/sbin/visudo -cf %s
    state: present
This works for simple changes but becomes fragile with complex rules or multiple authors.
Drop-in file approach
Manage a complete file for a group under /etc/sudoers.d and deploy it with ansible.builtin.copy plus validate. This is clearer and easier to audit.
Key Takeaway

Drop-in files are the recommended pattern for complex or multi-line sudoers policy managed by teams.
