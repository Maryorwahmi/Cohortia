Module 6 › Chapter 6.2 › File permissions and ownership
Why 0440?
Mode 0440 gives read permission to owner and group, and no write permission to anyone except through root. This prevents unauthorized edits to sudo rules while allowing sudo to read the policies.
Ansible enforcement
- name: Deploy sudoers file
  ansible.builtin.copy:
    src: files/web_admins_sudoers
    dest: /etc/sudoers.d/web_admins
    owner: root
    group: root
    mode: '0440'
    validate: /usr/sbin/visudo -cf %s
Common pitfalls
  • Uploading files with incorrect modes, e.g., 0644, which allows write by owner only in some contexts — still risky.
  • Deploying files owned by the wrong user or group, which can complicate management and audits.
  • Assuming validate replaces the need for strict permissions — it does not.
