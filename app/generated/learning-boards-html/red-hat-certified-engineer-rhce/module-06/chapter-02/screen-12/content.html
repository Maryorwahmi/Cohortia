Module 6 › Chapter 6.2 › Audit sudo usage and recovery
Sudo logging
Add a Defaults logfile=/var/log/sudo.log to capture sudo usage. Review logs regularly and include sudo entries in your centralized logging if possible.
Recovery options
  • Keep an alternate root console or direct root login for emergency fixes.
  • Test changes in staging and maintain backups of working sudoers fragments.
Practical guidance
Combine visudo validation, strict file permissions, auditing, and a recovery pathway to manage risk when automating sudo policy changes.
