Module 6 › Chapter 6.2 › Why visudo and validation matter
Validation process
  1. Write a tested sudoers template on the control node.
  2. Use ansible.builtin.copy with validate set to visudo -cf %s.
  3. If visudo passes, Ansible places the file in /etc/sudoers.d with proper mode and ownership.
  4. If visudo fails, the task fails and the system keeps a working sudoers configuration.
Common mistake
Relying on permissions without validation creates a false sense of safety. Use both correct permissions and visudo validation.
Ansible example
- name: Deploy sudoers file for 'devops' group
  ansible.builtin.copy:
    src: files/devops_sudoers
    dest: /etc/sudoers.d/devops
    owner: root
    group: root
    mode: '0440'
    validate: /usr/sbin/visudo -cf %s
Pro tip

Lint and test templates locally before deployment to catch logic errors that visudo will flag during validate.
