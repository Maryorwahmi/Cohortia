Module 6 › Chapter 6.2 › Use /etc/sudoers.d for modular grants
Modular layout
Each group or team gets one file under /etc/sudoers.d. Files are additive to the main sudoers content, keeping team grants isolated and auditable.
/etc/sudoers
/etc/sudoers.d/team-a
/etc/sudoers.d/team-b
Benefits include clearer audits, smaller diff footprints, and safer rollbacks. Use Ansible tasks to deploy each file individually and validate with visudo so one bad file does not affect others.
Example
# /etc/sudoers.d/devops
%devops ALL=(ALL) NOPASSWD: /usr/bin/systemctl restart httpd, /usr/bin/systemctl status httpd
Key Takeaway

Separate files mean smaller, safer changes and simpler team ownership when you deploy with Ansible.
