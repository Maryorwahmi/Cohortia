Module 6 › Chapter 6.6 › Common Mistakes
Top mistakes
  • Incorrect NTP Servers: Using unreachable servers prevents sync. Use multiple reliable entries.
  • Firewall Blocking: NTP uses UDP port 123. Ensure outbound UDP 123 is allowed to NTP servers.
  • Forgetting to Restart: Template changes require a notify handler to restart chronyd to apply.
  • Large Time Jumps: Very large offsets may need manual intervention despite makestep settings.
Checks to include in runbook
  1. Ping or resolve configured NTP server names from the host.
  2. Confirm firewall rules permit UDP 123 traffic.
  3. Run chronyc tracking and chronyc sources after deployment.
Common Mistake

Skipping verification or assuming a running service means successful synchronization.
