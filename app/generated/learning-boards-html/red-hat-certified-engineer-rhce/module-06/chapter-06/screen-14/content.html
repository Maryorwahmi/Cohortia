Module 6 › Chapter 6.6 › Network & Security
Firewall guidance
  • Confirm outbound UDP 123 is allowed to your NTP servers.
  • For servers providing NTP, allow inbound UDP 123 only from authorized networks.
  • Include firewall checks in automation runbooks to avoid silent failures.
Access control

When exposing chrony as a server, use allow directives to restrict clients and reduce risk. Document allowed networks in your configuration template so changes are auditable.

Key Takeaway

Balance reachability and security: open UDP 123 where necessary and restrict server access with allow rules.
