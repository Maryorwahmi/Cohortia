Module 6 › Chapter 6.6 › Install & Ensure Service
Code example
- name: Ensure chrony package is installed
  ansible.builtin.package:
    name: chrony
    state: present

- name: Ensure chronyd service is running and enabled
  ansible.builtin.service:
    name: chronyd
    state: started
    enabled: yes
This small snippet is idempotent: running it repeatedly leaves the host in the desired state without extra changes.
Explanation & checks
  • Use package to manage installation across distributions consistently.
  • Service ensures chronyd is active and configured to start on boot.
  • After deployment, run chronyc tracking on the host to confirm synchronization.
Key Takeaway

Install first, manage the service state, and use handlers for configuration-triggered restarts.
