Guided sequence
  1. Create chrony.conf.j2 with a loop over ntp_servers and iburst on server lines.
  2. Write configure_chrony.yml with vars: ntp_servers and tasks to install chrony, deploy template, and ensure service.
  3. Add a handler Restart chronyd and include notify on the template task.
  4. Run the playbook against app_servers and then verify with chronyc tracking and chronyc sources.
Troubleshooting flow
If verification fails:
  • Confirm ntp_servers resolve and respond.
  • Check firewall rules for UDP 123.
  • Ensure the handler ran by checking service uptime and logs.
Key Takeaway

Follow the template → deploy → handler → verify loop and include a fallback server for resilience.
