Module 6 › Chapter 6.6 › chrony.conf Directives
Directive cards
server / pool
List NTP sources. Use multiple servers for redundancy and add iburst for fast startup.
driftfile
Records clock drift so chrony can apply long-term corrections.
rtcsync
Synchronize the hardware real-time clock from the system clock.
makestep
Allow controlled large clock steps during initial updates to correct large offsets.
Concrete example
server ntp1.internal.local iburst
server ntp2.internal.local iburst
driftfile /var/lib/chrony/drift
rtcsync
makestep 1 3
Key Takeaway

Pick multiple reliable servers and include directives that match your update policy and tolerance for large steps.
