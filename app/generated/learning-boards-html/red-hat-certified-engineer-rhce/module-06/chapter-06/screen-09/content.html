Module 6 › Chapter 6.6 › Handlers & notify
Playbook snippet
tasks:
  - name: Deploy chrony configuration file
    ansible.builtin.template:
      src: chrony.conf.j2
      dest: /etc/chrony.conf
      owner: root
      group: root
      mode: '0644'
    notify: Restart chronyd

handlers:
  - name: Restart chronyd
    ansible.builtin.service:
      name: chronyd
      state: restarted
Handlers execute at the end of a play for changed tasks, aggregating multiple notifications into a single restart.
Practical notes
  • Include notify on the template task so new server entries load automatically.
  • Avoid restarting services unnecessarily by relying on handlers aggregating changes.
  • Confirm behavior on your distribution; use restarted when a full reload is required.
Key Takeaway

Use a handler to restart chronyd only when configuration changes, ensuring predictable rollouts.
