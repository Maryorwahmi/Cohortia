Module 6 › Chapter 6.6 › Verify with chronyc
Example commands
chronyc tracking
chronyc sources
Use these commands on the target host to inspect synchronization state and the status of each configured source.
Interpreting results
  • Reference ID and stratum indicate which server is the time source and its trust level.
  • System time offset shows how far off the system clock is; small offsets are normal.
  • chronyc sources identifies unreachable servers and helps narrow firewall or DNS issues.
Key Takeaway

Verification commands are the final confirmation that automation succeeded; always run them after deployment.
