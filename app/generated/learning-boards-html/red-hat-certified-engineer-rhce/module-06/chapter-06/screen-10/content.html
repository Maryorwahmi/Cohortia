Module 6 › Chapter 6.6 › Hands-on Playbook
Playbook template
---
- name: Configure chrony for time synchronization
  hosts: app_servers
  become: true

  vars:
    ntp_servers:
      - ntp1.internal.local
      - ntp2.internal.local
      - 0.rhel.pool.ntp.org

  tasks:
    - name: Ensure chrony package is installed
      ansible.builtin.package:
        name: chrony
        state: present

    - name: Deploy chrony configuration file
      ansible.builtin.template:
        src: chrony.conf.j2
        dest: /etc/chrony.conf
        owner: root
        group: root
        mode: '0644'
      notify: Restart chronyd

    - name: Ensure chronyd service is running and enabled
      ansible.builtin.service:
        name: chronyd
        state: started
        enabled: yes

  handlers:
    - name: Restart chronyd
      ansible.builtin.service:
        name: chronyd
        state: restarted
Checklist before run
  • Define ntp_servers in play or inventory so the template renders server lines.
  • Ensure play targets the correct host group, e.g., app_servers or all.
  • Have a handler to restart chronyd so new configuration is applied.
Key Takeaway

Follow the sequence and include a fallback server to improve resilience during failures.
