Module 6 › Chapter 6.6 › Templating chrony.conf
Jinja2 template example
# /etc/chrony.conf.j2
# Cohortia internal NTP servers
{% raw %}{% for server in ntp_servers %}{% endraw %}
server {{ server }} iburst
{% raw %}{% endfor %}{% endraw %}

driftfile /var/lib/chrony/drift
rtcsync
makestep 1 3
logdir /var/log/chrony
Use this template with ansible.builtin.template and supply ntp_servers as a variable in your playbook or inventory.
Why template over line edits
  • Ensures entire file matches desired state instead of piecemeal edits.
  • Makes it easy to include or exclude sections based on variables.
  • Simplifies auditability and rollbacks when stored in version control.
Key Takeaway

Render /etc/chrony.conf from a Jinja2 template for predictable, repeatable configuration across hosts.
