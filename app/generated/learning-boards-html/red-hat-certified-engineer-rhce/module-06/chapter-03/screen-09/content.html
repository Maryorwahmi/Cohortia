Module 06 › Chapter 6.3 › state: present vs state: absent
Add key (state: present)
ansible.posix.authorized_key:
  user: admin_user
  state: present
  key: "{{ lookup('file','/tmp/new_admin_key.pub') }}"
Idempotent: creates the line if missing and ensures correct permissions.
Remove key (state: absent)
ansible.posix.authorized_key:
  user: old_automation_user
  state: absent
  key: "ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAABAQC... old-automation-key"
Removal requires the exact public key string. If using lookup('file', ...), ensure the file contains only that key.
Key Takeaway

Use present to grant, absent to revoke. Confirm the exact key line when removing to avoid mistakes.
