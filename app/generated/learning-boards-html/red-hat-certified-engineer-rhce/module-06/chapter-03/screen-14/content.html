Module 06 › Chapter 6.3 › Key Concepts
SSH Key-Based Authentication
Private key kept secret; public key placed in authorized_keys.
ansible.posix.authorized_key
Idempotent module to add or remove keys and set key_options.
Permissions matter
~/.ssh must be 0700 and authorized_keys 0600; incorrect modes cause SSH to ignore keys.
Summary Takeaway

Combine dedicated keys, idempotent playbooks, key_options, and strict permissions for secure, automated access control.
