Learning Objectives
Bloom targets: Learn → Understand → Apply → Master
Learn → Understand → Apply → Master
01
Explain SSH key authentication

Describe public/private key roles and why key-based login is safer than passwords. This conceptual clarity prevents common misconfigurations.

VERIFIED COMPETENCY MILESTONE
02
Deploy keys with Ansible

Use ansible.posix.authorized_key and lookup('file', ...) to deploy keys idempotently and avoid embedding key content directly in playbooks.

VERIFIED COMPETENCY MILESTONE
03
Enforce correct permissions

Ensure ~/.ssh is 0700 and authorized_keys is 0600; incorrect permissions are a top cause of key rejection by SSH.

VERIFIED COMPETENCY MILESTONE
04
Manage lifecycle and revocation

Plan for revoking keys and avoid private key reuse. Automate state: absent to remove compromised keys reliably.
