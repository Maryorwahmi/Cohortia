Module 06 › Chapter 6.3 › Generate a dedicated automation key
Key generation example
Choose RSA or ED25519. Store files in a clear path and secure the private key.
ssh-keygen -t rsa -b 4096 -f ~/.ssh/ansible_svc_key -N ""
# or
ssh-keygen -t ed25519 -f ~/.ssh/ansible_svc_key -N ""
Quick checks
  • ls -l ~/.ssh/ansible_svc_key*
  • cat ~/.ssh/ansible_svc_key.pub to confirm the comment
  • chmod 600 private key if needed
Misconception
Leaving a passphrase blank is acceptable for automation only if the private key is protected by strict host controls or an agent; never publish the private key file.
Key Takeaway

Create a dedicated automation key, verify both files, and secure the private key with owner-only permissions.
