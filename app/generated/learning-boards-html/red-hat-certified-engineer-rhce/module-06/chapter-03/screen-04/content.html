Module 06 › Chapter 6.3 › SSH key pairs: private and public
Definition
Private key: secret file used to authenticate. Public key: text placed on servers to authorize that private key.
Example generation
ssh-keygen -t rsa -b 4096 -f ~/.ssh/ansible_svc_key -N ""
Generates a private key and a matching .pub public key file on the control node.
Misconception
Public keys do not grant access by themselves and do not need the same secrecy as private keys; however comments are useful for identification.
Key Takeaway

Keep private keys secure. Deploy only public keys to servers and use descriptive comments for management.

Analogy
Think of the private key as your house key and the public key as a copy of a lock configuration placed at each door. The lock recognizes a correct key without the key being shared.
Practical tip
Generate a dedicated automation key and avoid reusing personal keys in CI or service accounts to limit exposure.
Check
Verify files exist: ~/.ssh/ansible_svc_key and ~/.ssh/ansible_svc_key.pub on the control node before deployment.
