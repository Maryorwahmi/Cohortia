Module 06 › Chapter 6.3 › Hands-on: deploy and verify an automation key
Step-by-step checklist
  1. On control node: generate key pair and confirm files exist.
  2. Create deploy_automation_key.yml with tasks to ensure user and deploy key using lookup('file', path).
  3. Run ansible-playbook -i inventory.ini deploy_automation_key.yml against test hosts.
  4. On target: check ownership and modes for ~/.ssh and authorized_keys.
  5. Test access: ssh -i ~/.ssh/ansible_svc_key ansible_svc@target_ip to verify login.
  6. To revoke: use ansible.posix.authorized_key with state: absent and the exact key string, then re-run playbook.
Why it matters
Following an explicit checklist prevents permission errors and accidental key exposure when automating across many hosts.
