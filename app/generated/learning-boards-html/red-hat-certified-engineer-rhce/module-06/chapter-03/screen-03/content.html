Skills & Verification
Practical checks you will perform after automation runs.
Key generation

Create a dedicated RSA or ED25519 key for automation and protect the private key with strict filesystem permissions.

VERIFIED COMPETENCY MILESTONE
Playbook deployment

Use ansible.posix.authorized_key with lookup('file', ...) so your playbook references the public key without embedding it.

VERIFIED COMPETENCY MILESTONE
Verification steps

Confirm ~/.ssh permissions, check authorized_keys contains the expected line, and test ssh -i to ensure the key works.
