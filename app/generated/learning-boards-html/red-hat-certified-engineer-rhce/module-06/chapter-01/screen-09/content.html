Hashed passwords
Generate a hashed password locally and store the hash in the playbook or secrets store.
password: "$6$saltsalt$hashedpasswordhere"
Why hashes?
  • Prevents exposing credentials if playbooks are stored in version control.
  • Hashes are required by many systems for direct assignment to /etc/shadow.
authorized_key
Deploy public SSH keys to grant secure, passwordless access.
Practical example
Use the authorized_key parameter to add a public key string to a user's authorized_keys file and protect it with vault when necessary.
Misconception
Ansible will not hash plain-text passwords for you; pre-hash or use keys and protect secrets externally.
