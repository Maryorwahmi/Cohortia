Group creation and GID
Use gid for consistent numeric identities across systems.
Example
- name: Ensure 'developers' group exists
  ansible.builtin.group:
    name: developers
    gid: 2000
    state: present
Why GID matters
  • File ownership uses numeric GID; fixed GIDs keep permissions stable across hosts.
  • Migrating data between systems benefits from matching numeric IDs.
Safe removal
Before setting state: absent, ensure no user has the group as their primary group and reassign any critical file ownership.
Misconception
Deleting a group is not risk-free; it may leave files with unexpected ownership or cause access issues.
Key Takeaway

Declare GIDs when you need deterministic ownership and audit primary group usage before deletion.
