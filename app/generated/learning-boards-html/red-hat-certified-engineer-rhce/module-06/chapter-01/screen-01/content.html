Automating User and Group Management
Define user and group state with playbooks to ensure consistent access and safe deletions.
Interactive 16:9 Masterclass
In this lesson
User & group modules, UID/GID, append behavior, deletion safety.
Live demo
Create qa_team and two users, run playbook, verify with id and getent.
Common pitfall
Forgetting append: yes removes existing secondary groups.
Quick visual
Users and groups declared in YAML become the single source of truth for target hosts.
Playbook
- name: Create qa_team group
  ansible.builtin.group:
    name: qa_team
    gid: 2005
    state: present
Verify
$ id qa_lead
uid=1005(qa_lead) gid=2005(qa_team) groups=2005(qa_team)
$ getent group qa_team
qa_team:x:2005:qa_lead,qa_engineer
Visual concept
Desired state
Declare users and groups once, apply to many hosts.
Danger
Omitting append can remove secondary group memberships.
Audit
Test playbooks in staging before production runs.
