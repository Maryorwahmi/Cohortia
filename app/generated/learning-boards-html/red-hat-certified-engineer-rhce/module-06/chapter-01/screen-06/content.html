Module 6 › Chapter 6.1 › Primary vs Secondary
Primary Group
The user's main group; often matches the username and sets default file group owner.
Example
User qa_lead with primary group qa_team results in new files owned by gid 2005 by default.
Secondary Groups
Additional groups granting access to group-owned resources; managed with the groups parameter.
Pitfall
Using groups without append: yes will replace all supplementary groups, possibly removing legitimate access.
Correct pattern to add membership
- name: Add 'devops_user' to 'developers' group
  ansible.builtin.user:
    name: devops_user
    groups: developers
    append: yes
    state: present
