Common mistakes and fixes
append missing
Always include append: yes when adding supplementary groups to avoid removal of existing memberships.
No become
Use become: true for tasks that modify system accounts to prevent privilege failures.
Plain-text passwords
Use hashed passwords or authorized_key and protect with vault; do not commit secrets to source control.
Pro tip

Break large user management changes into targeted tasks and run them in staging to reduce blast radius and improve traceability.
