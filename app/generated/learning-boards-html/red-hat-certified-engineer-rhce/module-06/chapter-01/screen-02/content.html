Learning Objectives
What you'll be able to do after this chapter
Bloom: Learn → Understand → Apply → Master
Create, modify, delete users
Use ansible.builtin.user to declare account state. This ensures repeatability and reduces manual errors across hosts.
VERIFIED COMPETENCY MILESTONE
Manage groups and assignments
Create groups with gid and assign users to primary and secondary groups to control access consistently.
VERIFIED COMPETENCY MILESTONE
Understand UID/GID and attributes
UID and GID determine ownership and access. Specify shell and home for predictable login behavior across systems.
VERIFIED COMPETENCY MILESTONE
Avoid common pitfalls
Learn to use append: yes, hashed passwords, and remove: yes carefully to prevent data loss or revoked access.
VERIFIED COMPETENCY MILESTONE
