Module 6 › Chapter 6.1 › Verification commands
id command
Shows uid, gid, and supplementary groups for a user.
$ id qa_lead
uid=1005(qa_lead) gid=2005(qa_team) groups=2005(qa_team)
getent group
Displays the group entry and membership list for a given group. 
$ getent group qa_team
qa_team:x:2005:qa_lead,qa_engineer
Automation tip
Add id and getent checks to a post-deployment verification step or CI job to automatically confirm account and group state on target hosts.
