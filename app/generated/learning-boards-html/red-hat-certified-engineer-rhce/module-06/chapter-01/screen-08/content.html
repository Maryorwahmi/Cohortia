Module 6 › Chapter 6.1 › Delete & cleanup
Removal pattern
Archive, reassign ownership, then remove user account with remove: yes.
Example: complete removal
- name: Remove old_employee completely
  ansible.builtin.user:
    name: old_employee
    state: absent
    remove: yes
Checklist before deletion
  • Backup or archive home directory.
  • Find files owned by the user's UID outside home and reassign.
  • Test removal in staging to confirm expected cleanup.
Misconception
remove: yes does not hunt for all files owned by the user across the filesystem; it deletes home and mail spool only.
Practical tip
Use find with -uid to locate orphaned files and reassign ownership before deletion.
Key Takeaway

Deletion requires backup and ownership checks; test in staging before production removal.
