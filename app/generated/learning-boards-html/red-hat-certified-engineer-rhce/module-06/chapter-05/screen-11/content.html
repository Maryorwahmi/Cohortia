Module 6 › Chapter 6.5 › Verify & Test
Verification steps
Confirm both configuration and behavior after automation.
Listing and inspection
Inspect the zone listing to see services, ports, and rich rules. Confirm the rule entries appear in the appropriate zone so they will be evaluated for matching traffic.
Automated assertions
Include small test tasks after configuration that attempt a connection from a control host in the management subnet and from a denied host to assert expected behavior.
Connectivity tests
Test from an allowed host: connect to the application and database ports to confirm success. Test from a host outside the allowed subnet to confirm denial. Use these results in your deployment checklist.
Troubleshooting checklist
  • Is the interface assigned to the expected zone?
  • Is the rule present in the permanent and runtime stores?
  • Did you protect SSH access before restrictive changes?
