Module 6 › Chapter 6.5 › Install & manage firewalld
Ensure firewalld is present and running
Install the package, then start and enable the service before applying rules.
Why ordering matters
If rule tasks run before the daemon exists or is running, the automation may appear successful locally but rules won't be applied. Keep tasks idempotent so repeated runs are safe.
Example tasks
- name: Ensure firewalld is installed and running
  ansible.builtin.package:
    name: firewalld
    state: present

- name: Start and enable firewalld service
  ansible.builtin.service:
    name: firewalld
    state: started
    enabled: yes
Checklist
  • Install package before configuring rules.
  • Enable the service so it starts after reboots.
  • Use clear task names for auditability.
Safety note
Test on non-critical machines before widespread deployment to confirm no unexpected interactions with other network services.
