What you'll accomplish

Write an Ansible playbook to install and enable firewalld, add permanent and immediate rules using ansible.posix.firewalld, and craft rich rules scoped to a management subnet while keeping fallback access.

Zones
Assign trust to interfaces and apply rules by zone.
Services
Use predefined service names when possible for clarity.
Rich Rules
Write rules that include source addresses, ports, and actions.
Quick example
- name: Open HTTP (port 80) in the public zone permanently
  ansible.posix.firewalld:
    port: 80/tcp
    zone: public
    state: enabled
    permanent: yes
    immediate: yes
This task writes the rule permanently and applies it immediately so connectivity continues without a reload.
