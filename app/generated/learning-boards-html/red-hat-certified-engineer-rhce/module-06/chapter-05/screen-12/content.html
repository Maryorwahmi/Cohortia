Module 6 › Chapter 6.5 › Assessment
Practice prompts
Tasks to check your automation skills and safety practices.
Task 1
Open HTTPS (port 443) permanently in the public zone and apply immediately. Verify with a zone listing and from a remote host.
Task 2
Close a test port such as 8000/tcp permanently and confirm the port is removed from both runtime and permanent lists.
Task 3
Create a rich rule to allow SSH only from a specific IP address and verify access patterns from that IP and another.
When you finish, document the verification steps and any unexpected behaviors. Use this documentation for later audits and to reduce drift across your servers.
