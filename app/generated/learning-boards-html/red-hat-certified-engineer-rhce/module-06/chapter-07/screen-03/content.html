Verification cards
Check package install

Use rpm -q nginx to confirm installation and version. This proves an Ansible task with state present has achieved the desired result.

Confirm repo presence

Run dnf repolist to ensure EPEL is enabled and the gpg key is installed where required.

Validate cache refresh

After adding a repo, an ansible.builtin.dnf task with update_cache: yes should detect newly available packages.

Operational checklist
  • Run updates in dev first, then staging, then production.
  • Schedule reboots when kernel or core library updates are applied.
  • Keep snapshots or rollback steps for major changes.
Key Takeaway

Every automation task should include a short verification step to make changes auditable and recoverable.
