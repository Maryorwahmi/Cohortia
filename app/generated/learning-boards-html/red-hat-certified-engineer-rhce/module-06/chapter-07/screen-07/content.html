Module 7 › Chapter 6.7 › Full system updates
System-wide update pattern
- name: Perform a full system update
  ansible.builtin.dnf:
    name: '*' # Or omit 'name' entirely
    state: latest
    update_cache: yes
This task updates all packages the package manager knows about. Because it affects many components, plan testing and reboots when necessary.
Checklist for full updates
  • Refresh cache to get current metadata.
  • Test updates in dev and staging before production.
  • Plan reboots for kernel or library changes.
  • Have snapshots or rollback strategies ready.
Pro tip

Run a dry check of available updates first, then schedule the playbook during a maintenance window when doing a full update.
