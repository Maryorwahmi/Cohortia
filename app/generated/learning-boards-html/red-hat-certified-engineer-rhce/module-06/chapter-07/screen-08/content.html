Module 7 › Chapter 6.7 › Package groups
Group install example
- name: Install "Development Tools" package group
  ansible.builtin.dnf:
    name: "@Development Tools"
    state: present
Prefix the group name with an at-sign. This installs the entire group rather than individual packages.
Verification and notes
  • Use dnf groupinfo to list group contents.
  • Groups are useful for provisioning similar node types with consistent toolsets.
  • When using groups, verify a few representative packages to confirm the outcome.
