Module 7 › Chapter 6.7 › ansible.builtin.dnf
Code examples
- name: Ensure httpd package is installed
  ansible.builtin.dnf:
    name: httpd
    state: present

- name: Update httpd package to the latest version
  ansible.builtin.dnf:
    name: httpd
    state: latest

- name: Remove an unwanted package
  ansible.builtin.dnf:
    name: unwanted_package
    state: absent
    autoremove: yes
Note

state: present adds a package if missing; state: latest updates it when newer versions exist; state: absent removes it. Autoremove helps clean orphaned dependencies.

Explanation cards
  • Idempotency: repeated runs do not change state once desired state is reached.
  • Targeted updates: use name to limit which package is affected.
  • Full updates: omit name or use name: '*' for system-wide updates.
Common mistake

Forgetting update_cache: yes after repository changes can cause missing updates or stale packages.
