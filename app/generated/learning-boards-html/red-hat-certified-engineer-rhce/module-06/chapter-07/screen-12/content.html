Module 7 › Chapter 6.7 › Safety notes
Safety checklist
  • Phased rollout: dev → staging → small prod subset → full production.
  • Plan reboots for kernel and core library updates.
  • Keep snapshots or backups to enable rollback.
  • Validate key services after update before continuing rollout.
Scenario

Apply a critical library update to a database node in staging, run health checks and queries, then update one production replica and observe. If all checks pass, continue. If not, revert the snapshot and investigate.

Pro tip

Automate health checks and verification as part of your update playbook so every update run includes validation steps.
