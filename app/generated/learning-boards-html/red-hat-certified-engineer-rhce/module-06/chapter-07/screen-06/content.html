Module 7 › Chapter 6.7 › Updating to the latest package version
Playbook snippet
- name: Update nginx package to latest, refresh cache first
  ansible.builtin.dnf:
    name: nginx
    state: latest
    update_cache: yes

# Full system update
- name: Perform a full system update
  ansible.builtin.dnf:
    name: '*' # Or omit this line entirely
    state: latest
    update_cache: yes
This pattern refreshes metadata and then applies available upgrades for the named package or the entire system.
Explanation
  • update_cache: yes is equivalent to refreshing dnf metadata so new versions are visible.
  • state: latest will only act if a newer version exists compared to the installed one.
  • Scheduling or running playbooks regularly is necessary for continuous patching.
Misconception

state: latest does not run continuously; it changes the package only when this playbook runs.
