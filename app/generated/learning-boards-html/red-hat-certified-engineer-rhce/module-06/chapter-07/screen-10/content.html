EPEL repository example
- name: Add EPEL repository
  ansible.builtin.dnf_repository:
    name: epel
    description: Extra Packages for Enterprise Linux
    baseurl: https://download.fedoraproject.org/pub/epel/$releasever/$basearch/
    gpgcheck: yes
    gpgkey: /etc/pki/rpm-gpg/RPM-GPG-KEY-EPEL-{{ ansible_distribution_major_version }}
    enabled: yes
    state: present
After adding a repository, follow with update_cache: yes in a subsequent dnf task so the system sees newly available packages.
Repository considerations
  • Only add trusted repositories to avoid conflicts and security risks.
  • Set gpgcheck and provide the correct gpgkey path for package signing validation.
  • After adding, refresh cache before installing packages from the new repository.
Common mistake

Adding multiple overlapping repositories can lead to dependency resolution issues. Prefer minimal, trusted sources.
