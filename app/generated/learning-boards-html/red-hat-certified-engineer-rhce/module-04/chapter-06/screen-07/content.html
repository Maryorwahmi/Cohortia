Definition

iSCSI (Internet Small Computer System Interface)

iSCSI exposes storage as raw block devices to initiators. The client is responsible for partitioning and creating a filesystem.

Key terms
IQN: unique name for targets and initiators. LUN: logical unit number identifying a disk. Portal: IP and port where the target listens.
Common misconception
iSCSI does not manage filesystems for you. The system that logs in must format and mount the disk.
Concrete example
A server creates an LV named iscsi_lun1, presents it under an IQN and portal 3260; a client discovers and logs in, a new /dev device appears and is formatted and mounted.
Key Takeaway

iSCSI delivers raw block devices that are ideal for VMs and databases, but they require careful access control and stable device handling on clients.
