NFS client playbook

---
- name: Configure NFS Client
  hosts: nfs_clients
  become: yes
  tasks:
    - name: Ensure nfs-utils package is installed
      ansible.builtin.yum:
        name: nfs-utils
        state: present

    - name: Ensure mount point for NFS share exists
      ansible.builtin.file:
        path: /mnt/nfs_data
        state: directory
        mode: '0755'

    - name: Mount NFS share from nfs_server.example.com
      ansible.posix.mount:
        path: /mnt/nfs_data
        src: nfs_server.example.com:/srv/nfs_share
        fstype: nfs
        opts: defaults,_netdev
        state: mounted
Notes and verification
  • Use ansible.builtin.yum so the client package installation is idempotent.
  • Create a stable mount point with file to ensure it exists before mounting.
  • Mount with _netdev so persistent mounts wait for networking and don’t fail during boot.
  • Verify with df -h and create a test file on the client; confirm it appears on the server to validate write access.
Pro tip

Use hostnames resolvable by DNS or inventory and avoid ephemeral IPs in the src field for long-term stability.
