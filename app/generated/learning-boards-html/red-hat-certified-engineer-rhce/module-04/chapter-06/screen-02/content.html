Learning Objectives

Each objective shows a measurable skill and why it matters in practice.

01
Configure an NFS server
Write a playbook to install nfs-utils, create export directories, and add exports to /etc/exports. This ensures a reproducible export configuration for many clients.
Verified competency milestone
02
Mount NFS clients persistently
Use ansible.posix.mount and the _netdev option so mounts wait for network availability and avoid boot-time failures.
Verified competency milestone
03
Set up an iSCSI target
Create a backing store, define an IQN, add LUNs and portals with targetcli via Ansible, while ensuring idempotency to avoid duplicates.
Verified competency milestone
04
Configure an iSCSI initiator
Discover and log in to targets, wait for device nodes, and mount using by-path or UUID to avoid device name drift.
Verified competency milestone
