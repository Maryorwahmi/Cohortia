Definition

Network File System (NFS)

NFS exports directories on a server. Clients mount those exports and interact with files the same way they would locally.

When to use NFS
Shared home directories, common web content, or application logs that many hosts read and write.
Common misconception
NFS is not block storage; do not treat an NFS share as a raw disk for local filesystem creation.
Key Takeaway

NFS provides shared file access with server-side consistency — automate exports and mounts for reliability.

Concrete example: export options
A typical export grants read/write, synchronous writes, and controls root squashing. Use host-specific entries for security.
/srv/nfs_share *(rw,sync,no_root_squash,no_subtree_check)
Why _netdev matters
When you persist mounts in fstab, include _netdev so the system waits for the network before mounting and avoids boot failures.
