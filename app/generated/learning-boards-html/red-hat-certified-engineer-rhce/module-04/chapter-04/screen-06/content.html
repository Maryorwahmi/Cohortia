Module 04 › Chapter 4.4 › Ansible playbook
Code example
---
- name: Configure LVM Physical Volumes and Volume Groups
  hosts: lvm_servers
  become: yes
  tasks:
    - name: Ensure /dev/sdb and /dev/sdc are initialized as Physical Volumes and added to 'data_vg'
      community.general.lvg:
        vg: data_vg
        pvs:
          - /dev/sdb
          - /dev/sdc
        state: present
      register: lvg_creation_result

    - name: Display LVM VG creation/extension result
      ansible.builtin.debug:
        var: lvg_creation_result
This task both initializes PVs when needed and creates or extends the named VG in an idempotent way. Registering allows you to inspect what changed.
Walkthrough
  • vg: sets the target Volume Group name, here data_vg.
  • pvs: lists devices to include; lvg will initialize them as PVs if required.
  • state: present ensures the VG exists and the listed PVs are members.
  • register: captures module output to examine changed status and detail.
Key Takeaway

This module simplifies PV initialization and VG creation into a single, repeatable Ansible task. Always inspect the registered output.
