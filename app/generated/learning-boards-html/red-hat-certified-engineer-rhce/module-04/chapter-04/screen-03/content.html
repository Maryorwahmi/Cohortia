Module 04 › Chapter 4.4 › Learning Objectives
Objective
Read and use Ansible task output
Register results from community.general.lvg, review changed/failed status, and debug variables to confirm exact changes that occurred on the host.
Objective
Perform safe prechecks
Use lsblk to confirm device names and emptiness, and avoid initializing disks containing data. Always run display commands to verify LVM state after automation.
Mnemonic
Check, run, verify. This three-step loop prevents common mistakes when changing block devices automatically.
VERIFIED COMPETENCY MILESTONE
After practice, you can run a playbook that creates or extends a VG and confirm the change with pvdisplay/vgdisplay output on the target host.
