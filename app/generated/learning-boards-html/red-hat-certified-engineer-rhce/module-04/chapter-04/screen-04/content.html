Module 04 › Chapter 4.4 › Physical Volume
Definition
Physical Volume (PV)
A raw disk or partition prepared with an LVM header. It cannot be used directly for filesystems once initialized.
Analogy
Think of each PV as a brick that can be combined with other bricks to build a storage wall (the VG).
Common misconception
A PV is not mountable and is not a filesystem. It is a block device allocated into a VG to host logical volumes.
Key Takeaway

Initializing a PV writes metadata to the device header. Verify with lsblk and pvdisplay before initializing to avoid data loss.

Example
You have two unpartitioned disks, /dev/sdb and /dev/sdc. Each will become a PV when initialized and then can be added to a VG to provide combined capacity.
Check devices
Run lsblk to confirm devices are present and unmounted before automation.
Verify PV
Use pvdisplay on the target host after playbook runs to confirm PV creation and attributes.
Pro tip
Label devices consistently on VMs so your playbooks target the intended disks and reduce risk.
