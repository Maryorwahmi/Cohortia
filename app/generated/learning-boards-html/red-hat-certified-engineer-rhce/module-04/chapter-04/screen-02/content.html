VERIFIED COMPETENCY MILESTONE
Mnemonic
Think: Disk → PV (initialized) → VG (pooled) → LV (carved). The playbook supplies the step from Disk to VG and initializes PVs when needed.
How you'll practice
  1. Identify unpartitioned disks with lsblk.
  2. Run a minimal lvg task to create a VG from two devices.
  3. Verify results using pvdisplay and vgdisplay.
