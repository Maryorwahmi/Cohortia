Module 04 › Chapter 4.4 › Safe workflow
Step 1
Check
Run lsblk to identify unpartitioned disks and ensure devices are unmounted. Confirm names and availability on the target host.
Step 2
Run
Execute an Ansible playbook using community.general.lvg with become: yes. Register results so you can inspect changed status and module output.
Step 3
Verify
Use pvdisplay and vgdisplay on the managed node to confirm PV headers and VG size. Ensure the free extents match expected capacity.
Common mistake
Adding a device that is mounted or part of another VG will cause errors or data loss. Always unmount and verify device membership first.
