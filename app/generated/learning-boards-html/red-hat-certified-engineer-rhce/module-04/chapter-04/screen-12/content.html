Module 04 › Chapter 4.4 › Assessment
Question
You have two new disks, /dev/sdd and /dev/sde. Create a Volume Group named web_data_vg that uses both disks.
Write the Ansible task and explain which verification commands you will run after the playbook to confirm success.
Model answer
- name: Create 'web_data_vg' Volume Group from /dev/sdd and /dev/sde
  community.general.lvg:
    vg: web_data_vg
    pvs:
      - /dev/sdd
      - /dev/sde
    state: present
After running, inspect pvdisplay and vgdisplay web_data_vg to confirm the PVs and VG size. Confirm changed: true in registered output for initial creation.
