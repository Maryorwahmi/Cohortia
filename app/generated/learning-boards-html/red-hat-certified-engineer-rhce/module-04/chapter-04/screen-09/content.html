Warning › Safety and mistakes
Common mistakes
  • Initializing a device that contains a filesystem and losing data.
  • Attempting to add a device already in another VG without removing it first.
  • Adding a mounted or in-use device, causing errors or corruption.
Preventive actions
  • Run lsblk and confirm the device is unmounted and unpartitioned.
  • Use pvdisplay and vgdisplay to review current LVM state before changes.
  • Label and document VM disk layouts so playbooks target the correct disks.
Safety Note

If you add a disk that already contains data, lvg will overwrite its headers to initialize it as a PV and the previous data will become inaccessible. Always backup critical data before performing block-level operations.
