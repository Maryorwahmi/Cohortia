Module 4 › Chapter 4.5 › Formatting & Mounting
Step-by-step tasks
Format
Use community.general.filesystem with dev set to /dev/VG/LV and fstype xfs or ext4.
Mount point
Ensure directory exists with ansible.builtin.file before mounting.
Persistent mount
Use ansible.posix.mount with src set to UUID=... for resilient fstab entries.
Verify
sudo blkid -s UUID -o value /dev/data_vg/app_lv
sudo df -h /app_data
Concrete example
- name: Get UUID of /dev/data_vg/app_lv
  ansible.builtin.command: blkid -s UUID -o value /dev/data_vg/app_lv
  register: app_lv_uuid
  changed_when: false

- name: Mount /dev/data_vg/app_lv to /app_data and ensure fstab entry
  ansible.posix.mount:
    path: /app_data
    src: "UUID={{ app_lv_uuid.stdout }}"
    fstype: xfs
    opts: defaults,noatime
    state: mounted
Key Takeaway

Use UUIDs for persistent mounts and verify filesystem size with df after formatting and mounting.
