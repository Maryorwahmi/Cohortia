Logical Volumes with Ansible
Automate LV creation, resizing, snapshots, and filesystem resizing reliably.
In this lesson
Create and manage LVs using community.general.lvol, then format, mount, and resize filesystems safely with Ansible tasks.
Why it matters
LVM makes storage elastic. Automation reduces human error and ensures consistent steps such as filesystem resizing after volume changes.
Explore Key Topics
Create LV
Use community.general.lvol to make a named LV of specified size.
Resize safely
Extend then grow filesystem; shrink filesystem first before LV reduction.
Snapshots
Point-in-time LVs let you backup or mount historic data safely.
Storage Concept Map
Volume Group
Aggregated physical space
Logical Volume
Formatted and mounted like a partition
Snapshot LV
Stores changes since snapshot creation
Automation Highlights
Use community.general.lvol to manage LVs. Follow with filesystem and mount tasks. Always verify with lvdisplay and df -h.
Presentation Mode
Terminal-first demo: playbook + terminal output split. Follow the hands-on activity later in the chapter.
