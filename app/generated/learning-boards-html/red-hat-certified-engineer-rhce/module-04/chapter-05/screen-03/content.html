Module 4 › Chapter 4.5 › How these objectives apply
Scenario cards
Provision new app volume
Create LV, format with ext4, ensure mount at /var/www/html, and add fstab entry.
Scale storage for DB
Extend LV and run resize2fs or xfs_growfs so the database sees additional space immediately.
Create backup snapshot
Snapshot the LV, mount the snapshot, back up files, then remove snapshot LV.
Recover from misstep
If a reduction is miscalculated, restore from backup or snapshot before continuing.
Checks
Confirm VG free space, run lvdisplay, check mount fstype, run df -h after resize, and monitor snapshot usage to avoid overflow.
