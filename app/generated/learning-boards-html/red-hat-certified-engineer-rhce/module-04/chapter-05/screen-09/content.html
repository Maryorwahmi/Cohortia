Module 4 › Chapter 4.5 › Reducing LVs
Safe reduction steps
  1. Create backup or snapshot of the LV.
  2. Shrink the filesystem to target size (for ext4 use resize2fs).
  3. Confirm filesystem fits within new LV size.
  4. Run community.general.lvol with size_reduction: yes to reduce the LV.
  5. Mount and verify data integrity with fsck and application checks.
Warning

Reducing an LV without shrinking the filesystem first will likely cause irreversible data loss.

Example annotation
Assume ext4 filesystem mounted at /data. To reduce from 50G to 30G: unmount if required, run resize2fs /dev/vg_name/lv_name 30G, verify, then reduce with lvol and size_reduction set to yes. Always test on non-production systems first.
Check list
  • Have a current backup or snapshot.
  • Confirm target size < current filesystem size after shrink.
  • Plan maintenance window and notify stakeholders.
