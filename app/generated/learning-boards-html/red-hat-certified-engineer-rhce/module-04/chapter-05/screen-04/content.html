Logical Volume — quick definition
A named block device within a Volume Group that you can format and mount.
Key properties
  • Resizable: extend or reduce (with care).
  • Holds a filesystem such as XFS or ext4.
  • Located at /dev/VG_NAME/LV_NAME.
Concrete example
An LV named app_lv in VG data_vg appears as /dev/data_vg/app_lv and can be formatted and mounted at /app_data.
Key Takeaway

Treat LVs as block devices: automate their creation, then run filesystem commands to make the space usable.

Common misconceptions
  • LV equals filesystem. Correction: LV is a device; filesystem runs on top.
  • Resizing LV auto-resizes filesystem. Correction: you must run xfs_growfs or resize2fs.
  • LVs come directly from disks. Correction: they come from VGs created from PVs.
Quick verification commands
sudo lvdisplay
sudo vgdisplay
sudo lsblk /dev/data_vg/app_lv
df -h /app_data
