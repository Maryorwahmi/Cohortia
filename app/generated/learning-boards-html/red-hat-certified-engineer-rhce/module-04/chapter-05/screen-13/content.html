Module 4 › Chapter 4.5 › Key Concepts
Logical Volume (LV)
A resizable block device carved from a Volume Group to host a filesystem.
Filesystem Resizing
After LV extension, run xfs_growfs or resize2fs so the OS sees added capacity.
Snapshots
Point-in-time LV copies that record changes and let you back up stable data without copying the whole LV.
Summary

Treat LVs as devices, always perform filesystem operations after LV changes, and manage snapshot size and lifecycle carefully.
