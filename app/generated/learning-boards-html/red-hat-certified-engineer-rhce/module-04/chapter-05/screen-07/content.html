Module 4 › Chapter 4.5 › Size: Absolute vs Percentage
Absolute sizes
Specify exact capacity such as 20G or 50G for predictable behavior and capacity planning.
When to use
Databases, dedicated volumes, or when you must ensure consistent size across hosts.
Example
size: 20G
Percentage tokens
Use tokens like 100%FREE to consume remaining free space in a VG; useful for dynamic, single-purpose allocations.
When to use
Ephemeral or single-use volumes where maximum utilization is desired.
Caution
Reserving free space for snapshots or future growth is critical; avoid 100%FREE in production without planning.
Quick check
Run sudo vgdisplay to inspect VG free space before choosing a size token and decide whether to leave a reserve for snapshots.
