Module 4 › Chapter 4.5 › Extend and Grow
Extend LV task
- name: Extend 'app_lv' to 30GB
  community.general.lvol:
    vg: data_vg
    lv: app_lv
    size: 30G
    state: present
After this task completes the block device backing the filesystem is larger, but the filesystem itself still requires resizing.
Resize commands
XFS
xfs_growfs /mount_point — can run while mounted.
ext4
resize2fs /dev/VG/LV — can often run while mounted if the kernel supports it, otherwise unmount.
Check

Run lvdisplay and df -h to confirm the LV size and filesystem size match after resizing.
