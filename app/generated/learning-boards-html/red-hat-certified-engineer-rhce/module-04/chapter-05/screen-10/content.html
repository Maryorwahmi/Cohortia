Module 4 › Chapter 4.5 › LVM Snapshots
Create a snapshot
- name: Create a snapshot of 'app_lv'
  community.general.lvol:
    vg: data_vg
    lv: app_lv_snap
    size: 5G
    snapshot: app_lv
    state: present
This creates app_lv_snap which reflects app_lv at creation time. Mount app_lv_snap to read consistent data for backups.
Snapshot considerations
  • Snapshot size must hold changes — monitor usage to avoid snapshot exhaustion.
  • Snapshots do not duplicate full LV contents; they record differences.
  • Remove snapshots when backup completes to reclaim space.
Key Takeaway

Use snapshots for consistent backups of live data but ensure snapshots have enough space for changes.
