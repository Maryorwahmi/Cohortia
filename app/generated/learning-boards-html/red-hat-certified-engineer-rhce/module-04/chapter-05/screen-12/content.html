Module 4 › Chapter 4.5 › Common Mistakes
Common mistakes and fixes
  • Forgetting filesystem resize after LV extension — run xfs_growfs or resize2fs and verify with df -h.
  • Shrinking LV before filesystem — always shrink filesystem first; have a backup.
  • Snapshot too small — monitor snapshot usage and size accordingly.
  • Incorrect mount path in fstab — use UUID obtained via blkid to avoid device name shifts.
Verification commands
sudo lvdisplay
sudo vgdisplay
sudo lsblk /dev/data_vg/app_lv
df -h /app_data
Remediation flow
If a resize step failed, check the Ansible task output, restore from snapshot if available, and rerun verification commands. For reductions gone wrong, restore from backup and avoid in-place fixes unless you are certain of sizes.
