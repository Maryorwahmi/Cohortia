Module 4 › Chapter 4.3 › Format with community.general.filesystem
Example task
- name: Format /dev/sdb1 with XFS
  community.general.filesystem:
    dev: /dev/sdb1
    fstype: xfs
    force: no
  register: format_result
Registering the result lets you decide to skip future formatting steps, and shows whether change occurred. Keep force at no to avoid accidental destruction.
Teaching notes
  • The module is idempotent: if the device already uses the requested fstype it reports ok and does nothing.
  • Only run format tasks when you are certain the target device is the intended partition.
  • Use conditionals and registered results to format only on the first run or when explicitly required.
Key takeaway
Formatting is powerful and destructive — prefer safety by default and verify results with blkid or filesystem inspection tools after running the task.
