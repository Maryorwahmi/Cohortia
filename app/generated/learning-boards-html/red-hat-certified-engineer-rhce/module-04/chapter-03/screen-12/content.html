Module 4 › Chapter 4.3 › Guided Lab
Lab steps
  1. Ensure /data exists with ansible.builtin.file and mode '0755'.
  2. Format /dev/sdb1 with community.general.filesystem, force: no, register result.
  3. Run blkid to read UUID, register stdout and set changed_when false.
  4. Mount using ansible.posix.mount with src set to the UUID and state mounted.
  5. Set owner, group, and mode on /data after the mount so services can write.
  6. Verify with df -h /data and cat /etc/fstab.
Starter playbook hint
Use the combined example from the chapter as a template. A small challenge: modify the fstype to ext4 and re-run the lab to observe the difference in formatting and UUID generation.
Check your understanding
Why is force set to no the safer default for format tasks? What could happen if you omit checking device identity first?
