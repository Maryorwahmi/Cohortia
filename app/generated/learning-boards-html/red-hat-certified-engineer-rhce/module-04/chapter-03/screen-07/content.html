Module 4 › Chapter 4.3 › Using UUIDs
Get UUID example
- name: Get UUID of the new filesystem for fstab
  ansible.builtin.command: blkid -s UUID -o value /dev/sdb1
  register: sdb1_uuid
  changed_when: false
This command returns just the UUID which you can then insert into the mount src using the UUID prefix for robust fstab entries.
Mount using the UUID
- name: Mount using UUID in fstab
  ansible.posix.mount:
    path: /data_storage
    src: "UUID={{ sdb1_uuid.stdout }}"
    fstype: xfs
    opts: defaults,noatime
    state: mounted
Using UUID equals ensures the mount still works if the kernel renames devices on reboot or after hardware changes.
