Module 4 › Chapter 4.3 › Mounting & fstab
1. Ensure mount point
Use ansible.builtin.file with state directory to create the target path and set owner/group/mode so services can write after mount.
2. Mount and persist
Call ansible.posix.mount with path, src (device or UUID), fstype, opts, and state mounted to ensure current mount and fstab entry.
3. Use nofail when appropriate
If a non-critical device may be missing, include nofail in opts so the system continues booting even if the mount fails.
Example mount task
ansible.posix.mount:
  path: /mnt/data
  src: /dev/sdb1
  fstype: xfs
  opts: defaults,noatime
  state: mounted
Remember to replace src with a UUID for robustness in production, and verify /etc/fstab afterwards.
