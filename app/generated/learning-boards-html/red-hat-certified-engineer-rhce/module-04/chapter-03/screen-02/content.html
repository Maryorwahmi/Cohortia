Learning Objectives
Bloom continuum: Learn → Understand → Apply → Master
Learn → Understand → Apply → Master
01
Format partitions
Use community.general.filesystem to create ext4 or XFS filesystems. Learn the destructive nature of formatting and how idempotence prevents unnecessary changes.
VERIFIED COMPETENCY MILESTONE
02
Mount persistently
Manage /etc/fstab entries and mount state with ansible.posix.mount. Choose states like mounted or present depending on your goal.
VERIFIED COMPETENCY MILESTONE
03
Configure permissions
Adjust owner, group, and mode of mount points after mounting so applications gain the intended access.
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot mounts
Recognize missing mount directories, incorrect device or fstype entries, and use nofail to avoid boot issues while debugging.
VERIFIED COMPETENCY MILESTONE
