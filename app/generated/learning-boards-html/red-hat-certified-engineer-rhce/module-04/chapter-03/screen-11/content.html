Module 4 › Chapter 4.3 › Troubleshooting
Quick checks
  • Does the mount point directory exist?
  • Is the src correct (UUID or device) and fstype accurate?
  • Does /etc/fstab contain the expected entry?
Diagnostic commands
Use mount or df -h to list mounts, blkid to list UUIDs, and cat /etc/fstab to inspect entries. Run mount manually to test a single mount before relying on fstab at boot.
Safety tip
Add nofail to opts if a non-critical filesystem might be missing so the machine can boot while you correct fstab entries.
