Module 4 › Chapter 4.3 › Permissions & Ownership
Best practice
Mount the filesystem first, then run ansible.builtin.file to set owner, group, and mode on the mount point so the settings apply to the mounted filesystem root.
Example: 
- name: Ensure ownership on /mnt/data
  ansible.builtin.file:
    path: /mnt/data
    owner: appuser
    group: appgroup
    mode: '0755'
Common mistake
Applying permissions before mounting. If you change permissions on the underlying directory and then mount, the mounted filesystem's own permissions control access instead.
Key takeaway: sequence tasks so the ownership and mode changes apply to the filesystem itself, not the directory that becomes hidden by the mount.
