Physical disk and partition definition
A physical disk is a raw block device. Partitions divide that device into addressable regions you can format separately.
Common tools
  • fdisk — interactive partitioning
  • parted — scriptable, flexible geometry
  • sfdisk -l — non-interactive partition table listing
Inspection checks
  • Run lsblk or sfdisk to confirm device names and sizes before changing anything.
  • Record which device is intended for automation to avoid accidental data loss.
Key Takeaway

Partitioning separates addressable ranges; formatting creates filesystems and will erase data. Always confirm device identity before automation.

Annotated example
Imagine a new disk at /dev/sdb. You create /dev/sdb1 as a 50GB partition to host application data. That partition must then be formatted with a filesystem before it is mounted.
Misconception
A partition is not a filesystem. Creating a partition does not make it usable until you format it with a filesystem type.
Example checklist before automation
  • Confirm block device path with lsblk.
  • Decide partition size and label.
  • Use parted or community.general.parted in automation for scripting partitions.
