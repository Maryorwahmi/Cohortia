Module 4 › Chapter 4.1 › Learning Objectives — Practical Checks
Objective checks
  • Inspect disks and partitions with lsblk and sfdisk to identify resources before making changes.
  • Create a small playbook that declares a mount at /data and run it against a test host to show reproducible results.
  • Run your playbook twice and confirm the second run reports no changes to demonstrate idempotency.
Quick alignment
Map each task to a module: create partitions with community.general.parted; format filesystems with community.general.filesystem; manage /etc/fstab and mounts with ansible.posix.mount; create LVM groups and volumes with community.general.lvg and community.general.lvol.
