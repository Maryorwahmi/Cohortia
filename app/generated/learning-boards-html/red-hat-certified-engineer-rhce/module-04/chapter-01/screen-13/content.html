Hands-on Activity › Discovering Storage State
Ad-hoc commands to run
Run these commands across your managed nodes to collect the state before you automate any changes.
- ansible all -m ansible.builtin.command -a "df -h"
- ansible all -m ansible.builtin.command -a "lsblk"
- ansible all -m ansible.builtin.command -a "sudo sfdisk -l"
What to look for
  • Unexpected mounts that indicate a device is in use.
  • Device naming differences between hosts that require playbook conditions.
  • Existing partition tables or data that mean you cannot safely format.
