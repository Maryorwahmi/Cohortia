Declare LVM resources
Declare volume groups and logical volumes so the modules create or adjust resources only when needed.
Example tasks
- name: create vg
  community.general.lvg:
    vg: vg_data
    pvs: /dev/sdb,/dev/sdc

- name: create lv
  community.general.lvol:
    vg: vg_data
    lv: lv_data
    size: 100g
Operational notes
  • Resizing logical volumes may require filesystem-aware steps; some filesystems support online resize, others require unmounting.
  • Always avoid shrinking volumes without explicit backups and validation.
  • Test LVM operations in staging to observe behavior and required downtime.
Key takeaway
Ansible's LVM modules let you express logical storage topology and keep it consistent across multiple systems when used with care.
