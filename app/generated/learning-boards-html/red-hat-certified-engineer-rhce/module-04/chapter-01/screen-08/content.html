Code Walkthrough › Ansible modules for partitioning & filesystems
Declarative sequence
The safe order: ensure partition exists, create filesystem if absent, then mount. Each module checks state before changing anything.
Example playbook fragment
- name: create partition
  community.general.parted:
    device: /dev/sdb
    number: 1
    state: present
    size: 50GiB

- name: create filesystem
  community.general.filesystem:
    fstype: xfs
    dev: /dev/sdb1
Practical guidance
  • Use modules instead of shell to maintain idempotency and clearer error messages.
  • Explicitly specify filesystem type to avoid differences across distributions.
  • Include checks or conditions if a partition might hold important data.
Misconception
Wrapping CLI commands in shell tasks loses declarative checks and may perform destructive operations on re-run.
