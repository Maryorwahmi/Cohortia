Architecture › Logical Volume Management
LVM components
LVM composes three layers: physical volumes created from block devices, volume groups aggregating physical volumes, and logical volumes carved from volume groups for filesystems.
Benefits
  • Flexible resizing of logical volumes
  • Combine multiple disks into a single pool
  • Support for snapshots in many workflows
Automation fit
Use LVM modules in Ansible to declare volume groups and logical volumes so that resizing and creation are repeatable and auditable.
Concrete analogy
Imagine combining three small rooms into one large hall and then placing movable partitions where you need smaller rooms. LVM makes the storage pool like that hall and logical volumes like the movable partitions.
Misconception
LVM is flexible but not a substitute for backup. Resizing or removing logical volumes without care can still lose data.
Example flow
  1. Create physical volumes from /dev/sdc and /dev/sdd.
  2. Create a volume group vg_data from those physical volumes.
  3. Create a logical volume lv_data inside vg_data and format it for use.
