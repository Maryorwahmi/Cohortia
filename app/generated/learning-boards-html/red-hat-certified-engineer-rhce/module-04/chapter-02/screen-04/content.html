Module 4 › Chapter 4.2 › Why partitions matter
Definition

A partition is a table entry that reserves a contiguous region on a disk. The kernel exposes these regions as separate device nodes, which you then format and mount.

Example: New disk
New disk appears as /dev/sdb. Create partition -> /dev/sdb1 becomes available for formatting.
Misconception
Creating a partition does not format it. You must run a separate mkfs step.
Key Takeaway

Confirm device identity with lsblk before altering partition tables to prevent accidental damage to the OS disk.

Quick verification commands
# List block devices and partitions
lsblk

# Show partition tables for /dev/sdb
sudo sfdisk -l /dev/sdb
Use these commands before running an Ansible playbook that modifies partitions. They are the fastest way to confirm which device is new and safe to target.
