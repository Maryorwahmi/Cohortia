Module 4 › Chapter 4.2 › Safe workflow
Four steps
1. Verify device identity with lsblk or sfdisk to confirm an unpartitioned disk.
2. Prepare a focused playbook that targets a specific host or group, not all hosts.
3. Run the playbook in check mode to preview changes. Inspect the planned changes carefully.
4. If check mode is acceptable, run normally and verify results with lsblk.
Helpful commands
ansible-playbook create_partition.yml --check
ansible-playbook create_partition.yml
ansible target -m command -a "sudo lsblk"
ansible target -m command -a "sudo sfdisk -l /dev/sdb"
Common Mistake

Running the playbook without check mode or against all hosts can lead to accidental changes to the OS disk. Always scope your runs.
