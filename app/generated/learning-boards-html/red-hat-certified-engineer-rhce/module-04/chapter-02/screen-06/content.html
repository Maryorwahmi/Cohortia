Module 4 › Chapter 4.2 › Playbook Walkthrough
Playbook snippet
---
- name: Configure new disk partitions
  hosts: webservers
  become: yes
  tasks:
    - name: Ensure /dev/sdb has a GPT partition table
      community.general.parted:
        device: /dev/sdb
        number: 1
        state: present
        part_start: 1MiB
        part_end: 100%
      register: parted_result
Run this in check mode first with ansible-playbook --check to preview actions. If the output looks correct, run it without check mode and verify afterward.
Post-run verification
After a real run, confirm the partition exists and that start and end match expectations.
ansible webservers -m command -a "sudo lsblk"
ansible webservers -m command -a "sudo sfdisk -l /dev/sdb"
Key Takeaway

Register module output and verify results with lsblk; these steps make automated partitioning auditable and safer.
