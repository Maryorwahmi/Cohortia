Learning Objectives
Four measurable skills to practice and verify
Bloom: Learn → Understand → Apply → Master
01
Use community.general.parted
Declare device, number, part_start and part_end to create or remove partitions. Practice matters: run a simple task and verify with lsblk.
VERIFIED COMPETENCY MILESTONE
02
Configure partition types
Set part_type for MBR or rely on GPT defaults. Understand primary, extended, and logical partitions when MBR is used.
VERIFIED COMPETENCY MILESTONE
03
Apply safe, idempotent changes
Use check mode, verify target devices, prefer 1MiB start alignment, and back up data before changes.
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot partitioning issues
Recognize overlaps, mismatched partition table types, and accidental device targeting. Practice mitigation patterns.
VERIFIED COMPETENCY MILESTONE
