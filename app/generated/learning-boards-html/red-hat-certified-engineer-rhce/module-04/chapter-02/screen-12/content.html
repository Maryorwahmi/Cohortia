Module 4 › Chapter 4.2 › fs_type vs part_type
fs_type
A partition table hint such as ext4. It does not create a filesystem. Run mkfs separately to format a partition after creation.
part_type & flags
part_type matters for MBR (primary, logical). Flags like boot are table attributes. Set them as needed but understand they are metadata, not filesystems.
Key Takeaway

Separate partition creation and filesystem formatting into distinct, gated tasks. Use register variables to avoid reformatting.
