Module 4 › Chapter 4.2 › GPT vs MBR
GPT
Modern standard. No primary/extended split. Supports many partitions. Safer for large disks and UEFI boot setups.
Practical note: On new disks prefer GPT and start at 1MiB for alignment.
Parted behavior: You can omit part_type and parted will create GPT-style entries.
MBR
Legacy format. Up to 4 primary partitions or 3 primary plus an extended partition containing logical partitions.
Use case: Older systems or special bootloader requirements may require MBR.
Pitfall: You may need to set part_type: primary or logical explicitly when using MBR with parted.
Key Takeaway

Prefer GPT unless you have a specific legacy requirement. Know when to use part_type to meet MBR expectations.
