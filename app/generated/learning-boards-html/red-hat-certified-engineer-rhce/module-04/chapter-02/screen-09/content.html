Module 4 › Chapter 4.2 › Hands-on Activity
Lab steps
  1. Run lsblk on the target node to find the new disk device name.
  2. Create create_partition.yml with the community.general.parted task to create /dev/sdb1.
  3. Run ansible-playbook create_partition.yml --check and review the planned changes.
  4. Run the playbook normally and then verify with lsblk and sfdisk -l /dev/sdb.
Starter playbook
---
- name: Create a new primary partition on /dev/sdb
  hosts: your_target_host
  become: yes
  tasks:
    - name: Ensure /dev/sdb exists and create a single primary partition
      community.general.parted:
        device: /dev/sdb
        number: 1
        state: present
        part_type: primary
        part_start: 1MiB
        part_end: 100%
      register: new_partition_result
Replace your_target_host with the specific inventory name for the VM with the new disk. Run check mode before applying changes.
