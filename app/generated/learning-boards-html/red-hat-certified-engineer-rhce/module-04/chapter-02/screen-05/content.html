Module 4 › Chapter 4.2 › Parted parameters
Parameter reference
  • device: absolute device path, required. Target disk is critical.
  • number: partition index, e.g. 1 for the first partition.
  • part_start / part_end: boundaries, support units such as 1MiB or percentages like 100%.
  • state: present or absent to create or remove partitions.
  • fs_type: partition type hint; does not format the partition.
  • flags: array of flags like boot for partition attributes.
Key Takeaway

Use explicit starts and ends, and treat fs_type as a hint. Always check the module return to confirm intended changes.

Concrete example
 - name: Ensure /dev/sdb has a GPT partition table
   community.general.parted:
     device: /dev/sdb
     number: 1
     state: present
     part_start: 1MiB
     part_end: 100%
     fs_type: ext4
     flags: ['boot']
   register: parted_result
This example sets a single partition spanning the whole disk. Note fs_type is only a hint; you must format the partition afterward for a usable filesystem.
