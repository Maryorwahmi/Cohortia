Module 4 › Chapter 4.2 › Verification Targets
Verification checklist
Playbook Evidence
Show register output after creating /dev/sdb1 and include the parted_result variable to prove change or no-change semantics.
Command Verification
Run lsblk and sfdisk -l to show the new partition and confirm start and end boundaries.
Check Mode
Run ansible-playbook --check to preview changes and compare with the actual run output.
Idempotency
Re-run the playbook; Ansible should report no changes when parameters already match the partition table.
