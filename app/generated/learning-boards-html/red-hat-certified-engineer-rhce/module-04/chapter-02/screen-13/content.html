Question
Create /dev/sdc1 of 10GB starting at 1MiB. What is the correct task?
- name: Create /dev/sdc1 as a 10GB primary partition
  community.general.parted:
    device: /dev/sdc
    number: 1
    state: present
    part_type: primary
    part_start: 1MiB
    part_end: 10GB
Explanation: The task specifies device, number, state present, explicit part_type for MBR intent, and clear start and end boundaries. Run this in check mode before applying.
Key Takeaway

Write explicit parameters and verify with check mode and lsblk to confirm correct partition creation.
