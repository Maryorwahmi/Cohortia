Module 4 › Chapter 4.2 › Key Concepts
Parted parameters
device, number, part_start, part_end and state describe the partition to create or remove.
GPT vs MBR
GPT is preferred for modern systems; MBR has primary/extended/logical semantics you must manage explicitly.
Safety first
Always verify the device, use check mode, scope hosts, and back up data before making changes.
Summary

Manage partition tables declaratively, separate formatting steps, and follow a preview-apply-verify loop to automate safely.
