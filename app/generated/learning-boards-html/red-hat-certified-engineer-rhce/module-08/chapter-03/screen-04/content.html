Module 8 › Chapter 8.3 › Start with interfaces and addresses
Definition
ip a / ip link
Use these commands to see the kernel view of interfaces, their state, and assigned addresses. The kernel's view determines actual connectivity.
$ ip a
1: lo: <LOOPBACK,UP> mtu 65536 qdisc noqueue state UNKNOWN
    inet 127.0.0.1/8 scope host lo
2: eth0: <BROADCAST,MULTICAST> mtu 1500 qdisc fq_codel state DOWN
    link/ether 52:54:00:12:34:56
If eth0 is DOWN, bring it up:
$ ip link set eth0 up
$ ip a
Supporting points
  • ip a shows the kernel's configured addresses and operational states.
  • ip link set can change the link state immediately, but persistent config may need nmcli or network scripts.
  • Always re-test connectivity after changing interface state.
Concrete example
A server with eth0 DOWN after maintenance is fixed by bringing the link up and confirming the expected IPv4 address, restoring service reachability.
Key Takeaway

Interface state is the fastest elimination step. If the interface is down or missing an IP, higher-layer diagnostics are misleading.
