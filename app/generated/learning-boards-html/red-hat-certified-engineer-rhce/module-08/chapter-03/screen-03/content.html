Module 8 › Chapter 8.3 › Learning Objectives
01 • Interfaces
Use ip a to list addresses and ip link set interface up to bring a link online. This is the first step whenever a host is unreachable.
02 • Routing
Read ip r for the kernel routing table and use traceroute to locate where path breaks occur between local and remote hosts.
03 • Sockets (ss)
Run ss -tunap to confirm listening sockets, associated processes, and unexpected socket states that can explain failed connections.
04 • Ansible checks
Write playbooks to gather network facts, run dig, verify ports, and list firewalld rules so diagnostics are consistent across your fleet.
