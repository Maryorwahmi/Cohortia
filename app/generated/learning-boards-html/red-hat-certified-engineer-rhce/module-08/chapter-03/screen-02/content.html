Module 8 › Chapter 8.3 › Learning Objectives
01
Diagnose connectivity
Apply a layered approach to confirm interfaces, IP addresses, and basic reachability using ip and ping. This reduces guesswork and narrows the problem quickly.
VERIFIED COMPETENCY MILESTONE
02
Use advanced utilities
Interpret ss, ip r, nmcli and firewall-cmd output to understand sockets, routing tables, NetworkManager status, and active firewall zones.
VERIFIED COMPETENCY MILESTONE
03
Troubleshoot DNS
Check /etc/resolv.conf, query specific DNS servers with dig or nslookup, and flush local caches when entries appear stale.
VERIFIED COMPETENCY MILESTONE
04
Manage firewall & automate
Inspect firewalld with firewall-cmd, test rules temporarily, reload to apply permanent changes, and capture checks in Ansible playbooks for consistent remediation.
VERIFIED COMPETENCY MILESTONE
