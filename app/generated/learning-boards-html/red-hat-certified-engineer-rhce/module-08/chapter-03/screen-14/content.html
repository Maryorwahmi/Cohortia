Module 8 › Chapter 8.3 › Key Concepts
dig / nslookup
Query specific DNS servers and inspect authoritative answers to isolate resolver vs server problems.
firewalld & firewall-cmd
Inspect zones, test temporary rules, then make permanent changes and reload carefully to avoid lockouts.
ss & Ansible
ss inspects sockets; Ansible automates checks so diagnostics are repeatable and examinable across many hosts.
Summary: Combine these tools in a layered workflow, collect evidence, and only apply persistent changes after validating temporary tests.
