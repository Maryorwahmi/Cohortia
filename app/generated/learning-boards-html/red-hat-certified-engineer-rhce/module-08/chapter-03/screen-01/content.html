Advanced Network Troubleshooting
A practical, layered workflow for diagnosing connectivity, name resolution, routing, firewall, and socket-level problems.
In this lesson

You will follow a step-by-step diagnostic flow using ip, ping, dig, ip r, traceroute, ss and firewall-cmd, then see how to automate those checks with Ansible.

Why it matters

Network problems often surface as application failures. A structured approach reduces mean time to repair and prevents risky ad-hoc changes that can cause outages.

Explore Key Topics
Interface & Connectivity
Use ip a and ping to confirm interfaces and basic reachability; bring links up when necessary.
DNS & Routing
dig, nslookup and ip r/traceroute help separate name problems from path or gateway issues.
Firewall & Sockets
firewall-cmd and ss show whether ports are allowed and services are listening.
