Module 8 › Chapter 8.3 › Scenario: Diagnose DB connectivity
Step-by-step checklist
  1. Check interface state and IP with ip a.
  2. Ping the database by IP to test path.
  3. Ping the database by hostname to test name resolution.
  4. Run dig @ to validate DNS server responses.
  5. Test TCP connectivity: nc -zvw3 dbserver1 3306.
  6. Inspect local sockets with ss -tunap for listening processes.
  7. Check firewalld rules: firewall-cmd --list-all --zone=public when firewalld is active.
# If using the provided playbook:
ansible-playbook diagnose_db_connectivity.yml
Decision grid
Record the first failing layer and act there: interface → DNS → routing → firewall → sockets → application. Fix the lowest failed layer first and re-run the checks.
