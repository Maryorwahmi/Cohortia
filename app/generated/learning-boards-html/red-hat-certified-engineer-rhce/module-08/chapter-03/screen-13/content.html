Module 8 › Chapter 8.3 › Key Concepts
ip a
Displays interfaces and configured IP addresses for kernel-level truth.
ip r
Shows the kernel routing table and whether a default gateway exists.
ping & traceroute
Ping checks reachability; traceroute locates failing hops and latency along the path.
Summary: Use these tools first to form a clear hypothesis about whether the problem lives on the host, on your network, or upstream, before changing persistent configuration.
