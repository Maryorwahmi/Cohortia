Module 8 › Chapter 8.3 › Playbook walkthrough
Playbook excerpt
---
- name: Diagnose Database Connectivity from Webserver
  hosts: webservers
  become: yes
  vars:
    db_host: dbserver1
    db_port: 3306

  tasks:
    - name: Ping database server
      ansible.builtin.ping:
        data: "{{ db_host }}"
      register: ping_result
      ignore_errors: true

    - name: Resolve database server hostname
      command: dig +short {{ db_host }}
      register: dig_result
      changed_when: false
      ignore_errors: true

    - name: Check TCP connectivity to database port
      shell: nc -zvw3 {{ db_host }} {{ db_port }}
      register: nc_result
      changed_when: false
      ignore_errors: true
Supporting explanation
The playbook registers each command result so you can print and analyze them. ignore_errors allows the play to continue gathering data from every host rather than aborting early.
Concrete scenario
Run this playbook from a control host to collect DNS, ping, and TCP connectivity results from webservers. Compare outputs to identify whether failures are local or remote.
Key Takeaway

Use registered outputs to form a remediation plan and avoid making blind changes across production hosts.
