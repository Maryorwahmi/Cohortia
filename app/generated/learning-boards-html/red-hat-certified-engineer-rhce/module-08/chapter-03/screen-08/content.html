Module 8 › Chapter 8.3 › Firewall diagnosis
Commands to try
Check firewalld status and zone rules before changing anything. Test temporary rules and only make them permanent after validation.
$ systemctl status firewalld
$ firewall-cmd --get-active-zones
$ firewall-cmd --list-all --zone=public
$ firewall-cmd --add-service=http   # temporary test
$ firewall-cmd --add-service=http --permanent
$ firewall-cmd --reload
Supporting points
  • Temporary rules allow immediate testing without committing changes that could lock you out.
  • Check the correct zone — services may be allowed in a different zone than the interface is bound to.
  • Always reload after applying permanent changes so the runtime and persistent config align.
Common mistake
Forgetting to reload or adding rules to the wrong zone are common errors that leave the service still blocked.
Safety Note

Test changes in a controlled environment and ensure console or out-of-band access before modifying firewall rules on production hosts.
