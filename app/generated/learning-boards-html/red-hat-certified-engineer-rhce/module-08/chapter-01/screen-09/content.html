Module 8 › Chapter 8.1 › strace
Common strace patterns
strace -p <PID> -e trace=open,read,write,connect
strace -f -o trace.log <command>
Filter calls to reduce noise. Attach to a running process or start the program under strace to capture startup failures.
Interpreting output
  • ENOENT indicates a missing file or incorrect path.
  • EACCES points to permission issues.
  • Connection failures appear in connect or sendto calls.
Example

An app crashes when reading a config. strace shows open returned ENOENT for the path the app attempts. The fix is to correct the path or place the file where expected.

Caution

strace can slow processes. Limit duration and avoid prolonged tracing on critical production workloads unless you plan for impact.

Key Takeaway

Use strace to convert opaque failures into concrete system call evidence you can act on.
