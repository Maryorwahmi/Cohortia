When to use journalctl

Use journalctl to collect unit-specific logs and to read explanatory messages added by services. Apply filters so the output is concise and relevant.

Useful commands
journalctl -u httpd -xe
journalctl --since "20 minutes ago" -p err
journalctl -f -u httpd
The first line filters to the httpd unit with explanatory text and recent entries. The second shows errors since a time window. The third tails live output.
Example

If httpd fails to start, run a time-limited journalctl to capture the error lines that occurred during the attempted start, and save output to a file for analysis.

Notes
  • Use -u to focus on a single service unit.
  • -x adds explanatory text; -e jumps to the end of the journal.
  • Use --since or -S to limit results to a relevant timeframe.
Common mistake

Not filtering the journal makes it hard to find relevant messages. Start narrow, then expand if needed.
