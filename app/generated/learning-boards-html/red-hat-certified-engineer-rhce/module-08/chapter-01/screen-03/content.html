Practical Outcomes
What you will be able to do in the lab
Run targeted commands to confirm service state
Example: use systemctl to check httpd status and journalctl to read recent error messages before restarting.
Diagnose port conflicts and process issues
Use lsof and ps to identify which process is bound to a port and whether the expected daemon is running.
Collect multi-host diagnostics with Ansible
Automate fact gathering so every host produces the same logs, timestamps, and a copy saved on the control node.
Assessment hints
Check your understanding

When a service shows "failed" in systemctl, fetch the unit's recent journal entries with the service filter and include explanatory text to identify likely root cause.

Common mistake

Restarting a service before collecting logs can lose transient messages. Always gather evidence first.

Pro tip

Use timestamped output and store it on the control node so you can compare before and after changes during postmortem review.
