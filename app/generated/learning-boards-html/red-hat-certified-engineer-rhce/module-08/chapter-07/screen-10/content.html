Module 08 › Chapter 8.7 › Provisioning with Ansible
Provisioning concept

Use Ansible to install virtualization packages, create VMs (or configure cloud instances), and perform initial configuration so labs are repeatable.

Example snippet (illustrative)
- name: Create virtual machines
  hosts: localhost
  connection: local
  tasks:
    - name: Ensure virt-install is present
      ansible.builtin.package:
        name: virt-install
        state: present

    - name: Create VM using virt-install command
      ansible.builtin.command: "virt-install --name rhce-node1 --ram 2048 --vcpus 1 --disk path=/var/lib/libvirt/images/rhce-node1.qcow2,size=20G --os-variant rhel8.0"
      ignore_errors: yes
Why automate provisioning

Repeatable lab creation saves time and ensures consistent starting states for practice runs.

Misconception

Full automation of VM install is not always needed. Use a mixed approach: automate post-provisioning and essential steps first.
