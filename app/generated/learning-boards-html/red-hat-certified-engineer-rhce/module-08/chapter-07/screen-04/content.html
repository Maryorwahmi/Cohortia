Module 08 › Chapter 8.7 › Performance-Based Exam
Definition

A test format where candidates perform tasks on live systems; scoring is based on achieving required system states.

Example

Use Ansible to ensure httpd is installed, enabled, and serving a page. Verify by checking the service status and HTTP response.

Key Takeaway

Automation and verification are graded. Make changes via Ansible and confirm results.

Misconception

Many learners think manual fixes earn full credit. They usually do not. Use Ansible where required to demonstrate reproducibility.

Pro-tip: when a task allows manual commands, still prefer a short playbook to capture your work and support verification.
Check your understanding
  • Can your playbook run twice without reporting changes when the system is already configured?
  • Do you verify each change with a factual check on the managed node?
