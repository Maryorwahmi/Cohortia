Module 08 › Chapter 8.7 › No-Internet Practice & Docs
Practice rule

During timed runs, disable general internet access and rely on man, info, and your local docs mirror. This builds accuracy and speed finding exact module parameters.

Concrete exercise

Simulate a firewall task. Use man firewall-cmd to learn syntax, then implement the rule and verify it with firewall-cmd --list-all or a test connection.

Misconception

Memorizing every flag is less effective than knowing how to find them quickly during the exam.

Tip

Keep a small set of tested playbook templates for common tasks and practice adapting them using local docs rather than building from scratch each time.
