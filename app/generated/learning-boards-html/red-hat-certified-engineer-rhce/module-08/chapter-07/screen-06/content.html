Module 08 › Chapter 8.7 › Practice Environment Essentials
Components
  • Control node: run Ansible playbooks and hold inventory.
  • Managed nodes: at least 2–3 VMs to practice multi-host tasks.
  • Snapshot or restore mechanism for clean slate resets.
Why this matters

Multi-node orchestration and reproducibility are core exam skills. A lab that mirrors the exam exposes real issues like inventory or SELinux differences.

Concrete setup example

Use VirtualBox, KVM, or cloud instances. Make node1 and node2 accessible via SSH from the control node, add them to an inventory group, and test with an initial ping playbook.

Remember to practice without web searches—use local documentation and man pages as on exam day.
Misconception

Using a single multi-purpose VM hides multi-host orchestration issues. Practice with separate managed nodes to reproduce exam complexity.
