Module 08 › Chapter 8.4 › Ansible automation
Playbook snippet (diagnostic mode)
- name: Get disk space usage
  ansible.builtin.command: df -h
  register: df_output
  changed_when: false

- name: List active Logical Volumes
  ansible.builtin.command: lvscan --active
  register: lvscan_active_output
  changed_when: false
This approach gathers state safely. For repair automation, include dry-run flags and human approval gates. Never run destructive tasks blindly in production.
Caveat
Unattended unmount + repair can break services. Prefer reporting and guided remediation in production environments.
