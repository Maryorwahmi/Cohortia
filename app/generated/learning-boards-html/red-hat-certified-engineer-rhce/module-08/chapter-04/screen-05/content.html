Module 08 › Chapter 8.4 › df vs du
df (Filesystem view)
Reports allocation using filesystem metadata. Shows blocks used, available, and percent used. Includes files deleted but still open.
du (Directory view)
Sums file sizes in the directory tree. Only counts files that are present in the namespace.
Common diagnostic pattern
1) Run df -h to find full mount. 2) Run du -sh --max-depth=1 on that mount. 3) If totals differ, check for deleted-but-open files with lsof or by restarting services.
Illustrative example
# df shows 100% used on /var
$ df -h /var
Filesystem      Size  Used Avail Use% Mounted on
/dev/mapper/vg01-lvvar  20G   20G     0 100% /var

# du shows less usage because a deleted log is held by a process
$ du -sh /var
8.5G    /var
Misconception
If du is smaller, do not immediately delete files; investigate open file handles first.
Pro-tip
Use lsof +L1 to list deleted files still held open by processes.
