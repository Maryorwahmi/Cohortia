Skill Breakdown and Verifications

Concrete tasks ensure you can prove competency in diagnosis and recovery.

Disk space exercise
Run df -h, then du -sh --max-depth=1 /var. Verify reduced usage with df after cleaning logs or rotated archives.
Device mapping exercise
Run lsblk and fdisk -l and compare the device names to mounted sources. Confirm no unexpected devices are missing.
Filesystem repair exercise
On a test disk, unmount and run xfs_repair -n for a dry run. Only proceed with live repair when you have a backup.
LVM automation exercise
Run pvscan/vgscan/lvscan and then the example Ansible playbook to collect outputs from multiple hosts for review.
