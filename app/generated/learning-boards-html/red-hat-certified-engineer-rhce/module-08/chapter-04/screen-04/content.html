Module 08 › Chapter 8.4 › Inspecting filesystem usage
Command primer
df -h
# shows mounted filesystems and usage

du -sh --max-depth=1 /var
# summarizes top-level directories under /var

du -sh /var/log
# size of a specific directory
Example scenario
df -h reports /var at 100%. Running du finds /var/log/apache2 as the largest directory. Rotate or archive large logs and then confirm with df.
Explanation and common mistakes
  • df uses filesystem metadata; du sums file sizes. They may differ when files are deleted but still open.
  • Always capture outputs before making changes so you can audit what was present.
  • Be cautious removing files in system directories; consider archiving or rotating logs instead.
Analogy
df is the mailbox count; du is counting individual letters in folders.
Key Takeaway
Use both tools together and check for open-deleted files when results differ.
