Module 08 › Chapter 8.4 › Inspecting block devices
Primary commands
# tree of block devices
lsblk

# detailed partition table
fdisk -l

# modern partition tool output
parted -l
Cross-check lsblk with findmnt or /etc/mtab so you know which device backs which mount point. Save outputs for auditing and recovery plans.
Example output snippet
NAME            MAJ:MIN RM  SIZE RO TYPE MOUNTPOINT
sda               8:0    0  100G  0 disk 
├─sda1            8:1    0    1G  0 part /boot
└─sda2            8:2    0   99G  0 part 
  └─vg01-lvroot 253:0    0   90G  0 lvm  /
Warning
Do not repartition a device until you have verified the mapping and taken backups; partitioning can destroy data.
