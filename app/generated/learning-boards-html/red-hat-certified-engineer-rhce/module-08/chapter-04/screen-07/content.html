Module 08 › Chapter 8.4 › Detecting disk failure
Check kernel messages
dmesg | grep -i -E "error|fail|i/o"
# look for repeated I/O errors and sector failures
Repeated I/O errors in dmesg are a strong indicator of failing hardware. Record the messages and plan to migrate data off the device.
Query S.M.A.R.T.
smartctl -a /dev/sda
# reviews attributes like reallocated sectors and overall-health
Action
If S.M.A.R.T. shows degrading metrics, schedule replacement and migrate data with LVM or block-level tools rather than relying on repeated repairs.
