Module 08 › Chapter 8.4 › fsck and ext4
Command example
# check without making changes (varies by distro)
fsck.ext4 -n /dev/sda1

# run repair (destructive) after backup
fsck.ext4 -y /dev/sda1
fsck can prompt for fixes. Use -n for a non-destructive check if supported, and -y to answer yes to prompts when you have validated the plan beforehand.
Checklist before fsck
  • Back up or snapshot the device.
  • Unmount the filesystem or enter rescue mode.
  • Run a safe, non-destructive check first.
  • Apply repairs only after confirming expected changes.
