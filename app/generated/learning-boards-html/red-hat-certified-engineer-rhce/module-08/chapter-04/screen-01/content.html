Storage and Filesystem Recovery

Understand inspection commands, repair tools, and LVM troubleshooting. Focus on safe steps to preserve data while restoring service.

Duration: ~14 minutes
In this lesson
Diagnostic commands, LVM hierarchy, filesystem repair safety, and automation via Ansible.
Why it matters
Prevent data loss and downtime by following correct diagnosis and repair steps on production systems.
Explore Key Topics
Disk space inspection
Use df and du to find where space is used and when processes hold deleted files.
Filesystem repairs
xfs_repair and fsck must run on unmounted filesystems; back up first.
LVM troubleshooting
Trace missing LVs to VGs and PVs, and activate VGs carefully with vgchange.
Visual overview
Storage Layers
PV → VG → LV → filesystem. Knowing the layer where a fault occurs is key to safe recovery.
Quick commands
df -h · du -sh · lsblk · pvscan · vgscan · lvscan · xfs_repair · fsck
Getting started

Start by collecting system state: df for mounted usage, lsblk for device layout, and lvscan/vgscan to confirm LVM health. Always plan backups before repair.
