Module 8 › Chapter 8.6 › Learning Objectives
01
Identify optimization opportunities
Learn to recognise bottlenecks by collecting metrics and logs so you can target changes where they matter most. This helps avoid speculative tuning that may not improve performance.
Mnemonic: baseline → change → compare
VERIFIED COMPETENCY MILESTONE
02
Configure kernel parameters with sysctl
Use sysctl to tune networking and memory-related kernel settings, test changes at runtime, and persist the ones that help.
Mnemonic: sysctl -a, sysctl -w, /etc/sysctl.d/
VERIFIED COMPETENCY MILESTONE
03
Manage resource limits with ulimit and systemd
Set per-user and per-process limits to protect the system. Use limits.conf for sessions and systemd unit directives for services to be specific and reliable.
Mnemonic: soft/hard limits → services use systemd
VERIFIED COMPETENCY MILESTONE
04
Implement cron jobs for maintenance
Schedule log rotation, temporary file cleanup, and data collection. Always use absolute paths and account for cron's minimal environment.
Mnemonic: crontab -e and /etc/cron.daily
