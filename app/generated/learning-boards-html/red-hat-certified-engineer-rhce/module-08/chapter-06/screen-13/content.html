Process Flow › Testing & Rollback
Verification checklist
  • Re-run the baseline metrics under comparable load.
  • Query sysctl for the parameter you changed and confirm the value.
  • Check /etc/security/limits.conf or use su to verify ulimit for the target user.
  • Confirm systemd services restarted and effective limits are applied.
Automate verification with follow-up Ansible tasks that assert state or gather metrics and fail the run if checks do not pass.
Rollback plan
Keep a versioned copy of previous config and an Ansible playbook that restores it. Test the rollback in staging to ensure it returns the system to a healthy state quickly.
