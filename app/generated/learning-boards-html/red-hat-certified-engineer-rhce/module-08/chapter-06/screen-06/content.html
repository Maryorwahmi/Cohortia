Process Flow › Applying sysctl changes
Step-by-step
  1. Collect baseline: sysctl -a and relevant socket/file metrics.
  2. Apply temporary change: sysctl -w name=value and observe under load.
  3. If successful, create /etc/sysctl.d/99-custom-settings.conf with the parameter line.
  4. Apply persistent config: sysctl --system and re-run your tests.
  5. Document the change and keep a rollback plan.
Common mistake: changing many kernel parameters at once or skipping verification under realistic load. Always change one variable at a time and monitor the same metrics you recorded in the baseline step.
Concrete example
# temporary
sysctl -w net.core.somaxconn=65536

# persistent file: /etc/sysctl.d/99-custom-settings.conf
net.core.somaxconn = 65536

# apply
sysctl --system
