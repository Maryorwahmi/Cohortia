Core Concept › cron for automated maintenance
cron essentials
Use crontab -e for per-user jobs or /etc/cron.daily for system-wide daily tasks. Always prefer absolute paths and explicit environment settings to avoid surprises.
Example cron job
0 3 * * * /usr/local/bin/cleanup_web_logs.sh >> /var/log/web_cleanup.log 2>&1
Troubleshooting tips
  • Check that scripts are executable and have a correct shebang.
  • Use absolute paths for commands and files.
  • Capture output to logs for auditing and debugging.
Common mistake

Scripts work interactively but fail under cron because they rely on user environment variables or relative paths.
