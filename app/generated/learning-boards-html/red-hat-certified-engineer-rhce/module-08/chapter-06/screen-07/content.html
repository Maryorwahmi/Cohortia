Definition › ulimit and limits.conf
What ulimit controls
ulimit shows and sets resource limits for the current shell and child processes, including open files and process counts. Use it to protect the system from runaway processes that exhaust descriptors or memory.
Example usage
ulimit -a
ulimit -n 65536
Persisting limits
Edit /etc/security/limits.conf or add a file to /etc/security/limits.d/ with entries such as:
dbuser soft nofile 65536
dbuser hard nofile 65536
Remember that services started by systemd may not inherit these settings and should be configured at the unit level where appropriate.
