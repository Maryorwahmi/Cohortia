Learning Objectives

Bloom goals: Learn → Understand → Apply → Master

01
Apply Ansible end-to-end
Compose a playbook that configures hosts, services, storage and security. Practice matters because exam tasks combine domains, requiring reliable sequences.
Mnemonic: Venn of services + storage
VERIFIED COMPETENCY MILESTONE
02
Integrate troubleshooting & optimization
Use check mode, syntax checks, and incremental tests to find issues early and reduce cascading failures during a lab run.
Mnemonic: timeline of build → test → verify
VERIFIED COMPETENCY MILESTONE
03
Manage services, storage, and security
Demonstrate tasks such as LV creation, filesystem formatting, SELinux context configuration, and firewall rules using the right modules.
Mnemonic: layered stack icons
VERIFIED COMPETENCY MILESTONE
04
Review and build confidence
Perform a post-lab review: what worked, what failed, and which topics need targeted practice to prepare for the exam.
Mnemonic: checklist icon
VERIFIED COMPETENCY MILESTONE
