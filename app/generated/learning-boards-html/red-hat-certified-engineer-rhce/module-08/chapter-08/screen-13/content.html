  • SSH to dbserver1: systemctl status mariadb, firewall-cmd --list-all, mysql -u webapp_user -pwebapp_pass -h <webserver_ip> webapp_db -e "SELECT 1;"
Debug flow
  1. Find the first failing task in playbook output.
  2. Run the equivalent manual command on the host to observe real errors.
  3. Fix the root cause, document it, and re-run the targeted playbook section.
