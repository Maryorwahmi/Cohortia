Process › Webserver Tasks
Core tasks to implement on webserver1
  • Ensure httpd is installed, running, and enabled using ansible.builtin.systemd.
  • Create an LVM logical volume webapp_data (5G) in vg_app and format it with XFS.
  • Create /srv/webapp, mount the LV persistently, and deploy index.html with copy.
  • Set SELinux file contexts with ansible.posix.sefcontext and notify restorecon handler.
  • Open HTTP in firewalld and create webadmin user and sudoers file for restart privileges.
Common mistake
A 403 error after deployment usually indicates SELinux context is missing or restorecon handler did not run. Always include sefcontext and a handler.
Task examples (excerpt)
- name: Ensure httpd is installed, running, and enabled
  ansible.builtin.systemd:
    name: httpd
    state: started
    enabled: yes
  when: inventory_hostname == 'webserver1'

- name: Create webapp_data Logical Volume
  community.general.lvol:
    vg: vg_app
    lv: webapp_data
    size: 5G
    state: present
  when: inventory_hostname == 'webserver1'

- name: Deploy index.html
  ansible.builtin.copy:
    content: "Hello from WebApp!"
    dest: /srv/webapp/index.html
    mode: '0644'
Example verification
curl http://localhost/index.html should return "Hello from WebApp!" and ls -Zd should show httpd_sys_content_t.
Pro tip
Run restorecon -Rv /srv/webapp as a handler after sefcontext changes instead of running it unconditionally to preserve idempotence.
Key Takeaway
Order matters: storage and mount must exist before file deployment, and SELinux contexts must be correct for httpd to serve non-standard paths.
