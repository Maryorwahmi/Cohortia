Module 8 › Chapter Final Lab › Firewall Scoping
A: Enable service globally
Less secure
Enabling the MariaDB service opens port 3306 across the zone. This is simple but allows any host in the zone to attempt connections. Use only when broad access is intended.
B: Allow port with source restriction
Recommended for DB
Using source: "{{ webserver_ip }}" restricts access to only the web server. This reduces attack surface and matches the lab requirement to permit only webserver1.
Playbook excerpt
- name: Configure firewalld to allow MariaDB from webserver1 on dbserver1
  ansible.posix.firewalld:
    port: 3306/tcp
    permanent: yes
    state: enabled
    zone: public
    source: "{{ webserver_ip }}"
  when: inventory_hostname == 'dbserver1'
  notify: Reload firewalld on dbserver1

# Verification from control node:
# mysql -u webapp_user -pwebapp_pass -h 192.168.122.11 webapp_db -e "SELECT 1;"
Test
Test connectivity from webserver1's IP with the mysql client to validate the rule.
Troubleshoot
If blocked, check zone, source syntax, and that firewalld was reloaded by the handler.
