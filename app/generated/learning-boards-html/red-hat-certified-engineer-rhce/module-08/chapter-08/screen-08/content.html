Process › Database Tasks
Essential steps on dbserver1
  • Ensure mariadb is installed, running, and enabled.
  • Create webapp_db using community.mysql.mysql_db.
  • Create webapp_user with password webapp_pass and grant privileges on webapp_db but limit host to webserver_ip.
  • Open 3306/tcp in firewalld only for source webserver_ip and reload the firewall via a handler.
Common mistake
Allowing 3306 globally instead of limiting by source makes the DB accessible to hosts that should not have access and is a security risk.
Task snippet
- name: Ensure mariadb is installed, running, and enabled
  ansible.builtin.systemd:
    name: mariadb
    state: started
    enabled: yes
  when: inventory_hostname == 'dbserver1'

- name: Configure firewalld to allow MariaDB from webserver1
  ansible.posix.firewalld:
    port: 3306/tcp
    permanent: yes
    state: enabled
    zone: public
    source: "{{ webserver_ip }}"
  when: inventory_hostname == 'dbserver1'
Verification
From webserver1: mysql -u webapp_user -pwebapp_pass -h <dbserver_ip> webapp_db -e "SELECT 1;" should succeed.
Pro tip
Test firewall source values with firewall-cmd --list-all on dbserver1 to confirm the rule includes the intended webserver IP.
Key Takeaway
Limit database access by source IP and verify connectivity from the authorized host to prove correct network-level security.
