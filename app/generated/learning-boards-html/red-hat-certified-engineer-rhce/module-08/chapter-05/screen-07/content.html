Module 8 › Chapter 8.5 › Troubleshooting web servers vs databases
Web server checklist (Apache/Nginx)
  • Run apachectl configtest or nginx -t to catch syntax errors.
  • Confirm listening ports: ss -tunap | grep :80
  • Verify document root exists and is readable by the server user.
  • Check SELinux context and audit.log for AVC denials.
Concrete command
apachectl configtest
ss -tunap | grep :80
ls -l /var/www/html
ls -Zd /var/www/html
Database checklist (MariaDB/PostgreSQL)
  • Check service status and server logs for startup errors.
  • Test client connectivity from the app host to isolate network vs credentials.
  • Validate database user privileges for the application account.
Concrete command
systemctl status mariadb
# Example client test
mysql -u appuser -p -h 127.0.0.1
