01
Diagnose systemd services
Run and interpret systemctl status and use journalctl to dig into failures; this skill helps you know why a service is not running.
VERIFIED COMPETENCY MILESTONE
02
Analyze application logs
Locate application logs, use tail, grep, and timestamps to correlate errors with events and reproduce failures safely.
VERIFIED COMPETENCY MILESTONE
03
Troubleshoot web & DB services
Check config syntax, listening ports, document roots, client connectivity, and database user permissions to isolate failures.
VERIFIED COMPETENCY MILESTONE
04
Automate checks with Ansible
Use systemd, fetch, and command tasks to collect service status, logs, and SELinux context across multiple hosts for centralized analysis.
