Module 8 › Chapter 8.5 › Scenario walkthrough: intermittent 'Forbidden' and blank pages
Terminal checklist
  1. systemctl status httpd
  2. journalctl -u httpd -xe
  3. tail -f /var/log/httpd/error_log while reproducing
  4. ls -l /var/www/html && ls -Zd /var/www/html
  5. firewall-cmd --list-all --zone=public
Decision guide
If logs show permission denied: check ownership, apply correct permissions, then verify SELinux context.
If audit.log shows AVC denials: use semanage fcontext and restorecon to set the correct context and re-test.
If configtest fails: fix syntax, then restart and confirm with journalctl.
Common Mistake
Applying broad permission changes like chmod 777 masks root causes and weakens security; prefer targeted ownership and SELinux fixes.
