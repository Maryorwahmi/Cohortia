Module 8 › Chapter 8.5 › Assessment: interpret logs and choose the next command
Practice question
A service is reported as failed. Which command gives the most detailed information about why it failed? Use journalctl -u <service> -xe to find the startup error and copy the first error lines into your report.
Why this matters
Focused journal queries avoid noise and point directly to ExecStart errors, missing dependencies, port bind failures, or SELinux denials.
Assessment steps
  1. Run systemctl status and note the state and timestamp.
  2. Run journalctl -u <service> -xe and capture the first error lines.
  3. Locate the application error_log and save the matching timestamped lines.
Key Takeaway
Assessments should validate your ability to pick the most diagnostic command and collect evidence, not to guess remedies without logs.
