Module 8 › Chapter 8.5 › SELinux and firewall: frequent causes of inaccessibility
Firewalld checks
# Inspect public zone rules
firewall-cmd --list-all --zone=public

# Ensure http and https services are allowed
# or check open ports
ss -tunap | grep :80
If http/https are missing from allowed services, add them with firewall-cmd --add-service= http --permanent and reload. Always verify after reload.
SELinux checks
  • Check file context: ls -Zd /var/www/html
  • Review AVC denials: /var/log/audit/audit.log for messages labeled avc
  • Temporary test: setenforce 0 to see if access is restored (diagnostic only)
Common Pitfall
Don't leave SELinux disabled. Use semanage fcontext and restorecon to set correct contexts as a permanent fix.
