Module 8 › Chapter 8.5 › Application logs: where to look and how to parse them
Common locations
  • /var/log/httpd/ — Apache access_log and error_log
  • /var/log/mariadb/ or /var/log/mysql/ — database server logs
  • Application-specific directories under /var/log or within app install path
Useful commands
# Follow errors live
tail -f /var/log/httpd/error_log

# Get last 100 lines
tail -n 100 /var/log/httpd/error_log

# Filter for errors
grep -iE "error|fail|exception" /var/log/httpd/error_log
Example scenario
While reproducing a blank page, you run tail -f on the Apache error_log and see a permission denied entry with matching timestamp. That shows the server process couldn't read a file. Next steps include ls -l to check ownership and ls -Zd to check SELinux context.
Pro Tip
Use grep with a time range or use awk to extract timestamps so you can correlate application logs with journalctl entries and firewall events.
