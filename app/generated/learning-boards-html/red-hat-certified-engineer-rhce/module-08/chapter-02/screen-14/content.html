Module 8 › Chapter 8.2 › Key Concepts
CPU Bottleneck
High CPU use or load averages > cores indicate compute contention.
Memory Bottleneck
Active swap in vmstat (si/so) signals memory pressure and performance loss.
Disk I/O Bottleneck
High %util and await in iostat point to storage saturation and latency.
Summary
Form hypotheses from these signals, automate collection, change one thing, and remeasure to verify impact.
