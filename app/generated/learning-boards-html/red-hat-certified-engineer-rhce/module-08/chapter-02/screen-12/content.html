Interpret outputs — examples
Use metric evidence to answer diagnostic questions concisely.
Question 1
Top shows wa > 50% regularly. What is the primary bottleneck?
Answer: Disk I/O. High wa means CPU waits for I/O; target storage latency or queueing.
Question 2
vmstat shows consistent si and so activity. What does that imply?
Answer: Active swapping and memory pressure; add RAM or reduce memory usage and re-measure.
Write a diagnostic note
Observed: iostat %util ~98% and await 40ms. Diagnosis: storage device saturated causing high latency and process waits. Immediate action: move hot files to faster storage or reduce I/O during peak. Re-measure: run iostat -x 1 60 before and after the change to compare await and %util.
Key Takeaway
Answer diagnostics by citing metrics, providing a targeted remediation, and specifying how to verify the result.
