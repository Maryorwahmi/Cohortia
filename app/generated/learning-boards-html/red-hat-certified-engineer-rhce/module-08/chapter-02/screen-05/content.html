Definition
Load average vs I/O wait
Understand the numeric meaning and practical implications for troubleshooting.
Quick comparison
Load average
Average runnable processes over time. Compare to CPU core count.
I/O wait (wa)
Percent of CPU time waiting for I/O. High values point to disk or storage latency.
Key Takeaway

Always compare load average to the number of cores and verify high wa with iostat or vmstat before changing hardware.

Example scenario
A 4-core VM shows load averages 6.2, 5.8, 5.0 and %Cpu(s): 5 us, 2 sy, 92 id, 1 wa. Here, load > cores but CPU is mostly idle. The explanation is blocked processes waiting on disk or swap, making the run queue longer while CPU remains idle waiting for I/O. Resolve by measuring disk latency and queue depth with iostat.
Misconception check
Don't assume low user CPU means healthy: idle time can hide long I/O waits. Always corroborate multiple metrics.
