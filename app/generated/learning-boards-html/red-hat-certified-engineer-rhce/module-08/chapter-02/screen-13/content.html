Best Practice
From evidence to action
A safe checklist to implement changes with confidence.
  1. Document baseline metrics and timestamp before changes.
  2. Pick one targeted, reversible change.
  3. Apply change during a controlled window.
  4. Rerun identical measurements and compare to baseline.
Key Takeaway
Single, reversible changes with before/after measurements create reliable, learnable operations.
Example actions by bottleneck
  • CPU bound: profile processes, reduce concurrency, or scale CPU resources.
  • Memory pressure: reduce caches, fix leaks, or add RAM.
  • Disk I/O: reschedule jobs, move hot data, or increase storage performance.
After any change, run the same iostat/vmstat/sar samples used originally to confirm whether the measured symptom improved.
