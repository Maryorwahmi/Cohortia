Definition
Memory signals and swapping
When the system moves pages to swap, performance typically drops sharply.
$ free -h total used free shared buff/cache available Mem: 32G 20G 8G 512M 4G 11G Swap: 4G 1G 3G $ vmstat 1 5 procs -----------memory---------- ---swap-- -----io---- -system-- ------cpu----- r b swpd free buff cache si so bi bo in cs us sy id wa 1 0 1048576 8388608 1024 4194304 50 30 0 10 100 200 30 10 40 20
Key Takeaway
Consistent si/so values mean active swapping; increasing RAM or reducing memory usage is needed.
Concrete example
A web server serving many large in-memory caches may push a VM into swap during peak traffic. Check vmstat si/so; if swap activity is frequent, reduce cache size or increase RAM.
Misconception
Swap presence alone is not always bad; brief swap use is acceptable. It's the sustained, frequent swap activity that causes thrashing and visible slowdowns.
