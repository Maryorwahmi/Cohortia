Monitoring database servers
Follow a repeatable workflow to collect and compare samples across hosts.
# Run the playbook ansible-playbook monitor_db_performance.yml # After completion, check: ./performance_reports//vmstat_.log ./performance_reports//iostat_.log
Open the vmstat file to inspect si and so for swapping. Open the iostat file to check %util and await. Correlate timestamps with application logs to match slow periods.
Scenario tips
  • Collect during peak operations to capture realistic load.
  • Keep file naming consistent to ease automated parsing later.
  • When unsure, widen sample duration before concluding.
Key Takeaway
Collect consistent, timestamped logs and compare them to determine whether CPU, memory or disk correlates with the slowdown.
