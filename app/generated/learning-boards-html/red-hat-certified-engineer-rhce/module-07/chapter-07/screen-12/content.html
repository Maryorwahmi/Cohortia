Module 8 › Chapter 7.7 › Secrets Management
Recommended approach
Encrypt secrets with Ansible Vault and commit the encrypted file to Git. Keep the vault password in CI secret storage and provide it at pipeline runtime.
Why this matters
This prevents plaintext secrets in the repository and limits the decryption key exposure to the secure pipeline environment only.
Practical note
Pass the vault password using the CI platform's secret variables and use process substitution or a temporary file at runtime. Do not persist the password to disk or logs.
