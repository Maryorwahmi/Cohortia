Module 8 › Chapter 7.7 › Integration Testing
Why integration tests

Integration tests exercise roles against a real or simulated system to validate runtime behavior that static checks cannot verify.

Molecule can provision containers, run roles, and run assertions to confirm services and files are set correctly.
Pipeline placement
Run integration tests after linting and quick checks because they are slower. Use them for roles that change services, packages, or network configuration.
Note
Integration tests increase confidence but require maintenance. Keep scenario definitions small and focused to reduce flakiness.
