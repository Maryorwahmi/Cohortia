Module 8 › Chapter 7.7 › ansible-lint
What it does

ansible-lint analyzes playbooks and roles against a set of rules to detect style issues and anti-patterns that may cause problems when run at scale.

Enforces consistent variable naming and task structure.
Flags potential idempotency problems and deprecated modules.
Configurable rules let teams align linting with their standards.
CI integration
Run ansible-lint as an early pipeline step. Fail the stage on critical violations so contributors fix issues before merge.
Example
A shell task that overwrites configuration might be flagged and suggested to be replaced with a dedicated module that preserves idempotency.
