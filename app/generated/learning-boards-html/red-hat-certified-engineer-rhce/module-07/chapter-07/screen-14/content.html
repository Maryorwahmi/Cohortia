Module 8 › Chapter 7.7 › Best Practices
Idempotency
Ensure tasks reach a desired state without causing side effects when run multiple times.
Modularity
Break automation into small roles to improve reuse and simplify testing and reviews.
Environment separation
Use distinct inventories and variable files for dev, staging, and prod to avoid mixing configurations.
Practical note
Design roles so they accept variables and do not assume a single environment. This makes the same role reusable across inventories and pipeline stages.
