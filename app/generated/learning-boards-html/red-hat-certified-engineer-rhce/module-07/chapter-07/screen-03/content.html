Module 8 › Chapter 7.7 › Skills You Will Demonstrate
Four verification tasks
  1. Initialize a Git repository, commit playbooks and roles, and push a feature branch for a change.
  2. Configure CI to run ansible-lint and a playbook syntax check on PRs to catch style and syntax errors.
  3. Run a dry run with the check mode and diff to show what would change without applying it.
  4. Store the vault password in CI secrets and pass it at runtime so encrypted variables are decrypted only in the pipeline.
Quick mnemonic
Think: Commit → Validate → Simulate → Deploy. Each step is automated in CI and reviewed before merge.
Verified competency milestone
Run the CI checks for a sample playbook and review the pipeline logs to confirm the expected outputs and any linting warnings.
