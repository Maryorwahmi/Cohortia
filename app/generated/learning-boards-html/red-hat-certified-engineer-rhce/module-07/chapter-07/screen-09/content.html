What check mode does

Check mode simulates task execution and, with diff enabled, shows the exact changes that would be made to files or configurations without applying them.

Use check mode in CI to verify intended outcomes and avoid accidental production changes.
Limitation and note
Not all modules fully support check mode; if a module lacks support, the dry-run might be incomplete. Always validate critical changes with integration tests when possible.
Example
Running a dry run after editing index.html shows the diff of the file content to confirm the intended change without touching the server.
