Module 07 › Chapter 7.2 › Key Concepts
Role Dependencies
Declare other roles in meta/main.yml so they run first and provide required setup.
Handlers
Special tasks that run only when notified and only once at the end of a play.
notify & listen
Tasks use notify with a string that must match the handler's listen value to queue that handler on change.
One-line takeaway

Compose roles with dependencies and use handlers for safe, change-driven operations to keep automation idempotent and predictable.
