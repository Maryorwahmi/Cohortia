Learning Objectives
Walk through the configuration and reasoning so you can apply dependencies and handlers safely.
01
Configure role dependencies

Declare dependent roles in meta/main.yml so prerequisites run first. This prevents missing components from breaking subsequent tasks.

VERIFIED COMPETENCY MILESTONE
02
Explain handler lifecycle

Describe why handlers run only when notified and why they execute once at the end of a play. This preserves service availability.

VERIFIED COMPETENCY MILESTONE
03
Implement notify statements

Use notify in tasks to trigger handlers by their listen name when a task reports changed. This ties actions to real changes.

VERIFIED COMPETENCY MILESTONE
04
Design idempotent handlers

Write handlers that safely restart or reload services only when necessary and test them in staging to avoid interruptions.
