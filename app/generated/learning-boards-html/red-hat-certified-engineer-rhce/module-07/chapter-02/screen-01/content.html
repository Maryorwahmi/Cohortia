Role Dependencies and Handlers
Compose roles with meta/main.yml and react to changes safely with notify/listen handlers.

You will understand how to declare prerequisites so roles run in a safe order, and how to use handlers to perform actions such as service restarts only when a change happens. These features keep playbooks idempotent and reduce unnecessary restarts.

Visual Concept
Role dependency: webserver → common_packages
Handler: Restart Nginx only when config changed
Outcome: predictable order and fewer restarts
In this lesson
Role Dependencies
How to declare dependent roles in meta/main.yml to guarantee execution order.
Handlers
Define handlers with listen and trigger them with notify when tasks change state.
Best Practices
Avoid circular dependencies, design idempotent handlers, and test in staging.
