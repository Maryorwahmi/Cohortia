Architecture: Role graph to execution list
Role Graph (concept)
webserver depends on common_packages and firewall; database depends on storage.
common_packages
firewall
webserver
Flattened Execution
  1. Run common_packages tasks
  2. Run firewall tasks
  3. Run webserver tasks
Why this matters

Ensures prerequisites like packages and ports exist in time for dependent configuration, reducing runtime failures.

Misconception

Roles do not run concurrently by default; order is important and derived from the dependency graph.

Check

Run the playbook and inspect output to validate the expected execution order and ensure no circular dependency error appears.
