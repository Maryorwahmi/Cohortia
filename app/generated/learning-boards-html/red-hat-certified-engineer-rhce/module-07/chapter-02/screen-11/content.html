Module 07 › Chapter 7.2 › Hands-on Activity
Step 1 — common_packages
# common_packages/tasks/main.yml
---
- name: Ensure common utilities are installed
  ansible.builtin.dnf:
    name:
      - vim
      - git
      - curl
    state: present
Step 2 — webserver meta and handler
# webserver/meta/main.yml
dependencies:
  - role: common_packages

# webserver/handlers/main.yml
---
- name: Restart Nginx
  ansible.builtin.service:
    name: nginx
    state: restarted
  listen: "Restart Nginx"
Run and verify
  1. Create deploy_full_stack.yml that applies the webserver role.
  2. Run ansible-playbook and confirm common_packages runs before webserver.
  3. Edit the template to change content, re-run, and confirm handler runs once.
