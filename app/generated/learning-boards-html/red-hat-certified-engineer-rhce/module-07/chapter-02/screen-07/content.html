Module 07 › Chapter 7.2 › Notify a Handler from a Task
tasks/main.yml (snippet)
---
- name: Copy Nginx configuration template
  ansible.builtin.template:
    src: nginx.conf.j2
    dest: /etc/nginx/nginx.conf
    owner: root
    group: root
    mode: '0644'
  notify: "restart_nginx_service"
The notify string must match the handler listen name exactly.
handlers/main.yml (snippet)
---
- name: Restart Nginx
  ansible.builtin.service:
    name: nginx
    state: restarted
  listen: "restart_nginx_service"
Handlers with listen act as targets for notify strings from tasks.
Example
Modify nginx.conf.j2, run the playbook, and observe that the template task shows changed and the handler runs once at the end.
Misconception
Assuming notify triggers a handler even when a task reports ok. Handlers are queued only on changed.
Key Takeaway
Match notify to listen and prefer modules that accurately report changed to avoid unwanted handler runs.
