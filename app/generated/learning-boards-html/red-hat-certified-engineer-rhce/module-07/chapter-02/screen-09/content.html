Module 07 › Chapter 7.2 › Designing Idempotent Handlers
Recommended pattern
Use a single restart or reload that expresses the final intent and lets the service manager act gracefully.
- name: Restart Nginx
  ansible.builtin.service:
    name: nginx
    state: restarted
  listen: "restart_nginx_service"
Avoid this
Avoid separate stop and start operations inside handlers since they increase risk and are not as atomic as restart.
Example
If only a reload is required, use state: reloaded or the module's reload action to avoid full restarts.
Test
Validate handler behavior in staging, ensuring single-run semantics and safe state transitions.
Key Takeaway
Keep handler actions minimal, idempotent, and reversible when possible to reduce production risk.
