Module 07 › Chapter 7.2 › What Are Handlers?
Handler characteristics
  • Defined in handlers/main.yml
  • Executed only when a task notifies them and reports changed
  • Each unique handler runs at most once per play
handlers/main.yml example
---
- name: Restart Nginx
  ansible.builtin.service:
    name: nginx
    state: restarted
  listen: "restart_nginx_service"
Listen name ties notifications to the handler.
Behavioral notes
  • Handlers are queued when tasks report changed
  • They run after task execution at the end of the play
  • Use meta: flush_handlers to force immediate execution in special cases
Key Takeaway

Handlers respond to real changes only and consolidate repeated notifications into a single run for efficiency and stability.
