Module 07 › Chapter 7.2 › Using meta: flush_handlers Carefully
When to use flush_handlers
Only when subsequent tasks truly depend on the handler's effect and you cannot restructure the play or roles to avoid it.
Example usage
- meta: flush_handlers
Place after tasks that notify handlers when you must apply their changes immediately.
Alternatives
  • Restructure roles so ordering is explicit via dependencies.
  • Split the play into multiple plays to allow handlers to run between them.
Caution

Flushing handlers can increase restarts and should be accompanied by tests to avoid unintended downtime.
