Module 07 › Chapter 7.2 › What are Role Dependencies?
Definition

A role lists other roles it requires under dependencies in meta/main.yml so those roles run first. Use this to ensure prerequisites such as packages, storage, or firewall rules are present before the main role's tasks execute.

meta/main.yml example
# webserver/meta/main.yml
galaxy_info:
  author: Your Name
  description: An Ansible role for deploying Nginx web server.

dependencies:
  - role: common_packages  # ensures utilities are installed first
  - role: firewall        # open ports before configuring services
Ordered list: common_packages will run before firewall, and both before the webserver tasks.
Explanation and common pitfall
  • Dependencies form a directed graph; avoid cycles to prevent runtime errors.
  • Use dependencies to keep roles small and focused, reducing duplication.
  • Verify execution order by running the playbook and reading the output.
Key Takeaway

Declare prerequisites in meta/main.yml so roles run predictably and avoid missing dependencies at runtime.
