Module 07 › Chapter 7.2 › Practical Best Practices and Safety Notes
Role design
Keep roles focused and declare only true prerequisites to avoid complex dependency graphs.
Handler naming
Give handlers descriptive listen names and ensure notify strings match exactly to avoid silent failures.
Testing
Test in staging, check verbose output, and create minimal reproductions for diagnostics.
Safety note
Handlers that restart critical services must be idempotent and tested. Prefer restart/reload semantics to minimize downtime.
Key Takeaway

Design dependencies and handlers conservatively, test behavior, and document intent so automation remains reliable in production.
