Module 07 › Chapter 7.3 › Sensitive Data
Safe vs Unsafe
Prefer Vault and omit fallbacks
Comparison: embedding a literal password in a template is unsafe; using encrypted variables and default(omit) keeps templates flexible and secure.
Unsafe pattern
password: "supersecret123"
Safer pattern
password: "{{ item.password | default(omit) }}" (encrypt variable with Vault)
Tip: limit who can read the playbook and vault files. Audit logs and rendered outputs for unexpected leaks before applying to production.
Practical checklist
  • Store secrets in Ansible Vault and restrict vault passwords.
  • Use default(omit) in tasks and templates to avoid empty fields.
  • Verify rendered files and file permissions after template generation.
Pro Tip

When a template might include a secret, render it in a safe test environment and scan output before accepting changes.

Key Takeaway

Never store secrets in plain text in templates; use omit fallbacks and Vault encryption.
