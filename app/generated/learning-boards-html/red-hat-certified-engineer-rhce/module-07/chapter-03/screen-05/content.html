Module 7 › Chapter 7.3 › Conditional Logic
Definition

Conditionals choose which text is rendered based on variable values or tests. Tests make checks explicit and protect templates from errors.

Useful tests
  • is defined — ensure a variable exists before using it.
  • is empty — check for empty lists or strings.
  • is divisibleby(n) — numeric divisibility checks.
Common mistake

Relying on truthiness may hide whitespace-only strings; trim or test explicitly when necessary.

Check your understanding

If a variable may be undefined, which test plus filter ensures safe rendering while still signaling missing data?

Key Takeaway

Prefer explicit tests and an else branch to handle unexpected or missing values gracefully.

Conditional example
{% raw %}{% if service_type == 'web' %}
listen 80;
listen 443 ssl;
{% elif service_type == 'database' %}
listen 5432;
{% else %}
# Default configuration or comment to indicate unexpected service_type
{% endif %}{% endraw %}
Scenario
A playbook sets service_type per host. The template uses explicit branches to ensure ports match the role, avoiding manual per-node files.
Misconception
Assuming an empty list is falsy: test is empty to differentiate an intentionally empty list from an unset variable.
