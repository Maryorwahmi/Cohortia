Module 07 › Chapter 7.3 › Template Maintainability
Refactor process
Identify, extract, parameterize, test
  1. Identify repeated or conditional blocks that vary by host or distribution.
  2. Extract them into focused template fragments and name them meaningfully.
  3. Pass minimal variables to fragments and provide default fallbacks.
  4. Render fragments with test variable sets and inspect outputs.
Example pattern
Create small fragments for distro-specific settings and include them where needed to keep the main template focused.
Misconception

Breaking templates makes them slower — extraction is about clarity and testability, not runtime performance.

Quick checklist
  • Name fragments clearly.
  • Use default filters for expectations.
  • Render with multiple variable sets during review.
Key Takeaway

Small, well-documented template pieces reduce bugs and simplify debugging.
