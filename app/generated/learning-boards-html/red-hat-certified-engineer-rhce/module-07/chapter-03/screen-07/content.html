Module 7 › Chapter 7.3 › Ansible Facts
What are facts?

Facts are host-specific variables automatically gathered by Ansible that describe network, OS, CPU, memory, and more. They enable host-aware rendering inside templates.

Common facts
  • ansible_default_ipv4.address — primary IPv4 address.
  • ansible_distribution — distribution name for distro-specific snippets.
  • ansible_memtotal_mb / ansible_processor — for sizing configs.
Pitfall

If fact gathering is disabled or a custom fact is missing, direct access can cause failures. Use is defined or default filters to avoid this.

Key Takeaway

Facts let templates adapt to each node. Always guard fact usage with defined checks or default fallbacks.

Concrete example
# Bind service to node's primary address
bind_address = {{ ansible_default_ipv4.address }}

# Choose distro-specific include
{% raw %}{% if ansible_distribution == 'RedHat' %}
include 'rhel.conf'
{% else %}
include 'generic.conf'
{% endif %}{% endraw %}
Scenario
Use facts to generate systemd units that reference the node's IP and memory size so services start with appropriate resource limits per host.
