Learning Objectives

From transform to host-aware rendering.

Bloom: Learn → Understand → Apply → Master
01
Use filters to transform data

Apply filters like upper, join, to_nice_json, and hash to change variable presentation and compute values needed in configs.

Mnemonic: pipe symbol stands for transformation.
VERIFIED COMPETENCY MILESTONE
02
Write conditionals and tests

Use if, elif, else and tests such as is defined or is empty to control which configuration blocks render based on variables or facts.

Mnemonic: guard rails for template branches.
VERIFIED COMPETENCY MILESTONE
03
Implement loops for repeated blocks

Use for-loops to render lists or dictionaries, producing scalable blocks like multiple vhost or firewall entries from one template.

Mnemonic: enumerate and render each item.
VERIFIED COMPETENCY MILESTONE
04
Use Ansible facts safely

Reference ansible_default_ipv4.address or ansible_distribution to create host-specific bindings and conditional snippets in templates.

Mnemonic: facts are the node's self-portrait.
VERIFIED COMPETENCY MILESTONE
