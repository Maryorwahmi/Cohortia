What filters do

Filters transform a variable's presentation at render time. Use them to change case, join list elements, produce hashes, and format complex data for configuration files.

Common filters
  • upper, lower, capitalize — simple string transformations.
  • join(',') — combine list elements into a single delimiter-separated string.
  • to_nice_json — pretty-print nested structures for JSON configs.
  • hash('sha256') — compute a SHA256 hex digest from a string.
Common mistake

Forgetting default fallbacks leads to undefined-variable errors. Also, applying filters in the wrong order produces unexpected results.

Key Takeaway

Compose short filter chains and always provide default fallbacks to avoid runtime failures.

Code examples
Read these examples to see filters in action.
# Uppercase and join
{{ my_string | upper }}
{{ my_list | join(',') }}

# Pretty JSON for config insertion
{{ my_complex_var | to_nice_json }}

# Hash for checksum or password storage
{{ 'somestring' | hash('sha256') }}

# Example using ipaddr filter with a fact
{{ ansible_default_ipv4.address | ipaddr('network') }}
Concrete example
Render a CSV of allowed IPs safely: {{ allowed_ips | default([]) | join(',') }}. If allowed_ips is undefined, the default prevents an error.
Pro tip
Prefer to_nice_json for debugging complex structures and only minify for production output if needed.
