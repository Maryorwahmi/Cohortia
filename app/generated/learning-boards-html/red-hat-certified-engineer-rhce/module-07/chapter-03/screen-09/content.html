Module 07 › Chapter 7.3 › Whitespace Control
Definition
Trim and manage rendered whitespace
Core idea: use the dash form of block tags to remove unwanted newlines while keeping template logic clear.
{% raw %}{%- for vhost in web_vhosts -%}
server {
  listen {{ vhost.port }};
  server_name {{ vhost.domain }};
}
{%- endfor -%}{% endraw %}
When to use

Use trimming when rendered files must match strict syntaxes, such as XML, JSON, or service config files.

Common mistake

Over-trimming makes templates harder to read. Prefer explicit structure in templates and trim only the edges that affect output.

Practical checks
  • Render templates locally and inspect files for blank lines or extra spaces.
  • Use {%- and -%} on control lines that otherwise leave empty lines.
  • Keep comments explaining why a trim is applied so future readers see intent.
Key Takeaway

Trim control tags selectively so generated configs are syntactically correct and tidy.
