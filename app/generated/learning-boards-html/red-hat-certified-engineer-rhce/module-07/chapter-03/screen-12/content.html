Module 07 › Chapter 7.3 › Firewall Template
Template snippet
Loop + conditional + defaults
<rule family="ipv4">
{% raw %}{% for rule in firewall_rules %}
  {% if rule.state == 'present' %}
  <rule>
    <source address="{{ rule.source_ip | default('0.0.0.0/0') }}"/>
    <port port="{{ rule.port }}" protocol="{{ rule.protocol | default('tcp') }}"/>
    <accept/>
  </rule>
  {% endif %}
{% endfor %}{% endraw %}
</rule>
Explanation: the for loop iterates firewall_rules; the if guard ensures only present rules are emitted; default filters provide fallbacks for optional fields.
Test idea

Render the template with a rule that omits protocol to confirm the default tcp is applied and XML remains valid.

Pitfall

Unescaped or user-provided values can break XML. Validate or sanitize external inputs before templating.

Quick tips
  • Guard template calls with when or an if to avoid undefined lists.
  • Use default(...) for optional keys to preserve output structure.
  • Validate XML after rendering in tests or CI.
Key Takeaway

Combine loops, conditionals, and sensible defaults to create reliable, idempotent configuration output.
