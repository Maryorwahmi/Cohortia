Module 7 › Chapter 7.3 › Debugging
Three common errors
  • Undefined variables: use default('value') or is defined tests.
  • Syntax errors: check matching control tags and the line numbers in Ansible output.
  • Whitespace issues: manage blank lines with {%- and -%} to strip unwanted spacing.
Debugging steps
  1. Reproduce rendering with a small variable set.
  2. Use to_nice_json to pretty-print complex structures for inspection.
  3. Fix the smallest fragment, re-run, and iterate until the output validates.
Common-mistake

Ignoring Ansible's line-number hints. They point you to the offending block; inspect surrounding control tags for mismatches.

Example fixes
# Provide a safe fallback
{{ maybe_value | default('UNSET') }}

# Strip whitespace around a loop
{% raw %}{%- for item in list -%}
- {{ item }}
{%- endfor -%}{% endraw %}

# Pretty print complex var for inspection
{{ complex_var | to_nice_json }}
Why it matters
Small template mistakes can cause playbook failures across many hosts. A reproducible, minimal test and the right filters save time and reduce outages.
