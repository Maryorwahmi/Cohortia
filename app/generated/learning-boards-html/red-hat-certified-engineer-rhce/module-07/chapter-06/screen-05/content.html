Module 7 › Chapter 7.6 › Installing Collections
Install command
ansible-galaxy collection install community.general
FQCN example
# In a playbook you can reference a module by FQCN
- name: Ensure an INI file section exists
  community.general.ini_file:
    path: /tmp/my_config.ini
    section: database
    option: host
    value: db.example.com
    state: present
Tip: Use collections: at the top of a play to allow short names for modules provided by listed collections.
Example playbook fragment
---
- name: Example playbook using an Ansible Collection
  hosts: localhost
  collections:
    - community.general
  tasks:
    - name: Ensure an INI file section exists
      community.general.ini_file:
        path: /tmp/my_config.ini
        section: database
        option: host
        value: db.example.com
        state: present
Key Takeaway

Install collections with ansible-galaxy and prefer FQCNs when you need explicit, conflict-free module references.
