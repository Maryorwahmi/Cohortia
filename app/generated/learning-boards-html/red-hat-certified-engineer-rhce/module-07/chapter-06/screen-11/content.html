ansible.cfg
# ansible.cfg
[defaults]
inventory = ./dynamic_inventory.py
forks = 5
pipelining = True
# fact_caching = jsonfile
# fact_caching_connection = ./fact_cache
# fact_caching_timeout = 86400
Place this file in your project directory so these settings apply when you run ansible-playbook from that project. Monitor control-node load if you increase forks.
Common mistake
Raising forks without profiling control-node resources can cause resource exhaustion. Tune incrementally and measure.
