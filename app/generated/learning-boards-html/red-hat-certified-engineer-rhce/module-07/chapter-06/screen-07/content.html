Module 7 › Chapter 7.6 › Dynamic Inventory — Definition
Why use dynamic inventory?
  • Automatically discover hosts that are running now.
  • Group hosts by tags, roles, or other metadata.
  • Avoid manual edits and stale data in cloud environments.
Concrete example

Use an aws_ec2 inventory plugin to filter instances by tag Environment: production and instance-state-name: running so only production hosts are returned at runtime.

Key Takeaway

Prefer dynamic inventory in cloud or ephemeral environments so your playbooks always target the right hosts and groups.
