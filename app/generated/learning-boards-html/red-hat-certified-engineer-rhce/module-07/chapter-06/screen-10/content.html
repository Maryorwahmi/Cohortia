Module 7 › Chapter 7.6 › Performance Tuning — Parameters
forks
Controls parallel processes. Increase to run tasks on more hosts simultaneously, but monitor control-node CPU and RAM.
pipelining
Reduces SSH round-trips by sending multiple module operations over a single connection. Useful on high-latency networks.
fact_caching
Store gathered facts in a cache so subsequent runs avoid re-collecting unchanged data. Choose jsonfile, redis, or another supported cache backend.
strategy
linear waits for batches; free lets hosts proceed independently. Use free when task duration varies but accept debugging complexity.
Key Takeaway

Combine settings: increase forks cautiously, enable pipelining, cache facts when they are stable, and choose a strategy that matches your task profile.
