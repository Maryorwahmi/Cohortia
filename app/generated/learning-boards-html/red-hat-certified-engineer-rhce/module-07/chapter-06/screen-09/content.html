Module 7 › Chapter 7.6 › Custom Inventory Script
dynamic_inventory.py
#!/usr/bin/env python3
import json
print(json.dumps({
    "webservers": {
        "hosts": ["localhost"],
        "vars": {
            "http_port": 80,
            "max_connections": 200
        }
    },
    "_meta": {
        "hostvars": {
            "localhost": {
                "ansible_connection": "local"
            }
        }
    }
}))
Make executable with chmod +x dynamic_inventory.py and reference it as your inventory.
Practical guidance
  • Run the script directly to confirm valid JSON.
  • Replace static data with API calls to return live host lists.
  • Ensure authentication and error handling for production scripts.
Key Takeaway

Custom inventory scripts demonstrate dynamic inventory behavior and can be adapted to any external data source for runtime discovery.
