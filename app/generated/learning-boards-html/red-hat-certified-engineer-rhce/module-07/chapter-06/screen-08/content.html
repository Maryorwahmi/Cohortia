Module 7 › Chapter 7.6 › AWS EC2 Inventory Plugin
aws_ec2.yml
# aws_ec2.yml
plugin: amazon.aws.aws_ec2
regions:
  - us-east-1
filters:
  tag:Environment: production
  instance-state-name: running
keyed_groups:
  - key: tags.Name
    prefix: tag_Name_
  - key: tags.Role
    prefix: tag_Role_
Save as aws_ec2.yml and reference with ansible-playbook -i aws_ec2.yml.
Practical notes
  • Ensure AWS credentials or an instance profile are available.
  • Filters limit returned instances and reduce API calls.
  • Keyed groups create human-friendly group names from tags.
Key Takeaway

An inventory plugin configuration file queries the provider and returns groups you can target directly, avoiding manual host lists.
