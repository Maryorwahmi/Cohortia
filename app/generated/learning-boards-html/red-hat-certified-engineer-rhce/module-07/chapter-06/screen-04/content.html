What is a Collection?

A versioned package that can contain modules, plugins, roles, playbooks, and docs — distributed and installed with ansible-galaxy.

Modularity
Versioning
Dependency control
Distribution
Common misconception
Collections are optional conveniences. In reality, relying on collections prevents conflicts and enforces versioned content sharing across teams.
Concrete example

A cloud vendor publishes an official collection containing modules and plugins for its services. Installing that collection ensures you reference supported modules with an expected API.

Key Takeaway
Use Collections to package and share curated Ansible content so playbooks remain explicit and stable.
