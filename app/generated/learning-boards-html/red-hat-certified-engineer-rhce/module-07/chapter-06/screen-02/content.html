Module 7 › Chapter 7.6 › Learning Objectives
01
Understand Collections
Explain why packaging content into versioned collections avoids dependency and naming issues.
Mnemonic: A single package holds modules, roles, plugins — think "one box" for related content.
VERIFIED COMPETENCY MILESTONE
02
Install and use Collections
Run installation commands and reference modules using FQCNs or the collections: list in playbooks.
Mnemonic: "ansible-galaxy collection install" — a single command to add curated content.
VERIFIED COMPETENCY MILESTONE
03
Implement Dynamic Inventory
Configure inventory plugins or scripts so Ansible queries a live source for hosts and variables.
Mnemonic: Treat your inventory like a live lookup rather than a static list.
VERIFIED COMPETENCY MILESTONE
04
Apply Performance Tuning
Set forks, pipelining, fact caching, strategies, and async to optimize playbook runs for large fleets.
Mnemonic: Tune multiple knobs together; one change rarely solves all problems.
