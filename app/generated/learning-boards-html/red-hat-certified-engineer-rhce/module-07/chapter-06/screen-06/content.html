Module 7 › Chapter 7.6 › FQCN vs Short Name
Short name example
- name: Modify INI (short name)
  ini_file:
    path: /tmp/my_config.ini
    section: database
    option: host
    value: db.example.com
Concise but ambiguous if multiple collections provide ini_file.
FQCN example
- name: Modify INI (FQCN)
  community.general.ini_file:
    path: /tmp/my_config.ini
    section: database
    option: host
    value: db.example.com
Explicit and safe for shared or mixed-content repositories.
Key Takeaway

Prefer FQCN for reproducibility and clarity, especially when sharing playbooks or using multiple collections.
