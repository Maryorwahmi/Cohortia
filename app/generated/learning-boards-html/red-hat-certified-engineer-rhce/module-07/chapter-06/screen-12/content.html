Module 7 › Chapter 7.6 › Gathering Facts & Caching
When to disable

If your tasks do not use host facts, set gather_facts: false to save the time required to connect and run the setup module on every host.

Fact caching

Enable fact_caching in ansible.cfg and choose a backend. Cache retrieval avoids repeated gathers when facts are stable.

Pro Tip

Use targeted setup calls to fetch specific facts when you need only a small subset of data, reducing overhead.
