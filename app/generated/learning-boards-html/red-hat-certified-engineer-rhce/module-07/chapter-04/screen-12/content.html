Question

You run a script that returns 0 for success, 1 for minor issue, and 2 for critical failure. Configure failed_when so Ansible treats only 2 as failure.

- name: Run script with custom failure logic
  ansible.builtin.shell: /path/to/your/script.sh
  register: script_output
  failed_when: script_output.rc == 2
Explanation

This failed_when checks the registered rc and evaluates to failure only when rc equals two. Allowing zero and one preserves successful runs or expected warnings without failing the playbook.

Key takeaway
Explicit rc checks express clear intent and avoid masking issues or creating misleading reports.
