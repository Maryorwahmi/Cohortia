How to use these objectives
  • Practice customizing failed_when on commands that have context-specific return codes.
  • Prefer block/rescue/always for recoverable sequences rather than broadly ignoring failures.
  • Run playbooks with -vvv when you need module arguments and raw output, and use --step for cautious testing.
  • Test error paths deliberately in a staging environment to validate your recovery steps.
