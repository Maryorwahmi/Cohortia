Module 7 › Chapter 7.4 › Interactive Debugging
Using --step

Run ansible-playbook with --step to get a prompt before each task. When uncertain about state, this allows inspection and selective execution to build confidence.

Workflow
  1. Reproduce the issue with --step in staging.
  2. When prompted, inspect variables or run an interactive shell if needed.
  3. Decide to run, skip, or modify the task before continuing.
Resuming with --start-at-task

After editing or diagnosing, resume from a named task to avoid re-running unaffected work. This speeds iterative fixes and validation.

# Example commands
ansible-playbook playbook.yml --step
ansible-playbook playbook.yml --start-at-task "Verify htop installation"
Caution
Do not pause production systems during critical windows; step mode can impact service availability.
