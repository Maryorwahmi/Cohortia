Module 7 › Chapter 7.4 › Verbosity Flags
Incremental diagnostics
  1. -v: basic task changes and brief info.
  2. -vv: more output, often shows module return data.
  3. -vvv: module arguments and often internal details.
  4. -vvvv: connection debugging and the deepest level of detail.
Workflow
Start with -v and reproduce the problem. If insufficient, escalate to -vvv to inspect arguments passed to modules. Use -vvvv only when you suspect transport or plugin issues.
Safety notes
  • Higher verbosity may print secrets; avoid running it in untrusted logs or open channels.
  • Prefer staging for deep debugging and sanitize logs when saving them.
  • Combine higher verbosity with --start-at-task when you only need to inspect a specific section.
Key takeaway
Use verbosity as a diagnostic dial: increase detail only as required and protect sensitive output.
