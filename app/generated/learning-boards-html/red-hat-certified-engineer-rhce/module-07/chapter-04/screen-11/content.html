Module 7 › Chapter 7.4 › Hands-on Activity
Activity outline
  1. Create debug_and_error_handling.yml with tasks to install htop and register results.
  2. Use ignore_errors: true on the install to continue even if the package manager errors.
  3. In a block, check which htop, set failed_when to rc != 0, and changed_when: false.
  4. In rescue, output debug messages using the registered installation result and attempt remediation.
  5. Always print a final debug message indicating completion.
Starter code template
---
- name: Demonstrate advanced error handling and debugging
  hosts: all
  become: true
  tasks:
    - name: Ensure htop is installed (ignoring initial errors)
      ansible.builtin.package:
        name: htop
        state: present
      register: htop_install_result
      ignore_errors: true

    - name: Verify htop installation and handle outcomes
      block:
        - name: Check if htop executable exists
          ansible.builtin.command: which htop
          register: which_htop_result
          failed_when: which_htop_result.rc != 0
          changed_when: false

      rescue:
        - name: Handle htop installation failure or not found
          ansible.builtin.debug:
            msg: "Htop not found. Details: {{ htop_install_result | default({}) }}"

      always:
        - name: Final status message for htop check
          ansible.builtin.debug:
            msg: "Htop installation/verification attempt completed."
Exercise tip
Run with different verbosity levels and try --step to practice inspection before and after the check.
Reflection
Note whether install errors carried enough context to diagnose the root cause without rescue messages—improve rescue logging if not.
