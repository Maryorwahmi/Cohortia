Module 7›Chapter 7.1›Apply role
Playbook example
---
- name: Deploy web server
  hosts: webservers
  become: yes
  roles:
    - webserver
  vars:
    nginx_port: 8080
Run ansible-playbook -i inventory deploy_web.yml to apply the role. Confirm Nginx is running and that the rendered config uses the overridden port.
Execution flow
  1. Find role in roles_path
  2. Load defaults/main.yml
  3. Load vars/main.yml
  4. Execute tasks/main.yml and notify handlers if needed
  5. Run handlers at end of play
Misconception check: Ensure the role path is configured or the role resides in a roles/ folder adjacent to your playbook. Otherwise Ansible may not locate it.
