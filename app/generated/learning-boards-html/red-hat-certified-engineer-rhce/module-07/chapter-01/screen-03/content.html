Skills to practice
  • Create tasks: Add package, template, and service tasks in tasks/main.yml and ensure handlers are notified when needed.
  • Use templates: Place Jinja2 templates in templates/ and reference role variables to render host-specific config.
  • Set defaults: Put easily overridden values in defaults/main.yml and use playbook variables to change behavior per deployment.
  • Verify idempotency: Re-run the role and confirm tasks report ok when state is already achieved.
Quick checklist
Scaffold role with ansible-galaxy init
Populate tasks, templates, defaults, handlers
Run playbook and override defaults for environment-specific settings
