Understanding Ansible Roles
Interactive 16:9 Masterclass

Roles package tasks, handlers, templates, files, and variables into reusable units. This improves readability, enforces a standard layout, and helps teams share automation reliably.

In this lesson
Create a webserver role, populate tasks and templates, and run a playbook that overrides defaults.
Why it matters
Cleaner automation, predictable behavior, and safer variable management in production environments.
Coming up
Role Structure
Identify tasks, handlers, templates, files, vars, defaults, and meta.
Idempotency
Make tasks report OK if no change is needed so repeated runs are safe.
ansible-galaxy
Quickly scaffold roles using the built-in init command.
Visual concept
Role = Blueprint
Encapsulates tasks, handlers, templates, files, and variables for one concern.
Standard Layout
tasks, handlers, templates, files, vars, defaults, meta — everyone understands the layout.
Safe Overriding
Defaults live in defaults/main.yml and are intentionally easy to override from inventory, playbook, or CLI.
