Module 7›Chapter 7.1›ansible-galaxy init
Command and quick check
$ ansible-galaxy init webserver
# Creates webserver/ with defaults, tasks, handlers, templates, files, vars, meta
After creating the skeleton, edit tasks/main.yml and handlers/main.yml. Place templates in templates/ and defaults in defaults/main.yml. Commit the role to a repo so teammates can reuse it.
Populate tasks example
---
- name: Ensure Nginx package is installed
  ansible.builtin.dnf:
    name: nginx
    state: present

- name: Copy Nginx configuration template
  ansible.builtin.template:
    src: nginx.conf.j2
    dest: /etc/nginx/nginx.conf
  notify: Restart Nginx

- name: Ensure Nginx service is running and enabled
  ansible.builtin.service:
    name: nginx
    state: started
    enabled: true
Misstep to avoid: notify must match a handler name exactly. Verify handlers/main.yml contains the matching Restart Nginx handler.
