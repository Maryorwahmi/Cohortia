Diagnostic steps
  1. Check defaults/main.yml for the role's default value.
  2. Check vars/main.yml for role-specific overrides.
  3. Inspect host_vars and group_vars for inventory overrides.
  4. Check playbook vars and command-line extra vars (-e).
  5. Use a debug task to print the value on the target host.
Example debug task:
- name: Show nginx_port debug ansible.builtin.debug: var: nginx_port
Common root causes
  • Mismatched handler and notify names.
  • Placing overridable settings in vars instead of defaults.
  • Role not in roles_path or wrong directory layout.
Misconception check: setting a value in defaults does not prevent later overrides; defaults are intentionally low-precedence.
