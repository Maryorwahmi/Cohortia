Module 7›Chapter 7.1›Variable precedence
Precedence snapshot
defaults/main.yml (lowest)
vars/main.yml (role-specific)
host_vars / group_vars
playbook vars
extra vars (-e) (highest)
Concrete example: defaults sets nginx_port: 80. In deploy_web.yml you can override it with nginx_port: 8080. An extra var passed with -e will override both.
Example scenario
# defaults/main.yml
nginx_port: 80

# playbook override
defaults:
  nginx_port: 8080

# command-line override
$ ansible-playbook -i inventory deploy_web.yml -e "nginx_port=8111"
Misconception check: defaults are not immutable. Use defaults when you want sensible values that the operator can easily change.
