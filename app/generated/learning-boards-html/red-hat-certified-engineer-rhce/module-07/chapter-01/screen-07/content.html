Template example (Jinja2)
user  nginx;
worker_processes  auto;

http {
  server {
    listen       {{ nginx_port | default(80) }};
    server_name  {{ ansible_hostname }};
    root         /usr/share/nginx/html;
  }
}
When this file changes after rendering, the template task should use notify: Restart Nginx so the handlers file can restart the service once after all tasks complete.
Handler example
---
- name: Restart Nginx
  ansible.builtin.service:
    name: nginx
    state: restarted
  listen: "Restart Nginx"
Misconception check: do not restart the service inside the template task. Use a handler so the restart runs only when a change occurred and runs once even if multiple tasks notify it.
