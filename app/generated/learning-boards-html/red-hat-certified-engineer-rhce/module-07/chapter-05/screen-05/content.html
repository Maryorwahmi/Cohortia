Module 07 › Chapter 7.5 › Core Vault Commands
Command sequence
1. ansible-vault create <file> — create and save a new encrypted file via editor.
2. ansible-vault edit <file> — open an encrypted file for safe edits.
3. ansible-vault view <file> — decrypt temporarily to inspect contents.
4. ansible-vault encrypt <file> — convert plain text to encrypted file.
5. ansible-vault decrypt <file> — revert to plaintext (use cautiously).
Tip: Always back up before decrypting and avoid decrypting on shared filesystems.
Example session
ansible-vault create group_vars/all/vault.yml
# prompts for a new password, opens editor for you to add variables
Supporting notes
  • Editing re-encrypts on save, so you don't manually handle ciphertext.
  • Use view when you must confirm values without accidental edits.
  • Encrypt will replace the original file with its encrypted form.
