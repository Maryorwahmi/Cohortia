Learning Objectives

Practical skills you will demonstrate
Learn → Understand → Apply → Master
01
Recognize the need for Vault

Explain why plaintext secrets in playbooks are risky and how Vault reduces exposure.

VERIFIED COMPETENCY MILESTONE
02
Perform Vault operations

Create, edit, view, encrypt and decrypt files or strings using ansible-vault commands.

VERIFIED COMPETENCY MILESTONE
03
Integrate Vault into playbooks

Use vaulted variables with vars_files, include_vars or group_vars so playbooks can access secrets during runs.

VERIFIED COMPETENCY MILESTONE
04
Manage passwords securely

Choose appropriate password delivery: prompt, file, environment or ansible.cfg and secure the password file with strict permissions.

VERIFIED COMPETENCY MILESTONE
