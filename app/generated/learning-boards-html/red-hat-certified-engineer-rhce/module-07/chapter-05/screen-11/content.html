Common mistakes and fixes
Hardcoding secrets. Fix: move them to Vault and reference variables.
Committing password files. Fix: gitignore and remove from history.
Losing vault password. Fix: secure backups of password material in a vault or secret manager.
Exposing secrets in logs. Fix: use no_log on sensitive tasks and avoid debug prints.
Pro tip: before a production run, scan for debug tasks and check file modes on destination files to ensure secrets remain protected.
