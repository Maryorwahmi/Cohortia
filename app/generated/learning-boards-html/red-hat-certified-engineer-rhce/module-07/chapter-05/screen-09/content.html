Module 07 › Chapter 7.5 › Vault IDs
Why use Vault IDs?

Separate secrets for dev, staging and production reduce risk. Vault IDs assign an identifier to each password so multiple keys can coexist in a project.

Example commands
ansible-vault encrypt --vault-id dev@prompt dev_secrets.yml
ansible-vault encrypt --vault-id prod@/path/to/prod_pass.txt prod_secrets.yml
Runtime example

When running a playbook you can pass multiple vault IDs so Ansible can try the right password for each encrypted file.

Key takeaway

Vault IDs enable environment separation at the cost of managing multiple passwords and rotation policies.
