Module 07 › Chapter 7.5 › Vault Password Delivery
Delivery options
--ask-vault-pass — interactive prompt; secure but not automated.
--vault-password-file <file> — file containing only the password; ideal for automation with strict permissions.
Environment variable — pass the password file path via env var for orchestration; still secure the file.
ansible.cfg — set vault_password_file for automatic use from that configuration; convenient but handle the config securely.
Security checklist
  • Never commit password files to Git; add them to .gitignore.
  • Set tight file permissions, e.g., chmod 0600 on vault password files.
  • Prefer password prompt for interactive sessions to avoid disk persistence.
Operational note

Automated CI/CD pipelines typically use a vault password file placed in a secure runner workspace; ensure the file is ephemeral and permission-restricted.
