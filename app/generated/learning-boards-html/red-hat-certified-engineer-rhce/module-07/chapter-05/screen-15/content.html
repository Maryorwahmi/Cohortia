Module 07 › Chapter 7.5 › Key Concepts
Ansible Vault
Encrypts secrets at rest so they are unreadable without the vault password.
Password handling
Use prompts for manual runs, protected files for automation, and secure permissions.
Vault IDs
Allow multiple passwords per project for environment separation and reduced blast radius.
Takeaway

Encrypt sensitive data, protect the vault password, avoid logging decrypted values, and choose the password delivery method that matches your automation needs.
