Module 07 › Chapter 7.5 › Encrypt a single string
Use case

When a single secret must be embedded in a vars file or playbook, encrypt_string produces the necessary vaulted YAML block.

Command pattern
ansible-vault encrypt_string 'mysecretvalue' --name 'my_secret_variable'
Output notes

The tool prints a YAML block that looks like a variable assignment followed by a vault marker and the ciphertext. Copy the whole block into your vars file exactly as shown.

Example use

Embed an encrypted API key in role defaults or group_vars without creating a separate file if it is truly a single secret.

Misuse check

Avoid overusing encrypt_string for many secrets; prefer organized vault files for maintainability.
