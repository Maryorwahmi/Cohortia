Question 1
You have prod_credentials.yml in plain text. Encrypt it and have Ansible run without prompting, using /opt/ansible/vault_key.txt as the password file. Explain the steps and why they are secure.
Correct approach
ansible-vault encrypt prod_credentials.yml
# create /opt/ansible/vault_key.txt containing only the vault password
# set strict permissions: chmod 0600 /opt/ansible/vault_key.txt
ansible-playbook -i inventory/hosts my_playbook.yml --vault-password-file /opt/ansible/vault_key.txt
Explanation: Encrypt converts the file to ciphertext. The password file provides automatic decryption during runs while restrictive permissions protect the password file from other users.
Question 2
What are the security implications of using a debug task to print a vaulted variable, and what is the safer alternative?
Answer: Printing a vaulted variable reveals plaintext to console and logs. Use no_log: true on tasks handling secrets or avoid printing secrets entirely.
