Skills Checklist

Use this as a verification guide during hands-on practice.

Create & edit vault files
ansible-vault create and ansible-vault edit preserve encryption while allowing secure updates.
Encrypt existing files
Use ansible-vault encrypt when a secret was saved in plain text by mistake.
Embed single secrets
Use encrypt_string to add a vaulted variable block inside a vars file or playbook.
Manage passwords
Test runs with --ask-vault-pass and with a secure vault password file for automated pipelines.
