Module 07 › Chapter 7.5 › Hands-on Activity
Step-by-step
  1. Create directory structure and inventory with a localhost entry.
  2. Run ansible-vault create group_vars/all/vault.yml and add db_password and app_api_key.
  3. Create playbook that uses these variables in templates or copy modules.
  4. Run with --ask-vault-pass for manual verification.
  5. For automation, create a vault_pass.txt with only the password, set chmod 0600, and run with --vault-password-file.
Verification
Confirm playbook runs succeed and secrets are used in templates.
Check /tmp/app_config.conf or your target file has mode 0600 and contains values only on the target host, not in your repo.
Delete ephemeral password files after use and add them to .gitignore.
