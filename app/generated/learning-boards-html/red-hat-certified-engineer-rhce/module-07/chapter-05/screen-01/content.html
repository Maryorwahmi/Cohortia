Ansible Vault for Sensitive Data
Protect credentials and secrets used by your automation workflows.
Interactive 16:9 Masterclass
Why Vault matters

Secrets committed to Git can be leaked. Vault encrypts files so stored credentials remain unreadable without the vault password.

How it works

Ansible uses symmetric encryption: the same password encrypts and decrypts. At runtime it decrypts in memory and does not write plain text to disk.

Quick commands
ansible-vault create
ansible-vault encrypt
ansible-vault decrypt
