Module 2 › Chapter 2.1 › Understanding Ansible Playbooks and YAML Syntax
What this chapter teaches

Understand playbook structure, write a minimal playbook, apply YAML rules, and validate with linters and ansible-playbook checks.

Playbooks are lists of plays. Each play targets inventory hosts, optionally escalates with become, and contains tasks that call modules. YAML indentation denotes nesting, lists start with hyphens, and maps use colon-separated key-value pairs. A single misplaced space can break a playbook, so consistent spacing and validation are critical.
