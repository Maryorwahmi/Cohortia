Core constructs
  • Key-value: name: Install Nginx
  • List: packages: - nginx - httpd-tools
  • Dictionary/map: service_config: name: nginx state: started
Editor tips
Enable visible spaces and set YAML linting in your editor. Pick 2 or 4 spaces for indentation and do not use tabs. Run yamllint to enforce rules before execution.
Examples
packages:
  - nginx
  - httpd-tools

service_config:
  name: nginx
  state: started
  enabled: yes
These examples show lists and maps. Verify colons and indentation to ensure they parse as intended. Mis-parsed YAML can cause missing module arguments or runtime errors.
