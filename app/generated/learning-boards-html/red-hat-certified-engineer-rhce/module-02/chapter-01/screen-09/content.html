Module 2 › Chapter 2.1 › Validate then run
Three-step safe workflow
Step 1
Run yamllint to find indentation and syntax problems early.
Step 2
Run ansible-playbook --syntax-check to validate playbook structure for Ansible.
Step 3
Execute ansible-playbook against a test host, then inspect ok and changed results.
Example commands you will use in a terminal: run yamllint, then ansible-playbook --syntax-check first. If both succeed, run ansible-playbook and verify results on the target host with ls and cat to confirm files and permissions. This staged approach reduces the risk of accidental changes.
