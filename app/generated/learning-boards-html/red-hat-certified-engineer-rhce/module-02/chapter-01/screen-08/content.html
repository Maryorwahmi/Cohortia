Module 2 › Chapter 2.1 › Minimal playbook example
first_playbook.yml
---
- name: Ensure a specific directory exists
  hosts: webservers
  become: yes
  tasks:
    - name: Create the /opt/my_app_data directory
      ansible.builtin.file:
        path: /opt/my_app_data
        state: directory
        mode: '0755'
        owner: root
        group: root
Explanation & checks
  • hosts: inventory group to target.
  • become: escalate privileges for file creation.
  • file module: enforces path and attributes idempotently.
  • Validation: run ansible-playbook --syntax-check before execution.
