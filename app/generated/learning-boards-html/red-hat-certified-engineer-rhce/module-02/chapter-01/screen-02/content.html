Define playbook purpose

Explain how playbooks declare desired state and how plays target hosts and tasks call modules. VERIFIED COMPETENCY MILESTONE

02
Explain YAML fundamentals

Describe indentation, key: value pairs, lists with hyphens, and dictionaries as maps used in playbooks. VERIFIED COMPETENCY MILESTONE

03
Identify YAML errors

Recognize incorrect indentation, missing colons, and mixing tabs; use linting and syntax checks to resolve them. VERIFIED COMPETENCY MILESTONE

04
Construct a basic playbook

Create a play that uses become: yes and tasks that ensure directories and files exist on managed hosts. VERIFIED COMPETENCY MILESTONE

These four objectives prepare you to read and author playbooks with confidence, validate them with linters and ansible-playbook --syntax-check, and run idempotent plays that produce predictable ok or changed states. Practical checks and hands-on tasks on later screens will let you verify each milestone.
