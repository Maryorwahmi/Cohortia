Module 2 › Chapter 2.1 › Activity: create_content.yml
Starter template
---
- name: Setup application configuration directory and file
  hosts: your_target_host_group # Replace with 'control_node', 'localhost', or your inventory group
  become: yes
  tasks:
    - name: Ensure /opt/my_app_config directory exists
      ansible.builtin.file:
        path: /opt/my_app_config
        state: directory
        mode: '0770'
        owner: root
        group: root

    - name: Create config.txt file inside the directory
      ansible.builtin.copy:
        dest: /opt/my_app_config/config.txt
        content: "This is my application configuration."
        mode: '0644'
Verification steps
  1. Run yamllint and ansible-playbook --syntax-check create_content.yml.
  2. Run ansible-playbook create_content.yml against your inventory.
  3. On the target run ls -ld /opt/my_app_config and ls -l /opt/my_app_config/config.txt and cat the file to verify content.
