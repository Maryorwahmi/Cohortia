Module 2 › Chapter 2.1 › Choosing modules
Module examples
- name: Ensure 'developers' group exists
  ansible.builtin.group:
    name: developers
    state: present

- name: Ensure 'devuser' exists and is in 'developers'
  ansible.builtin.user:
    name: devuser
    state: present
    groups: developers
    append: yes
Why modules matter
Modules provide idempotent behavior and semantic clarity. Using user and group modules avoids brittle shell commands and reduces risk when automating account and group management.
