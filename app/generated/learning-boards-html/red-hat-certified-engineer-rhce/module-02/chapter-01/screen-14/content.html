Module 2 › Chapter 2.1 › Key Concepts
Playbooks are declarative
Describe desired state instead of explicit steps.
YAML requires strict indentation
Use consistent spaces and proper nesting for lists and maps.
Validate and prefer modules
Run yamllint and ansible-playbook --syntax-check; use modules for idempotence.
Final takeaway

Combine clear declarative intent, correct YAML structure, and validation to build safe, repeatable automation.
