Playbook = list
Start with a leading hyphen; each play contains hosts and tasks.
YAML indentation
Use spaces consistently; run yamllint to catch errors.
Validate & test
Use ansible-playbook --syntax-check, then run against a test host and inspect ok/changed.
Quick practice

Write a one-play playbook that creates a directory, lint it, syntax-check it, and run it against localhost. Confirm permissions and contents on the filesystem.
