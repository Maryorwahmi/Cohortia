Practice steps
  1. Draft create_content.yml using become: yes and tasks for directory and file resources.
  2. Run yamllint and ansible-playbook --syntax-check to detect structure issues early.
  3. Run ansible-playbook and inspect ok/changed output to confirm idempotence.
  4. Correct any indentation or argument placement and re-run checks.
Verification checklist
  • Playbook starts with a list marker: a leading hyphen for the play.
  • Hosts value matches an inventory group or localhost for testing.
  • Tasks are a YAML list; module arguments are indented under the module name.
  • Use consistent spaces for indentation; avoid tabs.
