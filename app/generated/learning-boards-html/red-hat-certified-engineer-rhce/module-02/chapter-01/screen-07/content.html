Module 2 › Chapter 2.1 › Common YAML Errors
Error types
  • Indentation: wrong nesting moves keys to the wrong level.
  • Missing colon: key: value must include colon or mapping fails.
  • Tabs vs spaces: tabs cause parser issues; use spaces only.
Example correction
Incorrect:
- name: Start Apache service
  ansible.builtin.service:
    name: httpd
    state: started
  enabled: yes

Corrected:
- name: Start Apache service
  ansible.builtin.service:
    name: httpd
    state: started
    enabled: yes
Notice enabled: yes must be indented under the service module. A linter will flag the incorrect indentation and a syntax check will fail until fixed.
