Override Mechanism

Extra variables (-e) and overrides

Command-line override
ansible-playbook configure_app.yml -e "app_port=80 app_env=production"
# or with a file
ansible-playbook configure_app.yml -e @prod_vars.yml
Extra-vars provide a direct way to change values for a run without editing inventory or playbooks.
When to use
  • CI/CD pipelines that inject environment-specific values.
  • Temporary overrides during debugging or emergency fixes.
  • Passing sensitive values from a secure pipeline step (prefer Vault for long-term secrets).
Common Mistake

Relying on ad-hoc extra-vars in local runs without recording them can cause irreproducible deployments. Use documented pipeline overrides for consistency.
