Definition & Scope

Variable scopes in Ansible

Understand where to place values and the role each scope plays in deployment patterns.

Process: Choose a scope
  1. Start with group_vars for sensible environment or role defaults that apply to many hosts.
  2. Use host_vars for per-host exceptions or identifiers that must differ per machine.
  3. Use playbook vars for defaults tied to a specific play's intent and not reusable elsewhere.
  4. Use extra-vars for deliberate overrides at runtime, such as CI/CD pipelines or one-off runs.
Pro tip

Prefer group_vars for environment defaults and reserve extra-vars for explicit overrides to avoid accidental changes.
