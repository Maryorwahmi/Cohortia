Playbook Example

Playbook variables in use

A clear example showing vars: and how tasks reference those values.
Code walkthrough
---
- name: Configure web server
  hosts: webservers
  vars:
    nginx_port: 8080
    app_version: "1.2.3"
  tasks:
    - name: Ensure Nginx is configured on port {{ nginx_port }}
      ansible.builtin.template:
        src: nginx.conf.j2
        dest: /etc/nginx/nginx.conf
This play defines nginx_port and app_version. Any task in the play can reference these variables using double curly braces. The template module renders files with those values at runtime.
Explanation & Example
- The vars: section is ideal for play-scoped defaults.
- To change the port for production without editing the playbook, pass an extra-var or set a host_var.
Common mistake: hardcoding values across multiple plays makes maintenance harder.
Key Takeaway

Use playbook vars for defaults tied to the play. For environment or host differences, prefer inventory scopes or extra-vars.
