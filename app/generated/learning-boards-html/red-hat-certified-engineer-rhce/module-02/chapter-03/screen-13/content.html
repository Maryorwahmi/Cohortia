Hands-on Activity

Dynamic user creation and facts verification

Follow these templates and verify users and facts on each host.
Inventory file
[servers]
host1.example.com
host2.example.com
host_vars/host1.example.com.yml
username: devops_user1
user_comment: "First DevOps User"
host_vars/host2.example.com.yml
username: devops_user2
user_comment: "Second DevOps User"
Playbook template
---
- name: Create users and display facts
  hosts: servers
  become: yes
  tasks:
    - name: Create user {{ username }}
      ansible.builtin.user:
        name: "{{ username }}"
        comment: "{{ user_comment }}"
        state: present
        shell: /bin/bash

    - name: Display host information
      ansible.builtin.debug:
        msg: "Hostname: {{ ansible_hostname }}, OS Family: {{ ansible_os_family }}"
Run: ansible-playbook -i inventory.ini dynamic_user.yml. Verify with id devops_user1 on host1 and inspect the debug output for each host to confirm facts.
Verification

Users created and debug messages show ansible_hostname and ansible_os_family for each host. Rerun with -e to test overrides.
