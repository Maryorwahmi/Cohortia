Safety & Best Practices

Secrets, safety, and common mistakes

Protecting secrets
- Do not hardcode secrets into playbooks or inventory files that may be committed.
- Use Ansible Vault to encrypt passwords and API keys and reference the variables normally in runs.
- Store vault passwords securely in your CI/CD system when required for automated runs.
Other common mistakes
  • Expecting a group_var to override a playbook var without checking precedence.
  • Using extra-vars casually and creating irreproducible runs.
  • Disabling gather_facts when tasks depend on facts.
Pro tip

Track all overrides in automation pipelines and use Vault for persistent secrets to keep runs auditable and safe.
