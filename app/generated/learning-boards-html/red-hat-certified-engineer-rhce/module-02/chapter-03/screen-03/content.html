Lab Walkthrough Objectives

Steps overview
  1. Create inventory.ini and host_vars files for two hosts.
  2. Write dynamic_user.yml to create users using host_vars.
  3. Run playbook and observe created users and debug outputs.
  4. Rerun with --extra-vars to override and confirm precedence.
  5. Use ansible -m setup to inspect facts.
Verification
- Confirm user accounts exist with id command on each host.
- Confirm debug prints include ansible_hostname and ansible_os_family.
- Confirm passing -e overrides a variable value in the run output.
Starter commands
# Run playbook with extra-vars override example
ansible-playbook -i inventory.ini dynamic_user.yml -e "app_env=production"

# Inspect all facts for a host
ansible host1.example.com -m setup
