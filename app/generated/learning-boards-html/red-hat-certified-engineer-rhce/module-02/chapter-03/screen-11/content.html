Variable Precedence

Precedence: which value wins?

Simplified precedence (low → high)
Role defaults
Inventory variables (group_vars / host_vars)
Playbook vars (vars:)
Role vars
Extra variables (-e)
To resolve conflicts, determine where each value is defined and apply the precedence chain. If a value appears unexpectedly, add a debug task to print the variable and its origin, or use -vvv to inspect variable loading during a run.
Troubleshooting
- Use a debug task: ansible.builtin.debug: var=your_var to see the selected value.
- Check inventory and playbook for duplicate names and remove ambiguity.
- Reserve extra-vars for intentional, documented overrides.
Common Mistake

Expecting a lower-precedence value to override a higher-precedence one leads to confusing behavior. Always check the precedence chain when conflicts appear.
