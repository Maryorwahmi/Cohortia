Learning Objectives

Each objective includes a small mnemonic and a verification milestone so you can confirm practical competence.

01
Explain variables
Describe why variables replace hardcoded values and how that supports reuse and environment variations. Example: using a single template while changing nginx_port per environment.
Mnemonic: Replace hardcode with placeholders
VERIFIED COMPETENCY MILESTONE
02
Define variable scopes
Show how to place vars in playbooks, host_vars, group_vars, and pass extra vars on the command line. Explain when each scope is appropriate.
Mnemonic: Local, Inventory, Override
VERIFIED COMPETENCY MILESTONE
03
Use Ansible facts
Understand the setup module and use facts like ansible_os_family and ansible_default_ipv4.address for conditional tasks and templates.
Mnemonic: Observe then act
VERIFIED COMPETENCY MILESTONE
04
Manage precedence
Learn the common precedence chain and avoid expecting lower-precedence sources to override higher-precedence variables such as extra-vars passed via -e.
Mnemonic: Higher wins
VERIFIED COMPETENCY MILESTONE
