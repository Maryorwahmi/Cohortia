Inventory Variables

Host and group variables

Store environment and host-specific settings in host_vars and group_vars so playbooks remain generic.
Host variable example
# inventory/host_vars/host1.example.com.yml
nginx_port: 8080
server_id: "WEB01"
This file applies only when Ansible targets host1.example.com. Files in host_vars are loaded automatically at runtime.
Group variable example
# inventory/group_vars/webservers.yml
nginx_port: 80
default_app_version: "1.0.0"
Values here apply to every host in the webservers group. Group_vars is great for role- or environment-level defaults.
Best practices
  • Keep environment data in inventories, not in playbooks, for clearer separation of concerns.
  • Use separate inventory directories for staging and production if structure diverges.
