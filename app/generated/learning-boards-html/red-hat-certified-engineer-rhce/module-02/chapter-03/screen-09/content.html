Definition

What are Ansible facts?

Facts are gathered automatically to describe each managed host so playbooks can make informed decisions.
Show facts
ansible myhost -m setup

# Example fact usage in a task
- name: Print OS family
  ansible.builtin.debug:
    msg: "This host is part of the {{ ansible_os_family }} family."
Facts are available after gather_facts runs. If gather_facts is disabled, run the setup module explicitly to collect them.
Practical uses
  • Conditional tasks based on ansible_os_family.
  • Templates that pick addresses using ansible_default_ipv4.address.
  • Selecting packages, paths, or service names per host characteristics.
Key Takeaway

Facts let playbooks adapt to the actual properties of each host, making cross-platform automation practical.
