Module 3 › Chapter 2.5 › Handlers & notify

Handler example

# handlers/main.yml
---
- name: Restart Nginx
  ansible.builtin.service:
    name: nginx
    state: restarted
The template task uses notify: Restart Nginx. If the template reports changed, Ansible queues the handler. At the end of the role's tasks the handler runs once, even if multiple tasks notified it.

Process steps

1. Task runs and changes state
2. Task notifies handler name
3. Handler runs at end of host's tasks
Misconception: Handlers run immediately. They don't — they run after the current set of tasks for that host completes, which helps batch multiple changes to a single restart.
