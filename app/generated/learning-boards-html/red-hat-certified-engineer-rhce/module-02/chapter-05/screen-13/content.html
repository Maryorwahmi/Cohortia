Module 3 › Chapter 2.5 › Common Mistakes
Variable precedence
Put tunables in defaults, role constants in vars, and environment secrets in inventory with Vault.
Wrong file paths
Use relative src names; Ansible resolves templates/ and files/ automatically for roles.
Missing notify
If you forget to notify a handler after changing a template, services won’t reload and new configurations won’t take effect.
Troubleshooting tip: Run a test playbook that targets localhost, watch task changed states, and check which handlers were queued. That narrow feedback loop accelerates debugging.
