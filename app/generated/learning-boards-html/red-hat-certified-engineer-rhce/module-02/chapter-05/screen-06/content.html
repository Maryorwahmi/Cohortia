Module 3 › Chapter 2.5 › tasks/main.yml

Code example

---
- name: Install Nginx package
  ansible.builtin.dnf:
    name: nginx
    state: latest

- name: Deploy Nginx configuration
  ansible.builtin.template:
    src: nginx.conf.j2
    dest: /etc/nginx/nginx.conf
    owner: root
    group: root
    mode: '0644'
  notify: Restart Nginx

- name: Ensure Nginx is running and enabled
  ansible.builtin.service:
    name: nginx
    state: started
    enabled: yes

Explanation & tips

  • Idempotence: Use modules that only report changed when needed to avoid spurious handler runs.
  • Notify pattern: Template changes should notify handlers instead of immediate restarts.
  • Order matters: Install packages before templating files that require binaries.
Example misconception: Running service restart immediately after a template may restart even if the file did not change. Use notify to restart only on change.
