Role folder map

my_role/
├── defaults/        # default variables
│   └── main.yml
├── handlers/        # restart/reload handlers
│   └── main.yml
├── tasks/           # main role tasks
│   └── main.yml
├── templates/       # Jinja2 templates
├── files/           # static files
├── vars/            # higher-precedence variables
│   └── main.yml
├── meta/            # metadata and dependencies
│   └── main.yml
└── README.md

Why the layout matters

  • Automatic lookup: template and file src paths are resolved inside the role.
  • Clear precedence: defaults vs vars defines which values are easy to override.
  • Separation of concerns: tasks do the work, handlers react to changes, templates render configs.
Misconception: You must use all folders. Reality: Use only the folders needed, but follow the convention when you do.
