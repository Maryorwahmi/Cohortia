Module 3 › Chapter 2.5 › defaults vs vars

defaults/main.yml

# defaults/main.yml
nginx_port: 80
log_level: notice
Lowest precedence so administrators can override values in inventory or extra vars. Use for sensible defaults.

vars/main.yml

# vars/main.yml
internal_template_path: '/opt/role/templates'
service_user: nginx
Higher precedence. Use for role-internal values that should not be casually overridden.
Misconception: defaults are hidden. They are purposely low precedence to make roles flexible. For secrets, prefer inventory with Ansible Vault rather than defaults.
