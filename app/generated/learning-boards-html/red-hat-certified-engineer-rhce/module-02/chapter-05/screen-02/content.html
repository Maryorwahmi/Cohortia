Learning Objectives

Build, scaffold, and apply Ansible roles with correct directory structure and variable usage.

01
Explain role benefits

Describe how roles increase reuse and reduce duplication across playbooks. Verified competency milestone.

Mnemonic: Lego blocks — each role is a reusable block.
02
Describe directory structure

Identify tasks, handlers, defaults, vars, templates, files, and meta and their purpose. Verified competency milestone.

Mnemonic: Folder map — every role has a standard map.
03
Create roles with ansible-galaxy

Scaffold a new role and populate its main.yml files. Verified competency milestone.

Mnemonic: Init command → skeleton role quickly.
04
Apply roles from playbooks

Use the roles: keyword in playbooks and verify handlers and variables execute as expected. Verified competency milestone.

Mnemonic: roles: is the single line that applies a role.
