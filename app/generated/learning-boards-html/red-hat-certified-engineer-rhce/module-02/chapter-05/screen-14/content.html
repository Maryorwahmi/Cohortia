Module 3 › Chapter 2.5 › Activity: Nginx role

deploy_web.yml

---
- name: Deploy Nginx web server using a role
  hosts: webservers
  become: yes
  roles:
    - nginx_webserver

defaults/main.yml

nginx_port: 80

tasks/main.yml & handlers

# tasks/main.yml
---
- name: Install Nginx package
  ansible.builtin.dnf:
    name: nginx
    state: latest

- name: Copy Nginx configuration template
  ansible.builtin.template:
    src: nginx.conf.j2
    dest: /etc/nginx/nginx.conf
    owner: root
    group: root
    mode: '0644'
  notify: Restart Nginx

- name: Ensure Nginx service is running and enabled
  ansible.builtin.service:
    name: nginx
    state: started
    enabled: yes

# handlers/main.yml
---
- name: Restart Nginx
  ansible.builtin.service:
    name: nginx
    state: restarted
Verification: Run ansible-playbook deploy_web.yml, then check the host with system tools to confirm nginx is installed, running, and listening on the expected port. Override nginx_port in group_vars to test different environments without changing the role itself.
