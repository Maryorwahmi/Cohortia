Module 3 › Chapter 2.5 › Key Concepts
Role
A self-contained unit bundling tasks, handlers, variables, files, templates, and metadata for reuse.
ansible-galaxy init
Command that scaffolds a consistent role directory so you can implement tasks and templates cleanly.
defaults vs vars
defaults are low-precedence and overridable; vars have higher precedence and are for role-internal values.
Summary Takeaway

Design roles as small, well-documented, and testable units. Use defaults for tunables, templates for dynamic configs, and handlers to react to changes.
