Assessment
Create users with conditional UID
Task
Write a user task that loops users_to_create and applies uid only when present.
Starter list: 
users_to_create:
  - name: alice
    uid: 1001
  - name: bob
  - name: charlie
    uid: 1003
Correct answer (pattern)
- name: Create users with conditional UID
  ansible.builtin.user:
    name: "{{ item.name }}"
    uid: "{{ item.uid | default(omit) }}"
    state: present
    shell: /bin/bash
  loop: "{{ users_to_create }}"
Explanation: default(omit) removes the uid parameter when absent, allowing the module to assign a default UID.
