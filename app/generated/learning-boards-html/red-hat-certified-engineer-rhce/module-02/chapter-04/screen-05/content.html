Definition
Logical combinations and defaults
Make expressions precise and resilient to missing data.
Process: evaluate and protect
  1. Choose the facts or variables to test, e.g., ansible_os_family.
  2. Combine with and / or for specificity.
  3. Apply default filters to variables that might be missing.
  4. Test the condition on representative hosts.
Misconception: default(false) is for boolean fallbacks; default(omit) removes a parameter so the module uses its built-in default behavior.
Example
Check both OS family and architecture before running a debug message.
- name: Debug message for specific OS and architecture
  ansible.builtin.debug:
    msg: "This is a 64-bit RedHat system."
  when: ansible_os_family == "RedHat" and ansible_architecture == "x86_64"
Try toggling the architecture to see the when condition skip or run. This helps you understand how combined tests narrow the set of target hosts.
