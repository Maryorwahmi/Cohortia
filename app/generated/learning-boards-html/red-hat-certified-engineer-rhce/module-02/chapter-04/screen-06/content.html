Core Concept
Looping with loop and item
Why loops help
  • One task, many inputs reduces errors and duplication.
  • Use simple lists for packages and lists of dicts for structured items.
  • Refer to the current element with item inside the task body.
Key Takeaway

Loops make playbooks concise and more maintainable — prefer loop over older constructs.

Example: packages and users
Install a list of web packages and create application users defined as dictionaries.
---
- name: Manage multiple packages and users
  hosts: webservers
  become: yes
  vars:
    web_packages:
      - httpd
      - php
      - mariadb-server
    app_users:
      - name: appuser1
        uid: 1001
      - name: appuser2
        uid: 1002
  tasks:
    - name: Install required web packages
      ansible.builtin.dnf:
        name: "{{ item }}"
        state: latest
      loop: "{{ web_packages }}"

    - name: Create application users
      ansible.builtin.user:
        name: "{{ item.name }}"
        uid: "{{ item.uid }}"
        state: present
        shell: /bin/bash
      loop: "{{ app_users }}"
Note: when a dictionary lacks a key, use default filters to avoid errors.
