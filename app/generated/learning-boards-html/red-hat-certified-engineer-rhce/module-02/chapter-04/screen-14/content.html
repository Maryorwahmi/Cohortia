Chapter 2.4 › Key Concepts
when statement
Run tasks only when the Jinja2 expression evaluates to true, use safe defaults to avoid errors.
loop & item
Iterate lists or dicts so a single task handles many inputs using item as the current element.
Handlers & notify
Define named handlers and notify them from tasks that change resources so restart happens only when needed.
Summary Takeaway
When, loop, and handlers together let your playbooks be precise, concise, and harmless to running services — aim to use them intentionally.
