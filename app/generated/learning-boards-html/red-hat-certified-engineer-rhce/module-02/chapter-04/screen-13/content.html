Common Mistakes
Avoid these pitfalls
Unquoted strings
Always quote RHS string literals in when comparisons for consistency and to avoid parser surprises.
Forgetting notify
If you modify a config but do not notify a handler, services will not be reloaded and changes won't take effect.
Wrong defaults
Use default(omit) to avoid passing empty values to modules that would interpret them differently.
Pro tip

Name handlers explicitly and test the sequence by running playbooks twice to verify changed vs ok behavior and handler execution.
