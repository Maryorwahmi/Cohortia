Real-world benefits
  • Reduce risk: run actions only where intended using when and facts.
  • Maintainability: use loop across packages or users instead of repeated tasks.
  • Stability: handlers prevent unnecessary restarts and keep services available.
  • Resilience: default filters avoid runtime errors when variables are missing.
