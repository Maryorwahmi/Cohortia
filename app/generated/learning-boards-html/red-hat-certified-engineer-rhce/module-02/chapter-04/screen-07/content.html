Process Flow
Looping dictionaries and conditional parameters
Pattern
Use dot notation to read keys from the current loop item and apply filters to handle absent keys.
- name: Create users with conditional UID
  ansible.builtin.user:
    name: "{{ item.name }}"
    uid: "{{ item.uid | default(omit) }}"
    state: present
    shell: /bin/bash
  loop: "{{ users_to_create }}"
Practical tip: use default(omit) rather than default("") so modules receive no parameter instead of an empty value.
Concrete scenario
You have a mixed list of users; some require specific UIDs for ownership consistency, others can use system-assigned IDs. The loop handles both cleanly.
Misconception: trying to branch inside the loop with separate tasks adds repetition; prefer the default filter to keep one task handling both cases.
