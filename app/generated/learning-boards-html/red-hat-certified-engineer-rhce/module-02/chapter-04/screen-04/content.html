Core Concept Conditional execution with when
Definition & guidance
  • when evaluates a Jinja2 expression to permit or skip a task.
  • Use facts like ansible_os_family and filters like default(false) to be safe.
  • Combine conditions with and / or for precise targeting.
  • Always test conditions on a small host subset before wide runs.
Key Takeaway

Guard tasks with when to run only where they apply and avoid unintended changes.

Concrete example
Install Nginx only on Red Hat-based systems. Note the quoted string and safe default in the second example.
---
- name: Conditional task execution
  hosts: all
  become: yes
  tasks:
    - name: Install Nginx on Red Hat-based systems
      ansible.builtin.dnf:
        name: nginx
        state: latest
      when: ansible_os_family == "RedHat"

    - name: Create a file only if a specific variable is set to true
      ansible.builtin.file:
        path: /tmp/important_marker.txt
        state: touch
      when: create_marker_file | default(false)
Misconception: unquoted string comparisons may sometimes work, but quoting avoids ambiguous parsing and is the safer practice.
