Comparison
loop vs with_items
When to use loop
  • New playbooks should use loop for clarity and forward compatibility.
  • Loop blends with loop_control and index tracking.
  • Loop works consistently with lists and lists of dictionaries.
Example: package loop
- name: Install required web packages
  ansible.builtin.dnf:
    name: "{{ item }}"
    state: latest
  loop: "{{ web_packages }}"
Misconception: older code found in the wild may use with_items. Refactor to loop when updating playbooks to reduce future confusion.
