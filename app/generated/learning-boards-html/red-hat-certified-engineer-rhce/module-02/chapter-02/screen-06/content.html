Module Focus

Package management with dnf

How to ensure packages are installed, updated, or removed using the built-in dnf module.

- name: Ensure Nginx is installed and latest ansible.builtin.dnf: name: nginx state: latest - name: Remove an old package ansible.builtin.dnf: name: old-package state: absent
Explanation: the first task checks the package state and upgrades only if necessary. The second ensures the named package is absent. Running these tasks twice demonstrates idempotency when the system already matches the desired state.
Key Takeaway

Prefer the dnf module over shell package commands to get idempotent, auditable package changes.

Practical notes
  • Use state: latest to ensure the package is up-to-date.
  • Use state: absent to remove packages idempotently.
  • Test idempotency by running the playbook twice and observing changed → ok.
Common mistake

Running dnf install via shell loses Ansible's understanding of package state and may report changed every run, even when no update was necessary.
