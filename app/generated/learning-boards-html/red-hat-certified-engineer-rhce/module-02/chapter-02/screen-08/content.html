Comparison

copy vs file

Decide based on whether you need to transfer content or only manage filesystem state and attributes.

Use copy

To transfer files from the control node and enforce content plus metadata.

Use file

To create directories, set modes, or manage symlinks without copying content.

Concrete examples
- name: Copy Nginx configuration file ansible.builtin.copy: src: /path/to/local/nginx.conf dest: /etc/nginx/nginx.conf owner: root group: root mode: '0644' - name: Ensure application log directory exists ansible.builtin.file: path: /var/log/my_app state: directory mode: '0755'
Common misconception

Using file to try to copy content will not work. If you need templated content, choose template; if static files, use copy.
