Key Modules to Know

ansible.builtin.dnf

Manage packages idempotently: install, update, or remove packages on Red Hat-based systems.

ansible.builtin.service

Manage service runtime state and boot enablement in an idempotent way.

ansible.builtin.copy

Copy files from control node to hosts and enforce content plus metadata idempotently.

Summary Takeaway

These modules form the typical workflow: install (dnf), deploy content (copy), and manage daemons (service).
