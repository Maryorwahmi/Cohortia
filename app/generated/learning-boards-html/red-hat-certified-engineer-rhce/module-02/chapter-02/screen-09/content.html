Module Focus

Managing users and groups

Create, modify, and remove user accounts and groups with predictable results using the built-in modules.

- name: Create a new user 'webadmin' ansible.builtin.user: name: webadmin state: present shell: /bin/bash groups: wheel append: yes - name: Ensure 'webdevs' group exists ansible.builtin.group: name: webdevs state: present
Explanation: append yes ensures we add the user to wheel without removing other group memberships. Group ensures the named group exists and is idempotent.
Common mistakes & tips
  • For adding groups, set append: yes to avoid clobbering memberships.
  • Avoid shell useradd; user module records state and is idempotent.
  • Test user creation on a disposable VM before applying to production hosts.
Key Takeaway

Use user and group modules for repeatable account management and preserve existing group relationships with append when needed.
