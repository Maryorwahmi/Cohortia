Module Focus

Managing services with service

Ensure services are running and enabled without unnecessary restarts by using the built-in service module.

- name: Ensure Nginx service is running and enabled at boot ansible.builtin.service: name: nginx state: started enabled: yes - name: Stop a service ansible.builtin.service: name: firewalld state: stopped
Explanation: the first task checks both runtime and boot-enabled state, changing only when necessary. The second task stops the named service if it's running.
Practical checklist
  • Ensure package is installed before starting a service.
  • Use enabled: yes to configure boot behavior in a single task.
  • Run playbooks twice to confirm idempotency for both package and service tasks.
Common mistake

Using a shell command to restart a service each run leads to repeated changes and hides whether the service needed restarting. Prefer the service module.

Key Takeaway

Combine package and service modules to install and enable daemons predictably and idempotently.
