Core Concept

What is an Ansible module?

A concise definition, the execution model, and why modules are preferable to ad-hoc scripts for predictable automation.

Execution flow
  • Control node calls a module with arguments
  • Module runs on the managed host and inspects state
  • Module changes state only if required and returns results
Why it matters

Modules reduce complexity, improve safety, and provide structured reporting used by Ansible to show changed vs ok.

Key Takeaway

Use modules to ensure tasks run safely, report correctly, and can be re-run without unwanted side effects.

Concrete example
- name: Ensure Nginx is installed and latest ansible.builtin.dnf: name: nginx state: latest
Explanation: the dnf module will check package state and only install or upgrade when needed, returning changed for the first run and ok on subsequent runs if already current.
Common misconception

Thinking a module only calls system commands ignores the state checks modules perform. That state logic is why modules support safe, repeatable automation.
