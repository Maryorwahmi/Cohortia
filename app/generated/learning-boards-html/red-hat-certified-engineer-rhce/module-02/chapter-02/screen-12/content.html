Web Server Setup: playbook walkthrough

Follow this template to build a test playbook that installs nginx, copies a static index file, and ensures the service is running and enabled.

--- - name: Configure Nginx web server hosts: webservers # Or 'localhost' if testing locally become: yes tasks: - name: Install Nginx package ansible.builtin.dnf: name: nginx state: present - name: Copy custom index.html ansible.builtin.copy: src: ./files/index.html dest: /usr/share/nginx/html/index.html owner: root group: root mode: '0644' - name: Ensure Nginx service is running and enabled ansible.builtin.service: name: nginx state: started enabled: yes
Verify

Run the playbook twice. On the first run you should see changed where actions applied; on the second run tasks should report ok when the system already matches the desired state.

Checks
  • systemctl status nginx
  • curl http://localhost to view the deployed index.html
