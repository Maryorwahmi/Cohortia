Module 5 › Chapter 5.4 › What is Generic Programming?
Core Concept

Generic programming explained

Describe algorithms in terms of operations; supply types later. Templates are compile-time blueprints, not runtime polymorphism.

Analogy
Blueprint used with different materials produces different buildings.
Misconception
Templates are not runtime virtual dispatch; they expand at compile time into concrete code.
Key Takeaway

Write once, compile many: templates remove duplication while preserving performance.

Concrete example
#include <iostream>

// Function template to find the maximum of two values
template <typename T>
T maximum(T a, T b) {
  return (a > b) ? a : b;
}

int main() {
  int i = maximum(10, 20);        // instantiates maximum<int>
  double d = maximum(3.14, 2.71); // instantiates maximum<double>
}
Why it matters
Templates enable a single verified implementation to serve many types, reducing bugs and simplifying maintenance.
