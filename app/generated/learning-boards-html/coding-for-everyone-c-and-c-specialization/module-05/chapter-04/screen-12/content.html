Module 5 › Chapter 5.4 › Implementing a Generic Pair Class
Starter code
#include <iostream>
#include <string>

// Define the class template Pair
template <typename T1, typename T2>
class Pair {
private:
  T1 first;
  T2 second;
public:
  Pair(T1 f, T2 s) : first(f), second(s) {}
  T1 getFirst() const { return first; }
  T2 getSecond() const { return second; }
  void setFirst(T1 f) { first = f; }
  void setSecond(T2 s) { second = s; }
};

int main() {
  Pair<int, double> p1(10, 20.5);
  std::cout << p1.getFirst() << ", " << p1.getSecond() << std::endl;
}
Test multiple type combinations and ensure getters and setters behave as expected. Keep the template in a header to allow instantiation across translation units.
Common pitfalls
  • Returning references to local temporaries.
  • Forgetting template parameters when instantiating the class.
Extension
Add move semantics or const-reference getters for efficiency and document behavior for large types.
Key Takeaway

Implementing Pair reinforces class templates, constructor initialization, and safe getter/setter design across types.
