Function Template

maximum<T> walkthrough

#include <iostream>
#include <string>

template <typename T>
T maximum(T a, T b) {
  return (a > b) ? a : b;
}

int main() {
  int im = maximum(10, 20);           // generates maximum<int>
  double dm = maximum(3.14, 2.71);    // generates maximum<double>
  std::string s = maximum(std::string("a"), std::string("b"));
}
Deduction caveat
Calling with mixed types prevents automatic deduction; specify the template type explicitly or cast.
Practical tip
Keep template bodies restricted to operations you know the intended types support.
Example scenario

You have two sort functions for different numeric types. Replace them with a single template and compile tests that use int and double to confirm behavior. If compilation fails for another type, check what operation is unsupported.

Common mistake
Assuming deduction will convert mixed arguments; it will not. Be explicit or cast when types differ.
Key Takeaway

Templates are instantiated per used type; deduction is convenient but has limits you must handle explicitly.
