Module 5 › Chapter 5.4 › Template Type Parameters and Deduction
Deduction process
  1. Compiler parses the template definition without concrete types.
  2. At each call site, it tries to deduce type parameters from arguments.
  3. If a concrete type is found, it instantiates a specialized function or class for that type.
  4. If deduction fails, provide explicit template arguments or convert values.
Quick checklist when deduction fails
  • Compare actual argument types for compatibility.
  • Try an explicit template argument like maximum<double>(10, 20.5).
  • Consider overloads or casts as a last resort.
Example
maximum(10, 20.5) fails deduction. Fix: maximum<double>(10, 20.5) or cast 10 to double.
Misconception
The compiler will not silently choose a wider type for you during deduction; it needs a single consistent T.
Key Takeaway

When deduction stumbles, make the intended type explicit or align argument types so the compiler can instantiate correctly.
