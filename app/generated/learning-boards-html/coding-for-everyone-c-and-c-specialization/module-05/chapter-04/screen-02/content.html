Learning Objectives

Concrete skills you will demonstrate by coding and reasoning about templates.

Bloom: Learn → Understand → Apply → Master
01
Explain generic programming

Describe how algorithms can be independent of data types and why that reduces duplication and bugs.

VERIFIED COMPETENCY MILESTONE
02
Implement function templates

Write a maximum function template and demonstrate instantiations for int, double, and string.

VERIFIED COMPETENCY MILESTONE
03
Implement class templates

Build a Stack or Pair class template and use different type arguments to verify behavior.

VERIFIED COMPETENCY MILESTONE
04
Diagnose template instantiation issues

Explain two-phase lookup, header-only practice, and identify the first compiler error in noisy template traces.

VERIFIED COMPETENCY MILESTONE
