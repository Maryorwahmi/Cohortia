Class Template Example
#include <vector>
#include <stdexcept>

template <typename T>
class Stack {
private:
  std::vector<T> elements;
public:
  void push(const T& item) { elements.push_back(item); }
  T pop() {
    if (elements.empty()) throw std::runtime_error("Stack is empty!");
    T item = elements.back(); elements.pop_back();
    return item;
  }
  bool isEmpty() const { return elements.empty(); }
  size_t size() const { return elements.size(); }
};

Instantiate as Stack<int> or Stack<std::string>. Each instantiation becomes a distinct compiled type with the same interface.

Design tips
  • Keep the interface minimal and well-documented.
  • Document type requirements: what operations T must support.
  • Handle exceptional states consistently.
Common mistake
Writing Stack without template arguments, e.g., Stack myStack; the compiler requires explicit template parameters.
Key Takeaway

Class templates provide typed containers by instantiation; design interfaces and document supported operations on the parameter types.
