Module 5 › Chapter 5.4 › Header-Only Templates vs Separate Definitions
Header-only
  • Definitions are in headers, visible at instantiation.
  • Compiler can generate concrete types where needed.
  • Preferred default for general templates.
Separate .cpp
  • Hiding definitions in .cpp causes link-time unresolved symbols for instantiations in other translation units.
  • Explicit instantiation is an advanced alternative but often impractical.
Practice note
If you must separate, either provide explicit instantiations for all needed combinations in the implementation file or include the implementation into the header so the compiler can instantiate as needed.
Key Takeaway

Prefer header-only templates so the compiler can instantiate templates where they are used; separate definitions commonly cause linker errors.
