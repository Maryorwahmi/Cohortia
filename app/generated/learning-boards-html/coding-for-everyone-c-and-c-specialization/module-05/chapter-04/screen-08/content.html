Module 5 › Chapter 5.4 › Non-Type Template Parameters
Definition

Compile-time constants as template arguments

template <typename T, size_t N>
class Array {
  T data[N];
};

// Usage:
// Array<int, 10> and Array<double, 5> are different types

Non-type parameters let the compiler place configuration into types without runtime cost. They are constrained to constant expressions and thus cannot depend on runtime input.

When to use
Fixed-size containers, compile-time tuning, or when a parameter must be part of the type identity.
Pitfall
Different non-type values create different types, preventing straightforward assignments between them.
Key Takeaway

Non-type parameters encode compile-time configuration into types for zero-cost specialization.
