Module 5 › Chapter 5.4 › Template Instantiation and Two-Phase Lookup
Two-phase compilation
  1. Parsing phase: template syntax is parsed and stored without concrete types.
  2. Instantiation phase: for each use, the compiler substitutes template arguments and type-checks the body.
  3. If valid, a concrete function or class is generated and compiled.
Why header-only matters
The compiler must see the full template body at the point of instantiation. Placing definitions in headers ensures availability across translation units.
Observed symptom
Linker error like "unresolved external" often indicates template definitions are hidden in a .cpp while instantiations occur elsewhere.
Debug tip
Find the first error in a long trace — it usually pinpoints the invalid use of the template parameter.
Key Takeaway

Templates are compiled in two phases; ensure definitions are visible at instantiation time to avoid linker and instantiation errors.
