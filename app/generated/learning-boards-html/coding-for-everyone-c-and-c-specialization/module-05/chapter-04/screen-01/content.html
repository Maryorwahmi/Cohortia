Templates: Generic Programming

Write a single blueprint that the compiler uses to build many concrete functions or classes. Templates reduce duplication and increase reuse while keeping type safety.

Problem
Duplicate max_int, max_double
Solution
Function templates like maximum<T>
Result
Reusable, type-safe code
In this lesson
  • How function and class templates are written and instantiated.
  • Type vs non-type template parameters and when to use each.
  • Header-only compilation, common errors, and debugging strategies.

Visual Concept
Blueprints → Types
Template
template <typename T> T maximum(T a, T b)
Instantiations
maximum<int>, maximum<double>, maximum<std::string>
Why this matters
One definition, many compiled types. Less duplication, consistent behavior.
