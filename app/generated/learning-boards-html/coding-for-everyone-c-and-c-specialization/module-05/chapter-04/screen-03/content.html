From objective to practice

Small checks you can run right now to verify each learning objective.

Verify function templates
  • Implement maximum<T> and call with int and double.
  • Call with mixed types, observe deduction failure, then call with explicit template argument.
Verify class templates
  • Create Stack<int> and Stack<std::string> instances and run push/pop tests.
  • Ensure constructors and methods compile for both types.
Check instantiation
  • Move template implementation to a .cpp and observe linker errors, then move it to header to fix.
Read errors effectively
  • Locate the first error in the trace and inspect how T is used where the failure occurred.
