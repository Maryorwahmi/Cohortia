Multiple-choice & design prompts
Question 1
Which signature is preferred for operator== to allow symmetric implicit conversions? Explain your choice.
Question 2
How would you implement matrix[row][col] access given that operator[] accepts a single argument? Sketch the proxy pattern.
Expected answers
Use a non-member friend operator== for symmetric conversions; implement operator[] to return a Row proxy that itself supports operator[] for column access.
Reflection

Consider the conversion and usability consequences of your operator choices when designing public class APIs.
