Core idea

Operator overloading explained

Operators map to functions. Use them to make expressions on your types concise and readable while respecting expected behavior.

Analogy
Think of an operator as a verb like add. Overloading tells the class how to perform that verb for its state.
Misconception
You cannot create new operators or change precedence. Overloading only provides implementations for existing symbols.
Key Takeaway

Use operator overloading to make types behave like built-ins, but keep the operator's expected meaning.

Concrete example
class Vector2D {
private:
  double x, y;
public:
  Vector2D(double _x=0, double _y=0): x(_x), y(_y) {}
  Vector2D operator+(const Vector2D& other) const {
    return Vector2D(x + other.x, y + other.y);
  }
};

// Usage:
// Vector2D a(1,2), b(3,4);
// Vector2D c = a + b; // (4,6)
Why const?
Marking the method const lets the operator be used on const objects and guarantees no modification.
Why return by value?
Arithmetic should produce a new object, so returning by value is the usual pattern.
