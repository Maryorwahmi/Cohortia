Module 5 › Chapter 5.3 › Stream Operators
Code example
class Vector2D {
  double x, y;
public:
  Vector2D(double _x=0, double _y=0): x(_x), y(_y) {}
  friend std::ostream& operator<<(std::ostream& os, const Vector2D& v) {
    os << "Vector(" << v.x << ", " << v.y << ")";
    return os; // enable chaining
  }
  friend std::istream& operator>>(std::istream& is, Vector2D& v) {
    char ch1, ch2, ch3;
    is >> ch1 >> v.x >> ch2 >> v.y >> ch3; // expects (x, y)
    return is;
  }
};
Key points: operator<< and operator>> are non-member functions. Mark them friend if they need access to private fields. Always return the stream reference to allow chaining.
Quick notes
  • Friend: Grants access but is not a member method.
  • Parameter order: Streams come first: ostream& then const T&.
  • Return: Return the same stream by reference for chaining.
Misconception check
Declaring a friend doesn't hide design problems; use it selectively to keep encapsulation reasonable.
