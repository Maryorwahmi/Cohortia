operator<<
std::ostream& operator<<(std::ostream& os, const Vector2D& v) {
  os << "Vector(" << v.x << ", " << v.y << ")";
  return os;
}
Keep formatting simple and return the stream. Chaining depends on returning the same stream reference.
operator>>
std::istream& operator>>(std::istream& is, Vector2D& v) {
  char o, c;
  if (!(is >> o >> v.x >> c >> v.y >> c)) {
    is.setstate(std::ios::failbit);
  }
  return is;
}
Validate separators and set the stream's failbit on error so callers can detect malformed input.
Check

Test reading and writing together: reading should fail cleanly on bad input and writing should allow chaining without side effects.
