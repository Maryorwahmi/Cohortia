Module 5 › Chapter 5.3 › Member vs Non-member
Member overload
Signature: ReturnType Class::operatorOp(Other) const. Left operand is this. Good for unary and when left-hand must be class.
Return by value for arithmetic results.
Mark const to allow calls on const objects.
Non-member (friend) overload
Signature: ReturnType operatorOp(Left, Right). Use when left is not your class or when you need symmetric conversions. Mark friend if private access is required.
Essential for operator<< and operator>> where stream must be left operand.
Return stream references for chaining.
Misconception

Friend functions are not methods; they simply gain access. Use them only when necessary to keep class interfaces stable.
