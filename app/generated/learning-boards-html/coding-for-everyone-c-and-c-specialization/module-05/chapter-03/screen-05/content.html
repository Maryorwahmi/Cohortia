Module 5 › Chapter 5.3 › Member Overloads
Code walkthrough
class Vector2D {
  double x, y;
public:
  Vector2D(double _x=0, double _y=0): x(_x), y(_y) {}
  Vector2D operator+(const Vector2D& other) const {
    return Vector2D(x + other.x, y + other.y);
  }
  Vector2D operator-() const { // unary minus
    return Vector2D(-x, -y);
  }
};
Note how operator+ takes one parameter because this is the left operand. Declaring the function const allows calls on const instances.
Remember: return by value for arithmetic results. Return by reference for assignment operators to support chaining.
Explanation cards
When to use
Use member overloads when left operand is naturally your class and you need implicit access to this.
Common mistake
Forgetting const prevents overloads from working with const objects and causes confusing compiler errors.
Check your understanding
If operator+ is a member, can an int + MyType call it? No, because the left operand must be MyType or convertible to it.
Key Takeaway

Choose member overloads when the class is the natural left operand and keep methods const when they don't mutate state.
