Module 5 › Chapter 5.3 › Final Reminders
1. Preserve semantics
Overloads should behave like the built-in operators users expect.
2. Choose form
Member for left-class; non-member friend for streams or symmetric conversions.
3. Signature rules
Use const refs and correct return types to enable chaining and const usage.
Final takeaway

Well-designed operator overloads make your types expressive while remaining predictable and safe.
