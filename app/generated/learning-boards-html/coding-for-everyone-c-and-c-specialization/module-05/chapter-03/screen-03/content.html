Practical Skills Checklist

Actions to complete during the live coding and the Fraction lab.

Correct return types
Return new value objects for arithmetic, return stream references for I/O chaining.
Const-correct signatures
Mark methods const when they don't modify object state to enable use with const operands.
Friend stream operators
Declare operator<< and operator>> as friends so they can access private members for I/O.
Safety checks
Handle denominator zero, simplify fractions, and preserve expected operator behavior.
