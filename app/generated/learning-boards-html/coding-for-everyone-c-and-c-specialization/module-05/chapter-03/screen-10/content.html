Common mistakes and how to fix them
  • Missing const: Add const to methods that do not change object state.
  • Wrong return type: Use value returns for arithmetic, & for assignment, stream& for I/O.
  • Semantics: Keep operator meaning consistent with user expectations.
  • Un-overloadable operators: Don't attempt to overload scope resolution or the ternary operator.
  • Parsing errors: Set stream failbit on bad input; avoid leaving the stream partially consumed.
Pro tip
Write small unit tests that exercise chaining behavior, const and non-const overloads, and malformed input to catch these mistakes early.
Warning

Changing operator meaning is a serious violation of API expectations and should be avoided.
