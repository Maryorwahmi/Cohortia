Module 5 › Chapter 5.3 › Key Concepts
Operator Overloading
Provide class-specific implementations for existing operators to improve expressiveness.
Member vs Non-member
Members use this for left operands; non-members required when another type must be left operand or symmetry is needed.
Const & Returns
Mark const when appropriate; return by value for arithmetic, by reference for assignment, and stream references for I/O.
Summary takeaway

Design overloads that match developer expectations, use the correct form and types, and test chaining and edge cases.
