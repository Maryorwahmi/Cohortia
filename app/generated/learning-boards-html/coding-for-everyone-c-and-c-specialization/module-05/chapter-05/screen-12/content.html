Common Pitfall
Object Slicing
Slicing removes derived-specific data and behavior when copying by value to a base object.
Bad example
Derived d; Base b = d; // slices derived parts
Avoidance
  • Pass by reference or pointer instead of by value.
  • Store pointers (smart pointers) in containers instead of object slices.
  • Use clone methods if you need to copy polymorphically.
Concrete remedy
Change functions that take Base b to take const Base& b or Base* b. Using const references avoids copies and preserves the derived object identity so virtual functions continue to dispatch to derived implementations.
Misconception
Slicing is not just a missing field; methods that depend on derived behavior will also break because the dynamic type is lost.
