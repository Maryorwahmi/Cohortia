Command Processor
Follow the template to implement a polymorphic command processor.
#include <iostream>
#include <vector>
#include <memory>

class Command {
public:
  virtual void execute() = 0; // pure virtual
  virtual ~Command() { std::cout << "Command destructor called." << std::endl; }
};

Scaffolding & Tips
  • Use make_unique to construct commands into the vector.
  • Keep execute parameterless for simplicity in this exercise.
  • Verify destructors print messages to confirm proper destruction order.
