Mechanism
vtable and vptr
A per-class table of function addresses and a per-object pointer that links to it.
vtable
A compiler-generated table holding pointers to the virtual implementations for a class.
vptr
A hidden pointer in each object that points to that object's class vtable.
Dynamic dispatch
A call through a base pointer uses the object's vptr to find and call the correct function address at runtime.
Annotated View
Class A vtable
[ <addr> draw, <addr> print, <addr> ~A ]
Object instance layout
vptr → points to Class A vtable; data members follow vptr in memory layout.
Why it matters
Understanding vtables helps explain why virtual calls have one indirection and why destructors must be virtual for correct cleanup order.
