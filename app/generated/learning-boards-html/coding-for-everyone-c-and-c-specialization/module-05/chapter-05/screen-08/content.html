Shape example
Read the code to see how virtual draw and smart pointers work together.
#include <iostream>
#include <vector>
#include <memory>

class Shape {
public:
  virtual void draw() const { std::cout << "Drawing a generic shape." << std::endl; }
  virtual ~Shape() { std::cout << "Shape destructor called." << std::endl; }
};

class Circle : public Shape {
public:
  void draw() const override { std::cout << "Drawing a Circle." << std::endl; }
  ~Circle() { std::cout << "Circle destructor called." << std::endl; }
};

int main() {
  std::vector<std::unique_ptr<Shape>> shapes;
  shapes.push_back(std::make_unique<Circle>());
  shapes.push_back(std::make_unique<Shape>());

  for (const auto & s : shapes) {
    s->draw(); // dynamic dispatch
  }
}
Output will include Drawing a Circle. and Drawing a generic shape., and destructors called when unique_ptr releases objects. Try adding a Square derived class; no changes to the loop are needed.
Explanation
  • unique_ptr preserves polymorphic ownership and prevents leaks.
  • virtual draw and override ensure correct method selection at runtime.
  • Putting a base object into the vector is allowed; its draw remains the base implementation.
