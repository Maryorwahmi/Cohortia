Definition
Pure Virtual & Abstract Class
A pure virtual function sets a required contract for derived classes and makes the base abstract.
Key points
  • Declare with = 0 to make a function pure virtual.
  • An abstract class cannot be instantiated directly.
  • Use virtual destructor with abstract bases to ensure safe cleanup.
Example Interface
class Drawable {
public:
  virtual void draw() const = 0; // pure virtual
  virtual ~Drawable() = default;  // virtual destructor
};
Any class inheriting Drawable must provide draw to become concrete. This pattern enforces consistent behavior across implementers.
