Learning Objectives
Practical skills to design polymorphic hierarchies and avoid common mistakes.
Bloom: Learn → Understand → Apply → Master
Progression bar: from concept to applied design
01
Explain polymorphism
Define many-forms behavior and differentiate compile-time and runtime polymorphism.
VERIFIED COMPETENCY MILESTONE
02
Implement runtime polymorphism
Use virtual functions and pointers/references to base types to dispatch to derived behavior.
VERIFIED COMPETENCY MILESTONE
03
Use pure virtual functions
Create abstract classes to define interfaces that derived types must implement.
VERIFIED COMPETENCY MILESTONE
04
Identify common pitfalls
Recognize object slicing and the need for virtual destructors to avoid leaks and incorrect behavior.
VERIFIED COMPETENCY MILESTONE
