Core Concept
What is Polymorphism?
A single interface used by many concrete types.
Quick definition

Polymorphism allows objects of different derived classes to respond differently to the same function call through a shared base type.

Analogy

Think of an electrical outlet: many devices plug in and each behaves according to its design though the plug interface is the same.

Example
A renderer loops over Shape pointers and calls draw(); each concrete shape provides its own implementation so the renderer remains unchanged when new shapes are added.
Key Takeaway

Use polymorphism to separate what code does from how specific types implement the behavior.

Definition Visual
Compile-time
Overloading and templates where the compiler selects the function.
Runtime
Virtual functions, vtable lookups, and dynamic dispatch using base pointers or references.
Misconception
Polymorphism is not automatically present with inheritance; methods must be virtual and objects must be accessed via pointers or references to enable runtime behavior.
