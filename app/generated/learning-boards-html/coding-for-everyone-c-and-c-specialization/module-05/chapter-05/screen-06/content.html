Process Flow
Steps to Enable Runtime Polymorphism
1.
Declare virtual in base
Mark the function virtual to trigger vtable generation.
2.
Override in derived
Provide derived implementations and use override to catch mistakes.
3.
Use pointers or references
Store objects polymorphically in pointers or references, not by value.
4.
Virtual destructor
Ensure proper cleanup when deleting through a base pointer.
Misconception: Declaring derived methods with the same name is not enough; the base must be virtual for dynamic dispatch through base pointers.
Concrete Checklist
Code pattern
virtual void draw() const; // base class Circle : public Shape { void draw() const override; } // derived
Pro tip
Prefer override to catch signature mismatches and use smart pointers like unique_ptr to manage lifetimes.
Common mistake
Passing by value causes slicing and defeats polymorphism. Use references or pointers instead.
