Learning Objectives

Learn, understand, apply, and prepare to master inheritance patterns.

Bloom: Learn → Understand → Apply → Master
01
Explain inheritance & is-a

Define inheritance as creating a derived class from a base class and use examples like Dog is an Animal to show reuse and specialization.

VERIFIED COMPETENCY MILESTONE
02
Differentiate access specifiers

Compare public, protected and private inheritance and predict which members are visible to derived classes and external code.

VERIFIED COMPETENCY MILESTONE
03
Trace constructor/destructor order

Describe why base constructors run before derived constructors and why destructors run in reverse, ensuring safe initialization and cleanup.

VERIFIED COMPETENCY MILESTONE
04
Implement simple hierarchies

Write base and derived classes in C++, forwarding constructor parameters and implementing derived methods for behavior like area calculations.

VERIFIED COMPETENCY MILESTONE
