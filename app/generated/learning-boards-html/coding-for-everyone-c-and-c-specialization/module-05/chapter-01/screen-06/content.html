Module 5 › Chapter 5.1 › Constructor Order
Code Example
#include <iostream>
#include <string>

class Animal {
public:
    std::string name;
    Animal(const std::string& n) : name(n) {
        std::cout << "Animal constructor called for " << name << std::endl;
    }
    ~Animal() { std::cout << "Animal destructor called for " << name << std::endl; }
};

class Dog : public Animal {
public:
    std::string breed;
    Dog(const std::string& n, const std::string& b) : Animal(n), breed(b) {
        std::cout << "Dog constructor called for " << name << " (" << breed << ")" << std::endl;
    }
    ~Dog() { std::cout << "Dog destructor called for " << name << std::endl; }
};

int main() {
    Dog myDog("Buddy", "Golden Retriever");
    return 0;
}
Explanation & Trace
  • When myDog is created, Animal constructor runs first to initialize base fields.
  • Dog constructor runs next to initialize breed and derived behavior.
  • When myDog goes out of scope, Dog destructor runs first, then Animal destructor.
Key Takeaway

Always ensure base initialization is performed, especially when base constructors require arguments. Trace printed messages to confirm the order.
