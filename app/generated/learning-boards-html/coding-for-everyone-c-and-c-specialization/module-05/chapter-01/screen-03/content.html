Practice and Pitfalls

What to watch for as you implement inheritance and test your code.

Apply → Test → Review
01
Identify common mistakes

Recognize missing base constructor calls, trying to read private base members, and overcomplicated deep hierarchies that hurt maintenance.

VERIFIED COMPETENCY MILESTONE
02
Complete the Shape activity

Implement Shape with protected color, Circle and Rectangle with constructors that call Shape, and methods that return area values.

VERIFIED COMPETENCY MILESTONE
03
Understand interface hiding

Private inheritance hides the base interface from users of the derived class; use it intentionally when you want implementation rather than an "is-a" relationship.

VERIFIED COMPETENCY MILESTONE
04
Prepare for polymorphism

Note: if you will delete derived objects via base pointers, the base should later include a virtual destructor — this chapter flags that and points forward to polymorphism topics.
