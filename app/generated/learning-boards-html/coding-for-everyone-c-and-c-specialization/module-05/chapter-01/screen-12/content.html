Q1: Constructor/Destructor Order
Base Constructor
Derived Constructor
Derived Destructor
Base Destructor
Reason: the base initializes the base subobject first. On destruction, the derived class must clean up its resources before the base is destroyed, so destructors run in reverse order.
Q2: Access to members
Given engineType is private and maxSpeed is protected in Vehicle, a derived Car using public inheritance can access maxSpeed directly but not engineType. Private members are never directly accessible to derived classes.
Key Takeaway

Trace lifecycle order for constructors/destructors and use protected when you want derived access but keep members hidden externally.
