Process Flow

Five steps to design inheritance

1
Is-it "is-a"?
Confirm subtype semantics before reusing code.
2
Centralize common members
Put shared data and methods in the base.
3
Choose access
Public, protected, or private depending on exposure needs.
4
Forward constructors
Use initializer lists to initialize base subobjects correctly.
5
Test lifecycle
Confirm construction, method access and destructor order with small main tests.
Example: Book → Magazine
Identify borrow and returnBook in Book; make Magazine inherit publicly and add issueNumber. Forward title/author via constructor and test method calls.
