Definition

Inheritance and the "is-a" idea

Inheritance lets a derived class reuse attributes and methods from a base class and add specialized behavior.

Concrete example
Animal defines name, eat(), sleep(); Dog inherits these, adds breed and bark(). This reduces duplicate code across animal types.
Common misconception
Inheritance is not a general reuse tool. Ask whether a true subtype relationship exists; if not, prefer composition.
Why it matters
Correctly used inheritance centralizes shared behavior, simplifies maintenance, and clarifies intent in your class designs.
Analogy & Visual
Book → Magazine

Book has title, author, ISBN, borrow() and returnBook(). Magazine can inherit those and add issueNumber and publicationDate, removing duplication.

Quick checks
  • Is the relationship truly a specialization?
  • Will derived objects need the base interface publicly?
  • Can initialization be forwarded correctly?
Key Takeaway
Use inheritance to model clear subtype relationships, centralize shared behavior, and avoid deep hierarchies that complicate maintenance.
