Module 5 › Chapter 5.1 › Key Concepts
Inheritance (is-a)
Derived classes reuse and extend base classes to model specialization without duplicating code.
Access Specifiers
Public preserves, protected restricts externally but allows descendants, private hides the base interface from users of the derived object.
Constructor/Destructor Order
Base constructors run before derived; destructors run in reverse order so derived resources are cleaned first.
Summary

Use inheritance for true specialization, pick the right access level, forward base initialization, and keep hierarchies shallow. Practice with the Shape activity and review constructor messages to confirm behavior.
