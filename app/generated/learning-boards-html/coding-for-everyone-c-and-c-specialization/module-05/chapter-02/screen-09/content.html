Starter Code

Modify the base class to be abstract, implement derived areas, and use a polymorphic container.

#include <iostream>
#include <cmath> // For M_PI
#include <vector>

class Shape {
protected:
  std::string color;
public:
  Shape(const std::string& c) : color(c) {}
  void displayColor() const { std::cout << "This shape is " << color << "." << std::endl; }
  virtual double calculateArea() const = 0; // pure virtual
  virtual ~Shape() { std::cout << "Shape destructor called for color: " << color << std::endl; }
};

// Circle and Rectangle implement calculateArea and override destructor
Run checklist
  1. Make calculateArea pure virtual.
  2. Implement Circle and Rectangle calculateArea.
  3. Create std::vector<Shape*> and add objects.
  4. Iterate, call methods, delete objects.
Pro tip
Prefer smart pointers like std::unique_ptr to manage ownership and avoid manual delete in real code.
Concrete expectation

When you iterate the vector and call calculateArea on each Shape*, each derived implementation will compute its area correctly. Deleting the pointers will call derived destructors first then the base destructor if it is virtual.

Key Takeaway

Make Shape abstract to force derived implementation, store polymorphic objects via pointers, and clean up properly to observe polymorphism.
