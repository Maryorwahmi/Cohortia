Architecture

Interfaces vs Implementations

Define stable interfaces with abstract bases and keep implementation details in derived classes for flexibility and testability.

Client code

Depends on the abstract base type and calls virtual methods; it should not depend on concrete derived types.

Concrete implementers

Implement required virtual functions and encapsulate implementation details; new implementations can be added without changing clients.

Key Takeaway

Design APIs around abstract bases and keep concrete details isolated so your system remains extensible and testable.

Analogy

Think of an electrical socket as the interface and different appliance plugs as implementations; new appliances work without changing the socket.

Misuse warning

Do not use inheritance purely for code reuse. Prefer composition if shared behavior can be factored into member objects rather than imposing an is-a relationship.
