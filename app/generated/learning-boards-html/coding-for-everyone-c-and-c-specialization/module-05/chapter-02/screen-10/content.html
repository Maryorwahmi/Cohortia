Module 5 › Chapter 5.2 › override & final
Language Feature

override and final

Annotate intent and let the compiler help you catch mistakes or lock behavior.

override

Place override after the derived method signature to ensure it matches a base virtual method; a mismatch becomes a compile-time error.

final

Use final on a virtual function to prevent further overrides, or on a class to prevent inheritance.

Key Takeaway

Annotate overridden functions with override and use final to fix an API surface when extension would be unsafe or confusing.

Example scenario

If you intend to override void draw() const but accidentally write void draw(), using override causes the compiler to complain about the missing const — saving a subtle runtime bug.

Misconception

override and final are compile-time safety tools. They do not change dynamic dispatch semantics but prevent programmer errors that could break those semantics.
