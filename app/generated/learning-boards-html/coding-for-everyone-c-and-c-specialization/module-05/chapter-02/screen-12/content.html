Comparison

Common mistakes and fixes

Slicing

Cause: storing derived by value. Fix: use pointers/references or smart pointers.

Missing virtual

Cause: base method is not virtual. Fix: declare base method virtual to enable dynamic dispatch.

No override

Cause: signature mismatch silently creates new method. Fix: use override to force compile-time checks.

Non-virtual destructor

Cause: only base destructor runs on delete. Fix: make base destructor virtual for polymorphic classes.

Pro tip

Favor std::unique_ptr<Base> in containers to prevent leaks and avoid manual delete while preserving polymorphism.
