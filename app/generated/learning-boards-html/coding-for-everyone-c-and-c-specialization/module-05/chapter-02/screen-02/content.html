Learning Objectives

Understand, apply, and design polymorphic C++ code.

Bloom: Learn → Understand → Apply → Master
01
Define polymorphism in C++

Explain how different derived objects respond to the same base operation and why this simplifies code that works with collections of mixed types.

Mnemonic: Many forms, one interface
VERIFIED COMPETENCY MILESTONE
02
Understand virtual functions & dynamic dispatch

Describe how declaring a method virtual lets C++ choose the derived override at runtime when called through a base pointer or reference.

Mnemonic: Call via pointer, pick real type
VERIFIED COMPETENCY MILESTONE
03
Explain the slicing problem

Show when assigning a derived object to a base object by value loses derived parts and how pointers/references prevent this loss.

Mnemonic: Don't copy polymorphic objects by value
VERIFIED COMPETENCY MILESTONE
04
Differentiate virtual, pure virtual, and abstract

Recognize when to make a function pure virtual and why that makes the base class abstract and uninstantiable.

Mnemonic: Pure virtual = interface requirement
VERIFIED COMPETENCY MILESTONE
