Module 5 › Chapter 5.2 › Key Concepts
Polymorphism
Different types respond to the same call based on runtime type.
Virtual function
Declare base methods virtual to enable late binding when called via base pointers or references.
Virtual destructor
Make base destructors virtual to ensure proper derived cleanup during deletion.
Slicing
Assigning derived to base by value loses derived parts; use pointers or smart pointers instead.
override & final
Use override to catch signature mismatches and final to prevent further overrides.
Abstract classes
Use pure virtual functions (= 0) to make bases abstract and enforce implementations.
Summary
Polymorphism, when used with virtual functions and safe ownership patterns, enables extensible and maintainable C++ code. Remember the rules: virtual base methods, pointer/reference storage, override/final annotations, and virtual destructors.
