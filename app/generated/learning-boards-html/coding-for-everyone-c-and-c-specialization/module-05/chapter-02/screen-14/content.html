Quick checks

Use these to self-verify your understanding of polymorphism.

Conceptual
  1. What happens when you assign a derived object to a base object by value?
  2. Why make a base destructor virtual?
Practical
  1. Convert a non-virtual method to virtual, add override in derived, and observe runtime change.
  2. Change std::vector<Base> to std::vector<std::unique_ptr<Base>> and confirm polymorphism and proper cleanup.
Key Takeaway

Small, focused experiments in code reveal subtle polymorphism bugs and reinforce safe patterns such as override and virtual destructors.
