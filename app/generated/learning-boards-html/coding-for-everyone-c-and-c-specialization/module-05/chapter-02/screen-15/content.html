Practical Tip

Smart pointers & polymorphism

Use smart pointers in containers to manage lifetime while preserving dynamic dispatch.

Recommended pattern
std::vector<std::unique_ptr<Shape>> shapes;
shapes.push_back(std::make_unique<Circle>("Red", 5.0));
shapes.push_back(std::make_unique<Rectangle>("Blue", 4.0, 6.0));
for (const auto &s : shapes) {
  s->displayColor();
  std::cout << "Area: " << s->calculateArea() << std::endl;
}
Key Takeaway

Smart pointers preserve polymorphism and automate destruction; prefer them over raw pointers in modern C++ containers.

Why smart pointers?

They prevent memory leaks, are exception-safe, and ensure the correct derived destructor runs because the stored type retains polymorphic identity.

Misconception

Smart pointers don't change how virtual dispatch works; they only manage lifetime. Polymorphism still requires virtual functions and base pointers or references.
