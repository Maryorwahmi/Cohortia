Module 5 › Chapter 5.2 › Pure Virtual & Abstract
Definition

Pure virtual functions

Declare a function with = 0 to force derived classes to implement it and to make the base class abstract.

Example

virtual double calculateArea() const = 0; in Shape ensures every concrete shape provides an area computation.

Behavior

Attempting to instantiate Shape directly will cause a compile error because it's abstract.

Key Takeaway

Use pure virtual functions to define interfaces and make incomplete base classes abstract so only complete derived types can be instantiated.

Starter code (concept)
class Shape {
public:
  virtual double calculateArea() const = 0;
  virtual ~Shape() {}
};

class Circle : public Shape {
  double calculateArea() const override { /* ... */ }
};
Misconception

An abstract class can still contain implemented methods or data; it's not an empty interface unless you make it so.
