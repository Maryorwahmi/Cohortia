Module 5 › Chapter 5.2 › What to Remember
Make base methods virtual
Virtual in the base plus pointer/reference calls are required for runtime behavior.
Avoid slicing
Use pointers or smart pointers in containers to keep full derived identity.
Annotate intent & cleanup
Use override/final for safety and virtual destructors for correct cleanup.
One-line summary
Follow the checklist: virtual base methods, pointer/reference storage, override/final, virtual destructors, and smart pointers for safe ownership.
