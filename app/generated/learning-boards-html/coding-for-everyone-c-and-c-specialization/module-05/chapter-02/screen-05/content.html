Process Flow

How virtual functions enable dispatch

Follow these steps to make calls resolve at runtime.

1. Declare virtual
Give the base method the virtual keyword to signal runtime override.
2. Override in derived
Implement the method in each derived class using matching signature.
3. Use base pointers/refs
Store or pass objects via Base* or Base& so runtime type is preserved.
4. Call and dispatch
Call through base pointer/reference and runtime chooses the derived override.
Concrete example

Animal* pet = new Dog("Buddy"); pet->makeSound(); results in Dog's makeSound running because the call goes through a base pointer.

Common mistake

Calling through a base object copy uses the base type's method and defeats polymorphism – that is object slicing.

Key Takeaway

Make the base method virtual and invoke it via pointer or reference to get dynamic behavior at runtime.
