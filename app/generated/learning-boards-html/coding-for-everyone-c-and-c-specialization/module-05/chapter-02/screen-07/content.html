Comparison

Value assignment vs pointer/reference

Compare the behaviors and choose the right storage for polymorphic objects.

Value assignment (slicing)

Derived object copied into base object loses derived fields and methods; virtual dispatch no longer reaches derived overrides because the object is now a base instance.

Pointer/reference

Pointing or referencing preserves the full derived object, so virtual calls still dispatch to the derived implementation.

Key Takeaway

Never store polymorphic objects by value if you expect derived behavior; use pointers, references, or smart pointers in containers.

Concrete code scenario

Dog buddy("Buddy"); Animal genericAnimal = buddy; // slicing: genericAnimal behaves like Animal, not Dog.

Recommended container

Use std::vector<Animal*> or std::vector<std::unique_ptr<Animal>> so each element keeps its derived identity and virtual calls work as expected.

Misconception

Some expect virtual to override slicing; it cannot. Slicing happens at the object level, before any virtual dispatch can occur.
