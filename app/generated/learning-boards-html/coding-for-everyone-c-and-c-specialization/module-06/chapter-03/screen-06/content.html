Module 6 › Chapter 6.3 › Iterator categories
Input Iterator
Single-pass read; supports ++ and * for reading.
Use when you only need to consume data once, like reading from a stream.
Output Iterator
Single-pass write; used to send values to an output range.
Often used with std::transform when writing into an output sequence.
Forward Iterator
Multi-pass forward read/write.
More stable than input/output; allows revisiting elements via new iterators.
Bidirectional Iterator
Adds -- for backward traversal.
Example: std::list iterators.
Random Access Iterator
Supports arithmetic, indexing, and comparisons.
Example: std::vector iterators; required by std::sort.
Key Takeaway

Know the iterator category of your container before using algorithms that require higher capabilities.
