Module 6 › Chapter 6.3 › Iterator operations
Read and write via iterators
Use *it to access and ++it to advance. Assignment through *it modifies the element in place.
  • • Read: value = *it
  • • Write: *it = newValue
  • • Move: ++it or it++ (prefer pre-increment for iterators)
Example
for (auto it = v.begin(); it != v.end(); ++it) {
  *it = *it * 2; // modify in place
}
When to use
Use explicit iterators when algorithms expect iterators or when you need to erase or insert at specific positions while iterating.
Common mistake
Assuming you can use arithmetic like it + 3 on every iterator. Only random access iterators support that.
Pro tip
Use range-based for loops for readability when only reading; use iterators when you need the iterator type or to modify in place.
Key Takeaway

Dereference and increment are the core operations; know whether your iterator supports random access before using arithmetic.
