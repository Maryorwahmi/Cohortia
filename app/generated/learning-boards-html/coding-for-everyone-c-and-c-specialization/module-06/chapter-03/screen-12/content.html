Module 6 › Chapter 6.3 › Filtering & Transforming
Starter code
#include <iostream>
#include <vector>
#include <algorithm>

std::vector<double> celsius = {5.5,12.0,8.2,15.1,9.9,20.3,7.8,11.5};
double threshold = 10.0;

// Filter (erase-remove idiom)
auto filtered = celsius; // keep original
auto new_end = std::remove_if(filtered.begin(), filtered.end(), [threshold](double c){ return c < threshold; });
filtered.erase(new_end, filtered.end());

// Transform to Fahrenheit
std::vector<double> fahrenheit; fahrenheit.resize(filtered.size());
std::transform(filtered.begin(), filtered.end(), fahrenheit.begin(), [](double c){ return c * 9.0 / 5.0 + 32.0; });
Notes
  • • Copy original if you need it later.
  • • remove_if returns logical end; erase removes remaining elements.
  • • Ensure output vector is sized before transform.
Key Takeaway

Compose algorithms and lambdas to express filtering and mapping clearly and safely.
