Iterator as a generalized pointer
Iterators provide ++ and * operations so algorithms can traverse containers uniformly.
  • • begin() returns first element's iterator; end() is one past the last element.
  • • Ranges are half-open: [begin, end) — common in STL algorithms.
  • • Treat iterators like pointers: do not dereference end(), and compare iterators to test for termination.
Concrete example
#include <vector>
#include <iostream>

std::vector<int> v = {5,2,8};
for (std::vector<int>::iterator it = v.begin(); it != v.end(); ++it) {
  std::cout << *it << " ";
}
Key Takeaway

Use [begin, end) consistently. Iterators behave like pointers but are container-aware.

Misconception
End is not an element. Dereferencing end leads to undefined behavior.
Why it matters
Algorithms expect ranges; consistent ranges allow reuse of generic functions across containers.
