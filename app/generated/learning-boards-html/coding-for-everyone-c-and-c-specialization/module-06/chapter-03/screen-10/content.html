Module 6 › Chapter 6.3 › Lambda functions
Capture by value
[threshold] copies threshold into the lambda so the outer variable is not modified.
int threshold = 5;
int cnt = std::count_if(v.begin(), v.end(), [threshold](int n){ return n > threshold; });
Capture by reference
[&] or [&cnt] lets the lambda modify outer variables like counters.
int count_even = 0;
std::for_each(v.begin(), v.end(), [&count_even](int n){ if (n % 2 == 0) ++count_even; });
Pitfall
Capturing by value and expecting the outer variable to update will lead to surprising results. Choose capture semantics intentionally.
Key Takeaway

Lambdas make algorithms concise; always decide whether captures should be by value or by reference to avoid bugs.
