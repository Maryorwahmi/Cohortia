Module 6 › Chapter 6.3 › Algorithm requirements
Algorithms that scan
std::find, std::for_each, std::count_if — these only need forward or input iterators because they examine elements sequentially.
They work with many containers and are flexible for streaming-style processing.
Algorithms that jump
std::sort requires random access iterators because it performs non-sequential access and indexing.
If your container doesn't provide random access, use a container-specific member algorithm like list::sort.
Example
std::sort(v.begin(), v.end()); // vector OK
Pitfall
std::sort(list.begin(), list.end()); // compile error — list is bidirectional
Key Takeaway

Always confirm the iterator category required by an algorithm and match it to your container.
