Module 6 › Chapter 6.3 › Key Concepts
Iterator
A generalized pointer for traversing containers using begin and end.
Iterator Categories
Input, Output, Forward, Bidirectional, Random Access — each adds capabilities.
STL Algorithms
Generic functions operating on ranges: sort, find, for_each, transform, count_if, remove_if.
Summary takeaway

Match algorithm needs to iterator capabilities, use lambdas for concise behavior, and apply the erase-remove idiom to filter containers safely.
