Module 6 › Chapter 6.3 › Common STL algorithms
std::find
Returns iterator to first matching element or end.
Use std::distance to compute the position when needed.
auto it = std::find(v.begin(), v.end(), value);
if (it != v.end()) {
  auto pos = std::distance(v.begin(), it);
}
std::for_each
Applies a function to each element for side effects.
std::for_each(v.begin(), v.end(), [](int n){ std::cout << n << " "; });
std::transform
Maps input range to output range using a function.
std::transform(in.begin(), in.end(), out.begin(), [](int n){ return n*n; });
std::count_if
Counts elements satisfying a predicate.
int c = std::count_if(v.begin(), v.end(), [](int n){ return n > 40; });
Common mistake

Remember std::remove_if only rearranges elements and returns a new logical end; you must call erase to shrink the container.
