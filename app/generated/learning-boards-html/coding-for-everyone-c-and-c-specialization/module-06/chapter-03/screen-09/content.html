Module 6 › Chapter 6.3 › Erase-remove idiom
Why two steps?
Algorithms like remove_if reorder elements but cannot resize the container. The container itself must perform erasure.
Example
auto new_end = std::remove_if(v.begin(), v.end(), [](int n){ return n % 2 == 0; });
v.erase(new_end, v.end());
Misconception
Calling remove_if alone will not shrink the container; it only returns a new logical end.
Iterator note
After erase, iterators into the erased range are invalid; obtain fresh iterators if continuing work.
Key Takeaway

Remember: remove_if compacts, erase removes. Use both to filter a container safely.
