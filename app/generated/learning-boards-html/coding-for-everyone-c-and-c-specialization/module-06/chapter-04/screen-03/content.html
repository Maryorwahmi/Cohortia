Practice & Patterns

Small experiments confirm ownership behavior and destructor timing. Use console messages to observe lifetimes.

Pattern
Observe destructors

Add print statements in constructors and destructors to confirm when objects are created and destroyed under different ownership scenarios.

Mnemonic
Owner counts

Think: unique means one owner; shared means a counter, weak means a peek that doesn't increase the count.

Verification
Small tests to run
  • Move a unique_ptr and confirm the source becomes null and destructor runs once.
  • Copy a shared_ptr, push into a vector, and print use_count at each step.
  • Create mutual references and then switch one to weak_ptr to observe destruction.
