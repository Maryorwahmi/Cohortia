Module 6 › Chapter 6.4 › Quick Checklist
Decide ownership
Who must control lifetime? Single owner → unique_ptr. Multiple owners → shared_ptr.
Avoid cycles
If objects reference each other, make at least one reference weak_ptr to allow destruction.
Prefer make_*
Use std::make_unique and std::make_shared for safety and efficiency.
Custom deleters
Wrap C handles in smart pointers with custom deleters to get RAII behavior for non-new resources.
Never manual delete
Do not call delete on pointers owned by smart pointers; let destructors run automatically.
Final thought

Small design decisions about ownership make large differences in reliability. Apply these rules to keep C++ code safe and maintainable.
