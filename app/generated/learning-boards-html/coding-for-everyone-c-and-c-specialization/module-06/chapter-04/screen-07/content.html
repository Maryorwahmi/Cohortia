Module 6 › Chapter 6.4 › unique_ptr Function Patterns
Pattern

Transfer vs Observe

Decide if the function should own the resource or just use it temporarily.

Transfer ownership
Accept std::unique_ptr by value and call with std::move to hand off ownership.
Observe only
Pass a raw pointer or a reference. Remember the caller still controls lifetime.
Common Mistake

After moving, do not use the original pointer. It no longer owns the resource and may be null.

Example
void processResource(std::unique_ptr<MyResource> res) {
  // res now owns the resource; it will be destroyed when res goes out of scope
  res->doSomething();
}

int main() {
  auto resource = std::make_unique<MyResource>("A");
  processResource(std::move(resource)); // ownership transferred
  // resource is now null
}
Concrete scenario
Pass ownership of a socket or file handle to a worker function that is responsible for closing it.
Pro tip
If you don't want transfer, prefer const reference or raw pointer for observation only.
