Smart Pointers and RAII

Understand ownership models in C++ and how smart pointers use RAII to manage dynamic memory safely, even across exceptions.

Why this matters

Automatic cleanup prevents leaks and crashes, and makes ownership explicit in interfaces.

Concept Map
RAII
Acquire in constructor, release in destructor.
unique_ptr
Exclusive ownership, move-only.
shared_ptr
Reference counted shared ownership.
Explore Key Topics
Ownership patterns
Decide between exclusive and shared ownership based on who must control lifetimes.
Breaking cycles
Use weak_ptr for non-owning back-references to avoid memory leaks.
Practical patterns
Prefer make_unique and make_shared for safety and efficiency.
Quick Visual
Object lifetime
Destructor releases the resource when the owner goes out of scope.
What you'll practice
Creating unique_ptr and shared_ptr, transferring ownership, and using weak_ptr to avoid leaks in graphs.
