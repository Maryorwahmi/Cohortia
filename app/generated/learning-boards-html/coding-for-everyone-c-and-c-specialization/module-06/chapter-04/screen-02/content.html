Learning Objectives

Master the ownership models and RAII patterns used to manage dynamic resources in C++.

01
Recognize raw pointer problems

Understand memory leaks and dangling pointers, and why they are hard to debug. This skill lets you spot unsafe manual management in code reviews.

VERIFIED COMPETENCY MILESTONE
02
Apply RAII

Tie resource lifetime to object lifetime so destructors always run, even on exceptions. This reduces leakage across the codebase.

VERIFIED COMPETENCY MILESTONE
03
Implement unique_ptr

Create exclusive owners with make_unique, use move semantics to transfer ownership, and avoid copying to keep lifetimes clear.

VERIFIED COMPETENCY MILESTONE
04
Use shared_ptr and weak_ptr

Manage shared ownership with reference counts and use weak_ptr for non-owning links to avoid circular leaks in graphs and caches.
