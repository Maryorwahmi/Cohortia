Activity

Build nodes and connect neighbors

Define Node with name and vector<shared_ptr<Node>> neighbors. Use make_shared to create nodes and push neighbors into the vector.

Implementation checklist
Constructor/destructor logs, addNeighbor method, create three nodes in main, connect A->B, A->C, B->C, run and observe ref counts and destructions.
Extension
Add back-references as weak_ptr and watch how destruction proceeds when main resets owners.
Key Takeaway

This lab shows how shared ownership in containers affects lifetime and when weak_ptr is necessary to avoid leaks.

Starter code
#include <iostream>
#include <memory>
#include <string>
#include <vector>

class Node {
public:
  std::string name;
  std::vector<std::shared_ptr<Node>> neighbors;
  Node(const std::string& n) : name(n) { std::cout << "Node '" << name << "' created." << std::endl; }
  ~Node(){ std::cout << "Node '" << name << "' destroyed." << std::endl; }
  void addNeighbor(std::shared_ptr<Node> neighbor) {
    neighbors.push_back(neighbor);
    std::cout << "  Node '" << name << "' added neighbor '" << neighbor->name << "'." << std::endl;
  }
};

int main() {
  auto nodeA = std::make_shared<Node>("A");
  auto nodeB = std::make_shared<Node>("B");
  auto nodeC = std::make_shared<Node>("C");

  nodeA->addNeighbor(nodeB);
  nodeA->addNeighbor(nodeC);
  nodeB->addNeighbor(nodeC);

  // Observe destructor calls when main exits
}
