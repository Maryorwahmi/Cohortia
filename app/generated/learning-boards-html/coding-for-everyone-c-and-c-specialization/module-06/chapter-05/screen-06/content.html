Process Flow

Filtering with remove_if + erase

Use remove_if to partition elements that satisfy a condition, then erase the trailing range that now contains removed elements.

Steps
  1. Call std::remove_if with a predicate lambda; capture threshold by value for safety.
  2. std::remove_if returns an iterator new_end marking valid elements.
  3. Call container.erase(new_end, container.end()) to physically remove them.
Code example
#include <algorithm>
#include <vector>

int min_score_threshold = 85;
auto new_end = std::remove_if(students.begin(), students.end(),
    [min_score_threshold](const Student &s) {
        return s.score < min_score_threshold;
    });
students.erase(new_end, students.end());
Pitfall

Calling erase repeatedly inside a loop on std::vector is costly. Use the single erase(new_end, end) idiom.

Why it matters

Understanding remove_if’s behavior prevents logical bugs and poor performance when removing many elements.
