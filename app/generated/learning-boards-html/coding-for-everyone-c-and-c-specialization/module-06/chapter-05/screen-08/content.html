Definition

Iterator categories at a glance

Input
Read forward only (e.g., stream iterators).
Bidirectional
Read/write and move both directions (e.g., std::list).
Random Access
Jump to any element quickly (e.g., std::vector, pointers).
Example

std::sort requires random access. std::remove_if only needs forward iterators. Knowing these requirements prevents compile-time errors and performance surprises.

Performance note

Vector is often the best default for algorithm work. Reserve capacity to avoid reallocations that invalidate iterators used elsewhere.

Common mistake

Trying to run std::sort on a std::list will either not compile or produce suboptimal code. Match container to algorithm.

Check

Which iterator category does your container provide, and which algorithms require that category?
