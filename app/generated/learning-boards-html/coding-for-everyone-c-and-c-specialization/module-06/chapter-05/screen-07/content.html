Comparison

Sort students with a comparator lambda

Write a comparator that returns true when the first element should appear before the second. For tie-breakers, include additional fields like name.

Example comparator
std::sort(students.begin(), students.end(),
  [](const Student &a, const Student &b) {
    if (a.score != b.score) return a.score > b.score; // descending
    return a.name < b.name; // tie-breaker: name ascending
  });
Common mistake

Providing an inconsistent comparator (not transitive) can make std::sort misbehave or crash. Always ensure strict weak ordering.

Why random access matters

std::sort needs to jump around the range, so containers that offer random access iterators like std::vector are required. std::list provides only bidirectional iterators.

Try this

If you must sort a std::list, consider copying elements to a vector of pointers, sorting that, or using list::sort which is optimized for lists.
