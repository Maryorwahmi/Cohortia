Definition

Lambda structure and captures

Lambdas let you inline small function objects. Decide capture semantics deliberately: copying small values is cheap, copying large containers is not.

Example captures
// capture by value
auto f1 = [threshold](const Student &s) { return s.score < threshold; };
// capture by reference
auto f2 = [&limit](const Student &s) { return s.score < limit; };
// mixed
auto f3 = [=, &acc](const Student &s) { acc += s.score; return s.score < threshold; };
Pro tip
When a lambda outlives local scope, avoid capturing references to locals. Use copies or store state elsewhere to prevent dangling references.
Common mistake

Capturing a local variable by reference and then storing the lambda beyond the local scope creates undefined behavior when that variable goes out of scope.

Analogy

Think of capture-by-value as giving the lambda a snapshot photo; capture-by-reference is giving it a live camera feed.

Check your understanding

When would you prefer an explicit [threshold] capture over [=]? Why might you avoid [&] on a large scope?
