Core Concept

Map and reduce with STL algorithms

Using std::transform and std::accumulate expresses two different data transformations: producing a new sequence, and collapsing a sequence to a value. Both are single-pass and readable.

Key Takeaway

Transform maps, accumulate reduces. Avoid forgetting to size the output range for transform.

Concrete example

Square numbers and sum them using transform then accumulate. Destination vector must match source size.

#include <vector>
#include <algorithm> // std::transform
#include <numeric>   // std::accumulate
#include <iostream>

int main() {
  std::vector<int> numbers = {1, 2, 3, 4, 5};
  std::vector<int> squared(numbers.size());

  // Apply lambda to each element and store in squared
  std::transform(numbers.begin(), numbers.end(), squared.begin(),
                 [](int n) { return n * n; });

  // Sum the squared numbers
  long long sum_of_squares = std::accumulate(squared.begin(), squared.end(), 0LL);

  std::cout << "Sum of squared numbers: " << sum_of_squares << std::endl;
}
Explains
  • transform applies the lambda to every element.
  • accumulate reduces to a scalar using an initial value.
Common mistake
Not sizing the destination vector or assuming remove_if removes elements physically.
Try this
Combine mapping into accumulate to avoid a temporary when you only need the sum.
