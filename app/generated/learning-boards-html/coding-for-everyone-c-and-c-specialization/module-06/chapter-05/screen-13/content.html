Module 6 › Chapter 6.5 › Best Practices Checklist
Checklist
  1. Include the right headers: <algorithm>, <numeric>, <functional>.
  2. Prefer STL algorithms to manual loops when available.
  3. Respect iterator invalidation rules and prefer erase-return-value or remove-erase for deletions.
  4. Use const references to avoid copies for read-only access.
  5. Pick the right container for the operations you need; measure when in doubt.
  6. Avoid repeated single-element erase on vector inside loops; prefer bulk operations.
Check your understanding

Given a vector of 10,000 elements where you will remove 40% of elements by a predicate, would you use repeated erase, remove-erase, or build a new vector with copy_if? Explain your performance reasoning.

Quick tips
  • Write clear intent: transform, accumulate, remove_if, sort — pick names that match the operation.
  • When in doubt, benchmark a real input set, not synthetic microtests.
  • Prefer explicit types in public APIs and const references for parameters you don't modify.
Common mistake

Assuming all STL algorithms have identical performance across containers. They do not — algorithm complexity often depends on iterator category.
