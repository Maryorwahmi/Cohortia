Module 6 › Chapter 6.1 › Learning Objectives
Practice Items
  • Implement Pair<T1,T2> and test two instantiations.
  • Write template swap and observe deduction.
  • Create printValue template and predict outputs.
  • Fix linker errors by moving template defs to header.
Verification Checks
Check 1
Instantiate Pair<int,double> and Pair<std::string,char> and confirm printed values match constructor.
Check 2
Call swap on two ints and two doubles. Confirm values are exchanged without additional overloads.
Check 3
Run printValue with an int, a string literal, and a float. Predict the output types and the printed lines.
Check 4
If you see undefined reference errors, move definitions to the header and recompile. Confirm the linker error disappears.
