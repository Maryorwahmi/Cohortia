Module 6 › Chapter 6.1 › Key Concepts
Class Template
A class parameterized by types to form type-specific classes upon instantiation.
Template Instantiation
The compile-time generation of concrete code from a template using supplied type arguments.
Linker Error (Templates)
Occurs when template definitions aren't visible at instantiation time, causing undefined references.
Quick summary

Use templates to reduce duplication, keep definitions visible, and verify type requirements early with small tests.
