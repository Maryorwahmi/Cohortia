Learning Objectives
Learn, Understand, Apply, Master — a short Bloom path to templates.
Bloom's path
Learn → Understand → Apply → Master
01
Explain Generic Programming
Describe why templates let algorithms work independently of concrete types and why that reduces duplication.
VERIFIED COMPETENCY MILESTONE
02
Write Function Templates
Implement a template function such as a generic swap and use the compiler to instantiate it for ints and doubles.
VERIFIED COMPETENCY MILESTONE
03
Implement Class Templates
Design a MyStack or Pair template to hold any specified type and test several instantiations.
VERIFIED COMPETENCY MILESTONE
04
Diagnose Template Errors
Recognize linker errors from misplaced definitions and know the simple header-based fix for beginners.
VERIFIED COMPETENCY MILESTONE
