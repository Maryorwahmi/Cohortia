Undefined reference from separated definitions

When template definitions live in a .cpp, other translation units cannot see them to instantiate concrete code. The linker then fails to find the needed symbols and reports undefined references.

Beginners' fix:
Move template definitions into the header file so the compiler can instantiate templates wherever they are used.
Concrete scenario
LinkedList.h declares the template; LinkedList.cpp defines members. main.cpp uses LinkedList<int>. Because main.cpp can't see the definitions, the compiler cannot instantiate functions and the linker reports undefined references.
Practical tip

Keep template code in headers or use explicit instantiation techniques only when you understand the build system implications.
