How deduction works

The compiler inspects function call arguments and matches them to template parameters to infer types. This reduces verbosity but has clear limits when types differ or when context is missing.

Example
printValue(5) → T deduced as int. swap(1, 2.0) → deduction fails because a single T cannot match both int and double.
When to specify types
  • When argument types differ and a single type cannot be deduced.
  • When you declare a class template object — explicit type arguments are required.
  • When you want to force a particular overload or conversion path.
Misconception

Type deduction will not silently convert differing argument types into a single type. It must find an exact match pattern to infer T.
