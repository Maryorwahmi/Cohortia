MyStack<T> example

Use a template parameter T for the element type. The stack allocates a T array and provides push, pop, and peek. Instantiations like MyStack<int> and MyStack<std::string> create concrete classes.

<?cpp
template <typename T>
class MyStack {
private:
  T* arr;
  int top;
  int capacity;
public:
  MyStack(int size) : capacity(size), top(-1) { arr = new T[capacity]; }
  ~MyStack() { delete[] arr; }
  void push(const T& val) { arr[++top] = val; }
  T pop() { if(top==-1){ return T(); } return arr[top--]; }
};
?>
Type requirements
Templates may require that types support copying, default construction, or certain operators. If a type lacks these, the instantiation will fail at the point it is used.
Practical check
Instantiate MyStack<int> and MyStack<std::string> in a small main to verify push/pop behavior and to test exception or underflow handling.
Key Takeaway

Class templates let you design reusable containers, but check the expectations you place on types and keep definitions visible for instantiation.
