template<typename T>

The template declaration introduces a type parameter. It signals that the following function or class is generic and that the compiler should replace the placeholder with concrete types at instantiation.

Note on 'class' vs 'typename'
Using class instead of typename for a type parameter is permitted, but typename is clearer when the parameter represents a type rather than a user-defined class only.
Concrete example
<?cpp
template <typename T>
void swap(T& a, T& b) {
  T temp = a;
  a = b;
  b = temp;
}
?>
When called with ints, the compiler creates swap<int>.
Misconception check
typename does not change runtime behavior. Templates are resolved at compile time; typename only labels a parameter as a type during compilation.
