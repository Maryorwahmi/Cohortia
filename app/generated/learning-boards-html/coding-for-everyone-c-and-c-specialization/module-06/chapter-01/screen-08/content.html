Module 6 › Chapter 6.1 › Template Instantiation
Instantiated vs single class
A template yields separate compiled versions for each type you use. A regular class has one compiled version shared by all uses. Instantiation happens at compile time and requires visible definitions.
Example
Using MyStack<int> and MyStack<std::string> produces two concrete classes in the final binary generated by the compiler.
Consequences
  • Each instantiation generates code, which can increase binary size.
  • Instantiation gives type-specific optimizations and inlining opportunities.
  • Definitions must be visible at instantiation to avoid linker errors.
Misconception

Templates are not polymorphic at runtime. Instantiation happens at compile time and produces distinct code paths for each type used.
