Module 6 › Chapter 6.1 › Why Generic Programming?
Problem: duplication

When logic repeats across types, separate implementations create maintenance and correctness risks. Generic programming replaces many similar functions with one parametrized blueprint.

Analogy
A template is like a mold for shoes: one mold can make many sizes. The mold holds the process; the size parameter produces the concrete shoe.
Common misconception
Templates are not runtime polymorphism. They generate distinct code for each type at compile time rather than dispatching at runtime.
Key Takeaway

Find repeated logic across types and convert it to a template to reduce duplication and bugs while keeping performance.

Where it helps
  • Utility functions like swap or max used for multiple numeric types.
  • Containers such as stacks, vectors, and maps that hold various element types.
  • Library code that must be reused across projects and types.
Example snapshot
If you have swap for int and swap for double, convert both into a single template that accepts a placeholder type. The compiler will generate swap<int> or swap<double> automatically when used.
