Generic swap

This template swaps two values of the same deduced type. The compiler will generate a separate swap function for each distinct type you use.

<?cpp
template <typename T>
void swap(T& a, T& b) {
  T temp = a;
  a = b;
  b = temp;
}

int main() {
  int x = 1, y = 2;
  swap(x, y); // compiler instantiates swap<int>
  double p = 1.5, q = 2.5;
  swap(p, q); // compiler instantiates swap<double>
}
?>
When deduction fails
If you call swap(1, 2.0) the compiler cannot deduce a single T because argument types differ. You must use explicit template parameters or overloads to handle mixed types.
Quick tips
  • Rely on argument deduction for concise calls.
  • Use multiple template parameters when types differ.
  • Keep template bodies visible at instantiation sites.
Key Takeaway

Function templates let you write one generic function; the compiler auto-generates concrete versions where needed. Watch for deduction limits when argument types differ.
