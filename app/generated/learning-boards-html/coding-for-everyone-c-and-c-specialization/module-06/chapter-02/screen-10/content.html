Process
Inventory: containers combined
Vector for display order, map for quantities sorted by name, unordered_set for discontinued membership.
Key steps
  1. Add product name to vector with push_back.
  2. Set or update stock in std::map using stock[name] = qty.
  3. Mark discontinued products using unordered_set.insert(name).
  4. Remove from vector using remove-erase idiom to avoid dangling iterators.
Starter code (excerpt)
<#include <iostream>>
<#include <vector>>
<#include <map>>
<#include <unordered_set>>
<#include <algorithm>>

// add product
void addProduct(std::vector<std::string>& products, const std::string &name) {
  products.push_back(name);
}

// remove using remove-erase
void removeProduct(std::vector<std::string>& products, const std::string &name) {
  auto it = std::remove(products.begin(), products.end(), name);
  if (it != products.end()) products.erase(it, products.end());
}
Concrete tip
Use the map for sorted stock reports and unordered_set for constant-time discontinued checks when processing sales.
