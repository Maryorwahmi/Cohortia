Definition
std::vector basics
Contiguous dynamic array with indexed access and dynamic resizing.
Key operations
  • push_back, pop_back — append and remove last
  • insert, erase — insert or remove at arbitrary positions (O(N) shifts)
  • size, capacity, reserve — manage growth and allocation
Common pitfall
Using [] out of bounds causes undefined behavior. Prefer at() when you need safety checks during development.
Key Takeaway

std::vector is the go-to sequence when you want fast index access and growth at the end; manage capacity to avoid occasional costly reallocations.

Code example
<#include <iostream>>
<#include <vector>>

int main() {
  std::vector<int> numbers; // empty vector
  numbers.push_back(10);
  numbers.push_back(20);
  numbers.push_back(30);

  // Access
  std::cout << "First element: " << numbers[0] << std::endl;
  std::cout << "Second element: " << numbers.at(1) << std::endl;

  // Size and capacity
  std::cout << "Size: " << numbers.size() << std::endl;
  std::cout << "Capacity: " << numbers.capacity() << std::endl;

  // Insert and erase
  numbers.insert(numbers.begin() + 1, 15);
  numbers.erase(numbers.begin() + 2);

  return 0;
}
Concrete example
Use vector to store sensor readings that you mostly append to and occasionally index by position for analysis.
