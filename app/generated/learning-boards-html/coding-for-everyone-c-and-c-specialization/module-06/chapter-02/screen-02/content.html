Learning Objectives
By the end of this chapter you will be able to choose and use common STL containers correctly.
Bloom
Learn
Understand
Apply
Master
01
Explain STL purpose
Describe why STL provides containers and how templates enable reusable, type-safe data structures. Recognize that STL reduces duplicated implementation work and common bugs.
VERIFIED COMPETENCY MILESTONE
02
Differentiate containers
Identify vector, list, map, unordered_map, and set, and explain when each is appropriate based on access and modification patterns.
VERIFIED COMPETENCY MILESTONE
03
Use vector effectively
Perform push_back, pop_back, insert, erase, and manage capacity. Understand amortized complexity and how to avoid reallocation costs with reserve.
VERIFIED COMPETENCY MILESTONE
04
Master associative containers
Choose between map and unordered_map based on ordering needs, and use sets to store unique keys; understand complexity trade-offs for lookups and iteration.
VERIFIED COMPETENCY MILESTONE
