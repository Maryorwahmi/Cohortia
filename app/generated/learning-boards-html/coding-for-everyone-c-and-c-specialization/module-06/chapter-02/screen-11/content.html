Checklist
Do you need index access?
Yes → std::vector. No → consider list or associative containers.
Frequent mid-list insert/delete?
Yes → std::list if you already hold iterators; otherwise rethink data flow or use indexing with vector if occasional.
Key lookup vs ordered iteration?
Need sorted iteration → std::map. Need fastest average lookup → std::unordered_map.
Example decision
Sensor readings: mostly append and index → vector. User profiles by username where quick lookup matters → unordered_map. Product catalog requiring alphabetical reports → map.
