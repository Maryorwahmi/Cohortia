Module 6 › Chapter 6.2 › Key Concepts
Container
An object that stores elements and manages their memory; templates make them type-generic.
Vector
Contiguous dynamic array with O(1) index access and amortized O(1) push_back.
Associative Containers
map and unordered_map store key-value pairs; choose by ordering and lookup needs.
Summary

Choose containers by the operations you need most: access pattern, insertion pattern, and ordering determine the right choice.
