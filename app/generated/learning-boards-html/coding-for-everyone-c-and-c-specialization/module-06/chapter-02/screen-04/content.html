Core Concept
What is a Container?
An STL container is a templated object that stores elements and provides operations for insertion, removal, and traversal while managing memory.
Definition
A templated class that stores multiple elements and exposes iterators and member functions to manipulate them.
Why templates?
Templates let containers work with any element type while keeping a single, tested implementation.
Common misconception
Containers are not interchangeable — each offers different access patterns and performance guarantees.
Key Takeaway

Pick containers based on required access patterns, insertion patterns, and ordering guarantees, not by name alone.

Analogy: Containers are toolboxes
Like a toolbox organized for different tasks, each container groups operations and guarantees. You choose the toolbox before starting the job.
Concrete example
If you need sorted traversal of key-value pairs, use std::map so iteration yields keys in order without extra sorting steps.
Check your understanding
  • What operations does your program perform most often: random access, frequent mid-list inserts, or key lookups?
  • If you need ordering by key, is unordered_map acceptable? (No — unordered_map is not ordered.)
  • Would a custom container be better than STL for your case? Usually not unless you have specialized constraints.
