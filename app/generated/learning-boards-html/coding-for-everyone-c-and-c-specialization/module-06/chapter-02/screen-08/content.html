Comparison
std::map (sorted)
Typically implemented as a balanced tree, supports ordered iteration and O(log N) operations.
When to use
When you need keys in sorted order or range queries, or when worst-case logarithmic performance is required.
<#include <map>>
std::map<std::string, int> ages;
ages["Alice"] = 30;
ages["Bob"] = 25;
// Iteration yields sorted keys
for (const auto &p : ages) {
  // p.first is key, p.second is value
}
Comparison
std::unordered_map (hashed)
Implements a hash table for average O(1) lookup, insertion, and deletion; iteration order is unspecified.
When to use
When you prioritize average lookup speed and do not require sorted keys.
<#include <unordered_map>>
std::unordered_map<std::string, int> scores;
scores["Math"] = 95;
// Fast lookup by key on average
int m = scores["Math"];
