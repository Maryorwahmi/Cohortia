Core Concept
Complexity recap
std::vector
Index: O(1); push_back: amortized O(1); insert/erase middle: O(N).
std::list
Insert/erase at iterator: O(1); random access: O(N).
std::map
Lookup/insert/delete: O(log N) — sorted keys.
std::unordered_map
Average O(1) for lookup/insert/delete; worst-case O(N) on heavy collisions.
Practical note
Big-O is a guideline. Also consider constants, memory usage, and cache behavior. Prefer simple containers until profiling shows a real bottleneck.
