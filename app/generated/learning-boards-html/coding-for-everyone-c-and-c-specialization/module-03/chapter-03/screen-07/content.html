Include Guard Example
// myheader.h
#ifndef MY_HEADER_H // If MY_HEADER_H is NOT defined
#define MY_HEADER_H // Define MY_HEADER_H

// Declarations go here
struct MyData { int value; };
void myFunction(void);

#endif // End of MY_HEADER_H guard
This pattern ensures that even if multiple files include myheader.h directly or indirectly, the declarations are processed only once.
Concrete scenario
If fileA.c includes header1.h and header1.h includes header2.h, and fileA.c also includes header2.h directly, include guards prevent header2.h from being expanded twice.
Key takeaway
Include guards are a small, portable pattern that prevents redefinition errors from repeated header expansion.
Misconception
Guards stop multiple inclusion but do not fix poor header design, such as putting definitions in headers.
