Definition
What to put in .h files
  • Function prototypes and signatures
  • Struct and typedef declarations
  • Macro definitions for constants or small utilities
  • Extern declarations for shared variables (rare)
Concrete example
Declare in header, define in source. Compile sources to object files and then link.
// myheader.h
#ifndef MY_HEADER_H
#define MY_HEADER_H

struct MyData { int value; };
void myFunction(void);

#endif

// myheader.c
#include "myheader.h"

void myFunction(void) {
  // implementation
}
Why it matters
Proper separation prevents duplicate definitions and keeps compilation units independent.
Mistake to avoid
Placing a function body in a header and including it widely causes linker redefinition errors.
