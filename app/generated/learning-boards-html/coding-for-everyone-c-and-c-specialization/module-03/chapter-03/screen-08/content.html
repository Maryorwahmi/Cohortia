Core Concept
#define for constants and macros
Symbolic constants replace names with literal values. Macros expand textually and must be used carefully to avoid bugs.
#define PI 3.14159 — simple constant, no runtime memory used.
#define SQUARE(x) ((x) * (x)) — macro with safe parentheses.
Code example
// Symbolic constant
#define MAX_VALUE 100

// Macro with safe parentheses
#define SQUARE(x) ((x) * (x))
Remember: pass plain variables to macros, not expressions with side effects, or use inline functions where available.
Good practice
Parenthesize macro parameters and the whole expansion to preserve operator precedence.
Gotcha
Macros duplicate argument evaluation, so expressions with increments can behave unexpectedly.
