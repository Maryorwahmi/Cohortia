Core Concept
Definition: The Preprocessor
A stage that transforms source text by expanding directives such as #include and #define before the compiler sees the code.
Text substitution: macros and constants are replaced literally.
File inclusion: #include copies header text into the translation unit.
Conditional inclusion: #ifdef/#if control what code is present for compilation.
Concrete example
A source file with a #include becomes a single expanded file the compiler processes. This can reveal redefinition errors if headers repeat declarations.
#include "myheader.h"

int main() {
  return 0;
}

/* After preprocessing, myheader.h content is inserted verbatim */
Key takeaway
Preprocessing changes what the compiler sees, so debug and include errors often originate from these expansions.
Common mistake
Confusing macros with functions; macros are textual and can cause precedence or side-effect bugs.
