Architecture
Simple makefile
# Makefile example
CC = gcc
CFLAGS = -Wall -g

all: myprogram

myprogram: main.o utility.o
	$(CC) $(CFLAGS) main.o utility.o -o myprogram

main.o: main.c myheader.h
	$(CC) $(CFLAGS) -c main.c

utility.o: utility.c myheader.h
	$(CC) $(CFLAGS) -c utility.c

clean:
	rm -f *.o myprogram
Concrete advice
List header dependencies so make rebuilds object files when relevant headers change. Use variables for compiler and flags to keep rules concise.
Why it matters
Make automates and speeds development by rebuilding only the necessary parts of a project.
Pitfall
Leaving out header dependencies causes stale builds or missing rebuilds after header edits.
