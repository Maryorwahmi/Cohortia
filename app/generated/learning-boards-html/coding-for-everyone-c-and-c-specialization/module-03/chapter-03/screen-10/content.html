Debugging and platform-specific code
#define DEBUG_MODE // or pass -DDEBUG_MODE when compiling

#ifdef DEBUG_MODE
  #include <stdio.h>
  #define DEBUG_PRINT(msg) printf("DEBUG: %s
", msg)
#else
  #define DEBUG_PRINT(msg) do {} while (0)
#endif

int main() {
  DEBUG_PRINT("Starting program");
  return 0;
}
Concrete usage
Compile normally to run without debug prints. Compile with -DDEBUG_MODE to enable verbose output for development builds.
Why it matters
Conditional blocks keep debug code available but excluded in release builds, reducing runtime overhead.
Misconception
Relying on many conditionals can fragment logic; prefer small, well-documented flags.
