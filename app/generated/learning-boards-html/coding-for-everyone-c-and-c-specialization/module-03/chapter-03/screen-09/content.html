Problematic macro vs safer macro
// Problematic
#define SQUARE(x) (x * x)

// Safer
#define SQUARE(x) ((x) * (x))

// MAX with parentheses
#define MAX(a, b) ((a) > (b) ? (a) : (b))
Test macros with expressions and ensure arguments without side effects to avoid surprises.
Concrete demonstration
Using SQUARE(a + b) with the naive macro changes operator grouping; using SQUARE((a + b)) with the safe macro yields the expected result.
Avoid: SQUARE(i++) — increments i twice after expansion.
Prefer: inline function when argument evaluation must be single and predictable.
Common mistake
Treating macros as safe substitutes for functions; they do not evaluate arguments exactly once.
