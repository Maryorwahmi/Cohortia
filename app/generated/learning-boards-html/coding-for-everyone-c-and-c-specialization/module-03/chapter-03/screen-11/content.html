Process Flow
Four build stages
Preprocessing
Expands #include, #define, and conditionals to produce single source.
Compilation
Translates source to assembly and checks types.
Assembly
Assembler produces object files containing machine code.
Linking
Linker resolves references and creates the final executable.
Example: compiling main.c and utility.c yields main.o and utility.o, then the linker combines them and any libraries to produce myprogram. Diagnose by stage: preprocessing issues show as syntax after expansion; missing symbols show as linker errors.
