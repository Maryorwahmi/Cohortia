Definition
#include Behavior
The directive copies a file's contents into the source. Angle brackets search system directories; quotes search current directory first.
#include <stdio.h> — system header, searched in system include paths.
#include "app.h" — project header, searched in current directory first.
Avoid: #include "file.c" — duplicates definitions across translation units.
Concrete example
Choosing the wrong include form can pull a different header with the same name from system paths, creating hard-to-find bugs.
// Use system header
#include <stdio.h>

// Use local header
#include "app_config.h"
Tip
Keep project headers in a dedicated include directory and use quotes for clarity.
Pitfall
Including .c files duplicates code and often results in multiple-definition linker errors.
