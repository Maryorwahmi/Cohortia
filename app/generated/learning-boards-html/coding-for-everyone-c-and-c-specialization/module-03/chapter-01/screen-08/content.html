Comparison
qsort-style callback
Define a comparison signature and pass different implementations to change behavior without modifying the algorithm.
// Comparison signature example
int cmp_asc(const void *a, const void *b) {
  const int *ia = a; const int *ib = b;
  return (*ia > *ib) - (*ia < *ib);
}

Practical tips
  • Match calling signature exactly to avoid undefined behavior.
  • Perform a null check on the function pointer before calling.
  • Keep comparison functions pure and side-effect free when possible.
Design benefit
Function pointers let you separate control flow from specific operations, improving reuse and testability.
