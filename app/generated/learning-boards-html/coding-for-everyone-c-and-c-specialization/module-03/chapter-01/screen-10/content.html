Process Flow
Resize with realloc safely
  1. Compute new capacity and byte size
  2. Call temp = realloc(original, new_size)
  3. If temp is NULL, handle failure and keep original intact
  4. If temp is non-NULL, assign original = temp and continue
  5. Free original when done
Misconception
Do not overwrite the original pointer with realloc's return until you check for NULL; otherwise you may leak memory on failure.
Code example
int *arr = malloc(initial_capacity * sizeof(int));
if (arr == NULL) { /* handle error */ }

// When full:
size_t new_capacity = capacity * 2;
int *tmp = (int *)realloc(arr, new_capacity * sizeof(int));
if (tmp == NULL) {
  // Realloc failed, arr is still valid
  fprintf(stderr, "Reallocation failed
");
} else {
  arr = tmp;
  capacity = new_capacity;
}

// When done:
free(arr);
arr = NULL;
Key Takeaway

Use a temporary pointer for realloc. This simple step prevents accidental loss of the original buffer and is the most common safe-resize idiom.
