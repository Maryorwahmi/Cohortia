Core Concept
Function pointer syntax
Declare a variable that can hold a function address matching a specific signature.
// Declare a pointer to function taking two ints, returning int
int (*op)(int, int);

// Assign and call
int add(int a, int b) { return a + b; }
op = add; // or &add
int s = op(2, 3); // calls add
Gotcha
Parentheses matter. int *f(int) is not the same as int (*f)(int).
Use case: callback
Pass different functions to a routine that applies an operation to two values. This decouples the algorithm from the operation.
Example
A generic calculate function receives an int open-paren star op close-paren and calls op when needed.
Key Takeaway

Function pointers let you pass behavior into routines. Always match the expected signature and validate the pointer before calling to avoid runtime crashes.
