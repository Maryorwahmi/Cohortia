Definition
Array of strings: char **
Two allocation levels: the pointer array, and each string buffer. Free in reverse order to avoid leaks.
Allocation steps
  • Allocate char** array for N pointers
  • For each index, allocate char* with strlen+1 bytes
  • Copy or read characters into the buffer
Common mistake
Not freeing each string before freeing the pointer array, causing memory to remain allocated but unreachable.
Code pattern
// Allocate array of pointers
char **strings = (char **)malloc(n * sizeof(char *));
if (strings == NULL) { /* handle error */ }
// For each string
strings[i] = (char *)malloc((strlen(src) + 1) * sizeof(char));
if (strings[i] == NULL) { /* free previous and exit */ }
strcpy(strings[i], src);

// Freeing later:
for (i = 0; i < count; i++) {
  free(strings[i]);
}
free(strings);
strings = NULL;
Key Takeaway

Treat the pointer array and its element buffers as separate objects: allocate and free each layer explicitly, and use calloc if you want zeroed pointers for safer cleanup on failure.
