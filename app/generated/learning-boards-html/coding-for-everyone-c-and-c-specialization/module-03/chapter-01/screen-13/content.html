Module 3 › Chapter 3.1 › Key Concepts
Pointer to Pointer
A double-asterisk variable holds the address of another pointer, enabling functions to modify caller pointers.
Function Pointer
Holds the address of a function. Use to pass behavior; check signatures and null before calling.
char ** for strings
An array of char pointers. Allocate the pointer array, then each string, and free each in reverse order.
Summary

These three building blocks combine: pointers-to-pointers for ownership transfer, function pointers for flexible behavior, and careful heap management for dynamic structures. Practice the safe patterns and checks to avoid subtle bugs.
