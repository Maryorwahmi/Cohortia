Definition
malloc vs calloc
malloc(size_t size)
Allocates size bytes. Contents uninitialized. Check for NULL.
calloc(size_t n, size_t size)
Allocates n elements of size bytes and zeroes memory. Useful for pointer arrays and guaranteed zero.
realloc(void *p, size_t new_size)
Resizes existing block. Use a temporary pointer to avoid losing original on failure.
free(void *p)
Deallocates memory. Set the pointer to NULL after freeing to avoid dangling references.
Example checklist
  • Always test allocation returns for NULL before use.
  • For realloc, store result in temp and only assign back when non-NULL.
  • Free every allocation and set pointer to NULL after free.
  • Use calloc when you need zero-initialized memory for correctness or safety.
Key Takeaway

Match allocations with frees, check returns, and use temporary pointers for realloc. These patterns are small but protect programs from many memory errors.
