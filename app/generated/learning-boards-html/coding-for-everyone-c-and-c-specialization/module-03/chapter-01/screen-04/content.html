Core Concept
Pointer to Pointer
A second level of indirection lets a function update a caller's pointer so newly allocated memory can be returned indirectly.
int x = 42; int *ptr = &x; int **pptr = &ptr; // *pptr == ptr (address), **pptr == x (value)
When to use
When a function must allocate or reassign a pointer in the caller. Example: allocating memory for a buffer inside a helper function.
Common mistake
Dereferencing the wrong level. Using *pptr when you needed **pptr leads to reading an address instead of the value or crashing.
Example scenario
A function wants to allocate memory for an integer and return that pointer to main. Passing &myPtr as int ** allows the function to call malloc and store the new address into main's variable.
void allocate_int(int **p) { *p = (int *)malloc(sizeof(int)); if (*p != NULL) { **p = 100; // set value } } /* Caller: */ int *myPtr = NULL; allocate_int(&myPtr);
Key Takeaway

Pointer-to-pointer gives the callee access to change a pointer variable in the caller. Visualize each asterisk to avoid incorrect dereferencing.
