Alloc & Init
Use malloc for raw bytes, calloc for zeroed memory. Always test for NULL after allocation.
Resize Safely
Assign realloc to a temp pointer, check that it’s non-null, then update the original pointer and capacity.
Free & Null
Free every allocation and set pointer to NULL to prevent double free and use-after-free bugs.
Final Thought

Small, consistent memory management habits make C programs reliable. Before leaving any function, ask: who owns this memory and who will free it?
