Process Flow
Allocate inside a function
Follow this safe sequence to allocate and hand back memory:
  1. Pass the pointer's address: function(int **p)
  2. Inside function, call malloc and assign to *p
  3. Check *p for NULL before use
  4. Initialize **p if needed
  5. Caller frees and nulls the pointer when done
Pitfall
If you assign a local copy of the pointer instead of writing *p, the caller's pointer remains unchanged and the allocated block is lost.
Annotated Code Example
void modifyPointer(int **ptr_ref) {
  // Allocate and store into caller's pointer
  *ptr_ref = (int *)malloc(sizeof(int));
  if (*ptr_ref != NULL) {
    **ptr_ref = 100; // initialize allocated int
  }
}

int main() {
  int *myPtr = NULL;
  modifyPointer(&myPtr); // pass address of pointer
  if (myPtr != NULL) {
    printf("Value: %d
", *myPtr);
    free(myPtr); // caller frees
    myPtr = NULL; // avoid dangling pointer
  }
  return 0;
}
Key Takeaway

Pass &pointer when the function must allocate or reset it. Always check malloc results and have the caller own the free step.
