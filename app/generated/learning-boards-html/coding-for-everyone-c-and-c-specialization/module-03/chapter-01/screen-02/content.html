Learning Objectives
These skills build from understanding to applying safe memory patterns in real code.
01
Explain pointers to pointers
Describe multi-level indirection, how int**, char**, and arrays of pointers map to memory, and why this matters for modifying pointers in a caller.
VERIFIED COMPETENCY MILESTONE
02
Use function pointers
Declare, assign, and call function pointers for callbacks and generic interfaces. Understand syntax pitfalls and null checks.
VERIFIED COMPETENCY MILESTONE
03
Manage dynamic memory
Apply malloc, calloc, realloc, and free correctly. Check returns, initialize when needed, and free when finished.
VERIFIED COMPETENCY MILESTONE
04
Prevent memory errors
Identify leaks, dangling pointers, double frees, and buffer boundaries. Use recommended fixes such as nulling and temporary pointers for realloc.
VERIFIED COMPETENCY MILESTONE
