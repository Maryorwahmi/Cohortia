Memory Leak
Cause: forget to free allocated memory. Fix: free on all code paths and set pointer to NULL.
Dangling Pointer
Cause: use pointer after free. Fix: null the pointer after free and avoid shared ambiguous ownership.
Double Free
Cause: freeing same block twice. Fix: track ownership and null pointers after free.
Buffer Overflow
Cause: writing past allocated size. Fix: validate indices, use sizeof, and limit string copies safely.
realloc Failure
Cause: out of memory. Fix: use temporary result and clean up on error to avoid leaks and preserve old data.
NULL Dereference
Cause: using allocation result without checking. Fix: check for NULL before dereference and handle errors gracefully.
Practical defense
  • Use clear ownership rules: who is responsible to free?
  • Free nested allocations in reverse order of allocation.
  • Null pointers after free and check for NULL after allocation.
  • Use temporary variables for realloc and thorough error handling.
Key Takeaway

Memory errors are avoidable with consistent patterns: check returns, track ownership, free in reverse, use temp pointers for realloc, and null after free. These habits prevent most heap-related crashes and leaks.
