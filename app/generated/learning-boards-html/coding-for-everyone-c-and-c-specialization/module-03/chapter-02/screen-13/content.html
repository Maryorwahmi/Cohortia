Module 3 › Chapter 2 › Mistakes & Debugging

Common mistakes

  • Not checking fopen for NULL
  • Using scanf without bounds instead of fgets
  • Using "w" when you meant to append
  • Ignoring fread/fwrite return values

Debug tips

  1. Call perror immediately after a failing system call.
  2. Log ftell positions to verify expected offsets.
  3. Ensure every fopen has a matching fclose, even on error paths.
Pro Tip

When in doubt, reproduce the problem with a small file and step through reads/writes while printing return values.
