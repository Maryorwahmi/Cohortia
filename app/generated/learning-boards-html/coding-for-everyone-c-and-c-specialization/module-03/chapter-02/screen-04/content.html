Definition

File streams and FILE pointer

A file stream is an abstract channel. fopen returns a FILE* which all file functions use. The pointer includes buffer state, the file position indicator, and error flags.

Concrete example
Open data.txt with fopen("data.txt", "w"), check for NULL, then use fprintf to write lines and fclose to flush.
Common misconception
FILE* is not a simple file descriptor. It manages buffering and formatted I/O and must be handled with library functions.
Annotated Flow
Open → Use pointer in calls → Buffering occurs → Close to flush
Check your understanding
  • What does fopen return on failure? (NULL)
  • Why call fclose? (flush buffers and release the handle)
  • What does the FILE* track besides the file name? (position and error flags)
Key Takeaway

Treat FILE* as the single source of truth for an open file; always validate and close it.
