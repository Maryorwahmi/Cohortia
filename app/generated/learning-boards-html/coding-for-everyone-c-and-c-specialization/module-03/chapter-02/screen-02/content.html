Learning Objectives

Clear, measurable skills you will demonstrate in code

Bloom: Learn → Understand → Apply → Master
01
File streams & FILE*

Identify what a file stream is and how FILE* serves as the handle for all file operations. This matters because every subsequent call uses that pointer as context.

VERIFIED COMPETENCY MILESTONE
02
Text I/O: fprintf, fgets

Write and read human-readable files safely, using formatted output and line reads to avoid buffer overflows and parsing errors.

VERIFIED COMPETENCY MILESTONE
03
Binary I/O: fread, fwrite

Use block reads and writes for efficiency when storing arrays or structs, and understand returned item counts to detect partial I/O.

VERIFIED COMPETENCY MILESTONE
04
Errors & Seeking

Detect errors with ferror and feof, report system errors with perror, and reposition files with fseek, ftell, and rewind to implement random access patterns.

VERIFIED COMPETENCY MILESTONE
