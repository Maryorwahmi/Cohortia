Module 3 › Chapter 2 › Error Handling
Checks to perform
  • Check fopen != NULL and call perror if it fails.
  • Check fread/fwrite return values for expected counts.
  • Use feof to detect end-of-file, and ferror to detect stream errors.
Example snippet
if (ferror(inFile)) {
  perror("Error during file read");
}
Common pitfalls

Do not treat EOF as an error. Also avoid overwriting errno before you call perror — check and report errors immediately after the failing call.

Pro Tip

After a failing I/O, close streams you opened and free any resources before returning or exiting to avoid leaks.
