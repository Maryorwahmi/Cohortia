Checklist
  1. On startup, fopen contacts.txt for reading only if it exists.
  2. Use fgets with buffer length to avoid overflow.
  3. Append with fprintf and use fclose after appending.
  4. Free each allocated contact before exit.
Key Takeaway

Build file routines defensively: check returns, avoid overflows, and manage memory lifecycle visibly.
