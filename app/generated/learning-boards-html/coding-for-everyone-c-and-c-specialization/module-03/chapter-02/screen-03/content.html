Practical Outcomes

Concrete tasks you will complete to verify competence.

Load and Parse
Read contacts from a text file using fgets and parse with strtok or sscanf.
Append Safely
Open in append mode and use fprintf to add a new line for each contact.
Binary Snapshot
Write an array of integers with fwrite and read it back with fread, checking counts.
