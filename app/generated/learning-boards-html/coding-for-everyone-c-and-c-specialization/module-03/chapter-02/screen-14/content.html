Practice Assessment

Implement the config reader that uses a default of 10 if reading fails. Check fopen, use fgets, parse with sscanf, and always fclose.

Mini-quiz: Mode matching
  1. "r" — Read mode, file must exist.
  2. "w" — Write mode, creates or truncates file.
  3. "a" — Append mode, creates if missing and preserves existing data.
  4. "rb" — Read binary mode, raw byte access.
Task checklist
  • Check fopen return and use perror if needed.
  • Read line with fgets to avoid overflow.
  • Parse with sscanf and fallback to default on failure.
Assessment Tip

Write tests that remove or corrupt config.txt to verify your fallback behavior.
