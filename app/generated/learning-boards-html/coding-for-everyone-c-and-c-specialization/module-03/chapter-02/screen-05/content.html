Module 3 › Chapter 2 › fopen and modes
Mode Reference
"r": Read mode. File must exist.
"w": Write mode. Creates or truncates.
"a": Append. Creates if needed, preserves existing data.
Binary: Add b such as "rb" or "wb" for raw bytes.
Read/Write: "r+", "w+", "a+" allow both operations with subtle differences.
Examples & Pitfalls

When saving logs use "a" to append. Using "w" would erase previous log entries. For binary snapshots, use "wb" and "rb" to avoid newline translations.

Check your code
  • Does fopen return NULL? Handle it.
  • Are you using the correct mode for binary vs text?
  • Will your choice truncate data unexpectedly?
Key Takeaway

Pick the mode to match intent and always check fopen’s return value before using the FILE pointer.
