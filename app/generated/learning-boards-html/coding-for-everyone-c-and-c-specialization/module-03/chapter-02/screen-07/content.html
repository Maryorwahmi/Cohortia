Module 3 › Chapter 2 › fprintf vs fwrite
fprintf — Formatted text

Use when records should be readable and editable. Conversions like %d and %s create text output.

Example: fprintf(outFile, "Name: %s, Age: %d ", name, age);
fwrite — Raw bytes

Use for efficient block storage when exact memory representation is desired. Check returned count to ensure full write.

Example: fwrite(numbers, sizeof(int), count, binFile);
Portability note

Binary dumps of structs can break across architectures because of endianness and padding. Use text or a stable serialization for cross-platform data exchange.
