Module 3 › Chapter 2 › Seeking & Position
Common calls
  • fseek(stream, offset, SEEK_SET|SEEK_CUR|SEEK_END)
  • ftell(stream) returns current offset
  • rewind(stream) sets offset to zero
Record access pattern
To read record n of fixed size S: fseek(stream, n * S, SEEK_SET); then fread the record.
Example snippet
FILE *f = fopen("seek_test.txt", "w+");
if (f == NULL) { perror("Error"); }
fprintf(f, "0123456789");
long pos = ftell(f); /* should be 10 */
fseek(f, 3, SEEK_SET);
int c = fgetc(f); /* '3' */
rewind(f);
int first = fgetc(f); /* '0' */
fclose(f);
Note: fseek may fail on non-seekable streams; check the return value and handle errors accordingly.
