Module 3 › Chapter 2 › Key Concepts
File Stream & FILE*
An abstract handle from fopen used by all file operations; always check and close.
Text I/O vs Binary I/O
fprintf/fgets for readable files; fwrite/fread for efficient raw bytes. Choose based on readability and portability needs.
Error & Position APIs
Use ferror/feof/perror and fseek/ftell/rewind to detect issues and move the file pointer for random access.
Summary Takeaway

File I/O in C is powerful and low-level; write defensive code that checks returns, closes streams, and chooses formats appropriate to your portability and performance needs.
