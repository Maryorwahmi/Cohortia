Module 3 › Chapter 3.4 › Free the List
freeList implementation
void freeList(Node** head_ref) {
  Node* current = *head_ref;
  Node* nextNode;
  while (current != NULL) {
    nextNode = current->next; // Save next pointer
    free(current);           // Free current node
    current = nextNode;      // Move forward
  }
  *head_ref = NULL; // Caller sees an empty list
  printf("List freed.
");
}
Setting *head_ref to NULL prevents dangling top-level pointers in the caller.
Checklist
  • Save current->next before calling free.
  • Loop until current becomes NULL.
  • Set caller's head to NULL after freeing to indicate emptiness.
Key Takeaway

Freeing every node prevents memory leaks; clearing head avoids leaving a stale pointer to freed memory.
