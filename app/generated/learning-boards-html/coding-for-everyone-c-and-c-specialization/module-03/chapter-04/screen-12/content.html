Module 3 › Chapter 3.4 › Common Mistakes
Dangling pointer example

If you call free(current) and then attempt to read current->next, you are accessing freed memory. Always save current->next before free and then use the saved pointer.

Pattern to avoid
free(current);
current = current->next; // Unsafe: current has been freed
Memory leak example

If you remove a node from the list but never call free on it, that memory remains allocated until the program ends. In long-running programs this leads to steadily increasing memory usage.

Safe free pattern
Node* nextNode = current->next;
free(current);
current = nextNode;
Why it matters

Avoiding dangling pointers and leaks is essential for correct, stable programs; these practices form the backbone of safe C programming.
