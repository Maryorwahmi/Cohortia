Node structure in words

A node stores the payload and a pointer to the next node. The last node's next is NULL to mark the end. Head is the entry point to the whole sequence.

Typical C definition
typedef struct Node {
  int data;          // Data part
  struct Node *next; // Pointer to next node
} Node;
Note the self-referential pointer: struct Node *next;
Examples & checks
  • Insert at front: new->next = head; head = new;
  • Empty list: head == NULL
  • Null checks: always test a pointer before accessing ->data or ->next
Common mistake

Failing to update head in the caller after a function inserts at the beginning causes the caller's list to remain unchanged.
