Module 3 › Chapter 3.4 › Delete Head
Delete the first node
Node* deleteHead(Node* head) {
  if (head == NULL) return NULL; // empty list
  Node* temp = head;       // save current head
  head = head->next;       // move head forward
  free(temp);              // free old head
  return head;             // new head
}
Always save the pointer you will free before changing pointers.
Common pitfalls
  • Freeing before saving next leads to accessing freed memory.
  • Not updating the caller's head leaves the list unchanged externally.
Watch out

Accessing a node after free causes undefined behavior; always save needed pointers first.
