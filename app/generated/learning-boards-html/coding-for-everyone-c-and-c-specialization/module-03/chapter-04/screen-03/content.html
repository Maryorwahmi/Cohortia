Practical checks
  • Always check malloc result before using the pointer.
  • Return or update head when it changes in a function.
  • Save next pointer before freeing the current node.
Common misconceptions
  • Thinking append is constant time without extra tail pointer.
  • Assuming freeing a node removes all references elsewhere automatically.
Checkpoint

By the end of the exercises you should be able to write and call functions that create, insert, print, delete, and free nodes while preserving head and preventing memory bugs.
