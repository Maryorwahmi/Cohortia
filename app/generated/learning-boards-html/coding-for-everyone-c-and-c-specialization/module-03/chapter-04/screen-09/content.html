Print function
void printList(Node* head) {
  Node* current = head;
  printf("Linked List: ");
  while (current != NULL) {
    printf("%d -> ", current->data);
    current = current->next;
  }
  printf("NULL
");
}
This loop visits every node exactly once.
Use cases & cautions
  • Use traversal to search for a value before deletion.
  • Do not modify pointers you will still need later without saving them first.
  • Traversal cost is proportional to list length, so avoid repeated full scans when possible.
Key Takeaway

Traversal is the central mechanism for reading and searching linked lists; it must check for NULL before dereferencing pointers.
