Module 3 › Chapter 3.4 › Insert at the Beginning
Step-by-step
  1. Create the new node with createNode(value).
  2. Set newNode->next = head; this links to the old first node.
  3. Update head to point to newNode so it becomes the new first node.
// Returning new head
Node* insertAtBeginning(Node* head, int value) {
  Node* newNode = createNode(value);
  newNode->next = head; // Link to old head
  return newNode;       // New head
}
Edge cases & tips
  • If head is NULL, newNode->next becomes NULL and newNode becomes the only node.
  • To modify caller head directly, accept Node** head_ref and assign *head_ref = newNode.
  • Set newNode->next before reassigning head to avoid losing the old list.
Key Takeaway

Prepending is O(1) and safe for empty lists; the order of pointer updates matters to preserve the list.
