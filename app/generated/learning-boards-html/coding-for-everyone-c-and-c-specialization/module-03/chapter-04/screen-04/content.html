Module 3 › Chapter 3.4 › What is a Data Structure?
Definition and comparison

A data structure organizes data for efficient access and modification. Arrays provide index access but fixed size. Linked lists provide dynamic size and pointer-based chaining at the cost of sequential access.

Array (when to use)
When you need fast random access by index and predictable memory layout.
Linked List (when to use)
When insertions or deletions happen frequently and size is not known ahead of time.
Misconception
Linked lists always save memory — not necessarily. Node pointer overhead and allocator metadata can make them larger for small elements.
Key Takeaway

Choose linked lists for flexible size and frequent insertion/deletion; choose arrays for indexed access and contiguous memory.

Analogy

Think of an array as a row of numbered boxes in a shelf, and a linked list as a chain of boxes where each box points to the next with a ribbon. Moving the first ribbon is cheap; jumping to box five requires following ribbons one by one.

Concrete scenario

A logging buffer where entries arrive unpredictably and are frequently removed from the front is a good use of a linked list. You can pop the front quickly without shifting every remaining entry.
