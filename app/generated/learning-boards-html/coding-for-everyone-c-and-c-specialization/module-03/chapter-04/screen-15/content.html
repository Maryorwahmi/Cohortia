Module 3 › Chapter 3.4 › Key Concepts
Node
A node holds data and a pointer to the next node; it's the fundamental unit of the list.
Head Pointer
Head points to the first node; if head is NULL the list is empty. Update it carefully when changing the first element.
Memory Management
Use malloc and free responsibly. Save next before freeing and free all nodes when the list is no longer needed.
Summary

Nodes, a correct head discipline, and disciplined malloc/free pairing are the foundation of safe and effective linked lists in C.
