Module 3 › Chapter 3.4 › Insert at End
Algorithm
  1. Create the new node and set newNode->next = NULL.
  2. If head is NULL, return newNode as the head.
  3. Otherwise, traverse: current = head; while current->next != NULL, current = current->next.
  4. Set current->next = newNode to append.
Node* insertAtEnd(Node* head, int value) {
  Node* newNode = createNode(value);
  if (head == NULL) return newNode;
  Node* current = head;
  while (current->next != NULL) {
    current = current->next;
  }
  current->next = newNode;
  return head;
}
Performance & tips
  • Append is O(n) unless you maintain a tail pointer that points to the last node.
  • Always handle the empty list case explicitly when appending.
  • Be mindful of off-by-one errors in the traversal loop condition.
Pro tip

If you will append frequently, consider storing a tail pointer or using a dummy head to simplify edge cases.
