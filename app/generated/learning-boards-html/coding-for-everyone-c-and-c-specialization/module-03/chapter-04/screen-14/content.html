Testing checklist
  • Insert at beginning on empty and non-empty lists.
  • Append when list is empty and when not empty.
  • Delete head, delete middle, delete tail, and delete non-existent values.

Developer tip

Use printList liberally during development; printing after each change makes pointer mistakes obvious.
