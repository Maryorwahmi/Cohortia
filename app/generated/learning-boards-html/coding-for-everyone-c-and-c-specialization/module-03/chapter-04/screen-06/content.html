Module 3 › Chapter 3.4 › createNode
Explanation

createNode allocates memory on the heap, initializes the node's data and next pointer, and returns a Node pointer. Always check malloc's return value and handle allocation failure appropriately.

#include <stdio.h>
#include <stdlib.h>

Node* createNode(int value) {
  Node* newNode = (Node*)malloc(sizeof(Node));
  if (newNode == NULL) {
    fprintf(stderr, "Memory allocation failed for new node!
");
    exit(EXIT_FAILURE);
  }
  newNode->data = value;
  newNode->next = NULL;
  return newNode;
}
Checks and tips
  • Include <stdlib.h> for malloc and free.
  • Handle NULL returns from malloc to avoid undefined behavior.
  • Initialize next to NULL so new nodes safely mark the end when appended.
Danger

Dereferencing a NULL pointer returned by malloc causes a crash. Always validate before use.
