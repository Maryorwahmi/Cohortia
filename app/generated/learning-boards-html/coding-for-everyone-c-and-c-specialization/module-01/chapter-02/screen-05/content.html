What the include does

The include directive asks the preprocessor to insert declarations and macros from a header file into your source before compilation. It does not execute code; it supplies the compiler with the signatures and definitions needed to validate function calls.

Example header: standard input output provides declarations for the print function and related I/O helpers.
Misconception: including a header runs the code it references. Correction: only declarations are made available; linking later resolves implementations.
Visual analogy
Header = toolbox catalog
You consult the catalog to know what tools exist. If the catalog doesn't list a tool you try to use, the compiler will complain.
Common mistake

Forgetting to include a header leads to undefined or unresolved reference errors when compiling.
