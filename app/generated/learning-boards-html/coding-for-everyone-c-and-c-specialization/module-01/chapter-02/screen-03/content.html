Assessment tasks
  1. Create a small program that prints a string and a number using the right placeholders.
  2. Explain why including the standard input output header is necessary for the print function.
  3. Identify and fix a missing semicolon and a mismatched placeholder example.
  4. Run the compiled program and interpret the exit status.

M - Main entry
P - Print statements
