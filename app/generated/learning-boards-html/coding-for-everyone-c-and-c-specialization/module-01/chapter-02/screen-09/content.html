Module 1 › Chapter 1.2 › Format placeholders
percent d / percent i
For integer values. Example: printing an age.
percent f / percent dot two f
For floating point values; add dot two to show two decimals like 1.75 -> 1.75.
percent c / percent s
percent c prints one character; percent s prints a string or character array.
Example
Use percent s then percent c then percent d then percent dot two f and pass variables in the same order for predictable substitution.
