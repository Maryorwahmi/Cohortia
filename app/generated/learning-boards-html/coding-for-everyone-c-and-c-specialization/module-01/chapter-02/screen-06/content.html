Role of main

Execution starts at main. The integer return value is the program's way to inform the operating system about success or failure.

Return zero is conventional for success; use non-zero codes strategically for different error conditions.
Later: main can accept arguments from the command line to influence program behavior.
Why it matters
  • Scripting and automation check the exit code to decide next steps.
  • Returning specific codes helps debugging and integration with other programs.
  • Explicit returns make intent clear and portable across compilers.
Pro tip

Plan meaningful non-zero codes for different failure modes in larger programs.
