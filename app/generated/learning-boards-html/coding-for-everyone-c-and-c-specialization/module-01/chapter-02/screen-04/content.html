Module 1 › Chapter 1.2 › Dissecting a minimal program
Annotated source (hello dot c)
#include <stdio.h> // Preprocessor directive: provides I/O declarations

int main() {
    printf("Hello, World!
"); // Call the print function to show text and newline
    return 0; // Return zero indicates success to the OS
}
Explainer bullets
  • Include: inserts declarations from the standard input/output header so the print function is known.
  • Main: the entry point where execution begins and where a return value is provided.
  • Print call: shows literals or variable values, uses placeholders to format output.
  • Return zero: conventional signal for successful termination to the operating system.
Key Takeaway

A minimal program gives you a predictable start point: include headers, run code in main, and return a status.
