With and without newline
With backslash n:
print function output: Hello
World
Console shows:
Hello
World
Why it matters
  • Readability: logs and results are easier to scan with proper newlines.
  • Formatting: tables or multi-line messages require explicit line breaks.
  • Literal backslash: to show backslash n you must escape the backslash itself.
