Module 1 › Chapter 1.2 › Printing text and variables
Example code
#include <stdio.h>

int main() {
    int age = 30;
    float height = 1.75;
    char initial = 'J';
    char name[] = "John";

    printf("My name is %s %c.
", name, initial);
    printf("I am %d years old.
", age);
    printf("I am %.2f meters tall.
", height);
    return 0;
}
Explanation
  • Placeholders: percent s for strings, percent c for characters, percent d for integers, percent f for floats.
  • Argument order must match the placeholders; a mismatch produces incorrect output or undefined behavior.
  • Format modifiers like percent dot two f control decimal precision for floats.
Common mistake

Using percent d for a float or swapping the order of variables yields wrong or unpredictable results.
