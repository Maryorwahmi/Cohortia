Module 1 › Chapter 1.2 › Semicolons & errors
Typical symptom
Compiler points at a token on a line where code looks fine. Check the previous line for a missing semicolon or an unclosed comment.
Debug tip

If error location seems odd, inspect and correct punctuation on the preceding lines first.

Example fix
printf("Hello, World!
"); // ensure semicolon is present
A missing semicolon before a return statement is a common real example; fix it and recompile.
