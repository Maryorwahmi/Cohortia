Common Mistake

Diagnose & fix typical errors

• Missing ampersand → likely segmentation fault.
• Wrong format specifier → misinterpreted bytes and wrong stored value.
• Uninitialized variable → garbage values and unpredictable results.
Example fix
// Wrong
int n;
scanf("%d", n); // missing &

// Right
int n = 0;
scanf("%d", &n);
Debugging tips
  • • Read compiler warnings and treat them seriously.
  • • Add prints after each input to confirm values were stored as expected.
  • • Initialize variables at declaration to make behavior deterministic.
Quick fix

When in doubt, initialize, match specifiers, and pass addresses. These three changes fix most early bugs.
