Process

Casting before evaluation

1. Identify the operation that needs higher precision.
2. Cast one operand to float or double using parentheses before the value.
3. Evaluate the expression; the presence of a floating-point operand makes the whole expression use floating-point arithmetic.
int a = 10, b = 3;
float precise = (float)a / b; // 3.333333

// Or cast b instead:
float precise2 = a / (float)b; // same effect
Practical note
Use explicit casts to make code intentions clear. When accuracy is critical, cast to double rather than float to gain extra precision.
Exercise
Calculate the average of two integers with and without casting. Print both outputs and explain why they differ. This cements the role of casting in numerical results.
Key Takeaway

Cast before division to get fractional results; explicit casts document intent and prevent silent truncation.
