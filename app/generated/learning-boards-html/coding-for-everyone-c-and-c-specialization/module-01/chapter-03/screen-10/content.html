Integer vs Floating-Point Division

Integer: Both operands integer → fractional part truncated.
Floating-point: Any operand float/double → fractional division result.
int a = 15, b = 4;
float r1 = a / b;           // r1 == 3.00  (integer division happens first)
float r2 = (float)a / b;    // r2 == 3.75  (cast forces floating-point division)
Practical advice
When computing averages or rates, cast before dividing so you retain decimals. For accurate accumulation or scientific calculations prefer double precision.
Check exercise
Compute the average of two integers using integer division and then using casting. Observe the difference and explain why casting changed the result.
Key Takeaway

Cast before dividing when you need fractional results; otherwise integer division will truncate values.
