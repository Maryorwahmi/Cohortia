Definition

Core data types

int
Stores whole numbers. Use for counts and indexes. Example: int score = 5;
float
Single-precision decimal. Use when memory or precision constraints allow. Example: float temp = 23.5f;
double
Double-precision decimal. Prefer when you need accuracy. Example: double pi = 3.141592653589793;
char
Single character stored as a small integer code. Example: char initial = 'A';
Comparison & Examples
When to choose int: counts like number of students, loop indices, or status codes.
When to choose float: simple measurements where 6–7 digits precision is sufficient.
When to choose double: scientific or financial calculations needing greater accuracy.
When to choose char: single letter inputs, small markers, or components of a string.
Common misconception
Assuming char stores a string. A char holds one character; strings require character arrays or pointers. Also don't assume float precision equals double—results differ for division and accumulation.
Key Takeaway

Choose types to balance memory and precision; prefer double when accuracy matters.
