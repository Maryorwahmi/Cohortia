Process Flow

scanf: format, address, store

1. Prepare a variable of the correct type and size.
2. Call scanf with a format string that uses the proper specifier.
3. Pass the address of the variable using the address-of operator so scanf can write into it.
4. Check the return value when you need robust validation.
Quick examples
int age;
printf("Enter age: ");
scanf("%d", &age);

float height;
printf("Enter height: ");
scanf("%f", &height);

char initial;
printf("Enter initial: ");
scanf(" %c", &initial); // leading space skips leftover newline
Common mistakes & tips
  • • Forgetting & causes scanf to treat the current variable value as an address, which usually crashes.
  • • Using %f for double or vice versa will misinterpret bytes and produce incorrect values.
  • • When reading characters after numbers, prefix %c with a space to skip whitespace.

Write a short program that reads an int, a float, and a char and prints them back. Intentionally try leaving out & to observe the error and then fix it.
