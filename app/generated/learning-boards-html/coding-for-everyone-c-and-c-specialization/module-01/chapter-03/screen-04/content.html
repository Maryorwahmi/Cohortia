Core Concept

Variables as labeled boxes

Declaration tells the compiler the label and type. Initialization places a known value inside the box so you avoid garbage data.

Declaration example
int score;  // declares an integer variable named score
Initialization example
int age = 30;  // declares and initializes age to 30
Key Takeaway

Always initialize variables before use to avoid unpredictable program behavior.

Analogy & Quick Rules
  • • Variable name: the label on the box. Use descriptive names like student_count.
  • • Data type: the box size and allowed contents (int, float, double, char).
  • • Declaration: reserve space. Initialization: place a known item inside.
  • • Naming rules: no leading digits, only underscore as special character, follow snake_case for readability.
Common mistake
Using a variable before it is initialized results in garbage values and unpredictable behavior. Initialize variables when declaring them when possible.
