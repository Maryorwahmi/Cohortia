Code Walkthrough

Read age, height, and initial

#include <stdio.h>

int main() {
  int user_age;
  float user_height;
  char user_initial;

  printf("Enter your age: ");
  scanf("%d", &user_age);

  printf("Enter your height in meters (e.g., 1.75): ");
  scanf("%f", &user_height);

  printf("Enter your first initial: ");
  scanf(" %c", &user_initial); // leading space skips newline

  printf("You are %d years old, %.2f meters tall, and your initial is %c.
",
         user_age, user_height, user_initial);

  return 0;
}
Annotations
  • • Each variable is declared before use so the compiler reserves memory.
  • • scanf format specifiers match the variable types exactly.
  • • The address-of operator provides locations for scanf to write into.
  • • The printf call formats the output and shows the stored values, verifying successful reads.
Pro tip
Always test with unexpected input, like letters where numbers are expected, to observe how scanf behaves. For production code, consider safer input parsing techniques.
