Learning Objectives

Skills to show you can write, read, and compute with variables in C.

Learn → Understand → Apply → Master
01 Declare & Initialize
Write variables with types and starting values

You will learn declaration syntax, initialization best practices, and why uninitialized variables can hold garbage. Verified competency: create and initialize three variables of different types.

02 Data Types
Distinguish int, float, double, and char

You will match types to uses and precision needs, and learn typical sizes and limits. Verified competency: choose correct types for 3 sample variables.

03 Read Input Safely
Use scanf with the address-of operator

You will see how scanf writes into memory addresses and why forgetting the address-of operator causes crashes. Verified competency: read and print three inputs without errors.

04 Arithmetic & Casting
Perform calculations and control precision

You will learn operator precedence, integer division behavior, and how casting changes arithmetic results. Verified competency: compute a precise average using casting.
