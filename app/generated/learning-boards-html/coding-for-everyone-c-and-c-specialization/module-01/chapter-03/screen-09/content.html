Core Concept

Arithmetic operators

• + addition
• - subtraction
• * multiplication
• / division
• % modulus (remainder for integer division)
Examples
int a = 10, b = 3;
int q = a / b;     // q == 3 (integer division)
int r = a % b;     // r == 1 (remainder)
float f = (float)a / b; // f == 3.333... (floating-point division)
Operator precedence
Multiplication, division, and modulus are evaluated before addition and subtraction. Use parentheses to clearly express the intended order and avoid subtle bugs.
Quick checks
  • • Evaluate 2 + 3 * 4 → 14, not 20.
  • • Use parentheses: (2 + 3) * 4 → 20.
  • • Cast operands to float to avoid truncation during division.
Key Takeaway

Understand precedence and use casting to control whether division returns integers or fractions.
