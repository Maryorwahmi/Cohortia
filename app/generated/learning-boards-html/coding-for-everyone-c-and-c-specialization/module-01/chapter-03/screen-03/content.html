Practice & Checks

Small tasks to confirm you understand declaration, types, input, and arithmetic.

Apply → Test → Reflect
Task 1: Initialize

Declare three variables of different types, initialize them, and print their values to confirm no garbage data.

Task 2: Choose types

Pick int for counts, float or double for measured values, char for single symbols. Note precision needs.

Task 3: scanf practice

Read an integer, a float, and a character using correct format specifiers and the address-of operator. Verify behavior with different inputs.

Task 4: Arithmetic & Casting

Compute integer division and then compute the precise floating-point result by casting one operand. Confirm difference in outputs.

Common mistakes

Uninitialized variables, missing ampersand with scanf, wrong format specifier, and forgetting to cast for floating-point division.
