Definition

Address-of operator

Using ampersand before a variable returns its memory address, which is required for functions that write into memory locations.

Example contrast
// Correct
int age;
scanf("%d", &age);

// Incorrect — likely crash
int age2;
scanf("%d", age2); // age2 value treated as address
Common misconception

Beginners sometimes believe the input function can infer where to store a value from the variable name alone. In C, you must explicitly pass the address of the variable to enable direct memory writes.

Check your understanding
Write a short program that omits the ampersand, run it to see the error, then correct it to see the successful read. This concrete comparison helps cement why ampersand is required.
Key Takeaway

Always pass the address of a variable to scanf so it can safely write user input into memory.
