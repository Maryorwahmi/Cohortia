Quick Reference

Three short reminders to guide your coding sessions.

Initialize
Set starting values when declaring to avoid unpredictable memory contents.
Address-of & Specifiers
Pass & to scanf and match format specifiers to variable types.
Cast for precision
Cast operands to float or double before dividing to preserve decimals.
Final takeaway
These three rules will reduce common runtime errors and ensure your numeric results match expectations as you build interactive C programs.
