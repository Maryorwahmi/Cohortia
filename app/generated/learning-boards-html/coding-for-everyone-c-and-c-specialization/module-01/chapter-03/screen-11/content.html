Area calculator walkthrough

#include <stdio.h>

int main() {
  float length;
  float width;
  float area;

  printf("Enter the length of the rectangle: ");
  scanf("%f", &length);

  printf("Enter the width of the rectangle: ");
  scanf("%f", &width);

  area = length * width;
  printf("The area of the rectangle is: %.2f square units.
", area);

  return 0;
}
Walkthrough notes
  • • Use float for measured values that may have decimals.
  • • Always pass addresses to scanf so values are written into your variables.
  • • Use formatting in printf to control decimal places when displaying results.
  • • Test with integers and decimals to ensure consistent results.
Extension challenge
Modify the program to compute the average of two integer inputs but output a decimal result by casting before dividing. This reinforces casting and input handling together.
