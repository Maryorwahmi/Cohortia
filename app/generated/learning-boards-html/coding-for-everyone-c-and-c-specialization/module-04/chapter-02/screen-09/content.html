Module 4 › Chapter 4.2 › Constructors
Default constructor

Creates sensible defaults when no arguments are provided. Good for simple instantiation.

Car() : make("Unknown"), model("Unknown"), year(2023), speed(0) {
  std::cout << "Default Car created." << std::endl;
}
Parameterized constructor

Accepts parameters to customize the object's state at creation.

Car(std::string carMake, std::string carModel, int carYear)
  : make(carMake), model(carModel), year(carYear), speed(0) {
  std::cout << "Car " << make << " " << model << " created." << std::endl;
}
Practical notes
  • Prefer initialization lists for non-trivial members and performance.
  • Print statements in constructors help verify when and with which values objects are built.
  • Always ensure constructors leave objects in valid states, even on error paths.
