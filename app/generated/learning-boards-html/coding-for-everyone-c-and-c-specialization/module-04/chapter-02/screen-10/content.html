Destructor syntax
~Car() {
  std::cout << "Car destroyed" << std::endl;
  // free resources here if any
}

Destructors should free any resources the object acquired during its lifetime.

When destructors run
  • Stack objects: at scope exit automatically.
  • Heap objects: when delete is called on the pointer.
  • If a program exits without deleting heap objects, destructors may not run — this leads to leaks during long runs.
Common mistake

Allocating memory in a constructor but forgetting to free it in the destructor produces memory leaks. Always match allocation and deallocation during practice to observe proper behavior.
