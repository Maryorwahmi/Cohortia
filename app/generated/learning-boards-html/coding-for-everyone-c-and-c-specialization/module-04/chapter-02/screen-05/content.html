Module 4 › Chapter 4.2 › Class Members
Data members

Store attributes that define each object's state. Prefer private scope to protect invariants.

Example
private:
  std::string make;
  int year;
  int speed; // current speed
Member functions

Offer operations that maintain valid state and provide a stable interface to users.

Example methods
public:
  void accelerate(int delta);
  int getSpeed() const;
  void setYear(int year);
Key Takeaway

Keep state private and expose only the operations required by program logic. Validate in setters to keep objects consistent.

Why this organization helps
  • Makes code easier to read and reason about because state and behavior live together.
  • Prevents accidental corruption by external code.
  • Allows you to change implementation details without changing the public interface.
Pro tip
Favor clear method names and keep each method focused on a single responsibility. This improves testability.
