Module 4 › Chapter 4.2 › What is a Class?
Class: a blueprint
Declare structure and behavior together so each instance follows the same contract.
Data members

Variables that hold an object's attributes, for example make, model, speed.

Member functions

Operations that change or read the object's state, like accelerate or getSpeed.

Key Takeaway

Design classes to encapsulate related data and behavior, keeping the public interface minimal and purposeful.

Analogy & Example
Blueprint analogy: the class is a plan. The object is a built item following that plan. The same class can produce many objects, each with independent state.
Quick code sketch
class Car {
  // data members
  std::string make;
  int year;
  int speed;

  // member functions
  void startEngine();
  void accelerate(int delta);
};
Misconception
A class is not an object. Declaring a class only creates the type; instantiation creates an object with memory and state.
