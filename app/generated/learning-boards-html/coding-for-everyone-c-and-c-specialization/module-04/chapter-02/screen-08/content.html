Module 4 › Chapter 4.2 › Create Objects
Stack allocation

Declared objects have automatic lifetime and are cleaned up when out of scope.

Example
Car myCar; // stack object
myCar.startEngine();
Heap allocation

Use new to allocate on the heap and delete to free. Destructors run when delete is called.

Example
Car* fancyCar = new Car("Ferrari","488",2022);
fancyCar->accelerate(100);
delete fancyCar; // destructor called
Practical guidance
  • Prefer stack allocation for simple objects with limited lifetime.
  • Use heap allocation when lifetime must outlast the creating scope or when polymorphism requires pointers.
  • Always pair new with delete to observe destructor execution in learning exercises.
