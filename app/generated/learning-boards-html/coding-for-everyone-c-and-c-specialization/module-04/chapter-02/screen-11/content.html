Module 4 › Chapter 4.2 › The this Pointer
Disambiguation example
void setYear(int year) {
  this->year = year; // parameter and member have same name
}
Return *this to enable chaining:
Student& setName(const std::string& n) {
  name = n;
  return *this;
}
Practical notes
  • Const methods see a const-qualified this pointer, preventing modification.
  • Static methods have no this pointer because they are not tied to a specific instance.
  • Use clear names to avoid always needing this, but use it when needed for clarity or chaining.
