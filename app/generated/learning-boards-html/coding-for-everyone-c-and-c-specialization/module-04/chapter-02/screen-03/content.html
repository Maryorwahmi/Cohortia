Module 4 › Chapter 4.2 › Practice & Verify
Step-by-step practice
  1. Write a minimal class and compile it to check syntax and the required semicolon.
  2. Make data members private and add public getters/setters with validations.
  3. Create objects on the stack and with new; observe constructor messages.
  4. Delete heap objects and observe destructor messages; practice avoiding leaks.
Keep a small main function to run each change and confirm console output.
Verification hints
  • Constructor should print or set meaningful initial values.
  • Setter validation should prevent invalid state and print warnings in tests.
  • For heap allocation, always pair new with delete in the same scenario.
Misconception alert

Private does not mean unreachable by class methods. It means external code cannot modify internals directly — this is by design.
