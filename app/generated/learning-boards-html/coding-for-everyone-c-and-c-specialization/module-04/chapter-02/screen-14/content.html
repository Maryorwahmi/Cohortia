Module 4 › Chapter 4.2 › Common Mistakes
Frequent errors
  • Missing semicolon after class definition — check the closing brace line.
  • Accessing private members externally — use public methods or change design.
  • Forgetting delete for new — leads to memory leaks; observe destructor output.
  • Shallow copies of objects that own resources — leads to double delete.
Debugging tips
  1. Add prints to constructors and destructors to follow lifecycle order.
  2. Test one feature at a time with a minimal main function.
  3. When errors cascade, fix the first reported error before subsequent ones.
Reminder

Good class design and small tests reduce the time spent debugging later.
