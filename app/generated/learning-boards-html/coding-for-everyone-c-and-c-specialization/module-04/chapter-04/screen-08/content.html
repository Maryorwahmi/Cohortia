Common Mistakes and How to Avoid Them
Practical checks to keep your overloads and templates safe and predictable.
Meaning changes
Don't redefine an operator to do the opposite of its conventional behavior; readers rely on expectations.
Dangling references
Return new objects by value for arithmetic operators; avoid returning references to locals.
Stream return
Always return ostream& or istream& from << and >> to support chaining.
Template visibility
Keep template definitions where they can be seen at instantiation, usually in headers.
Quick fix

When a problem arises, check return types first, then whether the function should be member or non-member, and finally whether template code is visible to the compiler.
