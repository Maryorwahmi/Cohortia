Module 5 › Chapter 4.4 › Key Concepts — Part 1
Operator Overloading
Give operators natural behavior for your types without changing core meanings.
Friend Functions
Grant non-member operators access to private data, commonly for stream operators.
Stream Operators
Implement as non-members that return ostream& or istream& to support chaining.
One-line takeaway

Operator overloads and friend functions connect your types to idiomatic C++ I/O and behavior.
