Return safety
Prefer returning new objects by value for arithmetic operators to avoid dangling references.
Template visibility
Place templates where the compiler can instantiate them, usually in headers.
Minimal friends
Keep friend functions narrow in scope to preserve encapsulation when necessary.
Final takeaway

Use operator overloading and templates to express intent and reuse code, while following rules that keep code safe and maintainable.
