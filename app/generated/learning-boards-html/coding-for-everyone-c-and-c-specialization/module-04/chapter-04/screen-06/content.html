Stream operators
Use non-member signatures that accept the stream and the object.
<!-- Example: streamed output signature -->
std::ostream& operator<<(std::ostream& os, const ComplexNumber& cn) {
  os << cn.getReal() << " + " << cn.getImag() << "i";
  return os;
}
Must return
Always return the stream by reference to allow chaining like cout << a << b.
Friend functions
Declare the operator as friend within your class when it needs access to private members without exposing them publicly.
Example pattern
Inside class: friend std::ostream& operator<<(std::ostream&, const Class&);
Common pitfall
Returning void or returning an object instead of the stream breaks chaining and standard style.
