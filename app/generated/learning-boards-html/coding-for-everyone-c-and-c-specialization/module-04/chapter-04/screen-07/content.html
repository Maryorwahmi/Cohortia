Code example
A focused snippet demonstrating member + and == and friend <<.
<!-- ComplexNumber.h snippet -->
class ComplexNumber {
private:
  double real;
  double imag;
public:
  ComplexNumber(double r = 0.0, double i = 0.0) : real(r), imag(i) {}

  ComplexNumber operator+(const ComplexNumber& other) const {
    return ComplexNumber(real + other.real, imag + other.imag);
  }

  bool operator==(const ComplexNumber& other) const {
    return (real == other.real && imag == other.imag);
  }

  friend std::ostream& operator<<(std::ostream& os, const ComplexNumber& cn);
};

std::ostream& operator<<(std::ostream& os, const ComplexNumber& cn) {
  os << cn.real << (cn.imag >= 0 ? " + " : " - ") << (cn.imag >= 0 ? cn.imag : -cn.imag) << "i";
  return os;
}
Test scenario
Create two ComplexNumber objects, add them, and print the result to confirm (3,4) + (1,2) = (4,6).
Walkthrough notes
  • Make arithmetic operators const and return by value for safety.
  • Use friend for << to access private fields without exposing them publicly.
  • Ensure << returns ostream& to allow chaining.
