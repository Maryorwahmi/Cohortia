Assessment tasks
Two short tasks to check coding and conceptual knowledge.
Task 1 — Fraction::operator+
Write a member operator+ that computes a new numerator and denominator and returns a new Fraction by value. Avoid reducing the fraction to keep the skeleton simple.
Fraction operator+(const Fraction& other) const {
  int newNum = (this->numerator * other.denominator) + (other.numerator * this->denominator);
  int newDen = this->denominator * other.denominator;
  return Fraction(newNum, newDen);
}
Task 2 — Template linker pitfall
Explain why placing template definitions in a .cpp file causes linker errors and how to avoid it: keep definitions in headers or use explicit instantiations.
Grading hint

Correct signature and returning by value for operator+ and a clear explanation about template instantiation visibility earn full marks.
