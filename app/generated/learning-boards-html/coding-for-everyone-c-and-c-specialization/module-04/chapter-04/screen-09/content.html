Module 5 › Chapter 4.4 › Function Templates: maximum
Template declaration
A single definition that the compiler specializes for each used type.
template <typename T>
T maximum(T a, T b) {
  return (a > b) ? a : b;
}

// Usage:
// maximum(5, 10)
// maximum(3.5, 2.1)
// maximum(std::string("apple"), std::string("banana"))
Constraint
Types must support operator> or you must provide an overload or comparator.
Template pitfalls
  • Separating implementation into a .cpp can cause linker errors unless you use explicit instantiation.
  • Templates instantiate only for types actually used; errors surface at instantiation time.
  • Make sure operations used inside the template are valid for intended types.
Key Takeaway

Templates are powerful for reuse but rely on type capabilities and require implementation visibility at instantiation.
