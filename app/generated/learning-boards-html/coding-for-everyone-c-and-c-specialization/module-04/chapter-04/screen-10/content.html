Stack template code
template <typename T>
class Stack {
private:
  T* arr;
  int top;
  int capacity;
public:
  Stack(int size) : capacity(size), top(-1) { arr = new T[capacity]; }
  ~Stack() { delete[] arr; }

  void push(T value) {
    if (top < capacity - 1) arr[++top] = value;
  }

  T pop() {
    if (top >= 0) return arr[top--];
    return T();
  }

  bool isEmpty() const { return top == -1; }

  T peek() const { return (top >= 0) ? arr[top] : T(); }
};
Usage
Stack<int> intStack(3); Stack<std::string> stringStack(2);
Implementation notes
  • Return default-constructed T on underflow to avoid undefined behavior.
  • Manage heap memory carefully; consider using std::vector in production code.
  • Keep the template definition visible in the header for instantiation.
Check

Try pushing and popping with different types and observe compile-time specialization of the template.
