Definition
C++ iostream: std::cout and std::cin
A compact live-coding panel demonstrates sending and receiving values with streams and explains std::endl and common input errors.
Code example (read and echo)
#include <iostream>

int main() {
  std::cout << "Please enter your age: ";
  int age;
  std::cin >> age;
  std::cout << "You entered: " << age << std::endl;
  return 0;
}
This example shows insertion and extraction operators. If a non-integer is entered, std::cin sets an error state and further reads fail until cleared.
Concrete example
Prompt the user for age and echo it. This replaces printf/scanf and avoids format specifiers like %d.
Misconception
Streams are not simply slower replacements; they provide type-safety and clearer code, though input error handling is different than scanf.
Key Takeaway

Use std::cout and std::cin for readable, type-aware I/O; handle input errors explicitly when reading user data.
