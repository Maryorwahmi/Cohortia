Definition
bool: true or false
A clear boolean type improves readability and communicates intent in conditionals and function signatures.
Example
bool isStudent = true;
if (isStudent) {
  std::cout << "You are a student." << std::endl;
} else {
  std::cout << "You are not a student." << std::endl;
}
Misconception
Integers can represent truth, but they obscure intent and lead to accidental arithmetic or ambiguous checks. Use bool for flags.
Replacing int flags with bool often clarifies APIs and reduces the need for comments explaining numeric values.
Key Takeaway

Prefer bool for logical values. It communicates intent and reduces errors compared with integer truthiness.
