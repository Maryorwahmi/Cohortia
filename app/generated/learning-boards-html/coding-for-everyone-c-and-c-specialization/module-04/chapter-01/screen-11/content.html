References vs Pointers — choosing the right parameter
Compare usage patterns and examples that illustrate optionality, safety, and syntax differences.
Reference example
void increment(int& n) {
  n++;
}

int main() {
  int value = 5;
  increment(value); // value becomes 6
}
Pointer example (optional)
void maybeIncrement(int* p) {
  if (p != nullptr) (*p)++;
}

int main() {
  int* p = nullptr;
  maybeIncrement(p); // safe no-op
}
Pointers allow null to indicate absence; references do not.
Key Takeaway

Match parameter style to intent: use references for mandatory aliases, pointers for optionality, and const references to avoid copies for large read-only data.
