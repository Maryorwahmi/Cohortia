Best Practices
Common mistakes and practical tips
A layered panel that groups common pitfalls, pro tips, and a checklist to reduce errors when adopting C++ idioms.
Pitfall
Mixing printf/scanf with std::cout/std::cin causes buffering issues. Stick to one I/O system.
Pitfall
Mismatching new/new[] and delete/delete[] leads to undefined behavior. Match allocation and deallocation forms.
Pitfall
Using using namespace std; globally increases risk of name collisions. Prefer explicit qualification in shared code.
Pro tip
Prefer RAII and std::vector for dynamic data. Let containers manage memory where possible.
Checklist
  • Use std::cout/std::cin consistently.
  • Match new with delete and new[] with delete[].
  • Prefer explicit std:: qualification in libraries.

Introduce a small deliberate leak and then fix it with delete[]; observe program memory before and after in a longer-running example.
