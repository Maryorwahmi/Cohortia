Process Flow
new and delete: single-object lifecycle
Three steps
  1. Allocate and initialize: int* ptr = new int;
  2. Use the object: *ptr = 100; or call methods if it’s a class.
  3. Deallocate: delete ptr; then optionally ptr = nullptr;
Code
int* dynamicInt = new int;
*dynamicInt = 100;
// use dynamicInt
delete dynamicInt;
dynamicInt = nullptr;
Concrete example
Allocating a single int and printing it demonstrates allocation and cleanup. For classes, constructors and destructors run at these points.
Misconception
New is not the same as malloc: new constructs objects, while malloc only reserves raw memory.
Key Takeaway

Pair new with delete for single objects; remember constructors and destructors participate in this lifecycle.
