Definition
Namespaces and std
Namespaces group identifiers and prevent collisions. Learn when to qualify with std and when a using declaration is acceptable.
Short example
// qualification
std::cout << "Hello" << std::endl;

// selective import
using std::cout; 
cout << "Hi" << std::endl;
Selective imports reduce typing but still limit scope. Avoid using namespace std; in shared code.
Analogy
Think of namespaces like folders: the same filename can exist in different folders without conflict; qualification tells the compiler which folder to use.
Common mistake
Blindly adding using namespace std; in header files or shared modules can cause collisions and confusing errors across a project.
Key Takeaway

Namespaces avoid naming conflicts. Prefer explicit std:: usage in larger code to keep intent and avoid ambiguity.
