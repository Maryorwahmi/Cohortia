Practice & Pitfalls
Short exercises and common mistakes to watch for during conversion from C to C++.
Tip: treat small examples with using namespace std; prefer std:: in projects.
Exercise
Convert rectangle area program to use std::cin/std::cout and references.
Follow the hands-on activity: make a calculateArea function that uses references and print the result with std::cout.
Pitfall
Mixing C I/O and C++ streams
Mixing printf/scanf with std::cout/std::cin can cause buffering surprises. Prefer one I/O style per program.
Memory check
Match allocation and deallocation
Always use delete[] for new[] and delete for new to avoid leaks and undefined behavior.
