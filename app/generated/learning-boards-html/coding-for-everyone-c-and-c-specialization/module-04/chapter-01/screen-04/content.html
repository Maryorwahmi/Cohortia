C vs C++: changing idioms
A focused comparison showing practical differences in I/O, allocation, and boolean clarity with examples and common misconceptions.
Core concept: choose the C++ idiom for clearer, safer code.
I/O: format strings vs streams
C: printf/scanf require format specifiers. C++: std::cout/std::cin use insertion/extraction operators and are type-aware.
Example
// C++ example using streams
std::cout << "Hello, Cohortia!" << std::endl;
int age;
std::cout << "Please enter your age: ";
std::cin >> age;
std::cout << "You entered: " << age << std::endl;
Memory: malloc/free vs new/delete
C's malloc does raw allocation. C++ new allocates and constructs objects; delete destructs and frees. Match new[] with delete[].
Example
int* p = new int;        // single int
*p = 42;
delete p;

int* arr = new int[5];   // array
// ... use arr ...
delete[] arr;
bool type
Explicit true/false gives clearer conditionals than C's integer truthiness.
Common mistake
Forgetting to use delete[] for arrays allocated with new[] causes leaks and undefined behavior.
Check your understanding
If you replace malloc with new, do you still call free? Think about constructors and destructors.
