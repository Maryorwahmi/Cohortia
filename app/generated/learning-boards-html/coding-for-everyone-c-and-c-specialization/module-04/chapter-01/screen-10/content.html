Definition
Reference variables (&): aliases for existing variables
References provide safe pass-by-reference semantics without pointer syntax and null checks.
Example
void modifyValue(int& val) {
  val += 10;
}

int main() {
  int original = 50;
  modifyValue(original); // original now 60
}
Pointer vs reference
References cannot be null and cannot be reseated. Pointers can be null and reassigned. Choose references when aliasing a definite object.
Common mistake
Expecting a reference to be reseatable like a pointer leads to design errors; references are permanent aliases after initialization.
Key Takeaway

Use references to write clear mutate-by-reference functions without pointer syntax or null checks; use pointers when you need optionality or reseating.
