new[] and delete[] for arrays
Follow a clear example that shows initialization, usage, and correct deallocation of an array allocated with new[].
Code example
int* dynamicArray = new int[5];
for (int i = 0; i < 5; ++i) {
  dynamicArray[i] = (i + 1) * 10;
}
// print
for (int i = 0; i < 5; ++i) {
  std::cout << dynamicArray[i] << " ";
}
std::cout << std::endl;

delete[] dynamicArray;
dynamicArray = nullptr;
Why match delete[]?
Matching ensures destructors run for each element and prevents undefined behavior from mismatched deallocation.
Practical tip
Prefer standard containers like std::vector when you can. They manage allocation and deallocation for you.
Key Takeaway

For arrays, always call delete[] on memory allocated with new[]; otherwise you risk undefined behavior and leaks.
