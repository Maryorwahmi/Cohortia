Definition
Inheritance explained
A derived class acquires public and protected members of a base class. Use inheritance when the relationship is truly "is-a" so polymorphism and substitution make sense.
Why it matters
Centralizing shared behavior reduces duplication, eases maintenance, and clarifies intent when types share common responsibilities.
Common misconception
Inheritance is not a catch-all for reuse. If you only need to reuse implementation, composition may be a better choice to avoid tight coupling.
Concrete example
Animal holds name and age; Dog inherits them and adds breed and fetch(), reusing the Animal constructor and methods.
Key Takeaway

Use inheritance to represent a substitutable subtype that shares behavior and can be treated as the base type when needed.

Hierarchy
Visual: simple hierarchy
Animal (name, age) → Dog (breed, fetch) and Cat (mood, purr). Derived classes reuse Animal members and can override behavior.
