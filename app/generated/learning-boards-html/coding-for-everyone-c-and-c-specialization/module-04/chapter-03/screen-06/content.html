Override
Replacing base behavior with derived code
When a derived class implements a method with the same signature as a virtual base method, the derived implementation overrides the base for polymorphic calls.
Misconception
Not using override can turn a misspelled or mismatched signature into an accidental overload, hiding the intended polymorphism.
Key Takeaway

Declare override on derived methods to have the compiler confirm your intent and prevent subtle bugs.

Quick code snapshot
// Base
class Animal {
public:
  virtual void makeSound() const {
    // default
  }
};

// Derived override, safer with override specifier
class Dog : public Animal {
public:
  void makeSound() const override { // compiler checks this really overrides
    // Dog-specific sound
  }
};
Read the code to confirm signatures match. If they don't, override triggers a compile error, saving debugging time.
