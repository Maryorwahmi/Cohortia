Learning Objectives — Part 2
Polymorphism, virtual destructors, and avoiding slicing.
Bloom: Apply → Master
05
Define polymorphism
Explain "many forms": how different classes respond to the same call and why runtime decisions produce flexible code.
Mnemonic: One message, many responses
VERIFIED COMPETENCY MILESTONE
06
Implement virtual functions
Declare virtual in the base, override in derived, and use base pointers or references to enable late binding at runtime.
Mnemonic: Mark the base to allow later choices
VERIFIED COMPETENCY MILESTONE
07
Virtual destructor safety
Make the base destructor virtual so deleting derived objects through base pointers calls derived destructors first, preventing leaks.
Mnemonic: Virtual destructor = safe polymorphic deletion
VERIFIED COMPETENCY MILESTONE
08
Avoid slicing
Understand why assigning a derived object to a base object copies only the base part, and prefer pointers or references to preserve polymorphism.
Mnemonic: Use references or pointers, never object copies
