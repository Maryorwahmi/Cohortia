Safety check
Declare virtual destructors for polymorphic bases
A virtual destructor ensures derived destructors are invoked when deleting through a base pointer, preventing resource leaks.
Risk
Without virtual, derived cleanup is skipped when deleting via base pointers — a common source of leaks.
Key Takeaway

When a class is used polymorphically, make its destructor virtual to guarantee proper destruction order.

Code reminder
class Animal {
public:
  virtual ~Animal() { std::cout << "Animal destructor" << std::endl; }
};

class Dog : public Animal {
public:
  ~Dog() override { std::cout << "Dog destructor" << std::endl; }
};

// delete through Animal* calls Dog then Animal when destructor is virtual
Try removing virtual to see only the base destructor run — observe the difference in cleanup output during the lab.
