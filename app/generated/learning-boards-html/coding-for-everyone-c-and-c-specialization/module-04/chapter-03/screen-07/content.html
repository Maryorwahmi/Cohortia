Concept
Virtual functions and late binding
A virtual function lets the runtime choose the derived override when you call via a base pointer or reference. This is how different types respond to the same message.
Concrete example
Animal* a = &myDog; a->makeSound(); will call Dog's makeSound if it's virtual in Animal and overridden in Dog.
Common mistake
Forgetting to use pointers or references leads to slicing, so virtual dispatch won't occur when storing objects by value.
Quick trial
Animal* a = new Dog("Rex", 2, "Shepherd");
a->makeSound(); // Calls Dog's implementation because makeSound is virtual
delete a; // With virtual destructor, both Dog and Animal destructors run
Try this in the lab using a vector of Animal* to see multiple derived types respond through the same pointer type.
