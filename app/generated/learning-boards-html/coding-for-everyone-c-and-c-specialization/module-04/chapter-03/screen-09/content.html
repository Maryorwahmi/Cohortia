Pitfall
The slicing problem
Assigning a derived object to a base object by value copies only the base portion. The derived members and behavior are lost in the copy.
Practical consequence
Polymorphism disappears because the copied object is now a plain base object, not the original derived type.
Avoidance

Use base pointers or references, or smart pointers in containers, to preserve dynamic type and behavior.

Try this
Dog d("Buddy",3,"Retriever");
Animal a = d; // slicing: a now contains only Animal part
// a.makeSound() calls Animal's version — derived behavior is lost
Prefer: Animal* p = &d; p->makeSound(); to preserve polymorphism.
