Key Concepts
Three compact cards summarize what to remember.
Inheritance
Derived classes inherit public and protected members from a base, modeling an "is-a" relationship and enabling reuse.
Polymorphism & virtual
Virtual functions plus base pointers or references allow runtime selection of the correct override for each object.
Safety & pitfalls
Make base destructors virtual and avoid slicing by using pointers or references; prefer override to catch signature errors early.
Summary takeaway
Design hierarchies that reflect substitution, mark virtual methods where needed, and use pointers for polymorphism to keep behavior intact.
