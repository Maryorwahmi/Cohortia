Animal and Dog example
#include <iostream>
#include <string>

class Animal {
protected:
  std::string name;
  int age;
public:
  Animal(std::string n, int a) : name(n), age(a) {
    std::cout << "Animal constructor called for " << name << std::endl;
  }

  virtual void makeSound() const {
    std::cout << "Animal makes a sound." << std::endl;
  }

  virtual ~Animal() {
    std::cout << "Animal destructor called for " << name << std::endl;
  }
};

class Dog : public Animal {
private:
  std::string breed;
public:
  Dog(std::string n, int a, std::string b) : Animal(n, a), breed(b) {
    std::cout << "Dog constructor called for " << name << std::endl;
  }

  void makeSound() const override {
    std::cout << name << " barks: Woof! Woof!" << std::endl;
  }

  ~Dog() override {
    std::cout << "Dog destructor called for " << name << std::endl;
  }
};
Explanation
This code shows protected data, a virtual method, constructor chaining via the member initializer list, and a virtual destructor. Run-time polymorphism is visible when you call makeSound using an Animal pointer to a Dog object. Deleting dynamically allocated Dog objects through Animal* calls the Dog destructor first because the base destructor is virtual.
Guided experiment
  1. Create Animal and Dog instances and observe constructor messages.
  2. Use Animal* to point to Dog and call makeSound(). Note the Dog output.
  3. Delete a dynamically allocated Dog via Animal* and confirm two destructors run in order.
Key Takeaway

Use virtual where you expect polymorphic behavior and always declare virtual destructors for polymorphic bases.
