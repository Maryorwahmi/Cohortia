// Abstract Base Class: Shape
class Shape {
protected:
  std::string color;
public:
  Shape(std::string c) : color(c) { std::cout << "Shape constructor called for " << color << std::endl; }
  virtual double getArea() const = 0; // pure virtual
  virtual void displayColor() const { std::cout << "Color: " << color << std::endl; }
  virtual ~Shape() { std::cout << "Shape destructor called for " << color << std::endl; }
};

Lab checklist
  1. Implement Shape with pure virtual getArea and virtual destructor.
  2. Create Circle and Rectangle with proper constructors calling Shape(c).
  3. Use a vector of Shape* to store dynamic objects.
  4. Iterate and call getArea and displayColor to confirm polymorphism.
  5. Delete all objects to avoid leaks and verify destructor order.
Key Takeaway

The lab demonstrates abstract classes as contracts and how virtual functions let multiple shapes respond through a single interface.
