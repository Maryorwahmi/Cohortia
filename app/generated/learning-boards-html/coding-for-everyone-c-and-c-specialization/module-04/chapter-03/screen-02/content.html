Learning Objectives
Learn, understand, apply, and prepare to master inheritance and polymorphism.
Bloom: Learn → Understand → Apply → Master
01
Explain inheritance
Describe the "is-a" relationship and how a derived class acquires members from a base class. Explain why this reduces duplication and improves maintainability.
Mnemonic: Venn overlap — shared features in the middle
VERIFIED COMPETENCY MILESTONE
02
Implement single inheritance
Write a base class and a derived class that calls the base constructor, inherits protected members, and adds derived-specific behavior or data.
Mnemonic: Parent blueprint → Child specialization
VERIFIED COMPETENCY MILESTONE
03
Understand method overriding
Explain how derived classes provide their own implementation for methods inherited from the base class, and when to use the override specifier to catch mistakes.
Mnemonic: Replace the base voice with a specialized voice
VERIFIED COMPETENCY MILESTONE
04
Access modes
Name public, protected, and private inheritance and describe how they change member accessibility in derived classes and outside code.
Mnemonic: Visibility dial — who can see which members
VERIFIED COMPETENCY MILESTONE
