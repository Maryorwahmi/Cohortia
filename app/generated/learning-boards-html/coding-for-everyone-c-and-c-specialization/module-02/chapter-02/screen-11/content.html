Module 2 › Chapter 2.2 › Buffer Overflow
Why overflows happen
Common when copying or reading without checking destination size.
Consequences
Data corruption, crashes, and security exploits.
Prevention
  • Pass explicit sizes with arrays.
  • Use bounded functions for copying and formatting.
  • Validate indices before reading or writing.
Key Takeaway

Always check bounds and favor API variants that accept a maximum length to prevent buffer overflows.

Concrete scenario
A char buffer of size 10 receives user input without checking length. Writing more than 10 characters overwrites adjacent memory. Safer alternatives provide a length parameter so excess input is truncated or rejected.
Developer tip
During testing, print buffer addresses and sizes. Use tools and sanitizers to detect out-of-bounds access early.
