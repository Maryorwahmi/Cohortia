Contiguous memory explains addresses
Elements are placed next to each other so address arithmetic is predictable.
Conceptual memory slots (int numbers[5])
[0] value 85
addr 0x100
[1] value 92
addr 0x104
[2] value 78
addr 0x108
[3] value 95
addr 0x10C
[4] value 88
addr 0x110
Bullets
  • Contiguity means adjacent addresses equal element offsets times the element size.
  • Pointer arithmetic moves by element size automatically.
  • Compilers can optimize linear scans thanks to predictable layout.
Example
If numbers is at address 0x100 on a system with 4-byte ints, numbers + 3 will point to 0x10C, the start of numbers[3].
Key Takeaway

Think of arrays as numbered slots so address arithmetic becomes simple multiplication by element size.

Common misconception
An array name is not an assignable pointer variable. It will act like a pointer in many expressions, but you cannot reassign the array name to point elsewhere.
Why this helps
Predict memory accesses, avoid undefined behavior from invalid pointer arithmetic, and reason about multi-dimensional layouts which are also contiguous in row-major order.
