Decay: array name → pointer
The callee receives a pointer, not a copy of the array.
Pattern
Always pass length separately: int func(int *arr, int size).
Pitfall
sizeof(arr) inside a function gives pointer size. Do not use it to infer the number of elements.
Key Takeaway

Treat function parameters declared as arrays as pointers; include an explicit size parameter when needed.

Concrete example
int sumArray(int *arr_ptr, int count) {
  int sum = 0;
  for (int i = 0; i < count; i++) {
    sum += *(arr_ptr + i);
  }
  return sum;
}
Notice that sizeof(arr_ptr) would print the pointer size, not the array's total bytes.
