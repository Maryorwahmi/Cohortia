Module 2 › Chapter 2.2 › Indexing vs Dereference
Two equivalent forms
arr[i] and *(arr + i) produce the same effect: compute address then access value.
Readable form
Use arr[i] when clarity matters.
Explicit form
Use *(arr + i) when reasoning about address arithmetic or pointer traversal.
Quick example
/* conceptual */
int scores[] = {85,92,78};
// indexing
printf("%d at %p
", scores[1], (void*)&scores[1]);
// pointer arithmetic
printf("%d at %p
", *(scores + 1), (void*)(scores + 1));
Misconception check
Do not assume arr is a regular pointer you can assign to. The decay gives a pointer value in expressions but the array itself is not reassignable.
Try this

Convert a loop that uses arr[i] into one that advances a pointer and confirm the printed addresses match.
