#include <stdio.h>

int sumArray(int *arr_ptr, int count) {
  int sum = 0;
  for (int i = 0; i < count; i++) {
    sum += *(arr_ptr + i); // pointer arithmetic
  }
  return sum;
}

Hints & checks
  • Initialize max with the first element using dereference of arr_ptr.
  • Loop from 1 to size minus 1 and compare *(arr_ptr + i) to max_val.
  • Return a sentinel like -1 only when appropriate; otherwise document behavior for empty arrays.
Common mistake

Do not use sizeof inside findMax to determine number of elements — the parameter is a pointer and does not carry length information.

Key Takeaway

Passing arrays as pointers is efficient but requires explicit size handling to avoid undefined behavior.
