Pointer arithmetic scales by type size
The compiler interprets pointer addition as an increase by element size, not single bytes.
Step-by-step
  1. Start with pointer p pointing to element 0.
  2. Compute p + i: compiler multiplies i by sizeof(*p).
  3. Dereference *(p + i) to access element i.
Concrete example
If p points to address 0x200 and sizeof(int) is 4, then p + 3 points to 0x20C, the start of the fourth element.
Key Takeaway

Think in elements not bytes: pointer arithmetic moves in element-sized steps.

Important comparison
Indexing and pointer arithmetic are two faces of the same operation; choose the one that improves readability while keeping performance identical.
Check your understanding
If you have int *r = matrix[row]; then r + col points to the element at row and col. Does r + 1 move to the next column or next row? Remember the pointer points to the row's first element.
