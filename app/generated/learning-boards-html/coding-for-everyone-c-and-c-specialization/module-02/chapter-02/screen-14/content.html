Module 2 › Chapter 2.2 › Key Concepts
Array
Collection of same-typed elements stored contiguously.
Pointer Arithmetic
Pointer moves are scaled by element size, enabling address computation.
Array Decay
Array names convert to pointers to the first element in most expressions.
Summary Takeaway

Use a memory-first model: addresses, element steps, and explicit sizes protect correctness and security when working with arrays and pointers.
