Checklist for validating array code
1. Confirm allocation size
Use sizeof at the allocation site to compute element count.
2. Pass explicit length
Never assume a callee can determine the original array size.
3. Print addresses
Verify pointer arithmetic produces expected addresses.
4. Edge cases
Test empty arrays, single elements, and maximum lengths.
5. Use bounded APIs
Prefer functions that accept destination size to avoid overruns.
6. Instrument tests
Automate checks that detect out-of-bounds behavior early with tools and sanitizers.
Key Takeaway

A disciplined testing routine that prints addresses and verifies bounds is the most reliable defense against array-related bugs.
