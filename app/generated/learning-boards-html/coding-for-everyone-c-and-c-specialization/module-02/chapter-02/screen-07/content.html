Code
#include <stdio.h>

int main() {
  int scores[] = {85, 92, 78, 95, 88};
  int size = sizeof(scores) / sizeof(scores[0]);

  printf("Indexing:
");
  for (int i = 0; i < size; i++) {
    printf("scores[%d] = %d at address %p
", i, scores[i], (void*)&scores[i]);
  }

  printf("
Pointer arithmetic:
");
  for (int i = 0; i < size; i++) {
    printf("*(scores + %d) = %d at address %p
", i, *(scores + i), (void*)(scores + i));
  }

  return 0;
}
Explanation
  • sizeof in main returns total bytes because the array size is known at compile time.
  • Both loops produce the same values and addresses — proof of equivalence.
  • Assigning int *ptr = scores; copies the base address into a pointer variable.
Common mistake

Do not use sizeof on a parameter inside a function to determine number of elements — the parameter is a pointer there.

Key Takeaway

Print addresses to confirm behavior: address increments match element sizes and confirm pointer/index equivalence.
