Module 2 › Chapter 2.2 › Common Mistakes
Typical mistakes and fixes
Mistake: Reassigning array name
Fix: Use a pointer variable if you need a reassignable address.
Mistake: sizeof in parameter
Fix: Always pass length explicitly with the array pointer.
Mistake: off-by-one loops
Fix: Use clear loop bounds and test edge values like size-1 and zero.
Mistake: unchecked dereference
Fix: Validate size before using arr[0] or similar operations.
Pro tip

Write small helper functions that wrap common checks like bounds validation to reduce repeated errors in larger codebases.
