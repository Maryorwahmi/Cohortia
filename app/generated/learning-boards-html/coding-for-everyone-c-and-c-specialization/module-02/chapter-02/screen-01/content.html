Why this matters

Efficient array access underpins many core algorithms. Knowing how pointer arithmetic maps to element addresses helps you reason about performance, interoperability with C APIs, and prevents mistakes when memory is read or written incorrectly. The decay behavior explains common surprises when measuring sizes inside functions.

Example snapshot

int scores[] = {85, 92, 78, 95, 88};
Address view (conceptual)

Quick warning
Writing past the allocated element count corrupts nearby memory and can cause crashes or security issues.
Key Takeaway
Think in addresses and element steps: array names point to the first element and pointer arithmetic advances by element size.
