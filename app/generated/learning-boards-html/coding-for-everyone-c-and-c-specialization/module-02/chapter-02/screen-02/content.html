Learning Objectives
Skills you'll verify after practice
Learn → Understand → Apply → Master
01
Recognize contiguous arrays
Define arrays as adjacent memory locations and explain why addresses advance by element size.
VERIFIED COMPETENCY MILESTONE
02
Explain array decay
Show that an array name becomes a pointer to its first element in expressions and function calls.
VERIFIED COMPETENCY MILESTONE
03
Use pointer arithmetic
Access elements with both indexing and arithmetic, and predict addresses using element size.
VERIFIED COMPETENCY MILESTONE
04
Prevent buffer overflows
Identify out-of-bounds writes and prefer bounded operations when copying or formatting strings.
