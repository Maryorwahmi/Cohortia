Module 2 › Chapter 2.2 › Multidimensional Arrays
Row-major ordering
Rows are stored sequentially; each row's elements are contiguous.
Address formula
Address(matrix[row][col]) = base + ((row * columns) + col) * sizeof(element). Use this to compute offsets reliably.
Pointer form
matrix[row][col] equals *(*(matrix + row) + col). This emphasizes arrays of arrays with nested pointer arithmetic.
Key Takeaway

Treat multi-dimensional arrays as flattened buffers when computing addresses; row-major affects locality and traversal speed.

Example matrix layout (3 x 4)
Row 0: [m00][m01][m02][m03]
Row 1: [m10][m11][m12][m13]
Row 2: [m20][m21][m22][m23]
Performance note
Iterating row by row is cache friendly because consecutive accesses read adjacent memory locations.
Misconception
Do not assume column-major order; languages differ and assuming the wrong order leads to incorrect address calculations.
