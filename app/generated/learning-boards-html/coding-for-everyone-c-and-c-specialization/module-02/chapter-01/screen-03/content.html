Practice & safety checks

These micro-tasks focus on observable, testable behaviors and safety patterns.

Task: Change a value via pointer
Declare an int, make a pointer to it, use the pointer to set a new value, compile and run to confirm.
VERIFIED COMPETENCY MILESTONE
Task: Write a swap function
Write a function that accepts two int pointers and swaps the values at their addresses. Test with sample numbers.
VERIFIED COMPETENCY MILESTONE
Task: Safety check
Initialize pointers to NULL when you cannot assign a valid address. After freeing dynamic memory, set the pointer to NULL to avoid dangling references.
VERIFIED COMPETENCY MILESTONE
