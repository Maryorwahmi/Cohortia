Code Walkthrough › Swap example explained

Source code

#include <stdio.h>

void swap(int *pa, int *pb) {
  int temp = *pa;  // store value at pa
  *pa = *pb;       // copy value at pb into pa
  *pb = temp;      // write stored value into pb
}

int main() {
  int num1 = 5;
  int num2 = 10;

  printf("Before swap: num1 = %d, num2 = %d
", num1, num2);
  swap(&num1, &num2); // pass addresses
  printf("After swap: num1 = %d, num2 = %d
", num1, num2);
  return 0;
}

Explanation & walk-through

  • swap receives pointers pa and pb that point to the caller's integers.
  • *pa and *pb access the actual values stored at those addresses.
  • The temporary stores one value so the second can overwrite the first, then the temp restores the second value.
Concrete example

Before: num1 is 5, num2 is 10. After swap with addresses, num1 becomes 10 and num2 becomes 5 because the function wrote directly into the caller's memory.

Misconception check: passing &num1 and &num2 is not copying values. It passes addresses. The function changes original variables by dereferencing those addresses.
