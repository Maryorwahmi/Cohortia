Common Mistakes › Debugging pointers

Frequent errors

  • Dereferencing uninitialized pointers.
  • Accessing memory after it has been freed.
  • Performing pointer arithmetic beyond array bounds.
  • Returning addresses of local variables from functions.

Debugging checklist

Print addresses and pointer values. Confirm pointers point to the expected variables. Use a debugger to inspect memory at those addresses. Add NULL checks before dereference. Audit functions for ownership and lifetime of returned pointers.
Pro tip

Write small tests that exercise pointer paths: assign, dereference, free, and check for invalid access. Reproduce crashes in a debugger to inspect the failing pointer.
