Operator › Address-of and dereference

How & works

Address-of returns the memory address of a variable. You store that address in a pointer whose type matches the variable type.

Example
int x = 5; int *p = &x; // p now holds x's address
Dereference
Use *p to access or change the value at the address stored by p. Writing *p = 9 sets x to 9 when p points to x.

Common pitfalls

  • Do not dereference pointers that are NULL or uninitialized.
  • Remember the asterisk in a declaration marks type, not dereference.
  • Parentheses affect combined expressions; be explicit when mixing & and *.
Pro tip

Check for NULL before dereferencing when a pointer may be unset or returned from a function that can fail.
