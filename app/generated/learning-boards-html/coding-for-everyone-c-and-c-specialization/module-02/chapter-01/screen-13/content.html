Best Practices › Pointer style and safety

Naming & initialization

Use clear pointer names and initialize immediately. Example: int *ptrCount = NULL; or int *ptr = &value; These patterns communicate intent and avoid wild pointers.
Example naming
int *pNode; struct Node *head; int *ptrIndex;

Ownership & documentation

Document which function allocates memory and which frees it. When a function may return NULL, say so. Clear contracts prevent leaks and crashes.
Checklist

Name pointers, initialize, check for NULL, avoid returning stack addresses, document allocation responsibility, and set to NULL after free.
