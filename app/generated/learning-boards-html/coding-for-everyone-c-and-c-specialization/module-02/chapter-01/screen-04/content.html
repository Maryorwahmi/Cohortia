Core Concept › What is a pointer?

Pointer definition

A pointer stores the memory address of a variable. It does not contain the variable's value itself. This indirection enables functions and structures to refer to original data without copying it.

Metaphor — Mailbox
Variables are mailboxes with values. Pointers hold mailbox numbers. Dereferencing opens the referenced mailbox.
Common misconception
int *p does not make p an int. It declares p as a pointer to an int. Confusing the two leads to type errors and incorrect dereferences.
Why this matters
Pointers let functions modify caller data and avoid copying large objects. They are the foundation of dynamic structures and efficient APIs in C.
Annotated example
#include <stdio.h>

int main() {
  int value = 7;    // a box containing 7
  int *p = &value;  // p stores the address of that box

  printf("value = %d
", value);
  printf("value via pointer = %d
", *p);
  return 0;
}
Example explained: &value yields the address of value. Assigning it to p makes p point to that address. Using *p accesses the value at that address.
Key Takeaway

Think of pointers as addresses. Use & to get an address and * to open the box at that address.
