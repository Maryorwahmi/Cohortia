The scaling idea

Adding an integer to a pointer moves it by that many elements, not bytes. The step size equals sizeof(the pointed type).

Example
If ptr is int*, then ptr + 1 points to the next integer in memory. If ints are four bytes, ptr + 1 increments the address by four bytes.

Arrays and traversal

Pointer arithmetic is a natural fit for array traversal. A pointer initially points to the array's first element and increments move through the elements predictably.

Concrete snippet

Given int arr[3]; int *p = arr; p++ moves from arr[0] to arr[1]. This is independent of the byte size of int on the system.

Misconception: pointer arithmetic always adds one byte. It does not. It scales by the element size, which makes pointer arithmetic type-aware and powerful for element traversal.
