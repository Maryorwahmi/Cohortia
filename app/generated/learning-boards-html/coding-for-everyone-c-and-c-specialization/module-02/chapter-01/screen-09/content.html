Definition › NULL and dangling pointers

What is NULL?

NULL indicates a pointer does not point to any valid memory. Set pointers to NULL until you assign a valid address, and use checks to avoid dereference of NULL pointers.

Example
int *p = NULL; if (p != NULL) { use *p } else { handle empty case }

Dangling pointers

A dangling pointer points to memory that has been deallocated or went out of scope. Accessing it is undefined behavior and often crashes programs.

Best practice

After freeing memory, set the pointer to NULL. Document APIs that return pointers and whether they may return NULL.

Misconception: a pointer still holding a numeric address means the memory is valid. It does not. Always understand who owns memory and when it is freed.
