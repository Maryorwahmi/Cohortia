Learning Objectives

We will practice four core pointer skills and confirm competency with short, focused tasks.

01
Define a pointer
Explain that a pointer stores an address and how that differs from a regular variable.
Mnemonic: Mailbox map
VERIFIED COMPETENCY MILESTONE
02
Declare & initialize
Write declarations like int *p; initialize to a valid address or NULL to avoid wild pointers.
Mnemonic: Star means pointer
VERIFIED COMPETENCY MILESTONE
03
Use & and *
Apply address-of to get a variable's address and dereference to inspect or change its value.
Mnemonic: Reach and open
VERIFIED COMPETENCY MILESTONE
04
Pointer arithmetic
Understand scaling when adding or subtracting so you traverse arrays safely.
Mnemonic: Steps scaled by type size
VERIFIED COMPETENCY MILESTONE
