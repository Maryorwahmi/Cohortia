Starter code

#include <stdio.h>

int main() {
  int myNumber = 42;        // 1. Declare and initialize
  int *ptrToNumber;         // 2. Declare pointer

  ptrToNumber = &myNumber;  // 3. Assign address

  printf("Original value: %d
", myNumber);
  printf("Address of myNumber: %p
", (void*)&myNumber);
  printf("Value in ptrToNumber: %p
", (void*)ptrToNumber);
  printf("Value pointed to: %d
", *ptrToNumber);

  *ptrToNumber = 99;        // 8. Modify via pointer

  printf("After modification: %d
", myNumber);
  printf("Via pointer: %d
", *ptrToNumber);
  return 0;
}

Guided checks

  1. Did the printed address match the pointer's stored value? It should.
  2. Did dereferencing print the original value before modification?
  3. After assigning through the pointer, did myNumber change to ninety-nine?
Common mistake

Printing a pointer with %d instead of a pointer format can show incorrect output. Use the address print specifier for pointer values.
