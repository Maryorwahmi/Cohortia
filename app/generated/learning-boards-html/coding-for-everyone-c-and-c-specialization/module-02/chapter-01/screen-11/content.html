Comparison › Pointers vs. values

When to use values

  • Small types where copying is cheap, like ints and chars.
  • When you want no side effects and simpler reasoning about state.
  • When ownership and lifetime management would be complex with pointers.

When to use pointers

  • Large structures or buffers where copying is expensive.
  • When a function must modify the caller's variables.
  • To build linked data structures that use addresses to connect nodes.
Misconception: pointers always improve performance. They can, but they also increase complexity. Balance performance needs against safety and clarity.
