Key Concepts › Quick reference
Address vs Value
Remember the difference; pointers hold addresses, not the values themselves.
Initialize & NULL
Initialize pointers and use NULL to indicate an empty pointer.
Type-aware arithmetic
Pointer increments move by the pointed type's size. Check bounds when iterating arrays.
Final takeaway

Practice the patterns: declare, initialize, dereference, and set to NULL after free. These steps make pointer code reliable and predictable.
