Definition › Declaring and initializing pointers

Declaration patterns

Write the pointed type, then an asterisk, then the name. Prefer one declaration per line to avoid confusion about which variables are pointers.
Good
int *p; // p is a pointer to int
Watch out
int *p, q; // p is a pointer, q is a plain int
Mnemonic: attach the star to the name in your head but write declarations clearly, one per line when possible.

Initialization choices

Always give a pointer a safe initial value: the address of an existing variable, the return from an allocator when appropriate, or NULL if it has no valid address yet.
int value = 1;
int *p = &value;   // valid
int *q = NULL;    // explicitly empty
int *r;           // uninitialized — avoid
Common mistake

Dereferencing an uninitialized pointer can crash your program. Initialize to NULL or a valid address immediately.
