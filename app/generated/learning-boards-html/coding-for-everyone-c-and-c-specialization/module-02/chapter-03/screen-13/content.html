Tests will validate that you performed null checks after allocation and used realloc into a temporary pointer.
Remember to free on all return paths, including error cases, to avoid leaks in the lab tests.

Concrete example

If initial size is 3, allocate space for 3 integers, read three numbers, then realloc to new size as requested.
If realloc fails, do not free original array here—instead report the error and free at the end before returning.
