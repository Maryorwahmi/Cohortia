Module 3 › Chapter 2.3 › calloc vs malloc

At a glance

calloc(count, size) — allocates and zeroes all bytes.
malloc(size) — allocates raw bytes with indeterminate contents.
Use calloc when you need a clean zeroed block for predictable initialization.

Example

int *arr_zero = (int *) calloc(num_elements, sizeof(int));
if (arr_zero == NULL) {
  printf("Memory allocation failed!
");
  return 1;
}
// arr_zero points to num_elements integers, all set to zero
calloc sets each byte to zero; this often results in numeric zeros for integers and predictable initial state for many structures.
Do not assume pointer bit patterns beyond using null checks; zeroed bytes may or may not correspond to a valid null pointer representation on unusual platforms.
Practical tip: choose calloc to avoid manual zeroing loops when you need all bytes cleared.
