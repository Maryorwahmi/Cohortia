Module 3 › Chapter 2.3 › Dangling Pointers & Double free

Definitions

Dangling pointer: holds an address whose block has been freed; dereferencing it is undefined.
Double free: freeing the same block twice, which can corrupt allocator state and crash.
Defensive rule: free(ptr); ptr = NULL; and document ownership so only one party frees each allocation.

Contrast

Double free often produces immediate, reproducible crashes.
Dangling pointer bugs are often intermittent and harder to trace because memory may have been reallocated for other uses.
Key Takeaway

Nulling pointers after free and clear ownership rules prevent both dangling pointers and double frees.
