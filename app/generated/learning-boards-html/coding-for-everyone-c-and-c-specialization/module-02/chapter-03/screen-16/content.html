Module 3 › Chapter 2.3 › Key Concepts — Quick Reference
Size safely
Use sizeof on the element type when computing allocation sizes to avoid off-bytes mistakes.
realloc safely
Assign realloc's return to a temp pointer and only update the original pointer on success.
Free & null
Free memory when done and set pointers to null to avoid dangling references and double frees.
Final takeaway
Small, consistent habits in allocation and deallocation prevent the majority of dynamic memory bugs.
