API Walkthrough

Using malloc safely

#include <stdlib.h>

int *arr;
int num_elements = 5;
arr = (int *) malloc(num_elements * sizeof(int));
if (arr == NULL) {
  printf("Memory allocation failed!
");
  return 1;
}
// arr now points to uninitialized memory for 5 integers
Compute the allocation size as elements times sizeof(element). Casting the returned pointer is common practice, though in C it's not strictly required.
Always check for null and handle failure paths to avoid dereferencing an invalid pointer.
Initialize memory before use because malloc does not zero the contents.
Common pitfalls
Incorrect size multiplication causes under-allocation and potential overflow.
Using memory before initialization can read garbage values and produce incorrect behavior.
Misusing a null pointer after allocation failure will crash the program.
Key Takeaway

Always compute sizes carefully, check for null, and initialize after malloc before use.
