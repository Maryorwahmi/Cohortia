Hierarchy of defensive patterns

  1. Check every allocation result for null and handle errors cleanly.
  2. Use temporary pointer for realloc and only replace original on success.
  3. Free memory once and then set pointer to null to avoid dangling and double free.
  4. Document ownership and prefer localized ownership where feasible.
  5. Write tests that exercise both success and failure paths for allocations.

Quick checklist

Size computed with sizeof(element).
realloc assigned to temp pointer then checked.
Free in all early exit and error branches.
