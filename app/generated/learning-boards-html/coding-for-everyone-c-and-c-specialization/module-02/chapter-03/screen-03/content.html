Module 3 › Chapter 2.3 › Learning Objectives

Lab Skills to Practice

  • Prompting the user and allocating an integer array dynamically.
  • Filling and printing the array contents and verifying correctness.
  • Resizing the array safely using realloc and a temporary pointer.
  • Freeing memory and nulling pointers to prevent dangling references.

Assessment Checks

Check 1: All allocations are checked for null.
Check 2: realloc assigned to temporary before updating original pointer.
Check 3: Memory freed and pointer set to null at program end.
