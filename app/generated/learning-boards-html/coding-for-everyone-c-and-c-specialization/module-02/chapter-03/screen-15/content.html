Module 3 › Chapter 2.3 › Key Concepts
Heap vs Stack
Heap for dynamic, long-lived storage; stack for short-lived locals.
Check allocation returns
Always verify that malloc, calloc, and realloc did not return null before use.
Free and null
Free memory when done and set pointers to null to prevent dangling and double frees.
Summary
Follow these rules consistently and your code will be more reliable, easier to test, and easier to maintain.
