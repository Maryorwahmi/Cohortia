Module 3 › Chapter 2.3 › realloc — resizing blocks safely
Process Flow

Safe realloc pattern

1. Call realloc with the original pointer and new size into a temporary pointer.
2. If the temporary pointer is null, handle the error; the original pointer still points to the valid old block.
3. If temporary is non-null, assign the original pointer to the temporary and continue.
int *temp = (int *) realloc(arr, 10 * sizeof(int));
if (temp == NULL) {
  printf("Memory reallocation failed!
");
  // arr still valid here
} else {
  arr = temp;
}
Notes & pitfalls
realloc may move memory; always use returned pointer for subsequent access.
Do not free the original block after a successful realloc; realloc frees it when it moves data.
Never overwrite the original pointer before checking realloc's return; that is a leak risk.
Key Takeaway

Treat realloc as a potentially moving operation and use a temporary pointer to avoid losing the original block on failure.
