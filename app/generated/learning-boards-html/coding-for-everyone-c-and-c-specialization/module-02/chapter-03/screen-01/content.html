Dynamic Memory Allocation

Learn how C programs request memory from the heap, resize blocks, and return memory safely to the system. This chapter emphasizes correct patterns to avoid leaks and undefined behavior.

In this lesson: malloc, calloc, realloc, free and safe patterns for each.
Why it matters: build flexible arrays and data structures that adapt at runtime.
Outcome: write allocation-safe code that checks for null and avoids leaks.
Heap vs Stack Quick Visual
A compact reminder of roles and lifetime
Stack
Used for local variables and function frames. Managed automatically; size fixed at compile time. Good for small, short-lived data.
Heap
Used for dynamic allocations that the programmer controls. Flexible size at runtime and requires explicit free calls to avoid leaks.
