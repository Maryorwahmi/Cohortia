Module 3 › Chapter 2.3 › Lab walkthrough

Step-by-step

  1. Prompt for initial size and call malloc with size * sizeof(int); check for null.
  2. Read integers into the array and print them to verify the data was stored correctly.
  3. Prompt for new size and call realloc into a temporary pointer; check for null before updating original pointer.
  4. If realloc succeeds, read extra integers; if it fails, handle error without freeing the original pointer unexpectedly.
  5. Print all integers and finally call free and set pointer to null.

Checks and tests

Test: program frees memory on every return path.
Test: realloc uses temporary pointer and original remains valid on failure.
Test: inputs and outputs match expected counts after resizing.
