Module 6 › Chapter 5.3 › 8-point Algorithm
Step-by-step
1. Normalize
Translate and scale points to improve numerical stability.
2. Build A
Each correspondence yields a linear row in A so that Af = 0.
3. SVD solution
The smallest singular vector of A gives the estimated f reshaped into a 3×3 matrix.
4. Enforce rank‑2
Set the smallest singular value of the estimate to zero and recompose to obtain a valid F or E.
Wrap the estimation inside RANSAC to handle mismatches. Denormalize the result if you began in normalized coordinates.
Concrete example
Given 8 ORB matches, normalize coordinates, form A, run SVD, reshape to E, force rank‑2, and verify p2^T E p1 ≈ 0 for inliers.
Common mistake

Skipping normalization yields unstable results on real images. Always precondition the points before solving.
