Module 6 › Chapter 5.3 › Decompose E
How decomposition works
Compute the SVD of E, construct candidate rotations and translations from the canonical form, and remember that t is recoverable only up to a scale factor.
Practical disambiguation
Triangulate points for each candidate pair. The valid pair is the one where reconstructed points lie in front of both cameras (positive depth). This geometric check resolves the four algebraic solutions.
Example execution
  1. Enforce rank‑2 on E and compute SVD(E).
  2. Build four (R, t) candidates using sign permutations.
  3. Triangulate matches and count positive‑depth points for each candidate.
  4. Select the candidate with the most points in front of both cameras.
Key Takeaway

Algebra gives four possibilities; geometry (depth test) selects the physically correct camera pose.
