Module 5 › Chapter 5.1 › Key Concepts
Pinhole projection
u = f X/Z + cx; v = f Y/Z + cy — size scales inversely with depth.
Intrinsic matrix K
K = [f 0 cx; 0 f cy; 0 0 1] groups internal camera properties.
Extrinsics [R|t]
R and t transform world coordinates into the camera frame before projection.
Summary

Combine K and [R|t] and normalize homogeneous coordinates to project world points for robotic perception. Validate with both numeric error and visual checks.
