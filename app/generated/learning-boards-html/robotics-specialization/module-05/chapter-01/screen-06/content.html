Module 5 › Chapter 5.1 › Intrinsic Matrix
Matrix form
K = [ f  0  cx
      0  f  cy
      0  0  1 ]
K maps camera coordinates to pixel coordinates when used with homogeneous vectors, making projection linear in the homogeneous representation.
Concrete example
With f=500, cx=320, cy=240, multiply K by [X, Y, Z]^T and scale by 1/Z to retrieve u,v in pixels for validation.
Notes and pitfalls
If pixels are not square, K includes pixel aspect ratio; if the sensor is skewed there is an extra off-diagonal term. Most algorithms assume the simple form, so inspect your camera metadata.
Why this matters
K is the interface between raw pixel readings and metric camera geometry. Accurate K is required for mapping image measurements into metric space.
