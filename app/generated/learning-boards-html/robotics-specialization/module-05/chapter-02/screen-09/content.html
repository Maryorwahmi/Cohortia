Module 5 › Chapter 5.2 › Matching & Ratio Test
Matching steps
  1. Compute descriptor distances between sets of features.
  2. Find nearest and second-nearest neighbors for each descriptor.
  3. Apply ratio test: accept match if distance1 / distance2 < threshold (0.7–0.8).
  4. Collect accepted matches and pass to geometric verification like RANSAC.
Example
In a scene with repeating windows, nearest neighbor matching yields many false pairs. The ratio test removes matches where the top two candidates are similarly close.
Tradeoffs
Tighter thresholds improve precision but reduce recall. For downstream pose estimation you often prefer precision because a few correct inliers are enough for RANSAC to find a good model.
Key Takeaway

The ratio test rejects ambiguous matches, improving the quality of correspondences before geometric filtering.
