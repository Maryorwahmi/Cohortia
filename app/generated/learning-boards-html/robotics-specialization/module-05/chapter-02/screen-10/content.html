RANSAC steps
  1. Randomly select a minimal subset of matches.
  2. Fit the geometric model (affine, homography, fundamental matrix).
  3. Count inliers whose reprojection error is below a threshold.
  4. Repeat and keep the model with the largest inlier set; refine using all inliers.
Example
Estimate an affine transform with MaxNumTrials 2000. Begin with matched points, run RANSAC, and visualize inliers only to see stable correspondences.
Practical tips
- Set an inlier threshold appropriate for image noise and expected reprojection error.
- Increase trials if the inlier ratio is low; RANSAC needs enough samples to find a good set.
- After RANSAC, refine the model with all inliers to improve accuracy.
Key Takeaway

RANSAC is essential for rejecting false matches and recovering accurate geometric transforms in noisy real-world data.
