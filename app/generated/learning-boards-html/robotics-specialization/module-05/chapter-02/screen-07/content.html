Module 5 › Chapter 5.2 › SIFT Descriptor
Construction steps
  1. Align a 16×16 patch to keypoint orientation.
  2. Split into sixteen 4×4 subregions.
  3. Compute 8-bin gradient orientation histograms per subregion.
  4. Concatenate histograms → 128-D vector, normalize and clamp.
Why gradients?
Gradients capture edge structure and are less affected by uniform illumination changes than raw pixels.
Concrete example
A textured patch with a dominant diagonal edge will produce strong responses in bins near that edge orientation across the four subregions that contain the edge. These responses form a recognizable pattern when concatenated.
Key Takeaway

By summarizing gradient directions and normalizing, SIFT descriptors provide a stable, distinctive signature for matching.
