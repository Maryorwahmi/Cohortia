Module 5 › Chapter 5.2 › Failures & Remedies
Failure modes
  • Low-texture scenes → too few keypoints.
  • Repetitive patterns → ambiguous matches.
  • Large viewpoint/scale changes → descriptor mismatch.
  • Motion blur or exposure problems → degraded gradients.
Remedies
  • Change detector or include multi-scale features for low texture.
  • Tune ratio threshold and add geometric consistency checks for repetitive patterns.
  • Prefer SIFT-like detectors when viewpoint variation is large.
  • Improve image acquisition or use cameras with better exposure control.
Key Takeaway

Diagnose the root cause of matching failure and apply the corresponding mitigation before blaming the algorithm itself.
