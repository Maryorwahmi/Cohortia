Label frames
Always carry the frame name with vectors to avoid mixing frames.
Use homogeneous matrices
Combine rotation and translation into a single 4×4 transform for chaining.
Validate numerically
Check R*R'≈I and det(R)=1 to catch numerical or modeling errors.
Final thought

Make these checks part of your code pipeline so frame errors are caught before they reach hardware.
