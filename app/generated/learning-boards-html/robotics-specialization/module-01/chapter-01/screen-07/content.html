Module 1 › Chapter 1.1 › 3D Rotation Matrices
Axis rotations
Rz(θ) = [ cosθ  -sinθ  0;
           sinθ   cosθ  0;
             0      0   1 ]

% Rx and Ry are similar but rotate about x and y axes
Compose these matrices to build complex 3D orientations.
Order matters
Example: compute R = Ry(α) * Rx(β) and compare to R' = Rx(β) * Ry(α). The two results differ. This is non-commutativity of 3D rotations.
Common mistake
Applying rotations in the wrong order leads to unexpected final orientations. Use explicit conventions like Z-Y-X to avoid ambiguity.
