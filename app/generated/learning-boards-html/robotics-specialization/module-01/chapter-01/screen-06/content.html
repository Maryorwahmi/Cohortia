Module 1 › Chapter 1.1 › 2D Rotation Matrix
Rotation formula
R(θ) = [ cos(θ)  -sin(θ);
           sin(θ)   cos(θ) ]

p_rot = R(θ) * p
Check orthogonality: R * R' ≈ I
Concrete example
Rotate p = [1; 0] by θ = 30°. cos(30°)=0.866, sin(30°)=0.5. The rotated vector becomes approximately [0.866; 0.5].
Key Takeaway
In 2D rotations preserve magnitude and are inverted by transpose; use this for quick checks.
