What is a vector?
A vector is an ordered list of numbers that represents either a position or a direction relative to a coordinate frame.
Example position vector
p = [x; y; z]  % column vector in a frame
Mnemonic: Always attach a frame label, e.g., p_camera or p_world.
Coordinate frame

A frame defines axis directions and an origin. Measurements without a frame are ambiguous. Transformations map vectors from one frame to another.

Concrete scenario
A camera reports p_camera = [0.5;0.3;2.0]. To plan movement in world coordinates, you must transform that vector into the world frame using a homogeneous transform.
Key Takeaway
Label frames and never mix vectors from different frames without an explicit transform.
