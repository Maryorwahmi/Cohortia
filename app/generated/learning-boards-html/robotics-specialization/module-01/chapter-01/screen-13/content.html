Module 1 › Chapter 1.1 › MATLAB Example
MATLAB code
% Define a rotation of 30 degrees around the z-axis
theta = deg2rad(30);
Rz = [cos(theta) -sin(theta) 0;
      sin(theta)  cos(theta) 0;
      0           0          1];

% Define a translation vector
t = [1; 2; 3];

% Construct the homogeneous transformation matrix
T = [Rz, t; 0, 0, 0, 1];

% Transform a point from the body frame to the world frame
p_body = [0.5; 0.2; 1.0; 1];
p_world = T * p_body;
Remember to use homogeneous coordinates when applying T. Validate by computing the inverse via R' and -R'*p and applying it to p_world to recover p_body.
Tip
Keep tests that verify round-trips and orthogonality to catch numerical mistakes early.
