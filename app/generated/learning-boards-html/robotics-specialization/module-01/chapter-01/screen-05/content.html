What a matrix does

A matrix maps input vectors to output vectors by a fixed linear rule. For rotations, that rule preserves vector lengths and angles.

Property
If R is a rotation, then R * R' = I and det(R) = 1.
Example: rotation applied
% rotate point p by R:
p_rotated = R * p;
Misconception: translations are not linear. To include translations use homogeneous coordinates and a 4×4 matrix.
Why it matters
Using matrices makes batch operations and chaining efficient, which is essential for real-time robot calculations.
