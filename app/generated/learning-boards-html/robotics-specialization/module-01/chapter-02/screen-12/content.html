Pendulum with ode45
Define the dynamics as dx/dt = [v; -(g/L) sin(theta)] and call ode45 for an adaptive solution.
% Define the dynamics of a simple pendulum
% dx/dt = [v; -(g/L)*sin(theta)]
g = 9.81;
L = 1.0;

f = @(t, x) [x(2); -(g/L)*sin(x(1))];

x0 = [0.1; 0];

[t, x] = ode45(f, [0 10], x0);

plot(t, x(:,1));
xlabel('Time (s)');
ylabel('Angle (rad)');
Solver note
ode45 controls error automatically — ideal for many nonlinear robot models, but check solver selection for stiff dynamics.
Key Takeaway

Use ode45 as a reliable, adaptive integrator for non-stiff robotics problems and validate results against fixed-step methods.

Practical tip
When measuring performance, compare solver timings, step counts, and error behavior. Plot state trajectories from different solvers on the same axes for clarity.
