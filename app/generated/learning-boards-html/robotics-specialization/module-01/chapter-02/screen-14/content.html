Module 1 › Chapter 1.2 › Key Concepts
Vector derivatives
p(t), v=dp/dt, a=d2p/dt2 map directly to sensors and control signals.
Skew-symmetric Ω
Ω encodes ω and satisfies dR/dt = RΩ for correct orientation propagation.
First-order ODEs
Write dynamics as dx/dt = f(x,u,t) so solvers like ode45 can be applied directly.
Summary: combine correct mathematical form with thoughtful numerical choice to get simulations you can trust.
