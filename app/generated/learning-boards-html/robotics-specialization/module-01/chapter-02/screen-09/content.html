Euler integration
x_{n+1} = x_n + dt * f(x_n). Easy to implement, but sensitive to dt and stability.
Example
dx/dt = -2x, x(0)=5. Euler with dt=0.1 will approximate decay but may show noticeable error compared to the exact x(t)=5 e^{-2t}.
Stability warning
For oscillatory or stiff systems, Euler can become unstable unless dt is very small; this is not always practical for real-time simulation.
Key Takeaway

Euler is a baseline method: learn it, but expect to upgrade to RK4 or adaptive solvers for accurate robotics simulations.
