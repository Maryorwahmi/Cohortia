RK4 step
Four intermediate slope evaluations produce a weighted update that greatly reduces truncation error.
Pseudocode
k1 = f(x, u)
k2 = f(x + dt*k1/2, u)
k3 = f(x + dt*k2/2, u)
k4 = f(x + dt*k3, u)

x_next = x + dt*(k1 + 2*k2 + 2*k3 + k4)/6
Practical note
RK4 is efficient for fixed-step scenarios; for variable-step and automatic error control prefer adaptive solvers like ode45.
Key Takeaway

RK4 balances cost and accuracy and is a practical fixed-step integrator for many robotics simulations.

Concrete example
Compare Euler and RK4 on the damped oscillator: RK4 with dt=0.1 typically tracks the ode45 reference much closer than Euler with dt=0.01.
