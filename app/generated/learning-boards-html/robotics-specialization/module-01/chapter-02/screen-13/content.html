Damped oscillator comparison
Run Euler with dt=0.1 and dt=0.01, and run ode45. Plot position over time to compare behaviors.
Parameters
m = 1 kg, c = 0.5, k = 2, F(t)=0, x(0)=1, v(0)=0. Observe how dt affects Euler stability.
Result expectation
Euler dt=0.1 may diverge or be noticeably inaccurate. Euler dt=0.01 should be closer. ode45 should provide the best reference for non-stiff dynamics.
Key Takeaway

Empirical comparison of solvers is essential: tune dt and solver choice based on accuracy needs and computational budget.

Implementation hints
  • Record time and position arrays for each method.
  • Plot with distinct colors and include legend for comparison.
  • Check energy or amplitude decay to assess physical realism.
Reflection prompt
