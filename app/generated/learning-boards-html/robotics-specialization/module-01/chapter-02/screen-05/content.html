Module 1 › Chapter 1.2 › Rotation Rates
Skew-symmetric Ω and dR/dt
dR/dt = R · Ω where Ω encodes angular velocity components and defines how orientation evolves.
Matrix form
Ω = [ 0   -ωz  ωy
      ωz   0   -ωx
     -ωy  ωx    0 ]
Analogy
Think of Ω as the generator of infinitesimal rotations; multiplying R by Ω gives the instantaneous change in orientation.
Common mistake
Integrating Euler angles separately ignores non-commutativity and can produce incorrect orientation over time.
Key Takeaway

Use RΩ propagation or quaternion integration to reliably update orientation from angular velocity measurements.

Concrete example
Rotation about z with ω=[0,0,ωz] yields Ω with entries ±ωz. Then dR/dt = RΩ simplifies to the planar rotation derivative used for yaw-only motion.
Try this
Integrate a small time step using R_next = R + dt * RΩ and re-orthogonalize R periodically to avoid numerical drift. Compare to quaternion-based integration.
