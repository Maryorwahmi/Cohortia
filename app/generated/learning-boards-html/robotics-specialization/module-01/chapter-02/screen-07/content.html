Module 1 › Chapter 1.2 › ODEs
dx/dt = f(x, u, t)
State-based representation is the standard form for describing robot dynamics and feeding into solvers.
Pendulum example
x = [θ; ω]
dx/dt = [ ω
          -(g/L) * sin(θ) ]
Conversion trick
Convert second-order equations to first-order by augmenting state with velocities so solvers can proceed.
Key Takeaway

Formulate dynamics as first-order ODEs to apply numerical integration consistently across systems.

State & input
x contains mechanical states, u contains forces or torques. Time-varying inputs or external forces appear explicitly in f(x,u,t).
