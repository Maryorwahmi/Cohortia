Convert to first-order
Define x1 = position, x2 = velocity. Then write dx/dt = [x2; (1/m)(F - c x2 - k x1)].
Worked numbers
m = 1, c = 0.5, k = 2, F = 0
x1(0)=1, x2(0)=0

dx1/dt = x2
dx2/dt = -0.5*x2 - 2*x1
Why this matters
Solvers operate on first-order systems; controllers observe and command states separately, so position and velocity must be explicit.
Key Takeaway

State augmentation makes dynamics solver-ready and clarifies which state each control action affects.

Analogy
Think of splitting motion into position tracks and velocity tracks; each evolves according to equations that reference both tracks.
