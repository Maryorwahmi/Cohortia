rk4_step function
Four intermediate evaluations form a stable, higher-order update for non-stiff problems.
function x_next = rk4_step(f, x, u, dt)
    k1 = f(x, u);
    k2 = f(x + dt*k1/2, u);
    k3 = f(x + dt*k2/2, u);
    k4 = f(x + dt*k3, u);
    x_next = x + dt*(k1 + 2*k2 + 2*k3 + k4)/6;
end
Notes
If input u changes with time, call f with appropriate time-shifted u for k2 and k3 evaluations. For stiff systems consider implicit alternatives.
Concrete example
Use this step to advance the damped oscillator states on a fixed grid, then plot results against ode45 to visually inspect accuracy.
