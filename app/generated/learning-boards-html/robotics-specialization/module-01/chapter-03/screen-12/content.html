GPS vs Wheel Odometry

Combine two independent Gaussian estimates to get a more precise position.

Given
GPS: μ=50, σ=5. Odometry: μ=48, σ=2. Assume independence and Gaussian noise.
Result
Fused μ_post ≈ 48.28 m, σ_post ≈ 1.86 m — more accurate and more confident than either sensor alone.
Key Takeaway

Fusing independent Gaussian estimates reduces overall uncertainty and gives a more reliable state estimate.

Calculation
% Numeric example
mu_gps = 50; sigma_gps = 5;
mu_odo = 48; sigma_odo = 2;
sigma_gps2 = sigma_gps^2; sigma_odo2 = sigma_odo^2;
mu_post = (sigma_odo2*mu_gps + sigma_gps2*mu_odo) / (sigma_gps2 + sigma_odo2);
sigma_post2 = (sigma_gps2 * sigma_odo2) / (sigma_gps2 + sigma_odo2);
sigma_post = sqrt(sigma_post2);
% Result: mu_post ≈ 48.28, sigma_post ≈ 1.86
Practical note: verify independence assumption. If sensors share error sources, covariances must be included in fusion to avoid overconfidence.
