Core Concept

Random variables & distributions

Model sensor outputs as samples from a distribution so you can quantify how likely different readings are.

What it means
A random variable maps uncertain outcomes to probabilities. Use a distribution to describe expected value and spread.
Concrete example
GPS reports 10 m with sigma 2 m. The distribution tells you how likely the true position lies near 10 m and supports decision thresholds.
Common mistake
Treating the measurement as exact. Always propagate measurement uncertainty into downstream decisions like planning or mapping.
Key Takeaway

Modeling observations probabilistically gives you the tools to combine, compare, and decide under uncertainty.

Distribution snapshot
A visual is helpful: imagine many repeated sensor readings forming a histogram. That histogram is the empirical distribution from which we model the random variable. Below is a compact code-like pseudocode to sample a sensor model for simulation and testing.
% Sample sensor readings from a sensor noise model
mu = 10;        % expected reading
sigma = 2;      % measurement spread
N = 1000;
samples = mu + sigma * randn(N,1);  % draw samples from a normal distribution
% Use samples to estimate confidence intervals and visualize uncertainty
histogram(samples,30);
Note: The code uses a normal distribution to simulate repeated noisy measurements for analysis and plotting.
