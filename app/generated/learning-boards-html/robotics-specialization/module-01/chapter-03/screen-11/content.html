MATLAB fusion script

A short script computes densities and plots prior, measurement likelihood and posterior. Then it fuses a second measurement to show uncertainty shrinking.

Notes before running
Choose an x range wide enough to include ±3σ of both prior and measurement so curves are visible. Label axes and include a legend to compare spreads.
Key Takeaway

Running the script makes the analytic fusion intuitive: the posterior narrows and moves toward the more precise measurement.

MATLAB example
% Prior
mu_prior = 10;
sigma_prior = 3;

% First measurement
mu_meas1 = 12;
sigma_meas1 = 2;

% Define x axis
x = linspace(mu_prior-6*sigma_prior, mu_meas1+6*sigma_meas1, 400);

% Gaussian densities
p_prior = (1./(sigma_prior*sqrt(2*pi))) .* exp(- (x-mu_prior).^2 ./ (2*sigma_prior^2));
p_meas1 = (1./(sigma_meas1*sqrt(2*pi))) .* exp(- (x-mu_meas1).^2 ./ (2*sigma_meas1^2));

% Fusion (analytic)
sigma_prior2 = sigma_prior^2; sigma_meas12 = sigma_meas1^2;
mu_post1 = (sigma_meas12 * mu_prior + sigma_prior2 * mu_meas1) / (sigma_prior2 + sigma_meas12);
sigma_post12 = (sigma_prior2 * sigma_meas12) / (sigma_prior2 + sigma_meas12);

p_post1 = (1./(sqrt(sigma_post12)*sqrt(2*pi))) .* exp(- (x-mu_post1).^2 ./ (2*sigma_post12));

% Plot prior, measurement and posterior
figure; plot(x,p_prior,'b','LineWidth',1.5); hold on; plot(x,p_meas1,'orange','LineWidth',1.5); plot(x,p_post1,'g','LineWidth',1.8);
legend('Prior','Measurement','Posterior'); xlabel('State'); ylabel('Density'); title('Prior, Measurement, Posterior');

% Fuse a second measurement
mu_meas2 = 11; sigma_meas2 = 1.5;
sigma_post1_2 = sigma_post12; sigma_meas22 = sigma_meas2^2;
mu_post2 = (sigma_meas22 * mu_post1 + sigma_post1_2 * mu_meas2) / (sigma_post1_2 + sigma_meas22);
sigma_post22 = (sigma_post1_2 * sigma_meas22) / (sigma_post1_2 + sigma_meas22);

% Compute and plot second posterior
p_post2 = (1./(sqrt(sigma_post22)*sqrt(2*pi))) .* exp(- (x-mu_post2).^2 ./ (2*sigma_post22));
plot(x,p_post2,'purple','LineWidth',1.5); legend('Prior','Measurement1','Posterior1','Posterior2');
When you run this, notice how the purple posterior is narrower than the green one — each measurement reduces uncertainty when models are independent and Gaussian.
