Module 6 › Chapter 6.2 › Loop Closure
What it does
Correct accumulated drift
When a revisit is detected, add a constraint between the current and past poses. Then run global optimization to adjust the entire trajectory and the map.
Detection tip
Use descriptor similarity plus geometric verification to avoid false positives that could corrupt the map.
Simple loop detector
Descriptor matching
Compute similarities between the current descriptor and all previous descriptors, take the highest match, and check against a threshold. If it exceeds the threshold, declare a loop and add the constraint.
Key Takeaway

Loop closure provides the global constraints needed to correct drift and produce a consistent final map.
