Module 6 › Chapter 6.2 › Occupancy Grid Map
Definition

Cell-based probability map

Each grid cell stores P(occupied). Cells start as unknown (0.5) and are updated as the robot observes the world. The representation is compact, supports incremental updates, and integrates naturally with planning.

Example
A LiDAR ray that sees an obstacle at 3 m will make cells before 3 m more likely free and the cell at 3 m more likely occupied.
Common mistake
Treating probabilities as binary. Occupancy is belief, so keep fusing evidence instead of hard-thresholding too early.
Key Takeaway

Occupancy grids let a robot accumulate uncertain sensor evidence into a usable map for navigation.
