Build an occupancy grid
Assemble per-cell probabilities from range measurements using the inverse sensor model.
Mnemonic: picture rays carving tunnels of free cells until the endpoint marks an obstacle.

02
Understand SLAM
Describe simultaneous localization and mapping and why mapping with unknown poses is harder.
Mnemonic: two blindfolded tasks — finding position and drawing the map — done together.
VERIFIED COMPETENCY MILESTONE
03
Differentiate SLAM types
Explain online SLAM versus full SLAM and when each is used.
Mnemonic: online = live navigation; full = offline map refinement.
VERIFIED COMPETENCY MILESTONE
04
Implement mapping in MATLAB
Write a script that casts rays, updates log-odds, and visualizes the grid until a full loop is complete.
Mnemonic: simulate a 100×100 grid for a 10 m × 10 m arena and watch the map emerge.
VERIFIED COMPETENCY MILESTONE
Bloom's path
Learn → Understand → Apply → Master. Start by learning definitions, then implement the map, compare SLAM families, and finally examine loop closure effects on global consistency.
