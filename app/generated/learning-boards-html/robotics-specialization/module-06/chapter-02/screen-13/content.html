Module 6 › Chapter 6.2 › Hands-on Lab
Task
Build and visualize a 2D occupancy grid
  • Initialize a 100×100 grid for a 10 m × 10 m environment (cell_size = 0.1 m).
  • Define a rectangular ground-truth obstacle in the center.
  • Simulate robot poses around the perimeter and a 180° LiDAR with 1° resolution.
  • For each beam compute endpoint, run ray tracing, and update log-odds: -0.1 for free cells, +0.4 for endpoint.
  • Use imagesc to visualize grid states after each pose; compare final map to ground truth.
Checks
Common issues
Make sure to convert world coordinates to integer grid indices correctly and avoid marking endpoints for max-range readings. Tune increments to reflect sensor noise.
Key Takeaway

This lab links theory to code: you will see how rays dynamically carve free space and endpoints accumulate occupancy to reveal obstacles.
