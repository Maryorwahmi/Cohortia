Algorithm

Bresenham for occupancy grids

Convert world coordinates to grid indices using cell size, then run Bresenham to list cells on the ray. Each listed cell except the last receives a free update; the last receives an occupied update if within sensor range.

Note
If the reading equals the sensor max or is invalid, apply only free updates and do not mark an endpoint occupied.
Concrete scenario
100×100 grid, 10 m world
With cell_size = 0.1 m, a 3.2 m endpoint maps to index floor(3.2 / 0.1) = 32. Bresenham enumerates cells from the robot cell to index 32 so you can apply free and occupied updates consistently.
Key Takeaway

Precise cell indexing and ray tracing ensure free-space evidence is applied correctly, which is essential for accurate maps.
