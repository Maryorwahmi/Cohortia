Module 6 › Chapter 6.2 › Graph-Based SLAM
Core idea

Nodes and edges

Nodes = poses; edges = constraints (odometry, observations, loop closures). Optimize the whole graph to satisfy constraints in the least-squares sense.

Why it helps
Global optimization aligns measurements and corrects drift when loop closures add constraints.
Incremental use
Modern solvers permit incremental updates so graph methods can operate in near-real-time.
Concrete example
Add edges and optimize
Build odometry edges as the robot moves, add observation edges when scans match, and add loop closure edges when revisits are detected. Run nonlinear least-squares to tighten the graph and update node poses.
Key Takeaway

Graph formulation makes global correction straightforward: constraints are explicit and optimization restores consistency.
