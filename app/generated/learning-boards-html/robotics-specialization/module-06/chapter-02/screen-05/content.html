Module 6 › Chapter 6.2 › Inverse Sensor Model
Process

Ray → cells → updates

Step 1
For each LiDAR beam, compute the ray endpoint in world coordinates using robot pose and beam angle.
Step 2
Trace the ray through grid cells (e.g., Bresenham) and apply a free update to traversed cells.
Step 3
Apply an occupied update to the endpoint cell and leave cells beyond unknown.
Common mistake
Do not ignore free updates. If you only mark endpoints, free space remains unknown and planning can be overly conservative.
Concrete example
180° LiDAR, 1° steps
For each of 180 beams, compute endpoint, run Bresenham to get cells along the beam, decrement log-odds slightly for traversed cells and increment more for the endpoint cell. Repeat across poses to build the map.
Key Takeaway

Distribute sensor evidence: free evidence along rays is as important as endpoints for a correct map.
