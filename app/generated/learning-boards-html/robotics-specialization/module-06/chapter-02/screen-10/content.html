Module 6 › Chapter 6.2 › SLAM Families
EKF-SLAM
Joint Gaussian state
State and covariance include poses and landmarks. Updates use linearized Kalman math. Scales poorly as landmarks increase.
FastSLAM
Particles + per-landmark EKFs
Particles represent pose uncertainty while independent landmark filters keep per-particle map estimates. More scalable in many scenarios.
Graph-based
Constraint optimization
Nodes are poses/landmarks, edges are constraints. Nonlinear least-squares optimizes the whole graph and handles loop closures directly.
Practical note
Choose algorithms based on scale and sensor modality. Visual SLAM methods adapt these ideas to cameras, extracting features and building constraints from images instead of range endpoints.
