Core Concept
What is State Estimation?
Convert noisy sensor readings into a reliable, uncertainty-aware state for planning and control.
Belief as mean + covariance
Represent uncertainty with a covariance matrix so the filter knows how much to trust predictions versus measurements.
Prediction + Update
Predict dynamics, then correct with measurements weighted by noise R.
Key Takeaway

State estimation produces both an estimate and a quantified uncertainty so downstream systems can make safer decisions.

Concrete scenario
A wheeled robot uses wheel odometry for frequent motion updates and GPS for occasional absolute position fixes. Odometry drifts over time; GPS is noisy. The estimator combines both to yield a smoother, more accurate trajectory than either alone.
Sensors
  • GPS: absolute but noisy
  • Wheel odometry: frequent but drifts
  • IMU: high-rate orientation info
Model
A motion model predicts next state from control inputs and captures process noise via Q. If the model is wrong, prediction uncertainty grows.
Common mistake
Treating the filter as magic. If Q and R are mis-specified, the filter can overweight bad data and diverge. Always validate with simulations and RMSE tests.
