EKF loop (MATLAB)
for k = 1:N
    % Prediction (nonlinear)
    x_pred = x + v*dt*cos(theta);
    y_pred = y + v*dt*sin(theta);
    theta_pred = theta + omega*dt;

    % Jacobian of prediction
    F = [1, 0, -v*dt*sin(theta);
         0, 1,  v*dt*cos(theta);
         0, 0,  1];

    % Predict covariance
    P = F * P * F' + Q;

    % Measurement prediction (GPS + compass)
    z_pred = [x_pred; y_pred; theta_pred];
    H = eye(3);

    % Update
    K = P * H' / (H * P * H' + R);
    x = [x_pred; y_pred; theta_pred] + K * (z_k - z_pred);
    P = (eye(3) - K * H) * P;
end
Note: ensure consistent noise models for GPS and odometry in R and Q. If odometry provides v and omega measurements, include their uncertainty in Q or augment the measurement model accordingly.
Hands-on activity
Simulate a circular trajectory with v = 1 m/s and omega = 0.2 rad/s for 100 steps with dt = 0.1 s. Add Gaussian noise: GPS σ = 0.5 m; odometry σ_v = 0.1 m/s; σ_omega = 0.05 rad/s. Plot true path (green), GPS (red dots), EKF estimate (blue), and compute RMSE for GPS and EKF.
Expected observation
EKF should produce a smoother, more accurate estimate than raw GPS or odometry alone, reducing RMSE in typical cases.
Failure mode
If linearization is poor, EKF can diverge or oscillate. Monitor innovation and P to detect this early.
