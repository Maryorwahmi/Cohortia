Definition
Extended Kalman Filter (EKF)
Linearize nonlinear dynamics around the current estimate using Jacobians, then apply Kalman steps.
Nonlinear model
x_k = f(x_{k-1},u_{k-1}) + w; z_k = h(x_k) + v
F = ∂f/∂x, H = ∂h/∂x evaluated at the current estimate.
Mobile robot example
Prediction using motion model:
x_pred = x + v*dt*cos(theta); y_pred = y + v*dt*sin(theta); theta_pred = theta + omega*dt
Jacobian
F = [1,0,-v*dt*sin(theta); 0,1,v*dt*cos(theta); 0,0,1] captures linearized dependence on theta.
Limitation
If the linear approximation is poor, EKF updates may push the estimate away from the true state. Monitor innovation magnitude and covariance growth as diagnostics.
Question: during an EKF run, would a sudden large innovation always mean the measurement is correct? Not necessarily—check sensor faults, model mismatch, and whether the prior uncertainty supports such a change before accepting it.
