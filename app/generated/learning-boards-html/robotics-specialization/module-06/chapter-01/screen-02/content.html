Learning Objectives
These four objectives connect derivation, implementation, and application so you gain conceptual and practical mastery of Kalman-based state estimation.
01
Derive Kalman Filter equations
Work through the prediction and update equations and show how covariance P evolves. This matters because derivation reveals assumptions and informs tuning.
VERIFIED COMPETENCY MILESTONE
02
Implement a 1D MATLAB Kalman Filter
Translate the equations into code for a position/velocity tracker and inspect how estimates respond to noise and inputs.
VERIFIED COMPETENCY MILESTONE
03
Extend to nonlinear systems (EKF)
Use Jacobians to linearize f and h, then apply the Kalman steps locally. This is essential for realistic robot motion models.
VERIFIED COMPETENCY MILESTONE
04
Apply EKF to mobile robot localization
Fuse GPS and odometry to estimate x, y, theta, compute RMSE, and compare performance to raw sensors.
VERIFIED COMPETENCY MILESTONE
Bloom: Learn → Understand → Apply → Master. These objectives guide you from derivation to hands-on evaluation in MATLAB.
