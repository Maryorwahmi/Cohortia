Definition
Linear discrete-time model
Two equations specify dynamics and measurements; Q and R quantify uncertainty.
Equations
x_k = A x_{k-1} + B u_{k-1} + w_{k-1}
z_k = H x_k + v_k
A, B
State transition and control influence the predicted mean and covariance.
H
Maps the state to measurement space. Example: H = [1 0] to read position from [pos; vel].
Noise covariances
Q models process uncertainty; R models measurement noise. Both should match physical sensors and model errors when possible.
Concrete example
For a discrete constant-velocity model, A and B use dt. Q might include small process noise on position and larger relative noise on velocity to reflect uncertainty in acceleration.
Misconception
Choosing tiny Q makes the filter ignore model error and trust dynamics too much; choosing tiny R makes the filter chase noisy measurements.
Reflect: when building a model for a new robot, what measurements or experiments would you perform to estimate Q and R numerically?
