Optimality
Minimum mean-square error estimator for linear Gaussian systems. Use this when assumptions hold.
Recursion
Only previous estimate and covariance are required, enabling streaming operation without storing history.
Efficiency
Each iteration uses matrix multiplications and inversion sized by measurement dimension, keeping computation light for common sensor setups.
Uncertainty & usage
The covariance P quantifies estimator confidence and should guide planners. For example, larger P should cause more conservative path choices.
Concrete guidance
  • Validate optimality assumptions before relying on theoretical guarantees.
  • Use P for safety margins in planning and control.
  • Monitor computation time when measurement dimension grows.
