MATLAB 1D Kalman Filter
State: [position; velocity]. Measurement: position from GPS.
% Kalman Filter for 1D position tracking
% State: [position; velocity]
% Measurement: position from GPS

A = [1, dt; 0, 1];      % State transition
B = [0.5*dt^2; dt];     % Control input
H = [1, 0];             % Measurement matrix
Q = [0.01, 0; 0, 0.001]; % Process noise covariance
R = 0.5;                % Measurement noise covariance

x = [0; 0];             % Initial state estimate
P = eye(2);             % Initial covariance

for k = 1:N
    % Prediction
    x = A * x + B * u(k);
    P = A * P * A' + Q;

    % Update
    K = P * H' / (H * P * H' + R);
    x = x + K * (z(k) - H * x);
    P = (eye(2) - K * H) * P;

    % Store estimate
    x_est(k) = x(1);
end
Tip: inspect P values during the run. If P grows unbounded, check your Q, model A, and whether measurements arrive. To evaluate, compute RMSE between true positions and x_est, and compare that value to RMSE of raw GPS measurements.
Example run
Simulate a true trajectory, add Gaussian noise to GPS measurements, run the filter, and plot three series: true path (green), noisy GPS (red dots), and KF estimate (blue line). Expect the filter to smooth noise and reduce RMSE relative to raw GPS.
Common mistake
Using inconsistent units for dt or mismatched covariances causes unstable behavior. Ensure Q and R reflect real sensor characteristics.
Check
Verify K magnitude behaves as expected when scaling Q and R: larger Q increases K, larger R decreases K.
Try this

Run the script, then double R and observe how the filter trusts prediction more and produces a smoother but less measurement-aligned estimate.
