Process Flow
Prediction
Propagate mean and covariance using A, B, and Q.
x̂_k|k-1 = A x̂_{k-1|k-1} + B u_{k-1}
P_k|k-1 = A P_{k-1|k-1} A^T + Q
Key Takeaway

Prediction models uncertainty growth; choose Q to reflect model error.

Process Flow
Update
Blend prediction and measurement using the Kalman gain K.
Kalman gain
K_k = P_k|k-1 H^T (H P_k|k-1 H^T + R)^{-1}. It balances trust between prediction and measurement.
State & covariance update
x̂_k|k = x̂_k|k-1 + K_k (z_k - H x̂_k|k-1); P_k|k = (I - K_k H) P_k|k-1.
Concrete example
State is [position; velocity]. H = [1 0] selects position. A noisy GPS measurement of position moves the predicted position toward the measured value by a fraction K determined by P and R.
Misconception check: Kalman gain is not a tuning knob you pick arbitrarily; it results from uncertainty and should be inspected by changing Q or R to see expected behavior.
