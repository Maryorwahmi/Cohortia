State Estimation with Kalman Filters
Recover a robot's position, velocity, and orientation by fusing model predictions and noisy measurements. Learn both the linear Kalman Filter and the Extended Kalman Filter for nonlinear robot systems.
In this lesson
Kalman Filter basics, MATLAB 1D example, EKF for a mobile robot
Watch how prediction uncertainty and measurement noise meet and produce a tighter estimate. You will implement a basic filter in MATLAB and extend it to nonlinear motion using Jacobians.
Prediction
Model-based forward step using A, B and process noise Q to predict state and covariance.
Update
Incorporate measurements with covariance R using the Kalman gain to correct the prediction.
EKF
Linearize nonlinear dynamics with Jacobians F and H, then apply the Kalman equations locally.
Interactive Concept (visual)
Two Gaussians multiply
A prediction Gaussian and a measurement Gaussian combine to a narrower posterior. The Kalman gain controls the balance.
