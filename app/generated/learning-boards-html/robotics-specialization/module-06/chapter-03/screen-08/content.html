Module 7 › Chapter 6.3 › Resampling
Algorithm sketch
Normalize weights, compute cumulative distribution, choose a random start in [0,1/N), then walk pointers with step 1/N to select particles.
Why systematic
It is low-variance and runs in O(N) time, making it preferred for many MCL implementations.
Key Takeaway

Resampling focuses particles in probable regions but must be balanced with diversity-preserving steps to avoid impoverishment.

Concrete detail
Step size equals 1/num_particles. The start is a uniform random number in [0, step). Using a deterministic start would bias selection across repeated runs.
Misconception
Resampling always improves filter quality. In fact too frequent resampling removes diversity and can hurt recovery from novel states.
