Module 7 › Chapter 6.3 › Prediction Step
Step overview
For each particle, apply the odometry delta and add sampled Gaussian noise to x, y, and theta.
Pseudo-code
for each particle: particle.pose += odometry.delta + sample(noise)
Common mistake
Adding odometry deterministically without noise underestimates uncertainty and causes overconfidence.
Key Takeaway

Model motion uncertainty explicitly by sampling noise during prediction; tune noise to match observed odometry error.

Concrete example
If odometry reports delta_x = 0.5 m and sigma = 0.1 m, sample noise from N(0,0.1) for x, similarly for y and theta, then add to each particle. The cloud shifts forward and expands slightly.
Performance tip
Vectorize sampling and pose updates where possible. Batch ray-casting later in update stage to use GPU or optimized libraries.
