Module 7 › Chapter 6.3 › MCL & Hands-On
Activity summary
Create a 20×20 grid map, simulate a circular true trajectory, add Gaussian odometry and range noise, initialize 1000 particles, and run 100 steps with visualization.
Simulation parameters
Odometry sigma = 0.1 m, range sigma = 0.2 m, particles = 1000, steps = 100, kidnapping at step 50.
Key Takeaway

Hands-on simulation makes resampling effects, degeneracy, and recovery immediately visible—use it to tune parameters and policies.

Guided checklist
  1. Generate free-space particle set uniformly.
  2. Implement motion_update with sampled noise.
  3. Implement sensor_update with ray-casting and likelihoods.
  4. Compute N_eff and apply adaptive resampling.
  5. Inject random particles and regularize after resample if needed.
