Module 7 › Chapter 6.3 › Update Step
Key idea
Compute expected sensor reading for each particle, measure likelihood of the actual reading, and set particle weight accordingly.
Per-beam likelihood
weight = product over beams of gaussian_likelihood(observed, expected, sigma)
Numerical note
Multiply many small numbers can underflow. Use log-likelihoods or normalize weights and add a small epsilon before dividing.
Key Takeaway

Design an appropriate sensor noise model and handle normalization robustly so resampling selects meaningful hypotheses.

Concrete example
A particle predicts ranges [2.1, 1.0, 3.0]. Measured ranges are [2.0, 1.2, 2.9] with sigma 0.2. Compute per-beam Gaussian likelihoods and multiply to obtain the particle weight.
Visualization
Render particle size proportional to weight. This makes it obvious which particles the resampler will prefer.
