Module 7 › Chapter 6.3 › Rao-Blackwellized PF
Concept
Decompose state and apply analytic Kalman updates to linear-Gaussian parts conditioned on sampled variables. Particles represent only the remaining uncertainty.
Robotics example
Pose sampled by particles, landmark positions estimated with Kalman filters conditioned on each sampled pose.
Key Takeaway

Use Rao-Blackwellization when parts of the state are linear and Gaussian to reduce particle dimensionality and improve efficiency.

Trade-offs
  • Fewer particles required for similar accuracy.
  • Increased implementation complexity and per-particle compute for Kalman updates.
  • Requires careful bookkeeping of filter states per particle.
