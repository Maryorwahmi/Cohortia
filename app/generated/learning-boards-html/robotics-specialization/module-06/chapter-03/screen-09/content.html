Annotated MATLAB snippet
% Normalize weights
weights = [particles.weight];
weights = weights / sum(weights);

% Cumulative sum
cumulative = cumsum(weights);

% Systematic resampling
new_particles = particles; % preallocate
step = 1 / num_particles;
start = rand() * step;

for i = 1:num_particles
    threshold = start + (i-1)*step;
    idx = find(cumulative >= threshold, 1);
    new_particles(i) = particles(idx);
    new_particles(i).weight = 1 / num_particles;
end
This code shows the essential operations. Replace copies with index-based selection to reduce memory overhead if particle objects are large.
Practical checks
  • Plot cumulative and thresholds to verify selection visually.
  • Ensure weights sum is non-zero; add small epsilon if needed.
  • Test edge cases: single dominant particle, uniform weights, and numerical rounding.
Key Takeaway

Understand pointers on the cumulative distribution and guard against numerical edge cases when implementing resampling.
