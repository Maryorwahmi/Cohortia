Module 3 › Chapter 3.2 › Single-query vs Multi-query planners
Timeline of decision
Pick planner based on problem characteristics
Step 1: Is the environment static? If yes, consider PRM.
Step 2: How many queries? Many queries favor PRM; few favor RRT/RRT*.
Step 3: Does path quality matter? If so, prefer RRT* and budget iterations.
Use cases
PRM — static factory aisle with many pick tasks.
RRT — ad-hoc single path for a mobile robot in a changing corridor.
RRT* — offline planning for a manipulator where smooth, short trajectories reduce execution cost.
Key Takeaway

Planner selection is primarily driven by environment dynamics, query count, and whether optimal paths are required.
