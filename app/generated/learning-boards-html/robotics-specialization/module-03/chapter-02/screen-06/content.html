Module 3 › Chapter 3.2 › Rapidly-exploring Random Tree (RRT)
Algorithm
Sampling, nearest, steer
  • Sample q_rand and find nearest q_near in the tree.
  • Compute q_new = steer(q_near, q_rand, step_size).
  • If path q_near→q_new is collision-free, add q_new with parent q_near.
  • Terminate if q_new reaches the goal region or iterations exhausted.
Practical tip
Goal biasing — occasionally choosing the goal as q_rand — increases the chance of reaching the goal quickly at little extra cost.
Canonical code
function tree = rrt(cspace, start, goal, max_iter, step_size)
    tree.nodes = start;
    tree.parent = 0;

    for i = 1:max_iter
        q_rand = cspace.random_sample();
        [q_near, idx_near] = nearest_neighbor(tree.nodes, q_rand);
        q_new = steer(q_near, q_rand, step_size);

        if cspace.is_collision_free(q_near, q_new)
            tree.nodes = [tree.nodes; q_new];
            tree.parent = [tree.parent; idx_near];

            if norm(q_new - goal) < step_size
                if cspace.is_collision_free(q_new, goal)
                    tree.nodes = [tree.nodes; goal];
                    tree.parent = [tree.parent; size(tree.nodes,1)-1];
                    return;
                end
            end
        end
    end
end
Misconception
RRT will not reliably find the shortest path; it finds a feasible path quickly but does not optimize path length without additional processing.
Key Takeaway

RRT gives a fast feasible solution for single-query planning but often requires smoothing or optimization for execution.
