Module 3 › Chapter 3.2 › Learning Objectives
Objective 01
Explain PRM
You should be able to list construction steps: sampling, validation, k-nearest neighbor lookup, edge collision checks, and query-time connection of start and goal. Know why PRM suits multi-query static maps.
Objective 02
Implement RRT
Implementation includes sampling, nearest neighbor, steering by step size, collision testing, and termination when the goal is reached or iterations exhausted.
Objective 03
Understand RRT*
RRT* chooses optimal parents among nearby nodes and rewires neighbors when a shorter route is found. These changes are the reason RRT* converges toward optimal paths.
Objective 04
Compare planners
You will decide between grid-based and sampling planners by reasoning about dimension, queries, dynamic changes, and desired path quality.
Verified Competency Milestone
Complete a MATLAB experiment that implements RRT and RRT*, plots path length versus iterations, and explains when RRT* provides benefits over RRT.
