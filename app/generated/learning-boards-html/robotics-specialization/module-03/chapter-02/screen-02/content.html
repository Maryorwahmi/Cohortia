Mnemonic
SAMPLE → CONNECT → QUERY
Sample points, connect neighbors when collision-free, and answer queries by joining start and goal to the graph. This captures the PRM workflow in a single phrase.
Competency
After you finish these objectives you will be able to both reason about planner trade-offs for a 7-DOF arm and implement RRT and RRT* experiments that demonstrate path improvement with iteration count.
Verified Competency Milestone
Provide a short report: implement RRT and RRT* in MATLAB for a 2D scene, plot path length vs iterations, and justify planner choice for a 7-DOF arm.
