Module 3 › Chapter 3.2 › Probabilistic Roadmap (PRM)
Construction phase
Sampling and connecting
  1. Sample N random configurations and keep only collision-free ones.
  2. For each valid sample find k nearest neighbors in C-space.
  3. Check straight-line connections for collisions; add edges when safe.
Concrete example
Precompute a roadmap for a pick-and-place area and reuse it for many grasp queries without rechecking the entire scene each time.
Query phase
Connect and search
Given start and goal, connect them to nearby roadmap nodes if collision-free, then run graph search to find a path across the roadmap.
MATLAB snippet
function roadmap = prm_construct(cspace, N, k)
    roadmap.nodes = [];
    roadmap.edges = {};

    % Sample N configurations
    for i = 1:N
        q = cspace.random_sample();
        if cspace.is_valid(q)
            roadmap.nodes = [roadmap.nodes; q];
        end
    end

    % Connect nearest neighbors
    for i = 1:size(roadmap.nodes, 1)
        neighbors = knn(roadmap.nodes, roadmap.nodes(i,:), k);
        for j = 1:length(neighbors)
            if cspace.is_collision_free(roadmap.nodes(i,:), roadmap.nodes(neighbors(j),:))
                roadmap.edges{i} = [roadmap.edges{i}, neighbors(j)];
            end
        end
    end
end
Common pitfall
Using PRM in a changing environment without rebuilding the roadmap leads to invalid edges and incorrect paths. Recompute or repair the roadmap when obstacles change.
Key Takeaway

PRM shifts expensive collision checking to an offline construction phase so many later queries become efficient.
