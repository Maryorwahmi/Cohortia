Module 4 › Chapter 3.3 › Attractive Potential
Definition

Quadratic attractive potential

U_att(q) = 0.5 * K_att * ||q - q_goal||²
Attractive force
F_att(q) = -K_att * (q - q_goal), a linear restoring force toward the goal.
Parameter note
Higher K_att increases speed but can overwhelm repulsion; tune it relative to K_rep and d0.
Key Takeaway

Attractive potential creates a smooth valley and a linear force; it should be balanced with repulsion to avoid collisions.

Concrete example
% Example values
q = [0, 0];
q_goal = [10, 10];
K_att = 1;
F_att = -K_att * (q - q_goal); % points to the goal
Misconception check: Increasing K_att always improves convergence. In reality, if K_att is too large the robot may ignore repulsive corrections and collide with nearby obstacles.
