Module 4 › Chapter 3.3 › Comparison
Potential Fields
  • Fast, local, reactive
  • Good for dynamic obstacles and smoothing
  • Prone to local minima
Sampling-Based (RRT, PRM)
  • Global planning, explores configuration space
  • Probabilistic completeness in many problems
  • Computationally heavier and slower to react
Hybrid pattern
Generate an initial path with a sampling method and then apply local potential fields for dynamic avoidance and gradient descent for smoothing. This preserves long-range guarantees while enabling immediate reactions to unexpected obstacles.
