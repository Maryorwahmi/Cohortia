Optimization

Refine trajectories with gradients

Define a cost that penalizes obstacle proximity, deviation from the path, and sharp turns. Update interior waypoints using gradient descent and a small learning rate.
Algorithm outline
For each iteration and for each interior waypoint: compute gradient; waypoint = waypoint - alpha * gradient; check collisions.
Code example
function trajectory = gradient_descent_path(trajectory, obstacles, alpha, iterations)
    for iter = 1:iterations
        for i = 2:length(trajectory)-1
            grad = compute_gradient(trajectory(i,:), obstacles);
            trajectory(i,:) = trajectory(i,:) - alpha * grad;
        end
    end
end
Misconception check: Gradient descent always finds the global optimum. In nonconvex trajectory cost landscapes you may reach a local minimum; use multiple initializations or combine with global planning to improve results.
