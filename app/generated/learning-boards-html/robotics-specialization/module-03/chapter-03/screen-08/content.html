potential_field_force

Review the function that computes attractive and repulsive forces and returns the combined vector for control.

Key checks: only add repulsion when d <= d0, compute gradient correctly, clamp very small distances.
Common pitfall

For circular obstacles, the gradient of distance is the normalized vector from obstacle center; for complex shapes compute the closest-point gradient carefully.

function F = potential_field_force(q, q_goal, obstacles, K_att, K_rep, d0)
    % Attractive force
    F_att = -K_att * (q - q_goal);

    % Repulsive force
    F_rep = [0; 0];
    for i = 1:length(obstacles)
        d = distance_to_obstacle(q, obstacles{i});
        if d < d0
            grad_d = gradient_distance(q, obstacles{i});
            F_rep = F_rep + K_rep * (1/d - 1/d0) * (1/d^2) * grad_d;
        end
    end

    F = F_att + F_rep;
end
Testing tip: plot F_att, F_rep, and F to verify they combine as expected and to spot cancellations that indicate potential minima.
