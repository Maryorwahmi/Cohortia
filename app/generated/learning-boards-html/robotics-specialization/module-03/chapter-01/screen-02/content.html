Learning Objectives
Bloom progression: build from understanding to applied planning
Learn → Understand → Apply → Master
01
Define C-space
Explain the configuration space as the set of all robot poses and contrast it with the workspace. This matters because it turns geometry into a search problem.
VERIFIED COMPETENCY MILESTONE
02
Represent C-obstacles
Use Minkowski expansion for simple robots and understand swept volumes for rotating shapes to ensure safe, collision-free graphs.
VERIFIED COMPETENCY MILESTONE
03
Implement search algorithms
Write BFS, Dijkstra, and A* on a graph or grid and verify correctness and optimality behavior under different heuristics.
VERIFIED COMPETENCY MILESTONE
04
Analyze complexity
Compute time and space cost for BFS, Dijkstra, and A*, and relate them to grid resolution and dimensionality of C-space.
VERIFIED COMPETENCY MILESTONE
