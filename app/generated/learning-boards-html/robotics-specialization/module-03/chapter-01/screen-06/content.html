Module 3 › Chapter 3.1 › Graph representation
Grid to graph
Discretize C-space into cells and link free cells to create a graph for search.
Connectivity choices: 4-connected (N,E,S,W) or 8-connected (diagonals allowed). Edge cost may be uniform or equal to Euclidean distance between cell centers.
Practical note: A fine grid improves path fidelity but raises V and E, increasing memory and run time.
Key Takeaway

Select grid resolution and connectivity to match robot accuracy requirements and available compute, and be ready to smooth paths afterward.

Example counts
For a 50×50 grid: V = 2500 nodes. With 4 neighbors per cell, E ≈ 4V. These magnitudes guide algorithm choice.
Edge costs
# Uniform cost: cost = 1 for each neighbor
# Distance cost: cost = Euclidean distance between cell centers
