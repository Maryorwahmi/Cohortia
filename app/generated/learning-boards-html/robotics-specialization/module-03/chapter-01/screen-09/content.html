A* in brief
Combine the path cost so far with a goal estimate to guide search efficiently.
• Uses f(n) = g(n) + h(n) to order the open set.
• If h is admissible, A* finds an optimal path.
• If h is consistent, implementation can avoid reprocessing nodes and remains efficient.
• A* often explores far fewer nodes than Dijkstra with a good heuristic.
Key Takeaway

Admissible heuristics let A* remain optimal while focusing exploration; choose heuristics that reflect true geometric cost when possible.

Heuristic examples
• Euclidean distance: admissible for continuous movement, encourages straight paths.
• Manhattan distance: admissible on 4-connected grids and when movements are axis-aligned.
• Zero heuristic: reduces A* to Dijkstra, exploring broadly but safely.
Carefully test heuristics on your grid: a heuristic that overestimates can speed up runtime but sacrifices optimality, which is usually unacceptable for critical robot tasks.
