Experiment steps
Code A*, visualize runs, and compare node counts against Dijkstra over multiple trials.
• Create 50×50 grid, randomly place 20% obstacles for each trial.
• Implement A* with Euclidean heuristic and Dijkstra (heuristic = 0).
• Visualize obstacles, explored nodes, and final path for each algorithm and trial.
• Repeat 10 trials and compute average explored-node ratio between A* and Dijkstra.
Key Takeaway

Empirical measurement over random trials demonstrates practical benefits of a good heuristic and surfaces variance in planning difficulty.

Starter pseudocode
function [path, explored] = astar(grid, start, goal, heuristic)
  open = PriorityQueue();
  open.insert(start, heuristic(start, goal));
  g = containers.Map(); g(mat2str(start)) = 0;
  parent = containers.Map();
  explored = [];
  while ~open.isEmpty()
    current = open.pop();
    explored(end+1,:) = current;
    if isequal(current, goal)
      path = reconstruct_path(parent, start, goal); return;
    end
    for nb = grid.neighbors(current)
      tentative = g(mat2str(current)) + grid.cost(current, nb);
      if ~g.isKey(mat2str(nb)) || tentative < g(mat2str(nb))
        g(mat2str(nb)) = tentative;
        f = tentative + heuristic(nb, goal);
        open.insert(nb, f);
        parent(mat2str(nb)) = current;
      end
    end
  end
  path = []; 
end
Use a consistent random seed when debugging, but vary seeds across trials when measuring average behavior. Visualize explored nodes to build intuition about algorithmic differences.
