Module 3 › Chapter 3.1 › Configuration Space (C-space)
Definition and intuition
The configuration space is the set of all robot poses. Use it to map collision checking into pathfinding for a point.
Concrete example
A circular mobile robot of radius r: expand workspace obstacles by r and plan for a point.
Misconception
C-space is not the same as workspace unless the robot is a point. Orientation and joint angles create extra dimensions.
Why this matters
A correct C-space makes collision checking local and lets you reuse graph search algorithms for planning.
Key Takeaway

Modeling the right degrees of freedom and representing obstacles in C-space is the foundational step for any motion planner.

Quick reference
Common C-spaces:
  • Point robot in 2D: (x, y)
  • Circular robot in 2D: (x, y, theta) but obstacles expanded by radius
  • 6-joint arm: (theta1, theta2, ..., theta6)
Short notation
Point mobile robot: C = { (x, y) }
Circular robot: C = { (x, y, θ) }
6-DOF arm: C = { (θ1, θ2, θ3, θ4, θ5, θ6) }
Remember: dimensionality grows quickly with degrees of freedom, making naive grids intractable for many manipulators.
