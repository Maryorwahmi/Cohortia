Module 3 › Chapter 3.1 › Breadth-First Search
BFS overview
Use BFS for unweighted grids to guarantee fewest-step paths.
• Uses a FIFO queue and a visited set to avoid repeats.
• Guarantees shortest path in number of edges on unweighted graphs.
• Memory grows with the frontier size; be cautious for large grids.
• Not appropriate when edges have non-uniform costs; use Dijkstra or A* instead.
Key Takeaway

BFS is reliable and simple for uniform-cost grids but becomes costly in memory as grid size grows.

MATLAB-style pseudocode
function path = bfs(graph, start, goal)
  queue = {start};
  visited = containers.Map();
  visited(mat2str(start)) = true;
  parent = containers.Map();
  while ~isempty(queue)
    current = queue{1}; queue(1) = [];
    if isequal(current, goal)
      path = reconstruct_path(parent, start, goal);
      return;
    end
    for neighbor = graph.neighbors(current)
      if ~visited.isKey(mat2str(neighbor))
        visited(mat2str(neighbor)) = true;
        parent(mat2str(neighbor)) = current;
        queue{end+1} = neighbor;
      end
    end
  end
  path = [];
end
Reconstruct the final path by following parent pointers back from goal to start; this is standard in grid planners.
