Module 7 › Chapter 7.1 › Cascade PD
Inner loop — Balance

Control law: τ_balance = Kp_theta (θ_des − θ) + Kd_theta (0 − θ̇). Designed for speed and damping to keep θ near zero despite disturbances.

Tuning tip: prioritize damping to avoid high-frequency oscillation; increase derivative gain carefully to avoid noise amplification.
Outer loop — Position

Compute x_des = Kp_x (x_target − x) + Kd_x (0 − ẋ). Convert to θ_des = x_des / L to command the inner loop. Designed with lower bandwidth than inner loop.

Tuning tip: adjust position gains so θ_des remains small and within linearization limits.
Concrete example

At t=3s set x_target=2m; outer loop commands small θ_des, inner loop moves wheels to track θ_des until the robot reaches the target.

Common mistake

Tuning both loops simultaneously without locking inner loop first. Always tune inner balance to be fast and stable first.

Key takeaway

Nested loops simplify design: inner loop keeps angle small, outer loop moves position by commanding small tilts.
