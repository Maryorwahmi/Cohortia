Module 7 › Chapter 7.1 › MIP states and sensors
State vector
  • x — wheel position
  • ẋ — wheel velocity
  • θ — pendulum angle (rad)
  • θ̇ — pendulum angular velocity
Example

A typical measurement vector is [θ_imu; θ̇_imu; ẋ_encoder]. Use these to feed the EKF update step.

Sensors and limitations
  • IMU: noisy angle and gyro bias under vibration.
  • Encoders: good for relative motion but can slip or drift.
  • EKF: treats sensor noise explicitly via R and process noise Q.
Common mistake

Assuming encoder-derived velocity is noise-free. Always model measurement uncertainty and include it in R.

Concrete example

If θ is 0.1 rad and ẋ is 0.2 m/s, EKF prediction and an IMU update will correct biases and reduce variance.

Why it matters

Accurate state estimates let the balance controller use precise angle error and angular velocity feedback, which are time-critical.

Key takeaway

Treat sensors as partial and noisy; plan estimation accordingly so the controller receives reliable state information.
