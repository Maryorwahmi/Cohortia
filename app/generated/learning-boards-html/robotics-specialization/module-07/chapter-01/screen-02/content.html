Learning Objectives

Learn the skills to model, control, estimate, and simulate the MIP.

01
Model MIP dynamics

Derive the nonlinear Lagrangian equations for x and theta and assemble the four-state vector for simulation and control.

VERIFIED COMPETENCY MILESTONE
02
Design cascade PD controller

Create an inner angle PD and an outer position PD. Convert position error to a desired tilt to command the inner loop.

VERIFIED COMPETENCY MILESTONE
03
Implement EKF state estimation

Fuse noisy IMU angle and gyro readings with encoder velocity to produce a reliable state estimate for control.

VERIFIED COMPETENCY MILESTONE
04
Simulate and evaluate

Run MATLAB with ode45, compare true and estimated states, and study stability limits and fail-safe triggers.

VERIFIED COMPETENCY MILESTONE
