Simulation recipe
  1. Write mip_dynamics(t,x,...) that returns x_dot using nonlinear equations and PD control.
  2. Set parameters and initial state x0 with small tilt, e.g., 0.1 rad.
  3. Call ode45(@(t,x) mip_dynamics(...), tspan, x0).
  4. Run EKF updates against simulated noisy measurements and log estimates.
  5. Plot position and angle subplots to inspect response.
MATLAB plotting example
% Simulate
tspan = [0 10];
x0 = [0; 0; 0.1; 0];
[t,x] = ode45(@(t,x) mip_dynamics(t,x,...), tspan, x0);

figure;
subplot(2,1,1); plot(t, x(:,1)); ylabel('Position (m)');
subplot(2,1,2); plot(t, x(:,3)); ylabel('Pendulum Angle (rad)'); xlabel('Time (s)');
Concrete test

At t=3s set x_target=2m and watch the angle tilt forward and then back to stop at the target.

Common mistake

Forgetting to add sensor noise; the EKF must be tested with realistic noise to tune Q and R properly.

Key takeaway

Use simulation to compare true state and EKF estimate and iterate on controller gains and filter covariances until behavior matches requirements.
