Module 7 › Chapter 7.1 › Hands-on Activity
Step-by-step lab
  1. Write mip_dynamics implementing nonlinear Lagrangian equations and PD control.
  2. Include torque saturation and safety threshold checks for large θ.
  3. Use ode45 with x0 = [0; 0; 0.1; 0] and tspan = [0 10].
  4. Implement EKF as prediction-update with H mapping θ, θ̇, and ẋ.
  5. Run three gain sets and a step at t=3s for position, then plot true vs estimated states.
Experiment

Compare underdamped, oscillatory, and well-tuned gains and document results.

Common mistake

Running EKF at a different rate than the simulation output without interpolation, causing filter instability.

Key takeaway

A well-instrumented simulation with noise and safety checks is the best way to validate controller and estimator performance before hardware trials.
