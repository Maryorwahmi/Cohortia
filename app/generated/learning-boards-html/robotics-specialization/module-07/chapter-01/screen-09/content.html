EKF steps (verbal)
  1. Predict: x_pred = A x + B F; P_pred = A P A' + Q.
  2. Build measurement matrix H for θ, θ̇, ẋ.
  3. Compute K = P_pred H' / (H P_pred H' + R).
  4. Update: x = x_pred + K (z − H x_pred); P = (I − K H) P_pred.
Misconception

Treating EKF as a black box. Inspect residuals and covariance to understand filter behavior and to tune Q and R properly.

MATLAB snippet
% EKF prediction and update
x_pred = A * x + B * F;
P_pred = A * P * A' + Q;

H = [0 0 1 0; 0 0 0 1; 0 1 0 0];
K = P_pred * H' / (H * P_pred * H' + R);

x = x_pred + K * (z - H * x_pred);
P = (eye(4) - K * H) * P_pred;
Concrete example

Add Gaussian noise to IMU and encoder signals and observe that the EKF estimate smooths angle and velocity traces while reflecting slow drifts in P.

Tuning reminder

Increase Q for model uncertainty, increase R for less trust in sensors. Watch innovation magnitudes to guide tuning.

Key takeaway

EKF requires careful tuning and diagnostics. Use plots of residuals and covariance to gain confidence in your estimates.
