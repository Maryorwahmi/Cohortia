Controller logic (verbal)
  1. Compute position error and x_des with Kp_x and Kd_x.
  2. Compute θ_des = x_des / L.
  3. Compute torque F = Kp_theta (θ_des − θ) + Kd_theta (0 − θ̇).
  4. Saturate F to motor limits and send to dynamics.
Pro tip

Tune the inner loop first. Log θ and θ̇ to confirm inner-loop bandwidth before tuning outer loop gains.

Code example (MATLAB style)
% Compute outer loop desired tilt
x_error = x_target - x;
x_des = Kp_x * x_error + Kd_x * (0 - x_dot);
theta_des = x_des / L;

% Inner loop torque
F = Kp_theta * (theta_des - theta) + Kd_theta * (0 - theta_dot);
% Saturate
F = max(min(F, F_max), -F_max);
Concrete example

With Kp_theta=50 and Kd_theta=10 a small 0.1 rad tilt corrects quickly; observe if oscillation appears when Kp_theta is raised too far.

Common mistake

Applying large torque without saturation. Physical motors have limits; include saturations to avoid unrealistic simulations or damage in hardware.

Key takeaway

Implement nested PD logic directly in the dynamics so the integrator sees the closed-loop input at every time step.
