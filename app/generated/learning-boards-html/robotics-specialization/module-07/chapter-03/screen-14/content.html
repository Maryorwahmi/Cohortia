Potential Fields

Limit obstacle influence and add escape rules or global planning to avoid local minima traps.

Rotation Convention

Always document rotation order; test near ±90° pitch and prefer quaternions for robust orientation handling.

SfM Scale

Monocular SfM lacks absolute scale; include metric references or additional sensors to resolve true dimensions.

Final Thought

These pragmatic checks and documented conventions save debugging time and improve reliability when moving from simulation to hardware.
