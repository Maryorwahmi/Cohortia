Comparison

Kalman vs EKF vs Particle

Kalman Filter
Single Gaussian, linear models, computationally light, optimal under assumptions.
Extended Kalman Filter
Linearizes nonlinear models around the estimate. Works locally; vulnerable to poor initialization.
Particle Filter
Nonparametric belief representation, supports multimodal and global localization. Resampling concentrates hypotheses by weight.
Concrete example

If a robot has no initial pose estimate, initialize particles uniformly across the map and let sensor updates and resampling focus particles near the true pose. The EKF cannot represent that initial uniform uncertainty because it uses a single Gaussian.

Misconception

Believing EKF can handle arbitrary nonlinearity by repeated linearization. EKF is an approximation that fails for multimodal beliefs.

Key Takeaway

Match estimator assumptions to your task: use particle filters for global or multimodal uncertainty, EKF for mild nonlinearity, Kalman for linear Gaussian problems.
