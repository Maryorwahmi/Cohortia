Definition & Bug

Order matters — and so does singularity

% Provided code
Rx = [1 0 0; 0 cos(phi) -sin(phi); 0 sin(phi) cos(phi)];
Ry = [cos(theta) 0 sin(theta); 0 1 0; -sin(theta) 0 cos(theta)];
Rz = [cos(psi) -sin(psi) 0; sin(psi) cos(psi) 0; 0 0 1];
R = Rx * Ry * Rz; % ambiguous convention
The correct standard Z-Y-X aerospace order is R = Rz * Ry * Rx. If theta equals ±90 degrees expect gimbal lock. Consider quaternions to avoid singularities when continuous orientation coverage is required.
Practical checks
  • Document rotation convention clearly (intrinsic vs extrinsic).
  • Test edge angles near ±90° to reveal singular behavior.
  • Use quaternions for long sequences of rotations or interpolation.
Why it matters

Orientation bugs are subtle and often manifest only near singular configurations or during interpolation; rigorous tests prevent costly failures on hardware.
