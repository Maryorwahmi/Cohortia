Code Analysis

Attractive and Repulsive Forces

function F = controller(q, q_goal, obstacles)
    F = -2 * (q - q_goal);           % attractive
    for i = 1:length(obstacles)
        d = norm(q - obstacles{i});
        F = F + 10 * (q - obstacles{i}) / d^3;  % repulsive
    end
end
The code above lacks a finite influence distance for obstacles and can create singularly large repulsive forces when d is small. The local minimum problem appears when attractive and repulsive vectors cancel. Fixes include limiting repulsion to d < d0 and adding randomness or planning to escape minima.
Practical fixes
  • Use finite influence radius d0 so obstacles beyond d0 do not contribute.
  • Clip repulsive force magnitude to avoid singularities at very small d.
  • Combine with a planner or add escape heuristics for minima.
Warning

Do not rely on potential fields alone for guaranteed navigation in complex maps.
