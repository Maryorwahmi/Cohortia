Process

Prediction & Update

Prediction (state)
x = A x + B u — propagate the mean using the system model and control input.
Prediction (covariance)
P = A P A' + Q — project uncertainty through dynamics and add process noise. Omitting A' is a common bug.
Update
Compute Kalman gain K = P_pred H' (H P_pred H' + R)^{-1}, apply innovation to correct state and covariance.
Key Takeaway

Both state and covariance propagation must be correct. Test with known noise to validate behavior.

Code snippet (covariance bug)
% Incorrect:
P = A * P + Q;

% Correct:
P = A * P * A' + Q;
Run unit tests where A rotates uncertainty to confirm the A' term is present. Without it the covariance will not represent the rotated uncertainty correctly.
