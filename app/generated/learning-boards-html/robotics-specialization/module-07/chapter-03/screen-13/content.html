Module 7 › Chapter 7.3 › Key Concepts
Homogeneous Transform

A single matrix that composes rotation and translation for chained frame calculations.

Covariance Propagation

Always use P = A P A' + Q when predicting covariance; this preserves orientation and scale of uncertainty.

Particle Resampling

Resampling draws particles with replacement proportional to weights, concentrating probability on high-likelihood hypotheses.

Takeaway

Check matrix forms, estimator assumptions, and resampling logic first when debugging estimation and localization systems.
