Module 7 › Chapter 7.2 › Key Concepts
Motor driver required
Drivers handle motor currents; GPIO pins alone are insufficient.
Ultrasonic sensing
Distance via echo timing; add filtering and timeouts to handle edge cases.
Data logging
CSV logs of sensor and motor data make tuning and debugging possible.
Summary takeaway

Protect hardware with correct power and drivers, treat sensor data as noisy, and log everything that helps you reproduce and fix behavior.
