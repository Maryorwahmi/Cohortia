Ultrasonic operation

Sends a sound pulse and measures return time. Distance = time times speed of sound / 2. Use short trigger pulses and measure echo edges precisely.

IR proximity role

Best for short-range detection and edge sensing. Quick and cheap, but influenced by surface color and reflectivity.

Practical checks
  • Compare ruler distance vs sensor output at multiple angles.
  • Average readings or use median filters to remove spikes.
  • Set timeouts to avoid infinite waits in edge cases.
Example scenario
Place a foam block at 30 cm and record readings at 0.5 second intervals while rotating the block at different angles. Notice when the sensor under-reads due to an angled surface or when reflections create erroneous short distances. Use this data to refine detection thresholds used in the avoidance loop.
Common mistake

Assuming the sensor always returns accurate distances; instead, expect noise and handle it in software before relying on the measurement for control.
