Module 7 › Chapter 7.2 › Wiring
Power topology
  1. USB power bank → Raspberry Pi (5V stable supply).
  2. Separate motor battery → motor driver power input.
  3. Connect grounds of Pi and motor battery together for shared reference.
Common GPIO mapping
Motor direction pins: GPIO 17, 18, 22, 23. Ultrasonic TRIG → GPIO 24, ECHO → GPIO 25. I2C: SDA → GPIO 2, SCL → GPIO 3.
Incremental test flow
  • Power Pi alone and confirm boot.
  • Attach driver, run a script that toggles control pins without motors attached.
  • Add motors and run short pulses to confirm direction and polarity.
Wiring snapshot
TRIG → GPIO 24
ECHO → GPIO 25 (input)
Motor control → GPIO 17,18,22,23
I2C → SDA GPIO 2, SCL GPIO 3
Check this before you run

Confirm common ground, battery voltage under load, correct pin numbering (BCM), and that the motor driver enable pins are set properly.
