Learning Objectives

What you'll be able to do and how you'll prove it.

Bloom: Learn → Understand → Apply → Master
01
Assemble rover hardware

Put together the Pi, motor driver, motors, and sensors so the platform is electrically safe and mechanically stable. Proper assembly prevents short circuits and loose connections that break experiments.

VERIFIED COMPETENCY MILESTONE
02
Program GPIO in Python

Use RPi.GPIO to read sensors and drive motors with direction and PWM. This skill connects software logic to physical actuation so your rover can move and react.

VERIFIED COMPETENCY MILESTONE
03
Implement obstacle avoidance

Create a reactive loop using ultrasonic or IR readings to detect obstacles and steer away. Small decision routines enable autonomous behaviors without mapping.

VERIFIED COMPETENCY MILESTONE
04
Log and analyze data

Record timestamps, distance readings, and motor commands to a CSV for plotting and troubleshooting. Data helps you tune thresholds and verify behavior under real conditions.

VERIFIED COMPETENCY MILESTONE
