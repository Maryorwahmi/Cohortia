PWM basics

Pulse-width modulation varies the duty cycle of a digital signal to control motor power. Use PWM outputs to the motor driver's PWM input pins for variable speed.

When to add encoders

Add encoders when you need distance estimates or consistent wheel speed under load. Encoders enable odometry and closed-loop control.
