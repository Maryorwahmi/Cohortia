Learning Objectives
Concrete competencies for trajectory generation and tracking
Learn → Understand → Apply → Master
01
Generate smooth trajectories
You will build time-parameterized curves through waypoints that ensure continuous position and velocity, preventing impossible motor demands.
Mnemonic: Curve before Cruise
VERIFIED COMPETENCY MILESTONE
02
Implement waypoint-following control
You will code a cascade controller that converts position error into velocity, acceleration and finally thrust and torques for attitude control.
Mnemonic: Outer-to-Inner
VERIFIED COMPETENCY MILESTONE
03
Differentiate generation and tracking
You will be able to explain why generation chooses smooth derivatives and tracking uses feedback to correct disturbances.
Mnemonic: Plan the path, then close the loop
VERIFIED COMPETENCY MILESTONE
04
Analyze trajectory trade-offs
You will reason about speed versus control effort, and when to prefer minimum-snap versus simpler polynomials for safety and agility.
Mnemonic: Aggressive vs Conservative
VERIFIED COMPETENCY MILESTONE
