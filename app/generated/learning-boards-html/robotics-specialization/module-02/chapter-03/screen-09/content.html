Module 3 › Chapter 2.3 › Cascade Control
Cascade structure
Outer: position error → desired velocity. Middle: velocity error → desired acceleration. Inner: attitude error → torques. This hierarchy keeps high-rate inner loops focused on stabilization and slower outer loops on guidance.
Common mistake
Too-large outer gains can command accelerations the inner loop cannot produce, causing actuator saturation and loss of stability.
MATLAB example (visual)
function u = cascade_controller(x, x_ref, v_ref, a_ref, Kp_pos, Kd_pos, Kp_att, Kd_att, m, g)
    % Outer: position control
    v_des = v_ref + Kp_pos * (x_ref(1:3) - x(1:3));

    % Middle: velocity control
    a_des = a_ref + Kd_pos * (v_des - x(4:6));

    % Convert desired acceleration to thrust and attitude
    u_total = m * norm(a_des + [0; 0; g]);

    % Inner: attitude control (simplified)
    angles_des = acceleration_to_angles(a_des);
    tau = Kp_att * (angles_des - x(7:9)) - Kd_att * x(10:12);

    u = [u_total; tau];
end
This pseudo-code shows the flow from reference to the low-level inputs. In practice the conversion to angles accounts for desired yaw and thrust directions.
Pro tip

Tune inner-loop attitude gains first, then tune middle and outer loops progressively, ensuring no actuator saturation.
