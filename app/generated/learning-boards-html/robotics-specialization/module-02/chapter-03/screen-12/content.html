Module 3 › Chapter 2.3 › Safety Features
Geofencing
Define a virtual boundary. When the vehicle approaches it, plan a safe return or hold pattern. Always test geofence triggers in simulation with sensor noise to avoid false positives or unsafe responses.
Emergency landing
Trigger when battery or comms fail. Use a conservative descent trajectory that limits descent rate and avoids nearby obstacles. The controller must be able to track this descent without saturating thrust.
Collision avoidance
Fuse sensors to detect obstacles and replan trajectories in real time. Replanning can either produce avoidance waypoints or modify timing and path to steer clear while preserving smooth derivatives.
Check your design
Simulate a motor failure or an obstacle suddenly appearing. Confirm the system triggers the intended fail-safe, such as an immediate gentle descent or a safe landing zone selection.
