Module 3 › Chapter 2.3 › Cubic Trajectories
Form and constraints
p(t) = a0 + a1*t + a2*t^2 + a3*t^3
Constraints: p(0), p(T), p'(0), p'(T)
Use the four equations to solve for coefficients. If endpoint velocities are zero, the system simplifies and the polynomial yields a smooth ramp in velocity between endpoints.
Concrete example
Fit a cubic from position 0 with zero velocity to position 5 with zero velocity over one second. The resulting acceleration profile is finite but may jump when concatenated with the next segment unless velocities and accelerations are matched at the junction.
When to use cubic: low-speed tasks, simple implementations, or when you explicitly smooth accelerations elsewhere.
Misconception: cubic guarantees smooth acceleration — it does not across segment boundaries.
Key Takeaway

Cubic ensures position and velocity continuity within a segment; check joins for acceleration jumps and consider higher order if needed.
