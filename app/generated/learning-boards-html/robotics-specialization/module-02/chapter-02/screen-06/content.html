MATLAB function
This snippet returns total thrust including feedforward gravity and PD corrections.
<!-- Escaped MATLAB code -->
function u = altitude_controller(z, z_dot, z_des, Kp_z, Kd_z, m, g)
    e_z = z_des - z;
    u = m*g + Kp_z * e_z - Kd_z * z_dot;
end
Notes: the m*g term supplies hover thrust; Kp_z corrects altitude error; -Kd_z*z_dot damps vertical motion.
Concrete walkthrough
If z_des=5 m and current z=4.8 m, e_z=0.2 m, Kp_z*e_z increases thrust to climb. If the vehicle is already moving upward, the -Kd_z*z_dot term subtracts thrust to prevent overshoot. The net thrust combines physics and corrections.
Misconception
Dropping the feedforward term forces the controller to hold hover via offset in Kp, making tuning and disturbance rejection harder.
