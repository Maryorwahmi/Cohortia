function [pos, vel, acc] = cubic_trajectory(p0, p1, v0, v1, T, t)
    % p0, p1: initial and final positions
    % v0, v1: initial and final velocities
    % T: total duration
    % t: current time (0 <= t <= T)
    
    a0 = p0;
    a1 = v0;
    a2 = (3*(p1 - p0) - T*(2*v0 + v1)) / T^2;
    a3 = (2*(p0 - p1) + T*(v0 + v1)) / T^3;
    
    pos = a0 + a1*t + a2*t^2 + a3*t^3;
    vel = a1 + 2*a2*t + 3*a3*t^2;
    acc = 2*a2 + 6*a3*t;
end
This produces continuous pos, vel and acc across the interval [0,T]. Verify by plotting pos, vel and acc against time.
Why continuous acceleration matters
Motors and propellers cannot instantaneously change thrust. Continuous acceleration avoids commanding infinite jerk and keeps actuator demands feasible.
Misconception
Higher-order polynomials always solve problems. They add complexity and require more constraints; start with cubic for typical waypoint transitions.
Key Takeaway

Use cubic polynomials when you need smooth position, velocity and acceleration profiles with minimal constraints and simple implementation.
