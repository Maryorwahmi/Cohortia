Module 2 › Chapter 2.2 › Hands-on: ode45
Activity steps
  1. Implement altitude_controller as shown previously with feedforward m*g and PD terms.
  2. Model vertical dynamics: m * z_ddot = u - m*g - disturbance (apply saturation if desired).
  3. Run ode45 for t in [0,T] from z=0 to z_des=5 m with four gain sets and plot z(t) together.
  4. Add Ki=2 and a constant downward disturbance of 0.5 N; compare PD vs PID results and observe steady-state error correction.
  5. Introduce thrust saturation and test anti-windup via clamping the integral term.

Reflection
