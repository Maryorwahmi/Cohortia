Module 2 › Chapter 2.1 › Key Concepts — Quick Reference
Motor mapping
Sum thrusts for lift; differences for roll and pitch; rotor spin imbalance for yaw.
Core equations
1D: m·z̈ = u − m·g. 2D: ẍ=(u/m)sinθ, z̈=(u/m)cosθ−g. 3D: Newton–Euler pair.
Rotation choice
Euler for intuition; quaternions for production to avoid gimbal lock.
Final prompt
When plotting simulation results, relate each trajectory segment to the attitude and thrust commands that produced it. This habit reveals coupling and builds intuition.
