Vertical motion model
m · z̈ = u − m · g — the basis for altitude control.
Interpretation
Thrust produces acceleration. Controllers must command thrust so the integrated acceleration yields the desired position profile.
Example: simple hover controller
Set u = m·g + Kp·(z_des − z). If Kp is small this yields gradual correction; if large it can overshoot. Use a derivative or integral term to tune performance.
Key Takeaway

Altitude control is a second-order problem: design controllers that convert position error into a thrust that safely produces required acceleration.

Simulation note
When you simulate this equation with ode45, integrate z and ż as state variables and apply u(t). Start by validating hover: constant u = m·g should keep ż constant at zero.
Misconception
Treating thrust as a direct position command leads to poor controllers. Always remember thrust changes acceleration, then integrate.
