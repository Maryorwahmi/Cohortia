Module 2 › Chapter 2.1 › 2D tilt-and-thrust dynamics
2D dynamics equations
ẍ = (u/m)·sin(θ); z̈ = (u/m)·cos(θ) − g; θ̈ = τ / Iy.
Example trajectory
Start at x=0, z=2. To reach x=5, command a positive pitch and maintain thrust near m·g. To stop, pitch back to create negative acceleration and then level out.
Control implication
Controllers must coordinate torque commands (to change θ) and thrust commands (to control magnitude of acceleration). Separate loops for attitude and position are common, with position commanding desired pitch.
Misconception
Assuming thrust alone moves horizontally ignores geometry. Horizontal force is created by reorienting the same thrust vector.
Annotated step cards
Step 1 — Attitude change
Apply τ to change θ according to θ̈ = τ/Iy.
Step 2 — Thrust
Collective thrust u projects into horizontal via sin(θ).
Step 3 — Position update
Integrate ẍ and z̈ to update velocities and positions in simulation.
Reflect: how does a heavier vehicle (larger m) change the required pitch or thrust for the same horizontal acceleration?
