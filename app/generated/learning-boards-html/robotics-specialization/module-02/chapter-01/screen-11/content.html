Module 2 › Chapter 2.1 › Controller for hover and trajectory
Hover controller
u = m·g + Kp_z·(z_des − z) plus attitude PD to keep roll/pitch near zero.
Position → Attitude
Compute desired pitch from x error: θ_des = Kp_x·(x_des − x). Send θ_des to attitude controller.
Tuning tips
Start with small gains to avoid overshoot. Validate hover before enabling horizontal motion. Add integral action if steady-state errors persist.
Simulation exercise
Parameters: m = 0.5 kg, Iy = 0.01 kg·m², g = 9.81 m/s². Simulate 10 seconds, plot x vs z, and observe how the quadrotor must pitch forward to accelerate, then pitch back to stop.
Key Takeaway

Nested control loops that map position error to attitude commands and attitude error to torque are standard. Validate with step tests and gradually enable more aggressive maneuvers.
