Definition MATLAB odometry
A minimal, readable odometry update
Code
function pose = odometry_update(pose, v_L, v_R, L, dt)
    v = (v_R + v_L) / 2;
    omega = (v_R - v_L) / L;

    pose.x = pose.x + v * cos(pose.theta) * dt;
    pose.y = pose.y + v * sin(pose.theta) * dt;
    pose.theta = pose.theta + omega * dt;
end
Ensure v_L and v_R are linear speeds (m/s). Convert encoder counts using wheel circumference and time delta before calling this function.
Notes & checklist
  • Normalize theta periodically to avoid numerical overflow in long runs.
  • Account for encoder quantization; small dt helps but increases compute cost.
  • If wheels slip, add sensor fusion to correct drift.
Key Takeaway

This function is the simple, testable core of odometry. Use it as a baseline before adding filters or corrections.
