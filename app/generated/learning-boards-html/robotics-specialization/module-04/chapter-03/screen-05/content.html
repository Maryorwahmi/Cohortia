Definition Forward kinematics
Compute forward and angular velocities
Core formulas used by odometry and controllers.
v = (v_R + v_L) / 2
ω = (v_R - v_L) / L

// Example:
v_L = 0.4   // m/s
v_R = 0.6   // m/s
L   = 0.5   // m
v   = (0.6 + 0.4)/2 = 0.5 m/s
ω   = (0.6 - 0.4)/0.5 = 0.4 rad/s
Note: v_L and v_R must be linear wheel speeds in meters per second. If you measure wheel rotations, convert using wheel radius first.
Explanation points
  • The average of wheel speeds gives straight-line speed because both wheels contribute to forward motion.
  • The difference in speeds produces rotation; dividing by track width converts linear speed difference to angular rate.
  • If v_R > v_L the robot turns left in a right-handed coordinate system where positive ω rotates the body counterclockwise.
Key Takeaway

These formulas let you translate wheel commands into instantaneous motion and are the building block for odometry.
