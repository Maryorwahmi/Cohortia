Process Flow Odometry
From velocities to pose by integration
Dead reckoning is inexpensive, but remember its limitations.
Integration equations
Δx = v * cos(θ) * dt
Δy = v * sin(θ) * dt
Δθ = ω * dt

pose.x += Δx
pose.y += Δy
pose.theta += Δθ
Apply these updates each time step using the current heading θ to project motion into the world frame.
Practical notes
  • Odometry is cheap and fast, useful for short-term control and dead-reckoning within loops.
  • Error sources include wheel slip, uneven surfaces, encoder rounding, and timing inaccuracies.
  • Correct drift with absolute sensors or by fusing measurements in a state estimator.
Common mistake

Relying on odometry alone for long-term global accuracy will fail due to accumulated errors.
