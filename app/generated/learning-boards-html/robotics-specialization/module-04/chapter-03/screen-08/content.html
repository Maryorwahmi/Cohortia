Process Flow Square path simulation
Drive a square and watch odometry drift
Activity outline
  1. Start at (0,0), θ = 0. Drive to (5,0) with v_L = v_R = 0.5 m/s.
  2. Turn in place with v_L = -0.3, v_R = 0.3 to rotate 90°.
  3. Repeat for the other three sides to return to origin.
  4. Add Gaussian noise to v_L and v_R with σ = 0.02 and plot noisy path vs ideal path.
Observe how the noisy path drifts and how errors accumulate across segments, especially after repeated turns.
MATLAB snippet (concept)
% Pseudocode outline
pose = struct('x',0,'y',0,'theta',0);
L = 0.3; dt = 0.01;
for t from 0 to end
  % set v_L and v_R for straight/turn segments
  v_L_noisy = v_L + sigma*randn();
  v_R_noisy = v_R + sigma*randn();
  pose = odometry_update(pose,v_L_noisy,v_R_noisy,L,dt);
  record pose.x, pose.y;
end
plot(ideal_path); hold on; plot(noisy_path);
Key Takeaway

Simulate noise to measure expected drift and to determine how often you need external corrections for your task.
