Starter MATLAB code
% Damped pendulum phase portrait and example trajectories
theta = linspace(-2*pi, 2*pi, 30);
omega = linspace(-6, 6, 30);
[TH, OM] = meshgrid(theta, omega);

% Equations with damping
g = 9.81; L = 1; c = 0.1;
dTH = OM;
dOM = -(g/L)*sin(TH) - c*OM;

quiver(TH, OM, dTH, dOM);
hold on;

Exercise checklist
  • Generate quiver plot of the vector field with damping.
  • Overlay trajectories from at least three initial conditions.
  • Implement computeCOT and test with provided values.
  • Write a short note on whether adding an SEA would reduce motor energy.
Common mistakes
Forgetting damping in domega, not overlaying trajectories, or miscomputing COT by omitting gravity in the denominator.
