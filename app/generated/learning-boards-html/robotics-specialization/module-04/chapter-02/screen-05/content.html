Phase portraits and the pendulum example
Follow the MATLAB snippet to build a quiver plot and overlay trajectories that reveal stability.
MATLAB snippet (visual)
% Phase portrait of a simple pendulum with damping
theta = linspace(-2*pi, 2*pi, 20);
omega = linspace(-5, 5, 20);
[TH, OM] = meshgrid(theta, omega);

% dtheta/dt = omega
% domega/dt = -(g/L)*sin(theta) - c*omega
g = 9.81; L = 1; c = 0.1;
dTH = OM;
dOM = -(g/L)*sin(TH) - c*OM;

quiver(TH, OM, dTH, dOM);
xlabel('Angle (rad)');
ylabel('Angular velocity (rad/s)');
% Overlay trajectories using ode45 from various initial states
Explanation
  • Vectors show instantaneous state flow: arrows point where the state moves next.
  • Closed orbits in the undamped case represent neutral oscillations; add damping to see attraction.
  • Fixed points are where both derivatives are zero; linearization predicts local behavior but not global switching.
Concrete example: add c=0.1 and plot trajectories from θ=0.5, 2.5, 3.14 to see spirals into (0,0) and divergence near π.
Misconception check: a closed orbit is not necessarily a stable gait unless nearby trajectories return to it — that is a limit cycle.
Key takeaway: visualizing phase space reveals attraction basins and separatrices important for gait design.
