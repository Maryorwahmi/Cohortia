How to construct a Poincaré map
  1. Choose an event surface, e.g., each touchdown instant.
  2. Record the relevant state vector at that event (horizontal speed, leg compression, angle).
  3. Simulate one full cycle from touchdown to next touchdown to obtain the map.
  4. Linearize around fixed points to assess attraction or repulsion.
This procedure turns continuous, hybrid dynamics into a discrete return map that is easier to analyze for periodicity.
Concrete example

Simulate the SLIP with fixed k and vary touchdown angle. For each angle, compute the touchdown state sequence and check whether successive touchdown velocities converge. Angles that produce a convergent sequence indicate stable running regimes.

Misconception check: a fixed point does not guarantee global stability; it can be locally attracting only for small perturbations.
Key Takeaway

Use Poincaré maps to convert cyclic hybrid motions into discrete maps. Analyze fixed points and local attraction to understand parameter ranges for stable running.
