Module 3 › Chapter 3.1 › Reserved Addresses
Network Address
All host bits = 0

Identifies the subnet. Example: 192.168.1.0 for a /24. Not assignable to hosts.

Role
Used in routing tables and as the network identifier in calculations.
Broadcast Address
All host bits = 1

Sends traffic to all hosts on the subnet. Example: 192.168.1.255 for a /24. Not assignable to hosts.

Role
Used for discovery, ARP broadcasts, and some service announcements within the subnet.
Usable host range
For 192.168.1.0/24: usable hosts are 192.168.1.1 through 192.168.1.254.
Tip
Always compute reserved addresses from the mask before assigning host IPs.
