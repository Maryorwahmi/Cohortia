Module 3 › Chapter 3.1 › Activity
Activity steps
  1. Compute network and broadcast for 192.168.50.123 with mask 255.255.255.0 using binary AND.
  2. Convert 172.16.25.1 into full 32-bit binary and note /16 behavior.
  3. Convert 11000000.10101000.00000010.00001100 back to dotted-decimal.
  4. Run ipconfig or ip a on your machine and record IPv4, mask, and default gateway.
Template example
# Example for step 1
IP:   192.168.50.123 -> 11000000.10101000.00110010.01111011
Mask: 255.255.255.0   -> 11111111.11111111.11111111.00000000
Network (AND):      -> 11000000.10101000.00110010.00000000 = 192.168.50.0
Broadcast: set host bits to 1 -> 192.168.50.255
Usable: 192.168.50.1 - 192.168.50.254
Reflection
After doing the steps, ask: do these hosts share the same network? If not, is the mask the reason?
Checkpoints
  • Each octet has 8 bits
  • Pad leading zeros
  • Don’t assign network/broadcast
Key Takeaway

Working conversions and computing networks manually builds confidence and prevents address assignment mistakes.
