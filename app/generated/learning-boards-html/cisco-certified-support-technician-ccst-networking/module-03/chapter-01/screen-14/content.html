Module 3 › Chapter 3.1 › Quick Reference
Pad octets
Always write eight bits per octet when converting to binary to align with masks correctly.
Compute network
Network = IP AND mask; broadcast = network with host bits set to one; reserve both addresses.
Use OS tools
Run ipconfig or ip a to confirm the machine’s view of its IP, mask, and gateway before making changes.
Final thought

These quick checks resolve many common addressing problems and form the backbone of effective troubleshooting.
