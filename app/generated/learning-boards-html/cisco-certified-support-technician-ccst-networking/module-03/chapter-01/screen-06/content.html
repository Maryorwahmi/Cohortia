How masks work

Mask = pattern of ones and zeros

A mask marks which bits are fixed for the network. Apply a logical AND between IP and mask to extract the network address.

Example: /24 mask
IP:   192.168.1.10   = 11000000.10101000.00000001.00001010
Mask: 255.255.255.0  = 11111111.11111111.11111111.00000000
AND result (network): 11000000.10101000.00000001.00000000 = 192.168.1.0
Non-aligned masks
Masks can split inside octets. For example 255.255.240.0 covers 20 network bits, not a full octet boundary.
Misconception
Assuming masks always map to whole octets leads to wrong network calculations when masks are /17, /19, etc.
Visual
Mask /24 indicates first 24 bits as network: NN.NN.NN.HH where N=network bit, H=host bit.
/24 = 255.255.255.0
/20 = 255.255.240.0
/16 = 255.255.0.0
Key Takeaway

Masks are binary patterns; use binary AND to compute the network address and always align bits correctly.
