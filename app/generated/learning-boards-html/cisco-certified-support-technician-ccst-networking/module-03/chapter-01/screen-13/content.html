Module 3 › Chapter 3.1 › Key Concepts
IPv4 = 32 bits
Dotted-decimal maps to four binary octets; pad each octet to eight bits for calculations.
Subnet mask defines network
Network = IP AND mask; broadcast = network with host bits set to one.
Special & private ranges
Loopback, APIPA, and RFC 1918 ranges are not routable like public addresses; treat them accordingly.
One-line summary

Convert, compute, verify: binary conversion + mask calculation + OS checks are your routine for IPv4 troubleshooting.
