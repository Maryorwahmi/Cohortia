Module 3 › Chapter 3.1 › Public vs Private
Private (RFC 1918)
10.0.0.0 - 10.255.255.255 (10/8) 172.16.0.0 - 172.31.255.255 (172.16/12) 192.168.0.0 - 192.168.255.255 (192.168/16)
Use case
Internal LAN addressing, isolated from the public internet and combined with NAT for outbound access.
Public
Assigned by registries or ISPs. Globally routable and must be unique across the internet when used on external interfaces.
Use case
Servers or edges that must be reachable from the internet. Private addresses are not valid for this role without NAT.
Key Takeaway

Check whether an IP is in an RFC 1918 range to determine if it’s intended for internal use; use NAT when private hosts need internet access.
