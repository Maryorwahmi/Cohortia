Module 3 › Chapter 3.1 › Dotted-decimal to binary
Step-by-step

Convert each octet to eight bits

Work octet by octet, pad with leading zeros, then join the results into a full 32-bit sequence for mask arithmetic.

Example walkthrough
# Given: 192.168.1.10
192 -> 128 + 64 = 11000000
168 -> 128 + 32 + 8 = 10101000
1   -> 00000001
10  -> 00001010

Full 32-bit: 11000000.10101000.00000001.00001010
Pro tip
Memorize common octet binaries like 128, 192, 224, and 255 to speed conversions.
Misconception
Never drop leading zeros; 1 is 00000001, not just 1 when aligning bits with a mask.
Quick reference
128 = 10000000
192 = 11000000
224 = 11100000
255 = 11111111
Key Takeaway

Always convert and pad each octet; the aligned 32-bit view is necessary for mask operations.
