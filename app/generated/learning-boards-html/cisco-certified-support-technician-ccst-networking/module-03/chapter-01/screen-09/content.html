Module 3 › Chapter 3.1 › Loopback & APIPA
Loopback
127.0.0.1

Used for local testing of network services. Traffic never leaves the host. Seeing services bound to loopback indicates the process is running locally.

Troubleshoot hint
If an application responds on loopback but not on the host IP, check application binding and firewall rules.
APIPA
169.254.0.0/16

Automatically assigned when DHCP fails. Allows link-local communication only; not routable to other networks or the internet.

Troubleshoot hint
When clients show APIPA, verify DHCP server reachability, network cabling, and switch port configuration before changing host settings manually.
Quick check

Loopback is for local tests; APIPA means DHCP failed — these clues point to different troubleshooting paths.
