Module 3 › Chapter 3.1 › What is IPv4?
Definition

IPv4 as a 32-bit label

An IPv4 address is a contiguous string of 32 bits, usually shown as four octets in dotted-decimal format for readability.

Analogy
Think of the network portion as the street and the host portion as the house number. Routers use the street to forward mail toward the right neighborhood before the exact house receives it.
Example
192.168.1.10 = 11000000.10101000.00000001.00001010
Common mistake
Treating octets as independent fields instead of parts of a continuous 32-bit number causes errors when computing networks.
Octet view
192  . 168  . 1    . 10
11000000.10101000.00000001.00001010
Key Takeaway

IPv4 is a single 32-bit number; dotted-decimal is a human-readable representation that maps directly to binary octets.
