Module 3 › Chapter 3.1 › Network & Broadcast
Step 1 — Convert
IP:   192.168.50.123 = 11000000.10101000.00110010.01111011
Mask: 255.255.255.0   = 11111111.11111111.11111111.00000000
Step 2 — AND
AND result: 11000000.10101000.00110010.00000000 = 192.168.50.0
Network address: 192.168.50.0
Step 3 — Broadcast
Broadcast: set host bits to 1 -> 11000000.10101000.00110010.11111111 = 192.168.50.255
Results
Network: 192.168.50.0 Broadcast: 192.168.50.255 Usable: 192.168.50.1 - 192.168.50.254
Common error
Assigning .0 or .255 (on a /24) to a host. These are reserved for network and broadcast functions.
Key Takeaway

Use AND to find the network, then set host bits to one to get broadcast; usable hosts are the addresses between them.
