Module 3 › Chapter 3.2 › Variable Length Subnet Masking
VLSM workflow
  1. List subnets by size (largest first).
  2. Assign the smallest mask that satisfies the largest subnet's host need.
  3. Use the remaining address space for the next subnet, using the magic number to step blocks.
  4. Repeat until all subnets are allocated.
Example: For a link needing 2 hosts use /30. For a department needing 50 hosts choose smallest mask where 2^h − 2 ≥ 50.
Practical tip
Always allocate from the top or bottom of the major network consistently and record each assigned block with the mask and usable ranges. This prevents accidental overlaps.
Key Takeaway

Use VLSM to match mask sizes to actual needs, minimizing wasted addresses and preserving space for future growth.
