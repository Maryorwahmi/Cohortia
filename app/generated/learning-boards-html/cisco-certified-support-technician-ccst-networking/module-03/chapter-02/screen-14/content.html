Module 3 › Chapter 3.2 › Key Concepts
Subnetting
Divide a network into smaller broadcast domains by borrowing host bits to the network portion.
Formulas
Subnets = 2^n (borrowed bits). Usable hosts = 2^h − 2 (remaining host bits).
Magic Number
Block size = 256 − last octet of mask. Use multiples to find networks and broadcasts quickly.
Summary Takeaway
Plan from largest to smallest, choose the smallest mask that meets requirements, use magic number to list ranges, subtract two for usable hosts, and document allocations to avoid overlaps.
