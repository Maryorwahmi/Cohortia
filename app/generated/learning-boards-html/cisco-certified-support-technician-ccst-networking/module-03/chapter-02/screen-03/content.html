Practice Tasks
Task
Calculate network, broadcast, and usable range for 172.16.10.65 / 255.255.255.240
Use the magic number 16 and list the block that contains .65.
Lab
Split 192.168.10.0/24 into 4 subnets with ≥25 hosts
Choose the smallest mask that satisfies 2^h - 2 ≥ 25 and then list the first four subnet ranges.
Common Mistakes & Checks
  • Forgetting to subtract 2 when counting usable hosts.
  • Assigning the network or broadcast address to a device.
  • Mixing up CIDR and dotted decimal without converting to binary first.
  • Not verifying block boundaries with the magic number for the last octet.
Mnemonic
Think: Borrow bits → fewer hosts per subnet → more subnets. Checkable with 2^n and 2^h - 2 formulas.
