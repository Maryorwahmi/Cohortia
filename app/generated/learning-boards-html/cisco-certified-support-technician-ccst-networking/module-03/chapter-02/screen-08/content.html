Module 3 › Chapter 3.2 › Subnet & Host Formulas
Formula cards
Subnets
2^n
n = number of bits borrowed. Example: borrow 3 bits → 2^3 = 8 subnets.
Usable hosts
2^h − 2
h = remaining host bits. Example: /27 → h = 5 → 2^5 − 2 = 30 usable hosts.
Side-by-side example
Original /24: subnets = 2^0 = 1, usable hosts = 2^8 − 2 = 254
Borrow 3 bits → /27: subnets = 2^3 = 8, usable = 2^5 − 2 = 30
Design implication
When planning, list required hosts per subnet first. Choose a mask that meets the largest subnet's requirement, then use VLSM to fit smaller needs into leftover space.
Key Takeaway

Use the formulas to verify your plan: compute both subnets and usable hosts to avoid mismatches.
