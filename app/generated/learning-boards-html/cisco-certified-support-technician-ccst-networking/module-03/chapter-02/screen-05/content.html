Module 3 › Chapter 3.2 › Borrowing Bits and CIDR
Step-by-step
1. Determine required subnets
Pick n so that 2^n ≥ required subnets.
2. Borrow n bits
New prefix = original prefix + n.
3. Convert mask to dotted-decimal
Write binary then convert each octet to decimal.
4. Compute hosts per subnet
Hosts = 2^(remaining host bits) - 2.
Worked conversion
Original /24 mask:
11111111.11111111.11111111.00000000
Borrow 3 bits → new mask bits:
11111111.11111111.11111111.11100000
Last octet 11100000 = 128 + 64 + 32 = 224
Dotted-decimal mask = 255.255.255.224 (/27)
Hosts per subnet = 2^(32-27) - 2 = 30
Concrete example
You have 192.168.1.0/24 and need 8 subnets. Borrow 3 bits to get /27. Each subnet has 32 addresses, 30 usable.
Misconception check
Do not count network and broadcast addresses as usable. If a calculation yields 32 addresses, usable hosts equal 30 for that block.
Key Takeaway

CIDR prefix shows network bits. Borrow bits to increase subnets; always verify with binary conversion and host-count formulas.
