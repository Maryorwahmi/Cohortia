Subnetting Fundamentals
Divide a network into smaller subnets to reduce broadcast domains and allocate addresses efficiently.

In this chapter you'll learn CIDR notation, how to borrow bits from the host portion, compute subnet masks and host counts, and apply the magic number to list subnets and ranges.

This is a narrated lab-style walkthrough with practical examples and checks for common mistakes.
