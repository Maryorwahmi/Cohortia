Module 3 › Chapter 3.2 › Lab: 192.168.10.0/24
Step 1: Choose mask
Solve 2^h − 2 ≥ 25 → 2^5 − 2 = 30 → h = 5. Prefix = 32 − 5 = /27. Mask = 255.255.255.224
Step 2: Magic number
Last octet 224 → 256 − 224 = 32. Subnet increments = 32.
First four subnets
Subnet 1: Network 192.168.10.0, usable 192.168.10.1–192.168.10.30, broadcast 192.168.10.31
Subnet 2: Network 192.168.10.32, usable 192.168.10.33–192.168.10.62, broadcast 192.168.10.63
Subnet 3: Network 192.168.10.64, usable 192.168.10.65–192.168.10.94, broadcast 192.168.10.95
Subnet 4: Network 192.168.10.96, usable 192.168.10.97–192.168.10.126, broadcast 192.168.10.127
Verification steps
  • Confirm host count per subnet equals 2^h − 2.
  • Check that network and broadcast are not assigned to hosts.
  • Document each block and its purpose to avoid overlap.
Key Takeaway

Pick the smallest mask satisfying host needs and use the magic number to enumerate subnets reliably.
