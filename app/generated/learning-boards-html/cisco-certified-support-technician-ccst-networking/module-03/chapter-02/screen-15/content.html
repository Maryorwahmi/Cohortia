Module 3 › Chapter 3.2 › Quick Reference
Translate masks
Write the 32-bit binary mask and convert octets to decimal to avoid misinterpretation.
Apply formulas
Subnets = 2^n; usable hosts = 2^h − 2. Use these to confirm counts and sizes.
Use magic number
Compute 256 − last octet of mask to step subnet boundaries in the last octet quickly.
Final Tip
Document allocations and verify each host lies inside network+1 and broadcast−1. These habits prevent conflicts and save time when troubleshooting live networks.
