Module 3 › Chapter 3.2 › Binary to Dotted-Decimal
Step-by-step conversion
CIDR: /27
Binary mask:
11111111.11111111.11111111.11100000
Octets:
11111111 = 128+64+32+16+8+4+2+1 = 255
11111111 = 255
11111111 = 255
11100000 = 128+64+32 = 224
Dotted-decimal: 255.255.255.224
Why this matters
Devices and some configs require dotted-decimal masks. Converting confirms you applied the intended prefix and prevents mismatches that cause routing or ACL errors.
Quick checks
  • Count ones carefully; group into octets to avoid off-by-one errors.
  • If masks cross octets, write all 32 bits to see exact distribution.
  • Use the result to compute the magic number when the last octet is non-zero.
Key Takeaway

Binary conversion is the reliable method to verify masks, especially when masks are not standard classful values.
