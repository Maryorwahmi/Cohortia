Module 3 › Chapter 3.2 › Network, Broadcast, Usable
Definitions
  • Network address: first address of the block; identifies subnet.
  • Broadcast address: last address; used to reach all hosts in subnet.
  • Usable hosts: addresses between network+1 and broadcast−1.
Example: /27 block starting at 192.168.1.32 → network=192.168.1.32, broadcast=192.168.1.63, usable=192.168.1.33–192.168.1.62
Checklist for assignment
  1. Confirm network and broadcast using the block increment.
  2. Assign hosts only within network+1 to broadcast−1.
  3. Record the mask and CIDR to avoid mismatches when configuring devices.
Common Mistake

Never assign the network or broadcast to a host. These are reserved and will break communication.
