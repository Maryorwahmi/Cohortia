Module 3 › Chapter 3.2 › Calculation Errors & Checks
Common errors
  • Counting network or broadcast as usable hosts.
  • Applying magic number incorrectly across octets.
  • Converting CIDR to dotted-decimal with a miscounted binary string.
  • Overlapping ranges because of inconsistent allocation direction.
Simple verification checklist
  1. Write the 32-bit mask and count ones.
  2. Compute magic number and list multiples for the last octet when applicable.
  3. Confirm usable hosts = 2^h − 2.
  4. Record allocations to avoid overlap.
Practical tip
When troubleshooting, check a device's IP against the documented ranges. If a device cannot reach others in its subnet, verify mask and gateway configuration first — many issues stem from incorrect masks.
Quick Fix

If hosts can't communicate, compare mask and network assignment to the documented subnet block and correct any mismatches immediately.
