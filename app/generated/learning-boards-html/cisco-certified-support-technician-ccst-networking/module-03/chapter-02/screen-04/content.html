Module 3 › Chapter 3.2 › What is Subnetting?
Definition
Subnetting
Dividing a larger IPv4 network into smaller subnets by borrowing host bits to expand the network portion.
Analogy
Like partitioning an open office into smaller rooms so only a department hears local broadcasts. This isolates traffic, improving performance and manageability.
Why it matters
  • Reduces broadcast domains to limit unnecessary traffic.
  • Enables logical segmentation for security and troubleshooting.
  • Improves address allocation when planned with VLSM.
Common misconception
Subnetting is only about address counts. In reality it also controls broadcast scope and isolates faults. Design choices balance the number of subnets against usable hosts per subnet.
Concrete example
Given 192.168.1.0/24, borrowing 3 bits yields /27, creating 8 subnets each with 30 usable hosts.
Example
/24 → borrow 3 bits → /27. Hosts per subnet = 2^(32-27) - 2 = 30 usable hosts.
Key Takeaway

Subnetting trades host capacity per subnet for more network segments, improving isolation and control.
