Module 3 › Chapter 3.2 › Worked Assessment
Given
IP: 172.16.10.65, Mask: 255.255.255.240
Step 1: CIDR
Binary mask has 28 ones → /28
Step 2: Magic number
256 − 240 = 16 → increments of 16 in the last octet.
Result
Network address: 172.16.10.64
Broadcast address: 172.16.10.79
Usable hosts: 172.16.10.65 – 172.16.10.78 (14 usable)
Key Takeaway

Follow binary→CIDR→magic number→range checks to avoid errors; always verify usable count with 2^h − 2.
