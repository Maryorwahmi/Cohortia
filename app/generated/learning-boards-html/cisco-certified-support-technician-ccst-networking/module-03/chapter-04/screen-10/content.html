Module 4 › Chapter 3.4 › What is DNS and the hierarchy of servers?
DNS hierarchy explained
  1. Root servers: know TLD server locations.
  2. TLD servers: know authoritative servers for domains under the TLD.
  3. Authoritative servers: hold the definitive records for a domain.
Local resolvers perform recursive queries for clients, and they cache results to speed subsequent lookups. Caching is helpful but can cause stale answers if records change.
Analogy
Think of DNS like a phone book index: the root tells you which TLD index to consult; the TLD index points to the local directory that contains the entry.
