Module 4 › Chapter 3.4 › Learning Objectives
Practical checks
  • Verify DHCP server IP, lease obtained and lease expires fields.
  • Identify exclusion ranges used for static devices like printers.
  • Use ipconfig/dhclient to release and renew leases safely.
  • Use nslookup/dig to verify DNS records and authoritative servers.
Security & escalation
Recognize DHCP spoofing and DNS poisoning indicators, and know basic mitigations such as DHCP snooping and validating authoritative records before responding to incidents.
Practice prompt
Pick one objective to practice in a lab: perform a lease renew and run dig to inspect TTLs and record sources.
Caution
Avoid releasing leases on production services without coordination. Some devices expect fixed addresses for firewall or routing rules.
