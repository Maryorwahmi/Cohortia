Module 4 › Chapter 3.4 › DORA — Discover and Offer
Process

Discover → Offer

Client broadcasts a Discover. DHCP servers with available addresses reply with an Offer including address, mask, gateway, DNS, and lease time.

Example: A laptop broadcasts Discover; server offers 10.0.0.120 with 24-hour lease and DNS 10.0.0.1.
Misconception: If the client doesn't receive an Offer it is always the server's fault. Often the issue is that broadcast is blocked or a DHCP relay is missing.
Step details
  • Discover: client uses broadcast; server must be reachable on the same layer-2 or via relay.
  • Offer: includes offered IP and lease length; may be unicast if client MAC known.
  • Multiple Offers: client usually picks the first acceptable one.
Troubleshooting hints
Check server status, DHCP relay agent configuration, switch port settings, and firewall rules preventing UDP ports 67 and 68. Use packet capture on the client or server to observe Discover and Offer exchanges.
Try this
If you see a Discover in a capture, follow the packet to the server or relay and confirm the server has an address available in its scope.
