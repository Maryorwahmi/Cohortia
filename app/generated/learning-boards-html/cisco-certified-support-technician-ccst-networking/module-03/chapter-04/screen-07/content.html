Module 4 › Chapter 3.4 › DHCP scopes, exclusions, and lease durations
Scope anatomy
  • Start and end IP define the scope’s pool.
  • Exclusion ranges remove addresses from automatic assignment.
  • Reservations tie a MAC address to a specific IP via the DHCP server.
Lease duration trade-offs
Short leases: better reuse in transient environments, more renew traffic.
Long leases: stable addresses and less renew overhead, but slower reuse of orphaned addresses.
Practical checklist
  1. Confirm exclusions for printers and servers.
  2. Set lease duration appropriate to device churn.
  3. Monitor active leases and scope usage regularly.
