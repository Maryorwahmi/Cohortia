Module 4 › Chapter 3.4 › DNS record types and practical queries
Record cheat-sheet
  • A — hostname to IPv4 address.
  • AAAA — hostname to IPv6 address.
  • CNAME — alias to canonical name.
  • MX — mail exchange hosts for a domain.
  • NS — authoritative name servers for the domain.
  • PTR — reverse lookup from IP to hostname.
Command examples
nslookup -type=mx cohortia.com
dig cohortia.com A
dig @ns1.cohortia.com cohortia.com SOA
nslookup -type=ptr 142.250.190.132  # reverse lookup
Practical tip
When in doubt, query the authoritative server directly to confirm the source value. If the authoritative record is correct but clients still see the old value, flush caches or wait for TTL expiry.
