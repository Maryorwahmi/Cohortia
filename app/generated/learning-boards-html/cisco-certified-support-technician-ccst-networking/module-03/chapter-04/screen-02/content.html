This set of objectives is focused on practical technician tasks: diagnosing leases, testing name resolution, and applying quick fixes that restore connectivity.
01
Explain DHCP function
Describe how DHCP automates IP assignment and why scope management and leases reduce errors and conflicts. Practical because manual addressing does not scale.
VERIFIED COMPETENCY MILESTONE
02
Walk the DORA steps
Explain Discover, Offer, Request, Acknowledge and identify which step failed from observable signs such as APIPA or missing offers.
VERIFIED COMPETENCY MILESTONE
03
Describe DNS hierarchy
Explain root, TLD, and authoritative servers, and how a recursive client request gets resolved across iterative referrals.
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot with commands
Use ipconfig, dhclient, nslookup, and dig to verify DHCP server addresses, leases, DNS answers, and to flush caches when needed.
VERIFIED COMPETENCY MILESTONE
