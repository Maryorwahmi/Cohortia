Module 4 › Chapter 3.4 › DHCP security risks and mitigations
Threats
  • DHCP spoofing: rogue server provides malicious network settings.
  • DNS poisoning: incorrect DNS responses direct users to malicious IPs.
These threats often appear as sudden changes in DNS servers handed to clients or mass redirects; they can also cause selective outages when clients cannot resolve names correctly.
Mitigations
  • Enable DHCP snooping on switches to trust only authorized DHCP servers.
  • Use secure DNS practices and monitor authoritative records for changes.
  • Capture traffic to verify which server responded and its MAC address.
Field playbook
If users report redirects: isolate a client, run nslookup to see which DNS server answered, capture DHCP packets to identify the server MAC, and check switch DHCP snooping tables before escalating to security.
