Module 4 › Chapter 3.4 › What is DHCP and why use it?
Definition

DHCP — Dynamic Host Configuration Protocol

Automates IP address assignment and delivers network parameters from a central server configured with scopes and leases.

Analogy
Think of DHCP as a hotel check-in desk that assigns room numbers and gives you the house rules for a stay.
Key Takeaway
DHCP makes address management scalable, but scope design and lease settings must match operational needs.
How DHCP works in practice
  • Server configured with one or more scopes (address pools).
  • Client broadcasts a request to find a DHCP server when it has no IP.
  • Server assigns an address plus subnet mask, gateway, DNS servers, and a lease time.
Concrete example
In a 200-seat lab, set a scope from 10.0.0.100 to 10.0.0.199 and exclude 10.0.0.150–10.0.0.155 used by reserved devices. Use a moderate lease time so idle machines return addresses quickly.
Common misconception
DHCP does not prevent static addressing; instead, it supports reservations and exclusion ranges so static devices remain stable while others use dynamic leases.
