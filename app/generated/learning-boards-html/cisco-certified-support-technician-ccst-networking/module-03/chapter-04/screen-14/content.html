Module 4 › Chapter 3.4 › Key Concepts — DNS
Hierarchy
Root → TLD → Authoritative servers direct queries to the source of truth for a domain.
Record types
A, AAAA, CNAME, MX, NS, PTR each carry specific mapping information used by different services.
Diagnostics
Use nslookup and dig, including direct queries to authoritative servers and the +trace option to visualize referrals.
Summary takeaway

DNS ties human names to addresses through a chain of authoritative sources; targeted queries and cache checks guide accurate troubleshooting.
