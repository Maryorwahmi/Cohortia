Module 4 › Chapter 3.4 › DNS resolution: recursive vs iterative queries
Process

Recursive client → Resolver and iterative server lookups

Resolver performs iterative queries when uncached, collecting referrals from root to TLD to authoritative server, then returns the final answer to the client.
Try: dig +trace www.cohortia.com to observe each referral step from root down to the authoritative server.
When caches cause trouble
If a resolver returns a stale IP, compare the answer from the authoritative server using dig @authoritative_server example.com to confirm whether the cache is outdated or the authoritative record itself is wrong.
Diagnostic commands
nslookup example.com           # quick lookup
dig example.com                # detailed output
dig +trace example.com         # shows iterative referrals
nslookup -type=mx cohortia.com # check MX records
Takeaway
Use authoritative queries to determine whether a cache or the source data is the problem, and use trace to observe iterative referrals.
