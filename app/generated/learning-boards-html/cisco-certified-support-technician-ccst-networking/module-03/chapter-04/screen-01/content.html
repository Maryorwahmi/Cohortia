DHCP and DNS Services

Learn how devices receive addresses and how names resolve to addresses. This chapter focuses on practical checks and common failures you will see in the field.

In this lesson
DHCP DORA, DHCP scope and lease management, DNS hierarchy, record types, recursive vs iterative resolution, and troubleshooting commands you can run now.
Coming up
Terminal demos for ipconfig, dhclient, nslookup and dig; practical scenarios such as APIPA and stale DNS caches.
Quick start
If a user cannot reach sites, check IP configuration first, then DNS. IP issues often show APIPA addresses; DNS issues often resolve with cache flush or direct dig queries.
Visual Concept
Services in the network
A small card view shows a DHCP server handing addresses and a DNS server responding to name queries. Think of DHCP like hotel check-in and DNS like a phone book.
DHCP
Auto-assigns IPs, gateway, and DNS to clients from a scope.
DNS
Resolves human names to machine addresses using hierarchical servers.
Troubleshoot
Use ipconfig, dhclient, nslookup, dig; watch for APIPA and stale caches.
