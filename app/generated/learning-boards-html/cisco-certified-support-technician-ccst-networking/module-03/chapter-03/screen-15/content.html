Module 3 › Chapter 3.3 › Key Concepts
IPv6
128-bit addressing, massive address space and protocol improvements over IPv4.
Hexadecimal
Addresses are written in hex groups; each hex digit equals four bits.
Shortening Rules
Omit leading zeros; compress the longest run of zero segments with '::' once.
Address Types
GUA (global), LLA (link-local), ULA (private), Multicast, Anycast.
SLAAC & EUI-64
Host forms LLA, solicits RAs, and combines prefix with IID generated via EUI-64.
DHCPv6
Used for stateful address assignment or stateless option provisioning like DNS.
Summary Takeaway
Learn to read prefixes and scope first — these clues tell you whether issues are local, internal, or global and guide the correct troubleshooting path.
