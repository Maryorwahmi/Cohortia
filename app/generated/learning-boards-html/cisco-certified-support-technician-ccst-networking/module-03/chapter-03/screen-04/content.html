Module 3 › Chapter 3.3 › Why IPv6?
From 32 bits to 128 bits
IPv6 increases available addresses dramatically and changes network operations.
Key advantage: address space
IPv4: ~4.3 billion addresses. IPv6: about 3.4 x 10^38 addresses — enough to avoid large-scale NAT for most designs.
Operational changes
Autoconfiguration becomes common (SLAAC), and link-local addressing is always present for local operations.
Common misconception
IPv6 isn't only longer addresses — it introduces new behavior like mandatory link-local addresses and different troubleshooting steps.
Key Takeaway

IPv6 gives huge address space and changes address management. Learn to spot scope and autoconfiguration as your primary troubleshooting signals.

Illustrative example
2001:0DB8:85A3:0000:0000:8A2E:0370:7334
This single address format already shows why hex and grouping matter. Shortening makes it readable.
Support technician angle
  • Look for FE80 addresses to diagnose local link issues.
  • If only LLA exists, check for router advertisements before suspecting routing.
  • Recognize GUA prefixes to determine global reachability.
