Hexadecimal groups and prefix length
Each hex digit is 4 bits; four hex digits make a 16-bit segment. Prefix length indicates how many leftmost bits are network bits.
Canonical example
2001:0DB8:85A3:0000:0000:8A2E:0370:7334
Practical note
Routers use prefix notation like /64 to tell hosts which bits form the network. SLAAC commonly relies on a /64 network prefix to combine with a 64-bit interface identifier.
Small conversion example
Hex to bits: DB8 = D(13) B(11) 8(8) → 1101 1011 1000 — each hex digit maps to 4 bits, which helps you verify prefix boundaries.
Support tip
  • Recognize common prefix markers like 2000::/3 for Global Unicast networks.
  • Expect /64 networks for SLAAC; if prefix length differs, autoconfiguration behavior changes.
