Practice & Verification
Hands-on exercises and safe command checks you can run in a VM.
Exercise: Shorten Addresses
Apply leading-zero omission and '::' compression once per address. Try three provided examples during the hands-on lab.
Mnemonic: remove zeros left-to-right, compress longest run
Safe Terminal Checks
# Windows (read-only)
netsh interface ipv6 show addresses "Ethernet"

# Linux (read-only)
ip -6 a show eth0
Do not add addresses on production systems. Use a VM or isolated lab.
Milestone
Shorten three addresses correctly and display IPv6 addresses in a terminal session on a test VM.
Safety Note
When adding or removing addresses, use virtual machines or understand the consequences. Prefer ULA ranges for testing.
