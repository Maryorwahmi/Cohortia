Unicast, Multicast, Anycast
Delivery semantics determine the address type and expected behavior when you troubleshoot reachability.
Unicast
Delivers to a single interface. GUAs start with 2000::/3, LLAs with FE80::/10, ULAs with FC00::/7.
Multicast
Delivers to all members of a group. Multicast prefixes start with FF00::/8.
Anycast
Assigned to multiple interfaces; routing delivers to the nearest one. Common for distributed services.
Quick reference
GUA: 2000::/3 • LLA: FE80::/10 • ULA: FC00::/7 • Multicast: FF00::/8
Scenario
If a host can ping a neighbor's FE80 address but not a GUA, the problem likely involves routing or router advertisements rather than the host's address configuration.
