Stateless Address Autoconfiguration
SLAAC allows hosts to form addresses autonomously after receiving router advertisements.
Step 1: LLA generation
Host generates a link-local address (FE80::/10), often using EUI-64.
Step 2: Router Solicitation / Advertisement
Host sends RS; routers reply with RA containing prefix and flags.
Step 3: Form global address
Host combines RA prefix (e.g., /64) with its 64-bit IID to create the GUA.
Example RA prefix
2001:DB8:ABCD:1::/64
A host receiving this RA will use the left 64 bits as the network portion and generate or reuse its 64-bit IID.
Misconception check
SLAAC does not always supply DNS addresses. Use DHCPv6 in stateful or stateless mode if DNS must be assigned centrally.
