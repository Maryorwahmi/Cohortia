GUA, LLA, ULA explained
Recognize prefixes and intended scopes to narrow troubleshooting quickly.
Global Unicast (GUA)
Typically start with 2000::/3. Routable on the internet when permitted by routing and policy.
Link-Local (LLA)
Start with FE80::/10. Auto-configured and essential for local link functions like ND and RS/RA.
Unique Local (ULA)
Start with FC00::/7. Private to an organization, not for global routing.
Real-world check
# Example display on a host fe80::21a:2bff:fe3c:4d5e/64 (Link-Local) 2001:db8:abcd:1::1234/64 (Global Unicast) fc00:db8::10/64 (Unique Local)
Troubleshooting tip
If a server has only a ULA and clients on the internet cannot reach it, that behavior is expected because ULAs are not globally routable.
