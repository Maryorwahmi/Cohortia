How RAs form the global address
Router Advertisements supply prefixes and flags that hosts use with their IID to create GUAs.
RA contains:
Network prefix, prefix length, and flags indicating SLAAC/DHCPv6 usage.
Host action
Combine RA prefix (left 64 bits) with IID (right 64 bits) to form a full address under SLAAC.
Example RA prefix
2001:DB8:ABCD:1::/64
The host will append its IID to this 64-bit prefix to create the GUA.
Troubleshooting hint
If a host has an LLA but no GUA, verify RAs are present and advertising a usable /64 prefix; also check RA flags for DHCPv6 requirements.
