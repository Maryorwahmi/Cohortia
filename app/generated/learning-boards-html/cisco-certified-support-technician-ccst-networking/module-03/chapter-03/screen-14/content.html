Safe add/delete examples
Use these commands only in a lab or VM. Prefer ULA addresses for tests.
Windows (example)
# View current IPv6 addresses
netsh interface ipv6 show addresses "Ethernet"

# Add a test ULA (requires admin)
# netsh interface ipv6 add address "Ethernet" FC00:DB8::10/64

# Delete test ULA
# netsh interface ipv6 delete address "Ethernet" FC00:DB8::10
Linux (example)
# View current IPv6 addresses
ip -6 a show eth0

# Add a test ULA (requires root)
# sudo ip -6 addr add FC00:DB8::10/64 dev eth0

# Delete test ULA
# sudo ip -6 addr del FC00:DB8::10/64 dev eth0
Post-check
After adding, re-run the view command to confirm the address appears. After testing, delete it and verify it's removed.
