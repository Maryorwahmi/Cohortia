Learning Objectives
Learn the concepts, then practice configuration and verification.
Bloom: Learn → Understand → Apply → Master
01
Explain IPv6 necessity
Describe why IPv6 replaces IPv4 and list advantages like larger address space and built-in IPsec support.
Mnemonic: timeline of address exhaustion → IPv6 launch
VERIFIED COMPETENCY MILESTONE
02
Read and shorten addresses
Use hexadecimal groups, omit leading zeros, and compress zero runs with '::' only once.
Mnemonic: drop zeros, compress longest run
VERIFIED COMPETENCY MILESTONE
03
Identify address types
Differentiate Unicast, Multicast, and Anycast and recognize GUA, LLA, and ULA prefixes.
Mnemonic: scope from local (FE80) to global (2000)
VERIFIED COMPETENCY MILESTONE
04
Understand SLAAC & EUI-64
Explain how a host forms a link-local with EUI-64 and builds a global address after receiving a router advertisement.
Mnemonic: MAC → EUI-64 → IID + RA prefix
VERIFIED COMPETENCY MILESTONE
