Module 3 › Chapter 3.3 › SLAAC vs DHCPv6
Compare configuration models
SLAAC = stateless host-driven. DHCPv6 = central server-driven or stateless DNS provisioning.
SLAAC
Autoconfigures addresses using RA prefixes and IIDs. No server state required.
DHCPv6 (Stateful)
Server assigns addresses and keeps lease state. Useful for strict control.
DHCPv6 (Stateless)
Provides configuration like DNS while addresses are SLAAC-derived.
Diagnostic example
If hosts have GUAs but no DNS, DHCPv6 stateless mode or DNS settings are likely missing — check DHCPv6 reachability and RA flags.
Best practice
Use SLAAC for scale and simplicity; add DHCPv6 when you need centralized options like DNS assignment or inventorying addresses.
