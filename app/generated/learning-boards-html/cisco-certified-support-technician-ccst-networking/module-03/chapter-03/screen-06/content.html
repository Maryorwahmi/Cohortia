Two rules to shorten safely
Omit leading zeros inside segments. Compress the longest sequence of all-zero segments once with '::'.
Rule 1: Omit leading zeros
0DB8 → DB8; 0000 → 0
Rule 2: Compress longest zero run
Replace a contiguous set of all-zero 16-bit segments with '::' once per address.
Pitfall
Using '::' more than once is invalid and creates ambiguity.
Worked example
Original: 2001:0DB8:85A3:0000:0000:8A2E:0370:7334 Step 1: Omit leading zeros → 2001:DB8:85A3:0:0:8A2E:370:7334 Step 2: Compress largest zero run → 2001:DB8:85A3::8A2E:370:7334
