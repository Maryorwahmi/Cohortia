Module 4 › Chapter 4.3 › Diagnosis Scenario
Scenario breakdown
Client supports 802.11ac but the AP is using 2.4 GHz only. 802.11ac achieves best speeds on 5 GHz, so this mismatch likely limits throughput.
Follow these checks: confirm AP band support, scan 2.4 GHz channel congestion, measure signal strength, and verify security settings do not throttle performance.
Best corrective action
Enable the 5 GHz band on the AP so the 802.11ac laptop can connect at higher speeds. If 5 GHz is already enabled, ensure the laptop preferred band is set or move it closer to improve link quality.
Why not replace the AP?
If the AP supports 5 GHz, replacing it is unnecessary. Adjusting the band configuration is simpler and faster.
