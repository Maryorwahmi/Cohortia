Module 4 › Chapter 4.3 › Router Configuration
Step-by-step
  1. Connect via Ethernet and open the router web interface at the default IP.
  2. Change the default admin username and password immediately.
  3. Set a unique SSID and enable WPA2‑PSK or WPA3‑Personal with a strong passphrase.
  4. Enable both 2.4 GHz and 5 GHz bands if supported.
  5. Run a channel scan and set a non‑overlapping 2.4 GHz channel if needed.
Tools and test
Use a smartphone Wi‑Fi analyzer or desktop tool to view neighboring networks and channel usage. After configuration, test device connectivity and open a few websites to confirm throughput.
Safety note
Do not reuse default credentials. Use unique, strong passphrases to reduce the risk of unauthorized access.
Try this

After saving settings, observe if high‑bandwidth devices connect on 5 GHz automatically for better performance.
