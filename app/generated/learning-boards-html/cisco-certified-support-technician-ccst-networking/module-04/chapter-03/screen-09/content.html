Module 4 › Chapter 4.3 › Wireless Security
Protocol history and status
WEP is insecure and obsolete. WPA2 with AES is the current standard for many deployments. WPA3 provides stronger protections and improved resistance to brute‑force attacks.
WPA2‑Personal
Uses a shared passphrase; suitable for homes and small offices.
WPA2‑Enterprise
Uses 802.1X and RADIUS for individual user authentication; recommended for larger organizations.
Practical guidance
Always enable the strongest available encryption. Replace default credentials. For businesses, use Enterprise mode to enable per‑user credentials and centralized authentication and logging.
Common mistake
Leaving default router credentials or using outdated WEP leaves the network open to compromise.
Key Takeaway

Upgrade to WPA2 or WPA3 and prefer 802.1X enterprise authentication where possible.
