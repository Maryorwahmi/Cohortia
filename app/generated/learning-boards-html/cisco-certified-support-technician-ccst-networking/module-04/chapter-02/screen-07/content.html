Process Flow

Flood, reply, learn

1 • Receive
Record source MAC and ingress port.
2 • Flood
Send to all ports except ingress when destination unknown.
3 • Reply
Destination replies, allowing learning of its MAC.
4 • Forward
Update table and forward future frames to the correct port only.
Example
If Host X is powered on but never sends traffic, the switch may never learn Host X's MAC and will flood frames intended for it. Ensure hosts generate traffic or use static entries if necessary for critical devices.
Check
Use the switch's MAC table command to confirm learning and look for port mismatches or table exhaustion which can cause prolonged flooding.
