Command

show ip route (illustrative)

A routing table shows connected, static, and protocol-learned routes and the next hops or interfaces to reach them.

Router# show ip route
Codes: C - connected, S - static, O - OSPF
C 192.168.1.0/24 is directly connected, Gig0/0
S 10.0.0.0/24 [1/0] via 192.168.1.254
O 172.16.0.0/16 via 10.0.0.2, 00:00:12, FastEthernet0/1
Practical notes
Connected routes show networks attached to router interfaces. Static routes are configured by admins. Protocol routes are learned dynamically. When troubleshooting, confirm the route type and the next hop shown in the table.
Check
If external destinations are unreachable, check the host default gateway and the router's routing table for a suitable route or default entry.
