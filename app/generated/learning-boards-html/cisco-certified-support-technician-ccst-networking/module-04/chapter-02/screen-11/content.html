Step-by-step
  1. Run ipconfig /all or ip a to find the host MAC and default gateway.
  2. Run arp -a to see IP-to-MAC mappings your host knows.
  3. On the switch, run show mac address-table to find which port learned the MAC.
  4. On the router, run show ip route to confirm a route to the destination network.
Common mistake
Assuming the router is the issue before confirming local Layer 2 connectivity. If ARP or the MAC table is missing entries, fix local learning first.
Practical tip
Follow the order: host → ARP → switch → router. This isolates the problem with minimal guesswork.
