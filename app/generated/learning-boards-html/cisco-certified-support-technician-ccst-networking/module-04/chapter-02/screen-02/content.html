Learning Objectives

Four focused outcomes to guide your study and hands-on checks.

Bloom: Learn → Understand → Apply → Master
01
Device identification
Differentiate hub, switch, router

You will name each device's OSI layer and describe how it forwards traffic. Recognizing these roles prevents misconfigured networks and poor device choices.

VERIFIED COMPETENCY MILESTONE
02
Domains
Explain collision and broadcast domains

You will explain how hubs create large collision domains, how switches isolate collisions per port, and how routers separate broadcast domains. This helps with capacity planning and segmentation.

VERIFIED COMPETENCY MILESTONE
03
Switch mechanics
Describe MAC address tables

You will explain how a switch builds and uses a MAC address table to forward frames and when it floods unknown destinations. Understanding this reduces troubleshooting time when devices are not learned correctly.

VERIFIED COMPETENCY MILESTONE
04
Routing
Outline router forwarding and routing tables

You will describe how routers consult routing tables and use next-hop decisions to forward packets between networks, and why misconfigured gateways block external reachability.

VERIFIED COMPETENCY MILESTONE
