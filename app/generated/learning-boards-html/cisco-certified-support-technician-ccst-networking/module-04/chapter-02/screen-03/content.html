Applied checks and common mistakes

Four focused, repeatable verifications you can run during troubleshooting.

01 • Host inspection
Find MAC, IP, and default gateway

Use ipconfig or ifconfig to capture the host's MAC address and its configured default gateway. This maps the host into the network and points to the router for off-subnet traffic.

VERIFIED COMPETENCY MILESTONE
02 • ARP & MAC tables
Relate IP to MAC and ports

Check the ARP cache on the host and the MAC address table on the switch. This confirms whether the switch has learned the device and which port to expect traffic on.

VERIFIED COMPETENCY MILESTONE
03 • Router checks
Inspect routing table

Use a routing table check to verify that a router has a route to the destination network or a valid default route. Missing routes often cause unreachable external destinations.

VERIFIED COMPETENCY MILESTONE
04 • Mistake avoidance
Avoid hub and gateway errors

Know that a hub will worsen collisions and that an incorrect default gateway prevents reaching other networks. These are common, avoidable mistakes.
