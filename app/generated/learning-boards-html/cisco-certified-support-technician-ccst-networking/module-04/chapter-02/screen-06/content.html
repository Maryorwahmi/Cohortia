Definition

MAC address table (CAM)

The switch maps layer‑2 addresses to physical ports. This enables targeted forwarding and reduces unnecessary traffic on the LAN.

Learning
Switch records source MAC and ingress port when frames arrive.
Forwarding
If destination MAC known: forward to that port. If unknown: flood and learn from responses.
Example flow
Host A sends a frame to Host B. First time, switch floods because Host B's MAC is unknown. When Host B replies, the switch learns Host B's MAC and future frames go directly to Host B's port without flooding.
Key Takeaway

The MAC address table is essential to efficient forwarding; problems with learning result in flooding and extra traffic.

Troubleshooting hint
Check the switch's MAC table to confirm a host's MAC is learned on the expected port (for example, using show mac address-table on Cisco devices).
