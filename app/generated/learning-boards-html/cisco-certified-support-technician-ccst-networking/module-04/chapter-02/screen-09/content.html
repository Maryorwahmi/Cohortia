Definition

Router: Layer 3 forwarding

Routers examine IP addresses and consult a routing table to determine the next hop for packets. Each interface usually represents a different network and its own broadcast domain.

Example
If a workstation needs to reach another subnet, it sends traffic to its default gateway; the router then forwards the packet according to its routing table entries or default route.
Why it matters
Routers control the reachability between networks and prevent broadcasts from propagating globally. Correct routing table entries are essential for efficient and reliable forwarding.
Misconfiguration risk
A wrong default gateway on hosts or missing static routes on routers will block traffic to outside networks — check both host settings and router tables when troubleshooting.
