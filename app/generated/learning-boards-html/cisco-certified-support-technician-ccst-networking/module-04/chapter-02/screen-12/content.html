Inspect your host

Use host commands to find MAC, IP, default gateway, and ARP entries. Then relate those to the switch and router tables.

Ethernet adapter Ethernet:

Reflection
Why is the MAC called physical? Because it identifies the network interface at Layer 2, not a logical IP address configured at Layer 3.
Common error
Failing to find the gateway in ARP often means a wrong gateway address or a local link problem; don't jump to routing checks first.
