Module 4 › Chapter 4.1 › NIC Definition
Network Interface Card (NIC)
A hardware adapter that prepares data for transmission and receives incoming frames from the network medium.
Role
Converts device data to electrical or optical signals and vice versa. Provides a Layer 2 identifier: the MAC address.
MAC address
A 48-bit hexadecimal identifier burned into the NIC by the manufacturer, used by switches for local forwarding.
Common mistake
Assuming IP configuration alone proves connectivity. If the NIC/link is down, IP settings won’t help until the physical link is restored.
Key Takeaway

The NIC is the device’s physical gateway to the network and its MAC address enables local frame delivery.

Concrete example
A workstation sends a file to a local server. The NIC attaches source and destination MAC addresses to frames and the switch uses those MACs to forward the frames to the server’s port.
Quick checks
  • Confirm NIC is enabled in the operating system.
  • Inspect link lights for activity; if dark, verify cable and switch port.
  • View the NIC’s MAC address for identification purposes.
