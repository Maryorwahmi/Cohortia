MAC address mechanics
How switches use MACs to forward frames within a LAN segment.
Definition
A 48-bit hexadecimal identifier assigned to each NIC used for local frame delivery.
Concrete example
A PC sends to a printer: the frame’s destination MAC matches the printer and the switch forwards only to that switch port.
Misconception
MAC addresses do not replace IP routing. Switches forward by MAC; routers forward by IP between networks.
Why this matters

Understanding MAC forwarding helps you focus troubleshooting on Layer 2 when local delivery fails.

Troubleshooting tip
  • Confirm the NIC’s MAC matches inventory if you suspect duplicate addresses.
  • Use switch MAC tables to see which port a MAC is learned on when tracing devices.
  • If frames are not reaching a device, verify NIC link lights and cable integrity first.
