Definition

Ethernet frame structure

Frames wrap packets with MAC addresses and a trailer for link-level delivery and error detection.

Ethernet Frame:
  [Ethernet Header]
    Destination MAC: 00:11:22:33:44:55
    Source MAC: 66:77:88:99:AA:BB
    Ethertype: IPv4
  [Payload]
    IP Packet
  [Trailer]
    FCS: 0x1a2b3c4d
Example
When sending off-subnet traffic, your NIC sets the frame destination MAC to the router’s MAC address.
Misconception
Believing MAC addresses travel unchanged across the internet. MACs are local and will be rewritten at each hop where re-encapsulation occurs.
Key Takeaway

Frames are link-local containers that allow switches to forward using MAC addresses and check for errors with FCS.
