Module 3 › Chapter 2.3 › HTTP Trace
Process Walkthrough

Client to Server — stepwise

1. Application
HTTP GET payload created by the browser.
2. Transport
TCP header adds source/destination ports and sequence number.
3. Internet
IP header supplies source and destination IP and TTL.
4. Data Link
Ethernet frame gets source/destination MAC and FCS trailer.
5. Physical
Frame converts to bits for transmission over the medium.
Key Takeaway
Follow header fields through each PDU to understand where and why data might be lost or modified.
Example contrast
If this were a DNS query using UDP, the transport PDU would be a UDP datagram lacking sequence and acknowledgment fields, changing how reliability is handled.
Self-reflection
