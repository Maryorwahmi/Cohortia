Module 3 › Chapter 2.3 › Quick Reference
Label PDUs
Annotate packet captures: name the PDU and the header field you will inspect.
Know device roles
Switch = MACs; Router = IPs and forwarding decisions; Host = full decapsulation.
Verify physical/link first
Frame corruption and link errors block higher-layer delivery—check them before blaming services.
Summary
These simple heuristics speed troubleshooting and reduce the chance of investigating the wrong layer.
