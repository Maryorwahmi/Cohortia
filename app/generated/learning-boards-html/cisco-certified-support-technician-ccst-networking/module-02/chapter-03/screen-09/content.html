Module 3 › Chapter 2.3 › Decapsulation
Process Flow

From bits back to application data

Each upward step validates and removes the layer-specific wrapper until the original payload is recovered.

Step 1 — Link
Reassemble bits into a frame, validate FCS, strip header/trailer, pass IP packet up if address matches.
Step 2 — Internet
Check destination IP, strip IP header, forward segment up to transport.
Step 3 — Transport
Check destination port, perform reassembly using sequence numbers, strip TCP header.
Step 4 — Application
Deliver payload (for example, the HTTP response) to the application process for presentation.
Key Takeaway
Each host layer inspects only what it needs and passes valid data upward; failed validation at an early step prevents delivery.
Example
A received Ethernet frame fails FCS: the NIC drops it and the OS never sees the IP packet. If the FCS passes but the IP address is not for this host, the frame can be ignored unless forwarding is intended.
Misconception
Intermediate devices like routers do not usually reassemble transport segments for the final application; they only need to reach the level required for their function.
