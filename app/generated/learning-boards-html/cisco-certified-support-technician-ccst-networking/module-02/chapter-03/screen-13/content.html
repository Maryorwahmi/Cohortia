Troubleshooting steps

Use encapsulation knowledge to pick the correct diagnostic layer and tool.

Physical/Link
Look for cable faults, interface errors, and FCS failures in captures.
Network
Inspect destination IP and routing table entries when packets do not reach remote networks.
Transport/Application
Check ports, retransmissions, and application-level responses when reachability is established but services fail.
Assessment example
Order of headers added during encapsulation from innermost to outermost: TCP Header, IP Header, Ethernet Header.
Common mistake
Assuming an intermediate router decapsulates to the Transport Layer during normal forwarding; it typically only decapsulates to the Internet Layer.
Practice drill: Given a packet capture with a dropped TCP connection, list the first three headers you would inspect and why. This habit builds fast, layered troubleshooting.
