Core Concept

IP Packet and routing fields

The IP header provides logical addressing and routing controls—key pieces routers examine to forward packets.

Key fields
Source IP, Destination IP, Protocol, Time To Live (TTL).
IP Packet:
  [IP Header]
    Source IP: 192.0.2.10
    Destination IP: 198.51.100.5
    Protocol: TCP
    TTL: 64
  [Payload]
    TCP Segment
Misconception
IP addresses do not identify physical interfaces; they identify logical network endpoints used for routing.
Key Takeaway

Routers use the destination IP in the IP header to make forwarding decisions and then re-encapsulate packets for the next link.

Visual
Source IP
Where the packet came from
Destination IP
Where it is headed
TTL
Limits packet lifespan
Contrast: The packet shown will be re-encapsulated at each hop into a new frame; the IP header persists across link changes until decapsulation at destination or inspection by a middlebox.
