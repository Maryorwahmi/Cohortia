Definition

Encapsulation as nested envelopes

Each layer adds control information. That information is tailored to the layer's function and travel scope.

Why headers matter
Headers carry routing, addressing, sequencing, and flow control data the higher layers do not provide.
Concrete example
An HTTP GET becomes a TCP segment (ports, sequence), then an IP packet (IPs, TTL), then an Ethernet frame (MACs, FCS).
Misconception
Headers are redundant. They are not — each layer adds unique control data needed for its role.
Key Takeaway

Encapsulation provides modularity: each layer can evolve independently while preserving communication correctness.
