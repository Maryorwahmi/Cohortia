Module 3 › Chapter 2.3 › Switch vs Router
Switch
Inspects MAC addresses in Ethernet frames to forward on the local segment. Uses MAC learning tables and does not need IP information to switch frames.
When to check a switch
Unreachable hosts on the same VLAN, incorrect MAC mappings, or unexpected flooding indicate Layer 2 issues.
Misconception
Switches do not resolve IP routing — they forward frames based purely on MAC tables.
Router
Decapsulates frames to read the IP packet and uses destination IP to determine the next hop. It then re-encapsulates the packet for the outgoing link.
When to check a router
Packets failing to reach remote networks, incorrect routes, or TTL expiry point to routing issues.
Practical tip
If a packet is dropped by a router, inspect the IP header and routing table rather than the transport ports for routing faults.
Example question: A host cannot reach an off-subnet server. The switch forwards frames correctly to the default gateway’s MAC. Where do you look next? The router’s routing table and the IP packet's destination address.
