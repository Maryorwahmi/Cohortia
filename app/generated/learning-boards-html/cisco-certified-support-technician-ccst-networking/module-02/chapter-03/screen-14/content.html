Layered Modularity

Encapsulation boundaries allow independent evolution of protocols and technologies at each layer.

Why it matters
You can upgrade link hardware or replace switching technologies without rewriting applications, because layer boundaries preserve expected interfaces.
Practice activity
Draw the encapsulation sequence for an HTTP GET and then for a DNS query using UDP. Identify only the transport differences.
Pro tip
When documenting network behavior, always name the PDU and the header field you inspected; it prevents cross-layer confusion.
Misconception
Believing encapsulation ties layers permanently. In fact, layers are intentionally independent and designed to interface cleanly.
Reflection: Which layer would you change to improve link speed without touching applications? (Data Link or Physical.)
