Learning Objectives

Four competency milestones for encapsulation and decapsulation.

Bloom: Learn → Understand → Apply → Master
01
Describe encapsulation

Explain how each layer wraps data with headers and trailers and why the process is modular.

Verified Competency Milestone
02
Identify PDUs

Name the PDU at each layer and recognize them in a packet trace or diagram.

Verified Competency Milestone
03
Explain header roles

Describe what fields like ports, IPs, MACs, TTL, and FCS do and where they live.

Verified Competency Milestone
04
Trace a full flow

Map an HTTP request from application to bits and then back to the receiving application, explaining decapsulation.

Verified Competency Milestone
Practice tip: While studying, draw the nested envelopes for a real packet capture. Label fields and note which device would inspect each header during forwarding.
