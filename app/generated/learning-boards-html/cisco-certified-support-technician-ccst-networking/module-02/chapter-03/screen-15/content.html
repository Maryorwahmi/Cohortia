Module 3 › Chapter 2.3 › Key Concepts
Encapsulation
Layers add headers and trailers as data moves down toward the physical medium.
Decapsulation
Headers and trailers are stripped in reverse order to deliver the application payload.
PDU names
Segment/datagram, packet, frame, bits — use them to choose the right diagnostic layer.
Final takeaway
Encapsulation and device responsibilities let you target problems efficiently: start from physical and move up layers only as needed.
