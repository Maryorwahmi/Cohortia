Core Concept

TCP segment structure

Transport headers identify application endpoints and provide reliability controls used by TCP.

TCP Segment:
  [TCP Header]
    Source Port: 49152
    Destination Port: 80
    Sequence Number: 1001
    Acknowledgment Number: 0
    Flags: SYN
    Window Size: 64240
  [Payload]
    HTTP GET /index.html
Example
An HTTP GET uses TCP so you will see source and destination ports plus sequence numbers in the TCP header.
Contrast — UDP
UDP keeps ports but removes sequencing and acknowledgments, making it connectionless and lower overhead.
Key Takeaway

TCP headers make ordered, reliable streams possible; inspecting ports and sequence numbers explains application behavior.
