Module 2 › Chapter 2.2 › TCP vs UDP
TCP — reliable, ordered
Connection setup, acknowledgments, retransmission, and flow control.
When used
Web browsing, file transfer, and email where data integrity matters.
Symptoms of problems
Retransmits, slow transfers, or sessions that stall indicate TCP issues.
UDP — fast, connectionless
No handshake, no retransmission; suitable for real-time traffic.
When used
Streaming, VoIP, and gaming where latency is more harmful than occasional loss.
Symptoms of problems
Dropped frames, audio stutter, or short glitches often point to UDP packet loss or congestion.
Example
A video conference using UDP shows dropped frames when the network is congested. TCP-based downloads would slow but recover via retransmission.
Key Takeaway

Match troubleshooting expectations to the transport protocol: speed vs reliability.
