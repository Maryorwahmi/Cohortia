Commands and purpose
A safe sequence to gather evidence.
ipconfig / ifconfig
Shows IP, subnet, gateway, and MAC. Use this first to confirm correct addressing.
ping
Uses ICMP to test reachability. Sequence: loopback, gateway, external IP, external hostname.
tracert / traceroute
Shows each router hop to the destination; helps locate the failing segment.
Safe command examples
ipconfig /all
ifconfig -a

ping 127.0.0.1
ping 192.168.1.1
ping 8.8.8.8
ping www.cisco.com

tracert www.cisco.com
traceroute 1.1.1.1
Interpretation tips
  • Loopback success means the local stack is functioning.
  • Gateway failure suggests local link or ARP problems.
  • External IP failure indicates routing or ISP issues.
  • Hostname failure but IP success points to DNS at the Application layer.
Key Takeaway

Follow the command sequence to collect evidence and narrow faults from local to remote.
