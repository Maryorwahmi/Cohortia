Module 2 › Chapter 2.2 › Internet Layer
IP — addressing & routing
IP packets are routed across networks; each packet is independent.
ICMP
Used for reachability tests and error messages; ping is the common ICMP tool.
ARP
Resolves local IPs to MAC addresses. If ARP fails, local subnet communication fails.
Command examples
ping 8.8.8.8
ping www.google.com
tracert www.cisco.com
traceroute 1.1.1.1
Scenario
If ping to 8.8.8.8 works but ping to a hostname fails, suspect DNS at the Application layer. If ping to gateway fails, suspect ARP or link issues at the Network Access layer.
Key Takeaway

Trace hops to find where packets stop and inspect ARP and interface state for local problems.
