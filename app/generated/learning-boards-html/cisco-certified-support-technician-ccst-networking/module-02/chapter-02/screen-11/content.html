Step-by-step
Run each command and make one observation sentence.
1
ipconfig / ifconfig — record IP, mask, gateway, MAC.
2
ping 127.0.0.1 — validates local stack.
3
ping — tests link and ARP.
4
ping 8.8.8.8 and ping www.cisco.com — compare IP vs name reachability.
5
tracert / traceroute — inspect hops and locate failure point.
Example command block
# Windows
ipconfig /all
ping 127.0.0.1
ping 192.168.1.1
ping 8.8.8.8
ping www.cisco.com
tracert www.cisco.com

# Linux/macOS
ifconfig -a
ping 127.0.0.1
ping 192.168.1.1
ping 8.8.8.8
ping www.cisco.com
traceroute www.cisco.com
Check your hypothesis
Write one sentence: what layer does each failing test point to, and what next step will you take?
Key Takeaway

Practice the sequence until interpretation becomes second nature; evidence over assumption wins in troubleshooting.
