Module 2 › Chapter 2.2 › Troubleshooting Workflow
Repeatable sequence
Follow these ordered steps to reduce investigation time.
1
Check physical link
Cables, link lights, Wi‑Fi association, and switch port status.
2
Verify interface config
Run ipconfig/ifconfig and confirm IP, mask, gateway, and MAC.
3
Ping sequence
Loopback → gateway → external IP → hostname to isolate the failing layer.
4
Traceroute
If external pings fail, trace the path to find the failing hop.
Example log
# Step 1: ipconfig shows IP and gateway
# Step 2: ping 127.0.0.1 OK
# Step 3: ping gateway FAILED → check cable/ARP
# Step 4: traceroute not needed until gateway responds
Common mistake
Jumping to service configuration changes before confirming link and addressing increases troubleshooting time.
Key Takeaway

Document each step and the outputs; evidence-driven diagnosis is faster and safer.
