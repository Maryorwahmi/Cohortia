Module 2 › Chapter 2.2 › Quick Reference
Layer → Protocols
Application: HTTP, DNS. Transport: TCP/UDP. Internet: IP, ICMP, ARP. Network Access: Ethernet, Wi‑Fi.
Command → Layer
ipconfig/ifconfig → Network Access, ping → Internet, tracert/traceroute → routing path.
Diagnosis shortcuts
Ping IP ok + ping name fail → DNS. Ping gateway fail → ARP/link. Use traceroute to find hop failures.
Quick summary

Keep protocol and command mappings top of mind and follow the layer-first troubleshooting order for faster results.
