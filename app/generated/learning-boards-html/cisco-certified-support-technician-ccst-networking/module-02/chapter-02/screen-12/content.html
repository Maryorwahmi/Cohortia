Module 2 › Chapter 2.2 › Key Concepts
TCP/IP Model
A practical four-layer model used for real-world protocol mapping and troubleshooting.
Layer-to-tool mapping
Use ipconfig/ifconfig, ping, and traceroute where each maps to the layer being tested.
TCP vs UDP
TCP = reliability and order; UDP = speed and low overhead. Expect different failure modes.
Summary

Use the model and tools together: test layer-by-layer, read outputs carefully, and form a clear hypothesis before acting.
