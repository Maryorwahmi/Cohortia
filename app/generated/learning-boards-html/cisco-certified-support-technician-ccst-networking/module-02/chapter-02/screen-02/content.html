Learning Objectives
Skill-focused outcomes tied to practical troubleshooting
Bloom: Learn → Understand → Apply → Master
Practice maps directly to command-line actions and diagnosis.
01
Outline TCP/IP layers
List each layer and relate it to the OSI model. This helps you place faults quickly.
02
Identify layer protocols
Recognize HTTP, DNS, TCP, UDP, IP, ICMP, and ARP and why each matters for tests.
03
Explain TCP vs UDP
Describe reliability and use cases so you pick the right expectations during troubleshooting.
04
Use CLI diagnostic tools
Run ping, ipconfig/ifconfig, and tracert/traceroute and interpret which layer they test.
