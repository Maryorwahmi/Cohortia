Application Layer Protocols
User services and name resolution live here.
HTTP / HTTPS
Web page requests and responses; often human-visible errors indicate this layer.
DNS
Translates names to IPs; a failed hostname but reachable IP points to DNS problems.
Email: SMTP/POP3/IMAP
Mail delivery and retrieval protocols; errors can be configuration or connectivity issues.
SSH / FTP
Remote access and file transfer; authentication problems often surface here.
Concrete scenario
A user cannot reach example.com in a browser but can ping 93.184.216.34. This points to a DNS resolution failure at the Application layer rather than to routing.
Pro tip
Check whether a browser shows an HTTP error code before changing DNS settings; some 500-series errors indicate server-side application issues.
Key Takeaway

Application symptoms can be caused by lower-layer failures; verify connectivity first, then inspect service configs.
