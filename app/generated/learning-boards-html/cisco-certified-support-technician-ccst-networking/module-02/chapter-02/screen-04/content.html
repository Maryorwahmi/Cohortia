Module 2 › Chapter 2.2 › TCP/IP vs OSI
Layer mapping
Translate OSI theory into TCP/IP actions.
Application
Includes OSI Application, Presentation, Session. Protocols: HTTP, DNS, FTP, SMTP.
Transport
TCP and UDP provide end-to-end delivery behavior; choose tests accordingly.
Internet
IP, ICMP, ARP — addressing and routing across networks.
Network Access
Frames, MAC addresses, and physical media such as Ethernet or Wi‑Fi.
Concrete example
If a browser shows a DNS error, start with Application layer tests (resolve names). If ping to 8.8.8.8 succeeds but ping to a hostname fails, DNS is likely the issue.
Common mistake
Assuming a failed name lookup is a routing issue instead of a DNS configuration problem. Validate name resolution first.
Key Takeaway

Map symptoms to the layer and choose the command that tests that layer directly.
