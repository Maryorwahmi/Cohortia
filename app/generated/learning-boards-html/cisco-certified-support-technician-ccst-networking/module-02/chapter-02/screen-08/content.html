Module 2 › Chapter 2.2 › Network Access
Physical & Link Layer
Frames, MAC addresses, cables, and wireless signals.
MAC addresses
Local hardware addresses used to deliver frames within a LAN segment.
Link checks
Verify cable, switch port, or Wi‑Fi association before assuming higher-layer issues.
Practical checklist
Collect interface status, MAC address, ARP entries, and link lights as initial evidence. If interface is down, fix physical link before further tests.
Scenario
You have a valid IP but cannot ping the gateway. Check ARP table and cable first — the interface may be disconnected despite correct IP settings.
Key Takeaway

Local link failures are common; verify physical connectivity and ARP resolution before testing remote paths.
