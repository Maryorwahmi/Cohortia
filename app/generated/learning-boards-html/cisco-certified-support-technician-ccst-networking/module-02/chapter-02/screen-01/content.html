The TCP/IP Model
A compact, practical model used to reason about real network protocols and troubleshooting.

We treat the Application, Transport, Internet, and Network Access layers as your diagnostic roadmap. Each layer has typical protocols and command-line indicators you will use every day.

This lesson focuses on mapping commands to layers and using that map to pick tests that narrow failures quickly.

In this lesson
Identify layer-specific protocols and tools
Practice common CLI commands and interpret output
Apply a layer-first troubleshooting workflow
Concept map
How protocols and tools connect to each layer
Application
HTTP, DNS, FTP, SMTP — services users interact with. Failures often show as names failing to resolve or service errors.
Transport
TCP ensures reliable delivery; UDP prioritizes speed. Choose tests that surface retransmits or latency.
Internet
IP, ICMP, ARP — routing and addressing. Ping and tracert target this layer.
Network Access
Ethernet, Wi‑Fi, MAC addresses. Check link lights, cables, and interface configs here.
