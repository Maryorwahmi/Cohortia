Definition

Data Link Layer

Provides MAC addressing and frame delivery on a single LAN segment; switches operate at this layer.

Concrete example

Sending a print job to a local printer uses frames with the printer's MAC so switches forward to the correct port.

Common mistake

Expecting a switch to route between networks — switching is local, routing is inter-network and requires routers.

Sublayers & tools
LLC
Logical Link Control handles multiplexing and flow control.
MAC
Media Access Control manages access to the physical medium and uses MAC addresses for local delivery.
Key Takeaway
Check switch MAC tables and VLAN membership when local delivery problems occur.
