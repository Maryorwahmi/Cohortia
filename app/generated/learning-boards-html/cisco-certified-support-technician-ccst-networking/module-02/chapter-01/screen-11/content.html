No Internet — step mapping

A concise command checklist tied to OSI layers helps you find the fault quickly.

Common commands
ping www.example.com
ipconfig /all   (Windows)
ifconfig         (Linux/macOS)
arp -a
nslookup www.example.com
Use ping to test reachability. Use ipconfig/ifconfig to confirm IP settings. Use nslookup to test DNS resolution. Use packet captures when deeper inspection is needed.
Concrete mapping

Step 1: Physical — unplugged cable. Step 2: Data Link — switch port down. Step 3: Network — wrong IP or gateway. Step 4: Transport/Session — blocked ports or resets. Step 5: Application — DNS failing or web server error.

Key Takeaway

Run quick commands in order, map outcomes to layers, and escalate only when a layer's tests are inconclusive.

Check your understanding
Scenario
Ping fails with "Destination Host Unreachable" — which layer and next test?
Answer hint
Network Layer — check IP, mask, gateway and routing tables.
Misconception
Don't change application settings before confirming IP and DNS behavior.
