Architecture

Network Layer

Responsible for logical addressing and routing packets between networks using IP.

Concrete example

A packet to a remote web server carries source and destination IP addresses so routers across the internet can forward it hop-by-hop.

Common confusion

IP is for routing across networks; MAC addresses are for local delivery on a single segment.

Key Takeaway

If external connectivity fails but local access works, check IP config and routing before changing applications.

Device roles
Router
Operates at Layer 3; forwards IP packets between networks using routing tables.
Routing table
A lookup that maps destination networks to the next hop.
Troubleshoot hint
Use basic IP configuration checks first: correct IP, mask, and default gateway are essential.
