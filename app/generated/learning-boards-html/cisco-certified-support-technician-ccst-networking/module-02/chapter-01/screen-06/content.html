Comparison

TCP vs UDP

Two Transport Layer approaches: one prioritizes reliability, the other prioritizes low overhead and latency.

TCP
  • Connection-oriented
  • Retransmission and ordering
  • Flow control
UDP
  • Connectionless
  • No retransmission
  • Lower latency
Concrete example

File download uses TCP for reliable transfer; voice calls often use UDP to preserve low delay.

Common mistake

Assuming TCP is always best — real-time apps may break under TCP's retransmission delays.

When to choose
Reliability
Use TCP when delivery and order are essential.
Performance
Use UDP when low latency or multicast outweighs loss concerns.
Key Takeaway
Match Transport choice to the application's tolerance for loss versus delay.
