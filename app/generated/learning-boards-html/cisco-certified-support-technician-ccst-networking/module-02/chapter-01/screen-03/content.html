Practice Activities

Short, repeatable exercises mapped to verification milestones.

A
Layer flashcards

Match functions and protocols to layer numbers until recall is instant.

B
Trace a web request

Mentally or with a capture, watch headers added by Layer 4 and removed at the receiver.

C
Compare adjacent layers

Explain one example where a problem is Transport vs Network to practice distinctions.

D
Five-step troubleshooting

Run the physical-to-application checklist and map each test to a layer.

Milestone
Explain the root layer and next action in one sentence.
Mnemonic
"Please Do Not Throw Sausage Pizza Away" — a layer-number reminder.
Verification
Demonstrate one end-to-end test that confirms the suspected layer.
