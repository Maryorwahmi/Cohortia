Module 2›Chapter 2.1›Application, Presentation, Session
Definition

Layers 7–5

These layers prepare data for transport by providing services, formatting, and session management for applications.

Concrete example

A secure web session: HTTP at Application, TLS encryption at Presentation, and session negotiation to resume an interrupted stream.

Misconception

Developers sometimes assume formatting is an application responsibility; separating Presentation clarifies interoperability and encryption tasks.

Key Takeaway

When an app fails, test service behavior first, then check format and session state before blaming lower-layer connectivity.

Layer cards
Application (7)
HTTP, FTP, SMTP, DNS — services used directly by users.
Presentation (6)
Formatting, compression, encryption — ensures cross-system readability.
Session (5)
Dialog control, checkpoints, reconnect behavior for long interactions.
