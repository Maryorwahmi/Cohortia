Core Concept

What is the OSI Model?

A conceptual standard that divides network communication into seven layers to make functions and troubleshooting clearer.

Concrete example

When you request a webpage, headers and segments are added and removed as the data moves through layers, from HTTP at the top to bits on the wire at the bottom.

Common misconception

The OSI model is not a literal implementation rule; many protocols span layers, but the model is still useful for isolating responsibilities.

Key Takeaway

Use the OSI layers as diagnostic lenses to focus testing and narrow root causes quickly.

Seven-layer summary
7
Application — end-user services (HTTP, FTP, SMTP, DNS)
6
Presentation — formatting, compression, encryption
5
Session — dialogs, synchronization, checkpoints
4
Transport — segmentation, reassembly, reliability (TCP/UDP)
3
Network — logical addressing and routing (IP)
2
Data Link — MAC addressing, local frames, switches
1
Physical — cables, connectors, voltages, raw bits
