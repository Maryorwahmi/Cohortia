IP vs MAC
IP = routing between networks; MAC = local delivery on a LAN segment.
TCP vs UDP
TCP for reliability; UDP for low-latency or multicast use cases.
Start at Physical
Check cables and link lights before moving up the stack to avoid wasted effort.
Final takeaway

Use layer responsibilities, device mapping, and an ordered checklist to diagnose and resolve network issues efficiently.
