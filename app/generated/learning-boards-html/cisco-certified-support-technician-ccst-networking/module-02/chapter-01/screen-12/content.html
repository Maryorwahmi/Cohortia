Comparison

Where common devices operate

Map devices to layer responsibilities for effective diagnostics.

NIC / Port
Physical Layer — link, speed, and electrical/optical signals.
Switch
Data Link — MAC address learning and frame forwarding; VLAN segregation.
Router
Network — IP routing and next-hop decisions via routing tables.
Concrete example

A host with no link light requires Physical fixes; a host blocked by VLAN needs Data Link checks; a host with wrong gateway needs Network checks.

Key Takeaway

Identify the device in the path and test the layer it primarily serves to narrow your focus quickly.
