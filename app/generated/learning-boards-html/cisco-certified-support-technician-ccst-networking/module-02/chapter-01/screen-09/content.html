Module 2›Chapter 2.1›Physical Layer
Definition

Physical Layer

Specifies how bits are physically transmitted: cables, connectors, voltages, and encoding.

Concrete example

A cut cable or loose connector produces no link light and prevents any higher-layer communications from succeeding.

Key Takeaway

Start troubleshooting with the physical link: cable, connector, and link indicators are quick checks that can save time.

Common physical items
Cables
Ethernet copper and fiber optic types determine connectors and speeds.
Connectors
RJ‑45 and fiber connectors physically connect devices to the medium.
Link diagnostics
Check link lights, run cable testers, and confirm negotiated speeds for obvious faults.
