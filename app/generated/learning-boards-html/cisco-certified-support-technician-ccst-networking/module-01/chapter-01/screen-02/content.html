Learning Objectives
Learn the essential skills to describe, identify, and reason about basic networks.
Bloom: Learn → Understand → Apply → Master
01
Define a computer network
Explain the network's purpose: enabling communication and shared resources. You will link the definition to examples like shared printers and web access, so the concept is practical and not abstract.
Verified competency milestone
02
Identify network components
Name end devices, intermediary devices, and media by role and example so you can categorize equipment you encounter during troubleshooting.
Verified competency milestone
03
Differentiate network types
Distinguish LAN, WAN, WLAN, and PAN by scope and typical use so you can narrow problem domains appropriately in support scenarios.
Verified competency milestone
04
Explain network services
Describe how applications and services depend on the network and how that influences troubleshooting and design choices.
Verified competency milestone
