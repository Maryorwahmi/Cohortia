Module 1 › Chapter 1.1 › Switch vs Router
Switch
Forwards frames within the same LAN. Learns device locations and forwards only to the correct port.
Use when devices need local connectivity and minimal broadcast traffic.
Example: Connects workstations and a shared printer in an office.
Router
Forwards packets between separate networks and chooses paths to remote destinations.
Use when networks must communicate across different IP subnets or to the internet.
Example: Connects the office LAN to an ISP WAN link.
Quick test
If local devices can reach each other but not the internet, check the router or WAN link.
Mistake
Assuming a switch can solve inter-network routing problems.
Takeaway
Distinguish scope: switch = local; router = between networks.
