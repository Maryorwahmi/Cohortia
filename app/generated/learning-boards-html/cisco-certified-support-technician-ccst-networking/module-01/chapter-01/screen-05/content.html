What are end devices?
Devices that originate or terminate network traffic and that users interact with directly.
  • Examples: desktops, laptops, smartphones, tablets, printers, IP phones, smart devices.
  • Role: create or consume data, run applications, and present results to users.
  • Troubleshooting focus: check device settings, physical connection, and local firewall or drivers first.
Scenario
A user cannot reach a shared drive. Start by checking the user's device network status, IP address, and whether the server is reachable by ping or file explorer before changing server settings.
Misconception
An access point or switch is not an end device; they forward traffic. Treat them as intermediary equipment when tracing paths.

Key takeaway
Start troubleshooting at the end device: confirm it is powered, connected, has the correct IP settings, and can reach simple services.
