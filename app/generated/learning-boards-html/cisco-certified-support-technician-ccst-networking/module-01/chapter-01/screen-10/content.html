Module 1 › Chapter 1.1 › Troubleshooting Sequence
Step-by-step
  1. Device: power, IP settings, local reachability.
  2. Media: cable integrity, link lights, Wi‑Fi signal.
  3. Intermediary devices: switch port status, AP health.
  4. Scope: determine if issue is LAN-only or multi-site.
  5. Service: server or firewall configuration.
Example
User cannot print. Check device connectivity first, test the Ethernet cable, verify switch link, then check the print server or firewall rules if needed.
Pro tip: always reproduce the problem before changing configuration to avoid masking the root cause.
