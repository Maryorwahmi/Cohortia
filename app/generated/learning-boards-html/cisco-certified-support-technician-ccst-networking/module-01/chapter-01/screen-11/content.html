Module 1 › Chapter 1.1 › ipconfig / ifconfig
What to look for
  • IPv4 address: confirms device addressing.
  • Subnet mask: defines the local subnet size.
  • Default gateway: the router used to reach other networks.
  • DNS servers: used to resolve names to addresses.
Practical check
If the gateway is missing or the IP looks auto-assigned, check the cable, Wi‑Fi association, or DHCP server before changing server settings.
