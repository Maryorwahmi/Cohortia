Module 1 › Chapter 1.1 › Network Types
Local Area Network (LAN)
Connects devices within a small area like a home or office. High speed and locally managed.
Example: Office network connecting desktops and a file server.
Wide Area Network (WAN)
Connects LANs across cities or countries; often uses carrier services and has different cost and performance trade-offs.
Example: Company branches connected to central datacenter over an ISP link.
Wireless LAN (WLAN)
A LAN using wireless media for mobility inside the local area.
Example: Campus Wi-Fi for students and staff.
Personal Area Network (PAN)
A very small network connecting personal devices, commonly using Bluetooth.
Example: Phone paired to wireless headphones.
Diagnostic tip
Use the network type to scope your tests: wired-only failures suggest LAN or media, multi-site outages suggest WAN.
