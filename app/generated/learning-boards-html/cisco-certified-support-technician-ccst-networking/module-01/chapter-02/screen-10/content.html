Definition

Client-server architecture

Dedicated servers provide services; clients request them. Central management simplifies security, backups, and scaling for business networks.

Benefits
  • Centralized control and security
  • Easier backups and monitoring
  • Scalable by provisioning server resources
Concrete example

A file server stores company documents centrally. Workstations request files from the server, which enforces access control and performs backups.

Common misconception

That client-server always needs enterprise hardware. Small businesses can use a modest server or hosted service to gain centralized control without large capital expense.

Key Takeaway

Client-server centralizes services and control, helping with management and security. Protect servers with redundancy and backups.
