What it is

Mesh topology — redundant paths

Devices have multiple links so traffic can take alternate routes if a link fails. Full mesh connects every device to every other; partial mesh connects only key nodes redundantly.

When to use

Critical systems where uptime is paramount, such as WAN backbones, data center cores, or wireless mesh networks.

Illustration
Full mesh: maximum redundancy, maximum cost
Partial mesh: redundancy for critical links
Use case: backbone or key server clusters
Example

A cluster of core routers is partially meshed so if one router or link fails, traffic reroutes across alternate core links without interruption.

Trade-off: cost vs uptime
Common misconception

Mesh removes risk entirely. In reality, more links mean more configuration and potential for routing complexity; plan redundancy intentionally.
