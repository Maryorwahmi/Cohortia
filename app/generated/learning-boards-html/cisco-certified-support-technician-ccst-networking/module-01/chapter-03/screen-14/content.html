Key Concepts
Three compact cards summarize the essentials.
Protocol
A set of rules for formatting and exchanging data between devices.
Protocol Suite
Layered collection of protocols, e.g., TCP/IP, that split responsibilities to simplify networking.
Standards
Agreed specifications by organizations like IEEE, IETF, and ISO that enable interoperability.
Summary

Know what each protocol does, gather evidence with simple commands, then map symptoms to the correct protocol layer before making changes.
