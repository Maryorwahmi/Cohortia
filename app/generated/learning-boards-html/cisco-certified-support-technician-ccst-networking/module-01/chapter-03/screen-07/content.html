DNS: domain name resolution
Translates easy-to-remember names into IP addresses machines use to route traffic.
Resolver workflow
Client asks local resolver → resolver queries authoritative servers or cache → resolver returns IP address to client.
Hands-on check
Run nslookup or dig for a name. If the lookup returns no records or times out, the problem is in name resolution rather than transport.
Example
If pinging 172.217.160.142 succeeds but pinging google.com fails to resolve, DNS is the issue — the system cannot translate the hostname to that IP.
Key Takeaway

Use targeted name queries to determine whether DNS or another layer is causing access failures.
