ARP: IP to MAC mapping
Enables local delivery by resolving an IP address to a physical interface address on the same network segment.
How ARP works
Sender broadcasts an ARP request for an IP. The owner replies with its MAC. Sender caches the mapping for future frames.
Practical check
Run arp -a to view cached IP-to-MAC entries. Missing entries indicate an unresolved mapping or lack of recent communication.
Key Takeaway

ARP is local only. If you cannot reach a device on the same subnet, confirm ARP resolution before checking higher-layer protocols.
