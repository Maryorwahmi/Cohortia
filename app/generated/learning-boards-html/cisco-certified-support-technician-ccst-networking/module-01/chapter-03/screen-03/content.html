Skills and Practice
Structured checks and short command-line observations
Observe
Collect IP, DNS, and ARP evidence from the system using standard tools. Record the output before changing settings.
Hypothesize
Map observed symptoms to likely protocols: name resolution problems point to DNS; no IP indicates DHCP issues.
Test
Run targeted commands to confirm your hypothesis and then document the results for next steps.
Quick checklist
  • Can you ping the IP address? If yes, link layer and routing are likely OK.
  • Can you resolve the name with nslookup or dig? If no, investigate DNS configuration.
  • Does ipconfig or ip a show a valid address? If no, DHCP may be failing.
