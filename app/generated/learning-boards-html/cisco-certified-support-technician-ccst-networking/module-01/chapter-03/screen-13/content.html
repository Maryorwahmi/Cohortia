From Symptom to Fix
A repeatable hierarchy of checks to isolate protocol responsibility.
Layered checklist
  1. Link: is the physical/wireless link up?
  2. Address: does the host have a valid IP from DHCP?
  3. Name resolution: does DNS resolve hostnames correctly?
  4. Application: do protocols like HTTP respond correctly?
Key Takeaway

Apply the same checklist for every ticket: collect evidence at each layer, form a hypothesis, test it, and change configuration only when the evidence supports the fix.
