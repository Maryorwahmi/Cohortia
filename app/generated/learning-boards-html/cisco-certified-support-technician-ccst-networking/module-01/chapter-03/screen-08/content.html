DHCP: automatic IP configuration
A four-step broadcast exchange that provides IP, gateway, subnet mask, and DNS settings to clients.
Exchange steps
1. Discover: client broadcasts a request for an IP.
2. Offer: server offers an IP and lease details.
3. Request: client asks to accept the offered address.
4. Acknowledge: server confirms and assigns the lease.
Troubleshoot tip
If ipconfig or ip a shows an APIPA address instead of a valid one, the client did not receive an offer. Check DHCP server reachability and scope availability.
Common mistake

Assuming Wi‑Fi association implies IP configuration. A device can be linked at the link layer but still lack a usable IP if DHCP fails or is unreachable.
