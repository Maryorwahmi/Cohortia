Spotting misconfigurations
Map the symptom to the likely protocol and gather targeted evidence before making changes.
Symptom: name lookup fails
Likely area: DNS. Test with nslookup or dig to confirm resolver responses.
Symptom: no IP assigned
Likely area: DHCP. Check client lease state and server scope availability.
Symptom: local peer unreachable
Likely area: ARP or link layer. Inspect ARP cache and physical connectivity.
Key Takeaway

Always gather ipconfig/ip a, nslookup/dig, and arp -a output before changing settings. Evidence-driven fixes reduce downtime and missteps.
