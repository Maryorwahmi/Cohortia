Collecting evidence from your system
Run these commands to observe protocol behavior and save their output for troubleshooting.
Windows
ipconfig /all
nslookup google.com
arp -a
macOS / Linux
ip a
cat /etc/resolv.conf
dig google.com
arp -a
Reflection

Capture outputs, note whether DHCP assigned an IP, whether DNS names resolve, and if ARP entries exist for local peers. Use those notes to form your troubleshooting hypothesis.
