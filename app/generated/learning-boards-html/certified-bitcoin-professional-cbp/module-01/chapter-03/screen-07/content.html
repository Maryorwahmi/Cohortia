Module 2 › Chapter 1.3 › UTXO Model
What is a UTXO?
An unspent transaction output: a discrete output you can spend in a future transaction.
Analogy
Think of UTXOs as bills in a physical wallet. Spending consumes whole bills and returns change.
Misconception
Bitcoin is not debited from a single balance. Transactions consume UTXOs and create new ones.
Key Takeaway

Manage UTXOs consciously: they affect fees, privacy, and how much you must send as inputs and receive as change.

Concrete example: spending a 1 BTC UTXO
Transaction {
  inputs: [ { txid: "...", vout: 0, amount: 1.00000000 } ],
  outputs: [
    { address: "recipient", amount: 0.50000000 },
    { address: "change", amount: 0.49990000 } // fee = 0.00010000
  ]
}
The input consumed the full 1 BTC output. Two outputs were created: recipient and change back to the sender after a fee.
