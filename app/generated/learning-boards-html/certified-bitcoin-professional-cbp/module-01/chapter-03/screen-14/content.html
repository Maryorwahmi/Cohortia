Module 2 › Chapter 1.3 › Key Concepts
P2P Network
Decentralized peer connections relay transactions and blocks without a central server.
UTXO Model
Value is tracked as unspent outputs that are consumed and created by transactions.
Confirmations
Each block containing a transaction increases its security against reversal.
Takeaway

These concepts together explain how Bitcoin moves value trustlessly: peers propagate data, UTXOs carry value, and confirmations secure finality.
