How a wallet builds a transaction
Selection of inputs, outputs, and fee calculation determine the final shape of a transaction.
Step: Select inputs
Choose UTXOs whose total covers the amount plus fee.
Step: Create outputs
Add recipient output and change output if inputs exceed payment+fee.
Step: Choose fee
Fee reflects transaction size and miner priority; higher fee usually leads to faster inclusion.
Misconception check: Wallets do not 'split' a UTXO — they consume it as an input and create new outputs. Which UTXOs a wallet picks affects privacy and future fees.
Example transaction structure
Transaction {
  inputs: [
    { txid: "abcd...", vout: 0, amount: 1.00000000 }
  ],
  outputs: [
    { address: "recipient", amount: 0.50000000 },
    { address: "change", amount: 0.49990000 }
  ],
  fee: 0.00010000
}
Practical tip
Review your wallet's change addresses and input selection behaviour if you care about privacy or UTXO management.
