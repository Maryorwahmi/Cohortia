Module 2 › Chapter 1.3 › Node Types
Full Node
Downloads and verifies the complete blockchain, enforces consensus rules, and relays valid data.
Example: A user runs a full node to confirm received funds independently without trusting a third party.
Lightweight (SPV) Client
Holds minimal data and relies on full nodes for transaction proofs, trading strong verification for convenience.
Example: A mobile wallet that checks merkle proofs provided by a full node to confirm a transaction.
Miner
Selects transactions from mempool to assemble blocks and performs proof-of-work to find a valid block hash.
Example: A mining node chooses higher-fee transactions to maximize incentives when creating a candidate block.
Why these differences matter
  • Verification strength: full nodes provide independent validation, SPV clients do not.
  • Privacy: full nodes expose less metadata to third parties than lightweight clients that query remote nodes.
  • Incentives: miners prioritize transactions with higher fees from the mempool.
