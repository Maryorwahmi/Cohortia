Module 2 › Chapter 1.3 › Mining & Inclusion
How miners include transactions
Miners assemble candidate blocks from mempool transactions and perform proof-of-work to find a valid block.
Select transactions
Miners typically pick higher fee-per-byte transactions to maximize reward.
Find proof-of-work
Miners search for a valid block hash that satisfies the difficulty target.
Broadcast block
A valid block is broadcast; nodes validate it and add it to their chain, confirming the included transactions.
Example: first confirmation
If your transaction was included in the block a miner found and broadcast, nodes that accept that block record your transaction as having one confirmation. Each additional block added on top increases confirmation count and reduces the chance of reversal.
Practical note
For higher-value transfers, waiting for more confirmations lowers the risk from competing chains or reorganizations.
