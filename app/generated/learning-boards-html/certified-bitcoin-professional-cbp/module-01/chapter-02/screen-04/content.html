Module 1 › Chapter 1.2 › What is a cryptographic hash function?
Definition

Cryptographic hash function

Maps data of any size to a fixed-size digest. Key properties ensure integrity and tamper evidence on the blockchain.

Deterministic: same input, same output every time.
One-way: infeasible to reverse a hash to find the input.
Collision resistance: hard to find two inputs with the same output.
Avalanche effect: tiny input change yields an unpredictable different hash.
Key Takeaway

Hashes are integrity tools: they prove data has not been altered and provide compact identifiers in Bitcoin.

Analogy & example
Think of a hash as a tamper-evident fingerprint for data. If the fingerprint changes, the data changed. This is why blocks link together: the previous block's fingerprint is embedded in the next block header, creating an unalterable history.
Common misconception
Hashes are not encryption. Encryption is reversible with a key; hashing intentionally discards recoverable structure to provide one-way integrity.
Try this mentally
  • Pick a sentence and imagine a unique 256-bit fingerprint: change one word and the fingerprint becomes unrelated.
  • Consider how storing the previous fingerprint in the next block prevents undetected edits.
