Module 1 › Chapter 1.2 › Private → Public → Address
Hierarchy
Private key: a secret large random number. Control equals access to funds.
Public key: derived from the private key mathematically; used for verification and address derivation.
Bitcoin address: derived by hashing and encoding the public key; shared to receive bitcoin.
Privacy note
An address is shareable, but once you spend from it the public key may become visible and reduce privacy. Understand derivation to manage exposure.
Annotated chain
Secret
Private key — never reveal.
Derived
Public key — used to verify signatures and derive addresses.
Shareable
Bitcoin address — give to others to receive funds.
Practice tracing: for one private key, identify which artifacts you would store offline, which you might publish in a transaction, and which you can safely give to someone to receive bitcoin.
