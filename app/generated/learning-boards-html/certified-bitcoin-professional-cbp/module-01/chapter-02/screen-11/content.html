Module 1 › Chapter 1.2 › Alice sends 0.5 BTC
Step-by-step
  1. Create transaction referencing UTXOs and Bob's address for 0.5 BTC.
  2. Wallet uses Alice's private key to produce a signature for that transaction.
  3. Broadcast the transaction with Alice's public key and signature.
  4. Nodes verify the signature and check that referenced UTXOs are unspent and sufficient.
Common failure modes
Wrong private key, malformed signature, or already spent UTXOs will cause verification to fail and reject the transaction.
Concrete example card
Alice constructs: send 0.5 BTC to Bob's address
Wallet signs with Alice's private key → signature
Broadcast: transaction + Alice public key + signature
Nodes verify signature and UTXOs → accept or reject
Key Takeaway
Signatures bind authorization to a specific transaction and let the network validate ownership without revealing secrets.
