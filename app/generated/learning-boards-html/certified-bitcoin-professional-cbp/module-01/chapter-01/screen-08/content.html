Module 1 › Chapter 1.1 › Network Security
Architecture
Nodes, miners, and collective validation
Full nodes
Verify blocks and enforce rules; they do not need to mine to secure the ledger.
Miners
Propose blocks by producing proofs tied to computational effort.
Network
Broadcasts and independent verification let participants converge on a single chain.
Misconception
Decentralization does not equal immediate finality; security improves as more blocks confirm a transaction.
Concrete example
If an attacker tries to double-spend by creating a private chain, they must produce a chain with more cumulative work than the honest public chain to convince nodes. That requirement creates a practical economic barrier to successful double-spend attacks.
Key takeaway
Security is achieved by distributed validation plus costly proofs, not by secrecy or trust in a single party.
