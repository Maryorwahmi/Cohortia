Process Flow
Broadcast, block, secure
1. Broadcast: Transactions are shared with peers so many nodes can see them.
2. Block formation: Miners group valid transactions into a candidate block.
3. Proof production: A cryptographic proof tied to computational effort secures the block.
4. Chain linking: Each block references the previous, creating an immutable sequence.
Illustrative example
Imagine two competing blocks that include conflicting spends. Nodes choose the chain with the greater cumulative proof-of-work. To change an accepted spend, an attacker must produce a heavier chain, requiring control of most computational power.
Why that stops double-spend
Only one chain will become the network consensus. A second conflicting spend can only win if its chain outcompetes the honest chain, which is costly and unlikely under normal conditions.
