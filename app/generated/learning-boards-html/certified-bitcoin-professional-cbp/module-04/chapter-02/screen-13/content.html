Module 4 › Chapter 4.2 › Activity — Monitor a Transaction

Step-by-step

  1. Send a tiny transaction on testnet or a small mainnet amount and copy the TxID.
  2. Open a mempool-aware block explorer and paste the TxID to check status.
  3. Record the shown fee rate (sats/vB) and compare to current averages.
  4. Refresh periodically and note when the transaction moves to 'confirmed' and the block number.
  5. Watch confirmation count grow as new blocks are mined and reflect on delay sources.
Safety note

Use very small amounts to avoid loss during practice, especially on mainnet.

Example code-like display
TxID: 4b7f...a2c3
Status: unconfirmed
Fee rate: 25 sats/vB
Explorer estimate: 1-3 blocks
Key Takeaway

Monitoring a live transaction links the abstract lifecycle to real-world timing and fee decisions.
