Module 4 › Chapter 4.2 › Validation Checks
Core Concept

What nodes verify

  • Signature verification: confirm the spending keys authorized the transaction.
  • Unspent inputs: ensure referenced outputs are still available.
  • Format and rules: script and transaction structure comply with consensus rules.
  • Value check: inputs ≥ outputs + fee.
Example

If a wallet references an already-spent output, nodes will reject the transaction during the unspent input check and it will not enter mempools or be relayed further.

Common mistake

Assuming a malformed transaction will be mined; it will be rejected early and never reach miners' mempools.

Key Takeaway

Validation filters out invalid transactions so miners work only on correct ones.
