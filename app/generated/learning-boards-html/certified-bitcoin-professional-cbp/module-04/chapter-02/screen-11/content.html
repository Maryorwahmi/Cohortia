Module 4 › Chapter 4.2 › First Confirmation

Block validation steps

  • Verify proof-of-work and header linking.
  • Validate each transaction's signatures and inputs.
  • Ensure no consensus rules are violated.
Result

If valid, the node appends the block and marks included transactions as confirmed once.

Example

A miner finds a block including your tx and broadcasts it; nodes verify and then your tx shows 1 confirmation. If another competing block later replaces it, that confirmation may be lost.

Key Takeaway

One confirmation is meaningful but not definitive; additional blocks increase certainty.
