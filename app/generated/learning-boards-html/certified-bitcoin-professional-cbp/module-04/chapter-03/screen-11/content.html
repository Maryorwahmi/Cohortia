Module 4 › Chapter 4.3 › Common Mistakes
Mistake
Thinking an address contains the public key. In reality many addresses store only hashes until spend time.
Mistake
Believing P2SH permanently hides script logic. It delays revealing the redeem script until spending.
Mistake
Expecting Script to be Turing-complete. Its constrained design is a feature for security and predictability.
Clarification
Hash checks compare values but do not prove control; signature verification is required for proof of ownership.
Checklist
  • What does the output store? (pubkey hash or script hash)
  • What must the input supply? (pubkey, signature, or redeem script)
  • Which opcodes will run and what is the final expected value?
Takeaway
Use the checklist to avoid reasoning errors when auditing or constructing transactions.
