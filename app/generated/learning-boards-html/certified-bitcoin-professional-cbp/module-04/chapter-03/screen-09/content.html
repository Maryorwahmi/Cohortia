Hints & reflection
  • Order matters: signature then public key in scriptSig is the expected pattern.
  • OP_EQUALVERIFY both compares and enforces the equality; it aborts if mismatched.
  • OP_CHECKSIG requires a signature that was created for that public key and transaction context.
Why this helps
Walking the stack makes the verification logic explicit, which helps when auditing transactions or designing wallets that produce valid scriptSigs.
