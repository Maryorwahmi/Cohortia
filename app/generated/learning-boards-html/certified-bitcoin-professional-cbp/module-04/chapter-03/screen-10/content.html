How it works

The output contains HASH(redeemScript). The spender must provide a redeemScript and the data that satisfies it. Nodes verify the redeemScript hash matches and then execute the script with the provided data.

Concrete example
A wallet using a 2-of-3 multi-signature redeem script publishes its P2SH address. When funds are spent, the redeem script plus two signatures appear in the input and are verified.
Pro tip
When reviewing a spent P2SH output on-chain, you will see the redeem script only in the spending input, not earlier.
