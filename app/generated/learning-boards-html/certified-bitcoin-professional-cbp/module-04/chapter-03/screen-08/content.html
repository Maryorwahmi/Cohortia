Module 4 › Chapter 4.3 › Script Execution
Step-by-step
1. scriptSig runs
Pushes data such as signatures and public keys onto the stack.
2. scriptPubKey runs
Executes opcodes that consume and transform the data pushed by scriptSig.
3. Final check
If the final stack value is true, the spend is valid.
Concrete P2PKH trace
Initial stack: []
Push <Signature>  → [Signature]
Push <PublicKey> → [Signature, PublicKey]
OP_DUP             → [Signature, PublicKey, PublicKey]
OP_HASH160         → [Signature, PublicKey, HASH160(PublicKey)]
Push <PubKeyHash>→ [Signature, PublicKey, HASH160(PublicKey), PubKeyHash]
OP_EQUALVERIFY     → [Signature, PublicKey]  (if hashes equal)
OP_CHECKSIG        → [TRUE]  (if signature verifies)
Final result must be: [TRUE]
Check your understanding
If the public key hash does not match, what step fails? OP_EQUALVERIFY fails and the script aborts before signature verification.
