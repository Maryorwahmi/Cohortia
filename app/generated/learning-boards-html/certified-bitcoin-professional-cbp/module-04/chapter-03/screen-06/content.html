Module 4 › Chapter 4.3 › Bitcoin Script
What it is

Stack-based verification language

Script manipulates a stack of values with opcodes. It evaluates to true or false to allow or deny a spend. It is not Turing-complete by design.

Why limited?
Limiting features avoids infinite loops and ensures every node can validate quickly and predictably.
Key Takeaway

Treat Script as a verification DSL for spending rules, not a general-purpose programming language.

Concrete example

P2PKH uses a short sequence of opcodes to confirm ownership: duplicate the public key, hash it, compare to the stored hash, then check the signature. No loops or external calls are necessary.

Analogy
Script is like a checklist of verifications: each step must pass for the item to be approved.
Misconception
Expecting Script to support complex program logic. Instead, compose limited checks to express conditions.
