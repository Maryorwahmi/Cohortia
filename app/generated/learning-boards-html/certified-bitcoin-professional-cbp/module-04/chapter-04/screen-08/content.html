Module 5 › Chapter 4.4 › Block Propagation
Process

Mine → Broadcast → Validate → Relay

A mined block is broadcast to peers. Each peer checks proof-of-work, validates all transactions, and ensures the block fits on its best chain before accepting and relaying it.
Effects on the mempool
When a node accepts a block, it removes contained transactions from its mempool so they are no longer relayed as pending.
Example
A miner broadcasts a new block to peers. Those peers validate and relay, and the block reaches far-flung nodes which then update their local chain and clear included transactions.
Common misconception
Miners do not determine consensus alone. Nodes decide which blocks are valid and which chain is the correct one by independently validating rules.
Key Takeaway

Fast, validated block relay minimizes forks and keeps the network aligned on a single longest valid chain.
