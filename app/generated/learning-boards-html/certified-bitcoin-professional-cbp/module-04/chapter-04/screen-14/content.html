Module 5 › Chapter 4.4 › Node Distribution Activity

Activity: Reflect on Distribution

Observe a public node map to note geographic spread and operator concentration. Consider implications for censorship and outages.

Questions to ask
  • Are nodes clustered in one country or cloud provider?
  • Would a regional outage disconnect many nodes?
  • How would diversification improve resilience?
Reflection
Write or mentally note how you would balance running a node with hosting and connectivity choices to maximize decentralization.
Key Takeaway

Distribution matters. Use node maps to inform decisions about running or connecting to nodes to support network resilience.
