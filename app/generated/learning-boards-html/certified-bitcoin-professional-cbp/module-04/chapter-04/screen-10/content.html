Module 5 › Chapter 4.4 › Full Node vs SPV
Full Node

Trustless Verification

  • Stores full blockchain (hundreds of gigabytes).
  • Independently validates all transactions and blocks.
  • Provides best privacy — no third-party queries for your balance.
SPV Client

Lightweight Verification

  • Only downloads block headers and requests Merkle proofs.
  • Suitable for mobile or low-storage devices.
  • Relies on full nodes for inclusion proofs, so it has higher trust assumptions.
Decision guide
If your threat model requires independent verification and maximum privacy, run a full node. If you need convenience and low resource use for everyday transactions, an SPV client is a practical choice. Consider using both: run a personal full node at home and connect mobile wallets to it for improved privacy.
