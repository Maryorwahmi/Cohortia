Simplified JSON example
This conceptual JSON shows the key fields you'll encounter.
{
  "transaction_id": "...",
  "version": 1,
  "locktime": 0,
  "inputs": [
    {
      "previous_transaction_id": "...",
      "output_index": 0,
      "script_signature": "",
      "sequence": 4294967295
    }
  ],
  "outputs": [
    {
      "value": 60000000,
      "script_pubkey": ""
    },
    {
      "value": 20000000,
      "script_pubkey": ""
    }
  ]
}
Mapping exercise
Take a transaction from an explorer and find: transaction_id, each input's previous_transaction_id and output_index, each output's value and script_pubkey. Then compute fee by summing inputs and outputs.
Key Takeaway

The JSON is just a compact map of fields you can see in explorers. Practice mapping to build fluency.

Misconception
Script fields look complex but are only the locking conditions and signatures; you do not need to read every opcode to compute fees or identify inputs/outputs.
