Unspent Transaction Output (UTXO)
An output that has been received and not yet spent. The atomic unit wallets manage.
Transaction Input
Reference to a prior UTXO plus unlocking data (signature) that authorizes spending.
Transaction Output
A new UTXO specifying value and a script that defines who can spend it next.
Summary takeaway
Read transactions as a flow of discrete coins: inputs consume prior outputs, outputs create new coins, and signatures and fees govern authorization and inclusion in a block.
