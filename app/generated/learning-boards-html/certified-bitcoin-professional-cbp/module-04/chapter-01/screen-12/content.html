Module 4 › Chapter 4.1 › Common mistakes when constructing transactions
Top mistakes and fixes
  • Omitted change: compute inputs − outputs before signing.
  • Insufficient fee: check suggested fee per byte against network conditions.
  • Unit confusion: use satoshis for exact arithmetic.
  • Privacy leak: avoid combining unrelated UTXOs unless necessary.
  • Signature misunderstandings: each input needs a valid signature.
Example fix
Before broadcasting, list inputs and outputs in satoshis: if inputs total 1,100,000 satoshis and outputs total 900,100 satoshis, fee is 199,900 satoshis. If you expected a smaller fee, check whether change was omitted.
Quick checklist
Verify signatures present, verify change exists if expected, confirm fee per byte, and use consistent units.
