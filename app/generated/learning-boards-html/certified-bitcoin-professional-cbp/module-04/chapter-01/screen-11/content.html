Module 4 › Chapter 4.1 › Deconstructing a real transaction (guided)
Step-by-step walkthrough
  1. Choose a recent simple transaction (1–2 inputs, 2 outputs).
  2. Record the Transaction ID (TxID).
  3. For each input: note previous TxID, output index, and value in satoshis.
  4. For each output: note script type or address and value in satoshis.
  5. Sum inputs and outputs; compute fee = inputs − outputs and verify with explorer.
  6. Identify likely change output and explain your reasoning.
Unit clarity
Work in satoshis for exact arithmetic. 1 BTC = 100,000,000 satoshis. Converting mid-calculation can introduce rounding errors.
Check your understanding
After deconstruction, can you explain where each input came from and which output will be spent next by the sender?
Common error
Mixing BTC and satoshi units. Always compute fees using the same unit to avoid mistakes.
