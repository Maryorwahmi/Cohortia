Module 4 › Chapter 4.1 › Inputs and Outputs — how a transaction is formed
Transaction process
Follow these steps when forming a transaction.
  1. Select inputs. Wallet chooses UTXOs to cover amount plus fee.
  2. Build outputs. One output to recipient, optional change output back to sender.
  3. Calculate fee. Inputs − outputs equals miner fee.
  4. Sign inputs. Sign each input with the corresponding private key.
Note: More inputs increases transaction size in bytes, which often raises the fee required for timely confirmation.
Example
Inputs: 0.7 BTC and 0.4 BTC. Outputs: 0.9 BTC to friend, 0.1999 BTC change. Fee: 0.0001 BTC. The inputs reference previous TxIDs and specific output indexes.
Why inputs matter
They prove which previous outputs are being spent and determine the total available value.
Why outputs matter
They set the new ownership and are the UTXOs future transactions will reference.
Common mistake

Omitting a change output sends the leftover as an implicit fee. Always confirm outputs equal the intended recipient and change sums.
