Definition

Block header and nonce

The header encodes the previous block hash, Merkle root, timestamp, and nonce. Miners vary the nonce to create new hash attempts without changing transaction contents.

Header fields
  • Previous block hash
  • Merkle root of transactions
  • Timestamp
  • Nonce
Nonce in practice
Often incremented millions of times; if exhausted, miners change other fields like the timestamp or extra nonce in coinbase.
Concrete example
Start with nonce 0 and compute the header hash. If it does not meet the target, increment the nonce and try again. This repeats until success or alternative header fields change.
Practical tip
If nonce space is exhausted, miners adjust the coinbase transaction to create a new Merkle root and continue trying.
Key Takeaway

Understanding the nonce clarifies that mining is systematic brute force on header variants while block contents remain auditable.
