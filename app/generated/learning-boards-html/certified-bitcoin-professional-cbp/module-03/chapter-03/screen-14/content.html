Module 3 › Chapter 3.3 › Key Concepts
Mining
Verifying transactions, adding blocks, and introducing new bitcoins through Proof-of-Work.
Proof-of-Work (PoW)
A consensus algorithm requiring costly computation to find a hash meeting a target, easy to verify once found.
Nonce & Target
Nonce is the adjustable number miners change; the target defines the hash requirement that constitutes a valid block.
Hash Rate
The rate of hash attempts per second; higher combined hash rate raises the cost of attacking the network.
Mining Difficulty
Protocol-level difficulty that adjusts every 2016 blocks to keep average block time near ten minutes.
Block Reward & Halving
Block reward provides newly minted bitcoins; halving reduces that reward every 210,000 blocks.
Summary

Mining, PoW, and difficulty adjustment together provide a predictable issuance schedule and a high-cost security barrier that defends the Bitcoin ledger.
