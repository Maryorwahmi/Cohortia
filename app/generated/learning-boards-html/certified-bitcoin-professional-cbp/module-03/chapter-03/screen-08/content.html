Module 3 › Chapter 3.3 › Mining Difficulty & Adjustment
Mechanism

Difficulty adjusts every 2016 blocks

The protocol measures the time to mine the last 2016 blocks and raises or lowers the difficulty to steer average block time back toward ten minutes.

Why automatic adjust
Keeps issuance predictable and prevents rapid changes in confirmation rates.
Example
If hash rate doubles, difficulty will increase at the next adjustment so block timing returns to the target.
Contrast
Unlike centralized systems that can change issuance arbitrarily, Bitcoin uses a fixed algorithmic adjustment that keeps supply and confirmations stable over time.
Misconception
Difficulty is not chosen by miners; it's computed from observed block times by the protocol every 2016 blocks.
Key Takeaway

Difficulty adjustment stabilizes block timing and issuance despite changing hash rate, preserving Bitcoin's economic model.
