Module 3 › Chapter 3.3 › Hash Rate: Measuring Work
Definition

Hash rate and units

Hash rate is the number of hash attempts per second a miner or the whole network performs. Large-scale mining is measured in terahashes per second and beyond.

Why it matters
Higher network hash rate raises the cost and difficulty for attackers to outcompute the honest miners.
Example
If many miners add hardware, collective TH/s increases, prompting the protocol to raise difficulty to preserve block timing.
Security note
The network's enormous hash rate makes a 51% attack theoretically possible but practically very expensive to mount and sustain because the attacker must control more than half of the global hash rate.
Misconception
Higher hash rate does not directly mean more decentralization; it measures capacity, not distribution.
Key Takeaway

Hash rate is the defensive muscle of Bitcoin. More hashing makes attacks costlier and confirms how much real work secures the ledger.
