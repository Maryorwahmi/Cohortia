Process

Searching for a valid hash

  1. Collect transactions and compute the Merkle root.
  2. Create a block header with previous hash, Merkle root, timestamp, and nonce.
  3. Hash the header and check if the result meets the target requirement.
  4. If not, change the nonce and repeat until success.
Concrete example
Millions of guesses per second until a hash with required leading zeros appears.
Misconception
Validation is expensive — false. Verifying a found hash is quick for any node.

Key Takeaway

PoW makes block creation costly and verification cheap, forming a secure, decentralized lottery for block rights.
