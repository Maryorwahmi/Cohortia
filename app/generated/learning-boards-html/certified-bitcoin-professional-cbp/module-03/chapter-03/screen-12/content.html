Code Walkthrough
A simplified script builds a test string from sample block data and a nonce, then computes SHA-256 until the hexadecimal hash starts with the difficulty prefix.
import hashlib
import time

def find_proof_of_work(block_header, difficulty_prefix):
  nonce = 0
  start_time = time.time()
  print(f"Searching for a hash starting with '{difficulty_prefix}'...")

  while True:
    test_string = f"{block_header}{nonce}".encode('utf-8')
    current_hash = hashlib.sha256(test_string).hexdigest()

    if current_hash.startswith(difficulty_prefix):
      end_time = time.time()
      print(f"Found nonce: {nonce}")
      print(f"Resulting hash: {current_hash}")
      print(f"Time taken: {end_time - start_time:.2f} seconds")
      return nonce, current_hash
    nonce += 1

Experiment
Change the difficulty prefix from '0000' to '00000' to observe increased run time.
Safety note
Be careful with very strict targets; they may take a long time on a normal CPU.
What to observe
  • How many nonces it takes to find a match.
  • How elapsed time changes with difficulty prefixes.
  • Why faster hardware lowers time but doesn't change the brute-force nature.
Key Takeaway

The script makes the brute-force nature of PoW tangible: small changes to difficulty produce large changes in search time.
