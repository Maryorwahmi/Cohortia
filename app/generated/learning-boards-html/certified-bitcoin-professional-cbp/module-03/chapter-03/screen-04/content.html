Definition

Mining as verification and issuance

Miners gather transactions, form a block, perform expensive computation to find a valid hash, and broadcast the block to the network for verification.

Key points
  • Miners act as decentralized auditors and record-keepers.
  • Work performed secures the chain by making history costly to rewrite.
  • New bitcoins enter circulation only when a valid block is mined.
Analogy

Digital lottery that secures a public ledger

Imagine miners buying lottery tickets where each ticket is a hash attempt. Winning validates a set of transactions and earns a reward, but the process requires real computing work.

Example
Assemble mempool transactions into a block and search for a nonce that produces a hash meeting the target.
Common mistake
Believing miners simply create bitcoins like printing currency — issuance is protocol-driven and linked to work.
Key Takeaway

Mining secures the ledger by turning verification into costly, verifiable work tied to protocol issuance rules.
