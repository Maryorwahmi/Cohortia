Definition

Merkle Root & Nonce

Merkle root summarizes block transactions; nonce is a variable miners change to produce a valid header hash under proof-of-work.

Merkle root
A compact fingerprint of all transactions. Any change in the transactions changes the root and therefore the header hash.
Nonce
A number miners adjust repeatedly while hashing the header to meet the network difficulty. It is operational, not transactional.
Analogy & Example
Analogy
Think of the Merkle root as a single stamp that represents every line on a page, and the nonce as dials you twist until the stamp pattern fits a required template.
Common misconception
The nonce does not store transaction data; it is only a mechanism to vary the header hash during mining attempts.
Key Takeaway

Merkle root enables compact verification of transactions; the nonce enables miners to search for a valid header hash that satisfies proof-of-work.
