Simulating Block Hashing

Use the script to observe how a tampered transaction changes a block hash and breaks the chain link.

Starter code
<pre><code>import hashlib import json import time def calculate_hash(block_data): # Ensure data is consistently formatted and encoded block_string = json.dumps(block_data, sort_keys=True).encode('utf-8') return hashlib.sha256(block_string).hexdigest() # --- Block 1 Data --- block1_data = { "index": 0, "timestamp": time.time(), "transactions": [ {"sender": "Alice", "recipient": "Bob", "amount": 5.0}, {"sender": "Charlie", "recipient": "David", "amount": 10.0} ], "previous_hash": "0" * 64, # Genesis block has no previous hash "nonce": 0 } block1_hash = calculate_hash(block1_data) print(f"Block 1 Hash: {block1_hash} ") # --- Block 2 Data --- block2_data = { "index": 1, "timestamp": time.time(), "transactions": [ {"sender": "Eve", "recipient": "Frank", "amount": 2.5}, {"sender": "Grace", "recipient": "Heidi", "amount": 7.0} ], "previous_hash": block1_hash, # This links Block 2 to Block 1 "nonce": 0 } block2_hash = calculate_hash(block2_data) print(f"Block 2 Hash: {block2_hash} ") # --- Experiment: Tamper with Block 1 --- print("--- Attempting to tamper with Block 1 ---") tampered_block1_data = { "index": 0, "timestamp": block1_data["timestamp"], "transactions": [ {"sender": "Alice", "recipient": "Bob", "amount": 500.0}, # Changed amount! {"sender": "Charlie", "recipient": "David", "amount": 10.0} ], "previous_hash": "0" * 64, "nonce": 0 } tampered_block1_hash = calculate_hash(tampered_block1_data) print(f"Tampered Block 1 Hash: {tampered_block1_hash}") print(f"Does Block 2's previous_hash still match the tampered Block 1's hash? {block2_data['previous_hash'] == tampered_block1_hash}") </code></pre>
Pro tip

Use consistent serialization (sort_keys=True) when hashing so comparisons between nodes are reliable.

Explanation & Reflection
What you will observe
The printed original and tampered hashes will differ drastically. The comparison will show that Block 2's stored previous_hash no longer equals the tampered Block 1's hash, verifying how tampering breaks chaining.
Common mistake
If you serialize data inconsistently, hashes will differ even without tampering. Always keep formatting consistent when comparing hashes across nodes.
Key Takeaway

This simple script demonstrates the central immutability principle: a single change alters fingerprints and breaks the cryptographic chain.
