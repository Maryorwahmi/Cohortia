Core Concept

What is a Blockchain?

A ledger distributed across nodes where blocks are sealed and cryptographically linked into an immutable chain.

Distribution
Many nodes hold identical copies so there is no single point of control or failure.
Linking
Each block stores the previous block's hash, creating a chain that is easy to verify and hard to alter.
Immutability
Changing a block changes its hash and invalidates all subsequent links unless enormous computational work is redone.
Key Takeaway

Distribution plus cryptographic linking turns verification into the guardrail that prevents silent alteration.

Definition • Analogy
Analogy — Public notebook with stamped pages
Each page lists transactions. After sealing a page you write that seal on the next page. If someone tampers with an earlier page the seals don't match and everyone can see the alteration.
Common misconception
Blockchain is not synonymous with Bitcoin. Bitcoin is a prominent application of the blockchain idea, but other systems may use different consensus rules or access controls.
