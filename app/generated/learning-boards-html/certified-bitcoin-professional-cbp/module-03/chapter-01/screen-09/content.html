Definition

What is a Node?

A node is any independent computer that holds a copy of the blockchain and validates new blocks using protocol rules.

Full node
Stores and enforces all validation rules and keeps the entire blockchain history.
Light client
Relies on other nodes for full validation while retaining concise proofs for specific transactions.
Hierarchy • Replication
Concrete scenario
If a node is compromised and altered, other honest nodes will not accept its invalid chain. The compromised node's changes remain isolated unless it can convince a majority, which is practically infeasible for Bitcoin.
Misconception
Replication does not magically mean instant consensus. Nodes must still validate and follow protocol rules; replication supports resilience, not unilateral authority.
Key Takeaway

Multiple independent copies and collective validation turn data integrity into a network property rather than a single-party guarantee.
