Module 3 › Chapter 3.2 › Decode a Raw Transaction
Activity
Inspect a transaction in a block explorer
Find a recent confirmed transaction. Note TxID, status, amounts, fee, size/weight, inputs, and outputs. Trace inputs to their previous UTXOs.
1. Identify TxID and confirmation count.
2. Verify inputs total = outputs total + fee.
3. Determine likely recipient vs change address.
4. Compare fee relative to transaction size.
Example prompts
  • Which output is change and why?
  • How many confirmations does the transaction have and what does that imply about its security?
  • Does the fee per byte explain the observed confirmation speed?
Key Takeaway

Reading a raw transaction reinforces the UTXO model and shows how fees, size, and change affect confirmations.
