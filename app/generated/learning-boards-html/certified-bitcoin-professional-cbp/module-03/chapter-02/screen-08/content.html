Module 3 › Chapter 3.2 › How Miners Package Transactions
Architecture
Select → Pack → Header → Mine
Miners choose transactions up to the block weight limit, compute the Merkle Root, build the block header, and then search for a valid nonce.
Select highest-fee-per-byte transactions first
Compute Merkle Root for all transactions
Include Merkle Root in the block header
Concrete note
Block size limits constrain how many transactions fit per block. SegWit changed how weight is counted, increasing effective capacity while preserving protocol rules about what miners include in a header.
Misconception
Blocks are not unlimited. Throughput depends on block weight/size and the ten-minute average block interval, which together shape fees during high demand.
Key Takeaway

Miners optimize block contents to maximize fees while respecting size constraints; the Merkle Root in the header summarizes included transactions.
