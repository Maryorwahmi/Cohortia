Module 3 › Chapter 3.2 › Inputs, Outputs, and UTXOs
Hierarchy
Inputs ← UTXOs ← Outputs
Outputs created by transactions become UTXOs, which later transactions reference as inputs. Wallets select UTXOs to fund new outputs and fees.
Select UTXOs to cover payment + fee
Create outputs for recipient and change
Sign inputs to authorize spending
Concrete scenario
Your wallet spends a single UTXO of 1 BTC to send 0.25 BTC. It creates two outputs: 0.25 BTC to the recipient and 0.749 BTC back to you as change, with 0.001 BTC as fee. The original UTXO is now spent and no longer available.
Misconception
Don't assume balances are single numbers stored on-chain. Balances are computed from the set of UTXOs you control.
Key Takeaway

Inputs spend UTXOs; outputs create new UTXOs. Change is simply an output back to the sender.
