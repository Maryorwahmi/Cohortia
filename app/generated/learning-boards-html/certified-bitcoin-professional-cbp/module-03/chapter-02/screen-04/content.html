Module 3 › Chapter 3.2 › What is a Bitcoin Transaction?
Definition
Transaction as a signed record
A transaction consumes previous unspent outputs and creates new outputs. Inputs must be authorized with signatures and outputs specify recipient addresses and amounts.
Input = reference to UTXO + signature
Output = recipient address + amount (plus change)
Fee = inputs − outputs
Concrete example
Imagine spending a UTXO worth 0.8 BTC: send 0.1 BTC to a friend, return 0.698 BTC as change, leave 0.002 BTC as fee. Inputs must match total outputs plus fee.
Common misconception
Addresses are not accounts. Your balance is the sum of UTXOs you control. Spending consumes UTXOs and creates new ones.
Key Takeaway

Transactions reassign ownership by consuming UTXOs and creating outputs; signatures prove permission to spend.
