Module 4 › Chapter 3.4 › Key Concepts
Consensus
Process by which nodes agree on one valid ledger state.
Longest Chain Rule
Nodes prefer the chain with the most cumulative Proof-of-Work.
Confirmations
Each additional block on top increases finality and reversal cost.
Summary Takeaway

These concepts together explain how Bitcoin maintains agreement, measures transaction finality, and handles protocol change safely or, when incompatible, with real consequences.
