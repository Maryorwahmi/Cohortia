Module 4 › Chapter 3.4 › What is Consensus?
Consensus — precise claim
Agreement on a single, valid ledger state enforced by shared rules and Proof-of-Work.
Nodes validate blocks and follow the same rules so they accept the same history.
Proof-of-Work provides a measurable quantity to compare competing histories.
Temporary disagreement is allowed; eventual convergence is required for safety.
Key Takeaway

Consensus is a resilient agreement process that tolerates delays but requires honest majority work to secure the ledger.

Illustration: nodes and rules
Concrete example
Two nodes see different incoming transactions but validate according to the same rules and later converge to the same chain once cumulative work chooses the canonical history.
Common misconception
Consensus does not require perfect synchronization. Temporary forks are normal and resolved by chain selection.
Why it matters
Without consensus, irreversible transactions and reliable ownership would be impossible in a decentralized currency.
