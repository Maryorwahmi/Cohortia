Module 6 › Chapter 6.3 › Litecoin

Design highlights

  • Shorter block time aimed at quicker confirmations for payments.
  • Different hashing algorithm to alter mining characteristics.
  • Higher maximum supply compared to Bitcoin.
Practical note

Litecoin is often used as a testbed for features and demonstrates how small protocol changes alter user experience and infrastructure requirements.

Quick facts (illustrative)
Block time: ~2.5 minutes
Hashing: alternative algorithm
Supply: larger cap than Bitcoin
Key Takeaway

Adjusting protocol parameters changes performance and suitability for everyday payment use; evaluate these changes when comparing to Bitcoin.
