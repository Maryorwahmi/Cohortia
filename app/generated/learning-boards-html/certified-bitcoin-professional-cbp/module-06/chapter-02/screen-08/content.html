Module 6 › Chapter 6.2 › VASP Responsibilities
Architecture: Components and obligations
Onboarding
Collect KYC fields, verify documents, and classify customer risk.
Monitoring
Apply AML rules, score transactions, and route alerts for review.
Data sharing
Transmit Travel Rule fields securely between regulated counterparties.
Security
Encrypt identity data, enforce access controls, and maintain audit logs for compliance reviews.
Retention
Store records according to local retention rules so investigations can access transaction histories.
Key Takeaway

Design systems so compliance is built into every data flow, from onboarding to reporting.
