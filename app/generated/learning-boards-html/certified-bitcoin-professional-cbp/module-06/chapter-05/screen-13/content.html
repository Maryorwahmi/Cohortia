Evaluating projects as a CBP

Use a problem-first checklist to determine whether a blockchain solution is appropriate and which design fits best.

Checklist
  1. Define required properties: censorship resistance, privacy, programmability.
  2. Match to ledger type: public, Layer 1, or permissioned.
  3. Score risks: execution, economic, governance.
  4. Confirm tooling and audit maturity.
Decision exercise
Pick a use case and run the checklist: if public auditability matters most, prefer a public chain; if controlled access matters, prefer permissioned networks.
Key Takeaway

Match the tool to the job: the right ledger is the one whose properties solve the problem without unnecessary trade-offs.
