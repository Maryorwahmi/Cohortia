Process Flow

Decentralized Finance components

DeFi composes smart contracts into financial primitives: swapping, lending, and yield generation.

1
User supplies asset to protocol
2
Protocol pools assets in smart contract
3
Other users borrow or trade against the pool
This automated flow replaces a central counterparty with contract logic. Liquidity providers earn fees but may face impermanent loss if relative prices move.
Concrete example
Supplying a token to a lending protocol allows others to borrow. Interest rates adjust algorithmically based on supply and demand.
Risks
  • Smart contract bugs can result in loss of funds.
  • Impermanent loss reduces value for liquidity providers when token prices diverge.
  • Underlying asset volatility affects borrower's collateral value.
Key Takeaway

DeFi automates financial roles with contracts, offering access but shifting risk to code and market dynamics.
