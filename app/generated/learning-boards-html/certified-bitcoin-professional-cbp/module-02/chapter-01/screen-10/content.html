Compute hashes for strings and files

Use hashlib.sha256. Encode strings to UTF-8 bytes before hashing. Read files in binary and update the hasher in chunks for efficiency.

import hashlib

def calculate_sha256(data_string):
  data_bytes = data_string.encode('utf-8')
  sha256_hash = hashlib.sha256(data_bytes).hexdigest()
  return sha256_hash

# Determinism example
original = "Cohortia Bitcoin Course"
h1 = calculate_sha256(original)
h2 = calculate_sha256(original)
print(h1)
print(h2)

# Avalanche: small change
modified = "Cohortia Bitcoin course"  # lowercase 'c'
h3 = calculate_sha256(modified)
print(h3)
Practical notes
  • Always encode text to bytes consistently (UTF-8).
  • Read files as binary and hash in chunks to support large files.
  • Compare hex digests exactly; any difference indicates a different input.
Key Takeaway

This lab shows determinism and the avalanche effect clearly. Use consistent encoding to make comparisons reliable.
