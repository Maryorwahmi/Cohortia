Module 2 › Chapter 2.1 › One-Wayness
Definition

Pre-image resistance

Even with the digest visible, finding the original input is practically impossible because of computational cost. This supports safe publication of hash values for verification.

Why it matters: prevents attackers from reconstructing data from a published hash.
Practical use: publish a file hash; recipients can verify without risk of reconstruction.
Misconception check: hashing is not the same as encrypting data for confidentiality. Encryption is reversible with a key; hashing is intentionally not reversible.
Scenario
A software provider publishes a SHA-256 hash of an update file. Users compute the hash locally to confirm authenticity. The published hash does not reveal the file's contents, but it allows confident verification.
Key Takeaway

One-wayness lets you publish digests safely and still trust verification, because reversing the digest is impractical.

Common mistake
Treating a hash as encrypted data you can decrypt. Hashes are not reversible keys.
