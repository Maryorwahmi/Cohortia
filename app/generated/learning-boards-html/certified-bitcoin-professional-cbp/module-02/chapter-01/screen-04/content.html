Module 2 › Chapter 2.1 › What is a Hash Function?
Definition

Hash function = fixed-size fingerprint

A deterministic algorithm that compresses arbitrary input into a fixed-length digest. Used for quick comparisons and integrity checks.

Determinism: same input → same output every time.
Not reversible: you cannot reconstruct the original data from the hash.
Avalanche effect: tiny input changes produce large output changes.
Analogy and example
Analogy: fingerprint
Just as a human fingerprint identifies a person without revealing their entire life story, a hash identifies data without revealing the original content. If the fingerprint changes, the identity no longer matches.
Concrete example
Hashing a long document and a single sentence both produce fixed-length digests. If the sentence changes by one character, the digest changes completely, which reveals tampering.
Key Takeaway

Hashes are compact, deterministic fingerprints that reveal any change but do not reveal the original data.
