Module 2 › Chapter 2.1 › Verify a Download
Process

Three steps to verify integrity

  1. Obtain the publisher’s published SHA-256 digest from a trusted channel.
  2. Compute the SHA-256 digest of your downloaded file using a trusted tool or the provided Python script, reading the file in binary.
  3. Compare the published digest with your computed digest exactly; any difference indicates modification.
Practical checks: verify the digest source, prefer HTTPS or an authenticated channel, and canonicalize file bytes to avoid false mismatches.
Example
A software vendor publishes a SHA-256 string alongside a download. You compute the file's SHA-256 and find an exact match. You may now trust the file's integrity and proceed, assuming the digest source itself was trustworthy.
Key Takeaway

Comparing digests is a fast, reliable integrity check when both the digest and file bytes are handled consistently and trusted channels are used.
