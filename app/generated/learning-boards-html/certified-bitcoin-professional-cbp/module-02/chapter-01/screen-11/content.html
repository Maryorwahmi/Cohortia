Module 2 › Chapter 2.1 › Hashing vs Encryption
Comparison

Different goals, different guarantees

Encryption: reversible with a key. Use for confidentiality.
Hashing: one-way and deterministic. Use for integrity and identity.
Obfuscation: not reliable. Hashing is not a substitute for encryption.
Concrete scenario
If you need to hide file contents from everyone except authorized parties, use encryption. If you need anyone to confirm a file has not changed, publish a hash and let them verify by recomputing it.
Key Takeaway

Use encryption for secrecy and hashing for verification; they solve different problems.

Check your understanding
Which tool would you use to confirm a download's authenticity without revealing the file? Hashing.
