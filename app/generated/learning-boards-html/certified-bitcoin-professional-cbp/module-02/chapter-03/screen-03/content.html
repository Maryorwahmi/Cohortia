Module 3 › Chapter 2.3 › Practice Objectives
Explain the signing chain
Translate the steps into a spoken walkthrough you could deliver in an assessment.
01
Construct transaction
Identify inputs, outputs, change, and fee; this is the data later hashed for signing.
02
Hash the transaction
Use SHA-256 to produce a concise digest that is the target of the signature.
03
Sign with private key
ECDSA combines the private key and the transaction hash to create the signature locally.
04
Verify with public key
Nodes recompute the hash and check the signature against the public key to accept the transaction.
Assessment cues
Short prompts to use while explaining each step aloud.
  • Say the exact data hashed: inputs, outputs, amounts, and referenced UTXOs.
  • Explain that the private key never leaves the wallet and only produces a signature.
  • State the verification claim: valid signature equals authorized by the private key holder and unchanged data.
