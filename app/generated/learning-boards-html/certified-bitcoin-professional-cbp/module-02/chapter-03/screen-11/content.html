Comparison
Address (label) vs Public Key (verifier)

Understand the separate roles: addresses identify, public keys confirm signatures.

Address

A derived identifier used to receive funds. It is convenient and shorter than a public key.

Public key

Mathematically linked to the private key and used to verify signatures on the transaction hash.

Concrete scenario

When Alice spends an output she signs the transaction hash and may include her public key so a node can check the signature. The address helped pick that output, but the public key enables verification.

What is broadcast
Public key + Signature + Transaction
Practical note
Nodes need the public key
Verification requires the public key that mathematically corresponds to the signing private key. That key is included or derived so nodes can check the signature.
Misconception to avoid
An address alone is not the proof. The signature plus the public key are the cryptographic proof of authorization.
Check your understanding
Why might a public key only appear when an output is spent? Consider how addresses are derived and when verification becomes necessary.
