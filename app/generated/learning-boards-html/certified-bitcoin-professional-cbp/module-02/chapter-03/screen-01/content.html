Digital Signatures in Bitcoin
Prove authorization for a transaction without revealing your private key
Why it matters
Signatures let the network trust that only the owner can spend funds, enabling a decentralized ledger.
What it guarantees
Authenticity, integrity, and non-repudiation for each signed transaction.
Example
Alice's wallet signs a transaction hash for a payment to Bob. The resulting signature plus Alice's public key prove the payment came from Alice.
Common confusion
A signature is not encryption. The transaction is still visible to the network; the signature only proves who authorized it.
Explore Key Topics
Signing process
Transaction hash + private key + ECDSA produce a signature.
Verification
Network nodes check signature validity using the public key and the transaction hash.
Security benefits
Authenticity, integrity, and non-repudiation enable trustless validation.
