Process

Private key to Bitcoin address

1) Private key: 256-bit number
2) ECC (secp256k1) -> public key
3) SHA-256(public key)
4) RIPEMD-160(previous)
5) Add version byte
6) Double SHA-256 -> checksum
7) Append checksum and Base58Check encode -> address
Why the steps matter
  • Hashing shortens and obfuscates the public key before encoding.
  • The checksum detects common typing or copy-paste errors.
  • Base58Check avoids ambiguous characters for human use.
Concrete example

A legacy P2PKH address might look like 1A1zP1eW5QGefi2DMPTfTL5SLmv7DivfNa. It starts with '1' and uses Base58Check to remain compact and detect errors.

Misconception
An address is not the public key. It is a hashed, encoded form built for convenience and error detection.
