Architecture

secp256k1 one-way derivation

The private key is mapped to a public key by elliptic curve math. Computing the mapping is efficient; reversing it to discover the private key from a public key is computationally infeasible with current methods.

Forward: Private key -> ECC point (public key)
Reverse: Public key -> Private key (infeasible)
Security depends on computational limits, not theoretical impossibility.
Concrete example
When you sign, the signature is checked against the public key. Nodes verify signatures without needing or discovering your private key.
Misconception

'One-way' means secure today; it does not guarantee security against all future advances. Security relies on current computational hardness.
