Process Flow

Generate a key pair

  1. Collect high-quality entropy from hardware or secure OS sources.
  2. Construct a 256-bit random private key number.
  3. Derive the public key deterministically using secp256k1 ECC.
  4. Store the private key securely; publish the public key/address as needed.
Misconception
Weak randomness can produce predictable or colliding keys. Never rely on low-entropy sources for private keys.
Example: hardware wallet
A hardware wallet gathers entropy internally and generates the private key on-device so that the raw secret never touches the host computer. This reduces the risk of malware or poor OS RNG leaking the key.
Pro tip

Prefer wallets that document entropy sources and avoid exporting raw private keys when possible.
