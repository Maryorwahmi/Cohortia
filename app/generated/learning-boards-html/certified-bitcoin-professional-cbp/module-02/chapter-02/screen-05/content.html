Module 2 › Chapter 2.2 › Public vs Private
Comparison

Private Key

A secret 256-bit number used to create signatures that authorize spending. Must remain confidential and protected.

Risk: exposure leads to theft
Format: WIF or raw hex (long, secret)
Function: creates signatures to spend funds
Comparison

Public Key

Derived from the private key using ECC. Used to verify signatures and derive addresses for receiving funds.

Safe to share for receiving funds
Format: long hex, compressed or uncompressed
Function: verifies that a signature matches a private key
Concrete scenario
Publishing an address invites donations; publishing a private key invites theft. Always share addresses, never private keys.
Misconception
Some assume a public key can recover funds if a private key is lost. It cannot; recovery requires the original private key.
