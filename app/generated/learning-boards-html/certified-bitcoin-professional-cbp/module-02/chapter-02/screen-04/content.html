Core Concept

Asymmetric cryptography

A paired-key system where the private key creates digital signatures and the public key verifies them without revealing the private key.

Everyday analogy
Mailbox: public address receives mail; only the private key holder opens it and retrieves contents.
Common misconception
The public key cannot be used to spend funds; it only verifies signatures.
Key Takeaway

Sign with private; verify with public. This separation enables secure, verifiable ownership without secret sharing.

How verification works (visual cards)
1. Private key creates signature
2. Public key verifies signature
3. Nodes accept valid signatures
4. Invalid signatures are rejected
Concrete example
If you sign a transaction to send funds, the signature proves you authorized the spend without revealing your private key. Anyone can check the signature with the public key and confirm the transaction is genuine.
