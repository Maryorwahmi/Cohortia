Definition

Bitcoin address explained

An address is a compact, encoded representation derived from a public key that includes a checksum for error detection. It is what you share to receive Bitcoin.

Human-readable and shorter than raw keys
Includes checksum via double SHA-256
Uses Base58Check to avoid confusing characters
Practical note
When pasting or typing an address, a checksum mismatch prevents mistaken sends by flagging invalid addresses before broadcasting.
Key Takeaway

Share addresses to receive funds; the checksum helps catch human errors and prevents many accidental losses.
