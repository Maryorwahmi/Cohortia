Conceptual Python template

from bitcoinlib.keys import Key print("--- Bitcoin Key Pair and Address Generation Demonstration ---") # Step 1: Generate a Private Key private_key_object = Key() # Generates a new random private key private_key_wif = private_key_object.wif private_key_hex = private_key_object.private_hex print(f"1. Private Key (WIF format): {private_key_wif}") print(f" Private Key (Hex format): {private_key_hex}") # Step 2: Derive the Public Key from the Private Key public_key_hex = private_key_object.public_hex public_key_compressed_hex = private_key_object.public_compressed_hex print(f"2. Public Key (Uncompressed Hex): {public_key_hex}") print(f" Public Key (Compressed Hex): {public_key_compressed_hex}") # Step 3: Derive the Bitcoin Address from the Public Key bitcoin_address = private_key_object.address print(f"3. Bitcoin Address (P2PKH): {bitcoin_address}") print(" !!! SAFETY WARNING !!!") print("The keys generated here are for demonstration purposes ONLY. Do NOT use them for real Bitcoin transactions.")
What to observe
Note the different formats: WIF is a wallet-import format, hex is raw. Public keys can be compressed to save space. Addresses are shorter and include checksums.
Safety reminder

Do not run demonstrations that export usable private keys on machines connected to the internet unless you fully understand the risks.
