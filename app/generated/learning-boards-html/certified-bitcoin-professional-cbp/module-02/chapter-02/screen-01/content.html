Public-Key Cryptography: Securing Transactions

Understand how a secret, randomly generated private key creates a public key through elliptic curve math, and how that public key is transformed into a short Bitcoin address with built-in error checking. This is the foundation of ownership and signing on Bitcoin.

In this lesson
Key concepts: public vs private keys
Derivation: ECC and hashes
Safety: private key secrecy

Coming up: a clear derivation pipeline and a safe demo of the Python template used for conceptual practice.

Secure mailbox analogy
Anyone can send to the mailbox (public key). Only the private key holder can open it.
Private key: 256-bit random number
Public key: derived via secp256k1
Address: hashed + Base58Check encoded
Why start here

This chapter links identity and custody on Bitcoin. Learn these building blocks now so you can reason about transaction signing and wallet security later.
