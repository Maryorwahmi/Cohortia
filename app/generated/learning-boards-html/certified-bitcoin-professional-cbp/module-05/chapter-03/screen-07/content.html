Module 5 › Chapter 5.3 › Secure Generation
Steps
  1. Generate keys on an air‑gapped device or inside a hardware wallet.
  2. Write the seed phrase by hand; check each word carefully.
  3. Create multiple physical copies and store them in separate secure locations.
  4. Test recovery with a simulated seed on a spare device before adding real funds.
Example
Practice: Write a simulated 12‑word phrase, store one copy in a fire‑resistant safe and one in a bank safe deposit box. Do not store photos or cloud copies.
Common mistake
Using the internet to generate a paper wallet without ensuring the generator and the machine are offline.
Key Takeaway

Generation is a critical step: protect it by keeping the machine offline and creating multiple physical backups in separate locations.
