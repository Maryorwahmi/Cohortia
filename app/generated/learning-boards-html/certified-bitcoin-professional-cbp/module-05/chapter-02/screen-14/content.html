Key Concepts

Essential terms to remember from this chapter.

Software Wallet

A Bitcoin wallet implemented as a software application on a computer, smartphone, or accessed via a web browser.

Seed Phrase (Mnemonic)

A sequence of 12-24 words used to generate and recover all private keys within a deterministic wallet.

Password

Used to encrypt the wallet file on your device, protecting it from unauthorized access if the device is compromised.

Chapter Summary

Software wallets provide convenient Bitcoin access, but their security hinges on understanding and protecting your seed phrase and using strong passwords.
