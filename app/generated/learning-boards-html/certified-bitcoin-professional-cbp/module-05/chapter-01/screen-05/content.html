Core Concept Key Relationship
Private Key → Public Key → Address
Derivation is one-way; addresses are safe to share.
Architecture overview
Wallet generates a private key as a secret value used to sign transactions.
From the private key a public key is computed via a one-way process.
Addresses are derived from public keys and are the values you share to receive funds.
Concrete example
A wallet creates a private key, derives a public key, derives an address, and you share that address to receive bitcoin — the network records the resulting transactions to that address.
Common misconception

An address is secret by default. In fact, addresses are public; privacy depends on address reuse and wallet behaviors.

Annotated flow
Step 1 — Generate
Create a private key inside the wallet using a secure random source.
Step 2 — Derive
Compute the public key and then the address from the private key.
Step 3 — Share & Receive
Share the address to receive funds; do not share the private key or seed phrase.
