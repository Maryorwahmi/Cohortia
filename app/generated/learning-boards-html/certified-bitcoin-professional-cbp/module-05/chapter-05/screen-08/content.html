Watch-only vs Full-access

Choose watch-only for safe monitoring; use full-access when you must sign and broadcast transactions.

Watch-only
Contains public keys or master public key. Can display balances and incoming transactions but cannot spend funds.
Full-access
Holds private keys or seed. Can sign transactions and move funds; requires strict backup and storage practices.
Concrete organizational use
Monitor receipts with watch-only in the cloud while signing keys stay on offline hardware wallets in secure locations.
Key Takeaway

Use watch-only to separate visibility from control. Never assume monitoring equals spending capability.

Setup example
Export the master public key from an offline wallet and import into an online monitoring tool as watch-only.
Risk note
Sharing a public key with an improper path may reveal address correlations; apply hardened choices when privacy matters.
Misconception check
A watch-only wallet cannot sign. If you need to move funds, ensure private keys exist and are accessible under the planned workflow.
