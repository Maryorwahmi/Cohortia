BIP44: Derivation Path Structure

A five-part path naming convention that ensures interoperable address derivation across wallets.

m/44'/0'/0'/0/0
Purpose: 44' indicates BIP44.
Coin type: 0' for Bitcoin in the common registry.
Account: 0' groups a logical account (savings vs spending).
Change: 0 for external receiving addresses, 1 for change addresses.
Index: the individual address number within the chain.
Key Takeaway

When importing a mnemonic, matching the derivation path is essential to recovering the same addresses; mismatched paths are a frequent source of confusion.

Concrete scenario
Restore example
Restore the same 12-word mnemonic in Wallet A and Wallet B with BIP44 selected. You will see identical account and address lists.
Common error
Using a different purpose or coin type will yield different derived addresses and may hide funds until the correct path is chosen.
