Module 6 › Chapter 5.5 › BIP32 Structure
Definition

BIP32: HD Key Derivation

A standardized method to derive child keys from a master key and chain code, producing a deterministic tree.

Concrete example
From master key 'm' derive account 0 and account 1, each with many addresses using defined child indices.
Hardened vs non-hardened
Hardened derivation increases isolation between nodes and prevents certain public-key based derivations.
Misconception
Do not conflate the mnemonic with the derivation algorithm; BIP39 gives the words, BIP32 defines how keys are computed from the seed.
Key Takeaway

BIP32 ensures deterministic, interoperable key derivation; confirm hardened choices when sharing public keys or creating watch-only wallets.

Architecture: master key → accounts → addresses
Master
m (master private key + chain code)
Accounts
m/0', m/1' ... each account holds chains and addresses
Addresses
Child index produces receiving and change addresses within each chain
