Core Concept

Hierarchical Deterministic (HD) Wallet

A deterministic tree of keys derived from a single master seed simplifies backups and organizes accounts.

Key idea
Back up one mnemonic to recover every address generated by the wallet.
Concrete example
A single 12-word phrase can restore separate accounts for savings and daily spending, each with many addresses.
Common misconception
You do not need to back up each address's private key individually when using an HD wallet — the mnemonic is the canonical backup.
Key Takeaway

Treat the mnemonic as your single critical backup. If it is lost and no copies exist, you cannot recover derived keys.
