Module 5 › Chapter 5.4 › Receiving Bitcoin
Procedure

Generate address → Verify on device → Share

1. Use the companion software to request a receiving address.
2. The device derives and displays the address on its secure screen.
3. Compare the full address on-device with the app’s address before sharing.
Misconception: Assuming the app display is safe can lead to address substitution; the device screen is the trusted verifier.
Concrete example
Companion software shows bc1qxyz...; check that your device shows the exact same string before sharing. If malware changed the app’s address, the device will show the original address generated from your seed, revealing the mismatch.
Takeaway

Always use the hardware wallet screen as the authoritative source for any address you will receive funds to. Verification prevents silent redirection of funds.
