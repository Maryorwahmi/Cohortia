Module 5 › Chapter 5.4 › Setup Process
Process

Initialize: Generate seed, confirm words, set PIN

1
Generate seed
Device creates 12/18/24 word recovery phrase — write it down offline.
2
Confirm words
Device asks you to confirm selected words to prove they were recorded correctly.
3
Set PIN
Choose a non-trivial numeric code to protect local access to the device.
Common mistake
Photographing or storing the seed digitally exposes it to theft. Physical backups must be offline and multiple copies should be geographically separated.
Concrete example
When the device generates the 24-word phrase, you write each word on the recovery sheet. The device then asks for word 3, word 12, and word 20. If any word is incorrect, the setup fails until corrected. This confirms your written copy is accurate.
Takeaway

Initialization locks in both recovery and local protection. If you lose the seed, you lose access; if you choose a weak PIN, someone who steals the device might unlock it faster.
