Querying Key Vault Logs with Kusto Query Language (KQL)

Extracting Security Insights from Log Analytics Workspace

The Power of KQL

Kusto Query Language (KQL) allows you to perform powerful queries on your log data in Log Analytics Workspaces, enabling deep security analysis.

Query Breakdown

  • AzureDiagnostics: The primary table for diagnostic logs.
  • where ResourceProvider == "MICROSOFT.KEYVAULT" and Category == "AuditLogs": Filters for Key Vault audit events.
  • where OperationName contains "Secret": Narrows down to secret-related operations.
  • project TimeGenerated, OperationName, identity_claim_upn_s, clientIp_s, ResultType: Selects specific columns for clarity.
  • order by TimeGenerated desc: Sorts results by most recent events.
AzureDiagnostics
| where ResourceProvider == "MICROSOFT.KEYVAULT" and Category == "AuditLogs"
| where OperationName contains "Secret" // Filter for secret operations
| project TimeGenerated, OperationName, identity_claim_upn_s, clientIp_s, ResultType
| order by TimeGenerated desc
Key Takeaway

KQL is essential for extracting actionable security intelligence from raw log data, enabling detailed forensic analysis and threat hunting.
