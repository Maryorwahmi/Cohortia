Azure Monitor: The Foundation of Telemetry

Collecting and Analyzing Data from Your Azure Environment

What is Azure Monitor?

A comprehensive service for collecting, analyzing, and acting on telemetry data from your Azure and on-premises environments. It's the central hub for operational data.

Two Fundamental Data Types

  • Metrics: Numerical values describing system aspects at a point in time (e.g., CPU utilization, network traffic). Great for performance trending.
  • Logs: Structured or unstructured text data describing discrete events (e.g., user login, resource creation, errors). Essential for security auditing and threat detection.

Types of Logs Collected

  • Activity Logs: Management plane operations (who did what, when, where).
  • Diagnostic Logs: Resource-specific logs (e.g., web server logs, Key Vault access logs).
  • Azure AD Audit Logs: Identity-related events (user logins, password changes).

Logs Drive Security

For security auditing and threat detection, logs are paramount as they provide the detailed event history required for forensic analysis and identifying suspicious patterns.

Key Takeaway

Azure Monitor unifies telemetry, with logs being the critical data type for detailed security auditing and proactive threat detection.
