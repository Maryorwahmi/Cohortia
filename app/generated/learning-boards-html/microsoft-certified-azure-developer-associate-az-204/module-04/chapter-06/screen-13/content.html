Key Concepts

Essential Terms to Remember

Azure Monitor

Comprehensive service for collecting, analyzing, and acting on telemetry data (metrics and logs) from Azure and on-premises environments.

Metrics

Numerical values describing system performance or behavior at a point in time, useful for trending and threshold alerting.

Logs

Structured or unstructured text data describing discrete events, crucial for auditing and detailed security analysis.

These foundational components provide the essential visibility for detecting and responding to security events in your Azure environment.
