Configuring Diagnostic Settings for Azure Key Vault

A Step-by-Step Example for Critical Resource Logging

Why Key Vault?

Key Vault stores highly sensitive data. Auditing its access and operations is paramount for security and compliance.

Configuration Steps

  1. Navigate to your Key Vault in the Azure portal.
  2. Select "Diagnostic settings" under "Monitoring."
  3. Click "Add diagnostic setting."
  4. Give it a descriptive name (e.g., KeyVaultSecurityLogs).
  5. Under "Logs," select "AuditLogs" and "AzurePolicyEvaluationDetails."
  6. Under "Destination details," select "Send to Log Analytics workspace" and choose your workspace.

Ensuring Auditability

This configuration ensures that every operation on your Key Vault, from secret access to key creation, is logged and available for security analysis.

Key Takeaway

Configuring diagnostic settings for Key Vault to send AuditLogs to a Log Analytics Workspace is a critical step for securing sensitive assets.
