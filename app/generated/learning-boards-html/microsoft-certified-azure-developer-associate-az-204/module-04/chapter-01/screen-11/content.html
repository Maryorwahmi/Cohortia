Hands-on Activity

Creating an Azure App Service with System-Assigned Managed Identity

Using Azure CLI to deploy and secure a web app

Activity Overview

You will deploy a basic Azure App Service and enable a system-assigned managed identity for it using Azure CLI, then verify its existence.

  • •Create a resource group and App Service Plan.
  • •Deploy an App Service with --assign-identity flag.
  • •Retrieve and verify the Managed Identity's Principal ID.

Why This Matters

This hands-on experience demonstrates how to provision secure Azure resources from the start, integrating identity management directly into your deployment workflow.

  • •Learn practical secure deployment techniques.
  • •Understand the impact of --assign-identity.
  • •Prepare for credential-free access to other services.
Azure CLI Commands
# 1. Create a Resource Groupaz group create --name "az204-security-rg" --location "eastus"# 2. Create an Azure App Service Planaz appservice plan create --name "az204-security-plan" --resource-group "az204-security-rg" --sku "B1" --is-linux# 3. Create an Azure App Service and Enable System-Assigned Managed Identity# Replace <your-unique-app-name> with a globally unique name.az webapp create --name "<your-unique-app-name>" --resource-group "az204-security-rg" --plan "az204-security-plan" --runtime "DOTNET|6.0" --assign-identity
Key Takeaway

The --assign-identity flag is crucial for enabling a system-assigned managed identity during Azure App Service creation via CLI, automating secure identity provisioning.
