Introduction to Azure Security and Identity Management

Securing Your Cloud Applications and Data with Azure AD

This chapter introduces the fundamental principles of Identity and Access Management (IAM) in Azure, focusing on Azure Active Directory (Azure AD). You'll learn how to differentiate between Azure AD users, groups, and application registrations, understand the concept and benefits of Managed Identities, and implement them for secure programmatic access to Azure resources, eliminating the need for hardcoded credentials.
