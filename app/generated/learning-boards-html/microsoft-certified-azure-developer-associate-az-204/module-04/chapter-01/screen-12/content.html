Hands-on Verification

Verifying Managed Identity and Principal ID

Confirming the identity's existence in Azure AD

Retrieve Principal ID

After creating the App Service, use the Azure CLI to retrieve the Managed Identity's Principal ID. This ID is essential for assigning permissions.

  • •The Principal ID is the Object ID of the identity in Azure AD.
  • •It uniquely identifies the Managed Identity.
  • •You'll use this ID in RBAC role assignments.

Verify in Azure Portal (Optional)

Confirm the Managed Identity status and Object ID directly in the Azure portal for visual confirmation and troubleshooting.

  • •Navigate to your App Service in the portal.
  • •Go to the 'Identity' blade and check 'System assigned' status.
  • •Ensure the Object ID matches the CLI output.
Azure CLI Commands
# 4. Retrieve the Managed Identity's Principal ID# Replace <your-unique-app-name> with your app's name.az webapp identity show --name "<your-unique-app-name>" --resource-group "az204-security-rg" --query "principalId" --output tsv# Example Output:xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx# Make a note of this principalId. This is the Object ID of the managed identity in Azure AD.
Key Takeaway

Retrieving the Principal ID confirms the Managed Identity's creation and provides the necessary identifier for subsequent permission assignments via RBAC.
