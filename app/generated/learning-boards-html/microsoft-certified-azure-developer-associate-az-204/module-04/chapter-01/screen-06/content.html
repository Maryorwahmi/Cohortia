Application Identity

Application Registrations and Service Principals

Giving your applications an identity in Azure AD

Application Registration

This is the process of registering your application with Azure AD, giving it an identity that Azure AD can recognize. It defines the application's properties and required permissions.

  • •Defines application name, logo, and redirect URIs.
  • •Declares permissions needed to access APIs/resources.
  • •Enables application to authenticate and obtain access tokens.

Service Principal

A service principal is the actual instance of an application in a specific Azure AD tenant. It's what's used to assign roles and permissions for that application.

  • •Represents the application's identity in a directory.
  • •Used for access control and role assignments.
  • •Created automatically when an application is registered.

Application Authentication Flow

Applications use their registered identity (service principal) to authenticate with Azure AD and gain access to protected resources.
