Azure AD Identities: Users and Groups

Managing human access to Azure resources

Users: Individual Identities

Users represent individual people who need to interact with Azure resources. Each user has a unique User Principal Name (UPN) and an Object ID.

  • •Can be synchronized from on-premises Active Directory.
  • •Created directly in Azure AD for cloud-only users.
  • •External guest users can be invited for collaboration.

Groups: Collections for Permissions

Groups allow you to manage permissions for collections of users, simplifying administration and adhering to the principle of least privilege.

  • •Assign permissions to a group, and members inherit them.
  • •Reduces complexity compared to individual assignments.
  • •Can be security groups (access control) or Microsoft 365 groups.

Simplified Access Management

Using groups streamlines permission assignments, ensuring consistency and reducing the risk of misconfigurations.

Key Takeaway
