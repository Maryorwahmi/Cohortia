Module 4›Chapter 4.2›The Three Pillars of RBAC

1. Security Principal

The 'who' or 'what' that needs access (user, group, service principal, managed identity).

2. Role Definition

The 'what' actions the principal can perform (a collection of permissions).

3. Scope

The 'where' the access applies (management group, subscription, resource group, or resource).

Security Principal is assigned Role Definition at Scope

Key Takeaway

A role assignment combines a security principal, a role definition, and a scope to grant specific access to Azure resources.

Common Misconception

Forgetting any one of these three components makes an RBAC assignment incomplete or ineffective. All three are required for a valid permission.
