Common Built-in RBAC Roles

Owner

Full access to all resources and can delegate access to others. Highly privileged.

Contributor

Can manage all resources but cannot delegate access. Common for developers.

Reader

Can view all resources but cannot make any changes. Ideal for auditing.

User Access Administrator

Manages access to Azure resources but cannot manage the resources themselves.

Key Takeaway

Always choose the built-in role with the minimum necessary permissions to adhere to the principle of least privilege.

Common Mistake

Granting 'Owner' or 'Contributor' at a broad scope (like subscription) to developers is a common mistake and a significant security risk.
