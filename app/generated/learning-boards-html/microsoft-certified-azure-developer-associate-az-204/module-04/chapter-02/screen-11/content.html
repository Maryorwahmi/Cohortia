Advanced RBAC

Custom Roles: Tailored Permissions

Custom RBAC roles allow you to define a precise set of permissions tailored to your specific needs when built-in roles are insufficient.

  • •Granular Control: Define exact Actions and NotActions.
  • •JSON Definition: Roles are defined using a JSON structure.
  • •Assignable Scopes: Specify where the custom role can be assigned.
  • •Principle of Least Privilege: Enables highly precise enforcement.
Key Takeaway

Custom roles are powerful for advanced scenarios, allowing you to create highly specific permission sets that align perfectly with your security policies.

JSON Structure Example

Simplified Custom Role Definition

{
  "Name": "Web App Restart Only",
  "IsCustom": true,
  "Description": "Can restart web apps, but nothing else.",
  "Actions": [
    "Microsoft.Web/sites/restart/action"
  ],
  "NotActions": [],
  "DataActions": [],
  "NotDataActions": [],
  "AssignableScopes": [
    "/subscriptions/<subscriptionId>"
  ]
}
Important Note

When defining AssignableScopes, ensure you include all management groups or subscriptions where you intend to make this custom role available for assignment.
