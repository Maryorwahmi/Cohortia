Secrets: Your Sensitive Data

Storing passwords, API keys, and connection strings securely

What are Secrets?

Secrets are small data blobs (up to 25 KB) that you want to keep secure. They represent any sensitive information that your applications need to function but should not be exposed.

  • •Passwords: For databases, services, or external systems.
  • •API Keys: For third-party services or internal APIs.
  • •Connection Strings: For databases, storage accounts, or message queues.
  • •Configuration Values: Any sensitive settings that should not be in plain text.
Key Takeaway

Secrets in Key Vault are small, sensitive data blobs that are versioned, allowing for auditing and rollbacks.

Versioning for Control

Key Vault automatically versions secrets. Each time a secret is updated, a new version is created, preserving the old ones. This provides a powerful mechanism for:

  • •Auditing: Track changes to secrets over time, who made them, and when.
  • •Rollbacks: Easily revert to a previous, stable version of a secret if a new one causes issues.
  • •Compliance: Meet regulatory requirements for managing and tracking sensitive data changes.
Example Scenario

An application uses a database connection string stored as a secret. If a new connection string is deployed and causes connectivity issues, you can quickly revert to the previous working version in Key Vault without redeploying your application.
