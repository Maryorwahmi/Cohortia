Accessing Secrets in C#

Using DefaultAzureCredential and SecretClient in .NET

using Azure.Identity;
using Azure.Security.KeyVault.Secrets;
using System;

// ... inside your function logic ...
string keyVaultUri = Environment.GetEnvironmentVariable("KEY_VAULT_URI");
// e.g., https://my-kv-204.vault.azure.net/

var client = new SecretClient(new Uri(keyVaultUri), new DefaultAzureCredential());

KeyVaultSecret secret = await client.GetSecretAsync("MyDatabaseConnectionString");
string dbConnectionString = secret.Value;

// Use dbConnectionString to connect to your database
Key Takeaway

Use DefaultAzureCredential and SecretClient in C# to retrieve Key Vault secrets, automatically leveraging Managed Identities in Azure.

Explanation of Code

  • •Azure.Identity: Provides DefaultAzureCredential for flexible authentication.
  • •Azure.Security.KeyVault.Secrets: Contains SecretClient for interacting with Key Vault secrets.
  • •KEY_VAULT_URI: Retrieved from environment variables, avoiding hardcoding the vault URI.
  • •DefaultAzureCredential: Automatically authenticates using the Managed Identity when running in Azure.
  • •GetSecretAsync: Retrieves the secret by its name.
Pro-Tip

Always store the Key Vault URI itself as an environment variable or application setting. This prevents hardcoding even the vault's address and allows for easy changes across environments.
