Configuring NSG Rules: Principle of Least Privilege

Each NSG rule defines how traffic is filtered based on multiple criteria.

Rule Components

Priority (lowest first), Direction (Inbound/Outbound), Source/Destination (IP/range/tag), Port Range, Protocol, Action (Allow/Deny).

Common Mistake

Creating overly permissive rules (e.g., allowing 'Any' source to 'Any' destination on 'Any' port), which negates security.

Principle of Least Privilege

Only open necessary ports and protocols, and restrict IP ranges as much as possible for enhanced security.
