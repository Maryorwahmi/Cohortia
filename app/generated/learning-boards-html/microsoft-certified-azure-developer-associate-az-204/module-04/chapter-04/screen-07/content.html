Azure Firewall: Centralized Network Protection

A managed, cloud-based network security service for advanced, centralized protection.

What is Azure Firewall?

A fully stateful, managed, cloud-based network security service protecting Azure Virtual Network resources.

Key Capabilities

Built-in high availability, unrestricted cloud scalability, and centralized policy enforcement across subscriptions.

Filtering Types

Supports both application-level (FQDNs) and network-level filtering (IP, port, protocol) with threat intelligence.
