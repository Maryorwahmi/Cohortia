Azure Service Endpoints: Securing Azure Service Access

Extend your VNet's private address space to Azure services over the Azure backbone network.

What They Do

Secure critical Azure service resources to only your virtual networks, removing public internet access.

How Traffic Flows

Traffic from your VNet to the Azure service is routed directly over the Azure backbone network, bypassing the public internet.

Configuration

Enable on a subnet; then configure the Azure service (e.g., Storage account) to accept traffic only from that specific subnet.
