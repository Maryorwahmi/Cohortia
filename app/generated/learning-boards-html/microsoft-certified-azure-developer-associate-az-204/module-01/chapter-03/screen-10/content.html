Template Structure

Anatomy of an ARM Template

Exploring the essential components of an ARM JSON file.

$schema & contentVersion

Defines the template's JSON schema for validation and its internal version number.

parameters

Input values provided at deployment time, making templates reusable and customizable.

variables

Values constructed within the template to simplify expressions and improve readability.

Core Definition

resources Section

This is the heart of the ARM template, where you define all the Azure resources you want to deploy. Each resource specifies its type, apiVersion, name, location, and specific properties.

Key Takeaway

ARM templates are structured JSON files, using parameters for input, variables for internal logic, resources for definitions, and outputs for post-deployment information.
