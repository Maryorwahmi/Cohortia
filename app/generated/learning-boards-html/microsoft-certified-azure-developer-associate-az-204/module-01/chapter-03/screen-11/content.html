ARM Template Example: Deploying a Storage Account

A practical ARM template for creating an Azure Storage Account.

{
"$schema": "https://schema.management.azure.com/schemas/2019-04-01/deploymentTemplate.json#",
"contentVersion": "1.0.0.0",
"parameters": {
"storageAccountName": {
"type": "string",
"metadata": { "description": "Name of the storage account" },
"defaultValue": "az204armstorage"
},
"location": {
"type": "string",
"defaultValue": "[resourceGroup().location]",
"metadata": { "description": "Location for all resources." }
}
},
"resources": [
{
"type": "Microsoft.Storage/storageAccounts",
"apiVersion": "2021-09-01",
"name": "[parameters('storageAccountName')]",
"location": "[parameters('location')]",
"sku": { "name": "Standard_LRS" },
"kind": "StorageV2",
"properties": {}
}
],
"outputs": {
"storageAccountEndpoint": {
"type": "string",
"value": "[reference(parameters('storageAccountName')).primaryEndpoints.blob]"
}
}
}
Template Breakdown

Key Elements in the Storage Account Template

  • Parameters: storageAccountName and location allow for template customization.
  • Resources: Defines a Microsoft.Storage/storageAccounts resource with its API version, name, location, SKU, and kind.
  • ARM Functions: [resourceGroup().location] and [reference()] provide dynamic values and resource properties.
  • Outputs: Returns the storageAccountEndpoint, useful for connecting applications post-deployment.
Key Takeaway

This ARM template demonstrates how to declaratively define an Azure Storage Account, leveraging parameters for flexibility and outputs for post-deployment information.
