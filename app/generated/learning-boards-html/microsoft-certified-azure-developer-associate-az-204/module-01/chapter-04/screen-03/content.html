Understanding the Compute Spectrum

IaaS, PaaS, and FaaS Explained

01

Infrastructure as a Service (IaaS)

Provides virtualized computing resources. You manage the OS, middleware, and applications. Offers maximum control, ideal for legacy or custom environments.

Azure VMs
02

Platform as a Service (PaaS)

Provides a managed environment for developing, running, and managing applications. Azure manages the infrastructure, OS, and middleware. Focus on code.

Azure App Services
03

Function as a Service (FaaS)

Event-driven, serverless compute. You write code (functions) that run in response to triggers. Azure manages all infrastructure and scaling. Pay per execution.

Azure Functions
04

Shared Responsibility Model

Crucially, understand what Azure manages versus what you manage in each model. This dictates your operational overhead and the flexibility you have.
