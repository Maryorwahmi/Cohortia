Module 2 › Chapter 1.4 › Trade-offs
Infrastructure as a Service (IaaS)
  • Control: Maximum (OS, runtime, app).
  • Management: High (OS patching, security).
  • Scalability: Manual or auto-scaling via VM Scale Sets.
  • Cost: Pay for VM instance size, even when idle.
Platform as a Service (PaaS)
  • Control: Moderate (app code, configuration).
  • Management: Low (Azure manages OS, web server).
  • Scalability: Built-in auto-scaling, easy configuration.
  • Cost: Pay for App Service Plan, even when idle.
Function as a Service (FaaS)
  • Control: Minimal (function code only).
  • Management: Very Low (Azure manages all infrastructure).
  • Scalability: Automatic, scales to zero, event-driven.
  • Cost: Pay-per-execution, highly cost-effective for intermittent workloads.
Key Takeaway

Aligning your application's needs with the right compute model's trade-offs in control, management, scalability, and cost is crucial for efficient cloud architecture.
