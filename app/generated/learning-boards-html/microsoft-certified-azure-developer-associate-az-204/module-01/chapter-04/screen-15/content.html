Module 2 › Chapter 1.4 › Key Concepts
Azure Virtual Machines (VMs)

IaaS offering providing full control over the OS and environment, suitable for legacy and highly customized workloads.

Azure App Services

PaaS offering for hosting web apps, APIs, and mobile backends, providing managed infrastructure and auto-scaling.

Azure Functions

FaaS offering for event-driven, serverless execution of small code snippets, billed per execution.

Summary Takeaway

Azure offers a robust portfolio of compute services, including VMs for maximum control, App Services for managed web hosting, and Functions for highly scalable serverless workloads.
