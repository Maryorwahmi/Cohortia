Function as a Service (FaaS) / Serverless

Azure Functions: Serverless Computing

Write event-driven code that runs on demand. Azure manages infrastructure and scaling, offering cost efficiency for variable workloads.

Key Characteristics
  • Event-driven execution
  • Automatic scaling (including to zero)
  • Pay-per-execution model
  • No server management required
  • Ideal for microservices, APIs, background tasks
Key Takeaway

Azure Functions provide a highly scalable and cost-effective way to run code in response to events, abstracting away server management.

# Create a storage account (required for Function App)
az storage account create \
  --name az204funcstorage \
  --location eastus \
  --resource-group MyComputeRG \
  --sku Standard_LRS

# Create a Function App
az functionapp create \
  --resource-group MyComputeRG \
  --consumption-plan-location eastus \
  --name myuniqueaz204funcapp \
  --runtime python \
  --runtime-version 3.9 \
  --functions-version 4 \
  --storage-account az204funcstorage
