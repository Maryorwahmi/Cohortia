IaaS (Virtual Machines)
Customer Responsibility
  • Operating System
  • Applications & Data
  • Network Configuration
Azure Responsibility
  • Physical Infrastructure
  • Virtualization Layer
PaaS (App Services)
Customer Responsibility
  • Application Code
  • Data & Access Control
Azure Responsibility
  • Operating System
  • Runtime & Middleware
  • Scaling & Load Balancing
FaaS (Azure Functions)
Customer Responsibility
  • Application Code
  • Data & Access Control
Azure Responsibility
  • Operating System
  • Runtime & Middleware
  • Application Platform
Key Takeaway

The shared responsibility model clarifies who manages what in the cloud, with customer responsibilities decreasing from IaaS to PaaS to FaaS.
