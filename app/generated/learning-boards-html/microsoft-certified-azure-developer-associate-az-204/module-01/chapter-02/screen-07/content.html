Understanding Azure CLI Command Structure

Groups, Subgroups, Actions, and Parameters

Anatomy of a Command

az

The base command for all Azure CLI operations.

group

A command group, organizing related commands (e.g., `group` for resource groups).

create

The action to perform within the command group (e.g., `create`, `show`, `delete`).

--name

A parameter, providing specific details or options for the action.

Key Takeaway

Mastering the `az --param value` pattern unlocks efficient Azure resource management.

Example Command
az group create --name MyWebAppResources --location eastus
az

The Azure CLI executable.

group

The command group for managing resource groups.

create

The action to create a new resource group.

--name MyWebAppResources

Parameter to specify the name of the resource group.

--location eastus

Parameter to specify the Azure region for the resource group.
