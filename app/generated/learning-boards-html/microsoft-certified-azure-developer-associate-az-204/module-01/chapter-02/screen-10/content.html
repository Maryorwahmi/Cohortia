Deploying Core Services: Storage and Virtual Machines

Hands-on with `az storage account create` and `az vm create`

Key Considerations

  • Storage Account Names: Must be globally unique and lowercase across all of Azure.
  • VM Images: Specify the operating system image (e.g., `UbuntuLTS`, `Win2019Datacenter`).
  • Readability: Use `\` to break long commands into multiple lines for better script clarity.
Key Takeaway

Azure CLI simplifies the deployment of complex resources like storage accounts and VMs through concise, parameterized commands.

Command Examples
# Create an Azure Storage Account
az storage account create \
  --name myuniqueappstorage \
  --resource-group MyWebAppResources \
  --location eastus \
  --sku Standard_LRS \
  --kind StorageV2

# Create a simple Linux Virtual Machine
az vm create \
  --resource-group MyWebAppResources \
  --name MyLinuxVM \
  --image UbuntuLTS \
  --admin-username azureuser \
  --generate-ssh-keys \
  --location eastus
Common Mistake

Using non-globally unique names for services like storage accounts, leading to deployment failures.
