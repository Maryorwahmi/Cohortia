Navigating the CLI with `--help`

Your Best Friend for Command and Parameter Discovery

Hierarchical Help System

Level 1: Top-Level Groups

`az --help` lists all primary command groups (e.g., `account`, `group`, `vm`).

Level 2: Group Commands

`az group --help` shows commands within a specific group (e.g., `create`, `delete`).

Level 3: Action Details

`az group create --help` provides parameters and examples for a specific action.

Key Takeaway

The `--help` flag is indispensable for discovering commands, understanding syntax, and finding examples directly within the CLI.

Example Usage
# Get help for top-level commands
az --help

# Get help for the 'group' command group
az group --help

# Get detailed help for creating a resource group
az group create --help

# Output for 'az group create --help' (truncated)

Common Mistake

Forgetting to use `--help` and instead guessing parameters, leading to errors and wasted time.
