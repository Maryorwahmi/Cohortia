Inspecting Azure Resources and Output Formats

Using `az resource list` and `az <resource-type> show`

Querying Commands

  • `az resource list`: Lists all resources, filterable by group, type, or tag.
  • `az <resource-type> show`: Retrieves detailed properties for a specific resource.

Output Formats (`--output`)

  • `json` / `jsonc`: Machine-readable, ideal for scripting. `jsonc` is colorized.
  • `table`: Human-readable, formatted as a clear table.
  • `tsv`: Tab-separated values, useful for piping to other command-line tools.
Command Examples
# List all VMs in a resource group as a table
az vm list \
  --resource-group MyWebAppResources \
  --output table

# Show detailed properties of a specific VM as JSON
az vm show \
  --resource-group MyWebAppResources \
  --name MyLinuxVM \
  --output json

# List all storage accounts in a resource group as TSV
az storage account list \
  --resource-group MyWebAppResources \
  --output tsv
Key Takeaway

Use `--output table` for quick human review and `--output json` for programmatic parsing in scripts.
