Ensuring Data Availability: LRS and ZRS

Protecting your data within a single region.

Locally Redundant Storage (LRS)

  • Replication: 3 copies within a single data center.
  • Protection: Against server rack and drive failures.
  • Limitation: Does not protect against data center outages.
  • Use Case: Development, testing, non-critical data.
Key Takeaway

LRS is cost-effective but offers the lowest level of redundancy.

Zone-Redundant Storage (ZRS)

  • Replication: Synchronously across 3 Azure availability zones.
  • Protection: Against data center-level failures within a region.
  • Benefit: Higher availability within a region than LRS.
  • Use Case: Production workloads requiring high intra-regional availability.
Pro Tip

ZRS is ideal for applications needing high availability without geo-replication overhead.
