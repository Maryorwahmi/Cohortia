Choosing the Right Storage Account

Optimizing for Workloads, Features, and Cost

General-purpose v2 (GPv2)

  • Recommended: Most common and versatile.
  • Supports: Blobs, Files, Queues, Tables.
  • Features: Latest features and pricing.
  • Use Case: General storage needs, diverse workloads.
Key Takeaway

GPv2 is your default choice for most Azure Storage requirements.

BlockBlobStorage

  • Optimized For: High-performance block blob data.
  • Supports: Only block blobs.
  • Performance: Premium performance tier.
  • Use Case: High-throughput, low-latency block blob storage.
Common Mistake

Using BlockBlobStorage for non-block blob data or general needs, leading to higher costs.

FileStorage

  • Optimized For: Premium file shares.
  • Supports: Only Azure Files.
  • Performance: High-performance file shares.
  • Use Case: Enterprise file shares, high-performance applications.
Pro Tip

For most general development, stick with GPv2 to leverage broad service support and cost efficiency.
