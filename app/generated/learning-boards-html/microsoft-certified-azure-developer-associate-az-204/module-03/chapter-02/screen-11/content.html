Enhancing Blobs with Custom Metadata

Attaching Key-Value Pairs for Additional Context

    public async Task SetBlobMetadataAsync(string blobName, string key, string value)    {        BlobClient blobClient = _containerClient.GetBlobClient(blobName);        IDictionary<string, string> metadata = new Dictionary<string, string> { { key, value } };        await blobClient.SetMetadataAsync(metadata);        Console.WriteLine($"Metadata '{key}: {value}' set for blob '{blobName}'.");    }
Metadata Benefits
  • Stores custom key-value pairs alongside the blob.
  • Does not modify the blob's content.
  • Useful for descriptive information (e.g., author, version).
  • Efficient to retrieve without downloading the entire blob.
Example Use Case

Tagging an uploaded image with the user ID of the uploader and the date it was processed.

Key Takeaway

Blob metadata is a powerful way to add contextual information to your blobs, improving organization and enabling richer application logic.
