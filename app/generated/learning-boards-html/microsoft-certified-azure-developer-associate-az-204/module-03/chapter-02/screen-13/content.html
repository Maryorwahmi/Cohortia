Shared Access Signatures (SAS): Delegated Access

Understanding Secure, Time-Limited Access to Storage Resources

What is SAS?

A URI that grants restricted, time-limited access rights to Azure Storage resources without exposing account keys.

SAS Configuration
  • Resources: Blob, container, or service.
  • Permissions: Read, Write, Delete, List, etc.
  • Validity: Start and expiry times.
  • Restrictions: IP addresses, protocol (HTTPS only).
Key Takeaway

SAS is crucial for granting secure, granular, and temporary access to storage resources, minimizing the risk of exposing sensitive credentials.

Types of Shared Access Signatures
Service SAS

Grants access to a resource within a single storage service (e.g., a specific blob or container).

Account SAS

Grants access to resources across one or more storage services, including service-level operations.

User Delegation SAS

Signed with Azure Active Directory credentials, offering enhanced security and avoiding account keys.
