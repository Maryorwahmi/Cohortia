Retrieving Blob Properties and Metadata

Accessing System-Defined and Custom Blob Information

    public async Task GetBlobPropertiesAndMetadataAsync(string blobName)    {        BlobClient blobClient = _containerClient.GetBlobClient(blobName);        BlobProperties properties = await blobClient.GetPropertiesAsync();        Console.WriteLine($"Properties for blob '{blobName}':");        Console.WriteLine($"  Content Type: {properties.ContentType}");        Console.WriteLine($"  Size: {properties.ContentLength} bytes");        Console.WriteLine($"  Last Modified: {properties.LastModified}");        Console.WriteLine($"Metadata for blob '{blobName}':");        foreach (var item in properties.Metadata)        {            Console.WriteLine($"  {item.Key}: {item.Value}");        }    }
Information Retrieved
  • System Properties: `ContentType`, `ContentLength`, `LastModified`, etc.
  • Custom Metadata: `IDictionary` of user-defined key-value pairs.
  • Efficiency: No full blob download required for retrieval.
Use Case

Displaying file details in a UI, or checking a blob's version before initiating a download or update operation.

Key Takeaway

`GetPropertiesAsync` is a powerful, lightweight method to access both system-managed properties and custom metadata, crucial for informed blob management.
