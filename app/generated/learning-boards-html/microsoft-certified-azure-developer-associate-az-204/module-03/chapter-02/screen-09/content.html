Discovering Blobs in a Container

Iterating Through Blob Items and Their Properties

    public async Task ListBlobsAsync()    {        Console.WriteLine("Listing blobs in container:");        await foreach (BlobItem blobItem in _containerClient.GetBlobsAsync())        {            Console.WriteLine($"  - {blobItem.Name} (Type: {blobItem.Properties.BlobType}, Size: {blobItem.Properties.ContentLength} bytes)");        }    }
Listing Details
  • `GetBlobsAsync()`: Returns an asynchronous enumerable of `BlobItem`.
  • `BlobItem`: Contains blob name, type, and properties.
  • Efficiency: Processes blobs one by one, ideal for large containers.
  • Filtering: Can filter by prefix to narrow down results.
Use Case

Displaying a list of uploaded documents in a user interface or processing all log files from a specific date.

Key Takeaway

`GetBlobsAsync` provides an efficient way to enumerate and inspect blobs within a container, supporting filtering for targeted searches.
