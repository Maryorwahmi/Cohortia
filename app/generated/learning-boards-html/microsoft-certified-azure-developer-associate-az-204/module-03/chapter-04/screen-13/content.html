Entity Size and Property Limits

Designing within Table Storage constraints.

Azure Table Storage entities have a maximum size of 1MB and a maximum of 255 properties (excluding system properties). Adhering to these limits is crucial for performance and avoiding errors.

Key Takeaway

Design your entities to stay within the 1MB size and 255-property limits for optimal performance and to prevent operational errors in Azure Table Storage.

Key Limits
Entity Size

Maximum 1MB per entity. Avoid storing large binary data directly; use references instead.

Number of Properties

Maximum 255 properties per entity (excluding system properties like `PartitionKey`, `RowKey`, `Timestamp`, `ETag`).
