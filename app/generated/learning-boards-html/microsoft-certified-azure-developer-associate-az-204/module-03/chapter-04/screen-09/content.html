Retrieving a Single Entity

Direct access using `PartitionKey` and `RowKey`.

The `GetEntityAsync` method provides the most efficient way to retrieve a single entity by specifying its exact `PartitionKey` and `RowKey`. It's essential to handle the `RequestFailedException` (status 404) that occurs if the entity is not found.

Key Takeaway

Direct entity retrieval via `GetEntityAsync` is the fastest method when both `PartitionKey` and `RowKey` are known, but requires error handling for non-existent entities.

Efficient Retrieval
Method

`await _tableClient.GetEntityAsync(partitionKey, rowKey);`

Performance

Optimal performance due to direct key-based lookup within a partition.

Error Handling

Use `try-catch` for `RequestFailedException` (status 404) when entity might not exist.
