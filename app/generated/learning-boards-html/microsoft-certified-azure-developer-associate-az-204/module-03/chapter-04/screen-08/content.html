Adding and Updating Entities (Upsert)

Using `UpsertEntityAsync` for flexible data management.

The `UpsertEntityAsync` method is a powerful tool that either inserts a new entity if it doesn't exist or updates an existing one based on its `PartitionKey` and `RowKey`. This simplifies code by handling both creation and modification in a single call.

Key Takeaway

`UpsertEntityAsync` streamlines data management by combining insert and update logic into one efficient operation.

How it Works
New Entity

If `PartitionKey` and `RowKey` do not exist, a new entity is created.

Existing Entity

If `PartitionKey` and `RowKey` match an existing entity, that entity is updated.

Code Example

`await _tableClient.UpsertEntityAsync(myEntity);`
