Defining Entities with ITableEntity

Ensuring type safety and structure for your data.

Define custom entity classes by implementing `ITableEntity` or inheriting `TableEntity`. These classes must include `PartitionKey`, `RowKey`, `Timestamp`, and `ETag` properties. Additional properties represent your data, enhancing type safety and simplifying serialization.

Key Takeaway

Using `ITableEntity` or `TableEntity` provides a structured, type-safe way to represent your data for Azure Table Storage operations.

Required Properties
`PartitionKey` (string)

Required. Determines the partition.

`RowKey` (string)

Required. Uniquely identifies entity within partition.

`Timestamp` (`DateTimeOffset?`)

System-managed. Records last modification time.

`ETag` (`ETag`)

System-managed. For optimistic concurrency control.
