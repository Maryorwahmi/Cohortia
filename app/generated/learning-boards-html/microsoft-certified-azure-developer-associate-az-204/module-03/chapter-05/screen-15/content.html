Key Concepts

Essential Terms to Remember

Dequeue

Retrieving a message from the queue, making it invisible for a set duration.

Visibility Timeout

The duration a dequeued message remains invisible to other consumers.

Poison Message

A message that repeatedly fails processing and is moved to a dead-letter queue.

Summary Takeaway

Dequeueing messages involves a visibility timeout to prevent duplicates, and messages that repeatedly fail processing become poison messages requiring special handling.
