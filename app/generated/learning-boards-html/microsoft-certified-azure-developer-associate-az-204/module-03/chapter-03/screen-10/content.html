Programmatic Access

Azure Storage SDK for File Shares (C#)

Interacting with file shares using client libraries

Key Client Classes (C#)

  • •ShareServiceClient: Represents the storage account for file shares.
  • •ShareClient: Represents a specific file share within the account.
  • •ShareDirectoryClient: Represents a directory within a file share.
  • •ShareFileClient: Represents an individual file within a directory.

These classes are found in the Azure.Storage.Files.Shares NuGet package.

Hierarchy of Interaction

ShareServiceClient
ShareClient
ShareDirectoryClient
ShareFileClient
Key Takeaway

The Azure Storage SDK for C# provides a clear object model for managing file shares, directories, and files programmatically.
