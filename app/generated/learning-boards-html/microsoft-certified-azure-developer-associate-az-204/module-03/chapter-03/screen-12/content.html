Downloading, Listing, and Deleting (C#)

Completing the programmatic file management cycle

Downloading and Listing Files

Retrieve file content using DownloadAsync(). List directory contents with GetFilesAndDirectoriesAsync(), iterating through ShareFileItem objects.

public async Task DownloadFileAsync(string directoryName, string fileName, string localDownloadPath){    ShareDirectoryClient directoryClient = _shareClient.GetDirectoryClient(directoryName);    ShareFileClient fileClient = directoryClient.GetFileClient(fileName);    ShareFileDownloadInfo download = await fileClient.DownloadAsync();    using (FileStream stream = File.OpenWrite(localDownloadPath))    {        await download.Content.CopyToAsync(stream);    }}public async Task ListFilesAndDirectoriesAsync(string directoryName = ""){    ShareDirectoryClient directoryClient = _shareClient.GetDirectoryClient(directoryName);    await foreach (ShareFileItem item in directoryClient.GetFilesAndDirectoriesAsync())    {        Console.WriteLine($"  {(item.IsDirectory ? "[DIR]" : "[FILE]")} {item.Name}");    }}

Deleting Files (with Safety)

Use DeleteIfExistsAsync() for safe file removal. Always verify target paths and implement error handling.

public async Task DeleteFileAsync(string directoryName, string fileName){    ShareDirectoryClient directoryClient = _shareClient.GetDirectoryClient(directoryName);    ShareFileClient fileClient = directoryClient.GetFileClient(fileName);    await fileClient.DeleteIfExistsAsync();    Console.WriteLine($"File '{fileName}' deleted if it existed.");}
**Safety Note**: Always double-check target paths and ensure proper error handling when deleting files to prevent accidental data loss.
Key Takeaway

The SDK provides comprehensive methods for downloading, listing, and safely deleting files, enabling full programmatic control over Azure File Shares.
