Mounting Azure File Shares on Windows

Connecting your cloud file share as a network drive

The `net use` Command

On Windows, you'll typically use the net use command in Command Prompt or PowerShell to map the Azure File Share as a network drive. This command requires the storage account name, file share name, and a storage account key for authentication.

# Example for Windows PowerShell$storageAccountName = "yourstorageaccountname"$fileShareName = "yourfilesharename"$storageAccountKey = "YourStorageAccountKey" # Get this from Azure Portal or CLI# Mount the file share as a network drive (e.g., Z:)net use Z: \\$storageAccountName.file.core.windows.net\$fileShareName /u:AZURE\$storageAccountName $storageAccountKey

Common Mistakes & Considerations

  • •**Missing AZURE\ prefix**: The username parameter requires AZURE\ before the storage account name.
  • •**Incorrect Storage Account Key**: Ensure the key is accurate and up-to-date.
  • •**Port 445 Blocked**: Outbound port 445 (SMB) must be open. Many ISPs block this, preventing on-premises mounting.
Key Takeaway

Mounting Azure File Shares on Windows uses the net use command with SMB 3.0, requiring careful attention to authentication details and network port 445.
