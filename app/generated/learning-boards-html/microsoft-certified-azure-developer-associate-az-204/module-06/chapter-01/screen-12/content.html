Core Definition

What is Application Insights?

Azure Application Insights is an Application Performance Management (APM) service that monitors live web applications, automatically detecting performance anomalies and providing deep insights into usage and health.

Key Telemetry Collected
  • Request Rates & Response Times: Performance of web requests.
  • Dependency Calls: Performance of calls to databases, APIs, etc.
  • Exceptions: Detailed information on application errors.
  • User Sessions & Page Views: Understanding user behavior.
How it Works

Application Insights uses an SDK integrated directly into your application code. This allows it to collect rich, code-level telemetry that goes beyond what infrastructure logs can provide. The collected data is sent to a dedicated Application Insights resource, which is backed by a Log Analytics workspace for storage and querying using KQL.

Key Takeaway

Application Insights provides crucial application-centric observability, offering deep insights into performance, usage, and exceptions at the code level, complementing broader infrastructure monitoring.

Misconception

Application Insights replaces Log Analytics. In reality, Application Insights leverages Log Analytics for its backend data storage and querying, providing a specialized layer of application-focused insights.
