Telemetry Data Sources

Where Data Comes From

  • Azure Subscription: Activity logs, service health, resource health.
  • Azure Resources: VMs, App Services, Functions, Storage, Databases.
  • Custom Applications: Via Application Insights SDKs or custom logging.
  • Other Monitoring Tools: Integration with third-party systems.
Data Storage Mechanisms

Where Data Resides

  • Metrics: Stored in a specialized time-series database, optimized for numerical analysis and trending.
  • Logs: Ingested into a Log Analytics workspace, built on Azure Data Explorer for large-scale querying.
Key Takeaway

Azure Monitor provides a unified ingestion point for diverse telemetry, storing metrics and logs in purpose-built databases for optimal performance and analysis.
