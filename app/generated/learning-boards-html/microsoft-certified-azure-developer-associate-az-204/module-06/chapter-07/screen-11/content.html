Developer Best Practices: Resource Sizing & Scaling

Optimizing Compute and Database Resources for Cost Efficiency

Choose the Right Resource Size

Avoid over-provisioning. Start with smaller resources and scale up as needed, using monitoring data to guide decisions.

Example

A new web application starts with a B1s App Service Plan. As traffic grows, monitoring shows consistent CPU spikes, prompting an upgrade to a B2s plan.

Implement Auto-scaling

Dynamically adjust resources to match demand, preventing over-provisioning during low-traffic periods and ensuring capacity during peaks.

Example

Configure an Azure App Service to automatically scale out to 5 instances during peak hours and scale back to 1 instance overnight, saving costs.

Key Takeaway

Proactive right-sizing and intelligent auto-scaling are fundamental developer practices for optimizing compute costs and ensuring efficient resource utilization.
