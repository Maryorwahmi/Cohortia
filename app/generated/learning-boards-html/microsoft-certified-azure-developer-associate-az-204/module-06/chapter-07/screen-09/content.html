Resource Tagging: Granular Cost Allocation

Tags are name-value pairs applied to Azure resources for effective management, cost allocation, and automation.

  • Fundamental for breaking down costs in Cost Analysis.
  • Enables automation and governance policies.
  • Requires a consistent tagging strategy for effectiveness.
Safety Note

Establish a clear and consistent tagging strategy early on. Without it, cost analysis will be messy, and automation efforts will be hampered. Use Azure Policy to enforce mandatory tags.

Tagging Purposes
Cost Allocation

Attribute spending to specific teams or projects.

Automation

Use tags in policies or automation scripts.

Governance

Identify resources for compliance or ownership.

CLI Example
az webapp update \
    --resource-group "MonitorDemoRG" \
    --name "cohortia-demo-app-YOUR_UNIQUE_NAME" \
    --set tags.Project="CohortiaDemo" tags.Environment="Dev" tags.Owner="DevTeamA"
