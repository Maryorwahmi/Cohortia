Configuring Auto-healing Rules

Setting up triggers and actions for automated recovery.

HTTP Status Codes

Trigger a restart if the app consistently returns HTTP 500 errors.

Memory Consumption

Restart if memory usage exceeds a defined threshold for a period.

Request Duration

Trigger action if average request time becomes too high, indicating performance issues.

// Conceptual Auto-healing Rule Configuration
{  "triggers": {    "requests": {      "count": 500,      "timeWindow": "00:05:00"    },    "statusCodes": [      {        "statusCode": 500,        "count": 10,        "timeWindow": "00:01:00"      }    ]  },  "actions": {    "actionType": "Recycle" // Or "Restart"  }}
Key Takeaway

Auto-healing rules provide granular control over automated recovery, allowing you to define triggers and actions tailored to your application's needs.
