Logging Custom Events and Metrics

Tailoring Telemetry for Business-Specific Insights

// Example: Logging a custom event and metric in .NET
using Microsoft.ApplicationInsights;
using Microsoft.ApplicationInsights.DataContracts;

public class OrderService
{
    private readonly TelemetryClient _telemetryClient;

    public OrderService(TelemetryClient telemetryClient)
    {
        _telemetryClient = telemetryClient;
    }

    public void ProcessOrder(string orderId, decimal amount)
    {
        // Log a custom event for order processing
        var eventTelemetry = new EventTelemetry("OrderProcessed");
        eventTelemetry.Properties["OrderId"] = orderId;
        eventTelemetry.Properties["CustomerTier"] = "Premium";
        _telemetryClient.TrackEvent(eventTelemetry);

        // Log a custom metric for order amount
        _telemetryClient.TrackMetric("OrderAmount", amount);

        // Simulate an exception
        if (amount > 1000)
        {
            throw new InvalidOperationException("Order amount exceeds limit.");
        }

        _telemetryClient.Flush(); // Ensure telemetry is sent immediately
    }
}
TrackEvent for Actions

Use TrackEvent to log specific user actions or business events, attaching custom properties for context.

TrackMetric for Values

Use TrackMetric to log numerical values, such as order amounts, processing times, or queue lengths.

TrackException for Handled Errors

Log handled exceptions with TrackException to capture errors that don't crash the application but are still important to monitor.

Key Takeaway

Custom telemetry allows you to extend Application Insights' capabilities, providing granular, business-specific insights that are crucial for understanding user behavior and operational efficiency.
