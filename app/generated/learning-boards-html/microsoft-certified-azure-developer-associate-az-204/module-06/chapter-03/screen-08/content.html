Live Metrics Stream and Performance Blade

Instant Insights into Application Health and Speed

Live Metrics Stream

  • •Provides real-time, minute-by-minute view of application performance.
  • •Shows incoming requests, failures, server CPU, and custom events as they happen.
  • •Ideal for monitoring deployments, high-traffic events, and immediate anomaly detection.
Key Use Case

Use Live Metrics during a new feature rollout to instantly verify performance and catch any regressions in real-time.

Performance Blade

  • •Offers aggregated, historical views of request response times and dependency durations.
  • •Allows drilling down to specific operations to identify slow calls and their distribution.
  • •Best for identifying long-term performance trends and areas for optimization.
Misconception

Live Metrics is not a replacement for detailed historical analysis. It's a real-time pulse, while the Performance blade provides the full diagnostic history.

Key Takeaway

Live Metrics Stream provides instant operational awareness, while the Performance blade offers aggregated historical data for deeper analysis and identifying long-term optimization opportunities.
