Querying Application Insights Data with KQL

Unlocking Deeper Insights with Log Analytics

Log Analytics Integration

Application Insights data is stored in a Log Analytics workspace, enabling powerful querying capabilities.

Kusto Query Language (KQL)

Use KQL to perform complex queries, aggregations, and correlations across your telemetry data.

Key Benefit

KQL allows you to correlate application-level telemetry with infrastructure logs, providing a truly holistic view of your system's health and performance.

// Example KQL Query
customEvents
| where name == "OrderProcessed"
| project TimeGenerated, name, customDimensions.OrderId, customMetrics.OrderValue
| order by TimeGenerated desc

Key Data Tables

Data is organized into tables like requests, dependencies, exceptions, traces, customEvents, and customMetrics.

Pro Tip

Start with simple queries and gradually add filters, aggregations, and joins to refine your analysis and uncover deeper insights.

Key Takeaway

KQL in Log Analytics is a powerful tool for advanced analysis of Application Insights data, enabling deep correlation and troubleshooting across your entire system.
