Azure Portal Features

Navigating Application Insights in Azure Portal

A Suite of Tools for Diagnostics and Monitoring

Real-time Monitoring
Live Metrics Stream

Real-time, minute-by-minute view of performance, requests, failures, and server CPU.

Performance

Aggregated views of request response times, dependency durations, and exceptions.

Issue Diagnostics
Failures

Summary of exceptions and failed requests, with drill-down to specific error types and stack traces.

Transaction Search

Search for individual requests, events, or exceptions and view their full end-to-end transaction flow.

Behavioral Insights
Dependencies

Visualizes the performance and success rate of calls your application makes to external services.

Usage

Tracks user sessions, page views, and custom events to understand how users interact with your application.

Key Takeaway

The Azure Portal provides a rich set of interconnected tools within Application Insights, allowing developers to gain deep insights into application performance, diagnose issues, and understand user behavior effectively.
