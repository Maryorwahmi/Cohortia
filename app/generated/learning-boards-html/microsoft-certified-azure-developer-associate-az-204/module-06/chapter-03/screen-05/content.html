Key Components

Understanding Application Insights Telemetry

The Rich Data Collected by the SDK

Requests

Incoming HTTP requests to your web application, including URL, response time, and success/failure.

Dependencies

Calls your application makes to external services like databases, HTTP APIs, or other Azure services.

Exceptions

Details about unhandled exceptions in your application, including stack traces and request context.

Performance Counters

System performance metrics collected from the host machine, such as CPU, memory, and disk I/O.

Availability

Results of web tests that periodically ping your application from various global locations to ensure uptime.

Custom Events & Metrics

Telemetry you explicitly log from your code to track specific business events or performance indicators.

Key Takeaway

Application Insights automatically collects a wide array of telemetry types, providing a holistic view of your application's operational health, performance, and user interactions.
