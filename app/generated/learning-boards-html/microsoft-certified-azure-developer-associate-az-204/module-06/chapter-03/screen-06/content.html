Integrating Application Insights into .NET

Enabling Automatic Telemetry Collection

// Program.cs for .NET 6+
using Microsoft.ApplicationInsights.Extensibility;

var builder = WebApplication.CreateBuilder(args);

// Add services to the container.
builder.Services.AddApplicationInsightsTelemetry(); // Automatically picks up instrumentation key

// Configure custom telemetry processor (optional)
builder.Services.AddApplicationInsightsTelemetryProcessor<MyCustomTelemetryProcessor>();

builder.Services.AddControllersWithViews();

var app = builder.Build();

// Configure the HTTP request pipeline.
if (!app.Environment.IsDevelopment())
{
    app.UseExceptionHandler("/Home/Error");
    app.UseHsts();
}

app.UseHttpsRedirection();
app.UseStaticFiles();

app.UseRouting();

app.UseAuthorization();

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Home}/{action=Index}/{id?}");

app.Run();
Add NuGet Package

Install Microsoft.ApplicationInsights.AspNetCore to bring the SDK into your .NET project.

Enable Telemetry

Call builder.Services.AddApplicationInsightsTelemetry() in Program.cs to enable automatic collection.

Connection String/Key

Provide an Instrumentation Key or Connection String via environment variables or configuration to link your app to the AI resource.

Key Takeaway

Proper SDK integration and configuration of the Instrumentation Key are fundamental for Application Insights to begin collecting and sending telemetry from your application.
