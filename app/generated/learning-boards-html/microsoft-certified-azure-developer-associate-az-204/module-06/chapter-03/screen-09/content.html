Troubleshooting Tools

Investigating Failures and Transactions

Pinpointing Errors and Tracing End-to-End Flows

Failures Blade

  • •Shows a summary of exceptions and failed requests.
  • •Allows investigation of specific error types, their count, and sample stack traces.
  • •Helps prioritize and address the most impactful errors.
Key Use Case

Quickly identify the most frequent exceptions after a new release to address critical bugs first.

Transaction Search

  • •Enables searching for individual requests, events, or exceptions.
  • •View the full end-to-end transaction flow, including all associated dependencies and logs.
  • •Invaluable for debugging specific user issues or complex multi-service interactions.
Pro Tip

When a user reports a specific issue, use Transaction Search with their user ID or request ID to trace their exact journey and pinpoint the failure point.

Key Takeaway

The Failures blade identifies what's breaking, while Transaction Search provides the detailed context of how and why, enabling efficient and targeted troubleshooting.
