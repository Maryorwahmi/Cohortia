Module 6›Chapter 6.5›Cold Starts
Core Definition

Serverless Cold Start

The delay experienced when a serverless function instance needs to be initialized from scratch after a period of inactivity.

Cause 1

Code & Runtime Loading

Function code and runtime environment must be loaded into memory.

Cause 2

Dependency Initialization

External libraries and connections need to be established.

Impact

Increased Latency

First requests after inactivity experience noticeable delays.

Analogy

Restaurant Setup

Kitchen setup time before the first dish is prepared.

Key Takeaway

Cold starts are an inherent trade-off in serverless, causing initial latency due to on-demand resource provisioning.
