Module 6›Chapter 6.5›CDN Configuration
CDN Implementation Steps
  1. Create CDN Profile & Endpoint: Define your CDN profile and an endpoint pointing to your origin (e.g., Azure Storage, Web App).
  2. Update Application URLs: Modify your application's code to reference the CDN endpoint for static assets instead of the origin.
  3. Configure Cache-Control: Ensure your origin server sends appropriate Cache-Control headers for effective caching.
Common CDN Mistakes
  • Not configuring proper Cache-Control headers on the origin.
  • Attempting to cache dynamic or user-specific content.
  • Forgetting to update all static asset URLs to use the CDN.
Key Takeaway

Proper CDN integration involves creating endpoints and updating asset URLs, coupled with correct cache-control settings on the origin.

HTML Code Example: Before & After CDN
<!-- Before CDN -->
<img src="https://mywebapp.azurewebsites.net/images/logo.png" />

<!-- After CDN -->
<img src="https://mycdnendpoint.azureedge.net/images/logo.png" />

<!-- CSS Example -->
.hero-background {
  background-image: url('https://mycdnendpoint.azureedge.net/css/hero.jpg');
}
