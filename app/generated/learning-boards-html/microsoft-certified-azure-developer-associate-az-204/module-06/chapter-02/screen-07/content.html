Azure CLI for Function App Diagnostics

# Assuming you have an existing Function App and Log Analytics Workspace
# Replace placeholders with your actual resource names

FUNCTION_APP_NAME="my-cohortia-functionapp"
FUNCTION_APP_RG="MonitorDemoRG"
WORKSPACE_ID=$(az monitor log-analytics workspace show \
    --resource-group "MonitorDemoRG" \
    --workspace-name "CohortiaLogWorkspace" \
    --query id -o tsv)

az monitor diagnostic-settings create \
    --name "FunctionAppToLogAnalytics" \
    --resource-group $FUNCTION_APP_RG \
    --resource $FUNCTION_APP_NAME \
    --resource-type Microsoft.Web/sites \
    --workspace $WORKSPACE_ID \
    --logs '[{"category": "FunctionAppLogs", "enabled": true, "retentionPolicy": {"enabled": false, "days": 0}}]' \
    --metrics '[{"category": "AllMetrics", "enabled": true, "retentionPolicy": {"enabled": false, "days": 0}}]'

Command Breakdown

Resource Identification

Define your Function App's name, resource group, and retrieve the Log Analytics Workspace ID for routing.

az monitor diagnostic-settings create

The core command to create a new diagnostic setting. Specify a unique name for the setting.

Target Resource & Type

Point to your Function App using --resource and its resource type (Microsoft.Web/sites).

Log & Metric Categories

Specify which log categories (e.g., FunctionAppLogs) and metrics (AllMetrics) to enable and route to the --workspace.

Key Takeaway

Using Azure CLI for diagnostic settings ensures consistent, automated, and scalable monitoring configurations for your Azure Function Apps.
