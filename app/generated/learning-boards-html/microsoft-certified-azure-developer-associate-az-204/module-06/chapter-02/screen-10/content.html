KQL Query: App Service HTTP Patterns

AppServiceHTTPLogs
| where TimeGenerated > ago(1h)
| summarize RequestCount = count(), AverageLatencyMs = avg(TimeTaken) by CsUriStem, HttpStatus
| order by RequestCount desc

Query Explanation

AppServiceHTTPLogs: Data Source

Specifies the table containing HTTP access logs for your Azure App Service.

where TimeGenerated > ago(1h): Time Filter

Filters logs to include only those generated within the last one hour.

summarize RequestCount = count(), ...: Aggregation

Calculates the total request count and average latency for each unique URI stem and HTTP status.

by CsUriStem, HttpStatus: Grouping

Groups the aggregated results by the requested URI path and the HTTP response status code.

Key Takeaway

This KQL query provides a powerful way to analyze App Service HTTP traffic, revealing request patterns, endpoint performance, and overall web application health at a glance.
