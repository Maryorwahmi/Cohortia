KQL Query: Function App Errors

FunctionAppLogs
| where LogLevel == "Error"
| project TimeGenerated, HostInstanceId, FunctionName, Message
| order by TimeGenerated desc

Query Explanation

FunctionAppLogs: Data Source

Specifies the table containing logs from your Azure Function Apps.

where LogLevel == "Error": Filtering

Filters the logs to include only entries where the severity level is 'Error'.

project TimeGenerated, ...: Column Selection

Selects specific columns (timestamp, host, function name, message) for focused analysis.

order by TimeGenerated desc: Sorting

Sorts the results in descending order by the time the log was generated, showing the most recent errors first.

Key Takeaway

This KQL query efficiently isolates and presents critical error information from Function App logs, enabling rapid diagnosis and troubleshooting of serverless application issues.
