Data-Driven Diagnosis

Examining Logs and Metrics for Clues

Leverage KQL queries and performance metrics to pinpoint the root cause of issues.

KQL Query Example (Log Analytics)
# Example KQL query for App Service errors
AppServiceConsoleLogs
| where LogLevel == "Error" or Message contains "exception"
| project TimeGenerated, Message, Exception
| order by TimeGenerated desc

# This query filters for error-level logs or messages
# containing the word "exception" from App Service console logs,
# projecting relevant fields and ordering by time.
Log Examination Strategy

Start with high-level logs (HTTP status codes), then drill down into application and dependency logs for detailed error messages and stack traces.

Key Metrics to Monitor
  • CPU usage
  • Memory consumption
  • Network I/O
  • Request rates
  • Error rates

Anomalies in these metrics often indicate resource exhaustion or application crashes.

Key Takeaway

Correlating insights from detailed logs (via KQL) and performance metrics is crucial for transforming symptoms into actionable diagnostic information.
