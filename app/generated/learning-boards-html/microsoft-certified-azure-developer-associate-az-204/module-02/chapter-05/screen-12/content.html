Security: Shared Responsibility in the Cloud

Understanding security models and best practices for each service.

Shared Responsibility Model

  • IaaS (VMs): You manage OS, network config, application security. Azure manages physical infrastructure.
  • PaaS/FaaS (App Service, Functions, ACI, AKS): Azure manages underlying infrastructure security. You manage application, data, and network configurations.

Key Security Best Practices

  • Network Security Groups (NSGs): Control inbound/outbound traffic.
  • Azure Private Link: Private connectivity to Azure services.
  • Azure Key Vault: Securely store secrets, keys, and certificates.
  • Azure Active Directory: Identity and access management.
  • Container Image Scanning: Regularly scan container images for vulnerabilities.
Concrete Example

For an Azure VM, you are responsible for installing OS security patches, while for an App Service, Azure handles OS patching, but you must secure your application code and data.

Key Takeaway

Always understand your security responsibilities for each compute service and implement comprehensive best practices to protect your applications and data.

Common Pitfall

Assuming Azure handles all security aspects for PaaS/FaaS, neglecting application-level security, which remains your responsibility.
