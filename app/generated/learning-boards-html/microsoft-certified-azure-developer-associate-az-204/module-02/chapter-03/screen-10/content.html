AKS Deployments: YAML Manifests

Defining your application's desired state

Key Deployment Fields

  • `apiVersion`, `kind`: Defines the Kubernetes object type.
  • `metadata`: Name and labels for the Deployment.
  • `spec.replicas`: Desired number of Pod instances.
  • `spec.selector`: Matches labels of Pods managed by this Deployment.
  • `spec.template`: Defines the Pods (containers, images, ports).
Key Takeaway

Deployments are central to managing the lifecycle and scaling of your containerized applications in Kubernetes.

Pro Tip

Always define your desired state in YAML; Kubernetes will work to achieve and maintain it.

# my-nginx-deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  replicas: 3 # Ensure 3 instances of Nginx are running
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:latest
        ports:
        - containerPort: 80
