Key Concepts

Core orchestration and management terms

Azure Kubernetes Service (AKS)

A fully managed Kubernetes service for orchestrating containerized applications at scale.

Kubernetes

An open-source system for automating deployment, scaling, and management of containerized applications.

`kubectl`

The command-line tool for interacting with a Kubernetes cluster.

Deployment (Kubernetes)

A Kubernetes object that manages a replicated set of pods, ensuring desired state.

Service (Kubernetes)

A Kubernetes object that defines a logical set of Pods and a policy by which to access them.

Pod (Kubernetes)

The smallest deployable unit in Kubernetes, typically containing one or more containers.

Summary Takeaway

AKS, powered by Kubernetes, provides advanced orchestration for complex applications, managed through `kubectl` and declarative objects like Deployments and Services.
