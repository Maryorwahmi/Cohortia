Getting Started with AKS

Interacting with AKS: `kubectl` and Cluster Setup

Preparing your environment for Kubernetes deployments

Key Steps for AKS Setup

  • Install `kubectl`: The command-line tool for Kubernetes.
  • Create AKS Cluster: Use `az aks create` via Azure CLI.
  • Get Credentials: Configure `kubectl` with `az aks get-credentials`.
  • Verify Connectivity: Use `kubectl get nodes` to confirm access.
Key Takeaway

`kubectl` is essential for AKS management, requiring proper cluster creation and credential configuration.

Pro Tip

Cluster creation can take 5-10 minutes; plan accordingly for your deployments.

# 1. Create an AKS cluster (takes 5-10 minutes)
RESOURCE_GROUP="MyAksRG"
AKS_CLUSTER_NAME="MyAKSCluster"

az aks create \
  --resource-group $RESOURCE_GROUP \
  --name $AKS_CLUSTER_NAME \
  --node-count 1 \
  --generate-ssh-keys
# 2. Get AKS cluster credentials
az aks get-credentials \
  --resource-group $RESOURCE_GROUP \
  --name $AKS_CLUSTER_NAME \
  --overwrite-existing
# 3. Verify `kubectl` connectivity
kubectl get nodes
