Deploying a Container with ACI

A quick start with Azure CLI

Deployment Steps

  • Create Resource Group: Organize Azure resources.
  • Define Container: Specify image, ports, and DNS label.
  • Deploy with CLI: Use `az container create` command.
  • Verify Access: Open the FQDN in a browser.
Key Takeaway

ACI deployments are fast and require minimal configuration, making them ideal for quick tests or simple services.

Common Mistake

Forgetting to specify a unique DNS name label, leading to deployment failure.

# 1. Create a resource group
RESOURCE_GROUP="MyContainerRG"
LOCATION="eastus"
az group create --name $RESOURCE_GROUP --location $LOCATION
# 2. Deploy a public Nginx container to ACI
ACI_NAME="mynginxcontainer"
DNS_LABEL="mynginxapp"

az container create \
  --resource-group $RESOURCE_GROUP \
  --name $ACI_NAME \
  --image nginx \
  --ports 80 \
  --dns-name-label $DNS_LABEL \
  --query ipAddress.fqdn --output tsv
# Expected Output (FQDN)
mynginxapp.eastus.azurecontainer.io
