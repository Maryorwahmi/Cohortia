Creating a Function App with Azure CLI

Provisioning the hosting environment for your Azure Functions.

What is a Function App?

A Function App is the hosting environment for your Azure Functions. It provides the necessary runtime, scaling, and networking for your serverless code.

Key CLI Parameters

  • --resource-group: Logical container for Azure resources.
  • --consumption-plan-location: Region for deployment, often tied to billing.
  • --name: Globally unique name for your Function App.
  • --runtime & --runtime-version: Specifies the language and version (e.g., node 18).
Key Takeaway

The Azure CLI command az functionapp create is essential for setting up the foundational environment for your serverless functions.

az functionapp create \
  --resource-group MyResourceGroup \
  --consumption-plan-location eastus \
  --name MyHttpFunctionApp \
  --runtime node \
  --runtime-version 18 \
  --functions-version 4
Pro Tip

Ensure your Function App name is globally unique across Azure, as it forms part of the public URL.
