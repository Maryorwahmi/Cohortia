Setting Up Your App Service Environment

Creating an App Service Plan and Web App with Azure CLI.

App Service Plan

Defines the underlying compute resources, region, VM size, and scaling options. Multiple apps can share a plan.

Web App

The actual application instance that hosts your code, linked to an App Service Plan and configured with a runtime.

Azure CLI Commands

Use az appservice plan create to define resources and az webapp create to provision the application instance.

Key Takeaway

Creating an App Service Plan first, then a Web App, establishes the necessary compute resources and hosting environment for your application.

# 1. Create Resource Group (if not exists)
az group create --name MyResourceGroup --location eastus
# 2. Create App Service Plan
az appservice plan create \
  --name MyWebAppPlan \
  --resource-group MyResourceGroup \
  --sku B1 \
  --is-linux
# 3. Create Web App
az webapp create \
  --resource-group MyResourceGroup \
  --plan MyWebAppPlan \
  --name MyWebAppName \
  --runtime "NODE|18-lts"
Note: Replace placeholders like MyResourceGroup, MyWebAppPlan, MyWebAppName with your unique values.
