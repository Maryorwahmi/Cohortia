Pushing Your Code with Local Git

Integrating your local repository with Azure App Service.

Deployment Credentials

Set a username and strong password for Git authentication to your App Service app.

Azure Git Remote

Add the App Service's Git deployment URL as a remote to your local Git repository.

Direct Push

Use git push azure master to deploy your code directly to the App Service, triggering a build and deployment.

Key Takeaway

Local Git deployment provides a quick and direct way to push code changes to your App Service app, integrating seamlessly with Git workflows.

# 1. Set Deployment User Credentials
az webapp deployment user set \
  --user-name "<your-deployment-username>" \
  --password "<your-strong-password>"
# 2. Get Git Deployment URL
GIT_URL=$(az webapp deployment source config-local-git \
  --name MyWebAppName \
  --resource-group MyResourceGroup \
  --query scmUri --output tsv)
# 3. Add Azure Remote to Local Git
git remote add azure $GIT_URL
# 4. Deploy Code to Production
git push azure master
Note: Replace placeholders with your unique values. Ensure local Git repo is initialized.
