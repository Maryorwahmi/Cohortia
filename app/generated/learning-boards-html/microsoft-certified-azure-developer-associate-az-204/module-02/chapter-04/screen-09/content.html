Terminal Demo: Create Resource Group & VM
Command: Create Resource Group
RESOURCE_GROUP="VMDemoRG"
LOCATION="eastus"
VM_NAME="MyWebAppVM"

az group create --name $RESOURCE_GROUP --location $LOCATION

This command creates a new resource group to logically organize your VM and related resources.

Command: Create Azure VM
az vm create \
  --resource-group $RESOURCE_GROUP \
  --name $VM_NAME \
  --image UbuntuLTS \
  --admin-username azureuser \
  --generate-ssh-keys \
  --public-ip-sku Standard \
  --output json

Creates an Ubuntu VM, generates SSH keys for secure access, and sets up a public IP. Note the publicIpAddress from the output.

Pro-Tip

Always use --generate-ssh-keys for Linux VMs to ensure secure, passwordless authentication, which is a best practice.
