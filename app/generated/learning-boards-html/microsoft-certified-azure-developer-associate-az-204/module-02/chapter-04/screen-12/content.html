Terminal Demo: Verify & Connect
Action: Verify Nginx Installation

Open your web browser and navigate to the publicIpAddress of your VM. You should see the Nginx welcome page.

This confirms that Nginx is running and accessible over HTTP.

Optional: Connect via SSH
ssh azureuser@<YOUR_VM_PUBLIC_IP>

Replace <YOUR_VM_PUBLIC_IP> with the actual IP address. This allows secure remote access to your VM.

Key Takeaway

Always verify your deployments to ensure applications are accessible and management access is secure, confirming successful configuration.
