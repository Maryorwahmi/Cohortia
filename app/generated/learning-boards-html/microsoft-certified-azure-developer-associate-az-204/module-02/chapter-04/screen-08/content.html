Module 2.4›Chapter 2.4›Securing Azure VM Access and Network Connectivity
Core Security Principles
  • Use SSH keys for Linux, strong passwords for Windows.
  • Avoid exposing management ports (22, 3389) directly to the internet.
  • Use separate, encrypted data disks for sensitive application data.
  • Deploy VMs within a Virtual Network (VNet) for private communication.
Common Mistake

Directly exposing RDP/SSH ports to the internet, creating a significant security vulnerability.

Key Security Tools

Network Security Groups (NSG)

Firewall that filters network traffic to and from Azure resources.

Azure Bastion

Secure RDP/SSH connectivity to VMs over TLS, without public IPs.

These tools work together to create a layered security approach for your VMs.
