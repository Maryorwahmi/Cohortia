Terminal Demo: Configure NSG for HTTP Traffic
Command: Get NSG Name
NSG_NAME=$(az vm show --resource-group $RESOURCE_GROUP --name $VM_NAME --query networkProfile.networkInterfaces[0].id --output tsv | xargs -n 1 az network nic show --query networkSecurityGroup.id --output tsv | xargs -n 1 az network nsg show --query name --output tsv)

This command dynamically retrieves the name of the Network Security Group associated with your VM.

Command: Create NSG Rule for HTTP (Port 80)
az network nsg rule create \
  --resource-group $RESOURCE_GROUP \
  --nsg-name $NSG_NAME \
  --name AllowHTTP \
  --protocol Tcp \
  --direction Inbound \
  --priority 100 \
  --source-address-prefixes '*' \
  --source-port-ranges '*' \
  --destination-address-prefixes '*' \
  --destination-port-ranges 80 \
  --access Allow

This rule opens port 80 (HTTP) for inbound traffic, allowing external access to your Nginx web server.

Security Best Practice

Always apply the principle of least privilege: only open ports that are absolutely necessary for your application to function.
