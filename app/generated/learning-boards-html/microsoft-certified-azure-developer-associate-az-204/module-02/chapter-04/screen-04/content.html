Definition

Infrastructure-as-a-Service (IaaS)

Azure VMs provide virtualized computing resources where Azure manages the underlying hardware, but you manage the operating system, runtime, and applications.

Your Responsibility
  • Operating System (OS) patching and updates
  • Application installation and maintenance
  • Runtime environments and dependencies
  • Data management and security within the OS
Key Takeaway

VMs offer the highest level of control in Azure's compute services, making them ideal for specific migration and software requirements.

Key Scenarios for Azure VMs

Lift-and-Shift Migrations

Migrate existing on-premises applications without significant code changes.

Specialized Software

Run applications requiring specific OS configurations or custom enterprise software.

Legacy Applications

Host older applications that cannot be easily containerized or adapted to serverless.

Specific Database Servers

Deploy database instances requiring dedicated OS control and performance tuning.
