Terminal Demo: Install Nginx with Custom Script Extension
Script: install_nginx.sh (local creation)
#!/bin/bash
sudo apt-get update
sudo apt-get install -y nginx
sudo systemctl start nginx
sudo systemctl enable nginx
echo "<h1>Hello from Azure VM!</h1>" | sudo tee /var/www/html/index.nginx-debian.html

This script updates packages, installs Nginx, starts it, and creates a simple HTML page.

Command: Apply Custom Script Extension
NGINX_INSTALL_SCRIPT_URL="https://raw.githubusercontent.com/Azure-Samples/azure-cli-samples/master/vm/install-nginx-on-ubuntu/install-nginx-on-ubuntu.sh"

az vm extension set \
  --resource-group $RESOURCE_GROUP \
  --vm-name $VM_NAME \
  --name customScript \
  --publisher Microsoft.Azure.Extensions \
  --version 2.1 \
  --settings "{\"fileUris\": [\"$NGINX_INSTALL_SCRIPT_URL\"],\"commandToExecute\": \"./install-nginx-on-ubuntu.sh\"}"

This command applies the custom script extension to your VM, executing the Nginx installation script.

Important Note

In a production environment, always host your custom scripts securely in Azure Storage, not a public URL.
