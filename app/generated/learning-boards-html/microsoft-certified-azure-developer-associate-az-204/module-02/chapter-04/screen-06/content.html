What are VM Extensions?

Small applications that run on Azure VMs to provide post-deployment configuration and automation capabilities.

Benefits
  • Automate software installation
  • Run custom scripts for setup
  • Configure anti-malware
  • Collect diagnostics
  • Ensure consistent configurations
Key Takeaway

VM extensions are essential for automating setup tasks, enabling infrastructure as code, and ensuring consistent VM deployments.

Custom Script Extension Example
az vm extension set \
  --resource-group MyVmRG \
  --vm-name MyUbuntuVM \
  --name customScript \
  --publisher Microsoft.Azure.Extensions \
  --version 2.1 \
  --settings '{
    "fileUris": ["https://raw.githubusercontent.com/Azure-Samples/azure-cli-samples/master/vm/install-nginx-on-ubuntu/install-nginx-on-ubuntu.sh"],
    "commandToExecute": "./install-nginx-on-ubuntu.sh"
  }'
Practical Use Case

Automatically install a web server like Nginx and deploy a simple web page immediately after VM creation.
