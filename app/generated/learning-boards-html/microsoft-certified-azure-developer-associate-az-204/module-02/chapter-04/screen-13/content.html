Key Concepts

Essential terms for Azure Virtual Machines

Azure Virtual Machines (VMs)

IaaS compute resources providing full control over the OS and software stack.

VM Image

A template used to create a VM, containing an operating system and potentially pre-installed software.

VM Size

Defines the number of vCPUs, memory, and temporary storage capacity of a VM.

Summary Takeaway

Azure VMs provide the foundational IaaS layer, with images and sizes defining the core characteristics of your virtualized compute resources.
