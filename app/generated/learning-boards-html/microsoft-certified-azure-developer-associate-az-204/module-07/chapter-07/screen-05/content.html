Core Components

Defining API Access and Control

APIM uses a structured approach to expose backend services and manage consumer access.

1. API

Represents a backend service (e.g., Azure Function) exposed through APIM, with defined operations.

2. Product

A logical grouping of one or more APIs, packaged for different consumer segments (e.g., Basic, Premium).

3. Subscription

Mechanism for consumers to gain access to products, identified by a unique subscription key for authentication.

Key Takeaway

This tiered model allows for granular control over API access, enabling monetization and tailored experiences for different consumer groups.
