Policy Scenarios

Transforming & Monitoring API Traffic

Adapt API requests/responses and gain insights into API performance and usage.

URL Rewriting

Change the backend URL path for incoming requests while maintaining the public API endpoint.

Header Manipulation

Add, remove, or modify HTTP headers in requests or responses (e.g., set-header).

Body Transformation

Reshape request/response bodies using XSLT or Liquid templates for data format compatibility.

Monitoring & Logging

Send events to Event Hubs or log to Azure Monitor for diagnostics and analytics.

Key Takeaway

Transformation policies enable seamless integration, while monitoring policies provide essential visibility into API operations.

Example: Set Header Policy

<policies>  <inbound>    <set-header name="X-Request-ID" exists-action="override">      <value>@(Guid.NewGuid().ToString())</value>    </set-header>    <base />  </inbound>  <outbound>    <base />  </outbound></policies>

This policy injects a unique X-Request-ID header into every inbound request for tracing purposes.
