Core Concept

Understanding AKS Architecture

AKS separates the Kubernetes control plane (managed by Azure) from agent nodes (your VMs running containers), simplifying management and enhancing focus on applications.

Key Takeaway

AKS abstracts the Kubernetes control plane, letting you manage your applications on agent nodes without worrying about the underlying infrastructure management.

Common Misconception

It's a common mistake to think you manage the entire Kubernetes cluster infrastructure in AKS. Remember, Azure manages the control plane components for you.

AKS Control Plane
Managed by Azure: API Server, Scheduler, Controller Manager, etcd. Handles cluster operations and state management.
Abstraction
AKS Agent Nodes
Your Virtual Machines: Run Pods and containers. You manage their configuration, scaling, and OS.
