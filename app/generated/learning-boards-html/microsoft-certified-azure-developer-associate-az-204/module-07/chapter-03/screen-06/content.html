Example

Deploying an NGINX Web Server

Define a Deployment for NGINX Pods and a LoadBalancer Service to expose them externally via an Azure Load Balancer.

Key Takeaway

This example demonstrates the fundamental pattern of defining application components (Deployment) and their network exposure (Service) in Kubernetes.

Hands-on

Refer to the 'Hands-on activity' section for the exact YAML manifests and `kubectl` commands to deploy this NGINX server yourself.

nginx-deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:latest
        ports:
        - containerPort: 80
nginx-service.yaml
apiVersion: v1
kind: Service
metadata:
  name: nginx-service
spec:
  selector:
    app: nginx
  ports:
    - protocol: TCP
      port: 80
      targetPort: 80
  type: LoadBalancer
