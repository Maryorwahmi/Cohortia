Question 1

External Access Issue

Users can't access your AKS app. Pods are running. What's likely misconfigured?

  • A) Deployment
  • B) Pod
  • C) ConfigMap
  • D) Service (LoadBalancer/NodePort)

Question 2

Automatic Scaling

Need to scale Pods automatically based on CPU. Which feature?

  • A) VPA
  • B) HPA
  • C) Cluster Autoscaler
  • D) Rolling Update
Correct Answer: B
