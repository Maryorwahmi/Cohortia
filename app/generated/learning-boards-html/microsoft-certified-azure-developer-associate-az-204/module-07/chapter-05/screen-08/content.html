Durable Function Components

Understanding the roles of orchestrator, activity, and entity functions.

Orchestrator Function

Defines the workflow logic, coordinating activity and entity functions. It's the 'conductor' of the durable workflow.

Activity Function

Performs the actual work within the workflow, such as making API calls or processing data. These are typically stateless.

Entity Function

Manages explicit state, allowing for durable actors. They define operations to read and update a specific piece of state.

Key Takeaway

Durable Functions orchestrate complex workflows by delegating tasks to activity functions and managing state through orchestrator and entity functions, ensuring state persistence and resilience.
