Declarative Infrastructure with Bicep

Defining the desired state of your Azure resources.

Declarative vs. Imperative

  • •Declarative (Bicep): You describe the 'what' – the desired end state of your infrastructure.
  • •Imperative (Scripts): You specify the 'how' – a sequence of commands to execute.
Key Takeaway

Bicep's declarative nature simplifies complex deployments by focusing on the desired outcome, not the execution steps.

The Declarative Loop

Azure Resource Manager ensures your infrastructure matches the Bicep definition.

1. Define Desired State (Bicep)
2. Deploy via ARM
3. Azure Resources Match State
4. ARM Reconciles Differences
