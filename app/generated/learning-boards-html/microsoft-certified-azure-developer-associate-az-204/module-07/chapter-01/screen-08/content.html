Defining Azure Resources in Bicep

Directly mapping to Azure resource provider schemas for precise control.

param location string = resourceGroup().locationparam storageAccountName string = 'mystorage${uniqueString(resourceGroup().id)}'resource myStorageAccount 'Microsoft.Storage/storageAccounts@2022-09-01' = { // Resource Type & API Version  name: storageAccountName // Resource Name  location: location // Resource Location  sku: { // SKU property    name: 'Standard_LRS'  }  kind: 'StorageV2' // Kind property  properties: { // Additional properties    accessTier: 'Hot'  }}
Resource Type & API Version

Identifies the Azure service and locks to a specific API version for consistency.

Name & Location

Unique identifier for the resource and the Azure region for deployment.

Properties

Configuration details specific to the resource, such as SKU, kind, and access tiers.

Pro Tip

Always consult Azure documentation for the correct resource types, API versions, and properties to avoid deployment errors.
