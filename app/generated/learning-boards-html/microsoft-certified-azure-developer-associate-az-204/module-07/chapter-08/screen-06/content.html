Granular Telemetry

Capturing Custom Metrics and Events

Extending Application Insights with application-specific data.

Custom Metrics

Numerical values describing application-specific performance or business logic (e.g., 'SuccessfulCheckouts', 'CalculationDuration').

Custom Events

Records discrete occurrences or user actions within your application (e.g., 'UserRegistered', 'FeatureActivated').

Why Use Them?

Gain deeper, business-relevant insights beyond standard telemetry, enabling targeted optimization and data-driven decisions.

Key Takeaway

Custom metrics and events allow you to extend Application Insights to track application-specific business logic and performance indicators, providing granular, tailored insights.

C# Example: Tracking Custom Metrics
using Microsoft.ApplicationInsights;

public class MyService
{
    private readonly TelemetryClient _telemetryClient;

    public MyService(TelemetryClient telemetryClient)
    {
        _telemetryClient = telemetryClient;
    }

    public void ProcessOrder(Order order)
    {
        // Simulate processing time
        int processingTimeMs = SimulateProcessing();

        // Track a custom metric: processing time
        _telemetryClient.TrackMetric("OrderProcessingTime", processingTimeMs);

        // Track a custom event: order processed
        _telemetryClient.TrackEvent("OrderProcessed", 
            new Dictionary<string, string> { { "OrderId", order.Id } });

        // ... further processing ...
    }

    private int SimulateProcessing() { return new Random().Next(100, 1000); }
}
`TelemetryClient` is used to send custom data.
