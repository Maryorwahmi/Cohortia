Action Groups: Automating Alert Responses

Define what happens when an alert fires, from notifications to automated remediation.

Notification Actions

  • Email: Send notifications to specific email addresses or distribution lists.
  • SMS: Send text messages to mobile numbers for critical alerts.
  • Push to Mobile App: Deliver notifications directly to the Azure mobile app.
  • Voice Call: Initiate an automated voice call to a phone number.

Automation Actions

  • Webhook: Call a custom HTTP endpoint to trigger external systems or custom scripts.
  • Azure Function: Execute a serverless function for complex custom logic or remediation.
  • Logic App: Trigger a workflow for advanced orchestration and integration with other services.
  • Automation Runbook: Start an Azure Automation runbook for predefined operational tasks.

Example Scenario

An alert for high error rates in an Azure Function triggers an Action Group. This group sends an email to the development team, an SMS to the on-call engineer, and executes an Azure Logic App to restart the problematic Function App instance, attempting automated recovery.

Key Takeaway

Action Groups are crucial for automating alert responses, combining various notification and remediation actions to streamline incident management and improve system resilience.
