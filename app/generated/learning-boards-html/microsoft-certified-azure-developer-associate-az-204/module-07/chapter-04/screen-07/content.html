Publishing Custom Events with Event Grid

Sending events from your applications to an Event Grid Topic.

Custom Event Flow

  • Define Custom Topic: Create an Event Grid Custom Topic in Azure.
  • Use SDK: Integrate Event Grid Data Plane SDK (e.g., C#, Python) into your application.
  • Publish Events: Use `EventGridPublisherClient.SendEventsAsync()` to send events to your custom topic.
  • Event Schema: Events are JSON objects conforming to CloudEvents or Event Grid schema.

Delivery Guarantees

  • At-Least-Once Delivery: Event Grid ensures events are delivered at least once.
  • Retry Mechanisms: Built-in retries with exponential back-off for subscriber failures.
  • Dead-Lettering: Undeliverable events can be sent to a storage account for later analysis.

C# Custom Event Publisher

using Azure.Messaging.EventGrid; // NuGet package
using Azure.Core;

// ...

string topicEndpoint = "https://YOUR_TOPIC.eastus-1.eventgrid.azure.net/api/events";
string topicKey = "YOUR_TOPIC_KEY";

EventGridPublisherClient client = new EventGridPublisherClient(
    new Uri(topicEndpoint),
    new AzureKeyCredential(topicKey));

var customEvent = new EventGridEvent(
    subject: "/myapp/users/new",
    eventType: "MyApp.UserRegistered",
    dataVersion: "1.0",
    data: new { UserId = "user123", Email = "user@example.com" });

await client.SendEventAsync(customEvent);
Console.WriteLine("Custom event published.");

This code snippet demonstrates how to publish a custom 'UserRegistered' event to an Event Grid topic.

Key Takeaway

Custom applications can publish their own events to Event Grid topics using SDKs, enabling tailored reactive workflows with built-in delivery guarantees and error handling.
