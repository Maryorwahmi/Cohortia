Implementing the Event Grid Blob Processor Function

Writing C# code to handle Blob Created events.

Function Role

This Azure Function will serve as the subscriber endpoint for Event Grid. It's an HTTP-triggered function designed to receive and process events, specifically Microsoft.Storage.BlobCreated events.

  • Receives Event Grid events as JSON.
  • Handles subscription validation.
  • Processes BlobCreated events.

Key Logic Points

  • Deserialization: Events arrive as an array; deserialize the request body.
  • Validation: Respond to SubscriptionValidationEvent with its ValidationCode.
  • Event Processing: Extract data from BlobCreatedEventData and implement custom logic (e.g., logging, further processing).

C# Event Grid Blob Processor Function

// EventGridBlobProcessor.cs
using System;
using System.IO;
using System.Threading.Tasks;
using Microsoft.AspNetCore.Mvc;
using Microsoft.Azure.WebJobs;
using Microsoft.Azure.WebJobs.Extensions.Http;
using Microsoft.AspNetCore.Http;
using Microsoft.Extensions.Logging;
using Newtonsoft.Json;
using Azure.Messaging.EventGrid; 

public static class EventGridBlobProcessor
{
    [FunctionName("EventGridBlobProcessor")]
    public static async Task<IActionResult> Run(
        [HttpTrigger(AuthorizationLevel.Function, "post", Route = null)] HttpRequest req,
        ILogger log)
    {
        string requestBody = await new StreamReader(req.Body).ReadToEndAsync();
        var events = JsonConvert.DeserializeObject<EventGridEvent[]>(requestBody);

        foreach (var eventGridEvent in events)
        {
            if (eventGridEvent.EventType == "Microsoft.EventGrid.SubscriptionValidationEvent")
            {
                var validationEventData = eventGridEvent.Data.ToObject<SubscriptionValidationEventData>();
                return new OkObjectResult(new SubscriptionValidationResponse(validationEventData.ValidationCode));
            }
            else if (eventGridEvent.EventType == "Microsoft.Storage.BlobCreated")
            {
                var blobCreatedEventData = eventGridEvent.Data.ToObject<StorageBlobCreatedEventData>();
                log.LogInformation($"Blob Created: {blobCreatedEventData.Url}");
                // Add your actual blob processing logic here
            }
        }
        return new OkResult();
    }
}

This code handles Event Grid validation and logs details for Blob Created events.

Key Takeaway

The Azure Function acts as our event subscriber, parsing Event Grid events, handling validation, and performing custom logic, such as processing a newly created blob.
