Setting Up Event Grid with Blob Storage and Azure Functions

Preparing your Azure resources for event-driven automation.

Lab Goal: Reactive File Processing

We will configure Azure Event Grid to trigger an Azure Function whenever a new blob is created in a specific Azure Blob Storage container. This demonstrates serverless automation.

  • Event Source: Azure Blob Storage
  • Event Router: Azure Event Grid
  • Event Handler: Azure Function

Prerequisites

  • An active Azure Subscription.
  • Azure CLI installed and configured.
  • Visual Studio Code (or similar IDE) for Function development.

1. Create Azure Resources

# Define variables
RESOURCE_GROUP="cohortia-eventgrid-rg"
LOCATION="eastus"
STORAGE_ACCOUNT_NAME="cohortiaeventgrid$(openssl rand -hex 4)"
CONTAINER_NAME="input-blobs"

# Create Resource Group
az group create --name $RESOURCE_GROUP --location $LOCATION

# Create Storage Account
az storage account create \
  --name $STORAGE_ACCOUNT_NAME \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION \
  --sku Standard_LRS

# Create Blob Container
az storage container create \
  --name $CONTAINER_NAME \
  --account-name $STORAGE_ACCOUNT_NAME \
  --public-access off

These commands create a resource group, a unique storage account, and a private blob container.

Key Takeaway

The initial setup involves provisioning a resource group, a storage account, and a blob container, which will serve as the event source for our Event Grid-driven Azure Function.
