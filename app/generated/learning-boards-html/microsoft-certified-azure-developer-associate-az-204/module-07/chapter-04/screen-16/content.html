Key Concepts

Deepening your understanding of event processing

Event Grid Topic

An endpoint where publishers send events to Event Grid, which can be system-defined or custom.

Event Subscription

Defines which events from an Event Grid Topic should be delivered to a specific endpoint (subscriber).

Publisher / Consumer

A Publisher sends events; a Subscriber/Consumer receives and processes events from Event Grid or Event Hubs.

Partitions (Event Hubs)

Logical divisions of an Event Hub's event stream, enabling parallel processing and enhancing scalability.

Checkpointing (Event Hubs)

Recording the last successfully processed event in an Event Hubs stream to enable recovery from failures.

Dead-lettering

A mechanism to send events that could not be delivered or processed successfully to a designated storage for analysis.

Summary Takeaway

Understanding event flow components like topics and subscriptions, alongside resiliency mechanisms like partitions, checkpointing, and dead-lettering, is crucial for building robust event-driven systems.
