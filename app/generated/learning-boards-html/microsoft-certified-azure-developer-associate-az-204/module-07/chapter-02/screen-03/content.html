Learning Objectives

Deepen your understanding of CI/CD and pipeline implementation.

01
Explain CI/CD

Understand the core components and benefits of Continuous Integration (CI) and Continuous Delivery/Deployment (CD) within Azure DevOps, recognizing their role in modern software development.

VERIFIED COMPETENCY MILESTONE
02
Design YAML Pipelines

Design and implement multi-stage YAML pipelines for building and deploying applications to Azure, understanding the structure of stages, jobs, and steps.

VERIFIED COMPETENCY MILESTONE
03
Configure Connections & Agents

Configure service connections for secure authentication with Azure and set up agent pools for efficient pipeline execution across different environments.

VERIFIED COMPETENCY MILESTONE
04
Implement Release Gates & Troubleshoot

Implement release gates and approvals for controlled deployments and learn to troubleshoot common issues encountered in Azure DevOps pipelines.

VERIFIED COMPETENCY MILESTONE
