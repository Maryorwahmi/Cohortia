System Topics: Built-in Event Streams

Reacting to events published directly by Azure services.

What are System Topics?

  • Built-in topics provided by Azure services.
  • Automatically created and managed by Azure.
  • You subscribe to them; you don't create them.
  • Enable reactions to operational events within Azure.

Example: Blob Storage Event

To react to a new blob being created, you'd create an event subscription on the Blob Storage account's system topic. Event Grid then pushes 'BlobCreated' events to your handler.

Key Takeaway

System topics are essential for integrating your applications with the native event streams of Azure services, allowing for automated responses to platform-level changes.

Common Azure System Topics

Azure Storage

Blob created/deleted, queue messages

Azure Resource Groups

Resource created/deleted/updated

Azure IoT Hub

Device created/deleted, telemetry

Azure Key Vault

Secret new version, vault access policy
