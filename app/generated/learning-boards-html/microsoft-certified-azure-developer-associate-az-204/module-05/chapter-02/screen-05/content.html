Building Blocks of a Logic App Workflow

Triggers initiate workflows, actions perform tasks, and connectors bridge services.

Trigger

Starts the workflow

Actions

Perform operations

Connectors

Bridge to services

Trigger Types

  • Scheduled recurrence (e.g., hourly)
  • HTTP request (callable API)
  • Event-driven (e.g., new file, email)

Action Examples

  • Send an email
  • Create a user account
  • Update a database record
  • Post to social media

Connector Variety

  • Microsoft services (Azure, O365)
  • Third-party (Salesforce, Twitter)
  • Custom APIs (HTTP connector)
Key Takeaway

Logic Apps combine triggers, actions, and connectors to visually orchestrate complex, event-driven workflows across diverse services.
