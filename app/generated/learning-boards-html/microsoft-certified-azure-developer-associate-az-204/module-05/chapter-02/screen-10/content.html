Anatomy of a Logic App Workflow Definition

Understanding the underlying JSON structure for triggers, actions, and connections.

JSON Structure Overview

  • `definition` object: Contains the entire workflow logic.
  • `triggers` section: Defines how the Logic App starts (e.g., HTTP request, schedule).
  • `actions` section: Lists all operations performed by the workflow.
  • `inputs`: Configuration for each action, including method, URI, and authentication.
  • `runAfter`: Specifies dependencies and error handling conditions.
Key Takeaway

The JSON definition provides a declarative, programmatic way to define, manage, and troubleshoot Logic App workflows.

{
    "definition": {
        "$schema": "https://schema.management.azure.com/providers/Microsoft.Logic/schemas/2016-06-01/workflowdefinition.json#",
        "actions": {
            "HTTP_Request_to_Microsoft_Graph": {
                "inputs": {
                    "method": "GET",
                    "uri": "https://graph.microsoft.com/v1.0/me",
                    "authentication": {
                        "type": "ManagedServiceIdentity" // <-- Managed Identity for secure access
                    }
                },
                "runAfter": {},
                "type": "Http"
            },
            "Send_an_email_(V2)": {
                "inputs": {
                    "body": {
                        "IsHtml": true,
                        "Body": "<p>Hello @{body('HTTP_Request_to_Microsoft_Graph')['displayName']},</p>",
                        "Subject": "Microsoft Graph Profile Access Notification",
                        "To": "@{body('HTTP_Request_to_Microsoft_Graph')['mail']}"
                    },
                    "host": {
                        "connection": {
                            "name": "@parameters('$connections')['office365']['connectionId']"
                        }
                    },
                    "method": "post",
                    "path": "/v2/Mail"
                },
                "runAfter": {
                    "HTTP_Request_to_Microsoft_Graph": [
                        "Succeeded" // <-- Action runs only if previous succeeded
                    ]
                },
                "type": "ApiConnection"
            }
        },
        "triggers": {
            "When_a_HTTP_request_is_received": {
                "inputs": {
                    "method": "POST",
                    "schema": {} // <-- Defines input JSON schema
                },
                "kind": "Http",
                "type": "Request" // <-- HTTP Trigger
            }
        },
        "outputs": {}
    },
    "parameters": {
        "$connections": {
            "defaultValue": {},
            "type": "Object"
        }
    }
}
