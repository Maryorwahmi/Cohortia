Implementing the Image Resizer Function: Processing and Output

Add image resizing logic and configure a Blob output binding to save results.

Image Processing

Utilize a library like SixLabors.ImageSharp to perform transformations on the inputBlob stream.

Blob Output Binding

[Blob("resized-images/{name}", FileAccess.Write)] directs the function's output to a new blob in a specified container.

Key Takeaway

The combination of input and output bindings allows the function's core logic to be entirely focused on data transformation, abstracting away I/O concerns.

using System;
using System.IO;
using System.Threading.Tasks;
using Microsoft.Azure.WebJobs;
using Microsoft.Extensions.Logging;
using Azure.Messaging.EventGrid;
using SixLabors.ImageSharp;
using SixLabors.ImageSharp.Processing;

public static class ImageProcessorFunction
{
    [FunctionName("ImageResizer")]
    public static async Task Run(
        [EventGridTrigger] EventGridEvent eventGridEvent,
        [Blob("{data.url}", FileAccess.Read, Connection = "AzureWebJobsStorage")] Stream inputBlob,
        [Blob("resized-images/{name}", FileAccess.Write, Connection = "AzureWebJobsStorage")] Stream outputBlob, // Output binding: write resized blob
        ILogger log)
    {
        // ... logging and event type check ...
        if (eventGridEvent.EventType == "Microsoft.Storage.BlobCreated")
        {
            var data = eventGridEvent.Data.ToObjectFromJson<dynamic>();
            string blobUrl = data.url;
            string blobName = data.url.Split('/')[^1];
            log.LogInformation($"Processing new blob: {blobName} from {blobUrl}");

            if (inputBlob != null)
            {
                using (Image image = await Image.LoadAsync(inputBlob))
                {
                    image.Mutate(x => x.Resize(200, 200)); // Resize the image
                    await image.SaveAsync(outputBlob, image.Metadata.DecodedImageFormat); // Save to output binding
                    log.LogInformation($"Resized image '{blobName}' and saved to 'resized-images' container.");
                }
            }
            else { log.LogError($"Input blob for '{blobName}' was null."); }
        }
        // ... unhandled event type warning ...
    }
}
Code Annotation: The image.Mutate line performs the resizing, and image.SaveAsync writes the result to the outputBlob stream, which is managed by the output binding.
