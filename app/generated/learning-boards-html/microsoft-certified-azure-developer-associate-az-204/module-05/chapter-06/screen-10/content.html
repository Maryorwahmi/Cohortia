Implementing the Image Resizer Function: Trigger and Input

Set up an Event Grid trigger and a Blob input binding to receive image data.

Event Grid Trigger

The [EventGridTrigger] attribute ensures the function runs when a relevant event occurs, passing the event details.

Blob Input Binding

[Blob("{data.url}", FileAccess.Read)] automatically reads the blob content into a Stream, simplifying data access.

Key Takeaway

Declarative attributes for triggers and bindings significantly reduce boilerplate code, allowing focus on core business logic.

using System;
using System.IO;
using System.Threading.Tasks;
using Microsoft.Azure.WebJobs;
using Microsoft.Extensions.Logging;
using Azure.Messaging.EventGrid;

public static class ImageProcessorFunction
{
    [FunctionName("ImageResizer")]
    public static async Task Run(
        [EventGridTrigger] EventGridEvent eventGridEvent, // Triggered by Event Grid
        [Blob("{data.url}", FileAccess.Read, Connection = "AzureWebJobsStorage")] Stream inputBlob, // Input binding: read original blob
        ILogger log)
    {
        log.LogInformation($"Event Grid event received: {eventGridEvent.EventType}");
        log.LogInformation($"Subject: {eventGridEvent.Subject}");

        if (eventGridEvent.EventType == "Microsoft.Storage.BlobCreated")
        {
            // ... image processing logic will go here ...
        }
        else
        {
            log.LogWarning($"Unhandled event type: {eventGridEvent.EventType}");
        }
    }
}
Code Annotation: The [EventGridTrigger] attribute automatically binds the incoming event, and [Blob] with FileAccess.Read provides the blob's content as a stream.
