Connecting with StackExchange.Redis

The standard client for .NET applications

Key Components for Connection

  • Connection String: Securely stored (e.g., Azure Key Vault, App Settings).
  • ConnectionMultiplexer: Manages the physical connection to Redis.
  • IDatabase: Provides methods for performing Redis operations.
Key Takeaway

The ConnectionMultiplexer should be a singleton instance in your application for optimal performance and resource management.

C# Connection Example
using System;
using System.Threading.Tasks;
using StackExchange.Redis;

public class RedisConnectionService
{
    private static ConnectionMultiplexer _redis;
    private static IDatabase _db;
    private static readonly string _connectionString = 
        Environment.GetEnvironmentVariable("RedisCacheConnectionString");

    public static async Task InitializeAsync()
    {
        if (_redis == null || !_redis.IsConnected)
        {
            _redis = await ConnectionMultiplexer.ConnectAsync(_connectionString);
            _db = _redis.GetDatabase();
            Console.WriteLine("Connected to Azure Cache for Redis.");
        }
    }

    public static void Dispose()
    {
        _redis?.Dispose();
        Console.WriteLine("Disconnected from Azure Cache for Redis.");
    }
}

Note: The ConnectionMultiplexer is thread-safe and should be reused across your application's lifetime.
