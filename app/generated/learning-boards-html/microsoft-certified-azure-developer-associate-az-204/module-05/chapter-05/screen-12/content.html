Hands-on: Integrating Redis in .NET Core

Provisioning, connecting, and testing Redis operations

Task Overview

  • Provision Azure Cache for Redis instance.
  • Retrieve connection string.
  • Create .NET Core console application.
  • Install StackExchange.Redis NuGet package.
  • Implement RedisCacheService for basic operations.
  • Set RedisCacheConnectionString environment variable.
  • Run and observe cache set/get with TTL expiry.

Goal: Understand the end-to-end process of integrating Azure Cache for Redis into a .NET application.

Key Steps & Considerations

  • Azure Portal: Create Basic/Standard C0/C1 tier for learning.
  • Access Keys: Copy the primary connection string securely.
  • Program.cs: Use the provided RedisCacheService example.
  • Environment Variable: Crucial for secure connection string management.
  • Observation: Note the 'Not Found' after TTL expiry.

Pro Tip: Always use environment variables or Key Vault for sensitive connection strings, especially in production.

Key Takeaway

Hands-on practice with provisioning, connecting, and performing operations is essential for solidifying your understanding of Azure Cache for Redis integration.
