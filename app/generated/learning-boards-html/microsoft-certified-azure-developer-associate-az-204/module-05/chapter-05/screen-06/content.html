Provisioning Azure Cache for Redis

Choosing the right tier and configuration

Basic Tier

  • Single node
  • No SLA
  • Ideal for dev/test
  • Lowest cost

Use Case: Quick proof-of-concept or learning environment.

Standard Tier

  • Two nodes (primary/replica)
  • High availability
  • SLA included
  • Suitable for production

Use Case: Most production web applications requiring reliability.

Premium Tier

  • Advanced features (VNet, persistence, clustering)
  • Highest performance & scalability
  • SLA included
  • Mission-critical workloads

Use Case: Enterprise applications requiring maximum security and performance.

Key Takeaway

The choice of Redis tier directly impacts features, performance, and high availability; Standard or Premium tiers are recommended for production environments.
