Redis Operations

Performing Basic Caching Operations

Core key-value interactions with Redis

Key-Value Operations Overview

  • Set: Stores a key-value pair, optionally with a TTL.
  • Get: Retrieves the value associated with a key.
  • Delete: Removes a key-value pair from the cache.
Key Takeaway

Mastering StringSetAsync, StringGetAsync, and KeyDeleteAsync is fundamental for effective Redis cache management.

C# RedisCacheService Methods
public static async Task SetCacheValueAsync(string key, string value, TimeSpan? expiry = null)
{
    await InitializeAsync();
    await _db.StringSetAsync(key, value, expiry);
    Console.WriteLine($"Set cache key '{key}' with value '{value}' (Expiry: {expiry?.TotalSeconds ?? 0}s)");
}

public static async Task<string> GetCacheValueAsync(string key)
{
    await InitializeAsync();
    string value = await _db.StringGetAsync(key);
    Console.WriteLine($"Get cache key '{key}': {(value ?? "Not Found")}");
    return value;
}

public static async Task DeleteCacheValueAsync(string key)
{
    await InitializeAsync();
    await _db.KeyDeleteAsync(key);
    Console.WriteLine($"Deleted cache key '{key}'");
}

Note: The expiry parameter in StringSetAsync uses TimeSpan to define how long the data remains in the cache before automatic invalidation.
