Module 6 › Chapter 6.7 › System-assigned vs. User-assigned
System-assigned Managed Identity
  • Tied directly to the lifecycle of a single Azure resource.
  • Automatically created and managed by Azure.
  • A resource can have only one system-assigned identity.
  • Ideal for single-resource scenarios where identity management should be automatic.
User-assigned Managed Identity
  • Created as a standalone Azure resource.
  • Has its own lifecycle, independent of compute resources.
  • Can be assigned to multiple Azure resources.
  • Suitable for shared identities or when granular lifecycle control is needed.
Comparison

System-assigned is simpler for single resources, while User-assigned offers more flexibility for shared identities and independent lifecycles.

Key Takeaway

Choose the identity type that best matches your resource's lifecycle and sharing requirements.
