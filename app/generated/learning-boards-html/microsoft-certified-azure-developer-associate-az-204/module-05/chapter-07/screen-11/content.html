Module 6 › Chapter 6.7 › Common Mistakes and Misconceptions
Common Pitfalls
  • Missing Permissions: Enabling Managed Identity but not granting it access to Key Vault or other services.
  • Service Compatibility: Assuming Managed Identities work with all services; always verify Azure AD support.
  • Incorrect Scope: Granting permissions at the wrong level (e.g., Key Vault vs. specific secret).
  • Over-Privileging: Granting more permissions than necessary, violating the least privilege principle.
  • Local Development vs. Azure: Not understanding how `DefaultAzureCredential` works differently in development vs. production.
Misconception

"My application is secure because I'm using environment variables for secrets." While better than hardcoding, environment variables still require management and can be exposed.

Key Takeaway

Carefully review configurations and permissions to avoid common mistakes and ensure robust security.
