Module 6 › Chapter 6.7 › Lab Walkthrough: Securely Accessing Key Vault
Lab Steps Overview
  1. Create Key Vault: Store a sample secret and note the Vault URI.
  2. Create App Service: Enable System-assigned Managed Identity.
  3. Grant Permissions: Assign 'Get'/'List' secret permissions to the Managed Identity in Key Vault.
  4. Develop .NET Web API: Use `Azure.Identity` and `Azure.Security.KeyVault.Secrets` with `DefaultAzureCredential`.
  5. Deploy API: Publish the Web API to the App Service.
  6. Configure App Service: Add `KEY_VAULT_URI` as an application setting.
  7. Test Endpoint: Verify the secret is retrieved securely.
Hands-on Learning

This practical exercise reinforces the concepts by building a complete, secure credential retrieval system.

Key Takeaway

Successfully completing this lab demonstrates your ability to implement secure credential management in Azure.
