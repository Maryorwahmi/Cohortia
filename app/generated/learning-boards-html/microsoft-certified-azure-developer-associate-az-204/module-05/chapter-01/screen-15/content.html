Practical Application

Deploying and Testing APIM Policies

Walk through deploying an APIM instance, importing an API, and applying a rate limit.

01

Deploy Azure Function App

Create an HTTP Trigger function (e.g., 'HelloWorld') that returns a simple greeting. This will be your backend API.

02

Deploy Azure API Management

Provision a new APIM instance in the Azure portal, choosing the 'Developer' tier for learning purposes. Note that deployment can take time.

03

Import Function App API

In your APIM instance, import the 'HelloWorld' Function App, setting a display name and API URL suffix.

04

Apply Rate Limiting Policy

Navigate to your imported API's operations, open the policy editor, and add a <rate-limit calls="2" renewal-period="60" /> policy.

05

Test the API and Policy

Use the APIM test console to make multiple calls. Observe successful calls followed by a '429 Too Many Requests' error.

Key Takeaway

This hands-on activity demonstrates the end-to-end process of deploying an API, integrating it with APIM, and enforcing policies to control its behavior.
