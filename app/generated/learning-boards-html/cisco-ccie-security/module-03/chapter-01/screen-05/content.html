Packet Filtering Firewalls: The Basic Gatekeeper

Inspecting individual packets without tracking connection state.

Definition

A stateless firewall that inspects individual packets based on static criteria like source/destination IP, port, and protocol, operating at OSI Layers 3 and 4.

How it Works

Each packet is examined against a predefined access control list (ACL). If it matches a permit rule, it passes; otherwise, it's dropped. No memory of past packets in a connection.

Example Scenario

A rule allows outbound TCP port 80. A packet filtering firewall would also allow an unsolicited inbound TCP port 80 packet if it matches the same criteria, as it doesn't know if it's a response to an internal request.

Key Takeaway

Packet filtering firewalls are fast but stateless, making them less secure for dynamic connections as they lack context about ongoing sessions.
