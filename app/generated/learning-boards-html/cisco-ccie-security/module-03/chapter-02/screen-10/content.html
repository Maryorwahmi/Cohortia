Core Mechanism

The Dynamic Connection Table

How stateful firewalls track session details.

What the Table Stores

  • •Source IP & Port: Originator of the connection.
  • •Destination IP & Port: Target of the connection.
  • •Protocol: TCP, UDP, ICMP, etc.
  • •Connection State: e.g., SYN_SENT, ESTABLISHED, FIN_WAIT.
  • •TCP Sequence Numbers: For preventing session hijacking.
Analogy

A detailed guest registry at a secure building, tracking who entered, where they're going, and when they're expected to leave.

How it Works

  • •Entry created when outbound connection initiated.
  • •Return traffic matched against existing entries.
  • •Legitimate return traffic permitted automatically.
  • •Entry removed upon connection termination.
Key Takeaway

The connection table is the 'brain' of a stateful firewall, enabling it to understand and manage the full lifecycle of network conversations.
