Critical Weaknesses

The Stateless Nature and Its Vulnerabilities

Why packet filters fall short in modern networks.

Key Limitations

  • •Vulnerability to Spoofing: Easily fooled by forged source IP addresses.
  • •Symmetry Issues: Struggles with legitimate return traffic for outbound connections.
  • •Complex Protocols: Cannot effectively handle dynamic port assignments (e.g., FTP).
  • •Configuration Complexity: Requires explicit rules for both directions of traffic.
Scenario

An internal user initiates a web request, but the web page never loads because the firewall blocks the server's response.

Common Mistakes with ACLs

  • •Incorrect Rule Order: Broad denies placed too high.
  • •Forgetting Implicit Deny: Leads to unexpected traffic drops.
  • •Lack of Bidirectional Rules: Blocking legitimate return traffic.
Key Takeaway

The stateless nature of packet filtering firewalls makes them vulnerable and impractical for securing complex, dynamic network applications.
