Core Concept

How Packet Filtering Firewalls Work

Decisions based on individual packet headers.

Stateless Packet Inspection

  • •Operates at Network (Layer 3) and Transport (Layer 4) layers.
  • •Examines each packet in isolation.
  • •No memory of previous packets or connection state.
  • •Decisions based purely on header information.
Example Criteria

Source IP, Destination IP, Source Port, Destination Port, Protocol Type (TCP/UDP/ICMP).

Rule-Based Processing

  • •Compares packets against a predefined list of rules (ACLs).
  • •Rules are processed in sequential order (top-down).
  • •First matching rule determines action (permit or deny).
  • •Implicit 'deny all' at the end of most rule sets.
Key Takeaway

Packet filtering offers basic, granular control but lacks the context needed for dynamic, secure communication.
