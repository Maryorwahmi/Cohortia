A Stateful Connection Walkthrough

Following a packet through a stateful firewall.

1. Outbound SYN Packet

Internal client (192.168.1.10:12345) sends SYN to external web server (203.0.113.50:80).

Firewall Action

Inspects outbound packet, creates connection table entry: (TCP, 192.168.1.10:12345 -> 203.0.113.50:80, SYN_SENT).

3. Connection Established

Subsequent data packets for the established session.

Firewall Action

Continues to monitor state and sequence numbers, permits legitimate traffic. Updates entry to ESTABLISHED.

2. Inbound SYN-ACK Packet

Web server responds with SYN-ACK to internal client.

Firewall Action

Consults connection table, finds matching entry, permits return traffic even without explicit inbound ACL.

4. Connection Termination

Client and server exchange FIN/ACK or RST packets.

Firewall Action

Removes the entry from the connection table, freeing resources.
