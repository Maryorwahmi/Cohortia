Cisco ASA CLI Configuration (Using Interface IP)
ASA(config)# object network INTERNAL_LAN
ASA(config-network-object)# subnet 192.168.1.0 255.255.255.0
ASA(config-network-object)# nat (inside,outside) dynamic interface
ASA(config-network-object)# exit
Command Breakdown
  • •
    `object network INTERNAL_LAN`: Defines the internal subnet for PAT.
  • •
    `nat (inside,outside) dynamic interface`: The key PAT rule. It translates source IPs from `INTERNAL_LAN` to the `outside` interface's IP, using port overloading.
Alternative: Using a Specific Public IP for PAT
ASA(config)# object network INTERNAL_LAN
ASA(config-network-object)# subnet 192.168.1.0 255.255.255.0
ASA(config-network-object)# nat (inside,outside) dynamic 203.0.113.50
ASA(config-network-object)# exit
Key Takeaway

PAT on ASA is typically configured using `nat (inside,outside) dynamic interface` for maximum efficiency, allowing many internal hosts to share the firewall's public IP.
