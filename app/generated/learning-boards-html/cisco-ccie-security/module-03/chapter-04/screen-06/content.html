Cisco ASA CLI Configuration
ASA(config)# object network WEB_SERVER_PRIVATE
ASA(config-network-object)# host 192.168.1.100
ASA(config-network-object)# nat (inside,outside) static 203.0.113.10
ASA(config-network-object)# exit
Command Breakdown
  • •
    `object network WEB_SERVER_PRIVATE`: Defines a logical name for the internal server.
  • •
    `host 192.168.1.100`: Specifies the internal private IP address of the server.
  • •
    `nat (inside,outside) static 203.0.113.10`: The core NAT rule, mapping the private host to the public IP for traffic between inside and outside interfaces.
Common Mistake

Forgetting Bidirectional Nature

Static NAT is inherently bidirectional. If you only want inbound access and not outbound initiation using the public IP, you must combine NAT with specific Access Control Lists (ACLs) to restrict outbound traffic from the server.

Key Takeaway

Static NAT on ASA uses `object network` and `nat (inside,outside) static` to create a permanent, bidirectional one-to-one mapping for internal servers.
