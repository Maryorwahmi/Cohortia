Module 3›Chapter 3.4›Dynamic NAT Config
Cisco ASA CLI Configuration
ASA(config)# object network INTERNAL_LAN
ASA(config-network-object)# subnet 192.168.1.0 255.255.255.0
ASA(config-network-object)# exit

ASA(config)# object network PUBLIC_IP_POOL
ASA(config-network-object)# range 203.0.113.20 203.0.113.22
ASA(config-network-object)# nat (inside,outside) dynamic PUBLIC_IP_POOL
ASA(config-network-object)# exit
Command Breakdown
  • •
    `object network INTERNAL_LAN`: Defines the internal subnet that will use Dynamic NAT.
  • •
    `object network PUBLIC_IP_POOL`: Defines the range of public IP addresses available for dynamic assignment.
  • •
    `nat (inside,outside) dynamic PUBLIC_IP_POOL`: The NAT rule that dynamically translates source IPs from `INTERNAL_LAN` to an available IP from `PUBLIC_IP_POOL`.
Dynamic NAT Flow
  • •
    Internal host initiates connection.
  • •
    ASA checks `PUBLIC_IP_POOL` for an available IP.
  • •
    ASA assigns an IP, translates the source, and forwards the packet.
  • •
    Upon session termination, the IP is released back to the pool.
Key Takeaway

Dynamic NAT on ASA uses defined network objects for both internal subnets and public IP pools to manage temporary one-to-one IP assignments.
