Key Concepts

Review the essential terms and definitions from this chapter.

Port Address Translation (PAT) / NAT Overload

A form of NAT that allows multiple private IP addresses to share a single public IP address by using different source port numbers.

`object network` & `nat` (ASA)

`object network` defines IP addresses/subnets; `nat (inside,outside) ...` is the core command for configuring NAT rules on Cisco ASA.

NAT Exemption (`no nat`)

A rule configured on a firewall to explicitly prevent NAT from occurring for specific traffic flows, often used for VPN traffic.

Summary Takeaway

PAT is key for IP conservation, ASA uses `object network` and `nat` commands for configuration, and `no nat` is used for explicit NAT exemption.
