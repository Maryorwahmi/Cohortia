Definition

Static Network Address Translation (SNAT)

A one-to-one, permanent mapping between a single private IP address and a single public IP address. This mapping is always active and bidirectional.

Ideal for consistent external access.
Key Characteristics
  • •
    One-to-One: Each private IP gets a dedicated public IP.
  • •
    Permanent: The mapping is fixed and always active.
  • •
    Bidirectional: Allows both inbound access and outbound connections using the public IP.
Typical Use Cases
  • •
    Web Servers: To host websites accessible from the internet.
  • •
    Mail Servers: For receiving external email traffic.
  • •
    VPN Servers: To allow remote users to connect to the internal network.
  • •
    Other Public-Facing Services: Any internal resource needing a fixed, public presence.
Key Takeaway

Static NAT is crucial for internal servers that must be consistently reachable from the internet via a dedicated public IP address.
