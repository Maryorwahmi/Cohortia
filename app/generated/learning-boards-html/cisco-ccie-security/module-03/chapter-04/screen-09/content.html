Definition

Port Address Translation (PAT) / NAT Overload

A form of NAT that allows multiple private IP addresses to share a single public IP address by using different source port numbers for each connection. This is a many-to-one mapping.

Most efficient for IP conservation.
How it Works
  • •
    IP & Port Translation: Modifies both source IP and source port.
  • •
    Unique Port Assignment: Firewall assigns a unique source port on the public IP for each internal connection.
  • •
    Translation Table: Maintains a table to track which internal host corresponds to which translated port.
Key Benefits
  • •
    Maximum IP Conservation: Thousands of internal users can share a single public IP.
  • •
    Cost-Effective: Reduces the number of public IP addresses an organization needs to purchase.
  • •
    Standard for Internet Access: The default choice for most outbound internet browsing.
Key Takeaway

PAT is the most efficient NAT type, allowing many internal hosts to share one public IP by leveraging unique port numbers for each connection.
