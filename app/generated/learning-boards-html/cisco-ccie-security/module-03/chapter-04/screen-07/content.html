Definition

Dynamic Network Address Translation (DNAT)

Provides a one-to-one mapping between private and public IP addresses, but the mapping is temporary and assigned dynamically from a pool of public IPs.

Flexible for outbound access.
How it Works
  • •
    Public IP Pool: A range of public IP addresses is configured on the firewall.
  • •
    Dynamic Assignment: When an internal host initiates a connection, an available public IP from the pool is assigned.
  • •
    Temporary: The mapping exists only for the duration of the session and is released back to the pool afterward.
When to Use Dynamic NAT
  • •
    More Internal Hosts than Public IPs: When you have a limited number of public IPs to share among many internal users.
  • •
    Outbound Internet Access: For general user internet browsing where a fixed public IP isn't required per user.
  • •
    Specific Logging Needs: Sometimes used when you need to trace outbound connections to a specific public IP from the pool.
Key Takeaway

Dynamic NAT provides flexible, temporary one-to-one mappings from a pool of public IPs, suitable for outbound access when public IPs are limited.
