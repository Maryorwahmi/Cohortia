Defining and Applying ASA Access Lists

ACLs are defined using the access-list command and then applied to interfaces using the access-group command, specifying directionality.

ACL Creation Syntax

  • access-list <name> extended permit/deny <protocol> <source> <destination> <port>
  • Example: access-list DMZ_INBOUND extended permit tcp any host 172.16.1.100 eq www

ACL Application Syntax

  • access-group <acl_name> in/out interface <interface_name>
  • Example: access-group DMZ_INBOUND in interface dmz
ASA(config)# access-list DMZ_INBOUND extended permit tcp any host 172.16.1.100 eq www
! This ACL permits TCP traffic from any source to the web server
! 172.16.1.100 on port 80 (www).

ASA(config)# access-group DMZ_INBOUND in interface dmz
! This command applies the DMZ_INBOUND ACL to the 'dmz' interface
! for inbound traffic, meaning traffic entering the dmz interface.
Key Takeaway

ACLs are defined globally and then explicitly applied to specific interfaces with a direction (in/out) to filter traffic.
