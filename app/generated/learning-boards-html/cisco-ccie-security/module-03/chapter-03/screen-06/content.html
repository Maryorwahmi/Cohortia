ASA Security Levels and Zones

Cisco ASA interfaces are fundamentally about security zones and security levels, which define trust boundaries and impact default traffic flow.

100

Most Trusted (e.g., Internal LAN)

Represents the highest trust network. Traffic initiated from here can flow to lower security levels by default.

50

Intermediate Trust (e.g., DMZ)

Used for networks like DMZs. Traffic flow is restricted from lower to higher levels.

0

Least Trusted (e.g., Internet)

Represents the lowest trust network. Traffic from here is implicitly denied to higher security levels.

Key Rule

Traffic from higher to lower security levels is permitted by default; all other traffic (lower to higher, same to same) is implicitly denied.
