Verifying Your ASA Configuration

After configuration, use essential show commands to verify interface status, routing, and ACL application to ensure correct operation.

show interface ip brief

Displays IP addresses and status of all interfaces.

show nameif

Shows interface names and their assigned security levels.

show route

Displays the ASA's routing table, including default routes.

ASA# show interface ip brief
ASA# show nameif
ASA# show route
ASA# show access-list
ASA# show access-group
ASA# show conn
Pro-Tip

Use show conn to see active connections and verify if traffic is being tracked by the stateful firewall as expected.
