Understanding ASA ACL Directionality

ASA ACL directionality (`in` vs. `out`) is relative to the interface, not the overall traffic flow through the firewall, which can be counter-intuitive.

'in' Direction

Filters traffic entering the interface from the connected network segment. Example: in interface inside for traffic originating from the internal LAN.

'out' Direction

Filters traffic leaving the interface towards the connected network segment. Less common for initial filtering on trusted interfaces.

Common Mistake

Applying an ACL 'out' on an interface when you intend to filter traffic originating from that connected network segment. Always consider the traffic's entry point to the ASA.
