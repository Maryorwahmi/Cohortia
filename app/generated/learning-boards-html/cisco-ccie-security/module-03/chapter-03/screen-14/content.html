Key Concepts

Important Principles for ASA Configuration

access-list command

Used to define extended Access Control Lists on the ASA, specifying permit/deny rules based on various packet criteria.

access-group command

Applies a defined ACL to an ASA interface in a specific direction (in or out), activating the filtering rules.

Directionality (ASA ACLs)

Refers to whether an ACL is applied to traffic entering ('in') or leaving ('out') an interface, which can be counter-intuitive compared to router ACLs.

Implicit Deny (ASA)

Traffic between interfaces with the same security level, or from a lower to a higher security level, is denied by default unless explicitly permitted.

Chapter Summary

ASA ACLs provide granular control, applied with specific directionality, and operate under an implicit deny rule for traffic not explicitly permitted between security zones.
