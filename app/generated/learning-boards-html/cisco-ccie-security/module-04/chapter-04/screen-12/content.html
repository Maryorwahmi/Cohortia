Configuration Step 4

Configure Group Policy

Granular Control Over VPN User Access

Key Group Policy Attributes

  • •VPN Tunnel Protocol: Specify allowed protocols (e.g., ssl-clientless, ssl-client).
  • •Split Tunneling Policy: Control whether all traffic goes through VPN (`tunnelall`) or only specific traffic (`splitspecified`).
  • •DNS Servers: Assign specific DNS servers to VPN clients.
  • •Access Rights: Define which internal resources users can access.
Key Takeaway

Group policies are essential for implementing granular control over VPN user access, allowing administrators to tailor network settings and security features to specific user groups.

ASA CLI: Group Policy Configuration

ASA(config)# group-policy RA_VPN_GROUP_POLICY internalASA(config-group-policy)# group-policy RA_VPN_GROUP_POLICY attributesASA(config-group-policy-attrs)# vpn-tunnel-protocol ssl-clientless ssl-clientASA(config-group-policy-attrs)# split-tunnel-policy tunnelall  ! Or splitspecifiedASA(config-group-policy-attrs)# dns-server value 192.168.1.10ASA(config-group-policy-attrs)# default-group-policy RA_VPN_GROUP_POLICY! Apply Group Policy to Tunnel GroupASA(config)# tunnel-group RA_VPN_GROUP webvpn-attributesASA(config-webvpn-attributes)# group-policy RA_VPN_GROUP_POLICY

This configures a group policy with specific VPN protocols, split tunneling, and DNS settings, then applies it to the previously defined tunnel group.

Security Note

`split-tunnel-policy tunnelall` is generally recommended for maximum security, as it forces all traffic through the corporate security controls.
