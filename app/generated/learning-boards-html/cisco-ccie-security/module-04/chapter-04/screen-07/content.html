SSL VPN Type

Client-Based SSL VPNs

Full Network Access with Dedicated Software

Key Aspects of Client-Based SSL VPNs

  • •Software Client Required: A small application is installed on the user's device.
  • •Full-Tunnel Connection: All network traffic is routed through the encrypted VPN tunnel.
  • •Broad Resource Access: Users can access virtually any resource on the corporate network.
  • •Seamless User Experience: Applications behave as if the user is physically in the office.
Key Takeaway

Client-based SSL VPNs, like Cisco AnyConnect, provide comprehensive and seamless access to all corporate network resources by establishing a full-tunnel connection via dedicated client software.

Example

A remote developer uses AnyConnect to access internal code repositories and development servers directly, just like in the office.
