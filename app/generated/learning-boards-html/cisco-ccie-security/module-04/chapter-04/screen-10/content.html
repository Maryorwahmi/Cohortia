Configure Connection Profile & IP Pool

Defining VPN Parameters and Client Addressing

Components & Their Roles

  • •Tunnel Group (Connection Profile): Defines VPN parameters for a group of users, including authentication and IP pool.
  • •Group Alias: A user-friendly name for the tunnel group, presented to clients.
  • •Authentication Server Group: Specifies where users will authenticate (e.g., LOCAL, RADIUS).
  • •IP Local Pool: A range of IP addresses assigned to connecting VPN clients.
Key Takeaway

Connection profiles and IP address pools are fundamental for defining how remote users connect, authenticate, and receive network addresses, enabling their access to corporate resources.

ASA CLI: Tunnel Group & IP Pool

ASA(config)# tunnel-group RA_VPN_GROUP type remote-accessASA(config-tunnel-group)# webvpn-attributesASA(config-webvpn-attributes)# group-alias AnyConnectAccess enableASA(config-webvpn-attributes)# authentication-server-group LOCAL  ! Or RADIUS/TACACS+ASA(config-webvpn-attributes)# address-pool VPN_POOLASA(config-webvpn-attributes)# exitASA(config)# ip local pool VPN_POOL 10.10.10.1-10.10.10.254 mask 255.255.255.0

This configures a tunnel group named RA_VPN_GROUP, sets its webvpn attributes, and defines an IP address pool for clients.

Common Mistake

Forgetting to define the `ip local pool` or assigning an overlapping IP range can lead to client connectivity failures.
