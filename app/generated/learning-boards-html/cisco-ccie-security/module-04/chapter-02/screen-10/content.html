IPsec Protocol
Encapsulating Security Payload (ESP)
Providing confidentiality, integrity, and authentication.

ESP is the more widely used IPsec protocol, offering data confidentiality (encryption), data integrity, and data origin authentication for IP packets.

  • •Confidentiality: Encrypts the IP payload or entire original packet.
  • •Integrity & Authentication: Uses hashing for verification.
  • •Preferred Choice: Widely adopted for securing sensitive data.
Key Takeaway

Encapsulating Security Payload (ESP) provides confidentiality (encryption), integrity, and authentication, making it the preferred IPsec protocol for securing sensitive data.
