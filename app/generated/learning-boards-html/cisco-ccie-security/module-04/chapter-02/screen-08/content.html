IKE Phase 2: Quick Mode
Establishing IPsec SAs for protecting user data.

IKE Phase 2 establishes the actual IPsec Security Associations (SAs) that will protect user data traffic. It occurs over the secure channel created in Phase 1.

  • •Data Protection: Focuses on securing the actual user data.
  • •Unidirectional SAs: Establishes two SAs (inbound/outbound) for data.
  • •Transform Set Defined: Parameters are specified in an IPsec transform set.
Key Takeaway

IKE Phase 2 establishes unidirectional IPsec SAs for user data protection, defining parameters like IPsec protocol, encryption, hashing, and mode within a transform set.

Key Phase 2 Parameters
IPsec Protocol

AH, ESP, or both.

Encryption Algorithm

AES, 3DES for data confidentiality.

Hashing Algorithm

SHA, MD5 for data integrity.

Mode

Tunnel (default for VPNs) or Transport.
