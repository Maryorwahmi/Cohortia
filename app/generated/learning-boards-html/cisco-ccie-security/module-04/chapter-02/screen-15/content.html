IPsec Protocols & Mechanisms
Understanding how data is protected.
IKE Phase 2

The second phase of IKE negotiation where the actual IPsec SAs are established to protect user data traffic.

ESP

Encapsulating Security Payload, an IPsec protocol providing data confidentiality (encryption), integrity, and authentication.

DH Group

Diffie-Hellman Group, a cryptographic method used within IKE to securely exchange keys over an insecure channel, ensuring perfect forward secrecy.

Summary Takeaway

IKE Phase 2 establishes data SAs, ESP provides encryption, integrity, and authentication, and DH groups enable secure key exchange for Perfect Forward Secrecy.
