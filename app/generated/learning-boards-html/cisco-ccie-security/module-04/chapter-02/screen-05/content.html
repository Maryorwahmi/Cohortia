Core Protocol
Internet Key Exchange (IKE)
Negotiating Security Associations for IPsec.

IKE is a protocol responsible for negotiating, establishing, and maintaining Security Associations (SAs) between two IPsec peers. SAs are the 'contracts' for secure communication.

  • •Automated Key Management: Eliminates manual key configuration.
  • •Defines Parameters: Specifies encryption, hashing, and key lifetimes.
  • •Two Phases: Operates in distinct Phase 1 and Phase 2 for setup.
Key Takeaway

IKE automates the negotiation and maintenance of Security Associations (SAs), defining encryption, hashing, and key lifetimes for IPsec, simplifying key management.

IKE Versions & Evolution
IKEv1 (Older)

Main Mode & Aggressive Mode for Phase 1, Quick Mode for Phase 2.

IKEv2 (Modern)

Streamlined, fewer messages, enhanced security, EAP & NAT traversal support.
