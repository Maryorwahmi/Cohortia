Configuration Example
crypto ipsec transform-set
Defining IPsec security parameters for data traffic.

An IPsec transform set specifies the combination of IPsec protocols, encryption algorithms, and hashing algorithms used to protect user data traffic in IKE Phase 2.

  • •Protocol Selection: Choose between AH, ESP, or both.
  • •Algorithm Definition: Specify encryption (e.g., AES) and hashing (e.g., SHA) algorithms.
  • •Mode of Operation: Define tunnel mode (default for VPNs) or transport mode.
Key Takeaway

An IPsec transform set defines the IPsec protocol (AH/ESP), encryption, hashing, and mode for data protection; these must match between peers.

crypto ipsec transform-set MY_TRANSFORM_SET
 esp-aes 256
 esp-sha256-hmac
 mode tunnel
esp-aes 256: Uses ESP with AES-256 for data encryption.
esp-sha256-hmac: Uses ESP with SHA-256 for data integrity and authentication.
mode tunnel: Specifies tunnel mode, encapsulating the entire original IP packet.
