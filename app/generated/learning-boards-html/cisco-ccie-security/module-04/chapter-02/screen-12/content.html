Diffie-Hellman Groups & PFS
Secure key exchange and perfect forward secrecy.

Diffie-Hellman (DH) is an algorithm allowing two parties to establish a shared secret key over an insecure channel. DH groups determine the strength of this key.

  • •Shared Secret: Enables secure key generation without direct exchange.
  • •Group Strength: Higher DH groups (e.g., 14, 19, 20) offer stronger security.
  • •Mismatched Groups: Prevents IKE Phase 1 establishment.
Key Takeaway

Diffie-Hellman groups enable secure shared secret generation, with higher groups offering stronger security. Perfect Forward Secrecy (PFS) ensures key compromise resilience by generating new keys for each session.

Perfect Forward Secrecy (PFS)
Key Compromise Resilience

Compromising one key does not compromise past or future keys.
