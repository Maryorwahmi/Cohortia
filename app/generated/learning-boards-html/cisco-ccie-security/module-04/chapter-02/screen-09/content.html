IPsec Protocol
Authentication Header (AH)
Ensuring data integrity and authentication without encryption.

AH provides data integrity and authentication for the entire IP packet, including the IP header. It uses hashing to verify the sender and detect tampering.

  • •Data Integrity: Guarantees data has not been modified.
  • •Data Origin Authentication: Verifies the sender's identity.
  • •NO Confidentiality: Does not encrypt the data.
Key Takeaway

Authentication Header (AH) provides data integrity and authentication for the entire IP packet but does not encrypt the data, making it less common for modern VPNs.
