Tying It Together: The Crypto Map

Binding all IPsec components for tunnel establishment

RouterA(config)# crypto map MY_CRYPTO_MAP 10 ipsec-isakmp
RouterA(config-crypto-map)# set peer 203.0.113.2
RouterA(config-crypto-map)# set transform-set MY_TRANSFORM_SET
RouterA(config-crypto-map)# match address 101
RouterA(config-crypto-map)# exit

Crypto Map Commands

  • `crypto map NAME SEQ ipsec-isakmp`: Creates the crypto map and links to IKE/IPsec.
  • `set peer IP_ADDRESS`: Specifies the remote VPN gateway's public IP.
  • `set transform-set NAME`: Links to the IKE Phase 2 transform set.
  • `match address ACL_NUMBER`: Links to the interesting traffic access list.

The VPN Blueprint

The crypto map acts as the central configuration, orchestrating how IKE Phase 1, Phase 2, and interesting traffic work together to form the VPN tunnel.

Key Takeaway

The `crypto map` command is essential for integrating all IPsec components, defining the remote peer, transform set, and interesting traffic ACL, to enable VPN tunnel establishment.
