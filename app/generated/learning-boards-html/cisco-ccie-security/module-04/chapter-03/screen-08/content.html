Traffic Selection

Defining 'Interesting Traffic' with ACLs

Identifying which traffic should be encrypted by the VPN tunnel

RouterA(config)# access-list 101 permit ip 192.168.1.0 0.0.0.255 192.168.2.0 0.0.0.255

ACL for VPN Traffic

  • `access-list 101`: Creates an extended access list.
  • `permit ip`: Allows any IP protocol.
  • `192.168.1.0 0.0.0.255`: Source network (Router A's local LAN).
  • `192.168.2.0 0.0.0.255`: Destination network (Router B's remote LAN).

Bidirectional Requirement

For a bidirectional tunnel, Router B will need a corresponding ACL permitting traffic from 192.168.2.0/24 to 192.168.1.0/24.

Key Takeaway

Use an access list to precisely define 'interesting traffic' (source and destination private networks) that should be encrypted by the VPN, ensuring ACLs are mirrored on both peers.
