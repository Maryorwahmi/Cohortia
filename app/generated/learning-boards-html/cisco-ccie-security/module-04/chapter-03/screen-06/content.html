IKE Phase 1 Authentication

Configuring the Pre-shared Key

Authenticating VPN peers with a shared secret

RouterA(config)# crypto isakmp key cisco123 address 203.0.113.2
! Pre-shared key for Router B's public IP

Key & Peer Association

The `crypto isakmp key` command defines the pre-shared key (`cisco123`) and associates it with the remote VPN peer's public IP address (`203.0.113.2`). This key must be identical on both ends.

PSK vs. Digital Certificates

  • Pre-shared Keys (PSK): Simple for small deployments, but less scalable and secure.
  • Digital Certificates: Preferred for production, offer stronger identity verification and scalability, but require CA infrastructure.
Key Takeaway

Always use strong, complex pre-shared keys and consider digital certificates for enhanced security and scalability in production environments.
