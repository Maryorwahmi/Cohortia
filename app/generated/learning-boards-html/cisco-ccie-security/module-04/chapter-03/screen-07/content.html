IKE Phase 2 Configuration

Defining the IPsec Transform Set

Specifying how actual data traffic will be protected

RouterA(config)# crypto ipsec transform-set MY_TRANSFORM_SET esp-aes 256 esp-sha256-hmac
RouterA(config-transform)# mode tunnel
RouterA(config-transform)# exit

Transform Set Components

  • `esp-aes 256`: Specifies ESP (Encapsulating Security Payload) with AES 256-bit encryption.
  • `esp-sha256-hmac`: Specifies ESP with SHA256 for data integrity.
  • `mode tunnel`: Encapsulates the entire original IP packet, standard for site-to-site VPNs.

Matching is Critical

Just like IKE Phase 1, the transform set parameters (encryption, hashing, and mode) must be identical on both VPN peers for the IPsec SA to establish.

Key Takeaway

The `crypto ipsec transform-set` defines the encryption and integrity for data traffic in IKE Phase 2, using `mode tunnel` for site-to-site VPNs, and must match on both peers.
