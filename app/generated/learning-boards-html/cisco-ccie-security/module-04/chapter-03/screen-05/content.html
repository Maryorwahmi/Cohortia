IKE Phase 1 Configuration

Defining the ISAKMP Policy

Establishing the secure control channel for key exchange

RouterA(config)# crypto isakmp policy 10
RouterA(config-isakmp)# authentication pre-share
RouterA(config-isakmp)# encryption aes 256
RouterA(config-isakmp)# hash sha256
RouterA(config-isakmp)# group 14
RouterA(config-isakmp)# lifetime 86400
RouterA(config-isakmp)# exit

Policy Parameters Explained

  • Authentication: `pre-share` uses a shared secret key.
  • Encryption: `aes 256` specifies the Advanced Encryption Standard with a 256-bit key.
  • Hash: `sha256` for data integrity and authentication.
  • DH Group: `group 14` for Diffie-Hellman key exchange strength.
  • Lifetime: `86400` seconds (24 hours) for the SA.

Why Match Exactly?

All ISAKMP policy parameters (encryption, hash, authentication, DH group, lifetime) must be identical on both VPN peers. A mismatch will prevent IKE Phase 1 from establishing, leading to tunnel failure.

Key Takeaway

The `crypto isakmp policy` defines the security parameters for IKE Phase 1, which must be precisely matched on both VPN endpoints to establish the secure control channel.
