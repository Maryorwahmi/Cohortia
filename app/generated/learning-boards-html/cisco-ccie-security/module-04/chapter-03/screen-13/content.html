Key Concepts: IPsec VPN Fundamentals

Essential terms for site-to-site VPN configuration

Crypto Isakmp Policy

Defines IKE Phase 1 parameters (auth, encryption, hash, DH group, lifetime) for the control channel.

Crypto Isakmp Key

The pre-shared key used for IKE Phase 1 authentication, associated with the remote peer's public IP.

Crypto IPsec Transform-Set

Defines IKE Phase 2 parameters (IPsec protocol, encryption, hash, mode) for data traffic protection.

Summary Takeaway

These core configurations establish the secure control channel and define how data traffic is protected within an IPsec VPN tunnel.
