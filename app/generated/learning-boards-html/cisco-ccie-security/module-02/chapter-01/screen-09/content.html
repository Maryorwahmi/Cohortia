Biba Model

Ensuring Data Integrity from Corruption

Model Overview

The Biba Model is a security model focused exclusively on integrity. It prevents data from flowing from a lower integrity level to a higher integrity level, ensuring that untrusted data cannot corrupt trusted data.

  • No Read Up: Subjects cannot read objects of a higher integrity level.
  • No Write Down: Subjects cannot write to objects of a lower integrity level.
Application Context

Ideal for environments where data accuracy is paramount, such as manufacturing control systems, financial transaction processing, or critical scientific data.

Illustrative Example

Consider a 'Validated' database record (high integrity) and a 'User Input' process (low integrity):

  • The 'User Input' process cannot read the 'Validated' record (violates 'no read up').
  • A 'Validated' process cannot write to an 'Untrusted Log' file (violates 'no write down').
  • A 'User Input' process can write to an 'Untrusted Log' file.
Key Takeaway

The Biba Model is crucial for systems where data integrity is the primary concern, preventing the corruption of trusted information by less trusted sources.
