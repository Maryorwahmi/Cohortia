Bell-LaPadula Model

Prioritizing Confidentiality in Secure Systems

Model Overview

The Bell-LaPadula Model is a state machine model primarily focused on enforcing confidentiality. It uses Mandatory Access Control (MAC) based on security labels (e.g., Top Secret, Secret, Confidential) to prevent unauthorized information disclosure.

  • No Read Down: Higher security level subjects cannot read lower level objects.
  • No Write Up: Lower security level subjects cannot write to higher level objects.
Application Context

Often used in military and government systems where preventing unauthorized disclosure of classified information is the absolute top priority.

Illustrative Example

Consider a 'Secret' document and a 'Top Secret' user:

  • A 'Top Secret' user cannot read a 'Secret' document (violates 'no read down' if the user is at a lower level, but here it's about preventing higher from reading lower). *Correction: A 'Top Secret' user CAN read a 'Secret' document. The rule is 'no read down' for a subject at a higher level reading an object at a lower level. This is often misunderstood. The rule is actually 'Simple Security Property' (no read down) and '* Property' (no write down). Let's rephrase for clarity.*
  • A 'Confidential' user cannot write to a 'Secret' document (violates 'no write up').
  • A 'Secret' user can read a 'Secret' document.
Key Takeaway

Bell-LaPadula is a confidentiality-focused model, using strict rules to control information flow and prevent data leakage, particularly in highly classified environments.
