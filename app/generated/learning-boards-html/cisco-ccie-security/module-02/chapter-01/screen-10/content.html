Clark-Wilson Model

Practical Integrity for Commercial Applications

Model Overview

The Clark-Wilson Model is a practical security model for commercial applications, emphasizing integrity through controlled access and modification. It uses two key concepts:

  • Well-Formed Transactions: Data can only be modified by authorized programs/procedures.
  • Separation of Duties: Critical tasks require multiple individuals to complete.
Application Context

Widely applied in database systems and financial applications where specific operations must be performed by authorized users in a predefined, auditable manner.

Illustrative Example

In a financial system, consider a payment processing task:

  • Well-Formed Transaction: A payment can only be initiated via a specific, validated 'Payment Processing' application, not direct database edits.
  • Separation of Duties: One employee initiates the payment request, and a different employee must approve it before it's executed.
Key Takeaway

Clark-Wilson provides a robust, practical framework for ensuring data integrity in commercial settings by controlling transactions and enforcing separation of duties.
