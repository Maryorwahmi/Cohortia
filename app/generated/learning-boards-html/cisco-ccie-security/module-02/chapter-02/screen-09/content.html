Extending SNA to the Cloud

Secure your hybrid and multi-cloud environments with integrated Cisco solutions.

Cloud-Delivered Security

Cisco offers solutions that extend visibility and control into public cloud environments, ensuring consistent security policy enforcement across on-premises and cloud infrastructures.

  • • Cisco Umbrella: Cloud-delivered DNS-layer security, blocking malware, phishing, and C2 callbacks.
  • • Cisco Cloudlock: CASB capabilities for visibility and control over sanctioned/unsanctioned cloud apps.
  • • Cisco Secure Firewall Cloud Native: NGFW capabilities directly within public cloud infrastructures.
Key Concept

Hybrid Cloud Extension

SNA ensures security policies and controls are consistently applied across both on-premises and public cloud environments.

Real-World Scenario

Protecting Remote Cloud Access

A remote user accesses a SaaS application. Umbrella blocks a malicious link within the app, while Cloudlock monitors data sharing for compliance.

Key Takeaway

Cloud security in SNA is about extending your defense perimeter and policies to cover all your cloud assets and user interactions.
