What is Accounting?

Accounting involves tracking and logging the actions performed by an authenticated and authorized user or device within a network.

Core Question

"What did you do?"

Logged Details

Login times, commands executed, resources accessed, session duration.

Key Takeaway

Accounting provides the audit trail necessary for accountability, compliance, and effective incident response.

Importance of Accounting Data

Auditing & Compliance

Essential for proving adherence to security policies and regulations.

Incident Response

Provides critical forensic data to understand and mitigate security incidents.

Common Oversight

Insufficient logging or failure to regularly review accounting logs can leave significant security blind spots.
