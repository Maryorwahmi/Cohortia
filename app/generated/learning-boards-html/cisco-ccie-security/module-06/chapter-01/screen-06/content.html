What is Authorization?

Authorization is the process of determining what an authenticated user or device is permitted to do or access within a system or network.

Core Question

"What are you allowed to do?"

Key Principle

Enforces the Principle of Least Privilege, granting only necessary access.

Key Takeaway

Authorization ensures that even legitimate users operate within defined security boundaries, preventing over-privilege.

Authorization Scenarios

Network Admin

Authorized to configure routers, but not firewalls.

Guest User

Authorized for internet access only, not internal resources.

Security Risk

Over-privileging users can lead to significant security breaches if their accounts are compromised, even if they are authenticated.
