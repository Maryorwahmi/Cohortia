Cisco IOS Local User Setup

This CLI example demonstrates how to configure a local user account on a Cisco router, providing administrative access and enabling local authentication for console and VTY lines.

Purpose

Basic device-level authentication for administrative access.

Key Commands

username ... secret ..., line console 0, line vty 0 4, login local.

Key Takeaway

Local user configuration is a fundamental authentication method, but it has scalability limitations for larger networks.

CLI Configuration Example

! Start by entering global configuration mode
configure terminal

! Create a local user with a username and a strong, encrypted password
username adminuser privilege 15 secret YourStrongPassword!

! Configure console line for local authentication
line console 0
 login local
 transport input none
 exit

! Configure VTY lines for local authentication
line vty 0 4
 login local
 transport input ssh telnet
 exit

! Save the configuration
end
write memory
