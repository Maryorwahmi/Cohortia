Applying Authorization to VTY Lines

Securing Remote Access

Purpose

To ensure that all remote access sessions (SSH/Telnet) are subject to the defined AAA authorization policies, controlling both initial shell access and specific command execution.

Common Mistake

Forgetting `aaa authorization commands 15 default group tacacs+ local` or `authorization commands default` under VTY lines. This can lead to exec access without command-level control.

  • •`login authentication default`: Uses configured AAA for user login.
  • •`authorization exec default`: Authorizes initial shell access via TACACS+.
  • •`authorization commands default`: Authorizes every command executed.
Key Takeaway

Properly configuring VTY lines with authorization commands is essential to extend granular access control to all remote management sessions, preventing unauthorized actions.

! Apply the authorization lists to the VTY lines
line vty 0 4
 login authentication default
 authorization exec default
 authorization commands default
 transport input ssh telnet
 exit

! Save the configuration
end
write memory

`line vty 0 4`: Configures virtual terminal lines for remote access.

`login authentication default`: Specifies the default AAA method for login authentication.

`authorization exec default`: Applies authorization to the initial user shell.

`authorization commands default`: Applies authorization to all commands executed by the user.
