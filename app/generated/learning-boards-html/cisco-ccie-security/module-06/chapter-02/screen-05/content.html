Definition

Remote Authentication Dial-In User Service (RADIUS)

An open standard protocol for centralized Authentication, Authorization, and Accounting (AAA) services, primarily for network access.

Open standard, widely supported
Uses UDP (ports 1812/1813)
Encrypts only the password in authentication packets
Combines Authentication and Authorization
Misconception

RADIUS does NOT encrypt the entire packet. Only the password is encrypted, leaving other attributes vulnerable if intercepted.

How it Works

RADIUS Packet Flow

User/DeviceNetwork Device (Client)
Authentication Request (UDP 1812)RADIUS Server
Access-Accept/RejectNetwork Device (Client)
Key Takeaway

RADIUS is best for general network access where full packet encryption and granular command authorization are not critical requirements.
