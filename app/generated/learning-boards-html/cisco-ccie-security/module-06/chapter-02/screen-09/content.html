RADIUS vs. TACACS+

Key differences that determine protocol choice for network access control.

RADIUS

  • Standard: Open standard, widely supported.

  • Transport: UDP (ports 1812/1813), connectionless.

  • Encryption: Only password encrypted.

  • AAA Separation: Combines AuthN & AuthZ.

  • Primary Use: Network access (VPN, 802.1X).

TACACS+

  • Standard: Cisco proprietary.

  • Transport: TCP (port 49), connection-oriented.

  • Encryption: Entire payload encrypted.

  • AAA Separation: Separates AuthN, AuthZ, Acc.

  • Primary Use: Network device administration.

Key Takeaway

The choice between RADIUS and TACACS+ depends on the specific use case: network access vs. granular device administration.
