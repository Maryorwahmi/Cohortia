Module 6›Chapter 6.2›Local vs. Centralized Authentication
Core Concept

Local Authentication

User credentials are stored directly on the network device (e.g., router, switch). Authentication happens locally on that device.

Simple for small deployments
Poor scalability and security for large networks
No centralized logging or policy enforcement
Example Scenario

A small branch office with one router and two administrators might use local authentication for simplicity, but it's not recommended for growth.

Core Concept

Centralized Authentication

Authentication requests are forwarded to a dedicated, central server (e.g., Cisco ISE) that manages user credentials and policies.

Scalable for large enterprises
Centralized management, logging, and policy enforcement
Enhanced security and compliance
Key Takeaway

Centralized authentication is the preferred method for modern, secure, and manageable network environments.
