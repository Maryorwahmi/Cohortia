Scenario

Secure Router Admin Access

Configure a Cisco router to use a TACACS+ server for administrative access, providing secure and centralized authentication.

Enable AAA new-model.
Define TACACS+ server host and key.
Configure authentication lists for login and enable.
Apply authentication to console and VTY lines.
Key Takeaway

Proper TACACS+ configuration centralizes administrative access, improving security, auditability, and control over network devices.

Cisco IOS CLI
configure terminal

aaa new-model

tacacs-server host 192.168.1.10 key MySharedSecret

aaa authentication login default group tacacs+ local
aaa authentication enable default group tacacs+ enable

line console 0
 login authentication default
 transport input none
 exit

line vty 0 4
 login authentication default
 transport input ssh telnet
 exit

end
