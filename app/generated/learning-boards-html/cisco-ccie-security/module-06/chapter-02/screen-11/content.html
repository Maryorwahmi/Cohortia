Multi-Factor Authentication (MFA)

Adding layers of defense by requiring multiple verification factors.

Something You Know

Traditional credentials like passwords, PINs, or security questions.

Something You Have

Physical items like security tokens, smart cards, or a smartphone for OTPs.

Something You Are

Biometric data such as fingerprints, facial recognition, or iris scans.

Key Takeaway

MFA significantly strengthens security by requiring multiple, independent verification factors, making it much harder for attackers to gain unauthorized access.
