Definition

Terminal Access Controller Access-Control System Plus (TACACS+)

A Cisco proprietary protocol for centralized AAA services, specifically designed for robust network device administration.

Cisco proprietary protocol
Uses TCP (port 49) for reliable communication
Encrypts the entire payload of AAA packets
Separates Authentication, Authorization, and Accounting
Key Feature

The strict separation of AAA allows for highly granular command authorization, a critical security capability.

How it Works

TACACS+ Packet Flow

User/DeviceNetwork Device (Client)
Auth Request (TCP 49)TACACS+ Server
Auth ResponseNetwork Device (Client)
AuthZ RequestTACACS+ Server
AuthZ ResponseNetwork Device (Client)
Key Takeaway

TACACS+ is the superior choice for administrative access to critical network devices due to its enhanced security and granular control.
