Key Concepts

Operational Roles and Network Integration

Policy Service (PSN) Persona

Handles all AAA requests (Authentication, Authorization, Accounting) from Network Access Devices (NADs).

Monitoring (MnT) Persona

Collects and stores all logging, auditing, and reporting data from other ISE nodes for troubleshooting and compliance.

Network Access Device (NAD)

A network device (e.g., switch, router, WLC) that enforces policies defined by ISE, acting as an access control point.

Summary Takeaway

The PSN handles real-time AAA, the MnT provides critical logging, and NADs are the network's enforcement points, all working together for comprehensive ISE security.
