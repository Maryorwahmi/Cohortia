Integrating Network Access Devices (NADs)

Connecting Your Network to ISE for Policy Enforcement

What are NADs?

Network Access Devices (NADs) are the network infrastructure components (e.g., switches, routers, WLCs) that enforce access policies defined by Cisco ISE. They are the 'gatekeepers' of your network.

Steps to Add a NAD in ISE

  • Specify IP Address: Unique identifier for the NAD.
  • Shared Secret: A pre-shared key for secure RADIUS/TACACS+ communication.
  • Protocol: Choose RADIUS or TACACS+ for AAA.
  • Device Profile: Select the appropriate profile (e.g., Cisco IOS, Cisco WLC).

Example: Shared Secret Mismatch

If you configure 'Cisco123!' as the shared secret in ISE for a switch, but configure 'cisco123!' (lowercase 'c') on the switch itself, authentication requests will fail. The shared secret must be an exact match, including case.

Key Takeaway

Integrating NADs is fundamental for ISE to enforce policies. The shared secret is critical for secure communication and must be configured identically on both ISE and the NAD.

Common Mistake: Mismatched Shared Secret

This is the most frequent cause of authentication failures when integrating NADs. Always double-check the shared secret for exact matching, including case sensitivity, on both ISE and the NAD.
