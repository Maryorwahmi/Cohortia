Key Concepts

Essential Terms for Cisco ISE

Cisco Identity Services Engine (ISE)

A centralized network access control (NAC) solution providing unified policy enforcement for wired, wireless, and VPN access.

Persona

A specific role or function that an ISE node can perform, contributing to its distributed and scalable architecture.

Administration (Admin) Persona

Manages ISE configuration, monitoring, and reporting, serving as the central control point for the deployment.

Summary Takeaway

Cisco ISE is a powerful NAC solution built on a distributed architecture of specialized personas, with the Admin persona overseeing all management and reporting functions.
