Admin and Monitoring Personas

Managing and Observing Your ISE Deployment

Administration (Admin) Persona

  • Handles all configuration tasks for ISE.
  • Manages policies, users, and network devices.
  • Provides a central point for system monitoring and reporting.
  • Typically deployed as a primary node with an optional secondary for redundancy.

Monitoring (MnT) Persona

  • Collects and stores all logging, auditing, and reporting data.
  • Offers a centralized view of network access events.
  • Crucial for troubleshooting, compliance, and security audits.
  • Can also be deployed in a primary/secondary pair for data resilience.

Example: Redundancy in Action

In a production environment, you'd typically have a primary Admin node and a secondary Admin node. If the primary fails, the secondary takes over, ensuring uninterrupted management of your ISE system. Similarly, MnT nodes are paired to protect valuable log data.

Key Takeaway

Admin and MnT personas provide the essential control and visibility layers of ISE, ensuring manageability and comprehensive logging, often deployed in redundant pairs for high availability.

Misconception: Single Point of Failure

While there's a 'primary' Admin node, the architecture allows for a secondary, preventing a single point of failure for administrative control. Similarly, MnT data is protected through pairing.
