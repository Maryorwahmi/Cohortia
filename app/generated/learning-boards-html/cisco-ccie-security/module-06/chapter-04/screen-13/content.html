Key Concepts: Accounting Fundamentals

Core definitions for tracking network activities.

Accounting

The AAA component responsible for tracking and logging user activities, resource consumption, and network events.

Accounting Data

Information collected by network devices, including connection times, commands executed, resource usage, and authentication/authorization failures.

Centralized Accounting Server

A dedicated server (e.g., Cisco ISE, TACACS+ server) that aggregates accounting data from multiple network devices.

Summary Takeaway

Accounting provides the essential raw data of network activities, which is then centralized for efficient management, correlation, and security analysis.
