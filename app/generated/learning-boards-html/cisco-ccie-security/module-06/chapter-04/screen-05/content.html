Data Collection

What Network Devices Log

Capturing essential details of user and device interactions.

Key Data Categories

  • •Connection Start/Stop Times: Records login/logout and device connect/disconnect events.
  • •Commands Executed: Logs every command entered by administrative users (especially with TACACS+).
  • •Resource Usage: Tracks data transfer volumes, session durations, and other consumption metrics.
  • •Authentication Failures: Records unsuccessful login attempts.
  • •Authorization Failures: Logs attempts to access unauthorized resources or execute restricted commands.
Key Takeaway

Comprehensive accounting logs provide granular details of network activities, crucial for security investigations and policy enforcement.
