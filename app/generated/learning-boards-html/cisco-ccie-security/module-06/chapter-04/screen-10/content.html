Practical Application

Configuring TACACS+ Command Accounting (Part 1)

Ensuring every administrative action is logged on Cisco IOS.

Initial Configuration Steps

  • •Enable AAA New Model: Activates the advanced AAA framework.
  • •Configure TACACS+ Server: Define the server's IP and shared key for communication.
  • •Set Authentication/Authorization: Establish how users log in and what commands they can execute.
Key Takeaway

The initial setup of AAA new-model and TACACS+ server details is foundational for implementing robust command accounting on Cisco devices.

! Start by entering global configuration mode
configure terminal

! Enable the new AAA model (if not already done)
aaa new-model

! Configure TACACS+ server (if not already done)
tacacs-server host 192.168.1.10 key MySharedSecret

! Configure authentication and authorization (if not already done)
aaa authentication login default group tacacs+ local
aaa authorization exec default group tacacs+ local
aaa authorization commands 15 default group tacacs+ local
Note: Replace 192.168.1.10 and MySharedSecret with your actual TACACS+ server details.
