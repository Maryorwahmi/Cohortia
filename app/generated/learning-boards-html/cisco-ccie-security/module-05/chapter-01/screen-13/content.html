Key Concepts: Detection & Prevention

Essential terms for understanding IDS and IPS

Intrusion Detection System (IDS)

Monitors network traffic or system activity for malicious activity or policy violations and generates alerts without blocking traffic.

Intrusion Prevention System (IPS)

Detects malicious activity and actively blocks or prevents it from reaching its target, typically operating in-line with traffic.

Network-based IDS (NIDS)

Monitors network segments for suspicious traffic patterns, usually by passively analyzing a copy of network traffic.

Summary Takeaway

IDS and IPS are fundamental security tools, with IDS providing passive detection and IPS offering active prevention, both crucial for a comprehensive defense strategy.
