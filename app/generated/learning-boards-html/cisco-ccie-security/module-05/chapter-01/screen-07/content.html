Network-based IDS (NIDS)

NIDS monitors network segments by passively receiving a copy of traffic (promiscuous mode) to detect threats without affecting flow.

  • •**Deployment:** Promiscuous mode (SPAN port, network tap).
  • •**Function:** Detects network-wide attacks (e.g., port scans, DoS).
  • •**Impact:** No latency, no blocking of legitimate traffic.
Example

A NIDS detects a sudden surge of connection attempts to various ports on internal servers, indicating a potential port scan, and alerts the security team.

Network-based IPS (NIPS)

NIPS operates in-line, actively inspecting and blocking malicious network traffic as it passes through, providing real-time prevention.

  • •**Deployment:** In-line with network traffic.
  • •**Function:** Actively blocks known exploits, malware, DoS attacks.
  • •**Impact:** Real-time protection, potential for latency/false positives.
Example

A NIPS detects a signature matching a known worm attempting to spread. It immediately drops the malicious packets and prevents the worm from entering the internal network.

Key Takeaway

NIDS provides passive network visibility, while NIPS offers active, in-line prevention for network-wide threats, each with distinct deployment models and impacts.
