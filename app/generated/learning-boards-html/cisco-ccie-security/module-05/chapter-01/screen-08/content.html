Host-based IDS (HIDS)

HIDS monitors individual endpoints for suspicious activity by analyzing system calls, file changes, and logs directly on the host.

  • •**Scope:** Individual servers, workstations, critical devices.
  • •**Monitoring:** System calls, file integrity, log files, running processes.
  • •**Detection:** Catches attacks bypassing network defenses (e.g., malware already present).
Example

A HIDS detects an unauthorized attempt to modify a critical system registry key on a server, generating an alert for the administrator.

Host-based IPS (HIPS)

HIPS actively prevents malicious actions on individual hosts, such as blocking unauthorized process execution or file modifications.

  • •**Scope:** Granular protection for specific host activities.
  • •**Prevention:** Blocks unauthorized processes, file changes, network connections.
  • •**Integration:** Often part of modern EDR solutions.
Example

A HIPS prevents a newly downloaded executable from running because its behavior matches a known malware signature, thereby stopping an infection.

Key Takeaway

HIDS provides deep visibility into host-level activities, while HIPS offers active prevention directly on the endpoint, complementing network-based defenses.
