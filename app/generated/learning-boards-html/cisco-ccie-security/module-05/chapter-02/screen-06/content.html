Common Signature Types: String and Header

Exploring how specific data patterns are used for detection.

String Signatures

These signatures look for specific text strings within the data payload of network packets. They are effective for detecting known exploit names or command injection attempts.

Example: Detecting /etc/passwd in a web request URL, indicating an attempt to access sensitive system files.

Header Signatures

These signatures analyze specific values or patterns within packet headers (IP, TCP, UDP, HTTP) to identify anomalies or malicious constructs.

Example: Detecting unusual TCP flag combinations or malformed IP headers, often used in reconnaissance or evasion.

Packet Inspection Focus

String and header signatures are fundamental, focusing on distinct parts of network packets to identify known malicious patterns.

Key Takeaway

String signatures target specific text in payloads, while header signatures analyze packet header anomalies, both critical for detecting known attack patterns.
