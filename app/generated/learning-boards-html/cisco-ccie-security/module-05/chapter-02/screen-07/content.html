Advanced Signature Types: Port/Protocol and Stateful

Detecting anomalies and multi-stage attacks.

Port/Protocol Signatures

These identify traffic on unusual ports for specific protocols or non-standard protocol usage, often indicating covert channels or misconfigurations.

Example: Detecting HTTP traffic on port 22 (SSH), which could signify an attempt to tunnel web traffic to bypass firewalls.

Stateful Signatures

These track the state of a connection or sequence of events over time, detecting multi-stage attacks that involve multiple steps or interactions.

Example: Detecting a port scan followed by an exploit attempt, which collectively indicates a more sophisticated attack sequence.

Contextual & Sequential Analysis

Advanced signatures move beyond single packet inspection to understand the broader context and sequence of network events for more robust detection.

Key Takeaway

Port/Protocol signatures detect unusual network behavior, while stateful signatures analyze event sequences over time, enabling detection of complex, multi-stage attacks.
