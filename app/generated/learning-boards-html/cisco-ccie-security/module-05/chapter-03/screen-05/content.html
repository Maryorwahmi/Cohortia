Establishing the Baseline:
Defining 'Normal'

Learn the critical process of profiling normal network and system behavior to enable effective anomaly detection.

The Learning Phase: Building a Profile

Network Traffic

Monitors connection counts, protocols, ports, and data volumes.

System & Resource Use

Tracks CPU, memory, disk I/O, and process execution patterns.

User Behavior

Analyzes login times, locations, access patterns, and command usage.

Application Activity

Profiles typical application interactions and expected outputs.

Key Takeaway

A robust, dynamic baseline is the cornerstone of effective anomaly detection, requiring continuous monitoring and refinement.

Example Scenario

A server usually has 10-20 active connections. A sudden jump to 500 connections would be flagged as anomalous against this learned baseline.

Common Misconception

The baseline is not static; it must adapt to legitimate network changes to avoid excessive false positives.
