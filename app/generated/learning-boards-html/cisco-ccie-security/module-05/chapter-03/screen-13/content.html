Key Concepts:
Challenges & Real-World Context

Review critical terms related to the challenges and practical applications of anomaly-based detection.

Zero-Day Attack

An attack exploiting a previously unknown vulnerability, which anomaly detection is particularly suited to identify.

False Positive

A legitimate activity mistakenly flagged as anomalous, a common challenge in anomaly detection.

Slow and Low Attack

An attack designed to operate below detection thresholds, gradually blending into normal activity.

Mimicry Attack

An attack where malicious activity attempts to imitate normal behavior to avoid detection.

Cisco Stealthwatch

A Cisco solution using NetFlow data and behavioral analytics for network anomaly detection.

Summary Takeaway

Anomaly detection is a powerful defense against unknown threats, but requires careful management of false positives and awareness of sophisticated evasion techniques, as seen in solutions like Cisco Stealthwatch.
