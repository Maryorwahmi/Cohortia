Statistical Analysis:
Quantifying Deviations

Understand how statistical methods are used to identify anomalies by measuring deviations from expected norms.

How it Works: Metrics and Thresholds

  • •Calculates statistical metrics like mean, median, and standard deviation.
  • •Applies to parameters such as connection count, packet size, or login frequency.
  • •Flags activity that falls outside a predefined statistical threshold (e.g., 3 standard deviations).
  • •Effective for detecting clear, quantifiable outliers.
Example Scenario

A user typically transfers 50MB of data daily. A sudden transfer of 5GB would be a statistical anomaly, triggering an alert.
