Definition Inline Styles
Inline style syntax and use cases
Simple, dynamic, and immediate style objects
Code example
<Text style={{ color: 'blue', fontSize: 20 }}>Hello</Text>

// Dynamic inline style
<View style={{ backgroundColor: isActive ? 'blue' : 'gray', padding: 12 }} />
When to use
  • One-off styles computed from props or state.
  • Rapid prototyping where extraction is premature.
  • Simple conditional colors or spacings per render.
Explanation and common pitfalls

Inline style objects are created anew on each render unless memoized. This can stop some optimizations. They are fine for occasional dynamic rules, but not for large reusable style sets.

Misconception: Inline styles always cause major slowdowns. Reality: For small components they are acceptable; the problem appears when many large objects are recreated on frequent renders.

Example: button color computed by prop — quick and clear.
Common mistake: Using kebab-case or '18px' strings inside inline objects.
Key takeaway: Reserve inline for dynamic values; extract static rules.
