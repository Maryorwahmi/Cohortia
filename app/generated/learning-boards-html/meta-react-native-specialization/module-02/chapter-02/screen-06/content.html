Definition StyleSheet.create
Define and organize static styles
Reference example
import { StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  container: {
    backgroundColor: '#f0f0f0',
    padding: 10,
    borderRadius: 5,
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    color: 'darkblue',
  },
});

// Usage: <View style={styles.container}><Text style={styles.title}>...</Text></View>
Why outside the component?
  • Created once at module load.
  • Prevents re-creating objects on each render.
  • Makes component render functions concise.
Misconception: Defining it inside a function is the same — it is not; it negates optimization.
Takeaway: Extract static rules into StyleSheet.create for performance and clarity.
