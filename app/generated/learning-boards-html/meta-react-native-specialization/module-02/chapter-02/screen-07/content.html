CamelCase and unitless numbers
Incorrect example
const myStyles = StyleSheet.create({
  myText: {
    'font-size': '18px',
    'background-color': 'lightgreen'
  }
});
This will fail because of kebab-case and pixel strings.
Corrected example
const myStyles = StyleSheet.create({
  myText: {
    fontSize: 18,
    backgroundColor: 'lightgreen'
  }
});
Use numbers for sizes and camelCase for names.
Tip: Use percent strings like width: '50%' when relative sizing is needed.
