Style arrays and precedence
Example code
style={[styles.base, styles.modifier]}

// styles.base = { padding: 12, backgroundColor: 'white' }
// styles.modifier = { backgroundColor: 'lightblue' }
Result: backgroundColor becomes 'lightblue' because modifier is later in the array.
Best practices
  • Keep base styles generic and modifiers minimal.
  • Place specific overrides later in the array.
  • Avoid deep nested style objects expecting deep merges.
Misconception: Later styles merge deeply — only top-level props are merged, so nested objects replace earlier ones.
