Debugging Common mistakes
Quick fixes for frequent errors
Broken example
myText: {
  'font-size': '18px',
  'background-color': 'lightgreen'
}
Symptoms: style keys ignored or runtime warnings.
Fixed example
myText: {
  fontSize: 18,
  backgroundColor: 'lightgreen'
}
Use camelCase and numbers for sizes.
Accessibility tip: ensure sufficient contrast for text on backgrounds and prefer readable font sizes for small devices.
