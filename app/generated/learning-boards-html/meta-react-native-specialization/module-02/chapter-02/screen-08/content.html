Process Flow Common properties
Core properties with examples
Spacing
padding: 10 — interior spacing. marginVertical: 10 — space between items.
Typography
fontSize: 16, color: '#333', fontWeight: 'bold'. Numbers, not strings with px.
Size & Shape
width: 80, height: 80 or width: '50%'; borderRadius: 10 for rounded corners.
Concrete card example
cardContainer: {
  backgroundColor: '#FFFFFF',
  padding: 20,
  borderRadius: 10,
  marginVertical: 10,
  alignItems: 'center'
}
avatar: { width: 80, height: 80, borderRadius: 40 }
Practice these values in your ProfileCard to see how each affects layout and look.
