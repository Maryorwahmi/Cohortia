How flex divides space
flex is a shorthand that determines how a child grows or shrinks in relation to siblings. Use it when you want relative sizing instead of fixed pixels.
Code example
{`import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

const FlexExample = () => {
  return (
    
      Box 1 (flex: 1)
      Box 2 (fixed height)
      Box 3 (flex: 2)
    
  );
};

const styles = StyleSheet.create({
  container: { flex: 1, flexDirection: 'column' },
  box1: { flex: 1, backgroundColor: 'lightblue' },
  box2: { height: 100, backgroundColor: 'lightgreen' },
  box3: { flex: 2, backgroundColor: 'lightcoral' },
});

export default FlexExample;`}
Experiment
Try the pattern with horizontal boxes: set flexDirection: 'row' and give children flex values to see proportional widths change immediately.
Key Takeaway
Use flex on children to make layouts that adapt proportionally; use flex on the root to fill screen space for nested layouts to work correctly.
