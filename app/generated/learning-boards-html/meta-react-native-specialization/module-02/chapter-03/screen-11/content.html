Examples to try
1) flexDirection: 'row', justifyContent: 'flex-start' — left-aligned items.
2) justifyContent: 'center' — items grouped centrally.
3) justifyContent: 'space-between' — first and last at edges; even gaps between.
Scenario
Use space-between for navigation bars where you want the outer controls anchored and inner space flexible for titles or search inputs.
Challenge
Create a row with three icons. Use justifyContent so icons are centered and spaced evenly across the width without touching edges. Which setting achieves that best?
Hint
Try space-evenly for equal gaps including edges, or use padding plus space-between for controlled edge spacing.
