Module 2 › Chapter 2.3 › Key Concepts
Flexbox
Reactive layout system modeling container and children relationships.
Axes
flexDirection chooses main axis; justifyContent acts on main axis, alignItems on cross axis.
flex
Child shorthand for growth/shrink; flex: 1 commonly used to fill available space.
Summary Takeaway

Design with relationships: set a main axis, distribute space with justifyContent, align on the cross axis, and use child flex values for proportional sizing. This yields responsive, maintainable layouts.
