Module 2 › Chapter 2.3 › alignItems
Definition & examples
alignItems affects cross-axis placement. Use center to middle-align, flex-start to anchor at the cross-axis start, flex-end to anchor at the end, or stretch to fill available cross-axis space when items lack fixed size.
Example: card list
A vertical list container with alignItems: 'center' keeps cards centered horizontally, which improves readability on narrow devices.
Misconception
alignItems does not control spacing along the main axis; that is justifyContent's role.
Quick exercises
  1. Set a row container and try alignItems: 'flex-end' to push children downwards.
  2. Remove explicit child heights and set alignItems: 'stretch' to see them expand.
  3. Use baseline when aligning mixed-size text elements.
