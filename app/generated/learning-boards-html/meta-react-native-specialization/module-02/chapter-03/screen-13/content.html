Activity › Build Layout
Lab steps
  1. Create <View style={{ flex: 1 }}> as root container.
  2. Header: <View style={{ height: 60, flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center' }}> add title and icon.
  3. Content: <View style={{ flex: 1 }}> add Text or ScrollView to expand and scroll.
  4. Footer: <View style={{ height: 50 }}> center its content with alignItems and justifyContent.
  5. Rotate device to verify content resizes while header and footer stay fixed.
Check
Does the main content area grow when the screen height increases? If not, check flex: 1 on the content View.
Pitfall
Applying justifyContent to a child expecting it to move itself will not work. Apply it to the parent container.
