Module 2 › Chapter 2.3 › What is Flexbox?
Definition and analogy

Think of a Flex container as a shelf and children as boxes placed on that shelf. The shelf sets the orientation and how boxes share leftover room. This mental model helps when you switch between column and row.

Container vs Item
Container properties (flexDirection, justifyContent, alignItems) affect children. Item properties (flex) affect growth and shrinkage.
Concrete example
A header View with flexDirection: 'row' and alignItems: 'center' places avatar and title side-by-side and aligned by baseline or center depending on settings.
Key Takeaway

Treat a View as either a shelf or a box depending on whether you apply Flexbox on it; set relationships, not absolute positions.

Quick reference
  • flexDirection: sets main axis ('column' default).
  • justifyContent: distributes space on main axis.
  • alignItems: aligns on cross axis.
  • flex: child shorthand for growth and shrink.
Misconception check
Flexbox is not for absolute positioning. If you need exact overlay, other techniques are used; Flexbox gives predictability across sizes.
