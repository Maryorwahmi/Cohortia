Starter template
{`
  
    My App
    ☰
  

  
    Main content fills available space
  

  
    Footer
  
`}
This code makes the content area flexible and keeps header and footer at fixed sizes. Adjust heights as needed, but avoid placing main structure with absolute positioning unless overlay is required.
Scenario
Use this layout for screens where content should scroll independently inside the flexible area, while header and footer remain visible and consistent.
Common mistake
If you omit flex: 1 on the content View, the footer will not sit at the bottom and content may not expand as expected.
