Module 2 › Chapter 2.3 › flexDirection
Process: decide an axis
  1. Identify whether items should stack vertically or horizontally.
  2. Set flexDirection to 'column' for vertical stacking, 'row' for horizontal.
  3. Adjust justifyContent and alignItems after choosing the axis to get intended spacing and alignment.
Example
To lay out three icons across the top bar, set the bar View to flexDirection: 'row' and use justifyContent: 'space-between' so the first and last items sit at the ends.
