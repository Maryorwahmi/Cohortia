Module 2 › Chapter 2.1 › Text Rules
Definition & behavior

Text is responsible for font rendering, line height, and inline nesting. Always import and wrap strings to avoid render errors.

Example

Use two Text components: one for a bold name and another for a truncated bio using number-of-lines.

Common mistake

Placing a raw string inside a View triggers an error; always wrap it in Text.

Nesting & styles
<Text>Hello, <Text style={{fontWeight: 'bold'}}>World</Text>!</Text>

Use nesting to style inline fragments without splitting layout into separate lines.

Key Takeaway

Treat Text as the canonical container for any rendered string and style fragments by nesting Text elements.
