Module 2 › Chapter 2.1 › Debugging Text
Problem scenario
// Incorrect
<View>
  Hello World!
  <Image source={{ uri: 'https://example.com/logo.png' }} />
</View>

The raw string causes a render error because it is not wrapped by a Text component.

Fix

Wrap the string with Text and ensure Text is imported from react-native.

Corrected example
// Correct
import { View, Text, Image } from 'react-native';

<View>
  <Text>Hello World!</Text>
  <Image source={{ uri: 'https://example.com/logo.png' }} style={{ width: 100, height: 100 }} />
</View>
Key Takeaway

Simple fixes — wrap strings and provide image sizes — solve many beginner render issues quickly.
