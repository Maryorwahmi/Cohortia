Module 2 › Chapter 2.1 › ProfileCard Activity
Implementation checklist
  1. Create View container with padding and background.
  2. Add Image for avatar with width, height, and resizeMode.
  3. Add Text for name and Text for bio with number-of-lines.
  4. Compose and apply styles via StyleSheet.create.
Testing steps

Run the app, check for render errors, verify the avatar loads, the name is bold, and the bio truncates when long.

Example expectations
Avatar: 80x80, resizeMode cover, circular
Name: larger font-size, bold
Bio: smaller font-size, number-of-lines=2
Key Takeaway

Follow the checklist and the ProfileCard will demonstrate correct use of View, Text, and Image together.
