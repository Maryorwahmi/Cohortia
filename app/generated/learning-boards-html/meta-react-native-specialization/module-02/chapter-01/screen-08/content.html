Module 2 › Chapter 2.1 › Image Comparison
Local images
  • Bundled at build time using require.
  • Often have intrinsic dimensions and load instantly.
  • Best for app icons and fixed assets.
Note

Changing a local image requires a new app build and redeploy.

Network images
  • Retrieved at runtime via a uri object.
  • Require explicit width and height for reliable rendering.
  • Good for dynamic user content like avatars.
Pro tip

Show a placeholder while network images load to improve perceived performance.
