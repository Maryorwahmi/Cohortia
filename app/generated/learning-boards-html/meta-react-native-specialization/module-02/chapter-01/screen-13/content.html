Module 2 › Chapter 2.1 › Image Performance
Performance checklist
  • Use appropriately sized images and compress assets.
  • Show placeholders or skeletons while network images load.
  • Prefer server-side resizing for dynamic images when possible.
Testing

Test on slower networks and lower-end devices to surface memory and loading issues early.

UX patterns

Placeholder example: render a circular View with a background color until the avatar finishes loading, then fade in the Image. This keeps layout stable and reduces perceived loading time.

Key Takeaway

Small images and placeholders dramatically improve perceived performance and avoid memory spikes.
