Module 2 › Chapter 2.1 › Native Mapping
Definition

React Native primitives are lightweight wrappers that instruct the native renderer to create corresponding platform widgets. This ensures UI fidelity, native performance, and consistent behavior across devices.

Analogy

Think of View, Text, and Image as instructions to a native UI factory. You specify structure and properties; the factory creates the actual native parts.

Misconception

These components are not direct copies of web tags — they map to native controls and may expose platform-specific behaviors.

Concrete examples
  • Text: Handles font metrics and inline nesting for mixed styles.
  • Image: Uses native image loading; network images often need width and height.
  • View: Manages layout, background, and touch interaction like a native container.
Key Takeaway

Design for native behavior: think in components that the platform will actually render.
