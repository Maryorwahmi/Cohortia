Practice: ProfileCard checklist
  • Wrap all strings in a Text component to avoid errors.
  • Use View for layout and apply Flexbox for positioning children.
  • For network images, set width and height in style so they render.
  • Use require for local images and confirm the asset path.
Common misconceptions
Text can be raw inside View — incorrect.
Network images size themselves — often invisible without dimensions.
Quick Debug

Check imports, wrap text, size images, and inspect require paths for local assets.

Key Takeaway

Small checks prevent the most common render errors.
