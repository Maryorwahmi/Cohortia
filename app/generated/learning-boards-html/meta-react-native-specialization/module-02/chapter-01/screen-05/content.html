Layout pattern

Typical process to structure a card UI:

  1. Create a parent View as card container and set padding and borderRadius.
  2. Place an Image or avatar inside a child View and give it fixed size.
  3. Use a nested View for Text lines and control spacing with margin and align-items.
Pro tip

Compose styles with arrays so you can reuse a base container and add modifiers on demand.
