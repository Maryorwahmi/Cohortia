Module 2 › Chapter 2.1 › Image Source
Source patterns
// Local image
source = require('./assets/avatar.png')

// Network image
source = { uri: 'https://example.com/avatar.png' }

Local images are bundled and referenced with require. Network images use a uri object and typically need width and height defined.

Resize modes

cover, contain, and stretch change how the image fits its box. Pick one to preserve aspect ratio or to fill the container.

Concrete example
A profile avatar from the network should use a fixed width and height and resizeMode set to cover so the image fills the circular frame without distortion.
Key Takeaway

Always provide dimensions for network images and choose a resize mode that matches your visual intent.
