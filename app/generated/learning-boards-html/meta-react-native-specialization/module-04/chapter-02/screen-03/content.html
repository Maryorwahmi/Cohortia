Distinguish network vs HTTP errors

Remember fetch rejects on network errors only. Check response.ok to treat HTTP 4xx/5xx as errors within your try/catch flow.

08
Know Fetch limitations

Fetch lacks a built-in timeout and global interceptors. For advanced needs consider libraries that provide cancellation, retries, and interceptors.
