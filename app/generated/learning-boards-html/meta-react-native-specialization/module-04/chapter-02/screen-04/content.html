Core Concept

Fetch API: Request & Response

Fetch is a native modern alternative to older HTTP techniques. It returns a Response which you must inspect and parse.

Request object
Describes the operation: url, method, headers, and body. Use it to configure POST and PUT payloads.
Response object
Contains status, statusText, headers, and functions like response.json() to parse the body.
Common mistake
Assuming fetch rejects on HTTP errors. Always check response.ok and response.status.
Concept Visual
Short annotated example of the Request → Response flow.
<!-- Example: simple GET flow -->
const response = await fetch('https://jsonplaceholder.typicode.com/users');
// Check HTTP status
if (!response.ok) {
  throw new Error(`HTTP error! status: ${response.status}`);
}
const data = await response.json();
// data is now a parsed JavaScript array or object
Key Takeaway

Always await both fetch and response.json, and treat non-2xx responses as errors.
