Suggested api helper design
// api.js (concept)
export const checkedFetch = async (url, options = {}) => {
  const response = await fetch(url, options);
  if (!response.ok) {
    try { const err = await response.json(); throw new Error(err.message || `Status ${response.status}`); } catch(e) { throw new Error(`Status ${response.status}`); }
  }
  return response.json();
};
This helper centralizes checks and parsing so components only call get/post/put/delete helpers and handle results and errors.
UI patterns
  • Show clear loading indicators and item-level spinners for actions.
  • Display friendly error messages derived from parsed error bodies.
  • Use optimistic updates with rollback where the UX benefits outweigh complexity.
Key Takeaway

Centralize network logic into small helpers to make your components simpler and easier to test or update later.
