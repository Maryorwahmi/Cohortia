Process

Fetch on mount and render list

Follow this exact pattern to avoid common mistakes and show good UI states.

// UsersScreen.js (excerpt)
import React, { useState, useEffect } from 'react';

useEffect(() => {
  const fetchUsers = async () => {
    try {
      const response = await fetch('https://jsonplaceholder.typicode.com/users');
      if (!response.ok) {
        throw new Error(`HTTP error! status: ${response.status}`);
      }
      const json = await response.json();
      setUsers(json);
    } catch (e) {
      setError(e.message);
    } finally {
      setLoading(false);
    }
  };
  fetchUsers();
}, []);
Key Takeaway

Await fetch and response.json, check response.ok, and update loading and error state in finally.

Example UI behavior
While loading show an ActivityIndicator. On error show a friendly message. On success render a FlatList of items.

Misconception
Fetch will reject on HTTP 404 or 500. Actually, fetch resolves; you must check response.ok and handle non-2xx statuses yourself.
