Module 4 › Chapter 4.2 › POST, PUT, DELETE: using the options object
Process Flow

Build the options object for mutations

Step-by-step
  1. Decide method: 'POST' to create, 'PUT' to replace/update, 'DELETE' to remove.
  2. Set headers. For JSON include 'Content-Type': 'application/json'. Add Authorization when required.
  3. Stringify the payload: body: JSON.stringify(payload).
  4. Call fetch(url, options) and await the response, then check response.ok and parse as needed.
  5. Update local state to reflect the mutation and handle errors in catch.
// POST example
const createPost = async (title, body) => {
  const response = await fetch('https://jsonplaceholder.typicode.com/posts', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ title, body, userId: 1 }),
  });
  if (!response.ok) throw new Error(`HTTP error! status: ${response.status}`);
  return await response.json();
};
Analogy
Think of headers as labels on a package and JSON.stringify as packing the contents into the required format.
Common Mistake

Passing a plain object as body without JSON.stringify will send [object Object] or cause unexpected payloads.

Key Takeaway

Always stringify JSON bodies and set Content-Type so servers parse your payload correctly.
