Module 4 › Chapter 4.2 › Parsing JSON: await response.json()
Definition

Await the parser

response.json returns a Promise that resolves to the parsed object; forgetting to await it yields bugs.

const response = await fetch(url);
if (!response.ok) {
  // Optionally parse an error body
  let errMsg = `Status ${response.status}`;
  try {
    const errorBody = await response.json();
    errMsg = errorBody.message || errMsg;
  } catch (parseErr) {
    // body not JSON
  }
  throw new Error(errMsg);
}
const data = await response.json();
Analogy
Think of fetch as the delivery van and response.json as unpacking and assembling the boxes into usable parts.
Common Pitfall
If you set state to the result of response.json without awaiting, your UI may render a Promise object or crash. Always await the parse step before setState.
Concrete example
Bad: setData(response.json()); Good: const data = await response.json(); setData(data);
Key Takeaway

Await response.json() and guard parsing for error bodies that might not be valid JSON.
