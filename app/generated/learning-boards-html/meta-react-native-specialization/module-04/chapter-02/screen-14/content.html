Fetch & Response
Fetch returns a Response; check response.ok and parse with response.json().
JSON payloads
Set Content-Type to application/json and use JSON.stringify for bodies.
Error semantics
fetch rejects on network errors only. Inspect response.status or response.ok for HTTP errors.
Takeaway
Master the simple patterns: checked fetch, await parsing, and clear UI states. These foundations make future enhancements predictable and safe.
