Learning Objectives

Short, verifiable skills to practice with live code and the To-Do example.

Bloom: Learn → Understand → Apply → Master
01
Perform GET requests

Trigger a fetch to retrieve JSON and render it with useState and useEffect. Verified competency: fetch a users list and show loading and error states.

Mnemonic: Timeline icon representing request → response
VERIFIED COMPETENCY MILESTONE
02
Construct POST/PUT/DELETE

Build the options object with method, headers, and body stringified as JSON to create or update resources. Verified by sending a simulated post and handling the response.

Mnemonic: Small form icon with arrow
VERIFIED COMPETENCY MILESTONE
03
Parse JSON safely

Await the response.json() call after ensuring response.ok so you get parsed objects, not unresolved Promises. Verified by parsing and rendering an array of items.

Mnemonic: Small JSON braces icon
VERIFIED COMPETENCY MILESTONE
04
Handle errors & timeouts

Implement try/catch, check response.ok, and use Promise.race for a basic timeout. Verified by showing error UI when fetch fails or times out.

Mnemonic: Small clock icon
