Module 4 › Chapter 4.1 › Skills & Pitfalls
01 — Apply async/await

Refactor Promise chains into async functions to make sequential logic read like synchronous code while keeping non-blocking behavior.

Mnemonic: think of await as a pause inside an async bubble — it doesn't freeze the whole app, only the function execution.
VERIFIED COMPETENCY MILESTONE
02 — Avoid forgetting await

Always await promise-returning calls when you need their results. Otherwise you'll operate on a Promise object instead of the value you expect.

Mnemonic: missing await is like leaving a package unopened — the content is still inside the Promise.
VERIFIED COMPETENCY MILESTONE
03 — Handle errors explicitly

Use catch or try...catch to handle rejected Promises so the app doesn't surface unhandled rejections to users or crash in production.

Mnemonic: every await should be inside a try or paired with a catch somewhere in the chain.
VERIFIED COMPETENCY MILESTONE
04 — Manage loading state

Set loading flags before awaiting network calls and reset them in finally blocks so the UI always reflects the operation's status.

Mnemonic: start loader, await result, stop loader in finally.
