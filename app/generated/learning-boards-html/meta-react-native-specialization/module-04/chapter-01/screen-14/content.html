Synchronous vs Asynchronous

Synchronous runs sequentially and can block; asynchronous lets the app remain responsive while long tasks complete.

Promises & States

Promises can be pending, fulfilled, or rejected. Use then and catch to manage success and failure paths.

async / await

async functions implicitly return Promises and await pauses inside them; wrap awaits in try...catch to handle rejections.

Takeaway

Treat Promises as values that settle over time and use the right abstraction—Promises or async/await—to keep your code readable and robust.
