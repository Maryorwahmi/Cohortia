How callbacks work

A callback is a function passed into another function and executed when an async operation completes. They are simple for single asynchronous tasks but scale poorly when tasks are sequential and dependent.

Nested example (conceptual)
fetchUser(function(user){
  fetchPosts(user.id, function(posts){
    posts.forEach(function(post){
      fetchComments(post.id, function(comments){
        // deeply nested callbacks
      });
    });
  });
});
Problems & remedy
  • Readability suffers as indentation grows.
  • Error handling becomes fragmented across many callbacks.
  • Refactor into Promises or async/await to flatten control flow and centralize error handling.
Pro tip

When you see nested callbacks, pause and refactor into Promises or async/await to simplify reasoning and error paths.
