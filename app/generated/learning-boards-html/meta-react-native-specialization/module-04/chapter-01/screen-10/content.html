Module 4 › Chapter 4.1 › Common Mistakes
Incorrect code
async function fetchUserData() {
  const response = fetch('https://api.example.com/users/1');
  const data = await response.json();
  console.log(data);
}
fetchUserData();
Corrected
async function fetchUserData() {
  const response = await fetch('https://api.example.com/users/1');
  const data = await response.json();
  console.log(data);
}
fetchUserData();
The key fix is awaiting fetch itself so response is the actual Response object instead of a Promise. Wrap awaits in try...catch to handle network or parsing errors.
