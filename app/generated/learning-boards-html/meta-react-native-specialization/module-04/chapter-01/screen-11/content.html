Module 4 › Chapter 4.1 › UI State During Async
Pattern
const [isLoading, setIsLoading] = useState(false);
const [message, setMessage] = useState('');

async function simulateLogin() {
  setIsLoading(true);
  setMessage('Logging in...');
  try {
    const response = await fakeLogin();
    setMessage(response);
  } catch (error) {
    setMessage('Login Failed: ' + error);
  } finally {
    setIsLoading(false);
  }
}
Advice
  • Always reset loading in finally so spinners stop.
  • Show clear success or error messages derived from the settled Promise.
  • When starting multiple requests, consider cancellation or request keys to avoid race conditions.
Real-world connection

In React Native, users expect instantaneous feedback. Managing loading and error states around async calls preserves perceived performance.
