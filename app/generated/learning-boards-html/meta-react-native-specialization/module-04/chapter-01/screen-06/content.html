What is a Promise?

A Promise represents the eventual completion or failure of an asynchronous operation. It exposes a predictable lifecycle and lets you attach success and error handlers.

Pending
Operation in progress; no result yet.
Fulfilled
Operation completed successfully; value available.
Rejected
Operation failed; error available.
Attach handlers
fetch('url')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error(error));
Chain then calls to sequence steps. Use catch to centralize error handling. Remember a settled Promise is immutable in state.
