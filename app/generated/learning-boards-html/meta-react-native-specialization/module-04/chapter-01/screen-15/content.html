Module 4 › Chapter 4.1 › Quick Reminders
Await needed Promises

If you need a resolved value, await the Promise rather than using it directly.

Handle errors

Use catch for Promises and try...catch for async/await to avoid unhandled rejections.

Manage loading

Set loading before await and reset in finally so the UI always reflects the operation state.

Final takeaway

Small habits—awaiting Promises, handling errors, and managing loading—lead to reliable asynchronous code and better user experiences.
