Module 4 › Chapter 4.1 › Synchronous Execution
Definition

Synchronous JavaScript

Code runs sequentially on a single thread. Each step must finish before the next begins, which is predictable but prone to blocking for long operations.

Example scenario: a fetch that waits synchronously would freeze the UI until the response arrives.
Misconception: assuming UI tasks run on a separate thread by default.
Key Takeaway

Avoid synchronous waits for I/O in apps that must remain responsive.

Concrete Example

Imagine a mobile screen that starts a network request and blocks until the response returns. Users can't tap back, animations freeze, and the app feels broken. Using asynchronous calls releases the main thread while the request completes.

Check your understanding
  • Is a network fetch synchronous or asynchronous by default? (Asynchronous.)
  • What happens if a long task blocks the main thread? (UI freezes.)
