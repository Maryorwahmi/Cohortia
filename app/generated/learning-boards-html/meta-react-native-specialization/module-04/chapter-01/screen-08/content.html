Module 4 › Chapter 4.1 › async / await
Syntax
async function fetchDataAsync() {
  try {
    const message = await new Promise((resolve) => {
      setTimeout(() => resolve("Data fetched successfully with async/await!"), 2000);
    });
    console.log(message);
  } catch (error) {
    console.error(error);
  }
}

fetchDataAsync();
Why use it?
  • Reads like synchronous code, making logic easier to follow.
  • Error handling uses familiar try...catch blocks.
  • Preserves non-blocking behavior because only the async function pauses.
Key Takeaway

Use async/await for sequential async code and wrap awaits in try...catch to handle errors robustly.
