Module 5 › Chapter 4.4 › Remember Me Login
Starter snippet
const USERNAME_KEY = 'rememberedUsername'
const REMEMBER_FLAG = 'rememberMeFlag'

async function loadRememberedUser() {
  try {
    const storedUsername = await AsyncStorage.getItem(USERNAME_KEY)
    const storedFlag = await AsyncStorage.getItem(REMEMBER_FLAG)
    if (storedFlag === 'true' && storedUsername) {
      setUsername(storedUsername)
      setRememberMe(true)
    }
  } catch (e) { console.error(e) }
}

async function handleLogin() {
  if (rememberMe) {
    await AsyncStorage.setItem(USERNAME_KEY, username)
    await AsyncStorage.setItem(REMEMBER_FLAG, 'true')
  } else {
    await AsyncStorage.removeItem(USERNAME_KEY)
    await AsyncStorage.removeItem(REMEMBER_FLAG)
  }
}
Explanation & checklist
  • Store the username only when the user opts in.
  • Use a dedicated flag key so intent is explicit and easy to check.
  • Call removeItem to clear previous values when the user opts out.
  • Test across full app restart to ensure persistence works as expected.
