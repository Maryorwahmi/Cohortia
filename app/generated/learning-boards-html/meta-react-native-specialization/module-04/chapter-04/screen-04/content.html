What is AsyncStorage?
A lightweight persistence layer for small, non-sensitive data.
Definition & analogy

AsyncStorage stores string values by key, persists through app restarts, and exposes promise-based APIs. Think of it as localStorage but asynchronous and mobile-focused.

Use case example: Save theme preference (dark vs light) so the UI restores after restart.
Misconception: It is encrypted or secure by default — it is not. Avoid storing secrets here.
Practical tip: Use async/await and try/catch to handle promise results cleanly.
Compact visual: store model
Key: 'userSettings' → Value: '{"isDarkMode":true,"sound":false}'
All values must be strings; serialize objects first with JSON.stringify.
Example check: After getItem('userSettings'), check for null before calling JSON.parse to avoid errors.
Key Takeaway

Use AsyncStorage for small persisted state, always serialize objects and never store sensitive data unencrypted.
