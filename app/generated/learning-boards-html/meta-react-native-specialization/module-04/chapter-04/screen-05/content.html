Core API Methods
Understand the lifecycle of basic AsyncStorage operations.
Numbered flow
1. Save: await AsyncStorage.setItem(key, value)
2. Load: const value = await AsyncStorage.getItem(key); check value !== null
3. Delete: await AsyncStorage.removeItem(key)
4. Reset: await AsyncStorage.clear() — confirm with user first
5. Inspect: const keys = await AsyncStorage.getAllKeys()
Common pitfalls & checks
  • Always await setItem to ensure write completes before app state changes.
  • Check getItem result for null before parsing with JSON.parse.
  • Don't call clear without explicit confirmation; it removes all keys.
Pro tip

Group related settings under a single key as a JSON object to reduce number of operations and simplify migrations.
