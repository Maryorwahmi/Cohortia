Starter code (excerpt)
import AsyncStorage from '@react-native-async-storage/async-storage'

const SETTINGS_KEY = 'userSettings'

async function loadSettings() {
  try {
    const jsonValue = await AsyncStorage.getItem(SETTINGS_KEY)
    if (jsonValue != null) {
      const settings = JSON.parse(jsonValue)
      // apply settings.isDarkMode, settings.notificationSound
    }
  } catch (e) {
    console.error('Failed to load settings', e)
  }
}

async function saveSettings(settings) {
  try {
    const jsonValue = JSON.stringify(settings)
    await AsyncStorage.setItem(SETTINGS_KEY, jsonValue)
  } catch (e) {
    console.error('Failed to save settings', e)
  }
}
Explanation & checklist
  • Use one key for the settings object to batch reads/writes when appropriate.
  • Always check for null before parsing to avoid JSON.parse errors.
  • Wrap AsyncStorage calls in try/catch for robust error handling.
  • Save after initial load completes to prevent accidental overwrites.
