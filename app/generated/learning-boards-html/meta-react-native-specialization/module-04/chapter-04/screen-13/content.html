Module 5 › Chapter 4.4 › Hands-on Activity
Activity checklist
  1. Install '@react-native-async-storage/async-storage' if needed and import it.
  2. Build a login form with username, password, and a remember switch.
  3. Load keys on mount; pre-fill username when the flag is 'true'.
  4. On login, setItem for username and flag when checked; otherwise removeItem.
  5. Test persistence across full app restart and implement Logout to clear data.
Testing tips
  • Simulate a full app restart to verify persisted state.
  • Check storage contents with getAllKeys during debugging.
  • Confirm removeItem removes the right keys when opting out.
