Module 5 › Chapter 4.4 › Managing Keys
Key management
Use getAllKeys to list keys. Remove specific keys with removeItem. Only use clear when you intend to erase every stored value and protect it with confirmation.
Danger

clear() deletes all AsyncStorage entries. Confirm with the user before calling it.

Migration example
Read all keys, transform legacy entries into a new format, set the consolidated key, then remove legacy keys. This keeps storage tidy and predictable.
