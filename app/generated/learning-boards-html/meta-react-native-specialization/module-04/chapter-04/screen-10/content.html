Module 5 › Chapter 4.4 › When Not to Use AsyncStorage
Good fit for AsyncStorage
  • Theme and UI preferences
  • Small flags and feature toggles
  • Remembered username or short tokens (non-sensitive)
When to choose alternatives
  • Large message histories or collections
  • Complex queries or relationships between data
  • Sensitive data that requires encryption
Practical contrast

Store a theme object in AsyncStorage. But store chat history or user credentials in a database or encrypted store to protect privacy and scale reads/writes.
