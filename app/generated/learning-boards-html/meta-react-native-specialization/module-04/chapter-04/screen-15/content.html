Module 5 › Chapter 4.4 › Security & Privacy
Do not store
  • Raw passwords or secret keys
  • Sensitive personal information without encryption
  • Large datasets that increase attack surface
Prefer alternatives
  • Encrypted storage for secrets
  • Databases for large, structured data
  • Short-lived tokens with server-based refresh
Practical checklist

Review each persisted item and ask: is this sensitive? If yes, do not store it in AsyncStorage without encryption; choose a secure alternative.
