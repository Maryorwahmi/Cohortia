Learning Objectives — Practice
Map each objective to a real coding milestone to practice the API and error handling.
01. Choose data to persist
Pick non-sensitive items like theme, last viewed tab, or a remembered username. Confirm no secrets are stored.
Milestone: Identify and document a single persisted key.
02. Implement save/load
Use async/await with setItem/getItem and test across hot reload and full restart to ensure persistence.
Milestone: Data remains after app restart.
03. Serialize objects
Wrap objects with JSON.stringify when storing and JSON.parse when reading, checking for null first.
Milestone: Parsed object used without parse errors.
04. Remove & reset safely
Use removeItem for single keys and clear only behind a confirmation prompt to avoid data loss.
Milestone: Confirmation before clear and removeItem tested.
