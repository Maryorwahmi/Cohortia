Module 5 › Chapter 4.4 › Common Mistakes
Mistake → Symptom → Fix
Not stringifying objects → stored value like '[object Object]' → JSON.stringify before save.
Parsing null → crash → check for null before JSON.parse.
Not awaiting setItem → lost writes or race conditions → await the promise.
Debugging checklist
  • Log getItem output before parsing.
  • Use getAllKeys to inspect what keys exist.
  • Test save/load across a full app restart, not just hot reload.
