JSON.stringify & JSON.parse
Convert objects into strings for storage and back into objects for use.
Example
const settings = { isDarkMode: true, notificationSound: false }
const jsonValue = JSON.stringify(settings)
await AsyncStorage.setItem('userSettings', jsonValue)

const stored = await AsyncStorage.getItem('userSettings')
if (stored != null) {
  const parsed = JSON.parse(stored)
  // use parsed.isDarkMode
}
Notes & pitfalls
  • Do not call JSON.parse on null — check for null first.
  • JSON does not preserve functions or prototypes; rehydrate if necessary.
  • Dates are converted to strings; parse back with new Date(string) if needed.
Common mistake

Saving an object directly stores an unhelpful string like '[object Object]'. Always stringify first.
