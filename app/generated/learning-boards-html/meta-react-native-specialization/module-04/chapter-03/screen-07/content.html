Module 4 › Chapter 4.3 › Error Handling
Typical try...catch
try {
  const response = await axios.get(url);
  // use response.data
} catch (err) {
  if (err.response) {
    // server responded with status outside 2xx
    // use err.response.status and err.response.data
  } else if (err.request) {
    // request made but no response received
  } else {
    // request setup error
  }
}
During development, console.log err.response and err.request to learn backend behavior.
Handling examples
401 Unauthorized
If err.response.status === 401, prompt for sign-in or trigger token refresh logic.
No response
When err.request exists, surface a network retry UI and avoid showing misleading server messages.
Key Takeaway
Differentiate server, network, and setup errors and handle each with a targeted UX path.
