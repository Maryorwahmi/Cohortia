Module 4 › Chapter 4.3 › Custom Instances
api.js example
import axios from 'axios';

const api = axios.create({
  baseURL: 'https://api.yourapp.com/v1',
  timeout: 10000,
  headers: { 'Content-Type': 'application/json', 'Accept': 'application/json' }
});

api.interceptors.request.use(config => config);
export default api;
Import this instance in components and call api.get('/users') instead of full URLs.
Why it matters
Instances keep configuration local, avoid global mutations, and allow instance-specific interceptors that only affect a single API surface.
Practical example
Create an instance for your public API and another for an internal service that requires extra headers or shorter timeouts.
Common mistake
Modifying axios.defaults spreads settings across all requests and makes isolation and testing harder.
