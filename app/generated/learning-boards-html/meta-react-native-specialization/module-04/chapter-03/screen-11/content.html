Module 4 › Chapter 4.3 › Timeouts & Headers
Configurations that matter
baseURL
Shortens calls and centralizes API root.
timeout
Automatically cancels excessively slow requests.
default headers
Set Content-Type and Accept consistently for the API.
Common mistakes and fixes
  • Not awaiting axios calls — fix by using await inside async functions so try...catch catches errors.
  • Checking only error.message — inspect err.response and err.request for reliable handling.
  • Mutating axios.defaults globally — prefer axios.create for per-API settings.
Key Takeaway
Small configuration choices prevent intermittent bugs and make behavior predictable across environments.
