Request & response interceptors
Step through the common interceptor lifecycle and a typical use-case to attach a header.
1. Request interceptor
Receives config, optionally read token from storage, set config.headers.Authorization, return config.
2. Server processing
Server receives headers and body, returns a response or an error status code.
3. Response interceptor
Inspect response, transform data, or on error check status codes to trigger global logic like sign-out.
<!-- request interceptor example -->
axios.interceptors.request.use(async config => {
  const token = await AsyncStorage.getItem('userToken');
  if (token) config.headers.Authorization = `Bearer ${'{token}'}`;
  config.headers['X-App-Version'] = '1.0.0-rn';
  return config;
}, error => Promise.reject(error));
Key Takeaway
Register interceptors on the correct instance to limit side effects, and use them to centralize auth headers and response handling.
