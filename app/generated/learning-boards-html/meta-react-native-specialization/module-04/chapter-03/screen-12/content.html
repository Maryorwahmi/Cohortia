Activity: AxiosUsersScreen refactor
Follow the chapter starter code to create a custom instance, add a request interceptor, and fetch users.
<!-- key steps -->
1. Create api = axios.create({ baseURL, timeout: 5000 })
2. api.interceptors.request.use(config => { config.headers['X-App-Version'] = '1.0.0-rn'; return config; })
3. Use const response = await api.get('/users'); setUsers(response.data)
4. In dev tools, verify the X-App-Version header is present
Debugging check
If the header is missing, ensure the component imports the same instance that registered the interceptor.
Challenge
Add a response interceptor that logs response.status and response.config.url for successful responses.
