Install
npm install axios
# or
yarn add axios
GET example
<!-- in a React Native component -->
async function fetchPosts() {
  try {
    const response = await axios.get('https://jsonplaceholder.typicode.com/posts?_limit=10');
    // parsed JSON available at response.data
    setPosts(response.data);
  } catch (err) {
    // handle err.response / err.request / err.message
  }
}
POST example
async function createPost() {
  const newPost = { title: 'My New Axios Post', body: 'Content', userId: 1 };
  try {
    const response = await axios.post('https://jsonplaceholder.typicode.com/posts', newPost);
    // response.data contains the created resource
  } catch (err) {
    // handle error
  }
}
Note: Axios sets Content-Type and stringifies the body automatically for JSON objects.
Check your understanding

Run the GET and POST in a small component, log response.data, and confirm the network tool shows the JSON body and Content-Type header.
