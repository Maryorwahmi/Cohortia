Stepwise refactor to Context

Follow a safe, incremental approach to replace prop forwarding with Context.

Refactor checklist
  1. Identify the global value being forwarded.
  2. Create ThemeContext and export it.
  3. Wrap the owning component subtree with Provider.
  4. Update leaf consumers to use useContext.
  5. Remove forwarded props from intermediate components incrementally.
Safety checks
  • Run tests after each change to catch regressions.
  • Memoize Provider value to avoid needless re-renders.
  • Split contexts when unrelated data would cause broad updates.
Real-world note
Refactor incrementally and prefer small, testable changes. That keeps components reusable and reduces risk.
