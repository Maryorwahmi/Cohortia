Choosing the right state approach

Match the tool to your data patterns and update frequency.

Local state (useState)

Best for UI that only one component manages, e.g., a text input or toggle within a component.

Context API

Good for global preferences like theme or language that change infrequently and need to be read by many components.

State libraries

Use Redux or similar when you need advanced patterns, performance optimizations, or middleware for complex global state.

Assessment tip
When asked whether Context is appropriate, consider how frequently the value updates and how many components would re-render. That determines whether Context will be efficient.
