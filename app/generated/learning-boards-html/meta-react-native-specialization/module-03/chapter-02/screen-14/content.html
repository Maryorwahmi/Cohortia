What to Remember

Prop Drilling
Passing props through components that don't use them, increasing boilerplate.
Context API
A built-in way to share values across a subtree without prop forwarding.
React.createContext()
Creates a Context object; default value is a fallback when no Provider is present.
Takeaway

Prefer Context for global, infrequently changing data like theme; memoize Provider values and scope Providers thoughtfully.
