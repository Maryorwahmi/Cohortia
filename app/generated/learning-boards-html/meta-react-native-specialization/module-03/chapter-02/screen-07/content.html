ThemeContext.js (starter)

A minimal file that exports a Context with safe defaults so consumers don't crash when a Provider is absent.

Starter code
// ThemeContext.js
import React from 'react';

const ThemeContext = React.createContext({
  theme: 'light',
  toggleTheme: () => {}, // dummy function as default
});

export default ThemeContext;
Why a default matters

It prevents runtime errors in isolated tests and makes the import contract explicit. The Provider will override these values in real use.
