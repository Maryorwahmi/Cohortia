Practice steps

Follow these steps to build a Theme Switcher and to check your understanding.

Create ThemeContext
Make a file that exports React.createContext with sensible defaults. This default keeps components safe if a Provider is missing.
Wrap App in Provider
Provide a value object containing theme and toggleTheme at the top of your tree so descendants can read it.
Consume with useContext
Use useContext in functional components to access theme and actions without prop forwarding.
Key Tip

Keep Context for global, infrequently changing data. For highly dynamic cross-cutting state, prefer a specialized state library.
