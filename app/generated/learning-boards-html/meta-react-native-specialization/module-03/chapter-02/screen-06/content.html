Context API essentials

Three primitives let you create and consume shared values with clear scope.

1. createContext()

Creates a Context object with an optional default value used when no Provider is present.

2. Context.Provider

Wrap a subtree and pass a value prop. All descendants can read that value from the closest Provider above them.

3. useContext()

A hook for functional components that returns the current context value from the nearest Provider.

Quick example
const ThemeContext = React.createContext({ theme: 'light', toggleTheme: () => {} });

// Provider in App
<ThemeContext.Provider value={{ theme, toggleTheme }}> ... </ThemeContext.Provider>

// Consumer
const { theme } = useContext(ThemeContext);
