Prop Drilling: definition & example

A clean definition, a short code snippet, and a simple analogy make it concrete.

Analogy

Think of passing a message through a line of people who don’t need it, only to get it to someone at the end. Each person still has to hold and pass the message.

Example code (prop forwarding)
// Parent.js
const Parent = () => {
  const theme = 'light';
  return <A theme={theme} />;
};

// A.js
const A = ({ theme }) => <B theme={theme} />;

// B.js
const B = ({ theme }) => <C theme={theme} />;

// C.js (uses theme)
const C = ({ theme }) => <Text>Theme: {theme}</Text>;
Costs & misconceptions
  • Increases boilerplate: many components accept and forward props they don't use.
  • Tightens coupling: components become tied to a specific prop shape.
  • Maintenance overhead: changes to shared data require updates across forwards.
  • Misconception: it's not merely cosmetic — it can hurt reuse and clarity.
Check your understanding
If you find yourself adding the same prop to many intermediate components, you're likely experiencing prop drilling.
