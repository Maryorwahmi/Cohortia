Wrap the app with ThemeContext.Provider

Manage state at the Provider owner and pass a value object to descendants.

App.js (example)
import React, { useState, useMemo } from 'react';
import ThemeContext from './ThemeContext';

const App = () => {
  const [theme, setTheme] = useState('light');
  const toggleTheme = () => setTheme(prev => (prev === 'light' ? 'dark' : 'light'));

  const value = useMemo(() => ({ theme, toggleTheme }), [theme]);

  return (
    <ThemeContext.Provider value={value}>
      <MainNavigation />
    </ThemeContext.Provider>
  );
};
Provider placement & performance
  • Place Provider where the shared scope should begin: too low and some components miss it.
  • Memoize the value object to avoid passing a new reference on every render.
  • Only include what consumers need: avoid passing large data structures unnecessarily.
Pro tip
If only a small part of your app needs frequent updates, consider scoping a separate Provider for that subtree to limit re-renders.
