Implement a Theme Switcher

Follow these ordered steps to complete the lab in your project.

Step 1: Create ThemeContext.js
Export React.createContext with defaults so components are safe before Provider exists.
Step 2: Provide in App
Use useState, create toggleTheme, memoize value, and wrap children with Provider.
Step 3: Consume with useContext
In ThemeToggler read theme and toggleTheme and update styles accordingly.
Try this
Run the app and change the theme. Observe which components update. If too many update, consider splitting contexts or memoizing values.
