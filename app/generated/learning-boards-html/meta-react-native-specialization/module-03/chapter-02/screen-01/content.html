Prop Drilling vs. Context API

Understand why passing props through many layers becomes fragile, and how the Context API provides a clearer pattern for sharing global data such as theme or authentication across your component tree.

In this lesson
Prop Drilling

Passing props through many components to reach a nested child.

Context API

Create and provide a shared value to any descendant consumer.

When to use

Best for global data that changes infrequently, like theme or language.
