Core API
Open & Close Drawer
Use navigation.openDrawer and navigation.closeDrawer from any screen with access to the navigation prop. This gives you predictable control for header icons and buttons.
  • Open the drawer: navigation.openDrawer()
  • Close the drawer: navigation.closeDrawer()
  • Navigate to drawer routes vs opening UI are different actions.
Example
function FeedScreen({ navigation }) {
  return (
    <View>
      <Button title="Open Drawer" onPress={() => navigation.openDrawer()} />
      <Button title="Go to About" onPress={() => navigation.navigate('About')} />
    </View>
  );
}
