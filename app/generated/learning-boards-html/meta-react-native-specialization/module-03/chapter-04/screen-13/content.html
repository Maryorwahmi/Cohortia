Concept
options vs screenOptions
Use screenOptions on the navigator for shared defaults. Use options on individual screens for overrides such as tabBarLabel or headerShown.
  • screenOptions sets defaults for all children.
  • options overrides values for a specific screen.
  • Some properties replace rather than merge; be explicit when needed.
Example
function HomeTabs() {
  return (
    <Tab.Navigator screenOptions={({ route }) => ({
      tabBarIcon: ({ color, size }) => {/* return icon based on route */},
      tabBarActiveTintColor: 'tomato',
      tabBarInactiveTintColor: 'gray',
    })}>
      <Tab.Screen name="Feed" component={FeedScreen} />
      <Tab.Screen name="Profile" component={ProfileScreen} />
    </Tab.Navigator>
  );
}
