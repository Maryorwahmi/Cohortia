Module 4 › Chapter 3.4 › Key Concepts
Tab Navigator
A navigation pattern showing primary routes, usually in a bottom bar for quick switching.
createBottomTabNavigator
The function from @react-navigation/bottom-tabs used to create a bottom tab navigator and register its screens.
Drawer Navigator
A side menu that slides out to present secondary or less-frequent screens such as About or Settings.
Takeaway: Map frequency to visibility — tabs for frequent, drawers for secondary.
