Process
Install & Configure
1. Install: @react-navigation/drawer plus gesture and reanimated packages.
2. For bare iOS projects run pod install in the ios folder.
3. Import createDrawerNavigator and declare Drawer.Screen items.
4. Provide initialRouteName and optional drawerStyle or drawerContent options.
Misconception: The drawer always belongs at the root. It can be nested, but consider discoverability and swipe conflicts when nesting multiple gesture-enabled navigators.
Code snippet
import { createDrawerNavigator } from '@react-navigation/drawer';

const Drawer = createDrawerNavigator();

function MyDrawer() {
  return (
    <Drawer.Navigator initialRouteName="Feed">
      <Drawer.Screen name="Feed" component={FeedScreen} />
      <Drawer.Screen name="Article" component={ArticleScreen} />
    </Drawer.Navigator>
  );
}
