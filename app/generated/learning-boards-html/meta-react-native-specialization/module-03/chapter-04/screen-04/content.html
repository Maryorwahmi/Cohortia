Comparison
Tab Navigator
Best for 3–5 primary sections that users switch between frequently. Visible by default and optimized for quick switching.
Visibility: Always shown
Interaction cost: Low (one tap)
Typical use: Home, Search, Upload, Profile
Misconception: Tabs are not a place for every screen. Overloading tabs reduces clarity.
Comparison
Drawer Navigator
Best for secondary or infrequently used screens. Hidden by default and opened by gesture or icon.
Visibility: Hidden (slide-out)
Interaction cost: Medium (open then select)
Typical use: Settings, About, Legal, Help
Misconception: The drawer is not a replacement for organized primary navigation; use it sparingly.
