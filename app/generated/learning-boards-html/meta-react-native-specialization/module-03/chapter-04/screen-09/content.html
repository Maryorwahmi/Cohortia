Common Nesting Patterns
Root Stack > Tab Navigator: push detail screens above static tabs.
Drawer > Tabs: expose About or Settings in a drawer while main content uses tabs.
Stack > Drawer > Tabs: complex apps can compose all three to control header and modal behavior.
Misconception: You should not try to control lower-level navigators' headers from arbitrary nested screens; use options and higher-level navigator settings for consistent results.
