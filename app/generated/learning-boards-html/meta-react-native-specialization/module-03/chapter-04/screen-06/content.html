Definition
tabBarIcon & tabBarLabel
tabBarIcon is a function that receives color and size and should return an icon element. tabBarLabel is a string or function to label the tab.
  • Accept color and size parameters and pass them to your icon.
  • Prefer concise labels for clarity and accessibility.
  • Use tabBarBadge for counts like unread messages.
Common Mistake

Hard-coding icon color or size prevents the navigator from showing active/inactive state correctly.

Example code
// inside Tab.Screen options
options={{
  tabBarLabel: 'Products',
  tabBarIcon: ({ color, size }) => (
    <Icon name="shopping-bag" color={color} size={size} />
  ),
  tabBarBadge: 3, // optional
}}
