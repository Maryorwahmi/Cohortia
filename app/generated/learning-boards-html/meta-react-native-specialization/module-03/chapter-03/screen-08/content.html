Comparison

navigate vs push vs goBack

navigation.navigate('Route')
Navigate to a route; may reuse an existing instance deeper in the stack.
navigation.push('Route')
Always push a new instance of a screen, enabling multiple detail pages in history.
navigation.goBack()
Pop the current screen and return to the previous one.
Example scenario
News feed: tapping three different articles should open each in its own detail screen. Use navigation.push so each tap pushes a new instance. If you used navigate and an ArticleDetail route already existed near the top, navigate might return to it instead of creating a new one, which loses the separate reading history.
Misconception to avoid
Assuming navigate always creates a new instance. It may instead move to an existing route with the same name.
Key Takeaway

Choose push when you need distinct instances; use navigate for route reuse and goBack to return.
