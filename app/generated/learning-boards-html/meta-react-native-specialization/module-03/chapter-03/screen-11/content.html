Static vs Dynamic headers

// Static title
<Stack.Screen name="Home" component={HomeScreen} options={{ title: 'Welcome Home' }} />

// Dynamic title based on params
<Stack.Screen name="Details" component={DetailsScreen} options={({ route }) => ({ title: route.params?.name || 'Details' })} />
Runtime updates
When data loads asynchronously in a screen, call navigation.setOptions({ title: loadedName }) so the header updates. Always guard against undefined params when computing titles to avoid rendering issues.
Practical tip
Use fallback titles until data is available, then update the header to show loaded content for a smoother UX.
Key Takeaway

Choose between static options, options-as-function, or setOptions depending on when and how your title data becomes available.
