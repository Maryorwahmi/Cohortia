Process

Install and configure

Follow a short install sequence and verify native modules are linked for iOS.

// Core
npm install @react-navigation/native

// Expo projects
npx expo install react-native-screens react-native-safe-area-context

// Bare RN projects
npm install react-native-screens react-native-safe-area-context
cd ios && pod install
Why react-native-screens?
Prevents rendering screens that are not focused, improving memory and transitions.
Why safe-area
Ensures content respects notches and status bars on different devices.
Verification steps
  1. Install packages and run pod install on iOS.
  2. Wrap your app with NavigationContainer.
  3. Create a simple Stack.Navigator and confirm screens render and back behavior works.
Common mistake
Skipping pod install or using mismatched native versions leads to runtime failures. Always run the platform-specific commands after installing native dependencies.
Key Takeaway

Follow the install checklist and verify native linking to avoid runtime navigation issues.
