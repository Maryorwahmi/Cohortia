Definition

Passing parameters

// Sending
navigation.navigate('Details', { itemId: 86, name: 'T-Shirt' });

// Receiving
function DetailsScreen({ route, navigation }) {
  const { itemId, name } = route.params || {};
  // defensive access prevents crashes when params are missing
}
Prefer passing IDs for large data and fetch on the Details screen when needed. Small plain objects are fine for quick flows.
Practical notes
  • Always check route.params exists before destructuring.
  • Use optional chaining like route.params?.itemId for concise safety.
  • Set header titles with options={({ route }) => ({ title: route.params?.name || 'Details' })}.
Common mistake
Destructuring route.params without a fallback causes runtime errors when the screen is opened without parameters.
Key Takeaway

Pass small data or IDs and always read route.params defensively to prevent crashes.
