Module 3 › Chapter 3.3 › Practice Objectives
01 — Build the two-screen app

Implement a Home and Details screen. Use navigate to pass a product object and verify the details render.

02 — Install & verify

Run npm install for @react-navigation/native and platform helpers. On iOS run pod install then test on a simulator.

03 — Observe push vs navigate

Open the same detail multiple times and compare navigate versus push behavior for history and back navigation.

04 — Defensive params

Read route.params? in the Details screen to prevent crashes and display a fallback when missing.
