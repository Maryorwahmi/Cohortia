Hands-on Activity

Build a two-screen stack

  1. Initialize project and install navigation packages.
  2. Create HomeScreen.js with a product object and navigate on press.
  3. Create DetailsScreen.js and read route.params with a fallback.
  4. Wire App.js with NavigationContainer and Stack.Navigator.
Verification checklist
  • Details displays the passed product fields.
  • Back button returns to Home and preserves any state.
  • Using push opens multiple distinct detail instances.
  • No runtime errors about undefined route.params when opening Details directly.
Mini challenge
Implement a Go Back button in Details that calls navigation.goBack() and confirm history behaves as expected.
Key Takeaway

A simple two-screen stack shows the core patterns of installation, wiring, param passing, and back navigation you will reuse across apps.
