Common Mistakes

Defensive coding

Undefined params
Always use route.params || {} or optional chaining to avoid crashes when params are missing.
Missing native linking
Run pod install on iOS after adding native modules to avoid runtime errors.
Wrong route names
Ensure the name used in Stack.Screen matches the string you pass to navigate or push.
Performance caution
Avoid passing large objects or functions through navigation parameters. Instead pass an ID and fetch or reference cached data in the target screen to keep navigation payloads small.
Test cases
Open Details with params, open Details without params, open Details multiple times, and verify goBack returns you to the previous state to ensure correct behavior.
Key Takeaway

Defensive patterns and careful testing prevent most navigation-related bugs.
