Mapping objectives to code
Snapshot mnemonic

Treat state as a snapshot taken at render time; use the setter to request the next snapshot.

Functional update

When multiple updates may run, pass a function to the setter to compute the next snapshot from the previous one.

Checkpoints
  • Declare state with useState and read it in render logic.
  • Use functional updates when the new value depends on old value.
  • Create new object/array references when updating complex state.
