When to use functional updates
Use this pattern whenever the new state is computed from previous state. It is safe during rapid events, timeouts, and when multiple setters run before React re-renders.
Examples
  • Toggle: setIsOpen(prev => !prev)
  • Increment: setCount(prev => prev + 1)
  • Append to array: setItems(prev => [...prev, newItem])
Pro tip

Prefer functional updates as a default when deriving a new value. They are concise and avoid subtle bugs from stale values.

Check your understanding

If you need to do count = count + 1 based on the current render only once, direct setCount(5) is fine; but when you need to add relative to current state, use prev => prev + 1.
