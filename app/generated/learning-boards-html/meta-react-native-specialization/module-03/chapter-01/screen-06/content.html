Code walkthrough
import React, { useState } from 'react';

const LikeButton = () => {
  const [isLiked, setIsLiked] = useState(false);

  const toggle = () => {
    // functional update ensures correctness under rapid taps
    setIsLiked(prev => !prev);
  };

  return null; // UI omitted here
};
The key line is setIsLiked(prev => !prev). It uses the previous snapshot, so even if multiple toggle calls run before React re-renders, each call uses the most recent prior value.
Tips
  • Name setters clearly: setCount, setUser.
  • Use functional updates for sequential changes.
  • Do not read the state variable expecting it to be immediately updated after calling the setter.
