Module 3 › Chapter 3.1 › Immutability
Do this — Objects and arrays
// Objects
setUser(prev => ({ ...prev, age: 31 }));

// Arrays (append)
setItems(prev => ([...prev, newItem]));

// Arrays (remove)
setItems(prev => prev.filter(item => item.id !== id));
These patterns always create a new reference so React notices the change and re-renders. They are also easier to reason about and safer for undo/redo logic.
Don't do this
// Mutating in place
user.age = 31;
setUser(user); // may not re-render

items.push(newItem);
setItems(items); // mutates same array
Mutations keep the same reference, which can prevent React from detecting the update.
