Module 3 › Chapter 3.1 › What is component state?
Definition

State is data a component keeps and manages itself. When state changes, React schedules a re-render so the UI matches the latest snapshot.

Analogy

Think of state as a photograph of the component's data at a moment in time. Updates create a new photograph rather than editing the old one.

Concrete example

A Like button stores isLiked boolean. Toggling that boolean changes label and color on the next render.

Key Takeaway

State is local, drives rendering, and must be updated via setter functions to remain predictable.

Quick comparison
State
Private to component; drives UI based on its snapshot.
Props
Passed from parent; read-only inside the child.
