Module 3 › Chapter 3.1 › Key Concepts
State

Local snapshot data that affects rendering and behavior.

useState Hook

Returns [value, setter]; use setter to schedule updates rather than mutate directly.

Immutability

Create new object/array copies when updating complex state so React detects changes.

Summary takeaway

Adopt the functional update pattern and immutability habits early to make stateful components reliable and easy to reason about.
