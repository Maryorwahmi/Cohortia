Module 3 › Chapter 3.1 › Debugging state
Common mistakes
Direct mutation of objects or arrays prevents React from detecting changes.
Relying on state immediately after calling setter; remember updates are scheduled.
Stale closures or shadowed variables cause unexpected values in callbacks.
Debug tips
  • Log the state value in render to observe snapshots.
  • Log object references or use JSON.stringify to confirm new copies.
  • Switch to functional updates when behavior seems inconsistent under rapid actions.
