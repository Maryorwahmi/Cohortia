Starter code (visual)
import React, { useState } from 'react';
import { View, Text } from 'react-native';

const App = () => {
  const [count, setCount] = useState(0);

  // Implement handlers using functional updates
  const handleIncrement = () => {
    setCount(prevCount => prevCount + 1);
  };

  const handleDecrement = () => {
    setCount(prevCount => Math.max(0, prevCount - 1));
  };

  return null; // UI omitted for brevity
};
Implement UI with a large count display and two tappable areas that call the handlers. Test by rapidly invoking increment to confirm count increases correctly.
Implementation checklist
  • Declare count with useState(0).
  • Use functional updates in both handlers.
  • Prevent negative counts with Math.max.
  • Test under rapid interactions.
