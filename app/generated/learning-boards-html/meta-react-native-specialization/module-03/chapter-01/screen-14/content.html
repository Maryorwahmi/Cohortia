Module 3 › Chapter 3.1 › What to Remember
Snapshot mindset
Treat state as the component's current photograph; avoid in-place edits.
Functional updates
Use setState(prev => ...) when the next value depends on previous state.
Immutable changes
Always return new arrays/objects so React detects changes.
Final thought

These three habits make stateful components predictable and resilient to rapid user interactions and optimization behaviors like batching.
