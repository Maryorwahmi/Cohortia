Module 3 › Chapter 3.1 › Declaring state
Process: declare useState
  1. Import useState from React: import { useState } from 'react'.
  2. Call useState with an initial value: const [value, setValue] = useState(initial).
  3. Read value in your render logic and call setValue to request changes.
Quick example
const [count, setCount] = useState(0);
// read: {count}
// update: setCount(1) or setCount(prev => prev + 1)
Explanation and tips
  • The setter schedules an update; it does not change the variable immediately.
  • Pass a function to setter when the new value depends on previous state.
  • Keep state minimal—derive values from state when possible.
Common misconception

Assuming setter updates the variable synchronously in the same function. Use functional updates when needed.
