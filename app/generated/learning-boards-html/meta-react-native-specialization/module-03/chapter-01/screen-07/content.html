Module 3 › Chapter 3.1 › Asynchronous updates
Scenario: increment twice
Initial count = 0. Two calls inside one handler:
// Using variable
setCount(count + 1);
setCount(count + 1);
// Result: 1 (both used same snapshot)

// Using functional updates
setCount(prev => prev + 1);
setCount(prev => prev + 1);
// Result: 2 (each uses the latest prior value)
Why this matters
  • Batched updates improve performance but require correct update patterns.
  • Functional updates are resilient to batching and concurrent scheduling.
  • If a handler depends on the current state, prefer prev => compute(prev).
Misconception

Do not assume setters update the variable synchronously within the same function call.
