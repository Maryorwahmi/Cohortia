Troubleshooting

Checklist for setup issues

  • Confirm CLI installed globally and accessible via the terminal.
  • Check Node and package manager versions; use a version manager if needed.
  • Verify device and computer share a network and that firewall rules are not blocking traffic.
Common Mistake

Running a project without a global CLI install or with the wrong Node version is the most frequent blocker.

Repair commands and checks
# Reinstall Expo CLI globally
npm install -g expo-cli

# Use a version manager (example placeholder)
# nvm install 14 && nvm use 14

# Restart dev server
npm start
After running these checks, review the dev server logs for hints and retry connecting your device. If network errors persist, try a different network or tethering to isolate the issue.
