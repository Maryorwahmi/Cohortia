Module 1 › Chapter 1.1 › Key Concepts
Node.js
A runtime that executes the development tools required to build and serve your JavaScript app.
npm & yarn
Package managers that install project dependencies; use global installs only for CLI tools.
Expo CLI / Expo Go
A managed workflow and mobile app that enable rapid prototyping by running your JavaScript bundle on devices via a QR code.
Summary
Verify installs with version checks, use Expo for fast iteration, and follow a short troubleshooting checklist when things go wrong.
