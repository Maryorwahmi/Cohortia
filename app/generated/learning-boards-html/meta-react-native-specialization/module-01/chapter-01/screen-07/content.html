Hands-on

Create and edit

Follow the commands to make a project, then edit App.js to replace the starter text with a personalized message to confirm live reload works.

Command: expo init HelloReactNative
Command: cd HelloReactNative
Command: npm start
Key Takeaway

A single file edit and save should update the app immediately when the dev server is running.

Example App.js change
import React from 'react';
import { Text, View } from 'react-native';

export default function App() {
  return (
    <View style={{ flex: 1, alignItems: 'center', justifyContent: 'center' }}>
      <Text>Hello, Cohortia React Native!</Text>
    </View>
  );
}
Replace the Text content, save, and the updated text should appear immediately in Expo Go or your simulator. If it doesn't, check the dev server output for errors or a blocked port.
