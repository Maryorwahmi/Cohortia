Process Flow

Create and run with Expo

1
Install Expo CLI
npm install -g expo-cli
2
Create a project
expo init HelloReactNative (choose blank)
3
Start the dev server
npm start or expo start — scan the QR or press a/i for emulators
Key Takeaway

Expo gives you a fast feedback loop so you can focus on building UI in JavaScript.

Terminal demo (commands)
# Install Expo CLI globally
npm install -g expo-cli

# Create a new project using the blank template
expo init HelloReactNative

# Change into the project and start
cd HelloReactNative
npm start
When the server starts it prints a QR code in the terminal and opens the Expo Dev Tools in a browser. Scan with Expo Go to run on a device, or press 'a' or 'i' in the terminal to launch emulators when configured.
