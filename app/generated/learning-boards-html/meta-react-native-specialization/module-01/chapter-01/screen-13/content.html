Check Your Understanding

Edit and observe

Make a minor change in App.js, save, and confirm the update appears in Expo Go or the simulator. This confirms your development server and bundler are operational.

Key Takeaway

If the change does not appear, inspect logs, look for syntax errors, and verify connectivity before changing native code.

Example snippet
// App.js example
import React from 'react';
import { View, Text } from 'react-native';

export default function App() {
  return (
    <View style={{ flex: 1, alignItems: 'center', justifyContent: 'center' }}>
      <Text>Hello, Cohortia React Native!</Text>
    </View>
  );
}
Change the Text value, save, and observe the update. If it fails, check the terminal for bundler errors or network issues.
