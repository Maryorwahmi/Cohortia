Core Concept

Node.js — runtime explained

Node.js runs JavaScript on your machine so development tools like bundlers, package managers, and dev servers can execute. It is not required on the mobile device that runs the app.

Definition: A server-side JavaScript runtime used by tooling.
Example: expo start runs a Node process that serves your JavaScript bundle.
Misconception: You do not need Node on your phone; only on your development machine.
Key Takeaway

Install Node first and confirm the version to avoid later tooling issues.

Quick checks and example
node --version
# expected output example: v14.17.0
If the command prints a version, Node is installed. If not, install Node.js before proceeding.
Analogy
Think of Node as the engine that runs your build tools; without it, the car won’t move even if the rest is assembled.
