Definition

npm vs Yarn

Both install packages. npm ships with Node. yarn is an alternative package manager you can install using npm and then use to manage dependencies with consistent locking.

Local install example: npm install react-native — adds to project dependencies.
Global install example: npm install -g expo-cli — makes the CLI available system-wide.
Common mistake: using yarn add when you intended a global install.
Commands (try these in your terminal)
# Install yarn using npm
npm install -g yarn

# Install Expo CLI globally with npm
npm install -g expo-cli

# Or with yarn
yarn global add expo-cli

# Verify versions
node --version
npm --version
yarn --version
After installation, confirm the global binary is present by checking its version. If you see an error, you may have installed without the global flag or need permission adjustments.
