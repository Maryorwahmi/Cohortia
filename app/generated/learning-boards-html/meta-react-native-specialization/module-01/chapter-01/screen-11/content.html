Core Tool

Visual Studio Code

VS Code offers an integrated terminal and a rich extension ecosystem that supports React Native development and debugging workflows.

ESLint — catches common code quality and syntax issues as you type.
Prettier — enforces consistent code formatting on save.
React Native Tools — helps attach debuggers and view logs from running apps.
Practical tip
Open the project folder in VS Code, use the integrated terminal to run expo start, and enable extensions for linting and formatting to catch errors before runtime.
Key Takeaway

Set up VS Code with a small set of extensions to shorten feedback loops and avoid simple errors.
