Module 2 › Chapter 1.3 › Pitfalls & Tips
Avoid var
Use const by default; let when reassignment is needed.
Reason: var's function scope and hoisting cause subtle bugs in loops and conditionals.
Const ≠ immutable
const prevents reassigning the binding, not mutating contents.
Use spread to create new objects/arrays for state updates to avoid mutation issues.
Shallow copy caution
Spread copies only top-level properties; nested objects remain shared.
If nested state changes, clone each affected level or use structured update helpers.
Arrow functions
Great for callbacks; not for constructors or functions needing their own this.
Destructuring
Use defaults and avoid deeply nested patterns when data shape may vary.
Module design
Export focused utilities and import only what you need to keep files testable.
