Module 2 › Chapter 1.3 › Key Concepts
let & const
Block-scoped declarations; prefer const to express immutability of binding.
Arrow Functions
Concise callbacks that inherit lexical this; ideal for handlers and inline functions.
Destructuring
Extracting properties or items into variables reduces ceremony when handling props or responses.
Summary takeaway

Adopt const-first, use arrow functions for stable callbacks, and destructure to make intent explicit. These patterns reduce common bugs in React Native.
