Module 2 › Chapter 1.3 › Rest Operator
Function parameters
Gather arguments into an array parameter to accept variable inputs.
function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}

sum(1, 2, 3); // 6
Use case
Build flexible wrappers around APIs that accept varying numbers of arguments.
Object rest example
Extract named fields and collect the remainder into a new object for forwarding props or building reduced objects.
const person = { name: 'John', age: 30, city: 'NY' };
const { name, age, ...otherInfo } = person;
// otherInfo = { city: 'NY' }
Misconception
Rest is not spread. Rest collects into a new array or object. Spread expands elements into a literal or call.
