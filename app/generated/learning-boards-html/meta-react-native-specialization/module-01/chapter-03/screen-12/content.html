Refactored (after)
import React from 'react';
import { View, Text } from 'react-native';

const Greeting = ({ user }) => {
  const message = `Hello, ${user.firstName} ${user.lastName}!`;
  return (
    
      {message}
    
  );
};

export default function App() {
  const currentUser = { firstName: 'Alice', lastName: 'Smith' };
  return (
    
      
    
  );
}
What changed
var → const, function → arrow, props destructured, template literals for clarity.
Why it matters
Clearer intent, fewer accidental reassignments, and simpler callbacks in components.
Try this
Run the refactor locally and check that visual output matches. If something changes, look for in-place mutation or missing reassignments.
