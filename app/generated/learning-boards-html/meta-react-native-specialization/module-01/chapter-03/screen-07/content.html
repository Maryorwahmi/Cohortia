Module 2 › Chapter 1.3 › Destructuring Objects
Basic syntax
Unpack properties from objects into variables in one statement. You can also rename and set defaults.
// basic
const user = { name: 'Sam', age: 28 };
const { name, age } = user;

// rename and default
const { name: userName, email = 'unknown@example.com' } = user;
Key takeaway
Destructuring reduces boilerplate when extracting known properties and improves readability.
Nested destructuring & caution
You may destructure nested objects, but deep patterns can be fragile if the shape is inconsistent. Consider safe defaults or optional chaining before nesting patterns.
// nested
const response = { user: { id: 1, profile: { name: 'Lee' } } };
const { user: { profile: { name } = {} } = {} } = response;
Common mistake
Assuming destructuring performs safety checks. If a path is undefined you may get an error; use defaults or optional chaining when necessary.
