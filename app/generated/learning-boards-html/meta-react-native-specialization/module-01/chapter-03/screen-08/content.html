Array destructuring
Bind elements by position. Use defaults for missing items and skip positions with commas.
const arr = [10, 20, 30, 40];
const [first, second] = arr; // 10, 20
const [head, ...tail] = arr; // head=10, tail=[20,30,40]
const [a, , c = 0] = [1]; // a=1, c=0 (default)
Tip
Use rest to capture remaining items into a new array for non-destructive processing.
Function parameters with rest
Rest gathers a variable number of arguments into a real array you can iterate over.
function sum(...numbers) {
  return numbers.reduce((s, n) => s + n, 0);
}

sum(1,2,3); // 6
Misconception
Rest is not the same as spread. Rest collects into a new array; spread expands elements into a context like a literal or function call.
