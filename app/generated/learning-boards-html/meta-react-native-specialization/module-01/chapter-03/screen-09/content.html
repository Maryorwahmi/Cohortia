Module 2 › Chapter 1.3 › Spread Operator
Array patterns
Create new arrays by spreading existing ones. This avoids mutating the original reference.
const oldArray = [1,2];
const newArray = [...oldArray, 3]; // [1,2,3]

// insert at front
const front = [0, ...oldArray];
Key takeaway
Use spread to produce new arrays and avoid in-place operations like push in state updates.
Object merge example
Combine base properties with overrides while creating a new object reference.
const base = {a:1, b:2};
const override = {b:20, c:3};
const merged = { ...base, ...override }; // {a:1,b:20,c:3}

// merging styles
const baseStyle = { padding: 10, backgroundColor: 'white' };
const cardStyle = { ...baseStyle, backgroundColor: '#e0e0e0' };
Common mistake
Thinking spread does a deep clone. For nested objects, create new copies at each nested level instead of relying on a single spread.
