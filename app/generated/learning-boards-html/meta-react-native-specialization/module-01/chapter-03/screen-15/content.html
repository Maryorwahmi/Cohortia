Module 2 › Chapter 1.3 › What to Remember
Spread is shallow
Great for top-level updates, but create copies per nested level when needed.
Rest collects
Use rest in parameters and destructuring to gather remaining items or properties.
Use modules
Organize helpers and components with clear named and default exports for reuse and testing.
Final takeaway

Combine these ES6 tools deliberately: prefer const, use arrow functions for callbacks, destructure for clarity, and apply spread/rest to manage data without mutation. Your React Native code will be cleaner and easier to maintain.
