Process Flow

Refactor Steps

1. Identify
Find repeated inline objects to extract.
2. Extract
Create keys inside StyleSheet.create().
3. Replace
Use styles.key in the style prop.
4. Verify
Run the app and confirm identical visuals and dynamic overrides.
Example merge pattern
Combine static and dynamic styles: style={[styles.baseText, { color: dynamicColor }]} so you keep both reuse and flexibility.
Key Takeaway

Refactor incrementally, verify UI parity, and use style arrays for dynamic values.
