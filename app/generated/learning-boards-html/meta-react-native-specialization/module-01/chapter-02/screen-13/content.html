Hands-on Activity

Build the Profile Card

  1. Create App.js and import React, View, Text, Image, StyleSheet.
  2. Render a View container and add Text inside it to verify setup.
  3. Add an Image with a network uri and explicit width and height.
  4. Add Text for name and title and style them inline.
  5. Refactor repeated inline objects into StyleSheet.create() keys and replace usages.
Challenge: Add a conditional bio: render it only when a bio variable exists. Use style arrays to apply a dynamic color override for emphasis.
Starter checklist
Confirm: Text nodes wrapped in Text
Confirm: Image has width and height
Confirm: Styles extracted to StyleSheet
Key Takeaway

Follow the plan: build, verify, then refactor. Incremental changes reduce errors and teach how JSX and styles interact.
