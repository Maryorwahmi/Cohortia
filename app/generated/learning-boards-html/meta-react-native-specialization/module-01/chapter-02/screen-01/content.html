Components & JSX

Learn the core building blocks — View, Text, Image — and the JSX syntax that wires them together. See how styles are JavaScript objects and when to use StyleSheet.create().

Why this matters
Components let you reuse UI and keep logic isolated. JSX makes your UI readable and maintainable.
Practical example
Build a profile card with an Image, two Texts, and a View container — first with inline styles, then refactor with StyleSheet.

View, Text, Image and how they map to native widgets.
JSX Syntax
How JSX describes UI in JavaScript and how attributes differ from HTML.
Styling
Inline style objects vs StyleSheet.create() for reuse and performance.
View
Container that supports layout, touch handling, and accessibility. Similar to a web div.
Text
All visible text must be wrapped in a Text component; it handles fonts and layout for text nodes.
Image
Displays local or network images. Use style prop for size and border radius.
