StyleSheet.create()

Extract repeated or static style rules into a centralized StyleSheet object for readability and performance.

Why extract styles
  • Reduces duplication and keeps components lean.
  • Helps find and fix typos in one place.
  • Enables style validation and potential native optimizations.
Refactor example
{`import { StyleSheet, Text, View, Image } from 'react-native';

const styles = StyleSheet.create({
  container: { flex: 1, alignItems: 'center', justifyContent: 'center' },
  titleText: { fontSize: 24, fontWeight: 'bold', color: 'purple' },
  paragraphText: { fontSize: 16, color: 'gray', marginTop: 10 },
});

// Usage: Welcome`}
Key Takeaway

Use StyleSheet.create() to centralize static style rules, then apply them via the style prop for cleaner, faster code.
