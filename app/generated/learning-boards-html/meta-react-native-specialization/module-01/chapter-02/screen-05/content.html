Comparison

View vs Text vs Image

View
Layout container, handles Flexbox, touch events, and accessibility. Similar to a web div but native-backed.
Text
Dedicated to displaying text. All visible text must be wrapped in Text components; nesting Text is supported.
Image
Displays images from local or remote sources. Style controls size, border radius, and layout.
Misconception
Styles cascade like web CSS — they do not. Each component's style prop is independent.
Concrete scenario
Name must be in Text
If you accidentally put raw text into a View you will lose text layout control and may see runtime warnings. Always wrap text nodes.
Key Takeaway

Respect component roles: View for layout, Text for text, Image for images. This prevents layout errors and keeps code predictable.
