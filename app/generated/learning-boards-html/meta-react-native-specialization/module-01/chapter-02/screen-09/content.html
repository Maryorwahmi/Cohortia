Profile Card

Follow the chapter's example closely: container View, Image with uri, and Text nodes styled via StyleSheet.

Common pitfall
Image without width/height may not render; Text nodes must be nested inside a Text component.
Starter code (visual)

import { StyleSheet, Text, View, Image } from 'react-native';

const styles = StyleSheet.create({

  profileImage: { width: 120, height: 120, borderRadius: 60 },
  userName: { fontSize: 28, fontWeight: 'bold' },
