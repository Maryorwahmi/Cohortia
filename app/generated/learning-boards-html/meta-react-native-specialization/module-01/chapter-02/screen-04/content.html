Core Concept

What is a Component?

A component encapsulates rendering and optional behavior. It receives props and returns UI. Components enable reuse and clearer code structure.

Why it matters
  • Promotes reuse: update one component and all instances reflect the change.
  • Improves testability: small units are easier to reason about.
  • Encourages composition: build complex UI from simple parts.
Common mistake
Create overly large components that mix unrelated concerns; prefer splitting into focused components.
