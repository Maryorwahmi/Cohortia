Common Mistakes

Debugging checklist

  • Text nodes must be inside Text components; otherwise wrap them correctly.
  • Style prop must receive a JavaScript object or an array of objects, not a CSS string.
  • Image components need explicit width and height, or a constrained parent with percentage sizing.
Use the inspector and small edits to locate the offending node quickly. Confirm prop types and style shapes if something looks off.

Key Takeaway

Small structural errors cause many beginner bugs. Check node types, style shapes, and image dimensions first.
