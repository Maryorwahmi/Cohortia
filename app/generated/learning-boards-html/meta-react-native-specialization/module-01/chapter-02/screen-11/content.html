Architecture

Image handling

Use uri for network images and require for local assets. Always set width and height or constrain via a parent container to ensure predictable rendering.

Best practices
  • Provide explicit dimensions or a constrained parent.
  • Use borderRadius with matching width/height for circles.
  • Use accessibilityLabel for meaningful images.
Tip
Use a placeholder while a network image loads to avoid layout jumps.
