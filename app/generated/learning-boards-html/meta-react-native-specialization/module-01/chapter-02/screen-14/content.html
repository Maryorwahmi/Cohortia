Module 1 › Chapter 1.2 › Key Concepts
Components
Independent, reusable units that encapsulate rendering and behavior.
Core components
Use View for layout, Text for all visible text, and Image for images.
Styling
Pass JavaScript objects to style; prefer StyleSheet.create() for repeated styles.
Summary Takeaway

Apply small, focused components, use the right core components, and centralize styles to build maintainable React Native apps.
