Definition

Inline Styles

Pass a JavaScript object to the style prop. Outer braces mark a JavaScript expression; inner braces form the object literal.

Best uses
  • Quick one-off adjustments while prototyping.
  • Dynamic styles based on props or state.
  • Small conditional variations that are local to a component.
Common error
Using CSS strings like "background-color: red" instead of an object with backgroundColor: 'red'.

// dynamic example
Resizable text`}
Inline styles update immediately when the underlying JavaScript values change. For repeated patterns, extract style objects into a StyleSheet for clarity and performance.
Pro Tip

Use inline styles for dynamic values, then move static repeated rules into StyleSheet.create().
