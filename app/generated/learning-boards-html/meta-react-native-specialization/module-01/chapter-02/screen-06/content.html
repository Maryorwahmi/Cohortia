Definition

JSX

A JavaScript syntax extension that represents UI structure. It reads like HTML, but it compiles to JavaScript calls that create elements and pass props.

Important rules
  • Use curly braces to evaluate JavaScript inside JSX.
  • Self-closing tags are allowed for elements without children.
  • Keep statements out of JSX; use expressions or helper functions instead.
Misconception
JSX runs in the browser the same way HTML does — it does not. It is compiled into JavaScript before execution.
Concrete example
{`// JSX snippet (visual only)

  {userName}
  {userRole ? {userRole} : null}
  
`}
Notice the braces used to insert variables and to evaluate a conditional expression. Style is passed as an object, not a CSS string.
Key Takeaway

Use JSX to declaratively express UI; keep logic in JavaScript expressions and pass styles as objects.
