Module 6 › Chapter 6.2 › Objectives — Practical

How these objectives look in practice

Setup

One shared setup file imports jest-native/extend-expect so matchers like toBeOnTheScreen are globally available.

Unit

Assert visible output from props for presentational components to keep tests resilient to refactors.

Integration

Simulate button presses and check that state changes are reflected in rendered text.

Mocking

Replace API modules with jest.mock and control resolved and rejected values for predictable flows.

VERIFIED COMPETENCY MILESTONE

Run a test suite that includes a unit test, an interaction test, and a mocked API test, and observe all tests pass deterministically.
