Mock pattern
// mock the service
jest.mock('../../services/api', () => ({
  fetchUsers: jest.fn(),
}));

// in a test
(apiService.fetchUsers as jest.Mock).mockResolvedValueOnce(mockUsers);
This replaces the real fetchUsers with a Jest mock you control for the duration of the test. Use mockResolvedValueOnce and mockRejectedValueOnce to vary responses per test.
Best practices
  • Mock external modules only, not the module under test.
  • Clear mocks in beforeEach with jest.clearAllMocks().
  • Use mockResolvedValueOnce for per-test variations.
Misconception

Over-mocking can hide integration issues. Balance with tests that use the real implementation where appropriate.
