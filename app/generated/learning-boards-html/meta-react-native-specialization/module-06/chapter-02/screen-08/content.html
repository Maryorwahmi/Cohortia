Module 6 › Chapter 6.2 › fireEvent
Common events
  • fireEvent.press(element) — simulate tap or press
  • fireEvent.changeText(element, 'value') — input text changes
  • fireEvent.scroll(list, { y: 100 }) — simulate scroll
Example
const button = screen.getByText('Login');
fireEvent.press(button);
await waitFor(() => expect(mockOnPress).toHaveBeenCalled());
Practical tips
Sequence events
Test realistic sequences: enter text, press, then assert resulting UI.
Async handlers
If handlers are async, use waitFor to observe state changes after the promise resolves.
Key Takeaway

Simulate the ways users interact and wait for async changes to assert the final UI state.
