Unit & Integration Testing with Jest & RTL

This module focuses on writing tests that assert what users see and do. We emphasize setup, common queries, event simulation, asynchronous assertions, and mocking external modules.

In this lesson
Configure Jest and RNTL, write unit and integration tests, and mock async dependencies.
Coming up
Examples for Greeting, Counter, UserList, and LoginButton with concrete tests and common pitfalls.
Explore Key Topics
Setup
Install RNTL and jest-native and configure setupFilesAfterEnv.
Queries & Events
Use getByText, getByTestId, fireEvent, and waitFor for assertions.
Mocking
Use jest.mock and jest.fn to replace API calls and control outcomes.
Visual Concept
Render
render(component) mounts a component for assertions.
Events
fireEvent simulates user interactions such as presses and text changes.
Async
waitFor waits for UI updates after promises or timeouts.
Mock
jest.mock replaces modules so tests are deterministic and fast.
