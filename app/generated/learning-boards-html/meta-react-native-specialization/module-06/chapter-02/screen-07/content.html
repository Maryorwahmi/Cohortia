Module 6 › Chapter 6.2 › Queries & Matchers
When to use
getByText
Best for visible text assertions that reflect user experience.
getByTestId
Use when elements lack accessible text or in complex lists, sparingly.
Matchers
toBeOnTheScreen, toHaveTextContent, toBeDisabled are useful for clear assertions.
Example contrasts
Good
expect(screen.getByText('Hello, Alice!')).toBeOnTheScreen()
When to use testID
expect(screen.getByTestId('loading-spinner')).toBeOnTheScreen()
Misconception

Using test IDs everywhere makes tests pass even when the UI visible content is broken.
