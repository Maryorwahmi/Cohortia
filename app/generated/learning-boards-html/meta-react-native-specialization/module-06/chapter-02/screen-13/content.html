Resetting mocks

Use jest.clearAllMocks in beforeEach to remove call history and ensure predictable behavior across tests.

describe('suite', () => {
  beforeEach(() => {
    jest.clearAllMocks();
  });

  it('test A', () => { /* mock and test */ });
  it('test B', () => { /* different mock and test */ });
});
Why
Avoid test pollution and flakiness by ensuring each test’s mock state is independent.
Pitfall
Not clearing mocks can cause subtle cross-test dependencies and intermittent failures.
Key Takeaway

Reset mocks between tests to keep suites reliable and easier to debug.
