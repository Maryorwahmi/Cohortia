Common mistakes and fixes

Brittle assertions
Fix: Assert visible text and behavior, not internal variables.
Missing waitFor
Fix: Use waitFor for assertions that depend on promised results or timers.
Over-mocking
Fix: Mock external services but keep integration tests for real flows.
Test pollution
Fix: Clear mocks in beforeEach to isolate tests.
Final thought

Write tests for behavior, keep them deterministic with mocks, and ensure they reflect real user interactions.
