Integration tests explained
Test how units work together—especially network to UI transitions.
Example
Mock an API response and assert the component switches from a loading indicator to a populated list view.
Mistake to avoid
Leaving real network calls in tests produces slow, flaky outcomes.
Practical tip: Use react-native-testing-library queries to assert on visible text or accessibility roles instead of internals.
Scenario card
A ProfileList component calls an API and renders items. Stub the API to return 3 users and assert that three list rows appear and a loading spinner disappears.
Key Takeaway

Integration tests validate interactions. Mock heavy dependencies and assert on the visible UI that the user observes.
