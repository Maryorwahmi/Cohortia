Module 6 › Chapter 6.1 › End-to-End Testing
When to use E2E
Select E2E for full journeys that must work for real users across devices.
Example
A login-to-dashboard flow that includes navigation and a network-backed dashboard render.
Pitfall
Relying on fragile selectors or running too many E2E tests that slow the CI pipeline.
Best practice: Keep a small set of E2E tests for the highest-value flows and maintain them deliberately.
Scenario card
Test a purchase flow from product selection through checkout to a confirmation screen using a stable test backend or mocked payment gateway.
Key Takeaway

E2E tests are your final safety net. Use them judiciously for the highest-risk flows while preserving fast feedback with unit and integration tests.
