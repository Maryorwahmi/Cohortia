Module 6 › Chapter 6.1 › Setup Walkthrough
Install commands
npm install --save-dev @testing-library/react-native jest-react-native @testing-library/jest-native
Add a setup-tests.js that imports '@testing-library/jest-native/extend-expect' and include it in Jest's setupFilesAfterEnv.
Example test file
// __tests__/App.test.tsx
import React from 'react';
import { render, screen } from '@testing-library/react-native';
import App from '../App';

describe('App', () => {
  it('renders correctly', () => {
    render(<App />);
    expect(screen.getByText('Welcome to React Native!')).toBeOnTheScreen();
  });
});
Note: Adjust the expected text based on your App's actual content. Mock network modules to keep the test deterministic.
