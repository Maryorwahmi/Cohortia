Module 6 › Chapter 6.1 › Mocking
Why mock?
Mocks keep tests deterministic and fast by removing external variability.
Mock network requests to avoid flaky responses.
Mock device APIs like storage, camera, or geolocation.
Mock third-party modules that start heavy native processes.
Balance: Mock what you cannot control, but test realistic behavior within your module boundaries.
Example mock
// jest.mock('api');
// api.getUsers = jest.fn().mockResolvedValue([{ id: 1, name: 'Alice' }]);
Key Takeaway

Use mocks to isolate behavior and maintain fast test suites, but avoid hiding realistic integration issues by mocking too much.
