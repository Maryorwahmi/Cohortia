Test like a user
Use RNTL queries to focus on visible behavior and accessibility roles.
  • Prefer getByText, getByRole, getByPlaceholderText for stable queries.
  • Simulate actions with fireEvent rather than manually calling internals.
  • Avoid asserting on component internals or implementation details.
Example: If a button label reads 'Submit', use getByText('Submit') instead of relying on a testID tied to a specific element type.
Concrete example
Simulate a press on a login button and assert that an error message appears when the mocked API returns a 401 response.
Key Takeaway

RNTL makes your tests reflect user interactions and helps them survive component refactors.
