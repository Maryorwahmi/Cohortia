Module 5 › Chapter 5.3 › Scheduling Local Notifications
Set notification handler
Notifications.setNotificationHandler({
  handleNotification: async () => ({
    shouldShowAlert: true,
    shouldPlaySound: false,
    shouldSetBadge: false,
  }),
})
Schedule example
await Notifications.scheduleNotificationAsync({
  content: {
    title: "You've got mail! 📬",
    body: 'Here is the notification body',
    data: { someData: 'goes here' },
  },
  trigger: { seconds: 2 },
})
Tip: Keep notification bodies short and include a small data payload for secure fetch after the app opens.
Example scenario
User sets a reminder message and delay. After confirming permission, call scheduleNotificationAsync to show the reminder at the requested time.
Key Takeaway
Use scheduleNotificationAsync for local reminders and setNotificationHandler to control foreground presentation.
