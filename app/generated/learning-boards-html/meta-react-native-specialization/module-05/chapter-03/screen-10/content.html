Module 5 › Chapter 5.3 › Android Notification Channels
Create a channel example
await Notifications.setNotificationChannelAsync('reminders', {
  name: 'Reminders',
  importance: Notifications.AndroidImportance.MAX,
  vibrationPattern: [0, 250, 250, 250],
  lightColor: '#FF231F7C',
})
Channels should be created before sending any notification that targets them, typically at app start or onboarding.
Why channels matter
They provide user control and consistency across devices. Without proper channels, users may not receive alerts as you intended.
Key Takeaway
On Android, always register meaningful channels so users can control notification behavior per category.
