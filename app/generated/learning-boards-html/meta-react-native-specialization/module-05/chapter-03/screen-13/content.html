Module 5 › Chapter 5.3 › Common Mistakes and Troubleshooting
Top issues and quick fixes
  • Permission checks omitted: always call getPermissionsAsync first.
  • Testing only on simulator: use physical devices for tokens and delivery tests.
  • Token stale or invalid: update tokens on app start and remove failed tokens server-side.
  • Wrong payload format: follow push service API specs to avoid rejections.
  • Android channels not created: register channels to control behavior and visibility.
Diagnostic flow
Check permission → Confirm client returns token → Verify token exists on backend → Inspect push service response → Test on target device.
Warning
Avoid notification spam. Irrelevant or frequent notifications lead users to disable or uninstall your app.
