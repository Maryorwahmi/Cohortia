Module 5 › Chapter 5.3 › Listening for Notifications and User Response
Listener example
// notification received while app is foregrounded
notificationListener.current = Notifications.addNotificationReceivedListener(notification => {
  setNotification(notification)
})

// notification tapped by user
responseListener.current = Notifications.addNotificationResponseReceivedListener(response => {
  // use response.notification.request.content.data to deep-link
})
Remember to store subscriptions in refs and remove them in cleanup to prevent duplicate handlers.
Handling app launch from notification
If the app is started by a notification tap, check the initial notification or response to route the user to the appropriate screen once.
Common Mistake
Not removing listeners on unmount, causing multiple triggers over time. Always clean up subscriptions.
