Concept Map
Interactive 16:9 Masterclass
Local Notification — scheduled on device. Good for reminders, alarms. No server required.
Remote Notification — sent from backend through APNS/FCM/Expo service. Used for broadcast and server-timed events.
Device Token — unique identifier your backend uses to target a device. Keep tokens updated and secure.
