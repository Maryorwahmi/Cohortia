Module 5 › Chapter 5.3 › Key Concepts
Local Notifications
Scheduled on device; ideal for reminders without a backend.
Remote Notifications
Sent via APNS/FCM/Expo by a server to many devices.
Device Tokens
Unique identifiers used by your backend to address devices; manage lifecycle carefully.
Takeaway
Use local scheduling for client timers, remote pushes for server-driven events, always check permissions, and keep tokens secure and up-to-date.
