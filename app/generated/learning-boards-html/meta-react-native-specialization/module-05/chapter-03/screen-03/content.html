Verification Tasks
Schedule a local reminder
Use scheduleNotificationAsync and confirm the notification appears on a physical device.
Retrieve and POST token
Call getExpoPushTokenAsync and send it to a backend endpoint to be stored for sending remote messages.
Respond to notification taps
Implement addNotificationResponseReceivedListener to deep-link or show relevant content when tapped.
Quick reminders
Test on a real device. Simulators have limitations. On Android, set up channels. On iOS bare projects, enable Push Notifications capability in Xcode.
Common mistake: Not checking getPermissionsAsync before scheduling. This causes silent failures.
Privacy note: Avoid sending sensitive data inside notification bodies; use data payloads to fetch secure content after the app opens.
