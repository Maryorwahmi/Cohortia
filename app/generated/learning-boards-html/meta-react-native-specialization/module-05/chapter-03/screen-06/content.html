Module 5 › Chapter 5.3 › Device Tokens and What They Mean
What is a device token?
A token is a service-issued identifier for a device and app installation that your backend uses to target notifications.
• Expo Push Token: returned by getExpoPushTokenAsync in managed Expo projects.
• FCM Token: used in bare React Native projects integrating Firebase Cloud Messaging.
• APNS Token: the platform-level token used on iOS behind the scenes.
Practical: after obtaining the token, send it to your backend with the user id. Keep a mapping so you can target devices for remote notifications.
Server-side considerations
Store tokens securely, track their created_at and last_seen, and implement logic to remove tokens that become invalid or return errors from the push service.
Misconception: tokens never change. In reality, tokens can and will change; plan to re-register and update server records when the app restarts or after reinstall.
Key Takeaway
Treat tokens as device addresses. Send them to your server, keep them current, and remove invalid tokens to maintain delivery quality.
