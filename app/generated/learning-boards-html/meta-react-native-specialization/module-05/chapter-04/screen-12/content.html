Module 5 › Chapter 5.4 › Offset management and state mistakes
Problem
Jumps occur when offsets are not applied after a gesture ends.
Symptoms
After dragging and releasing, the next drag starts from the original coordinate and the element snaps or jumps.
Cause
Not updating Animated.Value's offset via setOffset and not resetting the base value to zero for the next gesture.
Solution
Add translation to lastOffset, call setOffset(lastOffset) and then setValue(0). For dismissals, animate off-screen and then reset offsets or remove the item from state.
Key Takeaway

Proper offset handling ensures continuous interactions and avoids surprising jumps during repeated gestures.
