Module 5 › Chapter 5.4 › Draggable box with PanGestureHandler
Code
import React, { useRef } from 'react';
import { Animated, View, Text } from 'react-native';
import { PanGestureHandler, State } from 'react-native-gesture-handler';

export default function DraggableBox() {
  const translateX = useRef(new Animated.Value(0)).current;
  const translateY = useRef(new Animated.Value(0)).current;
  const lastOffset = useRef({ x: 0, y: 0 }).current;

  const onGestureEvent = Animated.event([
    { nativeEvent: { translationX: translateX, translationY: translateY } }
  ], { useNativeDriver: true });

  const onHandlerStateChange = event => {
    if (event.nativeEvent.oldState === State.ACTIVE) {
      lastOffset.x += event.nativeEvent.translationX;
      lastOffset.y += event.nativeEvent.translationY;
      translateX.setOffset(lastOffset.x);
      translateY.setOffset(lastOffset.y);
      translateX.setValue(0);
      translateY.setValue(0);
    }
  };

  return null; // UI omitted for brevity
}
Explanation
  • Use Animated.event to map native gesture translations directly into Animated.Values for continuous updates.
  • When the gesture ends, accumulate translation into lastOffset and apply it with setOffset to preserve visual position.
  • Reset the animated value to zero after setting the offset so subsequent gestures start from the right baseline.
  • Consider velocity for fling behavior or Animated.decay for momentum after release.
Common mistake
Not calling setOffset and setValue causes the element to snap back because the next gesture starts from an unadjusted baseline.
Key Takeaway

Preserve the final position using offsets so dragging feels continuous across multiple interactions.
