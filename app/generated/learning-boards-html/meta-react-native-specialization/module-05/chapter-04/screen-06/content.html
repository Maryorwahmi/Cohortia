Process Flow

Pick the right primitive

Timing
Deterministic duration-based changes. Good for fades and controlled panel moves.
Spring
Simulates physics for bouncy and natural returns.
Decay
Momentum-based slowing, useful after flings.
Composition patterns
  • Sequence: run fade out, then slide off-screen.
  • Parallel: animate opacity and translate at the same time for combined effects.
  • Decision flow: on gesture end choose dismiss sequence or snap-back spring based on threshold and velocity.
Concrete example
After a drag ends, if the card crosses a threshold run a parallel dismiss: opacity to 0 and translate off-screen. Otherwise spring it back to zero.
Key Takeaway

Compose primitives to match interaction intent: timing for control, spring for physics, decay for momentum.
