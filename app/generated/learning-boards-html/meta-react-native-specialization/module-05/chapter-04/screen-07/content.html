Module 5 › Chapter 5.4 › useNativeDriver: benefits and limits
Comparison
Supported (useNativeDriver works)
  • opacity
  • transform: translate, scale, rotate
Unsupported
  • width / height
  • margin / padding
  • backgroundColor
Practical rule

When you need layout changes, update state and let the layout settle, then animate a transform or opacity overlay for the motion portion. Keep heavy visual updates off the JS thread when possible.

Example
If you want a view to slide off-screen, animate translateX with useNativeDriver: true. If you must animate width, perform the width change via layout and then animate an overlaid transform for the visible motion.
Common mistake
Expecting color or layout properties to animate with useNativeDriver turned on will lead to confusion; always verify property support.
Key Takeaway

Prefer transforms and opacity for native-driven smoothness. Use layout updates for structural changes and overlay transforms for motion.
