Learning Objectives

Learn, understand, apply, and master animation and gesture patterns.

Bloom: Learn → Understand → Apply → Master
01
Understand motion principles

Explain why animations guide attention and when to prefer subtle feedback over flashy motion. Good motion improves clarity and reduces cognitive load.

Venn: clarity + delight
VERIFIED COMPETENCY MILESTONE
02
Utilize Animated API

Create Animated.Value instances and drive them with timing, spring, or decay functions to animate opacity, transform, and position.

Mnemonic: Value → Drive → Render
VERIFIED COMPETENCY MILESTONE
03
Implement gestures

Use react-native-gesture-handler components to detect pan, pinch, and tap gestures and map event values into Animated values.

Timeline: install → wrap → handle
VERIFIED COMPETENCY MILESTONE
04
Compose animations and gestures

Combine sequence and parallel functions and feed gesture events into animated flows for interactive components like swipe cards.

Mnemonic: Sequence + Parallel
VERIFIED COMPETENCY MILESTONE
