Module 5 › Chapter 5.4 › Gesture handler setup and root wrapper
Architecture
Required root wrapper and handler components
GestureHandlerRootView
Wrap your app root to enable native recognizers and prevent conflicts with navigation gestures.
PanGestureHandler
Detects panning with translation and velocity properties used to update Animated values.
Pinch & Tap handlers
PinchGestureHandler provides scale; TapGestureHandler detects nuanced touch patterns.
Example setup
In App.js wrap your root: import GestureHandlerRootView and return it as the outermost view, then use PanGestureHandler around the component you want to drag.
Common mistake
Not wrapping the app root leads to handlers that do not intercept touch events reliably, causing missed gestures or conflicts.
Key Takeaway

GestureHandlerRootView is required. Use specialized handlers around interactive components and map gesture events into Animated values for smooth visuals.
