Module 5 › Chapter 5.2 › Requesting Permissions
Platform requirements
  • iOS: add NSLocationWhenInUseUsageDescription and any needed background keys to Info.plist with clear text.
  • Android: declare ACCESS_FINE_LOCATION and ACCESS_COARSE_LOCATION in AndroidManifest.xml.
Runtime API (expo-location)
Use requestForegroundPermissionsAsync to prompt the user. Background requests require requestBackgroundPermissionsAsync and additional justification.
Process checklist
  1. Prepare your Info.plist/AndroidManifest with descriptive text.
  2. Show a short in-app explanation before prompting.
  3. Call expo-location request method and handle denied status gracefully.
  4. If denied, offer guidance to open system settings rather than repeatedly prompting.
Common mistake
Skipping descriptive Info.plist entries leads to silent failures on iOS even after user consent appears granted.
