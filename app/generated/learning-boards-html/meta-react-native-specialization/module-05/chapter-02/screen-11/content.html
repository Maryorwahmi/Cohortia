Module 5 › Chapter 5.2 › Debugging
iOS configuration
Ensure NSLocationWhenInUseUsageDescription and other required keys have clear text in Info.plist.
Android configuration
Declare ACCESS_FINE_LOCATION and ACCESS_COARSE_LOCATION in AndroidManifest.xml and test runtime prompts.
Emulator testing
Enable a simulated location feed or test on a real device to confirm coordinates are returned as expected.
Data checks
Inspect accuracy, timestamp, and whether coords are null. Indoor readings are often coarse or stale.
Performance
Avoid re-rendering MapView on each update; batch marker updates and debounce region changes.
Permissions logic
Always check the returned permission status property; do not assume requests always succeed.
