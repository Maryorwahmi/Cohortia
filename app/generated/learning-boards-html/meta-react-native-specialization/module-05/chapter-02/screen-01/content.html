Module 5 › Chapter 5.2 › Overview
Working with Geolocation and Maps
Request permissions, capture location, and show it on an interactive map.
In this lesson

You will learn how to request and check permissions, fetch a one-time location, optionally subscribe to updates, and render a MapView with markers.

Focus areas
  • Platform permission configuration for iOS and Android
  • expo-location methods and accuracy trade-offs
  • MapView setup and marker handling
Explore Key Topics
Permissions
Platform keys and explicit descriptions are required to access location data.
Location APIs
expo-location gives getCurrentPositionAsync and watchPositionAsync for one-time or continuous data.
Maps & Markers
react-native-maps provides MapView and Marker for interactive maps and pins.
Concept snapshot
A device requests permission, obtains coordinates from the OS, and passes them to a MapView to center and place markers.
Device
GPS + OS location services provide coordinates.
Library
expo-location or native SDK returns a LocationObject with latitude and longitude.
Interactive map + location
This presentation is code-first and hands-on. You will build a Local Business Finder that centers on the user and shows static markers.
