Accuracy vs Battery
Set Location options mindfully. High accuracy consumes more power and may delay results, while low accuracy is faster and cheaper.
Visual mnemonic: slider between Accuracy and Battery.
Permission messaging
Explain why you need location, what is collected, and how long you keep it. Good descriptions reduce denials and app-store issues.
Background tracking
Request background permissions only if essential. Background tracking requires additional OS justification and strong user controls.
Debugging checks
If location fails on iOS, verify Info.plist keys are present. On Android ensure manifest entries exist and the device/emulator has location services enabled.
