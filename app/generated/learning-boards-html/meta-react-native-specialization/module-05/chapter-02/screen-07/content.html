When to use continuous tracking
Live navigation, fitness tracking, or real-time delivery tracking are valid uses. Avoid continuous updates for simple location-aware displays.
Best practices
  • Provide explicit start/stop controls for tracking.
  • Allow the user to select lower accuracy modes to extend battery life.
  • Debounce UI updates and batch writes to storage or network.
Subscription lifecycle
Start the subscription when tracking begins, and always remove it when done to avoid continuous background drain.
Pro tip
Show a clear status indicator when tracking is active so users know data collection is ongoing.
Misconception
Assuming continuous tracking is cheap. High frequency and high accuracy combine to consume substantial battery power.
Key Takeaway

Only subscribe for continuous updates when the app needs them, and always provide clear controls and status to the user.
