Module 5 › Chapter 5.1 › Image-pick workflow
Step-by-step
  1. Check current permission status.
  2. If needed, request permission with the correct function for camera or gallery.
  3. Launch camera or library with options like aspect and quality.
  4. When resolved, check result.canceled before using assets.
  5. Display the image or convert to FormData for upload.
Options to consider
  • allowsEditing: let the user crop or edit.
  • aspect: enforce ratio such as [1,1] for avatars.
  • quality: lower values reduce upload size.
Key Takeaway

Design your flow so cancelled operations and denied permissions never cause unhandled errors.
