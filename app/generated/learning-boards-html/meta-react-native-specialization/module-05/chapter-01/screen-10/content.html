Module 5 › Chapter 5.1 › Camera vs Gallery
When to use camera

For capturing new content now: selfies, document scans, or moment-based photos.

Example

"Take Photo" button opens the camera and requests camera permission before launching.

When to use gallery

For selecting previously taken photos or images saved on the device.

Example

"Choose from Gallery" opens the image library and requests media permissions when needed.

Editing options

Consider allowsEditing and aspect options to guide user cropping. Editing UIs vary by platform; test behavior on both iOS and Android.
