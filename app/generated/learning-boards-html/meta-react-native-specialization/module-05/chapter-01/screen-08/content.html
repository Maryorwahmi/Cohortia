Module 5 › Chapter 5.1 › Result object
Key fields
  • canceled: boolean indicating user cancellation.
  • assets: array of selected assets, each with uri, width, height, and optional base64.
Common pitfall

Accessing result.assets[0] without checking canceled leads to undefined errors when the user cancels.

URI considerations

URIs are local file references. To upload, place the file into FormData or read the file contents using a file-system API if needed.

Example

After successful pick: setSelectedImage(result.assets[0].uri) and render with Image source={{ uri: selectedUri }}.
