Module 5 › Chapter 5.1 › Accessing Device Camera and Gallery
What you'll master

Gain working knowledge of permission flows, the expo-image-picker API, and practical patterns to display and upload images from a React Native app.

In this lesson

Permission requests, camera vs gallery flows, result handling, and preparing images for network upload.

Why it matters

Images are common user content. Handling them correctly improves UX, avoids crashes, and protects user privacy.

Common pitfall

Missing iOS privacy keys or ignoring the canceled state causes platform-specific failures and silent errors.

Key Takeaway

Always request permissions, check the canceled flag, and treat the returned URI as a local file that may need conversion before upload.
