Module 5 › Chapter 5.1 › expo-image-picker vs native
Expo workflow

Install with npx expo install expo-image-picker and call the request and launch functions from JavaScript. Returns a result object with assets and URIs.

Pros
  • Unified API
  • Less native setup in Expo
  • Structured result object
Bare React Native

Libraries like react-native-image-picker work well but need more native configuration and linking. Use them if you are not on Expo.

When to choose

Choose expo-image-picker for speed in Expo projects; choose native libraries when you need deeper native control.

Practical example

Call requestMediaLibraryPermissionsAsync, then launchImageLibraryAsync with options such as allowsEditing, aspect, and quality. Check result.canceled before using result.assets[0].uri.
