Module 5 › Chapter 5.1 › Profile Picture Uploader
Starter checklist
  1. Run npx expo install expo-image-picker.
  2. Copy the starter component into App.js or a new file.
  3. Implement permission requests and handle denied status with alerts.
  4. Use aspect [1,1] and quality 0.7 for profile uploads.
  5. Display the selected image in a circular Image component.
  6. Package the image into FormData with uri, name, and type to upload.

await ImagePicker.launchCameraAsync({ allowsEditing: true, aspect: [1,1], quality: 0.7 })
if (!result.canceled) setProfileImage(result.assets[0].uri)

Success check
