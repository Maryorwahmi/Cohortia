Module 5 › Chapter 5.1 › Why permissions matter
Definition

Permission is the explicit consent required by the operating system to access the camera or media library. It is enforced at runtime and often requires platform-specific configuration.

Concrete example

If a user taps "Set profile photo", you request camera permission. If denied, show an alert explaining why and offer to open settings.

Common misconception

Assuming permissions are granted by default will cause silent failures or crashes, especially on iOS without Info.plist entries.

Pro tip

Explain the reason for the permission in user-facing text, not only in the manifest, so users are more likely to grant it.

Platform notes
  • iOS: add NSCameraUsageDescription and NSPhotoLibraryUsageDescription to Info.plist with a user-facing reason.
  • Android: ensure camera and read storage permissions are declared and test on real devices or emulators.
Check flow
  1. Check current permission status.
  2. If not granted, call the request function.
  3. If granted, open camera or gallery. If denied, show guidance.
