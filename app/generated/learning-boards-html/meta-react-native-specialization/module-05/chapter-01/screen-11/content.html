Module 5 › Chapter 5.1 › State & Lifecycle
State patterns
  • Keep selected image URI in state as a string reference.
  • For galleries, store an array of asset objects.
  • Avoid storing large binary blobs in React state.
Lifecycle safety

Use a mounted flag to avoid setState after unmount when async permission or picker calls complete.

UX tip

Show a placeholder or spinner while image is being processed to communicate work in progress.

Example

Keep profileImageUri in state, render a circular Image when present, and upload only after the user confirms to avoid unexpected network calls.
