Module 5 › Chapter 5.1 › Preparing for upload
FormData pattern
{`const formData = new FormData();
formData.append('image', {
  uri: imageUri,
  name: 'photo.jpg',
  type: 'image/jpeg',
});

const response = await fetch('YOUR_UPLOAD_URL', {
  method: 'POST',
  body: formData,
});`}
Practical notes
  • Include a sensible file name and MIME type when appending.
  • Let fetch/axios handle the multipart boundary header.
  • Consider resizing before upload to save bandwidth.
Pitfall

Sending raw uri string instead of FormData typically fails server-side file handling.
