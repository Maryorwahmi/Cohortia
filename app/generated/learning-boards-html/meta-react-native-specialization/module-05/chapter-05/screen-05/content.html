Module 6 › Chapter 5.5 › How Bridging Works
Bridge process
Step-by-step flow that keeps the UI responsive
  1. JS sends async call: JavaScript invokes a native method via NativeModules.
  2. Bridge queues message: The call traverses the bridge as an asynchronous message.
  3. Native executes: Native code runs the requested work on an appropriate native thread.
  4. Return or event: Native resolves via callback, promise resolution, or emits an event back to JS.
Misconception
Assuming native calls are synchronous. Always treat them as asynchronous and design your code around callbacks or promises.
Threading rules
  • • Android UI changes must run on the main thread; use runOnUiThread.
  • • iOS UI updates must be dispatched to the main queue using dispatch_async(dispatch_get_main_queue(), ...).
  • • Long computations belong on background threads; return results with promises or callbacks.
Check your understanding
If a native method takes several seconds, how will you structure it so the UI does not freeze? Answer: perform work on a background thread and resolve a promise or callback when complete.
