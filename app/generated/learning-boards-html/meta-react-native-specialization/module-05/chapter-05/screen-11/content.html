Module 6 › Chapter 5.5 › Common Mistakes & Safety
Common mistakes
  • • Running long computations on the main thread (Android ANR).
  • • Updating UI from a background thread instead of the main/UI thread.
  • • Forgetting to register the package or export the module macros.
  • • Leaving promises unresolved or not handling error paths.
Safety notes
  • • Crashes in native code crash your app; add robust error handling and tests.
  • • Watch memory management on iOS to avoid leaks in Objective‑C code.
  • • Check permissions and security when accessing sensitive device features.
  • • Test on real devices and monitor Logcat or Xcode console output during development.
Debugging checklist
Confirm package registration
Verify module name matches getName or RCT_EXPORT_MODULE
Rebuild native app after changes
