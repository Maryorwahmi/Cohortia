Module 6 › Chapter 5.5 › Testing & Debugging
Run and observe
Commands and consoles to verify native behavior
  • • Rebuild Android: use your normal development command such as npx react-native run-android or your preferred build flow.
  • • Rebuild iOS: run through Xcode or your CLI workflow to ensure files are compiled into the app.
  • • Inspect Android Studio Logcat and the Xcode console to find native log output and startup errors.
Testing tips
  • • Test on physical devices when possible, especially for hardware and permission behavior.
  • • Add defensive error handling in native code and return informative errors to JS consumers.
  • • Use logs to confirm arguments and flow, and remove or lower log verbosity for production builds.
If a native method causes a crash, isolate it with targeted tests and validate thread usage and memory management before reintroducing it to your main app.
Key takeaway
Rebuild, log, and test on devices. Good logging and small, well-tested native APIs reduce risk and debugging time.
