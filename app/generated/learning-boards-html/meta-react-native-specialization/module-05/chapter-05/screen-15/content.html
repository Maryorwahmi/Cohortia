Module 6 › Chapter 5.5 › What to Remember
Android annotations
Extend ReactContextBaseJavaModule and use @ReactMethod to expose functions to JS.
iOS macros
Use RCT_EXPORT_MODULE and RCT_EXPORT_METHOD to make Objective‑C methods available to JavaScript.
Threading rules
Run UI code on the main thread: runOnUiThread on Android and dispatch_async on iOS.
Final note: Keep native modules minimal, asynchronous, and well-logged. Rebuild and test on devices to ensure safe, stable integrations.
