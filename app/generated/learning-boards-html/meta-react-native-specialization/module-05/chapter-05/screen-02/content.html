Learning Objectives
Learn the practical skills to create, register, and safely call native modules.
01
When to use native modules
Decide when a platform API or performance need justifies native code. This prevents unnecessary complexity and improves maintainability.
VERIFIED COMPETENCY MILESTONE
02
Explain bridging
Describe how calls traverse an asynchronous bridge between JavaScript and native threads and why the bridge keeps UI responsive.
VERIFIED COMPETENCY MILESTONE
03
Create Android module
Implement a ReactContextBaseJavaModule, expose methods with @ReactMethod, and register it via a ReactPackage.
VERIFIED COMPETENCY MILESTONE
04
Create iOS module
Use RCTBridgeModule, RCT_EXPORT_MODULE, and RCT_EXPORT_METHOD to expose Objective‑C methods and dispatch UI code to the main queue.
VERIFIED COMPETENCY MILESTONE
