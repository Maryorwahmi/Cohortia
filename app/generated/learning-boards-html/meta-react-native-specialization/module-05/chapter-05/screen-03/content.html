Module 6 › Chapter 5.5 › Learning Objectives
Practice & Integration
These objectives focus on applying your knowledge across code, registration, and testing.
01
Call native functions
Use NativeModules to access exported native methods and handle results with callbacks or promises in JavaScript.
VERIFIED COMPETENCY MILESTONE
02
Register and rebuild
Add your package on Android, ensure RCT_EXPORT_MODULE on iOS, and rebuild so the native code is bridged to JavaScript.
VERIFIED COMPETENCY MILESTONE
03
CustomLogger activity
Implement logMessage to print to Logcat or Xcode console and call it from JavaScript to verify output.
VERIFIED COMPETENCY MILESTONE
04
Safety and testing
Check threading, memory, and permissions. Crashes in native code will crash the app, so add error handling and test on devices.
VERIFIED COMPETENCY MILESTONE
