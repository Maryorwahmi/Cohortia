NativeModules usage example
import React from 'react';
import { Button, View, StyleSheet, NativeModules, Platform, Text, Alert } from 'react-native';

const ToastExample = NativeModules.ToastExample;

export default function NativeModuleComponent() {
  const showNativeToast = () => {
    if (ToastExample) {
      const duration = Platform.OS === 'android' ? ToastExample.SHORT : ToastExample.DURATION_SHORT;
      ToastExample.show('Hello from Native!', duration);
    } else {
      Alert.alert('Error', 'Native Toast module not found. Are you running on a device/emulator with native code?');
    }
  };

  return (
    
      Native Module Integration
      This triggers a platform-specific native UI element.
    
  );
}
Important patterns
  • • Check module presence: NativeModules.ModuleName may be undefined in non-native contexts.
  • • Choose constants by Platform.OS for platform-specific values.
  • • Use Alert or graceful fallback when native modules are unavailable.
  • • For returned results, prefer promises and async/await in JS.
Scenario: call show from a debug screen to confirm the native module is registered and observe Toast on Android or Alert on iOS.
Key takeaway
Always validate module availability and design JS to handle async native results; rebuild the app after native code changes.
