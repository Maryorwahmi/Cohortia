Collecting Key Metrics

Quantitative Measurements for Performance and Health

What are Metrics?

Metrics are quantitative measurements collected over time, providing numerical data about the performance, health, and resource utilization of your infrastructure.

  • Essential for tracking trends and baselines.
  • Help identify deviations from normal behavior.
  • Crucial for capacity planning and optimization.
Key Takeaway

Metrics provide the measurable data points that form the backbone of any effective monitoring system, allowing for objective assessment of system health and performance.

Common Metric Examples

  • CPU Utilization: Percentage of processor time in use.
  • Memory Usage: Amount of RAM consumed by processes.
  • Network Bandwidth: Data throughput on interfaces (e.g., Mbps).
  • Interface Error Rates: Number of errors on network ports.
  • Temperature: Environmental conditions within racks or devices.

Collection Methods

  • SNMP (Simple Network Management Protocol): Widely used for polling device statistics.
  • Streaming Telemetry (gRPC): Provides real-time, high-frequency data streams.
  • API Calls: Direct programmatic access to device or application data.
  • Agents: Software installed on servers to collect OS and application metrics.
