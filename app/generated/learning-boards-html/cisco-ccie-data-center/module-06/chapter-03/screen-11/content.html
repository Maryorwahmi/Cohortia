Automating Cisco ACI Tenant Creation

Deploy new ACI tenants programmatically using Python and the `requests` library.

Tenant Payload Structure

A Python dictionary representing the ACI tenant's JSON configuration.

tenant_payload = {
    "fvTenant": {
        "attributes": {
            "name": "Cohortia_Tenant",
            "dn": "uni/tn-Cohortia_Tenant"
        },
        "children": []
    }
}
Success Confirmation

Check the HTTP status code (e.g., 200 OK) to confirm successful creation.

Code Walkthrough: Sending POST Request
# Assuming 'apic_cookie' is obtained from previous login
apic_url = "https://<APIC_IP_OR_HOSTNAME>/api/node/mo/uni.json"

headers = {
    "Content-Type": "application/json",
    "Cookie": f"APIC-Cookie={apic_cookie}"
}

# Payload for creating a new ACI tenant (defined above)

try:
    post_response = requests.post(apic_url, headers=headers, json=tenant_payload, verify=False)
    post_response.raise_for_status()
    print(f"Tenant creation status code: {post_response.status_code}")
    print("Response:")
    print(json.dumps(post_response.json(), indent=2))
    if post_response.status_code == 200:
        print("Successfully created Cohortia_Tenant.")
    else:
        print("Failed to create tenant.")
except requests.exceptions.RequestException as e:
    print(f"An error occurred during tenant creation: {e}")
Key Takeaway

Python scripts can automate complex configuration tasks like ACI tenant creation by constructing appropriate JSON payloads and sending them via authenticated POST requests to the API.
