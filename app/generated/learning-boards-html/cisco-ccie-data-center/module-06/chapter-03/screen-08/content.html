Performing HTTP GET Requests

Use `requests.get()` to retrieve data from REST APIs, a fundamental operation for network monitoring and data collection.

GET Request Components

Key elements for a successful GET request:

  • API URL: The endpoint for the desired resource.
  • Headers: Specify content type and authentication (e.g., cookies, tokens).
  • Error Handling: Use `try-except` and `response.raise_for_status()`.
Security Warning

`verify=False` bypasses SSL certificate validation and should NEVER be used in production environments.

Code Walkthrough: Simple GET Request
import requests
import json

api_url = "https://sandboxapic.cisco.com/api/node/class/topSystem.json"
headers = {
    "Content-Type": "application/json",
    "Cookie": "YOUR_APIC_COOKIE_HERE" # Replace with actual cookie/token
}

try:
    response = requests.get(api_url, headers=headers, verify=False)
    response.raise_for_status() # Raise HTTPError for bad responses

    device_data = response.json()
    print("Successfully retrieved device data:")
    print(json.dumps(device_data, indent=2))

except requests.exceptions.RequestException as e:
    print(f"An error occurred: {e}")
Key Takeaway

`requests.get()` is used to fetch data from an API, requiring the correct URL, headers for authentication, and robust error handling for reliable scripts.
