Parsing JSON Responses

Convert JSON API responses into Python data structures and extract relevant information.

`response.json()` Method

Automatically deserializes JSON string into Python dictionaries or lists.

device_data = response.json()
Common Parsing Mistakes
  • Incorrect key names or case sensitivity.
  • Trying to access a dictionary key on a list.
  • Not handling missing keys (use `.get()` or `if key in dict`).
  • Assuming a flat structure for nested JSON.
Code Walkthrough: Extracting Hostname
# Assuming 'device_data' is the parsed JSON from previous screen
if 'imdata' in device_data and device_data['imdata']:
    for system in device_data['imdata']:
        if 'topSystem' in system:
            hostname = system['topSystem']['attributes']['name']
            print(f"Extracted Hostname: {hostname}")
else:
    print("No 'imdata' or 'topSystem' found in response.")

# Example of safe nested access using .get()
user_data = {
    "id": 1,
    "name": "John Doe",
    "address": {
        "street": "123 Main St",
        "city": "Anytown"
    }
}
city = user_data.get('address', {}).get('city', 'N/A')
print(f"User city: {city}")
Key Takeaway

Parsing JSON involves converting the response into Python dictionaries and lists, then navigating these structures to extract specific data points, often requiring careful handling of nested elements and potential missing keys.
