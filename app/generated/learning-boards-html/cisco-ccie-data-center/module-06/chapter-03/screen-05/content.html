Python Basics: Variables and Data Types

Understand how to store and organize data using fundamental Python variables and lists.

Variables: Data Containers

Variables are named storage locations for data. Python infers the data type automatically.

device_ip = "192.168.1.1"
vlan_id = 100
is_active = True
Lists: Ordered Collections

Lists store an ordered sequence of items, useful for collections like VLANs or interfaces.

vlan_ids = [10, 20, 30, 40]
interface_names = ["Gi1/0/1", "Gi1/0/2"]

print(vlan_ids[0]) # Output: 10
Code Walkthrough: Data Storage
# 1. Define a variable for a device hostname
hostname = "nexus-01"

# 2. Create a list of IP addresses
ip_addresses = ["10.1.1.1", "10.1.1.2", "10.1.1.3"]

# 3. Access an element from the list
first_ip = ip_addresses[0]

# 4. Print the stored data
print(f"Hostname: {hostname}")
print(f"First IP: {first_ip}")
print(f"All IPs: {ip_addresses}")
Key Takeaway

Variables provide flexible data storage, while lists offer ordered collections, both fundamental for managing network-related information in Python.
