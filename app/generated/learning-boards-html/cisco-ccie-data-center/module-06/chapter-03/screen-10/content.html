Performing HTTP POST Requests

Send data to APIs to create or modify resources, a core function for configuration automation.

POST Request Essentials

Key elements for sending data to an API:

  • Payload: A Python dictionary representing the JSON data to send.
  • Authentication: Often requires a prior login to obtain a token or cookie.
  • Headers: Include `Content-Type` and authentication details.
`requests.post()` Method

Sends a POST request with the specified URL, headers, and JSON payload.

response = requests.post(url, headers=headers, json=payload)
Code Walkthrough: Login for Authentication
import requests
import json

login_url = "https://<APIC_IP_OR_HOSTNAME>/api/mo/aaaLogin.json"

# Simplified login payload
login_payload = {
    "aaaUser": {
        "attributes": {
            "name": "admin",
            "pwd": "password"
        }
    }
}

try:
    login_response = requests.post(login_url, json=login_payload, verify=False)
    login_response.raise_for_status()
    apic_cookie = login_response.cookies['APIC-Cookie']
    print("Successfully logged in and retrieved APIC-Cookie.")
    print(f"APIC-Cookie: {apic_cookie}")
except requests.exceptions.RequestException as e:
    print(f"Login failed: {e}")
    apic_cookie = None
Key Takeaway

POST requests are used to create or modify resources via an API, typically requiring a JSON payload and prior authentication to obtain a session cookie or token.
