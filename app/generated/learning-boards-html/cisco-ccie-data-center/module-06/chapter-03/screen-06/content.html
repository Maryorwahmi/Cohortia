Python Basics: Dictionaries and Control Flow

Learn to represent structured data with dictionaries and implement logic with control flow statements.

Dictionaries: Key-Value Pairs

Unordered collections of key-value pairs, ideal for structured data like device configs or API responses.

device_info = {
    "hostname": "nexus-01",
    "ip_address": "10.1.1.1",
    "role": "leaf"
}

print(device_info["hostname"]) # Output: nexus-01
Control Flow: Logic & Iteration

`if/else` for decisions, `for` loops for iterating over collections.

status = "down"
if status == "down":
    print("Interface is down!")
else:
    print("Interface is up.")

for vlan in [10, 20, 30]:
    print(f"Configuring VLAN {vlan}")
Code Walkthrough: Dynamic Logic
# 1. Represent a device with a dictionary
device = {
    "name": "router-a",
    "status": "active",
    "interfaces": ["eth0", "eth1"]
}

# 2. Check device status using an if statement
if device["status"] == "active":
    print(f"{device["name"]} is operational.")
else:
    print(f"{device["name"]} requires attention.")

# 3. Iterate through interfaces using a for loop
print("Configuring interfaces:")
for interface in device["interfaces"]:
    print(f" - {interface}")
Key Takeaway

Dictionaries are crucial for handling structured API data, while control flow statements enable scripts to make decisions and automate repetitive tasks dynamically.
