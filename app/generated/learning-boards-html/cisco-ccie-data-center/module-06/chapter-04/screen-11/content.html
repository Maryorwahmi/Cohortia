Executing Playbooks

Running Your First Playbook

Use the ansible-playbook command to execute your automation logic on managed hosts.

ansible-playbook -i inventory.ini ping_devices.yml
Key Takeaway

Executing playbooks with ansible-playbook is the final step to apply your defined automation tasks to your infrastructure, with clear success or failure indicators.

Output Interpretation

Understanding Results

  • SUCCESS: Indicates successful connection, authentication, and task execution.
  • FAILED/UNREACHABLE: Points to connectivity, authentication, or host definition issues.
  • CHANGED: Indicates that the task made a modification to the managed node.
  • OK: Task ran successfully but made no changes (due to idempotence).
Troubleshooting Tip

Verbose Output

If a playbook fails, add -vvv (or even -vvvv) to the ansible-playbook command for verbose output. This provides detailed debugging information that can help pinpoint the exact cause of the error, such as SSH connection issues or module failures.
