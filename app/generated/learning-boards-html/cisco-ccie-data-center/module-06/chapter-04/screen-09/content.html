Inventory Management

Crafting Your Ansible Inventory File

The inventory file lists your managed hosts, groups them logically, and can include host- or group-specific variables.

[nexus_switches]
nexus-01 ansible_host=192.168.1.101 ansible_user=admin ansible_password=password ansible_network_os=nxos
nexus-02 ansible_host=192.168.1.102 ansible_user=admin ansible_password=password ansible_network_os=nxos

[linux_servers]
server-a ansible_host=192.168.1.201 ansible_user=ubuntu ansible_ssh_private_key_file=~/.ssh/id_rsa
Key Takeaway

A well-structured inventory file is essential for Ansible, providing a clear definition of your managed infrastructure and its connection parameters.

Inventory Components

Groups and Host Variables

  • Groups: Organize hosts (e.g., [nexus_switches], [linux_servers]) for targeted automation.
  • ansible_host: Specifies the IP address or hostname for connection.
  • ansible_user/ansible_password: Authentication credentials for SSH/WinRM.
  • ansible_network_os: Specifies the network operating system for network-specific modules.
Common Mistake

Incorrect Credentials

One of the most frequent issues is providing incorrect ansible_user or ansible_password, leading to authentication failures. Always verify your credentials and SSH key paths.
