Ansible Fundamentals

Ansible Architecture: Inventory and Playbooks

Inventory

Lists managed hosts, groups, and variables.

Playbooks

YAML files defining tasks to execute on hosts.

Inventory Details

Host Grouping & Variables

  • Organize hosts into logical groups (e.g., `[webservers]`).
  • Assign host-specific variables (e.g., `ansible_user`, `ansible_host`).
Playbook Structure

Plays, Tasks, and Modules

  • Plays: Define target hosts and variables.
  • Tasks: Call Ansible modules to perform specific actions.
  • Modules: Small programs that execute actions (e.g., `ping`, `copy`).
Key Takeaway

The Inventory defines 'who' to manage, while Playbooks define 'what' to do, using modules to abstract complex operations into simple tasks.
