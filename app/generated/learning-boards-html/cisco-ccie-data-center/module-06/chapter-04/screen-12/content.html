Network Automation

Configuring VLANs on Cisco NX-OS with Ansible

Ansible's specialized network modules allow declarative configuration of Cisco NX-OS devices.

---
- name: Configure VLANs on Nexus Switches
  hosts: nexus_switches
  gather_facts: false

  tasks:
    - name: Ensure VLAN 100 exists and is named "Web_Servers"
      cisco.nxos.nxos_vlan:
        vlan_id: 100
        name: Web_Servers
        state: present
      register: vlan_config_result

    - name: Display VLAN configuration results
      ansible.builtin.debug:
        var: vlan_config_result
      when: vlan_config_result is changed
Key Takeaway

Ansible's network modules enable idempotent, declarative configuration of devices like Cisco NX-OS switches, ensuring consistent network states.

Module Parameters

Understanding nxos_vlan

  • vlan_id: The numeric ID of the VLAN to configure (e.g., 100).
  • name: The desired name for the VLAN (e.g., Web_Servers).
  • state: present: Ensures the VLAN exists; creates it if absent, updates if name differs.
Pro Tip

Idempotence in Action

The state: present parameter is a prime example of Ansible's idempotence. Running this playbook multiple times will only make changes if the VLAN's state doesn't match the desired configuration, preventing unintended side effects and ensuring consistency.
