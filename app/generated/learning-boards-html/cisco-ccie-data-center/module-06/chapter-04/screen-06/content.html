Ansible Fundamentals

Ansible Architecture: Control Node & Managed Nodes

Control Node

Where Ansible is installed and playbooks are run.

Managed Nodes

Target devices configured by Ansible (servers, switches).

Key Characteristics

Control Node Responsibilities

  • Ansible installation and playbook execution.
  • Manages inventory and credentials.
Managed Node Interaction

Agentless Communication

  • Uses SSH for Linux/Unix and network devices.
  • Uses WinRM for Windows hosts.
Key Takeaway

Ansible's architecture is built on a central Control Node communicating with agentless Managed Nodes via standard protocols, simplifying deployment and management.
