Cisco Data Center Platforms: API Integration

ACI APIC and NX-OS Programmability

Cisco ACI APIC

  • •Centralized controller for Cisco ACI.
  • •Exposes a comprehensive REST API.
  • •Enables full programmatic control over the ACI fabric.
  • •Integrates with automation tools for policy deployment and monitoring.

Example: ACI Tenant Creation

An automation script can use the ACI APIC REST API to programmatically create a new tenant, define its EPGs, and apply network policies, all without manual GUI interaction.

Cisco NX-OS Programmability

  • •Available on Nexus switches.
  • •Supports REST APIs (NX-API REST) and NETCONF.
  • •Allows direct Python scripting on the device (EEM with Python).
  • •Manages configurations, gathers telemetry, automates tasks.
Key Takeaway

Cisco's commitment to API integration in ACI APIC and NX-OS empowers data center professionals to build highly automated and software-defined infrastructure solutions.
