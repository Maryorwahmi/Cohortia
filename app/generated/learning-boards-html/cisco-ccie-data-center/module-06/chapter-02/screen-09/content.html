Data Formats

Structuring API Data: JSON and XML

The Languages of Data Exchange

JSON: JavaScript Object Notation

  • •Lightweight and Human-Readable: Easy to read and write.
  • •Key-Value Pairs and Arrays: Simple, intuitive data structure.
  • •Widely Used with REST: Popular due to simplicity and ease of parsing.

JSON Example

{
  "hostname": "nexus-01",
  "ip_address": "10.1.1.1",
  "role": "leaf"
}

XML: Extensible Markup Language

  • •Verbose and Tag-Based: Uses opening and closing tags.
  • •Strong Schema Validation: Ensures data conforms to a defined structure.
  • •Often Used with NETCONF: Preferred for its structural integrity.

XML Example

<device>
  <hostname>nexus-01</hostname>
  <ip_address>10.1.1.1</ip_address>
  <role>leaf</role>
</device>
Key Takeaway

JSON and XML are foundational for API communication, with JSON favored for its simplicity in REST and XML for its robust validation in protocols like NETCONF.
