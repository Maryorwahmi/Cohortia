Implementing Fibre Channel Zoning

Defining and activating zones for secure device communication in a SAN.

Zoning Configuration Steps

  • Define Zone: Specify which WWNs (server HBAs, storage ports) can communicate.
  • Create Zone Set: Group multiple zones into a single manageable entity.
  • Add Zones to Zone Set: Include defined zones within the zone set.
  • Activate Zone Set: Apply the zoning configuration to the VSAN.
  • Verify Configuration: Use `show` commands to confirm active zones.
Common Mistake

Misconfiguring WWN entries or failing to activate the zone set can lead to servers not seeing their assigned storage.

Key Takeaway

Correct Fibre Channel zoning is paramount for SAN security, preventing unauthorized access and ensuring proper storage visibility.

Cisco MDS CLI: Zoning Configuration

Creating a zone and activating a zone set.

# 1. Create a zone for Dev_VSAN 10
zone name Dev_Server_Storage_Zone vsan 10
  member pwwn 50:06:01:60:86:12:34:56
  member pwwn 50:06:01:60:86:78:90:AB
exit

# 2. Create a zone set and add the zone
zoneset name Dev_ZoneSet vsan 10
  member Dev_Server_Storage_Zone
exit

# 3. Activate the zone set
zoneset activate name Dev_ZoneSet vsan 10
exit

# Verify configuration (optional)
show zone active vsan 10
