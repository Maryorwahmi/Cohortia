Configuring VSANs on Cisco MDS Switches

Step-by-step CLI commands for creating and assigning interfaces to Virtual SANs.

VSAN Configuration Steps

  • Enter VSAN Database Mode: Access the configuration context for VSANs.
  • Create VSAN: Define a unique ID and a descriptive name for the new VSAN.
  • Assign Interfaces: Map specific Fibre Channel ports to the newly created VSAN.
  • Enable Interface: Ensure the assigned Fibre Channel interface is active.
  • Verify Configuration: Use `show` commands to confirm VSAN and interface status.
Pro-Tip

Always use descriptive names for your VSANs to easily identify their purpose and associated environments.

Key Takeaway

Proper VSAN configuration is essential for logical SAN segmentation, security, and fault isolation on Cisco MDS switches.

Cisco MDS CLI: VSAN Configuration

Creating a VSAN and assigning an interface.

# 1. Create VSAN 'Dev_VSAN' with ID 10
config terminal
vsan database
vsan 10 name Dev_VSAN
exit

# 2. Assign interface fc1/1 to VSAN 10
interface fc1/1
switchport access vsan 10
no shutdown
exit

# Verify configuration (optional)
show vsan 10
