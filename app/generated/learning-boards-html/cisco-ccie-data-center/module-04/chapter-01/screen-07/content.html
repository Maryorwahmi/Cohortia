Hypervisor Types

Type 2: Hosted Hypervisors & Comparison

Running as an application on an operating system.

Type 2 Hypervisor Details

  • •
    Runs as Application: Installed on a conventional operating system.
  • •
    Increased Overhead: Extra layer of abstraction can impact performance.
  • •
    Use Cases: Development, testing, desktop virtualization.

Type 1 vs. Type 2 Comparison

FeatureType 1 (Bare-Metal)Type 2 (Hosted)
InstallationDirectly on hardwareOn a host OS
PerformanceHigh (minimal overhead)Lower (OS overhead)
SecurityHigh (smaller attack surface)Lower (depends on host OS)
Use CaseProduction data centersDevelopment, testing, desktop

Examples

Type 2: VMware Workstation, Oracle VirtualBox, Parallels Desktop.

Key Takeaway

Type 2 hypervisors run as applications on a host OS, offering flexibility for non-production use, but with more overhead than the high-performance, bare-metal Type 1 hypervisors.
