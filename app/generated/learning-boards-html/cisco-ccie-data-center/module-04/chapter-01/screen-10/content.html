Practical Application

Deploying ESXi with UCS Service Profiles

A real-world example of rapid host provisioning.

Scenario: Deploying ESXi Hosts

You need to deploy 5 new VMware ESXi hosts on UCS blades, each requiring specific network and storage configurations, booting from SAN.

Key Service Profile Configurations

  • •
    UUID Suffix Pool: Ensures unique server identities.
  • •
    MAC Address Pool: Provides unique MACs for vNICs.
  • •
    WWN Pool: Assigns unique WWNs for vHBAs.
Key Takeaway

Service Profiles enable rapid, consistent deployment and quick recovery of virtualized hosts like ESXi by defining all server characteristics in software.

Service Profile Configuration Steps

1

Define vNICs

Create `vNIC_Management_vMotion` and `vNIC_VM_Traffic` with specific VLANs and MAC addresses.

2

Configure vHBAs

Set up `vHBA_A` and `vHBA_B` for redundant SAN paths with unique WWN addresses and VSANs.

3

Set Boot Policy

Specify boot order from SAN LUNs via `vHBA_A` then `vHBA_B`.

4

Associate with Server Pool

Link the Service Profile template to a server pool for automatic assignment to available blades.
