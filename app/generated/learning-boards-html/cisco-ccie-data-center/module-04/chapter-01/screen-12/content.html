Key Concepts: Part 1

Essential terms from server virtualization.

Server Virtualization

Creating multiple virtual instances of a server (VMs) on a single physical server.

Virtual Machine (VM)

A software-based emulation of a physical computer system, running its own OS and applications.

Hypervisor

Software that creates and runs virtual machines, managing physical hardware resources.

Chapter Summary

Server virtualization, enabled by hypervisors, allows multiple virtual machines to run on a single physical server, dramatically improving resource utilization and operational agility.
