What is an API?

Programmatic Communication

An API (Application Programming Interface) provides a standardized way for software components to communicate and interact with each other, replacing manual GUI/CLI interactions.

Enabling IaC

API-driven interaction is the cornerstone of Infrastructure-as-Code (IaC), allowing data center configurations to be defined in scripts, managed via version control, and deployed automatically.

Key Takeaway

APIs are fundamental to modern data center automation, enabling programmatic control and the powerful paradigm of Infrastructure-as-Code for consistent and rapid deployments.

REST API Example: Create ACI EPG
POST /api/node/mo/uni/tn-prod/ap-web/epg-web.json
Content-Type: application/json

{
  "fvAEPg": {
    "attributes": {
      "name": "web-epg",
      "descr": "Web Application EPG",
      "prefGrMemb": "included"
    },
    "children": [
      {
        "fvRsDomAtt": {
          "attributes": {
            "tDn": "uni/vmmp-VMware/dom-vCenter"
          }
        }
      }
    ]
  }
}
This JSON payload sent via a REST API call programmatically defines a new EPG in Cisco ACI, including its attributes and domain association.
