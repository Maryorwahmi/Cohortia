Endpoint Groups (EPGs) in ACI

Grouping endpoints for common network and security policies.

What is an EPG?

  • •A collection of endpoints (VMs, bare-metal servers, containers).
  • •Endpoints within an EPG share common network and security policies.
  • •Abstracts policy definition from individual IP/MAC addresses.
  • •Simplifies policy management and enhances scalability.
Key Takeaway

EPGs are fundamental to ACI, enabling logical grouping of endpoints for simplified, scalable, and application-centric policy enforcement.

Example: 3-Tier Application EPGs

Web Servers EPG
Application Servers EPG
Database Servers EPG

Misconception: EPGs are VLANs

While an EPG might correspond to a VLAN in some traditional designs, it's a much richer construct. EPGs define policy domains, not just Layer 2 segments. They are about grouping endpoints that require the same policy, regardless of their underlying network identifier.
