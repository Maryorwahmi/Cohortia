Key Concepts (Continued)

Further essential terms for Cisco ACI

Cisco ACI

Cisco's SDN solution for data centers, providing a policy-driven, automated network.

Endpoint Group (EPG)

A collection of endpoints (e.g., VMs, servers) that share common network and security policies in ACI.

Contract

A policy construct in ACI that explicitly defines allowed communication paths and services between EPGs.

Summary Takeaway

Cisco ACI leverages EPGs and Contracts to implement a powerful, application-centric policy model for automated and secure data center networking.
