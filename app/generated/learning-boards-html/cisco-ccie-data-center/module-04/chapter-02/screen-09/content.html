Cisco ACI: An Application-Centric Approach

Policy-driven automation for the modern data center.

What is Cisco ACI?

  • •Cisco's flagship Software-Defined Networking (SDN) solution.
  • •Built to leverage overlay technologies like VXLAN.
  • •Provides a policy-driven, automated network for data centers.
  • •Shifts from device-centric to application-centric management.
Key Takeaway

Cisco ACI transforms data center networking by enabling policy-driven automation, simplifying operations, and accelerating application deployment.

Traditional vs. ACI Configuration

Traditional

Manual switch-by-switch configuration

VLANs, ACLs, routing protocols

Device-centric

Cisco ACI

High-level policy definition

Application requirements

Application-centric

ACI abstracts the complexity, allowing you to define 'what' the network should do for your applications, not 'how' each device should be configured.

Example: Policy-Driven Deployment

Instead of configuring each switch for a new application, with ACI, you define a policy stating that 'Web servers need to talk to App servers on port 8080'. The ACI fabric automatically translates and applies this policy across all relevant switches, ensuring consistent and correct configuration without manual intervention.
