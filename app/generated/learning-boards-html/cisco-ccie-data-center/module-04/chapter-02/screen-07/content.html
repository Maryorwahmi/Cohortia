VXLAN: The Core Overlay Technology

Extending Layer 2 segments across Layer 3 IP networks.

VXLAN Fundamentals

  • •Encapsulates Layer 2 Ethernet frames within UDP packets.
  • •Allows Layer 2 segments to span Layer 3 IP networks.
  • •Uses a 24-bit VXLAN Network Identifier (VNI) for segmentation.
  • •Provides over 16 million unique network segments.
Key Takeaway

VXLAN is crucial for modern data centers, offering massive scalability and flexibility by extending Layer 2 networks over Layer 3 using encapsulation.

VLAN vs. VXLAN: A Comparison

Traditional VLANs

Limited to 4096 IDs

Layer 2 only

Spanning Tree Protocol (STP) limitations

VXLAN

Over 16 Million VNIs

Layer 2 over Layer 3

Leverages Layer 3 routing

VXLAN's ability to provide millions of unique segments makes it ideal for multi-tenant cloud environments, far surpassing the scalability of traditional VLANs.

Example: Multi-Tenant Cloud

In a public cloud environment, each customer requires network isolation. With VXLAN, a cloud provider can assign a unique VNI to each tenant, allowing them to have their own virtual network segments that are logically separate but share the same physical underlay infrastructure. This ensures security and prevents resource conflicts.
