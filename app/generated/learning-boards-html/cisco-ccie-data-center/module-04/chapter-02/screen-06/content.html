Fundamental Concept

Introduction to Overlay Networking

Building virtual networks 'on top' of physical infrastructure.

Key Characteristics

  • •Creates virtual networks over an existing physical 'underlay'.
  • •Traffic is encapsulated within the underlay network's packets.
  • •Decouples virtual network topology from physical topology.
  • •Enables greater flexibility, scalability, and multi-tenancy.
Key Takeaway

Overlay networking provides a flexible and scalable way to create virtual networks, abstracting them from the physical infrastructure.

Misconception: Underlay Irrelevance

A common misconception is that the physical underlay network becomes unimportant. In reality, a stable, high-performance, and well-designed IP underlay is absolutely critical for the overlay network to function reliably and efficiently. The overlay relies on the underlay for packet transport.
