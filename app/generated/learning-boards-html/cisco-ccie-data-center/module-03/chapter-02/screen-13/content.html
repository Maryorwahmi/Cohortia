Designing a Basic Service Profile

Conceptualizing server identity and configuration for a virtualized database.

Key Parameters to Define

  • Identity Pools: UUID, MAC Address, WWN pools for unique identifiers.
  • Network (vNICs): MAC addresses, VLANs, Adapter Policies.
  • Storage (vHBAs): WWNs, VSANs, Adapter Policies.
  • Boot Policy: Define boot order (e.g., Remote SAN Boot).
  • Firmware Policy: Specify desired BIOS, Adapter, CIMC versions.
  • Host OS Config: Host Name Prefix (e.g., DB-SERVER-).
Key Takeaway

A service profile template defines all logical aspects of a server, from network identity to boot order, ensuring consistent and rapid provisioning.

Scenario: Replacing a Failed Server

If a physical server fails, disassociate its service profile and re-associate it with a healthy, unassigned server. The new server instantly inherits all defined identities and configurations, ensuring quick recovery without manual setup.
