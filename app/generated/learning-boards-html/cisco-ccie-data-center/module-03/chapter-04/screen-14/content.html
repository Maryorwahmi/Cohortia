Verifying SAN Zoning and Interface Status

Confirming active zones and Fibre Channel interface operational state.

`show zoneset active`

Displays the currently active zoneset, including all defined zones and their members (typically by WWN). Essential for verifying if devices are correctly zoned.

`show interface fc X/Y`

Provides detailed operational status for a specific Fibre Channel interface, including its link state (up/down), speed, and VSAN membership. Crucial for physical layer troubleshooting.

Troubleshooting Scenario

If a server cannot access storage, first check `show fcns database` for device registration, then `show zoneset active` for correct zoning, and finally `show interface fc` for physical link status.

MDS-V# show zoneset active
zoneset name ACTIVE_ZONESET vsan 1
  zone name APP_SERVER_ZONE vsan 1
    member pwwn 20:00:00:25:B5:A0:00:01
    member pwwn 50:06:01:60:80:C0:00:01 (Storage_Port_A)
...
MDS-V# show interface fc 1/1
fc1/1 is up
    Port mode is F, Port speed is 16 Gb/s
    Port vsan is 1
...
