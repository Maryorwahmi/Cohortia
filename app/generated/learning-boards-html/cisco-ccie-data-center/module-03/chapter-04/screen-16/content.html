Chapter Summary

Key Concepts (Continued)

More essential takeaways from this chapter

Port Zoning

A type of SAN zoning based on the physical port numbers of devices connected to the FC switch.

WWN Zoning

A type of SAN zoning based on the unique World Wide Name (WWN) of devices, offering greater flexibility and independence from physical port location.

Virtual Storage Area Network (VSAN)

A feature that partitions a single physical Fibre Channel switch or fabric into multiple logical, isolated SANs, each with its own services and zoning.

Host Bus Adapter (HBA)

A hardware component in a server that connects the server to a Fibre Channel SAN.

Summary Takeaway

WWN zoning and VSANs are advanced features for flexible security and isolation, while HBAs are the essential server-side components for SAN connectivity.
