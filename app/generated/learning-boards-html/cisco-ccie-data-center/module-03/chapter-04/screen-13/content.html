Verification Commands

Verifying SAN Connectivity: `show fcns database`

Inspecting the Fibre Channel Name Server database for registered devices.

Purpose of FCNS

The Fibre Channel Name Server (FCNS) acts as a directory service within the SAN, registering all connected devices (HBAs, storage ports) and their attributes.

Command Output Details

  • FCID: Fibre Channel ID, a unique address within the fabric.
  • TYPE:PWWN: Port World Wide Name of the device.
  • NODE:WWN: Node World Wide Name of the device.
  • INTERFACE: The physical switch interface the device is connected to.

Troubleshooting Insight

If a device is not listed in the FCNS database, it indicates a fundamental connectivity issue (e.g., cable, HBA, switch port) that needs to be resolved before zoning can function.
