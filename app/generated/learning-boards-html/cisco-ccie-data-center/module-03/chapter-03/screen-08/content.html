Enhancing Performance with Data Locality

Minimizing Latency by Accessing Local Data First

What is Data Locality?

Data locality is a critical performance feature where the HX Data Platform attempts to store and serve a virtual machine's data from the local storage of the HyperFlex node where that VM is actively running.

  • Reduced Latency: Data access doesn't need to traverse the network.
  • Improved Performance: Faster read/write operations for applications.
  • Network Efficiency: Less traffic on the cluster interconnect.
Example Scenario

A database VM on Node A needs to read a record. With data locality, the HX Data Platform ensures that record is primarily served from Node A's local SSDs, not from Node B or C, resulting in near-instant access.

Key Takeaway

Data locality is a core HX Data Platform feature that significantly improves application performance by prioritizing local data access for virtual machines.
