VXLAN: Virtual Extensible LAN

Learn how VXLAN creates scalable, multi-tenant overlay networks across the data center, overcoming VLAN limitations.

Key Aspects of VXLAN

  • •
    Overlay Network: Creates virtual Layer 2 networks over a Layer 3 underlay.
  • •
    Encapsulation: Encapsulates Layer 2 Ethernet frames in Layer 3 IP packets.
  • •
    Scalability: Uses 24-bit VNI (VXLAN Network Identifier) for 16M+ segments, overcoming 4096 VLAN limit.
  • •
    Nexus Support: Native hardware support for high-performance forwarding.

VXLAN Benefits & Example

VMs communicate across physical boundaries

  • •
    Benefit: Enables VMs on different physical hosts/subnets to act as if on the same Layer 2 segment.
  • •
    Example: Two VMs in the same VXLAN segment, but on different racks, communicate seamlessly.
  • •
    Misconception: VXLAN itself does not provide inherent encryption; security relies on underlying network measures.
Key Takeaway

VXLAN is essential for building scalable, multi-tenant data center networks by extending Layer 2 domains over a Layer 3 infrastructure, with Nexus switches providing crucial hardware support.
