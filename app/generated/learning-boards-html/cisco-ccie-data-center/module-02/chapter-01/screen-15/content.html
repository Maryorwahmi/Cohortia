Key Concepts

Advanced Terms for Modern Data Centers

East-West Traffic

Network traffic flowing between servers or virtual machines within the data center.

Spine Switch

High-density, high-speed switches forming the backbone of a spine-leaf network, interconnecting all Leaf switches.

Leaf Switch

Access layer switches in a spine-leaf network, connecting directly to servers and uplinked to all Spine switches.

Equal-Cost Multi-Path (ECMP)

A routing technique that allows traffic to be distributed across multiple equal-cost paths to the same destination.

NX-OS

The network operating system used by Cisco Nexus switches, optimized for data center environments.

Summary Takeaway

Spine and Leaf switches, combined with ECMP and NX-OS, form the core technological components of modern, high-performance data center networks.
