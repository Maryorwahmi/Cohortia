Configuration Example

Configuring Leaf Switch Access Ports

Connecting Servers to the Data Center Network

Configuration Steps

  • •Select Interface: Enter interface configuration mode (e.g., interface Ethernet1/1).
  • •Add Description: Label the port for clarity (e.g., description "Connection to Server-A").
  • •Set Mode: Configure as an access port (switchport mode access).
  • •Assign VLAN: Place the port in the appropriate VLAN (e.g., switchport access vlan 10).
  • •Activate Port: Bring the interface up (no shutdown).
Key Takeaway

Properly configuring access ports on Leaf switches ensures servers have correct Layer 2 network connectivity.

Leaf1(config)# interface Ethernet1/1
Leaf1(config-if)# description "Connection to Server-A"
Leaf1(config-if)# switchport mode access
Leaf1(config-if)# switchport access vlan 10
Leaf1(config-if)# no shutdown
Leaf1(config-if)# exit
