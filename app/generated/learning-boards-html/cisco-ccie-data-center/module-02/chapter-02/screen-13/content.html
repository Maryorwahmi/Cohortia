Foundational Concepts

Understanding the building blocks of network virtualization

VLAN

Traditional Layer 2 segmentation with 4094 ID limit, confined to a single broadcast domain.

Overlay Network

A virtual network built on top of an existing physical (underlay) network, providing logical connectivity.

Underlay Network

The physical IP network that provides the foundational connectivity for the overlay network.

Summary Takeaway

Understanding VLAN limitations and the concept of overlay/underlay networks is crucial for appreciating modern data center virtualization solutions.
