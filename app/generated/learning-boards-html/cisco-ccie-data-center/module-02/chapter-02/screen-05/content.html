Embracing Overlay Networks with VXLAN

Solving scalability and flexibility issues with encapsulation

Overlay Network (VXLAN)
Underlay Network (IP)
Encapsulation
Logical L2 over Physical L3

What is VXLAN?

Virtual Extensible LAN, encapsulates Layer 2 frames in Layer 3 UDP packets.

Why Overlays?

Overcomes VLAN limits, extends Layer 2 domains across Layer 3 networks for scalability.

Underlay Network

The physical IP network that provides basic IP reachability between VXLAN devices.

Key Takeaway

VXLAN enables logical Layer 2 networks to span physical Layer 3 infrastructures, providing unprecedented scalability and flexibility for modern data centers.
