VTEPs and VNIs: The Building Blocks of VXLAN

Understanding VXLAN Tunnel Endpoints and Network Identifiers

VTEP (VXLAN Tunnel Endpoint)

A device (e.g., Leaf switch, server NIC) that performs VXLAN encapsulation and de-encapsulation. It's the gateway between the L2 segment and the L3 underlay.

VNI (VXLAN Network Identifier)

A unique 24-bit identifier for a Layer 2 segment within a VXLAN overlay, providing over 16 million possible segments (compared to 4094 VLAN IDs).

Key Takeaway

VTEPs handle the tunneling, while VNIs provide massive logical segmentation, together enabling VXLAN to scale far beyond traditional VLAN capabilities.
