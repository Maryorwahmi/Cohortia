Configuring a Basic VXLAN VTEP

Step-by-step setup on a Cisco Nexus device

// Step 1: Enable VXLAN featureLeaf1(config)# feature vn-segment-vlan-basedLeaf1(config)# feature nv overlay// Step 2: Create a Layer 2 VNI and map it to a VLANLeaf1(config)# vlan 100Leaf1(config-vlan)# vn-segment 500100Leaf1(config-vlan)# exit// Step 3: Configure the NVE (Network Virtualization Edge) interface (the VTEP)Leaf1(config)# interface nve1Leaf1(config-if)# no shutdownLeaf1(config-if)# source-interface loopback0 // Loopback for VTEP IPLeaf1(config-if)# host-reachability protocol bgpLeaf1(config-if)# member vni 500100 associate-vrfLeaf1(config-if)# exit// Step 4: Configure the loopback interface for the VTEP IPLeaf1(config)# interface loopback0Leaf1(config-if)# ip address 192.168.1.1/32Leaf1(config-if)# ip pim sparse-mode // If using multicast for BUM trafficLeaf1(config-if)# exit
Key Takeaway

Basic VXLAN configuration involves enabling features, mapping VLANs to VNIs, and setting up the NVE interface with a source loopback for Layer 2 extension.

Enable Features

Activate `vn-segment-vlan-based` and `nv overlay` for VXLAN functionality.

Map VLAN to VNI

Associate a traditional VLAN (e.g., VLAN 100) with a unique VXLAN Network Identifier (e.g., VNI 500100).

Configure NVE Interface

Set up the Network Virtualization Edge interface as the VTEP, specifying its source IP and VNI associations.

Common Mistake

Incorrect underlay routing or VNI assignments can prevent VXLAN tunnels from forming or traffic from flowing correctly.
