Configuring OTV: Enabling the Feature and Site ID

Initial Steps on a Cisco Nexus OTV Edge Device

// Step 1: Enable OTV feature
OTV_Edge1(config)# feature otv

// Step 2: Configure the OTV site identifier (unique per data center)
OTV_Edge1(config)# otv site-identifier 0x1
Key Takeaway

The first steps in configuring OTV involve enabling the feature and assigning a unique site identifier to distinguish each data center.

Enable OTV Feature

The feature otv command activates the OTV functionality on the Nexus device, making OTV-specific commands available for configuration.

Configure Site Identifier

The otv site-identifier command assigns a unique hexadecimal ID to the data center, crucial for OTV control plane operation and preventing site conflicts. Each data center must have a unique ID.

Common Mistake

Using the same site identifier for multiple data centers will cause OTV to malfunction, leading to unpredictable Layer 2 extension behavior and potential network loops.
