Key Concepts

Deepening Your DCI Vocabulary

OTV Join Interface

The Layer 3 interface on an OTV edge device that connects to the DCI underlay IP network, carrying encapsulated OTV traffic.

OTV Extended VLAN List

The list of VLANs explicitly designated to be extended across the DCI using OTV, ensuring only specified Layer 2 segments participate.

Ethernet VPN (EVPN)

A modern control plane technology (using BGP) for Layer 2 and Layer 3 VPN services, often used with VXLAN for scalable DCI and network virtualization.

BGP EVPN

The combination of BGP (Border Gateway Protocol) as the control plane and EVPN address families to advertise MAC and IP reachability information for Layer 2 and Layer 3 VPNs.

These terms are fundamental to understanding the configuration and operation of both OTV and EVPN in DCI environments.
