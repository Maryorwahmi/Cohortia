Configuring OTV: The Overlay Interface and Join Interface

Connecting the OTV Overlay to the DCI Underlay

// Step 3: Create the OTV overlay interface
OTV_Edge1(config)# interface overlay 1
OTV_Edge1(config-if)# otv join-interface Ethernet1/10 // The interface connecting to the DCI IP network
Key Takeaway

The OTV overlay interface acts as the logical connection point, using a physical join interface to connect to the underlying IP transport network, enabling encapsulated Layer 2 traffic to traverse the DCI.

Overlay Interface

This is a logical interface where OTV configurations are applied. It's the virtual representation of the Layer 2 extension over the DCI.

Join Interface

The join-interface is the physical Layer 3 interface on the OTV edge device that connects to the DCI IP underlay. It must have IP connectivity to other OTV edge devices.

Important Note

The join interface itself does not extend Layer 2. It's the transport for the IP-encapsulated Layer 2 OTV traffic. Ensure it has an IP address and is routable across the DCI.
