Key Concepts

Review the fundamental terms and ideas from this chapter.

Application Policy Infrastructure Controller (APIC)

The centralized controller, management engine, and policy repository for the Cisco ACI fabric.

Underlay Network

The physical IP network formed by the leaf and spine switches, providing IP reachability between all fabric nodes.

Overlay Network

A virtual network built on top of the underlay, typically using VXLAN, to extend Layer 2 segments across the Layer 3 underlay.

Key Takeaway

The APIC provides centralized intelligence, while the underlay ensures physical connectivity and the overlay (via VXLAN) enables flexible network virtualization.
