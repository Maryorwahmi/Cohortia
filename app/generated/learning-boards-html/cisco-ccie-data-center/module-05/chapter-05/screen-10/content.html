AAEPs and Interface Policies

Linking Resources to Physical Settings

Component 3

Attachable Access Entity Profiles (AAEPs)

A construct that links VLAN pools to physical domains and specifies which interface policies can be used. It acts as a bridge between logical and physical access configurations.

Function: Links VLAN Pool + Physical Domain + Interface Policies
Component 4

Interface Policies

Define physical layer settings for leaf switch ports, such as speed, duplex, LLDP, and CDP. These policies ensure consistent port behavior across the fabric.

Example: 10Gbps_LLDP_Enabled (speed, duplex, LLDP, CDP)
Key Takeaway

AAEPs and Interface Policies work in tandem to ensure that physical ports are configured correctly and associated with the right VLANs and domains for external device connectivity.
