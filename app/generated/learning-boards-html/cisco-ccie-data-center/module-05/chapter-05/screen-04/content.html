Initial APIC Setup

Configuring Out-of-Band Management

Core Concept

Out-of-Band Management (OOB)

A dedicated network path for managing network devices, independent of the data plane. It's crucial for initial setup, troubleshooting, and maintaining access during fabric issues.

Key Parameters
  • IP Address: Unique identifier for the APIC on the OOB network.
  • Subnet Mask: Defines the network portion of the IP address.
  • Default Gateway: Route for traffic outside the local OOB subnet.
  • DNS Servers: For name resolution of external services.
Key Takeaway

Proper OOB configuration is the foundational step for APIC management and cluster formation, ensuring reliable access and communication.
