Registering and Configuring Switches

APIC Takes Control of the Fabric

1

Assign IDs

Assign unique Fabric ID and Node ID to each discovered switch.

2

Push Initial Config

APIC pushes roles (leaf/spine) and underlay routing protocols (IS-IS).

3

Fabric Under Management

Switches are now managed by APIC, ready for policy deployment.

Pro-Tip

Ensure stable in-band connectivity between APICs and leaf switches for successful LLDP discovery and configuration push. Network issues here can halt fabric bring-up.

Key Takeaway

APIC's automated registration and configuration push centralizes management, assigns roles, and establishes the underlay, forming the intelligent ACI fabric.
