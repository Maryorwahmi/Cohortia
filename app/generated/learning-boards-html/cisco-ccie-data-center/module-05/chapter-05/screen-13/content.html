Instructions
  • Connect to APIC console and initiate setup wizard.
  • Input fabric name, APIC ID, cluster size, and controller name.
  • Configure OOB IP, subnet, gateway, and DNS.
  • Set admin password.
  • Verify OOB connectivity using ping.
  • Access APIC GUI via web browser (https://OOB_IP).
Common Mistakes & Safety Notes

Incorrect OOB IP/Mask/Gateway settings will prevent access. Ensure the OOB IP is unique and the physical cable is connected to the correct management port.

Key Takeaway

The initial APIC console configuration is a guided process that establishes the foundational management access and fabric parameters, requiring careful attention to network settings.
