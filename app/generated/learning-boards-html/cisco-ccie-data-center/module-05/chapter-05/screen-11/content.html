Interface Policy Groups & Port Selectors

Applying Policies to Specific Ports

Component 5

Interface Policy Groups

Logical groupings of similar interface policies. They simplify management by allowing you to apply a consistent set of physical layer settings to multiple ports.

Example: Server_Access_Group (10Gbps, LLDP enabled)
Component 6

Port Selectors & Access Port Selectors

Used to apply Interface Policy Groups to specific ports or ranges of ports on leaf switches, linking the policy to the physical hardware.

Function: Maps Policy Group to Leaf Port(s)
Scenario: Connecting a Bare-Metal Server

Create a VLAN pool, an AAEP, an interface policy for the server port, an interface policy group, and then apply this group to the specific leaf switch port connected to the server using a port selector. This ensures the correct physical port configuration is automatically applied when an EPG is deployed.

Key Takeaway

The combination of Interface Policy Groups and Port Selectors provides the granular control needed to apply specific access policies to physical leaf switch ports, automating endpoint connectivity.
