EPG Deep Dive

EPGs, Contracts, and Micro-segmentation

Enforcing a Whitelist Security Model

Default Deny Posture

EPGs cannot communicate by default; traffic is blocked unless explicitly allowed.

Contracts Enable Communication

Explicit policies (Contracts) define permitted communication between EPGs.

Micro-segmentation Achieved

Granular security by isolating workloads and controlling inter-EPG traffic.

Security Model Comparison

Traditional: Blacklist

Allow all traffic, then block specific bad traffic.

ACI: Whitelist

Block all traffic by default, then explicitly allow good traffic via Contracts.

Key Takeaway

EPGs and Contracts together enable a powerful whitelist security model, providing inherent micro-segmentation and a significantly reduced attack surface.
