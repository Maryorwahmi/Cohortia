Core Construct

Bridge Domains: Defining Layer 2 Broadcast

The ACI Equivalent of a VLAN Segment

Layer 2 Broadcast Domain

Defines a segment where all endpoints can communicate at Layer 2.

Associated with a VRF

Each BD belongs to one and only one VRF, linking Layer 2 to Layer 3 context.

Granular Segmentation

Allows for fine-grained Layer 2 network segmentation within a Layer 3 VRF context.

Bridge Domain Analogy: Rooms in an Apartment

ACI VRF

A single apartment unit.

Each Bridge Domain

A distinct room within the apartment, where occupants can communicate directly.

Key Takeaway

Bridge Domains provide Layer 2 broadcast isolation, acting as logical segments that are always bound to a specific VRF for Layer 3 context.
