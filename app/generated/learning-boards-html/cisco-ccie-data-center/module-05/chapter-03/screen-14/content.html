Chapter Summary

Key Concepts

Essential ACI Building Blocks

Tenant

The highest-level logical container in ACI, providing secure and isolated partitions for different customers, departments, or application environments.

VRF Instance (Context)

A logical Layer 3 forwarding domain within a Tenant, providing isolated routing tables and IP address spaces.

Bridge Domain (BD)

A logical Layer 2 broadcast domain within a VRF, defining a segment where endpoints can communicate at Layer 2. BDs can have associated subnets that act as default gateways.

Summary Takeaway

Tenants, VRFs, and Bridge Domains form the hierarchical foundation for isolation and segmentation in Cisco ACI, enabling robust and flexible network designs.
