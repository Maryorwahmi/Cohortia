Filters: The Granular Rules

Specifying Layer 3 and Layer 4 traffic parameters

Definition

Filters define specific Layer 3 (protocol) and Layer 4 (port) parameters for allowed traffic.

Granular Control

Allows for fine-grained control over which types of traffic are permitted between EPGs.

Common Parameters

Typically specifies protocol (TCP/UDP) and destination port numbers (e.g., 80, 443, 3306).

Filter Definition
Protocol:TCP
Destination Port:80 (HTTP)
Source Port:Any (Ephemeral)
EtherType:IP
Key Takeaway

Filters are the precise rules for traffic, defining protocol and port numbers.
