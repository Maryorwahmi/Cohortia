Key Concepts

Essential terms to remember

Contract

A policy construct that explicitly defines permitted communication between EPGs; without it, EPGs are isolated.

Provider EPG

An Endpoint Group that offers a service and provides a contract to other EPGs.

Consumer EPG

An Endpoint Group that needs to access a service and consumes a contract from a provider EPG.

Chapter Summary

ACI Contracts define explicit communication rules between isolated EPGs, using a directional provider-consumer model to enforce a whitelist security posture.
