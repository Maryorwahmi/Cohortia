Building a Contract: Step-by-Step Scenario

Allowing TCP 8080 between EPGs

01

Define a Filter

Create Filter_TCP_8080 to permit TCP traffic on Destination Port 8080.

02

Define a Subject

Create AppService_Access and add Filter_TCP_8080 to it.

03

Define a Contract

Create Contract_Web_to_App and add AppService_Access as a subject.

04

Apply the Contract

App_EPG will provide, and Web_EPG will consume Contract_Web_to_App.
