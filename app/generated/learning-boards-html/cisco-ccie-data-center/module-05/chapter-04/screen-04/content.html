EPG Isolation: The Default State

Why Contracts are essential for EPG communication

Default Security Posture

EPGs are inherently isolated; no communication is allowed between them without explicit policy.

Whitelist Approach

ACI operates on a 'permit by exception' model, where only explicitly defined traffic is allowed.

Enhanced Security

This model significantly reduces the attack surface and prevents unauthorized lateral movement.
