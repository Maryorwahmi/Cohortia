Introducing Cisco ACI: SDN for the Data Center

Enhancing SDN with an Application-Centric Philosophy

Cisco ACI Defined

Cisco Application Centric Infrastructure is a leading SDN solution specifically designed for modern data centers.

Application-Centric

Focuses on defining network policies based on application requirements, not low-level network constructs.

Policy Translation

ACI translates high-level application policies into concrete network configurations across the entire fabric.

Key Takeaway

Cisco ACI extends SDN by prioritizing application needs, simplifying network provisioning, and ensuring alignment between applications and infrastructure.
