Core Principle

Defining Network Behavior with Application-Centric Policies

From Low-Level Constructs to High-Level Application Needs

Traditional Approach

  • Configure VLANs, IP addresses, ACLs on individual devices.
  • Example: permit tcp 10.1.10.0/24 host 10.1.20.10 eq 8080
  • Device-centric, imperative, complex, error-prone.
Misconception

ACI doesn't eliminate low-level configurations; it automates their generation and enforcement based on high-level policies.

ACI Policy-Driven Approach

  • Define Endpoint Groups (EPGs) and Contracts.
  • Example: EPG_Web_Tier provides Contract_Web_to_App
  • Application-centric, declarative, simplified, agile.
Key Takeaway

ACI's application-centric policies abstract away low-level network details, allowing administrators to define network behavior based on application needs, enhancing simplicity and agility.
