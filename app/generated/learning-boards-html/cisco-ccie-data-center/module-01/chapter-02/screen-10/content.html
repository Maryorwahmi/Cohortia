VXLAN: Extending Layer 2 Over Layer 3

Enabling Virtual Networks in an IP Fabric

How VXLAN Works

  • Encapsulation: Layer 2 Ethernet frames are encapsulated within Layer 3 UDP packets.
  • Underlay/Overlay: Uses an existing L3 IP fabric (underlay) to carry L2 virtual networks (overlay).
  • VNI: Each virtual network is identified by a unique VXLAN Network Identifier.
  • Purpose: Extends L2 domains across L3 boundaries for VM mobility and flexible segmentation.
Real-World Use Case

Enables seamless migration of virtual machines between hosts connected to different Leaf switches, without changing their IP address.

Key Takeaway

VXLAN is essential for modern data centers, providing the flexibility to extend Layer 2 networks over a Layer 3 IP fabric, supporting virtualization and cloud-like environments.
