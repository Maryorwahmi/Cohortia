Key Concepts: Virtualization

Essential terms for understanding virtualized environments.

Virtualization

Creating a software-based representation of a physical resource.

Hypervisor

Software that creates and runs virtual machines (VMs).

Type 1 Hypervisor

Runs directly on host hardware (bare-metal).

Summary Takeaway

Virtualization, VMs, and hypervisors (Type 1 and Type 2) are the core components enabling flexible and efficient data center operations.
