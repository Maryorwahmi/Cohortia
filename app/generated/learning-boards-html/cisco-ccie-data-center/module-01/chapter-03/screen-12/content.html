Cloud Service Models: SaaS

Ready-to-use applications over the internet.

Key Takeaway

SaaS offers the highest level of abstraction, providing complete, managed applications directly to end-users.

User Responsibility

Users simply access and use the software; the provider manages everything else, including infrastructure, platform, and application.

Software as a Service (SaaS) Model

Fully managed applications delivered over the internet.

End User
SaaS Application
Cloud Provider (Manages Everything)

Examples: Gmail, Salesforce, Dropbox – ready-to-use applications.
