Hosted Hypervisors (Type 2)

Running as an application on an existing operating system.

Key Takeaway

Type 2 hypervisors are convenient for personal use and development, but less efficient for enterprise data centers.

Examples
  • VMware Workstation
  • Oracle VirtualBox
  • Parallels Desktop
