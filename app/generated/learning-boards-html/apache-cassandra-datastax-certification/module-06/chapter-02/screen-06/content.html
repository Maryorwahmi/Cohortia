Module 6 › Chapter 6.2 › Configure & Query: Steps
Step 1
Enable DSE Search on the cluster
Start DSE with search enabled and verify node configuration. This prepares nodes to host Solr cores.
Step 2
Create keyspace and table
Model your data in Cassandra tables and choose columns that require full-text indexing.
Step 3
Create a custom Solr-backed index
Use CREATE CUSTOM INDEX with WITH OPTIONS to map columns to a Solr schema and set default text fields.
Step 4
Insert data and allow indexing
DSE keeps Solr indexes in sync with Cassandra writes; validate index behavior under representative write patterns.
Step 5
Query with solr_query in CQL
Run SELECT statements using the solr_query JSON to combine full-text and filter queries.
Pitfall
Under-provisioning resources
Search cores and Spark executors need memory and disk. Plan node sizing and monitor index growth to avoid bottlenecks.
Concrete scenario
Create a products table, index name and description, insert a sample set, then run a solr_query searching for the term "camera" and filter by a tags field to display matching items. This flow demonstrates full-text plus structured filtering without moving data off the cluster.
