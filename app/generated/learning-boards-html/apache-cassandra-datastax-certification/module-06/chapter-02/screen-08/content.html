Module 6 › Chapter 6.2 › DSE Analytics
What it is
Spark integrated into DSE so you can run analytics jobs directly against Cassandra-stored data for both batch and streaming use cases.
Common workloads
  • Real-time dashboards that aggregate operational metrics.
  • Anomaly detection and streaming alerts.
  • Machine learning training on recent production data.
Architecture note
Cassandra remains the storage layer. Spark reads data and runs processing in-place. This avoids ETL but introduces resource sharing trade-offs.
Practical tip
Test Spark executor sizing and monitor network I/O because analytics jobs can contend with operational traffic if resources are not planned.
Concrete example
A streaming pipeline that consumes events, writes them to Cassandra, and runs Spark Streaming jobs to update a real-time dashboard with rolling aggregates and anomaly scores.
