DataStax Enterprise (DSE)
A commercial distribution of Cassandra with integrated search, graph, analytics, and security.
DSE Search
Solr integrated with Cassandra for full-text and faceted search using a Solr-backed custom index.
DSE Graph
A native graph on Cassandra using Apache TinkerPop and Gremlin for relationship modeling and traversals.
Summary takeaway

Remember: search for text and facets, graph for relationships, analytics for large-scale processing — all can operate on the same Cassandra data in DSE.
