Module 6 › Chapter 6.4 › Disk & Network
Disk guidance
  • Prefer SSDs for production to improve random IOPS.
  • Avoid NAS or shared storage for data directories.
  • Choose RAID only after weighing I/O vs durability trade-offs.
Network guidance
  • Use high-bandwidth, low-latency links between nodes.
  • Give inter-node traffic its own interface when possible.
  • Tune TCP buffers for large streaming operations if required.
Check disk latency and compaction durations to decide whether storage or network is the bottleneck.
