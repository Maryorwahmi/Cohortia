Module 6 › Chapter 6.4 › STCS Process
How it works
  1. Memtables flush and create new SSTables.
  2. STCS groups SSTables of similar size.
  3. Grouped SSTables are merged into larger SSTables.
  4. Over time, many overlapping SSTables can increase read work.
Example

An append-only event log with heavy writes and few updates benefits from STCS because it reduces immediate compaction overhead. Monitor read latency to ensure overlap doesn't become costly.

Pro tip: use nodetool cfstats to inspect SSTable counts and compaction throughput before changing strategy.
