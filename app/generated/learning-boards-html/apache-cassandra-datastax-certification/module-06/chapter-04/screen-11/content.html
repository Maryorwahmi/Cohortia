Key settings
  • Set -Xms and -Xmx; keep them equal to avoid resizing.
  • Choose a modern collector such as G1GC for balanced pauses.
  • Monitor gc.log to detect long or frequent full GCs.
gc.log example (snippet)
[GC pause (G1 Evacuation) (young) ...  2000ms]
[Full GC ... 5000ms]
If you see repeated long pauses, review heap size and collector choice; increase observation before changing values.
