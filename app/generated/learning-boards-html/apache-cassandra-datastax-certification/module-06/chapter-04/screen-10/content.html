Module 6 › Chapter 6.4 › Compaction Example
Scenario

user_posts is append-only and time-ordered. user_profiles is read-heavy with occasional updates. Choose TWCS for the posts table and LCS for profiles.

Run these statements in cqlsh and monitor with nodetool cfstats.
CQL Examples
ALTER TABLE user_posts WITH compaction = {
  'class': 'TimeWindowCompactionStrategy',
  'compaction_window_unit': 'DAYS',
  'compaction_window_size': 7
};

ALTER TABLE user_profiles WITH compaction = {'class': 'LeveledCompactionStrategy'};
Reminder: Changes are table-level. Observe CPU and I/O after applying to ensure your cluster can absorb compaction work.
