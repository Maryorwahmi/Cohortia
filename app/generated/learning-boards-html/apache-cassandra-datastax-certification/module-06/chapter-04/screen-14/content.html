Module 6 › Chapter 6.4 › Monitoring
Key nodetool commands
nodetool cfstats
nodetool tpstats
Interpret counts: many SSTables per read indicates compaction or write pattern issues; high tombstone counts indicate deletes accumulating.
Practical check sequence
  1. Run cfstats and note SSTable and tombstone counts.
  2. Run tpstats to check compaction and flush activity.
  3. Examine gc.log if GC pauses are suspected.
  4. Decide: compaction strategy change, JVM tuning, or I/O upgrade.
