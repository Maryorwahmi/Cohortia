How leveled compaction works
  • SSTables are arranged into levels with size targets.
  • Compaction keeps overlap at each level minimal.
  • Reads touch fewer SSTables, improving predictability.
When to use

Use LCS for read-heavy tables like user_profiles where low and predictable read latency is a priority. Ensure CPU and I/O capacity can absorb increased compaction work.

Misconception: LCS will always reduce disk usage immediately. In practice, it can cause short-term overhead before steady-state improvements appear.
