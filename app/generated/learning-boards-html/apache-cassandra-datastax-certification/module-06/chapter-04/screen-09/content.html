How TWCS groups data

TWCS assigns SSTables to time windows, compacting only within windows. This avoids merging recent and very old data together, reducing unnecessary compaction overhead on stable historical data.

Concrete configuration
WITH compaction = {
  'class': 'TimeWindowCompactionStrategy',
  'compaction_window_unit': 'HOURS',
  'compaction_window_size': 6
};
Pitfall: TWCS performs poorly when writes are out of order across windows or when old data is frequently updated.
