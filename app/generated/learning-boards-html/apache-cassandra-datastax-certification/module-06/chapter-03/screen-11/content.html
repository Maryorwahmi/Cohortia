Hands-on Activity Simulate Data Flow

A safe staging checklist

Steps
  1. Inspect sink.properties and note topics, contactPoints, keyspace, and field mappings.
  2. Publish representative JSON messages to each topic and observe connector logs for parsing errors.
  3. Query Cassandra tables to verify rows were written and columns populated as expected.
  4. Run Spark aggregation against a small dataset and write results back, checking write.mode behavior.
Example prompt

Add a topic order_events mapped to orders_by_customer and map customer_id, order_id, order_total fields accordingly. Test with a few sample messages.

Key Takeaway

Work in staging, validate mappings, and test connectors and Spark jobs with representative data to avoid surprises in production.
