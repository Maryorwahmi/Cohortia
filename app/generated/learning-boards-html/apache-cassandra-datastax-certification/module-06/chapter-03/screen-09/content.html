Read, aggregate, write

Scala example (conceptual)
import org.apache.spark.sql.SparkSession

val spark = SparkSession.builder()
  .appName("CassandraSparkIntegration")
  .config("spark.cassandra.connection.host", "cassandra-node1")
  .config("spark.cassandra.connection.port", "9042")
  .getOrCreate()

val sensorReadingsDF = spark.read
  .format("org.apache.spark.sql.cassandra")
  .options(Map("table" -> "sensor_readings", "keyspace" -> "iot_data"))
  .load()

val avgTempPerSensor = sensorReadingsDF
  .groupBy("sensor_id")
  .avg("temperature")

avgTempPerSensor.write
  .format("org.apache.spark.sql.cassandra")
  .options(Map("table" -> "avg_sensor_temps", "keyspace" -> "iot_data"))
  .mode("append")
  .save()
Notes & pitfalls
  • Use append to add results, overwrite to replace — choose based on desired behavior.
  • Ensure connector jar is available to Spark and network access to Cassandra is configured.
  • Test with small partitions and confirm pushdown is active to avoid full table reads.
Check your understanding

If sensor_readings included a location column, group by sensor_id and location to compute averages per location as needed.
