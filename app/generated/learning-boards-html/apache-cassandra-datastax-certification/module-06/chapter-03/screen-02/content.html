Learning Objectives

Build practical skills to integrate Cassandra with streaming and analytics tools.

01
Identify integration patterns

Recognize when to use streaming versus batch and how Cassandra participates in each. This matters for latency, throughput, and design trade-offs.

VERIFIED COMPETENCY MILESTONE
02
Understand Kafka for ingestion

Explain Kafka topics, producers, consumers, and why Kafka Connect links Kafka and Cassandra in real-time pipelines.

VERIFIED COMPETENCY MILESTONE
03
Explore Spark Cassandra Connector

Describe how Spark reads and writes Cassandra efficiently and how predicate pushdown and data locality improve performance.

VERIFIED COMPETENCY MILESTONE
04
Implement basic data flows

Map Kafka topic fields to Cassandra columns, test connector configs, and reason about schema evolution to avoid ingestion failures.

VERIFIED COMPETENCY MILESTONE
