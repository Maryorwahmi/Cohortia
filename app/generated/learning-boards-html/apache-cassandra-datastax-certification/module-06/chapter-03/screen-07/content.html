Comparison Source vs Sink

Which connector for your flow?

Direction matters: exporting from Cassandra has different constraints than ingesting into Cassandra.

Sink Connector (Kafka → Cassandra)
  • Common for ingesting real-time events into Cassandra tables.
  • Requires careful field mapping and write idempotency handling.
  • Good for event-driven architectures and dashboards.
Source Connector (Cassandra → Kafka)
  • Used to stream changes from Cassandra to Kafka for downstream systems.
  • May require CDC or custom change detection logic.
  • Useful for audits, backups, or feeding analytics that prefer Kafka topics.
Design considerations
Decide direction early and document primary keys and expected message order. Consider how out-of-order events and retries will affect Cassandra's state.
Test connectors with representative load and message shapes to find mapping or ordering issues before production.
