ETL tools and language drivers

ETL (JDBC/ODBC)

Useful for batch archival and reporting. Not ideal for high-volume real-time ingestion where Kafka shines.

Use case: nightly loads into a warehouse where latency is minutes or hours.
Language drivers & custom integration

App-level access via drivers lets applications read and write directly. Custom connectors allow tailored behavior but require operational care.

Operational considerations
  • Plan for schema evolution, connector updates, and connector task scaling.
  • Design for idempotent writes or handle duplicates in consumers.
  • Test for backpressure and use buffer or scaling strategies when needed.
