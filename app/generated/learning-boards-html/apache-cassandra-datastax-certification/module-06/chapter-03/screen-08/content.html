Core Concept Spark Cassandra Connector

Connector benefits for analytics

Read and write Cassandra data from Spark while minimizing unnecessary data transfer.

Optimizations
  • Predicate pushdown sends filters to Cassandra so only necessary rows are returned.
  • Data locality encourages Spark tasks to run near the Cassandra data to reduce network overhead.
  • Use connector options to tune parallelism and fetch sizes for large reads.
Concrete example

Read sensor_readings, compute average temperature per sensor, and write results back to avg_sensor_temps. Use filters to limit time ranges to enable pushdown.

Key Takeaway

Optimize Spark jobs by enabling predicate pushdown and aligning partitioning to avoid full table scans.
