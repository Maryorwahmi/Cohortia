Hands-on Activity

Activity steps

  1. Sign into Astra DB and create a serverless database. Choose cloud and region.
  2. Download the secure connect bundle and create a DB user; store credentials securely.
  3. Install the DataStax-enabled driver for cqlsh on your machine.
  4. Connect with cqlsh using Client ID, Secret, and bundle. Run CQL to create keyspace/table and insert data.
  5. Verify with SELECT and review usage metrics in the console.
Example verification
After connecting, create products_ks with NetworkTopologyStrategy, create a products table, insert two rows, and run SELECT to confirm results.
Check your understanding
If SELECT returns no rows after INSERT, check credentials, bundle path, and keyspace selection before troubleshooting further.
Key Takeaway

Follow the provisioning-to-verification flow and secure credentials to confirm a working Astra DB instance.
