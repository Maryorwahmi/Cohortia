Process Flow

Provisioning steps

  1. Create a serverless database in the Astra console and choose cloud + region.
  2. Wait for the database to become active, then download the secure connect bundle ZIP file.
  3. Create a database user and record the Client ID and Client Secret securely.
  4. Unzip the bundle locally and use cqlsh or a driver with the bundle and credentials to connect.
  5. Run a quick CREATE KEYSPACE / CREATE TABLE / INSERT / SELECT to validate.
Concrete example
Name the instance meaningfully, for example myfirstastradb, then download secure-connect-myfirstastradb.zip and create a user for development access.
Pro tip
Store Client ID and Secret in a secrets manager and rotate them periodically. Do not embed them in code repositories.
Key Takeaway

Provisioning is fast; the secure connect bundle plus credentials are required for secure client connections.
