Code Walkthrough

Connect with cqlsh

Install the DataStax-enabled driver and call cqlsh with your Client ID and Secret, pointing to the secure connect bundle.

# Example: connecting to Astra DB with cqlsh
# 1. Download secure-connect-mydb.zip and unzip if needed
# 2. Install the driver that supports Astra connectivity
#    pip install cassandra-driver[datastax-astra]
# 3. Connect using the secure connect bundle path
cqlsh -u <YOUR_ASTRA_CLIENT_ID> -p <YOUR_ASTRA_CLIENT_SECRET> -b /path/to/secure-connect-mydb.zip

# Once connected you can run CQL commands like:
CREATE KEYSPACE IF NOT EXISTS myapp_keyspace WITH replication = {'class': 'NetworkTopologyStrategy', 'datacenter1': 3};
USE myapp_keyspace;
Concrete example
Use your downloaded secure-connect-mydb.zip with the cqlsh command, replacing placeholders with your Client ID and Secret.
Common mistake
Forgetting to install the DataStax connector or passing the wrong bundle path causes authentication failures; check both first.
Key Takeaway

The secure connect bundle and DB user credentials are required to authenticate cqlsh to Astra DB.
