Definition

Secure Connect Bundle

A ZIP file containing certificates and client connection metadata used to authenticate and encrypt connections to Astra DB.

Contains TLS certs and endpoints for your database.
Paired with Client ID and Client Secret for authentication.
Do not expose in public repositories.
Practical rule
Store bundle and credentials in a secrets manager. Rotate credentials if exposed and reissue access.
Common mistake
Using the wrong bundle for a database or sharing client secrets across projects causes auth failures and security risks.
Key Takeaway

Handle bundles and credentials like any secret: secure storage, limited exposure, and credential rotation.
