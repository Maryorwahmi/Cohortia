Learning Objectives

Four practical skills to provision, connect, operate, and evaluate Astra DB for real projects.

Bloom: Learn → Understand → Apply → Master
01
Understand Astra DB architecture

Explain serverless, managed Cassandra, multi-cloud deployment, and why operational overhead is reduced.

Verified competency milestone
02
Provision and connect

Create a serverless DB, download the secure connect bundle, and generate credentials for client connections.

Verified competency milestone
03
Run basic CQL operations

Use cqlsh or drivers to create keyspaces and tables, insert rows, and verify reads in Astra DB.

Verified competency milestone
04
Evaluate use cases

Identify scenarios where managed Astra DB reduces risk and time-to-market versus self-managed Cassandra.

Verified competency milestone
