Learning Objectives
Bloom levels: Learn → Understand → Apply → Master
LearnMaster
Verified Competency Milestones below
01
Design a DR plan for Cassandra
You will list RTO/RPO goals, candidate backup locations, and recovery steps for node and datacenter failures. This matters because a plan turns recovery knowledge into repeatable actions during an incident.
VERIFIED COMPETENCY MILESTONE
02
Implement snapshot backups
You will run nodetool snapshot, list and clear snapshots, and copy snapshot files to remote storage. This prevents local-only backups from being lost in a site failure.
VERIFIED COMPETENCY MILESTONE
03
Configure auth and RBAC
You will enable password authentication and create roles with minimal permissions so applications cannot perform administrative actions. Least privilege reduces blast radius from compromised credentials.
VERIFIED COMPETENCY MILESTONE
04
Enable encryption and auditing
You will understand TLS for clients and nodes, at-rest encryption options, and the role of auditing logs for compliance. These controls protect data confidentiality and trace access.
VERIFIED COMPETENCY MILESTONE
