Auditing

Track administrative and data access

Enable auditing to capture who changed roles, who granted permissions, and who accessed sensitive tables. Use logs in your SIEM for alerts and periodic reviews.

• Log schema and role changes for compliance.
• Monitor unusual activity like mass permission grants or unexpected superuser logins.
• Retain audit logs according to your compliance policy and secure them separately from Cassandra backups.
DR Drill

A repeatable recovery checklist

  1. Provision nodes in target region and apply configuration.
  2. Retrieve the verified off-site snapshot manifest and copy files onto each node.
  3. Clear commit logs if appropriate, start nodes, then run nodetool refresh and nodetool repair as needed.
  4. Validate by running schema checks, sample queries, and application smoke tests.
After Action

Document time taken for each step, failure points, and any missing credentials. Update the runbook to close these gaps.
