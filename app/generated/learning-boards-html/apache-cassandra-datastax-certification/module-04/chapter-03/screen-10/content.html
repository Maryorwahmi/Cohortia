ALERT

ALLOW FILTERING

Using ALLOW FILTERING forces expensive scans. Its presence typically means you need a new table keyed for that filter pattern.

Wide Rows

Extremely large partitions increase compaction and memory pressure. Break up data or use time-windowed partitions.

Hot Partitions

Uneven traffic on a few keys creates bottlenecks. Choose partition keys with high cardinality to distribute load evenly.

Refactor checklist
  • Does the query use ALLOW FILTERING? Create a new table.
  • Are partitions growing without bound? Consider sharding by time.
  • Are a few keys receiving most traffic? Add entropy or change partitioning.
