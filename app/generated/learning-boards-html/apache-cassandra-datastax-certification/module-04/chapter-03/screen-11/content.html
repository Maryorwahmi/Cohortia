Module 4 › Chapter 4.3 › Consistency Strategies
Options
Batches
Use Cassandra batches to update multiple tables atomically when touching a bounded set of partitions. Useful for small, related updates.
Application propagation
Have the application write denormalized copies at insertion time and propagate updates to duplicates when authoritative data changes.
Reconciliation jobs
Run background jobs to detect and repair stale denormalized values periodically.
Guidance

Decide based on how critical immediate consistency is. For user display names, eventual consistency is often acceptable. For billing or legal fields, prefer stronger coordination.

Key Takeaway

Choose an update pattern that balances user expectations for freshness with system complexity and operational cost.
