Insert statements populate each table with the denormalized fields needed for display.
Sample Selects
SELECT article_title, publish_date FROM articles_by_author WHERE author_id = a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11;
SELECT user_name, comment_text FROM comments_by_article WHERE article_id = b0eebc99-9c0b-4ef8-bb6d-6bb9bd380a12;
SELECT activity_type, related_article_title FROM user_activity_feed WHERE user_id = c0eebc99-9c0b-4ef8-bb6d-6bb9bd380a13;
Each select uses a partition key so Cassandra returns a single partition and clustering order gives the most recent rows first.
Runtime note

When you insert, write denormalized copies for every table that needs that data. This ensures reads are cheap and fast.

Check

If a select requires a full scan or ALLOW FILTERING, create a new table to serve that query instead.
