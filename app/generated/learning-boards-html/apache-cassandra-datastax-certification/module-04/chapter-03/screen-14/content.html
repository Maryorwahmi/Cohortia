Module 4 › Chapter 4.3 › Key Concepts
Denormalization
Duplicate fields across tables so a query returns all needed data in one read, avoiding joins across nodes.
Query‑First Approach
Design table schemas based on the queries you must support rather than on normalized entities and relationships.
Read Optimization
Ensure all data needed for a query is available by primary key so reads are fast and predictable.
Summary

Model for queries: accept denormalization when it yields single-table, low-latency reads.
