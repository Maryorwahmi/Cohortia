Module 4 › Chapter 4.3 › Primary Keys
Partition Key

Defines data distribution and the unit of lookup. Choose keys with enough cardinality to avoid hot partitions.

Clustering Columns

Provide ordering and uniqueness within a partition. Use DESC for recent-first timelines.

Examples
posts_by_user: PRIMARY KEY ((user_id), post_timestamp) WITH CLUSTERING ORDER BY (post_timestamp DESC)
comments_by_article: PRIMARY KEY ((article_id), comment_time, comment_id) WITH CLUSTERING ORDER BY (comment_time DESC)
Key Takeaway

Primary keys must mirror the query's partition and ordering needs to make reads efficient and avoid filtering.
