Module 4 › Chapter 4.3 › Assessment
Task

Create orders_by_customer with customer_id as the partition key and order_date as the clustering key. Include customer_name as a denormalized column.

CREATE TABLE orders_by_customer (
  customer_id uuid,
  order_id uuid,
  customer_name text,
  order_date timestamp,
  total_amount decimal,
  PRIMARY KEY ((customer_id), order_date, order_id)
) WITH CLUSTERING ORDER BY (order_date DESC);
When customer_name changes, update orders_by_customer rows for that customer as part of your update strategy.
Assessment criteria
  • Table serves the query in a single read.
  • Clustering order returns newest orders first.
  • Update strategy described for duplicated customer_name.
Key Takeaway

Map relational queries to denormalized tables that return complete results in one read and explain how duplicates will be kept consistent.
