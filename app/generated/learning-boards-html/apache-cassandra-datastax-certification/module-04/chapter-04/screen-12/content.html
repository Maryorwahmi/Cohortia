Module 5 › Chapter 4.4 › Balancing Trade-offs
Questions to answer
  • Which queries must be served under strict latency SLAs?
  • How many tables will each write touch, and what is the write cost?
  • Can some updates be asynchronous with reconciliation later?
Patterns and costs
Use logged batches for small transactional updates; prefer async writes and background reconciliation for high-throughput paths. Track storage overhead and operational complexity as part of design acceptance.
Key Takeaway

Make schema choices with explicit trade-offs: read latency versus write cost and operational effort.
