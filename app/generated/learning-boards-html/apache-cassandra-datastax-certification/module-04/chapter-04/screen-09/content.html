Why collections fail at scale
  • Every update can rewrite the entire collection, causing write amplification.
  • Large collections inflate row sizes and contribute to wide partitions.
  • Collections are not efficient for frequent append-heavy workloads.
Common anti-pattern
articles table with a LIST> for comments on popular posts.
Correct pattern
Create a comments_by_article table where each comment is a row. Example schema:
CREATE TABLE comments_by_article (
  article_id uuid,
  comment_time timestamp,
  comment_id timeuuid,
  user_id uuid,
  comment_text text,
  PRIMARY KEY ((article_id), comment_time, comment_id)
) WITH CLUSTERING ORDER BY (comment_time DESC);
Key Takeaway

When the number of related items is unbounded, use a table of rows instead of a collection column.
