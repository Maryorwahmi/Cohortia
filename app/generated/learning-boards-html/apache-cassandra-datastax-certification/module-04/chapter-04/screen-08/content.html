Module 5 › Chapter 4.4 › Modeling Relationships
Recommended tables
users_by_id
PRIMARY KEY (user_id) — profile lookups.
groups_by_id
PRIMARY KEY (group_id) — group metadata.
users_by_group
PRIMARY KEY ((group_id), user_id) — list members of a group.
groups_by_user
PRIMARY KEY ((user_id), group_id) — list groups for a user.
Consistency patterns
  • Use logged batches for multi-table atomic writes when atomicity is required.
  • For high-throughput paths, use asynchronous updates and reconciliation jobs to repair drift.
  • Design idempotent writes so retries are safe and reconciliation is straightforward.
Example scenario

When adding a user to a group, write both users_by_group and groups_by_user; use a batch for atomicity if immediate consistency is required.
