Module 5 › Chapter 4.4 › Secondary Indexes
When to use
Low-cardinality columns where indexed values are selective and result sets are small. Examples include small enumerations like status or region codes.
When to avoid
High-cardinality fields or queries that return many rows. Instead, create a dedicated table keyed by the field you need to query.
Operational note

Secondary-index queries involve coordinator fan-out; measure and avoid coordinator saturation for frequent, non-selective queries.
