Module 5 › Chapter 4.4 › Practice Outcomes
Practical tasks
  • Design denormalized tables for many-to-many relationships and plan application-level consistency.
  • Refactor unbounded collections into per-item rows with clustering keys for ordering.
  • Implement and test bucketing for time-series data to limit partition growth.
  • Apply salting or hashing to mitigate hot partitions and evaluate query complexity trade-offs.
Assessment
Explain and defend

You will justify schema choices and identify which anti-patterns cause operational risk.
