Query collections and UDTs
Select elements, dot-notation for UDT fields, and map lookups by key.
Mnemonic: point-and-select the exact piece you need.
VERIFIED COMPETENCY MILESTONE
02
Manage update costs
Recognize when collection changes will rewrite whole columns and create tombstones.
Mnemonic: small, seldom-updated collections are safer.
VERIFIED COMPETENCY MILESTONE
03
Avoid deep nesting
Use UDTs sensibly; prefer flattening or separate tables for frequently queried subfields.
Mnemonic: nest for clarity, not for heavy independent queries.
VERIFIED COMPETENCY MILESTONE
04
Use static columns deliberately
Choose static when a value truly applies to the whole partition and updates are infrequent or acceptable.
Mnemonic: one value per partition, updated once if needed.
