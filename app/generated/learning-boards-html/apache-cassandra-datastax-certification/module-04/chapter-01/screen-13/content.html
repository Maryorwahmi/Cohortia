Question 1 — Favorite books
Which design stores ordered book entries where each element contains title and author?
Correct: LIST<frozen<tuple<text, text>>> because it preserves order and keeps title-author together as an atomic element.
Question 2 — Static column benefit
What is the main advantage of declaring a column STATIC for a composite primary key table?
Answer: It stores a single value per partition shared by all clustering rows, reducing duplication and simplifying reads for partition-level attributes.
Design checklist
  • Is the collection bounded and updated infrequently?
  • Do grouped fields belong together logically and are they usually read together? Use UDTs.
  • Does the value apply to the whole partition? Consider STATIC.
