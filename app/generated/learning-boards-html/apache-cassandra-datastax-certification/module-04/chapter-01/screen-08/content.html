Module 4 › Chapter 4.1 › FROZEN Keyword
What frozen does
Frozen marks a composite type as an indivisible value. Updates replace the entire composite rather than parts of it. Cassandra requires frozen for UDTs or tuples used inside collections.
-- frozen UDT and frozen tuple example delivery_address frozen<address> items list<frozen<tuple<text, int, decimal>>>
Best practice: freeze composite elements when they are treated as a single unit; avoid freezing when you need frequent partial updates.
Concrete scenario
If you store a list of product tuples, freezing each tuple means updating quantity requires replacing the tuple entirely. This simplifies consistency but increases write sizes for frequent partial changes.
Check
Do you need to update inner fields often? If yes, avoid frozen; if no and you prefer atomicity, use frozen.
