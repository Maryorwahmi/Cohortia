Module 4 › Chapter 4.1 › Key Concepts
LIST
Ordered sequence, allows duplicates; use for bounded ordered data.
SET
Unordered and unique values; ideal for tags and role lists.
MAP
Key-value pairs for flexible attributes; lookup by key supported in queries.
Summary takeaway

Pick the collection type that matches the data semantics, keep sizes bounded, and prefer separate tables for unbounded or frequently updated elements.
