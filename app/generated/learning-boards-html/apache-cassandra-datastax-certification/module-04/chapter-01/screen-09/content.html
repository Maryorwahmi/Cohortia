Module 4 › Chapter 4.1 › Static Columns
Definition
Static columns store a single value per partition and are shared by all clustering rows for that partition key. They are useful for partition-level metadata.
-- static column example CREATE TABLE user_posts ( user_id uuid, post_id timeuuid, user_name text STATIC, post_content text, PRIMARY KEY ((user_id), post_id) );
Tip: Only mark a column static if the value truly applies to the whole partition and updates are acceptable at partition scope.
Behavior note
A static update will be visible to reads across all clustering rows in the same partition. It reduces storage duplication but does not make updates free.
Analogy
Think of a static column as a header printed once for a folder containing many pages; the header applies to every page inside.
