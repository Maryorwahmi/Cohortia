Module 5 › Chapter 5.3 › debug.log — deep dives with caution
Definition

debug.log

Verbose internal trace logs for query execution, gossip, and thread-level details used for deep troubleshooting.

When to enable
  • Target a specific suspected component or query pattern.
  • Limit time window and nodes to avoid excessive data.
  • Stream logs to a central aggregator where possible.
Caution

debug.log can quickly fill disks and affect performance. Never enable it globally in production for long periods.

Practical tip

Enable debug, collect the traces, then disable. Use host-level disk alerts and central logging to keep control.

Key Takeaway

Debug logging is powerful but expensive; use it only when system.log and metrics leave unanswered questions.
