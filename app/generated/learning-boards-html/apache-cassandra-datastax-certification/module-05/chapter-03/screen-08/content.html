Module 5 › Chapter 5.3 › Diagnosing a WriteTimeoutException
One-sentence

WriteTimeout troubleshooting

Follow timestamps, inspect coordinator and replica logs, then use nodetool to find backpressure or GC issues.

Step check list
  1. Check system.log on coordinator and replicas for timeout messages.
  2. Run nodetool tpstats to inspect MutationStage pending tasks.
  3. Run nodetool netstats to find pending messages.
  4. Check gc.log for long GC pauses during the time window.
  5. Examine disk I/O and compaction activity for saturation.
Concrete example

If system.log shows 'Timeout while waiting for replica' on the coordinator and tpstats shows a high pending count for MutationStage on a replica, that replica is likely overwhelmed and causing the timeout.

Common pitfall

Assuming network only: often GC pauses or disk saturation are the real cause. Correlate across logs and metrics before concluding.

Key Takeaway

A write timeout is a symptom; logs and nodetool data across nodes reveal whether it is overload, GC, network, or disk related.
