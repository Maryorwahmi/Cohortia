Module 5 › Chapter 5.3 › gc.log — diagnosing JVM pauses
Definition

gc.log

Records garbage collection cycles: type, memory reclaimed, heap sizes, and pause durations that impact Cassandra latency.

Sample lines
[Full GC (Allocation Failure) 100M->10M(200M), 2.543 secs]
[GC pause (G1 Evacuation Pause) 20ms] Young collection statistics...
What it means

Full GC entries with multi-second pauses are stop-the-world events that block Cassandra threads and cause client timeouts.

Remedies
  • Review heap settings (-Xmx) and GC algorithm choices.
  • Tune GC parameters or consider more nodes to reduce per-node pressure.
  • Investigate memory leaks or heavy allocations in application UDFs or UDA.
Key Takeaway

gc.log gives the evidence you need to decide whether to tune heap, GC settings, or scale out.
