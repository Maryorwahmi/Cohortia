Process Flow

Repeatable checklist

1. Capture the symptom
Record timestamps, client errors, and affected endpoints so logs can be searched precisely.
2. Check system.log
Search for correlating warnings and errors on coordinator and replica nodes.
3. Run nodetool
Use tpstats, netstats, and status to inspect pending tasks, message queues, and node state.
4. Enable targeted debug
If necessary, enable debug for a short window and collect output centrally, then disable.
5. Inspect gc.log
Look for long GC pauses that align with client timeouts or latency spikes.
6. Remediate and monitor
Take corrective action and continue monitoring to confirm resolution.
Key Takeaway

A consistent troubleshooting flow reduces noise and leads to faster, reliable fixes.
