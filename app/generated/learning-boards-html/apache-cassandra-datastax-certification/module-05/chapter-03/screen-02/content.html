Learning Objectives

Build diagnostic skills and safe logging practices for Cassandra operations.

Bloom: Learn → Understand → Apply → Master
01
Identify Logs
Locate system.log, debug.log, gc.log

Recognize each file's purpose and why it matters during incidents. Use a simple Venn visual: system for events, debug for deep tracing, gc for JVM.

VERIFIED COMPETENCY MILESTONE
02
Interpret Messages
Read common errors and warnings

Translate messages like WriteTimeoutException or compaction failures into likely causes, and know what to check next.

VERIFIED COMPETENCY MILESTONE
03
Troubleshoot Systematically
Follow a repeatable flow

Start with symptoms, correlate timestamps, run nodetool checks, and enable debug logging only when needed to avoid noise and disk pressure.

VERIFIED COMPETENCY MILESTONE
04
Manage Retention
Rotate and archive logs

Configure log4j2 rolling appenders or centralize logs to prevent disk exhaustion from large debug output.

VERIFIED COMPETENCY MILESTONE
