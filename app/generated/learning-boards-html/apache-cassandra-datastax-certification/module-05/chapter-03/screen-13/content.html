Key nodetool commands

Use these commands near the incident time to correlate with log entries.
tpstats
Shows thread pools and pending tasks; look for MutationStage backlog during write timeouts.
netstats
Shows pending messages and streaming; useful to detect network or messaging bottlenecks.
status
Confirms cluster membership and live/down nodes to ensure topology is stable.
Practical note

Capture nodetool output while the issue is occurring. Correlate timestamps with system.log and gc.log to build an accurate incident timeline.

Key Takeaway

Nodetool metrics validate hypotheses from logs and point to specific resource bottlenecks to fix.
