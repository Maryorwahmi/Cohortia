Learning Objectives

Practical skills and knowledge you will apply immediately.

Bloom: Learn → Understand → Apply → Master
01
Explain why regular backups matter

Describe data integrity and disaster recovery needs in distributed Cassandra clusters and set backup cadence accordingly.

Mnemonic: Timeline -> snapshot points
VERIFIED COMPETENCY MILESTONE
02
Differentiate snapshot vs incremental

Recognize when to use a full snapshot and when incremental backups provide better RPO with lower transfer size.

Mnemonic: Snapshot = point-in-time link; Incremental = stream of new files
VERIFIED COMPETENCY MILESTONE
03
Perform nodetool snapshot

Run nodetool snapshot for a keyspace or table and optionally name the snapshot for later retrieval.

Mnemonic: nodetool snapshot -t name
VERIFIED COMPETENCY MILESTONE
04
Implement incremental backups

Enable incremental_backups in cassandra.yaml, restart, and copy the backups directory to off-cluster storage on a schedule.

Mnemonic: Base snapshot + incremental stream
VERIFIED COMPETENCY MILESTONE
