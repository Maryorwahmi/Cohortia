Module 5 › Chapter 5.4 › Snapshot
Definition

Snapshot = point-in-time hard links

A snapshot creates hard links to the SSTables present when the snapshot was taken. This provides a consistent backup image with minimal initial storage cost.

Key takeaway

Snapshots must be copied off-cluster to be durable beyond the node's lifetime.

How it looks on disk
Path
data_file_directories/<keyspace>/<table>/snapshots/<snapshot_name>
Behavior
Hard links point to existing SSTables; originals cannot be deleted until snapshot removed.
Misconception
A snapshot is not a separate copy until you copy files off the node; it's a link to existing files.
Practical tip
After snapshotting, immediately copy snapshot directories to off-cluster storage to ensure durability.
