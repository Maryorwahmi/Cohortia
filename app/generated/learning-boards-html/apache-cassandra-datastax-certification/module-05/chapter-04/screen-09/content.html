Module 5 › Chapter 5.4 › Enable incremental backups
Configuration

Edit cassandra.yaml

Set incremental_backups: true and restart the node to begin hard-linking new SSTables into backups directories.

Operational steps
  1. Edit cassandra.yaml and set incremental_backups: true.
  2. Restart Cassandra to apply the change.
  3. Schedule periodic copying of backups directories to off-cluster storage.
Limitations
  • Incremental backups only capture SSTables created after enabling.
  • They do not capture in-place changes to existing SSTables.
  • A base snapshot is still required to restore completely.
Key takeaway
Enable incremental backups as part of a combined strategy: snapshot base + incremental stream + off-cluster copy.
