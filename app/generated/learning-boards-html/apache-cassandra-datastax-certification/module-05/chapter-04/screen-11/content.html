Module 5 › Chapter 5.4 › Refresh & Repair
nodetool refresh

After copying SSTables into the data directory, run nodetool refresh <keyspace> <table> to make files visible without a full rebuild.

Tip
Refresh is fast and file-level; it simply registers new SSTables with Cassandra.
nodetool repair

After refresh, run nodetool repair to ensure the restored node receives any missing writes and that tombstones are propagated, avoiding data inconsistencies.

Caution
Repair can be time-consuming; include it in recovery time estimates and plan maintenance windows accordingly.
Misconception check
Refreshing files alone does not restore cluster-wide correctness. Repair is required to reconcile state with other replicas and to ensure deletions are respected cluster-wide.
