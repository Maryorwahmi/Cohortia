Module 5 › Chapter 5.4 › Snapshots vs Incremental
Snapshot
  • Point-in-time hard links to SSTables.
  • Good for full baseline backups before risky changes.
  • Requires off-cluster copy to be durable.
Watch out
Snapshots prevent deletion of referenced SSTables, increasing disk usage if not managed.
Incremental backups
  • Hard-links new SSTables into backups after flush.
  • Useful for frequent, smaller transfers to off-cluster storage.
  • Requires a base snapshot and careful restore ordering.
Best used
When you need frequent recovery points but want to control transfer volume.
Key takeaway
Combine both: take a snapshot as a base, enable incrementals, copy both to off-cluster storage, and test restores regularly.
