Backup and Restore Strategies

Learn how Cassandra snapshots and incremental backups provide point-in-time protection and continuous file-level backups, and how to restore nodes reliably.

In this lesson
Snapshots, incremental backups, off-cluster copy, restore steps, repair.
Snapshots
Point-in-time hard-linked SSTable copies suitable for full backups.
Incremental
Continuous backup of new SSTables into backups directories.
Restore
Copy files back, run refresh, then repair to reconcile replicas.
Quick Orientation

We will alternate explanation and a terminal-based hands-on demo. Practice the commands, copy snapshot files off-cluster, and test a restore in a safe environment.

Visual concept
Snapshot (hard links)
Links to SSTables preserve a point-in-time set without copying immediately. Manage snapshots to avoid disk growth.
Incremental backups
New SSTables are hard-linked into backups directories after flush; copy them off-cluster regularly.
Restore flow
Stop Cassandra, clear data, copy snapshot + incrementals, start, nodetool refresh, nodetool repair.
Topic
