Process Flow

Step-by-step restore checklist

1. Stop Cassandra
Ensure the service is down to avoid file conflicts during copy.
2. Clear data directories
Remove existing files for the target keyspace/table. Do not touch system keyspaces.
3. Copy snapshot files
Copy the base snapshot files from off-cluster storage into the data directory.
4. Copy incremental SSTables
If using incrementals, copy SSTables generated after the base snapshot into the directory.
5. Start Cassandra
Bring the node back online after file copy completes.
6. Run nodetool refresh
Make the copied SSTables visible to Cassandra without a full restart of the data layer.
7. Run nodetool repair
Ensure the node is reconciled with other replicas so tombstones and missing writes are synchronized.
Warning
Skipping repair can lead to inconsistent data and the resurrection of deleted rows. Always plan repair as a final step.
