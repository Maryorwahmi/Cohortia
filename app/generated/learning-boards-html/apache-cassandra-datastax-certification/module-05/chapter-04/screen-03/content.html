Learning Objectives — Safety & Restore

Restore steps, snapshot lifecycle, testing, and common mitigations.

Bloom: Apply → Master
05
Outline restore steps

Stop the node, clear data directories for the keyspace/table, copy snapshots and incrementals back, start, refresh, and repair.

Mnemonic: Stop → Clean → Copy → Start → Refresh → Repair
VERIFIED COMPETENCY MILESTONE
06
Manage snapshots and space

Because snapshots hard-link SSTables, they can prevent deletions and fill disk; schedule snapshot removal and off-cluster copies.

Mnemonic: Snapshot retention → disk planning
VERIFIED COMPETENCY MILESTONE
07
Test your backups

Simulate loss, restore from off-cluster copies, and verify application-level data to ensure backups are valid.

Mnemonic: Practice recovery
VERIFIED COMPETENCY MILESTONE
08
Avoid common pitfalls

Copy snapshots off-cluster, run repair after restores, and manage tombstone lifetimes to avoid resurrecting deleted data.

Mnemonic: Copy → Repair → Validate
VERIFIED COMPETENCY MILESTONE
