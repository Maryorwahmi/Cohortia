Module 5 › Chapter 5.4 › Copy snapshots off-cluster
Why

Durability beyond node failure

Always copy snapshot directories to off-cluster storage. Local snapshots are lost if the node's disk fails.

Disk path example
data_file_directories/<keyspace>/<table>/snapshots/<snapshot_name>
Copy workflow
  • Find snapshot directories after nodetool snapshot.
  • Copy the snapshot contents to off-cluster location (S3 or NFS).
  • Verify file integrity and then remove local snapshot if desired.
Practical commands
> docker exec -it cassandra-backup find /var/lib/cassandra/data/mybackup/products -name "snapshots"
> # then copy snapshot dir contents to off-cluster storage
Common mistake
Not copying snapshots off-cluster leaves your backup vulnerable to node or disk failure.
Tip
Automate snapshot discovery and off-cluster transfer in the same maintenance job that creates the snapshot.
