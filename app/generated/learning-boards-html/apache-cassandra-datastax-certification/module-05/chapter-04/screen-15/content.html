Module 5 › Chapter 5.4 › Key Concepts
Snapshot
Point-in-time, hard-linked copy of SSTables used for full backups.
nodetool snapshot
Command-line utility to create named snapshots for a keyspace or table.
Incremental Backup
Hard-links new SSTables into backups directories; use with a base snapshot to restore.
Takeaway
Combine snapshots and incremental backups, copy files off-cluster, and always run refresh and repair after restores.
