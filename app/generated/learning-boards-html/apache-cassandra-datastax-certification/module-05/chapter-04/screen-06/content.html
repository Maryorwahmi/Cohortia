Process Flow

Use nodetool snapshot

Run nodetool snapshot for a keyspace or table. Use -t to name the snapshot for easier retrieval and off-cluster copy.

Examples
> nodetool snapshot myapp
> nodetool snapshot myapp users
> nodetool snapshot -t my_daily_backup myapp
Important

Snapshot creation makes hard links; it does not transfer files off the node. Always copy snapshot directories to off-cluster storage immediately.

Operational cards
Scope
nodetool snapshot runs on nodes containing the targeted keyspace/table.
Retention
Remove old snapshots to free SSTables that would otherwise be retained.
Common mistake
Assuming snapshot equals off-site backup. Without copying, snapshots are lost if node fails.
Key takeaway

Name snapshots for traceability and script immediate off-cluster copies as part of the process.
