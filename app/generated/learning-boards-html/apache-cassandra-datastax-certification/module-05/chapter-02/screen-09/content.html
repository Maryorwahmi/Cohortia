Module 5 › Chapter 5.2 › JConsole walkthrough
MBean tree navigation
Expand domains like org.apache.cassandra.metrics and org.apache.cassandra.db, then drill down by scope or keyspace to find table attributes.
Example workflow
  1. Connect JConsole to 127.0.0.1:7199.
  2. Open org.apache.cassandra.metrics → ThreadPools → ReadStage.
  3. Observe ActiveTasks, PendingTasks while issuing reads from cqlsh.
Live inspection
Attribute interpretation
Use attribute combinations to reason about cause: PendingTasks + ReadLatency suggests queueing; LiveDiskSpaceUsed + TombstoneCount suggests compaction impacts.
Caution
Avoid executing MBean operations you don't understand. Attributes are safe to read; operations can change state.
