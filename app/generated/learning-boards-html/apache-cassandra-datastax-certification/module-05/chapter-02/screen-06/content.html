Module 5 › Chapter 5.2 › netstats & ring
netstats: messages and streaming
netstats displays pending messages to peers and current streaming operations; pending messages indicate backpressure in replication or gossip.
Example
If netstats shows many pending messages to node B, check node B for network errors, GC pauses, or disk slowness that prevents it from processing messages timely.
ring: token ownership
ring shows token ranges and ownership; imbalanced ownership can concentrate reads/writes on a subset of nodes, producing hot spots.
Combine evidence
Use netstats to find communication issues and ring to see if those nodes own disproportionate token ranges for the affected data.
Key Takeaway
Network and token ownership issues often appear together; correlate netstats, ring, tpstats and tablestats before taking corrective action.
