Module 5 › Chapter 5.2 › Key MBeans & Attributes
ThreadPools (org.apache.cassandra.metrics)
ActiveTasks, PendingTasks, CompletedTasks — detect queuing and processing delays.
ClientRequest metrics
ReadLatency and WriteLatency — client-observed performance indicators.
Table attributes (org.apache.cassandra.db)
LiveDiskSpaceUsed, TombstoneCount, CompactionBytesWritten — table storage and compaction health.
Key Takeaway
Read related MBeans and table attributes together to confirm whether the issue is a hot partition, compaction activity, or an I/O bottleneck.
