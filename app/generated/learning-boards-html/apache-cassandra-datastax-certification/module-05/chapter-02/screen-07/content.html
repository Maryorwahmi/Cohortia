What is JMX?
A Java standard for exposing runtime metrics and management operations as MBeans, organized by domain and scope.
Concrete attribute examples
  • ReadLatency — measured latency for reads.
  • PendingTasks — queued tasks for a thread pool.
  • LiveDiskSpaceUsed — on-disk bytes used by a table.
MBean domains
org.apache.cassandra.metrics
Client latencies, caches, thread pools and aggregated metrics.
org.apache.cassandra.db
Keyspace and table-level attributes like LiveDiskSpaceUsed and TombstoneCount.
Tip
Use the domain names as a quick map when you open JConsole; they guide you to aggregated vs table-specific metrics.
