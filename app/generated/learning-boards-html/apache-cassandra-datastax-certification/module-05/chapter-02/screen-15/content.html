Monitor thread pools
Use tpstats to detect queues and blocked tasks early.
Inspect table metrics
Run tablestats to find per-table hotspots and tombstone issues.
Secure JMX
Always enable authentication, SSL and network controls for production JMX access.
One-line summary

Use nodetool for fast triage, JMX MBeans for deep confirmation, and secure all JMX access in production.
