Learning Objectives
Learn, Understand, Apply, Master — stepwise skills for observability
Bloom: Learn → Understand → Apply → Master
01
Run advanced nodetool commands
Execute tpstats, tablestats, netstats and ring to get a granular CLI view of thread pools, per-table stats, networking and ownership.
VERIFIED COMPETENCY MILESTONE
02
Explain JMX and MBeans
Describe how Cassandra exposes metrics via JMX MBeans and how nodetool maps to those objects for management and monitoring.
VERIFIED COMPETENCY MILESTONE
03
Use JConsole or VisualVM
Connect to a Cassandra node, navigate the MBean tree and read attributes to diagnose latency, queueing and resource usage.
VERIFIED COMPETENCY MILESTONE
04
Identify relevant MBeans and attributes
Recognize domains like org.apache.cassandra.metrics and attributes such as PendingTasks, ReadLatency, and LiveDiskSpaceUsed to act on incidents.
VERIFIED COMPETENCY MILESTONE
