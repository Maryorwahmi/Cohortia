Module 5 › Chapter 5.2 › Enable JMX (lab)
Prepare cassandra-env.sh
Create a small custom cassandra-env.sh to set JMX JVM options used for the lab container.
#!/bin/bash
# Add JMX remote configuration
JVM_OPTS="$JVM_OPTS -Dcom.sun.management.jmxremote.port=7199"
JVM_OPTS="$JVM_OPTS -Dcom.sun.management.jmxremote.ssl=false"
JVM_OPTS="$JVM_OPTS -Dcom.sun.management.jmxremote.authenticate=false"
JVM_OPTS="$JVM_OPTS -Djava.rmi.server.hostname=127.0.0.1"
This example disables auth and SSL for a local lab only. Do not use in production.
Docker run command
Mount the custom file and expose the JMX port so JConsole can connect from your host.
docker run --name cassandra-jmx -p 9042:9042 -p 7199:7199 -v $(pwd)/custom-cassandra-env.sh:/etc/cassandra/cassandra-env.sh -d cassandra:latest
Lab tip
Use 127.0.0.1 binding so the JMX listener is reachable only from the host machine for the lab.
