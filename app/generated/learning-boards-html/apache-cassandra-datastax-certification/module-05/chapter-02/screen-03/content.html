Objective Deep Dive
Nodetool practice
Run tpstats to check thread pools and tablestats for per-table metrics. Mnemonic: TP = Thread Problems; TS = Table Stats.
JMX connection practice
Enable JMX in a local environment, connect JConsole, and observe MBean attributes while generating load from cqlsh.
MBean identification
Use domains like org.apache.cassandra.metrics for aggregate metrics and org.apache.cassandra.db for keyspace/table attributes.
Security checklist
In production, enable JMX authentication and SSL and restrict access to trusted hosts; do not expose the port publicly.
