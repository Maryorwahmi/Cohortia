Module 5 › Chapter 5.2 › Lab: cqlsh load
Step sequence
  1. Create a keyspace and table in cqlsh.
  2. Run an insert loop to generate writes.
  3. Run concurrent selects to generate reads.
  4. Watch ReadLatency, WriteLatency and PendingTasks in JConsole.
Example cqlsh snippet
-- create a simple keyspace and table
CREATE KEYSPACE IF NOT EXISTS lab WITH REPLICATION = {'class': 'SimpleStrategy', 'replication_factor': 1};
CREATE TABLE IF NOT EXISTS lab.users (id uuid PRIMARY KEY, name text);
Observe
What to watch
PendingTasks, ReadLatency, WriteLatency and per-table LiveDiskSpaceUsed as the data grows.
Misconception
Do not assume instant reflection of every single query. Many metrics are aggregated; look for trends and correlated changes across attributes.
