Tombstones & compaction

Visual concept
Metric flow
Node status → Latency → Tombstones → Compaction
Think of metrics as a pipeline: node availability enables reads, latency measures responsiveness, tombstones influence how much work reads must do, and compaction keeps tombstones and SSTable count manageable.
