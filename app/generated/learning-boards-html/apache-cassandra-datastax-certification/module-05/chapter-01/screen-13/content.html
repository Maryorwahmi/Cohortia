Starter commands
docker run --name cassandra-node1 -p 9042:9042 -d cassandra:latest

docker exec -it cassandra-node1 bash

# inside container
nodetool status
nodetool info
nodetool compactionstats
nodetool cfstats
Then use cqlsh to create a keyspace and table, insert rows, update, delete, and re-run cfstats to observe the tombstone and latency changes.
CQL example
CREATE KEYSPACE myapp WITH replication = {'class': 'SimpleStrategy', 'replication_factor': 1};
USE myapp;
CREATE TABLE users (
  user_id UUID PRIMARY KEY,
  username TEXT,
  email TEXT,
  created_at TIMESTAMP
);
INSERT INTO users (user_id, username, email, created_at) VALUES (uuid(), 'alice', 'alice@example.com', toTimestamp(now()));
DELETE FROM users WHERE user_id = ...;
After running these operations, re-run nodetool cfstats and compare the Tombstone Count and Read Latency before and after.
Lab tip
Allow a short interval after operations for background processes, then re-check compactionstats and cfstats. Collect outputs into a time-series system to visualize changes over time.
