Typical nodetool info
ID                    : b1a2c3d4-0000-0000-0000-abcdef123456
Gossip active          : true
Thrift active          : false
Native Transport active: true
Load                  : 120.53 GB
Uptime (seconds)      : 86400
Heap Memory (used)    : 1.2 GB
These fields provide runtime and resource context that help explain latency and stability issues.
Guided interpretation
Heap usage
High heap can indicate GC pressure; check GC logs and latency percentiles.
Load
Shows disk usage; low free disk impairs compaction and can increase read latency.
Versions
Storage and native transport versions should be consistent during rolling upgrades.
Quick action: if heap or disk is abnormal, collect logs and monitor GC traces and disk I/O before performing restarts.
