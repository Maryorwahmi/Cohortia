Mnemonic
STATUS → LATENCY → TOMBSTONES → COMPACTION
Think of the sequence as a pipeline: node availability enables reads, latency measures responsiveness, tombstones add read work, and compaction reduces that work over time.
Verified Competency Milestone

Run nodetool status and cfstats on a node and explain three fields that indicate a healthy or unhealthy state.
