Practice Tasks
Concrete steps you will perform to validate each skill.
Task: Collect status and info
Run nodetool status and nodetool info on a node to see topology, datacenter, rack, and simple runtime statistics.
Task: Measure latency percentiles
Capture median, 95th, and 99th percentile values from cfstats to detect tail latency issues.
Task: Tombstone experiment
Insert, update, and delete sample rows then re-run cfstats to observe tombstone count and ratio changes.
Quick mnemonic
Observe, Compare, Baseline
Observe metrics now, compare new readings to a baseline, and add alerts for deviations that matter to your application.
