Module 6 › Chapter 5.5 › Key Concepts
nodetool cleanup
Removes data a node no longer owns after token ranges change; use it after node joins or removals.
nodetool decommission
Gracefully removes a healthy node by streaming its data to other replicas before exit.
GC Tuning
Make incremental JVM changes, monitor gc.log, and correlate pauses with latency before broad rollouts.
Final takeaway

Safe, repeatable sequences—bootstrap, repair, cleanup, and measured GC tuning—are the foundation of long-term cluster health and predictable performance.
