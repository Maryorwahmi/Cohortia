Learning Objectives

Learn, understand, apply, and prepare to maintain a production Cassandra cluster.

Bloom: Learn → Understand → Apply → Master
01
Perform routine maintenance
Run compaction and repair, interpret nodetool output, and schedule heavy tasks safely.
Verified Competency Milestone
02
Add and remove nodes safely
Configure seeds, allow auto_bootstrap, stream data, then cleanup or decommission as required.
Verified Competency Milestone
03
Manage data center topology
Expand or contract data centers with proper rack and dc configuration and seed planning for cross-DC communication.
Verified Competency Milestone
04
Tune garbage collection
Adjust JVM flags gradually, review gc logs, and monitor pause times to avoid long interruptions.
Verified Competency Milestone
