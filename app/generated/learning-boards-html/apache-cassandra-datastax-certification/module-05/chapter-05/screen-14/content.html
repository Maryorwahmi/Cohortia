Module 6 › Chapter 5.5 › Key Concepts
nodetool compact
Manual compaction trigger; use sparingly and monitor compactionstats during execution.
nodetool repair
Synchronizes replicas using Merkle trees; scope repairs and run sequentially to reduce load.
Merkle Tree
Hash tree used by repair to compare token ranges efficiently and stream only differences.
Summary

These commands and structures form the core maintenance toolkit: control compaction, schedule scoped repairs, and rely on Merkle trees to minimize repair work.
