Objectives: examples, pitfalls, and verification

When to run manual compaction
After large imports or mass deletions, run nodetool compact cautiously during off-peak hours. Use compactionstats to verify completion. Confusing strategies can increase I/O or latency.
Node lifecycle checks
For new nodes, confirm auto_bootstrap, run nodetool repair once streaming completes, then run cleanup on old nodes. Missing cleanup leaves redundant data and wasted disk.
Data center operations
Configure dc and rack names properly and adjust seed lists for cross-DC communication. Plan streaming windows and test in staging when possible.
GC tuning checklist
Adjust -Xms/-Xmx and MaxGCPauseMillis in small steps, examine gc.log, and monitor latency. Aggressive tuning can introduce instability.
