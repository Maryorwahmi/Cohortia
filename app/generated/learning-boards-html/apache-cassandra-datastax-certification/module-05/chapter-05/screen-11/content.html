Expanding and contracting data centers

Operational checklist for dc-level changes to preserve availability and consistent token distribution.

Expansion checklist
  • Set dc_name and rack_name in cassandra-rackdc.properties for new machines.
  • Update seed lists for cross-DC gossip and metadata sharing.
  • Bootstrap nodes with auto_bootstrap true and monitor streaming.
  • Run repair and cleanup as nodes finish streaming.
Contraction checklist
  • Plan decommissions in a staged manner to preserve replica coverage.
  • Use decommission for healthy nodes and removenode only if nodes are unreachable.
  • Run cleanup and targeted repairs on remaining nodes to rebalance data.
Key Takeaway

Treat data center changes as large-scale topology operations: configure labels and seeds, sequence bootstrapping and streaming, then run repairs and cleanup to finalize the new topology.

Operational note
Plan cross-DC streaming capacity and pick maintenance windows to avoid saturating wide-area links.
