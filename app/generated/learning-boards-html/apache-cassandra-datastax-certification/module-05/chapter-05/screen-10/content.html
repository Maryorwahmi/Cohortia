Removing a node: decommission vs removenode

Guided process for graceful removal and emergency removal, plus follow-up tasks.

Graceful removal
Run nodetool decommission on the healthy node. It streams data to replicas and leaves the ring cleanly. Confirm with nodetool status.
Emergency removal
If a node is dead, use nodetool removenode <host_id> from a healthy node. Document the host_id and follow with targeted repairs and cleanup on remaining nodes.
Common mistake

Using removenode without planning can leave inconsistent token ownership and hidden data gaps. Use it only when decommission is impossible.

Pro tip
After any removal, run nodetool cleanup and targeted repairs to reclaim space and restore replica consistency.
