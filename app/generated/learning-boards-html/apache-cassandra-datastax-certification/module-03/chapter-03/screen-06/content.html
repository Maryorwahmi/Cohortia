Module 3 › Chapter 3.3 › UPDATE basics
UPDATE simple columns
Specify SET for columns and WHERE for the full primary key.
-- Update a simple column
UPDATE user_profiles.users
SET email = 'alice.new@example.com', last_login_date = toTimestamp(now())
WHERE user_id = 92a7f0e0-5a3b-4c8d-8e1f-2b6c7d8e9f0a;
Important
You must provide the full primary key in WHERE. UPDATE does not change primary-key columns themselves.
Concrete scenario
When a user changes their email, issue an UPDATE with their user_id. If you must ensure the user exists before changing, use IF EXISTS but accept LWT cost.
Misconception
Thinking UPDATE can change the partition key or cluster columns. It cannot; you must write a new row and delete the old key if you need that effect.
Key Takeaway

Use UPDATE to change non-key columns for the identified row. Use IF EXISTS only when you require a guaranteed presence check.
