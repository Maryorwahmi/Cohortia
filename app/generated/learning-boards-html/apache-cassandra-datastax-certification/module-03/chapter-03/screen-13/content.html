Question: IF NOT EXISTS effect
Which state results when INSERT ... IF NOT EXISTS targets an existing primary key?
INSERT INTO users (id, name) VALUES (1, 'Alice') IF NOT EXISTS;
Correct understanding: the row stays as it was if a row with that key already exists. The IF NOT EXISTS condition prevents the write and is executed via an LWT.
Key Takeaway

IF NOT EXISTS disables the upsert behavior for that operation by performing a conditional existence check with LWT semantics.
