Learning Objectives
Master key DML operations and the trade-offs they imply.
Bloom: Learn → Understand → Apply → Master
01
Execute INSERT
Run INSERT statements to add rows, and know that INSERT behaves as an upsert unless you use IF NOT EXISTS.
VERIFIED COMPETENCY MILESTONE
02
Perform UPDATEs
Modify existing rows by primary key, including updates to SET and MAP collection types.
VERIFIED COMPETENCY MILESTONE
03
Use DELETE safely
Remove specific columns or rows and recognize that deletions write tombstones that affect reads until compaction.
VERIFIED COMPETENCY MILESTONE
04
Explain LWTs
Describe how IF conditions create Lightweight Transactions and why they add latency and coordination overhead.
VERIFIED COMPETENCY MILESTONE
