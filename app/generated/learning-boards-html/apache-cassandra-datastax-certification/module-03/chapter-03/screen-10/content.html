Safe state transitions with IF
Use IF column = value to change state only when the current state matches the expected value.
-- Conditional state transition
UPDATE user_profiles.posts
SET status = 'approved'
WHERE post_id = /* post_id */
IF status = 'pending';

-- Ensure row exists before update
UPDATE user_profiles.users
SET last_seen = toTimestamp(now())
WHERE user_id = /* user_id */
IF EXISTS;
Benefit
Prevents lost updates and enforces single-row atomic logic without an external coordinator.
Cost
Higher latency and coordination overhead due to LWT; test under expected load.
Key Takeaway

Use conditional updates for correctness-sensitive state changes, and avoid them on high-frequency write paths to keep throughput high.
