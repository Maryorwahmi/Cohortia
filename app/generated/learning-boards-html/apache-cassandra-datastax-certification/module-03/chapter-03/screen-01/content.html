Inserting, Updating, and Deleting Data
Learn how CQL write and delete operations behave in Cassandra, and when to use conditional writes and TTL.
In this lesson
INSERT vs upsert, UPDATE semantics, DELETE and tombstones, LWTs, and TTL.
Why it matters
Predictable writes and sensible deletion policies keep read performance stable at scale.
Concept map
INSERT
Upsert by default. Use IF NOT EXISTS for uniqueness.
DELETE
Writes tombstones; compaction removes data later.
TTL
Automatically expires data and produces tombstones.
Key Takeaway

Treat CQL writes as upserts. Use IF conditions only when you need strict single-row consistency; use TTL to manage ephemeral data but plan for tombstones.

Deletes & Tombstones
