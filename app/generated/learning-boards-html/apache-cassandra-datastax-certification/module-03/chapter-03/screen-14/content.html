Module 3 › Chapter 3.3 › Key Concepts — Part 1
INSERT
Upsert by default; overwrites existing primary-key rows.
IF NOT EXISTS
Triggers an LWT to ensure a row does not already exist before inserting.
UPDATE
Modifies columns for a row identified by its full primary key.
Summary
Design keys to avoid accidental overwrites, use LWTs only when necessary, and always identify rows by their primary key for updates.
