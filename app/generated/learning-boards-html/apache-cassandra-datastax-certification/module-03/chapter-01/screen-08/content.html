Architecture
Replication strategies
How replicas are placed and why datacenter awareness matters.
SimpleStrategy
Ring-based placement suitable for single-datacenter development or tests.
NetworkTopologyStrategy
Datacenter-aware, allows per-datacenter replication factors for multi-region resilience.
Choosing replication factor
Higher replication gives more fault tolerance but increases write cost and storage; align factor with availability needs.
Key Takeaway

Select SimpleStrategy only for single-datacenter testing; use NetworkTopologyStrategy to control replicas per region in production.

Example CQL
-- SimpleStrategy for local development CREATE KEYSPACE user_profiles WITH replication = {'class': 'SimpleStrategy', 'replication_factor': 1};-- NetworkTopologyStrategy for multi-dc CREATE KEYSPACE global_orders WITH replication = {'class': 'NetworkTopologyStrategy', 'NorthAmerica': 2, 'Europe': 3};
Common misconception
Higher replication factor is not always better; it increases write amplification and storage cost and must match routing and failure assumptions.
