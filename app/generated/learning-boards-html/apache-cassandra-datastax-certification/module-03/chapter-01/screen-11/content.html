Troubleshooting common cqlsh issues
A short checklist to resolve typical beginner errors quickly.
Missing semicolon
If cqlsh waits, finish the statement with a semicolon or abort with CTRL+C.
Connection refused
Verify Cassandra is running and use cqlsh <ip> <port> if necessary.
Wrong replication
Avoid SimpleStrategy for multi-datacenter production; choose NetworkTopologyStrategy instead.
Type misuse
Prefer UUID over TEXT for identifiers to save space and retain native semantics.
Quick checks
  • Run DESCRIBE CLUSTER; to confirm cluster membership.
  • Use HELP; inside cqlsh when you are unsure of available commands.
  • Inspect service logs on the host for network issues before changing replication.
