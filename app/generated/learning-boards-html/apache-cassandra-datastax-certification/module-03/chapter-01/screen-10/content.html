Create a keyspace and use it
Exact commands to type in a local cqlsh session.
-- Open cqlsh cqlsh-- Create a development keyspace CREATE KEYSPACE user_profiles WITH replication = {'class': 'SimpleStrategy', 'replication_factor': 1};-- Set the working keyspace USE user_profiles;-- Verify keyspace definition DESCRIBE KEYSPACE user_profiles;
Key Takeaway

Follow these exact steps to establish a safe development keyspace and verify its configuration before creating tables.

Example scenario
For local testing use a replication factor of 1. In production, replace SimpleStrategy with NetworkTopologyStrategy and appropriate per-datacenter counts.
Common pitfall
Creating a keyspace with the wrong strategy or replication factor without considering topology can cause data availability issues later.
