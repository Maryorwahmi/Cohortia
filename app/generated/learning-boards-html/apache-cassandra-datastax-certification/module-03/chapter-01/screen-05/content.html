Process Flow
Open cqlsh and inspect the cluster
Follow these steps to connect and check cluster state before changes.
Step 1 — Start shell
Run cqlsh locally or cqlsh 192.168.1.100 9042 for a remote node.
Step 2 — Discover commands
Use HELP; to list cqlsh capabilities and shortcuts.
Step 3 — Check cluster
Run DESCRIBE CLUSTER; to view node and cluster metadata.
Step 4 — Use a keyspace
After creating a keyspace, run USE user_profiles; to set the context for table commands.
Common pitfall
Forgetting the semicolon will keep cqlsh waiting; press semicolon and Enter, or CTRL+C to cancel.
Code walkthrough

Key Takeaway

Connecting and confirming cluster state with cqlsh is a safe, repeatable first step before schema changes.
