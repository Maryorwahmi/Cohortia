Definition
Keyspace
A container for tables and type-level settings that control replication across the cluster.
What it contains
Tables, user-defined types, functions, and replication settings.
Replication settings
Choose a replication strategy and factor that match single or multi-datacenter deployments.
Practical note
Use USE <keyspace>; to set the working keyspace after you create it.
Key Takeaway

Keyspaces control where and how many copies of your data exist; set replication strategy according to deployment topology.

Example keyspace
-- Local development CREATE KEYSPACE user_profiles WITH replication = {'class': 'SimpleStrategy', 'replication_factor': 1};-- Production multi-datacenter CREATE KEYSPACE global_orders WITH replication = {'class': 'NetworkTopologyStrategy', 'NorthAmerica': 2, 'Europe': 3};
Common mistake
Using replication_factor 1 in production leaves no copies if a node fails. Choose replication to meet availability goals.
