Learning Objectives
Progress from understanding CQL to creating keyspaces and choosing types.
01
Explain CQL purpose and syntax
Describe why CQL resembles SQL but targets Cassandra's distributed model. Knowing this prevents SQL-based assumptions when modeling data.
Verified competency milestone
02
Connect with cqlsh and run admin commands
Use cqlsh, HELP, DESCRIBE CLUSTER, and connection flags to inspect and manage a cluster. This gives you situational awareness before schema changes.
Verified competency milestone
03
Identify and use CQL data types
Choose between TEXT, INT, UUID, and collections like LIST or MAP to match application needs and storage trade-offs.
Verified competency milestone
04
Create and manage keyspaces and replication
Define keyspaces with SimpleStrategy or NetworkTopologyStrategy and choose replication factors that meet availability requirements.
Verified competency milestone
