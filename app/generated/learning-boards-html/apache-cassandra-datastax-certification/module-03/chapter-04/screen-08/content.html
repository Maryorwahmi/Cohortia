Module 4 › Chapter 3.4 › LIMIT vs PER PARTITION LIMIT
Process Flow

How to choose a limit

  • LIMIT caps the total rows returned for the entire query.
  • PER PARTITION LIMIT caps rows returned from each partition involved.
  • Use PER PARTITION LIMIT when using IN for many partition keys to get balanced samples.
-- Top 5 comments for a single post
SELECT * FROM user_profiles.post_comments
WHERE post_id = /* id */
LIMIT 5;

-- At most 2 comments per post when querying multiple posts
SELECT * FROM user_profiles.post_comments
WHERE post_id IN (/* id1, id2 */)
PER PARTITION LIMIT 2;
Example & guidance

If your endpoint needs the latest three items per user across many users, PER PARTITION LIMIT is the right tool. If you need three items total across many users, LIMIT plus client-side aggregation is required.

Key Takeaway

Select the limit type that matches the business requirement: per-group ceilings use PER PARTITION LIMIT; global ceilings use LIMIT plus aggregation.
