Module 4 › Chapter 3.4 › ORDER BY
Definition

ORDER BY inside a partition

You can sort results only by clustering columns and only in ways the table's clustering order allows. This keeps sorting efficient and local to replicas for that partition.

SELECT comment_text, created_at FROM user_profiles.post_comments
WHERE post_id = /* your_post_id */
ORDER BY comment_id DESC;
Why it matters
Efficient ordering avoids expensive sorts across nodes and keeps latency low for time-ordered feeds.
Misconception
ORDER BY does not create a global sorted set across partitions. For global sorting, you need different modeling or client-side merge.
Checklist
  • Confirm clustering column used by ORDER BY.
  • Confirm clustering order in table definition supports requested direction.
  • Prefer LIMIT to restrict result size after ordering.
Key Takeaway

ORDER BY is safe and efficient only when it sorts within a single partition according to clustering order.
