Definition

Secondary index basics

-- Create an index on email
CREATE INDEX ON user_profiles.users (email);

-- Then query by email without ALLOW FILTERING
SELECT * FROM user_profiles.users
WHERE email = 'alice.new@example.com';
  • Indexes speed development for occasional, low-volume lookups.
  • Indexes add write overhead because they are maintained on updates and deletes.
  • They are sensitive to the indexed column's cardinality and query selectivity.
Practical guidance

If the indexed column has few unique values, the index will generate large index partitions and degrade performance. If a query pattern is frequent or needs high throughput, prefer creating a new denormalized table keyed for that query.

Pro tip

Use secondary indexes for admin tools and low-traffic lookups. For application queries, model tables for the access pattern.
