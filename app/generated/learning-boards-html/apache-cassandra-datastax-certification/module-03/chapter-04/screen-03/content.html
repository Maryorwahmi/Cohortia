Use clustering ranges

Query clustering columns with range operators to implement time windows, for example comments between two timestamps. This supports efficient slices inside a partition.

VERIFIED COMPETENCY MILESTONE
06
Limit per partition

Apply PER PARTITION LIMIT when querying multiple partitions with IN to get a fixed number of rows per partition. This pattern prevents one partition from dominating results.

VERIFIED COMPETENCY MILESTONE
07
Create and evaluate indexes

Build a secondary index for selective, low-volume queries and evaluate write/read costs. We will compare index trade-offs to creating new tables.

VERIFIED COMPETENCY MILESTONE
08
Refactor for queries

Given a frequent query pattern that needs non-key filters, propose a denormalized table keyed to that pattern instead of using ALLOW FILTERING.
