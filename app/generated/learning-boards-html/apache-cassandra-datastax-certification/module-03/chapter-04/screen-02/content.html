Learning Objectives

Understand and practice the essential SELECT patterns for Cassandra.

Bloom: Learn → Understand → Apply → Master
01
Construct basic SELECTs

Write SELECT statements that retrieve specific columns and supply full partition keys so queries are efficient. This matters because scanning partitions can overwhelm nodes in a distributed cluster.

VERIFIED COMPETENCY MILESTONE
02
Filter with WHERE and keys

Apply WHERE using the partition key and clustering columns in order. Understand how an incomplete partition key forces inefficient scans or errors.

VERIFIED COMPETENCY MILESTONE
03
Order and limit results

Use ORDER BY only on clustering columns in proper sequence and LIMIT or PER PARTITION LIMIT to control result size. This keeps responses predictable and bounded.

VERIFIED COMPETENCY MILESTONE
04
Recognize ALLOW FILTERING risks

Understand why ALLOW FILTERING can cause full scans and cluster instability, and when it might be acceptable for ad-hoc tasks on small data sets.

VERIFIED COMPETENCY MILESTONE
