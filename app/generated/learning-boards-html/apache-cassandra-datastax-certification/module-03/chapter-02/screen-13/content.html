Clustering Columns
Define row order inside partitions and enable range queries and sorted retrievals.
Query-First Modeling
Design distinct tables per access pattern so reads remain single-partition and efficient.
Static Column
Stores a single value per partition shared across rows; only valid when clustering columns exist.
Also remember

A hot spot or hot partition arises from low-cardinality partition keys. Measure cardinality and test queries to avoid it.
