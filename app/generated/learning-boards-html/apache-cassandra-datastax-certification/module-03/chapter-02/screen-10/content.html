Module 3 › Chapter 3.2 › Hands-on: Blog Tables
Starter template
Use the user_profiles keyspace, then create two tables: blog_posts and post_comments.
-- Use the keyspace
USE user_profiles;

-- Create blog_posts table
CREATE TABLE blog_posts (
  post_id UUID,
  title TEXT,
  content TEXT,
  author_id UUID,
  publication_date TIMESTAMP,
  PRIMARY KEY (post_id)
);

-- Create post_comments table
CREATE TABLE post_comments (
  post_id UUID,
  comment_id TIMEUUID,
  author_id UUID,
  comment_text TEXT,
  created_at TIMESTAMP,
  PRIMARY KEY (post_id, comment_id)
) WITH CLUSTERING ORDER BY (comment_id DESC);
The post_comments table uses post_id as the partition key so all comments for a post are co-located, and comment_id as a TIMEUUID clustering column ordered DESC to fetch newest comments first.
Verification steps
  1. Insert a post and several comments with different timestamps.
  2. Query SELECT * FROM post_comments WHERE post_id = ? LIMIT 10; and confirm newest-first order.
  3. Query SELECT * FROM blog_posts WHERE post_id = ?; to confirm single-row retrieval.
Key Takeaway

Translate queries to tables, then verify by inserting and selecting to confirm distribution and order behavior.
