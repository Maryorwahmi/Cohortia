Module 3 › Chapter 3.2 › Clustering Columns
Comparison: ORDER BY behavior
Clustering order controls on-disk sorting and read retrieval order.
Ascending (default)
Rows are stored from oldest to newest when used with timestamps as clustering columns.
Descending
Use WITH CLUSTERING ORDER BY (col DESC) to store and return newest-first without client reversal.
Key Takeaway

Pick clustering columns and order to match common range and sorted queries so reads remain server-side efficient.

Concrete CQL
CREATE TABLE user_profiles.user_activity_by_month (
  user_id UUID,
  activity_month INT,
  activity_id TIMEUUID,
  activity_type TEXT,
  PRIMARY KEY ((user_id, activity_month), activity_id)
) WITH CLUSTERING ORDER BY (activity_id DESC);
Here activity_id is a TIMEUUID clustering column ordered DESC so queries for recent activities return newest first without extra work.
Misconception
Clustering order does not change partition placement; it only affects ordering inside partitions.
