Module 3 › Chapter 3.2 › Static Columns
Static column definition
A column declared STATIC has one value per partition shared by all rows in that partition.
Example
CREATE TABLE user_profiles.user_activity_with_static (
  user_id UUID,
  activity_timestamp TIMESTAMP,
  user_email TEXT STATIC,
  activity_type TEXT,
  PRIMARY KEY (user_id, activity_timestamp)
);
Caveat
Static columns require clustering columns. If your table only has a partition key, static columns are not applicable.
When to use
  • Store partition-level metadata that is the same for all rows in the partition.
  • Reduce storage duplication for values that change infrequently.
  • Keep updates to static columns limited to avoid frequent writes affecting many rows.
Key Takeaway

Use static columns when data belongs to the partition and does not vary per clustering row; otherwise store it as a regular column or in a separate table.
