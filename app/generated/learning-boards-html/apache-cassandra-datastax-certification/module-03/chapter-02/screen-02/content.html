Learning Objectives
Bloom steps: Learn → Understand → Apply → Master
01
Design and create tables
Compose CREATE TABLE statements with column names and types that match required reads. You will practice concrete CQL examples using UUIDs, TEXT, TIMESTAMP, and collection types.
VERIFIED COMPETENCY MILESTONE
02
Partition vs clustering columns
Explain how the partition key selects node placement and clustering columns order rows within the partition, with examples showing single and composite partition keys.
VERIFIED COMPETENCY MILESTONE
03
Query-first data modeling
Design tables for specific queries, accept denormalization, and create distinct tables per access pattern to keep reads efficient.
VERIFIED COMPETENCY MILESTONE
04
Static columns and pitfalls
Understand when static columns reduce duplication and the limitation that they require clustering columns to be meaningful.
VERIFIED COMPETENCY MILESTONE
Bloom's progression
Learn: Identify partition and clustering components.
Understand: Explain how keys affect distribution and order.
Apply: Create tables for read patterns.
Master: Prevent hot partitions and choose clustering order.
