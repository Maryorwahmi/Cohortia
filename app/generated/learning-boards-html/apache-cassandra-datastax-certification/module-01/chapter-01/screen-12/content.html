Module 1 › Chapter 1.1 › Scenario Analysis
Application 1

Online Banking System

  • Requirements: strict transactional integrity, strong consistency, complex reporting.
  • Recommended: RDBMS for ACID, schema enforcement, and SQL reporting.
Application 2

IoT Sensor Data Platform

  • Requirements: billions of readings, high ingest, flexible schema, eventual consistency acceptable.
  • Recommended: NoSQL for horizontal write scale and schema flexibility.
Hybrid note
Often the best design combines both paradigms: use an RDBMS for critical transactions and a NoSQL pipeline for analytics and high-throughput ingestion, keeping integration and boundary conditions explicit.
