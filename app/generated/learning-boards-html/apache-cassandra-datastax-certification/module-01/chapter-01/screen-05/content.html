Process

ACID step-by-step

1. Atomicity

All parts of a transaction succeed or none do. Example: transfer funds requires both debit and credit.

2. Consistency

Database constraints and business rules remain satisfied after each transaction.

3. Isolation

Concurrent transactions appear to run in isolation; isolation levels balance performance and correctness.

4. Durability

Once committed, changes persist through failures because they are stored durably.

Illustration
Walkthrough: an online order must create an order record, reserve inventory, and charge payment. Atomicity groups the three steps. Consistency enforces stock levels cannot be negative. Isolation prevents two orders from reserving the same last item concurrently. Durability ensures the confirmed order remains after a server crash.
Misconception
Assuming ACID equals speed. ACID ensures correctness; it can increase coordination and latency, particularly with distributed nodes.
