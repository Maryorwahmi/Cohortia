Module 1 › Chapter 1.2 › Document Databases
Definition
Self-contained, semi-structured documents stored as JSON/BSON. Documents may have nested fields and variable schemas.
Example document
{
  "id": 101,
  "name": "Trail Running Shoe",
  "price": 129.95,
  "attributes": { "color": "red", "size": [9,10,11] },
  "tags": ["outdoor","running"]
}
Use cases
Content management, user profiles, product catalogs, and mobile app backends where fields differ by record or change frequently.
Design guidance
  • Embed related data when reads should be served in one fetch.
  • Denormalize carefully to avoid expensive cross-document joins.
  • Create indexes on frequently queried fields, including nested paths.
Key Takeaway

Document stores fit variable data structures and support field-level queries, but cross-document queries may need denormalization strategies.
