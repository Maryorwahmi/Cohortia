Module 1 › Chapter 1.2 › Key Concepts
Key-Value Store
Stores unique keys mapped to arbitrary values for fast lookups.
Document Database
Stores flexible JSON-like documents, suitable for evolving schemas.
Column-Family Store
Organizes rows with dynamic columns grouped into families for high write throughput.
Graph Database
Models nodes and edges; ideal when relationship traversal is primary.
Summary takeaway
Map the dominant access pattern and data shape to a storage category, and use polyglot persistence to combine stores only where each adds clear value.
