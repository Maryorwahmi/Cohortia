Module 1 › Chapter 1.2 › How to Choose
Decision steps
  1. Identify the dominant access pattern: key lookup, document queries, wide-row writes, or traversals.
  2. Sketch one or two example queries your app must support and measure their cost conceptually.
  3. Pick the store that serves the primary queries efficiently, prototype, then add a secondary store if needed.
Example scenarios
Session cache → Key-Value
Product catalog → Document
Sensor readings → Column-Family
Friend recommendations → Graph
Try this
Write two example queries for a subsystem and ask which store serves them with minimal extra work. If answers differ, consider polyglot persistence for that subsystem split.
