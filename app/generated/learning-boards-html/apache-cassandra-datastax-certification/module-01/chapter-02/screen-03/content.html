Module 1 › Chapter 1.2 › Learning Objectives
Verified Tasks
  • Key-Value: Write an example key like "user:123" and state why a simple lookup is O(1) in practice for the store.
  • Document: Sketch a JSON product document and explain querying by a nested field such as category or tags.
  • Column-Family: Describe a row key used for time-series and show how different columns can be added per row without schema changes.
  • Graph: Model a tiny friend graph and explain a friends-of-friends traversal and why edge-first queries are efficient.
Pro-tip
Use small sketches and one-sentence justifications. If you can explain the access pattern and one example query, you can usually pick the right NoSQL category.
