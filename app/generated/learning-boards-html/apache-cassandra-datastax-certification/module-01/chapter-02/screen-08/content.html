Module 1 › Chapter 1.2 › Comparing Models
Side-by-side
Key-Value
Strength: ultra-fast lookups. Limitation: weak query and relationship support.
Document
Strength: schema flexibility and field queries. Limitation: cross-document joins can be costly.
Column-Family
Strength: write scalability and sparse wide rows. Limitation: design relies on correct partitioning.
Graph
Strength: relationship queries and traversals. Limitation: not optimal for simple cache-like workloads.
Practical decision rule
Start with the dominant access pattern: if it’s direct keys use Key-Value; if it’s nested document queries use Document; if it’s append-heavy wide rows use Column-Family; if it’s relationship traversal use Graph.
Polyglot note
Many systems combine stores to match different subsystems to the best model.
