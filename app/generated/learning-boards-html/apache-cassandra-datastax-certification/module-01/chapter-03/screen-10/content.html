Module 2 › Chapter 1.3 › Read and Write Coordination
Write path
A coordinator node forwards the write to replicas and waits for acknowledgments per consistency setting. Background processes handle eventual synchronization.
Reads may contact multiple replicas and reconcile responses. If replicas disagree, read repair can update stale replicas. Hinted handoff temporarily stores hints about missed writes so replicas can be repaired later when they come back online.
Hinted handoff
Helps availability during outages
Read repair
Repairs replicas during reads
Concrete example
If a write reaches node A and nodes B and C are replicas, A sends writes to B and C and waits based on consistency. If B is down, A may store a hint and continue, allowing writes to succeed while B recovers later.
Key Takeaway

Coordination is distributed and ephemeral; Cassandra uses background mechanisms to maintain eventual convergence while keeping the cluster available.
