Apache Cassandra
An open-source distributed wide-column store for high availability and linear scale.
Peer-to-peer Architecture
All nodes are equal; no single master and no single point of failure.
Wide-Column Store
Rows with flexible columns grouped into tables; model tables to match queries.
Summary

These core concepts explain Cassandra's approach to scale and availability: topology, data model, and intentional schema design for queries.
