Replication basics
Replication factor sets how many copies of each partition are stored. Copy placement is controlled by the replication strategy.
With multiple replicas, reads and writes can succeed even when some nodes fail. The replication strategy can be tuned for single or multiple datacenters to keep local copies for low latency while maintaining durability across sites. Remember that replication increases storage cost and write overhead because each write must be stored on all replicas according to the consistency level.

Practical considerations
Choose RF to tolerate the number of node failures you expect. Consider how QUORUM is computed relative to RF since read and write quorums interact with replica counts to provide stronger guarantees.
Key Takeaway

Replication gives resilience and locality. Balance replication factor with cost and the consistency behavior you need.
