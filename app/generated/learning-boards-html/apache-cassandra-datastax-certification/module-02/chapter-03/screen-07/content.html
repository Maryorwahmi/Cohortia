Module 3 › Chapter 2.3 › SSTables & Compaction
SSTable properties
  • Immutable on-disk files created by memtable flushes.
  • Contain sorted key-value pairs and auxiliary index/summary/filter files.
  • Multiple SSTables can contain different versions of the same partition key.
Why immutability matters
Immutability simplifies concurrent writes and avoids in-place updates, but requires compaction to merge state.
Compaction overview
Compaction selects SSTables and merges them into a smaller set, keeping the latest values and dropping expired tombstones when safe.
Operator note
Compaction reduces read amplification but consumes I/O. Choose a strategy that matches your write and read patterns.
Key Takeaway

Compaction reconciles multiple immutable SSTables to present a single current view of data while reclaiming space from deletions.

Analogy
Think of SSTables as snapshots. Compaction is like consolidating many incremental snapshots into a single clean backup that contains the latest state and removes deleted files.
