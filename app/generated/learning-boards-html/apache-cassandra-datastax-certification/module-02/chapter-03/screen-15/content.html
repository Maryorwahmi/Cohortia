Module 3 › Chapter 2.3 › Key Concepts
SSTable
Immutable on-disk file created by memtable flushes; contains sorted key-value data and auxiliary files.
Bloom Filter
A fast probabilistic test that rules out SSTables that cannot contain a key, reducing disk reads.
Read Repair & Handoff
Read repair heals stale replicas during reads; hinted handoff temporarily stores missed writes for brief outages.
Final takeaway
These optimizations and background processes reduce read I/O, keep replicas consistent, and balance performance with eventual consistency guarantees.
