Module 3 › Chapter 2.3 › Reconciliation & Read Repair
Reconciliation
Coordinator merges returned results from replicas, selecting newest values by timestamp and respecting tombstones for deletions.
Concrete example
If replicas disagree, the coordinator returns the most recent column values and notes which replicas need updates.
Read repair
An asynchronous write that updates stale replicas discovered during reads. It is opportunistic and relies on reads to detect inconsistencies.
Key Takeaway

Read repair helps maintain eventual consistency by fixing replicas discovered to be stale during normal read traffic.

When to run repair
For prolonged outages or large divergence, schedule full repair/anti-entropy operations; rely on read repair for opportunistic fixes during normal traffic.
