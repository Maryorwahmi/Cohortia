Module 3 › Chapter 2.3 › Write Path Overview
1
Coordinator receives write
Start enforcement of the chosen consistency level and prepare local durable and in-memory writes.
2
Commit log append
Append the mutation to an append-only commit log to ensure crash recovery before acknowledging the client.
3
Memtable write and replication
Write to the in-memory memtable and forward the mutation to replica nodes; wait for required acknowledgements.

Key Takeaway
Commit log + memtable on coordinator and replicas is the minimum durable write path; hints handle temporary replica outages.
Common Mistake
Assuming memtable writes alone are durable. Without commit log, memtable data can be lost on crash.
