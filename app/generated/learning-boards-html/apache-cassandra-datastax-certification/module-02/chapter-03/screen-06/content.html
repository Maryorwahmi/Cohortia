Module 3 › Chapter 2.3 › Memtable & SSTable Timeline
Timeline
Write arrives and commit log is appended
Durable append ensures the mutation is recoverable.
Memtable stores the update in memory
Fast reads of recent writes come from the memtable.
Memtable flush creates SSTable
An immutable on-disk file with sorted data and auxiliary indices.
Compaction merges SSTables
Removes tombstones where safe and reduces read amplification.
Example: force a flush
nodetool flush my_data sensor_readings
This forces the memtable for the table to be written to a new SSTable on disk. After the command, check the data directory to see new .db files.
Key Takeaway

Memtable flushes produce immutable SSTables; compaction later reduces file count and reclaims space.
