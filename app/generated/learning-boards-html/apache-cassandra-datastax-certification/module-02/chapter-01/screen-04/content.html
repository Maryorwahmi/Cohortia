Definition

Node & Cluster

A node stores part of the dataset and participates equally in the cluster. A cluster is the full set of nodes cooperating to serve requests and store data.

Peer-to-peer model
No master node. Any node can act as coordinator for client requests and forward operations to replicas.
Horizontal scaling
Add commodity nodes to increase capacity; token ownership shifts so new nodes take portions of the ring.
Concrete example
Imagine three nodes sharing the token ring evenly. Each node holds roughly a third of keys. Add a fourth node and token ranges rebalance so each node holds about a quarter. Because any node can accept requests, clients don't need to know where data lives; they connect to any node which coordinates the request.

Key Takeaway

Nodes are equal peers; cluster resilience comes from replication and distribution, not master election.
