Architecture

NetworkTopologyStrategy

Set a replication factor per data center to control how many copies exist locally in each region. Cassandra spreads those copies across racks inside the data center when possible.

Example configuration
NetworkTopologyStrategy: DC1:3, DC2:2 — three local replicas in DC1 and two in DC2 for redundancy and locality.
Operational note
Changing replication requires running appropriate repair or streaming; replicas must be materialized after topology changes.
Misconception check
Don’t assume replication factors sum into a single global number; they are applied per data center and affect local read availability and cross-DC write cost differently.
Key Takeaway

Choose replication per DC to balance durability, cost, and latency; ensure replicas are spread across racks inside each data center.
