Definition

Rack groups and replication

Racks are logical groupings used to ensure replicas are placed across different physical failure domains. Rack-aware replication prevents losing all replicas when a rack-level outage occurs.

Example
Three replicas in one data center placed across rack1, rack2, and rack3. If rack2 loses power, replicas in rack1 and rack3 still serve requests.
Practical tip
Ensure each node's rack property reflects physical isolation; otherwise rack-aware placement cannot protect you.
Quick checklist
  • Label racks to reflect switch and power boundaries.
  • Verify nodetool output shows varied Rack values for replicas.
  • Avoid giving all nodes the same rack name unknowingly.
Common mistake

Treating racks as optional labels and not aligning them with physical failure domains disables rack-aware safety guarantees.
