Process Flow › Implementing IEnumerable/IEnumerator
Steps
  1. 1. Choose storage: Array or List are common. Keep storage private.
  2. 2. Implement IEnumerable<T>: Add public IEnumerator<T> GetEnumerator() returning a new iterator.
  3. 3. Create IEnumerator<T>: Implement Current, MoveNext, Reset, Dispose and a constructor that receives storage.
  4. 4. Add non-generic compatibility: Implement IEnumerator and IEnumerable explicit members by delegating.
  5. 5. Safety: Handle nulls, sparse arrays, and call Dispose when needed.
Follow these steps and the collection will integrate with foreach and LINQ automatically.
Example method
GetEnumerator returns new ConcreteIterator(_storage). Keep this factory logic simple and focused.
Check your understanding
If you change array to a dictionary, which class must be updated? (Answer: aggregate storage; iterators must adapt or be new types.)
Common mistake
Having the aggregate perform traversal or exposing internal lists rather than providing an iterator.
