Pattern Components › Iterator Roles
Iterator (IEnumerator<T>)
Defines MoveNext(), Current, Reset(). It encapsulates traversal state and rules.
Concrete Iterator
Implements IEnumerator<T>, tracks position, handles sparse arrays or traversal variations.
Aggregate (IEnumerable<T>)
Declares GetEnumerator which returns an IEnumerator<T> to clients.
Concrete Aggregate
Implements IEnumerable<T> and returns instances of concrete iterators. Keeps storage private.
Example mapping
DinerMenu : IEnumerable<MenuItem> → GetEnumerator() returns DinerMenuIterator : IEnumerator<MenuItem>.
Pro tip
If you need multiple traversals, offer named factory methods that return different concrete iterators instead of embedding traversal logic in the aggregate.
