Core Concept › What the Iterator pattern solves
Pattern definition and metaphor
Iterate without exposing how the collection stores items. Think: a playlist you can walk through regardless of internal storage.
  • • Problem: clients tied to internal representation if you expose storage directly.
  • • Claim: provide an Iterator object to step through elements instead of exposing the collection.
  • • Misconception: foreach removes the need to implement iterators — it only hides the calls; you must implement enumerators for custom collections.
Key Takeaway

Design traversal as a separate component so collection internals can change without impacting callers.

Concrete example: Menu and MenuItem
A DinerMenu holds MenuItem objects in an array. DinerMenu exposes GetEnumerator which returns a DinerMenuIterator that knows how to step through the array and skip nulls.
Analogy
Iterator is like a bookmark in a book — it remembers your current position while the book stays unchanged.
Common mistake
Returning the internal list directly couples callers to implementation and prevents changing storage later.
