Comparison › foreach vs manual enumerator
foreach (compiler-generated)
Compiler calls GetEnumerator, then MoveNext/Current in a loop and disposes the enumerator automatically.
• Safer for resource disposal.
• Cleaner and preferred for simple traversal.
Manual IEnumerator
You call GetEnumerator(), then loop with MoveNext and use Current, and call Dispose when finished.
• Use when you need control or to pause iteration.
• Must manage Dispose to avoid leaks when iterators hold resources.
Concrete example
Manual enumeration filters vegetarian items by checking Current.IsVegetarian inside a while loop using MoveNext.
Misconception
Thinking foreach removes the need to implement IEnumerable; you still must provide a correct enumerator for custom collections.
