Best Practices › Robust iterator design
Disposal
Implement Dispose for iterators that manage external resources and ensure using patterns or foreach properly disposes them.
LINQ compatibility
Expose IEnumerable<T> so your collection works with LINQ operators without extra adapters.
Testing
Unit test empty, single, sparse, and concurrent modification scenarios to validate iterator behavior.
Final checklist
Return fresh iterators, document modification policies, implement Dispose if needed, and provide specialized iterators for alternate traversals.
