Process › Traversal strategies
Forward iterator
Standard left-to-right traversal using an index or cursor.
Reverse iterator
Starts at the end and decrements the position. Expose as GetReverseEnumerator.
Filtered iterator
Skips items that don't meet criteria, such as a VegetarianMenuIterator that only returns vegetarian items.
Design rule
Prefer separate iterator types for each traversal algorithm. This keeps traversal logic independent and easily testable.
