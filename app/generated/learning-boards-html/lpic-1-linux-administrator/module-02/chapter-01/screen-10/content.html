Virtual Machine Network Modes

Connecting Your Guest OS to the World

NAT (Network Address Translation)

VM shares host's IP, accesses internet via host. Not directly accessible from host or external network.

Bridged Adapter

VM acts as a separate device on the physical network, getting its own IP. Directly accessible from host and network.

Host-only Adapter

Creates a private network between the host and VMs. Isolated from the external network, useful for testing.

Scenario: Server Access

If you want to SSH into your Linux VM from your host machine, or have other devices on your physical network access services on the VM, 'Bridged Adapter' is the ideal choice. NAT would prevent this direct access.

Key Takeaway

Choosing the correct network mode is crucial for your VM's connectivity and how it interacts with your host and external networks.
