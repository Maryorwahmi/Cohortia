Understanding Disk Partitioning

Dividing Storage for Optimal Linux Performance

What is Disk Partitioning?

The process of dividing a hard disk drive into multiple logical storage units, each treated as a separate disk.

Root Partition (/)

  • Contains the entire Linux file system.
  • All directories, files, and applications reside here.
  • Essential for the OS to function.

Swap Partition

  • Acts as virtual RAM, extending physical memory.
  • Used when physical RAM is exhausted, moving inactive data to disk.
  • Slower than RAM, but prevents system crashes.
Key Takeaway

Proper disk partitioning, especially for root and swap, is fundamental for a stable and performant Linux system.
