FHS Deep Dive

Hardware Interfaces and Kernel Information

Exploring /dev, /proc, and /sys

/dev: Device Files

Contains special files that represent hardware devices. Programs interact with these files to communicate with hardware.

  • /dev/sda: First SATA disk
  • /dev/null: A 'black hole' device

/proc: Process & Kernel Info

A virtual filesystem providing dynamic information about running processes and kernel parameters. Not stored on disk.

  • /proc/cpuinfo: CPU details
  • /proc/meminfo: Memory usage

/sys: Kernel Objects Interface

Another virtual filesystem exposing kernel objects, allowing interaction with hardware devices and drivers.

Key Takeaway

These directories provide crucial interfaces for hardware interaction and real-time kernel/process monitoring.

Terminal Demo: Peeking into System Interfaces
# List common device files
ls /dev | head -n 5

# Expected Output (example):
console
core
cpu
cpu_dma_latency
disk

# View CPU information
head -n 5 /proc/cpuinfo

# Expected Output (example):
processor       : 0
vendor_id       : GenuineIntel
cpu family      : 6
model           : 158
model name      : Intel(R) Core(TM) i7-7700HQ CPU @ 2.80GHz

Virtual Filesystems

/proc and /sys are unique because their content is generated on-the-fly by the kernel, reflecting the current state of the system rather than static files on disk.
