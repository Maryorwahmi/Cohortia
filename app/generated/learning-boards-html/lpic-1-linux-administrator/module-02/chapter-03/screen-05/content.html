FHS Deep Dive

Root, User, and System Binaries

Exploring /, /bin, and /sbin

/: The Root Directory

The base of the entire filesystem tree. All other directories and files are descendants of the root.

/bin: Essential User Binaries

Contains fundamental command-line utilities available to all users, such as ls, cp, and mv.

/sbin: Essential System Binaries

Holds critical system administration commands, often requiring root privileges, like fdisk and reboot.

Key Takeaway

The root is the filesystem's origin; /bin provides common user tools, while /sbin houses administrative commands.

Terminal Demo: Listing Binaries
# List essential user binaries
ls /bin | head -n 5

# Expected Output:
bash
cat
chgrp
chmod
chown

# List essential system binaries
ls /sbin | head -n 5

# Expected Output:
agetty
badblocks
blkdiscard
blockdev
bootctl

Why the Separation?

Separating user and system binaries enhances security and clarifies the purpose of executables, preventing accidental misuse of powerful commands by regular users.
