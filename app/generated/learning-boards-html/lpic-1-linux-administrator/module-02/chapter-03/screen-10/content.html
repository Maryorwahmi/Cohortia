Removable Media and Navigation Fundamentals

Understanding /mnt, /media, and the Start of Command-Line Navigation

/mnt: Temporary Mount Points

A traditional directory for temporarily mounting filesystems, often used for manual mounts like network shares.

/media: Removable Media Mounts

Specifically designated for automatically mounting removable media such as USB drives, CD-ROMs, and SD cards.

Key Takeaway

/mnt and /media are crucial for accessing external storage and managing temporary filesystem mounts.

Terminal Demo: Checking Mount Points
# List contents of /mnt (often empty by default)
ls /mnt

# Expected Output (example):
# (empty or custom mounts)

# List contents of /media (if removable media is connected)
ls /media

# Expected Output (example):
