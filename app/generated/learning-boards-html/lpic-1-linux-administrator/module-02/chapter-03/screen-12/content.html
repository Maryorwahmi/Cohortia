Changing Directories with cd

Using Absolute, Relative, Home, and Previous Paths

Absolute Paths

Start from the root directory (/) to specify the full location (e.g., cd /etc/apache2).

Relative Paths

Specify location relative to your current directory (e.g., cd Desktop, cd .. for parent).

Shortcuts: ~ and -

cd ~: Go to your home directory. cd -: Go to the previous directory.

Key Takeaway

Mastering cd with various path types is crucial for efficient and precise filesystem navigation.

Terminal Demo: cd in Action
# Start in home directory
cd ~
pwd
# Output: /home/lpicuser

# Navigate to /etc using absolute path
cd /etc
pwd
# Output: /etc

# Navigate to a subdirectory (e.g., apt) using relative path
cd apt
pwd
# Output: /etc/apt

# Go up one level to parent directory
cd ..
pwd
# Output: /etc

# Go back to home directory using shortcut
cd ~
pwd
# Output: /home/lpicuser

# Go back to the previous directory (/etc)
cd -
pwd
# Output: /etc
