Avoiding Navigation Pitfalls

Understanding Path Confusion and Destructive Commands

Mistake 1: Confusing Paths

Using a relative path when an absolute path is needed, or vice-versa. Always verify your current directory and target path.

Example: If in /home/lpicuser, cd etc looks for /home/lpicuser/etc, not /etc.

Mistake 2: Destructive Commands

Using powerful commands like rm -rf without extreme caution can lead to irreversible data loss.

Warning: rm -rf / as root can delete your entire filesystem!

Key Takeaway

Always confirm your location with pwd and double-check paths before executing commands, especially destructive ones.

Terminal Demo: Path Confusion
# Assume current directory is /home/lpicuser
pwd
# Output: /home/lpicuser

# Attempt to change to /etc using relative path
cd etc

# Expected Output:
bash: cd: etc: No such file or directory

# Correct way to change to /etc
cd /etc
pwd
# Output: /etc

Pro Tip: Tab Completion

Use the Tab key for auto-completion of directory and file names. This helps prevent typos and confirms paths exist before execution.
