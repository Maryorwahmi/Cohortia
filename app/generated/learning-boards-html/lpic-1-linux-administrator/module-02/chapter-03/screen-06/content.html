System Configuration and User Data

Understanding /etc and /home

/etc: Configuration Files

Contains host-specific system-wide configuration files. These are typically text files that control system behavior.

  • /etc/passwd: User account information
  • /etc/fstab: Filesystem mount points

/home: User Home Directories

The primary location for users' personal files, documents, and user-specific settings.

  • /home/lpicuser: Example user home directory
Key Takeaway

/etc is for system configuration, while /home is for individual user data, ensuring separation and organization.

Terminal Demo: Inspecting Configuration & Home
# View first few lines of passwd file
head -n 3 /etc/passwd

# Expected Output:
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin

# List contents of /home (if users exist)
ls /home

# Expected Output (example):
lpicuser
student

Security Note for /etc

Modifying files in /etc requires careful attention. Always back up configuration files before making changes to prevent system instability.
