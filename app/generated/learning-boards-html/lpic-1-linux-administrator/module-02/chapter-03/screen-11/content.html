Command Essentials

Knowing Your Location and Listing Contents

Mastering pwd and ls for Directory Exploration

pwd: Print Working Directory

Displays the absolute path of your current location in the filesystem. Essential for orientation.

ls: List Directory Contents

Lists files and directories. Use options for more detail:

  • ls -l: Long listing format (permissions, ownership, size, date)
  • ls -a: Show all files, including hidden ones (starting with '.')
Key Takeaway

pwd confirms your location, and ls (with options) provides detailed views of directory contents.

Terminal Demo: Using pwd and ls
# Identify current directory
pwd

# Expected Output (example):
/home/lpicuser

# List contents of current directory
ls

# Expected Output (example):
Desktop Documents Downloads Public

# Long listing format
ls -l

# Expected Output (example):
drwxr-xr-x 2 lpicuser lpicuser 4096 Feb 28 10:00 Desktop
drwxr-xr-x 2 lpicuser lpicuser 4096 Feb 28 10:00 Documents

# Show all files, including hidden
ls -a

# Expected Output (example):
. .. .bashrc .profile Desktop Documents

Understanding Hidden Files

Files starting with a dot (e.g., .bashrc) are hidden by default. They often contain user-specific configuration settings.
