APT Operations

Upgrading and Installing Packages with apt

Keeping your software current and adding new applications

`sudo apt upgrade`

  • •**Updates Installed Packages:** Upgrades all currently installed packages to their newest versions available in the repositories.
  • •**Security & Stability:** Crucial for applying security patches and bug fixes.
  • •**Dependency Handling:** Resolves dependencies for upgrades automatically.
Example

`sudo apt upgrade` will update packages like `firefox` or `systemd` if newer versions are available.

`sudo apt install `

  • •**Installs New Software:** Downloads and installs a specified package and its dependencies.
  • •**Automatic Dependencies:** Automatically pulls in any other packages required for the software to function.
  • •**Confirmation:** Often prompts for confirmation before proceeding.
Example

`sudo apt install htop` installs the interactive process viewer `htop`.

Key Takeaway

`apt upgrade` keeps your system secure and up-to-date, while `apt install` expands its capabilities with new software.
