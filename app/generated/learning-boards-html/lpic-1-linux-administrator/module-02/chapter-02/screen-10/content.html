Updating and Installing Packages with dnf

Managing software on Red Hat-based systems

`sudo dnf update`

  • •**Refreshes & Upgrades:** Updates package lists AND upgrades all installed packages.
  • •**Combined Operation:** Similar to `apt update` + `apt upgrade` in one command.
  • •**System Health:** Essential for security and stability.
Example

`sudo dnf update` ensures your Fedora system is fully patched.

`sudo dnf install `

  • •**Installs New Software:** Downloads and installs the specified package and its dependencies.
  • •**Dependency Resolution:** DNF automatically handles all required components.
  • •**Confirmation:** Prompts for user confirmation before proceeding.
Example

`sudo dnf install httpd` installs the Apache web server on RHEL/Fedora.

Key Takeaway

`dnf update` handles both refreshing and upgrading, while `dnf install` adds new software with automatic dependency resolution.
