Removing, Searching, and Info with dnf

Comprehensive package management on Red Hat systems

`sudo dnf remove `

  • •**Uninstalls Software:** Removes the specified package and its no-longer-needed dependencies.
  • •**Clean System:** Helps keep your system free of orphaned packages.
  • •**Confirmation:** Prompts for confirmation before removal.
Example

`sudo dnf remove htop` uninstalls the `htop` utility.

`dnf search ` & `dnf info `

  • •**`dnf search`:** Finds packages by keyword in names or descriptions.
  • •**`dnf info`:** Provides detailed metadata for a specific package (version, size, dependencies).
  • •**Informed Decisions:** Essential for discovering and understanding software.
Example

`dnf search firewall` or `dnf info firewalld`.
