APT Operations

Searching and Showing Package Information with apt

Discovering and inspecting software details

`apt search `

  • •**Finds Packages:** Lists packages whose names or descriptions match the keyword.
  • •**Broad Search:** Useful when you don't know the exact package name.
  • •**Output:** Shows package name, version, and a brief description.
Example

`apt search web server` might list `nginx`, `apache2`, etc.

`apt show `

  • •**Detailed Info:** Displays comprehensive information about a specific package.
  • •**Includes:** Version, size, dependencies, description, maintainer, and installed files.
  • •**Invaluable:** Helps understand package functionality and requirements.
Example

`apt show htop` provides details about the `htop` process viewer.

Terminal Commands
$ apt search htop
Sorting... Done
Full Text Search... Done
htop/focal 3.0.5-1build1 amd64
  interactive processes viewer

$ apt show htop
Package: htop
Version: 3.0.5-1build1
Priority: optional
Section: utils
Origin: Ubuntu
Maintainer: Ubuntu Developers <ubuntu-devel-discuss@lists.ubuntu.com>
Bugs: https://bugs.launchpad.net/ubuntu/+filebug
Installed-Size: 288 kB
Depends: libc6 (>= 2.28), libncursesw6 (>= 6), libtinfo6 (>= 6)
Homepage: https://hisham.hm/htop/
Download-Size: 106 kB
APT-Sources: http://archive.ubuntu.com/ubuntu focal/main amd64 Packages
Description: interactive processes viewer
 htop is an interactive process viewer for Linux. It is a text-mode application
 (using ncurses) that shows a frequently updated list of the processes running
 on a computer, normally sorted by the amount of CPU usage.
Key Takeaway

Use `apt search` to find packages and `apt show` to get detailed information before installation.
