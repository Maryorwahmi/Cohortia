Key Concepts: Core Terminology

Essential definitions for package management

Package Manager

Software tools that automate installing, upgrading, configuring, and removing programs.

Package

An archive file containing software, configuration, and metadata about its dependencies.

Repository

A centralized server location where software packages are stored and maintained.

Summary Takeaway

Understanding these core terms is fundamental to navigating and utilizing Linux's powerful package management systems effectively.
