Special Permissions: The Sticky Bit

Understand how the Sticky Bit protects files in shared directories.

Sticky Bit (on Directories)

  • Prevents users from deleting/renaming files they don't own.
  • Applies even if user has write permission to the directory.
  • `x` for others becomes `t` in `ls -l` (e.g., `drwxrwxrwt`).
  • If others lack `x`, it becomes `T`.

Example: The `/tmp` directory commonly has the Sticky Bit set (`drwxrwxrwt`). This allows anyone to create files, but only the owner can delete their own files.

Key Takeaway

The Sticky Bit is a crucial security feature for shared directories, ensuring users can only manage files they own, even with directory write access.

Octal Representation

The Sticky Bit is represented by a leading `1` in octal (e.g., `1777` for `/tmp`).

Security Best Practice

Always apply the Sticky Bit to publicly writable directories to prevent unauthorized file deletion and maintain system integrity.
