Ownership Management

Changing File Ownership: `chown` and `chgrp`

Assign new owners and groups to files and directories.

# Change user owner of a file
sudo chown newuser file.txt
# Example: user:group becomes newuser:group

# Change both user and group owner
sudo chown newuser:newgroup file.txt
# Example: user:group becomes newuser:newgroup

# Change only the group owner
sudo chgrp newgroup file.txt
# Example: user:group becomes user:newgroup

# Recursively change ownership for a directory and its contents
sudo chown -R newuser:newgroup /path/to/directory
Key Takeaway

`chown` modifies user and optionally group ownership, while `chgrp` changes only the group. Both often require `sudo` for security reasons.

`sudo` Requirement

You typically need `sudo` privileges to change the owner of a file, especially if you are not the current owner or if the file is in a system directory. This prevents unauthorized ownership transfers.

Real-world Scenario

In a web server environment, you might `chown` web application files to the `www-data` user and group to ensure the web server process has appropriate access.
