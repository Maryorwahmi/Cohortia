Special Permissions: SUID and SGID

Understand how SUID and SGID affect execution and group inheritance.

SUID (Set User ID)

  • Executable runs with owner's permissions.
  • `x` for owner becomes `s` in `ls -l` (e.g., `-rwsr-xr-x`).
  • Example: `passwd` command.

SGID (Set Group ID)

  • Executable runs with group's permissions.
  • Directory: new files inherit parent's group.
  • `x` for group becomes `s` (e.g., `-rwxr-sr-x`).

Security Implication: Misconfigured SUID/SGID binaries can be exploited to gain elevated privileges. Always audit and restrict their use.

Key Takeaway

SUID and SGID grant temporary elevated privileges or enforce group inheritance, but require careful management due to security risks.

Octal Representation

SUID is represented by a leading `4` in octal (e.g., `4755`). SGID is represented by a leading `2` (e.g., `2775`).

Real-world Example (SGID)

A shared `/project` directory with SGID set ensures all new files created by different users automatically belong to the `devs` group, simplifying collaboration.
