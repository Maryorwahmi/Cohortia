Permission Management

`chmod` with Symbolic Mode

Use letters and symbols for incremental permission changes.

Who

  • `u` (user)
  • `g` (group)
  • `o` (others)
  • `a` (all)

Operator

  • `+` (add)
  • `-` (remove)
  • `=` (set exact)

Permissions

  • `r` (read)
  • `w` (write)
  • `x` (execute)

Symbolic Mode Structure:

chmod [who][operator][permissions] file/directory

Key Takeaway

Symbolic mode offers a flexible, human-readable way to add, remove, or set specific permissions for user, group, or others.

Example Command

To add execute permission for the owner on `script.sh`, you would use `chmod u+x script.sh`.

Pro Tip

Use symbolic mode when you need to make small, targeted adjustments to permissions without affecting other existing rights.
