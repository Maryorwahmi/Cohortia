Permission Management

`chmod` with Octal Mode

Use numeric values to set precise file and directory permissions.

Read (r) = 4

Write (w) = 2

Execute (x) = 1

Calculating Octal Values:

  • `rwx` = 4 + 2 + 1 = 7
  • `rw-` = 4 + 2 + 0 = 6
  • `r-x` = 4 + 0 + 1 = 5
  • `r--` = 4 + 0 + 0 = 4
  • `---` = 0 + 0 + 0 = 0
Key Takeaway

Octal mode provides a concise, numeric way to define permission sets by summing the values of read (4), write (2), and execute (1).

Example Command

To set permissions to `rw-r--r--` (owner read/write, group/others read-only), you would use `chmod 644 file.txt`.

Pro Tip

Memorizing the basic octal values (7 for rwx, 6 for rw-, 5 for r-x, 4 for r--) will significantly speed up your permission management tasks.
