Practical Application

Symbolic `chmod` in Practice

Execute common permission changes using symbolic notation.

# Add execute permission for the owner
chmod u+x script.sh
# Example: -rw-r--r-- becomes -rwxr--r--

# Remove write permission for group and others
chmod go-w file.txt
# Example: -rw-rw-r-- becomes -rw-r--r--

# Set exact permissions: owner rw, group r, others no access
chmod u=rw,g=r,o= file.txt
# Result: -rw-r-----

# Grant full read, write, execute to all (use with caution!)
chmod a=rwx my_directory
# Result: drwxrwxrwx
Key Takeaway

Symbolic mode is highly effective for making specific, incremental permission changes without affecting other existing rights.

Comparison

While octal mode is good for setting a complete permission state, symbolic mode shines when you only need to add or remove a single permission.

Security Best Practice

Always review the permissions after using `chmod` with `ls -l` to ensure they are set as intended and adhere to the principle of least privilege.
