Practical Application

Octal `chmod` in Action

Apply common octal permission values to files and scripts.

# Scenario 1: Private document, readable by others
chmod 644 document.txt
# Result: -rw-r--r--

# Scenario 2: Executable script for owner, readable/executable for others
chmod 755 script.sh
# Result: -rwxr-xr-x

# Scenario 3: Highly restricted configuration file (owner only)
chmod 600 config.yaml
# Result: -rw-------

# Scenario 4: Shared directory (owner full, group rwx, others r-x)
chmod 775 shared_folder
# Result: drwxrwxr-x
Key Takeaway

Octal mode allows for quick and precise permission setting, with `644` and `755` being common values for files and executables respectively.

Security Warning

Avoid using `chmod 777` (`rwxrwxrwx`) unless absolutely necessary, as it grants full read, write, and execute permissions to everyone, creating a major security risk.

Real-world Use

When deploying web applications, configuration files often use `640` (owner rw, group r, others no access) to protect sensitive data from public view.
