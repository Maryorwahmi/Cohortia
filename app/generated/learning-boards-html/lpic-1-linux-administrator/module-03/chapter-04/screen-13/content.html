awk: BEGIN and END Blocks

Execute commands before processing the first line or after the last line.

Purpose of BEGIN/END Blocks

  • •BEGIN block: Executes once before processing any input lines.
  • •END block: Executes once after processing all input lines.
  • •Ideal for printing headers, footers, or summary information.
Key Takeaway

BEGIN and END blocks provide powerful control over report formatting, allowing you to add context and summaries to your awk output.

Report Generation Example

Create a simple user report from /etc/passwd with a header and footer.

# Print a report with header and footer
awk -F':' 'BEGIN { print "--- User Report ---" } { print "User: "$1", UID: "$3 } END { print "--- End Report ---" }' /etc/passwd
# Expected output (first few lines):
# --- User Report ---
# User: root, UID: 0
# User: daemon, UID: 1
# --- End Report --- (after all lines)
Real-world Connection

This feature is invaluable for generating daily system health reports, summarizing log file statistics, or creating custom inventory lists with clear formatting.

Pro-Tip

You can also use BEGIN to set variables like the output field separator (OFS) for cleaner output formatting, e.g., BEGIN { OFS="," }.
