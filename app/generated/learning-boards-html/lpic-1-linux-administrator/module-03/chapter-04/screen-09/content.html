sed: Deleting Lines and Piping

Learn to remove lines based on patterns and integrate sed into command pipelines.

Deleting Lines (`d` command)

  • •The d command deletes lines that match a specified pattern.
  • •Syntax: sed '/pattern_to_match/d' file.txt.
  • •Useful for filtering out unwanted log entries or configuration comments.
Key Takeaway

sed's ability to delete lines and integrate into pipelines makes it a flexible tool for filtering and transforming data streams.

Deleting Lines Example

Let's create a sample file and then delete lines containing a specific word.

# Create a sample file
echo -e "Line 1: Active user
Line 2: Inactive user
Line 3: Active process" > status.txt

# Delete lines containing 'Inactive'
sed '/Inactive/d' status.txt
# Expected output:
# Line 1: Active user
# Line 3: Active process

Piping with `sed`

sed can process input from a pipe, making it a powerful component in command chains.

# Pipe cat output to sed for substitution
cat log.txt | sed 's/ERROR/WARNING/g'

Real-world Connection

Imagine a large log file where you only want to see 'INFO' messages and remove all 'DEBUG' entries. You could use grep INFO log.txt | sed '/DEBUG/d' to achieve this, demonstrating the power of pipelines.
