cut: Selecting Specific Fields

Use the -f option to extract single, multiple, or ranges of fields.

The `-f` Option

  • •Specifies which fields (columns) to extract from each line.
  • •Can select a single field (e.g., -f1).
  • •Can select a range of fields (e.g., -f1-3).
  • •Can select a comma-separated list of fields (e.g., -f1,5).
Key Takeaway

Combine -d and -f to precisely target and extract desired data from structured files.

`cut` Examples with `/etc/passwd`

The /etc/passwd file uses a colon (:) as a delimiter, with fields like username, password hash, UID, GID, comment, home directory, and shell.

# Get usernames (first field)
cut -d':' -f1 /etc/passwd
# Expected output (first few lines):
# root
# daemon
# bin

# Get username and home directory (first and sixth fields)
cut -d':' -f1,6 /etc/passwd
# Expected output (first few lines):
# root:/root
# daemon:/usr/sbin
# bin:/bin
Scenario Card

You need to quickly list all user accounts and their primary shells. Using cut -d':' -f1,7 /etc/passwd would provide this exact information.

Limitation of `cut`

cut is excellent for simple column extraction but cannot perform complex pattern matching or conditional logic, which requires more advanced tools.
