Critical Feature

sed: In-Place Editing (-i option)

Directly modify files with sed, but always with caution and backups.

Understanding `-i`

  • •The -i option modifies the original file directly, overwriting its content.
  • •Changes are permanent and irreversible.
  • •Extremely useful for automating configuration updates.
Key Takeaway

sed -i is powerful for direct file modification, but always prioritize backups and testing to prevent data loss.

In-Place Editing Example

Let's change a database host in a configuration file directly.

# Create a sample config file
echo "database_host=old_db_server" > config.ini

# 1. ALWAYS BACKUP FIRST!
cp config.ini config.ini.bak

# 2. Test the command without -i (optional but recommended)
sed 's/old_db_server/new_db_server/g' config.ini

# 3. Perform in-place replacement
sed -i 's/old_db_server/new_db_server/g' config.ini

# Verify the change
cat config.ini
# Expected output: database_host=new_db_server
Safety Warning

Changes made with sed -i are permanent. Always back up files before using this option to prevent accidental data loss or corruption.

Pro-Tip

For `sed -i`, you can provide an extension to create a backup automatically, e.g., `sed -i.bak 's/old/new/' file.txt` will create `file.txt.bak`.
