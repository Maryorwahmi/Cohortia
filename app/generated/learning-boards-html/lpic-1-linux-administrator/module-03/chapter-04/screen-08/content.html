Advanced `sed`

Global Substitution and Custom Delimiters

Enhance sed's substitution power with the g flag and alternative delimiters.

The Global (`g`) Flag

  • •By default, sed's s command replaces only the first match on a line.
  • •Adding the g flag at the end of the command replaces *all* occurrences on a line.
  • •Essential for comprehensive text clean-up or mass updates within lines.
Key Takeaway

The g flag and custom delimiters make sed more robust and adaptable for complex text manipulation tasks.

Global Substitution Example

Observe how the g flag changes the behavior of the substitution command.

# Replace all 'error' with 'warning'
echo "An error occurred, another error." | sed 's/error/warning/g'
# Output: An warning occurred, another warning.

# Without 'g' flag (for comparison)
echo "An error occurred, another error." | sed 's/error/warning/'
# Output: An warning occurred, another error.

Custom Delimiters

If your pattern or replacement contains slashes, you can use a different character as a delimiter (e.g., |, #).

# Using '|' as delimiter for paths
sed 's|/old/path|/new/path|g' file.txt

Why it matters

Using custom delimiters prevents 'leaning toothpick syndrome' (too many backslashes) when dealing with paths or URLs, making your scripts more readable and less error-prone.
