Introducing sed: The Stream Editor

Perform non-interactive text substitutions and transformations line by line.

What is `sed`?

  • •A non-interactive command-line text editor.
  • •Processes text line by line, applying commands to each line.
  • •Incredibly powerful for substitutions, deletions, and insertions.
  • •By default, outputs to standard output; does not modify the original file.
Key Takeaway

sed is a versatile tool for automating text changes across multiple lines or entire files.

Basic Substitution (`s` command)

The s command is the most common sed operation, replacing a pattern with new text. By default, it replaces only the first occurrence on each line.

# Syntax: sed 's/old_pattern/new_pattern/' file.txt

# Example: Replace 'error' with 'warning' (first occurrence)
echo "An error occurred, another error." | sed 's/error/warning/'
# Output: An warning occurred, another error.

# Example: Replace 'old_db' with 'new_db' in config.conf
sed 's/old_db/new_db/' config.conf
Pro-Tip

Always enclose sed commands in single quotes to prevent the shell from interpreting special characters within your patterns.

Analogy Card

Think of sed like a find-and-replace function in a word processor, but operating automatically on a stream of text, line by line, without needing to open the file interactively.
