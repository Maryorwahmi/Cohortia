More `grep` Options in Action

Explore additional grep options to enhance your search capabilities, including line numbering, recursive directory searches, and match counting.

# Create a multi-line file
echo "Line one: Apple is red." > fruits.txt
echo "Line two: Banana is yellow." >> fruits.txt
echo "Line three: Orange is orange." >> fruits.txt
echo "Line four: Grape is green." >> fruits.txt

# Search for 'orange' with line numbers
grep -n "orange" fruits.txt

# Count lines containing 'Line'
grep -c "Line" fruits.txt

# Search for whole word 'is'
grep -w "is" fruits.txt
3:Line three: Orange is orange.
---
4
---
Line one: Apple is red.
Line two: Banana is yellow.
Line three: Orange is orange.
Line four: Grape is green.
Key Takeaway

grep's advanced options provide granular control over searches, from line numbering to recursive directory traversal and match counting.

Key Advanced `grep` Options

  • •-n: Display line numbers with matching lines.
  • •-r or -R: Recursively search through directories.
  • •-c: Count the number of matching lines.
  • •-w: Match the whole word only.
Pro Tip

For very complex patterns, grep supports regular expressions, which we'll briefly touch upon in the next chapter.

Common Mistake

Using grep -r on a root directory without specifying a pattern, which can take a very long time and consume significant resources.
