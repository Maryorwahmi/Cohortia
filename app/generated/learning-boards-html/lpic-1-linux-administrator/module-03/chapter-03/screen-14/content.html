Using `<` for Input

The < operator redirects the content of a file as standard input to a command. This is an alternative to specifying the filename as an argument.

# Create an unsorted data file
echo "Banana" > unsorted.txt
echo "Apple" >> unsorted.txt
echo "Orange" >> unsorted.txt

# Sort using input redirection
sort < unsorted.txt

# Equivalent command without input redirection
sort unsorted.txt
Apple
Banana
Orange
---
Apple
Banana
Orange
Key Takeaway

Input redirection (`<`) provides flexibility in how commands receive data, especially useful in complex scripting or when a command expects stdin.

When to Use Input Redirection

  • •When a command is designed to read from standard input only.
  • •In complex shell scripts where you want to explicitly control data flow.
  • •As an alternative syntax for commands that also accept filenames as arguments.
Pro Tip

While often interchangeable with direct filename arguments, understanding < is crucial for mastering advanced shell scripting.

Common Mistake

Confusing < with >. Remember, the arrow points in the direction of data flow: < means data flows *into* the command, > means data flows *out* of the command.
