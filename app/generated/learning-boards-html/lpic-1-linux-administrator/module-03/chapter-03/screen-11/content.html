`uniq` and the Importance of `sort`

uniq filters adjacent duplicate lines. For comprehensive duplicate removal, always sort the file first.

# Create a file with non-adjacent duplicates
echo "Alice" > names.txt
echo "Bob" >> names.txt
echo "Alice" >> names.txt
echo "Charlie" >> names.txt
echo "Bob" >> names.txt
echo "Alice" >> names.txt

# Incorrect: uniq without sort
uniq names.txt

# Correct: sort then uniq
sort names.txt | uniq

# Count unique occurrences
sort names.txt | uniq -c
Alice
Bob
Alice
Charlie
Bob
Alice
---
Alice
Bob
Charlie
---
3 Alice
2 Bob
1 Charlie
Key Takeaway

Always pipe the output of sort to uniq to ensure all duplicates are correctly identified and filtered, not just adjacent ones.

`uniq` Options

  • •(Default): Filters out adjacent duplicate lines.
  • •-c: Prefix lines by the number of occurrences.
  • •-d: Only print duplicate lines.
  • •-u: Only print unique lines (non-duplicated).
Pro Tip

The combination sort | uniq -c is incredibly powerful for frequency analysis of text data.

Common Mistake

Using uniq without first sorting the file. This will only remove *adjacent* duplicates, leading to incomplete results.
