The `cat` Command

The cat command (short for concatenate) reads files sequentially and prints their contents to standard output. It's best for quick views of small files.

# Create a sample file
echo "Hello, Linux!" > greeting.txt
echo "This is a small file." >> greeting.txt

# View its content
cat greeting.txt
Hello, Linux!
This is a small file.
Key Takeaway

Use cat for quick, full displays of small text files. For larger files, it's inefficient as content scrolls too fast.

When to Use `cat`

  • •Viewing short configuration files (e.g., /etc/hostname).
  • •Displaying small scripts or code snippets.
  • •Concatenating multiple small files into one (e.g., cat file1.txt file2.txt > combined.txt).
Pro Tip

While cat can concatenate, its primary use for viewing is best limited to files that fit comfortably on a single screen.

Common Mistake

Using cat on very large files. The content will scroll by too quickly, making it impossible to read or analyze effectively.
