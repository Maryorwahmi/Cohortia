`>` (Overwrite) vs. `>>` (Append)

The > operator redirects output, overwriting the file. The >> operator appends output to the file.

# Create a file with initial content
echo "First line" > output.txt
cat output.txt

# Overwrite the file
echo "Second line" > output.txt
cat output.txt

# Append to the file
echo "Third line" >> output.txt
cat output.txt

---

Third line
Key Takeaway

Use > to save command output, but be cautious as it overwrites. Use >> to safely add content to an existing file.

Practical Uses of Output Redirection

  • •Saving command output (e.g., ls -l > files.txt).
  • •Creating new files with specific content (e.g., echo "Hello" > hello.txt).
  • •Adding log entries to an existing log file (e.g., echo "Error occurred" >> error.log).
Pro Tip

You can redirect standard error (stderr) as well, using 2> or 2>>, which is useful for capturing error messages separately.

Common Mistake

Accidentally overwriting a critical file with > when you intended to append with >>. Always double-check!
