Using `head` and `tail`

head and tail allow you to view the first or last lines of a file, respectively. Use the -n option to specify the number of lines.

# Create a sample log file
echo "Line 1: Server start" > server.log
echo "Line 2: Initializing" >> server.log
echo "Line 3: User login" >> server.log
echo "Line 4: Process A started" >> server.log
echo "Line 5: Process B finished" >> server.log

# View the first 3 lines
head -n 3 server.log

# View the last 2 lines
tail -n 2 server.log
Line 1: Server start
Line 2: Initializing
Line 3: User login
---
Line 4: Process A started
Line 5: Process B finished
Key Takeaway

head and tail provide quick, focused views of file extremities, saving time and resources compared to viewing entire large files.

Practical Applications

  • •Checking the first few lines of a configuration file for critical settings.
  • •Reviewing the most recent entries in a system log file.
  • •Verifying the output of a batch job or script.
Pro Tip

Combine head or tail with other commands using pipes for more complex filtering, which we'll cover later.

Common Mistake

Forgetting the -n option when you need a specific number of lines, resulting in the default 10 lines being displayed.
