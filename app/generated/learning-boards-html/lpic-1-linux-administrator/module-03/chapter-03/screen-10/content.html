Basic `sort` and Options

The sort command arranges lines of text. Use options like -r for reverse, -n for numeric, and -k for specific fields.

# Create a sample data file
echo "Banana" > fruits.txt
echo "Apple" >> fruits.txt
echo "Orange" >> fruits.txt
echo "Grape" >> fruits.txt

# Sort alphabetically
sort fruits.txt

# Sort in reverse alphabetical order
sort -r fruits.txt

# Create a numeric file
echo "10" > numbers.txt
echo "2" >> numbers.txt
echo "1" >> numbers.txt

# Sort numerically
sort -n numbers.txt
Apple
Banana
Grape
Orange
---
Orange
Grape
Banana
Apple
---
1
2
10
Key Takeaway

sort is essential for organizing text data, with options to control order (ascending/descending) and data type (alphabetic/numeric).

Useful `sort` Options

  • •-r: Reverse the sort order (descending).
  • •-n: Sort numerically (important for numbers).
  • •-k N: Sort by a specific field (column) N.
  • •-u: Output only unique lines after sorting.
Pro Tip

When sorting by fields, remember that fields are typically delimited by whitespace by default, but you can specify other delimiters.

Common Mistake

Forgetting -n when sorting numbers, leading to incorrect order (e.g., '10' before '2' because '1' comes before '2' alphabetically).
