Basic `grep` Usage

grep "pattern" filename.txt prints lines containing the specified pattern. Options like -i and -v modify search behavior.

# Create a sample log file
echo "INFO: Server started" > app.log
echo "WARN: Low disk space" >> app.log
echo "ERROR: Database connection failed" >> app.log
echo "info: User 'admin' logged in" >> app.log
echo "WARN: High CPU usage" >> app.log

# Search for 'ERROR'
grep "ERROR" app.log

# Search for 'info' (case-insensitive)
grep -i "info" app.log

# Show lines that DO NOT contain 'WARN'
grep -v "WARN" app.log
ERROR: Database connection failed
---
INFO: Server started
info: User 'admin' logged in
---
INFO: Server started
ERROR: Database connection failed
info: User 'admin' logged in
Key Takeaway

grep is fundamental for filtering text. Use -i for case-insensitivity and -v to exclude lines matching a pattern.

Common `grep` Options

  • •-i: Ignore case distinctions in patterns and input data.
  • •-v: Invert the sense of matching, to select non-matching lines.
  • •-n: Prefix each line of output with the 1-based line number within its input file.
Pro Tip

Always enclose your pattern in double quotes to prevent shell interpretation issues, especially with spaces or special characters.

Common Mistake

Forgetting that grep is case-sensitive by default. Use -i when you need to match regardless of case.
