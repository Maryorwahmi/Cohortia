Essential Navigation

Locating Your Position: pwd and cd

Moving through the filesystem using absolute and relative paths.

pwd: Print Working Directory

Shows your current location as an absolute path from the root (/). Always use it to confirm your position.

cd: Change Directory

Moves you to a different directory. Can use absolute paths (/etc/nginx) or relative paths (.., ~).

Key Takeaway

pwd and cd are your primary tools for understanding and changing your current location in the Linux filesystem.

Terminal Demo: Navigating with pwd and cd
user@host:~$ pwd
/home/user

user@host:~$ cd /etc

user@host:/etc$ pwd
/etc

user@host:/etc$ cd ..

user@host:/$ pwd
/

user@host:/$ cd ~

user@host:~$ pwd
/home/user

user@host:~$ cd

user@host:~$ pwd
/home/user
