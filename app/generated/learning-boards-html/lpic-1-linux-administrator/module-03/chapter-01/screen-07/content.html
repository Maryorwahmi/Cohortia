Inspecting Files

The ls Command: Listing Files and Directories

Viewing contents with basic and detailed options.

ls (default)

Lists names of files and directories in the current working directory. Simple and quick overview.

ls -l (Long Listing)

Shows detailed information: permissions, owner, group, size, modification date, and filename. Essential for file attributes.

ls -a (All Files)

Includes hidden files (those starting with a dot .). Reveals configuration files often hidden by default.

Key Takeaway

ls is your window into a directory's contents; use options like -l and -a for comprehensive details and hidden files.
