Duplicating Content

The cp Command: Making Copies

Replicating files and entire directory structures.

cp source_file destination

Copies a file. If destination is a directory, the file is copied into it with its original name. If destination is a new filename, the file is copied and renamed.

cp -r source_dir destination_dir

Recursively copies a directory and all its contents (files and subdirectories) to a new location. Essential for full backups.

Key Takeaway

Use cp for files and cp -r for directories to create duplicates, ensuring you always have backups or copies as needed.

Terminal Demo: Copying Files and Directories
user@host:~$ touch file1.txt file2.txt

user@host:~$ mkdir backups project_data

user@host:~$ cp file1.txt backups/

user@host:~$ ls backups
file1.txt

user@host:~$ cp file2.txt file2_copy.txt

user@host:~$ ls
backups  file1.txt  file2.txt  file2_copy.txt  project_data

user@host:~$ touch project_data/config.ini project_data/main.py

user@host:~$ cp -r project_data project_data_backup

user@host:~$ ls -R project_data_backup
project_data_backup:
config.ini  main.py
