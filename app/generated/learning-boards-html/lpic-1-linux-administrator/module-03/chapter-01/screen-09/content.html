File Creation

touch and mkdir: Bringing Files and Folders to Life

Creating empty files and single or nested directories.

touch: Create Empty Files

Creates a new, empty file if it doesn't exist, or updates the access/modification timestamps of an existing file. Example: touch report.txt.

mkdir: Make Directories

Creates a new directory. Use mkdir -p to create parent directories if they don't exist. Example: mkdir -p project/src/main.

Key Takeaway

touch and mkdir are fundamental for structuring your filesystem, allowing you to create files and complex directory hierarchies with ease.

Terminal Demo: Creating Files and Directories
user@host:~$ pwd
/home/user

user@host:~$ touch my_notes.txt

user@host:~$ ls
Desktop  Documents  Downloads  my_notes.txt  Public  Templates  Videos

user@host:~$ mkdir new_project

user@host:~$ ls
Desktop  Documents  Downloads  my_notes.txt  new_project  Public  Templates  Videos

user@host:~$ mkdir -p reports/daily/2023

user@host:~$ ls -R reports
reports:
daily

reports/daily:
2023
