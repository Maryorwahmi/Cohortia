File Deletion

rmdir and rm: Deleting with Caution

Understanding the differences and dangers of file and directory removal.

rmdir: Remove Empty Directories

Only removes directories that are completely empty. Fails if the directory contains any files or subdirectories.

rm: Remove Files and Directories

Removes files. Use -r for recursive deletion of non-empty directories and their contents. Caution: No undo!

Danger: rm -rf /

This command attempts to delete your entire filesystem without prompting. Never run this unless you fully understand the consequences.

Key Takeaway

Always double-check your target and options when using rm, especially with -r, as deletions are permanent.

Terminal Demo: Removing Files and Directories
user@host:~$ mkdir empty_dir filled_dir

user@host:~$ touch filled_dir/file.txt

user@host:~$ ls -R
.:
empty_dir  filled_dir

./filled_dir:
file.txt

user@host:~$ rmdir empty_dir

user@host:~$ rmdir filled_dir
rmdir: failed to remove 'filled_dir': Directory not empty

user@host:~$ rm filled_dir/file.txt

user@host:~$ rmdir filled_dir

user@host:~$ mkdir -p complex_dir/sub_dir/data

user@host:~$ touch complex_dir/sub_dir/data/important.log

user@host:~$ rm -r complex_dir

user@host:~$ ls
Desktop  Documents  Downloads  my_notes.txt  new_project  Public  Templates  Videos
