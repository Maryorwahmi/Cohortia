Key Concepts: Filesystem Structure & Navigation

Essential terms and commands for understanding and moving through the Linux filesystem.

Filesystem Hierarchy Standard (FHS)

A standard defining the logical directory structure and content for Linux operating systems.

Root Directory (/)

The top-level directory in the Linux filesystem, from which all other directories branch.

Absolute Path

The full path to a file or directory starting from the root directory (e.g., /home/user/documents).

Relative Path

The path to a file or directory relative to the current working directory (e.g., ../documents).

pwd Command

Prints the current working directory, showing your exact location in the filesystem hierarchy.

cd Command

Changes the current working directory, allowing navigation using both absolute and relative paths.

Summary Takeaway

Mastering the Linux filesystem structure and navigation commands is foundational for effective command-line administration.
