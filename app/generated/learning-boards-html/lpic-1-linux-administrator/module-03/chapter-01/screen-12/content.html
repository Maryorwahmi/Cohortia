The mv Command: Relocating and Renaming

Changing file locations and names within the filesystem.

mv old_name new_name (Rename)

Renames a file or directory within the same location. Example: mv report.txt final_report.txt.

mv source_path destination_path (Move)

Moves a file or directory to a new location. The original item is removed from the source. Example: mv file.txt /new/location/.

Key Takeaway

mv is a versatile command for both renaming and relocating files and directories, crucial for maintaining an organized filesystem.

Terminal Demo: Moving and Renaming
user@host:~$ touch old_report.txt

user@host:~$ ls
Desktop  Documents  Downloads  my_notes.txt  new_project  old_report.txt  Public  Templates  Videos

user@host:~$ mv old_report.txt final_report.txt

user@host:~$ ls
Desktop  Documents  Downloads  final_report.txt  my_notes.txt  new_project  Public  Templates  Videos

user@host:~$ mkdir important_docs

user@host:~$ mv final_report.txt important_docs/

user@host:~$ ls
Desktop  Documents  Downloads  important_docs  my_notes.txt  new_project  Public  Templates  Videos

user@host:~$ ls important_docs
final_report.txt

user@host:~$ mkdir source_dir

user@host:~$ touch source_dir/data.log

user@host:~$ mv source_dir new_project/

user@host:~$ ls new_project
source_dir

user@host:~$ ls source_dir
ls: cannot access 'source_dir': No such file or directory
