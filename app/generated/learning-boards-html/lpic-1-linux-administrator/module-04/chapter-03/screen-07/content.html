Argument Handling
Differentiating `$@` and `$*`
Explore how Bash treats all arguments as separate words versus a single string.
`"$@"` (Preferred)

Expands to all arguments as separate, individually quoted words. Preserves spaces within arguments.

#!/bin/bash# script.shfor arg in "$@"; do echo "Argument: $arg"done# Execution:./script.sh "hello world" argument2# Output:# Argument: hello world# Argument: argument2
`"$*"` (Less Common)

Expands to all arguments as a single, quoted string, separated by the first character of `IFS` (default is space).

#!/bin/bash# script.shecho "All arguments as one string: \"$*\""# Execution:./script.sh "hello world" argument2# Output:# All arguments as one string: "hello world argument2"
Key Takeaway

Always double-quote `"$@"` when iterating or passing arguments to preserve individual argument integrity, especially with spaces.
