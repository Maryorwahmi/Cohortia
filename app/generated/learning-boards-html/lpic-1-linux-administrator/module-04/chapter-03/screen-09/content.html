Tracing Script Execution with `set -x`
Enable xtrace mode to see commands and variable expansions before execution.
What is `set -x`?

`set -x` activates xtrace mode, causing Bash to print each command and its arguments to standard error before execution, prefixed with `+`.

Full Script Debugging

Place `set -x` at the beginning of your script to trace all commands.

Targeted Debugging

Use `set -x` before a problematic section and `set +x` after it to limit the trace output.

Pro Tip

Combine `set -x` with redirection (`2> debug.log`) to capture debug output to a file for later analysis.

Example: Using `set -x`
#!/bin/bashecho "Starting script..."# ... some initial script logic ...echo "Entering problematic section..."set -x # Enable debuggingVAR1="valueA"VAR2="valueB"echo "Combined: $VAR1 $VAR2"# ... more commands in the problematic section ...set +x # Disable debuggingecho "Exited problematic section."# Execution output with set -x:# Starting script...# Entering problematic section...# + VAR1="valueA"# + VAR2="valueB"# + echo 'Combined: valueA valueB'# Combined: valueA valueB# + set +x# Exited problematic section.
Key Takeaway

`set -x` provides a detailed trace of command execution and variable expansion, making it invaluable for debugging complex script logic.
