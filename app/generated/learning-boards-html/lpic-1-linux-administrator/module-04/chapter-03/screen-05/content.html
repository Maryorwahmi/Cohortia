Passing Arguments and Local Variables
Understand how to pass data to functions and manage variable scope with `local`.
Arguments in Functions

Functions receive arguments just like scripts do, using positional parameters (`$1`, `$2`, etc.) within their body.

The `local` Keyword

Declaring variables with `local` inside a function limits their scope to that function, preventing accidental modification of global variables.

Common Mistake

Forgetting `local` can lead to unexpected behavior where a function overwrites a global variable with the same name, causing hard-to-trace bugs.

Example: `log_message` Function with `local`
#!/bin/bash# Function to log messages with a timestamplog_message() {    local MESSAGE="$1" # Use 'local' for function-scoped variable    echo "$(date '+%Y-%m-%d %H:%M:%S') - $MESSAGE"}# Main script logiclog_message "Script started."# ... perform some tasks ...log_message "Performing task A."sleep 1log_message "Task A completed."log_message "Script finished."
Key Takeaway

Always use `local` for variables within functions to prevent global scope pollution and ensure predictable script behavior.
