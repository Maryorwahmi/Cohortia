User Interaction
Prompting for User Input
Use the `read` command to gather interactive input from the user.
The `read` Command

`read` pauses script execution, displays a prompt, and waits for the user to type input, storing it into a specified variable.

`-p` Option

Displays a custom prompt message before waiting for input (e.g., `read -p "Enter name: " NAME`).

`-s` Option

Enables 'silent' input, useful for passwords or sensitive data, preventing characters from being displayed.

Real-world Use

Confirmations (y/N), password entry, configuration settings, or dynamic data collection.

Example: Interactive Input
#!/bin/bash# interactive_script.shread -p "What is your name? " USER_NAMEecho "Hello, $USER_NAME!"read -s -p "Enter your secret password: " SECRET_PASSecho "
Password received (not displayed)."# Execution:./interactive_script.sh# Output (user input in bold):# What is your name? Alice# Hello, Alice!# Enter your secret password: (input not shown)# Password received (not displayed).
Key Takeaway

The `read` command is essential for creating interactive scripts that can dynamically gather information from the user.
