Error Handling
Controlling Script Flow with `exit` and `$?`
Use `exit` to control script termination and `$?` to check command results.
The `$?` Variable

Contains the exit status of the most recently executed foreground command. It's crucial for conditional logic.

The `exit` Command

Terminates the script immediately with a specified exit status. `exit 0` for success, `exit 1` (or other non-zero) for failure.

Practical Application

Ensures that dependent operations don't proceed if a critical prerequisite command fails, making scripts more reliable.

Example: Conditional Exit
#!/bin/bash# script_with_exit.shecho "Attempting a critical operation..."cp /non/existent/path/file.txt /tmp/if [ $? -ne 0 ]; then    echo "Error: Critical operation failed. Exiting."    exit 1 # Exit with a non-zero status for errorfiecho "Critical operation succeeded. Continuing script..."exit 0 # Exit with zero status for success# Execution:# Attempting a critical operation...# cp: cannot stat '/non/existent/path/file.txt': No such file or directory# Error: Critical operation failed. Exiting.
Key Takeaway

Always use `if [ $? -ne 0 ]` to check for command failures and `exit` with appropriate statuses to control script flow and signal outcomes.
