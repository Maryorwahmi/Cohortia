Exit Statuses: Signaling Success or Failure
Learn how commands and scripts communicate their outcome using integer codes.
What is an Exit Status?

An integer value returned by every command or script upon completion, indicating whether it succeeded or failed.

`0` (Zero)

Conventionally indicates successful execution.

Non-Zero (1-255)

Indicates an error or failure. Specific values can denote different error types.

Why it Matters

Allows scripts to make intelligent decisions based on the outcome of previous commands, enabling robust error handling and conditional execution.

Example: Checking Exit Status
#!/bin/bash# Try to copy a file that might not existcp non_existent_file.txt /tmp/echo "Exit status of cp: $?"# Try to copy an existing filetouch existing_file.txtcp existing_file.txt /tmp/echo "Exit status of cp: $?"# Expected Output:# cp: cannot stat 'non_existent_file.txt': No such file or directory# Exit status of cp: 1# Exit status of cp: 0
Key Takeaway

Always check the exit status (`$?`) of critical commands to ensure your script reacts appropriately to success or failure.
