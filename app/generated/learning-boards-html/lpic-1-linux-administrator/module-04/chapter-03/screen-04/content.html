Functions: Building Reusable Code Blocks
Define and call named blocks of code to enhance script organization.
What is a Function?

A function in Bash is a named block of commands that you can define once and execute multiple times throughout your script. It acts like a mini-program within your main script.

Benefit: Modularity

Breaks down complex scripts into smaller, manageable units.

Benefit: Reusability

Avoids repeating code, making scripts more efficient and easier to update.

Benefit: Readability

Organized code is easier to understand and debug for yourself and others.

Benefit: Maintainability

Changes to a function only need to be made in one place.

Function Syntax & Example
# Basic Function Definitionfunction greet_user() {    echo "Hello, $1!"}# Alternative Syntaxmy_function() {    echo "This is my function."}# Calling a functiongreet_user "Alice"my_function# Expected Output:# Hello, Alice!# This is my function.
Key Takeaway

Functions are fundamental for writing clean, efficient, and scalable shell scripts by promoting code reuse and organization.
