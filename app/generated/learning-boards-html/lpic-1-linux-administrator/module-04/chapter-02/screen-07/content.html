MULTI-BRANCH LOGIC

Streamlining Decisions with `case`

Handle multiple possible conditions cleanly with pattern matching.

service_control.sh
#!/bin/bash

ACTION="$1"

case "$ACTION" in
    start)
        echo "Starting service..."
        # command to start service
        ;;
    stop)
        echo "Stopping service..."
        # command to stop service
        ;;
    restart)
        echo "Restarting service..."
        # command to restart service
        ;;
    status)
        echo "Checking service status..."
        # command to check status
        ;;
    *)
        echo "Usage: $0 {start|stop|restart|status}"
        exit 1
        ;;
esac

`case` Statement Structure

  • `case "$VARIABLE" in`: Specifies the variable to evaluate.
  • `pattern)`: Defines a pattern to match.
  • `commands ;;`: Commands to execute if pattern matches, `;;` ends the block.
  • `*)`: Default pattern, matches anything not caught by previous patterns.
  • `esac`: Marks the end of the `case` statement.

Pattern Matching

Patterns can include wildcards (e.g., `*` for any string, `?` for any single character, `[a-z]` for character ranges). Multiple patterns can be separated by `|` (OR).

Key Takeaway

`case` statements offer a clean, readable way to handle multiple distinct conditions, especially useful for parsing command-line arguments or menu selections.
