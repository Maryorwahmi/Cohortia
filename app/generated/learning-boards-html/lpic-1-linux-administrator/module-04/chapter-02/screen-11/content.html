Reading Files Line by Line

Use `while` loops to process text files efficiently.

read_file_lines.sh
#!/bin/bash

# Create a dummy file for demonstration
echo -e "Line 1: Hello World
Line 2: Bash Scripting
Line 3: End of File" > /tmp/sample.txt

# Read file line by line
echo "Reading /tmp/sample.txt:"
while IFS= read -r line;
do
    echo "  - Processed: '$line'"
done < /tmp/sample.txt

echo "
---"

# Example: Counting lines in a file (alternative to wc -l)
LINE_COUNT=0
while IFS= read -r line;
do
    LINE_COUNT=$((LINE_COUNT + 1))
done < /tmp/sample.txt
echo "Total lines counted: $LINE_COUNT"

# Clean up dummy file
rm /tmp/sample.txt

Key Components for Reading Lines

  • `IFS=`: Prevents leading/trailing whitespace trimming.
  • `read -r line`: Reads a line into the `line` variable, `-r` prevents backslash interpretation.
  • `done < file.txt`: Redirects `file.txt` as input to the `while` loop.

Why this pattern?

This robust pattern ensures that each line, including those with leading/trailing spaces or special characters, is read accurately without unintended modifications, crucial for data integrity.

Key Takeaway

The `while IFS= read -r line` construct is the most reliable way to process text files line by line in Bash, preserving data integrity.
