TESTING CONDITIONS

File and String Comparisons

Evaluate file attributes and string values within `if` statements.

file_string_tests.sh
#!/bin/bash

FILE="/tmp/testfile.txt"
DIR="/tmp/testdir"
USERNAME="admin"

# File existence test
if [ -f "$FILE" ]; then
    echo "File '$FILE' exists."
else
    echo "File '$FILE' not found."
fi

# Directory existence test
if [ -d "$DIR" ]; then
    echo "Directory '$DIR' exists."
else
    echo "Directory '$DIR' not found."
fi

# String equality test
if [ "$USERNAME" = "admin" ]; then
    echo "User is administrator."
else
    echo "User is not administrator."
fi

# String inequality test
if [ "$USERNAME" != "guest" ]; then
    echo "User is not a guest."
fi

Common File Test Operators

  • `-f file`: True if `file` is a regular file.
  • `-d dir`: True if `dir` is a directory.
  • `-e path`: True if `path` exists (file or directory).
  • `-s file`: True if `file` exists and has a size greater than zero.

String Comparison Operators

  • `"$VAR1" = "$VAR2"`: True if strings are equal.
  • `"$VAR1" != "$VAR2"`: True if strings are not equal.
  • `-z "$VAR"`: True if string `VAR` is empty.
  • `-n "$VAR"`: True if string `VAR` is not empty.
Key Takeaway

Always double-quote variables in conditions (`"$VAR"`) to prevent unexpected behavior with empty values or spaces.
