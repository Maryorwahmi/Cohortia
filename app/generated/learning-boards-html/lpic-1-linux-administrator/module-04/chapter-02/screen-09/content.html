Real-World `for` Loop Scenarios

Iterate through files, command outputs, and numeric ranges.

for_loop_examples.sh
#!/bin/bash

# Example 1: Process all .log files
echo "Processing log files:"
for file in *.log;
do
    if [ -f "$file" ]; then # Check if it's actually a file
        echo "  - Archiving $file"
        # Example: gzip "$file"
    fi
done

echo "
---"

# Example 2: Create numbered directories
echo "Creating numbered directories:"
for i in {1..5};
do
    DIR_NAME="backup_day_$i"
    echo "  - Creating $DIR_NAME"
    # Example: mkdir -p "$DIR_NAME"
done

echo "
---"

# Example 3: Iterate through users with specific UID range
echo "Users with UID > 1000:"
for user in $(awk -F: '$3 > 1000 {print $1}' /etc/passwd);
do
    echo "  - User: $user"
done

File Processing with Wildcards

Use `for file in *.ext; do ...` to easily iterate through all files matching a pattern. Always add `if [ -f "$file" ]` to ensure you're dealing with actual files.

Numeric Sequences

Bash's brace expansion `{start..end}` generates a sequence of numbers, perfect for creating multiple resources or running tests iteratively.

Key Takeaway

`for` loops are highly adaptable for automating tasks across various data sources, from file systems to generated sequences and command outputs.
