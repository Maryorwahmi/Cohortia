CORE CONCEPT

Introducing the `if` Statement

Execute code blocks based on conditions using `if`, `elif`, and `else`.

simple_if.sh
#!/bin/bash

# Define a variable
USER_AGE=20

# Basic if statement
if [ "$USER_AGE" -ge 18 ]; then
    echo "You are an adult."
fi

# if-else statement
if [ "$USER_AGE" -lt 18 ]; then
    echo "You are a minor."
else
    echo "You are not a minor."
fi

# if-elif-else statement
if [ "$USER_AGE" -lt 13 ]; then
    echo "You are a child."
elif [ "$USER_AGE" -lt 18 ]; then
    echo "You are a teenager."
else
    echo "You are an adult."
fi

Syntax Breakdown

  • `if [ condition ]; then`: Starts the conditional block.
  • `elif [ condition ]; then`: Optional, checks another condition if the first was false.
  • `else`: Optional, executes if all preceding conditions are false.
  • `fi`: Marks the end of the `if` statement.

Important: Spaces!

Always include spaces around the `[` and `]` characters, and around the condition itself. Forgetting these spaces is a common source of errors.

Key Takeaway

`if` statements are fundamental for creating scripts that can make decisions and adapt their behavior based on specific conditions.
