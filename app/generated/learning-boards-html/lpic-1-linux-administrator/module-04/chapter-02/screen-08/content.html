Automating with `for` Loops

Process each item in a list or sequence a predetermined number of times.

basic_for_loop.sh
#!/bin/bash

# Iterate over a simple list of strings
for FRUIT in apple banana cherry;
do
    echo "Processing fruit: $FRUIT"
done

echo "
---"

# Iterate over a sequence of numbers
for i in {1..3};
do
    echo "Count: $i"
done

echo "
---"

# Iterate over command output
for USER_HOME in $(ls /home);
do
    echo "Found home directory for user: $USER_HOME"
done

`for` Loop Structure

  • `for ITEM in LIST; do`: Initializes the loop, assigning each element from `LIST` to `ITEM`.
  • `commands`: The block of commands to execute for each `ITEM`.
  • `done`: Marks the end of the `for` loop.

Defining the `LIST`

  • **Space-separated strings:** `item1 item2 item3`
  • **Brace expansion:** `{start..end}` for numeric sequences.
  • **Command substitution:** `$(command)` to use command output as the list.
Key Takeaway

`for` loops are ideal for processing a known collection of items, making your scripts efficient for batch operations.
