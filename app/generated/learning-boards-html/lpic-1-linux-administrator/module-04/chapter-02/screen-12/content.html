Preventing Infinite Loops

Understand and avoid common mistakes in loop conditions, and use `break`.

loop_control.sh
#!/bin/bash

# Example of an infinite loop (DO NOT RUN WITHOUT CAUTION!)
# COUNT=1
# while [ "$COUNT" -eq 1 ]; do
#     echo "This will run forever!"
#     # No increment or condition change
# done

# Corrected loop with increment
echo "Corrected loop:"
COUNTER=0
while [ "$COUNTER" -lt 3 ]; do
    echo "  - Iteration $COUNTER"
    COUNTER=$((COUNTER + 1))
done

echo "
---"

# Using 'break' to exit a loop prematurely
echo "Loop with 'break':"
for i in {1..10};
do
    if [ "$i" -eq 5 ]; then
        echo "  - Reached 5, breaking loop."
        break # Exit the loop
    fi
    echo "  - Current value: $i"
done
echo "Loop finished after break."

What is an Infinite Loop?

A loop whose condition never becomes false, causing it to execute indefinitely. This can lead to resource exhaustion and system instability.

How to Prevent Them

  • **Ensure condition change:** Always include logic within the loop that will eventually make the condition false.
  • **Test thoroughly:** Use small datasets for testing loops before deploying to production.

The `break` Command

Immediately terminates the innermost loop it is in. Execution continues with the command following the loop. Useful for early exits based on specific internal conditions.

Key Takeaway

Always design loops with a clear exit strategy. Use `break` for controlled early termination when specific conditions are met.
