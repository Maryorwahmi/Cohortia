Conditional Repetition with `while`

Execute code repeatedly as long as a specified condition remains true.

basic_while_loop.sh
#!/bin/bash

COUNT=0
MAX_COUNT=3

# Basic while loop
while [ "$COUNT" -lt "$MAX_COUNT" ]; do
    echo "Current count: $COUNT"
    COUNT=$((COUNT + 1)) # Increment count to eventually make condition false
done

echo "Loop finished. Final count: $COUNT"

echo "
---"

# Example: Waiting for a file to exist
FILE_TO_WAIT="/tmp/my_data.txt"

echo "Waiting for $FILE_TO_WAIT to appear..."
while [ ! -f "$FILE_TO_WAIT" ]; do
    echo "  - File not found yet, waiting..."
    sleep 2 # Wait for 2 seconds before checking again
done
echo "File $FILE_TO_WAIT found!"

`while` Loop Structure

  • `while [ condition ]; do`: Evaluates the condition before each iteration.
  • `commands`: The block of commands executed if the condition is true.
  • `done`: Marks the end of the `while` loop.

Key Principle: Condition Change

For a `while` loop to terminate, the condition must eventually become false. Ensure there's a mechanism within the loop (e.g., incrementing a counter, modifying a file) that changes the condition.

Key Takeaway

`while` loops are essential for tasks requiring indefinite repetition until a specific condition is met, such as monitoring or event-driven processing.
