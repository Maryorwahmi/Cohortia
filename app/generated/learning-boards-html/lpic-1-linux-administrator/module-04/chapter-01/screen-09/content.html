Outputting Information and Commands

Displaying text and integrating system utilities.

The echo Command

echo is used to display text or the values of variables to the standard output.

echo "Hello, $GREETING_NAME!"
echo "Today's date is: $(date)"

MESSAGE="Welcome to Cohortia's LPIC-1 course."
echo "$MESSAGE"
  • •**Variable Expansion:** $VARIABLE is replaced by its value.
  • •**Command Substitution:** $(command) executes a command and inserts its output.
Key Takeaway

Use echo with variable expansion and command substitution to create dynamic and informative script outputs.

Full greet.sh Example

#!/bin/bash

# This script greets the user and displays the current date.

# Declare a variable for the user's name
GREETING_NAME="Admin"

echo "Hello, $GREETING_NAME!"
echo "Today's date is: $(date)"

# Another way to use variables:
MESSAGE="Welcome to Cohortia's LPIC-1 course."
echo "$MESSAGE"

This complete script demonstrates how variables and commands work together to produce meaningful output.

Pro-Tip: Command Substitution

Command substitution $(command) is incredibly versatile. You can use it to capture the output of almost any command and use it as part of a string or assign it to a variable.
