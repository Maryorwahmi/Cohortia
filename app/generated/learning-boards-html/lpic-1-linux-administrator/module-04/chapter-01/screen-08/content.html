First Script

Building Your First Script: greet.sh

Combining shebang, comments, and variables.

Script Structure Overview

Every basic script follows a pattern: shebang, comments, and then the commands or variable declarations.

  • •**Shebang:** First line, specifies interpreter (e.g., #!/bin/bash).
  • •**Comments:** Lines starting with #, for documentation.
  • •**Variables:** Store data for dynamic use (e.g., GREETING_NAME="Admin").
Key Takeaway

Your first script combines the shebang, descriptive comments, and variable declarations to create a clear and functional foundation.

greet.sh - Initial Code

#!/bin/bash

# This script greets the user and displays the current date.

# Declare a variable for the user's name
GREETING_NAME="Admin"

This snippet shows the shebang, a multi-line comment for the script's purpose, and a variable declaration.

Common Mistake: Spaces in Variable Assignment

A frequent error is adding spaces around the equals sign, e.g., GREETING_NAME = "Admin". This will cause a "command not found" error. Always use GREETING_NAME="Admin".
