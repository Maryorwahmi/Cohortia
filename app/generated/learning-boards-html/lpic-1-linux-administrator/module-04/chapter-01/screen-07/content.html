Storing Data with Bash Variables

Dynamic values for flexible script execution.

Declaring Variables

To declare a variable, use VARIABLE_NAME="value". Remember: no spaces around the equals sign!

MY_NAME="John Doe"
AGE=30
GREETING="Hello"
  • •**No Spaces:** VAR=value is correct; VAR = value is incorrect.
  • •**Case-Sensitive:** myvar is different from MyVar.
Key Takeaway

Variables are declared with NAME="value" (no spaces) and accessed with $NAME, making scripts dynamic and adaptable.

Accessing Variable Values

Use the dollar sign ($) before the variable name to retrieve its value.

#!/bin/bash
MY_NAME="Jane Doe"
echo "Hello, $MY_NAME!"
echo "Your current user is: $USER"

This script would output "Hello, Jane Doe!" and then your current system username.

Best Practice: Double Quotes

Always enclose variable references in double quotes ("$VARIABLE") when their values might contain spaces or special characters. This prevents unexpected word splitting or globbing.
