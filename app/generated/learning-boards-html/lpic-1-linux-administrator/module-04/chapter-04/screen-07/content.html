Providing Input

Feeding Commands from Files

Using Standard Input Redirection

Input Redirection (<)

Redirects stdin from a file, allowing a command to process the file's content as its input.

Real-world Connection

Automate script execution by providing configuration or data files as input, rather than manual entry.

Common Misconception

Not all commands require <. Many commands accept filenames as arguments directly (e.g., cat file.txt).

# Create an unsorted file
echo -e "banana
apple
orange" > fruits.txt
cat fruits.txt
# Output:
# banana
# apple
# orange
# Sort contents using input redirection
sort < fruits.txt
# Output:
# apple
# banana
# orange
Key Takeaway

Input redirection streamlines data processing by allowing commands to read directly from files, enhancing automation.
