Essential Data Stream Concepts

Foundational Knowledge for Linux Administration

Standard Input (stdin)

The default channel (FD 0) for a program to receive input, typically from the keyboard.

Standard Output (stdout)

The default channel (FD 1) for a program to send normal output, usually to the terminal.

Standard Error (stderr)

The default channel (FD 2) for a program to send error messages, typically to the terminal.

Summary Takeaway

Understanding stdin, stdout, and stderr is the fundamental first step to mastering data flow and command interaction in Linux.
