Stream Editor

Transforming Text with `sed`

Performing Substitutions and Edits

Purpose

A powerful text stream editor that performs basic text transformations (e.g., substitution) on input.

Substitution Syntax

's/old_text/new_text/g': Replaces all occurrences of old_text with new_text on each line.

Common Mistake

Forgetting that sed prints to stdout by default; it does not modify the original file unless -i is used.

# Example: Replace 'old' with 'new' globally
echo "This is an old text with old words." | sed 's/old/new/g'
# Output: This is an new text with new words.
# Example: Change 'http' to 'https' in a file
echo "http://example.com" > urls.txt
sed 's/http/https/g' urls.txt
# Output: https://example.com
Key Takeaway

sed is invaluable for automating repetitive text edits and transformations within command pipelines.
