Text Filtering

Searching with `grep`

Finding Patterns in Text Streams

Purpose

Searches for lines matching a pattern in files or standard input. Your primary tool for filtering text.

Common Options

-i (ignore case), -v (invert match), -r (recursive), -E (extended regex).

Pro Tip

Always use quotes around patterns in grep to avoid shell interpretation issues, especially with special characters.

# Example: Find case-insensitive 'error' in a log
cat access.log | grep -i "error"
# Output: (lines from access.log containing 'error', 'Error', etc.)
# Example: Find lines NOT containing 'success'
dmesg | grep -v "success"
# Output: (kernel messages without 'success')
Key Takeaway

grep is indispensable for quickly filtering and extracting relevant lines from text data, a core administrative task.
