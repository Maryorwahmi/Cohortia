`uniq` Utility

Reports or filters out repeated lines in a file. Requires **sorted input** to detect all duplicates.

Combining Tools

Chaining multiple utilities with pipes enables complex data analysis and manipulation tasks.

Important Note

uniq only works on *adjacent* lines. Always sort your input before piping to uniq for accurate results.

# Example: Count unique words
echo -e "apple
banana
apple" | sort | uniq -c
# Output:
#       2 apple
#       1 banana
# Complex Pipeline: Top 5 IPs from access.log
cat access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head -n 5
Key Takeaway

Mastering pipelines with `uniq` and other utilities is crucial for advanced data analysis and system administration.
