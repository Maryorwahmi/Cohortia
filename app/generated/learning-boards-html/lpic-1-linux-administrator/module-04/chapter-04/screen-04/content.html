Core Concept

The Three Standard Streams

Input, Output, and Error Channels

Standard Input (stdin)

File Descriptor 0. Where a command expects to receive input, typically from the keyboard or another source.

Standard Output (stdout)

File Descriptor 1. Where a command sends its normal, successful output, usually displayed on the terminal.

Standard Error (stderr)

File Descriptor 2. Where a command sends error messages and diagnostic output, typically to the terminal.
