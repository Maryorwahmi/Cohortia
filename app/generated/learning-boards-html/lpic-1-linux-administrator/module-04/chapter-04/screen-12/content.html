Extracting and Ordering Data

Using `cut` and `sort` for Structured Text

`cut` Utility

Extracts sections from each line of files by character position (-c) or delimiter and field number (-d, -f).

`sort` Utility

Sorts lines of text files. Options include -r (reverse), -n (numeric), -k (sort by key/field).

Use Case

Combine cut and sort to extract specific data columns and then order them for analysis or reporting.

# Example: Extract username and shell from /etc/passwd
cat /etc/passwd | cut -d: -f1,7
# Output: root:/bin/bash
#         daemon:/usr/sbin/nologin
#         ...
# Example: Sort names in reverse alphabetical order
echo -e "Charlie
Alice
Bob" > names.txt
cat names.txt | sort -r
# Output:
# Charlie
# Bob
# Alice
Key Takeaway

cut and sort are fundamental for precise data extraction and ordering, making raw text manageable.
