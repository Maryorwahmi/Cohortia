Pattern Scanning Language

Advanced Text Processing with `awk`

Extracting Fields and Generating Reports

Purpose

A programming language for text processing, excellent for extracting fields, calculations, and reports.

Field Processing

Processes text line by line, splitting each line into fields ($1, $2, etc.) by default whitespace-separated.

Pro Tip

Use -F 'delimiter' to specify a custom field separator if your data isn't whitespace-separated (e.g., -F: for /etc/passwd).

# Example: Extract filename and size from 'ls -l'
ls -l | awk '{print $9 "  " $5}'
# Output:
# file1.txt     1024
# file2.log     2048
# Example: Print lines where the 3rd field is 'root'
cat /etc/passwd | awk -F: '$3 == "0" {print $1}'
# Output: root
Key Takeaway

awk is indispensable for parsing structured text, extracting specific data points, and generating custom reports.
