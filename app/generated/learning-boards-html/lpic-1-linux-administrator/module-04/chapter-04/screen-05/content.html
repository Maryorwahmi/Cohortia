Data Flow Control

Redirecting Standard Output

Saving Command Results to Files

Overwrite (>)

Redirects stdout to a file, **overwriting** its contents if it exists. Creates the file if it doesn't.

Append (>>)

Redirects stdout to a file, **appending** to its contents if it exists. Creates the file if it doesn't.

Common Mistake

Forgetting that > overwrites existing file content. Always use >> if you intend to preserve data.

# Overwrite example
ls -l > file_list.txt
cat file_list.txt
# Output: (directory listing)
# Append example
echo "First line" > my_log.txt
echo "Second line" >> my_log.txt
cat my_log.txt
# Output:
# First line
# Second line
Key Takeaway

Use > for fresh output and >> for adding to existing files, preventing data loss.
