SSH Tunneling: Local Port Forwarding

Securely accessing remote services through an SSH connection

Local Port Forwarding Command_
ssh -L 8080:localhost:80 john@myserver.example.com
Forwards local port 8080 to remote server's port 80.
Secure Tunnel

Creates an encrypted path for traffic, bypassing firewalls and network restrictions.

Access Internal Services

Useful for accessing web servers or databases on a remote network that are not public-facing.

Key Takeaway

Local port forwarding (`-L`) allows you to securely access remote services by tunneling traffic from a local port through SSH.
