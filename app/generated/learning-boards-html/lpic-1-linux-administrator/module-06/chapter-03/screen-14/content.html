Chapter Summary

Key Concepts: Core SSH Components

Essential terms and tools for secure remote access

Secure Shell (SSH)

A cryptographic network protocol for secure remote access, command execution, and file transfers.

SSH Client / Server

The client initiates connections, while the server (`sshd`) listens for and handles them.

Host Key

A cryptographic key that uniquely identifies an SSH server, stored in `~/.ssh/known_hosts` on the client.

Chapter Summary

SSH is the foundational protocol for secure remote Linux administration, relying on client-server interaction and host key verification for trusted connections.
