Static vs. Dynamic IP

Manual control versus automatic assignment

Static IP Configuration

  • Manual Assignment: You explicitly set the IP address, subnet mask, and default gateway.
  • Predictable: IP address remains constant, ideal for servers and network devices.
  • Use Cases: Web servers, database servers, routers, printers.
  • Pros: Consistent address, easier for DNS records, better for services.
  • Cons: Requires manual management, prone to human error if not careful.
Example

Assigning 192.168.1.100 to a web server for consistent access.

Dynamic IP Configuration

  • Automatic Assignment: DHCP server assigns IP, subnet, and gateway.
  • Flexible: IP address can change, convenient for temporary devices.
  • Use Cases: Laptops, desktops, mobile devices, guest networks.
  • Pros: Easy setup, efficient IP address management, reduces conflicts.
  • Cons: IP address can change, harder to locate specific devices without DNS.
Example

A laptop automatically receiving an IP address when connecting to Wi-Fi.

Key Takeaway

Static IPs offer predictability for servers, while dynamic IPs provide convenience for clients, both crucial for different network roles.
