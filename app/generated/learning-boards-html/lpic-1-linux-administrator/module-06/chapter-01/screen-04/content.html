The IP Address

Your device's unique identifier on the network

What is an IP Address?

A unique numerical label assigned to each device (e.g., server, computer, printer) participating in a computer network that uses the Internet Protocol for communication.

  • Enables devices to be located and communicate.
  • IPv4 addresses are common: four octets separated by dots (e.g., 192.168.1.100).
  • Essential for routing data packets across networks.
Key Takeaway

An IP address is like a digital street address, uniquely identifying your device on the network for communication.
