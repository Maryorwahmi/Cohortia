Core Concept

Default Gateway

The exit point for external network traffic

Router's Role

The default gateway is the IP address of the router that forwards traffic from your local network to other networks, including the internet.

  • Essential for reaching external destinations.
  • Acts as the first hop for non-local traffic.
  • Incorrect configuration leads to isolation from the internet.
Key Takeaway

The default gateway is your network's bridge to the outside world; without it, your system is confined to its local network.
