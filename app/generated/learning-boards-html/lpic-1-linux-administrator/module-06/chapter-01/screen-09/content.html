Key `ip a` Features

  • Detailed Output: More comprehensive than ifconfig.
  • CIDR Notation: IP address and subnet mask combined (e.g., /24).
  • IPv6 Support: Displays IPv6 addresses and scope.
  • Interface State: Clearly shows if an interface is UP or DOWN.
Pro Tip

Use ip -s a for interface statistics, or ip link set eth0 up/down to manage interface state.

Key Takeaway

The ip command is the modern, versatile tool for all network interface management, providing detailed and actionable information.
