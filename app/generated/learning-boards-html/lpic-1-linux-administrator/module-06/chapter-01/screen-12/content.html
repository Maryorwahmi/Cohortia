Debian Network Configuration

Configuring interfaces via /etc/network/interfaces

File: /etc/network/interfaces
# The loopback network interface
auto lo
iface lo inet loopback

# The primary network interface
auto eth0
iface eth0 inet static
    address 192.168.1.100
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 8.8.4.4
Auto-activate interface
Static IP details

Key Directives

  • `auto [interface]`: Bring interface up at boot.
  • `iface [interface] inet static`: Define static IP configuration.
  • `address`, `netmask`, `gateway`: Core IP settings.
  • `dns-nameservers`: Specify DNS servers.
Safety Note

Always back up /etc/network/interfaces before editing. Incorrect changes can lead to loss of network connectivity.

Key Takeaway

/etc/network/interfaces is central for persistent network settings on Debian; careful editing and service restarts are required.
