Red Hat Network Configuration

Managing interfaces with ifcfg-ethX files

File: /etc/sysconfig/network-scripts/ifcfg-eth0
TYPE="Ethernet"
BOOTPROTO="static"
NAME="eth0"
DEVICE="eth0"
ONBOOT="yes"
IPADDR="192.168.1.101"
NETMASK="255.255.255.0"
GATEWAY="192.168.1.1"
DNS1="8.8.8.8"
DNS2="8.8.4.4"
Interface Type & Boot Protocol
IP, Gateway, DNS details

Key Parameters

  • `BOOTPROTO`: `static` or `dhcp`.
  • `ONBOOT`: `yes` to activate at boot.
  • `IPADDR`, `NETMASK`, `GATEWAY`: IP settings.
  • `DNS1`, `DNS2`: Primary and secondary DNS servers.
Important

Changes often require restarting NetworkManager or using nmcli to apply.

Key Takeaway

Red Hat systems use `ifcfg-` files for persistent network configuration, managed by NetworkManager, requiring specific commands to apply changes.
