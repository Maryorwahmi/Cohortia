Network Routing Tables

Directing traffic to its destination

Terminal Output
user@server:~$ ip route show

default via 192.168.1.1 dev eth0 proto dhcp metric 100 
192.168.1.0/24 dev eth0 proto kernel scope link src 192.168.1.100 metric 100
Default Gateway Route
Local Network Route

Routing Table Components

  • Destination: The target network or host.
  • Gateway: The next hop for traffic (e.g., router IP).
  • Interface: The local network interface to use (e.g., eth0).
  • Default Route: (default or 0.0.0.0/0) for all non-local traffic.
Common Issue

An incorrect or missing default gateway prevents internet access, limiting communication to the local network.

Key Takeaway

The routing table is crucial for directing network traffic; verifying its entries, especially the default route, is key to connectivity.
