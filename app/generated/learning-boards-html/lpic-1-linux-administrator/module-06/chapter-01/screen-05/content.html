Core Concept

Subnet Mask

Defining local network boundaries

How it Works

The subnet mask works with the IP address to distinguish the network portion from the host portion, defining the local network segment.

  • Determines which devices are on the same local network.
  • Commonly expressed as 255.255.255.0 or CIDR /24.
  • Crucial for direct communication within a subnet.
Key Takeaway

The subnet mask acts as a filter, telling your system which part of an IP address identifies the network and which identifies the specific device.

IP Address

192.168.1.100

Subnet Mask

255.255.255.0 (or /24)

Network Portion

192.168.1

Host Portion

.100
