Common Flags for `ss` / `netstat`

  • `-t`: Show TCP connections.
  • `-u`: Show UDP connections.
  • `-l`: Show listening sockets.
  • `-n`: Show numerical addresses (no DNS lookup).
  • `-p`: Show process ID and name.
Pro Tip

Use grep with ss or netstat to filter for specific ports or services, e.g., ss -tulnp | grep :80.

Key Takeaway

ss (and `netstat`) are indispensable for monitoring network activity, identifying open ports, and troubleshooting connectivity issues.
