Step 1: Explore System Logs

Using journalctl

# View last 20 boot messages
journalctl -b -n 20

# View logs from the sshd service
journalctl -u sshd

# View logs in real-time
journalctl -f
Tip

Open a new terminal and try to SSH into your VM to generate sshd logs while journalctl -f is running.

Step 2: Configure & Test logrotate

Custom Log File Management

# Create dummy log file
sudo mkdir /var/log/myapp
sudo touch /var/log/myapp/access.log
echo "Initial log entry" | sudo tee -a /var/log/myapp/access.log

# Create logrotate config for myapp
sudo nano /etc/logrotate.d/myapp
# Add content:
# /var/log/myapp/*.log {
#     daily
#     rotate 7
#     compress
#     delaycompress
#     missingok
#     notifempty
#     create 0640 root root
# }

# Test logrotate manually
sudo logrotate -f /etc/logrotate.d/myapp

# Verify rotation
ls -l /var/log/myapp/
zcat /var/log/myapp/access.log.1.gz
Key Takeaway

journalctl provides powerful log analysis, while logrotate ensures efficient log file management. Practice these commands to master system monitoring.
