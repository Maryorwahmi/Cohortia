Example Configuration

Apache Logrotate Block

/var/log/apache2/*.log {
    weekly
    missingok
    rotate 4
    compress
    delaycompress
    notifempty
    create 0640 root adm
    sharedscripts
    postrotate
        if /etc/init.d/apache2 status > /dev/null ; then \
            /etc/init.d/apache2 reload > /dev/null; \
        fi;
    endscript
}
Key Directives Explained

Understanding Each Line

/var/log/apache2/*.log: Specifies the log files to be rotated.
weekly: Rotates logs once a week. Other options: daily, monthly, yearly.
rotate 4: Keeps 4 old rotated log files. The 5th oldest is deleted.
compress: Compresses rotated logs (e.g., .gz).
delaycompress: Delays compression until the next rotation cycle.
notifempty: Skips rotation if the log file is empty.
create 0640 root adm: Creates a new log file with specified permissions and ownership.
postrotate/endscript: Commands executed after rotation (e.g., reload service).
Key Takeaway

Each logrotate directive plays a specific role in managing log files. Customize these settings to match your application's logging requirements and retention policies.
