Core Concept

Common Network Services & Ports

Understanding the backbone of network communication

HTTP / HTTPS

Web pages and encrypted web traffic. Ports: 80 (HTTP), 443 (HTTPS).

FTP / SSH

File transfer and secure remote access. Ports: 21/20 (FTP), 22 (SSH).

DNS / DHCP

Domain name resolution and IP address assignment. Ports: 53 (DNS), 67/68 (DHCP).

SMTP / POP3 / IMAP

Email sending and retrieval. Ports: 25 (SMTP), 110 (POP3), 143 (IMAP).

Key Takeaway

Knowing standard service ports is fundamental for network configuration, firewall rules, and troubleshooting connectivity issues.
