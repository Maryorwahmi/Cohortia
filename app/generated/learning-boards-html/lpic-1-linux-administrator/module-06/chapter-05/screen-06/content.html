Configuring Socket Activation

Defining .socket and .service files for on-demand services

.socket File

Defines the network socket systemd listens on (e.g., port 8080). Handles initial connection.

.service File

Describes how to run the actual application. Requires the corresponding .socket file.

Activation Command

Use sudo systemctl enable --now myservice.socket to activate.

Key Takeaway

Properly configured .socket and .service files allow systemd to manage service startup and resource allocation efficiently.

# /etc/systemd/system/myservice.socket
[Unit]
Description=My Service Socket

[Socket]
ListenStream=8080
Accept=yes

[Install]
WantedBy=sockets.target
# /etc/systemd/system/myservice.service
[Unit]
Description=My Service
Requires=myservice.socket

[Service]
ExecStart=/usr/local/bin/myservice_app
StandardInput=socket
