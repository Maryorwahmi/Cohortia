Traditional Logging

Syslog: The Classic Approach

syslog is the long-standing standard for message logging on Linux. Daemons and the kernel send messages to a syslogd process (like rsyslogd or syslog-ng), which then writes them to various text files in /var/log/.

Human-readable text files
Logs in /var/log/
Common Syslog Files
/var/log/auth.log   # Authentication attempts
/var/log/syslog     # General system messages
/var/log/kern.log   # Kernel messages
Modern Logging

Journald: Systemd's Logging System

journald, part of systemd, is the default logging system for many modern Linux distributions. It stores logs in a structured, binary format, offering advanced querying capabilities.

Structured, binary format
Advanced querying with journalctl
Journalctl Examples
# View logs in real-time
journalctl -f

# View logs for a specific service (e.g., sshd)
journalctl -u sshd

# View logs from the current boot
journalctl -b
Key Takeaway

Both syslog and journald are essential for monitoring system health and security. Master journalctl for efficient log analysis.
