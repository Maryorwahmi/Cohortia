Resolving Local Network Communication

Diagnosing Issues Within Your Own Subnet

# Scenario: Cannot reach other machines on local network
$ ping -c 1 192.168.1.101
ping: connect: Network is unreachable
# Check your own IP address and subnet mask
$ ip a show eth0
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc pfifo_fast state UP group default qlen 1000
    link/ether 00:11:22:33:44:55 brd ff:ff:ff:ff:ff:ff
    inet 192.168.1.50/24 brd 192.168.1.255 scope global dynamic eth0
       valid_lft 86399sec preferred_lft 86399sec
# Check default gateway (for traffic outside local network)
$ ip r
default via 192.168.1.1 dev eth0 proto dhcp src 192.168.1.50 metric 100
Key Checks
  • Your IP Address: Is it in the correct subnet range?
  • Subnet Mask: Is it consistent with other devices on the network?
  • Default Gateway: Is it correctly configured, even for local issues?
Common Causes
  • Incorrect static IP configuration.
  • DHCP client failure to obtain an IP.
  • Mismatched subnet masks between devices.
  • Incorrect network interface configuration.
Key Takeaway

Local network issues often stem from misconfigured IP addresses, subnet masks, or gateways on your own machine.
