Utility Spotlight

netcat: The TCP/IP Swiss Army Knife

Testing Port Availability and Network Services

# Test if a web server is listening on port 80
$ nc -zv example.com 80
Connection to example.com 80 port [tcp/http] succeeded!
# Test a closed/filtered port (e.g., 65535)
$ nc -zv example.com 65535
nc: connect to example.com port 65535 (tcp) failed: Connection refused
# Send a simple string to a listening service
$ echo "Hello Server" | nc 192.168.1.100 8080
Key Capabilities
  • Port Scanning: Quickly check if a port is open or closed.
  • Service Testing: Verify if a specific service is actively listening.
  • Simple Data Transfer: Establish basic TCP/UDP connections for sending/receiving data.
Interpreting Results
  • 'succeeded!': Port is open and a service is listening.
  • 'Connection refused': Port is closed, no service listening.
  • 'timeout': Port is filtered (e.g., by a firewall), no response.
Key Takeaway

netcat is indispensable for verifying service availability and diagnosing port-related connectivity issues.
