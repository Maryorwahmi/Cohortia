tcpdump: Deep Packet Inspection

Capturing and Analyzing Network Traffic at the Packet Level

# Capture all ICMP traffic on eth0
$ sudo tcpdump -i eth0 icmp
tcpdump: verbose output suppressed, use -v or -vv for full protocol decode
listening on eth0, link-type EN10MB (Ethernet), capture size 262144 bytes
10:00:00.123456 IP 192.168.1.100 > 8.8.8.8: ICMP echo request, id 12345, seq 1, length 64
10:00:00.123500 IP 8.8.8.8 > 192.168.1.100: ICMP echo reply, id 12345, seq 1, length 64
# Capture SSH traffic to/from a specific host
$ sudo tcpdump -i eth0 host 192.168.1.5 and port 22
# Save captured traffic to a file for later analysis
$ sudo tcpdump -i eth0 -w capture.pcap
Key Features
  • Interface Selection: Specify which network interface to monitor (-i).
  • Powerful Filters: Filter by host, port, protocol (TCP, UDP, ICMP), source/destination.
  • Packet Display: Shows packet headers and data in various formats.
  • File Output: Save captures to .pcap files for offline analysis (-w).
Safety Note

tcpdump can capture sensitive information (passwords, unencrypted data). Always use specific filters to narrow traffic and ensure responsible use.

Key Takeaway

tcpdump provides unparalleled visibility into network traffic, essential for diagnosing complex, low-level communication problems.
