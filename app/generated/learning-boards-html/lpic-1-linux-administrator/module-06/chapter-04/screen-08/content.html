Anatomy of an iptables Rule

Deconstructing the syntax and common components of a firewall rule.

`iptables -A `

Appends a new rule to the specified chain (e.g., INPUT, OUTPUT, FORWARD).

`-p `

Specifies the network protocol (e.g., tcp, udp, icmp).

`--dport ` / `--sport `

Specifies the destination or source port number (e.g., 22 for SSH, 80 for HTTP).

`-s ` / `-d `

Specifies the source or destination IP address or network range (e.g., 192.168.1.0/24).

`-j `

Specifies the action (target) to take if the packet matches the rule (e.g., ACCEPT, DROP, REJECT).

Key Takeaway

An iptables rule is a combination of matching criteria and a target action, allowing precise control over packet flow.
