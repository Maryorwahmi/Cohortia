Packet Flow

Understanding iptables Chains

How network packets are categorized and processed within the firewall.

INPUT Chain

Processes packets *destined for* the local system. Example: an incoming SSH connection to your server.

OUTPUT Chain

Processes packets *originating from* the local system. Example: your server initiating a web request to an external API.

FORWARD Chain

Processes packets *passing through* the local system (when acting as a router). Example: traffic from one internal network to another via your Linux gateway.

Key Takeaway

Each chain serves a specific purpose based on the packet's direction relative to the firewall, guiding rule placement.
