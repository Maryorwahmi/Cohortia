Configuration Persistence

Making iptables Rules Permanent

Ensuring firewall configurations survive system reboots across distributions.

Rules are Volatile

By default, iptables rules reside in kernel memory and are lost upon system reboot. They must be explicitly saved.

Debian/Ubuntu Persistence

Install iptables-persistent. Use sudo netfilter-persistent save to save rules to /etc/iptables/rules.v4 and rules.v6. Use sudo netfilter-persistent reload to restore.

Manual Save/Restore

sudo iptables-save > /etc/iptables/rules.v4 to save. Restore at boot via systemd or /etc/rc.local using sudo iptables-restore < /etc/iptables/rules.v4.

Key Takeaway

Always save your iptables rules using distribution-specific methods or manual commands to ensure your firewall configuration persists after a reboot.
