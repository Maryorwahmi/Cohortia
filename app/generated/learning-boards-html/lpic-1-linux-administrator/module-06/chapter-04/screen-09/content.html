Rule Actions

Defining Packet Actions with Targets

Deciding how the firewall handles matching network traffic.

ACCEPT

Allows the packet to pass through the firewall. Used for legitimate and desired traffic.

DROP

Silently discards the packet. The sender receives no notification, making the service appear unresponsive.

REJECT

Discards the packet and sends an error message (e.g., ICMP port unreachable) back to the sender. Provides feedback.

LOG

Records packet information to system logs (e.g., /var/log/syslog). Useful for debugging and monitoring, but does not stop the packet.

Key Takeaway

Choosing the correct target (ACCEPT, DROP, REJECT, LOG) determines how your firewall responds to matched packets, balancing security and network behavior.

Target Outcomes

What happens to the packet?

ACCEPT

Packet proceeds

DROP

Packet vanishes

REJECT

Packet returned with error

LOG

Packet details recorded

Consideration: DROP can make attackers guess, REJECT provides feedback.
