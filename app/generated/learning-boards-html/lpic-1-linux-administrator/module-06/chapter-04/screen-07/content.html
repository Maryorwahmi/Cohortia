Default Policies and Security

Implementing a 'default deny' strategy for robust firewall security.

Default Policy Explained

The action taken for any packet that does not match an explicit rule within an iptables chain. It's the 'catch-all' rule.

'Default Deny' Strategy

Setting the default policy for INPUT and FORWARD chains to DROP or REJECT. This blocks all traffic by default, and you then explicitly allow only necessary traffic.

Key Takeaway

A 'default deny' policy significantly enhances security by blocking all traffic unless explicitly permitted by a rule.

Default Deny

Block all, allow only what's needed.

Policy: DROP

Silently discards unmatched packets.

Policy: REJECT

Discards and sends error message.

Policy: ACCEPT

Allows all unmatched packets (less secure).

Safety Tip: Always allow SSH *before* setting default INPUT policy to DROP to avoid lockout!
