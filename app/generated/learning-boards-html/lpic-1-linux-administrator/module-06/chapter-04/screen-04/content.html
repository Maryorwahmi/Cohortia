Core Concept

Netfilter and iptables Fundamentals

The Linux kernel's packet filtering framework and its command-line interface.

Netfilter: The Kernel Framework

A set of hooks within the Linux kernel that allows modules to register callback functions to filter network packets. It's the engine that performs the actual packet inspection and manipulation.

iptables: The User-Space Utility

A command-line program that communicates with Netfilter to define, maintain, and inspect the packet filtering rules in the Linux kernel. It's your interface to the firewall.

Key Takeaway

Netfilter is the kernel framework, and iptables is the user-space utility for configuring Linux firewalls, providing granular control over network traffic.
