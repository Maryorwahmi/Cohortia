/etc/group: Defining User Collections

Organizing users for shared permissions.

# Example /etc/group entries
root:x:0:
users:x:100:
developers:x:1002:john_doe,jane_smith
sysadmins:x:1003:alex_admin

Field Breakdown

  • Group Name: Unique identifier for the group.
  • Password Placeholder: 'x' (group passwords are rarely used).
  • GID (Group ID): Unique numerical identifier for the group.
  • Members: Comma-separated list of users who are members of this group.
Important Note

Users can be members of multiple supplementary groups listed here, in addition to their primary group defined in /etc/passwd.

Concrete Example

The line developers:x:1002:john_doe,jane_smith defines a group named 'developers' with GID 1002, and 'john_doe' and 'jane_smith' are members of this group.

Key Takeaway

/etc/group is crucial for defining and managing groups, enabling efficient permission assignment for shared resources.
