/etc/passwd: User Account Information

Unpacking the user database.

# Example /etc/passwd entry
root:x:0:0:root:/root:/bin/bash
john_doe:x:1001:1001:John Doe:/home/john_doe:/bin/bash

Field Breakdown

  • Username: Login name.
  • Password Placeholder: 'x' indicates password in /etc/shadow.
  • UID (User ID): Unique numerical identifier (0 for root, <1000 for system, >=1000 for regular users).
  • GID (Group ID): Primary group ID.
  • Comment: Full name or description.
  • Home Directory: User's default working directory.
  • Default Shell: Command interpreter (e.g., /bin/bash).
Concrete Example

A line like john_doe:x:1001:1001:John Doe:/home/john_doe:/bin/bash defines a user named 'john_doe' with UID 1001, primary GID 1001, full name 'John Doe', home directory '/home/john_doe', and bash shell.

Key Takeaway

/etc/passwd is a public file containing user metadata, but never the actual password, which is stored separately for security.
