usermod: Adapting User Accounts

Changing user properties and group memberships.

# Change user's home directory
sudo usermod -d /srv/users/john_doe john_doe
# Change user's default shell
sudo usermod -s /bin/zsh john_doe
# Add user to 'developers' supplementary group
sudo usermod -aG developers john_doe

Key usermod Options

  • -d DIR (--home DIR): Changes the user's home directory.
  • -s SHELL (--shell SHELL): Changes the user's default login shell.
  • -l NEW_NAME (--login NEW_NAME): Changes the user's login name.
  • -aG GROUPS (--append --groups GROUPS): Adds the user to supplementary groups without removing existing ones.
Common Mistake

Using -G without -a will overwrite all existing supplementary groups, potentially removing critical access.

Concrete Example

If 'jane_doe' needs to join the 'designers' group, use sudo usermod -aG designers jane_doe to add her without affecting other group memberships.

Key Takeaway

usermod is essential for updating user account properties and managing group memberships, with -aG being critical for adding supplementary groups safely.
