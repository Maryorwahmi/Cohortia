userdel: Removing User Accounts

Safely decommissioning user profiles.

# Delete user account and home directory
sudo userdel -r jane_doe
# Verify user is removed (should return error)
id jane_doe
id: 'jane_doe': no such user

Key userdel Options

  • -r (--remove): Removes the user's home directory and mail spool along with the account.
Safety Note

Always back up critical data before using userdel -r, as the removal of the home directory is permanent and irreversible.

Important Consideration

If a user is the primary owner of files outside their home directory, those files will become owned by a numeric UID after deletion, requiring manual ownership changes.

Concrete Example

To completely remove a user 'old_employee' and all their associated files, you would execute sudo userdel -r old_employee.

Key Takeaway

Use userdel -r for a clean removal of user accounts and their home directories, but always exercise caution and consider data backups.
