/etc/shadow: Protecting Passwords

The vault for encrypted credentials.

# Example /etc/shadow entry
root:$6$salt$hash:18702:0:99999:7:::
john_doe:$6$salt$anotherhash:18702:0:90:7:7:

Key Fields & Security

  • Username: Corresponds to /etc/passwd.
  • Encrypted Password: Hashed password (one-way encryption).
  • Last Change: Days since Jan 1, 1970, password was last changed.
  • Min Age: Minimum days before password can be changed.
  • Max Age: Maximum days before password must be changed.
  • Warning Period: Days before password expires to warn user.
  • Inactivity Period: Days after password expires account is disabled.
Security Implication

Separating password hashes from user data in /etc/passwd prevents unauthorized access to credentials, even if the less sensitive file is compromised.

Key Takeaway

/etc/shadow is a root-only file that secures password hashes and enforces password aging policies, crucial for system integrity.
