Key Concepts

Commands for mastery.

useradd & passwd

Commands to create new user accounts and set their passwords.

usermod

Command to modify existing user account properties, including group memberships.

userdel

Command to delete user accounts, with -r for home directory removal.

groupadd & groupmod

Commands to create new groups and modify existing group properties (e.g., rename with -n).

groupdel

Command to delete groups, with the constraint that it cannot be a primary group for any user.

su & sudo & visudo

Commands for privilege escalation and safely editing the sudoers file.

Summary Takeaway

Mastering these command-line tools is essential for performing all aspects of user and group management, from creation to deletion and privilege control.
