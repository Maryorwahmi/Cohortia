useradd: Bringing New Users Online

Essential options for account creation.

# Create a new user with home directory and bash shell
sudo useradd -m -s /bin/bash john_doe
# Set a password for the new user
sudo passwd john_doe
New password: ********
Retype new password: ********
passwd: password updated successfully

Key useradd Options

  • -m (--create-home): Creates the user's home directory if it doesn't exist.
  • -s SHELL (--shell SHELL): Specifies the user's default login shell (e.g., /bin/bash).
  • -g GROUP (--gid GROUP): Specifies the primary group by name or GID.
  • -G GROUPS (--groups GROUPS): Adds the user to supplementary groups (comma-separated).
Common Mistake

Forgetting to set a password with passwd after creating a user will prevent them from logging in.

Concrete Example

To create a user 'dev_user' with a home directory and bash shell, you'd run sudo useradd -m -s /bin/bash dev_user, then sudo passwd dev_user.

Key Takeaway

useradd is the command to create new user accounts, always followed by passwd to secure the account with a strong password.
