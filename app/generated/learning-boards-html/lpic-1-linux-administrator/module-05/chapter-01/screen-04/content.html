Users and Groups: The Foundation of Access Control

Every resource is tied to an identity.

User Account

A user account represents an individual or a service that can interact with the system. Each user has a unique User ID (UID) and a primary Group ID (GID).

  • Identity: Unique login name.
  • Authentication: Requires a password for access.
  • Resources: Owns files and processes.

Group Account

A group is a collection of users who share common access permissions to certain resources. Each group has a unique Group ID (GID).

  • Collaboration: Simplifies shared access.
  • Permissions: Resources assigned to groups.
  • Membership: Users can belong to multiple groups.
Concrete Example

Imagine a 'developers' group with read/write access to a code repository. All developers are members, inheriting these permissions without individual assignments.

Key Takeaway

Users provide identity, while groups provide a mechanism for efficient, shared access control, simplifying system administration.
