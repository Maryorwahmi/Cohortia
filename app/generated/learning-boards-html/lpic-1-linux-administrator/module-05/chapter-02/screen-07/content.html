Command Reference

`chmod` with Numbers: Octal Mode

A Concise Way to Set Permissions

Permission Values

  • r (Read): 4
  • w (Write): 2
  • x (Execute): 1
  • No permission: 0

Common Octal Codes

  • 7 (rwx): Full access
  • 6 (rw-): Read & Write
  • 5 (r-x): Read & Execute
  • 4 (r--): Read only
Key Takeaway

Numeric mode provides a compact and powerful way to set precise permissions by summing `r=4, w=2, x=1` for each user category.

Octal Mode Examples

chmod 755 myfile.txt

Owner: rwx (7), Group: r-x (5), Others: r-x (5)

chmod 640 config.conf

Owner: rw- (6), Group: r-- (4), Others: --- (0)

chmod 700 private_dir

Owner: rwx (7), Group: --- (0), Others: --- (0)
