Managing Ownership: `chown` and `chgrp`

Changing Who Controls Files and Directories

`chown` Command

  • Changes the user owner of a file or directory.
  • Syntax: `sudo chown `
  • Can also change user and group: `sudo chown : `

`chgrp` Command

  • Changes only the group owner of a file or directory.
  • Syntax: `sudo chgrp `
Safety Note

Use `-R` (recursive) option with extreme caution, especially on system directories, as it can lead to system instability.

Key Takeaway

`chown` and `chgrp` are essential for transferring ownership, but recursive changes require careful consideration to avoid security risks.

`chown` and `chgrp` in Action
# Create a file owned by current user
touch report.txt
ls -l report.txt
-rw-r--r-- 1 currentuser currentgroup 0 Jan 1 10:00 report.txt

# Change owner to 'john_doe'
sudo chown john_doe report.txt
ls -l report.txt
-rw-r--r-- 1 john_doe currentgroup 0 Jan 1 10:00 report.txt

# Change group to 'developers'
sudo chgrp developers report.txt
ls -l report.txt
-rw-r--r-- 1 john_doe developers 0 Jan 1 10:00 report.txt

# Change owner to 'mary' and group to 'marketing'
sudo chown mary:marketing report.txt
ls -l report.txt
-rw-r--r-- 1 mary marketing 0 Jan 1 10:00 report.txt
