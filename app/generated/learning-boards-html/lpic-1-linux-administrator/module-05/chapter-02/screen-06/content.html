Command Reference

`chmod` with Letters: Symbolic Mode

Adding, Removing, or Setting Permissions Explicitly

User Categories

  • u: User (owner)
  • g: Group
  • o: Others
  • a: All (u, g, o)

Operators

  • +: Add permissions
  • -: Remove permissions
  • =: Set permissions explicitly (overwrite)
Key Takeaway

Symbolic mode offers a human-readable way to adjust permissions using user categories and operators, ideal for precise, incremental changes.

`chmod` Symbolic Mode Examples

chmod u+w myfile.txt

Adds write permission for the owner.

chmod go-rwx myfile.txt

Removes read, write, and execute for group and others.

chmod u=rw,go=r myfile.txt

Sets owner to read/write, group/others to read only.

chmod a+x myscript.sh

Makes `myscript.sh` executable by all users.
