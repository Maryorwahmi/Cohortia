Decoding Permission Strings

Understanding `ls -l` Output

Permission Breakdown

  • The first character indicates the file type (e.g., `-` for file, `d` for directory).
  • The next nine characters are divided into three sets of three.
  • Each set represents permissions for: Owner, Group, and Others.
  • `r` = Read, `w` = Write, `x` = Execute. A hyphen (`-`) means permission is denied.
Key Takeaway

The `ls -l` output provides a concise string detailing file type and granular `rwx` permissions for all three ownership categories.

Example: `ls -l` Output
$ ls -l myfile.txt
-rwxr-xr-- 1 john_doe devs 1024 Jan 1 10:00 myfile.txt

  ^
  |
  File Type: - (regular file)
  |
  Owner Permissions: rwx (read, write, execute)
  |
  Group Permissions: r-x (read, execute)
  |
  Other Permissions: r-- (read only)

Scenario: A script `myscript.sh` needs to be executable by its owner and group, but only readable by others. The `ls -l` output would show `-rwxr-xr--`.
