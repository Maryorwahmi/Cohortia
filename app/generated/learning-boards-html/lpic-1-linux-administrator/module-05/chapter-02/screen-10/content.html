SUID - Running with Owner's Privileges

Elevating Permissions for Specific Executables

What is SUID?

When set on an executable file, it allows the file to be run with the permissions of the file owner, not the user executing it.

Classic Example: `passwd`

The `passwd` command, owned by `root` with SUID set, allows regular users to change their password by temporarily gaining root privileges to modify `/etc/shadow`.

Security Warning

SUID can be a major security risk if misused or exploited. Only set SUID on trusted executables.

Key Takeaway

SUID enables temporary privilege escalation for specific executables, crucial for system functions but requiring careful security consideration.

SUID in `ls -l` Output
$ ls -l /usr/bin/passwd
-rwsr-xr-x 1 root root 68208 Apr 12 2023 /usr/bin/passwd

  ^
  |
  's' in owner's execute position indicates SUID is set.

# Setting SUID with numeric mode (4 is SUID bit)
chmod 4755 myscript.sh
ls -l myscript.sh
-rwsr-xr-x 1 user group ... myscript.sh

Numeric Value: SUID is represented by a leading digit 4 in `chmod` numeric mode (e.g., `chmod 4755`).
