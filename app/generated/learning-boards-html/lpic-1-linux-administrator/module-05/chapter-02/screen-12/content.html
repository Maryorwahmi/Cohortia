Sticky Bit - Protecting Shared Directories

Preventing Unauthorized Deletion in World-Writable Folders

What is the Sticky Bit?

When set on a directory, it prevents users from deleting or renaming files within that directory unless they own the file or are the directory owner (root can always delete).

Classic Example: `/tmp`

The `/tmp` directory is world-writable, but the sticky bit ensures users can only remove their own temporary files, preventing interference.

Real-world Connection

Essential for public upload directories or shared scratch spaces where multiple users need write access but not deletion rights over others' files.

Key Takeaway

The sticky bit is a critical security measure for world-writable directories, ensuring users can only manage their own files, preventing chaos and unauthorized deletion.

Sticky Bit in `ls -l` Output
$ ls -ld /tmp
drwxrwxrwt 10 root root 4096 Jan 1 10:00 /tmp

  ^
  |
  't' in others' execute position indicates Sticky Bit is set.

# Setting Sticky Bit on a directory (1 is Sticky Bit)
chmod 1777 /var/shared_uploads
ls -ld /var/shared_uploads
drwxrwxrwt 2 user group ... /var/shared_uploads

Numeric Value: The Sticky Bit is represented by a leading digit 1 in `chmod` numeric mode (e.g., `chmod 1777`).
