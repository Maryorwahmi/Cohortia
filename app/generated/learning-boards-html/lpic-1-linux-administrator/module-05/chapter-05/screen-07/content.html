Mastering Crontab Special Characters

Using Wildcards, Lists, Ranges, and Step Values for Flexible Scheduling

*

Wildcard (Any Value)

Matches all possible values for that field.

Example: * in minute field = "every minute"

,

List Separator

Specifies multiple discrete values.

Example: 1,15,30 in minute field = "at minutes 1, 15, and 30"

-

Range

Defines a continuous range of values.

Example: 9-17 in hour field = "from 9 AM to 5 PM"

/

Step Value

Specifies an interval for execution.

Example: */10 in minute field = "every 10 minutes"

Key Takeaway

Combining special characters with time fields allows for highly granular and efficient scheduling of cron jobs, reducing the need for multiple entries.
