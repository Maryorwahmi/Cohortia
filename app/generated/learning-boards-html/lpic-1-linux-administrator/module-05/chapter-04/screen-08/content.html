Controlling Services: Start, Stop, Restart

Managing active service states on demand.

Key Commands for Service Control

These commands allow you to directly manipulate the running state of a service. They are crucial for immediate operational changes and applying configurations.

  • •start: Initiates a service.
  • •stop: Terminates a running service.
  • •restart: Stops and then starts a service, often used for configuration changes.
Key Takeaway

systemctl start, stop, and restart provide immediate control over service execution, essential for maintenance and configuration updates.

Example: Managing Apache Web Server
# Start Apache web server
sudo systemctl start apache2

# Stop Apache web server
sudo systemctl stop apache2

# Restart Apache web server (e.g., after config changes)
sudo systemctl restart apache2

# Check status after operations
systemctl status apache2
Important Note

These commands only affect the service's current state. They do not configure whether the service starts automatically after a system reboot.
