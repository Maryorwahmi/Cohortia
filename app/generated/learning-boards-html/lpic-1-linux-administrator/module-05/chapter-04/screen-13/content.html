/var/log: The Directory of System History

Exploring traditional, plain-text log files.

Understanding /var/log

The /var/log directory is a standard location for various system and application log files. These are typically plain text files, often managed by logrotate.

  • •Contains historical records of system events.
  • •Complements systemd's journal for comprehensive logging.
  • •Readable with standard text processing tools (cat, tail, grep).
Key Takeaway

Traditional log files in /var/log remain vital for historical analysis and troubleshooting, especially for applications that don't fully integrate with journald.

Common Log Files in /var/log

/var/log/syslog (Debian/Ubuntu) or /var/log/messages (RHEL/CentOS): General system activity.

/var/log/auth.log (Debian/Ubuntu) or /var/log/secure (RHEL/CentOS): Authentication and security events.

/var/log/kern.log: Kernel-related messages.

Example: Viewing syslog
tail /var/log/syslog
