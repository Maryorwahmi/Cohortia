Targets: Defining System Runstates

systemd's approach to system initialization states.

Targets vs. Runlevels

systemd targets replace the traditional SysVinit runlevels. They are groups of systemd units that define a specific system state or set of services to be active.

  • •More flexible and extensible than numerical runlevels.
  • •Define a collection of services and configurations for a particular purpose.
  • •Used to configure the default boot state of the system.
Key Takeaway

systemd targets provide a modern, flexible way to define and manage system operational states, replacing older runlevel concepts.

Common systemd Targets

multi-user.target: Text-based, multi-user system (Runlevel 3 equivalent).

graphical.target: Multi-user system with graphical desktop (Runlevel 5 equivalent).

reboot.target: Used for system reboot.

Commands
  • •systemctl get-default: View default target.
  • •sudo systemctl set-default graphical.target: Set default target.
