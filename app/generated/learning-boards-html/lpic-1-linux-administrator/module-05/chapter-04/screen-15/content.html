Key Concepts

What to remember from this chapter

Service Unit File

A configuration file (e.g., sshd.service) that defines how a service is managed by systemd.

systemctl status <service>

Displays the current status of a service, including if it's active, enabled, and recent log entries.

systemctl start/stop/restart

Commands to initiate, terminate, or cycle a service's current running state.

Summary Takeaway

Effective service management relies on understanding unit files and using systemctl for both immediate control and persistent boot configuration.
