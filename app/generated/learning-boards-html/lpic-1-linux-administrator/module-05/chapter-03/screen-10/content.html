Module 5›Chapter 5.3›Foreground vs. Background Processes

Foreground Process

A command executed directly in the shell that occupies the terminal. The shell waits for it to complete before returning the prompt.

./my_script.sh

Background Process

A command that runs independently of the terminal, allowing the shell to return a prompt immediately. Achieved by appending `&`.

./my_script.sh &

Practical Example

Foreground Use Case

Running `ls -l` to list files; you wait for the output before typing the next command.

Background Use Case

Starting a long data processing script (`data_processor.py &`) while continuing to work in the same terminal.

Key Takeaway

Use `&` to run commands in the background, freeing your terminal for other tasks, but remember they are still tied to the session.
