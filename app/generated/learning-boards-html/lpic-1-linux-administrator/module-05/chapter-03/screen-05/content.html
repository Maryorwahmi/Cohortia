`ps aux` Explained

  • `a`: Shows processes for all users.
  • `u`: Displays user-oriented format (username, CPU/memory usage).
  • `x`: Includes processes not associated with a terminal (daemons).

Key Output Columns

  • USER: Owner of the process.
  • PID: Process ID.
  • %CPU, %MEM: CPU and memory usage.
  • STAT: Process state (R=running, S=sleeping, Z=zombie, T=stopped).
  • COMMAND: The command that started the process.

Key Takeaway

`ps aux` is a powerful command for getting a detailed, static overview of all system processes, their resource usage, and current states.
