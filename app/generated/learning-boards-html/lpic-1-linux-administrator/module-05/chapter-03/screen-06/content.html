Module 5›Chapter 5.3›Interactive Monitoring with `top` and `htop`

`top` Overview

  • Dynamic, real-time view of processes.
  • Sorted by CPU usage by default.
  • Displays system summary (uptime, load, CPU/Mem).
  • Interactive commands: `k` (kill), `r` (renice), `M` (sort by memory), `P` (sort by CPU).

`htop` Enhancements

  • More user-friendly, colorful, and interactive interface.
  • Allows scrolling and mouse interaction.
  • Easier to kill/renice processes.
  • Visualizes CPU cores and memory/swap usage with progress bars.

Key Takeaway

`top` and `htop` provide essential real-time insights into system performance and process behavior, allowing for immediate intervention when issues arise.
