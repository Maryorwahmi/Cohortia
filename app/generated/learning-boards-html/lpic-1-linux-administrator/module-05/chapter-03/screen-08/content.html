Module 5›Chapter 5.3›Common Signals: SIGTERM, SIGKILL, SIGHUP

SIGTERM (15)

Graceful Termination: Requests a process to shut down politely, allowing it to clean up resources before exiting. This is the default `kill` signal.

SIGKILL (9)

Forceful Termination: Immediately terminates a process without allowing any cleanup. Cannot be ignored. Use as a last resort for unresponsive processes.

SIGHUP (1)

Hang Up / Reload: Often used to tell daemon processes to re-read their configuration files without restarting, preserving service uptime.

When to Use Each Signal

Scenario: Unresponsive Application

First, try `kill PID` (SIGTERM) for a graceful shutdown. If it fails, then use `kill -9 PID` (SIGKILL).

Scenario: Configuration Change

For services like web servers, use `kill -1 PID` (SIGHUP) to reload configuration without downtime.

Key Takeaway

Always attempt graceful termination with SIGTERM first. Reserve SIGKILL for truly unresponsive processes, and use SIGHUP for configuration reloads.
