Module 5›Chapter 5.3›Managing Jobs: `Ctrl+Z`, `bg`, `fg`, `jobs`

`Ctrl+Z` (Stop)

Sends a `SIGSTOP` signal to the foreground process, pausing its execution and returning the shell prompt. The process is now 'stopped'.

`bg` (Background)

Resumes a stopped process in the background. It continues execution without occupying the terminal. Example: `bg %1`.

`fg` (Foreground)

Brings a backgrounded or stopped process back to the foreground, allowing direct interaction. Example: `fg %1`.

`jobs` (List Jobs)

Lists all processes currently managed by your shell's job control, showing their status (running, stopped) and job number.

Job Control Workflow

# Start a long process in foreground
./my_long_task.sh

# Press Ctrl+Z to stop it
# Output: [1]+  Stopped                 ./my_long_task.sh

# Move it to background
bg
# Output: [1]+ ./my_long_task.sh &

# Check current jobs
jobs
# Output: [1]+  Running                 ./my_long_task.sh &

# Bring it back to foreground
fg %1
# Output: ./my_long_task.sh (resumes in foreground)
Key Takeaway

Job control commands (`Ctrl+Z`, `bg`, `fg`, `jobs`) allow you to flexibly manage multiple processes within a single terminal session, enhancing productivity.
