Module 5›Chapter 5.3›Using `kill`, `killall`, and `pkill`

`kill PID`

  • Sends a signal to a specific process identified by its PID.
  • Default signal is SIGTERM (15) for graceful shutdown.
  • Example: `kill 12345` (sends SIGTERM) or `kill -9 12345` (sends SIGKILL).

`killall` & `pkill`

  • `killall `: Sends a signal to all processes with the exact specified name. Example: `killall firefox`.
  • `pkill `: More flexible, kills processes matching a pattern or other attributes. Example: `pkill -u john_doe` (kills all processes owned by 'john_doe').
# Find PID of 'my_long_script.sh'
ps aux | grep my_long_script.sh | grep -v grep
# Output: john      12345  0.1  0.2 ... my_long_script.sh

# Gracefully terminate process with PID 12345
kill 12345

# Forcefully terminate process with PID 12345 (last resort)
kill -9 12345

# Terminate all instances of 'apache2' gracefully
killall apache2

# Forcefully terminate all processes owned by user 'devuser'
pkill -9 -u devuser
Key Takeaway

Choose `kill`, `killall`, or `pkill` based on whether you need to target a specific PID, all instances of a name, or processes matching a pattern, always prioritizing graceful termination.
