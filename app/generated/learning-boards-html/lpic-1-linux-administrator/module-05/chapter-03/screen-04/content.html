Process Definition

A process is an instance of a running program. It's an independent execution unit with its own memory space, resources, and context, managed by the operating system.

PID & PPID Explained

  • PID (Process ID): A unique numerical identifier assigned to each running process. Essential for targeting specific processes.
  • PPID (Parent Process ID): The PID of the process that initiated the current process. Forms a hierarchical tree, with `init` or `systemd` at the root.

Process Hierarchy Example

systemd (PID 1)
sshd (PID 123)
bash (PID 456)
my_script.sh (PID 789)
Key Takeaway

Every running program is a process, uniquely identified by its PID, and linked to its parent by a PPID, forming a critical hierarchical structure for system understanding.
