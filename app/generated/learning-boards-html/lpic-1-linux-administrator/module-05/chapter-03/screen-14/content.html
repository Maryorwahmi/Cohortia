Key Concepts

Essential Terms and Tools for Process Management

Process

An instance of a running program, the fundamental unit of execution on a Linux system.

PID & PPID

PID: Unique Process ID. PPID: Parent Process ID, linking processes in a hierarchy.

`ps` Command

Displays a static snapshot of current processes and their attributes (e.g., `ps aux`).

`top` / `htop`

Interactive, real-time utilities for monitoring processes, CPU, and memory usage.

Process State

The current status of a process (e.g., Running, Sleeping, Zombie, Stopped).

`kill` Command

Used to send a signal to a process by its PID, requesting an action like termination.

Summary Takeaway

Mastering process identification, hierarchy, and monitoring tools like `ps`, `top`, and `htop` is foundational for effective Linux administration.
