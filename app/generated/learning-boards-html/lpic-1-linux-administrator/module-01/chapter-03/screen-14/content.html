Diagnosing Unbootable Systems

Strategies for identifying the root cause of boot failures.

Early Boot Failures

  • No POST: Hardware issue (RAM, CPU, PSU).
  • No Boot Device: BIOS/UEFI can't find MBR/GPT or bootloader.
  • GRUB Rescue: GRUB loaded, but config or kernel missing/corrupt.

Mid-Boot Failures

  • Kernel Panic: Severe kernel error, often due to incompatible hardware or drivers.
  • Emergency Shell: Root filesystem issues (corruption, missing `fstab` entries).
  • Service Failures: `systemd` units failing to start, preventing full system readiness.

Diagnostic Tools

  • Live USB/CD: Boot into a working environment to inspect and repair.
  • `chroot`: Change root to your installed system for repairs.
  • Log Files: Examine `/var/log/boot.log`, `journalctl` for clues.
Key Takeaway

Effective diagnosis of boot issues relies on carefully observing boot messages and leveraging rescue tools to identify the specific stage of failure.
