System Core

The Linux Kernel and Initial RAM Filesystem

Setting the Stage for the Root Filesystem

  • •

    Kernel Takes Over: Decompresses itself and initializes core system components.

  • •

    Mounts Root Filesystem: Attaches the main OS filesystem to the system.

  • •

    Initramfs Role: Provides temporary filesystem with essential drivers for early boot.

  • •

    Complex Storage: Crucial for mounting root filesystems on RAID or LVM.

Key Takeaway

The kernel and initramfs are a dynamic duo, ensuring the core system is ready and the root filesystem is accessible before the system fully initializes.
