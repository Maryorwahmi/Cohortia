Bootloader Function

GRUB: Loading the Linux Kernel

Your Gateway to the Operating System

  • •

    Loads Kernel: Primary role is to load the Linux kernel into memory.

  • •

    Boot Menu: Presents options for OS or kernel versions (often hidden).

  • •

    Boot Parameters: Allows passing parameters to the kernel for troubleshooting.

  • •

    Loads Initramfs: Also loads the initial RAM filesystem for early drivers.

Key Takeaway

GRUB is indispensable for system startup, providing flexibility and control over the boot process, especially for troubleshooting.
