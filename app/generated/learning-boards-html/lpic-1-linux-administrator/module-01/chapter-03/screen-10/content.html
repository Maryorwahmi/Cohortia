Managing systemd Targets with systemctl

Using the systemctl command to query and change systemd targets.

Querying Targets

  • 1. Get Default: `systemctl get-default` (Shows the target the system boots into by default.)
  • 2. List All Active: `systemctl list-units --type=target` (Displays all currently active systemd targets.)

Changing Targets

  • 1. Set Default: `sudo systemctl set-default multi-user.target` (Makes a target persistent across reboots.)
  • 2. Isolate (Temporary): `sudo systemctl isolate graphical.target` (Switches to a target without rebooting.)
# Get the current default target
systemctl get-default

# Example output:
# graphical.target

# List all active targets
systemctl list-units --type=target

# Example output snippet:
# UNIT                 LOAD   ACTIVE SUB    DESCRIPTION
# ...
# graphical.target     loaded active active Graphical Interface
# multi-user.target    loaded active active Multi-User System
# ...

# Set multi-user.target as default (persistent)
sudo systemctl set-default multi-user.target

# Temporarily switch to multi-user target
# (Caution: will switch to text console if on GUI)
sudo systemctl isolate multi-user.target

# Temporarily switch back to graphical target
sudo systemctl isolate graphical.target
Key Takeaway

`systemctl` is the essential command for managing systemd targets, allowing administrators to query, set, and temporarily switch system states for various operational needs.
