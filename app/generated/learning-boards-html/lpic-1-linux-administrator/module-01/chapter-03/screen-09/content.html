System State Management

systemd Targets: Modern System States

Understanding the flexible approach to defining system states in modern Linux.

SysVinit Runlevels

  • 0: Halt (power off)
  • 1: Single-user mode (maintenance)
  • 2: Multi-user, no networking (some systems)
  • 3: Multi-user, text-based networking (server default)
  • 4: Unused
  • 5: Multi-user, graphical desktop (desktop default)
  • 6: Reboot

systemd Targets

  • poweroff.target: Corresponds to runlevel 0.
  • rescue.target: Similar to runlevel 1, single-user mode.
  • multi-user.target: Corresponds to runlevel 3, text-based multi-user system with networking.
  • graphical.target: Corresponds to runlevel 5, multi-user system with a graphical desktop environment.
  • reboot.target: Corresponds to runlevel 6.
  • default.target: A symbolic link to the actual default target (e.g., graphical.target).
Key Takeaway

systemd targets provide a more granular and dependency-aware way to manage system states compared to the fixed runlevels of SysVinit, enhancing flexibility and control.
