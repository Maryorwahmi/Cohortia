Changing Directories with Absolute Paths

Navigating from the Root of the Filesystem

# Current location
$ pwd
/home/user/documents

# Change to /var/log using an absolute path
$ cd /var/log

# Verify new location
$ pwd
/var/log

# Change to /usr/local/bin from /var/log
$ cd /usr/local/bin

$ pwd
/usr/local/bin

Starts from Root (/)

An absolute path always begins with a forward slash, representing the top-level directory.

Unambiguous Location

It specifies the exact location of a file or directory, regardless of your current working directory.

Predictable Navigation

Always takes you to the same destination, making it reliable for scripts and fixed references.

Key Takeaway

Absolute paths provide a consistent and direct way to navigate to any specific location in the Linux filesystem.
