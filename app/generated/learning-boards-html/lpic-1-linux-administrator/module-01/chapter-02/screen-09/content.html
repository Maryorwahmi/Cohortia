File Management

Duplicating and Relocating Files

Mastering `cp` and `mv` for File Operations

# Assume current directory contains: file1.txt, old_report.txt, reports/
$ ls
file1.txt  old_report.txt  reports

# Copy file1.txt into the reports directory
$ cp file1.txt reports/
$ ls reports/
file1.txt

# Rename old_report.txt to new_report.txt in the current directory
$ mv old_report.txt new_report.txt
$ ls
file1.txt  new_report.txt  reports

# Move new_report.txt into the reports directory
$ mv new_report.txt reports/
$ ls
file1.txt  reports
$ ls reports/
file1.txt  new_report.txt

`cp` - Copy Files/Directories

Creates a duplicate of the source file or directory at the specified destination.

`mv` - Move/Rename Files/Directories

Relocates a file or directory, or renames it if the destination is in the same path.

Key Difference

`cp` creates a new entity; `mv` changes an existing entity's location or name.

Key Takeaway

`cp` and `mv` are essential for organizing and managing your files, allowing you to duplicate, relocate, and rename with precision.
