Filesystem Creation

Building Your Filesystem Structure

Using `mkdir` and `touch` for New Entries

# Create a new directory
$ mkdir my_project
$ ls
my_project

# Change into the new directory
$ cd my_project
$ pwd
/home/user/my_project

# Create an empty file
$ touch new_file.txt
$ ls
new_file.txt

# Create multiple directories at once
$ mkdir data reports scripts
$ ls
data  new_file.txt  reports  scripts

`mkdir` - Make Directory

Creates new directories (folders) in the specified location.

`touch` - Create Empty File

Creates a new, empty file if it doesn't exist, or updates its timestamp if it does.

Practical Use

Essential for setting up project structures and organizing your data before adding content.

Key Takeaway

`mkdir` and `touch` are your go-to commands for creating the foundational structure of your Linux filesystem.
