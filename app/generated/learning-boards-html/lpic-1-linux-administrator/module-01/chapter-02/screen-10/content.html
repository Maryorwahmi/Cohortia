Deletion Commands

Deleting Files and Directories

Using `rm` and `rmdir` with Caution

# Assume current directory contains: file_to_delete.txt, empty_dir/, full_dir/
$ ls
empty_dir  file_to_delete.txt  full_dir

# Remove a file
$ rm file_to_delete.txt
$ ls
empty_dir  full_dir

# Remove an empty directory
$ rmdir empty_dir
$ ls
full_dir

# Attempt to remove a non-empty directory (will fail)
$ rmdir full_dir
rmdir: failed to remove 'full_dir': Directory not empty

`rm` - Remove Files

Permanently deletes specified files. No trash bin, so use with care.

`rmdir` - Remove Empty Directories

Deletes directories, but only if they contain no files or subdirectories.

Common Mistake

Trying to use `rmdir` on a non-empty directory will result in an error.

Key Takeaway

`rm` and `rmdir` are powerful deletion tools; `rmdir` is safer for empty directories, but both are permanent.
