Understand Shell's Role

Grasp how the shell, especially Bash, interprets commands for the Linux kernel. This skill is vital for effective system interaction.

VERIFIED COMPETENCY MILESTONE

Navigate Filesystem

Learn to move through the Linux filesystem using both absolute and relative paths. This is fundamental for locating resources.

VERIFIED COMPETENCY MILESTONE
03

View Directory Contents

Utilize commands like 'ls' and 'pwd' to inspect your current location and directory contents. This is essential for situational awareness.

VERIFIED COMPETENCY MILESTONE
04

Manipulate Files & Dirs

Learn to create, remove, copy, and move files and directories. This is core to managing data on a Linux system.
