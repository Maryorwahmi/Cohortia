Key Concepts

Essential Terminology for Navigation and Paths

Absolute Path

A full path to a file or directory starting from the root directory (`/`).

Relative Path

A path to a file or directory specified in relation to the current working directory.

Current Working Directory

The directory you are currently operating within in the terminal.

`man` pages

Online manual pages providing documentation for commands and utilities.

Summary Takeaway

Understanding absolute and relative paths is key to navigation, and `man` pages are your go-to for command documentation.
