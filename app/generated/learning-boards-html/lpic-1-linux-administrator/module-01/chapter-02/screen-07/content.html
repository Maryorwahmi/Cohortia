Changing Directories with Relative Paths

Moving Relative to Your Current Location

# Start in home directory
$ pwd
/home/user

# Change to a subdirectory (relative)
$ cd Documents
$ pwd
/home/user/Documents

# Move up one level (parent directory)
$ cd ..
$ pwd
/home/user

# Move to home directory (shortcut)
$ cd ~
$ pwd
/home/user

# Move to a sibling directory (from /home/user/Documents to /home/user/Downloads)
$ cd Documents
$ pwd
/home/user/Documents
$ cd ../Downloads
$ pwd
/home/user/Downloads

`.` - Current Directory

Refers to the directory you are currently in.

`..` - Parent Directory

Refers to the directory one level above your current location.

`~` - Home Directory

A convenient shortcut to your user's home directory.

Key Takeaway

Relative paths offer efficient, context-aware navigation using special symbols to move within the filesystem.
