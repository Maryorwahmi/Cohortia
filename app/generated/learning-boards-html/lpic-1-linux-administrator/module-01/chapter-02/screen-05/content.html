Your Location and Directory Contents

Using `pwd` and `ls` to Explore the Filesystem

# Print Working Directory
$ pwd
/home/user

# List directory contents
$ ls
Documents  Downloads  Pictures  Public

# Long listing (details)
$ ls -l
total 20
drwxr-xr-x 2 user user 4096 Jan 15 10:00 Documents
drwxr-xr-x 2 user user 4096 Jan 15 10:00 Downloads
-rw-r--r-- 1 user user  120 Jan 15 10:05 my_report.txt

# List all files (including hidden)
$ ls -a
.  ..  .bashrc  Documents  Downloads  Pictures  Public

# Long listing of all files
$ ls -la
total 32
drwxr-xr-x 5 user user 4096 Jan 15 10:05 .
drwxr-xr-x 3 root root 4096 Jan 10 09:00 ..
-rw-r--r-- 1 user user  220 Jan 10 09:00 .bashrc
drwxr-xr-x 2 user user 4096 Jan 15 10:00 Documents
... (more files and directories)

`pwd` - Print Working Directory

Shows your current location in the filesystem tree.

`ls -l` - Long Listing

Displays detailed file information: permissions, owner, size, date.

`ls -a` - All Files

Includes hidden files (starting with a dot) in the listing.

Key Takeaway

`pwd` and `ls` are fundamental for understanding your current location and the contents of directories.
