Instruction components
  • program_id: the program to invoke.
  • account_metas: public keys with is_signer and is_writable flags.
  • instruction_data: a byte array of program-specific arguments.
Concrete example
System Program transfer: instruction contains program_id for System Program, account metas for source and destination, and data representing amount to transfer.
Design notes
Keep instruction_data compact and well-documented for your program. Always include the exact accounts the program expects, and set writable flags only when necessary.
Pro tip
When composing multi-instruction transactions, ensure the account keys are ordered and deduplicated as your program expects.
