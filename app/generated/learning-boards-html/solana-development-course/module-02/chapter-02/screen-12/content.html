Module 2 › Chapter 2.2 › Hands-on: Analyze a Devnet Transaction
Activity Steps
  1. Find a recent devnet transaction that lists multiple instructions.
  2. Copy the transaction signature and open its details in the explorer.
  3. Identify the program_id for each instruction and list involved accounts.
  4. Compare pre-balance and post-balance for each account to compute lamport changes.
  5. Label each instruction with a short purpose and reflect on atomicity.
Learning outcome
You will be able to trace how multiple instructions cooperate to complete a higher-level action, and to confirm which program IDs performed each step.
Analysis hints
  • If instruction decoding is unavailable, use program_id and account order to deduce intent.
  • Watch for approve-like instructions preceding transfers; they often set up permissions.
  • Note fees and whether pre/post balances align with your expected amounts.
Final reflection: did the transaction achieve its goal atomically, and which instruction would cause the transaction to fail if it failed alone?
