Terminal Commands
# Configure your CLI to use your devnet keypair solana config set --keypair devnet-wallet.json # Ensure you're connected to devnet solana config set --url devnet # Verify your configuration solana config get # Create a temporary recipient keypair solana-keygen new --outfile recipient-temp.json --no-passphrase # Transfer 0.5 SOL (replace <RECIPIENT_PUBLIC_KEY> with the generated public key) solana transfer <RECIPIENT_PUBLIC_KEY> 0.5 --allow-unfunded-recipient
When the transfer completes, the CLI will output a Signature line. Copy it for inspection on a block explorer. If you see errors about blockhash freshness, regenerate or reconfigure your CLI session and retry quickly.
Expected CLI output
# Example output: # Signature: 5Wj... (transaction signature you will copy)
Check after transfer
Confirm sender balance decreased by 0.5 SOL plus the fee in lamports. If not, inspect the signature to see transaction status.
