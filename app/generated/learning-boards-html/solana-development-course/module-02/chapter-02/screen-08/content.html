Module 2 › Chapter 2.2 › Transaction Lifecycle
Sign, Broadcast, Validate, Confirm
Validators verify signatures, blockhash freshness and execute instructions. Successful execution leads to inclusion in a block.
1. Construct
Build message with header, keys, blockhash, and instructions.
2. Sign
Required keypairs sign to authorize the operation.
3. Broadcast
Send the signed transaction to the network via RPC.
4. Validate & Confirm
Validators verify, execute instructions, and include the transaction if successful.
Concrete CLI example
When you run the solana transfer command, the CLI signs locally with your keypair, broadcasts, and prints a transaction signature you can inspect on a block explorer.
Check
If the blockhash is stale or the fee is insufficient, validators will reject the transaction even if it is properly signed.
