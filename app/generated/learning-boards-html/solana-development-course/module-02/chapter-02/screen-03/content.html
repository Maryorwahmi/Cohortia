Hands-on Objectives
  • Run the Solana CLI to set keypair and devnet URL and send 0.5 SOL.
  • Copy the transaction signature returned by the CLI and paste it into a block explorer search box to inspect.
  • Confirm the instruction is a System Program transfer and note pre/post balances and the fee paid in lamports.
  • Reflect: did the transaction include additional instructions or program calls?
Verification Tips
Always check recent blockhash freshness, ensure signer keys match the accounts that require signature, and confirm sender balance covers lamports for fees. Copy signatures immediately and keep them for audit and debugging.
