Understanding Solana Accounts
Accounts are Solana's primary storage primitives. They hold data, a lamport balance, and an owner program. This model powers high-performance programs and clear permission boundaries.
In this lesson
You will learn the account model, ownership rules, rent, and keypair CLI commands so you can create and manage accounts on devnet.
Why it matters
The account model determines how programs control state, how persistence is funded, and how wallets map to on-chain storage. Good account design prevents data loss and bugs.
Explore Key Topics
Account Model
Accounts store data, have an owner program, and a lamport balance.
Ownership & Security
Only the owning program can modify an account's data — a key permission concept.
Rent & CLI
Rent-exemption and solana-keygen commands ensure persistence and developer control.
Interactive Concept
Account
address = public key; owner = program; data & lamports
Keypair
public key derived from a keypair; private key signs transactions
Rent
small lamport deposit required for storage; rent-exempt if threshold met
Quick glance
Treat accounts as addressable files. Their owner program controls updates. Keep private keys secure and make accounts rent-exempt when you need persistent state. Use CLI to create and fund devnet accounts for testing.
