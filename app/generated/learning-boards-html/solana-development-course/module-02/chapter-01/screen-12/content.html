Module 2 › Chapter 2.1 › Security & Mistakes
Private key safety
  • Never commit key files to public repositories.
  • Use passphrase encryption for persistent keys.
  • Keep devnet keys separate from production keys.
Account persistence
  • Make critical accounts rent-exempt to prevent deallocation.
  • Check balances and ownership when state is missing.
  • Validate writable flags in instructions to avoid runtime rejections.
Debugging checklist
If an instruction fails, confirm the passed accounts, ownership alignment, writable flags, and sufficient lamport balance for rent; these are the most common failure points.
Final tip
Document which program owns each account type in your architecture so team members do not accidentally pass the wrong accounts or owners in transactions.
