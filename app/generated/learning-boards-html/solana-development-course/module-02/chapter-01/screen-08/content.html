Module 2 › Chapter 2.1 › Generate a Keypair
Command (example)
# Generate a new keypair and save it to 'my-keypair.json'
solana-keygen new --outfile my-keypair.json

# Example output:
# Generating a new keypair
# Writing new keypair to my-keypair.json
# Public Key: 5cK9m... (your unique public key)
You will be prompted to set a passphrase to encrypt the private key file. Use a strong passphrase for anything beyond ephemeral test keys.
Practical note
Generating a keypair creates the address but not funds it. The next step is to derive the public key and check the balance before requesting an airdrop on devnet.
Key Takeaway

Always secure key files. Use passphrases and separate devnet keys from mainnet keys.
