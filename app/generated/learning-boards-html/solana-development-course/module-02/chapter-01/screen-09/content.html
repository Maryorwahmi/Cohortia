Module 2 › Chapter 2.1 › Derive & Check Balance
Commands (examples)
# Get the public key from a keypair file
solana-keygen pubkey my-keypair.json

# Check the balance of that public key
solana balance $(solana-keygen pubkey my-keypair.json)

# On devnet, include --url devnet when necessary
you can also run: solana balance  --url devnet
Example output
A newly generated account typically shows 0 SOL. After an airdrop it will show the funded amount, which confirms the account holds lamports.
Checklist before airdrop
  • Copy the printed public key to avoid typos.
  • Confirm your CLI is pointed to devnet if you intend to use devnet.
  • Verify the balance is zero before requesting test funds.
Key Takeaway
Always confirm addresses and networks before funding. Mistargeted airdrops go to the wrong public key and are hard to recover.
