Module 2 › Chapter 2.1 › Account Types
Two-panel comparison
System accounts
Owned by the System Program; manage native SOL and account creation.
Program accounts
Contain executable code; marked executable and owned by deployment authority.
Data accounts
Hold application state and are owned by the program responsible for that state.
Concrete scenario
Imagine an on-chain auction: the auction program is a program account, each auction's state sits in a data account owned by that program, and bids may include SOL transfers between system accounts.
Common mistake: attempting to mutate a data account without the owning program will fail.

Key Takeaway
Choose account type based on purpose: system for native transfers, program for code, data for state. Ownership determines who can write data.
