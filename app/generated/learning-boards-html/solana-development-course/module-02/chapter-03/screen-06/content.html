Module 3 › Chapter 2.3 › Verify context & version
Command

solana config get

Use this to confirm your CLI's current URL and default keypair path. It prevents accidental use of the wrong cluster or signer.

solana config get
# Example output:
# RPC URL: https://api.devnet.solana.com
# Keypair Path: /home/user/.config/solana/devnet-wallet.json
# Commitment: confirmed
Command

solana cluster-version

Queries the node for its release version. Helpful when debugging compatibility or node-specific behavior.

solana cluster-version
# Example output:
# 1.18.15 (solana-release v1.18.15)
Key Takeaway

Make these checks part of your pre-flight routine to detect wrong contexts and node incompatibilities early.
