Commands

Set cluster and keypair

Use solana config set with --url to change clusters and --keypair to choose which wallet signs transactions. Always run solana config get afterwards.

# Set the cluster to Devnet
solana config set --url devnet

# Set your default keypair
essolana config set --keypair /path/to/your/devnet-wallet.json

# Verify configuration
solana config get
Why confirm

solana config get shows your current URL and keypair. This explicit confirmation prevents accidental operations on mainnet-beta or another unintended cluster.

Concrete tip

When scripting, prefer passing --url and --keypair in the command so the script is explicit about its target, rather than relying on global config.

Key Takeaway

Always confirm your cluster and signer. Mistaken context is the most common source of surprising CLI behavior.
