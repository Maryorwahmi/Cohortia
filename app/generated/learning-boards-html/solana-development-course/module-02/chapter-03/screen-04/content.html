Module 3 › Chapter 2.3 › What is the Solana CLI?
Definition

A developer tool for direct network access

The CLI provides commands to set cluster targets, choose a signing keypair, request development funds, execute transfers, deploy programs, and inspect transactions for logs and account changes.

Key capabilities
  • Configure cluster URL and default keypair.
  • Request airdrops on devnet, testnet, and localhost.
  • Send SOL transfers and inspect transaction details.
Common misconception

The CLI is not only for experts; it's the fastest way to reproduce and debug program behavior because it reveals raw transaction data and logs.

Analogy
The CLI is like a microscope for blockchain operations

It magnifies low-level details you cannot see in a wallet UI and helps you diagnose why a transaction or program instruction failed.

Example
Check cluster version
solana cluster-version
# Example output:
# 1.18.15 (solana-release v1.18.15)
