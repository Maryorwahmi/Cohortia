Module 3 › Chapter 2.3 › Transferring SOL
Command

solana transfer

Run a transfer and capture the signature to confirm or inspect the transaction afterwards.

# Transfer 0.1 SOL to a recipient, creating the recipient if needed
solana transfer <RECIPIENT_PUBLIC_KEY> 0.1 --allow-unfunded-recipient

# After the command you will see a signature; copy it for the next step.
Confirm

Use solana confirm with the signature to wait for network confirmation. This ensures the transaction reached the desired commitment level.

# Wait for confirmation
solana confirm <TRANSACTION_SIGNATURE>
Key Takeaway

Always copy your transaction signature and use it to confirm and inspect the transaction for reliable debugging.
