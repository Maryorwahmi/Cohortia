Overview

solana program deploy

Use this command to upload a compiled BPF program file to a cluster. Practice on localhost and devnet before attempting mainnet-beta deployment.

# Deploy a compiled program
# Assumes you have a compiled .so file
# solana program deploy <PATH_TO_PROGRAM_SO_FILE>
Post-deploy

After deployment, use transaction inspection to confirm your program receives correct instructions and logs. Verify the program ID and accounts used by each instruction.

Practice tip

Deploy locally and to devnet first. Confirm funding and account ordering in transaction logs before moving to mainnet-beta.

Key Takeaway

The CLI is also your deployment and program-debugging tool. Use it to view program logs and confirm instruction behavior after deploys.
