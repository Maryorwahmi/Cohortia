Command Line Access to Solana

Use the Solana CLI to control cluster connections, wallet keypairs, request test airdrops, move SOL, and inspect transaction details for debugging and development.

Why this matters: the CLI removes UI friction and surfaces raw transaction data and logs you need when the program behavior differs from expectation.

Concrete example: configure the CLI to devnet, request 2 SOL, transfer 0.1 SOL to a temporary keypair, then inspect the transaction signature to confirm state changes.

Misconception check: the CLI’s airdrops are available only on devnet, testnet, and localhost — never on mainnet-beta.
