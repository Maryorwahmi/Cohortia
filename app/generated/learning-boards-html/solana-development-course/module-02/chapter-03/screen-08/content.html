Module 3 › Chapter 2.3 › Balance & Recipient Options
Command

solana balance

Check the balance for your default keypair or a supplied public key to ensure sufficient funds for transfers and fees.

# Default keypair
solana balance

# Specific public key
solana balance <PUBLIC_KEY>
Flag

--allow-unfunded-recipient

When sending to a new address, this flag instructs the system to create the recipient account using part of the transfer to pay rent-exemption, avoiding a failed transaction.

# Transfer 0.1 SOL and allow creating the recipient
solana transfer <RECIPIENT_PUBLIC_KEY> 0.1 --allow-unfunded-recipient
Key Takeaway

Always ensure your balance covers the transfer and the fee. Use the flag only when you intentionally want the transfer to create the recipient account.
