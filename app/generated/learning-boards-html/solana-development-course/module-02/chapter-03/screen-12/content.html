Module 3 › Chapter 2.3 › Localhost Lab
Lab steps
  1. Start the local validator with solana-test-validator and keep it running.
  2. In a new terminal set CLI to localhost: solana config set --url localhost.
  3. Generate and set a keypair: solana-keygen new --outfile localhost-wallet.json and solana config set --keypair localhost-wallet.json.
  4. Request an airdrop: solana airdrop 100 and verify with solana balance.
  5. Create a recipient and transfer 50 SOL with allow-unfunded-recipient, then inspect the signature with solana transaction.
Command examples
# Start validator (keep open)
solana-test-validator

# Configure CLI for localhost
solana config set --url localhost
solana-keygen new --outfile localhost-wallet.json
solana config set --keypair localhost-wallet.json

# Request localhost funds
solana airdrop 100

# Check balance
solana balance

# Generate recipient and transfer
solana-keygen new --outfile recipient-localhost.json --no-passphrase
solana transfer $(solana-keygen pubkey recipient-localhost.json) 50 --allow-unfunded-recipient

# Inspect transaction
solana transaction <YOUR_TRANSACTION_SIGNATURE>
Key Takeaway

The localhost lab is the safest, fastest loop to validate transfers and program state without network variability.
