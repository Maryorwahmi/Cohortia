Module 3 › Chapter 2.3 › Requesting Airdrops
Commands

solana airdrop

Request test SOL for the default keypair or a specified public key. Use on devnet, testnet, or localhost only.

# Request 2 SOL for default keypair on Devnet
solana airdrop 2

# Request 2 SOL for a specific public key
solana airdrop 2 <PUBLIC_KEY_OF_ACCOUNT>
Verify

After the airdrop completes, copy the returned signature and run solana balance to confirm the funds arrived and the account balance updated.

Localhost note

When running solana-test-validator, airdrops are immediate and can be requested in larger amounts for local testing, making it ideal for program state experiments.

Key Takeaway

Use airdrops on devnet or localhost to fund development accounts; confirm signature and balance afterwards.
