Module 3 › Chapter 2.3 › Inspecting Transactions
Command

solana transaction

Supply a confirmed transaction signature to view its instructions, accounts, and program logs. This is the primary debugging output when programs fail.

# View details for a transaction signature
solana transaction <TRANSACTION_SIGNATURE>

# The output shows instruction list, accounts, and program logs used for debugging.
How to read

Look for program log lines and error messages. Confirm which instruction index failed and what accounts were passed to it. That reveals account ordering or funding issues.

Example observation

If you see an insufficient funds message, check the sender’s balance and the rent-exempt requirement for any created accounts.

Key Takeaway

Use transaction output to pinpoint failing instructions and account problems instead of guessing at high-level symptoms.
