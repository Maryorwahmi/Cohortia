Module 4 › Chapter 4.1 › Scaffold a Vite React + TypeScript Project
Process

Create your project

A short, reliable sequence to scaffold and verify a React TypeScript starter using Vite.

Step 1 — Scaffold
Run the create vite command with the react-ts template and give the project a name.
Step 2 — Install
Change into the project folder and run the package manager install to fetch dependencies.
Step 3 — Run Dev Server
Start the development server and open the provided local URL to confirm the default page appears.
Key Takeaway

A Vite + TypeScript scaffold provides a fast, type-safe foundation for adding Solana libraries and wallet integration.

// Terminal sequence (visual example)
npm create vite@latest my-solana-dapp -- --template react-ts
cd my-solana-dapp
npm install
npm run dev
// Open the URL shown by Vite, typically a localhost address
Concrete example
Name your folder my-solana-dapp so your project name is explicit about intent.
Common mistake
Not running install after scaffolding leaves the project unable to start. Always run install before the dev server.
