Learning Objectives — Practical Focus

Concrete verification steps for each objective.

Bloom: Apply → Master
01 Scaffold & Validate

Run the Vite scaffold command, install, and start the dev server. Milestone: browser shows your Hello Solana DApp message.

VERIFIED COMPETENCY MILESTONE
02 Install Solana libraries

Add @solana/web3.js and the wallet adapter packages, then check package.json. Milestone: packages successfully installed.

VERIFIED COMPETENCY MILESTONE
03 Organize Solana code

Create services or utils for connection and transaction logic to avoid UI entanglement. Milestone: src/services contains connection setup files.

VERIFIED COMPETENCY MILESTONE
04 Troubleshoot environment

Inspect console errors and apply a Buffer polyfill if needed. Milestone: no Buffer or global errors in console after fixes.

VERIFIED COMPETENCY MILESTONE
