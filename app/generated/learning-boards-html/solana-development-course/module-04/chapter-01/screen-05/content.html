A minimal App component to validate your setup

Keep the first UI simple so that later integration problems are easier to isolate.

Why this matters
A small, working UI confirms that the build and render pipeline are correct before adding wallet and blockchain logic.
Misconception
Don't add wallet adapter code until you confirm the base app loads. Mixing steps increases debugging noise.
