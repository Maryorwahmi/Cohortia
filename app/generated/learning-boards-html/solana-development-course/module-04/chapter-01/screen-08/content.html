Hierarchy

A practical folder layout

Keep your Solana-specific logic isolated from UI code for easier maintenance and testing.

components/ — Presentational UI components and buttons.
hooks/ — Reusable React hooks for wallet-aware behavior.
services/ or utils/ — Connection setup, transaction builders, and program interactions.
constants.ts — Program IDs, cluster URLs, and static configuration.
Key Takeaway

Isolating Solana logic in services and constants keeps UI components simple and easier to reuse.

Concrete example: src/services/connection.ts exports a function createConnection that selects the cluster URL from constants and returns a connection object from web3.js.
Common mistake: hardcoding program IDs in components makes refactoring and testing difficult. Use constants instead.
