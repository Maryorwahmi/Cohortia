Hands-on Activity

Initialize and verify your Solana DApp

Follow this checklist and confirm each milestone to complete the setup.

  1. Scaffold a Vite React TypeScript project and change into the folder.
  2. Run npm install and start the dev server to confirm the app renders.
  3. Install @solana/web3.js and the wallet adapter packages and confirm package.json.
  4. Replace src/App.tsx with the minimal Hello Solana DApp component and reload the page.
  5. Wrap your app with WalletProvider and WalletModalProvider and test connecting a wallet.
  6. Open the browser console and resolve missing globals by applying polyfills when necessary.
Key Takeaway

Work step-by-step: verify the base app first, then add libraries and providers, and finally troubleshoot runtime errors.

// Quick reference commands
npm create vite@latest my-solana-dapp -- --template react-ts
cd my-solana-dapp
npm install
npm install @solana/web3.js @solana/wallet-adapter-react @solana/wallet-adapter-react-ui @solana/wallet-adapter-wallets
npm run dev
Check: package.json should list the Solana packages and the browser console should not show missing Buffer or other Node.js globals.
