Architecture

Provider pattern for wallet access

Centralize wallet state and UI at the app root so all components can request signatures and read the connected public key consistently.

WalletProvider: React context and hooks for connection state and signing.
WalletModalProvider: supplies UI components like the multi-wallet button and modal.
Concrete setup
Configure wallet adapter instances, pass them to WalletProvider, and wrap your App so hooks like useWallet work across the app.
Common mistake

Placing provider wrappers inside deep components fragments wallet state. Keep providers high in the tree.

// conceptual example (not exact imports shown)
const wallets = [new PhantomWallet(), new SolflareWallet()];
Example check: after wrapping, call the adapter hook to read the public key and confirm it appears after connecting a wallet.
