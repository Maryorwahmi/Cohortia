Definition

What each package does

Install these packages to handle blockchain calls and wallet interactions reliably.

@solana/web3.js
Client-side API for connections, transactions, and account queries.
@solana/wallet-adapter-react
Provides React hooks and context to manage wallet state and requests.
@solana/wallet-adapter-react-ui
Pre-built UI components to let users select and connect wallets.
@solana/wallet-adapter-wallets
Collection of wallet implementations for common wallets used by DApps.
Concrete install command shown in the right panel installs all four packages at once.
// Install example (visual)
npm install @solana/web3.js \
  @solana/wallet-adapter-react \
  @solana/wallet-adapter-react-ui \
  @solana/wallet-adapter-wallets
Example: after install, inspect package.json to confirm entries for each package.
Misconception: wallet UI packages are optional; you can add them later but installing adapters early helps plan architecture.
