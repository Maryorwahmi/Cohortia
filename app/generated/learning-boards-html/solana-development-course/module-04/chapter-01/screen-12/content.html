Module 4 › Chapter 4.1 › Package Versioning and Dependency Conflicts
Definition

Keep package.json and installs consistent

Install packages, confirm entries, and heed version warnings to avoid runtime surprises.

Concrete steps: after installing libraries for Solana, open package.json, verify versions, and run npm install. If you edit package.json, always re-run install so node modules match the file.
Common mistake: leaving lockfile mismatches between team members or CI. Align package manager usage and lockfiles to reduce conflicts.
// Check package.json after install (example keys)
{
  "dependencies": {
    "@solana/web3.js": "",
    "@solana/wallet-adapter-react": "",
    "@solana/wallet-adapter-react-ui": "",
    "@solana/wallet-adapter-wallets": ""
  }
}
Check your understanding

If runtime errors reference version mismatches, re-evaluate package versions and reinstall to ensure consistency.
