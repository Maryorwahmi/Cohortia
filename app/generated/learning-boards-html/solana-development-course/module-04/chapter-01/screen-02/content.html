Learning Objectives

Master the essential setup steps for a React Solana DApp.

Bloom: Learn → Understand → Apply → Master
01
Initialize a Vite React-TS project

Scaffold a new project using Vite’s React TypeScript template and verify the dev server runs. Verified milestone: project boots to a Hello Solana DApp page.

Mnemonic: Scaffold → Serve
02
Install @solana/web3.js and wallet adapters

Add client libraries to enable blockchain calls and standard wallet connections. Verified milestone: packages appear in package.json and install completes without errors.

Mnemonic: Library → Connect
03
Understand project structure

Organize src into components, hooks, services, and constants so Solana logic is isolated. Verified milestone: a utils or services folder contains connection setup.

Mnemonic: Separate concerns
04
Identify setup issues and polyfills

Recognize errors like "Buffer is not defined" and apply the minimal polyfill steps when necessary. Verified milestone: browser console shows no missing global errors after fixes.

Mnemonic: Inspect → Fix
