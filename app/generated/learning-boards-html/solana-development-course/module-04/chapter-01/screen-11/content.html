Module 4 › Chapter 4.1 › Troubleshooting: The Buffer Polyfill Issue
Comparison

Polyfill present vs missing

Understand the difference and the minimal steps to resolve the browser Buffer error.

With polyfill: @solana/web3.js functions run, connections succeed, and transactions serialize correctly.
Without polyfill: console reports "Buffer is not defined" and blockchain calls fail at runtime.
Practical resolution: install the buffer package and configure your bundler to provide it in the browser environment. For many setups a small change in the bundler config restores the global Buffer reference.
// Visual hint (install example)
npm install buffer
// Then configure bundler to shim or provide global Buffer where required
Common mistake: assuming reinstalling web3.js resolves the error. Polyfills are bundler-level fixes, not package reinstallations.
Key Takeaway

When the console reports missing Node.js globals, fix the bundler or add a browser polyfill rather than reinstalling libraries alone.
