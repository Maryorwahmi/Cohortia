Module 4 › Chapter 4.3 › Tx lifecycle
Step-by-step
  1. 1. User triggers action. Example: 'Create Counter Account'.
  2. 2. Derive PDAs and assemble accounts required by IDL.
  3. 3. Build instruction(s) and append to Transaction.
  4. 4. Request wallet signature; wallet shows fees and signers.
  5. 5. Send signed transaction and wait for confirmation.
Concrete snippet
// Anchor builds and sends
await program.methods
  .create()
  .accounts({
    counterAccount: counterPda,
    user: publicKey,
    systemProgram: anchor.web3.SystemProgram.programId,
  })
  .rpc();
Common pitfall

If the wallet lacks sufficient SOL for new account rent or compute fees, the transaction will fail. Always check balances before creating new accounts.

Key Takeaway

Design UI flows that clearly show approval, pending confirmation, and final success or error so users understand the blockchain delay and cost.
