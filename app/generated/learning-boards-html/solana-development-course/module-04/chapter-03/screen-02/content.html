Learning Objectives

Learn, Understand, Apply, Master

Bloom: Learn → Understand → Apply → Master
01
Construct & sign transactions
Build a transaction, add instructions, and use the connected wallet to sign. This matters because signing is the user's consent to change state on-chain.
VERIFIED COMPETENCY MILESTONE
02
Use @coral-xyz/anchor
Instantiate anchor.Program with IDL and provider so you can call methods that map to your on-chain instructions.
VERIFIED COMPETENCY MILESTONE
03
Send instructions & handle confirmation
Send transactions, wait for rpc confirmation, and surface clear feedback or retries when needed.
VERIFIED COMPETENCY MILESTONE
04
Diagnose errors & fees
Recognize missing signers, incorrect program IDs, IDL mismatches, and insufficient funds for transaction fees or account rent.
VERIFIED COMPETENCY MILESTONE
