Module 4 › Chapter 4.3 › PDAs
What is a PDA?

A PDA is computed from seeds and a program ID and is owned by the program. It is not backed by a private key, so only the program can authorize actions on it.

// Derive PDA
const [counterPda] = PublicKey.findProgramAddressSync(
  [Buffer.from('counter'), publicKey.toBuffer()],
  program.programId
);
// counterPda is deterministic and program-owned
Concrete use

Use the PDA as the counterAccount referenced in your create and increment instructions so the program can store the count securely.

Misconception

PDAs are not keys. You cannot sign with a PDA; the program enforces operations on the PDA via instruction checks and program logic.

Key Takeaway

Derive PDAs identically in client and program. If derivation differs, account mismatches will cause transaction failures.
