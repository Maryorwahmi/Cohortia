Module 4 › Chapter 4.3 › Calling rpc()
Example call
await program.methods
  .create()
  .accounts({
    counterAccount: counterPda,
    user: publicKey,
    systemProgram: anchor.web3.SystemProgram.programId,
  })
  .rpc();
This single call builds the instruction from the IDL, requests wallet signing through AnchorProvider, and sends the signed transaction to the network.
Developer checklist
  • Keep IDL in sync with deployed program.
  • Provide all accounts declared in the IDL, especially signers.
  • Check wallet has funds before creating accounts that require rent.
  • Show clear UI states for approval, pending, and confirmation.
Key Takeaway

Use program.methods for convenience but validate accounts and IDL alignment to avoid runtime failures.
