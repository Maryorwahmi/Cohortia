Module 4 › Chapter 4.3 › Fees & rent
Why check balance?

Insufficient funds will cause failed transactions. Estimate fees and required rent for new accounts and show that info before requesting a signature.

// Example check const lamports = await connection.getBalance(publicKey); if (lamports < requiredLamports) { // inform user: not enough SOL }
Example

Before calling create, compute the rent-exempt amount and present it so the user understands the approval will deduct SOL.

Common pitfall

Assuming network fees are constant. Fees vary; always compute or fetch recent fee estimates and present a helpful message.

Key Takeaway

Estimate and show fees and rent before sending transactions to avoid surprises and failed attempts.
