Module 4 › Chapter 4.3 › AnchorProvider
Provider structure
  • Connection: RPC endpoint for sending transactions and querying state.
  • Wallet sendTransaction: used to request signatures and obtain signed transactions.
  • Options: commitment level and other provider settings.
Usage snippet
const provider = new anchor.AnchorProvider(connection, { publicKey, sendTransaction } as any, { commitment: 'confirmed' });
const program = new anchor.Program(idl as anchor.Idl, programId, provider);
Safety note

Never hardcode private keys in a client. Always rely on the connected wallet to sign transactions.

Key Takeaway

Centralize provider creation so all program interactions use the same signing and connection behavior, and handle network retries at this boundary.
