Module 4 › Chapter 4.3 › Anchor vs web3.js
Anchor (IDL-based)
  • Type-safe methods generated from IDL
  • Handles serialization and instruction building
  • Integrates with AnchorProvider for signing
@solana/web3.js (manual)
  • Full control over instruction bytes
  • Requires manual packing of arguments
  • Useful for programs without an IDL or custom serialization
Example

Anchor: program.methods.increment().accounts({...}).rpc() — minimal client code. Manual: build TransactionInstruction with program id, keys, and serialized data buffer.

Key Takeaway

Prefer Anchor for Anchor programs for clarity and speed; use raw web3.js when you need low-level control or when no IDL exists.
