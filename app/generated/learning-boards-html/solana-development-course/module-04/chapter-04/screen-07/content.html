Process Loading & Error UX
Pattern
Before fetch
setLoading(true); setMessage('Fetching counter...')
On success
setCurrentCount(account.count.toNumber()); setMessage('Counter fetched successfully.')
On error
log error, setCurrentCount(null); setMessage('Error fetching counter: ...')
Finally
setLoading(false) so UI does not remain locked.
Concrete example
setLoading(true);
setMessage('Incrementing counter...');
try {
  await program.methods.increment().accounts({ counterAccount: counterPda, user: publicKey }).rpc();
  await fetchCounter();
  setMessage('Counter incremented successfully!');
} catch (err) {
  setMessage('Error incrementing: ' + err.message);
} finally {
  setLoading(false);
}
Always disable transaction controls while loading to prevent duplicate transactions and confusing state.
