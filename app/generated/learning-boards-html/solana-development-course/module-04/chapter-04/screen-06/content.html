Process Flow PDA derivation
Step-by-step
1. Wait for wallet connect
Ensure publicKey and program exist before deriving.
2. Derive PDA deterministically
Use PublicKey.findProgramAddressSync with the same seeds used on-chain.
3. Store PDA in state
Set counterAccountPda and trigger fetch via useEffect.
Visual code hint
const [counterPda, setCounterPda] = useState<PublicKey | null>(null);
useEffect(() => {
  if (connected && publicKey && program) {
    setCounterPda(getCounterPda());
  } else {
    setCounterPda(null);
    setCurrentCount(null);
  }
}, [connected, publicKey, program, getCounterPda]);
Avoid deriving inside render. Use useCallback or useMemo for getCounterPda to keep effects stable.
