// memoize program
const program = useMemo(() => {
  if (publicKey) {
    const provider = new anchor.AnchorProvider(connection, { publicKey, sendTransaction } as any, { commitment: 'confirmed' });
    return new anchor.Program(idl as anchor.Idl, programId, provider);
  }
  return null;
}, [connection, publicKey, sendTransaction]);

// fetchCounter
const account = await program.account.counterAccount.fetch(counterAccountPda);

Explanation cards
Memoize program to avoid reinitializing provider and repeating RPC setup.
Use program.account.X.fetch to both fetch and deserialize according to your IDL.
Convert BN to number before rendering; guard against overflow where needed.
Handle errors: if fetch fails reset state and show a helpful message.
Key Takeaway

Anchor fetch returns typed objects; convert anchor.BN to numbers and store in state to display safely.
