Definition AccountInfo Buffer
What is inside AccountInfo?
  • Owner, lamports, executable flag, and a data Buffer that contains serialized fields.
  • The Buffer follows the structure written by your program; fields must be parsed in the same order.
  • Deserialization turns bytes into usable primitives, arrays, or nested objects.
Concrete example
A Counter account contains a single u64. The Buffer holds eight bytes for that u64; Anchor returns an object with count as anchor.BN which you convert to number for display.
Anchor vs manual parsing
Use Anchor fetch to read and deserialize automatically according to the IDL.
Manual parsing requires exact byte offsets, integer widths, and endianness.
A common mistake: assuming parsed account formats apply to custom program accounts; they usually do not.
