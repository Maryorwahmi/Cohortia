Best Practices Common mistakes
Stale UI
Always call fetch after a transaction completes so the UI reflects the new on-chain state.
Infinite re-renders
Memoize functions used in effects. Avoid changing dependencies each render.
RPC limits
Prefer targeted re-fetches and limit subscriptions to reduce RPC usage and rate limiting.
Pro tip
If fetch fails because an account is missing, show a guided prompt to create the account rather than a raw error message.
