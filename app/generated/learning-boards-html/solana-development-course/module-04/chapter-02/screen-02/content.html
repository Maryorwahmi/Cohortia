Learning Objectives

Progress through these practical milestones to validate your DApp's network and wallet setup.

Bloom: Learn → Understand → Apply → Master
01
Identify Solana clusters

Explain devnet, testnet, and mainnet-beta and when to use each environment for safe testing and production readiness.

Mnemonic: devnet = sandbox, mainnet-beta = production
Verified Competency Milestone
02
Create a Connection instance

Use the Connection class and clusterApiUrl helper to initialize RPC access and choose appropriate commitment levels for queries and transactions.

Mnemonic: single connection instance for app lifecycle
Verified Competency Milestone
03
Wrap app with Wallet providers

Integrate ConnectionProvider, WalletProvider, and WalletModalProvider to manage wallet state and surface a connect modal to users.

Mnemonic: provider tree equals global wallet state
Verified Competency Milestone
04
Read wallet state with useWallet

Detect connection status and the publicKey, and handle connect and disconnect flows safely in your UI.

Mnemonic: publicKey?.toBase58() for display
Verified Competency Milestone
