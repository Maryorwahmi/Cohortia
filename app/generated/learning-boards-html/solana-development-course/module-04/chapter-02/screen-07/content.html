Architecture

Provider hierarchy

Use ConnectionProvider to set the RPC endpoint, WalletProvider to manage wallet state and wallets array, and WalletModalProvider to provide the modal UI for user selection.

ConnectionProvider: accepts endpoint and supplies RPC access.
WalletProvider: receives wallets array and handles connection state.
WalletModalProvider: renders modal UI for users to pick a wallet.
Concrete Example

In your top-level App, memoize both endpoint and wallets with useMemo and then nest the providers. Include the WalletMultiButton in your header for a standard connect control.

Common Mistakes
  • Forgetting to import the wallet-adapter UI CSS, which prevents the modal from showing correctly.
  • Not providing the wallets array to WalletProvider, leaving no adapters available.
Key Takeaway

Wrap providers in the correct order, memoize values, and ensure UI styles are imported so the modal is usable.
