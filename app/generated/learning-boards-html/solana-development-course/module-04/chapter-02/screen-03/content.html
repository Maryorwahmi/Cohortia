Practice Steps

Each card below gives a short verification step so you can confirm competency during live coding.

Cluster Test

Connect to devnet and request test tokens from the faucet. Verify that balances and program deployments behave as expected.

Milestone: See SOL balance on devnet
Connection Instance

Create a Connection with clusterApiUrl and confirm you can fetch the slot or account info without errors.

Milestone: connection.getSlot() returns a number
Provider Wrapping

Wrap your app with ConnectionProvider and WalletProvider. Open the modal and ensure the wallet list appears.

Milestone: Wallet modal lists Phantom
useWallet Check

Use useWallet to read publicKey and display its base58 string after connecting a wallet in the browser.

Milestone: publicKey?.toBase58() visible
