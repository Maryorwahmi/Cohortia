Definition

What a cluster is

A cluster is an independent Solana network deployment with its own ledger. Choosing a cluster affects tokens, programs, and the safety of testing versus production.

Devnet
Best for iterative development; free faucets; isolated ledger state.
Testnet
Useful for broader compatibility and stress tests before production.
Mainnet-beta
Live network; real tokens; run final production deployments here.
Concrete Example

Switching endpoints

Use a helper like clusterApiUrl to get a standard RPC URL for a cluster. For devnet, this lets you run and test code against a sandboxed ledger without real funds.

Misconception

Devnet is not a copy of mainnet; program addresses and state are different. Do not rely on devnet data to represent production state exactly.

Key Takeaway

Select the cluster that fits your testing goals: devnet for iteration, testnet for stress, mainnet-beta for production.
