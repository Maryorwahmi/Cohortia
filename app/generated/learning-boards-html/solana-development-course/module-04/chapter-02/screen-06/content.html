Architecture

Hook or util pattern

Return the memoized endpoint and connection so all components consume the same instance. Swap endpoints for production easily.

Step 1: Compute endpoint from chosen network and memoize with useMemo.
Step 2: Create or derive a Connection instance and export it or return it from a hook.
Step 3: Use ConnectionProvider with the endpoint and let children access RPC methods.
Example
// Visual example only
const network = 'devnet';
const endpoint = useMemo(() => clusterApiUrl(network), [network]);
// Provide endpoint to ConnectionProvider at app root
Common Mistake

Creating connections in many nested components causes extra overhead and inconsistent behavior. Centralize creation.

Key Takeaway

Centralize connection logic so your app uses one stable RPC gateway and you can swap endpoints cleanly for production.
