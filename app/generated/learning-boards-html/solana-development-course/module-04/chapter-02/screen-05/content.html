Process

Initialize Connection

Use clusterApiUrl to obtain a standard RPC URL and pass it to the Connection constructor. Configure commitment when needed.

// Example (visual only)
const endpoint = clusterApiUrl('devnet');
const connection = new Connection(endpoint, 'confirmed');

// Use connection.getSlot(), connection.getAccountInfo(pubkey) to verify
Note: The code block is a read-only example to demonstrate the API pattern. Keep a single instance and reuse it across your app.
Supporting Points
  • Encapsulate connection logic in a hook or util to avoid duplication.
  • Choose commitment: 'confirmed' for speed, 'finalized' for stronger guarantees.
  • Test connectivity using simple queries such as getSlot().
  • Avoid creating many Connection objects in nested components.
Key Takeaway

Use clusterApiUrl and a single Connection instance configured with an appropriate commitment level and reuse it across your DApp.
