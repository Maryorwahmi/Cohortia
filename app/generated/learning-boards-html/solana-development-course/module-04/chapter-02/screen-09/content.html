Module 4 › Chapter 4.2 › useWallet Hook
Definition

What useWallet provides

  • publicKey: PublicKey object for the connected wallet or null.
  • connected: Boolean indicating connection state.
  • connect / disconnect: Functions to trigger connection or disconnect flows.
Pro Tip

Use optional chaining when reading publicKey to avoid null access: publicKey?.toBase58().

Example
WalletInfo component concept

Read connected and publicKey from useWallet. If connected, display publicKey?.toBase58(), otherwise prompt the user to connect.

Misconception

The hook does not bypass user approval. Signing still requires user confirmation in their wallet extension or device.

Key Takeaway

Use useWallet to render connection-aware UI, guard null publicKey, and avoid exposing sensitive data in logs.
