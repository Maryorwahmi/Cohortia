Common Issues to Watch

  • Missing CSS: require the adapter UI styles or the modal looks wrong or breaks.
  • No wallets array: WalletProvider needs adapters to show in the modal.
  • autoConnect: convenient but reconsider for user privacy and UX.
  • Production endpoints: clusterApiUrl is ok for development, but production apps should use robust RPC providers.
  • Logging secrets: do not print public keys or sensitive identifiers to public logs in production.
Quick Fix

If the modal does not appear, confirm the style import and the wallets array are present, then open the browser wallet and retry.

Key Takeaway

Confirm styles, provide adapters, and think through autoConnect and production endpoints before release.
