Module 4 › Chapter 4.2 › Wallet UI Comparison
WalletMultiButton

Pros

  • Pre-built connect UI and modal behaviors.
  • Works across adapters with consistent UX.
  • Low integration effort for beginners.
Custom UI

When to choose

  • You need bespoke styling or additional flows before connect.
  • You want to integrate non-modal experiences or multi-step onboarding.
  • Remember: still use useWallet to call connect and disconnect.
Key Takeaway

Start with WalletMultiButton for speed. Build custom controls only when UX or branding requires them, but rely on useWallet actions.
