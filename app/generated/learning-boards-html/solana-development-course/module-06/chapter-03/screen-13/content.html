Real-time NFT list

Subscribe to program-level account changes for the token or metadata program and filter callbacks to update a wallet's NFT list when mints or transfers occur.

Step 1: initial fetch of token accounts for connected wallet.
Step 2: set up onProgramAccountChange and filter updates by owner or mint.
Step 3: reconcile changes and refresh only affected items to remain efficient.
Error messaging checklist
  • Wallet locked or rejection → instruct user to unlock/approve.
  • Simulation errors → show likely causes such as insufficient funds.
  • Network errors → offer retry and check connection guidance.
Avoid subscribing to overly broad filters. Narrow the subscription and filter early to minimize client work.
Key Takeaway

Design subscriptions to be targeted and translate errors into actionable suggestions for users.
