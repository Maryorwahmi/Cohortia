useEffect subscription pattern

This code shows initial fetch, subscription callback, and cleanup in a React useEffect for FullCounterDApp.

// Inside FullCounterDApp.tsx useEffect
useEffect(() => {
  if (!wallet || !connection) {
    setCounterValue(null);
    setCounterAccountPublicKey(null);
    return;
  }

  const program = getProgram();
  if (!program) return;

  let listenerId = null;

  const setup = async () => {
    try {
      const [pda] = PublicKey.findProgramAddressSync(
        [Buffer.from("counter"), wallet.publicKey.toBuffer()],
        PROGRAM_ID
      );
      setCounterAccountPublicKey(pda);

      const counterAccount = await program.account.counter.fetch(pda);
      setCounterValue(counterAccount.count.toNumber());

      listenerId = connection.onAccountChange(
        pda,
        (accountInfo) => {
          try {
            const deserialized = program.coder.accounts.decode("Counter", accountInfo.data);
            setCounterValue(deserialized.count.toNumber());
          } catch (err) {
            console.error("Decode error:", err);
          }
        },
        'confirmed'
      );
    } catch (e) {
      console.error(e);
      setCounterValue(0);
    }
  };

  setup();

  return () => {
    if (listenerId !== null) connection.removeAccountChangeListener(listenerId);
  };
}, [wallet, connection, getProgram]);
Explanation
  • Guard for wallet and connection to avoid errors.
  • Perform an initial fetch to populate state before subscribing.
  • Deserialize accountInfo.data with program.coder.accounts.decode.
  • Always remove the listener on cleanup to prevent leaks.
Pro tip: log decode errors but avoid showing them to users; instead show a friendly fallback.
Key Takeaway

Use a combined fetch + subscription pattern and ensure cleanup to keep UI accurate and memory safe.
