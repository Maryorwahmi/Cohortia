handleIncrement pattern

const handleIncrement = async () => {
  setIsLoading(true);
  try {
    const txSignature = await program.methods.increment().accounts({ ... }).rpc();
    // Notify user transaction was sent
    const latestBlockHash = await connection.getLatestBlockhash();
    await connection.confirmTransaction({
      blockhash: latestBlockHash.blockhash,
      lastValidBlockHeight: latestBlockHash.lastValidBlockHeight,
      signature: txSignature,
    });
    // Notify user confirmed and refresh
    await fetchCounter();
  } catch (error) {
    console.error("Transaction failed:", error);
    if (error.message.includes("User rejected the request")) {
      alert("Transaction rejected by wallet.");
    } else if (error.message.includes("custom program error")) {
      alert(`Program error: ${error.message.split("custom program error: ")[1].split(" (")[0]}`);
    } else {
      alert(`Transaction failed: ${error.message || "Unknown error"}`);
    }
  } finally {
    setIsLoading(false);
  }
};
Explanation
  • Set isLoading and disable actions during the flow.
  • Send transaction, then explicitly confirm using the latest blockhash.
  • Catch known errors and present friendly, actionable messages.
Misconception: showing only the signature is sufficient. Instead, show progress and final confirmation to avoid user uncertainty.
Key Takeaway

Translate internal errors into short, helpful messages and keep users informed during confirmation.
