Definition

Transaction confirmation

Awaiting confirmation ensures the transaction is included in a block and reaches the chosen finality. Use the latest blockhash and confirmTransaction to avoid race conditions.

// Confirmation sequence (conceptual)
const txSignature = await program.methods.increment().rpc();
const latestBlockHash = await connection.getLatestBlockhash();
await connection.confirmTransaction({
  blockhash: latestBlockHash.blockhash,
  lastValidBlockHeight: latestBlockHash.lastValidBlockHeight,
  signature: txSignature,
});
// Update UI after confirmation
User feedback patterns
  • Show pending spinner and disable related buttons.
  • Display concise success notification on confirmation.
  • If failure occurs, show a friendly message and suggested fixes.
Misconception: returning a signature means success. Always confirm using the latest blockhash to ensure inclusion.
Key Takeaway

Present explicit pending and confirmed states, and use confirmTransaction to avoid showing premature success.
