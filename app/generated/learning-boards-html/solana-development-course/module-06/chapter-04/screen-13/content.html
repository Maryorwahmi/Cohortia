Module 6 › Chapter 6.4 › Key Concepts
Local Validator
Run a private Solana cluster for cost-free, deterministic testing.
Anchor Testing Framework
Write JavaScript/TypeScript unit and integration tests that deploy to the local validator.
Unit & Integration Tests
Unit tests focus on single instructions; integration tests verify multi-step interactions.
Takeaway
Adopt a layered test strategy: use the local validator for fast loops, write Anchor tests for program logic, and run focused E2E tests for user paths in CI.
