Module 6 › Chapter 6.4 › Testing Pitfalls
List of common mistakes
  • Skipping edge-case tests (zero, max values, empty inputs).
  • Not writing negative tests for unauthorized actions or invalid inputs.
  • Using shared devnet state instead of isolated local validator runs.
  • Trying to automate real wallet flows without mocks, producing brittle E2E tests.
Practical fix
Adopt a test-first habit: write a failing test for the bug you want to prevent, reproduce locally, then implement code changes and re-run tests to confirm the fix.
Mistake to avoid
Relying on manual testing only. Manual checks miss regressions and make releases risky.
Quick wins
  • Add a negative test for unauthorized signer behavior.
  • Include a simple E2E smoke test for the critical user path in CI.
