Example CI stages
  1. Install dependencies and build artifacts.
  2. Start solana-test-validator for the job, deploy program artifacts.
  3. Run Anchor unit and integration tests.
  4. Run a focused E2E smoke test or schedule heavy E2E nightly runs.
When possible, cache compiled artifacts to speed repeated runs. Collect test outputs and validator logs for failing runs so developers can reproduce locally.
Practical tip
Keep PR pipelines fast: run unit and integration tests on PRs, and gate releases with additional E2E checks or manual sign-offs as needed.
Security & reliability
Include tests that exercise access control and edge numeric cases in CI to prevent regressions that could be exploited or cause unexpected behavior on-chain.
Key Takeaway
Automate the validator and tests in CI. Use short PR checks and heavier scheduled tests so feedback stays fast and reliable.
