Module 6 › Chapter 6.5 › Key Management
Deployer Key
Used to deploy and, if allowed, to upgrade the on-chain program. Secure this key first.
Hardware Wallet / Vault
Prefer hardware devices or encrypted key vaults for any key that can modify program code or move funds.
Multi-sig Upgrade Authority
Reduce single-key risk by delegating upgrade authority to a multi-signature wallet.
Compromise Response
Rotate keys, emergency upgrade to remove upgrade authority or transfer to multi-sig, and notify users.
Practical Checklist
  • Never commit keypair files to Git.
  • Use CI secrets and ephemeral deploy keys for automation.
  • Prefer multi-sig for upgrade operations.
Common Mistake

Committing id.json to a repository exposes your deployer key and invites program hijacking.
