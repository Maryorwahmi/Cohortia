Definition

Integer Overflow & Safe Arithmetic

Protect numeric operations with checked arithmetic and explicit error handling.
Why it matters

A wrapped integer can turn a credit into a huge balance or make counters reset. Attackers and edge cases can exploit absent checks, so prefer checked arithmetic and return explicit errors.

Common Fix
let new = current.checked_add(amount).ok_or(ProgramError::Custom(0))?;
account.value = new;
account.serialize(&mut &mut acct.data.borrow_mut()[..])?;
Anchor & Safe Arithmetic

Anchor offers patterns and community crates to make checked math less noisy. When possible, centralize arithmetic checks in helper functions to keep instruction handlers readable.

Key Takeaway

Explicitly check arithmetic results and return clear errors to make failures diagnosable on-chain.

Concrete Code Example
// Example: safe increment
let mut data = Counter::try_from_slice(&acct.data.borrow())?;
let next = data.value.checked_add(1).ok_or(ProgramError::Custom(1))?;
data.value = next;
data.serialize(&mut &mut acct.data.borrow_mut()[..])?;
