Module 6 › Chapter 6.5 › Anchor Deploy
Deploy Steps
  1. Set provider.cluster and wallet path in Anchor.toml.
  2. Ensure deployer wallet has SOL. On devnet use airdrop for quick funds.
  3. Run anchor deploy --provider.cluster devnet to build and deploy.
  4. Copy the Program ID printed after deploy and update your client and Anchor.toml.
  5. Verify transactions on a public explorer and test end-to-end flows.
Key Takeaway

Always capture the Program ID from the deploy output and update your client before testing.

Terminal Demo (Example)
# Deploy to devnet
anchor deploy --provider.cluster devnet

# Deploy to mainnet-beta (requires real SOL)
anchor deploy --provider.cluster mainnet-beta

# Sample output will include a Program ID you must copy:
# Program Id: 4xY...YourNewProgramIdHere
Note: If deploy fails, inspect compilation errors, missing crates, or payer balance.
