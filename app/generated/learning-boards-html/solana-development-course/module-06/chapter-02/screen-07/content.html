Module 6 › Chapter 6.2 › Fetch & Display
Code (React pattern)
useEffect(() => {
  const fetchCounter = async () => {
    if (!wallet || !connection) return;
    const provider = new AnchorProvider(connection, wallet, AnchorProvider.defaultOptions());
    const program = new Program(idl as any, PROGRAM_ID, provider);
    const [pda] = PublicKey.findProgramAddressSync(
      [Buffer.from('counter'), wallet.publicKey.toBuffer()],
      PROGRAM_ID
    );
    try {
      const acc = await program.account.counter.fetch(pda);
      setCounterValue(acc.count.toNumber());
    } catch (e) {
      setCounterValue(null); // account may not be initialized
    }
  };
  fetchCounter();
}, [wallet, connection]);
UX considerations
  • Show a clear "Account not initialized" state and an Initialize action.
  • Provide a Refresh control that re-runs fetch on demand.
  • Guard BN conversions for display to avoid overflow.
Example
After incrementing, re-fetch returns a new BN value which you convert and show as an updated count.
