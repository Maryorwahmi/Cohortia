Concept: serialization & deserialization

Serialization turns a structured object into bytes for storage; deserialization reverses the process so your UI can use named fields. Anchor uses the program IDL and Rust struct definitions to automate this mapping.

Why it matters
Prevent data misinterpretation and maintain compatibility between client and program.
Common mistake
Using a mismatched layout between client and program causes wrong values when deserializing.
Concrete snippet
const counterAccount = await program.account.counter.fetch(pda);
// Anchor returns: { count: new BN(123) }
const display = counterAccount.count.toNumber();
If fetch fails because the account doesn't exist, handle that by showing an initialization action rather than crashing the UI.
