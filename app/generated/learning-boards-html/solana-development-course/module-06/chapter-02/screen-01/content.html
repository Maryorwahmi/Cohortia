Interactive 16:9 Masterclass

Manage on-chain program state from your DApp

Learn to fetch and deserialize Anchor accounts, convert BN values for display, send update instructions, and respect account ownership rules that protect data.

Duration: ~11 min demo
In this lesson
  • How accounts store program data and why clients deserialize bytes.
  • Using Anchor's program.account.fetch helpers.
  • Sending transactions to update mutable accounts and handling errors.
Why it matters

Correct client-side handling keeps your UI consistent with chain state and prevents dangerous race conditions or failed transactions.

Visual Concept
Accounts, client, and program
Account (bytes)
Raw byte array stored on-chain, owned by a program.
Client (serialize/deserialize)
Convert bytes to structured objects to display, then serialize to send updates.
Program (authority)
Only the owning program can modify its account data; clients request changes via instructions.
