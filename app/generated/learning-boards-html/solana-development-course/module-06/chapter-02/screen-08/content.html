Module 6 › Chapter 6.2 › Update Transaction
Step-by-step
  1. Build provider and Program instance.
  2. Prepare accounts object and instruction call.
  3. Send with .rpc() and await confirmation.
  4. Re-fetch the modified account to refresh the UI.
Example call
const txSig = await program.methods
  .increment()
  .accounts({
    counterAccount: pda,
    user: wallet.publicKey,
  })
  .rpc();
console.log('tx', txSig);
await fetchCounter();
