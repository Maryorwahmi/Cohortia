Module 6 › Chapter 6.2 › Implementation Tasks
Task checklist
  • Fetch PDA: derive with PublicKey.findProgramAddressSync and confirm it exists before rendering.
  • BN conversion: use BN.toNumber() only when values fit safely into JavaScript numbers.
  • Increment flow: call program.methods.increment().accounts(...).rpc() then await and re-fetch.
  • Initialize handling: gracefully show an Initialize action if the account returns an error on fetch.
Practical checks
After implementing fetch, verify the UI shows the current on-chain count for your wallet's PDA.
After increment, confirm the displayed number increases and no ownership errors appear in logs.
When an account is missing, ensure a clear message appears and initialization is possible.
