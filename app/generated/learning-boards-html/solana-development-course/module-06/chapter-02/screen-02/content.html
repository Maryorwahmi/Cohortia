VERIFIED COMPETENCY MILESTONE

  1. Implement fetch logic with Anchor and display BN-converted numbers.
  2. Wire transaction calls so UI re-fetches after success.
  3. Provide graceful UI state for uninitialized accounts.
  4. Validate account ownership expectations during testing.
