Module 6 › Chapter 6.2 › Anchor Fetch
Example fetch flow (editor)
const provider = new AnchorProvider(connection, wallet, AnchorProvider.defaultOptions());
const program = new Program(idl as any, PROGRAM_ID, provider);
const [pda] = PublicKey.findProgramAddressSync(
  [Buffer.from("counter"), wallet.publicKey.toBuffer()],
  PROGRAM_ID
);
const counter = await program.account.counter.fetch(pda);
// counter.count is a BN
const displayCount = counter.count.toNumber();
This read-only fetch needs no signature. If the account is absent, fetch throws an error; handle it to enable initialization flows.
Tips & pitfalls
  • Keep IDL and on-chain layout in sync with your client types.
  • Avoid converting large BN values to numbers — display safely or use string formatting.
  • Re-fetch after writes to keep UI consistent with the chain.
Common mistake
Treating BN as native number leads to precision loss. Prefer BN.toString() or conditional toNumber() for small values.
