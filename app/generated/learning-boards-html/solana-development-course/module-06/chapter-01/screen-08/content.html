Invoking an instruction with Anchor methods

A single Anchor call performs data serialization, accounts wiring, wallet signing, and submission.

Full interaction example (conceptual)
// Derive PDA (example)
const [counterAccount] = PublicKey.findProgramAddressSync(
  [Buffer.from('counter'), wallet.publicKey.toBuffer()],
  PROGRAM_ID
);

// Call the instruction
const tx = await program.methods
  .increment()
  .accounts({ counterAccount, user: wallet.publicKey })
  .rpc();

console.log('Transaction signature', tx);
Checks
  • Are all required accounts present?
  • Do account owners and flags match the IDL?
  • Is the wallet connected and able to sign?
Key Takeaway
The single method call is convenient, but correctness depends on accurate accounts, the right IDL, and a valid Program ID.
