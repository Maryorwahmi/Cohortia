Core Concept

Program ID — the program's immutable address

The unique public key that identifies the deployed program on a cluster.

Definition
Program ID = program's public key (immutable address)
Concrete example
// Example: using a Program ID in code
const programID = new PublicKey("YOUR_PROGRAM_ID_HERE");
const program = new Program(idl as any, programID, provider);
Common misconception
  • Thinking the IDL alone routes calls. The IDL describes interface; only the Program ID routes them to the on‑chain address.
  • Assuming redeploy keeps same address. Redeploying often produces a new Program ID unless you manage a fixed address.
Scenario
Devnet counter
If your counter program is at address A, your DApp must use address A exactly to call increment. Using a different address targets the wrong program or fails.
Key Takeaway
Treat the Program ID as immutable config. Store and update it when you redeploy to avoid broken integrations.
Pitfall
Using an outdated Program ID leads to silent routing errors or transaction rejections; always confirm the address after deployment.
