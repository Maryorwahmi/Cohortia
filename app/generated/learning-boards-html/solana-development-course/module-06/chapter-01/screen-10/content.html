Common pitfalls and how to diagnose them

Symptoms and fixes for the most frequent integration errors.

Wrong Program ID
Symptom: transaction targets wrong program or fails. Fix: update the Program ID constant to the deployed address.
Stale IDL
Symptom: method signatures or account lists don't match. Fix: rebuild program, copy new idl.json to frontend.
Incorrect accounts
Symptom: runtime rejects transaction. Fix: consult IDL/Rust code, correct PDA seeds and writable/signer flags.
Debug checklist
  1. Confirm deployed Program ID equals client config.
  2. Regenerate and replace idl.json after program changes.
  3. Log derived PDAs and compare owners and mutability.
  4. Use transaction simulation logs to inspect failing assertions.
