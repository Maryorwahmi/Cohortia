Hands‑On Activity

Connect your React DApp to a deployed counter

Follow these steps in your project to invoke increment() on devnet.

Step checklist
  1. Copy idl.json into src/
  2. Set PROGRAM_ID to deployed address
  3. Initialize provider and Program object
  4. Derive counter PDA with seeds used by the program
  5. Call program.methods.increment().accounts({...}).rpc()
  6. Show transaction signature and confirm
Starter code hint
const program = getProgram();
if (!program) { /* prompt connect wallet */ }

const [counterAccount] = PublicKey.findProgramAddressSync(
  [Buffer.from('counter'), wallet.publicKey.toBuffer()],
  PROGRAM_ID
);

const tx = await program.methods.increment().accounts({ counterAccount, user: wallet.publicKey }).rpc();
