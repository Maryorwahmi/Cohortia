Assessment Idea

What to update after redeploying a program

Explain and perform the two critical client updates after a redeploy.

Update 1: Program ID
If the program address changed during redeploy, update the Program ID used by your client so it targets the correct on‑chain code.
Update 2: idl.json
If instruction signatures or account structures changed, regenerate idl.json and copy the updated file into your frontend project.
Demonstration task
Change one constant, replace idl.json, rebuild client, and call increment() to show the system works; document errors before fixes and success after.
