Summary

Key Concepts

A quick reference of the most important terms and actions.

Program ID
Immutable public key address of your deployed program.
IDL
JSON description of instructions, args, and account requirements.
Anchor Client
Type-safe methods generated from the IDL to call program instructions.
Takeaway

Combine the Program ID and IDL inside an Anchor Program object, derive the expected accounts, let the wallet sign, and use rpc() to send and monitor transactions.
