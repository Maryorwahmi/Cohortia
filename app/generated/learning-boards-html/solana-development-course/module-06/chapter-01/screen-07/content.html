Deriving Program Accounts (PDAs) and supplying accounts

Compute or fetch the exact public keys required by instructions and verify their permissions.

Example PDA derivation
const [counterPubkey] = PublicKey.findProgramAddressSync(
  [Buffer.from('counter'), wallet.publicKey.toBuffer()],
  programID
);
This deterministic address is computed with the same program ID and seeds as the program expects.
Supplying accounts
Use the derived keys in the accounts object when calling methods, for example accounts: { counterAccount: counterPubkey, user: wallet.publicKey }.
Debug tip
Log derived PDAs and compare to addresses your program expects; a mismatch is a fast indicator of incorrect seeds or Program ID.
Pitfall
Passing an account that is not writable when the program expects it to be writable causes an immediate runtime rejection before your program logic runs.
