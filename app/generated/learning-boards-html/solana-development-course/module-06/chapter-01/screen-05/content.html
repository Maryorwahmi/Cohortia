Definition

Interface Definition Language (IDL)

A JSON contract describing instructions, arguments, and accounts for a program.

IDL excerpt (conceptual)
{
  "name": "counter",
  "instructions": [
    { "name": "increment", "accounts": ["counterAccount","user"], "args": [] }
  ]
}
Anchor generates idl.json during build. The client uses this to expose methods and validate account shapes.
Concrete example
When calling increment(), pass an accounts object that supplies counterAccount and user. The IDL indicates which accounts are required and their expected properties.
Pro Tip
Keep a single source of idl.json in your repo and update it after every program change to avoid mismatches between client and program.
Misconception
The IDL does not route calls or sign transactions; it only describes the interface. You still need the correct Program ID and provider for execution.
