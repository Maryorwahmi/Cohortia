Core Concept

Transaction signing and the user's wallet

Wallets sign transactions so users retain custody and authorize all actions.

What happens on rpc()
  1. Anchor builds the transaction using IDL and accounts.
  2. The provider requests the connected wallet to sign.
  3. Upon signing, the transaction is sent to the cluster.
  4. rpc() returns a signature for monitoring confirmation.
Developer checklist
Handle user rejects, show fee info when available, catch network errors, and log or display the transaction signature for follow up.
Concrete example
After tx = await program.methods.increment().accounts({...}).rpc(); display tx to the user and poll for confirmation using connection.getConfirmedTransaction(tx) or similar utilities.
