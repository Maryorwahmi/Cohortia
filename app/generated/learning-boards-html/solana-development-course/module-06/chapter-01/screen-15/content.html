Three concise reminders to guide integration work.

Program object
Holds IDL and Program ID bound to a provider for method calls.
Correct accounts

Signed submission
rpc() requests wallet signature then returns a signature to monitor confirmations.
One sentence takeaway

A correct Program ID, an up‑to‑date IDL, and accurate account wiring with wallet signing are the essentials for a working client integration.
