Integrating Frontend with On‑Chain Programs

Learn how your React DApp uses a Program ID and IDL to create an Anchor Program client, invoke instructions, and sign transactions via a connected wallet.

Program ID
Immutable public key that locates your program on the cluster.
IDL — JSON contract describing instructions and accounts.
Wallet — signs transactions so users keep custody of keys.
In this lesson we’ll cover: initializing a Program object from an IDL and Program ID, deriving account public keys such as PDAs, invoking an instruction with the correct accounts, and using the wallet to sign and send the transaction. You will also see common mistakes and a short hands‑on activity outline.
