Module 2 › Chapter 1.3 › Keypairs and Wallets
Definition
Keypair
A keypair contains a public key used to receive funds and a private key used to sign transactions and prove ownership.
Security note
Never share your private key or id.json file. If lost or exposed, wallet access is lost or compromised.
Passphrase
You can add an optional passphrase during key generation to encrypt the key file for extra security.
Concrete example
Generate a new keypair and print the public key. The CLI will prompt for an optional passphrase and will show a seed phrase you must save offline.
solana-keygen new
# Example to write a separate file:
solana-keygen new --outfile ~/.config/solana/my_first_keypair.json

# Get the public key for that file:
solana-keygen pubkey ~/.config/solana/my_first_keypair.json
Use the pubkey command to copy your wallet address safely. Only the public key is safe to post or use for receiving tokens.
