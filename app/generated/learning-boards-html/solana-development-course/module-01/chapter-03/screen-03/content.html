Verification
Restart or source your shell profile so Cargo and Solana binaries are available. Use rustc --version, cargo --version, and solana --version to confirm installs. Missing versions usually indicate PATH issues.
Check versions
Confirm each tool reports a version string before proceeding to key generation or airdrops.
Balance check
Use solana balance to verify airdrops and ensure you can submit transactions.
Safety & best practice
Treat seed phrases and id.json files as highly sensitive. Maintain separate keypairs for experiments and production, and use offline backups to reduce the risk of loss or compromise.
Mistake to avoid
Do not post id.json files publicly; anyone with that file can control the wallet.
Pro tip
Use --outfile to create named keypairs and keep the default id.json untouched for recovery strategies.
