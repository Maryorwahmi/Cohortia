Module 2 › Chapter 1.3 › Create a keypair and use an outfile
Code walkthrough
Create a named keypair, request airdrop for that key, and check balance specifying the same keypair file so actions affect the intended wallet.
solana-keygen new --outfile ~/.config/solana/my_first_keypair.json

# Get the public address for the file you created
solana-keygen pubkey ~/.config/solana/my_first_keypair.json

# Request 2 test SOL to that address
solana airdrop 2  --keypair ~/.config/solana/my_first_keypair.json

# Check balance using the same keypair
solana balance --keypair ~/.config/solana/my_first_keypair.json
Notes & pitfalls
  • If you omit --keypair, the CLI may use your default id.json.
  • Always copy the public key output when requesting an airdrop to avoid errors.
  • Keep seed phrases for named keypairs backed up separately.
Key Takeaway

Named keypairs let you isolate test wallets and avoid overwriting your default identity.
