Module 2 › Chapter 1.3 › Devnet vs Testnet vs Mainnet-beta
Cluster comparison
Devnet
A developer playground with faucets for test SOL. Use this for everyday development and quick iteration.
Testnet
A larger, closer-to-production test environment used for system-wide testing before mainnet deployment.
Mainnet-beta
The live production network where real assets exist. Only use when you intend to interact with actual funds.
Concrete commands
Set and verify the active cluster using the following commands. Always confirm your cluster before performing operations that move tokens.
solana config set --url devnet
solana config get

# Example: request test SOL only works on Devnet
solana airdrop 2 

# Check balance
solana balance
If solana config get shows mainnet-beta, switch to devnet before requesting airdrops or testing to avoid real fund operations.
