Module 2 › Chapter 1.3 › Verify installation and configuration
Verification commands
rustc --version
cargo --version
solana --version

# Inspect CLI configuration
solana config get
If the config shows a URL other than devnet, set the cluster explicitly and re-check the configuration before requesting airdrops or deploying code.
Troubleshooting
  • Restart or source your shell profile if binaries are not found.
  • Confirm the installer added the expected path to your shell profile.
  • Reference named keypairs with --keypair to avoid accidental use of id.json.
Key Takeaway

Verification commands reduce errors and protect you from accidental mainnet interactions.
