Module 2 › Chapter 1.3 › Learning Objectives
01
Install Rust & Cargo

Install the Rust toolchain using rustup, then verify with rustc --version and cargo --version to confirm the compiler and package manager are available.

VERIFIED COMPETENCY MILESTONE
02
Install Solana CLI

Run the Solana installer, add the install path to your shell profile, and confirm with solana --version so CLI commands work from your terminal.

VERIFIED COMPETENCY MILESTONE
03
Generate a Keypair

Create a new wallet with solana-keygen new, securely record the seed phrase, and understand which key is public versus private.

VERIFIED COMPETENCY MILESTONE
04
Connect to Devnet & Airdrop

Set the CLI to Devnet, request test SOL with airdrop, and verify your balance so you can safely run transactions without mainnet funds.

VERIFIED COMPETENCY MILESTONE
05
Manage Keypairs

Learn to create separate keypairs with --outfile and retrieve a public key with solana-keygen pubkey to manage multiple wallets safely.

VERIFIED COMPETENCY MILESTONE
06
Verify Install & PATH

Confirm binaries are on your PATH and verify versions. Restart your shell or source your profile so commands resolve to the installed tools.

VERIFIED COMPETENCY MILESTONE
07
Security Best Practices

Understand the consequences of sharing id.json or seed phrases and adopt secure backups like encrypted stores or offline copies to protect access.

VERIFIED COMPETENCY MILESTONE
