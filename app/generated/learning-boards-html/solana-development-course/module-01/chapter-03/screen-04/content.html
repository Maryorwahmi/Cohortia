Module 2 › Chapter 1.3 › Rust and Cargo — the Solana toolchain
Definition
Rust and Cargo
Rust is the language used to author Solana programs. Cargo builds and manages dependencies so your code compiles predictably across environments.
Why Cargo matters
Cargo runs builds, downloads crates, and produces reproducible artifacts used during program deployment.
Common mistake
Skipping a version check after install can leave you working with a missing or misconfigured toolchain.
Key Takeaway

Install Rust with rustup and verify rustc and cargo so your compiler and package manager are both available.

Concrete example
Run the rustup installer and then check versions. The following is the installer command and typical verification commands you will use in the terminal.
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# After install, restart the terminal or run:
source $HOME/.cargo/env

rustc --version
cargo --version
If version commands fail, check that the installer added the cargo env line to your profile and then restart your terminal. That resolves most PATH issues.
