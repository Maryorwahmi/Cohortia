Module 2 › Chapter 1.3 › Install the Solana CLI
Installer
Run the stable installer to download the official CLI. The installer will place executables into a local directory and suggest adding that directory to your PATH.
sh -c "$(curl -sSfL https://release.solana.com/stable/install)"

# After install, restart the terminal and verify:
solana --version
If solana --version fails, confirm the install path (typically ~/.local/share/solana/install/active_release/bin) is added to your shell profile and restart your terminal.
Checklist
  • Run the installer with the stable tag.
  • Restart or source your shell profile to update PATH.
  • Verify with solana --version.
Common mistake
Not restarting the shell after install. Always restart or source the profile immediately after installation.
Key Takeaway

The CLI must be discoverable on your PATH and verified with a version check before interacting with clusters.
