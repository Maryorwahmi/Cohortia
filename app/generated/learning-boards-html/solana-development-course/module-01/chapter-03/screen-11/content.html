Module 2 › Chapter 1.3 › Activity: Complete your Solana CLI setup
Step-by-step
  1. Install Rust: run the rustup installer and verify versions.
  2. Install Solana CLI: run the stable installer and verify solana --version.
  3. Create a keypair using --outfile and save the seed phrase offline.
  4. Set cluster to Devnet: solana config set --url devnet and verify config get.
  5. Request 2 SOL with solana airdrop and confirm with solana balance.
Terminal starter
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
sh -c "$(curl -sSfL https://release.solana.com/stable/install)"
solana-keygen new --outfile ~/.config/solana/my_first_keypair.json
solana config set --url devnet
solana-keygen pubkey ~/.config/solana/my_first_keypair.json
solana airdrop 2  --keypair ~/.config/solana/my_first_keypair.json
solana balance --keypair ~/.config/solana/my_first_keypair.json
If you see 2 SOL, your environment is ready. If not, re-run the verification commands and check PATH and keypair references.
