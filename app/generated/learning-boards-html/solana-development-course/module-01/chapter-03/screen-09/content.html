Module 2 › Chapter 1.3 › Requesting test SOL with airdrop
Steps
  1. Get the wallet address using solana address or solana-keygen pubkey.
  2. Request test SOL with solana airdrop 2 <YOUR_PUBLIC_KEY>.
  3. Confirm with solana balance <YOUR_PUBLIC_KEY> or with --keypair.
Common issue
Airdrops only work on Devnet. Verify your cluster before requesting tokens.
Terminal example
# Show current address (default keypair)
solana address

# Request 2 test SOL to a specific address
solana airdrop 2 7i1f...j9z

# Or specify a keypair file
solana airdrop 2 7i1f...j9z --keypair ~/.config/solana/my_first_keypair.json

# Check balance
solana balance --keypair ~/.config/solana/my_first_keypair.json
Key Takeaway

Follow the get-address → airdrop → balance check sequence and confirm your CLI is set to Devnet.
