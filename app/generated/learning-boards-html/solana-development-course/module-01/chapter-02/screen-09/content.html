Module 1 › Chapter 1.2 › Pipelining & Storage
Pipelining
Stages optimize verification, signature checks, and ledger writes to reduce stalls.
By streaming work through specialized stages, pipelining minimizes wasted CPU cycles and IO delays, improving throughput for validator nodes.
Example: Signature verification runs as an early stage so later stages receive already-validated transactions ready for execution.
Cloudbreak & Archivers
Cloudbreak enables scalable account access; Archivers offload historical ledger data.
Cloudbreak supports concurrent reads and writes across many accounts so Sealevel can execute parallel transactions. Archivers let validators avoid storing the entire ledger locally by distributing older data to archival nodes.
Example: Older ledger segments are stored by Archivers, freeing validators to focus on current processing and maintaining performance.
Key Takeaway

Compute, state access, and storage must scale together. Pipelining, Cloudbreak, and Archivers form a coordinated stack that prevents new bottlenecks as TPS increases.
