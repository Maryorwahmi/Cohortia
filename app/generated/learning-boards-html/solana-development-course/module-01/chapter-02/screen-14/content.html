Module 1 › Chapter 1.2 › Key Concepts
Blockchain Trilemma
The challenge of achieving decentralization, security, and scalability at once.
Proof of History (PoH)
A verifiable hash sequence acting as a cryptographic clock for event ordering.
Tower BFT
A PoH-aware consensus protocol that reaches agreement faster by using the PoH clock.
Summary: Trilemma motivates design, PoH orders events, and Tower BFT uses that order to speed agreement.
