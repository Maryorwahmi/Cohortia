Module 1 › Chapter 1.2 › Key Concepts
Sealevel
Parallel runtime that executes non-overlapping transactions concurrently.
Gulf Stream
Mempool-less forwarding protocol that pushes transactions to validators early.
Pipelining / Cloudbreak / Archivers
System optimizations for staged processing, scalable account access, and distributed ledger storage.
Final takeaway: PoH provides order; Sealevel executes in parallel; Gulf Stream and system components keep processing smooth so high throughput and low fees are achievable.
