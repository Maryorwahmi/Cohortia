Assessment prompt 2
Which benefit does decentralization primarily provide over a centralized database? Explain why, and correct the misconception that decentralization equals anonymity.
Tip: write brief answers and then run the Python demo to confirm the technical mechanism described in prompt 1.
Common misconceptions
  • Decentralization means anonymity — false. Many chains are transparent and pseudonymous, not anonymous.
  • Immutability is absolute legal immunity — false. Immutability is technical; legal action or governance can still affect how records are interpreted.
  • All distributed ledgers are blockchains — false. Blockchains specifically use cryptographic linking and consensus to create a tamper-evident history.
Key Takeaway

Answer assessments by referencing the technical mechanisms—hashes, links, node verification—and avoid common confusions about anonymity and immutability.
