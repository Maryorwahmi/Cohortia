Run-time example
After upgrade, the first invoke should log a migration notice, and subsequent invokes only update value and timestamp.
Best practice
Include migration paths in your deserialization logic so any caller will bring old accounts forward safely.
Common mistake
Neglecting to test migration on many existing account shapes; do not assume one successful migration proves compatibility for all.
