Module 5 › Chapter 5.3 › Upgrade Authority
Role of the upgrade authority
Only this keypair or multisig can sign the upgrade instruction that replaces program bytes in the program data account.
Best practice
  • Use multisig governance for production programs.
  • Keep key backups in secure, audited storage.
  • Set authority to None if you want permanent immutability once stable.
Risk
If the authority is lost, you can no longer upgrade. If it’s stolen, attackers can perform malicious upgrades. Multisig reduces both risks.
Practical tip: use a known multisig provider and rehearse upgrade signing workflows on a testnet to ensure readiness.
