Lab: Deploy & Upgrade
A repeatable checklist to practice the full upgrade cycle on a testnet.
Phase 1
Compile v1, deploy, create counter account, invoke multiple times, confirm version=1 and value increments.
Phase 2
Modify code to add timestamp, bump version, compile v2, write-buffer, then upgrade using the authority keypair.
Phase 3
Invoke after upgrade, observe migration log on first call, then check timestamp updates on subsequent calls.
Verification
Fetch account data and deserialize to confirm version=2 and presence of timestamp field with updated value.
Work on devnet first, and ensure the upgrade authority is secured by multisig in any real deployment.
