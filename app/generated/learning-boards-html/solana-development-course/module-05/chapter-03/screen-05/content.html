Module 5 › Chapter 5.3 › Loader Comparison
Original BPF Loader
Deploys immutable programs. Use when you want a fixed, auditable contract that cannot be changed.
Pros
  • Maximal trust and reproducible bytecode guarantees.
  • Removes upgrade-related attack surface.
Cons
  • Any bug or feature requires deploying a new program and migrating users.
BPF Loader Upgradeable
Keeps program ID stable while storing executable bytes in a program data account that the loader owns and can replace.
Pros
  • Enables in-place upgrades without changing user-facing program ID.
  • Supports operational patching and iterative development on mainnet when controlled.
Cons
  • Requires secure management of upgrade authority and migration logic for data changes.
