Deploy Process (high level)
The CLI performs buffer upload, finalize, and authority assignment steps in sequence.
Step 1
Upload buffer
CLI writes bytes to a temporary buffer account owned by the loader.
Step 2
Finalize
Buffer becomes a program data account and a stable program ID is associated.
Step 3
Set authority
Deploying wallet becomes upgrade authority unless changed.
CLI example
solana program deploy ./dist/counter_v1.so
# returns Program Id and Program Data Address; save them
Tip: always save the program data address in addition to the program ID for audits and ownership checks.
