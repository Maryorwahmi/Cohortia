Module 5 › Chapter 5.3 › Program Identity
Component architecture
Program ID (stable) ← derived PDA relationship → Program Data Account (executable bytes owned by loader).
Program ID
Public key users interact with; address remains constant across upgrades.
Program Data Account
Holds bytecode. Owned by the loader so the loader can change the bytes when authorized.
Buffer Account
Temporary storage for new bytecode during upgrade preparation.
Concrete note
When you deploy with the CLI, expect to receive a program ID and program data address. Save both; the latter is useful for auditing and understanding ownership.
Misconception check
Do not assume program-owned accounts can change the program data. The loader manages program data ownership and must perform upgrades.
