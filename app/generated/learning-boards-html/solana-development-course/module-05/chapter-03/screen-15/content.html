Module 5 › Chapter 5.3 › Key Concepts
Program Upgradability
Updating executable bytes while keeping the same public program ID.
BPF Loader Upgradeable
The system program that manages upgradable program deployments and program data ownership.
Program Data Account
Account owned by the loader that stores the executable bytecode for an upgradeable program.
Takeaway

Remember ownership: program data is owned by the loader; program ID is the stable interface. Use this to reason about upgrades and authority.
