Bloom's mini-bar
Learn → Understand → Apply → Master
Learn
Define the difference between the BPF Loader and BPF Loader Upgradeable and why upgradability exists.
Understand
Map program ID, program data account, buffer, and upgrade authority into a working mental model.
Apply
Execute deploy and upgrade commands on a devnet, check returned addresses, and run test invocations.
Master
Design and test a migration path for existing accounts, and set a secure upgrade authority or remove it if immutability is desired.
Each stage includes a short practice: run CLI commands, examine program data addresses, and implement conditional deserialization in code.
