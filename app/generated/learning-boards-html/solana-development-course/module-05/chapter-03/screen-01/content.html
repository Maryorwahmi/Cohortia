Concept Map
Program ID (stable)
Public key users call; stays the same across upgrades.
Program Data Account
Holds executable bytes; owned by BPF Loader Upgradeable.
Buffer Account
Temporary store for new bytecode during an upgrade.
These pieces let you patch code without changing program identity, reducing user migration risk.
