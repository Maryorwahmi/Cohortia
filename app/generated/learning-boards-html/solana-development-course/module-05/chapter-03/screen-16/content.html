Module 5 › Chapter 5.3 › Practical Patterns
Buffer Account
Temporary holder for new bytecode; create a fresh buffer per upgrade and note its address.
Upgrade Authority
Signer allowed to execute upgrades. Prefer multisig or remove authority for immutability.
Version Field
Embed a version in account data and handle older versions during deserialization for safe migration.
Bottom line

Treat upgrades as an operational procedure: secure authority, use fresh buffers, embed migrations, test, and audit.
