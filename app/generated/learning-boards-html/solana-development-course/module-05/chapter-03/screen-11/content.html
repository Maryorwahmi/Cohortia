Terminal: deploy & test sequence
Commands you will run in the lab and what each returns.
cargo build-bpf --manifest-path=./Cargo.toml --bpf-out-dir=./dist
solana program deploy ./dist/counter_v1.so
# save: Program Id and Program Data Address
solana create-account <COUNTER_ACCOUNT_KEYPAIR.JSON> 8285 --program-id <YOUR_PROGRAM_ID>
solana program invoke <YOUR_PROGRAM_ID> <COUNTER_ACCOUNT_KEYPAIR.JSON> --keypair <YOUR_WALLET_KEYPAIR.JSON>
solana account <COUNTER_ACCOUNT_PUBKEY> -o
Expected logs
On first invoke: initialization log and version set to 1. Subsequent invokes: increment logs showing updated counter value.
Pitfall
Allocating insufficient account space will cause deserialization and write failures. Use the correct byte size estimate for your struct plus overhead.
