Module 5 › Chapter 5.3 › Upgrade Process
Upgrade workflow
Prepare a buffer, then upgrade the program data account using the upgrade authority.
Step A
Compile
Build your updated Rust program to produce a new .so file ready for upload.
Step B
Write buffer
Use solana program write-buffer to upload bytes to a new buffer account and note its address.
Step C
Upgrade
Call solana program upgrade with the program ID, buffer, final flag, and upgrade authority keypair.
Safety
Use multisig authorities and test upgrades on devnet before mainnet to catch migration issues.
CLI commands
solana program write-buffer ./dist/counter_v2.so --keypair <YOUR_WALLET_KEYPAIR.JSON>
solana program upgrade <PROGRAM_ID> <BUFFER_ADDRESS_OR_KEYPAIR> --final --keypair <UPGRADE_AUTHORITY_KEYPAIR.JSON>
