Testing and common pitfalls
Reduce risk with rehearsals, audits, and embedded migration logic.
Test
Run the full deploy and upgrade on devnet and validate all account migrations and invariants.
Audit
Security reviews are required for upgrades that change core logic or permission checks.
Document
Record program IDs, program data addresses, and buffer addresses used for each release.
Avoid
Do not change account layouts without a migration plan. Do not rely on single-key upgrade authorities in production. Do not skip testnet trials.
