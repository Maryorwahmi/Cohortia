use borsh::{BorshDeserialize, BorshSerialize};

#[derive(BorshSerialize, BorshDeserialize, Debug)]
pub struct CounterAccount {
  pub value: u32,
  pub version: u8, // Version field
}

// process_instruction: deserialize, init on version 0, increment value, serialize back
Example action
Create a counter account with enough space, call the program multiple times to increment, then fetch and deserialize to confirm version is 1 and value increments.
Did you know?
Even simple structs benefit from an explicit version field. It makes future migrations explicit and easier to test.
Pitfall
Changing field order or sizes without migration causes deserialization errors and program crashes.
