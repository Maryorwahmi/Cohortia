Learning Objectives
A clear set of measurable skills to practice during the lab and demo.
Explain Upgradability
Define why upgradable programs exist and contrast them with immutable deployments. This helps you choose the right trust model for your use case.
VERIFIED COMPETENCY MILESTONE
Identify Key Accounts
Differentiate program ID, program data account, and buffer account and explain how they interact during deployment and upgrade.
VERIFIED COMPETENCY MILESTONE
Run Deploy & Upgrade
Execute solana program deploy, write-buffer, and upgrade commands and interpret returned addresses for program ID, program data, and buffer.
VERIFIED COMPETENCY MILESTONE
Design Safe Migrations
Implement a version field and conditional deserialization logic so older account data remains usable after upgrades.
VERIFIED COMPETENCY MILESTONE
