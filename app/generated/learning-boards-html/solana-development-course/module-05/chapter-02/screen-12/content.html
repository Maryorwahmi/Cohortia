Integration steps
  1. Define the error enum and numeric discriminants.
  2. Implement From for ProgramError.
  3. Implement PrintProgramError to print descriptive messages.
  4. Place msg! around critical state changes for traces.
End-to-end example
Send a transaction that triggers InsufficientFunds, then run solana logs to confirm you see msg! traces and the printed error string. Verify the ProgramError::Custom numeric code matches your enum discriminant.
