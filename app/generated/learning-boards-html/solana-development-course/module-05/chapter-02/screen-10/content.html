Process Flow › solana logs
Typical CLI usage
$ solana logs <TRANSACTION_SIGNATURE>
// Streams msg! output and any PrintProgramError messages
Collect the signature from your transaction and run the command to see a chronological log of what the runtime printed during execution.
Interpreting logs
  • • msg! entries show variable values and progress markers.
  • • PrintProgramError lines reveal the descriptive error for a failed variant.
  • • The numeric ProgramError::Custom code is visible in the transaction metadata — correlate it with your documented discriminants.
Example
Run a failed transaction, copy its signature, then run solana logs to see why it failed.
