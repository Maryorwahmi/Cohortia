Process Flow › Enum → ProgramError
Pattern
// Check a condition and return a custom error
if balance < required_amount {
  return Err(EscrowError::InsufficientFunds.into());
}
This uses the From implementation so the enum variant becomes ProgramError::Custom(code) automatically at the call site.
Why numeric codes matter
  • • On-chain returns carry only the numeric payload; clients parse that value.
  • • Stable codes let frontends map code→message reliably across deployments.
  • • Place .into() returns at the logical failure point for clarity.
Misconception
Don't assume human messages are part of the error payload; make PrintProgramError print them to logs instead.
