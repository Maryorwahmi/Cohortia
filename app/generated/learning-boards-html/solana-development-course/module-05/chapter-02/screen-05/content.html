Definition › Define custom error enums
Rust enum example
use solana_program::{program_error::ProgramError};
use thiserror::Error; // crate for error messages

#[derive(Clone, Debug, PartialEq, Error)]
pub enum EscrowError {
  #[error("Invalid instruction data provided.")]
  #[num_enum(error = 0)]
  InvalidInstruction,

  #[error("Account is not initialized.")]
  #[num_enum(error = 1)]
  UninitializedAccount,

  #[error("Insufficient funds in the source account.")]
  #[num_enum(error = 3)]
  InsufficientFunds,
  // ... other variants
}

impl From for ProgramError {
  fn from(e: EscrowError) -> Self { ProgramError::Custom(e as u32) }
}
Explanation
  • • thiserror attaches readable messages used when printing logs.
  • • num_enum assigns the numeric discriminant that becomes ProgramError::Custom(u32).
  • • From impl converts enum into ProgramError for ProgramResult returns.
Pro tip
Document numeric codes so frontends map them reliably. Reserve ranges if you expect many errors.
