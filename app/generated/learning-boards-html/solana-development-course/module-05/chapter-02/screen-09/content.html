Definition › msg! logging
Common msg! patterns
msg!("Instruction: {}", instruction_tag);
msg!("Account key: {:?}", account_info.key);
msg!("Amount: {}", amount);
These entries appear in transaction logs and are useful for tracing the exact path your program took during execution.
Best practices
  • • Log inputs and key state transitions during development.
  • • Avoid logging secrets or large blobs; keep entries concise.
  • • Consider toggling verbose logs only in test/dev environments.
Pitfall
Excessive logging can increase compute usage and risks reaching transaction log limits.
