Comparison › Common mistakes
Generic errors
Consequence: poor UX and long debugging cycles. Mitigation: define specific variants for each meaningful failure.
Missing checks
Consequence: unexpected behavior or vulnerabilities. Mitigation: assert ownership, signer and writability explicitly and return clear errors.
Over-logging
Consequence: higher compute cost and log limits. Mitigation: restrict msg! to development or behind flags.
Inconsistent codes
Consequence: client-side parsing failures. Mitigation: document and reserve code ranges for growth.
Leaking sensitive data
Consequence: privacy/security risk. Mitigation: never log secrets or private keys in msg! output.
Relying on logs as state
Consequence: incorrect assumptions about permanence. Mitigation: treat logs as ephemeral diagnostics only.
