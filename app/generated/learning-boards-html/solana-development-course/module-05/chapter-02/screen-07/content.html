impl PrintProgramError for EscrowError {
  fn print(&self)
  where R: solana_program::log::Log {
    match self {
      EscrowError::InsufficientFunds => R::sol_log("Error: Insufficient funds in the source account."),
      EscrowError::Unauthorized => R::sol_log("Error: Unauthorized access to the account."),
      // ... other variants
    }
  }
}
Notes
  • • Printed messages appear in transaction logs and help trace failures.
  • • Keep messages concise and non-sensitive for public logs.
  • • Pair PrintProgramError with numeric codes for client parsing and human-readable debugging.
Key Takeaway
PrintProgramError bridges the gap between numeric on-chain codes and developer-friendly diagnostics.
