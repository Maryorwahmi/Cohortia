Module 6 › Chapter 5.5 › Lab Objectives
Lab step checklist
  • Confirm counter account owner equals program_id; return IllegalOwner otherwise.
  • Enforce user_signer.is_signer; return MissingRequiredSignature when absent.
  • Replace raw addition with checked_add and return an arithmetic error on overflow.
Why this order?

The order enforces authority and type safety before mutating state. Validations protect against spoofing and malicious inputs prior to any change.

Validation patterns

Use require_owner_eq! and require_signer! macros or explicit comparisons, and use custom error enums for clear diagnostics and testing.

Outcome

A hardened counter program that demonstrates ownership, signing, and safe arithmetic patterns you can reuse.
