Module 6 › Chapter 5.5 › Owner & Type Checks
Owner check checklist
  • Confirm account.owner == &EXPECTED_PROGRAM_ID before deserialization.
  • For SPL Token accounts, check owner == &spl_token::ID and use Pack to validate structure.
  • Include a magic number or enum variant in your state to confirm type after deserialization.
Concrete example
If you expect a token account, check owner equals spl_token::ID and that the data parses successfully via Pack::unpack; otherwise reject the instruction.
Common mistake
Deserializing arbitrary account data without owner checks can lead your program to treat attacker-controlled bytes as valid structured state.
Watch out

Always fail fast on owner mismatch; use require_owner_eq! or explicit comparison to return a clear error.
