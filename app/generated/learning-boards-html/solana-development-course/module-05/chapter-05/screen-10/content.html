Module 6 › Chapter 5.5 › Input Validation
Input validation checklist
  • Check numeric ranges: non-zero, upper limits, and that arithmetic won’t overflow.
  • Check buffer and string lengths to avoid panics during deserialization.
  • Confirm public keys match expected authorities or derivations.
  • Return clear custom errors so tests can assert failure modes.
Key Takeaway

Perform thorough on-chain validation of all inputs; treat off-chain validation as helpful but not authoritative.
