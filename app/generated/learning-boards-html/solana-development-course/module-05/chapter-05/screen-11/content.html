Module 6 › Chapter 5.5 › Counter Walkthrough
Vulnerable snippet
use borsh::{BorshDeserialize, BorshSerialize};

pub struct CounterAccount { pub value: u32 }

// ... inside process_instruction
let counter_account = next_account_info(account_info_iter)?;
let user_signer = next_account_info(account_info_iter)?;

let mut counter_data = CounterAccount::try_from_slice(&counter_account.data.borrow())?;

// VULNERABILITY: unchecked arithmetic
counter_data.value += 1;

counter_data.serialize(&mut &mut counter_account.data.borrow_mut()[..])?;
What to change
  • Owner check: if counter_account.owner != program_id return IllegalOwner.
  • Signer check: if !user_signer.is_signer return MissingRequiredSignature.
  • Checked arithmetic: counter_data.value = counter_data.value.checked_add(1).ok_or(CounterError::ArithmeticOverflow)?;
Key Takeaway

Make these three changes and add a small custom error enum. Tests should assert these error paths to prevent regressions.
