Module 6 › Chapter 5.5 › Audit Checklist
Security checklist (repeat on every handler)
1 Authority
Owner and signer checks, PDA derivation and invoke_signed verification.
2 Input validation
Ranges, lengths, and public key expectations.
3 Arithmetic
Use checked_* APIs and explicit errors.
4 CPI validation
Confirm owners, writeable flags, and token mints for passed accounts.
5 CEI ordering
Checks, then Effects, then Interactions.
6 Rent & authorities
Ensure rent-exempt accounts and minimal freeze authority.
7 Tests
Negative tests for each error path and boundary cases for arithmetic.
8 Simplicity
Favor small, auditable functions and clear state transitions.
Key Takeaway

Use the checklist routinely and include negative tests and property testing to catch edge cases before deployment.
