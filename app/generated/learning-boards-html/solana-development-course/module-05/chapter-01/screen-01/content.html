Cross-Program Invocation (CPI)

CPI lets one Solana program call another program's instruction so logic can be composed across programs. We'll practice with SPL Token CPI and PDAs.

Why it matters
Build modular programs that reuse secure, audited logic like the SPL Token Program.
What you'll learn
Assemble CPI calls, choose invoke vs invoke_signed, and validate accounts safely.
In this lesson
Practical CPI: PDAs, signer seeds, account ordering, and safety checks illustrated with token transfer examples.
