Module 5 › Chapter 5.1 › What is CPI?
Definition

CPI allows one program to call another program's instruction with a specific set of accounts and optional signer seeds.

Metaphor
Think of the invoker as a client sending a request packet to a service that already knows how to perform the operation.
Key Takeaway

CPI is explicit: you must assemble instruction data, ordered accounts, and provide signer seeds when a PDA should sign.

Concrete Example: Escrow token transfer
  • Invoker constructs an SPL Token transfer instruction with amount and authority fields.
  • Invoker collects AccountInfo objects: source, destination, authority, token program in the expected order.
  • If the authority is a PDA the program controls, it calls invoke_signed and supplies signer seeds to sign on behalf of that PDA.
Common misconception
CPI does not implicitly grant signing power; invoke_signed is required for PDAs and signing must be explicit via seeds.
Check
Always confirm the callee's expected account order before calling.
