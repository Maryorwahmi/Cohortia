Module 5 › Chapter 5.1 › invoke vs invoke_signed
invoke

Use when all required signatures are already present and your program does not need to sign for any accounts.

Example use
A proxy that forwards a user-signed instruction to the SPL Token Program without adding signatures.
invoke_signed

Use when your program must sign on behalf of a PDA it controls by supplying signer seeds to reconstruct the PDA for the runtime.

Example use
An escrow program transferring tokens from a PDA-owned token account where the program must provide the PDA signature.
