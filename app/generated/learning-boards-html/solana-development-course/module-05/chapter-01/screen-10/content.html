Module 5 › Chapter 5.1 › Validation Checklist
Validation Flow
1. Program IDs
Confirm the callee program account equals the expected program id (e.g., SPL token).
2. Ownership
Verify account.owner for token accounts and PDAs before trusting roles.
3. Flags
Check is_signer and is_writable to match callee expectations.
Process
  1. Validate static invariants and ownership.
  2. Derive expected PDAs and compare keys.
  3. Assemble AccountInfo in exact callee order.
  4. Call invoke or invoke_signed and handle errors explicitly.
Key Takeaway

Run the validation sequence before any external call to minimize attack surface.

Common Mistake

Trusting client-supplied accounts without checking owner and signature flags.
