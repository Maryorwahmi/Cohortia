Module 5 › Chapter 5.1 › What to Remember
Validate accounts
Check owner, signer, and writable flags before CPI.
Design PDAs
Use clear seeds and bumps so you can reconstruct PDAs in tests and runtime.
Test failure modes
Write negative tests for misordered accounts, bad seeds, and wrong program ids.
Final takeaway
CPI is powerful but explicit: assemble correct accounts, supply signer seeds for PDAs, validate everything, and test both success and failure modes before deployment.
