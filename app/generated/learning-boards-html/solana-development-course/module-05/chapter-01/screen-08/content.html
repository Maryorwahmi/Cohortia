Module 5 › Chapter 5.1 › Escrow transfer
Step summary
  1. Validate token program id and that accounts are token accounts.
  2. Confirm PDA derivation and ownership of the source token account.
  3. Create transfer instruction for SPL Token Program and collect AccountInfos in expected order.
  4. Call invoke_signed with signer seeds and handle the result.
Analogy
Think of seeds as the program's sealed stamp; only with the right stamp will the runtime treat the PDA as signed.
// Example excerpt: building transfer instruction and calling invoke_signed
let transfer_instruction = token_instruction::transfer(
  token_program.key,
  source_token_account.key,
  destination_token_account.key,
  pda_authority.key,
  &[],
  amount,
)?;

let pda_seeds = &[b"escrow", &[bump]];
let signer_seeds = &[&pda_seeds[..]];

invoke_signed(
  &transfer_instruction,
  &[
    source_token_account.clone(),
    destination_token_account.clone(),
    pda_authority.clone(),
    token_program.clone(),
  ],
  signer_seeds,
)?;
Key Takeaway

Assemble instruction and accounts correctly; provide exact signer seeds so runtime recognizes the PDA signer.

Common Mistake

Not checking token program id or passing accounts in the wrong order causes runtime errors.
