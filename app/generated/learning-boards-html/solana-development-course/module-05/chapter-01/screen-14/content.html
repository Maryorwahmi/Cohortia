Cross-Program Invocation
One program calls another's instruction with ordered AccountInfos.
invoke
Use when no program signature is required; the transaction already contains needed signatures.
invoke_signed
Use when the program must sign for a PDA by supplying signer seeds to the runtime.
Summary
Keep account ordering, ownership checks, and signer requirements explicit when preparing CPIs; these small details determine success or runtime failure.
