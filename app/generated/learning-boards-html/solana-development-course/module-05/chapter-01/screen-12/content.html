Module 5 › Chapter 5.1 › Testing CPI
Test plan
Positive test
Derive PDA with seeds, create mint with PDA authority, call wrapper to mint, assert destination balance increased.
Negative tests
Use wrong seeds, wrong account order, or an incorrect token program id and assert calls fail as expected.
Debug tip
Print or log the account public keys and derived PDA in tests to confirm the expected ordering and derivation match runtime expectations.
Key Takeaway

Integration tests that cover both success and failure modes give you confidence in CPI logic and safety checks.
