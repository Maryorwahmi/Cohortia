Module 5 › Chapter 5.1 › Troubleshooting CPI
Diagnostic checklist
  1. Confirm the callee program id equals expected program (e.g., SPL token).
  2. Verify signer errors: did you use invoke_signed with correct seeds?
  3. Print account public keys and compare with callee expected order.
  4. Run targeted tests swapping accounts to reproduce failure and identify position expectations.
Common runtime errors
InvalidAccountData, IncorrectProgramId, MissingRequiredSignature — map each to a likely cause and a next diagnostic step.
Key Takeaway

Methodical checks and targeted tests that alter account order are the fastest route to identify CPI failures.
