PDA-owned token vaults
Securely hold tokens under program control using PDAs as authorities.
Vault design steps
  1. Derive a vault PDA using stable seeds, e.g., b"escrow", user_a, user_b.
  2. Create an SPL Token account and make the PDA the authority for that token account.
  3. Store the bump in escrow state for later invoke_signed calls.
  4. Authorize transfers by calling the token program via invoke_signed with signer_seeds.
Pitfall
Creating the token account with the wrong authority or owner prevents the program from controlling funds.
Escrow example seed shape
// escrow vault PDA
let (vault_pda, bump) = Pubkey::find_program_address(&[b"escrow", user_a.key.as_ref(), user_b.key.as_ref()], program_id);
// create token account with authority = vault_pda
// later, transfer using invoke_signed with &[&[b"escrow", user_a.key.as_ref(), user_b.key.as_ref(), &[bump]]]
Key Takeaway

Make the vault authority the PDA and preserve bump seeds. Always assert authority and ownership before moving funds.
