Module 5 › Chapter 5.4 › Bloom Progression
Bloom: Learn → Understand → Apply → Master
Four testable skill levels for PDA design and implementation.
Learn
Define PDA and bump seed; explain why a PDA has no private key. Example: a profile PDA derived from a user's public key.
Understand
Explain Pubkey::find_program_address behavior and how the bump seed is used to force the address off-curve. Misconception: a PDA is not the program ID.
Apply
Derive PDAs in code, store bump seeds in state, and call invoke_signed to create PDA-owned accounts and transfer tokens into PDA vaults.
Master
Design patterns: program state PDA, token vault PDAs for escrow, and using PDAs as mint or freeze authority via CPI calls to SPL Token.
