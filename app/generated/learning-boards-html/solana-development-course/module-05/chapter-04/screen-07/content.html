Program signing via invoke_signed
How to supply signer_seeds and avoid CPI failures.
Mechanics
  • Construct signer_seeds as an array of byte slices matching derivation seeds.
  • Append the bump as a single-element byte slice, e.g., &[&[b"escrow", user.key.as_ref(), &[bump]]].
  • Call invoke_signed with those signer_seeds so the runtime can validate the PDA signer.
Debug checklist
If invoke_signed fails: verify seed content and order, confirm bump is included, and verify the PDA account is owned by your program.
Example signer_seeds shape
// Rust-style signer seeds for a PDA
let signer_seeds: &[&[u8]] = &[
  b"escrow",
  initializer.key.as_ref(),
  &[bump_seed],
];
invoke_signed(
  &create_account_ix,
  accounts,
  &[&signer_seeds],
)?;
Pro tip

Wrap seed construction in a helper function shared by client and program to avoid order mismatch bugs.
