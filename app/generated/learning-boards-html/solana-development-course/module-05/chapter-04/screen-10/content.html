Comparison › PDA vs Wallet Authority
Authority delegation choices
Compare PDA authority with wallet-based authority to select the right model.
Wallet Authority
  • Can sign off-chain for immediate control.
  • Requires secure key custody and rotation plans.
  • Easy human intervention for recovery or emergency action.
When to prefer
Administrative tools, emergency freezes, or when a human must retain irreversible control.
PDA Authority
  • Programmatic control with no private key risk.
  • Requires invoke_signed and stored bump seeds for CPIs.
  • Enforces rules deterministically in program logic.
When to prefer
Automated minting, escrow logic, or when trustless enforcement is desired.
Design note

If using PDA authority, design and document program-side governance and migration strategies so control can be updated safely.
