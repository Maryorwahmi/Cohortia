Core Concept › What is a PDA
Program Derived Address — core idea
A deterministic account address that has no private key and is owned by a program.
Formal definition

A PDA is produced by Pubkey::find_program_address using seeds and a program ID; the returned bump seed is required to re-create signer seeds for invoke_signed. The bump forces the address off-curve.

Concrete example
Using seeds [b"profile", user_pubkey.as_ref()] with your program ID yields a user profile PDA and a bump. Store that bump in the account so future CPIs can supply it.
Misconception

Do not treat the PDA as the program ID. The PDA is a separate account owned by the program; it cannot sign off-chain.

Visual seeds and derivation
Seeds: b"profile" + user_pubkey
Program ID: your program public key
Output: PDA pubkey + bump seed (u8)
Quick code snippet (conceptual)
// derive PDA and bump
let (pda, bump) = Pubkey::find_program_address(
  &[b"profile", user_pubkey.as_ref()],
  program_id,
);
// store bump for future use
Key Takeaway

PDAs are deterministic and off-curve; always keep the bump seed with state so invoke_signed can reconstruct signer seeds later.
