Learning Objectives
Clear, testable milestones to verify your PDA skills.
01
Derive PDAs deterministically
You will use Pubkey::find_program_address with explicit seeds to produce a PDA and bump seed. Knowing how to pick seeds matters for uniqueness and context.
Verified Competency Milestone
02
Use invoke_signed with signer seeds
Practice providing the exact seeds plus bump seed to invoke_signed so the runtime can validate program signatures for PDAs.
Verified Competency Milestone
03
Design PDA-owned state and vaults
Design a global state PDA and token vault PDAs so a program controls configuration and funds without external keys.
Verified Competency Milestone
04
Implement a user profile PDA
Create, initialize, and update a user-specific PDA profile, storing the bump seed and validating ownership in updates.
Verified Competency Milestone
