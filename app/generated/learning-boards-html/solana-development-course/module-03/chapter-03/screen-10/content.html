Module 3 › Chapter 3.3 › Mut vs Read-only
Mutable access

#[account(mut)]

Grants write permission and yields &mut references in handlers so you can change account data.

Remember to mark mut in the Accounts struct, not only in handler code.
Immutable access

Read-only accounts

Safe for checks and reading fields. Trying to mutate them causes a runtime error because transaction flags do not permit writes.

Check

Write tests that attempt forbidden mutations to confirm Anchor enforces mutability constraints.
