What msg! does

Writes formatted text to transaction logs. Useful during development and for test traceability.

msg!("Counter incremented to: {}", counter_account.count);
msg!("Counter account initialized with count: {}", counter_account.count);
Guidance
  • Log meaningful state changes and important validation failures.
  • Avoid verbose logging in production to reduce noise and cost.
  • Combine msg! with custom errors so logs and failure reasons both exist.
Practical example

Use msg! inside tests to assert that a logged line appears for a successful initialize or increment, improving test diagnostics.

Misuse

Relying on msg! for control flow or user-facing behavior is a mistake; logs are diagnostic, not business logic.
