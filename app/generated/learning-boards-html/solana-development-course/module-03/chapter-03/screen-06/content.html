Code walkthrough
pub fn initialize(ctx: Context<Initialize>) -> Result<()> {
  let counter_account = &mut ctx.accounts.counter_account;
  counter_account.count = 0;
  msg!("Counter account initialized with count: {}", counter_account.count);
  Ok(())
}
This sets the on-chain field and logs the action for visibility in transaction logs.
Explanation & checks
  • Ensure the Accounts struct marks the counter as #[account(init, payer = user, space = ...)] if the handler creates it.
  • Confirm payer and signer constraints so the transaction is valid and the account is funded.
  • Log with msg! so tests and developers can inspect the action in logs.
Example assertion

After initialize, a test should assert that counter_account.count == 0 to verify the initial state.

Misconception

Initialize won't run automatically — a client transaction must call it and supply correct accounts and fees.
