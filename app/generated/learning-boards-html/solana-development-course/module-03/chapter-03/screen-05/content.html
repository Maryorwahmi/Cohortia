Module 3 › Chapter 3.3 › Context struct
Core idea

Context bundles accounts and metadata

Use ctx.accounts to obtain typed references matching your Accounts struct, and check program_id and remaining_accounts when needed.

Practical notes
  • Mutable access requires the account to be declared with #[account(mut)] in the Accounts struct.
  • Anchor checks many constraints automatically, but custom validations often remain necessary.
  • remaining_accounts is useful for CPIs and variable-length account lists.
Example usage
let counter_account = &mut ctx.accounts.counter_account;
counter_account.count = 0;
msg!("Counter initialized: {}", counter_account.count);
// ctx.program_id and ctx.remaining_accounts are also available for advanced flows
Common mistake

Treating an account as mutable without #[account(mut)] will compile but panic at runtime when the change is attempted.

Pro tip

Declare ownership and signer constraints in the Accounts struct so Anchor can automatically enforce them before your logic runs.
