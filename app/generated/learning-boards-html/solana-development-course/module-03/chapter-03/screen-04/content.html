Module 3 › Chapter 3.3 › Instruction Handlers
Definition

What an instruction handler is

A function exposed by Anchor via the program macro that executes when a client includes it in a transaction instruction.

Key points
  • Clients include the instruction in a transaction with the accounts it needs.
  • Only functions in the #[program] module are callable as instructions.
  • Handlers receive a Context struct with typed account references.
Concrete example
pub fn initialize(ctx: Context<Initialize>) -> Result<()> {
  let counter_account = &mut ctx.accounts.counter_account;
  counter_account.count = 0;
  msg!("Counter account initialized with count: {}", counter_account.count);
  Ok(())
}

pub fn increment(ctx: Context<Increment>) -> Result<()> {
  let counter_account = &mut ctx.accounts.counter_account;
  counter_account.count += 1;
  msg!("Counter incremented to: {}", counter_account.count);
  Ok(())
}
Common misconception

Assuming any function is callable as an instruction. Only functions in the program module become instructions.

Key takeaway

Design instruction signatures to clearly list required accounts and their mutability to keep clients correct.
