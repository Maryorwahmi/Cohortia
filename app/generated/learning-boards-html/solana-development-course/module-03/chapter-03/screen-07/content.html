Guard pattern
pub fn increment(ctx: Context<Increment>) -> Result<()> {
  let counter_account = &mut ctx.accounts.counter_account;
  if counter_account.count == u64::MAX {
    return Err(MyError::CounterOverflow.into());
  }
  counter_account.count += 1;
  msg!("Counter incremented to: {}", counter_account.count);
  Ok(())
}
Explanation
  • Check bounds before mutation to avoid overflow and to return a clear error variant.
  • Use Anchor errors to convert enum variants into ProgramError for the runtime.
  • Emit msg! after a successful change so logs reflect the new state for debugging.
Misconception

Assuming increment will always succeed. Always plan for edge cases like max value or invalid account data.

Check

After implementing increment, add tests that attempt to increment at max to ensure the error path works as expected.
