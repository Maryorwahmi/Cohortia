Module 3 › Chapter 3.3 › Key Concepts
Instruction Handler
A callable program function invoked by client transactions to change or read state.
Context Struct
Provides typed access to accounts, program_id, and remaining_accounts for handlers.
Account Access
Declare mut for writable accounts and validate ownership and signer constraints.
State Manipulation
Modify account fields via mutable refs; changes are committed if the instruction succeeds.
msg! Macro
Emit transaction logs for debugging and test verification.
Custom Errors
Use #[error_code] enums and return .into() for clear, testable failure reasons.
Summary takeaway

Explicit account contracts, validation, and structured errors make your program safer and your tests reliable.
