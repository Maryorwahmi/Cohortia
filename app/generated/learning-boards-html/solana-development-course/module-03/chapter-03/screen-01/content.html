Instruction handlers and state changes

Understand how Anchor exposes callable functions, how Context provides accounts, and how to change account state safely.

Estimated time: 10 min
In this lesson

Implement initialize and increment handlers, access ctx.accounts, and add custom error handling.

Why it matters

Correct account access and validation prevent panics and provide clear client feedback on failures.

Quick concept

Context bundles account refs, program id, and any remaining accounts for advanced flows.

Tip

Always mark accounts mut when you intend to change them. Missing mut causes runtime failures.

Explore Key Topics
Instruction Handler
A callable function in your program that runs when included in a transaction.
Context & Accounts
Anchor's Context gives typed references to accounts and program metadata.
Errors & Validation
Custom errors let your program fail with clear reasons, improving client UX and safety.
Counter app concept
A program exposes initialize and increment. Clients send instructions to change stored count.
Initialize

Sets the counter account's count to zero and logs a message.

Increment

Increments the stored count and optionally returns an overflow error if at max.
