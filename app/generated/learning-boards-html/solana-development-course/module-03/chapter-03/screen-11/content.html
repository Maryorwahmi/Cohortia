Module 3 › Chapter 3.3 › Validation Patterns
Validation checklist
Ownership

Confirm the account.owner equals your program id when required.

Signer

Require signer constraints for authorized actions and check them in code if needed.

Range checks

Validate numeric bounds before modifying values to avoid overflows and invalid states.

Invariant assertions

Check any application invariants such as unique ownership, non-empty fields, or maximum counts.

Testing tip

Write tests that trigger each validation failure and assert the specific custom error is returned.
