Architecture

Program ID and invocation

The runtime routes instructions to a program using its Program ID. The transaction includes accounts and data the program will act on.

Program ID
An immutable public key that identifies deployed executable logic.
Accounts
Passed into instructions as the source of persistent state.
Instruction Data
Parameters that tell the program which operation to perform.
Concrete scenario
Token transfer call
You include the token program’s Program ID, the source and destination accounts, and the authority signer. The program enforces permissions and updates account balances.
Key Takeaway

Program IDs route calls; correct account and signer designation are required for safe updates.
