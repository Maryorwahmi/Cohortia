Common mistakes and safety tips

PATH issues
If installers succeed but commands are not found, restart the shell or add bin paths to PATH.
Installer flags
Using locked and force when installing Anchor CLI helps produce consistent builds and avoid version drift.
Verification
Run rustc --version, solana --version, and anchor --version and confirm readable output.
Safety reminder

Inspect installer scripts and prefer official sources to reduce supply-chain risk during tool installation.
