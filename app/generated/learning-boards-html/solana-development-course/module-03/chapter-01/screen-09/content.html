Module 3 › Chapter 3.1 › Anchor Init
Scaffold

anchor init my-counter-app

The command scaffolds a workspace. Key folders are programs/, tests/, and the Anchor.toml configuration file.

Directory layout
my-counter-app/
├─ programs/
│  └─ my_counter_program/
│     └─ src/lib.rs
├─ tests/
│  └─ my_counter_test.ts
└─ Anchor.toml
Inspect
Open Anchor.toml to confirm workspace members and program IDs. Update IDs for your deployment targets as needed.
Key Takeaway

Use the generated structure as a starting point: programs contain Rust code and tests validate behavior against a local validator.
