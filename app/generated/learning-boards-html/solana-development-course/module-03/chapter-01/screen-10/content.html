Config file

Anchor.toml

This file records workspace members and program IDs. Use it to align builds, deployments, and tests.

Example snippet
[programs.localnet]
my_counter_program = "ReplaceWithProgramID"

[workspace]
members = ["programs/*"]
Practical notes
  • Update Program IDs after deploy.
  • Ensure tests point to the same config environment.
  • Share and document environment differences with collaborators.
Key Takeaway

Anchor.toml keeps your workspace aligned; treat it as the source of truth for program addresses used in tests and deploys.
