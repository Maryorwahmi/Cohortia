Installers
Use the language installer for Rust, the Solana CLI installer, and the Anchor CLI installer. After running each installer, check versions to confirm success.
Example command output checks
rustc --version
solana --version
anchor --version
Troubleshoot

If a command returns "not found," restart your terminal or add the installer bin path to your PATH environment variable.

Notes
  • Prefer the official installers provided by the tool maintainers.
  • Use the locked and force flags when installing Anchor CLI to ensure a consistent build.
  • Verify with version commands and inspect the shell PATH if necessary.
Key Takeaway

Installers set up tools but verification is essential to confirm a working environment before creating a project.

The exact installer commands are shown below in the reference panel for you to copy into a terminal. Review them before running.
Reference installer commands
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
sh -c "$(curl -sSfL https://release.solana.com/v1.18.4/install)"
cargo install --git https://github.com/coral-xyz/anchor anchor-cli --locked --force
