Module 3 › Chapter 3.1 › Hands-on Activity
Starter commands
Run the scaffold and then inspect the created folders. Review Anchor.toml before running tests or deploys.
mkdir solana-dev-workspace
cd solana-dev-workspace
anchor init my-counter-app
After scaffolding, open programs/ to view the Rust crate and tests/ to see the example test harness. Update Anchor.toml if you deploy to a non-default address.
Check your work
  • Locate programs/, tests/, and Anchor.toml
  • Open a Rust source file and identify an instruction handler
  • Run the example test and confirm it invokes the program
Key Takeaway

The scaffold gets you to a runnable workspace quickly; inspect and adapt configuration before running tests on a real validator.
