Module 3 › Chapter 3.1 › Key Concepts
Solana Program
Stateless executable logic that operates on account data supplied to instructions.
Rust
Provides performance and compile-time memory safety important for low-level account handling.
Anchor Framework
A DSL and macros that reduce boilerplate for account validation, deserialization, and errors.
Summary takeaway

Keep the separation of program logic and account data central, use Rust for safe low-level control, and use Anchor to speed development while maintaining clarity of account design.
