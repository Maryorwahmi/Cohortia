Module 3 › Chapter 3.2 › Learning Objectives
01
Explain Solana accounts

Describe accounts as the blockchain's storage files, including owner, lamports, address and raw bytes. This matters because programs cannot hold data internally; they must use accounts.

VERIFIED COMPETENCY MILESTONE
02
Understand PDAs and seeds

Explain deterministic PDA generation from seeds and program ID, and why PDAs have no private key. This ensures program‑owned accounts are secure from external signing.

VERIFIED COMPETENCY MILESTONE
03
Define Rust structs for accounts

Use #[account] on structs so Anchor serializes and deserializes fields for storage. Proper struct layout determines how much space the account needs.

VERIFIED COMPETENCY MILESTONE
04
Apply Anchor constraints

Use init, payer, space, mut, signer, seeds, and bump to create and protect accounts deterministically and safely. Correct constraints prevent unauthorized writes.
