Hands-on Activity › Define a Counter Account
Lab steps
  1. Open programs/my-counter-app/src/lib.rs and paste the Counter example from the lesson.
  2. Update declare_id to the program ID in your Anchor.toml under programs.localnet or programs.devnet.
  3. Ensure Initialize uses #[account(init, payer = user, space = 8 + 8)] and user is Signer and mut.
  4. Ensure Increment marks counter_account as #[account(mut)].
  5. Run anchor build from project root to compile. Address any error messages about space or ownership.
Tip
If build fails, read Anchor's diagnostics: they often indicate a missing constraint or mismatched discriminator before runtime deployment.
Key Takeaway

Build early and often. Small changes to structs must be paired with space updates or migrations to avoid runtime errors.
