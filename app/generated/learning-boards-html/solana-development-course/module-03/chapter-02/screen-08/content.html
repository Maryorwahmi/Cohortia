Definition › Anchor #[account] attribute
What #[account] does
  • Marks the struct as an account data layout for Anchor.
  • Automatically serializes and deserializes fields to bytes.
  • Adds an 8‑byte discriminator to identify the account type.
Example struct
#[account] pub struct Counter { pub count: u64 }
Misconception
Anchor does not resize existing accounts. You must allocate sufficient space when you create the account.
Practical advice
When adding fields later, update the space value in init and migrate existing accounts or create new ones. Keep the struct and space calculation together in comments to reduce mistakes.
Pro tip

Document the byte size of each field in comments so future changes remain consistent with allocated space.
