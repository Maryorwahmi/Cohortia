Calculate space

Add 8 bytes for Anchor's discriminator plus your field sizes. Undersizing causes runtime failures when Anchor tries to write beyond account capacity.

VERIFIED COMPETENCY MILESTONE
Choose PDA seeds

Use deterministic seeds, for example [b"profile", user.key().as_ref()], to tie an account to a user without exposing a private key.

VERIFIED COMPETENCY MILESTONE
Apply init and payer

init creates an account; payer specifies which signer covers rent. Mistaking payer or forgetting mut on the signer leads to transaction failures.

VERIFIED COMPETENCY MILESTONE
Use mut and signer

mut indicates data will change; signer enforces the account signs the transaction. Both express access intent and are enforced by Anchor.

VERIFIED COMPETENCY MILESTONE
Mnemonic
Think: discriminator + fields = space. Seeds + program ID = PDA. init + payer = create.
Key Takeaway

Anchor's attributes express intent and perform boilerplate so your program is safer and easier to read.
