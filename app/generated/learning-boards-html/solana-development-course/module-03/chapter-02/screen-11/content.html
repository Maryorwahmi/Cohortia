Common Mistakes › Mistakes & debugging
Undersized accounts
Symptoms: runtime deserialization errors or panics when writing. Fix: recompute space including discriminator and all fields; migrate or recreate.
Wrong owner
Symptoms: writes rejected. Fix: ensure init sets program as owner or use proper system calls to change ownership only when safe.
PDA signing errors
Symptoms: signing failures if you attempt to use PDA like a keypair. Fix: derive PDA with seeds and bump, let program authorize actions.
Debug tips
  • Inspect account bytes and discriminator to confirm types.
  • Check that payer is a signer and has enough lamports to fund creation.
  • Use local unit tests and anchor build to catch type and size mismatches early.
