Architecture › Serialization / Deserialization
Hierarchy: data flow
Entry: raw bytes in account → Anchor deserializes into typed struct → program updates fields → Anchor serializes struct → bytes written to account.
Concrete checklist
  • Discriminator: 8 bytes at start to identify struct type.
  • Field sizing: primitives have fixed bytes; collections require careful allocation.
  • Space allocation: allocate enough bytes in init to hold serialized struct plus discriminator.
Example
Counter: 8 + 8 bytes. If you add an i64 timestamp, update space to 8 + 8 + 8 and migrate existing accounts or recreate them.
Key Takeaway

Keep your struct and space calculation in sync. Anchor saves time but does not replace planning for byte layout and migrations.
