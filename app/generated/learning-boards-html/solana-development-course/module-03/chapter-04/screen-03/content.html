Testing and Iteration Objectives
Build confidence by running structured tests and reproducing errors locally.
Run anchor test
Execute TypeScript tests that call program.methods on your local validator and read program logs and state.
Inspect logs & outputs
Use CLI output and msg! logs to trace program execution and assert expected behavior.
Test error cases
Create controlled conditions to trigger program errors, such as overflow, and verify your error messages and assertions.
Repeat build → deploy → test
After changes, run anchor build then anchor deploy, then anchor test to confirm behavior. Never deploy without rebuilding.
Verified Competency Milestone

Run anchor test locally, see msg! logs, and confirm assertions by fetching program account state.
