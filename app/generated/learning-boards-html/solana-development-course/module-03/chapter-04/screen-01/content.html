What you'll do in this chapter

Compile Anchor programs to BPF, run a local validator, deploy with Anchor CLI, and build a TypeScript client that sends transactions and reads account state.

Compile
anchor build -> .so in target/deploy and IDL in target/idl
Local Validator
Run solana-test-validator for isolated testing and a faucet.
Deploy & Test
anchor deploy, then run anchor test and client calls using the IDL.
Artifacts to inspect
  • .so file in target/deploy/
  • IDL JSON in target/idl/
  • Program ID reported by anchor deploy
Why this matters

Local deploy lets you iterate quickly and test program logic end-to-end with client code before you touch public clusters. The IDL bridges your on-chain program and TypeScript tests, giving typed access to instructions and accounts.
