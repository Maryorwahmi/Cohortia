Activity: Deploy and interact

Follow these steps to run the my-counter-app end-to-end on your machine.

Step 1 — Start validator
solana-test-validator
Step 2 — Configure CLI
solana config set --url localhost
solana config get
Step 3 — Build
anchor build
Step 4 — Deploy
anchor deploy
Step 5 — Update tests and run
edit tests/my-counter-app.ts
anchor test
Key Takeaway

Follow the sequence exactly: start validator, set CLI, build, deploy, then run tests to confirm on-chain behavior.
