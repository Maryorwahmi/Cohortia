Deploy with Anchor CLI

Run anchor deploy from your project root after a successful anchor build and with the validator running.

Example command
anchor deploy
What to watch
  • Program ID printed by the CLI
  • Anchor.toml updated for fresh deployments
  • Any keypair or signing errors in output
Practical checks
Confirm your .so was built recently and that the validator is reachable before deploying. Check Anchor.toml to ensure the program ID matches the deployed program if you rely on a fixed ID.
Common mistake
Deploying without rebuilding leads to a mismatch between source and deployed behavior. Always run anchor build after edits.
Key Takeaway

anchor deploy publishes the compiled .so to the configured cluster and writes or updates the program ID so clients can target it.
