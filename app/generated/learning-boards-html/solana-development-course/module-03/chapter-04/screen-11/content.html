Module 4 › Chapter 3.4 › Testing
Run tests

Execute anchor test to run TypeScript tests against the local validator and inspect outputs and logs.

Command
anchor test
What to expect
  • Program msg! logs printed during execution
  • Fetch calls returning account data for assertions
  • Test framework pass/fail results
Diagnosing failures
When a test fails, inspect the fetch result and any msg! logs inserted in the program. Add targeted logs to clarify which branch executed.
Error testing pattern
Temporarily lower the threshold for an overflow in your program or set up a loop in the test to reach the error, then assert that the expected error message is thrown.
Key Takeaway

Use anchor test for full integration checks and use program logs plus fetches to pinpoint failing logic quickly.
