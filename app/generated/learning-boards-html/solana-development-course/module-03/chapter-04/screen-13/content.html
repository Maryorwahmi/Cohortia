Common pitfalls and how to fix them
Stale build
Always run anchor build after Rust edits; deploy sends whatever was last built.
CLI misconfiguration
Confirm solana config get shows the local URL when using the test validator.
Signer missing
Include keypairs in signers for account creation; otherwise the transaction will fail authorization checks.
Wrong account metas
Passing incorrect public keys causes runtime account mismatch errors. Verify account addresses and types against the IDL.
Quick debugging workflow

Confirm validator, run anchor build, run anchor deploy, execute anchor test, inspect msg! logs and fetch results to locate failures.
