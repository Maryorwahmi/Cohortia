Learning Objectives
Learn the commands, artifacts, and client calls needed for local development and testing.
01
Compile to BPF
Run anchor build to produce a .so and an IDL. Verified competency milestone
Understand what the .so is and why the IDL describes the program interface. A concrete check is locating target/deploy/*.so and target/idl/*.json.
02
Run local validator
Start solana-test-validator for isolated testing. Verified competency milestone
Practice starting the validator, using the faucet, and configuring solana CLI to point to localhost.
03
Deploy with Anchor CLI
Use anchor deploy to publish the .so to the configured cluster. Verified competency milestone
Learn how Anchor reads Anchor.toml, manages keypairs, and outputs the program ID so your client can target it.
04
Client interaction
Write TypeScript tests that call program.methods and fetch account state. Verified competency milestone
Practice initializing accounts, signing with generated keypairs, and reading state via program.account.fetch.
