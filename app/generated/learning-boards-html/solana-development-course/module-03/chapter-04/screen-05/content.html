Start the local validator

Run the validator in its own terminal and keep it running while you deploy and test.

Commands
solana-test-validator
solana config set --url localhost
solana config get
Checklist if you see connection errors
  • Is solana-test-validator running?
  • Does solana config get show localhost as the RPC URL?
  • Are there firewall or port issues preventing local RPC connections?
Practical notes
The local validator includes a faucet so your test wallet can receive SOL for transactions. It is ephemeral by default; you can configure ledger persistence for longer-lived experiments.
Common misconception
The local validator is not a perfect replica of public networks. It is intended for functional testing, not performance or stress testing against mainnet conditions.
Key Takeaway

Use solana-test-validator and configure your CLI to localhost for fast, isolated testing and to capture program logs during development.
