Module 4 › Chapter 3.4 › Sending Instructions
Chainable API

The builder pattern helps you assemble an instruction with accounts, signers, and finally send it with rpc.

Concrete example
// initialize a counter account
await program.methods
  .initialize()
  .accounts({
    counterAccount: counterAccount.publicKey,
    user: provider.wallet.publicKey,
    systemProgram: anchor.web3.SystemProgram.programId,
  })
  .signers([counterAccount])
  .rpc();
Fetch and verify

After sending an instruction, fetch the account to check state changes:

const account = await program.account.counter.fetch(counterAccount.publicKey);
console.log(account.count.toString());
Common mistake
Providing the wrong account public key or forgetting a required account will cause the transaction to fail at runtime with an account validation error.
Key Takeaway

Construct instructions using the IDL-driven builder and always verify state with a fetch after rpc completes.
