Test structure

Provider, workspace, account generation, rpc calls, fetches, and assertions form a repeatable test pattern.

Key snippet
const provider = anchor.AnchorProvider.env();
anchor.setProvider(provider);
const program = anchor.workspace.MyCounterApp as Program;
const counterAccount = anchor.web3.Keypair.generate();

await program.methods
  .initialize()
  .accounts({
    counterAccount: counterAccount.publicKey,
    user: provider.wallet.publicKey,
    systemProgram: anchor.web3.SystemProgram.programId,
  })
  .signers([counterAccount])
  .rpc();
Assertions and logs
After actions, fetch the account and assert values. The test logs also show program msg! outputs which help trace logic during execution.
Error testing
To test an error path, temporarily adjust program logic to make the error reachable, then run anchor test and assert that the error message is thrown as expected.
Key Takeaway

anchor test runs full integration tests against the local validator, letting you validate on-chain behavior with TypeScript assertions.
