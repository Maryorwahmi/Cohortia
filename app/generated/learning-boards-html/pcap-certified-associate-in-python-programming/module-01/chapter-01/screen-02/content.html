Learning Objectives

Each objective is paired with a short verified milestone so you can confirm competency before moving forward.

01
Understand Python's philosophy
Explain the Zen of Python, readability, and why indentation is meaningful. Verified competency milestone: recite one principle and show an indented code sample that runs.
02
Install and verify Python 3
Install Python 3 and check python --version and pip --version. Milestone: terminal shows Python 3.x and pip is present.
03
Run a first script
Create hello.py and run it. Milestone: printed messages appear in the terminal after running python hello.py.
04
Prefer Python 3, not Python 2
Identify key differences and why Python 2 is deprecated. Milestone: explain print as a function and integer division behavior in Python 3.
