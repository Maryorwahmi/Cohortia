Setup Checklist and Practice

A brief checklist shows the exact steps to validate a working environment and gives a concrete test you can repeat.

Check 1
python --version and pip --version
Open the terminal and run these two commands to confirm Python 3 and pip are present. If the command is not found, check the PATH setting during installation or re-run the installer.
Check 2
Create hello.py and run it
Save a small script and run python hello.py. Seeing printed text confirms your editor and terminal workflow.
Check 3
Install a package with pip
Try pip install requests. If installation succeeds, pip and the network work; if permission errors appear, consider using user installs or a virtual environment later.
Common setup mistakes
  • Not checking "Add Python to PATH" on Windows, causing terminal errors.
  • Saving files with the wrong extension or in the wrong folder and running from another directory.
  • Confusing system Python with installed Python; use explicit python --version to confirm.
Key Takeaway

A verified terminal run and a successful pip install prove your environment is ready for learning and experimentation.
