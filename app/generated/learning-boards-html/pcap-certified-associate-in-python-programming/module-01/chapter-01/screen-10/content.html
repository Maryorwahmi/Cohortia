pip and Managing Packages

Understand pips role and perform a simple install to confirm your environment can add libraries.

Verify pip
pip --version
pip install requests
Successful installation confirms network access and that pip is associated with your Python 3 interpreter.
Why use pip?
It saves development time by letting you reuse community-tested libraries rather than reimplementing common features.
Practical note
Later you'll learn about virtual environments to avoid conflicts; for now, confirm pip works with a single install.
Key Takeaway

pip is the standard tool for installing libraries; verifying it early clears the path to more powerful Python tools.
