The print() Function

Use print to inspect program state and confirm execution during learning and debugging.

Example
name = "Cohortia"
age = 2
print("Name:", name)
print("Age next year:", age + 1)
Including a label in the print call helps you distinguish outputs when multiple prints appear in the terminal. This small habit reduces confusion while debugging.
Common mistake
Using print without parentheses (Python 2 style) or forgetting to save files before running causes syntax errors or stale outputs.
Try this
Save a script with several labeled prints and run it to practice reading and interpreting terminal output quickly.
Key Takeaway

Use the print function to verify values and behavior as you build confidence with code execution.
