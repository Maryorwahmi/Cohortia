Write and Run hello.py

A concrete code example and terminal commands show the exact steps to run your first script.

Code
# This is our first Python program!
print("Hello, Cohortia!")
print("Learning Python is fun!")
Terminal Commands
Navigate to the folder then run:
cd path/to/your/folder
python hello.py
Expected output
Hello, Cohortia!
Learning Python is fun!
If you do not see output, check that the file was saved and that the terminal is in the same folder as the file.
Key Takeaway

A successful printed output proves your editor, file save, and interpreter are working together.
