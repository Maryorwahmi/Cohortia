Python 2 vs Python 3

A side-by-side comparison highlights the practical differences that affect beginners.

Python 2 (legacy)
  • print can be used without parentheses.
  • Integer division truncates by default.
  • No longer supported by the community or security updates.
Python 3 (modern)
  • print is a function and requires parentheses.
  • Integer division yields floats, more consistent math.
  • Improved Unicode and ongoing support from the ecosystem.
Concrete example
# Python 3 example
print("Hello, Cohortia!")
# 5 / 2 gives 2.5 in Python 3
If you run code with print without parentheses in Python 3, you'll see a syntax error. That difference alone makes Python 3 the only sensible choice now.
Key Takeaway

Learn and use Python 3; it is the maintained and modern language everyone uses today.
