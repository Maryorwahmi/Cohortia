Lab: Install, Run, and pip Install

Follow the three verified steps below and confirm the expected outputs to ensure your environment is ready.

Step 1: Install Python 3
Run the installer and select add to PATH on Windows; use package managers on macOS/Linux if preferred.
Step 2: Run hello.py
Save and run the sample script. Expected output will be two printed lines confirming success.
Step 3: pip install requests
Install a lightweight library to confirm pip works and that installs succeed from the network.
Expected confirmations
  • python --version shows Python 3.x
  • hello.py prints messages when run
  • pip install requests finishes without errors
If any step fails, check the terminal output for specific errors: missing PATH entries, file location mistakes, or network/permission problems during pip installs.
Key Takeaway

Completing these three checks gives you a reliable, working Python environment for the rest of the course.
