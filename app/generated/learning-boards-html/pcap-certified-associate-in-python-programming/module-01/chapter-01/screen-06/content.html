Install Python 3 — Step-by-step

Follow these numbered steps to install Python and confirm your terminal can run it immediately.

1. Choose Python 3 installer
Download the appropriate Python 3 installer for your OS and run it.
2. Add Python to PATH (Windows)
Check the Add Python to PATH checkbox. This makes python accessible from any terminal window.
3. Verify installation
Open a terminal and run python --version and pip --version. Confirm both return versions and that Python reports a 3.x version.
Terminal verification example
# Expected terminal output
> python --version
Python 3.x.x
> pip --version
pip x.x from ... (python 3.x)
If the commands fail, revisit the installer and check PATH options, or confirm which python is active with system tools.
Common Mistake

Skipping the Add Python to PATH option on Windows leads to a terminal that cannot find python; fix by re-running the installer or updating PATH manually.
