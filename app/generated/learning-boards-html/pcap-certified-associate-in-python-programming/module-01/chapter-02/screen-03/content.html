Verified Practice Checks

Small, focused tasks you can complete to demonstrate each objective.

Task: Declare & initialize
Pick a descriptive variable name using snake_case and set it to a numeric or text value. Run the script and inspect its type using the type function.
Task: Convert input
Read two values as text, convert them to float, and compute a result. Add error handling for invalid input.
Mnemonic
Think: "Name, Know, Change, Use" — Name variables, Know their types, Change types when needed, Use operators correctly.
Outcome
A short script that reads input, converts types, computes and prints a formatted result.
