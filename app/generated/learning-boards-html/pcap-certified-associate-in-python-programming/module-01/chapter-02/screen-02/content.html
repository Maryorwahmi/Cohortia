Learning Objectives

Understand and apply variables, types, operators, and casting.

Bloom: Learn → Understand → Apply → Master
01
Declare variables

Create and assign names to values that Python tracks. Good names reduce bugs and improve readability.

VERIFIED COMPETENCY MILESTONE
02
Identify common types

Recognize int, float, str, and bool, and know common behaviors like string immutability and float precision issues.

VERIFIED COMPETENCY MILESTONE
03
Apply operators

Use arithmetic, assignment, comparison, and logical operators correctly to compute and compare values.

VERIFIED COMPETENCY MILESTONE
04
Perform type conversion

Convert strings to numbers and vice versa safely, understand exceptions, and guard conversions with checks.
