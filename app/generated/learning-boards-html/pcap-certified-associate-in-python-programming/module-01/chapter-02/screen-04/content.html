Module 1 › Chapter 1.2 › What is a Variable?
Definition

Variables as labeled storage

A name points to a value object. The object's type determines what operations are valid on it.

Explanation
  • Names are references; objects have types.
  • Assigning a new value changes the object the name refers to.
  • Dynamic typing makes prototyping faster but requires careful variable use.
Analogy
Think of names as sticky labels and values as the boxes beneath them. You can remove a label and stick it to a different box, but the box still has its contents.
Concrete examples
Number example
A name holding a whole number used for counting or index values.
Text example
A name holding descriptive text used for messages or labels.
Check your understanding
If you assign a string to a name previously used for a number, what problems could arise? Consider later code that expects arithmetic.
Key Takeaway

Names label values. Types belong to values, not to names. Keep variable roles consistent to avoid confusion.
