Type hierarchy

Group types by their purpose to pick the right one for the job.

Numeric types
  • int: whole numbers, exact
  • float: decimal numbers, may have precision quirks
Text and truth
  • str: immutable text sequences
  • bool: True or False, used for logic
Practical note
Use the appropriate type for clarity: do not store numeric data as text unless you need formatting — convert only when necessary.
Common mistake
Trying to add text and a number without conversion leads to a TypeError. Always convert explicit types before mixing operations.
Quick reference
Integer
Whole numbers for counts and discrete math.
Float
Decimal numbers for measurement; watch precision.
String
Text data, immutable; concatenation makes new strings.
Boolean
True / False values used in conditions and logic.
Key Takeaway

Choose types to match the role: counting, measuring, labeling, or deciding.
