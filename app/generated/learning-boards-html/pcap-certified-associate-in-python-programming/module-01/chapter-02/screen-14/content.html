Module 1 › Chapter 1.2 › Key Concepts
Variable
A name bound to a value; Python infers the value's type.
Data types
Common types: int, float, str, bool — choose the one that matches your data role.
Operators
Arithmetic, assignment, comparison, and logical operators let you compute and decide.
Takeaway
Explicit casting and validation make programs robust. Treat types as contracts between operations and values.
