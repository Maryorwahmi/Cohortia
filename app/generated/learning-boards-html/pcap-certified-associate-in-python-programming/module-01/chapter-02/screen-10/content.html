Basic and compound assignment

  • Use = to assign the result of an expression to a name.
  • Use compound forms like += and -= to update values concisely.
  • Understand the difference between mutating an object and rebinding a name.
Edge case
When operating on mutable objects, using a compound operator may change the object itself rather than creating a new one.
Example
count = 10
count += 5  # equivalent to: count = count + 5
values = [1, 2]
values += [3]  # extends the list in place
Observe whether the operation mutates the object or rebinds the name depending on the type.
Key Takeaway

Compound assignment makes updates concise; know whether the underlying object is mutated or a new object is created.
