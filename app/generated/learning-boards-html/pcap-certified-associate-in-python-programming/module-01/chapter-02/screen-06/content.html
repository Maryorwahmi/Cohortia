Strings are immutable

Any operation that seems to change a string actually builds a new one and assigns the name to it.

Practical patterns
  • Concatenate short pieces for readable code.
  • Use formatted strings to combine numbers and text cleanly.
  • For heavy repeated concatenation, collect pieces and join them once.
Common mistake
Trying to assign to a character index in a string will fail because strings cannot be changed directly.
Examples
# Build a welcome message by joining pieces
greeting = "Hello"
name = "Taylor"
welcome = greeting + " " + name
# Using formatted text to include a number
score = 95
result_text = f"Your score: {score}"
These create new strings rather than changing existing ones. Use list+join if you build very large text incrementally.
Key Takeaway

Treat text as immutable. Use formatting for clarity and list-join for heavy concatenation.
