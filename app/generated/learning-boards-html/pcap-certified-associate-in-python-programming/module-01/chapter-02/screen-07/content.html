Logical operators

Use and, or, and not to combine boolean expressions into the rules your program enforces.

  • and: True only if both parts are True.
  • or: True if at least one part is True.
  • not: Reverses a boolean value.
Misconception
Using bitwise operators for logical checks can produce unexpected results; use logical operators for boolean logic.
Concrete scenario
Eligibility rule: a user is accepted if they are at least a minimum age and have confirmed terms. Model each requirement as a boolean and combine them with and to enforce both.
Key Takeaway

Booleans and logical operators let you express the rules that control program flow; keep expressions clear with parentheses.
