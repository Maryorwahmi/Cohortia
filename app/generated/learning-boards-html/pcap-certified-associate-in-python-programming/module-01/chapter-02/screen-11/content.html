Operators that compare

  • Use equality and inequality to check whether values match.
  • Use relational operators to compare magnitudes.
  • Chained comparisons can make range checks readable.
Common mistake
Confusing assignment and comparison leads to syntax errors or incorrect logic; use the equality comparison explicitly in conditionals.
Example
Check that a value falls between two bounds by chaining comparisons to avoid nested logical operators and improve readability.
Key Takeaway

Comparison operators produce booleans — use them in conditionals and never confuse the assignment operator with equality checks.
