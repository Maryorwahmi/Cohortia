Script structure

The following starter script shows the full flow: input, conversion, validation, calculation, and formatted output.

# bmi_calculator.py
print("--- BMI Calculator ---")
weight_str = input("Enter your weight in kilograms (e.g., 70.5): ")
height_str = input("Enter your height in meters (e.g., 1.75): ")
try:
  weight_kg = float(weight_str)
  height_m = float(height_str)
except ValueError:
  print("Error: Please enter valid numbers for weight and height.")
  exit()
if height_m <= 0:
  print("Error: Height cannot be zero or negative. Please enter a positive value.")
  exit()
bmi = weight_kg / (height_m ** 2)
print(f"Your calculated BMI is: {bmi:.2f}")
Exercise
Run the script with valid and invalid inputs, then add boolean range checks that classify the BMI and print simple True/False flags for overweight and healthy ranges.
Example outputs
Formatted weight and height lines and a BMI rounded to two decimals improve usability. Boolean checks show classification logic in action.
Key Takeaway

A single small script can exercise variables, types, operators, conversions, and conditionals together — a great test bed for learning.
