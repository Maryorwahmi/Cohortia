Safe casting patterns

Always verify or catch errors when converting user-provided text to numbers. Use explicit conversions to make intent clear.

  • int(value): convert numeric text without decimals to an integer.
  • float(value): convert decimal text to a floating-point number.
  • str(value): convert any value to text for display.
  • Wrap conversions in try/except to catch ValueError for invalid input.
Gotcha
Converting a non-numeric string raises ValueError; convert only after validation or handle the exception gracefully.
Walkthrough: safe conversion
# Pattern for converting user input
weight_str = input("Enter weight in kilograms: ")
try:
  weight_kg = float(weight_str)
except ValueError:
  print("Please enter a valid number for weight.")
  exit()
This pattern prevents the program from crashing and gives a clear message to the user about expected input.
Key Takeaway

Cast explicitly and handle exceptions for robust input parsing.
