Core Concept

print function parameters

Change how output joins values and whether a newline follows. These small controls improve readability.

Code examples
print("Hello", "World", sep='-')  # Hello-World
print("Line 1", end=' ')
print("Line 2")                 # Line 1 Line 2
print(1, 2, 3, sep='  ')        # columns separated by a tab
Explanation
  • print converts each argument to text before joining them.
  • Use sep to change the inserted string between values.
  • Use end to avoid or replace the default newline when continuing output.
Pro tip
Custom separators help when printing structured logs or CSV-like lines without extra formatting steps.
Key Takeaway

Small print parameters produce big improvements in how users read output.

Interactive example outputs
Simulated console:
# Example output
Hello-World
Line 1 Line 2
1	2	3
Common mistake
Expecting print to return a value. It only writes to standard output; it does not produce a usable return value.
Check your understanding
Change sep to a comma and end to an empty string to create inline comma-separated values without trailing newline.
