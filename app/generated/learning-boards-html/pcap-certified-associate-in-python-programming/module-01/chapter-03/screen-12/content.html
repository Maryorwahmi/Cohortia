Module 1 › Chapter 1.3 › Debugging I/O
Assessment Idea

Find and fix common errors

Practice by intentionally creating small failing examples and then correcting them.

Examples and fixes
  • TypeError from adding int and input string — fix by converting input with int().
  • FileNotFoundError when reading — handle with try-except or create file before reading.
  • Formatting mismatch — ensure placeholders align with provided arguments and types.
Common pitfall
Assuming user input is valid; always validate or catch exceptions and guide the user to correct input.
Check your work
After writing to a file, re-open it and read its content to verify persistence and correct formatting.
Quick debug checklist
  1. Confirm variable types before performing arithmetic.
  2. Verify file mode matches intent (r, w, a, x).
  3. Check formatting placeholders and arguments for count and type.
  4. Use try-except to catch and report IO or conversion errors.
Key Takeaway

Predictable mistakes are easy to fix: verify types, modes, and placeholders before assuming larger faults.
