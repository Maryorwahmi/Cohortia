Key Concepts

Three compact reminders from the chapter.

print / input
print formats console output; input returns text and must be converted for math.
String formatting
Prefer f-strings for clarity; format for templates; % for legacy compatibility.
File I/O best practice
Use with open and correct modes: r, w, a, x, and choose text or binary as needed.
Summary
These practices ensure clear program output, safe user input handling, and reliable data persistence.
