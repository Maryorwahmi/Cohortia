Learning Objectives

Four core skills to practice with short exercises and examples.

Bloom: Learn → Understand → Apply → Master
01
Obtain console input
Use the input function to prompt users and capture responses as text. Convert when arithmetic is needed so operations behave as expected.
VERIFIED COMPETENCY MILESTONE
02
Display readable output
Master print's sep and end to structure outputs cleanly for users and logs, avoiding awkward spacing and unwanted newlines.
VERIFIED COMPETENCY MILESTONE
03
Format strings professionally
Apply f-strings, str.format, or the percent operator to control precision, padding, and interpolation when presenting numbers or text.
VERIFIED COMPETENCY MILESTONE
04
Perform safe file I/O
Open files with the correct mode, read or append content, and use the with statement to avoid forgetting to close files.
VERIFIED COMPETENCY MILESTONE
