Comparison

Three formatting styles

Compare syntax, readability, and use cases with concrete examples.

Same output, three ways
# f-string
item = 'Laptop'
price = 1200.5
print(f"You purchased {2} {item}(s) for a total of ${price * 2:.2f}.")

# str.format()
print("You purchased {} {}(s) for a total of ${:.2f}.".format(2, item, price * 2))

# % operator
print("You purchased %d %s(s) for a total of $%.2f." % (2, item, price * 2))
When to use each
  • Prefer f-strings for modern, readable code and direct expression evaluation.
  • Use str.format for reusable templates or when you need named placeholders.
  • Reserve % for reading or maintaining older codebases.
Pro tip
For currency, format to two decimals to avoid confusing floating point output.
Formatting pitfalls
Common issues and contrasts
  • F-strings evaluate expressions immediately; they are not safe placeholders for late formatting in templates.
  • str.format allows re-ordering and named fields, useful for localization or complex templates.
  • The percent operator uses type-specific codes and can be less readable for complex expressions.
Key Takeaway

Choose f-strings for clear expression embedding; use format for templating needs and % only for legacy compatibility.
