Module 1 › Chapter 1.3 › Reading files
Core Concept

read, readline, iterate

Select a reading strategy that matches file size and processing needs to avoid memory issues.

Code examples
# Read whole file
with open("journal.txt", "r") as f:
  content = f.read()

# Read line by line
with open("journal.txt", "r") as f:
  line = f.readline()
  while line:
    print(line.strip())
    line = f.readline()

# Iterate over file (recommended for large files)
with open("journal.txt", "r") as f:
  for line in f:
    print(line.strip())
Memory note
read and readlines load the whole file into memory. Use iteration for large or unknown-size files.
Pro tip
Strip trailing newline characters before processing to avoid formatting surprises when printing.

Key Takeaway

Iterate for efficiency, read for simplicity; always strip whitespace before further processing.
