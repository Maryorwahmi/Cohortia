Definition

File modes explained

Understand each mode and the effect it has on the filesystem when opening a file.

r — read
Open an existing file for reading; fails if the file doesn't exist.
w — write
Create or truncate a file. Use carefully as this will erase previous contents.
a — append
Add new data at the end of the file. Creates the file if it doesn't exist.
x — exclusive create
Create a new file and fail if it already exists.
Practical guidance
Choose modes to avoid data loss
  • Use append when you want to keep historical data like logs or journals.
  • Use write only when replacing a file intentionally; consider backups first.
  • Combine modes with t (text) or b (binary) as appropriate for your data type.
Common mistake
Using write mode when you intended to append, which erases the file. Always double-check your chosen mode.
