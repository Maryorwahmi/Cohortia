Daily Journal flow

Add and view entries using append mode and safe reading patterns.

Core code snippet
def add_entry(date, content):
  formatted = f"Date: {date}
Entry: {content}
---
"
  with open("journal.txt", "a") as f:
    f.write(formatted)

def view_entries():
  try:
    with open("journal.txt", "r") as f:
      for line in f:
        print(line.strip())
  except FileNotFoundError:
    print("No journal entries found.")
Why this pattern
Appending preserves history and reading via iteration keeps memory use low while the with statement handles closing automatically.
Common mistake
Using write mode for appends will erase the journal; confirm mode before writing.
