12-minute live coding sequence

Follow these steps during a short demo to explain concepts clearly and consecutively.

Step 1: print demo
Show default print, then change sep and end to highlight output composition and line control.
Step 2: input and conversion
Prompt for values, attempt arithmetic on raw input to trigger the common error, then convert and correct it.
Step 3: formatting comparison
Render the same string with f-strings, str.format, and percent operator to compare readability and use cases.
Step 4: file I/O walkthrough
Show appending an entry, then reading entries back with iteration, and underline the use of with for safety.
Instructor checklist
  • Demonstrate output differences live so learners see immediate effect.
  • Trigger and fix the input conversion error to teach debugging.
  • Wrap file writes in with and verify persistence by re-opening the file.
