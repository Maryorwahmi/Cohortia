Precision and alignment

Use specifiers to control decimals and spacing so table output is tidy and consistent.

Table example code
items = [('Pen', 1.2), ('Notebook', 3.456), ('Backpack', 45)]
print(f"{'Item':<10} {'Price':>8}")
for name, price in items:
  print(f"{name:<10} ${price:8.2f}")

# Output shows names left-aligned and prices right-aligned to two decimals.
Explanation
  • {:<10} left-aligns a field in a width of ten characters.
  • {:8.2f} sets total width and two decimal places for floats.
  • Use named placeholders with format for clearer templates when needed.
Pro tip
Format output for humans while keeping raw numbers for calculations to avoid floating point surprises.
Example output
Item            Price
Pen            $    1.20
Notebook       $    3.46
Backpack       $   45.00
Key Takeaway

Use formatting specifiers to make numeric output precise and aligned; formatting does not change numeric values themselves.
