Module 1 › Chapter 1.3 › input() basics
Definition

input always returns text

Capture user responses as strings, then convert deliberately for numeric use.

Example code
name = input("What is your name? ")
year = input("Enter your birth year: ")
age = 2024 - int(year)
print(f"Hello, {name}! You are {age} years old.")
Explanation
  • input shows a prompt and returns user text including digits as characters.
  • Use int or float to convert when you need numbers for arithmetic.
  • Wrap conversions with try-except to handle invalid entries gracefully.
Common mistake
Attempting arithmetic on the raw input, which raises a TypeError because one operand is a string.
Validation & UX
Input best practices
  • Strip leading and trailing whitespace before converting.
  • Provide clear prompts so users know the expected format.
  • Use try-except to catch ValueError during conversion and re-prompt the user.
Key Takeaway

Treat input as text first; convert deliberately and validate to avoid runtime errors.
