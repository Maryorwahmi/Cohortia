Process Flow
Top-to-bottom evaluation
Conditions are checked in order. The first true condition executes and the rest are skipped, which affects both correctness and performance.
Step 1
Evaluate the if condition. If true, run block and stop.
Step 2
If the if was false, evaluate each elif in order until one is true.
Step 3
If none matched and an else exists, run else as a default.
Example — importance of order
score = 85
# Wrong: general check first hides specific result
if score >= 70:
  print("Passed")
elif score >= 80:
  print("Good")

# Correct: specific to general
if score >= 90:
  print("A")
elif score >= 80:
  print("B")
Misconception: placing a broad condition early can prevent more precise logic from running. Order is both a correctness and readability tool.
