Core Concept
Conditional expression
A lightweight inline if-else for assigning values concisely.
When to use
  • Single-line assignments based on a simple test.
  • Keep branches short and readable; avoid heavy nesting.
Example
age = 18
status = "Adult" if age >= 18 else "Minor"
print(status)
Misconception: using this for complex logic hurts readability. If branches do more than compute a value, prefer a block with named variables and comments.
