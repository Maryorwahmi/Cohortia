Grading example
def grade(score):
  if score >= 90:
    return "A"
  elif score >= 80:
    return "B"
  elif score >= 70:
    return "C"
  else:
    return "F"

print(grade(85))  # prints B
Test edge values like 90 and 80 to see how ordering determines the returned grade.
Age and consent example
age = 16
has_parental_consent = True

if age >= 18 and has_parental_consent:
  print("Access granted")
else:
  print("Access denied")
Short-circuit: if age is below the threshold, the consent check is not needed. Verify with tests for ages 17 and 18 to observe different outputs.
