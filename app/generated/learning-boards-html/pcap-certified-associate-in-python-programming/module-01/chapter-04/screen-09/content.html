Definition
pass — a no-op placeholder
Use pass to keep a block present when logic is unfinished. It's a development aid, not a final behavior.
When to use
  • Sketching program flow before implementation.
  • Keeping conditionals syntactically valid while building other parts.
Example
if feature_enabled:
  # TODO: implement advanced path
  pass
else:
  print("Default behavior")
Pro tip: add a TODO comment or raise an explicit exception if the branch must not remain unimplemented.
