Comparison
and, or, not
Use these operators to express compound conditions without deep nesting.
and
True only if both parts are true. Short-circuits on first false.
or
True if either part is true. Short-circuits on first true.
not
Inverts truth value; use to negate a condition cleanly.
Tip
Use parentheses to group complex expressions and avoid precedence surprises.
Concrete example
temperature = 25
is_raining = True

if temperature > 20 and not is_raining:
  print("Perfect day for a picnic")
elif temperature > 20 and is_raining:
  print("Warm but raining; indoor options")
else:
  print("Chilly or cloudy; stay warm")
Misconception: expect and/or to always return True or False. They return one of the operands; use them with truthiness in mind.
