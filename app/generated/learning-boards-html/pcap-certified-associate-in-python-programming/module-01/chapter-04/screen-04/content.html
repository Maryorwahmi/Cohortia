Core Concept
If, Elif, Else
A chain of tests where the first true branch runs once. Maintain ordering from specific to general.
Explanation
  • if evaluates a condition and runs its indented block only when true.
  • elif provides an additional test only reached if previous conditions were false.
  • else runs when no prior tests succeeded, acting as a default path.
Concrete example
Grade selection based on numeric score using descending thresholds.
Key Takeaway

Order matters. Use elif when you want mutually exclusive branches and avoid separate ifs for the same decision.

Code example
score = 85
if score >= 90:
  print("Grade: A")
elif score >= 80:
  print("Grade: B")
elif score >= 70:
  print("Grade: C")
else:
  print("Grade: F")
Misconception
Using separate if statements here would allow multiple prints; use elif to enforce exclusivity.
