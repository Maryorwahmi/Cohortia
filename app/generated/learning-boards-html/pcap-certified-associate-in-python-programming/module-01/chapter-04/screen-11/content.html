Mistakes to avoid
  • Using assignment where you meant to compare; think carefully about intent.
  • Mixing tabs and spaces or misaligned blocks causing IndentationError or logic shifts.
  • Deep nesting; prefer helper functions or combined conditions to keep branches clear.
  • Assuming truthiness safe for all domain values; use explicit tests when needed.
Practical debugging tips
- Add small print statements to confirm which branch executed during manual testing.
- Write unit tests that exercise each branch with representative inputs.
- Configure your editor to show whitespace and convert tabs to spaces automatically.
- Use linters to flag suspicious conditionals and unreachable code.
