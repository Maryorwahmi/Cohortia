Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Implement branching with if, elif, else
Write conditional blocks that run only when their condition is true. This lets programs react differently to input and state.
VERIFIED COMPETENCY MILESTONE
Mnemonic: a folded decision tree — only one branch executes at a time.
02
Master indentation for blocks
Indentation defines which statements belong to which conditional. Consistent spacing prevents errors and logic bugs.
VERIFIED COMPETENCY MILESTONE
Mnemonic: indentation is the boundary, like braces in other languages.
03
Combine conditions with logical operators
Use and, or, and not to express compound rules without nested ifs.
VERIFIED COMPETENCY MILESTONE
Mnemonic: think Boolean algebra — both, either, or invert.
04
Recognize truthiness and falsiness
Treat empty containers, zero, and None as false in conditions to write concise checks.
VERIFIED COMPETENCY MILESTONE
Mnemonic: empty equals false, anything else is true unless explicitly false.
