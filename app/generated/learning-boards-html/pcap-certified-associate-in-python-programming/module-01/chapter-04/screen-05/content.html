Definition
Indentation matters
Blocks are formed by consistent indentation. Misaligned lines change which code runs together and often cause errors.
Common mistakes
  • Mixing tabs and spaces; use spaces only.
  • Incorrect indentation level that moves statements out of blocks.
  • Excessive nesting that reduces readability.
Common mistake

An IndentationError or altered logic often indicates inconsistent spacing or a misplaced line.

Example and check
if user_is_admin:
    print("Welcome, admin")
    print("You have full access")
print("This always runs")
If the final print is indented, it would run only for admins. Keep block levels visually consistent. Configure your editor to show invisible characters and set tabs to insert spaces.
