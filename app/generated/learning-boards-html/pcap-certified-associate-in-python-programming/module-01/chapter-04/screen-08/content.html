Definition
Truthiness and Falsiness
Python treats certain non-boolean values as false in boolean contexts. Knowing which ones saves comparisons.
Common falsy values
  • False, None
  • 0, 0.0
  • "" (empty string)
  • [] , (), {}, set() (empty containers)
Pro tip

Use direct truthiness checks for brevity, but test explicitly when zero and empty mean different things.

Examples
if my_list:
  print("List has items")

if not user_input:
  print("No input provided")

# Numeric zero is falsy
if score:
  print("Non-zero score")
else:
  print("Score is zero or missing")
Misconception: a list containing zero is truthy. It's non-empty, so the direct check will be true.
