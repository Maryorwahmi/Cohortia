Module 5 › Chapter 5.4 › Method Overriding
Definition

Override or extend a parent method

Decide whether you replace behavior or call the parent and add to it.

class Employee:
    def __init__(self, name, id):
        self.name = name
        self.id = id

    def display_info(self):
        return f"Name: {self.name}, ID: {self.id}"

class Manager(Employee):
    def __init__(self, name, id, department):
        super().__init__(name, id)
        self.department = department

    def display_info(self):
        parent_info = super().display_info()
        return f"{parent_info}, Department: {self.department}"
Explanation
  • Manager extends Employee.display_info by calling super().display_info() and adding department data.
  • This avoids duplicating the name and id formatting in multiple subclasses.
  • If the parent method enforces invariants, call it first before adding extra behavior.
Pro tip
When extending, keep the order clear: parent initialization or behavior then subclass additions to avoid unexpected state.
Key Takeaway

Use overriding to specialize, and super to preserve and extend shared behavior without duplication.
