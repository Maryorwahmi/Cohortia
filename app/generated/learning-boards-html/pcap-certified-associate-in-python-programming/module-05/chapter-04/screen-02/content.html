Learning Objectives

Learn, understand, apply, and master core OOP patterns in Python

Bloom: Learn → Understand → Apply → Master
01
Explain Inheritance

Describe how subclasses derive attributes and methods from superclasses and model "is-a" relationships.

Mnemonic: family-tree Venn
VERIFIED COMPETENCY MILESTONE
02
Implement Single Inheritance

Write subclasses that call the parent constructor and add or override attributes and methods.

Mnemonic: constructor chain
VERIFIED COMPETENCY MILESTONE
03
Override and Extend Methods

Use method overriding to specialize behavior and super() to extend parent functionality safely.

Mnemonic: replace or extend
VERIFIED COMPETENCY MILESTONE
04
Understand Polymorphism

Recognize duck typing and write functions that call the same method across different types.

Mnemonic: quacks like a duck
VERIFIED COMPETENCY MILESTONE
