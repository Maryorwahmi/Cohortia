Definition

Multiple inheritance basics

A class can inherit from more than one parent, combining behaviors from each.

class Flyer:
    def fly(self):
        return "I can fly!"

class Swimmer:
    def swim(self):
        return "I can swim!"

class Duck(Flyer, Swimmer):
    def quack(self):
        return "Quack!"
Practical notes
  • Method Resolution Order (MRO) decides which parent method is used when methods collide.
  • Diamond-shaped hierarchies can be confusing; test combined behavior carefully.
  • Prefer composition or single inheritance unless multiple inheritance clearly simplifies the design.
Caveat
Multiple inheritance is powerful but can hide where a method originates. Use it with restraint and clear tests.
Key Takeaway

Multiple inheritance combines behaviors from multiple parents but requires care around method lookup and design clarity.
