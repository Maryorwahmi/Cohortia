Core Concept

Inheritance: reuse and hierarchy

Inheritance lets a subclass gain the attributes and behaviors of a superclass while allowing specialization.

How it works
  • Subclass inherits parent's attributes and methods unless overridden.
  • Lookup falls back to the parent when a name isn't found in the child.
  • Use inheritance when you have a clear "is-a" relationship.
Common misconception

Inheriting just to reuse code is risky if the classes do not model the same concept. Prefer composition if the relationship is "has-a" instead of "is-a."

Key Takeaway

Use inheritance to express specialization and reuse only when the subclass truly is a subtype of the parent.

Concrete example
class Animal:
    def __init__(self, name):
        self.name = name

    def eat(self):
        return f"{self.name} is eating."

class Dog(Animal):
    def fetch(self):
        return f"{self.name} is fetching the ball!"

# dog inherits name and eat() from Animal
Analogy
Think of a base blueprint and a specialized copy that adds features.
Check your understanding
Does your subclass really represent a more specific kind of the parent?
