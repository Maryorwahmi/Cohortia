Module 5 › Chapter 5.4 › Single Inheritance & super()
Process

Call parent constructors with super

Follow this pattern to ensure inherited attributes exist and avoid initialization bugs.

class Animal:  # Superclass
    def __init__(self, name):
        self.name = name

    def speak(self):
        raise NotImplementedError("Subclass must implement abstract method")

class Dog(Animal):  # Subclass
    def __init__(self, name, breed):
        super().__init__(name)  # initialize parent state
        self.breed = breed

    def speak(self):
        return f"{self.name} says Woof!"
Common mistake

Omitting super().__init__ leaves name uninitialized and can cause attribute errors when methods expect it.

Example behavior

After calling super, Dog instances have name and breed; they reuse eat() from Animal if present and override speak().

Scenario

Imagine a library expects every animal to have a name. Using super in your subclass guarantees that expectation is met.

  2. Are attributes referenced by methods initialized in the chain?
