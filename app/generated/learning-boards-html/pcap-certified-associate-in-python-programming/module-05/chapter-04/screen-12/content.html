Module 5 › Chapter 5.4 › Shape Demo & Polymorphism
Example Code
rectangle = Rectangle("Blue", 10, 5)
circle = Circle("Red", 7)

print(f"Rectangle color: {rectangle.get_color()}")
print(f"Rectangle area: {rectangle.area()}")
print(f"Rectangle perimeter: {rectangle.perimeter()}")

print(f"Circle color: {circle.get_color()}")
print(f"Circle area: {circle.area()}")
print(f"Circle perimeter: {circle.perimeter()}")

shapes = [rectangle, circle]
for shape in shapes:
    print(f"
Processing a {shape.get_color()} shape:")
    print(f"  Area: {shape.area():.2f}")
    print(f"  Perimeter: {shape.perimeter():.2f}")
What to verify
  • Colors print correctly: super set the color attribute.
  • Numeric outputs match expected formulas: width*height for rectangle, pi*r**2 for circle.
  • The loop calls area() and perimeter() on each object without checking its type.
Debug tip
If a method is missing, inspect shape.__class__ and shape.__class__.__mro__ to confirm the class and lookup order.
Key Takeaway

Running the demo proves both correct initialization via super and polymorphism when processing mixed objects uniformly.
