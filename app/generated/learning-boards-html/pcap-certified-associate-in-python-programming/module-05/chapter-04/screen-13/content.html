Module 5 › Chapter 5.4 › Debugging Inheritance
Common Mistakes
  • Omitted super().__init__ in subclass constructors.
  • Passing objects that lack the expected method for duck-typed calls.
  • Unexpected method lookup in complex multiple inheritance hierarchies.
Quick fixes
Call super in constructors, add unit tests for polymorphic code, and inspect Class.__mro__ for lookup order.
Practical steps
  1. Reproduce the issue with minimal code.
  2. Print instance.__class__ and instance.__class__.__mro__.
  3. Adjust constructors or refactor to composition if needed.
  4. Add tests that call the shared method on mixed objects to catch regressions early.
Warning

Avoid deep or unrelated inheritance; it increases cognitive load and makes bugs harder to isolate.
