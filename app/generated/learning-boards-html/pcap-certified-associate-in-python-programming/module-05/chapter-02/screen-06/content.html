Module 5 › Chapter 5.2 › Shadowing
Side-by-side: intention vs effect
  • Intended: change default for every object -> assign on class.
  • Accidental effect: assign on instance -> instance-only override created.
  • Result: inconsistent behavior across objects, harder to test.
Debug tip: inspect instance.__dict__ to see which attributes are per-instance.
Example
class Employee:
  raise_amount = 1.04

emp = Employee()
Employee.raise_amount = 1.05   # affects all
emp.raise_amount = 1.02       # creates instance attribute; emp now differs

print(Employee.raise_amount)  # 1.05
print(emp.raise_amount)       # 1.02
Use a class method to change raise_amount intentionally for all employees.
