When to use static methods
  • When a function relates to the class conceptually but needs no class or instance data.
  • Keep code organized by grouping related utilities inside the class.
  • Prefer module-level functions if they are broadly useful outside the class.
Example use: conversions, validations, or calculations that don't require state.
Example: MathUtil
class MathUtil:
  @staticmethod
  def add(x, y):
    return x + y

  @staticmethod
  def is_even(number):
    return number % 2 == 0

print(MathUtil.add(5,3))   # 8
print(MathUtil.is_even(4)) # True
These methods are simple utilities that belong conceptually to MathUtil but do not use self or cls.
