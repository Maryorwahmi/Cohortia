Module 5 › Chapter 5.2 › Key Concepts
Instance attribute
Per-object state defined via self, unique to each instance.
Class attribute
Shared value declared on the class body; update via the class or a class method.
Method types
Instance (self), Class (cls), Static (neither) — choose based on data access needs.
Takeaway

Decide where data belongs and which method type to use by asking simple questions about scope and access. That clarity prevents bugs and improves maintainability.
