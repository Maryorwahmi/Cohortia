Module 5 › Chapter 5.2 › Attribute Access
Rules and tips
  • Reading: Python checks instance __dict__, then class attributes.
  • Writing on class changes value for everyone who has not shadowed it.
  • Writing on instance creates/updates that instance attribute only.
  • Prefer ClassName.attr = value to make intent clear for shared data.
Pro tip: Use class methods to modify shared state so subclasses can override behavior via cls.
Run-through code
class Config:
  MAX_CONNECTIONS = 10

config1 = Config()
config2 = Config()

Config.MAX_CONNECTIONS = 20       # update on class
config1.MAX_CONNECTIONS = 5      # creates instance attribute for config1

print(Config.MAX_CONNECTIONS)    # 20
print(config1.MAX_CONNECTIONS)   # 5 (instance attribute shadows class)
print(config2.MAX_CONNECTIONS)   # 20 (still reads class attribute)
This pattern helps you recognize when an unexpected instance assignment created a shadowed attribute.
