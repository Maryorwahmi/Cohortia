Module 5 › Chapter 5.2 › Method Choice
Instance
Use when the method operates on per-object state. Example: car.accelerate().
Class
Use when the method needs to operate on or create instances of the class. Example: Employee.from_string().
Static
Use for utilities unrelated to class or instance data. Example: MathUtil.is_even().
Check your reasoning
If you hesitate, write the function outside the class first. If its purpose is tightly linked to the class concept, move it in as a static method. If it needs class awareness later, refactor to @classmethod.
