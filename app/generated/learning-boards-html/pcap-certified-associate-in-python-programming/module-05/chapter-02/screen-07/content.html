Module 5 › Chapter 5.2 › Instance Methods
When to use
  • Modify or read data specific to this object.
  • Implement behaviors like accelerate, apply_raise, display_temperature.
  • Prefer clear single-responsibility methods that change object state only when necessary.
Misconception: instance methods cannot access class data — they can, via lookup fallback, but changing shared data from an instance is not recommended.
Example: Car
class Car:
  wheels = 4

  def __init__(self, make, model):
    self.make = make
    self.model = model
    self.speed = 0

  def accelerate(self, increment):
    self.speed += increment
    print(f"{self.make} {self.model} is now at {self.speed} km/h.")

c = Car('Toyota','Corolla')
c.accelerate(30)  # updates only c.speed
Observe how accelerate updates a single object's internal speed without touching class attributes.
