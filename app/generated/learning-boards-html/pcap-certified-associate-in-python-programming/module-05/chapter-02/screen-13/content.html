Simple organization checklist
  1. Does it need instance data? -> instance method.
  2. Does it create or alter class-level behavior? -> class method.
  3. Is it a pure utility? -> static method or module function.
Example split
Company class holds company_name as class attribute; Employee instances hold employee_id. Order factory functions use class methods for from_json constructors; tax calculations are static utilities.
