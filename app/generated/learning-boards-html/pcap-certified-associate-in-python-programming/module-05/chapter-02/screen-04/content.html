Module 5 › Chapter 5.2 › Instance vs Class
Core definitions
Instance attribute: created per object inside the constructor and accessed through the instance using self. Class attribute: declared in the class body and shared by all instances unless shadowed.
Example: Dog class with name and breed as instance attributes, species as class attribute.
Misconception: Assigning to instance changes class value — false. It creates a new instance attribute.
Key Takeaway

If a value varies per object, make it an instance attribute; if it is constant across kind, declare it on the class.

Concrete example (read-only)
# Instance vs class attributes
class Dog:
  species = 'Canis familiaris'  # class attribute

  def __init__(self, name, breed):
    self.name = name            # instance attribute
    self.breed = breed

buddy = Dog('Buddy', 'Golden')
lucy = Dog('Lucy', 'Labrador')

print(buddy.species)  # Canis familiaris
print(lucy.species)   # Canis familiaris

buddy.species = 'Felis catus'  # creates instance attribute; does not change Dog.species
print(Dog.species)    # Canis familiaris
print(buddy.species)  # Felis catus
Example shows how assigning on buddy shadows the class attribute for that instance only.
