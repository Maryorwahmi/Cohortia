Module 6 › Chapter 5.6 › Method Overriding
Inheritance and specialization
class Animal:
  def speak(self):
    raise NotImplementedError("Subclasses must implement speak")

class Dog(Animal):
  def speak(self):
    return "Woof!"

class Cat(Animal):
  def speak(self):
    return "Meow!"
Here the base class declares the method and the subclasses override with concrete implementations, allowing polymorphic use via the shared API.
Notes & common pitfalls
  • Remember to call super() when you need to preserve base class behavior during override.
  • Use NotImplementedError in base methods to clearly indicate required overrides when not using ABCs.
  • Overriding without consistent signatures can break callers; keep parameters compatible.
Key Takeaway

Use overriding to specialize behavior while preserving a predictable interface for callers.
