Module 6 › Chapter 5.6 › TypeError & Pitfalls
Typical TypeError
When a subclass fails to implement all abstract methods, instantiation fails with a clear message identifying the missing methods.
Example error:
TypeError: Can't instantiate abstract class Shape with abstract methods area, perimeter
Debug steps
  1. Read which abstract methods are missing from the TypeError.
  2. Ensure subclass methods have the same name and parameter signatures.
  3. Confirm imports: from abc import ABC, abstractmethod.
Common mistakes
Missing method implementations, mismatched signatures, and forgetting to inherit from ABC cause TypeError on instantiation.
Pro tip
Add unit tests that instantiate each concrete class and call required methods to catch abstract contract violations early.
Key Takeaway

Use the TypeError message as a direct pointer to missing implementations; keep signatures consistent and test instantiation in CI.
