Module 6 › Chapter 5.6 › Operator Overloading
Comparison: built-in vs custom
# Built-in polymorphism
1 + 2        # 3  (numeric addition)
'hello' + 'world'  # 'helloworld' (string concatenation)

# Customizing in a class
class Vector:
  def __init__(self, x, y):
    self.x = x
    self.y = y
  def __add__(self, other):
    return Vector(self.x + other.x, self.y + other.y)
When you implement __add__, the plus operator expresses vector addition in a natural way for that domain.
Guidelines
  • Overload operators only when the meaning is obvious and consistent.
  • Document semantics and expected operand types to prevent surprises.
  • Follow Python conventions: prefer returning new objects for immutable semantics.
Pro tip
Implement __repr__ or __str__ so debugging and interactive use are easier when you overload operators.
Key Takeaway

Operator overloading offers expressive domain modelling but must be used judiciously and documented clearly.
