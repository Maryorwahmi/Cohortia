Key Concepts
Polymorphism
Objects respond to shared method calls in their own way.
Duck Typing
Behavior-based compatibility: methods matter more than declared types.
Method Overriding
Subclasses provide specific implementations of base class methods.
Quick tip
Document expected method names and signatures when you rely on duck typing, and add tests to ensure concrete implementations behave correctly.
Summary
Use polymorphism for flexible code; use ABCs when you need to enforce an interface across implementations.
