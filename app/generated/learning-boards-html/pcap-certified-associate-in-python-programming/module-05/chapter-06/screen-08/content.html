ABC Fundamentals
Use the abc module and @abstractmethod to declare methods that must be implemented by subclasses.
from abc import ABC, abstractmethod

class Shape(ABC):
  @abstractmethod
  def area(self):
    pass

  @abstractmethod
  def perimeter(self):
    pass
Attempting to instantiate Shape will raise a TypeError until concrete subclasses implement all abstract methods.
Why use ABCs?
  • Catch missing implementations at class instantiation time rather than later at runtime.
  • Provide a clear interface contract for teams and plugin architectures.
  • Allow shared concrete methods in the abstract class while enforcing key methods.
Key Takeaway

Choose ABCs to formalize behavior contracts when you need safety and clarity across implementations.
