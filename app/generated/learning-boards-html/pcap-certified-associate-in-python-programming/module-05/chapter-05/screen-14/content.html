Module 5 › Chapter 5.5 › Key Concepts
Abstraction
Expose essential behavior, hide internal details.
Abstract Base Class (ABC)
A class that can declare abstract methods and cannot be instantiated until implemented.
Abstract Method
Marked with @abstractmethod; subclasses must implement it to become concrete.
Takeaway
Design ABCs for the essential contract, implement concrete subclasses that satisfy the contract, and use shared concrete methods to avoid duplication.
