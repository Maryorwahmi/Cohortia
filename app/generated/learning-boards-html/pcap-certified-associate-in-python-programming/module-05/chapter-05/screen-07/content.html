Module 5 › Chapter 5.5 › Instantiation & TypeError
Attempt to instantiate
# This will raise a TypeError
processor = PaymentProcessor()

# Example error message:
# TypeError: Can't instantiate abstract class PaymentProcessor with abstract methods process_payment, refund_payment
The error lists the abstract methods still missing.
Developer workflow
  • Read the TypeError to find missing methods.
  • Implement all abstract methods in the subclass.
  • Re-run instantiation to confirm the class is now concrete.
  • Use tests to ensure implementations meet the contract expectations.
Misconception

A subclass with missing abstract methods is not an incomplete concrete class — it is still abstract and cannot be instantiated.
