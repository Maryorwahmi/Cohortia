Module 5 › Chapter 5.5 › Abstract Base Classes
What is an ABC?
A class that defines required methods and cannot be instantiated until they are implemented.
How to create one
Inherit from ABC and use @abstractmethod for required methods.
Rule
Missing implementation of any abstract method makes the subclass abstract as well and uninstantiable.
Design tip
Keep abstract methods minimal — they represent the essential contract.
Example snippet
from abc import ABC, abstractmethod

class PaymentProcessor(ABC):
    @abstractmethod
    def process_payment(self, amount):
        pass

    @abstractmethod
    def refund_payment(self, transaction_id):
        pass

    def get_processor_name(self):
        return "Generic Payment Processor"
This ABC declares two required methods and one concrete helper.
