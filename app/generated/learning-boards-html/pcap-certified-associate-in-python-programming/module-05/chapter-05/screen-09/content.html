PayPalProcessor example
class PayPalProcessor(PaymentProcessor):
    def process_payment(self, amount):
        print(f"Processing PayPal payment of ${amount}.")
        return f"PP_TRANS_{amount}_XYZ"

    def refund_payment(self, transaction_id):
        print(f"Refunding PayPal transaction: {transaction_id}.")
        return True

# Polymorphism demo
cc = CreditCardProcessor()
pp = PayPalProcessor()
processors = [cc, pp]
for p in processors:
    print(f"Using {p.get_processor_name()}:")
    trans_id = p.process_payment(25.00)
    p.refund_payment(trans_id)
Practices
  • Test each concrete implementation independently to verify the contract behavior.
  • Use lists or registries of processors to operate polymorphically in client code.
  • Maintain consistent method signatures to ensure substitutability.
Key Takeaway

Design interfaces once and implement many ways; client code stays unchanged when implementations vary.
