collections.abc example
ABCs in the standard library define expected behaviors like iteration, sizing, and mapping.
Iterable
Defines the protocol for objects that can be iterated over.
Mapping
Specifies methods expected of mapping types like dictionaries.
Architectural benefit
  • Defines capabilities your code can depend on.
  • Makes it easier to swap implementations that honor the same interface.
  • Provides a formal way to express duck-typed behavior across a project.
Design reminder

Use ABCs to document and enforce capabilities that other code relies on, not to force implementation details.
