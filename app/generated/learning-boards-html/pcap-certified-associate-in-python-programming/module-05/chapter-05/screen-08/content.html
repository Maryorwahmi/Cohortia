Concrete class example
class CreditCardProcessor(PaymentProcessor):
    def process_payment(self, amount):
        print(f"Processing credit card payment of ${amount}.")
        return f"CC_TRANS_{amount}_ABC"

    def refund_payment(self, transaction_id):
        print(f"Refunding credit card transaction: {transaction_id}.")
        return True

    def get_processor_name(self):
        return "Credit Card Processor"

# Instantiate and use
cc = CreditCardProcessor()
print(cc.get_processor_name())
cc.process_payment(100.50)
Notes
  • Signature must match the abstract method so Python recognizes it as implemented.
  • Override concrete helper methods only when specialization is needed.
  • Concrete classes enable polymorphism: different processors can be used interchangeably.
Key Takeaway

A concrete subclass completes the contract and becomes instantiable; this is how you provide specific behavior behind an abstract API.
