Starter template
from abc import ABC, abstractmethod
import datetime

class Logger(ABC):
    @abstractmethod
    def log_message(self, message):
        pass

    @abstractmethod
    def close_logger(self):
        pass

    def get_logger_type(self):
        return "Abstract Logger"

# Implement ConsoleLogger and FileLogger following the template in the chapter.
Checklist
  • Logger inherits from ABC and declares two abstract methods.
  • ConsoleLogger prints messages with timestamps and closes with a message.
  • FileLogger opens a file in append mode, writes timestamped lines, flushes, and closes the file in close_logger.
  • Call close_logger on each logger to avoid leaking file handles.
Safety note

Ensure FileLogger.close_logger closes the file to prevent resource leaks. Flush after writes when necessary.
