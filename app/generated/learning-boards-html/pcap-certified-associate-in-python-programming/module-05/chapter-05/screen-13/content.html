Example from chapter
from abc import ABC, abstractmethod

class Device(ABC):
    def __init__(self, name):
        self.name = name

    @abstractmethod
    def turn_on(self):
        pass

    def get_name(self):
        return self.name

class Light(Device):
    def __init__(self, name, brightness):
        super().__init__(name)
        self.brightness = brightness

    def turn_on(self):
        print(f"{self.name} light is ON at {self.brightness}% brightness.")

class Fan(Device):
    def __init__(self, name, speed):
        super().__init__(name)
        self.speed = speed

    # Missing turn_on implementation!
Debugging steps
  • Read the TypeError to identify which abstract methods are missing.
  • Implement methods with exactly the expected signature.
  • Add unit tests that instantiate concrete classes to catch missing methods early.
Misconception

Having similar method names or partial implementations does not satisfy the abstract contract; the method must exist with the correct signature.
