Abstract Classes and Interfaces
Define contracts with abc, then implement them in concrete subclasses.

Abstraction exposes essential behavior and hides implementation. Python's abc module formalizes that abstraction: an abstract class can declare methods without implementing them and require subclasses to provide concrete implementations.

This prevents accidental creation of objects that are not fully implemented. You will see code examples that demonstrate these rules and common mistakes, plus a hands-on Logger activity to practice designing an ABC and two concrete loggers.

Why this matters
