Module 5 › Chapter 5.5 › Quick Reminders
Use abc
Inherit from ABC and use @abstractmethod for required methods.
Implement all methods
A missing abstract method keeps a class abstract and uninstantiable.
ABCs as interfaces
Think of ABCs as contracts you can rely on across implementations, like collections.abc.
Final takeaway
Declare essential behavior, enforce it with ABCs, and implement concrete classes responsibly to create predictable, maintainable systems.
