PaymentProcessor (definition)
from abc import ABC, abstractmethod

class PaymentProcessor(ABC):
    @abstractmethod
    def process_payment(self, amount):
        """Abstract method to process a payment."""
        pass

    @abstractmethod
    def refund_payment(self, transaction_id):
        """Abstract method to refund a payment."""
        pass

    def get_processor_name(self):
        return "Generic Payment Processor"
Explanation and tips
  • Inherit from ABC to mark a class as abstract.
  • @abstractmethod means the method must be overridden by concrete subclasses.
  • Concrete methods in an ABC provide shared utilities and are optional to override.
  • Include docstrings for implementers to clarify expected inputs, outputs, and side effects.
Common mistake

Trying to instantiate PaymentProcessor directly will raise a TypeError because abstract methods remain unimplemented.
