Common errors and fixes
Missing self
Symptom: TypeError because the method received the instance but the definition did not expect it. Fix by adding self as the first parameter.
Constructor mismatch
Symptom: TypeError about missing arguments. Fix by calling class with correct parameters or providing defaults in __init__.
Shared mutable state
Symptom: Lists or dicts appear shared across instances. Fix by initializing mutable attributes inside __init__.
Debugging pattern
Reproduce the issue with minimal code, inspect attributes on two instances, and read the error trace to find the problematic line.
Quick test
Create buddy and lucy, add a trick to buddy, then print both tricks lists to ensure separation of state.
