__init__ (Constructor)
Automatically initializes instance attributes to set the object's initial state.
Mutability caution
Keep mutable per-instance data inside __init__ to avoid shared lists or dicts across objects.
Test pattern
Create multiple instances and run small interactions to confirm expected behavior.
Closing takeaway
OOP helps model real systems. Practice by building small classes, focusing on clear attribute scope, and testing instance independence.
