__init__ explained
Initialize instance attributes reliably
Role of __init__
Set up per-instance state, validate inputs if needed, and provide sensible defaults like empty lists or False flags.
Good practice
Accept required parameters explicitly and initialize complex defaults within __init__ to avoid shared state.
Avoid
Don't use mutable objects as class-level defaults when they should be instance-specific.
Example — Book initialization
class Book:
    def __init__(self, title, author, isbn):
        self.title = title
        self.author = author
        self.isbn = isbn
        self.is_checked_out = False
This constructor ensures every Book starts with a False checked-out status.
