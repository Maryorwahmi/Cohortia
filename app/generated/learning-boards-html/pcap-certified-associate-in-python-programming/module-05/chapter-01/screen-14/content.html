Class Design Checklist
A compact workflow to create clean classes
1. Name and responsibility
Pick a clear class name and limit its role to a single responsibility.
2. Attribute scope
Decide which attributes are shared and which are per instance.
3. Initialize state
Use __init__ for per-instance attributes and complex defaults.
4. Focused methods
Keep methods small and operate via self to modify instance state.
5. Test with examples
Create two instances and exercise methods to confirm expected behavior and independence.
Quick reminder
Start simple, then extend. Use tests and small examples to validate design choices early.
