Module 5 › Chapter 5.1 › Key Concepts
Object-Oriented Programming
A paradigm that structures programs around objects combining data and behavior.
Class
A blueprint that defines attributes and methods for its objects.
Object (Instance)
A concrete entity created from a class with its own attribute values.
Attribute
A variable associated with a class or instance representing state.
Method
A function defined on a class that describes behavior and often uses self.
self
The conventional first parameter in instance methods that refers to the specific object.
Summary takeaway
Use classes to model domain entities, initialize per-instance state in __init__, and access state and behavior through self and dot notation.
