Module 5 › Chapter 5.1 › Anatomy of a Class
Class structure
Design attributes and methods intentionally
Class attributes
Shared across instances; useful for constants or values common to all objects.
Constructor (__init__)
Sets up per-instance state like name, breed, or a list for tricks.
Instance methods
Operate on instance data using the self parameter, implementing behavior like bark or display_status.
Example anatomy
class Dog:
    species = "Canis familiaris"   # class attribute

    def __init__(self, name, breed):  # constructor
        self.name = name              # instance attribute
        self.breed = breed
        self.tricks = []

    def bark(self):                  # instance method
        return f"{self.name} says Woof!"
Key takeaway
Plan attributes first, then implement constructor and methods that operate on that state through self.
