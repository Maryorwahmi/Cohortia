Classes and Instances
Understand shared vs. per-object state
Class (blueprint)
Defines attributes and methods that objects will have. Example: Dog defines breed and bark behavior.
Object (instance)
A concrete entity created from the class. Example: buddy is a Dog with a specific name and tricks.
Code example
class Dog:
    species = "Canis familiaris"  # class attribute

    def __init__(self, name):
        self.name = name            # instance attribute

buddy = Dog("Buddy")
print(Dog.species)  # shared
print(buddy.name)   # per-instance
Key takeaway
Decide if a value is shared or unique, then place it at class or instance level accordingly.
