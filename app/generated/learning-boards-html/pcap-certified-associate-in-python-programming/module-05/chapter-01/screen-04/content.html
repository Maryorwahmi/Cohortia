Module 5 › Chapter 5.1 › What is OOP?
Definition and analogy
Think of classes as blueprints and objects as built things.
Definition
Objects combine state and behavior. A class is a template for creating such objects in Python, where attributes represent data and methods represent actions.
Analogy
A LEGO mold produces many similar blocks; a class produces many similar objects, each configured with its own pieces and stickers.
Common misconception
OOP is not only about inheritance. Many problems are solved with simple classes and composition; inheritance is one tool among several.
Concrete example — Dog class
class Dog:
    species = "Canis familiaris"

    def __init__(self, name, breed):
        self.name = name
        self.breed = breed
        self.tricks = []

    def bark(self):
        return f"{self.name} says Woof!"
This example shows class attributes, instance attributes initialized in the constructor, and a simple method that uses instance state.
Key takeaway
Model the things you care about; keep related data and behavior together for clarity and reuse.
