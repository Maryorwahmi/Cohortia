Create and use objects
A step-by-step code walkthrough
Run this example
buddy = Dog("Buddy", "Golden Retriever")
lucy = Dog("Lucy", "Labrador")

print(f"{buddy.name} is a {buddy.breed}.")
print(buddy.bark())

buddy.learn_trick("roll over")
print(buddy.tricks)
print(lucy.tricks)
Observe that buddy and lucy have independent tricks lists and the same species value when printed via the class.
Concrete example output
Buddy is a Golden Retriever. Buddy says Woof! ['roll over'] []
Key takeaway
Use dot notation to inspect and call methods; test interactions with two instances to confirm independence.
