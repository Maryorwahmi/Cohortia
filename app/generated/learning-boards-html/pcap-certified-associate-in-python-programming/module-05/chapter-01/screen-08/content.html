Class attribute vs instance attribute
Choose scope carefully to avoid shared-state bugs
Class attribute
Defined in class body. Shared across instances. Good for constants or values common to all objects.
Instance attribute
Created in __init__ via self. Unique to each instance. Required for per-object state, especially mutable collections.
Illustration
class Dog:
    species = "Canis familiaris"  # class attribute

    def __init__(self, name):
        self.name = name             # instance attribute
        self.tricks = []             # instance-level mutable list
If tricks were defined at class level, all dogs would share the same list.
Common mistake
Defining mutable attributes at the class level causes unexpected sharing between instances. Initialize such attributes inside __init__ instead.
