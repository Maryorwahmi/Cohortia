Understanding self
A convention that links methods to their instance
How it works
When you call an instance method, Python passes the instance as the first argument. self names that parameter so methods access the instance's attributes and other methods.
Common error
Omitting self from a method definition leads to argument mismatch errors at call time.
Best practice
Always include self as the first parameter of instance methods and use that name for readability.
Example call mechanics
def bark(self):
    return f"{self.name} says Woof!"

# call: buddy.bark()  --> Python passes buddy as first argument
Reflection
If you see a missing argument error when calling a method, check whether self was omitted from the method definition.
