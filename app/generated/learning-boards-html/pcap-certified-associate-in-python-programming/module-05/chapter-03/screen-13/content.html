Question
Wallet balance design
Best answer: implement balance as a read-only @property and ensure deposit() and withdraw() are the only mutators that update the internal _balance with validation to prevent negative values.
Question
Purpose of name mangling
Correct concept: name mangling prevents accidental name clashes between subclasses and superclasses; it is not a guarantee of strict privacy.
Key Takeaway

Design APIs that enforce invariants inside the class and choose access conventions for clarity; use properties for controlled attribute access and name mangling to avoid subclass collisions.
