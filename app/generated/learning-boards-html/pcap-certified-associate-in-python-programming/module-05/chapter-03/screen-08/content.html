Convention

Single underscore usage

Prefixing a name with a single underscore signals that it’s intended for internal use or subclass access. It’s a social contract between developers rather than a language-enforced rule.

When to use
For caches, computed internals, or values you expect subclasses to read but not treat as stable API.
Pitfall
Do not rely on it for security; external code can still access _private members.
Example
class UserProfile:
    def __init__(self, username, password):
        self.username = username
        self._password_hash = hash(password)  # internal use

    def _authenticate(self, password):
        return hash(password) == self._password_hash
Here _password_hash and _authenticate are internal. Access is possible but discouraged to avoid coupling to fragile internals.
