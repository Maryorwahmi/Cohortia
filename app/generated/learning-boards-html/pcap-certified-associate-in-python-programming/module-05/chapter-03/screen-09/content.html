Mechanics

How name mangling works

Python rewrites __attr inside the class to _ClassName__attr so subclasses or external code won't accidentally override or clash with the name.

When to use
For internal state that must be protected from accidental subclass overrides in inheritance hierarchies.
Example & note
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.__salary = salary  # private via name mangling

    def get_salary(self):
        return self.__salary

emp = Employee("Alice", 50000)
print(emp.name)            # Alice
# print(emp.__salary)      # AttributeError if attempted
print(emp._Employee__salary)  # Accesses mangled name (discouraged)
Name mangling is designed to reduce accidental collisions, not to provide impenetrable privacy.
