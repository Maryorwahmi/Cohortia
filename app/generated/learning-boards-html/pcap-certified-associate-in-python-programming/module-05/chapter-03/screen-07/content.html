Definition

When to use public attributes

Use public fields for simple, unconstrained data. If no validation or extra computation is needed, public attributes keep code compact and readable.

Pros
Simplicity and readability when no control is required.
Cons
No built-in validation or prevention of invalid external writes.
Code example
class BankAccount:
    def __init__(self, balance):
        self.balance = balance  # Public attribute

    def deposit(self, amount):
        if amount > 0:
            self.balance += amount
If you need to prevent direct assignment that breaks invariants, refactor balance into a property or make mutators the only way to change it.
