Module 5 › Chapter 5.3 › What is Encapsulation?
Definition

Encapsulation explained

Encapsulation groups attributes and methods into a class and restricts direct external modification of internal state. It keeps validation and invariants inside the class so external code cannot break them accidentally.

Analogy: a safe
You turn a dial or enter a code; you do not fiddle with the lock's internal springs.
Why it matters
Preserves state validity, reduces accidental errors, and allows internal changes without breaking callers.
Concrete example
BankAccount with controlled access
# Public attribute example
class BankAccount:
    def __init__(self, balance):
        self.balance = balance  # public attribute

    def deposit(self, amount):
        if amount > 0:
            self.balance += amount
            print(f"Deposited {amount}. New balance: {self.balance}")
        else:
            print("Deposit amount must be positive.")
This shows a class with a public balance attribute; it works but does not prevent external code from setting a negative balance directly.
Key Takeaway

Entrust classes with enforcing their own invariants. Encapsulation gives a single place to check and enforce rules.
