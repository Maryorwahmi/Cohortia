Learning Objectives
Understand, apply, and manage serialized data safely and effectively.
01
Explain serialization
Describe why converting objects to storable formats is necessary for persistence and communication between programs. Verified competency milestone
02
Use json to serialize and deserialize
Apply json.dumps and json.loads for strings and json.dump/json.load for files, keeping encoding and text modes in mind. Verified competency milestone
03
Use pickle for Python objects
Serialize complex Python objects to bytes with pickle.dumps and files with binary modes; know the environment constraints. Verified competency milestone
04
Identify security implications
Recognize that unpickling untrusted data can run code. Choose json when data origin is uncertain. Verified competency milestone
