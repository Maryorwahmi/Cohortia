Process Flow
pickle.dump and pickle.load
Write and read steps
  1. Open file in 'wb' (write binary) and call pickle.dump(object, file).
  2. Close or use a context manager to flush and close the file.
  3. Open file in 'rb' (read binary) and call pickle.load(file) to restore.
Example
import pickle

with open('game_state.pkl', 'wb') as f:
  pickle.dump(game_state_obj, f)

with open('game_state.pkl', 'rb') as f:
  loaded_state = pickle.load(f)

print(loaded_state.player_name)
Keep the class definitions available when unpickling to avoid import errors.
