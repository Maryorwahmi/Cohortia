Safety
Security implications of pickle
Why pickle is risky
  • Unpickling can call constructors and other callable code paths.
  • A crafted payload can execute arbitrary code during load.
  • Pickle is unsafe for untrusted or unauthenticated data sources.
Safe practices
  • Use JSON for external or cross-language data exchange.
  • Authenticate and validate sources before unpickling.
  • Limit pickled file access to trusted storage and lifecycle-managed files.
Warning

Never unpickle data from an untrusted source. Treat pickled bytes as potentially executable instructions and protect your runtime accordingly.
