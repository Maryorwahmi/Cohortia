Comparison
JSON: Pretty vs Compact
Pretty-printed (indent=4)
{
    "name": "Alice",
    "age": 30,
    "courses": [
        {
            "title": "History",
            "credits": 3
        },
        {
            "title": "Math",
            "credits": 4
        }
    ]
}
Readable for humans, easy to diff and edit.
Compact (no indent)
{"name":"Alice","age":30,"courses":[{"title":"History","credits":3},{"title":"Math","credits":4}]}
Smaller size, faster transfers. Ideal for network payloads.
When to pretty-print
Configuration files, repositories, or any case where humans inspect and modify JSON.
When compact is better
High-volume network traffic, logs intended for machines, or space-sensitive storage.
