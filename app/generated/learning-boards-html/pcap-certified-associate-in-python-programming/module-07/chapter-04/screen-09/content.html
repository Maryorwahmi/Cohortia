Core Concept
pickle: Python-specific serialization
What pickle does
  • Serializes complex Python objects into bytes.
  • Restores instances with equivalent state when unpickled.
  • Requires binary file modes for file operations.
Quick example
import pickle

class GameState:
  def __init__(self, player, score):
    self.player = player
    self.score = score

state = GameState('Hero', 1500)
# Serialize to bytes
pickled = pickle.dumps(state)
# Deserialize
restored = pickle.loads(pickled)
print(restored.player)
Pickle is convenient for internal persistence but not safe for untrusted data.
