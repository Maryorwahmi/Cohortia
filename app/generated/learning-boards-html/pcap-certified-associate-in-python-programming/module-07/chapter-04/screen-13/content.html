Hands-on Activity
Configuration and Game State Persistence
Part 1 — JSON config
  1. Create a settings dictionary, e.g., theme and notifications.
  2. Open app_config.json in text write mode and call json.dump with indent.
  3. Open it in text read mode and call json.load; verify a value.
Part 2 — Pickle game state
  1. Define a GameState class with attributes and methods to manage inventory.
  2. Open game_state.pkl in binary write mode and call pickle.dump.
  3. Open game_state.pkl in binary read mode and call pickle.load; inspect restored attributes.
Remember to remove created files after the exercise and perform pickle steps only in a trusted environment.
