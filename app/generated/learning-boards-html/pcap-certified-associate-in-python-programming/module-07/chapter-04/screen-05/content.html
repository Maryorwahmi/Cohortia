Definition
json.dumps and json.loads
Convert Python structures to JSON text and back.
Example code
<pre><code>import json # Python dictionary user = { "name": "Alice", "age": 30, "isStudent": False, "courses": [ {"title": "History", "credits": 3}, {"title": "Math", "credits": 4} ] } # Serialize to JSON string json_string = json.dumps(user, indent=2) print("JSON string saved to a variable") # Deserialize back to Python decoded = json.loads(json_string) print(type(decoded)) # dict print(decoded['age']) </code></pre>
Explanation and tips
  • json.dumps returns a text string; use it for network payloads or textual fields.
  • json.loads expects text and returns Python types like dict and list.
  • Use indent to pretty-print for humans; omit indent for compact transfer.
  • Remember JSON does not preserve Python-only semantics like object identity or methods.
Key Takeaway

Use dumps/loads for in-memory conversion between Python and JSON text; convert unsupported types manually.
