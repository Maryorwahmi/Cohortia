Module 7 › Chapter 7.4 › Practical outcomes
Verification habits
  • Confirm the deserialized object's type before using it.
  • Open JSON files in text mode and pickle files in binary mode.
  • Convert complex types like datetimes to strings for JSON and back after loading.
  • Never unpickle data from untrusted sources; validate origins first.
Quick references
json: dumps, loads, dump, load. Pickle: dumps, loads, dump, load (binary file modes required). Use indent for readable JSON.
