JSON limitations and workarounds
Types not supported directly
  • datetime objects
  • custom class instances with methods
  • binary blobs and certain numeric types
Workaround pattern
Convert unsupported types to JSON-friendly representations before dumping, and convert them back after loading. Keep conversion logic near type definitions.
Datetime example
# Convert to string before dump
obj['last_login'] = obj['last_login'].isoformat()
# After load
obj['last_login'] = datetime.fromisoformat(obj['last_login'])
Common mistake

Attempting to dump complex types directly will raise a TypeError. Always convert first or supply custom encoder helpers.
