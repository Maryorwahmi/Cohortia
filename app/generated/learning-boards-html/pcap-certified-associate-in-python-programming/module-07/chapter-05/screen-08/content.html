Using re.findall()
Extract multiple non-overlapping matches as a list of strings or tuples when groups are used.
import re
text = "The price is $12.50 and discount is $2.00."
# No groups: returns list of strings
prices = re.findall(r"\$\d+\.\d{2}", text)
# prices -> ['$12.50', '$2.00']

# With groups: returns list of tuples
pairs = re.findall(r"(\$)(\d+\.\d{2})", text)
# pairs -> [('$', '12.50'), ('$', '2.00')]
Concrete example: use a single group when you only want a specific capture (e.g., the numeric part) and expect tuples from findall; otherwise use a full-match pattern without groups.
Tips & common mistakes
If you need indices or group methods, use finditer which yields match objects. If you want the full match and used groups for precedence, convert groups to non-capturing with (?: ).
Key Takeaway

findall is great for quick lists. Remember the tuple behavior when groups are present and switch to finditer for richer details.

Pro tip
Use raw strings for patterns to avoid Python escape issues, e.g., r"\$\d+\.\d{2}".
