Core Concept
Grouping & Capture
Parentheses control precedence and capture substrings for later retrieval or replacement.
• Capturing group: (pattern) — stores the matched text as a numbered group.
• Non-capturing: (?:pattern) — groups without creating a capture slot.
• findall returns tuples when capture groups exist; consider group usage accordingly.
Concrete example
Pattern: User '([^']+)' captures the username inside quotes. findall returns the captured names.
Practical note
When building patterns for extraction, decide whether you want full matches or specific captured fields. Use non-capturing groups to avoid accidental tuple outputs from findall.
Key Takeaway

Grouping affects both matching logic and the shape of your extracted results. Plan groups intentionally.
