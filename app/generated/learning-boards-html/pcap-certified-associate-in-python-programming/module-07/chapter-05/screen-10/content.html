Raw Strings & Escaping
Use raw strings to ensure backslashes are passed to the regex engine unchanged.
• Use r"..." for patterns, e.g., r"\d+". This prevents Python from turning backslash sequences into special characters before regex sees them.
• Escape literal metacharacters like dot with a backslash: use \\., not . when matching a period.
• Raw strings cannot end with an odd number of backslashes; be careful in edge cases.
Concrete example
Pattern to match prices: r"\$\d+\.\d{2}" — raw string keeps backslashes intact for the regex engine.
Common-mistake
Using a regular Python string without raw prefix and writing patterns like "\\d+" makes the pattern hard to read and increases risk of accidental escapes.
Key Takeaway

Prefer raw strings for regex patterns so backslashes are handled by the regex engine, not by Python string parsing.
