import re
log_entry = "ERROR:2023-10-27 15:30:45: User 'admin' failed login from IP 192.168.1.10. (Attempt 3)"

# 1. Error type
error_type_pattern = re.compile(r"^(\w+):")
err = error_type_pattern.search(log_entry)
if err:
    error_type = err.group(1)

# 2. Timestamp

# 3. Username
username_pattern = re.compile(r"User '([\w]+)'")
# 4. IP address
ip_pattern = re.compile(r"IP (\d{1,3}(?:\.\d{1,3}){3})")
# 5. Attempt number
attempt_pattern = re.compile(r"\(Attempt (\d+)\)")

modified = re.sub(r"failed login", "unsuccessful authentication", log_entry)

Explanation & checklist
  • Compile focused patterns for each field to improve clarity and reuse.
  • Use search to find each field anywhere in the entry, except when anchored.
  • Extract groups with group(1) for the relevant capture.
  • Use re.sub and assign its result to perform replacements.
Key Takeaway

Break the log into fields with small, tested patterns, compile for reuse, and use sub for consistent replacements across entries.
