Core Concept
Character Classes & Sets
Shorthand classes and bracket sets control which characters match at a given position.
• \d matches a digit. \D matches a non-digit.
• \w matches word characters (alphanumeric and underscore). \W is inverse.
• \s matches whitespace; \S matches non-whitespace.
• [aeiou] matches any listed character; ranges like [0-9] match numeric ranges.
Concrete example
To match simple phone segments: \d{3}-\d{3}-\d{4} will match sequences like 123-456-7890.
Common-mistake & tips
Do not assume \w covers non-ASCII letters in every environment. Use explicit ranges or Unicode flag when needed. Also, remember that a class matches a single position; combine with quantifiers to accept multiple characters.
Tip: prefer raw strings in Python, e.g., r"\d+" so backslashes are preserved.
Tip: character classes are faster than alternations like (a|b|c) in many cases.
Try-it: Convert vowel class [aeiouAEIOU] into a case-insensitive pattern with a flag when appropriate.
Key Takeaway

Choose the right class for the job; use brackets for custom sets and remember quantifiers apply to the whole class.
