Skills & Pitfalls
Build patterns, test them, and avoid the common regex traps.
Character classes & shorthand
Practice \d, \w, and \s for digits, word characters, and whitespace. Use square brackets for custom sets like [aeiou].
Mnemonic: d-digit, w-word, s-space
VERIFIED COMPETENCY MILESTONE
Quantifiers & greediness
Test *, +, ? and learn to add ? to make quantifiers non-greedy when you need minimal matches.
Mnemonic: star wants everything, add ? to calm it
VERIFIED COMPETENCY MILESTONE
Grouping & findall behavior
Observe how parentheses create capture groups and how findall returns tuples when groups are present.
Mnemonic: groups = structured results
VERIFIED COMPETENCY MILESTONE
Replacement & flags
Use re.sub to replace text; pass flags like re.IGNORECASE to match case-insensitively and use functions for dynamic replacements.
Mnemonic: sub = substitute smartly
