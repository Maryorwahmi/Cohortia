What to Remember
Raw strings
Use r"..." so backslashes are preserved for regex parsing.
Pick the right function
search, match, findall, sub each solve different tasks—use them intentionally.
Group intentionally
Decide whether to capture or use non-capturing groups to control output structure.
Final tip: test patterns on representative samples and use compiled patterns for repeated processing. With a few practiced patterns, regex becomes a predictable, repeatable tool in your toolbox.
