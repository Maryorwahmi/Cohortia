Core Concept
What is a Regular Expression?
A sequence of characters that defines a search pattern used for matching, extracting, and changing text.
• Literal characters match themselves, e.g., 'cat' finds the substring cat.
• Metacharacters like . * + ? alter matching behavior.
• Parentheses group and capture substrings for retrieval.
Concrete example
Pattern: \$\d+\.\d{2} matches a dollar sign, digits, a dot, and two decimals — ideal for prices like $12.50.
Key Takeaway

Regex describes patterns. Learn symbols first, then combine them to express practical text queries.

Common mistake
Assuming regex always improves clarity. Use it when patterns are non-trivial or repeated.
Building blocks at a glance
Dot: . = any single character (except newline)
Star: * = zero or more of the previous element
Plus: + = one or more of the previous element
Question: ? = zero or one of the previous element
Anchors: ^ and $ match start and end of string
Analogy
Think of regex as a compact Swiss Army knife: each symbol is a tool you combine to cut, measure, and shape text into the form you need.
