Definition
re.sub() Basics
Replace occurrences of a pattern with a replacement string or function, optionally limiting count and using flags.
import re
sentence = "Hello world, this is a test. world hello."
new = re.sub(r"world", "Python", sentence)
# new -> 'Hello Python, this is a test. Python hello.'

# Case-insensitive replacement
modified = re.sub(r"color", "colour", document_text, flags=re.IGNORECASE)
Concrete example: use re.sub with a function to convert matched numbers from dollars to cents for dynamic replacements.
Tips
Remember to assign the result of re.sub. Use flags for case-insensitive replaces and a callable when replacement depends on match content.
Key Takeaway

Use re.sub for targeted, repeatable replacements. For dynamic logic, provide a function that formats the match result.

Common mistake
Forgetting to escape dots in patterns when you mean a literal period. Use \\., not .
