Learning Objectives
Master the re module patterns, functions, and common pitfalls.
01
Understand regex syntax
You will read and build patterns using metacharacters, quantifiers, and anchors. Knowing what each symbol does prevents common errors.
Mnemonic: dot = any, star = zero-or-more
VERIFIED COMPETENCY MILESTONE
02
Use search vs match correctly
You will choose search to scan anywhere in a string and match when the pattern must appear at the start. This prevents off-by-one logic errors.
Mnemonic: match = morning check, search = whole walk
VERIFIED COMPETENCY MILESTONE
03
Extract and replace text
You will extract lists of matches with findall and perform replacements with sub, including limiting replacements and using functions as replacements.
Mnemonic: findall = collect, sub = transform
VERIFIED COMPETENCY MILESTONE
04
Compile patterns for reuse
You will compile commonly used patterns into regex objects to reduce repeated compilation and improve readability in scripts and tools.
Mnemonic: compile once, use many
VERIFIED COMPETENCY MILESTONE
