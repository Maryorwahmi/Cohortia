Metacharacters & Quantifiers
Learn the special symbols that change how patterns match text.
• . matches any single character (except newline).
• * zero or more; + one or more; ? zero or one.
• ^ asserts the start of string; $ asserts the end of string.
• Add ? after a quantifier to make it non-greedy, e.g., .*?.
Concrete example
Pattern: ^ID:\\d+ matches lines that begin with ID: followed by one or more digits, ensuring the pattern appears at the start.
Key Takeaway

Quantifiers give you repetition control; anchors pin patterns to positions. Watch greedy behavior carefully.

Common mistake
Using .* when you need the smallest match; prefer .*? for minimal matching in nested structures.
Process: read a quantifier
Step 1: Identify the base token (literal or character class).
Step 2: See if a quantifier follows: none means single instance; ?, *, +, {n,m} change repetition.
Step 3: Consider greediness; add ? if you want the shortest possible match.
Step 4: Test with sample strings to confirm behavior.
Try this idea
Compare greedy .* and non-greedy .*? on a string with repeated delimiters to see which part each captures.
