Compile for reuse
Create a regex object once and call its methods multiple times to avoid repeated compilation overhead.
import re
email_pattern = re.compile(r"[\w\.-]+@[\w\.-]+")
for line in log_lines:
    m = email_pattern.search(line)
    if m:
        print(m.group())
Concrete example: compiling an IP or timestamp pattern once is efficient when scanning thousands of log lines.
Practical guidance
Use compile when patterns are used repeatedly, and pass flags like re.IGNORECASE at compile time for consistent behavior across calls.
Key Takeaway

Compile for clarity and speed when using patterns multiple times; prefer method calls on the compiled object.
