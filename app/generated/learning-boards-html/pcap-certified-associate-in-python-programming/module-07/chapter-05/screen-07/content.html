Comparison
re.search() vs re.match()
Pick search to find a pattern anywhere; pick match when the pattern must be at the start.
import re
text = "The quick brown fox"
# search finds 'quick' anywhere
m1 = re.search(r"quick", text)
# match checks only at beginning
m2 = re.match(r"quick", text)
# m1 is a match, m2 is None
Concrete example: use search for locating first email anywhere; use match to validate that a string starts with a date stamp.
Common-mistake
Using match when you expect the pattern later in the string leads to silent None results. If unsure, use search or explicitly anchor with ^ when you mean start-of-string.
Pro tip

To check a prefix reliably, either use re.match or use re.search with the caret anchor ^ to make intent explicit.

Key Takeaway

search scans; match anchors. Pick the function that matches your desired match location.
