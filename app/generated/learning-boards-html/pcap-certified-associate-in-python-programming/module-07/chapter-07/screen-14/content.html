Module 8 › Chapter 7.7 › Key Concepts
collections module
A standard library module with specialized container datatypes for common patterns.
namedtuple
Tuple subclass with named fields for readable, immutable records.
deque
Double-ended queue offering O(1) operations at both ends and optional maxlen for fixed-size buffers.
defaultdict
Creates default values using a factory callable, simplifying grouping and incremental updates.
Counter
Counts hashable items, returns zero for missing keys, and supports most_common and arithmetic operations.
Decision guide
Match the container to the pattern: records, queues, grouping, or counting for best clarity and performance.
Final summary

These four collections solve common patterns—use them intentionally to simplify code, avoid errors, and optimize performance where needed.
