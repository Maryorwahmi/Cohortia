Module 8 › Chapter 7.7 › Log analysis
Starter code (conceptual)
from collections import defaultdict, Counter
import re

log_entries = [
    "INFO: User 'Alice' logged in from 192.168.1.100",
    "WARNING: Disk space low on /dev/sda1",
    "ERROR: Failed to connect to database 'prod_db'",
    # ... more entries
]

# Group by severity
logs_by_severity = defaultdict(list)
for entry in log_entries:
    sev, _, rest = entry.partition(':')
    logs_by_severity[sev].append(rest.strip())

# Count words across all logs
word_counts = Counter()
for entry in log_entries:
    words = re.findall(r"\b\w+\b", entry.lower())
    word_counts.update(words)

print(logs_by_severity)
print(word_counts.most_common(5))
Guidance

Use a simple pattern to split severity and rest, then append. For counting, normalize case and extract word tokens before feeding into Counter.

Concrete scenario

Group logs so you can quickly inspect all ERROR lines and then report the top five most frequent words across all logs for triage.

Key Takeaway

defaultdict and Counter combine naturally: grouping plus counting delivers useful analytics with minimal code.
