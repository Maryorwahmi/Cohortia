Module 8 › Chapter 7.7 › defaultdict
Grouping example
from collections import defaultdict

s = [('yellow', 1), ('blue', 2), ('yellow', 3), ('blue', 4), ('red', 1)]
grouped_by_color = defaultdict(list)
for k, v in s:
    grouped_by_color[k].append(v)

print(grouped_by_color)

# Counting occurrences
letter_counts = defaultdict(int)
text = 'hello world'
for char in text:
    if char.isalpha():
        letter_counts[char] += 1
print(letter_counts)
Concrete use

Grouping log entries by severity or collecting values by keys becomes straightforward without if-checks for key presence.

Gotcha

Don’t pass a value instead of a callable. Use defaultdict(int) not defaultdict(0).

Key Takeaway

defaultdict reduces boilerplate for grouping and incremental updates by auto-creating container defaults.
