Module 8 › Chapter 7.7 › Mini-challenge
Before (list-based)
history = []

def add(item):
    history.insert(0, item)
    if len(history) > 10:
        history.pop()
After (deque)
from collections import deque
history = deque(maxlen=10)

def add(item):
    history.appendleft(item)  # oldest removed automatically when full
Checklist
  1. Replace list with deque(maxlen=10).
  2. Swap insert/pop to appendleft/popleft or append/pop as appropriate.
  3. Run tests to confirm older items drop when capacity exceeded.
Key Takeaway

A few API changes can simplify code and eliminate hidden O(n) operations when maintaining a recent-items buffer.
