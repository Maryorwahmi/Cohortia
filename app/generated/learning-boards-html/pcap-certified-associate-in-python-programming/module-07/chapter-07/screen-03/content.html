Verification and common pitfalls

Each objective includes a small verification: a code check or quiz that confirms you can apply the right collection and avoid typical errors such as trying to mutate a namedtuple or supplying a non-callable default factory.

Namedtuple test

Create a Student record, access fields by name, and convert to a dictionary for serialization.

Deque exercise

Replace a list-based history with a deque(maxlen=10) to automatically drop oldest entries.

Grouping & counting

Group log lines by severity with defaultdict and compute word frequencies with Counter.

Common Mistake

Passing a value instead of a callable to defaultdict or trying to set attributes on a namedtuple causes runtime errors or surprising behavior.
