Module 8 › Chapter 7.7 › Common mistakes

Pitfalls and fixes

  • defaultdict requires a callable factory, e.g., defaultdict(int) not defaultdict(0).
  • namedtuple instances are immutable; assignment to fields raises AttributeError.
  • Counter keys must be hashable; avoid lists and dicts as items.
  • defaultdict inserts keys on access; access intentionally to avoid accidental keys.
  • Use deque for head/tail operations; use list for frequent indexing.
Pro tip

Prefer Counter.update with an iterable for concise code when combining many tokens instead of manual loops.

Check

Before counting, ensure tokens are immutable types like strings or tuples to avoid type errors.

Key Takeaway

Small API details matter: supplying the right factory and respecting immutability avoids common runtime errors.
