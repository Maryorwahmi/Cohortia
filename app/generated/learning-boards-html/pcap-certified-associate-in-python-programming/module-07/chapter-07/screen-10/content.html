Word frequency example
from collections import Counter

sentence = 'the quick brown fox jumps over the lazy dog quick brown fox'
words = sentence.split()
word_counts = Counter(words)
print('Word frequencies:', word_counts)
print("Count of 'quick':", word_counts['quick'])
print("Two most common words:", word_counts.most_common(2))

# Counter arithmetic
c1 = Counter('aabbc')
c2 = Counter('bbccdd')
print('c1 + c2:', c1 + c2)
print('c1 - c2:', c1 - c2)
Concrete use

Use Counter to find top-occurring words in logs or to merge counts from multiple sources quickly using arithmetic operators.

Gotcha

Counter requires hashable items like strings or tuples. Passing lists or dicts will raise a TypeError.

Key Takeaway

Use Counter for concise frequency analysis and merging counts across datasets.
