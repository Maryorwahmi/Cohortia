Module 8 › Chapter 7.7 › namedtuple
Definition and shown example
from collections import namedtuple

# Define a namedtuple for a Point
Point = namedtuple('Point', ['x', 'y'])

# Create instances of Point
p1 = Point(10, 20)
p2 = Point(x=30, y=40)

print('Point 1:', p1)
print('X coordinate of p1:', p1.x)  # Access by name
print('Y coordinate of p1:', p1[1]) # Access by index

# Convert to an ordered mapping
print('Point 1 as dictionary:', p1._asdict())
Concrete use

Use namedtuple for small records like a Student or Car where fields are fixed and immutability helps avoid accidental changes.

Common mistake

Attempting to set a field causes AttributeError; choose a class if you need mutable attributes.

Performance note

Namedtuple retains tuple memory layout, making it efficient for many small records compared to full classes with __dict__.

Key Takeaway

Use namedtuple for readable, immutable, memory-efficient records where fields are fixed.
