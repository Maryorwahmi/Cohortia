Module 8 › Chapter 7.7 › deque
Example and operations
from collections import deque

# Create a deque
d = deque(['a', 'b', 'c'])

# Add to right and left
d.append('d')
d.appendleft('z')

# Remove from right and left
popped_right = d.pop()
popped_left = d.popleft()

# Fixed-size history
history = deque(maxlen=3)
history.append('command1')
history.append('command2')
history.append('command3')
history.append('command4')  # oldest removed automatically
Concrete use

Use deque for a web server request queue, an undo stack, or keeping the last N log lines with automatic eviction.

Performance note

Left-side inserts on list are O(n), while deque appendleft and popleft are O(1).

Pro tip

Use maxlen when you need a rolling window; deque handles eviction for you, so you don’t write extra boundary checks.

Key Takeaway

deque is the right choice for frequent both-end operations and fixed-length histories.

Check your understanding

Replace a list-based recent-items buffer with deque(maxlen=10) and observe simpler code and automatic eviction.
