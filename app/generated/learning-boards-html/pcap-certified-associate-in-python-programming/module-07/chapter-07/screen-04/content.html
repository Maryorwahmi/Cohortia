Module 8 › Chapter 7.7 › What the collections module provides

Definition and motivation

These container types address recurring needs: named records, double-ended queues, automatic default values for dicts, and efficient counting of items.

When to use namedtuple

When you need immutable, memory-efficient records with readable field names and no behavior.

When to use deque

When you frequently add or remove items at both ends or want a fixed-size history.

When to use defaultdict

When a missing key should automatically create a default container or value.

When to use Counter

When you need to compute frequencies or merge/subtract counts concisely.

Example

Counting words in a sentence is a classic Counter use-case. Grouping values by a key is a classic defaultdict scenario. Maintaining last N items is a deque use-case.

Key Takeaway

Choose a collection when it directly simplifies a repeated pattern: records, queues, grouping, or counting.

Misconception

These types are not universally better than built-ins. They are specialized and should be chosen when they reduce complexity or cost.
