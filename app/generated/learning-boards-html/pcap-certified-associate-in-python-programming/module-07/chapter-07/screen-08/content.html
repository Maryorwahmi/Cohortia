Module 8 › Chapter 7.7 › list vs deque
List head operations

Inserting or popping at index zero shifts elements and is O(n). That cost can accumulate in loops.

When list is fine

When sequences are small or you need fast random access by index.

deque head operations

appendleft and popleft are O(1). Use deque for queue-like workloads and sliding windows.

When deque is better

When you need many operations at either end and order matters more than direct indexing.

Example contrast

A server request buffer where you frequently pop the oldest entry benefits from deque; a lookup table that requires random index reads benefits from list.
