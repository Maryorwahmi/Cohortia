Comparison

os.rename vs shutil.move

os.rename is a simple rename that may fail across devices. shutil.move falls back to copy and delete to handle cross device moves reliably.
Example: move across partitions
Use shutil.move when you are not certain whether source and destination are on the same filesystem.
Safety

Handling shutil.rmtree

rmtree deletes recursively and permanently. Verify the path and permissions, and consider copying to a backup location first.
Checklist
  • Confirm path starts with expected prefix
  • Check os.path.exists before running
  • Catch PermissionError during removal
