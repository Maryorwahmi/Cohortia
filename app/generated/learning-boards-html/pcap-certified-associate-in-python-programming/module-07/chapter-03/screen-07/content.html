Comparison

mkdir vs makedirs

Use mkdir when parent exists and you only need one directory. Use makedirs to create nested paths and avoid manual parent creation.
os.mkdir('x') fails if parent not present
os.makedirs('a/b/c', exist_ok=True) creates intermediates safely
Pro tip
Use exist_ok=True or guard with os.path.exists to make scripts idempotent.
Comparison

os.rmdir vs shutil.rmtree

os.rmdir removes empty directories only. For non empty directories use shutil.rmtree, but treat it as destructive and verify the target first.
os.rmdir('empty_dir') raises if not empty
shutil.rmtree('dir') deletes recursively without confirmation
Safety note
Double check the full path and permissions before calling rmtree. Consider creating a backup with copytree first if unsure.
