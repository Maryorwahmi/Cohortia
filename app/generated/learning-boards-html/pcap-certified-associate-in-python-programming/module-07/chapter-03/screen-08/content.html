Module 7 › Chapter 7.3 › os.path
Definition

Abstract path handling

Use os.path to build, split, and normalize paths without worrying about platform specifics.
os.path.join('a','b') builds a platform correct path
os.path.exists(path) checks for existence
os.path.abspath(path) returns the absolute path
Concrete example
import os file_path = os.path.join('temp_dir','my_file.txt') print(os.path.abspath(file_path)) print(os.path.isfile(file_path))
Misconception
Concatenating strings with separators can break on other platforms and produce incorrect paths.
