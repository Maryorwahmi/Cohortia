Process Flow

List contents and create directories

Use os.listdir to examine a directory. Use os.makedirs with exist_ok or try except to build nested structures safely.
os.listdir(path) returns immediate entries for iteration
os.mkdir(path) creates one directory and fails if parent missing
os.makedirs(path, exist_ok=True) creates nested directories safely
Key Takeaway

Prefer os.makedirs with exist_ok for scripts that may rerun, and use os.listdir to verify results.

Concrete scenario
import os path = os.path.join('parent','child','grandchild') if not os.path.exists(path): os.makedirs(path) print(os.listdir('parent'))
Common mistake
Calling os.mkdir for nested paths causes errors when intermediate folders do not exist.
