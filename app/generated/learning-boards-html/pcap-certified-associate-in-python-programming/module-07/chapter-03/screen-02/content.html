Learning Objectives
Learn, Understand, Apply, Master
Bloom: Learn → Understand → Apply → Master
01
Navigate the file system
Use os.getcwd, os.chdir, and os.listdir to find and move the working directory so code opens the right files.
VERIFIED COMPETENCY MILESTONE
02
Create, delete, rename
Use os.mkdir, os.makedirs, os.remove, os.rmdir and os.rename to manage files and folders safely.
VERIFIED COMPETENCY MILESTONE
03
Manipulate file paths
Use os.path.join, exists, isfile, isdir and abspath to write cross platform scripts.
VERIFIED COMPETENCY MILESTONE
04
Use shutil for higher level operations
Copy files, copy directory trees, move items, and clean up with rmtree when appropriate.
VERIFIED COMPETENCY MILESTONE
