Module 7 › Chapter 7.3 › shutil
Process

Copy single files or whole trees

Use shutil.copy for files and shutil.copytree for directory trees. Remember copytree requires the destination not to exist.
shutil.copy(src,dst) copies a file to a path or into a directory
shutil.copytree(src,dst) recursively copies all contents into a new directory
shutil.move(src,dst) moves or renames and handles cross device moves
Code example
import os import shutil if not os.path.exists('source_dir'): os.makedirs('source_dir') with open(os.path.join('source_dir','data.txt'),'w') as f: f.write('Some data') shutil.copy(os.path.join('source_dir','data.txt'),'temp_dir') if not os.path.exists('destination_dir'): shutil.copytree('source_dir','destination_dir')
Misconception
copytree will not overwrite an existing destination; you must remove or choose another name first.
