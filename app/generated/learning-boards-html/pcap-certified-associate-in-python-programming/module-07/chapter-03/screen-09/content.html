Create and remove files safely

import os if not os.path.exists('temp_dir'): os.makedirs('temp_dir') file_path = os.path.join('temp_dir','my_file.txt') with open(file_path,'w') as f: f.write('Hello from my_file!') print(os.listdir('temp_dir')) if os.path.isfile(file_path): os.remove(file_path)
Explanation
  • Check existence to avoid errors when creating or removing files.
  • Use with to ensure files are closed even if an error occurs.
  • Prefer os.remove for files and os.rmdir for empty dirs; use shutil for non empty directories.
Key Takeaway

Use context managers for file writes and guard deletions with checks or exception handling to avoid crashes.
