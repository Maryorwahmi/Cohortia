Definition

Anticipate FileNotFoundError and PermissionError

File system state can change. Use try except even when you check beforehand to account for race conditions.
import os import shutil try: if os.path.isfile('temp.txt'): os.remove('temp.txt') except FileNotFoundError: print('File already deleted') except PermissionError as e: print('Permission denied', e)
Practical guidance
  • Use try finally to always restore state like working directory
  • Log errors and return appropriate exit codes in scripts
  • When deleting, verify ownership and permissions to avoid failures
Misconception
A prior exists check does not replace exception handling because other processes or threads may mutate filesystem state.
