File System Operations with os and shutil
Practical control for files, directories, and cross platform paths.

Use os for navigation and low level operations like creating directories and removing single files. Use shutil for higher level tasks such as copying entire directory trees, moving across devices, and cleaning up non empty directories.

Key safety rules include checking existence, catching FileNotFoundError and PermissionError, and avoiding hardcoded path separators by using os.path.join.
