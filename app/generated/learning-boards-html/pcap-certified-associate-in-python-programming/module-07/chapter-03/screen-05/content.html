Module 7 › Chapter 7.3 › Working directory
Process Flow

Confirm, change, perform, restore

A safe pattern saves the original working directory, changes into the target, and restores the original in a finally block so other code is not impacted.
1. Save original: cwd = os.getcwd()
2. Ensure target exists: os.path.exists or os.makedirs
3. os.chdir(target) and perform operations
4. finally: os.chdir(original)
Code example
import os original = os.getcwd() try: target = os.path.abspath('data_folder') if not os.path.exists(target): os.makedirs(target) os.chdir(target) # process files here finally: os.chdir(original)
Pro tip
Prefer using absolute paths passed into functions instead of relying on a global change to the working directory.
