Module 7 › Chapter 7.3 › os vs shutil
Core Concept

os and shutil play different roles

Think of os as file system primitives and shutil as shell like utilities that operate on those primitives at scale.

os: getcwd, chdir, listdir, mkdir, remove, rmdir
os.path: join, exists, isfile, isdir, abspath
shutil: copy, copytree, move, rmtree
Key Takeaway

Match the function to the task: primitives for single items, shutil for higher level copies and recursive changes.

Concrete example
Create a temporary folder, write a file inside using standard file I O, then use shutil.copytree to create a full backup. This sequence demonstrates using both modules together for a common workflow.
import os import shutil if not os.path.exists('tmp'): os.makedirs('tmp') with open(os.path.join('tmp','data.txt'),'w') as f: f.write('sample') shutil.copytree('tmp','tmp_backup')
Common mistake
Using os.rename to move across devices can fail; prefer shutil.move for cross device safety.
