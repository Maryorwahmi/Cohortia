Common functions
  • math.sqrt(x) — square root (returns float).
  • math.sin, math.cos — trigonometric functions using radians.
  • math.pi, math.e — constants for pi and Euler's number.
Precision note
Results are floating-point values; avoid exact equality checks and prefer tolerances for comparisons.
Example outputs
math.sqrt(144) -> 12.0 math.e ** 3 -> numeric value format(math.pi, '.5f') -> 3.14159
Common misconception
Expecting integer returns from math functions can lead to type errors; be explicit about float handling.
Key Takeaway

Use math for common numeric tasks and format floating-point results when presenting them to users.
