Module 7 › Chapter 7.6 › Logarithms and exponentials
Concept
Log and exp functions
math.log is natural log, math.log10 is base-10, and math.exp raises e to a power. Use them for growth, scaling, and transformations.
Bulleted notes
  • math.log(x) returns the natural logarithm of x.
  • math.log10(x) gives the base-10 logarithm; explicit base helps readability.
  • math.exp(n) computes e to the n, often used to invert a natural log.
Key Takeaway

Be intentional about log base and data types; prefer math functions when mathematical accuracy and clarity matter.

Code examples
import math

print('Natural log of 100:', math.log(100))
print('Base-10 log of 1000:', math.log10(1000))
print('e squared via exp:', math.exp(2))
print('2**3 vs math.pow(2,3):', 2**3, math.pow(2,3))
Example scenario
When transforming skewed data for plotting or modeling, apply a logarithm to compress large ranges and improve interpretation.
