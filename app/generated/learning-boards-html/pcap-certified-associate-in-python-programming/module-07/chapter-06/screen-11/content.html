Module 7 › Chapter 7.6 › Seeding the generator
Concept
Seeding for reproducibility
Set a seed to recreate pseudo-random sequences for testing and debugging; same seed produces the same sequence.
Notes
  • random.seed(value) initializes the generator; value can be any hashable object.
  • Calling seed with the same value resets the sequence to a known state.
  • Avoid forcing a global seed in libraries; set seeds in tests or scripts where reproducibility is desired.
Key Takeaway

Seeding gives you repeatable randomness for debugging and deterministic test data, but it does not create cryptographic randomness.

Seed example
import random

random.seed(42)
print(random.randint(1,100))
print(random.randint(1,100))

random.seed(42)
print(random.randint(1,100))  # repeats
print(random.randint(1,100))
Misconception
Seeding doesn't improve randomness quality; it only makes sequences repeatable. For secure tokens use a different module.
