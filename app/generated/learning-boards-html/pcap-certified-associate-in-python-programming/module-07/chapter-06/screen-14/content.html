Module 7 › Chapter 7.6 › Key Concepts
math module
Provides constants and functions like sqrt, pow, sin, log, pi and e for numerical tasks.
Floating-point precision
Small rounding errors are normal; compare with math.isclose or a tolerance rather than exact equality.
random module
Generates pseudo-random values for sampling, shuffling and testing. Use correct functions for each selection need.
Summary takeaway
Rely on math for numeric correctness, use appropriate random functions for selection tasks, and seed when you need reproducible behavior.
