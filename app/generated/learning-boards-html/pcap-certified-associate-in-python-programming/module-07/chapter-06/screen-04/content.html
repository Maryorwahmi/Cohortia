Module 7 › Chapter 7.6 › Intro to the math Module
Definition
math: standard numeric utilities
Provides constants and functions for accurate numerical computation: sqrt, pow, sin, log, pi, and e.
Explanation
  • Import the module before use; forgetting import causes NameError.
  • Functions like sqrt and pow perform well-tested operations; pow returns a float.
  • Trig functions expect radians; use math.radians to convert degrees safely.
  • Floating-point results may show tiny rounding differences; prefer tolerance for equality checks.
Key Takeaway

Rely on math functions for clarity and correctness; they reduce bugs and improve readability.

Code examples
import math

# Constants
print('Value of Pi:', math.pi)
print('Value of e:', math.e)

# Basic operations
x = 16
print('Square root of', x, ':', math.sqrt(x))
print('2 to the power of 3:', math.pow(2, 3))

# Trig (degrees → radians)
angle_degrees = 30
angle_radians = math.radians(angle_degrees)
print('Sine of 30 degrees:', math.sin(angle_radians))

# Logarithm
print('Natural log of 100:', math.log(100))
