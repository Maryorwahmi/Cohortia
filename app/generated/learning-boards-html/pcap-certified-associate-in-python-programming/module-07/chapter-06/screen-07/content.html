Module 7 › Chapter 7.6 › Rounding: floor and ceil
Definition
math.floor and math.ceil
Deterministic rounding toward negative infinity or toward positive infinity, respectively.
Notes & pitfalls
  • floor(-3.1) returns -4 — floor rounds toward negative infinity.
  • ceil(4.2) returns 5 — ceil always rounds up.
  • Use round() if you want nearest-integer rounding with ties handled by Python rules.
Concrete example

Compute pages required: pages = math.ceil(total_items / page_size) ensures partial pages count as a full page.

Short code
import math

print('ceil(4.7):', math.ceil(4.7))
print('floor(4.7):', math.floor(4.7))
print('floor(-2.1):', math.floor(-2.1))

# Pages example
total_items = 23
page_size = 10
pages = math.ceil(total_items / page_size)
print('Pages needed:', pages)
