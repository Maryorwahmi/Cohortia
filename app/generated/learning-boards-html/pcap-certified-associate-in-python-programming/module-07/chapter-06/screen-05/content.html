Module 7 › Chapter 7.6 › Trigonometry and radians
Why it matters
Trig functions expect radians. Use math.radians to convert degrees to avoid incorrect calculations in geometry and simulations.
Bulleted notes
  • math.radians(deg) converts degrees to radians accurately using pi.
  • Expect floating-point outputs; compare with a tolerance if needed.
  • Common tasks: convert angles for rotations, compute wave values, or derive coordinates from polar angles.
Pro tip

Write helper functions that accept degrees and call math.radians internally to keep caller code simple and explicit about units.

Code walkthrough
import math

# Convert degrees to radians and compute trig values
deg = 30
rad = math.radians(deg)
print('Radians:', rad)
print('sin(30°):', math.sin(rad))

# Another example
print('sin(90°):', math.sin(math.radians(90)))
print('cos(0°):', math.cos(math.radians(0)))
