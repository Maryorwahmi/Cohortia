Module 7 › Chapter 7.6 › Selecting and shuffling
Process
Pick or shuffle depending on goal
Understand whether you need a single pick, unique picks, a shuffled copy, or an in-place mutation.
Step-by-step
  1. For a single random element, use random.choice(sequence).
  2. For unique multiple elements, use random.sample(population, k).
  3. To reorder a list in place, use random.shuffle(list).
  4. To get a shuffled copy, use random.sample(list, len(list)).
Common-mistake

Do not assign the result of random.shuffle to a variable; shuffle returns None and modifies the list in place.

Code examples
import random
fruits = ['apple','banana','cherry','date']
print('Choice:', random.choice(fruits))

my_list = [1,2,3,4,5]
random.shuffle(my_list)
print('Shuffled in place:', my_list)

numbers = list(range(1,21))
print('Sample 6 unique:', random.sample(numbers, 6))
Example scenario
Select two unique students for a presentation using random.sample(students, 2) instead of calling choice twice.
