Module 7 › Chapter 7.6 › Floating-point precision
Concept
Floating-point representation
Binary representation can produce tiny rounding errors; plan comparisons accordingly.
Common pitfalls
  • Avoid exact equality checks on floating-point results.
  • Prefer math.isclose or explicit absolute tolerances.
  • Choose tolerance relative to the magnitude of values you compare.
Common mistake

Testing equality like result == 2.0 can fail due to rounding; use a tolerance instead.

Example code
import math

x = math.sqrt(2)
product = x * x
print('product:', product)  # may be 2.0000000000000004

# Safe comparison
print('isclose to 2:', math.isclose(product, 2.0))

# Explicit tolerance
eps = 1e-12
print('within eps:', abs(product - 2.0) < eps)
