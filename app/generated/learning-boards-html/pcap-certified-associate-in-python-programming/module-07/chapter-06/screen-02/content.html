Learning Objectives
Bloom skills: Learn → Understand → Apply → Master
01
Use core math functions
Call functions like sqrt, pow, sin, log and use constants like pi and e to compute real values reliably. Practice computing a circle area and trig values from degrees.
VERIFIED COMPETENCY MILESTONE
02
Generate pseudo-random numbers
Use random.random and random.randint to generate floats and integers for simulations or test data, and understand their ranges and inclusivity.
VERIFIED COMPETENCY MILESTONE
03
Select and shuffle sequences
Choose random elements with choice, shuffle lists in place, and use sample to pick unique items without replacement for tasks like drawing cards.
VERIFIED COMPETENCY MILESTONE
04
Seed for reproducibility
Use random.seed to recreate sequences for debugging and tests. Understand that the same seed gives the same pseudo-random sequence every time.
VERIFIED COMPETENCY MILESTONE
