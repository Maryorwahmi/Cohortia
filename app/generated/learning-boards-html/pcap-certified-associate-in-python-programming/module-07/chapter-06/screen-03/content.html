Learning Objectives — Practice & Pitfalls
Bloom skills: Learn → Understand → Apply → Master
01
Compose math + random
Write small programs that use math outputs as inputs to random sampling or generate parameterized test data with both modules together.
VERIFIED COMPETENCY MILESTONE
02
Avoid off-by-one errors
Understand inclusive vs exclusive ranges, especially when using randint, randrange, and range to avoid boundary bugs.
VERIFIED COMPETENCY MILESTONE
03
Respect in-place operations
Remember that shuffle mutates the original list and returns None. If you need a new list, use sample or copy before shuffling.
VERIFIED COMPETENCY MILESTONE
04
Handle floating-point comparisons
Use small tolerances when checking equality of math function results, because floating-point arithmetic can produce tiny rounding differences.
VERIFIED COMPETENCY MILESTONE
