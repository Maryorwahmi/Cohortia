Working with Dates and Times
Use Python's datetime module to represent moments, compute intervals, and format or parse timestamps reliably.
In this lesson
Create date/time objects, add or subtract durations, convert to strings, parse strings, and handle timezone awareness.
Coming up
A hands-on scheduler exercise that calculates reminders and differences between events.
Concept Map
Core types and conversions
date / time
Separate types for calendar date and wall-clock time. Use when you only need one or the other.
datetime
Combines date and time into a single moment. Often returned by now() or parsed from strings.
timedelta
A duration you add or subtract to move moments forward or backward.
strftime / strptime
Format and parse with explicit format directives. Mismatches cause ValueError.
