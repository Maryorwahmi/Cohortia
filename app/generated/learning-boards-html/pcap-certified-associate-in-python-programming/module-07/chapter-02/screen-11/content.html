Module 7 › Chapter 7.2 › Naive vs Aware
Comparison
Naive
No tzinfo. Good for simple local timestamps but ambiguous across systems.
Aware
Includes tzinfo. Required for correct conversions and cross-zone comparisons.
Example
from datetime import datetime, timezone

naive = datetime.now()
aware_utc = datetime.now(timezone.utc)
print(naive.tzinfo)      # None
print(aware_utc.tzinfo)  # UTC
Practical rule
Decide on a canonical timezone for storage (often UTC) and convert to local time only when presenting to users.
