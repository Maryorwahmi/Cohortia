now() and utcnow()
Inspect tzinfo to determine if a datetime is naive or aware.
Examples
from datetime import datetime, timezone

local = datetime.now()
utc_naive = datetime.utcnow()
utc_aware = datetime.now(timezone.utc)

print(local.tzinfo)        # None
print(utc_naive.tzinfo)    # None
print(utc_aware.tzinfo)    # UTC
Practical notes
  • Use timezone-aware datetimes when passing timestamps between systems.
  • For logging, prefer UTC with explicit tzinfo to avoid ambiguity.
  • When comparing datetimes, both must be either naive or aware to avoid TypeError.
Common misconception
utcnow returns an aware UTC datetime — it does not. You must attach tzinfo explicitly.
