Parse and compute
Example: parse a DD-MM-YYYY timestamp and compute days since that entry.
from datetime import datetime

log_timestamp_str = "15-03-2023 10:45:30"
parsed_dt = datetime.strptime(log_timestamp_str, "%d-%m-%Y %H:%M:%S")
print(parsed_dt)

later = datetime(2023, 3, 20, 12, 0, 0)
diff = later - parsed_dt
print(f"Difference: {diff.days} days and {diff.seconds//3600} hours")
Explanation
Parsing succeeds only when the format exactly matches input. After parsing, subtract to obtain a timedelta to measure intervals for alerts or reports.
Error handling
Use try/except around strptime to skip or log malformed timestamps when processing large files.
