Activity: Event Scheduler
Follow the starter code and verify outputs at each step.
Starter code
from datetime import datetime, timedelta

# 1
event_datetime = datetime(2023, 12, 25, 10, 30, 0)
print('Original Event:', event_datetime)

# 2
reminder_offset = timedelta(days=3, hours=2)
reminder_datetime = event_datetime - reminder_offset
print('Reminder Date/Time:', reminder_datetime)

# 3
formatted_event = event_datetime.strftime("%A %B %d, %Y - %I:%M %p")
print('Formatted Event:', formatted_event)

# 4
party_string = "2024/07/04 18:00"
party_datetime = datetime.strptime(party_string, "%Y/%m/%d %H:%M")
print('Independence Day Party:', party_datetime)

# 5
time_difference = party_datetime - event_datetime
print('Days between events:', time_difference.days)
What to verify
  • Reminder is earlier than the event by exactly 3 days and 2 hours.
  • Formatted string matches the requested pattern and shows AM/PM correctly.
  • Parsed datetime matches the intended calendar and time values.
  • The days attribute of the difference is the integer count of full days between events.
Key Takeaway
Work step-by-step and print intermediate values to confirm each transformation is correct.
