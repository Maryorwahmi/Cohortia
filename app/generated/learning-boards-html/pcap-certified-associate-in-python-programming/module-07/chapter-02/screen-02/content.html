01 Create date/time/datetime
Construct objects with integer arguments and use class methods to get current time, ensuring you represent the intended moment precisely.

02 Timedelta arithmetic
Use timedelta to add or subtract durations like days and hours to compute deadlines, reminders, and intervals reliably.
VERIFIED COMPETENCY MILESTONE
03 Format with strftime
Convert datetimes to strings using directives like %Y %m %d %H %M %S so output matches user expectations and logs are consistent.
VERIFIED COMPETENCY MILESTONE
04 Parse with strptime & timezones
Parse strings with strptime using an exact format, and distinguish naive from aware datetimes for basic timezone handling.
