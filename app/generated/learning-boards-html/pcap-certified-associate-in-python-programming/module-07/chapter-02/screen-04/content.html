Module 7 › Chapter 7.2 › Core types
Definitions
date
Represents year, month, and day. Use for birthdays and calendar dates.
time
Represents hour, minute, second, microsecond. Use for daily schedules.
datetime
Combines date and time into a single moment. Often returned by now().
Example
from datetime import date, time, datetime

bday = date(1990, 5, 17)
meeting_time = time(14, 30)
meeting = datetime(2023, 10, 27, 14, 30)
print(bday)
print(meeting_time)
print(meeting)
Why it matters
  • Choosing the wrong type can cause API mismatches and surprising errors.
  • Date-only values ignore time components when compared to datetimes.
  • Converting between them requires explicit construction to avoid ambiguity.
Key Takeaway

Match the type to your domain need: calendar, clock, or a full timestamp.
