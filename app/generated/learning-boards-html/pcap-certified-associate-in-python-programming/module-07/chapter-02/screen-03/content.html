Apply & Master Objectives
Tasks you will practice with verification checks
01 Make aware datetimes
Practice converting a naive now object to UTC or a local timezone using replace(tzinfo=timezone.utc) and verify comparisons across zones.
02 Timedelta scenarios
Create reminders and compute durations; verify by printing resulting datetimes and comparing days or seconds attributes.
03 Format variations
Produce different user-facing strings using directives and check results against expected examples.
04 Parse logs
Parse common log timestamp formats precisely with strptime and handle ValueError by checking your format string.
