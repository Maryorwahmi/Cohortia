Live code example
Copy and run to observe printed datetimes and results of arithmetic.
from datetime import datetime, timedelta

# Creating a specific datetime
current_moment = datetime(2023, 10, 27, 14, 30, 0)
print('Current moment:', current_moment)

# Getting current local time
now = datetime.now()
print('Now (local):', now)

# Adding 5 days and 3 hours
future_moment = current_moment + timedelta(days=5, hours=3)
print('Future moment:', future_moment)
Explanation
  • Construct datetime with year, month, day, hour, minute, second.
  • now() captures the current local time but is naive by default.
  • Adding timedelta returns a new datetime object.
Pro tip
Print intermediate values when debugging schedules to verify offsets and avoid off-by-one-day errors across midnight boundaries.
