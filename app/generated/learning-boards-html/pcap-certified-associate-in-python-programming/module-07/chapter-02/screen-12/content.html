Common sources of bugs
Format directive errors
Check for %m versus %M and %I versus %H; small differences change results or raise errors.
Timezone mixing
Do not compare naive and aware datetimes; convert or make them consistent first.
Incorrect assumptions
Timedelta does not support months/years. Use calendar-aware tools when needed.
Debug checklist
  1. Print raw input and the format string when parsing fails.
  2. Check tzinfo on both operands before comparing datetimes.
  3. Write small tests asserting expected timedelta attributes.
