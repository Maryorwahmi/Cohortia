Function Parameters: defaults & flexibility
Practical patterns to accept optional inputs, variable arguments, and enforce clarity with keyword-only parameters.
Interactive 16:9 Masterclass
In this lesson

Learn safe defaults, how *args and **kwargs collect inputs, and how keyword-only parameters improve API clarity.

Why it matters

Reduce bugs caused by shared mutable defaults and design functions that adapt to future needs without breaking code.

Defaults
Provide sensible fallbacks and optional parameters without breaking existing callers.
*args / **kwargs
Accept variable numbers of positional or named arguments for flexible utilities.
Keyword-only
Force explicit names to avoid ambiguous positional calls and improve readability.
Concept Map
Default values
Optional parameters with fallbacks
*args / **kwargs
Tuples and dictionaries of extra inputs
Keyword-only
A bare * requires later args be named
Quick takeaway
Combine these patterns to build clear, adaptable functions while avoiding common pitfalls.
