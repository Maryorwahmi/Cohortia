Core Concept › Arbitrary keyword arguments
Use **kwargs to accept named extras
**kwargs collects all unmatched keyword arguments into a dictionary for flexible handling.
Points to remember:
  • Explicit parameters consume matching names first; kwargs only contains the extras.
  • The collected object is a dict; you can iterate items() to process them.
  • Useful for forwarding context to logging, formatting, or adapter functions.
Pro tip
Document expected keys even when you accept arbitrary keywords to help callers use your API.
Example
def display_profile(**details):
  """Displays user profile details."""
  print("User Profile:")
  for key, value in details.items():
    print(f"  {key.replace('_', ' ').title()}: {value}")

# Callers can pass any named fields
display_profile(name="Alice", age=30, city="New York")
Concrete scenario: accept extra metadata in a logging call so new fields can be added without updating the signature. Misconception check: kwargs won't include named args that match a parameter declared in the signature.
