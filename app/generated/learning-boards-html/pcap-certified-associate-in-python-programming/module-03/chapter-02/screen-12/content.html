log_message pattern
Required message, optional level default, and arbitrary keyword context are combined to produce readable logs.
Design choices explained:
  • Keep message positional for convenience.
  • Give level a default like "INFO" so callers rarely specify it.
  • Accept **context to allow future fields without changing the signature.
Starter code
import datetime

def log_message(message, level="INFO", **context):
  """Logs a message with optional level and additional context."""
  timestamp = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
  log_entry = f"[{timestamp}] [{level.upper()}] {message}"

  if context:
    context_str = ", ".join([f"{k}={v}" for k, v in context.items()])
    log_entry += f" ({context_str})"

  print(log_entry)

# Examples:
log_message("User logged in", username="alice", ip_address="192.168.1.100")
log_message("Application started")
Try extending this by adding a keyword-only parameter like show_timestamp=False to practice keyword-only enforcement and to control output formatting.
