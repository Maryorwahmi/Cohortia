Core Concept › Keyword-only arguments
Force named parameters with a bare *
A bare asterisk in the signature makes all following parameters keyword-only.
Why use keyword-only parameters:
  • Prevents accidental positional arguments from shifting meaning.
  • Makes call sites clearer and self-documenting.
  • Useful for flags and optional settings like is_admin or timeout.
Example
def create_user(username, *, email, password, is_admin=False):
  """Creates a new user profile.
  'email' and 'password' must be passed as keyword arguments.
  """
  print(f"Creating user: {username}")
  print(f"  Email: {email}")
  print(f"  Password (hashed): {'*' * len(password)}")
  print(f"  Admin: {is_admin}")

# Correct:
create_user("john_doe", email="john@example.com", password="securepassword123")

# Incorrect call raises TypeError:
# create_user("peter_pan", "peter@example.com", "neverland")
Concrete scenario: require API keys or security-sensitive parameters be named to avoid accidental leakage or mis-ordering. Misconception check: keyword-only parameters still accept defaults like any other parameter.
