Learning Objectives
What you'll be able to do after this chapter
Bloom: Learn → Understand → Apply → Master
01
Use default parameter values
Make arguments optional with sensible fallbacks. Example: a greeting function with a default message so callers can omit it safely.
VERIFIED COMPETENCY MILESTONE
02
Accept arbitrary positional args
Use *args to collect extra positional inputs into a tuple. Example: a sum function that handles any count of numbers.
VERIFIED COMPETENCY MILESTONE
03
Accept arbitrary keyword args
Use **kwargs to gather named values into a dictionary for flexible context like user profiles or logging.
VERIFIED COMPETENCY MILESTONE
04
Avoid mutable default traps
Prefer None and create a fresh mutable object inside the function to avoid shared state across calls.
VERIFIED COMPETENCY MILESTONE
