Comparison › *args vs **kwargs and combined signatures
Mixing positional and keyword collections
Design functions that accept a core value, a variable list, and extra named options.
Key binding rules:
  • Positional-only or regular positional parameters fill first.
  • Remaining positionals go into *args as a tuple.
  • Named parameters are matched first; leftover names go into **kwargs as a dict.
Example
def process_data(name, *items, **options):
  print(f"Name: {name}")
  print(f"Items: {items}")
  print(f"Options: {options}")

process_data("Report 1", 10, 20, 30, format="pdf", date="2023-10-26")

# Output:
# Name: Report 1
# Items: (10, 20, 30)
# Options: {'format': 'pdf', 'date': '2023-10-26'}
Scenario: create a wrapper that forwards a primary resource name, any number of data items, and options like format and date to an exporter function. Misconception check: keyword arguments never flow into *args; they are either bound by name or end up in **kwargs.
