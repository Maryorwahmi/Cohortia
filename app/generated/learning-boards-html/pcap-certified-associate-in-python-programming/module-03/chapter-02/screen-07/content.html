Core Concept › Arbitrary positional arguments
Use *args to accept many positionals
*args collects leftover positional arguments into a tuple for iteration or forwarding.
Points to remember:
  • The name is a convention; only the * matters to collect values.
  • Values matching earlier parameters are bound first, then remaining positionals go to args.
  • Use when callers legitimately supply varying numbers of positionals.
Pro tip
Prefer keyword arguments when parameters are conceptually named to enhance readability.
Example
def calculate_sum(*numbers):
  """Calculates the sum of an arbitrary number of numbers."""
  total = 0
  for num in numbers:
    total += num
  return total

print(calculate_sum(1, 2, 3))        # 6
print(calculate_sum(10, 20, 30, 40)) # 100
print(calculate_sum())               # 0
Concrete scenario: build a logger that accepts a variable list of tags as positional arguments. Misconception check: args is a tuple, not a list, and the tuple reflects what was passed positionally.
