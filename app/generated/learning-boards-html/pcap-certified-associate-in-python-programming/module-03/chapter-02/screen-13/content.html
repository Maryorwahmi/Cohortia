Troubleshooting › Common mistakes
Typical errors and how to fix them
SyntaxError
Cause: invalid parameter ordering, e.g., placing **kwargs before keyword-only parameters. Fix: reorder to positional, *args, keyword-only, **kwargs.
TypeError at call time
Cause: passing positional values where keyword-only parameters are required. Fix: pass the parameter by name or change the signature.
Mutable default bugs
Cause: shared default list or dict. Fix: use None and create a new container inside the function.
Misunderstanding args/kwargs
Cause: expecting kwargs in *args or vice versa. Fix: log types and contents inside the function to confirm where values land.
Check your understanding
Given a failing test that shows a function returning accumulated items, ask: was a mutable default used? If yes, replace with None and re-run the test.
