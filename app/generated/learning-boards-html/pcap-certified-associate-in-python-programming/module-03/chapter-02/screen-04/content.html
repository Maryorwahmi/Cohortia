Module 3 › Chapter 3.2 › Default parameter values
Definition
Defaults make arguments optional
Assign a value in the signature so callers may omit the argument. Explicit values override the default.
Key points:
  • Defaults are evaluated at function definition time.
  • Defaults provide backward compatibility when extending signatures.
  • Prefer immutable defaults or safe initialization when a mutable default is needed.
Key Takeaway

Use defaults to make parameters optional and choose defaults that avoid shared mutable state.

Code example
def greet(name, message="Hello"):
  """Greets a person with a customizable message."""
  print(f"{message}, {name}!")

# Uses default message
greet("Alice")  # Hello, Alice!

# Overrides default
greet("Bob", "Hi there")  # Hi there, Bob!

# Using keyword arguments
greet(message="Good morning", name="Charlie")
Concrete scenario: add a default parameter when adding optional behavior to a function so existing calls remain valid. Misconception check: defaults are not re-created each call when mutable; prefer None when you need a fresh object per call.
