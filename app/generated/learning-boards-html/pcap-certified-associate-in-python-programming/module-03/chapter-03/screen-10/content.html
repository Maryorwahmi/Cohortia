When to use nonlocal

Use nonlocal inside a nested function when you need to assign to a name that lives in an enclosing function. This updates the outer name rather than creating a fresh local.

Example snippet
def outer_enclosing():
    x = 5
    def inner_enclosing():
        nonlocal x
        x += 1
        print(f"Inside inner_enclosing, x: {x}")
    inner_enclosing()
    print(f"Inside outer_enclosing, x: {x}")
Misconception

nonlocal does not make the name global; it only refers to the nearest non-global enclosing scope.

Why it matters

nonlocal lets closures maintain mutable private state without polluting module-level variables, supporting safer encapsulation.
