LEGB in Python

Master the rules that determine where a name is found and when assignments create new variables. Clear scope reasoning prevents subtle bugs.

Estimated runtime: 11 min animated explainer
Why this matters

Scope determines visibility and lifetime for variables. Predicting which name is read or modified helps you avoid NameError, unintentional shadowing, and difficult-to-find side effects in larger programs.

Practical payoff: Reasoning about state makes functions safer to reuse and test.
Quick orientation
Local
Variables inside a function. Temporary and not visible outside.
Enclosing
If functions are nested, inner functions can access outer function variables.
Global
Top-level module variables, accessible across the module unless shadowed.

Shadowing example

Nonlocal & global

Explore Key Topics
Local scope — lifetime limited to function execution; essential for small, predictable functions.
Enclosing scope — enables closures; use nonlocal to modify enclosing names.
Global & built-in — accessible widely; modifying them requires care and explicit keywords.
