Module 3 › Chapter 3.3 › Key Concepts
Scope
Region where a variable is accessible and how long it exists.
LEGB Rule
Search order: Local, Enclosing, Global, Built-in.
Variable Shadowing
A local name can hide an outer name with the same identifier.
global
Declare assignment should affect the module-level name.
nonlocal
Declare assignment should affect the nearest enclosing (non-global) scope.
Built-in caution
Don't shadow built-ins like len or print; it removes standard functionality in that scope.
Summary takeaway

Use LEGB to reason about name resolution. Prefer explicit input/output; use nonlocal for closures, and global only for intentional module mutations.
