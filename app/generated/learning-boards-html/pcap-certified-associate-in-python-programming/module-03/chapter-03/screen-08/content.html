Module 3 › Chapter 3.3 › Using global correctly
Code walkthrough
counter = 0

def increment_good():
    global counter
    counter += 1
    print(f"Inside increment_good, global counter: {counter}")

increment_good()  # increments the module-level counter
print(f"Outside function, global counter: {counter}")
This example shows explicit declaration of intent. The assignment modifies the global counter because of the global statement.
Alternative pattern

Return the new value from the function and assign at the call site. This keeps the function pure and easier to test.

def increment_return(v):
    return v + 1

counter = increment_return(counter)
Pitfall

Using global widely scatters mutations across the module and can hide dependencies that make debugging harder.

Key Takeaway

Use global only for intentional module-level state; prefer returns to keep functions independent.
