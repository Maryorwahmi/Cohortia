Module 3 › Chapter 3.3 › What is scope?
Definition & reason

Scope determines where a variable name is bound and how long that binding lives. Local variables created in a function exist only during the function's execution; they are destroyed when it returns. This isolates temporary computation and reduces unintended interactions between functions.

Concrete example
def my_function():
    x = 10  # x is local to my_function
    print(f"Inside function, x: {x}")

my_function()
# print(x)  # NameError: x not defined in global scope
Key Takeaway

Local scope gives functions private names; use arguments and returns to pass state instead of relying on cross-function visibility.

Common misconception

Assuming a name assigned inside one function is visible in another. Assignment inside a function creates a local name unless specified otherwise.

Why it matters

Predictable scopes reduce bugs and make functions easier to test and reuse. When you need shared state, choose an explicit mechanism rather than accidental reliance on globals.
