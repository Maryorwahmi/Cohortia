Module 3 › Chapter 3.3 › Local vs Global
Comparison: read vs assign
Reading a global
If you only reference a global variable inside a function, Python will read the global value without needing a declaration.
Assigning inside a function
Assignment creates or binds a local name, which can shadow a global variable of the same name.
Example: bad vs good
counter = 0

def increment_bad():
    counter = 1  # creates a new local 'counter'
    print(f"Inside increment_bad, local counter: {counter}")

increment_bad()
print(f"Outside function, global counter: {counter}")  # still 0

# Correct using global:
counter = 0

def increment_good():
    global counter
    counter += 1
    print(f"Inside increment_good, global counter: {counter}")
Key Takeaway

Prefer returning values to modify state where possible; use global only when module-level mutation is intentional and clear.
