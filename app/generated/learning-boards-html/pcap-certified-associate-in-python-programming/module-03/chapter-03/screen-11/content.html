Module 3 › Chapter 3.3 › Design choices
Compare patterns
Use return values
Most explicit and testable approach. Clear data flow; minimal side effects.
Use nonlocal closures
Encapsulates state per factory instance. Good for counters and small private state.
Use global sparingly
Explicit module-level mutation; document side effects and keep focused functions.
Concrete scenario

Suppose multiple parts of a program need a separate counter each: return a closure-based counter or a small object rather than a single global counter so each caller gets independent state.

Key Takeaway

Choose the pattern that keeps state explicit and makes side effects visible at the call site whenever possible.
