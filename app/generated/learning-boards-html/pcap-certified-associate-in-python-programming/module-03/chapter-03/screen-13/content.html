def create_counter():
    """
    Creates and returns a counter function.
    Each call to the returned function increments an internal count.
    """
    count = 0 # This variable is in the enclosing scope for 'increment_and_get'

    def increment_and_get():
        nonlocal count # Declare intent to modify 'count' from the enclosing scope
        count += 1
        return count

    return increment_and_get

# Test your counter
counter1 = create_counter()
print(f"Counter 1: {counter1()}") # Expected: 1
print(f"Counter 1: {counter1()}") # Expected: 2
print(f"Counter 1: {counter1()}") # Expected: 3

counter2 = create_counter() # Create a new independent counter
print(f"Counter 2: {counter2()}") # Expected: 1
print(f"Counter 1: {counter1()}") # Expected: 4 (counter1 is still independent)
# --- END CODE TEMPLATE ---
Run the test to confirm independence of counters. If both counters share state, you likely used a global instead of an enclosing variable.
Expected behavior

Each counter maintains its own count in the enclosing scope. Calls to one counter do not affect the other.

Common mistake

Forgetting nonlocal causes inner assignment to create a new local variable or raises an error when reading before assigning.

Key Takeaway

Closures plus nonlocal are the canonical way to create lightweight independent state without globals.
