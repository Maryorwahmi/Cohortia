LEGB process

When Python resolves a name it follows a strict path. Think of this as a search from the innermost scope outward. If the name is found at any step, Python stops and uses that binding.

Local
Names defined in the currently executing function; most immediate.
Enclosing
Names in outer functions when functions are nested; available to inner functions.
Global
Top-level names in the module; accessible across functions unless shadowed.
Built-in
Language-provided names like the print function and len.
Concrete example
value = 10

def func1():
    value = 20
    print(f"Inside func1: {value}")

def func2():
    print(f"Inside func2: {value}")

func1()
func2()
print(f"Global: {value}")
Misconception check

func1 creates a local value that shadows the global while it runs. func2 reads the global because it has no local value.
