Module 3 › Chapter 3.3 › NameError & debugging
Why NameError occurs

NameError indicates Python searched Local, Enclosing, Global, and Built-in and did not find the name. This often arises when a name was intended to be available but was created in a different scope or misspelled.

Debug checklist
  • Check if the name was defined in another function and not returned or passed.
  • See if assignment created a local that shadowed the expected binding.
  • Confirm spelling and capitalization.
  • If using nested functions, consider nonlocal for assignments to enclosing names.
Example pitfall

Assigning to a name before declaring nonlocal leads to UnboundLocalError when the inner function tries to read it. Order of operations matters.

Fix

Make the flow explicit: pass arguments, return values, or use nonlocal/global intentionally and document the side effects.
