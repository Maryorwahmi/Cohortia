Closures and captured state

When a function is nested, the inner function can reference names from the outer function. If the inner function is returned, those outer names remain accessible and form a closure. This enables encapsulated state without globals.

Concrete example (create_counter)
def create_counter():
    count = 0
    def increment_and_get():
        nonlocal count
        count += 1
        return count
    return increment_and_get

counter1 = create_counter()
print(counter1())  # 1
print(counter1())  # 2

counter2 = create_counter()
print(counter2())  # 1
Misconception

Enclosing variables are not global; their lifetime can be extended by returned inner functions, forming closures that hold state privately.

Pro tip

Use closures for light-weight encapsulation, but prefer explicit objects or return values for complex state to improve clarity.
