Learning Objectives

Practice LEGB: define, trace, and safely modify names across scopes.

Bloom: Learn → Understand → Apply → Master
01
Define scope & lifetime
Explain where a variable is visible and how long it exists.
Mnemonic: think "box lifetime" — a box opens when the function runs, closes when it returns.
VERIFIED COMPETENCY MILESTONE
02
Trace the LEGB rule
Predict which scope supplies a name when code runs.
Mnemonic: search from inner to outer: Local, Enclosing, Global, Built-in.
VERIFIED COMPETENCY MILESTONE
03
Use global safely
Modify globals with the global keyword or return new values explicitly.
Mnemonic: prefer returned state over hidden mutations.
VERIFIED COMPETENCY MILESTONE
04
Use nonlocal for closures
Modify enclosing-scope variables from a nested function when needed.
Mnemonic: nonlocal reaches one box outwards, not all the way to the global scope.
VERIFIED COMPETENCY MILESTONE
