Sort using key lambdas

A small lambda often suffices to extract a key for sorting complex items.

points = [{'x': 2, 'y': 5}, {'x': 1, 'y': 1}, {'x': 3, 'y': 3}]

# Sort by y coordinate
points.sort(key=lambda p: p['y'])
print(points)  # [{'x': 1, 'y': 1}, {'x': 3, 'y': 3}, {'x': 2, 'y': 5}]

# Multi-field key using tuple
people = [{'name': 'Alice', 'age': 30}, {'name': 'Bob', 'age': 25}]
people.sort(key=lambda p: (p['age'], p['name']))
Practical notes
  • Key functions should be pure and cheap; avoid heavy computations inside them.
  • For repeated expensive keys, precompute key values in a list of tuples and sort those instead.
  • Misconception: lambdas mutate data; they only compute keys and return values.
Key Takeaway

Use key lambdas for concise ordering; when ordering logic grows, prefer named functions or tuple keys for clarity and maintainability.
