Using map with functions and lambdas

Map applies the same callable to each element; remember it returns an iterator in Python 3.

numbers = [1, 2, 3, 4]

# Named function
def double(x):
  return x * 2

doubled_numbers_iter = map(double, numbers)
print(list(doubled_numbers_iter))  # [2, 4, 6, 8]

# Lambda
squared_numbers_iter = map(lambda x: x * x, numbers)
print(list(squared_numbers_iter))  # [1, 4, 9, 16]

# Map with multiple iterables
list1 = [1, 2, 3]
list2 = [10, 20, 30]
sum_lists_iter = map(lambda x, y: x + y, list1, list2)
print(list(sum_lists_iter))  # [11, 22, 33]
Explanation
  • Map returns an iterator; use list() to see results immediately.
  • Multiple iterables advance in parallel; the mapping function must accept the same number of arguments.
  • Choose named functions for clarity if the transform is reused or complex.
Key Takeaway

Map is for elementwise transforms and supports parallel iteration across multiple iterables; it returns a lazy iterator in Python 3.
