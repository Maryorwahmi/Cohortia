Definition

Lambda syntax

A lambda defines a single expression function inline. Use it for short callbacks like sorting keys or simple transforms in map and filter.

# Example: add two numbers with a lambda
add_lambda = lambda x, y: x + y
print(add_lambda(5, 3))  # Output: 8

# Example: square a number
square_lambda = lambda x: x * x
print(square_lambda(4))  # Output: 16

# Lambda used as a sort key
points = [{'x': 2, 'y': 5}, {'x': 1, 'y': 1}, {'x': 3, 'y': 3}]
points.sort(key=lambda p: p['y'])
print(points)  # Sorted by 'y' value
Explanation
When to use
Short, single-expression behavior such as small transforms or keys for sorting.
Common mistake
Putting complex logic into a lambda instead of a named function reduces clarity and testability.
Pro tip
If you repeat or test the logic, extract a named def to improve reuse and documentation.
Key Takeaway

Lambda is compact and useful for small callbacks; prefer def for multi-step or documented behavior.
