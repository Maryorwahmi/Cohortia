Checklist to choose the right tool

Is it a simple transform?
Prefer lambda or comprehension for short expressions.
Do you need laziness?
Choose map/filter to avoid creating intermediate lists.
Is it a standard aggregation?
Use sum, max, min rather than reduce when possible.
Is the function reusable?
If yes, keep it named and use map to apply it.
Will others read this code?
Favor the clearest, most explicit idiom for team readability.
Is the key expensive?
Precompute keys or cache them before sorting to avoid repeated work.
Key Takeaway

Answer these simple questions to select the clearest, most maintainable approach: simplicity, reuse, laziness, and built-in coverage.
