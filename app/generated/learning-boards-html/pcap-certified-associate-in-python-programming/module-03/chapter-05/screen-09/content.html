Pipeline example

Discount → Filter → Sum

A typical real-world pipeline applies a transform, filters relevant items, then aggregates a total.

from functools import reduce

products = [
  {"name": "Laptop", "category": "Electronics", "price": 1200, "in_stock": True},
  {"name": "Mouse", "category": "Electronics", "price": 25, "in_stock": True},
  {"name": "Monitor", "category": "Electronics", "price": 300, "in_stock": True},
  {"name": "Webcam", "category": "Peripherals", "price": 50, "in_stock": True},
]

# 1) map to discounted prices
discounts = map(lambda p: p['price'] * 0.9, products)

# 2) filter for in-stock electronics
electronics_in_stock = filter(lambda p: p['in_stock'] and p['category'] == 'Electronics', products)

# 3) reduce to total in-stock value (example requires mapping prices first)
total = reduce(lambda total, p: total + p['price'] if p['in_stock'] else total, products, 0)
print(total)
Notes
  • Keep pipeline order logical: filter before expensive transforms when possible to save work.
  • Use sum for numeric totals where appropriate instead of reduce to improve clarity.
  • Pitfall: mapping then filtering versus filtering then mapping can change performance and intermediate sizes; choose order intentionally.
Key Takeaway

Design pipelines for intent and efficiency: filter early to reduce work, materialize only when necessary, and prefer named built-ins for common aggregates.
