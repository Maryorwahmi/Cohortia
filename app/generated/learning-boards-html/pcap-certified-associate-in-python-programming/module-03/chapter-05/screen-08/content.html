Side-by-side examples

numbers = [1, 2, 3, 4]

# Map + lambda
squares_map = list(map(lambda x: x * x, numbers))

# List comprehension equivalent
squares_lc = [x * x for x in numbers]

# Filter + map
even_squares = list(map(lambda x: x * x, filter(lambda x: x % 2 == 0, numbers)))

# Comprehension equivalent
even_squares_lc = [x * x for x in numbers if x % 2 == 0]
Tradeoffs
  • Comprehensions are usually more readable for simple transforms and filters.
  • Map and filter are lazy and can be more memory efficient for large streams.
  • If you already have a function, map avoids writing an inline expression and can improve reuse.
Key Takeaway

Choose the form that makes intent clearest: comprehensions for inline clarity, map/filter for laziness or reuse.
