Definition & examples

Reduce in functools

Reduce applies a two-argument function cumulatively to items, optionally starting with an initializer.

from functools import reduce

numbers = [1, 2, 3, 4, 5]

# Sum all numbers
sum_result = reduce(lambda x, y: x + y, numbers)
print(sum_result)  # 15

# Find maximum
max_result = reduce(lambda x, y: x if x > y else y, numbers)
print(max_result)  # 5

# Concatenate strings
words = ["Python", "is", "awesome"]
sentence = reduce(lambda x, y: x + " " + y, words)
print(sentence)  # Python is awesome
Explanation
  • If an initializer is provided it becomes the first accumulator value; otherwise the first item becomes the initial accumulator.
  • Prefer sum, max, min when aggregating common operations — they document intent and are clearer.
  • Misconception: reduce is not always the most readable; use it only when custom fold behavior is required.
Key Takeaway

Use reduce for custom cumulative logic; prefer specific built-ins for common aggregates to increase clarity.
