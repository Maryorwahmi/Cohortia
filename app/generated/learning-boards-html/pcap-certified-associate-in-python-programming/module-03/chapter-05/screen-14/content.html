Module 4 › Chapter 3.5 › Key Concepts
Lambda Function
Anonymous, single-expression functions for small callbacks.
map()
Applies a function to each item and returns an iterator of results.
filter()
Selects items for which a predicate is true, returning a lazy iterator.
Summary
These three concepts form the basis of concise, composable data transformations in Python. Keep laziness and readability in mind when you choose which to use.
