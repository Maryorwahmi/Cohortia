Lambda, map, filter & reduce

Concise function expressions and three higher-order tools for transforming and aggregating iterables in Python.

In this lesson: concise transformations
Lambda

Anonymous single-expression functions. Good for short callbacks like sorting keys and simple transforms.

Map / Filter

Map transforms each element; filter selects elements by a predicate. Both return iterators.

Reduce

Cumulative application to reduce an iterable to a single value. Found in functools.

List comprehensions

Often a more Pythonic and readable alternative for many map/filter patterns.

Transform
map applies a function to each element and yields transformed items.
Select
filter keeps elements that meet a condition, producing a filtered iterator.
Aggregate
reduce combines items cumulatively into a single result when needed.
Key Takeaway

Use the simplest tool that expresses your intent clearly: lambda for small callbacks, list comprehensions for straightforward transforms, and reduce only when you need cumulative aggregation.
