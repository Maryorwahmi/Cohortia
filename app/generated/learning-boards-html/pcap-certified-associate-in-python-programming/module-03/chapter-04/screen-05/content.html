Module 3 › Chapter 3.4 › Import: module_name
Pattern

Use import module_name to bring a module into your script, then reference its attributes with the module prefix.

# main_script.py
import my_math

print(f"PI from module: {my_math.PI}")
print(f"Sum: {my_math.add(5, 3)}")
Why this helps
  • Clarity: origin of names is explicit.
  • Safety: reduces accidental name clashes.
  • Refactor-friendly: local renames don't break module access.
Example: aliasing
import my_math as mm

print(mm.add(2, 4))
Common misconception

Some think aliases hide the origin. In fact, a well-chosen short alias keeps clarity while improving brevity.

Check your understanding

When would you prefer import module_name over from module_name import name? Think about readability and risk of name collisions.

Key Takeaway

Default to importing modules and using the module prefix for clarity and safety.
