Module 3 › Chapter 3.4 › What to Remember
Group by responsibility
Each module should express a single concern, like math helpers or string utilities.
Choose imports consciously
Prefer qualified imports for clarity; selective imports for small, explicit uses.
Guard executable code
Use the __name__ check to prevent tests and prints from running on import.
Action
Refactor one script into a module and import it. Add a small guarded test to confirm behavior and inspect sys.path if imports fail.
