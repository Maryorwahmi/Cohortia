Module 3 › Chapter 3.4 › Why modules?
Definition

A module is a .py file containing functions, classes, and variables related to a specific concern. It creates a named unit you can import and reuse.

Common benefits
  • Clear namespace for definitions
  • Reusable components across scripts
  • Smaller files that are easier to test and review
Key Takeaway

Prefer multiple focused modules over one large file to reduce cognitive load and duplication.

Example: split a script
my_math.py
PI = 3.14159

def add(a, b):
  return a + b

def subtract(a, b):
  return a - b
main.py
import my_math

print(my_math.add(5, 3))
print(my_math.PI)
Common mistake

Putting unrelated utilities together because they seem small. Prefer grouping by responsibility instead of size.

Pro tip

Start with one module per logical concern, then split further when a file grows or has distinct responsibilities.
