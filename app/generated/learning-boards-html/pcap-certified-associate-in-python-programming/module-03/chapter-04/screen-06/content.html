Module 3 › Chapter 3.4 › Selective vs Wildcard
Selective import
from my_math import PI, add

print(PI)
print(add(4, 2))
  • Shorter calls, direct access to names.
  • Risk: name clashes with local definitions.
Wildcard import (discouraged)
from my_math import *

# All public names now in the current namespace
  • Conceals origin of names.
  • Makes debugging and maintenance harder.
Quick rule

If you need more than a couple of names, prefer importing the module to keep code provenance clear.
