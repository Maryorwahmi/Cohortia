Module 3 › Chapter 3.4 › Module Search Path
Search order
  1. The directory containing the input script or current directory
  2. Directories in PYTHONPATH environment variable
  3. Standard library directories
  4. site-packages for installed libraries
Inspect
import sys
print(sys.path)
Common issues
  • Shadowing a standard library name with a local file.
  • Project directory missing from sys.path when running from a different working directory.
  • Relying on PYTHONPATH without documenting it for collaborators.
Fixes

Rename local files that conflict, add a package structure with __init__.py, or modify PYTHONPATH carefully and document it.

Key Takeaway

Use sys.path to make import resolution visible and avoid accidental shadowing of names.
