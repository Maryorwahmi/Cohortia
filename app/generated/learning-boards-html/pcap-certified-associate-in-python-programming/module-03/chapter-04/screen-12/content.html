Module 3 › Chapter 3.4 › Key Concepts
Module
A .py file grouping functions, classes, and variables for reuse.
Import styles
import, from-import, and import as each have trade-offs between clarity and brevity.
__name__ idiom
Guard code to run tests only when a file is executed directly, not on import.
Module search path
Python checks script dir, PYTHONPATH, standard library, then site-packages.
Package
A directory with __init__.py used to group related modules hierarchically.
__init__.py
Marks a directory as a package and can export a package-level interface.
Summary
Use modules and packages to split responsibilities, prefer explicit imports for clarity, guard executable code, and inspect sys.path to solve import problems.
