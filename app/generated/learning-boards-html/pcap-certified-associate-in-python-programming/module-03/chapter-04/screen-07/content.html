Module 3 › Chapter 3.4 › import ... as
Example
import my_math as mm

print(mm.PI)
print(mm.subtract(7, 2))
When to alias
  • Long module names that reduce readability.
  • Multiple modules with similar function names.
  • Interactive or repeated use where brevity matters.
Guidelines
  • Choose conventional short names when available.
  • Avoid cryptic single-letter aliases unless standard.
  • Document non-obvious aliases in module headers.
Common mistake

Over-aliasing everything makes code harder to read for new contributors. Be selective.

Key Takeaway

Use aliasing to balance brevity with clarity; keep aliases recognizable and documented.
