Modules and Packages

Use modules to keep related functions together and packages to group modules. This improves reuse, testing, and discoverability.

In this lesson
  • What a module is and common import styles.
  • How to run module tests safely with the __name__ idiom.
  • How Python finds modules and how to structure packages.

my_math.py
# my_math.py
PI = 3.14159

def add(a, b):
  """Returns the sum of two numbers."""
  return a + b

def subtract(a, b):
  """Returns the difference of two numbers."""
  return a - b

if __name__ == "__main__":
  print("Running my_math.py directly as a script.")
  print(f"2 + 3 = {add(2, 3)}")
Package: utils/
__init__.py — marks the folder as a package
string_helpers.py — string helpers like capitalize_words
math_helpers.py — numeric helpers like multiply
Key Takeaway

Start small: group related functions into modules, group modules into packages, and use clear names.
