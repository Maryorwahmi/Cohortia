Module 3 › Chapter 3.4 › __name__ idiom
Concept

Module-level code runs when a module is imported. Use the __name__ check to prevent test or demo code from running on import.

if __name__ == "__main__":
  print("Running my_math.py directly as a script.")
  print(f"2 + 3 = {add(2, 3)}")
Why it matters
  • Prevents side effects during import.
  • Keeps library modules safe for reuse.
  • Enables simple ad-hoc testing without a test framework.
Misconception

People sometimes assume imports never execute code; in fact module-level code runs — so guard side effects.

Try this

Run a module directly and import it from another script to observe the difference in behavior.
