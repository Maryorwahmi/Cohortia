Import a submodule
from utils import string_helpers
from utils.math_helpers import multiply

text = "hello world"
capitalized = string_helpers.capitalize_words(text)
print(capitalized)
print(multiply(4, 5))
Hands-on activity

Create my_utilities package with string_utils.py and numeric_utils.py. Implement reverse_string and is_even, then import them in main.py to test.

Starter templates
# my_utilities/string_utils.py
def reverse_string(s):
  return s[::-1]

# my_utilities/numeric_utils.py
def is_even(n):
  return n % 2 == 0
Key Takeaway

Use package imports to compose functionality from small, focused modules and practice by building a tiny utilities package.
