Module 3 › Chapter 3.4 › Packages & __init__.py
Example structure
my_project/
├── main.py
└── utils/
    ├── __init__.py
    ├── string_helpers.py
    └── math_helpers.py
You can import with from utils import string_helpers or from utils.math_helpers import multiply.
__init__.py role
  • Marks the directory as a package.
  • Can import submodules to expose a package-level API.
  • Can be empty for simple packages.
Pro tip

Start with simple packages; only add __init__ exports when you want a cleaner top-level interface for consumers.

Key Takeaway

Use packages to group related modules and provide a stable, discoverable API surface.
