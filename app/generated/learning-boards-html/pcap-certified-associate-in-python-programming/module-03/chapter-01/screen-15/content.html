Docstring
Triple-quoted string under def that documents purpose, args, and returns for users and tools.
Mutable side effects
Passing a list or dict can lead to in-place changes; document when a function mutates its inputs.
Common errors
TypeError for wrong args, IndentationError for misaligned bodies, forgetting parentheses yields a function object.
Final takeaway

Write clear signatures and docstrings, test with known inputs, and read error tracebacks carefully — these habits make functions reliable and reusable.
