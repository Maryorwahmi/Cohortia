Module 3 › Chapter 3.1 › What is a function?
Definition

A function is a named block of code that runs when called. It accepts parameters and may return a value. Definitions do not execute the body.

Example
def greet_person(name):
  """Prints a personalized greeting message."""
  print(f"Hello, {name}!")

# Call the function:
greet_person("Alice")
Takeaway: Definition creates, call executes. Use parentheses to call a function.
Misconception: Defining a function runs code immediately — it does not.
Why functions help
  • Reduce repetition by centralizing logic you call multiple times.
  • Improve readability by naming a block according to its purpose.
  • Enable testing and reuse across programs.
Check your understanding
If you define a function but forget parentheses when trying to run it, you will reference the function object instead of executing it. How would you spot this in a program? Look for no output and values that are function objects instead of expected results.
