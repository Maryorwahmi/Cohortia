Module 3 › Chapter 3.1 › Key Concepts — Part 1
Function
A named block of code defined with def for reuse and modularity.
Parameter vs Argument
Parameter is the placeholder in a definition; argument is the actual value provided at a call.
Return
Sends a value back to the caller; functions without return return None implicitly.
Summary Takeaway

Master these basics: define functions with def, name parameters clearly, return values when needed, and document behavior with docstrings.
