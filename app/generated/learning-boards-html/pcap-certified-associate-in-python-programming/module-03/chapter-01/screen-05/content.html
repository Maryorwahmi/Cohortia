Module 3 › Chapter 3.1 › def syntax and indentation
Code example
def calculate_area(length, width):
  """Calculates the area of a rectangle.

  Args:
    length (int or float): length of the rectangle.
    width (int or float): width of the rectangle.

  Returns:
    int or float: area of the rectangle.
  """
  return length * width

area1 = calculate_area(10, 5)
print(f"Area 1: {area1}")
Note: keep consistent indentation. The docstring appears directly after the header and before other code.
Common mistakes
  • Forgetting the colon at the end of the header raises a SyntaxError.
  • Incorrect indentation raises IndentationError; enable visible whitespace in your editor.
  • Using built-in names for functions can shadow core behavior and cause confusion.
Pro tip: Keep docstrings and returns clear so your function's contract is obvious when reused.
