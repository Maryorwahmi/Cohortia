Module 3 › Chapter 3.1 › Return values and None
Example: return
def calculate_area(length, width):
  return length * width

area = calculate_area(10, 5)
print(area)  # 50
Key takeaway: return provides a usable value to the caller.
Example: print only
def show_area(length, width):
  print(length * width)

result = show_area(10, 5)
print(result)  # None
Misconception: printing is not returning. Use return when other code must use the value.
