Module 3 › Chapter 3.1 › Parameters vs Arguments
Parameter (definition)
A named variable in the function header that defines what inputs the function expects. Example: def power(base, exponent): base and exponent are parameters.
Docstring tip
List parameter types and purpose so callers know what to pass and what the function returns.
Argument (call site)
The actual value provided when calling the function. It can be a literal, variable, expression, or keyword argument like exponent=3.
Example calls
power(2, 3)            # positional
power(base=2, exponent=3)  # keyword
power(2, exponent=3)     # mix: positional first, then keywords
Common confusion

Passing the same value both positionally and as a keyword causes a TypeError for multiple values for the same parameter. Keep positional arguments first to avoid errors when mixing styles.
