Module 3 › Chapter 3.1 › Common errors and how to fix them
Error examples
TypeError from wrong argument order or count; IndentationError from incorrect indentation; forgetting parentheses yields a function object instead of execution.
Illustration: Which call is correct?
calculate_discount(100, discount_percentage=10) is correct because positional arguments precede any keyword arguments.
Debug checklist
  • Read the traceback and note the problematic call and message.
  • Simplify the call to minimal arguments to isolate the error.
  • Confirm parameter names and counts match the definition.
  • Check for missing return when a value is expected.
Pro tip: Add small print statements or use quick asserts to verify the values bound to parameters during execution.
