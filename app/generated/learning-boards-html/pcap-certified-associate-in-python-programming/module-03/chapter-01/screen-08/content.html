Module 3 › Chapter 3.1 › Positional vs Keyword Arguments
Positional
Match by order. Good for short, conventional parameter lists. Example: calculate_area(10, 5).
Pros: concise. Cons: less explicit for many parameters.
Keyword
Match by name. Great for clarity and optional parameters. Example: calculate_area(width=5, length=10).
Pros: readable, order-independent. Cons: longer to type.
Rule

When mixing both styles in one call, write all positional arguments first, then keyword arguments to avoid TypeError.
