Defining and Calling Functions

Learn why functions reduce repetition, how parameters and arguments work, and how to return values and document behavior with docstrings.

In this lesson you'll see concrete examples and a hands-on temperature conversion activity.
You will practice positional and keyword arguments and learn common errors to avoid.
Why this matters

Functions let you package logic once and reuse it safely. They make testing, debugging, and collaboration easier because each function has a clear responsibility and inputs.

Ingredients

Parameters act like recipe ingredients. They are placeholders that receive values when the function is called.

Example: name, length, width
Steps

The function body executes steps using the parameters and may return a result to the caller.

Example: calculate area, format greeting
Execution flow
Call the function name with parentheses; Python runs the block and returns control when finished. If a value is returned, the caller can use it immediately.
