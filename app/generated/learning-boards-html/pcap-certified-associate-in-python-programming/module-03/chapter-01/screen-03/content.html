Module 3 › Chapter 3.1 › Learning Objectives
Practice cards
Temperature converter task
Implement two functions that convert between Celsius and Fahrenheit and include docstrings describing inputs and returns.
Small tests
After defining each function, run test calls that compare the result to expected numeric values to confirm correctness.
Error check
Intentionally try wrong argument counts to observe type errors and learn how to fix them.
Mnemonic
Think: Define once, test often. Use docstrings as short contracts for inputs and returns.
