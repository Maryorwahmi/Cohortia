Example: modifying a list
def modify_list(my_list):
  my_list.append(4)
  print(f"Inside function: {my_list}")

data = [1, 2, 3]
result = modify_list(data)
print(f"Outside function (data): {data}")
print(f"Outside function (result): {result}")
This prints that the list was changed inside the function and that the function returned None because it had no explicit return.
Guidelines
  • Document mutation in the docstring so callers know the function changes the input.
  • Prefer returning a new object when you need immutability guarantees.
  • Use immutable types when possible to avoid accidental shared-state bugs.
