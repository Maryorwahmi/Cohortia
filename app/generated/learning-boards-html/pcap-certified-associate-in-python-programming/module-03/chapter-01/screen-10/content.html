Good docstring pattern
def power(base, exponent):
  """
  Calculates the power of a base number to a given exponent.

  Args:
    base (int or float): The base number.
    exponent (int): The exponent.

  Returns:
    int or float: The result of base raised to the power of exponent.
  """
  return base ** exponent
Why docstrings matter
  • They appear in help tools and IDEs via __doc__.
  • They document the expected types and behavior for callers and future maintainers.
  • They clarify whether a function returns a value or only performs side effects.
