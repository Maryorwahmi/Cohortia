Module 3 › Chapter 3.1 › Calling a function
Step-by-step
1. Evaluate argument expressions and prepare values.
2. Bind those values to the function's parameter names.
3. Execute the indented body in the function's scope.
4. Evaluate a return expression if present and send the result back; otherwise return None.
Concrete example
def greet_user():
  print("Hello, Cohortia learner!")

# Calling the function runs its body and prints:
greet_user()

# Without parentheses you get the function object:
obj = greet_user
print(obj)  # shows function object, not execution
Misconception: Assigning a call to a variable is the same as assigning the function — they are different. One executes, the other references.
