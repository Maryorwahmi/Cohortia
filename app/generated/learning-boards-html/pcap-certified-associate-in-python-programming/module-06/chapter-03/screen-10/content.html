Comparison
Class vs Generator
Class-based
  • Explicit __enter__ and __exit__ methods
  • Good for complex initialization and multiple methods
  • Clear lifecycle and easier to extend
@contextmanager
  • Concise generator using yield
  • Great for simple setup/teardown with one yield point
  • Remember to use try/finally to guarantee cleanup
Example decision
If you need to keep connection handles and offer commit/rollback methods separately, prefer a class. If you only open, yield, and close, @contextmanager is succinct and readable.
