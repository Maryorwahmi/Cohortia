Process Flow
Stepwise
1
Enter: evaluate and call __enter__
Acquire the resource and return the value for the as variable.
2
Run: execute the with block
Normal code runs here; exceptions may occur and will be reported to __exit__.
3
Exit: call __exit__ with exception info
Cleanup runs. Returning True suppresses exceptions; otherwise they re-raise after cleanup.
Concrete walkthrough
