Core Concept
contextlib

@contextmanager example

from contextlib import contextmanager

@contextmanager
def db_connection_generator(db_name):
    conn = None
    try:
        print(f"Connecting to database: {db_name}...")
        conn = f"Connection object for {db_name}"
        yield conn
    except Exception as e:
        print(f"An error occurred in the with block: {e}")
    finally:
        if conn:
            print(f"Closing connection to database: {db_name}...")
            conn = None

When to choose this

  • Use for short setup/teardown that maps naturally to a single yield point.
  • Avoid for managers needing complex state between enter and exit that benefits from explicit methods.
  • Always wrap yield in try/finally to guarantee teardown.
Misconception
@contextmanager is just syntactic sugar. It is sugar, but it also changes how exceptions are propagated because they re-enter the generator at yield.
