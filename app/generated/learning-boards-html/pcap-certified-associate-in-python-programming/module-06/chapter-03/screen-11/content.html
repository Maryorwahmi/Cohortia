Common Mistakes
Error handling
Missing cleanup
Always run cleanup in __exit__ or finally. If cleanup is skipped, resources leak.
Accidental suppression
Only return True from __exit__ when you've handled the exception deliberately; otherwise let it propagate.
Bad acquisition timing
Perform acquisition in __enter__, not __init__, to avoid side effects at construction time.
Teardown failure
Guard cleanup code to avoid secondary exceptions masking the original error, and log cleanup failures.
