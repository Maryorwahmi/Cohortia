Definition
Class-based

Example: DatabaseConnection

class DatabaseConnection:
    def __init__(self, db_name):
        self.db_name = db_name
        self.connection = None

    def __enter__(self):
        print(f"Connecting to database: {self.db_name}...")
        self.connection = f"Connection object for {self.db_name}"
        return self.connection

    def __exit__(self, exc_type, exc_val, exc_tb):
        if exc_type:
            print(f"An error occurred: {exc_val}")
        print(f"Closing connection to database: {self.db_name}...")
        self.connection = None
        return False

Notes and best practices

  • Do acquisition in __enter__ to avoid side effects at construction time.
  • Use __exit__ to always release, even when exceptions occur.
  • Carefully decide whether to suppress exceptions; prefer explicit returns.
Pro tip
Log context transitions in __enter__ and __exit__ to help debug resource leaks during development.
