Master resource safety with context managers

Learn how the with statement ensures setup and teardown run reliably for files, locks, sockets, and temporary resources. We'll show class-based and generator-based patterns and practical pitfalls to avoid.

Real problem: a file left open
If an error interrupts your code, explicit close calls may never run. with guarantees cleanup.
Two ways to build managers
Use class-based __enter__/__exit__ for full control or @contextmanager for concise generators.

Problem
A file is opened and an error occurs before close is called, leaving system handles open.
with Example
with open("my_file.txt", "w") as f:
    f.write("Hello, Cohortia!
")

Result
Cleanup runs whether the block completes or raises an exception, preventing leaks and improving reliability.
