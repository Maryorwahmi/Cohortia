Core Concept What a context manager is
Definition

Context manager protocol

Implement two methods to support with: __enter__ for setup and __exit__ for teardown. __exit__ gets exception details and can suppress exceptions by returning True.

__enter__
Return a resource and perform acquisition. Example: the opened file object.
__exit__
Run cleanup and examine exception info. Returning True suppresses the exception.
Key Takeaway

The with statement does not hide errors; it guarantees cleanup regardless of errors.

Analogy: door open / door close

Think of __enter__ as opening a door to a controlled environment, and __exit__ as closing it and cleaning up the room. Even if smoke is inside, you still close the door on the way out.

Concrete example
with open("my_file.txt", "w") as f:
    f.write("Hello, Cohortia!
")
# File is closed automatically on block exit
Common misconception
Context managers suppress exceptions by default. Clarification: they may suppress exceptions only if __exit__ explicitly returns True; otherwise exceptions propagate after cleanup.
