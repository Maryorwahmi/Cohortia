MyCounter implementation
class MyCounter:
  def __init__(self, high):
    self.current = 0
    self.high = high

  def __iter__(self):
    # An iterator's __iter__ method typically returns itself.
    return self

  def __next__(self):
    if self.current < self.high:
      num = self.current
      self.current += 1
      return num
    raise StopIteration

# Usage
for i in MyCounter(5):
  print(i)
# 0, 1, 2, 3, 4
Why this pattern
Gives explicit control over sequence generation and termination.
Common error
Not raising StopIteration or returning None instead will break iteration semantics.
Scenario
Use a custom iterator when you must embed and control iteration state inside objects — for example, a cursor over a network stream that can't be replayed.
Key Takeaway

Returning self makes the class single-pass. If you need reusability, return a new iterator instance each time __iter__ is called.
