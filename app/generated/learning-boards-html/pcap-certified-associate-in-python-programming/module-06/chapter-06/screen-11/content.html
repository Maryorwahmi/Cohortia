Best Practices › Avoid mistakes
Common mistakes
  • Exhaustion: Iterators are single-pass — recreate them for a new iteration.
  • Eager computation: Avoid building lists inside generators or doing heavy prepwork before the first yield.
  • Resource leaks: Use with when opening files inside generators so they close properly.
Pro tips
- Use map for simple transformations when you want clarity and laziness.
- Prefer generator expressions for short pipelines passed directly to functions like sum or any.
- If you need multiple passes, materialize results or create fresh iterators each time.
Key Takeaway

Be intentional: choose lazy producers for streaming and lists for repeated/random access.
