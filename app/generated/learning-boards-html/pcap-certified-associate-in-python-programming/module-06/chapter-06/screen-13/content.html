What to Remember › Generators & Lazy Eval
Generator Function
A function with yield that returns a generator object when called.
Generator Expression
Parentheses-based shorthand that returns a generator; ideal for one-off lazy pipelines.
Lazy Evaluation
Values are produced only when requested, reducing memory footprint for large data.
Takeaway

Choose lazy producers for streaming and lists for repeated or indexed access. Generators bridge clarity with efficiency.
