Comparison › Generators vs Lists
Memory profile
List comprehension
Eagerly computes and stores all items; good for multi-pass or indexing.
Generator expression / map
Lazily produces values; low memory overhead; best for single-pass consumption.
Examples
# list comprehension (eager)
squares_list = [x*x for x in range(1000000)]

# generator expression (lazy)
squares_gen = (x*x for x in range(1000000))

# map also returns an iterator
squares_map = map(lambda x: x*x, range(1000000))
Practical rule

If you only pass the sequence to a consuming function or iterate once, prefer generator expressions or map to save memory.
