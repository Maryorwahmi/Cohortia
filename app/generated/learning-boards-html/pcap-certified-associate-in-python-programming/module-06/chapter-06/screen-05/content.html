Process Flow › for loop internals
Step-by-step
  1. Call iter(container) → calls container.__iter__() and returns an iterator.
  2. Call next(iterator) repeatedly → invokes iterator.__next__() to get each value.
  3. When __next__ raises StopIteration, the loop terminates cleanly.
  4. If __iter__ returns a fresh iterator each time, the container is reusable for multiple loops.
Design choice
Return self for single-pass streams; return new iterator instances for reusable containers.
Illustration
for item in my_list:
    # Python calls iter(my_list) -> iterator
    # then repeatedly calls next(iterator) until StopIteration
Pitfall

Making an iterable return self without resetting internal counters causes subsequent loops to start where the last one left off.
