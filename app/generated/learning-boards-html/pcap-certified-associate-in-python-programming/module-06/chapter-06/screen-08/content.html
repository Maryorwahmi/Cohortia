Code Walkthrough › Fibonacci generator
Generator implementation
def fibonacci_sequence(limit):
  a, b = 0, 1
  while a < limit:
    yield a
    a, b = b, a + b

# Using the generator
for num in fibonacci_sequence(10):
  print(num)
# Outputs 0,1,1,2,3,5,8
Why this is memory-efficient
Only the current pair of values are stored; the generator does not collect the full sequence.
Guided check
Try pausing early: stop after three yields and observe that the generator did not compute later values. That demonstrates lazy behavior.
Misconception

Do not assume the generator has computed values it hasn't yielded yet; it computes only up to the next yield when requested.
