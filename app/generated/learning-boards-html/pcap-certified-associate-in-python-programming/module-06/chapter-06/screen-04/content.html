Core Concept › Iterable vs Iterator
Precise definitions
An iterable has __iter__ that returns an iterator. An iterator implements __iter__ and __next__, yielding values until StopIteration.
Iterable — role
Container or producer capable of returning an iterator for traversal.
Iterator — role
Stateful object that yields the next value on each call to next().
StopIteration
Raised by __next__ to signal the end of iteration.
Concrete example
items = [1, 2, 3]
it = iter(items)     # calls items.__iter__()
print(next(it))      # 1
print(next(it))      # 2
print(next(it))      # 3
# next(it) now raises StopIteration
Common misconception

Assuming all iterables are reusable iterators. Generators and many iterator objects are single-pass and must be recreated for repeated traversal.
