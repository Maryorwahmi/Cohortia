Definition › Generator & yield
How yield works
Yield returns a value and pauses the function, saving local variables and the instruction pointer for the next call.
Generator lifecycle
  • Call generator function → returns generator object (no execution).
  • Call next() → execute until first yield; yield returns value and pauses.
  • Repeat next() until function returns; then StopIteration is raised.
Practical note
Generators are ideal for processing streams, reading large files, or implementing pipelined transforms because they avoid building full intermediate lists.
Contrast

Unlike functions that return lists, generator functions return a generator object and execute lazily only as values are requested.
