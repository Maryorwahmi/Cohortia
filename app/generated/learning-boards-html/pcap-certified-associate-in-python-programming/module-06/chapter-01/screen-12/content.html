Module 6 › Chapter Iterators & Generators › Single-use Generators
Why single-use matters
Generators yield values in sequence and do not store them. After the final yield, the generator is exhausted and further next() calls raise StopIteration. This is efficient but means you must plan for reuse if required.
• Recreate the generator by calling the generator function again when you need a fresh sequence.
• Return an iterable factory that provides new generators on each __iter__ call when designing APIs for repeated use.
• Materialize to a list only when memory allows and repeated access is needed.
Example
g = (x for x in range(3))
for x in g: print(x)  # runs once
for x in g: print(x)  # prints nothing; g exhausted
Design hint
If API consumers might iterate multiple times, return an object with __iter__ that creates a new generator each time.
Key Takeaway
Match your return type to the consumer's needs: generator for streaming, iterable or list for repeated access.
