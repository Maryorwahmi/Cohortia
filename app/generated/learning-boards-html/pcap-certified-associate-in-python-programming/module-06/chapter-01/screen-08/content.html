Module 6 › Chapter Iterators & Generators › Generator Expressions
Claim
Generator expressions are syntactic sugar for creating a generator object in-place, saving memory by producing values lazily rather than building collections up front.
Example
gen = (x*x for x in range(10))
# gen yields squares one by one
lst = [x*x for x in range(10)]
# lst holds all squares in memory
When to use
• Streaming pipelines where data is consumed once.
• Large ranges or datasets where building a list would be memory heavy.
• When you don't need indexing or multiple passes.
Common pitfall
Expecting to reuse the generator or to index into it; recreate or convert to a list if needed.
Key Takeaway
Choose generator expressions for one-pass, memory-efficient processing; choose lists for random access or repeated passes.
