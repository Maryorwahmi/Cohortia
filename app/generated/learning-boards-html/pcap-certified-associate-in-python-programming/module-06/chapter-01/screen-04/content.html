Module 6 › Chapter Iterators & Generators › Iterable vs Iterator
Definition
Clear claims and a short example
An iterable provides a way to get an iterator. An iterator returns values with __next__ and raises StopIteration when finished. Remember: iterables can be restarted; iterators are stateful and single-use.
Analogy
Recipe (iterable) vs baker (iterator). The baker consumes the recipe to produce bread; once done, the baker stops.
Concrete example
Using iter() and next()
# Python-like pseudocode for clarity
my_list = [1, 2, 3]
it = iter(my_list)
print(next(it))  # yields 1
print(next(it))  # yields 2
print(next(it))  # yields 3
# next(it) now raises StopIteration
Common mistake
Assuming an iterator can be reused. After exhaustion you must call iter() again on the iterable.
Key Takeaway
Return iterables when callers may need multiple passes; return iterators for single-pass streaming APIs.
