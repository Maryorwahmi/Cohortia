Module 6 › Chapter Iterators & Generators › Practical Rules
Rule 1
Use generators for streaming and memory efficiency.
Rule 2
Recreate generators or return iterable factories for repeated passes.
Rule 3
Implement __next__ and StopIteration correctly when using classes.
Final Thought

Choose the simplest pattern that meets your needs: generators for streaming, iterables for repeatable sequences, and classes when you need richer control.
