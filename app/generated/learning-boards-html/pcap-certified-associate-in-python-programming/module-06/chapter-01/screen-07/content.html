Module 6 › Chapter Iterators & Generators › How yield Works
Concept
yield pauses execution and stores local state. The generator object holds the instruction pointer and locals so subsequent calls resume seamlessly. This eliminates manual state fields and keeps code linear and readable.
Misconception
Don't expect a generator to return all values immediately or to be reusable after exhaustion without recreation.
Code walkthrough
def powers_of_two_generator(max_power):
  current_power = 0
  while current_power < max_power:
    yield 2 ** current_power
    current_power += 1

# The generator preserves current_power after each yield
Concrete example
Use yield to stream large files: yield one parsed row at a time so memory usage stays small.
Key Takeaway
Yield provides automatic state management for iterative algorithms, making code clearer and more memory-efficient.
