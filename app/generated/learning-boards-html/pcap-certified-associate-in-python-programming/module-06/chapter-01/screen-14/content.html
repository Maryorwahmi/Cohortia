Module 6 › Chapter Iterators & Generators › Key Concepts
Iterable
An object capable of returning its members one at a time; lists and strings are common examples.
Iterator
A stateful object implementing __iter__ and __next__; it yields values until StopIteration.
Generator
A function using yield that creates an iterator with automatic state saving and lazy production of values.
Summary Takeaway

Prefer generators when you need lazy, memory-efficient sequences; prefer iterables or lists when you need repeated passes or indexed access.
