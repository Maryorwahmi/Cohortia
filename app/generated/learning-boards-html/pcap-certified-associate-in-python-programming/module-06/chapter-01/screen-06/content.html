Custom Iterator Class
Explicit control, extendable
• Good for complex state, extra methods, or reset behavior.
• Requires writing __iter__ and __next__ boilerplate and careful state management.
• Easier to add helper methods and attributes on the iterator object.
Example
PowersOfTwo class shown earlier implements manual state and StopIteration.
Generator Function
Concise, automatic iterator protocol
• Use yield to pause and resume, Python manages __iter__ and __next__.
• Ideal for simple sequences, streaming, and readability.
• Single-use generator objects must be recreated for multiple passes.
Example
def powers_of_two_generator(max_power):
  current_power = 0
  while current_power < max_power:
    yield 2 ** current_power
    current_power += 1
Key Takeaway
Prefer generators for simple sequences; choose classes when you need extendable behavior or extra methods.
