Module 6 › Chapter Iterators & Generators › Fibonacci Challenge
Guided steps
1. Define fibonacci_sequence with a, b = 0, 1.
2. Use while True: yield a; then update a, b = b, a + b.
3. Create a generator and use for _ in range(10): print(next(gen)).
4. Write tests that compare produced values to the expected first ten Fibonacci numbers.
Solution template
def fibonacci_sequence():
  a, b = 0, 1
  while True:
    yield a
    a, b = b, a + b

# Consume first 10
fib_gen = fibonacci_sequence()
for _ in range(10):
  print(next(fib_gen))
Test hint
Collect values with a list comprehension over range and compare with expected list to assert correctness.
Key Takeaway
Building and testing a generator reinforces state preservation, single-use behavior, and controlled consumption of infinite sequences.
