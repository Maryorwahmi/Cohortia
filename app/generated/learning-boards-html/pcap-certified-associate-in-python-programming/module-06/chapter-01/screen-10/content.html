Module 6 › Chapter Iterators & Generators › Infinite Fibonacci
Pattern explained
Use a while True loop with yield and update local state at the end of each iteration. Control the number of outputs in the consumer by looping a fixed number of times or breaking when a condition is met.
Use case
Generating sequence values on demand for streaming visualizations or algorithmic pipelines.
Starter code
def fibonacci_sequence():
  a, b = 0, 1
  while True:
    yield a
    a, b = b, a + b

# Consume first 10 numbers
fib_gen = fibonacci_sequence()
for _ in range(10):
  print(next(fib_gen))
Common mistake
Letting a consumer accidentally iterate forever. Always plan a break condition when consuming infinite generators.
Key Takeaway
Infinite generators are safe and powerful when consumption is controlled externally; use them for on-demand unbounded sequences.
