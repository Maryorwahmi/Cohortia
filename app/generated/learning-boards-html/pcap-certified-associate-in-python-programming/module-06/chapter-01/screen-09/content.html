Module 6 › Chapter Iterators & Generators › Streaming Files
Pattern
Chain iterators and generators: the file iterator yields lines, a parser generator yields structured records, and a consumer function consumes records one by one.
Example generator
def parse_csv_lines(file_path):
  with open(file_path, 'r') as f:
    for line in f:
      yield line.strip().split(',')  # yields one row at a time
Advantages
• Bounded memory regardless of file size.
• Composable pipeline stages with clear responsibilities.
• Low latency since you can start processing before reading the entire file.
Common pitfall
Loading lines into a list or forgetting to manage file handles properly. Use with blocks for safe cleanup.
Key Takeaway
Structure pipelines as small generators so you can stream records and keep memory usage minimal.
