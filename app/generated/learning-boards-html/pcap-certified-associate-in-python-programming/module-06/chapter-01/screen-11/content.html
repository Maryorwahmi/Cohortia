Module 6 › Chapter Iterators & Generators › StopIteration
How iteration ends
An iterator indicates completion by raising StopIteration. For for loops this is handled for you; for manual next() calls you must catch StopIteration yourself.
Generator return
A return inside a generator stops it. The returned value is attached to StopIteration but is not yielded as an item.
Concrete handling
g = (x for x in range(3))
print(next(g))  # 0
print(next(g))  # 1
print(next(g))  # 2
# next(g) now raises StopIteration
Pitfall
Expecting return to yield a final value. Use yield for values; use return for termination and metadata if necessary.
Key Takeaway
Let for loops handle StopIteration, and design generators so their termination is predictable for consumers.
