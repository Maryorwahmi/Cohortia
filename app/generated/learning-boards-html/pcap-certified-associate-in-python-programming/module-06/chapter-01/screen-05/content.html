Module 6 › Chapter Iterators & Generators › Iterator Protocol
Process: step by step
1.
Call iter(iterable) which invokes the iterable's __iter__ method.
2.
Receive an iterator object; the iterator implements __next__ and __iter__.
3.
Call next(iterator) which calls iterator.__next__ to obtain the next value.
4.
When no values remain, __next__ raises StopIteration and iteration ends.
Example: powers of two iterator
class PowersOfTwo:
  def __init__(self, max_power):
    self.max_power = max_power
    self.current_power = 0

  def __iter__(self):
    return self

  def __next__(self):
    if self.current_power < self.max_power:
      value = 2 ** self.current_power
      self.current_power += 1
      return value
    else:
      raise StopIteration
Common mistake
Forgetting to raise StopIteration will confuse consumers. Also check off-by-one logic in your state updates.
Key Takeaway
Implement __iter__ and __next__ correctly and plan the iterator's state variables before coding.
