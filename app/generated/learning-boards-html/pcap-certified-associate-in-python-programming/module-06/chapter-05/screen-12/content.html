Module 06 › Chapter 6.5 › When to use descriptors
Common scenarios
Validation
Centralize type and range checks across many fields with one reusable descriptor.
Lazy loading
Compute expensive values on first access and cache them in instance.__dict__.
ORM mapping
Map attributes to database columns and centralize serialization/deserialization.
When to avoid
If logic is one-off or complicates testing, prefer simple properties or explicit helper functions.
Design advice
Keep descriptors small, document stored keys, and unit test descriptor behavior independently from owner classes.
