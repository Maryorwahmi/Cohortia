Module 06 › Chapter 6.5 › Data vs Non-data
Data descriptor
Implements __set__ or __delete__. It takes precedence over instance.__dict__ entries. Use when you must enforce invariants on write.
Example
TypeChecked which validates and stores values per-instance.
Non-data descriptor
Implements only __get__. It controls reads but instance assignment can shadow it. Functions on classes are the canonical example.
Example
A method object implements __get__ to return a bound function; setting an instance attribute with the same name will hide the method for that instance.
Design decision
Choose data descriptors when you require control over assignment and deletion. Choose non-data descriptors when you only need to compute or present a value on read and still allow instance-level overrides.
