Module 06 › Chapter 6.5 › @property as a descriptor
Mapping

When you declare a property with getter and setter, Python constructs an object that implements the descriptor protocol. Its __get__ calls the getter, __set__ calls the setter, and __delete__ calls the deleter if provided.

class Circle:
  def __init__(self, radius):
    self._radius = radius

  @property
  def radius(self):
    return self._radius

  @radius.setter
  def radius(self, value):
    if value < 0:
      raise ValueError('Radius cannot be negative')
    self._radius = value
Practical note
Why use property
It provides an attribute-like interface while enabling validation and computed values under the hood via the descriptor protocol.
Takeaway
Recognizing property as a descriptor helps you reuse patterns and build your own managed attributes when needed.
