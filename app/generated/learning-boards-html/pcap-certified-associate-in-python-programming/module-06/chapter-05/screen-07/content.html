Module 06 › Chapter 6.5 › Implementing __set__
Pattern

Capture the attribute name in __set_name__, validate in __set__, and store the value in instance.__dict__[self._name]. This ensures per-instance storage and predictable behavior.

class TypeChecked:
  def __init__(self, expected_type):
    self.expected_type = expected_type
    self._name = None

  def __set_name__(self, owner, name):
    self._name = name

  def __get__(self, instance, owner):
    if instance is None:
      return self
    return instance.__dict__.get(self._name, None)

  def __set__(self, instance, value):
    if not isinstance(value, self.expected_type):
      raise TypeError(f"Expected {self.expected_type.__name__}, got {type(value).__name__}")
    instance.__dict__[self._name] = value
Wrong approach
Assigning self.value = value stores state on the descriptor object itself, making the attribute shared across all owner instances.
Concrete example
Person example
Person.name = TypeChecked(str) stores each person's name in their own __dict__ key, preventing cross-instance leakage.
Key takeaway
Use instance.__dict__ to keep attributes instance-local; use descriptor attributes only for metadata like expected_type or _name.
