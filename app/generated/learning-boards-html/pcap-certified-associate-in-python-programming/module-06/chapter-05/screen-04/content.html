Module 06 › Chapter 6.5 › What is a descriptor?
Core claim

If an object stored on a class implements __get__, __set__, or __delete__, Python routes attribute access to those methods. That single rule explains how property, bound methods, and other managed attributes behave.

Example
A TypeChecked descriptor can validate types on assignment and store the value in instance.__dict__ under a name learned from __set_name__.
Common mistake
Storing values as attributes on the descriptor creates shared state across all instances. Use instance.__dict__ instead.
Key takeaway
Descriptors provide controlled, reusable attribute behavior when you need logic on access, assignment, or deletion.
Annotated view
Descriptor object
Implements the protocol methods to intercept operations.
Instance storage
values stored in instance.__dict__ keep state per-instance.
Class-level access
When instance is None in __get__, return the descriptor to support introspection.
Check your understanding
Is a plain function defined on a class a descriptor? Yes: functions implement __get__, making them non-data descriptors that produce bound methods on instance access.
