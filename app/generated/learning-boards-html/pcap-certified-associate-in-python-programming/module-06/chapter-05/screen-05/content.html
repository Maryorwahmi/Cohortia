Module 06 › Chapter 6.5 › Attribute lookup order
Ordered steps
  1. Data descriptor in the class dict (implements __set__ or __delete__) — takes precedence.
  2. Instance dictionary entry, if no data descriptor blocked it.
  3. Non-data descriptor in the class dict (implements only __get__).
  4. Plain class attribute or attributes found in base classes.
Practical debugging tip
Inspect owner.__dict__ for an attribute and check whether it implements __set__. That tells you whether instance assignment will be effective.
Misconception
Instance assignment does not always override class-level behavior when a data descriptor is present. Expect interception when __set__ exists.
Visual process
Data descriptor
Always wins. Example: a TypeChecked descriptor with __set__.
Instance dict
Normal stored values which can shadow non-data descriptors.
Non-data descriptor
Methods are an example; they implement __get__ but not __set__.
Reflection question
If a descriptor blocks instance writes, how would you add a per-instance override? Consider removing the descriptor or changing it to a non-data descriptor.
