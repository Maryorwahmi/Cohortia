Module 06 › Chapter 6.5 › __set_name__
Why __set_name__ exists

It is called at class creation and gives the descriptor the attribute name so that later __get__ and __set__ can store values under a consistent key in instance.__dict__. This removes fragile naming conventions and makes descriptors reusable across classes.

Behavior note
__set_name__ is not invoked when you assign a descriptor to a class attribute at runtime after class creation. Rely on it only for class-time assignments.
Concrete usage
Capture key
def __set_name__(self, owner, name): self._name = name — later use instance.__dict__[self._name]
Takeaway
Prefer __set_name__ to hard-coded keys; it makes descriptors robust when reused or subclassed.
