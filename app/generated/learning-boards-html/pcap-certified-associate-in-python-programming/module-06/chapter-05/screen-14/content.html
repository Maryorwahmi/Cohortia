Module 06 › Chapter 6.5 › Pitfalls & Debugging
Common mistakes
  • Storing per-instance values on the descriptor, creating shared state.
  • Not using __set_name__ and relying on fragile string keys.
  • Missing clear error types for invalid writes or forbidden deletes.
Testing strategy
Unit-test __get__, __set__, and __delete__ against a small mock owner class to verify per-instance storage and error semantics.
Quick checks
Inspect
owner.__dict__["attr"] reveals whether attr is a descriptor and which methods it implements.
Shadowing
If an instance assignment seems ignored, check whether a data descriptor controls that name.
Takeaway
Design descriptors deliberately, document storage keys, and test them as independent units to avoid runtime surprises.
