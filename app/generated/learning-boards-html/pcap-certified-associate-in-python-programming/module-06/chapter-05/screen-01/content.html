Descriptors

Intercept attribute access to run custom logic on get, set, or delete.

In this lesson

Why descriptors exist, the protocol methods, common pitfalls, and hands-on patterns.

Why it matters

They give reusable control for validation, lazy loading, and framework integrations like ORMs.

Explore key topics
Protocol Methods
__get__, __set__, __delete__ are the interception points.
Use Cases
Validation, lazy loading, ORMs, and read-only attributes.
Property
@property is a built-in descriptor implementing get/set/deleter methods.
Concept map
Descriptor Object
Implements one or more of the special methods to manage attribute access.
Instance Storage
Values should be stored in instance.__dict__ to avoid shared state across instances.
Data vs Non-Data
Data descriptors implement __set__ and take precedence over instance attributes.
Quick example
class TypeChecked:
  def __init__(self, expected_type):
    self.expected_type = expected_type
    self._name = None

  def __set_name__(self, owner, name):
    self._name = name

  def __get__(self, instance, owner):
    if instance is None:
      return self
    return instance.__dict__.get(self._name, None)

  def __set__(self, instance, value):
    if not isinstance(value, self.expected_type):
      raise TypeError("Expected type mismatch")
    instance.__dict__[self._name] = value
