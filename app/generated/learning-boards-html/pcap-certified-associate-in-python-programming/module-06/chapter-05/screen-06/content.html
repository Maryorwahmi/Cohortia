Module 06 › Chapter 6.5 › __get__ semantics
Behavior rules
  • __get__(self, instance, owner) is called on attribute access.
  • If instance is None, callers are using the class; often return self for introspection.
  • Otherwise, return a per-instance value, compute on demand, or create a bound object.
Example pattern
Return self when instance is None, otherwise return instance.__dict__.get(self._name, None) or compute and cache lazily.
Misconception
Do not assume __get__ always returns the descriptor. It usually returns the descriptor on class access, but on instance access it should provide usable values or bound objects.
Concrete scenario
Bound methods
Functions implement __get__ to return a function object bound to the instance, explaining why methods receive self.
Lazy compute
__get__ can compute a value on first access and store it in instance.__dict__ so subsequent reads are cheap.
Takeaway
Always check the instance argument inside __get__ to decide whether to return the descriptor or an instance value.
