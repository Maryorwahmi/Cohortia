Module 06 › Chapter 6.5 › __delete__ and deletion rules
Use and behavior

Implement __delete__ to remove the stored value from the instance or to manage cleanup of external resources. If deletion is not permitted, raise AttributeError with a meaningful message so callers understand why the operation fails.

Practical rule
If you stored the value in instance.__dict__ under the key gathered from __set_name__, __delete__ should delete that key to restore the pre-assignment state.
ReadOnly example
A ReadOnly descriptor should implement __delete__ to raise AttributeError to prevent deletion of protected attributes.
