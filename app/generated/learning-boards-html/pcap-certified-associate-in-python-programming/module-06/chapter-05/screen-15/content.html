Module 06 › Chapter 6.5 › Key Concepts
Descriptor
An object implementing __get__, __set__, or __delete__ to manage attribute access.
__set_name__
Called at class creation so the descriptor learns the attribute name for instance storage.
Data vs Non-data
Data descriptors implement __set__ and take lookup precedence; non-data only implement __get__.
Summary takeaway

Descriptors are the small building blocks behind properties and many framework features; use them when you need centralized, reusable control over attribute access and mutation.
