Implementation pattern
def repeat(num_times):
  def decorator_repeat(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
      result = None
      for _ in range(num_times):
        result = func(*args, **kwargs)
      return result
    return wrapper
  return decorator_repeat

@repeat(num_times=3)
def shout(message):
  print(message.upper() + '!')

shout('hello')
Design choice
Decide whether the wrapper should return the last result, all results, or None. Be explicit in documentation for maintainability.
Example output
HELLO!
HELLO!
HELLO!
Pitfall
Putting heavy side effects in the outer factory runs at import time. Keep the outer layer lightweight.
Try: adapt the wrapper to collect values into a list if the repeated results are meaningful to callers.
