Timer using contextmanager
from contextlib import contextmanager
import time

@contextmanager
def timer(label):
  start_time = time.time()
  print(f"--- {label} started ---")
  try:
    yield
  finally:
    end_time = time.time()
    print(f"--- {label} finished in {end_time - start_time:.4f} seconds ---")

with timer("Data Processing"):
  time.sleep(0.2)
  print("Processing data...")
This generator-based manager maps directly to enter/exit logic and is excellent for timing blocks, temporary patching, or simple resource guards.
Example output
--- Data Processing started ---
Processing data...
--- Data Processing finished in 0.2001 seconds ---
Pitfall
Omitting finally means teardown might not run on exceptions. Always ensure teardown is in finally or after yield.
If you need to return a value to the with-as target, yield that value from the generator; it becomes what the as variable receives.
