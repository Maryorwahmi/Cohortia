Module 7 › Chapter 6.7 › Quick Reminders
No heavy import-time work
Keep decorator factories light; heavy setup at import time can surprise users.
Preserve metadata
Use functools.wraps inside wrappers so function names and docs remain intact.
Be deliberate about exceptions
Only return True from __exit__ when you intend to suppress exceptions. Otherwise allow them to propagate.
One final thought
When used responsibly, decorators and context managers reduce duplication and make your program more robust. Use them to simplify, not to hide important behavior.
