Module 7 › Chapter 6.7 › Class vs Generator
Class-based
  • Explicit __enter__ and __exit__ methods.
  • Good for persistent manager state and methods.
  • Clear object API for with-as target.
Example: FileLock class that returns itself and provides filename while inside the block.
Generator-based
  • Use @contextmanager and yield once.
  • Concise and expressive for simple enter/exit logic.
  • Less suitable when you need complex state or methods.
Example: timer generator that yields and measures elapsed time in finally.
Key Takeaway

Choose the simplest tool that expresses your lifecycle. Use classes for state, generators for concision.
