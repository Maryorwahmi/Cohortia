Enter and exit
__enter__ is called when you enter the with block and often acquires and returns a resource. __exit__ is called at block exit and performs cleanup. The __exit__ signature receives exc_type, exc_val, exc_tb to allow conditional handling of exceptions.
Safe default
Return False from __exit__ to let exceptions propagate and avoid masking errors unless you intentionally handle and suppress them.
When to use
Use context managers to manage files, locks, network connections, and transaction boundaries that must be reliably closed or rolled back.
Class-based example
class ManagedResource:
  def __enter__(self):
    # acquire resource
    return self
  def __exit__(self, exc_type, exc_val, exc_tb):
    # release resource
    return False  # do not suppress exceptions
Check
Run a with block that raises an exception and confirm __exit__ still runs and that the exception is re-raised unless you return True.
