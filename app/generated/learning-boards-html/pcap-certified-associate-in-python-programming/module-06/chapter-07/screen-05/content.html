Module 7 › Chapter 6.7 › Decorator Call Flow
Three-step process
  1. Decoration time: decorator(func) returns wrapper and replaces the original binding.
  2. Call-time pre-action: wrapper runs code before calling the original function.
  3. Call-time post-action: wrapper runs code after the original function returns and then returns the result.
Decorator with arguments
Wrap an outer function that accepts parameters and returns the actual decorator. This creates an extra nesting layer but gives you configurable behavior.
Example: repeat decorator
def repeat(num_times):
  def decorator_repeat(func):
    def wrapper(*args, **kwargs):
      for _ in range(num_times):
        func(*args, **kwargs)
    return wrapper
  return decorator_repeat

@repeat(num_times=3)
def shout(msg):
  print(msg.upper() + '!')
Misconception
The outer function runs when the decorator is applied, not when the decorated function is called. Ensure any side effects in the outer layer are safe at import time.
Check
Confirm that the number of repetitions matches the argument you passed into the decorator factory.
