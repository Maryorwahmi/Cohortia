Decorators
Wrap functions to add behavior without touching their body

Decorators accept a function and return a new callable that can run code before and after the original call. They are used for logging, timing, authentication, and other cross-cutting concerns. The @ syntax is shorthand for reassignment, and functools.wraps preserves metadata.

Example
A simple timing decorator records start and end times and prints elapsed seconds.
Why it helps
Move repeated setup or cleanup into reusable helpers so functions stay focused on business logic.
Context Managers
Guarantee setup and teardown around a block of code

A context manager defines __enter__ and __exit__ or uses a generator with contextlib.contextmanager. The with statement ensures cleanup runs even if an exception occurs. This is essential for files, locks, connections, and other resources.

Pattern
Implement __enter__ to acquire and return the resource, and __exit__ to release it; return True to suppress exceptions when appropriate.
