Module 7 › Chapter 6.7 › Key Concepts
Decorator
A function that takes and returns a function, used to add behavior like logging or timing without changing the original function body.
functools.wraps
A decorator used inside custom decorators to copy metadata from the original function to the wrapper, preserving __name__ and __doc__.
Context Manager
Defines __enter__ and __exit__ or uses contextlib.contextmanager to ensure resources are acquired and released reliably around a with block.
Final takeaway
Use decorators to centralize behavior and context managers to protect resource lifecycles. Together they make code cleaner, safer, and easier to maintain.
