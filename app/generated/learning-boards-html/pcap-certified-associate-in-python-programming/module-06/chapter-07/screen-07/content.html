Implementation
import functools

def log_calls(func):
  """A decorator that logs function calls and return values."""
  @functools.wraps(func)
  def wrapper(*args, **kwargs):
    print(f"--- Calling {func.__name__} with args: {args}, kwargs: {kwargs} ---")
    result = func(*args, **kwargs)
    print(f"--- {func.__name__} returned: {result} ---")
    return result
  return wrapper

@log_calls
def calculate_sum(a, b):
  return a + b

print(f"Sum: {calculate_sum(5, 3)}")
Concrete test
Call calculate_sum(5, 3) and confirm printed call details, then the printed correct sum output. The decorator should not change the returned value.
Pro tip
For production use the logging module instead of print and include exception handling inside the wrapper if needed.
Example output
--- Calling calculate_sum with args: (5, 3), kwargs: {} ---
--- calculate_sum returned: 8 ---
Sum: 8
Misconception
Printing inside a decorator is visible to callers; it does not change the function semantics unless you modify the return value.
Try decorating a function with a docstring and confirm that function.__name__ and function.__doc__ remain correct thanks to functools.wraps.
