Module 7 › Chapter 6.7 › functools.wraps
Problem

A decorated function often loses __name__ and __doc__. That makes stack traces and documentation misleading. functools.wraps copies metadata from the original function to the wrapper so tools and developers see the original identity.

Pattern
import functools

def my_decorator(func):
  @functools.wraps(func)
  def wrapper(*args, **kwargs):
    # do work
    return func(*args, **kwargs)
  return wrapper
Concrete example
A log_calls decorator should print the original function name. Use functools.wraps to ensure printed names are correct for readable logs.
Check
After decorating, inspect function.__name__ and function.__doc__ to confirm preservation.
Mistake
Not using wraps is easy to miss during quick prototyping, but it causes real debugging friction later.
