Module 7 › Chapter 6.7 › Practical Outcomes
Tasks you will complete
  • Implement log_calls decorator and verify it prints function calls and results.
  • Write repeat decorator that accepts an argument to run a function multiple times.
  • Create class-based FileLock with __enter__ and __exit__ showing acquisition and release.
  • Write a generator-based file_lock using contextlib.contextmanager and compare behavior.
Checkpoints
Verification
Run test drivers that call your decorated functions and use with blocks to confirm printed acquisition and release messages appear as expected.
Pitfall to avoid
Do not forget functools.wraps; also be deliberate about returning True from __exit__ only when you intend to suppress exceptions.
These tasks are small but focused. They are designed to run quickly and give immediate printed feedback so you can iterate on your implementations.
