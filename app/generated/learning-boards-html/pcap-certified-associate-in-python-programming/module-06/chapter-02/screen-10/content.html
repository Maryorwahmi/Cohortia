Module 6 › Chapter Decorators › Built-in decorators
@staticmethod
No self or cls. Use for utility methods that logically belong to the class but do not access class or instance state.
@classmethod
Receives the class as first argument. Good for alternative constructors or methods that need class-level information.
@property
Exposes a method as an attribute for computed or validated access, often with a setter and deleter pair when needed.
Examples
class Circle:
  def __init__(self, r):
    self.radius = r

  @property
  def area(self):
    return 3.1415 * self.radius * self.radius

  @classmethod
  def from_diameter(cls, d):
    return cls(d / 2)

  @staticmethod
  def pi():
    return 3.1415
