Learning Objectives

Progress from concept to applied decorator patterns.

Bloom: Learn → Understand → Apply → Master
01
Explain decorators

Define what a decorator does and why it is metaprogramming. Verify by showing the equivalent function reassignment example.

VERIFIED COMPETENCY MILESTONE
02
Create a simple decorator

Implement a wrapper that logs or times a function, and return the original result. Demonstrate with a short task function.

VERIFIED COMPETENCY MILESTONE
03
Use *args and **kwargs safely

Write wrappers that accept any positional and keyword arguments to avoid breaking decorated functions.

VERIFIED COMPETENCY MILESTONE
04
Chain decorators

Apply multiple decorators and predict the order of execution. Practice with a logger and timer combination.

VERIFIED COMPETENCY MILESTONE
