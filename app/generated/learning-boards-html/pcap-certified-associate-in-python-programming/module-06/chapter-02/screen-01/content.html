Decorators

Wrap functions to extend behavior such as logging, timing, authorization, or caching without changing the function body.

What you'll learn
  • How @decorator syntax maps to function reassignment.
  • Designing wrapper functions with *args and **kwargs.
  • Preserving metadata using functools.wraps.
  • Writing decorators that accept arguments and chaining them.
Why it matters

Decorators help separate concerns. They enable cross-cutting features like logging and authentication to be reused across functions without changing core logic.
