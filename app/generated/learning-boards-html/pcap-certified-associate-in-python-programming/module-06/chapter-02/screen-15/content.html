Module 6 › Chapter Decorators › Quick Checklist
Factory for args
Use outer function to accept decorator configuration parameters.
Use wraps
Preserve __name__ and __doc__ with functools.wraps for clarity.
Cache scope
Put caches in the decorator closure so they survive across calls but remain isolated.
Final takeaway

Small, disciplined patterns make decorators safe and maintainable: factory for config, wraps for identity, outer scope for state, and tests for behavior.
