Module 6 › Chapter Decorators › functools.wraps
Why it matters

Keep the original function identity

wraps copies key attributes from the original function to the wrapper so introspection and debugging show the original name and documentation.

from functools import wraps

def timer(func):
  @wraps(func)
  def wrapper(*args, **kwargs):
    # timing logic
    return func(*args, **kwargs)
  return wrapper

@timer
def task():
  """A short task"""
  pass

print(task.__name__)  # task, not wrapper
print(task.__doc__)   # 'A short task'
Quick check
When to use
Always add wraps when your decorator replaces a function used by tests, tools, or documentation generators.
Misconception
wraps does not change behavior or fix argument forwarding. It only copies metadata for clarity.
