Pattern

Factory → decorator → wrapper

Use an outer factory to capture configuration, return a decorator that will be applied to the function, and implement a wrapper that performs the configured behavior and returns the function result.

def repeat(num_times):
  def decorator_repeat(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
      for _ in range(num_times):
        result = func(*args, **kwargs)
      return result
    return wrapper
  return decorator_repeat

@repeat(num_times=3)
def greet(name):
  print(f"Hello, {name}!")
Concrete example
Calling greet("Alice") will print the greeting three times because num_times is captured by the outer factory.
Common pitfall
Do not confuse decorator arguments with the decorated function's arguments. The factory runs when the function is defined.
Check
Test idea
Decorate a function, call it, and confirm the number of prints and returned value behavior are as expected.
Why closures matter
The outer function closes over the configuration so the inner wrapper can use it at call time without additional parameters.
