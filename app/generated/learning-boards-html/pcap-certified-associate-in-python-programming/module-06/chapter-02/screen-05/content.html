Module 6 › Chapter Decorators › @ Syntax Mapping
Claim

Decorator application is assignment

The @ syntax is shorthand for calling the decorator with the function and rebinding the name to the returned callable. This happens when the function is defined.

# Syntactic sugar
@my_decorator
def greet():
  print("Hello")

# is equivalent to

def greet():
  print("Hello")

greet = my_decorator(greet)
Example
Stacked decorators apply from bottom to top. The decorator next to def runs first and its result is passed to the upper decorator.
Gotcha
Decorators execute at definition time, so avoid side effects if you only want runtime behavior.
Visual
Stack example
@debug_log  # applied second
@timer      # applied first
def calculate(a, b):
  return a + b

# Equivalent: calculate = debug_log(timer(calculate))
Notice how the inner decorator wraps the function first, then the outer decorator wraps the result.
