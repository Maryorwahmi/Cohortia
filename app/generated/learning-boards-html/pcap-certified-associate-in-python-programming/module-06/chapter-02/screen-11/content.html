Module 6 › Chapter Decorators › Authorization Decorator
Starter code
from functools import wraps

current_user_permissions = {"read", "write"}

def requires_permission(permission_level):
  def decorator_requires_permission(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
      if permission_user_has_access(permission_level):
        return func(*args, **kwargs)
      else:
        print(f"Access Denied: Requires '{permission_level}' permission.")
        return None
    return wrapper
  return decorator_requires_permission

# Helper
def permission_user_has_access(required_permission):
  return required_permission in current_user_permissions
How to test
  • Decorate a function that prints or returns a value and call it with different permission sets.
  • Confirm that when permission is missing, the function does not run and a message appears.
  • Add permissions and verify the function runs and returns the expected result.
Notes
Edge cases
Consider raising exceptions instead of printing in library code. Ensure consistent return types for callers expecting values.
Extension
You can extend this pattern to check roles, time windows, or rate limits by adjusting the helper or adding more checks in the wrapper.
