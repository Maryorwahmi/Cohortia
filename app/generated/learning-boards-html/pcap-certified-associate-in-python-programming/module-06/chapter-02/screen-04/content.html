Module 6 › Chapter Decorators › What is a decorator?
Definition

Decorator = callable that returns a callable

A decorator receives a function and returns a new function that usually calls the original and adds behavior. It is syntactic sugar for reassigning the function name to the decorator's return value.

Analogy
Gift wrap: the item is unchanged, the wrapping adds a presentation layer or side effects like logging.
Common misconception
A decorator does not edit internal code; it creates a wrapper that delegates to the original function.
Key Takeaway

Decorators add behavior by returning a new callable that calls the original and optionally does work before or after.

Example
import time

def timer(func):
  def wrapper(*args, **kwargs):
    start = time.time()
    result = func(*args, **kwargs)
    end = time.time()
    print(f"Function '{func.__name__}' executed in {end - start:.4f} seconds.")
    return result
  return wrapper

@timer
def task(delay):
  time.sleep(delay)
  print("Task completed")

# Calling task actually runs wrapper
Walkthrough
  • The decorator timer receives the original function and returns wrapper.
  • Wrapper forwards args and kwargs and returns the original result.
  • The @ syntax rebinds task to timer(task) at definition time.
