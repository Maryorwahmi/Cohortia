Module 6 › Chapter Decorators › Common Mistakes
Forgot return
def broken(func):
  def wrapper(*args, **kwargs):
    func(*args, **kwargs)  # forgotten return
  return wrapper

@broken
def value():
  return 5

# value() returns None
Fix: capture the result and return it.
Lost metadata
def log_call(func):
  def wrapper(*a, **k):
    return func(*a, **k)
  return wrapper

# Inspecting decorated function shows 'wrapper' unless functools.wraps is used.
Fix: add @wraps(func) before wrapper.
Side effects at import
Remember decorators run at definition time. Avoid I/O, heavy computation, or network calls in decorator factories unless intentional.
Debugging tips
  • Test decorated functions for return values.
  • Print __name__ and __doc__ to confirm metadata.
  • Instrument decorators to observe execution order when chained.
