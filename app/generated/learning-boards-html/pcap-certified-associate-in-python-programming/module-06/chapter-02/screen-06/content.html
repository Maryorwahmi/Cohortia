Module 6 › Chapter Decorators › Wrapper Signatures
Rule

Use *args and **kwargs and return result

These two practices keep wrappers compatible with any function signature and ensure the decorated function's return value is preserved for callers and tests.

def log_call(func):
  def wrapper(*args, **kwargs):
    print(f"Calling {func.__name__} with args: {args}, kwargs: {kwargs}")
    result = func(*args, **kwargs)
    print(f"{func.__name__} returned: {result}")
    return result
  return wrapper

@log_call
def add(a, b):
  return a + b

# add(5, 3) returns 8 and prints call info
Pro tip
If you miss return result you will silently return None and break callers. Always test decorated functions for return values.
Method note
When decorating methods, wrapper still receives self as the first positional argument; you do not need special handling for bound methods.
Check your understanding
Common mistake demo
def broken(func):
  def wrapper(*args, **kwargs):
    func(*args, **kwargs)  # forgot to return
  return wrapper

@broken
def get_value():
  return 42

# get_value() now returns None
Fix by storing and returning the original function's result.
