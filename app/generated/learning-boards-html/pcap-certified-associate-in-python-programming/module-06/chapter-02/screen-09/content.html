Concept

Compose decorators carefully

When multiple decorators are present, the decorator nearest the function definition is executed first during application, and calls flow through nested wrappers at run time. Order matters for side effects, returned values, and exception handling.

@debug_log  # outer
@timer      # inner
def calculate(a, b):
  print("Calculating")
  return a + b

# Equivalent: calculate = debug_log(timer(calculate))
Example
If debug_log prints entry/exit, those messages will surround the timer's prints when called.
Design tip
Decide which decorator should observe raw input and which should observe processed output and order them accordingly.
Quick test
Run small examples
Print messages inside each decorator to observe the exact execution order and verify the combined behavior matches your expectation.
