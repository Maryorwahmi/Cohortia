Module 6 › Chapter Decorators › Caching Decorator
Design pattern
def cache_decorator(func):
  cache = {}
  @wraps(func)
  def wrapper(*args, **kwargs):
    key = (args, tuple(sorted(kwargs.items())))
    if key in cache:
      return cache[key]
    result = func(*args, **kwargs)
    cache[key] = result
    return result
  return wrapper
Cache is created once when func is decorated and persists across calls. Keys must be hashable and consistent.
Practical notes
  • Store cache in outer scope for persistence across calls.
  • Global cache works but reduces encapsulation and test isolation.
  • Beware of memory growth; consider eviction or limited size.
Misconception

Caching always saves resources — not always. Evaluate memory cost and eviction strategy for long-running programs.
