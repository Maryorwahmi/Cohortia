Registration & Injection
Registry = {}

class RegMeta(type):
  def __init__(cls, name, bases, namespace):
    super().__init__(name, bases, namespace)
    Registry[name] = cls

class Base(metaclass=RegMeta):
  pass

class PluginA(Base):
  pass

# Registry now contains 'PluginA'
Why it matters
  • Reduces boilerplate for plugin authors and ensures discoverability.
  • Allows framework-level checks once during class definition rather than repeatedly at runtime.
  • Attribute injection can centralize versioning or metadata policies.
Caution
Registration produces import-time side effects. Document and consider opting-in to avoid surprising users.
