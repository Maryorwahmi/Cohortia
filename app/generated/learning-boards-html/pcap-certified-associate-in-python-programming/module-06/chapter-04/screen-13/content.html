When to Use
When metaclasses are appropriate
Plugin or ORM registration at definition time
Enforcing presence of required methods during class creation
Injecting class-level metadata like VERSION at definition time
Avoid when only instance behavior or post-creation changes are needed
Checklist before using a metaclass
  1. Does the requirement need definition-time intervention?
  2. Can a decorator or factory achieve the goal more clearly?
  3. Can you document and test the side effects thoroughly?
Key Takeaway
Metaclasses are powerful but should be chosen consciously and sparingly.
