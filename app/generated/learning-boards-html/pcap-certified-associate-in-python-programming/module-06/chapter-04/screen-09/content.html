Comparison
Metaclass vs Decorator
Metaclass
Runs during class creation and can alter the namespace or inheritance chain. Best for enforcing definition-time rules.
Class decorator
Runs after creation and receives the class object. Best for adding methods or registering classes without changing construction.
Scenario guide
  • If you must inject attributes before class exists → metaclass.
  • If you want to wrap methods or attach behavior after creation → decorator.
  • For plugin registration, either can work; prefer decorators for clarity unless definition-time constraints are required.
Key Takeaway
Prefer the simpler solution that satisfies the requirement; choose metaclasses only when you truly need definition-time control.
