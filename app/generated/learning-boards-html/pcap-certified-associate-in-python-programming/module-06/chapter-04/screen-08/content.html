__new__ vs __init__
class CheckingMeta(type):
  def __new__(mcs, name, bases, namespace):
    # Validate or add defaults before creation
    if 'VERSION' not in namespace:
      namespace['VERSION'] = '0.1'
    return super().__new__(mcs, name, bases, namespace)

  def __init__(cls, name, bases, namespace):
    # Register the created class
    Registry.register(cls)
    super().__init__(name, bases, namespace)
  • Put namespace edits in __new__ so they become part of the class.
  • Use __init__ for registration or side effects that require the class object.
  • Always call super to maintain correct behavior.
Common mistakes
Modifying namespace in __init__: ineffective for creating class attributes.
Omitting super(): breaks the metaclass chain and can prevent proper class creation.
Using instance-level logic: metaclasses act at definition time, not on instance creation.
Pitfall
Expecting instance-side initialization to occur in metaclass methods confuses object lifecycle and leads to missing attributes.
