Definition
type(name, bases, dict)
Construct a class object at runtime by providing a name, base classes, and a namespace of attributes and methods.
# Dynamically create a class
MyDynamicClass = type('MyDynamicClass', (object,), {
  'version': '1.0',
  'greet': lambda self: f"Hello from {self.__class__.__name__}!"
})

inst = MyDynamicClass()
print(inst.version)        # 1.0
print(inst.greet())        # Hello from MyDynamicClass!
Notes
  • Always pass bases as a tuple, even for a single base.
  • Functions in the dict become methods bound to instances.
  • Use this when class structure depends on runtime configuration.
Example card
Use type to create test doubles or to generate many small classes with predictable differences, such as lightweight DTOs constructed from a schema.
Common pitfall
Supplying a non-tuple for bases raises a TypeError. Also prefer named functions to lambdas for readability in class dictionaries.
Key Takeaway

type(...) constructs classes programmatically; it's the same mechanism behind the class statement.
