Definition
Custom metaclass structure
Inherit from type and override __new__ and/or __init__ to control class creation and post-creation initialization.
class MyMetaclass(type):
  def __new__(mcs, name, bases, namespace):
    # modify namespace before class creation
    if 'version' not in namespace:
      namespace['version'] = '0.0-default'
    namespace['added_by_metaclass'] = True
    new_cls = super().__new__(mcs, name, bases, namespace)
    new_cls.metaclass_processed = True
    return new_cls

  def __init__(cls, name, bases, namespace):
    super().__init__(name, bases, namespace)
    # additional initialization if needed
Behavioral notes
  • Code in __new__ runs before the class object exists and can change the namespace that constructs the class.
  • __init__ receives the created class object and should call super to preserve normal initialization.
  • Prints or logs in the metaclass occur at import/definition time, not at instance creation.
Pro tip
When adding attributes, choose names unlikely to collide with user-defined names. Consider configuration flags as reserved keys.
Key Takeaway

Metaclasses intercept class creation; use __new__ to change the namespace and __init__ to finalize the class object.
