type is a metaclass
All classes you define are instances of type unless you specify another metaclass.
Dynamic creation
type(name, bases, dict) mirrors the class statement and returns a class object.
Where to act
Modify namespace in __new__; register or finalize in __init__.
Parting thought
Metaclasses give definition-time control. Use them sparingly and document side effects for maintainability.
