Common Pitfalls
What to avoid
  • Omitting super().__new__ or super().__init__ and breaking class creation.
  • Changing namespace in __init__ instead of __new__, which has no effect on the created class.
  • Adding attributes without guarding against name collisions.
  • Expecting metaclasses to run per-instance — they execute at class definition time.
Mitigations
  • Call super() in both __new__ and __init__.
  • Make namespace modifications only in __new__.
  • Use reserved attribute names or prefixes to avoid collisions.
  • Document metaclass side effects clearly for users.
Key Takeaway
Careful design and tests keep metaclasses powerful without becoming maintenance hazards.
