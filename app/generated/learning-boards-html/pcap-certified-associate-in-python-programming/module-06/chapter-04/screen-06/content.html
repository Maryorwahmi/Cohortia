Process Flow
Parts of type(name, bases, dict)
name
A string used for class.__name__ and representation; choose readable identifiers for debugging.
bases
A tuple of base classes that determines inheritance and MRO. Always pass a tuple, e.g., (object,).
dict
A mapping of names to attributes, methods, and descriptors. Functions here become bound methods on instances.
Concrete example
# Build a small class with a property
def _get_full(self):
  return f"{self.first} {self.last}"

Person = type('Person', (object,), {
  'first': 'John',
  'last': 'Doe',
  'full_name': property(_get_full)
})

p = Person()
print(p.full_name)  # John Doe
Tips
  • Use descriptors in the dict to create computed or validated attributes.
  • Remember that class decorators run after the metaclass has created the class.
  • Validate the dict content if you build classes from untrusted sources.
