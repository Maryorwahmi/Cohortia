Core Concept
Everything is an object
Classes are objects, and the metaclass is the class that creates them. This underpins introspection and metaprogramming.
Quick verification
# Inspect types
class MyClass:
  pass

obj = MyClass()
print(type(obj))    # <class '__main__.MyClass'>
print(type(MyClass))# <class 'type'>
Analogy
If classes are blueprints, metaclasses are the factory machines that assemble those blueprints into usable class objects.
Misconception
Metaclasses do not create instances of your classes; they control the creation of the class objects themselves.
What to observe
  • type(X) describes the class of X; for a class object, its class is a metaclass.
  • type is itself a class, so Python's object model is consistent and reflective.
  • Understanding this makes metaprogramming predictable and debuggable.
Key Takeaway

Thinking of classes as objects lets you inspect and modify them programmatically. The metaclass is the constructor of those class objects.
