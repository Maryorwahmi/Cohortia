AbstractInterface metaclass
class AbstractInterface(type):
  def __new__(mcs, name, bases, namespace):
    if 'process_data' not in namespace or not callable(namespace['process_data']):
      raise TypeError(f"Class {name} must implement 'process_data(self, data)' method.")
    return super().__new__(mcs, name, bases, namespace)

# Example that should pass
class ConcreteProcessor(metaclass=AbstractInterface):
  def process_data(self, data):
    return f"Processing: {data}"

Testing tips
  • Import the module containing the metaclass to see the TypeError on faulty classes.
  • Write unit tests that assert the presence of a method and behavior of a correctly implemented class.
  • Use clear error messages showing the class name and missing method for quick debugging.
Key Takeaway

Validate required APIs in __new__ and raise clear errors so authors know why their class failed to be defined.
