Understand how Python constructs class objects, create classes at runtime with type, and write metaclasses that alter class definitions before they exist in code.

Explore Key Topics
Three core ideas you'll encounter in this chapter
Everything is an Object
Classes are themselves objects; they are instances of a metaclass.
Dynamic Creation
type(name, bases, dict) constructs classes at runtime using those three parts.
Custom Metaclasses
Override __new__ and __init__ in a metaclass to modify classes when they are defined.
