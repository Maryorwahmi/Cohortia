Step-by-step checklist
  1. 1. Try: convert num1_str and num2_str to float.
  2. 2. Inside try: select operation and compute result; raise ValueError for unsupported operations.
  3. 3. Except ValueError: print the message and return None.
  4. 4. Except ZeroDivisionError: print a division-specific error and return None.
  5. 5. Else: print and return the result.
  6. 6. Finally: always print a completion message.
