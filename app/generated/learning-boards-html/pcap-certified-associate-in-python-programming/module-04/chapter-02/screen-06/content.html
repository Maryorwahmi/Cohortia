Comparison › Specific vs Broad
Specific Handlers

Handle known error types directly, for example ValueError for bad conversions or FileNotFoundError for missing files. This yields targeted messages and correct recovery.

Example
except ValueError: print('Please enter a number')
Broad Handlers

Using except Exception: will catch many unexpected issues, which can hide real bugs and make debugging harder. Use it sparingly for logging or safe shutdown.

Pitfall
A broad catch may silence exceptions that indicate programming errors you should fix.
Ordering rule
Place specific except blocks first, then broader ones. Python matches the first suitable handler it finds.
