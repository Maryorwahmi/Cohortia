Process Flow › Try & Except Flow
Step-by-step
  1. 1. Try: execute the risky statement(s).
  2. 2. If an exception occurs, jump to the first matching except block.
  3. 3. Run handler code to recover, log, or inform the user.
  4. 4. Continue execution after the try-except construct.
Common pitfall
Placing unrelated statements in try makes it unclear which statement raised the exception and can produce misleading handlers.
Annotated Example
Scenario
Get two inputs, convert to numbers, divide. Either conversion or division can fail and needs a clear handler.
Example handler
try:
  num = int(user_input)
  result = 10 / num
except ValueError:
  print("Please enter a valid integer.")
except ZeroDivisionError:
  print("Cannot divide by zero.")
Key Takeaway

Use try for the minimal risky code and specific except handlers for clear recovery paths.
