Introduction to Exception Handling
Use try, except, else and finally so runtime errors are handled predictably.

Exceptions occur during execution when an operation cannot complete: dividing by zero, missing files, or invalid conversions. Proper handling lets your program continue, inform users, or safely recover.

We will focus on specific, practical patterns: small try blocks for risky operations, targeted except clauses for known errors, else for success-only logic, and finally for cleanup that must always run.

Throughout the lesson you will see concrete code examples and common pitfalls, so you can write resilient Python programs for user input, file I/O, and arithmetic operations.
