Definition › Else Clause
Why else exists
Else separates the code that should only run when the try succeeds from the code that you want to protect with exception handling. This increases clarity and reduces accidental exception capture.
Pattern
try: risky operation except X: handle error else: dependent work
Concrete example
Try opening a file; if successful, else parse its contents; finally close it.
Misconception

Else is optional but helps prevent handlers from catching errors that occur in success logic.
