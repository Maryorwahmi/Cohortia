def safe_divide():
    try:
        num1 = float(input("Enter the numerator: "))
        num2 = float(input("Enter the denominator: "))
        result = num1 / num2
    except ValueError:
        print("Invalid input. Please enter numbers only.")
        return None
    except ZeroDivisionError:
        print("Error: Cannot divide by zero.")
        return None
    else:
        print(f"Division successful. Result: {result}")
        return result
    finally:
        print("Division attempt completed.")

safe_divide()
Annotations
  • Try: conversion and division are the risky steps that may raise ValueError or ZeroDivisionError.
  • Except ValueError: handles non-numeric input and returns None so caller sees failure.
  • Except ZeroDivisionError: handles division by zero separately for a clearer message.
  • Else: runs only on success and prints and returns the result.
  • Finally: always runs and prints the completion note even if a return occurred earlier.
