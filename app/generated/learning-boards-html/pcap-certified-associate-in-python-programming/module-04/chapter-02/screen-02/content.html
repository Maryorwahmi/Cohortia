Mnemonic & Practical Tip
Think: try the risky operation, except when an expected error occurs, else if successful, finally always. Keep try blocks minimal and handle only the errors you know how to fix.
Venn
Try ⊆ Risky code; Except ⊆ Known fixes; Finally ∩ Always-run cleanup.
Quick Example
Converting user input to int can raise ValueError. Catch it explicitly and prompt again rather than letting the program crash.
