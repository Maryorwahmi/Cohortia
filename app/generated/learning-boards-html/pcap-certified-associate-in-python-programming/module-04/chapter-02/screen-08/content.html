Process › Finally Clause
What finally guarantees
No matter whether try succeeded, an except handled an error, or an exception propagated, finally executes before control leaves the surrounding construct.

Use finally to free resources: close files, release locks, or print a final status message. Keep its code minimal to avoid new errors.

Misconception: finally is not a place to attempt complex recovery; its purpose is guaranteed housekeeping.

Concrete pattern
try: open resource and operate except: handle known errors else: post-success work finally: release resource
Key Takeaway

Finally runs always; use it for concise cleanup so resources are never left open after errors.
