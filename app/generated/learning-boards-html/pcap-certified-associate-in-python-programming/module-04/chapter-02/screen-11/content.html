Starter Template
def calculator(num1_str, num2_str, operation_str):
    try:
        num1 = float(num1_str)
        num2 = float(num2_str)

        if operation_str == "add":
            result = num1 + num2
        elif operation_str == "subtract":
            result = num1 - num2
        elif operation_str == "multiply":
            result = num1 * num2
        elif operation_str == "divide":
            result = num1 / num2
        else:
            raise ValueError("Unsupported operation. Choose from 'add', 'subtract', 'multiply', 'divide'.")

    except ValueError as e:
        print(f"Input Error: {e}")
        return None
    except ZeroDivisionError:
        print("Calculation Error: Cannot divide by zero.")
        return None
    except Exception as e:
        print(f"An unexpected error occurred: {e}")
        return None
    else:
        print(f"Calculation successful: {num1} {operation_str} {num2} = {result}")
        return result
    finally:
        print("Calculator operation attempt finished.")
Design notes
  • Place conversion inside try so ValueError is caught for both conversion and explicit unsupported operation raise.
  • Handle ZeroDivisionError separately so division errors give a clear message.
  • Use a final broad except for logging unexpected issues, but consider re-raising in development.
  • Else prints the result only when conversion and operation succeeded.
