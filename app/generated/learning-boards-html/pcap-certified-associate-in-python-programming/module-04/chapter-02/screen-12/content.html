Scenario Cards
some_function(0) — raises ZeroDivisionError
Try executes until division, ZeroDivisionError raised, except ZeroDivisionError runs, else skipped, finally runs, then flow continues.
some_function(5) — runs successfully
Try completes, except blocks skipped, else executes, finally executes, and the program continues normally.
Unhandled exception scenario
If an exception is raised and no except matches, finally still runs, and then the exception propagates out of the current scope.
Check your trace
When reading code, ask: could any line raise an exception? Which exception types? Where will each type be handled? This habit helps you place handlers and cleanup where they belong.
Key Takeaway

Predicting flow for each scenario clarifies where to log, recover, and free resources.
