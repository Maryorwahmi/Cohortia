Core Concept › Text vs Binary Files
Text Files (encoding)

Text files store characters and require an encoding to map bytes to characters. Python decodes bytes into str when opened in text mode.

Example
A .txt file opened with encoding UTF-8 returns str objects, suitable for human-readable content.
Common mistake
Treating binary data as text, which can raise UnicodeDecodeError or corrupt data.
Binary Files (bytes)

Binary files hold raw bytes. Python returns bytes objects when reading in binary mode and expects bytes when writing.

Example
Images, audio, and compressed archives must be copied or processed as bytes to avoid corruption.
Pro tip
Always decide if the content is textual or binary before choosing the open mode.
Analogy
Think of text as a typed letter you can read and edit, and binary as a photograph: both are files, but only the letter is meant to be interpreted as characters.
