Learning Objectives

Four practical skills with verification milestones to measure your competency.

01
Differentiate text and binary

Explain encoding and why text files are character sequences while binary files are raw bytes. Verified competency milestone: explain and give an example where binary mode is required.

02
Read and write binary data

Use rb and wb to handle bytes objects, and avoid TypeError by matching bytes and str usage. Verified milestone: copy a binary file and confirm byte counts match.

03
Read CSV robustly

Use csv.reader and newline handling to parse rows reliably, avoiding manual split pitfalls. Verified milestone: read headers and iterate rows without extra blank lines.

04
Use DictReader / DictWriter

Map rows to dictionaries and write rows from dictionaries with explicit fieldnames. Verified milestone: create output with writeheader and matching fieldnames.
