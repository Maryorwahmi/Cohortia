Code Walkthrough › csv.reader
Example Code
import csv

with open("data.csv", "r", newline='') as infile:
  reader = csv.reader(infile)
  header = next(reader)  # header row
  print(f"Header: {header}")
  for row in reader:
    print(f"Row: {row}")
Notes & Pitfalls
  • Use newline equals empty string when opening the file to prevent extra blank rows.
  • csv.reader returns lists, not dictionaries; use DictReader for named access.
  • Convert types with try/except to handle malformed numeric fields.
Check your understanding
If a field contains a comma inside quotes, will csv.reader split it into extra columns? No — csv handles quoting and preserves the field.
