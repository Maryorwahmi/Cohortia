Comparison › Mistakes vs Best Practices
Common Mistakes
  • Writing str to a binary file or bytes to a text file, causing TypeError.
  • Using split(',') on CSV, breaking on quoted commas or newlines inside fields.
  • Omitting newline='' when opening CSVs and seeing extra blank lines.
  • Mismatched fieldnames with DictWriter causing missing or extra columns.
Best Practices
  • Match file mode to data type: rb/wb for bytes, r/w with encoding for text.
  • Use the csv module to respect quoting and delimiters.
  • Open CSV files with newline equal to empty string so csv handles newlines.
  • Validate numeric conversions and supply explicit fieldnames to DictWriter.
Key Takeaway
Simple, consistent rules make file handling predictable and prevent corrupt outputs.
