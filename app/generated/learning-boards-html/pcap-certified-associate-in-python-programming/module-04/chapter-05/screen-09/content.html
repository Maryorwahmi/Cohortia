Code Walkthrough › DictReader & DictWriter
Reading with DictReader
with open("data.csv", "r", newline='') as infile:
  reader = csv.DictReader(infile)
  for row in reader:
    print(f"Name: {row['Name']}, Age: {row['Age']}")
Writing with DictWriter
fieldnames = ['Name','Occupation','Age']
with open("new_people.csv", "w", newline='') as outfile:
  writer = csv.DictWriter(outfile, fieldnames=fieldnames)
  writer.writeheader()
  writer.writerows(new_people)
Practical Notes
  • DictReader uses the first row as keys; missing headers lead to unexpected keys.
  • Provide fieldnames to DictWriter and call writeheader to create the header row.
  • Validate your dictionaries against the fieldnames to avoid ValueError or missing columns.
Common error
Mismatched fieldnames or incorrectly-typed dictionary keys cause ValueError or blank columns in output.
