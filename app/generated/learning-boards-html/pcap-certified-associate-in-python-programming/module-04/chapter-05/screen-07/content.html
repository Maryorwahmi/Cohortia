Definition › CSV structure
What is a CSV?

A CSV file stores rows of values separated by commas or other delimiters. Headers are usually the first row and name each column.

Why not split on commas?
Splitting breaks when fields include commas inside quotes or when different delimiters are used. The csv module handles these cases correctly.
Important detail
Always open CSV files with newline set to an empty string so the csv module can manage newlines and avoid blank rows in the output.
Concrete Example
A row like: Joe,"New York, NY",30 would include a comma inside the quoted city field. csv.reader returns the correct three fields instead of splitting inside the quoted city.
Pro tip
Let csv handle quoting and delimiters to avoid brittle parsing logic.
Key Takeaway

Use csv.reader and newline equals empty string to read rows reliably, even when fields contain commas or newlines.
