Code Walkthrough › Binary copy example
Example Code
# Create a dummy binary file
with open("source.bin", "wb") as f:
  f.write(b'\x47\x49\x46\x38\x39\x61\x01\x00')

try:
  with open("source.bin", "rb") as infile:
    binary_data = infile.read()
    print(f"Read {len(binary_data)} bytes from source.bin")

  with open("destination.bin", "wb") as outfile:
    outfile.write(binary_data)
    print("Successfully copied source.bin to destination.bin")

except FileNotFoundError:
  print("Error: Binary file not found.")
except Exception as e:
  print(f"An error occurred: {e}")
Line-by-line Notes
  • The first block creates a small binary file using wb so the written object is bytes.
  • Reading with rb returns a bytes object; checking len confirms the number of bytes read.
  • Writing to wb writes raw bytes unchanged to the destination.
  • Try/except handles missing files and other unexpected errors without crashing the program.
Common Misconception

Do not decode binary data to strings for simple copying; decoding is only for textual data with a known encoding.
