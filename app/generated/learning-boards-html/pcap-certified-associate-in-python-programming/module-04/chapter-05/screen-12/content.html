Module 4 › Chapter 4.5 › Key Concepts
Text Files
Human-readable characters decoded from bytes using an encoding such as UTF-8.
Binary Files
Raw bytes for images, audio, or other non-text data; use rb and wb modes to handle them safely.
bytes object
An immutable sequence of bytes returned by binary reads; required when writing to binary files.
Summary
Pick the right mode and let Python's csv and binary I/O tools handle format details for reliable data exchange.
