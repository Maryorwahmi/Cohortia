Process Flow › Binary read/write
Step-by-step
  1. Open source in binary read mode, for example rb.
  2. Read bytes with read(); store in a bytes object and optionally check len(bytes).
  3. Open destination in binary write mode wb and write those bytes back.
  4. Catch FileNotFoundError and other exceptions to report issues cleanly.
Common mistake
Writing strings to a binary stream causes TypeError. Always match bytes to binary modes.
Concrete Example
# Copy a small binary file safely
with open("source.bin", "rb") as infile:
  data = infile.read()
  print(f"Read {len(data)} bytes")

with open("destination.bin", "wb") as outfile:
  outfile.write(data)
  print("Copy complete")
This example reads raw bytes and writes them unchanged to the destination. Use try/except in production to catch missing files or other errors.
Key Takeaway
Binary operations work with bytes objects; match file mode to data type and verify byte counts after copying.
Try verifying file size or checksum after copy to detect corruption.
