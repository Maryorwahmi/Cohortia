Definition and common calls
The os module exposes filesystem utilities that work across operating systems. These functions let scripts inspect and mutate directories and files safely when used with path checks.
import os

# Find where the script runs
cwd = os.getcwd()
print(f"Current directory: {cwd}")

# List files and directories
entries = os.listdir('.')
print(entries)

# Create nested folders
os.makedirs('data/reports', exist_ok=True)

# Remove an empty folder
# os.rmdir('old_empty_folder')

# Rename a file
# os.rename('temp.txt', 'final.txt')
Explanation
  • os.getcwd gives your script an absolute reference point for building paths.
  • os.listdir returns names only; combine with os.path.join to get full paths.
  • Use os.makedirs to create nested directories in a single call.
Concrete example
A logger ensures a logs directory exists before writing a file, preventing FileNotFoundError when opening the logfile later.
Key Takeaway

Prefer constructing absolute or joined paths instead of changing the current working directory globally.
