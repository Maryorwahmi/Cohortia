Module 5 › Chapter 4.6 › Binary file modes
Key distinctions
  • Text mode returns str and uses encoding/decoding.
  • Binary mode returns bytes; no decoding is attempted.
  • Use chunked reads to copy large binary files without high memory usage.
Mnemonic: add b for raw bytes — "rb" reads raw bytes, "wb" writes raw bytes unchanged.
Example
To copy a binary file, read a chunk with source.read(4096) and write that chunk directly to the destination file. Repeat until empty bytes are returned.
Common mistake

Opening a binary file in text mode can raise UnicodeDecodeError or corrupt data when writing; always use the appropriate mode.
