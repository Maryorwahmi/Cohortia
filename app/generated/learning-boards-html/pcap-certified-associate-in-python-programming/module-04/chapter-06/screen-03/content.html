Module 5 › Chapter 4.6 › Learning Objectives — Practice
Objective: directory lifecycle
Create PROFILE_DIR if missing, use os.path.join to build paths, and ensure clean removal only when appropriate.
Objective: save and load profiles
Implement save_profile and load_profile that use pickle with binary modes and handle missing files gracefully.
Objective: list profiles
Enumerate .pkl files in PROFILE_DIR and return names without the extension for display or selection.
Objective: chunked binary copy
Read and write fixed-size byte chunks to copy binary files without excessive memory use.
Practice Hint
Keep small, focused tests: create a directory, save two profiles, list them, then load one. Clean up test files afterwards to avoid confusion.
