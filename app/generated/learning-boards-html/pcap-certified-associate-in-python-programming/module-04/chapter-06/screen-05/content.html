Module 5 › Chapter 4.6 › Working with cwd
Step-by-step
A defensive sequence to perform file operations without global side effects.
  1. Read os.getcwd to log the starting directory.
  2. Build paths with os.path.join rather than relying on relative paths.
  3. Create directories with os.makedirs if they don’t exist.
  4. Open files using the constructed absolute paths.
Concrete code
import os
base = os.getcwd()
profile_dir = os.path.join(base, 'user_profiles')
if not os.path.isdir(profile_dir):
  os.makedirs(profile_dir)
# Now use absolute paths under profile_dir safely
Misconception
Changing the current directory isolates changes to a function: it doesn't. chdir affects the whole process and can create hard-to-debug behavior in larger apps.
Pro Tip

If you must chdir in a script, do it in a short-lived context and restore the original directory afterward to limit side effects.
