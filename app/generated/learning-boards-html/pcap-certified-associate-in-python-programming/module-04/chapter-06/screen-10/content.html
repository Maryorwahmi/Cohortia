Module 5 › Chapter 4.6 › Binary copy
Example code
# Create a small dummy binary file and copy it
with open('source_image.bin', 'wb') as f:
  f.write(b'\x89PNG\r
\x1a
\x00\x00\x00\rIHDR\x00\x00')

try:
  with open('source_image.bin', 'rb') as source:
    with open('destination_image.bin', 'wb') as destination:
      while True:
        chunk = source.read(4096)
        if not chunk:
          break
        destination.write(chunk)
  print('Binary file copied successfully.')
except FileNotFoundError:
  print('Source file not found.')
except IOError as e:
  print(f'Error copying file: {e}')
Why it works
Reading fixed-size chunks avoids excessive memory use. The loop stops when source.read returns empty bytes, signaling EOF.
Pitfall
Don't check for None; check for an empty bytes object. Also, remember to open streams in binary mode.
Key Takeaway

Chunked reads and writes are memory efficient and robust for copying arbitrary binary content.
