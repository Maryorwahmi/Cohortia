Module 5 › Chapter 4.6 › Serialization
What serialization does
Transform an object graph into bytes for storage or transmission, then reconstruct it later preserving Python types where possible.
Use cases include saving user profiles, caching computed results between runs, or storing program state across sessions.
Pickle example
import pickle

my_data = {'name': 'Alice', 'age': 30, 'courses': ['Python', 'Data Science']}
with open('my_data.pkl', 'wb') as f:
  pickle.dump(my_data, f)

with open('my_data.pkl', 'rb') as f:
  loaded = pickle.load(f)
print(type(loaded), loaded)
Misconception

Pickle is not safe for data from unknown sources; unpickling can run arbitrary code during reconstruction.
