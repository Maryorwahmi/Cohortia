Module 5 › Chapter 4.6 › pickle vs json
Pickle
  • Serializes most Python objects with minimal work.
  • Requires binary mode to read/write pickled bytes.
  • Not safe for untrusted data due to potential code execution.
JSON
  • Language-agnostic and human-readable.
  • Supports a limited set of types; custom classes need translation.
  • Prefer JSON for configuration, API data, and untrusted input.
Security reminder
Never unpickle data from untrusted sources. If you must accept external pickled data, use alternative safe formats or strong sandboxing because pickle can execute arbitrary code during deserialization.
