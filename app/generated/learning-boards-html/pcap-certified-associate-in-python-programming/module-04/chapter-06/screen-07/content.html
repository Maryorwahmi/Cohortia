Module 5 › Chapter 4.6 › Path handling
Helper architecture
Design small, testable helpers to construct paths, validate them, and perform file actions.
1. Path builder: os.path.join(base, component)
2. Validator: os.path.exists / isfile / isdir
3. Action: os.rename / os.remove guarded by try-except
Code snippet
import os

def safe_rename(src, dst_base):
  dst = os.path.join(dst_base, os.path.basename(src))
  if os.path.exists(src):
    try:
      os.rename(src, dst)
    except PermissionError:
      print('Permission denied when renaming')
  else:
    print('Source not found')
This pattern separates concerns and keeps file operations predictable and testable.
Key Takeaway

Always construct paths programmatically and validate before performing rename or delete actions to avoid cross-platform bugs and accidental data loss.
