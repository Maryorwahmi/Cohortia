Implementation hints
  • Use os.makedirs(PROFILE_DIR, exist_ok=True) for setup.
  • Construct file paths with os.path.join(PROFILE_DIR, f"{username}.pkl").
  • Open files with 'wb' for dump and 'rb' for load, and catch FileNotFoundError in load_profile.
Common pitfall
Returning an empty dict on load hides the difference between a missing file and an empty profile; prefer None or raise a clear message when a profile doesn't exist.
Key Takeaway

Break the activity into tiny tests: setup, save, list, load. Each function should be small and verifiable.
