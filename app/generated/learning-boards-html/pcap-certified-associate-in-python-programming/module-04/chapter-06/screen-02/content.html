Learning Objectives
Concrete skills and why they matter for reliable file-backed applications.

01
Manage the file system with os
Use getcwd, listdir, mkdir, remove and rename to inspect and modify files and directories. This matters for organizing app data and automating maintenance.
Mnemonic: Think "os = operating system map" — learn where you are and how to move files.
VERIFIED COMPETENCY MILESTONE
02
Read and write binary files
Open files with rb/wb and process raw bytes in chunks to copy images or other binary assets safely without decoding errors.
Mnemonic: b for bytes — "rb" reads raw bytes, "wb" writes raw bytes.
VERIFIED COMPETENCY MILESTONE
03
Serialize Python objects with pickle
Use pickle.dump and pickle.load to persist complex objects like dicts or lists. This is convenient for Python-only storage but requires caution about untrusted data.
Mnemonic: pickling stores Python objects as bytes you can later unpickle back into objects.
VERIFIED COMPETENCY MILESTONE
04
Handle file errors robustly
Anticipate FileNotFoundError and PermissionError when reading, writing, or deleting files. Use try-except and path checks to fail gracefully.
Mnemonic: Check first, then act — validate paths to avoid destructive mistakes.
VERIFIED COMPETENCY MILESTONE
