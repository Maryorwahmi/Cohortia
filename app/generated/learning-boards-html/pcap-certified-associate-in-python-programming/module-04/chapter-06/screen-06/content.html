Module 5 › Chapter 4.6 › Directory lifecycle
Safety checklist
  • Build a full path with os.path.join before acting.
  • Use os.path.isdir or os.path.exists to confirm the target.
  • Prefer os.makedirs(path, exist_ok=True) to avoid race errors.
  • Before removal, list contents and confirm emptiness when using rmdir.
Example: safe cleanup
Check that the directory is under an allowed base, list files, archive or move them if needed, then remove only empty folders with rmdir or removedirs.
Sample code
import os
base = os.path.abspath('data')
# Only remove if target is inside base
target = os.path.abspath(os.path.join(base, 'temp'))
if target.startswith(base):
  entries = os.listdir(target) if os.path.isdir(target) else []
  if not entries:
    os.rmdir(target)
  else:
    print('Directory not empty; archive contents first.')
