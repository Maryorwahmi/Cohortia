Module 5 › Chapter 4.6 › Create, write, rename
Full example code
import os

print(f"Current directory: {os.getcwd()}")
try:
  os.mkdir('my_data')
  print("Directory 'my_data' created.")
except FileExistsError:
  print("Directory 'my_data' already exists.")

file_path = os.path.join('my_data', 'notes.txt')
with open(file_path, 'w') as f:
  f.write('This is a test note.')
print(f"File '{file_path}' created.")

new_file_path = os.path.join('my_data', 'important_notes.txt')
os.rename(file_path, new_file_path)
print(f"File renamed to '{new_file_path}'.")
Explanation
  • Create directories before creating files inside them to avoid FileNotFoundError.
  • Use try-except to handle existing directories or permission issues.
  • os.rename is used to move or rename files atomically when possible.
Common mistake
Opening a file with the wrong path or before creating its parent directory often causes FileNotFoundError; always create parent directories first or build absolute paths safely.
Key Takeaway

Order your operations: ensure parent directories exist, write files, then rename or move as a final step, and guard with exceptions.
