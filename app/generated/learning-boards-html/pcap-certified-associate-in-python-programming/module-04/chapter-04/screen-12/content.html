Module 04 › Chapter 4.4 › Lab: Filter names

Lab steps

Step 1 — Create input file
Write several names into names.txt, one per line for predictable input during testing.
Step 2 — Read and filter
Use with open(..., 'r') and for line in file to strip and test length, adding uppercase names that meet the length to a list with ' '.
Step 3 — Write results
Open filtered_names.txt in 'w' and call writelines on the prepared list. Re-open to verify content.
Step 4 — Error handling
Wrap the initial read in try-except FileNotFoundError to notify the user if the input is missing.
# Starter template (adapt as needed)
with open("names.txt", "w") as f:
    f.write("Alice
")
    f.write("Bob
")
    f.write("Charlie
")

input_filename = "names.txt"
output_filename = "filtered_names.txt"
processed_names = []

try:
    with open(input_filename, 'r') as infile:
        for line in infile:
            name = line.strip()
            if len(name) >= 5:
                processed_names.append(name.upper() + '
')
except FileNotFoundError:
    print(f"Error: The file '{input_filename}' was not found.")

if processed_names:
    with open(output_filename, 'w') as outfile:
        outfile.writelines(processed_names)
