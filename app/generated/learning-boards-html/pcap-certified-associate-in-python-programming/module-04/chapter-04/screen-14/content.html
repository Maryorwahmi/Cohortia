What to remember

File object
open() returns a managed resource you must close or context-manage.
File modes
'r', 'w', 'a', 'x' determine creation and overwrite behavior.
Context managers
Use with to auto-close and maintain safe, predictable behavior.
Summary: choose the right mode, write with explicit newlines when needed, iterate for large files, and handle file exceptions to build robust scripts.
