Module 04 › Chapter 4.4 › Open a file
Core Concept

What open() gives you

A file object with methods and a pointer. It represents the program's access to a file on disk and must be closed when finished.

Key properties
  • Exposes read, write, readline, readlines, and close.
  • Keeps a current position pointer used by sequential operations.
  • Is a resource allocated by the OS that needs release.
Key Takeaway

Treat file objects as managed resources: open, use, and close to avoid leaks and unfinished writes.

Concrete example
# Open a file for reading
file = open("my_data.txt", "r")
content = file.read()
print(content)
file.close()

# File object methods: read(), readline(), write(), close()
Misconception
Relying on program exit to close files risks lost buffered writes during long-running processes.
Pro tip
Prefer the with statement to ensure closure even if exceptions occur.
