Module 04 › Chapter 4.4 › Append vs Overwrite

Preserve history or start fresh?

Append ('a')
Adds new data to the end. Creates file if missing. Use for logs and incremental updates.
Overwrite ('w')
Creates or clears file before writing. Use when you intentionally want a fresh output.
Exclusive create ('x')
Fails if the file exists. Use when accidental overwrite is unacceptable.
Practical pattern
For critical writes, write to a temp file then rename to replace atomically and reduce partial-write risk.
Check your intent
Ask: Should existing data be kept or replaced? The correct mode follows the answer.
