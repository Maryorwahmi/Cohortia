Using with for file safety

The with block creates a scope where the file is guaranteed to close when the block ends, even after exceptions.

# Bad practice
file = open("out.txt", "w")
file.write("Line one")
# If an error occurs here, file.close() might never run

# Good practice
with open("out.txt", "w") as file:
    file.write("Line one")
# File is closed automatically here
Use finally with manual close only when you have unusual lifetime needs; for typical I/O the with pattern is shorter and safer.
Concrete scenario

Imagine writing a log and then raising an exception. With ensures the log file is closed and the entry is flushed; without it you may lose recent writes.

Key Takeaway
Prefer with open(...) as file for all ordinary file operations to guarantee closure and flush behavior.
