Comparison

File modes at a glance

'r' — Read
Requires existing file, returns content for reading. Raises FileNotFoundError if missing.
'w' — Write
Creates or truncates file. Use when you intentionally overwrite content.
'a' — Append
Creates if missing and writes at end. Ideal for logs where prior content must be preserved.
'x' — Exclusive create
Fails if the file exists. Use when you must avoid overwriting any existing file.
Concrete example
To add a timestamped log entry without deleting prior entries, open the file in append mode. Using 'w' would replace the log each run.
Common mistake
Accidentally opening a persistent data file with 'w' instead of 'a' and losing historical data.
