Module 04 › Chapter 4.4 › Verify outputs

Post-write checks

Open and read
Re-open the output file and print the first few lines to confirm format and content.
Check newlines
Ensure each written string ends with ' ' so lines display separately when read.
Detect empty outputs
If no content was written, verify your filter conditions and confirm the input file contains expected data.
# Verify output
with open("filtered_names.txt", "r") as f:
    for i, line in enumerate(f, 1):
        print(i, line, end='')
        if i >= 5:
            break
Key Takeaway
Verification is part of the file workflow and prevents surprises when scripts run unattended.
