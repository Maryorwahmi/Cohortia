Module 04 › Chapter 4.4 › Line reading
Examples
# readline in a loop
with open("my_data.txt", "r") as f:
    line = f.readline()
    while line:
        print(line, end='')
        line = f.readline()

# readlines returns a list
with open("my_data.txt", "r") as f:
    lines = f.readlines()
    print(lines)

# iterate file object (most memory-efficient)
with open("my_data.txt", "r") as f:
    for line in f:
        print(line, end='')
Guidance
  • Prefer iteration for large files to keep memory usage low.
  • Use readline for controlled, manual progression when needed.
  • Use readlines only when you need random access to lines in memory.
Misconception
Iterating is slower than readlines — often false; iteration is both memory-efficient and simple, suitable for most tasks.
