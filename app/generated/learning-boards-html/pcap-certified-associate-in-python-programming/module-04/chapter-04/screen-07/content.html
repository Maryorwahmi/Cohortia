read() — all at once

Returns the entire content as a single string. Simple, but watch memory usage for large files.

with open("my_data.txt", "r") as file:
    content = file.read()
print("--- Full Content ---")
print(content)
When to use
Small files like short configs or templates.
When not to use
Large logs or datasets where memory could spike.
Concrete example
Read a small config file and split on newlines for simple parsing.
