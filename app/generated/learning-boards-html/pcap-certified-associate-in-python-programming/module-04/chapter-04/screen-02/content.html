Learning Objectives

Practical skills you will practice and verify.

Bloom: Learn → Understand → Apply → Master
01
File I/O fundamentals

Explain what a file object is and what open() returns, so you can reason about file handles and operations.

VERIFIED COMPETENCY MILESTONE
02
Open & close safely

Use the with statement to ensure files close even on exceptions and avoid resource leaks.

VERIFIED COMPETENCY MILESTONE
03
Read methods

Choose read, readline, readlines, or file iteration depending on file size and access pattern.

VERIFIED COMPETENCY MILESTONE
04
Write methods & errors

Use write or writelines correctly, know when append is needed, and handle FileNotFoundError and PermissionError.

VERIFIED COMPETENCY MILESTONE
