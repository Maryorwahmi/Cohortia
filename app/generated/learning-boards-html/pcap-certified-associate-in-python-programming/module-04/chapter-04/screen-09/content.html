write() and writelines()

Both write text exactly as given. Add ' ' when you want new lines; prepare lists for writelines accordingly.

# Using write()
with open("out.txt", "w") as f:
    f.write("Hello, Cohortia!
")
    f.write("This is a new line.
")

# Using writelines() - ensure each element ends with a newline
lines = ["Alice
", "Bob
", "Charlie
"]
with open("out.txt", "w") as f:
    f.writelines(lines)
Concrete example
Prepare a list of uppercase names each ending with ' ' before calling writelines to write them cleanly.
Common mistake
Forgetting newlines and seeing concatenated output on a single line.
