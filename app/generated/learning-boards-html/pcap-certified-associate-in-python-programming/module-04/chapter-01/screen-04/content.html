Module 04 › Chapter 4.1 › String Immutability
Definition
Once created, the characters in a Python string cannot be changed. Operations produce new strings.
Explanation
  • Methods like upper or replace return new string objects without modifying the original.
  • To persist changes, assign the returned value to a variable.
  • Frequent rebuilds create temporary strings; performance matters for heavy workloads.
Analogy
Think of a sealed letter: you cannot change what's written inside — you must compose a new letter with edits.
Key Takeaway

Always expect a new string result after a transformation. Assign when you mean to keep the change.

Concrete example
my_string = "hello"
upper = my_string.upper()
# my_string is still "hello"
# upper is "HELLO"
Common misconception
Beginners expect methods to change the variable in place, similar to list methods. Strings do not behave that way.
Try this
Assign transformed results to variables and run small examples to observe original values remain unchanged.
