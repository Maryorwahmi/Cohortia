Slicing with step
Use the step part of a slice to pick regular intervals or reverse a sequence.
s = "abcdefg"
# every second char
sample = s[::2]        # 'aceg'
# reverse
rev = s[::-1]          # 'gfedcba'
# slice with start and step
part = s[1:6:2]        # 'bd'
Practical uses
Sampling characters, reversing text for display, extracting patterned substrings for parsing.
Common misconception
Negative step values change how start and end are interpreted. Test examples to confirm behavior.
Key Takeaway

Slicing with step is a concise tool for extracting regular patterns and reversing strings; always remember slices return new strings.
