Mistakes and fixes
Identify typical errors and the correct patterns to resolve them.
Index assignment
Error: trying to set s[0] = 'X'. Fix: build a new string using slices, for example 'X' + s[1:].
split variants
split() collapses whitespace and trims ends. Use split(' ') when you need to preserve empty tokens between spaces.
Chaining without assign
Calling methods without storing the result discards transformations. Assign the returned string when needed.
Inefficient concatenation
Repeatedly concatenating in a loop creates many temporary strings. Collect pieces and use join for efficiency.
Quick check

When you see code that appears to modify a string in place, pause and rewrite using slices, assignment, or join to respect immutability and performance.
