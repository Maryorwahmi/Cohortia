Width, alignment, precision
Use format specifiers inside braces to control appearance.
products = [
  {"id": "P001", "name": "Laptop Pro", "price": 1200.50, "stock": 15},
]
print(f"{'ID':<5} {'Product Name':<20} {'Price':>8} {'Stock':>6}")
print("-" * 41)
for p in products:
    print(f"{p['id']:<5} {p['name']:<20} {p['price']:>8.2f} {p['stock']:>6}")
Field width
A number before the format type sets total width, e.g., 20 for a name field.
Alignment & precision
Use < for left, > for right. Use .2f to set two decimal places for floats.
Key Takeaway

Test field widths with your longest expected values and choose alignment that makes numbers and text easy to scan.
