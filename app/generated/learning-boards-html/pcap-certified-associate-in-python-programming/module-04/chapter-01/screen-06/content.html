Module 04 › Chapter 4.1 › strip / split / join
Common cleaning pipeline
Trim, split into tokens, transform tokens, then join for output.
line = "  apple,  Banana ,cherry ,, "
fields = [f.strip() for f in line.split(',') if f.strip()]
normalized = ", ".join(f.title() for f in fields)
# normalized -> 'Apple, Banana, Cherry'
strip()
Removes surrounding whitespace or specified characters. Use it to clean inputs before parsing.
split()
Splits into a list using a delimiter. No-argument split collapses consecutive whitespace.
join()
Combines a list into a single string using the caller as the separator. Efficient for many pieces.
Common mistake
Using split without arguments vs split(" ") leads to different tokenization. Test with extra spaces.
Example use
Normalize CSV fragments into a clean, titled list suitable for display or storage.
