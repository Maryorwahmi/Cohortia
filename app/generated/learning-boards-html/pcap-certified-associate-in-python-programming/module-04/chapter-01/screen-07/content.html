Locate and check
Use find/index for positions and startswith/endswith for simple pattern checks.
text = "user@example.com"
pos = text.find("@")
if pos != -1:
    local = text[:pos]
    domain = text[pos+1:]
# startswith and endswith for quick guards
if text.endswith(".com"):
    pass
  • index raises an exception if not found; find returns -1.
  • Use startswith/endswith for fast boolean checks used in filtering.
Replace safely
replace returns a new string; specify count to limit how many occurrences are replaced.
line = "one two one two"
new = line.replace("one", "1", 1)
# new -> '1 two one two'
Common mistake
Treating find return -1 as truthy. Always compare explicitly against -1 or use if pos >= 0.
Key Takeaway

Use inspection methods to guide safe slicing and replacements, choosing find or index based on whether absence is expected.
