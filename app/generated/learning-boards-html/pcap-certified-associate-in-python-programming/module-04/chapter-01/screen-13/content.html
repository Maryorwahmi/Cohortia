String Immutability
Transformations return new strings; assign results to keep changes.
String Methods
Use strip, split, join, find, replace, startswith, and endswith for common tasks.
f-strings & Formatting
Embed expressions, control width, alignment, and precision for clear output.
Summary

These three ideas are foundational for reliable text processing: produce new strings intentionally, choose methods to match the task, and format output for readability.
