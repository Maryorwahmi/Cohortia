How you will show mastery
Short runnable checks and small code tasks that demonstrate each objective.
Predict method output
Given chained methods, explain why the original string is unchanged and what the returned string contains.
Clean and rejoin
Strip whitespace, split tokens, apply transformations, and join back into a single formatted string.
Formatted reports
Use f-strings to print aligned tables with headers, numeric precision, and padding.
Slicing patterns
Extract every n-th character or a reversed string using slice step values.
Each task is intentionally small so you can practice iteratively and confirm results quickly.
