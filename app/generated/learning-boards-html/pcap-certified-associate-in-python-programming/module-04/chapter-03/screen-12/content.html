Module 4 › Chapter 4.3 › Catching and handling
Pattern
try:
  new_stock = update_stock(pid, change)
except ProductNotFoundError as e:
  # Inform user or create product
  print(e)
except InvalidQuantityError as e:
  # Show validation message
  print(e)
except Exception as e:
  # Last-resort handler: log and re-raise or alert
  raise
Rules of thumb
  • Catch specific exceptions first, broader ones later.
  • Prefer attribute-based logic over parsing messages.
  • Re-raise if you cannot resolve the error to preserve failure visibility.
Misconception

Catching Exception to hide errors in production hides bugs. Log and re-raise when in doubt.

Key Takeaway

Write focused except blocks and use exception attributes to decide how to recover or report errors.
