Module 4 › Chapter 4.3 › Key Concepts
raise statement

Explicitly trigger exceptions to interrupt normal flow and let callers decide recovery. Include clear messages for debugging.

Custom Exception

Define classes ending with Error, attach attributes, and call super to preserve message and traceback behavior.

assert statement

Use for development-time assertions and invariants only. Assertions can be disabled and should not guard production inputs.

Quick summary

Design exceptions with clarity: raise for runtime checks, make custom exceptions expressive and inspectable, and reserve assertions for developer checks.
