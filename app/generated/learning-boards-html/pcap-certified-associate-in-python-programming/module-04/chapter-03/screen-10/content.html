Module 4 › Chapter 4.3 › The assert statement
Example asserts
def calculate_discount(price, discount_rate):
  assert 0 <= discount_rate <= 1, "Discount rate must be between 0 and 1."
  final_price = price * (1 - discount_rate)
  assert final_price >= 0, "Final price cannot be negative."
  return final_price

# These asserts help find logic errors during development but can be disabled in optimized runs.
When to use

Use assert to verify pre-conditions, post-conditions, and invariants that indicate programmer error when violated.

When not to use

Do not use assert to check user input, authentication, or other runtime conditions that must always be enforced.

Key Takeaway

Reserve assert for development assertions and use raise for production checks that must not be disabled.
