Module 4 › Chapter 4.3 › Raise built-in exceptions
Code example
# Validate and raise a built-in exception for bad input
def set_age(age):
  if not isinstance(age, int):
    raise TypeError("age must be an integer")
  if age < 0:
    raise ValueError("Age cannot be negative")
  return age

# Caller handles the exception
try:
  print(set_age(-5))
except (TypeError, ValueError) as e:
  print("Validation error:", e)
Why this helps
  • Signals contract violations explicitly so callers can respond.
  • Provides standard exception types that are recognizable across codebases.
  • Preserves stack traces and message context for debugging and logging.
Example scenario

A library that accepts configuration should raise clear exceptions if a required field is missing or of the wrong type so application code can fall back or show a helpful error to users.

Key Takeaway

Use raise with built-in exceptions and descriptive messages to enforce input contracts and let callers decide recovery.
