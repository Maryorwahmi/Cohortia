Learning Objectives

Master raising exceptions, creating custom errors, and using assert responsibly.

Bloom: Learn → Understand → Apply → Master
01
Raise built-in exceptions

Know how and when to raise ValueError, TypeError or FileNotFoundError to move error handling to the caller. This matters for input validation and clear API contracts.

VERIFIED COMPETENCY MILESTONE
02
Create custom exceptions

Define exception classes that inherit from Exception or a subclass so your code signals domain-specific errors clearly and supports fine-grained except blocks.

VERIFIED COMPETENCY MILESTONE
03
Attach context to exceptions

Store attributes like balance or product_id in your exception so handlers can make informed decisions without parsing messages.

VERIFIED COMPETENCY MILESTONE
04
Differentiate assert vs raise

Use assert for developer invariants and raise for runtime validation. Avoid using assert for checks that must run in production.

VERIFIED COMPETENCY MILESTONE
