class InsufficientFundsError(Exception):
  def __init__(self, balance, amount):
    self.balance = balance
    self.amount = amount
    message = f"Attempted to withdraw {amount} with only {balance} available."
    super().__init__(message)

try:
  raise InsufficientFundsError(100, 150)
except InsufficientFundsError as e:
  print("Error:", e)
  print("Balance:", e.balance, "Attempted:", e.amount)
Testing tip

Assert exception attributes in tests rather than depending solely on message text to avoid brittle tests that break when wording changes.

Avoid this

Do not embed large objects in exceptions just for convenience. Keep exceptions lightweight and focused on handling needs.

Key Takeaway

Design exceptions with attributes for programmatic inspection and meaningful messages for humans.
