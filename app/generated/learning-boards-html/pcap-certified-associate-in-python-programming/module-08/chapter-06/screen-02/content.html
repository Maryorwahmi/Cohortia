Learning Objectives
Four focused exam-ready capabilities
01
Evaluate complex expressions
Trace precedence and short-circuiting to predict exact returned operands and values. Practice with nested comparisons and boolean chains.
VERIFIED COMPETENCY MILESTONE
02
Handle mutable defaults
Detect shared default objects and apply the None pattern to ensure fresh mutable state per call.
VERIFIED COMPETENCY MILESTONE
03
Distinguish is vs equals
Use equality for value checks and identity only for same-object checks or singletons like None.
VERIFIED COMPETENCY MILESTONE
04
Use generators appropriately
Pick generator expressions to save memory and list comprehensions when you need repeatable iteration.
VERIFIED COMPETENCY MILESTONE
