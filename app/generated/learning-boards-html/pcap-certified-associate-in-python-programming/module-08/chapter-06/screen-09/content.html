Module 8 › Chapter 8.6 › Generators vs Lists
Side-by-side comparison
List comprehension
Constructs full list immediately. Good for small data and multi-pass usage.
Generator expression
Creates an iterator yielding values lazily. Memory-efficient and single-use.
  • Generators don't store all values; lists do.
  • Generators are exhausted after one iteration.
  • Convert a generator to a list to reuse elements.
Examples
# List comprehension
lst = [x * 2 for x in range(1000)]

# Generator expression
gen = (x * 2 for x in range(1000000))
Use generators to process large ranges without allocating the whole sequence. Use lists when you need the whole sequence in memory or multiple passes.
Key takeaway

Match structure to need: memory efficiency or repeated access. Generators for streaming; lists for reuse and indexing.
