Module 8 › Chapter 8.6 › Closure Loop Snippet
Snippet walkthrough
def create_incrementers():
  incrementers = []
  for i in range(3):
    incrementers.append(lambda x: x + i)
  return incrementers

incs = create_incrementers()
print(incs[0](5))
print(incs[1](5))
print(incs[2](5))
Because i is looked up when the lambda runs, not when it was defined, all three lambdas see the final value of i and produce the same result. The correct outputs will reflect that final i value applied to each call.
Fix
def create_incrementers_fixed():
  incrementers = []
  for i in range(3):
    def inc(x, factor=i):
      return x + factor
    incrementers.append(inc)
  return incrementers
Binding i as factor=i captures its current value, so each function retains the intended multiplier or offset.
Key takeaway

If closures are created in loops, bind loop variables as defaults to freeze the value per closure.
