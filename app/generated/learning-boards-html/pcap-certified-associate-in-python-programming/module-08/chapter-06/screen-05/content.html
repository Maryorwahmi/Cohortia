Short-circuiting process
  1. Evaluate sub-expressions based on operator precedence.
  2. For and: return first falsy operand, else return last operand.
  3. For or: return first truthy operand, else return last operand.
  4. Apply left-to-right evaluation during short-circuit checks.
Common mistake
Treating and/or as boolean-only operators. They can return non-boolean operands and lead to surprising printed values.
Worked example
# Evaluate step-by-step
result = 0 or 1 and 2 or 3
# 1 and 2 -> 2 (both truthy, returns last operand)
# 0 or 2 or 3 -> 2 (first truthy operand)
print(result)  # prints 2
Try rewriting with parentheses to confirm: (0) or ((1 and 2)) or (3) yields the same result.
Pro tip

When reading exam snippets, annotate truthy/falsy for each operand before applying and/or rules — this avoids mistakes.
