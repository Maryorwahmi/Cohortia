Assessment snippet explained
def process_data(item, cache={}):
  if item not in cache:
    cache[item] = f"Processed_{item}"
  return cache[item]

result1 = process_data("A")
result2 = process_data("B")
result3 = process_data("A")
result4 = process_data("C", {})

print(f"{result1}, {result2}, {result3}, {result4}")
print(len(process_data.__defaults__[0]))
Trace: the shared default cache stores A and B after the first two calls. Calling with a fresh {} for C does not affect the shared cache. Inspecting __defaults__[0] reveals the shared cache and its length reflects accumulated keys.
Correct outcome
Printed values: Processed_A, Processed_B, Processed_A, Processed_C. Length of shared default cache: 3 — keys for A, B, and C from the shared interactions.
Exam tip

When defaults are mutable, consider function.__defaults__ to inspect or reason about shared state during questions that ask about internal sizes.
