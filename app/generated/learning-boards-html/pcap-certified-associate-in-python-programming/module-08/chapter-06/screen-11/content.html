Closure semantics
Closures remember variables from enclosing scopes. Names are bound at call time unless captured with defaults at definition time.
  • Closures capture variables, not snapshot values.
  • Functions created in a loop will share the same loop variable reference.
  • Bind the loop variable using a default parameter to freeze its current value.
Fix pattern
def make_funcs():
  funcs = []
  for i in range(3):
    def f(x, factor=i):
      return factor * x
    funcs.append(f)
  return funcs
Binding i as factor=i captures the current value into the function’s default parameter at definition time.
Misconception

Don’t assume each closure created in a loop has its own independent copy of the loop variable unless you explicitly bind it.
