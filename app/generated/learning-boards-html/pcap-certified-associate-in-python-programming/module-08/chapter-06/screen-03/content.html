Scope, Closures, and Generator Lifecycle
Objectives for reliable reasoning about variable binding and iterator lifetime.
Closure
A nested function that remembers variables from its enclosing scope even after that scope returns.
Binding nuance
Loop variables are bound late; to capture the current value, bind it as a default parameter.
Generator lifecycle
Generators yield lazily and are single-use. Create a new generator if you need to iterate again.
