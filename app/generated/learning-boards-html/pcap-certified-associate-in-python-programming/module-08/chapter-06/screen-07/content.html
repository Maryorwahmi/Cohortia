Walkthrough
Trace calls and remember the default object was created once. Follow the same list reference across invocations unless a new list is passed explicitly.
Bulleted trace
  • Call 1: append 10 to shared default -> [10]
  • Call 2: append 20 to same shared default -> [10, 20]
  • Call 3 with []: operates on new list -> [30]
  • Shared default remains mutated from previous calls unless reset explicitly.
Snippet
def append_to_list(value, my_list=[]):
  my_list.append(value)
  return my_list

list_a = append_to_list(10)
list_b = append_to_list(20)
list_c = append_to_list(30, [])
print(list_a)
print(list_b)
print(list_c)
Predicted prints: [10, 20], [10, 20], [30] — because list_a and list_b reference the same default list, while list_c uses a fresh list.
Check your understanding

Ask: when was the default object created? If before all calls, it will be shared across calls.
