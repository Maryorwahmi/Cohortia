Module 8 › Chapter 8.6 › Generator Practicalities
Practical behaviors to remember
  • Generators yield values lazily and do not store them.
  • They are single-use; once exhausted, they produce no more values.
  • Consuming functions like list(), sum(), or loops exhaust generators.
  • Recreate or convert to a list if you need multiple passes.
Snippet
gen = (x for x in range(3))
for v in gen:
  print(v)
# generator exhausted
for v in gen:
  print(v)  # prints nothing
The second loop prints nothing because gen was exhausted by the first loop. Convert with list(gen) before the first loop if you need the values again.
Pro tip

If uncertain about reuse, materialize results explicitly or create a fresh generator each time to avoid surprises.
