Module 8 › Chapter 8.6 › Identity vs Equality
Definition & contrast
Equality checks value equivalence; identity checks same memory object. Interning can make identity appear true for some immutables, but it's not guaranteed.
  • [1,2] == [1,2] is True because values match.
  • [1,2] is [1,2] is False because two lists are separate objects.
  • Use is to check singletons like None: if x is None.
  • Avoid using is to compare integers or strings for content equality.
Example
x = [1, 2, 3] y = [1, 2, 3] z = x x == y # True x is y # False x is z # True
Misconception check

If two objects compare equal, they are not necessarily the same object. Rely on == for content checks.

Pro tip

On the exam, treat is as a test of identity or singletons only. When in doubt about values, use ==.
