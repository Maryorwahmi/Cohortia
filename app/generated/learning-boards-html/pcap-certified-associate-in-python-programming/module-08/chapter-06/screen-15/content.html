Module 8 › Chapter 8.6 › Key Concepts
What to Remember
Operator Precedence
Comparisons run before not/and/or; parentheses remove ambiguity.
Short-circuiting
and/or return operands; determine which operand is returned by truthiness rules.
Mutable Defaults
Avoid mutable literals as defaults; use None and allocate inside the function.
Keep these cards visible while practicing snippets to internalize the tracing method: annotate truthiness, note creation time, and identify binding time.
