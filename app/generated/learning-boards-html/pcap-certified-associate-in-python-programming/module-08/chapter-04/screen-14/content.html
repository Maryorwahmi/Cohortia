Module 08 › Chapter 8.4 › Practice Reminders
Mutate or not?
Identify whether the operation returns a new object or changes the existing one. This determines visible side effects.
Alias or copy?
Decide whether two names reference the same object or independent objects to predict cross-name effects.
Conversion safe?
Think before casting: will the input structure and values support the requested conversion or will it raise an error?
Final takeaway
Use quick checks to reason about code: mutation, aliasing, and conversion. These rules accelerate correct predictions and debugging.
