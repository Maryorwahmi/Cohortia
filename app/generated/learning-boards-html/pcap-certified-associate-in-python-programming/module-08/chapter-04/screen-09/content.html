Module 08 › Chapter 8.4 › Sequence Operations
Core behaviors
  • Indexing returns a single element; negative indices count from the end.
  • Slicing returns a new sequence of the same type; it does not mutate the source.
  • Concatenation and repetition create new sequence objects.
Shallow copy reminder
Slicing performs a shallow copy: nested mutable elements remain shared between the original and the slice.
Example walkthrough
letters = ['a', 'b', 'c', 'd']
slice1 = letters[1:3]   # ['b', 'c']
new = slice1 + ['x']     # ['b', 'c', 'x']
# letters unchanged unless mutated directly
Common exam task
Break multi-step expressions into steps: evaluate slices, then concatenation, then indexing. Track types after each step.
Key Takeaway

Slicing and concatenation produce new sequences. Only mutating methods change objects in place.
