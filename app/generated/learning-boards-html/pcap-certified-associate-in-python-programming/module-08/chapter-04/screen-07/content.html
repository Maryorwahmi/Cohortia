Module 08 › Chapter 8.4 › Immutable Types
Summary of operations
  • Integers and floats: arithmetic; int plus float becomes float.
  • Booleans: True and False used in comparisons and conditionals.
  • Strings: slicing, concatenation, repetition, and common methods like upper and split — each returns a new string.
  • Tuples: indexing and slicing work like lists but you cannot reassign elements.
Performance note
Repeatedly concatenating immutable strings creates many intermediate objects. For building large strings, collect pieces in a list and then join them into a final string for efficiency.
Code examples
# String rebinding example
s1 = "hello"
s2 = s1
s1 = s1 + " world"
# s2 remains "hello"

# Tuple with mutable item
t = (1, 2, [3, 4])
# t[2].append(5) will modify the list inside the tuple
Misconception
Believing that tuples are completely immutable. The container's references are fixed, but referenced mutable elements can change.
Key Takeaway

Immutable types are predictable and hashable. For performance, avoid naive repeated concatenation of strings.
