Module 08 › Chapter 8.4 › Mutable Types
Lists: common operations
  • append adds one element; extend adds multiple elements from an iterable.
  • insert places an element at an index; pop removes by index and returns the value.
  • sort and reverse mutate the list in place.
Dictionaries and sets
Dictionaries map immutable keys to values. Keys must be hashable. Sets are collections of unique elements supporting union, intersection, and difference operations.
Copying
Shallow copies duplicate only top-level references. For nested mutable objects, use deep copies when you need complete independence.
Concrete aliasing example
list1 = [1, 2, 3]
list2 = list1  # alias, not a copy
list2.append(4)
# Both names show [1, 2, 3, 4]

# Copy instead
list3 = list1[:]  # shallow copy
Common mistake
Using mutable objects as dictionary keys or set elements. Mutable types are not hashable and will raise an error if used as keys.
Key Takeaway

Mutating methods change the shared object. Create copies when you require separate state and use immutables as keys for mappings.
