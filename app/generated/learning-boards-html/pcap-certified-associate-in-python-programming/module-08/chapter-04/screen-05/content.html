Arithmetic & type promotion
  • Addition, subtraction, multiplication, true division, integer division, modulo, exponentiation.
  • When an int and a float participate in an arithmetic operation, the result is a float.
  • Integer division returns the floor of the quotient for numeric types; modulo returns the remainder.
Logical & comparison
Comparison operators produce True or False. Logical operators evaluate truthiness: empty sequences and zero are falsy; otherwise values are truthy. Remember short-circuit behavior for and and or.
Step-by-step examples
# True division vs integer division
result1 = 7 / 2    # true division, result1 is 3.5
result2 = 7 // 2   # integer division, result2 is 3
remainder = 7 % 2  # remainder, remainder is 1

# int + float -> float
val = 3 + 2.0      # val is 5.0 (float)
Common pitfall
Assuming integer division truncates toward zero for negatives. Python floors, so negative quotients round down.
Key Takeaway

Be precise: integer division floors, modulo yields remainder, and mixing numeric types promotes to float — these determine result types and subsequent operations.
