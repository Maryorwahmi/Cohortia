Snippet 1 — String immutability
s1 = "Python"
s2 = s1
s1 += " rocks"
print(s2)  # predict: Python
Explanation: s1 is rebound to a new string; s2 still references the original string.
Snippet 2 — List mutability
l1 = [10, 20]
l2 = l1
l1.append(30)
print(l2)  # predict: [10, 20, 30]
Explanation: l1 and l2 reference the same list object; append mutates it in place.
Snippet 3 — Tuple with mutable item
t = (1, 2, [3, 4])
# t[2].append(5)
print(t)  # predict: (1, 2, [3, 4, 5])
Explanation: The tuple's structure is immutable, but the list inside it is mutable and can be changed.
Snippet 4 — Dictionary get
d = {'a': 1, 'b': 2}
print(d.get('c', 0))  # predict: 0
print(d)             # predict: {'a':1, 'b':2}
Explanation: get returns the provided default when the key is missing and does not modify the mapping.
