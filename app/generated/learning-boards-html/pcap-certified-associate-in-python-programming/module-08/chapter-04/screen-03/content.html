Module 08 › Chapter 8.4 › Skill Checks
Practice tasks
  1. Predict the output of short snippets that test mutability and reassignment.
  2. Explain why changing one variable affected another when both reference the same object.
  3. Identify conversions that would raise an error and why.
  4. Demonstrate safe ways to make copies when needed.
Verification hints
Explain
Always justify why an object changed or did not change — reference mutability or assignment semantics.
Predict
Work through expressions mentally: consider types, operator rules, and potential type promotion to float.
Test
Run code after predicting to confirm and revise your model when you are wrong.
