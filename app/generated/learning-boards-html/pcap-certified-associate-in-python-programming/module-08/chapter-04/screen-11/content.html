Conversion reminders
  • int and float conversion succeed only for appropriate inputs; invalid inputs raise ValueError.
  • list of characters is what you get when converting a string to a list.
  • Constructing a dict from a sequence requires nested pairs of key and value.
Append vs extend
append adds a single element as-is; extend iterates over the argument and adds each element. Confusing them often leads to nested lists unintentionally.
Code examples
# append vs extend
lst = [1, 2]
lst.append([3, 4])  # [1, 2, [3, 4]]
lst = [1, 2]
lst.extend([3, 4])  # [1, 2, 3, 4]

Common exam trap
Predicting outputs without noting whether a method mutates the object or returns a new one. Always ask whether the method name suggests in-place change.
Key Takeaway

Check input compatibility before converting types. Use extend to add multiple elements, and avoid mutable keys in mappings.
