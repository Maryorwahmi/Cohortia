Module 08 › Chapter 8.4 › Key Concepts
Mutability
Lists, dicts, and sets can be changed in place. Mutations affect all references to the same object.
Immutability
Integers, floats, booleans, strings, and tuples cannot be altered after creation; operations return new objects.
Dynamic typing
Names are labels bound to objects at runtime. Track the current object when predicting behavior.
Summary
Use immutables for stable keys, copy mutable structures when needed, and always reason about mutability to predict program output correctly.
