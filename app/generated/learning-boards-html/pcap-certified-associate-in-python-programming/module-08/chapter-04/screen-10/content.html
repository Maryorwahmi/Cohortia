Module 08 › Chapter 8.4 › Dictionaries
Key properties
  • Unordered collection of key-value pairs; keys must be immutable and unique.
  • get returns a default instead of raising an error when the key is missing.
  • update merges mappings; pop removes entries and returns values.
Aliases and copying
Assigning a dictionary to another name creates an alias. Use the copy method for a shallow copy when you need a separate dictionary object.
Examples
d = {'a': 1, 'b': 2}
print(d.get('c', 0))  # prints 0

new = d
new['c'] = 3
# d shows the new key because new is an alias

copy_d = d.copy()  # shallow copy
Common pitfall
Using a mutable object as a key. This will raise an error because the key is not hashable.
Key Takeaway

Use dictionaries for fast key-based access; ensure keys are immutable and create copies when you need independent mappings.
