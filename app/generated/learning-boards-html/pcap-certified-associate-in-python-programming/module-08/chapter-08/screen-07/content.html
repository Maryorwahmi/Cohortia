Common Pitfalls
  • Not reading keywords like "NOT" or "final" carefully.
  • Mis-tracing code — skipping assignments or scope changes.
  • Panicking and dwell too long on a single question.
  • Overcomplicating straightforward prompts.
  • Forgetting to monitor remaining time.
Avoidance Strategies
Adopt a consistent triage: read the question slowly, trace execution, mark and guess if unsure, and re-evaluate flagged items at the end.
Concrete scenario
If a decorator question stalls you for three minutes, make an educated guess, flag it, continue, and return later. Use the break to rebuild confidence and avoid panic.
Key Takeaway

Develop triage rules you follow automatically: read, trace, guess, flag, and move on. Consistency beats last-minute adrenaline.
