Project Design
Project Options
Inventory Management: Product and Inventory classes, JSON persistence, CLI operations.
Personal Finance Tracker: Transaction and Account classes, datetime handling, CSV/JSON storage.
CSV Data Analyzer: loader module, DataAnalyzer class, numeric statistics and filtering.
All projects should include: input validation, exception handling, file persistence, and a short README describing design choices and how to run tests.
Starter Architecture
Suggested components: Data models (classes), Manager/Controller layer, Persistence module (json/csv), and CLI or simple demonstration script.

Key Takeaway

Design a clear, minimal architecture, implement core behaviors first, and add robust error handling and tests before extra features.
