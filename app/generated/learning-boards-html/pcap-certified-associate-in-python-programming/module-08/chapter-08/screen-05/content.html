Process Flow › Balanced Topic Checklist
Checklist Template
For each domain: 1) Explain the concept, 2) Write a minimal example, 3) List a common mistake to avoid.
Data Types & Operators
Explain mutability, show sample arithmetic and boolean operations, note type coercion pitfalls.
Functions & Modules
Define a function with default args, import a module correctly, note common import mistakes.
OOP
Explain __init__, inheritance, polymorphism; write a small class example and note common scope errors.
Concrete example
Under "exceptions and file I/O": 1) Explain try/except/else/finally, 2) Write a file-read with try/except and explicit close or context manager, 3) Note FileNotFoundError and encoding issues.
How to use during review
  1. Pick two domains per day and run through the three checks for each.
  2. Mark items you cannot do from memory and schedule focused practice.
  3. After a mock exam, map each mistake to a checklist item for targeted review.
Key Takeaway

A short explain→code→error checklist for each domain prevents gaps and guides targeted practice between mocks.
