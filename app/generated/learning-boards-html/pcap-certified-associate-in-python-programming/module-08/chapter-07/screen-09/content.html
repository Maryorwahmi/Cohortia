Module 08 › Chapter 8.7 › TypeError
Common patterns
  • Unsupported operand types (e.g., int + str).
  • Calling a non-callable object (e.g., my_int()).
  • Passing unexpected types into functions.
Misconception: not all conversion failures are TypeErrors; sometimes the argument is correct type but invalid value.
Example
my_int = 5
print(my_int())  # TypeError: 'int' object is not callable
Prediction: TypeError at the print line. Fix by removing parentheses or ensuring my_int is a function.
Pro tip
When a TypeError appears, mentally check operand types and whether the object should be callable.
