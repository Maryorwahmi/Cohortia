Module 08 › Chapter 8.7 › Mental Debugging
What it is

A structured way to simulate the interpreter: assign values, evaluate expressions, and follow control flow without executing code.

Steps to practice
  • Read the snippet and set initial variable states.
  • Follow each line in order, updating variable values mentally.
  • When a function is called, expand its body and simulate returns.
  • Predict the final output or the exact exception and line number.
Concrete example
def avg(nums):
  total = 0
  for n in nums:
    total += n
  return total / len(nums)

print(avg([]))  # empty list case
Mentally: len is 0, division by zero will occur on return, producing a ZeroDivisionError. That prediction saves time on the exam.
Key Takeaway

Practice mental runs with edge cases. Predict output or exact exception and the line it originates from.
