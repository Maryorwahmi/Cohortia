Traceback as roadmap
Read bottom-up for error type, raising line, and call stack context.
Mental debugging
Simulate execution, track values, inline function calls, and predict exceptions.
Error-type mapping
Quickly map messages to NameError, TypeError, AttributeError, IndexError, KeyError, ValueError, SyntaxError.
Bottom summary: Read the message, identify the raising line, run a mental simulation, and give a minimal fix. That concise approach is the fastest way to correct answers on the PCAP exam.
