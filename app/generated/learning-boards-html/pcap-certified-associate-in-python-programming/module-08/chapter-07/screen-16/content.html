Traceback rule
Last line: error type. Line above: raising line. Above that: call chain context.
Answer format
State error type, line number, cause, and a minimal fix.
Practice tip
Use short snippets and timed drills to make mental debugging fluent.
Final takeaway
A consistent, bottom-up traceback read and a short mental-simulation checklist are your fastest path to correct, explainable answers on exam items.
