Module 08 › Chapter 8.7 › Common Errors
SyntaxError
Invalid grammar; caught before execution. Fix the missing colon, bracket, or keyword misuse.
NameError
Undefined identifier. Check spelling and scope, or missing import.
TypeError
Operation not supported for this type. Example: adding string and int or calling a non-callable.
AttributeError
Missing attribute on an object. Often a wrong-type or typo in attribute name.
IndexError
Sequence index out of range. Remember zero-based indexing and len(list)-1 is last valid index.
KeyError / ValueError
KeyError: missing dict key. ValueError: wrong value for an otherwise correct type (e.g., int('x')).
Misconception check
Don't assume a ValueError is a TypeError in disguise. Ask: was the operation allowed for this type but the value invalid, or is the operation incompatible with the type itself?
