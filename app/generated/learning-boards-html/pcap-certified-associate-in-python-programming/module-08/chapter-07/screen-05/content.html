Module 08 › Chapter 8.7 › Reading Tracebacks
Bottom-up checklist
  1. Identify the error type and message from the last line.
  2. Locate the file and line where the error was raised.
  3. Read the call stack above to see how execution arrived at that line.
  4. Formulate a hypothesis for the root cause and a minimal fix.
Common misconception
Don't fix only the symptom you see at the raising line without checking the caller chain. Often the wrong input originated elsewhere.
Example traceback (mental exercise)
Traceback (most recent call last):
  File "exam.py", line 12, in 
    process()
  File "exam.py", line 8, in process
    print(items[3])
IndexError: list index out of range
Bottom-up: IndexError on line 8 at print(items[3]). Check how items was created or passed in earlier calls. The call stack shows process called by main code on line 12.
Pro tip

Always record the error type and exact line number first. It focuses your hypothesis testing.
