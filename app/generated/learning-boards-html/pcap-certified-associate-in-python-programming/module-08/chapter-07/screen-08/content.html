Module 08 › Chapter 8.7 › NameError
Typical causes
  • Typos in variable or parameter names.
  • Using a variable before it is assigned.
  • Missing import statements for modules.
Misconception: assuming NameError is a runtime type problem — it is a missing identifier issue.
Concrete example
def calculate_average(numbers):
    total = 0
    for num in number:  # Typo: should be 'numbers'
        total += num
    return total / len(numbers)
Prediction: NameError on the loop line because 'number' is undefined. Minimal fix: change 'number' to 'numbers'.
Check
Always verify that each identifier is declared, spelled correctly, and in scope before concluding a type-related diagnosis.
