Module 08 › Chapter 8.7 › IndexError vs KeyError
IndexError (Sequence)
data_list = [10, 20, 30]
print(data_list[3])  # IndexError: list index out of range
Fix by adjusting range or checking length before access.
KeyError (Mapping)
my_dict = {"a":1, "b":2}
print(my_dict["c"])  # KeyError: 'c'
Fix by testing membership, using get, or providing a default key.
Key Takeaway

Identify container type first, then apply the appropriate guard: index bounds for sequences, membership checks for mappings.
