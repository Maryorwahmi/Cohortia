Module 08 › Chapter 8.7 › Common Pitfalls
Scope & shadowing
Annotate whether a name refers to a local, global, or nonlocal binding. Shadowed variables cause surprising values.
Mutable defaults
Default lists or dicts persist across calls. On the exam, suspect persistent state when multiple calls are shown to mutate a default.
Operator pitfalls
Use '==' to compare values. 'is' checks identity and often misleads in equality checks for small integers or strings.
Off-by-one errors
Check inclusive/exclusive ranges and remember len(seq)-1 is the last valid index.
Check your understanding
When you see unexpected shared state, ask whether a mutable default or aliasing is the cause before assuming a logic bug elsewhere.
