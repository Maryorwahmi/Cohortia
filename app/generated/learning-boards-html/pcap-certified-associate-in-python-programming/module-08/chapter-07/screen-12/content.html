Module 08 › Chapter 8.7 › Debugging Checklist
Seven-step routine
  1. Read the snippet end-to-end to understand intent.
  2. Set initial values for variables and parameters.
  3. Simulate each line, updating values and noting side effects.
  4. Inline and simulate function calls with given arguments.
  5. Check scope and shadowing issues.
  6. Predict exception type and exact line if any.
  7. Propose a minimal fix and justify it briefly.
Quick scenario
Given a function that sums item.value, check the class initialisation. If the class sets self.val not self.value, you'll predict an AttributeError during the first loop iteration. Minimal fix: align attribute names between class and consumer code.
Key Takeaway
A short, repeated checklist reduces guessing and yields precise error predictions and repair actions.
