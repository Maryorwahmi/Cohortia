Error patterns

Frequent exam pitfalls

  • Misreading constraints: Noting whether a question asks for two options or all correct options changes strategy.
  • Assumption errors: Expecting in-place modification or type coercion without verifying code behavior.
  • Rushed simulation: Failing to mentally run the code with simple values before answering.
