Process

How to use the pre-exam minutes

Treat tutorial and NDA time as a structured warm-up: verify controls, rehearse navigation, and calm your focus before the clock starts.

1
Confirm interface elements
Locate flag, navigation, and code-editing areas so clicks become second nature.
2
Practice pacing
Time a practice item to set realistic per-question targets before the main timer runs.
3
Calm and prepare
Use the NDA minutes to settle, adjust lighting, and confirm a distraction-free space.
Key Takeaway

Rehearse controls and pacing in tutorial time. That practice saves cognitive energy for answering once the clock is running.

Quick Checklist
  • Locate the navigation and flag controls.
  • Time a practice question to calibrate pace.
  • Confirm how multiple-select and code completion look.
Practice this flow in every full-length mock to make it habitual.
