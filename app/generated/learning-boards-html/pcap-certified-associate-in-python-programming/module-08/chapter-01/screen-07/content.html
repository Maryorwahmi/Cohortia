Core Concept

What the exam tests

Practice these skills with short coding tasks and small debugging exercises.

  • Data types & operations: lists, tuples, sets, dictionaries, and their common methods.
  • Control flow: conditionals and loops, including nested structures and loop termination.
  • Functions: definition, arguments, return values, and variable scope.
  • Exceptions & File I/O: basic try/except and reading/writing text files.
Object-oriented topics
Classes, instances, inheritance, and simple polymorphism appear in syllabus items that check your understanding of design and runtime behavior.
Concrete example
A question may show a base class and a derived class and ask which method is called when an instance of the derived class invokes that method — testing inheritance and method resolution.
Common error
Overemphasizing libraries not listed in the syllabus. The exam rewards solid foundations, not library-specific knowledge beyond the standard library scope.
Study task
Create short code snippets that demonstrate a single concept — e.g., a function showing scope rules — and explain the output aloud or in writing.
