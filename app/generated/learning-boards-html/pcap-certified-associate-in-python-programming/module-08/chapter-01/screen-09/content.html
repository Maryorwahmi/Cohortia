Module 08 › Chapter 08.1 › Scoring Mechanism
Definition

How points are awarded

The exam assigns a point value per item; question formats determine whether partial credit applies. Understanding this prevents wasted time on low-return items.

Common rule

Each correct answer contributes to the total score. Multiple-select may require exact selections to count.

Misconception

Assuming partial credit always applies. Read the question wording closely to avoid this trap.

Pro tip

When unsure, eliminate impossible choices first. This raises odds on multiple-select and saves time.

Key Takeaway

Focus effort where each question yields the greatest score impact; verify how multi-part items are scored before assuming partial credit.

Example

Scoring scenario

Imagine 40 items total. If the pass threshold is 70%, you must correctly earn the equivalent of 28 full-item points. Missing several high-weight topics makes reaching that number harder than missing low-weight items.

Decision rule
If a question costs equal points, skip and return when stuck. Preserve time for solvable items.
Misread alert
Watch for wording like "select two" or "choose all that apply" — these change how scoring works.
