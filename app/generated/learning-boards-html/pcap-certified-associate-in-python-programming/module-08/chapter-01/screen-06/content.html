Definition

What the syllabus tells you

The official blueprint names the topics and often indicates how much each contributes to the final score — this directs study priorities.

Example weights
For instance: Control flow and data structures might account for 25% of questions, and object-oriented programming might account for 20%. Use those as planning anchors.
Action: map to hours
If you study 10 hours per week, assign roughly 2.5 hours to a 25% topic and 2 hours to a 20% topic, adjusting for current confidence.
Misconception
Do not study by curiosity alone. High-impact topics deserve proportionally more practice even if they are less interesting.
Topic cards
Control Flow & Data Structures
Example weight: 25%
Practice loop tracing, conditionals, lists, tuples, sets, and dictionaries.
Object-Oriented Programming
Example weight: 20%
Practice classes, instances, inheritance, and method resolution scenarios.
Functions & Scope
Practice topics
Argument passing, default values, and local vs. global scope.
Modules, File I/O, Exceptions
Include practical code examples and small debugging tasks in study sets.
Takeaway
The syllabus is a measurement tool. Use its weights to shape your study calendar and mock exam composition.
