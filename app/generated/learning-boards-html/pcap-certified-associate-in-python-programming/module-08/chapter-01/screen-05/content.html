Module 8 › Chapter 8.1 › Question Types
Process Flow

Classify → Triage → Answer

Apply a simple flow to handle different question types consistently under time pressure.

  1. Classify: identify whether it is multiple-choice, drag-and-drop, or code completion.
  2. Triage: decide if it is quick, medium, or time-consuming and mark accordingly.
  3. Answer: use a format-specific tactic (eliminate/test/order/trace), then move on.
Example scenario
A code-completion item asks for a missing line that changes loop termination. Trace the loop with a simple input and predict the output before inserting the line.
Common pitfall
Spending too long on one tricky item instead of answering easier ones first and returning later.
Format tips
Multiple-choice
Eliminate impossible answers; confirm each chosen option meets the full stem.
Drag-and-drop
Identify logical order and grouping before placing fragments; watch for scope clues.
Code completion
Trace execution with small inputs and fill missing lines that restore the intended output.
Key takeaway
Practice classification first. The right tactic reduces wasted time and improves accuracy under the clock.
