Module 08 › Chapter 08.1 › Syllabus Mapping
Activity steps
  1. List each major syllabus topic and sub-topics.
  2. Rate your confidence 1–5 and note specific weak sub-topics.
  3. Create a short practice task for each low-rated area and add 3 mock questions to test progress.
  4. Re-rate after practice and repeat the cycle until scores stabilize.
Example entry
Topic: Functions. Sub-topic: Argument passing and scope. Confidence: 2. Task: Write 3 short functions showing local vs global scope, then answer 3 mock items on scope rules.
Key Takeaway

Turn each weakness into a named, time-boxed practice task and verify improvement with targeted mock questions.
