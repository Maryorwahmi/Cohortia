Module 8 › Chapter 8.1 › Practice Strategy
Process Flow

Map → Mock → Review

A simple weekly loop that turns syllabus weightings into practice actions and measurable feedback.

  1. Map: convert syllabus percentages into weekly hours.
  2. Mock: run a 65-minute practice exam under timed conditions.
  3. Review: create micro-tasks from errors and practice those specifically.
Daily checklist
A timed mini-drill, one targeted exercise on a weak topic, and a 10-minute review of yesterday's mistakes.
Implementation cards
Timed mock routine
Simulate the exam end-to-end, record per-question time and correctness, then tag the most frequent error types.
Error-driven micro-tasks
For each recurring mistake, make a focused 15–30 minute exercise that isolates the underlying concept.
Progress metric
Track average time per question and percent correct per topic. Use these numbers to reallocate hours each week.
Why it works
Syllabus alignment and iterative feedback make each practice hour more effective than unfocused study.
