Module 08 › Chapter 8.2 › Flashcard Activity
Activity Steps
Create at least 10 focused cards and commit to daily reviews.
1. Pick 10 low-confidence syllabus items.
2. Make single-concept cards with code or direct questions.
3. Review daily and rate recall honestly so scheduling adapts.
Example Card
Front: short code asking for output. Back: exact output and a one-line explanation of the behavior, e.g., mutable default argument explanation.
Check
After one week, remove ambiguous cards or split them into smaller prompts for clarity.
