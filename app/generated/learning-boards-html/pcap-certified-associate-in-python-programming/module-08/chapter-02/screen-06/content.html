Spaced Schedule
Schedule reviews at gradually increasing intervals to cement memory.
Day 0: Learn + initial recall
Day 1: Quick review
Day 3: Deeper review
Day 7+: Longer-term checks
Card Design Rules
  • One idea per card so recall is unambiguous.
  • Use a small code snippet or direct question on the front and the expected output or concise explanation on the back.
  • Rate your recall honestly so the scheduler adapts correctly.
Example
Front: short code asking 'What is the output?'. Back: output and brief explanation for why.
