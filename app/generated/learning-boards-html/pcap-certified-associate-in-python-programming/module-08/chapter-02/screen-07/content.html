Walkthrough: Mutable Default Argument
Observe, explain, and fix a common Python behavior.
def foo(a, b=[]):
  b.append(a)
  print(b)

foo(1)
foo(2)
foo(3, [10])
foo(4)
Explanation
  • The default list is created once at definition time.
  • Calls without b reuse the same list, causing accumulation.
  • Passing an explicit list bypasses the default shared object.
Fix Pattern
Use None as the default and create a fresh list inside the function to avoid shared state.
