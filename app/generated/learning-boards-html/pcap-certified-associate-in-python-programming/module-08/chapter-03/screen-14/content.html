Quick exam checklist
Memorable rules to use during the test.
Two-pass rule
Answer quick questions first and mark harder ones for the second pass.
Trace variables
Write or note variable states to avoid hidden state errors.
Eliminate distractors
Discard clear wrong answers first, then compare remaining choices.
Micro-resets
Breathe, re-read, and break down stalled questions to regain clarity.
Final tip
Practice these behaviors under timed drills so they become automatic during the PCAP exam.
