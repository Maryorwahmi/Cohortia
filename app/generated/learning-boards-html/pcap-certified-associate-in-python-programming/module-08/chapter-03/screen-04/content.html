Two-Pass Routine
A disciplined order to protect points and manage time.
Step 1 — First pass
Answer all questions you know immediately. Mark the ones needing deeper analysis. Don't linger.
Step 2 — Prioritize
On the second pass, sort marked questions by estimated solve time and by how many points you can gain.
Step 3 — Guess when stuck
If a question exceeds your planned time, make an educated guess and move on. There is no penalty for guessing.
Key Takeaway

Protect easy points on the first pass, use the second pass for prioritized deeper work, and guess when the clock demands it.

Common mistake
