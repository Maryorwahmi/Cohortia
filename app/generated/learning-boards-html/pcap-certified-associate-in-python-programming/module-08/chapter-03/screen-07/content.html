Elimination workflow
Turn distractors into easy rejects with a short checklist.
Checklist for elimination
  1. Read the question and note exact requirements.
  2. Discard options that contradict facts or the question's wording.
  3. Compare remaining options for completeness.
  4. Treat each option independently for select-all items.
Pairwise comparison
If two options look plausible, ask which one better satisfies every part of the question. Prefer completeness and correctness over partial matches.
Example thought bubble
Question keyword check
If the question asks about mutability, eliminate options that ignore in-place changes or scope behavior.
Common mistake
Choosing the first plausible option without reading all choices. Always scan fully before committing.
Key Takeaway

Eliminate clearly wrong options rapidly, then compare remaining choices for completeness and precision.
