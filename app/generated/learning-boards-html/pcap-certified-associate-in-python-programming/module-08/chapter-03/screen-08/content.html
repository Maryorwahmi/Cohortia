Activity: 2-minute trace
Simulate exam pressure and verify by running the code after your prediction.
Instructions
  1. Set a 2-minute timer.
  2. Read the snippet once to understand intent.
  3. Trace line-by-line, record states, predict output.
  4. Run the code to compare and analyze differences.
Reflection prompts
How did you manage time? Which step caused the mismatch? What edge case surprised you?
Key Takeaway

Short, timed tracing drills with immediate verification are the fastest path to reliable exam predictions.

Activity snippet
def process_data(data):
  result = {}
  for item in data:
    if isinstance(item, int):
      if item % 2 == 0:
        result.setdefault('even', []).append(item)
      else:
        result.setdefault('odd', []).append(item)
    elif isinstance(item, str):
      if len(item) > 3:
        result.setdefault('long_strings', []).append(item.upper())
      else:
        result.setdefault('short_strings', []).append(item.lower())
    else:
      result.setdefault('other', []).append(str(item))
  return result

my_list = [1, "apple", 4, "banana", 7, 10.5, "cat", "dog"]
output = process_data(my_list)
print(output)
Tip: when tracing, write the dictionary state after each iteration. That immediately exposes where types diverge or where mutability matters.
