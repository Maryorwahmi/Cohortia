Practice and verify
Concrete drills to confirm each objective under timed conditions.
01 — Two-pass timing
Run a timed set, record first-pass coverage and count of marked items. Aim to answer all quick questions and leave no easy points behind.
02 — Trace verification
Trace code mentally or on scratch paper, then run the code to confirm. Note discrepancies and refine your tracing habit.

Small measurable goals show progress: percent correct, time per question, and guess frequency.
