Module 8 › Chapter 8.3 › Frequent Errors and How to Avoid Them
Common pitfalls
A short checklist to catch recurring mistakes.
Pitfall — Not reading all choices
Always scan every option before selecting; a later choice may be more complete.
Pitfall — Ignoring mutability
Watch for methods that modify objects in place; they change the state you must predict.
Pitfall — Miscounting loops
Write out a quick iteration table when loop logic is central to the output.
Corrective habits
Habit — Quick state notes
Record variable values for critical steps to avoid mental drift.
Habit — Soft time caps
Set a maximum time per marked question and move on if exceeded, returning later if time allows.
Key Takeaway

Turn common errors into short, repeatable corrective habits you use automatically during timed practice and the exam.
