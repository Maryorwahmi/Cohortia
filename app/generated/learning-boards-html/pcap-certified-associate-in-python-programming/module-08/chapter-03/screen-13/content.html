Module 8 › Chapter 8.3 › Key Concepts
Two-Pass Method
Answer quick items first, mark and return to harder problems so easy points are secured under time pressure.
Code Tracing
Follow execution, log variable states, and consider edge cases to predict outputs with confidence.
Elimination Strategy
Remove impossible options first, compare remaining choices, and treat each select-all option independently.
Takeaway
Integrate timing, tracing, and elimination into practice until they operate automatically under exam pressure.
