Process Flow › Logical Operators

Operator Behavior

and
Evaluates left to right, returns first falsy operand or last operand if all truthy. Short-circuits on falsy.
or
Evaluates left to right, returns first truthy operand or last operand if none are truthy. Short-circuits on truthy.
not
Negates the truthiness of the operand; always returns a boolean value.

Code Examples & Notes

a = ''
b = 'fallback'
print(a or b)    # 'fallback' because a is falsy

user = None
if user and user.active:
    print('Active')  # safe: second part not evaluated when user is None

# Beware: using or to set defaults treats 0 and '' as falsy
count = 0
default = 10
print(count or default)  # prints 10, but 0 may be a meaningful value
Misconception
and/or always return booleans — false. They return the operand that determined the result.
Pro tip
When zero or empty strings are valid, prefer explicit checks like if value is None or if value == 0.
