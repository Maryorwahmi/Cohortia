How to use loop else

The else block on a loop runs only if the loop completes without a break. Use it for search patterns and when you want post-loop behavior only on normal completion.

Pattern
  • Search items in iterable
  • break when found
  • else: run when none matched
Common mistake

Confusing loop else with an inner if else. Remember: else belongs to the loop, not the if inside it.

Concrete Example

def find_and_report(seq, target):
    for item in seq:
        if item == target:
            print('Found!')
            break
    else:
        # runs only if loop did not break
        print('Not found.')

find_and_report([1,2,3], 2)  # Found!
find_and_report([1,2,3], 9)  # Not found.
Key Takeaway

Loop else expresses 'no match' clearly; use break to signal success and else to handle failure.
