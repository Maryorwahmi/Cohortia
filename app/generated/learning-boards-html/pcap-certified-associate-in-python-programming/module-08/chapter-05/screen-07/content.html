Parameters & Calling

Positional parameters match by order. Keyword parameters match by name. Defaults make parameters optional but are evaluated once at definition.

Mutable default trap
Using a list or dict as a default shares it across calls, causing accumulated state unless you reinitialize inside the function.
Common mistake

def f(a, b=[]): ... — this b is the same list for every call. Use None sentinel instead.

Code Example

def append_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst

print(append_item(1))  # [1]
print(append_item(2))  # [2]  -- fresh list each call
Key Takeaway

Avoid mutable defaults; initialize inside the function using None as a sentinel.
