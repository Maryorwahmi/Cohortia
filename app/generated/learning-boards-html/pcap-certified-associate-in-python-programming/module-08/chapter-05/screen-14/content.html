What to remember

A compact set of concepts to keep at hand while coding and studying.

LEGB Rule
Local, Enclosing, Global, Built-in order explains name resolution. Use nonlocal/global only when you deliberately modify outer bindings.
Argument Passing
Positional, keyword, default, *args, **kwargs. Avoid mutable defaults and prefer explicit signatures for clarity.
Exception Handling
Use try/except for anticipated errors, else for success flows, and finally for cleanup. Catch specific exceptions.
Summary Takeaway

Combining clear scope rules, explicit argument patterns, and precise error handling yields code that is reliable and exam-ready.
