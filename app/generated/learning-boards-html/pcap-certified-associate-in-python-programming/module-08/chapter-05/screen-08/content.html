Code Walkthrough › *args & **kwargs

What they do

*args collects extra positional args into a tuple. **kwargs collects extra keyword args into a dict. Both enable flexible function calls and argument forwarding.

Best practices
  • Document expected keys for **kwargs.
  • Convert *args to list if you need to mutate.
  • Prefer explicit parameters for required data.

Example & Output

def summarize_info(name, age, *grades, **details):
    print(f"Name: {name}, Age: {age}")
    print(f"Grades: {grades}")
    for key, value in details.items():
        print(f"{key.replace('_', ' ').title()}: {value}")

summarize_info("Alice", 25, 90, 85, 92, city="New York", occupation="Engineer")

# Expected output:
# Name: Alice, Age: 25
# Grades: (90, 85, 92)
# City: New York
# Occupation: Engineer
Misconception
Thinking **kwargs will reject unexpected keys — it accepts them; you must validate inside the function.
Key Takeaway

*args/**kwargs increase flexibility but require documentation and validation to keep APIs clear and robust.
