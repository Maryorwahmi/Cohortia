LEGB: Where Python Looks for Names

Predictability in name resolution prevents subtle bugs. We'll inspect patterns and deliberate keywords for modification.

Concept Map
Local → Enclosing → Global → Built-in
Use nonlocal to reach an enclosing function binding. Use global to affect module-level variables intentionally. Prefer returns over global mutation when possible.
Annotated Example
x = 10

def outer():
  x = 20
  def inner():
    nonlocal x
    x = 30
  inner()
  print('outer x ->', x)

outer()
print('global x ->', x)
Prediction: inner() modifies the enclosing x via nonlocal; the global x remains unchanged. This pattern demonstrates the enclosing frame in LEGB.
Common Mistake
Assigning to a name inside a function without global creates a new local variable, not a modification of a global binding. This often hides bugs.
Pro Tip
Prefer returning a value and reassigning at the caller instead of using global state. It improves testability and clarity.
Key Takeaway

LEGB determines name resolution. Use nonlocal to access enclosing scopes and global only when necessary; otherwise return values.
