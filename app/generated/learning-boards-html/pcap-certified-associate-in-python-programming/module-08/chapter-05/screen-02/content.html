Learning Objectives

Each objective explains the skill and why it matters in practice and on the exam.

Bloom: Learn → Understand → Apply → Master
01
Conditional Statements
Write precise if, elif, else logic using Python truthiness. This reduces errors and makes intent explicit in tests and guard clauses.
Mnemonic: "Truthy means non-empty or non-zero"
VERIFIED COMPETENCY MILESTONE
02
Loops & Control
Use for and while loops with break, continue, and else to express search and iteration patterns clearly and avoid off-by-one errors.
Mnemonic: "Else after loop means 'no breaks'"
VERIFIED COMPETENCY MILESTONE
03
Function Arguments
Define and call functions with positional, keyword, defaults, *args and **kwargs so your interfaces handle many use cases gracefully.
Mnemonic: "Order: positional, *args, defaults, **kwargs when calling"
VERIFIED COMPETENCY MILESTONE
04
Scope & Exceptions
Understand LEGB for variable lookup and use try/except/else/finally for robust error handling and resource cleanup.
Mnemonic: "LEGB — look here in order"
VERIFIED COMPETENCY MILESTONE
