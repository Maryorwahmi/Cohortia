Core Concept › Conditionals & Truthiness

Definition & Characteristics

Values considered falsy: empty sequences, 0, 0.0, None, and False. Everything else is truthy. Short-circuiting saves work and prevents errors.

Common patterns
  • if my_list: # True only when list non-empty
  • if data and data.get('key'): # safe chained check
  • if user_input is not None: # explicit when 0 or empty string are valid
Common mistake

Treating 0 as a missing value. If zero is a valid result, test explicitly with is None or compare to 0 rather than relying on truthiness.

Key Takeaway

Truthiness makes conditionals concise; be explicit when empty or zero are meaningful values.

Concrete Example

def first_element_is_five(seq):
    # Safe: short-circuits if seq is empty
    if seq and seq[0] == 5:
        return True
    return False

print(first_element_is_five([]))  # False
print(first_element_is_five([5, 2]))  # True
Why it matters
Short-circuiting avoids index errors and communicates intent clearly in guard clauses.
