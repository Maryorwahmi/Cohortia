Robust CSV reader
import csv

def read_grades_from_csv(filepath):
  students = []
  try:
    with open(filepath, 'r', newline='') as csvfile:
      reader = csv.reader(csvfile)
      header = next(reader)
      if header != ['Name', 'Assignment1', 'Assignment2', 'Assignment3']:
        print('Warning: CSV header does not match expected format.')
      for line_num, row in enumerate(reader, start=2):
        try:
          name = row[0]
          scores = [int(score) for score in row[1:]]
          students.append(Student(name, scores))
        except (ValueError, IndexError) as e:
          print(f"Skipping malformed row {line_num}: {row} - Error: {e}")
  except FileNotFoundError:
    print(f"Error: The file '{filepath}' was not found.")
    return None
  return students
Key points: use newline='' for csv, validate header, catch conversion errors per row, and report line numbers for quick fixes.
Example Scenario
Given a row with 'invalid' score, the function logs the line and continues. Valid rows become Student objects for reporting.
Debugging Tip
Include file name and line number when printing parse errors. That makes correcting source data fast.
Key Takeaway

Treat input as untrusted. Validate each row and handle errors locally so the program can continue processing valid data.
