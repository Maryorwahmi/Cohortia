Module 2 › Chapter 2.3 › Shallow vs Deep Copy
Code example
original = [1, 2, [3, 4]]
alias = original             # alias, same object
shallow = original[:]        # shallow copy
import copy
deep = copy.deepcopy(original)  # deep copy

alias[0] = 99
alias[2][0] = 88
print(original)  # shows nested change
print(shallow)   # top-level differs at index 0, nested changed
print(deep)      # deep remains unchanged
Practical rule
Use shallow copy for top-level separation and deep copy for nested independence.
Common pitfall
Expecting slicing to isolate nested objects; remember slicing copies references to nested mutables.
Key Takeaway

When nested mutable objects are present, prefer deep copies to prevent unexpected shared-state bugs; otherwise, slicing is a lightweight shallow copy.
