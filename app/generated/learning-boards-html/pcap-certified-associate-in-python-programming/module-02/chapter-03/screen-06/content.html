Module 2 › Chapter 2.3 › Adding & Extending
Step-by-step examples
students = ['Alice', 'Bob']
students.append('David')         # ['Alice','Bob','David']
students.insert(1, 'Eve')       # ['Alice','Eve','Bob','David']
students.extend(['Frank','Grace'])
# ['Alice','Eve','Bob','David','Frank','Grace']
students.append(['x','y'])      # creates nested list at end
Pro tip
If you want to add items from another list as separate elements, use extend, not append.

Key Takeaway

Choose append, insert, or extend based on whether you need to add a single item, place it at an index, or merge multiple items into the existing list.
