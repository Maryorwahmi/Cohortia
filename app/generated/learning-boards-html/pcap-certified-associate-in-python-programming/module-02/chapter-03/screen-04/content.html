Module 2 › Chapter 2.3 › What is a Python list?
Definition & Properties
Ordered, mutable, allows duplicates, and elements can be of mixed types.
Concrete example
fruits = ['apple', 'banana', 'cherry']
print(fruits[0])   # 'apple'
print(fruits[-1])  # 'cherry'
fruits[1] = 'blueberry'  # mutate in place
Why it matters
Lists let you collect and change sequences without reconstructing the whole container.
Misconception
Lists enforce type homogeneity — they do not. Heterogeneous lists can break operations expecting uniform types.
Key Takeaway

Lists are flexible and mutable sequences; use them when you need ordered, changeable collections but be mindful of type expectations and shared references.

Related concept: tuple contrast
Tuples are ordered but immutable. Choose tuples for fixed records and lists for changeable sequences.
Quick comparison
List
Mutable, supports methods like append and pop.
Tuple
Immutable, used for fixed collections and dictionary keys when needed.
