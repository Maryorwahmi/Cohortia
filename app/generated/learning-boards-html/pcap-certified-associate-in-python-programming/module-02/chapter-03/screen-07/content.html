Module 2 › Chapter 2.3 › Removing & Modifying
Examples
data = [10, 20, 30, 40]
del data[1]            # [10,30,40]
removed = data.pop()    # removes last, removed == 40
data.remove(10)         # removes first occurrence of 10
data.clear()            # []
# Removing while iterating: avoid modifying the same list during iteration
Pitfall
Removing inside a loop can skip items because the list shrinks and indices change.
Scenario & Fix
To remove all odd numbers from a list safely, either iterate over a copy or build a new list using a comprehension that filters evens.
# Safe approach
nums = [1,2,3,4,5]
nums = [n for n in nums if n % 2 == 0]  # [2,4]
Key Takeaway

Choose deletion method by whether you know the index or value, and avoid in-place removals while iterating unless you are iterating over a copy.
