Learn when methods modify the list and when they return a new list, so you do not assign None by mistake. Mnemonic: in-place methods change the original plate.

Use count and index to inspect lists. Check membership to avoid exceptions with remove or when accessing indices.

07 — Shallow vs deep copy
Create independent copies using slicing or list constructor for top-level copies and use a deep copy for nested mutable elements.

08 — Safe iteration & mutation
Avoid modifying a list while iterating over it; iterate over a copy or build a new list using comprehension.
