Inventory script
inventory = {
  "apples": 50,
  "bananas": 100,
  "oranges": 75,
  "grapes": 20
}

print("--- Current Inventory ---")
for item, quantity in inventory.items():
    print(f"{item.capitalize()}: {quantity}")

# Simulate a sale
item_sold = "apples"
quantity_sold = 10
if item_sold in inventory:
    if inventory[item_sold] >= quantity_sold:
        inventory[item_sold] -= quantity_sold
        print(f"
Sold {quantity_sold} {item_sold}.")
    else:
        print(f"
Not enough {item_sold} in stock. Only {inventory[item_sold]} available.")
else:
    print(f"
{item_sold} not found in inventory.")

# Add a new item
inventory["mangoes"] = 30

# Low stock check
for item, qty in inventory.items():
    if qty < 30:
        print(f"Warning: {item.capitalize()} stock is low ({qty})")

# Total items
total_items = sum(inventory.values())
print(f"
Total items in stock: {total_items}")
Lessons from the example
  • Check membership before subtraction to avoid KeyError or negative counts.
  • Use assignment to add new items and iteration to find low stock.
  • sum(inventory.values()) quickly aggregates numeric values.
Key Takeaway

Dictionaries model mutable state well. Validate values before mutating to maintain correct application state.
