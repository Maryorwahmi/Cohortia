Module 3 › Chapter 2.5 › Comparison: collections
Dictionary

Named access by key, mutable, ideal for lookups and modeling records.

List / Tuple

Ordered sequence. Use lists for changeable sequences, tuples for fixed collections.

Set

Unordered collection of unique items. Great for membership checks and deduplication.

Practical guidance
  • If you frequently lookup by name or ID, use a dictionary.
  • If you maintain a sorted sequence, use a list and sort when needed.
  • For fast membership without values, use a set.
Key Takeaway

Match the collection type to access patterns. Dictionaries are unmatched for name-to-value maps and fast lookups.
