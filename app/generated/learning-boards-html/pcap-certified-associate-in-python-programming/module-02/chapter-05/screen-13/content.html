Common errors
  • KeyError: raised on missing key with direct indexing or del.
  • TypeError: unhashable key like a list cannot be used as a key.
Safe alternatives

Use get(default), pop(default), membership checks or try-except depending on whether missing data is exceptional or expected.

Example: safe retrieval
# Safe get with default
value = my_dict.get("maybe_key", "default")

# Safe pop with default
removed = my_dict.pop("maybe_key", None)
Pitfall to avoid

Catching KeyError broadly can mask bugs. Choose explicit handling when possible and log unexpected missing keys for diagnostics.

Key Takeaway

Design access patterns for your data's reliability: use safe lookups for user data and strict indexing when absence indicates an error you want to detect early.
