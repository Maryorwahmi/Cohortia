Module 3 › Chapter 2.5 › What is a dictionary?
Definition

A mapping from unique, immutable keys to values. Mutable collection and fast for lookups by key.

Key rules
  • Keys must be hashable: strings, numbers, tuples allowed.
  • Values accept any type and can be duplicated.
  • Mutable: you can add, change, or delete entries.
Common misconception

Do not treat dictionaries as ordered lists. Even though insertion order is preserved in recent Python versions, avoid relying on it for logic that requires explicit ordering.

Key Takeaway

Pick keys that uniquely and immutably identify values. That design choice makes lookups simple and fast.

Concrete example
# Map usernames to profiles
profiles = {
  "alice": {"age": 30, "city": "NY"},
  "bob": {"age": 25, "city": "SF"}
}
# Tuple key example (allowed)
coords_map = { (10, 20): "landmark" }
Why this matters

Choosing an appropriate key transforms many problems into constant-time lookups. For example, use user IDs or SKUs rather than searching through lists for a match.

Misuse example

Attempting to use a list as a key raises a TypeError because lists are not hashable. Use tuples instead if you need a compound immutable key.
