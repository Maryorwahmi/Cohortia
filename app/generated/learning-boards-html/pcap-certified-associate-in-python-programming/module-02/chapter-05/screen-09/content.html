Module 3 › Chapter 2.5 › Iterating
Examples
person = {"name":"Alice","age":31,"city":"NY"}
# Keys
for key in person:
    print(f"Key: {key}, Value: {person[key]}")

# Items (preferred when you need both)
for key, value in person.items():
    print(f"{key}: {value}")

# Values
for value in person.values():
    print(value)
Performance note

items() avoids extra dictionary lookups when you need both key and value, which is often slightly more efficient and clearer.

Mutating while iterating

If you remove keys while iterating, iterate over list(dict.keys()) to work on a snapshot and avoid runtime errors or skipped items.

Key Takeaway

Match the loop to the data you need. Prefer items() when you need both key and value and snapshot keys before mutating.

Check
