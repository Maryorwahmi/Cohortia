Dictionaries in Python

Named lookup, mutable storage, keys must be unique and immutable.

Definition

A dictionary is a collection of key-value pairs enclosed in curly braces. Lookups use keys instead of numeric indexes.

Why it matters

Fast access by identifier makes dictionaries ideal for configuration, small caches, and modeling structured records like user profiles.

Example — literal creation
# Creating simple dictionaries
person = {"name": "Alice", "age": 30, "city": "New York"}
student_grades = {"Math": 95, "Science": 88, "History": 92}
empty_dict = {}
Key Takeaway

Use dictionaries when you need to associate unique keys with values and perform frequent lookups or updates by key.
