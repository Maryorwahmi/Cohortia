Code walkthrough
person = {"name": "Alice", "age": 30}
# Add a key
person["occupation"] = "Software Engineer"
# Update a key
person["age"] = 31

# Use setdefault to initialize a list for grouping
groups = {}
groups.setdefault("admins", []).append("alice")
Example scenario

In inventory code, substract sold quantities and write back the updated count to the same key to keep stock accurate.

Common pitfall

If a value is a list and you modify it in place, any other reference to that list sees the change. Decide whether to copy or replace depending on intent.

Key Takeaway

Assignment both adds and updates. Use setdefault for safe initialization and be intentional about in-place mutation.

Pro tip

For nested counters consider collections.defaultdict(int) in larger programs, but setdefault is handy in small scripts.
