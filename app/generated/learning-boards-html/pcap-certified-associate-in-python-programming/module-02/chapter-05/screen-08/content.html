Module 3 › Chapter 2.5 › View objects
Quick code
person = {"name":"Alice", "age":31, "city":"NY"}
keys_view = person.keys()
print(keys_view)             # dynamic view
person["country"] = "USA"
print(keys_view)             # reflects new key

# Snapshot
keys_list = list(person.keys())
print(keys_list)
When to snapshot

Snapshot before mutating while iterating, or when you need stable indexed access to keys or items.

Iteration pattern

Use for key, value unpacking: for key, value in person.items(): process both without extra lookups.

Common confusion

Don’t assume the view supports list methods or indexing. Convert to list when you need those behaviors.

Key Takeaway

View objects are efficient and live. Convert to list for a stable snapshot before mutating during iteration.
