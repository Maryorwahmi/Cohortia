Module 3 › Chapter 2.5 › Final Reminders
Immutable keys

Use strings, numbers or tuples as keys. Avoid mutable objects like lists.

Intentional access

Decide whether to allow defaults or require keys and choose get() or direct indexing accordingly.

Snapshot before mutate

Convert keys() or items() to list() if you need a stable collection while changing the dictionary.

Final takeaway

Design keys and access patterns thoughtfully. That small design decision determines how robust and maintainable your code will be.
