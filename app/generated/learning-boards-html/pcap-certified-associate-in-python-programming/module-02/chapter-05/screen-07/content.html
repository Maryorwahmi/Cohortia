Module 3 › Chapter 2.5 › Removing entries
Code examples
person = {"name": "Alice", "age": 31, "occupation": "Software Engineer"}
# del removes, raises KeyError if missing
del person["occupation"]

# pop returns a value, with optional default
grade = {"Math":95, "Science":88}
science_grade = grade.pop("Science")   # returns 88
missing = grade.pop("Art", None)      # returns None, no error

# popitem removes an arbitrary pair
pair = grade.popitem()

# clear empties the dictionary
person.clear()
Practical note

When deleting while iterating, iterate over a copy of the keys list to avoid modifying the dictionary during iteration.

When to use which
  • del: you expect key present and want an error if not.
  • pop: you want the removed value and safe default handling.
  • popitem: consume entries without concern for order.
  • clear: reset the dictionary.
Common mistake

Using del without checking can raise KeyError unexpectedly on user data. Use pop with a default for safer deletion when keys may be absent.
