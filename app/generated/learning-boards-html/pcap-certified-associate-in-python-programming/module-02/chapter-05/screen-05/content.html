Code examples
# Creating dictionaries
person = {"name": "Alice", "age": 30, "city": "New York"}
student_grades = {"Math": 95, "Science": 88, "History": 92}
empty_dict = {}

# Direct access (can raise KeyError)
print(person["name"])            # Alice

# Safe access with get
print(person.get("city"))       # New York
print(person.get("country"))    # None
print(person.get("country", "Unknown"))  # Unknown
Example scenario

When reading configuration values that may be missing, get with a default avoids crashes and provides sensible fallbacks.

Patterns
  • Direct indexing when a missing key is a programming error.
  • get(default) for optional keys or user-supplied data.
  • Membership check with in operator when you want explicit branching.
Common mistake

Relying exclusively on direct indexing with unpredictable input leads to KeyError. Use get or membership checks instead.

Check your understanding

If get returns None, how would you distinguish between an explicit stored None value and a missing key? Consider using a unique default marker or checking membership first.
