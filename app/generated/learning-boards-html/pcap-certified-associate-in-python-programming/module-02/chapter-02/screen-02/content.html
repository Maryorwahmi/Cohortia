Explain iteration

Define iteration and why repeating a block of code is more reliable and efficient than copying statements. Understand typical use cases like processing lists of items.

Mnemonic: loop = repeat

02
Implement for loops

Use for to iterate over strings, lists, tuples, sets, and dictionaries, and perform actions per item. Learn common patterns for processing and transforming collections.

Mnemonic: for-each item
VERIFIED COMPETENCY MILESTONE
03
Use while loops

Write indefinite loops that run until a condition changes, useful for validation or interactive prompts. Ensure the condition eventually becomes false to avoid infinite loops.

Mnemonic: while true → until false
VERIFIED COMPETENCY MILESTONE
04
Control loop flow

Apply break to exit early and continue to skip the current iteration. Use these statements to keep loops efficient and readable when searching or filtering.

Mnemonic: break = stop, continue = skip
