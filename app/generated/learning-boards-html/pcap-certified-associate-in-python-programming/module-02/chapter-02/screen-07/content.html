Module 2 › Chapter 2.2 › while loops
Definition

Indefinite repetition

Use while when the termination depends on a runtime condition instead of a known number of steps.

# Example: limited login attempts
attempts = 0
max_attempts = 3
password = ""
while password != "secret" and attempts < max_attempts:
  password = input("Enter password: ")
  if password == "secret":
    print("Access granted")
  else:
    print("Incorrect")
  attempts += 1
else:
  if password != "secret":
    print("Too many failed attempts")
Common mistake
Not changing a condition variable inside the loop produces an infinite loop.
Pro-tip
Use a counter or a clear break condition in interactive loops to ensure termination.
When to pick while

Choose while when the number of iterations depends on user input, external events, or dynamic state changes.

Key Takeaway

Design the loop so a clearly defined variable or condition will progress toward termination on every iteration.

Safety checks
Checklist
  • Is the loop condition well-defined?
  • Does something in the body change that condition?
  • Do you have a fallback or counter to break after many attempts?
Misconception

Loops are safe by default; in reality, you must design for termination explicitly.
