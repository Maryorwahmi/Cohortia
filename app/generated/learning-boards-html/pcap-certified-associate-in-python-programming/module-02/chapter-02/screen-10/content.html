Module 2 › Chapter 2.2 › Common mistakes
Checklist

Avoid these mistakes

  • Infinite loop: loop condition never changes
  • Off-by-one: mistaken range boundaries or index limits
  • Mutating an iterable while iterating it
  • Incorrect use of break/continue in nested loops
Fixes
Use counters, copy iterables before modifying, test small examples, and add assertions after loops to check invariants.
Pro Tip

When debugging, print the loop variable and key counters for the first few iterations to confirm expected behavior before running full data.

Mini exercise
Test case

Run your loop with a tiny list and an intentionally invalid value to see whether the loop handles it and terminates as expected.

Post-check

After the loop, verify counts or list lengths with assertions to catch off-by-one and missing items early.
