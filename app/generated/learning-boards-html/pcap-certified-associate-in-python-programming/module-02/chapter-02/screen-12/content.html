Module 2 › Chapter 2.2 › Key Concepts
Iteration

Repeat a block for items or until a condition changes to scale tasks and reduce duplication.

for & range()

Use for to walk iterables. Use range to generate numeric sequences; stop value is excluded.

while & control

Choose while for condition-driven repetition. Use break to exit and continue to skip iterations; watch for infinite loops.

Summary

Choose the right loop for the task, structure the body to ensure termination, and use control statements to keep loops efficient and readable.
