How range works

Remember: range produces numbers from start up to but not including stop. This half-open interval is intentional and consistent across Python.

# Examples
list(range(5))        # [0, 1, 2, 3, 4]
list(range(1, 5))     # [1, 2, 3, 4]
list(range(5, 0, -1)) # [5, 4, 3, 2, 1]
Pitfall
Assuming range(stop) includes stop leads to missed or extra iterations.
Check
Print the sequence from range during development to confirm it matches expectations.
Example

Indexing a list

When you need indexes, iterate over range(len(my_list)) and be careful with stop value to cover valid indexes only.

Key Takeaway

Think of range as start <= value < stop. Use small tests to confirm boundary behavior before using indices in logic.

Visual check
Half-open interval

Range includes the start and excludes the stop. This rule prevents off-by-one surprises when applied consistently.

Quick rule

If you need N iterations, use range(N) and remember the last value is N-1.
