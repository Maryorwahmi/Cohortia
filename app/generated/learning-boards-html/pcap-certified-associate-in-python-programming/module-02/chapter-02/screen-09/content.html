Module 2 › Chapter 2.2 › Loop else clause
Definition

When else runs

Else runs after normal completion of a loop. If a break happens, else is skipped. Use this to differentiate found versus not-found results.

for x in items:
  if match(x):
    print("Found")
    break
else:
  print("Not found")

# The else runs only if break never executed
When to use
Search operations and verification steps where a normal finish needs handling.
Avoid
Overusing else when a simple boolean flag would be clearer to new readers.
Example

Iterate through a list to find an even number; print the found value and break. If none are found, else prints a not-found message. This keeps the code compact.

Key Takeaway

Use loop else to express 'nothing found' outcomes without extra state variables. Remember break prevents else from running.

Analogy
Library search

Search shelves; break when you find the book. If you finish the shelf without finding it, else handles the not-found result.

Clarity tip

Use else only when it improves readability; otherwise a flag or separate check is fine.
