Definition

Iteration explained

Repeat the same steps reliably for multiple items or until a condition changes. This improves readability and reduces duplication.

Analogy

A bakery repeating the same recipe for each loaf is like a loop applying the same code to each item.

Common use cases
  • Processing records in a list or file
  • Aggregating values like sums or averages
  • Prompting users until valid input arrives
Example

Counting valid items

A loop can scan readings and collect valid ones into a new list while skipping invalid markers.

# Example pattern (conceptual)
readings = [25.5, -999, 26.1]
valid = []
for r in readings:
  if r == -999:
    continue
  valid.append(r)
# valid now holds only non-marker values
Key Takeaway

When you see repeated actions, prefer a loop. Decide whether you know the number of iterations or must loop until a condition changes.
