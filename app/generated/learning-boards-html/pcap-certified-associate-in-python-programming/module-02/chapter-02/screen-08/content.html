Process Flow

Stop or skip

break exits the loop immediately. continue skips to the next iteration. Use both to keep loop logic small and explicit.

numbers = [1, 3, 5, 8, 9]
for n in numbers:
  if n < 0:
    continue  # skip negatives
  if n % 2 == 0:
    print(f"First even number found: {n}")
    break
else:
  print("No even numbers found")
Pattern
Use continue to filter, break to short-circuit a search, and else to handle the not-found case.
Watch out
break prevents the loop's else block from executing, which matters in search patterns.
Analogy

Think of continue as skipping a single tray on a conveyor, and break as stopping the conveyor entirely when you find what you need.

Key Takeaway

Use continue to keep loop bodies focused, and break to stop work early when a result is found. Combine with else for clear search outcomes.

Example flow
Search pattern
