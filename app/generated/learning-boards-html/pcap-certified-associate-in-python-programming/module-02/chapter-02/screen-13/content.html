Range rule

If you need N iterations, use range(N) and expect the last value to be N-1.

Progress

Always change a loop condition inside a while loop or provide a maximum attempts guard to prevent infinite runs.

Mutation

Avoid removing or inserting items in the list you are iterating; iterate a copy or build a new list instead.

Closing thought

Small habits around range boundaries, termination progress, and safe mutation make loops predictable and easy to test.
