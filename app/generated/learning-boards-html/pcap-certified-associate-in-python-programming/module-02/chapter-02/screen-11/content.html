Code walkthrough

Filter, count, aggregate

temperatures = [25.5, 27.0, 24.8, -999, 26.1, 28.3, -999, 25.9]
valid_temperatures = []
high_temp_threshold = 28.0
high_temp_count = 0
invalid_marker = -999

for temp in temperatures:
  if temp == invalid_marker:
    print(f"Skipping invalid reading: {temp}")
    continue
  valid_temperatures.append(temp)
  if temp > high_temp_threshold:
    high_temp_count += 1
    print(f"High temperature detected: {temp}°C")

# Average calculation
if valid_temperatures:
  total = 0
  for t in valid_temperatures:
    total += t
  average_temp = total / len(valid_temperatures)
  print(f"Average valid temperature: {average_temp:.2f}°C")
else:
  print("No valid temperatures to calculate average.")
Why this pattern

Separating filtering and aggregation keeps logic clear and avoids index mistakes. The first pass cleans data; the second computes aggregates safely.

Key Takeaway

Use continue to skip invalid markers, collect valid items, and always check for emptiness before dividing to avoid runtime errors.

Scenario

Sensors may emit invalid markers. A robust program filters these markers out and only analyzes valid readings to compute reliable statistics.

Try this

Change the invalid marker and threshold, then re-run the code to see how results update.

Misconception

Calculating average on the original list without removing markers may yield incorrect averages or runtime errors.
