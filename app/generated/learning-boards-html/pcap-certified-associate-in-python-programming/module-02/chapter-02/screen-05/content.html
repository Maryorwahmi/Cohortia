Code walkthrough

Iterating a collection

Use descriptive loop variables and avoid mutating the iterable while iterating.

temperatures = [25.5, 27.0, -999, 26.1]
valid_temperatures = []
for temp in temperatures:
  if temp == -999:
    continue
  valid_temperatures.append(temp)
# valid_temperatures now contains only valid readings
Tip
Iterate over a copy if you must remove items from a list during traversal.
Misconception
Altering the list while iterating can skip items or cause unexpected behavior.
Use case

Filtering and transforming

Use for loops to build new lists of cleaned or converted values, which keeps original data intact for verification.

Key Takeaway

For loops visit each element of an iterable. Keep loop bodies focused and avoid in-place removals when possible.

Visual
Iterable examples
  • String → characters
  • List → items in order
  • Dictionary → iterate keys or items()
When to use for

When you can enumerate every item or when you need a fixed number of iterations using range.
