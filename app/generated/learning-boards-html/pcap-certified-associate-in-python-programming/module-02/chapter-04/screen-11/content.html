Module 2 › Chapter 2.4 › Lists vs Tuples vs Sets
List
Ordered, mutable, allows duplicates. Use for dynamic sequences where order matters and elements change.
Tuple
Ordered, immutable, allows duplicates. Use for fixed records and when hashability is needed.
Set
Unordered, mutable, unique elements. Use for membership checks and deduplication.
Scenario Prompts
  • Store user credentials that shouldn't change: tuple.
  • Collect unique error codes: set.
  • Manage a dynamic shopping cart: list.
