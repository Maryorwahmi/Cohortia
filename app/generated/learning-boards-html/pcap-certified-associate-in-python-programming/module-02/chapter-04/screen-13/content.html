Module 2 › Chapter 2.4 › Pitfalls and Misconceptions
Top Pitfalls
  • Missing trailing comma for single-item tuples returns the inner type.
  • Attempting to assign to tuple indices raises TypeError due to immutability.
  • Putting unhashable objects, like lists, into sets causes TypeError.
  • Using remove on a non-present element raises KeyError; use discard to be safe.
Quick Remedies
When you need an ordered unique sequence, convert a set to a list and sort it. When you need a hashable record, ensure all tuple elements are immutable. Use discard when removal should be safe.
Check Your Understanding
If you see TypeError when adding to a set or using a tuple as a key, inspect whether any inner item is mutable. That diagnosis solves many debugging sessions.
