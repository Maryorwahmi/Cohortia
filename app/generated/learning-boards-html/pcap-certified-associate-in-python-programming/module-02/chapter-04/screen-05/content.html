Module 2 › Chapter 2.4 › Creating and Accessing Tuples
Examples
coordinates = (10, 20)
rgb_color = (255, 0, 128)
# single-item tuple needs trailing comma
single_item = ("hello",)

# indexing and slicing
print(coordinates[0])      # 10
print(rgb_color[0:2])      # (255, 0)
Explanation
  • Parentheses group values; commas define tuple elements.
  • Indexing is zero-based; slicing returns a new tuple.
  • Trying to assign to an index raises a TypeError because tuples are immutable.
Common Mistake
Omitting the comma for single-item tuples yields the inner type rather than a tuple. Always use the trailing comma to signal a tuple.
Key Takeaway
Use tuples for small, fixed data groups and rely on slicing to produce new tuples when you need different subsets.
