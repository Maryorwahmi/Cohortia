Module 2 › Chapter 2.4 › What is a Set?
Definition

A set contains only unique elements and does not preserve insertion order. It's mutable via add and remove operations and is ideal for deduplication and fast membership tests.

  • Cannot be indexed or sliced.
  • Use set() to create an empty set; curly braces make a non-empty set.
  • Only hashable objects can be elements.
Concrete Example
unique_numbers = {1, 2, 3, 2, 1}
print(unique_numbers)  # {1, 2, 3} (order may vary)
vowels = set("aeiou")
print(vowels)
Why it matters
Sets give a simple way to express mathematical relations between groups and to perform efficient lookups for membership tests.
