Module 2 › Chapter 2.4 › Set Operations
Examples
set_a = {1,2,3,4}
set_b = {3,4,5,6}
print(set_a | set_b)   # union {1,2,3,4,5,6}
print(set_a & set_b)   # intersection {3,4}
print(set_a - set_b)   # difference {1,2}
print(set_a ^ set_b)   # symmetric difference {1,2,5,6}
Practical Scenario
Find premium visitors today: intersection between daily_visitors and premium_members. Remove premium from visitors to find non-premium: difference.
Note: these return new sets unless using update-style methods.
