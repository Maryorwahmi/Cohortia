Module 2 › Chapter 2.4 › Tuple Packing and Unpacking
Packing
# Tuple packing
person_info = "Alice", 30, "Engineer"
print(type(person_info))  # <class 'tuple'>
Packing uses commas to group values; parentheses are optional.
Unpacking
# Unpacking and swapping
name, age, occupation = person_info
x, y = 10, 20
x, y = y, x  # swap
Unpacking requires matching counts or use of a starred variable to collect extras.
Practical tip
Use packing/unpacking to return multiple values from functions and to make swaps clear and concise without temporary variables.
