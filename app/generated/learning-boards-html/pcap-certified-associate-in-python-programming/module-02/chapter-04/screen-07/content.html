Module 2 › Chapter 2.4 › Tuple Methods & Hashability
Common Methods
t = (1,2,2,3)
print(t.count(2))   # 2
print(t.index(3))   # 3's index is 3
Tuples intentionally lack mutation methods because they are immutable.
Hashability Rule
A tuple is hashable only if all its elements are hashable. Use tuples as keys when you need a compound, immutable key.
Example
Use a tuple as a key: cache[(x, y)] = result. Avoid putting a list into a tuple if you need hashability.
Common Mistake
Placing a mutable item inside a tuple makes it unhashable and unsuitable as a key or set element.
