Module 2 › Chapter 2.4 › Creating and Modifying Sets
Creation
non_empty = {"alice", "bob", "charlie"}
empty = set()   # correct empty set
# {} creates an empty dictionary, not a set
Modification
s = {1,2,3}
s.add(4)
s.remove(2)    # raises KeyError if 2 not present
s.discard(5)   # safe: does nothing if 5 absent
print(3 in s)  # membership test
Common Mistake
Using {} for an empty set or relying on order in a set. If order matters, convert to a list and sort it.
