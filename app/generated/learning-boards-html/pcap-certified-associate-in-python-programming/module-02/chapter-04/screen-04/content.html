Module 2 › Chapter 2.4 › What is a Tuple?
Definition
Ordered, immutable collection

A tuple preserves insertion order and does not allow modification after creation. Because of immutability, tuples can be used as keys in dictionaries or elements of sets when they contain only hashable items.

  • Allows duplicates and zero-based indexing.
  • Supports slicing to extract sub-tuples.
  • Has only a couple of methods: count and index.
Analogy
Think of a sealed container — once closed you cannot swap contents without creating a new container. That sealed nature is exactly what immutability gives you.
Common mistake: forgetting the trailing comma for single-item tuples.
Concrete Example
# coordinates as a tuple
coordinates = (10, 20)
print(coordinates[0])  # 10

# single-item tuple
single = ("hello",)
print(type(single))  # <class 'tuple'>
Key Takeaway
Choose tuples when values represent a fixed record and you want to prevent accidental modification.
