Process Flow
else as fallback
One else per chain. Runs only when no earlier condition matched.
Step-by-step
1. Evaluate if condition. If true, run its block and exit the chain.
2. If false, evaluate the first elif. Repeat for subsequent elif blocks.
3. If every test is false, run the else block if present.
Example use: show a default message when no specific rule applies, but avoid masking errors that should be explicit.
Concrete example
score = 72
if score >= 90:
  print("A")
elif score >= 80:
  print("B")
elif score >= 70:
  print("C")
else:
  print("F")
Order matters: higher ranges must appear first, otherwise a high score might match a lower threshold early.
Key Takeaway

Use else for defaults but prefer explicit checks when missing states should trigger errors.

Common mistake

Placing broader conditions before narrower ones causes incorrect early matches.
