Elif: ordered alternatives
When using multiple tests, place the most specific tests first so they are evaluated before broader ones.
Specific first
General later
Example
Check if score >= 90 before checking >= 70.
Pitfall
Wrong ordering causes early matches and incorrect results.
Concrete comparison
# correct order
if score >= 90:
  print("A")
elif score >= 80:
  print("B")
# incorrect order
if score >= 70:
  print("C")
elif score >= 90:
  print("A")
Predict for score 95: first block prints A in the correct chain, but the incorrect chain prints C because the broader 70 check matched first.
Key Takeaway

Elif checks are sequential; order affects behavior. Use separate ifs for independent checks.
