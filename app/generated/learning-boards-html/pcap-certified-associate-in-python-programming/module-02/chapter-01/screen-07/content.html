Definition
Comparison operators
Use equality, inequality, and order comparisons to turn values into true/false results.
== equality — tests whether values are equal
!= inequality — tests whether values are different
< , > , <= , >= — order and inclusive comparisons
Concrete example and check
age = 65
# inclusive check
if age >= 13 and age <= 65:
  print("Valid")
Test age values 12, 13, 65, and 66 to confirm inclusive behavior. An alternative chained form exists and reads naturally for ranges.
Pro tip

When checking ranges, prefer clear conjunctions or well-ordered chained comparisons to avoid mistakes.
