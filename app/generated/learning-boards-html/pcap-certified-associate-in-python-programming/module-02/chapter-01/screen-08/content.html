Core Concept
and, or, not
Combine comparisons into composite conditions and understand short-circuiting.
and — true when both operands are true
or — true when at least one operand is true
not — inverts a boolean
Concrete scenarios
Examples to practice mentally:
  • age >= 18 and has_license evaluates true only for adults with a license.
  • is_admin or is_owner grants access if either role applies.
  • not is_authenticated catches unauthenticated users.
Pro tip

For complex expressions, assign parts to named booleans to document intent and simplify testing.
