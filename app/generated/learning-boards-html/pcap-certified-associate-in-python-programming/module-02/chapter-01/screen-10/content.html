Text adventure snippet
player_location = "forest"
has_sword = False
is_door_locked = True

command = input("What do you do? ").lower()

if command == "go north":
  print("You head deeper into the forest.")
  player_location = "deep_forest"
elif command == "pick up sword":
  if player_location == "forest":
    print("You pick up a rusty sword.")
    has_sword = True
  else:
    print("There's no sword here to pick up.")
elif command == "open door":
  if player_location == "deep_forest":
    if is_door_locked:
      print("The door is locked.")
      if has_sword:
        print("Perhaps the sword can help...")
      else:
        print("You need a key, or something to force it open.")
    else:
      print("The door creaks open.")
else:
  print("I don't understand that command.")

print(f"Current location: {player_location}, Has sword: {has_sword}")
What to observe
  • State variables guide nested checks: location and has_sword change outcomes.
  • Commands map to branches; unknown commands hit the else fallback.
  • Order and nesting produce narrative flow — trace sample sequences.
