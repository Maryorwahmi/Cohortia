Module 2 › Chapter 2.1 › Learning Objectives
01
Read and write if, elif, else
Recognize required colon and indentation; predict which branch will run for given inputs.
VERIFIED COMPETENCY MILESTONE
Mnemonic: think of an ordered checklist. If the top item applies, stop and act; otherwise, continue down the list.
02
Use comparison and logical operators
Combine equality, inequalities, and and/or/not to express rules like age limits or membership checks.
VERIFIED COMPETENCY MILESTONE
Mnemonic: comparisons give single checks; logical operators stitch them into boolean sentences.
03
Implement nested conditionals
Use nested checks for context-sensitive decisions but refactor if nesting exceeds readability limits.
VERIFIED COMPETENCY MILESTONE
Mnemonic: nest only when the inner check depends on the outer condition being true.
04
Identify common errors
Spot indentation errors, missing colons, and logic-order mistakes during testing.
VERIFIED COMPETENCY MILESTONE
Mnemonic: syntax mistakes raise errors; logic mistakes produce wrong behavior — test edge cases to find both.
