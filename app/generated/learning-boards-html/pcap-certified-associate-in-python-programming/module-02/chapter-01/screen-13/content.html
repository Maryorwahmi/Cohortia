Process
Refactor for readability
Turn complex conditions into named booleans or functions and add unit tests for boundaries.
Extract eligibility checks into functions.
Use early returns to avoid deep nesting.
Write tests for true, false, and edge conditions.
Concrete refactor pattern
def is_free_shipping(order_total, premium):
  if premium:
    return order_total >= 50
  return order_total >= 100

if is_free_shipping(order_total, premium_member):
  shipping_cost = 0.0
else:
  shipping_cost = 5.0 if premium_member else 10.0
This isolates eligibility logic and makes direct unit testing of the helper function simple.
