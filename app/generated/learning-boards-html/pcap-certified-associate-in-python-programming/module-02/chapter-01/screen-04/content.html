Core Concept
if statement
A conditional that runs its indented block when its expression is true.
Syntax rules
  • Use a colon after the condition.
  • Indent the block consistently (commonly four spaces).
  • Indentation defines block membership; mixing tabs and spaces causes errors.
Common mistake
Missing colon or inconsistent indentation → SyntaxError or IndentationError.
Concrete example
number = 5
if number > 0:
  print("Positive number")
print("Done")
This snippet prints the message only when the number is greater than zero. Test values of zero and negative numbers to see the alternate path.
Key Takeaway

An if statement is a condition plus an indented block; syntax and spacing are essential.
