Hierarchy
Nested conditionals
Use when an inner decision only applies after an outer condition holds.
Checklist: keep nesting shallow, use descriptive helper functions, and write tests for all combinations of outer and inner conditions.
Example pattern
if user_logged_in:
  if user_role == "admin":
    grant_admin_permissions()
  else:
    show_standard_view()
else:
  prompt_login()
Refactor option: move role handling into a function to keep the top-level flow readable.
Key Takeaway

Nesting is powerful but should be limited; refactor deep logic into functions for clarity.
