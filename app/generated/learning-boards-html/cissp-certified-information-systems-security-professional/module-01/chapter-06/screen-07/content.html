Module 2 › Chapter 1.6 › Policy Types Comparison
Organizational
High-level direction and commitment; applies to the whole organization.
Example: Corporate Information Security Policy stating commitment to protect data.
Issue-Specific
Focused rules for a security topic that affects a broad audience.
Example: Remote Access Policy defining secure VPN use and multi-factor requirements.
System-Specific
Technical requirements for a particular system, application, or network segment.
Example: Database Server Security Policy listing secure configurations and patch windows.
Guidance
Avoid duplicating detailed technical controls across levels. Keep high-level commitments in organizational policies, put prescriptive rules in issue-specific policies, and reserve exact configurations for system-specific documents and procedures.
