Exception Process
1. Formal request with business justification.
2. Risk assessment and identification of compensating controls.
3. Approval by authorized reviewer and documentation.
4. Defined expiration and periodic review until resolved.
Compensating Controls Examples
Network isolation and strict firewall rules for legacy systems.
Enhanced logging and continuous monitoring when encryption cannot be applied.
Temporary additional access controls and multi-factor authentication for elevated accounts.
Example Scenario
A legacy app requires an unsupported OS. Approve an exception only if isolated, monitored, and scheduled for migration within a fixed timeframe.
