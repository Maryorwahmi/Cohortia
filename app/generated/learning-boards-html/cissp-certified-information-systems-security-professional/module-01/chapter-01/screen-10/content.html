Activity

Draft and map a remote access framework

Use the template to write a high-level policy and derive a standard, guideline and first procedural steps.

Policy Statement (example)

Cohortia requires all remote access to internal networks to be authorized by management and protected using approved remote access controls to preserve confidentiality and integrity of corporate data.

Standard (example)

All remote access to Cohortia internal networks MUST use a Cohortia-approved VPN solution with multi-factor authentication enabled.

Guideline (example)

Employees are encouraged to use strong, unique passwords and to avoid accessing sensitive systems over untrusted public Wi-Fi.

Procedure — First 3 steps (example)
1. Verify new employee's remote access authorization via the HR or access control system.
2. Provision a VPN account for the new user and configure multi-factor authentication per standard.
3. Provide the user with installation instructions for the approved VPN client and verify successful initial connection and MFA enrollment.
When you map these artifacts, also list the artifacts that prove enforcement: VPN config records, MFA enrollment logs, and onboarding audit entries. These become evidence of due care and due diligence.
