Assessment

Questions and artifact mapping

Use short knowledge checks plus real artefacts to validate that governance is implemented and effective.

Knowledge check (example)
"A new requirement mandates MFA for all employees and applies uniformly. Which documentation type best describes this?"
Correct answer: Security Standard
Scenario check (example)
"A critical server lacked patches despite a policy to patch. The process was not audited."
Primary lacking concept: Due Diligence
Artifact checklist
  • Policy with approval record or signature.
  • Standard specifying the technical requirement and version control.
  • Baseline configuration scan results and patch reports.
  • Procedure execution logs showing steps were completed and verified.
When you assess governance, prioritize evidence that shows both the existence of controls and the continuous work that maintains them.
