Comparison

Standards and baselines compared

Both are mandatory, but standards are organisation-wide requirements while baselines define minimum configurations for system types.

Standard example
All remote access MUST use an approved VPN with multi-factor authentication enabled.
Baseline example
Web server baseline: disable unused services, required patch level, secure TLS configuration, and specific file permissions.
Common mistake
Treating baselines as advisory or making standards too narrow without lifecycle management.
Enforcement & Evidence

Implement monitoring to collect patch records, configuration scans, and access logs that demonstrate compliance with standards and baselines. Use automated scans to detect drift from baselines and report to governance bodies for remediation.

Key Takeaway

Standards direct the mandatory method; baselines give the minimal, system-level settings required to meet that standard.
