Definition

Acceptable Use Policy

A readable, role-aware document that explains permitted and prohibited uses of systems and data.

  • Include internet and email usage rules.
  • Specify handling of sensitive data and software installation policies.
  • State consequences for violations to enable enforcement.
Practical cards
Example clause

"Do not move proprietary code to personal cloud accounts" — specific, actionable language.

Onboarding action

Require acknowledgement and short explanation of the AUP during onboarding.

Common mistake

Vague legalese that employees ignore. Make it readable and role-specific.

Key Takeaway

AUPs must be readable and enforced; pair them with role-specific training and acknowledgement.
