Process Flow

Standard offboarding checklist

  1. Disable network accounts (Active Directory, email, VPN).
  2. Collect company-issued laptop and mobile phone.
  3. Remove physical access badge.
  4. Conduct exit interview and record notes.
Enhancements for sensitive roles
Repository access review

Revoke source control access and verify no private forks or offsite copies remain.

Transfer of ownership

Assign project owners and document where responsibilities and IP are transferred.

Forensic imaging

Image devices before wiping when evidence preservation is required for investigations.

Key Takeaway

Use a documented, audited offboarding checklist; expand it for sensitive roles and third parties to close security gaps quickly.
