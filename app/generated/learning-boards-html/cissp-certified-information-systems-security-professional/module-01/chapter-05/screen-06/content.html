Module 1 › Chapter 1.5 › Copyright vs Patent
Definition

When to use copyright or patent

Practical guidance for software and product teams choosing IP strategies.

Copyright example
Source code and course text are protected expressions. Copyright prevents copying of that expression.
Patent example
A novel algorithm or hardware design with inventive steps could be patented to prevent others from using the method commercially.
Misconception
Assuming one protection covers everything. Copyright does not stop the use of an idea; patents may be needed to block functional use.
Practical checklist
  • Is the asset an expression? If yes, copyright applies.
  • Is it a novel, non-obvious invention? If yes, consider patent protection.
  • Do you need secrecy? If yes, trade secret controls may be preferable.
Key takeaway
Document the decision with rationale and owner so the organization can sustain the protection strategy.
