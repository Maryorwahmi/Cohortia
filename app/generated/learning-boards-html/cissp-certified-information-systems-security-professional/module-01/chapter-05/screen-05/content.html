Definition

Four IP types with examples

Protecting intellectual property preserves innovation and competitive advantage. Choose protections appropriate to the asset type.

Copyright
Protects original works such as code and curriculum. Example: Cohortia course materials.
Patent
Protects new inventions like a unique algorithm or hardware design for a limited term.
Trademark
Protects brand identifiers such as names and logos. Example: Cohortia logo.
Trade Secret
Protects confidential business information as long as secrecy is maintained. Example: secret processes.
Practical register
IP register card
Record: asset name, type of IP protection chosen, owner, justification, and controls (e.g., NDAs for trade secrets, patent filings).
Misconception
Thinking that copyright protects ideas. It protects the expression; patents protect the idea implemented as an invention.
Key takeaway
Match asset to protection, document the decision, and maintain controls to enforce the protection.
