Process Flow

Steps to operationalize GDPR

  1. Document lawful basis: register the legal justification for each processing activity.
  2. Data minimization: limit collection and retention to what is necessary for the purpose.
  3. Rights handling: create verified procedures for access, rectification, and erasure requests.
  4. Accountability: maintain records and carry out impact assessments where required.
Concrete example
For personalization, choose consent or legitimate interest, set limited retention for browsing history, expose deletion options, and log each subject request.
Controls and tooling
Automation
Use automated retention and deletion to enforce minimization and retention schedules.
Access controls
Implement least privilege and logging to support subject access requests and audits.
Misconception
Relying solely on consent. Consent can be revoked and is not the only lawful basis; select the basis appropriate to the processing.
Key takeaway
GDPR is operational: show records, processes, and controls that enforce the principles, not only policy statements.
