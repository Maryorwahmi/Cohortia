Formulas
SLE, ARO, ALE provide a numerical estimate of expected loss.
// Single Loss Expectancy
SLE = Asset Value × Exposure Factor

// Annualized Loss Expectancy
ALE = SLE × ARO
Keep inputs documented: asset value, exposure factor, and ARO assumptions.
Worked calculation
Given SLE of $500,000 and ARO 0.20, compute ALE as $100,000 per year. This is the expected annual cost of the risk.
Use ALE to compare to control cost; if controls cost less than ALE over the decision horizon, invest.
Common mistake: using invented numbers without validation, which produces false precision.
Pro tip

Run sensitivity checks on ALE by varying ARO and exposure factor to see how robust your recommendation is.
