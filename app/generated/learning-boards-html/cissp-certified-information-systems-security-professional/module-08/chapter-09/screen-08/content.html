Data Encryption Strategies: At Rest

Protecting sensitive data when it's stored on disk

Encryption Methods

  • Full Disk Encryption: OS-level encryption for entire storage.
  • Database-Level Encryption (TDE): Encrypts database files/tablespaces.
  • Column-Level Encryption: Application-level encryption for specific sensitive columns.
Key Takeaway

Employ a layered approach to data at rest encryption, combining disk, database, and column-level methods for robust protection.

Data at Rest Encryption Layers

1. Full Disk Encryption

Encrypts the entire physical or virtual disk. Protects against physical theft or unauthorized access to raw disk files.

2. Transparent Data Encryption (TDE)

Encrypts database files or tablespaces at the database engine level. Transparent to applications, protecting data even if database files are copied.

3. Column-Level Encryption

Encrypts specific, highly sensitive data fields within tables. Offers the highest granularity but requires application-level key management.

Misconception

Believing full disk encryption alone protects data from all threats. It protects the disk, but not necessarily data accessed via a running, compromised database server.
