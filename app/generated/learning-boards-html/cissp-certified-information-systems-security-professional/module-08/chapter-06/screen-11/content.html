UAT: Validating Security from the User's Perspective

User Acceptance Testing (UAT) must include validation of security requirements to ensure user-centric security and compliance.

What is UAT?

Performed by end-users/stakeholders to ensure the application meets business requirements.

Security Scenarios in UAT
  • Verify users cannot access others' data (e.g., shopping cart).
  • Ensure sensitive reports are role-restricted.
  • Test for privilege escalation from a user's view.
Key Takeaway

Integrating security validation into UAT ensures that security controls are not only functional but also meet user expectations and compliance needs, building trust.

UAT Security Focus Areas

Compliance Verification

Verify GDPR/HIPAA controls (e.g., data deletion, export).

Usability of Security Features

Ensure MFA, password reset are user-friendly.

Example: User verifies they cannot view another user's order history.
