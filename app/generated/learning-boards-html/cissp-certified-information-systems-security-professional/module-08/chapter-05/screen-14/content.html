Essential Security Testing Terms

Foundational concepts for application security

SAST

"White-box" testing analyzing source code without execution to find vulnerabilities.

DAST

"Black-box" testing analyzing a running application by simulating attacks to find runtime vulnerabilities.

IAST

"Hybrid" testing using agents within a running application to combine SAST (code context) and DAST (runtime behavior).

SCA

Identifies open-source components for known vulnerabilities (CVEs) and license compliance issues.

False Positive

A security alert generated by a tool that does not represent a genuine vulnerability.

CI/CD Pipeline

Automated process for building, testing, and deploying software, integrating security tools.

Summary Takeaway

A comprehensive application security strategy leverages a combination of static, dynamic, hybrid, and composition analysis to detect vulnerabilities across the entire software development lifecycle.
