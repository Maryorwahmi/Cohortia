Broken Access Control & Cryptographic Failures

Understanding Authorization and Data Protection Weaknesses

Broken Access Control

Flaws in how access is controlled, allowing users to bypass authorization checks and access unauthorized resources or functions.

Cryptographic Failures

Weak or incorrect use of cryptography, leading to sensitive data exposure due to inadequate encryption or key management.

Key Takeaway

Broken Access Control allows unauthorized actions; Cryptographic Failures expose sensitive data. Both require strict, server-side controls and strong, correctly implemented cryptography.

Common Scenarios & Impact

Broken Access Control Example

A user modifies a URL parameter to access another user's account data without authentication. This bypasses the intended authorization logic.

Cryptographic Failures Example

An application stores user passwords using MD5 hashing, which is easily reversible, leading to plaintext password exposure if the database is breached.

Prevention Strategy

Implement granular, server-side access control checks and use strong, modern cryptographic algorithms with proper key management for all sensitive data.
