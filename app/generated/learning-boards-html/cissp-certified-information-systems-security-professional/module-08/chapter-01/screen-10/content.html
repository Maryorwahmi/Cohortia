SDLC Phase: Maintenance

Ongoing Security Operations

Sustaining Security Posture Over Time

Key Maintenance Activities

  • •Continuous monitoring for new vulnerabilities.
  • •Prompt patching and software updates.
  • •Regular security audits and re-evaluations.
  • •Feedback loop from incident response to development.

Example: Brute-Force Feedback

If operational logs frequently show brute-force login attempts, the development team should implement stronger rate limiting, CAPTCHA, or multi-factor authentication in a subsequent release to counter this specific threat.

Common Mistake: Stagnant Security

Believing an application is 'secure enough' after deployment is a critical error. The threat landscape constantly evolves, and without continuous monitoring and adaptation, even well-secured applications become vulnerable.

Key Takeaway

Security in maintenance is an ongoing cycle of monitoring, patching, auditing, and using operational feedback to continuously improve the application's security posture.
