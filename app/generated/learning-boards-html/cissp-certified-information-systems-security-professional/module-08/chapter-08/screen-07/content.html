The Software Bill of Materials (SBOM)

Gaining transparency into your software's composition

What is an SBOM?

A formal, machine-readable inventory of all software components and dependencies (open-source and commercial) used in a product.

Purpose: Transparency

Provides transparency into software composition, enabling quick identification of affected applications by new vulnerabilities and tracking license compliance.

SBOM: Software's Ingredient List

Component Name & Version
Supplier & License Info
Unique Identifiers (e.g., SPDX)
Key Takeaway

An SBOM is a critical inventory that provides transparency into software components, enabling rapid vulnerability assessment and license compliance tracking.
