Least Privilege

Any user, process, or program should have only the bare minimum permissions necessary to perform its function.

Core Definition

Granting only the essential access rights required for a specific task, nothing more.

Example Scenario

A web server process only has write access to its log directory, not the entire file system. A database user only has SELECT/INSERT on specific tables, not administrative rights.

Limited Access

Only what's needed, nothing more.

Key Takeaway

Minimizing permissions reduces the attack surface and limits the potential impact of a security breach, preventing privilege escalation.
