STRIDE: Categorizing Software Threats

Understanding the Six Primary Threat Types for Comprehensive Threat Modeling

Spoofing

Impersonating someone or something else.

Example: Attacker pretends to be a legitimate user.

Tampering

Modifying data or code without authorization.

Example: Altering a transaction record in a database.

Repudiation

Denying an action that occurred.

Example: A user denies making a purchase.

Information Disclosure

Exposing sensitive data to unauthorized individuals.

Example: Leaking customer records or system configurations.

Denial of Service (DoS)

Preventing legitimate users from accessing resources.

Example: Overwhelming a server with traffic.

Elevation of Privilege

Gaining unauthorized higher-level access.

Example: A regular user gaining administrative rights.

Key Takeaway

STRIDE provides a systematic way to identify a broad range of threats, ensuring that no major attack vector is overlooked during the design phase.
