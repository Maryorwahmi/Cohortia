Definition

Vulnerability Scanning

Automated, repeatable checks that identify known vulnerabilities and configuration issues across assets.

Tools
Examples: Nessus, OpenVAS, Qualys, Tenable.io. These automate discovery and export results for tracking.
Safe scheduling
Throttle intensive scans and use maintenance windows for critical systems to avoid impact.
Misconception
Scanner results are indicators, not proof of exploitability — verification is required.
Sample scanner output (concept)
[Scan] Host: production-web-01
- Apache RCE (CVE-2023-1234) - CVSS: 9.8 - State: detected
- Login page XSS - CVSS: 7.5 - State: detected
- OpenSSH old ciphers - CVSS: 6.1 - State: detected
Key Takeaway

Automated scans give broad visibility but require human review for prioritization and verification.
