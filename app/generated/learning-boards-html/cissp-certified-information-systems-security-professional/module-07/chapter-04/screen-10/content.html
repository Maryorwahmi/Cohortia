Definition

CVSS in practice

Use CVSS scores to compare technical severity, then translate that into business-prioritized actions using context and exploitability intelligence.

Example
A CVSS 9.8 RCE on production web server → High priority. Add firewall restrictions if immediate patching is delayed.
Misconception
CVSS does not measure business impact. Translate scores into stakeholder-facing risk terms.
Score bands (concept)
9.0 – 10.0: Critical
7.0 – 8.9: High
4.0 – 6.9: Medium
0.1 – 3.9: Low
Key Takeaway

Treat CVSS as a standardized technical baseline, then apply business context and exploitability to prioritize remediation.
