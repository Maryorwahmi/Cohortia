Safety

Rules of Engagement

Define scope, allowed methods, time windows, and emergency contacts before any pen test. For scanning, set throttling and maintenance windows to avoid production impact.

Authorization
Get written approval for all intrusive testing and ensure stakeholders are informed.
Impact mitigation
Throttle scans, test in staging, and prepare rollback plans for updates.
Common mistakes
Failing to verify fixes before closing the ticket.
Ignoring low-severity issues that can be chained into bigger attacks.
Running intrusive scans without coordination.
Operational tip

Track mitigation timelines and escalate when temporary controls become long-term technical debt.
