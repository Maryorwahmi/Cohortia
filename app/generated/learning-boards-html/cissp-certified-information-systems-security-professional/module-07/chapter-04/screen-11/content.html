Process

Remediation & Mitigation

Primary remediation is patching or upgrading. If that is not immediately possible, apply compensating controls that reduce exposure while tracking the issue for permanent resolution.

Primary action
Install vendor patches or apply configuration updates to remove the vulnerability.
Temporary mitigations
Firewall rules, access restrictions, or IPS signatures reduce exploitability until remediation is possible.
Concrete example
OpenSSH weak ciphers
Remediate by upgrading OpenSSH in a staged manner. If immediate upgrade is blocked, restrict access to the jump server and monitor connections.
Key Takeaway

Prefer permanent remediation; use mitigations only as tracked, temporary measures and verify after action.
