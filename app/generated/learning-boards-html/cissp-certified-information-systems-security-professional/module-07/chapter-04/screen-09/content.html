How to prioritize

Use CVSS as a baseline, then layer on exploitability, asset value, and compensating controls to assign response priority and SLA.
Example
CVE-2023-1234, CVSS 9.8 on production web server → Priority: Critical → Immediate remediation.
Counterexample
CVE-2023-7890, default credentials on test DB, CVSS 9.0 → Priority: Lower if isolated and no sensitive data.
Prioritization matrix (concept)
High CVSS + High Asset → SLA: 24–72 hours
High CVSS + Low Asset → SLA: evaluate compensating controls
Medium CVSS + High Asset → SLA: schedule rapid remediation
Low CVSS + Low Asset → SLA: patch in routine cycle
Common mistake

Sorting only by CVSS creates misaligned priorities; always include asset context and exploitability.
