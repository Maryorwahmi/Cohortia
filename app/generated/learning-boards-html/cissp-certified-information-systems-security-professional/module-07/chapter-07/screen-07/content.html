Diverse Sources of Digital Evidence

Where to Look for Critical Clues

Computer Systems

  • Hard drive images, memory dumps
  • Log files (system, application, security)
  • Registry entries, browser history, deleted files

Network Devices

  • Firewall and router logs
  • IDS/IPS alerts
  • Network traffic captures (packet captures)

Mobile Devices

  • Call logs, SMS messages, GPS data
  • Application data
  • Internal storage

Cloud & IoT

  • Cloud: Access logs, activity logs, VM snapshots
  • IoT: Device logs, sensor data
Investigator's Skill

Understanding where to look for relevant evidence is a critical skill for a forensic investigator, as evidence can be highly distributed.
