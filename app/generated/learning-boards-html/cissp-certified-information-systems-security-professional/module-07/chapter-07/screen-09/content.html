Preservation and Collection

Securing the Scene and Acquiring Evidence

Securing the Scene

Prevent further alteration or destruction of potential evidence. This is the most critical phase for maintaining integrity.

Forensic Copies

Create bit-for-bit images of storage devices (e.g., hard drives) and capture volatile memory (RAM) contents.

Key Takeaway

Always work with forensic copies and verify their integrity with hashes to ensure the original evidence remains pristine and admissible.

Terminal Demo: Disk Imaging
# Example: Create a forensic image of a disk
sudo dd if=/dev/sda of=/media/forensic_drive/disk_image.dd bs=4M conv=noerror,sync

# Calculate hash of the image
sha256sum /media/forensic_drive/disk_image.dd

Explanation:

  • dd: Copies raw data from input file (if) to output file (of).
  • if=/dev/sda: Specifies the source disk (e.g., the compromised hard drive).
  • of=/media/forensic_drive/disk_image.dd: Specifies the destination for the forensic image.
  • bs=4M: Sets block size for efficient copying.
  • conv=noerror,sync: Ensures errors are ignored and input blocks are padded to maintain data integrity.
  • sha256sum: Generates a SHA-256 hash to verify the image's integrity.
