Examination and Analysis

Uncovering and Interpreting the Digital Story

Examination Phase

  • Analyzing collected data for relevant information.
  • Techniques: File carving (recovering deleted files), keyword searching, timeline analysis, registry analysis.
  • Goal: Extract all potentially relevant data without drawing conclusions.

Analysis Phase

  • Interpreting examined data to reconstruct events.
  • Identifying malicious activity, root cause, and incident impact.
  • Goal: Piece together the puzzle and form conclusions.
Key Takeaway

Examination is about finding the data, while analysis is about understanding what that data means in the context of the incident.

File Carving

Recovering deleted files from raw disk images by searching for file headers and footers.

Keyword Searching

Locating specific terms, phrases, or patterns within large datasets to find relevant information.

Timeline Analysis

Reconstructing events in chronological order from various log sources to understand the attack progression.

Registry Analysis

Examining Windows Registry entries for evidence of program execution, user activity, and system configuration changes.
