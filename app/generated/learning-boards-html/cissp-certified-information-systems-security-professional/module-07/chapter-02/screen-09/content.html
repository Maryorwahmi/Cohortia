NIST IR Lifecycle

Phase 4: Eradication

Eliminating the Root Cause of the Incident

01

Remove Malware

Thoroughly scan and remove all malicious software from affected systems.

02

Patch Vulnerabilities

Apply security patches and reconfigure systems to close exploited weaknesses.

03

Rebuild/Restore

Rebuild compromised systems from trusted backups or secure images if necessary.

Common Pitfall

Incomplete eradication can leave behind backdoors or unpatched vulnerabilities, leading to a quick re-infection.

Collaboration is Key

This phase often requires close teamwork between the IR team, system administrators, and developers to ensure thoroughness.

Key Takeaway

Eradication is about surgically removing the threat and its root cause, ensuring a clean and secure environment before systems are brought back online.
