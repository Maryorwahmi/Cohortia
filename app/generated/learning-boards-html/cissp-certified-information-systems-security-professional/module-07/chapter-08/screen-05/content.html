Module 7 › Chapter 7.8 › Concentric circles of security

Layered defense explained

Each circle supports the next, creating redundancy and operational depth.

Perimeter

Fences, lighting, guards, boundary cameras and gates.

Building

Hardened doors, main entry readers, alarms, secure windows.

Internal

Mantraps, server-room readers, internal CCTV, rack locks.

Key Takeaway

Design layers so that a breach in one raises detection and response in others.

Scenario

If the perimeter gate is forced, building entry readers should record the time and trigger CCTV focus and guard dispatch. Internal locks and mantraps prevent immediate access to server racks while responders investigate.

Misconception

Layers are not independent backups. They must be integrated operationally so detection at one layer informs increased vigilance at others.

Check

Do your alarms cascade events across systems for coordinated response?

Pro tip

Map your assets and align controls so the most critical assets sit inside the tightest layers.
