Module 7 › Chapter 7.6 › Common Mistakes

Common pitfalls

  • Plans are not tested or restored.
  • DRP developed without linking to BCP.
  • Documentation not updated after changes.
  • Dependencies like vendors and network overlooked.
  • Single backup copy or media type used.
Practical fix
Create a test schedule, assign owners, and require documented proof of successful restores before accepting recovery claims.
Stakeholder involvement
Involve operations, security, facilities, legal, and vendors in planning and testing to expose cross-domain dependencies.
Key Takeaway

Mitigate risk by testing regularly, validating restores, and keeping plans current with assigned ownership.
