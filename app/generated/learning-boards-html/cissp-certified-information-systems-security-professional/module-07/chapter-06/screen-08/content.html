Definition

Backup types and rules

Choose full, incremental or differential backups to meet your recovery point objective while balancing storage and restore time.

Full
Complete data snapshot; fastest to restore but costly in storage and time to create.
Incremental
Saves only changes since last backup; efficient storage but restores may require multiple steps.
Differential
Saves changes since last full backup; restores faster than incremental but uses more storage than incremental.
Key Takeaway

Pick backup types that meet RPO and implement the 3-2-1 rule with encryption and off-site storage.

Practical sync example
rsync -avz --delete /var/www/html/ user@offsite_backup_server:/backups/web_app/
Use secure transport and test restores from the off-site copy.
3-2-1 Rule
Three copies, two different media, one off-site. Apply encryption and physical security to backup media.
Misconception
Having backups does not guarantee recovery without frequent, documented restore tests.
