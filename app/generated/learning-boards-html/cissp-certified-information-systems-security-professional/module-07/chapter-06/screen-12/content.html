Module 7 › Chapter 7.6 › DR/BC Lifecycle
Process

Plan → Implement → Test → Maintain

Each stage has clear deliverables and owners. Use RTO/RPO as acceptance criteria and schedule tests after changes.

Plan
Run a BIA, set RTO/RPO/MTD, and select recovery strategies.
Implement
Deploy backups, replication, and runbooks; document owners and escalation paths.
Test
Execute tabletop, component, and full-scale tests and record measurable outcomes.
Maintenance
Update plans after tests, system changes, or personnel shifts. Keep a change log and re-test significant updates.
Continuous improvement
Treat DR/BC as an ongoing program, not a one-time project. Use test results to prioritize next steps.
