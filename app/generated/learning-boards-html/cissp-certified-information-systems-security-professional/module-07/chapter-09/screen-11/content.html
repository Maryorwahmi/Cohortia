Phishing Awareness Module Outline
A compact, interactive training structure
1. Opening Statement
A brief real-world narrative that sets a supportive tone and explains why reporting matters.
2. Indicators
  • Unexpected sender or domain mismatch
  • Links where the display text differs from the actual URL
  • Urgent credential or payment requests
3. Employee Response
  • Do not click or reply
  • Use the internal report button or forward to security
  • If in doubt, verify by phone using a known contact number
4. Interactive Element
A mini-game where learners pick suspicious elements in a simulated email and receive instant coaching.
Measurement

Track pre/post simulation click rates and use targeted coaching for repeat clicks to show improvement.

Opening Statement (starter)
"Last year a single credential theft led to a costly data recovery. In this module we'll learn simple checks that prevent similar incidents."
