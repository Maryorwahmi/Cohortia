Comparison

Intrusion Detection vs. Prevention Systems

Passive Monitoring vs. Active Blocking

IDS (Intrusion Detection System)

  • •Passive monitoring of network or host activity.
  • •Detects suspicious patterns and anomalies.
  • •Generates alerts for administrators.
  • •Does NOT actively block or prevent traffic.
  • •Deployment: Out-of-band (monitors a copy of traffic).
Example

Detects a port scan and sends an alert to the security team.

IPS (Intrusion Prevention System)

  • •Active monitoring and real-time prevention.
  • •Detects and attempts to block malicious activity.
  • •Can drop packets, reset connections, or block IPs.
  • •Actively prevents attacks from reaching targets.
  • •Deployment: Inline (all traffic passes through it).
Misconception

An IPS can block legitimate traffic if improperly tuned, leading to denial of service.
