Detection Methods

How IDS and IPS Spot Threats

Signature-Based vs. Anomaly-Based Detection

Signature-Based Detection

  • •Compares traffic against a database of known attack patterns.
  • •Highly effective against known threats.
  • •Generates fewer false positives.
  • •Ineffective against unknown or zero-day attacks.
Example

Detects a specific malware hash or a known SQL injection string.

Anomaly-Based Detection

  • •Establishes a baseline of normal behavior.
  • •Identifies deviations from the baseline as suspicious.
  • •Effective against zero-day attacks.
  • •Can generate more false positives.
Challenge

Requires careful tuning to minimize false positives and accurately define 'normal' behavior.
