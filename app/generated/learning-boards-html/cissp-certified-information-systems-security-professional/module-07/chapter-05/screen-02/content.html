Explain Firewall Functions & Types

Understand the core role of firewalls as network gatekeepers and differentiate between packet-filtering, stateful inspection, application-layer, and WAFs. This skill is vital for designing secure network perimeters.

Differentiate IDS & IPS

Distinguish between Intrusion Detection Systems (IDS) and Intrusion Prevention Systems (IPS), including their passive vs. active roles and detection methods. This distinction is crucial for selecting appropriate threat response tools.
