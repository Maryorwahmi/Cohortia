Framework

Confidentiality, Integrity, Availability

Operations use the triad to set priorities: which incidents threaten which aspect and what immediate action minimizes risk.

Confidentiality
Prevent data exposure. Example: block exfiltration attempts and rotate compromised credentials.
Integrity
Ensure data hasn’t been altered. Example: validate checksums and restore clean copies when integrity is broken.
Availability
Keep services running. Example: failover to backups and run disaster recovery procedures.
Scenario
Ransomware affecting database: availability and integrity are impacted. Response may prioritize restoring availability while preserving forensic traces for integrity analysis.
Operational Checklist
  • Assess which CIA element is at greatest risk.
  • Choose containment or restoration actions aligned to that priority.
  • Preserve evidence if investigation is needed.
  • Communicate with stakeholders about availability impact and timeline.
Misconception
Treating one element as always primary; priorities shift based on the incident and business needs.
