Module 7 › Chapter 7.1 › Incident Response
Process

Containment → Eradication → Recovery

Containment
Stop the active threat to limit damage — e.g., isolate hosts and block malicious IPs.
Eradication
Remove malware and close exploited vulnerabilities.
Recovery
Restore services from validated backups and monitor for re-infection.
Evidence Preservation
Follow playbooks that specify how to collect logs and images before making destructive changes.
Lessons Learned
Capture root cause and update detection rules and playbooks so the incident is less likely to recur.
Key Takeaway
Response must balance rapid mitigation with careful evidence preservation and a clear path to restore secure operations.
