Hierarchy

Common SOC roles and what they do

Tier 1
Initial triage, validate alerts, handle routine incidents, escalate when needed.
Tier 2
Deep investigation, correlation across systems, containment plans.
Incident Responder
Leads containment, eradication and recovery, preserves evidence.
Threat Hunter
Proactively searches for stealthy adversary activity using hypotheses.
Security Engineer
Maintains tooling, detection rules, and remediation automation.
Concrete Example
A suspicious outbound data stream: Tier 1 flags, Tier 2 confirms exfiltration, incident responder coordinates containment, engineers patch and reconfigure controls.
Common Mistake
Escalating everything to incident response wastes specialist time; effective triage reduces burden.
Key Takeaway
Define role boundaries so routine alerts are handled quickly and specialists focus on complex incidents.
