Comparison

Preventative vs Detective vs Corrective

Preventative
Stops incidents: firewalls, MFA, access controls, training.
Example: firewall blocks unauthorized VPN access.
Detective
Finds incidents: IDS, SIEM, log analysis, vulnerability scans.
Example: IDS alerts on suspicious packet patterns.
Corrective
Remediates and restores: incident response, backups, DR plans.
Example: restore from backup after compromise.
Operational Example
A vulnerability scan (detective) finds missing patches; engineers patch systems (corrective); future exposure is reduced by updated configuration and patch automation (preventative).
Misconception
Believing one control type is sufficient. Effective security combines all three in a layered strategy.
