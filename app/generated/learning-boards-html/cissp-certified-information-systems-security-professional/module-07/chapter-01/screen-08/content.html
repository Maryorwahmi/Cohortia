Module 7 › Chapter 7.1 › Tiered Alert Workflow
Process

Alert flow: Triage → Analyze → Respond

A clear triage workflow reduces false positives and makes sure responders handle true incidents efficiently.

Tier 1
Validate alerts, enrich context, and escalate per playbook.
→
Tier 2
Deep analysis, cross-system correlation, and containment recommendations.
→
Incident Response
Lead containment, eradication, and restore operations.
Example
Suspicious process on server: Tier 1 flags, Tier 2 correlates network and auth logs, incident response isolates host and coordinates restore if compromise confirmed.
Checklist for Escalation Rules
  • Preserve forensics if escalation is possible.
  • Define evidence thresholds for auto-escalation.
  • Document who must be notified at each level.
  • Review and tune rules monthly to avoid fatigue.
Key Takeaway
Escalation criteria must balance speed with evidence quality so response teams act decisively and efficiently.
