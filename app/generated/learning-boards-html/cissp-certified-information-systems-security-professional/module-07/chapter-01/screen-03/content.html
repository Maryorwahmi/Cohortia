Alert List
A: Multiple failed VPN logins; B: High outbound traffic; C: New critical vulnerability; D: Off-hours access to HR records; E: Firewall rule changed.
Use the template in the chapter to record control type, assigned role, justification, and preliminary action.
Tip
When deciding role assignment, prefer Tier 1 for triage, Tier 2 for deeper technical analysis, incident responders for active containment, and security engineers for remediation actions that change infrastructure.
Key Takeaway
Practical triage skills reduce response time and ensure specialists focus on tasks that need their expertise.
