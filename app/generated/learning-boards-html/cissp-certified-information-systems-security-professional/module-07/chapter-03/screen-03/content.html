Verified Competency Milestones

Short, specific tasks to demonstrate each learning objective in practice.

01
Reconstruct an incident timeline
Given a suspected compromise, list the minimum logs and timestamps you would collect for a forensic timeline and justify each selection.
VERIFIED COMPETENCY MILESTONE
02
Classify sample log lines
Sort five example log lines into the correct log type and explain which fields led to your choice.
VERIFIED COMPETENCY MILESTONE
03
Design a SIEM correlation
Draft a rule that correlates failed logins, a geographically improbable successful login, and a large outbound transfer to flag a credential compromise.
VERIFIED COMPETENCY MILESTONE
04
Draft retention and integrity rules
Create a short retention table for three log types and list at least two integrity controls you would implement to prevent tampering.
VERIFIED COMPETENCY MILESTONE
