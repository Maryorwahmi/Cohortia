Module 7 › Chapter 7.3 › How a SIEM works

SIEM process

01
Collection
Agents, syslog, API pulls gather logs from across the environment.
02
Normalization
Map different formats to a common schema so events can be compared and correlated.
03
Correlation & Analytics
Link events across sources and time to detect patterns and anomalies.
04
Alerting & Reporting
Notify analysts, provide context for triage, and generate compliance reports.
Concrete correlation example
A SIEM rule correlates multiple failed authentication events, a successful login from a new country, and a large outbound transfer within a short window. When combined these signals indicate possible credential compromise and data exfiltration.
Misconception
SIEMs are not automatic truth detectors. They require correct data sources, field mappings, and tuned rules to avoid false positives and missed detections.
Key Takeaway

Treat SIEM as a pipeline: input quality and continuous tuning determine whether alerts are reliable and investigation-ready.
