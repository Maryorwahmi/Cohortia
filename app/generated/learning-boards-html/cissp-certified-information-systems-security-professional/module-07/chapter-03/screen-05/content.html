Module 7 › Chapter 7.3 › Types of logs
System Logs
Operating system events like service start/stop, boot messages, and system errors. Use them to detect host compromise and confirm configuration changes.
Application Logs
Application-specific events: user actions, API calls, and internal errors. They provide context about what users or services were doing.
Network Logs
Traffic and device logs from firewalls, routers, and flow collectors. Ideal for tracking connections, blocked traffic, and large transfers.
Security Logs
Alerts and telemetry from EDR, antivirus, authentication systems. These logs are targeted for threat detection and response workflows.
Example scenario: an alert for possible credential theft. Security logs show failed and successful logins; application logs show the account accessed a sensitive record; system logs show an unexpected process spawn on the host; network logs show a large outbound transfer. Only by pivoting across these types do you get a complete picture.
