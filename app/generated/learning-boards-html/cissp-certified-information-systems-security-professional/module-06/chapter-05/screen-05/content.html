Log categories
Each category answers different investigative questions.
System Logs
Operating system events: logons, service failures, startup/shutdown, and system errors.
Application Logs
Application-specific activity: user transactions, errors, and data access records.
Network Device Logs
Firewall and switch logs that record connections, blocks, and traffic patterns.
Security Logs
Alerts and events focused on security activity, often overlapping other categories.
Example
A web server access log shows source IP, requested URL, and response code. System logs on the web host show the user account used by the process. Firewall logs show whether the external IP was blocked or allowed.
Common mistake
Treating a single log source as sufficient. Correlation across sources provides context and reduces false conclusions.
Key Takeaway

Collect multiple log types to answer who, what, and how — no single log gives a complete picture.
