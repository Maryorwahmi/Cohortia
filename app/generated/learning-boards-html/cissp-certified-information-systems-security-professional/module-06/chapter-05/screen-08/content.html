Suspicious patterns to identify
  • Multiple DENY entries to SSH (port 22) from the same source in seconds — possible brute-force.
  • Multiple DENY entries to RDP (port 3389) from a single source — another likely brute-force pattern.
Recommended investigation steps
  1. Check logs on the source IP for signs of compromise or automated tools.
  2. Review destination host authentication logs for failed and successful logins.
  3. Consider temporary firewall blocking if malicious activity persists after analysis.
Common-mistake

Blocking immediately without investigation can disrupt business traffic. Start with analysis, then block if confirmed malicious.
