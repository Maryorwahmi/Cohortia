Web server access log (simplified)
192.0.2.10 - - [26/Oct/2023:09:00:01 +0000] "GET /sensitive/report.pdf HTTP/1.1" 200 124560 "-" "Mozilla/5.0"
192.0.2.11 - - [26/Oct/2023:09:05:10 +0000] "POST /login HTTP/1.1" 401 560 "-" "curl/7.68.0"
What to check
  • Source IP and user agent to identify clients.
  • Requested URL and response code to detect successful data retrievals.
  • Timestamp alignment with system logs to correlate access to accounts or processes.
Best practices
  • Structure logs (JSON) where possible to simplify parsing and correlation.
  • Include user identifiers and request context in application logs.
  • Forward to a central store and normalize fields for analysis.
Key Takeaway

Application logs give you the transaction-level evidence required to prove who did what inside an application.
