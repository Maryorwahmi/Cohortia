Module 6 › Chapter 6.5 › IDS vs IPS
Intrusion Detection System (IDS)
Monitors traffic or host activity and generates alerts without blocking traffic.
Types & methods
  • Network-based IDS (NIDS) watches network segments for signatures or anomalies.
  • Host-based IDS (HIDS) monitors file changes, system calls, and local logs.
  • Detection by signature or anomaly; signatures are precise, anomaly detects unknowns but may false alarm.
Intrusion Prevention System (IPS)
Performs detection and can block malicious traffic in-line to stop attacks in real time.
Deployment notes
  • NIPS sits inline with traffic and can drop packets or reset connections.
  • HIPS runs on endpoints to block host-based attacks.
  • Risk: false positives can block legitimate traffic; tune rules in detection-only mode first.
Pro tip

Start prevention devices in detection-only mode, tune rules using real traffic, then enable blocking to avoid service disruption.
