Module 6 › Chapter 6.6 › Correlation
What correlation does

It analyzes normalized events and applies rules that identify multi-step attack patterns or risky conditions that single events cannot reveal.

Example pattern
Failed login attempts → successful login from same IP to another host → large outbound transfer = suspicious multi-step chain.
Misconception
More rules are not always better; unfocused rules generate false positives and overwhelm analysts.
Design tips
  • Include context like user role and asset criticality to improve precision.
  • Use reasonable time windows and count thresholds to balance sensitivity and noise.
  • Test rules on historical data and iterate based on analyst feedback.
Key Takeaway

Correlation uncovers attack sequences; design rules with context, test them, and tune to reduce false positives.
