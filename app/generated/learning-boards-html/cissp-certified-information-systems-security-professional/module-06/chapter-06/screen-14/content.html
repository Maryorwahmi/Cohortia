Lab steps
  1. Define the insider exfiltration scenario you want to detect.
  2. Identify log sources: EDR (file access, USB), DLP (transfer attempts), Firewall (outbound connections).
  3. Specify sequence and time window (e.g., 5 minutes) and contextual filters (user role, asset class).
  4. Implement rule in SIEM and test with historical data.
  5. Tune thresholds, add allow-lists, and document the playbook and dashboard widget.
Example solution outline
Condition 1: EDR File_Access of classified file by user X.
Condition 2: DLP Sensitive_Data_Transfer_Attempt by user X to external destination.
Condition 3: Firewall Outbound_Connection from same host/IP shortly after.
Time window: All within 5 minutes. Trigger: High severity alert, create incident and notify SOC.
Key Takeaway

Design rules with explicit sequence, shared identifiers, and a time window. Test and tune using historical logs to avoid noisy alerts.
