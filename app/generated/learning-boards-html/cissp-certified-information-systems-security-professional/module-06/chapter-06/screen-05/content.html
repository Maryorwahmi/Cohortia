Module 6 › Chapter 6.6 › Data Collection
Common data sources
  • Operating Systems: Windows event logs, Linux syslog.
  • Applications: Web servers, databases, ERP systems.
  • Network Devices: Firewalls, routers, switches via syslog.
  • Security Tools: IDS/IPS, EDR, DLP.
  • Cloud Services: Audit logs and APIs.
Practical example
To detect compromised credentials, collect authentication logs from identity systems, domain controllers, and cloud providers, plus EDR telemetry to confirm subsequent activity on endpoints.
Collection methods
Agents: detailed telemetry from endpoints and servers.
Syslog: standardized stream for network devices and some apps.
API pulls: cloud and SaaS apps that provide structured logs.
SNMP and streaming telemetry for device metrics when needed.
Tip
Ensure clocks are synchronized across sources so correlation windows are reliable.
Common mistake
Onboarding everything at once without prioritization creates storage strain and noise; phase sources by use-case value.
