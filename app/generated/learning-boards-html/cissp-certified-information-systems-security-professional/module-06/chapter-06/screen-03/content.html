Micro-tasks
  • Select first logs: Authentication logs, critical server logs, and EDR telemetry are high-value starting points.
  • Author a rule: Combine EDR file access, DLP transfer attempts, and firewall outbound connections to flag exfiltration.
  • Tune: Add time windows, asset classification, and user roles to reduce noise.
  • Dashboard task: Build a widget that shows recent high-severity correlated alerts and top alerting users.
Quick mnemonic
Think C-A-N-C: Collect, Aggregate, Normalize, Correlate.
