Definition
Software Composition Analysis
Scan dependency manifests and match components to known CVEs.
Why it matters
Open-source vulnerabilities in libraries can expose applications even when their own code is secure.
Common pitfall
Ignoring transitive dependencies and not automating continuous checks.
Key Takeaway

Treat dependency inventory as a continuous activity and prioritize fixes based on exploitability and severity.

Practical example
# Example: Using npm audit for SCA in a Node.js project # Navigate to your project directory cd my-nodejs-app npm audit --production # This command checks your project dependencies for known vulnerabilities # and provides recommendations for remediation.
Run the package manager's audit or a dedicated SCA tool in CI to continuously detect and triage vulnerable components.
