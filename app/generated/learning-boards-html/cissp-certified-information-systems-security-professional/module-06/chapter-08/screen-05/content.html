Definition
Static Analysis
Parse code, build syntax tree, apply rules to flag risky patterns.
Common detections
  • Hardcoded credentials and secrets
  • Unsafe string concatenation in queries
  • Use of insecure functions
Common mistake
Treating all SAST findings as actionable. Triage is necessary to avoid developer fatigue.
Key Takeaway

Integrate SAST early and combine with review to convert reports into targeted fixes.

Code Example — insecure query (illustrative)
// Java example: vulnerable string concatenation String query = "SELECT * FROM users WHERE id = '" + userInput + "'"; Statement stmt = connection.createStatement(); ResultSet rs = stmt.executeQuery(query); // SAST would flag use of concatenated userInput and recommend prepared statements
SAST flags the concatenation and points to the line to change to a parameterized query. This gives the exact file and line where remediation is required.
