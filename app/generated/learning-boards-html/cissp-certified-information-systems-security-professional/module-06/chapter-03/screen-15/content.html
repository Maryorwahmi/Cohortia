Module 6 › Chapter 6.3 › Key Concepts
Penetration Test
A simulated attack that proves real impact.
Phases
Recon → Scan → Exploit → Maintain → Cover → Report.
Reporting
Evidence-backed, prioritized recommendations for remediation.
Summary

Pen tests must be authorized, methodical, and documented. Tools are important but safe execution, clear scope, and high-quality reporting create real value.
