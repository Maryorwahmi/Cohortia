Common exploitation techniques
  • Exploit unpatched services and known CVEs that match discovered versions.
  • Perform SQL injection or XSS tests on web inputs where allowed.
  • Use credential attacks or misconfiguration exploitation when appropriate.
Conceptual Metasploit flow
# Conceptual Metasploit steps (sequence only)
# msfconsole
# search 
# use 
# set RHOSTS 192.168.1.100
# set PAYLOAD 
# set LHOST 10.0.0.5
# exploit
This example shows the conceptual commands used to find and run an exploit; live testing must follow ROE and safety steps.
Post-success considerations

If exploitation succeeds, document exactly what was done, capture evidence, and follow the client's agreed behavior about maintaining access or stopping the test.

Common mistake

Failing to document live commands and outputs makes the report unverifiable; always capture reproducible evidence.

Key Takeaway

Exploitation must be controlled, documented, and aligned with the ROE to be useful and safe.
