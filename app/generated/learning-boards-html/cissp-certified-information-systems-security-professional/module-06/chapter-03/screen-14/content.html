Exploit chain phases
Phase 1 — Initial Access

Technique: SQL injection to bypass login. Tools: Burp Suite Repeater or SQLMap. Objective: reach admin panel.

Phase 2 — Post-Exploitation

Technique: Upload web shell via weak file validation. Tools: browser + Burp Proxy. Objective: persistent command execution.

Phase 3 — Impact

Technique: Trigger web shell to execute commands. Tools: netcat or terminal listener. Objective: demonstrate control and data access.

Documentation

For every step, capture command lines, timestamps, and proof artifacts so the chain is reproducible and defensible.

Safety

Confirm ROE allows these actions and prepare rollback steps and emergency contacts before testing.

Key Takeaway

A reproducible exploit chain demonstrates real risk and supports targeted remediation; document every step and follow ROE safety rules.
