Module 6 › Chapter 6.3 › Tools
Tool roles
Nmap
Network discovery and port/service enumeration; informs exploit selection.
Metasploit Framework
Exploit repository and execution environment for controlled exploitation and post-exploitation modules.
Burp Suite
Web application testing platform for proxying, scanning, and manipulating requests.
Supporting tools
Wireshark
Capture and analyze packets to confirm behaviors or exfiltration paths.
Kali Linux
Preconfigured distribution that centralizes many penetration testing tools for convenience.
Workflow tip

Document tool versions and commands used for each finding so engineers can validate and reproduce tests accurately.

Key Takeaway

Use the right tool for the phase and always record versions and invocation details for reporting.
