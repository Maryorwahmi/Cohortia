Reconnaissance — Goals
  • Identify hosts, services, and public assets relevant to scope.
  • Gather service versions and configuration clues to suggest exploits.
  • Compile prioritized targets for focused scanning and exploitation.
Passive OSINT

Public records, DNS, certificates, and social media can reveal subdomains and administration details without touching the target directly.

Active discovery

Targeted port and banner grabs yield service versions and reachable endpoints for follow-up testing.

Example: Recon outputs
Artifact

Nmap service banners showing an outdated web server version that may correspond to known exploits.

Practical note

Document sources and timestamps of recon data so results can be validated if the client questions findings later.

Key Takeaway

Recon builds your hypothesis about weak points. Keep it targeted and documented to stay within scope.
