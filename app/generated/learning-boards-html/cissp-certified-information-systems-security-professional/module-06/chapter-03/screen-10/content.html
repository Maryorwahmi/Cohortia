Module 6 › Chapter 6.3 › Testing Approaches
Black-box

No prior internal knowledge. Simulates an external attacker; good for realistic external assessments.

Pros: Realism. Cons: Time-consuming.
Gray-box

Partial knowledge, such as user-level credentials. Balances realism and efficiency for targeted scenarios.

Pros: Focused. Cons: May miss external blind spots.
White-box

Full knowledge including code and diagrams. Efficient for deep analysis of logic flaws and configurations.

Pros: Thorough. Cons: Less external realism.
Choose by objective

Select approach based on what you need to prove: outsider risk, insider risk, or deep code flaws.

Report context

Always state the approach in the report so stakeholders interpret findings correctly.

Misconception

Different approaches are complementary; combine them across assessments for best coverage.
