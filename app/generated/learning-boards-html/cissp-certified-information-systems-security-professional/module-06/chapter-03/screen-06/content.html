Module 6 › Chapter 6.3 › Scanning
Focus of scanning
  • Find open ports and running services with version details.
  • Use focused scripts and fingerprinting to reduce false positives.
  • Record outputs and command lines for reproducibility and reporting.
Example Nmap command
# Example: Basic Nmap scan for open ports and service versions
nmap -sV -p 1-1000 192.168.1.100
This command enumerates service versions on common ports; adjust scope and timing according to ROE.
Practical tip

Use output formats that are easy to archive and share with engineers, such as XML or grepable output, for the final report.

Triage and next steps

After scanning, rank findings by exploitability and business impact. Choose 2–3 high-confidence targets for controlled exploitation and document why each was selected.

Key Takeaway

Scans convert recon into concrete exploit candidates; record commands and outputs to support reproducible testing and reporting.
