Parameters to set
  • Target: IP address or range (example: 192.168.1.100).
  • Credential: SSH username/password for Linux, SMB for Windows.
  • Scan config: Full and Fast or custom plugin set.
  • Schedule: daily, weekly, or on-demand.
Test credentials and use least-privilege accounts to reduce risk.
