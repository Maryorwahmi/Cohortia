Hands-on Lab
Step-by-step
  1. Add target: IP or range and label asset.
  2. Add credential: SSH username/password or key; test auth.
  3. Create task: select scan config and schedule.
  4. Run scan and filter results by severity.
  5. Verify a sample finding via SSH and record evidence.
  6. Create remediation ticket and re-scan to validate fix.
