Process Flow
Five-step remediation flow
1. Identify
2. Verify
3. Prioritize
4. Remediate
5. Re-scan
Example: identify a High CVE on a web server, verify by checking the package manager, prioritize because the server is public-facing, patch the package in staging, then re-scan production after deployment.
Common mistake: skipping verification.
Pro tip: include compensating controls when patching is delayed.
Check your understanding: will you re-scan immediately after a hotfix or wait for scheduled scans?
