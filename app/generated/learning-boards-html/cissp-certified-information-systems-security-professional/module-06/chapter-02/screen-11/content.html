Process Flow
Three-factor priority
Use three factors to score each finding: Technical Severity, Exploitability, and Asset Criticality.
Technical Severity (CVSS or scanner)
Exploitability: ease and availability of exploit code
Asset Criticality: business impact if compromised
Example
Vulnerability on public web server: High severity + easy exploit + high criticality = immediate priority. Same severity on internal dev server: lower priority.
Key Takeaway

Score against technical and business factors and document the rationale for each prioritized action.
