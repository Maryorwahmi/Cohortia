Definition
True vs False Positives
True positives indicate real vulnerabilities. False positives are incorrect alerts. Both affect how you allocate remediation effort.
  • Verify high-impact findings manually to confirm true positives.
  • Document false positives and tune scanner configuration to reduce repetition.
  • Use verification evidence when closing or deprioritizing findings.
Verification checklist
  1. Log into host and check package/version.
  2. Review service configuration for enabling conditions.
  3. Record evidence and mark finding accordingly.
Pro tip

Tune plugin sets after verification to reduce noise and improve future scan quality.
