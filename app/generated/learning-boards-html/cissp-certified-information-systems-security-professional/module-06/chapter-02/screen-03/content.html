Module 6 › Chapter 6.2 › Learning Objectives
Hands-on outcomes
  • Configure a scan target and add SSH or SMB credentials for deeper inspection.
  • Schedule and run a credentialed scan and observe how findings differ from non-credentialed results.
  • Filter and prioritize a report, then verify a sample finding by logging into the host.
Mnemonics
Use the simple priority formula: Severity + Exploitability + Asset Criticality = Remediation Priority.
Verified competency
You'll demonstrate the ability to correctly rank the provided sample vulnerabilities and justify each choice based on business context.
