Definition
Severity and CVSS
Reports categorize findings and often reference CVSS base scores. Use CVSS as a technical indicator, not a sole decision maker.
  • Consider exploitability: how easy is it to exploit this finding?
  • Consider asset criticality: what does the system support for the business?
  • Consider compensating controls: WAFs, segmentation, or monitoring that mitigate risk.
Detecting false positives
Verify by logging in, checking patch levels, and confirming configuration before raising high-effort remediation work.
Key Takeaway

Treat scanner output as a starting point: verify, prioritize, and then remediate with follow-up scans to confirm success.
