Comparison
Non-Credentialed Scan
Simulates an external unauthenticated attacker. Detects services, banners, and externally visible misconfigurations.
  • Good for perimeter checks and public exposure assessments.
  • May miss host-level misconfigurations and missing patches.
  • Lower risk to target; minimal authentication required.
Common mistake: using this alone for internal security.
Credentialed Scan
Runs with authenticated access to inspect files, installed software, permissions, and patch levels for a deeper view.
  • Recommended for internal servers and compliance checks.
  • Finds issues invisible to external scans, such as missing patches and weak file permissions.
  • Requires secure credential storage and least-privilege accounts.
Best practice: run both types regularly and compare results.
