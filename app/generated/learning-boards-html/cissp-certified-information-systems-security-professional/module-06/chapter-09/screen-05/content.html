Module 7 › Chapter 6.9 › Assessment Methods
Method sequence
Choose methods by vendor criticality and data sensitivity.
01
Security Questionnaires
Baseline, cost-effective, but self-attested and sometimes incomplete.
02
Independent Audit Reports
SOC and ISO provide external assurance; Type 2 reports show operating effectiveness over time.
03
On-site Audits
Deep verification of controls and processes; resource intensive but high assurance.
04
Technical Reports & Monitoring
Pen tests, vulnerability scans, and continuous monitoring reveal technical exposure over time.
Example workflow
For a vendor handling PII: start with a questionnaire, request a SOC 2 Type 2, review recent penetration test results, and enable continuous monitoring if cloud-hosted.
Pro tip
Tailor questionnaires to capture evidence references, dates, and links to full audit documents rather than accepting generic answers.
Pitfall

Do not treat a questionnaire as conclusive for high-risk services; always seek independent evidence where risk is high.
