Module 7 › Chapter 6.9 › Cloud Shared Responsibility
Shared responsibility overview
Understand which layers are provider-managed and which are customer-managed across service models.
IaaS
Provider: physical infra and virtualization. Customer: OS, apps, data, identity.
PaaS
Provider: platform and runtime. Customer: apps, data, and some configs.
SaaS
Provider: application and platform. Customer: user access, data classification, integration settings.
Assessment checklist
  • Review provider certifications and SOC reports for platform controls.
  • Validate your own cloud configurations with CSPM and configuration audits.
  • Confirm log forwarding, retention, and incident notification clauses contractually.
Pro tip
Require that the vendor notify you of cloud incidents and provide evidence of remediation timelines; include these clauses in the contract.
