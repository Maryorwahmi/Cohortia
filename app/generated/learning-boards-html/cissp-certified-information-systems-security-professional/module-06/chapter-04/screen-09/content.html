Module 6 › Chapter 6.4 › Audit Criteria: ISO/IEC 27001 and NIST CSF
Comparison

ISO 27001 vs NIST CSF

ISO 27001 supports certification of an ISMS; NIST CSF provides voluntary functions for risk management and control mapping.

ISO/IEC 27001
Audit verifies documented ISMS, risk assessment, control implementation, and continual improvement evidence.
NIST CSF
Framework maps controls to Identify, Protect, Detect, Respond, Recover; useful as audit criteria but not a certification in all cases.
Practical use

Select criteria that match stakeholders: ISO for certification and external assurance, CSF for internal risk alignment and control mapping.

Example mapping

Map a control such as access control to NIST CSF Protect function and to ISO 27001 annex controls to create audit test steps.

Misconception

Assuming a framework alone provides security. Frameworks guide audits, but implementation quality determines security outcomes.

Key Takeaway

Choose criteria that align with your audit objective and stakeholders. Use mapping to convert framework requirements into testable evidence steps.
