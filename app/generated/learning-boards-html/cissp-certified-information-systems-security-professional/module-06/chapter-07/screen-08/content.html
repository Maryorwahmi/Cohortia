Containment

Stop the spread

Select containment actions that reduce impact while preserving the forensic trail and volatile evidence.

Short-term
Isolation, firewall blocks, disable accounts to immediately limit spread.
Long-term
Network segmentation and architectural changes to prevent recurrence.
Concrete scenario

If a server shows active data exfiltration, capture memory and network traffic, then isolate the host or block the destination. Recording each action ensures subsequent forensic analysis remains valid.

Pro tip

Prefer containment steps that are reversible where possible and document why irreversible actions were necessary.
