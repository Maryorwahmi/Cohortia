Preparation

Build capability

Define policies, train the team, procure tools, and create runbooks so responses are repeatable and defensible.

Runbooks
Step-by-step actions for common incidents to avoid ad hoc decisions.
Tools & Workflows
Forensic workstations, write blockers, logging, and secure communications.
Example Runbook excerpt
  • Verify alert authenticity and assign incident ID.
  • Preserve volatile data: capture memory image before reboot.
  • Image disks with write blocker and verify hashes.
  • Isolate host from network and notify stakeholders.
Common mistake

Waiting to procure tools and test runbooks until after an incident results in slower containment and lost evidence.
