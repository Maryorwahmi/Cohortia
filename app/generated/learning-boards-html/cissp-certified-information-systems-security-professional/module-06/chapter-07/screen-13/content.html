Forensics

Preserve, verify, and analyze

Work on copies, compute hashes, maintain chain of custody, and use appropriate tools for disk, memory, and log analysis.

Disk imaging
Create bit-for-bit copies with a write blocker and record hashes for integrity verification.
Memory analysis
Capture RAM early to preserve volatile processes and network connections for analysis.
Imaging example
# BE EXTREMELY CAREFUL: dd can overwrite disks if used incorrectly
# Create a forensic image of a disk
dd if=/dev/sda of=/mnt/forensics/disk_image.dd bs=4M conv=noerror,sync status=progress
# Calculate a SHA-256 hash of the image
sha256sum /mnt/forensics/disk_image.dd
Safety notes

Always image originals using a write blocker, record original and image hashes, and work on copies only. Log all actions in the chain of custody.
