Eradication

Remove attacker access

Patching, malware removal, credential changes, and rebuilding compromised systems are common eradication actions.

Validation
Confirm that persistence mechanisms are removed and access vectors are closed.
When to rebuild
If integrity is uncertain, rebuild from trusted backups rather than attempting in-place cleanups.
Example

After malware removal, patch the exploited service, rotate credentials, and run integrity checks. If evidence shows attacker-created tasks, rebuild from a verified backup to ensure no hidden backdoors remain.

Misconception

Eradication is not complete until you validate that the attacker cannot return; visible cleanup is not enough without validation.
