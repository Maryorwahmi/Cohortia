Detection & Analysis

Turn alerts into answers

Confirm incidents, determine scope, and prioritize response using logs, endpoint data, and network captures.

Sources
SIEM, IDS, endpoint protection, logs, and user reports.
Triage actions
Validate alerts, assign severity, preserve evidence, and document findings.
Concrete example

A SIEM alert for unusual outbound connections triggers log review. Analysts confirm a database backup file was exfiltrated via an unusual destination IP, capture packet data, and mark systems for containment. Documentation starts immediately so subsequent containment steps do not break evidence integrity.

Misconception

Not every alert is an incident. Use triage rules to avoid chasing false positives while ensuring true incidents are prioritized.
