Module 6 › Chapter 6.1 › Test Types
Common test categories
Discovery — automated scanning to find known vulnerabilities across many assets.
Validation — manual or focused checks to confirm whether a finding is real and exploitable.
Demonstration — simulated attacks to illustrate impact and attack paths for critical systems.
Key Takeaway

Match the test to the decision it must support: broad discovery, focused validation, or impact demonstration.

Example workflow
1. Build asset inventory. 2. Run non-intrusive scans. 3. Validate high-severity findings. 4. Plan penetration testing only for critical systems with authorization.
Pitfall: launching penetration testing across unknown assets without clearly excluding critical production servers.
Reflection
For the next test you plan, what decision will the results enable: remediation prioritization, control validation, or compliance evidence?
