Exercise: ROE snippet
Fill in a concise ROE for a non-intrusive internal vulnerability scan using the provided context.
---
InnovateTech Solutions - Vulnerability Assessment ROE
1. Assessment Type: Internal Vulnerability Scan (non-intrusive)
2. Scope: IP Range 192.168.1.0/24; workstations, file servers, and non-critical network devices within range
3. Out-of-Scope: Production database server 192.168.1.10; HR application server 192.168.1.15
4. Denial-of-Service: Prohibited
5. Social Engineering: Prohibited
6. Permitted Hours: Monday-Friday, 9:00 AM - 5:00 PM local time
7. Reporting: Initial findings due 3 days after scan completion
8. Emergency Contact: IT Manager (name/phone)
---
Review checklist
Is scope explicit? Are critical systems excluded? Are prohibited actions clearly listed? Is an emergency contact provided?
Key Takeaway

A clear ROE prevents mistakes and reduces legal risk; make authorization and scope explicit before testing.

Exercise hint
Avoid phrases like "critical systems" without listing them. Prefer exact IP addresses or hostnames to reduce ambiguity.
Misconception
Scanning is harmless — even non-intrusive scans can affect fragile systems. Always confirm scope and exclusion lists with business owners.
