Module 4 › Chapter 4.6 › DoS vs DDoS
Core Concept
DoS vs DDoS
Origin matters: single attacker versus many coordinated sources.
Volume-based
Overwhelm bandwidth with floods like UDP or ICMP.
Protocol
Exploit protocol state, e.g., SYN floods consuming connection tables.
Application-layer
Target specific application functions, such as HTTP floods or slow-request techniques.
Visual comparison
Single-source DoS
May be blocked by simple IP filtering; often lower scale and easier to trace.
Distributed DoS (DDoS)
Requires rate limiting, scrubbing, or CDN distribution because of many source addresses and high volume.
Key Takeaway

Determine whether an incident is distributed and which layer is targeted to choose the correct mitigation path.
