Module 4 › Chapter 4.6 › ARP Spoofing
Definition
ARP spoofing / ARP poisoning
Forged ARP replies convince devices to send traffic to the attacker's MAC address.
Example detection: duplicate IP entries with different MACs in an ARP capture for the gateway's IP.
Mitigations: static ARP for critical hosts, Dynamic ARP Inspection on managed switches, and TLS/SSH to protect content.
Misconception: encryption is optional; in truth, encryption is required to protect payloads even if ARP protections fail.
Packet analysis checklist
Apply an ARP display filter and sort by IP to find multiple MAC claims for the same IP address.
Look for unsolicited ARP replies and frequent MAC changes for a single IP, especially the gateway.
# Wireshark example filter
arp
# Then sort by 'ARP Sender IP address' and inspect differing 'Sender MAC address' values
Key Takeaway

Prevent local interception with ARP validation and always encrypt sensitive traffic so interception yields no usable data.

Pro tip
Use DHCP snooping bindings to strengthen Dynamic ARP Inspection so it only accepts ARP replies for known leases.
