Module 4 › Chapter 4.6 › DNS Spoofing
Definition
DNS spoofing / cache poisoning
Forged DNS responses cause resolvers to cache incorrect mappings and redirect users.
Example: a poisoned cache maps a legitimate domain to an attacker-owned IP, sending clients to a fake site.
Defense: DNSSEC signs records so resolvers can verify authenticity before accepting them into cache.
Operational: monitor DNS record changes and limit who can make updates to authoritative servers.
Practical notes
DNSSEC requires key management and validation at resolvers; ensure rollovers are tested so clients continue to resolve names reliably. Don’t treat DNS security as only a DNS admin task—coordinate with certificate and web teams to ensure end-to-end trust.
Key Takeaway

Protect name resolution with DNSSEC and strict certificate validation to prevent redirection and impersonation attacks.
