Module 4 › Chapter 4.6 › Mitigations
Controls
Mitigation toolbox
Rate limiting: throttle per IP or session to reduce abusive request rates.
Ingress/Egress filtering: drop packets with forged sources to reduce spoof-based attacks.
SYN cookies & protocol hardening: avoid allocating state until handshake completes.
CDN / Scrubbing services: offload and filter large-scale volumetric attacks.
Decision guide
  1. Confirm attack class with flow and packet samples.
  2. Apply protocol hardening and per-source throttles for protocol or application faults.
  3. If link capacity is saturated, route traffic through a scrubbing provider or enable CDN edge filtering.
Key Takeaway

Match control to attack scope: local protocol fixes for small incidents, external scrubbing for volumetric threats.
