Module 4 › Chapter 4.6 › DDoS Categories
Process Flow
Classify and detect
  1. Step 1: Establish baseline metrics—bandwidth, concurrent sessions, and request rates.
  2. Step 2: Identify anomalies—large volume spikes suggest volumetric attacks; excess half-open sessions suggest protocol abuse; targeted endpoints suggest application attacks.
  3. Step 3: Collect flow logs and packet samples for signature analysis before making blocking decisions.
Indicators
Volume clues
High bits-per-second, many small packets, international distribution of sources.
Protocol clues
Excess half-open TCP sessions, rapid SYNs without completes.
Application clues
High request rate to a single API or many slow HTTP requests that exhaust worker threads.
Key Takeaway

Use evidence from flow and packet captures to choose focused mitigations before broad blocks that may harm legitimate traffic.
