Module 4 › Chapter 4.6 › MAC Spoofing
Core Concept
MAC spoofing
Spoofed MAC addresses allow impersonation or bypass of MAC-based policies.
Controls: port security, 802.1X, and strict management access to prevent unauthorized MAC changes.
Detection: alert on MAC/IP mapping changes and frequent reassignments for critical IPs like gateways.
Implementation notes
Configure per-port allowed MAC counts, bind static MACs for servers, and use 802.1X for device authentication at the network edge.
Key Takeaway

Port-level enforcement and authentication reduce risk of MAC spoofing and improve detection of compromised hosts.
