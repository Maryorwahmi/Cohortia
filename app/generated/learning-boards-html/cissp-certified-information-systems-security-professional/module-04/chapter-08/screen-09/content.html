Module 5 › Chapter 4.8 › NetFlow / IPFIX Config
Router NetFlow/IPFIX: Conceptual template
Set export version, point to collector, tune timeouts, and enable flow on interfaces.
# Assume the NetFlow collector IP is 192.168.10.60 and port 2055

# Step 1: Enable NetFlow globally
# Command: `ip flow-export version 9` (or `ip flow-export version 10` for IPFIX)
# Command: `ip flow-export destination 192.168.10.60 2055`
# Command: `ip flow-cache timeout active 1`
# Command: `ip flow-cache timeout inactive 15`

# Step 2: Enable NetFlow on specific interfaces
interface GigabitEthernet0/0
  ip flow ingress
  ip flow egress
  exit

# Step 3: Verify NetFlow (conceptual command)
# Command: `show ip flow export`
# Command: `show ip cache flow`
After enabling, verify flows arrive at the collector and inspect exported records for expected fields. Tune timeouts to balance export granularity against collector load.
Verification
Confirm the collector receives flows, check router export status, and validate that the flows include expected endpoint pairs and byte counts.
Pitfall
Forgetting to enable flow on interfaces or misconfiguring destination IP/port results in no exported records.
Key Takeaway

NetFlow exports require global settings and per-interface activation — validate both sides and monitor collector capacity.
