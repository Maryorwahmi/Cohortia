Module 5 › Chapter 4.8 › Logs • Flows • Packets
Logs
Device and application events, authentication records, policy enforcement entries.
  • Context: usernames, policy hits, error messages.
  • Retention for compliance and incident timelines.
  • Requires centralization for cross-device correlation.
Flow (NetFlow / IPFIX)
Conversation metadata: endpoints, ports, bytes, timestamps.
  • Efficient for long-term storage and trend analysis.
  • Good for spotting large transfers or suspicious connections.
  • Cannot show payload content.
Packet Capture
Raw packets for protocol and payload inspection using tools like Wireshark or tcpdump.
  • Highest fidelity; essential for payload forensics and protocol debugging.
  • High storage and privacy cost; use for targeted captures.
  • Handle captures carefully — they may contain sensitive data.
Analyst guideline
Start with logs and flow data. Use those to narrow a time window and target hosts, then capture packets selectively for content evidence.
Misconception
Believing one data type solves all problems. Each source answers different forensic questions.
