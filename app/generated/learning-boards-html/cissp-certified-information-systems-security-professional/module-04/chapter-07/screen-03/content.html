Objective 05 — Subnet planning

Plan public and private subnets across two availability zones, select CIDR blocks that avoid overlaps, and document routing for each subnet.

Example
VPC 10.0.0.0/16 with /24 subnets per AZ
Mnemonic
Map CIDR → AZ → Role
Objective 06 — IGW & NAT patterns

Implement an Internet Gateway for public subnets and a NAT Gateway for private subnets so private resources can update without direct exposure.

Objective 07 — Logging and monitoring

Enable VPC Flow Logs and forward records to a SIEM or logging platform to audit network flows and detect misconfigurations or suspicious activity.

Objective 08 — Secure management plane

Apply least privilege to cloud console and API access. Protect management accounts to prevent bypassing network controls.

How to practice
  1. Design CIDR and subnets on paper.
  2. Create SG and NACL rules for a sample app.
  3. Enable VPC Flow Logs and validate events.
Verification
Each milestone should include a configuration artifact and log evidence showing traffic matches expected patterns.
