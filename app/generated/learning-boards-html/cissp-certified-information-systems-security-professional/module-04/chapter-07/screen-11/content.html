Module 4 › Chapter 4.7 › SDN & Micro-segmentation
What SDN enables

SDN centralizes control logic and enables programmatic configuration of networking. This supports policy-driven security and consistent enforcement as workloads scale.

Micro-segmentation
Define per-workload policies that allow only required ports between named workloads, greatly reducing lateral movement risk.
Implementation needs
Automation, inventory of workload communication, and integration with orchestration platforms for policy lifecycle.
Key Takeaway

Micro-segmentation is a high-value defense-in-depth control but requires automation and continuous maintenance.

Concrete example
Example policy
Allow web-sg to connect to db-sg on TCP 3306 only. Deny other inter-tier connections unless explicitly required.
Misconception
Micro-segmentation is not a one-time config. It must be updated as services change; otherwise policies become obsolete or overly permissive.
