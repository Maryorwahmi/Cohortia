What is a VPC?

A VPC is a logically isolated virtual network you define in a public cloud. It includes subnets, IP ranges, route tables, and gateways so you control connectivity and isolation.

Components
Subnets, CIDR block, route tables, Internet Gateway, NAT Gateway, security groups, NACLs.
Example
VPC 10.0.0.0/16 with public web subnets 10.0.1.0/24 and private DB subnets 10.0.3.0/24 across two AZs.
Common mistake
Using default VPCs or broad CIDR ranges without segmentation leads to exposed or poorly isolated resources.
Key Takeaway

Design VPC CIDR and subnet segmentation intentionally and never rely solely on provider defaults for security.

Visual: typical VPC layout
High-level layout
Public subnets with Internet Gateway for web tier. Private subnets with NAT Gateway for outbound updates and no direct inbound internet routes for databases.
Scenario
You need two public subnets and two private subnets across two availability zones to support high availability for a web application and its database tier.
