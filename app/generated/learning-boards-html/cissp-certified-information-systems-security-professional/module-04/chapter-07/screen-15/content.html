Module 4 › Chapter 4.7 › Key Concepts
Virtual Private Cloud (VPC)
A logically isolated virtual network within a public cloud, configurable like a data center.
Shared Responsibility Model
Cloud providers secure infrastructure; customers secure their VPCs and resources.
Security Group (SG)
A stateful, instance-level firewall controlling inbound and outbound traffic for instances.
Quick takeaway

Use these core concepts as a checklist when designing cloud networks: isolate, control scope, protect credentials, and log traffic.
