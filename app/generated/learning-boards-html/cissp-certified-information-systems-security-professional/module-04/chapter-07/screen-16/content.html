Module 4 › Chapter 4.7 › Key Concepts
Network ACL (NACL)
Stateless subnet firewall; rules are ordered and you must allow both directions explicitly.
Hybrid Connectivity
VPN for encrypted internet tunnels; Direct Connect / ExpressRoute / Interconnect for private links with better performance.
Micro-segmentation
Create workload-level policies to limit lateral movement and reduce blast radius when combined with SDN.
Final takeaway

Combine NACLs, Security Groups, proper connectivity choices, micro-segmentation, logging, and management-plane hardening to create resilient cloud network security.
