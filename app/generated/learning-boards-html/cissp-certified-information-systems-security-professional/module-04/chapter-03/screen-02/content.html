Learning Objectives

Bloom levels: Learn → Understand → Apply → Master

Bloom progression
01
Explain TLS/SSL security

Describe the handshake, cipher negotiation, and how certificates establish server identity. Verifying TLS keeps web sessions private and trusted.

VERIFIED COMPETENCY MILESTONE
02
Describe SSH and keys

Explain how SSH encrypts sessions and how key-based authentication uses public/private pairs to avoid password exposure.

VERIFIED COMPETENCY MILESTONE
03
Understand IPsec modes

Differentiate transport and tunnel modes and know when to use AH versus ESP for integrity or confidentiality.

VERIFIED COMPETENCY MILESTONE
04
Identify DNSSEC and email options

Explain how DNSSEC signs DNS records and contrast S/MIME and PGP for email encryption and signatures.

VERIFIED COMPETENCY MILESTONE
Practical checks
Inspect a TLS certificate
Look at issuer, subject, validity, and SAN entries.
Generate SSH keys
Create a key pair and view the public key file content.
