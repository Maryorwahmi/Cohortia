Module 4 › Chapter 4.3 › Key Concepts
TLS
Encrypts transport sessions; uses certificates for authentication.
SSH
Secure shell and file transfer with key-based auth for strong identity proof.
IPsec
Network-layer protection; transport vs tunnel modes, AH and ESP protocols.
Takeaway

Apply the correct protocol to the appropriate layer, keep software and ciphers current, and protect private keys and certificates to maintain trust and confidentiality.
