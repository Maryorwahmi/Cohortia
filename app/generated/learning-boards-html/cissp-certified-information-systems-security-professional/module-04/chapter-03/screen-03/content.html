Practical skills

Generate keys, inspect certificates, and compare email encryption models.

SSH key generation checklist
  • Use RSA 4096 or ECDSA with a strong passphrase.
  • Store private key securely and share only the public key.
  • Disable password authentication when possible.
TLS certificate inspection
  • Confirm the issuer and subject match expected values.
  • Check validity period and SAN entries for the domain.
  • Verify key algorithm and key size are modern.
Email security comparison
S/MIME uses X.509 and PKI for enterprise-managed certificates; PGP relies on a web-of-trust. Choose based on organizational control and key management preference.
IPsec scenario check
For site-to-site VPNs that need confidentiality and full packet protection, prefer tunnel mode with ESP and IKE to manage security associations.
Key Takeaway

Practice the tasks and evaluate which protocol addresses the layer and threat model you face; correct configuration is as important as the protocol choice.
