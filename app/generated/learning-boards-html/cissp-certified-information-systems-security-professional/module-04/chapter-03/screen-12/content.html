Process

How DNSSEC prevents spoofing

1. Zone signs records
Each DNS zone signs its records with a private key, producing digital signatures for responses.
2. Parent publishes public key
The parent zone publishes a delegating record that points to the child's public key, forming a chain.
3. Resolver validates chain
Resolvers verify signatures up the chain to a trusted anchor, ensuring authenticity and integrity of DNS responses.
Example
A resolver checks that example.com's A record signature matches the visible public key chained to the parent, preventing a forged response from being trusted.
Misconception
DNSSEC is not a cure-all for DNS problems; it secures responses but increases operational complexity and requires correct key management.
Why it matters

DNS is the internet's directory; signing records prevents attackers from redirecting users to malicious sites via forged DNS answers.
