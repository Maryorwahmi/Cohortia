Module 4 › Chapter 4.3 › SSH: Secure Remote Access
Definition

SSH secures shells and file transfer

SSH provides encryption and authentication for administrative tasks and replaces insecure legacy protocols.

Authentication methods
Password-based or key-based (public/private key pairs). Key-based is stronger when the private key is protected with a passphrase.
Hardening tips
Disable root login, disable password auth when possible, and limit source IPs for SSH access.
Example: Key generation
# Generate a new RSA SSH key pair with a strong passphrase
ssh-keygen -t rsa -b 4096 -C "my_cissp_key@cohortia.com"

# List keys
ls -l ~/.ssh

# Display public key
cat ~/.ssh/id_rsa.pub
Reminder
Keep your private key secure and always prefer a passphrase to protect it if the client is compromised.
