Module 4 › Chapter 4.3 › IPsec Modes
Transport Mode
Encrypts and/or authenticates only the payload of the IP packet. Use for host-to-host scenarios where the original IP header must remain intact.
When to use
Direct host communication where gateways are not involved in encapsulation.
Tunnel Mode
Encrypts/authenticates the entire original IP packet and places it inside a new IP packet. Ideal for VPNs between networks or gateways.
Example
Site-to-site VPN between two corporate gateways should use tunnel mode with ESP for confidentiality and integrity.
