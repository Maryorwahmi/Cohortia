Module 4 › Chapter 4.3 › IPsec: AH, ESP, IKE
AH
Provides integrity and data origin authentication for IP packets. It does not encrypt payloads, so confidentiality is not offered.
Use case
When you need tamper-evidence but not confidentiality for packet payloads.
ESP
Provides confidentiality, authentication, integrity, and anti-replay protection. Most VPNs use ESP when encryption is required.
Example
Encapsulating Security Payload used with tunnel mode to protect all traffic between two network gateways.
IKE and Security Associations
IKE negotiates SAs, selecting algorithms and exchanging keys. Proper IKE configuration ensures both peers agree on encryption, integrity, and lifetime parameters for the session.
