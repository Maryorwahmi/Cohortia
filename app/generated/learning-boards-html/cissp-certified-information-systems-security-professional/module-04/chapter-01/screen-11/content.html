Module 4 › Chapter 4.1 › ACLs & Firewall Policies
Design rules
  1. Start with deny-by-default and add minimal allow rules.
  2. Scope rules to specific source IPs, destinations, and ports.
  3. Document each rule's purpose and review regularly.
Example flow matrix
Internet → DMZ Web: Allow TCP 80, 443
DMZ Web → Internal DB: Allow TCP 3306 from web server IP only
DMZ → Internal: Deny all other traffic
Key takeaway

Use explicit, minimal rules and document them to prevent accidental over‑permissive configurations.
