Why port security

Port security reduces unauthorized device connectivity at the switch access layer by controlling MAC addresses allowed on a port and defining violation behavior.

Checklist
  • Set ports to access mode for endpoints.
  • Enable port security with a reasonable maximum.
  • Use sticky MAC binding when possible and configure violation action.
CLI example
interface GigabitEthernet0/1
  switchport mode access
  switchport port-security
  switchport port-security maximum 1
  switchport port-security mac-address sticky
  switchport port-security violation restrict
  exit
Validation

After applying, connect a new device and confirm the restrict action triggers and logs the violation; monitor syslog or the management station for events.
