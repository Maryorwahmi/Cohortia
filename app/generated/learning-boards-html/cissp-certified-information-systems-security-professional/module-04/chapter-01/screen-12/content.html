Zones & Subnets (suggested)
  • DMZ: 10.0.1.0/24 — Web & Email servers
  • Internal Corporate: 10.0.2.0/24 — Employee devices
  • Finance: 10.0.3.0/24 — Financial DB and workstations
  • Guest Wi‑Fi: 10.0.4.0/24 — Guest devices
  • Management: 10.0.5.0/24 — Network management hosts
Firewall placement

External firewall at internet edge, internal firewall between DMZ and internal networks, and ACLs at router interfaces between internal zones.

Traffic flows & policies
Internet → DMZ Web: Allow TCP 80, 443
DMZ Web → Internal DB: Allow DB port from web server IP only
Guest → Internal: Deny all
Management → Devices: Allow SSH, SNMP only from management host
Validation steps

Simulate a compromise in the DMZ and verify the internal firewall prevents lateral movement to finance and internal networks.
