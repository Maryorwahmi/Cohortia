Module 4 › Chapter 4.1 › Network Segmentation
Step-by-step segmentation
  1. Inventory assets and classify by sensitivity.
  2. Group assets into zones: DMZ, Internal, Finance, Guest, Management.
  3. Assign subnets and VLAN IDs to each zone and plan routing.
  4. Enforce boundaries with firewalls, ACLs, and host policies.
  5. Test flows and simulate a breach to validate containment.
Concrete example

A DMZ web server accepts HTTP/HTTPS from the internet. It is allowed to query the internal DB only on the specific database port and only from the web server's IP. All other internal access is denied by default.

Visual checklist
VLANs
Logical separation on switches for offices, servers, guests.
Subnets & Routers
Route between segments through enforcement points, not implicitly.
Mistake to avoid

Allowing broad internal access from the DMZ or leaving management interfaces on unsegmented networks.

Key takeaway

Design zones by trust, enforce least privilege between them, and verify the boundaries with testing.
