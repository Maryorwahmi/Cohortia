Module 4 › Chapter 4.1 › Zero Trust
Core definition

Zero Trust asserts that no user or device is inherently trusted. Every request is evaluated using identity, context, and device posture before granting access.

Component
Identity and access management with MFA.
Component
Device posture checks and continuous monitoring.
Component
Micro‑segmentation and least privilege policies.
Example

An employee on the corporate LAN tries to access a financial application. Even if authenticated earlier, the application requires MFA, verifies the device has current patches, and enforces a policy denying access from unmanaged devices.

Misconception

Zero Trust is not just adding another perimeter; it is an identity and context‑driven enforcement model that enhances existing controls.
