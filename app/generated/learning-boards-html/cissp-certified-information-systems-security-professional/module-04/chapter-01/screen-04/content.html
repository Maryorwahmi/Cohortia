Module 4 › Chapter 4.1 › OSI & TCP/IP Mapping
Definition

OSI is a seven‑layer conceptual model. TCP/IP is a practical four‑layer model used for implementing network protocols. Use them to localize threats and pick controls.

Example
MAC spoofing on the LAN is a Data Link/Network Access issue. Port security and ARP inspection counter it.
Common misconception

One firewall alone will not secure all layers. Layered defenses must be applied where threats manifest.

Key takeaway

Always map threats to a model layer and choose controls targeted to that layer for better protection.

Layer-to-Control Guide
Data Link / Network Access
Port security, VLANs, dynamic ARP inspection.
Network / Transport
Firewalls, ACLs, segmentation, IDS/IPS.
Application
WAFs, secure coding, patch management.
Scenario check

If an internal web server is compromised, ask which layer allowed the compromise, then add controls at that layer and neighboring layers to contain it.
