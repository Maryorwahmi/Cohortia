Learning Objectives
Understand, Apply, and Verify core network security controls and device configurations.
01
Explain device functions
Name how firewalls, IDS/IPS, routers, and switches inspect or enforce traffic and why that placement matters.
VERIFIED COMPETENCY MILESTONE
02
Differentiate firewall types
Distinguish packet-filtering, stateful, application-layer and NGFW and map each to a use case.
VERIFIED COMPETENCY MILESTONE
03
Describe IDS vs IPS
Explain detection, alerting, inline prevention and the operational trade-offs of each approach.
VERIFIED COMPETENCY MILESTONE
04
Implement router & switch security
Write ACLs, enforce SSH for management, and configure switch port security for access ports.
VERIFIED COMPETENCY MILESTONE
