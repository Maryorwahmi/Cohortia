Module 4 › Chapter 4.2 › IDS vs IPS
Side-by-side comparison
IDS (Intrusion Detection System)
  • Passive monitoring and alerting
  • Can be signature or anomaly based
  • Usually out-of-band, no inline latency
IPS (Intrusion Prevention System)
  • Inline and active blocking
  • Drops malicious packets or resets connections
  • Introduces latency and needs tuning to avoid false positives
Deployment trade-offs
Use IDS where availability and latency are critical and analysts can respond. Use IPS where immediate blocking is required and you can manage false positives.
Concrete Example
A signature-based IDS alerts on a known exploit string. An IPS inline with that signature could drop the packets and reset the connection, blocking the attempt immediately but risking disruption if the signature yields false positives.
Misconception
Assuming IPS should always be used. If false positives would break services, start with IDS and operationalize response workflows before enabling inline prevention.
Reflection

Consider trade-offs: is immediate blocking worth potential latency and a single point of failure for this network segment?
