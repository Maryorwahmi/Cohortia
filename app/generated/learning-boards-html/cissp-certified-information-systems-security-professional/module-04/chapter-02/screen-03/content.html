Practical Outcomes
Each objective ties to a short verification task you can run in a lab or review during an audit.
ACL verification
Write an ACL entry to restrict SSH to a management IP and verify denied attempts are logged and blocked.
Port security test
Enable sticky MAC and restricted violation. Connect an unauthorized device to observe violation counters increment without bringing the port down.
IDS/IPS tuning
Tune signatures and anomaly thresholds to reduce false positives while maintaining coverage for real threats.
Proxy/load balancer design
Design a reverse proxy or load balancer placement for SSL offload and to prevent direct exposure of backend servers.
Verification checklist
  • Document ACL rules and expected traffic flows.
  • Capture traffic to confirm denied packets match ACL expectations.
  • Test port security by swapping endpoint hardware and observing counters.
  • Run a basic load test to confirm load balancer health checks remove unhealthy nodes.
