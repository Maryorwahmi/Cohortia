Module 4 › Chapter 4.2 › Switch Hardening Lab
Task Overview
Enable port security on GigabitEthernet0/1 with one sticky MAC and configure SSH for VTY management with a local admin account.
Why these steps matter
Port security prevents unauthorized devices from joining an access port. Using SSH and local login prevents plaintext credentials and restricts remote access. Stick the learned MAC to reduce manual configuration while keeping auditability.
Check your understanding
After applying the commands, how will the switch behave when a second device is plugged into the port? Expect packets from the unknown MAC to be dropped and a violation counter incremented, while the original MAC continues to pass traffic.
Command Template
! Global Configuration
hostname MySecureSwitch
enable secret MyStrongEnablePassword!

! Configure Port Security on GigabitEthernet0/1
interface GigabitEthernet0/1
  switchport mode access
  switchport port-security
  switchport port-security maximum 1
  switchport port-security mac-address sticky
  switchport port-security violation restrict
  description Employee_Workstation_Port
  no shutdown
  exit

! Configure SSH for Management Access
ip domain-name mycompany.local
crypto key generate rsa modulus 2048
username admin privilege 15 secret MySSHPassword!
line vty 0 15
  transport input ssh
  login local
  exit
Run these commands in a controlled lab. After applying, save the running configuration and record the learned MAC address for inventory.
