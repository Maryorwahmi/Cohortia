Module 4 › Chapter 4.2 › Load Balancers
Core responsibilities
  • Distribute traffic across backends for scalability and resilience.
  • Perform health checks and remove unhealthy nodes from service.
  • Provide SSL offload, rate limiting, and sometimes basic request filtering.
Why it matters
By centralizing connection handling and TLS, load balancers simplify certificate management and shield backend servers from direct client traffic.
Concrete Example
A reverse proxy terminates TLS, performs a health check, and forwards requests to healthy backend servers. If a backend fails health checks, it is removed so clients continue to receive successful responses from the pool.
Misconception
Relying solely on the load balancer for application security. The application must still validate input and enforce authentication and authorization.
