Module 4 › Chapter 4.2 › Key Concepts
Intrusion Detection (IDS)
A passive system that monitors activity and alerts on suspicious patterns without blocking traffic.
Intrusion Prevention (IPS)
An inline system that can drop or block malicious traffic when a threat is detected.
ACLs & Port Security
ACLs filter traffic by rules; port security limits MACs on switch ports to prevent unauthorized devices.
Final Takeaway
Combine detection and prevention with careful tuning and testing. Use ACLs and port security to enforce least privilege and validate results in a lab before production deployment.
