Module 4 › Chapter 4.2 › Router ACLs
Concept
ACLs list permit/deny rules evaluated sequentially to control traffic or management access.
Key points
  • Order matters: first match wins.
  • Apply ACLs in the correct direction (in/out) on the appropriate interface or vty lines.
  • Use explicit allow for management hosts then deny any-other to enforce least privilege.
Key Takeaway
An ACL that permits a management host and then denies everything prevents unauthorized management access when applied correctly.
Configuration Example
access-list 10 permit ip host 192.168.1.100 any
access-list 10 deny ip any any
line vty 0 4
  access-class 10 in
  transport input ssh
Apply and then test from 192.168.1.100 (allowed) and from another host (denied). Verify access with connection attempts and logs.
