Module 4 › Chapter 4.2 › Key Concepts
Firewall
A device that monitors and filters traffic based on configured policies to enforce security boundaries.
Packet-Filtering
Stateless inspection of packet headers: fast but without connection context.
Stateful Inspection
Tracks sessions and allows return traffic for established connections, improving security over stateless filters.
Summary
Match inspection depth to risk and avoid overly permissive rules; use deny-by-default and test applied policies.
