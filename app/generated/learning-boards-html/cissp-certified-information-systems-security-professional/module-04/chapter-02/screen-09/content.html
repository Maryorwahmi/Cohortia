Module 4 › Chapter 4.2 › Switch Security
Core features
  • Port security: limit MACs, enable sticky, set violation mode to restrict or protect.
  • VLANs: logically segment traffic to reduce broadcast domains and isolate groups.
  • Management hardening: disable unused ports, use SSH, and apply AAA or local login with strong secrets.
Key Takeaway
Use port security and VLANs to limit unauthorized access and segment traffic, and enforce secure management practices to protect the switch itself.
Concrete Scenario
On an employee access port, enable port security with maximum 1, sticky MAC, and violation restrict. If an attacker connects another device, the switch drops frames from the unauthorized MAC and increments the violation counter while keeping the port operational for the original MAC.
Misconception
VLANs alone are not a security boundary for determined attackers; combine them with ACLs, monitoring, and endpoint controls.
