Defence-in-Depth Steps
1. Perimeter Filtering
Use packet-filtering or stateful firewalls at the internet edge for broad traffic control.
2. Detection & Prevention
Deploy IDS for monitoring and IPS inline where automatic blocking is necessary and safe.
3. Application Edge
Use reverse proxies/load balancers for TLS offload, filtering, and availability.
4. Internal Segmentation
Use VLANs, ACLs, and port security to limit lateral movement and protect sensitive segments.
This pattern balances visibility, performance, and security. Always test for single points of failure and tune inline devices to minimize false positives while maintaining protection.
