Module 4 › Chapter 4.5 › Design Exercise
Task brief

Design a secure remote access solution for GlobalConsult Inc. using the chapter template. Justify VPN type, tunneling mode, authentication, NAC checks, and server administration controls.

Design hints
  • Prefer full-tunnel when inspection of all traffic is required.
  • Apply MFA to all remote access and admin accounts.
  • Use NAC pre-admission and post-admission checks and automatic quarantine actions.
Key Takeaway

Document your choices clearly and include operational steps for patching, monitoring, and remediation.
