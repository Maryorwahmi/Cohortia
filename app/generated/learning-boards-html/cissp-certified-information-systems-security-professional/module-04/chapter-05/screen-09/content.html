Module 4 › Chapter 4.5 › Remote Desktop Security
Hardening checklist
  • Restrict source IPs or require connection via a management network.
  • Enforce MFA for all remote desktop access.
  • Keep remote desktop services patched to close known vulnerabilities.
  • Log and monitor all administrative sessions for anomalies.
Concrete scenario
Administrators VPN in with MFA, SSH to a bastion host, which then proxies connections to internal servers while logging the session.
Jump box patterns
Hardened host — single, monitored entry point with strong controls.
Session logging — record admin activity for audit and post-incident analysis.
Disposable builds — rebuild jump boxes frequently to reduce persistent compromise risk.
Key Takeaway

Centralize admin access through a hardened, logged jump box and enforce MFA and network restrictions to reduce exposure.
