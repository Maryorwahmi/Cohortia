Definition
Network Access Control (NAC)

A security system that enforces policies on devices attempting to access network resources, ensuring authorization and compliance before and after access is granted.

Key properties
  • Pre-admission checks: verify posture before granting access.
  • Post-admission checks: continuous monitoring and remediation actions.
  • Dynamic enforcement: quarantine, restrict, or grant access based on compliance.
Key Takeaway

NAC ensures devices meet security posture requirements before reaching sensitive resources and continues to protect after connection.

How it works
Supplicant
Client device requesting access; proves identity and posture.
Authenticator
Network device that holds the port until validation completes.
Auth Server
RADIUS or similar server validates credentials and posture policy.
Concrete example
A laptop fails antivirus checks after a threat update. NAC quarantines it into a remediation VLAN until signatures are updated.
Common mistake
Treating NAC as a single-time check rather than enabling continuous posture monitoring.
