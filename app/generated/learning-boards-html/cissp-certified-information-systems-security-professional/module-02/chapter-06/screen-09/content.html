Concepts

Masking vs Tokenization

Masking: Non-reversible display transformation, e.g., **** **** **** 1234.
Tokenization: Replace value with token stored in secure vault; reversible only via controlled service.
When to use: Masking for UI; tokenization for secure reference across systems when original retrieval is occasionally needed.
Example Flow
Simplified tokenization pseudocode to illustrate the end-to-end idea.
// Pseudocode example
function tokenizeCard(cardNumber) {
  // send to secure vault service
  token = vault.createToken(cardNumber)
  return token
}

function getMaskedForDisplay(token) {
  cardNumber = vault.lookup(token)
  return '**** **** **** ' + cardNumber.slice(-4)
}
Key takeaway
Use tokenization for storage and controlled reversibility; use masking for safe displays and reports.
