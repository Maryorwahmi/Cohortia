Architecture

Layered controls for PII/PHI

Encryption
Encrypt sensitive databases at rest and use TLS for data in transit to protect confidentiality.
Access controls
Implement RBAC and least privilege so only authorized roles access PII/PHI.
DLP & tokenization
Use DLP to block exfiltration and tokenization to store substitutes for sensitive values.
Auditing
Log all access and changes to PII/PHI and review logs regularly for anomalies.
Practical Example
Analytics pipeline protecting payment data:
Pipeline steps
  1. Tokenize raw card numbers at ingest.
  2. Store tokens in encrypted database.
  3. Provide masked card suffixes to analytics.
  4. Log all access and enforce RBAC for analysts.
Key takeaway
Use multiple controls together; encryption without access limits and DLP is insufficient.
