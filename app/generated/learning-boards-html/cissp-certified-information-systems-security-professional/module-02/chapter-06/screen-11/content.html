Logging, Detection, and Incident Response for PII/PHI

Logging requirements
Record user identity, action, object accessed, and timestamp for all PII/PHI access and modifications.
Monitoring & alerts
Trigger alerts on anomalous exports, bulk reads, or repeated failures and review immediately.
Example
DLP blocks an email with social security numbers and logs the attempt, generating an alert for security review.
Incident response
Follow identification, containment, eradication, recovery, and notification steps tailored for PII/PHI breaches.
Pitfall
Failing to protect logs: log records may contain references to sensitive data and need access controls and secure retention.
Key takeaway
Make logging complete and tamper-resistant, integrate alerts with response plans, and document regulatory notifications.
