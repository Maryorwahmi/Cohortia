Module 2 › Chapter 2.6 › PII
Definition

Personally Identifiable Information

Any data that can identify an individual directly or indirectly. Classification informs control choices.

Direct identifiers
  • Name, social security number, driver's license, biometric data
Indirect identifiers
  • Date of birth, IP address, place of birth, employment details
Analysis
Risk assessment
Evaluate combinations of indirect identifiers during threat modeling to estimate re-identification likelihood.
Common mistake
Removing a name alone does not anonymize data; attackers may re-link records using auxiliary sources.
Example
A table with birth date, ZIP code, and gender can often re-identify individuals when matched to external lists.
Key takeaway
Classify fields as direct/indirect and apply proportional controls to reduce risk.
