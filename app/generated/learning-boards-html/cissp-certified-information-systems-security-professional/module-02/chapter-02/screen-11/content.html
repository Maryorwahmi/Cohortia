Module 2 › Chapter 2.2 › GlobalTech Mapping
Scenario

GlobalTech marketing campaign

Actors: Sarah (Marketing head), GlobalTech (entity), IT Department, EmailBlast (third party), Marketing Associate.

Mapping
Sarah (Head of Marketing)       → Data Owner
GlobalTech (the organization)   → Data Controller
IT Department (DB admins)       → Data Custodian
EmailBlast (campaign service)   → Data Processor
Marketing Associate             → Data User
Why each label
Owner decides classification; Controller determines purpose; Custodian secures storage; Processor acts on instruction; User follows handling rules.
Follow-up actions
  • Issue a DPA and SLAs to EmailBlast.
  • Document owner decisions and access approvals.
  • Train Marketing Associates on handling rules.
Example evidence
Owner: signed policy. Custodian: encryption configuration. Processor: DPA and audit report. User: training completion record.
Key Takeaway

Map actors, then collect evidence for each role: policy, configuration, contract, and training.
