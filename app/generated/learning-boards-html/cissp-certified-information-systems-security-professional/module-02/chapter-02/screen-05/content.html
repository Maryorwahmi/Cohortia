Module 2 › Chapter 2.2 › Data Custodian — Implementation
Definition

Data Custodian

The technical and operational team that implements, maintains, and documents security controls for data.

Core activities
  • Configure access controls and logging.
  • Patch systems, maintain backups, and verify restores.
  • Provide evidence and reports for audits.
Pro tip

When custodians are vendors, include clear SLAs and audit rights so responsibilities are verifiable.

Example activity

An IT admin encrypts an HR database, configures role-based access, runs periodic integrity checks, and documents the patch schedule for compliance.

Key takeaway
Custodians make controls real. They must document and monitor to prove protection.
Common mistake
Assuming custodians decide classification or accept business risk.
