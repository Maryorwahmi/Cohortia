Module 2 › Chapter 2.2 › Operational Checklist
Checklist

Artifacts that prove role assignments

Data Owner
Policy, signed decisions, retention approvals.
Data Custodian
Configuration snapshots, patch logs, backup verification.
Controller / Processor
DPA, SLA, audit reports, incident timelines.
Data User
Access approvals, training records, handling checklists.
Practical step

Link each artifact to the dataset in your governance register and schedule periodic evidence refreshes.

Avoid

Relying on verbal confirmations or undocumented configurations. Evidence must be written and verifiable.

Key Takeaway

Attach artifacts to datasets so audits and incident responses can verify responsibilities quickly.
