Module 2 › Chapter 2.2 › Data User — Frontline
Definition

Data User

Any person who accesses or uses data while performing job duties and must follow handling rules.

Daily responsibilities
  • Follow access approvals and classification rules.
  • Avoid unnecessary copying, printing, or sharing.
  • Report suspicious or anomalous activity promptly.
Training note

Regular awareness sessions should cover classification handling, secure sharing, and reporting procedures for users.

Example

An HR specialist accesses a confidential file to process leave. They must not email the file to a personal account or print it without authorization.

Why this matters
Users control many accidental exposures; simple rules multiplied across staff reduce incidents.
Common mistake
Relying on technical controls alone and under-investing in user training.
