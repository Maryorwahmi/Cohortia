Module 2 › Chapter 2.2 › Controller vs Processor
Controller

Determines the purposes and means of processing personal data and is responsible for regulatory obligations.

Example

A company collecting customer emails to send service notifications is the Controller for that data.

Responsibilities
  • Define lawful basis and purposes.
  • Ensure data subject rights are handled.
  • Select and oversee processors via agreements.
Misconception

Hosting or controlling infrastructure does not automatically make a vendor a controller if they act only on instructions.

Processor

Processes personal data on behalf of the Controller and follows the Controller's documented instructions.

Example

A cloud provider storing customer records or a payroll processor handling salaries for another company.

Responsibilities
  • Process data only per instructions.
  • Implement technical and organizational measures.
  • Support the Controller for audits and requests.
Key takeaway
Document and contract Controller–Processor relationships to clarify obligations and audit rights.
