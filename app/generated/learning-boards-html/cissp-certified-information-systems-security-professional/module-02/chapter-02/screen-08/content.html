Process

Policy → Implementation → Use → Oversight

A clear sequence ensures each role performs its part and that actions are auditable.

Owner
Classify, set policy, accept risk.
Custodian
Implement controls and document them.
User
Follow handling rules and report incidents.
Controller/Processor
Define purpose / process on instruction, contractually bound.
Example chain

Owner classifies marketing list as confidential. Custodian enables RBAC, encryption, and logging. User accesses only required fields. Processor sends campaigns under a DPA.

Check your understanding
  • Does policy state measurable control requirements?
  • Are custodial actions documented and auditable?
  • Do users have simple handling steps per classification?
Key Takeaway

A broken link in the chain turns policy into a paper exercise. Make requirements measurable and evidenceable.
