Module 2 › Chapter 2.2 › Key Concepts
Data Owner

Individual or entity ultimately accountable for a dataset, its classification, and accepted risk.

Data Custodian

Technical stewards who implement, maintain, and document security controls as directed by the Owner.

Controller / Processor

Controller decides purpose and means; Processor acts on instruction and must be contractually bound and auditable.

Takeaway

Map actors, document decisions and evidence, and use contracts to bind external processors to security obligations.
