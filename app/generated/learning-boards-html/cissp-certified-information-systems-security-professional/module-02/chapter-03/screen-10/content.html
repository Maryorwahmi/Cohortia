Scenario
Confidential Financial Report in cloud storage
Design specific controls for each state and document operations.
At Rest
Cloud-side encryption with customer-managed keys, FDE on laptops, strict access roles and logging.
In Transit
Enforce HTTPS, use VPN for remote users, and confirm certificate validity to avoid MITM.
In Use
Endpoint DLP, multi-factor authentication, managed editing apps, and OS hardening.
Implementation checklist
  • Enable and validate cloud encryption, align keys with corporate KMS.
  • Turn on FDE on all laptops and restrict local copies.
  • Enforce HTTPS and test certificate chains; configure VPN where required.
  • Deploy endpoint DLP rules and test prevention workflows.
Key Takeaway

A documented, tested plan that covers each data state and key management ensures protections are practical and verifiable.
