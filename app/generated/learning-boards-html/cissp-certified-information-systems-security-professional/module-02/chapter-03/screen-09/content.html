scp example
This command copies a local file to a remote host using SSH encryption.
scp /path/to/local/file user@remotehost:/path/to/remote/directory
Why this is safer than ftp
  • Encrypts both credentials and file contents.
  • Uses SSH host keys to verify the endpoint and resist MITM.
  • Supports key-based authentication for automation without plaintext passwords.
Operational checklist
  • Replace FTP with scp or SFTP where possible.
  • Use dedicated service accounts and rotate keys.
  • Limit remote account permissions and directories.
Common mistake

Assuming a VPN alone removes the need to encrypt the application layer; prefer protocols that encrypt end-to-end where feasible.
