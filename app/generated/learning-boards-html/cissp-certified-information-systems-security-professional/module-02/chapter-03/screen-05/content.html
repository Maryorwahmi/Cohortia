Data at Rest
Risks and core controls
Focus on preventing unauthorized access when data is stored. Use encryption, access control, and lifecycle practices together.
Full Disk Encryption (FDE)
Protects an entire storage device. Examples: BitLocker, FileVault.
Database encryption
Transparent Data Encryption secures DB files on disk so stolen drives are unreadable.
Example command
-- Enable TDE on SQL Server
ALTER DATABASE [YourDB] SET ENCRYPTION ON;
Supplemental controls
Encryption must be paired with policies and operational controls.
Access control
NTFS permissions, database roles, and least privilege limit who can read stored data.
Physical and disposal practices
Secure server rooms, encrypted backups, and certified wiping for retired drives.
Common mistake
Relying on physical security alone and omitting logical access controls or key management.
Key Takeaway

Encrypt stored data and govern access and keys; encryption without proper key storage is ineffective.
