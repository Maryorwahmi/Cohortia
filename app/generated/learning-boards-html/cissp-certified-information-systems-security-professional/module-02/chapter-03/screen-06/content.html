Data in Transit
Protocols and endpoint checks
Secure the path and verify who you are talking to. Integrity and confidentiality are both critical.
TLS (HTTPS)
Encrypts web traffic and provides server identity via certificates.
SSH and secure file copy
Use SSH for remote access and scp instead of ftp. Example command shown below.
# Secure copy example
scp /path/to/local/file user@remotehost:/path/to/remote/directory
VPN and IPsec
VPNs protect remote endpoints; IPsec provides network-layer encryption between sites or hosts.
Operational guidance
Beyond choosing a protocol, verify certificates and keys, enforce HTTPS redirects, and segment sensitive flows.
Verify endpoints
Use certificate pinning or strong PKI controls to ensure you are connecting to authentic servers.
Network segmentation
Use VLANs and firewalls to limit who can observe or intercept sensitive traffic.
Common mistake

Assuming encryption alone solves all network risks; you still need segmentation and endpoint hardening to reduce exposure.
