Objective: Apply protections to a scenario
Practice mapping controls to each data state and documenting trade-offs.
01 • Scenario Mapping
Map risks to controls
Create a short table that lists the data state, likely threats, chosen controls, and why each control applies.

Address operational needs

03 • Trade-off Analysis
Weigh performance vs. protection

Confirm protections work
