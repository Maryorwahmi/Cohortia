Protections
Common controls and limits
Full Disk Encryption
Protects stored device data. Limit: does not protect data once logged in and decrypted to memory.
Transparent Data Encryption (TDE)
Encrypts database files on disk. Limit: does not protect data in transit or in use.
TLS / SSH
Secure transport and endpoint identity. Limit: misconfigured certificates can enable MITM.
More controls
VPN / IPsec
Encrypts network traffic at layer 3; useful for remote devices and site links.
Data Loss Prevention (DLP)
Monitors and enforces use rules to prevent exfiltration. Limit: needs tuning to reduce false positives.
Pro tip

Document which state each control protects and include test steps in runbooks so operations can verify protections after deployment.
