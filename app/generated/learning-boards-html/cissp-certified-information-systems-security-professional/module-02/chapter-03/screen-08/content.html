Architecture
Map controls across the lifecycle
Show how storage, transport, and runtime protections combine to reduce risk and blast radius.
At Rest
Disk and database encryption, strong access roles, encrypted backups and secure deletion.
In Transit
TLS for web, SSH for remote, VPN or IPsec for network encryption, and endpoint verification.
In Use
Application hardening, process isolation, DLP, and hardware enclaves where available.
Concrete scenario
Cloud file store used from corporate and remote laptops.
Controls applied
  • Cloud-side encryption with customer-managed keys and folder access policies.
  • Enforce HTTPS and optional VPN for remote devices.
  • Full disk encryption on laptops and endpoint DLP to block unauthorized copying.
Operational note
Document key rotation, incident workflows, and recovery paths. Verify controls with periodic audits and tests.
Key Takeaway

Design layered protections that complement each other and include policy, verification, and lifecycle steps.
