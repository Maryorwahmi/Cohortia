Module 2 › Chapter 2.5 › Marking & Labeling
Definition
Marking and labeling
Combine visible banners with embedded metadata so both humans and automated systems know a file's classification.
Practical template
Header/footer text: "Confidential - Project Phoenix". Metadata property: Classification=Confidential.
Why use both
  • Banner guides human handling decisions at a glance.
  • Metadata enables automated enforcement and discovery by DLP.
  • Together they reduce ambiguity and misclassification.
Concrete example
Header: Confidential - Project Phoenix
Document Property: Classification=Confidential
Common mistake
Applying labels inconsistently or only visually while neglecting metadata means DLP and automated workflows cannot enforce handling rules.
Pro tip
Automate tagging via templates or document creation workflows so metadata is applied reliably without relying on every user to remember the step.
