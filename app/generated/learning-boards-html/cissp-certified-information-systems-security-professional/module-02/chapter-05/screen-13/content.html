Hands-on Activity
Confidential - Project Phoenix
Map marking, storage, and transmission to specific, verifiable actions for the project document.
Marking & Labeling (example)
Header/footer: "Confidential - Project Phoenix". Document property: Classification=Confidential.
Storage requirements
Store on an encrypted share with group-based RBAC limited to the project team and enable audit logging.
Transmission requirements
Share internally with S/MIME email or SFTP. Never send via public webmail or unencrypted attachments.
Command examples
# Owner-only example
chmod 600 /srv/project_phoenix/plan.docx

# Group read/write example
chown :project_team /srv/project_phoenix/plan.docx
chmod 640 /srv/project_phoenix/plan.docx

# Secure transfer example
sftp user@host:/secure/path
Key Takeaway

Document the exact header, metadata, storage location, permission settings, and approved transfer methods so the team has one authoritative process to follow.
