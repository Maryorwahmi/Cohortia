Module 2 › Chapter 2.5 › Transmission Requirements
Definition
Encrypted channels only for sensitive data
Select approved protocols and enforce them in policy to prevent interception and unauthorized sharing.
# Secure transfer (example)
sftp user@host:/path/to/destination

# Insecure transfer (do not use)
ftp host
# avoid sending sensitive files with plain FTP
Operational reminder
Require certificate validation, server authentication, and central logging for all encrypted channels used with classified data.
Concrete guidance
  • Approved: HTTPS, SFTP, SCP, VPN, S/MIME, PGP.
  • Not approved: Unencrypted FTP or public webmail without end-to-end encryption.
Common mistake
Assuming transport encryption is enough without endpoint authentication and secure key management.
Key Takeaway

Define approved encrypted methods and require validation and logging to ensure secure transmission of classified data.
