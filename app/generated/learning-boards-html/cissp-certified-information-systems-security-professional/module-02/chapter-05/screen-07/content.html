Module 2 › Chapter 2.5 › Storage Requirements
Comparison
Physical vs Digital storage
Apply locked storage and controlled rooms for physical media; encrypted volumes, RBAC, and audited cloud services for digital assets.
Physical controls
Locked cabinets, secure rooms, access logs, and strict visitor procedures for sensitive printed materials.
Digital controls
Encryption at rest, RBAC, encrypted backups, restricted cloud buckets, and key management safeguards.
Concrete command (example)
chmod 600 sensitive_file.txt  # restricts file to owner read/write on Linux
When encryption is not enough
If keys or credentials are poorly protected, encryption fails. Pair encryption with access controls, logging, and secure key storage.
Checklist for Confidential storage
  • Encrypted at rest
  • Strict RBAC with limited group membership
  • Audit logging enabled
  • Keys stored separately and protected
