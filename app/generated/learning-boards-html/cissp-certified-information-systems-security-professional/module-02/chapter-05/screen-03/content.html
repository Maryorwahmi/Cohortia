Applied Skills and Verification
Concrete demonstrations that prove competency in handling classified information.
Objective Demo: Marking
Create a header/footer like "Confidential - Project Phoenix" and add a metadata property named Classification with that same value to enable DLP enforcement.
Verification: Open the document properties and confirm the Classification property exists.
Objective Demo: Storage
Place the file on an encrypted share with group-based RBAC and demonstrate a permission command such as a Linux permission example or Windows ACL setting.
Verification: Show the access list includes only the project group.
Objective Demo: Transmission
Send files using an approved encrypted method such as SFTP or company email with S/MIME enabled, and never use unencrypted public webmail.
Verification: Capture transfer logs or show encryption headers.
Objective Demo: Processing
Implement least privilege by granting only required roles and apply data minimization so only necessary fields are collected and stored.
Verification: Review the access matrix and data retention settings.
