Module 3 › Chapter 2.7 › Discovery Tools
Tool categories
  • Network discovery scanners for active host enumeration.
  • Endpoint detection and inventory agents for configuration details.
  • Cloud provider inventory services for native resources and tags.
  • Vulnerability scanners that enrich asset records with findings.
Example command
nmap -sP 192.168.1.0/24
This discovery output can be parsed and imported to update inventory records. Validate findings before assigning lifecycle states.
Integration pattern
Feed discovery results to the inventory or CMDB, attach metadata such as tags and owner, and trigger an owner verification workflow. Automate classification where possible but require human signoff for criticality changes.
Misconception
Discovery is not a substitute for policy. Without owner assignment and audit trails, discovered items remain orphaned and risky.
