Module 3 › Chapter 2.7 › Build a VM Record
Minimal VM schema (example)
ID: VM-123
Owner: finance@example.com
OS: Ubuntu 20.04
IP: 10.2.3.14
Criticality: High
Use this structured format to enable queries and automation. Store timestamps for discovery and last verification for auditability.
Workflow
  1. Run discovery job and create candidate records.
  2. Automatically tag with discovery time and suggested owner if available.
  3. Send owner verification notification; owner confirms or reassigns.
  4. Onboard into inventory with lifecycle state or remediate/remove.
Key takeaway
Combine structured records with a short verification workflow so discovered assets are quickly validated and governed.
