Assessment checklist
  • Completeness: all asset categories present
  • Freshness: recent verification timestamps
  • Accuracy: fields match reality
  • Integration: inventory feeds vulnerability and incident processes
Common mistakes & fixes
Mistakes include missing owners, stale records, disconnected systems, and unmanaged shadow IT. Fix these by enforcing owner tags, automating discovery plus validation, and centralizing or federating inventories into a CMDB for relational context.
Practical drill
Time how long it takes to list all assets running a vulnerable OS and notify owners. Use the result to set a remediation SLA.
