Module 3 › Chapter 2.7 › Asset Lifecycle
Lifecycle steps
1
Planning & Acquisition
Define security requirements, vendor checks, and secure configuration baselines before purchase.
2
Deployment & Configuration
Apply hardening, initial patches, and integrate with access controls and monitoring.
3
Operation & Maintenance
Ongoing patching, scanning, audits, and configuration management to maintain posture.
4
Decommissioning & Disposal
Securely wipe or destroy data and update records to prevent unmanaged lingering assets.
Why gates matter
Gates ensure security steps aren't skipped. Procurement gates set expectations, deployment gates ensure secure defaults, and disposal gates remove residual risk. Without gates, assets drift into unmanaged states that attackers can exploit.
Example checkpoint
Require a configuration baseline and an ownership assignment before a VM moves from staging to production.
Common mistake
Treating disposal as optional. Old hardware or cloud instances left active create ghost assets that evade scanning and policy enforcement.
