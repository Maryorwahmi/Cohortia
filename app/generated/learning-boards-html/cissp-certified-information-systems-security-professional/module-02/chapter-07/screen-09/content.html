Top: Task walkthrough
VM Attributes (example)
  • VM ID
  • Owner
  • OS and version
  • IP / network
  • Criticality
Discovery steps (conceptual)
  1. Enable provider inventory service for VMs.
  2. Map provider tags to your inventory schema.
  3. Run initial discovery and place results in review queue.
  4. Validate owner and criticality; assign lifecycle state.
Example action
Enable inventory, require an owner tag on provisioning, and create an automated notification to the tagged owner for verification within 48 hours of discovery.
Key takeaway
Automation plus owner verification prevents orphaned cloud assets and enforces lifecycle ownership.
