Module 3 › Chapter 2.7 › Asset Attributes
Attribute comparison
Identifier & Owner
Unique ID and accountable owner enable action and audit trails.
Classification & Criticality
Sensitivity and business impact drive prioritization.
Configuration
OS, installed software, and patch level enable targeted remediation.
Network Context
IP, DNS, and certificates inform scanning and exposure analysis.
Concrete example
VM record: ID=VM-42; owner=HR; classification=PII; criticality=high; OS=Ubuntu 20.04; patch=2023-09; IP=10.1.5.12. With these fields you can filter all Ubuntu 20.04 hosts and contact owners to schedule urgent patches.
Common mistake
Recording attributes as free-text notes that are not queryable. Structured fields are essential for automation and reporting.
Key Takeaway
Choose a minimal structured schema that supports filtering, reporting, and automated alerts.
