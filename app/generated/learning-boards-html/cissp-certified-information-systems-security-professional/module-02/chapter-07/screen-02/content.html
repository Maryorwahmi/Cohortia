01
Explain Inventory Importance

Explain why a complete and accurate inventory is the bedrock of security controls, compliance, and incident response. This matters because unknown assets increase exposure and delay remediation.

VERIFIED COMPETENCY MILESTONE
02
Define Asset Attributes

Describe the essential fields — owner, location, classification, patch level, and criticality — and why each field enables security actions like patch prioritization and incident triage.

VERIFIED COMPETENCY MILESTONE
03
Apply Lifecycle Controls

Understand acquisition through disposal and how lifecycle gates — secure configuration, ongoing patching, and secure decommissioning — reduce unmanaged risk.

VERIFIED COMPETENCY MILESTONE
04
Use CMDBs & Tools

Identify when a Configuration Management Database or automated discovery tools are appropriate and how they provide relational context for impact analysis.
