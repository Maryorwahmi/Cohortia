Module 2 › Chapter 2.1 › Marking, metadata, and enforcement
Techniques
  • Visible markings: headers/footers indicating classification.
  • Metadata tags that systems can read and enforce.
  • Access control lists enforcing need-to-know and least privilege.
  • Data loss prevention rules to block unauthorized transfers.
Enforcement example
A document tagged Confidential triggers DLP to block external email and writes an audit entry. The same metadata restricts cloud sync to approved buckets only.
Common Mistake
Relying on human adherence to markings without automated enforcement increases the chance of accidental exposure.
