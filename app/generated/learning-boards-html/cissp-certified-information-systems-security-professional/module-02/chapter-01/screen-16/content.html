Classification Scheme
A structured set of labels and criteria used to categorize assets consistently.
Need-to-Know
Grant access only to individuals who require the information to perform their job.
Least Privilege
Users receive only the permissions necessary for tasks, reducing exposure from excess rights.
Action
When in doubt, ask if access is necessary. If not, tighten permissions and document the decision with the data owner.
