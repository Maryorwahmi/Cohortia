Module 2 › Chapter 2.1 › Common classification schemes
Commercial scheme
Public — minimal protection, integrity checks.
Internal Use Only — internal access, no external sharing.
Confidential — encryption, ACLs, audit trails.
Restricted — highest commercial sensitivity, strict controls.
Government scheme
Unclassified — public or non-sensitive.
Confidential — guarded items affecting operations.
Secret — significant national interest implications.
Top Secret — highest sensitivity; strict handling rules.
Pro-tip
Fewer, well-defined levels reduce ambiguity and improve consistent assignment by data owners.
Key Takeaway

Names are flexible; what matters are defined criteria and handling requirements for each level.
