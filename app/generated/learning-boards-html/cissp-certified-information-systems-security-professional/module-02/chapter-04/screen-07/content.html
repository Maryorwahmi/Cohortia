Definition › Purging & Degaussing
Purging

A high-assurance sanitization that aims to prevent recovery even with laboratory techniques.

  • Degaussing for magnetic media.
  • Cryptographic erase for encrypted media.
  • Often required for highly sensitive or regulated data.
Misconception: purging is a single universal method. Select purging technique by media type and encryption state.
Degaussing & Crypto Erase

Degaussing neutralizes magnetic domains; crypto erase removes keys so ciphertext is unreadable.

Degaussing is effective for tapes and HDDs but will render media unusable.
Cryptographic erase is fast and effective only if encryption and key management were correct.
Pro Tip

Record the method used and evidence; for cryptographic erase, document key lifecycle handling.
