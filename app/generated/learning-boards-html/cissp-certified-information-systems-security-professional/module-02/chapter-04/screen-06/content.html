Process Flow › Clearing / Sanitization
Clearing steps
  1. Identify media and sensitivity level.
  2. Select appropriate overwrite pattern and pass count.
  3. Run tool and capture logs for verification.
  4. Confirm sanitization and record evidence.
Tool examples include DBAN and shred for Linux environments.
Practical command example
sudo shred -n 3 -z -u /dev/sdX
This overwrites three times, zeros the drive, and removes the file. Capture the command output for your records.
Misconception: this command guarantees overwrites the entire physical SSD. Due to wear leveling on SSDs, some cells may remain unchanged.
When to use
When media will be reused and it is a magnetic drive.
Verification
Keep logs, operator name, timestamp, and stored output as evidence.
Key Takeaway

Use clearing carefully: tools work well for HDDs but verify and log every action; SSDs need different care.
