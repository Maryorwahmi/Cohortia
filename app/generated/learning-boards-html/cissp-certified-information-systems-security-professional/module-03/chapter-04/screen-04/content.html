Module 3 › Chapter 3.4 › PKI Core Components
Definition
PKI is a system of hardware, software, policies and procedures that creates and manages digital certificates and keys. The CA is the root of trust; the RA is an identity verification gate; certificates bind identity to a public key.
Certificate Authority (CA): issues, signs, and revokes certificates.
Registration Authority (RA): validates identity before CA issues.
CRL / OCSP: communicate revoked certificates for relying parties.
Example scenario
When a server requests a certificate, the RA performs checks and the CA signs the certificate. If the server key is later exposed, the CA revokes the certificate, preventing further trust.
Misconception: treating revocation as optional. Revocation is essential to stop compromised keys immediately.
Architecture — Chain of Trust
Root CA (offline)
Intermediate CA (online)
Leaf Certificate (server or device)
Revocation Path
CRL or OCSP responses traverse the chain and inform relying parties about revoked serial numbers.
Operational Control
Store root CA keys offline and protect intermediate CA keys with HSMs to limit compromise impact.
