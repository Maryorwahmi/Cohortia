Module 3 › Chapter 3.4 › Key Concepts
Public Key Infrastructure (PKI)
System of hardware, software, policies and procedures to manage certificates and keys.
Certificate Authority (CA)
Trusted entity that issues and revokes certificates; the root of trust.
Registration Authority (RA)
Optional component that validates identity before forwarding requests to the CA.
Summary

Understand these core roles and separate duties so an attacker cannot break trust by compromising a single component.
