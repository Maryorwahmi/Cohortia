Module 3 › Chapter 3.4 › OpenSSL Example
Commands (example)
# Generate a 2048-bit RSA private key
openssl genrsa -out server.key 2048

# Create a Certificate Signing Request (CSR)
openssl req -new -key server.key -out server.csr -subj "/C=US/ST=CA/L=SanFrancisco/O=Cohortia/OU=IT/CN=localhost"

# Self-sign the CSR to create a certificate (testing)
openssl x509 -req -in server.csr -days 365 -key server.key -out server.crt

# Verify certificate matches private key
openssl x509 -noout -modulus -in server.crt | openssl md5
openssl rsa -noout -modulus -in server.key | openssl md5
Note: these commands are for demonstration. Protect any private key you create and remove test files when finished.
Explanation & Example
The private key file is the secret. The CSR contains the public key and identity data used by a CA. Self-signing creates a certificate that will verify against its key but will not be trusted by others unless the root is trusted. Verifying modulus hashes confirms the certificate was signed with the matching private key.
Key Takeaway

Use the CSR and verification steps to ensure authenticity. Never embed private keys in plain config files or repositories.
