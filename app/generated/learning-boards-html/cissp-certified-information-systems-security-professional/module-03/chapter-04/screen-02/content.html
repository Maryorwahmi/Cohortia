01
Describe PKI components
You will identify CAs, RAs, X.509 certificates, CRLs and OCSP responders and explain their functions. Knowing these roles helps you design a trust model that matches organizational security requirements.
Mnemonic: layered trust stack (root → intermediate → leaf)
VERIFIED COMPETENCY MILESTONE
02
Explain certificate lifecycle
You will trace a certificate from CSR and issuance through use, revocation, renewal, and secure destruction. This enables correct automation and reduces windows of vulnerability.
Mnemonic: birth → life → retire
VERIFIED COMPETENCY MILESTONE
03
Apply key management best practices
You will learn secure key generation, HSM usage, backup and recovery planning, and rotation policies. These practices limit impact if keys are exposed and support compliance.
Mnemonic: generate, protect, rotate, destroy
VERIFIED COMPETENCY MILESTONE
04
Evaluate revocation strategies
You will compare CRL and OCSP trade-offs, availability risks, and how misconfiguration affects validation. Practical choices here affect both security and service reliability.
Mnemonic: batch list vs real-time check
