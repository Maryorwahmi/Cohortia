Module 3 › Chapter 3.4 › Key Management
Key Generation & Storage
Generate keys with strong randomness and suitable lengths. Store high-value keys in HSMs and restrict access with multi-person controls.
Generator: cryptographically secure RNG and policy-aligned sizes (e.g., RSA 2048/4096).
Storage: HSMs for CA keys; protected keystores or smart cards for user keys.
Usage: limit keys to their intended purpose (signing vs encryption).
Backup, Recovery & Destruction
Backup critical keys with strict access controls. Plan recovery procedures to balance availability with security. Destroy keys with cryptographic erasure or physical destruction when retired.
Backup: offline and encrypted copies, split across secure locations.
Recovery: documented processes, tested in controlled drills.
Destruction: render keys unrecoverable when no longer needed.
Key Takeaway

Key management is operational discipline. Use HSMs and strict access controls, back up carefully, rotate keys regularly, and securely destroy retired keys.
