What is an HSM?
A tamper-resistant hardware module that stores keys and performs cryptographic operations without exposing private key material.
Prevents key extraction and supports secure signing APIs.
Supports split knowledge and multi-person activation for sensitive actions.
Requires policies for backup and recovery; backups must be protected equally well.
Example Practice
Store the root CA key in an offline HSM, keep the device in a secure facility, and require multiple authorized parties to perform signing operations. For cloud providers, use a managed key service with strict access controls and audit logging.
Misconception: HSMs are a silver bullet. They raise security but must be paired with strong process, secure backups, and strict administrative controls.
