Module 3 › Chapter 3.2 › Hardening Flow
Steps
1. Isolate Management
Dedicated network, no tenant access.
2. Least Privilege
Limit hypervisor roles and require MFA.
3. Image Hygiene
Patch and scan templates before production.
4. Monitor & Audit
Log management actions and integrity checks.
Scenario
An admin endpoint is compromised. Because management networks were isolated and MFA required, the attacker cannot reach the hypervisor API to deploy malicious images. This containment prevents a broader compromise.
Common mistake
Assuming tenant network segmentation is enough. If management access is reachable from any tenant path, an attacker can leverage it to control hypervisor operations.
