Module 3 › Chapter 3.2 › Trusted Platform Module
Definition

Trusted Platform Module

A hardware chip that securely stores cryptographic keys and records measurements of the boot process to support platform attestation.

Endorsement and Attestation Keys
Device-unique keys used to prove platform identity and measured state.
Secure Boot Integration
Measurements taken during boot can prevent use of secrets if boot chain is altered.
Concrete example
A laptop with a TPM can seal disk encryption keys so those keys are only available if the boot measurements match a known-good configuration. If the bootloader was tampered with, the TPM will not release the key, preventing unauthorized decryption.
Common mistake
Using TPMs alone for enterprise key management. TPMs are excellent for device-bound keys and attestation but are not a replacement for HSMs for centralized, high-assurance key services.
Pro tip
Document which keys are sealed to TPM measurements and maintain a trusted baseline so attestation comparisons are meaningful during incident response.
