Module 3 › Chapter 3.2 › Key Concepts
Trusted Platform Module
Hardware chip for storing device-bound keys and attesting platform boot integrity.
Hardware Security Module
Enterprise-grade appliance for centralized, tamper-resistant key management and cryptoprocessing.
Hypervisor
The virtualization layer that must be hardened and monitored because its compromise breaks tenant isolation.
Final takeaway: map protections to their proper deployment contexts, verify configurations, and harden high-impact components such as the TCB and hypervisor first.
