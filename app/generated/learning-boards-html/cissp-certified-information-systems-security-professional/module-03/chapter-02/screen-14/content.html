Module 3 › Chapter 3.2 › Key Concepts
Memory Protection
Mechanisms that prevent unauthorized memory access and mark data pages non-executable.
Process Isolation
Each program operates in an isolated environment to prevent interference and unauthorized access.
Trusted Computing Base
The set of hardware, firmware, and software components whose correct operation enforces security policy.
Summary: Use these concepts as the checklist when auditing a host. Identify where protections are implemented, then verify configuration and patch state.
