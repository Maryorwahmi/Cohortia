Module 3 › Chapter 3.2 › TPM vs HSM
TPM
Endpoint-embedded, holds device-unique keys, performs limited crypto, supports platform attestation and sealing of keys to measured boot state. Ideal for disk encryption keys and local integrity checks.
When to use
Protect device-bound secrets and verify boot integrity on endpoints.
HSM
Network-attached or appliance-based module that manages keys at scale, provides tamper resistance and high-throughput cryptoprocessing, and supports enterprise PKI, code signing, and database encryption keys.
When to use
Centralized key management, high-assurance signing, and scenarios requiring FIPS-level tamper protection and auditability.
Concrete scenario
Use a TPM on endpoints to ensure a disk encryption key is only released on a known-good boot. Use an HSM in the data center to host the certificate authority's signing key used across many services.
