Module 3 › Chapter 3.2 › Process Isolation & TCB
Core claim

Isolation keeps faults and attacks contained

The OS enforces boundaries so processes cannot access each other's memory or privileged kernel areas. This preserves confidentiality and integrity at runtime.

Security Kernel & Reference Monitor
The security kernel mediates access; the reference monitor is the principle ensuring always-invoked, tamper-proof mediation.
Key Takeaway

Treat the TCB as your smallest, most critical trusted surface. Hardening here yields the greatest systemic benefit.

Annotated hierarchy
Hardware & Firmware
CPU, MMU, firmware that must be trusted for enforcement.
Security Kernel
Small, verifiable mediation layer inside the OS.
Reference Monitor
Concept enforcing access control checks as always-invoked and tamper-proof.
Applications
Run in isolated address spaces and rely on kernel mediation.
Common mistake
Not documenting or auditing TCB components. If you don't know what you trust, you cannot verify its integrity.
