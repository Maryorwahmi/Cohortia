Module 3 › Chapter 3.2 › Terminal Walkthrough
Commands
Run the following in a controlled test VM. These commands only read configuration and are safe for inspection.
Task 1: Check ASLR
echo "Checking ASLR status:" 
cat /proc/sys/kernel/randomize_va_space
Task 2: Check DEP / NX support
echo "Checking NX support:" 
grep -q nx /proc/cpuinfo && echo "NX supported" || echo "NX not found"
Task 3: Review kernel hardening parameters
echo "Inspecting sysctl hardening entries:" 
grep "net.ipv4.conf.all.rp_filter" /etc/sysctl.conf 
grep "net.ipv4.conf.default.rp_filter" /etc/sysctl.conf 
grep "net.ipv4.conf.all.accept_redirects" /etc/sysctl.conf 
grep "net.ipv4.conf.default.accept_redirects" /etc/sysctl.conf 
grep "net.ipv4.icmp_echo_ignore_broadcasts" /etc/sysctl.conf 
grep "net.ipv4.conf.all.log_martians" /etc/sysctl.conf
Interpretation
randomize_va_space = 2 indicates full ASLR. 'NX supported' suggests DEP is available at the CPU level. Presence of secure sysctl entries shows network hardening. If values differ from your baseline, investigate configuration management and patching status.
Safety note

Do not change production settings without impact analysis. Use a test VM to learn and then apply validated changes through configuration management.
