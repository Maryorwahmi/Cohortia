Module 3 › Chapter 3.2 › Common Mistakes
Ignoring OS Hardening
Relying on perimeter controls while leaving default settings or unpatched services increases risk. Use CIS or other baselines and automate compliance.
Weak Hypervisor Security
Treating the hypervisor like a normal host underestimates its impact. Isolate management and enforce least privilege.
Misunderstanding TPM/HSM Roles
TPM for platform attestation; HSM for centralized, high-assurance key management. Choose based on the use case.
Memory safety myth

ASLR and DEP increase difficulty for attackers but do not remove the need for secure development and testing to prevent memory corruption vulnerabilities.

TCB oversight

Inventory and audit every component you consider part of the TCB: firmware, drivers, kernel modules, and management agents.
