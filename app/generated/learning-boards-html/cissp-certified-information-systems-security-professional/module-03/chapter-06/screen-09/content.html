Module 3 › Chapter 3.6 › Network Segmentation (Purdue)
Purdue model — zones and conduits
Segment the network into zones from process devices up to enterprise systems and control traffic with firewalls and monitored conduits.
Zone examples
Level 0 - Field devices
Sensors, actuators, PLC I/O.
Level 1/2 - Control
PLCs, local control logic, HMI.
Level 3 - Operations
SCADA servers, historians.
Level 4/5 - Enterprise
DMZ, corporate network, business apps.
Practical redesign example
Convert a flat SCADA network into segmented zones. Add a DMZ for historians and patch servers, place firewalls that only allow whitelisted traffic, and deploy IDS between the DMZ and operations zone.
Key Takeaway

Segmentation must be enforced with strict ACLs, gateway controls, and monitoring to limit lateral movement and reduce impact of a breach.
