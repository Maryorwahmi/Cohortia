SCADA, DCS, PLC — quick definitions
Know the role each plays so you can match controls to their operational constraints.
SCADA — Supervisory Control
Monitors dispersed assets, aggregates telemetry, and issues supervisory commands over large areas.
DCS — Localized Process Control
Handles continuous control loops in a plant with tight timing and redundancy.
PLC — Controller
Specialized controller executing logic to operate machinery and actuators.
Operational implication
Because these systems directly affect physical processes, any security control must be evaluated for its effect on timing, redundancy, and safety protocols.
Example scenario
A SCADA HMI displaying sensor readings must be prevented from accepting unauthorized commands that could cause a pump to overrun. Controls include whitelisted command sets and strict access policies.
Key Takeaway

Map security controls to the ICS component’s role and timing needs. Do not apply blanket IT rules without checking operational impact.
