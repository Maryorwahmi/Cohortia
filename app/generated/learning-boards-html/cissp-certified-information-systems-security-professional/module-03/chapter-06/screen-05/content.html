Resource Constraints
Why limited CPU, memory and power change the security playbook.
Device-level limits
  • Insufficient RAM for full packet logs
  • Limited CPU for heavy asymmetric crypto
  • Battery constraints affecting uptime
Network & gateway options
Delegate heavy processes to secure gateways, use efficient protocols, and rely on network-based monitoring.
Key Takeaway

Pick lightweight device protections and rely on architecture—gateways, segmentation, and monitoring—to provide layered defense.

Concrete Example
A remote sensor cannot perform full TLS handshakes for every transmission. The solution is to authenticate to a nearby gateway once, use an efficient session protocol, and let the gateway handle heavy TLS connections to the cloud.
Common misconception
Assuming every embedded device can and should be patched as often as a server. Many devices must balance patch frequency with certification and operational uptime.
Pro tip
When possible, design the system so the gateway enforces policy and filters traffic; keep device code minimal and verifiable.
