Module 3 › Chapter 3.6 › Common Vulnerabilities
Vulnerabilities that recur
Understand the attack patterns so you can prioritize mitigations.
Unpatched firmware
Legacy OS and firmware with known vulnerabilities remain common in ICS.
Weak/default credentials
Factory passwords or easily guessed accounts provide quick access to attackers.
Insecure protocols
Unencrypted legacy protocols allow interception or forgery of commands.
Lack of segmentation
Flat networks allow lateral movement and easier reach to critical devices.
Concrete scenario
An enterprise compromise reaches an IoT gateway with default credentials. Because the OT network is flat, attackers can reach HMIs and issue disruptive commands.
Key Takeaway

Start with hygiene—remove defaults, harden configs, patch when possible—and pair those steps with segmentation and monitoring to limit damage.
