Core Concept
Digital Signatures
Provide authenticity, integrity, and non-repudiation via hash-then-sign.
Workflow
Hash message → encrypt digest with private key → recipient decrypts with public key and compares hash.
Use case
Signing software releases to provide users with assurance of origin and integrity.
Example scenario
A developer hashes the build and signs that hash with their private key. A user verifies the signature with the developer's public key and recomputes the hash of the downloaded file to confirm integrity.
Misconception
Digital signatures do not encrypt the message. They only prove origin and integrity.
Key Takeaway

Use signatures to authenticate and detect tampering; protect private keys to preserve non-repudiation.
