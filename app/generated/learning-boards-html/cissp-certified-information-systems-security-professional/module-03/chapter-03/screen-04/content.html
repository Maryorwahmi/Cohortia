Core Concept
Symmetric Encryption
Single shared key for both encrypting and decrypting data. Fast and suitable for bulk encryption.
Common algorithms
AES, DES, 3DES (historical).
Why modes matter
ECB is deterministic and unsafe for multi-block data; prefer CBC or GCM with proper IV/nonces.
Key Takeaway

Use AES for bulk data and always pair it with a secure mode and correct IV/nonce handling.

Modes of operation (visual)
ECB
Deterministic per-block encryption. Insecure for repeated blocks; leaks patterns.
CBC
Chains blocks with IV randomness. Requires correct IV and padding handling.
CTR
Turns block cipher into stream cipher with counter nonces; efficient for random access.
GCM
Provides confidentiality and integrity when nonces are unique; widely recommended.
Example scenario
Encrypting a multi-terabyte backup: AES-256 in GCM mode gives performance and integrity, as long as IVs/nonces are unique per encryption operation.
Common mistake
Using ECB for large files or reusing IVs in GCM undermines confidentiality and/or integrity.
