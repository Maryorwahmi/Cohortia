Practical scenario mapping
Short decision guide for common use cases.
Large backup encryption
AES-256 in an authenticated mode; protect keys and rotate regularly.
Software release verification
Sign the release hash with a private key; users verify with the public key.
Password storage
Salt each password and use a slow key derivation function rather than plain hashes.
Secure channel setup
Use Diffie-Hellman or ECC variants to establish ephemeral symmetric keys, then encrypt data symmetrically.
