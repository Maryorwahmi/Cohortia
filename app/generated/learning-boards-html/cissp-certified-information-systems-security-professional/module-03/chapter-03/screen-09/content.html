AES-256-CBC: Encrypt & Decrypt
Reproducible OpenSSL commands to encrypt a text file and then decrypt it.
# --- Setup: Create a test file
echo "This is a secret message for encryption testing." > secret_message.txt

# Encrypt with AES-256-CBC, using salt and PBKDF2 for key derivation
openssl enc -aes-256-cbc -salt -pbkdf2 -in secret_message.txt -out secret_message.enc -k "MyStrongPassword123!"

# Decrypt to recover the original
openssl enc -d -aes-256-cbc -pbkdf2 -in secret_message.enc -out decrypted_message.txt -k "MyStrongPassword123!"

# View decrypted content
cat decrypted_message.txt
Observation
The encrypted file contains salt metadata. Different salts yield different ciphertexts for identical plaintexts.
Practice tip
Use strong passphrases or better yet, securely manage keys rather than relying on typed passwords in production.
Example card
This small workflow demonstrates the cryptographic lifecycle: key derivation, encryption, storage of ciphertext, and successful decryption with the same keying material.
Key Takeaway

For reproducible testing use OpenSSL, but for production use robust key management rather than passphrase-derived keys.
