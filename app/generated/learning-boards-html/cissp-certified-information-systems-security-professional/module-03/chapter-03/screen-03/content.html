Practical Skills & Safety
Reproducible OpenSSL exercises and rules to avoid common cryptographic mistakes.
Safety: Avoid deprecated algorithms
Hands-on outcomes
  • Encrypt and decrypt a file with AES-256-CBC using OpenSSL and observe the ciphertext.
  • Compute SHA-256 digests before and after modifying a file to witness integrity checks fail on tampering.
  • Generate a 2048-bit RSA keypair and extract the public key for signature verification.
Common pitfalls
Hardcoding keys, reusing nonces, and using weak algorithms are frequent causes of compromise.
