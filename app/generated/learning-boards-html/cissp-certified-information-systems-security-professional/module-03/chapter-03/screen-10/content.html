SHA-256: Compute and compare digests
See how a single change produces a dramatically different digest.
# Create a file to hash
echo "This is a file for hashing integrity check." > integrity_check.file

# Compute SHA-256 digest
openssl dgst -sha256 integrity_check.file

# Modify the file and compute again
echo "Appending new line." >> integrity_check.file
openssl dgst -sha256 integrity_check.file
Observation
The two digest outputs will differ completely, illustrating sensitivity to small changes.
Trust note
Ensure the digest source is trusted; storing a digest alongside the file without protection is insufficient.
Analogy
A hash is like a fingerprint: two different objects rarely share the same fingerprint if the hash function is collision-resistant.
Key Takeaway

Hashes detect tampering effectively when the original digest is obtained via a trusted channel and salts are used for password storage.
