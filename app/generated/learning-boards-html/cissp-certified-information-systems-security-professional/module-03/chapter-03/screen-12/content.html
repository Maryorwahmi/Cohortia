Comparison
Common Mistakes
  • Using deprecated algorithms (DES, MD5, SHA-1).
  • Hardcoding keys in application code or config files.
  • Reusing IVs/nonces, especially in authenticated modes.
  • Improperly implementing cryptographic primitives instead of using vetted libraries.
Best Practices
Mitigations
  • Select modern algorithms: AES-256, SHA-256/SHA-3, RSA 2048-bit+ or ECC.
  • Use secure, unique randomness for IVs and key generation.
  • Protect keys: rotate, revoke, and store private keys securely.
  • Prefer authenticated encryption modes and vetted libraries.
Key Takeaway

Strong algorithms alone are not enough — correctness of implementation, randomness, and lifecycle management are essential.
