RSA: Generate private key and extract public key
Create a 2048-bit RSA keypair and derive the public key for distribution.
# Generate a 2048-bit RSA private key
openssl genrsa -out rsa_private.pem 2048

# Extract the public key from the private key
openssl rsa -pubout -in rsa_private.pem -out rsa_public.pem

# Files: rsa_private.pem (keep secret), rsa_public.pem (share as needed)
Practice note
Protect the private key with filesystem controls or move it into a hardware key manager for signing operations.
Scenario card
Signing installers: keep the private signing key offline or in a protected store, publish the public key to verifiers.
Key Takeaway

Use RSA keys for signatures and key distribution, and secure private keys to maintain authenticity.
