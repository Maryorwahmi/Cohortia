Definition
Hashing functions
One-way transforms for integrity checks and password verification.
Properties
Deterministic, one-way, collision-resistant.
Salting
Add a unique random string to each password before hashing to avoid rainbow tables.
Example: file integrity
Compute SHA-256 digest of a file, modify one byte, then recompute to see a different digest that reveals tampering.
Password storage note
Never store passwords in plaintext. Use a salt plus a slow key derivation function to make brute force attacks expensive.
Common mistake
Using MD5 or SHA-1 for password hashing or integrity checks that must resist collision attacks.
