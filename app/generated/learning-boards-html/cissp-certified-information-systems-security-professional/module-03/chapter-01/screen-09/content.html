Formal Model

Bell-LaPadula: confidentiality by labels

This model uses security levels and two rules to prevent unauthorized disclosure: Simple Security (no read up) and Star Property (no write down).
Simple Security Property
A subject cannot read data at a higher sensitivity than the subject's clearance.
Star Property
A subject cannot write information to a lower sensitivity level, preventing leakage.
Example
A process at Confidential cannot write to a Public file. This prevents accidental disclosure when handling high-sensitivity data.
Considerations
Where it fits
Suitable when confidentiality is the system's primary objective, such as classified information systems.
Misconception
Bell-LaPadula protects disclosure, not integrity. Don't apply it blindly where integrity is the core concern.
Key Takeaway
Use BLP when you must prevent information from flowing from high to low sensitivity levels.
