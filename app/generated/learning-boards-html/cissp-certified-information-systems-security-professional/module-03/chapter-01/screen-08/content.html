Module 3 › Chapter 3.1 › Psychological Acceptability and Usability
Definition

Make secure behaviors the easy behaviors

Usable security reduces risky workarounds and increases the longevity of controls.

Concrete example
Single sign-on plus a streamlined second factor reduces login friction and avoids users storing passwords insecurely.
Common mistake
Implementing controls without user testing leads to non-compliance and shadow practices.
Key Takeaway

Design controls that align with real workflows to maintain security and minimize risky user workarounds.

Design Checklist
Observe workflows
Identify where security steps create real friction and reduce unnecessary steps.
Automate recovery
Provide safe, quick recovery paths so users don't bypass controls when errors occur.
Test with users
Validate that users follow the control under normal workload and time pressure.
