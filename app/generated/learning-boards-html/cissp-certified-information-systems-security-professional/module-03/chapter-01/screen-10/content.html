Formal Model

Biba: integrity through restrictions

Biba's rules prevent lower-integrity data from contaminating higher-integrity subjects and objects.
Simple Integrity Property
No read down: a subject must not read data from a lower integrity level.
Star Integrity Property
No write up: a subject must not write information to a higher integrity level.
Example
Sensor data of uncertain provenance should not be allowed to update a high-integrity control table without verification and transformation.
Considerations
Misconception
Biba does not focus on confidentiality. Applying it where secrecy is the primary need will miss disclosure risks.
When to use
Financial records, audit logs, or control-system state where correctness of data is critical.
Key Takeaway
Use Biba where preventing contamination and unauthorized modification is the design goal.
