Module 3 › Chapter 3.1 › Defense in Depth vs Fail-Safe Defaults
Comparison

How they align

Defense in Depth
Multiple, independent barriers so that bypassing one control does not lead straight to the asset.
Fail-Safe Defaults
Components fail to a secure state, denying access or actions by default to prevent accidental exposure.
Integration Example
An authentication service is protected by a perimeter firewall and host protections. If the auth service fails, the application denies logins and raises alerts rather than allowing unauthenticated fallback access.
Misconception
Adding many controls without consistent error handling creates complexity that attackers can exploit.
Check Your Design
Test failure modes
Simulate outages and verify each layer denies access and logs the event.
Design goal
Keep layers few but strong, with consistent fail-safe behavior and monitoring to catch anomalies early.
Key Takeaway
Layered defenses must use consistent, secure failure modes to remain effective.
