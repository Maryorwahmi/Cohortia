Module 03 › Chapter 3.5 › Mobile Application Security
Mobile threats
Device loss, untrusted networks, reverse engineering, and over-privileged apps increase risk.
Device security
Keep OS updated, use encryption, enforce passcodes and biometrics.
App storage
Use hardware keystore or secure enclave; avoid plain local storage for sensitive tokens.
Networking
Always use TLS and validate certificates; minimize sensitive data in transit.
Developer practices
  • Request minimal permissions and explain their purpose to users.
  • Use obfuscation and anti-tampering as additional layers, not primary defenses.
  • Avoid embedding secrets in code or resources; use secure distribution and runtime retrieval.
Key Takeaway

Design mobile apps assuming the device may be lost or inspected. Minimize stored secrets and rely on hardware-backed protections when available.
