Module 03 › Chapter 3.5 › XSS — Safe Output
Lab task
Identify the vulnerable assignment and replace it to prevent script execution.
<!-- Vulnerable snippet (simulated server-side rendering) -->
const urlParams = new URLSearchParams(window.location.search);
const userName = urlParams.get('name') || 'Guest';
document.getElementById('userNamePlaceholder').innerHTML = userName;

<!-- Corrected code -->
document.getElementById('userNamePlaceholder').textContent = userName;
Explanation: innerHTML interprets markup. textContent treats the string as plain text, so tags and scripts are rendered inert.
Checklist
  • Replace innerHTML with textContent or server-side encoding.
  • Apply Content Security Policy to restrict script execution sources.
  • Sanitize where HTML is intentionally allowed, using vetted libraries.
Key Takeaway

Prefer safe insertion methods and server-side encoding. Treat XSS prevention as both a coding and a configuration task.
