Comparison

Perimeter Security

Purpose: deter and detect before the attacker reaches the building. Typical controls include fences, gates, signage, and lighting. These reduce probability of approach and increase chance of early response.

Failure Mode

If perimeter fails, intruders are closer and response time shortens. Mitigation: redundant lighting, patrols, and rapid alarm channels.

Building Exterior

Purpose: limit direct access to the structure and detect attempts to breach building entry points. Controls include reinforced doors, alarmed windows, roof access locks, and CCTV with recording.

Failure Mode

If exterior controls fail, attackers can enter quickly. Mitigation: layered interior controls and immediate lockdown procedures triggered by sensors.

Key Takeaway

Perimeter gives early warning; exterior hardening limits immediate entry. Plan redundancies across both.
