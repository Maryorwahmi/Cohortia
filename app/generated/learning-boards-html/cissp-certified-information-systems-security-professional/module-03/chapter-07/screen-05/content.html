Process Flow

Layered Physical Model

Perimeter Security

Fencing, gates, signage, and lighting that deter, detect, and delay. Early detection reduces response time and exposure.

Building Exterior

Reinforced doors, alarmed windows, CCTV, and roof access controls limit direct entry paths to the building.

Building Interior

Card readers, biometrics, mantraps, security staff, and CCTV provide the final barriers to sensitive areas.

Visual Example
Example: Data Center in Office Building
  • Perimeter: gated compound with motion-activated lighting.
  • Exterior: CCTV at doors, reinforced frames, alarmed windows.
  • Interior: Reception check, floor card access, mantrap at server room, biometric reader on cabinets.
Misconception Check

Avoid repeating the same control type across layers. Use complementary controls for detection, delay, and response instead.

Key Takeaway

Layered, complementary controls provide measurable detection, delay, and response at each stage.
