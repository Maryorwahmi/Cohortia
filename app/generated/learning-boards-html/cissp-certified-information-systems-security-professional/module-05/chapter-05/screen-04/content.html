Module 5 › Chapter 5.5 › What is IDaaS?
IDaaS — compact definition

A cloud-hosted identity platform offering SSO, MFA, provisioning, and governance so teams can scale identity without managing underlying infrastructure.

Services included
Single sign-on, adaptive multi-factor authentication, user provisioning, directory connectors, access reviews and reporting.
Concrete example
A company uses an IDaaS provider for SSO to Microsoft 365 while maintaining on-premises HR and AD; the IDaaS handles MFA and federated access for cloud apps.
Common misconception
IDaaS is not a free pass to ignore on-prem directories or governance; synchronization and access reviews remain necessary.
Key Takeaway

IDaaS centralizes identity capabilities to reduce operational burden, but organizations still configure security controls and integrate authoritative directories correctly.

Analogy
IDaaS is like a managed utilities provider for identity — it supplies authentication and access services while you specify policies and usage.
Why organizations adopt IDaaS
  • Reduce maintenance of identity infrastructure and scale globally.
  • Gain access to advanced features like adaptive MFA and identity governance.
  • Enable consistent access across cloud and hybrid applications.
