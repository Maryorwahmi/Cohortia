Module 5 › Chapter 5.5 › AD vs AAD
Active Directory (On-prem)
Authentication & Domain Services
  • Kerberos and NTLM authentication
  • Group Policy and DNS integration
  • Authoritative store for Windows domain attributes
Example
A domain-joined workstation uses Kerberos tickets to access a file server on the corporate network.
Azure Active Directory (Cloud)
Cloud identity and access tokens
  • Token-based authentication for cloud resources and SaaS
  • Federation, SSO, and adaptive MFA
  • Identity governance and app integrations
Example
A user signs in to Microsoft 365 and receives an access token that the service uses for authorization.
Integration note
Use synchronization tools or federation to ensure consistent identity state. Plan attribute mappings and know which features remain on-premises.
