Recommended sequence
A phased approach reduces operational disruption and improves security steadily.
Phase 1
Enforce MFA
Phase 2
Least privilege audit
Phase 3
Automate provisioning/deprovisioning
Phase 4
Monitoring & access reviews
Concrete example
Enable MFA, then run a privilege audit to remove broad roles, automate new user provisioning, and schedule quarterly access reviews with logs preserved for audit.
Misconception
Thinking one control is sufficient is risky; combine MFA, least privilege, automation, and monitoring for a layered defense.
