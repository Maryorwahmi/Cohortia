LDAP and Active Directory
Directories act as authoritative stores for identity attributes and group information.
LDAP
A protocol for querying and modifying directory entries; used by many directory services.
Active Directory
Provides authentication, Kerberos, domain services, group policy, and integrates with DNS.
Concrete scenario
A user password change on-premises updates Kerberos tickets and, when synced, updates cloud authentication to preserve a single credential experience.
Common misconception
Directories are not replaced by cloud IAM in hybrid setups; they remain authoritative sources that cloud services either federate with or synchronize from.
How directories affect authorization
Authorization often uses group membership and attributes read from the directory. Keeping these accurate prevents privilege creep and unauthorized access.
Why this matters
If directory attributes are stale or unsynchronized, users may retain access they should have lost, or lose access they still need — both create security and availability problems.
