Module 5 › Chapter 5.5 › Provisioning & Deprovisioning
Provisioning process
  1. HR triggers account creation with role and department metadata.
  2. Provisioning engine creates directory account and assigns groups.
  3. Connected apps receive provisioned accounts and entitlements.
  4. Audit logs record all actions and notify approvers where needed.
Example
A new developer onboarding triggers creation in AD, membership in developer groups, and access to source control and CI tools automatically.
Deprovisioning process
  1. HR marks termination in the authoritative system.
  2. Workflow disables the on-premises directory account.
  3. Sync propagates disability to cloud identities and connected apps revoke access.
  4. Licenses are reclaimed and actions are logged for audit.
Common mistake
Delaying deprovisioning or relying on manual steps creates orphaned accounts and increases breach risk.
Key Takeaway
Automate lifecycle actions from authoritative HR events, include verification and logging, and test deprovisioning regularly to remove access promptly.
