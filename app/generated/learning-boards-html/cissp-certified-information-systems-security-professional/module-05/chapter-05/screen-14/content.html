Module 5 › Chapter 5.5 › Key Concepts
Identity as a Service (IDaaS)
Cloud-delivered SSO, MFA, provisioning, and governance.
Directory Service
Authoritative store for users, groups, and devices used for authentication and authorization.
Identity Synchronization
The process that keeps on-premises and cloud identity data consistent.
Summary Takeaway

Adopt a layered identity model: authoritative directories plus cloud IAM, synchronized state, automated lifecycle actions, and continuous monitoring to reduce risk.
