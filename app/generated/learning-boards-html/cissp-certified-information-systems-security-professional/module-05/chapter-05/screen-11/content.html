Module 5 › Chapter 5.5 › Shared Responsibility
Provider responsibility
  • Platform availability and underlying infrastructure security.
  • Service-level protections and automated platform patches.
Note
Provider responsibilities vary; always review the provider's shared responsibility documentation for specifics.
Customer responsibility
  • Configure IAM roles and least privilege.
  • Protect API keys and service accounts and monitor identity logs.
  • Set up MFA and just-in-time access for privileged identities.
Common risk
Overly permissive roles and exposed access keys increase the chance of broad compromise if a credential is stolen.
Key Takeaway
Treat IAM as a shared responsibility: enforce least privilege, protect service accounts, enable MFA, and monitor identity activity continuously.
