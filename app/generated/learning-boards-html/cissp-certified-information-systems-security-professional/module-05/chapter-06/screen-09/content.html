Architecture

Component overview

Discovery
Continuous scans to find privileged/service accounts and orphaned credentials.
Vaulting
Encrypted repository and access controls for secrets.
Session Gateway
Launches and records privileged sessions while injecting credentials.
Rotation & JIT
Rotate secrets automatically and grant just-in-time, time-limited access.
Example workflow
Continuous discovery finds a service account, vault stores its password. An engineer requests access, PAM issues a temporary credential, opens a recorded session, and rotates the password after use.
Monitoring
Analyze session recordings and alert on anomalous commands or long-running sessions. Monitoring provides the signals to improve policies and detect misuse.
Common mistake
Assuming discovery is static. Without continuous discovery, new service accounts and containers will remain unmanaged and risky.
Key Takeaway
Ensure components hand off automatically so access requests are short-lived, logged, and auditable.
