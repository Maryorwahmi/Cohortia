Module X › Chapter 5.6 › Privileged Access Management
Definition

Protect accounts with elevated privileges

Discovery
Find all privileged accounts across systems, including service accounts.
Vaulting
Store credentials encrypted and control retrieval.
Session Management
Launch sessions via gateway with recording for audit and monitoring.
Password Rotation & JIT
Rotate passwords after use and grant time-limited access on demand.
Concrete example
An administrator requests access to a production server via PAM. The system retrieves a one-time password from the vault, opens a recorded session, and rotates the credential after the session ends.
Risks addressed
  • Shared credentials and unknown accounts
  • Long-lived credentials that increase exposure
  • Lack of session accountability
Common mistake
Treating PAM as only password storage. Without session controls and rotation, risk remains high.
