Module 5 › Chapter 5.4 › Mandatory Access Control
Definition

Label-based, centrally enforced

Subjects and objects carry labels. The system enforces access by comparing clearances and classifications plus optional categories.

When MAC fits
  • Government, military, and other environments requiring strict need-to-know controls.
  • Systems where owners must not be able to override policy.
Trade-offs
  • High administrative overhead to label and maintain resources and users.
  • Requires specialized infrastructure and governance.
Concrete example
A document classified as "Secret, Project Alpha" requires a user with clearance Secret and matching category Project Alpha. Owners cannot grant access if the subject lacks those labels.
Misconception

MAC is not always necessary; it is strongest where policy must be non-discretionary. In many commercial settings RBAC gives sufficient control with lower overhead.

Key question

Does your environment require system-enforced labels despite the administrative cost?
