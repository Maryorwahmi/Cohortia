Module 5 › Chapter 5.4 › Discretionary Access Control
Definition

Owner-managed permissions

Owners grant or revoke access. This decentralization gives flexibility but reduces consistency and central oversight.

When DAC fits
  • Personal files, developer environments, small teams.
  • Quick sharing where central policy would slow work.
Risks
  • Privilege creep from ad-hoc grants.
  • Hard to audit and enforce across many owners.
Concrete example
File owner sets permissions: user alice grants group finance read access to a spreadsheet. Owner later adds bob without a formal review, creating an accidental expanded audience.
Pro tip

Combine DAC with periodic automated audits that flag ACLs with overly broad grants. This keeps owner flexibility but reduces drift.
