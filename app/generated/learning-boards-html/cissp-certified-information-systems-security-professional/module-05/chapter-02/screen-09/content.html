Comparison

MFA implementations

Compare common MFA methods and their security properties to choose the right fit for each risk tier.

SMS
Convenient but susceptible to SIM swap and interception; avoid for critical systems.
TOTP
Authenticator apps generate time-based codes and are more secure than SMS.
FIDO2
Security keys and WebAuthn are phishing-resistant and recommended for high assurance.
Example implementation
High-assurance admin access
Require a hardware security key plus a PIN. This combination resists phishing and prevents remote compromise even if a password is leaked.
Common mistake
Allowing weak recovery options or inconsistent MFA enforcement across apps, which negates protections.
Key Takeaway

Use MFA with at least two different factor types and select phishing-resistant methods for high-risk systems while designing strong recovery flows.
