Comparison

The three categories

Understand each factor's properties, examples, and practical limitations so you can choose complementary methods.

Something you know
Passwords, PINs. Vulnerable to phishing and reuse; require strong policies and user education.
Something you have
Smart cards, hardware keys, OTP apps, SMS or push. Stronger but subject to loss, theft, or SIM-based attacks.
Something you are
Fingerprints, face, iris, voice, or behavior. Convenient but raises privacy, spoofing, and irrevocability issues.
Misconception
Assuming a biometric alone is always high assurance. Evaluate false accept/false reject trade-offs and the consequences if biometric data is compromised.
Concrete scenario
Example: enterprise laptop login
Combine a password (something you know) with a hardware security key (something you have). This makes remote phishing of the password insufficient because the attacker would also need the physical key.
Key Takeaway

Classify methods correctly and pair different factor types to compensate for each other's weaknesses.
