Architecture

Token types and properties

Compare token categories and evaluate resistance to attacks like cloning or interception.

Hardware keys
Phishing-resistant cryptographic challenge-response. Strong but requires distribution and backups.
Authenticator apps & OTP
Time-based codes are convenient and more secure than SMS, but can be cloned if device is compromised.
SMS and push
User-friendly; push is better than SMS. SMS is susceptible to SIM swap and interception.
Operational example
Large workforce deployment
For 500 employees, authenticator apps or push notifications reduce hardware costs. Hardware keys offer best security but require budget for procurement and lost-key handling.
Common mistake
Weak recovery flows that allow simple identity resets via less-secure channels, e.g., email or SMS, which negate the token's protection.
Key Takeaway

Select possession factors to match threat models and ensure replacement and recovery procedures preserve assurance.
