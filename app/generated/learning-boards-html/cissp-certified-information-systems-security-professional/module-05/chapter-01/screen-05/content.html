Module 5 › Chapter 5.1 › Identification
Definition

Claiming an identity

Identification is how a user or system presents a named identifier that the service can map to an account and attributes.

  • Identifiers must be unique and stable for reliable audits.
  • Use internal immutable IDs for enforcement; display names are for humans.
  • Define a naming convention to reduce collisions and simplify administration.
Example

Active Directory uses a unique Security Identifier so even if two users share a display name, each action maps to the correct account.

Practical naming cards
Convention A
first initial + last name (jsmith). Add numeric suffix when duplicate.
Convention B
employee ID based (EMP12345) for guaranteed uniqueness.
Lifecycle rule
Never immediately recycle identifiers; apply a quarantine period to avoid misattribution.
Audit tip
Store both display name and immutable ID in logs to support clear reporting.
Common mistake: relying on email addresses that can be reassigned without updating legacy logs.
