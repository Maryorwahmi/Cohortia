Logging and SIEM

Accountability relies on comprehensive logging, centralization, and correlation so teams can detect and investigate incidents.

Events to log
Log auth attempts, file access, config changes, and privilege grants.
Centralization
Aggregate logs in a SIEM to correlate cross-system behavior.
Retention
Store logs long enough to support investigations and compliance needs.
Example: Correlate failed access attempts, successful admin login, and configuration changes to detect potential account takeover followed by privilege escalation.
Practical checklist
  • Include unique IDs in every log entry.
  • Protect log integrity and limit access to logs.
  • Create correlation rules for high-risk sequences.
  • Schedule regular log review and alert tuning.
Key Takeaway

Logs are only useful when they contain unique identifiers, are centralized, and are actively reviewed or correlated for alerts.
