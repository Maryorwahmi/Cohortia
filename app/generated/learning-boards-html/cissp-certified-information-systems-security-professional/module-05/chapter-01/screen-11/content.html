Module 5 › Chapter 5.1 › Identity Lifecycle
Timeline

Provision → Change → Deprovision

  1. Provision: create identity, apply baseline role and MFA requirements.
  2. Manage: adjust permissions when roles or projects change; use approvals for elevation.
  3. Deprovision: disable and remove access promptly when no longer required.
Example: Contractors receive temporary accounts that expire at contract end. Automating expiration prevents accounts from lingering and reduces cleanup work.
Controls
Auto-provision templates for common roles
Time-bound elevated access with automatic expiry
Exit workflows that immediately revoke credentials
Risk: delayed deprovisioning is a frequent cause of unauthorized access post-employment.
