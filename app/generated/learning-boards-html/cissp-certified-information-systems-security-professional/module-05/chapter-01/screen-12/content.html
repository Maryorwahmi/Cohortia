Scenario

New Role: Junior Data Analyst

Fill the template to practice operational decisions that support least privilege and accountability.

Template (fill in):
**New Role: Junior Data Analyst**

1. Identification Naming Convention:
   - [e.g., jdoe, or EMP12345]

2. Authentication Factors:
   - Primary (something you know): [e.g., strong password]
   - Secondary (something you have/are): [e.g., mobile authenticator app]

3. Initial Authorization Requirements:
   - Resource 1: \\\\corpdata\\analytics\\reports
     - Access Level: Read-Only
   - Resource 2: SQL Database AnalyticsDB
     - Access Level: SELECT on SalesData table
   - Resource 3: Data Visualization Tool
     - Access Level: Dashboard viewing and report generation

4. Accountability Measures:
   - Log all login attempts, DB queries on SalesData, and access to reports with user ID and timestamp.
   - Retain logs for investigation period and schedule quarterly review.
Guided example
Example answer
ID: first initial + last name with numeric suffix. Auth: strong password + authenticator app. Permissions: read-only reports, SELECT on SalesData, view dashboards. Accountability: log logins, DB access, and file reads with retention and quarterly review.
Check your work: does each permission follow least privilege? Is elevated access time-limited and approved? Are logs stored with user IDs and timestamps?
