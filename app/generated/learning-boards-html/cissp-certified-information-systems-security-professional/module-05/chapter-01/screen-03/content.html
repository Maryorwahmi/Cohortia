Practical checklist

Create a policy snapshot

  • Naming: standardize usernames to avoid collisions and ease audits.
  • Authentication: require strong passwords and a second factor for remote access.
  • Authorization: assign least privilege and document initial resource scopes.
  • Accountability: enable logging of key events and schedule reviews.
VERIFIED COMPETENCY MILESTONE
Mnemonic
CLAAR
Claim (identify), Verify (authenticate), Allow (authorize), Audit (accountability), Review (lifecycle).
How to practice
  1. Write a naming convention for one role.
  2. Choose authentication factors and justify them.
  3. List three resources and assign minimal access.
  4. Describe which events you would log and why.
