Module 5 › Chapter 5.3 › OAuth
Definition

OAuth — delegated authorization

A framework to grant limited access to resources without sharing user credentials, issuing access tokens to clients on consent.

Artifacts: authorization code, access token, refresh token.
Pitfall: access tokens are not identity assertions; don’t treat them as proof of who the user is.
Concrete example
A third-party app asks permission to read a user's social feed. The user grants consent at the social provider, and the app receives an access token to call the provider's API without ever seeing the user's password.
Key Takeaway

OAuth is for delegated access. Use OIDC when you require authenticated identity tokens.
