Practice checks and validation steps

Concrete checks you can perform when reviewing an integration.

  • Check SAML assertions are signed and include expected attributes like a stable identifier and roles.
  • Verify OAuth redirect URIs are exact matches and that scopes are minimal for the task.
  • Validate JWT signatures and required claims when using OIDC for sign-in.
  • Ensure domain controllers and clients are time-synchronized for Kerberos to succeed.
Mnemonic
Think: Authenticate once, validate everywhere. Each protocol issues artifacts that must be checked for integrity and correct routing.
