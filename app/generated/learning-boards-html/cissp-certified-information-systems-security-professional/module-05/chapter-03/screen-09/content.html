Module 5 › Chapter 5.3 › OpenID Connect (OIDC)
Definition

OpenID Connect

An identity layer on OAuth that issues ID tokens as signed JSON Web Tokens to prove authentication and provide profile claims.

ID tokens are signed; clients must validate issuer, audience, and expiration claims.
OIDC suits modern web and mobile apps and social login providers.
Concrete example
When a user selects 'Sign in with Google', the client receives an ID token that it validates to confirm the user's identity, while an access token allows API calls if needed.
Misconfiguration risk

Failing to validate JWT signatures and claims opens the system to token replay or forged tokens; always validate issuer, audience, and expiry.
