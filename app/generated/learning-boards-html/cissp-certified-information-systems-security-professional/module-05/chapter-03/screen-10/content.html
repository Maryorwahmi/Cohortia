Definition

Kerberos

A ticket-based authentication protocol using a Key Distribution Center to issue TGTs and service tickets without sending passwords across the network.

Key components: client, KDC, Ticket Granting Ticket, service tickets, and services with SPNs.
Misconfiguration: clock skew and wrong SPNs often break authentication.
Scenario card
A user logs into a domain-joined workstation. The workstation authenticates to the KDC and receives a TGT. Later, when the user opens a file share, the client requests a service ticket for that file server using the TGT and presents the service ticket to access resources.
Key Takeaway

Kerberos secures local domain authentication through tickets and a trusted KDC; ensure accurate time sync and SPN registration to keep it working.
