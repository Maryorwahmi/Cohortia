Module 5 › Chapter 5.3 › SAML vs OAuth vs OIDC
SAML

Enterprise SSO

XML assertions, browser redirects, signed assertions; common for B2B and enterprise SaaS SSO.

OAuth

Delegated Authorization

Framework for granting third-party apps limited access to user resources without sharing credentials.

OpenID Connect

OAuth + Identity

Adds an identity layer using signed JSON Web Tokens for authentication and profile claims; mobile-friendly.

Practical guidance: choose SAML for legacy enterprise SSO integrations, OAuth for delegated API access and third-party actions, and OIDC when you need a standardized authentication token for web or mobile sign-in. Never treat OAuth alone as proof of identity.
Misconception

OAuth is not an authentication protocol. Use OIDC when you need reliable identity assertions.
