Definition

Single Sign-On (SSO)

Users authenticate once to an IdP and then access multiple SPs without re-entering credentials, improving usability and security.

Important: SPs still enforce local authorization and role mapping.
Security note: Protect the IdP with multi-factor authentication and monitoring; compromise affects many services.
Concrete example
A user logs into the corporate IdP at work. After authentication, they access email, CRM, and cloud storage without separate logins. Each SP accepts the IdP assertion or token to create a session.
Key Takeaway

SSO gives seamless access across services, but you must secure the IdP and maintain SP-level authorization controls.
