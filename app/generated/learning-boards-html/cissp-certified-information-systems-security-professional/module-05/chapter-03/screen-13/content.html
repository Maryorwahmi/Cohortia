Module 5 › Chapter 5.3 › Common Misconfigurations

Common configuration risks and checks

  • OAuth/OIDC: Strictly match redirect URIs and validate ID token signatures and claims (issuer, audience, expiry).
  • SAML: Ensure entity IDs and certificates are correctly exchanged and signatures validated.
  • Kerberos: Keep time synchronized and register correct Service Principal Names.
  • Operational: Protect IdP signing keys with secure storage and rotation; monitor for unusual token use.
Quick mitigations
  • Register exact redirect URIs.
  • Validate JWT signatures and claims on every request.
  • Use NTP and monitor Kerberos errors.
  • Rotate IdP keys and monitor access to them.
Warning

Neglecting these checks can lead to token interception, replay, or widespread account impersonation.
