Module 5 › Chapter 5.3 › Key Concepts
Federated Identity
One IdP manages identity and attributes for multiple SPs.
SAML
XML-based assertions and signed exchanges for enterprise SSO.
OAuth
Delegated authorization for APIs; not an authentication protocol by itself.
Summary
Match protocol to the problem: SAML for enterprise SSO, OAuth for delegated access, OIDC for modern identity tokens, and Kerberos for domain authentication. Protect signing keys and validate tokens to maintain trust.
