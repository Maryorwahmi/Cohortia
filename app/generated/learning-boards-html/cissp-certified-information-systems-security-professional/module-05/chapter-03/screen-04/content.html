Module 5 › Chapter 5.3 › Federated Identity
Definition

Federated Identity

An IdP manages user identity and attributes, which SPs accept so users don’t need separate accounts for each service.

Benefits
  • Centralized provisioning and deprovisioning
  • Improved user experience through fewer logins
  • Consistent policy and stronger auditability
Common misconception
Federation doesn’t remove SP authorization needs; SPs must still map attributes and enforce fine-grained access control.
Analogy & Example
Analogy: an IdP is like a passport office that issues a stamped document the traveler shows at different border checkpoints. Example: an internal Active Directory IdP issues assertions so a user gets SSO access to an external HR SaaS without a separate account.
Key Takeaway

Federation centralizes identity authority; ensure SPs validate and map attributes correctly to avoid authorization gaps.
