Module 5 › Chapter 5.7 › What is PKI?
Definition

Public Key Infrastructure

A system of authorities, certificates, and policies that binds public keys to identities so systems can trust keys and signatures.

Analogy
CA as a passport office: verification then issuance of a credential that others trust.
Services
Confidentiality, integrity, authentication, and non-repudiation enabled by certificates.
Components
CAs, RAs, certificates, revocation data, and client trust stores.
Common mistake
Assuming certificates alone secure systems without operational controls.
Concrete example
When a browser connects to a website, it receives the server certificate. The browser verifies the signature on that certificate, confirms the issuing CA is trusted, and checks validity and revocation status before establishing an encrypted session.
Key Takeaway

PKI ties keys to identities via trusted signatures and operational practices; protect keys and check status.
