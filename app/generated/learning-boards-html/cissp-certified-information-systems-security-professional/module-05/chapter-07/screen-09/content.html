Process

From CSR to certificate

  1. Generate key pair locally; keep private key secret.
  2. Create CSR containing public key and identity fields.
  3. Submit CSR to CA; RA may verify identity.
  4. CA signs and issues the certificate; installer deploys certificate and intermediates.
Concrete cautions
Never transmit the private key. Store it with access controls or in an HSM. Ensure the server presents the full chain including intermediates so clients can validate back to a trusted root.
Key Takeaway
CSRs carry public info for signing; secure private keys and deploy full chain to enable client validation.
