Module 5 › Chapter 5.7 › CRL vs OCSP
CRL

Periodic list of revoked certs

Published by the CA, downloaded by clients. Can be large and introduce latency between revocation and client awareness.

OCSP

Real-time single-certificate check

Clients query an OCSP responder for a certificate's status; OCSP stapling lets servers present recent responses to clients to reduce direct queries.

Concrete example
After key compromise, CA revokes the certificate and updates OCSP responders so clients see the revoked status quickly.
Misconception
Assuming revocation is instantaneous for all clients ignores CRL publication intervals and OCSP caching behaviour.
Key Takeaway
Choose OCSP for timely checks; use stapling to reduce client load and latency where supported.
