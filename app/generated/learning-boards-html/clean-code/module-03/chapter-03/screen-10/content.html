Starter code (violates CQS)
A single method adds items and returns the total.
# Starter code
class ShoppingCart:
  def __init__(self):
    self.items = {}  # {item_id: quantity}

  def add_item_and_get_total(self, item_id, quantity, price_per_item):
    """
    Adds an item to the cart and returns the current total.
    Violates CQS.
    """
    if item_id in self.items:
      self.items[item_id] += quantity
    else:
      self.items[item_id] = quantity
    print(f"Added {quantity} of item {item_id} to cart.")

    current_total = 0
    for item_in_cart, qty_in_cart in self.items.items():
      assumed_price = price_per_item if item_in_cart == item_id else 10
      current_total += assumed_price * qty_in_cart

    print(f"Current cart total: {current_total}")
    return current_total
Refactor instructions
  1. Create ShoppingCartClean with add_item(item_id, quantity) as a command.
  2. Create get_total(price_lookup_func) as a pure query that does not mutate state.
  3. Demonstrate usage: call add_item, then call get_total with a price lookup function.
Design note

Pass a price lookup into the query so the query remains side-effect-free and does not fetch prices from a DB.

Key Takeaway

Separate mutation from computation so each method has a single responsibility.
