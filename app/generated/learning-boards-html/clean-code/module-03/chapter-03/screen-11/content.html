Clean implementation
Separate command and query as required by CQS.
class ShoppingCartClean:
  def __init__(self):
    self.items = {}  # {item_id: quantity}

  def add_item(self, item_id, quantity):
    """Command: updates cart state. Returns True on success."""
    if item_id in self.items:
      self.items[item_id] += quantity
    else:
      self.items[item_id] = quantity
    print(f"Added {quantity} of item {item_id} to cart.")
    return True

  def get_total(self, price_lookup_func):
    """Query: computes total using a provided price lookup function; does not mutate state."""
    total = 0
    for item_id, qty in self.items.items():
      price = price_lookup_func(item_id)
      total += price * qty
    return total

# Example usage:
# cart = ShoppingCartClean()
# cart.add_item('apple', 2)
# total = cart.get_total(lambda id: 0.5 if id == 'apple' else 10)
# print(total)
Why this is test-friendly
  • get_total can be tested with a simple lambda price lookup without I/O.
  • add_item can be tested by asserting items contents after the call.
  • Behaviour is explicit: tests won't be surprised by hidden mutation during reads.
Integration pattern

At integration points, wire a real price service to the query or cache outside the pure get_total.
