Module 3 › Chapter 3.3 › Costs of Hidden Side Effects
Failure modes
  • Unpredictable behavior: calls produce different external state over time.
  • Hard-to-write unit tests: need mocks for implicit I/O and state.
  • Flaky tests: shared mutable state causes order dependency.
  • Opaque bugs: the mutation source may be distant from the symptom.
Common Mistake

Treating helper functions as pure when they perform logging or cache updates behind the scenes.

Practical mitigations
Isolate side effects

Encapsulate I/O and state changes in dedicated commands that are easy to mock or stub.

Use defensive copies

When receiving mutable inputs, copy before mutating, or return a new modified value.

Explicit naming

Name functions to indicate mutation, e.g., increment_login_count or save_user, so intent is explicit.
