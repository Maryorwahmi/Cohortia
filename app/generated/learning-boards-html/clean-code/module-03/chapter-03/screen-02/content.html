Learning Objectives
Skills we'll practice and why they matter
Bloom: Learn → Understand → Apply → Master
01
Define side effects
Explain what constitutes a side effect and list common examples like I/O, mutations, and logging.
VERIFIED COMPETENCY MILESTONE
02
Distinguish query vs command
Recognize functions that only return data and those that intentionally mutate state; learn the naming cues that help.
VERIFIED COMPETENCY MILESTONE
03
Apply CQS to functions
Refactor functions to follow CQS so queries never mutate and commands clearly express intent.
VERIFIED COMPETENCY MILESTONE
04
Refactor a mixed method
Take a method that both returns data and mutates state, and split it into a safe query and a focused command.
VERIFIED COMPETENCY MILESTONE
