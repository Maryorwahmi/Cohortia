Propagation
Call stack example
A function deep in the stack raises ValueError. No local handler exists, so the error travels up to the caller, and so on, until a matching except ValueError is found.
main() ➜ calls process_file()
process_file() ➜ calls parse_line()
parse_line() ➜ raises InvalidFileDataError
Design implication: handle where you have enough context to decide whether to retry, log detailed diagnostics, or convert to a user-level message.
Practical tips
  • Document which exceptions your functions may raise.
  • Handle errors at the layer that can decide recovery or escalate.
  • Use centralized logging handlers to record stack traces for ops.
