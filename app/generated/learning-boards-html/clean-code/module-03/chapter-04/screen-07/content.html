Process Flow
1
Expected?
If yes, consider sentinel.
2
Caller checks?
If callers won’t reliably check, prefer exceptions.
3
Diagnostics
Need stack/context? Exceptions help.
4
Performance
Avoid exceptions in hot loops for expected failures.
5
Document
Make the contract explicit.
Example: an API that looks up users should return None when a user is not found because that outcome is expected, but should raise ApiException when the backend returns a 500 because that is exceptional and requires operator attention.
