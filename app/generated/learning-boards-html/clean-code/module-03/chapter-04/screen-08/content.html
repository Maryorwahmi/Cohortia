def safe_divide(numerator, denominator):
  try:
    if not isinstance(numerator, (int, float)):
      raise TypeError("numerator must be a number")
    if not isinstance(denominator, (int, float)):
      raise TypeError("denominator must be a number")
    if denominator == 0:
      raise ValueError("denominator is zero")
    return numerator / denominator
  except (TypeError, ValueError) as e:
    # Provide context and re-raise or return a sentinel as appropriate
    raise
Guidelines & example
Log the exception with context, and if you cannot handle it at this level, re-raise. Use finally to close resources. Do not use generic 'except Exception' unless you log and re-raise.
Misconception: "Catching all exceptions makes code safer." In truth, it often hides bugs and leads to harder to diagnose failures. Prefer targeted handlers and clear logging.
