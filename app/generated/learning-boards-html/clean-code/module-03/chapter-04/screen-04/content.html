Definition
Core concept
Error Codes explained
A function returns a status value that the caller inspects. Use this when failure is expected and can be handled locally without unwinding the stack.
  • Explicit: the caller sees a code and decides the next step.
  • Good for recoverable outcomes, like parsing user input.
  • Costs: cluttering checks and risk of ignored returns.
Concrete example
A divide function returns (status, result) where status 0 means success and negative values indicate specific input or runtime errors.
Code Example
def divide_numbers_with_code(numerator, denominator):
  if denominator == 0:
    return -1, "Error: Cannot divide by zero."
  if not isinstance(numerator, (int, float)) or not isinstance(denominator, (int, float)):
    return -2, "Error: Invalid input types."
  return 0, numerator / denominator

# Caller:
status, result = divide_numbers_with_code(10, 2)
if status == 0:
  print(f"Result: {result}")
else:
  print(f"Failed: {result}")
Key Takeaway

Choose error codes for common, expected failures and ensure callers consistently check returned status.
