Module 3 › Chapter 3.4 › Key Concepts
Error Code
A status return indicating success or specific failure that callers must check.
Exception
An event that disrupts normal flow and propagates until a matching handler is found.
try-except
A construct to handle exceptions; catch specific types and keep handlers meaningful.
Summary Takeaway

Design error behavior deliberately: treat expected failures as returns and unexpected problems as exceptions. Document, test, and log each case.
