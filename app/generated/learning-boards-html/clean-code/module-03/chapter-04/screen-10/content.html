Common Mistakes
Swallowing exceptions
Do not use empty except blocks. They hide errors and make debugging impossible.
# Dangerous
try:
  value = int(input_value)
except ValueError:
  pass  # silently ignores bad input
Better: log the issue, provide user feedback, or raise a clearer exception so the caller can decide.
Catching Exception broadly
Using 'except Exception' masks many root causes and conflates them with recoverable errors.
# Risky
try:
  do_work()
except Exception as e:
  handle_error()  # hides underlying error
Better: catch specific exceptions, log details, and re-raise if you cannot fully handle them.
