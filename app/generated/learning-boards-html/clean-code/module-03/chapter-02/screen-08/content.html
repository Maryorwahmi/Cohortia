When to encapsulate

If the same group of parameters occurs in multiple functions, model it as a domain type and pass that object instead.

Example: Rectangle
Bundle width, height, x, y into a Rectangle class and add area or translate methods.
Configuration objects
Use DatabaseConfig, ApiConfig, CacheConfig to express intent and reduce signature size.
Diagram: object replaces parameters
Before
draw(x, y, width, height, color)
After
draw(Rectangle(x,y,width,height), color)
Why it helps
Fewer arguments, clearer intent, and a central place for related behavior and validation.
