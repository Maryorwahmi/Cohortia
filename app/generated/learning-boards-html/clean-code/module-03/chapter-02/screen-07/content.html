Refactored dataclasses (excerpt)
from dataclasses import dataclass
from typing import Optional

@dataclass
class Address:
    line1: str
    line2: Optional[str] = None
    city: str
    state: str
    zip_code: str
    country: str

@dataclass
class ContactInfo:
    phone_number: str
    preferred_language: str = "en"
    timezone: str = "UTC"

@dataclass
class UserProfileData:
    user_id: int
    username: str
    email: str
    password_hash: str
    first_name: str
    last_name: str
    date_of_birth: str
    address: Address
    contact: ContactInfo
    is_admin: bool = False
    account_status: str = "active"
Benefits
  • Clearer function signature: create_user_profile_clean(profile_data)
  • Callers construct domain objects where context exists.
  • Fewer positional errors and simpler tests.
Pro tip
When many fields are optional, provide sensible defaults in the dataclass so tests and call sites remain concise.
