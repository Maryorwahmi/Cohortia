Module 3 › Chapter 3.2 › Split vs Group
Split responsibilities

When tasks are distinct, create smaller functions each with narrow, meaningful inputs.

  • Improves SRP adherence
  • Makes unit tests more focused
  • Reduces hidden side-effects
Group parameters

When parameters represent a single domain concept, create a DTO or domain object and pass that instead.

  • Clarifies intent at call sites
  • Reduces ordering errors
  • Allows attaching behavior to data
Practical rule
Ask: do these values form a meaningful object? If yes, group. Otherwise, split the function until each has a single, clear job.
