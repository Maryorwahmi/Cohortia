How to make the decision
Signal
Many parameters often indicate mixed responsibilities or missing domain objects.
Action
Group related values, or split the function into focused helpers with narrow inputs.
Check
Write a small test before refactoring to keep behavior safe.
Mnemonic
Swiss Army vs Toolbox: narrow focused tools beat one giant multipurpose blade.
Practice
Refactor the supplied initialize_system starter into nested config dataclasses and a single SystemConfig parameter.
