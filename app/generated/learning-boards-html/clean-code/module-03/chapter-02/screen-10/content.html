Module 3 › Chapter 3.2 › Refactor Recipe
Step-by-step
  1. Identify argument groups: database, API, cache, logging, features.
  2. Create dataclasses for each group with sensible defaults.
  3. Define SystemConfig to contain the nested config objects.
  4. Change initialize_system to accept one SystemConfig parameter.
  5. Adjust callers to construct and pass SystemConfig from application bootstrap code.
  6. Run or add tests to ensure behavior is preserved at each step.
Concrete snippet
# initialize_system_clean(system_config: SystemConfig)
# system_config.database.host
# system_config.cache.size_mb
Why test first
Small tests let you verify behavior before renaming or moving parameters, reducing regression risk during refactors.
