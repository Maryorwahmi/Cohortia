Sample quiz item
Which strategy is least effective for improving argument count and maintainability? Making values global is the correct answer because it hides dependencies and increases fragility.
Refactor checklist
  • Does the function do one thing? If not, split it.
  • Do parameters form a cohesive domain concept? If yes, group them.
  • Are flags indicating multiple paths? If yes, extract explicit functions.
  • Have you added or updated tests to preserve behavior?
Reviewer note

Apply the checklist during code review to guide safe, incremental refactors that reduce argument count and function size.
