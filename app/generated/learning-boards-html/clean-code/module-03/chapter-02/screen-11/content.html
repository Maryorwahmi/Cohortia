Module 3 › Chapter 3.2 › Common Mistakes
Boolean flags

Flags create multiple execution paths inside one function. They often indicate split responsibilities and complicate tests.

Instead
Create separate functions with explicit names for each behavior so callers choose intent directly.
Global state

Hidden dependencies via globals make functions less predictable and harder to test. Tests must manage global setup and teardown, increasing fragility.

Alternative
Pass dependencies explicitly, or inject configuration objects so behavior is explicit and testable.
