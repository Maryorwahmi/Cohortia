Module 4 › Chapter 3.5 › Accidental Duplication
How to tell the difference
  • Ask if the code expresses the same business rule.
  • Ask if a change would apply to all instances.
  • Check if extraction requires many context parameters.
Example
Two similar calculations used in finance and physics may look the same now but are conceptually different and should not be merged.
Practical tip
If unsure, keep small readable duplication and add a TODO to revisit if patterns repeat across multiple modules.
