Module 4 › Chapter 3.5 › Refactor Process
Step-by-step
1. Detect
Classify duplication as identical or similar; note minor variations.
2. Test
Add tests for current behavior so refactor is safe and reversible.
3. Design
Define helper signature, return type, and error contract clearly.
4. Extract
Move shared logic into the helper and give it an intention-revealing name.
5. Replace
Call the helper from each caller and remove duplicated lines.
6. Verify
Run tests, integration checks, and manual validation flows.
Pitfall
Avoid extracting helpers prematurely when duplication is accidental; prefer clear semantic matches.
Takeaway
A safe, test-driven extraction gives you DRY benefits with low risk.
