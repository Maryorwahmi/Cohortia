Question 1: SMTP duplication
Two functions duplicate SMTP connection, authentication, and close steps. Which refactor best follows DRY?
Best answer: Create a send_email function that encapsulates the entire sending process, then call it from specific email functions.
Why: This makes the sending process the single source of truth and keeps subject/body construction in callers.
Question 2: Similar calculations
Two functions have nearly identical complex math but different domain meanings. Should you extract?
Answer: Analyze semantics first. If they represent the same knowledge, extract. If they serve different business rules, avoid premature extraction.
Why: Pulling apart semantic intent avoids coupling unrelated changes and fragile abstractions.
Reflection
When in doubt, write tests and defer extraction until the pattern is clear; small, well-tested helpers are safe to DRY.
