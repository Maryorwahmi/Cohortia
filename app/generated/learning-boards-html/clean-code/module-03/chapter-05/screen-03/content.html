Module 4 › Chapter 3.5 › Practice & Judgment

Hands-on Practice

A short refactor exercise and a checklist to guide smart DRY decisions.

Exercise
Refactor two functions by extracting a validator. Then apply it to a third similar function.
Checklist
  • Do these blocks express the same business rule?
  • Will they change together?
  • Does abstraction make code clearer?
Misconception
Not all duplication is bad: accidental duplication can diverge and should not be forced into a shared helper prematurely.
