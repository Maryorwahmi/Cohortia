Clean orchestrator example
def process_order_clean(order_details, customer_email):
    if not _validate_order_details(order_details):
        return False

    final_total = _calculate_total_with_tax(order_details)
    order_details["total_amount"] = final_total

    if not _save_order_to_database(order_details):
        return False

    _send_order_confirmation_email(customer_email, order_details.get("id", "N/A"))

    print(f"Order {order_details.get('id', 'N/A')} processed successfully.")
    return True
Behavioral tests
  • Mock helpers to assert sequence and error handling.
  • Test that calculate and validate are invoked with correct data.
  • Decide and test the policy for non-critical failures like email sending.
Key takeaway: the orchestrator documents workflow and policy, not implementation detail.
