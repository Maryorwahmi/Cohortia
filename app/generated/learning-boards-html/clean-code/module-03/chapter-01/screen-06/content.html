Module 3 › Chapter 3.1 › Refactor Process
Step-by-step
1. Run tests / create safety net
2. Identify distinct logical blocks
3. Extract helpers with clear names
4. Orchestrate and add focused tests
After extraction, tests should verify helpers independently. Keep behavior unchanged during the refactor and only simplify intent once safety is assured.
Example rule
If a block would change because of different policies, extract it. If two blocks change for the same reason, they may remain together.
Common mistake: extracting every single line into a function. That fragments intent; prefer meaningful groupings.
