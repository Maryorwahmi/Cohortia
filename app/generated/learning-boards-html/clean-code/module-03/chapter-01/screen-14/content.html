Assessment ideas
  • Multiple-choice: choose the refactoring that best separates concerns.
  • Refactor task: submit extracted helpers and orchestrator preserving behavior.
  • Code review: justify why each extracted function has a single reason to change.
Reflective prompt
Think of a function you wrote recently. Can you identify multiple reasons it might change? List them and plan which helpers to extract.
