Naming rules
  • Use verbs that state the single action.
  • Avoid names with multiple actions or conjunctive "and".
  • Document return values and side effects in the helper's docstring.
Examples
Good: _calculate_total_with_tax(order)
Bad: processOrderAndNotifyCustomerAndLogTransaction()
Pro tip: naming helps reviewers decide whether a function has mixed concerns.
