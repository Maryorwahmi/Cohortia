Before vs After
A simple visual comparison helps you decide what to extract.
Before: validate, calculate, save, send — all in one function.
After: validate(); calculate_total_with_tax(); save_order(); send_confirmation();
Heuristic: name, reason-to-change list, and side-effect isolation.
Checklist
  • Name includes multiple verbs or "and"
  • Function body has distinct blocks that could be extracted
  • Testing the main behavior triggers unrelated side effects
  • Changing one concern often requires editing the whole function
Quick tip: write the one-line purpose of the function. If it reads like a sentence with several clauses, refactor.
