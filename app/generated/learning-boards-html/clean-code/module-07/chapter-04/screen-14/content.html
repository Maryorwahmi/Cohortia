Hands-on › Refactor CustomerManager

Task

Refactor CustomerManager to extract billing and loyalty responsibilities into two new classes, then update CustomerManager to delegate.

Step hints
  1. Identify fields and methods related to billing_info and loyalty program.
  2. Create BillingInfoManager and LoyaltyProgramManager classes holding state and behavior.
  3. Update CustomerManager to compose these managers and add delegation methods.
  4. Write unit tests for each new class and run integration tests.

Testing strategy

Prioritize small unit tests for BillingInfoManager and LoyaltyProgramManager. Keep CustomerManager tests to validate orchestration.

Key Takeaway

Practice small, test-backed extractions that keep the system behavior intact and improve modularity.
