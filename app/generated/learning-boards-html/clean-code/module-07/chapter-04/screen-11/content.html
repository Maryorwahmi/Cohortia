Architecture › Composition & Delegation

Why composition helps

Composition keeps each class focused and provides a clear boundary for tests and reuse.

Delegate calls

Original class can expose thin convenience methods that forward to the new class.

Control visibility

Keep the public API stable during migration, reveal new managers gradually.

State sync

When shared data changes, update composed objects so invariants hold across the system.

Practical pattern

Use composition to separate concerns and delegation to keep older callers functional while you refactor.
Key Takeaway

Composition plus small delegation methods is the safest migration path from monolith to modular classes.
