Process › Extract Class Steps

Step-by-step

  1. Identify a cohesive responsibility by grouping methods and state.
  2. Create a new class named for that responsibility.
  3. Move the related fields and methods into the new class together.
  4. Replace original logic with delegation methods that forward calls.
  5. Run and update tests; commit each small successful change.
Safety tip

If a method needs state you didn't move, move the state too or refactor the method into a pure function.

Example heuristic

Pick the responsibility that appears the most cohesive and smallest first. That yields quick wins and reduces risk.

Key Takeaway

Small, test-backed extractions are the fastest path to safer design improvement.
