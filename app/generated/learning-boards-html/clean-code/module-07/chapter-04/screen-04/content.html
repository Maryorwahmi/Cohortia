Core Concept › What is a Large Class?

Definition & Symptoms

A Large Class accumulates unrelated fields and behaviors and often violates SRP.

  • • Long constructors with many parameters and state.
  • • Dozens of methods that span different domains.
  • • Frequent unrelated changes in one file across features.
  • • Hard to unit test because of tangled dependencies.
Analogy

Like a Swiss Army knife stuffed with tools: flexible but difficult to use for focused work.

Key Takeaway

Look for multiple reasons to change — that is the true smell, not just physical size.

Quick Checklist

Change history
Do commits touch this class for unrelated features?
Cohesive groups
Are there groups of methods that always change together?
Test complexity
Do tests require heavy mocks and long setups?
Key Takeaway

A Large Class signals multiple responsibilities. Name the responsibilities before refactoring.
