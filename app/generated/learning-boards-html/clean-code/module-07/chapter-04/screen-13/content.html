Common mistakes

  • • Creating anemic models that only hold data.
  • • Over-extracting single methods into classes.
  • • Moving methods without their required state.
  • • Exposing internals and breaking encapsulation.

Best practices

Extract meaningfully
Move behavior and its state together and name the class for its role.
Stepwise refactor
Make small changes, run tests, and commit often to keep the change reversible.
Preserve APIs
Use delegation to avoid breaking callers; migrate callers later.
Key Takeaway

Practical restraint and tests keep Extract Class from becoming an expensive mistake.
