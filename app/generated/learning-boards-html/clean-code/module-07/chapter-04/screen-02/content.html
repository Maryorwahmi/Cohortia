Learning Objectives

Skills to recognize and fix Large Classes using Extract Class.

Learn → Understand → Apply → Master
01
Identify Large Class

Recognize symptoms like many fields and mixed responsibilities so you can flag risky classes during reviews.

Mnemonic: look for 'many hats' on one object.
VERIFIED COMPETENCY MILESTONE
02
Understand impacts

Explain how large classes violate SRP and harm testability and reuse so teams can set refactor priorities.

Mnemonic: single reason to change.
VERIFIED COMPETENCY MILESTONE
03
Apply Extract Class

Move cohesive behavior into new classes, preserve behavior with delegation, and run tests after each small step.

Mnemonic: pull a cohesive bundle out.
VERIFIED COMPETENCY MILESTONE
04
Select extraction criteria

Choose cohesive methods and fields, avoid over-extracting, and favor composition with clear interfaces.

Mnemonic: cohesion over count.
VERIFIED COMPETENCY MILESTONE
