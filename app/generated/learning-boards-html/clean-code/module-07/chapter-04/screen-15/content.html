Summary › Key Concepts
Large Class (God Object)
A class with too many responsibilities, causing multiple reasons to change.
Single Responsibility Principle
Each class should have one reason to change to minimize entanglement.
Extract Class
Move cohesive fields and methods into a new class and delegate from the original.
Cohesion
How well elements inside a module belong together; high cohesion is desirable.
Coupling
Degree of interdependence between modules; aim for low coupling.
Composition
A class holds instances of other classes to provide behavior via delegation.
Summary Takeaway

When you see many responsibilities, extract cohesive units, test them, and use composition to keep code maintainable.
