Practical Checkpoints

How to convert objectives into safe actions during a refactor.

Learn → Understand → Apply → Master
01 • Flag the class

Look for many fields, unrelated methods, or a class that is the center of many changes.

Venn mnemonic: responsibilities ∩ change points.

02 • Explain cost

Quantify test complexity and risk so you can get time for incremental refactors.

Timeline mnemonic: small steps with test gates.
VERIFIED COMPETENCY MILESTONE
03 • Extract in steps

Move one cohesive bundle, update the original to delegate, run tests, commit, then repeat.

Mnemonic: pick one cohesive responsibility, not five.
VERIFIED COMPETENCY MILESTONE
04 • Validate with tests

Use focused unit tests for the new class and keep integration tests to ensure overall behavior.

Mnemonic: tests as safety rails.
