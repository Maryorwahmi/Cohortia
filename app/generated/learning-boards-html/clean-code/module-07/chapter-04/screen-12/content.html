Process › Testing Strategy

Safe testing steps

  • • Run full test suite to establish a baseline.
  • • Extract a single cohesive responsibility and add focused unit tests for the new class.
  • • Keep integration or end-to-end tests to confirm system behavior.
  • • Use delegation on the original class to preserve API compatibility.
  • • Commit frequently and revert if failures appear.
Common failure mode

Missing state or incorrect constructor arguments after moving methods causes test regressions. Move state and behavior together.

Testing tips

Prefer small fixtures, test the new class in isolation, and keep integration tests as a safety net.
Key Takeaway

Tests are your safety harness. Use them to guide and validate small, reversible extractions.
