Testing & SafetyBest practices

Keep refactors safe

Testing checklist
  • Run integration tests before refactor and save outputs.
  • Extract one helper, add unit tests for it, then re-run integration tests.
  • Prefer pure functions that return values for easier testing.
  • Add an integration assertion that final outputs remain consistent.
Common mistakes
  • Over-extracting into many tiny functions.
  • Creating parameter objects that become god objects.
  • Leaving side-effects scattered across helpers.
Final reflection
Refactor to reveal intent, not hide it. Keep tests close to the code changes and extract with purpose.
