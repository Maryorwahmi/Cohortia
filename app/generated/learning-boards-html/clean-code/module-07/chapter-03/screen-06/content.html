Extract Method — Steps

  1. Identify logical blocks inside the long method (fetch, filter, aggregate, format).
  2. Create a helper with a clear name and explicit inputs/outputs.
  3. Replace the original block with the helper call and run tests.
  4. Repeat until the top-level method reads as an orchestrator.
  5. Keep helpers private if not part of the public API.
Example helpers
_fetch_and_filter_sales(criteria)
_aggregate_sales_by_product(filtered_sales)
_apply_sales_filters_and_tax(aggregated_products, criteria)
_format_and_print_report(report_items, criteria)
Pro-tip
Fail fast with tests
Run tests after each extraction to ensure behavior remains consistent.
Common mistake
Extracting unrelated logic
Avoid helpers that mix unrelated concerns; each should represent a single logical step.
Key Takeaway

Extract one meaningful block at a time and validate with tests so refactoring is safe and incremental.
