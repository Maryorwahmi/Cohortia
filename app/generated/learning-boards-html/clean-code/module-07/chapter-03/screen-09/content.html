Introduce Parameter Object

When to use it
  • Methods taking five or more related arguments.
  • When parameters represent a clear concept, like report criteria.
  • When call sites suffer from ordering mistakes or poor readability.
Trade-offs
  • Introduces a small type to maintain, which is usually acceptable.
  • Avoid grouping unrelated parameters into a god object.
  • Improves readability and ease of extension.
Example dataclass
from dataclasses import dataclass

@dataclass
class ReportCriteria:
    start_date: str
    end_date: str
    region: str
    product_category: str
    min_sales_amount: float
    include_tax: bool
    currency_symbol: str
