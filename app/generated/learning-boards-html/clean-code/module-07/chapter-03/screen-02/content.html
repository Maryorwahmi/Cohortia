Learning Objectives

Understand detection, refactoring, and parameter-object design.

Identify Long Method
Detect methods with multiple responsibilities, deep nesting, or long scroll length and understand why they reduce readability and raise bug risk.
Verified Competency Milestone
02
Apply Extract Method
Break a long method into private helpers with clear names so each unit has a single responsibility and is easier to test.
Verified Competency Milestone
03
Introduce Parameter Object
Encapsulate related parameters (criteria and flags) into a dataclass to simplify signatures and reduce ordering bugs.
Verified Competency Milestone
04
Refactor Safely & Test
Run and extend tests as you extract and introduce objects; verify behavior remains the same and avoid over-fragmentation.
Verified Competency Milestone
