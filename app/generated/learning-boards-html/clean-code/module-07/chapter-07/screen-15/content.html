Key Concepts
Primitive Obsession
Using raw primitives for domain concepts causes scattered rules and conditional logic.
Replace with Class
Create a small type object to centralize related data and simple behavior.
Replace with Subclasses
When types need distinct behavior, use subclasses and polymorphism to remove conditionals.
Takeaway

Model intent explicitly. Replace primitive type codes with well-scoped types or subclasses to centralize behavior, reduce bugs, and make future extensions easier.
