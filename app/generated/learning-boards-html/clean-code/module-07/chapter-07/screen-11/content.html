Design & Persistence
Persistence and migration planning
Serialization strategies
  • Discriminator column: store a type key and reconstruct the correct subclass on load.
  • Registry/factory: store a simple code and map it to a type object when loading.
  • Custom serializers: write the object's data and type metadata for full fidelity.
Client migration
Provide constructors and factory methods that accept legacy primitives so callers can migrate gradually. Update tests to verify both legacy and new paths.
Testing checklist
  • Unit tests for each type or subclass behavior.
  • Factory tests mapping old codes to new types.
  • Integration tests for persistence round-trip.
