Refactoring Pattern
Replace Type Code with Class
Process
  1. Find the primitive type code and list associated behaviors and data.
  2. Create a new immutable type class to hold those properties.
  3. Replace the primitive field with an instance of the new type in the owner class.
  4. Use a single factory or registry to map old primitive values to the new type instances.
  5. Move related small methods onto the new type and update callers.
Mini Example (conceptual)
# Conceptual: AccountType holds interest_rate and can_deposit
class AccountType:
  def __init__(self, name, interest_rate, can_deposit):
    self.name = name
    self.interest_rate = interest_rate
    self.can_deposit = can_deposit

# Account now holds account_type: AccountType
class Account:
  def __init__(self, id, balance, account_type):
    self.account_id = id
    self.balance = balance
    self.account_type = account_type

  def deposit(self, amount):
    if not self.account_type.can_deposit:
      return False
    self.balance += amount
    return True
Key Takeaway

A small type object centralizes data and simple behaviors, shrinking conditionals and clarifying intent.
