Module 8 › Chapter 7.7 › Learning Objectives
Safe migration and testing
Small steps that keep behavior stable while replacing primitives with types.
Factory
Map old codes to new types
A factory isolates the mapping and is the single place to change during migration.
Persistence
Adjust serialization
Plan how type objects are stored and retrieved, and version migrations if necessary.
Testing
Cover behaviors
Unit tests for each type, factory tests, and regression checks to compare old and new outputs.
Pro Tip

When possible, perform the refactor behind a factory or constructor so callers keep the same API while you swap the concrete representation under the hood.
