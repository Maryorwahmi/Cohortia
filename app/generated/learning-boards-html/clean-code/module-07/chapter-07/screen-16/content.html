Key Concepts — Quick Reference
Primitives hide intent
If a value carries rules, validation, or behavior, model it as a type.
Use classes for encapsulation
A type class centralizes data and simple behavior and reduces duplication.
Use subclasses for polymorphism
When types need different methods or state, subclasses avoid scattered conditional logic.
Final Tip

Prefer incremental refactors with factories and tests. Replace type codes gradually so behavior remains stable and reviewable.
