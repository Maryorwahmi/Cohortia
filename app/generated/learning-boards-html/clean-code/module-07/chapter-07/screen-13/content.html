Best Practices
Common mistakes and testing
Mistakes
  • Jumping to subclasses too early.
  • Creating anemic classes with no behavior.
  • Forgetting persistence and client updates.
Testing
  • Unit tests per type/subclass.
  • Factory mapping tests from old codes.
  • Integration tests for persistence round-trip.
Checklist
  1. Conditionals reduced or removed.
  2. Behavior located with the type.
  3. Tests and migration strategy in place.
