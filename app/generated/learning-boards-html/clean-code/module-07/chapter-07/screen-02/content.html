Learning Objectives
Four practical outcomes you can verify in code and tests.
01
Identify
Spot Primitive Obsession
Recognize when primitives stand for domain concepts and how that leads to scattered validation and unclear intent. Visual mnemonic: a raw-ingredient icon representing untidy data.
VERIFIED COMPETENCY MILESTONE
02
Explain
Why it's harmful
Explain type-safety loss, missing behavior encapsulation, and conditional complexity; give an example of money and status codes.
VERIFIED COMPETENCY MILESTONE
03
Apply
Replace Type Code with Class
Convert a primitive code into a dedicated type object and delegate behavior to it to reduce if/else blocks.
VERIFIED COMPETENCY MILESTONE
04
Master
Replace Type Code with Subclasses
Use a subclass per type when behaviors diverge; learn factory and testing implications.
VERIFIED COMPETENCY MILESTONE
