Process Flow

Extract Method: The Steps

1. Identify
2. Name
3. Extract
4. Parameterize
5. Test
Details & tips
  • Name the method to express the 'what' not the 'how'.
  • Pass differing values as parameters; avoid capturing distant state.
  • Extract small logical chunks and run tests after each move.
Example checklist
Confirm the block has one responsibility, can be named, and is repeated in two or more places. If so, extract.
Common mistake
Extracting a block that still does multiple things. If naming is hard, split further before extraction.
Key Takeaway

Extraction is a small, test-backed process: pick, name, extract, parameterize, and test.
