Learning Objectives

Skills to practice: identify duplication, refactor with Extract Method, parameterize, and avoid common pitfalls.

01
Recognize duplication
Spot identical and subtly similar logic that repeats intent across files and methods. This skill lets you locate single points to refactor.
VERIFIED COMPETENCY MILESTONE
02
Explain the cost
Describe how duplication increases maintenance, introduces inconsistent bugs, and slows changes across the codebase.
VERIFIED COMPETENCY MILESTONE
03
Apply Extract Method
Perform an extraction: pick a coherent chunk, create a helper method, and replace duplicated sites while running tests.
VERIFIED COMPETENCY MILESTONE
04
Parameterize extracted methods
Turn variations into parameters so one method serves multiple call sites without duplicating logic.
VERIFIED COMPETENCY MILESTONE
Bloom: Learn → Understand → Apply → Master
