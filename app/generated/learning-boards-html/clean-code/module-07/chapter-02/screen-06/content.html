Customer class — before

Original code (excerpt)
class Customer:
  def __init__(self, name, member_status, purchases):
    self.name = name
    self.member_status = member_status
    self.purchases = purchases

  def calculate_loyalty_points(self):
    if self.member_status == 'Gold':
      print(f"[{self.name}] Gold member - calculating points with bonus.")
      points = sum(self.purchases) * 0.15
    elif self.member_status == 'Silver':
      print(f"[{self.name}] Silver member - calculating points.")
      points = sum(self.purchases) * 0.10
    else:
      print(f"[{self.name}] Standard member - calculating points.")
      points = sum(self.purchases) * 0.05
    return points

  def apply_discount(self, total_amount):
    discount_rate = 0.0
    if self.member_status == 'Gold':
      print(f"[{self.name}] Gold member - applying 20% discount.")
      discount_rate = 0.20
    elif self.member_status == 'Silver':
      print(f"[{self.name}] Silver member - applying 10% discount.")
      discount_rate = 0.10
    else:
      print(f"[{self.name}] Standard member - no discount.")
      discount_rate = 0.0
    return total_amount * (1 - discount_rate)
Notes
  • The same membership checks appear in two methods.
  • Print statements differ, but the membership-to-rate mapping is duplicated.
  • If rules change, multiple places must be updated.
Misconception
Different outputs mean the logic can't be shared. In fact, shared rules can be called and the final calculation kept in each method.
