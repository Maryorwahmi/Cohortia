Common Mistakes

Pitfalls When Extracting Methods

Granularity errors
Extracting an incoherent chunk makes naming and testing harder. Aim for single responsibility.
Naming problems
Names should express the 'what' and the business intent, not the implementation steps.
Dependency traps
Avoid letting the helper rely on many outer variables. Prefer explicit parameters to hidden coupling.
Testing mistakes
Run tests after each extraction and revert immediately if behavior changes unexpectedly.
Check your practice
If you cannot name the extracted method or it needs more than three parameters, pause and split the chunk further.
