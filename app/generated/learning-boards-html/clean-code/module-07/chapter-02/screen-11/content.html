Testing & Safety

Verify Behavior — Tests and Small Steps

Practical checks
  • Write assertions that capture expected outputs before refactoring.
  • Run those assertions after each extraction to confirm unchanged behavior.
  • If a test fails, revert the last change and debug the difference.
Example assertions
# Example checks (conceptual)
assert customer1.calculate_loyalty_points() == expected_points
assert abs(customer2.apply_discount(200) - expected_total) < 1e-6
# For settings manager, assert expected keys exist in settings dict
Team practice
Run the full test suite and peer-review refactors so missed call sites are caught early.
