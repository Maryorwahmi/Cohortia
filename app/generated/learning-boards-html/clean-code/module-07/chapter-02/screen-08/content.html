Definition

Parameterize the extracted method

Give the helper the differing data as arguments, not by capturing context implicitly.

Good parameter candidates
  • Different messages or context strings.
  • Numeric multipliers, rates, or thresholds.
  • Flags that select small behavioral variants.
Anti-patterns
  • Passing entire objects when a single field suffices.
  • Not passing values and relying on global or instance state.
  • Adding many parameters instead of splitting responsibilities.
Quick example
If callers differ only in the printed phrase, pass a context string; if they differ in numeric rates, return all rates and let callers pick.
Key Takeaway

Parameterize small differences to reuse one implementation while keeping explicit, simple method signatures.
