Core Concept

What is duplicated code?

Repeated logic appears as identical lines or near-duplicates that implement the same rule in multiple places.

Key signals
  • Repeated control structures like identical if/else blocks across methods.
  • Similar setup/teardown sequences in multiple functions.
  • Duplicate calculations with different names but same formula.
Concrete example
Two methods each check a customer's membership tier to decide points and discounts. Same intent, duplicate logic.
Key Takeaway

Duplication hides intent and multiplies your maintenance surface; prefer a single named implementation.

Common misconception

Different variable names or logging messages do not remove duplication if the underlying logic is the same. Treat the rule as the unit of reuse.

Check your understanding
  1. Find two small functions that repeat a calculation.
  2. Ask whether they express the same business rule.
  3. If yes, consider extraction and parameterization.
Why it matters
A single source of truth reduces risk: one change, one place to update, fewer missed fixes.
