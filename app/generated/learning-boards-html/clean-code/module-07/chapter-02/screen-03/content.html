Skills & Safety Goals

Small steps and good names preserve behavior while you centralize logic.

Extract at the right granularity
Aim for a single responsibility per extracted method. If you can name it clearly, it's likely the right size.
VERIFIED COMPETENCY MILESTONE
Use clear names
A good name communicates what the method does, reducing the need to read its internals.
VERIFIED COMPETENCY MILESTONE
Parameterize variations
Pass the differing parts as arguments rather than embedding them in the helper to maximize reuse.
VERIFIED COMPETENCY MILESTONE
Test after each step
Run or write tests immediately after an extraction. If tests fail, revert and re-evaluate the change.
