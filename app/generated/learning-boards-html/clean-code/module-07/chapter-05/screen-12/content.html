Module 07 › Chapter 7.5 › Tests & Safety
Testing Checklist
  • Write unit tests that cover normal and edge cases before changing code.
  • Run tests after copying the method to the new location and after updating callers.
  • Use forwarding methods to keep APIs stable while users migrate.
  • If circular dependencies appear, introduce value objects or interfaces to decouple classes.
Concrete testing idea

Record before-and-after totals for representative orders and assert equality after the refactor.

API stability

Keep a forwarding method that calls the new implementation and mark it deprecated while clients migrate.
