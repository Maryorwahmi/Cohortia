Learning Objectives

Understand identification, consequences, and refactorings for Feature Envy.

Bloom: Learn → Understand → Apply → Master
01
Identify Feature Envy
Detect methods that call many accessors on another object and use little of their own state.
VERIFIED COMPETENCY MILESTONE
02
Explain consequences
Describe how Feature Envy increases coupling and weakens encapsulation, making changes ripple across classes.
VERIFIED COMPETENCY MILESTONE
03
Apply Move Method
Move a method to the class whose data it uses most, update references, and run tests for safety.
VERIFIED COMPETENCY MILESTONE
04
Apply Move Field
Move a field to the class that primarily uses it, adjust access, and check for circular dependencies.
VERIFIED COMPETENCY MILESTONE
