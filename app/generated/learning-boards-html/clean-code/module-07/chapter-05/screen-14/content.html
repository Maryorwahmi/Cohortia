Move vs Extract — quick guide
One owner?

Yes → Move Method/Field into that class.

Multiple owners?

Yes → Extract Class that encapsulates shared behavior.

API concerns?

Use forwarding methods and a deprecation plan to avoid breaking clients.

Reflection

Ask: if a bug appears in this behavior, which class should I inspect first? The answer points to the correct home for the code.
