Module 07 › Chapter 7.5 › Move Method Steps
Move Method — Process Flow
1. Tests
Cover the method so behavior is verified during change.
2. Copy
Duplicate the method into the target class and adapt references to local fields.
3. Run tests
Run the suite, fix issues, iterate until green.
4. Clean up
Update callers and remove or forward the original method for compatibility.
Concrete example

Copy a calculate_final_price(product) method into Product as calculate_final_price(self), change product.get_price() to self.price and run tests to confirm results match.

Check your understanding

If moving the method introduces tight coupling back to the original class, consider Extract Class or interfaces instead of a direct move.

Key Takeaway

Follow the copy-and-test pattern to move behavior safely and keep public APIs stable when needed.
