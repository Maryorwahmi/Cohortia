Module 07 › Chapter 7.5 › What is Feature Envy?
Definition & Detection

A method shows Feature Envy when it calls many accessors on another object and uses little of its own state. Count foreign accesses versus local uses to detect it.

Detection heuristic
  • Look for repeated calls like obj.get_...()
  • Check for empty host class state
  • Ask: would this method be simpler in the other class?
Concrete example
A Billing class method that frequently calls customer.get_address(), customer.get_tax_id(), and customer.get_discount() is a sign the calculation belongs with Customer or a dedicated BillingInfo object.
Common misconception
Moving code is always best. Sometimes an Extract Class preserves clarity when multiple collaborators are involved.
Spotting in code
def calculate_final_price(self, product):
    base = product.get_price()
    discount = base * product.get_discount()
    return base - discount
This method lives on a calculator but mostly reads product. It likely belongs on Product instead.
Key Takeaway

If behavior touches another object's internals frequently, move the behavior to that object's class when appropriate.
