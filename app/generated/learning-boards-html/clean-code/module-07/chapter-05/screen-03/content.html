Refactor Checklist

A short, repeatable process to apply Move Method or Move Field safely.

1. Tests

Ensure the method is covered so behavioral changes are caught quickly.

2. Duplicate

Copy the method into the target class and adapt to use local state.

3. Test

Run tests. If failures occur, adjust logic and dependencies carefully.

4. Clean

Remove old code or add a thin forwarding method for compatibility.

When to Extract Class

If behavior depends equally on several classes, create a new collaborator instead of moving into one home.

Avoiding Circularity

Move fields carefully and check dependencies to prevent classes from requiring each other.

Misconception

Moving code always reduces complexity. Not always — sometimes a new helper or Extract Class is the better design.
