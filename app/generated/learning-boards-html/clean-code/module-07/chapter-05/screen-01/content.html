Feature Envy

When a method is more interested in another class's data than its own.

Chapter 7.5 • 16:9
Why this matters

Methods that live in the wrong class create brittle dependencies. Moving behavior back to the owning data keeps responsibilities clear and reduces breaks when internals change.

What you'll practice
  • Detect Feature Envy by looking for repeated accessor calls to another object.
  • Move methods into the class that owns the data.
  • Move fields when another class primarily uses that data.
Coming up

Python code walkthroughs, refactor step checklists, and testing strategies to keep behavior stable.

Visual Concept
Behavior should sit next to the data it operates on. If a method accesses another object's internals often, the method likely belongs there.
