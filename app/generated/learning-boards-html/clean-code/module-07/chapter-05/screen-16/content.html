Module 07 › Chapter 7.5 › Reminders
Spot the smell

Many accessor calls to the same object is a reliable indicator of Feature Envy.

Refactor safely

Write tests first, move code incrementally, and keep forwarding methods when required.

Choose Extract Class

If a method depends equally on multiple classes, introduce a dedicated collaborator instead of forcing one owner.

Final takeaway

Refactoring Feature Envy keeps behavior with the data it needs, making code easier to change and reason about.
