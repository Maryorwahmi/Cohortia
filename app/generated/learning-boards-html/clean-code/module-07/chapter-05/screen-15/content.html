Module 07 › Chapter 7.5 › Key Concepts
Feature Envy

A method that leans on another class's data more than its own, signaling misplaced responsibility.

Move Method

Copy the method into the class whose data it uses, adapt to local fields, test, and clean up callers.

Move Field

Relocate a field to the class that primarily uses it, update construction, and watch for cycles.

Summary

Move behavior to its data, test thoroughly, and use forwarding methods for compatibility when needed.
