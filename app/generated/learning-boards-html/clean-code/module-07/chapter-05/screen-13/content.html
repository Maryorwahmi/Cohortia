Module 07 › Chapter 7.5 › Common Mistakes
Not moving enough

After moving one method, follow dependencies and move supporting fields or helpers if they belong together.

Breaking APIs

Use forwarding methods to preserve compatibility while clients migrate to the new location.

Circular dependencies

If moving causes cyclic imports, extract a small value object or interface to break the cycle cleanly.

Pro tip

When in doubt, write a test for the behavior you want to preserve, perform the move, and let the tests guide safe cleanup.
