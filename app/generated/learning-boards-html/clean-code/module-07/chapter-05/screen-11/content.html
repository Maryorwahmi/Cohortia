Module 07 › Chapter 7.5 › Refactor Order
Refactoring steps
  1. Add calculate_final_total(self) to Order.
  2. Adapt logic to use self.items, self.shipping_cost_per_item, and self.tax_rate directly.
  3. Run tests and update callers to use order.calculate_final_total().
  4. Remove or forward the original method in OrderProcessor.
Example refactor (conceptual)
class Order:
    def calculate_final_total(self):
        total_items_price = sum(item['price'] * item['quantity'] for item in self.items)
        shipping_total = sum(item['quantity'] for item in self.items) * self.shipping_cost_per_item
        subtotal = total_items_price + shipping_total
        tax = subtotal * self.tax_rate
        return subtotal + tax
After this change, processors can call order.calculate_final_total() and no longer need to inspect Order internals.
