BookingManager with Separate Dates
A date pair used repeatedly is an ideal data clump candidate.
Original snippet
class BookingManager:
    def __init__(self, bookings=None):
        self.bookings = bookings if bookings is not None else []

    def check_availability(self, room_id, start_date, end_date):
        print(f"Checking availability for room {room_id} from {start_date} to {end_date}.")
        for booking in self.bookings:
            if booking['room_id'] == room_id:
                if not (end_date <= booking['start_date'] or start_date >= booking['end_date']):
                    print(f"  Room {room_id} is booked during {booking['start_date']} - {booking['end_date']}.")
                    return False
        print(f"  Room {room_id} is available.")
        return True
Explanation
The overlap logic is repeated and the pair (start_date, end_date) carries semantic meaning: a DateRange.
Concrete suggestion
Create DateRange.overlaps_with to hide the comparison details and reduce risk.
