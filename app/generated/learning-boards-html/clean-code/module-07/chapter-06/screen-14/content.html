When to Create a Value Object
A short checklist to decide whether to encapsulate primitives.
Checklist
  • Frequency: repeated across three or more sites.
  • Cohesion: fields describe one domain concept.
  • Behavior: there is logic tied to these fields.
  • Evolution: likely to add fields later.
Decision outcomes
If most answers are yes, create an object. If not, keep primitives but revisit as the code evolves.
Avoid
Creating objects for accidental pairings or single-use tuples.
