Learning Objectives
Clear goals to measure your progress through data-clump refactoring.
01
Spot Data Clumps
Identify groups of primitives that appear together across methods and classes. This skill reduces redundant changes later.
Mnemonic: Think "Always Together" — words that travel as a set.
VERIFIED COMPETENCY MILESTONE
02
Refactor to Value Object
Create a class that encapsulates the primitives and related behavior such as formatting and validation.
Mnemonic: Bundle + Behavior = Value Object.
VERIFIED COMPETENCY MILESTONE
03
Prefer Immutability
Make value objects immutable to simplify reasoning and avoid accidental state changes.
Mnemonic: Fixed state, predictable behavior.
VERIFIED COMPETENCY MILESTONE
04
Migrate Safely
Update all call sites, move validation into the object, and add tests to ensure behavior is unchanged.
Mnemonic: Change once in the object, not everywhere.
VERIFIED COMPETENCY MILESTONE
