Why Data Clumps Hurt
Compare the cost of passing primitives vs a value object.
Problems
  • Long parameter lists: harder to read and easy to misorder.
  • Duplicated validation: same checks repeated across call sites.
  • Brittle changes: adding a field forces many edits.
Pitfall
Treating every pair as a clump leads to over-encapsulation. Use frequency and cohesion as your guide.
Benefits of a Value Object
  • Clearer intent in signatures (Address vs three strings).
  • Single place for formatting and validation.
  • Safer extension when adding fields like country.
Quick takeaway
If multiple call sites change when you add a field, you have a clump.
