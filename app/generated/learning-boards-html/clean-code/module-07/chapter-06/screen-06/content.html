Replace Data Value with Object — Steps
Follow an incremental process to keep changes safe and reversible.
1. Identify
Find groups repeated across methods and classes.
2. Design
Choose fields, add behavior like formatters and validation, prefer immutability for value semantics.
3. Implement
Use dataclass frozen=True in Python to get simple equality and immutability.
4. Migrate
Update callers incrementally and move validation into the object.
5. Test
Run existing tests after small steps to catch regressions immediately.
6. Serialize
Adjust serialization/deserialization to handle the new object shape.
