Value Object Principles
Design rules for small domain primitives.
Immutability
Prevent accidental changes and make objects safe to share.
Value equality
Equality is determined by attributes, not identity.
Encapsulated behavior
Move formatting, validation, and small helpers into the object.
Concrete example
Address.get_full_address centralizes display logic; DateRange.overlaps_with encapsulates overlap checks used across booking logic.
