What is a Data Clump?
A recurring group of primitive values that should be a single concept.
Definition & signs
  • Frequently repeated together across methods or classes.
  • Composed of primitives like strings, numbers, or dates.
  • Represents a logical concept — e.g., Address or DateRange.
Example
street, city, zip_code used in many signatures — this trio indicates an Address concept.
Key Takeaway

If primitives travel together often, name them and encapsulate to express intent and reduce repetition.

Analogy
Think of data clumps like a recipe’s ingredient trio: sugar, flour, and eggs often appear together. Packaging them as a 'Batter' object makes recipes easier to read and modify.
Common misconception
Not every pair of values needs an object. Prefer an object when the group is conceptually cohesive and reused across places.
Check your code
Search for repeated parameter sequences. If found in multiple modules, design a value object.
