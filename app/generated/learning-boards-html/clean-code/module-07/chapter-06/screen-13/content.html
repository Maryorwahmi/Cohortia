Testing and Migration Strategy
Practical steps to keep behavior stable while refactoring.
1. Capture current behavior
Run and add tests that define expected outputs before making changes.
2. Test the value object
Add focused tests for overlaps_with, get_full_address, and validation rules.
3. Migrate incrementally
Update one caller at a time and keep commits small so you can revert easily if needed.
Serialization tip
Provide to_dict and from_dict adapters on your value object to bridge existing JSON or DB formats during transition.
