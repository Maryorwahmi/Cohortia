Contextual Naming › Scope and Short Names
Acceptable Short Names
for i in range(len(items)):
    item = items[i]

def process_coordinates(x, y):
    return x * y
These are concise because the local meaning is obvious and short names reduce visual clutter.
Unacceptable Short Names
# Bad at module scope
db = connect()

# Better
db_connection = connect()
Global or long-lived names should be explicit to communicate lifetime and purpose.
Key Takeaway

Match name brevity to scope. Short in tiny scopes, explicit across larger boundaries.
