Common Mistakes › Anti-Patterns to Avoid
False Implications
user_list used for a Set; list implies ordering and duplicates allowed, Set does not.
Inconsistent Abbreviations
Using prod in some files and product in others fragments searches and confuses readers.
Under/Over Contextualization
Short cryptic globals vs. bloated local names both hinder comprehension; choose based on scope.
Pro Tip
Apply a tiny naming audit during reviews: search for inconsistent abbreviations, check plurality on collections, and ensure verbs reveal side effects.
