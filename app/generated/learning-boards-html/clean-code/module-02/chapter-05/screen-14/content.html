Key Concepts › What to remember
Misleading Name
A name that implies the wrong type or behavior; it actively deceives the reader.
Meaningful Distinction
Ensure similar names reflect actual functional or data differences, e.g., Summary vs Details.
Contextual Naming
Match name length and clarity to scope: small scope allows brevity; large scope requires explicitness.
Core tip: run a quick review checklist—false implications, plurality, verbs for side effects, and domain terms—to catch naming problems early.
