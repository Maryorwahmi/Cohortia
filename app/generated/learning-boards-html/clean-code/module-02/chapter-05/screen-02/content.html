Learning Objectives
Build naming habits that prevent bugs and reduce cognitive load.
Learn
Understand
Apply
Master
01
Identify misleading names
Spot names that imply the wrong type or hide important side effects. This reduces debugging time and surprising behavior.
VERIFIED COMPETENCY MILESTONE
02
Make meaningful distinctions
Use names that reflect real functional differences, such as ProductSummary vs ProductDetails, to avoid confusion between similar entities.
VERIFIED COMPETENCY MILESTONE
03
Apply contextual naming
Choose short names in very tight scopes and explicit names when scope and responsibility grow. This balances readability and brevity.
VERIFIED COMPETENCY MILESTONE
04
Use domain-specific language
Favor terms from the problem domain such as orders, invoices, or customers to make code understandable to domain experts and new teammates.
