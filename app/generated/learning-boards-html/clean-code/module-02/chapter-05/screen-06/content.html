Meaningful Distinctions › Distinguishing Similar Concepts
Bad Pair
Product vs ProductInfo — too similar and unclear about responsibilities.
Why it hurts
Reviewers can't tell which fields belong where, and code that expects one may receive the other, causing runtime errors.
Better Pair
ProductSummary vs ProductDetails — names reflect size and intent.
ProductSummary — id, title, price; for listing and search
ProductDetails — full description, inventory, supplier info; for edit and display
Tip: write a one-line purpose for each type; if you can’t, the name is probably too weak.
