Hands-On Example › Refactor the Reporting Module
Original Usage
report_info = {"source": "database", "format": "pdf"}
rd = ReportData(report_info)
rd.process_cfg()
if rd.is_ready:
    report_content = gen_report([{"id":1}], "summary")
Refactored Usage
report_info = {"source": "database", "format": "pdf"}
report_config = ReportConfiguration(report_info)
report_config.initialize_configuration_from_settings()
if report_config.is_ready:
    report_content = generate_report_content([{"id":1}], "summary")
Why this helps
Each identifier now communicates its role and side effects; a reader no longer needs to open the class to guess purpose.
