Task
  1. Separate add_user_and_log into add_user and log_user_added.

Verification Tips
  • Run the code paths and confirm queries do not mutate state.
  • Unit test predicates to return true/false explicitly.
  • Document your renames with short comments explaining the reason if needed.
Key Takeaway

Small refactors that make names honest are high-leverage. Practice on one class to build the habit and prevent hidden side effects.
