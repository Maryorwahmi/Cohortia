Mastery Activities
Small actionable tasks to prove naming & CQS skills
Refactor: Split mixed function
Take a function that returns data and updates state, split into a query and a command, and rename both to reflect purpose.
Rename: Predicate functions
Ensure boolean-returning functions use is_/has_/can_ and have no side effects.
Parameter naming drill
Replace short ambiguous parameter names with explicit names that explain expected values.
Assessment idea
Multiple choice and short refactor tasks. Example question focuses on choosing the best name for a function that both processes and stores results.
