Verb Phrase Naming
Names should state the action and expected outcome.
Command-Query Separation
Separate state changes from data-only queries.
Predicate & Parameter Naming
Use is_/has_/can_ and descriptive parameter names for readability.
Summary

Consistent naming and clear separation of responsibilities make code easier to read, test, and maintain. Treat names as promises and keep them honest.
