Module 2 › Chapter 2.3 › Commands vs Queries — Naming Patterns
Command Prefixes
  • save_user_profile()
  • delete_order()
  • update_inventory()
  • log_activity()
Commands can return success indicators but should not return data for further processing.
Query Prefixes
  • get_user_by_id()
  • fetch_product_details()
  • calculate_total_price()
  • is_admin_user()
Queries should be free of side effects and clearly named for the returned value.
Naming Distinctions
get_
Direct retrieval from a local store.
fetch_
May imply remote access, cache, or I/O behavior.
calculate_
Indicates a computed value, no side effects expected.
