Bad Example (Violates CQS)
def handle_data(data_list):
    # This function both processes data and returns a result.
    # It might also modify data_list in place.
    processed = [d.upper() for d in data_list]
    print("Data handled.")
    return processed
Good Refactor (Adheres to CQS)
def process_strings_to_uppercase(strings):
    return [s.upper() for s in strings]


def log_data_handled():
    print("Data handled.")
Key Takeaway

Split return-value computations from side effects. Name each function to reflect its single responsibility for easier reasoning and testing.
