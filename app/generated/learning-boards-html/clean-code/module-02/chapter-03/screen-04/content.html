Module 2 › Chapter 2.3 › Verb Phrase Naming
Definition

Functions should be named with verbs or verb phrases describing a single action and its expected result.

Concrete Example
calculate_average_temperature()
This name communicates the action and the returned value clearly, unlike process_data.
Key Takeaway

Prefer readable verb phrases that reduce the need to inspect implementation.

Common Mistakes & How to Fix
Generic verb: process()
Fix by naming the precise action, e.g., filter_invalid_readings or normalize_sensor_values.
Overlong names that repeat implementation
Trim implementation detail from names; prefer intent over internal steps.
Try this
Inspect a function you recently wrote. If you need a sentence-long comment to explain it, rewrite the function name so that the comment is unnecessary.
