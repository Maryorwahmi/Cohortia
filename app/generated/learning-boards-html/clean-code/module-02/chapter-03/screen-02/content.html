Learning Objectives
Learn → Understand → Apply → Master
01
Verb Phrase Naming
Formulate names as verbs that describe the single action performed and why that action exists.
VERIFIED COMPETENCY MILESTONE
02
Command-Query Separation
Apply CQS by splitting state-changing commands from pure queries that return data without side effects.
VERIFIED COMPETENCY MILESTONE
03
Avoid Pitfalls
Detect generic verbs, hidden side effects, and inconsistent prefixes that make code brittle to change.
VERIFIED COMPETENCY MILESTONE
04
Parameter & Predicate Naming
Choose descriptive parameter names and is_/has_/can_ prefixes for boolean-returning functions so calls read like questions.
VERIFIED COMPETENCY MILESTONE
How to practice
  • Refactor ambiguous names into explicit verbs and split mixed-responsibility methods.
  • Rename parameters to reflect data shape and intent.
  • Verify predicate names start with is_/has_/can_ and return only booleans without side effects.
Check your understanding
Which function name promises a query and which promises a command? Practice by renaming three methods in a small class.
