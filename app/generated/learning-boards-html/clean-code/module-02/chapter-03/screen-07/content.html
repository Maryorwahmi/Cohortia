Module 2 › Chapter 2.3 › Parameter Naming
Why it matters

Descriptive parameter names make call sites readable and reduce the need to consult implementation or documentation.

Better:
def send_email(recipient_address, message_body)
Worse:
def send_email(to, msg)
Practical check
  • Does the parameter name describe the role and expected content?
  • Would a caller at a call site understand what to pass without reading the function?
Key Takeaway

Names are part of your API. Choose parameters that make calls self-explanatory.
