Why verbs, CQS, and clear parameters

Well-named functions are the verbs of your program. They reduce cognitive load, act as contracts, and make intent explicit without inspecting implementation.

Explore Key Topics
Verb Phrase Naming
Pick clear, focused action names like calculate_average_temperature.
Command-Query Separation
Keep commands and queries distinct so callers understand side effects.
Parameter & Predicate Naming
Use descriptive parameter names and is_/has_/can_ prefixes for booleans.

Visual Concept
Interactive 16:9 Masterclass
Command
save_user_profile()
Performs an action and changes state. Name uses an imperative verb.
Query
get_user_by_id()
Returns data without side effects. Name describes returned value.
Common Mistake
get_users_and_update_status()
This name hides a side effect and mixes query and command behavior. Prefer splitting into two clearer functions.
Key Takeaway

Names are promises. Choose verbs for action, clear prefixes for predicates, and split mixed behavior into commands and queries.
