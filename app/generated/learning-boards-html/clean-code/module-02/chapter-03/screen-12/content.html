Module 2 › Chapter 2.3 › Common Mistakes and How to Avoid Them
Generic Verbs
Replace process(), handle() with specific names like filter_invalid_readings or normalize_user_input.
Hidden Side Effects
If a query mutates state or prints, extract that behavior into a command with an imperative name.
Inconsistent Prefixes
Choose clear meanings for get_, fetch_, calculate_ and apply them consistently to avoid confusion.
Practical Rule
If a function needs a comment to be understood, rename it. If a query has side effects, split it. If a predicate has logic beyond a boolean check, reconsider its responsibility.
Reflection

Which of your recent functions likely needs renaming or splitting? Try refactoring one and observe if call-site clarity improves.
