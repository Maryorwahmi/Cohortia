Module 2 › Chapter 2.3 › Predicate Naming for Booleans
Why predicate prefixes help
  • Calls read like questions and document intent.
  • Expectations on return type and purity are clearer.
  • Make tests and conditionals easier to understand.
Examples
is_admin_user(user), has_permission(user, action), can_edit(post, user)
Misuse: A function called is_available that also updates inventory would violate expectations. Keep predicates side-effect free.
Key Takeaway

Name boolean functions as questions and keep them pure. Rename check_active to is_active_user for clarity and predictability.
