Module 2 › Chapter 2.4 › Concrete Naming Examples
Bad examples
class MyObject:
    pass

class DataProcessor:
    pass

class Helper:
    pass
These names give no clue to responsibility.
Good examples
class UserProfile:
    pass

class OrderFulfillmentService:
    pass

class ConfigurationLoader:
    pass

class EmailNotificationSender:
    pass
Names show entity and primary action or role.
Refactor tip
When renaming, update the file name to reflect the primary class to keep imports discoverable.
