Practice and Application
Refactoring exercises and judgment rules.
Checklist-driven practice
One-sentence test
Describe the class responsibility in one sentence. If you cannot, consider renaming or splitting the class.
Single Responsibility check
If a class has multiple reasons to change, its name will fail to communicate a single focused responsibility.
File mapping rule
Name the file after the primary class or function it contains and keep casing consistent with project conventions.
Practice example
Rename data_utils.py → csv_json_serializer.py if it mainly serializes CSV and JSON formats. Move user objects into models/user.py.
