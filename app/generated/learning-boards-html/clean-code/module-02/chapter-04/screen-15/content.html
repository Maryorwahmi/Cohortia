Quick Reference
Noun names
Classes should read as entities or domain concepts.
Avoid vague suffixes
Manager, Helper, Util usually mean split responsibilities are present.
File alignment
Name files for the primary class and use consistent casing.
Actionable habit: when reviewing code, perform the one-sentence responsibility test for every class you touch. If it fails, plan a rename or split.
