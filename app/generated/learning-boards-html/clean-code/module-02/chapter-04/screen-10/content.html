Organizing with packages
Group modules by cohesive domain responsibility, not by file type.
auth/
user_authentication.py, permission_management.py
models/
user.py, item.py — domain types here.
services/
order_service.py, payment_service.py
Practical note: avoid mixing domains in a package. If multiple unrelated responsibilities live together, split into clear packages to improve discoverability.
