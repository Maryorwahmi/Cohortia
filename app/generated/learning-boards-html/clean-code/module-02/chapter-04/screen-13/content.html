Common Mistakes
Generic names
Processor, Handler, Utility — too vague.
Redundant suffixes
UserClass or ItemModel repeat type information unnecessarily.
Inconsistent casing
Mixing CamelCase and snake_case makes navigation harder.
Versioned filenames
db_query_v2.py should be managed by source control, not file names.
Avoid these mistakes by applying the one-sentence test and keeping files focused on a single responsibility.
