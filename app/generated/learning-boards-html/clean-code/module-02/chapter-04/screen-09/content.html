Module 2 › Chapter 2.4 › File and Module Naming
Python file naming: step-by-step
Step 1
Identify primary responsibility.
Step 2
Name file in snake_case after that element.
Step 3
Avoid versions inside filenames; use source control.
Step 4
Split and package by domain as code grows.
Example
user_profile.py contains UserProfile; product_service.py contains ProductService; auth package groups authentication modules.
