Module 2 › Chapter 2.4 › Manager / Helper / Util
Why they’re problematic
  • They obscure the class's true responsibility and invite unrelated code.
  • They make ownership unclear — who owns and maintains the helper?
  • They hinder testing since helpers often mix concerns.
Concrete example
DataHelper with CSV, JSON, and DB methods mixes IO, serialization, and persistence responsibilities.
Better breakdown
CsvSerializer
Handles CSV encoding and decoding only.
JsonSerializer
Encapsulates JSON conversion.
DbConnector
Contains database access logic.
Splitting responsibilities clarifies intent and simplifies tests. Ask: what single responsibility does this class have?
