Naming Classes and Files
Precision in naming reduces cognitive load and prevents architecture drift.
Nouns
Classes are noun phrases: UserProfile, Order.
Contracts
Interfaces and abstracts should read as contracts: NotificationService, PaymentGateway.
Files
Name files after primary class or function: user_profile.py, csv_parser.py.
In this lesson
You will practice renaming classes and reorganizing files for a small e-commerce project, and learn common anti-patterns to avoid.
