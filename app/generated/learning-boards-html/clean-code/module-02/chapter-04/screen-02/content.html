Verified Competency Milestone included
01
Name classes as nouns
Formulate names that reflect the entity or concept. This reduces guesswork and improves discoverability.
Mnemonic: 'Person, Product, Profile' → think nouns.
VERIFIED COMPETENCY MILESTONE
02
Avoid vague suffixes
Detect when 'Manager', 'Helper', or 'Util' hide multiple responsibilities and refactor them into focused classes.
Mnemonic: 'If you can't say what, rename it.'
VERIFIED COMPETENCY MILESTONE
03
Name interfaces as contracts
Use naming that signals an abstract role or contract, so implementers are clearly separate from definitions.
Mnemonic: 'Service, Gateway, Repository' as roles.
VERIFIED COMPETENCY MILESTONE
04
Align files with primary content
Name modules after the main class or function and keep casing consistent across the project.
Mnemonic: 'user_profile.py contains UserProfile.'
VERIFIED COMPETENCY MILESTONE
