Module 2 › Chapter 2.1 › Intent-revealing names
Definition & rule
Include the minimal domain-relevant information in a name so a reader forms correct expectations without checking implementation.
Best practice
State unit or format when it matters: use elapsed_time_in_days rather than a vague days.
Misconception
Long names are not always wrong; clarity often justifies longer names when they reveal intent.
Key Takeaway

If a name needs a comment to explain its purpose, change the name instead of adding a comment.

Concrete contrasts
Bad: f(a,b)
You cannot infer what f computes or what a and b represent.
Good: calculate_triangle_area(base, height)
The name declares purpose and parameter roles; no comment needed.
Reflection: Before renaming, ask what future readers need to know to use this symbol correctly.
