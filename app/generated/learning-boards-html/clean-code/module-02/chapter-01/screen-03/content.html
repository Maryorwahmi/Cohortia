Apply → Verify
Assessment tasks
  1. Multiple choice: pick the most intent-revealing name for a counter of active users.
  2. Refactor task: rename variables in a starter Python script and run basic tests.
  3. Explain: write a one-sentence justification for each rename you chose.
Use the naming checklist while you work: describe, test, update references, document subtle intent.
Practice checklist
  • Does the name reveal intent? If not, make it more specific.
  • Can you pronounce it? Say it aloud in a code-review comment.
  • Will the name be searchable without noise? Avoid too-generic tokens.
  • Do not encode type or scope unless necessary; rely on tooling instead.
Each item maps to a competency milestone you'll verify after the refactor activity.
