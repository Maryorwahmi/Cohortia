Module 2 › Chapter 2.1 › Pronounceability & Searchability
Comparison
Unpronounceable & generic
genymdhms, data, value — hard to say, remember, and search reliably.
Pronounceable & searchable
generate_date_time_string, user_profile_list — easier to discuss and locate.
Tip: say the name aloud and run a search; both checks are fast and effective.
Concrete example
Searching for data in a large repository returns many unrelated occurrences. A targeted name like active_user_emails narrows results to the specific concept you need to inspect or refactor.
Check your naming
  • Pronounce it — can you say it in one phrase?
  • Search it — does it return focused results?
  • Discuss it — would you use the same phrase in a code review?
