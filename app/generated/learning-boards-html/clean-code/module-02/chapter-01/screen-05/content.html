Module 2 › Chapter 2.1 › The cost of bad names
Process
1
Reader pause
Ambiguous names force inspection of usages and context, adding minutes per encounter.
2
Misinterpretation
Wrong assumptions can lead to incorrect edits and regressions.
3
Bug and remediation
Fixing the bug often requires tracing ambiguous names across files, prolonging recovery.
Key Takeaway

Small naming improvements prevent repeated time loss and lower the chance of costly misreads.

Concrete example
If searching for occurrences of data returns thousands of hits, you waste time filtering results. Choosing a specific name narrows search results to relevant contexts and speeds refactors.
Quick mitigation
  • Identify ambiguous tokens during code review.
  • Replace with intent-revealing names and run tests immediately.
  • Add a short comment if the reason for a name is subtle.
