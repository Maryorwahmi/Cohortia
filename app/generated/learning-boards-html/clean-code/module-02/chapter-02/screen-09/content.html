Bad → Better examples
Generic or abbreviated names hurt clarity. Refactor to explicit, domain-focused identifiers.
# bad
x = 10
db_conn = connect()
tmp = calculate_value()

# better
max_login_attempts = 10
database_connection = connect()
processed_value = calculate_aggregated_metrics()
Why this matters
Descriptive names are searchable, easier on reviewers, and reduce mistakes when values are passed between modules.
Refactor approach
  1. Find generic identifiers across files.
  2. Replace with domain-specific names that answer "what" and "why".
  3. Run tests and update docs to reflect the clearer names.
Common Mistake

Abbreviating to save typing is a false economy. Modern tooling reduces typing cost while descriptive names reduce maintenance cost.
