Problem: Magic Number
# bad
retry_count = 3
timeout = 600
cache_ttl = 3600
Each literal leaves readers guessing what the value represents and whether it should change globally or locally.
Refactor to constants
MAX_LOGIN_ATTEMPTS = 3
DEFAULT_TIMEOUT_SECONDS = 600
CACHE_TTL_SECONDS = 3600
Clear names explain purpose and units and centralize changes.
Practical note
Decide whether a value belongs as a constant in code or in configuration. Use constants to document intent and grouping.
Key Takeaway

Named constants replace magic numbers, making code easier to understand and change confidently.
