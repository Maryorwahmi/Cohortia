Module 2 › Chapter 2.2 › Key Concepts
Intention-Revealing
Names should explain what the variable represents and why it exists.
Predicate Naming
Booleans should read like assertions using is, has, can, or should.
Magic Number
Replace unexplained literals with named constants to document purpose.
Takeaway

Apply these three habits consistently and naming will speed understanding and reduce subtle bugs caused by misunderstanding intent or units.
