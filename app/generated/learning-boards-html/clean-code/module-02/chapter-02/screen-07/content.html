Module 2 › Chapter 2.2 › Naming Collections and Pluralization
Principles
  • Name collections in plural form: users, product_ids.
  • Include element type for clarity: user_profiles, invoice_items.
  • Avoid generic names like data, items, list.
Example
# good
user_profiles = fetch_profiles()
for profile in user_profiles:
  process(profile)

# bad
profiles = fetch_profiles()
for p in profiles:
  process(p)
Concrete scenario
When APIs change and you handle both customer and vendor profiles, naming collections user_profiles and vendor_profiles prevents accidental mixing of data structures.
Loop iterator guidance
Use descriptive iterator names in nested loops: for row_index in range and for cell_value in row. Reserve i for simple, single-level loops.
Key Takeaway

Plural collection names with element context make code easier to scan and reduce errors from mixing different lists.
