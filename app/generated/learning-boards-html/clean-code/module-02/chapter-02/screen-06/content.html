Comparison: ambiguous vs explicit
Ambiguous
timeout = 600
max_size = 50
length = 2
Units and meaning are missing.
Explicit
DEFAULT_TIMEOUT_SECONDS = 600
max_file_size_mb = 50
length_in_meters = 2
Embedding units prevents mistakes and clarifies intent.
Concrete scenario
A service expecting milliseconds receives seconds. Tests pass in one environment but fail in another. Naming timeout_in_ms versus timeout_seconds reduces this risk and helps reviewers catch unit mismatches.
Checklist
  • Include units for measurements
  • Include element type for counts
  • Prefer names over comments for unit clarity
Key Takeaway

Make units explicit in identifiers so arithmetic and conversions stay correct and obvious.
