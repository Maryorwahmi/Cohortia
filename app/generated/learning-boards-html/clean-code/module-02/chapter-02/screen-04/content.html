Module 2 › Chapter 2.2 › Why variable names matter
Claim
A name that reveals intent reduces the effort required to read and reason about code, and prevents errors.
Concrete Example
Compare user_age in a module handling multiple age types versus age alone. user_age immediately disambiguates who the age refers to and prevents mix-ups.
Common misconception
Short names are always better. Not true: brevity helps local, simple code, but harms readability in shared or domain-rich contexts.
Key Takeaway

Favor names that answer why the variable exists. When in doubt, add context or domain terms rather than shorten.

Bad
x = 10
user = get_user()
age = 30
print(age)
Better
user_age_in_years = 30
user = get_user()
print(user_age_in_years)
Try this: pick a function with generic names and rename them to reveal intent. Run tests and observe how the code discussion during review becomes shorter and clearer.
