Learning Objectives

Learn, understand, and apply naming practices that make code self-explanatory and robust to change.

01
Formulate descriptive names
You will practice crafting intention-revealing names that state why a variable exists. This reduces the need for comments and prevents misinterpretation when revisiting code.
VERIFIED COMPETENCY MILESTONE
02
Distinguish constants
You will learn how to name constants in ALL_CAPS and move magic numbers into named variables, making changes safe and intent explicit.
VERIFIED COMPETENCY MILESTONE
03
Correct anti-patterns
You will identify generic names and unnecessary abbreviations and refactor them to explicit, searchable identifiers that help maintainers.
VERIFIED COMPETENCY MILESTONE
04
Context-aware naming
You will add units, domain qualifiers, and pluralization so names carry precise meaning, avoiding unit-mixup bugs and ambiguous collections.
VERIFIED COMPETENCY MILESTONE
