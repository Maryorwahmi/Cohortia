Naming Variables and Constants

Good names remove guesswork. They reveal why a value exists, what unit it uses, and how it will be used. This lesson gives patterns and examples you can apply immediately in Python and other languages.

Intention
Use names that answer why the variable exists. Avoid generic words like data or temp.
Booleans
Name booleans as predicates: is_active, has_permission, can_edit.
Constants
Avoid magic numbers; assign them to ALL_CAPS constants with units in the name.
Visual: name families
Readability matters
is_user_authenticated = True
Boolean predicate reads naturally in conditionals.
MAX_FILE_SIZE_MB = 50
Constant includes units to avoid mistakes.
processed_data_records = []
Plural collection name indicates element type and plurality.
