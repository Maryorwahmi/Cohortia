Concept
First-class & Higher-order Functions
numbers = [1, 2, 3, 4]
squared = list(map(lambda x: x * x, numbers))
# squared is [1, 4, 9, 16]
# numbers remains [1, 2, 3, 4]

# Or using a pure function
def square(x):
  return x * x
squared2 = [square(n) for n in numbers]
Practical checks
  • Ensure callbacks passed to higher-order functions do not mutate shared state.
  • Prefer named pure functions over inline side-effecting lambdas for readability.
  • Use list comprehensions if they make intent clearer in Python.
Pro tip
Wrap impure I/O in well-named functions and call them from a small imperative boundary, keeping the core logic functional.
