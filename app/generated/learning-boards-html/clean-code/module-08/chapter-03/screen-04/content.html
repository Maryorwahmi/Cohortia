Definition
Immutability

An object whose state cannot be modified after creation. Any change yields a new object.

Predictable state: no surprises from other code
Safe sharing: inherently thread-safe
Easier caching: values won't mutate after caching
Example — Python
# Mutable Point
class MutablePoint:
  def __init__(self, x, y):
    self.x = x
    self.y = y

  def move(self, dx, dy):
    self.x += dx
    self.y += dy
    return self

p1 = MutablePoint(1, 2)
p2 = p1
p1.move(1, 1)
# p2 now observes changed state

# Immutable Point
class ImmutablePoint:
  def __init__(self, x, y):
    self._x = x
    self._y = y

  @property
  def x(self):
    return self._x

  @property
  def y(self):
    return self._y

  def move(self, dx, dy):
    return ImmutablePoint(self.x + dx, self.y + dy)

p3 = ImmutablePoint(1, 2)
p4 = p3
p5 = p3.move(1, 1)
# p3 and p4 remain unchanged, p5 is new
Concrete takeaway
Prefer immutability where state sharing or concurrency exists.
Common mistake
Treating returned objects as mutated references instead of new instances.
