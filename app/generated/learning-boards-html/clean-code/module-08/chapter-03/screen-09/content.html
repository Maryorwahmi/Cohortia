Starter Code — Mutable
class ShoppingCart:
  def __init__(self, items=None):
    self.items = list(items) if items is not None else []

  def add_item(self, item_name, quantity, price):
    self.items.append({"name": item_name, "quantity": quantity, "price": price})
    print(f"Added {quantity}x {item_name}.")
    return self

# Usage
cart1 = ShoppingCart()
cart2 = cart1.add_item("Laptop", 1, 1200)
cart3 = cart2.add_item("Mouse", 1, 25)
print(cart1)  # unexpectedly shows items
Observation
The class mutates internal list and returns the same instance; aliases see mutations.
Fix direction
Change add_item/remove_item to return a new ShoppingCart with a copied and updated items list.
