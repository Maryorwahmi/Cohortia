Core Concept
Pure Functions

A pure function's output depends only on its input values and it causes no external effects.

def add(a, b):
  return a + b

# Impure: modifies list in place
my_list = [1, 2]
def append_impure(lst, item):
  lst.append(item)
  return lst

# Pure: returns a new list
def append_pure(lst, item):
  return lst + [item]
Why it matters
  • Deterministic behavior makes tests reliable and repeatable.
  • Pure functions are safe to run in parallel because they do not share mutable state.
  • They compose well: small pure functions can be combined without surprising interactions.
Misconception
Purity doesn't forbid I/O in an application; it encourages isolating side effects to the edges and keeping core logic pure.
