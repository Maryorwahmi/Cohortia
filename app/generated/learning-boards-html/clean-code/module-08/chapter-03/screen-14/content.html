What to Remember
Three compact concept cards to carry forward.
Immutability
Objects that don't change after creation; updates return new objects.
Pure Function
Deterministic output and no side effects; great for testing and parallelism.
Higher-order Functions
Functions that take or return other functions to build reusable abstractions.
Final Takeaway

Use immutability where it reduces risk, keep core logic pure, and isolate side effects at the edges for clearer, safer code.
