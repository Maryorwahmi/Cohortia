Pattern
Encapsulation & Immutable API
Keep mutation inside modules, return immutable snapshots or value objects to callers. Use defensive copies when exposing internal collections.
Snapshot example
Return tuple or frozen dataclass instead of live list to avoid external mutation.
Copy-on-write
Mutate privately for performance; create a snapshot when handing data to callers.
Analogy
Think of internal mutation as a workshop bench where parts are assembled. Visitors receive finished, sealed boxes that cannot be opened or altered.
Design Tip
Document whether returned objects are live views or immutable snapshots to set correct caller expectations.
