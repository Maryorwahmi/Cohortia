Starter Code
import time
import functools

_cache = {}

class DataService:
    def fetch_user_data(self, user_id):
        print(f"Fetching user data for {user_id} from slow source...")
        time.sleep(2)
        return {"id": user_id, "name": f"User_{user_id}", "email": f"user{user_id}@example.com"}

    def fetch_product_details(self, product_id):
        print(f"Fetching product details for {product_id} from slow source...")
        time.sleep(1.5)
        return {"id": product_id, "name": f"Product_{product_id}", "price": 99.99}
Implementation hints
  • Use functools.wraps to preserve metadata.
  • Generate a cache key from function name and args (tuple or serialized string).
  • Store value and timestamp: {"result": value, "ts": time.time()}.
  • Check expiration by comparing current time and stored timestamp against TTL.
Key Takeaway

A simple decorator demonstrates AOP-like caching without changing service methods.
