Weaving
How and when aspects are integrated into the execution path affects observability, debugging, and performance.
Compile-time weaving: Predictable, baked-in behavior, less runtime flexibility.
Load-time weaving: Applied when modules/classes load, balances flexibility and predictability.
Runtime weaving: Dynamic and flexible, harder to reason about at runtime.
Python note
Decorators in Python apply at definition time, effectively weaving behavior when the function or class is defined. This gives a predictable weaving moment similar to load-time weaving.
Practical checklist
  • Document when weaving occurs in your system.
  • Write tests to validate advised and non-advised behavior.
  • Log aspect application during startup to aid debugging.
Misconception

Weaving is not invisible: you can and should make its effect visible through logs and documentation.
