Advice
Before: Run checks like authorization before the method executes.
After: Run cleanup actions regardless of success.
After Returning: Run only on successful completion, useful for success metrics.
After Throwing: Run when exceptions occur, useful for error logging or compensation.
Around: Wrap the execution and optionally control whether the original method runs at all.
When to use which
  • Use Before for validation and early rejection.
  • Use After for recording final state or cleanup.
  • Use After Returning for success-only metrics or notifications.
  • Use After Throwing for error diagnostics and alerts.
  • Use Around for transactions, timing, or when you must alter execution flow.
Key Takeaway

Prefer the simplest advice type that meets the need; reserve Around advice for cases that need full control.
