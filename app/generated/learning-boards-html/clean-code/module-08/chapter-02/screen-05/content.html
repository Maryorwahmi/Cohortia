Definition

Aspect

A modular unit that encapsulates a cross-cutting concern and its application rules.

Contains pointcuts that select join points and advice that runs at those points.
Design tip: keep aspects focused and document their scope to avoid surprising side effects.
Key Takeaway

Aspects centralize repeated behavior so fixes and enhancements happen in one place.

Practical example
LoggingAspect
Advice: Log method entry and exit. Pointcut: All public methods in services package.
SecurityAspect
Advice: Check current user roles. Pointcut: Methods annotated or named for admin operations.
Misconception check
An aspect is not a substitute for poor module boundaries. Use it for concerns truly independent of business logic, not to hide tangled design.
