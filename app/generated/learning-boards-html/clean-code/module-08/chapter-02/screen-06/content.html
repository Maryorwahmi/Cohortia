Process Flow

From Join Point to Pointcut

1. Identify join points: method executions, calls, field access, exceptions.
2. Write a pointcut: a pattern that selects a set of join points, prefer explicit annotations where possible.
3. Attach advice only after testing the pointcut's coverage and edge cases.
Examples of pointcuts
All public methods in UserService
Methods with names that start with 'process' in Order module
Methods annotated with @TrackPerformance
Common mistake
Using broad wildcards that match new or unrelated methods introduced later, leading to surprising behavior.
Pro Tip

Prefer explicit annotations for clarity and testable boundaries for pointcuts.
