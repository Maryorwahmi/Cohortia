What to Remember
Use Strategy
Encapsulate interchangeable algorithms to reduce branching.
Use Factory
Decouple creation to make adding types painless.
Use Decorator
Compose behaviors dynamically rather than subclassing repeatedly.
Final Checklist
Spot repetition, test behavior, extract minimal abstraction, apply pattern incrementally, and verify tests simplify maintenance.
