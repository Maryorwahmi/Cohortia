Decision Process
1
Spot repeated conditionals
Look for if-else structures that select different algorithms for the same role.
2
Check variation reasons
Confirm the algorithms change for reasons independent of the client’s responsibilities.
3
Estimate extension needs
If you expect new algorithms in the future, Strategy reduces future modifications.
4
Testability check
Will isolating the algorithm make unit testing simpler? If yes, proceed.
Scenario
A report generator with many format cases and a roadmap to add more formats.
Takeaway
Prefer small refactors and add strategy classes incrementally as need appears.
