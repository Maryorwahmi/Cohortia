Learning Objectives
Progress from concept to implementation
Bloom: Learn → Understand → Apply → Master
01
Recall design pattern definition
Name and describe what a design pattern is and why it is used to solve recurring design problems.
VERIFIED COMPETENCY MILESTONE
02
Explain pattern benefits
Explain how patterns promote separation of concerns, OCP, and SRP to improve maintainability and extensibility.
VERIFIED COMPETENCY MILESTONE
03
Identify appropriate patterns
Recognize common scenarios where a pattern provides a clear structural improvement over ad-hoc solutions.
VERIFIED COMPETENCY MILESTONE
04
Implement common patterns
Create working implementations of Strategy, Factory Method, and Decorator in the supplied languages and test their behavior.
VERIFIED COMPETENCY MILESTONE
