class WeatherStation:
    def __init__(self):
        self._temperature = 0
        self._humidity = 0
        # How do we notify displays? This is where the pattern comes in.

    def set_measurements(self, temperature, humidity):
        self._temperature = temperature
        self._humidity = humidity
        print(f"WeatherStation: New measurements set: Temp={temperature}°C, Humidity={humidity}%")

Implementation steps
  1. Create an Observer interface with update(temperature, humidity).
  2. Make displays implement Observer and its update method.
  3. Add register_observer, remove_observer, and notify_observers to WeatherStation.
  4. Call notify_observers from set_measurements after updating state.
Hints & pitfalls
Keep WeatherStation unaware of concrete display types. Pass only the data observers need rather than exposing internals.
Reflection
After implementing, add a new display and register it. If WeatherStation requires no changes, your pattern application succeeded.
Key Takeaway

Observer decouples subject and observers so changes to display logic don’t ripple through the data source.
