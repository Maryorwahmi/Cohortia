Process Flow
Constructor Injection — Steps
1. Identify
List required collaborators the class cannot run without.
2. Declare
Add constructor parameters typed to interfaces, not concrete classes.
3. Assign
Store dependencies in readonly fields so behavior relies on stable collaborators.
4. Wire
Compose objects in a composition root or use a container to resolve them.
5. Test
Pass fakes or in-memory implementations to test behavior without external systems.
Example
ReportGenerator requires IDataReader in constructor. Tests pass a FakeDataReader to validate report logic without I/O.
Pitfall
If constructors grow too large, the class likely violates SRP; split responsibilities first.
Key Takeaway
Constructor injection makes required dependencies explicit and enforces valid object creation.
