Learning Objectives
Learn core ideas, implement injection styles, and reason about when a container helps.
01
Explain IoC and DI
Describe how control is inverted and how injection supplies collaborators. This matters because it separates composition from behavior.
VERIFIED COMPETENCY MILESTONE
02
Show decoupling & testability
Explain with an example how replacing a concrete repository with a mock simplifies unit tests and isolates behaviour.
VERIFIED COMPETENCY MILESTONE
03
Implement injection styles
Create constructor, setter, and interface injection forms and state when each is appropriate.
VERIFIED COMPETENCY MILESTONE
04
Recognize DI smells
Identify over-engineering, god objects, or invalid states caused by optional injection. Learn remediation patterns.
VERIFIED COMPETENCY MILESTONE
