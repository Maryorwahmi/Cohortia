Comparison
Direct Instantiation
Class creates its own collaborator. This causes tight coupling and hard-to-test code.
Example
UserService calls new SqlUserRepository() internally and performs persistence directly.
Drawback
Tests require a database or complex fakes; swapping implementations requires code changes.
Comparison
Injected Dependency
Class receives an interface implementation from outside and focuses on behavior.
Example
UserService constructor accepts IUserRepository; the composition root provides SqlUserRepository or InMemoryUserRepository.
Benefit
Tests can pass a simple in-memory repository; implementations can be swapped without touching business code.
Key Takeaway
Prefer injection for collaborators that influence behavior and environment. Use direct instantiation only for pure value objects or simple, internal helpers.
