Hierarchy
Composition Root
A single place to compose concrete implementations and pass them into constructors or register them with a container.
Step 1
Create concrete implementations (e.g., SqlUserRepository).
Step 2
Compose them into services (e.g., new UserService(sqlRepo)).
Step 3
Pass composed services into application entry points or register with a container.
Why this helps
Keeping composition centralized makes it obvious what a class depends on and reduces hidden coupling across the codebase.
