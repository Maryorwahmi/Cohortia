Definition
Setter Injection
Provide dependencies via public properties or setter methods after construction. Useful for optional features or late binding.
When to use
Optional logging, telemetry, or optional extensions that are not required for core behavior.
Risk
Objects can be in an invalid state if setters are not called. Validate state where necessary.
Definition
Interface Injection
The dependent class implements an interface that exposes an injection method. The injector calls that method to provide the dependency.
When it appears
Mostly seen in older frameworks or where an explicit injection contract is required.
Trade-off
It couples the dependent class to the injection contract, which can be less flexible than constructor injection.
Key Takeaway
Prefer constructor injection for required dependencies. Use setter or interface injection only for optional or lifecycle-specific needs, and validate state to avoid surprises.
