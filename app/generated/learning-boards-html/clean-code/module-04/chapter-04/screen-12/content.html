Module 4 › Chapter 4.4 › Check Your Understanding
Checklist
  • • Will adding a new case edit this method?
  • • Is dispatch logic duplicated across modules?
  • • Do tests break when new cases are added?
Refactor recipe
  1. Identify the variation point.
  2. Extract a minimal contract for the behavior.
  3. Create concrete implementations and wire them via injection or registration.
  4. Test implementations and keep the core unchanged.
Pro tip
Prefer focused contracts and explicit wiring. Avoid hiding branching in a central factory unless registration and plugin patterns are available.
