If-else chains

Long chains that require editing when new cases arrive.

Duplicated dispatch

Same decision logic repeated in multiple places instead of a single abstraction.

Type checks

Inspecting concrete types to decide behavior couples callers to implementations.

Quick detection checklist
  • • Will adding a new type require editing this method?
  • • Is dispatch logic duplicated across files?
  • • Are concrete types inspected to choose behavior?
