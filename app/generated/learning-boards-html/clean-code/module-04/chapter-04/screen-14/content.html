Module 4 › Chapter 4.4 › Key Concepts
Open/Closed Principle

Software entities should be open to extension but closed to modification to prevent regressions.

Abstraction

Use minimal interfaces or abstract classes so new functionality is added via implementations.

Conditional logic

If-else and switch statements that expand for new types are a primary sign of OCP violation.

Takeaway

Prefer adding new modules over editing old ones. Use focused contracts and test new implementations in isolation.
