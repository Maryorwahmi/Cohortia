Module 4 › Chapter 4.4 › Comparison
Model A — Edit every time

You add branches or cases inside existing methods. Each addition edits tested logic and increases regression risk.

  • • Requires modifying core code for each new type.
  • • Tests for the original method may need updates.
  • • Cognitive overhead rises as logic grows.
Model B — Extend by adding

Define a contract and create new implementations for each behavior. The base module remains unchanged and stable.

  • • New behavior is added as new modules.
  • • Existing tests remain meaningful and passing.
  • • Easier to test and reason about new code in isolation.
Benefit
Reduced regressions
Tradeoff
More files, clearer responsibilities
Guideline
Refactor when changes are frequent
