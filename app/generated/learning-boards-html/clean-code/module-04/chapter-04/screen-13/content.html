Assessment prompts
Multiple choice

Which statement matches 'closed for modification' in OCP? Correct answer: add new functionality by extending behaviour rather than altering existing code.

Short answer

Given a report generator with branching for formats, explain how you would refactor to obey OCP: extract a ReportFormat interface, implement each format, and let the generator depend on the interface.

Common error
Confusing OCP with 'never change code'. Clarify that OCP concerns how to add new features, not whether you may edit code for bugs.
