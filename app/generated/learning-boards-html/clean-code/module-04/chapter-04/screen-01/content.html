Open/Closed Principle (OCP)
Open for extension, closed for modification — design to add behavior without editing stable code.
Stable base

Keep proven implementations intact to avoid regressions when requirements change.

Extend safely

Add new implementations that conform to an abstraction rather than editing existing code.

Core idea

Use interfaces or abstract contracts so the system can accept new behaviors via new types without changing the original implementation.
