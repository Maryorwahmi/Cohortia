Module 4 › Chapter 4.4 › Architecture
Contract

A minimal interface that defines the operation the core requires.

Core module

Depends on the contract and invokes a single method to perform behavior.

Implementations

Each behavior is a concrete class that implements the contract and can be added without editing the core.

Wiring options
  • • Constructor injection: pass the implementation to the core during creation.
  • • Registry or plugin registration: register implementations so the system selects them without changing core logic.
  • • Factory with configuration: factory returns appropriate implementation, but minimize branching in the factory.
