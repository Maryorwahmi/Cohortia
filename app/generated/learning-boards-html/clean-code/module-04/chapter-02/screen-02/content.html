We move from understanding the definition, to diagnosing violations, to refactoring and measuring benefit. Each objective is tied to a verification milestone.
Objectives
01
Define SRP
State that SRP means one reason to change, with a concrete example of a class that violates it. Use the mnemonic: "one change, one class."
VERIFIED COMPETENCY MILESTONE
02
Identify Responsibilities
Analyze methods and verbs to find distinct responsibilities. Visual mnemonic: method verbs grouped into colored buckets representing concerns.
VERIFIED COMPETENCY MILESTONE
03
Refactor Violations
Split mixed classes into smaller ones that each have a single reason to change. Timeline mnemonic: before → split → after.
VERIFIED COMPETENCY MILESTONE
04
Explain Benefits
Articulate how SRP improves maintainability, testability, and reduces coupling. Simple Venn mnemonic: cohesion + small classes = clarity.
