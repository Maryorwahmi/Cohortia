Question 1
Customer class methods: getCustomerDetails(), saveCustomerToDatabase(), sendWelcomeEmail(), validateCustomerAddress(). Which most clearly violates SRP?
Correct: sendWelcomeEmail() — emailing is a separate communication responsibility and should live in an EmailService or NotificationService.
Question 2
Should authentication and profile management live in one UserManager? Choose and justify.
Correct: No. Authentication and profile management are distinct reasons to change — protocols and session handling change independently from profile data and preferences.
Reflective prompt

Pick a class in your codebase and list the change drivers. If you find multiple unrelated drivers, plan a small extraction as a refactor task.
