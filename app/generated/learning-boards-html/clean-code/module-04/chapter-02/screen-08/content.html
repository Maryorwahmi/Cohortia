Architecture › Component Roles
Role list
  • ReportGenerator (interface): single generate method.
  • PdfReportGenerator / CsvReportGenerator: format implementations.
  • ReportSaver: persistence implementation for storage.
  • ReportEmailer: delivery implementation for notifications.
  • Orchestrator: composes components to run end-to-end tasks.
Interfaces keep dependencies directional and explicit, enabling injection and independent testing of each role.
Dependency guidelines
Keep dependencies narrow and directional.
Expose small interfaces for a single behavior.
Avoid leaking implementation details across boundaries.
Following these guidelines preserves SRP across components and keeps the system flexible to independent change.
