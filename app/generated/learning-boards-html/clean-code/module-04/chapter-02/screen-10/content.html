Common Mistakes › Violations & Misconceptions
Frequent violations
  • Feature creep: adding convenience features that mix concerns.
  • Mixing persistence, UI, and business rules inside one class.
  • Keeping emailing or logging logic inside core classes.
Misconceptions
SRP is not about making every class tiny. It is about grouping behavior that changes together and splitting when change vectors differ. Balance clarity against excessive indirection.
If you find many unrelated methods in a class, treat it as a technical debt item and plan an incremental refactor to separate concerns.
