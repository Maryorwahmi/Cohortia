Common mistakes and quick wins
Practical checks for immediate improvement.
Avoid
  • Exposing raw data through many getters.
  • Creating deep inheritance for convenience.
  • Keeping unrelated responsibilities in one class.
Try this
  • Rename classes to a single responsibility phrase.
  • Extract Validator or Mailer as small collaborators.
  • Introduce small interfaces to make testing easier.
