Key Concepts
Three concise reminders
Encapsulation
Bundle data and behavior; expose a minimal API to protect invariants.
God Object (anti-pattern)
A class that holds too many unrelated responsibilities; hard to test and risky to change.
Responsibility
Each class should have one reason to change; name it and keep methods aligned to it.
Takeaway
When in doubt, ask: what is this class for? If you cannot answer in a short phrase, plan a small extraction to clarify its responsibility.
