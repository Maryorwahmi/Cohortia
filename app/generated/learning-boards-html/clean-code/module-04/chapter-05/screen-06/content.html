Design Pattern
Strategy Pattern
Encapsulate each algorithm in its own class and make them interchangeable via a common interface.
When to use
When you have multiple algorithms that vary independently and may be selected at runtime.
Misconception
Don’t use Strategy to hide context state; strategies should focus on the varying behavior.
Process: how Strategy implements OCP
1
Define the strategy interface with required behavior.
2
Create concrete strategy classes implementing the interface.
3
Inject the chosen strategy into the context; delegate calls.
Example

PaymentMethod is the strategy interface; each payment option is a concrete strategy injected into the processor.
