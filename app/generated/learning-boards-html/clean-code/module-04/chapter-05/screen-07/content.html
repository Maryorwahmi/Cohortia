Design Pattern
Template Method
Define an algorithm skeleton and let subclasses implement specific steps without changing the skeleton.
When to use
When you want consistent control flow and allow subclasses to supply step implementations.
Misconception
Avoid putting too much responsibility in the base class; that creates rigid hierarchies.
Code example
public abstract class AbstractReportGenerator {
  public final void generateAndExportReport() {
    String data = fetchData();
    String formatted = formatData(data);
    exportReport(formatted);
  }
  protected String fetchData() { return "Raw Report Data"; }
  protected abstract String formatData(String rawData);
  protected abstract void exportReport(String formattedData);
}

public class PdfReportGenerator extends AbstractReportGenerator { ... }
Key Takeaway

Choose Template Method when control flow must remain stable and extension points are individual steps.
