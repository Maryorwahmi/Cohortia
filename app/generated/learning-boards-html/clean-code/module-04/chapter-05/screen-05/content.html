Refactor walkthrough
From branches to strategies
Follow three practical steps: extract abstraction, create concrete strategy classes, and inject the chosen strategy into the processor.
Step 1 — Extract
Define PaymentMethod with processPayment; keep it minimal to avoid over-abstracting.
Step 2 — Implement
Create CreditCardPayment, PayPalPayment, etc., each containing only its specific logic.
Step 3 — Inject
Have OcpPaymentProcessor receive a PaymentMethod and delegate process calls; add new payments by adding classes.
Code example
// Context receives a strategy
public class OcpPaymentProcessor {
  private PaymentMethod paymentMethod;
  public OcpPaymentProcessor(PaymentMethod paymentMethod) {
    this.paymentMethod = paymentMethod;
  }
  public void executePayment(double amount) {
    paymentMethod.processPayment(amount);
  }
}

// Add a new option without editing the context:
public class BankTransferPayment implements PaymentMethod {
  @Override
  public void processPayment(double amount) {
    System.out.println("Processing Bank Transfer of $" + amount);
  }
}
Key Takeaway

Small, focused interfaces plus concrete classes make adding behavior safe and localize change.
