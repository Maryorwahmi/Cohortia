Template Method
A final algorithm skeleton with overridable steps in subclasses.
Dependency Injection
Provide dependencies from a composition point to enable swapping implementations.
Inversion of Control
Shift creation and lifecycle control away from domain code to a composition layer.
Final question: can you add a new behavior by adding a class and wiring it, or do you need to edit an existing client? Aim for the former to embody OCP.
