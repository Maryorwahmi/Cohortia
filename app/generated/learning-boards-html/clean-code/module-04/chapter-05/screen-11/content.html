Code Example
Order class (given)
class Order {
  private double weight;
  private String destinationCountry;
  public Order(double weight, String destinationCountry) {
    this.weight = weight;
    this.destinationCountry = destinationCountry;
  }
  public double getWeight() { return weight; }
  public String getDestinationCountry() { return destinationCountry; }
}
The Order class gives the data strategies need. Keep your strategy code focused on calculation and free of external I/O.
Main usage sketch
public class Main {
  public static void main(String[] args) {
    Order domestic = new Order(2.5, "USA");
    Order international = new Order(5.0, "Germany");

    ShippingCostCalculator calc = new ShippingCostCalculator(new StandardShippingStrategy());
    System.out.println("Standard: $" + calc.calculate(domestic));

    calc = new ShippingCostCalculator(new InternationalShippingStrategy());
    System.out.println("International: $" + calc.calculate(international));
  }
}
