Refactoring steps (mnemonic: A.D.I.D.)
  • Abstraction: define an interface for the variable behavior.
  • Delegation: have the client call the abstraction instead of branching.
  • Injection: pass a concrete implementation into the client.
  • Decide: choose or configure the strategy at composition time.
Pitfalls & checks
• Only introduce interfaces where change is likely.
• Prefer constructor injection for required dependencies.
• Remember: Template controls structure; Strategy controls variable steps.
Quick practice tip
Pick a class with multiple conditionals. Identify the varying behavior, extract an interface with a single method, implement a concrete class, and inject it. Run tests and verify no edits were needed to the original client.
