Module 4 › Chapter 4.3 › Key Concepts
Extract Class
Create a new class to hold a cohesive set of methods and data so each class has one responsibility.
Extract Interface
Define minimal contracts so other code depends on behavior, not implementation.
Composition
Compose objects from focused collaborators rather than forcing behaviors through inheritance.
Summary
Refactor incrementally with tests, apply reason-to-change, and prefer composition plus interfaces to keep code modular and testable.
