Module 4 › Chapter 4.3 › Extract Interface
Minimal contract
Define an interface that exposes only the operations clients need.
public interface IEmailSender {
    void sendEmail(String recipient, String subject, String body);
}

public class SmtpEmailService implements IEmailSender { ... }
public class MockEmailService implements IEmailSender { ... }
Benefits
  • Loose coupling: swap implementations without changing callers.
  • Testability: inject mocks or fakes in unit tests.
  • Clarity: callers express their dependencies via interfaces.
Avoid adding every method from a concrete class; keep the interface focused on the single responsibility it represents.
