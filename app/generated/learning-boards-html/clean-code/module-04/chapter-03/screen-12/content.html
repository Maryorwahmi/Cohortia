Module 4 › Chapter 4.3 › Extract IUserRepository
Interface
public interface IUserRepository {
    void save(User user);
}
Keep the interface methods at the domain level; don't expose database details here.
Concrete implementation
public class DatabaseUserRepository implements IUserRepository {
    @Override
    public void save(User user) {
        System.out.println("Saving user " + user.username + " to database...");
        // Simulated DB save
    }
}

// UserService now accepts IUserRepository and calls repository.save(user);
Why this helps
You can inject a mock repository in unit tests and add a FileUserRepository later without changing UserService.
