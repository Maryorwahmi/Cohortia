Practice & Milestones
Small-step workflow
  • Write or confirm tests for current behavior.
  • Extract one responsibility to a new class and run tests.
  • Refactor callers to use the new collaborator and run tests again.
Verified milestone
A green test suite and a small commit showing no external behavior change is the signal your refactor succeeded.
Reason-to-change heuristic
If two methods always change together, keep them together. Extract when change reasons diverge.
Testing tip
Use interface extraction to inject test doubles so you can verify behavior without production dependencies.
