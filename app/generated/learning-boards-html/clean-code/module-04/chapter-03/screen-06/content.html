Module 4 › Chapter 4.3 › OrderProcessor Refactor
Original (simplified)
// Simplified
public class OrderProcessor {
    public void processOrder(Order order) {
        // 1. validate
        // 2. save to DB
        // 3. send email
        // 4. update inventory
        // 5. generate invoice
    }
}
This single method mixes many responsibilities and is hard to test in isolation.
Refactored orchestration
public class OrderProcessor {
    private OrderValidator validator;
    private OrderRepository repository;
    private EmailService emailService;
    private InventoryService inventoryService;
    private InvoiceGenerator invoiceGenerator;

    public void processOrder(Order order) {
        validator.validate(order);
        repository.save(order);
        emailService.sendConfirmationEmail(order.getCustomerEmail(), order.getId());
        inventoryService.updateInventory(order.getItems());
        invoiceGenerator.generatePdf(order);
    }
}
OrderProcessor now coordinates collaborators that each have a single responsibility and can be tested independently.
Key Takeaway
Replace internal responsibilities with collaborators and delegate. This keeps behavior the same while improving structure.
