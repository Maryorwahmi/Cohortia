        PasswordHasher hasher = new PasswordHasher();
        DatabaseUserRepository repo = new DatabaseUserRepository();
        UserService service = new UserService(hasher, repo);
        service.createUser("alice", "securepass123", "alice@example.com");
    }
}
Running Main should print the same sequence: hashing output, saving messages, and confirmation.
Testing strategy
  • Unit tests for PasswordHasher to assert deterministic hash outputs.
  • UserService tests with mock IUserRepository to verify interactions.
  • Integration test that runs Main or a higher-level flow for end-to-end verification.
