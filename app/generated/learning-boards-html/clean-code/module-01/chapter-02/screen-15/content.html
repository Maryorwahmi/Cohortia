Module 1 › Chapter 1.2 › Key Concepts
Self-documenting Code
Make the code explain the what; reduce redundant comments.
Reduce Cognitive Load
Clear names and structure lower the effort to understand logic.
Use Comments Sparingly
Reserve comments for reasons and constraints the code cannot show.
Final takeaway

Apply these habits in small refactors often; the cumulative effect is a codebase that's easier to read, maintain, and extend.
