Module 1 › Chapter 1.2 › Learning Objectives
01
Recognize code as communication
See source as a message to future readers and teammates.
You will practice reading code with the goal of reducing ambiguity. This matters because many bugs come from misunderstood intent.
Verified competency milestone
02
Apply descriptive naming
Make identifiers explicit about role and meaning.
You will refactor names to reveal intent, reducing the need for comments. A concrete metric is that readers should not guess what variables represent.
Verified competency milestone
03
Use domain-specific language
Align code with business terms where appropriate.
You will replace generic names with domain terms like Order, Product, or ShoppingCart so domain experts immediately understand the code’s purpose.
Verified competency milestone
04
Make names consistent and correct
Follow predictable conventions across the codebase.
You will adopt consistent casing and role-based naming so readers don't have to translate conventions between files or modules.
Verified competency milestone
