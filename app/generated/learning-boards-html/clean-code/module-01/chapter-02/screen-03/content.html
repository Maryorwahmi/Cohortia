Module 1 › Chapter 1.2 › Learning Objectives
01
Make functions verb-noun
Name actions and their targets explicitly.
You will practice naming functions so a reader immediately knows what happens and to what, for example "calculateTotalPrice" instead of "process".
Verified competency milestone
02
Use noun phrases for classes
Capture entities and responsibilities clearly.
You will rename vague classes like "Manager" to specific roles such as "OrderProcessor" or "PaymentGateway" to clarify purpose.
Verified competency milestone
03
Spot naming anti-patterns
Find abbreviations and misleading names that add cognitive friction.
You will practice identifying when names mislead or fail to describe updated logic after refactors and recommend safer alternatives.
Verified competency milestone
04
Know when to comment
Use comments to explain why, not what.
You will learn when explanatory comments are appropriate, such as workarounds, business rules, and legal notes, while preferring to make code self-explanatory where possible.
Verified competency milestone
