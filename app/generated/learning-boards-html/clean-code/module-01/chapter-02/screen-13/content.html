Pattern: extract intent
Extract complex logic into a well-named function so the calling code reads like a narrative: result = calculate_discounted_total(cart_items).
  • Keep functions small and single-purpose.
  • Choose names that make the caller code readable without comments.
  • Use tests to validate behavior after refactors.
Concrete micro-refactor
# Before:
# in checkout flow
subtotal = 0
for item in cart:
  subtotal += item['price'] * item['qty']
if subtotal > discount_threshold:
  subtotal *= (1 - discount)

# After:
def calculate_discounted_total(cart_items, discount_threshold, discount_rate):
  subtotal = sum(item['price'] * item['qty'] for item in cart_items)
  if subtotal > discount_threshold:
    return subtotal * (1 - discount_rate)
  return subtotal

# and in checkout:
final = calculate_discounted_total(cart, threshold, rate)
