Naming pattern: verb-noun
Pick verbs that describe the effect and nouns that describe the object. For exported APIs, be fully explicit.
  • Prefer calculate_total_price over process_total.
  • Prefer authenticate_user over check_user or validate.
  • For mutating functions, indicate update or set in the verb.
Pro tip
If two verbs could fit, choose the one that reveals side-effects: persist vs compute, for instance.
Example: rename for clarity
# Before:
def process(order):
  # complex logic
  pass

# After:
def calculate_order_total(order_items):
  subtotal = sum(item.price * item.quantity for item in order_items)
  return subtotal
Misconception
Avoid reusing vague verbs like handle or manage across modules; they force readers to inspect implementation to know what actually happens.
