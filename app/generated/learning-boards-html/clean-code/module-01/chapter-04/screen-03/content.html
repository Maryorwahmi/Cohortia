Learning Objectives — Practical Skills

Concrete actions: audit, refactor, document public APIs, and track comment debt.

Audit
Classify comments

Keep only comments that add unique intent or necessary constraints; create tickets for misleading ones.

Refactor
Rename & extract

Turn explanatory comments into clearer names and smaller functions so code explains itself.

Document
Docstrings for public APIs

Use formal docstrings for library code and public interfaces, not for everyday implementation details.
