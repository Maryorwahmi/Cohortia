Learning Objectives

Learn to evaluate comments, refactor for clarity, and use comments sparingly and purposefully.

Bloom: Learn → Understand → Apply → Master
01
Identify
Evaluate comment value

Decide if a comment provides unique context or simply restates code. This saves review time and prevents trusting stale text.

VERIFIED COMPETENCY MILESTONE
02
Refactor
Make code self-documenting

Use clear names and small functions so the code communicates intent without extra prose. This reduces the need for comments.

VERIFIED COMPETENCY MILESTONE
03
Apply
Write good comments

Learn when to explain the why, a trade-off, or a complex algorithm that the code cannot show clearly.

VERIFIED COMPETENCY MILESTONE
04
Maintain
Manage comment debt

Detect stale or misleading comments and remove or update them as part of routine refactoring and reviews.
