Redundant Comments — Example and Refactor

See the bad example, then a refactored version that removes the need for comments.

Original (noisy)
# Initialize counter to zero
count = 0

# Loop through the list of users
for user in user_list:
    # Increment counter
    count += 1
Refactored (self-documenting)
def count_users(user_list):
    """Return the number of users in the list."""
    return len(user_list)

# Example usage
users = get_users()
result = count_users(users)
print(result)
The function name and docstring now convey purpose without redundant inline comments.
