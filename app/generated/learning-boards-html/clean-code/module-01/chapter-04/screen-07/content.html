Misleading Comments — A Dangerous Case

What to do when comments and code disagree, and why prompt reconciliation matters.

Example
# This function calculates the total price including tax, but excludes shipping.
def calculate_total_price(items):
    # Implementation now includes shipping due to a later change
    pass
This comment and code disagree; a new developer may trust the comment and introduce errors.
Remediation
  • Confirm current behavior with a small test or reading the implementation.
  • Update or remove the comment to match the code.
  • If behavior is wrong, file a focused fix and document the intended behavior in code or tests.
