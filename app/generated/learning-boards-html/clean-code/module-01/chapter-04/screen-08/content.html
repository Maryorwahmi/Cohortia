Comment Debt — Detection and Repair

Detect
  1. Notice comments during edits.
  2. Flag those that need verification.
Verify

Write a focused test or inspect the implementation to confirm current behavior before changing comments.

Remediate
  • Update or delete the comment.
  • Refactor code if the comment exists because code lacks clarity.
  • Document long historical reasons outside the code if necessary.
Practical tip

Small, frequent fixes during regular refactors prevent comment debt from growing. Avoid one-off large deletions that might miss context.
