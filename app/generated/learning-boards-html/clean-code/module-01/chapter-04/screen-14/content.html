Key Concepts

Three core ideas to keep top of mind.

Self-documenting Code
Code that clearly expresses intent reduces the need for explanatory comments.
Comment Debt
Outdated or misleading comments that accumulate and hinder maintenance.
Avoid Redundant Comments
Comments that restate code add noise — prefer clearer naming and extraction.
Summary

Prefer self-documenting code. Use comments sparingly to explain why, complex logic, or necessary warnings. Keep docstrings for public APIs updated.
