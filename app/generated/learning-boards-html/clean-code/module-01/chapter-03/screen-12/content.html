Module X › Chapter 1.3 › Common Mistakes
Anti-Patterns
  • Over-extraction into tiny, poorly named functions.
  • Hiding unrelated settings inside a single object that obscures intent.
  • Scattering side effects across helpers instead of isolating them.
  • Mixing commands and queries in the same function.
Quick fixes
Rename helpers for intent
If a helper's name doesn't clearly state its single job, rename it to match the responsibility.
Group related inputs
Create small data objects for related fields to reduce argument lists and clarify purpose.
Reflection prompt
Pick a helper and ask: does this improve testability and readability? If not, revise it.
