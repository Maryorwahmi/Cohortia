Module X › Chapter 1.3 › Key Concepts
Single Responsibility Principle
Each function should have one reason to change and one clear task.
Function Cohesion & Size
Keep functions small and consistent in abstraction; lines are a guide, cohesion is the goal.
Side Effects & CQS
Separate commands (mutations) from queries (pure data) and isolate side effects for testability.
Summary

Apply SRP, keep functions concise and cohesive, and make side effects explicit to build maintainable systems.
