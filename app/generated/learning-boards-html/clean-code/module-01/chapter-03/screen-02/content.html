Learning Objectives

Learn, Understand, Apply, Master — practical steps for function design.

Learn
Understand
Apply
Master
01
Apply SRP
Break functions so each has one reason to change. This reduces bugs and makes tests precise.
Mnemonic: Single purpose, single reason.
VERIFIED COMPETENCY MILESTONE
02
Keep functions concise
Aim for small functions, commonly under 10–20 lines. If you must scroll to read it, consider splitting.
Mnemonic: Short and focused.
VERIFIED COMPETENCY MILESTONE
03
Manage arguments
Reduce parameter counts by grouping related data into objects. Fewer args make calls and tests easier.
Mnemonic: Group related inputs.
VERIFIED COMPETENCY MILESTONE
04
Identify and refactor
Spot functions doing multiple jobs, extract responsibilities, and create orchestrators to coordinate steps.
Mnemonic: Split then orchestrate.
