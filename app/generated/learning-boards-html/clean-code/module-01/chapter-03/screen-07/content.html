Size Guidelines
Guideline
Aim for 10–20 lines as a guideline. Favor single responsibility and consistency of abstraction.
Heuristic
  • Readable in one glance? Good candidate.
  • Requires different levels of abstraction? Split it.
  • Too many arguments? Consider grouping inputs.
Key Takeaway
Lines are a hint; cohesion and testability are the real measures.
Process — Decide to Split
1
Identify the responsibility
Ask what the function is meant to do; name it for that single task.
2
Extract coherent helpers
Pull out steps that represent distinct operations or differing abstraction levels.
3
Verify with tests
If helpers are easy to test independently, the split likely improved design.
Example
Transform a long price-calculation function into compute_subtotal, apply_discounts, and format_total helpers.
