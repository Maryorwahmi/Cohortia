Side Effects
Any change to system state visible outside the function.
  • Modifying a global variable or shared object
  • Writing to a database or file
  • Printing to console or sending network requests
Contain side effects
Isolate I/O in clearly named commands and mock them during tests.
Command-Query Separation
Design queries that return data and commands that mutate state. Do not mix both behaviors in one function.
Command example
save_user(user) — performs persistence, returns success/failure.
Query example
get_user_by_id(id) — returns user data and performs no mutation.
Try this

Audit a function and label each step as a query or command. Extract queries to pure functions and commands to explicit side-effecting helpers.
