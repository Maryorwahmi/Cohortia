Identify Costs of Messy Code
Review the snippet, list issues, estimate costs, and propose single-commit refactors.
Step 1: Read the code and note unclear names and mixed responsibilities.
Step 2: For each issue, write why it's a problem and estimate time or risk impact.
Step 3: Propose a focused refactor that can be tested in one commit.
Step 4: Apply the Boy Scout Rule: commit the small improvement with a clear message.
Reflection: which single change from your list reduces the most time-to-fix for future bugs?
