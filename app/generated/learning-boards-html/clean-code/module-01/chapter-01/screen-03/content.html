Applied Milestones
Concrete actions that demonstrate competency and reduce risk.
01
Rename for Intent
Rename three unclear identifiers and add a one-line purpose comment to validate improved readability.
Mnemonic: label → meaning
Verified Competency Milestone
02
Measure Fix Time
Record the time to implement a fix before and after a small refactor to see tangible benefits.
Mnemonic: stopwatch
Verified Competency Milestone
03
List Risks
Identify five maintainability risks in a function and explain the likely cost of each.
Mnemonic: checklist
Verified Competency Milestone
04
Make a Small Clean-Up
Commit a small refactor when touching a file, such as extracting a helper or clarifying a name, to prevent debt accumulation.
Mnemonic: small shovel
Verified Competency Milestone
