Module 1 › Chapter 1.1 › Boy Scout Rule
Habit: leave the code cleaner than you found it
Small, safe refactors prevent accumulation of technical debt without interrupting feature flow.
Example: while fixing a bug, rename unclear variables and extract a helper that clarifies intent. Run tests and keep the change focused.
Guideline: limit each clean-up to a single responsibility and include a clear commit message describing the improvement.
Team habit: encourage one tiny cleanup per feature commit to accumulate benefits over time.
Key Takeaway

Small, consistent improvements are both low-risk and high-return. Make them habitual.
