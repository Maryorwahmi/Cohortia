Team habits
  • Enforce readable names and small functions in code review.
  • Adopt the Boy Scout Rule: one small cleanup per commit.
  • Require tests for behavior changes and refactors.
Tools and metrics
Use linters and small metrics to guide improvements without policing teammates.
Example metrics: mean time to fix bugs, files touched per change, and defect rate after releases.
