WPA Features

Message Integrity and WPA Modes

How WPA protected data and offered flexible authentication

Message Integrity Code (MIC)

  • Purpose: Provided robust data integrity, preventing tampering.
  • Mechanism: Cryptographic checksum appended to each packet.
  • Protection: If MIC didn't match, packet was discarded, preventing forgery.
  • Improvement: Direct countermeasure to WEP's lack of integrity.

WPA's Temporary Nature

  • RC4 Dependency: TKIP was still based on the RC4 cipher.
  • Inherited Vulnerabilities: Despite mitigations, some underlying RC4 weaknesses remained.
  • Temporary Fix: WPA was always intended as a short-term solution until 802.11i was complete.
Misconception

While WPA was a huge step up, it wasn't a perfect, long-term solution due to its underlying reliance on RC4, which still carried some inherent risks.

WPA Authentication Modes

WPA-Personal (WPA-PSK)

Uses a Pre-Shared Key for authentication. Ideal for home and small office networks.

WPA-Enterprise (WPA-802.1X)

Integrates with an 802.1X authentication server (e.g., RADIUS). For corporate environments.

Key Takeaway

WPA introduced MIC for data integrity and offered flexible authentication modes, but its reliance on RC4/TKIP meant it was still an interim solution.

Scenario: Small Office vs. Large Corporation

A small business with five employees might use WPA-PSK for simplicity, sharing a single passphrase. A large corporation with hundreds of employees, however, would opt for WPA-Enterprise, where each employee logs in with their unique credentials, providing individual accountability and easier management.
