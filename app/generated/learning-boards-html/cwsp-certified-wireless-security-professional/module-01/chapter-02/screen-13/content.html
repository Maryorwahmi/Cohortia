Key Concepts

Essential terms from this chapter.

Reconnaissance

The initial phase of an attack where an attacker gathers information about the target network.

MAC Spoofing

Changing a device's MAC address to impersonate another device or bypass filtering.

Deauthentication Attack

A Denial of Service (DoS) attack that forces clients off a wireless network by sending forged deauthentication frames.

Summary Takeaway

Understanding these core attack techniques is fundamental to recognizing and defending against common wireless vulnerabilities.
