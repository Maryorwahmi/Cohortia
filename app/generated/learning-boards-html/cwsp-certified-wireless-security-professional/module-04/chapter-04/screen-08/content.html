Preparing for a WPS Attack with Reaver

Setting up monitor mode and identifying target APs.

1. Put Adapter in Monitor Mode

Monitor mode allows your wireless adapter to capture all 802.11 frames, which is essential for tools like Reaver. This is typically done using airmon-ng.

sudo airmon-ng check kill
sudo airmon-ng start wlan0 # Replace wlan0 with your adapter

2. Identify Target WPS-Enabled AP

Use airodump-ng to scan for nearby APs and identify those with WPS enabled. Look for the 'WPS' flag in the BEACONS column.

sudo airodump-ng wlan0mon
Key Takeaway

Proper setup of monitor mode and accurate identification of the target AP's BSSID and channel are prerequisites for a successful WPS attack.

Example `airodump-ng` Output

BSSID              PWR  RXQ  Beacons  #Data  #/s  CH  MB   ENC  CIPHER AUTH ESSID
AA:BB:CC:DD:EE:FF  -55  100      123      0    0   6  54e. WPA2 CCMP   PSK  MyWPS_AP <WPS>

Note the BSSID (AA:BB:CC:DD:EE:FF) and Channel (6) for the WPS-enabled AP.

Ethical Warning

This activity must be performed ONLY in an isolated lab environment with explicit permission. Exploiting WPS on unauthorized networks is illegal and unethical.
