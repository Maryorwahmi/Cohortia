Identify Client-Side Vulnerabilities

Recognize common flaws in wireless network drivers, OS components, and application software on user devices. Understanding these vulnerabilities is key to protecting endpoints from targeted attacks.

Exploit WPS Vulnerabilities

Understand and demonstrate the process of exploiting Wi-Fi Protected Setup (WPS) vulnerabilities. This includes grasping the PIN design flaw and using tools like Reaver to compromise WPS-enabled Access Points.
