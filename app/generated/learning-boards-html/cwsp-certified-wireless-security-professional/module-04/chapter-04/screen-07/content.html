AP-Side Attacks

Wi-Fi Protected Setup (WPS) Flaw

Understanding the critical design weakness in WPS PINs.

What is WPS?

WPS (Wi-Fi Protected Setup) is a network security standard that attempts to make connections between a router and wireless devices easier and faster. It typically involves pressing a button or entering an 8-digit PIN.

The Critical Design Flaw

The 8-digit PIN is processed in two independent halves: the first four digits and the last three (the eighth is a checksum). This allows an attacker to brute-force each half separately.

Key Takeaway

WPS's PIN validation mechanism significantly reduces the complexity of brute-force attacks, making it a major security vulnerability.

Brute-Force Complexity

  • Full 8-digit PIN: 10^8 (100,000,000) possibilities.
  • First half (4 digits): 10^4 (10,000) possibilities.
  • Second half (3 digits + checksum): 10^3 (1,000) possibilities.
  • Total effective: ~11,000 possibilities.

Example: PIN Validation

An AP responds with an error if the first 4 digits are wrong, or if the last 3 (plus checksum) are wrong. This feedback allows an attacker to confirm correct segments, speeding up the attack significantly.

Safety Note

Due to this critical flaw, WPS should be disabled on all production Access Points if not absolutely necessary, as it poses a significant security risk to the network's WPA/WPA2 passphrase.
