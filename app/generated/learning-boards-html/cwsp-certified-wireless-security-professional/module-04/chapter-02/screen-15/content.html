Key Concepts: Tools and Techniques

Important terms for attack and defense.

Deauthentication Attack

A DoS attack forcing clients to disconnect from an AP, often used to push them towards an Evil Twin.

Captive Portal

A web page requiring user agreement or credentials before granting broader network access; used by attackers for phishing.

`airbase-ng` & `hostapd`

Tools for creating fake APs; `airbase-ng` for basic cloning, `hostapd` for advanced, legitimate-looking configurations.

Summary Takeaway

Understanding deauthentication, captive portals, and tools like `airbase-ng`, `hostapd`, and WIDS is crucial for both offensive and defensive wireless security strategies.
