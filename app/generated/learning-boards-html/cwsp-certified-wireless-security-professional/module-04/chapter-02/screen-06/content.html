Definition

Evil Twin Attacks: Mimicking Trust

A malicious AP impersonating a legitimate one to deceive users and intercept traffic.

Key Characteristics

  • •

    SSID/BSSID Cloning: Uses the same network name and often MAC address.

  • •

    User Deception: Primary goal is to trick users into connecting to the fake AP.

  • •

    MITM Attacks: Enables Man-in-the-Middle attacks, credential capture, malware distribution.

Key Takeaway

Evil Twins exploit user trust and convenience through social engineering to intercept sensitive data.
