Rogue AP vs. Evil Twin: Key Distinctions

Understanding the different intents and attack vectors.

Rogue AP

  • •

    Primary Intent: Unauthorized access to a legitimate internal network.

  • •

    Deployment: Physically connected to the wired internal network (insider or physical breach).

  • •

    Main Danger: Provides an unmonitored backdoor, bypassing firewalls and security controls.

  • •

    Example: Employee plugs in a personal Wi-Fi router to an office Ethernet port.

Evil Twin

  • •

    Primary Intent: Deceive users into connecting to a malicious AP.

  • •

    Deployment: Attacker sets up a portable AP mimicking a legitimate SSID nearby.

  • •

    Main Danger: Enables MITM attacks, credential harvesting, malware distribution.

  • •

    Example: Fake 'Free_Coffee_WiFi' at a cafe to steal login credentials.

Key Takeaway

Rogue APs are internal network breaches, while Evil Twins are external user-deception attacks, each requiring distinct defense strategies.
