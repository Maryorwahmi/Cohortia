Forcing Connections: Deauthentication and Redirection

Deauthenticating clients to force connection to the Evil Twin.

Attack Sequence

  • •

    1. Deauthentication: Use aireplay-ng to disconnect clients from the legitimate AP.

  • •

    2. Client Reconnection: Clients attempt to reconnect, ideally to the Evil Twin.

  • •

    3. DHCP & DNS: Configure dnsmasq to provide IP addresses and DNS services to clients.

  • •

    4. Fake Captive Portal: Host a phishing page on a web server (e.g., Apache) to capture credentials.

Example Command: Deauthentication Attack
sudo aireplay-ng --deauth 0 -a [LEGIT_BSSID] wlan0mon

This command continuously sends deauthentication packets to force client disconnection.

Key Takeaway

Deauthentication attacks are crucial for forcing client connections to an Evil Twin, enabling subsequent credential harvesting via fake portals.
