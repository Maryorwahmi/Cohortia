Wireshark for Hidden SSID Discovery

Applying Capture Filters for Targeted Analysis

Wireshark Display Filter
wlan.fc.type_subtype == 0x04 || wlan.fc.type_subtype == 0x05

This filter isolates probe request (0x04) and probe response (0x05) frames.

Filter Breakdown
  • 0x04: Represents an 802.11 Probe Request frame.
  • 0x05: Represents an 802.11 Probe Response frame.
  • These frames are key to revealing non-broadcast SSIDs.
Practical Example

After capturing wireless traffic, apply the filter. You'll see packets where the SSID is explicitly listed in the 'Tagged Parameters' section under the 'Wireless LAN' details, even if the AP doesn't broadcast it.

Key Takeaway

Wireshark's display filters for probe frames are a direct and effective method to uncover SSIDs that network administrators attempt to hide.

Common Mistake

Overlooking the client's role in broadcasting SSIDs. Clients actively seeking hidden networks are often the source of their exposure.
