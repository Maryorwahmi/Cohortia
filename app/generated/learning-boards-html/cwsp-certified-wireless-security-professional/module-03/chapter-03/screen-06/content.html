Deauthentication Flood Signature

A deauthentication flood attack has a specific signature: a high volume of 802.11 deauthentication frames from a single source to multiple targets in a short timeframe.

High Volume: Many deauthentication frames sent rapidly.

Single Source: Frames originate from one attacker MAC address.

Multiple Targets: Directed at many clients or a broadcast address.

Key Takeaway

WIDS/WIPS systems use specific rules, like 'X deauth frames from one source to Y clients in Z seconds,' to detect deauthentication floods.

Simulated Signature Rule
rule deauth_flood_detection {
  event_type: "802.11_DEAUTHENTICATION"
  threshold: {
    count: 50 // 50 deauth frames
    time_window: 5 // within 5 seconds
  }
  group_by: "source_mac_address"
  condition: "target_count > 5" // targeting more than 5 clients
  action: "ALERT"
}
Pro-Tip

Regularly update WIDS/WIPS signature databases to ensure protection against the latest known wireless attack vectors. Outdated signatures leave your network vulnerable.
