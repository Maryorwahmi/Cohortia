Detection Technique

Anomaly-Based Detection

This technique identifies threats by detecting deviations from a learned baseline of 'normal' network behavior, making it effective against unknown attacks.

Learned Baseline: Builds a profile of typical wireless traffic and behavior over time.

Deviation Detection: Flags significant departures from the established normal behavior.

Zero-Day Capable: Can identify unknown or novel attacks without prior signatures.

Key Takeaway

Anomaly-based detection is powerful for unknown threats but requires careful tuning to minimize false positives during legitimate network changes.

How it Works: Example
1. Establish Baseline
2. Monitor for Deviations
3. Flag Anomalies
Disadvantage

Anomaly-based detection can generate higher false positives, especially during legitimate network changes or new application deployments that alter normal traffic patterns.
