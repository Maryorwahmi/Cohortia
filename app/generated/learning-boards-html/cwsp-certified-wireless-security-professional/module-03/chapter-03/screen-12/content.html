Critical Concepts

Understanding False Negatives

A false negative occurs when a real attack or threat is missed by the WIDS/WIPS system, failing to generate an alert and creating a false sense of security.

Missed Threat: A genuine attack goes undetected.

False Security: Network appears safe while an intrusion is active.

Severe Consequences: Can lead to data breaches and system compromise.

Key Takeaway

False negatives are dangerous as they allow real threats to go unnoticed, emphasizing the need for multi-layered detection and continuous system updates.

Example Scenarios

Scenario 1: Signature Bypass
An attacker crafts a novel attack that subtly alters a known pattern, bypassing existing signature definitions.

Scenario 2: Mimicking Normal Behavior
A sophisticated attacker slowly 'trickles' deauthentication frames over hours, staying below the anomaly detection threshold.

Scenario 3: Zero-Day Exploit
A brand new vulnerability is exploited for which no signature or baseline anomaly has been established yet.

Comparison

While false positives lead to wasted resources, false negatives lead to actual security breaches. Both must be minimized for an effective WIDS/WIPS.
