PEN TEST PHASE

Phase 1: Reconnaissance

Gathering Information Non-Intrusively

What is Reconnaissance?

The initial phase of gathering information about the target wireless environment without direct, intrusive interaction.

Information Collected

  • SSIDs (Network Names)
  • BSSIDs (Access Point MAC Addresses)
  • Operating Channels
  • Encryption Types (e.g., WPA2, WPA3)
  • Physical Locations of Access Points
Key Takeaway

Reconnaissance is like detective work: passively collecting crucial network details to inform later, more active testing phases.
