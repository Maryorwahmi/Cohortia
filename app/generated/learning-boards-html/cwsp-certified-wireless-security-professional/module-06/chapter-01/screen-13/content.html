CHAPTER SUMMARY

Key Concepts

Core Terms to Remember

Penetration Testing (Pen Test)

A simulated cyberattack against a system, network, or application to identify exploitable vulnerabilities.

Rules of Engagement (RoE)

A formal document outlining the scope, objectives, permitted activities, and legal authorization for a penetration test.

Monitor Mode

A special mode for wireless network adapters that allows them to capture all wireless traffic in range.

Summary Takeaway

Wireless penetration testing is a structured, ethical process governed by explicit rules, requiring specialized tools and a deep understanding of network behavior.
