Phase 2: Scanning and Enumeration

Actively Probing for Detailed Network Information

What is Scanning & Enumeration?

Actively probing the network to gather more detailed information, identifying specific characteristics that might indicate vulnerabilities.

Key Activities

  • Identify connected clients.
  • Discover hidden SSIDs.
  • Map network topology.
  • Identify device types and configurations.
Key Takeaway

This phase involves active probing to uncover deeper network details, crucial for identifying specific vulnerability indicators.
