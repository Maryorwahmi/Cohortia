Putting It All Together: A Reconnaissance Workflow

A step-by-step guide to performing passive network discovery with `airodump-ng` and `Kismet`.

Passive Reconnaissance Steps
1. Start Monitor Mode: Prepare your wireless adapter for packet capture.
2. Discover with `airodump-ng`: Perform a broad scan to identify APs and clients.
3. Targeted Capture: Focus `airodump-ng` on a specific AP and save data to a file.
4. Explore with `Kismet`: Use its web UI for a graphical overview and hidden SSID detection.
5. Stop Tools & Reset: Close tools and return adapter to managed mode.

Expected Outcome: You will have a `.cap` file for targeted analysis and a comprehensive understanding of the wireless environment from `Kismet`'s interface.

Monitor Mode Setup
sudo airmon-ng check kill
sudo airmon-ng start wlan0
Initial `airodump-ng` Scan
sudo airodump-ng wlan0mon
Start `Kismet`
sudo kismet
Cleanup
sudo airmon-ng stop wlan0mon
sudo service NetworkManager start
Key Takeaway

An integrated workflow combining `airodump-ng` for raw data and `Kismet` for comprehensive visualization is essential for thorough passive wireless reconnaissance.
