Client Tracking and Targeted Capture

Leveraging `airodump-ng` to identify connected clients and focus data collection.

Targeted Capture Steps
Identify Target AP: Locate the BSSID and channel of the desired access point from initial `airodump-ng` output.
Focus Scan: Use `--channel` and `--bssid` to narrow down the monitoring to a single AP.
Save Data: Employ `--write` to save captured packets to a `.cap` file for offline analysis, crucial for password cracking.

Pro Tip: When capturing to a file, always monitor your disk space. Large, active networks can generate gigabytes of data quickly, potentially filling your storage and stopping the capture prematurely.

Targeted `airodump-ng` Command
sudo airodump-ng \
  --channel 6 \
  --bssid AA:BB:CC:DD:EE:FF \
  --write capture_file \
  wlan0mon
Output File Example
-rw-r--r-- 1 root root 12345678 Oct 26 10:30 capture_file-01.cap
-rw-r--r-- 1 root root     1234 Oct 26 10:30 capture_file-01.csv
-rw-r--r-- 1 root root     5678 Oct 26 10:30 capture_file-01.kismet.netxml
Key Takeaway

Targeting `airodump-ng` scans with specific channels and BSSIDs, and saving to file, is crucial for efficient data collection and subsequent security analysis.
