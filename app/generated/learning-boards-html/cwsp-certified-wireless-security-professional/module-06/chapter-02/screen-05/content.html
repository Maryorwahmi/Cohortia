airodump-ng: Network Discovery

A fundamental tool for passive scanning, airodump-ng captures raw 802.11 frames to reveal nearby access points and clients.

# Ensure adapter is in monitor mode first
sudo airodump-ng wlan0mon

Key Takeaway

airodump-ng provides a real-time overview of wireless networks, their security, and connected clients.

Understanding airodump-ng Output

BSSID & ESSID

BSSID is the AP's MAC address; ESSID is the network name (SSID).

PWR & Beacons

PWR indicates signal strength; Beacons count broadcast frames from the AP.

ENC, CIPHER, AUTH

Details on encryption type (WPA2), cipher (CCMP), and authentication (PSK).

STATIONS (Clients)

Lists connected client MAC addresses and their associated APs.
