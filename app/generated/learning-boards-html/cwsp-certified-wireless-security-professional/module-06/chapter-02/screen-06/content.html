Advanced Usage

Targeted airodump-ng Scans

Optimize your reconnaissance by focusing airodump-ng on specific channels and capturing data to files for later analysis.

# Scan only on channel 6
sudo airodump-ng --channel 6 wlan0mon

# Targeted capture to file for a specific AP
sudo airodump-ng --channel 6 \
  --bssid AA:BB:CC:DD:EE:FF \
  --write capture_file \
  wlan0mon
Key Takeaway

Targeted scanning improves efficiency and enables crucial data capture for advanced security tasks like password cracking.

Why Target Your Scan?

Avoid Missing Activity

Default channel hopping can be slow and miss crucial data on specific channels.

Crucial for Cracking

Capturing to a .cap file is essential for WPA/WPA2-PSK cracking attempts.

Disk Space Warning

Captured files can grow very large quickly; ensure adequate storage.
