Key Concepts: Foundational Techniques

Revisiting the core ideas behind wireless reconnaissance and passive scanning.

Passive Scanning

Gathering information about a wireless network by only listening to broadcasted traffic, without sending any active probes or requests.

Active Scanning

Sending probes or requests to a wireless network to elicit responses and gather information, which is faster but more detectable.

`airodump-ng`

A command-line tool from the Aircrack-ng suite used for capturing raw 802.11 frames and displaying information about APs and clients.

Summary Takeaway

Understanding the difference between passive and active scanning, and mastering tools like `airodump-ng`, is fundamental for effective wireless security assessments.
