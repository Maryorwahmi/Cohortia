WPA/WPA2-Enterprise Fundamentals

Understanding 802.1X, EAP, and RADIUS

The Enterprise Advantage

WPA/WPA2-Enterprise offers enhanced security over PSK by using individual user credentials and a centralized authentication system, making it resilient to dictionary attacks on a shared key.

802.1X

Port-based network access control standard, acting as a gatekeeper for network access.

EAP

Extensible Authentication Protocol, a flexible framework for various authentication methods.

RADIUS

Remote Authentication Dial-In User Service, a centralized server for authentication, authorization, and accounting (AAA).

New Attack Vectors

Focus shifts to credential harvesting and bypassing the authentication process itself.

Enterprise Authentication Flow

User/Client
Access Point (802.1X Authenticator)
RADIUS Server (EAP Authenticator)
Backend Directory (e.g., Active Directory)
Key Takeaway

Enterprise wireless security relies on a multi-component architecture that, while strong against simple attacks, introduces new complex vulnerabilities for credential harvesting.
