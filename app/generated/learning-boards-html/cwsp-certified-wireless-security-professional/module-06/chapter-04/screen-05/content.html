Attack Vector

The Evil Twin Attack

Mimicking Legitimate Networks to Harvest Credentials

How it Works

  • Attacker sets up a malicious AP.
  • Malicious AP mimics a legitimate corporate Wi-Fi network (same SSID).
  • Unsuspecting users are tricked into connecting to the rogue AP.
  • Once connected, the rogue AP solicits and captures authentication credentials.

Why it's Effective

Many enterprise clients are configured to automatically connect to known SSIDs. This automation, combined with user trust, makes the attack highly successful in harvesting credentials without direct user interaction beyond the initial connection.

Evil Twin Attack Flow

1. Legitimate AP (Corporate_WiFi)
2. Attacker sets up Rogue AP (Corporate_WiFi)
3. User connects to Rogue AP (believing it's legitimate)
4. Rogue AP captures user credentials
Key Takeaway

Evil Twin attacks exploit client automation and user trust by impersonating legitimate APs to steal authentication credentials.
