Cracking Captured MSCHAPv2 Hashes

Recovering Passwords from Captured Hashes

The Goal: Plaintext Passwords

Captured MSCHAPv2 hashes are not plaintext passwords, but they can be subjected to offline cracking attacks using specialized tools and wordlists to reveal the original credentials.

Tools for Cracking

  • Hashcat: A powerful, GPU-accelerated password cracker supporting various hash types.
  • John the Ripper: Another widely used password cracking tool, often used for CPU-based cracking.

`hashcat` Example for MSCHAPv2

Using hashcat with the correct hash mode and a comprehensive wordlist is key to recovering passwords.

hashcat -m 5500 captured_mschapv2.hash /usr/share/wordlists/rockyou.txt
  • -m 5500: This is the specific hash mode identifier for MSCHAPv2.
  • captured_mschapv2.hash: The file containing the NTLMv2 hash(es) captured from the Evil Twin attack.
  • /usr/share/wordlists/rockyou.txt: A common wordlist used for dictionary attacks. The larger and more relevant the wordlist, the higher the chance of success.
Key Takeaway

Offline cracking of MSCHAPv2 hashes with tools like hashcat is a critical step to obtain plaintext passwords, underscoring the importance of strong password policies.
