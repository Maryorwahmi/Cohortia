Key Concepts

Attack Techniques and Tools

Rogue AP (Evil Twin)

A malicious AP mimicking a legitimate network to trick users into revealing credentials.

`hostapd-wpe`

Modified hostapd for setting up rogue APs and capturing EAP authentication hashes.

`EAPHammer`

Automated framework for performing Evil Twin attacks against various EAP methods.

PEAP/MSCHAPv2 Vulnerability

Vulnerable to credential harvesting if client certificate validation is weak.

Deauthentication Attack

Forces clients to disconnect from an AP, used to facilitate other attacks or for DoS.

These attack vectors highlight the critical vulnerabilities in enterprise wireless networks and the tools used to exploit them.
