WPA/WPA2 Fundamentals

WPA/WPA2-PSK Security & Handshake

Understanding the stronger security of WPA/WPA2 and the 4-way handshake.

Robust 4-Way Handshake

This is a critical exchange of four messages between a client and an AP to establish a secure session key, ensuring mutual authentication.

Per-Packet Keying

Unlike WEP, WPA/WPA2 uses dynamic encryption keys that change frequently, significantly increasing security and preventing IV reuse.

Key Takeaway

WPA/WPA2-PSK's strength lies in its 4-way handshake and dynamic keys, but a weak pre-shared key remains its primary vulnerability to offline attacks.

WPA/WPA2 4-Way Handshake
1. AP sends ANonce
2. Client sends SNonce + MIC
3. AP sends GTK + MIC
4. Client confirms + MIC
