Core Concept

WEP's Fundamental Vulnerabilities

Understanding why Wired Equivalent Privacy is easily broken.

24-bit Initialization Vector (IV)

WEP uses a very short 24-bit IV, which is transmitted in plaintext with every packet. This small key space means IVs repeat quickly.

IV Collisions

Due to the small IV space, the same IV is frequently reused with the same WEP key, creating 'collisions' that reveal cryptographic information.

Statistical Key Derivation

With enough captured packets containing IV collisions, statistical analysis can be used to derive the WEP key, making it easily crackable.

Key Takeaway

WEP's reliance on a short, plaintext IV leads to predictable reuse and cryptographic weaknesses, making it fundamentally insecure.

WEP Key Derivation Process
1. Capture Packets (IVs + Data)
2. Identify IV Collisions
3. Statistical Analysis
4. WEP Key Revealed
