WEP Cracking: ARP Replay Attack

Accelerating IV collection with aireplay-ng.

Re-injecting ARP Requests

aireplay-ng captures and re-injects Address Resolution Protocol (ARP) requests back into the network, simulating legitimate traffic.

Forcing New IVs

Each re-injected ARP request forces the Access Point (AP) to generate and transmit new Initialization Vectors (IVs) in its responses.

Key Takeaway

The ARP replay attack is crucial for rapidly collecting enough IVs to make WEP cracking feasible, especially on low-traffic networks.

# Perform ARP Replay Attack
sudo aireplay-ng --arpreplay -b AA:BB:CC:DD:EE:FF -h CC:DD:EE:FF:GG:HH wlan0mon
Explanation:
  • --arpreplay: Specifies the ARP replay attack mode.
  • -b AA:BB:CC:DD:EE:FF: The BSSID (MAC address) of the target AP.
  • -h CC:DD:EE:FF:GG:HH: The MAC address of a connected client or a spoofed MAC.
  • wlan0mon: Your wireless interface in monitor mode.
Pro Tip

If no clients are connected, you can spoof a MAC address using tools like macchanger and then use that spoofed MAC with aireplay-ng.
