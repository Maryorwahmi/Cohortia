WEP Cracking: Packet Capture

Setting up monitor mode and capturing data with airodump-ng.

Monitor Mode Activation

Your wireless adapter must be in monitor mode to passively capture all network traffic, not just traffic directed at your device.

Targeted Packet Capture

Use airodump-ng to focus on a specific Access Point (AP) by its BSSID and channel, saving all captured packets to a .cap file.

Key Takeaway

Successful WEP cracking begins with correctly configuring monitor mode and using airodump-ng to capture sufficient raw network traffic.

# Put adapter in monitor mode (example)
sudo airmon-ng check kill
sudo airmon-ng start wlan0
# Capture packets with airodump-ng
sudo airodump-ng --channel 6 --bssid AA:BB:CC:DD:EE:FF --write wep_capture wlan0mon
Explanation:
  • --channel 6: Specifies the target AP's channel.
  • --bssid AA:BB:CC:DD:EE:FF: Filters for the target AP's MAC address.
  • --write wep_capture: Saves captured data to files prefixed with 'wep_capture'.
  • wlan0mon: Your wireless interface in monitor mode.
Common Mistake

Forgetting to put the adapter in monitor mode or specifying the wrong channel/BSSID will result in no or insufficient packet capture.
