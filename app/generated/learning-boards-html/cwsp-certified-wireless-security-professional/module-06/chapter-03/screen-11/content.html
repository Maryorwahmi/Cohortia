WPA/WPA2 Cracking

Dictionary Attacks with Aircrack-ng

Leveraging wordlists to crack captured WPA/WPA2-PSK handshakes.

Wordlist Application

aircrack-ng takes a wordlist (a file containing potential passphrases) and attempts each entry against the captured 4-way handshake.

Hash Comparison

For each wordlist entry, aircrack-ng generates a hash and compares it to the hash within the handshake. A match reveals the passphrase.

Key Takeaway

Dictionary attacks with aircrack-ng are effective against WPA/WPA2-PSK networks if the passphrase exists in a provided wordlist.

# Dictionary attack with aircrack-ng
sudo aircrack-ng wpa_capture-01.cap -w /usr/share/wordlists/rockyou.txt
Explanation:
  • wpa_capture-01.cap: The captured file containing the WPA/WPA2 handshake.
  • -w /usr/share/wordlists/rockyou.txt: Specifies the path to the wordlist file.
  • aircrack-ng will iterate through the wordlist, attempting to crack the passphrase.
Common Mistake

Using a wordlist that is too small or irrelevant to the target, leading to a failed cracking attempt.
