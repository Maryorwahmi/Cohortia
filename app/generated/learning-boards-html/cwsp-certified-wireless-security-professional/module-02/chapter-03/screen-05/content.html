FreeRADIUS: Defining Clients

Securing communication between your WLC/AP and the RADIUS server.

clients.confFreeRADIUS Configuration
# Example FreeRADIUS clients.conf entry
client my_wlc {
    ipaddr = 192.168.1.100  # IP address of your WLC
    secret = mySuperSecretRadiusKey # Shared secret
    nas_type = cisco
}
client my_ap_1 {
    ipaddr = 192.168.1.101
    secret = mySuperSecretRadiusKey
    nas_type = other
}
Common Mistake

A mismatched shared secret is a frequent cause of authentication failures. Double-check for typos or incorrect values on both the RADIUS server and the WLC/AP.

Key Components

  • `client` block: Defines a network access server (NAS), typically a WLC or AP.
  • `ipaddr`: The IP address of the WLC or AP. This tells FreeRADIUS which device is allowed to send requests from this IP.
  • `secret`: The shared secret, a passphrase that must be identical on both the RADIUS server and the WLC/AP for secure communication.
  • `nas_type`: Specifies the type of Network Access Server, which can influence how attributes are handled (e.g., `cisco`, `other`).
Key Takeaway

Properly defining RADIUS clients with matching shared secrets is the foundational step for secure communication and authentication in an enterprise wireless network.
