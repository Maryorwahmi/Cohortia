FreeRADIUS: Managing Users and Groups

Controlling who can authenticate to your wireless network.

users fileFreeRADIUS Configuration
# Example FreeRADIUS users file entry
"john.doe" Cleartext-Password := "SecurePassword123"
    Service-Type = Login,
    Tunnel-Type = VLAN,
    Tunnel-Medium-Type = IEEE-802,
    Tunnel-Private-Group-Id = "10" # Assigns John to VLAN 10
Dynamic VLAN Assignment

RADIUS can return attributes that instruct the WLC/AP to dynamically assign clients to specific VLANs based on their authenticated identity, enhancing network segmentation.

User Management Options

  • Local Files: Simple for testing, users defined directly in the `users` file.
  • LDAP/Active Directory: Integrates with existing directory services for centralized user management.
  • SQL Databases: Stores user credentials and attributes in a database for flexible management.
  • Groups: Users can be part of groups, allowing policy application based on group membership.
Key Takeaway

Effective user and group management in FreeRADIUS is crucial for granular access control and dynamic policy enforcement, such as VLAN assignment, based on authenticated identities.
