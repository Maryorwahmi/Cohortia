Key Concepts

Essential Terms for Enterprise Wireless Security

RADIUS Client

A network access device (e.g., WLC, AP) that sends authentication requests to a RADIUS server.

Shared Secret

A pre-shared key used to secure communication between a RADIUS client and a RADIUS server.

FreeRADIUS

A popular open-source implementation of a RADIUS server, widely used for authentication services.

Summary Takeaway

These core terms define the fundamental components and mechanisms for establishing and securing enterprise wireless networks using RADIUS.
