Supplicant, Authenticator, Server

The Key Roles in 802.1X Authentication

1. Supplicant

The client device (e.g., laptop, smartphone) attempting to gain network access. It initiates the authentication request.

2. Authenticator

The network access device (e.g., AP, WLC) that the supplicant connects to. It relays messages and enforces access decisions.

3. Authentication Server

The central authority (typically a RADIUS server) responsible for verifying credentials and making the final access decision.

Centralized Control

This architecture centralizes authentication decisions, simplifying management and enhancing security by having a single, trusted entity verify credentials.

Key Takeaway

Understanding the distinct roles of the supplicant, authenticator, and authentication server is fundamental to grasping how 802.1X secures network access.
