Key Concepts

Essential Terms to Remember

802.1X

An IEEE standard for port-based network access control, providing a framework for authenticating devices before granting network access.

Supplicant

The client device (e.g., laptop, smartphone) attempting to gain network access by initiating an authentication request.

Authenticator

The network access device (e.g., Wireless Access Point) that relays authentication messages and enforces access decisions.

Summary Takeaway

The 802.1X standard defines the roles of the supplicant, authenticator, and authentication server, which are fundamental to securing network access.
