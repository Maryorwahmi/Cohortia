Completing the Authentication

Method Negotiation and Access Decision

04

AP Forwards Identity to RADIUS

The AP encapsulates the Supplicant's identity and forwards it to the RADIUS (Authentication) Server.

05

RADIUS Negotiates EAP Method

The RADIUS server sends EAP-Request messages (e.g., for password/certificate) to the AP, which relays them to the Supplicant. The Supplicant responds with EAP-Response messages, relayed back to RADIUS.

06

Access Decision & Key Derivation

RADIUS sends Access-Accept or Access-Reject to the AP. If accepted, the AP authorizes the client and derives unique encryption keys (PMK, TK, GTK) for the session.

The Full Exchange

This multi-step process ensures a secure, verified connection, culminating in either authorized network access or denial.

Key Takeaway

The complete 802.1X/EAP authentication flow involves a detailed exchange between all three components, ensuring robust verification before network access is granted.
