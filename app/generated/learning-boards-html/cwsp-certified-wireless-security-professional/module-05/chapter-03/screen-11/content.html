Access Control Types

Post-admission Control: Continuous Monitoring

Post-admission control grants initial limited access and then continuously monitors the device's compliance, dynamically adjusting access if non-compliance occurs.

  • Continuous Monitoring: Devices are monitored for compliance after connecting.
  • Dynamic Access Changes: Access can be restricted or revoked if non-compliance is detected.
  • Flexibility: Useful for BYOD or when initial access is needed for posture assessment.
Example Scenario

A compliant laptop connects to the network. Later, its antivirus expires. Post-admission control detects this and moves it to a quarantine VLAN.
