Process Flow

How NAC Controls Network Access

A step-by-step look at device connection and policy enforcement.

01

Device Connection Attempt

A device (supplicant) attempts to connect to a wireless AP (enforcement point).

02

Authentication Request

The AP acts as an authenticator, relaying the connection request to the NAC Policy Server.

03

Policy Evaluation

The Policy Server evaluates the device against predefined security policies (identity, posture, etc.).

04

Access Decision

Based on evaluation, the Policy Server decides to grant, deny, or quarantine access.

05

Enforcement Action

The AP enforces the decision, allowing access, blocking, or placing in a restricted VLAN.

06

Continuous Monitoring

For granted access, NAC can continuously monitor compliance and react to changes.

Key Takeaway

NAC ensures every device is vetted against security policies before gaining network access, providing a robust defense mechanism.
