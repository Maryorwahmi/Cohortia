Compliance Check

Ensuring Device Health with Posture Assessment

Verifying a device's security health and compliance with organizational policies before granting network access.

OS Up-to-Date

Checks if the operating system has the latest security patches and updates installed.

Antivirus Status

Verifies if antivirus software is installed, running, and has current definition files.

Firewall Enabled

Confirms that the device's local firewall is active and properly configured.

Missing Patches

Detects if critical security patches are absent, indicating potential vulnerabilities.

Remediation Action

If checks fail, NAC can quarantine the device to a remediation VLAN for fixes.

Key Takeaway

Posture assessment is a vital layer of defense, preventing non-compliant devices from introducing vulnerabilities to the network by enforcing security health checks.
