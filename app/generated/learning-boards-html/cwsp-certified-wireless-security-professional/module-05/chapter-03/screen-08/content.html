Device Intelligence

Understanding Device Profiling

The process of identifying the type, manufacturer, and operating system of a device connecting to the network.

MAC Address OUI

Identifies the manufacturer of the network interface card, providing a clue about the device type.

DHCP Fingerprints

Analyzes DHCP requests to infer the operating system of the connecting device.

HTTP User Agents

For web-enabled devices, the user agent string can reveal browser and OS information.

Endpoint Agent Reports

Dedicated software agents on devices can provide detailed system information to NAC.

Key Takeaway

Device profiling enables NAC to apply context-aware policies, ensuring appropriate access levels based on the specific type of device connecting to the network.
