System Architecture

The Building Blocks of NAC

A typical NAC system comprises three key components that work together to enforce security policies and control network access.

  • Policy Server: The 'brain' where rules are defined and decisions are made.
  • Enforcement Points: Network devices (APs, switches) that block or allow access.
  • Supplicants: Client software on end-devices that communicates for authentication.
Key Relationship

These components work in concert: the Supplicant requests access, the Enforcement Point relays it, and the Policy Server makes the decision.
