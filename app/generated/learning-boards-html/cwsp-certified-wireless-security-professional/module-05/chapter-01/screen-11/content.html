Threat Type 1

Rogue Access Points

Definition

Unauthorized APs connected to the corporate network, often by employees.

Risk

Bypass security controls, creating unmonitored backdoors for attackers.

Example

An employee plugs in a personal Wi-Fi router to get better signal in their office.

Threat Type 2

Evil Twin Access Points

Definition

Malicious APs mimicking legitimate ones to trick users into connecting.

Risk

Intercept traffic, steal credentials via phishing, or launch further attacks.

Example

An attacker sets up an AP with your company's SSID in a nearby public area.
