Process Walkthrough

Facilitating an Example Mapping Session

A step-by-step guide from feature to resolved questions.

1

Start with the Feature (Blue Card)

Product Owner presents the user story or feature to be discussed.

2

Brainstorm Business Rules (Yellow Cards)

Team identifies and captures the specific rules governing the feature.

3

Generate Concrete Examples (Green Cards)

For each rule, create examples illustrating its behavior, including edge cases.

4

Capture & Resolve Questions (Red Cards)

Identify and address any ambiguities or uncertainties that arise.

Key Takeaway

An Example Mapping session systematically moves from defining a feature to identifying rules, illustrating with examples, and resolving questions, ensuring comprehensive understanding.
