Gherkin Keyword

Verifying Outcomes: The Then Clause

Specifying the expected observable results.

Expected Result

What should happen or be visible after the 'When' action.

Observable Outcome

Focus on user-facing changes, not internal system states.

Key Takeaway

The 'Then' clause defines the verifiable success criteria, ensuring the system behaves as expected from a user's perspective.

Then Example: User Login
Scenario: Successful login
  Given ...
  When ...
  Then I should be redirected to the dashboard
  And I should see a welcome message "Welcome, testuser!"

These 'Then' steps describe the observable outcomes after a successful login attempt.
