Gherkin Keyword

Defining a Feature: High-Level Capability

Capturing the 'who, what, and why' of a system capability.

High-Level Description

Corresponds to a user story or major business function.

Optional Narrative

Explains 'As a..., I want..., So that...' for business context.

Key Takeaway

The 'Feature' keyword provides the overarching context and business value for the scenarios that follow.

Feature Example: User Login
Feature: User Login
  As a registered user
  I want to log in to the application
  So that I can access my personalized content

This example clearly states the feature, the user role, their goal, and the business benefit.
