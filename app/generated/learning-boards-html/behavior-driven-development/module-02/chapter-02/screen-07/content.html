Gherkin Keyword

Detailing Behavior: The Scenario Keyword

Describing specific examples of system behavior.

Specific Example

Each scenario illustrates one particular instance of system behavior.

Descriptive Title

Summarizes the behavior clearly and unambiguously.

Key Takeaway

Scenarios break down features into concrete, testable examples, each with a clear, descriptive title.

Scenario Example: User Login
Feature: User Login
  ...

  Scenario: Successful login with valid credentials
    Given I am on the login page
    When I enter valid credentials
    Then I should be redirected to the dashboard

This scenario title clearly indicates the specific behavior being tested: a successful login.
