Gherkin Structure

Organizing Behavior: Feature Files and Core Keywords

How Gherkin structures specifications for clarity.

.feature Files

Containers for Gherkin specifications, typically describing a single system feature.

Core Keywords

Feature, Scenario, Given, When, Then provide the essential structure.

Key Takeaway

Gherkin uses a set of keywords within '.feature' files to structure executable specifications, ensuring clarity and consistency.

Feature File Structure
Feature: User Login
  As a registered user
  I want to log in to the application
  So that I can access my personalized content

  Scenario: Successful login
    Given I am on the login page
    When I enter valid credentials
    Then I should be redirected to the dashboard

This structure ensures that each feature is clearly defined, and its associated behaviors are described in a consistent, understandable format.
