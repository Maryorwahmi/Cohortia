Gherkin Keyword

Triggering Action: The When Clause

Describing the action or event that initiates behavior.

User Interaction

Typically a direct action performed by a user, like clicking or typing.

Single Action Focus

Each 'When' step should describe one distinct action or event.

Key Takeaway

The 'When' clause specifies the single, triggering action that initiates the behavior under test, focusing on 'what' rather than 'how'.

When Example: User Login
Scenario: Successful login
  Given ...
  When I enter "testuser" into the username field
  And I enter "password123" into the password field
  And I click the "Login" button
  Then ...

These 'When' steps describe the user's actions to attempt a login.
