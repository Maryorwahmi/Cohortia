Key Concepts

Essential terms from this chapter

Gherkin

A plain-text, human-readable language for describing software behavior as executable specifications.

Feature File

A '.feature' file containing Gherkin specifications for a particular system capability.

Feature

A high-level capability of the system, described with a title and optional narrative.

Chapter Summary

Gherkin provides a structured, human-readable way to define and organize software behavior, bridging business needs with automated tests.
