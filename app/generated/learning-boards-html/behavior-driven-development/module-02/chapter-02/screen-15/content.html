Key Concepts

More essential terms from this chapter

Scenario

A specific example of how the system should behave under particular conditions.

Given-When-Then

The core structure for scenarios: Context, Action, and Expected Outcome.

Ubiquitous Language

The shared language used by all team members to describe the domain, formalized by Gherkin.

Chapter Summary

Gherkin provides a structured, human-readable way to define and organize software behavior, bridging business needs with automated tests.
