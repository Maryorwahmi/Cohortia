Module 5 › Chapter 5.3 › Key Concepts
What to Remember
Parameter Types
Predefined tokens like {int} and {double} that parse values for you.
Custom Parameter Type
Map domain text directly to enums or objects via @ParameterType.
Data Transformation
Use DataTableType to produce lists of typed domain objects from tables.
Summary takeaway
Choose the right mapping for your data: primitive → built-in, domain token → custom type, structured rows → DataTableType. Centralize parsing to make tests clearer and easier to maintain.
