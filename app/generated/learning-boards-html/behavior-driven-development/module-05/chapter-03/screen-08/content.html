Module 5 › Chapter 5.3 › Data Transformations
Definition
Use DataTableType to map Data Table rows to typed objects like Product or BookingRequest.
Why it helps
  • Reduces boilerplate parsing inside step methods.
  • Encapsulates header-to-property mapping in one place.
  • Improves reuse across multiple scenarios that share the table shape.
Key Takeaway

Transform tables to domain lists so the step focuses on behavior, not parsing.

Common pitfalls
Be careful with header names and numeric parsing. Build transforms that validate and throw clear errors for malformed rows so test failures are actionable.
Example mapping
Map a row with keys 'Product Name', 'Quantity', 'Price' to a Product object and parse Quantity and Price into numeric types inside the DataTableType.
