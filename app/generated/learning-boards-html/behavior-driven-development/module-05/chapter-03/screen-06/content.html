Module 5 › Chapter 5.3 › Custom Parameter Types
Definition & rationale
Create a named parameter type that matches domain tokens and returns a typed object or enum.
Example domain
Order statuses such as pending, shipped, delivered map naturally to an OrderStatus enum rather than raw strings.
Misconception
Custom types are not overengineering when the domain value appears across scenarios; they simplify many step definitions at once.
Key Takeaway

Centralize domain parsing in ParameterType implementations for consistent, typed values in steps.

Domain example
Define an enum OrderStatus with values PENDING, SHIPPED, DELIVERED, CANCELLED and a ParameterType that recognizes the lowercase labels and returns the corresponding enum.
Pro tip
Keep the regex specific to valid tokens. If values expand, update a single ParameterType rather than many step definitions.
