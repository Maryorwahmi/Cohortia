ParameterTypes.java
import io.cucumber.java.ParameterType;

public class ParameterTypes {

  @ParameterType("pending|shipped|delivered|cancelled")
  public OrderStatus orderStatus(String status) {
    return OrderStatus.valueOf(status.toUpperCase());
  }
}
This registers {orderStatus} so Gherkin can use that token and steps receive an OrderStatus enum directly.
Implementation notes
  • Normalize input before mapping to the enum to avoid case issues.
  • Keep the regex narrow to valid domain values to avoid accidental matches.
  • Throw informative exceptions on unexpected input so feature failures are diagnosable.
Key Takeaway

A single ParameterType definition gives every step a consistent, typed view of the domain token.
