Practice & Verification
Concrete checks to confirm competence
Run parsing scenarios
Verify that built-in types produce correct numeric and string values without manual parsing.
Milestone: Step receives a double and arithmetic asserts correctly.
Test custom types
Confirm your ParameterType returns the expected enum or object in step code when run from Gherkin text.
Milestone: Step receives an OrderStatus or RoomType instance.
Transform tables
Use DataTableType and assert the List<Product> or List<BookingRequest> has correct typed fields.
Milestone: Each row maps to a typed object without manual parsing code in the step.
Watch for header mismatches
Add defensive parsing in DataTableType to handle missing or misnamed columns gracefully.
Milestone: Tests show helpful failures when headers don't match.
