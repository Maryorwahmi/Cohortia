Quick comparison
Built-in types
Best for single primitive values. Fast to use and no setup required.
Custom parameter types
Best when text maps to domain concepts repeated across scenarios.
DataTableType
Best for structured lists that map naturally to domain objects.
Example contrasts
  • Price with currency: prefer a custom Price type rather than two separate primitives so the concept stays cohesive.
  • Room booking rows: use DataTableType to map rows to BookingRequest objects for batch processing.
  • One-off numeric flags: use built-in {int} or {double}.
Reflection

Ask: does this value represent a primitive, a domain concept, or a structured record? Your answer directs the mapping strategy.
