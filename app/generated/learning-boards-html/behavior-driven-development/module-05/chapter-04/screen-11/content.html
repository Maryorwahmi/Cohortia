Module 5 › Chapter 5.4 › Simulate CI Locally
Steps
  1. Ensure TestRunner writes json, html, junit to target/cucumber-reports.
  2. Run mvn test locally.
  3. Check for cucumber.json, cucumber.html, cucumber.xml.
  4. Open cucumber.html in your browser to inspect scenarios.
Troubleshooting
  • Missing files: verify plugin paths and test class inclusion.
  • Different output in CI: replicate the exact CI command locally.
  • Use a container image to mimic CI environment if necessary.
Pro tip
Start with a small tagged run to verify configuration before running the full suite locally or in CI.
