Practice Goals & Assessment

Concrete tasks you will perform in the hands-on activity and what counts as success.

Lab checklist
Configure reports
Set TestRunner to write JSON, HTML and JUnit XML into target/cucumber-reports.
Add CI job
Run mvn test in a pipeline job, archive artifacts, and feed the JUnit XML to your CI reporter.
Use tags
Run @smoke for fast feedback on each commit and @regression on scheduled runs or before staging.
Triage failures
Show a failing step with an error message and stack trace and describe the next debugging action.
