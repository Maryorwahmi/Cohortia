Module 5 › Chapter 5.4 › CI Job Example: GitLab CI
Example .gitlab-ci.yml
image: maven:3.8.5-openjdk-17

stages:
  - build
  - test
  - deploy

build_job:
  stage: build
  script:
    - mvn clean install -DskipTests
  artifacts:
    paths:
      - target/*.jar

bdd_test_job:
  stage: test
  script:
    - mvn test -Dcucumber.options="--tags @smoke"
  artifacts:
    when: always
    paths:
      - target/cucumber-reports/
    reports:
      junit: target/cucumber-reports/cucumber.xml
  allow_failure: false
Explanation
  • Use artifacts to retain HTML and JSON outputs for review.
  • reports:junit tells GitLab where to parse test results for the dashboard.
  • allow_failure:false enforces fail-fast so broken behavior stops the pipeline.
Tip
Run the job locally first by executing the mvn test command to confirm reports are produced in the expected path.
