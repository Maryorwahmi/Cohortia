Module 5 › Chapter 5.4 › Tagging Strategy
Design the smoke set
Choose a small number of fast, high-value scenarios that reflect the core functionality developers care about on each commit.
Run patterns
  • On push: run @smoke for fast feedback.
  • Nightly or pre-release: run @regression for full coverage.
  • Use pipeline conditionals to control execution frequency.
Avoid mistakes
Do not include flaky or slow tests in @smoke; that defeats the purpose of fast feedback.
Key Takeaway

Keep @smoke small and stable; run @regression at lower frequency to maintain confidence without slowing developers.
