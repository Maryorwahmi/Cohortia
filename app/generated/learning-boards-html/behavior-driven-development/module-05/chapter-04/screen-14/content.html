Module 5 › Chapter 5.4 › Key Concepts
CI/CD Pipeline
Automates build, test and deploy so BDD tests validate behavior continuously.
Report Formats
JSON for automation, JUnit XML for CI dashboards, HTML for human review.
Fast Feedback
Run critical tests on each commit and full suites less frequently to maintain speed.
Takeaway
Make your TestRunner emit the right reports, ensure CI archives and parses them, and keep tests stable so the pipeline is a reliable quality gate.
