Module 5 › Chapter 5.4 › Interpreting BDD Test Reports
What to look for
  • The failed step text and expected vs actual values.
  • Error type and stack trace (AssertionError, NoSuchElementException, TimeoutException).
  • Associated logs or screenshots captured during the scenario.
Example
A failing login test shows "Expected 'Dashboard', but found 'Login Page'". This suggests a redirect or authentication regression rather than a UI locator issue.
Action checklist
  • Reproduce the failure locally using the same tag or scenario.
  • Inspect logs and server responses if applicable.
  • Isolate whether the test or the application changed.
Key Takeaway

Use the detailed message and stack trace to decide whether to fix the test, the app, or the environment.
