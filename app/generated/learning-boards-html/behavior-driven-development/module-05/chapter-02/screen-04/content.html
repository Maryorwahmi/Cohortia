Core Concept
Tags: Label & Filter
Tags allow fast selection and intent communication across features and scenarios.
Filtering: run a subset like --tags @smoke
Categorization: domain tags such as @authentication or @product
Conditional hooks: e.g., @Before("@ui") initialize browser
Example
@authentication @smoke
Feature: User Login
  Scenario: Successful login
    Given I am on the login page
    When I enter valid credentials
    Then I see the dashboard
Key Takeaway

Use tags to speed CI feedback and to scope hooks; adopt a small, documented tag set to avoid confusion.

Common mistakes & pro tip
Over-tagging
Giving each scenario unique tags defeats the purpose; prefer a few cross-cutting tags and domain tags.
Using tags as environment flags
Tags are labels about execution and intent, not feature toggles or runtime config switches.
Pro tip
Document tag semantics in a README so CI pipelines and team members use them consistently.
