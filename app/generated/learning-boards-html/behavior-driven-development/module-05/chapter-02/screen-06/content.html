Process Flow
Hooks: before, after, ordered, and tagged
Hooks live in code and manage resources that are not part of the business narrative.
Typical responsibilities
  • Initialize and quit browser drivers
  • Open and close database connections
  • Take screenshots or collect logs on failure
Key Takeaway

Keep technical setup in hooks and business setup in Background. Use tag-scoped hooks to avoid unnecessary work.

Hook patterns
Global hooks
Run for every scenario to prepare or tear down shared resources.
Tagged hooks
Conditionally run setup only for scenarios that carry a specific tag such as @ui or @database.
Ordered hooks
Use order attributes to control execution sequence when multiple hooks exist.
