Definition
Directory Structure
Group features and step definitions by bounded context to reduce collisions and ease discovery.
Example layout
features/authentication, features/product, steps/authentication, steps/product
Key Takeaway

Organize by domain and keep step definitions nearby; enforce structure with a README so contributors follow it.

Practical tips
Ownership
Assign folders to teams so they can maintain their features and steps.
Avoid cross-cutting step misuse
If a step is genuinely cross-domain, keep it in a shared steps package with clear naming.
Update CI paths
When moving files, update any CI configuration that selects features by path.
