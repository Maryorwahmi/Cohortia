Activity steps

  1. Mock NotificationService and inject into UserService.
  2. Call updateProfile which triggers an async notification call.
  3. Simulate UI message update after a short delay and implement an explicit wait for it.
  4. After the wait succeeds, verify mockNotificationService.sendConfirmation was called.
