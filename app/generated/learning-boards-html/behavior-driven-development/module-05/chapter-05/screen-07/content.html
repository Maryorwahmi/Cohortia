Polling loop example

Poll an endpoint or check a simulated UI message until it equals the expected text or until timeout.

// Explicit wait simulation with polling long startTime = System.currentTimeMillis(); long timeout = 2000; // 2 seconds timeout while (!displayedMessage.equals(expectedMessage) && (System.currentTimeMillis() - startTime < timeout)) { Thread.sleep(100); // Poll every 100ms } assertTrue(displayedMessage.equals(expectedMessage), "Expected message not displayed.");
When to poll
Use polling when you can only observe state via repeated reads, such as checking an API resource for a status change.
Tune intervals
Short intervals give faster success detection; total timeout prevents infinite waits. Balance load on the system with test speed.
Misconception
Polling always slows tests. Not if an early success is common; well-chosen intervals detect success quickly and only poll longer on slow cases.
