Practice questions
Q1: Execution count
If a Scenario Outline has three placeholders and the Examples table has five rows, how many times will the scenario run? Answer: five times, once per row.
Q2: Pick the structure
Which is better for adding multiple items to a cart: Data Table or Examples table? Answer: Data Table, because the list belongs to one step.
