Module 5 › Chapter 5.1 › Step definitions for Outlines
Java example
A typical step definition accepts typed parameters using Cucumber expressions.
import io.cucumber.java.en.Given;

public class CalculatorSteps {
  private Calculator calculator;

  @Given("I have entered {double} into the calculator")
  public void iHaveEnteredNumberIntoTheCalculator(double number) {
    if (calculator == null) {
      calculator = new Calculator();
    }
    calculator.enter(number);
  }
}
This method receives the parsed double directly. If your Examples row contains 1.5, the method gets 1.5 as a double rather than a raw string.
Practical tips
  • Reset or reinstantiate state between Outline runs so rows don't share leftover data.
  • Choose typed capture groups to avoid manual parsing and conversion errors.
  • Keep step code small: parsing and delegating to domain helpers simplifies tests and maintenance.
Misconception

Putting heavy business logic inside step methods makes tests brittle. Prefer light parsing and delegate logic to domain helpers.
