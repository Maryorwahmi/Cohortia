Data-Driven Scenarios
Use Scenario Outlines and Data Tables to express repeated behavior clearly and concisely.
In this lesson you'll learn to move from duplicated examples to parameterized scenarios, and when to prefer an Examples table versus a Data Table for a step. The patterns you learn reduce maintenance and make intent visible to both technical and non-technical stakeholders.
