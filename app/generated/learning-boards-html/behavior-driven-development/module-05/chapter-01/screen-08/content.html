Java step definition example
import io.cucumber.java.en.When;
import io.cucumber.datatable.DataTable;

public class ShoppingCartSteps {
  private ShoppingCart cart = new ShoppingCart();

  @When("I add the following products to my cart:")
  public void iAddTheFollowingProductsToMyCart(DataTable productsTable) {
    List> products = productsTable.asMaps(String.class, String.class);
    for (Map product : products) {
      String productName = product.get("Product Name");
      int quantity = Integer.parseInt(product.get("Quantity"));
      double price = Double.parseDouble(product.get("Price"));
      cart.addProduct(productName, quantity, price);
    }
  }
}
Key considerations
  • Data tables are strings by default; convert types explicitly and validate formats.
  • Use asMaps to preserve header-to-value mapping for readability and stability.
  • Delegate business logic to domain helpers so the step remains an adapter between Gherkin and code.
Pro tip

Include clear error messages on parsing failures so failing table rows point to the problematic values quickly.
