Module 5 › Chapter 5.1 › Key Concepts
Scenario Outline
Run one scenario multiple times using placeholders and an Examples table.
Data Table
Pass structured rows to a single step; convert to lists or maps in code.
Step Definitions
Accept typed parameters and table maps, and delegate logic to helpers to keep tests simple.
Summary

Use Scenario Outlines for repeated runs, Data Tables for structured inputs, and keep parsing and business logic in code to preserve readable, maintainable features.
