When to choose a Data Table
Structured rows for a single step action, like multiple cart items or permission rows.
Example: Shopping cart
When I add the following products to my cart:
  | Product Name | Quantity | Price |
  | Laptop       | 1        | 1200  |
  | Mouse        | 2        | 25    |
  | Keyboard     | 1        | 75    |
This table is an argument to the When step. The step implementation will typically convert it into a list of maps where keys are column headers and values are the row values.
Why not use an Examples table here?
An Examples table repeats the entire scenario. If the variation is internal to a single action, repeating scenarios is unnecessary and reduces readability. Use Data Tables to keep complex inputs local to the step.
Key Takeaway

Use Data Tables when a single step needs a structured list or map; use Examples to repeat the whole scenario with different top-level inputs.
