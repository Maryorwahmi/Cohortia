How placeholders become values
Each Examples row yields one run with placeholders substituted before step matching.
1. Use angle-bracket placeholders like <item> in steps to indicate variable positions.
2. Add an Examples table whose column headers match placeholder names exactly.
3. Each table row becomes a separate execution and the test runner replaces placeholders with row values.
4. Step definitions receive parsed values as typed parameters according to their step annotations.
Common mistake

Mismatched header names or extra whitespace prevents substitution and causes runtime errors. Spell headers exactly.

Concrete example
Scenario Outline: Add two numbers
  Given I have entered <number1> into the calculator
  And I have entered <number2> into the calculator
  When I press add
  Then the result should be <expected_result>

  Examples:
    | number1 | number2 | expected_result |
    | 2       | 3       | 5               |
    | 1.5     | 2.5     | 4.0             |
Note how the table headers match the placeholders. If the header was Number1 instead of number1, the placeholder would not resolve and the runner would not substitute the values correctly.
