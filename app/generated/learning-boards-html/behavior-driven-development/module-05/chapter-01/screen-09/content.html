Module 5 › Chapter 5.1 › Examples vs Data Table
Examples table
Runs the scenario once per row; placeholders map to columns.
  • Use for top-level permutations and multiple test cases.
  • Each row is a distinct execution.
  • Keep headers precise and consistent with placeholders.
Data Table
Provides structured rows to a single step; ideal for lists and maps.
  • Use as an argument to one step.
  • Convert to a list of maps in step code for predictable parsing.
  • Keep complex data close to the consuming step.
Quick decision rule
If you need repeated runs with different top-level inputs, use Examples. If you need to pass a structured list or table to one action, use a Data Table. When in doubt, prefer the option that keeps the feature readable for stakeholders.
