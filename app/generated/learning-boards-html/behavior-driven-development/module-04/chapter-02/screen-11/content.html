Module 4 › Chapter 4.2 › Common Pitfalls
Problem: Undefined steps
Cause: glue path mismatch or step classes in an unexpected package. Remedy: ensure @CucumberOptions glue points to the package containing your step definitions, e.g., com.cohortia.steps.
Problem: Missing features
Cause: feature files not under src/test/resources or wrong features path in the runner. Remedy: move features to resources and set features = "src/test/resources/features".
Problem: Version incompatibility
Cause: mismatched Cucumber and JUnit versions. Remedy: manage versions in properties and consult compatible version pairs before upgrading.
Quick debug sequence
  1. Confirm features path and file locations.
  2. Check glue package names and runner configuration.
  3. Verify dependency versions and run with verbose logs.
