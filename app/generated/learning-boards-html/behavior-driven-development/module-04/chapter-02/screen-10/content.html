New step method
@When("I press the subtract button")
public void i_press_the_subtract_button() {
  if (numbers.size() < 2) {
    throw new IllegalStateException("Not enough numbers to subtract.");
  }
  result = numbers.get(0);
  for (int i = 1; i < numbers.size(); i++) {
    result -= numbers.get(i);
  }
}
Key Takeaway

Adding scenarios and corresponding step methods is the standard way to grow executable specifications.

Common Mistake

Not validating state size before arithmetic can lead to runtime exceptions; add checks or guard clauses.
