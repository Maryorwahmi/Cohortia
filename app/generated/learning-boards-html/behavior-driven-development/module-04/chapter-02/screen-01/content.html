Set Up Your First Cucumber Project

Create a minimal Java BDD project, write a Gherkin scenario, implement step definitions, and run it with Maven.

Follow conventions: feature files under src/test/resources, Java steps and runners under src/test/java.

Add cucumber-java, cucumber-junit, and junit as test scope dependencies.

Run mvn test to execute scenarios and generate a report.

Concept map
Feature
Gherkin file describing scenarios, kept in resources.
Steps
Java methods annotated with Given/When/Then implement steps.
Runner
JUnit test runner uses @CucumberOptions to locate features and glue.
Build
Maven or Gradle declares dependencies and runs tests.
Connecting lines are conceptual: feature files map to steps via the glue package configured in the runner.
