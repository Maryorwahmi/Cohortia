TestRunner.java
package com.cohortia.runners;

import io.cucumber.junit.Cucumber;
import io.cucumber.junit.CucumberOptions;
import org.junit.runner.RunWith;

@RunWith(Cucumber.class)
@CucumberOptions(
  features = "src/test/resources/features",
  glue = "com.cohortia.steps",
  plugin = {"pretty", "html:target/cucumber-reports.html"}
)
public class TestRunner {
}
Key settings
  • features: path to Gherkin files. Use test resources paths.
  • glue: package(s) where step definitions live; must match your Java package names.
  • plugin: reporting options like pretty console output and HTML reports.
Common mistake: wrong glue package causes "Undefined steps" even when your step classes exist.
