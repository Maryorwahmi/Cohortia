Feature: Basic Calculator Operations
  As a user of the calculator
  I want to perform basic arithmetic operations
  So that I can get correct results

  Scenario: Adding two positive numbers
    Given I have entered 5 into the calculator
    And I have entered 7 into the calculator
    When I press the add button
    Then the result should be 12 on the screen
Notes and common mistakes
  • Avoid implementation details; describe what the user does and expects.
  • Use placeholders like {int} in step definitions to capture numbers from steps.
  • Keep scenarios small and focused so tests are fast and diagnostic.
Key Takeaway

Write concise, behavior-focused scenarios that are easy to map to step definitions.
