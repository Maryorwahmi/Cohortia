Module 4 › Chapter 4.2 › Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Project layout
Create a convention-based structure with features in resources and test code under src/test/java. This separation makes discovery and packaging predictable for Maven or Gradle.
VERIFIED COMPETENCY MILESTONE
02
Dependencies
Add cucumber-java, cucumber-junit, and junit to your build file so tests compile and run only in test scope. This avoids shipping test libraries with production code.
VERIFIED COMPETENCY MILESTONE
03
Write a feature
Author a Gherkin feature file that describes scenarios in plain language. Clear scenarios serve as living documentation and automated checks.
VERIFIED COMPETENCY MILESTONE
04
Implement steps
Create step definition methods with Given, When, Then annotations. Use placeholders like {int} to capture values and assertions to verify results.
