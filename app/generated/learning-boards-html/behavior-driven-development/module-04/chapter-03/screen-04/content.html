Module 4 › Chapter 4.3 › What is a Step Definition?
Definition

Step definition

A method annotated with @Given, @When, or @Then that matches a Gherkin step and executes test logic. It captures parameters from the step expression.

Common misconception

Method names do not need to mirror step text; the annotation expression controls binding. Don’t embed multiple responsibilities in one step.

Key Takeaway

Step definitions should express behavior intent, accept parameters, and delegate implementation to clean helpers or page objects.

Example
// In UserSteps.java
@Given("a user with email {string}")
public void a_user_with_email(String email) {
  // create or look up user by email
  System.out.println("Creating user with: " + email);
}
Explanation
  • The {string} captures the quoted email and passes it as a String.
  • The annotation controls which Gherkin step will invoke this method.
  • Keep the method focused: creation or lookup, not UI assertions.
