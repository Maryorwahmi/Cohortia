Gherkin Data Table
Given the following users exist:
  | Name  | Email             | Role  |
  | Alice | alice@example.com | Admin |
  | Bob   | bob@example.com   | User  |
Structure the table with headers on the first row to enable asMaps conversion into row maps keyed by header strings.
Java consumption
@Given("the following users exist:")
public void the_following_users_exist(DataTable dataTable) {
  List> expectedUsers = dataTable.asMaps(String.class, String.class);
  System.out.println("Creating users: " + expectedUsers);
}
Use expectedUsers to create or assert user objects. For verification, fetch actual users and compare the lists of maps by equality.
Practical note

Prefer keyed row access so columns can be reordered in the feature without changing step code. Use POJOs only when typed access brings clear benefits.
