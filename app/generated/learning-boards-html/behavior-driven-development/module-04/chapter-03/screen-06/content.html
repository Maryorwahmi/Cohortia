Gherkin example
Scenario: Adding multiple numbers
  Given I have entered the numbers 10, 20, 30
  When I press the add button
  Then the result should be 60 on the screen
Capture the whole list as a string and parse it to a list of integers in your step definition.
Java step (parse)
@Given("I have entered the numbers {string}")
public void i_have_entered_the_numbers_string(String inputNumbersString) {
  numbers = Arrays.stream(inputNumbersString.split(", "))
                  .map(Integer::parseInt)
                  .collect(Collectors.toList());
  System.out.println("Entered numbers: " + numbers);
}
Notes
  • Trim and validate tokens before parsing to avoid NumberFormatException.
  • Keep parsing logic in a helper if reused across steps.
  • Consider registering a custom type only when many steps require the same conversion.
Common mistake
Relying on a specific separator without trimming causes brittle parsers; prefer a robust split and trim approach and assert helpful errors on invalid input.
