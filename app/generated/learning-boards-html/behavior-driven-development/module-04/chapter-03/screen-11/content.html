Module 4 › Chapter 4.3 › Avoiding Over-specific Glue and State Leakage
Over-specific step example
Instead of writing two steps like @When("I click the 'Login' button on the header") and @When("I click the 'Login' button on the footer"), write a single generic step and let a Page Object resolve which element to click based on context.
State leakage
Use @Before and @After hooks to reset lists, clear registrations, or reset the test database. Clearing collections inside Then steps is fragile; use hooks for reliable isolation.
Quick fix checklist
  • Refactor duplicate steps into parameterized steps.
  • Move UI lookup to Page Objects.
  • Reset shared state with hooks, not ad-hoc clears in steps.
  • Keep assertions in Then steps only.
