Module 4 › Chapter 4.3 › Cucumber Expressions vs Regular Expressions
Cucumber Expressions
@When("the user searches for {string} in the {string} category")
public void search_book(String query, String category) {
  // query and category are ready to use
}
  • Readable: tokens show intent.
  • Type conversion: {int} becomes Integer, {string} becomes String.
  • Preferred for maintainability.
Regular Expressions
@When("the user searches for (.+) in the (.+) category")
public void search_book(String query, String category) {
  // regex captures any characters; more control but less readable
}
  • Powerful for specific patterns.
  • Harder to read and maintain at scale.
  • Use only when necessary.
Misconception check

You do not need to prefer regex by default. Start with Cucumber Expressions and move to regex when a scenario requires it.
