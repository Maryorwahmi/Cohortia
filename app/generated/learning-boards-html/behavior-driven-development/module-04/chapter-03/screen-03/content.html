Practical verification steps

Small, testable tasks to prove each objective.

Map & verify

Run a scenario that triggers a step method which prints values. Confirm the binding works and types are converted correctly.

VERIFIED COMPETENCY MILESTONE
Parameterize

Capture lists or quoted strings, parse them into collections, and assert that parsed counts and values match expected ones.

VERIFIED COMPETENCY MILESTONE
Data Tables

Add a feature table, convert it to a list of maps, and assert that expected rows equal actual rows fetched from your application or a simulated list.

VERIFIED COMPETENCY MILESTONE
