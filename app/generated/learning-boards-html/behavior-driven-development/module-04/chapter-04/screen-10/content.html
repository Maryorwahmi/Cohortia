Module 5 › Chapter 4.4 › Cucumber Reports
Built-in plugins
pretty
Readable console output for quick inspection while developing.
html:target/cucumber-reports.html
Human-friendly HTML report saved to target for post-run review.
json:target/cucumber.json
Machine-readable output consumed by dashboard tools like Allure or ExtentReports.
Practical guidance
  • Produce both human and machine outputs for developer and pipeline needs.
  • Store reports as pipeline artifacts so they are available after runs.
  • Use JSON for downstream rich reporting tools and JUnit for CI test summaries.
Misconception
Reports show failures but won’t fix flaky tests by themselves. Use them to guide root-cause fixes.
Key Takeaway

Emit both human and machine reports so teams can triage locally and pipelines can gate releases automatically.
