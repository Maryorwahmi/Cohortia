Learning Objectives

Learn, Understand, Apply, Master

Bloom: Learn → Understand → Apply → Master
01
Project Structure

Place feature files in src/test/resources/features and step classes in src/test/java organized by feature area. This reduces lookup time and keeps steps manageable.

VERIFIED COMPETENCY MILESTONE
02
Hooks & Lifecycle

Use @Before and @After for scenario-level setup and teardown; reserve @BeforeStep/@AfterStep for lightweight tasks like logging or screenshots.

VERIFIED COMPETENCY MILESTONE
03
Tagging for Selective Runs

Label scenarios with tags like @SmokeTest or @Regression and run subsets via your TestRunner's tags option to build suites without changing feature files.

VERIFIED COMPETENCY MILESTONE
04
Reporting & CI

Generate human and machine reports (HTML, JSON, JUnit) and integrate them into CI so failures annotate builds and stop faulty deployments.

VERIFIED COMPETENCY MILESTONE
