Module 5 › Chapter 4.4 › Project Layout
Definition

Organize features, steps, and support code

A modular layout places feature files under resources, step definitions in test Java packages, and support classes in dedicated packages. That separation keeps steps concise and reusable.

Feature folder
src/test/resources/features and subfolders per domain, e.g., features/authentication.
Step packages
src/test/java/com/cohortia/steps. keeps related step classes together.
Support code
com/cohortia/pages, com/cohortia/api, com/cohortia/utils — separate from glue code.
Concrete example
Example mapping
  • features/authentication/login.feature
  • src/test/java/com/cohortia/steps/authentication/LoginSteps.java
  • src/test/java/com/cohortia/pages/LoginPage.java
Common mistake
Putting page interactions directly in step classes — this makes steps large and hard to reuse. Keep step definitions declarative and delegate implementation to support classes.
Key Takeaway

Map features to step packages and keep support code separate so tests are readable and maintainable.
