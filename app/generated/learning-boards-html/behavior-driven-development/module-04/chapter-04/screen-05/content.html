What is support code?

Page Objects, API clients, utilities

Support code encapsulates how interactions happen. Use Page Objects for UI actions, API clients for backend calls, and utilities for reuseable helpers.

Page Objects
Provide methods like login(), clickSubmit(), and getErrorMessage() so steps call intent-focused APIs.
API Clients
Wrap request and response handling so tests use high-level calls instead of raw HTTP.
Utilities
Centralize data builders, waits, and parsing helpers to avoid duplication across steps.
Concrete example
LoginSteps → LoginPage
LoginSteps calls LoginPage.login(username, password). LoginPage finds elements and performs typing and submit. If selectors change, update LoginPage only.
Misconception
Putting interaction details in step definitions makes steps harder to read and maintain. Delegate implementation to support code instead.
Key Takeaway

Keep step definitions declarative; let support code handle implementation details so fixes are centralized.
