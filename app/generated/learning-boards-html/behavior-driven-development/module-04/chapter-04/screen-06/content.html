Lifecycle overview

When hooks run

@Before
Runs once before each scenario. Use it for initializing WebDriver, test data, or common mocks.
@After
Runs after each scenario regardless of outcome. Close resources and clean state here.
@BeforeStep / @AfterStep
Runs for every step. Keep these lightweight — logging or conditional screenshots only.
Best practice
Place all hooks in a Hooks.java or ScenarioHooks.java within your glue package so they are discovered by Cucumber and easy to maintain. Scope with tags when needed to avoid running unnecessary setup for unrelated scenarios.
Common mistake
Putting heavy setup in @BeforeStep/@AfterStep which executes per step and slows the suite dramatically.
Key Takeaway

Use scenario hooks for heavy operations and step hooks for minimal per-step tasks like logging.
