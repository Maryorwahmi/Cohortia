Hands-on Objectives

Write a Hooks class

Create both general and tag-filtered @Before/@After methods so scenarios start and finish consistently.

Tag features and scenarios

Apply @SmokeTest or @Regression to build fast-running or comprehensive suites without editing the runner each time.

Configure TestRunner plugins

Add pretty, html, json, and junit outputs so both humans and tools can consume results.

Inspect reports in CI

Verify that pipeline runs publish HTML or machine-readable output so teams can quickly triage failures.
