Gherkin examples
@SmokeTest @LoginFeature
Feature: User Login

  @Regression
  Scenario: Successful login with valid credentials
    Given I have entered 5 into the calculator
    When I press the add button
    Then the result should be 12 on the screen

  @SmokeTest @NegativeTest
  Scenario: Failed login with invalid credentials
    # ... steps ...
Runner expressions
tags = "@SmokeTest" | tags = "@SmokeTest and @Regression" | tags = "not @NegativeTest"
Why use tags?
  • Create fast smoke suites for quick feedback.
  • Run deep regression suites on schedule or before release.
  • Exclude known-failing or long-running tests from daily runs.
Misunderstanding
Tags filter which scenarios execute; they do not change the scenario logic or ordering by themselves.
Key Takeaway

Tag scenarios to create focused suites and manage test runtime without changing feature content.
