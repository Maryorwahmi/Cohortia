Organizing and Executing BDD Tests

Learn a practical project layout, lifecycle hooks, tagging strategies, and reporting so your suite stays fast and actionable.

Project Health
Structure, hooks, tags
Orientation

This chapter focuses on organization and execution: put feature files under src/test/resources/features, keep step definitions and support code in src/test/java with clear packages, use hooks for lifecycle control, apply tags to build targeted suites, collect machine- and human-friendly reports, and integrate execution into CI so tests validate every change.
