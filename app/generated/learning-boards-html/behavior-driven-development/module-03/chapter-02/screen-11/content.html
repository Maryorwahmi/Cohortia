Structured Data

Passing Complex Data with `Data Tables`

Attaching structured data directly to a step.

What are `Data Tables`?

`Data Tables` are a versatile Gherkin feature that allows you to pass structured data directly to a specific `Given`, `When`, or `Then` step. They are defined using pipe-separated columns.

  • Step-Specific: Attached to a single step, unlike `Examples` for an entire scenario.
  • Structured Data: Ideal for lists of items, key-value pairs, or complex inputs.
  • Readability: Enhances scenario expressiveness and reduces verbosity.
  • Format: Uses `|` to separate columns, with an optional header row.
Key Distinction

`Data Tables` provide data for *one step*, while `Examples` provide data for an *entire Scenario Outline*.

Example: Creating Multiple Users
Feature: User Management

  Scenario: Create multiple users with roles
    Given the following users exist:
      | username | email             | role  |
      | alice    | alice@example.com | admin |
      | bob      | bob@example.com   | user  |
      | charlie  | charlie@example.com | guest |
    When I view the user list
    Then I should see 3 users in the list
Key Takeaway

`Data Tables` allow structured data to be passed directly to a single step, making scenarios more expressive for complex inputs.
