Core Concept

Templating Scenarios with Placeholders

Using variables in `Given`, `When`, and `Then` steps.

What is `Scenario Outline`?

`Scenario Outline` allows you to define a scenario template with placeholders (variables) in its steps. These placeholders are then dynamically replaced with actual values from an `Examples` table during execution.

  • Template Definition: A single scenario structure.
  • Placeholders: Variables enclosed in angle brackets (e.g., `<username>`).
  • Flexibility: Reuses the same logic with different data.
  • Keyword: Starts with `Scenario Outline:`.
Key Benefit

Reduces scenario duplication and makes tests more maintainable by separating scenario logic from test data.

Example: Login `Scenario Outline`
Feature: User Login

  Scenario Outline: Login with various credentials
    Given I am on the login page
    When I enter username "<username>"
    And I enter password "<password>"
    And I click the login button
    Then I should see "<expected_message>"

    Examples: # Data will be provided here
      | username | password | expected_message |
      | ...      | ...      | ...              |
Key Takeaway

`Scenario Outline` uses placeholders (e.g., `<variable>`) to create a reusable scenario template for data-driven testing.
