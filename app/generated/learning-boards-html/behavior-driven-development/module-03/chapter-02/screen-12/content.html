Application

Versatile `Data Tables` in Action

Creating entities, complex inputs, and verifying multiple outcomes.

1. Creating Multiple Entities

Define multiple users, products, or other entities as a precondition for your scenario in a single `Given` step.

Given the following users exist:
  | username | role  |
  | alice    | admin |
  | bob      | user  |

2. Inputting Complex Data

Pass detailed form submissions or order items to a `When` step, keeping the scenario concise and readable.

When I submit the order:
  | item   | qty | price |
  | Laptop | 1   | 1200  |
  | Mouse  | 2   | 25    |

3. Verifying Multiple Outcomes

Assert that a report or display contains specific metrics and their corresponding values in a `Then` step.

Then the report should contain:
  | metric      | value |
  | total_sales | 1500  |
  | avg_order   | 750   |
Key Takeaway

`Data Tables` are highly versatile, enabling clear and concise representation of structured data for various purposes within scenario steps.
