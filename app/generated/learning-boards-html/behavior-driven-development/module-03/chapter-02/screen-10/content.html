Supplying Data via the `Examples` Table

Executing a `Scenario Outline` with multiple data sets.

The `Examples` Keyword

The `Examples` table is used in conjunction with `Scenario Outline` to provide the concrete data for its placeholders. Each row in the table represents a distinct execution of the scenario.

  • Header Row: Defines column names, matching `Scenario Outline` placeholders.
  • Data Rows: Each row provides a set of values for one test run.
  • Automated Execution: Gherkin runs the `Scenario Outline` once for each `Examples` row.
  • Keyword: Starts with `Examples:`.
Practical Tip

Ensure placeholder names in `Scenario Outline` exactly match column headers in `Examples` for correct data mapping.

Example: `Scenario Outline` with `Examples`
Feature: User Login

  Scenario Outline: Login with various credentials
    Given I am on the login page
    When I enter username "<username>"
    And I enter password "<password>"
    And I click the login button
    Then I should see "<expected_message>"

  Examples:
    | username     | password     | expected_message   |
    | valid_user   | correct_pass | Welcome to Dashboard |
    | valid_user   | wrong_pass   | Invalid credentials  |
    | unknown_user | any_pass     | Invalid credentials  |
    | locked_user  | correct_pass | Account locked       |
Key Takeaway

The `Examples` table provides the data for `Scenario Outline` placeholders, enabling multiple test runs from a single template.
