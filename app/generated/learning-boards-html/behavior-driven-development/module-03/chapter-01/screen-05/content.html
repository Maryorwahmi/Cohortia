Defining a Feature

The Feature keyword introduces a single, distinct piece of functionality or a user story.

High-Level Capability: Describes a major function from a user's perspective (e.g., 'User Authentication').

Optional Narrative: Provides context using 'As a [role], I want [capability] so that [benefit]' structure.

Business Value: Clarifies the 'why' behind the feature, aligning the team's understanding.

Key Takeaway

The Feature keyword sets the scope for a Gherkin file, ensuring all scenarios contribute to a single, valuable capability.

Example: Feature Definition

Feature: User Authentication
  As a registered user,
  I want to log in
  So that I can access my account.

This example clearly states the feature's purpose and its benefit to the user, providing essential context for the scenarios that will follow.
