Understanding `Then`

Then steps describe the observable outcome or result that should occur after the When action.

Observable Outcome: Verifies the system's state or response (e.g., 'my cart should contain "Laptop"').

Assertions: Confirms that the system behaved as expected according to the business rules.

Direct Consequence: All Then steps must be a direct result of the single When action.

Key Takeaway

Then steps provide clear, verifiable criteria for success, ensuring the system meets specified behavior.

Common Pitfall

Including actions or setup within Then steps, which should only focus on verifying outcomes.

Example: `Then` Steps

Then the user should be redirected to the dashboard
And a welcome message "Welcome, testuser!" should be displayed
Then an error message "Invalid username or password." should be displayed

These examples verify the expected results after a user action, confirming system behavior.
