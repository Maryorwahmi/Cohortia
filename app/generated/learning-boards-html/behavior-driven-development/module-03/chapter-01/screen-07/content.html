Understanding `Given`

Given steps establish the initial state or context (preconditions) of the system before any action occurs.

Initial State: Describes what is already true or exists (e.g., 'I am logged in').

Preconditions: Sets up the necessary environment for the scenario to proceed.

Focus on 'What Is': Should describe a state, not an action that changes state.

Key Takeaway

Effective Given steps ensure scenarios start from a clear, consistent, and repeatable baseline state.

Example: `Given` Steps

Given the user is on the login page
And a user "testuser" exists with password "password123"
Given the shopping cart is empty

These examples clearly define the starting conditions for a scenario, without performing any actions.
