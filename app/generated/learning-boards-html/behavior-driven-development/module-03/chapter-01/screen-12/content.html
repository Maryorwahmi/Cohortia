`Given` is for State, Not Action

Given steps should establish a precondition or initial state, not perform an action that changes the system's state.

Incorrect Usage: Treating Given as a setup action (e.g., 'Given I log in').

Correct Usage: Describing an existing state (e.g., 'Given I am logged in').

Confusion: Blurs the line between setup and the actual behavior being tested.

Key Takeaway

Always ensure Given steps describe a static precondition, reserving dynamic actions for When steps.

Good vs. Bad `Given` Steps

Avoid
Given I click the 'Sign Up' button
Given I submit the form

These are actions, not states.

Prefer
Given the user is on the sign-up page
Given the form is pre-filled with valid data

These describe existing states.

Correctly using Given for state ensures clarity and proper separation of concerns in your scenarios.
