Filtering and Execution Control

How tags streamline your BDD workflow.

Selective Test Runs

Run only specific subsets of tests (e.g., @smoke tests) for quick feedback or targeted validation.

Status & Ownership

Indicate scenario status (@pending, @wip) or assign ownership (@team-a) for better project management.

Key Takeaway

Tags provide powerful control over test execution, enabling teams to run targeted test suites and manage scenario statuses efficiently.

Command-Line Filtering Example

BDD frameworks use command-line options to filter scenarios based on tags. Here's a common pattern:

# Run scenarios tagged @smoke AND @critical
cucumber --tags "@smoke and @critical"

# Run scenarios tagged @web OR @mobile
behave --tags=@web,@mobile

# Exclude scenarios tagged @wip
specflow run --tags "~@wip"

Real-world connection: In a CI/CD pipeline, you might configure a nightly build to run all @regression tests, while a pre-merge check only runs @smoke tests.
