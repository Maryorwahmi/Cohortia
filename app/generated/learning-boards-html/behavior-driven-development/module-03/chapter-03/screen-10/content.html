Multi-line Text with Doc Strings

Passing rich textual arguments to steps.

What are Doc Strings?

Doc Strings are multi-line text blocks enclosed by three double-quotes (""") on separate lines. They allow you to pass a single, large block of unstructured text as an argument to a step definition.

Key Takeaway

Doc Strings provide a clean and readable way to handle complex, multi-line textual inputs or outputs within your Gherkin scenarios.

Doc String Syntax

When I send an email with the following body:
  """
  Dear Customer,

  Your order #12345 has been shipped.
  You can track it here: example.com/track/12345

  Sincerely,
  The Team
  """

How it works: The entire text block between the triple quotes is passed as a single string argument to the step definition, preserving line breaks and formatting.
