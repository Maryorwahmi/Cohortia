The Given-When-Then Pattern

This fundamental structure describes a single scenario of behavior by outlining its context, action, and expected outcome.

GIVEN

Sets the initial context or pre-conditions.

What state is the system in before the action occurs? What data is available?

WHEN

Describes the specific action or event.

What triggers the behavior being tested? Typically a user interaction or system event.

THEN

Defines the expected outcome or result.

What should the system look like or do after the 'When' action has occurred?

Key Takeaway

The Given-When-Then structure provides a clear, narrative flow for scenarios, making them easy to understand, implement, and verify for all team members.
