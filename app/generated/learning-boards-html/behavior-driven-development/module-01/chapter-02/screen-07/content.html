Describing Features and Extending Steps

The Feature block provides context, while And/But keywords enhance scenario readability.

Feature Block

High-level description and motivation (As a... I want... So that...) for a set of related scenarios.

And / But Keywords

Used to add more conditions or outcomes to Given, When, or Then steps, improving natural language flow.

Key Takeaway

Using Feature blocks and 'And'/'But' steps creates more coherent, readable, and business-aligned Gherkin scenarios, enhancing overall communication.

Feature: User Authentication
  As a registered user,
  I want to be able to log in securely,
  So that I can access my personalized content.

  Scenario: Successful login with valid credentials
    Given I am on the login page
    And I have a registered account with username "testuser" and password "password123"
    When I log in with username "testuser" and password "password123"
    Then I should be redirected to the dashboard
    And I should see a welcome message
    But I should not see any error messages
