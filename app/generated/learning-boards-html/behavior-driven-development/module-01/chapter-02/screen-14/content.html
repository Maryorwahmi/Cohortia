Key Concepts

Review the essential terms and ideas from this chapter.

Gherkin

A plain-text, human-readable language used to describe software behavior in a structured format, serving as executable specifications.

Given-When-Then

The core structure of a Gherkin scenario, describing the context (Given), the action (When), and the expected outcome (Then).

Feature File

A .feature file containing one or more Gherkin scenarios related to a specific feature of the software.

Summary

Gherkin provides a structured, human-readable way to define software behavior, using the Given-When-Then pattern within Feature Files to ensure clarity and testability.
