Data-Driven Scenarios: Discount Example

See how Scenario Outline uses Examples tables to test various data combinations efficiently.

Placeholders

Variables (e.g., <membership_level>) in the scenario outline are replaced by data from the table.

Multiple Test Cases

Each row in the Examples table generates a separate, distinct scenario execution.

Key Takeaway

Scenario Outline with Examples is crucial for efficient, comprehensive data-driven testing, eliminating redundant scenario definitions.

  Scenario Outline: Customer receives correct discount based on membership level
    Given I am a <membership_level> customer
    And I have <item_count> items in my cart
    When I apply a discount code
    Then my total price should be <expected_total>

    Examples:
      | membership_level | item_count | expected_total |
      | Gold             | 2          | $90            |
      | Silver           | 3          | $140           |
      | Bronze           | 1          | $50            |
