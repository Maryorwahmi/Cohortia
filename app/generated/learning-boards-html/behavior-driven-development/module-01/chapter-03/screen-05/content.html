The Discover Phase: Shared Understanding
Collaboratively exploring features with the 'three amigos'
Core Goal

Achieve a deep, shared understanding of desired feature behavior, business rules, and edge cases.

The 'Three Amigos'
  • Product Owner: Defines 'what' is needed.
  • Developer: Understands 'how' it can be built.
  • QA Engineer: Explores 'what could go wrong'.
Technique: Example Mapping

Identify a user story, brainstorm concrete examples of its behavior, and classify them into rules to clarify the feature.

Common Pitfall

Rushing or skipping discovery leads to assumptions, misunderstandings, and costly rework later in the development cycle.

Example: User Login Feature
1

Successful Login: Valid credentials, user gains access.

2

Failed Login: Incorrect password, error message displayed.

3

Account Locked: Multiple failed attempts, temporary lockout.

Facilitator Note

A skilled facilitator is essential to guide discussions and ensure all perspectives are heard and understood.
