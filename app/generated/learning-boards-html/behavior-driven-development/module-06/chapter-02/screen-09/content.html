Module 6 › Chapter 6.2 › Testing — Acceptance vs Exploratory
Automated acceptance
Scenarios verify business-critical behaviors continuously and act as regression tests during refactoring.
  • Covers core user journeys and rules.
  • Provides quick feedback when changes break behavior.
  • Serves as living documentation.
Exploratory testing
Focused on usability, edge cases, performance and unexpected interaction patterns that scenarios may miss.
Practical balance
Automate behaviors that represent business risk. Use exploratory tests to uncover issues that scripted scenarios don’t reveal. When exploratory testing finds a bug, convert it to a scenario to prevent regression.
Key Takeaway

BDD automation secures core behavior so QA can focus on finding new kinds of problems.

Common misconception

Automation replaces exploratory testing. It should enable deeper exploration instead.
