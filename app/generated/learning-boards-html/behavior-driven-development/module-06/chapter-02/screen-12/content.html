POST /api/products — Add product
Request:
POST /api/products
{
  "name": "Laptop Pro",
  "description": "Powerful laptop",
  "price": 1200.00,
  "stock": 50
}

Response:
201 Created
{
  "id": "P124",
  "name": "Laptop Pro",
  "price": 1200.00
}
Include authorization notes: requires administrator token. Validate required fields and return 400 with a clear error body when validation fails.
GET /api/products/{id}
Return 200 and product details when the id exists; return 404 when not found.
Pro tip

Attach example request and response bodies to the scenario so frontend can mock responses immediately.
