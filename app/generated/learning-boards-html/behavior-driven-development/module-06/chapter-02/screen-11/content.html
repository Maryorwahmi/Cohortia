Feature: Product Management
Scenario: Add a new product successfully
  Given I am an authenticated administrator
  When I send a POST request to "/api/products" with body:
    {
      "name": "Laptop Pro",
      "description": "Powerful laptop for professionals",
      "price": 1200.00,
      "stock": 50
    }
  Then the response status code should be 201 Created
  And the response body should contain the product details including an "id"
Use this template to extract the API design elements and record them as acceptance criteria for implementation and tests.

Example answer (Add Product)
Method: POST
Path: /api/products
Request Body: name, description, price, stock (JSON)
Expected Response: 201 Created with product object including id
