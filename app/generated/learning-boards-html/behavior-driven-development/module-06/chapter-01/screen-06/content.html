Starter Workflow
name: BDD CI Pipeline on: push: branches: - main pull_request: branches: - main jobs: build_and_test: runs-on: ubuntu-latest steps: - name: Checkout code uses: actions/checkout@v3 - name: Set up JDK 17 uses: actions/setup-java@v3 with: java-version: '17' distribution: 'temurin' cache: 'maven' - name: Run Maven BDD Tests run: mvn clean install -DskipTests=false - name: Upload Cucumber Reports (Optional) uses: actions/upload-artifact@v3 if: always() # Upload even if tests fail with: name: cucumber-reports path: target/cucumber-reports
Concrete Tip
Use if: always() on the upload step so artifacts are preserved for failed builds and can be inspected by the team.
Common Mistake
Running an incomplete lifecycle phase that doesn't generate reports. Confirm whether you should run mvn test or mvn verify depending on where reporting is bound.
Key Takeaway
Publish report artifacts in every run so failures can be diagnosed without rerunning the pipeline immediately.
