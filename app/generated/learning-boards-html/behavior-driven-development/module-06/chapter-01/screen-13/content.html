Module 6 › Chapter 6.1 › Interpreting Failures
Triage Checklist
  • Download the HTML report and inspect the failing scenario and step trace.
  • Read CI logs to identify setup errors or missing artifacts.
  • Attempt to reproduce the failure locally using the same test command.
  • Decide whether to fix the test, the code, or the environment.
Concrete Example
A Given step that prepares a DB record fails consistently. Reproduce locally with a fresh DB; if it passes locally, investigate CI environment setup or test data seeding.
Key Takeaway
Use reports plus CI logs to isolate the cause. Prefer making tests deterministic instead of temporarily silencing failures.
