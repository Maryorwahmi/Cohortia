Report Generation
Runners emit JSON or XML. Reporting plugins turn those artifacts into readable HTML that shows features, scenarios, step status, and failure details.
plugin: maven-cucumber-reporting outputDirectory: target/cucumber-reports cucumberOutput: target/json-reports
Concrete Example
Bind report generation to the verify phase and upload the produced directory as a CI artifact so it is available even on failure.
Common Mistake
Not uploading reports when tests fail. Use conditional upload steps that run always to preserve diagnostics.
Key Takeaway

Publish human-friendly reports as artifacts every run to enable quick triage and maintain living documentation of behavior status.
