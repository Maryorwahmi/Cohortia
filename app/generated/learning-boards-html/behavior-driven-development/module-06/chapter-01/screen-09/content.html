Module 6 › Chapter 6.1 › Fast Feedback
Compare Suites
Smoke
Purpose
Fast, critical-path checks on every commit.
Full
Purpose
Comprehensive behavior coverage, run nightly or on PRs.
Split
When to use
Run smoke on commit, full on schedule or PR to balance speed and depth.
Concrete Example
Choose core happy paths like login, checkout, and payment authorization as your smoke suite so failing these surfaces immediate risk.
Common Mistake
Putting too many scenarios in smoke increases latency. Instead, evaluate which scenarios detect the most critical regressions quickly.
Key Takeaway

Define a minimal smoke suite to guard core behavior and schedule full suites so the pipeline stays fast and trustworthy.
