Surefire and Reporting

Use the Surefire plugin to execute the runner, and add a reporting plugin to convert JSON output into HTML artifacts that CI can publish.

<plugin> <groupId>org.apache.maven.plugins</groupId> <artifactId>maven-surefire-plugin</artifactId> <version>3.0.0-M5</version> <configuration> <testFailureIgnore>false</testFailureIgnore> <includes> <include>**/*Runner.java</include> </includes> </configuration> </plugin>
Concrete Example
Run mvn clean install locally to make sure the Surefire plugin finds and runs your Cucumber runner. If test reports are missing, verify the runner class name pattern and that feature files are on the test classpath.
Common Mistake
Leaving testFailureIgnore true or misconfiguring includes causes CI to report green builds despite failing scenarios or to skip scenarios entirely.
Key Takeaway
Explicitly configure your test plugin and validate locally before CI runs the job to avoid surprises in pipeline runs.
