Module 6 › Chapter 6.1 › Test Runners
What runners do
Locate features and step definitions, execute scenarios, and emit structured results for CI to consume.
Produce both machine-readable artifacts and optional human-friendly HTML reports so developers and product owners can inspect behavior status across commits.
Practical example
Cucumber emits a JSON summary of scenarios; a reporting plugin transforms that JSON into HTML that teams can view and store as pipeline artifacts.
Common Mistake
Relying only on console logs. Structured artifacts are required to visualize scenario outcomes and attach failure artifacts for triage.
Key Takeaway

Configure your runner to output JSON or XML and ensure reporting is generated in a predictable location for CI to publish.
