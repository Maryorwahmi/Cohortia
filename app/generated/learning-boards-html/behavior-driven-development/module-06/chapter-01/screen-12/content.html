Module 6 › Chapter 6.1 › Hands-On Activity
Activity Steps
  1. Create or update pom.xml to run your Cucumber runner and reporting plugin.
  2. Add src/test/java/.../Runner.java to link feature files and steps.
  3. Create .github/workflows/ci.yml with checkout, setup-java, and mvn clean install.
  4. Add an upload-artifact step with if: always() to save reports.
  5. Introduce a failing scenario and observe the pipeline fail and artifacts uploaded.
Starter Check
# Run locally to verify mvn verify # In CI run: mvn clean install -DskipTests=false
If reports are not found, confirm output directories and that report generation is bound to the lifecycle phase you run in CI.
