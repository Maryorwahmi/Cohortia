Key Concepts

What to remember from this chapter

Flaky Tests

Automated tests that sometimes pass and sometimes fail without any changes to the underlying code or environment.

Defect Escape Rate

A quality metric indicating how many defects are found in production that were not detected earlier in the development process.

Lead Time/Cycle Time

Metrics measuring the total time from the start of a work item (e.g., feature idea) to its completion and delivery.

Chapter Summary

Measuring BDD success involves tracking quantitative metrics like defect escape rate and lead time, while actively addressing issues like flaky tests to ensure a reliable and efficient development process.
