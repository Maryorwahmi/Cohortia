Module 06 › Chapter 6.3 › Review cadence & safety
Simple review checklist
  1. Update feature files in the same branch as the code change.
  2. Run affected scenarios locally before pushing.
  3. Have the Three Amigos review scenario language and behavior.
  4. Run CI smoke tests on commit; run full regression on schedule.
Ownership

Share responsibility for step definitions and feature maintenance across the team to avoid single-point failure and to encourage consistent language.
