Module 06 › Chapter 6.3 › Deterministic setup
Why deterministic setup?

Using API or DB setup reduces runtime and makes tests deterministic. It separates the intent of the scenario from the mechanics of creating test data.

Example step
Given a user with email "existing@example.com" already exists
Implementation: call test API or insert a row in test database before running the UI steps.
Pro tip

Mark heavy data setup scenarios with @slow and keep smoke tests lightweight to maintain CI speed.

Key Takeaway

Hide technical setup behind business language so scenarios stay readable and fast.
