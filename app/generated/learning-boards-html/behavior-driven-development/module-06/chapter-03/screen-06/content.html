Module 06 › Chapter 6.3 › Refactor scenarios
Step-by-step refactor
  1. Run scenarios and record failures to reproduce current behavior.
  2. Identify repeated steps and extract a Given helper.
  3. Convert repeated data variations into a Scenario Outline with Examples.
  4. Split scenarios that test multiple outcomes into focused examples.
  5. Run tests and review for behaviour-preserving changes.
