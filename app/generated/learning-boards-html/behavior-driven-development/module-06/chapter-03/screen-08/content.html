Module 06 › Chapter 6.3 › Layer your automation
Suggested layers
Step definitions: express intent and call business actions.
Business actions: domain methods combining flows, reusable by steps.
Technical layer: Page Objects, API clients, or DB helpers that perform low-level actions.
Example call chain
Step: register user → Business action: registrationService.register(email,password) → Page Object: registrationPage.fillForm(...); registrationPage.submit()
Key Takeaway

Layering isolates UI changes and keeps scenarios stable and readable.
