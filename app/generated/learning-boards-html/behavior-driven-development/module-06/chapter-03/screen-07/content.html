Module 06 › Chapter 6.3 › Anti-patterns in steps
Before vs After
Before

Repeated driver calls in many step methods; UI locators in step definitions.

After

Page Objects encapsulate locators; steps call high-level methods like registerWith(email,password).

Refactor actions
  • Extract repeated code to helpers.
  • Create Page Objects for UI.
  • Introduce Context/World for shared services.
Pro tip

Keep step methods short and descriptive; the implementation details belong in the automation layer.
