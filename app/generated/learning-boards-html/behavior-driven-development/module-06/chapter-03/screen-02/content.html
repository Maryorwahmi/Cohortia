Learning Objectives
Learn → Understand → Apply → Master
01
Detect scenario rot and anti-patterns

You will be able to recognize outdated or brittle scenarios and common smells that reduce value. This matters because untrustworthy tests block development progress.

Mnemonic: red flag list
VERIFIED COMPETENCY MILESTONE
02
Refactor scenarios for clarity

You will practice extracting helpers, using Scenario Outlines, and splitting long scenarios to express single behaviors that stakeholders can validate.

Mnemonic: one behavior per scenario
VERIFIED COMPETENCY MILESTONE
03
Refactor step definitions

You will convert duplicated, tightly-coupled steps into layered automation with helper methods, Page Objects, and DI-friendly contexts for reuse and testability.

Mnemonic: keep steps high-level
VERIFIED COMPETENCY MILESTONE
04
Organize and tag large suites

You will apply foldering patterns and tagging like @smoke, @regression, and @wip so CI runs the right tests at the right time.

Mnemonic: tag for purpose
VERIFIED COMPETENCY MILESTONE
