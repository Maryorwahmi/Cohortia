Folder and tag patterns
  • Organize by domain: features/authentication, features/checkout, features/profile
  • Use tags for CI: @smoke for commits, @regression nightly, @wip exclude until stable
  • Document tag meanings in README so usage is consistent
Quick commands
Run smoke suite: mvn test -Dcucumber.options="--tags @smoke"
