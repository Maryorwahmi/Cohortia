Managing Objects: Listing and Class Rewrites

Exploring bucket contents and modifying object properties.

1. List Objects (`gsutil ls`)

The `ls` command lists the contents of a bucket or a specific path within it.

gsutil ls gs://my-unique-bucket-name-12345/
  • Displays objects and subdirectories.
  • Useful for verifying uploads and exploring bucket structure.

2. Rewrite Storage Class (`gsutil rewrite`)

The `rewrite` command changes an object's storage class after upload.

gsutil rewrite -s NEARLINE gs://my-unique-bucket-name-12345/data/my_remote_file.txt
  • `-s`: Specifies the new storage class (e.g., NEARLINE, COLDLINE).
  • Manual alternative to Object Lifecycle Management for one-off changes.
Key Takeaway

`gsutil ls` helps you inspect your storage, while `gsutil rewrite` allows for manual adjustments to an object's storage class.
