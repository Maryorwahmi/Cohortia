`gsutil` in Action: Bucket Creation and File Upload

Essential commands for managing Cloud Storage resources.

1. Create a Bucket (`gsutil mb`)

The `mb` command is used to 'make bucket'. You specify project, storage class, and location.

# Create a bucket in the US-EAST1 region with Standard storage classgsutil mb -p your-gcp-project-id -c STANDARD -l us-east1 gs://my-unique-bucket-name-12345
  • `-p`: Your Google Cloud project ID.
  • `-c`: Default storage class (e.g., STANDARD, NEARLINE).
  • `-l`: Location (e.g., us-east1, europe-west1).

2. Upload a File (`gsutil cp`)

The `cp` command copies local files to your Cloud Storage bucket.

# Upload a local file to your bucketgsutil cp ./my_local_file.txt gs://my-unique-bucket-name-12345/data/my_remote_file.txt
  • `./my_local_file.txt`: Path to your local file.
  • `gs://...`: Destination path in your Cloud Storage bucket.
Key Takeaway

`gsutil mb` and `gsutil cp` are fundamental for initializing buckets and populating them with data from your local environment.

`gsutil` Command Structure

`gsutil`

The main command-line utility.

`command` (e.g., `mb`, `cp`, `ls`)

The action you want to perform.

`options` (e.g., `-p`, `-c`, `-l`)

Flags to modify command behavior.

`arguments` (e.g., `gs://bucket-name`)

The resources the command acts upon.
