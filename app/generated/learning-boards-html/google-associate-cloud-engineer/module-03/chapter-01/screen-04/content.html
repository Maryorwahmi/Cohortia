Objects and Buckets: The Building Blocks

Understanding the fundamental units of Cloud Storage.

What is an Object?

An object is a piece of data (e.g., image, video, document) along with its associated metadata. It's the fundamental unit of storage in Cloud Storage.

What is a Bucket?

A bucket is a fundamental container that holds objects. It acts like a top-level directory but exists in a globally unique namespace across all of Google Cloud.

Key Takeaway

Objects are your data + metadata; buckets are their globally unique containers. This structure ensures scalability and unique addressing.
