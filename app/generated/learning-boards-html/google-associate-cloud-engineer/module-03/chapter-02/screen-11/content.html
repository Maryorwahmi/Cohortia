Managing Disks with gcloud Commands

Practical examples for creating, attaching, detaching, and resizing Persistent Disks.

Create a Disk

Provision a new 50GB Balanced Persistent Disk.

gcloud compute disks create my-data-disk \
  --size=50GB \
  --type=pd-balanced \
  --zone=us-central1-a

Attach to Instance

Connect the disk to an existing Compute Engine VM.

gcloud compute instances attach-disk my-instance \
  --disk=my-data-disk \
  --device-name=my-data-disk-attachment \
  --zone=us-central1-a

Format & Mount (within VM)

Make the attached disk usable by the operating system.

sudo mkfs.ext4 -F /dev/sdb
sudo mkdir /mnt/data
sudo mount /dev/sdb /mnt/data

Detach from Instance

Disconnect the disk from the Compute Engine VM.

gcloud compute instances detach-disk my-instance \
  --disk=my-data-disk \
  --zone=us-central1-a

Resize a Disk

Increase the disk size from 50GB to 100GB.

gcloud compute disks resize my-data-disk \
  --size=100GB \
  --zone=us-central1-a
Pro Tip

Always verify the device name (e.g., /dev/sdb) within the VM before formatting to avoid data loss on the wrong disk.

Key Takeaway

The gcloud CLI is your primary tool for programmatic Persistent Disk management, enabling automation and precise control over your storage resources.
