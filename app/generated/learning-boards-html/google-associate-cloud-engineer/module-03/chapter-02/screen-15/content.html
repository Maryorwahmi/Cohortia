Key Concepts

Essential terms to remember from this chapter.

Persistent Disk

Google Cloud's block storage service for Compute Engine instances, behaving like a traditional hard drive.

Block Storage

A storage architecture where data is stored in fixed-size blocks, allowing for file system creation and direct OS access.

Standard Persistent Disk

Cost-effective HDD-based storage for sequential I/O and large data processing.

Balanced Persistent Disk

A balance of performance and cost, suitable for general-purpose workloads.

Summary Takeaway

Persistent Disk is foundational block storage for VMs, with types like Standard and Balanced offering different performance-cost trade-offs.
