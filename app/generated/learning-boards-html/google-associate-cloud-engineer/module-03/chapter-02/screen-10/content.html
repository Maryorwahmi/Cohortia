Disk Management

Core Operations: Create, Attach, Detach, Resize

Essential steps for managing Persistent Disks throughout their lifecycle.

Create Disk

Provision a new Persistent Disk with specified size, type, and zone. It exists independently until attached.

Attach/Detach Disk

Connect a disk to a VM instance or disconnect it. Useful for data migration or troubleshooting.

Resize Disk

Increase disk size, often without downtime. Decreasing size requires data migration to a new disk.

Format & Mount (within VM)

After attachment, new disks must be formatted with a file system and mounted to be usable by the OS.

Key Takeaway

Proficiency in disk creation, attachment, detachment, and resizing is essential for dynamic and responsive cloud infrastructure management.
