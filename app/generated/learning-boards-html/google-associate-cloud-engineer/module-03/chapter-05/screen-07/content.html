Rule Breakdown

Understanding the Conditions

  • 1

    Action: SetStorageClass to ARCHIVE
    Specifies the target storage class for objects matching the conditions.

  • 2

    Condition: age: 365
    The rule triggers when an object reaches 365 days old.

  • 3

    Condition: isLive: true
    Ensures only live (non-deleted, non-superseded) objects are affected.

  • 4

    Condition: matchesStorageClass
    Applies the rule only to objects currently in Standard, Nearline, or Coldline.

Key Takeaway

A well-defined OLM rule automates the transition of aging data to Archive, ensuring cost optimization and adherence to retention policies.
