Storage Transfer Service: Common Scenarios

On-Premises to Cloud

Transfer data from local file systems or NAS to Cloud Storage. Consider Transfer Appliance for very large datasets.

Other Clouds to GCS

Move data from Amazon S3 or Azure Blob Storage to Google Cloud Storage seamlessly.

Between GCS Buckets

Facilitate data movement between regions, projects, or for applying new storage classes.

Scheduled Transfers

Set up one-time or recurring jobs for continuous data ingestion and synchronization.

Key Takeaway

STS provides robust solutions for nearly any large-scale data movement requirement, from initial migration to ongoing synchronization.
