Module 3›Chapter 3.5›STS Command
gcloud transfer jobs create
# Example: Transfer from S3 to Cloud Storagegcloud transfer jobs create s3://my-source-s3-bucket gs://my-destination-gcs-bucket  --project=your-gcp-project-id  --description="S3 to GCS Migration"  --schedule-starts-at="2024-01-01T00:00:00Z"  --status=ENABLED  --overwrite-when=DIFFERENT
Command Breakdown

Key Parameters Explained

  • 1

    Source & Destination URIs: Specify `s3://` for Amazon S3 and `gs://` for Cloud Storage.

  • 2

    --project: Your Google Cloud project ID where the transfer job will run.

  • 3

    --description: A human-readable name for your transfer job.

  • 4

    --schedule-starts-at: Defines the start time for the transfer job.

  • 5

    --overwrite-when: Specifies conditions for overwriting existing destination objects.

Key Takeaway

The `gcloud transfer jobs create` command provides a flexible and powerful way to configure and automate data transfers between various sources and Cloud Storage.
