Definition

Transfer Appliance

A physical device provided by Google for offline data transfer of petabyte-scale datasets to Cloud Storage, bypassing network bandwidth limitations.

Physical Device

Offline Transfer

Key Takeaway

For petabyte-scale data or slow networks, Transfer Appliance is the most efficient solution, bypassing internet bandwidth limitations.

When to Use

STS vs. Transfer Appliance

Storage Transfer Service

  • •Gigabytes to Terabytes
  • •Good network connection
  • •Recurring transfers

Transfer Appliance

  • •Petabytes of data
  • •Slow or no network
  • •One-time bulk migration

Example Scenario

A company with 50TB of archival data and a 100 Mbps internet connection should use Transfer Appliance to avoid months of network transfer time.
