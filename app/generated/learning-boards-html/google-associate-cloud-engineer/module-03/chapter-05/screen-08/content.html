Definition

Storage Transfer Service (STS)

A fully managed Google Cloud service that simplifies the migration of large volumes of data into and out of Cloud Storage from various sources.

Fully Managed

Scalable & Reliable

Key Takeaway

STS streamlines large data migrations, handling complexity and ensuring data integrity across diverse storage environments.

Core Capabilities

What STS Handles

  • Network Retries: Automatically handles transient network issues.

  • Data Integrity Checks: Verifies data consistency during transfer.

  • Parallel Transfers: Optimizes speed by transferring multiple objects concurrently.

  • Scheduled Jobs: Set up one-time or recurring transfers for continuous ingestion.
