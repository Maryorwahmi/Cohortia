Cloud Firestore

Document-Oriented Data Model

Organizing data with collections, documents, and subcollections.

Collections

Containers for documents, like a folder for files. They don't contain data directly.

Documents

JSON-like objects with key-value pairs. The actual units of data storage.

Subcollections

Collections nested within documents, enabling hierarchical data structures.

Key Takeaway

Firestore's hierarchical model simplifies complex data relationships without traditional joins, enhancing flexibility.
