Memorystore Management

Creating a Memorystore Redis Instance

Provisioning an in-memory cache with `gcloud`.

Terminal Command: Create Redis Instance
gcloud redis instances create my-redis-cache \
  --project=your-gcp-project-id \
  --region=us-central1 \
  --zone=us-central1-a \
  --tier=STANDARD_HA \
  --size=1 \
  --connect-mode=DIRECT_PEERING \
  --network=default
Command Breakdown

--tier: Defines availability (STANDARD_HA for high-availability). --size: Memory capacity in GB. --connect-mode & --network: Configure VPC connectivity.

Key Takeaway

Properly configuring tier, size, and network for your Redis instance ensures optimal performance and availability.
