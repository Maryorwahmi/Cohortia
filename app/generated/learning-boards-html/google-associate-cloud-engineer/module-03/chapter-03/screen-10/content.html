User, Database, and Connection Management

Essential post-provisioning steps

Key Management Tasks

  • Create secure database users with strong passwords.
  • Provision new databases for different applications or services.
  • Retrieve connection details for secure application access via proxy.
Key Takeaway

Managing Cloud SQL users and databases via `gcloud` ensures secure access and proper data organization, while retrieving the connection name is essential for proxy-based application connectivity.

# Create a database user (e.g., for your application)
gcloud sql users create myappuser \
  --host=% \
  --instance=my-pg-instance \
  --password=YOUR_STRONG_PASSWORD \
  --project=your-gcp-project-id

# Create a database
gcloud sql databases create myappdb \
  --instance=my-pg-instance \
  --project=your-gcp-project-id

# Get connection name for Cloud SQL Proxy
gcloud sql instances describe my-pg-instance \
  --format="value(connectionName)" \
  --project=your-gcp-project-id
# Output will be like: your-gcp-project-id:us-central1:my-pg-instance
