Creating a Cloud SQL Instance via gcloud

Automating instance provisioning

Key Command Flags

  • `--database-version`: Specifies the database engine and version.
  • `--region`: Sets the geographical location for the instance.
  • `--cpu`, `--memory`: Defines the machine type and resources.
  • `--failover-replica-name`: Enables High Availability.
  • `--backup-start-time`: Configures automated daily backups.
Key Takeaway

The `gcloud sql instances create` command allows programmatic provisioning of Cloud SQL instances, enabling automation and consistent configuration of critical features like HA and backups.

# Create a PostgreSQL Cloud SQL instance with high availability
gcloud sql instances create my-pg-instance \
  --database-version=POSTGRES_14 \
  --region=us-central1 \
  --cpu=2 \
  --memory=8GB \
  --storage-type=SSD \
  --storage-size=50GB \
  --database-flags=cloudsql.iam_authentication=On \
  --enable-bin-log \
  --backup-start-time=03:00 \
  --failover-replica-name=my-pg-instance-failover \
  --project=your-gcp-project-id
