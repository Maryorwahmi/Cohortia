Creating a Preemptible VM

Using the gcloud CLI to deploy a cost-effective instance

Command Breakdown

  • `gcloud compute instances create`: The base command for creating VMs.
  • `--preemptible`: The crucial flag to designate the VM as preemptible.
  • `--machine-type`, `--zone`, `--image-family`: Standard VM configuration options.
Key Takeaway

The `--preemptible` flag is the key to creating cost-saving, interruptible Compute Engine instances.

Example: Creating a Preemptible VM

gcloud compute instances create my-preemptible-vm \
    --machine-type=e2-medium \
    --preemptible \
    --zone=us-central1-a \
    --image-family=debian-11 \
    --image-project=debian-cloud

This command creates a new VM instance named 'my-preemptible-vm' in 'us-central1-a' using a Debian 11 image, configured as a preemptible instance.

Important Note

Even after creation, a Preemptible VM remains subject to preemption. Manually stopping and starting it does not remove its preemptible characteristic.

Safety Note: Do not use Preemptible VMs for critical, stateful services without robust recovery mechanisms.
