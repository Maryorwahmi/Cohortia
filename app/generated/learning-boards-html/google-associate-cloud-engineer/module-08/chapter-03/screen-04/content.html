Core Concept

Selecting the Right Machine Type

Matching VM resources to workload demands for optimal cost-efficiency

Key Considerations

  • Workload Profile: Identify if your application is general-purpose, compute-intensive, or memory-intensive.
  • Performance vs. Price: Balance the need for high performance with cost constraints.
  • Customization: Use custom machine types to precisely match vCPU and memory, avoiding waste.
Key Takeaway

Always start with the smallest viable machine type and scale up, or use custom types to prevent over-provisioning.

Common Machine Families

E2 Family

Cost-optimized, general-purpose workloads. Good balance of price/performance.

N2/N2D Family

Higher performance, demanding applications. More vCPU/memory options.

C2 Family

Compute-intensive tasks. Optimized for high CPU performance.

M1 Family

Memory-intensive workloads. Ideal for large in-memory databases.

Custom Machine Types

Allows precise specification of vCPU and memory, avoiding waste from predefined types.

gcloud compute instances create my-vm \
  --custom-cpu=4 --custom-memory=16GB

Example: 4 vCPUs, 16GB RAM, tailored to exact needs.
