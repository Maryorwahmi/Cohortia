Cost-Saving Strategy

Leveraging Preemptible VMs

Achieving significant savings for fault-tolerant and flexible workloads

What are Preemptible VMs?

  • Low-cost instances: Up to 80% cheaper than standard VMs.
  • Preemptible: Can be shut down by Compute Engine at any time (typically within 24 hours).
  • Pay-per-use: Only charged for the time the instance runs.
Key Takeaway

Preemptible VMs are ideal for flexible, fault-tolerant workloads, offering significant cost savings if your application can handle interruptions.

Ideal Workloads for Preemptible VMs

Batch Processing

Large, parallelizable jobs that can be restarted or checkpointed.

Stateless Applications

Applications that don't store session data locally and can be easily restarted.

Dev/Test Environments

Non-critical environments where occasional downtime is acceptable.

Data Analytics

Processing large datasets where intermediate results can be saved.

Handling Preemption

Your application must be designed to gracefully manage preemption:

  • Save State Frequently: Persist work to external storage (e.g., Cloud Storage, databases).
  • Use Managed Instance Groups (MIGs): Automatically restart preempted instances.
