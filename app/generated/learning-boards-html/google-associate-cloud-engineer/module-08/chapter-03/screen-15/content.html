Key Concepts

Essential terms to remember for Compute Engine cost optimization

Sustained Use Discounts (SUDs)

Automatic discounts for Compute Engine instances that run for a significant portion of a billing month.

Committed Use Discounts (CUDs)

Discounts obtained by committing to a specific amount of Compute Engine resource usage for 1 or 3 years.

Rightsizing

The process of adjusting VM instance sizes to match actual workload requirements, typically based on monitoring data.

Summary Takeaway

SUDs, CUDs, and Rightsizing are crucial for ongoing, strategic Compute Engine cost optimization, ensuring efficient and economical cloud operations.
