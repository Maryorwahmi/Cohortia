Discount Mechanism

Sustained Use Discounts (SUDs)

Automatic savings for long-running Compute Engine instances

How SUDs Work

  • Automatic Application: No configuration needed; GCP applies them automatically.
  • Usage-based: Discounts increase as VM uptime approaches 100% within a billing month.
  • No Commitment: No upfront commitment or contract required.
Key Takeaway

SUDs provide effortless, automatic cost savings for your consistently running Compute Engine instances.

SUDs vs. Other Discounts

SUDs

Automatic, no commitment, for standard VMs running >25% of month.

Preemptible VMs

Manual flag, high discount, for interruptible workloads.

CUDs

Requires commitment, highest discount, for predictable base loads.

Custom Machine Types

Fine-grained resource matching, avoids over-provisioning.

Example Scenario

A web server VM runs 24/7 for the entire month. It automatically qualifies for the maximum Sustained Use Discount, reducing its hourly cost without any manual intervention.

Benefit: Predictable savings for stable infrastructure.
