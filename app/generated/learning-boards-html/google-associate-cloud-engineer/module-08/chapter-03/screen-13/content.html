Managed Instance Groups (MIGs) with Preemptible VMs

Automating resilience for cost-effective, interruptible workloads

What are Managed Instance Groups?

  • Single Entity Management: Manage a group of VMs as one unit.
  • Automated Features: Includes auto-scaling, auto-healing, and rolling updates.
  • High Availability: Ensures a consistent number of running instances.
Key Takeaway

MIGs provide automated resilience for Preemptible VMs, making them suitable for fault-tolerant, cost-optimized workloads.

MIGs + Preemptible VMs

Combining these two features offers a powerful solution:

  • Automated Recreation: If a Preemptible VM is preempted, the MIG automatically recreates it.
  • Consistent Capacity: Maintains the desired number of instances for your workload.
  • Cost-Effective Resilience: Achieve high availability for interruptible workloads at a lower cost.

Example Use Case

A large-scale image rendering farm uses a MIG of Preemptible VMs. If some VMs are preempted, the MIG ensures new ones are spun up, maintaining rendering throughput without manual intervention and at a fraction of the cost of standard VMs.

Benefit: High throughput, low cost, and automated management.
