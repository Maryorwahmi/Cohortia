Persistent Disk (PD) Cost Management

Optimizing block storage for Compute Engine VMs.

Persistent Disk Types & Costs

Persistent Disks (PD) for Compute Engine VMs come in various types, each with different performance and cost profiles:

  • Standard PD: Cost-effective for sequential I/O.
  • Balanced PD: Good balance of performance and cost.
  • SSD PD: Highest performance for transactional workloads, highest cost.

Cost Optimization Strategies

  • Right-size: Choose the smallest disk size needed.
  • Right-type: Select the appropriate disk type for I/O requirements.
  • Review & Delete: Regularly delete unattached or unused disks.
  • Snapshot Management: Manage and delete old snapshots, as they incur storage costs.
Key Takeaway

Choose the smallest Persistent Disk size and appropriate type (Standard, Balanced, SSD) to match VM I/O needs and optimize costs.

Example: VM Disk Provisioning

Over-provisioning Pitfall

Provisioning a 1TB SSD PD for a VM that only uses 100GB for its OS and applications. This leads to 900GB of wasted, expensive storage.

Snapshot Cost

Keeping daily snapshots for months without review. Each snapshot incurs storage costs, which can add up significantly over time for large disks.
