Practical Application

Enabling Cloud CDN on Backend Services

Configuring your services to utilize Google's global cache.

Integration with Load Balancing

Cloud CDN works by integrating with Google Cloud Load Balancing, making it a seamless addition to existing web architectures.

serve-while-stale Policy

This policy allows CDN to serve cached content even if the origin is temporarily unavailable, improving resilience and reducing origin load.

Key Takeaway

Enabling Cloud CDN is a simple command that yields significant benefits in performance, availability, and cost reduction for global content delivery.

Cloud Shell Command (Conceptual)
gcloud compute backend-services update my-backend-service \
    --enable-cdn \
    --cdn-policy=serve-while-stale=3600 # Serve stale content for 1 hour
Command Explanation
  • gcloud compute backend-services update: Modifies an existing backend service.
  • my-backend-service: The name of your target backend service.
  • --enable-cdn: Activates Cloud CDN for this backend service.
  • --cdn-policy=serve-while-stale=3600: Configures the CDN to serve cached content for up to 3600 seconds even if the origin is stale or unreachable.
