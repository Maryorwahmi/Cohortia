SQL Query: Cost by Labels

SELECT
    invoice.month,
    labels.key,
    labels.value,
    SUM(cost) AS total_cost
FROM
    `your-billing-project.your_billing_dataset.gcp_billing_export_v1_XXXXXX` AS t,
    UNNEST(t.labels) AS labels -- <-- Key for label analysis
WHERE
    invoice.month = '202309' -- <-- Filter for a specific month
GROUP BY
    invoice.month, labels.key, labels.value
ORDER BY
    total_cost DESC;

This query aggregates costs by each unique label key-value pair for a specified month, providing a detailed breakdown of spending attributed to your custom tags.

Understanding UNNEST

The UNNEST operator is crucial for working with arrays in BigQuery. It flattens the labels array, allowing each key-value pair to be treated as a separate row for grouping and filtering.

Practical Application

Identify costs associated with specific teams (team:frontend), environments (environment:dev), or cost centers (cost-center:R&D) across all projects.

Key Takeaway

Leveraging UNNEST with resource labels in BigQuery SQL provides the most flexible and granular way to attribute and analyze cloud costs.
