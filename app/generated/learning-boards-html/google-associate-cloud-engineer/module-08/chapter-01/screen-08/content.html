SUDs vs. CUDs: Choosing the Right Discount

Leveraging automatic vs. committed savings for optimal cost efficiency.

Sustained Use Discounts (SUDs)

  • •Automatic, no action required.
  • •Applies to Compute Engine instances.
  • •Discount increases with monthly uptime.
  • •Best for stable, long-running VMs without strict predictability.
Use Case

A development server that runs 24/7 but might be shut down occasionally for maintenance.

Committed Use Discounts (CUDs)

  • •Requires 1-year or 3-year commitment.
  • •Applies to Compute Engine, Spanner, BigQuery, etc.
  • •Offers deeper, more substantial discounts.
  • •Best for highly predictable, long-term production workloads.
Use Case

A production database cluster with consistent vCPU and memory requirements for the next three years.

Common Mistake

Committing to CUDs without accurately forecasting long-term usage can lead to paying for unused capacity.
