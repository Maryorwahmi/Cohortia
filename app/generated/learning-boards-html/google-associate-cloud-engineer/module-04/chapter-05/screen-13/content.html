Hands-on Activity

Creating a Public DNS Zone and A Record

A practical walkthrough using gcloud commands

Activity Steps

  • **Create Zone:** Define a public managed zone for your domain.
  • **Add A Record:** Map a hostname to an IPv4 address within the zone.
  • **Verify & Clean Up:** Confirm the record and remove resources after testing.
Important Note

For actual public resolution, you would need to own the domain and update its nameservers at your registrar.

`gcloud` Commands for DNS Management
# 1. Create a public managed zone
gcloud dns managed-zones create my-public-zone \
  --dns-name=your-domain.com. \
  --description="Public DNS zone"

# 2. Add an A record
gcloud dns record-sets transaction start --zone=my-public-zone
gcloud dns record-sets transaction add 34.100.200.50 \
  --name=www.your-domain.com. --ttl=300 --type=A --zone=my-public-zone
gcloud dns record-sets transaction execute --zone=my-public-zone

# 3. Verify the A record
gcloud dns record-sets list --zone=my-public-zone --name=www.your-domain.com.
Key Takeaway

The `gcloud` CLI provides powerful commands for programmatic management of Cloud DNS zones and records, enabling automation and scripting.
