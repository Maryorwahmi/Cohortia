Public DNS Zones: Internet-Facing Domains

Configuring your domain for global accessibility

Key Steps for Public Zones

  • **Create Managed Zone:** Use `gcloud dns managed-zones create` to define your domain in Cloud DNS.
  • **Delegate Nameservers:** Update your domain registrar with Google Cloud's nameservers.
  • **Add DNS Records:** Populate the zone with A, CNAME, MX, TXT records as needed.
Common Mistake

Forgetting to update your domain registrar's nameservers after creating a public zone in Cloud DNS will prevent your domain from resolving globally.

Creating a Public Managed Zone
# Create a public managed zone for example.com
gcloud dns managed-zones create example-com \
  --dns-name=example.com. \
  --description="Public zone for example.com"

# Output will include nameservers to update at your registrar
gcloud dns managed-zones describe example-com --format='value(nameServers)'

This command creates the zone. The outputted nameservers must be configured with your domain registrar.

Key Takeaway

Public DNS zones in Cloud DNS enable global domain resolution, requiring both GCP zone creation and registrar nameserver delegation for full functionality.
