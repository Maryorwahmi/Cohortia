Components of an HTTP(S) Load Balancer

Frontend Configuration and URL Maps

Frontend Configuration

  • ›Public Entry Point: Defines the global external IP address for client access.
  • ›Protocol & Port: Specifies HTTP/HTTPS and the listening port (e.g., 80, 443).
  • ›Forwarding Rule: Directs incoming traffic from the IP/port to the load balancer's target proxy.

Key Takeaway

The frontend configuration defines the public entry point (IP, port, protocol), while URL maps provide intelligent, path-based routing for HTTP(S) traffic to different backend services.
