Service Overview

Diverse Load Balancer Types

Matching the Right Balancer to Your Application Needs

External Load Balancers: Global Reach

HTTP(S) Load Balancer

Global, Layer 7 for web traffic. Supports URL maps, SSL termination, and CDN integration.

TCP/SSL Proxy Load Balancer

Global, Layer 4 for TCP/SSL traffic. Ideal for non-HTTP(S) applications requiring global reach.

UDP Load Balancer

External, Layer 4 for UDP traffic. Suitable for gaming, media streaming, or DNS services.

Internal Load Balancers: Private Network Traffic

Internal HTTP(S) Load Balancer

Regional, Layer 7 for internal HTTP/HTTPS traffic. Ideal for multi-tier microservice architectures.

Internal TCP/UDP Load Balancer

Regional, Layer 4 for internal TCP/UDP traffic. For backend services communicating within a VPC.

Key Takeaway

Google Cloud provides a diverse range of load balancers, each tailored for specific protocols, traffic types, and deployment scopes (internal vs. external, regional vs. global).
