Layer 4 Options

External TCP/SSL and UDP Load Balancers

Handling Non-HTTP(S) External Traffic

External TCP/SSL Proxy Load Balancer

  • ›Protocol: TCP and SSL traffic.
  • ›Layer: Layer 4 (Transport Layer).
  • ›Scope: Global, providing a single IP address.
  • ›Use Cases: Custom protocols, gaming servers, secure backend services requiring direct TCP.
  • ›Feature: SSL termination for raw TCP streams.

External UDP Load Balancer

  • ›Protocol: UDP traffic.
  • ›Layer: Layer 4 (Transport Layer).
  • ›Scope: External, distributing UDP traffic.
  • ›Use Cases: Real-time gaming, DNS services, media streaming, VoIP.
  • ›Benefit: High performance for connectionless protocols.
Key Takeaway

External TCP/SSL Proxy and UDP Load Balancers provide global Layer 4 traffic distribution for non-HTTP(S) protocols, catering to specialized applications like gaming, custom services, or DNS.
