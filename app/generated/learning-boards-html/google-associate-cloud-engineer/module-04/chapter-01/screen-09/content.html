VPC Network Scope

Global Resource

A VPC network itself is a global resource, spanning all Google Cloud regions. This allows resources across different regions to communicate internally.

Subnet Scope

Regional Resource

Each subnet is a regional resource, defined within a specific Google Cloud region. VMs and other resources are deployed into specific subnets.

Key Takeaway

The global VPC provides overarching connectivity, while regional subnets enable localized network segmentation and fault tolerance.

VPC & Subnet Relationship
A global VPC contains regional subnets, where resources are deployed.
