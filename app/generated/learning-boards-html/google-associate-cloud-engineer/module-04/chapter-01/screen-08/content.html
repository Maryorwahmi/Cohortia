Module 4›Chapter 4.1›Creating a Custom Mode VPC Network
Command Overview

`gcloud compute networks create`

This command is used to create a new VPC network. The `--subnet-mode=custom` flag is crucial for defining a custom mode VPC, giving you full control over subnets.

Key Parameters
  • `[NETWORK_NAME]`: A unique name for your VPC network (e.g., `my-custom-vpc`).
  • `--subnet-mode=custom`: Specifies that you will manually create subnets.
  • `--description="..."`: (Optional) Adds a descriptive text for clarity.
Key Takeaway

Creating a custom mode VPC is the first step to building a highly controlled and flexible network. Remember the `--subnet-mode=custom` flag.

Terminal Demo: Create VPC
# 1. Create a custom mode VPC network
gcloud compute networks create my-custom-vpc \
  --subnet-mode=custom \
  --description="My first custom VPC network for learning"

# Expected Output:
# Creating network [my-custom-vpc]...done.
# NAME           SUBNET_MODE  BGP_ROUTING_MODE  IPV4_RANGE  GATEWAY_IPV4
# my-custom-vpc  CUSTOM       REGIONAL

Note: After creation, the VPC network is global but has no subnets yet. You'll add them next!
