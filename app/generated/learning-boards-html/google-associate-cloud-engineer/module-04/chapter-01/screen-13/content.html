Module 4›Chapter 4.1›Verifying VPC Network and Subnet Creation
Verify VPC Networks

`gcloud compute networks list`

This command displays all VPC networks in your project, allowing you to confirm the existence and basic configuration of your custom VPC.

Verify Subnets

`gcloud compute networks subnets list`

Use this command with `--network` and `--region` flags to list subnets within a specific VPC and region, verifying their IP ranges and details.

Key Takeaway

Always verify your network resources after creation using `gcloud` commands to ensure correct provisioning and prevent deployment issues.

Terminal Demo: Verify Resources
# 3. Verify the creation of your VPC network
gcloud compute networks list

# Expected Output (partial):
# NAME           SUBNET_MODE  BGP_ROUTING_MODE  IPV4_RANGE  GATEWAY_IPV4
# my-custom-vpc  CUSTOM       REGIONAL

# 4. Verify the creation of your subnet
gcloud compute networks subnets list --network=my-custom-vpc --region=us-central1

# Expected Output (partial):
# NAME                   REGION       NETWORK        RANGE
# my-subnet-us-central1  us-central1  my-custom-vpc  10.10.0.0/20

Check Your Work: Ensure the `SUBNET_MODE` is `CUSTOM` for your VPC and the subnet details match your creation command.
