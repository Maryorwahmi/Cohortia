Module 4›Chapter 4.1›Adding a Subnet to Your Custom VPC
Command Overview

`gcloud compute networks subnets create`

This command creates a new subnet within an existing VPC network. Subnets are regional and define the IP ranges for resources in that region.

Key Parameters
  • `[SUBNET_NAME]`: A unique name for your subnet.
  • `--network=[VPC_NETWORK_NAME]`: The VPC network this subnet belongs to.
  • `--range=[IP_CIDR_RANGE]`: The IP address range for the subnet (e.g., `10.10.0.0/20`).
  • `--region=[REGION_NAME]`: The Google Cloud region for this subnet (e.g., `us-central1`).
Key Takeaway

Subnets are regional and define the usable IP space for your resources. Carefully choose your IP ranges and regions for optimal design.

Terminal Demo: Create Subnet
# 2. Add a subnet to your custom VPC in the us-central1 region
gcloud compute networks subnets create my-subnet-us-central1 \
  --network=my-custom-vpc \
  --range=10.10.0.0/20 \
  --region=us-central1 \
  --description="Subnet for us-central1 region"

# Expected Output:
# Creating subnetwork [my-subnet-us-central1]...done.
# NAME                   REGION       NETWORK        RANGE
# my-subnet-us-central1  us-central1  my-custom-vpc  10.10.0.0/20

Pro Tip: Always choose IP ranges large enough for growth but small enough to avoid waste and potential overlaps.
