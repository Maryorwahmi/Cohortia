Module 4›Chapter 4.1›Cleaning Up VPC Network Resources
Delete Subnets First

`gcloud compute networks subnets delete`

You must delete all subnets within a VPC network before you can delete the VPC network itself. Specify the subnet name and its region.

Then Delete VPC Network

`gcloud compute networks delete`

Once all associated subnets are removed, you can delete the VPC network by specifying its name. Use `-q` for quiet deletion.

Key Takeaway

Always clean up your resources in the correct order (subnets then VPC) to avoid orphaned resources and unnecessary costs.

Terminal Demo: Clean Up Resources
# 5. Clean up: Delete the subnet
gcloud compute networks subnets delete my-subnet-us-central1 \
  --region=us-central1 -q

# Expected Output:
# Deleted [my-subnet-us-central1].

# 6. Clean up: Delete the VPC network
gcloud compute networks delete my-custom-vpc -q

# Expected Output:
# Deleted [my-custom-vpc].

Warning: The `-q` flag skips confirmation. Use with caution in production environments to prevent accidental deletions.
