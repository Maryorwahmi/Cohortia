Core Concept

What is a Subnet?

A subnet (or subnetwork) is a logical division of a Virtual Private Cloud (VPC) network's IP address space, confined to a single region.

  • •
    Regional Resource: Subnets are always tied to a specific Google Cloud region, unlike global VPCs.
  • •
    IP Address Allocation: When you create a subnet, you define its primary IP address range using CIDR notation (e.g., 10.10.0.0/20).
  • •
    Internal Communication: VM instances and other resources deployed into a subnet receive internal IP addresses from this primary range, enabling direct communication within the subnet and across the VPC.
Key Takeaway

Subnets provide essential network segmentation, allowing for organized IP address management and controlled communication within your VPC.

Analogy

Imagine a VPC as a large university campus. Each subnet is like a specific department building on that campus, located in a particular area (region). All students and faculty within that building (resources) get their office numbers (IP addresses) from that building's designated range.
