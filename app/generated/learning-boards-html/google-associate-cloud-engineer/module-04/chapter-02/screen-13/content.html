Inspecting VPC Routes and Cleanup

Understanding traffic flow and managing resources responsibly to avoid unnecessary costs.

Terminal: gcloud CLI
# List routes for your VPC network
gcloud compute routes list --filter="network=my-custom-vpc"

# Expected Output (truncated):
NAME                                  NETWORK        DEST_RANGE    NEXT_HOP        PRIORITY
default-route-00c0000000000000        my-custom-vpc  0.0.0.0/0     default-internet-gateway  1000
default-route-10c0000000000000        my-custom-vpc  10.10.16.0/24  my-subnet-us-central1  1000

# Clean up resources (important!)
gcloud compute instances delete my-web-server --zone=us-central1-a -q
gcloud compute addresses delete my-app-static-ip --region=us-central1 -q

# Expected Cleanup Output:
Deleted [my-web-server].
Deleted [my-app-static-ip].
Command Breakdown
  • •
    gcloud compute routes list --filter: Displays routes, filtered by your VPC network.
  • •
    Route Interpretation: Look for DEST_RANGE (destination IP range) and NEXT_HOP (where traffic is sent).
  • •
    gcloud compute instances delete: Removes the VM instance.
  • •
    gcloud compute addresses delete: Releases the static external IP address.
Key Takeaway

Regularly reviewing routes is crucial for network health, and diligent cleanup of unused resources is vital for cost management and security.
