Practical Application

Deploying a VM with a Static IP

Attaching a reserved IP to a new instance and verifying its configuration for public access.

Terminal: gcloud CLI
# Create VM and assign the static IP
gcloud compute instances create my-web-server \
  --zone=us-central1-a \
  --machine-type=e2-medium \
  --image-family=debian-11 \
  --image-project=debian-cloud \
  --network=my-custom-vpc \
  --subnet=my-subnet-us-central1 \
  --address=my-app-static-ip \
  --tags=http-server \
  --metadata=startup-script="#! /bin/bash
    sudo apt update
    sudo apt install -y apache2
    echo '<!doctype html><html><body><h1>Hello from my-web-server!</h1></body></html>' | sudo tee /var/www/html/index.html"

# Verify the VM's IP addresses
gcloud compute instances describe my-web-server \
  --zone=us-central1-a \
  --format='get(networkInterfaces[0].networkIP,networkInterfaces[0].accessConfigs[0].natIP)'

# Expected Output:
10.10.16.2,34.123.45.67
Command Breakdown
  • •
    gcloud compute instances create: Command to create a new VM instance.
  • •
    --address=my-app-static-ip: Crucial flag to assign the previously reserved static IP.
  • •
    --metadata=startup-script: Installs Apache and creates a simple web page for testing.
  • •
    gcloud compute instances describe --format: Used to extract and display the internal and external IP addresses.
Key Takeaway

Verifying IP assignment after VM creation is a critical step to ensure your resources are correctly configured for both internal and external communication.
