What are Secondary IP Ranges?

Secondary IP ranges, also known as IP aliases, are additional CIDR blocks assigned to a subnet, separate from its primary IP range.

  • •
    Specialized Workloads: Primarily used for advanced scenarios like Kubernetes Engine (GKE) clusters, where pods and services require their own dedicated IP space.
  • •
    IP Exhaustion Prevention: Helps prevent the primary IP range from running out of addresses, especially in large-scale container deployments.
  • •
    Enhanced Flexibility: Allows for more granular network design and segmentation within a single subnet.
Example Command
gcloud compute networks subnets create my-subnet-with-secondary \
  --network=my-custom-vpc \
  --range=10.10.16.0/24 \
  --region=us-central1 \
  --secondary-range=pods=10.10.32.0/20

This command creates a subnet with a primary range and a secondary range named 'pods'.

Key Takeaway

Secondary IP ranges are crucial for modern, containerized applications, providing isolation and scalability for IP management.
