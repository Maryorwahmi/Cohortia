Route Types

Default vs. Custom VPC Routes

Leveraging system-generated and user-defined traffic rules for network control.

Default Routes

  • •
    System-Generated: Automatically created with every VPC network.
  • •
    Internet Gateway: Includes a default route for 0.0.0.0/0 (all traffic) to the default internet gateway.
  • •
    Basic Connectivity: Ensures VMs can communicate within the VPC and reach the internet.
Example

The default route 0.0.0.0/0 directs all outbound traffic to the internet, allowing your VMs to fetch updates or access external APIs.

Custom Static Routes

  • •
    User-Defined: Created to direct traffic to specific destinations.
  • •
    Specific Next Hops: Can point to internal load balancers, VPN tunnels, or VM network appliances.
  • •
    Advanced Control: Essential for network segmentation, hybrid connectivity, and custom traffic flows.
Example Command
gcloud compute routes create my-custom-route \
  --destination-range=192.168.1.0/24 \
  --next-hop-instance=my-nat-instance \
  --next-hop-instance-zone=us-central1-a \
  --network=my-custom-vpc --priority=1000
Key Takeaway

Combine default and custom routes to build a comprehensive and secure network traffic management strategy for your cloud environment.
