IP Address Types

Internal vs. External IP Addresses

Understanding how resources communicate within your VPC and with the public internet.

Internal IP Address

  • •
    Scope: Used for communication within the same VPC network.
  • •
    Source: Allocated from the primary IP range of its subnet.
  • •
    Accessibility: Not directly accessible from the internet.
  • •
    Use Case: Ideal for backend services, database servers, and internal microservices.
Analogy

Like an office extension number, only reachable from within the company network.

External IP Address

  • •
    Scope: Used for communication with the public internet.
  • •
    Source: Assigned to a VM instance or other network services.
  • •
    Accessibility: Publicly routable and accessible from anywhere on the internet.
  • •
    Use Case: Essential for web servers, public APIs, and load balancers.
Analogy

Like a public phone number, reachable by anyone outside the company.

Key Takeaway

Choosing the correct IP address type is fundamental for controlling network access and ensuring the security and functionality of your cloud applications.
