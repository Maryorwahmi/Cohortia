Ephemeral External IP Addresses

Ephemeral external IP addresses are temporary public IP addresses automatically assigned to VM instances.

  • •
    Dynamic Assignment: Automatically assigned to a VM instance when it starts.
  • •
    Transient Nature: The IP address changes if the VM is stopped and restarted, or if the VM is deleted.
  • •
    Use Cases: Suitable for development, testing, or temporary workloads where a stable public endpoint is not critical.
Scenario

You're running a temporary data processing script on a VM. An ephemeral IP is sufficient because the public address doesn't need to persist across restarts.

Key Takeaway

Ephemeral IPs are cost-effective for non-critical, short-lived tasks but are unsuitable for production services requiring consistent public access.
