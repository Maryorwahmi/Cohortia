Hands-on: Verifying Access and Cleanup

Confirming the rule's effect and cleaning up resources

# 1. Test accessing the web server again
#    Open a browser to http://<EXTERNAL_IP>
# Expected Result: You should now see "Hello from my-web-server!"

# 2. Clean up resources (IMPORTANT!)
gcloud compute firewall-rules delete allow-http-https-web -q
gcloud compute instances delete my-web-server --zone=us-central1-a -q
gcloud compute addresses delete my-app-static-ip --region=us-central1 -q
Key Takeaway

Successful web access confirms the firewall rule's effectiveness. Always clean up lab resources to manage costs and maintain a tidy cloud environment.

Post-Lab Actions
  • Verify Access: Confirm the web page loads successfully after rule creation.
  • Delete Firewall Rule: Remove the allow-http-https-web rule.
  • Delete VM Instance: Terminate my-web-server.
  • Delete Static IP: Release my-app-static-ip.
Best Practice

Always use the -q flag for non-interactive deletion in scripts, but be cautious in manual operations.
