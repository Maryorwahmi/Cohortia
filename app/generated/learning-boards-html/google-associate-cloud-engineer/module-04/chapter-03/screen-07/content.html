Network Tags

Grouping VMs for Firewall Rules

Network tags are arbitrary string labels applied to VM instances, allowing firewall rules to target a dynamic group of VMs.

  • Dynamic Application: Rules automatically apply to VMs with the specified tag, even as instances are added or removed.
  • Simplified Management: Reduces the need for manual updates when scaling your infrastructure.
Key Takeaway

Network tags provide a flexible way to apply firewall rules to groups of VMs, adapting to changes in your infrastructure.

Service Accounts

Identity-Based Rule Targeting

Service accounts can also be used as sources or targets for firewall rules, enabling identity-based security.

  • GCP Service Communication: Useful for allowing specific Google Cloud services to communicate with your VMs securely.
  • VM-to-VM Security: Allows VMs running with a specific service account to be targeted by rules.
Practical Example

Tag all your web servers with http-server. Create an ingress rule allowing HTTP/HTTPS from 0.0.0.0/0 to instances with the http-server tag.
