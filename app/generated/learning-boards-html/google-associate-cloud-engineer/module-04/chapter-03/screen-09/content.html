Auto Mode VPC Defaults

Convenience with Default Access

When an auto mode VPC is created, Google Cloud automatically provisions several firewall rules.

  • allow-internal: Permits all internal traffic within the VPC.
  • allow-ssh, allow-rdp, allow-icmp: Allow common administrative access and diagnostics from 0.0.0.0/0.
Key Takeaway

Auto mode VPCs provide default access rules, which can be convenient but may require review for security hardening.

Custom Mode VPC Defaults

Security by Default

Custom mode VPCs are more restrictive, typically only including the allow-internal rule.

  • Implied Deny-All: Both ingress and egress traffic are implicitly denied unless explicitly allowed.
  • Explicit Rules Required: You must create rules for any external access, including SSH.
Security Best Practice

Custom mode VPCs enforce the principle of least privilege by default, requiring you to define all allowed traffic explicitly.
