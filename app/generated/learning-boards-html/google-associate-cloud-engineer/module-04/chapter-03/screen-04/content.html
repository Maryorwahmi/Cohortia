Core Concept

Understanding VPC Firewall Rules

VPC firewall rules are the primary tool for controlling network traffic to and from your VM instances and other resources within a Google Cloud Virtual Private Cloud (VPC) network.

  • Stateful Operation: If an incoming connection is allowed, the corresponding outgoing response traffic is automatically permitted, and vice versa.
  • Network Level: Rules apply to all instances within a specified VPC network, regardless of subnet or region.
  • Centralized Control: Simplifies management but requires careful consideration of broad impact.
Key Takeaway

VPC firewall rules are stateful, network-level controls that are fundamental for securing all resources within your Google Cloud VPC network.

Example Scenario

If you create an ingress rule to allow SSH (port 22) from your office IP to a VM, the VM's SSH responses back to your office are automatically allowed by the stateful nature of the firewall.
