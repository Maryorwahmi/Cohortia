Source/Destination Filters

Using CIDR IP Ranges

Define the origin (source) or target (destination) of network traffic using CIDR (Classless Inter-Domain Routing) IP ranges.

  • 0.0.0.0/0: Represents all IP addresses (the entire internet). Use with extreme caution.
  • 192.168.1.0/24: A specific private IP range, allowing traffic only from that subnet.
Key Takeaway

CIDR IP ranges are fundamental for defining the scope of firewall rules, from global access to specific subnets.

Protocols and Ports

Specifying Service Access

Firewall rules also specify the network protocols and port numbers for which traffic is allowed or denied.

  • Protocols: Common examples include TCP (Transmission Control Protocol), UDP (User Datagram Protocol), and ICMP (Internet Control Message Protocol).
  • Ports: Numeric identifiers for specific services, e.g., 22 (SSH), 80 (HTTP), 443 (HTTPS).
Practical Example

To allow secure web traffic, you would specify tcp:443. For standard web traffic, it would be tcp:80.

Misconception

Allowing all protocols or ports from 0.0.0.0/0 is highly insecure and should be avoided unless absolutely necessary for specific, temporary debugging.
