Ingress Rules

Controlling Incoming Traffic

Ingress rules define which traffic is allowed into your VM instances and other resources within the VPC network.

  • Direction: From external sources to your VMs.
  • Example: Allowing SSH (port 22) from your office IP range to a specific VM.
Egress Rules

Controlling Outgoing Traffic

Egress rules define which traffic is allowed out of your VM instances and other resources within the VPC network.

  • Direction: From your VMs to external destinations.
  • Example: Blocking all outbound traffic except to a specific database service.
Rule Evaluation

How Firewall Rules Are Applied

  • Priority: Rules are evaluated in order of priority (lower numbers = higher priority).
  • First Match Wins: The first rule that matches the traffic's characteristics determines the action (allow or deny).
  • Implied Deny: If no rule matches, traffic is implicitly denied.
Common Mistake

Forgetting the implied deny rule can lead to unexpected traffic blocks if no explicit allow rule exists.

Key Takeaway

Ingress rules control traffic into VMs, egress rules control traffic out of VMs. Rules are evaluated by priority, with an implied deny if no match.
