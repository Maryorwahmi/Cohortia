Key Concepts: Core Firewall Elements

Essential terms for network security in Google Cloud

VPC Firewall Rules

Stateful rules controlling ingress and egress traffic to/from VM instances within a VPC network.

Ingress Rule

A firewall rule that specifically controls incoming traffic to your cloud resources.

Egress Rule

A firewall rule that specifically controls outgoing traffic from your cloud resources.

Summary Takeaway

VPC Firewall Rules are stateful controls that manage both incoming (Ingress) and outgoing (Egress) network traffic to secure your VM instances.
