Hands-on: Setting Up Your Web Server VM

Preparing the environment for firewall rule testing

# 1. Create a static IP address
gcloud compute addresses create my-app-static-ip --region=us-central1

# 2. Create the VM instance with http-server tag and startup script
gcloud compute instances create my-web-server \
  --zone=us-central1-a \
  --machine-type=e2-medium \
  --image-family=debian-11 \
  --image-project=debian-cloud \
  --network=my-custom-vpc \
  --subnet=my-subnet-us-central1 \
  --address=my-app-static-ip \
  --tags=http-server \
  --metadata="startup-script=#! /bin/bash
    sudo apt update
    sudo apt install -y apache2
    echo '<!doctype html><html><body><h1>Hello from my-web-server!</h1></body></html>' | sudo tee /var/www/html/index.html"
Key Takeaway

The VM is created with a specific network tag (http-server) and a startup script to install Apache, making it ready for web traffic testing.

Setup Steps
  • Static IP: Reserve a static external IP for consistent access.
  • VM Creation: Provision a Debian VM with specified network and IP.
  • Network Tag: Apply http-server tag for dynamic firewall rule targeting.
  • Startup Script: Automatically installs Apache and deploys a simple web page.
Important Note

Allow a few minutes for the VM to boot and the startup script to complete Apache installation before proceeding.
