Diagnosing Connectivity: Firewall Rules and Routes

A systematic approach to identify common network culprits.

1. Check Firewall Rules

Most common cause. Use `gcloud compute firewall-rules list` and `describe` to inspect rules. Firewall Insights or Connectivity Tests can help.

2. Verify Routes

Incorrect routing can misdirect traffic. Use `gcloud compute routes list` to ensure correct paths exist for destinations.

Common Mistake

Assuming all network issues are firewall problems. Always check routes too!

Key Takeaway

Always start troubleshooting by systematically checking firewall rules and VPC routes, as these are the most frequent causes of network connectivity issues.
