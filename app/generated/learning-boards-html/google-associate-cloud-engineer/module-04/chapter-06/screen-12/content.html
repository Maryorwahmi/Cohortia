Troubleshooting Steps

Verifying IPs, VM Status, and Flow Logs

Expanding your diagnostic scope for complex issues.

3. Confirm IP Addresses

Ensure source and destination IPs are correct and the target resource has the expected IP.

4. Check VM Status & Application

Verify VM is running (`gcloud compute instances describe`) and application is listening on correct ports (`sudo systemctl status `).

5. Analyze VPC Flow Logs

If enabled, analyze flow logs for specific traffic patterns or drops to pinpoint communication failures.

6. Run Connectivity Tests

Perform a test between source and destination for a detailed path analysis and identification of blocking factors.
