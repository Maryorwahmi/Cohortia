Leveraging Instance Metadata

Dynamically pass configuration and information to your Compute Engine instances.

What is Instance Metadata?

A service that provides information about the instance to the instance itself, accessible via a local HTTP endpoint.

Custom Key-Value Pairs

Define your own metadata to pass configuration data, environment variables, or application secrets (with Secret Manager for sensitive data).

Key Takeaway

Metadata enables flexible, dynamic instance configuration without baking it into images.
