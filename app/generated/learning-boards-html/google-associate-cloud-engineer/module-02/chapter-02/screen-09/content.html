startup.sh
# Example startup script to install Nginx and deploy a simple HTML page
#!/bin/bash
sudo apt update
sudo apt install -y nginx
echo "<h1>Hello from my Compute Engine VM!</h1>" | sudo tee /var/www/html/index.nginx-debian.html
sudo systemctl start nginx
gcloud Command
gcloud compute instances create my-web-server \
    --zone=us-central1-a \
    --machine-type=e2-medium \
    --image-family=debian-11 \
    --image-project=debian-cloud \
    --metadata-from-file=startup-script=./startup.sh \
    --tags=http-server

Deploying Applications with Startup Scripts

Attach a shell script to your instance creation to automate software installation and service configuration.

Automated Setup

The script installs Nginx and deploys a basic web page upon instance startup.

Common Mistakes

Not making scripts idempotent (run multiple times safely) or handling errors gracefully.

Key Takeaway

Startup scripts streamline deployment, but require careful design for robustness.
