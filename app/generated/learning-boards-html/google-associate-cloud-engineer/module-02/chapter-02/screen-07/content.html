Retrieving Metadata from Within a VM

Access instance-specific information and custom data using a special internal HTTP endpoint.

Internal Endpoint

http://metadata.google.internal/computeMetadata/v1/ is only accessible from the instance.

Required Header

Include Metadata-Flavor: Google for authentication.

Key Takeaway

Metadata provides a secure, dynamic way for applications to fetch configuration data.

Terminal Output
# Accessing a custom metadata key
curl "http://metadata.google.internal/computeMetadata/v1/instance/attributes/my-custom-key" -H "Metadata-Flavor: Google"

my-secret-value-123

# Accessing instance zone
curl "http://metadata.google.internal/computeMetadata/v1/instance/zone" -H "Metadata-Flavor: Google"

projects/1234567890/zones/us-central1-a
