Managing SSH Access to Instances

Securely connect to your Compute Engine instances using `gcloud` or custom SSH keys.

Simplified Access

gcloud compute ssh automatically manages SSH keys for convenience.

Custom Key Management

Add public SSH keys to instance-level or project-level metadata for granular control.

Security Best Practice

Always use strong, unique SSH keys and avoid password-based authentication.

Adding SSH Key to Instance Metadata
# To add your public key to an instance's metadata
gcloud compute instances add-metadata my-instance \
    --zone=us-central1-a \
    --metadata=ssh-keys="username:ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAABAQC..."
Explanation
  • •`username`: The user account on the VM that will be granted access.
  • •`ssh-rsa AAAAB3NzaC...`: Your actual public SSH key string.
  • •This key grants access only to `my-instance` in `us-central1-a`.
