Deployments: Ensuring Application Availability

Defining and managing a desired state for your Pods.

  • •Manages Pods: Controls a set of identical Pods, ensuring a specified number of replicas are always running.
  • •Self-Healing: Automatically replaces failed Pods to maintain the desired state.
  • •Rolling Updates: Enables zero-downtime application updates.
  • •Rollbacks: Allows reverting to previous stable versions if issues occur.
Key Takeaway

Deployments are crucial for maintaining application availability and managing updates reliably in Kubernetes.

Example: `deployment.yaml`

apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-web-app-deployment
spec:
  replicas: 3 # Desired number of Pods
  selector:
    matchLabels:
      app: my-web-app
  template:
    metadata:
      labels:
        app: my-web-app
    spec:
      containers:
      - name: my-web-app-container
        image: us-central1-docker.pkg.dev/your-gcp-project-id/my-docker-repo/my-docker-app:1.0
        ports:
        - containerPort: 3000
Deployment Command

Apply this manifest using: kubectl apply -f deployment.yaml
