Key Concepts

Core resources and tools in GKE.

Pod

The smallest deployable unit in Kubernetes, encapsulating one or more containers.

Deployment

A Kubernetes object managing a set of identical Pods, ensuring desired replicas and self-healing.

Service

Defines a logical set of Pods and a policy for accessing them, providing stable network access.

Summary Takeaway

Pods are the runtime units, Deployments manage their lifecycle, Services enable stable access, and `kubectl` is your command-line interface for all interactions.
