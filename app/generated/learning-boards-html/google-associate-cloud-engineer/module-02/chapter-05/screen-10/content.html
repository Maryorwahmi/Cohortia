Services: Stable Network Access for Your Applications

Providing consistent access to ephemeral Pods.

  • •Stable Endpoint: Provides a consistent network entry point for your application, abstracting dynamic Pod IPs.
  • •LoadBalancer Type: Commonly used to expose applications to the internet.
  • •GCP Integration: GKE automatically provisions a Google Cloud Load Balancer for `LoadBalancer` Services.
  • •Selector Matching: Connects to Pods based on matching labels defined in the Service and Deployment.
Key Takeaway

Services are essential for providing stable and accessible network endpoints to your applications, especially `LoadBalancer` for external exposure.

Example: `service.yaml`

apiVersion: v1
kind: Service
metadata:
  name: my-web-app-service
spec:
  selector:
    app: my-web-app # Selects Pods with this label
  ports:
    - protocol: TCP
      port: 80 # External port
      targetPort: 3000 # Container port
  type: LoadBalancer # Exposes the service externally
Accessing the Service

After applying, use kubectl get service my-web-app-service to find the external IP address.
