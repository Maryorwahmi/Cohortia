Load Balancer Architecture

Anatomy of an HTTP(S) Load Balancer

Key Components for Global Traffic Management

01

Backend Service

Defines how traffic is distributed to backend instances (e.g., a Managed Instance Group).

02

Health Check

Monitors the health of instances in the backend service, ensuring traffic only goes to healthy ones.

03

URL Map

Routes requests to different backend services based on URL paths or hostnames.

04

Target HTTP(S) Proxy

Receives requests from the URL map and forwards them to the appropriate backend service.

05

Forwarding Rule

The entry point for external traffic, specifying the IP address and port the load balancer listens on.

Key Takeaway

Each component of the HTTP(S) Load Balancer plays a vital role in directing and managing traffic from the internet to your backend instances.
