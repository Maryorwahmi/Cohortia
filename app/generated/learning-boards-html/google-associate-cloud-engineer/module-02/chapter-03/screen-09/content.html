External IP Management

Ephemeral vs. Static External IPs

Choosing the Right Public Identity for Your Services

Ephemeral External IPs

  • •Temporary public IP addresses.
  • •Assigned when an instance starts, released when it stops/deletes.
  • •IP address can change upon restart.
  • •Suitable for instances not needing a fixed public identity (e.g., batch jobs).
Key Takeaway

Static IPs provide stability for public services, while ephemeral IPs are cost-effective for temporary public access.

Static External IPs

  • •Reserved public IP addresses.
  • •Persist across instance restarts and deletions.
  • •Recommended for public-facing services needing a constant IP (e.g., DNS records).
  • •Incur a small cost, even when not in use.

gcloud Static IP Example

# Reserve a static external IP address
gcloud compute addresses create my-static-ip --region=us-central1

# Assign it to an instance (during creation or update)
gcloud compute instances create my-instance \
    --zone=us-central1-a \
    --address=my-static-ip \
    # ... other parameters
