Configuring HTTP(S) Load Balancer

A Step-by-Step gcloud Example

Health Check Creation

  • •http-basic-check: Name of the health check.
  • •--request-path=/: Path to check (root path).
  • •--port=80: Port to check on backend instances.
  • •Ensures traffic is only sent to healthy instances.
Key Takeaway

Health checks and backend services are foundational for load balancing, ensuring traffic is intelligently routed to available resources.

gcloud Load Balancer Setup

# Example: Create a health check
gcloud compute health-checks create http http-basic-check \
    --request-path=/ \
    --port=80

# Example: Create a backend service (assuming a MIG named 'my-web-mig' exists)
gcloud compute backend-services create web-backend-service \
    --protocol=HTTP \
    --port-name=http \
    --health-checks=http-basic-check \
    --global
gcloud compute backend-services add-backend web-backend-service \
    --instance-group=my-web-mig \
    --instance-group-zone=us-central1-a

Backend Service Details

The backend service defines the protocol and port for traffic distribution and links to the health check. The --global flag is crucial for HTTP(S) Load Balancers.
