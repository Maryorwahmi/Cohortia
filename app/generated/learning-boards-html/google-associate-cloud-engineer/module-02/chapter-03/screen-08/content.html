IP Address Types

Connecting Your Instances

Internal vs. External IP Addresses

Internal IP Addresses

  • •Private IP addresses from the subnet's range.
  • •Used for communication between instances within the same VPC network.
  • •Free and provide secure, high-speed communication.
  • •Ideal for backend services, databases, or internal APIs.
Key Takeaway

Choose internal IPs for secure, private communication within your VPC and external IPs for internet connectivity.

External IP Addresses

  • •Public IP addresses that allow instances to communicate with the internet.
  • •Essential for public-facing services (web servers, APIs).
  • •Incur a small cost.
  • •Can be ephemeral (temporary) or static (reserved).

Use Case: Internal IP

A database server should only have an internal IP address, accessible only by application servers within the same VPC for enhanced security.
