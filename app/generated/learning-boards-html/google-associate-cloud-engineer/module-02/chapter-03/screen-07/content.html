Implementing Firewall Rules

Configuring Specific Traffic Access with gcloud

Firewall Rule Breakdown

  • •--network=default: Applies the rule to the specified VPC network.
  • •--action=ALLOW: Specifies whether to allow or deny traffic.
  • •--rules=tcp:80: Defines the protocol and port (HTTP traffic).
  • •--source-ranges=0.0.0.0/0: Allows traffic from any IP address.
  • •--target-tags=web-server: Targets instances with the 'web-server' network tag.
Key Takeaway

Use network tags to apply firewall rules selectively, ensuring granular control over traffic to specific instance groups.

gcloud Firewall Rule Creation

gcloud compute firewall-rules create allow-http-web \
    --network=default \
    --action=ALLOW \
    --rules=tcp:80 \
    --source-ranges=0.0.0.0/0 \
    --target-tags=web-server \
    --description="Allow HTTP traffic to web servers"

Security Best Practice

Always limit --source-ranges to the minimum necessary IPs. Using 0.0.0.0/0 should be reserved for truly public services and carefully considered.
