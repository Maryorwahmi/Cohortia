Pushing and Pulling Images with Artifact Registry

Storing and retrieving Docker images from your private registry.

TerminalImage Workflow
# 1. Configure Docker to authenticate with Artifact Registry
gcloud auth configure-docker us-central1-docker.pkg.dev

# Expected Output:
Adding credentials for: us-central1-docker.pkg.dev
...
Credentials configured for: us-central1-docker.pkg.dev

# 2. Tag your local image with the Artifact Registry path
docker tag my-node-app:1.0 us-central1-docker.pkg.dev/your-gcp-project-id/my-docker-repo/my-node-app:1.0

# 3. Push the tagged image to Artifact Registry
docker push us-central1-docker.pkg.dev/your-gcp-project-id/my-docker-repo/my-node-app:1.0

# Expected Output (truncated):
The push refers to repository [us-central1-docker.pkg.dev/your-gcp-project-id/my-docker-repo/my-node-app]
...
1.0: digest: sha256:... size: 1.23MB

# 4. Pull the image from Artifact Registry (e.g., on another machine)
docker pull us-central1-docker.pkg.dev/your-gcp-project-id/my-docker-repo/my-node-app:1.0
Authenticate Docker

Use `gcloud auth configure-docker` to enable Docker to interact with Artifact Registry.

Tag Image

Rename your local image with the full Artifact Registry path for proper addressing.

Push/Pull

Use standard `docker push` and `docker pull` commands with the fully qualified image name.

Key Takeaway

Artifact Registry provides a secure, centralized hub for sharing and deploying your Docker images across Google Cloud.
