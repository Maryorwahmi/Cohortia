Running Containers Locally: The `docker run` Command

Mapping ports and naming containers for local execution.

TerminalContainer Output
# Run the Docker image, mapping host port 80 to container port 3000
docker run -p 80:3000 --name my-running-app my-node-app:1.0

# Expected Output (from server.js inside container):
App listening at http://localhost:3000

# To access the application, open your browser to:
http://localhost

# To stop the running container (in a new terminal or after detaching)
docker stop my-running-app

# To remove the container
docker rm my-running-app
`docker run`

Creates and starts a new container from a specified image.

`-p HOST_PORT:CONTAINER_PORT`

Maps a port on the host machine to a port inside the container.

`--name`

Assigns a custom name to the container for easier management.

Common Mistake

Incorrect port mapping (`-p`) can lead to 'connection refused' errors when trying to access the application.
