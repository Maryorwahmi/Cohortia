Building Your First Docker Image

Compiling your application into a runnable Docker image.

TerminalBuild Process
# Build the Docker image, tagging it with a name and version
docker build -t my-node-app:1.0 .

`docker build`

Executes Dockerfile instructions to create an image.

`-t` Flag

Tags the image with a name (e.g., `my-node-app`) and version (e.g., `1.0`).

Build Context (`.`)

Specifies the path to the Dockerfile and files to include in the build.

Key Takeaway

A successful build creates a local Docker image, ready to be run or pushed to a registry.
