Creating an Artifact Registry Repository

Using `gcloud artifacts repositories create` to prepare for image storage.

TerminalRepository Setup
# Create a Docker repository in Artifact Registry
gcloud artifacts repositories create my-docker-repo \
    --repository-format=docker \
    --location=us-central1 \
    --description="My Docker images"

# Expected Output (truncated):
Creating repository [my-docker-repo] in project [your-gcp-project-id]...
Done.
Name: my-docker-repo
Format: DOCKER
Location: us-central1
Description: My Docker images
...
`gcloud artifacts repositories create`

The command to provision a new repository in Artifact Registry.

`--repository-format=docker`

Specifies that this repository will store Docker images.

`--location`

Defines the Google Cloud region for the repository (e.g., `us-central1`).

Key Takeaway

A repository acts as a dedicated, organized storage space for your Docker images within Artifact Registry.
