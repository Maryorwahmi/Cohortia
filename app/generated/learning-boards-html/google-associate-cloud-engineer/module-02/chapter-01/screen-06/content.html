Selecting VM Images

The blueprint for your VM's software environment.

What is a VM Image?

An image is a pre-configured template containing an operating system and a base software configuration. It's used to create new VM instances with a consistent starting environment.

Key Definition

Example: Linux Images

For a Linux server, you might choose:

  • debian-cloud/debian-11
  • ubuntu-os-cloud/ubuntu-2004-lts

These provide a stable and widely supported base for your applications.

Image Options

Public Images

Provided by Google (Debian, Ubuntu, CentOS, Windows Server, specialized images).

Custom Images

Created from existing instances for consistent deployments.

Imported Images

Migrate images from other environments to GCE.

Key Takeaway

Images define your VM's initial software environment. Choose from Google's public catalog or create custom images for consistency and migration.
