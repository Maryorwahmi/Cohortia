Choosing Machine Types

Defining your VM's virtual hardware resources.

What are Machine Types?

Machine types specify the virtual hardware resources (vCPUs and memory) allocated to your VM instance. This choice directly impacts performance and cost.

  • vCPUs: Virtual Central Processing Units.
  • Memory: RAM allocated to the VM.

Example: `e2-medium` Instance

An e2-medium instance is a General-purpose machine type that offers:

  • 2 vCPUs
  • 4 GB of Memory

Suitable for many development or small production workloads, balancing price and performance.

Machine Type Families

General-purpose

E2, N2, N2D (Balanced)

Compute-optimized

C2 (High CPU)

Memory-optimized

M1, M2 (High RAM)

Storage-optimized

L2 (High Disk I/O)

Key Takeaway

Selecting the right machine type is crucial for balancing performance and cost. Over-provisioning wastes money, while under-provisioning degrades performance.
