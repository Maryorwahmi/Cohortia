Persistent Disk Storage Options

Durable block storage for your Compute Engine instances.

What are Persistent Disks?

Persistent disks are durable block storage devices that your VM instances can access. They are independent of your VM's lifecycle, meaning data persists even if the VM is deleted or fails.

Key Definition

Use Case: Database Storage

For a production database, you would typically use an SSD Persistent Disk. This ensures high IOPS and low latency for database transactions, crucial for application responsiveness. If the VM hosting the database fails, the disk can be reattached to a new VM, preserving your data.

Persistent Disk Types

Standard Persistent Disks

Cost-effective, good for sequential I/O (boot disks, less intensive workloads).

SSD Persistent Disks

Higher IOPS and lower latency (databases, high-performance apps).

Extreme Persistent Disks

Highest performance, provisioned IOPS and throughput (mission-critical apps).

Key Takeaway

Persistent disks offer durable, independent storage with varying performance tiers. Always use them for data you need to keep, as they are decoupled from the VM's lifecycle.
