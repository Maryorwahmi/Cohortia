Understanding Local SSDs

High-performance, ephemeral storage for temporary data.

What are Local SSDs?

Local SSDs are block storage devices physically attached to the host server. They offer extremely high IOPS and low latency, making them ideal for performance-critical, temporary data.

Key Definition

Use Case: Caching Layer

A common use case for Local SSDs is for a caching layer in a high-traffic application. The cache data is temporary and can be rebuilt if lost, but requires extremely fast access to improve application responsiveness. This leverages the high performance of Local SSDs without risking critical data.

Key Characteristics

  • High Performance: Excellent IOPS and low latency.
  • Ephemeral Data: Data is lost if the instance stops, restarts, or is terminated.
  • Physically Attached: Directly connected to the host server.
  • Cost-Effective for Temporary Needs: Good for scratch disks or temporary storage.
Key Takeaway

Local SSDs provide superior performance but are ephemeral. Always use persistent disks for critical, long-term data, and local SSDs only for temporary, high-speed storage.
