Service Walkthrough

Exposing with a LoadBalancer Service

Making your Nginx application publicly accessible.

Service Manifest (`my-app-service.yaml`)

# my-app-service.yaml
apiVersion: v1
kind: Service
metadata:
  name: my-nginx-service
spec:
  selector:
    app: nginx # Selects Pods with the label 'app: nginx'
  ports:
    - protocol: TCP
      port: 80
      targetPort: 80
  type: LoadBalancer # Creates a GCP Load Balancer
Key Takeaway

A `LoadBalancer` Service provisions a cloud load balancer to expose your application externally, providing a public IP address.

Service Deployment Steps

1

Create YAML: Define your Service in a file like `my-app-service.yaml`.

2

Apply Command: Use `kubectl apply -f my-app-service.yaml` to create the Service.

3

Get External IP: Run `kubectl get service my-nginx-service` and wait for the `EXTERNAL-IP`.

Terminal Command

# Deploy the Service
kubectl apply -f my-app-service.yaml
Pro Tip

Ensure the `selector` in your Service YAML exactly matches the `labels` in your Deployment's Pod template to correctly route traffic.
