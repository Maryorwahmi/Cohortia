Pods: The Smallest Deployable Unit

Understanding the basic building block of Kubernetes.

What is a Pod?

  • •Atomic Unit: Smallest deployable unit in Kubernetes, not individual containers.
  • •Encapsulates: One or more tightly coupled containers (e.g., app + sidecar).
  • •Shared Resources: Containers within a Pod share storage, network IP, and IPC.
  • •Ephemeral: Pods are designed to be short-lived and easily replaced.
Key Takeaway

A Pod is the smallest deployable unit in Kubernetes, encapsulating one or more containers, storage, and a unique network IP.

Pod Structure & Lifecycle

Containers: The actual application processes run inside Docker or other OCI-compliant containers.

Storage: Volumes can be attached to Pods, allowing data to persist or be shared between containers.

Network: Each Pod gets its own unique IP address within the cluster, enabling communication.

Analogy

Think of a Pod as a single apartment unit, where one or more roommates (containers) live together, sharing the same address and utilities.
