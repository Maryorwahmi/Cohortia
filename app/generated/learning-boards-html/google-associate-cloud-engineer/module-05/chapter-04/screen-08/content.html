Deploying Your First Application

Using `kubectl apply` with a YAML manifest.

Deployment Manifest (`my-app-deployment.yaml`)

# my-app-deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-nginx-deployment
  labels:
    app: nginx
spec:
  replicas: 3 # Desired number of Pod instances
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:1.14.2 # The Docker image to use
        ports:
        - containerPort: 80
Key Takeaway

Define your application's desired state in a YAML manifest and use `kubectl apply` to deploy it to GKE.

Deployment Steps

1

Create YAML: Define your Deployment in a file like `my-app-deployment.yaml`.

2

Apply Command: Use `kubectl apply -f my-app-deployment.yaml` to send the configuration to GKE.

3

Verify: Check the status with `kubectl get deployments` and `kubectl get pods`.

Terminal Command

# Deploy the application
kubectl apply -f my-app-deployment.yaml
Important Note

The `selector` in the Deployment must match the `labels` in the Pod template for Kubernetes to correctly manage the Pods.
