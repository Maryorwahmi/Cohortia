Deploying Cloud Functions: Python Code

Examine a basic HTTP-triggered Python Cloud Function (`main.py`).

Function Purpose

This function responds to an HTTP request, extracting a 'name' parameter from either the JSON body or URL query to provide a personalized greeting.

Dependency Management

If your function uses external libraries (like Flask for request handling), they must be declared in a requirements.txt file for Cloud Functions to install them.

Stateless Design

Cloud Functions are designed to be stateless; they do not retain client-specific data between invocations, ensuring high scalability and resilience.

Key Takeaway

A Cloud Function's code defines its logic, handling inputs and producing outputs, with dependencies managed via requirements.txt.

# main.py
def hello_http(request):
    """Responds to an HTTP request.
    Args:
        request (flask.Request): The request object.
    Returns:
        The response text, or any set of values that can be turned into a
        Response object using `make_response`
    """
    request_json = request.get_json(silent=True)
    request_args = request.args

    if request_json and 'name' in request_json:
        name = request_json['name']
    elif request_args and 'name' in request_args:
        name = request_args['name']
    else:
        name = 'World'
    return 'Hello {}!'.format(name)
