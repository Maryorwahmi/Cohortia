Deploying Cloud Run: Command Line

Use the gcloud run deploy command to publish your containerized service.

Image Specification

The --image flag points to your Docker container image, typically stored in Google Container Registry or Artifact Registry.

Managed Platform

--platform managed ensures your service runs on the fully managed Cloud Run environment, abstracting away infrastructure concerns.

Region & Access

--region specifies the deployment location. --allow-unauthenticated grants public access, which should be restricted with IAM for production.

Key Takeaway

gcloud run deploy simplifies the process of deploying container images as scalable, serverless services on Google Cloud Run.

gcloud run deploy my-cloud-run-service \
    --image gcr.io/YOUR_PROJECT_ID/my-cloud-run-app:latest \
    --platform managed \
    --region us-central1 \
    --allow-unauthenticated
Prerequisite

Before deployment, you must have a Docker image of your application, typically built and pushed to a container registry.
