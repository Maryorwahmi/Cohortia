Leveraging Builder Images and Variables

Customizing steps with Docker images and dynamic values.

Builder Images (`name`)

Each build step uses a Docker image (a 'builder') to execute commands. Google provides many official builders, but you can also use custom ones.

  • •gcr.io/cloud-builders/docker for Docker commands
  • •gcr.io/cloud-builders/gcloud for GCP CLI commands
  • •gcr.io/cloud-builders/npm for Node.js builds

Built-in Variables

Cloud Build automatically provides variables that inject dynamic information into your build steps, useful for unique artifact naming.

  • •$PROJECT_ID: Your GCP project ID
  • •$COMMIT_SHA: SHA of the triggering commit
  • •$BRANCH_NAME: Name of the triggering branch
Example Use

Tagging a Docker image with gcr.io/$PROJECT_ID/my-app:$COMMIT_SHA ensures unique versioning.

Pro Tip

Explore the Cloud Builders community for specialized images or create your own custom builders for unique needs.

Key Takeaway

Leveraging builder images and built-in variables makes your Cloud Build pipelines highly flexible and dynamic.
