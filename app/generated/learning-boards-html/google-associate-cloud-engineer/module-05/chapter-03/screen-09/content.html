Initiating Cloud Builds

From manual submission to automated triggers.

Manual Build Submission

For one-off builds or local testing, you can manually submit your cloudbuild.yaml from the command line.

gcloud builds submit --config cloudbuild.yaml .

Automated Build Triggers

Triggers automatically start a build pipeline in response to events like code pushes or pull requests in your repository.

  • •Connects to Cloud Source Repositories, GitHub, Bitbucket
  • •Configurable for specific branches or events
Manual Use Case

Quickly test a new build step or validate a cloudbuild.yaml change before committing.

Automation Benefit

Ensures continuous integration, providing immediate feedback on code changes and keeping artifacts up-to-date.

Key Takeaway

While manual builds are useful for testing, automated triggers are essential for a true CI/CD workflow.
