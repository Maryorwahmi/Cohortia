Structuring Your Build Pipeline

The cloudbuild.yaml file and its essential components.

# cloudbuild.yaml
steps:
  # Step 1: Compile code
  - name: 'gcr.io/cloud-builders/maven'
    args: ['install']

  # Step 2: Run tests
  - name: 'gcr.io/cloud-builders/pytest'
    args: ['-v', 'tests/']

  # Step 3: Build Docker image
  - name: 'gcr.io/cloud-builders/docker'
    args: ['build', '-t', 'gcr.io/$PROJECT_ID/my-app:$COMMIT_SHA', '.']

images:
  - 'gcr.io/$PROJECT_ID/my-app:$COMMIT_SHA'

cloudbuild.yaml File

The primary configuration file for Cloud Build, defining the entire CI/CD pipeline. It's typically located at the root of your repository.

steps Array

A list of individual actions Cloud Build executes sequentially. Each step is an independent operation.

Docker Container Execution

Each step runs in a Docker container, allowing you to use any tool available as a Docker image (e.g., maven, npm, docker, gcloud).

Key Takeaway

The cloudbuild.yaml file is your declarative script for automating every stage of your software delivery pipeline.
