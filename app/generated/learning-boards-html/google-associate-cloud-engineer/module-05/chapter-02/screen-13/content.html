Safety & Cleanup

Preview Mode and Deleting Deployments

Ensuring safe operations and responsible resource management

Key Safety Practices

  • •Always use the --preview flag before `create` or `update` commands.
  • •Review the preview output carefully to understand planned changes.
  • •Understand that `delete` is a destructive operation; use with extreme caution.
  • •Verify deployment names before executing deletion commands.
Key Takeaway

Leverage preview mode for non-destructive verification and exercise extreme caution with `delete` commands to ensure safe and responsible cloud operations.

# Previewing changes
gcloud deployment-manager deployments create my-complex-infra \
--config my-infra-config.yaml --preview

# Deleting a deployment
gcloud deployment-manager deployments delete my-complex-infra

The Power of Deletion

The `delete` command removes all resources associated with a deployment. This is incredibly useful for cleaning up test environments or decommissioning projects. However, because it's irreversible, always ensure you are targeting the correct deployment and understand the full impact before proceeding.
