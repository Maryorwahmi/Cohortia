Python Templates for Dynamic Resources

Creating reusable and parameterized resource definitions

Key Features of Python Templates

  • •Define a GenerateConfig(context) function.
  • •context.properties allows passing parameters to the template.
  • •Enables conditional logic and complex resource generation.
  • •Promotes reusability across different deployments.
Key Takeaway

Python templates provide powerful programmatic control over resource definitions, making infrastructure highly flexible and reusable.

# vm_template.py
def GenerateConfig(context):
"""Generates the configuration for a Compute Engine instance."""

resources = [{
'name': context.env['name'],
'type': 'compute.v1.instance',
'properties': {
'zone': context.properties['zone'],
'machineType': 'zones/{}/machineTypes/{}'.format(
context.properties['zone'], context.properties['machineType']),
'disks': [{
'deviceName': 'boot',
'type': 'PERSISTENT',
'boot': True,
'autoDelete': True,
'initializeParams': {
'sourceImage': 'projects/debian-cloud/global/images/family/debian-11'
}
}],
'networkInterfaces': [{
'network': 'global/networks/default',
'accessConfigs': [{
'name': 'External NAT',
'type': 'ONE_TO_ONE_NAT'
}]
}]
}
}]
return {'resources': resources}

Parameterization Example

The template uses context.properties['zone'] and context.properties['machineType']. This means the actual zone and machine type are not hardcoded in the template but are provided when the template is referenced in the main configuration file, making it highly adaptable.
