Template Integration

Referencing Templates in Configuration

Orchestrating complex deployments with modular files

How Templates are Integrated

  • •Use the imports section to declare template files.
  • •Reference the template file path as the type for a resource.
  • •Pass parameters to the template via the properties block.
  • •This creates a clear separation of concerns: logic vs. parameters.
Key Takeaway

By importing and referencing templates, you build highly modular and maintainable IaC, enabling flexible deployments with minimal code duplication.

# template-config.yaml
imports:
- path: vm_template.py

resources:
- name: my-templated-vm
type: vm_template.py
properties:
zone: us-central1-a
machineType: e2-small

Benefits of Template Referencing

This approach allows you to define complex resource logic once in a template and then reuse it across multiple deployments with different configurations. It significantly reduces boilerplate code and makes your infrastructure definitions more readable and easier to manage.
