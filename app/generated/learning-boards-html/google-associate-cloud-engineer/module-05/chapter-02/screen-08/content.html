Deployment Execution

Deploying Your First Configuration

Using the gcloud command to create resources

Deployment Steps

  • •Define your infrastructure in a YAML configuration file.
  • •Use gcloud deployment-manager deployments create to initiate.
  • •Deployment Manager parses the config and shows a preview.
  • •Upon confirmation, resources are provisioned in GCP.
Key Takeaway

The gcloud deployment-manager deployments create command is used to provision resources, with a crucial preview step for safety.

# Deploying the configuration
gcloud deployment-manager deployments create my-first-deployment \
--config my-vm-config.yaml

The Importance of Preview

Before executing, Deployment Manager provides a detailed preview of all changes. This allows you to verify that the planned actions (creations, updates, deletions) align with your intentions, preventing costly mistakes in production environments. Always review this output carefully.
