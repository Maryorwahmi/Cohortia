Updating Deployments and Configuration Drift

Maintaining desired state and avoiding inconsistencies

Updating Process

  • •Modify your configuration or template files to reflect new desired state.
  • •Run gcloud deployment-manager deployments update <deployment-name> --config <new-config.yaml>.
  • •Deployment Manager calculates and applies only necessary changes.
Key Takeaway

Always update deployments through Deployment Manager to prevent configuration drift and maintain your IaC as the single source of truth.

# Updating a deployment
gcloud deployment-manager deployments update my-first-deployment \
--config my-vm-config-v2.yaml

Understanding Configuration Drift

Configuration drift occurs when the actual state of your infrastructure deviates from its defined IaC configuration due to manual changes. This can lead to unexpected behavior during updates, as Deployment Manager might try to revert manual changes or fail due to an inconsistent state. It's a common source of errors and should be strictly avoided.
