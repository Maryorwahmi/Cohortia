Deployment Manager Basics

Configuration and Template Files

The building blocks of Deployment Manager deployments

Configuration File (YAML)

The main blueprint for your deployment. It specifies which resources to create and can reference template files.

  • •Written in YAML.
  • •Defines the overall deployment structure.
  • •Acts as the orchestrator.

Template Files (Jinja2/Python)

Modularize infrastructure code, define parameters, and use conditional logic for reusable resource definitions.

  • •Written in Jinja2 or Python.
  • •Enable reusability and flexibility.
  • •Accept parameters for dynamic deployments.

Example: Reusable VM Template

You can create a Python template for a Compute Engine instance that takes machineType and zone as parameters. This single template can then be used to deploy VMs with different specifications across various environments by simply passing different parameter values in the main configuration file.

Key Takeaway

Combining configuration and template files allows for powerful, modular, and maintainable IaC solutions with Deployment Manager.
