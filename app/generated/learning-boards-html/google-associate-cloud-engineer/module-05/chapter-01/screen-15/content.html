Key Concepts

More essential terms to remember

Canary Deployment

A risk-averse strategy where a small percentage of user traffic is routed to a new version for gradual rollout.

Manual Deployment

The process of deploying an application by hand, typically involving SSH and manual command execution.

Automated Deployment

Using scripts and tools to deploy applications consistently and repeatedly, reducing human error.

Summary Takeaway

Automated deployments, leveraging tools like startup scripts and strategies like canary releases, are crucial for efficient and reliable cloud operations.
