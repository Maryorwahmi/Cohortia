Automating VM Setup with Startup Scripts

Ensuring consistent configuration upon instance boot

File: startup-script.sh
#!/bin/bash
sudo apt-get update
sudo apt-get install -y python3 python3-pip git
git clone https://github.com/your-repo/my-flask-app.git /opt/my-flask-app
cd /opt/my-flask-app
pip3 install -r requirements.txt
gunicorn --bind 0.0.0.0:8000 app:app &
Script Explanation

This script automates software installation, application cloning, dependency management, and application startup, ensuring a fully configured VM on boot.

Terminal: Deploying VM with Script
# Deploy a VM with the startup script
gcloud compute instances create my-auto-web-app \
    --project=your-gcp-project-id \
    --zone=us-central1-a \
    --machine-type=e2-medium \
    --image-family=debian-11 \
    --image-project=debian-cloud \
    --tags=http-server \
    --metadata-from-file=startup-script=startup-script.sh
Deployment Explanation

The --metadata-from-file flag attaches our startup script to the new VM instance, which will execute automatically upon creation and every subsequent reboot.

Key Takeaway

Startup scripts are a powerful way to automate VM configuration, ensuring consistent and repeatable application deployments without manual intervention.
