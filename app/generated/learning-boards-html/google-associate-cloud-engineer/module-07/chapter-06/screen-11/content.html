Shared Responsibility Model: Cloud Compliance

Understanding Google's and your roles in security and compliance

Core Principle

Security and compliance in the cloud are a shared responsibility between the cloud provider (Google) and the customer (you).

Clear Delineation

Google secures the underlying cloud infrastructure, while customers secure their data, applications, and configurations within the cloud.

Critical Understanding

Misunderstanding this model can lead to compliance gaps and security vulnerabilities in your cloud environment.

Google's Responsibility

Security OF the Cloud: Infrastructure, hardware, software, networking, facilities.

Customer's Responsibility

Security IN the Cloud: Data, applications, OS, network config, IAM, service config.

Key Takeaway

The Shared Responsibility Model clearly defines that Google secures the cloud's foundation, while customers are accountable for securing their specific resources and configurations within the cloud.
