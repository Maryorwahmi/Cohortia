Disabling External IPs: A gcloud Example

Applying a policy to restrict Compute Engine external IP access

Policy Objective

Prevent the creation of Compute Engine instances with external IP addresses for enhanced security.

YAML Definition

The policy is defined in a YAML file, specifying the constraint (compute.vmExternalIpAccess) and rules.

Application

Use gcloud org-policies set-policy to apply the YAML file, typically at the Organization or Folder level.

# Create policy.yaml to deny all external IP access
name: projects/my-gcp-project-123/policies/compute.vmExternalIpAccess
spec:
  rules:
  - enforce: true
    values:
      deniedValues:
      - '*' # Deny all external IP access
# Apply the policy
gcloud org-policies set-policy policy.yaml

Important:

For broad enforcement, apply this policy at the Organization or Folder level using --organization or --folder.

Key Takeaway

Implementing an Organization Policy to disable external IPs is a critical security measure, enforced programmatically via gcloud and a YAML definition, ideally at a high level of the resource hierarchy.
