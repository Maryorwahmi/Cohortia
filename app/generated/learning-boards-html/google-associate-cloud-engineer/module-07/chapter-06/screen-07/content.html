Managing Policies with gcloud: Overview

Viewing and applying policies via the command line

Key Commands

gcloud org-policies describe to view and gcloud org-policies set-policy to apply policies.

Policy Definition

Policies are typically defined in YAML files, specifying constraints and allowed/denied values.

Best Practice

Apply policies at the Organization or Folder level for broad and consistent enforcement, using project-level overrides sparingly.

# View an Organization Policy
gcloud org-policies describe compute.vmExternalIpAccess \
    --project=my-gcp-project-123 --format=yaml
# Apply an Organization Policy from a YAML file
gcloud org-policies set-policy policy.yaml

Note on Scope:

For Organization or Folder level policies, use --organization=ORGANIZATION_ID or --folder=FOLDER_ID instead of --project.

Key Takeaway

The gcloud CLI is essential for managing Organization Policies, allowing you to describe and set constraints programmatically, with a strong emphasis on applying them at higher levels of the resource hierarchy.
