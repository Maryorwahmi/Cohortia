What is a 'Finding'?

A finding is a detected security issue, vulnerability, or threat reported by SCC. It's the primary output of SCC's monitoring and analysis.

Key Attributes of a Finding

  • Severity: Critical, High, Medium, Low (for prioritization).
  • Type: Vulnerability, Misconfiguration, Threat, Compliance (for root cause).
  • Details: Affected resource, specific issue, remediation recommendations.

Why Findings Matter

Findings provide the actionable intelligence needed to understand and address security risks, enabling informed decision-making and efficient response.

CriticalSource: Security Health Analytics

Open Firewall Port

A firewall rule is configured to allow ingress traffic from '0.0.0.0/0' (all IP addresses) on port 22 (SSH).

Affected Resource: projects/my-project-123/global/firewalls/default-allow-ssh

Category: Misconfiguration

Remediation Recommendation

Restrict the source IP ranges for SSH access to only trusted networks or specific IP addresses.

Key Takeaway

Findings are the actionable output of SCC, providing categorized details and remediation steps for security issues.
