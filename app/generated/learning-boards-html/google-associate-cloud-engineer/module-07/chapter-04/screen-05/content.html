Rule Components

Anatomy of a Firewall Rule: Direction, Action, Priority

Understanding how rules are evaluated and applied.

Key Components Explained

  • •Direction: Specifies if the rule applies to incoming (ingress) or outgoing (egress) traffic.
  • •Action: Determines whether to allow or deny traffic that matches the rule criteria.
  • •Priority: A numerical value (0-65535) where lower numbers indicate higher precedence.
Evaluation Logic

If multiple rules match a packet, the rule with the highest priority (lowest numerical value) wins.

Visualizing Rule Flow

Ingress: Traffic entering your instances.

Egress: Traffic leaving your instances.

Allow: Permit traffic flow.

Deny: Block traffic flow.

Key Takeaway

Firewall rules use direction (ingress/egress), action (allow/deny), and priority (lower number = higher precedence) to control network traffic.
