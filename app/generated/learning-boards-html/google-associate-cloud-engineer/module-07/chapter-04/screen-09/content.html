Hierarchical Firewall Policies: Organization-Wide Security

Enforcing consistent rules across projects and folders.

What are Hierarchical Firewall Policies?

  • •Centralized control for firewall rules across an organization.
  • •Defined at the Organization or Folder level in the resource hierarchy.
  • •Inherited by all child projects and VPC networks.
Key Benefit

Allows security administrators to enforce consistent firewall rules across the entire organization, overriding or augmenting project-level rules.

Policy Evaluation Order

1. Organization/Folder Policies: Evaluated first, giving them precedence.

2. VPC Network Firewall Rules: Evaluated after hierarchical policies.

Use Case

Enforce an organization-wide rule to block all egress traffic to certain malicious IP ranges.

Key Takeaway

Hierarchical Firewall Policies provide centralized, inherited control over network security, evaluated before project-level VPC rules.
