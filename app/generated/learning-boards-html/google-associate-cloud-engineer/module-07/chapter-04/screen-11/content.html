Introducing Cloud Armor: DDoS Protection and WAF

Safeguarding applications from DDoS attacks and web vulnerabilities.

What is Cloud Armor?

  • •A global DDoS protection service.
  • •A Web Application Firewall (WAF) service.
  • •Integrates with GCP's global external HTTP(S) Load Balancers.
Primary Role

Protects your applications by absorbing and scrubbing malicious traffic before it reaches your backend services.

Why Cloud Armor?

DDoS Protection: Defends against volumetric attacks, ensuring availability.

WAF Capabilities: Protects against common web vulnerabilities like SQL injection and XSS.

Integration

Cloud Armor policies are attached to the backend services of an external HTTP(S) Load Balancer.

Key Takeaway

Cloud Armor provides essential DDoS protection and WAF capabilities for public-facing applications, integrating with GCP's HTTP(S) Load Balancers.
