Advanced Features

Defending Against Threats: Cloud Armor Policies and Rules

Configuring WAF rules and IP-based access control.

Cloud Armor Capabilities

  • •DDoS Attacks: Absorbs and scrubs malicious traffic.
  • •OWASP Top 10: Pre-configured WAF rules protect against common vulnerabilities (SQLi, XSS).
  • •IP-based Access Control: Allow/deny traffic based on source IP or geographical location.
  • •Custom Rules: Define rules based on request attributes (headers, URL paths).
Integration Point

Cloud Armor policies are attached to the backend services of an external HTTP(S) Load Balancer.

gcloud Example: Cloud Armor Policy

# Create a Cloud Armor security policy
gcloud compute security-policies create my-web-app-policy \
    --description="Policy for my web application"

# Add a rule to block traffic from a specific IP range
gcloud compute security-policies rules create 1000 \
    --security-policy=my-web-app-policy \
    --expression="origin.ip_ranges['192.0.2.0/24']" \
    --action=deny \
    --description="Block known attacker IP" \
    --priority=1000
Scenario

This policy blocks traffic originating from the 192.0.2.0/24 IP range, protecting your web application from known malicious sources.

Key Takeaway

Cloud Armor provides comprehensive protection against DDoS and web vulnerabilities through customizable policies, IP-based controls, and OWASP Top 10 rules.
