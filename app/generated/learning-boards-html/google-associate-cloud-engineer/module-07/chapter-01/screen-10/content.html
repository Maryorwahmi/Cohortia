Managing IAM with `gcloud` - Granting Roles

Use the gcloud command-line tool to add IAM policy bindings and assign roles.

Key `gcloud` Command for Granting Roles

  • gcloud projects add-iam-policy-binding: Attaches a role to a member on a specific project.
  • --member='user:EMAIL': Specifies the user's Google account. Use serviceAccount:EMAIL for service accounts.
  • --role='roles/ROLE_NAME': Specifies the canonical name of the role to grant.
Key Takeaway

The gcloud projects add-iam-policy-binding command is essential for programmatically assigning roles and managing access control in GCP.

`gcloud` Command Example: Granting Compute Viewer Role

# Grant 'compute.viewer' role to alice@example.com on a project
gcloud projects add-iam-policy-binding my-gcp-project-123 \
--member='user:alice@example.com' \
--role='roles/compute.viewer' \
--condition=None

Explanation:

This command adds a policy binding to my-gcp-project-123, allowing alice@example.com to view Compute Engine resources. The --condition=None part is a placeholder for advanced conditional IAM, which we'll cover later.
