Understanding IAM Members

Members are the 'who' in GCP IAM, representing various identities that can be granted access to resources.

Types of IAM Members

  • Google Account: An end-user, like alice@example.com.
  • Service Account: An identity for applications or VMs, e.g., my-app@project.iam.gserviceaccount.com.
  • Google Group: A collection of Google accounts and service accounts, e.g., devs@example.com.
  • Domain: All users in a Google Workspace or Cloud Identity domain, e.g., example.com.
Key Takeaway

Selecting the appropriate member type is crucial for efficient and secure IAM management, especially distinguishing between human users and automated services.

Member Types & Use Cases

Google Account

Individual users, administrators.

Service Account

Applications, VMs, automation.

Google Group

Managing multiple users efficiently.

Cloud Identity Domain

All users within an organization.

Example Scenario:

For a new development team, create a Google Group dev-team@example.com and grant it the necessary roles. Add or remove individual developers from this group as needed, rather than updating IAM policies for each person.
