Key Concepts: Data Encryption

Essential terms for securing data at rest and in transit.

Data at Rest Encryption

Protecting data stored on physical media, ensuring its confidentiality when not actively being used.

Data in Transit Encryption

Protecting data as it moves across networks, safeguarding it during transmission between systems.

Google-Managed Encryption Keys (GMEK)

Default encryption where Google manages the keys, providing automatic and transparent data protection.

Customer-Managed Encryption Keys (CMEK)

Encryption where customers manage keys using Cloud KMS, offering enhanced control over key lifecycle.

Summary Takeaway

Effective data security in GCP relies on understanding and applying the right encryption strategy for both data at rest and in transit, balancing control with operational ease.
