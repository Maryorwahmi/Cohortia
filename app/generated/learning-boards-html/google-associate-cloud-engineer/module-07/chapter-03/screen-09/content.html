Bucket Configuration

Configuring a Cloud Storage Bucket with CMEK

Assigning your managed key as the default for a storage bucket.

# Set the default KMS key for a Cloud Storage bucket
gcloud storage buckets update gs://my-data-bucket \
    --default-kms-key=projects/my-gcp-project-123/locations/global/keyRings/my-keyring/cryptoKeys/my-cmek-key
Key Takeaway

Setting a default KMS key on a bucket ensures all new objects are automatically encrypted with your CMEK key, simplifying policy enforcement.

Verifying CMEK Configuration

Confirming your data is encrypted with your key.

Upload a Test File

After setting the default key, upload a small file to the bucket to test the encryption.

Verify in GCP Console

Navigate to the object's details in Cloud Storage and check the 'Encryption' section to confirm your CMEK key is listed.
