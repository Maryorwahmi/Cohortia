Audit Log Type

Data Access Logs: Auditing Sensitive Data Interactions

These logs record API calls that read or write user-provided data, essential for auditing sensitive information.

  • •Disabled by Default: Must be explicitly enabled due to volume and potential cost.
  • •Compliance Critical: Vital for meeting regulatory requirements for data access.
  • •Service Specific: Enable for services like Cloud Storage, BigQuery, Cloud SQL.
Key Takeaway

Always enable Data Access Logs for resources containing sensitive data to ensure a complete audit trail for compliance and security.

Common Mistake

Not enabling Data Access logs for sensitive resources creates critical blind spots in your auditing capabilities.
