Exporting Logs with Log Sinks

Log sinks allow you to export log entries from Cloud Logging to various destinations for long-term retention and analysis.

  • •Cloud Storage: Ideal for cost-effective, long-term archival and compliance.
  • •BigQuery: Enables advanced analytics and complex querying of log data.
  • •Cloud Pub/Sub: For real-time streaming to external SIEM systems or custom applications.
Key Takeaway

Log Sinks are crucial for meeting compliance requirements and enabling in-depth security analysis beyond Cloud Logging's default retention.

Common Mistake

Failing to configure log sinks can lead to critical logs being deleted after the default retention period, hindering forensic analysis.

user@cloudshell:~/$
# Example: Create a log sink to export all audit logs to a BigQuery dataset
gcloud logging sinks create my-audit-sink bigquery.googleapis.com/projects/my-gcp-project-123/datasets/audit_logs_dataset \
    --log-filter='logName:"cloudaudit.googleapis.com"' \
    --project=my-gcp-project-123
This command creates a sink to send all audit logs to a BigQuery dataset for advanced querying.
