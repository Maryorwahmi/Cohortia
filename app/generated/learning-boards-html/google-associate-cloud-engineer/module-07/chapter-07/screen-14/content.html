Key Concepts: Auditing and Logging

Reinforce your understanding of the core components for security auditing and log management.

Cloud Audit Logs

Logs recording administrative activities, data access, and system events in GCP.

Admin Activity Logs

Record configuration changes to GCP resources (always enabled, free).

Data Access Logs

Record read/write access to user-provided data (requires explicit enablement).

Summary Takeaway

Cloud Audit Logs are the immutable record of activity, with Admin Activity and System Event logs always on, and Data Access logs requiring explicit enablement for sensitive data.
