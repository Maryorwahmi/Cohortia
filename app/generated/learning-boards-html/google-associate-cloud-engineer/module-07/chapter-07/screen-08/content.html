Audit Log Type

System Event Logs: Google Cloud's Internal Activity

These logs record Google Cloud system events that modify resources, providing insight into platform-level operations.

  • •Always Enabled: Automatically collected, similar to Admin Activity Logs.
  • •Free of Charge: No cost for generation or storage.
  • •System-Initiated: Focus on actions by Google Cloud itself, not direct user actions.
Key Takeaway

System Event Logs offer transparency into Google Cloud's operational activities, completing the comprehensive audit picture.

Example System Events

Automatic VM migrations, internal system updates to managed services, or resource reconfigurations by Google Cloud.
