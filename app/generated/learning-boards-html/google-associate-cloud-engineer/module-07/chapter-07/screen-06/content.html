Audit Log Type

Admin Activity Logs: Tracking Configuration Changes

These logs record API calls or administrative actions that modify the configuration or metadata of resources.

  • •Always Enabled: Automatically collected for all GCP services.
  • •Free of Charge: No cost associated with their generation or storage.
  • •Crucial for 'Who Did What': Essential for understanding administrative changes.
Key Takeaway

Admin Activity Logs are your primary source for auditing changes to your GCP infrastructure and security policies.

Example Actions Logged

Creating a VM instance, changing an IAM role, updating a firewall rule, or configuring a new Cloud Storage bucket.
