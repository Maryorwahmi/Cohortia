Role Types

Fine-Grained Control: Predefined and Custom Roles

Achieving least privilege with service-specific and tailored permissions.

Predefined Roles

Service-specific roles with fine-grained permissions, designed for common use cases.

  • •`roles/compute.instanceAdmin`: Manage Compute Engine instances.
  • •`roles/storage.objectViewer`: Read objects from Cloud Storage.
  • •Ideal for adhering to the principle of least privilege.

Custom Roles

User-defined roles with a precise set of permissions, tailored for unique requirements.

  • •Define exact permissions when predefined roles are insufficient.
  • •Example: A role that only allows creating specific VM types.
  • •Ultimate expression of the least privilege principle.
Key Takeaway

Predefined and custom roles provide the granular control necessary to implement the principle of least privilege, offering service-specific or precisely tailored permissions for secure operations.
