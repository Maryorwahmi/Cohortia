Building Blocks of a Compute Engine Instance

Understanding machine types and durable persistent disks.

Machine Types

  • Defines CPU, memory, and optional GPU resources.
  • Predefined types (e.g., e2-medium) or custom configurations.
  • Crucial for matching compute power to workload demands.
  • Example: 'e2-medium' provides 2 vCPUs and 4 GB memory.

Persistent Disks

  • Durable block storage for VM instances.
  • Persist independently of VM lifecycle.
  • Types: Standard HDD, Balanced SSD, Performance SSD.
  • Essential for data integrity and application state.
Practical Consideration

Choosing the right machine type and disk combination directly impacts performance and cost. Over-provisioning can lead to unnecessary expenses, while under-provisioning can cause performance bottlenecks.

Key Takeaway

Machine types define a VM's compute resources, while persistent disks provide durable storage, both critical for configuring robust and efficient Compute Engine instances.
