Launching a Compute Engine VM with gcloud CLI

Provisioning a web server instance using a single command.

gcloud compute instances create webserver-1 \
    --machine-type=e2-medium \
    --image-family=debian-11 \
    --image-project=debian-cloud \
    --zone=us-central1-a \
    --network=my-custom-vpc \
    --subnet=my-subnet-us-central \
    --tags=web-server \
    --metadata=startup-script="#! /bin/bash
        sudo apt-get update
        sudo apt-get install -y nginx
        echo \"Hello from Cohortia Webserver!\" | sudo tee /var/www/html/index.nginx-debian.html
        sudo systemctl start nginx"

Command Breakdown

  • `--machine-type`: Specifies CPU and memory (e.g., `e2-medium`).
  • `--image-family`: Selects the OS image (e.g., `debian-11`).
  • `--zone`: Defines the deployment region (e.g., `us-central1-a`).
  • `--metadata=startup-script`: Executes commands on VM boot, here installing Nginx.
Key Takeaway

The `gcloud compute instances create` command, combined with startup scripts, provides a powerful way to automate the provisioning and initial configuration of Compute Engine VMs.
