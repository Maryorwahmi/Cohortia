Essential Compute Concepts

A quick review of the core terms from this chapter.

Compute Engine

GCP's Infrastructure as a Service (IaaS) offering for virtual machines, providing maximum control.

VM Instance

A virtual server running on Compute Engine, offering a customizable environment for your applications.

Machine Type

Defines the CPU, memory, and optional GPU resources allocated to a Compute Engine VM.

Summary Takeaway

Compute Engine, VM instances, and machine types are fundamental concepts for understanding and managing virtualized infrastructure on GCP.
