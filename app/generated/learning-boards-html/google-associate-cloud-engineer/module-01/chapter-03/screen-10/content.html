External IP Types: Ephemeral vs. Static

Choosing the right public IP for your services.

Ephemeral IP

Automatically assigned for the lifetime of an instance and released upon termination. Changes on restart.

Static IP

Reserved and assigned permanently until manually released. Remains consistent across instance lifecycle.

Common Pitfall

Using ephemeral IPs for services requiring a stable public endpoint can lead to service disruptions when the IP address changes unexpectedly.

Key Takeaway

Choose static external IPs for publicly accessible services requiring consistent addresses, and ephemeral IPs for temporary or non-public-facing resources.

External IP Lifecycle
Ephemeral IP
  • Assigned on instance start
  • Released on instance stop/delete
  • IP address changes
Static IP
  • Reserved and assigned
  • Persists across instance lifecycle
  • IP address remains constant
Use Case Example

A public-facing web server should always use a static external IP to ensure consistent access for users and DNS records.
