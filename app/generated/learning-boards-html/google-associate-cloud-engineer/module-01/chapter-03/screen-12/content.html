Creating a Custom VPC Network

Setting up your isolated network environment.

Why Custom?

Provides better control, security, and organization compared to the default VPC network.

`--subnet-mode=custom`

Crucial flag indicating that subnets will be manually defined, not auto-generated.

Example Use Case

Create a custom VPC named my-app-vpc to host all resources for a specific application, ensuring logical separation from other projects.

Key Takeaway

The gcloud compute networks create command with --subnet-mode=custom is the first step to building a controlled and organized GCP network.

Terminal Demo: Create VPC
$ gcloud config set project YOUR_PROJECT_ID
$ gcloud compute networks create my-custom-vpc \
--subnet-mode=custom \
--description="A custom VPC network for Cohortia labs."
Output:
Created [https://www.googleapis.com/compute/v1/projects/YOUR_PROJECT_ID/global/networks/my-custom-vpc].
NAME            SUBNET_MODE  BGP_ROUTING_MODE  IPV4_RANGE  GATEWAY_IPV4
my-custom-vpc  CUSTOM       REGIONAL_DEFAULT
