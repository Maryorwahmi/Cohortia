Firewall Configuration

Firewall Rule Criteria

Defining traffic policies with precision.

Sources/Destinations

Specify IP ranges (CIDR blocks), network tags, or service accounts to identify traffic origins or targets.

Protocols & Ports

Define specific protocols (TCP, UDP, ICMP) and port numbers (e.g., TCP:80 for HTTP, TCP:22 for SSH).

Common Mistake

Using overly permissive source IP ranges like 0.0.0.0/0 for all services can expose resources to unnecessary risks. Always follow the principle of least privilege.

Key Takeaway

Precise firewall rules are built by combining direction, action, priority, specific sources/destinations, and protocols/ports.

Firewall Rule Components
Direction

Ingress (inbound) or Egress (outbound)

Action

ALLOW or DENY

Priority

Numerical value (0-65535), lower is higher

Sources/Destinations

IP ranges, network tags, service accounts

Protocols & Ports

TCP, UDP, ICMP, specific port numbers
