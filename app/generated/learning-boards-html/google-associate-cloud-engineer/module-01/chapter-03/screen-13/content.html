Creating Regional Subnets

Segmenting your VPC across different regions.

Regional Scope

Subnets are created within specific GCP regions, allowing for localized resource deployment.

IP Range (`--range`)

Defines the CIDR block for the subnet, from which internal IP addresses are allocated.

Example Scenario

Create a subnet in us-central1 for web servers and another in europe-west1 for database servers, all within the same VPC.

Key Takeaway

Using gcloud compute networks subnets create, you can define regional subnets within your global VPC, enabling distributed application architectures.

Terminal Demo: Create Subnets
$ gcloud compute networks subnets create my-subnet-us-central \
--network=my-custom-vpc \
--range=10.10.0.0/20 \
--region=us-central1 \
--description="Subnet in us-central1 for web servers."
Output:
Created [https://www.googleapis.com/compute/v1/projects/YOUR_PROJECT_ID/regions/us-central1/subnetworks/my-subnet-us-central].
NAME                  REGION        NETWORK        RANGE
my-subnet-us-central  us-central1   my-custom-vpc  10.10.0.0/20
$ gcloud compute networks subnets create my-subnet-europe-west \
--network=my-custom-vpc \
--range=10.20.0.0/20 \
--region=europe-west1 \
--description="Subnet in europe-west1 for database servers."
Output:
Created [https://www.googleapis.com/compute/v1/projects/YOUR_PROJECT_ID/regions/europe-west1/subnetworks/my-subnet-europe-west].
NAME                    REGION         NETWORK        RANGE
my-subnet-europe-west   europe-west1   my-custom-vpc  10.20.0.0/20
