Network Segmentation

Subnets: Regional IP Allocation

Logically segmenting your VPC network within a region.

Regional Resource

Each subnet is tied to a specific GCP region, providing localized network control.

IP Address Range

Each subnet has a unique CIDR block (e.g., 10.10.0.0/24) from which resources get internal IPs.

Logical Segmentation

Allows you to group resources (e.g., web servers, databases) within a region for better management.

Key Takeaway

Subnets are regional components of a global VPC, providing specific IP ranges for resources and enabling granular network segmentation.
