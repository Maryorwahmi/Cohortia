Key Concepts: Traffic & IPs

Understanding traffic control and addressing types.

Ingress/Egress Rules

Control inbound (Ingress) and outbound (Egress) traffic to/from your GCP resources.

Network Tag

A label attached to Compute Engine instances, used to target specific instances in firewall rules.

IP Addresses

Internal IPs for VPC communication, External IPs for internet access (Ephemeral or Static).

Chapter Summary

Effective network security in GCP involves understanding traffic direction, leveraging network tags for dynamic rule application, and choosing appropriate IP address types for internal and external communication.
