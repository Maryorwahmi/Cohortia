Cloud Debugger: Live Production Debugging

Inspect running application state without interruption.

Key Capabilities

  • Live Snapshots: Capture application state at specific lines of code in production.
  • No Redeployment: Debug without stopping or redeploying your application.
  • Minimal Overhead: Designed to have negligible impact on application performance.
  • Logpoints: Log variable values without modifying code or restarting.
Key Takeaway

Cloud Debugger bridges the gap between development and production, enabling efficient, non-disruptive debugging of live applications.

Example: Intermittent Production Bug

A bug only appears under high load in production. Use Cloud Debugger to capture variable states at the exact moment of failure without impacting users.

Diagnose Elusive Issues
Pro-Tip

Use logpoints to gather diagnostic information without modifying code, especially for issues that are hard to reproduce.
