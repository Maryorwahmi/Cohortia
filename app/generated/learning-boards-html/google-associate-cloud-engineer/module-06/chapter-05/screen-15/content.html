Key Concepts

Essential terms to remember

Span

A logical unit of work within a trace, representing an operation or segment of a request.

Instrumentation

The process of adding code to an application to collect tracing data (spans) for observability.

Cloud Debugger

Google Cloud's service for live debugging of production applications without stopping them.

Summary Takeaway

Cloud Debugger, with its snapshot and logpoint features, provides powerful, non-disruptive live debugging capabilities for production environments.
