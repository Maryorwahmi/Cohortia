Instrumenting Applications for Cloud Trace

Enabling your code to send tracing data

What is Instrumentation?

The process of adding code or configuration to an application to collect and export tracing data (spans) to a tracing backend like Cloud Trace.

Methods of Instrumentation

  • Automatic: For many GCP services (App Engine, Cloud Run).
  • Manual: Using client libraries (OpenCensus, OpenTelemetry) for custom apps.
Key Takeaway

Proper instrumentation is fundamental for Cloud Trace to gather and visualize your application's distributed request data.
