Traces and Spans: Building Blocks of Observability

Understanding the hierarchical structure of a request

Trace Definition

A trace represents a single, end-to-end request or workflow as it executes across multiple services in a distributed system.

Span Definition

A span is a logical unit of work within a trace, representing an operation like an API call, database query, or function execution.

Key Takeaway

Traces are composed of hierarchical spans, providing a detailed, time-based view of request execution.

Trace and Span Hierarchy

Trace: User Checkout Request
Span: Process Order (Service A)
Child Span: Database Query
Child Span: External API Call
Span: Send Confirmation (Service B)
