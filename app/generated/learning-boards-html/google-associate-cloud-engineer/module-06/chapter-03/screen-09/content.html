Metric Query Language (MQL)

Unlocking complex transformations and aggregations for time-series data.

What is MQL?

A powerful, expressive language similar to SQL, but tailored for time-series data in Cloud Monitoring.

Key Capabilities

Perform complex transformations, aggregations, joins, and create custom metrics on the fly.

Key Takeaway

MQL provides unparalleled flexibility for sophisticated monitoring scenarios and deep data insights.

MQL vs. Metrics Explorer
Metrics Explorer

Visual builder, basic queries, quick insights.

Metric Query Language

Code-based, complex logic, custom metrics.
