Built-in Metrics

Navigating Built-in Metrics

Understanding resource types and metric types for automatic data collection.

Resource Type

The specific GCP entity emitting the metric (e.g., gce_instance, cloud_run_revision).

Metric Type

The specific measurement being collected (e.g., compute.googleapis.com/instance/cpu/utilization).

Key Takeaway

Built-in metrics provide immediate, zero-config insights, categorized by resource and metric types.

Example: CPU Utilization
Compute Engine Instance
Resource Type:

gce_instance

Metric Type:

compute.googleapis.com/instance/cpu/utilization

This combination provides the CPU usage percentage for a specific VM instance.
