Understanding Metric Cardinality

Impact on monitoring costs and performance, and how to avoid common mistakes.

What is Cardinality?

The number of unique combinations of label values for a given metric, directly impacting monitoring costs and performance.

Common Mistake

Using high-cardinality labels (e.g., unique user IDs) for every event, leading to excessive costs and performance issues.

Key Takeaway

Design custom metrics with low-cardinality labels for efficient and cost-effective monitoring.

Cardinality Impact
High Costs

More unique time series = higher storage and processing costs.

Performance Degradation

Complex queries on vast data sets slow down dashboards and analysis.

Actionable Labels

Use labels like region, version, tier for meaningful aggregation.

Focused Dashboards

Avoid 'dashboard sprawl' by focusing on critical KPIs.
