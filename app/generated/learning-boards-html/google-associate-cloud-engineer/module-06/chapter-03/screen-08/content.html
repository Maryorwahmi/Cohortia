Exploring Metrics with Metrics Explorer

Your primary interface for querying, visualizing, and analyzing metric data.

Key Capabilities

Select resource/metric types, apply filters (e.g., instance_name, zone), aggregate data, and group by labels.

Aggregation Options

Choose aggregators like mean, sum, max over various time windows (1 hour, 1 day, 1 week).

Key Takeaway

Metrics Explorer is your interactive workbench for understanding system performance trends.
