MQL in Action: Percentile Latency Query

Calculating the 99th percentile of HTTP response latency with MQL.

Query Goal

Determine the 99th percentile of HTTP response latencies for a load balancer, indicating user experience for slower requests.

Key MQL Clauses

fetch (data source), metric (specific measurement), group_by (aggregation and percentile calculation), align (time alignment).

Key Takeaway

MQL allows for highly specific and statistically advanced analysis of your monitoring data.

MQL Query: 99th Percentile Latency
fetch global
| metric 'loadbalancing.googleapis.com/https/response_latencies'
| group_by 1m, [value_response_latencies_mean: percentile(value.response_latencies, 99)]
| align rate(1m)
| every 1m
| group_by [], [value_response_latencies_mean_mean: mean(value_response_latencies_mean)]
This query retrieves load balancer latency, calculates the 99th percentile, and aggregates it.
