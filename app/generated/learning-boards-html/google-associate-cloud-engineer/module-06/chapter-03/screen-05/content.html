Metric Types

Differentiating Metric Types

Built-in, Custom, and Agent-based metrics for comprehensive coverage.

Built-in Metrics

Automatically collected from GCP services (e.g., CPU utilization for Compute Engine, request counts for Load Balancers).

Custom Metrics

Defined and collected by users for application-specific KPIs (e.g., active user sessions, business transaction rates).

Cloud Monitoring Agent

Installed on VMs to collect detailed system metrics (e.g., memory utilization, disk I/O, process metrics).

Key Takeaway

A robust monitoring strategy combines all three metric types to achieve full observability.

Metric Collection Flow
Different sources feed metrics into Cloud Monitoring for a unified view.
