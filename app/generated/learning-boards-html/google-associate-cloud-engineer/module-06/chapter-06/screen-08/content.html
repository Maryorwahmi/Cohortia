Querying Cloud Audit Logs

Using Log Explorer to find specific audit events.

Accessing Logs

Cloud Audit Logs are accessible through the Google Cloud Log Explorer, alongside other operational logs.

  • •Navigate to `Operations > Logging > Log Explorer`.
  • •The `logName` field differentiates audit log types.
Key Takeaway

Mastering `logName` filtering is essential for efficient audit log analysis.

Filtering Admin Activity Logs
logName="projects/YOUR_PROJECT_ID/logs/cloudaudit.googleapis.com%2Factivity"

This query targets all Admin Activity logs for a specified project. Replace `YOUR_PROJECT_ID` with your actual project ID.

LogName Field Values
  • •`cloudaudit.googleapis.com/activity` (Admin Activity)
  • •`cloudaudit.googleapis.com/data_access` (Data Access)
  • •`cloudaudit.googleapis.com/system_event` (System Event)
