Data Access Logs

Auditing interactions with user-provided data.

What they record

These logs capture API calls that read or modify user-provided data within GCP services.

  • •Disabled by default; must be explicitly enabled.
  • •Can generate large volumes of data and incur costs.
  • •Critical for data governance and compliance.
Key Takeaway

Enable Data Access logs judiciously for sensitive resources to balance auditing with cost.

Common Use Cases
  • •**Compliance:** Meeting requirements for HIPAA, PCI DSS, GDPR, etc.
  • •**Data Governance:** Ensuring proper handling and access to sensitive information.
  • •**Security Incident Response:** Detecting unauthorized data exfiltration or modification.
Example Actions Logged
  • •Reading an object from a Cloud Storage bucket.
  • •Querying data from a BigQuery table.
  • •Accessing a secret from Secret Manager.
  • •Modifying data in a Cloud SQL database.
