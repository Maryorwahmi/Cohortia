Admin Activity Logs

Tracking configuration and metadata changes.

What they record

These logs capture API calls and administrative actions that modify the configuration or metadata of your GCP resources.

  • •Always enabled by default; cannot be disabled.
  • •Free of charge.
  • •Essential for understanding infrastructure changes.
Key Takeaway

Admin Activity logs are your baseline for tracking all structural changes in your GCP environment.

Common Use Cases
  • •**Infrastructure Auditing:** Reviewing all changes made to VMs, networks, and databases.
  • •**Security Investigations:** Identifying who modified IAM policies or firewall rules.
  • •**Troubleshooting:** Pinpointing recent configuration changes that might have caused an issue.
Example Actions Logged
  • •Creating or deleting a Compute Engine instance.
  • •Deploying a Cloud Function or App Engine application.
  • •Changing IAM roles or permissions on a project.
  • •Modifying network configurations like VPCs or subnets.
