Log Sinks

Common Log Sink Destinations

Choosing the right destination for your exported log data.

Cloud Storage

Ideal for cost-effective, long-term archival of raw log data for compliance.

Use Case

Compliance archival, raw data backup.

BigQuery

Enables advanced analytics and complex SQL queries over petabytes of log data.

Use Case

Historical analysis, trend identification, custom reporting.

Pub/Sub

Enables real-time streaming of logs to other applications for immediate processing.

Use Case

Real-time alerts, security analysis, triggering automated workflows.
