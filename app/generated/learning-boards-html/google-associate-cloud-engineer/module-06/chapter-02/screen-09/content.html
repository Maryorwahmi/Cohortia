Advanced Querying with Log Explorer

Leveraging the powerful query language for precise log analysis.

Filter by Resource

Target logs from specific GCP services or resource types (e.g., resource.type="gce_instance").

Filter by Severity

Isolate logs based on their severity level (e.g., severity=ERROR, severity>=WARNING).

Query JSON Fields

Access specific fields within structured log payloads (e.g., jsonPayload.user_id="alice.smith").

Log Explorer Query Syntax
// Filter by resource type and severity
resource.type="gce_instance"
severity=ERROR

// Filter by specific JSON payload field
jsonPayload.user_id="john.doe"

// Combine conditions with boolean operators
resource.type="cloud_run_revision" AND severity>=WARNING

// Text search within log entry
"database connection failed"

// Using comparison operators
latency > 100ms
