Creating a Log Sink with gcloud CLI

A step-by-step guide to exporting logs to BigQuery.

Command

Use gcloud logging sinks create to define and activate a log export.

Log Filter

Specify which logs to export using a powerful query language (e.g., severity=ERROR).

Permissions

Grant the sink's service account appropriate IAM roles on the destination resource.

gcloud CLI Command
gcloud logging sinks create my-bigquery-sink \
    bigquery.googleapis.com/projects/YOUR_PROJECT_ID/datasets/my_log_dataset \
    --log-filter='severity=ERROR AND resource.type="gce_instance"' \
    --description="Export all GCE error logs to BigQuery" \
    --project=YOUR_PROJECT_ID
Important

Replace YOUR_PROJECT_ID and my_log_dataset with your actual values. Grant BigQuery Data Editor role to the sink's service account.
