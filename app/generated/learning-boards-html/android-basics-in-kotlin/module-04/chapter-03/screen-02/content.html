Learning Objectives

Master data transfer patterns between activities and practice safe retrieval.

Bloom: Learn → Understand → Apply → Master
01
Attach simple extras

Use putExtra to add Strings, Ints, Booleans, and Floats. Practice a short example sending a name from one activity to another.

VERIFIED COMPETENCY MILESTONE
02
Retrieve with matching getters

Use getStringExtra, getIntExtra, and provide defaults. This prevents nulls and makes your UI predictable.

VERIFIED COMPETENCY MILESTONE
03
Pass complex objects

Understand Parcelable and Serializable trade-offs and how to use putExtra with custom objects.

VERIFIED COMPETENCY MILESTONE
04
Handle nulls & defaults

Use safe retrieval patterns and the Elvis operator to supply sensible defaults and avoid crashes.

VERIFIED COMPETENCY MILESTONE
