Hands-on checks

Small, verifiable tasks help confirm you can pass and read data between activities safely.

Task 1
Add an EditText and send the entered name using putExtra. Verify SecondActivity shows the name.
Task 2
Retrieve with getStringExtra and use the Elvis operator to show a default when null.
Task 3
Pass a small Parcelable user object and display its name on arrival.
Why test defaults

Users may navigate without providing data. Testing defaults prevents crashes and shows predictable UI.

Common failure

A mismatched key string or wrong get method often returns null; verify key constants are identical across activities.
