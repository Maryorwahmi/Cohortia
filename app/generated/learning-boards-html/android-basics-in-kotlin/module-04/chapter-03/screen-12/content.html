Checklist to find missing extras
  • Verify the exact key string is identical in sender and receiver.
  • Confirm you used the correct get...Extra method for the value type.
  • For objects, ensure they implement Parcelable or Serializable and you use the matching getter.
  • Check that retrieval code runs in onCreate after setContentView.
  • Log intent.extras to inspect what was actually sent.
Example log
Log.d("IntentExtras", intent.extras?.keySet()?.toString() ?: "no extras")
Pro tip

When debugging, temporarily display debugging text in the UI listing the extras so you can see them without scanning logs.
