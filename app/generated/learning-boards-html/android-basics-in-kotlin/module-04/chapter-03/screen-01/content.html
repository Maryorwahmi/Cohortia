Passing Data Between Activities

Use Intent extras to attach simple values or parcelable objects and restore them in the destination activity. This slide deck teaches patterns, pitfalls, and a short lab so you can practice immediately.

In this lesson
putExtra, get...Extra, Parcelable vs Serializable
Why it matters
Data keeps screens connected and context-aware for users.

Intent Extras
Key-value pairs attached to an Intent for transfer.
Parcelable
Efficient Android interface for serializing objects.
Safe Retrieval
Use matching get methods and defaults to avoid crashes.
Visual overview
Message flow: MainActivity → SecondActivity
Static demo
MainActivity
Collects input, builds Intent, and attaches extras with putExtra using a constant key.
const USER_NAME_KEY = "com.example.mymultiscreenapp.USER_NAME"
SecondActivity
Retrieves extras with getStringExtra or getIntExtra and displays a default if missing.
val name = intent.getStringExtra(USER_NAME_KEY) ?: "Guest"
Tip: Define keys as constants and use matching get methods to avoid nulls and crashes.
