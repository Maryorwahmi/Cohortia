Module 4 › Chapter 4.3 › Retrieve Objects
Pattern for parcelable
val user: User? = intent.getParcelableExtra("USER_DATA")
if (user != null) {
  // safe to use user.name
  showWelcome(user.name)
} else {
  showNoUserMessage()
}
Always treat retrieved objects as nullable and handle the missing case gracefully.
Pattern for serializable
val serial = intent.getSerializableExtra("USER_DATA")
val user = serial as? User
if (user != null) {
  showWelcome(user.name)
} else {
  showNoUserMessage()
}
Note: The safe cast operator as? avoids a ClassCastException if the extra is not the expected type.
