Module 4 › Chapter 4.3 › Lab: Name Transfer
Steps
  1. Edit activity_main.xml: add EditText id="name_input_edit_text" and a button id="btn_go_to_second".
  2. In MainActivity define const val USER_NAME_KEY = "com.example.mymultiscreenapp.USER_NAME" and wire the button to read the EditText and call putExtra.
  3. In activity_second.xml add TextView id="display_name_text_view".
  4. In SecondActivity retrieve the name with intent.getStringExtra(USER_NAME_KEY) ?: "Guest" and set the TextView text.
  5. Run tests: enter a name, navigate, test empty input, and test missing extra.
Example check
If you enter "Sam" and navigate, SecondActivity must display "Hello, Sam!"; with no input it should say "Hello, Guest!"
Common pitfall
Forgetting to define or import the key constant in both activities causes mismatches and returns null without crash.
Key Takeaway

Follow the send → retrieve → fallback pattern and test both present and missing extras.
