Module 4 › Chapter 4.3 › putExtra()
Step-by-step
  1. Define a constant key string to avoid typos.
  2. Read or compute the value to send (text, id, boolean).
  3. Create an Intent to the destination activity.
  4. Call putExtra(key, value) with the appropriate type overload.
  5. Start the activity with startActivity(intent).
Example outcome
When you call putExtra with a String, the destination can use getStringExtra with the same key to retrieve it.
Code example
// In MainActivity.kt
const val USER_NAME_KEY = "com.example.mymultiscreenapp.USER_NAME"

// inside onCreate()
val nameInputEditText: EditText = findViewById(R.id.name_input_edit_text)
val goToSecondButton: Button = findViewById(R.id.btn_go_to_second)

goToSecondButton.setOnClickListener {
  val userName = nameInputEditText.text.toString()
  val intent = Intent(this, SecondActivity::class.java).apply {
    putExtra(USER_NAME_KEY, userName)
  }
  startActivity(intent)
}
Key Takeaway

Always use a constant key and the matching putExtra overload for the value type you intend to send.
