What is an extra?

A small piece of data attached to an Intent as a key-value pair. Keys are strings; values are typed.

Mnemonic
Think dictionary entry: key maps to value you need on the next screen.
Common types supported:
  • String, Int, Boolean, Float
  • Parcelable or Serializable objects for custom types
Key takeaway
Keep extras minimal and explicit; send the smallest data needed to render the next screen.
Concrete example

MainActivity sends an item id to DetailActivity so the detail screen fetches and shows the correct item.

Scenario
A shopping app passes productId=42 to the product screen, which then loads the product details from a repository.
Key Takeaway

Extras are ideal for passing small, explicit data that the next activity requires to render its UI.

Common mistake
Trying to pass large datasets via extras instead of using a shared data source or ID reference.
