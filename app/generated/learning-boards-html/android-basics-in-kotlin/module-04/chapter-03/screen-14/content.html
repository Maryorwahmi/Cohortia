Module 4 › Chapter 4.3 › Key Concepts
Intent Extras
Key-value pairs you attach to an Intent to carry data between activities.
putExtra / get...Extra
Use the matching put and get methods for the correct data type and include defaults where required.
Key Constants
Define keys once and reuse them to avoid subtle bugs caused by typos.
One-line takeaway

Send small, explicit data with matching getters and safe defaults; prefer Parcelable for performance and constants for keys.
