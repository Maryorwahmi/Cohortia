Why constants?

Constants keep a single source of truth for key strings and make your code easier to maintain and refactor.

Pattern
Define a top-level constant near your activity or in a shared file, then reference it from both sender and receiver.
Mistake to avoid
Using different literal strings in sender and receiver; the mismatch returns null silently.
Quick example
const val USER_NAME_KEY = "com.example.mymultiscreenapp.USER_NAME"
Developer tip

Group keys logically and name them with a package-like prefix to reduce accidental collisions.
