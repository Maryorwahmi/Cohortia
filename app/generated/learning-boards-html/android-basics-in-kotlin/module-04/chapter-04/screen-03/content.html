Practical Tasks

  1. Add navigation dependencies and Safe Args plugin lines to build files, then sync the project.
  2. Create HomeFragment and DetailFragment via New → Fragment and add a button to Home layout.
  3. Create nav_graph.xml in res/navigation and add both fragments with an action from Home to Detail.
  4. Replace MainActivity layout with a FragmentContainerView configured as a NavHostFragment and set defaultNavHost to true.
Verification: app shows HomeFragment first, button navigates to DetailFragment, and back button returns to HomeFragment.

Common pitfall

Forgetting to set app:defaultNavHost to true prevents the NavHost from handling the system back button, which leads to unexpected activity back behavior. If back presses don’t behave as expected, check this attribute first.

Pro tip
Use the navigation editor in Android Studio to visually add destinations and actions; it writes the nav_graph.xml for you and reduces XML errors.
