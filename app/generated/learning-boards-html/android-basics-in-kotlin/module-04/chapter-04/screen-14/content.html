Module 5 › Chapter 4.4 › Key Concepts
Jetpack Navigation Component
Library that simplifies navigation with a structured, visual approach.
Navigation Graph
XML map of destinations and actions; the app’s navigation blueprint.
NavHostFragment
Hosts and displays current destinations from your navigation graph.
Summary
Focus your edits on the graph to change routes, use NavController for runtime transitions, and place a NavHostFragment in your activity layout to host destinations.
