Module 5 › Chapter 4.4 › NavHostFragment Setup
activity_main.xml example
<androidx.fragment.app.FragmentContainerView
    android:id="@+id/nav_host_fragment"
    android:name="androidx.navigation.fragment.NavHostFragment"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    app:defaultNavHost="true"
    app:navGraph="@navigation/nav_graph" />
app:defaultNavHost="true" ensures that when the system back button is pressed the NavHostFragment receives the event and delegates it to the NavController according to the graph’s back stack rules.
Checklist
  • FragmentContainerView uses NavHostFragment class name.
  • app:navGraph references your nav_graph resource.
  • app:defaultNavHost is true to intercept back presses.
Key Takeaway

The NavHostFragment is the visual runtime host for destinations. Configure it once in your activity layout to let the navigation system run.
