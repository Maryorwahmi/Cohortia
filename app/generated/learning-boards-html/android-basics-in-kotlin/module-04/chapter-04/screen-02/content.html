Learning Objectives

Skills to design, set up, and implement navigation flows using the Navigation Component.

01
Explain benefits

Describe why a navigation graph and automatic back stack are more maintainable than many intents. Understand risk reduction in argument-passing.

Verified Competency Milestone
02
Identify core components

Name NavController, NavHostFragment, and the navigation graph and explain their roles using a short example with Home and Detail fragments.

Verified Competency Milestone
03
Set up project

Add the navigation fragment and UI dependencies and optionally apply the Safe Args plugin so generated classes simplify argument passing.

Verified Competency Milestone
04
Implement navigation actions

Create a nav_graph.xml with a start destination and an action, then call navigate() from a fragment and confirm back navigation behavior.

Verified Competency Milestone
Bloom: Learn → Understand → Apply → Master
Practical mnemonic
Think of navigation as a map. The graph is the map, the NavHostFragment is the pocket where you keep the map visible, and the NavController is your finger tracing the route.
Try this reflection

Identify one transition in your app you currently implement with an intent. How would that transition look as a graph action between destinations?

Checkpoint
You should be ready to add dependencies and create a nav_graph.xml in the next steps.
