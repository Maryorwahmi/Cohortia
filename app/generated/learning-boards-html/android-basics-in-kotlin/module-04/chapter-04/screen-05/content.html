Architecture Overview
Navigation Graph
An XML resource defining destinations, actions, arguments, and start destination. It is the single source of truth for navigation paths.
NavHostFragment
A special fragment that hosts and displays the active destination from the graph. Usually placed in activity_main.xml as a FragmentContainerView.
NavController
Runtime controller you get via findNavController() to perform navigate() calls and query back stack state.
Interaction example
Declare an action in nav_graph.xml and call findNavController().navigate(actionId) from your fragment to trigger it. The NavHostFragment will swap destinations accordingly.
Quick checklist
  • Graph created in res/navigation.
  • NavHostFragment in activity layout references that graph.
  • Fragments added as destinations in the graph.
Key Takeaway

Edit the navigation graph to change app routes. Use NavController only to trigger transitions at runtime.
