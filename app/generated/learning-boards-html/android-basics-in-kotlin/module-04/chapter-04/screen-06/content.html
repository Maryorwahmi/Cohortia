Module 5 › Chapter 4.4 › Dependencies & Safe Args
Add these dependencies
// In app/build.gradle (module level)
dependencies {
    implementation("androidx.navigation:navigation-fragment-ktx:2.7.7")
    implementation("androidx.navigation:navigation-ui-ktx:2.7.7")
}
If you use Safe Args add the plugin in the project build file and apply it in the app module so Gradle generates directions and argument classes for type-safe navigation.
Why Safe Args?
It replaces manual bundle keys with generated APIs that the compiler checks, eliminating a common source of runtime errors.
Build file hints
  • Project-level: declare Safe Args plugin if using it.
  • App-level: apply the Safe Args plugin and add navigation dependencies.
  • Sync project and rebuild to see generated classes.
Key Takeaway

Dependency and plugin changes are a one-time setup that yield safer and clearer navigation code going forward.
