Module 5 › Chapter 4.4 › Best Practices
Common mistakes
  • Mismatched IDs between menu items and destination IDs.
  • Forgetting app:defaultNavHost on the NavHostFragment.
  • Mixing manual fragment transactions with NavController navigation.
Tip: Use nested graphs for large apps to keep destinations organized.
Tip: Use the visual editor to reduce XML errors and speed authoring.
Verification checklist
  1. Project builds and Safe Args classes are generated.
  2. Start destination loads on app launch.
  3. Navigation actions switch destinations and back returns as expected.
Key Takeaway

Follow the checklist and use the navigation tools in Android Studio to keep navigation robust and testable as your app grows.
