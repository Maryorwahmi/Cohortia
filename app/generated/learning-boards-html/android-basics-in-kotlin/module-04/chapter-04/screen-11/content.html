Binding navigation to UI
Use NavigationUI.setupWithNavController to bind a BottomNavigationView or NavigationView (drawer) to a NavController so menu selections route to destinations declared in the nav_graph. Ensure menu item IDs match destination IDs for automatic linking.
Benefit
Selected state, proper back behavior, and deep linking integration are all handled for you when you connect UI controls to the NavController.
Practical note

When you use a drawer or bottom bar for top-level destinations, consider using app:popUpTo and app:popUpToInclusive in actions to control back stack behavior between top-level items if necessary.

Key Takeaway

Bind your navigation UI to the NavController and let the framework ensure consistent behavior across UI patterns like bottom bars and drawers.
