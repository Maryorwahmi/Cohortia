Module 5 › Chapter 4.4 › Back Stack Behavior
How it works
When you call navigate(), the NavController pushes a new destination on the NavBackStack. The NavHostFragment displays the top destination. Pressing back pops the stack and returns to the previous destination. This behavior is consistent across configuration changes.
Correct: app:defaultNavHost="true" lets NavHost handle back presses.
Wrong: mixing manual fragment transactions creates inconsistent back behavior.
Check your app
  1. Navigate Home → Detail.
  2. Press device back and confirm you return to Home.
  3. If not, verify app:defaultNavHost and that you’re not using manual fragment transactions alongside NavController.
Key Takeaway

Let the navigation framework manage the back stack to avoid common lifecycle and navigation bugs.
