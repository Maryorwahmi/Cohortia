Step-by-step
  1. Add navigation dependencies and optionally Safe Args; sync project.
  2. Create HomeFragment and DetailFragment and add a button to the Home layout.
  3. Create res/navigation/nav_graph, add both fragments, set startDestination, and add an action.
  4. Replace MainActivity with a FragmentContainerView configured as a NavHostFragment and set defaultNavHost and navGraph attributes.
  5. In HomeFragment call findNavController().navigate(actionId) from the button click.
  6. Run the app and verify navigation and back button behavior.
Checkpoint: Project builds with no unresolved symbols.
Checkpoint: Home launches as the start destination.
Checkpoint: Back returns to Home as expected.
