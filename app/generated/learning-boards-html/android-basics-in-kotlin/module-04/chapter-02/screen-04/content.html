Intent
A messaging object to request actions from other components.
Analogy: an Intent is like a postal request with an address. An explicit intent writes the exact house number (the activity class). An implicit intent describes the task, like "open a map," and the system finds a matching app.
Key point: Explicit intents are the standard pattern for navigating within your app.
Misconception: An Intent by itself does nothing until you call startActivity or a similar dispatcher.
Concrete example
// Create an explicit intent
val intent = Intent(this, SecondActivity::class.java)
startActivity(intent)
Key Takeaway

Intent = request. For in-app navigation use explicit intents and always ensure the target is declared in the manifest.
