Process Flow › Create and launch an explicit intent
Step-by-step
  1. Create the Intent with the current context and target activity class.
  2. Call startActivity(intent) to request the system open the target.
  3. Optionally call finish() if you want to remove the current activity from the back stack.
  4. Test the back button to confirm behavior.
Pro tip: Use explicit intents for predictable in-app navigation and test both button-driven and device back navigation.
Code example
// In MainActivity.kt
import android.content.Intent
import android.os.Bundle
import android.widget.Button
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
  override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    setContentView(R.layout.activity_main)

    val navigateButton: Button = findViewById(R.id.navigate_button)
    navigateButton.setOnClickListener {
      // Create an explicit intent to start SecondActivity
      val intent = Intent(this, SecondActivity::class.java)
      startActivity(intent) // Launch the SecondActivity
    }
  }
}
Key Takeaway

Use Intent(this, Target::class.java) then startActivity(intent). Remember ::class.java and manifest declarations.
