Implementing Basic Navigation with Intents

Discover how to request actions between components and build multi-screen flows using explicit intents. Practical code examples and back stack behavior make navigation predictable.

In this lesson: Intents, startActivity, finish
Why it matters: Controls user flow and app structure
Common pitfalls: Missing manifest entries
Hands-on: Add buttons and test back behavior
Explore Key Topics
Intent
A messaging object that requests actions from app components, typically launching activities.
Back Stack
How activities are retained and resumed. finish() removes an activity from this stack.
Debugging
ActivityNotFoundException usually means the activity is not declared in the manifest.
