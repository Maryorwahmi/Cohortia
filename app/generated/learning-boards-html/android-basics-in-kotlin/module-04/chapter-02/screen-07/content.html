Definition › Button and XML wiring
activity_main.xml
<Button
  android:id='@+id/navigate_button'
  android:layout_width='wrap_content'
  android:layout_height='wrap_content'
  android:text='Go to Second Screen' />
Ensure the layout file used in setContentView contains this ID and call findViewById after setContentView.
Common mistakes & fixes
  • Null pointer: called findViewById before setContentView. Fix: move setContentView up.
  • ID mismatch: ensure the XML id matches the Kotlin reference.
  • Wrong layout: verify the correct layout resource is set for the activity.
