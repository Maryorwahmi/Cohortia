Comparison › Common errors when using intents
ActivityNotFoundException
Cause: target activity not declared in AndroidManifest.xml or class name mismatch. Fix: add <activity> entry and verify package/class.
findViewById null
Cause: calling findViewById before setContentView or wrong layout. Fix: call setContentView first and verify IDs.
Kotlin class error
Cause: forgetting ::class.java when creating the Intent. Fix: use TargetActivity::class.java.
Debugging tip
Check logcat for the full exception. Reproduce the crash, then fix one suspected cause and re-run.
