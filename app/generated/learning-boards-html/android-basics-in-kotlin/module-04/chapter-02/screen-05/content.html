Comparison › Explicit vs Implicit Intents
Explicit Intent
Specifies the activity class to start. Best for navigation within your app because it targets a known component.
Example: val intent = Intent(this, SecondActivity::class.java); startActivity(intent)
Common pitfall: forgetting to declare the target activity in AndroidManifest.xml will cause a runtime crash.
Implicit Intent
Specifies an action and optional data; the system chooses an app that can handle it. Use for sharing, opening a map, or sending email.
Example: val intent = Intent(Intent.ACTION_VIEW, uri)
Misconception: implicit intents are not for addressing your own activities by class.
When to use
Explicit: internal screens. Implicit: system or third-party actions.
Verification
Run the app and confirm the intended component opens without chooser dialogs unless desired.
Common error
Misused intent types or missing manifest entries cause crashes or no resolution.
