Example manifest
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    package="com.example.myapp">

    <application
        android:allowBackup="true"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:roundIcon="@mipmap/ic_launcher_round"
        android:supportsRtl="true"
        android:theme="@style/Theme.MyApp">

        <activity android:name=".MainActivity"
            android:exported="true">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>

        <activity android:name=".DetailActivity" />

    </application>
</manifest>
This snippet shows MainActivity declared with an intent-filter that makes it the launcher entry, and a DetailActivity declared without the launcher filter so it is launched only when your code starts it.
Checklist and notes
  • Verify every activity you add appears under <application> in the manifest.
  • Only give MAIN and LAUNCHER to the true entry activity so the system shows it in the launcher.
  • Missing an activity tag commonly causes ActivityNotFoundException — always inspect the manifest after creating activities.
Key Takeaway

The manifest is the app's passport; ensure it lists and configures each activity so Android can launch and manage it properly.
