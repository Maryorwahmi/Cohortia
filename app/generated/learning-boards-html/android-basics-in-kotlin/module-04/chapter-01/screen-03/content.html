Module 4 › Chapter 4.1 › Learning Objectives
01
Create a second activity
Use the Empty Activity template to generate SecondActivity and its layout, then inspect the new files. This builds confidence in project structure.
Mnemonic: add a screen
VERIFIED COMPETENCY MILESTONE
02
Verify manifest entry
Open app/src/main/AndroidManifest.xml and confirm the tag for SecondActivity exists; this prevents runtime crashes when starting it.
Mnemonic: passport check
VERIFIED COMPETENCY MILESTONE
03
Understand launcher vs others
Confirm only MainActivity has the MAIN and LAUNCHER filters so it appears in the launcher; others are launched programmatically or via explicit intents.
Mnemonic: main is launcher
VERIFIED COMPETENCY MILESTONE
04
Detect common manifest mistakes
Know that missing an tag is the usual cause of an ActivityNotFoundException; always double-check the manifest after adding activities.
Mnemonic: double-check manifest
VERIFIED COMPETENCY MILESTONE
Practice guide
Work through the hands-on task: add SecondActivity, inspect files, confirm manifest entries, run the app and observe which activity opens first. Use the checklist to verify each step.
