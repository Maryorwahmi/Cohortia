Module 4 › Chapter 4.1 › onStart & onResume
When to start visible work
  • onStart: prepare resources needed while visible but not yet interactive.
  • onResume: resume or attach listeners for interactive updates and animations.
  • onPause/onStop: detach listeners and stop animations to conserve resources.
Example: start a live message subscription in onResume so the chat receives updates only while users are actively viewing the conversation.
Practical checklist
Attach UI listeners in onResume
Start animations in onResume and pause in onPause
Unregister receivers in onPause or onStop
Key Takeaway

Match resource start/stop to visibility and foreground state to avoid wasted work and memory leaks.
