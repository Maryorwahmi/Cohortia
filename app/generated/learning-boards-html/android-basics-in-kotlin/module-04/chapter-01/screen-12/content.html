Why ActivityNotFoundException occurs
This exception happens when the system cannot find an activity to handle an explicit intent, most commonly because the activity was not declared in the manifest or the android:name is incorrect.
Checklist to fix the error
  1. Open AndroidManifest.xml and confirm the activity tag exists under <application>.
  2. Verify the android:name attribute matches the activity class name and package.
  3. If using Android Studio templates, confirm the studio added the entry as expected.
Example
If DetailActivity is missing from the manifest, starting it will crash. Add <activity android:name=".DetailActivity" /> to resolve the issue.
Key Takeaway

After creating an activity, always confirm its manifest declaration to prevent runtime crashes.
