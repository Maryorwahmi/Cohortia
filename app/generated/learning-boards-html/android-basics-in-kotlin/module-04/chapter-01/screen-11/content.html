Module 4 › Chapter 4.1 › Entry Point vs Others
Launcher activity
An activity with an intent-filter including android.intent.action.MAIN and android.intent.category.LAUNCHER becomes the app's entry visible in the device launcher. It usually sets android:exported="true" so the system can start it.
Example
MainActivity declared with MAIN and LAUNCHER appears as the app icon the user taps.
Secondary activities
Activities without the MAIN/LAUNCHER filter are launched from code or other components. They do not appear in the launcher and often keep exported="false" by default for safety.
Misconception check
Don't add MAIN/LAUNCHER to multiple activities unless you intentionally want more than one launcher entry point.
Key Takeaway

Reserve MAIN+LAUNCHER for the single app entry point; design other activities to be started from within the app.
