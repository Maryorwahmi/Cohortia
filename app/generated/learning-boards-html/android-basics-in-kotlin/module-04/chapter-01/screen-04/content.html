Module 4 › Chapter 4.1 › What is an Activity?
Definition & Analogy
An Activity represents one focused thing the user does. Imagine each Activity as a separate page in a book: each page has its own content, and you can flip between pages to continue reading.
Example: Messaging app
ConversationsActivity, ChatActivity, ComposeActivity — each maps to a single user goal and UI layout.
Common misconception
Activities are not only view holders; they manage lifecycle decisions like registering listeners and releasing resources.
Key Takeaway

Choose activities for distinct user tasks to keep UI and code focused and maintainable.

Concrete scenario
If a user taps a conversation in a list, that action moves them from the conversations screen to a dedicated chat screen. This transition is typically implemented by starting a new Activity that displays messages for the selected conversation.
Check your understanding
  • Would this screen represent a distinct user goal?
  • Does it need its own lifecycle management for resources?
  • If yes to both, prefer a dedicated Activity.
