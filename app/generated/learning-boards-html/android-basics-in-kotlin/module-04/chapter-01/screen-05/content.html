LIFO navigation model
The back stack records each started activity so pressing Back reverses the most recent navigation. This preserves the user's history within your app's task.
Activity A: Conversations
User selects a conversation.
Activity B: Chat
ChatActivity is pushed onto the stack. Back pops ChatActivity and resumes ConversationsActivity.
Misconception check
The previous activity is not always destroyed; usually it is stopped and later resumed, so retain important UI state between onPause and onResume.
Practical implications
  • Decide if a screen should be a new Activity based on whether users will navigate back to the previous context.
  • Use intent extras to pass data between activities while preserving the back stack order.
  • Use special flags only when you need to modify the default back stack behavior.
Key Takeaway

The back stack gives users a predictable path back through your app; design screen flows with this behavior in mind.
