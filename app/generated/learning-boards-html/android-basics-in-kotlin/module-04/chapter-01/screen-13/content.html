Module 4 › Chapter 4.1 › Hands-on: SecondActivity
Step-by-step
  1. Create a new project using Empty Activity and name it MyMultiScreenApp.
  2. Right-click your package > New > Activity > Empty Activity. Name it SecondActivity.
  3. Inspect SecondActivity.kt and activity_second.xml generated by Android Studio.
  4. Open app/src/main/AndroidManifest.xml and confirm <activity android:name=".SecondActivity" /> appears.
  5. Run the app and observe that MainActivity launches; start SecondActivity programmatically to test it.
Troubleshooting
If starting SecondActivity crashes with ActivityNotFoundException, re-open the manifest and check that the android:name matches the activity class, including package prefix if needed.
Key Takeaway

Follow the create → verify manifest → run cycle to ensure new activities are correctly registered with the system.
