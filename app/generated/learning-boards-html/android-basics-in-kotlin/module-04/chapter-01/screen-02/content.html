Module 4 › Chapter 4.1 › Learning Objectives
01
Explain Activity & Lifecycle
Describe what an activity is and name key lifecycle callbacks such as onCreate, onStart, and onResume. This helps you place initialization work correctly and avoid resource leaks.
Mnemonic: stack of screens
VERIFIED COMPETENCY MILESTONE
02
Structure apps with multiple activities
Design focused screens like conversation list, conversation view, and compose screen to keep code maintainable and UX clear.
Mnemonic: small, single-purpose modules
VERIFIED COMPETENCY MILESTONE
03
Identify manifest components
Locate activity tags in AndroidManifest.xml and understand attributes like android:name and intent-filter entries that shape visibility and launch behavior.
Mnemonic: app passport
VERIFIED COMPETENCY MILESTONE
04
Differentiate entry point vs others
Recognize the intent-filter with MAIN and LAUNCHER that makes an activity the app's launch entry; other activities are reachable from code or intents.
Mnemonic: main + launcher
VERIFIED COMPETENCY MILESTONE
