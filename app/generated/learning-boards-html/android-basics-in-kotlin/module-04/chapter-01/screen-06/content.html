Module 4 › Chapter 4.1 › Lifecycle Overview
Lifecycle timeline
onCreate()
One-time setup like setContentView and initial variable binding.
onStart()
Activity becomes visible but not yet in the foreground.
onResume()
Activity now interacts with the user; resume animations and listeners here.
onPause() / onStop()
Pause ongoing actions, save quick state, then release heavy resources in onStop.
onDestroy()
Clean up final resources, though this may not always be called before the process is killed.
Practical guidance
  • Initialize UI and single-run setup in onCreate.
  • Start animations or foreground listeners in onResume, pause them in onPause.
  • Release network connections or heavy resources in onStop.
  • Save critical state in onPause or onSaveInstanceState because onDestroy may not be called.
Key Takeaway

Map each piece of setup and cleanup to the appropriate lifecycle method to keep your app responsive and leak-free.
