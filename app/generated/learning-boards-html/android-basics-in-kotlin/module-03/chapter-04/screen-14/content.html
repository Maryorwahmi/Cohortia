Module 3 › Chapter 3.4 › Key Concepts — Part 1
ConstraintLayout
A flexible ViewGroup that positions views using constraints to minimize nested hierarchies.
Constraint
A relationship linking a view edge to another view or the parent to determine position.
Parent Constraint
A constraint that ties a view's side to the corresponding side of the parent layout.
Summary
Keep these three concepts front of mind: the layout, the constraints that express relationships, and parent constraints that anchor key elements.
