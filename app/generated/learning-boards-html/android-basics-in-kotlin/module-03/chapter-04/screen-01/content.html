Introduction to ConstraintLayout
Build flat, responsive UIs by defining relationships between view edges instead of nesting view groups.
Why this matters

Flat hierarchies reduce layout passes and improve performance. Constraint relationships let a single layout describe complex arrangements that adapt to screen size.

In this lesson
Add constraints, use 0dp for flexible sizing, fix common mistakes, and convert the Tip Calculator to ConstraintLayout.
Explore Key Topics
Constraints
Relationships that lock view edges to parent or siblings to determine position and size.
0dp / MATCH_CONSTRAINT
Make a view stretch between anchors so it adapts to available space.
Common mistakes
Under-constrained views, conflicts, and over-constraining that make layouts fragile.
