Module 3 › Chapter 3.4 › What is a Constraint?
Definition

A constraint ties a view edge to another view edge or the parent. Use app:layout_constraintX_toY attributes to declare these relationships.

Common uses
  • Center horizontally: start-to-start and end-to-end of parent.
  • Place below another view: top-to-bottom of that view.
  • Align text baselines with baseline constraint for consistent text rows.
Analogy
Think of each constraint as a tether: you attach an edge of the view to another edge and the layout resolves those tethers to compute positions and sizes.
Example prompt
To place a button below a title and aligned to its start edge, use top-to-bottom of the title and start-to-start of the title — this guarantees the correct relative placement even as widths change.
