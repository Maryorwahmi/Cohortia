Module 3 › Chapter 3.4 › Button below TextView
XML Example
<TextView
    android:id="@+id/titleTextView"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Welcome to My App"
    android:textSize="24sp"
    app:layout_constraintEnd_toEndOf="parent"
    app:layout_constraintStart_toStartOf="parent"
    app:layout_constraintTop_toTopOf="parent"
    android:layout_marginTop="64dp" />

<Button
    android:id="@+id/startButton"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Get Started"
    app:layout_constraintEnd_toEndOf="parent"
    app:layout_constraintStart_toStartOf="parent"
    app:layout_constraintTop_toBottomOf="@id/titleTextView"
    android:layout_marginTop="32dp" />
Explanation & common mistake
The button's top is anchored to the title's bottom; start and end anchors to parent center it horizontally. The margin applies after the top-to-bottom anchor. Common mistake: anchoring the button to the parent's start instead of the title's start, which breaks alignment.
Try this

Change the button's start constraint to the title's start to see precise alignment, or use parent start for a separate alignment strategy.
