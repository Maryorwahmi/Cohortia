Module 3 › Chapter 3.4 › Margins in ConstraintLayout
Key points
  • Margins apply after constraints are resolved and create distance in the constraint direction.
  • They do not fix under-constrained views; anchors must exist first.
  • Combined with 0dp widths, margins create consistent padding while views stretch between anchors.
Example
Button constrained to title bottom with android:layout_marginTop="32dp" will always sit 32dp below the title once the anchor exists.
Misconception check
If a view jumps to the top-left, don't increase margins; instead add the missing horizontal or vertical constraint that Android Studio has warned about.
Key Takeaway

Margins are spacing after anchors; ensure anchors exist first and use margins to fine-tune distance.
