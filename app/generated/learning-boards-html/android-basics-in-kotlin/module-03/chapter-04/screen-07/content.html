Module 3 › Chapter 3.4 › Center a TextView (XML)
XML Example
<androidx.constraintlayout.widget.ConstraintLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto"
    android:layout_width="match_parent"
    android:layout_height="match_parent">

    <TextView
        android:id="@+id/centeredTextView"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Centered Text"
        android:textSize="24sp"
        app:layout_constraintBottom_toBottomOf="parent"
        app:layout_constraintEnd_toEndOf="parent"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintTop_toTopOf="parent" />

</androidx.constraintlayout.widget.ConstraintLayout>
Explanation
  • Opposing start and end plus top and bottom make the TextView centered in both axes.
  • If any axis lacks opposing constraints, the view is under-constrained and the editor will warn.
  • You can add margins to control distance from edges after constraints are set.
Misconception check
0dp is not used here; wrap_content leaves the view sized to its content. Use 0dp when you want it to stretch between anchors.
