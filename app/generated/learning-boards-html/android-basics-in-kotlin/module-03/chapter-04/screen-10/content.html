Module 3 › Chapter 3.4 › 0dp (MATCH_CONSTRAINT)
What 0dp means

Setting layout_width or layout_height to 0dp instructs the layout to size the view based on its constraints. It stretches between anchors after margins are applied.

Practical example
Set EditText width to 0dp with start and end constrained to parent, and it will fill available width while preserving margins.
Misconception check
0dp is not zero pixels. If the view appears zero, check that both anchors exist. Use wrap_content for content-sized views and match_constraint (0dp) for stretching views.
Key Takeaway

Use 0dp when you want a view to fill the space between anchors; verify both constraints are present.
