Module 3 › Chapter 3.4 › Adding constraints
Step-by-step
  1. Select the view in the Design editor.
  2. Drag a blue handle to the parent edge or a sibling view to create an anchor.
  3. Repeat until the view has a horizontal and a vertical constraint.
  4. Use android:layout_marginTop or other margins to add spacing after constraints.
Editor tip
Android Studio will highlight under-constrained views; address those warnings to avoid runtime jumps.
Concrete example
Anchor a title to parent top, start, and end with a top margin. Then select the button and connect its top handle to the title's bottom handle and its start and end to the parent for horizontal centering.
Pro tip

When centering horizontally prefer start and end constraints rather than fixed X positions so the view adapts to RTL and different screen widths.
