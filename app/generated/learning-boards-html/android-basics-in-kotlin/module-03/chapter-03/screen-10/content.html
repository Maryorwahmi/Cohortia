Code Walkthrough › Tip Calculator Logic
Starter Kotlin template
val billAmountEditText: EditText = findViewById(R.id.billAmountEditText)
val calculateButton: Button = findViewById(R.id.calculateButton)
val tipResultTextView: TextView = findViewById(R.id.tipResultTextView)
val totalResultTextView: TextView = findViewById(R.id.totalResultTextView)

calculateButton.setOnClickListener {
  val billAmountString = billAmountEditText.text.toString()
  val billAmount = billAmountString.toDoubleOrNull()

  if (billAmount != null && billAmount > 0) {
    val tip = billAmount * 0.15
    val total = billAmount + tip

    tipResultTextView.text = "Tip: $${String.format("%.2f", tip)}"
    totalResultTextView.text = "Total: $${String.format("%.2f", total)}"

    Toast.makeText(this, "Tip calculated!", Toast.LENGTH_SHORT).show()
  } else {
    Toast.makeText(this, "Please enter a valid bill amount.", Toast.LENGTH_LONG).show()
    tipResultTextView.text = "Tip: $0.00"
    totalResultTextView.text = "Total: $0.00"
  }
}
Testing steps
  1. Enter a valid decimal like 42.50 and press Calculate.
  2. Verify tip and total update and a short Toast appears.
  3. Enter invalid input or leave blank, press Calculate, and confirm long Toast and reset values.
Key Takeaway

Implement null-safe parsing and clear success/error branches to keep your app stable and user-friendly.
