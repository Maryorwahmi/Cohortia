Definition › findViewById & setContentView
Inflate layout, then get views
setContentView inflates the XML. After inflation, findViewById returns real view objects.
override fun onCreate(savedInstanceState: Bundle?) {
  super.onCreate(savedInstanceState)
  setContentView(R.layout.activity_main) // inflate layout

  val actionButton: Button = findViewById(R.id.actionButton)
  val resultTextView: TextView = findViewById(R.id.resultTextView)

  actionButton.setOnClickListener { resultTextView.text = "Clicked" }
}
Common mistake
Calling findViewById before setContentView leads to NullPointerException. Always inflate first.
Quick checklist
  • Call setContentView in onCreate.
  • Then call findViewById for each view you will use.
  • Keep references local to Activity or cache them for reuse.
Key Takeaway

Inflate first, bind next. The correct order prevents null references and enables interaction.
