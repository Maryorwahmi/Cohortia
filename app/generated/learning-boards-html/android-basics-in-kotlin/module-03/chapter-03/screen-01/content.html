Handling User Input and Events

Learn how listeners, EditText, TextView and Toasts work together to turn UI into useful behavior. We'll build a tip calculator as a hands-on example.

In this lesson
Detect taps
Use OnClickListener or a Kotlin lambda to run code when a View is tapped.
Read input
Call EditText.text.toString() and parse safely with toDoubleOrNull or toIntOrNull.
Give feedback
Update TextView and show a Toast for temporary confirmation.
Preview code
actionButton.setOnClickListener {
  val name = nameEditText.text.toString()
  if (name.isNotBlank()) {
    greetingTextView.text = "Hello, $name!"
    Toast.makeText(this, "Welcome, $name!", Toast.LENGTH_SHORT).show()
  }
}
Why this matters
Interactivity turns static layouts into useful apps. Proper validation keeps those apps reliable and safe.
