Process Flow › Validate and Branch
Validation steps
  1. Read string: val s = editText.text.toString()
  2. Quick check: if (s.isNotBlank())
  3. Safe parse: val n = s.toDoubleOrNull()
  4. Branch: if (n != null && n > 0) { /* success */ } else { /* error */ }
Example snippet
val billAmount = billAmountEditText.text.toString().toDoubleOrNull()
if (billAmount != null && billAmount > 0) {
  val tip = billAmount * 0.15
  // update UI
} else {
  Toast.makeText(this, "Please enter a valid bill amount.", Toast.LENGTH_LONG).show()
}
Why it matters

Validation avoids crashes, leads to predictable behavior, and helps users fix mistakes. It separates parsing logic from UI updates.

Key Takeaway

Always validate and use null-safe parsing. Treat invalid input as a normal branch, not an exception.
