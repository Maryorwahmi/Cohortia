From Editable to String
EditText.text is Editable. Convert to a String with .toString() before use or parsing.
val name = nameEditText.text.toString()
if (name.isNotBlank()) {
  greetingTextView.text = "Hello, $name!"
} else {
  greetingTextView.text = "Please enter your name."
}
Practical notes
  • Use isNotBlank to reject empty or whitespace-only input.
  • Call toString before parsing numeric conversions.
  • Editable implements CharSequence; treat it as transient input rather than final data.
Example

Read nameEditText.text.toString(), check isNotBlank(), then update greetingTextView and show a Toast for quick feedback.
