Module 3 › Chapter 3.3 › Learning Objectives
Objective checks
  1. Wire views: call setContentView then findViewById to avoid null references.
  2. Respond to taps: use setOnClickListener with a Kotlin lambda to update UI on tap.
  3. Safe parsing: use toDoubleOrNull and check for null before math.
  4. Feedback: update TextView and show Toasts to inform the user.
Mnemonic
Think: Wire → Listen → Read → Validate → Respond. Each step is small but required for a working interaction.
Wire
setContentView + findViewById
Validate
toDoubleOrNull, toIntOrNull, isNotBlank
