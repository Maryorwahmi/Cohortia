OnClickListener in Kotlin
Provide a small block of code that runs when the user taps a View. Lambdas keep this concise and readable.
val actionButton: Button = findViewById(R.id.actionButton)
actionButton.setOnClickListener {
  // runs on tap
  resultTextView.text = "Button was clicked!"
}
Example
Tap Greet, read EditText, and set greetingTextView.text to "Hello, name!".
Misconception
Listeners are heavy objects — in Kotlin they are usually simple lambdas, not bulky classes.
How it works
  • setOnClickListener registers a callback executed on tap.
  • Kotlin lambda replaces a one-method interface neatly.
  • Use for quick UI changes; avoid long blocking work there.
Key Takeaway

Use setOnClickListener with a lambda for clear, concise tap handling and keep heavy work off the main thread.
