Interaction pipeline
  • 1
    Wire: setContentView → findViewById.
  • 2
    Listen: setOnClickListener with a lambda.
  • 3
    Read & Parse: EditText.text.toString(), toDoubleOrNull.
  • 4
    Validate & Respond: if/else → update TextView & Toast.
Example outcome
A user types 50.00, taps Calculate. App parses 50.0, calculates tip, updates both TextViews, and shows a short Toast. If input is invalid, a long Toast explains the error and the TextViews reset.
Key Takeaway

Think of interactive features as a repeatable pipeline you can test and reuse across screens.
