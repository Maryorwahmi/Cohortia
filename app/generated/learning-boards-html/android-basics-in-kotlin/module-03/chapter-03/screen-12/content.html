Common Mistake › Runtime errors
NullPointerException
Usually caused by findViewById returning null because layout wasn't inflated or id mismatched.
Fix: call setContentView in onCreate and verify id names in XML and code.
NumberFormatException
Caused by calling toInt or toDouble on invalid strings.
Fix: use toDoubleOrNull/toIntOrNull and branch on null to handle malformed input.
Pro tip

Log the raw EditText string before parsing and test both empty and invalid inputs to confirm your guards work.
