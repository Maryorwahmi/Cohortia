Comparison › Null-safe vs direct parsing
Null-safe parsing
val n = s.toDoubleOrNull()
if (n != null) {
  // valid number
} else {
  // handle invalid input
}
Returns null on failure; lets you treat invalid input as a normal branch instead of an exception.
Direct parsing
val n = s.toDouble()
// throws NumberFormatException on invalid input
Use only when input is guaranteed valid. Not safe for user-entered text.
Key Takeaway

When reading user input, prefer toDoubleOrNull/toIntOrNull and handle the null case to avoid runtime exceptions.
