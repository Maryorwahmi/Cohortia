Hands-on Activity › Tip Calculator Layout
Recommended XML structure
<LinearLayout
  android:orientation="vertical"
  android:padding="16dp">

  <TextView
    android:text="Tip Calculator" />

  <EditText
    android:id="@+id/billAmountEditText"
    android:hint="Bill Amount"
    android:inputType="numberDecimal" />

  <Button
    android:id="@+id/calculateButton"
    android:text="Calculate Tip" />

  <TextView
    android:id="@+id/tipResultTextView"
    android:text="Tip: $0.00" />

  <TextView
    android:id="@+id/totalResultTextView"
    android:text="Total: $0.00" />

</LinearLayout>
Design tips
  • Use inputType=numberDecimal for numeric keyboards.
  • Provide clear hints and default TextView text like "Tip: $0.00".
  • Keep ids semantic so Kotlin findViewById is obvious.
Key Takeaway

Build a minimal layout with well-named ids so wiring and testing are straightforward.
