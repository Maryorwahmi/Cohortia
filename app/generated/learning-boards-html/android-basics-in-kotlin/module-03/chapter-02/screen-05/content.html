Definition
Button — trigger actions from taps
Buttons need ids, labels, and a connected click listener to become interactive.
XML example
<Button
    android:id="@+id/loginButton"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:text="Log In"
    android:backgroundTint="#6200EE"
    android:textColor="@android:color/white"
    android:layout_marginTop="16dp" />
Explanation
  • android:id allows findViewById to locate the button in Kotlin.
  • android:backgroundTint controls button color; match it to your theme for cohesion.
  • Always validate user input when the button triggers a form submission.
Example scenario
When the login button is tapped, read the username and password EditText values, check they are not empty, and then show an authenticated state or an error message.
Common mistake

Forgetting android:id or mis-typing the id. This causes findViewById to return null and may crash the app at runtime.
