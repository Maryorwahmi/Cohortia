Module 3 › Chapter 3.2 › Learning Objectives
Programmatic access

Use findViewById with the correct View type. This is the first step before exploring View Binding. Correct ids prevent null references and crashes.

Mnemonic: ID first, then code — the id unlocks programmatic control.
Avoid common pitfalls

Avoid hardcoded text, missing contentDescription, and wrong inputType. These cause localization, accessibility, and usability issues respectively.

Mnemonic: Strings, Description, InputType — the small checklist that prevents bad UX.
How you’ll demonstrate
  • Create a login screen with ids for username, password, and button.
  • Set appropriate inputType and hints for each EditText.
  • Use findViewById to read the username and update a TextView when the button is tapped.
