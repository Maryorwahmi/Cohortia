Definition
TextView — display text correctly
Use attributes and string resources to control content and appearance.
XML example
<TextView
    android:id="@+id/greetingTextView"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="@string/hello_android"
    android:textSize="24sp"
    android:textColor="#FF0000"
    android:textStyle="bold|italic"
    android:padding="8dp" />
Explanation
  • android:id makes the view accessible from Kotlin with findViewById.
  • Use @string resources for text to support localization and maintenance.
  • textSize and textStyle control visual hierarchy and readability.
Example
Start with a greeting and replace the text at runtime with the user’s name to show personalization.
Key Takeaway

Prefer string resources for android:text, give a clear id, and choose readable size and color for accessibility.

Common mistake

Hardcoding text directly in XML. This prevents localization and increases maintenance cost.

Pro tip

Use wrap_content for a TextView that will change content, and consider maxLines if you want to clamp long messages.

Quick check

Can you replace a hardcoded android:text with a string resource and reference it in XML? That change improves localization readiness.
