01. Add TextView
VERIFIED COMPETENCY MILESTONE

Place TextView in XML and use string resources for text. This ensures localization and consistent copy across screens.

Mnemonic: A label tag — think of it as a sign.
02. Implement Button
VERIFIED COMPETENCY MILESTONE

Configure text and tint, then connect an OnClickListener in Kotlin to turn the tap into action. Buttons make your app interactive.

Mnemonic: A real button — pushes behavior forward.
03. Use ImageView
VERIFIED COMPETENCY MILESTONE

Set src and scaleType for proper display, and always include contentDescription to support screen readers and accessibility tools.

Mnemonic: Picture frame — fits and describes the image.
04. Configure EditText
VERIFIED COMPETENCY MILESTONE

Set hint, inputType, and lines so users see guidance and get the right keyboard for the expected data. This improves usability and reduces errors.

Mnemonic: Input field — invite the user to type.
How you will practice
Hands-on: Build the login screen, then use findViewById in MainActivity to change a TextView and read the EditText value when the login button is tapped.
Assessment
Mini-quiz asks for the correct inputType for numbers and which attribute sets an ImageView's source.
