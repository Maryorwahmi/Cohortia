Definition
EditText — collect user input correctly
Hints and inputType align user expectations with the keyboard and behavior you want.
XML example
<EditText
    android:id="@+id/nameEditText"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:hint="Enter your name"
    android:inputType="textPersonName"
    android:minLines="1"
    android:maxLines="1"
    android:padding="12dp" />
Explanation
  • android:hint provides placeholder guidance when the field is empty.
  • android:inputType selects the keyboard and helps constrain input format.
  • Use minLines and maxLines to control the field height for multi-line entry.
Example
For an age field, set inputType to number so the numeric keypad appears. For email, use textEmailAddress so the keyboard offers the at-sign and email-friendly layout.
Common mistake

Using the wrong inputType, which leads to the wrong keyboard and more typing friction for users.

Try this
Change an EditText inputType to number and notice the different on-screen keyboard when you run the app on a device or emulator.
