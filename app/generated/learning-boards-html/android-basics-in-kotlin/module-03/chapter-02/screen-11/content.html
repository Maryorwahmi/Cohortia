Common mistakes and fixes
Small XML or ordering errors cause crashes or bad UX; compare mistake vs fix.
Mistake: Hardcoded text
android:text="Login" in XML is convenient but prevents localization.
Fix: Move to res/values/strings.xml and use @string/login_label.
Mistake: Missing id
No android:id means you cannot find the view in Kotlin and may crash when referencing it.
Fix: Add android:id="@+id/yourViewId" and match it in findViewById.
Mistake: Wrong inputType
Using text for numbers forces the user to switch keyboards and allows invalid characters.
Fix: Use inputType="number" for numeric fields to show the numeric keyboard and reduce errors.
Mistake: Missing contentDescription
Images without descriptions are invisible to assistive tech.
Fix: Provide android:contentDescription with useful text, or empty string for decorative images.
