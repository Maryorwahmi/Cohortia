Assessment idea
Mini-quiz & review
Questions to test your understanding and a short review checklist.
Question 1
Which inputType for an age field? Options: text, number, textPersonName, phone. Correct: number.
Question 2
How to set an ImageView source from drawable? Use android:src="@drawable/your_image".
Review checklist
  • Use string resources for text.
  • Assign clear android:id values.
  • Pick inputType to match expected data.
  • Add contentDescription for images.
  • Call setContentView before findViewById.
Practical prompt
Change a text field’s inputType and run the app to see how the keyboard and suggestions change. That simple experiment cements the concept.
