Wire the Login Button in Kotlin
Read input, validate, and respond with UI updates on button press.
Kotlin example
override fun onCreate(savedInstanceState: Bundle?) {
  super.onCreate(savedInstanceState)
  setContentView(R.layout.activity_main)

  val usernameEditText: EditText = findViewById(R.id.usernameEditText)
  val passwordEditText: EditText = findViewById(R.id.passwordEditText)
  val loginButton: Button = findViewById(R.id.loginButton)
  val titleTextView: TextView = findViewById(R.id.titleTextView)

  loginButton.setOnClickListener {
    val username = usernameEditText.text.toString().trim()
    val password = passwordEditText.text.toString()

    if (username.isEmpty()) {
      titleTextView.text = "Please enter a username"
    } else {
      titleTextView.text = "Welcome, $username!"
    }
  }
}
Explanation
  • Convert EditText.text to a string before validation with toString().
  • Trim whitespace to avoid accidental empty values that look non-empty.
  • Use simple checks to guide the user before proceeding to authentication logic.
Common mistake
Assuming EditText.text is already a string or ignoring trimming, which can allow only-space names to pass validation.
Key Takeaway

Read EditText values as strings, validate, then update TextView or proceed. This small pattern is the heart of user-driven interactions.
