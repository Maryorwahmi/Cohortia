Definition
ImageView — display images responsibly
Choose src and scaleType to control image fitting, and include contentDescription for screen readers.
XML example
<ImageView
    android:id="@+id/profileImageView"
    android:layout_width="120dp"
    android:layout_height="120dp"
    android:src="@drawable/ic_launcher_foreground"
    android:scaleType="centerCrop"
    android:contentDescription="User profile picture" />
Explanation
  • android:src points to drawable resources bundled with the app.
  • android:scaleType controls cropping and scaling; pick one that preserves important image content.
  • android:contentDescription is vital for accessibility and should describe the image purpose.
Example
A circular avatar often uses centerCrop to fill the shape while keeping the face centered. If the avatar is purely decorative, set contentDescription="" to avoid cluttering screen reader output.
Common mistake

Omitting contentDescription or using the wrong scaleType so important parts of the image are cropped out on different screens.

Pro tip
Choose scaleType to match your layout intent: centerCrop for filled squares, fitCenter for complete fit, and center for no scaling.
