Access views from Kotlin with findViewById
Call setContentView, then locate views by id and type to read or modify their properties.
Kotlin example
class MainActivity : AppCompatActivity() {
  override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    setContentView(R.layout.activity_main)

    // Find the TextView by its ID
    val greetingTextView: TextView = findViewById(R.id.greetingTextView)

    // Modify its properties
    greetingTextView.text = "Welcome, User!"
    greetingTextView.setTextColor(ContextCompat.getColor(this, R.color.purple_200))

    // Find the EditText for later reading
    val nameEditText: EditText = findViewById(R.id.nameEditText)
  }
}
Explanation
  • Always call setContentView before findViewById so the view hierarchy is available.
  • Use the correct Kotlin view type to get compile-time safety and clearer code.
  • After finding views, update text, colors, or attach listeners as needed.
Pitfall
Calling findViewById before setContentView or mis-typed ids returns null and often crashes the app with a NullPointerException.
Key Takeaway

Set content view, then find views by id with the correct type. This is the foundation for wiring UI to behavior.
