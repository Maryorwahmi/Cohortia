Learning Objectives

Skills and competencies you will build, arranged from foundation to application.

01
Differentiate View vs ViewGroup
Identify when an element draws and handles input versus when it arranges children. This helps you structure layouts more intentionally and avoid unnecessary containers.
Verified Competency Milestone
02
Use LinearLayout & orientation
Stack views in a row or column and distribute space using layout_weight. This produces predictable, flexible arrangements across sizes.
Verified Competency Milestone
03
Apply match_parent & wrap_content, dp & sp
Choose sizes and units that keep layouts consistent across densities and accessible for users who change font size.
Verified Competency Milestone
04
Avoid deep nesting; debug layout costs
Recognize when a layout can be flattened and how to refactor for better measurement and rendering performance.
Verified Competency Milestone
