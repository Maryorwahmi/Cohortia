Practice & Assessment

Concrete tasks and assessment framing to apply the fundamentals in a project context.

Activity
Design a profile card using a vertical LinearLayout with an ImageView and two TextViews. Use dp for image size and sp for text size.
Verified Competency Milestone
Assessment
Answer scenario questions about equal-button distribution and when to reference other view ids in RelativeLayout.
Verified Competency Milestone
Best Practice
Prefer flatter hierarchies. If layouts feel nested, consider refactoring to a single efficient container later.
Verified Competency Milestone
Debug tip
If a view doesn't appear where expected, check layout_width/height, orientation, and whether views referenced by id exist and are defined earlier.
