Definition

match_parent vs wrap_content

These values tell a view how much space to claim from its parent in a dimension.

match_parent
Expand to fill the parent's remaining space in that dimension.
wrap_content
Size to fit the view's own content only.
Units: dp vs sp
Use dp for layout sizes and margins; use sp for text sizes so the UI respects user font preferences.
Concrete Example
<Button
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:text="Click Me"
    android:textSize="18sp" />
Misconception
Using px for text or layout ties your design to raw pixels and breaks consistency across devices. Prefer dp and sp.
