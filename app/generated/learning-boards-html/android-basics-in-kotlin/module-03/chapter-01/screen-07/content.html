Three equal buttons with layout_weight

Copy this into activity_main.xml inside a layout root to experiment.

&lt;LinearLayout
    xmlns:android=&quot;http://schemas.android.com/apk/res/android&quot;
    android:layout_width=&quot;match_parent&quot;
    android:layout_height=&quot;wrap_content&quot;
    android:orientation=&quot;horizontal&quot;&gt;

    &lt;Button
        android:layout_width=&quot;0dp&quot;
        android:layout_height=&quot;wrap_content&quot;
        android:layout_weight=&quot;1&quot;

    &lt;Button
        android:layout_width=&quot;0dp&quot;

    &lt;Button
        android:layout_width=&quot;0dp&quot;

&lt;/LinearLayout&gt;
Misconception
Weights don't shrink content. If child content is larger than the allocated space, it still affects layout; design for realistic text lengths.
Example scenario
Use weights when you need proportional sizing across a row, such as toolbar segments, segmented controls, or evenly spaced buttons.
Key Takeaway

Use 0dp for the weighted axis and set layout_weight values; preview to ensure content fits at the smallest width you support.
