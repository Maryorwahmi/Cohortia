Starter XML

Paste into activity_main.xml inside the project and preview in Android Studio.

&lt;LinearLayout
    xmlns:android=&quot;http://schemas.android.com/apk/res/android&quot;
    android:layout_width=&quot;match_parent&quot;
    android:layout_height=&quot;match_parent&quot;
    android:orientation=&quot;vertical&quot;
    android:gravity=&quot;center_horizontal&quot;
    android:padding=&quot;24dp&quot;&gt;

    &lt;ImageView
        android:layout_width=&quot;100dp&quot;
        android:layout_height=&quot;100dp&quot;
        android:src=&quot;@drawable/ic_launcher_background&quot;
        android:layout_marginTop=&quot;16dp&quot;
        android:layout_gravity=&quot;center_horizontal&quot; /&gt;

    &lt;TextView
        android:layout_width=&quot;wrap_content&quot;
        android:layout_height=&quot;wrap_content&quot;
        android:text=&quot;Jane Doe&quot;
        android:textStyle=&quot;bold&quot;
        android:textSize=&quot;20sp&quot;
        android:layout_marginTop=&quot;12dp&quot; /&gt;

    &lt;TextView
        android:layout_width=&quot;wrap_content&quot;
        android:layout_height=&quot;wrap_content&quot;
        android:text=&quot;Mobile developer and coffee enthusiast.&quot;
        android:textSize=&quot;14sp&quot;
        android:layout_marginTop=&quot;8dp&quot; /&gt;

&lt;/LinearLayout&gt;
Guided tips
  • Use 100dp for the avatar so it appears similar on different densities.
  • Center elements horizontally using gravity or layout_gravity.
  • Use sp for text sizes so users adjusting font size see the change.
Key Takeaway

Start simple, preview across sizes, and adjust padding and margins to create balanced spacing.
