Understanding Layouts and View Groups

Learn how Android composes screens from Views and ViewGroups, and why the right layout choices keep apps responsive across device sizes.

Visual Overview
Views are small; ViewGroups hold and arrange them. Think of a ViewGroup as a room and Views as furniture.
View
Single drawable element that handles input and drawing, e.g., TextView or Button.
ViewGroup
Container that positions child views, e.g., LinearLayout, RelativeLayout.
Explore Key Topics
LinearLayout
Stacks children horizontally or vertically and uses layout_weight to share space.
RelativeLayout
Positions views relative to each other or the parent using id references.
Best Practices
Favor flatter hierarchies and correct dp/sp units to keep UI responsive.
