Core Concept

Nesting and layout cost

Each container increases measurement and layout passes. Deep nesting multiplies cost and can slow UI rendering.

Why it matters
More measure/layout work equals longer frame times. On animations or complex screens this leads to jank.
Refactor strategies
  • Combine stacks into a single LinearLayout with weights when possible.
  • Use RelativeLayout for simple positional relationships that eliminate wrappers.
Debugging tip
Use Android Studio's Layout Inspector to spot deep branches and expensive measure calls, then simplify the hierarchy.
Example
A UI built with three nested LinearLayouts can often be re-expressed with a single LinearLayout with appropriate weights and gravity adjustments, reducing the number of measure passes.
Key Takeaway

Aim for the flattest hierarchy that expresses layout intent clearly. Measure in the preview and refactor deep nests.
