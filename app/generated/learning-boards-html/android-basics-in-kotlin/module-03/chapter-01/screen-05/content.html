Definition

LinearLayout fundamentals

Understand orientation, weight, and best practices for proportional layouts.

Orientation
Set android:orientation to vertical or horizontal to control stacking direction.
Weight system
Give children android:layout_width or height of 0dp in the stacking axis and assign android:layout_weight to share available space.
Concrete example
Three equal buttons: set each button's width to 0dp and weight to 1 inside a horizontal LinearLayout.
Key Takeaway

Weights provide simple proportional sizing. Use 0dp along the weight axis so the layout system can allocate space predictably.

Process
  1. Choose orientation: horizontal for rows, vertical for stacks.
  2. Decide which children need proportional space.
  3. Set stacking-axis size to 0dp for those children.
  4. Assign layout_weight values to control proportions.
  5. Use layout_gravity for child alignment inside available cell space.
Common mistake
Using wrap_content for weighted children prevents weights from taking effect. Always set the axis dimension to 0dp when using weight.
