Definition

Density and units

Dp and sp abstract device pixels so layouts scale predictably across densities and user settings.

dp for layout
Use for widths, heights, margins, and padding to keep physical size consistent.
sp for text
Use for text sizes so the UI respects accessibility font-scale settings.
Practical checks
  • Preview your layout on small, medium, and large device presets.
  • Toggle font-size accessibility settings in the preview to test sp behavior.
  • Ensure images use appropriate dp sizes or use scalable drawables.
Key Takeaway

Design with dp and sp, preview across densities, and avoid absolute pixel values for a consistent experience.
