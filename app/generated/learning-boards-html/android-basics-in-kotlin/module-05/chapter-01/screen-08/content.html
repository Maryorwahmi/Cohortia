Module 5 › Chapter 5.1 › Files & Lifecycle
Step 1 — Who needs access?
Private to app → internal. User or other apps → external.
Step 2 — Size & expectation
Large media often belongs on external storage where users can manage it.
Step 3 — Sensitivity
Encrypt before putting sensitive data on external storage, or keep it internal.
Concrete example
A downloaded recipe image: store in internal files for offline in-app display. If the user chooses to export or share, copy it to external storage and handle permissions.
Common pitfall
Failing to check for external storage presence or requesting permissions at runtime can cause crashes or broken behavior. Always guard file operations and provide fallback paths.
Key Takeaway

Follow the access-size-sensitivity-lifetime checklist to pick internal, external, or cache storage.
