Module 5 › Chapter 5.1 › Internal Storage
Definition & properties
  • Private to the app; other apps can't access files.
  • Files are deleted when the app is uninstalled.
  • No runtime permission required for private internal files.
Example
Store a recipe cover image that should be accessible only to your app and removed on uninstall.
Best practices
Use for
Sensitive files, app-only caches, small to medium media intended only for the app.
System behavior
Files can be removed from cache directories under low storage pressure.
Avoid
Storing large user-shareable libraries that the user expects to access outside the app.
Key Takeaway

Internal storage gives privacy and automatic cleanup—prefer it for app-owned files that should not be shared.
