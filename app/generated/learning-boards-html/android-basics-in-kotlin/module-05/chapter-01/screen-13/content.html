Module 5 › Chapter 5.1 › Pitfalls & Best Practices
Top mistakes
  • Serializing complex objects into Shared Preferences.
  • Storing sensitive data on external storage without encryption.
  • Failing to check permissions or storage availability for external files.
  • Embedding large binaries in database rows instead of using files.
Best practices
  • Match storage to data shape and access pattern.
  • Encrypt sensitive data if it must be stored in shared areas.
  • Use Room for structured records and avoid manual cursor handling.
  • Plan migrations and document your storage design.
Check your understanding
Can you name one scenario where a database is better than a file and one where a file is better than a database?
Key Takeaway

Anticipate growth, privacy, and access patterns to avoid costly refactors and data leaks.
