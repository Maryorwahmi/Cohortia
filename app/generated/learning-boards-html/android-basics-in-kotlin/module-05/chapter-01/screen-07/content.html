Module 5 › Chapter 5.1 › External Storage
What it means

Shared storage space accessible to the user and other apps. Ideal for large media and files meant to be shared or exported.

Example
Save exported recipe PDFs or photos so the user can open them in other apps or transfer them elsewhere.
Considerations
  • Requires runtime permissions in many cases.
  • Files are public and can be modified or deleted by others.
  • May be unavailable if an external card is removed.
When to prefer
User-sharable content and large media.
Risks
Not secure; treat as untrusted storage unless encrypted.
Key Takeaway

Choose external storage when users need to access or share files outside the app, but add permission checks and treat files as untrusted.
