Why use a database
  • Efficient queries and filters for many records.
  • Structured schema and relationships between entities.
  • Better growth characteristics than ad-hoc files or preferences.
Practical example
A journal app where entries are searchable by date and keyword should use a database for speed and flexibility.
Common misconception
Databases are only for massive apps. In reality, adopting a database early avoids brittle workarounds when records grow.
Note on binary data
Store large images as files and keep their file paths in the database instead of placing binary blobs inside rows.
Key Takeaway

When you need queries, sorts, or relationships, a database is the robust solution.
