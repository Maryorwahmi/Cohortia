Module 5 › Chapter 5.1 › Learning Objectives
01
Identify storage options
Recognize Shared Preferences, files, databases, and network storage.
You will be able to name the main mechanisms and explain a simple example for each, such as storing a theme preference or saving a photo.
VERIFIED COMPETENCY MILESTONE
02
Understand trade-offs
Complexity, performance, security trade-offs.
You will evaluate a choice by asking whether structured queries, file size, or user access matter, and choose accordingly.
VERIFIED COMPETENCY MILESTONE
03
Differentiate private vs shared
How uninstall and permissions affect lifecycle.
You will explain why internal files are removed on uninstall and why external files require user permissions and are less private.
VERIFIED COMPETENCY MILESTONE
04
Apply choices to scenarios
Map data types to storage strategies.
You will practice choosing storage in a recipe app scenario, justifying each decision based on privacy and structure.
VERIFIED COMPETENCY MILESTONE
Bloom's taxonomy
Learn → Understand → Apply → Master
Use these objectives as checkpoints as you read examples and complete the activity at the end of the chapter.
