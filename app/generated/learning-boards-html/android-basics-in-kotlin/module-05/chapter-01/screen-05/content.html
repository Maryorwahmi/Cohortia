Module 5 › Chapter 5.1 › Shared Preferences
What it is

A simple dictionary of key-value pairs stored persistently. Best for tiny, app-specific settings.

Example
Save a boolean flag that keeps the user in dark mode across app launches.
Common mistake
Serializing complex objects or long lists into preferences instead of using a database or files.
Quick code example
// Pseudo-Kotlin style example
val prefs = context.getSharedPreferences("settings", Context.MODE_PRIVATE)
val editor = prefs.edit()
editor.putBoolean("dark_mode", true)
editor.apply()

val isDark = prefs.getBoolean("dark_mode", false)
Use apply for async save; get with a default value.
When to use
Preferences, small flags, one-off values.
Avoid
Large lists, binary data, or sensitive tokens without encryption.
