Warning External Storage
External storage: permissions and availability
Key checks before writing to shared storage.
Permissions
Declare READ_EXTERNAL_STORAGE or WRITE_EXTERNAL_STORAGE when targeting older APIs. For modern scoped storage, follow platform guidance. This chapter focuses on the basic considerations rather than runtime flows.
Availability
Check whether external storage is mounted and writable before writing. External media can be removed or temporarily inaccessible.
Security
External storage is not private; avoid storing passwords or unencrypted API keys there. If unavoidable, encrypt data before writing.
Danger Zone

Do not place sensitive or unencrypted credentials on external storage. Improper handling leads to security breaches or runtime exceptions when permissions are missing.
