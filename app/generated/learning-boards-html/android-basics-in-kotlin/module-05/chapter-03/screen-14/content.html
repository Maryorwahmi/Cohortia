Key Concepts
Remember these essentials when working with files.
Internal Storage
Private to your app and deleted on uninstall.
getFilesDir / getCacheDir
Use getFilesDir for persistent files; getCacheDir for temporary files the system may remove.
Stream I/O
Use FileOutputStream/FileInputStream and Kotlin's use to safely write and read bytes.
Takeaway

Default to internal storage for privacy and simplicity. For external files think about permissions, availability, and security before writing.
