Core Concept Definition
Why files instead of SharedPreferences
Match storage choice to data size and shape.
Key properties
  • Files handle large text or binary data and support sequential I/O.
  • Files allow append behavior useful for logs and streaming writes.
  • SharedPreferences is optimized for small, structured key-value pairs, not long blobs.
  • Use files for images, documents, and logs where queryability isn’t required.
Key Takeaway

Files are the right tool for larger or binary content; choose storage by data size and access pattern.

Concrete example
A chat app that stores full conversation history, attachments, or a download cache should use files rather than SharedPreferences. For instance, saving images as files lets you stream bytes and avoid loading everything into memory at once.
Common misconception
Some developers try to store large JSON blobs inside SharedPreferences. This leads to slow reads and harder migration; files or a database are better options.
Pro tip
If you anticipate queries on fields inside the data, prefer a database. Use files when simple read/write or append is sufficient.
