Learning Objectives
Skills and reasons you’ll take away from this chapter.
01
Differentiate storage types
Know the security, visibility, and lifecycle differences between internal and external storage so you store data in the correct place.
Mnemonic: Safe vs Shared
VERIFIED COMPETENCY MILESTONE
02
Read and write internal files
Implement file I/O using FileOutputStream, FileInputStream or openFileOutput and openFileInput, and use Kotlin's use extension to close streams safely.
Mnemonic: Stream → Close
VERIFIED COMPETENCY MILESTONE
03
Understand lifecycle and security
Know that internal files are removed on uninstall and cache files may be deleted by the system when space is low.
Mnemonic: Deleted on Uninstall
VERIFIED COMPETENCY MILESTONE
04
Know Context storage methods
Explain getFilesDir and getCacheDir and their intended uses: persistent files versus temporary cache that the system may remove.
Mnemonic: Files vs Cache
VERIFIED COMPETENCY MILESTONE
