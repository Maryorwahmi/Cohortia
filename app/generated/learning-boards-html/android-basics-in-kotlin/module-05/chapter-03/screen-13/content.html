Assessment Quiz
Assessment: Choosing storage and handling sensitive data
Brief questions and correct answers with rationale.
Question 1
Where to store a large user-generated image that must be private and deleted on uninstall? Provide the Context method.
Correct answer
Use internal storage; get the directory with context.filesDir and save the image there.
Question 2
What are two major problems with saving unencrypted API keys to external storage without requesting permissions, and how to improve?
Correct answer
Problems: security risk because external storage is public; and writes can fail or throw SecurityException if permissions are missing. Improve by using internal storage or encrypting keys and handling required permissions properly.
Assessment Tip

When you justify storage choices, mention privacy, lifecycle (uninstall), permission needs, and whether the data can be recreated.
