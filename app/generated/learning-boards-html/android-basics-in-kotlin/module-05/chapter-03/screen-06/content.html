Process Flow Write & Read
Write and read a text file in internal storage
A safe code walkthrough using streams and Kotlin's use extension.
Write example (Kotlin)
import android.content.Context
import java.io.File
import java.io.FileOutputStream

fun writeToFileInternal(context: Context, filename: String, content: String) {
    try {
        val file = File(context.filesDir, filename)
        FileOutputStream(file).use {
            it.write(content.toByteArray())
        }
        println("File written to internal storage: ${file.absolutePath}")
    } catch (e: Exception) {
        e.printStackTrace()
        println("Error writing file to internal storage: ${e.message}")
    }
}
Read example (Kotlin)
import android.content.Context
import java.io.File
import java.io.FileInputStream

fun readFromFileInternal(context: Context, filename: String): String? {
    try {
        val file = File(context.filesDir, filename)
        if (!file.exists()) {
            println("File does not exist: ${file.absolutePath}")
            return null
        }
        FileInputStream(file).use {
            val bytes = it.readBytes()
            return String(bytes)
        }
    } catch (e: Exception) {
        e.printStackTrace()
        println("Error reading file from internal storage: ${e.message}")
        return null
    }
}
Explanation
  • Use File(context.filesDir, filename) to target internal storage.
  • Kotlin's use closes streams even when exceptions occur.
  • Check file.exists() to avoid reading missing files.
