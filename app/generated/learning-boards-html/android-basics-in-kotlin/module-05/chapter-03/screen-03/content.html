Learning Objectives — Continued
Practical checks, safety notes, and the hands-on activity.

External storage considerations
Discuss permissions, availability, and the shared nature of external storage so you handle user data correctly.
Mnemonic: Ask Permission
VERIFIED COMPETENCY MILESTONE
02
Handle errors safely
Wrap I/O in try-catch blocks and log or surface errors so your app degrades gracefully when storage is full or unavailable.
Mnemonic: Try-Catch Always
VERIFIED COMPETENCY MILESTONE
03
Avoid common mistakes
Close streams with use, avoid unencrypted sensitive data on external storage, and check storage state before operations.
Mnemonic: Close, Check, Encrypt
VERIFIED COMPETENCY MILESTONE

Complete the logging activity
Implement append-style logging to a private file and read it back to display or log for debugging.
Mnemonic: Append & Read
