Create and Read an App Log File
Step-by-step implementation notes and starter snippet.
Steps
  1. Create LOG_FILENAME = "app_log.txt" and TextView with id log_display_text.
  2. Implement logEvent(message) to build timestamp + message and use openFileOutput with Context.MODE_APPEND.
  3. Implement readLogFile() to open the file, read bytes, and return a String or null if missing.
  4. Call logEvent in onCreate and set the TextView text to readLogFile() result.
Starter code (excerpt)
private val LOG_FILENAME = "app_log.txt"

private fun logEvent(message: String) {
    val timestamp = SimpleDateFormat("yyyy-MM-dd HH:mm:ss", Locale.getDefault()).format(Date())
    val logEntry = "$timestamp: $message
"
    try {
        openFileOutput(LOG_FILENAME, Context.MODE_APPEND).use {
            it.write(logEntry.toByteArray())
        }
    } catch (e: Exception) {
        e.printStackTrace()
    }
}

private fun readLogFile(): String? {
    try {
        val file = File(filesDir, LOG_FILENAME)
        if (!file.exists()) return null
        openFileInput(LOG_FILENAME).use {
            val bytes = it.readBytes()
            return String(bytes)
        }
    } catch (e: Exception) {
        e.printStackTrace()
        return null
    }
}
