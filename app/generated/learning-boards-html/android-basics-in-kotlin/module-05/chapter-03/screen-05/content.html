Definition Internal Storage
getFilesDir and getCacheDir
Pick persistent app files or temporary cache carefully.
API reminders
getFilesDir(): Returns the path for persistent internal files that survive restarts until app uninstall.
getCacheDir(): Returns the path for temporary cache files; system may delete these when storage is low.
Internal storage does not require external storage permissions because it is private to your app.
Example
Save app_log.txt to getFilesDir so logs remain until uninstall. Save ephemeral thumbnails to getCacheDir since they can be recreated.
Key Takeaway

Use filesDir for persistent app files; cacheDir is for temporary data the system can evict.

Annotation cards
When to pick filesDir
When the user expects the file to remain until uninstall, like logs or user documents.
When to pick cacheDir
When the data can be recreated and you want automatic eviction under low storage.
Misconception check
Don’t assume cacheDir is safe for critical data; it may disappear at any time.
