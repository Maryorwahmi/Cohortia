Checklist Common Mistakes
Common mistakes and safety notes
Quick practices to avoid bugs and leaks.
Mistakes
  • Forgetting to close streams — use use to auto-close.
  • Not catching IOExceptions — wrap I/O in try-catch.
  • Storing sensitive data on external storage unencrypted.
  • Assuming cacheDir is persistent.
Pro tips
Use openFileOutput/openFileInput for quick internal file access.
Prefer app-specific external directories over public ones when possible so files are removed on uninstall.
Log errors during file I/O for easier debugging and fail gracefully when storage is unavailable.
Key Takeaway

Adopt resource-safe patterns and defensive checks to keep file I/O reliable and data secure.
