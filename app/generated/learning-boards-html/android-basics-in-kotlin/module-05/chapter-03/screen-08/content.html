File lifecycle and uninstall behavior
Know where files persist and when they are removed.
Internal files
Private to app. Deleted on uninstall. Use for sensitive or app-specific persistent files.
Cache files
Stored in getCacheDir. The system may delete these when storage is low. Do not store critical data here.
External files
Shared or app-specific external directories. Public files may persist after uninstall; app-specific external files often get removed on uninstall.
Common mistake

Assuming cache is permanent or external is always persistent. Check where you write and the removal semantics for that directory.
