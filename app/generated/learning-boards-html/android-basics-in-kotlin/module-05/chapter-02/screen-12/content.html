Assessment ideas
Question 1
Save the selected theme string and explain why apply is preferred for UI settings.
Expected: Use Editor.putString and apply. apply is asynchronous and keeps UI responsive.
Question 2
Retrieve lastLoginTimestamp as a long and correct code that omitted a default.
Expected: sharedPreferences.getLong("lastLoginTimestamp", 0L) to avoid runtime issues.
Best practices
  • Use Context.MODE_PRIVATE to secure preference files.
  • Centralize keys as constants to avoid typos.
  • Prefer apply for routine saves on the main thread.
  • Avoid serializing large objects into preferences; use a database instead.
