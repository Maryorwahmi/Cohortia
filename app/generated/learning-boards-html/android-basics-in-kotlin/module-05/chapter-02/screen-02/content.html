Learning Objectives

Learn, understand, apply, and master SharedPreferences basics.

Bloom: Learn → Understand → Apply → Master
01
Get an instance

Learn getSharedPreferences and default preferences so you can access the right file securely.

VERIFIED COMPETENCY MILESTONE
02
Store primitives

Use Editor's putString, putInt, putBoolean, putFloat, and putLong to persist small values.

VERIFIED COMPETENCY MILESTONE
03
Retrieve with defaults

Always provide a sensible default when reading to avoid unexpected behavior if a key is missing.

VERIFIED COMPETENCY MILESTONE
04
Apply or commit safely

Understand the trade-offs: non-blocking saves vs. synchronous confirmation when required.

VERIFIED COMPETENCY MILESTONE
