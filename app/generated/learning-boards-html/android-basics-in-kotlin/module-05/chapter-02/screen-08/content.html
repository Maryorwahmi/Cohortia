Safe getters
getBoolean(key, default) — returns the saved boolean or the provided default.
getString(key, default) — returns the saved string or default. Avoid null by providing a sensible fallback.
getInt / getFloat / getLong — also require defaults; choose types that match what you stored.
Example
When reading the notification toggle, default to true or false depending on your app's safe default behavior.
Concrete scenario
First run of the app
No keys exist yet. By supplying defaults your app can render sensible UI without crashes or null handling.
Common mistake
Forgetting a default or using the wrong type for a key leads to unexpected behavior. Prefer constants and consistent types across reads and writes.
