Module 5 › Chapter 5.2 › What is SharedPreferences?
Definition

SharedPreferences stores key-value pairs for small, primitive data types. Use it for persistent UI settings and lightweight state.

Metaphor
A settings drawer

Easy access for a few items. Not a storage chest for large objects.

Use case
Remember toggles and small preferences
Misconception
Not for relational or large structured data
Key Takeaway

Use SharedPreferences for small, frequently-read settings that should persist across launches.

Quick comparison
SharedPreferences
Key-value store for primitives, lightweight, easy to use from Activities and Services.
Room / Database
Better for structured, relational, or large data sets — more overhead but scalable.
Concrete example
Save notification toggle and greeting name

These two small values persist across app restarts and control UI state on launch.

Check your understanding
Why would you avoid storing a large list of objects in SharedPreferences? Think about read and write efficiency and schema complexity.
