Module 5 › Chapter 5.2 › Writing Preferences
Process

Editor sequence

1
Get instance and Editor
Call getSharedPreferences(...).edit() to obtain an Editor for writes.
2
Call put methods
Use putString, putBoolean, putInt, putFloat, or putLong to queue changes.
3
Persist changes
Call apply to save asynchronously or commit to save synchronously.
Concrete example
Queue putBoolean for darkModeEnabled and putString for username, then call apply once to persist both values.
Illustration
// Pseudocode flow
val prefs = requireActivity().getSharedPreferences("MyAppPreferences", Context.MODE_PRIVATE)
val editor = prefs.edit()
editor.putBoolean("darkModeEnabled", true)
editor.putString("username", "kotlin_dev")
editor.apply() // persist asynchronously
Pro tip
Use a single editor for grouped changes to reduce writes. Avoid apply on extremely critical immediate-write cases where confirmation is required.
