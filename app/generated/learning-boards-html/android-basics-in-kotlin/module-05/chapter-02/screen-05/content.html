Comparison

Named file vs Default preferences

getSharedPreferences(name, mode)
Use when you want a specific file name and explicit separation of settings.
PreferenceManager.getDefaultSharedPreferences(context)
Convenient app-wide preferences file derived from your package name.
Practical rule

Use default for general settings; use named files to separate feature-specific preferences.

Concrete example
Named file
If a feature module needs isolated preferences, name the file like "com.example.feature_prefs" and use MODE_PRIVATE.
Common mistake
Mixing methods and expecting keys saved in one file to appear in the other. Keep a consistent approach to avoid missing keys and surprises when reading values.
Why it matters

Choosing the right instance prevents accidental key collisions and ensures data is scoped appropriately for your app's needs.
