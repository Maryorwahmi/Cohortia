Module 5 › Chapter 5.2 › Key Concepts
SharedPreferences
A persistent key-value store for small primitive data types.
Editor
Use putString/putBoolean/etc., then call apply or commit to save changes.
Defaults
Always supply sensible default values when reading to avoid surprises and crashes.
Summary

SharedPreferences is ideal for small app preferences. Use Editor and apply for responsive saves, and always provide defaults.
