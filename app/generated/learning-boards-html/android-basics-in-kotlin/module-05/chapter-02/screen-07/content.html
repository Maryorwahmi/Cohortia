Module 5 › Chapter 5.2 › apply vs commit
Comparison

apply (asynchronous)

Writes in the background and returns immediately. Preferred for UI settings to avoid blocking.

When to use
Saving toggles, theme choices, or other non-critical settings that do not require immediate confirmation.
Comparison

commit (synchronous)

Blocks until the write finishes and returns true on success. Use sparingly when you must know the write succeeded immediately.

When to use
Critical writes requiring immediate confirmation, and only from background threads or rare main-thread cases with careful consideration.
Common mistake

Calling commit for routine UI saves on the main thread can cause jank or ANRs. Prefer apply unless you need synchronous confirmation.
