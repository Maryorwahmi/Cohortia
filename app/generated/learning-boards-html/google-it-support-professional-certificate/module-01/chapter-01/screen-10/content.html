Tier 3: Specialist Support
Address infrastructure or application issues that require system-level access or engineering changes.
When Tier 3 acts
  • Server outages, database failures, and network architecture faults.
  • Tasks needing admin privileges or development changes.
  • System-wide incidents impacting multiple departments.
Example
Intermittent database outages require Tier 3 to inspect logs, resource usage, and possibly patch or reconfigure the server to restore stability.
Best practice for escalation
Provide clear reproduction steps, logs, timestamps, and any recent changes so Tier 3 can act efficiently.
Key Takeaway
Tier 3 resolves deep-rooted system problems; good prior documentation speeds resolution and reduces downtime.
