Tier 1: Help Desk Basics
Handle common, easily resolvable issues and restore user productivity quickly.
Typical Tasks
  • Password resets and account unlocks.
  • Basic software installs and updates.
  • Simple network connectivity checks and peripheral setup.
Example
A user cannot log in. Verify identity, reset the password per policy, and confirm access to required applications.
When to escalate
If the issue persists after standard checks, shows hardware failure signs, or affects multiple users, escalate with notes.
Key Takeaway
Tier 1 resolves many problems quickly; good documentation ensures smooth escalations when needed.
