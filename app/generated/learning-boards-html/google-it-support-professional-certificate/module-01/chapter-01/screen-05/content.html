Triage Steps
  1. Gather the user's description and urgency.
  2. Ask clarifying questions: scope, recent changes, error text.
  3. Attempt quick, documented fixes appropriate for Tier 1.
  4. Decide to close or escalate with notes.
Example Ticket Routine
User reports a printing error. Ask when it started, check printer queue, confirm cables, try restart, note result, then escalate if hardware fault persists.
Documentation & Handoffs
Good notes shorten resolution time. Include steps you tried, error messages, and user impact. That lets Tier 2 or Tier 3 pick up work without repetition.
Checklist Card
Time, symptom, steps attempted, result, and escalation reason (if any).
Common mistake
Skipping notes because you think you'll remember. Always write it down.
