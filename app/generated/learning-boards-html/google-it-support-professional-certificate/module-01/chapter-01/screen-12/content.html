User Complaint
"My computer is making a really loud grinding noise, and it's running incredibly slow." Use questions to narrow the cause.
Immediate Questions
  • When did the noise start and is it continuous?
  • Did you recently install hardware or software?
  • Does slowness affect all apps or specific ones?
Likely Hardware Components
Hard drive (mechanical failure), cooling fan obstruction, or failing power supply may cause grinding and slowness.
Initial Steps
Save work, shut down safely, remove external drives, inspect vents, and restart to observe symptoms.
If unresolved
Collect error messages and logs, capture SMART data if possible, and prepare to escalate for hardware repair.
Key Takeaway
Protect user data first, use focused tests, and escalate promptly when mechanical failure is likely.
