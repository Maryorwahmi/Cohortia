Tier 2: Intermediate Support
Handle persistent or configuration-level problems that Tier 1 cannot resolve.
Common Tasks
  • Advanced application debugging and configuration fixes.
  • Operating system repairs and driver troubleshooting.
  • Advanced hardware diagnostics and targeted repairs.
Example
If updates cause repeated crashes, Tier 2 analyses logs, tests rollbacks, and repairs the installation rather than blindly reinstalling software.
When to escalate to Tier 3
Escalate for server, database, or infrastructure-level problems that require specialised engineer intervention.
Key Takeaway
Tier 2 uses diagnostic evidence to repair issues, limiting unnecessary system changes and preserving uptime.
