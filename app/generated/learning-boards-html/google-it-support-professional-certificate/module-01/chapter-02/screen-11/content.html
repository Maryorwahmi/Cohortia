Common failures
Failing HDD
Grinding noises, SMART warnings, slow file access or read errors.
Insufficient RAM
High swap usage, frequent disk activity, sluggish multitasking.
Overheating CPU
Thermal throttling, sudden slowdowns, unexpected shutdowns.
Faulty PSU
Intermittent reboots, components failing under load, or no power at all.
Diagnostic steps
  1. Listen for drive noises and check SMART status for disks.
  2. Monitor memory and CPU utilization during the reported slow periods.
  3. Check temperatures and clean dust from heatsinks and fans.
  4. Test with a known‑good PSU or use a power supply tester if available.
Scenario
A system with slow file access and occasional read errors likely needs drive replacement; back up data immediately and advise replacement rather than continued use.
