Module 1 › Chapter 1.2 › Von Neumann
Core claim
A single processor executes instructions fetched from memory; storage and memory are distinct layers in the data path.
Definition
CPU + Memory + Storage model that explains program execution flow.
Example
Opening an app: binary loads from drive into RAM; CPU executes instructions from RAM.
Common misconception
The CPU does not repeatedly read the disk for active data; it relies on RAM to hold working data.
Key Takeaway

Trace performance problems to either memory capacity or storage speed using the Von Neumann data path as your guide.

Annotated process flow
Storage
Persistent files live here. Example: application binary on an SSD or HDD.
Memory (RAM)
Fast, volatile workspace that holds code and data while the CPU operates.
CPU
Executes instructions and manipulates data from RAM; writes results back to memory or storage.
Scenario card
A user opens a large spreadsheet and sees lag. If RAM is full, the system swaps data with storage and slows down. Options: add RAM or use faster storage to reduce swapping.
