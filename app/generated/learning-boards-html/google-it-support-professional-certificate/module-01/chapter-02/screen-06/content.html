RAM: volatile workspace
Definition: fast, temporary memory used by the CPU to hold active code and data.
Capacity
Measured in gigabytes. More capacity supports more simultaneous programs.
Volatility
Data is lost on power off; use storage for persistence.
Example
Editing a large image relies on RAM to hold the image data; insufficient RAM triggers swapping and slow edits.
Misconception
Adding RAM doesn't fix slow disk reads. If a system is I/O bound, use faster storage instead of unlimited RAM.
Key Takeaway

Measure memory usage and swap activity before recommending RAM upgrades; match modules to motherboard specs.

Quick checks
  • Task manager shows memory near 100% → consider more RAM.
  • High disk activity with low CPU usage → indicates swapping to storage.
  • Confirm DDR generation and slot configuration before adding modules.
Scenario
A user with many browser tabs and background apps experiences slowdowns. If memory is full, recommend additional RAM rather than a CPU upgrade.
