Module 1 › Chapter 1.2 › Input → Output
Process steps
1. Input captured
Mouse or keyboard sends a signal to the OS.
2. Load from storage
Executable or file is read and loaded into RAM.
3. Execute in CPU
CPU fetches instructions from RAM and performs operations.
4. Output produced
Results are sent to display, storage, or network as needed.
Example walkthrough
Opening a spreadsheet: the file loads from storage into RAM, the CPU calculates formulas using data in RAM, and the updated view appears on the monitor. If the sheet is huge and RAM is low, the system may swap pages and slow down.
Check your understanding
If a user clicks and nothing happens, inspect whether input is registered, whether storage is responsive, and whether BIOS or boot order changed, following the data path to isolate the issue.
