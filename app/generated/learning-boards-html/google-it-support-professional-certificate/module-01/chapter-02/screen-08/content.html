Motherboard: the communication backbone
Contains CPU socket, RAM slots, storage connectors, expansion slots and the chipset that manages data flow.
CPU Socket
Holds and connects the processor to the board's power and data buses.
RAM Slots
Place RAM modules in recommended slots for optimal channel configuration.
PCIe / M.2
Expansion and high‑speed storage connectors; lane counts affect throughput.
Practical tip
Check the motherboard manual to confirm slot priorities and supported configurations before installing new cards or drives.
Checklist for installs
  • Confirm CPU socket compatibility and supported generations.
  • Match RAM type and populate slots as the manual recommends for channels.
  • Install NVMe in correct M.2 slot to get full PCIe lanes when required.
Common mistake
Putting a card in the wrong slot or using unsupported RAM leads to reduced performance or failed boots; the board, not the device, is often the constraint.
