CPU: the operational center
Definition: executes program instructions and performs arithmetic and logical operations.
Clock Speed
Measured in GHz; more cycles per second can improve single‑threaded tasks.
Cores
Multiple cores allow parallel task execution and better multitasking.
Example
A video encoding job benefits from more cores; opening many browser tabs benefits from more RAM and multiple cores working together.
Common mistake
Assuming a faster clock always fixes slow systems. If the workload is I/O bound, the CPU is often waiting for data and a storage upgrade is better.
Key Takeaway

Diagnose whether tasks are CPU bound or waiting on memory or storage before recommending a CPU upgrade.

Quick diagnostics
  • High sustained CPU usage across cores → CPU bound.
  • Short spikes with swapping activity → possibly I/O or insufficient RAM.
  • Thermal throttling and sudden slowdowns → check cooling and vents.
Scenario
If a desktop runs many background tasks and is unresponsive, check task manager for CPU usage and background processes before suggesting hardware changes.
