Best Practices & Safety
Safe OS Practices, Common Mistakes, and Quick Diagnoses
A compact checklist for safe, effective troubleshooting.
Quick Diagnostic Checklist
  1. Gather system info: kernel version and system details.
  2. List processes and note high CPU or duplicate entries.
  3. Check memory and swap usage for signs of exhaustion.
  4. Inspect disk usage and file permissions before changes.
  5. Verify device drivers and network configuration for peripherals and connectivity.
Common Mistakes
- Acting without backups or permission checks.
- Trusting GUI errors without gathering logs or CLI output.
Action Cards
Confirm current permission level before running privileged commands.
Back up important data prior to system updates or mass file operations.
Collect CLI outputs and logs to preserve evidence for diagnosis.
