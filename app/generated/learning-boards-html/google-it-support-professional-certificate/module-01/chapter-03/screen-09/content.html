Interfaces
GUI vs CLI
Visual tools for ease, text tools for speed and automation.
Graphical User Interface (GUI)
  • Icons, menus, and windows for discovery and adjustment.
  • Good for one-off tasks and users who prefer visual controls.
  • Less efficient for repetitive tasks or remote servers without a desktop environment.
Example
Opening a file manager and clicking to see files and properties.
Command Line Interface (CLI)
  • Text commands for quick diagnostics and automation.
  • Essential when GUI fails or on headless servers.
  • Commands are scriptable for repeatable tasks.
Example
Running a single command to list directory contents or to show network settings and IP addresses.
