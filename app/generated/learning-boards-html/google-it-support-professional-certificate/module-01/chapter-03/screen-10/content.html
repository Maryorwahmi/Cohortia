Basic CLI Commands to Know
Commands for navigation, system info, and network checks.
Navigation & Listing
Windows: dir to list files, cd to change directories.
macOS/Linux: ls to list, cd to change directories, use tilde for home.
Example
Run cd to the user's folder then run dir or ls to confirm a missing file's presence.
Network & System Info
Network: ipconfig on Windows; ifconfig or ip a on macOS/Linux to see addresses.
System: systeminfo on Windows; uname -a on macOS/Linux for kernel and platform details.
Safety
Check your permission level before running commands that change system state. Use elevated rights only when necessary and back up important data first.
