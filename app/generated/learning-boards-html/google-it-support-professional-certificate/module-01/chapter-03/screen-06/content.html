Memory Management
How the OS Manages Memory
Allocation, protection, and swap keep programs running and data safe.
Key Concepts
  • Allocation: giving each process the memory it needs.
  • Isolation: preventing one process from accessing another's memory space.
  • Swap: using disk to extend memory when RAM is low, with performance cost.
Example
A browser with many open tabs can consume lots of RAM. The OS may compress memory or move inactive pages to swap to free RAM for active tasks.
Inspecting Memory
What to check: total RAM, free vs used, per-process allocation, and swap usage.
Symptoms of trouble: high swap activity, slow response when opening programs, or crashes with out-of-memory errors.
Immediate actions: close heavy applications, restart services, and plan for RAM upgrades if persistent.
Pro Tip

Track memory trends over time. A one-time spike may be normal, but steady increases suggest a leak needing further investigation.
