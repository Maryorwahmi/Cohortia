Process Management
How the OS Manages Processes
Scheduling, priorities, and multitasking keep the system responsive.
Process Flow
1
Create
Programs spawn processes when you open apps or services start.
2
Schedule
The kernel assigns CPU time slices and priorities to keep the system responsive.
3
Wait / Block
Processes may wait for I/O, network, or user input and are suspended until ready.
4
Terminate
When finished, processes release resources and exit, returning information to the parent process.
Example
If a file copy runs in the background, the scheduler gives short CPU bursts to the copy process while keeping the UI responsive so you can continue working.
Inspect & Troubleshoot
  • What to check: process list, CPU usage percentage, repeated processes, and process parentage.
  • Common cause: runaway processes or many background tasks that collectively consume CPU.
  • Quick action: identify the process ID and note whether it can be safely stopped or needs a controlled restart.
Common Mistake

Assuming a visible app is the cause. Background services or system processes can be the real source of CPU pressure.
