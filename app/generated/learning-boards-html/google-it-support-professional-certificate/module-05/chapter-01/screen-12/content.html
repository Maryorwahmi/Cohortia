Module 5 › Chapter 5.1 › Design Agency Upgrade
Identify limitations
  • Single tower server is a single point of failure and not rack-mounted.
  • Local storage is not optimized for multi-user large-file sharing.
  • Basic Wi-Fi router may limit throughput and lacks VLAN or QoS features.
Proposed components
Server: Rack server for virtualization and scalability.
Storage: NAS for shared design files and backups.
Networking: Managed switch and business router for wired speed and segmentation.
Simple connection diagram
[Internet]
  |
[Business Router]
  |
[Managed Switch]
  |---- [Rack Server (virtual machines)]
  |---- [NAS (shared files)]
  |---- [Workstations/Clients]
Justification
Rack server supports virtualization for the new app. NAS centralizes large files and simplifies backups. Managed switch and router provide consistent wired performance and proper segmentation.
Key Takeaway

Propose infrastructure that balances current needs and planned growth, prioritizing shared storage and managed networking for performance.
