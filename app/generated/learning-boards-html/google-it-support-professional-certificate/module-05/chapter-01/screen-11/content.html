Module 5 › Chapter 5.1 › Troubleshooting Network vs Storage vs Compute
Layered troubleshooting
A repeatable checklist prevents unnecessary changes and speeds diagnosis.
1
Confirm and reproduce
Validate the user report and capture steps to reproduce the issue.
2
Network checks
Ping gateway, traceroute external hops, inspect switch links.
3
Compute metrics
Check CPU, memory, and local disk I/O on servers.
4
Storage validation
For NAS check network paths; for SAN check host connectivity and LUN presentation.
Concrete example
If a team reports slow file saves during business hours, reproduce the action, ping the NAS, check server CPU and disk queue lengths, and verify switch utilization to find the bottleneck.
Misconception
Jumping to application fixes without checking network and storage often wastes time.
Key Takeaway

Follow a repeatable, layered checklist: confirm, network, compute, storage. Document each step and use reversible changes.
