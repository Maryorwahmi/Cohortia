Storage Area Network
Dedicated high-speed network providing block-level storage to multiple servers.
SANs deliver low-latency and high-throughput storage suitable for databases and virtual machines. They use technologies like Fibre Channel or iSCSI and allow centralized features such as snapshots and provisioning. The design requires planning for network fabric, redundancy, and host connectivity.
Concrete example
A database cluster uses SAN block devices to guarantee consistent low-latency I/O across multiple hosts and to enable live migration of virtual machines.
When to choose
High-performance databases, virtualization, and large-scale storage pools.
Considerations
Higher cost, fabric planning, and management overhead.
Key Takeaway

Use SAN for block-level, performance-sensitive workloads; ensure network fabric and host adapters support the design.
