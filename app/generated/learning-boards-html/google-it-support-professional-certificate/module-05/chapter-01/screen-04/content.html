Module 5 › Chapter 5.1 › What is IT Infrastructure?
IT infrastructure
Hardware, software, network resources, and services that make IT operations possible.
Think of infrastructure as layered: physical servers and storage sit at the bottom, operating systems and applications sit above, and the network ties everything together. When troubleshooting, ask about each layer. A single symptom may span compute, storage, and network causes.
Example
Slow file access at peak hours often means storage I/O or network saturation, not just server CPU load.
Common mistake
Blaming applications before checking hardware resources and network connectivity.
Key Takeaway

Treat infrastructure as layers: compute, storage, and network. Troubleshoot each layer systematically.

Layered view
Hardware
Servers, storage, switches, routers.
Software
Operating systems, management tools, applications.
Network
Connectivity that enables access and data flow.
Why it matters
A holistic approach reduces time-to-resolution and avoids misdirected fixes.
