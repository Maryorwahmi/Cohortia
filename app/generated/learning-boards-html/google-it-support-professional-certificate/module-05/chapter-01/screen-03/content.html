Practical skill: Server selection
Choose based on workload, space, redundancy, and growth plans. Planning reduces costly upgrades.
Mnemonic
Think CPU, RAM, Storage, Network — and then Scale.

Practical skill: Storage trade-offs
Match shared access needs to NAS for files or SAN for block-level, high-performance workloads.
Mnemonic
NAS = File sharing; SAN = Block performance.
VERIFIED COMPETENCY MILESTONE
Practical skill: Network troubleshooting
Use simple tools like ping and traceroute to isolate local vs external issues and verify IP configurations before sweeping changes.
Mnemonic
Local problems → switch; external problems → router.
VERIFIED COMPETENCY MILESTONE
Practical skill: Operational best practices
Plan for scalability, test changes in controlled windows, and document power and cabling to reduce outages and speed recovery.
Mnemonic
Plan, Test, Document, Repeat.
