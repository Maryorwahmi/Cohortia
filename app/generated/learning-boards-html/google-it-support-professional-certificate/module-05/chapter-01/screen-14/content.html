Module 5 › Chapter 5.1 › Quick Assessment
Question 1
A 10-person startup needs centralized file sharing and backups. Which storage solves this cost-effectively?
Answer: Network Attached Storage (NAS). It provides file-level sharing over Ethernet and is simpler and more affordable than a SAN for this use.
Question 2
Devices can communicate internally but not reach external websites. Which device is likely misconfigured?
Answer: The router. Routers manage traffic between networks; check routing and firewall rules after verifying local connectivity.
Why this matters
Matching the right technology to the problem keeps costs manageable and reduces unnecessary complexity. Always validate assumptions with simple tests before recommending major changes.
Key Takeaway

Choose solutions that meet actual needs: NAS for file sharing, router checks for external access issues. Avoid overengineering.
