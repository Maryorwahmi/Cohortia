Module 05 › Chapter 5.4 › Support Workflow
Interfaces and routine checks

Use the Console for visual checks, gcloud for repeatable actions, and gsutil for storage operations. IAM governs who can do what.

1. Reproduce
Try to reproduce the issue in Console or CLI to confirm symptoms before changing anything.
2. Collect evidence
Gather monitoring graphs, logs, and configuration snapshots to build an initial hypothesis.
3. Test fixes safely
Apply configuration changes in a safe environment or use a rollback plan when modifying production resources.
Concrete scenario

User reports slow website. Reproduce by requesting the site, gather CPU, disk, and load balancer metrics, check firewall rules, and then test scaling or disk changes in a staging environment before applying to production.

Common mistake

Changing production configuration without evidence can create larger incidents. Always collect metrics and have a rollback plan.

Key Takeaway

A reproducible, evidence-led process protects users and helps you resolve incidents with confidence and traceability.
