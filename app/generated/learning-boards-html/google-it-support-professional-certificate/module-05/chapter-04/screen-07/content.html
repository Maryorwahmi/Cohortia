Object storage basics

Cloud Storage holds objects in buckets with configurable storage classes and access controls. Use the Console or gsutil to manage objects and permissions.

Upload example
gsutil cp local-file.txt gs://my-unique-bucket-name/remote-file.txt

This command copies a local file into a bucket, which you can then inspect for storage class, ACLs, and metadata.

When to use

Backups, media, archives, and static website assets.

Common mistake

Using Standard class for rarely accessed archives increases cost unnecessarily.

Concrete scenario

A team needs to store months of logs. Recommend Coldline or Archive if access is rare, and show how to check and change lifecycle rules in the Console to move objects automatically.

Key Takeaway

Choose a storage class to match how often objects will be accessed. Use gsutil for scripted verification and the Console for quick checks.
