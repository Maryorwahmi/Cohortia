Simulated walkthrough

Verbally practice finding Compute Engine and Cloud Storage in the Console, opening an instance page, and reading monitoring charts for initial diagnosis.

Steps to practice
  1. Open Console menu → Compute → Compute Engine.
  2. Select an instance and view the Monitoring tab for CPU, disk, and network.
  3. Open Console menu → Storage → Cloud Storage to check buckets and object metadata.
  4. Document which metric was unusual and the recommended next step.
Concrete example

For a slow website, check instance CPU and disk I/O first. If disk latency is high, investigate the persistent disk type before resizing the VM.

Common mistake

Rushing to scale compute without evidence often increases cost without solving the root cause.

Key Takeaway

A short, repeatable Console checklist saves time and yields reliable evidence for support decisions.
