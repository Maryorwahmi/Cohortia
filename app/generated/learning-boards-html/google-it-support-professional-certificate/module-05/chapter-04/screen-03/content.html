Practical tasks to verify competency

Each card lists a quick verification step you can perform in a console or terminal to show readiness for support work.

Console navigation check

Find Compute Engine and Cloud Storage in the main menu, open instance or bucket pages, and read monitoring charts.

VERIFIED COMPETENCY MILESTONE
Create a VM via CLI

Run a gcloud compute instances create command and confirm the VM appears in the Console with correct zone and machine type.

VERIFIED COMPETENCY MILESTONE
Upload an object to Cloud Storage

Use gsutil cp to place a file in a bucket and confirm the object is present and has expected storage class.

VERIFIED COMPETENCY MILESTONE
Networking readout

Locate VPC settings, subnet ranges, and firewall rules that affect an instance's connectivity as part of diagnostics.
