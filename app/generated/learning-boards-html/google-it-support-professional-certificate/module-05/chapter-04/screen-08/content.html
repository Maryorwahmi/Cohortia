Persistent Disk as a VM's virtual drive

Used for boot disks and application storage, persistent disks are durable and replicated. Performance varies by disk type and size.

Support actions
  • Inspect attached disks in instance details
  • Check disk I/O and latency metrics
  • Consider resizing or changing disk type for performance
Misconception

Assuming disk performance is identical across types can hide the real source of latency.

Concrete example

A database on a VM shows slow queries. Monitoring shows high disk latency. Attach or migrate to a higher-performance persistent disk and verify reduced I/O wait times.

Key Takeaway

When disk latency appears in monitoring, inspect persistent disk type and size before changing application settings. Disk characteristics often explain performance problems.
