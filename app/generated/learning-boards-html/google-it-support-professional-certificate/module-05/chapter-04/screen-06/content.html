Managed platform vs serverless

App Engine runs web apps with automatic scaling and less operational overhead. Cloud Functions runs short-lived functions in response to events.

App Engine
  • Deploy web applications without server management
  • Automatic scaling based on traffic
  • Good for full web stacks
Cloud Functions
  • Event-driven execution
  • Short-lived, single-purpose functions
  • Ideal for file processing and lightweight APIs
Common misconception

Serverless is not always cheaper; cost depends on invocation frequency and execution duration. Evaluate expected usage patterns before deciding.

Concrete scenario

You need to run image resizing when users upload photos. A Cloud Function triggered by storage events is simpler and scales automatically for bursts, while App Engine would be heavier but suitable if resizing is part of a larger web application workflow.

Key Takeaway

Choose App Engine for full web apps and Cloud Functions for small, event-driven tasks. Your troubleshooting approach follows the execution model.
