Task: Data Center Design Proposal

Use the template to pick three critical elements and recommend redundancy and one physical security control.

Element 1: Power Management
Recommend dual UPS systems and a generator sized for expected load with fuel capacity for extended outages.
Element 2: Cooling System
Recommend N+1 CRAC units with hot-aisle containment to keep inlet temperatures stable even when one unit fails.
Element 3: Network Connectivity
Recommend dual internet providers and redundant core switches to avoid a single point of network failure.
Security Measure
Propose biometric access control at server-room entry to minimize unauthorized access and combine this with CCTV and access logs for audits.
Key Takeaway

Design proposals succeed when each recommended element includes a specific redundancy and a clear reason tied to availability or safety goals.
