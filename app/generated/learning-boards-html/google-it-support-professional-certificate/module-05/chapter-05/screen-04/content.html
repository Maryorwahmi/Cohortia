Module 6 › Chapter 5.5 › Cloud Monitoring
Definition and purpose

Cloud Monitoring ingests time-series metrics from resources and applications, displays them on dashboards, and evaluates alert conditions to notify teams.

What to monitor
CPU, memory, disk I/O, network throughput, request latency, and custom application metrics.
Alert policies
Define conditions and notification channels to receive emails, SMS, or PagerDuty calls when thresholds are exceeded.
Example scenario
A web server VM shows a growth in CPU utilization over 20 minutes. A 5-minute alert fires at 90 percent. You inspect the metric time series to see whether the spike matches traffic patterns or a runaway process, then choose to scale or restart.
Key takeaway
Treat alerts as signals; pair them with dashboards and runbooks so the first responder knows the next steps.
Common mistake
Setting thresholds too tight or too loose. Tune thresholds using historical data to avoid alert fatigue while preserving detection.
