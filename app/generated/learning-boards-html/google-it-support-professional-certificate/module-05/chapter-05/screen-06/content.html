Module 6 › Chapter 5.5 › Troubleshooting Checklist
Seven steps
1. Define the problem
2. Check recent changes
3. Monitor resource health
4. Review logs
5. Verify network
6. Check IAM
7. Consult docs/support
Each step narrows candidates and collects artifacts. Recording findings makes escalation faster and prevents repeated work.
Scenario example
A VM-hosted app is returning 500 errors. Follow the checklist: define impacted users, check for recent deployments, inspect CPU and memory charts, search logs for exceptions, confirm VPC firewall rules allow traffic, verify the VM's service account has database access, and then escalate with log snippets if needed.
Key Takeaway

A methodical checklist reduces time to resolution and creates clear evidence for audits and follow-up.
