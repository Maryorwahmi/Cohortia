Connectivity checklist
  • Confirm the VM's external or internal IP is present.
  • Check VPC Firewall Rules for ingress on the intended port.
  • Validate network tags and target service endpoints.
  • Inspect VPC flow logs for denied packets.
Remember that missing an external IP is a common reason a VM is unreachable from the internet. Use a NAT or load balancer if you need outbound access without exposing an instance.
Example
A VM cannot reach a database: check the database's private IP, VPC subnets, firewall rules allowing the database port, and whether the VM has a route to that subnet.
Common mistake

Assuming the default network allows all traffic. Defaults are restrictive; verify explicit rules allow the required flows.
