Module 6 › Chapter 5.5 › Troubleshooting Scenario
Incident steps
  1. Define problem: inaccessible app, timestamp and region noted.
  2. Check Audit Logs: firewall rule changed minutes earlier.
  3. Inspect metrics: VM running and not resource-starved.
  4. Review logs: connection failures without app errors.
  5. Verify networking: no external IP and firewall blocks port 80.
  6. Check IAM: service account unchanged.
Resolution: restore or correct firewall rule and temporarily add an ephemeral external IP while planning a stable architecture like a load balancer with a reserved IP.
Analyst notes
Document the Audit Log entry, dashboard snapshot, and log excerpts used. This creates the evidence trail for post-incident review.
Key Takeaway

Follow the checklist and keep an evidence log to speed recovery and prevent repeat issues.
