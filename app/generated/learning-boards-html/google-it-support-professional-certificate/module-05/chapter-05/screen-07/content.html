Module 6 › Chapter 5.5 › Shared Responsibility
Provider: Security of the cloud
  • Physical datacenter security and hardware.
  • Hypervisor and managed service availability.
  • Foundational platform updates and isolation.
Customer: Security in the cloud
  • Data protection and encryption choices.
  • IAM role assignments and service account keys.
  • Network configuration and firewall rules.
Example
A provider fixes a hardware outage; you must secure your bucket permissions and rotate credentials if keys are compromised.
Common mistake
Assuming provider manages your IAM. Always audit roles and enforce least privilege.
Key Takeaway
Clearly separate responsibilities in documentation and enforce controls you manage, especially IAM and network rules.
