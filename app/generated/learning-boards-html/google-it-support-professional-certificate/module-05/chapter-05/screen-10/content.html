Module 6 › Chapter 5.5 › Assign Ephemeral IP
When to use an ephemeral IP
Use an ephemeral external IP to quickly restore internet connectivity to a running VM when you need temporary access for debugging or to verify a service.
Notes
  • Ephemeral IPs can change after instance stop/start; choose static for stability.
  • After assigning, verify firewall rules permit ingress on the service ports.

Key Takeaway

Ephemeral IPs are effective temporary fixes; always follow with firewall and IAM checks and document the temporary change.
