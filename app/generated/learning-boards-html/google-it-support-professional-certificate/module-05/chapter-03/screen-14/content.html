Module 5 › Chapter 5.3 › Key Concepts

Quick Reference

Compact labels to use in conversation or notes.

Cloud
On-demand internet delivery of compute, storage, and services with measured billing.
Service Models
IaaS: infra, PaaS: platform, SaaS: software — different responsibility splits.
Deployment
Public for scale, private for control, hybrid for a balance.
Action

In meetings, state the model and the single trade-off you prioritized: control, cost, or compliance.
