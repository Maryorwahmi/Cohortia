Module 5 › Chapter 5.3 › NIST Essential Characteristics — Part 1
Definition

On-demand self-service

Users provision resources automatically without human interaction from the provider.

Concrete example
A developer uses a console to start a virtual machine in minutes.
Why it matters
Removes manual provisioning delays and supports agile delivery and autoscaling.
Misconception
Automation doesn’t remove governance; permissions and quotas still control access.
Definition

Broad network access

Services are accessible over standard networks and protocols so many clients can reach them.

Concrete example
A web application and mobile app both call the same cloud API and authenticate to use services.
Why it matters
Standardized access simplifies integration and enables distributed teams to use the same services.
Key Takeaway

Fast provisioning and standard network access are foundational for cloud agility, but governance must remain in place.
