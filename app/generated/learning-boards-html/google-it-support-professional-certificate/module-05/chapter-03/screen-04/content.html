Module 5 › Chapter 5.3 › What is Cloud Computing?
Core Concept

Cloud computing defined

On-demand delivery of IT resources and applications over the internet with pay-as-you-go pricing.

Business impact
Converts capital purchases into operational spending and enables rapid scaling.
Concrete example
Start a virtual server during a traffic surge instead of maintaining idle hardware.
Common misconception
Cloud is more than 'someone else’s server'; it includes managed services and billing models that change operations.
Analogy: Pizza as a Service
Think of infrastructure like renting an empty apartment, a platform like a furnished apartment, and software like a hotel room — each gives a different level of responsibility to you and the provider.
When to use cloud
Variable workloads, fast provisioning, and teams that prefer operational expenses over hardware ownership.

Key Takeaway

Cloud changes procurement and operations: it’s a delivery model, not just a hosting location.
