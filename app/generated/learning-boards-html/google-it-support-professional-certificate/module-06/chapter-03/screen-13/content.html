Module 6 › Chapter 6.3 › Key Concepts
Authentication
Verifying a user's identity before granting access.
Encryption
Encoding data so only holders of keys can read it; applies at rest and in transit.
Patch Management
Identify, test, deploy, and verify updates to remove vulnerabilities.
Endpoint Security
Antivirus, EDR, host firewalls, device and app controls for devices.
MFA
Multiple independent factors to verify identity and reduce risk.
Data Loss Prevention
Tools and rules to detect and prevent sensitive data leaving the organization.
Summary

Use layered controls: enforce strong authentication, encrypt data, keep systems patched, protect endpoints, and tune DLP to balance security with usability.
