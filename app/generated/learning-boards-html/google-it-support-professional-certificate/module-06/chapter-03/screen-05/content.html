Module 6 › Chapter 6.3 › Strong Passwords & MFA
Step-by-step flow
1
Create a strong password
Long, unique, stored in a password manager when possible.
2
Enroll a second factor
Use an authenticator app or hardware key for stronger assurance.
3
Add recovery options
Backup codes and secondary device registrations reduce lockout risk.
Common mistake

Relying on SMS as the only second factor is convenient but exposes accounts to SIM-related attacks.

Implementation examples
TOTP (Authenticator apps)
Codes change every 30–60 seconds and work offline. Common, easy to enroll.
Push notifications
Approve or deny a login attempt from a registered device. Simple for users, depends on device security.
Hardware keys
Strong physical factor; resistant to phishing, but requires issuing and support.
Pro-tip: Enforce MFA for admin and remote access accounts first to maximize protection quickly.
