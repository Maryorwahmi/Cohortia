Module 6 › Chapter 6.3 › Encryption: Rest vs Transit
Side-by-side
Encryption at Rest
Protects data stored on devices or in cloud storage. Examples: BitLocker, FileVault, VeraCrypt.
Encryption in Transit
Protects data while it moves across networks. Examples: TLS/SSL for HTTPS, VPN tunnels.
Key management
Keys must be stored and rotated securely. If an attacker obtains keys, they can decrypt data regardless of encryption type.
Concrete scenarios
Lost laptop
If disk is encrypted, contents remain unreadable without the key, protecting confidentiality.
Public Wi-Fi
Without TLS, an attacker on the same network can intercept web traffic and read sensitive data.
Key Takeaway

Apply both encryption types appropriately and ensure keys are protected and rotated as part of maintenance.
