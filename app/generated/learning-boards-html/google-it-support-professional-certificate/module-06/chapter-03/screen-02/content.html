Learning Objectives

Learn, Understand, Apply, Master

Bloom: Learn → Understand → Apply → Master
01
Enable MFA
Implement multi-factor methods and verify logins. You will practice an account setup flow and see how MFA reduces risk of credential theft.
VERIFIED COMPETENCY MILESTONE
02
Explain encryption types
Differentiate encryption at rest and in transit and why key management is essential. You will use examples like a locked safe and an encrypted tunnel.
VERIFIED COMPETENCY MILESTONE
03
Manage patches
Describe patch cycles, testing, and deployment. Understand why delayed updates are risky and how to back up before major changes.
VERIFIED COMPETENCY MILESTONE
04
Endpoint & DLP basics
Identify antivirus, EDR, host firewalls, device control, and DLP roles. Learn how these tools affect user workflows and incident response.
VERIFIED COMPETENCY MILESTONE
Visual mnemonics
Venn
Authentication ∩ Authorization
Authentication verifies identity; authorization grants permission. Both are needed to control access safely.
Timeline
Patch cycle
Identify → Test → Deploy → Verify. This repeats as vendors release fixes.
Icon
Locked safe & tunnel
Locked safe illustrates at rest; an encrypted tunnel illustrates in transit protection.
