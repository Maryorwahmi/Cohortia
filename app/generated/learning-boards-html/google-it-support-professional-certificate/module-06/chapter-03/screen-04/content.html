Module 6 › Chapter 6.3 › Authentication vs Authorization
Definition

Authentication: verifying identity using credentials or additional factors. Authorization: enforcing permissions and access controls after authentication.

Analogy
Door key and room assignment
Authentication is showing your badge to enter the building. Authorization is whether your badge lets you into a particular office.
Common mistake
Treating login as full protection
A valid login must still be checked against resource permissions; overly broad roles are a frequent problem.
Key Takeaway

Always pair strong authentication with fine-grained authorization policies to limit access appropriately.

Example: File Server
User logs in with username and password plus second factor. System checks group membership and applies read-only or admin rights. Audit logs record both authentication and authorization decisions.
Troubleshooting tips
  • Check authentication logs for failed logins or expired credentials.
  • Review group membership and access control lists if a user is denied.
  • Verify SSO configuration doesn't inadvertently bypass per-app authorization rules.
