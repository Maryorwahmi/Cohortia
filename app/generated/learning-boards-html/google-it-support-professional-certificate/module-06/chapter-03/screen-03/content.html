Module 6 › Chapter 6.3 › Learning Objectives — Practical Outcomes

Demonstrable Skills

  • Enable MFA: Walk a user through 2-step verification and test a code.
  • Explain encryption: Compare disk encryption and TLS for protecting different risks.
  • Patch safely: Identify updates, test, schedule, deploy, and back up when needed.
  • Support endpoints: Configure antivirus, host firewall, device controls, and explain DLP impact.

Assessment hints

When answering questions, link controls to the security property they protect. For example, encryption and MFA primarily protect confidentiality, while patch management preserves integrity and availability by removing exploited vulnerabilities.
Key Takeaway

Be ready to explain both how a control works and the practical steps to enable or troubleshoot it.
