Module 6 › Chapter 6.2 › Virtual Private Networks (VPNs)
Definition
What a VPN does
Encrypts traffic, authenticates endpoints, and encapsulates packets into a secure tunnel so remote users can access internal resources safely.
Encryption
Prevents eavesdroppers from reading intercepted traffic.
Authentication
Verifies clients and servers before granting access.
Tunneling
Encapsulates packets to carry them securely across untrusted networks.
Concrete example
A user connects from public Wi‑Fi to the corporate VPN; traffic to the file server is encrypted and authenticated, protecting sensitive files from local attackers.
Protocols to know
  • IPsec: widely used for site-to-site and remote access; robust but can be complex to configure.
  • OpenVPN: flexible and widely supported; runs in user space over TLS.
  • WireGuard: newer and designed to be simple, fast, and secure.
Key Takeaway

Use VPNs for secure remote access, but pair them with endpoint security and monitoring to reduce residual risk.
