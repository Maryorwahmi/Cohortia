Module 6 › Chapter 6.2 › Firewalls — Purpose and Types
Core Concept
What a firewall does
A firewall inspects and filters traffic to enforce security policies. Choose the right type based on network needs.
Packet-Filtering Firewalls
Inspects headers only; fast but stateless. Example: block incoming port 23 to prevent Telnet.
Stateful Inspection
Tracks connection state and allows return traffic for established sessions.
Application-Layer Gateways
Inspects application data and enforces protocol-specific rules; acts as a proxy.
Key Takeaway

Match firewall capabilities—speed, state tracking, deep inspection—to the environment and threat model.

Common Mistake

Relying on default firewall rules or opening many ports unnecessarily increases risk.

Concrete example
A web proxy can block specific HTTP methods or filter malicious payloads, while a stateful firewall correctly allows browser responses after an outbound request.
