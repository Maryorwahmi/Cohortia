Applied Objectives
Step-by-step skills you'll practice in labs and ticket scenarios
Firewall Baseline
Set default deny incoming and allow outgoing. Open only required ports and verify with status checks.
VPN Connection
Install and configure a VPN client, authenticate, and confirm resource access over the encrypted tunnel.
Wireless Hardening
Enable WPA2/WPA3, disable WPS, change admin password, and verify SSID settings.
Segmentation Plan
Map devices to VLANs or DMZs to limit access and apply tailored security policies.
Verified Competency

Upon completion, you will explain each control, perform a basic UFW configuration, and recommend wireless and segmentation changes to reduce risk.

Mnemonic: Gate, Tunnel, Lock, Partition — remember the four layers of defense.
