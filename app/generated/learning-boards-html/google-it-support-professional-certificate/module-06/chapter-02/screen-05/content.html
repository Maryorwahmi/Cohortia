Module 6 › Chapter 6.2 › Packet Filtering vs Stateful vs Proxy
Comparison
Performance, visibility, and control
Packet Filtering — Fast
Good for high throughput. Limitation: no session context.
Stateful — Context-aware
Tracks connections and reduces improper inbound openings.
Proxy — Deep inspection
Inspects application payloads for protocol-specific policy enforcement.
Concrete scenario
A high-traffic web gateway uses packet filtering at the edge, stateful inspection for session validation, and a proxy to block malicious uploads.
Symptoms and fixes
  • Port-based failures often indicate packet filter rules; verify IP and port rules and direction.
  • Unexpected connection resets suggest stateful timeouts or tracking table overflow; check state tables and session limits.
  • Blocked application requests point to proxy policies; review proxy logs and allow necessary methods or endpoints.
Key Takeaway

Layer firewall types so you keep performance where needed and add control where content must be inspected.
