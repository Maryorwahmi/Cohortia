Module 6 › Chapter 6.2 › UFW Lab — SSH-Only Firewall
Hands-on Activity
Terminal-first walkthrough
Step 1 — Check UFW status
sudo ufw status verbose
Step 2 — Enable if inactive (add SSH allow first if remote)
sudo ufw allow ssh
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw enable
Step 3 — Verify rules
sudo ufw status verbose
Example test
From another machine, attempt ssh user@your_vm_ip — it should connect. Try telnet your_vm_ip 80 — it should fail.
Pro Tip

When working remotely, add the SSH allow rule before enabling UFW to avoid locking yourself out.

What you will learn
  • How to set safe defaults with UFW.
  • How to add a service-level allow for SSH.
  • How to verify and test firewall behavior from another host.
Key Takeaway

This lab teaches a safe sequence to implement least-privilege firewall rules and verify them without disrupting access.
