Module 6 › Chapter 6.2 › Secure Wireless Networks
Core Concept
Hardening Wi‑Fi
Protect wireless traffic by using modern encryption, strong credentials, and configuration hygiene.
WPA2 / WPA3
Prefer WPA3 for stronger protections; avoid legacy protocols like WEP.
Credentials & WPS
Use a complex passphrase and disable WPS to prevent brute-force attacks.
Admin credentials
Change default admin username and password on the router or WAP.
Practical configuration
Create separate SSIDs for guests and corporate devices. Use unique passphrases and place guest traffic on a distinct VLAN to prevent access to internal resources.
Key Takeaway

Encryption and segmentation are the most effective defenses for Wi‑Fi; configuration hygiene reduces simple but dangerous exposures.

Common Misconception
Hiding the SSID is not a security measure. If the network is in use, it is discoverable and hiding only complicates legitimate connections.
