Module 6 › Chapter 6.2 › IDS vs IPS
Comparison
Detecting vs preventing attacks
IDS — Passive
Generates alerts on suspicious activity; does not block traffic.
IPS — Active
Blocks or mitigates detected threats in real time.
Detection types
Signature-based detection finds known attacks. Anomaly-based detection finds deviations from baseline behavior.
Operational guidance
  • Run in alerting mode first to tune rules and reduce false positives.
  • Use IDS alerts to prioritize investigation and gather logs for security teams.
  • When enabling IPS blocking, monitor for disruptions to legitimate services and adjust rules.
Key Takeaway

IDS gives visibility; IPS takes action. Tune detection before enabling automated prevention to avoid outages from false positives.
