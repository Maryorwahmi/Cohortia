Module 6 › Chapter 6.4 › Containment
Containment actions
  • Isolate compromised systems from the network.
  • Disable or rotate compromised credentials.
  • Block malicious IPs or domains at network edge when necessary.
Example
Workstation with active malware
Disconnect its network interface to stop external communication, leave power on, and capture memory and log files if instructed by IR lead.
Common Mistake
Re-imaging a host immediately removes evidence needed for forensics and root-cause analysis.
Key Takeaway
Contain fast but preserve evidence; containment controls spread while later steps remove the threat.
