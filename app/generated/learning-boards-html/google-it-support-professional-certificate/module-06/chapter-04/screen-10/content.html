Module 6 › Chapter 6.4 › Backups
Backup Types
Full Backup
Copies all data selected. Easy to restore; heavy on storage and time.
Incremental Backup
Copies changes since the last backup of any type. Fast to run; restore needs the full plus every incremental since then.
Differential Backup
Copies changes since the last full backup. Simpler restore: full plus latest differential.
3-2-1 Rule
Three copies, two media types, one off-site.
Example
Live data on servers, nightly full backups on network storage, and weekly cloud snapshots stored off-site meet the 3-2-1 guidance.
Key Takeaway
Design backups to meet recovery objectives and test restores regularly to avoid surprises during an incident.
