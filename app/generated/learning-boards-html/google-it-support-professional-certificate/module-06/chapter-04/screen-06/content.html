Module 6 › Chapter 6.4 › Identification
Verify before you escalate
Gather facts, correlate alerts, and determine scope.
What to collect: timestamps, log snippets, error messages, recent user actions, and device identifiers.
Indicators: unusual outbound traffic, multiple failed logins, unexpected processes, or data disappearance.
Scope check: confirm whether the issue affects one user, one subnet, or many systems.
Example
User report
User reports files disappearing. You check recent logs, find multiple outbound connections at the same time, and confirm these actions with the user timeline.
Common Mistake
Assuming an alert equals an incident and skipping verification leads to wasted effort and missed real threats.
Key Takeaway
Confirm facts, preserve logs, and determine scope before broad actions.
