Module 6 › Chapter 6.4 › IR Lifecycle
Six Phases
A step-by-step process to limit harm and restore operations.
1
Preparation
Policies, tools, training, and runbooks so responders act quickly and correctly.
2
Identification
Detect and confirm incidents using logs, alerts, and user reports.
3
Containment
Stop spread immediately by isolating systems or blocking access.
4
Eradication
Remove the root cause: clean malware and patch vulnerabilities.
5
Recovery
Restore services from clean sources and validate system integrity.
6
Post-Incident
Document findings, update plans, and run drills to strengthen prevention.
Example & Takeaway
Scenario
A user reports pop-ups. You check logs, find suspicious outbound connections, isolate the workstation, remove malware, restore files from backup, and then document lessons.
Key Takeaway

An ordered lifecycle helps teams control incidents; containment is immediate control, eradication is later removal.

Common mistake
Rushing to clean a system before preserving evidence destroys data needed for forensic analysis.
