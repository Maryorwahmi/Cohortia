Linux walkthrough
Identify interface, bring it down to isolate, then bring it back up to recover.
# Identify interfaces
ip a

# Bring interface down (isolate)
sudo ip link set <your_interface_name> down

# Verify network is unreachable
ping google.com

# Bring interface up (recover)
sudo ip link set <your_interface_name> up
Use a VM so you can safely disconnect networking without impacting your physical workstation. Record times and actions you take.
Windows walkthrough
List interfaces, disable the adapter to isolate, then enable it to recover.
# Show interfaces
netsh interface show interface

# Disable adapter (isolate)
netsh interface set interface "<Your Adapter Name>" disable

# Enable adapter (recover)
netsh interface set interface "<Your Adapter Name>" enable
After the exercise, restore your VM snapshot to return to a clean state. Document every step you performed.
