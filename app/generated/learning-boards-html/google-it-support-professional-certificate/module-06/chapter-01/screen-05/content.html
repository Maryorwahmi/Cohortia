Module 6 › Chapter 6.1 › CIA Triad
Confidentiality
Ensure only authorized people can access sensitive information. Examples: encryption, access controls, strong authentication.
Mnemonic: locked cabinet — only those with the key can see the documents.
Integrity
Keep data accurate and untampered. Examples: hashing, digital signatures, version control, strict change management.
Contrast: tampered financial records undermine trust even if data remains private.
Availability
Make systems and data reachable when needed. Examples: backups, redundant servers, disaster recovery plans.
Scenario: a critical server outage can halt business operations even if confidentiality and integrity are intact.
Key Takeaway

Balance the three pillars. Security controls should protect confidentiality and integrity without needlessly reducing availability.
