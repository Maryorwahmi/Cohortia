Module 6 › Chapter 6.1 › What is IT Security?
Definition & scope

Protects information systems from unauthorized access, disclosure, disruption, modification, or destruction by combining people, processes, and technology.

Why it matters
  • Prevents data breaches and protects user privacy.
  • Keeps services available so users can work without interruption.
  • Maintains trust and reputation for the organization.
Concrete example
Compromised workstation recovery
Identify suspicious processes, isolate the device from the network, run scans and forensics, restore from a verified backup, and educate the user on safer download practices.
Common misconceptions
Security is only for specialists
Support staff and users each play a role in prevention and detection.
Security always reduces usability
Good security balances protection and availability so work can continue safely.
One control fixes everything
Effective security uses layered controls across people, processes, and technology.
Key Takeaway

Security is continuous, layered, and shared: detection, prevention, and response combine to reduce risk.
