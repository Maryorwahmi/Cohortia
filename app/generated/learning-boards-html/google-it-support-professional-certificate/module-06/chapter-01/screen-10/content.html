Module 6 › Chapter 6.1 › Malware Overview
Common infection vectors
  • Email attachments and malicious links.
  • Untrusted downloads and bundled software.
  • Removable media like USB drives.
  • Exploited network services and vulnerable software.
Detection signs
Unexpected pop-ups, slow performance, unknown processes, sudden outbound traffic, or disabled security tools.
Concrete example
Ransomware via email
An attachment executes an encryptor when opened. Immediate steps: isolate the machine, preserve evidence, and restore from backups.
Prevention checklist
Limit install privileges, apply patches promptly, use up-to-date endpoint protection, and train users to avoid risky downloads.
Key Takeaway

Combine technical hardening with user awareness to reduce the most common infection vectors.
