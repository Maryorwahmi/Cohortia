Learning Objectives
Learn the practices that make security policies effective and the communication skills to help users follow them.
Learn → Understand → Apply → Master
01
Interpret Security Policies
Read and apply password, acceptable use, data handling, and remote work policies so you can advise users and configure systems accordingly.
Mnemonic: Policy → Rule → Action
VERIFIED COMPETENCY MILESTONE
02
Design Awareness Programs
Create recurring training, reminders, and simulated phishing to build awareness that persists beyond one-off sessions.
Mnemonic: Train → Remind → Test
VERIFIED COMPETENCY MILESTONE
03
Track Threats & Trends
Use threat feeds, vendor alerts, and community resources to identify risks that affect your organization and adjust guidance accordingly.
Mnemonic: Spot → Share → Act
VERIFIED COMPETENCY MILESTONE
04
Physical Security Basics
Understand access controls, surveillance, environmental protections, and asset inventory that protect hardware and data.
Mnemonic: Lock → Monitor → Protect
VERIFIED COMPETENCY MILESTONE
Why this matters
These objectives focus on shifting behavior and making technical controls enforceable. You will be able to point to specific actions and measurements that show progress.
