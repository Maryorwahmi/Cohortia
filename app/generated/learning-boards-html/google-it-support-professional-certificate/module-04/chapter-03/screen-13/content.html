Module 4 › Chapter 4.3 › Sandbox Activity
Windows (GUI & CLI)
GUI: Computer Management → Local Users and Groups. Create TestUser1 and ITSupport group, add user to group. Create C:\\SharedData, edit Security → remove Everyone, add ITSupport with Modify, disable inheritance and convert permissions, then verify effective permissions for TestUser1.
CLI: net user TestUser1 Password123! /add ; net localgroup ITSupport /add ; net localgroup ITSupport TestUser1 /add ; icacls C:\\SharedData
Linux (CLI)
Run: sudo useradd -m testuser1 ; sudo passwd testuser1 ; sudo groupadd itsupport ; sudo usermod -aG itsupport testuser1 ; sudo mkdir /opt/shareddata ; sudo chown root:itsupport /opt/shareddata ; sudo chmod 770 /opt/shareddata ; su - testuser1 ; touch /opt/shareddata/userfile.txt
Check
Verify permissions with ls -l and verify groups with id testuser1. Test write and read operations as the created account.
