Module 4 › Chapter 4.3 › NTFS Permissions & Inheritance
ACL basics
NTFS stores an ordered list of ACEs that grant or deny permissions to users and groups. Explicit permissions override inherited ones when conflicts occur.
CLI check: icacls C:\\SharedData
Inheritance
Inherited permissions apply from parent folders; disable inheritance to set folder-specific rules but review converted entries first.
Effective permissions
Use Advanced Security Settings to view the effective permissions for a user. Effective rights are the result of all explicit and inherited entries and group memberships.
Scenario
Restrict \\Server\Reports to FinanceTeam: remove Everyone, disable inheritance, convert permissions, add FinanceTeam with Modify, then verify effective access for a sample user.
