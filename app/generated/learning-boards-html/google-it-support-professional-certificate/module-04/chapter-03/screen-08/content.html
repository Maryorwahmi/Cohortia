Module 4 › Chapter 4.3 › File Ownership & Permissions
Permission bits
r = read (4), w = write (2), x = execute (1). Add values for numeric chmod: rwx = 7, rw- = 6, r-x = 5.
chmod 755 myscript.sh # owner rwx (7), group r-x (5), others r-x (5)
Directory note
Execute on a directory controls entering and traversing it, not running code.
Ownership and commands
Check owner and group with ls -l. Change ownership with chown new_owner:new_group file. Always set the appropriate owner and group before adjusting permissions.
Example: sudo chown root:itsupport /opt/shareddata ; sudo chmod 770 /opt/shareddata
Common mistake
Using chmod 777 on sensitive directories opens them to all users; avoid except for temporary debugging.
