Module 4 › Chapter 4.3 › Linux: Create & Manage Users
Common commands
sudo useradd -m testuser1 sudo passwd testuser1 sudo groupadd itsupport sudo usermod -aG itsupport testuser1 id testuser1
Explanation: useradd with -m creates a home directory. passwd sets the login password. groupadd creates a group. usermod -aG safely appends group membership. Use id to verify.
Verification & example
After adding testuser1 to itsupport, switch to that user or run id testuser1 to check groups. Also use ls -l on a shared directory to confirm owner and group ownership.
Scenario
Onboard a contractor: create user, set temp password, add to itsupport, and log the account for review.
Common mistake
Using usermod -G without -a replaces supplementary groups and may remove needed membership.
