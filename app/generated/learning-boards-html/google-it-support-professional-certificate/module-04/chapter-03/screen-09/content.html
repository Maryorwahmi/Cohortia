Module 4 › Chapter 4.3 › Symbolic vs Numeric chmod
Numeric examples
chmod 755 myscript.sh # owner rwx, group r-x, others r-x chmod 770 /opt/shareddata # owner rwx, group rwx, others none
Numeric is fast and clear when you want to set all bits explicitly, ideal for automation.
Symbolic examples
chmod u+x script.sh # add execute for owner chmod go-w file.txt # remove write for group and others
Symbolic mode modifies existing bits and is safer for incremental updates when you do not want to replace the full mode.
Common mistake
Using numeric mode without checking current bits can unintentionally remove permissions; verify with ls -l.
