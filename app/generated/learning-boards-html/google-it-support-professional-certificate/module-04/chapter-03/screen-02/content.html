Work through command examples, try the sandbox activity, and verify effective permissions. Use the objectives to self-assess: can you create a user, add them to a group, set secure permissions, and explain inheritance?
Mnemonic: AGP — Accounts, Groups, Permissions
Tip: Practice both GUI and CLI to be fast in real incidents.
