Module 4 › Chapter 4.3 › Windows: GUI and CLI User Management
GUI Workflow
Open Computer Management → Local Users and Groups to create, set passwords, add to groups, or disable accounts. Use Active Directory Users and Computers on a domain for centralized management.
Example steps: Create user → set password policies → add to ITSupport group → disable when finished
CLI example
net user TestUser1 Password123! /add
Group example
net localgroup ITSupport TestUser1 /add
PowerShell alternatives
PowerShell cmdlets like New-LocalUser and Add-LocalGroupMember support scripting and better error handling for automation.
PowerShell examples: New-LocalUser -Name "TestUser1" -Password (ConvertTo-SecureString "Password123!" -AsPlainText -Force)
Common mistake
Creating accounts without secure password policies or failing to disable accounts when access is no longer needed.
Key takeaway
Prefer PowerShell for repeatable tasks, GUI for ad hoc investigation and visual checks.
