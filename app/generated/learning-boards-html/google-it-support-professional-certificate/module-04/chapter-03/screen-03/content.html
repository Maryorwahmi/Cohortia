Module 4 › Chapter 4.3 › Learning Objectives
Verification tasks
Commands and GUI checks you should be fluent with to confirm correct setup and safe access.
Linux verification: id testuser1 ; ls -l /opt/shareddata
Windows verification: icacls C:\\SharedData ; check Effective Permissions in Advanced Security
Audit & clean up
Regularly review accounts and groups, disable or remove inactive users, and limit inherited permissions that broaden access unexpectedly.
Tip: Schedule periodic audits to remove dormant accounts.
Common mistake: Deleting system accounts. Prefer disabling first and verify recovery steps.
