Module 4 › Chapter 4.3 › Local vs Domain Accounts
Local Accounts
Credentials and policies stored on the single machine. Useful for standalone or recovery scenarios.
  • Authentication happens locally on the machine.
  • Passwords and account settings do not propagate.
  • Example: local administrator account on a standalone Windows PC.
Check
Windows GUI: Computer Management → Local Users and Groups
Domain / Network Accounts
Centralized directory authentication across many systems, supports consistent policy and single sign-on.
  • Authentication is verified by a domain controller or LDAP server.
  • Group policies and rights apply consistently across domain-joined machines.
  • Example: Active Directory user who can log in to any joined workstation.
Pro tip
When troubleshooting logins, check network connectivity to the directory server and local cached credentials.
