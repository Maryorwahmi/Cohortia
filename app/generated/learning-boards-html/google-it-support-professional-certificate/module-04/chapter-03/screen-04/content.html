Module 4 › Chapter 4.3 › What is a User Account?
Core definition
An account ties identity, authentication, and authorization together so systems can control who does what.
Analogy
Think of an account as a building ID badge: it names the person, proves identity at a turnstile, and indicates which rooms they may enter.
Concrete example
sudo useradd -m testuser1 ; sudo passwd testuser1 ; sudo usermod -aG itsupport testuser1
Explanation and notes
  • Identity: a username and metadata that identifies an account on the system.
  • Authentication: proof such as a password; without it a login fails even if the account exists.
  • Authorization: group membership and permissions determine what resources the account can access.
Key takeaway
An account must be paired with groups and permissions to be useful and secure.
Common mistake
Assuming account creation equals access; you must also set group membership and resource permissions.
