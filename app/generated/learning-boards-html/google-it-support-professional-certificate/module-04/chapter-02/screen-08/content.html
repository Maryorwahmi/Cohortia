Module 4 › Chapter 4.2 › What Is a Process?
Definition
Process: a running program
The operating system creates and manages processes, which consume CPU, memory, and other resources while running.
Foreground
Interacts with a user directly; typically the active window or a terminal session.
Background
Runs without direct user interaction, often as a service or scheduled task.
PID
A unique numeric identifier assigned by the OS to each running process.
Resources
Processes use CPU, memory, disk, and network; these metrics help diagnose problems.
Example
Browser processes
A browser often uses multiple processes for tabs and extensions; terminating one tab's process can recover responsiveness.
Mistake
Killing core processes
Force-killing essential OS processes may crash or destabilize the system.
Key Takeaway
Verify before terminate
Always verify the process identity and purpose before stopping it to avoid unintended consequences.
