Practice Objectives
Concrete lab actions to verify your competency
Bloom: Apply → Master
01 Create and copy

Make a test folder, add a text file, copy it, and rename the copy to demonstrate basic CLI and GUI file operations.

Verified competency milestone
02 Inspect attributes

View file metadata and basic permission bits to confirm ownership and access levels.

Verified competency milestone
03 Observe foreground/background

Launch an app and note whether it occupies the active window or runs detached as a background task.

Verified competency milestone
04 Monitor and terminate

Use Task Manager or system monitors to find a process by name or PID, then terminate it safely after verification.

Verified competency milestone
