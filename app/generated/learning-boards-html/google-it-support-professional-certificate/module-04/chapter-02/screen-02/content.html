Learning Objectives
Learn, understand, apply, and begin to master file and process management
Bloom: Learn → Understand → Apply → Master
01
Navigate files and folders

Use GUI file managers or the command shell to move through the filesystem, create directories, and list contents for troubleshooting and organization.

Verified competency milestone
02
Interpret attributes and permissions

Read file metadata and basic permission bits so you can control who can read, write, or execute files and avoid accidental exposure.

Verified competency milestone
03
Explain processes and states

Define what a process is and distinguish foreground tasks from background services so you can reason about system behavior.

Verified competency milestone
04
Monitor and control processes safely

Use system monitors and command-line tools to view resource use, find PIDs, and terminate tasks carefully to avoid system instability or data loss.

Verified competency milestone
