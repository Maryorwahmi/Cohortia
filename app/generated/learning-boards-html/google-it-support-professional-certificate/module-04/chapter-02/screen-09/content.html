Module 4 › Chapter 4.2 › Monitoring Processes with System Tools
GUI monitors
Task Manager / Activity Monitor
These tools show running apps, background processes, and resource columns for CPU, memory, disk, and network so you can spot resource hogs quickly.
Identify by name
Locate the process by its displayed name and check the resource columns and memory footprint.
Record PID and metrics
Note the numeric identifier and usage values before you act so troubleshooting is reproducible.
Shell tools
Process lists and realtime views
Use a process-listing command to find processes by name and an interactive viewer to sort by CPU or memory usage in real time for deeper diagnosis.

Practical tip
If unsure whether a process is critical, search the process name online in vendor documentation or check whether it's owned by the system before killing it.
