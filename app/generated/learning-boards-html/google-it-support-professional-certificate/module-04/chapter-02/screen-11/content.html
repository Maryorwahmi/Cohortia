Module 4 › Chapter 4.2 › Lab: File and Process Management Challenge
Step-by-step lab
Follow these steps in your GUI or shell to practice and verify key skills.
1. Create a test directory
Use your file manager or make a new folder in your documents area; this isolates changes from important files.
2. Create and copy files
Create a small text file, copy it, and rename the copy to practice basic operations.
3. Monitor and terminate
Open the system monitor, find a browser process, note its PID, and perform a safe termination to observe behavior.
Safety note
Never run destructive recursive deletes without listing the target first; use the verify-then-act habit.
Outcome
You will be able to perform basic file operations and manage processes safely in both GUI and CLI environments.
Clean up
Delete the test folder after the exercise so your workspace remains tidy.
