Module 4 › Chapter 4.2 › File Commands: Windows vs Unix-like
Windows
Command reference
List and change
Use the directory listing and change-directory commands to inspect and move between folders.
Copy, move, delete
Perform copy and move operations, and take caution with delete commands that can accept force options without prompts.
Tip
When in doubt, list the directory to confirm targets before destructive operations.
Linux / macOS
Command reference
Recursive operations
Commands can act recursively on directories; confirm targets first because many operations are permanent.
Scripting and pipes
The shell makes it easy to chain commands and automate repetitive file tasks across many files.
Example
Use the shell to copy an entire folder tree when you need every nested file preserved, instead of dragging many files in the GUI.
