Managing Files and Processes
Organize data, control running programs, and avoid common mistakes that cause data loss.
Interactive 16:9 Masterclass
In this lesson

You will learn filesystem layout across Windows and Unix-like systems, use GUIs and CLI to manipulate files, and monitor or terminate processes safely.

Why it matters

Good file and process practices prevent data loss, speed troubleshooting, and keep systems stable under load.

Explore Key Topics
Filesystem
Hierarchy and paths
Drive letters vs a single root, and common folders like home and etc.
File ops
Create, copy, move, delete
Use GUI for small tasks and CLI for speed and scripting.
Processes
Monitor and control
Identify PIDs, check CPU/memory, and terminate safely when needed.
Concept Preview
Files are stored in a hierarchy. Processes act on those files. Practice ties both together.
Example Exercise
Create a test folder, add a text file, copy it, rename the copy, then open Task Manager or System Monitor and stop a browser process to observe the effect.
Outcome
You will connect file operations to process behavior and practice safe command-line checks before making destructive changes.
