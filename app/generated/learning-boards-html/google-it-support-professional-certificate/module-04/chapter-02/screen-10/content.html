Module 4 › Chapter 4.2 › Terminating Processes Safely
Action pattern
Observe → Graceful → Force (last resort)
Always document the process identity and its resource usage before taking action. Try polite termination first so the application can save state.
Polite stop
Use the standard end action so the process has a chance to close files and save work.
Force stop
Apply only when the process is unresponsive and after recording evidence; expect potential data loss.
Scenario
A browser tab consumes excessive CPU and makes the system sluggish. Record the PID and memory usage, attempt a polite end for that tab's process, and if it remains hung, proceed with a forced stop as last resort.
Warning
Force-killing system or service processes can cause instability; verify ownership and role before action.
Key Takeaway

Prefer graceful termination; reserve force options for when you've documented the process and other recovery is unavailable.
