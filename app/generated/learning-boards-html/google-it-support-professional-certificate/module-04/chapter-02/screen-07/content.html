Module 4 › Chapter 4.2 › File Attributes and Permissions
Attribute cards
Read-only
Prevents modification; useful for protecting important files from accidental edits.
Hidden / System
Flags that change visibility in file browsers and backups.
Concrete example
Fixing execution errors
If a script fails to run, check its execute permission on Unix-like systems; lacking execute is often the cause.
Permission model
Owner, group, others
Three sets of rules determine whether a user can read, write, or execute a file. This model helps restrict access and reduce accidental modification in multi-user systems.
Misconception
Permissions are only about security. They also prevent accidental file changes that can break applications.
Key Takeaway

Inspect attributes and permission sets early in troubleshooting to avoid surprising access denials or unintended exposure.
