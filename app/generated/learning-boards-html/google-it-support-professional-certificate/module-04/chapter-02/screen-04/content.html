Module 4 › Chapter 4.2 › File System Hierarchy
Definition
File System Hierarchy
A structured layout of directories and files on a storage device that the operating system uses to organize data and system resources.
Windows style
Drive letters with separate roots per storage device. Common paths include user profiles on the system drive.
Unix-like style
Single root with mounted devices and top-level directories such as home, etc, bin, and var.
Why it matters
Correctly locating config files, logs, and user data depends on understanding the hierarchy and mount points.
Example
Find logs
On Unix-like systems, system logs are typically under a variable-data directory for logs rather than in user folders.
Takeaway
Map before modifying
Identify the correct filesystem area to avoid accidental changes to the wrong files.
Annotated Directory Cards
/home
Contains user data and personal files on Unix-like systems.
/etc
System configuration files that control behavior for services and the OS.
/var
Variable data such as logs and spool files.
C:\\Users
Typical location for individual user profiles and documents on Windows system drives.
Key Takeaway

Recognize common top-level directories so you can find logs, configuration files, and user data quickly during support tasks.
