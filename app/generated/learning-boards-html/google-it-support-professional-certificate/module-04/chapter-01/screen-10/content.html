Kernel and User Space
Privileges, system calls, and the safety boundary
Architecture
What each area does
  • Kernel: manages hardware, scheduling, memory, and enforces security policies.
  • User space: runs applications that request services via system calls.
  • System calls are the controlled entry points for user code to request kernel services.
Concrete example
When a browser reads a file, it asks the kernel with a system call. The kernel verifies permissions and returns data without exposing raw device access to the browser.
Misconception: user programs can change kernel state directly — they cannot without privileged interfaces.
Pro tip: check kernel logs for device and driver issues; check user logs for application faults.
Annotated callouts
Kernel mode: privileged access, direct hardware control. User mode: restricted; must use system calls.
Key Takeaway

The kernel is the protected mediator between hardware and apps. Proper debugging requires looking in the right space for errors.
