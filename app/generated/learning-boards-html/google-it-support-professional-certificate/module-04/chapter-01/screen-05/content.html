Resource and Process Management
How the OS schedules CPU and controls running programs
Process Management
Process life cycle
  1. Create: application launch creates a process and assigns an ID.
  2. Schedule: the kernel assigns CPU slices and context switches between processes.
  3. Monitor: the OS tracks resource use for each process.
  4. Terminate: the OS frees resources when a process ends or is killed.
Example scenario
Server slow → run top or ps aux → find PID using most CPU → kill <PID> to free resources
Common mistake: immediately rebooting without checking for a runaway process.
Pro tip: use niceness or priority tools to limit impact of noncritical processes.
Resource allocation snapshot
PID USER %CPU %MEM COMMAND 1234 www 92.3 4.1 python app.py 2345 alice 4.2 1.0 chrome 3456 root 0.1 0.2 sshd Use tools like top, ps, and task manager to inspect this data and take corrective action.
Key Takeaway

When a single process monopolizes resources, diagnose with process tools and act to terminate or reprioritize before rebooting.
