Learning Objectives
Learn the OS role, types, kernel design, and interfaces you’ll use as an IT support professional.
Bloom: Learn → Understand → Apply → Master
01
Explain OS role
Describe how the OS manages hardware and software, enabling applications to run reliably.
Mnemonic: Orchestra conductor — instruments are hardware, score is applications.
VERIFIED COMPETENCY MILESTONE
02
Differentiate OS types
Recognize desktop, server, and mobile OS and why their priorities differ.
Mnemonic: Workbench (desktop), Headless engine (server), Pocket (mobile).
VERIFIED COMPETENCY MILESTONE
03
Describe kernel vs user
Explain why the kernel runs in privileged mode and how user space is isolated for safety.
Mnemonic: Gatekeeper (kernel) vs guests (user apps).
VERIFIED COMPETENCY MILESTONE
04
Compare GUIs and CLIs
Identify strengths of visual interfaces and the precision and automation power of text-based shells.
Mnemonic: Click for ease, type for power.
