Module 5 › Chapter 4.4 › Event Viewer
Definition

Windows Event Viewer

A log browser that records Application, Security, Setup, and System events that help you find root causes.

Filter by time and level
Set a custom filter for Errors and Warnings within the incident timeframe to reduce noise.
Look for source and event ID
Event IDs and source names let you search vendor documentation and community fixes.
Correlate, don't assume
Not every logged warning is the cause; match timestamps and symptoms to find relevant entries.
Teaching Visual — Example Walkthrough
Scenario
A PC blue-screens at 09:12. Filter System log for Errors between 09:00 and 09:20. Look for BugCheck or Kernel-Power entries and copy the event ID and source name to your notes.
Example entry fields to record
  • Timestamp
  • Event ID and source
  • Brief message or referenced driver filename
Key Takeaway

Use Event Viewer filters and event IDs to convert logged noise into actionable clues; always record IDs and timestamps for your documentation.
