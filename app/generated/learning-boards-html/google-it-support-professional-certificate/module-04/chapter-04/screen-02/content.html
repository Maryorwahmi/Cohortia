Learning Objectives

Build practical habits: troubleshoot, read logs, maintain disks, and protect systems.

Learn → Understand → Apply → Master
01
Apply a troubleshooting methodology

Use a six-step workflow to collect facts, form and test theories, and implement reliable fixes. This reduces guesswork and avoids unnecessary changes.

Mnemonic: I-T-T-T-V-D (Identify, Theory, Test, Take action, Verify, Document)
VERIFIED COMPETENCY MILESTONE
02
Use system logs to identify root causes

Filter by error and timestamp in Event Viewer or journalctl to find the events that explain failures. Event IDs help you search for known causes.

Visual: timeline with error markers
VERIFIED COMPETENCY MILESTONE
03
Perform essential disk management

Run safe checks like chkdsk or fsck, and manage space with Disk Cleanup or du to keep systems responsive. Always back up before repairs.

Visual: simple disk icon + shield
VERIFIED COMPETENCY MILESTONE
04
Implement routine maintenance and documentation

Apply updates, schedule backups, create restore points, and record troubleshooting steps so problems are easier to resolve next time.

Visual: checklist icon
