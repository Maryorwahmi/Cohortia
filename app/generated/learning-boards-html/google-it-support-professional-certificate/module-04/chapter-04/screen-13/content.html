Core Concept

Antivirus, firewall, and least privilege

Security settings reduce the number of incidents that require troubleshooting and limit their impact.

Antivirus & anti-malware
Keep definitions current and schedule scans to detect and remove threats early.
Firewall configuration
Use built-in firewalls to block unauthorized access; review rules periodically for unnecessary openings.
Principle of least privilege
Grant only necessary permissions to users and services to limit accidental or malicious changes.
Teaching Visual — Scenario Card
Unexpected installs example
If programs appear without consent, check antivirus scan history, firewall logs, and recent admin actions. Restore from backup if data was affected and document the steps.
Misconception
Temporarily disabling security for convenience often creates larger risks. If testing requires a change, make it temporary and document the reasons and re-enable immediately.
Key Takeaway

Security configurations and least-privilege policies reduce incidents and simplify troubleshooting by narrowing the possible causes.
