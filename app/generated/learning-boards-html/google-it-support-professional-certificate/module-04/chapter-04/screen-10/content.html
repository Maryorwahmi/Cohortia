Module 5 › Chapter 4.4 › Disk Error Checking
Definition

chkdsk and fsck

Commands that check and optionally repair file system inconsistencies; use with backups and care.

Windows example
chkdsk /f (may require reboot)
Linux example
fsck /dev/sdX (run on unmounted partition or from live environment)
Safety note
Always back up critical data first and prefer read-only inspections until you're prepared for repairs in a maintenance window.
Teaching Visual — Scenario & Checks
When to run a check
If logs show file system errors, files fail to open, or the system reports corrupted sectors — schedule a backup and run a repair in maintenance mode.
Misconception
Running these utilities without a backup or on an unknown device can increase risk. Always confirm the target device and have backups ready.
Key Takeaway

File system repairs are powerful but potentially disruptive. Back up first, run checks in a safe context, and record what you ran.
