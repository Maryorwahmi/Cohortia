Comparison

Symptom → Check

Map common symptoms to focused diagnostic actions so you test the most likely causes first.

Slow performance
Check Task Manager/System Monitor for CPU, memory, disk, and network usage. Inspect large files and background processes.
System crashes
Search Event Viewer or journalctl for crash-related entries and stop codes; note event IDs and referenced drivers.
Boot failures
Attempt Safe Mode or recovery boot to bypass problematic drivers; run disk checks if file system errors are suspected.
Application freezes
Identify the process in Task Manager, disable extensions, clear app caches, and test again.
Teaching Visual — Scenario Cards
Browser freeze example
Other apps are fine. Open Task Manager, find the browser process using CPU or memory heavily, disable extensions, and clear cache. Document results.
Misconception check
Don't assume high CPU means the CPU is defective. It may be a runaway process or insufficient RAM causing paging and disk thrashing.
Key Takeaway

Triaging by symptom narrows the right checks and leads to faster, safer fixes. Always record the checks you ran and their outcomes.
