Tools & Safety

Link commands and GUI tools to safe practice: inspect, don't repair, until you've backed up critical data.

Windows Event Viewer

Open Event Viewer to filter System and Application logs for errors and use event IDs to target searches for fixes.

Linux logs & journalctl

Use /var/log and journalctl -p err -p warning to focus on recent problems. tail -f shows live updates while you reproduce an issue.

Visual: terminal with live stream
VERIFIED COMPETENCY MILESTONE
Disk inspection commands

Use df -h and du -sh to locate large files and partitions. Use Disk Cleanup or safe checks before repairs.

Visual: magnifier over disk

Security & privilege practices

Keep antivirus updated, configure firewalls, and apply the principle of least privilege to prevent many incidents before they start.
