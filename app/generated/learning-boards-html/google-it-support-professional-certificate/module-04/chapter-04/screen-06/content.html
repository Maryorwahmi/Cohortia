Module 5 › Chapter 4.4 › Establish & Test Theories
Process Flow

Form testable theories and run safe checks

A theory is a focused claim you can confirm or refute with a single test.

Choose plausible causes
Consider recent changes first: drivers, updates, or new software.
Design minimal tests
Examples: Safe Mode to isolate drivers, tail -f to watch logs while reproducing, or disabling a suspect extension.
Record test results
Note exact outcomes and timestamps to link results to log events and later documentation.
Teaching Visual — Test Cards
Driver theory test
Boot into Safe Mode. If crashes stop, suspect a driver or startup service. Check Device Manager and roll back the latest driver.
Disk space theory test
Run df -h and du -sh to find large directories. Free space by moving or cleaning temporary files and re-test performance.
Common mistake
Applying a blanket update or reinstall without confirming the cause; this can hide the true offender and cause downtime.
Key Takeaway

Design small, reversible tests that confirm or eliminate each theory and record results to guide your fix.
