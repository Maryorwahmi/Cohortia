Central Processing Unit
Executes instructions, performs calculations, and manages data flow for programs.
Architecture overview
  • Cores: Independent processing units for parallel tasks.
  • Clock speed: Instruction cycles per second measured in gigahertz.
  • Cache: Very fast onboard memory for frequent data to reduce latency.
Example

A video export that uses multiple cores will complete faster on a quad-core CPU than on a single-core CPU, even if the single core has a slightly higher clock speed, because tasks run in parallel.

Key Takeaway
Look beyond clock speed: core count, cache, and thermal behavior determine real workload performance.
Diagram
CPU internals
Cores, cache levels, and connection to memory and chipset determine throughput.
Troubleshooting
  • Check for sustained 100% CPU usage to identify runaway processes.
  • Verify cooling and fan operation to avoid thermal throttling.
  • Compare core utilization to see whether tasks are single-threaded or multi-threaded.
