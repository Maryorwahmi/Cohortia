Learning Objectives
Each objective focuses on a practical skill you can use when supporting users and systems.
01
Identify Components
Name and describe internal and external hardware
Learn to recognize CPU, RAM, storage, PSU, motherboard and common peripherals so you can document and report problems accurately.
VERIFIED COMPETENCY MILESTONE
02
Explain Functions
Understand CPU, RAM and storage roles
Explain why RAM is volatile and how SSDs differ from HDDs in performance and durability.
VERIFIED COMPETENCY MILESTONE
03
Differentiate Devices
Input, output, and storage distinctions
Know which devices send data, which present data, and which hold it long term — key when diagnosing user complaints.
VERIFIED COMPETENCY MILESTONE
04
Recognize Ports
USB, HDMI, Ethernet and audio connectors
Identify common ports and match cables to devices to avoid simple but common errors during support.
VERIFIED COMPETENCY MILESTONE
