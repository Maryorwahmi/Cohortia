Module 3 › Chapter 2.3 › Objectives — Practical
Troubleshooting Goals
  • Locate and update drivers using manufacturer tools or Device Manager.
  • Install apps safely from trusted sources and verify launch.
  • Remove apps cleanly to avoid leftover configuration files.
  • Assess update urgency and firmware risk before applying.
Practice Checklist
Windows
Run an .exe installer and verify in Apps & features.
macOS
Drag the app from the disk image to Applications and test launch.
Linux
Use a package manager to install and optionally purge to remove config files.
