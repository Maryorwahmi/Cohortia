Module 3 › Chapter 2.3 › Uninstallation
Platform removal patterns
  • Windows: Use Settings > Apps or Control Panel > Programs and Features. Follow prompts to remove related services.
  • macOS: Dragging to Trash removes the app bundle; check Library and Support folders for leftovers or use the vendor uninstaller.
  • Linux: Use package manager remove or purge to determine whether configuration files are retained.
Example
Removing GIMP by purge on Linux can delete config files so a clean reinstall starts fresh; remove may preserve user settings.
Checklist before uninstall
  • Backup user configuration if it should be preserved.
  • Use the OS uninstaller or vendor tool for complex software.
  • Search for leftover files in common config and profile locations after removal.
Pro tip
Document whether a purge was used so you know whether user settings will be restored on reinstall.
