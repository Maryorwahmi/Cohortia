Module 3 › Chapter 2.3 › What is Software?
Clear definition
Software is a set of instructions that tells hardware how to behave and what tasks to perform. It includes the operating system, utilities, device drivers, and end-user applications.
Concrete example
A browser interprets HTML and renders web pages; the operating system schedules CPU time and provides memory to the browser.
Common misconception
Deleting an application's folder removes it completely — not true. Residual configuration or registry entries often remain.
Key Takeaway

Treat software as instructions when diagnosing issues; asking "software or hardware?" narrows your path to a fix.

Analogy
Think of hardware as musical instruments and software as sheet music and a conductor — without the notes and direction, the instruments are silent or random.
Quick diagnostics
  • Restart the application and check logs.
  • Test with a different user profile to isolate config issues.
  • Boot from a rescue environment to exclude OS-level faults.
