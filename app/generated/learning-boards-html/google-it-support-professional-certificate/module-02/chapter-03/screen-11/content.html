Module 3 › Chapter 2.3 › Install & Remove Lab
Windows — Example workflow
Download installer, verify publisher, run the executable, accept EULA, finish, verify in Apps & features, then launch to test.
macOS & Linux — Example workflow
macOS: mount .dmg, drag to Applications, test, then remove and check support folders. Linux: update repos, install with package manager, test, then remove or purge depending on whether to keep configs.
Check your understanding
Which step confirms the installer came from a trusted source? Answer: verifying the publisher or using official repositories.
