Module 3 › Chapter 2.3 › Installation Patterns
Windows
Installers (.exe) present wizards and options. Always verify the publisher and watch for bundled software. Some installs require reboot to finalize system-level components.
Example
Run the installer, accept EULA, choose components, then finish and restart if prompted.
macOS
Many apps use disk images; drag the application icon to Applications. Some apps include a dedicated uninstaller or install helper for plugins.
Example
Open the downloaded .dmg and drag the app to Applications, then eject the image.
Linux
Package managers install software with dependency resolution. Commands like sudo apt install allow reproducible installs and clean removal.
Example
Run sudo apt update and sudo apt install package-name to fetch from repositories.
App Stores
Stores simplify discovery, sandboxing, and updates, but may restrict features compared to direct vendor installs.
Example
Use an official store for safer, curated installs and automatic updates.
