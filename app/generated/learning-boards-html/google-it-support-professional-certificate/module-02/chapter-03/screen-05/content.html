Module 3 › Chapter 2.3 › System vs Application
System Software
Manages hardware, offers core services, and includes the OS, drivers, and system utilities such as backup tools and antivirus.
Example
Device drivers let the OS communicate with a printer or graphics card.
Misconception
System software can always be swapped without impact — false; system updates can change application compatibility.
Application Software
Designed for end users to perform tasks: web browsing, editing, gaming, or business-specific functions.
Example
A word processor uses system services for file access and printing.
Practical tip
When multiple applications fail, suspect shared system components before reinstalling each app.
