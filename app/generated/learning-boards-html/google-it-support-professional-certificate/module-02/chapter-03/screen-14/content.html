Module 3 › Chapter 2.3 › Key Concepts
Software
Instructions that tell hardware what to do. Necessary to run any device function.
Drivers
Translate between OS and hardware so devices function correctly and efficiently.
Updates & Firmware
Patches fix vulnerabilities; firmware alters hardware behavior and must be applied carefully.
Summary takeaway
Manage software intentionally: identify the layer at fault, use proper install/uninstall flows, and apply updates with priority for security patches.
