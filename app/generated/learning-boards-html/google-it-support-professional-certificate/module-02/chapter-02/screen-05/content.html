Process lifecycle
Create → run → wait → terminate. The OS schedules processes and enforces isolation.
Scheduling: The OS gives each process slices of CPU time so multiple programs make progress.
Concurrency: Appears simultaneous through scheduling and multi-core execution.
Unresponsive processes: The OS provides ways to terminate a hung process to restore system stability.
Common mistake

Assuming a slow app means low CPU; it may be waiting on disk I/O or stuck in heavy memory swapping.

Practical tools & example
Open Task Manager, Activity Monitor, or top to inspect processes. Look for high CPU or memory usage. Example scenario: a browser tab causes 80% CPU usage and makes the system sluggish; terminating that tab’s process restores responsiveness.
Check
Are CPU usage and memory consumption aligned with user reports of slowness?
Action
Terminate or restart the offending process, then monitor for recurrence to determine root cause.
