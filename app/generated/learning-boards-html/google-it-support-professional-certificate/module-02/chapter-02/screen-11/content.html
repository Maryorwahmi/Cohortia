Terminal demo (visual)
Follow this short walkthrough in a terminal. These commands are safe and non-destructive when used as shown.
# macOS / Linux
$ pwd        # show current directory
$ ls -l      # list files with details
$ cd Downloads
$ ls

# Windows (Command Prompt)
C:\> cd Documents
C:\Users\You\Documents> dir
Network info
Find your IP address for diagnostics: Windows uses ipconfig, macOS/Linux use ip a or ifconfig depending on tools installed.
Example: run ipconfig and look for IPv4 Address to share with a network team.
Tip: The CLI is ideal for remote sessions and scripting repeatable checks during support.
Reminder: Confirm your current directory before running commands that modify files.
