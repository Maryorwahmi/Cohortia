Operating System
System software that manages hardware, resources, and services for programs.
Process Management
Allocates CPU time, schedules tasks, and handles unresponsive processes.
Memory Management
Allocates RAM, uses virtual memory when needed; swapping prevents crashes but slows performance.
Summary
Use these concept cards as a rapid checklist when diagnosing performance, file, or device issues during support.
