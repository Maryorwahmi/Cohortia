Module 2 › Chapter 2.2 › File System
Structure & metadata
Directories organize files; paths identify locations; permissions control access.
Path example: A path points to a file’s location in the hierarchy.
Permissions: Read, write, execute flags limit actions by users and groups.
Ownership: Files have owners who can change permissions when needed.
Troubleshooting steps
1. Verify current directory with pwd or cd. 2. List files with ls or dir. 3. Check permissions and ownership. 4. Adjust permissions if necessary with appropriate commands or GUI tools.
Example: A user cannot save a file. Check disk space, confirm write permission on the target directory, and verify the correct path.
Common mistake: Changing permissions without understanding ownership and security implications.
