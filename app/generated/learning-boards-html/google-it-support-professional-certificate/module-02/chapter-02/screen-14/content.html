Module 2 › Chapter 2.2 › CLI Activity
Try this sequence
# macOS / Linux
$ pwd
$ ls -l
$ cd Downloads
$ ls
$ cd ..
$ ip a

# Windows (Command Prompt)
C:\> cd
C:\> dir
C:\> cd Downloads
C:\> dir
C:\> ipconfig
These commands are read-only for inspection. Use them to prepare information to share with support teams or to decide your next step in troubleshooting.
Reflection prompts
  • Which directory did you start in and how did you confirm it?
  • Did the network command show an IPv4 address you could share for remote help?
  • Would the GUI have been faster or did the CLI give clearer information?
Tip: Always document the exact commands and outputs you collected for consistent troubleshooting records.
