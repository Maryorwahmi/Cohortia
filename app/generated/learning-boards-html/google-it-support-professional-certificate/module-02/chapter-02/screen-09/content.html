Module 2 › Chapter 2.2 › OS Families
Windows
Broad hardware and software compatibility. Support often involves updates, drivers, and Control Panel navigation.
Common task: Fixing driver issues via Device Manager.
macOS
Unix-based, tightly integrated with Apple hardware. Support focuses on system preferences, APFS behaviors, and recovery tools.
Common task: Using built-in recovery or reinstall tools for system repairs.
Linux
Open-source, customizable, widely used on servers. Support often uses the CLI and distribution-specific package managers.
Common task: Managing services and updates via the terminal.
Practical contrast
If you need graphical software compatibility, check Windows first. For integrated Apple hardware behaviors, use macOS. For server or development tasks and precise control, Linux and its CLI are often the best fit.
