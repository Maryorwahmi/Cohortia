PMFD checklist
Process
Memory
Files
Devices
Step 1: Identify runaway processes and restart or terminate them.
Step 2: Observe memory and swap activity to see whether RAM or disk swapping is causing slowness.
Step 3: Confirm file paths and permissions when applications report missing files or save failures.
Step 4: Check device listings and drivers when hardware is powered but not functioning.
Scenario
User reports slow computer. PMFD sequence: find an offending process, check memory usage, confirm files are accessible, then inspect devices. Document each step and outcome for handoff.
Tip

Working methodically avoids unnecessary hardware replacements when software or configuration is the real cause.
