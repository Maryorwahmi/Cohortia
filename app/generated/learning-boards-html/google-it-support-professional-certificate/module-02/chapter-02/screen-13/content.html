Kernel responsibilities
Privilege, scheduling, memory protection, and device coordination are kernel duties.
Privileged code: Kernel runs with higher privileges than user applications to access hardware directly.
Stability: Kernel faults often crash the whole system, so kernel issues are high priority.
Support focus
After a kernel crash, check recent driver installs or hardware changes. Collect logs in recovery mode when possible. Kernel errors usually point to drivers or failing hardware, not accidental user actions.
Example: A new printer driver causes a kernel panic after installation. Rolling back the driver or using a vendor-recommended driver often resolves the crash.
