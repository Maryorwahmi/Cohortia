Memory concepts
Allocation, protection, and extension via virtual memory and swap.
Allocation: OS assigns memory regions to processes on request.
Protection: Boundaries prevent one process from overwriting another.
Virtual memory: Swap file extends RAM at performance cost when RAM is full.
Misconception

Swap is not a performance boost; it prevents crashes by using slower storage when RAM is exhausted.

Example scenario
A user runs a browser with many tabs and a photo editor. The OS places inactive tab pages into swap so the editor has RAM. If the system becomes sluggish and shows high disk usage, swapping is a likely cause.
Check
Monitor memory and disk I/O. Look for high swap activity or paging counts.
Action
Close unused apps or suggest additional RAM if swapping persists under normal workloads.
