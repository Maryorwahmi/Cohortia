Module 2 › Chapter 2.2 › Objectives — Skills
Objective -> Action
  • ●Process: List and end unresponsive processes with Task Manager or Activity Monitor to restore interactivity quickly.
  • ●Memory: Check RAM use and swapping to determine whether slowdowns are caused by too many active apps or by heavy paging to disk.
  • ●Files: Navigate directories and verify file permissions so software can access needed data without permission errors.
  • ●Devices: Inspect device listings and drivers; update or reinstall drivers when hardware is detected but not functioning.
Quick practice prompts
CLI Navigation
Open Terminal, run pwd or cd to confirm your location. List files with ls or dir.
Driver Check
Open Device Manager or system information to confirm a device appears and has a valid driver.
