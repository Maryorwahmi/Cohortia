Module 2 › Chapter 2.2 › Device Management
Device stack
Hardware ↔ Driver ↔ OS. Drivers convert OS requests into device instructions.
Detection: The OS detects new hardware and attempts to find or install a driver.
Errors: Unknown device or yellow warnings indicate driver problems.
Action: Update, reinstall, or use vendor drivers when automatic updates fail.
Support checklist
1. Confirm the device is powered and connected. 2. Open the OS device listing. 3. Look for error icons. 4. Update or reinstall drivers from the device maker. 5. Restart to load the driver.
Example incident: Webcam powered but not recognized. Check Device Manager; if listed as unknown, update driver or download the model-specific driver from the vendor and install it, then restart.
