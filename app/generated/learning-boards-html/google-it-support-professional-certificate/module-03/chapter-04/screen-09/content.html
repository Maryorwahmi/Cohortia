Module 4 › Chapter 3.4 › ping — Test basic reachability
Sequence example
ping 127.0.0.1 // tests local stack
ping <Default_Gateway_IP> // tests local network
ping 8.8.8.8 // tests external IP connectivity
ping www.google.com // tests name resolution plus reachability
Interpretation tips
  • Loopback failure suggests local adapter or driver problems.
  • Gateway failure suggests a Layer 1/2 issue between client and router.
  • External IP failure may be ISP or router WAN issues or firewall blocking ICMP.
Scenario
A user complains of slow websites. Ping to the gateway shows low latency but pings to external hosts show high times. This suggests an issue beyond the LAN, possibly with the ISP or congestion on the upstream path.
Misconception
Absence of ping replies does not always mean a host is down; ICMP may be filtered by firewalls.
Key Takeaway

Ping is your quick evidence collector: start local, then expand outward. Combine with other tools for a full diagnosis.
