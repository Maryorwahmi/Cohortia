Module 4 › Chapter 3.4 › DHCP — Automatic address assignment
Definition
DHCP automatically provides IP configuration including address, mask, gateway and DNS server entries to clients for a lease period.
Commands to know
  • ipconfig /all — shows DHCP server and lease information.
  • ipconfig /release and ipconfig /renew — force the client to request a new lease.
Common symptom
A client with an automatic private address signals DHCP failure on the network path.
Scenario
A laptop cannot access the network and shows address 169.254.x.x. This indicates it could not reach the DHCP server. Check cabling or Wi-Fi association, then check DHCP server availability and scope.
Misconception check
Some assume DHCP always assigns the same address; unless a reservation exists, DHCP may assign a different address each lease cycle.
Key Takeaway

DHCP automates addressing; use release/renew and inspect lease info to resolve local addressing problems.
