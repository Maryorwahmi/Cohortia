Module 4 › Chapter 3.4 › DNS — The internet's phonebook
Definition
Domain Name System (DNS)
Transforms domain names into IP addresses so clients can locate servers.
How to test
  • Run nslookup for a domain to see which DNS server replies and the returned address.
  • Ping the returned IP to verify basic connectivity if name resolution fails.
  • Check client DNS settings in ipconfig /all to confirm configured servers.
Typical misconception
DNS failure is often mistaken for total internet outage. Verify IP-based connectivity first to separate DNS from routing issues.
Key Takeaway

If IP access works but names fail, your evidence points to DNS, not general connectivity.

Concrete example
Scenario: User can open a company file share by IP but cannot access the company website by name. Use nslookup to see the DNS response. If nslookup shows no answer or a different address, update DNS settings or contact the DNS provider.
Explain output
Nslookup will show the server used and returned addresses. Non-authoritative answers are normal for cached responses. Timeouts indicate unreachable DNS servers.
Pro tip: Keep a known good public DNS IP to test external resolution if your configured server appears broken.
