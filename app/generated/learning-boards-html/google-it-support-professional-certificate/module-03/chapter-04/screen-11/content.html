Module 4 › Chapter 3.4 › ipconfig / ifconfig — Inspecting your interface
Commands
ipconfig /all // shows IP, DNS servers, DHCP server and lease info
ipconfig /release // release DHCP lease
ipconfig /renew // request a new DHCP lease
When to use
When you suspect wrong IPs, stale leases or incorrect DNS settings on the client.
Scenario
A workstation can't access the internet but can see local resources. ipconfig /all shows a valid IP and DNS but the default gateway is missing. The next steps are to check the NIC driver, reconnect to the network, and test gateway reachability with ping.
Misconception
Seeing an IP does not guarantee routing; the gateway or higher-level services may still fail.
Key Takeaway

Ipconfig is your source of truth for what the client believes its network settings are. Use it before making changes.
