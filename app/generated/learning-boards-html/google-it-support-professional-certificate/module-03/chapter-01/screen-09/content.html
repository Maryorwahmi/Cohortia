Module 3 › Chapter 3.1 › Ethernet vs. Fiber Optic Cabling
Comparison table
Ethernet (Cat5e/Cat6)
Common for desktops and switches. Up to ~100 meters for a single run. Uses RJ45 connectors.
Fiber Optic
Uses light, supports long distances and high bandwidth. Immune to electromagnetic interference; requires transceivers and fiber connectors.
Troubleshooting tips
  • Measure run length when performance drops over long cable runs.
  • Check connectors and termination quality on copper runs.
  • Replace noisy electrical environments with fiber if interference is suspected.
Concrete example
150-meter workstation problem

A workstation 150 meters from the closet using Cat5e shows slow and flaky connectivity. Cat5e exceeds its reliable limit around 100 meters, causing attenuation. Solutions: add a switch midway, install fiber with appropriate transceivers, or move the endpoint closer.

Misconception
Fiber requires special handling but is not always necessary for short runs; cost and transceivers matter.
Key takeaway
Pick cabling for required distance and bandwidth; when in doubt, test and replace runs that exceed standards.
