Module 3 › Chapter 3.1 › Network Types: PAN, LAN, WAN
Side-by-side comparison
PAN
Very short range; personal devices; example: Bluetooth headset pairing.
LAN
Office or home network; Ethernet and Wi‑Fi; high throughput and low latency.
WAN
Connects LANs across distance; uses carrier links; higher latency.
Troubleshooting cues
  • PAN: check pairing and device radios.
  • LAN: check switch ports, cable type, and Wi‑Fi configuration.
  • WAN: check modem, ISP status, and router uplink settings.
Concrete example
Office case

A user can't reach a shared drive. If other LAN devices can reach it but the internet is fine, this points to a LAN issue: check the switch, VLANs, or the server's network settings. If everyone loses internet, check the WAN: the modem or ISP link.

Misconception
LAN means better latency but not necessarily better routing — logical segmentation can still block local traffic.
Key takeaway
Identify the network scope first to pick the right diagnostic steps.
