Module 3 › Chapter 3.1 › What is a Network?
Definition & Purpose

A network links devices to exchange data and share resources. Its purpose is reliable, efficient communication between endpoints.

Analogy
Think of data as mail: packets are letters routed to addresses. Local mail moves fast within a town; long-distance mail travels across carriers.
Quick checks
  • Are devices on the same IP range? That indicates a shared LAN.
  • Is the gateway the same? Different gateways imply different networks.
  • Can devices ping one another? A failure narrows the scope of troubleshooting.
Concrete example
Home LAN example

A laptop and a smart TV on the same Wi‑Fi share a LAN and can stream or print locally. The same laptop connecting to a corporate VPN reaches a different logical network through the WAN.

Common misconception
Same room ≠ same network. Logical addressing defines network membership.
Key takeaway
Start by confirming addressing and gateway to determine scope of a fault.
