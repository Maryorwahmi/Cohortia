Module 3 › Chapter 3.1 › How a Router Connects LAN to WAN
Router responsibilities
  • Forward packets between networks using routing tables and IP addresses.
  • Provide default gateway for LAN hosts so they can reach external networks.
  • Perform NAT to share a WAN IP among internal devices when needed.
Quick diagnostic checks
  1. Check link lights between modem and router.
  2. Verify router shows a WAN IP from the ISP.
  3. Confirm client gateway and DNS settings are correct.
Concrete example
Laptop to cloud web server

Your laptop sends a request to a web server. The packet goes to the default gateway, the router, which checks its routing table and forwards the packet toward the ISP. If the laptop uses a private address, the router applies NAT so the return traffic can be mapped back to the laptop.

Misconception
NAT hides internal hosts from the WAN, but it doesn't replace proper firewalling or routing policies.
Key takeaway
When internet access fails, confirm the router's WAN status and look for NAT or gateway misconfiguration before changing client settings.
