Module 3 › Chapter 3.1 › Switches and MAC Learning
How a switch works

A switch observes source MAC addresses and records which port a device is on. Using the MAC table, it forwards frames only to the destination port, reducing unnecessary traffic and collisions.

Learning MAC entries happens dynamically as devices send frames.
Managed switches provide port status and statistics useful in troubleshooting.
Hubs broadcast to all ports and create collisions; avoid using hubs in modern LANs.
Checks and symptoms
  • Frequent collisions or slow performance may indicate a hub or a physical loop.
  • Port LED off indicates link or power problem; blinking may indicate activity.
Concrete example
Printer traffic

When a workstation sends a job to a network printer, the switch forwards frames selectively to the printer's port. If the network used a hub instead, every device would see the print traffic, causing unnecessary load and possible collisions.

Misconception
Switches cannot route between IP networks; they forward at the data link layer by MAC addresses.
Key takeaway
Identify switches by multiple LAN ports and their MAC learning behavior; prefer switches over hubs for robust LANs.
