Module 3 › Chapter 3.3 › Key Concepts
IP Address
Numeric label that identifies a host and its location on a network.
IPv4 & IPv6
IPv4 is 32-bit dotted-decimal; IPv6 is 128-bit hexadecimal for more addresses.
Subnet Mask / CIDR
Mask or /xx shows which bits define the network and which define hosts.
Summary
Verify address, mask, gateway, and DNS. Convert to binary when masks create confusion. Use DHCP for scale and static for fixed services.
