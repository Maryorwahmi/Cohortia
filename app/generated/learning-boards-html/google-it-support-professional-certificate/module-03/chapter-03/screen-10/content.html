Formula

Calculate usable hosts

Given H host bits: total addresses = 2^H. Usable hosts = 2^H − 2 (network and broadcast reserved).

/24
H = 8 → 2^8 = 256 → 254 usable
/25
H = 7 → 2^7 = 128 → 126 usable
Planning steps
How to pick a mask
  1. Decide usable hosts required.
  2. Add 2 for network and broadcast.
  3. Find smallest H where 2^H ≥ total.
  4. Set prefix = 32 − H.
Common mistake
Not reserving addresses for DHCP or network services can exhaust a subnet quickly; plan a small buffer.
Key Takeaway

Use the 2^H − 2 rule for typical IPv4 LANs when choosing a subnet to ensure enough usable addresses.
