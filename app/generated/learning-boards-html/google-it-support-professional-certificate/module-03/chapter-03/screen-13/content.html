Process

Quick checks for connectivity

1. Verify addressing
Check IPv4 address and subnet mask with ipconfig /all.
2. Compute network
Use bitwise AND to confirm if devices are on same subnet.
3. Test gateway & DNS
Ping gateway and attempt DNS lookup to separate routing and name issues.
Address conflict
If two hosts use the same address, reassign one outside the DHCP range or update DHCP reservations.
Partial connectivity
Local reachability with no internet often points to DNS or gateway misconfiguration rather than IP uniqueness issues.
Key Takeaway

A structured checklist separating addressing, routing, and name resolution quickly isolates the root cause of most connectivity problems.
