Process

Translate /xx to mask and block size

  1. Start with 32 bits, set the first /xx bits to 1.
  2. Group bits into four octets and convert each to decimal for the mask.
  3. Block size = 256 − value of the last mask octet that contains network bits.
Worked examples
/24 → 255.255.255.0
Block size in last octet = 256 − 0 = 256, meaning one block of 256 addresses (254 usable).
/25 → 255.255.255.128
Block size = 128. Subnets: .0 and .128. Each has 126 usable hosts.
/26 → 255.255.255.192
Block size = 64. Subnets increment by 64 in the last octet: .0, .64, .128, .192.
Key takeaway

Reading CIDR quickly gives you the mask and block size needed for addressing and DHCP planning.
