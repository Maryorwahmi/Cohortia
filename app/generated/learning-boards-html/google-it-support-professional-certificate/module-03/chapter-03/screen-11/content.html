Module 3 › Chapter 3.3 › DHCP vs Static
Comparison

Dynamic leases vs fixed addresses

DHCP
Automated leases from a pool. Ideal for clients and mobile devices. Simplifies administration.
Static
Manual configuration for devices requiring persistent addresses, like servers and printers.
Best practice
Reserve a static address outside the DHCP range to avoid conflicts, or configure DHCP reservations on the server.
Concrete scenario
Printer example
Network: 192.168.10.0/24. DHCP: .100–.200. Choose static 192.168.10.50 for printer to ensure constant address.
Troubleshooting tip
Use ipconfig /all to verify "DHCP Enabled: No" when a device has a static IP. Look for mismatched gateway or DNS as common causes of partial connectivity.
Key Takeaway

Choose DHCP for scale, static for stability; always avoid assigning static addresses from an active DHCP range.
