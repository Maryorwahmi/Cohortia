Module 3 › Chapter 3.3 › IPv4 Structure
Definition

32 bits split into octets

Each IPv4 address contains four octets. Reading the binary shows which bits belong to network and host when a mask is applied.

Example conversion
192.168.1.1  →  11000000.10101000.00000001.00000001

Take the octet 192 → 128+64 = 192
Common misconception
Some people treat dotted-decimal as arbitrary. In reality, each decimal maps to exact bits that masks operate on; always check binary when masks look wrong.
Key takeaway
Practice converting octets to binary until you can spot mask boundaries quickly.
Annotated example
Address: 192.168.1.130
Last octet 130 → binary 10000010. Notice the second-highest bit is set.
Mask: 255.255.255.128 (/25)
In binary the mask ends with 10000000. That borrowed bit makes two subnets: .0/25 and .128/25.
Check
  • Convert address and mask to binary.
  • Compare network bits; identical network bits mean same subnet.
  • Misreading bits is the usual cause of 'can't reach local host' issues.
Key Takeaway

Binary conversion is the fastest way to verify mask boundaries and spot addressing errors when troubleshooting.
