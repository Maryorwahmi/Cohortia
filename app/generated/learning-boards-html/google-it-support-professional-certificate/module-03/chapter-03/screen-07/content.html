Module 3 › Chapter 3.3 › Subnet Masks
Core concept

Mask = network map

A mask's ones indicate network bits. Applying a bitwise AND with an IP yields the network address used for routing and adjacency checks.

Example: AND operation
IP:   192.168.1.130  → 11000000.10101000.00000001.10000010
Mask: 255.255.255.128 → 11111111.11111111.11111111.10000000
AND result →       192.168.1.128
Misconception
Matching only the first few octets doesn't guarantee same subnet; the mask can include bits inside any octet.
Practical steps
Step-by-step check
  1. Convert IP and mask to binary octets.
  2. Perform bitwise AND per octet.
  3. Convert AND result back to dotted-decimal to find the network address.
Key takeaway
The AND operation is the definitive method to decide whether two addresses belong to the same local network.
Check your understanding

If two hosts have different masks, compute both network addresses to verify if they match; identical host octets can be misleading.
