Module 3 › Chapter 3.3 › Public vs Private
Definition

Private address ranges (RFC 1918)

  • 10.0.0.0/8 — large private block
  • 172.16.0.0/12 — medium private block
  • 192.168.0.0/16 — common home networks
Why NAT matters
NAT lets many private hosts share one public IPv4 address assigned to the router, conserving global addresses and providing a basic layer of isolation.
Concrete scenario
Home network
Router WAN: public IP assigned by ISP. LAN hosts: 192.168.1.x private addresses sharing the router's public address via NAT.
Troubleshooting checklist
  • Is the host IP in a private range?
  • Does the router have a working public IP on the WAN?
  • Is NAT or a firewall blocking outbound traffic?
Key takeaway
Private addresses are reusable and rely on NAT to reach the internet; check both the host address and the router's public address when diagnosing reachability.
