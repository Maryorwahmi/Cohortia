Module 3 › Chapter 3.3 › Splitting /24 → /25
Step-by-step

Split 192.168.1.0/24 into two /25s

  1. Original: 192.168.1.0/24 (mask 255.255.255.0).
  2. Borrow 1 host bit → new prefix /25 → mask 255.255.255.128.
  3. Block size = 128 → subnets: .0/25 and .128/25.
  4. Usable hosts: .1–.126 and .129–.254 (exclude .0, .127, .128, .255 as network/broadcast).
Visual ranges
Subnet A
192.168.1.0/25 — usable 192.168.1.1 to 192.168.1.126
Subnet B
192.168.1.128/25 — usable 192.168.1.129 to 192.168.1.254
Common mistake
Assigning .128 to a host in the second subnet would conflict with that subnet's network address; avoid network and broadcast addresses.
Key Takeaway

Borrowing bits reduces hosts per subnet and increases the number of subnets; always compute usable ranges to prevent conflicts.
