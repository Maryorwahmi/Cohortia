Module 3 › Chapter 3.3 › Key Concepts
NAT
Translates private addresses to a public IP so private hosts can access the internet.
DHCP
Automatically assigns addresses and critical network settings from a pool.
Static IP
Used for devices that must be reliably reachable; choose addresses outside DHCP ranges.
Final summary
Use these checks and practices to prevent and resolve the majority of IP addressing and subnetting issues you will face in support roles.
