Module 3 › Chapter 3.3 › IPv4 vs IPv6
Comparison

Notation and capacity

IPv4
32-bit addresses, dotted-decimal, ~4.3 billion addresses. Example: 192.168.1.1
IPv6
128-bit addresses, hexadecimal groups. Example: 2001:0db8:85a3::8a2e:0370:7334
Practical note
Many systems are dual-stack. Troubleshoot both stacks when connectivity is inconsistent.
Misconception
IPv6 instantly eliminates NAT — not always. Deployment choices determine addressing and translation needs.
Concrete example
IPv4 example
192.168.1.10 is readable and easy to record for support tasks like printer addressing and DHCP scopes.
IPv6 example
IPv6 enables many unique addresses per networked device; writing and compressing the address is part of administration.
Check your thinking
  • Is the interface configured with IPv4, IPv6, or both?
  • Does the problem appear on one protocol only?
  • Would NAT or a firewall be interfering with traffic?
Key Takeaway

Both protocols coexist; recognizing which one is in use guides your troubleshooting and configuration choices.
