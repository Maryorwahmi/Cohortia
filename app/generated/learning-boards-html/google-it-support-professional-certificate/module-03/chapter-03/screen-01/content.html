IP Addressing and Subnetting

Understand how IPv4 and IPv6 identify hosts, how subnet masks partition networks, and how CIDR and DHCP shape address assignment.

In this lesson

Read and convert IPv4 addresses, compare IPv6, split networks with subnet masks, and assign addresses using DHCP or static configuration.

Why it matters

Accurate addressing prevents conflicts and enables routing across local and wide-area networks.

Common tool

Use ipconfig or ifconfig to inspect addresses and subnet masks during troubleshooting.

Visual concept
IPv4 (32-bit)
Dotted-decimal: 192.168.1.1 — four octets, each 0–255
IPv6 (128-bit)
Hexadecimal groups separated by colons; much larger address space.
Subnet Masks & CIDR
Masks separate network and host bits. CIDR uses "/" to show the network prefix length.
