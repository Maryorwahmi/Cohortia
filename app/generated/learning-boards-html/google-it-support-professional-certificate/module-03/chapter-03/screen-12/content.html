Module 3 › Chapter 3.3 › Static IP Steps
Checklist

Values to enter

  • IP address (chosen outside DHCP range)
  • Subnet mask (from CIDR)
  • Default gateway (router IP)
  • DNS servers (primary, optional secondary)
Example values
IP: 192.168.10.50, Mask: 255.255.255.0, Gateway: 192.168.10.1, DNS: 8.8.8.8
Verification
Command-line check
Run: ipconfig /all
Look for: DHCP Enabled : No
IPv4 Address : 192.168.10.50
Subnet Mask : 255.255.255.0
Default Gateway : 192.168.10.1
DNS Servers : 8.8.8.8
Troubleshooting
If connectivity fails, confirm gateway reachability with ping, verify no IP conflict, and check DNS resolution separately.
Key Takeaway

A correct static configuration plus verification prevents conflicts and ensures a device remains reachable for services like printing or hosting.
