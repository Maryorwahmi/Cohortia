Core Concept
Layer 2 — Data Link Layer
Responsible for local link communication using MAC addressing and basic error detection.
What it handles
Frame formatting, MAC addresses, switch forwarding, and error detection on a single link.
Troubleshooting cues
  • Adapter shows a MAC address and is enabled.
  • No excessive frame errors on the NIC or switch port.
  • VLAN membership and switch port configuration are correct.
Common mistake
Assuming IP addressing is wrong when the adapter is disabled or the MAC is missing—this is a Layer 2 symptom.
Example and checks
Example
A laptop shows a valid link light but ipconfig shows no IP and no MAC listed; check adapter state and drivers at Layer 2.
Quick checks
  • Verify the NIC is enabled in the OS and driver is present.
  • Confirm the MAC address appears in the adapter properties.
  • Review switch port stats for errors and VLAN tags.
Pro tip
A healthy link light with frame errors suggests duplex or cabling mismatch rather than an immediate Layer 3 routing problem.
Key Takeaway

Layer 2 ensures local link reliability—check NIC, MAC, and switch behavior before moving to addressing.
