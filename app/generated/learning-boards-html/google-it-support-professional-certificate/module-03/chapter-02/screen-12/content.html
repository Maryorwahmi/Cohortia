Process Flow
Troubleshooting Workflow
Use a stepwise approach from physical to application layers using basic diagnostic commands.
1. Layer 1 — Physical
Check cables, link lights, and power; replace cable if needed.
2. Layer 2 — Data Link
Confirm NIC enabled and MAC address present; review switch port stats.
3. Layer 3 — Network
Use ipconfig and ping to verify IP and gateway reachability.
4. Layer 4 — Transport
Test specific ports and review firewall rules for blocked TCP/UDP traffic.
5–7. Application layers
Check DNS, service status, application configuration, and logs.
Example commands
ipconfig (Windows)
Shows IP address, subnet mask, and default gateway to confirm Layer 3 configuration.
ping
Tests basic IP reachability to the gateway or remote hosts.
nslookup
Verifies DNS name resolution and identifies DNS server responses at the Application Layer.
Assessment (mini)
You can ping a server by IP but not by name. Which command helps verify whether the problem is DNS? A) ipconfig B) ping C) nslookup D) traceroute
Key Takeaway

Follow the layered flow and use the right command at the matching layer to isolate faults quickly.
