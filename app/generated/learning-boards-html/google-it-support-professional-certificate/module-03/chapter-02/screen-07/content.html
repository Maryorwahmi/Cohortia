Core Concept
Layer 3 — Network Layer
Handles logical addressing and routing across networks using IP.
What it handles
IP addressing, subnetting, routing decisions, and routers.
Diagnostic checks
  • Confirm IP address and subnet mask match expected network.
  • Ping the default gateway to check local routing.
  • If gateway responds, test external IP reachability to isolate upstream routing.
Common mistake
Assuming DNS or browser issues when the device lacks a proper default gateway or correct IP assignment.
Concrete example
Scenario
A workstation can access local file shares but cannot reach the internet. Ping to 192.168.1.1 (the gateway) succeeds, but ping to an external IP fails. This points to an upstream routing or ISP issue at or beyond Layer 3.
Check sequence
  1. Confirm IP address and gateway via ipconfig.
  2. Ping the default gateway.
  3. Ping a known external IP to test routing beyond the gateway.
Pro tip
If gateway pings fail for some devices but not others, check VLAN or routing ACLs on the switch or router.
Key Takeaway

Layer 3 controls access between networks—confirm IP configuration and gateway reachability before blaming applications.
