Definition
Layer 7 — Application Layer
Offers services to user applications such as web, email, and name resolution.
Key protocols
HTTP, FTP, SMTP, POP3, IMAP, DNS, and DHCP provide end-user services and name/address functions.
Troubleshooting cues
If service fails despite IP reachability, check DNS, service status, credentials, proxy settings, and application logs.
Examples & checks
Example
If you can ping 142.250.190.164 but not access www.google.com, use nslookup to test DNS resolution; DNS failure is an Application Layer problem.
Check sequence
  1. Verify IP reachability to the server.
  2. Run a name lookup to confirm DNS resolution.
  3. Test the service itself and review application logs or settings.
Common mistake
Don’t assume the web server is down if DNS fails; often correcting DNS settings or using a different resolver fixes the issue.
Key Takeaway

Application layer problems often involve DNS or service configuration; confirm name resolution and service status early.
