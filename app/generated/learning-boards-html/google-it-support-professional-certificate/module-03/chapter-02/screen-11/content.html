TCP/IP vs OSI
A practical four-layer model that maps to OSI's seven layers for real-world networking.
TCP/IP Application
Combines OSI Layers 5–7: session, presentation, and application responsibilities and protocols like HTTP and DNS.
TCP/IP Transport
Maps to OSI Layer 4 and includes TCP and UDP for end-to-end delivery.
TCP/IP Internet
Corresponds to OSI Layer 3 where IP handles addressing and routing.
TCP/IP Network Access
Combines OSI Layers 1–2: physical and data link functions like Ethernet and Wi‑Fi.
Practical mapping & example
Example
A DHCP failure that prevents a device from getting an IP address is an Application layer issue in TCP/IP (service), but in OSI it touches Data Link and Network functions too since the assignment interacts with link operations and addressing.
Check sequence using mapping
  1. Network Access: confirm physical and link connectivity.
  2. Internet: verify IP addressing and routing.
  3. Transport: test TCP/UDP ports for the service.
  4. Application: check service configuration and name resolution.
