Process Flow WPA3 Enterprise Architecture
Component roles
  • Access Point: Forwards 802.1X/EAP to RADIUS and enforces encryption on the radio link.
  • RADIUS Server: Authenticates users/devices against AD or a local store and returns accept/reject.
  • Certificate Authority: Issues certificates for mutual authentication in EAP-TLS deployments.
Key Takeaway

Design for availability and certificate lifecycle management to keep per-user authentication reliable and auditable.

Step-by-step example
1. Client requests join
Client initiates EAP, AP creates a RADIUS proxy request.
2. RADIUS validates
RADIUS checks certificate or credentials against the identity store and CA trust chain.
3. Authorization enforcement
RADIUS returns Accept or Reject and may include VLAN assignment for isolation.
Common misconfiguration
Client devices not set to validate the server certificate allow rogue RADIUS impersonation and credential theft. Ensure explicit validation of server common name and issuer.
