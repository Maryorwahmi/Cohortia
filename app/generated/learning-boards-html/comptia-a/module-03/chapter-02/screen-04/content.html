Core Concept Wireless Threats
Definition & context

Wireless transmits RF to all nearby receivers. This increases risk of eavesdropping, rogue APs, and credentials capture unless strong protocols are used.

Evolution
WEP → WPA2 → WPA3: each step addressed cryptographic and authentication weaknesses.
Forward Secrecy
WPA3’s SAE provides forward secrecy so past sessions remain protected if long-term keys leak.
Per-user Auth
802.1X with RADIUS ties credentials to users for revocation and audit.
Key Takeaway

Treat wireless as untrusted medium: enforce per-user authentication and forward-secret keying to limit exposure.

Concrete example
Imagine a campus where everyone uses a common WPA2 passphrase. When an employee leaves, you must change the shared passphrase on all devices — a slow and error-prone workflow. With WPA3 Enterprise and 802.1X each account can be disabled or certificates revoked immediately, preventing further access from that user’s device.
Misconception
Hiding an SSID or using a long PSK equals security — false. Obscurity and shared keys do not provide accountability or forward secrecy.
Pro tip
Plan certificate lifecycle and revocation before rolling out EAP-TLS to avoid long-term administrative gaps.
