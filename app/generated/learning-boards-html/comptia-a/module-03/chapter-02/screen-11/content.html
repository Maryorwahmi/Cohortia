Lab Walkthrough WPA3 Enterprise Checklist
Stepwise plan
  1. Identify components: APs, RADIUS, CA, clients.
  2. RADIUS setup: service account, EAP method selection, AD integration.
  3. Certificate work: issue server cert and client certs or prepare server certificate for PEAP.
  4. AP configuration: create WPA3 Enterprise SSID, RADIUS server IP and shared secret.
  5. Client profile: deploy Wi‑Fi profile or certificate and enforce server cert validation.
  6. Tests: authenticate client, check RADIUS logs, verify VLAN and firewall isolation.
Common mistake
Failing to test server certificate validation allows credential capture. Always validate mutual authentication flows in your lab.
Example configuration notes
# RADIUS server notes (conceptual)
RADIUS_IP=10.0.10.5
EAP_METHOD=EAP-TLS           # or EAP-PEAP
CA=Corporate-CA
SharedSecret=REDACTED
VLAN_TAG=200  # guest or employee mappings

# Client profile
- Install CA certificate
- Install client cert (EAP-TLS) or configure to validate server cert (PEAP)
- Enable EAP method and certificate validation
Key Takeaway

Follow a repeatable checklist: prepare CA, configure RADIUS, set APs, deploy client profiles, and test thoroughly including negative tests.
