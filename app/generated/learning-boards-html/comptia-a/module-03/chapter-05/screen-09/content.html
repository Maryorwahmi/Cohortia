Module 3 › Chapter 3.5 › EDR Overview
What EDR does
Continuous endpoint telemetry, analytics, and response actions for advanced threats.
Telemetry collected
Process creation, file changes, network connections, and registry modifications provide context for detections.
Detection and analytics
Uses behavior analysis and machine learning to identify suspicious activity beyond signatures.
Response capabilities
Isolate hosts, kill processes, and collect evidence to support remediation and forensics.
Deployment considerations
Agent coverage
Deploy agents to all endpoints and servers to avoid blind spots in telemetry.
Tuning
Tune rules to reduce false positives and define escalation procedures for alerts.
Common mistake
Expecting EDR to replace patching and baselines. EDR complements prevention by enabling detection and response.
Key Takeaway

EDR is most valuable when integrated into operations with playbooks for investigation and containment.
