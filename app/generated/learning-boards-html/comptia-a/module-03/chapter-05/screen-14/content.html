Host Hardening
Configure OS and applications to reduce vulnerabilities and limit services to only what is necessary.
Secure Boot & TPM
UEFI verifies boot code; TPM secures keys and measurements to ensure a trusted boot process.
EDR & App Control
EDR offers telemetry and response; whitelisting blocks unknown executables when managed with a proper process.
Summary

Combine baselines, firmware/hardware protections, and continuous monitoring to create a layered, maintainable host security posture.
