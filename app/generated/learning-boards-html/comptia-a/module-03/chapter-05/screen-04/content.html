Module 3 › Chapter 3.5 › Host Hardening
Definition & Purpose
Host hardening reduces the attack surface through configuration and controls; baselines provide repeatability and auditability.
Baseline Example Checklist
  • Disable legacy services such as SMBv1 and Telnet.
  • Enforce least privilege and strong password policies.
  • Configure firewall to deny inbound by default and allow only necessary ports.
  • Enable automatic security updates and regular patch cycles.
  • Document and automate the configuration with GPO or CM tools.
Common misconception
A baseline is not a one-off checklist. It must be maintained, tested, and version-controlled so it adapts to legitimate changes without introducing risk.
Key takeaway
Baselines are the foundation of predictable, auditable host security and should be enforced automatically where possible.

Validation & audit
Use configuration scans and GPO reports to prove baseline compliance and identify drift.
Mistake to avoid
Applying a strict baseline without a pilot can break production apps. Always pilot rules and include rapid rollback steps.
