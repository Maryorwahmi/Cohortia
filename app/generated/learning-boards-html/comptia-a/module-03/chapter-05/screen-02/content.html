Learning Objectives
Learn, Understand, Apply, Master
Bloom: Learn → Master
01
Create secure baselines
Design baseline configurations for Windows Server and Linux that disable unused services, enforce firewall rules, and ensure timely patching. This helps guarantee a consistent minimum security posture across systems.
VERIFIED COMPETENCY MILESTONE
02
Explain Secure Boot and TPM
Describe how UEFI Secure Boot prevents untrusted boot components and how a TPM stores keys and measurements to anchor trust. This knowledge supports choices for disk encryption and integrity verification.
VERIFIED COMPETENCY MILESTONE
03
Manage EDR solutions
Deploy agents, configure detection rules, and use telemetry for investigations. Effective EDR reduces dwell time and supports containment and forensics.
VERIFIED COMPETENCY MILESTONE
04
Implement application control
Plan and implement whitelisting and blacklisting strategies. Understand the operational impact of whitelisting and manage exceptions without blocking legitimate work.
VERIFIED COMPETENCY MILESTONE
