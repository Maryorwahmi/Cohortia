Steps for Linux hardening
Tools: systemctl, apt/yum, ufw/firewalld, chmod/chown.
Disable unnecessary services
Example: systemctl disable . Reduce background services to minimize the attack surface.
Remove unneeded packages
Example commands: apt remove or yum remove. Test package removals to avoid breaking dependencies.
Configure a firewall
Use ufw for simple rules or firewalld for zones; deny by default and allow required services only.
Concrete commands
# Disable a service
systemctl disable nginx

# Remove a package (Debian/Ubuntu)
apt remove package-name

# Update packages
apt update && apt upgrade -y

# Enable ufw and allow SSH
ufw default deny incoming
ufw allow 22/tcp
ufw enable
Example scenario
A database server only exposes local DB ports; disable web server packages and open only the internal database port in the firewall.
Common mistake
Removing packages without dependency checks can break services. Use staging and package audit before removal.
