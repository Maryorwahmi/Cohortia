Lab Steps (Conceptual)
Follow these steps in a virtual machine before applying in production.
Step A: Disable SMBv1
Run the PowerShell command to turn off legacy protocol: Set-SmbServerConfiguration -EnableSMB1Protocol $false
Step B: Firewall rule
Configure Windows Firewall to block inbound by default and allow RDP only from management addresses.
Step C: Local Security Policy
Enforce password complexity, account lockout, and auditing to support investigations.
