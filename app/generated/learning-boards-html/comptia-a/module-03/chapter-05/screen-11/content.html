AppLocker rule workflow
Default rules → custom file path rules → Audit → Enforce → Deploy by GPO.
Step 1: Create Default Rules
This automatically allows executables in Program Files and Windows directories and reduces initial friction.
Step 2: Add custom rule
Create a file-path rule for C:\CustomApps\MyApp.exe to permit that specific application.
Step 3: Set Application Identity
Ensure the Application Identity service is Automatic and running; without it AppLocker will not apply rules.
Policy snippet (conceptual)
Testing tip
Run AppLocker in Audit mode to log blocked attempts before enforcing rules. Use a pilot OU first.
