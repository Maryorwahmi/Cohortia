Module 3 › Chapter 3.4 › HIPS vs NIPS
Architecture

Network IPS (NIPS)

Inline device positioned at choke points to inspect and prevent malicious network traffic.

Placement Examples
Perimeter, DMZ boundaries, between internal zones where lateral movement must be observed.
Architecture

Host IPS (HIPS)

Agent on servers or endpoints that detects suspicious process activity, file integrity changes, and local attacks.

Where to Deploy
Domain controllers, database servers, jump hosts, and high‑value workstations where host telemetry matters.
Concrete Example
NIPS stops a port scan at the perimeter; HIPS on a server flags suspicious privilege escalation after a successful exploit.
Misconception
Don't assume HIPS replaces NIPS — host and network telemetry reveal different signals and should be layered.
Check
Which assets in your environment produce events only visible at the host level?
