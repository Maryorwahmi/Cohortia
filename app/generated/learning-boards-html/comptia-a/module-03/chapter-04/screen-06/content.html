Process

Step-by-step NGFW Rollout

  1. Audit traffic and map business application needs.
  2. Define allowed and blocked application categories.
  3. Create user-aware rules tied to directory groups.
  4. Apply threat profiles and run in detection mode.
  5. Tune from logs, then enable block and advanced features.
Example Rule
Allow: web-browsing, smtp, pop3, imap; Block categories: gambling, adult, malware; Block apps: bittorrent, tor.

Key Takeaway
Use detection mode to gather evidence before switching to block, and monitor performance after each change.
