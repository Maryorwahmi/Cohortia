Learning Objectives

Four verified milestones that map to configuration and analysis skills.

Bloom: Learn → Understand → Apply → Master
01
Differentiate and configure NGFW features

You will set application control, URL filtering, and user identity policies. This matters because policies become precise and auditable when tied to applications and users.

VERIFIED COMPETENCY MILESTONE
02
Design and implement IPS/IDS deployments

You will place sensors, choose NIPS or HIPS, and apply rule tuning. Proper placement improves detection and reduces blind spots.

VERIFIED COMPETENCY MILESTONE
03
Integrate with SIEM for correlation

You will forward logs and validate correlations that reveal multi-step attacks. Correlation reduces investigation time and surfaces context.

VERIFIED COMPETENCY MILESTONE
04
Leverage threat intelligence feeds

You will prioritize indicators for automated blocking and analyst review. Timely feeds let you block known bad infrastructure quickly.
