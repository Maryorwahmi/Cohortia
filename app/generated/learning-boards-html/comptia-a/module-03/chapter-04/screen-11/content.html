Module 3 › Chapter 3.4 › SIEM Integration
Architecture

Forward logs, normalize, and correlate

Collect firewall, IPS, HIPS, and server logs into the SIEM. Normalize fields like IP, user, application, and signature ID to enable correlation.

Example Correlation
Trigger when a port scan from an IP is followed within 30 minutes by a failed login and an IPS signature from the same IP. This indicates reconnaissance followed by an access attempt.
Integration Checklist
  • Reliable log forwarding and timestamps synchronized
  • Field parsers for IP, user, application, and signature
  • Enrichment with threat intelligence for reputation
Key Takeaway
A SIEM turns scattered alerts into a timeline of activity. Prioritize correlated alerts for analyst investigation to accelerate response.
