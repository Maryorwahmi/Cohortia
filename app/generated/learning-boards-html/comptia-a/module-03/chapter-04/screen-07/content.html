Module 3 › Chapter 3.4 › IDS vs IPS
Definition

Intrusion Detection System (IDS)

Monitors traffic and generates alerts based on signatures or anomalies; used for monitoring and forensics.

Concrete Example
An IDS logs repeated failed login attempts to a server and raises an alert for investigation.
Definition

Intrusion Prevention System (IPS)

Inspects inline and actively blocks or drops malicious traffic in real time based on configured rules.

Pitfall
Placing an IPS inline without tuning can result in legitimate sessions being blocked, causing outages.
Design Rule
Start with detection, tune rules for normal business traffic, then enable prevention for hardened flows.
Example Scenario
Use IDS in a production segment while tuning signatures, then move the tuned policy inline in front of web servers.
Check
When should you prefer IDS over IPS? Consider risk to availability and maturity of traffic baselines.
