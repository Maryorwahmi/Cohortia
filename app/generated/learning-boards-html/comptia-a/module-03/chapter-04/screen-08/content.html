Module 3 › Chapter 3.4 › IPS/IDS Design
Process

Placement Strategy

  • Place NIPS at perimeter, DMZ, and between sensitive segments.
  • Deploy HIPS on critical servers and endpoints for host-level signals.
  • Ensure sensors see bidirectional traffic to identify attacks.
Example Placement
NIPS in front of web and database DMZs; HIPS on database servers to capture anomalous process behavior.
Tuning Workflow
  1. Run signatures in detection mode and collect alerts.
  2. Validate alerts with application owners to confirm legitimacy.
  3. Create scope-limited exceptions or adjust thresholds for noisy signatures.
  4. Enable block for well-understood, low-risk rules.
Key Takeaway
Tuning is continuous: schedule regular reviews, especially after app updates or architecture changes.
