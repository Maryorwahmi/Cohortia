Scenario

Problem: False Positives from Internal App

Signature SNORT_ALERT_12345_INTERNAL_APP_SQLI flags legitimate queries from ReportGen to ReportingDB.

Tuning Steps
  1. Verify with app owners and capture sample logs/packets.
  2. Create a scoped exception for the specific source/destination/port.
  3. Monitor in detection mode, then enable blocking if safe.
Conceptual Rule Example
IPS Exception: SNORT_ALERT_12345_INTERNAL_APP_SQLI
Scope:
  Source: 10.10.20.45  # ReportGen server
  Dest:   10.10.30.12  # ReportingDB
  Port:   1433         # Database port
Action:  Bypass signature for this scoped flow (detection active)
Verification
Collect logs for the exception window and confirm no malicious attempts are missed globally. Prefer scoped exceptions to global disables.
