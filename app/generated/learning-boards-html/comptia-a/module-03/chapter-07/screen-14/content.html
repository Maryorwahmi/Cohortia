Module 4 › Chapter 3.7 › Key Concepts
Shared Responsibility
Provider secures infrastructure; customer secures workloads and configs.
Least Privilege IAM
Grant only necessary actions; prefer roles and MFA for admins.
CSPM
Continuous scans for misconfigurations, integrated into operations.
Takeaway

Security in the cloud is an operational practice: define ownership, enforce controls, automate checks, and monitor continuously.
