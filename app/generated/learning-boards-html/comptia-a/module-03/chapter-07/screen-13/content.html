Module 4 › Chapter 3.7 › Hands-on Activity
Conceptual checklist
Create bucket
Name example: cohortia-secure-data. Enable block public access and default encryption.
Enable versioning
Optional but recommended for recovery from accidental deletes.
Set lifecycle rules
Manage snapshots and retention to meet policy requirements.
Attach IAM policy and verify
Attach the read-only policy to a user or role; test upload, delete, list, and download. Only download should work.
Monitoring
Enable access logs and forward to centralized logging for detection.
Remediation
Use CSPM to auto-detect unencrypted buckets and trigger remediation playbooks.
Reflection
What would you automate in this checklist to reduce manual errors?
