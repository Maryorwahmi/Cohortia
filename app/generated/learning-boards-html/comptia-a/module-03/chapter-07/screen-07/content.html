Module 4 › Chapter 3.7 › Storage Security
Core controls
  • Enable encryption at rest (SSE-S3 or SSE-KMS) and enforce TLS in transit.
  • Block public access at the bucket level and deny anonymous List/Get in policies.
  • Use IAM role-based access to narrow which services or users can read or write objects.
  • Enable versioning and logging to support recovery and forensic analysis.
Concrete configuration (conceptual)
Ensure "Block all public access" is enabled, set default encryption to SSE-S3 or SSE-KMS, and consider lifecycle rules for retention.
Example policy impact
An explicit deny for public read prevents accidental public exposure even if other policies allow read. This is useful when multiple policies intersect.
Why this matters
Unencrypted or publicly accessible buckets are a common cause of data breaches. These controls reduce that risk and help meet compliance requirements.
