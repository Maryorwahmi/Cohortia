Module 4 › Chapter 3.7 › Managed Database Security
Essential configurations
  • Enable strong authentication and integrate with managed identity or directory services.
  • Restrict network access with security groups, private endpoints, or VPC peering.
  • Enable encryption at rest and enforce TLS for connections.
  • Enable auditing and retention for access logs, and secure backups/snapshots.
Example
When migrating an on-premises DB to a managed service, ensure application accounts have limited permissions, network access is restricted to application subnets, and snapshots are encrypted with customer-managed keys if required by policy.
Why it matters
Even though the platform patches the DB host, access control and data protection remain customer responsibilities and are frequent audit points.
