Learning Objectives

Learn, Understand, Apply, Master — a practical competency path
Learn → Understand → Apply → Master
01
Explain the shared responsibility model
Define provider vs customer duties and recognize which controls remain your responsibility in IaaS and PaaS.
VERIFIED COMPETENCY MILESTONE
02
Harden IaaS components
Apply host hardening, secure images, patching, secure network rules and storage encryption to reduce attack surface.
VERIFIED COMPETENCY MILESTONE
03
Analyze PaaS risks
Assess serverless and managed databases for insecure dependencies, permissions, and data protection needs.
VERIFIED COMPETENCY MILESTONE
04
Design IAM & CSPM strategies
Create least-privilege IAM policies and integrate CSPM findings into SIEM and incident response workflows.
VERIFIED COMPETENCY MILESTONE
