Module 4 › Chapter 3.7 › IAM Policy Walkthrough
Policy explanation

The Allow statement grants read access to objects in cohortia-secure-data. The Deny statement explicitly blocks write, delete, and list operations on both the bucket and its objects. This explicit deny helps prevent unintended wider access when other policies might allow additional actions.

Verification
Test by attempting upload, delete, list, and download with the user. Only download should succeed.
IAM Policy JSON (visual)
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:GetObject"
      ],
      "Resource": [
        "arn:aws:s3:::cohortia-secure-data/*"
      ]
    },
    {
      "Effect": "Deny",
      "Action": [
        "s3:PutObject",
        "s3:DeleteObject",
        "s3:ListBucket"
      ],
      "Resource": [
        "arn:aws:s3:::cohortia-secure-data/*",
        "arn:aws:s3:::cohortia-secure-data"
      ]
    }
  ]
}
Pro tip
Always include the object suffix '/*' when scoping GetObject to objects inside the bucket, and test policies in a staging account before production.
