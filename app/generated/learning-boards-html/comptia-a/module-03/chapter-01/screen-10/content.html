Module 3 › Chapter 3.1 › PVLAN Lab
Scenario steps
  1. Create primary and isolated VLANs and associate them.
  2. Configure server ports as private-vlan host with correct association.
  3. Configure firewall port as promiscuous and map isolated VLANs.
  4. Verify server-to-firewall connectivity and server-to-server isolation.
Reference configuration
! Global Configuration
vlan 100
 private-vlan primary
vlan 101
 private-vlan isolated
vlan 102
 private-vlan isolated
vlan 100
 private-vlan association 101,102

! Interface for Server A
interface GigabitEthernet0/1
 switchport mode private-vlan host
 switchport private-vlan host-association 100 101

! Interface for Server B
interface GigabitEthernet0/2
 switchport mode private-vlan host
 switchport private-vlan host-association 100 102

! Interface for Firewall
interface GigabitEthernet0/3
 switchport mode private-vlan promiscuous
 switchport private-vlan mapping 100 101,102
After applying, run pings: Server A → Firewall should succeed; Server A → Server B should fail. Inspect switch MAC/ARP tables for unexpected entries.
