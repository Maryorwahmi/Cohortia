PVLAN roles explained
  • Promiscuous: Can reach any port in the PVLAN. Typical use: firewall or gateway.
  • Isolated: Only talks to promiscuous ports. Use for servers that must not peer.
  • Community: Can talk to other community ports and promiscuous ports. Use for grouped services.
Concrete scenario
In a DMZ, make each web server an isolated port so compromised hosts can reach the external firewall but cannot reach each other directly.
Planning and pitfalls
When configuring PVLANs, carefully map secondary VLANs to the primary and verify that promiscuous mappings include all required isolated and community VLANs. Keep documentation and test reachability to avoid accidental full isolation or unintended communication paths.
Check your understanding
Can a host on an isolated port ping another isolated host? No — only the promiscuous port is reachable.
