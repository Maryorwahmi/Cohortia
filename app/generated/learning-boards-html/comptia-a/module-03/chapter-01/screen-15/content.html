Module 3 › Chapter 3.1 › Reminders
Harden defaults
Disable DTP, set explicit port modes, and avoid using user native VLANs.
Document mappings
Record VLAN, PVLAN and VRF associations and mapping for audits and troubleshooting.
Protect controllers
Treat SDN controllers and NFV orchestrators as high-value assets requiring strict access control and logging.
Final takeaway

Segmentation reduces risk when implemented with precise configurations, operational discipline, and secure control planes. Validate and document every change.
