Module 3 › Chapter 3.1 › VLAN Hopping
Attack patterns
  • Switch spoofing: attacker negotiates a trunk and gains multiple VLAN access.
  • Double tagging: attacker sends frames with two tags to trick native VLAN handling.
Misconception
Relying on default switch settings leaves you vulnerable; explicit configuration is required.
Mitigations checklist
  • Disable DTP on user ports.
  • Explicitly set access and trunk modes; avoid automatic negotiation.
  • Set native VLAN to an unused ID on trunks.
  • Implement port security to limit MAC addresses.
