Module 3 › Chapter 3.1 › Inter-VLAN Security
Step-by-step process
  1. Inventory services that must cross VLANs.
  2. Write ACLs that explicitly permit those services; deny by default.
  3. Apply stateful firewalling at the routing point for complex flows.
  4. Test and iterate; keep rules labeled and minimal.
Example ACL intent
Allow only application server traffic from the app VLAN to the database VLAN on the specific port required. Block everything else. Use logging for denied attempts during testing.
Key Takeaway
Enforce least privilege at the routing device and avoid implicit trust between VLANs.
