Module 3 › Chapter 3.1 › Key Concepts
VLAN
Logical broadcast domains for grouping devices; pair with ACLs for security.
PVLAN
Host-level isolation within a primary VLAN using promiscuous, isolated, and community ports.
VRF
Separate routing instances on one device; useful for multi-tenant isolation and overlapping addresses.
Summary Takeaway

Use layered segmentation: VLANs for zones, PVLANs for host isolation, VRF for routing separation, and microsegmentation for per-workload policy. Secure control planes and routing points to make segmentation effective.
