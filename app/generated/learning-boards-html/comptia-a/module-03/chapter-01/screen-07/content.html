Module 3 › Chapter 3.1 › Microsegmentation
What microsegmentation does
It isolates individual workloads with tailored policies, so each application tier only accepts intended traffic.
Concrete example
Apply rules so a database only accepts connections from an application server pool, and the app servers only accept traffic from the load balancer.
SDN/NFV considerations
  • SDN centralizes policy in a controller; protect it with strong access controls.
  • NFV lets you run firewalls and load balancers as virtual functions; maintain strict orchestration integrity.
  • Plan for policy audit trails and rollback to detect and recover from misconfiguration or compromise.
