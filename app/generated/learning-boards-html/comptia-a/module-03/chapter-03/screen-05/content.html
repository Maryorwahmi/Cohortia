SSH configuration pattern
hostname Router1
ip domain name cohortia.local
crypto key generate rsa modulus 2048
ip ssh version 2
username admin privilege 15 secret SuperSecret
line vty 0 4
 transport input ssh
 login local
Use a 2048-bit modulus at minimum and enable SSH version 2. Prefer key-based authentication over passwords where operationally feasible.
Checks and common mistakes
  • Verify ip ssh version 2 is present; ip ssh version 1 is insecure.
  • Ensure domain name is set before generating keys to avoid key mismatches.
  • Confirm transport input only allows ssh on vty lines to block Telnet.
  • Plan key rotation and recovery processes to prevent administrative lockout.
Pro tip

Store certificates or keys in a secure vault and document the procedure for replacing keys so rotations do not cause outages.
