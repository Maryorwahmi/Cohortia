Starter configuration (partial)
! SSH Configuration
hostname Router1
ip domain name cohortia.local
crypto key generate rsa modulus 2048
ip ssh version 2
line vty 0 4
 transport input ssh
 login local

! SNMPv3 Configuration
snmp-server view SECUREVIEW iso included
snmp-server group SECUREGROUP v3 auth priv read SECUREVIEW
snmp-server user COHORTIAUSER SECUREGROUP v3 auth sha COHORTIAPASS priv aes 128 COHORTIAENC

! CoPP Configuration (Example for SSH/SNMP)
ip access-list extended COPP_ACL
 permit tcp any any eq 22
 permit udp any any eq 161
class-map match-all COPP_CLASS
 match access-group name COPP_ACL
policy-map COPP_POLICY
 class COPP_CLASS
  police 8000 1500 conform-action transmit exceed-action drop
control-plane
 service-policy input COPP_POLICY
Lab steps & verification
  1. Apply the starter configuration in your simulator and save the running config.
  2. Attempt Telnet; confirm it is denied and SSH succeeds using local credentials or keys.
  3. Query SNMPv3 from the collector and verify only allowed OIDs are visible.
  4. Generate test traffic to the router and confirm CoPP drops exceed traffic but permits conforms.
Key Takeaway

Follow the sequence: secure access, secure monitoring, then protect the control plane, and always verify each step in a lab before production.
