Module 3 › Chapter 3.3 › Control Plane Policing
CoPP configuration pattern
ip access-list extended COPP_ACL
 permit tcp any any eq 22
 permit udp any any eq 161
class-map match-all COPP_CLASS
 match access-group name COPP_ACL
policy-map COPP_POLICY
 class COPP_CLASS
  police 8000 1500 conform-action transmit exceed-action drop
control-plane
 service-policy input COPP_POLICY
Define matching ACLs and class maps, set policing rates, and apply the policy to the control plane to limit CPU-bound traffic.
Design considerations
  • Choose rates that allow legitimate management bursts but reject flood traffic.
  • Test with simulated loads to validate no essential control protocols are dropped.
  • Log exceed events if possible to support tuning and forensic analysis.
Pro tip

Start with conservative policing rates and incrementally tune while monitoring routing stability and management responsiveness.
