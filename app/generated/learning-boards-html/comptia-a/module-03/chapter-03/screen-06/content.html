SNMPv3 configuration example
snmp-server view SECUREVIEW iso included
snmp-server group SECUREGROUP v3 auth priv read SECUREVIEW
snmp-server user COHORTIAUSER SECUREGROUP v3 auth sha COHORTIAPASS priv aes 128 COHORTIAENC
This creates a restricted view, groups it with auth and privacy, and creates a user mapped to that group. Adjust the view to include only necessary OIDs.
Operational guidance
  • Use strong authentication (SHA) and AES privacy to prevent sniffing and tampering.
  • Restrict SNMP access with ACLs so only collectors can query the device.
  • Limit views to required metrics to reduce data exposure if credentials are misused.
  • Harden and monitor the collector; if it’s compromised, flow records and alerts may be lost.
Common mistake

Leaving SNMPv2c enabled alongside SNMPv3 creates mixed security and exposure; disable older versions once SNMPv3 works.
