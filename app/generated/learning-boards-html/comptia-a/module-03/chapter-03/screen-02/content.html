Learning Objectives
Learn → Understand → Apply → Master
Bloom: Learn → Understand → Apply → Master
01
Device Hardening

Implement strong credentials, disable unused ports and services, and remove default accounts to reduce attack surface. Verified competency milestone: change defaults and shut down unused interfaces in a lab.

Mnemonic: Locked device outline
02
Secure Management Protocols

Configure SSHv2, prefer key-based auth, and replace SNMPv1/v2c with SNMPv3 for authenticated, encrypted monitoring. Verified competency milestone: configure SSH keys and SNMPv3 user in a router simulator.

Mnemonic: Key + shield
03
NTP & DNSSEC

Ensure authenticated time sources and sign DNS zones to preserve log integrity and prevent DNS hijacking. Verified competency milestone: configure authenticated NTP and explain DNSSEC trust chain basics.

Mnemonic: Clock + lock
04
CoPP & MPP Strategy

Design rate-limiting and management access restrictions so the control and management planes remain available under attack. Verified competency milestone: apply a basic CoPP policy and restrict management interfaces.

Mnemonic: Shielded CPU
