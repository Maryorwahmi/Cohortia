Module 3 › Chapter 3.6 › Kubernetes Control Plane Security
Architecture

Secure the control plane components

Focus on hardening API servers, encrypting etcd, and applying least privilege via RBAC.

API Server
Require authentication, enable RBAC, and limit open endpoint exposure.
etcd
Encrypt data at rest and restrict access to control plane nodes only.
RBAC
Grant only the minimal permissions needed by users and service accounts.
Example
Use OIDC for authentication, limit admin roles, and encrypt etcd to protect secrets even if storage is accessed.
Key Takeaway

The control plane is crown jewels; defend it with authentication, encryption, and least privilege to prevent cluster-wide compromise.
