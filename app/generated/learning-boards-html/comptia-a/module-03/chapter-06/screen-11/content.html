Module 3 › Chapter 3.6 › Container Runtime Hardening
Core Concept

Protect host, daemon, and container capabilities

Focus on kernel safety, daemon access controls, and runtime restrictions.

Host OS
Patch kernels, minimize installed packages, and harden the host using system controls.
Runtime API
Restrict access to the daemon API and use proper logging and storage driver configuration.
Runtime Security
Use seccomp, AppArmor, SELinux, no-new-privileges, and capability drops to minimize container privileges.
Example Flags
Use runtime flags to drop all capabilities and set no-new-privileges, then grant only what the app needs.
Common Mistake
Assuming a single kernel profile fits all containers. Tune seccomp or AppArmor to the application behavior to avoid unnecessary allowances.
Key Takeaway

Layer host, daemon, and per-container controls so a single vulnerability cannot lead to broad compromise.
