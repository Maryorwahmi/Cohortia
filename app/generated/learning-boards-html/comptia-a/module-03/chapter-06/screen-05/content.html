Definition

Type 1 and Type 2 Hypervisors

Understand the trusted computing base and where to focus hardening.

Type 1 — Bare-metal
  • Runs directly on hardware.
  • Smaller attack surface; preferred for production.
  • Secure by isolating management network and minimizing services.
Type 2 — Hosted
  • Runs on top of a host OS like a regular application.
  • More dependencies and higher attack surface due to host services.
  • Suitable for testing and desktop virtualization; avoid for shared production.
Hardening Checklist
- Regularly patch the hypervisor and management tools.
- Isolate management network and apply least privilege to admin accounts.
- Disable unused management services and interfaces.
Common Mistake
Assuming Type 2 is production-ready because it runs the same guests; host OS vulnerabilities can bridge to guests.
Key Takeaway

Know your hypervisor type, minimize its trusted components, and isolate management functions to reduce blast radius.
