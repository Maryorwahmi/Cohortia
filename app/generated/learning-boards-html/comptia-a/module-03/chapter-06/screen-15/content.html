Module 3 › Chapter 3.6 › Key Concepts
Hypervisor
Software that runs VMs; Type 1 favors smaller attack surface for production.
VM Escape
An attacker breaking out of a VM. Reduce risk by removing unnecessary virtual hardware and isolating management networks.
Container Image
A packaged application filesystem; scan, sign, and keep images minimal.
Runtime Hardening
Protect the host kernel, restrict daemon API, apply seccomp/AppArmor/SELinux and drop capabilities.
Kubernetes Security
Protect the API, encrypt etcd, use RBAC, and enforce Pod Security Standards.
Network Policies & Mesh
NetworkPolicy for connectivity rules; service mesh for mutual TLS and observability.
Summary Takeaway

Layer defenses: harden management, secure images and runtimes, and enforce network-level microsegmentation to limit blast radius.
