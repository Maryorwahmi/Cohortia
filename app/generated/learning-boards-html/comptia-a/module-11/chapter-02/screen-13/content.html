Scenario: S3 public bucket + unpatched EC2

Use the shared responsibility model to assign accountability and recommend mitigations for each failing control.

Unpatched EC2 OSCustomerCustomer controls guest OS and applications. Mitigation: automated patching via systems manager and scheduled vulnerability scans.
