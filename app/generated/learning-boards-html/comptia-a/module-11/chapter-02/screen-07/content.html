What the provider manages

In PaaS the CSP handles OS, runtimes, middleware, and the host infrastructure so you don't manage servers directly.

Provider responsibilities
Runtime maintenance, patching of the platform, and infrastructure availability.
Customer responsibilities
  • Application code security and dependency management
  • Database user permissions and sensitive-field encryption
  • Platform configuration such as API keys and environment access
Concrete example

A managed database is patched by the CSP, but the customer must enforce strong passwords, limit users to least privilege, and encrypt sensitive columns to prevent data exposure if credentials are leaked.

Common Mistake

Assuming that platform-level patching removes the need for application-level security controls and key management.

Key Takeaway

PaaS reduces infrastructure chores but requires you to secure code, data access, and platform-specific configurations.
