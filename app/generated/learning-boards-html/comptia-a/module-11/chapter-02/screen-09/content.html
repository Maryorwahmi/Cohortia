Block public S3 access (example)

Use account or bucket-level policies to prevent public ACLs and public policies. This command sets the public access block configuration for a bucket.

aws s3api put-public-access-block \
  --bucket your-sensitive-data-bucket \
  --public-access-block-configuration "BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true"
Replace the bucket name and run with appropriate credentials. Then verify with an inventory tool or the provider console.
Trigger an OS patch run (example)

Use your provider's systems manager to install patches across instances with a single command.

aws ssm send-command \
  --instance-ids "i-0abcdef1234567890" \
  --document-name "AWS-RunPatchBaseline" \
  --comment "Apply OS patches" \
  --parameters 'Operation=Install'
Schedule this in a maintenance window and track results in the systems manager console. Automate reporting for auditors.
Key Takeaway

Prefer repeatable automation over ad-hoc fixes. Automate blocking of dangerous defaults and scheduled patching to reduce human error.
