Customer-owned controls in IaaS

When you use virtual machines and raw storage, you own the OS, apps, network rules and data protections that run on those resources.

OS & Host
Patching, hardening, host-based firewalls and anti-malware are your responsibility for each VM you deploy.
Network
Security groups, NACLs, VPNs, and subnet design control traffic to and from your instances.
Data & IAM
Encryption, key management, data classification, and user/role permissions are customer duties.
Example scenario

An EC2 instance runs a web app with an unpatched OS. An attacker exploits a known kernel vulnerability and gains control. This is a customer responsibility because the guest OS and application are managed by the customer.

Mitigation
Automate patch management with a systems manager, use hardened baseline images, and run scheduled vulnerability scans.
Common Mistake
Assuming the CSP will patch guest operating systems on your behalf.
Key Takeaway

In IaaS you must operate and verify OS/ application patching, network controls, and data protections for resources you provision.
