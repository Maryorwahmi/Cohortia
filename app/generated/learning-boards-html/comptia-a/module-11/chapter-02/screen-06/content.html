Remediation process for misconfigurations

Use a repeatable process to detect and remediate security group and storage permission errors before they become breaches.

1. Inventory
List all public endpoints, security groups with broad rules, and public storage objects.
2. Enforce Defaults
Block public bucket policies at account level and establish minimal open security group templates.
3. Continuous Scan
Run automated checks and remediate findings with scripts or a CSPM tool.
Concrete example

An S3 bucket became public because a policy allowed public reads. The correct owner to fix the policy is the customer: they control bucket policies and ACLs. The provider secures the S3 service, but not your bucket policy.

Common Mistake

Believing that storage lives behind the VPC and inherits network protections — storage access is controlled by resource-level policies and must be reviewed.

Key Takeaway

Treat storage and network access as separate control planes and verify both are correctly configured by the customer.
