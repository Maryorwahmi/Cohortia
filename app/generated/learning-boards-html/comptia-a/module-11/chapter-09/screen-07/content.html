Module 12 › Chapter 11.9 › Snapshot & Immutable
Snapshot workflow
  1. Identify attached volumes and instance metadata.
  2. Create encrypted, tagged EBS snapshots or equivalent.
  3. Copy snapshots to a secure, versioned bucket if policy requires.
  4. Attach snapshots to an isolated forensic workstation for analysis.
Example tag

IncidentId=INC-2023-001, InstanceId=i-0abcdef1234567890, CollectedBy=IRTeam

Immutable recovery
Rather than patching a compromised VM, rebuild from a hardened image with applied patches and configuration management. This reduces the chance of residual backdoors and shortens outage windows.
Common mistake
Modifying a suspected compromised instance before snapshotting. Always snapshot first to preserve evidence.
Pro tip
Automate snapshot creation in your playbook and ensure snapshots are immutable once created via storage versioning and retention policies.
