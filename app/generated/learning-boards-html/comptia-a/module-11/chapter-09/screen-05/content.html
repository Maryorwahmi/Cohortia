Module 12 › Chapter 11.9 › Incident Types
Incident vs Indicator
Compromised credentials
IoCs: unexpected PutBucketPolicy, CreateUser, or unusual console/API activity from new IPs.
Misconfigured storage
IoCs: sudden PutObject activity, ACL changes, or public read/write policy changes.
Serverless or container compromise
IoCs: anomalous function invocations, error spikes, unexpected image pulls or registry pushes.
Supply chain attack
IoCs: new images pushed to registry, CI/CD pipeline changes, or unexpected deployments.
Practical alert mapping
Example rule
Alert when PutBucketPolicy + Data egress spike occurs within 10 minutes of each other.
Common mistake
Relying on a single log source. Effective detection correlates API, flow, and application logs.
Key Takeaway

Tag common IoCs to alerts and automate snapshotting for ephemeral resources to preserve evidence quickly.
