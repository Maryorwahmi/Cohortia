Module 12 › Chapter 11.9 › Log Correlation
Stepwise analysis
  1. Anchor on the alert timestamp and affected resource identifiers.
  2. Query CloudTrail/Audit logs for related EventName and ResourceName entries.
  3. Pull VPC Flow Logs for the same IPs and time windows to see network targets.
  4. Search application logs and registry events for complementary evidence.
Misconception

A single log entry rarely proves an attacker’s intent. Correlation across sources strengthens conclusions.

CLI-assisted queries
Use targeted CLI or console queries with precise time windows. Record the commands you run so the timeline can be reproduced by others.
aws cloudtrail lookup-events --lookup-attributes AttributeKey=ResourceName,AttributeValue=i-0abcdef1234567890 \
  --start-time 2023-01-01T10:00:00Z --end-time 2023-01-01T11:00:00Z --query 'Events[*].CloudTrailEvent'

# Then filter VPC Flow Logs for the same source IP and window to identify external destinations.
Example note
