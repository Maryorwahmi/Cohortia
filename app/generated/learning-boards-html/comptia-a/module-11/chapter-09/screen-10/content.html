Module 12 › Chapter 11.9 › Containment
Containment checklist
  • Capture current configuration and metadata for the affected resource.
  • Create encrypted snapshots of attached volumes.
  • Replace security groups with a quarantine group that blocks traffic.
  • Revoke or rotate credentials associated with the instance or role.
  • Move or stop the resource if required, preserving snapshots for analysis.
Record keeping
Log who performed each action, the timestamps, and artifact IDs so the chain of custody is preserved.
Quarantine example
Create a new security group with no inbound or outbound rules, then replace the instance's security groups. Verify isolation by checking access from a known-good host.
Common mistake
Stopping instance before snapshotting. Always snapshot disks before stop/terminate operations to protect evidence.
