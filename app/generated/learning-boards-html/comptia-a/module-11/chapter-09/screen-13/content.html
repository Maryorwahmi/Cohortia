Module 12 › Chapter 11.9 › CLI Walkthrough
Step overview
  1. Identify instance and attached volumes, record IDs.
  2. Create a quarantine security group and replace instance groups.
  3. Create encrypted snapshots, tag them with IncidentId.
  4. Query audit logs for related API activity and export results.
Recording
Record every command, outputs, snapshot IDs, and the operator who performed each step for later review.
Example commands
# Describe the instance (record the SecurityGroup and Volume IDs)
aws ec2 describe-instances --instance-ids i-0abcdef1234567890 --query 'Reservations[0].Instances[0].{InstanceId:InstanceId,State:State.Name,PublicIpAddress:PublicIpAddress,PrivateIpAddress:PrivateIpAddress,SecurityGroups:SecurityGroups,BlockDeviceMappings:BlockDeviceMappings}'

# Create a quarantine security group (note the VPC ID)
aws ec2 create-security-group --group-name quarantine-sg --description "Quarantine SG for compromised instances" --vpc-id vpc-0example

# Replace instance security groups with the quarantine group
aws ec2 modify-instance-attribute --instance-id i-0abcdef1234567890 --groups sg-0fedcba9876543210

# Create a snapshot of the root volume
aws ec2 create-snapshot --volume-id vol-0123456789abcdef --description "Forensic snapshot of i-0abcdef1234567890" --tag-specifications 'ResourceType=snapshot,Tags=[{Key=IncidentId,Value=INC-2023-001},{Key=InstanceId,Value=i-0abcdef1234567890}]'

# Query CloudTrail for events related to the instance in a time window
aws cloudtrail lookup-events --lookup-attributes AttributeKey=ResourceName,AttributeValue=i-0abcdef1234567890 --start-time 2023-01-01T10:00:00Z --end-time 2023-01-01T11:00:00Z --query 'Events[*].CloudTrailEvent'
