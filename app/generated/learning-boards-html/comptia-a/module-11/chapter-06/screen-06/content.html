Mitigation Pattern Input validation workflow
Validation and safe queries
A layered workflow for reliable protection.
Step-by-step
  1. Reject malformed requests at API Gateway with a schema.
  2. Apply allow-list validation in code for critical fields.
  3. Use parameter binding for database calls.
  4. Log and alert on repeated validation failures.
Example: safe DB call
# Using parameterized query with pymysql
with conn.cursor() as cursor:
    sql = "SELECT * FROM users WHERE username = %s"
    cursor.execute(sql, (user_input,))
    result = cursor.fetchone()
This binding ensures the database treats the user input as data, not SQL. Pair binding with a strict validation rule before the execute call to reduce invalid requests and noisy logs.
Key Takeaway

Validation reduces noise and attack surface; parameterized queries remove SQL semantics from input data.
