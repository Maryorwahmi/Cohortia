Network Consideration VPC & ephemeral compute
VPCs, security groups, and short-lived hosts
Bring classic network controls into serverless design when needed.
Practical guidance
  • Place functions in private subnets when accessing internal databases.
  • Use security groups that only allow required ports and destinations.
  • Prefer service endpoints and VPC endpoints over public IPs.
Monitoring and impact
VPC configuration can affect cold start and connectivity. Emit VPC flow logs and centralize them in your logging stack so you can investigate short-lived network activity.
Key Takeaway

When functions join a VPC, treat them like any other host for networking and logging, but rely on centralized telemetry for forensics.
