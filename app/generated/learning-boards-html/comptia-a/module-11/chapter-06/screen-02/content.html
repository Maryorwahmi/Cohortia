Module 11 › Chapter 11.6 › Learning Objectives
Learning Objectives
Skills and verifiable tasks you will master.
01
Explain serverless shared responsibility
You will describe which layers the provider secures and which layers you must secure, and why that distinction changes incident response planning.
Verified competency milestone
02
Identify serverless threats and vulnerabilities
You will recognize injection, broken auth, and over-permissive roles and explain how event triggers expand the attack surface.
Verified competency milestone
03
Apply least-privilege IAM to functions
You will author IAM policies that limit actions and resources so a compromised function has minimal blast radius.
Verified competency milestone
04
Use secrets manager, validation, and monitoring
You will remove hardcoded credentials, validate inputs, protect APIs with WAF and throttling, and configure logs for SIEM ingestion.
Verified competency milestone
