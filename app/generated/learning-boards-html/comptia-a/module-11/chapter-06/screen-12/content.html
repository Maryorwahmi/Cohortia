Deploy an insecure Lambda
Follow the scripted steps to create and test the insecure function.
Starter code (insecure_lambda.py)
import os
import json

# Insecure: Hardcoded secret (for demonstration ONLY)
HARDCODED_SECRET = "my-super-secret-api-key-123"

def lambda_handler(event, context):
    print(f"Received event: {json.dumps(event)}")
    print(f"Using hardcoded secret: {HARDCODED_SECRET}")

    if 'queryStringParameters' in event and 'action' in event['queryStringParameters']:
        action = event['queryStringParameters']['action']
        if action == 'reveal':
            return {
                'statusCode': 200,
                'body': json.dumps({'message': 'Secret revealed!', 'secret': HARDCODED_SECRET})
            }

    return {
        'statusCode': 200,
        'body': json.dumps({'message': 'Hello from insecure Lambda!'})
    }
Deployment checklist
  • Create InsecureLambdaRole with AdministratorAccess (demo only).
  • Zip and deploy the function, then invoke with action=reveal.
  • Inspect CloudWatch logs and the response to confirm secret exposure.
Warning

This insecure setup is for learning only. Do not use broad permissions in production.
