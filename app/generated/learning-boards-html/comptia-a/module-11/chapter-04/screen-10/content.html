Core Concept

Serverless Code Security

Treat functions like any other production code: scan, validate, minimize dependencies, and secure secrets at runtime.

Actionable checklist
  • Run SAST and dependency vulnerability scans in CI.
  • Validate and sanitize all inputs; never trust gateway validation alone.
  • Retrieve secrets from a vault using managed identity at runtime.
Key Takeaway

Combine static scanning, dependency management, runtime validation, and secure secret retrieval to reduce risk in serverless code.

Concrete example
def lambda_handler(event, context):
    # Validate input schema and fields before use
    item_id = event.get('itemId')
    if not valid_item_id(item_id):
        raise ValueError('Invalid itemId')
    # Retrieve secret at runtime via managed identity / secrets manager
    # Process safely and return
Note: Validate types and patterns, then retrieve secrets at runtime using environment secret names, not secret values.
Dependency note

Keep third-party libraries minimal and update them regularly. Use dependency scanning to detect known CVEs before packaging the function.
