Architecture

Function network placement

Place sensitive functions inside private networks, control outbound traffic, and route through security appliances when necessary.

Design considerations
  • Use VNet/VPC integration for functions that access private DBs.
  • Apply NSGs and egress control to restrict outbound destinations.
  • Balance cold-start impact with security needs and test performance.
Key Takeaway

Network isolation is a key control for functions that touch sensitive data, and it complements role and secret protections.

Concrete scenario

An Azure Function that queries an Azure SQL DB is integrated with a VNet and uses a subnet that routes egress through a firewall appliance. The function's managed identity has only database read permissions. Network controls and role limitations together prevent direct public access and restrict what the function can call externally.

Monitoring

Forward VNet flow logs and function invocation logs to your central monitoring stack. Look for unexpected outbound IPs or unusual volumes of connections from a function.
