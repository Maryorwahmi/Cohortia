Module 11 › Chapter 11.4 › Managed Databases
Definition

Managed Databases

Platform-managed engines that include patching, backups, and availability. Customers configure access, encryption, and network placement.

Best practices
  • Enable encryption at rest and enforce TLS for clients.
  • Place DBs in private subnets and restrict inbound sources to application servers.
  • Use secrets managers for credentials and enable auditing to central logs.
Key Takeaway

Managed services ease operations but do not remove your duty to isolate, control, and audit database access.

Example: AWS RDS security group ingress
# Allow inbound traffic on MySQL port from the AppServerSG
aws ec2 authorize-security-group-ingress \
    --group-id sg-0abcdef1234567890 # RDS Security Group ID \
    --protocol tcp \
    --port 3306 \
    --source-group sg-0fedcba987654321 # AppServerSG ID
Note: Prefer source-group scoping to avoid open CIDR ranges. Verify the security group IDs and region before applying.
Misconfiguration to avoid

Do not attach public IPs or allow 0.0.0.0/0 on database ports. Even if the provider encrypts data at rest, public network exposure remains a primary risk.
