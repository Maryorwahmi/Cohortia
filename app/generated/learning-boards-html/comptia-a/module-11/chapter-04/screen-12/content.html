Process Flow

From logs to alerts

Collect logs from gateways, functions, managed DBs, and network flows. Correlate events and trigger alerts for suspicious activity.

Checklist
  • Enable platform audit logs and forward to a central store.
  • Create alerts for abnormal invocation patterns and access to secrets or management APIs.
  • Maintain retention and ensure logs meet RPO/RTO and compliance requirements.
Key Takeaway

Logging without alerting is insufficient; define thresholds and runbooks so detections lead to rapid response.

Concrete practice

Forward application logs, function traces, and managed DB audit logs to a SIEM or monitoring stack. Create a dashboard that shows API Gateway denials, function error rates, and DB auth failures together for rapid triage.

Misconception

Assuming log retention is indefinite. Set retention to support investigations and compliance but avoid over-retention of sensitive logs without protection.
