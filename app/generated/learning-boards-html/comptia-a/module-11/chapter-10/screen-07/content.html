CWPP Overview

CWPP secures the runtime and images of compute workloads across cloud and hybrid environments, focusing on behavior and vulnerabilities.

Vulnerability Management
Scan images and running workloads for known vulnerabilities and feed fixes into pipelines.
Runtime Detection
Monitor process behavior, file integrity, and network anomalies and generate alerts or take action.
Enforcement
Application whitelisting and micro‑segmentation limit what can run and who can communicate with whom.

Concrete Scenario

A container is running in production. The CWPP flags a sudden child process spawning a shell inside the container and a connection to a suspicious external IP. Based on configured response, the platform quarantines the pod and forwards telemetry to the SIEM for triage.
Deployment Pitfall
Deploying agents without testing can cause performance regressions. Pilot and tune policies before broad rollout.
Key Takeaway

CWPP complements CSPM by defending workload behavior and integrity at runtime.
