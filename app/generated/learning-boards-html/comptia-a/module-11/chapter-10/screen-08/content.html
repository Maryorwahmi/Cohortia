Process Flow › Vulnerability Management

Pre-Deployment Scanning

Integrate scans into CI/CD so images with known high severity CVEs fail promotion and require fixes before deployment.

Runtime Scanning

Continuously assess running workloads for vulnerable packages and correlate these with exploit intelligence.

Concrete Example

A build pipeline scans an image and detects a critical vulnerability in an OS package. The pipeline blocks deployment, an issue is filed for the developer to update the base image, and the new build is rescanned before deployment.
Misconception
Scanning finds issues but does not fix them. Integrate scanning with patching and image hardening processes to close the loop.
Key Takeaway

Combine pre-deployment and runtime scanning and integrate results into your vulnerability management workflow for timely remediation.
