Architecture › Integration Strategy

High-Level Steps

  1. Connect CSPM to all cloud accounts with read-only API access and enable baseline scans.
  2. Tag assets and define criticality for accurate prioritization.
  3. Deploy CWPP agents/sidecars to critical VMs and Kubernetes clusters, and enable function monitoring for serverless.
  4. Forward both CSPM and CWPP alerts to your SIEM and create correlated rules that combine configuration and runtime signals.

Integration Example

If CSPM flags a public bucket and CWPP reports abnormal process activity from a host that accessed that bucket, the SIEM rule raises a higher-severity incident and triggers the IR playbook to isolate the host and revoke access to the bucket until investigation completes.
Operational Tip
Pilot integrations in a controlled environment and define clear notification thresholds so automation does not overwhelm responders.
Key Takeaway

Integrate CSPM and CWPP telemetry into SIEM and IR workflows to turn detection into coordinated response across configuration and runtime layers.
