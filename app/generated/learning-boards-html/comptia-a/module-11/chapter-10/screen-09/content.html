Process Flow › Runtime Protection

Detection Techniques

  • System call monitoring to catch abnormal process actions.
  • File integrity checks to detect unexpected binaries or tampering.
  • Network anomaly detection for unusual outbound connections.
  • Memory protection and HIPS to block exploit behavior.

Concrete Example

A containerized web app starts a child process that spawns a shell and initiates a connection to an external IP. The CWPP detects the system call pattern and network anomaly, quarantines the pod, and forwards detailed telemetry to the SOC for investigation.
Tuning Note
Tune baselines so legitimate background operations do not create repeated false positives that desensitize responders.
Key Takeaway

Runtime protection detects and can contain malicious behavior that configuration checks cannot prevent.
