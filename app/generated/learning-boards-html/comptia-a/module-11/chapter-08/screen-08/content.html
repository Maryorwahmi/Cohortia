Module 11 › Chapter 11.8 › Automated Remediation
Architecture
A typical flow: CSPM detection → Central aggregator (Security Hub) → Orchestrator (Lambda or Systems Manager) → Remediation action. Ensure remediation is idempotent and include extensive logging.
Example
AWS Config Rule detects a public S3 bucket, sends a finding to Security Hub, which triggers a Lambda that enables Block Public Access settings.
Warning
Start in audit mode and test remediations in staging to avoid unintended outages.
Remediation Stages
  1. Monitor-only: collect baseline and noise.
  2. Alert with playbook: prepare scripts and approvals.
  3. Manual approval: run remediation with human oversight.
  4. Automate safe fixes: only for low-risk, tested actions.
Key Takeaway

Automated remediation reduces mean time to remediate but must be staged, logged, and reversible to be safe.
