Module 11 › Chapter 11.8 › What is CSPM?
Definition

CSPM discovers cloud resources, evaluates configuration against baselines, and reports compliance and security issues continuously.

Why it matters
  • Prevents misconfigurations from reaching production.
  • Maintains audit evidence for compliance frameworks.
  • Helps prioritize fixes by impact and exploitability.
Common misconception

CSPM is not a replacement for runtime detection; it focuses on configuration hygiene and compliance, complementing other security layers.

Concrete example
A developer pushes a configuration that sets an object store bucket to public-read. CSPM flags the bucket as non-compliant with CIS benchmarks, raises an alert, and records evidence for auditors. That detection prevents data leakage when remediated.
Analogy
CSPM is like a continuous health check for cloud settings — it alerts when a vital sign is abnormal.
Key Takeaway
Use CSPM to detect and measure configuration risk, then design safe remediation plans.
Key Takeaway

CSPM is the continuous hygiene tool that finds configuration risk and provides the evidence and automation hooks to fix it.
