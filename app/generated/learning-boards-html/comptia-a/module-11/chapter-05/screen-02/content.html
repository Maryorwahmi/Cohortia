Learning Objectives
Four measurable skills you'll practice and verify.
01
Design federated IAM and SSO
Create a federated flow mapping AD identities to cloud roles so users sign in once and access multiple services. Verified Competency Milestone
Mnemonic: single key opens many doors (Venn)
02
Apply least privilege
Author policies with action and resource specificity and tag‑based conditions to reduce blast radius. Verified Competency Milestone
Mnemonic: scissors not shotgun (timeline)
03
Enforce MFA for privileged accounts
Configure and require MFA devices or FIDO keys for admin roles to harden access against credential theft. Verified Competency Milestone
Mnemonic: two factors for two locks (icons)
04
Secure programmatic access
Use managed identities and short‑lived credentials, rotate API keys, and store secrets in a vault. Verified Competency Milestone
Mnemonic: temporary passes, not permanent keys (Venn)
