Module 11 › Chapter 11.5 › SAML vs OIDC
SAML
XML assertions, browser‑centric, widely supported by enterprise SaaS for single sign‑on.
When to use
Legacy enterprise web apps and where robust attribute assertions are required.
Misconception
SAML isn't obsolete; it remains common in enterprise SSO even when OIDC is available.
OpenID Connect (OIDC)
JSON and RESTful, built on OAuth 2.0, ideal for APIs, SPAs, and mobile clients needing tokens.
When to use
New web, mobile, and API-first services that consume access and identity tokens.
Misconception
OIDC is not only for public apps; it also simplifies token flows for modern internal services.
Example
CRM via SAML SSO; mobile app via OIDC access tokens.
Check
Confirm your IdP supports both and map apps accordingly.
Takeaway
Match protocol to app needs: browser SSO or token-based API access.
