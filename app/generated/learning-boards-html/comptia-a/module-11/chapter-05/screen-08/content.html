Fine‑grained S3 policy with MFA
This policy grants read-only access to a single bucket and requires MFA for the actions.
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:GetObject",
        "s3:ListBucket"
      ],
      "Resource": [
        "arn:aws:s3:::my-secure-bucket",
        "arn:aws:s3:::my-secure-bucket/*"
      ],
      "Condition": {
        "Bool": {
          "aws:MultiFactorAuthPresent": "true"
        }
      }
    }
  ]
}
Walkthrough
Action list restricts allowed operations; Resource limits the exact bucket and objects; Condition enforces MFA for any permitted action.
Test idea
Attach to a role, assume the role without MFA and confirm access is denied, then with MFA confirm allowed behavior.
Pitfall
Do not leave Resource as "*" or remove condition keys for convenience; those weaken the policy severely.
