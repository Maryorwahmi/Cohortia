Roles and Managed Identities
Assign temporary credentials to compute resources so they authenticate securely to other services without embedded secrets.
Benefits
  • No hardcoded keys in code repositories.
  • Automatic credential rotation by the provider.
  • Fine-grained permissions attached to the identity.
Example
Attach an IAM role to an EC2 instance that grants s3:GetObject for a specific bucket; the instance requests temporary credentials when needed.
Design check
Limit the role's permissions to required APIs and monitor role assumption logs to detect misuse.
