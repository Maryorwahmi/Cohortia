API Keys: rotation and storage
When keys are necessary, treat them as high-value secrets: vault them, rotate them, and monitor their usage.
Minimize
Avoid root account keys; create dedicated users with scoped permissions for programmatic access.
Rotate
Automate rotation and remove old keys as part of your deployment pipeline.
Store
Use a secrets manager to store keys and grant access via tightly scoped IAM roles.
Common mistake

Hardcoding keys in repositories or leaving old keys active leads to long-lived exposure; remove and revoke keys as part of rotation.
