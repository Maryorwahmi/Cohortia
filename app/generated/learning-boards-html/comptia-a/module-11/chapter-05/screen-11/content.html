Module 11 › Chapter 11.5 › Programmatic Access
Roles and Managed Identities for Applications
Use provider-managed credentials so apps never store static secrets.
Example
An EC2 instance with an attached role can call S3 without an access key; the SDK fetches temporary credentials automatically.
Audit
Log role assumption and token requests. Correlate those logs with API calls to detect suspicious patterns.
Developer tip
Most SDKs automatically use instance or managed identity endpoints—no code changes needed beyond removing hardcoded keys.
Check
Ensure metadata endpoints are network-restricted where supported and that role permissions are narrowly scoped.
