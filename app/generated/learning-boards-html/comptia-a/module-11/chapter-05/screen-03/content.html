Audit and Monitoring Objectives
Practical checks you will perform to validate IAM posture.
Enable and review audit logs
Turn on CloudTrail or equivalent, search for policy changes and failed logins, and export logs for long‑term retention.
Use access analysis tools
Run native tools to find resources with open access or roles that trust external principals.
Periodic permission reviews
Schedule reviews of roles, unused keys, and group memberships to remove stale access.
Alerting for critical IAM events
Create alerts for root usage, policy changes, and credential creation so you can triage quickly.
