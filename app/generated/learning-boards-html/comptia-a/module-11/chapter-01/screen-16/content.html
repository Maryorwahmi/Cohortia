Module 11 › Chapter 11.1 › Key Concepts
IaaS
VMs and networks where customers manage OS, apps, and network configuration.
PaaS
Managed runtime; you secure application code and platform configurations.
SaaS
Vendor-managed applications; your focus is identity, roles, and data governance.
Final Takeaway
Always document the shared responsibility boundaries and automate enforcement to maintain a secure and auditable cloud posture.
