Module 11 › Chapter 11.1 › IaaS
Definition

IaaS — the building block layer and customer responsibilities

Virtual machines, storage, and network resources where the customer manages the guest OS, applications, and configuration.
Customer responsibilities
  • OS hardening, patching, and host security controls.
  • Application and data security, backup, and encryption.
  • Network ACLs, security groups, and access controls.
Concrete Example
Self-managed VM database: you apply OS patches, enable encryption at rest, and configure backup rotation.
Common Mistake
Assuming provider patches guest OS; neglecting patching leads to exposed CVEs and host compromises.
Operational best practices
- Use hardened images and immutable infrastructure to reduce drift.
- Automate patching and configuration with IaC and orchestration tools.
- Apply host-based logging and centralize telemetry for threat detection.
Key Takeaway
IaaS provides flexibility and control but puts OS and host security squarely on your team; automation is essential.
