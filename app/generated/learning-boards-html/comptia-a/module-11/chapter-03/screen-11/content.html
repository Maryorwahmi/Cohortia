Module 11 › Chapter 11.3 › Routing & NAT
Components
  • Internet Gateway: public subnet internet access.
  • NAT Gateway/Instance: allows private instances to initiate outbound traffic.
  • Route Tables: send private subnet outbound traffic to NAT.
Operational Notes

Deploy NAT gateways per availability zone for redundancy. Verify routing with connectivity tests and monitor NAT usage for cost and throughput planning.

Assessment Example

Question: Which component lets a private instance fetch updates but prevents inbound connections? Answer: NAT Gateway. This aligns with the requirement to preserve private subnet isolation while enabling necessary outbound access.

Key Takeaway

Use NAT plus route tables to provide outbound-only internet access for private instances and avoid assigning public IPs.
