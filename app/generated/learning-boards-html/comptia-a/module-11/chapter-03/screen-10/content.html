Module 11 › Chapter 11.3 › Security Groups vs NACLs
Security Groups

Stateful, instance-level rules. Best for least-privilege controls and limiting ports to trusted sources.

  • Remember connection state, so return traffic is implicit.
  • Attach per-tier security groups for web, app, and DB tiers.
Network ACLs (NACLs)

Stateless, subnet-level filters. Use for coarse rules and an additional layer of protection.

  • Explicit inbound and outbound rules required for each direction.
  • Good for blocking ranges or enforcing broad policies across subnets.
Key Takeaway

Combine NACLs and security groups: coarse subnet filters plus fine-grained, stateful instance rules yield layered defense.
