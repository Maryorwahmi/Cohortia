Micro-Segmentation Pattern
Define security groups by function, not by host. Example: WebSG allows HTTP/HTTPS from internet and SSH only from admin CIDR. AppSG allows traffic only from WebSG to app ports. DBSG allows only AppSG on DB port.
WebSG
Allow 80/443 from 0.0.0.0/0; SSH from admin CIDR.
AppSG
Allow HTTP from WebSG only; DB traffic to DBSG.
DBSG
Allow DB port only from AppSG; no inbound internet access.
Detection
  • Enable VPC Flow Logs to monitor internal traffic.
  • Use host agents to detect unexpected lateral attempts.
  • Review group rule changes regularly for drift.
Key Takeaway

Micro-segmentation constrains attacker movement by enforcing small, well-documented allowlists between services.
