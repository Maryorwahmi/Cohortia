Three-Tier Subnet Layout
Suggested example: VPC 10.0.0.0/16, Public Subnet 10.0.1.0/24, Private App 10.0.2.0/24, Private DB 10.0.3.0/24. Replicate across AZs for HA.
Segmentation Rules
  • Public subnets: Internet-facing load balancers or bastion points.
  • Private app subnets: No inbound internet access; communicate with web tier.
  • DB subnets: Highly restricted, only accept traffic from app security group.
Operational Guidance
  • Use VPC Flow Logs and network ACLs for additional monitoring and coarse-grained control.
  • Test routing and NAT behavior in staging before production changes.
  • Apply micro-segmentation via security groups to limit east-west traffic.
Key Takeaway

Plan your CIDR ranges and subnets for isolation and growth, and use layered controls to detect and contain lateral movement.
