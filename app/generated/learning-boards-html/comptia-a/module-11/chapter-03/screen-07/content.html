Encryption at Rest

Enable default encryption for object stores, encrypt block volumes before use, and require managed keys so you can audit usage.

Example: S3 Policy to require TLS
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "PublicReadGetObject",
            "Effect": "Deny",
            "Principal": "*",
            "Action": "s3:GetObject",
            "Resource": "arn:aws:s3:::your-sensitive-bucket/*",
            "Condition": {"Bool": { "aws:SecureTransport": "false" }}
        }
    ]
}
Encryption in Transit

Enforce TLS for all data movement, and use VPNs or private connections for hybrid links. Reject non-TLS traffic with policy and monitoring.

Pitfall

Assuming encryption replaces access controls. Keys and policies must limit who can decrypt and access the data.

Key Takeaway

Require encryption at rest and in transit and manage keys with least-privilege access to ensure true confidentiality.
