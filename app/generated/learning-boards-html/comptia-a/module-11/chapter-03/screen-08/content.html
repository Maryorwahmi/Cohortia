Quick Comparison
Object Storage (S3/Blob)
API access, ideal for uploads and backups. Secure with bucket policies, default encryption, versioning.
Block Storage (EBS/Disks)
Attached volumes behave like disks. Encrypt volumes and manage snapshots carefully.
File Storage (EFS/Files)
Shared filesystem access. Protect via network isolation and filesystem permissions.
Concrete Scenario

A web app stores user uploads in object storage. Configure the bucket to block public access, enable default encryption with a KMS key, enable versioning to protect against accidental deletion, and apply an IAM policy that restricts writes and reads to the application role.

Common Mistake

Treating object storage like a private file share and granting broad read permissions by default—this often leads to accidental public exposure.

Key Takeaway

Apply storage-specific protections and avoid assuming one storage type's controls cover another's risks.
