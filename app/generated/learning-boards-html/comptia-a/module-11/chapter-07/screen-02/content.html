Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Harden control plane & nodes
Identify attack paths against API server, etcd, and the Kubelet, and apply encryption and network restrictions to reduce exposure.
VERIFIED COMPETENCY MILESTONE
02
Implement RBAC least privilege
Write Roles and RoleBindings for service accounts so workloads only get the API permissions they need to function.
VERIFIED COMPETENCY MILESTONE
03
Design Network Policies
Control ingress and egress between pods to enforce micro-perimeters and limit lateral movement if a pod is compromised.
VERIFIED COMPETENCY MILESTONE
04
Enforce PSS, secrets, and images
Use Pod Security Standards, external secrets, and image scanning/signing to protect runtime secrets and supply chain integrity.
VERIFIED COMPETENCY MILESTONE
