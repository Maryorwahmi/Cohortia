Logging, monitoring, and runtime detection
Centralize telemetry and add runtime detectors for quick action.
Eyebrow: Process Flow
Telemetry stack
Collect audit logs from the API server, node logs from kubelets, and application logs. Forward them to a centralized store and configure retention and access controls. Use Prometheus for metrics and Falco for runtime rules that detect suspicious syscalls like unexpected privilege escalation.
Alerting for spikes in pod creation
Detect service account usage across namespaces
Audit log retention and search
Automate playbook runbooks for response
Example alert
Create an alert for any API calls that grant cluster-admin or for unexpected secret reads from non-privileged accounts. Pair alerts with runbook steps to isolate the pod, revoke tokens, and rotate credentials.
Misconception
Monitoring alone is not defense—it's detection. Combine it with automated or manual remediation steps to reduce dwell time.
