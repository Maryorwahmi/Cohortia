Hands-on outcomes
Steps you will complete and verify in the live coding demo:
  • Deploy two-tier app and observe default connectivity.
  • Apply Network Policy to restrict backend ingress to frontend only and validate with curl failures.
  • Create ServiceAccount, Role, and RoleBinding; test API access from pod token.
  • Enforce Pod Security Standards by applying a securityContext and observing admission behavior.
