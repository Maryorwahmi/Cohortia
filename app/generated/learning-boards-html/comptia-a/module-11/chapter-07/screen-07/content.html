Network Policies: default behavior vs. enforced isolation
Make pod connectivity explicit to limit lateral movement.
Eyebrow: Comparison
YAML example
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: allow-frontend-to-backend
  namespace: my-app-namespace
spec:
  podSelector:
    matchLabels:
      app: backend
  policyTypes:
    - Ingress
  ingress:
    - from:
        - podSelector:
            matchLabels:
              app: frontend
      ports:
        - protocol: TCP
          port: 8080
Before and after
  • Before: Pods communicate freely; frontend curl to backend succeeds from any pod.
  • After: Only pods with label app: frontend can open TCP 8080 to backend pods; other sources are denied.
  • Important: NetworkPolicy requires a CNI that supports it; otherwise rules have no effect.
