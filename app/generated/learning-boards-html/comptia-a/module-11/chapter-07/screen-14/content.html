Common mistakes and hardening checklist
A prioritized list of actions to reduce cluster risk.
Eyebrow: Definition
Network & control plane
  • Restrict API server access by network ACLs
  • Enable etcd encryption at rest
  • Require TLS and cert rotation
Workloads & identities
  • Create ServiceAccounts per workload
  • Grant least-privilege Roles; avoid cluster-admin
  • Enforce Pod Security Standards
Supply chain & secrets
  • Scan and sign images in CI
  • Use external secret managers and CSI injection
  • Centralize logs and enable runtime detection
