Module 11 › Chapter 11.7 › What to Remember
Protect endpoints
Lock down API server and etcd with network rules and encryption.
Least privilege
Use Roles and RoleBindings for ServiceAccounts; avoid cluster-admin scope.
Runtime hygiene
Enforce PSS, use external secrets, scan and sign images, and centralize logs.
Final thought

Iterate with small, testable controls: apply one NetworkPolicy, one Role, and one secret improvement, then verify denied behaviors to confirm security.
