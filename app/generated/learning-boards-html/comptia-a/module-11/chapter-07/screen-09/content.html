Secrets management: Kubernetes Secrets vs external managers
Why base64 is not encryption and how to inject secrets safely.
Eyebrow: Definition
Key points
  • Base64 only: Secrets retrieved from the API can be decoded easily if access is allowed.
  • Encrypt etcd: Enable encryption at rest for secret data to protect stored values.
  • Use external stores: Integrate Vault or cloud key stores and inject secrets via CSI drivers or operators.
Example pattern
Use a secrets operator or CSI driver to fetch secrets from Vault at pod startup rather than storing long-lived plaintext in etcd. Pair this with RBAC that prevents broad API read access.
Misconception
Assuming kubectl hides secrets is security. In reality, access controls and encryption are needed to stop decoding by attackers.
