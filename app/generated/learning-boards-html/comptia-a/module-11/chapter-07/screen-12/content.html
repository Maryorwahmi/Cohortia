Hands-on lab: deploy app, apply NetworkPolicy, and observe failures
A runnable workflow you can repeat in Minikube, kind, or a managed cluster.
Eyebrow: Process Flow
Starter manifests
# namespace
kubectl create namespace my-secure-app

# backend-deployment.yaml (excerpt)
apiVersion: apps/v1
kind: Deployment
metadata:
  name: backend-app
  namespace: my-secure-app
  labels:
    app: backend
spec:
  replicas: 1
  template:
    metadata:
      labels:
        app: backend
    spec:
      serviceAccountName: backend-sa
      containers:
      - name: backend-container
        image: nginx:latest
        ports:
        - containerPort: 80
Expected test
Before NetworkPolicy: frontend logs show responses from backend. After NetworkPolicy: curl commands from non-allowed pods fail to connect, proving the policy blocks traffic.
Key takeaway
Use reproducible manifests and log checks to verify that security policies have the intended effect.
