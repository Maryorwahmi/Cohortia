Module 9 › Chapter 9.2 › Credential Management
Patterns for secrets
  • Store secrets in a managed vault, not in source control.
  • Use slow, salted hashing for passwords (bcrypt, Argon2).
  • Automate rotation and limit access through least privilege.
  • Redact secrets from logs and error messages.
Example
Retrieve database credentials from a secrets manager at runtime and inject them into connection settings without storing them in the repository.
Common mistake
Using fast hashes or storing raw passwords. Fast hashes make brute-force attacks cheap.
Key Takeaway

Protect secrets with vaults and hash passwords using slow, salted algorithms provided by trusted libraries.
