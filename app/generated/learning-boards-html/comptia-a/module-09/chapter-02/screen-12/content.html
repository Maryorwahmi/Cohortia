Session and authorization checklist
Session IDs
Use long, cryptographically random values and regenerate after authentication or privilege change.
Cookie flags
Set Secure and HttpOnly on session cookies, and SameSite where appropriate.
Authorization
Enforce server-side checks per resource; do not rely on UI or hidden form fields for access control.
Least privilege
Grant minimal permissions to users and services and review permissions regularly.
Key Takeaway

Treat session tokens as sensitive secrets and validate authorization on each operation to prevent misuse.
