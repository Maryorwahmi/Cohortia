Insecure template render
<!-- Insecure if user_comment contains script -->
<div>User Comment: {{ user_comment }}</div>
If user_comment contains <script> tags the browser may execute them.
Secure template render
<div>User Comment: {{ user_comment | escape }}</div>
Escaping converts special characters to entities so the browser displays them as text.
Key Takeaway

Encode at render time using the context-appropriate escaping; configure template engines to auto-escape and avoid turning it off loosely.
