Module 9 › Chapter 9.2 › Flask Lab
Starter problem areas
  • Registration/login used string interpolation for INSERT/SELECT statements.
  • Comments were rendered without explicit escaping in the template.
  • App secret was hardcoded in the sample.
Your tasks: replace insecure db.execute calls with parameterized statements, and update templates to escape comment text. Add a couple of tests to ensure exploit strings no longer affect behavior.
Secure replacements (examples)
# Registration example (secure)
password_hash = hashlib.sha256(password.encode()).hexdigest()
query = "INSERT INTO users (username, password_hash) VALUES (?, ?)"
db.execute(query, (username, password_hash))
db.commit()

# Template example (Jinja2 explicit escape)
<div>User Comment: {{ comment.comment_text | escape }}</div>
Key Takeaway

Implement parameterized queries and output encoding, then validate fixes with tests that attempt prior exploits.
