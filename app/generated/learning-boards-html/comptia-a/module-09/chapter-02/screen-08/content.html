Direct DB API (SQLite)
# Use placeholders and pass parameters separately
query = "INSERT INTO users (username, password_hash) VALUES (?, ?)"
db.execute(query, (username, password_hash))
db.commit()
This ensures values are bound as data regardless of content.
ORM pattern
Use ORM query builders and parameterized filters instead of raw SQL strings. Validate any identifiers before use.
# Pseudocode style ORM usage
user = User(username=form.username.data)
user.set_password(form.password.data)  # uses safe hash
session.add(user)
session.commit()
Test tip
Add integration tests that submit injection strings and assert the database operations do not change query semantics.
