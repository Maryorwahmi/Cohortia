Module 9 › Chapter 9.2 › SQL Injection
Vulnerable example (unsafe concatenation)
username = request.form['username']
password = request.form['password']
query = f"SELECT * FROM users WHERE username = '{username}' AND password = '{password}'"
cursor.execute(query)
If username contains admin' OR '1'='1 the WHERE clause will evaluate true and authentication is bypassed.
Secure example (parameterized)
username = request.form['username']
password = request.form['password']
query = "SELECT * FROM users WHERE username = %s AND password = %s"
cursor.execute(query, (username, password))
The driver treats the inputs as data only. Quotes or SQL keywords inside username do not change query logic.
Common mistake

Attempting manual escaping is fragile. Use the DB API's parameterization instead.
