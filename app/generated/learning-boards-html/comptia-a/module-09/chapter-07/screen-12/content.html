Module 9 › Chapter 9.7 › DFD Threat Modeling

Step 1 — Draw DFD

Components: User client → Web server → Database & File storage. Mark flows for upload and retrieval.
Trust boundaries
User ↔ Web server and Web server ↔ Storage. Design controls at these boundaries.

Step 2 — Apply STRIDE

Spoofing: Ensure TLS and token-based auth to prevent impersonation.
Tampering: Server-side validation and metadata stripping before storing files.
Information disclosure: Strip EXIF and enforce access controls on storage.
Denial of Service: Enforce size limits, quotas, and rate limits at gateway.
Repudiation: Maintain secure logging with timestamps and user IDs.
Elevation of Privilege: Enforce least privilege for service accounts.
Key Takeaway
Translate each STRIDE finding into a mitigation and prioritize by impact for gates and implementation.
