Module 9 › Chapter 9.7 › Testing

SAST

Source code analysis integrated into CI to find coding patterns linked to vulnerabilities.
Strengths: early detection; Weaknesses: false positives, limited runtime context.

DAST & Pen Tests

DAST tests a running app for runtime vulnerabilities. Penetration testing applies human creativity to find logic and chained issues.
Workflow
SAST in CI, DAST against test environment, pen tests for high‑risk releases.
Key Takeaway
Combine automated and human testing to cover code patterns, runtime behavior, and business logic.
