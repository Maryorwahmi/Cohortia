Module 9 › Chapter 9.7 › Design

Architectural focus

Move from requirements to selected controls that enforce those requirements across components.
API Gateway: central auth, rate limiting, and routing
Token design: scopes, expiration, and refresh policies
Data segregation: separate storage and least privilege access

Risk analysis

Review DFDs and network diagrams to find trust boundaries and points for defense-in-depth.
Misconception
Hiding endpoints is not a substitute for authentication and authorization.
Analogy
Defense in depth is like locks on multiple doors: each layer reduces the chance of successful compromise.
Key Takeaway
Design choices make some classes of attacks far less likely and should be documented and tested later.
