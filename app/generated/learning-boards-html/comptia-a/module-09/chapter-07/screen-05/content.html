Process Flow

Security work by phase

  1. Requirements: Security requirements, data classification, abuse cases, initial threat model.
  2. Design: Architectural risk analysis, DFDs, control selection like MFA and API gateways.
  3. Implementation: Secure coding, SAST, peer reviews, input validation.
  4. Testing/Deployment: DAST, pen tests, security gates, go/no‑go checks.
  5. Operations: Monitoring, incident response, audits, patching.
Linking decisions across these steps avoids rework and ensures security choices are supported by earlier analysis.
