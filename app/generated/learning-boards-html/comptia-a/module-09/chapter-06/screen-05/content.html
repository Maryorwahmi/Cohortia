Module 9 › Chapter 9.6 › Content inspection
Detection techniques
Regular expressions
Structured patterns for SSNs, credit cards, IBANs. Fast and deterministic but can miss context.
Keywords & templates
Detect labels, document templates, or project names that indicate sensitivity.
Document fingerprinting
Exact-match detection for known sensitive files or exports.
Machine learning
Probabilistic classification for unstructured or nuanced content. Useful but needs training and validation.
Policy enforcement
Enforcement chooses an action based on detection plus context: classification, user, destination, and channel.
Actions
Alert, log, quarantine, block, or encrypt. Start with monitoring and escalate to blocking once tuned.
Context-aware rules
Consider user role, destination domain, number of matches, and application before enforcing a disruptive action.
Common mistake
Rigid global rules often create many false positives; tune by department and data type instead.
Key Takeaway

Use layered detection, context-aware policies, and phased enforcement to balance security and productivity.
