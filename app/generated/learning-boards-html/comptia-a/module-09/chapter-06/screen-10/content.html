Comparison: Broad vs. Granular
Which creates more signal for investigations?
Broad Rule
Easy to write but many false positives; impacts productivity.
Granular Rule
More accurate detection; more maintenance and tuning required.
Practical tuning checklist
  • Map high-risk documents to specific fingerprints.
  • Combine pattern matching with destination and role checks.
  • Start in monitor mode and measure false positive rate.
  • Provide approved exception workflows for legitimate business use.
Metric-driven tuning
Key measurements to track
False positives
Target low single digits
False negatives
Investigate escapes
Override rate
High overrides = policy problem
Example scenario
A legal team shares redacted contracts internally but uses same templates externally. Use document fingerprinting plus destination checks to allow internal sharing while blocking external uploads of unredacted versions.
Key Takeaway

Granularity reduces noise. Combine detection methods with context to protect data without crippling legitimate workflows.
