What is RASP?

Runtime Application Self-Protection

Embedded runtime protection that detects and blocks attacks based on in-process visibility and behavior analysis.

Typical actions
  • Block malicious requests in real time.
  • Generate high-fidelity alerts with context for faster investigation.
  • Mitigate zero-day attacks before code fixes are available.
Operational considerations
  • Configure thresholds to reduce false positives that block legitimate users.
  • Integrate alerts with incident response and ticketing to ensure remediation.
  • Consider performance impact and deployment scope—agent in production requires careful testing.
Key takeaway
Key Takeaway

RASP is a runtime mitigator that provides immediate protection, but pair it with testing and fixes to remove root causes.
