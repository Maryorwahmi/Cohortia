Application Security Testing

A practical foundation for finding and prioritizing application vulnerabilities across development and runtime.

This lesson shows the different testing methods, when to run them in the SSDLC, and how to interpret findings so you can close risk efficiently. Expect concrete examples and a hands-on DAST walkthrough using a local web app. We focus on practical integration with CI/CD and realistic limitations of automated scanners.

Explore Key Topics
SAST
Source-level analysis to find code patterns like buffer overflows and SQL injection before runtime.
DAST
Black-box scanning against a running app to validate exploitable behavior and misconfigurations.
IAST & RASP
Runtime instrumentation combines code visibility and live traffic for accurate findings and real-time protection.
Testing Spectrum
S
SAST: static code checks and IDE feedback for early remediation.
D
DAST: external scanning to confirm what is actually reachable and exploitable.
R
RASP: runtime defense that can block attacks in production.
Why this matters
Automated tools reduce risk and provide developer feedback, but they need orchestration and human review to prioritize and close the highest-impact issues. This lesson shows how to build that orchestration.
