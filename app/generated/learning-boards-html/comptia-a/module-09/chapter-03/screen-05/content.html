Definition

Dynamic Application Security Testing

Automated scanning that exercises a running application to verify exploitable behavior and misconfigurations.

Typical workflow
  1. Crawl or spider the application to discover pages and endpoints.
  2. Launch passive and active tests for injection, XSS, and auth checks.
  3. Collect alerts and evidence, then prioritize by impact and confidence.
Example result
Alert: Reflected XSS on /search?q parameter. Evidence: payload rendered in response with script tag. Action: validate and escape user input or use parameterized rendering.
Coverage strategies
  • Use authenticated scans to reach protected paths.
  • Include spidering and manual exploration to uncover deep routes.
  • Limit scan aggressiveness on production-like systems to avoid side effects.
Key takeaway
Key Takeaway

DAST finds real, runnable vulnerabilities but only along exercised paths—combine with other methods for full coverage.
