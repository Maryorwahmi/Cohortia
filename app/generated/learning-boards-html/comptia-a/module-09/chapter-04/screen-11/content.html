Module 9 › Chapter 9.4 › Strategies for Managing Third‑Party Components
Strategy

Policy, tooling, and automation

Approved list
Maintain a curated list of allowed dependencies and sources.
Private registry
Proxy or host vetted packages to control supply into builds.
Pin versions
Use fixed versions to avoid unexpected updates in production builds.
Automated checks
Require scanners and SBOM generation in CI as part of pull request gates.
Key Takeaway
Policies without automation are brittle; automation without policy can be inconsistent. Use both together.
