Applied Objectives

How to add detection and verification into CI/CD and dependency workflows.

Learn → Understand → Apply → Master
01
Vulnerability scanning

Run automated scans like npm audit and Dependabot in CI to find known issues.

Mnemonic: status light — green, yellow, red. VERIFIED COMPETENCY MILESTONE

02
SBOM generation

Use tools like Syft and SPDX to create machine-readable inventories of components.

Mnemonic: ingredients list. VERIFIED COMPETENCY MILESTONE

03
CI/CD hardening

Apply least privilege, MFA for pipeline access, and secrets handling to protect builds.

Mnemonic: locked build box. VERIFIED COMPETENCY MILESTONE

04
Artifact signing

Sign builds and verify signatures during deployment to detect tampering.

Mnemonic: digital receipt. VERIFIED COMPETENCY MILESTONE
