Architecture

Threats and controls

Pipeline threats include artifact tampering, compromised build credentials, malicious plugins, and exposure of secrets. Controls focus on prevention and detection: least privilege for pipeline roles, MFA, secrets vaults, ephemeral agents, and network segmentation. Treat artifact signing as an essential detection control — it proves the build origin and integrity.
Scenario
If an attacker gains pipeline credentials, they could inject a backdoor during build. Signing artifacts and verifying signatures during deployment would detect the tamper because the signature would not match the expected signer.
Practical controls
  • Apply least privilege and MFA for pipeline accounts.
  • Use secrets management vaults rather than plaintext variables.
  • Segment build and deployment networks; use ephemeral build agents.
  • Digitally sign artifacts and verify on deploy.
Key Takeaway
Protecting pipeline integrity prevents clean source code from becoming a compromised deployed product.
