Code Walkthrough

Run npm audit and interpret results

Open a terminal in your project directory and run the following commands. Observe the output, note severity levels, and follow suggested remediation actions, then re-run the scan to confirm resolution.
# In your project folder
npm audit

# If safe fixes exist
npm audit fix

# After remediation, re-scan and generate SBOM
npm audit
syft packages -o spdx -q > sbom.spdx
The audit output lists each affected package, severity, and a suggested fix when available. If an automatic fix is not possible, the report shows the dependency chain so you can identify which direct package to update. Always run your test suite after any dependency change.
Example output (abridged)
=== npm audit security report ===
Moderate      lodash  4.17.20  Prototype Pollution
High          left-pad  1.3.0  Arbitrary Code Execution

found 2 vulnerabilities (1 moderate, 1 high)
Limitations
npm audit depends on public vulnerability feeds and may miss zero-days or vulnerabilities outside the registry. Combine with SBOM awareness and other scanning tools.
Key Takeaway
Use npm audit as part of an automated CI workflow, but always triage results, test fixes, and update SBOMs for accurate inventories.
