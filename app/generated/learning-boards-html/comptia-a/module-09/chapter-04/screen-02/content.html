Learning Objectives

Clear, verifiable skills to secure software supply chains.

Learn → Understand → Apply → Master
01
Explain software supply chain security

Define the supply chain and why each component is an attack surface.

Mnemonic: imagine a recipe — every ingredient matters. VERIFIED COMPETENCY MILESTONE

02
Identify common risks and attack vectors

Recognize package supply risks, transitive dependencies, and pipeline threats.

Mnemonic: chain links — one weak link breaks the chain. VERIFIED COMPETENCY MILESTONE

03
Manage third‑party components and OSS

Use pinning, private registries, and reputation checks to reduce risk.

Mnemonic: curated pantry — only trusted sources. VERIFIED COMPETENCY MILESTONE

04
Use SBOMs and secure CI/CD controls

Create bill of materials and sign artifacts to verify integrity through deployment.

Mnemonic: signed receipt — proof of what went into the product. VERIFIED COMPETENCY MILESTONE
