Maintenance Workflow
1. Monitor
Collect logs and alerts to detect anomalies.
2. Discover
Find vulnerabilities via scanners and SBOM analysis.
3. Triage
Prioritize by impact, exploitability, and exposure.
4. Remediate
Patch, test, deploy, and verify; document the change.
Concrete Patch Example

A dependency has a critical CVE. Use SBOM to find affected services, create a patch branch, run automated tests, deploy to canary, monitor for regressions for one hour, then roll forward to production. If a regression appears, immediately rollback and open a postmortem ticket.

Verification checklist
  • Automated tests passed for canary
  • No increase in error rates or latency
  • Deployment artifacts signed and logged
Pitfall

Delaying patches because they are inconvenient or untested increases exposure. Prioritize critical fixes and make testing fast.

Key Takeaway

Automate detection, prioritize by risk, and verify patches with canaries and monitoring to reduce incident windows.
