Assets & Entry Points
  • Assets: User credentials, photos, metadata, DB, web server, cloud storage.
  • Entry Points: Login form, register form, upload API, view API.
STRIDE Table (sample rows)
Spoofing — attacker uses stolen credentials. Mitigation: MFA, strong hashing, monitor logins.
Tampering — malicious upload modifies stored files. Mitigation: content scanning, integrity checks.
Information Disclosure — public bucket exposes private photos. Mitigation: signed URLs, least-privilege storage roles.
Example: Upload Flow Mitigations
  1. Validate file type and size server-side; reject suspicious content.
  2. Store uploads in a private bucket with signed URL access.
  3. Scan files for malware as part of processing pipeline.
  4. Log upload actions with user ID and request context for non-repudiation.
Exercise

Draft a STRIDE row for the login endpoint, pick the top two threats, and propose a mitigation you can implement this sprint.

Key Takeaway

Threat modeling turns abstract risk into prioritized actions. Start small, focus on high-value assets, and iterate.
