Module 09 › Chapter 9.5 › Data in Transit
Protocols
  • TLS (HTTPS) for web and APIs
  • SSH for remote access
  • VPNs / IPsec for network-level tunnels
Example
Mutual TLS between microservices with certificate rotation and validation.
Best practices
  • Enforce TLS 1.2+ and disable legacy ciphers
  • Validate certificates and use PKI or managed certificate services
  • Avoid terminating encryption at untrusted intermediaries
Pitfall
Assuming private networks eliminate the need for transport encryption.
Key Takeaway
Encrypt every channel carrying sensitive data and validate endpoints and certificates to prevent interception or tampering.
