Module 09 › Chapter 9.5 › Encryption Choices
Full Disk Encryption
Device-level protection
Protects entire storage volume; useful for laptops and servers to defend against physical theft.
Transparent Data Encryption (TDE)
Database file encryption
Encrypts database files and backups with minimal application changes; suitable for protecting DB at rest.
Object Storage Encryption
Cloud object protection
Provider-managed or customer-managed keys for buckets and archives. Essential for cloud backups and archived data.
Key Management & Ownership
Who manages keys matters more than the encryption algorithm itself. Customer-managed keys reduce provider access but increase operational responsibilities.
Example
Use TDE and customer-managed keys for PHI databases, with strict RBAC around key usage and audited access logs.
Key Takeaway
Pick the encryption mode to match storage type and threat model, and always couple it with robust key management and access controls.
