Module 09 › Chapter 9.5 › Data at Rest
Primary controls
  • Full Disk Encryption for endpoints and servers
  • Transparent Data Encryption (TDE) for databases
  • Object storage encryption (customer-managed keys)
Access controls & key management
Use least privilege, RBAC, and separate key management so that possession of storage alone does not permit reading data.
Example
Encrypted DB backups in a region-specific bucket with customer-managed keys and audited service account access.
Retention & secure deletion
Define retention schedules and use secure deletion methods like cryptographic erase to prevent recovery after disposal.
Common mistake
Encrypting data but storing keys with the same system or not auditing access—that defeats protection.
Key Takeaway
Encryption is central, but combine it with access controls, key management, and secure deletion to fully secure data at rest.
