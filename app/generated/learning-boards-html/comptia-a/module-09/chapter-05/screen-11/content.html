Module 09 › Chapter 9.5 › Retention & Deletion
Retention policy elements
  • Legal and business retention requirements
  • Retention windows and archival rules
  • Roles responsible for retention decisions
Secure deletion methods
  • Cryptographic erase by destroying keys
  • Verified overwrite for local media
  • Ensure backups and snapshots are purged
Example
A healthcare application aligns retention windows to statute, ensures backups follow the same schedules, and uses cryptographic erase for archived datasets when retention ends.
Key Takeaway
Retention is a program: document retention reasons, enforce across all copies, and use secure deletion to remove legacy exposure.
