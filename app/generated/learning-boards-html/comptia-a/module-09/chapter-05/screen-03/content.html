How you'll demonstrate mastery
Concrete deliverables tied to each objective
Bloom: Apply → Evaluate → Create
Task: Label and justify
Produce a table mapping five data types to classification labels with reasons tied to sensitivity and regulation.
Verification: Peer review of label justification
Task: Select protections by state
Choose specific controls for at rest, in transit, and in use and explain trade-offs.
Verification: Explain why TDE or TEEs were chosen
Task: Residency mapping
State where data will be stored and why. Cite legal constraints that impact design decisions.
Verification: Region selection justification
Task: High-level protection plan
Create a concise plan that maps classification to controls, monitoring, and retention policy.
Verification: Security architect review
