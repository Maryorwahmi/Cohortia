Definition Privacy-Enhancing Technologies
PETs that enable data use while protecting privacy
Pseudonymization
Replace direct identifiers with reversible tokens to allow re-linking under strict controls.
Anonymization
Irreversibly remove identifiers for safe public release; evaluate re-identification risk carefully.
Homomorphic Encryption
Compute on encrypted data without needing decryption; useful for confidential analytics with performance trade-offs.
Differential Privacy
Add noise to outputs so individual records cannot be singled out while preserving statistical utility.
Secure Multi-Party Computation
Jointly compute functions across parties without exposing private inputs; useful for cross-organization collaboration.
When to Use Each
Match PET to utility needs: reversible linking needs pseudonymization; public analytics often need anonymization or differential privacy.
Key Takeaway

PET choice is a trade-off between data utility and privacy guarantees; consider threat model, performance, and re-identification risk.
