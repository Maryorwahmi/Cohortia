File encryption with OpenSSL (demo)
Illustrates encryption commands and highlights why key management matters.
Demo Commands
# Example: Encrypting a file using OpenSSL with a strong cipher
# This demonstrates basic file encryption. In an enterprise, KMS/HSM would manage keys.
# Safety Note: Never hardcode passwords or keys in scripts for production.
# For demonstration:
echo "This is highly sensitive data." > sensitive.txt

# Encrypt with AES-256-CBC, prompting for a password
openssl enc -aes-256-cbc -salt -in sensitive.txt -out sensitive.enc

# Decrypt the file
openssl enc -d -aes-256-cbc -in sensitive.enc -out sensitive_decrypted.txt

# Verify decryption
cat sensitive_decrypted.txt
Note: The demo uses a passphrase-based key. In production prefer KMS-issued keys and HSM protection to avoid password exposure.
Reflection & Checklist
  • Do not hardcode passwords; use KMS/HSM for key lifecycle.
  • Audit and log all key operations; ensure recovery procedures.
  • Encrypt both data at rest and in transit for layered defense.
Key Takeaway

Command-line encryption clarifies mechanics; scale to enterprise with managed keys and auditable controls.
