Core Concept Key Management
Protect keys, preserve encryption
Key Lifecycle
  • Generate keys in a trusted environment with sufficient entropy.
  • Store root keys in HSMs and manage operational keys through KMS APIs.
  • Automate rotation and plan re-encryption or key-derivation strategies.
  • Revoke keys and have procedures for incident-driven cryptographic recovery.
Example: an HSM-backed KMS issues short-lived data keys to services; services never see root keys and must authenticate via scoped roles to obtain keys.
Operational Controls
  • Enforce least-privilege for key access and multi-party approvals for key export.
  • Log all cryptographic operations and review key access periodically.
  • Avoid embedding keys in code, configs, or backups.
Pro Tip

Use HSM-backed key storage for high-impact keys, and prefer short-lived data keys to reduce exposure if a service is compromised.
