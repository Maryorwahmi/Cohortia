Comparison Encryption States
Encryption at rest versus encryption in transit
Encryption at Rest
Protects data stored on physical media and cloud storage.
  • Full-disk encryption for endpoints and servers.
  • Transparent Data Encryption for databases to guard files and backups.
  • File-level encryption for specific sensitive documents.
  • Example: encrypting a cloud database with TDE and restricting key access to a KMS.
Key Takeaway

At-rest encryption defends against storage compromise but depends on strong key management and access controls.

Encryption in Transit
Protects data as it travels across networks and public infrastructure.
  • TLS/SSL for web and application protocols; prefer TLS 1.3 when available.
  • IPsec for secure site-to-site tunnels and secure routing.
  • VPNs for remote access; consider client certificates for strong authentication.
  • Example: enforce TLS 1.3 between client and app and use mutual TLS for service-to-service communication.
Common Misconceptions
Encrypting only in one state is insufficient. Encryption must be combined with authentication, authorization, and key protections to be effective.
