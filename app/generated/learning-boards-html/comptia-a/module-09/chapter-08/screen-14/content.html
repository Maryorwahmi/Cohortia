Lab: OWASP ZAP Scan

Use a controlled vulnerable app, run an automated scan, and validate alerts safely.

Steps
  1. Deploy a vulnerable web app locally for testing.
  2. Open OWASP ZAP and point it to the app URL.
  3. Run an automated scan and review alerts in the Alerts tab.
  4. Reproduce a high-priority alert safely and apply a fix.
  5. Re-scan to verify remediation.
Safety Note
Only scan systems you control or where you have explicit authorization. Never target production without agreement.
Interpreting alerts
Open the alert details, read the description, solution, and other info to form a remediation plan.
Outcome
Practice the detection-to-remediation cycle: detect, reproduce, fix, re-test, and document.
