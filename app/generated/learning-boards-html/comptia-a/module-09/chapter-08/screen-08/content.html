Module 9 › Chapter 9.8 › RASP
Definition

Runtime Application Self-Protection

Embedded runtime protection that inspects application behavior and blocks malicious actions in real time.

Capabilities
Detects anomalous input, prevents exploitation, and can terminate sessions or requests.
Caution
Requires tuning; false positives or performance impact can disrupt users if misconfigured.
Key Takeaway

RASP provides inline protection when immediate mitigation is needed, but it complements secure code fixes rather than replacing them.

Comparison
WAF
Edge filtering, less visibility into application internals.
RASP
Runtime context, can block inside the app with accurate logic awareness.
Deployment note
Use RASP as a temporary guardrail while prioritizing code fixes and process changes.
