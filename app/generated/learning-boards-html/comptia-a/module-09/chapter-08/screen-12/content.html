Testing Placement in the Pipeline

Map each testing type to the SSDLC stage where it prevents the most risk.

Developer & Pre-commit
SAST and linting for immediate feedback.
CI / Integration
IAST during tests to capture runtime context and reduce false positives.
Staging & Pre-release
DAST against deployed staging environments to simulate external attacks.
Production
RASP for inline protection while fixes are scheduled; pen tests and bounties for continuous validation.
Design gates: fail CI for critical issues, create tracked tickets for medium issues, and warn on low issues while collecting metrics for training.
