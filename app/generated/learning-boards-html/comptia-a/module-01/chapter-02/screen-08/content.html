Implementation Phase › Secure Implementation
Implementation activities
  • Secure configuration management and baselines
  • Automated verification in CI/CD
  • Vulnerability scanning and penetration testing
  • Integration tests for control behavior
Concrete example
Design requires mTLS; implementation must provide certificate lifecycle management, secure storage for keys, and acceptance tests that fail builds if mTLS is not configured correctly.
Common mistake
Allowing shortcuts in configuration because of schedule pressure, which later requires extensive rework and increases risk.
Key Takeaway

Verify controls with automated checks and ensure architects review acceptance tests to prevent silent deviations from design.
