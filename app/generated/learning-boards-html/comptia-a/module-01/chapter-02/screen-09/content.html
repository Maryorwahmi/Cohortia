Operations › Monitoring & Feedback
Operational activities
Define logging, alerting, and runbooks; use SIEM and SOAR for detection and automation; feed incidents back to architecture via reviews and updates.
Example: Authentication anomalies
Repeated token validation failures may indicate an incorrect trust boundary or clock skew issues requiring architectural fixes.
Operational-artifact link
Ensure monitoring requirements are part of design so telemetry supports post-deployment analysis.
Collaboration note
Architects, operations, and security should agree on which metrics indicate architectural risk and how to escalate them for design changes.
Common misconception
Assuming monitoring is reactive. Instead, design telemetry to provide early indicators for architectural fixes.
Key Takeaway

Use operations data to refine threat models and architectures. Monitoring is the mechanism for continuous improvement.
