Top mistakes
Repeating patterns: checkbox modeling, missing acceptance criteria, configuration drift, and ignored decommissioning. Each one is preventable by design and process changes.
Remedy: Iteration
Version threat models and tie changes to design reviews and CI checks.
Remedy: Verification
Attach acceptance tests or configuration baselines to every security requirement.
Practical habit
Link each architectural decision to an owner and a verification artifact, and require that CI or automated audits check it before deployment.
Key Takeaway

Make security practices habitual: iterate, verify, automate, and document to avoid repeated mistakes.
