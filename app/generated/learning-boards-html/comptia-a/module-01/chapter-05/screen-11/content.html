Module 1 › Chapter 1.5 › Database Security
Hierarchy of Controls
Role-Based Access Control (RBAC)
Define narrow roles for applications and users; enforce least privilege and separate duties for admins.
Auditing
Record access and changes to data for investigation and compliance reporting.
Database Activity Monitoring (DAM)
Real-time detection of anomalous queries and bulk data access patterns.
Key Takeaway

Protect data by narrowing access, logging activity, and detecting anomalous database behaviour in real time.

Concrete Example
Production patient records are accessible only to a service account with audited credentials. DAM alerts on large exports and unusual administrative queries. Staging environments use masked or redacted data to prevent exposure to developers. Vulnerability scans and patching are scheduled to reduce known database threats.
Misconception
Assuming encryption removes need for RBAC or auditing. Encryption protects storage but governance requires controls on who may decrypt or query data.
