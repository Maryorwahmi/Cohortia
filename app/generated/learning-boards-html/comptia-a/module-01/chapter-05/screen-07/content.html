Module 1 › Chapter 1.5 › Encryption in Transit
Key Protocols
TLS / SSL
Primary choice for securing web and API traffic. Ensure certificate lifecycle management and strong cipher configuration.
IPsec
Use for secure site-to-site or host-to-host tunnels where network-layer protection is needed.
mTLS
Mutual authentication for service-to-service calls to prevent impersonation within a microservice mesh.
Key Takeaway

Protect each hop in a flow; use TLS for external clients and mTLS between internal services where identity matters.

Concrete Example
Mobile app sends data to API gateway over TLS. The gateway authenticates the client and forwards requests to microservices using mTLS. Administrative SSH access is limited via bastion hosts and uses key-based authentication. For a VPN segment, IPsec is used for secure links between datacenters.
Misconception
Relying only on network perimeter encryption like VPNs leaves application-layer connections vulnerable to lateral attacks. Always secure application channels independently.
