Module 1 › Chapter 1.5 › Encryption Overview
At a Glance
Encryption at Rest
Full disk, database TDE, and object storage encryption to protect stored data.
Encryption in Transit
TLS, IPsec, and other protocols to prevent eavesdropping while data moves.
Advanced Techniques
Homomorphic, format-preserving encryption, and tokenization for specialized scenarios.
Key Takeaway

Encryption choice depends on threat model, usability, and where data is processed; always pair with key controls.

Comparison: Methods and When to Use
Homomorphic Encryption
Allows computation over encrypted data without decryption. Example: running analytics on encrypted records where raw values must remain hidden. Misconception: currently practical only for limited workloads due to performance overhead.
Format-Preserving Encryption (FPE)
Maintains original data format. Useful when legacy systems require fixed-length fields, for example encrypting a 16-digit card number while preserving format to pass existing validation checks.
Tokenization
Replaces real values with tokens. Example: payments tokens stored in a vault, reducing systems in scope for PCI. Misconception: tokenization reduces scope but does not eliminate the need for secure key and vault access controls.
