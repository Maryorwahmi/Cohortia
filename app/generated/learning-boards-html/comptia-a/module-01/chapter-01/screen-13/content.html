Module 1 › Chapter 1.1 › Key Concepts
Enterprise Security Architecture
A business-aligned blueprint tying controls to objectives and risk tolerances.
Security Engineering
The tactical implementation and configuration of security solutions from architecture designs.
Security Operations
Ongoing monitoring, incident detection, response, and evidence collection for implemented controls.
Summary takeaway

Keep architecture business-driven, make controls measurable, and maintain strong feedback loops between architecture, engineering, and operations.
