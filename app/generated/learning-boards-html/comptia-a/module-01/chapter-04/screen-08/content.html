Module 1 › Chapter 1.4 › Container Security
Image Security
Use trusted base images, scan for vulnerabilities, and sign images so only verified artifacts are deployed. Integrate scanning into CI pipelines to block risky images before they reach production.
Runtime Security
Enforce least privilege for processes, use runtime detection tools to detect anomalous behavior, and limit container capabilities and resource access.
Orchestration
Secure control plane components, protect etcd or similar cluster stores, enforce RBAC for cluster access, and apply network policies to limit pod communication.
Concrete example
Scan images in CI and allow only signed images to be deployed to production.
Common mistake
Leaving default cluster and network configurations unchanged, which is often insecure.
Key Takeaway

Protect containers from build to runtime and treat orchestration controls as a critical part of your security boundary.
