Module 1 › Chapter 1.4 › Serverless Security
Function Permissions
Assign roles with minimal privileges. Prefer scoped actions that target specific resources rather than wildcard permissions.
Secrets & Validation
Store secrets in a managed vault and validate all inputs and outputs to reduce injection and data leakage risk.
Observability
Enable and centralize logs and monitoring for function invocations so abnormal behavior is visible and traceable.
Concrete example
Grant a function only read access to one bucket and specific logging permissions for its log group.
Common mistake
Giving functions broad storage or management permissions they don't need.
Key Takeaway

Limit function permissions, protect credentials in a vault, validate data, and log everything to reduce risk.
