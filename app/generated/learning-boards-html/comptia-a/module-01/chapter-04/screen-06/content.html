Module 1 › Chapter 1.4 › Securing IaaS
Architecture Checklist
  • Baseline hardened images and automated patching.
  • Network segmentation with VPCs, subnets, Security Groups and NACLs.
  • Instance IAM roles instead of hardcoded credentials.
  • Encrypt disks and enforce TLS for data in transit.
Common mistake
Assuming provider patches your guest OS.
Example
Use instance roles to grant scoped S3 read permissions instead of storing keys on disk.
Implementation Sketch
Combine hardened AMIs, a management subnet for patching, a production subnet for workloads, and strict Security Groups. Log host activity to a centralized collector and enforce disk encryption at provisioning time. Use role-based access for automation and operators.
Key Takeaway

Treat IaaS like owned infrastructure: you are responsible for everything inside the VM and for network boundaries that reduce exposure.
