Module 1 › Chapter 1.4 › Shared Responsibility
Claim

The model defines which security tasks the provider performs and which you must perform. It changes by service model, and it is the first principle for cloud architecture.

Provider example
Physical security, host virtualization, and the cloud control plane are the provider's responsibility.
Customer example
Data encryption, OS hardening, network rules, and IAM policies are the customer's responsibility.
Key Takeaway

Always verify the shared responsibility model for each service; incorrect assumptions create security gaps.

Concrete Example
You host a virtual machine. The provider ensures the hypervisor and physical host are maintained. You must patch the guest OS, configure security groups, and manage application access. If you assume the provider patches your guest OS, you leave the instance vulnerable.
Misconception
Believing the provider secures your configurations and identities.
