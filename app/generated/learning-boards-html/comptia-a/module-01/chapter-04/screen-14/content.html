Module 1 › Chapter 1.4 › Key Concepts
Shared Responsibility
A framework defining which security tasks the provider handles and which the customer must own.
Service-Model Controls
IaaS needs host/network controls, PaaS needs code and runtime controls, SaaS needs access and data controls.
IAM & Least Privilege
Use roles, temporary credentials, MFA, and organizational policies to reduce privilege risk and enforce guardrails.
Final takeaway

Design with the shared responsibility model, align controls to service models, and centrally enforce identity guardrails to reduce cloud risk.
