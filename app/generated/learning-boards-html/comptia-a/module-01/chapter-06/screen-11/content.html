Module 2 › Chapter 1.6 › Directory Services
Directory types
LDAP protocol, Active Directory, and cloud directories support authentication and attribute queries.
Integration patterns
Sync, federation, extension, and connector-based provisioning using tools such as SCIM or vendor connectors.
Practical concerns
  • Attribute mapping and conflict resolution
  • Password synchronization vs federated authentication
  • Service account and machine identity handling
Key Takeaway
Define sync rules, include service accounts in governance, and document offline authentication behavior for resilience.
