Hybrid IAM Architecture Design Template
1. Core IdP & Sync
Authoritative AD synchronized to cloud IdP (connector) for consistent attributes.
2. SSO for SaaS
SAML for enterprise SaaS; OIDC for modern apps and APIs.
3. AWS Federation
Use SAML to map IdP assertions to AWS IAM roles via Identity Center.
4. MFA & PAM
MFA at IdP; PAM for privileged servers and cloud root accounts with JIT and recording.
5. Provisioning & IGA
SCIM connectors and IGA workflows for automated provisioning, approvals, and certification cycles.
Concrete test
Disable an AD user and verify cloud accounts and AWS role access are removed within the required SLA.
Common mistake
Skipping service account rotation and PAM onboarding; these create persistent risk.
Key Takeaway
Document flows, test them, and ensure provisioning, SSO, MFA, and PAM produce verifiable audit events.
