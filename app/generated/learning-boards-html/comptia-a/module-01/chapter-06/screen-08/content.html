Module 2 › Chapter 1.6 › Federation Protocols
SAML
Enterprise web SSO using XML assertions for authentication and attributes.
Use when
Integrating enterprise IdPs with mature SaaS service providers.
OAuth / OIDC
OAuth delegates authorization; OpenID Connect provides identity tokens for modern apps and APIs.
Use when
APIs, mobile apps, and services needing token-based access control and identity claims.
Concrete example
SAML for Salesforce SSO; OIDC for a custom mobile app that obtains an ID token and API access token.
Common misconception
Treating OAuth alone as authentication. Use OIDC when identity assertions are required.
Check
Map each application to the protocol that meets client type, token needs, and audit requirements before integrating.
