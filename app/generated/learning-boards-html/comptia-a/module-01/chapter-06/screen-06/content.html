Authentication vs Authorization
Authentication verifies identity; authorization grants actions.
Authentication
Verify user or service identity using passwords, certificates, or MFA factors.
Authorization
Enforce what the authenticated identity can access using roles, groups, and policies.
SSO example
User authenticates to corporate IdP, receives assertion, and accesses multiple SaaS apps without repeated logins.
Practical considerations
  • Apply MFA at the IdP, especially for privileged roles.
  • Plan token lifetimes and revocation strategies for compromised devices.
  • Map assertions to least‑privilege roles at service providers.
Key Takeaway
SSO improves usability and centralizes control, but always pair it with MFA and explicit authorization checks.
