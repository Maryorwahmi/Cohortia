Identity lifecycle and centralization
Provisioning to de‑provisioning with a single source of truth
Lifecycle stages
  • Onboarding: create identity and attributes
  • Change: role updates, attribute updates, approvals
  • Offboarding: revoke access and de‑provision accounts
Key Takeaway

Automation and a single authoritative directory shrink the risk window for stale privileges and simplify audits.

Concrete example
AD synchronizes to Azure AD; disabling an employee in AD triggers SCIM connectors to remove SaaS entitlements and cloud roles within policy SLAs.
Common mistake
Assuming centralization removes local identities. Always plan reconciliation and periodic audits of local accounts.
Directory integration cards
Active Directory
On‑premises authoritative store for many enterprises.
LDAP
Protocol for directory access and attribute queries.
Cloud directories
Azure AD or cloud directory services used for SSO and cloud resources.
