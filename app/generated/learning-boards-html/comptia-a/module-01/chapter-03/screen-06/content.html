Module 1 › Chapter 1.3 › Micro-segmentation Process
Step-by-step
1. Inventory workloads and dependencies.
2. Baseline traffic in monitor-only mode.
3. Create intent-based rules with explicit ports and sources.
4. Stage enforcement: audit → soft-enforce → block.
5. Verify tests and maintain rollback steps.
Example rule table
Source: Web SG | Destination: App SG | Protocol/Port: TCP/8080 | Control: Security Group | Action: Allow
Source: App SG | Destination: DB SG | Protocol/Port: TCP/5432 | Control: Security Group+On-prem FW | Action: Allow
Misconception check: implementing many one-off rules without grouping by role increases operational cost. Group by role or service where possible and use templates for consistency.
