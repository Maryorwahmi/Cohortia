Transit Gateway vs Peering
Peering: direct VPC-to-VPC routing, simple but limited scale. Transit Gateway: hub-and-spoke, central routing and policy controls for many VPCs and VPNs.
Use transit gateways to centralize shared services and reduce routing complexity when multiple VPCs or accounts must interconnect.
Direct Connect / ExpressRoute
Dedicated private connections that bypass the public internet for improved security and performance when linking on-premises and cloud resources.
Practical note: combine dedicated circuits with strict on-prem firewall rules and route filters to limit which cloud subnets can access sensitive databases.
Operational tip
Assign clear route ownership for the transit gateway and require change control for route table edits to prevent accidental transitive exposures.
