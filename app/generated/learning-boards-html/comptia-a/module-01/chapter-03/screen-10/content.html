Design checklist
  • List tiers and required ports: LB(443), Web→App(8080), App→DB(5432).
  • Create Security Groups per tier and reference by SG instead of IPs when possible.
  • Run monitor-only logging to collect normal flow patterns.
  • Prepare rollback steps and schedule a maintenance window for enforcement.
Test commands (safe)
# From web instance: test app API
curl -I https://internal-app:8080/health
# From app instance: test DB connection
psql -h db.internal -U readonly -c 'SELECT 1;'
If curl or psql fail, consult flow logs and Security Group references. Monitor-only mode will show denied flows without breaking services.
