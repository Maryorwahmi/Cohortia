Module 1 › Chapter 1.3 › Cloud Networking Primitives
Core components
VPC: logical isolation boundary for your cloud resources. Design per-environment or per-account for separation.
Security Group: stateful, instance-level firewall. Prefer for micro-segmentation.
NACL: stateless, subnet-level filter. Useful as an additional hardening layer.
Example rule mapping: Web SG allows 8080 from LB SG; App SG allows 8080 only from Web SG; Database SG allows 5432 only from App SG. Use NACLs for broad denies or egress controls where necessary.
Practical checklist
  • Map intended flows and assign Security Groups by role, not by IP where possible.
  • Avoid overly permissive rules such as internal ports open to 0.0.0.0/0.
  • Use transit gateways for scalable hub-and-spoke connectivity across multiple VPCs and accounts.
  • Document which control enforces each allowed flow for troubleshooting.
Key Takeaway

Choose Security Groups for fine-grain instance controls and use NACLs for complementary subnet-level restrictions.
