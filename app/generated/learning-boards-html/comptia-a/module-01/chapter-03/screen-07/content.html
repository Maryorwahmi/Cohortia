Module 1 › Chapter 1.3 › VPN Comparison
IPsec VPN
Layer 3 tunnels for site-to-site. Strong crypto and routing. Provides full subnet access; manage keys and NAT traversal carefully.
Use when: stable network links are required between sites or to cloud VPCs.
SSL/TLS VPN
Higher-layer client access often browser-based. Easier deployment for many users and better traversal through firewalls.
Use when: many remote users need easy access to web apps and file shares.
ZTNA
Application-specific, continuous verification of user and device. Grants least-privilege access to apps instead of networks.
Use when: you need dynamic, context-aware access and want to reduce networkwide exposure.
Practical scenario
Headquarters to cloud connectivity: choose IPsec for persistent backend traffic. Remote distributed workforce: choose SSL/TLS or ZTNA to reduce client management and limit network exposure.
