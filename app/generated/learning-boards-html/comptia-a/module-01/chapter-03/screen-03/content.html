Objective Validation Steps
  • Deploy micro-segmentation in monitor-only mode to learn flow patterns before blocking.
  • Create distinct Security Groups per tier and test connections using safe client commands in a lab.
  • Set up an IPsec site-to-site tunnel for on-prem to cloud connectivity and compare latency and access scope.
  • Place IDS sensors at east-west chokepoints, tune signatures, and then enable prevention selectively.
