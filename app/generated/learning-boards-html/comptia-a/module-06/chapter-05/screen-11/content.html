Task

Find svc_web_app logins to non-standard hosts

The expected output fields are _time, user, src_host, dest_host, and event_id. Use a 24-hour window to limit noise.

index=windows_events event_id=4624 user="svc_web_app" dest_host!="WEB_APP_01" _time > relative_time(now(), "-24h") | table _time, user, src_host, dest_host, event_id
Expected result
A small table of login events that show unexpected destinations, ready for pivoting into EDR or network logs.
Investigation next steps
  • Take suspicious rows and note _time and src_host to pivot to EDR.
  • On the source host, search for process creation events +/- 20 minutes around the login.
  • Look for parent-child anomalies, LOLBIN usage, and outbound connections that may indicate pivoting.
Check your understanding
If the SIEM returns multiple dest_host values for the same _time and user, what pivot would you run first and why?
