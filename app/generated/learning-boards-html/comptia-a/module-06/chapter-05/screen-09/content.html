Module 6 › Chapter 6.5 › Behavioral Analytics
Definition

Baseline and deviation

Baselines define normal ranges for logins, access patterns, and process activity. Anomalies are deviations from those baselines and help prioritize investigations when signature-based detections miss novel behavior.

Example
A UEBA alert flags a user accessing sensitive files from an overseas IP outside normal hours. This sequence, combined with a login anomaly, raises priority.
Investigation steps
  1. Verify the anomaly against asset tags and scheduled maintenance windows.
  2. Pivot to SIEM logs for authentication details and source IP history.
  3. Use EDR to inspect process activity and network connections for the endpoint involved.
Key Takeaway
Anomalies should focus your hunting effort. Always validate with logs and endpoint telemetry before escalating.
