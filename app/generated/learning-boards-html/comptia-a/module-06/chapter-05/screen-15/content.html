Module 6 › Chapter 6.5 › Key Concepts
SIEM
Central log aggregation and correlation platform for historical queries and enrichment.
EDR
Endpoint telemetry platform capturing process, memory, and file activity for host investigations.
NetFlow / Zeek
Flow metadata and protocol logs used to detect unusual conversations and to prioritize packet captures.
Quick summary

Use SIEM to find leads, EDR to validate behavior, and network tools to confirm communications. Improve telemetry and tune queries for sustainable, accurate hunting.
