Module 6 › Chapter 6.5 › Data Visibility
Definition

What visibility includes

  • Structured logs: timestamps, user, source host, destination host, event IDs.
  • Endpoint telemetry: process creation, command line, parent process, loaded modules.
  • Network data: packet captures, Zeek logs, NetFlow metadata.
  • Enrichment fields: geoip, asset tags, owner, criticality.
Misconception
More raw logs without key fields increases noise. Focus on collecting the right fields with context.
Concrete Example
To detect suspicious PowerShell execution, ensure the endpoint agent captures the process command line and parent process name. With these fields you can search for powerhsell.exe with encoded commands or unusual parent-child relationships.
Why it matters
Hunters can only validate hypotheses when fields and timestamps are precise and accessible.
Action
Audit telemetry coverage for critical hosts, request missing fields, and test ingestion with sample events.
