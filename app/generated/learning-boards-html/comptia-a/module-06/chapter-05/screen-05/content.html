Query Walkthrough

Search for suspicious logins

This query demonstrates enrichment and filtering to find successful Windows logins to critical servers originating outside the United States in the past seven days.
index=windows_events event_id=4624 (dest_host="critical_server_A" OR dest_host="critical_server_B") | lookup geoip client_ip AS src_ip | where geo_country != "United States" AND _time > relative_time(now(), "-7d") | stats count by _time, user, src_ip, geo_country | sort - count
Example output
Timestamps, user, source IP, and country counts to spot repeat occurrences from unusual locations.
Refinement tip
Add user role or asset tags to focus on service accounts or high-value systems only.
Supporting points
  • Use short windows to reduce noise and iterate outward if needed.
  • Enrich IPs with geoip or asset metadata to add context to raw events.
  • Aggregate with stats to surface users or IPs that repeat across hosts.
  • Pivot suspicious timestamps and hosts into EDR for endpoint validation.
Common mistake
Running month-long queries without filters creates too much data and hides meaningful signals.
Key Takeaway

Start narrow, enrich results, and aggregate to find repeat patterns that indicate compromise.
