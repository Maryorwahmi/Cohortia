EDR Query (Conceptual)

Search for suspicious process creation events

Adjust vendor syntax as needed. Target the host WEB_APP_01 and the narrow time window around the login.
host_name="WEB_APP_01" AND event_time BETWEEN "2023-10-26T02:50:00Z" AND "2023-10-26T03:10:00Z" AND ( process_name IN ("powershell.exe", "cmd.exe", "wmic.exe", "psexec.exe") OR command_line CONTAINS "Invoke-Mimikatz" OR command_line CONTAINS "net user" OR command_line CONTAINS "whoami" ) | select event_time, process_name, command_line, parent_process_name, user
Why this helps
It surfaces suspicious process activity and command-line evidence you can use to confirm whether the web host was used to pivot to the database.
Follow-up
  • If you find suspicious processes, collect the entire process tree and any dropped artifacts.
  • Correlate process timestamps with network logs to find outbound connections or database access attempts.
  • Document findings and recommend containment steps if evidence supports compromise.
Key Takeaway
Time-bound, host-focused EDR searches reveal the process-level evidence needed to confirm or refute a suspected compromise.
