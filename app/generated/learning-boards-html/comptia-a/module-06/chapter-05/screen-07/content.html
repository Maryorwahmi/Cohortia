EDR Query Example

Parent-child process search

A conceptual EDR query that hunts for Word spawning PowerShell, a common malicious document pattern. Vendor syntax varies, but fields are consistent.
PROCESS_CREATE where ParentProcessName = "winword.exe" and ProcessName = "powershell.exe"
Why this helps
It surfaces cases where a document invoked scripting, bypassing static file checks.
Misconception
Not every powerhsell.exe instance is malicious; check command-line and parentage to avoid false positives.
Supporting searches and checks
  • Search for lsass.exe memory access or suspicious credential dumping indicators.
  • Look for LOLBINs like certutil or bitsadmin with unusual arguments.
  • Inspect module loads and file writes immediately after suspicious process creation.
Key Takeaway

Focus on behavior and relationships. Use command-line and parent context to separate admin activity from malicious chains.
