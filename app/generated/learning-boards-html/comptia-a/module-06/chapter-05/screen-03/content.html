Module 6 › Chapter 6.5 › Learning Objectives
Privacy-aware hunting
  • Use copies or sandboxed data when possible and avoid live changes without approval.
  • Limit queries to necessary fields and follow retention-policy constraints.
  • Document access and communicate with owners when user data is inspected.
Pro tip
Build reusable query templates that include safe defaults and time bounds to avoid sweeping queries.
Visibility reporting
  • Track which hosts and logs are missing command-line or process telemetry.
  • Request telemetry changes with examples that show why fields matter.
  • Prioritize logging improvements for critical systems first.
Outcome
You will be able to assess visibility gaps and propose targeted telemetry improvements with concrete examples.
