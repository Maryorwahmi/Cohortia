Module 6 › Chapter 6.5 › Integration Workflow
Workflow Steps
  1. Detect: SIEM query or UEBA anomaly identifies an event or user of interest.
  2. Pivot: Use SIEM fields to pivot to EDR for process and memory evidence.
  3. Corroborate: Check network flows or Zeek logs for unusual destinations or protocols.
  4. Confirm: Take a targeted packet capture only when necessary to inspect payloads.
  5. Document: Save timestamps, artifacts, and recommended containment steps.
Scenario snapshot
Example chain: SIEM alarm → EDR shows Document→PowerShell → Zeek shows rare DNS → Packet capture reveals DNS tunneling. Each layer adds a piece of the story and increases confidence before containment.
Key Takeaway
Layered evidence reduces uncertainty. Use tight queries and cross-source correlation to build a defensible incident narrative.
