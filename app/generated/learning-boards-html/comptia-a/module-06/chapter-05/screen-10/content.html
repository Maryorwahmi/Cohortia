Module 6 › Chapter 6.5 › Safe Hunting
Progressive query workflow
  1. Form a specific hypothesis (e.g., unusual service account login).
  2. Identify required fields and confirm telemetry exists.
  3. Run a narrow, time-bounded query and inspect top results.
  4. Pivot to EDR and network logs for corroboration before escalating.
Safety checklist
  • Prefer non-production data or copies when possible.
  • Limit fields and document access for privacy compliance.
  • Coordinate captures with owners and follow change control.
Common Mistakes
  • Blindly broad queries that return millions of rows.
  • Assuming every anomaly equals compromise without context.
  • Failing to collect command-line or parent process fields.
Key Takeaway
Hunt methodically, validate with multiple data sources, and protect systems and privacy while investigating.
