Module 6 › Chapter 6.5 › EDR Pivoting
Endpoint Architecture

Telemetry you need

  • Process create events with parent and command line.
  • File write and module load events.
  • Memory access and suspicious injection indicators.
  • Network connections originating from processes.
Analogy
Think of EDR as the host's black box: it records the sequence of actions that let you reconstruct what happened and when.
Concrete scenario
A SIEM alert shows a service account login to DB_PROD_01 at 3 AM coming from WEB_APP_01. In the EDR console for WEB_APP_01, search for process creations around 2:50 to 3:10. Look for suspicious parents like winword.exe spawning powershell.exe or cmd.exe invoking credential-dumping tools.
What to verify
  • Timestamps align with the SIEM event.
  • Parent process is unusual for that host or user.
  • Command-line contains encoded or suspicious arguments.
  • Network connections to rare external destinations follow the process.
Key Takeaway

EDR lets you validate and enrich SIEM hypotheses by exposing the host-level activity that proves or disproves attacker behavior.
