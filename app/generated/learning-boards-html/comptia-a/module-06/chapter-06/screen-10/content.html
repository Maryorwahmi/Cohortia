Definition

Playbooks vs Runbooks

Playbook (Strategic)
Scenario objectives, decision points, communications, and escalation criteria.
Runbook (Tactical)
Step-by-step commands and verification steps a technician executes under stress.
Runbook Example — Initial Containment
# Initial containment steps (excerpt)
1. Disable network interface on affected host.
2. Capture running processes and memory image.
3. Export relevant logs to immutable storage and record checksums.
4. Notify incident commander with collected evidence summary.
Key Takeaway

Use playbooks for choices and runbooks for execution. Both must include verification and ownership to be reliable.
