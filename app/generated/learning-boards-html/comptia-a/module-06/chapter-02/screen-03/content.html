Competency Milestones
Four practical tasks you can perform and verify.
  1. 1. Reconstruct an incident using SIEM logs and NetFlow, showing why the events indicate compromise.
  2. 2. Validate an external IoC by cross-referencing two independent sources and checking asset relevance.
  3. 3. Map IoCs to MITRE ATT&CK techniques and propose a behavior-based detection rule.
  4. 4. Ingest a STIX/TAXII feed into a TIP with filters to prevent alert fatigue and false positives.
Checks
Each milestone should include evidence: queries, mappings to ATT&CK techniques, and a short validation log showing cross-references and filters used during ingestion.
