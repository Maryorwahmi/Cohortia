Validation Process

Use a repeatable pipeline: assess source, corroborate, enrich, score confidence, set expiry, and decide enforcement policy. Combine automation and analyst review for reliable results.

1. Assess
Provenance, freshness, past accuracy.
2. Corroborate
Cross-check with internal logs and another feed.
3. Enrich
Add asset context, TTP mapping, and confidence metadata.
Concrete validation example
Received IP from a public feed. Check NetFlow for connections, consult EDR for process and file data, search a commercial feed for the same IP, and set a medium confidence with a 7-day expiry pending more evidence.
Key Takeaway

A curated pipeline with corroboration and expiry prevents stale or low-confidence indicators from disrupting operations.
