Module 6 › Chapter 6.2 › Internal Sources
Definition
Data originating inside your environment

Internal sources include SIEM logs, EDR alerts, NetFlow, PCAP captures, authentication logs, and analyst reports. These sources provide asset-specific context necessary to prioritize investigations.

SIEM: correlates events to reveal patterns and possible compromise chains.
EDR: endpoint activity, process trees, and file artifacts useful for containment.
NetFlow/PCAP: network flows and packet details for exfiltration or lateral movement analysis.
Key Takeaway

Always correlate at least two internal signals before escalating and enrich events with host and user context.

Illustrative Example
SIEM correlation example
index=web_logs status=500 | stats count by src_ip
Use a simple query to find anomalous clients; follow up with NetFlow and EDR on listed hosts.
Common mistake
Escalating on a single alert without corroborating telemetry leads to wasted investigations.
Pro tip
Add host and user context—asset criticality and business owner—to every alert to prioritize response.
