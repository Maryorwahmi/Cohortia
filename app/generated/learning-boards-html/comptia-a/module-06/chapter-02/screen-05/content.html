Module 6 › Chapter 6.2 › SIEM + EDR
One-line claim
Link SIEM queries to EDR context

A SIEM surfaces events at scale; EDR supplies endpoint detail. Use both to validate an incident before blocking or remediation.

Example SIEM query
index=web_logs status=500 | stats count by src_ip
Run this to find clients returning server errors; investigate their hosts in EDR next.
Follow-up steps
  • Identify hosts for each src_ip
  • Pull EDR process trees and recent network connections
  • Cross-reference hashes against validated feeds
Concrete example
Scenario
A SIEM query shows a spike of 500s from three client IPs. NetFlow shows connections to an uncommon external IP. EDR shows a child process creating a outbound connection and a new file hash.
Key Takeaway

Sequence queries and enrichments: SIEM → NetFlow → EDR → external IoC cross-check to avoid acting on uncorroborated alerts.
