Core Concept
Find and remove backdoors and accounts

Search for web shells, remote access tools, unknown SSH keys, and nonstandard service accounts. Correlate authentication logs and privilege changes.

Contain
Disable or restrict suspicious accounts while preserving evidence.
Remove
Delete backdoors only after snapshots and documentation to support investigations.
Scenario card
An attacker created a service account with elevated rights to preserve access. The team must remove access without breaking systems that rely on it.
Checklist:
 - Identify account creation timestamps and owner changes
 - Search configs for account usage (services, scheduled tasks)
 - Snapshot impacted systems for forensics
 - Disable account and rotate any tied credentials
 - After validation, remove account and confirm service continuity
Common mistake

Deleting accounts without checking dependencies can cause outages; always verify references first.
