Comparison
Restore vs Rebuild
Restore from Backup
Fast recovery if backups are immutable, verified, and pre-compromise. Saves configuration and reduces downtime.
Rebuild / Reimage
Safer when compromise is deep or backups may be contaminated. Ensures a clean baseline but costs time.
Decision factors
  • Backup verification and immutability
  • Scope and duration of attacker access
  • Business tolerance for downtime
Example scenario
A public web server is defaced but backups are known-good and immutable. A verified restore can return services quickly. If attackers had administrative access for weeks, prefer rebuild.
Key Takeaway

Base the choice on backup trustworthiness and compromise scope; always harden and validate afterward.
