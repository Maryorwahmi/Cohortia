Definition
What complete eradication requires

Eradication identifies and removes malware, persistence, backdoors, unauthorized accounts, and malicious configurations. It must be evidence-aware and documented.

  • Identify dropped files and injected processes.
  • Locate persistence: scheduled tasks, registry entries, service modifications.
  • Remove backdoors and disable rogue accounts.
  • Patch root-cause vulnerabilities organization-wide.
Example
Finding a web shell triggers a search for altered configs, new admin accounts, and scheduled tasks before restoration.
Common mistake
Deleting one file without checking persistence leads to re-infection.
Forensic checklist (readable panel)
Preserve evidence: timestamps, checksums
Search for:
 - Dropped binaries and scripts
 - Registry startup keys and scheduled tasks
 - Modified configuration files
 - New user accounts and SSH keys
 - Network indicators and unusual listeners
Document removal steps and verification scans
Apply patches to all similar systems
Key Takeaway

Eradication must find persistence and fix root causes; superficial cleanup is inadequate.
