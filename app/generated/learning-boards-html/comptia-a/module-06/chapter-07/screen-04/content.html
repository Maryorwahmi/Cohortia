Module 6 › Chapter 6.7 › What is Detection?
Definition
Recognizing a security event through telemetry and reports
Detection sources differ in coverage and confidence. Combine signals to strengthen your conclusions and reduce false positives.
SIEM: correlates multi-system logs to spot patterns.
EDR: shows process activity, file changes, and endpoint context.
IDS/IPS: inspects network traffic for signatures or anomalies.
User reports & threat feeds: human and external intelligence.
Concrete example
A SIEM flags multiple failed logins, then a successful login from an unusual IP and an outbound connection to a known command-and-control host. EDR shows a suspicious child process and file changes. Together these signals indicate a higher-confidence incident than any single alert alone.
Common misconception: Treating all alerts equally. Not all alerts carry the same weight; context matters.
Why this matters: Early, accurate detection reduces dwell time and limits adversary impact across systems.
Key Takeaway: Combine telemetry and reports to prioritize real incidents.
