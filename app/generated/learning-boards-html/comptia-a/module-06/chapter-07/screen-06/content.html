Module 6 › Chapter 6.7 › EDR — Why endpoint visibility matters
Definition
EDR records process, file, and memory activity on endpoints
EDR turns filesystem and process activity into evidence you can analyze for scoping and root-cause hypotheses.
Process trees and child processes
File modifications and handles
Memory artifacts and live telemetry
Concrete example
EDR shows that a scheduled task spawned cmd.exe which wrote a DLL to a system folder and opened a remote socket. Combined with SIEM outbound flow logs, this confirms active exfiltration attempts.
Misconception: EDR is a single source of truth. It must be correlated with network and log data.
Pro tip: Export process trees and capture volatile memory before rebooting or isolating the host.
Key Takeaway: Use EDR to turn alerts into concrete endpoint evidence for scoping.
