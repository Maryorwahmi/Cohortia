Module 6 › Chapter 6.7 › Scoping the Compromise
Process
Iterative expansion from initial artifact to full blast radius
Use indicators to search other systems and log sources. Verify before taking action to avoid missed hosts.
Search for shared indicators: hashes, C2 IPs, account names, scheduled tasks.
Validate each hit with EDR and network artifacts before marking as affected.
Concrete example
If a server's account shows logins on other servers, query those servers' EDR and logs for the same malicious child processes or C2 connections. Treat the set of confirmed systems as the scope for containment.
Pitfall: assuming the incident is contained to the initial host without evidence.
Key Takeaway: Scoping must be complete before final containment to prevent resurgence.
