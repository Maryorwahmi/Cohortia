Module 6 › Chapter 6.7 › IDS/IPS and Network Telemetry
Definition
IDS/IPS and flow logs reveal communications and signs of lateral movement
Network telemetry corroborates and extends endpoint evidence, and is often decisive for proving data flows to external hosts.
Flow logs: show TCP/UDP connections and volumes.
PCAPs: packet-level records useful for detailed analysis and legal evidence.
IPS actions: can block or rate-limit suspicious traffic.
Concrete example
Network flows show repeated small uploads from a server to an external IP over several hours. Combined with EDR file reads, this pattern indicates staged exfiltration rather than a one-off connection.
Misconception: Blocking C2 immediately is always best. Blocking before capturing flows can remove critical evidence.
Pro tip: If you must block quickly, capture recent flows and a PCAP snapshot first.
Key Takeaway: Preserve network evidence before irreversible network containment steps.
