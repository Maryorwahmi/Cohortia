Module 6 › Chapter 6.3 › Data Normalization
Definition

Canonical schema

Map diverse feed fields to a single schema so correlation and scoring use consistent inputs.

Canonical fields: indicator type, value, first-seen, last-seen, source, confidence.
Preserve raw payloads for audit and provenance.
Conflict resolution: deterministic rules when sources disagree.
Example
Map 'file_sha256' and 'malware_hash' into a single 'hash' field so both match the same indicator.
Misconception
Normalization does not erase original data; it augments it with canonical fields.
