Hypothesis templates

Use this template to write hypotheses: TTP/Indicator, Data sources, Conceptual query, Time window, and Validation criteria.
Hypothesis 1 — Encoded PowerShell
TTP: Encoded PowerShell execution
Data: EDR process creation, SIEM event_id=4688
Query (conceptual): event_id=4688 AND process_name="powershell.exe" AND (command_line LIKE "%-EncodedCommand%" OR length(command_line)>200)
Time window: last 7 days
Validation: parent process, host role, and matching network connections
Hypothesis 2 — Scheduled Task Persistence
Look for scheduled task creations or registry entries for tasks on non-admin workstations.
TTP: New scheduled task created for persistence
Data: Endpoint file & registry logs, SIEM task creation events
Query (conceptual): scheduled_task_create AND host_role!="server" AND creator_account NOT IN admin_list
Validation: associated payload files and task execution timestamps
Hypothesis 3 — Lateral Movement
Detect non-admin user authenticating to multiple sensitive servers in a short period, coupled with remote process execution.
TTP: Lateral movement using admin tools
Data: SIEM authentication logs, EDR remote command events
Query (conceptual): user!=admin AND count(distinct target_host) >= 3 within 15m AND remote_process_exec=true
Validation: correlated process creation and unexpected access patterns
Choose one hypothesis to test, document the outcome, and convert confirmed findings into TIP entries and SIEM rules for future detection.
