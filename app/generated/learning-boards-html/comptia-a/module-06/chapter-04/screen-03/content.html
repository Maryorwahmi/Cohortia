Lab-ready checklist

  • Define a clear hypothesis: who, how, and what you expect to observe.
  • Select minimally invasive queries against SIEM, EDR, and network logs.
  • Document both positive and negative results with timestamps and data scope.
  • Follow legal and privacy rules and have an escalation path for live threats.

Verified outputs

A verified competency is shown when you can produce: a written hypothesis, the set of data sources to query, a conceptual query to test the hypothesis, and an operational item that results (detection rule, TIP entry, or playbook update).
Example: Hypothesis record
Hypothesis: Encoded PowerShell commands launched from user workstations indicate post-exploitation. Data: EDR process creation events and SIEM event_id 4688. Output: New detection rule for encoded PowerShell execution.
