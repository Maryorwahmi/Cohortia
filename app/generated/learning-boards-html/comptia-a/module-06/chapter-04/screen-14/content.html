Module 06 › Chapter 6.4 › Key Concepts
Threat Hunting
A proactive, iterative search for unknown threats that have bypassed defenses.
Dwell Time
The duration an attacker remains undetected; aim to reduce it through hunting.
Hunting Loop
Formulate, collect, analyze, uncover/refine, and enrich to improve detection over time.
Summary takeaway

Build repeatable hunts that feed intelligence and detections so every investigation strengthens future defenses.
