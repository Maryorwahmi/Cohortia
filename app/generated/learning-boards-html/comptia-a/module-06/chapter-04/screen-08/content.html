Conceptual SIEM query

Search for Windows process creation events with powershell and encoded or long command lines.
SIEM_QUERY: event_id=4688 AND process_name="powershell.exe" AND (command_line LIKE "%-EncodedCommand%" OR length(command_line) > 200) | stats count by host, user, command_line
Tune length thresholds and exclude known admin automation accounts to reduce false positives.

EDR conceptual query

Query process creation logs for powershell with encoded flags, then pivot to parent process and child processes for context.
EDR_SEARCH: process_name: "powershell.exe" AND (command_line: "-EncodedCommand" OR command_line_length: > 180) | table timestamp, host, user, parent_process, command_line
Use host tags to limit to developer workstations or sensitive segments as your hypothesis dictates.
Practical tips
  • Start with a multi-day window and then narrow to the hour that looks most suspicious.
  • Pivot from any hits to network connections and scheduled task creation to build an incident timeline.
  • Document queries, thresholds, and why you excluded certain hosts or accounts.
