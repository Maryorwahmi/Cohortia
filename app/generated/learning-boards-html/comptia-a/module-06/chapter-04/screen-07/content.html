Core telemetry and why it matters

EDR
High-fidelity process creation, parent/child relationships, command line, and file activity. Essential for detecting encoded commands or unexpected child processes.
SIEM
Aggregates logs for cross-host correlation. Ensure event types like Windows event 4688 with command-line capture are available before hunting for process command lines.
Network Flows
Detect unusual external destinations, high-volume transfers, or protocol anomalies that indicate lateral movement or exfiltration.
Endpoint Forensics
Scheduled tasks, unusual file archives, and persistence artifacts provide the evidence needed for IR actions.
Checklist before you hunt
  • Verify command-line logging is enabled.
  • Confirm EDR event retention and query performance.
  • Map which hosts have complete telemetry to scope hunts appropriately.
Example
If SIEM lacks command-line data, use EDR process logs for command-line-based hunts. Recording this gap becomes part of your intelligence and operational improvements.
