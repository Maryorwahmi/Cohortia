Module 06 › Chapter 6.4 › Formulate Hypotheses

What makes a good hypothesis?

  • Specific TTP or behavior tied to intelligence.
  • Clear telemetry targets (EDR, SIEM, network logs).
  • Scoped time window and host/user filters to limit noise.
  • Measurable success criteria to confirm or refute.
Analogy
A hypothesis is like a detective's early lead: focused enough to investigate efficiently, not so broad that it goes nowhere.
Example hypothesis
"Encoded PowerShell commands launched from developer workstations during off-hours indicate post-exploitation activity."
Telemetry to query
  • EDR process creation events with command line capture
  • SIEM events mapped to Windows process creation (event_id 4688)
  • Network connections from the host to unusual external destinations
Document
Record the hypothesis, the queries used, time window, and outcome. Negative results are useful intelligence.
