Security

Security controls for DRP

Encrypt backups
Use strong encryption and separate key management; avoid co-located keys and backups.
Restrict recovery access
Enforce least privilege and MFA for all recovery roles and consoles.
Network segmentation
Apply segmentation and monitoring to recovery environments to limit lateral movement.
Forensic readiness
Preserve logs and snapshots before restoration so root cause analysis is possible.
Common mistake
Relaxing security during recovery to expedite operations increases the chance of re-compromise.
Post-restore checklist
  • Verify security groups and firewall rules
  • Rotate credentials used during recovery
  • Run IDS/IPS and vulnerability scans
  • Confirm forensic artifacts are preserved
Key Takeaway
Never relax security for speed; preserve forensics and enforce controls to avoid repeating an incident after recovery.
