Cloud recovery models

Cold — Snapshots
Store encrypted snapshots or images for on-demand restore.
Warm — Pre-provisioned resources
Run minimal instances, replicate data, and scale up during recovery.
Hot — Active/Active
Full workload across regions for near-zero downtime.
Cloud example
Warm standby with continuous database replication and pre-baked machine images meets a 4‑hour RTO and 1‑hour RPO while controlling costs.
Cloud security checklist
  • Encrypt data at rest and in transit
  • Protect keys with secure KMS and limited access
  • Replicate IAM and security groups consistently
  • Test cross-region orchestration and DNS failover
Key Takeaway
Leverage cloud flexibility but validate security and orchestration through tests matching your RTO/RPO targets.
