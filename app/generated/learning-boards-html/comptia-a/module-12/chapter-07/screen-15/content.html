Pre-test quick reference
Three checks to run before you start any exercise
Objective
Is this test type aligned with what we need to validate?
KPIs
Are KPIs defined and will observers capture timestamps and evidence?
Post-test
Is there a hotwash plan, assigned owners, deadlines, and a verification test scheduled?
Final Reminder

A test that lacks objectives, metrics, or a follow-up plan is a rehearsal without consequence. Make each exercise count by measuring and acting on results.
