Module 12 › Chapter 12.6 › Approval Processes
Fast Path
Authorized PR contact publishes a short, pre-approved template acknowledging the issue and giving an update time. This reduces silence and speculation.
When to use
Initial detection, service outages, and non-sensitive updates.
Review Path
Security and legal verify technical details and regulatory obligations before releasing detailed statements about data compromise.
When to use
Any assertion about types of data exposed, root cause, or legal admissions.
Key Takeaway

Design a short fast path for initial transparency and a reviewed path for sensitive technical or legal disclosures.
