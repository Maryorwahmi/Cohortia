Comparison Backup Types

Full, Incremental, Differential

Choose the type or combination that aligns with RPO and RTO tradeoffs.

Full Backup

A complete copy of all selected data. Pros: simplest restore process. Cons: longest runtime, highest storage use. Restore pattern: restore last full.

Incremental Backup

Copies only changes since the last backup of any type. Pros: fastest per job and minimal daily storage. Cons: restore requires last full plus every incremental, increasing complexity.

Differential Backup

Copies changes since the last full backup. Pros: simpler restore (last full + last differential). Cons: differentials grow over the interval between fulls.

Strategy Example
Schedule: weekly full backups on Sunday plus daily differential backups. Why: restore requires only the most recent full and latest differential, keeping restores straightforward while limiting daily backup runtime.
Concrete scenario
A team shares design files that change throughout the week. Weekly fulls keep a complete copy while daily differentials capture ongoing edits and allow a single-step restore to bring the server back to last night’s state.
Misconception

Assuming incrementals always lower cost. They can increase restore effort and risk if not managed.

Pro tip

Schedule periodic fulls to cap differential growth and simplify recovery procedures.
