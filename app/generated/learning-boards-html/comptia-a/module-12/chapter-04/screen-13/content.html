Hands‑on Activity: Secure Backup Strategy

Design a secure backup plan for a file server with RPO 24h, RTO 8h, and strict encryption and ransomware protection requirements.

Step 1 — Choose backup type & schedule
Suggested: Weekly full backup (Sunday 02:00), daily differential backups at 02:00. Rationale: meets 24‑hour RPO and keeps restores to two files (last full + last differential).
Step 2 — Storage map (3‑2‑1)
  • Copy 1 (On‑site, Media 1): NAS for fast restores.
  • Copy 2 (Off‑site, Media 2): Cloud object storage with immutability for durability.
  • Copy 3 (Air‑gapped): Removable encrypted media rotated weekly.
Step 3 — Security measures
Encrypt data at rest with AES‑256 and in transit with TLS. Store keys in KMS with restricted access and MFA. Use a separate backup VLAN and a dedicated backup account with least privilege.
Step 4 — Verification & tests
  • Daily job success/failure alerts and checksum validation.
  • Quarterly isolated full restore tests and integrity checks.
  • Documented restore order and rollback procedures with assigned roles.
When you complete your plan, ensure each copy is tracked in an inventory and that test restores are scheduled and documented as part of the verification milestone.
