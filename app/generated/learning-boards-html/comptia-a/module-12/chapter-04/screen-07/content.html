Comparison Storage Locations

On‑site, Off‑site, Cloud and the 3‑2‑1 Rule

Plan copies across locations and media to reduce correlated risk.

Media & Location Comparison
On‑site (NAS/SAN/Tape)
Fast restores, low latency. Vulnerable to site disasters; use for quick recovery steps in restoration order.
Off‑site (Vaults / Secondary DC)
Protects against local disasters. May increase retrieval time; excellent for long‑term resilience.
Cloud Storage
High durability and geographic redundancy; watch egress costs, sovereignty, and access controls. Use tiering for cost savings.
3‑2‑1 Rule in practice
Example mapping: primary data on production server, second copy on local NAS, third copy in cloud object storage with immutability set for ransomware protection.
Checklist
  • List each backup copy and media type.
  • Note location and retrieval time.
  • Document encryption, keys, and access controls.
Misconception

Cloud is a silver bullet. Without immutability or secure access, cloud backups can be modified or deleted by attackers.

Pro tip

Enable immutable object locks or maintain air‑gapped copies to protect against ransomware.
