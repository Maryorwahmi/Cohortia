Module 10 › Chapter 10.1 › Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Explain why security must span the SDLC

Describe costs of late fixes and how continuous security lowers risk. Verified Competency Milestone

Mnemonic: "Loop" — security is a continuous loop feeding back into requirements.
02
Identify phase-specific security activities

Map activities like abuse cases, threat modeling, SAST, DAST, IaC hardening. Verified Competency Milestone

Mnemonic: "Phase Map" — pin a security check to each phase.
03
Analyze challenges to embedding security

Recognize pitfalls such as late testing, overreliance on tools, or poor documentation. Verified Competency Milestone

Mnemonic: "Pitfall Radar" — list common failure modes and controls.
04
Formulate strategies for security-by-design/default

Propose measurable checkpoints, secure defaults, and stakeholder alignment. Verified Competency Milestone

Mnemonic: "Design Rules" — document secure defaults and enforce them.
