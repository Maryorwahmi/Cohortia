Module 10 › Development
Secure coding checklist
  • Validate and sanitize all inputs.
  • Use parameterized queries to prevent injection.
  • Handle errors without exposing secrets.
  • Use centralized secret management — never hardcode keys.
Tool integration

Enable SAST in the IDE for fast feedback and in CI for gate checks before merging.

Example SAST report
[SAST] Possible SQL injection detected at users.js:45
Suggested fix: use parameterized query with prepared statements.
Common pitfall

Treating SAST findings as cosmetic without assigning ownership or tracking them to resolution.

Key Takeaway

Integrate SAST and secure coding practices into normal development workflows so fixes happen where code is written.
