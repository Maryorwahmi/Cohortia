Module 10 › Design
Threat modeling steps
  1. Identify components and data flows.
  2. Define trust boundaries and assets to protect.
  3. Apply STRIDE to components and flows.
  4. Prioritize threats and propose mitigations.
STRIDE quick map

Spoofing, Tampering, Repudiation, Information disclosure, Denial of service, Elevation of privilege.

Secure design principles
  • Least privilege for services and users.
  • Defense in depth: multiple controls across layers.
  • Secure defaults and compartmentalization.
Example

Designing microservices should include inter-service authentication (mTLS), an API gateway for access control, and explicit trust boundaries in the architecture document.

Key Takeaway

Document trust boundaries and threat model results so design decisions carry forward into development and testing.
