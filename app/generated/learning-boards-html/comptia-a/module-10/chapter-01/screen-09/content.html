Module 10 › Deployment
IaC best practices
  • Define secure configuration baselines in templates.
  • Scan IaC for insecure patterns before deployment.
  • Use parameterization and secrets references — never hardcode keys.
Example

Use the secret manager to inject database credentials at deploy time rather than storing them in IaC files.

Hardening and access

Disable unused services, apply OS and server hardening guides, and enforce least privilege for production access with just-in-time controls.

Key Takeaway

IaC makes secure deployment repeatable; ensure templates and secrets are managed and access to production is restricted.
