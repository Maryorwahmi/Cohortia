Module 10 › Testing
SAST

Analyzes source code for insecure patterns without execution. Best early in development and in IDEs.

Finds: injection patterns, insecure APIs, improper error handling.
DAST

Scans the running application to detect issues visible only at runtime or due to configuration.

Finds: configuration leaks, auth bypasses, exposed endpoints.
Penetration Testing

Simulates an attacker using multiple techniques to validate business logic and chained exploits.

Finds: chained exploits, logic flaws, environment misconfigurations.
Practical integration
  • Run SAST on each code push, DAST in CI before merge, and schedule pen tests periodically.
  • Track findings centrally and assign owners to remediate and verify fixes.
