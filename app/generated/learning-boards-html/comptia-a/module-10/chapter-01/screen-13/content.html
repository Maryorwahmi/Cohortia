Module 10 › Activity
Task steps
  1. Identify components: browser, frontend, backend API, DB, payment gateway.
  2. Draw data flows for login and product browsing and mark trust boundaries.
  3. Apply STRIDE to each component and flow.
  4. Propose mitigations and assign owners.
Example: Node.js Backend API
Spoofing: attacker impersonates client
Mitigation: enforce TLS and strong JWT validation
Tampering: attacker alters payload
Mitigation: input validation and integrity checks
Deliverable

Produce a short document with identified threats, mitigations, and which team member will implement and verify each mitigation.

Key Takeaway

STRIDE-focused threat modeling yields practical mitigations you can prioritize and test in the SDLC.
