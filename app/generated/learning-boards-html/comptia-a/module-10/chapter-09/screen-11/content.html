Module 11 › Chapter 10.9 › PaymentService Scenario
Experiment plan
  1. Hypothesis: PaymentService will gracefully degrade using cache for in-stock items.
  2. Steady state: latency <50ms, error rate <0.1%, success rate >99%.
  3. Injection: proxy InventoryService and simulate latency or outage.
  4. Observe: metrics, logs, downstream effects.
  5. Remediate and repeat.
Small blast radius tip
Start with a single instance or a small percentage of traffic to limit impact while you validate behavior.
Example proxy commands
# Create proxy and add latency
toxiproxy-cli create inventory-proxy -l 0.0.0.0:8081 -u inventory-service:8080
toxiproxy-cli toxic add inventory-proxy -t latency -a latency=2000 -a jitter=500
Configure the PaymentService to call the proxy endpoint during the experiment and make sure monitoring dashboards capture both services' metrics.
