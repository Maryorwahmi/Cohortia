Authentication Example
Use this curl example to request a client credentials token from an auth server. In a test environment print the token, but in production pass it only via secure headers and store secrets in a vault.
curl -X POST https://auth.example.com/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials&client_id=YOUR_CLIENT_ID&client_secret=YOUR_CLIENT_SECRET"

# Use the returned access_token:
# Authorization: Bearer <access_token>
Verification steps: check signature, check exp, check iss and aud, and enforce scopes. If the token lacks necessary scope, the API should deny access.
Operational Notes
  • Store client secrets in a secret manager; never commit to source control.
  • Rotate credentials and monitor for unusual token requests.
  • Limit token scope and lifetime to reduce blast radius.
Key Takeaway

Use client credentials for backend-to-backend auth; never expose secrets in untrusted clients.
