Authorization

RBAC vs ABAC

RBAC assigns roles and maps permissions. ABAC evaluates attributes of user, resource and environment for more nuanced decisions.

RBAC: simple role-permission map.
ABAC: policies using attributes like owner, sensitivity, or time.
Preventing BOLA
When an endpoint accepts an object ID, verify on the server that the authenticated user is authorized to access that object. This may be a direct ownership check, or an ABAC policy evaluation.
Vulnerable pattern: GET /api/v1/users/<id> without checking that the caller owns or can view that ID.
Key Takeaway

Authorize at the object level; do not assume global authentication implies per-resource permission.
