Input Validation

Marshmallow schema example

from marshmallow import Schema, fields, validate

class UserSchema(Schema):
  username = fields.String(required=True, validate=validate.Length(min=3, max=30))
  email = fields.Email(required=True)
  password = fields.String(required=True, validate=validate.Length(min=8))

# Use schema.validate(data) and return 400 on errors
This example enforces types and lengths before reaching business logic. Log validation errors internally but keep client errors generic.
Output Encoding
When your API returns values that a browser renders, ensure that those values are encoded for the target context, such as HTML or JSON contexts, to avoid client-side XSS.
Common mistake: trusting client-side validation only. Server must validate every request.
Key Takeaway

Validate inputs with a schema and encode outputs to defend against injection and XSS.
