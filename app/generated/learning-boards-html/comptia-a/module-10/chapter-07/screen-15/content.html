API
A set of rules and endpoints for applications to communicate and exchange data.
OWASP API Top 10
A prioritized list of common API-specific risks and guidance to remediate them.
OAuth 2.0 / OIDC
Standards for delegated authorization and identity verification; prefer them over custom token schemes.
Summary Takeaway

Treat APIs as critical security boundaries: verify tokens, enforce per-resource authorization, validate inputs, and protect the edge with rate limits and gateways.
