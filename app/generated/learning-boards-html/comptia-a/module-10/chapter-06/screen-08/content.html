Architecture
Pod Security Standards (PSS)
Profiles: Privileged → Baseline → Restricted
securityContext:
  runAsNonRoot: true
  runAsUser: 1000
  seccompProfile:
    type: RuntimeDefault
containers:
- name: app
  securityContext:
    allowPrivilegeEscalation: false
    capabilities:
      drop: ["ALL"]
    readOnlyRootFilesystem: true
These settings reduce kernel-facing privileges and restrict what processes inside the pod can do.
RBAC & Network Policies
Control API actions and network segmentation
  • • RBAC: grant least privilege to service accounts and avoid cluster-admin roles unless required.
  • • NetworkPolicy: deny by default and allow only specific ingress/egress between pods.
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: deny-all-ingress
  namespace: default
spec:
  podSelector: {}
  policyTypes:
  - Ingress
  ingress: []
Real-world connection
Enforce these controls via admission controllers and automation to keep clusters consistent.
Common Mistake
Relying only on RBAC without network segmentation still allows lateral movement between pods.
Key Takeaway

Use PSS, RBAC, and Network Policies together to limit capabilities, access, and network reach.
