What to Remember
Containerization
Package apps and dependencies into portable images, but remember they share the host kernel and need extra host-focused controls.
Serverless Computing
The provider manages servers; you must secure function identity, inputs, and secret access to avoid large blast radii.
Kubernetes Security Controls
PSS, RBAC, and Network Policies work together to limit what workloads can do, who can control them, and how they communicate.
Final takeaway

Automate image checks, enforce cluster policies, and apply least-privilege IAM plus input validation to keep cloud-native systems secure.
