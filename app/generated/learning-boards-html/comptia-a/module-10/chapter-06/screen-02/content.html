Learning Objectives

Each objective links a practical skill to why it reduces risk in cloud-native deployments.

01
Identify container and serverless attack vectors

Learn to spot where shared kernels, image supply chains, and permissive IAM expand attacker options. This matters because defenses must map to the actual attack surface.

Verified Competency Milestone
02
Implement Dockerfile best practices

Apply minimal base images, multi-stage builds, non-root users, and image scanning in CI/CD. These reduce the size of the attack surface and catch known vulnerabilities earlier.

Verified Competency Milestone
03
Configure Kubernetes controls

Enforce Pod Security Standards, RBAC, and Network Policies to limit capabilities and network reach of pods. Proper configuration prevents privilege escalation and lateral movement.

Verified Competency Milestone
04
Deploy runtime monitoring and response

Use runtime tools and centralized logging to detect suspicious process or network behavior in containers and serverless invocations. This shortens detection and response time when incidents occur.

Verified Competency Milestone
