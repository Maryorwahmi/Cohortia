What to check
Dockerfile Checklist
Minimal base, multi-stage, non-root, image scanning and signing.
Cluster Checklist
PSS enforced, RBAC scoped, Network Policies deny-by-default.
Serverless Checklist
Least-privilege IAM, input validation, secrets in vaults, API Gateway protections.
Closing note

Automate these checks in CI/CD and admission flows so security is continuous and auditable.
