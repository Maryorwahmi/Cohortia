Container and Serverless Security

Practical controls for containers and serverless: image hygiene, Kubernetes admission and network controls, and least-privilege serverless design so attacks have minimal impact.

What you will do
Hardening steps you can apply in CI/CD and cluster admission to reduce risk from images, pods, and functions.
Image Hygiene
Minimal base images, multi-stage builds, scanning and signing.
Cluster Controls
PSS, RBAC, Network Policies to limit privileges and traffic.
Runtime Detection
Use Falco, Cilium, and centralized logging for alerts and response.
Serverless
Least-privilege IAM, input validation, and secrets managers.
Explore Key Topics
A quick map of the lesson sequence and why each piece matters.
Image Hardening
Reduce attack surface with small images and remove build tools before runtime.
Cluster Policies
Use PSS, RBAC, and Network Policies to control capabilities and traffic between pods.
Serverless IAM
Grant only the permissions each function needs and validate all inputs.
