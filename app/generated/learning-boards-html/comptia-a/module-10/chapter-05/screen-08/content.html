Definition DAST
What DAST finds
  • Runtime vulnerabilities and authentication/authorization issues.
  • Configuration problems such as directory listing or insecure headers.
  • Business logic flaws that depend on runtime state or flows.
Example
Automated DAST finds a session fixation vulnerability in staging; the team adds a test and fixes session handling before production deploy.
Integration notes
  • Run DAST after deployment to a realistic staging environment.
  • Use authenticated scans and seed test data to exercise protected paths.
  • Feed DAST findings into your issue tracker and link to reproduction steps.
Common Mistake

Running DAST against an unrealistic environment or without authentication yields false positives and missed findings.
