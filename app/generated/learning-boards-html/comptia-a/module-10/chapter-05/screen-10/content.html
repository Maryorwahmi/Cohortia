Definition Container Image Scanning
When to scan
Run image scans immediately after the image build and before pushing to registries. Integrate with CI so pushes are blocked on critical findings.
Example
Trivy or Clair identifies a critical CVE in a base image package; pipeline blocks push and suggests base image upgrade.
Best practices
  • Prefer minimal base images and regularly rebuild them to pick up patches.
  • Fail pushes on critical/high vulnerabilities; track medium/low via tickets.
  • Scan both build-time and runtime images periodically to catch late fixes.
Common Mistake

Relying only on the CI-time scan and ignoring periodic scans can miss newly published CVEs affecting older images.
