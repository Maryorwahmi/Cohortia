This sample shows the typical SAST finding and guidance. The tool provides file and line context so the developer can correct the issue before merge.
What SAST does and does not do
  • Finds: Code patterns, insecure API usage, possible injection sources, hardcoded secrets.
  • Does not find: Runtime misconfigurations or issues that only appear when the application runs, which are better covered by DAST or runtime tools.
Pro Tip

Integrate SAST early and tune rule sets for your codebase to minimize false positives and keep developer trust.
