Architecture Secrets Management
Secure flow
  1. Secrets stored centrally in a managed vault with access controls.
  2. CI/CD jobs request short-lived tokens to retrieve secrets at runtime.
  3. Applications get secrets injected at deployment or via platform integration.
  4. Rotate and audit secrets regularly and revoke compromised tokens.
Example: Replace hardcoded API keys with a vault reference and update deployment scripts to fetch secrets at start time.
Practices & Pitfalls
  • Never store plaintext secrets in source control.
  • Use least privilege and short-lived credentials for automation agents.
  • Audit access and rotate secrets on a schedule or when incidents occur.
Common Mistake

Using encrypted files in repos without automated access controls still risks exposure through leaked keys or misconfiguration.
