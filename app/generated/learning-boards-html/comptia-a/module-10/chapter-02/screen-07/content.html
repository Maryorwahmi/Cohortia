Module 10 › Chapter 10.2 › Applying STRIDE
Step-by-step
  1. List DFD elements and label data types.
  2. For each element, run STRIDE prompts and record findings.
  3. Annotate assumptions and confidence levels.
  4. Map each finding to candidate mitigations.
This creates a traceable record from threat to mitigation.
Concrete Example
API flow: client sends JWT to gateway. STRIDE check: Spoofing — can token be reused? Tampering — is transport encrypted? Info Disclosure — what fields are returned?
Suggested mitigations: token expiry and rotation, TLS enforced, field-level filtering, and scoped tokens per caller.
Common Mistake

Failing to record confidence and assumptions makes later prioritization difficult; always add context to findings.
