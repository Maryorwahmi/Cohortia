Layer Examples
Perimeter: firewalls, network ACLs
Edge: API gateway, rate limiting, WAF
Application: input validation, authz checks
Data-at-rest: encryption and access controls
Secure Defaults
Deploy templates with TLS enforced, admin access disabled by default, and unnecessary ports closed.
Balance defaults with usability to avoid creating incentives for dangerous workarounds.
Common Mistake

Relying on a single control as a silver bullet weakens defense in depth; document and test each layer.
