Module 10 › Chapter 10.2 › UserProfileService
Checklist
  • DB permissions: only SELECT, INSERT, UPDATE for the service account.
  • Inter-service tokens: scoped and short-lived; send only required fields.
  • Gateway: authentication, input validation, rate limiting, and logging.
  • Data protection: encryption at rest for sensitive fields and field-level filtering for outputs.
Implementation Example
When OrderService requests shipping address, UserProfileService returns only address fields mapped to a scoped token; hashed passwords are never returned.
Automate role reviews and credential rotation so least privilege is maintained over time.
Key Takeaway

Translate each threat to a measurable control and update the threat model so mitigation choices are auditable.
