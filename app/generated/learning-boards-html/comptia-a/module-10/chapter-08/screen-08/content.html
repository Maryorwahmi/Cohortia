Module 10 › Chapter 10.8 › TPM vs HSM vs PUF
TPM
Secure cryptoprocessor for endpoints, stores keys, performs measurements, and resists extraction.
HSM
High-assurance module for root key storage and signing; used in gateways or cloud services.
PUF
Derives unique, unclonable identifiers from silicon variation to avoid storing secret keys in flash.
Deployment pattern
Endpoint devices: TPM/PUF. Gateways/cloud: HSM for signing and root management.
Misconception
No single hardware feature removes the need for lifecycle and update security.
