Module 10 › Chapter 10.8 › Resource Constraints & Cryptography
Process

Select cryptography that fits

Start with standards
Choose well-vetted ciphers like AES-128 or ChaCha20-Poly1305; avoid custom algorithms.
Use hardware accelerators
Offload crypto when available to reduce CPU and power costs.
Protocol pairing
MQTT over TLS or CoAP over DTLS provide transport-level security suited to IoT.
Concrete example
An outdoor sensor using CoAP should implement DTLS with a supported cipher suite and use a gateway if the device cannot perform the handshake securely on its own. The gateway can manage certificates and offload heavy operations.
// Example configuration (illustrative)
protocol: coap
transport: dtls
cipher: aes-128-gcm
identity: device-x509-cert
notes: 'Use hardware crypto if available; avoid custom ciphers.'
Key takeaway
Standard algorithms + hardware acceleration minimize risk while conserving resources.
Misconception
Shorter keys or home-grown ciphers are not reliable optimizations.
