Process Flow

Boot stages and verification

HRoT (immutable)
Initial trust anchor that contains public key checks or fused values.
Boot ROM
Verifies bootloader signature before transferring control.
Bootloader & Kernel
Each validates the next stage's signature; failure leads to halt or recovery.
Example & Notes
A signed firmware image must include metadata and a signature verifiable against a public key rooted to HRoT. Protect signing keys in an HSM at the vendor, and ensure rollback protection so older, vulnerable images cannot be reinstalled.
Pro tip
Rotate signing keys carefully and maintain a secure recovery image signed by the same root to avoid unsafe fallbacks.
Pitfall
An unsecured recovery mechanism can be exploited to bypass Secure Boot.
