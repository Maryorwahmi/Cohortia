Module 10 › Chapter 10.8 › Hardware Security Features
Definition

Key hardware features explained

Hardware Root of Trust (HRoT)
Immutable starting point that verifies boot chain integrity.
Secure Boot
Cryptographically enforces that only trusted firmware runs by verifying signatures at each stage.
TPM / HSM / PUF
TPMs and HSMs protect keys; PUFs provide unclonable identity without storing keys in flash.
Concrete scenario
A field gateway with an HSM stores root signing keys and performs firmware signature verification for downstream sensors. If sensors are too weak to verify signatures, the gateway verifies and only allows signed images to be forwarded for installation.
Why this matters
Hardware protections make key extraction and firmware tampering harder, reducing risk of persistent compromise.
Misconception
Hardware features are not a silver bullet; they must be integrated into a complete lifecycle plan.
