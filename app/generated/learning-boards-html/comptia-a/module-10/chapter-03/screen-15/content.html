Module 10 › Chapter 10.3 › What to Remember
Parameterize
Replace string-built queries with bound parameters everywhere.
Encode
Escape output for HTML, attributes, and script contexts to stop XSS.
Automate
Use SAST in CI and DAST in staging to continuously find regressions.
Closing prompt
Identify one file in your repository that uses string SQL building or unescaped template output. Prepare a single-commit fix that parameterizes the SQL or enables escaping and include a brief remediation note referencing the OWASP risk.
