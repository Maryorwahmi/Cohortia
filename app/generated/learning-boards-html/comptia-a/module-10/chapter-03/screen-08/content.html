Module 10 › Chapter 10.3 › Broken Authentication
Problem vs Best Practice
Weak: Plain or fast hashing
Using MD5 or SHA1 for passwords stores reversible or fast hashes that attackers can brute force.
Safe: Adaptive hashing
Use bcrypt, scrypt, or Argon2 with unique salts to slow attacker attempts and protect stored credentials.
Session & flow controls
  • Generate cryptographically random session IDs and rotate them on privilege change.
  • Invalidate sessions on logout and after password changes.
  • Implement MFA and rate-limiting to reduce brute force risk.
  • Return generic login errors to avoid username enumeration.
Check your implementation
Review password storage algorithms, session token entropy, and reset flows for information leakage.
