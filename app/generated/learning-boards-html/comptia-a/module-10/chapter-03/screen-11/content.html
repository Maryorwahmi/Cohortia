Module 10 › Chapter 10.3 › SAST, DAST, IAST
SAST
Analyzes source without running. Good at spotting injection patterns and insecure crypto early in development.
DAST
Scans running applications by simulating attacks. Finds configuration and runtime interaction issues.
IAST
Runs inside the application, combining code context and runtime data to reduce false positives and provide precise traces.
Recommended pipeline
  1. Run SAST in pre-merge hooks to catch common code patterns early.
  2. Run DAST against a staging deployment to find runtime issues.
  3. Use IAST for critical services during integration testing to get accurate traces.
