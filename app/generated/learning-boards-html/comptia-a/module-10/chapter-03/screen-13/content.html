Review the vulnerable Flask code. Identify injection and XSS, implement fixes, and validate with scans and testing.

# - SQL injection in submit_feedback

# Deliverable 2: Provide corrected code and a short remediation note
Remediation checklist
  • Replace concatenated SQL with parameterized queries and validate inputs.
  • Enable template auto-escaping or apply explicit escaping for user content.
  • Run SAST and DAST scans and include results in the PR description.
Key Takeaway

Document the vulnerability and the fix clearly. Validation and scans prove the remediation.
