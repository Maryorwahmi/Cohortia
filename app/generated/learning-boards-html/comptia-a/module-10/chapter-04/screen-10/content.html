Module 10 › Chapter 10.4 › SCA in CI/CD
Typical pipeline steps
  1. 1. Run SCA scan on manifest files and artifacts.
  2. 2. Generate SBOM and attach to build artifacts.
  3. 3. Evaluate findings against policy thresholds.
  4. 4. Fail build or create remediation ticket for high-risk items.
Developer feedback
Provide clear remediation steps such as upgrade targets or suggested workarounds so developers can act quickly when builds fail on policy violations.
Policy tuning
Start with conservative thresholds for production branches and more permissive checks for developer branches. Refine rules to reduce noise and focus on high-impact findings.
Pro tip
Attach the SBOM to each build artifact so incident response can query deployed inventories quickly.
