Module 10 › Chapter 10.4 › Dependency Trees
Hierarchy view
Dependency tree analysis reveals direct and transitive packages. SCA tools generate these trees so you can trace a vulnerable item back to the top-level project that includes it.
Example
A top-level web framework may indirectly include a logging library with a CVE. Fixing the top-level dependency may require upgrading the framework or applying a patch.
Action
Use the dependency graph to identify which direct dependency brings in the vulnerable transitive package and then plan an upgrade or replacement path.
Policy implication
Policies should consider transitive components when specifying acceptable licenses, age thresholds, and vulnerability tolerances. Do not limit checks to direct dependencies only.
Tip
Automate dependency-tree exports in CI so you always have the transitive map for incident queries and audits.
