Learning Objectives
From enablement to SIEM integration — measurable skills you will gain.
Learn → Understand → Apply → Master
01
Enable and configure native logs
Identify CloudTrail, Activity Logs, and Cloud Audit Logs, enable them across regions, and secure log storage with encryption and retention.
VERIFIED COMPETENCY MILESTONE
02
Implement centralized monitoring
Deploy CSPM and CASB to continuously assess posture and control SaaS access; feed findings into central detection workflows.
VERIFIED COMPETENCY MILESTONE
03
Analyze cloud-native logs
Read JSON logs, build correlation rules across CloudTrail, VPC Flow Logs and provider findings to detect anomalies and multi-stage attacks.
VERIFIED COMPETENCY MILESTONE
04
Design monitoring for containers & serverless
Select collection agents, configure function telemetry, and ensure IAM roles and image scanning are part of monitoring plans.
VERIFIED COMPETENCY MILESTONE
