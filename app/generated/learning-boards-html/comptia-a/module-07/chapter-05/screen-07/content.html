Module 7 › Chapter 7.5 › CSPM & CASB
Cloud Security Posture Management
Continuously scans for misconfigurations, compliance violations, and security risks against benchmarks.
Detects
Public buckets, permissive IAM, missing encryption, insecure network rules.
Action
Generate findings and recommended remediations that should be streamed to your SIEM or ticketing pipeline.
Cloud Access Security Broker
Monitors SaaS access, enforces policies, and prevents data exfiltration to unauthorized services.
Detects
Unusual user uploads, shadow IT usage, suspicious OAuth tokens.
Action
Block or alert on risky transfers and forward logs to SIEM for correlation with CSPM findings.
Scenario
CSPM flags an exposed storage resource while CASB logs show a user copying files to an unsanctioned service. Correlating both signals raises the confidence of an exfiltration incident.
