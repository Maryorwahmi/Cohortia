Module 7 › Chapter 7.5 › Log Analysis
Normalization & enrichment
Map provider-specific fields to common columns: timestamp, actor, action, resource, source IP.
Enrichments
Resolve IP geolocation, resolve IAM identities to owners, and append vulnerability metadata for launched instances.
Sequence rules
Create rules that look for chained events within short windows, such as CreateUser → AssumeRole → DeleteSnapshot.
Concrete example
Timestamp: 2024-01-01T12:01:02Z
eventName: CreateUser
userIdentity: unknown
sourceIPAddress: 203.0.113.5

Timestamp: 2024-01-01T12:03:10Z
eventName: AssumeRole
userIdentity: temp-role

Timestamp: 2024-01-01T12:05:50Z
eventName: DeleteSnapshot
userIdentity: temp-role
Investigation prompt
Correlate these events with VPC Flow Logs for the instance that executed outbound connections and with any GuardDuty findings for unusual activity.
Key takeaway
Sequences and enrichment increase detection confidence; high-volume single-event alerts often produce noise.
