Module 7 › Chapter 7.5 › Enable & Secure Logs
Step-by-step
  1. Enable CloudTrail in all regions; select management and data events for critical S3 buckets.
  2. Route CloudTrail to a dedicated S3 bucket; enable server-side encryption and restrict writes to the CloudTrail service principal.
  3. Stream CloudTrail to CloudWatch Logs and create metric filters for sensitive API events, then attach alarms and notifications.
Test
Perform a controlled IAM policy change and verify the metric filter triggers the CloudWatch Alarm and the log file appears in the S3 bucket.
S3 bucket policy (sample)
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AWSCloudTrailAclCheck",
      "Effect": "Allow",
      "Principal": {"Service": "cloudtrail.amazonaws.com"},
      "Action": "s3:GetBucketAcl",
      "Resource": "arn:aws:s3:::cloudguard-cloudtrail-logs-1234567890"
    },
    {
      "Sid": "AWSCloudTrailWrite",
      "Effect": "Allow",
      "Principal": {"Service": "cloudtrail.amazonaws.com"},
      "Action": "s3:PutObject",
      "Resource": "arn:aws:s3:::cloudguard-cloudtrail-logs-1234567890/AWSLogs/1234567890/*",
      "Condition": {"StringEquals": {"s3:x-amz-acl": "bucket-owner-full-control"}}
    },
    {
      "Sid": "DenyUnencryptedObjectUploads",
      "Effect": "Deny",
      "Principal": "*",
      "Action": "s3:PutObject",
      "Resource": "arn:aws:s3:::cloudguard-cloudtrail-logs-1234567890/*",
      "Condition": {"StringNotEquals": {"s3:x-amz-server-side-encryption": "AES256"}}
    }
  ]
}
CloudWatch metric filter (pattern)
{ ($.eventName = "DeleteRolePolicy") || ($.eventName = "DeleteUserPolicy") || ($.eventName = "DeleteGroupPolicy") || ($.eventName = "DetachUserPolicy") || ($.eventName = "DetachRolePolicy") || ($.eventName = "DetachGroupPolicy") || ($.eventName = "PutUserPolicy") || ($.eventName = "PutRolePolicy") || ($.eventName = "PutGroupPolicy") }
Key takeaway
Templates accelerate safe configuration. Always replace example ARNs and test end-to-end delivery and alerting.
