Module 7 › Chapter 7.5 › Containers & Serverless
Containers
Collect runtime, application, and orchestration logs; tag with pod and node metadata for context.
Collectors
Fluentd, Fluent Bit, and sidecars to forward logs to cloud logging or SIEM.
Kubernetes audit logs
Capture control-plane changes like role bindings, deployments, and API server requests for security investigations.
Serverless
Functions emit logs per invocation to provider logging services; monitor invocation counts, errors, and IAM roles used.
Security actions
Enforce least privilege for function roles, scan images for vulnerabilities, and monitor network policies for Pod-to-Pod or function-to-service traffic.
Example check
Confirm Fluent Bit adds pod labels and namespace fields so logs can be filtered and correlated in your SIEM by application owner and environment.
