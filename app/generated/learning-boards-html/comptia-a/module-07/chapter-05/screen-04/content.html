What the model means for monitoring
Define responsibilities for collecting and protecting telemetry.
Provider responsibilities
  • Operate the physical infrastructure and host-level controls.
  • Emit platform and control-plane logs that you can consume.
Customer responsibilities
  • Enable and configure logging services across regions.
  • Secure log storage, set retention, and integrate logs into detection pipelines.
Common misconception
Believing provider-managed threat services remove the need to configure your own logging. They help but cannot compensate for disabled or misrouted logs.
Concrete scenario
An attacker uses stolen keys to launch instances. Cloud provider logs capture API calls, but unless you enabled account-wide API logging and routed logs to immutable storage, you may not retain evidence for investigation.
Why this matters
Detecting and reconstructing incidents depends on your configuration choices; logs are the forensic trail.
