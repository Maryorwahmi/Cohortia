Module 7 › Chapter 7.5 › Provider Logs
AWS telemetry
CloudTrail
API activity logging for governance and auditing; enable management and S3 data events where needed.
VPC Flow Logs
Network flow metadata for traffic analysis and anomaly detection; useful to detect unexpected outbound traffic.
CloudWatch & GuardDuty
Application logs and provider threat detection; both feed into your SOC pipelines when integrated correctly.
Azure & GCP telemetry
Azure Activity Logs
Control-plane events for subscription-level changes; pair with Monitor for resource logs and Defender for Cloud for posture findings.
GCP Audit & Cloud Logging
Administrative and data access events plus centralized logging across services; integrate with Security Command Center for findings.
Routing & storage
Deliver logs to encrypted storage, apply strict write permissions for the logging service principal, and set retention aligned to compliance needs.
Key takeaway
Treat provider services as sources to configure and secure; missing or regional gaps are the most common source of blind spots.
