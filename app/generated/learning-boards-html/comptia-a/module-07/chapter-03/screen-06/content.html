Module 7 › Chapter 7.3 › IDS/IPS Tuning
Tuning Steps
1.
Monitor in passive mode
Collect alerts for a trial period to understand baseline noise.
2.
Classify alerts
Label alerts as true positives, false positives, or low-fidelity noise.
3.
Adjust rules
Apply thresholds, create exceptions for trusted scanners, and refine signatures.
4.
Enable prevention selectively
Move high-confidence rules to IPS in controlled segments with rollback plans.
Example & Measurement
Example: A vendor vulnerability scanner triggers many port-scan alerts. Whitelist its IPs and reduce severity for that signature. Measure success by tracking false positive rate, mean time to investigate alerts, and number of incidents prevented after enabling IPS rules.
Common Mistake

Disabling noisy signatures without analysis removes detection capability. Prefer exceptions and thresholding.
