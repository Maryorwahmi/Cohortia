Hunt Example — DNS Tunneling
  1. Hypothesis: an internal host uses DNS to exfiltrate data.
  2. Query Zeek DNS logs for long query labels and high volumes per host.
  3. Cross-reference flows for periodic outbound connections and byte counts.
  4. Trigger targeted FPC for suspects and analyze payloads in Wireshark.
Operational Tips
Keep hunts documented with queries and findings, escalate confirmed compromises, and convert successful hunts into SIEM detections to automate future discovery.
Key Takeaway

Hunting is proactive, hypothesis-driven, and improves automated detection when findings are translated into rules and queries.
