Module 7 › Chapter 7.3 › Tcpdump Capture
Terminal Example
sudo tcpdump -i eth0 -s 0 -w suspicious_traffic.pcap 'host 10.0.1.50 and host 203.0.113.10 and port 4444'
Explanation: -i selects the interface. -s 0 captures full packets. -w writes to disk. The BPF expression limits capture to the two hosts and the given port to avoid excess data.
What to inspect in Wireshark
  • Protocol type on the port and whether it matches expectations (TCP, UDP, or tunneled data).
  • Payload content if unencrypted: look for command strings, base64 blocks, or file fragments.
  • Connection patterns: regular beacons, large uploads, or unusual TLS certificate info.
Key Takeaway

Narrow captures reduce exposure and speed analysis. Use flow data to guide precise tcpdump filters.
