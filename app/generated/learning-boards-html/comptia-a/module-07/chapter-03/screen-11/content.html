Module 7 › Chapter 7.3 › Wireshark Analysis
Step-by-step
  1. Filter by host and port to isolate relevant packets.
  2. Follow the TCP/UDP stream to view application-layer content.
  3. Inspect payloads for commands, file transfers, or encoded data.
  4. Check TLS metadata if encrypted: SNI, certs, and ciphers.
  5. Export evidence and note capture metadata for chain-of-custody.
Example & Misconception
Example: an HTTP POST with base64 content captured in a stream suggests data exfiltration. Misconception: encrypted traffic is harmless — in fact, metadata and timing patterns still provide investigative leads and should be correlated with flow and IDS data.
Pro Tip

Record capture parameters and time windows alongside exported packets to preserve context for later forensic review.
