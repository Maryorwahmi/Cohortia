Triage Checklist
  • Collect baseline metrics: average bytes per hour, common peers, and usual ports.
  • Detect beaconing: regular, small, periodic outbound flows to a single IP.
  • Detect scanning: many destinations or ports in a short interval.
  • Detect exfiltration: unusually large outbound bytes to external hosts.
Example Query Pattern
Query flows for a host and time range, sort by bytes and destinations, then inspect inter-arrival times. If you see small flows every five minutes to the same external IP, suspect beaconing and escalate for packet capture.
Pro Tip

Automate detection for periodicity and high-volume outbound flows to unknown external peers, but always enrich with DNS and asset context before action.
