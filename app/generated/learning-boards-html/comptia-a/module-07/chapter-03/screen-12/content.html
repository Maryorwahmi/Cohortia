Module 7 › Chapter 7.3 › NSM + SIEM
Integration Patterns
Ingest: IDS/IPS alerts and flow records in near-real time to enable correlation.
Index: store metadata and extracted indicators from FPC rather than raw packets in the SIEM.
Link: reference archived packet stores (Arkime-style) from SIEM incidents for retrieval.
Example Correlation
An IDS alert for a suspicious upload correlates with a web server access log entry, an endpoint creating a suspicious process, and flows showing outbound connections shortly after. Correlation creates a high-confidence incident, enabling faster containment.
Key Takeaway

Use SIEM for correlation and orchestration, but keep raw packet stores separate and access-controlled for forensic retrieval.
