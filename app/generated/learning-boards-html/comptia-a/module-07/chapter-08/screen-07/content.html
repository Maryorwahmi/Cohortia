Tool Overview

Reading imports & functions

Identify functions of interest by their imported APIs, then explore cross-references and call graphs to see how those APIs are used.
What to look for
  • CreateRemoteThread, WriteFile, InternetOpenUrl as red flags.
  • Call graphs showing network or file routines used widely.
  • Strings decoded at runtime or large blocks used for configuration.
Pro Tip
Label discovered functions and export an import list for documentation. Use these labels to set debugger breakpoints later.
Key Takeaway

Imports and function references guide your reverse-engineering focus and aid breakpoint placement during dynamic analysis.

Concrete Scenario
You find a function that resolves a domain, opens an HTTP connection, then writes to disk. This indicates network-assisted payload retrieval. Mark these points for API monitoring and network capture in the VM.
Common Mistake
Over-trusting decompiler output. Always cross-check pseudo-code against assembly and runtime behavior before forming conclusions.
