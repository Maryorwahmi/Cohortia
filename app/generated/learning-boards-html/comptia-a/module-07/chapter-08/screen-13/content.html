Module 8 › Chapter 7.8 › Invoice.exe Workflow
Hands-on Activity

Static → Dynamic → IoC

Follow a conservative, repeatable workflow: triage statically, prepare an isolated VM, execute with monitors, and extract IoCs.
Static steps
  • File/PE identification and SHA256 hashing.
  • Run strings/FLOSS and document suspicious strings.
  • Inspect import table for ws2_32, advapi32, kernel32 indicators.
Dynamic steps
  • Snapshot VM, enable FakeNet, start Process Monitor and Wireshark.
  • Execute sample, capture file, registry, process, and network events.
  • Record and export captures and logs for reporting.
Key Takeaway

A documented, repeatable workflow produces reliable IoCs and preserves evidence for incident response.

Example IoCs to extract
  • SHA256 of invoice.exe and any dropped payloads.
  • Observed C2 domains or IP addresses and ports.
  • Created registry Run keys and modified file extensions used for encryption.
Common Mistake
Uploading sensitive samples to public sandboxes can leak data and expose your environment. Keep all handling inside your isolated lab.
