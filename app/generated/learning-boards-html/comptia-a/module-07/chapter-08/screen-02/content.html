Learning Objectives

Learn the core skills needed to triage, execute, and reverse engineer malicious code safely.

01
Differentiate static and dynamic analysis

You will explain the benefits and limits of both approaches and choose the right method for safe triage and deeper inspection. Verified Competency Milestone

02
Set up a safe, isolated analysis VM

You will configure snapshots, network simulation, and monitoring tools so execution cannot reach production systems. Verified Competency Milestone

03
Use static analysis tools

You will extract strings, identify file types and imports, and interpret dependency tables to form hypotheses. Verified Competency Milestone

04
Perform dynamic analysis and extract IoCs

You will observe process and network behavior, log API calls, and capture artifacts to feed detection platforms. Verified Competency Milestone
