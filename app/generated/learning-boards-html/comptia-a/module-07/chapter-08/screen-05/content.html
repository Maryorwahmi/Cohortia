Process Flow

Isolated VM Setup

Step 1 — Create clean VM and snapshot
Install OS, apply no corporate network connections, and take a baseline snapshot to revert after each run.
Step 2 — Install monitoring
Process Monitor/Explorer, Wireshark, API monitoring, and debuggers inside the VM capture the runtime activity.
Step 3 — Configure network simulation
Use FakeNet-NG or INetSim to answer DNS and HTTP requests so malware cannot reach real C2 servers.
Key Takeaway

Multiple snapshots and simulated network responses allow safe experimentation and repeatable evidence collection.

Checklist: Before execution
  • Confirm VM network isolation and snapshot saved.
  • Start Process Monitor and Wireshark captures.
  • Enable FakeNet/INetSim if network observation is required.
  • Place benign test files to detect encryption or modification.
Common Mistake
Leaving shared folders or host integration enabled can allow malware to escape the VM. Disable these features before running samples.
Try This
Create a snapshot, then intentionally modify a test file after running a sample. Revert to confirm snapshot integrity.
