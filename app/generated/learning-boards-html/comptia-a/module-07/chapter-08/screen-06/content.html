Module 8 › Chapter 7.8 › Static Tools
Definition

Key static techniques

File type identification
Use file or PEiD to confirm format and detect packers before deeper analysis.
String extraction
Extract printable text with strings or FLOSS to locate potential URLs, file names, and API references.
Dependency analysis
Inspect import tables to understand high-level capabilities like networking or crypto.
Key Takeaway

Static tools give safe, quick clues. Treat findings as hypotheses to confirm with dynamic or reverse-engineering steps.

Example: Strings Output
> strings invoice.exe
RANSOM_NOTE.txt
Bitcoin: 1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa
CreateFileW
WriteFile
ws2_32.dll
http://malicious.example/update
This output suggests a ransom note, networking, and file manipulation — useful leads for triage.
Common Mistake
Assuming strings are always meaningful. Attackers encrypt strings; use disassembly to confirm if strings are decoded at runtime.
