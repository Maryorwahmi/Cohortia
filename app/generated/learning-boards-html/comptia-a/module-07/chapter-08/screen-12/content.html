Practice Workflow

Collecting and prioritizing IoCs

Gather hashes, network indicators, file paths, registry keys, and mutexes, then provide contextual evidence for each item.
Recommended priorities
  • SHA256 and other file hashes for exact identification.
  • C2 domains/IPs and specific URLs observed in network captures.
  • Registry keys used for persistence and file extensions of encrypted files.
Pro Tip
Include sample Process Monitor lines or Wireshark packet excerpts to help detection engineers reproduce detection logic.
Key Takeaway

Actionable IoCs are precise, reproducible, and accompanied by context so they can be deployed reliably in detection systems.

Example Report Snippet
SHA256: <hash> — Created README.txt at C:\\Users\\Public\\README.txt — Contacted bad.example on 198.51.100.23:8080 — Created Run key at HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run
Common Mistake
Publishing noisy indicators without context results in detection rules that trigger on benign behavior. Always provide supporting evidence with IoCs.
