Module 8 › Chapter 7.8 › Key Concepts
Static Analysis
Examining files without execution to extract strings, imports, and metadata for initial triage.
Dynamic Analysis
Execute in an isolated VM to observe runtime behavior, network traffic, and system modifications.
Reverse Engineering
Use debuggers and disassemblers to unpack obfuscation and reveal precise program logic and routines.
Summary
Combine these approaches to produce high-quality IoCs and defensive actions for SIEM and EDR systems.
