Core Concept

Static vs Dynamic Analysis

Compare what each approach reveals, their benefits, and their blind spots.

Static — Safe triage
  • Extract strings and imports to form initial hypotheses.
  • Use disassemblers to inspect code paths without execution.
  • Limitations: packers and encryption hide runtime artifacts.
Dynamic — Observe runtime
  • Execute in an isolated VM to see real behavior.
  • Capture file/registry changes, process injections, and network traffic.
  • Risk: poor isolation can lead to infection of host or network.
Key Takeaway

Start with static triage for safety. Use dynamic analysis to confirm behavior and extract final IoCs in an isolated lab.

Concrete Example: Packed Ransomware
Strings are encrypted in the file, so static tools show little. When executed in a VM, the sample unpacks in memory and reveals a ransom note filename and C2 domain.
Common Mistake
Running a suspicious sample on a non-isolated machine or skipping static triage before execution risks loss of forensic evidence and broader infection.
Pro Tip
Always snapshot a clean VM state before execution. Use simulated network services to capture C2 behavior safely.
