Process Flow

Capturing host activity

Use Process Monitor to log process creation, file writes, and registry modifications to identify persistence and payload behavior.
What to capture
  • Process launches, parent PID, and injected processes.
  • File creates/renames and deleted originals.
  • Registry Run keys, service entries, and configuration keys.
Pro Tip
Filter Process Monitor to the suspect process to reduce noise and preserve a clear timeline for post-execution analysis.
Key Takeaway

Host logs reveal persistence mechanisms and file activity that feed EDR and incident response actions.

Concrete Example
After execution, Process Monitor shows invoice.exe creating README.txt, renaming user documents with a new extension, and adding a Run key for persistence. These exact artifacts become host-based IoCs.
Common Mistake
Not correlating host activity timestamps with network captures can obscure the sequence of events. Always sync clocks and captures before analysis.
