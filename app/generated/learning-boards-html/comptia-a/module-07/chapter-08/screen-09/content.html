Module 8 › Chapter 7.8 › Network Analysis
Definition

Capture and simulate

Run Wireshark to record traffic and FakeNet to safely answer network requests so malware cannot reach real C2 servers.
What to capture
  • DNS queries and responses for domain discovery.
  • HTTP requests and headers for user-agent and payload data.
  • Unusual protocols or encrypted tunnels that suggest data exfiltration.
Pro Tip
Capture both simulated responses and raw packets. FakeNet shows intent; Wireshark gives forensics you can extract and decode.
Key Takeaway

Simulate network services to contain risk and use packet captures to extract network IoCs for detection.

Concrete Example
FakeNet responds to an HTTP POST. Wireshark shows the POST payload contains a base64 blob that decodes to configuration data and C2 commands. These domain and payload patterns become network IoCs.
Common Mistake
Not running simulated services when the malware expects real responses. If fake services are absent, the sample may exit or hide its behavior.
