Module 8 › Chapter 7.8 › Debugger
Definition

Debugger-based reverse engineering

Step through execution to uncover unpacking routines and reveal the original, executable code in memory.
Breakpoint strategy
  • Break on CreateThread, VirtualAlloc, VirtualProtect, and LoadLibrary.
  • Inspect memory regions for newly written executable pages.
  • Dump memory once unpacked and analyze in a disassembler.
Key Takeaway

Debugging uncovers runtime-decrypted code and is the primary method to defeat packing and obfuscation for analysis.

Concrete Example
Break on VirtualProtect. Step to the point where the process marks memory as executable. Dump that memory and open it in Ghidra to see deobfuscated code and meaningful function names.
Common Mistake
Rushing to dump memory without noting the instruction pointer and module offsets can create misaligned dumps that are hard to analyze. Record offsets and context carefully.
