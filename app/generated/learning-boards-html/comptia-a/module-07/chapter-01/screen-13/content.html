Architecture Proposal (summary)
Key data sources
AD logs, firewall syslog, IDS/IPS alerts, Linux syslog, EDR, CloudTrail, VPC Flow, GuardDuty, WAF, app logs.
Component placement
Forwarders and syslog collectors on-premise; Firehose/Lambda for AWS; regional aggregators; central indexer cluster with search heads and management server.
Data flow highlights
Buffer at collectors, pre-parse at aggregators, normalize at indexers, enrich and correlate at analytics nodes.
Critical correlation rule (pseudo)
IF (
  (Event_Type = "Windows_Authentication_Failure" AND User_Account = X)
  AND WITHIN 10 minutes (
    (Event_Type = "AWS_Console_Login_Success" AND User_Account = X AND Source_IP NOT_IN Known_VPN_Ranges)
    AND WITHIN 5 minutes (
      (Event_Type = "AWS_SecurityGroup_Modification" AND User_Account = X)
    )
  )
)
THEN GENERATE HIGH_SEVERITY_ALERT("Potential On-Premise to Cloud Credential Theft and Privilege Escalation")
Validation
Test this rule against historical logs, measure false positives, and tune time windows and aggregation thresholds accordingly.
Key Takeaway

Combine architectural placement with focused rules that link activity by account and time to detect lateral credential theft across environments.
