Module 07 › Chapter 7.1 › Data Source Integration
Collection Patterns
Agents / Forwarders
Reliable, near-source collection for servers and applications. Good for preserving timestamps and context.
Syslog Collectors
Network devices and firewalls often use syslog; requires parsing and field mapping.
Cloud-native Pipelines
Kinesis, Firehose, or Lambda to move CloudTrail and flow logs into the SIEM.
Concrete Example — CloudTrail
Map CloudTrail's eventName to an action field, userIdentity to the actor field, and sourceIPAddress to src_ip so cloud events align with on-prem logs for correlation.
Validation checklist
  • Confirm timestamp accuracy and timezone handling
  • Verify field mappings into the common schema
  • Test queries that join cloud and on-premise events
Common mistake
Assuming cloud JSON fields will map automatically; explicit mapping is required for reliable searches.
Key takeaway
Pick the collection method that preserves the necessary context and validate sample events end-to-end.
