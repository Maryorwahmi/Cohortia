Distributed SIEM Architecture
Design decisions that support scale, resilience, and compliance in enterprise environments.
Collectors / Forwarders
Aggregate and buffer logs near sources. Use them to filter and compress before sending to indexers.
Indexers / Data Nodes
Store, normalize, and index events for correlation and search.
Search Heads / Analytics
Query and visualization layer for analysts; scale separately from storage.
Example
A global retail operator places collectors in each region for POS and network logs, forwards normalized events to central indexers, and hosts search heads in a primary analytics region accessible to SOC teams.

Common mistake
Assuming one large server can replace distributed components, which risks data loss at scale.
Key takeaway
Design for buffering and graceful degradation so collectors can store and forward when central links fail.
