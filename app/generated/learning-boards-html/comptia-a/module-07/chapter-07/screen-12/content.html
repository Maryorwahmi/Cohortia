Module 7 › Chapter 7.7 › MACB Timeline
Timeline Components
M - Modified
When file content changed.
A - Accessed
When file was read or referenced.
C - Created
When file was created; may change on copies.
B - MFT change
When file record metadata changed on NTFS.
Practical Guidance
  • Collect MACB times across many files and order events to build a timeline.
  • Correlate with memory and network timestamps to link file events to process activity and communications.
  • Account for clock skew and timezone; include a margin of uncertainty when asserting exact times.
Misconception
Treating a single timestamp as definitive proof. Always corroborate with additional artifacts for confidence.
