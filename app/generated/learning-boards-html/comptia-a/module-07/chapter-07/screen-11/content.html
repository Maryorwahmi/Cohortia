Module 7 › Chapter 7.7 › File System Analysis
NTFS
MFT stores file records and metadata. Look for MFT entries indicating deleted files, alternate data streams, and MACB timestamp changes. Use tools that parse the MFT to recover file history and contents.
Artifacts
MFT entries, ADS, USN journal
Tools
Autopsy, sleuthkit, FTK Imager, EnCase
ext4
Inodes contain metadata and pointers to data blocks. Examine inode tables and extended attributes to find deleted or hidden files. Carve unallocated space when metadata references are missing.
Artifacts
Inode records, extended attributes, journal entries
Tools
sleuthkit, Autopsy, file carving utilities
Timeline & Correlation
Use MACB timestamps to construct event timelines and correlate file system events with memory and network evidence to confidently identify attacker actions.
Common Mistake
Overlooking alternate data streams or extended attributes where attackers can hide data undetected by simple file listings.
