Module 7 › Chapter 7.7 › Memory Forensics
Why it matters

What memory holds

  • Running processes and parent-child relationships (pslist, pstree).
  • Open and recent network connections (netscan).
  • Injected code and hooks revealing fileless malware (malfind, apihooks).
  • Loaded DLLs and decrypted secrets present only in RAM.
Concrete Example
A suspicious PowerShell script that never wrote to disk can be located by searching memory for injected executable regions or script command strings. Volatility's malfind helps identify such regions for further extraction.
Common Mistake
Waiting to capture memory until after reboot, causing loss of volatile artifacts that are critical to the investigation.
Analysis Tools
pslist / pstree
List processes and parent/child relationships to find suspicious or injected processes.
netscan
Reveal active and recently closed sockets to identify C2 connections.
malfind / apihooks
Detect injected code and API hooks characteristic of memory-resident threats.
