Learning Objectives
Bloom progression: Learn → Understand → Apply → Master
Bloom
Learn → Understand → Apply → Master
Use these objectives to guide hands-on labs and documentation practices.
01
Differentiate live and dead acquisition
Explain volatile versus persistent data, and decide which acquisition preserves the most probative evidence in an incident.
Mnemonic: Volatile = Vanishes on power loss
VERIFIED COMPETENCY MILESTONE
02
Perform forensic imaging
Create bit-for-bit disk and memory images using trusted tools and verify them with cryptographic hashes for integrity.
Mnemonic: Image then hash
VERIFIED COMPETENCY MILESTONE
03
Analyze file systems (NTFS, ext4)
Inspect MFT entries, inodes, and MACB timestamps to recover deleted files and build timelines of attacker activity.
Mnemonic: MFT and inodes reveal hidden history
VERIFIED COMPETENCY MILESTONE
04
Conduct memory and network forensics
Extract running processes, open connections, and reconstruct packet sessions to find C2 channels and payloads.
Mnemonic: RAM shows now, PCAP shows communication
VERIFIED COMPETENCY MILESTONE
