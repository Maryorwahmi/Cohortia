Example Commands
vol.py -f SRV-WEB-001_memory.raw --profile=Win2012R2x64 pslist
vol.py -f SRV-WEB-001_memory.raw --profile=Win2012R2x64 netscan
vol.py -f SRV-WEB-001_memory.raw --profile=Win2012R2x64 malfind
These commands list processes, network sockets, and search for injected code respectively. Use them as an initial triage sequence on a memory image.
Walkthrough
  1. Run pslist to spot unexpected processes (look for scripts or unusual parents).
  2. Run netscan to find outbound connections and correlate with suspicious PIDs.
  3. Run malfind on PIDs of interest to detect injected, executable regions for extraction.
Misconception
Assuming Volatility output is definitive without cross-checking. Always corroborate findings with disk and network artifacts.
Example Scenario
If pslist shows powershell.exe spawned by w3wp.exe and netscan shows that PID making external connections, malfind may reveal injected code regions. Extract those regions and analyze strings for C2 addresses or commands.
Key Takeaway
Use Volatility plug-ins in a targeted sequence and document profiles and options to ensure accurate interpretation of memory artifacts.
