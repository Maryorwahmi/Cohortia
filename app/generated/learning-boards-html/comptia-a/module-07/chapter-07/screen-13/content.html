PCAP Workflow
  1. Capture traffic with tcpdump or similar to a file on read-only media.
  2. Load PCAP into Wireshark for protocol-level inspection and session reconstruction.
  3. Use filters to isolate suspicious flows and extract transferred files.
  4. Parse PCAPs with Zeek for structured logs to accelerate triage.
Concrete Example
Filter HTTP in Wireshark, follow the TCP stream, and export objects to recover files transmitted during suspicious sessions. Correlate packet timestamps with process-level connections found in memory analysis.
Common Mistake
Relying solely on summary logs and missing payloads or session details preserved only in full PCAPs.
Key Takeaway

Full packet captures plus structured parsing provide the strongest basis for reconstructing attacker communications and extracting malicious payloads for analysis.
