Module 7 › Chapter 7.7 › Disk Imaging with dd
Command Example
sudo dd if=/dev/sda of=/media/forensics/disk_image.dd bs=4M status=progress
This creates a raw image. Use a write-blocker and compute a hash right after imaging.
Hashing Example
sha256sum /media/forensics/disk_image.dd
# Also pre-image: sudo dd if=/dev/sda bs=4M | sha256sum
Compare the hash of the original drive and the image. Exact match proves identical data.
Practical Notes
  • Use a block size that balances speed and memory, e.g., bs=4M.
  • Record dd progress and exit codes. Log the full command and environment.
  • Store original media in tamper-evident packaging after imaging.
Key Takeaway
Imaging plus matched hashes is the technical foundation of admissible disk evidence.
