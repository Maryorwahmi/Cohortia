Module 7 › Chapter 7.7 › Practical Outcomes
Prepare forensic workstation
  • Use trusted media and a write-blocker. Keep a secure storage area for images.
  • Verify tool hashes before use to avoid introducing corrupted utilities.
  • Document versions, times, and personnel for chain of custody.
Acquire and verify evidence
  • Run imaging commands (dd, FTK Imager) and immediately compute SHA256 or MD5 hashes.
  • Compare hashes of original and image files; mismatches indicate modification.
Analyze memory and network captures
  • Run Volatility commands like pslist, netscan, malfind for memory analysis.
  • Use Wireshark or Zeek to parse PCAPs and reconstruct sessions for payload extraction.
Quick Lab Checklist
  1. Document scene and tools.
  2. Acquire volatile data first when needed.
  3. Use write-blocker for disk imaging.
  4. Hash and store images securely.
Key Takeaway

Repeatable, documented steps and verified hashes make evidence defensible in legal settings.
