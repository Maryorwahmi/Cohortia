Module 7 › Chapter 7.7 › Live Acquisition Best Practices
Process
  1. 1. Document scene: timestamps, users, network, and running services.
  2. 2. Mount trusted media (write-protected) to run acquisition tools.
  3. 3. Acquire memory with winpmem/dumpit; produce raw memory dump.
  4. 4. Hash the memory image immediately (SHA256 or MD5) and record value.
  5. 5. Collect minimal volatile system artifacts: process lists, netscan, loaded DLLs.
Safety & Documentation
Record tool names, versions, exact commands, timestamps, and personnel. Avoid browsing files or running unrelated utilities that change state.
Concrete Example
E:\winpmem.exe -o C: emp\SRV-WEB-001_memory.raw
After the image is created, compute a SHA256 hash on a forensic workstation and record the value in your chain of custody file.
Misconception
Running many tools locally improves coverage. In fact, extra commands increase the chance of altering or destroying volatile evidence.
