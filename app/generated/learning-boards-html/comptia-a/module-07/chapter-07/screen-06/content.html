Module 7 › Chapter 7.7 › Dead Acquisition
Definition

Write-Blocker Workflow

  1. Photograph and document the device and its connections.
  2. Remove the drive carefully and attach it to the forensic workstation via a hardware write-blocker.
  3. Compute a pre-image hash of the original drive while blocked.
  4. Create a bit-for-bit image with dd, FTK Imager, or EnCase.
  5. Hash the image and compare to the original. Match indicates integrity.
Command Example
sudo dd if=/dev/sdb of=/media/forensics/suspect_drive_image.dd bs=4M status=progress
Then compute a hash: sha256sum /media/forensics/suspect_drive_image.dd and compare to the pre-image value.
Common Mistake
Skipping pre-image hashing or failing to use a write-blocker can invalidate evidence integrity and admissibility.
Key Takeaway

Always use a hardware write-blocker for dead acquisition and verify with matching cryptographic hashes to ensure the image is an identical copy of the original.
