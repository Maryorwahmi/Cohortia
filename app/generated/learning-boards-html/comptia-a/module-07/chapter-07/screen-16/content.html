Module 7 › Chapter 7.7 › Quick Reference
Capture RAM First
Volatile evidence can vanish on shutdown; acquire memory to preserve running state and credentials.
Write-Block & Hash
Prevent writes to originals and compute pre- and post-image hashes to show identical copies.
Document Everything
Log tools, commands, hashes, transfers, and handlers to maintain chain of custody and support admissibility.
Summary
These three reminders help preserve probative artifacts, validate integrity, and create a defensible investigative record.
