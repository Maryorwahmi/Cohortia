Module 7 › Chapter 7.4 › Automated Response
Common automated actions
  • Process termination to stop malicious execution.
  • File quarantine or deletion for known malicious artifacts.
  • Network isolation to prevent lateral movement and C2 communication.
  • Registry reversal and endpoint snapshotting for forensics.
Operational tradeoffs

Plan which endpoints can be safely isolated automatically and which require human approval. Test all actions to avoid service disruption.

Example decision

A high-severity ransomware precursor detected on a laptop: network isolation is appropriate to contain spread. The same action on a production database server would require approval due to business impact.

Check your playbook
  • Which endpoints are allowed automatic isolation?
  • What steps preserve evidence before disruptive actions?
Key Takeaway

Use automation to contain fast where safe, and require human review for high-impact endpoints to avoid unnecessary downtime.
