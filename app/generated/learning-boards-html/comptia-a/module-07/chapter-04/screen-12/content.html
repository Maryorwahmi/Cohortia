Module 7 › Chapter 7.4 › EDR → SIEM
Correlation advantage

EDR provides rich context like command lines and process lineage; ingest key fields into the SIEM so you can correlate endpoint events with firewall, cloud, and identity logs to reveal multi-stage attacks.

Keep full raw telemetry in EDR for forensics while forwarding enriched alerts and selected fields to the SIEM to avoid storage overload.
Example correlation

EDR alert + firewall outbound to known malicious IP + identity login from unusual location = prioritized incident with clear scope.

Operational guidance
  • Map EDR fields to SIEM schema: process_guid, command_line, endpoint_id.
  • Forward enriched alerts and selected telemetry, not all raw events.
  • Use EDR findings to refine SIEM rules and intelligence feeds.
Key Takeaway

Integrate EDR and SIEM thoughtfully: send rich context for correlation while keeping raw telemetry accessible for deep forensic work.
