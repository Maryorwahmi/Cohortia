Module 7 › Chapter 7.4 › What is EDR?
Definition

Endpoint Detection and Response continuously records process activity, file system changes, network connections, registry edits, and user actions to detect, investigate, and respond to threats based on behavior.

Why behavior matters

Signatures miss fileless and zero-day techniques. Behavior reveals intent even when a tool is legitimate.

Common misconception

EDR is not just an alert box. It supports hunting, investigation, and automated containment when configured carefully.

Key Takeaway

EDR turns endpoints into rich telemetry sources and active controls, enabling detection of stealthy attacks and faster, informed responses.

Concrete example

An alert shows PowerShell running a download. EDR shows the process lineage, full command line, outbound IP, and files written, making it possible to contain and investigate with confidence.

Check your understanding
  • What telemetry would you inspect to confirm an in-memory payload?
  • How would process lineage change your response priority?
Analogy

Think of EDR as a security camera that not only records motion but also recognizes suspicious patterns and can trigger a lock on a door when danger is detected.
