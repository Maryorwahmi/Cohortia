Module 7 › Chapter 7.4 › Investigation Lab
Task checklist
  1. Collect process lineage and full command line for the flagged PowerShell.
  2. List outbound network connections and cross-check with threat intelligence.
  3. Identify files created or modified and retrieve artifacts for sandbox analysis.
Response recommendation

For a workstation showing download-and-execute behavior, isolate the endpoint from the network to prevent spread, then collect forensic snapshots and continue investigation.

Conceptual EDR query (example)
event_type="process_execution" AND process_name="powershell.exe" AND endpoint_name="WKSTN-SALES-007" AND (command_line="*DownloadString*" OR command_line="*IEX*")
| join process_guid [ search event_type="network_connection" AND endpoint_name="WKSTN-SALES-007" ]
| join process_guid [ search event_type="file_write" AND endpoint_name="WKSTN-SALES-007" ]
| select process_lineage, command_line, network_connections, file_changes, parent_process, user_context, timestamp
| sort by timestamp asc
Use joined results to see all related events sharing the same process identifier and build a timeline for decision-making.
Key Takeaway

Contain quickly when telemetry indicates active compromise, preserve evidence, and use the investigation to harden detection rules.
