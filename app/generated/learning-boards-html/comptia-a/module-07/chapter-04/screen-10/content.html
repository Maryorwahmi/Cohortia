Comparison: Legitimate vs Malicious use
Legitimate
  • Run by admin tools during maintenance windows
  • Expected network destinations and file writes
  • Parent process is a management console
Malicious
  • Unexpected parent like document viewer
  • Download and execute patterns in command line
  • Outbound connections to unknown IPs
Reduce false positives
Use role and application profiles, threshold tuning, and combined telemetry scoring to prioritize likely malicious usage.
Concrete scenario

A user opens a document and a macro spawns PowerShell. The process lineage shows winword.exe → powershell.exe, the command line contains download flags, and a new executable appears in temp. These correlated signals justify containment and deeper investigation.

Pro tip
Score events across multiple telemetry categories instead of treating any single signal as definitive evidence.
Key Takeaway

Detect LotL attacks by contextualizing tool usage, reducing false positives while maintaining detection for stealthy abuse.
