Module 07 › Chapter 7.2 › Temporal Correlation
Sequence example
  1. Multiple failed logins from IP X within 5 minutes.
  2. Successful login for user A from IP X.
  3. Query on sensitive customer table within 2 minutes of the success.
When these events occur in order and close in time, correlation elevates the incident priority and provides a coherent timeline for analysts.
Check your understanding
What window size would you choose for slow lateral movement versus fast credential stuffing? Remember: larger windows catch slow attackers but add noise; smaller windows reduce false positives but may miss long-running sequences.
Common Mistake

Using the same time window for all rules. Tune windows per threat type and asset criticality.
