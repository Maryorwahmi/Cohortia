Module 07 › Chapter 7.2 › Normalization
Core claim
Map different source fields into one model
CloudTrail: sourceIPAddress → src_ip
Nginx: client_ip → src_ip
Windows: Source Network Address → src_ip
Result: rules use src_ip for all sources.
Keep raw fields for auditing while exposing normalized aliases for analysis. Normalize timestamps, user identifiers, and asset tags so correlation logic is source-agnostic.
Analogy
Translation layer
Normalization is like translating many dialects into one language so everyone can understand the rulebook.
Key Takeaway

Normalization removes source-specific friction so correlation and hunting operate across diverse logs.
