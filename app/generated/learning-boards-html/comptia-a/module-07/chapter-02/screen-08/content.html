Module 07 › Chapter 7.2 › Event Correlation
Temporal
Sequence + Windows
Detect ordered steps within a time window, e.g., reconnaissance → escalation → lateral movement.
Statistical
Baseline Anomalies
Compare current volumes or rates against historical baselines to detect spikes or drops.
Behavioral
Profile Deviations
Build entity profiles and alert on deviations, such as unusual resource access patterns for a user.
Concrete example
Temporal: multiple failed logins then a success within five minutes triggers an investigation. Statistical: downloads exceed three standard deviations above the user's mean. Behavioral: a developer accesses sensitive production data never accessed before.
Key Takeaway

Use all three correlation styles together to improve fidelity and reduce missed detections.
