Module 07 › Chapter 7.2 › Key Concepts
Centralized Log Management
Collect and store logs centrally so you can search and comply across sources.
Log Parsing
Extract fields from raw log lines so events can be indexed and queried.
Log Normalization
Map different source fields into a common model for consistent correlation.
Summary
Parsing, normalization, and enrichment provide the structured, contextual data that makes temporal, statistical, and behavioral correlation effective at scale.
