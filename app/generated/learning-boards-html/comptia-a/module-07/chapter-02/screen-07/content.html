Module 07 › Chapter 7.2 › Enrichment
Enrichment types
  • Geo-IP: country, region for external IPs.
  • Asset tags: owner, environment (prod/dev), criticality.
  • Identity data: user role, department, known aliases.
Tip: cache enrichment lookups and refresh regularly. Enrich only the fields needed for correlation to reduce cost.
Concrete example
Login event augmented with geo.country=Germany, asset.owner=FinanceApp, user.role=Admin. Correlation rules now consider country and role when scoring the alert.
Key Takeaway

Context from enrichment guides prioritization and increases the signal-to-noise ratio of alerts.
