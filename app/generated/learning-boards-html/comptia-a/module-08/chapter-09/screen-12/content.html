Module 9 › Chapter 8.9 › Prioritization Activity
Scenario

Two critical RCEs with identical CVSS

Compare a public-facing Apache Struts 2 server hosting the customer portal and an internal Jenkins instance. Both have CVSS 9.8, but different asset criticality.
Vulnerability 1
Apache Struts 2 RCE - CVSS 9.8. Asset criticality: High. Exposure: Public. Data: PII and payment information.
Vulnerability 2
Jenkins RCE - CVSS 9.8. Asset criticality: Low. Exposure: Internal, isolated dev network. No sensitive customer data.
Decision

Prioritize remediation of the public-facing portal immediately; document the Jenkins fix as scheduled maintenance with monitoring and isolation until patched.

Documentation example
Priority justification:
- Vulnerability: Apache Struts 2 RCE
- CVSS: 9.8
- Asset criticality: High (customer portal, PII/payment)
- Threat intelligence: public exploit known
Action: Emergency patch testing and deploy within 48 hours. Verification: scan + functional test.
Common Mistake
Using CVSS alone leads to misallocated effort. Always record the business rationale used to alter priority.
