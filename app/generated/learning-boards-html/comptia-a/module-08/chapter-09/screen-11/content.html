Module 9 › Chapter 8.9 › Vulnerability Disclosure
Definition

Responsible vendor coordination for vulnerabilities

Notify vendors privately with reproducible details, allow time for a fix, and coordinate public disclosure after remediation to protect users.

Practical steps
  • Provide reproduction steps, affected versions, and test artifacts.
  • Agree on a reasonable remediation timeframe and communicate status.
  • Coordinate public disclosure only after a patch is released.
Key Takeaway

Document communications, provide reproducible evidence, and avoid public disclosure before a patch is available.

Example
When reporting a third-party bug, include version numbers, reproduction steps, and a short PoC so the vendor can prioritize and patch quickly. Offer to re-test and confirm the fix.
Common Mistake
Publishing technical details publicly before a patch is available increases user risk and is discouraged unless vendor coordination fails and disclosure policies allow it.
