Module 8 › Chapter 8.3 › Penetration Testing
Definition

Controlled emulation to prove impact

Penetration tests use manual and semi-automated techniques to exploit vulnerabilities and show what an attacker could accomplish in-scope.

What testers deliver
Proof of exploitability, evidence of impact, reproducible steps, and prioritized remediation recommendations.
Safe practice example
Use the module 'check' when available, or test only in a lab to avoid production impact.
Concrete example
A scanner flags an outdated SMB service. A pen tester selects an SMB exploit, configures target addresses and payload options in a lab, and demonstrates a successful privilege escalation resulting in evidence that an attacker could access credential stores. The remediation recommended is prioritized because impact is demonstrated.
Key Takeaway

Pen tests validate risk by turning potential issues into verified impacts that guide remediation priorities.
