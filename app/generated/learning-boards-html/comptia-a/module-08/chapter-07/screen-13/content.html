Module 8 › Chapter 8.7 › Hands-on: Insider Exfiltration
Scenario
Alice uses valid credentials, runs PowerShell to enumerate shares, copies data locally, then uploads to personal cloud storage via browser.
Step 1
Initial Access
Technique: T1078 — Valid Accounts
Step 2
Execution
Technique: T1059 — Command and Scripting Interpreter
Step 3
Discovery
Technique: network share enumeration
Step 4
Collection
Technique: local data staging
Step 5
Exfiltration
Technique: web upload to cloud service
Detection Suggestions
  • Initial Access: monitor unusual logins and geolocation anomalies; telemetry: authentication logs.
  • Execution: detect PowerShell parent-child process relationships and encoded commands; telemetry: process monitoring and command-line auditing.
  • Discovery/Collection: alert on bulk file reads from sensitive shares; telemetry: file access logs and share enumeration history.
  • Exfiltration: flag large or unusual uploads to personal cloud domains; telemetry: proxy and DNS logs.
Key Takeaway

A mapping table with step, ATT&CK ID, telemetry, and one detection is the most actionable deliverable for defenders.
