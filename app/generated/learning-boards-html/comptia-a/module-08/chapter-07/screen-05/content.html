Module 8 › Chapter 8.7 › What is MITRE ATT&CK?
Core Definition
Adversary tactics, techniques, and common knowledge

ATT&CK documents observed adversary behaviour and assigns technique IDs so teams can design emulations and map detections consistently.

Plan & Scope
Select TTPs that emulate a threat group or exercise a detection gap.
Develop Scenarios
Chain techniques to reflect how adversaries operate in realistic campaigns.
Measure Defenses
Map detections to ATT&CK IDs to reveal coverage and gaps.
Quick Reference
# Example of MITRE ATT&CK TTPs for initial access:
# T1133 - External Remote Services (e.g., VPN, RDP)
# T1566 - Phishing (e.g., Spearphishing Attachment, Spearphishing Link)
# T1078 - Valid Accounts (e.g., compromised credentials)
Key Takeaway

Use ATT&CK IDs to plan realistic emulations and to map visibility gaps for defenders.
