Module 8 › Chapter 8.7 › Command and Control (C2) Frameworks
Architecture Overview
C2 Components
  • Agents/Beacons on compromised hosts that check in and execute tasks.
  • Server-side infrastructure that issues commands, stores exfiltrated data, and manages sessions.
  • Malleable traffic profiles and transport mechanisms to blend with legitimate traffic.
Cobalt Strike
Commercial C2 with Beacon and Malleable profiles for traffic shaping.
Empire
Open-source PowerShell agent and Python C2 server for post-exploitation tasks.
Metasploit
Exploit framework with Meterpreter offering robust post-exploitation control.
Choice Criteria
Balance features, OPSEC, telemetry expectations, and the rules of engagement when selecting a framework.
Common Mistake

Picking the most feature-rich tool without planning OPSEC can create detectable artifacts and reduce the realism of the emulation.
