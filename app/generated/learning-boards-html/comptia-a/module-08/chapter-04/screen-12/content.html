Module 8 › Chapter 8.4 › SPA Testing
Client-side inspection
Download JavaScript bundles and search for hardcoded keys or sensitive logic. Even minified code can reveal issues.
Example
A client-side check that hides admin controls does not prevent direct API calls to admin endpoints; test the APIs directly.
API validation
Capture SPA JSON requests with the proxy and replay or modify them to ensure server-side authorization and input validation exist.
Key Takeaway

Client logic is convenient for UX, but security must be enforced server-side; test both areas.
