Module 8 › Chapter 8.4 › Parameterized Queries
Unsafe Pattern
query = "SELECT * FROM users WHERE name = '" + user_input + "'"
Concatenation like this lets special characters in user input change query structure.
Parameterized Sketch
stmt = db.prepare("SELECT * FROM users WHERE name = ?")
stmt.execute(user_input)
Placeholders keep SQL and data separate; the database treats user input strictly as a parameter.
Validation
After applying parameterization, re-run confirming payloads and expect no change in query logic or unexpected exposed data.
