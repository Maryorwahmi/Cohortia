Module 8 › Chapter 8.4 › Broken Authentication
Common Weaknesses
  • Predictable or short session identifiers.
  • Missing HttpOnly or Secure cookie flags.
  • No rate limiting or account lockout.
  • Weak password reset flows that allow takeover.
Testing & Controls
Use token randomization analysis, attempt controlled credential guessing to validate rate limits, and review cookie attributes. Recommend MFA for high-value accounts.
Common Mistake

Assuming secure transport alone stops session attacks. The server must generate and manage tokens correctly.
