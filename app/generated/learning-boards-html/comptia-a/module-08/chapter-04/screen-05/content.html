Module 8 › Chapter 8.4 › Burp Setup
Steps
  1. Configure browser proxy to point at the intercepting proxy (for example localhost:8080).
  2. Install the proxy's CA certificate into the browser to decrypt HTTPS traffic for testing.
  3. Enable interception, load the target page, and observe requests passing through the proxy.
  4. Send interesting requests to Repeater or Intruder for manual modification and automated testing.
Misconception
Installing a CA in your test browser affects only that browser profile. Do not install in production browsers or systems.
Visual Workflow
Intercept
Capture requests and pause them so you can inspect or modify headers and parameters.
Repeater
Manually iterate on a request to craft payloads and observe responses.
Intruder
Run controlled automated payload sets such as fuzzing or credential stuffing where safe.
Pro Tip

Keep a separate browser profile for testing and only install CA certs there to reduce risk to your main browsing environment.
