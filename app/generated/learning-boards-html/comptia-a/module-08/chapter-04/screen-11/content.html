Module 8 › Chapter 8.4 › API Testing
Example curl
curl "http://target.com/product?id=123"

# Modified:
curl "http://target.com/product?id=124"
Compare responses. If changing an ID returns another user's data without authorization, classify as Broken Access Control / IDOR.
Checklist
  • Manipulate resource identifiers to test object-level authorization.
  • Inspect returned JSON for fields that expose unnecessary sensitive data.
  • Test rate limits with controlled request bursts.
Key Takeaway

APIs must enforce authorization per object and minimize returned data; do not rely on client-side controls.
