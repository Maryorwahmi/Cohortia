Module 8 › Chapter 8.4 › SQL Injection
Example Request
GET /products?id=123 HTTP/1.1
Host: example.com
User-Agent: test-client
Modified for testing
GET /products?id=123%20OR%201=1-- HTTP/1.1
Host: example.com
User-Agent: test-client
Send the modified request in Repeater and compare responses. If the results include unexpected records or bypass filters, document the exact response difference as evidence.
Notes
  • Use URL encoding for spaces and symbols when modifying GET parameters.
  • Prefer logical confirmation payloads to destructive payloads in test environments.
  • Record both requests and responses for reproducibility and remediation verification.
Remediation
Recommend parameterized queries and least-privilege database accounts to limit impact if injection exists.
