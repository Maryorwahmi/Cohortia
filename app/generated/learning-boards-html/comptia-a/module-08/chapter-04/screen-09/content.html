Confirming XSS
Submit a small, non-destructive script payload in a field that is reflected back to the page to observe whether it executes in the browser context.
<script>alert('XSS test')</script>
Remediation
Encode output according to context before rendering. For example, replace < with &lt; and & with &amp; when inserting user text into HTML.
Pro Tip
Use libraries or template engines that provide built-in context-aware encoding to reduce risk from manual errors.
