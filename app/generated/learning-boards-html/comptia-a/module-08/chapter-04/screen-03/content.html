Module 8 › Chapter 8.4 › Milestones
Evidence
Capture the intercepted request and the altered request showing the change in response. Include exact parameters and a short note on impact.
Example
An altered product id returns another user's product data without authorization.
Validation
Provide a confirmation step after the fix: send the same request and show access denied.
Remediation
Recommend a specific code or configuration change that addresses the root cause rather than a temporary mitigation.
Developer Note
Include code sketch or configuration steps so developers can reproduce the fix quickly.
