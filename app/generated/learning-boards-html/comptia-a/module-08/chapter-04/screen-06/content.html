Module 8 › Chapter 8.4 › Proxy Architecture
Flow
Browser
Sends requests via proxy; trust the proxy CA for HTTPS inspection.
Proxy
Intercepts, modifies, and forwards requests. Hosts tools like Repeater and Intruder.
Server
Receives the forwarded request and returns the response to the proxy, which then forwards to the browser.
Tools
Repeater, Intruder, Scanner, Sequencer, Decoder—each serves a distinct testing role.
Misconception
Proxying is passive unless you explicitly alter requests; it's a test tool, not an attack engine by itself.
Example
Intercept a session cookie in flight, then test cookie flags by replaying the request and observing server behavior. If cookies lack secure flags or tokens are predictable, show the finding with evidence.
Key Takeaway

Know the proxy's role and use the right module for proof of concept vs. broader scanning.
