Module 8 › Chapter 8.1 › Asset Inventory and Discovery
Asset discovery sources
Combine multiple discovery methods to produce a reliable inventory.
Network scanning
Host discovery finds devices on the network but may miss cloud or ephemeral workloads.
Cloud provider APIs
Use provider inventories to list instances, containers, and services running in cloud accounts.
CMDB & deployment pipelines
CMDBs and CI/CD outputs provide asset metadata and ownership useful for prioritization.
Example
Tagging assets with owners and criticality in the inventory enables automated routing of remediation tasks to the right team.
Validation & maintenance
Make discovery repeatable and monitored so new assets enter the program quickly.
Common mistake
Using a one-time inventory or manual spreadsheets; this creates blind spots for ephemeral cloud workloads.
Pro tip
Automate connectors to cloud APIs and CI/CD pipelines; reconcile multiple sources into a single authoritative inventory.
Check your understanding
If a new container is deployed hourly in production, how will your inventory detect and tag it for scanning? Consider connectors and frequency.
