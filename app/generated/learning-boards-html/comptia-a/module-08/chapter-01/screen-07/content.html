Module 8 › Chapter 8.1 › Assessment & Prioritization
Scoring & context
Combine quantitative scores with qualitative context to form priorities.
Use CVSS
CVSS provides a standardized base score; use it as the technical starting point for severity.
Add context
Consider asset criticality, exposure, exploitability, and controls to determine business risk.
Triage matrix (example)
Define buckets such as urgent (public-facing + critical data), high, normal, low with explicit criteria for each.
Example comparison
Compare two findings to see prioritization in action.
Finding A
CVSS 9.8 on an internal test server behind MFA — lower priority due to limited exposure and non-production status.
Finding B
CVSS 7.5 on a public-facing web server with sensitive customer data — higher priority because of exposure and data impact.
Common mistake
Blindly following numeric severity without context can divert effort from higher business-risk issues.
Key Takeaway
Document prioritization criteria and record exceptions so decisions are auditable and repeatable.
