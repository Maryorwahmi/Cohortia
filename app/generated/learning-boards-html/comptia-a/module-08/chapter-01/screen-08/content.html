Module 8 › Chapter 8.1 › Remediation
Remediation actions
Common technical responses and considerations.
Patching
Apply vendor updates; plan for testing and rollback procedures to avoid downtime.
Configuration changes
Update insecure parameters, disable unused services, and enforce hardening baselines.
Compensating controls
Use mitigations when immediate fixes are impossible — network filters, segmentation, or monitoring rules.
Collaboration & ownership
Clear roles speed remediation and reduce finger-pointing.
Supporting bullets
  • Assign each finding to a named owner with a deadline.
  • Coordinate fixes with maintenance windows and testing plans.
  • Use ticketing systems to track progress and produce audit evidence.
Example
Security triages a critical web server finding, assigns remediation to the application team, and schedules a post-patch verification scan.
Key Takeaway
Ownership, documented timelines, and follow-up verification are the controls that ensure remediation actually happens.
