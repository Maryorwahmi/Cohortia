Questions & Answers
Q1: Does the failed admin attempt meet logging policy?
A: Yes — the entry includes username and source IP for the failed attempt.
Q2: Is there a policy violation?
A: Yes — an administrative account was accepted from an external IP (203.0.113.5). This should be investigated and remediated.
Next steps
Create a POAM entry for the external admin login, preserve logs as evidence, and review access controls and firewall rules to block external admin access.
