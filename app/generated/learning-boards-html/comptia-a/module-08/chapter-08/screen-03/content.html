Module 8 › Chapter 8.8 › Learning Objectives
Evidence Types
  • Configuration snapshots for servers and network devices
  • Log exports showing timestamps, usernames, and source IPs
  • Control matrices mapping controls to framework requirements
Framework Usage
  • Use NIST CSF to structure functions and priorities
  • Use ISO 27001 for an auditable ISMS implementation
  • Use GDPR and HIPAA to define legal obligations for data protection
Remediation Practice
Create POAM entries that include the finding description, risk, owner, milestone dates, and verification steps. Track status until verification.
