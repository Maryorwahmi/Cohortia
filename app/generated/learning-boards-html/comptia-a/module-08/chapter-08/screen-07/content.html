Module 8 › Chapter 8.8 › Configuration Audits
Audit Steps
  1. Select or adapt a baseline (e.g., CIS Benchmark).
  2. Run automated scans against targets.
  3. Review deviations and assign remediation.
  4. Verify remediation and collect evidence for auditors.
Why automation matters
Automation reduces human error, scales across many systems, and provides consistent evidence during audits.
Example checklist items
  • SSH root login disabled
  • Password maximum and minimum days configured
  • Firewall enabled and expected zones configured
Key Takeaway

Automate baseline checks and treat deviations as tracked audit findings with owners and verification steps.
