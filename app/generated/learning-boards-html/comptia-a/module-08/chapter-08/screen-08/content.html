Module 8 › Chapter 8.8 › Linux Config Checks
Conceptual Commands and Expected Output
# Example: Basic Linux configuration check (conceptual)
# Check for strong password policy in /etc/login.defs
grep -E "PASS_MAX_DAYS|PASS_MIN_DAYS|PASS_WARN_AGE" /etc/login.defs

# Check for SSH root login disabled in /etc/ssh/sshd_config
grep "PermitRootLogin" /etc/ssh/sshd_config
# Expected output: PermitRootLogin no

# Check for firewall status (example using firewalld)
sudo firewall-cmd --state
sudo firewall-cmd --list-all

# Capture outputs to evidence files with timestamps
# Example: /var/audit/evidence/ssh_check_2023-03-15.txt
What to record for auditors
  • Command executed and exact timestamp
  • Captured output saved as evidence file
  • Owner who ran the check and method used
Misconception check
A single successful check is not continuous proof. Automate scheduled scans and retain historical outputs to show sustained compliance.
