Module 08 › Chapter 8.5 › Cloud testing overview
Shared responsibility explained
Providers secure the platform; customers secure configurations and data within it.
Customer responsibilities
Data protection, IAM, network rules, encryption, and application security.
Provider responsibilities
Physical hosts, hypervisor, global network, and foundational services.
Concrete example
Public S3 bucket check
Using aws cli to inspect bucket policy on your account to confirm whether s3:GetObject is allowed for Principal "*".
Key takeaway

Scope tests to what you control. Misconfigurations in IAM and storage are high-risk and high-priority to test.
