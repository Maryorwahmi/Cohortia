Module 08 › Chapter 8.5 › Container & Serverless Risks
Key risk areas
Image vulnerabilities
Outdated libraries and leaked secrets inside images.
Kubernetes RBAC
Overly permissive bindings and open admin endpoints.
Serverless permissions
Functions running with broad IAM roles or logging secrets.
Concrete example
Compromised function role
If a function's role allows broad S3 actions, attackers can exfiltrate data via the function's execution context.
Prioritize: image scanning, RBAC reviews, network policies, and minimal IAM for functions. Integrate checks into CI/CD to prevent regressions.
Key takeaway

Cloud-native workloads require supply-chain and permission hygiene. Stop insecure images and narrow runtime roles.
