Module 08 › Chapter 8.5 › Remediation & Shift-Left
Plan remediation
Separate immediate fixes from systemic changes in pipelines and policy.
Immediate
Rotate exposed keys, remove public policies, and revoke unnecessary roles.
Pipeline
Add static analysis, IaC scanning, and image vulnerability checks to CI.
Process
Define ownership for security fixes and include developers in remediation planning.
Concrete pipeline checks
  • MobSF in PRs to flag insecure APIs or hard-coded secrets
  • Prowler/ScoutSuite runs in a staging account to surface config drift
  • IaC linting to block public buckets or overly broad IAM statements
Key takeaway

Shift-left reduces production exposure and the cost of fixing vulnerabilities. Combine tooling, policy, and ownership for lasting security.
