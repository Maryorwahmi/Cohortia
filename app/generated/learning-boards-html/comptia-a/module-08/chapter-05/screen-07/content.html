Module 08 › Chapter 8.5 › Mobile tooling
Tool roles
MobSF
Automated static and binary analysis to surface issues quickly.
Frida / objection
Runtime instrumentation for hooking APIs and manipulating behavior.
ADB
Device management, file access on authorized builds, and log collection.
Burp / ZAP
Intercept and analyze mobile API traffic once TLS is bypassed or on test certs.
Practical sequence
  1. Run MobSF static scan on the APK/IPA to gather quick findings.
  2. Install app on emulator and configure proxy to capture traffic.
  3. If TLS is pinned, use Frida/objection on a test device to disable pinning.
  4. Use ADB to pull debug logs or databases if app is debuggable and authorized.
Example command snippets are shown in authorized test labs only.
Key takeaway

Combine static and dynamic tools in a sequence to validate and escalate findings safely.
