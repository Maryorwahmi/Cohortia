Module 8 › Chapter 8.2 › Nessus and OpenVAS
Nessus Overview
Commercial scanner with a large plugin database and detailed reporting. Use targeted policies like "Advanced Scan" and add SSH credentials for Linux authenticated checks.
  • Define targets by IP ranges or hostnames.
  • Select appropriate scan policy for asset type.
  • Securely store and scope credentials for authenticated scans.
OpenVAS Overview
Open-source alternative that offers many checks with more manual policy tuning. Good for shops that prefer open tooling but accept extra maintenance effort.
Use cases: cost-conscious environments, customization, and integration into scripted workflows.
Configuration Checklist
  1. Scope hosts and networks for each policy.
  2. Choose credential types per OS (SSH, SMB/WMI, DB creds).
  3. Use accounts with least privilege that can enumerate but not modify.
  4. Schedule scans during low-impact windows and test in staging first.
Key Takeaway
Key Takeaway

Both Nessus and OpenVAS can deliver comprehensive checks; success depends on targeted policies, credential scope, and post-scan validation.
