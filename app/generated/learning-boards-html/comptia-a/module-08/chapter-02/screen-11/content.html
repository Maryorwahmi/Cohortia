Module 8 › Chapter 8.2 › Integrating Scans into CI/CD
Pipeline Pattern
  1. Build the image or compile artifacts.
  2. Run image and dependency scanners with chosen severity thresholds.
  3. Fail the build on critical or exploitable high results; create tickets for others.
Practical Guidance
Tune scanner policies and thresholds to balance security with development velocity. Alert and block on the highest risks, track lower risks to remediation sprints.
Concrete Example
# pipeline fragment that runs Trivy after build
- docker build -t my-app:latest .
- docker run --rm -v $PWD:/root/.cache/ aquasec/trivy:latest image --severity HIGH,CRITICAL my-app:latest
- if [ $? -ne 0 ]; then echo "Vulnerabilities found, failing build!"; exit 1; fi
This enforces an image gate that prevents critical vulnerabilities from reaching registries and production.
