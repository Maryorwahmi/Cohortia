Container Scanning
Scans detect CVEs in base images and installed packages. When integrated into CI/CD, scanners like Trivy can fail builds that include high or critical findings, ensuring vulnerabilities are remediated before deployment.
CI/CD snippet (concept)
build_and_scan:
  stage: build
  script:
    - docker build -t my-app:latest .
    - docker run --rm -v $PWD:/root/.cache/ aquasec/trivy:latest image --severity HIGH,CRITICAL my-app:latest
    - if [ $? -ne 0 ]; then echo "Vulnerabilities found, failing build!"; exit 1; fi
Cloud Configuration Scanning
Cloud scanners check IAM, storage, security groups, and database settings for unsafe defaults. Misconfigured storage or permissive IAM policies are common sources of compromise.
Example
A scanner flags an S3 bucket policy that allows public read access. This is a high-priority fix because it exposes data regardless of application security.
Key Takeaway

Combine image scanning, runtime checks, and cloud audits; automate scanning in CI/CD to catch vulnerabilities early and reduce production risk.
