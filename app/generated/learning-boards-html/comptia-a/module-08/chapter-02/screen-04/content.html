Module 8 › Chapter 8.2 › What is Vulnerability Scanning?
Definition

Vulnerability scanning automatically checks assets against known checks to find vulnerabilities, misconfigurations, and outdated components. It is a discovery tool that requires interpretation and context to produce actionable results.

Common Mistake
Relying only on unauthenticated scans or default policies can leave internal problems undetected and generate false positives.
Pro Tip
Align the scan frequency and depth with asset criticality, and review results with contextual data before remediation.
Example Scenario
A development team uses containerized microservices. Integrating a container scanner into the CI pipeline finds a high-severity library CVE in the base image before deployment, preventing a vulnerable release.
Key Takeaway
Key Takeaway

Select scan types and configuration to fit the asset and reduce noise; scanning is discovery, not final judgement.

Check your understanding
When would a credentialed scan reveal a problem that an external scan cannot? Think about package versions and configuration files.
