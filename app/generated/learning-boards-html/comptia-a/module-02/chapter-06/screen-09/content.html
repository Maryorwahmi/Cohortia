Module 3 › Chapter 2.6 › Tool Comparison
Side-by-side
SAST — White-box
Best for early code fixes; finds unsafe patterns in source and bytecode.
DAST — Black-box
Tests the running app for real exploitability and configuration errors.
IAST — In-process tests
Offers precise traceable findings when tests exercise the code.
RASP — Runtime protection
Blocks attacks in production and provides live telemetry for incidents.
Complementary scenario
A suspected injection can be found by SAST, reproduced and confirmed by DAST, pinpointed with IAST, and mitigated by RASP while a fix is deployed.
Misconception
Relying on a single testing approach leaves gaps. Combine methods for depth and accuracy.
Check

Map tool coverage to threat models and prioritize the combination that closes the most high-risk gaps for your app.
