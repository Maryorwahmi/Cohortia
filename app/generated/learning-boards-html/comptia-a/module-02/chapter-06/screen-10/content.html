Module 3 › Chapter 2.6 › WAF & API Gateway
WAF: block common web attacks
Deploy as a reverse proxy or managed cloud service to inspect and filter HTTP traffic.
Learning mode
Run WAF in learning mode to collect traffic patterns and reduce false positives before enforcing rules.
Custom rules
Add application-specific signatures to capture unusual attack vectors and reduce noise.
API Gateway: manage API traffic
Gateways enforce authentication, authorization, rate limits, and routing for microservices and public APIs.
Rate limiting
Protect back-end services from abuse and DoS by limiting requests per client or key.
Auth & routing
Centralize token validation and route requests to correct microservices with policy enforcement.
Key Takeaway

Use WAFs and API Gateways to enforce security at the edge, but validate rules with production-like traffic to avoid disrupting users.
