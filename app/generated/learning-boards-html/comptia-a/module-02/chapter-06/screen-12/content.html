Module 3 › Chapter 2.6 › Dependency & Container Security
Dependency scanning
Detect known vulnerabilities in third-party libraries during build and prevent unsafe packages from entering production.
Container image scanning
Scan images for CVEs, insecure defaults, and dangerous capabilities before tagging and deployment.
Secret management
Store API keys and credentials in a vault and inject them at runtime; rotate periodically and enforce access policies.
Practical rules
  • Fail builds on critical dependency CVEs.
  • Scan images after build and before deployment; block if high-risk findings exist.
  • Enforce vault usage and disallow checked-in secrets through pre-commit hooks.
Key Takeaway

Automate dependency and image scans, and centralize secret storage and rotation to secure the supply chain and credentials.
