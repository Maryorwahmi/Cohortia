What RASP provides
In-process monitoring and active blocking to protect applications against live attacks.
Example
A RASP agent detects an attempt to inject SQL through a parameter and blocks the request before it reaches the database, logging the event to the SIEM.
Key Takeaway

RASP adds a live line of defense. Validate agents in canaries and monitor for false positives before broad rollout.

Operational considerations
  • Test compatibility and performance impact in staging or canary deployments.
  • Configure logging and alerts to feed into your monitoring and incident response processes.
  • Use RASP alongside SAST/DAST/IAST; it does not replace secure coding practices.
Misconception
RASP is not a silver bullet. It helps stop runtime attacks but should be part of a layered strategy that includes secure design and testing.
