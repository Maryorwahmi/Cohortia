What SAST does
Analyzes code statically to find patterns that indicate vulnerabilities.
-- Vulnerable SQL pattern a SAST would flag
query = "SELECT * FROM users WHERE id = " + user_input
execute(query)

-- SAST flags string concatenation into SQL and recommends parameterization
Example
A rule detects concatenated SQL and suggests using parameterized queries to prevent SQL injection.
Common mistake
Running SAST only at release leads to expensive refactors; tune rules to avoid ignored false positives.
Key Takeaway

Integrate SAST into CI and developer workflows so issues are found and fixed when they are least costly.

Triage & integration
  • Run lightweight local scans on developer machines before committing.
  • Trigger a full SAST scan in CI for pull requests and block merges on severe findings.
  • Map findings to issue trackers and provide remediation hints to developers.
Misconception
SAST is not a complete solution. It does not detect runtime configuration or authentication issues and produces false positives unless tuned.
Check your understanding
If your team receives hundreds of low-value SAST alerts, consider adjusting rule thresholds, adding suppressions, and training developers on triage.
