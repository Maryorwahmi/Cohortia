Module 3 › Chapter 2.6 › DAST
What DAST does
Simulates attacker behavior against a running application to validate real-world exposures.
-- Reflected XSS payload example shown for educational purposes
Input: "<script>alert('xss')</script>"
If the response includes this script unescaped, DAST flags a reflected XSS.
Example
A DAST test submits malicious input to a form and observes script execution or unescaped responses.
Key Takeaway

DAST finds runtime weaknesses. Run it in staging with representative data and authenticated scans for protected flows.

Operational notes
  • Use credentialed scans for authenticated endpoints.
  • Scope scans to high-value pages to control runtime and resource usage.
  • Schedule full-site scans when load windows permit or run incremental scans for frequent checks.
Common misconception
DAST does not remove the need for SAST; they target different classes of vulnerabilities and work best together.
