Module 3 › Chapter 2.6 › DevSecOps Pipeline
Pipeline stages with security gates
Plan & Code
Threat modeling, local SAST
Build (CI)
Automated SAST, dependency and container scanning
Test
DAST in staging, IAST agents
Release
WAF/API Gateway deployment, final image checks
Operate
SIEM, RASP alerts, vulnerability management
Practical rule: block on high-severity findings in CI, fail deployment on unscanned container images, and ensure WAF policies are applied before routing traffic.
Critical controls
  • Dependency scanning for OSS vulnerabilities.
  • Container image scanning for CVEs and config issues.
  • Secret management using a vault for keys and credentials.
Pitfall
Adding a tool without automating its checks creates manual bottlenecks and unreliable coverage.
