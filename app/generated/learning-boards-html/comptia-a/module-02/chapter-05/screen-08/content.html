Module 2 › Chapter 2.5 › Automated Response
Response patterns
Isolation: remove network access to prevent lateral movement.
Process termination: stop malicious activity in progress.
File quarantine/deletion: remove known-malicious artifacts.
Forensic capture: collect memory and disk images for deeper analysis.
Staged automation example
  1. Alert and notify analyst.
  2. If alert confidence high and matches policy, terminate process.
  3. If ransomware pattern detected, isolate endpoint and capture memory.
Safety considerations
  • Define critical endpoints excluded from immediate isolation.
  • Require multi-indicator confirmation for high-impact automated actions.
  • Conduct regular automation drills and rollback tests.
Key Takeaway

Automated actions speed containment but must be constrained by role, confidence, and thorough testing to avoid operational disruption.
