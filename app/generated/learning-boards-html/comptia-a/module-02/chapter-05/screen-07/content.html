Module 2 › Chapter 2.5 › Investigating Alerts
Read the process tree
Identify the alerting process, then find its parent and any children. Note command-line arguments, working directory, user, and timestamps to determine causality.
Fields to collect
  • process_name, command_line, process_path
  • parent_process_name, parent_pid
  • timestamp, user, endpoint_id
  • network connections and file hashes
Example timeline
10:00:00 Document opened → 10:00:10 powershell.exe spawned → 10:00:12 outbound connection to unusual IP → 10:00:20 file written to user profile → 10:01:00 registry Run key added.
Key Takeaway

A reliable incident timeline requires correlating process relationships, timestamps, network, and file artifacts before remediation.
