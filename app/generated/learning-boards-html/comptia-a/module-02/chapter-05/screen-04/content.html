Module 2 › Chapter 2.5 › EDR vs AV
Definition
EDR continuously records endpoint telemetry for detection, hunting and response; antivirus uses signature-based prevention.
Telemetry types
Process execution, file changes, registry events, and network activity provide a timeline for investigations.
Behavior visibility
EDR focuses on anomalous behavior, enabling detection of previously unknown threats.
Complementary role
Use both EDR and antivirus together: prevention plus extended detection and response.
Concrete Example
An obfuscated PowerShell script executes and reaches out to an external host. AV may not flag it without a signature, but EDR logs the script call, command-line, spawned child processes, and outbound connections to reconstruct the activity and enable containment.
Key Takeaway

EDR gives the context and timeline needed to hunt and respond to threats that traditional prevention may miss.

Common Mistake
Deploying EDR without storage planning, causing dropped telemetry and missed detections.
Pro Tip
Start with a pilot group to tune data collection and response rules before wide rollout.
