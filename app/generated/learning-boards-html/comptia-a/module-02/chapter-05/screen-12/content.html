Module 2 › Chapter 2.5 › Investigation Walkthrough
Scenario steps
  1. Record alert details: host, user, timestamp.
  2. If high risk, isolate endpoint; otherwise collect artifacts first.
  3. Examine process tree: parent, command-line, children.
  4. Query network connections for suspicious hosts and ports.
  5. Search file hashes across environment to measure scope.
  6. Remediate (terminate, quarantine, delete) and collect forensic images if needed.
  7. Return endpoint to service and monitor closely.

Key Takeaway

Follow the steps methodically: collect artifacts before destructive actions unless immediate containment is required.
