Module 2 › Chapter 2.5 › Threat Hunting
Hunting steps
  1. Form hypothesis describing suspicious behavior to search for.
  2. Write focused telemetry queries with time and context constraints.
  3. Validate results and pivot to parent/child process relationships.
  4. Collect artifacts, build timeline, and document indicators.
  5. Turn validated indicators into detections or automated playbooks.
Example pseudo-query
process_name == "powershell.exe"
and command_line contains "-EncodedCommand"
and process_path not in ("C:\\Windows\\System32\\WindowsPowerShell\\v1.0")
| join network_connections on endpoint_id
| where remote_ip not in (known_good_ips)
| where timestamp between (now-24h, now)
Interpreting results
  • Check parent process to spot unusual spawn chains.
  • Review user context and login activity for privilege escalation.
  • Pivot to file system and registry events for persistence artifacts.
Key Takeaway

A targeted hypothesis plus focused queries and pivoting across telemetry yields high-confidence findings that can be operationalized.
