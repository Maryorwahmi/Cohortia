Module 02 › Chapter 2.4 › Key Concepts
CASB
Policy enforcement and DLP between users and SaaS apps.
Hybrid Cloud
A mix of on-premises and public cloud with orchestration between them.
VPC / VNet
Logically isolated network where cloud resources are placed and segmented.
Summary

Use these concise definitions as a checklist when selecting tools and validating designs: CASB for SaaS, CWPP for workloads, CSPM for posture, and unified identity for hybrid operations.
