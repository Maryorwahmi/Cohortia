Module 02 › Chapter 2.4 › IaaS Security Integration
Architecture: virtual network + host protection
Network segmentation
Define VPC/VNet subnets for tiers. Use security groups to limit port access and avoid broad CIDR ranges.
Host protection
Deploy CWPP/EDR agents to VMs for vulnerability scanning, runtime policies, and host-based firewalling.
Identity
Replace static credentials with IAM roles and policies configured for least privilege and temporary credentials.
Annotated example
Example: Secure app tier
App instances run in a private subnet with a role granting only S3 read for backups. Security group allows 443 from the load balancer and SSH only from a jump host IP.
Common mistake
Lifting on-prem host rules without using cloud-native labels and roles.
Key Takeaway
Combine network rules, IAM least privilege, and CWPP agents for layered protection.
