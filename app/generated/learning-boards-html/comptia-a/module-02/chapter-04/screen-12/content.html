Task 1: S3 configuration review (conceptual)
  1. Publicly Accessible Bucket: Risk of data exposure and compliance violation; fix by setting private ACLs and removing public policies.
  2. Lack of Server-Side Encryption: Risk that stolen storage is readable; fix by enabling encryption and key management.
  3. Overly Permissive Bucket Policy/ACL: Risk of unauthorized uploads or deletes; fix by tightening actions and principals to least privilege.
Task 2: CASB for Microsoft 365
Define a DLP policy that matches PII patterns and external recipients. The CASB inspects content via API or proxy and then blocks, quarantines, or encrypts messages when matches occur. Start with monitoring, tune rules, then enable blocking to avoid disrupting business workflows.
Example CASB action
If a pattern matching a national ID is detected in an email to a personal address, the CASB can block sending and alert the security team.
Key Takeaway

Combine CSPM detection with CASB enforcement to prevent configuration-based exposure and policy-based data loss in SaaS.
