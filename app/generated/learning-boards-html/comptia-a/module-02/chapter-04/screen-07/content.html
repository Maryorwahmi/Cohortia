Module 02 › Chapter 2.4 › SaaS & CASB Comparison
CASB deployment modes
API mode
Uses provider APIs for activity logs and content inspection; easier to integrate but may be near-real-time.
Proxy mode
Intercepts traffic for real-time enforcement; forward or reverse proxies can block or encrypt traffic but require routing changes.
Concrete example
Preventing data leaks from Outlook
A CASB with DLP inspects outgoing email and attachments for PII. If a match is found to an external personal address, the CASB can block, quarantine, or encrypt that message depending on policy.
Misconception
CASB replaces identity controls. In reality, CASB complements SSO and MFA, it does not replace them.
Key Takeaway
Combine identity controls with CASB policies to enforce DLP and monitor SaaS activity effectively.
