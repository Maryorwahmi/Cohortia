Module 02 › Chapter 2.4 › Identity Synchronization
Design considerations
  • Decide which attributes and groups to sync to the cloud identity service.
  • Use federation or sync depending on SSO needs and account lifecycle.
  • Require MFA for administrative or privileged access.
Verification & operations
Run SSO flow tests, monitor authentication logs for anomalies, and ensure user provisioning and deprovisioning are reflected correctly in the cloud to avoid orphan accounts.
Misconception
Sync everything. Instead, filter to sync only necessary accounts and groups to minimize cloud exposure.
Key Takeaway
Plan attribute mapping and enforce MFA while auditing authentication to keep identities secure across hybrid environments.
