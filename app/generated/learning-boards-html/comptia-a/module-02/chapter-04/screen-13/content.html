Module 02 › Chapter 2.4 › Assessment & Mistakes
Sample assessment questions
  1. Which solution protects cloud workloads with vulnerability management and runtime defense? CWPP.
  2. Which integration ensures corporate credentials work across hybrid apps? Directory synchronization with cloud IAM.
Common integration pitfalls
  • Treating cloud as isolated from enterprise policies.
  • Granting excessive privileges to posture tools and agents.
  • Over-relying on a single control without layered defenses.
Key Takeaway
Assessments should require operational plans, expected telemetry, and rollback steps to confirm safe integrations.
