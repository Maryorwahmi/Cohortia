Module 02 › Chapter 2.4 › PaaS Security Focus
Key controls for PaaS
Secure application development and code scanning in CI/CD pipelines.
API security via gateways and proper authentication schemes.
Secret management using cloud-native services and rotation.
WAF protections and logging for platform endpoints.
Concrete scenario
Event function secret handling
Store DB credentials in a secret manager and grant the function read-only access to that secret. Ensure the function redacts or avoids logging sensitive values.
Misconception
PaaS equals secure by default. Platform management removes some risks but not application misconfiguration.
Key Takeaway
Prioritize secret management, API policies, and secure CI pipelines in PaaS environments.
