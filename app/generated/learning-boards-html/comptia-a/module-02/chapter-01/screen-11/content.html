Process Flow › Automation & SOAR
Progressive automation
  1. Read-only evidence gathering and enrichment.
  2. Automated notifications with suggested remediation steps.
  3. Limited automated remediation with validation gates.
  4. Human-in-the-loop for high-impact changes.
Always ensure playbooks are reversible and logged for auditability.
Example playbook
Trigger: SIEM correlates repeated exploit attempts from a host. Actions: check endpoint posture, add temporary NGFW deny rule for the host, isolate endpoint if posture fails, notify SOC. Final step: create ticket and require human close-out.
Common misconception
Automation should not be an immediate full replacement for human oversight—start small and verify outcomes.
