Core Concept › Centralized Management & Logging
Why centralize
Centralized logs allow event correlation across devices, revealing complex incidents that single devices cannot show.
Consistent timestamps and normalized fields make correlation reliable.
Forward logs securely to a SIEM for real-time correlation and alerting.
Use orchestration to automate validated responses, but validate playbooks before production.
Concrete example
An NGFW logs blocked exploit attempts while a switch logs port-security violations from a workstation. The SIEM correlates both into an incident, triggering a SOAR playbook to isolate the endpoint and notify the security team.
Common pitfall
Forwarding partial logs or using inconsistent time sources makes incident reconstruction difficult.
Verification: confirm all devices forward logs, check time sync, and run correlation tests using simulated incidents.
