Switch configuration (conceptual)
vlan 10
 name FINANCIAL_APPS
exit

interface GigabitEthernet0/1
 switchport mode access
 switchport access vlan 10
 switchport port-security
 switchport port-security maximum 1
 switchport port-security violation restrict
 switchport port-security mac-address sticky
exit
Note: this is a conceptual command sequence. Test in a lab environment and document learned MAC addresses.
NGFW policy (conceptual)
Policy: Allow_Finance_HTTPS_to_Apps
 Source Zone: Internal_Finance_Zone
 Source IP: 192.168.10.0/24
 Dest Zone: Financial_App_Zone
 Dest IP: 172.16.10.0/24
 Application: HTTPS (TCP/443)
 Action: Allow
 Logging: Enable

Policy: Deny_All_Other_to_Apps
 Source Zone: Any
 Dest Zone: Financial_App_Zone
 Action: Deny
 Logging: Enable
Validation: test HTTPS from allowed host and check allow logs.
Validation: attempt access from unallowed IP and confirm denial and logged event.
Keep a rollback plan and perform changes during a maintenance window where possible.
