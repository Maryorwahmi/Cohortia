Definition › Micro-segmentation & Policy Design
Why segment
Limiting which workloads can communicate reduces attacker movement and simplifies containment during incidents.
Deny-by-default
Only create allow rules for explicitly required flows between segments.
Classify assets by sensitivity and service dependencies before creating rules.
Document allowed flows and test them with representative traffic patterns.
Concrete scenario
Create VLAN 10 for financial servers. Allow only HTTPS from finance workstation subnet and management subnet. Block all other access to VLAN 10 and log denied attempts for forensic analysis.
Example control: NGFW rule permitting only application-level HTTPS from 192.168.10.0/24 to 172.16.10.0/24 with logging enabled.
Validation: run connection tests from approved hosts and confirm denied flows are blocked and logged.
Maintain a change log so rule evolution does not erode the deny-by-default posture.
