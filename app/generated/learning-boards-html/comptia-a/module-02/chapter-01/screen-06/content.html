Process Flow › Router & Switch Hardening
Step-by-step hardening
  1. Inventory: list devices, firmware, management IPs, and interfaces.
  2. Baseline: disable unused ports, update credentials, enforce SSH.
  3. Segmentation: create VLANs for sensitive systems and apply ACLs.
  4. Port security: limit MAC addresses and configure violation behavior.
  5. 802.1X: enable for authenticated network access where possible.
  6. Routing auth: enable authentication for OSPF/BGP to prevent route injection.
Example command flow
Create VLAN, assign port to VLAN, enable port-security with maximum 1 MAC and sticky learning. Test and document.
Pitfall
Applying port-security without a documented MAC list can cause unplanned outages; always test on a maintenance window.
Supporting cards
VLAN segmentation reduces attack surface and isolates sensitive services.
802.1X enforces endpoint authentication before Layer 2 access.
Routing protocol auth prevents malicious route injection between peers.
Document every change and include a rollback plan to preserve availability during hardening.
