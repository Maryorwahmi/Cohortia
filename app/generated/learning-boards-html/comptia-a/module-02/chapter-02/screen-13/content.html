Hands-on Activity
SAML SSO Integration Checklist
Prepare Active Directory
Validate replication, choose attributes to sync (UPN, email, groups), and enforce AD password policies and MFA for admin accounts.
Deploy Sync Agent
Install agent on domain-joined server, secure its connection to the cloud IdP, and configure provisioning rules.
Configure SP
Enter IdP SSO URL, issuer, ACS URL, and upload IdP certificate where required by the application.
Configure IdP for SP
Add the application, map AD attributes to SP claims, and assign test users or groups.
Testing
Use a pilot user to test login, verify NameID and group claims, and review IdP and SP logs for assertion errors.
Operate & Monitor
Enable MFA at the IdP, forward logs to SIEM, schedule access reviews, and document rollback procedures.
Key Takeaway

Follow the checklist: prepare AD, deploy sync, configure SP and IdP metadata, test with pilots, and enforce MFA and monitoring.
