Module 2 › Chapter 2.2 › IGA vs IAM Ops
Comparison
Identity Governance vs IAM Operations
IAM Operations
Authentication, SSO, MFA enforcement, and runtime access controls managed by IdP and access policies.
IGA
Provisioning, deprovisioning, access reviews, role mining, and certification campaigns for governance.
Use Case
IGA: periodic access reviews and role-based provisioning.
Integration
IGA consumes directory and IdP attributes to automate lifecycle actions.
Pitfall
Poor attribute quality undermines governance automation.
Key Takeaway

Use IGA for lifecycle and compliance tasks while IAM handles authentication; both must be integrated for consistent identity controls.
