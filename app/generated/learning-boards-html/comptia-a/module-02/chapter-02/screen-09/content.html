Module 2 › Chapter 2.2 › PAM Session Architecture
Architecture
Vault, Broker, Monitoring
Credential Vault
Encrypts and stores privileged credentials, manages rotation and TTL policies, and provides access controls for retrieval.
Session Broker
Proxies sessions or issues ephemeral credentials so secrets are never exposed on admin endpoints.
Monitoring & Audit
Records sessions, collects logs, and forwards events to SIEM for alerting and forensic analysis.
Integration points
Directory authentication, MFA at PAM entry, SIEM log forwarding.
Availability
Design redundancy and controlled break-glass paths to avoid operational outages.
Key Takeaway

Treat PAM as critical infra: secure it with MFA, isolate it, and ensure high availability while recording activity for auditability.
