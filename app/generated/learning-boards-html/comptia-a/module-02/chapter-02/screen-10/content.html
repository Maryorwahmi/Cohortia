Module 2 › Chapter 2.2 › Directory Services
Definition
Active Directory & LDAP
Authoritative stores for user identities, groups, and policies in enterprise networks.
Key attributes: UPN, email, group membership drive access decisions in cloud apps.
Sync tooling: Use connectors such as directory sync agents to mirror accounts to cloud directories.
Common pitfall: Inconsistent attribute mapping causes denied access or duplicated identities.
Hybrid pattern example
Run a sync agent on a domain-joined server, select attributes to export, and test group-based authorization in a cloud app using a test user. Ensure deprovisioning removes cloud access.
Schema extensions
Document and test extensions to avoid compatibility issues across directory versions and cloud connectors.
Security controls
Segment directory servers, harden admin access, and monitor for changes and replication errors.
Key Takeaway

Treat the directory as authoritative, plan attribute mapping and lifecycle actions, and secure directory services as high-value assets.
