Module 2 › Chapter 2.2 › SAML vs OIDC
Comparison
SAML and OIDC side-by-side
SAML
  • XML-based assertions for browser SSO
  • Common in enterprise portals and legacy apps
  • Requires metadata exchange and certificates
OIDC
  • JSON web tokens and REST endpoints
  • Designed for modern web, mobile, and APIs
  • Built on OAuth2 with lighter payloads
When to pick SAML
Enterprise web apps with existing SAML integrations.
When to pick OIDC
APIs, mobile, and modern single-page apps.
Common pitfall
Assuming protocol choice removes the need to validate claims and audience values.
Key Takeaway

Select the protocol based on application type and integration capabilities; enforce claim validation and secure metadata for both.
