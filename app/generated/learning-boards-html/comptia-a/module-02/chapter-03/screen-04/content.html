Module 2 › Chapter 2.3 › Inventory and Onboard Log Sources
Phased Onboarding Process
Step 1: Inventory sources — network, servers, endpoints, apps, cloud, security tools.
Step 2: Prioritize — identity, perimeter, critical servers first.
Step 3: Choose transport — syslog, agent, API, or cloud connector.
Step 4: Test forwarding and monitor ingestion rates to prevent drops.
Supporting Notes
  • Document log formats and required parsing fields for each source.
  • Run test ingestion on a representative subset before wide rollout.
  • Plan SIEM capacity and retention based on estimated event volume.
Concrete Example
Phase 1
Onboard domain controllers and perimeter firewalls. Validate parsing of authentication and network deny events.
Phase 2
Add EDR, web servers, and cloud audit logs. Tune ingest rules to filter verbose debug entries.
Key Takeaway

A phased, documented onboarding plan with test ingest prevents gaps and overloads that undermine detection.
