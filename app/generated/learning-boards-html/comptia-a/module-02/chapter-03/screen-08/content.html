Module 2 › Chapter 2.3 › Detecting Lateral Movement and Exfiltration
Comparison: Single Event vs Correlated Sequence
Single Event

A large outbound transfer can be benign if part of scheduled backup or a known business process.

Correlated Sequence

Authentication anomaly followed by outbound transfer to an external, suspicious IP is higher fidelity and warrants escalation.

  • Track baseline access per account to spot unusual server access.
  • Combine auth logs with network egress to detect possible exfiltration.
  • Use threat intelligence to add signal about external destinations.
Analyst Guidance

When confidence is medium, run enrichment playbooks before containment. For high-confidence events, follow validated containment steps with approval where required.

Concrete Scenario

An account authenticates to five previously unseen servers within 15 minutes and, minutes later, a large file transfer to an external IP occurs. Correlation rule combines the authentication anomaly and transfer, checks threat feeds for the external IP, and raises a high-severity alert for immediate review.

Key Takeaway

Correlation across event types provides context and reduces false positives when detecting attacker progression.
