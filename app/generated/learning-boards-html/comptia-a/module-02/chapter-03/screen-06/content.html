Module 2 › Chapter 2.3 › Parsing and Forwarding Agents
Architecture Choices
Edge Parsing
Parses at agent, reduces bandwidth but increases management complexity.
Central Parsing
Collectors receive raw logs and centralize parsing and mapping logic.
Monitoring Checklist
  • Ingestion rate and latency.
  • Dropped-event counters.
  • Parser error logs and timestamp accuracy.
Practical Tip

Filter verbose debug lines at source or collector to reduce noise, but always preserve a raw sample for re-parsing during tuning.

Scenario

A high-traffic web farm produces thousands of access logs per minute. Instead of sending all entries, the collector filters health-checks and static file hits, forwarding only authentication and error events for parsing and long-term retention. Monitoring shows ingestion within capacity and zero dropped events after tuning.

Key Takeaway

Parsing location is a trade-off. Choose based on bandwidth, manageability, and the ability to reprocess raw events later.
