Module 2 › Chapter 2.3 › How Enrichment Improves Triage
Enrichment Sources
  • EDR telemetry for process and file activity.
  • Vulnerability scanner results for system exposure.
  • Identity provider data for user behavior patterns.
  • Threat intelligence IOC matches.
Conditional Enrichment

Only run full enrichment when initial rule confidence is medium or higher to save resources and avoid delays.

Example Flow

Rule triggers on suspicious login. SIEM queries EDR and threat feeds. EDR returns a live alert and feed flags the IP. SIEM raises severity and suggests immediate containment steps in the analyst’s incident view.

Key Takeaway

Enrichment adds decisive context, but should be conditional to conserve resources and keep triage fast.
