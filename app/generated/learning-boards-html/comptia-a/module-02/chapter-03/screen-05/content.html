Module 2 › Chapter 2.3 › Normalize Diverse Log Formats
Definition

Normalization converts varied log formats into a common schema so correlation rules can operate reliably across sources.

Formats
  • Syslog
  • Windows Event Logs
  • JSON from cloud APIs
  • Proprietary appliance formats
Normalization
Map vendor fields to standard names like source_ip, user, action, and timestamp.
Common Mistake

Skipping raw preservation. Always keep the raw event so parsers can be updated when new fields are needed.

Concrete Example

A firewall logs address under src_ip while an application logs ip_address. Normalization maps both to source_ip so a single correlation rule can count failed attempts per source_ip.

Key Takeaway

Normalization is foundational: it lets correlation, enrichment, and analytics operate across sources without fragile, format-specific rules.
