Definition › Federated Identity
How federation works
Users authenticate with an external provider, obtain assertions, and gain cloud access without separate cloud credentials.
Protocols
Common protocols include SAML and OpenID Connect for web-based SSO and token exchange.
Enterprise sync
Tools like Azure AD Connect synchronize on-premises users to the cloud identity store for SSO.
Concrete example
Configure SSO so employees sign in with corporate AD credentials to access Azure portal and SaaS apps, removing the need to maintain separate cloud passwords.
Misconception
Federation centralizes authentication but you still must manage cloud-side roles and permissions. Federation does not replace authorization controls.
Key Takeaway

Federation simplifies sign-on and centralizes identity controls. Keep authorization in the cloud and monitor federated sign-ins.
