How to show competency
Concrete checks and deliverables you will produce to demonstrate each learning objective.
Documented IAM map
A mapping of users, groups, roles and key resources showing who can access what and why.
Example deliverable: a table listing roles and scoped resources.
VERIFIED COMPETENCY MILESTONE
Scoped policy example
A JSON policy granting only required actions on a single resource, e.g., s3:GetObject on a named bucket.
Example deliverable: policy JSON and a short justification for each permission.
VERIFIED COMPETENCY MILESTONE
MFA & federation evidence
Screenshots or logs showing MFA enabled and federation configured with AD sync or SAML assertions.
Example deliverable: an admin user with MFA status and a successful SSO sign-in report.
VERIFIED COMPETENCY MILESTONE
Audit configuration
Centralized, immutable logs with alerts for high-risk IAM events like new admin creation or policy changes.
Example deliverable: a retained CloudTrail/Azure Activity Log and an active alert rule.
