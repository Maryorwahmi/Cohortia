Comparison › Common Mistakes
Overly permissive policies
Wildcards like s3:* or resource "arn:aws:s3:::*" expand permissions beyond need and are frequent root causes of breaches.
Remediation steps
  1. Find policies with wildcards using analyzer tools.
  2. Determine required actions and resources used by the app.
  3. Replace with scoped statements and test.
Stale credentials
Unused access keys and orphaned roles increase exposure if compromised.
Remediation steps
  1. Inventory keys and roles, flagging those unused for a retention window.
  2. Revoke or rotate keys and disable unused roles after verification.
  3. Automate detection and enforce rotation policies.
Key Takeaway

Detect and remove wildcards and stale credentials, then verify changes with tests and monitoring to prevent regressions.
