Instance roles
Attach roles to compute so applications obtain short-lived credentials automatically.
Example flow
  1. Define a role that allows s3:GetObject on a specific bucket.
  2. Attach the role to the EC2 instance profile.
  3. Application retrieves temporary credentials and accesses S3.
Ensure trust policies restrict who or which service can assume a role, and avoid opening the trust relationship to broad principals.
Validation snippet (conceptual)
# On the instance, query metadata service for temporary credentials and test access using AWS SDK or CLI to read an object from secure-app-data-12345
Common mistake
Embedding access keys in configuration or environment variables. Those keys are long-lived and increase exposure if leaked.
Key Takeaway

Temporary credentials via roles reduce credential sprawl and support automatic rotation, but still require scoped permissions and monitoring.
