Core Concept › Multi-Factor Authentication
Why MFA matters
MFA adds an independent verification step to prevent access after a password leak.
Practical enforcement
Enable MFA for all administrative roles and enforce it via provider controls or conditional access policies.
Recovery planning
Define secure recovery for lost tokens to avoid admin bypasses that weaken MFA protections.
Concrete example
Require virtual MFA devices for console access and a hardware token for break-glass administrative accounts. Log the MFA events for correlation with sign-in records.
Misconception
Assuming MFA is only for root accounts. In cloud environments, any privileged or sensitive account should use MFA.
Key Takeaway

MFA stops many credential-based attacks. Enforce it broadly, plan for recovery, and log MFA events for audits.
