Module 4 › Chapter 4.4 › Network segmentation
Why policies matter

Network Policies let you declare which pods may talk to which endpoints. Use them to limit attack paths and protect sensitive services like databases.

Concrete example

Create a policy that allows only the frontend pod selector to reach the database pod on its listening port. All other sources are denied by default.

Common mistake

Assuming cluster network defaults are secure. Many clusters allow broad communication unless you apply explicit policies.

Policy pattern
  1. Establish default deny for ingress and egress.
  2. Allow specific pod selectors and ports for required flows.
  3. Test policies carefully and iterate to avoid outages.
Key Takeaway

Network policies reduce lateral movement. Start with deny-all and add minimal allows for services that must communicate.
