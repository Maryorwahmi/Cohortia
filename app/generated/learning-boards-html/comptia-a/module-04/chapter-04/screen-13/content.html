Module 4 › Chapter 4.4 › Common mistakes & CI/CD
Frequent mistakes
  • Using 'latest' tags leads to unreviewed changes.
  • Running containers in privileged mode or exposing the runtime API.
  • Not scanning images before deployment.
CI/CD action

Integrate scanning tools into build jobs and fail builds on critical findings. Require image signing before production push so only vetted artifacts are deployed.

Practical checklist
  1. Pin image tags; do not use 'latest'.
  2. Run automated scans in CI and block on critical CVEs.
  3. Enforce non-privileged runtime modes and drop unnecessary capabilities.
Key Takeaway

Shift left: prevent insecure images from being built and require signing to maintain provenance across deployments.
