Module 4 › Chapter 4.4 › Key Concepts
Containerization
OS-level virtualization where containers share the host kernel.
Container Image
A layered, immutable artifact containing code, libraries, and settings.
Container Registry
Central repository for storing and distributing images; enforce access and signing.
Takeaway

Provenance, vetting, and runtime enforcement are the pillars of container security—apply them across build, push, and run stages.
