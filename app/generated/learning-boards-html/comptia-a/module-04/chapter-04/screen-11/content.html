Module 4 › Chapter 4.4 › Runtime monitoring and threat detection
Monitoring goals
  • Observe system calls and process behavior.
  • Detect anomalous file or network access patterns.
  • Provide alerts and forensic logs for incident response.
Tool examples

Falco for syscall rules, Aqua or Sysdig for broader runtime policy enforcement and response.

Concrete rule example

A rule: alert when a container not labeled 'debug' execs a shell or tries to write to /etc. This indicates suspicious interactive access and should trigger an investigation.

Misconception

Relying only on scans misses runtime exploits. Detection is complementary and necessary for live environments.
