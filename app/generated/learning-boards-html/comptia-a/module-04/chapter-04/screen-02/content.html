Learning Objectives

Four verified competencies to secure container lifecycles.

Bloom: Learn → Understand → Apply → Master
01. Container fundamentals

Define containers and explain the shared-kernel model. This matters because isolation relies on kernel controls rather than separate hardware virtualization.

Mnemonic: Venn — app + libraries + kernel boundary
VERIFIED COMPETENCY MILESTONE
02. Image & registry risk

Identify dangerous base images, pin versions, and validate provenance. This prevents unknowingly deploying vulnerable or malicious images.

Mnemonic: Timeline — build → scan → sign → deploy
VERIFIED COMPETENCY MILESTONE
03. Runtime hardening

Apply least privilege, resource limits, and network policies so running containers have minimal attack surface.

Mnemonic: Checklist — user, caps, limits, network
VERIFIED COMPETENCY MILESTONE
04. Secrets & scanning in pipeline

Manage secrets with dedicated stores and shift image scanning left into CI to stop vulnerable images before deployment.

Mnemonic: Inject at runtime; rotate regularly
VERIFIED COMPETENCY MILESTONE
