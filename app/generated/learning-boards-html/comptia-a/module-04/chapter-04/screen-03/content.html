How you'll apply the skills

Concrete checks and tasks to prove competency.

Checklist style
Explain the shared-kernel model
  • Define what is shared and why isolation is not hardware-based.
  • Example: kernel exploit impact across containers and host.
  • Check: can you describe a mitigation at the host level?
Image pipeline gate
  • Pin base image version and scan with Trivy or Clair.
  • Reject builds with critical CVEs before push to registry.
  • Check: pipeline shows a signing step after successful scan.
Runtime hardening task
  • Run containers as non-root and drop unnecessary capabilities.
  • Set CPU and memory resource limits to avoid DoS by one container.
  • Check: verify effective UID and capability set inside container.
Secrets and rotation
  • Use Vault, Kubernetes Secrets, or cloud secret stores for injection.
  • Avoid baking secrets in images or committing them to source control.
  • Check: secret is accessed at runtime and not present in image layers.
