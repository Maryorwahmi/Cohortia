Comparison
Type 1 — Bare-metal
Runs directly on hardware; smaller attack surface and higher performance.
Security attributes
  • Minimal codebase to patch and audit.
  • Isolated from general-purpose OS vulnerabilities.
  • Preferred for enterprise production workloads.
Example
VMware ESXi or Microsoft Hyper-V used in datacenters for production VMs.
Comparison
Type 2 — Hosted
Runs as an application on a general OS, inheriting its attack surface and update cadence.
Security attributes
  • Convenient for development and testing.
  • Vulnerabilities in the host OS can affect the hypervisor and guests.
  • Not recommended for high-assurance production services.
Example
VirtualBox or VMware Workstation on a user laptop used for testing images.
