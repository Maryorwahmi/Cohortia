Architecture
Network Segmentation
Design virtual network zones with port groups, VLANs, and distributed switch policies.
Recommended zones
  • Management VLAN: hypervisor and admin tools only.
  • DMZ: public-facing services with strict outbound rules.
  • Internal: application and database VMs with restricted access.
Platform features
vSphere Distributed Switches let you apply consistent network policies across multiple hosts and port groups.
Key Takeaway

Logical network boundaries are as important as host hardening — combine both for effective containment.

Concrete Configuration
Create port groups for each zone and assign VLAN tags. Apply firewall rules between port groups to allow only required traffic flows.
Example policies
  • Management port group: allow SSH/HTTPS only from admin network.
  • DMZ web port group: allow HTTP/HTTPS from internet, restrict database access to application port group.
  • Internal DB port group: allow database ports only from application port group.
Check your understanding
If a web VM is compromised, segmentation and port group rules should prevent it from initiating direct connections to internal database VMs.
