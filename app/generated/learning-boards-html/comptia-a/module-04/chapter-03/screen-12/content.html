Process
Logging, alerting, and response
Log sources to collect
  • Hypervisor audit and management access logs.
  • Guest OS security logs and EDR telemetry.
  • Virtual switch and port group flow records.
Detection rules
Alert on unusual hypervisor API calls, rapid VM provisioning, or unexpected inter-VM traffic patterns.
Response playbook
Isolate host, snapshot evidence, notify stakeholders, and remediate according to severity and containment guidance.
Validation
Run tabletop exercises and verify logs contain necessary fields for investigations.
Key Takeaway

Detection and practiced response shorten attacker dwell time and reduce impact on the virtual estate.
