This module focuses on the trust boundary that the hypervisor creates, common virtualization threats, and practical hardening steps. Expect examples for ESXi and guidance for Windows Server guests.

Hypervisor
Software or firmware that runs VMs and enforces isolation.
VM Escape
When a guest breaks isolation and accesses the hypervisor or other VMs.
VM Sprawl
Uncontrolled VM proliferation that increases attack surface.
Network Segmentation
Use VLANs and port groups to limit lateral movement.
