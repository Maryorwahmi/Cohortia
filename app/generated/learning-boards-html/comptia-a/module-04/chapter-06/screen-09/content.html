Module 4 › Chapter 4.6 › Data in Use
What data in use means
Any data being processed by CPU or stored in application memory is considered data in use and can be vulnerable to privileged access or memory disclosure.
Mitigations
Limit plaintext lifetime, reduce logging of secrets, use strict process isolation, and consider TEEs for high-risk workloads.
Confidential computing
Hardware enclaves or trusted execution environments isolate memory so even host operators cannot read plaintext inside the enclave.
Concrete scenario
Processing decrypted payment tokens in a billing microservice: reduce the time tokens remain in memory, restrict service roles, and consider enclave protection for maximum assurance.
Misconception
Believing that TEEs eliminate the need for encryption elsewhere. They are complementary and should be combined with strong key management and transit encryption.
Key Takeaway

Treat data in use as a distinct risk area and apply minimal plaintext lifetimes and isolation; consider TEEs when threat models demand it.
