Module 4 › Chapter 4.6 › KMS Operations
Rotation steps
Use envelope encryption to reduce re-encryption and automate key lifecycle management.
Create new data key
Generate a new data key and wrap it with the current master key for use by the application.
Switch usage
Update services to use the new data key for new objects while still accepting older wrapped keys for read operations.
Rotate master key
Version the master key in KMS and ensure policies permit dual usage during migration.
Access & audit
Grant decrypt to the service principal only. Use audit logs to review decrypt calls and identify anomalous access patterns.
Pitfall
Rotating keys without testing access or without adjusting IAM policies can cause outages.
Key Takeaway

Plan and test rotation paths; enforce least privilege and monitor key usage through audit logs.
