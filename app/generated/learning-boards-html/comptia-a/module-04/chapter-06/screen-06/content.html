Module 4 › Chapter 4.6 › Encryption Concepts
Encryption goals
Prevent unauthorized access and reduce risk when data is leaked or misused.
Data at rest
Stored data in databases, object storage, and disks. Options include provider-managed keys, KMS-driven keys, or client-side encryption.
Data in transit
Encrypt network traffic with TLS, VPNs, and mutual authentication between services.
Data in use
Protect data while it is processed in memory using TEEs and confidential computing technologies.
Example choices
A database containing payment info likely uses KMS-managed keys with enforced rotation. Public content may use provider-managed defaults if keys are not a compliance concern.
Common misconception
Assuming provider default encryption implies appropriate key control. Key ownership and rotation matter for audits and breach response.
Key Takeaway

Match encryption mode to sensitivity and required key control; do not treat encryption as a single, uniform setting.
