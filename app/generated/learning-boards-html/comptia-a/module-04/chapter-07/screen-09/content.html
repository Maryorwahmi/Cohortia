CWPP Capabilities
  • Vulnerability management for images and hosts.
  • Runtime anomaly detection and response.
  • Host-based intrusion detection and application control.
  • Micro-segmentation and network controls for workloads.
Concrete Example

A CWPP notices an unexpected outbound connection from a container, flags it as anomalous, quarantines the pod, and records process and network telemetry for investigation.

Misconception: Config checks are enough. In reality, runtime protection detects attacker behavior that configuration scanning cannot foresee.
Key Takeaway

Combine CSPM and CWPP for both posture checks and runtime detection to close more attack paths.
