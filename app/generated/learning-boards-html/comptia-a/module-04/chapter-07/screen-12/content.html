Process › Cloud Incident Response
Plan Components
  • Defined roles and cloud provider coordination.
  • Automated containment playbooks (serverless functions to act on alerts).
  • Forensic collection: snapshots, flow logs, audit trails.
  • Immutable centralized logging and retention policies.
Example Playbook

A WAF alert triggers a serverless playbook that blocks the offending IP in security groups, snapshots suspect volumes, and escalates to the IR team while preserving audit logs.

Misconception: Host-based forensics always works. In cloud, logs and snapshots are primary; prepare to collect provider artifacts quickly.
