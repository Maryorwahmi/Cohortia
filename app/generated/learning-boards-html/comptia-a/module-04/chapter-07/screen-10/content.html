Checklist for Secure Functions
  • Least privilege IAM per function.
  • Secrets via secure stores, not environment variables in code.
  • Strict input validation and sanitization.
  • Network placement and VPC integration as needed.
  • Centralized logs and traces for forensics.
Concrete Example

A function that uploads user images should only be permitted to write to a single storage prefix, fetch credentials from a secrets manager at runtime, and validate file types and sizes before any processing.

Misconception: Serverless reduces responsibility. Instead, you must secure code, permissions, and inputs because the execution environment is opaque.
