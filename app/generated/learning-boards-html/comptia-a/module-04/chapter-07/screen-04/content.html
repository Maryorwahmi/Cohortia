Module 5 › DevSecOps › Shift Left Security
What DevSecOps claims

Security is not a gate at the end of delivery. It is an integrated set of automated checks and policy gates across the pipeline.

  • SAST in pre-commit or pre-merge.
  • Image and dependency scanning on build.
  • DAST in staging environments.
  • IaC scanning before provisioning.
Key Takeaway

Automate checks where code and configs are authored to reduce late-stage fixes and production risk.

Concrete Example: Protect IaC

Add an IaC scanner to the merge pipeline so misconfigurations such as public storage or missing encryption fail the build.

# Example pipeline step (illustrative)
- name: Scan IaC
  run: checkov --directory infra --output json
- name: Block on fail
  run: exit 1 if checkov reported failures
Misconception: Security will slow delivery. Reality: early automated checks reduce rework and emergency fixes later.
