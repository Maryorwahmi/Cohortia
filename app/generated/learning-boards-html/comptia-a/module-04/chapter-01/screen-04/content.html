Public Cloud: benefits and risks
Shared infrastructure with provider responsibility for the physical layer.
Core Definition
Public cloud services run on shared infrastructure provided by a cloud service provider. The provider secures the data centers and underlying platform; customers manage their applications, data, and configurations.
Benefits
  • Provider-managed physical security and compliance investments
  • Elastic scale and managed services
Risks & Misconception
Assuming the provider configures access controls for you. Misconfiguration of ACLs or public storage is a customer fault.
Concrete Example
Object storage misconfiguration
A public storage container left without access rules exposes data. The CSP secured the data center; the customer failed to set proper bucket policies. Fix: enforce least-privilege IAM, enable block-public-access, and use encryption and logging.
Key Takeaway

Public cloud shifts infrastructure risk to the provider, but data handling and configuration remain the customer's responsibility.
