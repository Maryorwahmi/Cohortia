Scenario: SecureHealth Inc. — model selection
Evaluate workloads and propose controls for a regulated healthcare enterprise.
Workload Mapping
  • Marketing site: Public cloud — low risk, scalable
  • Anonymized research: Public cloud or community cloud — depends on sharing needs
  • PHI: Private or hybrid with PHI kept on-premises
  • Consortium research: Community cloud with shared governance
Hybrid Controls (minimum 3)
  1. Dedicated interconnects for secure, high-bandwidth traffic
  2. Unified IAM via federation or directory synchronization
  3. Centralized SIEM collecting logs from both environments
Shared Responsibility Example
For the public cloud portion, the CSP secures infrastructure; SecureHealth secures access controls and data encryption.
Key Takeaway

Align workload sensitivity with model choice, codify responsibilities, and implement dedicated connectivity, unified IAM, and centralized monitoring for hybrid deployments.
