Shared Responsibility Model
A partnership describing which security tasks each party must perform.
Provider Responsibilities
  • Physical data center security and environmental controls
  • Hypervisor and platform patching
  • Core network and hosting infrastructure
Customer Responsibilities
  • Data classification, encryption, and lifecycle management
  • Application and OS patching, IAM, and network configuration
  • Logging, monitoring, and incident response for customer workloads
Concrete Example
Managed VM
The CSP provides the host, hypervisor, and physical network. The customer must harden the guest OS, configure host-based firewalls, maintain application patches, and enforce user permissions. If a misconfigured firewall exposes a service, responsibility lies with the customer.
Pro Tip
Use provider-managed encryption keys where appropriate, but document who can rotate and access those keys.
