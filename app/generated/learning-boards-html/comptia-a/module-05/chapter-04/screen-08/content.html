Module 5 › Chapter 5.4 › CRL & CDP
Definition
CRL Distribution Points
CRLs list revoked certificates. CDP extension in certificates tells clients where to fetch the CRL.
Publication cadence
Choose how often CRLs are updated; more frequent updates reduce revocation latency but increase distribution load.
Endpoint availability
CRL endpoints must be highly available; clients must access the CRL to validate certificates reliably.
Caching
Clients cache CRLs; plan cache lifetime and distribution to balance freshness and performance.
Concrete example
Configure the issuing CA to include an HTTP CRL distribution point that is replicated across multiple servers so clients can always access the latest CRL.
Common mistake
Publishing CRLs infrequently to reduce load; this increases the window in which revoked certificates remain trusted by clients.
Key Takeaway

CRLs are reliable but can be delayed. Ensure CDP entries point to highly available endpoints and choose a publication schedule aligned to revocation urgency.
