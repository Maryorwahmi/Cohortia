Module 5 › Chapter 5.4 › Issuing CAs & Templates
Architecture
Issuing CA → Directory Integration
Issuing CAs handle requests and enforce template policy. AD CS enables auto-enrollment for domain-joined machines and users.
Certificate Templates
Predefine key usage, SANs, and validity. Use templates to prevent inconsistent certificates.
Auto-enrollment
Group Policy can automatically request and renew certificates for domain members, reducing manual errors.
Monitoring
Templates do not replace monitoring; log issuance and track expirations to avoid outages.
Concrete scenario
Configure a Web Server template in AD CS with Server Authentication and SANs. Use Group Policy to auto-enroll all web servers in a specific OU so certificates issue and renew without manual steps.
Common mistake
Creating overly broad templates that grant too many key usages or long validity, which weakens security and increases risk if a key is exposed.
Key Takeaway

Templates and directory integration provide repeatable, auditable issuance. Combine automation with policy and monitoring to avoid outages and misconfiguration.
