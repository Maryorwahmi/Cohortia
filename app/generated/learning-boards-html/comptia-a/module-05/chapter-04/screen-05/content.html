Module 5 › Chapter 5.4 › Root CA Security
Definition
Protecting the Root CA
Minimize use, store keys in HSMs, and require multi-person control for signing ceremonies.
Offline & air-gapped
Root CA operations are infrequent and performed in a controlled environment.
HSM-backed keys
Keys are generated or imported into tamper-resistant modules and never exposed in software.
Multi-person control
Ceremonies require two or more authorized operators and an auditable checklist.
Auditing & backups
Record every use of the root key and maintain secure backups with well-defined destruction policies.
Concrete example
Create the root in an isolated environment, store the private key in an HSM, export only the public certificate, and use a documented signing ceremony to sign intermediate CA CSRs.
Common mistake
Keeping the Root CA online for convenience. This increases the attack surface and risks total PKI compromise.
Key Takeaway

Treat root operations as rare, high-assurance events and protect root keys with an HSM and documented multi-person controls.
