Module 5 › Chapter 5.6 › DH vs ECDH
Classic Diffie-Hellman
Modular arithmetic over large primes; widely supported but uses larger keys.
Strength
Strong when large safe primes and standardized groups are used.
Cost
Higher CPU and bandwidth due to large numeric values.
Use case
Legacy systems or where standardized DH groups are required.
Elliptic Curve Diffie-Hellman
Uses elliptic curve groups to achieve comparable security with smaller keys and faster operations.
Performance
Smaller keys reduce computation and bandwidth — ideal for constrained environments.
Considerations
Choose vetted curves and libraries; ensure interoperability with peers.
Use case
Mobile apps, IoT, and high-performance servers where reduced key sizes matter.
Key takeaway
ECDH offers equivalent security with smaller keys and better performance; choose based on compatibility and vetted curve selection. Both protocols support PFS when ephemeral secrets are used.
