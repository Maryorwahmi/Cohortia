What is Diffie-Hellman?
A mathematical protocol to derive a shared secret without prior secrets.
  • Agree public parameters: large prime p and generator g.
  • Each party selects a private exponent and computes a public value using g and p.
  • Exchange public values and compute the shared secret locally.
  • Security relies on the discrete logarithm problem for the chosen group and parameters.
Example
Alice and Bob compute g^a and g^b, exchange them, then compute (g^b)^a which equals (g^a)^b; they never send a or b.
Common misconception
Public values are not secrets; their exposure is expected. The secrecy is in the private exponents and the problem's hardness.
Key Takeaway
DH creates shared secrets without prior keys, but choose secure parameters and avoid weak groups.
Annotated math flow
Public: p (prime), g (generator)
Alice: choose private a, compute A = g^a mod p, send A
Bob:   choose private b, compute B = g^b mod p, send B
Alice: compute s = B^a mod p
Bob:   compute s = A^b mod p
Result: s is identical for both, used as shared secret
Why it matters
Establishing secrets without prior trust enables secure session keys for protocols like TLS and supports Perfect Forward Secrecy when ephemeral values are used.
Key Takeaway

DH provides a method to derive shared secrets without pre-shared keys; security requires strong group parameters and correct implementation.
