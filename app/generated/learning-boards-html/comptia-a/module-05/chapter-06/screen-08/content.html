Module 5 › Chapter 5.6 › HSMs & TPMs
Hardware Security Module (HSM)
Tamper-resistant appliance for generating and protecting central cryptographic keys.
Primary uses
Root CA keys, signing keys, database master keys, enterprise-wide key operations.
Security advantage
Keys never exported in plaintext; operations occur inside a tamper-resistant boundary.
Operational features
Operator separation, role-based access, and strong audit trails.
Trusted Platform Module (TPM)
Onboard microcontroller for device attestation and local key protection.
Primary uses
Disk encryption keys, measured boot, client authentication tied to hardware.
Security advantage
Keys protected by a chip bound to device integrity checks.
Operational features
Useful for endpoint security, not a full replacement for centralized HSM protections.
Design guidance
Combine HSMs for central key custody with TPMs for device-level protection. Integrate both with a key management service to enforce policies, audit access, and automate rotation.
