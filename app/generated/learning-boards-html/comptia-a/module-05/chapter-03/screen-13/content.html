Inspecting X.509 certificates with openssl

Retrieve a certificate chain and examine it for Subject, Issuer, SAN, Key Usage, and EKU.

Commands
# Part 1: Retrieve the certificate chain and save to a file
openssl s_client -connect www.google.com:443 -servername www.google.com \
    -showcerts -print_certs -verify_hostname www.google.com -verify_return_error \
    < /dev/null 2>/dev/null | openssl x509 -outform PEM > google_cert_chain.pem

echo "Certificate chain saved to google_cert_chain.pem"

# Part 2: Inspect the server certificate
openssl x509 -in google_cert_chain.pem -noout -text

echo "--- Certificate Inspection Complete ---"
Note: When running these commands locally, ensure your shell handles redirection and SNI is set with -servername.
What to look for in the output
  • Subject and Issuer names to confirm identity and signer.
  • Validity dates to ensure not expired or not yet valid.
  • X509v3 Subject Alternative Name for hostnames covered by the certificate.
  • X509v3 Key Usage and Extended Key Usage to confirm permitted operations.
Key Takeaway

Command-line inspection is an essential audit and incident response skill for validating certificates and revocation points.
