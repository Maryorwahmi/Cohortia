SAN, Key Usage, and Extended Key Usage

Extensions define which names, cryptographic operations, and applications a certificate supports.

Subject Alternative Name (SAN)

Lists domain names and IP addresses the certificate is valid for. Modern TLS clients check SAN entries for name validation.

Example: A certificate with SANs example.com and www.example.com covers both hostnames without separate certificates.
Key Usage & EKU

Key Usage indicates allowed cryptographic operations; EKU specifies the intended application context like Server Authentication or Code Signing.

Key Usage: digitalSignature
EKU: Server Authentication
Policy Guidance
  • Create distinct templates per use case so Key Usage and EKU align with function.
  • Restrict keyCertSign usage to CA roles only.
  • Always include SAN entries for all hostnames required by clients.
