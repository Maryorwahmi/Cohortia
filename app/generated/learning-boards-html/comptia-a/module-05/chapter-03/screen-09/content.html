Definition

X.509 certificate anatomy

Inspect fields to confirm identity, usage, and validity of a certificate.

Core Fields
  • Subject: Entity the certificate names.
  • Issuer: The CA that signed the certificate.
  • Public Key: The subject's public key material.
  • Serial Number: CA-unique identifier for the certificate.
  • Validity: Not Before and Not After dates.
Important Extensions
  • Subject Alternative Name (SAN): Hosts or IPs covered by the certificate.
  • Key Usage: What the key can do (e.g., digital signature).
  • Extended Key Usage (EKU): Intended application like Server Authentication.
  • Signature Algorithm: How the CA signed the certificate.
Example: A TLS server certificate needs SAN entries for each hostname and EKU for Server Authentication to avoid client errors.
Check-list when inspecting a certificate
Confirm Subject and Issuer match expected names.
Validate SAN entries include required hostnames.
Verify EKU and Key Usage align with the certificate's purpose.
