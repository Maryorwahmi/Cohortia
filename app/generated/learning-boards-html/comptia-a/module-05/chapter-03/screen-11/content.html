Lifecycle

Certificate lifecycle — stages and controls

Understand each lifecycle stage so you can design automation and incident playbooks.

1. Generation / Issuance — CSR & identity checks
2. Distribution — publish to repository and install
3. Usage — TLS handshakes, signing operations
4. Revocation — CRL or OCSP publication
5. Expiration / Renewal — replace or reissue before Not After
Controls & Examples
Use HSMs for private keys used by high-impact certificates.
Automate renewal for short-lived certificates to minimize human error.
Maintain a revocation playbook to revoke, publish CRL, and issue replacement certificates quickly.
