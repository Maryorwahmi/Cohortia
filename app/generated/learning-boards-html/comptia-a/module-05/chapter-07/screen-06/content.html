Chosen-Plaintext vs Chosen-Ciphertext

These attack models test an algorithm's resilience when an adversary can query encryptions or decryptions. Resistant schemes must not leak useful information under these queries.

CPA
Attacker obtains ciphertexts for chosen plaintexts. A scheme must ensure ciphertexts reveal no useful structure.
CCA
Attacker obtains plaintexts for chosen ciphertexts. Without integrity, decryption oracles can be abused to learn secrets or forge messages.
Concrete Example

Suppose an API decrypts user-provided ciphertext without integrity checks and reveals error messages on malformed padding. An attacker can submit crafted ciphertexts and infer plaintext structure from error timing or messages. Replacing the scheme with AES-GCM ensures decryption fails early and uniformly for tampered ciphertexts, preventing such an oracle from leaking data.

Key Takeaway
Always pair confidentiality with integrity; authenticated encryption resists both chosen-plaintext structure analysis and chosen-ciphertext manipulation.
