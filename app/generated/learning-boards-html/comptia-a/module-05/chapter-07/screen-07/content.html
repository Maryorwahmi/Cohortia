Module 6 › Chapter 5.7 › Birthday Attack
Definition

Birthday paradox applied to hashes

Collision finding requires about 2^(N/2) operations for an N-bit hash. Attackers exploit this to generate two inputs with the same digest far faster than 2^N work.

Practical consequence
Collision vulnerabilities break digital signatures and file integrity checks; a forged artifact can carry the same hash as the original.
Key Takeaway

Use hash outputs large enough that 2^(N/2) remains infeasible for adversaries; migrate from MD5/SHA-1 to SHA-256 or SHA-3 families.

Concrete Example

A 128-bit hash has a collision-difficulty of roughly 2^64 operations. Powerful attackers can feasibly find collisions against 128-bit digests, which is why MD5 (128-bit) and weak SHA-1 uses are no longer suitable where collision resistance matters, such as code signing or certificate generation.

Assessment Prompts
  • Which systems rely on hash collision resistance for integrity or signatures?
  • Are any legacy hashes used in signing chains that need urgent replacement?
