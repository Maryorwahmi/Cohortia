Learning Objectives

Outcomes and mastery targets

Each objective maps to a practical competency you can verify during assessments and configuration reviews.

Bloom: Learn → Understand → Apply → Master
01
Recognize attack classes
Name and explain brute-force, side-channel, chosen-plaintext/ciphertext, birthday, and downgrade attacks and why each matters to system integrity.
Verified Competency Milestone
02
Design implementation countermeasures
Apply constant-time code, shielding, authenticated encryption, and key-stretching to reduce practical attack success.
Verified Competency Milestone
03
Implement cryptographic agility
Structure libraries and policies so algorithms can be swapped quickly after vulnerability disclosures.
Verified Competency Milestone
04
Plan for post-quantum migration
Assess long-lived secrets, prioritize systems, and draft a migration path toward quantum-resistant algorithms.
Verified Competency Milestone
