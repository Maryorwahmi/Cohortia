Module 6 › Chapter 5.7 › Assessment Workflow
Process

Step-by-step cryptographic assessment

01 Discover
Inventory algorithms, keys, and their lifetimes.
02 Audit
Check protocol & cipher settings and library use.
03 Test
Run timing tests, code review, and external scanners.
04 Remediate
Apply configuration, patch libraries, or plan migrations.
Triage Tips
  • Prioritize long-lived secrets and signing systems.
  • Estimate remediation complexity for scheduling.
Verification
Re-scan and document changes; schedule periodic reviews because threat models evolve.
