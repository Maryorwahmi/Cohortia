Detached signing and verification

# Create a sample file
echo "This document is confidential." > document.txt

# Create a detached signature
# gpg --output document.txt.sig --detach-sign document.txt

# Verify the detached signature
# gpg --verify document.txt.sig document.txt
Run the commands in a terminal. The verify step reports whether the signature matches and which key produced it. If the public key is not trusted, GPG indicates the key's status; obtain the public key from a trusted source before accepting the signature.
Concrete scenario

When downloading a distribution iso, a detached PGP signature allows independent verification that the ISO file matches the vendor-signed digest before installation.

Trust reminder

Ensure you obtain the signer's public key through a trusted channel and check key fingerprints to avoid key substitution attacks.

Key Takeaway

Detached signatures let recipients verify files independently; always validate the public key's provenance.
