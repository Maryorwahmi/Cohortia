Module 5 › Chapter 5.5 › SHA-256 Exercise
Try this in your terminal
# Create a sample file
echo "This is the original document content." > original_document.txt

# Original SHA-256
openssl dgst -sha256 original_document.txt

# Modify a single character
# sed -i 's/original/Original/' original_document.txt

# Modified SHA-256
openssl dgst -sha256 original_document.txt
Compare the two hex outputs. You should observe completely different digests, demonstrating the avalanche effect and why hashes are powerful indicators of modification.
Safety note

This activity is observational; do not attempt to generate collisions. Use the exercise to understand sensitivity of digests to input changes.

Key Takeaway

The avalanche effect means hashes are reliable for change detection; authenticity still requires keys or signatures.
