Module 5 › Chapter 5.5 › RSA vs ECDSA
Comparison

RSA

Based on integer factorization. Well-supported and broadly compatible, but larger keys and signatures for a given security level.

Example use

Legacy PKI deployments and systems requiring broad support.

Comparison

ECDSA

Uses elliptic curve discrete logarithm problems. Smaller keys and signatures with comparable security, good for constrained environments.

Example use

Mobile devices, IoT, and modern TLS deployments prioritizing performance and smaller certificates.

Operational note

Ensure your key management and certificate provisioning processes support the algorithm you choose, and design for agility to migrate algorithms when necessary.
