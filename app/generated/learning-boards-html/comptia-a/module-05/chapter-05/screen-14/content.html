Module 5 › Chapter 5.5 › Key Concepts
Cryptographic Hashing
One-way digest for integrity; does not prove origin.
Message Authentication Code
Integrity and authenticity using a shared secret, e.g., HMAC.
Digital Signature
Asymmetric signing for integrity, authenticity, and non-repudiation.
Actionable reminder: Do not use MD5 or SHA-1 for trust-critical tasks. Prefer SHA-2 or SHA-3 and design systems to migrate algorithms safely.
