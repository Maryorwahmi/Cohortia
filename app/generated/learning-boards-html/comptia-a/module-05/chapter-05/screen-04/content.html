Definition

Properties of cryptographic hashes

A one-way mapping to a fixed-size digest with important resistance properties used to detect alteration.

Key properties
  • Preimage resistance: hard to find an input for a given digest.
  • Second preimage resistance: hard to find a different input with same digest as a target file.
  • Collision resistance: hard to find any two inputs with the same digest.
Concrete example

Compute SHA-256 for a file, edit one character, compute again — the two digests will be completely different because of the avalanche effect.

Common mistake

Trusting a published digest without ensuring the digest itself is authenticated can lead to a false sense of security.

Example — SHA-256
openssl dgst -sha256 original_document.txt
# returns a 64 byte hex digest for the file
Run the command before and after a small change to observe how drastically the hex output changes.
Key Takeaway

Use hashes to detect modification, not to assert who made a change. For origin, use a MAC or a signature.
