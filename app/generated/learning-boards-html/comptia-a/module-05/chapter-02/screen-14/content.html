Module 5 › Chapter 5.2 › Key Concepts
AEAD (AES-GCM)
Encryption plus authentication in a single operation; include AD to protect metadata.
Elliptic Curve Cryptography
Equivalent security with much smaller keys compared to RSA, improving performance and storage.
Key Management System
Centralized generation, storage, distribution, rotation, and destruction with auditability and HSM integration.
Summary

Adopt AEAD by default, prefer ECC for efficiency where compatible, and centralize key lifecycle management using HSMs or cloud KMS to reduce operational risk.
