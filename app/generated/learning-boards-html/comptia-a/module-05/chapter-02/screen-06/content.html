Module 5 › Chapter 5.2 › Associated Data
Definition
Associated Data is unencrypted metadata that is included in the authentication calculation of an AEAD operation.
Good AD candidates
  • Stable headers or protocol fields
  • Sequence or message identifiers
  • Object keys or ACL identifiers that must not change
Concrete scenario
An object store sends object names in cleartext but uses them as AD so an attacker cannot swap names without breaking authentication.
Pitfall
Including changing timestamps or non-deterministic fields in AD will cause valid messages to fail authentication.
