Module 5 › Chapter 5.2 › RSA vs ECC
RSA: Factoring-based
Security depends on the difficulty of factoring large semiprimes; key sizes tend to be large for modern security levels.
ECC: Curve-based
Security is based on the elliptic curve discrete logarithm problem. Equivalent security with smaller keys reduces computational cost.
Side-by-side
Example equivalence: a 256-bit ECC key approximates the security of a 3072-bit RSA key, translating to smaller transmissions and faster cryptographic ops.
Decision note
Prefer ECC for new deployments and constrained devices; retain RSA only for explicit legacy compatibility or policy reasons.
