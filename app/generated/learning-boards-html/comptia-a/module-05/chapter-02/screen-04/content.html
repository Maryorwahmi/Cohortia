Module 5 › Chapter 5.2 › Modes of Operation
Definition: ECB
ECB encrypts each block independently. Deterministic outputs reveal repeated plaintext structure.
Definition: CBC
CBC chains blocks with XOR and an IV, reducing visible patterns but offering no built-in integrity.
Common mistake
Assuming CBC provides tampering protection. Without an independent MAC, integrity is not guaranteed.
Visual analogy
Imagine stamping identical tiles in a mosaic for ECB—patterns repeat. CBC mixes tiles so the pattern is obscured, but it doesn't seal the mosaic against later changes.
Key takeaway
Do not use ECB for structured data. If using CBC, add a secure integrity mechanism or prefer AEAD modes for simpler, safer designs.
