Module 5 › Chapter 5.2 › Key Generation
What to use
Platform CSPRNGs, HSMs, or TPMs for key material; avoid handcrafted or predictable sources.
Audit and logging
Record generation events and provenance without logging key material itself to support later forensics.
Concrete example
Generating a symmetric key inside an HSM and exposing only an encrypted key blob to application servers minimizes exposure.
Pitfall
Seeding CSPRNGs manually or using weak platform entropy can produce keys that are effectively guessable.
