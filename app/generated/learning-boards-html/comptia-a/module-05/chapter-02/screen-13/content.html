Module 5 › Chapter 5.2 › OpenSSL AES-GCM Demo
What you'll do
Create a sample file, generate a key and IV, encrypt with AES-256-GCM, decrypt, then tamper and observe authentication failure.
Safety note
Do not commit generated keys to version control. Treat sample keys as sensitive and delete them after the exercise.
Terminal commands
# Create a sample file
echo "This is a secret message for our enterprise." > secret_message.txt

# Generate a random 256-bit key (32 bytes)
openssl rand -hex 32 > aes_key.txt
AES_KEY=$(cat aes_key.txt)

# Generate a random 12-byte IV (96 bits)
openssl rand -hex 12 > aes_iv.txt
AES_IV=$(cat aes_iv.txt)

# Encrypt using AES-256-GCM
openssl enc -e -aes-256-gcm -K $AES_KEY -iv $AES_IV -in secret_message.txt -out secret_message.enc -taglen 16

# Decrypt
openssl enc -d -aes-256-gcm -K $AES_KEY -iv $AES_IV -in secret_message.enc -out decrypted_message.txt

# Tamper: append a byte and attempt decryption to see authentication fail
echo "A" >> secret_message.enc
openssl enc -d -aes-256-gcm -K $AES_KEY -iv $AES_IV -in secret_message.enc -out decrypted_message_after_tamper.txt
