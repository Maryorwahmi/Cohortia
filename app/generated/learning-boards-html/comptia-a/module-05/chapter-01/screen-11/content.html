Architecture › Algorithm Selection

Evaluation criteria

  • Security strength and future margin against attacks.
  • Performance and resource consumption in expected workloads.
  • Availability of trusted, tested implementations.
  • Regulatory or compliance requirements on algorithms and key sizes.
Example mapping
AES-GCM for bulk encryption, ECDHE for ephemeral key exchange, PBKDF2 for credential hardening with policy-determined iterations.
Key Takeaway

Document your threat model, test candidate algorithms for performance, and ensure configuration meets compliance rules.

Algorithm quick guide
AES
Use for fast, standard symmetric encryption in authenticated modes.
RSA / ECC
RSA is widely supported; ECC gives smaller keys and comparable security with better performance in many cases.
PBKDF2 / bcrypt
Adaptive password hashing with configurable work factors; choose rounds based on hardware and policy.
Operational tip
Benchmark and tune settings like AES-GCM batch sizes or PBKDF2 iterations to align with service-level targets before deployment.
