Definition › Cryptographic Hashing

What a hash does

Produces a fixed-size fingerprint that proves data integrity without revealing the original content.

Core properties
One-way, deterministic, and collision-resistant. Use modern functions like SHA-256 or SHA-3.
Example
Compare a published SHA-256 digest of a software package to the digest you compute locally to confirm integrity.
Misconception
Using unsalted hashes for passwords invites offline rainbow-table attacks. Always add salt and stretching for stored secrets.
Key Takeaway

Use cryptographic hashes for integrity and signatures; combine salt and stretching when protecting passwords.

Hash uses in enterprise
File integrity
Store and compare digests to detect tampering or corruption.
Digital signatures
Sign hashes to provide authenticity and non-repudiation.
Password storage
Never store raw hashes; use salt and key stretching to harden against offline attacks.
