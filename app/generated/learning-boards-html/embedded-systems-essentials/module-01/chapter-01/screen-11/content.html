Module 1 › Chapter 1.1 › Resource constraints
Common constraints
  • RAM: limited workspace for variables and stack.
  • Flash: limited space for program code and constants.
  • CPU: limited cycles available per control loop.
  • Power: battery life and sleep modes constrain activity.
Concrete scenario
A remote sensor reports hourly. To save battery, keep the MCU in deep sleep and only wake briefly to sample sensors and send a small packet. Minimizing active time directly extends battery life.
Misconception
Optimizing one resource often affects others; reduce CPU time by using lookup tables and you may increase flash usage, so plan trade-offs deliberately.
Key Takeaway

Design for the tightest constraint first, then iterate with measurements to balance other resources.
