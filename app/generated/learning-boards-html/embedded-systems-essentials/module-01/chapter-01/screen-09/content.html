Module 1 › Chapter 1.1 › Firmware: bare-metal and RTOS
Bare-metal pattern
// Pseudocode structure initialize_peripherals(); while (true) { poll_or_sleep(); handle_inputs(); update_outputs(); }
Bare-metal systems initialize hardware, then run a continuous loop or use interrupts. Keep time-critical code short and avoid blocking calls.
RTOS pattern
// Pseudocode create_task(sensor_task); create_task(control_task); start_scheduler(); // scheduler runs tasks at defined priorities
An RTOS provides task scheduling and timing helpers. Use it when you need structured concurrency and predictable timing across multiple tasks.
Key Takeaway

Match your software model to timing needs: bare-metal for simple loops, RTOS for organized, timed tasks.
