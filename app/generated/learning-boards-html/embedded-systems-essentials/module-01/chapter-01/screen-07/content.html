Module 1 › Chapter 1.1 › Embedded vs. general-purpose
General-purpose computer
Powerful CPU, lots of RAM and storage, full OS, human interface. Great for networking, GUIs, and complex multi-application tasks.
When to use
Need GUI, file storage, or multiple programs.
Trade-off
Higher power and less deterministic timing.
Microcontroller / Embedded
Small, efficient processors with limited RAM and flash. Run one program, expose GPIO, and are optimized for low power and predictable timing.
When to use
Real-time control, low-power sensors, and simple I/O tasks.
Trade-off
Limited memory and less convenience for user apps.
Platform examples
Raspberry Pi: single-board computer. Arduino: microcontroller ecosystem. TI LaunchPad with ARM Cortex-M4F: powerful microcontroller for real-time tasks.
