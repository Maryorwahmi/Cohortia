Module 1 › Chapter 1.1 › Designing for reliability
Practical checks
  • Sensor validation: reject out-of-range values.
  • Watchdog timer: reset the system on lockups.
  • Safe defaults: choose a fail-safe state for actuators.
  • Redundancy: duplicate critical sensors if necessary.
Concrete example
If a temperature sensor reads an impossible value, ignore it and switch to a default control action; log the event and use the watchdog to recover if the system becomes unresponsive.
Misconception
Testing only in ideal lab conditions misses failures that occur in the field. Test under power, temperature, and mechanical stress to expose real faults.
Key Takeaway

Plan for failure: detection, recovery, and safe defaults make embedded devices trustworthy in real conditions.
