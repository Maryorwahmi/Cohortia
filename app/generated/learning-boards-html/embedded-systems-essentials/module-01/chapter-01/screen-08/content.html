Module 1 › Chapter 1.1 › Parts of an embedded system
Component list
Processor
Microcontroller or CPU executing the program. Example: ARM Cortex-M4F used in this course.
Memory
Volatile RAM for runtime data and non-volatile flash for program storage. Example sizes can be small and must be managed carefully.
I/O
GPIO, ADCs, UART, SPI, I2C — interfaces that connect sensors, displays, and actuators.
Software
Firmware written in C or C++ running bare-metal or on a small RTOS.
Power
Battery or supply constraints influence sleep modes and hardware selection.
Concrete example — TM4C123G
In this course the TM4C123G provides 32 KB of SRAM and 256 KB of flash. The LaunchPad board exposes GPIO for sensors and actuators and includes the ARM Cortex-M4F processor capable of real-time control and digital signal processing.
Misconception check
Do not assume that adding more flash solves runtime memory issues. Flash stores code and constants; RAM is the limited workspace for variables and stack, and it must be managed explicitly.
Key Takeaway

Each component has a distinct role; understand them to make correct trade-offs in design and code.
