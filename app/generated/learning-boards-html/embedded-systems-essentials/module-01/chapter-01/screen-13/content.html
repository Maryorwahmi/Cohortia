Module 1 › Chapter 1.1 › Inspect devices
Step-by-step activity
  1. Pick three devices you use regularly.
  2. For each, list observable inputs (buttons, sensors) and outputs (lights, sounds, motion).
  3. Search for model or board information and note the processor type if available.
  4. Write a short paragraph describing the embedded function and why the chosen platform fits the task.
