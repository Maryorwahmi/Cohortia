Module 1 › Chapter 1.1 › What ‘embedded’ really means
Core definition

An embedded system is a computer system built to perform a dedicated function inside a larger product. It typically runs one program that senses inputs, makes decisions, and controls outputs without needing a keyboard or general user interface.

Example — Microwave
Reads keypad, runs timer, and switches the heating element on and off. The user sees buttons and time; the embedded computer handles precise control.
Misconception
Embedded does not always mean simple. Some embedded controllers run complex algorithms and strict timing constraints.
Key Takeaway

Embedded means focused design: hardware and software are chosen to solve one continuous task efficiently and reliably.

Illustrative cards
Hidden
Often invisible inside appliances.
Continuous
Runs continuously to perform its task.
Specialized
Hardware and code are optimized for one job.
Safety
Failures can be hazardous in many systems.
