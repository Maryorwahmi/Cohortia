Hands‑On Activity
Follow this practical sequence to run the blink program and experiment with timing.
Install or open simulator
Choose your environment and create a new TM4C123G project.
Add code & build
Paste the blink source and compile to produce the binary.
Flash via ICDI
Connect USB, ensure ICDI enumerates and download the binary.
Run and debug
Set a breakpoint and step to observe clock and GPIO register writes.
Modify delay
Change the loop count and rebuild to see the blink speed change.
Troubleshoot
If nothing blinks, check clock enable, direction and digital enable bits and ensure volatile is used.
