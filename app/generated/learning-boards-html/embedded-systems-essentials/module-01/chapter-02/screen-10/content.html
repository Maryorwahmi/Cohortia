Module 2 › Chapter 1.2 › Memory‑Mapped I/O
Principle
Peripherals as addresses
Read and write hardware registers using standard load/store operations to fixed addresses in the peripheral region.
Example: Writing to GPIO_PORTF_DATA_R changes the voltage at PF2 and lights the LED.
Cautions
Because peripheral registers reflect hardware state and side effects, use volatile and obey required enable sequences such as enabling clocks and digital functions.
Common error: Accessing registers before enabling the peripheral clock produces no effect.
Debug tip: If reads return unexpected values, verify clock, reset state and required enable bits.
Reflection: Because reads may reflect asynchronous hardware state, avoid relying on a single read for timing-critical decisions without proper synchronization.
