Learning Objectives
Four measurable outcomes for this chapter
Bloom: Learn → Understand → Apply → Master
01
Identify Cortex‑M4F features
Recognize the 32‑bit core, DSP instructions and FPU and why they speed signal processing tasks.
Mnemonic: Think "M4F = micro + DSP + float"
VERIFIED COMPETENCY MILESTONE
02
Explain Harvard vs Von Neumann
Describe separate instruction/data buses versus a single shared bus and performance implications.
Mnemonic: Separate lanes let cars pass each other.
VERIFIED COMPETENCY MILESTONE
03
Describe registers & memory map
Name R0–R15, PC, LR, SP and map code, SRAM, and peripheral address ranges on TM4C123G.
Mnemonic: R15 is PC, R14 is LR, R13 is SP.
VERIFIED COMPETENCY MILESTONE
04
Run the first blink program
Set up an IDE or simulator, flash the LaunchPad, and explain the need for volatile with register access.
Mnemonic: Blink = clock enable → dir → digital enable → toggle data.
