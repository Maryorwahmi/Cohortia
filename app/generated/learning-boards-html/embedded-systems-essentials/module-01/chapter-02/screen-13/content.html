Module 2 › Chapter 1.2 › volatile
Purpose
Prevent compiler optimization on hardware registers
Use volatile when creating pointers to peripheral registers so each read and write occurs as coded.
Example: #define GPIO_PORTF_DATA_R (*((volatile uint32_t *)0x400253FC))
Limitations
Volatile does not ensure atomic updates, ordering across cores, or synchronization with interrupts; use additional concurrency primitives if needed.
Common mistake: Omitting volatile and losing needed reads or writes.
Pro tip: Use volatile for MMIO, but not as a substitute for proper synchronization in concurrent code.
