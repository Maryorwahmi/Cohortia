Address Regions
Code (Flash)
0x0000_0000 – 0x1FFF_FFFF: Stores the program image executed by the processor.
SRAM
0x2000_0000 – 0x3FFF_FFFF: Runtime variables, stack and heap live here.
Peripheral
0x4000_0000 – 0x5FFF_FFFF: Memory‑mapped I/O addresses for GPIO, UART, timers and more.
Memory‑Mapped I/O
Peripherals appear as addresses within the Peripheral region. Software reads and writes these addresses to observe or change hardware state.
Example: Writing to GPIO_PORTF_DATA_R sets PF2 to toggle the blue LED.
Pro tip: Treat peripheral addresses like volatile variables; they represent physical hardware.
Check: When you calculate a peripheral address, you add the peripheral's base to the register offset defined in the datasheet or header file.
