Module 2 › Chapter 1.2 › Blink Steps
Step‑by‑Step
Memorize this sequence to avoid common errors when programming the LaunchPad.
1
Enable clock
Set SYSCTL_RCGCGPIO_R bit for Port F.
2
Wait
Poll the clock register until the bit is set.
3
Set direction
GPIO_PORTF_DIR_R |= 0x04 to make PF2 an output.
4
Enable digital
GPIO_PORTF_DEN_R |= 0x04 to enable PF2's digital function.
5
Toggle
Set and clear GPIO_PORTF_DATA_R bit with delays to blink.
Note: For precise timing replace busy delays with hardware timers; busy loops are acceptable for demos but not for production real‑time control.
