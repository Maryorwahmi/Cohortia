LaunchPad Tour
RGB LED, user buttons, USB power, ICDI
RGB LED: PF1 red, PF2 blue, PF3 green. Useful as a first physical output.
ICDI debugger: onboard interface for flashing, breakpoints and stepping without extra hardware.
USB connector: powers the board and provides a programming path through the IDE or simulator.
Tip: enabling the GPIO clock and setting the data direction are required before writing to the LED register.
