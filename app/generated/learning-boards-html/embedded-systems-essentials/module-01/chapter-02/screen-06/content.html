Registers R0–R15
Sixteen 32‑bit registers
  • R0–R12: general purpose
  • R13: Stack Pointer (SP)
  • R14: Link Register (LR)
  • R15: Program Counter (PC)
Special registers & usage
PSR stores flags and processor state; use the stack pointer to allocate locals and save registers; the link register saves return addresses on calls.
Example: On a function call, LR contains the return address so the function can return without accessing memory for that value.
Misconception: Treating SP like a scratch register will corrupt call/return semantics.
Pro tip: When debugging, watch R13–R15 to trace call chains and detect stack corruption or unexpected jumps.
