Key components
  • TM4C123GH6PM microcontroller with Cortex‑M4F core
  • USB connector for power and programming
  • Onboard ICDI debugger for flashing and stepping
  • RGB LED on PF1, PF2, PF3 and two user buttons
  • Breakout pins for all GPIO ports
Practical workflow
Install an IDE or open the simulator, create a TM4C123G project, compile the blink code, and use the ICDI to flash and debug the program.
Concrete step: After flashing, use single‑step to watch R13–R15 and the GPIO registers as the code runs.
Troubleshooting tip: If Windows does not detect the board, verify drivers and USB cable power; the ICDI must enumerate for flashing.
