Register definitions
#define SYSCTL_RCGCGPIO_R (*((volatile uint32_t *)0x400FE608))
#define GPIO_PORTF_DIR_R  (*((volatile uint32_t *)0x40025400))
#define GPIO_PORTF_DEN_R  (*((volatile uint32_t *)0x4002551C))
#define GPIO_PORTF_DATA_R (*((volatile uint32_t *)0x400253FC))

// sequence:
// enable clock → wait → set PF2 dir → enable digital → loop toggle
These macros create volatile pointers to fixed addresses in the peripheral region so reads and writes affect hardware directly.
Example sequence
1) SYSCTL_RCGCGPIO_R |= 0x20 enables Port F clock. 2) Wait for the clock bit to be set. 3) GPIO_PORTF_DIR_R |= 0x04 sets PF2 as output. 4) GPIO_PORTF_DEN_R |= 0x04 enables digital function for PF2. 5) Toggle GPIO_PORTF_DATA_R with bitwise set and clear to blink.
Concrete check: If LED doesn't blink, verify clock enable, direction bit, and digital enable.
Common mistake: Omitting volatile so compiler optimizes away register writes and the hardware never sees them.
