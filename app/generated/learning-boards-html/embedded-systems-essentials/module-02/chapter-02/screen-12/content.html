Key Concepts
Transistor switch
Gate voltage makes conduction on or off; forms the physical basis of logic.
Logic gates & truth tables
Use expressions and tables to predict outputs for all input combinations.
Flip‑flops & registers
A D flip‑flop captures a bit on a clock edge; registers are groups of flip‑flops.
Summary

These concepts link silicon switching to the bitwise code patterns you use when programming microcontrollers.
