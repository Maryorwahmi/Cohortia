How to build a truth table
Follow a consistent, stepwise approach so no case is missed.
1
List all input combinations
For n inputs, there are 2^n rows. Example: three inputs → eight rows.
2
Compute intermediate columns
Break complex expressions into parts and evaluate each column stepwise.
3
Fill final output column
Apply the gate or boolean expression to each row to get the final output.
Worked example
Y = (A AND B) OR (NOT C). For A,B,C = 0,0,0 compute intermediate A AND B=0, NOT C=1, final OR=1. Repeat for all eight rows.
Key Takeaway

A complete truth table is the definitive check of a logic function's behavior.
