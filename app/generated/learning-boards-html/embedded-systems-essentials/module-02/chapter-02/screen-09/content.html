Set, Clear, Toggle, Test
These operations let software change individual flip‑flop states safely.

Set: use OR with a mask that has a 1 where you want to set a bit. This leaves other bits unchanged.

Clear: AND with the inverted mask clears the target bit while preserving others.

Toggle: XOR with a mask flips the target bit. Test: AND and check nonzero to read a bit.

Concrete visual idiom
Use masks that are a single 1 shifted to the desired position to operate on that bit only.
Example scenario
To enable a GPIO clock you set its enable bit. Use the set idiom so you don't disrupt other configuration bits in the same register.
Pattern
Set: register OR mask. Clear: register AND inverted mask. Toggle: register XOR mask. Test: (register AND mask) nonzero?
Key Takeaway

Bitwise idioms are the software equivalent of wiring single flip‑flops; use masks to avoid unintended changes.
