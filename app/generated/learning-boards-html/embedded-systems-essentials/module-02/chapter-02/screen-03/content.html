Practice & Assessment
Hands-on checks tied to each learning objective.
Transistor check
Predict on/off with a water‑gate sketch. Verify by observing whether current path is closed at 3.3V vs 0V.
Gate truth tables
Complete tables for two or three inputs. Confirm outputs match gate definitions for every row.
Flip‑flop tracing
Trace a D value through a rising clock edge and record Q after the edge.
Bitwise operations
Set or clear a single bit in a register and verify others remain unchanged using readback.
