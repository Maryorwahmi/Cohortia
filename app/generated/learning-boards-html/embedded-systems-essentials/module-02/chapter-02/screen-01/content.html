Digital Logic Foundations
From transistor switches to flip‑flop memory and bitwise register control.

Transistors are binary switches controlled by a gate voltage. Logic gates combine those switches to compute boolean results. Flip‑flops capture a single bit on a clock edge and form registers.

We will connect these ideas to simple C bit operations so you can see how code manipulates real hardware state.
