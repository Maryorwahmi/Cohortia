NAND, NOR, XOR
Inversion and exclusivity change gate meaning and application.

NAND: output LOW only when all inputs are HIGH. Often used as a universal primitive.

NOR: output HIGH only when every input is LOW. Useful for active‑low logic.

XOR: output HIGH when inputs differ; useful for parity and difference detection.

XOR example
Sensors A and B → output HIGH if exactly one sensor triggers.
NAND note
Because NAND is universal, complex logic can be built from NAND gates alone.
Truth table contrast
NAND two inputs:
00→1 | 01→1 | 10→1 | 11→0
NOR two inputs:
00→1 | 01→0 | 10→0 | 11→0
XOR two inputs:
00→0 | 01→1 | 10→1 | 11→0
Key Takeaway

Inversion and exclusivity change both truth tables and real uses; pick gates based on required behavior.
