Module 2 › Chapter 2.1 › LED Resistor
Guideline

Compute, then choose standard value

Formula: R = (Vsource − Vforward) / I. Example: R = (3.3 − 2.0) / 0.010 ≈ 130 Ω. Use 150 Ω or 220 Ω as standard values to be safer.
Safety check
Compare computed I to the GPIO limit (≈8 mA for TM4C123G). If I is larger, increase R or use a driver transistor.
Key Takeaway
Selecting a slightly larger resistor value reduces current and protects both LED and pin.
Comparison: Direct vs Series resistor
Direct connection (wrong)
An LED connected directly to a pin will draw uncontrolled current, likely burning the LED or damaging the pin.
Series resistor (correct)
A properly calculated resistor limits current to a safe value and lets you predict brightness and power dissipation.
Check with a meter
Measure the voltage drop across the resistor and compute I = Vr / R to confirm the actual current when the LED is on.
