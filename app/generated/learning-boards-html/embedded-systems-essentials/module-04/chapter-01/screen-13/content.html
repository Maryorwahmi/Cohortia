Module 4 › Chapter 4.1 › Hands-on: Multi-LED Pattern on Port F
Activity steps
  1. Enable clock: SYSCTL_RCGCGPIO_R |= 0x20; wait for bit set.
  2. Set direction bits: GPIO_PORTF_DIR_R |= (1<<1)|(1<<2)|(1<<3);
  3. Enable digital: GPIO_PORTF_DEN_R |= (1<<1)|(1<<2)|(1<<3);
  4. In loop: set PF1, delay; clear PF1; set PF2, delay; clear PF2; set PF3, delay; clear PF3; set PF1|PF2|PF3, delay.
Use OR/AND masks to preserve other bits. After running, measure voltages on each pin when HIGH and LOW to verify electrical behavior.
Safety note
Use low-current LEDs or current-limiting resistors provided on the LaunchPad. Measure voltages, not currents, unless you know the circuit.
Try this

After success, modify the pattern to blink two LEDs simultaneously and then rotate the pattern for a chasing effect.
