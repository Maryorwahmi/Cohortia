Module 4 › Chapter 4.1 › Direction and Digital Enable Registers
GPIODIR — set direction
0 = input, 1 = output per bit. Use OR to set and AND with complement to clear bits.
Example
To make PF2 an output: GPIO_PORTF_DIR_R |= (1 << 2); To make PF0 an input: GPIO_PORTF_DIR_R &= ~(1 << 0);
GPIODEN — enable digital
Set DEN bit for each pin used for digital I/O. A pin without DEN will not act as a digital input or output.
Practical note

Always enable DEN for pins used digitally; otherwise reads and writes may be ignored or the pin remains tri-stated.

Key Takeaway

Both direction and digital enable must be configured for a pin to operate as a reliable digital I/O.
