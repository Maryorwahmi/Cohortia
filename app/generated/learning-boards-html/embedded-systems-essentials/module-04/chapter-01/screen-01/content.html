GPIO Configuration and Digital I/O
Practical register steps to read switches and drive LEDs on the TM4C123G.

GPIO is the most direct way your program interacts with hardware pins. The TM4C123G exposes each port through memory-mapped registers, so software reads and writes normal addresses to change electrical signals.

We will follow a repeatable four-step pattern: enable the GPIO clock, set the pin direction, enable the pin's digital function, then read or write the data register. That pattern lets you control LEDs and read switches safely and predictably.
