Key GPIO registers (Port F addresses)
  • SYSCTL_RCGCGPIO (0x400FE608) — enables port clocks; set bit 5 for Port F.
  • GPIO_PORTF_DIR_R (0x40025400) — direction: 0=input, 1=output per bit.
  • GPIO_PORTF_DEN_R (0x4002551C) — digital enable for pins used as digital I/O.
  • GPIO_PORTF_DATA_R (0x400253FC) — read inputs and write outputs; mask-based addressing exists.
Register values are manipulated with bitwise operations. Use OR to set bits and AND with complement to clear bits so that you don't accidentally change other pins on the same port.
Sequence reminder
Enable clock → wait for it to stabilize → configure direction → enable digital function → access data.
Common mistake

Skipping the clock enable results in code that appears to run but has no effect on pins. The symptom is that LEDs won't change state even though your code sets the bits.

Check your understanding
Why must you wait after setting the RCGCGPIO bit? Because the peripheral clock needs time to stabilize before registers respond predictably.
