Ports and pins
Each port (A–F) has a base address and up to eight pins. Pins are addressed as bits within the port registers.
Port as container
One base address with multiple registers like DIR, DEN, DATA for all pins of that port.
Pin as bit
Pin number maps to a bit position: PF2 is bit two in Port F's registers.
Practical note
Some package pins are used for debugging or alternate functions, so count usable GPIO pins carefully for your board.

For Port F on the LaunchPad, PF2 controls the blue LED. Code uses a bit mask such as one shifted left by two to change PF2 without disturbing other bits.
Why it matters

Understanding the port/pin hierarchy reduces address errors and prevents unintentional changes to unrelated pins on the same port.
