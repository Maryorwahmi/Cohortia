Module 4 › Chapter 4.1 › What is GPIO?
Definition
GPIO are pins you configure as inputs or outputs. Inputs read a physical signal; outputs drive one.
Input example
Read a switch to detect button presses and trigger software events.
Output example
Drive an LED to indicate status, toggling the pin high and low in a loop.
Misconception
Assuming a pin is usable before enabling its port clock. The TM4C123G requires the RCGCGPIO bit to be set first.
Key Takeaway

GPIO maps software writes and reads to physical voltages; sequencing matters to avoid inert peripherals.

Concrete example — PF2 LED
// PF2 is the blue LED
#define PF2 (1<<2)
// After enabling clock and DEN, write GPIODATA |= PF2 to turn on LED
// Clear bit to turn it off
Measure the pin voltage when set high to confirm the LED is driven. Use the example blink code later to see this in action.
Check your understanding
How would you confirm a pin is configured as input? Answer: read the GPIODIR bit for that pin and then sample GPIODATA while toggling the external signal.
