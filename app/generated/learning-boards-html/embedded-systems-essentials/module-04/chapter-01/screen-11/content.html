Module 4 › Chapter 4.1 › Blink PF2 — Main Loop and Bit Operations
Main loop (excerpt)
while (1) {
    GPIO_PORTF_DATA_R |= PF2;   // Blue LED on
    delay(1000000);
    GPIO_PORTF_DATA_R &= ~PF2;  // Blue LED off
    delay(1000000);
}
This uses bitwise operations to change only PF2. Replace PF2 with a combined mask to toggle multiple LEDs together.
Common mistake
Using assignment like GPIO_PORTF_DATA_R = PF2 overwrites other pins and may disable unrelated outputs.
Pro Tip

When updating multiple pins, build a mask of all target bits and apply OR/AND to change them atomically in software.
