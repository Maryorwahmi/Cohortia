Module 4 › Chapter 4.1 › Enable the GPIO Clock (RCGCGPIO)
RCGCGPIO — the first step
Set bit 5 (0x20) to enable Port F's clock at address 0x400FE608.
Verification
  • Write SYSCTL_RCGCGPIO |= 0x20;
  • Poll until (SYSCTL_RCGCGPIO & 0x20) is nonzero.
  • Then configure GPIODIR and GPIODEN.
Debug tip
If LEDs don't respond, check that the clock bit is set and reads back as set. If not, power sequencing or incorrect address usage might be the cause.
Symptom

Writes to direction and data registers appear to do nothing. Often caused by missing or wrong RCGCGPIO enable.
