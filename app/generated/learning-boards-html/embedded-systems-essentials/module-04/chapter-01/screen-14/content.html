Module 4 › Chapter 4.1 › Key Concepts — Part 1
Clock gating
Enable SYSCTL_RCGCGPIO bit for the port before other register access.
Dir & Den
Use GPIODIR for direction and GPIODEN to enable digital I/O on each pin.
GPIODATA masking
Prefer |= and &=~ patterns or masked addresses to protect other pins.
Summary
Enable clock, set direction, enable digital function, then read or write data safely using masks.
