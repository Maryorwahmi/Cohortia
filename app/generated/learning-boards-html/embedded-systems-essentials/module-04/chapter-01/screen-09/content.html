Module 4 › Chapter 4.1 › GPIODATA and Address Masking
GPIODATA usage
Read inputs or write outputs. Prefer OR to set bits and AND with complement to clear bits.
Example operations
  • Set PF2: GPIO_PORTF_DATA_R |= (1 << 2);
  • Clear PF2: GPIO_PORTF_DATA_R &= ~(1 << 2);
  • Read PF2: value = GPIO_PORTF_DATA_R & (1 << 2);
Address mask note
Writes to different offsets within GPIODATA can affect only the bits selected by address bits [9:2]. This is a hardware mask that can be useful for atomic updates.
Practical advice

Unless you need the address-mask atomicity, use full GPIODATA and software masking for clarity and portability.

Key Takeaway

Protect other pins by using read-modify-write patterns on GPIODATA or by choosing masked addresses deliberately.
