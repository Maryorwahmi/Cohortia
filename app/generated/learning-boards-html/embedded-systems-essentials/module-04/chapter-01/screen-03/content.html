Apply and Verify
Concrete checkable steps to prove competency in the lab.
Milestones
  • Blink PF2 using the provided C example.
  • Configure PF0 as input and read it with GPIODATA.
  • Measure pin voltages with a multimeter for HIGH and LOW.
PF2 blink
Use SYSCTL_RCGCGPIO bit 5, set GPIODIR bit 2, enable DEN for PF2, then toggle GPIODATA bit 2.
VERIFIED COMPETENCY MILESTONE
PF0 input
Clear GPIODIR bit 0 and set GPIODEN bit 0, then read the corresponding GPIODATA bit to sample the switch state.
VERIFIED COMPETENCY MILESTONE
Measure voltages
When a pin is HIGH you should measure the MCU's VCC on that pin; when LOW you should see ground potential. Use these readings to confirm the code is driving the pin.
VERIFIED COMPETENCY MILESTONE
