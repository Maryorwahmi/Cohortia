Send routine
void UART0_SendChar(char c) {\n // Wait until transmit FIFO is not full\n while ((UART0_FR_R & UART_FR_TXFF) != 0) {}\n UART0_DR_R = c;\n}\n\nvoid UART0_SendString(char *str) {\n while (*str) {\n UART0_SendChar(*str);\n str++;\n }\n}
This code waits for the TX full flag to clear, then writes the byte. The string routine walks a null-terminated array and sends each character in turn.
Terminal example
Hello, Embedded World!\r\n
Misconception check

Assuming writes always succeed immediately can hide transient issues. Use the flag check to prevent overwrites and lost characters.

Key Takeaway

Simple send routines are reliable and portable; build on them to implement higher-level logging or printf helpers.
