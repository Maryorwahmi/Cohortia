Module 5 › Chapter 4.3 › Baud rate & divisors
Formula

Compute IBRD and FBRD

Use BRD = SystemClock / (16 × Baud). Extract integer part for IBRD. Multiply fractional part by 64 and round to get FBRD.

Example: 16 MHz, 115200 baud
BRD = 16000000 / (16 × 115200) = 8.6805\nIBRD = 8\nFBRD = round(0.6805 × 64) = 44
Common mistakes
  • Omitting the fractional divisor causes higher bit timing error.
  • Using the wrong system clock in the calculation yields incorrect divisors.
  • Not rounding the fractional product properly changes the effective baud slightly.
Assessment example

For 16 MHz and 9600 baud: BRD = 104.1667, IBRD = 104, FBRD = round(0.1667 × 64) = 11. Use these to program the divisors.
