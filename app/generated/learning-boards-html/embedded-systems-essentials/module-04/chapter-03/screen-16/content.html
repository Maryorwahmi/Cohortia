Module 5 › Chapter 4.3 › Quick Reference
Clocks & Pins

Always enable UART0 and GPIO clocks and set PA0/PA1 to alternate function before initializing the UART.

Divisors & Framing

Compute IBRD and FBRD from the system clock and configure LCRH for 8N1 unless you intentionally need a different framing.

Send & Verify

Wait for the transmit FIFO not-full flag before writing to the data register. Verify output in a PC terminal at the matching baud and framing.

Final thought

Start with small prints and known sequences to confirm setup. Use symptoms to guide register checks and fix the root cause efficiently.
