Module 5 › Chapter 4.3 › Initialize UART0
Process Flow

Initialization steps

  1. Enable clock: SYSCTL_RCGCUART_R |= 0x01; SYSCTL_RCGCGPIO_R |= 0x01; then wait for stability.
  2. Pin setup: GPIO_PORTA_AFSEL_R |= 0x03; GPIO_PORTA_DEN_R |= 0x03; make PA0/PA1 UART pins.
  3. Disable UART: clear UART0_CTL_R while changing settings.
  4. Baud rate: program UART0_IBRD_R and UART0_FBRD_R for the desired baud.
  5. Line control: set UART0_LCRH_R for 8N1 and enable FIFOs (0x70 in the example).
  6. Enable UART: set UART0_CTL_R |= 0x01 to allow TX and RX.
Why each step matters
  • Clock: register writes have no effect without a running peripheral clock.
  • Pin AF: pins default to GPIO and must be switched to the UART function to carry serial data.
  • Baud divisors: wrong numbers produce unreadable or garbled output at the PC.
Concrete example

With a 16 MHz system clock, setting IBRD=8 and FBRD=44 yields 115200 baud as shown in the provided code. Verify by printing a fixed string and watching the terminal.

Key Takeaway

Follow the enable-config-enable pattern and verify each step by printing a known string.
