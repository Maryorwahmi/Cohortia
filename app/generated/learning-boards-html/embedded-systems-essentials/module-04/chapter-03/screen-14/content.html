Assessment

Compute IBRD and FBRD for 9600

BRD = 16000000 / (16 × 9600) = 104.1667\nIBRD = 104\nFBRD = round(0.1667 × 64) = 11
Program UART0_IBRD_R = 104 and UART0_FBRD_R = 11, set UART0_LCRH_R for 8N1, and enable the UART. Verify by opening a terminal at 9600, sending a test string, and confirming readable output.
Key Takeaway

Always base divisors on the actual system clock and recompute when clock settings change.
