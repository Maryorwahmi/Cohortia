Objective checklist
  1. Configure UART0: Enable SYSCTL clocks and confirm PA0/PA1 act as UART pins.
  2. Send/Receive: Implement a send-char routine that waits for the transmit FIFO to accept data.
  3. Printf-style: Print counters or switch states and verify in the terminal.
  4. Framing & baud: Use 115200, 8 data bits, 1 stop bit, no parity for examples in this chapter.
VERIFIED COMPETENCY MILESTONE
Quick experiment

Upload a small program that initializes UART0 and prints numbers from 0 to 100 at 115200. Open a terminal and confirm you see each number on its own line. This isolates configuration from your application logic.

Common failure modes
  • Wrong baud settings cause garbled or unreadable text.
  • Pins left in GPIO mode instead of their alternate function remain silent.
  • Forgetting to enable the peripheral clock prevents the UART from responding.
