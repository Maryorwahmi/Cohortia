Module 5 › Chapter 4.3 › What is a UART?
Definition

Universal Asynchronous Receiver/Transmitter

A UART sends bytes as a sequence of bits with start and stop framing. Both devices must agree on the baud rate and data format.

Key properties
  • Asynchronous: no shared clock, relies on agreed baud.
  • Framing: start bit, data bits (commonly 8), optional parity, stop bits.
  • Simple hardware interface: TX and RX signals mapped to pins.
Practical debugging scenario

Print sensor values and a short label each time you read the sensor. Watching the stream in the terminal reveals timing and incorrect ranges faster than stepping through code with a debugger.

Concrete example: terminal output
Hello, Embedded World!\r\n\n sensor=512 time=0.123s\r\n sensor=514 time=0.223s\r\n sensor=1023 time=0.323s\r\n
Common misconception

Thinking UART requires a special display. In fact, the PC terminal serves as the display and the USB debugger often provides a virtual COM connection to UART0.

Key Takeaway

UART turns internal values into readable text, making it the most accessible debugging channel on many boards.
