Design pattern

Small helpers compose into printf

// send-char and send-string as before\n// integer to ascii (very small)\nvoid UART0_SendUnsigned(uint32_t value) {\n char buf[11];\n int i = 0;\n if (value==0) { UART0_SendChar('0'); return; }\n while (value) { buf[i++]= '0' + (value % 10); value/=10; }\n while (i--) UART0_SendChar(buf[i]);\n}
This minimal integer formatter prints unsigned decimals and can be combined with send-string to produce messages like "count=42" followed by newline for readability in the terminal.
Practical example
count=0\r\ncount=1\r\n...\r\ncount=100\r\n
Misconception check

Do not assume desktop printf is suitable for small microcontrollers. Implement only the features you need to keep code size and complexity low.

Key Takeaway

A few small, tested helpers give you robust debugging prints without large library overhead.
