Module 5 › Chapter 4.3 › Common errors
Symptom → Likely cause
  • No output: check SYSCTL RCGCUART and RCGCGPIO, and confirm PA0/PA1 alternate function and UARTCTL enable.
  • Garbled characters: check IBRD/FBRD values and terminal baud/framing.
  • Missing characters or drops: ensure you wait for TX FIFO not-full and consider pacing your prints.
  • Wrong variable values: add prints near the sensor read to isolate logic errors.
Practical diagnostic flow
  1. Print a fixed string immediately after initialization to confirm wiring and clock.
  2. If garbled, compute and rewrite divisors for the target baud.
  3. If intermittent, add checks for transmit fullness and slow down prints.
  4. When values are wrong, instrument the code more narrowly to find where data changes unexpectedly.
Why this matters

A focused checklist keeps you from guessing and reduces time spent toggling unrelated settings.
