Module 5 › Chapter 4.3 › UART Registers
Architecture

Key registers

  • UARTIBRD / UARTFBRD: integer and fractional divisors for baud generation.
  • UARTLCRH: line control, data bits, parity, stop bits, and FIFO enable.
  • UARTCTL: control register to enable TX and RX.
  • UARTDR: data register for sending and receiving bytes.
  • UARTFR: flag register for status bits like transmit FIFO full.
Concrete example

After calculating divisors for 115200, write IBRD=8 and FBRD=44. Set LCRH to 0x70 to request 8N1 with FIFOs. Then set CTL to enable the UART. If you still see nothing, check SYSCTL clock gating for UART0 and GPIO Port A.

Troubleshooting tip

If output is garbled, first check divisors and system clock. If there is no output at all, confirm the UARTCTL enable bit and the GPIO alternate function for PA0/PA1.

Key Takeaway

Divide responsibilities across registers: divisors for baud, LCRH for framing, CTL for enabling, DR/FR for data and status.
