Example C
// Enable clock for UART0 and GPIO Port A\nSYSCTL_RCGCUART_R |= 0x01;\nSYSCTL_RCGCGPIO_R |= 0x01;\n// Wait for clocks to stabilize\nwhile ((SYSCTL_RCGCGPIO_R & 0x01) == 0) {}\n\n// Set PA0/PA1 to UART\nGPIO_PORTA_AFSEL_R |= 0x03;\nGPIO_PORTA_DEN_R |= 0x03;\n\n// Disable UART while configuring\nUART0_CTL_R &= ~0x01;\n// Set baud: IBRD=8 FBRD=44 for 115200 with 16 MHz\nUART0_IBRD_R = 8;\nUART0_FBRD_R = 44;\n// 8 data bits, 1 stop, no parity, FIFOs enabled\nUART0_LCRH_R = 0x70;\n// Enable UART0\nUART0_CTL_R |= 0x01;
Annotation
  • Clock enables ensure the peripheral registers are functional.
  • Alternate function and digital enable switch pin modes from GPIO to UART.
  • IBRD and FBRD set the baud generator; they come from the baud calculation.
Terminal test
Hello, Embedded World!\r\n
Pro tip

After initialization, send a simple known string to confirm all steps worked. If you see nothing, re-check clock and pin settings before changing baud divisors.

Common mistake

Not waiting for clock stabilization or leaving PA0/PA1 as GPIO will result in no output.
