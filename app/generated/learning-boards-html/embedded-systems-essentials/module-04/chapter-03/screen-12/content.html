Task

Count 0 to 100 over UART

int main(void) {\n UART0_Init();\n for (int i=0;i<=100;i++) {\n UART0_SendUnsigned(i);\n UART0_SendString("\r\n");\n // optional: read switch and print its state\n }\n while(1) {}\n}
Open a terminal at 115200, set 8N1, and verify you see each number on its own line. Extend the loop to print a switch read value to practice combining inputs and prints.
Verification steps
  1. Upload firmware and ensure the board is powered via USB debugger.
  2. Open the correct virtual COM port in your terminal program.
  3. Set terminal settings to 115200, 8 data bits, no parity, 1 stop bit.
  4. Observe the sequence 0 to 100; if missing, re-check initialization and TX FIFO handling.
Troubleshooting tip

If output is present but numbers repeat or skip, check whether your loop runs faster than the UART can transmit and ensure you wait for the transmit FIFO as shown in the example code.
