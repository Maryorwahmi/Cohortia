GPIO Current Limits and Safe LED Driving
Always limit current to protect the MCU and LEDs
LED wiring rule
Use GPIO → 220 Ω → LED anode → LED cathode → ground. The resistor limits current so the pin and LED are not damaged.
When to use drivers
If you need to drive more current than a pin allows, switch to a transistor or dedicated LED driver rather than paralleling many LEDs on a single pin.
Common mistake
Omitting the resistor because the LED lights briefly—this damages the pin over time. Always include a series resistor and verify with a meter before long-term use.
Key Takeaway
Respect GPIO current limits. Use a 220 Ω resistor for 3.3V LEDs and add a transistor driver for higher loads.
