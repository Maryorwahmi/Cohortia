Floating Inputs and Defined States
Why pull resistors prevent random readings
Definition
A floating input is not connected to supply or ground when the switch is open. It may pick up interference and change state without a physical press. Pull-up and pull-down resistors provide a weak connection so the pin has a deterministic idle voltage.
Key points
  • Pull-up ties pin to 3.3 volts through a resistor; idle reading is HIGH.
  • Pull-down ties pin to ground; idle reading is LOW.
  • Use 10 kΩ as a common external value when internal resistors are unsuitable.
Concrete example
LaunchPad built-in switches are active-low with pull-ups. When not pressed the pin reads HIGH; pressing connects to ground and the pin reads LOW.
Analogy
Think of a pull-up like a gentle spring that holds the pin up unless you press it down to ground.
Common mistake
Assuming an unconnected pin will remain stable. Without a resistor, readings can flip randomly and cause false interrupts or toggles.
Key Takeaway
Always give each input a defined idle level using pull-ups or pull-downs to prevent random behavior.
