Common Mistakes and How to Fix Them
Practical fixes for frequent wiring and code errors
Mistake
No pull resistor on a switch (floating input).
Fix: add a pull-up or pull-down, or enable internal pull-up.
Mistake
Resistor placed in parallel with LED instead of series.
Fix: move resistor between GPIO and LED anode so it limits current.
Mistake
Assuming switches are active-high when they are active-low.
Fix: observe pin at rest and on press, then implement logic accordingly.
Key Takeaway
When debugging, measure voltages and pin reads first—most errors come from wiring and resistor placement, not mysterious code bugs.
