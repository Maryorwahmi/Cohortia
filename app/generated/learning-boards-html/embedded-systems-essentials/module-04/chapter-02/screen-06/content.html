Enabling Internal Pull-Ups
GPIOPUR and GPIOPDR control internal pull resistors
Code example (visual)
// Memory-mapped register alias
#define GPIO_PORTF_PUR_R    (*((volatile uint32_t *)0x40025510))

// Enable pull-up for PF0 and PF4
GPIO_PORTF_PUR_R |= 0x11;  // Bits 0 and 4
This write sets the pull-up bit for each pin. After this, the hardware provides a weak connection to 3.3 volts when the pin is not driven.
Quick checklist
  • Enable clock to the port before touching registers.
  • Set the pull-up bit in GPIOPUR for the specific pins.
  • Confirm the pin reads the expected idle value after enabling.
Misconception
Enabling a pull-up is not the same as configuring the pin as an output. It only affects the internal resistor when the pin is an input.
