Debounce: Stability Counter
Require consecutive stable reads before accepting the change
Code pattern (visual)
uint32_t lastState = 0;
uint32_t debounceCounter = 0;

uint32_t debouncedRead(void) {
    uint32_t currentState = GPIO_PORTF_DATA_R & 0x10;  // Read PF4

    if (currentState != lastState) {
        debounceCounter = 0;
        lastState = currentState;
    } else {
        debounceCounter++;
        if (debounceCounter > 10000) {
            return currentState;
        }
    }
    return lastState;  // Return stable state
}
This function only returns a new value after the counter indicates stability. Adjust the threshold to fit your timing and responsiveness needs.
Pros
Very robust against short bounces; works well when loop timing is consistent.
Caution
Picking an overly large threshold causes sluggish response. Measure typical bounce duration to set a reasonable threshold.
Key Takeaway
Use consecutive stable samples to confirm a switch state before acting; tune the threshold for responsiveness.
