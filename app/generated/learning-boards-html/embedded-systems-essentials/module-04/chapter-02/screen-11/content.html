Double-Read Debounce
A straightforward method that balances simplicity and effectiveness
Code pattern (visual)
uint32_t readSwitch(void) {
    uint32_t first = GPIO_PORTF_DATA_R & 0x10;
    delay(10000);  // Wait for bounce to settle
    uint32_t second = GPIO_PORTF_DATA_R & 0x10;
    if (first == second) {
        return second;
    }
    return 0x10;  // Not pressed if bouncing
}
If the two readings match, the switch is accepted. The delay value should be chosen based on typical bounce duration.
Pros
Very simple to implement and reason about; useful for quick prototypes.
Tradeoff
Adds a fixed delay per check which can make the interface feel slower if the delay is long.
Key Takeaway
Use double-read for simplicity, and tune delay to be long enough to outlast bounce but short enough to stay responsive.
