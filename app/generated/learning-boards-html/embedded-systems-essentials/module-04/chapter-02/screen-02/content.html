Learning Objectives
Practice outcomes and competency milestones
01
Wire switches and LEDs
Build a two-switch, two-LED breadboard circuit and verify toggles.
This objective emphasizes correct pin connections, resistor placement, and a simple test that toggles an LED from a switch press. A small Venn shows overlap of wiring and testing skills.
VERIFIED COMPETENCY MILESTONE
02
Explain pull-up vs pull-down
Describe how each resistor defines the idle pin state and prevents floating.
Relate the resistor choice to an example: a switch wired to ground uses a pull-up so the idle reading is HIGH. Misconceptions: internal pull-ups are not strong resistors—use external when you need a specific value.
VERIFIED COMPETENCY MILESTONE
03
Use internal pull resistors
Enable GPIOPUR or GPIOPDR to set internal pull behavior on the TM4C123G.
Understand the register names and the effect on individual pins. Example: enabling pull-up for bits 0 and 4 sets the idle state for the LaunchPad's built-in switches.
VERIFIED COMPETENCY MILESTONE
04
Debounce switches in software
Implement a counter or double-read strategy to accept only stable transitions.
Practice two patterns: a timed double-read and a counter that increments only when the reading is stable. Assess which is simpler or more reliable for your project.
VERIFIED COMPETENCY MILESTONE
