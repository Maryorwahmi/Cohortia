Hands-On Build Guide
Wiring checklist and program structure
Wiring checklist
  • PF0 switch: enable internal pull-up in software.
  • PE0 switch: external 10 kΩ pull-down to ground.
  • PB0 and PB1 LEDs: GPIO → 220 Ω → LED anode; LED cathode → ground.
Program structure
Initialize GPIO and pull resistors, run a debounce routine per switch, and toggle LEDs in the event handler when debounced state changes.
Debug tips
If you see ghost presses, check for floating pins, incorrect resistor placement, or missing register enabling for pull-ups.
Key Takeaway
Divide the task: wire first, then enable pulls, then add debounce logic and verify behavior step by step to isolate issues quickly.
