Ring buffer code
#define BUFFER_SIZE 64

uint32_t buffer[BUFFER_SIZE];
uint32_t head = 0;
uint32_t tail = 0;

void bufferWrite(uint32_t value) {
    buffer[head] = value;
    head = (head + 1) % BUFFER_SIZE;
    if (head == tail) {
        tail = (tail + 1) % BUFFER_SIZE; // overwrite oldest
    }
}

uint32_t bufferRead(void) {
    if (tail == head) {
        return 0; // buffer empty
    }
    uint32_t value = buffer[tail];
    tail = (tail + 1) % BUFFER_SIZE;
    return value;
}
This implementation uses modulo to wrap indexes and advances tail to preserve the most recent BUFFER_SIZE items when writes overtake reads.
Concurrency considerations
  • Single producer and single consumer may be safe with volatile indexing and careful ordering.
  • Multiple writers or readers require atomic operations or disabling interrupts briefly during index updates.
  • Document whether reads return a special empty code or block until data arrives.
Key Takeaway

Use modulo for wrap, advance tail on overwrite, and protect concurrent access according to your system's needs.
