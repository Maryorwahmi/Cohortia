Module 5 › Chapter 5.1 › Passing arrays to functions
Signature pattern
Pass pointer to first element, size, and a pointer for output if needed.
void calculateAverage(uint32_t *data, uint32_t size, uint32_t *result) {
    uint32_t sum = 0;
    for (uint32_t i = 0; i < size; i++) {
        sum += data[i];
    }
    *result = sum / size;
}

// Caller:
uint32_t values[10];
uint32_t avg;
calculateAverage(values, 10, &avg);
Example
This pattern computes an average without copying the array; the function writes the result back through the result pointer.
Pitfall
If size is zero or larger than the real array, the function will divide by zero or read out-of-bounds. Always validate inputs at the call and in the function.
Const correctness and documentation
When the function must not modify the buffer, declare the pointer const. Document whether null pointers are allowed and whether size zero is valid to make safe calling contracts.
Check Your Understanding

What happens if you pass an array and an incorrect size? Hint: reading beyond allocation leads to undefined behavior.
