Arrays and Data Collection
Store sequences, group fields, and log continuous streams while staying mindful of memory limits.

Arrays are contiguous memory for items of the same type. Use them for sensor histories and lookup tables.

Structures group related fields like timestamp, value, and status so each sample stays self-contained.

Circular buffers overwrite oldest data, keeping a sliding window of recent samples without dynamic allocation.
