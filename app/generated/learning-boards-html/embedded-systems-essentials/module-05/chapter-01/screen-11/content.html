Module 5 › Chapter 5.1 › Overwrite vs blocking semantics
Design trade-offs
Decide whether continuous logging or guaranteed capture matters more for your system.
Overwrite
  • No blocking, predictable memory usage.
  • Best for telemetry, diagnostics, and sliding windows.
  • Optionally set an overwrite flag so code knows data was lost.
Blocking / Reject
  • Preserves all samples at the cost of complexity.
  • Requires flow control, signaling, or increased buffer sizes.
  • Better for critical acquisition or packet capture.
Check

Which policy fits your application? If you can tolerate missing older samples, choose overwrite. If you cannot, design flow control or enlarge buffers.
