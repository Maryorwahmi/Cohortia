Module 5 › Chapter 5.1 › What is an array in C?
Array declaration and access
Fixed-size slot container in contiguous memory; index starts at zero.
// Reserve 100 unsigned 32-bit samples
uint32_t sensorData[100];

// Write samples
sensorData[0] = 42;
sensorData[1] = 55;

// Iterate
for (uint32_t i = 0; i < 100; i++) {
    sensorData[i] = readSensor();
}
Example
Storing one hundred temperature readings sampled once per second gives a predictable minute-and-forty history.
Common mistake
Assuming the language checks bounds. Writing past the last index corrupts memory and leads to unpredictable failures.
Key Takeaway

Arrays provide compact, predictable storage. Always ensure your index stays within declared size.

Memory layout visualization
Notice that the array's index labels map directly to consecutive memory. That mapping makes pointer arithmetic predictable: array plus offset leads to the correct element address, and lack of bounds checking is a safety cost we must manage.
