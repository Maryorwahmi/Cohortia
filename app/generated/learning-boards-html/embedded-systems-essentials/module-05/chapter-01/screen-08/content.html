Module 5 › Chapter 5.1 › calculateAverage example explained
Secure version
void calculateAverage(const uint32_t *data, uint32_t size, uint32_t *result) {
    if (data == NULL || result == NULL || size == 0) return; // defensive
    uint64_t sum = 0; // wider accumulator to avoid overflow
    for (uint32_t i = 0; i < size; i++) {
        sum += data[i];
    }
    *result = (uint32_t)(sum / size); // integer average
}
Note the defensive null checks and the use of a 64-bit accumulator to reduce overflow risk on many 32-bit additions.
Practical considerations
  • Validate size is non-zero to avoid division by zero.
  • Use wider accumulator if element values can sum beyond the accumulator width.
  • Remember integer division truncates; use fixed-point or float if you need fractions.
Check
Would a 64-bit accumulator be available on your MCU? If not, design scaled averaging or periodic subtraction to avoid overflow.
