Module 5 › Chapter 5.1 › Lab: sample a switch into a ring buffer
Lab steps
Step 1
Define BUFFER_SIZE = 64 and declare your buffer type. Decide whether to store timestamps or just states.
Step 2
Implement bufferWrite with head/tail wrap and overwrite policy. Sample switch every 100 ms and write to buffer.
Step 3
After 10 seconds, dump buffer contents to UART and compute average intervals between press timestamps.
Remember to account for debouncing: sample rate must not record multiple toggles for one press. If storing timestamps, use the same time base for interval calculation. If memory is tight, store only state transitions with timestamps instead of every poll.
Key Takeaway

The lab exercises declaration, ring writes, UART dumps, and basic analysis—use debouncing and choose types carefully for minimal RAM use.
