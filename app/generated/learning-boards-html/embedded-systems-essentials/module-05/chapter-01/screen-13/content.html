Why this helps
This exercise reinforces indexing, loop invariants, and how to communicate multiple results safely in C.
Misconception
Confusing notation does not change memory access; both indexing and pointer arithmetic result in the same element address calculation.
Key Takeaway

Practice traversal and clear return semantics; use array notation for readability and pointer notation when manipulating addresses explicitly.
