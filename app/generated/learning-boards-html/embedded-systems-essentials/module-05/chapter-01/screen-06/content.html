Module 5 › Chapter 5.1 › Structures and arrays of structures
Structure declaration
A structure groups related fields so each sample is a single record.
typedef struct {
    uint32_t timestamp;
    uint32_t value;
    uint8_t  status;
} SensorReading;

SensorReading readings[50];
Example
Each array element is a complete sample: timestamp plus value plus status makes processing simpler and clearer than parallel arrays.
Pro tip
Order fields from largest to smallest to reduce padding or explicitly use packed attributes only when alignment is acceptable for your CPU.
Array of structures visualization

timestamp | value | status
Record 1
timestamp | value | status
Processing one record at a time avoids scattered memory accesses and keeps code readable: readings[i].value is clear and compact. Consider size and alignment when designing the struct for minimal RAM usage.
Key Takeaway

Structures make grouped samples explicit and arrays of structs give contiguous records for easier per-sample processing.
