Module 5 › Chapter 5.1 › Sizing arrays and avoiding overflow
Sizing checklist
Choose types
Prefer the smallest integer width that preserves range. For timestamps, use 32-bit when needed; for flags, use 8-bit.
Document cost
Calculate bytes used and verify against available static RAM; update documentation if sizes change.
Accumulator
Use a wider accumulator for sums to prevent overflow when aggregating many elements.
Index validation
Always validate indexes or use less-than loop conditions tied to the declared size to prevent overruns.
Key Takeaway

Sizing choices and defensive checks prevent memory corruption and ensure predictable behavior on constrained microcontrollers.
