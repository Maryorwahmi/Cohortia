Module 5 › Chapter 5.1 › Circular buffer (ring buffer) concept
Ring buffer essentials
Head advances on write, tail advances on read, both wrap using modulo arithmetic.
State
Keep two indexes: head for next write and tail for next read. When head equals tail the buffer is empty; on write if head reaches tail, advance tail to overwrite oldest data.
Wrap
Use head = (head + 1) % BUFFER_SIZE to wrap. This guarantees head stays within bounds and simplifies logic.
Example
A 64-slot ring sampled every 100 milliseconds keeps 6.4 seconds of recent data without dynamic allocation.
Misconception
Rings do not automatically prevent data loss; deciding to overwrite oldest data is a deliberate design choice.
