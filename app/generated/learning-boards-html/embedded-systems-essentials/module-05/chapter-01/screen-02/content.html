Learning Objectives
Learn, understand, apply, and master array-based data collection
Bloom: Learn → Understand → Apply → Master
01
Declare arrays and structures
Declare uint32_t arrays and typedef structures to group sample fields. This matters for compact storage and clear code.
Mnemonic: stacked boxes = contiguous memory
VERIFIED COMPETENCY MILESTONE
02
Store sensor histories using arrays
Use arrays to maintain fixed-size history buffers for sensor samples where memory and timing are deterministic.
Mnemonic: timeline of dots = sample history
VERIFIED COMPETENCY MILESTONE
03
Implement circular buffers
Track head and tail indexes and wrap with modulo arithmetic to overwrite the oldest sample when full.
Mnemonic: ring arrow = wrap-around
VERIFIED COMPETENCY MILESTONE
04
Pass arrays to functions
Send a pointer to the first element and a size parameter so functions can process or modify the array in place.
Mnemonic: arrow into function = in-place change
