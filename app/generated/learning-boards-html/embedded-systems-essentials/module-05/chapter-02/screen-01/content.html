Functional Debugging and Performance Analysis
Verify behavior, measure execution time with SysTick, and use assertions to stop failures fast.
Observe
Dump arrays and UART output to verify function outputs for known inputs.
Measure
Use SysTick to count clock cycles and quantify execution time.
Assert
Add assertions that report line numbers and halt on unexpected conditions.
In this lesson
You will build test tables, run unit-style tests on hardware, measure functions with SysTick, and add assertion checks during development.
Getting started
Try a small test table and UART dump first. Then add a timing measurement to one function to compare behavior and cost.
