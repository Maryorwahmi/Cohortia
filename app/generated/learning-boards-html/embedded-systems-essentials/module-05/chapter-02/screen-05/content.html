typedef struct {
uint32_t input;

} TestCase;
TestCase tests[5] = { /* known inputs */ };

Checks and pitfalls
  • Reset shared state between cases if the function mutates global state.
  • Keep expected values authoritative and version-controlled.
  • Use clear UART formatting so rows are easy to parse by eye or script.
