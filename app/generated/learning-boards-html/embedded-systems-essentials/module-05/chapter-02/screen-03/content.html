Functional Debugging Demo
Create and run a test table, then inspect a UART dump to confirm pass/fail outcomes.
TestCase structure
input, expectedOutput, actualOutput, passed
Example: known ADC->temp pairs for verification.
Outcome: UART shows which cases failed and why so you can fix the converter.
Timing and Assertions
Wrap calls with a SysTick sampler and add assertions that report failures during development.
SysTick: load reload, clear current, enable, sample current register before and after the measured piece.
Assertion macro: send a message and halt on failure to stop misguided execution paths.
