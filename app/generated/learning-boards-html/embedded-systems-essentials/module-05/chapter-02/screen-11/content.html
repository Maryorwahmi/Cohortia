Comparison
Hardware timer vs software loop
Software loop: depends on compiled instructions and can vary across toolchains.
SysTick: hardware, counts clock cycles consistently and is independent of compiler decisions.
When to use each
  • Use software loops for simple delays when accuracy is not required.
  • Use SysTick for profiling and performance analysis where reproducibility matters.
Practical note
SysTick measures cycles at the core clock. To convert to time, divide cycles by clock frequency. This gives microsecond-level resolution on many embedded systems.
Assessment example: 8000 cycles on an 80 MHz processor equals 100 microseconds. Use this conversion to judge whether the function meets timing constraints.
Check your understanding
If you see differing timings between builds, suspect compiler changes if you used a software loop; with SysTick, investigate interrupts and hardware differences instead.
