Definition
Assertion macro
A development-time check that reports a failing condition and halts execution to aid debugging.
Behavior: if condition is false, send a clear message over UART with line number and stop in an infinite loop so developers can inspect state.
Development vs Production
Enable assertions during development builds. In production define the macro to nothing to avoid halting behavior and minimize code size.
Example run
ASSERT(false) → UART: ASSERTION FAILED at line 123 → system halts. Use the line number to locate the faulty assumption.
Common pitfalls
  • Don't rely on assertions for expected user input errors; handle those with normal error handling.
  • Be careful halting in safety-critical systems; use a development-only channel or fallback when needed.
Key Takeaway

Assertions give immediate, precise failure signals during development so you can fix incorrect assumptions quickly.
