Code Walkthrough
Init and read
NVIC_ST_CTRL_R = 0; NVIC_ST_RELOAD_R = 0x00FFFFFF; NVIC_ST_CURRENT_R = 0; NVIC_ST_CTRL_R = 0x05;
SysTick_Read simply returns the current value register. Use these two routines together to time calls.
Measurement caveat
Interrupts and context switches add cycles. For short deterministic measurements, run several iterations and take a median to reduce noise.
Visual timing flow
start = SysTick_Read(); call function; end = SysTick_Read(); elapsed = start - end;
Example use
Wrap the factorial or a sort routine and record cycle counts for increasing inputs to see scaling behavior.
Check your understanding
If a measured result is negative after subtraction, check for wrap or sampling order mistakes since SysTick counts down.
