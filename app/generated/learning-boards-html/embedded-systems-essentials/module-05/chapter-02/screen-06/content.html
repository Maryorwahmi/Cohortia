Definition
SysTick timer
A 24-bit countdown timer that can be sampled to measure execution time in clock cycles.
  • Initialize: set reload, clear current, enable with core clock.
  • Measure: read current before and after, compute start minus end.
  • Convert: cycles divided by CPU frequency yield seconds.
Wraparound note
Because it counts down, if your measured section exceeds the timer range the result will be incorrect. For short functions the 24-bit range is usually sufficient, but you can guard for wrap by checking whether end is greater than start and adjusting accordingly.
Key Takeaway

SysTick provides reliable cycle counts for short measurements and is more accurate than timing via software loops.

Register pattern (visual)
NVIC_ST_CTRL_R = disable during setup; NVIC_ST_RELOAD_R = max reload; NVIC_ST_CURRENT_R = 0 to clear; NVIC_ST_CTRL_R = enable with core clock.
Sample usage
Call SysTick_Read() before and after the measured function and return start minus end to get elapsed cycles.
Practical example
Measure a small math routine or a recursive function for a few inputs to see how cycles change. This gives concrete data to prioritize optimizations.
