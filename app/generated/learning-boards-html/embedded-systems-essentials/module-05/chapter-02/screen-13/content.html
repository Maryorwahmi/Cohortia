Process
Practical checklist
1. Build tests
Table-driven cases with expected outputs.
2. Run and dump
Inspect UART output for pass/fail rows.
3. Measure
Use SysTick, repeat runs, and record medians.
4. Guard wrap
Detect and correct timer wraparound where needed.
5. Assert
Enable assertions during development to halt on bad assumptions.
6. Document
Record CPU frequency, interrupt status, and measurement conditions.
Key Takeaway

A short, repeatable checklist ensures that your correctness checks and performance measurements are reliable and actionable on hardware.
