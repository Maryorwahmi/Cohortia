Module 3 › Chapter 3.1 › Operators — bitwise emphasis
Operator categories
  • Arithmetic: +, -, *, /, % — numerical maths.
  • Comparison: ==, !=, <, >, <=, >= — tests for decisions.
  • Logical: &&, ||, ! — combine boolean conditions.
  • Bitwise: &, |, ^, ~, <<, >> — manipulate individual bits.
Concrete example
Use a mask to set bit 3: perform register = register | (1u << 3). To clear bit 3: register = register & ~(1u << 3). Always use parenthesized masks to avoid precedence mistakes.
Common mistake
Applying arithmetic modification to a register without masking can change reserved bits and disrupt hardware state. Always mask and document which bits are safe to modify.
Pro tip
Define named constants for masks, like LED_MASK = (1u << 2), and use them to make intent clear.
Key Takeaway
Bitwise ops are the correct tool to change single bits; always use masks and named constants to prevent unintended side effects.
