Code walkthrough
#include <stdint.h>

int main(void) {
    // Initialization runs once
    uint32_t counter = 0;

    // Infinite loop runs forever
    while (1) {
        counter = counter + 1;
        // sensor read, decision, output update
    }
}
Initialization
Set up clocks, configure pin directions, initialize peripherals. This code runs just once at startup.
Main loop
The perpetual loop handles sensing and actuation. It does not return on embedded systems.
Check your understanding

Why must initialization run once, and what could happen if you reinitialize a peripheral inside the main loop by mistake?

Common mistake
Reinitializing peripherals inside the loop may reset settings, drop data, or disrupt timing. Keep one-time setup in initialization and repeated tasks in the loop.
Key Takeaway
Separate startup configuration from periodic work. Treat main as the perpetual runtime environment of your device.
