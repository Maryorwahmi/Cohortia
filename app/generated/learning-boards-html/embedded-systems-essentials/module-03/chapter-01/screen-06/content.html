Module 3 › Chapter 3.1 › Fixed-width integer types
Type reference
  • uint8_t — unsigned 8-bit integer (0 to 255)
  • int8_t — signed 8-bit integer (-128 to 127)
  • uint16_t — unsigned 16-bit integer (0 to 65,535)
  • int16_t — signed 16-bit integer (-32,768 to 32,767)
  • uint32_t / int32_t — unsigned/signed 32-bit integers
Concrete scenario
If a sensor yields values up to 65,000, use uint16_t. Choosing uint8_t would overflow; choosing uint32_t wastes memory if many such variables exist.
Why portability matters

Different compilers and boards define plain types differently. Fixed-width names remove ambiguity and make code behavior consistent across targets.

Pitfall
Assuming an int is always 32 bits can lead to subtle bugs when moving code to smaller architectures. Always pick an explicit width when hardware constraints matter.
Key Takeaway
Prefer the narrowest fixed-width type that safely holds your range to balance memory use and correctness.
