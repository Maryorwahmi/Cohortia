Practical task cards

Each card describes a short task that verifies competency and highlights reasoning.

Task: Compile minimal firmware
Produce a binary for an ARM Cortex-M target and observe initializations run once before the main loop.
Task: Count with uint8_t
Implement a loop that increments a uint8_t and watch the value wrap from 255 to 0 in the debugger.
Task: Bitwise register ops
Use bitwise AND and OR to set or clear bits in a mock hardware register variable to control pins or flags.
Task: Predict overflow
Given two unsigned bytes, predict the result and explain wrap-around behavior if the sum exceeds the maximum.
Assessment idea
Predict the output of a small snippet that demonstrates overflow. This checks both type knowledge and reasoning about wrap-around.
Verified competency milestone
You can explain why uint8_t wraps from 255 to 0 and how to prevent silent overflow by choosing a wider type or adding checks.
