    uint8_t counter = 0;
    while (1) {

Try adding an LED toggle when counter == 0 to detect the wrap event. If using a simulator without serial, use the debugger watch to observe the variable change.
Checkpoints
  • counter increments each loop iteration
  • counter wraps from 255 back to 0
  • a wrap event can trigger a state change like toggling an LED
Common mistake
Declaring counter as plain int may hide wrap-around; ensure you use uint8_t to intentionally observe wrapping.
Key Takeaway
This simple loop demonstrates how type choices directly determine runtime behavior; test and observe to build intuition.
