Module 3 › Chapter 3.1 › Signed vs Unsigned integers
Comparison: ranges
uint8_t
0 to 255 — ideal for counters and indices that never go negative.
int8_t
-128 to 127 — use when values can be below zero, such as signed sensor offsets.
Example pitfall
Subtracting larger unsigned from smaller unsigned underflows and yields a large positive value because the result wraps around the maximum representable value.
Practical guidance
  • Use unsigned for nonnegative counts, sizes, and bit masks.
  • Use signed for signed measurements or differences that can be negative.
  • Cast explicitly when mixing signed and unsigned to show intent.
Common mistake
Assuming subtraction yields a negative signed result when variables are unsigned. This leads to surprising large values due to wrap-around.
Key Takeaway
Pick signedness to match the domain of the value and be explicit about conversions to avoid implicit, dangerous behavior.
