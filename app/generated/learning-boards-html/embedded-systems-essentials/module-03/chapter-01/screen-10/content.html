Module 3 › Chapter 3.1 › Using switch for state handling
Process: state machine with switch
Define an enum or integer for states and use switch to dispatch behavior. Keep each case small and call helper functions to keep logic clear and testable.
Example structure
state variable: 0 = idle, 1 = sample, 2 = transmit. In main loop, switch(state) handles each mode and updates state when transitions are needed. default handles unexpected states by resetting or logging.
Common mistake
Omitting break leads to fall-through. Only use fall-through intentionally and document it with a comment so future readers understand the intent.
Key Takeaway
Switch simplifies multi-way branching for state machines; include a default and keep case bodies concise by calling handlers.
