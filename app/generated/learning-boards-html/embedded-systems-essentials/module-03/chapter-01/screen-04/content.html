Module 3 › Chapter 3.1 › Why C is the language of embedded systems
Definition

C compiles to native code, offers direct access to memory and registers, and supports compact, efficient programs suitable for resource-constrained microcontrollers.

Concrete example
Toggling a pin by writing a value to a register and using bitwise operations to change only specific bits without disturbing others.
Common misconception
People often assume C is unsafe; the reality is that with fixed-width types and clear patterns, C can be predictable and maintainable.
Key Takeaway

C's low-level capabilities make it ideal for firmware, but they require disciplined type choices and clear code to remain reliable.

Analogy

Think of C as the instrument panel controls in a machine: it gives you direct knobs and switches rather than higher-level automated menus. That directness is powerful if you know how to use it responsibly.

Why this matters
  • Direct native code reduces runtime overhead and latency.
  • Explicit memory access enables precise control of peripherals and DMA.
  • Predictable behavior simplifies reasoning about timing and resource use.
