Core Concept

Avoid these pitfalls

Cards list mistakes with prevention tips.

Buffer overflow
Always check bounds and prefer fixed-size buffers with clear limits.
Stack overflow
Avoid large local arrays and recursion. Move big buffers to static storage.
Uninitialized & dangling pointers
Initialize pointers to NULL and clear them after free; avoid returning addresses to stack-allocated memory.
Key Takeaway

Defensive coding and static allocation reduce the most common and dangerous memory errors in embedded systems.

Debugging cards
Use the debugger
  • Inspect addresses of globals, statics, and locals.
  • Monitor stack pointer in different contexts (main and interrupts).
  • Check for overwritten memory near array boundaries.
