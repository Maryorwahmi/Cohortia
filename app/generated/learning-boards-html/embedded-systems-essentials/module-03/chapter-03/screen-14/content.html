Startup & Reset
Reset vector leads to startup code that readies the runtime and calls main.
Memory Layout
.text, .data, .bss, stack, and heap each have distinct roles and constraints.
Variable Scope
Global, local, and static map to program lifetime or stack lifetime and visibility.
Summary

Design for predictability: initialize correctly, bound stack use, avoid heap where possible, and validate with tools.
