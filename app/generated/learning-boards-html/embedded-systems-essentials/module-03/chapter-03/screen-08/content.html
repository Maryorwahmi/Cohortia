Module 4 › Chapter 3.3 › Stack Behavior and Stack Overflow
Definition

Stack growth and frames

A vertical stack of call frames uses RAM; callers and callees add to depth. Keep frames small.

What consumes stack
Local arrays, saved registers, return addresses, and parameter passing.
Symptoms of overflow
Corrupted globals, strange behavior, and hard faults at return or interrupt boundaries.
Prevention
Use static buffers for big data, avoid deep recursion, estimate worst-case usage.
Key Takeaway

Design to bound stack use: move large buffers out of locals and keep call depth predictable.

Concrete example
Local bigArray pitfall

Declaring uint32_t bigArray[1000]; as a local on a microcontroller with 2 KB RAM will likely overflow the stack and crash the program. Make it global or static instead.

Misconception check

Embedded stacks are tiny compared to desktops; desktop habits like large automatic buffers are unsafe here.
