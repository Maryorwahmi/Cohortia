Hands-on Activity

Declare and observe

A step checklist helps you run the experiment and what to expect in the debugger.

  1. Declare a global array of 100 uint32_t values.
  2. Write a function with a local array of 10 uint32_t and a static counter.
  3. Set a breakpoint inside the function and inspect addresses of the three variables.
  4. Observe which region each address belongs to and how the stack pointer changes across calls.
Key Takeaway

Use the debugger to validate your assumptions about variable placement and stack usage before deploying code.

Example code snippet
uint32_t g_array[100];

void func(void) {
  uint32_t local[10];
  static uint32_t counter = 0;
  counter++;
  // breakpoint here and inspect addresses
}
Misconception check

Don't assume stack addresses are stable; they depend on current call depth and saved state.
