Module 3 › Chapter 3.2 › Practical Rules
Mask, don't overwrite
Use bit masks to preserve unrelated fields when updating a register.
Volatile is not a lock
It prevents optimization; use real synchronization primitives for concurrency and ordering.
Encapsulate bit logic
Small helpers reduce repeated mask math and centralize register access rules.
Final takeaway

Combine function design, pointer safety, volatile awareness, and bitwise masking to write robust low-level drivers that are easier to test and debug.
