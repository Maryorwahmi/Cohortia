Module 3 › Chapter 3.2 › GPIO Register Access
Pattern
Create a pointer to the fixed register address, cast to the proper width, and write through it. Use volatile if the register changes asynchronously.
uint32_t *portFData = (uint32_t *)0x400253FC; *portFData = 0x04;
Example
Writing 0x04 sets bit two, turning on the associated GPIO pin while leaving other bits unchanged if you use masked operations first.
Architecture view
Peripheral base
0x400253FC
Safety note
Mask and restore other bits when necessary. Avoid blind overwrites of full registers unless you control the entire register field.
Key Takeaway

Mapping an address with a typed pointer gives direct register access. Always consider masking to preserve unrelated bits.
