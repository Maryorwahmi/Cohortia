How we'll verify skills
  • Function correctness: return expected values for sample inputs and follow naming conventions.
  • Pointer access: read and write a known memory-mapped address and confirm changes with a test pattern.
  • Bit operations: use masks to change single bits and ensure other bits remain unchanged.
  • Integration: combine a pointer to a register with a set/clear helper and blink LEDs to verify live hardware output.
Assessment
Short question: given register 0x3A, what is the value after setting and clearing specific bits. Live task: implement GPIO_SetBit and GPIO_ClearBit and show the LED pattern.
