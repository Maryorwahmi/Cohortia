Module 3 › Chapter 3.2 › Bit Helpers
Design
Functions accept a pointer to a register and a bit index. Compute the mask by shifting one left by the bit and apply the correct operator for set or clear.
GPIO_SetBit(uint32_t *reg, uint8_t bit) { *reg |= (1u << bit); } GPIO_ClearBit(uint32_t *reg, uint8_t bit) { *reg &= ~(1u << bit); }
Concrete test
Pass the pointer to the GPIO data register and bit two to set and clear the LED. Observe the LED pattern to confirm operation.
Checklist
  • Ensure the pointer points to a valid address and uses volatile when accessing hardware.
  • Use unsigned shifts to avoid sign-extension issues.
  • Test with different bits to confirm you only affect the intended bit.
