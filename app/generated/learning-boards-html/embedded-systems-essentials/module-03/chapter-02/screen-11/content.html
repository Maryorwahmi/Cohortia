Step-by-step
Start: register = 0x3A (binary 00111010). Mask for bit one is one shifted left by one (binary 00000010). OR with that mask leaves the value unchanged because bit one is already set. To clear bit four, mask is one shifted left by four (00010000); take complement and AND it with the register to clear just that bit.
Result: 00111010 AND 11101111 = 00101010 which is 0x2A
Common pitfalls
  • Bit numbering off-by-one: datasheets use zero-based indexing.
  • Using signed shifts or forgetting to cast to unsigned can produce wrong masks.
  • Overwriting an entire register instead of masking can disable unrelated features.
