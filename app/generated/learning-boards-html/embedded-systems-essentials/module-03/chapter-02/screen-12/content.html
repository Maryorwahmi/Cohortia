Starter plan
Implement two helpers that compute masks and update the register through a pointer. Map the GPIO data address to a pointer and call the helpers in a pattern to blink LEDs.
// TODO: implement GPIO_SetBit and GPIO_ClearBit // Use pointer to 0x400253FC and blink bits for red, blue, green
Debug tips
Confirm clock enable and pin direction, read back the data register after writes, and verify bit indices from the board documentation.
Why this verifies learning
The pattern forces you to use function design, pointer mapping, volatile awareness, and bit masking. Visual LED feedback closes the loop between code and hardware.
Key Takeaway

A short live-coding task is the fastest way to validate low-level code: write, run, read, and observe.
