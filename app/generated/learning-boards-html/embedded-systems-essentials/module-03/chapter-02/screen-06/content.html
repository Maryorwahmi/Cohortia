Module 3 › Chapter 3.2 › Pointers 101
Core idea
A pointer variable stores a numeric memory address. Use the address-of operator to obtain addresses and the dereference operator to read or write the contents of that address.
uint32_t x = 10; uint32_t *p = &x; *p = 20;
Example
After storing the address of x in p and writing through p, the variable x holds the new value.
Common mistake
Dereferencing an uninitialized pointer leads to undefined behavior. Always initialize pointers to a valid address before use.

Takeaway
Think of pointers as keys to memory addresses; the * operator turns a key into access to that location's content.
