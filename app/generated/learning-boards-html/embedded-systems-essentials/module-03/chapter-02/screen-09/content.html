Module 3 › Chapter 3.2 › Register Macro
Macro pattern
#define GPIO_PORTF_DATA_R (*((volatile uint32_t *)0x400253FC))
Using this macro you write GPIO_PORTF_DATA_R |= 0x04 to set bit two. The macro both documents and centralizes the address.
Example
This macro hides the pointer cast in a readable alias and prevents scattered hard-coded addresses across your codebase.
Guidelines
  • Keep macro names descriptive and centralized in a header file.
  • Treat macro writes as I/O: they affect hardware state and are not just variable assignments.
  • Prefer masked updates where multiple bits share a register.
Key Takeaway

Use macros to centralize addresses and make register access concise, but keep side-effect awareness in your mental model.
