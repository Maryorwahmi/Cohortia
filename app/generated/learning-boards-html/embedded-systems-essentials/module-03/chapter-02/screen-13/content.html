Module 3 › Chapter 3.2 › Key Concepts
Function definition
A signature and body that encapsulate behavior for reuse and clarity.
Void semantics
Use void when no value is returned; common for side-effect routines like blocking delays.
Pointer basics
A typed numeric address. Use & to get addresses and * to access contents at that address.
Summary

Keep these fundamentals in mind as you write small drivers: functions structure code, pointers connect to hardware, and void/volatile choices affect behavior with peripherals.
