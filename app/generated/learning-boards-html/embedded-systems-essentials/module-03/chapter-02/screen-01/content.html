Functions, Pointers, and Bit Manipulation
Build modular code, access hardware addresses, and control single bits without collateral changes.
Why this matters
Embedded code interacts directly with pins and timers. Clear functions and safe register access prevent bugs and hardware faults.
What you'll be able to do
Write functions that accept registers or bit numbers, use pointers to write a hardware register, and use bitwise operators to change single bits.
