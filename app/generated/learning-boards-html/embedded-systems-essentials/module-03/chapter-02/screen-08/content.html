Operations and formulas
  • Set: register |= (1 << bitNumber) — turns a bit on
  • Clear: register &= ~(1 << bitNumber) — turns a bit off
  • Toggle: register ^= (1 << bitNumber) — flips a bit
  • Test: if (register & (1 << bitNumber)) — checks a bit
Example: register = 0x3A (binary 00111010); register |= (1 << 1) keeps it 0x3A; register &= ~(1 << 4) yields 0x2A.
Visual analogy
Imagine a panel of 32 light switches. Each bit corresponds to a switch. Bitwise OR throws the switch to ON for the bits in the mask; AND with complement forces specific switches OFF while leaving others untouched.
Practice
Given a byte, compute the effect of a set and a clear mask. Check your result in hex to confirm exact changes.
Pitfall
Avoid writing a raw literal when you only mean to change one bit; derive masks to preserve other fields.
