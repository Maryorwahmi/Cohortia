Module 7 › Chapter 7.1 › What device-to-device UART means
Definition
Two microcontrollers exchange asynchronous serial bytes directly using UART modules and shared ground.
Use case
Sensor module reports readings to a main controller, which uses the data to adjust outputs in real time.
Key rule
TX of A → RX of B, RX of A ← TX of B, and connect GNDs. This null modem crossover is mandatory.
Common mistake
Wiring TX to TX instead of crossing TX/RX. It appears connected but no data is received.
Concrete example
Two LaunchPads: use UART1 on PB0 (RX) and PB1 (TX) on each board. Connect PB1 of board A to PB0 of board B, PB1 of B to PB0 of A, and connect both grounds. With that wiring, a character sent by board A appears at board B's receive buffer.
Key Takeaway

Cross TX and RX and share ground. If nothing is received, check wiring and ground first before changing code.
