Module 7 › Chapter 7.1 › Designing a simple packet protocol
Packet Structure
A compact packet: start, command, data, checksum.
Start
0xAA
Command
0x01 (LED control)
Data
0x01 (ON)
Checksum
0xAC (sum of prior bytes)
Receiver algorithm: confirm start byte matches the expected marker, read command and data bytes, compute the sum of start, command, and data, and compare to the received checksum. If they match, execute the command; otherwise discard the packet and request retransmission.
