Baud rate essentials
Bit timing must match on both ends or frames break.

Both sides must be configured to the same baud. A mismatch causes the receiver to sample the bit stream at incorrect times and may miss the stop bit, producing a frame error.

Minor timing differences can lead to sporadic errors; treat baud alignment as the first configuration check.

Diagnostic steps
  • Confirm both UART modules use the same baud setting.
  • Check for frame error flags in the UART error register after a read.
  • When errors appear, reduce baud to a slower rate to simplify testing.
Common mistake
Assuming wiring is wrong when frame errors are really caused by an unmatched baud setting.
