Module 7 › Chapter 7.1 › Checksum verification vs packet discard
Accept
When recomputed checksum equals received checksum.
  • Execute command (e.g., toggle LED).
  • Optionally send an acknowledgment to the sender.
  • Log success for monitoring.
Discard
When checksum does not match or packet framing fails.
  • Do not execute the command to avoid unsafe actions.
  • Log the error and request retransmission from the sender.
  • Investigate repeated failures for wiring or baud issues.
Key Takeaway

A simple checksum detects many transmission errors. Prefer rejecting questionable packets and requesting retransmission rather than risking action on bad data.
