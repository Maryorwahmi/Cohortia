Common UART errors
Frame, overrun, and parity errors affect packet integrity.
Frame error
Stop bit not detected; often baud mismatch.
Overrun
New byte arrived before previous was read; reader too slow.
Parity
Parity bit mismatch when parity mode is enabled.
Handling flow
  1. Read UART data register.
  2. Check UARTECR or error status register for flags.
  3. If any flag set, log and discard packet, then request retransmission.
Explicit error checks make root cause analysis possible and keep your system from acting on corrupted data.
