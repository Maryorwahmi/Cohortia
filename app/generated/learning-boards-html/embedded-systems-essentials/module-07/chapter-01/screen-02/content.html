Learning Objectives
Bloom: Learn → Understand → Apply → Master
Verified Competency Milestone: Toggle LED over UART1 with checksum
01
Configure UART1
Enable UART1 on PB0/PB1, set baud and enable TX/RX. This ensures the hardware and pins are ready for device-to-device data.
VERIFIED COMPETENCY MILESTONE
02
Send & Receive Packets
Implement blocking send and receive routines so bytes arrive and are read in order. This supports predictable message parsing and timing.
VERIFIED COMPETENCY MILESTONE
03
Implement Checksum Protocol
Use a start byte plus a checksum computed as the sum of prior bytes to detect corrupted packets before acting on commands.
VERIFIED COMPETENCY MILESTONE
04
Detect & Handle Errors
Check the UART error register for frame, overrun, or parity errors and discard bad packets, then request retransmission.
VERIFIED COMPETENCY MILESTONE
