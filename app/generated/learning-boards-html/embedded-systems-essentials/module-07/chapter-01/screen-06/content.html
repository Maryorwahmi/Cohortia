Module 7 › Chapter 7.1 › Send and receive routines for UART1
Reference Routines
Blocking routines that poll hardware flags before performing I/O.
void UART1_SendChar(char c) {
    while ((UART1_FR_R & UART_FR_TXFF) != 0) {}
    UART1_DR_R = c;
}

char UART1_ReceiveChar(void) {
    while ((UART1_FR_R & UART_FR_RXFE) != 0) {}  // Wait for data
    return (char)(UART1_DR_R & 0xFF);
}
These functions wait on the transmit full and receive empty flags so data writes and reads occur safely. Use them as a baseline before moving to interrupts.
Explanation bullets
  • While loop checks hardware flag to avoid read/write hazards.
  • Writing UART data register transmits the byte onto TX line.
  • Reading UART data register returns the received byte; mask to 0xFF for the data byte.
  • Block until ready works well for short command packets and initial testing.
Pro tip
If you plan concurrent tasks, migrate to interrupt-driven receive to avoid busy-wait CPU usage.
