Module 7 › Chapter 7.3 › Architecture
Hardware blocks
  • LaunchPad MCU (GPIO, UART, timers, NVIC)
  • Button 1: mode select (interrupt)
  • Button 2: action (interrupt)
  • RGB LED: outputs for color and brightness
  • Potentiometer or timer: simulated temperature sensor
Pin mapping
Assign stable pins for buttons and LED, and document them in the architecture diagram for reproducibility.
Software modules
Organize code into small functions and files so each piece can be tested and reused.
initHardware()
Configure clocks, GPIO directions, digital enable, pull-ups, and UART initialization.
ISR handlers
Set volatile flags then return; keep handlers short to avoid missed interrupts.
runFSM()
Consume flags and sensor readings, update systemState, and set LED outputs and UART messages.
sendStatus(), readSensor()
Perform periodic UART reporting and sensor sampling from the main loop.
