Design steps (process)
Follow these ordered steps to keep development predictable.
  1. 1
    Requirements
    Define inputs, outputs, timing, and UART logging needs.
  2. 2
    Architecture
    Block diagram linking hardware pins to software modules.
  3. 3
    State Diagram
    Explicit states, events and outputs for each mode.
  4. 4
    Implementation
    Init, FSM, ISRs, main loop, and modular functions.
  5. 5
    Test & Debug
    Mode-by-mode tests, UART logging, and timing checks.
  6. 6
    Document
    Report design, tests, and known limitations.
Key Takeaway

Small, testable steps reduce integration risk. Start with mode switching and UART logs before adding sensor behavior.

Example increment
Implement Button 1 to cycle modes and send a UART message on each change. Verify the LED shows the current mode color before implementing other behaviors.
Step: Implement mode cycle and UART message.
Test: Press mode button repeatedly and confirm UART logs the new mode and LED color.
Misconception: Don't assume buttons are clean. Debounce and use flags; otherwise transitions will misfire.
