Module 7 › Chapter 7.3 › Implementation
Recommended function list
  • initHardware() — clocks, GPIO, UART init
  • runFSM() — evaluate flags and sensor data, set outputs
  • sendStatus() — format and send UART messages
  • readSensor() — sample ADC or simulate temperature
  • ISR handlers — set volatile flags only
Practical tips
Always enable the GPIO clock and wait for it before configuring pins. Use enums for state clarity. Keep globals small and document volatile flags set by ISRs. Debounce in main loop and avoid heavy work in ISRs.
Example enum (visual)
typedef enum { SECURITY, LIGHTING, CLIMATE } SystemMode;
volatile uint8_t button1Flag = 0; // set in ISR
