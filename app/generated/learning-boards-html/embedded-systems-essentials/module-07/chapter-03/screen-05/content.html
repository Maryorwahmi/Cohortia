Module 7 › Chapter 7.3 › Project Requirements
Requirements (formal)
  • Two buttons (mode, action) and an RGB LED output.
  • Mode cycle: Security, Lighting, Climate.
  • Security: Button 2 arms/disarms. Armed LED=red, Disarmed LED=green. Intrusion blinks red and sends UART alert.
  • Lighting: Button 2 cycles colors: red, green, blue, yellow, cyan, magenta, white.
  • Climate: LED brightness tracks simulated temperature. UART sends readings every 2 seconds.
  • Use FSM for modes, interrupts for button presses (debounced), main loop for periodic tasks.
Acceptance criteria
Define testable pass/fail checks that map to the rubric. Example: pressing Button 2 in Lighting mode cycles through exactly seven colors in order. UART must show temperature every two seconds in Climate mode.
Timing specifics
Debounce interval: 10–50 ms recommended. Temperature telemetry interval: 2 seconds. Alarm blink frequency: choose a visible blink, and log the alert once over UART.
Common mistake
Vague timing and incomplete acceptance tests make verification hard. Be explicit in the requirements document.
