Module 7 › Chapter 7.3 › Key Concepts
Modularity
Split init, FSM, ISR, UART, and sensors into clear functions and files.
Short ISRs
ISRs set volatile flags and clear interrupt status; main loop performs heavy work and debouncing.
UART Traces
Use concise UART messages for state changes, alarms, and periodic telemetry to make debugging objective.
Final takeaway
Combine disciplined design, disciplined ISRs, and disciplined logging to deliver a robust capstone that is easy to grade and extend.
