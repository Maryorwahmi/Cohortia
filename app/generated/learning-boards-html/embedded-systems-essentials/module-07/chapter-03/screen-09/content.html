Logging patterns
Choose short, structured messages that help trace timing and state.
Mode change example: "Mode: Security"
Alarm alert: "ALARM: intrusion detected"
Telemetry: "Temp: 24.2 C" sent every 2 seconds
Code snippet (visual)
// sendStatus() called from main loop
void sendStatus(void) {
    // format short, deterministic messages
    // Example: send "Mode: Lighting\r\n" or "Temp: 23\r\n"
}
Keep message formatting out of ISRs. Use UART logs to confirm state transitions and timing behavior during tests.
