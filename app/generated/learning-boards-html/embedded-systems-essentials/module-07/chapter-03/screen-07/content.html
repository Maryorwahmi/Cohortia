Module 7 › Chapter 7.3 › State Diagram
Top-level FSM
Define an enum for modes and keep the current mode in a global systemState variable.
SECURITY
Sub-states: ARMED, DISARMED, ALARM. Outputs: LED red/green/blink and UART alert when intrusion occurs.
LIGHTING
Maintain color index. Action button cycles colors; outputs are discrete LED colors.
CLIMATE
Read simulated temperature, set LED brightness, and send telemetry every 2 seconds over UART.
Concrete mapping
Use a typedef enum for modes and store a small struct for sub-state values like armed flag or color index. The runFSM function switches on the current mode and handles inputs and outputs there.
Key Takeaway

Make the FSM the single source of truth. Keep transitions simple and assign outputs to states rather than scattering output logic.
