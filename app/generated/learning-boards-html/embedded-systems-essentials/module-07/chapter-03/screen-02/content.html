Learning Objectives
Bloom targets: Learn → Understand → Apply → Master
01
Design a complete system
Write requirements and choose hardware so the system meets functional goals. This gives you a testable plan before coding.
VERIFIED COMPETENCY MILESTONE
02
Integrate core peripherals
Combine GPIO, UART, FSM, and interrupts so inputs and outputs cooperate. Integration reduces surprises in final testing.
VERIFIED COMPETENCY MILESTONE
03
Follow a structured process
Architecture, state diagram, and incremental implementation let you test each part and find bugs early.
VERIFIED COMPETENCY MILESTONE
04
Test, debug, document
Use UART logs, step tests per mode, and a short report to demonstrate correctness and discover edge cases.
VERIFIED COMPETENCY MILESTONE
