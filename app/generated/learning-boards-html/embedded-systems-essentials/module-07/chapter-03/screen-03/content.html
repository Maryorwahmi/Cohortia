How you will be graded
Map each rubric item to a deliverable so reviewers can verify your claims quickly.
Functionality
Does the system meet the requirements for all three modes and transitions?
Code Quality
Is the code modular, readable, and commented with clear function separation?
FSM Design
Is the state diagram correct and used by the implementation?
Debugging
Are UART logs and step tests used to find and fix issues?
Deliverables
  • Firmware binary and source with modular functions
  • State diagram and architecture block diagram
  • UART log sample showing mode changes and telemetry
  • Short report or demo video describing results
