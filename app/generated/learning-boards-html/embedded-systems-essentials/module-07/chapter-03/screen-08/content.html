ISR best practices
Use interrupts to capture events but pass responsibility to the main loop.
  • Declare volatile flags set by ISRs and read in main loop.
  • Keep ISR code minimal: set flag, clear peripheral interrupt, return.
  • Debounce in software in the main loop (10–50 ms or counter method).
  • Document which registers the ISR clears to avoid repeated triggers.
Example pattern
ISR: set buttonFlag = 1; clear GPIO interrupt; return. Main loop: if buttonFlag, perform debounce check, then process and clear buttonFlag.
Common mistake
Doing UART prints in the ISR or long computations there blocks other interrupts and can cause missed events.
