Module 7 › Chapter 7.3 › Testing & Debugging
Test checklist
  1. Hardware I/O verification: buttons generate interrupts; LED responds.
  2. UART sanity: send and receive basic messages.
  3. Mode cycling: confirm mode changes and LED color mapping.
  4. Mode-specific actions: arm/disarm, color cycle, temperature mapping.
  5. Integration: full scenario with intrusion and telemetry running.
Debugging techniques
  • Use UART state dumps to show systemState, flags, and sensor values.
  • Reproduce failures with deterministic inputs and capture logs.
  • Measure timing with SysTick timestamps to find missed deadlines.
  • Isolate failing modules and add temporary diagnostics while debugging.
Pro tip

Keep a test log describing each test step, expected outcome, observed output, and any corrective action. Include UART traces as attachments.
