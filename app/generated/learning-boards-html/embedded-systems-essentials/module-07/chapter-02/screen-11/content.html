Module 07 › Chapter 7.2 › ISR Best Practices
Principles
  • Clear the hardware flag immediately.
  • Keep handlers short and non-blocking.
  • Use volatile for variables shared with main code.
  • Avoid delays or heavy processing inside ISR.
Concrete example
ISR increments volatile switchCount and toggles LED. Heavy logging or delays should be done in the main loop instead, triggered by a flag set in the ISR.
Watch out
Delay inside an ISR blocks higher-priority interrupts and can lead to missed deadlines.
Practical tip
Do minimal work in ISR and signal the main loop to handle longer tasks like UART printing or debouncing.
