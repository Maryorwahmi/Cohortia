Module 07 › Chapter 7.2 › Lab Walkthrough
Step-by-step
  1. Implement GPIOF_InitInterrupt: configure edge, clear pending flag, enable mask, enable NVIC and set priority.
  2. Implement GPIOF_Handler: verify PF4 caused interrupt, increment volatile switchCount, clear GPIO_PORTF_ICR_R, toggle LED minimally.
  3. Main: enter low-power sleep loop and print switchCount via UART every five seconds.
  4. Polling version: sample button state in main loop with debouncing, update count, and measure CPU profile.
Expected outcome
Interrupt version shows lower CPU usage and immediate response; polling version is simpler but wastes cycles when events are rare.
Checks
Validation
  • ISR clears GPIOICR for PF4
  • counter is declared volatile
  • No delays inside ISR
