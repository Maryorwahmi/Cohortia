Module 07 › Chapter 7.2 › Configuring an Interrupt
Configuration steps
1
Enable peripheral
Enable the GPIO pin interrupt mask and set edge/level trigger registers appropriately.
2
Enable NVIC
Write the NVIC enable register for the interrupt number so CPU receives vectors.
3
Set priority
Set the NVIC priority field so critical events preempt less-critical ones.
4
Write ISR
Provide the correctly named ISR and clear the peripheral interrupt flag before returning.
Order matters
Enable peripheral configuration and clear pending flags before enabling NVIC to avoid spurious early interrupts.
Pitfall
If you enable NVIC while a peripheral flag is set, the ISR may run immediately. Clear flags first.
