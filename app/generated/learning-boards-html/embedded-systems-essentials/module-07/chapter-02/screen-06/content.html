Module 07 › Chapter 7.2 › NVIC and Priority
NVIC concept
A hardware controller that enables, prioritizes, and allows nesting of up to many interrupt sources on Cortex-M devices.
Priority behavior
Lower numerical priority value indicates higher priority. A higher-priority interrupt can preempt a lower-priority ISR.
Nesting example
If an ISR for a sensor runs at priority 5 and an emergency stop at priority 1 fires, the emergency ISR interrupts the sensor ISR to handle the urgent event.
NVIC registers
EN, PRI and grouping
Write NVIC_EN0 to enable an interrupt number and NVIC_PRIx to set priority bits for that interrupt.
Pro tip
Plan priorities based on urgency; reserve the highest priorities for critical safety events to prevent missed deadlines.
