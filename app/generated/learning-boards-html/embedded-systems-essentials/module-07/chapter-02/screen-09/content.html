Module 07 › Chapter 7.2 › Vector Table & ISR Names
What the vector table does
It stores addresses for the reset handler and all exception and interrupt handlers. When an interrupt occurs the controller loads the address and branches to it.
ISR naming
The startup code or linker script often provides weak defaults. Define the expected name, for example GPIOF_Handler, to override the weak symbol and provide your ISR.
Concrete detail
Interrupt 30 maps to Port F. The vector table entry must point to GPIOF_Handler for the ISR to run when PF interrupts occur.
Quick check
What if the name is wrong?
The default handler runs or the system can fault; always confirm your handler matches the vector table entry.
