Module 07 › Chapter 7.2 › GPIO Interrupt Example
Key registers in the example
  • GPIO_PORTF_IS_R: selects edge or level sensitivity
  • GPIO_PORTF_IBE_R: enables both-edge triggers
  • GPIO_PORTF_IEV_R: selects rising or falling edge
  • GPIO_PORTF_IM_R: interrupt mask for pins
  • GPIO_PORTF_ICR_R: interrupt clear register
  • NVIC_EN0_R and NVIC_PRI7_R: NVIC enable and priority registers
// core of example (visual only)
volatile uint32_t switchCount = 0;

void GPIOF_Handler(void) {
    if (GPIO_PORTF_RIS_R & 0x10) {
        switchCount++;
        GPIO_PORTF_ICR_R |= 0x10; // clear PF4
    }
}

void GPIOF_InitInterrupt(void) {
    GPIO_PORTF_IM_R &= ~0x10; // disable before configure
    GPIO_PORTF_IS_R &= ~0x10; // edge-sensitive
    GPIO_PORTF_IBE_R &= ~0x10; // not both edges
    GPIO_PORTF_IEV_R &= ~0x10; // falling edge
    GPIO_PORTF_ICR_R |= 0x10;  // clear any prior flag
    GPIO_PORTF_IM_R |= 0x10;   // enable interrupt mask
    NVIC_EN0_R |= (1 << 30);   // enable in NVIC
    NVIC_PRI7_R = (NVIC_PRI7_R & 0xFF00FFFF) | 0x00A00000; // set priority
}
Explanation highlights
The ISR checks the raw interrupt status to confirm the cause, updates program state using a volatile variable, and clears the flag to avoid retriggering. The init sequence prevents spurious interrupts by clearing pending flags before enabling NVIC.
Pitfall
Failing to clear GPIO_PORTF_ICR_R causes the ISR to fire immediately in a loop.
