Module 07 › Chapter 7.2 › What is an Interrupt?
Definition
A hardware event that causes the CPU to pause execution and run a short handler immediately.
Sequence
  1. Interrupt signal asserted by peripheral
  2. CPU saves state and vectors to ISR
  3. ISR services event and clears flag
  4. CPU restores state and resumes
Concrete example
A falling-edge on PF4 sets GPIO flag; NVIC directs CPU to GPIOF_Handler which increments a volatile counter and clears GPIOICR.
Analogy
A fire alarm
The alarm interrupts normal activity and demands a short, urgent response; once handled and silenced, regular activities resume.
Key Takeaway

An ISR is a short, prioritized response routine; it must clear its flag and return quickly so other interrupts can be serviced.
