Module 7 › Chapter 6.2 › Find the Missing Arrow
Diagnostic steps
  1. List every input possible in the current state.
  2. For each input, define the intended next state.
  3. Simulate sequences and watch traces for unhandled inputs.
  4. Add transitions and test again on hardware or in simulation.
Example fix
Add: if (state == DISPENSING && ItemDispensed) state = IDLE; Also ensure the output logic closes the dispenser and updates the display.
Use the UART trace to confirm the ItemDispensed event and the subsequent state change in real tests.
