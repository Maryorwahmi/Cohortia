Module 7 › Chapter 6.2 › Pedestrian Override
Step-by-step flow
1. Detect
Read button or interrupt flag and debounce to avoid false triggers.
2. Prioritize
Treat the event as higher priority than the normal timer if safety requires it.
3. Transition
Set next state and reset the appropriate timer on entry.
Example: A pedestrian press during GREEN sets state to YELLOW and resets greenTimer. That ensures yellowTimer governs the duration until RED and WALK.
Checks
  • Debounce physical switches to avoid multiple transitions.
  • Document priority rules so that multiple inputs do not conflict.
  • Simulate late inputs to verify WALK still occurs.
Common mistake

Failing to reset timers on state entry can create unexpected short or long phases.
