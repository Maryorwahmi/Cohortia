Module 7 › Chapter 6.2 › State vs Output
State Logic
Decides next state using current state and inputs. No hardware toggles. Example: if credit >= price and ButtonPressed, nextState = DISPENSING.
Tests: run sequences of input events in software and assert expected state sequence.
Output Logic
Maps the current state to outputs that drive LEDs, motors, or displays. Example: if state == DISPENSING then OpenDispenser = true.
Benefit: you can run output logic only when hardware is attached, keeping the FSM portable.
