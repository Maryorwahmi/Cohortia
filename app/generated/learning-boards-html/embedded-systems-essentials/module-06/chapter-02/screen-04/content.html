Module 7 › Chapter 6.2 › Traffic Light Requirements
Essential elements
  • States: GREEN, YELLOW, RED, WALK with independent timers.
  • Inputs: pedestrian button, timer expiration, optional emergency sensor.
  • Behavior: pedestrian press forces transition toward YELLOW, then RED, then WALK.
  • Verification: UART prints state and input each cycle for debugging.
Key Takeaway

Safety and clear input priorities drive the FSM structure; define them before coding.

Concrete example
If the system is GREEN and the pedestrian button is pressed, set the next state to YELLOW and reset the green timer. Even if the timer was not yet expired, the override ensures pedestrians are served promptly.
Common mistake
Putting LED control into transition checks can hide side effects; centralize outputs so tests can simulate states without hardware toggles.
