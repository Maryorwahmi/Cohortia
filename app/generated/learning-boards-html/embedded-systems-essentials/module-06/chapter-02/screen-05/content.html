Module 7 › Chapter 6.2 › Traffic Light Code
Core snippet
typedef enum { GREEN, YELLOW, RED, WALK } TrafficLightState;

TrafficLightState state = GREEN;

void trafficLightFSM(uint8_t pedestrianButton, uint8_t timerExpired) {
    switch (state) {
        case GREEN:
            setGreenLED(); clearWalkLED();
            if (pedestrianButton || timerExpired) { state = YELLOW; }
            break;
        case YELLOW:
            setYellowLED(); clearWalkLED();
            if (timerExpired) { state = RED; }
            break;
        case RED:
            setRedLED();
            if (timerExpired) { state = WALK; }
            break;
        case WALK:
            setWalkLED();
            if (timerExpired) { state = GREEN; }
            break;
        default:
            state = GREEN; break;
    }
}
Example: press the pedestrian button while GREEN; the state sequence becomes YELLOW → RED → WALK regardless of green timer remaining.
Explanation bullets
  • The enum gives readable state names for clarity and debugging.
  • The FSM runs repeatedly, checking inputs and timers each cycle.
  • Reset timers when you change state so durations are consistent.
  • Separate state selection from output side-effects to ease simulation.
Misconception: Timers alone are not sufficient; external inputs must be allowed to pre-empt timers for safety.
