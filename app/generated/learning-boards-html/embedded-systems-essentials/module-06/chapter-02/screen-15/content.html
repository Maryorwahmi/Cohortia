UART Traces
Print state and input each cycle; include cycle counters for correlation.
Pin Documentation
Label every pin in code comments and keep a breadboard snapshot for repeatability.
Extend Safely
When adding states, preserve input priorities and verify with traces and tests.
Final takeaway

Design FSMs with safety, testability, and observability in mind — those three features make embedded systems reliable.
