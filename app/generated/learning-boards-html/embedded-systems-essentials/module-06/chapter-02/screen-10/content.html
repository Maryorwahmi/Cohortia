Module 7 › Chapter 6.2 › Line-Tracking Robot
Sensor mapping
  • Both white → MovingForward
  • Left black → TurningLeft
  • Right black → TurningRight
Example scenario: drifting right causes left sensor to see the line; the FSM immediately enters TurningLeft until the line recenters.
Implementation note
Make transitions immediate and keep motor control in the output mapper. Use trace logs to confirm sensor readings and the resulting state each cycle.
Misconception: Adding long delays between turns makes the robot less responsive; prefer short, frequent FSM cycles.
