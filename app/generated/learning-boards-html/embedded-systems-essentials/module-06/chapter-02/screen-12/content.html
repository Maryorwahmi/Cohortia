Module 7 › Chapter 6.2 › UART Trace
Trace snippet
void traceFSM(uint32_t state, uint32_t input) {
    UART0_SendString("State: ");
    UART0_SendNumber(state);
    UART0_SendString(", Input: ");
    UART0_SendNumber(input);
    UART0_SendString("\r\n");
}
Run this each FSM cycle. Read the terminal while pressing buttons or forcing sensors; the log shows the exact sequence of inputs and state changes.
Debug tips
  • Include a cycle counter to timestamp traces.
  • Gate traces by debug flag to avoid performance hits in release builds.
  • Compare traces with expected state sequences during tests.
