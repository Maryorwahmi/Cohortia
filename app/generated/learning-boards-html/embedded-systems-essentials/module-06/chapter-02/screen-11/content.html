Example pin mapping
// LEDs
GREEN_LED_PIN = P1_0;
RED_LED_PIN   = P1_1;
YELLOW = RED + GREEN;
// Pedestrian button
PED_BUTTON_PIN = P2_0;
// UART
UART_TX = P3_1; UART_RX = P3_0;
// IR sensors
LEFT_IR  = A0; RIGHT_IR = A1;
Label pins in code comments and keep a matching breadboard diagram for reproducibility.
Test checklist
  • Confirm UART prints at each FSM cycle.
  • Verify button is debounced and sensor thresholds are tuned.
  • Check LED behavior matches state machine outputs.
