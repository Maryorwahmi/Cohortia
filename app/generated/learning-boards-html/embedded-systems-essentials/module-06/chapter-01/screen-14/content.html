Diagram-First
Diagrams are executable specifications; each arrow should map to a test case.
Implement in C
Use an enum for states and a switch handler to map states to transition logic and outputs.
Summary
Keep FSMs simple and testable: diagram, implement, and verify each transition; choose Moore for clarity and Mealy for immediate, input-driven outputs.
