Summary Advantages & Pitfalls
Why choose FSMs and common errors to avoid
Structure yields maintainability when used correctly.
Advantages
  • Explicit behavioral specification.
  • Direct mapping to readable C code.
  • Easy to enumerate tests for each transition.
Common Pitfalls
  • Using states to capture timing leads to state explosion.
  • Scattered output updates make testing difficult.
  • Missing default case allows invalid states to persist.
Key Takeaway

FSMs are powerful for embedded control when states are meaningful, transitions are centralized, and tests exercise each arrow.
