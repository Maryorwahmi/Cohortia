Core Concept What is an FSM?
Definition and the four components
A precise vocabulary that makes embedded behavior predictable.
Quick definition

An FSM is a system that occupies one of a finite number of named states, reacts to inputs, and transitions between states while producing outputs.

States
Named conditions that represent modes of operation.
Inputs
Events or signals that can trigger transitions.
Transitions
Rules that move the machine from one state to another.
Outputs
Signals produced either by states or transitions, depending on style.
Explanation and example
  • Think of a traffic light: Green, Yellow, Red are states; the timer is an input that causes transitions.
  • Transitions are labeled by the triggering input, for example timer expires leads from Green to Yellow.
  • Outputs may be LED signals that show the current state or may be pulses emitted on transitions.
Example
Traffic light uses three states and a periodic timer input to cycle through them predictably.
Common mistake
Confusing a state name with an output. State is a mode; outputs are signals used to represent or act on that mode.
Key Takeaway

An FSM separates what mode the system is in from what events cause moves and what signals get produced, making behavior explicit.
