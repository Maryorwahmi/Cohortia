Process Flow
Quick scene setup
Create primitives, name them, and use them as placeholders to define collision and play space.
Step 1 — New 3D project
Open the engine and create a blank 3D project. Keep default settings and a simple scene for speed.
Step 2 — Ground & obstacles
Add a Plane for the ground and Cubes for walls or obstacles. These define movement constraints and collision.
Step 3 — Prefab repeated items
Convert repeated placeholders into prefabs so you can duplicate and reposition them easily during playtests.
Scene Diagram (placeholder view)
Example layout
A Plane with three Cubes arranged to form a corridor highlights movement feel and turning radius. Use this to test collision response and camera framing quickly.
Scenario
Place a Capsule at the corridor start and walk to the end to confirm spacing and movement speed.
Checks & tips
  • Name objects clearly so you can locate them in the Hierarchy.
  • Use scaling sparingly — keep sizes that make collisions obvious.
  • Duplicate obstacles as prefabs to iterate layout quickly.
Key Takeaway

Define the smallest scene that validates your single design question — no art required.
