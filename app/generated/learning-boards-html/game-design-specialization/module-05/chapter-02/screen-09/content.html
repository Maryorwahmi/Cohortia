Process
Build: Collect the Cube
A quick activity to validate movement and pickup behavior.
1. Project Setup
Create a 3D project, add a Plane named Ground, and place a few Cube obstacles.
2. Player
Add a Capsule, add Rigidbody, name it Player, and assign the Player tag.
3. Movement Script
Attach the PlayerMovement script and confirm movement in Play mode.
4. Collectible
Create a Cube, set Box Collider to Is Trigger, add CollectibleItem script, and duplicate it across the scene.
5. Playtest
Press Play, move the player to each collectible, and confirm Console logs and that objects are destroyed on collection.
Scenario card
Starter scene
Plane sized 20x20, three obstacles, Player at origin, three Collectible Cubes scattered within 10 units.
Debug tip
Use Debug.Log statements in OnTriggerEnter to confirm logic fires before adding UI or score systems.
Key Takeaway

Assemble the minimal loop: move, detect, respond. Iterate on spacing and speed until the loop feels testable.
