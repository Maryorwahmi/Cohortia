Learning Objectives
Practical skills to create a minimal prototype and validate a mechanic.
01
Project setup in an engine
Create a new 3D project and add primitives to define the test area quickly. This enables rapid iteration without asset work.
Mnemonic: timeline — new project → scene → test objects
VERIFIED COMPETENCY MILESTONE
02
Implement core GameObjects & components
Add a Capsule or Cube for the player and attach Rigidbody or Collider components as needed to test physics and interactions.
Mnemonic: Venn — object ∩ component = behavior
VERIFIED COMPETENCY MILESTONE
03
Write simple scripts for movement
Use smoothed input and Time.deltaTime to move the player consistently across frame rates while keeping code focused on a single mechanic.
Mnemonic: icons — input → normalize → apply
VERIFIED COMPETENCY MILESTONE
04
Maintain a clean project structure
Organize Scripts, Prefabs, and Materials into folders so you can iterate confidently and find code when you refactor or expand the prototype.
Mnemonic: folder icons — Scripts, Prefabs, Materials
VERIFIED COMPETENCY MILESTONE
