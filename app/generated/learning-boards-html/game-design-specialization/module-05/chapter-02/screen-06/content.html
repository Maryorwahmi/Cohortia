PlayerMovement.cs (starter)
Below is the minimal script used to move the player. Read it visually and note the Time.deltaTime usage and normalization.
<!-- PlayerMovement.cs -->
using UnityEngine;

public class PlayerMovement : MonoBehaviour
{
    public float moveSpeed = 5f; // Adjustable speed in the Inspector

    void Update()
    {
        // Get input for horizontal and vertical movement
        float horizontalInput = Input.GetAxis("Horizontal"); // A/D or Left/Right Arrow
        float verticalInput = Input.GetAxis("Vertical");   // W/S or Up/Down Arrow

        // Calculate movement direction based on input
        Vector3 movement = new Vector3(horizontalInput, 0f, verticalInput);

        // Normalize movement vector to prevent faster diagonal movement
        if (movement.magnitude > 1f)
        {
            movement.Normalize();
        }

        // Apply movement based on speed and time
        transform.position += movement * moveSpeed * Time.deltaTime;
    }
}
Explanation & example
What each part does
  • Input.GetAxis returns a smoothed control value for horizontal and vertical movement.
  • Normalization prevents diagonal movement from being faster than axis-aligned movement.
  • Multiplying by Time.deltaTime makes movement per second consistent, independent of frame rate.
Common misconception
Directly changing Transform may feel fine at first, but if you need physics interactions like forces or proper collision response, convert to Rigidbody-based movement later.
Key Takeaway

Keep movement logic short and frame-rate independent. Start simple and add physics when your mechanic requires it.
