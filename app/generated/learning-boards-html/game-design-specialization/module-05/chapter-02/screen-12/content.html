Process
Debug & Iterate
Small changes, short playtests, and explicit logs keep prototypes moving forward quickly.
Use Debug.Log
Print informative messages to confirm code paths before adding UI or scoring systems.
Iterate in small steps
Change one value at a time, then playtest to see the effect; this isolates cause and effect.
Example debug checklist
  • Does the Console show the expected Debug.Log when you collide with the collectible?
  • Is the Player tag assigned and matching the CompareTag used in scripts?
  • Is the collider set to Is Trigger if you expect trigger events?
Key Takeaway

Use logging and small, repeatable tests to find issues quickly and keep iteration rapid.
