Definition
Is Trigger
A collider property that switches the collider from a solid barrier to a detection volume that fires trigger events.
Typical usage
Collectibles, goal zones, or areas that should detect presence without stopping movement.
Starter code (visual)
<!-- CollectibleItem.cs -->
using UnityEngine;

public class CollectibleItem : MonoBehaviour
{
    void OnTriggerEnter(Collider other)
    {
        if (other.CompareTag("Player"))
        {
            Debug.Log("Player collected a " + gameObject.name + "!");
            Destroy(gameObject);
        }
    }
}
Common mistake
Not assigning the Player tag or forgetting to set the collider to Is Trigger will stop OnTriggerEnter from running as expected.
Key Takeaway

Use triggers for pickups and zones; ensure tags and collider properties are set correctly before testing.
