Definition
GameObject + Components
Small building blocks combine to give objects game behavior without complex class hierarchies.
GameObject
A container for components — can represent a player, enemy, prop, or camera.
Rigidbody
Enables physics simulation such as gravity and forces. Use when objects should move under physics.
Collider
Defines the collision shape. Can be a physical barrier or a trigger for events when Is Trigger is checked.
Concrete example
Player Composition
Capsule GameObject + Capsule Collider + Rigidbody + PlayerMovement script. Gravity and collisions handled by Rigidbody; movement handled by script.
Common Mistake
Adding components unnecessarily, or forgetting to set a Collider to Is Trigger for non-physical interactions, leads to unexpected blocking or missing events.
Key Takeaway

Use only the components you need. Think in small behaviors attached to a GameObject.
