Mistakes vs Pro Tips
A quick reference to avoid common prototyping pitfalls.
Mistake: Over-polishing
Spending time on visuals before validating the mechanic wastes iteration momentum.
Pro Tip: Use placeholders
Use primitives and quick scripts to answer the core question, then polish once validated.
Practical checklist
  • Keep one mechanic per script to simplify testing and reuse.
  • Tag the Player early and verify triggers with Debug.Log.
  • Make prefabs of repeated setups to speed scene building.
  • Change one parameter at a time during playtests.
Key Takeaway

Focus on fast validation. Keep code clean, tests deliberate, and polish for later stages.
