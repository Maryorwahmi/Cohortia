Process Flow
Tags & Layers
Apply labels for quick identification and grouping to control collisions and logic paths.
Tags
Lightweight identifiers used in code checks, for example CompareTag("Player").
Layers
Physics layers control the collision matrix, allowing you to disable collisions between groups to simplify interactions.
Concrete checklist
  • Tag the Player object explicitly before relying on CompareTag checks.
  • Use Layers to prevent unnecessary physics checks between groups.
  • Keep tag names consistent and documented in a small README inside the project.
Key Takeaway

Use tags for identity checks and layers for collision rules to keep interactions predictable and performant.
