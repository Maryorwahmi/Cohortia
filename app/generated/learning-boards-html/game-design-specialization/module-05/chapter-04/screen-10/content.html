Module 5 › Chapter 5.4 › Activity: Iterating on Jump Mechanics
Steps
  1. Form a hypothesis from playtest notes.
  2. Make one small change in PlayerMovement.cs and commit with a hypothesis message.
  3. Run 4–6 short playtests and collect same metrics as before.
  4. Compare outcomes and decide next action: keep, tweak, revert, or try another hypothesis.
Starter checklist
Label the build, record metrics, capture recordings or notes, and assign one owner to drive the next iteration.
Example observation
Observation: Players overshoot platforms. Hypothesis: increase gravity when falling. Change: set fallMultiplier to 2.5. Test: run 6 players through the same jump task and measure success rate.
Reflection prompt
After testing, ask: did objective metrics improve and did players report better control? If not, what next hypothesis will you try?
Safety tip
Use version control to create a branch for each experiment so you can compare and revert safely.
