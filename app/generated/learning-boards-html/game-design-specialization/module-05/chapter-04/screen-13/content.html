Module 5 › Chapter 5.4 › Playtest Design and Practical Tips
Before the test
  • Define the hypothesis and the metric you will track.
  • Create consistent tasks for each player.
  • Label builds and commit messages for traceability.
During the test
  • Observe silently and take time-stamped notes.
  • Record objective and subjective measurements.
  • Keep environments and tasks consistent across players.
After the test
Analyze patterns, prioritize by frequency and severity, create testable changes, and document outcomes. Use the same tasks in the next round so you can make fair comparisons.
