Module 5 › Chapter 5.4 › Common Iteration Mistakes and Pro Tips
Top mistakes
  • Making many changes between tests.
  • Treating one-off suggestions as priorities.
  • Not using version control or clear commit messages.
  • Iterating without acceptance criteria.
Pro tips
  • Change one thing and test it.
  • Label builds and include hypothesis in commit messages.
  • Prefer lightweight tests that reveal major problems fast.
  • Focus first on reducing friction before adding complexity.
Reflection prompt
After your next iteration, identify one metric that will confirm whether a change truly improved the experience. Use that metric to decide keep, tweak, or revert.
