Activity

Design a short feedback form

  1. Write two screening questions to confirm target audience.
  2. Create a pre-play open prompt revealing expectations.
  3. Add 3 Likert statements about controls, difficulty, and fun.
  4. Add 3 open-ended post-play questions for frustration, favorite moment, and suggested change.
  5. Plan a two-player pilot and note any unclear responses.
Observer aids
Add a short observer section with timestamped notes and a category picker (Bug / Usability / Balance / Fun) to speed later aggregation.
