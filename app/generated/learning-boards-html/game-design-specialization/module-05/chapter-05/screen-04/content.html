Module 6 › Chapter 5.5 › What is an MVP?
Core Concept

Minimum Viable Product (MVP)

A functional, minimal game built to validate the core promise and gather player learning quickly.

Definition

The simplest playable version that demonstrates the fundamental fun or mechanic.

Misconception

MVPs are not excuses for buggy builds — they must be stable and clear enough to produce reliable feedback.

Key Takeaway

Focus on one interaction that must work to prove the game; everything else is optional for the MVP.

Concrete Example
MOBA MVP

Two playable characters, one basic map, core combat loop to validate teamwork and combat feel.

Roguelike MVP

One character, basic movement, 1–2 abilities, simple enemy types, placeholder art to validate exploration and loot.

Checklist
  • Core loop playable
  • Minimal mechanics
  • Placeholder assets
  • Stable build for testing
Question to Ask

If you could only show one interaction to prove the game, which would it be and why?
