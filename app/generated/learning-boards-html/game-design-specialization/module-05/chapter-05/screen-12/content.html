Module 6 › Chapter 5.5 › Roguelike — define MVP
Activity

MVP Scope

Core Loop

Enter room → Fight monster → Get loot → Choose next room → Repeat

Player

One character, basic movement, 1–2 abilities

Enemies

1–2 basic enemy types with simple AI

Environment

One procedural room type with placeholder visuals

Loot

1–2 randomized item types with basic stats

UI & Goal

Basic health and ability UI; goal: survive 5 rooms

Key Takeaway

Keep content minimal but stable; instrument simple metrics such as percent reaching room three and ability usage to validate fun.

Check Your Plan

If you can’t state a single metric that proves the loop, the MVP is underspecified.
