Module 6 › Chapter 5.5 › Key Concepts
Minimum Viable Product (MVP)
The simplest playable version that validates core concepts and gathers learning.
Vertical Slice
A polished, representative cross-section showing final quality and integrated systems.
Core Gameplay Loop
The repeating player action and reward cycle that defines your game’s primary engagement.
Summary

Use MVPs to test, vertical slices to present. Always anchor scope to the core loop and pick one clear metric per milestone.
