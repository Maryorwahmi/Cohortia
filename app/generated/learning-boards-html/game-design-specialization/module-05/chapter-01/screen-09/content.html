Module 5 › Chapter 5.1 › Functional Prototypes
What they are
Narrow digital builds that validate a single mechanic or technology without a full game context.
Assessment Example
Bridge-building pathfinding
A functional prototype verifies units correctly create and use bridges and that pathfinding adapts to dynamic terrain.
Acceptance Criteria
Define measurable success up front, e.g., units cross bridges reliably under X conditions.
Misconception
Functional prototypes equal full features
They only prove a mechanism; they are not finished systems or polished content.
Key Takeaway

When the risk is technical, build a minimal program that demonstrates the mechanic works under expected conditions.
