Module 5 › Chapter 5.1 › Fail Fast Mindset
Four-step fail-fast loop
  1. Write the single question and acceptance criteria.
  2. Choose lowest-fidelity prototype that can answer it.
  3. Playtest, observe, and collect evidence.
  4. Iterate or discard based on results.
Example
Control scheme test
A short playtest reveals input friction in minutes, saving months of work if the scheme were implemented fully first.
Mindset Shift
Treat prototypes as data generators, not milestones of progress.
Common Pitfall
Equating failure with waste
A failed test is useful if it produces clear evidence and informs the next step.
Key Takeaway

Failing fast is intentional: build small tests to learn quickly and free resources for better ideas.
