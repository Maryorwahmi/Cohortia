Feedback Loops
Action → Response → Interpretation — make each step clear.
Sensory feedback
Visual flashes, sound cues, and haptics confirm actions instantly.
System feedback
Score updates, health bars, and UI messages provide measurable outcomes.
Narrative feedback
Story beats and character reactions reinforce significance of actions.
Example
When an attack hits: a unique sound, a visual hit flash, numeric feedback, and an update to enemy state together make the result unmistakable and teach timing or precision.
Common Mistake
Ambiguous feedback causes players to repeat actions blindly. Always test if players can explain why an outcome happened.
Pro Tip

Start with strong feedback during onboarding, then reduce cue strength as players learn the system to preserve challenge and satisfaction.

Check: can a new player state what they did differently that produced success? If not, clarify your feedback mapping.
