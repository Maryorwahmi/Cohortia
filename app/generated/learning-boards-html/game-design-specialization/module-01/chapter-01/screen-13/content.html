Module 1 › Chapter 1.1 › Assessment: Hiring
Advisory answer
Recommend hiring a game designer first to define the core loop and high-level systems. Once defined, hire developers to prototype and validate technical feasibility.
Reasoning: A clear design prevents developers from building features misaligned with the intended player experience, saving time and cost.
Example deliverable
A one-minute playable prototype that demonstrates the core loop and collects basic player feedback.
Key Takeaway

Design-first reduces wasted technical effort and clarifies hiring priorities for early-stage studios.
