Module 1 › Chapter 1.1 › Components of a Playable System
Rules
Define legal actions and constraints. Example: planting costs a resource and consumes a turn.
Systems
Mechanisms that change state: timers, spawn logic, scoring, and resource flow.
Narrative
Context and motivation that makes actions meaningful, like a chef’s story in a cooking game.
Player Interaction
Physical inputs and perceptual feedback: taps, drags, visuals, and sounds.
How to iterate
Test rules in isolation, simulate system responses, then add narrative and sensory feedback. This order reduces wasted effort and clarifies which layer needs change.
Practical exercise

Pick a single rule to test in a paper prototype. Observe whether it yields the behaviors you expect before coding or designing art.
