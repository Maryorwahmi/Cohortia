Module 1 › Chapter 1.1 › Common Pitfalls
Premature polish
Spending time on visuals before confirming the loop wastes resources if the gameplay fails.
Role confusion
Designers coding gameplay or developers deciding rules without design review can misalign goals.
Too many loops
Multiple competing loops dilute focus and complicate testing and iteration.
Quick check
Can you explain the core loop in one sentence and test it in under an hour? If not, simplify.
Fix

Trim scope, run short tests, and keep objectives focused on proving engagement.
