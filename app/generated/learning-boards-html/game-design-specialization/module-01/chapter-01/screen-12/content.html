Module 1 › Chapter 1.1 › Design a Core Loop
Activity steps
  1. Choose a theme: gardening, space, or cooking.
  2. Write the Player Action that will repeat regularly.
  3. Describe the System Response that changes game state.
  4. Specify Player Feedback that is immediate and noticeable.
  5. Define the New Action the feedback encourages.
Example: Gardening
Action: water plant. Response: progress meter increases. Feedback: sprout animation and chime. New action: water again or harvest when ready.
Misconception
Avoid adding many action types; start with one core action and one core reward.
Try this

Prototype your loop in a minute using a mockup or a simple script and watch how often you want to repeat the action.
