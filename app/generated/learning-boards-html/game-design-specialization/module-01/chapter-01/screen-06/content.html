Loop formula
Player Action → System Response → Player Feedback → New Action
Player Action: the meaningful input that starts the cycle.
System Response: rules that change game state in reaction to the action.
Player Feedback: immediate cues — visual, audio, or numeric — that inform the player.
New Action: the decision made using feedback, which restarts the loop.
Concrete example: Space scanner
Action: player scans a planet. Response: system reveals resources and hazard level. Feedback: UI meter shows resource value and hazard warnings. New Action: player chooses collect, retreat, or upgrade ship.
Pro-tip
Keep the loop tight; long or ambiguous feedback breaks momentum.
Misconception
More mechanics do not equal more fun—polish one engaging loop first.
