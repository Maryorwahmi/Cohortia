Module 1 › Chapter 1.1 › Designer vs Developer
Game Designer
Creates the blueprint: mechanics, feedback, and player motivation. Specifies why actions matter.
Game Developer
Builds the design using code, art, and sound. Focuses on feasibility, optimization, and polish.
Shared practice
Maintain a shared specification, iterate rapidly on prototypes, and prioritize testing the core loop before extensive art or polish.
Example: Orb Upgrade Loop
Designer: orbs grant temporary power if collected 3 within 20 seconds. Developer: implements orb spawn logic, collision detection, and UI counters to reflect that rule.
Practical tip

Designers should produce short, testable rules and welcome early technical feedback to keep goals achievable.
