Mechanics
Explicit rules, components and actions that implement the system.
Definition
Rules you code or write that constrain player choices.
Designer checklist
  • What input or action does this mechanic allow?
  • What player decisions does it enable or restrict?
  • What immediate feedback signals success or failure?
Common mistake
Adding mechanics without a clear intent often produces noise, not play.
Concrete example: Chess mechanics
Mechanics include piece movements, board size, and victory condition. These explicit rules form the complete space of legal moves.
Mechanic
Knight moves in an L-shape
Mechanic
Board is 8x8 squares
Mechanic
Capture removes a piece from the board
Mechanic
Checkmate ends the game
Key Takeaway

Mechanics define the possible actions and constraints. Design each mechanic with the player choices you want to encourage.
