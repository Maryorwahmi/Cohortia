Module 3 › Chapter 2.3 › Common Mistakes & Fixes
Mistake: Overwhelm
Too many effects at once. Fix: prioritize and reduce concurrent signals.
Mistake: Misleading signals
Signals that don't match game state. Fix: tie cues directly to confirmed state changes.
Mistake: Insufficient feedback
Players unsure whether input registered. Fix: add minimal confirmations for key actions.
Mistake: Repetition
Identical cues for different events. Fix: create a cue vocabulary with variation for categories.
Testing protocol
Run short playtests, observe player confusion points, and iterate on timing and intensity. Small adjustments often yield large clarity gains.
