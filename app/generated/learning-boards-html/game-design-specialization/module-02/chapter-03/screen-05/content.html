Module 3 › Chapter 2.3 › Visual Feedback Deep Dive
Definition
Visual cues that confirm and guide

Particles, UI updates, animations, and environmental changes draw attention and explain results. Use contrast and timing to set priorities.

Design tips
  • Share visual families for similar events.
  • Reserve dramatic visuals for high-consequence moments.
  • Make animations readable at gameplay speed.
Misleading visuals
Avoid animations that imply success when none occurred. Consistency builds trust.
Key Takeaway

Visuals must be clear, consistent, and proportionate; pair them with other channels for accessibility and clarity.

Examples & variations
Health & UI
Health bar color change, subtle bar shake and floating damage numbers show magnitude and timing.
Environmental
Lights dimming, doors glowing, or a path highlighting to guide discovery without explicit tutorial text.
