Module 3 › Chapter 2.3 › Positive vs Negative Feedback Loops
Comparison
Positive feedback
Rewards that make success easier. Example: kill streak weapons that let skilled players snowball.
Effect
Increases power over time; can reduce competitiveness if unchecked.
Negative feedback
Mechanics that help trailing players catch up. Example: rubber-banding in racing or health pickups when low.
Effect
Promotes balance and engagement across different skill levels.
Design considerations
  • Match loop choice to the desired experience: dominance or balance?
  • Monitor telemetry for snowball indicators and adjust strengths.
  • Use subtlety: obvious catch-up can feel artificial; hidden balancing preserves immersion.
