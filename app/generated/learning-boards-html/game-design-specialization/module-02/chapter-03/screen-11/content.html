Code-like Template
// Feedback Design for Knight vs. Dragon Encounter

// Player takes damage:
// Visual: Knight flashes red; damage numbers float up; enemy flinches.
// Auditory: sharp "oof" sound.
// Haptic: strong short rumble.

// Player lands a critical hit on Dragon:
// Visual: bright flash; larger damage number; unique crit animation.
// Auditory: distinct "CRITICAL HIT" sting.
// Haptic: sharp double-pulse vibration.

// Player picks up a health potion:
// Visual: potion icon glows; health bar increases.
// Auditory: gentle chime.
// Haptic: subtle low-frequency rumble.

// Common Mistakes:
// 1. Overwhelm: too many effects at once.
// 2. Misleading: sound when no hit occurred.
// 3. Repetitive: identical cues for all events.
Implementation notes
  • Assign unique audio signatures for pickups vs damage.
  • Test vibration patterns on target devices for comfort.
  • Keep critical-event signals reserved to maintain impact.
Key Takeaway
Use the template as an implementation checklist and iterate with players to tune clarity and emotion.
