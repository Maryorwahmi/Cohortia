Module 2 › Chapter 2.2 › Learning Objectives — Practice
Practice Tasks
Short, measurable tasks to validate each objective.
01 — Analyze

Create a device vs genre table. Milestone: justified choice for at least two genres.

02 — Design

Draft layout for core actions. Milestone: newcomer can perform basic actions in one minute.

03 — Implement

Write conceptual mapping including checks. Milestone: mapping prevents obvious unintended actions.

04 — Accessibility

Propose remapping or toggle-hold. Milestone: test scenario shows improved playability.

Assessment Ideas
  • Short playtest to confirm mappings feel intuitive.
  • Peer review of pseudo-code for missing checks.
  • Accessibility checklist: remap, toggle-hold, hitbox sizing.
Key Takeaway

Assessment should measure player experience improvements, not only technical correctness.
