Module 2 › Chapter 2.2 › Platformer Input Mapping
Pseudo-code (conceptual)
// Conceptual Input Mapping for a 2D Platformer

// Player Movement
If Input.GetKey("A") then
    Player.MoveLeft()
Else If Input.GetKey("D") then
    Player.MoveRight()
Else
    Player.StopHorizontalMovement()

// Player Jump
If Input.GetButtonDown("Spacebar") then
    If Player.IsGrounded() then
        Player.Jump()
    End If
End If
This code maps physical inputs to actions and includes an explicit else condition to stop motion, and a grounding check for jump to prevent double-jumps unless intended.
Explanation
  • Else branch prevents sticky movement by stopping horizontal velocity when no key is pressed.
  • IsGrounded guard prevents in-air jumps and preserves challenge.
  • Input.GetButtonDown semantics mean a single press triggers an action once.
Common Mistake
Not adding an else to stop movement or omitting the grounded check results in movement or jumping that feels broken.
Key Takeaway

Translate mapping into code with explicit conditions and stops; treat the pseudo-code as a design blueprint to adapt to your engine's input model.
