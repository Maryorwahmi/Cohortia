Rapid Test Process
  1. Prototype core actions only.
  2. Run short, focused playtests with tasks.
  3. Record input logs and brief video snippets.
  4. Change one control or feedback cue and retest.
What to measure
  • Task completion time
  • Number of incorrect input attempts
  • Instances of failed action without feedback
Example Task Sheet
Move to marker, collect resource, fire mining laser, deploy drone. Note times and whether player remaps keys mid-test.
Pro Tip

Observe first attempts before instructing; natural behavior reveals intuitive expectations about mappings.

Key Takeaway

Short, repeatable tests reveal mapping issues quickly; iterate on one change at a time to isolate effects.
