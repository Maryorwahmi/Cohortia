Module 2 › Chapter 2.2 › Common Mistakes
Typical Problems
Sticky Movement
Ensure an explicit stop command when no movement input is present.
Double-Jump
Use grounded checks to gate jump actions unless double-jump is intentional.
No Feedback
Show a small cue when an input is rejected so players understand why nothing happened.
Debugging Tips
  • Log input events with timestamps during playtests.
  • Record a short clip showing the player's input and the resulting game state.
  • Tune small buffers and measure perceived fairness in tests.
Example Fix
Add an else branch to stop horizontal movement, add IsGrounded gating for jump, and play a short 'thud' sound or flash when a jump fails.
