Module 2 › Chapter 2.2 › Responsiveness and Feedback
What makes controls feel responsive?
Low technical latency plus perceptual feedback like animation, sound, and UI cues.
Technical
Polling frequency, input buffering, and frame timing determine raw latency.
Perceptual
Animations, immediate sound, and small UI flashes signal input registration.
Design technique — Coyote time
Allow a tiny grace window after a player leaves ground to still accept a jump input. It increases fairness while preserving timing challenge.
Common Mistake

Relying only on successful-action feedback. Always provide a clear signal for failed inputs so players understand why nothing happened.

Concrete Example
When a jump is attempted but the player is not grounded, play a short 'thud' sound and flash a small icon. If the player is grounded, start the jump animation immediately and accept buffered jump inputs that occurred slightly before landing.
Key Takeaway

Design both the technical input path and the perceptual feedback; small forgiveness windows can improve player satisfaction without removing challenge.
