Module 2 › Chapter 2.2 › Accessibility Options
Practical Options
Make controls configurable and forgiving; small options increase playability for many users.
Key Remapping
Allow every action to be rebound and provide presets for common layouts.
Toggle-Hold
Offer a toggle mode for actions normally requiring continuous hold to reduce strain.
Single-button Mode
Map complex interactions to context-sensitive single inputs for accessibility.
Touch Hitboxes & Sensitivity
Increase target sizes and allow sensitivity/deadzone tuning for analog controls.
Example — Space Mining
Provide a remappable key for deploying the drone, an option to toggle laser fire, and an accessibility preset with larger UI targets for touch screens.
Key Takeaway

Accessibility features improve usability for many players; plan them early and test with real users when possible.
