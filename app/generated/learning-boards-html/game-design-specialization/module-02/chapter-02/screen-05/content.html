Device vs Genre Comparison
Quick comparisons to guide device selection.
Real-time Strategy
Mouse offers high selection precision; keyboard shortcuts speed hotkeys and commands. Gamepad is less efficient unless redesigned UI is provided.
Platformer
Gamepad and keyboard are typical. Timing and responsiveness are critical; ensure grounding checks and instant feedback for jump/action.
Puzzle / Point-and-Click
Mouse or touch for direct manipulation. Choose larger targets for touch and precise cursors for mouse.
Fighting / Action
Gamepad preferred for analog control and tactile feedback. Fast combos rely on consistent input responsiveness.
Example Scenario
An RTS moving to console might require cursor snapping, radial menus, or reworked targeting to compensate for the controller's limited precision.
Misconception
Assuming a device can be shoehorned into a genre without UI changes. If device lacks precision or feedback, change the interface, not only the input layer.
Key Takeaway

If a device reduces the player's ability to perform core actions reliably, redesign the UI or provide alternate input mappings.
