Design Steps
  1. List core actions and frequency.
  2. Prioritize most-used and safety-critical actions.
  3. Map to familiar inputs and ergonomic positions.
  4. Prototype and run a short playtest.
  5. Refine mappings and provide remapping options.
Pro Tip
Default to conventions; add advanced bindings but keep core actions simple and discoverable.
Concrete Example
2D Platformer core actions and initial mapping.
Core actions
  • Move left/right
  • Jump
  • Interact
Initial mapping
  • Move: A / D
  • Jump: Spacebar
  • Interact: E
Key Takeaway

Design iteratively: the first mapping is a hypothesis to be validated by playtests and refined for ergonomics and clarity.
