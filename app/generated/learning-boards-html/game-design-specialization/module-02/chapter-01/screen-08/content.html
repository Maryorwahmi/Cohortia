Four-step checklist
  1. Define the verb in one word.
  2. Sketch the minimal interaction sequence.
  3. Specify clear feedback for success and failure.
  4. Prototype only the interaction and test quickly.
Example: Scan
Target object → press scan → show data → resource gained or hint given.
Prototype tips
  • Keep UI minimal — use simple indicators to show success.
  • Measure whether players repeat the interaction voluntarily.
  • Log decisions that follow the interaction to see if it leads to meaningful choices.
Key Takeaway

Design to reveal the decision the player must make, then test if that decision is engaging.
