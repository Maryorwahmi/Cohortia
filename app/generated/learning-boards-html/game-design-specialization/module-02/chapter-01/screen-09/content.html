Named verbs
  • Scan — learn about objects and hazards
  • Collect — gather resources for survival
  • Move — traverse terrain and choose paths
  • Avoid — react to environmental danger
Loop
Move → Scan → Collect/Bypass → Avoid Hazards → Return/Continue
Prototype focus
Test each verb in isolation. For Scan, create a simple interaction where pointing and activating reveals meaningful data. See if players repeat scanning because it leads to interesting choices.
Misconception
Assuming the integrated game will reveal issues. Instead, problems show earlier when verbs are tested alone.
