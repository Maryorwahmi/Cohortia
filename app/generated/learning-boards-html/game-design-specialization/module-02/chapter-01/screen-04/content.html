Module 2 › Chapter 2.1 › What is a Core Mechanic?
Definition

A core mechanic is a focused set of repeated player actions that define moment-to-moment play and the game's immediate goals. These are the verbs players use to interact with the system.

Why it matters
  • Directs design and polish priorities so work focuses on what players do most.
  • Reduces ambiguity for the team by naming the essential interactions.
  • Makes prototypes faster because you prototype verbs, not complete systems.
Example
Super Mario: jump, run, stomp. These verbs alone steer level design and enemy patterns.
Concrete checks
  • Can the mechanic be described as a verb? If not, refine it.
  • Does it repeat frequently during play? If not, it may be secondary.
  • When isolated, does it still produce satisfying decisions? If not, revise.
Key Takeaway

Name a few verbs and test them alone; polish those before adding supporting features.
