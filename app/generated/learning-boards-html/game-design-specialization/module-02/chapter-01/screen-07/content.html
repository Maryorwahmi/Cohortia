Verb template
Verb: Scan
Target: Object with readable data
Input: Activate scanner / press button
Feedback: Data panel, sound, visual highlight
Follow-up: Decide whether to collect or ignore
Example
Robot game verbs: Scan, Collect, Move, Avoid — each leads to distinct choices and can be prototyped individually.
Practice prompt
Choose one verb from your idea and write the four fields above. Prototype only that interaction and observe whether players understand its purpose without extra systems.
Common misconception
Using broad verbs like 'interact' hides important differences between actions and slows prototyping.
