Module 2 › Chapter 2.1 › Assessing Core Mechanics
Sample question
Which action is MOST likely a core mechanic for a wizard exploring a dungeon? a) Crafting spell components, b) Trading artifacts, c) Casting spells to defeat enemies and obstacles, d) Decorating a tower. Correct answer: casting spells.
Reflection prompt
Write one paragraph explaining why you chose the three verbs you listed and how they produce a compact loop.
Playtest checklist
  • Can a player perform the loop repeatedly in a short session?
  • Does the loop produce meaningful decisions each iteration?
  • Would you drop any mechanic and still retain core play?
Key Takeaway

Assessment combines objective questions with short playtests to verify that the core is both necessary and engaging.
