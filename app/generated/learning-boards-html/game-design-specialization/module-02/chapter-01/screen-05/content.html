Module 2 › Chapter 2.1 › Core vs Secondary Mechanics
Comparison grid
Core Mechanics
  • Repeated frequently
  • Essential to loop
  • Polish increases fun
  • Examples: jump, shoot, solve
Secondary Mechanics
  • Enhance or decorate
  • Optional for play
  • Can be deferred to later
  • Examples: crafting, trading, cosmetics
Practical checks
  1. Isolation test: remove the system. Does the core experience survive?
  2. Frequency test: how often will a player use this action during play?
  3. Value test: does this mechanic change the primary decisions players make?
Common mistake
Confusing novelty with necessity leads to feature creep. Reserve flashy ideas for after the core is solid.
