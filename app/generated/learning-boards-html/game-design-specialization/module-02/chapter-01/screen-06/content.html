Module 2 › Chapter 2.1 › From Verbs to Loop
Step-by-step
  1. List the most frequent verbs (3–5).
  2. For each verb, define triggers and feedback.
  3. Chain verbs into a short repeating sequence.
  4. Prototype these steps and iterate rapidly.
Example loop (FPS)
Find enemy → Aim → Shoot → Reload → Find cover → Repeat
Practice card
Write a 4-step loop for one mechanic from your idea. Keep steps short and test whether repeating those steps produces decisions the player cares about.
Key Takeaway

A loop is not a long feature list; it is a compact cycle that feels satisfying every iteration.
