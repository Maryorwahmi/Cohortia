Module 2 › Chapter 2.1 › Feature Creep and Scope Control
Why it matters
Unchecked features delay releases and hide whether the core loop works. Focused development exposes problems early and keeps player experience coherent.
Pruning checklist
  • Does it increase repetition of the core? If no, defer.
  • Does it deepen decisions inside the loop? If marginal, defer.
  • Is it easy to prototype in a single day? If not, add to backlog.
Practical controls
  • Define an MVP strictly tied to core mechanics.
  • Timebox experiments and evaluate against the MVP.
  • Keep a deferred list for attractive but nonessential ideas.
Warning
Feature creep often feels productive. Measure impact on the core loop before committing resources.
