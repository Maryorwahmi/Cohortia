Core Concept

Let systems say the same thing as story

Start by naming the theme and then design one mechanic that repeatedly places the player in situations that express it.

Example: survival
Scavenging, crafting, and resource scarcity create decision tension that aligns with a desperate narrative.
Example: connection
Mechanic: deliver items across distances to reconnect settlements; mechanic reward reinforces theme of rebuilding.
Misconception
Complexity is not required. Clear stakes and consistent feedback make a mechanic expressive.
Mechanic design checklist
  • Does this mechanic create decisions that reflect the theme?
  • Can the player feel the theme in repeated interactions?
  • Does feedback clearly show why choices matter?
