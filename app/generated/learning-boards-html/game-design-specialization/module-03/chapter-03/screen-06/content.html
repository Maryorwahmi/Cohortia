Definition

What is a motivation?

A motivation is the core want that explains a character's actions and creates stakes for the player.

Design implications
  • Use it to design quest goals and plausible reactions.
  • Let it predict behavior so NPCs react consistently.
  • Keep it focused: one primary motive, one nuance.
Example
Primary: Protect hometown. Secondary nuance: Believes outsiders caused the collapse. This yields quests defending the town, suspicion of strangers, and scenes where the character must choose loyalty over justice.
Common mistake
Layering too many primary motives makes choices feel random. If you need complexity, make one motive primary and others conditional or revealed later.
Key Takeaway

Use a clearly stated motive to steer believable behavior and to create meaningful player choices.
