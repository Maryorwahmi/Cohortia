Bloom: Apply → Master
From objective to task
  • Sketch an archetype silhouette and add one twist that surprises expectations.
  • Write a one-sentence motivation and a two-sentence backstory that informs it.
  • Map three key arc beats: start, crisis, transformation.
These micro-tasks make evaluation fast: if a silhouette is indistinct, improve shape; if motive is vague, tighten stakes.
Concrete example
Design a reluctant hero: motivation—protect family; backstory—escaped conscription; arc—avoids leadership, forced to lead, accepts responsibility. Verified through three interactions that reveal doubt, courage, and decision.
Mnemonic: small experiments reveal whether the character's choices feel plausible in play.
Assessment link
Use a short checklist: archetype clarity, single-sentence motivation, one revealing backstory detail, consistent personality trait across three sample dialogues.
Key takeaway
Turn each learning objective into a concrete, testable artifact that can be iterated rapidly.
