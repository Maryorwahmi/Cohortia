Module 3 › Chapter 3.3 › Common Mistakes
Fixes
One-dimensional characters
Fix: add a single flaw and one contradictory but coherent trait to create depth without over-complication.
Contradictory behavior
Fix: ensure designer backstory explains shifts, and stage incidents that plausibly change behavior.
Info-dumping backstories
Fix: reveal through action, collectible memories, or short quests rather than blocks of text.
Indistinguishable NPCs
Fix: give each NPC a single distinguishing prop, gesture, or line to avoid a bland crowd.
Quick repair exercise
Pick one problematic character and apply one of the fixes above. Test by writing a single in-world interaction that demonstrates the change.
