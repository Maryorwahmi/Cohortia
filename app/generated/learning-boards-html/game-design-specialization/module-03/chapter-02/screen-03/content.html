Module 3 › Chapter 3.2 › Practice & Assessment
Practice Tasks
  • • Create a one-paragraph origin story and list its consequences for daily life.
  • • Define one resource scarcity and turn it into a craft/quest mechanic.
  • • Draft a magic or tech rule with a clear cost and a visible gameplay effect.
Each task is designed to be recorded in a compact world bible entry for future reference.
Assessment Ideas
Multiple-choice: identify which world aspect is being defined.
Rewrite exercise: convert a lore dump into environmental clues.
Peer review: spot inconsistencies in a short entry.
Use short, focused assessments to check whether the learner can both create and critique world elements.
