Module 3 › Chapter 3.2 › Common Pitfalls
Pitfalls to avoid
A short list with practical fixes.
Inconsistency — Fix: Keep a searchable world bible and log exceptions.
Lore dump — Fix: Drip-feed through optional notes and environment.
Generic tropes — Fix: Add a twist or combine unlikely elements.
No purpose — Fix: Ensure each element affects mechanics, story, or art.
Examples & Tests
Test: Ask an imagined curious player ten questions. If you can answer them coherently from discovered clues, consistency is good. If not, tighten rules or add explanation fragments.
Leave room for mystery
Keep some histories ambiguous; mystery encourages exploration and player-driven theory building.
Key Takeaway

Avoid big, untracked lore and prefer small, testable facts that create gameplay possibilities.
