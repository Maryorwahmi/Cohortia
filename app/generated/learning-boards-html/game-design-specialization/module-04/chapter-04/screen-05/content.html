Process
Object Placement & Arrangement
A 5-step process helps designers place objects so players reconstruct events naturally.
  1. Define the single beat you want the scene to show.
  2. Select 5 purposeful elements that support that beat.
  3. Order elements to imply action or sequence.
  4. Place along likely sightlines and movement paths.
  5. Prune anything that confuses or dilutes the message.
Key Takeaway

An ordered set of props that imply cause and effect creates narrative clarity without explicit text.

Annotated Example
Scene: The Last Stand
Overturned chair, spent cartridges, broken sword by skeleton, bloodstain trail to back door.
Narrative reading: defensive effort → running out of ammo → final retreat or death.
Common Mistake
Scatter many unrelated props and expect players to assemble a coherent story. Quantity without order breeds ambiguity.
Pro Tip
Pick one striking object as an emotional anchor. Place it where light or contrast draws attention; smaller props then add context around it.
