Core Concept
Definition
Level Design
The practice of shaping space and interaction to guide player learning, emotion, and choice.
Analogy: theatre set
Props and lighting direct attention, actors create action; the player reads the scene and acts within it.
Concrete example
A platformer tutorial that places a visible coin beyond a small gap to teach jumping without text instructions.
Common misconception
Visual richness does not equal clarity; too much detail can obscure the intended path.
Example scenario
Sketch a small room that teaches a mechanic: include one obstacle, one reward, and one visual cue that points to the solution. This enforces the idea that placement communicates purpose.
Key Takeaway

Every object in a level should communicate intent — teach, block, reward, or reveal.
