Module 4 › Chapter 4.3 › Blockout Workflow
Conceptual steps (copyable)
// Conceptual steps for creating a simple blockout
// 1. Create a new empty scene or level.
// 2. Add a large flat geometric primitive to serve as the ground (e.g., 20x1x20 units).
// 3. Add smaller primitives for walls, obstacles, and cover.
//    - Walls: tall thin cubes. Cover: low cubes or cylinders.
// 4. Use move/rotate/scale and extrude or subtractive brushes to shape doorways and platforms.
// 5. Apply simple unlit colors for function: Floor=Grey, Walls=White, Cover=Red, Elevated=Blue.
// 6. Test player movement immediately. Adjust one element, then re-test.
Keep changes atomic. Test after each change to isolate effects.
Practical example
Example: Add three red low-cube covers around a central arena and two blue elevated platforms with ramps. Ask: can the player reach each elevated position smoothly?
Observation checklist: jump success rate, time spent in cover, preferred routes, camera collisions.
Pro Tip

Color-code functions clearly so testers understand which parts are interactive without instructions.
