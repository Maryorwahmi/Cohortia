Learning Objectives
Skills you will practice and verify
Bloom: Learn → Understand → Apply → Master
01
Differentiate UX vs UI

Describe how UX covers the player's feelings and journey, while UI is the concrete visual and interactive elements that deliver that experience. Recognition of each helps diagnose design problems quickly.

VERIFIED COMPETENCY MILESTONE
02
Apply core UX principles

Use clarity, feedback, affordance, consistency and efficiency to evaluate interfaces and guide design decisions that reduce cognitive load and increase satisfaction.

VERIFIED COMPETENCY MILESTONE
03
Design intuitive screens

Create HUDs, menus and inventory layouts that prioritize essential information and support quick decisions without extra clicks or confusion.

VERIFIED COMPETENCY MILESTONE
04
Design for accessibility

Identify color, motor, hearing and visual accessibility needs and include options that let more players enjoy the game with minimal friction.

VERIFIED COMPETENCY MILESTONE
