Redesign a Game HUD — Activity
Prioritize, annotate, and justify your changes
Activity steps
  1. Choose a HUD screenshot or sketch a layout.
  2. Identify primary info required in typical play.
  3. Propose visible redesigns with feedback and accessibility notes.
  4. Annotate each change with the principle addressed.
Template item: Element, Original Problem, Redesign Change, Principle Addressed, Accessibility note.
Sample annotation
1. Element: Health bar. Original problem: Too small, blends into background. Redesign: Increase size, add high-contrast outline, add damage pulse. Principle: Clarity, Feedback. Accessibility: High-contrast option and larger font selectable.
Misconception: Bigger always better. Use size where it matters and avoid turning HUD into a visual barrier.
Key Takeaway

Documenting problems and principles forces better design. Use annotations to communicate why a change improves player experience.

Deliverable
An annotated HUD sketch and a short justification for each change tied to UX principles and accessibility options.
