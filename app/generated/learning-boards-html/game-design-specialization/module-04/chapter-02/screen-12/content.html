Key Concepts — What to remember
Six compact concept cards
User Experience (UX)
The player's holistic interaction and emotional response.
User Interface (UI)
Visual and interactive elements that enable action.
Affordance
Design that suggests how to interact with elements.
Feedback
Signals confirming actions or state changes.
Consistency
Predictable behavior and appearance across the game.
Accessibility
Design options that let more players enjoy the game.
Summary
Design interfaces that serve clear player goals, confirm actions reliably, and include accessibility options from the start to improve reach and satisfaction.
