Definition UX vs UI
UX vs UI — A clear distinction
Different roles, shared goals
User Experience (UX)

The player's overall feelings and success when interacting with your game: learnability, satisfaction, and emotional response over time.

Core idea: measured by task completion and player confidence.
Example: a smooth onboarding that teaches mechanics gradually and keeps players engaged.
Misconception: polish equals UX. A glossy UI can mask confusing flows that harm experience.
User Interface (UI)

The concrete on-screen elements players interact with: HUD bars, menus, icons, buttons and input affordances.

Core idea: makes actions discoverable and understandable.
Example: an inventory where equipable items show a distinct border and an obvious action label.
Misconception: UI is only visuals; it also encodes behavior and feedback timing.
Key Takeaway

Design UI to reduce uncertainty and support the UX you intend; evaluate both together.
