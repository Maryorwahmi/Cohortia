Affordance and Consistency
Make interactions obvious and predictable
Affordance examples
  • Glow or animation to suggest interactability.
  • Distinctive cursor or highlight on hover.
  • Clear labels and icons that imply function.
Analogy: a door handle suggests turning; a lever suggests pulling. Interface elements should do the same.
Consistency checklist
  • Standardize colors for states (enemy, friendly, interactive).
  • Keep confirm/cancel actions in the same positions.
  • Use the same iconography for repeated actions.
Misconception: Variety is interesting. In interaction design, variety can force re-learning and irritate players.
Key Takeaway

Design affordances that invite the right action and use consistent visual language so players carry knowledge from one context to the next.
