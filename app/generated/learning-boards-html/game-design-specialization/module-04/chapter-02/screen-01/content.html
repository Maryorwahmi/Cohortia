Orientation

This module focuses on making game interactions predictable, readable, and efficient so players can focus on play, not on deciphering controls. We'll pair principles with hands-on redesign practice so you can apply changes immediately.

Visual Concept
HUD
Compact, prioritized bars, clear numbers, quick feedback on damage.
Menu
Logical grouping, consistent confirm action, quick search or sort.
