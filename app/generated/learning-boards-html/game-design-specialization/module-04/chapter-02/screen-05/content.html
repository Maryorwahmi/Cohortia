Core UX Principles
Clarity, Feedback, Affordance, Consistency, Efficiency
Clarity: readable labels, contrast, hierarchy.
Feedback: visual, audio, or haptic confirmation of actions.
Affordance: elements suggest how to use them without instruction.
Consistency: same inputs and meanings across contexts.
Efficiency: minimal steps for common tasks; quick actions available.
Design Checklist
  • List core player goals and required info for each.
  • Choose feedback modalities for key actions.
  • Prototype affordances and test for discoverability.
Practical example
Imagine an ability button that appears greyed out when on cooldown. Clarity: the grey shows status; Feedback: a small radial timer shows time remaining; Affordance: the button has a pressed visual when ready; Consistency: same style for all abilities; Efficiency: hotkeys let players trigger without opening a menu.
Key Takeaway

Apply all principles together; prioritize clarity and feedback early in the design cycle.

Misconception
Minimal UI is desirable only if it preserves discoverability and feedback. Remove clutter, not clarity.
