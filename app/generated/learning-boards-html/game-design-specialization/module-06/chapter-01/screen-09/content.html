Module 6 › Chapter 6.1 › Git Workflow
Workflow steps
  1. Create a feature branch for your work.
  2. Make incremental changes and commit often with clear messages.
  3. Push the branch to remote and open a pull request for review.
  4. Resolve feedback, then merge into the main development branch.
Misconception: Don't wait to commit until the feature is perfect. Frequent commits are your safety net.
Example commands
git checkout -b new-feature-branch
# make changes
git add .
git commit -m "Implement basic crafting combine logic"
git push origin new-feature-branch
# open a pull request on your remote hosting service
Practice: run these commands in a sandbox repo and open a pull request. Read the diff in your review to understand changes before merging.
