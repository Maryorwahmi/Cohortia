Module 6 › Chapter 6.1 › Assessment Scenarios
Scenario 1 — Overwritten assets
Problem: Team members accidentally overwrite each other's files. Correct response: adopt a VCS, define branch rules, and train the team in commits, pushes, and pull requests.
Assessment question: Which practice most directly prevents overwritten work? (Answer: Version control system)
Scenario 2 — Critical bug mid-sprint
Problem: A core mechanic fails after testing. Correct response: triage the bug and add it to the backlog for prioritization. If it blocks sprint goals, swap tasks; otherwise schedule in the next sprint.
Assessment question: Should you stop the sprint immediately for every bug? No — only for bugs that block current sprint progress.
