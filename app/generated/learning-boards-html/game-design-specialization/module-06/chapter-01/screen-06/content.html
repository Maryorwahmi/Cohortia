Module 6 › Chapter 6.1 › Team Roles
Role hierarchy
Producer
Manages schedule, resources, and stakeholder expectations.
Lead Designer
Defines vision, writes user stories, and sets acceptance criteria.
Lead Programmer / Lead Artist
Coordinate technical and art implementation and lead their teams.
QA Lead
Defines test plans, finds regressions, and verifies fixes.
Concrete scenario: handling a new feature
  • Designer: writes the user story and acceptance criteria.
  • Producer: schedules the work into an upcoming sprint and allocates effort.
  • Programmer/Artist: break story into tasks, estimate, and implement.
  • QA: defines tests, reports bugs, and verifies fixes before marking Done.
Tip: Add an explicit owner field to each backlog item so responsibility is always visible.
