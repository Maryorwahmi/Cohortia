Common Design Specializations
Knowing these roles helps you decide which projects to prioritize.
Game Designer
Core gameplay, mechanics, and player experience.
Level Designer
Environment layout, pacing, and player navigation challenges.
Narrative Designer
Story, characters, and dialogue systems.
UI / UX Designer
Interfaces and user flows that make systems accessible.
Technical Designer
Scripting, tools, and bridging design with engineering.
Systems Designer
Economies, progression, and interlinked gameplay systems.
How to target a role
Select projects that demonstrate the skills required for the role, and use your resume and portfolio summary to state your focus clearly. Start generalist, then specialize through repeated project choices.
