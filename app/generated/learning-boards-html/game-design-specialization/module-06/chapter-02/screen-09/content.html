Module 6 › Chapter 6.2 › Severity & Priority
Severity (Technical Impact)
  • Blocker: prevents testing or play entirely.
  • Critical/Major: core mechanics broken.
  • Minor/Cosmetic: visual or small UI issues.
Example
Character falling through terrain is Major or Blocker depending on frequency and impact.
Priority (Business Urgency)
  • High: must be fixed before release or blocks critical testing.
  • Medium: schedule in normal sprint cycle.
  • Low: fix if time allows or in a later patch.
Common Mistake

Treating severity as the only criteria for scheduling causes misaligned priorities with production goals.
