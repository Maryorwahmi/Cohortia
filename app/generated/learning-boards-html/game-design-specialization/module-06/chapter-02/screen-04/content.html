Module 6 › Chapter 6.2 › What is QA?
Definition
Systematic process ensuring the game meets quality standards and design goals across development.
Why it matters
Catching issues early cuts fix time and keeps gameplay consistent with design intent.
Concrete example
Run a smoke test each build to verify the game launches, the main menu works, and core mechanics respond.
Common misconception
QA is not just late-stage bug hunting; it is integrated validation throughout development.
Core checks
  • Verify main game loop and core mechanics on each build.
  • Confirm save/load and basic UI interactions work as specified.
  • Log performance smoke checks: frame rate and memory spikes in simple scenes.
Key Takeaway

QA prevents costly rework and clarifies acceptance criteria when embedded throughout development.
