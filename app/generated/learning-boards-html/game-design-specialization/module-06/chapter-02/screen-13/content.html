Mini Test Plan Template
Feature: Double Jump Mechanic
Objective: Ensure the double jump functions correctly and resets on landing.
Scope: PC build 0.5.1, Keyboard input.
Test Cases:
  DJ-001: Verify basic double jump functionality.
  DJ-002: Verify double jump cannot be performed more than once.
  DJ-003: Verify double jump resets upon landing.
  DJ-004: Verify double jump works near ledges.
Regression: DJ-001 must be included in smoke tests before build promotion.
Example Step
DJ-001 Steps: Start game, select Character A, press jump, press jump again while airborne.
Common Pitfall
Not specifying build and input device leads to ambiguous reproduction during triage.
Key Takeaway

Turning a mechanic into clear test cases makes verification and regression reliable and fast.
