Elements of a Test Case
  • Test Case ID and short description.
  • Preconditions and setup steps.
  • Numbered actions to execute.
  • Expected result with observable outcome.
  • Environment: build, platform, input device.
Example
DJ-001: Verify basic double jump. Steps include starting a new game and pressing jump twice. Expected: second jump gains height.
Sample Test Case (formatted)
Test Case ID: DJ-001
Description: Verify basic double jump functionality.
Preconditions: Start a new game on flat surface; character selected.
Steps:
  1. Press the 'A' button to jump.
  2. While airborne, press the 'A' button again.
Expected Result: Character performs a second jump, gaining additional height, then lands normally.
Common Mistake

Vague steps like "jump twice" without preconditions prevent reliable reproduction.
