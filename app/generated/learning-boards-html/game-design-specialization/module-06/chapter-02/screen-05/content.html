Testing Types — Quick Comparison
Functional Testing
Verifies mechanics and systems behave as designed. Example: confirm double jump triggers a second airborne impulse.
Usability Testing
Observes players to find confusion or friction. Example: players cannot find the crafting tab.
Performance Testing
Measures frame rate and resource use under load. Example: lag spikes in crowded fights.
Other tests
Compatibility Testing
Ensures correct behavior across hardware and input devices.
Regression Testing
Re-tests fixes and existing features after changes to prevent regressions.
Localization Testing
Verifies translations and regional appropriateness of text and audio.
Common Mistake

Confusing usability complaints for performance issues delays the correct analysis. Choose the test by observed symptom.
