Practice and Assessment Checkpoints
Mini Test Plan: Double Jump
Create test cases covering normal, edge, and regression scenarios. Use DJ-001 to DJ-004 as starting test case IDs.
Bug Report Draft
Draft a bug report that includes title, severity, priority, steps to reproduce, expected and actual results, environment, and attachments.
Common Mistakes
Vague steps, missing environment, no attachments, and treating QA as a final step.
Assessment Idea
A short quiz asks you to classify testing types and to pick a correct bug report from two examples.
