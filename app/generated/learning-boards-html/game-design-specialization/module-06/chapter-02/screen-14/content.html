Drafting the Bug Report
Bug Title: Rapid double-press of jump on ground causes character to fall through floor
Severity: Major
Priority: High
Steps to Reproduce:
  1. Launch build 0.5.1 on PC with Keyboard input.
  2. Start new game and select Character A on a flat surface.
  3. Press 'Spacebar' twice rapidly while still on the ground.
Expected Result: Character performs a single jump then lands normally.
Actual Result: Character performs a single jump and then falls through the terrain into the void.
Environment: Build 0.5.1, PC, Keyboard input
Attachments: Video capture of reproduction, physics engine console logs
Why this helps
Precise steps and attachments let engineers reproduce physics timing and examine logs for race conditions.
Common Omission
Not including input timing or build number forces requests for follow-up and delays fixes.
Key Takeaway

Document the bug while reproducing it. Precise steps plus evidence reduce developer time to reproduce and fix.
