Module 6 › Chapter 6.4 › Accessibility
High-impact accessibility features
Choose features that address common barriers and include them early in design.
Color blindness modes
Adjust palettes and iconography so color is not the only cue.
Remappable controls
Allow players to customize input layouts for comfort and accessibility.
Subtitles & captions
Display dialogue and key audio cues as text with timing options.
Adjustable difficulty
Offer modes or assist options to match different skill levels.
UI scaling
Enable larger text and scalable UI to improve readability.
Input alternatives
Support multiple controllers and assistive devices where possible.
Key Takeaway

Accessibility expands your audience and should be planned early; small changes often unlock play for many users.
