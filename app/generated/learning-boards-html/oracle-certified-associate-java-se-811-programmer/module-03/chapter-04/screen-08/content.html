Module 4 › Chapter 3.4 › Constructor chaining
Steps
1. Call new Subclass(...)
2. Subclass constructor executes; first statement is super(...) or implicit super()
3. Superclass constructor runs and initializes parent state
4. Control returns to subclass constructor to finish initialization
Key Takeaway

Constructor chaining ensures the parent initializes before the child; explicit super(...) is required when no default parent constructor exists.

Concrete example
class Animal {
  private String name;
  public Animal(String name) { this.name = name; }
}

class Dog extends Animal {
  private String breed;
  public Dog(String name, String breed) {
    super(name); // required
    this.breed = breed;
  }
}
Common error

If you omit the explicit super(name) and Animal has no no-arg constructor, compilation fails because the implicit super() does not exist.
