Module 4 › Chapter 3.4 › Key Concepts
Inheritance
A mechanism where a subclass acquires fields and methods from a superclass.
Superclass (Parent)
The class that defines shared fields and methods used by subclasses.
Subclass (Child)
A class that extends a superclass and may add fields or methods.
Summary

These concepts form the foundation for shared behavior and polymorphism in object-oriented design.
