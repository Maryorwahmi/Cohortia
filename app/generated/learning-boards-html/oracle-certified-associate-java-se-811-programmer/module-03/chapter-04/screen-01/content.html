Inheritance Fundamentals

Learn how subclasses acquire behavior from superclasses, how to call parent constructors, and how to avoid common pitfalls.

In this lesson
Inheritance • extends • super • Constructor chaining
Why it matters

Shared behavior lives in one place. When Vehicle provides accelerate and brake, every subclass can reuse that code without duplication.

What you'll practice

Create subclasses with extends, call super(...) in constructors, and override methods while calling the parent implementation when needed.

Illustration

A small card cluster shows Vehicle as the parent with Car and Motorcycle as children. Each child reuses speed and brand, adding its own fields like numberOfDoors.

Vehicle{brand, speed} ↦ accelerate(), brake()
Car extends Vehicle {numberOfDoors, honk()}

Explore Key Topics
extends keyword

Declares that a class inherits from another. Example: class Car extends Vehicle.

super keyword

Calls the parent constructor or accesses the parent implementation when needed.

Constructor chaining

Constructors run up the inheritance chain so parent state is initialized before child-specific setup.
