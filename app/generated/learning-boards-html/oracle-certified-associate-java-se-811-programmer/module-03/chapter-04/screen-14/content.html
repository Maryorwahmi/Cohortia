Module 4 › Chapter 3.4 › Key Concepts
extends
Keyword used to declare a subclass relationship between classes.
super
Calls a superclass constructor or a superclass method implementation from a subclass.
Constructor chaining
The ordered execution of constructors up the inheritance hierarchy so parent state initializes first.
Final takeaway

Remember these rules and check parent constructors before subclassing; use super to preserve correct initialization and access parent behavior.
