Module 4 › Chapter 3.4 › What is inheritance?
Definition

Inheritance

Inheritance is a mechanism where one class acquires fields and methods from another, creating an is-a relationship and enabling reuse.

Benefit: Code Reusability

Write a method once in the superclass and reuse it in many subclasses.

Benefit: Extensibility

Add specialized behavior in subclasses without changing the shared parent.

Common misconception

Inheritance does not grant direct access to private fields; use getters or protected members instead.

Key Takeaway

Use inheritance when a clear is-a relationship exists and you want to share behavior across related classes.

Concrete example

Vehicle and Car

// Superclass
public class Vehicle {
  private String brand;
  private int speed;
  public void accelerate(int increment) { /* update speed */ }
}

// Subclass
public class Car extends Vehicle {
  private int numberOfDoors;
  public void honk() { /* Car-specific */ }
}
Analogy

Think of a superclass as a blueprint for shared features and a subclass as a specialized blueprint that adds its own parts.
