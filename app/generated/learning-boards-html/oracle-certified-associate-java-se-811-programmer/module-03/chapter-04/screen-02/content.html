Learning Objectives

Master the fundamentals of inheritance and super so your classes cooperate predictably.

Bloom
Learn → Understand → Apply → Master
01
Define inheritance

Explain inheritance as a mechanism where one class acquires fields and methods of another, forming an is-a relationship.

Mnemonic: Parent chain
VERIFIED COMPETENCY MILESTONE
02
Use extends

Write subclasses with the extends keyword and understand Java’s single-class inheritance rule.

Mnemonic: extends → extends chain
VERIFIED COMPETENCY MILESTONE
03
Understand inheritance of members

Recognize which fields and methods are inherited and how access modifiers affect direct access.

Mnemonic: Inherit, not expose
VERIFIED COMPETENCY MILESTONE
04
Call super correctly

Use super to invoke parent constructors and methods, and know why that call must often be the first statement in a constructor.

Mnemonic: super first
VERIFIED COMPETENCY MILESTONE
