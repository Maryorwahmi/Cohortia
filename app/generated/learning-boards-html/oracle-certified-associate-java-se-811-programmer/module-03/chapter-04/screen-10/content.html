Implementation hints
  • Call super(color, isFilled) as the first statement in Circle's constructor.
  • Calculate area with Math.PI * radius * radius.
  • Use super.displayInfo() inside overridden displayInfo to preserve base output.
Expected behavior

When you run DrawingApp, Shape.displayInfo should print color and filled status. Circle.displayInfo should first print the same info via super.displayInfo and then print radius and computed area.

Check your understanding

If Circle.displayInfo omits super.displayInfo, what shared information will be missing from the output?

Key Takeaway

Implement constructors and overrides so parent state is initialized and parent behavior can be reused via super.
