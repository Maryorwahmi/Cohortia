Module 4 › Chapter 3.4 › Using extends
Syntax

class Subclass extends Superclass

Extends creates a direct parent-child link. A class may extend only one other class in Java.

public class Vehicle {
  private String brand;
  public Vehicle(String brand) { this.brand = brand; }
}

public class Car extends Vehicle {
  public Car(String brand, int doors) {
    super(brand); // must be first
    // initialize doors
  }
}
Common mistake

Calling super(...) after other statements in the constructor causes a compile-time error.

Pro tip

If you need multiple behaviors, prefer interfaces rather than attempting multiple class inheritance.

Example in action

Creating a Car instance calls Vehicle's constructor to initialize brand, then runs Car-specific initialization for doors. The Car object then can call accelerate or getBrand without reimplementing those methods.

Scenario

Imagine you have many vehicle types; putting common behavior in Vehicle prevents repeating accelerate, brake, and brand logic in every subclass.

Key Takeaway

Use extends for clear is-a relationships and always match superclass constructors when needed.
