Usage

super(...) and super.method()

Super ensures inherited state is initialized and lets a subclass call the parent implementation when needed.

public class Vehicle {
  public Vehicle(String brand) { /* init */ }
  public void display() { System.out.println("Vehicle display"); }
}

public class Car extends Vehicle {
  public Car(String brand) {
    super(brand);
  }
  @Override
  public void display() {
    super.display(); // call parent behavior
    System.out.println("Car details");
  }
}
Misconception

super does not bypass access rules; private members of the parent remain inaccessible to the child.

Concrete example

When Car's constructor calls super(brand), Vehicle's constructor runs first to set brand. Later calls to super.display() let Car reuse the Vehicle display code and then add Car-specific output.

Pro tip

When overriding a method, call super.methodName() if you want to keep the parent's behavior and extend it, rather than replace it entirely.

Key Takeaway

Use super to initialize parent state and to combine parent and child behavior during overrides.
