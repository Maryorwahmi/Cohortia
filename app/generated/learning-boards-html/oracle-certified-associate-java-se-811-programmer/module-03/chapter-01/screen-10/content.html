Common Mistakes
Forgetting new
If you declare a reference without new, the reference points to nothing until you instantiate an object.
Error pattern
Product product1; product1.name = "Laptop"; // causes error until product1 = new Product();
Class vs Instance
Do not assign instance fields on the class
Instance fields live on objects. Changing a field on one instance does not alter other instances.
Quick check
If multiple objects show the same unexpected field value, check for accidental use of static fields or shared references instead of separate instances.
