Module 3 › Chapter 3.1 › Quick Reference
Fields
Instance variables that store state for each object created from the class.
new keyword
Creates a new instance in memory and returns its reference to assign to a variable.
Dot operator
Use it to access a specific object's fields and to invoke its methods.
Final Tip

When in doubt, write out the four-step pattern: declare, new, initialize, call. This habit prevents most beginner errors.
