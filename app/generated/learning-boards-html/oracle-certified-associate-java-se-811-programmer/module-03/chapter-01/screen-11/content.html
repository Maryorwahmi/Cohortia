Design the Book class
Implement fields and methods, then create objects in a Library main method to test behavior and edge cases.
  • • Fields: title, author, isbn, isBorrowed (boolean).
  • • displayBookInfo(): print title, author, isbn, and borrowed status.
  • • borrowBook(): set isBorrowed true only if currently false and print a message.
  • • returnBook(): set isBorrowed false only if currently true and print a message.
