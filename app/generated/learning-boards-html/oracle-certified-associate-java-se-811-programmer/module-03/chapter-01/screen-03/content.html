Practice Checks
Try these immediately after reading the lesson
Explain OOP (1 sentence)
State that objects bundle data and behavior so code maps to real-world entities, improving modularity and reuse.
Class vs Object (write two lines)
Declare a class and then create an instance with new. Example: declare Dog, then Dog myDog = new Dog();
Define a class (fields & methods)
Add fields like String name; int age; and a method header like public void bark() { ... }
Instantiate & Access
Create two objects, set different values, and call a method to show each object's behavior is independent.
Tip

Write and run the short Kennel main program to see output from different instances immediately.
