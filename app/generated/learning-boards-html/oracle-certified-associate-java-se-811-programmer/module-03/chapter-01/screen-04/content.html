Core Concept
What is OOP?
Objects bundle state and behavior so code models real-world entities in a modular way.
  • • Objects contain fields (data) and methods (behavior).
  • • Classes define the shape and actions; objects are the concrete instances.
  • • Java uses classes and objects to implement encapsulation and reuse.
  • • Modularity reduces accidental coupling and helps maintenance.
Takeaway
Think in terms of entities: design a class once and create multiple independent objects from it.
Analogy: Blueprint and House
The blueprint is the class. Each house built from it is an object with its own paint color and furniture.
Example scenario
A Dog class describes name and age. Two Dog objects hold different names and ages but share the same methods like bark().
Common mistake
Confusing a class with an object. You cannot set instance values on a class itself; values belong to objects created from the class.
