Comparison
myDog vs yourDog
Same class, different instance state.
Try setting different names and calling bark()
myDog
name = "Buddy"
bark() → prints "Buddy says Woof!"
yourDog
name = "Lucy"
bark() → prints "Lucy says Woof!"
Common pitfall
Assuming instance fields are shared across instances. They are not. Only static fields share values across the class.
