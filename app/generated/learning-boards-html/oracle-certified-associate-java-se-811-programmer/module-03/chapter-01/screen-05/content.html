Definition
What a class contains
Fields declare the data each object will carry. Methods define the actions any instance can perform.
  • • Fields (instance variables): per-object state like name and age.
  • • Methods: code that acts on an object's state or performs operations.
  • • Access modifiers control visibility; focus on public for now.
Key Takeaway
Fields store unique data per instance; methods provide behavior available to every instance defined by the class.
Concrete Example: Dog class
This example shows fields and methods placed inside a class body.
public class Dog {
    String name;
    String breed;
    int age;

    public void bark() {
        System.out.println(name + " says Woof!");
    }

    public void eat(String food) {
        System.out.println(name + " is eating " + food + ".");
    }
}
Misconception
Fields are not shared between separate objects unless declared static. Each object has its own copy of instance fields.
