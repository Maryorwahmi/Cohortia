Assessment Idea
Short checks
  • • Write the two lines to declare and instantiate a Product object and explain each line's purpose.
  • • Identify the error when fields are accessed on a reference that has not been instantiated.
  • • Predict output for two Dog instances calling the same method after different field assignments.
Example question
// Which two lines belong at Line A and Line B?
// Line A
// Line B
product1.name = "Laptop";
product1.price = 1200.00;
product1.displayDetails();
Correct answer is: declare the variable, then assign new Product(); explaining that new allocates the object.
