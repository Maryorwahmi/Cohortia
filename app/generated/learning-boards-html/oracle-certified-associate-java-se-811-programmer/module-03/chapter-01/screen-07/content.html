How to instantiate and use an object
Follow these four steps every time you create and use an object.
Common error: forgetting new
1. Declare
Dog myDog;
2. Instantiate
myDog = new Dog();
3. Initialize
myDog.name = "Buddy";
4. Call
myDog.bark();
Why each step matters
  • • Declaration creates a reference variable type-checked by the compiler.
  • • new actually creates the object in memory and returns its reference.
  • • Initialization sets the instance's fields so methods can rely on valid data.
  • • Calling methods runs behavior that uses the object's state.
