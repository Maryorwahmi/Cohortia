Definition
Methods and parameters
Methods operate on an instance's fields and can accept parameters to receive input.
  • • Methods are defined in the class and executed on instances.
  • • Parameters are local names for values passed in at call time.
  • • Methods can change an object's fields, affecting that instance's state.
Pro tip
Keep method responsibilities focused: a method should do one clear action on the object's data.
Code example
public void eat(String food) {
    System.out.println(name + " is eating " + food + ".");
}

// Called as:
myDog.eat("kibble");
yourDog.eat("treats");
Each call passes a different argument. The same method uses the calling object's name field to produce different printed lines.
Misconception
Passing a variable into a method does not silently change the caller's variable unless the method explicitly assigns to a field or returns a new value that you assign back.
