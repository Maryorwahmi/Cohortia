How basics connect to later topics
Fields and methods are the primitives for constructors, access control, and inheritance.
Constructors
Run during new to initialize fields.
Access control
public/private determine visibility and encapsulation safety.
Inheritance
Extend classes to reuse and specialize behavior.
Concrete link
When you later add a constructor, you will remove repetitive field assignments from main and centralize initialization. When you apply private to fields, you will expose controlled access via methods.
Takeaway
Master these basics now to make the next topics intuitive and practical.
