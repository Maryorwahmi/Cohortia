Module 3 › Chapter 3.3 › Method overloading
Definition

Same method name, different signatures

The compiler distinguishes overloaded methods by parameter number, types, and order. Return type and visibility are ignored for overload resolution.

Good use case
Offering print methods for different input types improves readability for callers who conceptually perform the same action.
Pitfall
Do not overload only by return type; the compiler will report a duplicate method signature.
Example
public class Printer {
    public void print(String text) { System.out.println("Printing String: " + text); }
    public void print(int number) { System.out.println("Printing int: " + number); }
    public void print(String text, int copies) { /* print multiple copies */ }
    // public int print(String message) { return 0; } // invalid: same parameter list, return type differs only
}
Key Takeaway

Design overloads so each signature is unambiguous and conceptually consistent with the operation name.
