Module 3 › Chapter 3.3 › Run & verify
Example run
// In CalculatorApp.main after implementing MathUtility
System.out.println("Sum int: " + MathUtility.add(5, 10));
System.out.println("Sum double: " + MathUtility.add(2.5, 4.0));
System.out.println("Sum three ints: " + MathUtility.add(1,2,3));
System.out.println("Product double: " + MathUtility.multiply(2.5, 4.0));
System.out.println("PI: " + MathUtility.PI);
System.out.println("Circle area r=5: " + MathUtility.getCircleArea(5.0));
Expected observations
  • Each call prints the correct numeric result matching the overload.
  • MathUtility.PI prints the constant without creating any object.
  • If a call is ambiguous, the compiler will report an error rather than choose unpredictably.
Debug tip
If you get unexpected overload selection, check the declared types of your variables and add explicit casts if necessary to make your intent clear.
