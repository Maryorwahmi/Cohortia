Module 3 › Chapter 3.3 › Key Concepts
static keyword
Declares class-level members that are shared and accessible via the class name.
Static context restriction
Static methods have no implicit this and cannot access instance members directly; pass an object when needed.
Method overloading
Multiple methods with the same name but different parameter lists; resolved at compile time.
Summary takeaway
Use static for shared class-level state or stateless helpers and design overloads to be clear and tested. Prefer instance methods and interfaces for polymorphism and testability.
