Module 3 › Chapter 3.3 › Static context restriction
Why it happens

Static methods may execute without any instances existing, so they have no implicit this reference and therefore cannot access instance fields or methods directly.

Fix patterns
Either make the data static, or pass an object into the static method and access instance members through that object reference.
Misconception
Static methods are not magical: they simply lack an associated instance and the this keyword.
Example Fix
// Illegal: static method cannot use instanceField directly
public class Example {
  private int instanceField = 5;

  public static void bad() {
    // System.out.println(instanceField); // compile error
  }

  public static void good(Example e) {
    System.out.println(e.instanceField); // okay with explicit object
  }
}
Key Takeaway

If a method has no this, it can't access per-object fields; pass an object or make the field static where appropriate.
