Module 3 › Chapter 3.3 › What does static mean?
Core Concept

Static: class-level ownership

A static member is stored once for the class and shared by all instances. Use static for data or behavior that does not belong to any single object.

Analogy
Instance fields are furniture in each room. Static fields are the building thermostat everyone shares.
Common misconception
Static ≠ immutable. Unless marked final, a static field can be changed and will affect all instances that read it.
Check your understanding
Would a per-object color property be static? No. Would a shared object count be static? Yes.
Example
public class Counter {
  public static int total = 0; // one shared copy

  public Counter() {
    total++; // updates the class-level count for everyone
  }
}
Key Takeaway

Static determines ownership and sharing; use it for single authoritative values and utilities.
