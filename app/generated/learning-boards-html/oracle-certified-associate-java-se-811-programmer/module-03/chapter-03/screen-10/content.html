Module 3 › Chapter 3.3 › Overloading vs Overriding
Overloading
Multiple methods with same name but different parameter lists in the same class. Resolved at compile time.
Example: print(String), print(int), print(String,int)
Overriding
Subclass provides a new implementation for a superclass method with the same signature. Resolved at runtime using the object's actual class.
Example: class FancyPrinter extends Printer { public void print(String s) { ... } }
Design guidance
  • Use overloads for convenience when operations are conceptually the same with different inputs.
  • Use overriding to change behavior for subclasses while preserving an API contract.
  • Avoid overloading to attempt polymorphism across types; prefer interfaces and overriding.
