Learning Objectives

Skills you will verify with short examples and code checks.

01
Static semantics
Describe what it means for a field or method to belong to the class rather than to an instance, and why that affects storage and access patterns.
Mnemonic: single shared tile in a foyer
VERIFIED COMPETENCY MILESTONE
02
Instance vs Class
Differentiate instance variables and methods from static ones and give situations for each, such as per-object state versus totals or constants.
Mnemonic: per-car paint versus global odometer
VERIFIED COMPETENCY MILESTONE
03
Static context rules
Explain why static methods cannot access instance fields directly and show a correct pattern using an object reference when instance data is required.
Mnemonic: no "this" without an object
VERIFIED COMPETENCY MILESTONE
04
Method overloading
Write overloaded methods with different parameter lists and demonstrate how the compiler chooses the appropriate one based on arguments. Understand what does not count toward overloading, such as return type alone.
Mnemonic: same name, different signature
VERIFIED COMPETENCY MILESTONE
