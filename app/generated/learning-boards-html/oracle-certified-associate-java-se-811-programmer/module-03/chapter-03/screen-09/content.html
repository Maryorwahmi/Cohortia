Module 3 › Chapter 3.3 › Overload resolution
Selection steps
  1. Filter methods by name and parameter count.
  2. Check parameter types for compatibility and apply widening conversions when needed.
  3. If multiple candidates remain, choose the most specific match.
  4. If still ambiguous, compiler reports an error.
Runtime vs Compile-time
Overload selection uses compile-time types. The actual runtime class of an object does not change which overloaded method was selected at compile time.
Example
Printer p = new Printer();
p.print("Hi");    // matches print(String)
p.print(10);      // matches print(int)

Object x = "text";
p.print(x);       // matches print(Object) if defined; resolution uses declared type Object
Tip
Prefer non-overlapping parameter lists to reduce ambiguous calls when types can be converted.
