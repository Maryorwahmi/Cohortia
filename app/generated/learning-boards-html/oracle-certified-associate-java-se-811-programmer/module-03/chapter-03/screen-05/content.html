Module 3 › Chapter 3.3 › Robot counter
Code
public class Robot {
    private static int robotCount = 0; // static field: shared
    private String name;
    private int id;

    public Robot(String name) {
        this.name = name;
        this.id = ++robotCount; // update shared counter
        System.out.println("Robot " + this.name + " (ID: " + this.id + ") created. Total robots: " + robotCount);
    }

    public static int getRobotCount() {
        return robotCount; // static method reads static field
    }
}

public class RobotFactory {
    public static void main(String[] args) {
        Robot r1 = new Robot("Optimus");
        Robot r2 = new Robot("Bumblebee");
        System.out.println("Total: " + Robot.getRobotCount());
    }
}
Explanation
  • robotCount is allocated once for the class and shared by all Robot instances.
  • The constructor increments the shared value, giving each Robot a unique id from the counter.
  • Static methods like getRobotCount() access static fields directly.
Analogy & Takeaway
Think of robotCount as a single scoreboard everyone updates. If you need a total across objects, a static field is the right place.
Common mistake
Accessing static state through an instance name is legal but misleading; prefer the class name for clarity.
