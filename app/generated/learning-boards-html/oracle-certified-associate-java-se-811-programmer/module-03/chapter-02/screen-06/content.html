Dog class walkthrough
How custom constructors set up useful objects and avoid duplication.
public class Dog {
  String name;
  String breed;
  int age;

  public Dog(String name, String breed, int age) {
    this.name = name;
    this.breed = breed;
    this.age = age;
    System.out.println("A new dog named " + name + " has joined the pack!");
  }

  public Dog(String name, String breed) {
    this(name, breed, 0);
    System.out.println("A puppy named " + name + " (age unknown) has joined the pack!");
  }
}
Explanation
  • this.name refers to the instance variable; name alone refers to the parameter.
  • Constructor overloading gives callers different creation choices.
  • this(...) chains constructors to avoid repeating assignments.
  • this(...) must be the first statement in the calling constructor.
Key Takeaway

Use constructor chaining so all initialization funnels through a single canonical constructor.
