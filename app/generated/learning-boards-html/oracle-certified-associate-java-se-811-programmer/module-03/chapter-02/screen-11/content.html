Accessor and mutator pattern
Example with validation in setAge.
public class Dog {
  private String name;
  private int age;

  public Dog(String name, int age) {
    this.name = name;
    setAge(age); // use setter for validation
  }

  public int getAge() { return age; }

  public void setAge(int age) {
    if (age >= 0 && age <= 30) {
      this.age = age;
    } else {
      System.err.println("Invalid age provided: " + age + ". Age must be between 0 and 30.");
    }
  }
}
Notes
  • Setters centralize validation logic and side effects like logging.
  • Consider omitting setters for fields that should be immutable after construction.
  • Avoid calling overridden methods from constructors as subclass state may be incomplete.
Pro tip

Keep validation centralized: prefer calling setX from constructors rather than duplicating logic.
