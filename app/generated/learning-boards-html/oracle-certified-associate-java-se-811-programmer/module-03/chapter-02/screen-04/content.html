Constructor definition
A concise claim and why it matters.

Constructors have the same name as the class and no return type. Java invokes a constructor automatically when new is used. Their main job is initialization: set instance variables so the object behaves predictably.

Never assume other code will set required fields. Use constructors to enforce minimal valid state and reduce runtime errors caused by null or default values.

Misconception check: adding a method with the class name and a void return type is not a constructor; it's a normal method and will not be called during object creation.

Key Takeaway

Constructors form the single reliable place to set required initial values for an object.

Concrete example
// Car.java
public class Car {
  String make;
  String model;

  public Car(String make, String model) {
    this.make = make;
    this.model = model;
  }
}
This constructor guarantees every Car has make and model immediately after new Car(...).
