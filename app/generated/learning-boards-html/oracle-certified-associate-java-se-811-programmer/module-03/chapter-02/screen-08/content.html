Module 3 › Chapter 3.2 › this keyword uses
this.field (disambiguation)
When parameters shadow fields, use this to refer to the field.
public class Person {
  private String name;

  public Person(String name) {
    this.name = name; // assigns field, not parameter
  }
}
Without this the assignment would target the parameter and the field would stay null.
this(...) (constructor chaining)
Call another constructor to reuse initialization logic.
public class Book {
  private String title;
  private String author;
  private boolean isBorrowed;

  public Book(String title, String author, boolean isBorrowed) {
    this.title = title;
    this.author = author;
    this.isBorrowed = isBorrowed;
  }

  public Book(String title, String author) {
    this(title, author, false);
  }
}
this(...) must be the first statement in the constructor that uses it.
