Code Walkthrough

Vehicle and Car example

<!-- Vehicle.java -->
class Vehicle {
  String brand;
  int speed;

  public Vehicle(String brand) {
    this.brand = brand;
    this.speed = 0;
    System.out.println("Vehicle constructor called for " + brand);
  }

  public void start() {
    System.out.println(brand + " is starting.");
  }

  public void accelerate(int increment) {
    speed += increment;
    System.out.println(brand + " accelerating. Current speed: " + speed + " mph.");
  }
}

<!-- Car.java -->
class Car extends Vehicle {
  int numberOfDoors;

  public Car(String brand, int doors) {
    super(brand); // call to superclass constructor
    this.numberOfDoors = doors;
  }

  public void honk() {
    System.out.println("Beep beep!");
  }
}
• Car extends Vehicle so Car instances have brand, speed, start and accelerate available.
• The Car constructor calls super(brand) to initialize the Vehicle state.
• If Vehicle had no no-argument constructor, omitting super(...) in Car causes a compile error.
Practical notes

Remember that extends changes type relationships. A method accepting a Vehicle can accept a Car because Car is a Vehicle.

Common mistake

Forgetting to call a required superclass constructor is a frequent compile-time error when the superclass lacks a no-argument constructor.

Check your understanding

Try creating Vehicle with only a parameterized constructor, then make a Car and see the compiler message if you omit super(...).
