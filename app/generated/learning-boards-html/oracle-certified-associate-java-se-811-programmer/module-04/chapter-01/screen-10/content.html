Module 4 › Chapter 4.1 › Using super.method() from an Overridden Method
Code Walkthrough

Extend, don't replace

class Vehicle {
  public void start() {
    System.out.println(brand + " is starting.");
    // common initialization
  }
}

class Car extends Vehicle {
  @Override
  public void start() {
    super.start(); // run Vehicle startup logic
    System.out.println("Car " + brand + " is starting with a key.");
    // Car-specific startup
  }
}
• super.start() calls the immediate superclass implementation, preserving shared setup.
• Use this when subclass needs to add steps without duplicating superclass code.
Why it matters

It keeps initialization logic centralized while letting subclasses adapt behavior safely.

Misconception

super.method() calls the superclass version directly. It does not trigger dynamic dispatch to overridden methods further up the hierarchy in unexpected ways.
