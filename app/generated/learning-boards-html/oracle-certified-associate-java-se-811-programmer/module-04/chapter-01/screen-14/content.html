MCQ example

Signature must match

A correct test question focuses on whether the overriding method retains the exact method name and parameter list; a mismatch leads to overloading or a compile error if @Override is present.

Code reading

Practice with the Animal/Dog example: observe constructor output and the overridden makeSound() output to confirm the runtime uses the Dog implementation.

Guided exercise

Write a short snippet with a superclass private method and a subclass method with the same signature. Predict whether it is overriding or a new method; compile and observe the result to reinforce the concept.
