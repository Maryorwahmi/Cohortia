Module 4 › Chapter 4.1 › The @Override Annotation
Definition

Let the compiler check your intent

@Override is a signal to the compiler that you intend to override a superclass method. If the signatures don't match, compilation fails so you can fix it immediately.

class Vehicle {
  public void start() {}
}

class Car extends Vehicle {
  @Override
  public void start() {
    // correct override
  }

  // Mistake: different parameters -> compiler flags if @Override is present
  // @Override
  // public void start(int delay) { }
}
Why it matters

It prevents accidental overloading when you intended overriding, and it aids safe refactoring of superclass methods.

Misconception

@Override does not alter runtime dispatch; it only performs compile-time verification of your signature intent.
