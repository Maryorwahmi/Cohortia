Mistake

Missing super()

If the superclass defines only parameterized constructors, the subclass must call one explicitly as the first statement.

Mistake

Unintended overloading

Changing parameters when aiming to override creates a new method. Use @Override to detect this mistake early.

Mistake

Overexposing fields

Making fields protected ties subclasses to implementation. Prefer accessor methods for safer evolution.

Debugging tip

Reproduce the problem in a minimal example, read compiler errors for missing constructors or signature mismatches, and add @Override to validate intended overrides.
