Module 4 › Chapter 4.1 › Key Concepts
Inheritance
A class acquires properties and behaviors from another class.
extends keyword
Declares that a class is a subclass of another, enabling reuse of non-private members.
Superclass / Subclass
The parent provides shared behavior; the child specializes or overrides as needed.
Takeaway

Model true subtype relationships and centralize shared logic in superclasses to keep designs maintainable.
