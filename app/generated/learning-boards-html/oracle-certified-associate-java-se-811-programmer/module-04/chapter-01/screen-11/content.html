Module 4 › Chapter 4.1 › Access Modifiers in Inheritance
Definition

Modifiers and their reach

• public: accessible to all classes, including subclasses.
• protected: accessible to subclasses across packages and within the same package.
• package-private: accessible only inside the same package.
• private: inaccessible directly to subclasses; access via public/protected methods only.
Design tip

Prefer methods that encapsulate state changes rather than exposing fields directly to subclasses. This keeps the superclass free to change implementation details later.

Concrete scenario

Vehicle exposes protected speed so subclasses can adjust it. The engineSerial stays private and is exposed via a public getter if needed.

Misconception

Protected is not a global access flag—it's targeted to subclasses and same-package classes only.
