Module 4 › Chapter 4.1 › Calling super() in Constructors
Step-by-step

Constructor chaining rules

1) If you write super(...), it must be the first statement in the subclass constructor.
2) If you omit it, Java inserts a no-argument super() automatically.
3) If the superclass has only parameterized constructors, you must explicitly call one from the subclass.
class Vehicle {
  public Vehicle(String brand) { /* ... */ }
}

class Car extends Vehicle {
  public Car(String brand, int doors) {
    super(brand); // required: superclass has no no-arg constructor
    this.numberOfDoors = doors;
  }
}
Common error

Omitting the required super(...) when the superclass lacks a default constructor triggers a compile-time error. Fix by adding the explicit call.

Check your understanding

Try removing super(...) from a subclass whose superclass only has parameterized constructors and observe the compiler message. Adjust constructors accordingly.
