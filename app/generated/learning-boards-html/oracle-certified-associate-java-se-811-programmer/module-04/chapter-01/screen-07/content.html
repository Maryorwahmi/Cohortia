Module 4 › Chapter 4.1 › Method Overriding vs Method Overloading
Comparison

Same name, different meaning

• Overriding: same signature in subclass; changes behavior; supports polymorphism.
• Overloading: same name, different parameters; multiple method forms in the same class or hierarchy.
• Use @Override to ensure you are overriding, not unintentionally overloading.
Example

Vehicle: public void start(); Car: @Override public void start() — this is overriding. Car: public void start(String mode) — this is overloading.

Misconception

Changing parameters when you intended to override prevents polymorphic behavior and can hide bugs. Rely on @Override to avoid this mistake.

Check

Look at a pair of methods with the same name. Ask: are their parameter lists identical? If yes and they are in superclass/subclass, this is overriding.
