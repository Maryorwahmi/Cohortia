Module 04 › Chapter 4.2 › Quick Checklist
Program to behavior
Accept interfaces or superclasses that expose the methods callers need.
Prefer overriding
Let subclasses override to provide specific behavior instead of switching on type.
Guard casts
Use instanceof before downcasting; frequent casts suggest a refactor.
Final Thought

Polymorphism is a tool for clean, extensible code. Use it to express behavior, not to hide type assumptions.
