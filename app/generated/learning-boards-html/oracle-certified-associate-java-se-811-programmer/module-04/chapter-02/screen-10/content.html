Problem
ClassCastException example
Vehicle v = new Motorcycle();
Car c = (Car) v; // ClassCastException at runtime
Why: v refers to a Motorcycle, not a Car. The JVM rejects the invalid cast.
How to prevent
  • Check with instanceof before casting.
  • Prefer adding needed behavior to the common type or interface.
  • Consider polymorphic design patterns if casting occurs often.
Quick fix
Use instanceof or restructure code to avoid the cast entirely.
