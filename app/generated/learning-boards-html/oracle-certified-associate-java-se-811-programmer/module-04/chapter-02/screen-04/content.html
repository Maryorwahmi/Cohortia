Core Concept
Polymorphism defined
A single reference type can point to objects of several concrete classes, enabling behavior selection at runtime.
Analogy: Power outlet
One outlet (reference) powers many devices (objects); each device acts differently when powered (method implementations).
Example
Vehicle v = new Car(); v.service() calls the Car implementation at runtime.
Common mistake
Believing the reference type decides which overriding method runs; it does not.
Key Takeaway

Polymorphism separates what you can call (reference) from what actually runs (object), enabling extensible code.

Visual: Reference vs Object
Reference type
Vehicle v
Visible methods: service(), toString(), etc. (those declared in Vehicle)
Object type
new Car()
Actual implementation chosen by JVM when service() is called.
Try to design methods to accept the common type so they automatically benefit from new subclasses.
