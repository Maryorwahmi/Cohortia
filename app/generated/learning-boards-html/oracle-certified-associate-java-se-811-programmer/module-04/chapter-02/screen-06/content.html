Process Flow
Upcast & Dispatch Steps
1. Create subclass object
new Car() constructs a Car instance with Car behavior.
2. Upcast to superclass
Assign to Vehicle v = new Car(); Reference now limits visible methods.
3. Call the method
Invoke v.service(); the JVM inspects the object type and selects the correct implementation.
Misconception: The compiler chooses the implementation. It only checks method visibility. The JVM selects the implementation at runtime.
Concrete Example
Vehicle v1 = new Car();
Vehicle v2 = new Motorcycle();
v1.service(); // Car's service runs
v2.service(); // Motorcycle's service runs
Key Takeaway

Upcasting lets code be generic; dynamic dispatch ensures the concrete behavior executes for each object.
