Definition
Downcasting with instanceof
Vehicle myVehicle = new Car();
if (myVehicle instanceof Car) {
  Car myCar = (Car) myVehicle;
  myCar.wash();
} else {
  System.out.println("Not a Car object, cannot wash.");
}
Explanation & Pitfalls
  • instanceof checks an object's runtime type safely before a downcast.
  • Attempting a cast without checking can throw ClassCastException if the object is not the expected subclass.
  • Pattern matching for instanceof (modern Java) can both check and bind the variable in one step.
  • If you use downcasting frequently, reconsider your design: add behavior to the common type if appropriate.
Common mistake
Relying on casts frequently hides fragile type assumptions; prefer behavior-driven APIs when possible.
