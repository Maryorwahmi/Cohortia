Polymorphism: Many Forms, One Interface
Understand how references and objects interact so your code can operate on many concrete types through a single interface.
In this lesson
You will see why the JVM chooses an overriding method at runtime, how upcasting and downcasting work, and how to use instanceof to avoid runtime errors.
Polymorphic trio
Reference, Object, JVM dispatch
Reference
Declares what methods are visible.
Object
Provides the actual implementation used at runtime.
Dynamic method dispatch: the JVM looks at the object's real type to choose the overriding method.

Upcasting
Why storing a subclass in a superclass reference is safe and useful.
Downcasting
When you need subclass-only behavior and how instanceof prevents errors.
Collections
Process mixed objects via a common type for cleaner, extensible code.
