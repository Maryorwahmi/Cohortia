Comparison
Compile-time (Overloading)
Compiler chooses which method to call based on signatures. Runtime type is irrelevant.
class Logger {
  void log(String s) { /* ... */ }
  void log(String s, int level) { /* ... */ }
}
// Compiler picks which log method based on arguments
Misconception: Overloads change because of object type. They do not.
Comparison
Runtime (Overriding)
JVM chooses the implementation based on the actual object's class at runtime.
class Vehicle { void service() { System.out.println("Generic"); } }
class Car extends Vehicle { @Override void service(){ System.out.println("Car specific"); } }
Vehicle v = new Car();
v.service(); // Car specific printed at runtime
Tip: Use overriding for behavior extensibility across subclasses.
