Pattern
Polymorphic collections
List<Vehicle> vehicles = new ArrayList<>();
vehicles.add(new Car());
vehicles.add(new Motorcycle());
vehicles.add(new Vehicle());
for (Vehicle v : vehicles) {
  v.service(); // Each object's own implementation runs
}
Real benefit: Add new subclasses and the loop still works without modification.
Example scenario
Service station code processes all vehicles uniformly. No type-switch logic required; subclasses encapsulate specific behavior.
Key Takeaway

Use collections typed to a common type for concise, extensible processing of heterogeneous objects.
