Module 5 › Chapter 4.4 › Member Inner Class
Core properties
  • Declared as a non-static class inside another class.
  • Instance of inner class requires an outer instance.
  • Has direct access to outer's fields and methods, including private ones.
Instantiation pattern
Use the outer instance to create the inner: Outer.Inner inner = outer.new Inner();
Key Takeaway

Member inner classes are ideal when a helper must share the outer instance state, but be mindful of lifecycle and memory references.

Example — iterator helper
class Outer {
  private String outerMessage = "Hello from Outer!";
  class Inner { // Member Inner Class
    public void display() {
      System.out.println(outerMessage); // Accesses private outer member
    }
  }
}
// Instantiate:
// Outer outer = new Outer();
// Outer.Inner inner = outer.new Inner();
// inner.display();
Misconception: Member inner classes always need to be private. They can be public or protected depending on your API design, but prefer limiting visibility to the minimal required scope.
