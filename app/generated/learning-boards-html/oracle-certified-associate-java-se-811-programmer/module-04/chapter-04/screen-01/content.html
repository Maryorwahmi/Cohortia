Inner Classes
Encapsulation and organization by nesting classes where they logically belong.

Defining a class inside another creates a special relationship. Some nested types are tied to an outer instance and can access private members; some are static and act like grouped top-level types. Understanding these patterns helps you design clearer APIs and avoid subtle bugs like unexpected memory retention.

Think of nested classes as helpers kept inside a file but closer to their owner.
Example: Iterator
A member inner class can implement an iterator that reads the outer collection’s private fields directly, avoiding extra getters.
Example: One-off Handler
An anonymous inner class is ideal for a short-lived event callback where writing a named class would be verbose.
Example: Node Type
A static nested node groups the node type with a collection class while avoiding implicit outer references.
Warning
Non-static inner classes hold an outer reference that can cause memory leaks if misused.
