// OuterClass.java (excerpt)
class OuterClass {
  private String outerField = "Outer data";
  public int outerNumber = 10;

  class MemberInner {
    public void displayOuterField() {
      System.out.println("MemberInner accessing outerField: " + outerField);
    }
  }

  public void useLocalInner(int value) {
    final String message = "Local message: ";
    class LocalInner { public void printInfo() { System.out.println(message + value); } }
    new LocalInner().printInfo();
  }

  public void useAnonymousInner() {
    Thread myThread = new Thread(new Runnable() { @Override public void run() { System.out.println("Running from anonymous inner class!"); } });
    myThread.start();
  }
}

// StaticOuterClass snippet
class StaticOuterClass {
  private static String staticOuterField = "Static outer data";
  static class StaticNested { public void displayStaticOuterField() { System.out.println(staticOuterField); } }
}
Key steps to run
  1. Create OuterClass outer = new OuterClass();
  2. Create member: OuterClass.MemberInner m = outer.new MemberInner(); then call displayOuterField().
  3. Call outer.useLocalInner(200) to invoke the local inner class behavior.
  4. Call outer.useAnonymousInner() and allow the thread to print its message.
  5. Create static nested: StaticOuterClass.StaticNested s = new StaticOuterClass.StaticNested(); then call displayStaticOuterField().
Common mistakes

Trying to access instance fields from a static nested class or using incorrect instantiation syntax for member inner classes will cause compile errors.
