Module 5 › Chapter 4.4 › Access Rules
Quick comparison
Member Inner: Access to outer instance members, including private fields.
Local Inner: Scoped to block; accesses only final or effectively final locals.
Anonymous: One-off similar to local; accesses effectively final locals as well.
Static Nested: No outer instance reference; can access only static outer members.
Code note — this references
Inside an inner class, the keyword this refers to the inner class instance. To explicitly reference the outer instance, use OuterClass.this. That notation clarifies which object you mean and avoids ambiguity when both inner and outer define the same method names or fields.
Pitfall

Non-static nested instances implicitly hold an outer reference; if they escape, they can prevent outer object garbage collection.
