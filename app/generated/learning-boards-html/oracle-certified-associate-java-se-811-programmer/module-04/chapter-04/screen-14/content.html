Module 5 › Chapter 4.4 › Key Concepts
Member Inner
Bound to an outer instance; accesses all instance members.
Local Inner
Defined in a block; can use final or effectively final locals.
Anonymous / Static
Anonymous: one-off implementations. Static nested: no outer reference; static-only access.
Memory strip

Prefer static nested classes to avoid implicit outer references when outer access isn’t needed. Use local and anonymous classes to keep short-lived logic tightly scoped.
