Module 5 › Chapter 4.4 › Use Cases & Patterns
Common patterns
Iterator helper — Member inner class reads private collection fields.
One-off callback — Anonymous inner class for Runnable or event listener.
Node/Entry — Static nested class grouped with collection type.
Method helper — Local inner class to keep method complexity manageable.
Practical checklist
  • Does the helper need outer instance access? If yes, member inner; if not, prefer static nested.
  • Is the helper only used inside one method? Consider local inner.
  • Is the behavior trivial and one-off? Anonymous inner or lambda may suffice.
Key Takeaway

Match nested type to lifetime and access need. Prefer clarity over clever nesting.
