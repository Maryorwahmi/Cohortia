Module 5 › Chapter 4.4 › Anonymous Inner Class
What makes it anonymous?
Declared and instantiated in a single expression without a class name. Often used for short callbacks or task implementations.
Pros
  • Less boilerplate for single-use behavior.
  • Can capture effectively final locals.
Cons
  • Harder to test and reuse; not suitable for complex logic.
Example usages
Greeter englishGreeter = new Greeter() { // Anonymous Inner Class
  @Override
  public void greet() {
    System.out.println("Hello!");
  }
};

a new Thread(new Runnable() {
  @Override
  public void run() {
    System.out.println("Running in an anonymous thread.");
  }
}).start();
Misconception: Anonymous equals lambda. While lambdas cover many concise single-method cases, anonymous classes can implement multiple methods or extend classes; choose the appropriate form.
