Module 5 › Chapter 4.4 › Practice Objectives
Practice tasks
Concrete exercises to build confidence
Member Inner Exercise
Create a member inner iterator that prints the outer’s private fields. Verify instantiation using outer.new Inner().
Local Inner Exercise
Within a method, declare a local inner class that reads an effectively final parameter and prints a composed string.
Anonymous Inner Exercise
Provide a Runnable via an anonymous inner class that prints a message and run it on a new thread.
Static Nested Exercise
Implement a static nested Node class that accesses a static outer field and cannot access instance fields directly.
Why practice

Hands-on tasks make the syntactic forms and access rules feel natural. They also expose pitfalls such as trying to access instance members from a static nested class or unintentionally keeping outer references alive.
