Module 5 › Chapter 4.4 › Local Inner Class
Rules & scope
  • Declared inside a method, constructor, or block.
  • Scope is limited to the enclosing block.
  • Can access final or effectively final locals.
When to use
For method-specific behavior where a separate top-level class would be overkill.
Key Takeaway

Local inner classes improve organization inside complex methods, but remember the effectively final requirement for captured locals.

Concrete example
class Calculator {
  public void performOperation(int a, int b) {
    final String operationName = "Addition"; // effectively final
    class Adder { // Local Inner Class
      public int add() {
        System.out.println("Performing " + operationName);
        return a + b; // accesses effectively final locals
      }
    }
    Adder adder = new Adder();
    System.out.println("Result: " + adder.add());
  }
}
Misconception: Local inner classes change the visibility of local variables. They do not; they only capture values that are final or effectively final.
