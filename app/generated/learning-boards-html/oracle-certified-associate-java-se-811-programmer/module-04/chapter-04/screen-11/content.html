Module 5 › Chapter 4.4 › Instantiation Patterns
Member inner example
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();
inner.display();
If you try Outer.Inner inner = new Outer.Inner() for a non-static inner, the compiler will complain because the inner needs a specific outer instance.
Static nested example
DataStructure.Node head = new DataStructure.Node("First");
Local inner classes are instantiated inside their block as usual, and anonymous inner classes are created where you pass a new expression for an interface or superclass implementation.
Common error

Trying to instantiate a non-static inner class without an outer instance or expecting static nested classes to access instance members will both produce compiler errors.
