Module 5 › Chapter 4.4 › Static Nested Class
Characteristics
  • Declared with the static keyword inside another class.
  • No implicit association with an outer instance.
  • Can access static outer members only.
When to prefer: for implementation types like nodes or entries that do not need outer instance access and should avoid holding an outer reference.
Example
class DataStructure {
  private static String structureName = "LinkedList";
  private int instanceCount = 0; // not accessible by static nested class

  static class Node { // Static Nested Class
    String data;
    Node next;
    public Node(String data) {
      this.data = data;
      System.out.println("Node created for " + structureName);
      // cannot access instanceCount here
    }
  }
}
// Instantiate: DataStructure.Node head = new DataStructure.Node("First");
Misconception: static nested classes are less powerful. They are simply decoupled from a specific outer instance and are often the safer choice for internal types.
