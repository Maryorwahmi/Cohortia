Module 5 › Chapter 4.4 › Mistakes & Memory
Memory leak risk
Non-static inner objects hold an implicit reference to the outer instance. If an inner object is stored in a long-lived structure, the outer instance cannot be collected even if you expect it to be eligible for garbage collection.
Avoid this

Do not let member inner instances escape unless intended. Use static nested classes when outer instance access is not required.

this vs OuterClass.this
Inside an inner class, this refers to the inner instance. Use OuterClass.this to refer to the outer instance explicitly, especially when both define similar method names or fields.
Readability tip: If your nested type becomes large or complex, extract it into a named nested or top-level class to keep the codebase maintainable and testable.
