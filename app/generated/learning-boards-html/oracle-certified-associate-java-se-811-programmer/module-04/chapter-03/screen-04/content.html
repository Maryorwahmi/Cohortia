Core Concept

Abstract class essentials

An abstract class can contain concrete and abstract methods, constructors, and fields. It sets a shared structure while preventing direct instantiation.

Has constructors — called by subclasses via super()
May contain state (instance variables)
Contains abstract methods that subclasses must implement
Key Takeaway

Abstract classes are for related types that share state or behavior but need some methods implemented by each concrete subclass.

Example
public abstract class Shape {
  String color;

  public Shape(String color) {
    this.color = color;
  }

  public void displayColor() {
    System.out.println("Shape color: " + color);
  }

  public abstract double calculateArea();
}
Common mistake: trying to create new Shape("Red") will produce a compile-time error.
Pro tip: put shared logic in concrete methods to reduce duplication in subclasses.
