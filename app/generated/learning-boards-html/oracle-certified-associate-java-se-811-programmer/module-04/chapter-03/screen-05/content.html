Core Concept

Interface essentials

Interfaces declare a contract of method signatures. Java 8+ adds default and static methods to help evolve interfaces without breaking implementations.

No constructors, cannot be instantiated
Fields are constants: public static final
Supports multiple inheritance of type through implements
Key Takeaway

Use interfaces for capabilities that many different classes may provide, keeping coupling low.

Example
public interface Drivable {
  void startEngine();
  void stopEngine();
  void accelerate(int speed);

  default void honk() {
    System.out.println("Default honk sound!");
  }

  static String getVehicleType() {
    return "Generic Drivable Vehicle";
  }
}
Pro tip: Use default methods sparingly — they are for backward compatibility, not to store state.
Misconception: interface fields are not instance variables; they are constants only.
