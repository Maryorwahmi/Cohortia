Main.java (tester)
public class AbstractionDemo {
  public static void main(String[] args) {
    // AbstractShape s = new AbstractShape("Blue"); // Compile error

    Circle myCircle = new Circle("Red", 5.0);
    System.out.println("Initial Circle Area: " + myCircle.calculateArea());
    myCircle.resize(1.5);
    System.out.println("Resized Circle Area: " + myCircle.calculateArea());
    System.out.println("---");

    Rectangle myRectangle = new Rectangle("Green", 10.0, 4.0);
    System.out.println("Rectangle Area: " + myRectangle.calculateArea());
  }
}
Expected output and checks
1. Attempting to instantiate AbstractShape causes a compile-time error. This enforces the abstraction.
2. Circle.calculateArea returns Math.PI * radius * radius. After resize the area increases consistent with radius change.
3. Rectangle does not implement Resizable and therefore cannot be resized by that interface method unless modified.
