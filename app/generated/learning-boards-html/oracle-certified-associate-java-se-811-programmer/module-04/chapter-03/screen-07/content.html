Module 4 › Chapter 4.3 › Refactor: Shape into AbstractShape
Abstract Base
public abstract class AbstractShape {
  String color;

  public AbstractShape(String color) {
    this.color = color;
  }

  public void displayColor() {
    System.out.println("Shape color: " + color);
  }

  public abstract double calculateArea();
}
Concrete Subclass
public class Circle extends AbstractShape {
  double radius;

  public Circle(String color, double radius) {
    super(color);
    this.radius = radius;
  }

  @Override
  public double calculateArea() {
    return Math.PI * radius * radius;
  }
}
Check: compiling after making calculateArea abstract will fail if any concrete subclass does not implement it. Use the compiler message to find unimplemented subclasses quickly.
