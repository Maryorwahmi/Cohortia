Module 4 › Chapter 4.3 › Learning Objectives
Bloom Progress
Learn → Understand → Apply → Master

We begin with definitions and move toward applied refactoring and testing.

01
Abstract Classes
Define a class you cannot instantiate

You will declare abstract methods and share fields or implementation for closely related subclasses. Verified competency milestone: implement an abstract method in a concrete subclass.

02
Interfaces
Express capabilities and contracts

You will create interfaces, include default and static methods, and implement them across classes to gain multiple inheritance of type. Verified competency milestone: add a default method and use it.

03
Design Decision
When to choose abstract vs interface

You will learn the practical tradeoffs like state sharing and multiple inheritance of type. Verified competency milestone: justify a design choice with reasons.

04
Refactor & Test
Apply a refactor to Shape hierarchy

You will refactor Shape to be abstract, add Resizable, and run a small main method demonstrating compile-time behavior. Verified competency milestone: produce expected run output after resize.
