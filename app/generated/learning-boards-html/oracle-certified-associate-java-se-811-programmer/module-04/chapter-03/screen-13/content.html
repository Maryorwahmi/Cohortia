Module 4 › Chapter 4.3 › Key Concepts
Abstract Class
Non-instantiable base that may contain concrete methods, constructors, and state.
Interface
A contract of behavior; supports multiple inheritance of type and Java 8+ default/static methods.
Design Heuristic
Shared state -> abstract class. Independent capability -> interface.
Takeaway

Use abstraction intentionally: choose the construct that fits your design goal — shared identity and state with abstract classes, or composable capabilities with interfaces.
