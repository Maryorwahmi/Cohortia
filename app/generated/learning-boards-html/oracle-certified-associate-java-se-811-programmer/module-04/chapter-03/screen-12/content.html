Module 4 › Chapter 4.3 › Refactoring activity: Shape + Resizable
Activity steps
  1. Make Shape abstract and declare calculateArea as abstract.
  2. Create Resizable interface with resize(double factor) and a default helper.
  3. Make Circle implement Resizable and update radius inside resize.
  4. Run the main tester to verify output and compile errors if present.
Starter hints & checks
Hint: Remember to call super(color) in subclass constructors to initialize inherited fields.
Check: After resize the area output should reflect radius change by factor squared.
Reflection: If many subclasses need the same resize behavior, consider extracting a helper or reconsidering the division of responsibility.
Expected outcome

A compiled program where Circle resizes and shows updated area, Rectangle remains unresized, and abstract rules are enforced at compile time.
