Module 4 › Chapter 4.3 › Learning Objectives — Skills Map
Skill progression
  1. Declare abstract classes and methods — create a base that cannot be instantiated and forces subclasses to implement behavior.
  2. Use constructors and shared fields — call super() from subclasses to initialize shared state.
  3. Design interfaces with default/static methods — provide capability contracts and optional shared implementations.
  4. Refactor and test — run a main method to confirm compile-time rules and runtime behavior.
Common pitfalls
  • Trying to instantiate an abstract class causes a compile error.
  • Forgetting to implement every abstract method in a concrete subclass causes a compile error.
  • Expecting interfaces to hold instance state — interface fields are constants only.
