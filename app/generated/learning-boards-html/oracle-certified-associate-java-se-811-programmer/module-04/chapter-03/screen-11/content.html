Module 4 › Chapter 4.3 › Compile-time errors and fixes
Common compiler messages
  • Cannot instantiate the type AbstractShape — fix: instantiate a concrete subclass instead.
  • Class must be declared abstract or implement abstract method — fix: implement the missing method or mark class abstract.
  • Cannot assign a value to final variable — fix: do not attempt to mutate interface constants; move state to class fields.
  • Reference to resize is undefined — fix: add implements Resizable or cast to the correct type.
Quick fixes
  1. Read the compiler error; it points to the problematic class and line.
  2. Implement or declare abstract methods appropriately.
  3. Move mutable data out of interfaces into implementing classes.
  4. Override conflicting default methods explicitly if two interfaces clash.
