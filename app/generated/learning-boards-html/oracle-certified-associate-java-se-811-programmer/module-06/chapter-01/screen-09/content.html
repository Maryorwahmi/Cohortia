Process Flow

PECS mnemonic and practical patterns

A quick decision flow: produce or consume, then choose extends or super.

Decision steps
  1. Ask: does the method produce values for callers? If yes, use ? extends T.
  2. If the method consumes or adds values, use ? super T to allow safe writes.
  3. For copy operations, accept source as ? extends and destination as ? super.
Example: copy
void copy(List<? extends T> src, List<? super T> dst) { for (T t : src) dst.add(t); }
Common pitfalls
  • Using raw types to bypass generics rather than choosing the correct wildcard.
  • Assuming extends allows additions; it only guarantees safe reads as the upper bound.
  • Exposing arrays of parameterized types instead of collections, which creates erasure issues.
Key Takeaway

Apply PECS as a quick heuristic when designing collection APIs: Producer Extends, Consumer Super.
