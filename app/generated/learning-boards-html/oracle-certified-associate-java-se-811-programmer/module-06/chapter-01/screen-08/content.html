Comparison

Wildcards: ? versus ? extends T versus ? super T

A short comparison to choose the right wildcard for your API's read/write pattern.

Summary cards
Unbounded: List<?>
Unknown type; safe to read as Object; cannot add anything except null.
Upper bound: List<? extends Number>
Producer: read values as Number safely; cannot add new Number instances.
Lower bound: List<? super Integer>
Consumer: can add Integer values safely; reading returns Object.
Concrete code snippets
public static double sumOfList(List<? extends Number> list) {
  double sum = 0.0;
  for (Number n : list) {
    sum += n.doubleValue();
  }
  return sum;
}

public static void addIntegers(List<? super Integer> list) {
  list.add(10);
  list.add(20);
}
Key Takeaway

Remember PECS: use extends for producers (reading) and super for consumers (writing).
