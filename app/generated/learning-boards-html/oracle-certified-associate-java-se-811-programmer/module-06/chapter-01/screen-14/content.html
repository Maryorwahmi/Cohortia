Quick Reference

1. Explicit types
Prefer ArrayList<T> over raw ArrayList for clear contracts.
2. Use PECS
? extends for producers, ? super for consumers.
3. Respect erasure
Avoid new T(), instanceof T, or arrays of parameterized types; use Class tokens or collections instead.
One final thought

When in doubt, let the compiler guide your API design — it will point you to safer, clearer choices.
