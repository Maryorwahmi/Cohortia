Common Pitfalls

Common compile-time errors and how to resolve them

Practical resolutions for the frequent errors you'll see when using generics.

Unchecked assignment
Refactor signatures to use parameterized types; avoid passing raw collections between methods.
Illegal generic array
Use List<T> instead of T[] or create Object[] and cast elements carefully as a last resort.
Cannot instantiate type variable
Accept Class<T> and use reflection to construct instances when necessary, handling exceptions properly.
Key Takeaway

Compiler messages often point to API-level fixes: prefer types that express intent, use collections over arrays for generics, and apply PECS for wildcard correctness.
