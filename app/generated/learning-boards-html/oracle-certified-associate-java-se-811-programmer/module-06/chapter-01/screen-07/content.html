Core Concept

Type erasure: what it means and limits it imposes

The compiler removes generic labels, which forces certain runtime operations to be illegal and changes how you design APIs.

Typical limitations
  • Cannot create instances with new T().
  • Cannot use instanceof with a type parameter.
  • Cannot create arrays of parameterized types like new List<String>[10].
Workarounds
Pass a Class<T> token to create instances, use lists of Object with careful casting, or redesign APIs to avoid generic arrays.
Concrete example
// Illegal: cannot create arrays of parameterized types
// List[] arr = new ArrayList[10]; // compile-time error

// Workaround: use List[] or use List of lists
List[] arr2 = new ArrayList[10];

// Illegal: cannot instantiate T
// T instance = new T(); // compile-time error

// Workaround: pass a Class token
public <T> T create(Class<T> cls) throws Exception {
  return cls.getDeclaredConstructor().newInstance();
}
Key Takeaway

Erasure enforces design constraints; use tokens or API redesign to work around runtime limitations.
