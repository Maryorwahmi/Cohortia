Declaring generic classes: the Box example

Write Box<T> and use T just like a regular type inside the class definition.

Code walkthrough
public class Box {
  private T content;

  public void setContent(T content) {
    this.content = content;
  }

  public T getContent() {
    return content;
  }

  public static void main(String[] args) {
    Box stringBox = new Box<>(); // diamond infers String
    stringBox.setContent("Hello Generics");
    String message = stringBox.getContent();
    System.out.println(message);

    Box intBox = new Box<>();
    intBox.setContent(123);
  }
}
Explanation & tips
  • Type parameter T is a placeholder that becomes a real type at instantiation.
  • The diamond operator <> lets the compiler infer type arguments, reducing repetition.
  • You cannot use new T() or instanceof T because type parameters are erased at runtime.
  • Generic classes can be nested: Box<List<String>> remains type-checked at compile time.
Key Takeaway

Declare placeholders after the class name and use them to express safe storage and retrieval contracts.
