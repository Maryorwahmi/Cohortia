Comparison
StringBuffer
Synchronized mutable buffer suitable for multi-threaded scenarios where the same instance is shared.
StringBuffer sbuf = new StringBuffer(100);
sbuf.append("First part.");
sbuf.append(" Second part.");
// Methods are synchronized internally
String result = sbuf.toString();
When to choose
  • Use StringBuffer when multiple threads will call mutating methods on the same instance.
  • Prefer StringBuilder when working in a single thread or when you can manage synchronization yourself.
  • Be aware that synchronization reduces throughput; measure only if necessary.
Pro Tip

If only a small critical section needs protection, prefer external synchronization around a StringBuilder rather than using a fully synchronized buffer.
