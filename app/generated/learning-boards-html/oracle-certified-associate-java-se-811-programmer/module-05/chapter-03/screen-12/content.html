Module 5 › Chapter 5.3 › Key Concepts
String is immutable
Once created, a String's content cannot change; modifications return new objects.
equals() vs ==
Use equals() for content checks; == tests whether two references point to the same object.
StringBuilder vs StringBuffer
Use StringBuilder for single-thread speed and StringBuffer when internal synchronization is required.
Takeaway

Remember these trade-offs: immutability gives safety and pooling; builders give efficient mutation. Choose based on correctness, concurrency, and performance needs.
