Module 5 › Chapter 5.3 › Final Reminders
Use Strings as keys
Immutable Strings make reliable keys for maps and sets.
Avoid == for content
Always use equals or equalsIgnoreCase for text equality.
Prefer builders for loops
StringBuilder for speed; StringBuffer when you need synchronized mutation.
Final takeaway

Decide between immutability and mutation by asking: will this text change often? Will multiple threads touch it? Use that to choose String, StringBuilder, or StringBuffer.
