Learning Objectives
Learn, understand, apply, and master Java text APIs.
Bloom: Learn → Understand → Apply → Master
01
Explain immutability
Describe why a String cannot change and how that leads to thread-safety and literal reuse.
Mnemonic: locked box
VERIFIED COMPETENCY MILESTONE
02
Use String APIs
Apply trim, substring, indexOf, replace, split, and case conversion correctly in examples.
Mnemonic: toolkit
VERIFIED COMPETENCY MILESTONE
03
Compare strings correctly
Use equals() and equalsIgnoreCase() for content equality; understand why == checks references.
Mnemonic: content vs pointer
VERIFIED COMPETENCY MILESTONE
04
Choose string builders
Decide when to use StringBuilder for single-thread performance and StringBuffer for thread-safe mutation.
Mnemonic: speed vs safety
