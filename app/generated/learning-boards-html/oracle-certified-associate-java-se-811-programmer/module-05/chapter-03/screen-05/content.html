Common String methods
A compact code walkthrough shows typical method use and expected results.
String greeting = "  Hello, Cohortia!  ";
String trimmed = greeting.trim();
int len = trimmed.length();
String first = trimmed.substring(0,5); // "Hello"
String rest = trimmed.substring(7);   // "Cohortia!"
boolean has = trimmed.contains("Cohortia");
int i = trimmed.indexOf('o');
String replaced = trimmed.replace('o','*');
String[] parts = "apple,banana,cherry".split(",");
Explanation
  • trim removes only the ends; middle whitespace remains.
  • substring creates a new String and throws if indices are invalid.
  • indexOf returns -1 when the element is missing; check before using the index.
  • replace returns a new String and supports char or CharSequence replacements.
  • split returns an array; be careful with empty tokens and regex special characters.
Concrete Example

From " Hello, Cohortia! ", trim() yields "Hello, Cohortia!" and substring(0,5) yields "Hello".

Common mistake:
Assuming split with "," always returns three items; user input may vary and produce fewer tokens.
