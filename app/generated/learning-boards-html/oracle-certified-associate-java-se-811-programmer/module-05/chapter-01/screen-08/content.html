Module 5 › Chapter 5.1 › The finally Block and Cleanup
Example pattern
FileInputStream in = null;
try {
  in = new FileInputStream("data.txt");
  // read from stream
} catch (IOException e) {
  System.err.println("I/O error while reading file.");
} finally {
  if (in != null) {
    try { in.close(); } catch (IOException ex) { /* log and ignore */ }
  }
}
This classic pattern ensures the stream is closed regardless of success. The finally block itself should handle any exceptions from cleanup but keep logic simple to avoid masking the original exception.
Pro tip
Prefer try-with-resources for AutoCloseable resources; use finally when try-with-resources is not applicable.
Common mistake
Throwing a new exception inside finally without preserving the original hides the initial cause. Log and rethrow carefully if needed.
