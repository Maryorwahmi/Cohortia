Module 5 › Chapter 5.1 › Refactor the FragileCalculator
Starter code
public class FragileCalculator {
    public static void main(String[] args) {
        if (args.length < 2) {
            System.out.println("Usage: java FragileCalculator  ");
            return;
        }

        int num1 = Integer.parseInt(args[0]);
        int num2 = Integer.parseInt(args[1]);

        int result = num1 / num2;
        System.out.println("Result of division: " + result);
    }
}
Refactor checklist
  • Wrap parsing and division in try-catch blocks.
  • Catch NumberFormatException and report which input is invalid.
  • Catch ArithmeticException for division by zero and suggest a fix.
  • Include a finally block that prints "Calculation attempt complete."
  • Avoid catch(Exception) and do not swallow exceptions silently.
Testing scenarios
Try valid inputs, non-numeric inputs, and zero as the divisor to verify behavior and the final message always prints.
