Scenario — NumberFormatException
String numberString = "abc";
try {
  int number = Integer.parseInt(numberString); // throws NumberFormatException
  System.out.println("Parsed number: " + number);
} catch (NumberFormatException e) {
  System.err.println("Invalid number format for '" + numberString + "'.");
  System.err.println("Details: " + e.getMessage());
}
Catch specifically and provide user-friendly text. During debugging, log the stack trace to find where the input originated.
Scenario — ArrayIndexOutOfBounds
int[] numbers = {10,20,30};
try {
  System.out.println(numbers[1]);
  System.out.println(numbers[3]); // throws ArrayIndexOutOfBoundsException
} catch (ArrayIndexOutOfBoundsException e) {
  System.err.println("Attempted to access array with an invalid index.");
} finally {
  System.out.println("Finally block executed. This ensures cleanup happens.");
}
When exceptions occur, subsequent try statements are skipped. Finally runs to guarantee cleanup or logging actions happen.
Check your understanding
If the first print runs successfully and the second throws, which lines execute? Answer: the catch block runs for the thrown exception, then finally runs, and later code after the try-catch-finally executes.
