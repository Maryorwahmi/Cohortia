Module 5 › Chapter 5.1 › Throw and Throws — Raising and Declaring Exceptions
Explicit throw
if (value < 0) {
  throw new IllegalArgumentException("Value must be non-negative");
}
Throw an exception when the current method detects an invalid condition it cannot handle. Choose the appropriate exception type and include a clear message.
Declare checked exceptions
public void readFile() throws IOException {
  // file operations that may throw IOException
}
Use throws to signal to callers that a checked exception may propagate and must be handled or declared further up the call chain.
Design note
Prefer converting low-level exceptions into domain-specific exceptions when it clarifies caller responsibilities. Avoid using throws solely to defer error handling without documenting who should act.
