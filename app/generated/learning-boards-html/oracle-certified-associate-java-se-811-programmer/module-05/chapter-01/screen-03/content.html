Objective set
01
Order catches correctly
Practice catching specific subclasses before their superclasses to avoid unreachable code or concealed bugs.
VERIFIED COMPETENCY MILESTONE
02
Use finally for cleanup
Guarantee resource release even when exceptions interrupt normal flow.
VERIFIED COMPETENCY MILESTONE
03
Log usefully
Capture exception messages and stack traces for diagnostics while keeping user messages friendly.
VERIFIED COMPETENCY MILESTONE
04
Avoid silent catches
Never swallow exceptions without logging or a reason; it hides bugs and obstructs debugging.
VERIFIED COMPETENCY MILESTONE
Practice hints

When a method declares throws for a checked exception, callers must handle or declare that exception; this leads to deliberate design decisions about responsibility for recovery.

Prefer narrow exception handling near the code that can fix the problem. Use rethrowing when necessary to let higher layers decide.
