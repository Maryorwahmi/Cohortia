Module 5 › Chapter 5.1 › What is an Exception?
Definition
An exception is an event represented by an Exception object that interrupts the normal flow of instructions. It is created by the runtime or explicitly by code using throw, and it propagates until a matching catch handles it or the program terminates.
Misconception check
  • Exceptions are not ordinary return values; they force an abrupt transfer of control.
  • Handling an exception does not automatically fix the underlying bug; it manages the symptom and state.
Analogy
Think of an exception like a fire alarm: it interrupts normal activity and signals a condition that needs handling. The response may be a localized fix or an orderly shutdown, depending on severity.
Key Takeaway
Treat exceptions as structured signals requiring deliberate handling, not as silent failures to ignore.
Concrete example
String s = "abc";
try {
  int n = Integer.parseInt(s); // throws NumberFormatException
  System.out.println(n);
} catch (NumberFormatException e) {
  System.err.println("Invalid number: " + s);
}
This example shows runtime creation and throwing of a NumberFormatException when parse fails. Catching it prevents the program from crashing and lets you respond gracefully.
Common mistake
Don't catch Exception broadly to silence all problems. It hides the true cause and prevents correct fixes higher in the stack.
