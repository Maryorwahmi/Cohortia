Module 5 › Chapter 5.1 › Try → Catch → Finally Flow
Process steps
  1. Enter try; execute statements until one throws or all succeed.
  2. If no exception, skip catches, execute finally, then continue.
  3. If exception thrown, search catch blocks in order for a type match.
  4. If a catch handles it, run that catch, then finally, then continue.
  5. If no local catch matches, unwind the call stack and repeat the search in callers.
Key Takeaway
Finally is reliable for cleanup. Do not rely on finally for complex recovery logic that depends on higher-level context.
Annotated example
try {
  System.out.println(array[3]); // may throw ArrayIndexOutOfBoundsException
} catch (ArrayIndexOutOfBoundsException e) {
  System.err.println("Invalid index");
} finally {
  System.out.println("Cleanup always runs");
}
If index 3 is invalid, the catch runs then finally. If index 3 is valid, only finally runs after printing the value.
Misconception
Finally will run even if a return statement executes inside try or catch. Use finally for deterministic cleanup, not for conditional logic that should be in normal flow.
