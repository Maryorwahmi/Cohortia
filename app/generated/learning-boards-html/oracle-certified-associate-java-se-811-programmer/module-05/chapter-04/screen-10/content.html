Event Scheduler
Read current LocalDateTime, parse user input for date and time, combine them, and compute how long until the event using Period and ChronoUnit.
Validation
Loop until parse succeeds, catch DateTimeParseException and prompt again.
Calculation
Use Period for years/months/days and ChronoUnit.HOURS for approximate hour count.
Starter Code
DateTimeFormatter dateFormatter = DateTimeFormatter.ofPattern("yyyy-MM-dd");
DateTimeFormatter timeFormatter = DateTimeFormatter.ofPattern("HH:mm");

// parse loops (simplified)
LocalDate eventDate = LocalDate.parse(dateInput, dateFormatter);
LocalTime eventTime = LocalTime.parse(timeInput, timeFormatter);
LocalDateTime eventDateTime = LocalDateTime.of(eventDate, eventTime);

Period periodUntilEvent = Period.between(LocalDate.now(), eventDateTime.toLocalDate());
long hoursUntilEvent = ChronoUnit.HOURS.between(LocalDateTime.now(), eventDateTime);
Tip: Present both a Period breakdown and an approximate hours/minutes message so users get clarity on long and short intervals.
Key Takeaway

The scheduler ties parsing, combination, and interval math—practice each step and handle parse errors explicitly.
