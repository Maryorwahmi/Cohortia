Best Practice
Store UTC, display local
Persist Instants in storage and attach ZoneId only when displaying or interpreting user-local times.
  • Persist Instant for reliable comparison and ordering.
  • Convert to ZonedDateTime when showing times to users.
  • Avoid storing LocalDateTime without zone context.
Code
Instant now = Instant.now();
// store now.toString() or now.toEpochMilli()

ZoneId userZone = ZoneId.of("Europe/London");
ZonedDateTime userView = now.atZone(userZone);
String display = userView.format(DateTimeFormatter.ofPattern("EEEE, MMM dd, yyyy 'at' hh:mm a"));
Common mistake
Relying on system default zone for conversions, which can differ across deployments.
