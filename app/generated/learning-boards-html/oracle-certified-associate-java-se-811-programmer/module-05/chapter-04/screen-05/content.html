Definition
LocalDate / LocalTime / LocalDateTime
These classes model calendar concepts without zone data. They are ideal for domain data like birthdays, schedules, and local events where the zone is contextual.
  • LocalDate: year-month-day, e.g., 1990-05-15.
  • LocalTime: hour-minute-second, e.g., 14:30.
  • LocalDateTime: combined date and time, no zone.
Pro tip
Use LocalDate for birthdays and Instant for logged timestamps.
Code Example
LocalDate birthDate = LocalDate.of(1990, 5, 15);
LocalTime meeting = LocalTime.of(14, 30);
LocalDateTime appointment = LocalDateTime.of(2024, 1, 1, 9, 0);
LocalDate nextWeek = LocalDate.now().plusWeeks(1);
LocalTime earlier = LocalTime.now().minusHours(2);
// originals unchanged due to immutability
Key Takeaway

Local types are for context-local values; never assume they represent an absolute instant without a zone.
