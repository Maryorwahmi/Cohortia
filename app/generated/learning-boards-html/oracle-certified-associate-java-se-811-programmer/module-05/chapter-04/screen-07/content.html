Architecture
ZonedDateTime + ZoneId
Combine local date-times with a ZoneId to get an unambiguous instant. Conversions between zones preserve the same instant while changing the displayed local time.
Create with zone
ZonedDateTime.of(localDateTime, ZoneId.of("America/New_York"))
Convert zones
zdt.withZoneSameInstant(ZoneId.of("Europe/London"))
Example
ZoneId newYork = ZoneId.of("America/New_York");
ZonedDateTime ny = ZonedDateTime.now(newYork);
ZoneId london = ZoneId.of("Europe/London");
ZonedDateTime londonTime = ny.withZoneSameInstant(london);
System.out.println("NY: " + ny);
System.out.println("London: " + londonTime);
Misconception: LocalDateTime.atZone and ZonedDateTime.of behave the same—the important point is they interpret the local date-time as belonging to that zone, not converting an already absolute instant.
Key Takeaway

Always attach an explicit ZoneId when interpreting or converting local times to avoid implicit defaults and shifts.
