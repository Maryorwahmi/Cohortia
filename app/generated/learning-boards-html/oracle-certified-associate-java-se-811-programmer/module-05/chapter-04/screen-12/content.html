Core Concept
Immutability & Thread-Safety
java.time objects are immutable. Operations return new instances so threads cannot observe partial changes or race on shared objects.
Why it helps
No defensive copying required; fewer synchronization bugs.
Formatter safety
DateTimeFormatter instances are safe when used correctly across threads.
Example
Consider multiple threads logging timestamps. Using Instant.now() and a shared DateTimeFormatter avoids synchronized blocks and accidental mutation.
Key Takeaway
Prefer immutable java.time types to avoid shared-state bugs and simplify concurrent designs.
