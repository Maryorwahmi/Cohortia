Process
Construct & manipulate
Use factory methods and fluent operations. Remember each operation returns a new instance.
  1. 1. Create with of(...), now(), or parse(...).
  2. 2. Modify with plus/minus methods; assign result.
  3. 3. Combine date and time with of(date, time).
Check your understanding
If plusDays returns a value, what happens if you ignore it? The original remains unchanged.
Code Snippet
LocalDate today = LocalDate.now();
LocalDate nextWeek = today.plusWeeks(1);
System.out.println("Today: " + today);
System.out.println("Next week: " + nextWeek);

LocalTime currentTime = LocalTime.now();
LocalTime earlier = currentTime.minusHours(2);
Key Takeaway

Always capture the result of arithmetic operations; java.time values are immutable.
