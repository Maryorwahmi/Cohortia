Instant & Intervals
Instant is the machine-readable timestamp in UTC. Duration measures exact seconds and nanoseconds. Period measures calendar units—years, months, days.
Instant
Use for logs and database timestamps; unambiguous globally.
Duration
Time-based spans: hours, minutes, seconds.
Period
Date-based spans: years, months, days.
Example
LocalTime start = LocalTime.of(9,0);
LocalTime end = LocalTime.of(17,30);
Duration workDuration = Duration.between(start, end);
long hours = workDuration.toHours();
long minutes = workDuration.toMinutes() % 60;

LocalDate projectStart = LocalDate.of(2023,1,1);
LocalDate projectEnd = LocalDate.of(2024,6,15);
Period projectPeriod = Period.between(projectStart, projectEnd);
int years = projectPeriod.getYears();
Misconception: Don’t use Duration for months or years—use Period because calendar units vary.
Key Takeaway

Pick Duration for fixed time lengths, Period for calendar lengths, and Instant for storage.
