Definition
DateTimeFormatter
A thread-safe formatter for converting between date/time objects and strings. Supports built-in ISO formats and custom patterns.
Built-in
DateTimeFormatter.ISO_LOCAL_DATE
Custom
DateTimeFormatter.ofPattern("dd-MM-yyyy HH:mm:ss")
Code Example
DateTimeFormatter fmt = DateTimeFormatter.ofPattern("dd-MM-yyyy HH:mm:ss");
String formatted = LocalDateTime.now().format(fmt);
System.out.println("Formatted: " + formatted);

String input = "2025-12-25 18:00:00";
DateTimeFormatter parser = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
try {
  LocalDateTime parsed = LocalDateTime.parse(input, parser);
  System.out.println("Parsed: " + parsed);
} catch (DateTimeParseException e) {
  System.out.println("Invalid date format. Please use yyyy-MM-dd HH:mm:ss.");
}
Misconception: assuming parsing will accept multiple formats; be explicit and provide clear feedback on errors.
Key Takeaway

Prefer explicit patterns or ISO formats and always handle parse exceptions for robust input handling.
