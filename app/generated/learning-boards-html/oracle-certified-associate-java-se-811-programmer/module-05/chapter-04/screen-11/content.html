Comparison
Duration vs Period
Duration is for time-based amounts (hours, minutes, seconds). Period is for date-based amounts (years, months, days).
Duration example
Flight time: Duration between departure and arrival instants.
Period example
Project length: Period between start and end dates in years/months/days.
Concrete Guidance
  • Use Duration for precise elapsed times and timeouts.
  • Use Period for human-readable calendar differences like age.
  • When both are needed, compute Period for the date portion and Duration or ChronoUnit for the time portion.
Common mistake
Using Duration to represent months or years leads to incorrect results because months vary in days.
Key Takeaway

Match your choice of Duration or Period to the problem's semantic meaning: clock time or calendar time.
