Checked vs Unchecked
Checked = recoverable; Unchecked = programming/configuration error.
AutoCloseable
Implement close() to join try-with-resources and ensure cleanup.
Suppressed Exceptions
Close-time exceptions are attached to the primary exception and must be inspected with getSuppressed().
Final Note

Adopt these practices to make your Java code clearer, safer, and easier to debug when real failures occur.
