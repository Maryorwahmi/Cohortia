Module 5 › Chapter 5.2 › Suppressed Exceptions
Behavior
If an exception E1 is thrown in the try block and close() throws E2, E1 is the primary exception and E2 is added as suppressed to E1.
Inspect suppressed
catch (IOException e) {
  System.out.println("Caught: " + e.getMessage());
  for (Throwable suppressed : e.getSuppressed()) {
    System.out.println("Suppressed: " + suppressed.getMessage());
  }
}
Debugging tip
Always log the primary exception and iterate suppressed exceptions to capture close-time failures that may explain resource cleanup issues.
Key Takeaway
Suppressed exceptions preserve cleanup errors while keeping the original cause visible for handling.
