Module 5 › Chapter 5.2 › try-with-resources
Pattern
Declare resources in the try header. When the try block ends, each resource's close() is called automatically.
1
Open resource
2
Use resource
3
Automatic close (reverse order)
Important
try-with-resources guarantees close is invoked even when exceptions occur, but you still need catch blocks to handle read-time or close-time exceptions.
Quick Example
try (BufferedReader br = new BufferedReader(new FileReader(filePath))) {
  String line;
  while ((line = br.readLine()) != null) {
    System.out.println(line);
  }
} catch (IOException e) {
  System.err.println("Error reading or closing file (TWR): " + e.getMessage());
}
