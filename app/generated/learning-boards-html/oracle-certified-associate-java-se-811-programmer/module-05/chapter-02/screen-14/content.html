Question 1
Design InvalidCredentialsException for authentication failure. Which base class and why?
Correct answer
Extend java.lang.Exception so the caller is forced to handle the recoverable authentication failure.
Question 2
Predict output when try throws and close throws in try-with-resources. Which is caught and which is suppressed?
Correct answer
The exception from the try-block is caught. The close-time exception is added as suppressed to the primary exception and can be retrieved with getSuppressed().
Assessment Tip
When you answer, include reasoning: who should handle the error and why, and how getSuppressed preserves cleanup exceptions for diagnostics.
