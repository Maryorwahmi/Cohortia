Module 5 › Chapter 5.2 › Key Concepts
Custom Exception
User-defined exceptions that express domain failure and carry context.
try-with-resources
Automatic closing of AutoCloseable resources declared in the try header.
Suppressed Exceptions
Close-time exceptions attached to the primary exception and available via getSuppressed().
Takeaway

Design exceptions for intent, use try-with-resources to prevent leaks, and inspect suppressed exceptions for complete diagnostics.
