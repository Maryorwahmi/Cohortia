Module 5 › Chapter 5.2 › Unchecked Exceptions
Exception Code
class InvalidConfigurationException extends RuntimeException {
  public InvalidConfigurationException(String message) {
    super(message);
  }
  public InvalidConfigurationException(String message, Throwable cause) {
    super(message, cause);
  }
}
Usage Pattern
Check configuration at startup. If required settings are missing throw InvalidConfigurationException. Catch it at a high level to report and stop initialization.
Misconception
Using unchecked exceptions only to avoid signature changes sacrifices API clarity. Choose them for genuine non-recoverable faults.
