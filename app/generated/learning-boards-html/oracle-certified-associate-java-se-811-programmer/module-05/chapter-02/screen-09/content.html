Module 5 › Chapter 5.2 › Multiple Resources
Example
try (FileReader fr = new FileReader(filePath);
     BufferedReader br = new BufferedReader(fr)) {
  String line;
  while ((line = br.readLine()) != null) {
    System.out.println(line);
  }
} catch (IOException e) {
  System.err.println("Error with multiple resources: " + e.getMessage());
}
Why reverse order
The wrapper (BufferedReader) depends on the underlying FileReader. Closing the wrapper first avoids using a closed underlying resource and prevents subtle I/O errors.
Quick Tips
  • Declare wrappers after their underlying resources.
  • Expect close() to run even on exceptions.
  • Inspect suppressed exceptions to see close-time failures.
