Tasks
Task A — FileProcessingException
Create a checked exception with message and optional cause. Use it to wrap any IOException coming from resource reading.
Task B — ResourceReader
Implement AutoCloseable, simulate read exhaustion, and make close() announce closing. Throw IOException when appropriate.
Task C — Try-with-resources
Use try-with-resources to open ResourceReader and catch FileProcessingException. Print the cause stack trace if present.
Milestones
  • Exception compiles and includes constructors for cause.
  • ResourceReader close() sets closed and prints a message.
  • Main catches FileProcessingException and prints cause stack trace when present.
These measurable outputs let you confirm both compile-time correctness and runtime behavior.
