AutoCloseable
Defines void close() throws Exception. Implementing it enables try-with-resources support.
Implementation notes
  • Make close() idempotent when possible.
  • Release native handles and free buffers inside close().
  • Decide whether close() should throw an exception to signal cleanup failure.
Closeable
Extends AutoCloseable and declares close() throws IOException. Most I/O classes implement Closeable.
Starter ResourceReader
class ResourceReader implements AutoCloseable {
  private boolean closed = false; 
  private int readCount = 0;

  public String readLine() throws IOException { ... }

  @Override
  public void close() throws IOException {
    System.out.println("ResourceReader 'Name' closing...");
    this.closed = true;
  }
}
