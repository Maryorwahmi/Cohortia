Module 5 › Chapter 5.2 › Why create custom exceptions?
Definition

Custom Exception

A user-defined class that models domain errors and carries context so callers can make informed decisions.

When to use
Model recoverable domain failures or clearly named error conditions that callers should handle.
Avoid
Do not create trivial exceptions for every boolean check; prefer existing exceptions when they convey intent sufficiently.
Key Takeaway

Use custom exceptions to encode domain intent and pass structured error details to callers.

Concrete Example
InsufficientFundsException (concept)
class InsufficientFundsException extends Exception {
  private double requiredAmount;
  private double availableBalance;

  public InsufficientFundsException(String message, double required, double available) {
    super(message);
    this.requiredAmount = required;
    this.availableBalance = available;
  }

  public double getRequiredAmount() { return requiredAmount; }
  public double getAvailableBalance() { return availableBalance; }
}
Analogy
Think of a custom exception as a labeled container for failure details, like a form that contains the exact fields needed to resolve the issue.
