Key Concepts

Essential terms from this chapter

Class

The fundamental building block of Java programs; all code resides within classes.

main method

The entry point for any executable Java application; its signature is public static void main(String[] args).

System.out.println()

A standard Java statement used to print output to the console, followed by a new line.
