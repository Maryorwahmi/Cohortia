Output Operations

System.out.println() Explained

Displaying messages to the user on the console.

System.out.println("Hello, Cohortia!");

Output:

Hello, Cohortia!

Components of the Statement

  • System: A core Java class for system resources.
  • out: The standard output stream (console).
  • println(): Method to print text and add a new line.
  • "String Literal": The actual text to be printed.
  • ;: Terminates every Java statement.
Print vs. Println

println() adds a new line after printing; print() does not, keeping the cursor on the same line.

Key Takeaway

System.out.println() is your primary tool for displaying information and debugging in console applications.
