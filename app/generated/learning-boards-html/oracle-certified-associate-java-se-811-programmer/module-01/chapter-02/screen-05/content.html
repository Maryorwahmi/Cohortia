Anatomy of a Java Program

Deconstructing your first 'Hello, Cohortia!' class.

// Chapter 1.2: Your First Java Program

public class HelloCohortia {
    public static void main(String[] args) {
        System.out.println("Hello, Cohortia!"); // Prints message
    }
}

Key Components

  • Class Declaration: All Java code resides within classes, defined by the class keyword.
  • main Method: The essential entry point for program execution, recognized by the JVM.
  • Output Statement: System.out.println() is used to display text to the console.
  • Semicolon: Every statement in Java must end with a semicolon (;).
Pro Tip

The filename must exactly match the public class name, including capitalization, and end with .java.

Key Takeaway

A Java program is a collection of classes, with at least one containing a main method to start execution.
