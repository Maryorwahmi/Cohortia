Debugging Common Errors

Navigating compilation and runtime issues in simple Java code.

Compilation Errors

  • Missing Semicolon: Java statements require ;. Compiler will point to the line.
  • Case Sensitivity: Java is strict. hello is not Hello.
  • Filename Mismatch: Public class name must exactly match .java filename.
  • Typographical Errors: Misspelled keywords or variable names.

Example: error: ';' expected

System.out.println("Hello")

Runtime Errors & Logic Issues

  • Forgetting to Recompile: Running an old .class file after changing .java source.
  • print() vs println(): Affects output formatting, not a crash but a logical error.
  • Incorrect Class Name: Using java MyProgram.java instead of java MyProgram.

Example: Old output appears because javac wasn't run.

Key Takeaway

Read compiler messages carefully; they are your first and best debugging tool. Always recompile after changes!
