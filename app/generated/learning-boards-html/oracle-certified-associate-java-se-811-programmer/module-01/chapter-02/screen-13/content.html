Key Concepts

Essential terms from this chapter

javac command

The Java compiler, used to translate .java source code files into .class bytecode files.

java command

The Java launcher, used to execute compiled .class bytecode files via the Java Virtual Machine (JVM).

Source Code / Bytecode

Human-readable .java files vs. intermediate, platform-independent .class files.
