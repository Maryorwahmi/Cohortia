Declaring a Java Class

Defining the container for your Java code.

public class HelloCohortia {
    // ... class content goes here ...
}

Understanding the Declaration

  • public: An access modifier making the class universally accessible.
  • class: Keyword indicating that you are defining a class.
  • HelloCohortia: The name of your class. Must match the .java filename.
  • { }: Curly braces define the scope and body of the class.
Common Mistake

Mismatching the class name with the .java filename (e.g., helloCohortia.java for HelloCohortia class) will cause a compilation error.

Key Takeaway

A class declaration establishes the blueprint for your program, with strict naming conventions for compilation.
