Running Your Java Program

Invoking the JVM to execute your compiled bytecode.

$ java HelloCohortia

Output:

Hello, Cohortia!

The `java` Command

  • Purpose: Launches the Java Virtual Machine (JVM) to execute compiled Java bytecode.
  • Syntax: java YourProgramName (note: no .class extension).
  • Process: The JVM loads the .class file and starts execution from its main method.
  • Result: Your program's output is displayed in the terminal.
Common Mistake

Running java YourProgramName.java or forgetting to recompile after changes will lead to errors or outdated output.

Key Takeaway

The java command is your gateway to executing Java applications, relying on the JVM to interpret bytecode.
