Primitive Types

Integers and Floating-Point Numbers

Explore Java's numeric data types for whole and decimal numbers.

Integer Types (Whole Numbers)

byte

-128 to 127

short

-32,768 to 32,767

int

~-2 billion to ~2 billion (most common)

long

Very large range (append 'L')

Remember 'L' for long literals: long id = 123456789012345L;

Floating-Point Types (Decimal Numbers)

float

Single-precision (append 'f')

double

Double-precision (default)

Remember 'f' for float literals: float temp = 98.6f;
Key Takeaway

Integers (`byte`, `short`, `int`, `long`) handle whole numbers, while floating-point types (`float`, `double`) handle decimals. Use suffixes 'L' for `long` and 'f' for `float` literals.
