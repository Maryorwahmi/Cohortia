Primitive Types

Characters and Booleans

Understand how Java handles single characters and true/false values.

The char Data Type

  • •Stores a single Unicode character.
  • •Enclosed in single quotes (e.g., 'A', '#', '5').
  • •Represents characters from various languages.
Common Mistake: Using double quotes ("A") instead of single quotes ('A').

The boolean Data Type

  • •Stores either true or false.
  • •Fundamental for logical operations and control flow.
  • •No other values are permitted.
Example: boolean isActive = true; or boolean hasPermission = false;
Key Takeaway

char stores single characters in single quotes, supporting Unicode. boolean stores `true` or `false`, essential for program logic.
