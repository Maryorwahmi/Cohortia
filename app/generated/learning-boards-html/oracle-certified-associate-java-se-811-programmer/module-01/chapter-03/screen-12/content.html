Operator Precedence and Associativity

Control the order of operations in complex expressions to ensure correct results.

// Example 1: Precedence
int result = 5 + 3 * 2; // Multiplication (3*2=6) before addition (5+6=11)
System.out.println("Result 1: " + result); // Output: 11

// Example 2: Using Parentheses
int result2 = (5 + 3) * 2; // Parentheses force addition (5+3=8) first, then multiplication (8*2=16)
System.out.println("Result 2: " + result2); // Output: 16

// Example 3: Associativity (Left-to-Right for * and /)
int result3 = 10 / 2 * 5; // (10/2) then *5 => 5 * 5 = 25
System.out.println("Result 3: " + result3); // Output: 25

Rules for Evaluation

  • •Precedence: Operators with higher precedence are evaluated first (e.g., *, / before +, -).
  • •Associativity: For operators with the same precedence, evaluation order is determined by associativity (e.g., left-to-right for arithmetic).
  • •Parentheses (): Always override precedence and associativity, forcing inner expressions to evaluate first.
Common Mistake: Assuming left-to-right evaluation for all operators without considering precedence, leading to incorrect results.
Key Takeaway

Operator precedence and associativity determine evaluation order. Use parentheses to explicitly control the order and avoid common errors in complex expressions.
