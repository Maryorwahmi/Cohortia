Relational and Logical Operators

Compare values and combine boolean expressions to control program flow.

// Relational Operators
int num1 = 10;
int num2 = 20;
System.out.println(num1 == num2); // Output: false
System.out.println(num1 != num2); // Output: true
System.out.println(num1 < num2);  // Output: true
System.out.println(num1 >= num2); // Output: false

// Logical Operators
boolean isAdult = true;
boolean hasLicense = false;
System.out.println(isAdult && hasLicense); // Output: false (Logical AND)
System.out.println(isAdult || hasLicense); // Output: true (Logical OR)
System.out.println(!hasLicense);           // Output: true (Logical NOT)

Operator Types and Behavior

  • •Relational: ==, !=, >, <, >=, <=. Always return a boolean.
  • •Logical: && (AND), || (OR), ! (NOT). Combine boolean expressions.
  • •Short-circuiting: && and || evaluate operands only as needed, improving efficiency.
Pro-Tip: Use short-circuiting to your advantage, for example, checking for null before accessing an object's property.
Key Takeaway

Relational operators compare values to produce a boolean. Logical operators combine boolean expressions, with `&&` and `||` offering short-circuiting for efficiency.
