Type Casting: Converting Data Types

Learn to convert values between different data types, understanding implicit and explicit casting.

// Implicit (Widening) Casting: Smaller to Larger (Safe)
int myInt = 100;
double myDouble = myInt; // int to double, automatic
System.out.println("myDouble: " + myDouble); // Output: 100.0

// Explicit (Narrowing) Casting: Larger to Smaller (Potential Data Loss)
double anotherDouble = 10.99;
int anotherInt = (int) anotherDouble; // double to int, truncates decimal
System.out.println("anotherInt: " + anotherInt); // Output: 10

// Explicit Casting with Overflow/Underflow
int intValue = 200;
byte castedByte = (byte) intValue; // int 200 to byte (-128 to 127)
System.out.println("castedByte: " + castedByte); // Output: -56 (due to overflow)

Casting Types

  • •Implicit (Widening): Automatic, no data loss (e.g., int to double).
  • •Explicit (Narrowing): Requires (type) operator, potential data loss (e.g., double to int).
Common Mistake: Not understanding overflow/underflow with narrowing casts, especially when converting larger integer types to smaller ones.
Key Takeaway

Implicit casting is safe and automatic. Explicit casting requires a cast operator and can lead to data loss or unexpected values due to overflow/underflow if not handled carefully.
