Increment and Decrement Operators

Efficiently increase or decrease variable values by one, understanding prefix vs. postfix behavior.

int i = 5;
int j = i++; // Postfix: j gets 5, then i becomes 6
System.out.println("i: " + i + ", j: " + j); // Output: i: 6, j: 5

int k = ++i; // Prefix: i becomes 7, then k gets 7
System.out.println("i: " + i + ", k: " + k); // Output: i: 7, k: 7

// Decrement example
int count = 10;
int val1 = count--; // val1 is 10, count becomes 9
int val2 = --count; // count becomes 8, val2 is 8
System.out.println("count: " + count + ", val1: " + val1 + ", val2: " + val2); // Output: count: 8, val1: 10, val2: 8

Understanding the Difference

  • •Prefix (++var / --var): Increments/decrements the variable, then uses the new value in the expression.
  • •Postfix (var++ / var--): Uses the variable's current value in the expression, then increments/decrements it.
Common Mistake: Not understanding the order of operations for prefix vs. postfix, leading to incorrect results in complex expressions.
Key Takeaway

Prefix operators modify the variable before its value is used in an expression, while postfix operators use the original value first, then modify the variable.
