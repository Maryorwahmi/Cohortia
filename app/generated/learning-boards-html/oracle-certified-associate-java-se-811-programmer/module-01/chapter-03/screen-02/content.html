01

Differentiate Data Types

Distinguish between Java's primitive types (like `int` and `boolean`) and reference types (like `String`), understanding their fundamental differences in memory handling and behavior. This skill is vital for choosing the correct type for your data and avoiding common errors.

VERIFIED COMPETENCY MILESTONE
02

Declare & Initialize Variables

Master the syntax for declaring variables with specific primitive data types and assigning them initial values. This includes understanding the role of suffixes for `long` and `float` literals, which is essential for accurate data representation.
