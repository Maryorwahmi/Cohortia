Java Variable Naming Conventions

Write clean, readable code by following established naming rules and conventions.

Strict Naming Rules (Compiler Enforced)

  • •Must start with a letter, _, or $.
  • •Cannot start with a number.
  • •Can contain letters, numbers, _, or $.
  • •Cannot be a Java keyword (e.g., int, public).
Violation of these rules will cause a compile-time error.

Common Naming Conventions (Best Practice)

  • •Descriptive: Names should clearly indicate purpose (e.g., customerName).
  • •camelCase for variables: Start lowercase, capitalize subsequent words (e.g., totalAmountDue).
  • •ALL_CAPS_WITH_UNDERSCORES for constants: Use final keyword (e.g., final int MAX_USERS = 100;).
Good conventions improve code readability and maintainability.
Key Takeaway

Adhere to Java's strict naming rules and follow conventions like `camelCase` for variables and `ALL_CAPS` for constants to write clear, professional code.
