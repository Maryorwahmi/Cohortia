Arithmetic and Assignment Operators

Perform mathematical calculations and efficiently assign values to variables.

// Arithmetic Operators
int a = 10;
int b = 3;
System.out.println(a + b); // Output: 13
System.out.println(a / b); // Output: 3 (integer division)
System.out.println(a % b); // Output: 1 (remainder)

double x = 10.0;
double y = 3.0;
System.out.println(x / y); // Output: 3.333... (floating-point)

// Assignment Operators
int counter = 10;
counter += 5; // counter is now 15 (equivalent to counter = counter + 5)
counter *= 2; // counter is now 30 (equivalent to counter = counter * 2)

Operator Details

  • •Arithmetic: +, -, *, /, %.
  • •Integer Division: 10 / 3 results in 3 (truncates decimals).
  • •Modulo (%): Returns the remainder of a division.
  • •Assignment: = (simple), +=, -=, *=, /=, %= (compound shorthand).
Mistake: Expecting decimal results from integer division. Ensure at least one operand is a floating-point type for precise division.
Key Takeaway

Arithmetic operators perform calculations, with integer division truncating decimals. Assignment operators set values, with compound versions offering shorthand for common operations.
