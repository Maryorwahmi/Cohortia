Variable Management

Declaring and Initializing Variables

Learn the syntax for creating and assigning initial values to variables.

// Declaring variables
int age;
double price;
boolean isActive;
char initial;

// Initializing variables (assigning a value for the first time)
age = 30;
price = 19.99;
isActive = true;
initial = 'J';

// Declaration and initialization in one step
String firstName = "Cohortia";
long accountNumber = 123456789012345L;
float temperature = 98.6f;
byte level = 5;

Key Points for Initialization

  • •Variables must be initialized before use to avoid errors.
  • •L suffix for long literals (e.g., 123L).
  • •f suffix for float literals (e.g., 98.6f).
  • •String is a reference type, but often initialized directly.
Mistake: Forgetting 'L' or 'f' can lead to compile-time errors due to default type assumptions.
Key Takeaway

Variables are declared with a type and name, then assigned a value. Combining declaration and initialization is common, but remember suffixes for `long` and `float`.
