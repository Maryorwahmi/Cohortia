Confirming Your Java Installation

Verify your JDK installation and environment variable configuration using simple terminal commands.

Check Java Runtime

Run java -version to confirm the Java Runtime Environment is correctly recognized.

Check Java Compiler

Run javac -version to verify the Java compiler, indicating the JDK is fully functional.

Troubleshooting Tip

If you see "command not found", double-check your PATH variable and ensure you've restarted your terminal.

Terminal Output Examples
$ java -version
openjdk version "11.0.12" 2021-07-20
OpenJDK Runtime Environment (build 11.0.12+7)
OpenJDK 64-Bit Server VM (build 11.0.12+7, mixed mode)

$ javac -version
javac 11.0.12

$ java -version
bash: java: command not found
# This indicates PATH is not set correctly.
Key Takeaway

Successful execution of both java -version and javac -version confirms your Java development environment is fully operational.
