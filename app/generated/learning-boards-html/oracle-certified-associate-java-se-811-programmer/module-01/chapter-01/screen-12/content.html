Setting the JAVA_HOME Environment Variable

JAVA_HOME points to the root directory of your JDK installation, used by many Java-based tools and build systems.

Locate JDK Root Directory

Find the main directory of your JDK installation (e.g., C:\Program Files\Java\jdk-11).

Set JAVA_HOME

Create a new system variable named JAVA_HOME and set its value to this root path.

Why it Matters

Many development tools and build systems rely on JAVA_HOME to find your Java installation, ensuring smooth integration.

Terminal Example (macOS/Linux)
# Edit your shell configuration file (e.g., ~/.zshrc or ~/.bashrc)nano ~/.zshrc
# Add the following line, replacing with your actual JDK root pathexport JAVA_HOME="/Library/Java/JavaVirtualMachines/jdk-11.0.12.jdk/Contents/Home"
# Apply changessource ~/.zshrc
Pro Tip

It's good practice to set both PATH and JAVA_HOME for maximum compatibility with various Java tools and environments.
