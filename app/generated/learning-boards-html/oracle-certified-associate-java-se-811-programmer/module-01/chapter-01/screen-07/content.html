The Java Runtime Environment (JRE)

The JRE is the JVM plus the core Java class libraries and other supporting files, designed solely for running Java applications.

Runtime Components

Includes the JVM, core Java libraries, and other files needed to execute compiled Java programs.

Execution Only

Provides the environment to run existing Java applications; it does not contain development tools.

Real-World Example

Applications like Minecraft often bundle their own JRE to ensure they can run on any user's system without requiring a separate Java installation.
