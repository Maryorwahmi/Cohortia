Setting the PATH Environment Variable

The PATH variable tells your operating system where to find executable files, enabling command-line Java execution.

Locate JDK bin Directory

Find the bin subdirectory within your JDK installation (e.g., C:\Program Files\Java\jdk-11\bin).

Add to PATH Variable

Append this path to your system's PATH environment variable. On Windows, use System Properties; on Linux/macOS, edit shell config files.

Common Mistake

Pointing PATH to the JDK root instead of the bin subdirectory, or not restarting your terminal after changes.

Terminal Example (macOS/Linux)
# Edit your shell configuration file (e.g., ~/.zshrc or ~/.bashrc)nano ~/.zshrc
# Add the following line, replacing with your actual JDK bin pathexport PATH="$PATH:/Library/Java/JavaVirtualMachines/jdk-11.0.12.jdk/Contents/Home/bin"
# Apply changessource ~/.zshrc
Pro Tip

Always restart your terminal or command prompt after modifying environment variables to ensure the changes are loaded correctly.
