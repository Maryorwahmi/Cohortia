SumCalculator.java

public class SumCalculator {
    public static void main(String[] args) {
        int sum = 0;
        for (int i = 1; i <= 10; i++) { // i starts at 1, goes up to 10, increments by 1
            sum += i; // sum = sum + i;
        }
        System.out.println("Sum of numbers from 1 to 10: " + sum); // Output: 55
    }
}

Calculating Sums with `for`

Iterating a known number of times to perform cumulative operations.

Loop Counter

The variable `i` is initialized to 1, acts as the counter, and is incremented in each iteration.

Accumulator Pattern

The `sum += i` statement accumulates the value of `i` in each iteration, building the total sum.

Avoiding Off-by-One

Carefully define the condition (`i <= 10`) to include all desired values and prevent iterating one too many or too few times.

Key Takeaway

`for` loops are highly effective for tasks requiring a fixed number of iterations, such as summing ranges or processing elements by index.
