Avoiding Common Loop Pitfalls

Identify and prevent infinite loops and off-by-one errors.

Infinite Loops

A loop that never terminates because its condition always remains `true`. Often caused by not updating the loop control variable.

int i = 0;
while (i < 5) {
  System.out.println(i);
  // Missing i++; -> Infinite Loop!
}

Off-by-One Errors

A loop iterates one too many or one too few times. Often caused by incorrect comparison operators (`<` vs `<=`) or boundary values.

for (int i = 0; i <= 5; i++) {
  System.out.println(i);
} // Prints 0,1,2,3,4,5 (6 times)
// If only 5 iterations needed (0-4), should be i < 5
Key Takeaway

Always ensure loop conditions eventually become false and carefully check boundary conditions to prevent infinite loops and off-by-one errors.
