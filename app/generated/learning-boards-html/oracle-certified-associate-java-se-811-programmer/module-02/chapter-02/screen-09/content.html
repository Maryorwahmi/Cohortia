The `for` Loop: Definite Iteration

Consolidate initialization, condition, and update for clear, controlled loops.

`for` Loop Structure
for (initialization; condition; update) {
  // Code to execute repeatedly
}
All three parts are managed in a single line for definite iterations.
Initialization

Executed once at the start; typically declares and initializes a loop counter.

Condition

Evaluated before each iteration; if true, the loop body runs.

Update

Executed after each iteration; typically increments or decrements the loop counter.

Key Takeaway

The `for` loop is a compact and readable construct for definite iteration, managing loop control variables efficiently.
