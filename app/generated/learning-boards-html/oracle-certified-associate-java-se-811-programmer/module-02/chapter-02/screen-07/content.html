The `do-while` Loop: Guaranteed First Run

Execute the loop body at least once, then check the condition.

`do-while` Loop Structure
do {
  // Code to execute at least once
  // Must include logic to eventually make 'condition' false
} while (condition); // Condition checked AFTER execution
The condition is evaluated *after* each iteration.
Key Difference

Guarantees the loop body executes at least once, regardless of the initial condition.

Common Use Case

Ideal for menu-driven programs or scenarios where an action must occur before a decision to repeat is made.

Structure

The `do` block comes first, followed by the `while` condition, which must end with a semicolon.

Key Takeaway

The `do-while` loop is a post-test loop, ensuring its body runs at least once before checking the continuation condition.
