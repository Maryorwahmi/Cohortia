MenuExample.java

import java.util.Scanner;

public class MenuExample {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        char choice;
        do {
            System.out.println("
--- Menu ---");
            System.out.println("1. Option A");
            System.out.println("2. Option B");
            System.out.println("3. Exit");
            System.out.print("Enter your choice: ");
            choice = scanner.next().charAt(0);

            switch (choice) {
                case '1': System.out.println("You chose Option A."); break;
                case '2': System.out.println("You chose Option B."); break;
                case '3': System.out.println("Exiting program."); break;
                default: System.out.println("Invalid choice. Please try again.");
            }
        } while (choice != '3'); // Loop continues until '3' is entered
        scanner.close();
    }
}

Interactive Menus with `do-while`

Presenting options and repeating until a specific exit choice.

Initial Display

The `do` block ensures the menu is always shown and a choice is read at least once.

Choice Evaluation

A `switch` statement processes the user's input, directing the program flow based on their selection.

Loop Termination

The `while (choice != '3')` condition ensures the loop repeats until the user explicitly chooses to exit.

Key Takeaway

`do-while` loops are ideal for scenarios where an action must be performed at least once, such as presenting an initial menu or prompt.
