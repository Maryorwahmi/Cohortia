The `while` Loop: Indefinite Iteration

Execute code as long as a condition remains true, checking before each run.

`while` Loop Structure
while (condition) {
  // Code to execute repeatedly
  // Must include logic to eventually make 'condition' false
}
The condition is evaluated *before* each iteration.
When to Use

When the number of iterations is unknown, and the loop should only run if the condition is initially true.

Key Characteristic

The loop body might not execute at all if the condition is initially false.

Caution: Infinite Loops

Ensure the loop body modifies variables that affect the condition, eventually making it false to prevent infinite loops.

Key Takeaway

The `while` loop is a pre-test loop, executing its body only if the condition is true, making it suitable for indefinite repetitions.
