Altering Loop Flow: `break` and `continue`

Exit loops early or skip iterations based on conditions.

The `break` Statement

Immediately terminates the innermost loop (or `switch` statement) and transfers control to the statement following the loop.

for (int i = 0; i < 5; i++) {
  if (i == 3) {
    break; // Exits loop entirely
  }
  System.out.print(i + " ");
} // Output: 0 1 2

The `continue` Statement

Skips the remaining statements in the current iteration of the innermost loop and proceeds to the next iteration.

for (int i = 0; i < 5; i++) {
  if (i == 2) {
    continue; // Skips current iteration
  }
  System.out.print(i + " ");
} // Output: 0 1 3 4
Key Takeaway

`break` provides an immediate exit from a loop, while `continue` allows you to skip the current iteration and proceed to the next, offering flexible control over loop flow.
