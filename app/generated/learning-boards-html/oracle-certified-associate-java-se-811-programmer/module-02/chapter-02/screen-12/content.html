ForEachExample.java

public class ForEachExample {
    public static void main(String[] args) {
        String[] names = {"Alice", "Bob", "Charlie"};
        System.out.println("Names in the array:");
        for (String name : names) { // For each String 'name' in the 'names' array
            System.out.println(name);
        }
    }
}

Processing Arrays with For-Each

Accessing each element in a sequence effortlessly.

Element Variable

The `name` variable automatically takes on the value of each element in the `names` array during iteration.

Collection Source

The `names` array serves as the source of elements, which can be any array or `Iterable` collection.

When to Use

Ideal for simple read-only traversals where the index of the element is not required for the operation.

Key Takeaway

The enhanced `for` loop simplifies array and collection processing, making code more concise and less error-prone for sequential access.
