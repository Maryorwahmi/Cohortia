InputValidator.java

import java.util.Scanner;

public class InputValidator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int number = 0;
        boolean isValid = false;

        while (!isValid) { // Loop as long as input is NOT valid
            System.out.print("Enter a positive integer: ");
            if (scanner.hasNextInt()) {
                number = scanner.nextInt();
                if (number > 0) {
                    isValid = true; // Condition becomes false, loop exits
                } else {
                    System.out.println("Error: Number must be positive.");
                }
            } else {
                System.out.println("Error: Invalid input. Please enter an integer.");
                scanner.next(); // Consume the invalid input to prevent infinite loop
            }
        }
        System.out.println("You entered: " + number);
        scanner.close();
    }
}

Input Validation with `while`

Ensuring user input meets specific criteria before proceeding.

Loop Condition

The loop continues as long as `!isValid` is true, prompting the user until valid input is received.

Validation Logic

Checks if input is an integer and if it's positive. `isValid` is set to true only when both conditions are met.

Preventing Infinite Loops

`scanner.next()` is crucial to consume invalid non-integer input, preventing the loop from re-evaluating the same bad token indefinitely.

Key Takeaway

`while` loops are excellent for scenarios where you need to repeat an action until a specific, dynamic condition is met, such as validating user input.
