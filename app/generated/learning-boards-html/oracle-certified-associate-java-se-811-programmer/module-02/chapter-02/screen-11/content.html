Enhanced `for` Loop: Iterating Collections

Simplify iteration over arrays and collections without explicit indices.

Enhanced `for` Loop Structure
for (DataType element : collectionOrArray) {
  // Code using 'element'
}
Iterates directly over elements, no explicit index needed.
Readability Boost

Makes code cleaner and easier to understand for simple traversals.

No Index Needed

Automatically provides each element, removing the need for manual index management.

Limitations

Cannot modify elements by index, iterate in reverse, or skip elements based on index logic.

Key Takeaway

The enhanced `for` loop simplifies iterating over collections when you only need to access each element sequentially.
