Initialization Method 1

Using the `new` Keyword

Allocate memory and set default values for a fixed-size array.

Syntax

`dataType[] arrayName = new dataType[size];`

Default Values

Numeric types (int, double): 0
Boolean: `false`
Object types (String): `null`

Fixed Size

The `size` specified with `new` determines the array's length permanently.

Key Takeaway

Use `new` when you know the exact number of elements needed and want Java to handle default initialization.

Code Examples:
int[] ages = new int[5]; // {0, 0, 0, 0, 0}
String[] names = new String[3]; // {null, null, null}
boolean[] status = new boolean[2]; // {false, false}

Visualizing Memory Allocation

When you use `new int[5]`, Java reserves a block of memory large enough for five integers. Each slot is then automatically filled with the default value for an integer, which is 0. This ensures that every element has a defined state from the moment the array is created.
