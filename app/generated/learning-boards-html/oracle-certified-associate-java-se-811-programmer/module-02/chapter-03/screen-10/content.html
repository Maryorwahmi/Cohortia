Multi-dimensional Arrays

Arrays of arrays for representing grids and matrices.

Declaration

Use multiple sets of square brackets: `dataType[][] arrayName;`

Initialization (`new`)

`new dataType[rows][columns];` creates a rectangular grid, all elements default to 0/null/false.

Initialization (Literal)

Use nested curly braces: `{{val1, val2}, {val3, val4}}`.

Key Takeaway

2D arrays are powerful for modeling tabular data, accessed by `[row][column]` indices.

Code Examples:
// Declaration
int[][] matrix;

// Initialization with 'new' (3 rows, 4 columns)
matrix = new int[3][4]; // All elements initialized to 0

// Initialization with array literal
int[][] grid = {
{1, 2, 3}, // Row 0
{4, 5, 6}, // Row 1
{7, 8, 9} // Row 2
};

// Accessing an element
System.out.println("Element at [1][2]: " + grid[1][2]); // Output: 6

Visualizing a 2D Array

Imagine a spreadsheet. Each cell has a row number and a column number. A 2D array works similarly, where `grid[1][2]` refers to the element in the second row (index 1) and third column (index 2).
