Initialization Method 2

Using Array Literals

Declare and initialize an array with specific values in one step.

Syntax

`dataType[] arrayName = {value1, value2, ...};`

Implicit Size

The array's size is automatically determined by the number of elements provided in the initializer list.

Cannot Combine

You cannot use `new` with a size and an initializer list simultaneously (e.g., `new int[3] {1,2,3};` is invalid).

Key Takeaway

Array literals are ideal for quickly creating arrays with known, static data sets.

Code Examples:
double[] temperatures = {25.5, 28.1, 22.0, 30.2};
boolean[] flags = {true, false, true};
String[] fruits = {"Apple", "Banana", "Cherry"};

Visualizing Direct Population

With an array literal, you're essentially telling Java: "Create an array and immediately fill these specific values into its slots." The system then allocates just enough memory for those values and places them directly, making it a very direct way to set up your data.
