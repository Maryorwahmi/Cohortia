Declaring Array Variables

Creating a reference to an array object.

Preferred Style

`dataType[] arrayName;` clearly indicates the array holds elements of `dataType`.

C/C++ Style (Compatible)

`dataType arrayName[];` is supported but less common in modern Java code.

Important Note

Declaration only creates a reference variable; it does NOT allocate memory for the array itself.

Key Takeaway

Choose the `dataType[] arrayName;` style for clarity and consistency in your Java code.

Code Examples:
// Preferred style:
int[] numbers;
String[] names;
// C/C++ style (less common):
double temperatures[];
boolean flags[];

Analogy: Empty Container Label

Declaring an array is like labeling an empty container: "This container will hold integers." You've defined its purpose, but the container itself (the array object) doesn't exist yet, nor does it contain any actual integers.
