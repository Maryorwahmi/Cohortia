Array Interaction

Accessing & Modifying Elements

Using zero-based indices to interact with array data.

Zero-Based Indexing

The first element is at index `0`, the second at `1`, and so on. The last element is at `length - 1`.

Access Syntax

`arrayName[index]` is used to retrieve or assign a value.

Common Error: Out of Bounds

Accessing an index outside `0` to `length - 1` will cause an `ArrayIndexOutOfBoundsException`.

Key Takeaway

Always be mindful of array boundaries to prevent runtime errors when accessing elements.

Code Example:
int[] scores = new int[4]; // Array of size 4
scores[0] = 95; // Assign to first element
scores[1] = 88; // Assign to second
scores[3] = 90; // Assign to last

System.out.println("First score: " + scores[0]); // Output: 95
scores[1] = 89; // Modify an element
System.out.println("Updated second score: " + scores[1]); // Output: 89

Visualizing Index Access

Imagine a row of numbered lockers. To put something in or take something out of locker number 2, you go directly to that locker. Similarly, `scores[1]` directly targets the element at the second position in the array, allowing for immediate read or write operations.
