Array Length and Iteration

Discovering array size and looping through elements.

`length` Property

A built-in field (not a method) that stores the number of elements an array can hold.

Traditional `for` Loop

Best when you need to access the index or iterate in a specific order (e.g., reverse).

Enhanced `for` Loop (For-Each)

Ideal for simply processing each element in sequence, without needing the index.

Key Takeaway

Use `array.length` for dynamic iteration, choosing the loop type based on whether you need element indices.

Code Examples:
int[] numbers = {10, 20, 30, 40, 50};
System.out.println("Array length: " + numbers.length); // Output: 5

// Traditional for loop
for (int i = 0; i < numbers.length; i++) {
System.out.println("Index " + i + ": " + numbers[i]);
}

// Enhanced for loop
for (int num : numbers) {
System.out.println("Element: " + num);
}

Why `length` is a field, not a method

Unlike `String.length()`, `array.length` is a public final field. This means it's a constant value directly accessible, reflecting the array's fixed size. It doesn't require a method call because its value is determined at array creation and never changes.
