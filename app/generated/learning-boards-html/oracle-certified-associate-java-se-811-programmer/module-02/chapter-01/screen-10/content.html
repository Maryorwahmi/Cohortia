Common Pitfall

The "Dangling Else" Problem

Occurs when an else statement ambiguously associates with an if statement, often due to missing curly braces.

Ambiguous Code Example
int x = 5;
int y = 10;

if (x > 0)
    if (y > 0)
        System.out.println("Both positive");
else // This 'else' associates with 'if (y > 0)' by default!
    System.out.println("x is not positive");
Key Takeaway

Always use curly braces {} for `if` and `else` blocks, even for single statements, to explicitly define scope and prevent the dangling else problem.

The Rule
  • An else statement always binds to the nearest preceding unpaired if.
  • Indentation does not affect this binding; only curly braces do.
Resolution: Use Curly Braces
if (x > 0) {
    if (y > 0) {
        System.out.println("Both positive");
    }
} else {
    System.out.println("x is not positive");
}
Best Practice

Consistent use of curly braces improves code readability, reduces logical errors, and makes your code easier to debug and maintain for yourself and others.
