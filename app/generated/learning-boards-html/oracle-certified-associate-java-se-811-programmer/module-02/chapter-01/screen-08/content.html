Performance & Safety

Short-Circuiting Logical Operators

&& and || stop evaluating as soon as the result of the expression is known, preventing unnecessary computations and potential errors.

Code Example: Null Check
String myString = null;

if (myString != null && myString.length() > 0) {
    System.out.println("String is not null and not empty.");
} // If myString is null, myString.length() is NEVER evaluated.

myString = "Hello";
if (myString == null || myString.isEmpty()) {
    System.out.println("String is null or empty.");
} // If myString is not null, myString.isEmpty() IS evaluated.
Key Takeaway

Short-circuiting is a vital feature for writing safe and efficient Java code, especially when dealing with potential null references or expensive computations.

How it Works
  • && (AND): If the left operand is false, the right operand is not evaluated.
  • || (OR): If the left operand is true, the right operand is not evaluated.
  • This prevents errors and improves performance by avoiding unnecessary work.
Contrast: Bitwise Operators

The single & (bitwise AND) and | (bitwise OR) operators always evaluate both operands, even if the result is already determined. This can lead to NullPointerExceptions if not used carefully with boolean expressions.

Practical Application

Frequently used in validation logic, such as checking if an object exists AND meets certain criteria, or if any of several conditions are true.
