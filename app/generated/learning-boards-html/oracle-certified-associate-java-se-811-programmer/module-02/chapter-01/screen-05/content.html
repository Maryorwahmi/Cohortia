The `if-else` Statement

Provides an alternative block of code to execute when the preceding if condition is false.

Code Example: Login Scenario
String username = "user";
String password = "wrongpass";

if (username.equals("admin") && password.equals("pass123")) {
    System.out.println("Login successful."); // Executes if condition is true
} else {
    System.out.println("Invalid credentials."); // Executes if condition is false
}

System.out.println("Application continues...");
Key Takeaway

An `if-else` block ensures that exactly one of two code paths will always be executed, providing a complete decision-making structure.

Execution Flow
  • The if condition is evaluated.
  • If true, the if block runs.
  • If false, the else block runs.
  • Only one block ever executes.
Important Note

The else statement must immediately follow an if or else if block. It cannot exist on its own.

Practical Use

Ideal for binary decisions like 'is user authenticated?' (yes/no), 'is number even?' (true/false), or 'is file found?' (found/not found).
