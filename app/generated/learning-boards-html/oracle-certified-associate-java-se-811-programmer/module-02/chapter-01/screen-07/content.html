Boolean Logic

Logical Operators: `&&`, `||`, `!`

Used to combine or negate boolean expressions, enabling more complex conditions within if statements.

Operator Examples

&& (Logical AND)

Returns true if both operands are true.

(age >= 18 && hasLicense)

|| (Logical OR)

Returns true if at least one operand is true.

(isStudent || isTeacher)

! (Logical NOT)

Inverts the boolean value of its operand.

(!isRaining)
Key Takeaway

Use logical operators to combine simple conditions into powerful, expressive boolean expressions that precisely control program flow.

Precedence Rules
  • ! (NOT) has the highest precedence.
  • && (AND) has higher precedence than || (OR).
  • Use parentheses () to clarify intent and override default precedence, e.g., (A && B) || C.
Common Mistake

Confusing logical operators (&&, ||) with bitwise operators (&, |). While bitwise operators can work with booleans, they do not short-circuit, which can lead to unexpected behavior or errors.

Why it Matters

These operators are crucial for implementing complex business rules, validation logic, and user permissions in any application, ensuring precise control over program behavior.
