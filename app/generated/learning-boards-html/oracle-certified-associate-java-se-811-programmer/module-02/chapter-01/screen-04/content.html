Core Concept

The `if` Statement

The if statement allows a block of code to execute only if a specified boolean condition evaluates to true.

Code Example
int age = 20; // User's age

if (age >= 18) { // Condition: age is 18 or older
    System.out.println("Access granted."); // This code runs if condition is true
}

System.out.println("Program continues..."); // This always runs
Key Takeaway

The `if` statement provides a single point of decision, executing its block only when the condition is met, otherwise skipping it entirely.

How it Works
  • The condition must be a boolean expression (evaluates to true or false).
  • If true, the code inside the if block {} executes.
  • If false, the code inside the if block is skipped.
  • Program execution then continues with the statement immediately following the if block.
Common Mistake

Forgetting the curly braces {} for the if block. Without them, only the very next statement after the if line is considered part of the conditional block.

Real-World Analogy

Imagine a security checkpoint: IF you have a valid ticket, THEN you are allowed to enter. If not, you simply cannot proceed through that specific entry point.
