Nested `if` Statements

An if statement contained within another if, else if, or else block, useful for dependent conditions.

Code Example: User Access
boolean isLoggedIn = true;
String userRole = "admin";

if (isLoggedIn) {
    System.out.println("User is logged in.");
    if (userRole.equals("admin")) { // Nested condition
        System.out.println("Welcome, Administrator!");
    } else {
        System.out.println("Welcome, User!");
    }
} else {
    System.out.println("Please log in to continue.");
}
Key Takeaway

Nested `if` statements allow for granular control, enabling conditions to be checked only after a broader, prerequisite condition has been satisfied.

Execution Flow
  • The outer if condition is checked first.
  • If true, the program enters the outer block.
  • Inside, the nested if condition is then checked.
  • This allows for a sequence of dependent decisions.
Readability Challenge

Deeply nested `if` statements can become hard to read and maintain. Consider refactoring complex nested logic into separate methods or using logical operators to flatten conditions where appropriate.

Use Case

Commonly used in scenarios requiring multi-factor authentication, tiered access control, or complex data validation where conditions build upon each other.
