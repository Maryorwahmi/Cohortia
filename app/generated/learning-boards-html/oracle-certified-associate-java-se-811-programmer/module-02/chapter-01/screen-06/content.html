Multi-Path Decisions

The `if-else if-else` Ladder

Allows you to test a series of conditions sequentially, executing the first block whose condition evaluates to true.

Code Example: Student Grading
int score = 85;
String grade;

if (score >= 90) {
    grade = "A";
} else if (score >= 80) {
    grade = "B"; // This block executes for score = 85
} else if (score >= 70) {
    grade = "C";
} else {
    grade = "F";
}

System.out.println("Score: " + score + ", Grade: " + grade);
Key Takeaway

The order of conditions in an `if-else if-else` ladder is critical, as only the first matching condition's block will execute.

Execution Principle
  • Conditions are checked from top to bottom.
  • The first condition that is true executes its block.
  • All subsequent else if and else blocks are skipped.
  • If no if or else if is true, the final else (if present) executes.
Ordering Matters!

Always place more specific or restrictive conditions before more general ones. Incorrect order can lead to logical errors where a broader condition captures values meant for a narrower one.

Analogy

Think of it like a series of gates: you try the first gate. If it opens, you go through. If not, you try the second, and so on, until you find an open gate or reach the last default path.
