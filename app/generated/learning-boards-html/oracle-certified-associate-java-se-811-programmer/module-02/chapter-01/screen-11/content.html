The `switch` Statement

Evaluates an expression and matches its value against case labels to execute specific code blocks.

Basic `switch` Syntax
switch (expression) {
    case value1:
        // Code for value1
        break;
    case value2:
        // Code for value2
        break;
    default:
        // Code if no case matches
        break;
}
Key Takeaway

`switch` statements provide a structured and readable way to handle multiple distinct execution paths based on a single expression's value.

Compatible Types
  • byte, short, char, int (and their wrapper classes)
  • String (since Java 7)
  • enum types
  • Cannot use long, float, double, or boolean.
Case Label Rules

Each case label must be a constant literal (e.g., 1, 'A', "Monday") or an enum constant. Variables are not allowed as case labels.

When to Use `switch`

Ideal for menu selections, state machines, or categorizing data where the decision is based on exact matches of a single variable.
