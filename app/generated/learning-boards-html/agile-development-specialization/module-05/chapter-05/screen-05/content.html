Process Flow
Five Structured Steps
1
Set the Stage
Create psychological safety, state the Prime Directive, and set expectations for outcomes.
2
Gather Data
Collect facts, metrics, timeline events, and feelings to ground discussion.
3
Generate Insights
Analyze patterns and surface root causes rather than symptoms.
4
Decide What to Do
Select one or two concrete, measurable experiments with owners.
5
Close & Track
Add action items to the sprint backlog and review them during the sprint and in the next retrospective.
Example scenario
Late testing caused incomplete stories. Data: three stories blocked due to testing only at the end. Insight: testing deferred, creating a bottleneck. Action: require a definition of ready with test cases and have developers write basic acceptance tests as they code. Owner: development team. Measure: number of stories blocked at the end of the sprint drops to zero.
Key Takeaway

The five‑step flow turns observations into a small number of testable experiments that get tracked and inspected.
