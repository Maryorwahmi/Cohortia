Process
Gathering Data
Collect objective facts and subjective reactions so the analysis phase has firm evidence.
Techniques
  • Timeline reconstruction of notable sprint events.
  • Metrics: blocked stories, cycle time spikes, late testing counts.
  • Silent sticky note brainstorming for feelings and observations.
Example metric
Track how many stories were blocked due to testing at the end of the sprint versus previous sprints to confirm a bottleneck.
Common mistake

Avoid skipping data collection. Jumping straight to solutions often treats a symptom rather than root cause.

Example: Timeline
Create a horizontal sprint timeline and ask contributors to mark events: deployments, blockers, major handoffs, and stakeholder interruptions. Use this to spot clusters that explain delivery variance.
Practical tip
If remote, use a shared board for silent notes, then group items into themes for the insights phase.
