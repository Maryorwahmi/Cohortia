Process
Generating Insights
Use structured analysis to reach root causes, not just surface solutions.
Techniques
  • Five Whys to dig deeper into a symptom.
  • Affinity mapping to create themes from silent notes.
  • Ask: will fixing this remove the symptom? If yes, it’s promising.
Example
Many stories blocked by testing late in the sprint → Why? Testing deferred until the end. Why? No test cases at start. Root cause: lack of definition of ready that includes tests.
Misconception
Choosing many action items feels productive but often dilutes effort. Prefer a few deep experiments tied to root causes.
Analyst prompt
For each theme, ask: what process would have to change for this theme to vanish? That points you to potential experiments.
Key Takeaway

Insights should point to process changes. Target root causes so your experiments have measurable impact.
