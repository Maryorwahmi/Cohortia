Guidance
Rules to protect metrics
Make metrics team-focused, transparent, and paired with hypotheses and experiments. Avoid tying them to individual rewards or punishments.
Rule 1
Use metrics to ask questions, not to assign blame.
Rule 2
Limit metrics to a small, actionable set the team can influence.
Practical ritual
  1. Start each retrospective by picking a metric signal to investigate.
  2. Form a hypothesis about the cause and design a measurable experiment.
  3. Run the experiment for 1–2 sprints, then observe metric changes and learn.
Key Takeaway

Create a short, repeatable learning cycle: observe a metric, hypothesize, experiment, and measure again.
