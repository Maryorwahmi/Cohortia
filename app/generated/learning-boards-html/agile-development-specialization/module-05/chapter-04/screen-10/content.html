Compute velocity from sprint data
Use the last 3 sprints to smooth variability, then divide remaining backlog by that average to estimate sprints to complete.
// Sprint completed story points
sprint1 = 20
sprint2 = 25
sprint3 = 25
sprint4 = 28

// Use last 3 sprints for average
recent = [25, 25, 28]
average = (25 + 25 + 28) / 3  # = 26
remaining = 100
est_sprints = remaining / average  # ≈ 3.85 → plan 4 sprints
Interpretation
Estimate four sprints for 100 story points at an average velocity of 26. Include a buffer for uncertainty and check for a stable velocity before locking forecasts.
Misconception
Treating the forecast as a promise rather than a probabilistic estimate increases pressure and reduces learning.
Key Takeaway

Use averaged velocity for planning, but revisit forecasts regularly as new sprint data arrives and conditions change.
