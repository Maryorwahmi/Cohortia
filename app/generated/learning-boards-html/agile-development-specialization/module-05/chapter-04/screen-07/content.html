Process Flow
Calculate velocity
Sum completed story points per sprint, then average across recent sprints for forecasting.
Code-like example
<!-- Pseudocode for velocity calculation -->
completed = [25, 25, 28]
average_velocity = sum(completed) / len(completed)
# average_velocity = 78 / 3 = 26
remaining_backlog = 100
estimated_sprints = remaining_backlog / average_velocity
# estimated_sprints ≈ 3.85 → plan for 4 sprints
Worked example
Using the sample sprints: Sprint 2 = 25, Sprint 3 = 25, Sprint 4 = 28. Average velocity is 26. For a 100-point backlog, expect about four sprints. Use this as a planning anchor and revisit as new data arrives.
Misuse to avoid
Don’t use velocity to compare teams or reward individuals. Story points are team-specific and relative.
Key Takeaway

Use averaged velocity as a forecast input and combine it with risk assessment and regular inspection.
