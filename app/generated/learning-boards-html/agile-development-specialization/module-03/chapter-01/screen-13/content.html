Experiment design

A clear hypothesis, one variable, and a measurable outcome create useful learning.

Hypothesis
If we limit Doing WIP to two, average lead time will fall by the end of the week.
Metric
Average lead time for tasks; count of completed tasks per week.
Duration
Run the experiment for one sprint or a fixed number of days and record results.
Classroom activity
Design a personal board with To Do, Doing (WIP:2), Blocked, Done. Simulate moving cards and measure lead time for finished items.
Pitfall
Changing multiple variables at once prevents learning. Change one thing and measure.
