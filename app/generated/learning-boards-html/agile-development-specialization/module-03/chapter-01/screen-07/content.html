Six Core Practices

These practices are applied together to convert principles into measurable change.

1. Visualize workflow
Use columns and cards to reveal work and queues.
2. Limit WIP
Set explicit caps on active items to reduce multitasking.
3. Manage flow
Monitor movement and remove blockers to improve predictability.
4. Make policies explicit
Define clear entry and exit criteria for each stage.
5. Implement feedback loops
Use reviews and operations meetings to inspect outcomes and data.
6. Improve collaboratively
Propose small experiments, measure, and learn together.
Concrete example
Create a board, set Doing WIP to two, add an explicit rule for moving to QA, run a weekly delivery review, and test reallocating one tester for a sprint. Measure lead time before and after.
Pro tip
Don’t apply practices in isolation. Visualization without WIP limits rarely changes behavior.
