Learning Objectives

Build practical skills to visualize, limit, and improve your team's flow.

Bloom: Learn → Understand → Apply → Master
01
Explain Kanban origins

Describe how just-in-time manufacturing influenced Kanban and why that matters for knowledge work. VERIFICATION: competency milestone.

02
Name the four principles

State and explain each principle and how it supports incremental change and respect for current roles. VERIFICATION: competency milestone.

03
Describe six practices

Explain visualize workflow, limit WIP, manage flow, explicit policies, feedback loops, and experimental improvement. VERIFICATION: competency milestone.

04
Design a personal Kanban

Create a 3–4 column board, set a WIP limit, and run a short simulation. VERIFICATION: competency milestone.
