Reading a Cumulative Flow Diagram
What to read
  • Vertical distance between lines = WIP for that stage.
  • Horizontal distance between entry and done for same items = lead time.
  • Slope of Done line = throughput over time.
Remember to compare CFD changes with blocked counts or policy changes before making assumptions.
Concrete example
Using the two-week data, In Progress grew from 3 to 20 while Done moved slowly; this signals rising WIP and a likely bottleneck in the middle stages.
Common mistake

Treating cumulative counts as instantaneous throughput. Always use band widths and slopes for the right interpretation.
