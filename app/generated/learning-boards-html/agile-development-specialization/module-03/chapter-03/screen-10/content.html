Module 3 › Chapter 3.3 › Blocked Work

Make blockers visible

Move blocked items to a visible state so they don't consume counted WIP and so someone can own their resolution.

  • Use a 'Blocked' column or a clear marker that excludes the card from WIP counts.
  • Assign ownership for blocker resolution immediately.
  • Track blocked time as a metric to identify recurring external dependencies.
Example

Card awaiting external API: move it to Blocked, assign an owner to contact the API provider, and free the development slot so another card can be pulled.

Key Takeaway

Visible blockers prevent latent WIP and enable the team to act instead of guessing capacity.
