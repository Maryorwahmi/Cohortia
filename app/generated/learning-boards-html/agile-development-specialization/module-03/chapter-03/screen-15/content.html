Module 3 › Chapter 3.3 › Key Concepts
Work In Progress (WIP) Limits
Explicit constraints on the max items in a workflow stage that reduce multitasking and reveal bottlenecks.
Pull System
Work is pulled by available capacity downstream, preventing uncontrolled push-based queues.
Lead Time, Cycle Time, Throughput
Core metrics to measure flow and validate whether WIP changes improved delivery.
Final takeaway

Limit WIP, use pull signals, and measure flow. Experiment in small steps and validate improvements with metrics and visible board changes.
