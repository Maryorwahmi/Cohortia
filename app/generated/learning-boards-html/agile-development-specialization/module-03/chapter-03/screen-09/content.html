Module 3 › Chapter 3.3 › Addressing Bottlenecks

Practical tactics to clear a bottleneck

Swarming

Team focuses on a set of stuck items until they flow through.

Reduce batch size

Smaller work items move faster and reveal problems sooner.

Address blockers

Make impediments visible and act immediately to resolve external dependencies.

Cross-training & automation

Build flexible capacity and free time from repetitive tasks.

Scenario

Code review pile-up: pair-review, create review standards, or schedule focused review windows to clear backlog quickly.

Key Takeaway

Pick one intervention for the top bottleneck, run it briefly, and measure whether queue length and cycle time shrink.
