Module 3 › Chapter 3.2 › What is a Kanban board?
Definition

A Kanban board maps stages of work and the items moving through them, enabling visibility and team coordination.

Why it matters
  • Creates a shared view of work and responsibilities.
  • Highlights bottlenecks so the team can act on them.
  • Supports pull-based flow and continuous improvement.
Example
A checkout integration card is moved to Blocked when API keys are missing; that visibility triggers a dependency callout.
Misconception
The board is not a static status report; it must be updated and used to guide pull decisions.
Visual core
Basic board layout
To Do
Items waiting to be pulled.
Card example: "Design product display page"
Doing
Currently worked items where team focus is applied.
Card example: "Create database schema"
Done
Completed work that’s delivered or released.
Card example: "Implement user registration"
Key Takeaway

Visibility is the primary capability a Kanban board provides; use it to spot bottlenecks and coordinate work.
