Module 3 › Chapter 3.2 › Represent item types
Scannability rules
  • Color-code or icon-code item types (bug, feature, epic).
  • Keep card fields minimal: title, type, owner, short acceptance.
  • Use labels for priority and swimlane membership.
Example
A blocked, high-priority payment bug uses a bug icon, red color, High label, and the note "waiting for API keys."
Avoid overloading cards
If a card requires a long explanation, link to design docs or a ticketing page. Cards are for immediate decision-making, not full specifications.
Key Takeaway

Minimal, colored cards with a priority label help teams scan and act quickly.
