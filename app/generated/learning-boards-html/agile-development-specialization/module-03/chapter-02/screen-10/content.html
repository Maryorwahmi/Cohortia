Module 3 › Chapter 3.2 › Activity: Configure Digital Board
Step-by-step
  1. Create board: name it "E-commerce Website Project".
  2. Add columns: Backlog, Ready for Development, In Development, In Testing, Ready for Deployment, Done, Blocked.
  3. Add cards: implement login, design product page, set up payment gateway, create DB schema, develop cart, write unit tests.
  4. Add labels: Priority (High/Medium/Low). Assign High to registration card.
  5. Simulate: move DB schema to In Development, move payment integration to Blocked with a comment about missing API keys.
Example cards
Card: Implement user registration/login
Type: Story — Priority: High — Owner: Alice
Card: Set up payment gateway integration
Type: Task — Status: Blocked — Note: waiting for API keys
Policy

Define one explicit policy such as: "Unit tests must pass before moving to Code Review."
