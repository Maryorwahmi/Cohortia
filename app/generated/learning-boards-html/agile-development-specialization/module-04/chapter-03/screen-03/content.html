Assessing readiness and anti-patterns

Clear acceptance criteria, appropriate size, and an up-to-date estimate make an item ready for sprint planning.

Ready Item Checklist
  • Clear user outcome
  • Acceptance criteria listed
  • Estimate agreed
  • Small enough for a sprint
Anti-patterns
  • Big-bang grooming before planning
  • Backlog as stakeholder wish list
  • Delegating prioritization without a strategy
Practice prompt

Review a draft story and list missing acceptance criteria or unknowns that would block its readiness.

Concrete example
A payment feature labeled as 'add transfer' is an epic. Refinement splits it into: view balance, internal transfer, confirmation UI. Each resulting story lists acceptance criteria, has an estimate, and can be ordered by value and effort.
Key Takeaway

A healthy backlog combines clarity, right-sized items, and prioritized value. That prevents mid-sprint surprises.
