Value vs. Effort Matrix

Use a simple matrix to decide which items give the best return for the effort.

Example placements
  • High value, low effort: quick UX tweak to balance visibility.
  • High value, high effort: full loan workflow requiring backend and compliance.
Misconception

Avoid static placements; update the matrix as you learn from users and tech spikes.

Practical use

During refinement, place candidate stories into the matrix to highlight quick wins and to inform ordering choices for the next sprint.

Key Takeaway

Use the matrix to surface high-return, low-effort items and to deprioritize expensive, low-value work.
