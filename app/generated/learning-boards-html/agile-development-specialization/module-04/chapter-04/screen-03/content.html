Module 5 › Chapter 4.4 › Learning Objectives
Facilitation Skills
Run Planning Poker with neutral facilitation, anonymous reveal, and focused clarifying questions to surface assumptions.
Role cue: Moderator asks clarifying questions before estimates.
Tip: Encourage independent thinking; avoid early influence.
Improvement Strategies
Use retrospectives to compare estimates to outcomes, refine baselines, and adjust technique when consistent drift appears.
Mnemonic: Plan, Measure, Learn — small experiments to improve estimates.
Alternate Techniques
When early in a project, use T-shirt sizing or Affinity Estimation to quickly group items by relative size before refining with Story Points.
Mnemonic: S, M, L, XL as coarse approximations that later map to point ranges.
Verified Milestones
After practicing, aim to run a Planning Poker round, calculate velocity, and produce a forecast for the next release window.
