Module 5 › Chapter 4.4 › Baseline & Comparison
Choose a baseline
Pick a small, well-understood story the team agrees represents a single point of comparison, like 'Logging in'.
Comparison questions
  • Is this story simpler, similar, or more complex than the baseline?
  • What new dependencies increase risk?
  • Are acceptance criteria clear enough to size consistently?
Facilitation tip

Read the baseline aloud at the start of the session and re-establish it in retrospectives if drift appears.

Sizing example
Baseline 'Logging in' = 3. 'Password reset' similar → 3. 'Product catalog import' with unfamiliar CSV formats and validation → 8. 'Payment gateway integration' with new vendor API and certification → 13.
