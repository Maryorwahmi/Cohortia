Core Concept
Negotiable explained
A story should prompt discussion. Details are refined through negotiation, not fixed in the story text.
This keeps the backlog adaptable and allows the team to propose better technical or UX approaches during refinement.
Scenario
As a rider, I want to pay using my saved card, so that I can complete transactions quickly. The story leaves the gateway choice and retry logic to the team during refinement.
The negotiable part allows the team to pick secure, testable implementation details without constraining design.
Misconception
Thinking negotiable means vague. Negotiation expects clarity, not ambiguity.
Pro tip
If a story is too vague to estimate, add a small discovery spike to learn enough to size it.
