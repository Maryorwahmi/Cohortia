Core Concept
Valuable explained
A story must deliver observable value to a user or stakeholder. The 'so that' clause captures this value.
  • • Clarifies why the work should be prioritized.
  • • Guides acceptance criteria and testing.
  • • Prevents building features nobody uses.
Example
As a customer, I want to reset my password, so that I can regain access to my account if I forget it.
This specifies a clear user problem and a measurable success criterion.
Check
If you cannot state who benefits and how, the story likely lacks value and needs refinement.
