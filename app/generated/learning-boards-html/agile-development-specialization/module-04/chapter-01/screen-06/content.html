Definition
Template broken down
Role (As a): Names the user and their context. Helps the team understand who benefits.
Goal (I want): A clear action or outcome the user seeks. Phrase as what the user wants to achieve.
Benefit (so that): The reason the user cares. Explains value and helps prioritize work.
Misconception: writing the goal as a technical requirement rather than a user action removes meaning from the story.
Example and exercise
As a learner, I want to search courses by title and topic, so that I can quickly find lessons relevant to my goals.
This clarifies who benefits, the user's action, and the practical value of the feature.
Check your understanding
Can you rewrite 'Add a search bar' into the template? Think of the user and the benefit.
Key takeaway
Include all three parts so the team understands user, goal and value.
