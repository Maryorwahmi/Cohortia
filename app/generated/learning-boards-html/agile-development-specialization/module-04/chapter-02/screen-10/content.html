Definition › DoD and Acceptance Criteria
Definition of Done
A shared checklist for quality that applies across stories, such as code review, passing tests, and documentation updates.
Story-level criteria
Acceptance criteria list the specific behaviors needed for the PO to accept a particular story.
Combined value
A clear DoD plus precise acceptance criteria produces consistent, releasable work.
Practical pattern
  • Maintain a stable DoD for quality gates.
  • Write story acceptance criteria for behavior the PO needs to see.
  • Use criteria as evidence during demos and acceptance.
Example
DoD: automated tests present. Story criteria: dashboard redirection and welcome message. Both are required for acceptance.
