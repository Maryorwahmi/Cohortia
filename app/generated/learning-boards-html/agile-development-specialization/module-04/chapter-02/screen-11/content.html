Hands-on Activity › Event Creation Scenarios — Identify
User story
As an event organizer, I want to create a new event, so that I can list it on the platform and allow attendees to register.
Key actions to cover
  • Fill required fields and submit the create form.
  • Validate field errors when required inputs are missing or invalid.
  • Handle date conflicts or invalid date ranges.
Goal
Draft three focused scenarios: success, missing fields, and date conflict.
Guided prompts
  • What must be true before the organizer hits Submit?
  • Which fields are required and what exact error messages should appear?
  • What observable outcome proves the event was created?
Misconception
Don't try to list every validation rule here; pick the ones critical for acceptance and record others for QA testing.
