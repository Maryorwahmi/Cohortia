Hands-on Activity › Event Creation — Scenarios
Suggested Gherkin scenarios
Scenario: Successful Event Creation
Given I am logged in as an event organizer
And I am on the Create Event page
When I fill required fields with valid values and submit the form
Then I should be redirected to my Events dashboard
And I should see the new event title in my Events list
Scenario: Missing Required Fields
Given I am on the Create Event page
When I leave the Title field empty and submit the form
Then I should remain on the Create Event page
And I should see a validation message "Title is required" next to the Title field
Scenario: Invalid Date Range
Given I am on the Create Event page
When I enter an end date that is before the start date and submit the form
Then I should remain on the Create Event page
And I should see an error message "End date must be after start date"
Review checklist
  • Are outcomes observable and exact?
  • Can a tester follow the steps without assumptions?
  • Did you avoid implementation details?
Key takeaway
Clear scenarios speed testing and reduce rework; review them with PO and QA before implementation.
