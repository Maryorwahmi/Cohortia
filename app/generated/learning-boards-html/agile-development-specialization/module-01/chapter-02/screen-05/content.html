Definition

Incremental development

Deliver the product in small, complete, and usable pieces so each increment can be used and tested independently.

Example: Increment 1 = user authentication and basic task creation. It is usable and provides immediate value.
Pitfall
Delivering non-shippable increments—such as only backend or only UI layers—fails to deliver user value.
MVP note
Your first increment should focus on the minimum viable product: the smallest set of features that lets users accomplish a core job and produces feedback you can learn from.
Key Takeaway

An increment must be integrated and usable. If it cannot be released, it is not delivering user value.
