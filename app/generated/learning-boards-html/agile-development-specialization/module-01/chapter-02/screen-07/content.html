Module 1 › Chapter 1.2 › Agile vs Waterfall
Waterfall

Sequential phases, late feedback

  • Phases: Requirements → Design → Implementation → Testing → Deployment
  • Big design upfront; changes are costly after phase completion
  • User feedback typically arrives late in the cycle
Agile

Iterative and incremental, early feedback

  • Deliver small, usable increments frequently
  • Use short iterations to refine based on feedback
  • Adapt priorities and reduce late-cycle surprises
Practical example
A Waterfall plan might implement all backend first, then UI, then integrate. Agile would deliver a single user-facing feature end-to-end and iterate on it. The Agile route finds integration and usability problems earlier and at lower cost.
