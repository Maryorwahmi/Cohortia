Product Vision

A simple online task manager with user authentication, task creation, editing, deletion, categorization, due dates, and notifications.

Increment 1: Core Task Management
Features: user authentication, create task, view tasks, mark complete. Why shippable: users can manage a basic to-do list immediately.
Increment 2: Enhanced Management
Features: edit tasks, delete tasks, due dates. Why shippable: adds management capabilities that improve user workflow without requiring other systems.
Increment 3: Collaboration & Notifications
Features: task sharing, notifications. Why shippable: adds collaboration value and keeps users engaged with timely alerts.

Product Vision: Simple online task manager

Increment 1: Core Task Management
Features:
  - User authentication (login/logout)
  - Create Task (title, description)
  - View All Tasks
  - Mark Task as Complete
Why shippable: Users can authenticate and manage tasks; this provides immediate value.

Increment 2: Enhanced Management
Features:
  - Edit Task
  - Delete Task
  - Due Dates
Why shippable: Improves task workflow and planning; fully integrated with existing data.

Increment 3: Collaboration & Notifications
Features:
  - Share tasks with others
  - Notifications for due dates
Why shippable: Adds collaborative value and engagement features.
Tip: Keep increments vertical so each includes frontend, backend, and tests for the feature to remain shippable.
