Exercise: Sprint Retrospective Summary
Apply the template to the coffee shop sprint problems.
What went well?
Example: Automated tests found critical bugs early.
What could have gone better?
1) UI/API dependencies blocked progress. 2) User stories unclear caused rework. 3) Stand-ups ran over time and felt unfocused.
Commitments
Action 1: Implement API mock servers. Measure: reduce blocked UI tasks by 50%. Owner: backend lead. Action 2: Run 15-minute story refinement before work. Measure: reduce story rework by 25%. Owner: product owner. Action 3: Timebox stand-ups to 15 minutes with rotating facilitator. Measure: stand-ups finish in the timebox 90% of the time. Owner: team lead.
Reflection
Pick one commitment to track immediately. Small wins build momentum for continuing improvements.
Key Takeaway

Concrete, measured commitments with owners are the lifeblood of continuous improvement.
