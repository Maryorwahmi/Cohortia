Practice & Reflection Objectives
Tasks that move knowledge into action and help you spot shallow Agile adoption.
Apply each value to a short project
Use the coffee shop app scenario to write 3–5 sentence plans for each value, showing a concrete example of team action and a success indicator.
Map principles to practices
Create a mapping that links at least three principles to team rituals like demos, stand-ups, or automated testing.
Spotting Agile-in-name-only
Identify one practice that looks Agile but lacks the supporting principle or mindset, and propose one corrective step to align it with the values.
Mnemonic
E.A.R.N
Explain, Apply, Reflect, Next — a quick cycle to practice each objective.
