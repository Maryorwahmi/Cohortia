Module 1 › Chapter 1.1 › Coffee Shop App Activity
Apply the four values to the coffee shop app
A short template and measurable indicators to make values actionable.
Individuals & interactions
Action: Daily 15-minute pairing on the order UI. Example: product owner and developer clarify edge cases before coding. Measure: fewer clarifying tickets after implementation.
Working software
Action: Deliver a minimal 'place order' flow in two weeks. Example: allow a single item with payment stub. Measure: user feedback collected from first ten customers.
Customer collaboration
Action: Weekly demo with the shop owner. Example: owner suggests a loyalty feature. Measure: number of owner-suggested backlog items accepted.
Responding to change
Action: Reserve 20% of each sprint for priority changes. Example: add loyalty points mid-sprint if warranted. Measure: cycle time reduction for high-priority changes.
Misconception
Writing plans for the activity doesn't change behavior; attach indicators and a short review to ensure real change.
Key Takeaway
Make values actionable: one action, one example, one measurable indicator for each value to drive behavior change.
