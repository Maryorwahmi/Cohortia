Module 6 › Chapter 6.2 › Challenges & Anti-Patterns
Anti-Patterns
  • Big-bang rollout: scaled implementation without pilots overwhelms teams.
  • Insufficient training: role confusion when leaders are not coached into new responsibilities.
  • Top-down PI Planning: reduces team ownership and leads to unrealistic commitments.
  • Over-processification: adding artifacts without value creates bureaucracy.
Mitigations
Use pilots, invest in training and coaching, prepare the Program Backlog, and run Inspect & Adapt to iteratively improve the implementation.
Example corrective action
If an ART misses PI Objectives repeatedly, run a focused Inspect & Adapt workshop to identify systemic blockers, then implement targeted experiments in the next PI to resolve root causes.
Key takeaway
Key Takeaway

Treat SAFe as an adaptive framework: pilot, coach, and inspect to evolve the implementation for your context.
