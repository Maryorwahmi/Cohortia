Module 6 › Chapter 6.2 › Program Increment
PI Lifecycle
PI Planning
Two-day event to set objectives, identify dependencies, and build the Program Board.
Iterations
Multiple sprints where teams implement stories and integrate continuously.
System Demo
Integrated demonstration of features across teams to stakeholders.
Inspect & Adapt
Program-level retrospective to identify root causes and improvement actions for the next PI.
Output: PI Objectives
Team and program objectives with business value estimates for the upcoming PI.
Output: Program Board
Visual mapping of dependencies, milestones, and risks across teams.
Benefit
Predictability, earlier integration feedback, and a structured improvement loop at program scale.
