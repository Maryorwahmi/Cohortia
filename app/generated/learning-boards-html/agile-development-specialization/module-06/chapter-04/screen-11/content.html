Module 6 › Chapter 6.4 › IaC, Containers & Orchestration
Flow: code to running service
  1. Write IaC to define networks, databases, and permissions.
  2. Build container image for the application in CI.
  3. Push image to a registry and deploy with orchestration manifests.
  4. Monitor runtime and feed results back to development and operations.
Misconception
Containers do not replace tests. They only package what you build; test coverage and environment parity are still required.
Concrete example
Use IaC to create a VM or cluster, include a manifest that the orchestration platform reads, and let CI build and publish the container image used by that manifest.
Practical steps
  • Keep IaC and deployment manifests in version control.
  • Test IaC changes in ephemeral staging environments.
  • Automate container builds and push to a registry as part of CI.
Key Takeaway

Combine IaC, containers, and orchestration with tests and monitoring to make deployments repeatable and safe.
