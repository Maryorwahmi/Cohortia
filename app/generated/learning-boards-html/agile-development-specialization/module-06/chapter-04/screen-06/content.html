Module 6 › Chapter 6.4 › CALMS — Automation
What to automate
  • Builds and dependency installs
  • Automated tests: unit, integration, end-to-end
  • Container image builds and registry pushes
  • Infrastructure provisioning using IaC
  • Deployments with health checks and rollbacks
Example
A Git push triggers CI: tests run, container is built, image is stored, and a staging deploy runs automated smoke tests before manual approval to production.
Pitfalls
  • Automating poor processes accelerates failure.
  • Missing test coverage creates false confidence.
  • Lack of rollback or health checks makes deploys risky.
Pro tip
Start with small automations, validate them, and evolve the pipeline. Add gates for risky steps.
Key Takeaway

Automate repeatable, error-prone tasks and pair automation with tests and rollback plans to keep deployments safe.
