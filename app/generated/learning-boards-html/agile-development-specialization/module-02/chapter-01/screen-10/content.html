Definition of Done — practical checklist

// Example Definition of Done checklist
- Code implemented and peer-reviewed
- Unit tests written and passing
- Integration tests run in CI
- Documentation updated (user-facing and technical)
- Meets acceptance criteria and security review
- Potentially releasable and deployable
Use this checklist to structure story tasks during refinement and make work visible so no quality step is deferred.
Concrete example

For a login story, the team requires unit tests, end-to-end check, and documentation. They break the story so tests are written as code is developed, avoiding a last-minute testing surge.

Key Takeaway

A living Definition of Done embedded in planning reduces risk and improves predictability.

Pro tip
Review the Definition of Done in every retrospective and update it as the team matures.
