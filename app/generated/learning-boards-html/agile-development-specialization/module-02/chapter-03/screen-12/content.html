Module 3 › Chapter 2.3 › Hands-on

Sprint Goal

Enable users to securely connect and control basic smart devices (lights, thermostats).

Selected items (example)
• Register a new smart light bulb (8 points) • Turn a registered light on/off (3 points) • Secure login (5 points) — total 16 points, within a 15–20 point capacity.
Task breakdown example
Register light bulb tasks: API for device registration; UI for pairing; integration tests. Turn on/off tasks: control API; unit tests.
Template
Sprint Goal: Enable users to securely connect and control basic smart devices (lights, thermostats).

Item: Register a new smart light bulb (Estimate: 8)
  - Task 1.1: Implement device registration API
  - Task 1.2: Build pairing UI flow
  - Task 1.3: Write integration tests for registration

Item: Turn a registered light bulb on/off (Estimate: 3)
  - Task 2.1: Implement control API
  - Task 2.2: Write unit tests for control
Pitfall
Selecting unrefined, high-uncertainty items inflates risk and reduces likelihood of a Done Increment.
Key Takeaway

Choose items that align to the Sprint Goal and break them into clear tasks so the team can forecast and deliver reliably.
