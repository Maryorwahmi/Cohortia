Increment and Definition of Done

DoD defines the quality threshold an Increment must meet to be considered releasable and truly Done.

Increment
Sum of completed backlog items this Sprint plus previous Increments; must be usable regardless of release decision.
Definition of Done
A checklist of required quality practices that create a shared understanding of what Done means.
Enforcement
If an item doesn't meet DoD, it cannot be presented as Done and reverts to the Product Backlog.
Example: DoD checklist
  • • Code reviewed and merged
  • • Automated unit and integration tests passed
  • • Deployed to staging environment
  • • Security and performance sanity checks completed
Common Mistake
A vague DoD allows low-quality increments to hide behind the word "done."
Key Takeaway

Agree a practical, specific Definition of Done and apply it consistently so Increments are genuinely releasable.
