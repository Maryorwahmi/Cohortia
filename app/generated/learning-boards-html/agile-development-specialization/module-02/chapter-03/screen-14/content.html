Assessment scenario

Decide whether partially finished work can be presented as Done according to the team's Definition of Done.

Scenario
Coding and initial testing are complete, but integration and security review required by DoD are not done.
Correct response: Not Done. Missing DoD items must be completed before the Increment can include this feature.
How to grade
Learners should list missing DoD items, explain why each matters, and describe the next steps to move the item back to Done.
Example checklist
Definition of Done (example):
• Code review completed
• Unit and integration tests passing
• Integrated into main branch
• Deployed to staging
• Security review completed
Key Takeaway

Use scenarios to practice identifying missing DoD items and the required remediation steps before accepting work as Done.
