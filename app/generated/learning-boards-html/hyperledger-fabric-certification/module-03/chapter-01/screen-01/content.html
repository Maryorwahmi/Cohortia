Prerequisites for Fabric development

Install and confirm container tooling, language runtimes, and common CLI utilities so Fabric samples and chaincode can run locally without errors.

Core runtime
Docker Engine and Docker Compose to run peers, orderers, CAs and optional databases as containers.
Languages
Go and Node.js for chaincode and client apps; set GOPATH correctly for Go.
Utilities
cURL to download binaries and Git to clone fabric-samples and manage code.
Editor & OS
A good editor like VS Code and an up-to-date OS help prevent compatibility problems.
Explore Key Topics
Docker & Compose
Run multi-container Fabric networks; Compose orchestrates peers and orderers together.
Go & GOPATH
Go compiles chaincode. GOPATH tells Go where to find your workspace and binaries.
Verifying tools
Simple version checks confirm installations and avoid common command-not-found errors.

Why start here?
Installing and verifying these prerequisites prevents the most common early failures when you attempt to run Fabric samples or deploy chaincode. Treat this as the project checklist for a smooth start.
