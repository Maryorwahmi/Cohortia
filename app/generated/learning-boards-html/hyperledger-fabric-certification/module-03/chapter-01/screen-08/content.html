Module 3 › Chapter 3.1 › cURL & Git
cURL

cURL is used in setup scripts to download Fabric binaries and images. It enables scripted, repeatable downloads, which is preferable to manual browser downloads when preparing a dev environment.

Verify
curl --version
Git

Git clones the fabric-samples repository, which includes the test-network and example chaincode you will use. Using Git also enables version control for your own chaincode projects.

Verify
git --version
Practical note

Clone fabric-samples into a directory you control and follow the sample README instructions. Scripted downloads using cURL reduce human error and keep your setup repeatable across machines.
