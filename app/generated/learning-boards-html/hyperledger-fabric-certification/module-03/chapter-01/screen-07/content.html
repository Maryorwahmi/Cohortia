Module 3 › Chapter 3.1 › Node.js & npm
Role comparison
Go
Preferred for high-performance chaincode and strong typing.
Node.js
Popular for client apps and JavaScript chaincode due to rich npm ecosystem.
Verification
node --version
npm --version
Common pitfalls
  • Installing Node but not npm — confirm both commands return versions.
  • Using outdated Node LTS versions may still work, but prefer an LTS recommended by the community for stability.
  • When installing SDK dependencies, run npm install in the project directory so package.json is respected.
Key Takeaway

Confirm both the Node runtime and npm are present when working with JavaScript chaincode or Fabric client libraries.
