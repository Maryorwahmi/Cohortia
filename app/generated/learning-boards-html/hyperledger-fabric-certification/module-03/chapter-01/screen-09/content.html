Module 3 › Chapter 3.1 › Editor & OS
Editor / IDE

Use an editor with language support and an integrated terminal. Features like linting and debugger extensions accelerate chaincode development and client debugging.

OS compatibility

Keep your operating system up-to-date to avoid library and driver issues that can prevent Docker and related tools from running correctly.

Optional: Python

Python 3 may be useful for some utility scripts. Install it if you plan to run Python-based examples, but it is not required for Go or Node.js chaincode workflows.

Key Takeaway

A modern editor and updated OS reduce incidental errors and speed development; install Python only if your workflow requires it.
