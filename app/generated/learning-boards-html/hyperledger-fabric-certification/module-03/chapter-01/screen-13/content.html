Sample question 1

A developer runs a compose up command and receives a message that the command is not found. What is the most likely cause and the corrective steps?

Ideal response
  1. Verify docker-compose version to confirm presence.
  2. Install Compose or add it to PATH if missing.
  3. Rerun the version check to confirm the fix.
Sample question 2

Why is setting GOPATH important when building Go chaincode, and what happens if it is unset?

Ideal response

GOPATH points to the Go workspace where code and binaries are stored. If unset, go get and go build may fail to find packages, preventing compilation of chaincode. Set GOPATH and add its bin to PATH, then re-run the build.

Assessment tip

When answering, describe the verification commands you would run and attach the captured outputs. Demonstrating the diagnostic steps is as important as the final fix.
