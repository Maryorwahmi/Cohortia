01. Identify prerequisites
Verified competency milestone

List the required software components and confirm which are missing. This prevents blocked runs when you start Fabric samples.

02. Explain tool roles
Verified competency milestone

Describe why Docker is used, why Compose is helpful, and why language runtimes matter for chaincode and clients.

03. Verify installations
Verified competency milestone

Run version checks for Docker, Compose, Go, Node, npm, cURL and Git. Record outputs to confirm compatibility.

04. Troubleshoot common issues
Verified competency milestone

Apply basic troubleshooting steps for missing binaries, PATH problems, or an unset GOPATH so you can build chaincode successfully.

How to use these objectives

Work through the verification activity to practice the commands that check each tool. When you encounter an error message, note it and refer to the troubleshooting steps in later lessons. These objectives help you move from identifying tools to applying fixes and documenting your working environment.

Mnemonic
D-G-N: Docker, Go, Node — the core stack to check first.
Tip
Capture terminal output screenshots for each verification command; these are useful for troubleshooting later.
