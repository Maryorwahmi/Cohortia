Module 3 › Chapter 3.1 › Go & GOPATH
Why Go

Go is commonly used for Fabric chaincode because it compiles to fast binaries and presents strong typing. For chaincode development you need a compatible Go runtime installed and a workspace where your chaincode and dependencies live.

GOPATH explained

GOPATH is an environment variable that points to your Go workspace where go get, go build and other tools expect to find source and binaries. If it is unset, you may see errors when fetching or compiling packages.

Common mistake

Not setting GOPATH or forgetting to add GOPATH/bin to PATH causes go get or go build failures. Double-check your shell profile.

Quick verification
go version echo $GOPATH # on Linux/macOS echo %GOPATH% # on Windows CMD
Interpretation
  • Go version confirms runtime availability.
  • The GOPATH echo command shows your workspace location; set it if empty.
  • Add GOPATH/bin to PATH so installed tools are executable from your shell.
