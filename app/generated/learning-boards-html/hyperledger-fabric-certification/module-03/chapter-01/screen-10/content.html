Module 3 › Chapter 3.1 › Common Pitfalls
Symptom → Likely cause
  • "command not found" — PATH not set or binary not installed.
  • Docker errors about daemon — Docker service is not running or user lacks permissions.
  • Go build errors about packages — GOPATH unset or dependencies missing.
  • npm missing — incomplete Node install or PATH issue.
Fix strategy
  1. Run version checks in order and capture outputs.
  2. Address the first failing tool before proceeding to the next.
  3. Document changes to PATH or system services so you can reproduce the setup later.
Pro tip

When asking for help, include the exact version outputs you captured; they often reveal the root cause immediately.
