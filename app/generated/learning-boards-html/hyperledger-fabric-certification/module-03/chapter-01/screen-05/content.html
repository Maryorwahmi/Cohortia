Module 3 › Chapter 3.1 › Verify Docker
Checks to run
docker --version
docker-compose --version
docker info
Interpretation
  • If you see version strings, the binaries are present.
  • Docker info shows the daemon status and running containers; errors here indicate the service needs to start.
  • Compose must be compatible with your Docker Engine; older Compose can fail with complex Fabric compose files.
Troubleshooting
  • "Command not found" — check PATH and installation directories.
  • Daemon errors — start the Docker service or confirm permissions for the current user.
  • Compose compatibility — install a Compose version at or above the minimum recommended for your Fabric samples.
Pro tip

If installations succeed but networks fail to start, first confirm Docker info shows the daemon healthy before debugging Fabric-specific errors.
