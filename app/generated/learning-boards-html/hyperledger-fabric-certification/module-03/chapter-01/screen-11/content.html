Module 3 › Chapter 3.1 › Verification Activity
Commands to run
docker --version
docker-compose --version
docker info

go version
echo $GOPATH   # Linux/macOS
# or
# echo %GOPATH%  # Windows CMD

node --version
npm --version

curl --version
git --version
What to capture
  • Copy the version lines for each tool into a verification file.
  • Note any error messages verbatim; they are critical for troubleshooting.
  • Retake the check after making a correction to confirm the fix worked.
Example result

A successful run will show Docker and Compose versions, Go and Node versions, and outputs for cURL and Git. If any command fails, use the troubleshooting guide to resolve it before continuing.

Key Takeaway

Document each verification step. Evidence of correct versions prevents wasted debugging time later when running Fabric networks.
