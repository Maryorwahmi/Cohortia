Verification checklist
  1. Confirm Docker is installed and the daemon is running.
  2. Confirm Docker Compose is present and at a compatible version.
  3. Run Go version check and ensure GOPATH is set for your workspace.
  4. Confirm Node and npm versions to manage JavaScript chaincode and clients.
  5. Check cURL and Git for downloading binaries and cloning samples.
Troubleshooting quick steps
  • If a command is not found, check the PATH and installation directory.
  • If Docker commands fail, ensure Docker daemon/service is running and you have proper permissions.
  • If Go build fails, verify GOPATH and that required packages are reachable.
Recording results

Capture version outputs or take screenshots. When you open fabric-samples later, these artifacts help confirm compatibility. Save outputs with a timestamp and brief notes about the host OS.

Mnemonic
V-CHECK: Verify, Capture, Check PATH, Help when needed.
Common mistake
Assuming installed equals available on the PATH. Always run the version command to confirm.
