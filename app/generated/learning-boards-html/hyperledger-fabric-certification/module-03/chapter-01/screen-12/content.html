Module 3 › Chapter 3.1 › Troubleshooting
Issue: command not found
Likely caused by a missing binary or PATH not updated. Fix by locating the binary and adding its directory to your shell profile, then open a new terminal and re-check.
Issue: Docker daemon errors
Start the Docker service, ensure it runs, and verify your user permissions. After starting the daemon, re-run the Docker info check to confirm readiness.
Issue: Go build failures
Confirm GOPATH is set and dependencies are available. If using modules, follow the sample instructions. Re-run go build and verify that the compiler finds required packages.
Checklist

Address one failing check at a time, capture outputs before and after fixes, and document steps taken so fixes are repeatable on other machines.
