Module 3 › Chapter 3.2 › Verification
Terminal checks

Confirm daemon health and Compose availability

# Check daemon and system info
docker info

# Run a small test container to verify pull and run
docker run hello-world

# Verify Compose
docker-compose --version
Interpreting results
  • If docker info returns an error, check systemctl status docker or the Desktop logs to find why the daemon is not reachable.
  • Successful hello-world output shows the image pulled and the container executed correctly.
  • If docker-compose is missing, install the binary on Linux or confirm Desktop includes it on macOS/Windows.
Example output
A successful hello-world run prints a confirmation message from the test container. Capture that output as proof for the lab.
Check your assumptions

Do not assume a GUI icon equals a fully healthy daemon. Use the CLI checks to be certain.
