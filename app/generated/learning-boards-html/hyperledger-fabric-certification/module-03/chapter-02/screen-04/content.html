Definition

Docker Engine and Docker Compose

Engine executes containers and provides networking and storage. Compose defines multi-container applications so you can start a Fabric network consistently.

Analogy
Think of Engine as the engine in a car and Compose as the blueprint for a fleet of cars working together.
Example
A Fabric test network uses Compose to start peers and an orderer with one command; Engine actually runs each container.
Key takeaway
You will need both: Engine to run containers and Compose to manage multi-container Fabric deployments.
Common misconception
Compose is not a runtime. If Compose fails to start containers, inspect the Engine status and logs; Compose depends on Engine to function.
Quick reference
Engine command
docker run hello-world
Compose command
docker-compose up
Key Takeaway

Compose defines the network; Engine runs it. Confirm both before starting Fabric components.
