Installing Docker and Docker Compose

Set up Docker Engine and Docker Compose so Fabric peers, orderers, and CAs run reliably across Linux, macOS, and Windows.

16:9 HD Classroom
In this lesson
Install engine, install Compose, verify runtime
Why it matters
Fabric components run as containers; a stable install avoids later failures.
Visual concept
Docker Engine
Runs containers
Docker Compose
Orchestrates multi-container apps
Verify
Run hello-world
Explore Key Topics
Install Docker Engine
Add GPG key, add repo, install packages, start and enable the daemon.
Install Docker Compose
Desktop bundles Compose on macOS/Windows; Linux often needs the binary placed in /usr/local/bin.
Verify & Troubleshoot
Run hello-world, docker info, check daemon, and confirm group permissions.
Quick Checklist
  • Engine installed and daemon running
  • Compose available
  • Linux user in docker group
  • hello-world runs successfully
What you will need
A terminal with administrative rights for install steps, access to your OS settings for WSL 2 or Hyper-V on Windows, and network access to pull images for the hello-world test.
