Final checklist
Daemon & service
Confirm docker daemon is active and enabled to start on boot so Fabric services persist across restarts.
Compose
Confirm docker-compose --version or the Desktop-bundled Compose is present and matches expected syntax for Fabric definitions.
No sudo on Linux
Verify docker ps and docker run hello-world work without sudo after adding your user to the docker group and restarting your session.
Hello-world test
A successful hello-world run confirms the Engine can pull images and execute containers — a minimal but essential validation.
Key Takeaway

Completing this checklist reduces environment errors when you deploy Fabric, saving time and avoiding common pitfalls.
