Step-by-step
Linux (example)
Run repository setup and apt install, add user to docker group, log out and log back in, then verify with hello-world and docker-compose --version.
macOS
Install Docker Desktop via .dmg, launch it, then run docker run hello-world in the terminal to verify.
Windows
Install Docker Desktop, enable WSL 2 backend if possible, launch, then run hello-world in a WSL shell or PowerShell.

Why this matters
These outputs confirm your environment can pull images, run containers, and has Compose available for multi-container Fabric networks.
