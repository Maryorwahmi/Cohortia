Module 3 › Chapter 3.2 › Learning Objectives
Bloom Progression
01
Install Docker Engine
Perform a stable engine install on Linux, macOS, or Windows and start the daemon so containers can run.
VERIFIED COMPETENCY MILESTONE
02
Install Docker Compose
Confirm Compose is available; on Linux, place the binary in a PATH and mark it executable.
VERIFIED COMPETENCY MILESTONE
03
Configure docker group
Add your Linux user to the docker group so Docker CLI runs without sudo and avoid permission errors.
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot installs
Use docker info, systemd status, and hello-world output to diagnose daemon, permission, and backend issues.
VERIFIED COMPETENCY MILESTONE
Mnemonic
Think: Engine, Compose, Group, Verify — a four-step checklist before running Fabric networks.
Practice
Follow the lab commands for your OS and capture the hello-world and docker-compose version outputs to prove readiness.
Progress bar represents preparedness for Fabric experiments after completing these objectives.
