Process

Install Docker Engine on apt-based systems

Follow these sequential steps to ensure a stable engine install and avoid missing dependencies.
  1. 1. Update package index and install prerequisites such as curl and ca-certificates.
  2. 2. Add Docker's official GPG key and create /etc/apt/keyrings for the keyring.
  3. 3. Configure the stable repository with the distribution codename and architecture.
  4. 4. Install docker-ce, docker-ce-cli, containerd.io, and optionally Docker Compose plugin.
  5. 5. Start and enable the docker service with systemctl to persist across reboots.
Key Takeaway

Follow the repository setup steps exactly so package versions align with your kernel and container runtime.

Commands (example)
<!-- Example commands shown visually. Adapt for your distro. -->
sudo apt update
sudo apt install ca-certificates curl gnupg lsb-release
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl start docker
sudo systemctl enable docker
Misconception
Skipping the enable step leaves the daemon inactive after a reboot. Start and enable make the service persistent.
