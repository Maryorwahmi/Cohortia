Module 3 › Chapter 3.2 › Key Concepts
Docker Engine
Runtime that executes containers; verify with docker info and hello-world.
Docker Desktop
Bundled installer for macOS and Windows that includes Engine, CLI, and Compose.
WSL 2 / Hyper-V
Windows backends for Docker Desktop; WSL 2 is preferred for performance and integration.
Summary
Verify Engine, Compose, and backend settings with the CLI before deploying Fabric components to avoid common setup failures.
