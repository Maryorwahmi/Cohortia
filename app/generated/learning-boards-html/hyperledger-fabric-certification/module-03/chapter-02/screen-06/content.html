Module 3 › Chapter 3.2 › Compose on Linux
Walkthrough

Download and install Docker Compose binary

Use the official release matching your OS and architecture. Place the binary in a PATH directory and set executable permissions.

Common pitfall
Forgetting to mark the file executable or placing it outside a PATH causes "command not found" errors even after download.
Key Takeaway

Always verify docker-compose --version after installing the binary to confirm it is executable and on PATH.

Commands (example)
sudo curl -L "https://github.com/docker/compose/releases/download/v2.20.2/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
# Verify
docker-compose --version
Example explanation
The curl command downloads the correct binary for the kernel and CPU, chmod makes it executable, and the version check confirms success.
