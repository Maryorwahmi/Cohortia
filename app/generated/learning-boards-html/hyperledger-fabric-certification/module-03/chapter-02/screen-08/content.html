Module 3 › Chapter 3.2 › Desktop Comparison
macOS
Install flow
Download the .dmg, drag Docker to Applications, launch. The Desktop app starts the daemon and bundles Compose.
Verification
Check the whale icon in the menu bar and run docker run hello-world to validate.
Windows
Install flow
Run the Desktop installer. Prefer WSL 2 backend for better performance. Ensure a WSL distribution like Ubuntu is installed.
Common issue
Not enabling WSL 2 or selecting the wrong backend is a frequent cause of Docker Desktop failing to start.
Pro Tip
Regardless of OS, run docker run hello-world and docker-compose --version to confirm both engine and compose are available to the CLI.
No GUI assumptions — validate with the terminal.
