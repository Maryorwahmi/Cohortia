Module 3 › Chapter 3.2 › Key Commands
docker info
Show daemon status, containers, images and storage driver for diagnostics.
docker run hello-world
A minimal runtime test that confirms image pull and container execution.
docker-compose --version
Confirm Compose is installed and returns a version string compatible with Fabric compose files.
Permission check
On Linux verify your user is in the docker group by running docker ps without sudo. If permission is denied, add the user and restart your session.
