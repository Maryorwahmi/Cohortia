Module 3 › Chapter 3.2 › Docker Group
Definition

Add your user to the docker group

Grant your user permission to access the Docker socket and run CLI commands without sudo for smoother development workflows.

Why it matters: Fabric scripts often execute Docker commands. If those scripts assume non-root access, missing group membership causes permission denied errors and failed automation.
Caution

Adding a user to the docker group grants control over containers and can affect host security; apply this in trusted environments.

Command (example)
sudo usermod -aG docker $USER
# Then log out and log back in, or reboot. After that:
docker run hello-world
Misconception
Expecting immediate effect without logging out is the most common source of frustration. Group membership is applied at session start.
