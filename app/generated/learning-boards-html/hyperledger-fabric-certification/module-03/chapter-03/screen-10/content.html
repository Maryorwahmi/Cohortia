Module 3 › Chapter 3.3 › OS Comparison
Linux / macOS
  • Extract Go tarball to /usr/local
  • Edit ~/.bashrc or ~/.zshrc to export GOPATH and PATH
  • Install nvm with the install script and use nvm install to get LTS
echo $GOPATH
go version
node --version
Windows
  • Use MSI installer for Go and official Node installer or nvm-windows
  • Create a system variable GOPATH and add %GOPATH%\bin to Path
  • Restart the shell or log out to apply system Path changes
go version
echo %GOPATH%
node --version
