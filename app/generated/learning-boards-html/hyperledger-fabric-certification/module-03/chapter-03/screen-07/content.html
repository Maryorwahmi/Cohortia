Module 3 › Chapter 3.3 › Go Hello World
main.go
package main

import "fmt"

func main() {
  fmt.Println("Hello, Fabric")
}
Run: go run main.go — you should see the printed line.
Build: go build — produces a local binary you can run directly.
Install: go install — binary appears in $GOPATH/bin for global use.
Expected terminal session
$ go run main.go
Hello, Fabric
$ go build
$ ls -la
-rwxr-xr-x  1 you  staff  123456 Sep 1 12:00 main
after build: ./main
Key Takeaway

This small cycle proves Go tooling, build path, and PATH visibility for installed binaries.
