Terminal checklist
Commands to run during the lab
# Verify Go
go version
# Verify GOPATH
echo $GOPATH
# Use nvm to install Node.js
nvm install 16
nvm use 16
# Verify Node and npm
node --version
npm --version
Keep these commands handy while you work through the hands-on activity.
Tip

Use a version manager for Node.js so projects with different LTS requirements do not conflict.

Watch out

Forgetting to add $GOPATH/bin to your PATH is a common source of "command not found" errors after installing Go tools.
