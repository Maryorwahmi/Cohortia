Module 3 › Chapter 3.3 › Practical Skills

Four practical outcomes

Profile edits
Add GOPATH and append /usr/local/go/bin and $GOPATH/bin to PATH in ~/.bashrc or ~/.zshrc, then source the file.
nvm and Node
Install nvm, then install an LTS Node.js version and make it the default with nvm alias.
Windows checks
Use MSI installers and set system GOPATH and add %GOPATH%\bin to the Path variable in system settings.
Verification
Confirm with go version, echo $GOPATH, node --version, and npm --version and capture terminal output for assessment.
