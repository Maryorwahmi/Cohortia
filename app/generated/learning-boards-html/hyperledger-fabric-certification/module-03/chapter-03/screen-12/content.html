Module 3 › Chapter 3.3 › Lab Checklist
Step-by-step
  1. Install Go and add /usr/local/go/bin to PATH.
  2. Set GOPATH=$HOME/go and add $GOPATH/bin to PATH, then source your profile.
  3. Install nvm, then install and use an LTS Node version.
  4. Verify go version, echo $GOPATH, node --version, npm --version.
Example verification commands
go version
echo $GOPATH
node --version
npm --version
# Run examples
go run main.go
node index.js
Check

If any verification command fails, re-check PATH and that you sourced your profile or restarted the shell before moving on.
