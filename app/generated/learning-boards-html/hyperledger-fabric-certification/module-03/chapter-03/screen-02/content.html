Learning Objectives

Learn, understand, apply, and master environment setup for chaincode and client tooling.

Learn
Understand

Master
01
Install and configure Go
Set GOPATH and add Go binaries to PATH so compiled chaincode and tools are discoverable by the shell.
Mnemonic: GOPATH = workspace, PATH = find tools
VERIFIED COMPETENCY MILESTONE
02
Install Node.js and npm
Prefer a version manager so you can install and switch LTS versions for different Fabric projects.
Mnemonic: nvm = many nodes
VERIFIED COMPETENCY MILESTONE
03
Verify installations and versions
Use go version, node --version, and npm --version to confirm correct installations and PATH visibility.
Mnemonic: check the versions before you build
VERIFIED COMPETENCY MILESTONE
04
Manage versions for Fabric compatibility
Align your Go and Node.js versions with Fabric release notes and sample requirements to avoid subtle incompatibilities.
Mnemonic: match the runtime to the release
VERIFIED COMPETENCY MILESTONE
