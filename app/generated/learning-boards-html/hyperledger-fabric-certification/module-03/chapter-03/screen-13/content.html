Module 3 › Chapter 3.3 › Troubleshooting
Scenario: command not found
Symptom: command not found: go. Cause: go binary directory not in PATH. Fix: add /usr/local/go/bin to PATH and source your profile. Verify with go version.
Scenario: Node version mismatch
Symptom: project fails with runtime errors. Cause: wrong Node.js LTS version. Fix: use nvm to install and switch to the required version, then reinstall dependencies. Verify with node --version and npm --version.
