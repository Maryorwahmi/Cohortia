Module 3 › Chapter 3.3 › Verify Go
Verification commands
go version
go env GOPATH
echo $GOPATH
Expected outcomes: go version shows installed version; go env GOPATH and echo $GOPATH return the workspace you set.
Common issues and fixes
  • If go version returns "command not found", add /usr/local/go/bin to PATH and reload your shell.
  • If go env GOPATH differs from your expected workspace, export the desired GOPATH in your profile and source it.
  • Remember to include $GOPATH/bin in PATH so installed executables are runnable.
Key Takeaway

Verifying immediately after install saves time—capture outputs for reproducibility and assessment.
