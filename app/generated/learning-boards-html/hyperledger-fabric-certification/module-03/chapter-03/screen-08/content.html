Module 3 › Chapter 3.3 › Install Node.js with nvm
nvm install flow
# Install nvm (check for latest script)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.1/install.sh | bash
# Then restart the terminal
nvm install 16
nvm use 16
nvm alias default 16
# Verify
node --version
npm --version
Why this matters
  • Switch Node versions quickly to match Fabric samples or project dependencies.
  • Avoid breaking global Node installs when testing multiple projects.
  • nvm isolates versions per shell session, reducing side effects.
Key Takeaway

Prefer nvm on Linux/macOS for safe, flexible Node version management; consider nvm-windows or the installer on Windows.
