Module 3 › Chapter 3.3 › Installing Go
Installation steps (Linux/macOS)
Extract the tarball to /usr/local and make sure /usr/local/go/bin is added to PATH.
# Example: extract a tarball on Linux/macOS
sudo tar -C /usr/local -xzf go1.16.7.linux-amd64.tar.gz
# Then add to your shell profile
export PATH=$PATH:/usr/local/go/bin
Note: The installer typically does not set GOPATH. Set GOPATH yourself to a workspace like $HOME/go.
Verify: run go version and expect a version string to appear.
Installation steps (Windows)
Use the MSI installer. Then set a system GOPATH and add %GOPATH%\bin to the Path environment variable if needed.
# Verify Go on Windows (CMD)
go version
echo %GOPATH%
Key Takeaway

Installation must be followed by PATH updates and verification commands to avoid invisible runtime errors.
