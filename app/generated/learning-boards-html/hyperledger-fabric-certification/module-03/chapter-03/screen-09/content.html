Install a package
# Inside your project
npm init -y
npm install --save fabric-network
After installation, check node_modules and the package.json dependencies to ensure the library was added.
Common pitfall
If npm is missing or the wrong version, installs may fail or produce lockfiles that others cannot reproduce. When switching Node versions with nvm, re-run npm install to ensure native modules match the runtime.
Key Takeaway

Treat npm as part of the runtime; verify it and be mindful that it changes with Node versions managed by nvm.
