Module 3 › Chapter 3.3 › GOPATH
Definition

GOPATH points to your Go workspace where source, packages, and installed executables live. It complements but does not replace modules for source management.

Typical setting examples:
# Linux/macOS ~/.bashrc or ~/.zshrc
export GOPATH=$HOME/go
export PATH=$PATH:$GOPATH/bin:/usr/local/go/bin
# Windows (set as system variable)
# GOPATH = C:\Users\YourUser\go
# add %GOPATH%\bin to Path
Example
After setting GOPATH and PATH, install a tool and run it from the shell.
go install github.com/example/tool@latest
# executable appears in $GOPATH/bin and can be run directly
tool --help
Common mistake: forgetting to export $GOPATH/bin to PATH — tools then appear installed but cannot be run.
