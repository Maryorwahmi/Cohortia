Module 3 › Chapter 3.3 › Version Management
Practical guidance
  • Check Fabric release notes for supported Go and Node.js versions before setting up a project.
  • Use nvm to switch Node versions for different projects without reinstalling globally.
  • Install and test the specified Go version when a sample explicitly references it.
Misconception
Newer language versions will always be compatible. In practice, API changes or module differences can break older code. Match the runtime to the project's expectations.
