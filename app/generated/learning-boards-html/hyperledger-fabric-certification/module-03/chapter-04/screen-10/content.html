Understanding the bin directory and bootstrap script
Bootstrap populates binaries after clone to keep the repo lightweight and release-aligned.
Why bin is empty
Binaries are large and release-specific. The bootstrap script downloads or places executables into bin only when you run it, ensuring they match the branch and expected runtime.
Practical check
After clone, run ls fabric-samples/bin. If empty, run the repository bootstrap.sh following the README instructions and verify peer and orderer appear.
Pro tip
Read bootstrap.sh comments to understand downloaded versions or alternate flags for different releases.
Key Takeaway

Run bootstrap only after confirming the release branch so bin contains the correct executables for network scripts to call.
