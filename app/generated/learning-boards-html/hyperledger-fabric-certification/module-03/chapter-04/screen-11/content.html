Hands-on: cloning and initial exploration (activity)
Follow these commands and verify the outputs for a reproducible start.
Commands to run
mkdir -p ~/fabric-dev
cd ~/fabric-dev

# Clone a stable release
git clone https://github.com/hyperledger/fabric-samples.git --branch release-2.5

cd fabric-samples
ls -F

# Check test-network
cd test-network
ls -F

# Verify bin is empty
ls -F ../bin
After running these commands, take a screenshot of the terminal showing git clone and the ls output. Save it for verification in lab submission or self-check.
Common mistake
Forgetting --branch often leads to incompatible scripts; rerun clone with the correct branch if this occurs.
Key Takeaway

A quick terminal snapshot showing clone and ls output is valuable evidence of a correctly prepared workspace.
