Inspecting test-network
Locate network.sh and supporting folders to prepare for bring-up.
Expected contents
  • network.sh — orchestration script to create, deploy, and teardown the network.
  • organizations/ — MSP, certificate, and identity configuration for peers and orderers.
  • configtx/ and scripts/ — configuration templates and helper utilities.
Open network.sh and look for descriptive comments that explain each step before running it.
Concrete example
Inside network.sh you'll find steps that call peer binaries to create a channel, join peers, and deploy chaincode. Reading the script reveals required inputs and environment variables.
Common mistake
Attempting to run network.sh before installing Fabric binaries or running bootstrap leads to missing command errors.
Key Takeaway

Scan orchestration scripts first to understand dependencies and the order in which network resources are created.
