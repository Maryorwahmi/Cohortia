Ten-step terminal walkthrough to prepare your workspace
Follow each step to ensure a consistent lab environment.
  1. Create a dev directory and cd into it.
  2. Run git clone with the --branch flag for your target release.
  3. cd fabric-samples and run ls -F or dir.
  4. Confirm bin is empty after clone.
  5. cd test-network and list contents to find network.sh.
  6. Open network.sh to review deployment steps.
  7. Find a chaincode sample and read its README.
  8. Note commercial-paper and first-network for further study.
  9. Capture a terminal screenshot for verification.
  10. If errors occur, verify you used the correct release branch.
Concrete command examples
mkdir -p ~/fabric-dev
cd ~/fabric-dev
git clone https://github.com/hyperledger/fabric-samples.git --branch release-2.5
cd fabric-samples
ls -F
cd test-network
ls -F
Pro tip
Take a quick screenshot of the ls output. It documents your starting state and helps when you troubleshoot script errors.
Key Takeaway

A short checklist keeps your workspace consistent and makes later network bring-up predictable.
