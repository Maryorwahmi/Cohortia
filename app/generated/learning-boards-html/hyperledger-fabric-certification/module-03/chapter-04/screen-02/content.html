Learning Objectives
Practical skills to clone, inspect, and prepare the fabric-samples repository for labs.
Bloom: Learn → Understand → Apply → Master
01
Clone fabric-samples safely
Run git clone with --branch to pull a release that matches your Fabric binaries. This ensures scripts will run as expected.
VERIFIED COMPETENCY MILESTONE
02
Navigate repository layout
Identify test-network, chaincode, and helper scripts so you can target the right files for labs or deployments.
VERIFIED COMPETENCY MILESTONE
03
Recognize chaincode examples
Locate chaincode in Go, Node.js and Java to choose an example that matches your development skills for deployment practice.
VERIFIED COMPETENCY MILESTONE
04
Understand bin and bootstrap
Know that bin holds Fabric executables after running the provided bootstrap script so network scripts can call peer and orderer commands.
VERIFIED COMPETENCY MILESTONE
