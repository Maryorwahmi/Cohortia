Comparing example folders: test-network vs first-network
Choose the right example to match your learning goals.
test-network
  • Minimal, scripted orchestration with network.sh.
  • Ideal for rapid labs and certification walkthroughs.
  • Simpler organizations and Docker Compose usage.
first-network
  • Older, more verbose setup demonstrating manual configuration steps.
  • Useful for deep dives or historical understanding.
  • Can be more fragile with newer binaries unless updated carefully.
Key Takeaway

Start with test-network for labs; consult first-network later for legacy patterns or advanced configuration examples.
