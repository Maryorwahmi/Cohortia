What is fabric-samples and why it matters
A curated sandbox of networks, chaincode, and tooling for local development.
Repository contents at a glance
  • test-network: minimal Docker Compose based network and orchestration scripts to bring up peers, orderers, and CAs.
  • chaincode: multiple sample smart contracts in Go, Node.js, and Java for deployment practice.
  • bin: placeholder for Fabric executables populated by bootstrap.sh; empty after clone.
  • commercial-paper / first-network / fabcar / asset-transfer-basic: curated examples ranging from introductory to advanced scenarios.
Concrete example
Open chaincode/asset-transfer-basic and review language subfolders and README to understand how the sample models asset creation, transfer, and query operations.
Tip: read a sample README before running scripts to know expected prerequisites.
Key Takeaway

Treat fabric-samples as your lab sandbox: read readmes, pick a release, and run test-network to learn by doing.
