Module 3 › Chapter 2.6 › Deploy & Activate
Deploying Network Components
Use Docker Compose for development or Kubernetes for production to start orderers, peers, and CAs.
Channel lifecycle
Create a channel with the generated channel transaction, then have peers join using peer channel join.
Chaincode lifecycle
Package, install, approve per org, and commit the chaincode definition to activate it across the channel.
Example sequence
Create channel mychannel, join peer0.org1 and peer0.org2, install chaincode on both, approve by org admins, commit the chaincode definition, then invoke it to validate endorsements.
Common-mistake
Incorrect environment variables or file paths prevent peer CLI commands from finding MSP directories or connecting to the peer endpoint.
