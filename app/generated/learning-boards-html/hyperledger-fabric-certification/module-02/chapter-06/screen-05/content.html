Module 3 › Chapter 2.6 › Proposal & Endorsement
Transaction Proposal
Contents: function, args, channel ID, client signature (X.509).
Client example
Prepare a createAsset invocation with asset ID and owner fields, sign with client certificate before sending to endorsing peers.
Endorsing peer behavior
Verify client signature, execute chaincode simulation, produce read/write set, and sign the proposal response to create an endorsement.
Common-mistake

Expecting a peer to commit state during endorsement. Endorsement only simulates and attests; commit happens after validation.

Read/Write Set Example
Read: asset:ID -> version 5. Write: asset:ID owner -> "Org2". The read version is carried forward so later VCC can detect intervening writes.
