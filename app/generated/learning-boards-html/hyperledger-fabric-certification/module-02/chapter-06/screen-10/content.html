Module 3 › Chapter 2.6 › Generating Crypto
cryptogen (development)
Produces X.509 certificates, keys, and MSP directories based on a crypto-config.yaml definition.
# Example cryptogen command
cryptogen generate --config=./crypto-config.yaml --output=./organizations
Self-reflection
After running cryptogen, what directories appear under ./organizations? Where are the MSPs for Org1 and Org2 located?
Common-mistake

Running cryptogen but then using a different FABRIC_CFG_PATH or wrong file paths for subsequent commands causes mismatched artifacts.

Example: crypto-config.yaml snippet
Define Orderer and PeerOrgs with names, domains, and counts. cryptogen reads this file to produce identities and MSP folder structure.
