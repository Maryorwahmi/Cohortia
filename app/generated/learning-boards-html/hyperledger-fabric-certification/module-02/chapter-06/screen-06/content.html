Assemble endorsements
Bundle: proposal + endorsements + client signature.
// Pseudocode representation
proposal = { chaincode: 'asset', fcn: 'transfer', args: ['A','B', '10'], channel: 'mychannel' }
endorsements = [signedResp1, signedResp2]
transaction = { proposal, endorsements, clientSignature }
submitToOrdering(transaction)
Misconception

Ordering does not check endorsements or run chaincode. It only sequences transactions into blocks.

Example: two-org policy
If the policy requires Org1 and Org2, the client must collect at least one endorsement signed by a peer from each organization before submission. If one endorsement is missing, the transaction will fail endorsement policy validation later.
