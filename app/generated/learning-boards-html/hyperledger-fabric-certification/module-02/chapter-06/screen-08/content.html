Validation Steps
Each transaction is checked for correct endorsements and unchanged read versions before writes are applied.
1. Endorsement policy validation
Confirm endorsements are from required organizations and peers per the chaincode policy.
2. Version Concurrency Control (VCC)
Compare read-set versions captured during endorsement with current state versions to detect concurrent updates.
Important

Even invalid transactions are recorded on the blockchain to preserve an immutable audit trail; they simply do not change state.

Example: concurrent update
If peer A endorses a transfer using read version v5, but another transaction updates the same key and commits before this block is processed, the VCC check will detect the mismatch and mark the transaction invalid.
