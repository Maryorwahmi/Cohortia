Module 3 › Chapter 2.6 › Key Concepts — Part 1
Transaction Flow
The end-to-end steps a transaction follows, from client proposal to final ledger commitment.
Transaction Proposal
Client-created request containing chaincode invocation, arguments, and the client's signature.
Endorsement
A peer's signed proposal response attesting to the read/write set produced by chaincode simulation.
Summary
These terms help you trace and validate who did what and why a transaction is accepted or rejected.
