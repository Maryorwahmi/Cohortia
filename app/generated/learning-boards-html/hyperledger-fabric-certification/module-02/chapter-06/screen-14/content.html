Module 3 › Chapter 2.6 › Security & Maintenance
Operational security
Treat private keys and MSP artifacts as sensitive secrets. Use secure storage and backups.
Backups and runbooks
Regularly back up crypto material and channel artifacts. Maintain documented recovery steps for node or data loss.
Best practice

Use Fabric CA for production to support certificate lifecycle management, rotation, and revocation workflows.

Example: unsafe shortcut
Copying admin private keys between machines speeds testing but creates a single compromise point. Avoid this in any shared or production environment.
