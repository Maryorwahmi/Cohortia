configtxgen commands
Create the genesis block and channel transactions using profiles defined in configtx.yaml.
# Generate genesis block for the orderer
configtxgen -profile TwoOrgsOrdererGenesis -outputBlock ./system-genesis-block/genesis.block

# Generate channel create transaction
configtxgen -profile TwoOrgsChannel -outputCreateChannelTx ./channel-artifacts/channel.tx -channelID mychannel

Anchor peer updates
Generate an anchor peer update per org with configtxgen to advertise discovery endpoints on the channel.
FABRIC_CFG_PATH mistake
If FABRIC_CFG_PATH is not set to the directory with configtx.yaml, configtxgen will not find Profiles and will fail or emit incorrect artifacts. Always export the config path before running configtxgen.
