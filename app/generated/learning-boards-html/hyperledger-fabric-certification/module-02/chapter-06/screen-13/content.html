Module 3 › Chapter 2.6 › Common Failures
Frequent setup issues
A practical checklist to find likely causes quickly.
  • Missing or mislocated MSP directories after running cryptogen.
  • FABRIC_CFG_PATH or other environment variables pointing to wrong directories.
  • Firewall or host reachability preventing peers/orderers from connecting.
  • Endorsement policy referencing orgs not present on the channel.
Quick workflow

Check MSPs, verify env vars, inspect peer/orderer logs for signature errors, and confirm endorsement policy membership.

Example: FABRIC_CFG_PATH error
If you export FABRIC_CFG_PATH pointing to the wrong folder, configtxgen will not find profiles and will fail to generate a valid genesis block. The fix is to export the correct path and re-run configtxgen so artifacts embed the correct MSP references.
