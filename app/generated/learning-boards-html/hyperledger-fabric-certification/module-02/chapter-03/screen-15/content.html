Key Concepts — Practical
Commands and checks to recall quickly
ENV VARS
Set FABRIC_CA_CLIENT_HOME to the intended MSP directory and FABRIC_CA_CLIENT_TLS_CERTFILES to the CA TLS cert before operations.
VERIFY
After enrollment run ls on keystore and signcerts to confirm private key and certificate files were created.
SECURITY
Protect private keys, secure CA admin credentials, and back up root CA certs and CRLs to maintain trust.
Final takeaway
Small configuration mistakes can break trust. Verify environment variables, MSP contents, and CA trust anchors before rolling out identities.
