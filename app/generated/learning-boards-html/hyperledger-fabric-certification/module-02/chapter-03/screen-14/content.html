Key Concepts
Three compact reminders
Summary
Certificate Authority (CA)
Trusted issuer that signs X.509 certificates for identities.
X.509 Certificate
Standard certificate format containing subject, public key, issuer, validity, and signature.
Membership Service Provider (MSP)
Defines trusted root and intermediate CAs, CRLs, and validation rules for an organization.
Summary takeaway
CA issues, certificates attest, MSPs trust. Secure private keys and back up root CA certificates to maintain network trust.
