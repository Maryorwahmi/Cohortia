Definition
X.509 Certificate Structure
Key fields you will inspect when troubleshooting identity verification.
  • Subject: distinguished name for the identity (e.g., CN or organizational units).
  • Public key: used to verify signatures from the holder.
  • Issuer: the CA that signed the certificate.
  • Validity: not before / not after dates; expired certs fail validation.
  • Signature: CA signature proves issuance.
Practical checks
  1. Ensure the certificate chains to a root CA present in the MSP cacerts.
  2. Confirm the certificate’s validity window covers the current time.
  3. Confirm the public key in the certificate matches the local keystore when applicable.
Example location: signcerts/appUser1-cert.pem stored inside the user MSP after enrollment. If peers reject a signature, check issuer chain and whether the MSP includes the correct root certificate.
