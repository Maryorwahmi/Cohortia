Process Flow
Register → Enroll
1. Registration
Admin creates an identity record with attributes and an enrollment secret. No certificate is issued yet.
Mnemonic: file a request at the passport office.
2. Enrollment
Entity uses the enrollment secret to authenticate to the CA and receives an X.509 certificate and private key.
Mnemonic: present your request and get the passport.
Result
An MSP folder containing keystore, signcerts, cacerts, and other MSP artifacts for the identity.
Example CLI sequence is shown in the next lesson. Remember: registration requires admin rights and enrollment is done by the entity with the secret.
Misconception check: registration does not produce keys or certificates; it only creates an enrollment secret used in enrollment.
