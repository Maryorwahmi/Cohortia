Tool walkthrough
Administrator: Register a user
fabric-ca-client register --id.name appUser1 --id.secret appUser1pw --id.type client --id.affiliation org1.department1 -u http://localhost:7054
This command creates an identity record and enrollment secret; it must be run by an admin against the CA.
User: Enroll to obtain certs
fabric-ca-client enroll -u https://appUser1:appUser1pw@localhost:7054
After enrollment you will find keystore and signcerts in the FABRIC_CA_CLIENT_HOME MSP directory.
Operational hint: set FABRIC_CA_CLIENT_HOME to the admin MSP before register, then set it to the new user’s MSP path before enroll. Failing to switch places keys and certificates in the wrong folders.
