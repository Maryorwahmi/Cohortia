Definition
Certificate Authority (CA)
Trusted issuer that signs X.509 certificates, forming the root of identity verification.
  • Issues certificates tying a public key to an identity.
  • Signs certificates with its private key; verification uses the CA’s public certificate.
  • May publish certificate revocation lists to revoke trust for compromised certs.
Example: An Org1 administrator registers appUser1. The CA records attributes and provides an enrollment secret. When appUser1 enrolls, the CA issues an X.509 certificate signed by the CA’s key.
Fabric CA features
Integration
Designed to issue Fabric-compatible X.509 certificates.
Registration & Enrollment
Supports two-step identity creation: admin registers; entity enrolls.
CRLs
Supports certificate revocation lists to remove trust.
Intermediate CAs
Allows structuring trust with intermediates beneath a root CA.
Misconception check: not every CA is automatically trusted; the organization’s MSP must include the CA’s root certificate to accept issued identities.
