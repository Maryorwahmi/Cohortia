Learning Objectives — Practical
Verify MSP structure and apply security best practices
Inspect MSP directory
  • Locate keystore/ — contains private key file used for signing.
  • Locate signcerts/ — contains the issued X.509 certificate for the identity.
  • Locate cacerts/ — contains trusted root CA certificates for the MSP.
Mnemonic: keystore = wallet, signcerts = passport, cacerts = country registry.
VERIFIED COMPETENCY MILESTONE
Security checklist
  • Never commit private keys or keystore files to version control.
  • Back up root CA certificates; losing them prevents verification.
  • Use CRLs to revoke compromised certificates and update MSP configs when necessary.
Common mistake: Using one org’s MSP for another org’s identities will cause verification failures.
