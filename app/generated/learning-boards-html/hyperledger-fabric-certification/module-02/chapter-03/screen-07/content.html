Architecture
Membership Service Provider
MSP bundles define trusted root CAs, intermediates, CRLs, and optional OU rules for an organization.
cacerts/
Trusted root CA certs for the org.
intermediatecerts/
Optional intermediate CAs.
crls/
Certificate revocation lists to remove trust.
When a certificate is presented, Fabric validates the signature, ensures the certificate chains to an MSP root, and checks CRLs and optional OU rules. This lets each organization assert its own trust roots while participating in channels with others.
Operational note
When adding or changing trusted CAs, update the channel configuration so other participants will accept new certificates. Failing to distribute new root certs causes verification failures.
Common mistake

Using one org’s MSP for another org causes authentication failures because their trusted root CAs differ.
