Hierarchy
MSP Directory Example
cacerts/
Trusted root CA certificate files used to validate chains.
signcerts/
Contains the identity’s issued certificate file (PEM).
keystore/
Contains the private key file used for signing.
intermediatecerts/
Optional intermediate CA certificates when present.
crls/ and config.yaml
CRLs revoke trust; config.yaml may map organizational units and roles.
Key Takeaway

After enrollment, verify keystore and signcerts are present and that cacerts contains the expected root for the org.
