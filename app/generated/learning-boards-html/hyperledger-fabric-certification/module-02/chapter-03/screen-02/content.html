Learning Objectives
Learn → Understand → Apply → Master
01
Explain Certificate Authorities
Describe how a CA issues X.509 certificates binding identities to public keys and why that trust matters for authentication and non-repudiation.
Mnemonic: Passport office issues passports.
VERIFIED COMPETENCY MILESTONE
02
Understand X.509 certificates
Identify certificate fields, the role of signatures, and how certificates and private keys are used for authentication in Fabric.
Mnemonic: Certificate = passport data page.
VERIFIED COMPETENCY MILESTONE
03
Describe MSPs and trust roots
Explain what an MSP contains, including root and intermediate CAs, CRLs, and optional OU rules, and why an MSP defines an organization.
Mnemonic: MSP = country's immigration policy.
VERIFIED COMPETENCY MILESTONE
04
Register and enroll identities
Become able to run fabric-ca-client register and fabric-ca-client enroll to produce an MSP folder containing keystore and signcerts for a new user.
Mnemonic: Register (file record) → Enroll (get passport).
VERIFIED COMPETENCY MILESTONE
