Practical setup
Admin environment example
export FABRIC_CA_CLIENT_HOME=${PWD}/organizations/peerOrganizations/org1.example.com/users/Admin@org1.example.com/msp
export FABRIC_CA_CLIENT_TLS_CERTFILES=${PWD}/organizations/fabric-ca/org1/tls-cert.pem
export FABRIC_CA_CLIENT_URL=https://localhost:7054
These variables ensure register runs as admin and the client trusts the CA’s TLS certificate.
Verify generated MSP
ls -F ${PWD}/organizations/peerOrganizations/org1.example.com/users/appUser1@org1.example.com/msp
ls -F ${PWD}/organizations/peerOrganizations/org1.example.com/users/appUser1@org1.example.com/msp/keystore/
ls -F ${PWD}/organizations/peerOrganizations/org1.example.com/users/appUser1@org1.example.com/msp/signcerts/
Expected output shows keystore and signcerts directories with files created after enrollment.
Troubleshooting tip: if enrollment fails, confirm TLS cert path and FABRIC_CA_CLIENT_HOME, then inspect CA logs for authentication or TLS errors.
