Module 2 › Chapter 2.2 › Key Concepts
Ordering Service
Collects endorsed transactions, sequences them, forms blocks, and broadcasts to peers.
Consensus (Raft)
Raft provides leader-follower replication and crash fault tolerance for ordering.
Block & Genesis
Blocks bundle ordered transactions; genesis contains initial channel configuration and orderer endpoints.
Takeaway

A correctly configured, healthy ordering service is essential for a distributed ledger to remain consistent across peers.
