Comparison

Solo vs Kafka vs Raft

Solo
Single-node, used for development and testing. No fault tolerance; not for production.
Kafka (historical)
Provided CFT via an external Kafka cluster. Added external dependency and operational complexity.
Raft (EtcdRaft)
Leader-follower replication inside Fabric. CFT, automatic leader election, simpler operations than Kafka.
Fault tolerance math
Use N = 2F + 1. For example, N=5 tolerates F=2 failures. Deploy the number you need for your availability target.
Operational note
More nodes increase fault tolerance but also replication overhead; choose topology with both goals in mind.
