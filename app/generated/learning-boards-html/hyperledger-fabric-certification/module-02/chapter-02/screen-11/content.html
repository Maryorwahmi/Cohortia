Hierarchy

From configtx.yaml to genesis

Define orderer endpoints, TLS certs, batch settings, and policies in configtx.yaml. Run configtxgen to produce the genesis block used to bootstrap the ordering service for a channel.
# Example conceptual command
configtxgen -profile SampleSingleMSP -outputBlock ./genesis.block -channelID system-channel
Checklist before genesis
  • Confirm Orderer endpoints and advertised names match deployment.
  • Confirm TLS certificate paths and names are correct.
  • Decide batch size and timeout based on throughput and latency needs.
Practical tip

Generate and inspect the genesis block contents if orderers fail to join the channel; mismatched endpoints or certs are frequent causes.
