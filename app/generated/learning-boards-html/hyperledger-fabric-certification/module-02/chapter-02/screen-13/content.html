Troubleshooting scenario

Peers show divergent ledgers; ordering seems inconsistent. How do you diagnose and fix it?

Diagnosis steps
  1. Inspect orderer logs for Raft replication or election errors.
  2. Compare genesis and configtx Orderer endpoints to deployed nodes.
  3. Search logs for TLS handshake or certificate errors.
Remediation
  • Fix certificate references and restart orderers carefully.
  • Ensure node count meets N = 2F + 1 for desired tolerance.
  • Monitor logs to confirm a stable leader and resumed block creation.
Assessment prompt

Explain which logs and configuration files you would inspect and why, then outline the steps to restore consistent ordering.
