Module 2 › Chapter 2.2 › What the Ordering Service Does
Definition

Ordering service responsibilities

Collect, sequence, block, sign, and broadcast transactions. It is purely about ordering, not execution.

Key role
Ensure all peers receive the same ordered transactions so validation yields identical ledgers.
Common misconception
Orderers do not evaluate or apply transactions; peers perform validation and state updates after block delivery.
Analogy
Railway station model
Clients are passengers boarding trains (transactions). The orderer is the timetable maker that fixes departure order so every station records the same arrivals.
Practical example
Two organizations submit conflicting updates to the same key. The orderer chooses a single order; peers then validate and apply changes in that order, producing the same result everywhere.
Key Takeaway

Separation of concerns: orderers ensure order, peers ensure correctness and state changes.
