docker logs orderer.follower1.example.com -f

# Observe election and new leader messages in logs
This exercise shows election behavior and validates that ordering resumes. Note any errors about TLS or unreachable endpoints that would impede election or replication.
Expected log signs
  • Follower timeout detected, starting election.
  • Vote requests and responses between peers.
  • New leader elected and leader heartbeat resumes.
Reflection

After an election validate that peers resume receiving and validating blocks; this confirms the cluster tolerates the simulated failure.
