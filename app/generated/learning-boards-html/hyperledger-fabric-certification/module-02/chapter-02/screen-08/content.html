Terminology

Blocks and genesis

Blocks group ordered transactions; the genesis block contains initial channel configuration, including orderer endpoints and policies.
Config tool
Use configtxgen with configtx.yaml to produce the genesis block and channel config transactions used to bootstrap orderers and channels.
Practical checks
Compare the Orderer section in configtx.yaml, the generated genesis block, and the orderer startup logs to ensure endpoints and TLS certificates match deployed nodes.
Key Takeaway

Correct genesis and channel configuration are prerequisites for orderers to form a healthy Raft cluster and to deliver blocks to peers.
