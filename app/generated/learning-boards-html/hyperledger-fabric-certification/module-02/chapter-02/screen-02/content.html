Learning Objectives

Skills you'll gain and how to show competency.

Bloom: Learn → Understand → Apply → Master
01
Describe the ordering service

Explain how orderers sequence transactions and broadcast blocks so all peers share a consistent ledger. This helps you detect ordering faults causing ledger divergence.

VERIFIED COMPETENCY MILESTONE
02
Explain ordering and ACID guarantees

Relate how a consistent sequence preserves atomicity, consistency, isolation and durability for transaction outcomes across peers.

VERIFIED COMPETENCY MILESTONE
03
Compare ordering implementations

Contrast Solo, Kafka, and Raft, focusing on Raft’s leader-follower model and its CFT trade-offs for production networks.

VERIFIED COMPETENCY MILESTONE
04
Trace ordering lifecycle

Follow a transaction from client endorsement, to ordering, block creation, and delivery, including genesis and channel config steps.
