# Search for Orderer and EtcdRaft

cat docker/docker-compose-test-net.yaml | less
# Search for orderer.example.com

# View orderer logs
docker logs orderer.example.com 2>&1 | less
# Look for Raft, leader election, block, channel
These commands let you map configuration to runtime behavior. When checking logs, note entries mentioning leader election and block creation to confirm healthy ordering activity.
What to look for in logs
  • Messages confirming Raft membership and leader identity.
  • Entries showing blocks being created and signed.
  • Errors about TLS handshakes or unreachable endpoints indicating misconfiguration.
Tip
If you intentionally stop the leader, watch remaining orderer logs to see the election and subsequent leader announcements — this validates Raft behavior.
