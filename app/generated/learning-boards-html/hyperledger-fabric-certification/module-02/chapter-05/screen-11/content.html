Network Topology

Anchor peers and peer discovery

Anchor peers provide stable, discoverable endpoints that help peers from different organizations find each other and exchange blocks over gossip. When you update channel membership, you must also update anchor peer entries so new peers can be discovered.

  • Anchor peer update: a channel configuration change to register anchor peer addresses.
  • Gossip discovery: uses anchor peers to bootstrap cross-org connections.
  • Verification: after updating anchors, check gossip logs and peer channel list to confirm connectivity.
Key Takeaway

Anchor peers are essential for cross-organization gossip; include anchor updates in onboarding and verify connectivity to avoid replication gaps.

Operational checklist
  1. Add anchor peer config when adding organizations.
  2. Sign and submit the anchor peer update like other config changes.
  3. Verify with peer logs that gossip connections are established.
  4. Test cross-org transactions to confirm block dissemination.
