Comparison

What channels isolate vs what remains shared

Isolated: ledger & state
Transactions and world state for a channel are visible only to that channel’s members.
Shared: ordering & infra
Ordering nodes, networks, or other infrastructure can be shared across channels, producing separate block streams per channel.
Chaincode scope
Chaincode must be approved and committed on each channel where its logic will operate; installing alone does not grant access to a channel’s state.
Scenario
Two channels, A and B, both use the same orderer. A transaction on channel A is contained in channel A’s blocks and is never visible in channel B. Still, both channels can be delivered by the same orderer process.
Design question: to share selected data across channels, you could replicate events out-of-band or use application-layer sharing; each option affects confidentiality and complexity.
Key Takeaway

Channels provide logical ledger isolation; shared infrastructure does not imply shared data.
