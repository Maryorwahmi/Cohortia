Operational checklist

Concrete tasks for channel creation, signing, and peer join verification.

Generate channel transaction

Use configtxgen with the correct profile and channel ID to create a channel configuration transaction artifact for administrators to sign.

VERIFIED COMPETENCY MILESTONE
Collect signatures & submit

Ensure authorized admins sign the transaction before submission to the ordering service to avoid config rejection.

VERIFIED COMPETENCY MILESTONE
Peer join & verify

Retrieve the genesis block, run peer channel join, then list channels on each peer to confirm membership.

VERIFIED COMPETENCY MILESTONE
Anchor peers & gossip

Update anchor peer entries after adding organizations to maintain peer discovery and cross-org communication.

VERIFIED COMPETENCY MILESTONE
Each milestone should be verified using peer channel list, and by testing chaincode endorsement on the new channel.
