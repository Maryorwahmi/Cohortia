Module 2 › Chapter 2.5 › Create mychannel2 (Activity)

Step sequence

  1. Start the test network with certificate authorities.
  2. Export FABRIC_CFG_PATH and run configtxgen with TwoOrgsChannel to create mychannel2.tx.
  3. Set peer environment for Org1 admin and run peer channel create to produce mychannel2.block.
  4. Use peer channel join with the block on peer0.org1 and peer0.org2 after setting their envs.
  5. Run peer channel list on both peers to confirm membership.
Expected outputs include success messages for create and join and membership listed by peer channel list. If TLS or MSP paths are wrong, commands will error with permission or TLS validation messages.
Example commands
# generate channel tx
configtxgen -profile TwoOrgsChannel -outputCreateChannelTx ./channel-artifacts/mychannel2.tx -channelID mychannel2

# create channel (Org1 admin environment assumed)
peer channel create -o localhost:7050 --ordererTLSHostnameOverride orderer.example.com -c mychannel2 -f ./channel-artifacts/mychannel2.tx --tls --cafile "${PWD}/organizations/ordererOrganizations/example.com/orderers/orderer.example.com/msp/tlscacerts/tlsca.example.com-cert.pem"

# join peers (after setting envs per org)
peer channel join -b mychannel2.block
Key Takeaway

Follow the exact sequence and verify environment variables and certificate paths; these are the most frequent sources of error.
