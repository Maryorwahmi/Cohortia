Module 2 › Chapter 2.5 › Configtxgen & Channel TX
Definition

Channel configuration transaction

Contains channel ID, member organizations, ordering endpoints and governance policies required to initialize a channel.

  • Channel ID: unique name for the channel.
  • Member organizations: MSPs that will be initial members.
  • Ordering endpoints: which orderer nodes will produce blocks.
  • Policies: rules for who can update or add orgs and default endorsement behavior.
Misconception

Generating the .tx is not enough. It must be signed by authorized admins before the orderer will create the genesis block.

Command Example
# generate channel transaction from profile
export FABRIC_CFG_PATH=${PWD}/../config
configtxgen -profile TwoOrgsChannel -outputCreateChannelTx ./channel-artifacts/mychannel2.tx -channelID mychannel2
Note: the command above reads the profile from configtx.yaml and writes the transaction artifact. Ensure the profile names and MSP identifiers match expected values in your network configuration.
Key Takeaway

Define profiles carefully in configtx.yaml and collect signatures; the ordering service will reject mis-signed or malformed transactions.
