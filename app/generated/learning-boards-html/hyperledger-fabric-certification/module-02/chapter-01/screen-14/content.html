Key Concepts
Peer
A node that hosts the ledger and runs chaincode, acting as endorser or committer as needed.
Ledger
Consists of an immutable blockchain and a mutable state database for efficient reads.
VCC (Version Check)
A validation step comparing read set versions to current world state to prevent conflicting writes.
Takeaway
Keep endorsements, ordering, and commit validation conceptually separate; design clients accordingly.
