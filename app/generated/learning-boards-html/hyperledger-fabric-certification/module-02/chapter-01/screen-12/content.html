Module 2 › Chapter 2.1 › Inspect Ledger — CLI Walkthrough
High-level steps
  1. Start test-network and deploy chaincode with createChannel and deployCC scripts.
  2. Set peer CLI environment variables to target a specific peer (MSP, TLS, address).
  3. Invoke chaincode to create an asset and query it to confirm world state.
  4. Inspect the peer ledger directory to find 'chains/' and 'stateLeveldb/'.
CLI snippet
export CORE_PEER_LOCALMSPID="Org1MSP"
export CORE_PEER_ADDRESS=localhost:7051
peer chaincode invoke -o localhost:7050 --tls --cafile "..." -C mychannel -n basic -c '{"function":"CreateAsset","Args":["asset1","blue","5","Tom","1000"]}'
peer chaincode query -C mychannel -n basic -c '{"Args":["ReadAsset","asset1"]}'
Filesystem inspection
Navigate to organizations/peerOrganizations/org1.example.com/peers/peer0.org1.example.com/ledger/ and list contents. You should see 'chains/' for blockchain and 'stateLeveldb/' when using LevelDB.
Expected output
After querying, you will see the asset's JSON. After listing the ledger directory, you will confirm the physical presence of blockchain and state DB artifacts.
