Module 2 › Chapter 2.4 › Approve & Commit
Approve for my organization
Use the package ID and submit approveformyorg with the channel ID, name, version, sequence, and required flags. This transaction records your organization's approval on the channel ledger.
Approve example
export CC_PACKAGE_ID="YOUR_PACKAGE_ID_HERE"
peer lifecycle chaincode approveformyorg -o localhost:7050 --tls --cafile ... --channelID mychannel --name simple_chaincode --version 1.0 --package-id $CC_PACKAGE_ID --sequence 1 --init-required --waitForEvent
Check readiness and commit
Run checkcommitreadiness to confirm needed approvals. If readiness is satisfied, submit the commit transaction that activates the chaincode definition on the channel.
Check and commit
peer lifecycle chaincode checkcommitreadiness --channelID mychannel --name simple_chaincode --version 1.0 --sequence 1 --init-required --output json
# after approvals
peer lifecycle chaincode commitchanneldefinition -o localhost:7050 --tls --cafile ... --channelID mychannel --name simple_chaincode --version 1.0 --sequence 1 --init-required --peerAddresses localhost:7051 --tlsRootCertFiles ...
Key Takeaway

Approvals record organizational consent; commit only after readiness checks to ensure the chaincode definition is agreed upon.
