Competency Checks
  • Package and install chaincode, then query installed to obtain the package ID.
  • Approve the definition from each organization and check commit readiness before committing.
  • Invoke CreateAsset and query ReadAsset to confirm the asset JSON is stored and retrievable.
VERIFIED COMPETENCY MILESTONE
Quick Mnemonics
Pack → Install → Approve → Commit. Always keep execution deterministic and avoid calls to external or random sources inside chaincode.
Use unit tests to assert PutState/GetState behaviors before deploying.
