Packaging
Use the peer lifecycle chaincode package command to create a tar.gz that includes source and a descriptor. The label you choose helps identify the package but the package ID includes a content hash.
Example command
peer lifecycle chaincode package simple_chaincode.tar.gz --path ../chaincode/simple_chaincode --lang golang --label simple_chaincode_v1
After installation, queryinstalled returns the package ID string that you will export as CC_PACKAGE_ID for approveformyorg. Keep that identifier unchanged throughout approval and commit steps.
Installation and Query
Install the package on an endorsing peer. Installing makes the code available for simulation but does not activate it on a channel.
Install example
peer lifecycle chaincode install simple_chaincode.tar.gz
peer lifecycle chaincode queryinstalled
Key Takeaway

The package ID from queryinstalled is required for approval; treat it as a stable reference when managing approvals and commits.
