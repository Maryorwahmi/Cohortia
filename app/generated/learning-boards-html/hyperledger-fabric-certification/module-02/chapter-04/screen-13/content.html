Module 2 › Chapter 2.4 › Terminal Walkthrough
Bring up the network
cd fabric-samples/test-network
./network.sh up createChannel -ca
Package and install
cd fabric-samples/chaincode/simple_chaincode
peer lifecycle chaincode package simple_chaincode.tar.gz --path ../chaincode/simple_chaincode --lang golang --label simple_chaincode_v1
peer lifecycle chaincode install simple_chaincode.tar.gz
peer lifecycle chaincode queryinstalled
Approve, commit, and initialize
export CC_PACKAGE_ID="YOUR_PACKAGE_ID_HERE"
peer lifecycle chaincode approveformyorg -o localhost:7050 --ordererTLSHostnameOverride orderer.example.com --tls --cafile ... --channelID mychannel --name simple_chaincode --version 1.0 --package-id $CC_PACKAGE_ID --sequence 1 --init-required --waitForEvent
peer lifecycle chaincode checkcommitreadiness --channelID mychannel --name simple_chaincode --version 1.0 --sequence 1 --init-required --output json
peer lifecycle chaincode commitchanneldefinition -o localhost:7050 --tls --cafile ... --channelID mychannel --name simple_chaincode --version 1.0 --sequence 1 --init-required --peerAddresses localhost:7051 --tlsRootCertFiles ...
Invoke example
peer chaincode invoke -o localhost:7050 --tls --cafile ... -C mychannel -n simple_chaincode --isInit -c '{"function":"Init","Args":[]}'
peer chaincode invoke -o localhost:7050 --tls --cafile ... -C mychannel -n simple_chaincode -c '{"function":"CreateAsset","Args":["asset100","red","10","Alice","2000"]}'
peer chaincode query -C mychannel -n simple_chaincode -c '{"function":"ReadAsset","Args":["asset100"]}'
Expected output: successful lifecycle confirmations, and ReadAsset returns JSON for asset100.
