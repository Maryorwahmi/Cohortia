Module 2 › Chapter 2.4 › Lifecycle Overview
1
Package
Bundle source and descriptor into a tar.gz so installations reference the same code package.
2
Install
Install the package on endorsing peers' file systems to make the code available for simulation.
3
Approve for my organization
Submit an approval transaction that records your organization's acceptance of the chaincode definition and its endorsement policy.
4
Commit
Once the required organizations have approved, submit a commit transaction to the ordering service to activate the chaincode.
Practical checks
  • After install, use queryinstalled to obtain the package ID.
  • Use checkcommitreadiness to confirm enough approvals exist before commit.
  • Commit will make the chaincode available for endorsement and execution.
Key Takeaway

Lifecycle acts as governance: each organization must explicitly approve the chaincode definition before it is committed and activated.
