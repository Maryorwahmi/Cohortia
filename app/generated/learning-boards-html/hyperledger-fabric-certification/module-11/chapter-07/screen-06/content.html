Definition Block events
What a block event contains
  • All transactions in the block and their payloads.
  • Validation codes and read/write sets.
  • Block number and metadata for ordering and auditing.
When to use
  • Ledger replication or rebuilds where full transaction context is required.
  • Forensic audit services that must see all activity in order.
  • Deriving transaction status when SDK helpers are not sufficient.
Performance note
Parsing full blocks is heavier — ensure your listener can keep up or push to a queue for parallel processing.
Design tip
Checkpoint by block number to resume processing exactly where you left off after a failure.
Misconception
Block events are not a low-latency replacement for targeted chaincode events when you only need specific business outcomes.
