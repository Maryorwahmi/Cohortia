Core Concept Checkpointing
Checkpoint patterns
  • Store last processed block number in a durable database after successful processing.
  • Use transaction IDs for finer-grained resume points when processing per-transaction.
  • Push events to a queue first if you want durable buffering outside the listener process.
Pitfall to avoid: Writing the checkpoint before downstream updates finish. Instead, make checkpointing the last step of an atomic processing sequence.
