Core Concept Idempotency
How to be idempotent
  • Use transactionId as a unique key and record processed IDs.
  • Check external system state before creating or updating records.
  • Store processing results and checkpoint only after durable write.
Error handling
  • Retry transient failures asynchronously with backoff.
  • Quarantine and alert on validation failures for manual review.
  • Avoid blocking the listener loop; move retries to a worker queue.
