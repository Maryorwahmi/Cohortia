Other Pluggable Components: State Database & BCCSP

Exploring accessible and common customization points in Hyperledger Fabric.

State Database

  • •Supports LevelDB (default) and CouchDB.
  • •CouchDB is pluggable via core.yaml configuration.
  • •Enables rich queries and flexible data models for complex applications.

Cryptographic Service Provider (BCCSP)

  • •Allows plugging in different cryptographic providers.
  • •Crucial for Hardware Security Module (HSM) integration (PKCS#11).
  • •Enhances key security and meets compliance requirements.
Key Takeaway

Customizing the state database (e.g., CouchDB for rich queries) and cryptographic service provider (e.g., BCCSP for HSMs) offers practical and impactful ways to tailor Fabric networks for specific performance and security needs.
