Chapter Summary

Key Concepts: Pluggable Components & Fault Tolerance

Reinforcing understanding of Fabric's extensible components and resilience.

Crash-Fault-Tolerant (CFT)

A system's ability to operate correctly even if some non-malicious nodes crash or fail.

State Database

The component storing the current state of the ledger, pluggable in Fabric (LevelDB or CouchDB).

Cryptographic Service Provider (BCCSP)

Fabric's interface for cryptographic operations, allowing different providers (e.g., HSMs) to be plugged in.

External Chaincode Builders/Launchers

Pluggable components enabling custom build and execution environments for chaincode, supporting various programming languages.

Summary Takeaway

Fabric's CFT design, coupled with pluggable components like state databases, BCCSP, and external chaincode builders, provides a robust, secure, and highly adaptable platform for diverse enterprise needs.
