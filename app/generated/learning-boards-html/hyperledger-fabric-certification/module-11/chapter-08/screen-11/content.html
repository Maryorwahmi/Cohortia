Module 11 › Chapter 11.8 › Scalability & Resilience
Scalable components
Prefer HPA for chaincode containers while adding peers deliberately. Use node affinity/anti-affinity to spread critical components across failure domains.
Network policies
Restrict pod communication to only necessary ports and peers to minimize lateral movement risk.
Monitoring
Collect metrics and logs to observe endorsement latency, disk usage of PVs, and pod restarts.
Example safeguards
  • Set HPA thresholds conservatively and test under load to avoid thrashing.
  • Use anti-affinity rules to place peers across zones for availability.
  • Back up PVs regularly and test restore procedures for ledger data.
Key Takeaway

Combine autoscaling for stateless workloads with deliberate scaling of stateful peers, strong network policies, and observability to build resilient Fabric clusters.
