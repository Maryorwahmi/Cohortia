Module 11 › Chapter 11.8 › Lab Walkthrough
Step-by-step lab tasks
  1. Start Minikube or Kind cluster: minikube start or kind create cluster.
  2. Generate crypto material or use pre-created MSP and TLS files.
  3. Create Kubernetes Secrets for TLS and MSP: kubectl create secret generic org1-peer0-tls --from-file=ca.crt=path/to/peer0/tls/ca.crt ...
  4. kubectl apply -f fabric-ca-deployment.yaml and kubectl apply -f peer0-org1-statefulset.yaml.
  5. Verify: kubectl get pods, kubectl get pvc, kubectl logs -f <pod-name>.
Starter manifest excerpts
# fabric-ca-deployment.yaml (excerpt)
apiVersion: apps/v1
kind: Deployment
metadata:
  name: fabric-ca-org1
spec:
  replicas: 1
  template:
    spec:
      containers:
        - name: fabric-ca
          image: hyperledger/fabric-ca:1.5.7
          ports:
            - containerPort: 7054
---
# peer0-org1-statefulset.yaml (excerpt)
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: peer0-org1
spec:
  serviceName: peer0-org1
  replicas: 1
  template:
    spec:
      containers:

          image: hyperledger/fabric-peer:2.5.4
          ports:
            - containerPort: 7051
Lab checklist
Secrets present, pods Running, PVC bound, service endpoints resolvable, and logs show successful TLS and MSP load.
