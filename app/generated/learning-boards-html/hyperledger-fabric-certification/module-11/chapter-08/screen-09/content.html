Module 11 › Chapter 11.8 › Helm Charts for Fabric
Why Helm
Helm groups templates and values so you can install complex multi-resource Fabric topologies from a single chart and perform upgrades consistently.
Best practice
Use separate values files per environment, pin image tags, and test helm upgrades in staging to validate migrations and storage behavior.
Values snippet (example)
# Example Helm chart values snippet for a peer
peer:
  name: peer0
  org: org1
  image:
    repository: hyperledger/fabric-peer
    tag: 2.5.4
  resources:
    requests:
      cpu: 500m
      memory: 1Gi
    limits:
      cpu: 1000m
      memory: 2Gi
  persistence:
    enabled: true
    storageClass: standard
    size: 20Gi
