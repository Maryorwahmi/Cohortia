Module 11 › Chapter 11.8 › Benefits of Cloud & Kubernetes
Definition

Cloud platforms provide elastic compute and managed services; Kubernetes orchestrates containerized Fabric components to automate scaling, healing, and deployments.

Scalability
Scale peers and chaincode containers to match endorsement and transaction throughput.
High Availability
Kubernetes restarts pods and clouds provide zones/regions for node failure resilience.
Automation
Helm and IaC make multi-org deployments repeatable and auditable.
Key Takeaway

Kubernetes handles containers and scale, but you must design storage, identity and TLS to preserve ledger correctness.

Concrete Example
Imagine a network with one orderer and three peers across two zones. During a traffic spike, you add chaincode replicas and HPA scales chaincode pods by CPU to maintain endorsement latency. If a node fails, Kubernetes reschedules pods and PVCs reattach to new pods so ledger data remains consistent.
Misconception
Kubernetes does not automatically make storage durable. You must provision PVs with appropriate performance and backup strategies.
Why it matters
Properly designed infrastructure prevents data loss, reduces downtime, and controls cost through right-sized resource requests and autoscaling.
