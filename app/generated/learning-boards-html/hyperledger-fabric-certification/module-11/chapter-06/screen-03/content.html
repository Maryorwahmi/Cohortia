Verification Checklist

Follow these small, targeted activities to confirm each optimization's impact.

Index Lab

Populate ledger, run rich query without index, deploy index, rerun and compare timing.

Batching Test

Change BatchSize and BatchTimeout in a test Raft cluster and measure block latency and throughput.

Peer Sizing

Benchmark with different peer CPU/RAM and CouchDB indexing to understand commit latency impact.

Client Concurrency

Submit transactions concurrently, use connection pooling, and observe TPS improvements.

Key Takeaway

Experiments must be measured. Change one parameter at a time and monitor metrics like TPS, latency, CPU, and I/O.
