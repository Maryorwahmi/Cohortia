Terminal Demo Steps
1. Baseline query (no index)
echo "Querying WITHOUT index..."
time peer chaincode query -C mychannel -n basic -c '{"function":"QueryAssets","Args":["{\"selector\":{\"Owner\":\"Owner1\"}}"]}'
2. Create index file
{
  "index": {
    "fields": ["Owner"]
  },
  "ddoc": "indexOwnerDoc",
  "name": "indexOwner",
  "type": "json"
}
Place this file at META-INF/statedb/couchdb/indexes/indexOwner.json in your chaincode project.
3. Deploy index via upgrade
peer lifecycle chaincode package basic_2.0.tar.gz --path ../asset-transfer-basic/chaincode-go --label basic_2.0
peer lifecycle chaincode install basic_2.0.tar.gz
# then approve and commit the upgrade as usual
4. Re-run query and compare timing
echo "Querying WITH index..."
time peer chaincode query -C mychannel -n basic -c '{"function":"QueryAssets","Args":["{\"selector\":{\"Owner\":\"Owner1\"}}"]}'
Expect a noticeable reduction in query time and reduced CouchDB CPU load when the index is used.
Lab Tip

If CouchDB indexing does not appear immediately, check index creation logs and allow time for the index to build before re-running heavy queries.
