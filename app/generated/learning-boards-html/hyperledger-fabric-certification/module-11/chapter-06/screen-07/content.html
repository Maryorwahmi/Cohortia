Module 11 › Chapter 11.6 › CouchDB Indexing
Index Definition

Place a JSON index file under META-INF/statedb/couchdb/indexes in your chaincode so it deploys with chaincode packages.

indexOwner.json (example)
{
  "index": {
    "fields": ["Owner"]
  },
  "ddoc": "indexOwnerDoc",
  "name": "indexOwner",
  "type": "json"
}
Deploy & Test
Steps
  1. Package chaincode with indexOwner.json under META-INF/statedb/couchdb/indexes.
  2. Install and approve the chaincode package, then commit or upgrade to deploy the index.
  3. Run the same rich query and compare execution times and CouchDB CPU usage.
Concrete Example
Querying Owner='Owner1' without index may scan all documents. With indexOwner.json, CouchDB uses the index to return results quickly.
Key Takeaway

Design selectors and indexes together. Deploy indexes with chaincode or via CouchDB API and validate reduced query times.
