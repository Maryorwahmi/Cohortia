Module 11 › Chapter 11.6 › Client Strategies
Concurrency

Submit multiple proposal requests in parallel to increase TPS. The SDKs are designed for concurrent use.

Connection Pooling
Reuse TLS sessions and peer/orderer connections to avoid repeated handshake costs.
Event Listeners
Listen for commit events rather than polling peers for finality.
Retries & Error Handling

Detect endorsement failures due to read-write conflicts and implement exponential backoff retries with a cap. Avoid tight immediate retries that worsen contention.

Concrete Example
If many clients update the same inventory key, retries should detect the conflict, back off briefly, and then resubmit once the contention subsides.
Pro Tip

Use events to track commits and reduce unnecessary load. Implement scoped retries for transient conflicts only.
