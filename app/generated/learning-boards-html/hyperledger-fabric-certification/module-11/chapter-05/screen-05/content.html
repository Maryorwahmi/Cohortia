Module 11 › Chapter 11.5 › Config Update Flow
Process

Seven-step update flow

1. Fetch latest config block
Guarantees you are editing the current state before compute_update.
2. Decode to JSON
Use configtxlator proto_decode to inspect and extract the config envelope.
3. Edit config JSON
Add the new org and AnchorPeers under Application.groups.
4. Encode and compute delta
Compute the precise ConfigUpdate with configtxlator compute_update.
5-7. Wrap, sign, submit
Wrap in an envelope, collect required signatures, and submit the signed envelope to the orderer.
Misconception

Submitting raw modified JSON without computing the delta will not produce a valid configuration transaction; Fabric requires the computed update format.

Key Takeaway

Each step reduces risk: exact deltas and signatures preserve auditability and enforce policies.
