Common Mistakes

Where updates commonly fail

Incorrect Policies
Misreading Admin policies causes insufficient signatures and rejection.
Stale Config Block
An outdated original causes compute_update mismatches—refetch immediately before compute.
JSON Manipulation Errors
Manual jq edits can corrupt structure; validate using templates and compare with known orgs.
TLS / MSP Issues
Incorrect TLS certificates or MSP paths during signing cause policy verification to fail.
Mitigation
  • Use a staging environment and backups.
  • Fetch last config immediately before edits and minimize edit time.
  • Validate JSON and confirm AnchorPeers are set.
  • Coordinate admins and verify TLS/MSP contexts before signing.
