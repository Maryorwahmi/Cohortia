Definition

What the configuration block holds

This block stores the channel_group with sub-groups for Consortiums, Application (organizations), Orderer, and Policies. It is committed on-chain and updated via config transactions.

Consortiums
Which orgs may create channels.
Organizations
MSP entries and AnchorPeers for peer discovery.
Orderer
Ordering type, endpoints, and batching settings.
Channel Policies
Rules for admins, readers, and writers, using Signature and ImplicitMeta.
Example

When adding an Org4, you place its MSP definition under channel_group.groups.Application.groups, and define an AnchorPeers value so other peers can discover Org4's peers via gossip.

Common Mistake

Editing the wrong group or failing to set AnchorPeers will prevent peer discovery or cause the update to be rejected.

Key Takeaway

Treat the configuration block as authoritative; changes must be encoded as config transactions to be applied safely.
