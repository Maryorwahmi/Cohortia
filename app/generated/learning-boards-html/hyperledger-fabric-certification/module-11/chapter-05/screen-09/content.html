Module 11 › Chapter 11.5 › Signing & Approval
Approval

Collect required administrator signatures

Sign command
peer channel signconfigtx -f config_update_in_envelope.pb
Coordination
  • Each required org admin runs the sign command using their MSP context.
  • Signing appends a signature; it does not submit the update.
  • Confirm the envelope contains all expected signatures before submission.
Common Mistake

Providing fewer than the policy-required signatures will cause the ordering service to reject the update.

Key Takeaway

Signatures must match the policy. Coordinate admins and verify the envelope before submission to avoid rejected updates.
