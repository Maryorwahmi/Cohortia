Add Org4's MSP and AnchorPeers

Create an org4.json describing the MSP and anchor peer, then merge it into the Application group of config.json.

# Merge example (simplified)
jq -s '.[0] * {"channel_group":{"groups":{"Application":{"groups": {"Org4MSP": .[1]}}}}}' config.json ./org4.json > modified_config.json
Validation
  • Compare structure to an existing OrgMSP to ensure keys match.
  • Verify AnchorPeers value exists under values.AnchorPeers.
  • Keep backups of both original and modified JSON.
Example AnchorPeers snippet
"AnchorPeers": { "mod_policy": "Admins", "value": { "anchor_peers": [ { "host": "peer0.org4.example.com", "port": 10051 } ] } }
Common Error

Accidentally changing the Application group's top-level version or policies can alter access control. Make minimal edits and validate the JSON hierarchy.

Key Takeaway

Edit only what is necessary: add the org entry and anchor peers to keep the update minimal and auditable.
