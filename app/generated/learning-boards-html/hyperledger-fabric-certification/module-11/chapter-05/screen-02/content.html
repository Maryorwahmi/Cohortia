Learning Objectives

Progress from understanding to performing dynamic channel updates.

Bloom: Learn → Understand → Apply → Master
01
Describe the configuration block

Explain groups, MSP entries, orderer settings, and policies and why they are stored on-chain.

Verified Competency Milestone
02
Perform dynamic updates

Execute the fetch, decode, modify, compute, sign, and submit sequence to change a channel safely.

Verified Competency Milestone
03
Explain config transactions & approvals

Describe how configuration transactions require signatures and how policies determine quorum and approval rules.

Verified Competency Milestone
04
Troubleshoot updates

Identify stale config, JSON manipulation errors, missing anchor peers, and TLS/MSP mismatches and how to fix them.

Verified Competency Milestone
