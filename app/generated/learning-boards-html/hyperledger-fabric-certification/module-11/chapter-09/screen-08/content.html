Key fields for PKCS#11
  • Default: PKCS11 — selects the PKCS#11 provider.
  • Library — path to the vendor or SoftHSM shared library.
  • Pin and Label — used to authenticate to the token. Use secrets to inject them.
YAML example
# core.yaml snippet for HSM configuration
BCCSP:
  Default: PKCS11
  PKCS11:
    Library: /usr/lib/softhsm/libsofthsm2.so # Path to your PKCS#11 library
    Pin: "1234" # HSM user PIN (use secrets instead)
    Label: "my-hsm-label" # Token label
    hash: SHA2
    security: 256
    immutable: false
Remember: paths inside containers must match the mounted library path.
