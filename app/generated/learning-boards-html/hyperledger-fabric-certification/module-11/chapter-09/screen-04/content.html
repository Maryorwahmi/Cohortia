Module 11 › Chapter 11.9 › Key Management
Definition
Key management covers generation, storage, distribution, rotation, revocation, and recovery of cryptographic keys that Fabric relies on.
Risks and real example
  • Risk: Private key exfiltration enables identity impersonation.
  • Example: An attacker using a stolen peer key could sign incorrect endorsements that appear valid to the network.
  • Misconception: Filesystem permissions alone protect keys; they don't protect against kernel or container escapes.
Lifecycle responsibilities
Generate securely
Store in HSM when required
Rotate on policy
Revoke and dispose safely
Example
Rotate a CA key on a regular schedule and reissue dependent certificates to limit the exposure window if a key is compromised.
Key Takeaway
Treat keys as high-value assets: technical protections and operational policies must work together.
