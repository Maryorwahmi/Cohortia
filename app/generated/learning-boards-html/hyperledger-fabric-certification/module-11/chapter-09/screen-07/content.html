Module 11 › Chapter 11.9 › Integrating HSMs
Four-step integration
  1. Provision HSM — network or PCIe; validate network access and physical security.
  2. Install PKCS#11 library — verify file path and permissions for the Fabric process.
  3. Configure BCCSP — set PKCS11 fields in core.yaml and use secrets for PIN/Label.
  4. Verify — check logs and confirm signing calls go through the HSM.
Troubleshoot checklist
  • Validate library path and mount inside containers.
  • Confirm PIN/Label with pkcs11-tool.
  • Make sure HSM network is reachable for network HSMs.
Example scenario
After modifying core.yaml to point to SoftHSM's library and starting the peer, monitor logs for BCCSP PKCS11 initialization and signing entries to confirm usage.
