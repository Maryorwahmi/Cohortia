Module 11 › Chapter 11.9 › Common Mistakes
Frequent errors and fixes
Wrong library path or mount: Verify the path inside the container or host and correct Docker or Kubernetes mounts.
Incorrect PIN/Label: Confirm with pkcs11-tool and inject via secrets, not plain YAML.
HSM unreachable: Check network HSM connectivity and design redundancy to avoid downtime.
Performance concerns: Measure before disabling HSM; often acceptable for signing workloads.
Diagnostic checklist
  1. Check library path and mounts.
  2. List tokens with pkcs11-tool.
  3. Validate PIN and Label.
  4. Inspect Fabric logs for PKCS#11 errors.
