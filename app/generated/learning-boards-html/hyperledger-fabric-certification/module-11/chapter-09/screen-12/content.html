Module 11 › Chapter 11.9 › Operational Best Practices
Core operational areas
  • Threat modeling to prioritize controls and test assumptions.
  • Centralized audit logging for Fabric components and HSM access.
  • Strict RBAC across infrastructure, Kubernetes, and Fabric CAs.
  • Key rotation policies and tested re-issuance plans.
  • Vulnerability scanning, OS hardening, and multi-factor authentication for admin access.
Example action
Centralize peer and CA logs into a secure SIEM and create alerts for repeated PKCS#11 authentication failures.
Key Takeaway
Operational processes make technical controls effective; log, monitor, and test rotation and availability plans regularly.
