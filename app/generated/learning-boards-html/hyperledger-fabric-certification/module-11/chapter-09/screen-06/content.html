What PKCS#11 provides
A vendor-neutral API surface for cryptographic modules that supports listing tokens, authenticating, and performing operations so Fabric can delegate signing to an HSM.
Practical checklist
  • Ensure the PKCS#11 shared library is installed on the host.
  • Provide correct PIN and Label via secure injection.
  • Verify with pkcs11-tool that the token and slot exist.
Example config
# Example: point to your PKCS#11 library
BCCSP:
  Default: PKCS11
  PKCS11:
    Library: /usr/lib/softhsm/libsofthsm2.so
    Pin: "1234"
    Label: "my-hsm-label"
    hash: SHA2
    security: 256
    immutable: false
Note: avoid hardcoding PINs; use environment variables or secrets.
