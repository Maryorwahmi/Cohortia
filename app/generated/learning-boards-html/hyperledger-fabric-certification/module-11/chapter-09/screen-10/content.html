Module 11 › Chapter 11.9 › SoftHSM Lab
Step-by-step
  1. Install SoftHSMv2 and configure token directory if necessary.
  2. Initialize a token: set SO PIN, user PIN, and a label for the slot.
  3. Use pkcs11-tool to list slots and confirm the token label and slot ID.
  4. Generate a key pair inside the HSM with pkcs11-tool or allow Fabric to generate it on first use.
  5. Mount the PKCS#11 library into containers or bake it into images for runtime access.
Quick commands
softhsm2-util --init-token --slot 0 --label "myPeerHSM" --so-pin "987654" --pin "1234"
pkcs11-tool --module /usr/lib/softhsm/libsofthsm2.so --list-slots
# Optional: generate key inside HSM with pkcs11-tool
If running Fabric in Docker, mount the library path into the container.
