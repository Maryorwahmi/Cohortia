Hands-on focus and verification

This slide maps objectives to actions: a SoftHSM lab, configuration of core.yaml and fabric-ca-server-config, and verification checks for library path, token PIN/label, and HSM availability.

Verification Check 1
PKCS#11 library accessible and readable by the Fabric process.
Verification Check 2
PIN and Label match the initialized token and are injected securely.
Verification Check 3
Peer or CA logs confirm the PKCS#11 provider is used for signing.
Operational Note
Plan for HSM high availability; a disconnected HSM can halt Fabric operations.
Quick lab checklist
  1. Install SoftHSMv2.
  2. Init token and set PIN and label.
  3. Generate or allow Fabric to generate keys inside the HSM.
  4. Update core.yaml and start the peer.
