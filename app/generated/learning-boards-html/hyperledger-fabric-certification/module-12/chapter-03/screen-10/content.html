SDK feature checklist
  • Gateway and wallet support
  • Discovery APIs to reduce static endpoints
  • Event listeners for commit confirmations
  • Transient data support for private collections
  • HSM integration options
Read vs Write
Use evaluateTransaction for queries (read-only) and submitTransaction for proposals that change ledger state. Treat submit as asynchronous until you confirm commits.
Practical note
Explicitly set transient map keys for private data before sending proposals; do not rely on automatic behavior.
