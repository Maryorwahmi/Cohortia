Node.js SDK pattern
const { Gateway, Wallets } = require('fabric-network');
const fs = require('fs');

const ccp = JSON.parse(fs.readFileSync('connection-org1.json', 'utf8'));
const wallet = await Wallets.newFileSystemWallet('./wallet');
const identity = await wallet.get('appUser');
if (!identity) {
  console.log('Enroll appUser before running this application');
  return;
}
await gateway.connect(ccp, { wallet, identity: 'appUser', discovery: { enabled: true, asLocalhost: true } });
Note: this pattern separates configuration, identity, and network discovery for easier operations and safer secrets handling.
Practical tip
Check the wallet for the identity before calling connect. Give clear, actionable logs so operators can enroll missing users without digging into stack traces.
Misconception
Discovery reduces manual config but does not remove the need for secure TLS and validated certificates. Always validate TLS CA certs in production.
