Module 12 › Chapter 12.3 › Wallet-Based Identities
Identity storage options
File system wallet
Simple, portable for development, but store files securely in production hosts or containers.
Database-backed wallet
Persistent storage using CouchDB or similar for shared or scaled services.
In-memory wallet
Useful for ephemeral testing but not for production as keys are transient.
HSM-backed wallet
Hardware protection for private keys; recommended for high-security deployments.
Best practices
  • Never hardcode private keys or certificates in source.
  • Assign unique identities per user/service for accountability.
  • Integrate revocation checks and re-enrollment flows.
