Module 12 › Chapter 12.3 › Performance Considerations
Practical guidelines
  • Batch read queries where possible to reduce round trips.
  • Control concurrency for write submissions to avoid overwhelming endorsers and orderers.
  • Reuse gateway connections and wallets to minimize connection overhead.
  • Provide optimistic UI feedback but reconcile with commit events to avoid inconsistency.
Checklist
Measure endorsement latency, ordering latency, and commit propagation. Tune client concurrency and implement throttling or rate limiting to protect network resources.
