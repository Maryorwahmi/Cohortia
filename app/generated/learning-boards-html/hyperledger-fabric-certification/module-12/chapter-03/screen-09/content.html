Retry pattern
Implement exponential backoff with jitter and a capped attempt count. Classify errors to decide whether they are retryable or fatal.
// pseudo
retry = 0
while (retry < maxAttempts) {
  try {
    submit()
    break
  } catch (err) {
    if (isTransient(err)) sleep(base * 2^retry + jitter)
    else throw err
  }
  retry++
}
Common pitfalls
  • Retrying without idempotency can cause duplicate writes.
  • Not bounding retries can overwhelm peers or the ordering service.
  • Lack of correlation IDs makes debugging failed retries harder.
