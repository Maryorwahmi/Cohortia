Module 12 › Chapter 12.3 › Vulnerabilities
Threats
  • Mango query injection from unsanitized user input.
  • Denial-of-service by excessive transactions or expensive queries.
  • Accidental leakage via logs that include sensitive key material.
Mitigations
  • Sanitize and parameterize Mango queries; validate allowed fields and types.
  • Rate limit at the application layer and monitor anomalous activity.
  • Log transaction IDs and non-sensitive metadata; never log private keys.
