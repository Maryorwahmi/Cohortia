Module 12 › Chapter 12.3 › Learning Objectives — Verification
Objective Checks
  • Load and parse a connection profile; demonstrate discovery reducing hardcoded endpoints.
  • Enroll a user and store identity in a wallet; swap a wallet implementation to CouchDB for persistence.
  • Refactor submit-only flows to use createTransaction and addCommitListener and log commit events.
  • Write unit tests that simulate temporary peer downtime and verify retry/backoff behavior.
Verification Tips
Use terminal logs to capture transaction IDs, commit confirmations, and peer names. Do not log private keys or full certificate contents.
Automate a small test that sends a transaction then queries the ledger until the commit event arrives or a timeout occurs.
