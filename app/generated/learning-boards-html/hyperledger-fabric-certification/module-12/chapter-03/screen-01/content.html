Client Application Development Best Practices
Design client apps that are secure, observable, and resilient when interacting with a Fabric network.
In this lesson
Connection profiles, wallet-based identities, transaction submission patterns with event listening, SDK usage, and mitigation of common vulnerabilities.
Coming up
A terminal-focused code demo refactoring a simple submit flow into one with commit listeners and cleanup.
Key Takeaway

Treat the client as a first-class security and reliability boundary. Use profiles, wallets, event listening, and sane retry policies to avoid incorrect assumptions about ledger state.

Concept Map
Connection Profile ➜ Gateway ➜ Wallet Identity ➜ SDK Calls ➜ Submit → Ordering → Commit Event
Explore Key Topics
Secure Connections
Use connection profiles and TLS; do not hardcode endpoints.
Identity Management
Store credentials in wallets or HSMs; avoid embedding private keys.
Transaction Finality
Listen for commit events to confirm ledger updates and avoid race conditions.
