Module 12 › Chapter 12.9 › TDD & Simulating Transactions
Practice

Write tests and simulate proposals

  • Unit-test core business logic and edge cases offline.
  • Integration-test with a local ledger to validate end-to-end flows.
  • Use the peer CLI dry-run to validate endorsement responses before commit.
CLI Example
# Simulate an invoke without committing
peer chaincode invoke --tls --cafile  -C mychannel -n mycc -c '{"function":"CreateCar","Args":["CAR001","Audi"]}' --dry-run
Explanation: dry-run exercises endorsement and returns the proposal response so you can inspect errors without ledger changes.
Key Takeaway
Tests catch logic errors early; simulation helps validate endorsements and proposal responses before commit.
