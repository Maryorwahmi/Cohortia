Module 12 › Chapter 12.9 › Chaincode Logging & Container Logs
Best Practice

Instrument chaincode with context

  • Log transaction ID, invoked function, and key arguments for each request.
  • Avoid printing large blobs or secrets in logs.
  • Use log levels to separate info from debug details.
Concrete example
# View peer logs
docker logs peer0.org1.example.com

# View chaincode container logs
docker logs dev-peer0.org1.example.com-mycc-1.0
Analogy
Think of chaincode logs as breadcrumbs that show which branch was taken during execution. Well-placed crumbs help you retrace the path without dumping the whole forest.
Key Takeaway

Instrument chaincode with concise, contextual logs and use container logs to link chaincode behavior to peer processing.
