Module 12 › Chapter 12.9 › Remote Debugging Chaincode
Steps
  1. Start the chaincode container with delve listening on a debug port.
  2. Attach your IDE debugger to the container's debug endpoint.
  3. Set breakpoints and invoke the transaction to trigger them.
  4. Inspect variables, stack frames, and return values to find logic errors.
Caution: debugging can pause execution and affect endorsement timing, so perform this in non-production environments or during controlled windows.
Example workflow
Start the chaincode container with delve attached, open VS Code to attach, set a breakpoint at the function handling your transaction, then run the client invoke to hit the breakpoint and inspect variables.
Common misconception
Remote debugging is safe to run in production without impact. In reality breakpoints pause execution and can disrupt endorsement and throughput.
