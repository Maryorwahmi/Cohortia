Off-chain encryption pattern
Encrypt data externally, store the blob off-chain, and keep a hash and reference on the ledger.
Steps
  1. Encrypt the sensitive payload using a KMS-managed key.
  2. Store the encrypted blob in secure storage.
  3. Write the blob reference and its hash to the ledger.
Concrete example
Store medical or contractual documents encrypted in a cloud bucket, keeping only the hash and a pointer on Fabric for verification and audit.
Common mistake
Storing keys on-chain or in plain files removes any benefit of off-chain encryption; keys must be kept in a KMS.
Key management
  • Use a KMS for key lifetime and rotation.
  • Log KMS access and integrate with Fabric logs for investigations.
  • Plan key revocation and epoching strategies.
Key Takeaway

Use off-chain encryption when ledger immutability conflicts with privacy or deletion requirements, and protect keys using a KMS.
