Module 12 › Chapter 12.5 › Key Concepts
Certificate Authorities (CAs)
Issue and revoke identities; run per-org CAs and protect signing keys.
Mutual TLS (mTLS)
Two-way certificate authentication for nodes and clients to prevent impersonation.
Endorsement Policies
Explicit policies like AND or majority ensure correct signers approve transactions.
Summary: Run org CAs, enable mTLS everywhere, design explicit endorsement policies, protect keys with HSMs, use PDCs or off-chain encryption as needed, and centralize logs for auditing.
