Learning Objectives
Understand and apply Fabric security controls to protect identities, traffic, transactions, and data.
01
Identity & Access Management
Issue and revoke identities with org-managed CAs and enforce attributes via MSPs so chaincode checks can control actions. VERIFIED COMPETENCY MILESTONE
02
Transport Security (TLS/mTLS)
Configure TLS with mutual authentication so peers, orderers, and clients verify each other and prevent impersonation. VERIFIED COMPETENCY MILESTONE
03
Endorsement Policies
Define explicit AND or majority policies to control which orgs must sign transactions. VERIFIED COMPETENCY MILESTONE
04
Private Data & Auditing
Use PDCs or off-chain encrypted storage and centralize logs for effective auditing. VERIFIED COMPETENCY MILESTONE
