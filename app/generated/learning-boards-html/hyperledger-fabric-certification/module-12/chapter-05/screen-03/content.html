Module 12 › Chapter 12.5 › Learning Objectives
Practical Outcomes
These objectives map to lab steps you will perform to validate controls in a test-network.
Run an org CA and rotate credentials
Practice issuing and revoking identities and rotating enrollment secrets.
Configure mTLS
Set mutual authentication across peers, orderers, and client endpoints and test certificate expiry behavior.
Change endorsement policy
Upgrade chaincode definition with an AND policy and observe failed single-org endorsements.
Create a PDC
Limit visibility of sensitive data to specific organizations while storing a hash on-channel.
Milestone
Demonstrate a configuration change that prevents a transaction from committing until the required endorsements are present.
Tip
Always test certificate renewals in a staging environment to prevent unexpected outages from expired TLS certificates in production.
