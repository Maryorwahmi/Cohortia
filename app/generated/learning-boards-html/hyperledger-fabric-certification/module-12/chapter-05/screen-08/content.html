Private Data Collections
PDCs let a subset of orgs hold private values while a hash is stored on the main ledger.
How it works
Private data is distributed peer-to-peer among collection members. The ledger records only the hash for verification and audit.
Concrete scenario
Two organizations share contractual terms inside a PDC. Other channel members see only the hash and cannot read the private content.
Limitations
PDC members must secure their local private state. Misconfiguration or compromised peers can still risk privacy.
Off-chain encryption alternative
Store encrypted data off-chain and keep the hash and key reference on the ledger. Use a KMS for keys, never store keys on-chain.
Key Takeaway

PDCs provide Fabric-native privacy for subsets of orgs; combine with KMS and strong node security for robust protection.
