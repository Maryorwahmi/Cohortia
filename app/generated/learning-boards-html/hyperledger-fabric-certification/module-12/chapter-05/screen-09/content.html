Module 12 › Chapter 12.5 › HSM & Key Custody
Hardware Security Modules
Use HSMs for CA and ordering keys to minimize key compromise risk.
Why HSMs
HSMs store keys in tamper-resistant hardware and perform cryptographic ops without revealing keys to the host.
Operational notes
Integrate via PKCS#11, manage HSM credentials securely, plan rotation, and audit all key usage.
Common misconception
HSMs do not replace the need for strong OS and network security; they complement it by protecting keys.
Integration checklist
  • Identify CA and orderer keys for HSM migration.
  • Configure PKCS#11 providers and test signing operations.
  • Audit HSM administrative access and key usage logs.
Key Takeaway

HSMs significantly reduce the risk of key compromise but must be used as part of overall operational security and auditing.
