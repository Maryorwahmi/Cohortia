Module 12 › Chapter 12.8 › Practice CLI Lab
Lab Steps (Repeatable)
  1. Start fabric-samples test-network and ensure binaries are on PATH.
  2. Generate channel create transaction with configtxgen for your profile.
  3. Run peer channel create to generate the channel block.
  4. Set org environment variables and run peer channel join with the block.
  5. Verify with peer channel list and lifecycle queries.
Example Commands (from the chapter)
# As Org1 Admin (example)
# configtxgen -profile TwoOrgsApplicationGenesis -outputCreateChannelTx ./channel-artifacts/mychannel2.tx -channelID mychannel2
# peer channel create -o localhost:7050 -c mychannel2 --ordererTLSHostnameOverride orderer.example.com -f ./channel-artifacts/mychannel2.tx --outputBlock ./channel-artifacts/mychannel2.block --tls --cafile ${PWD}/organizations/ordererOrganizations/example.com/orderers/orderer.example.com/msp/tlscacerts/tlsca.example.com-cert.pem
# peer channel join -b ./channel-artifacts/mychannel2.block
# peer channel list
# peer lifecycle chaincode queryinstalled
Practice note
Run the full sequence three times, changing one parameter each run to observe different failure modes and fixes.
