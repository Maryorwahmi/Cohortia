Module 12 › Chapter 12.8 › Chaincode Lifecycle
Lifecycle Steps
Package, install, approve, commit, invoke.
Pattern: Asset Management
Implement create, read, update, delete patterns with access control checks for permitted identities.
Pitfall to avoid
For upgrades, increment sequence and update package ID; failing to do so will prevent commit.
Example CLI Sequence
# Example sequence (values elided for clarity)
peer lifecycle chaincode package mycc.tar.gz --path ./chaincode --lang golang --label mycc_1
peer lifecycle chaincode install mycc.tar.gz
peer lifecycle chaincode queryinstalled
# note package ID from queryinstalled
peer lifecycle chaincode approveformyorg --package-id  --sequence 1 --channelID mychannel
peer lifecycle chaincode commit -o localhost:7050 --channelID mychannel --name mycc --sequence 1
peer chaincode invoke -C mychannel -n mycc -c '{"Args":["CreateAsset","asset1", "100"]}'
Key takeaway
Practice the full lifecycle until package IDs, approvals, and sequence numbers are familiar. This reduces exam-time errors.
