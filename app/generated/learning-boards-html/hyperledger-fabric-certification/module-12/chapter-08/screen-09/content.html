Common Artifacts
configtx.yaml drives genesis and channel transactions. Practice generating channel artifacts with configtxgen and updating channel config safely.
Environment variables to practice
  • CORE_PEER_LOCALMSPID
  • CORE_PEER_MSPCONFIGPATH
  • CORE_PEER_TLS_ROOTCERT_FILE
  • CORE_PEER_ADDRESS
Example Commands
# Create channel artifacts (example)
configtxgen -profile TwoOrgsApplicationGenesis -outputCreateChannelTx ./channel-artifacts/mychannel2.tx -channelID mychannel2
# Create channel
peer channel create -o localhost:7050 -c mychannel2 --ordererTLSHostnameOverride orderer.example.com -f ./channel-artifacts/mychannel2.tx --outputBlock ./channel-artifacts/mychannel2.block --tls --cafile ${PWD}/organizations/ordererOrganizations/example.com/orderers/orderer.example.com/msp/tlscacerts/tlsca.example.com-cert.pem
# Join peer
peer channel join -b ./channel-artifacts/mychannel2.block
# List channels
peer channel list
Common mistake
Switching org contexts without updating environment variables causes permission and TLS errors. Always re-export the variables for the current role.
