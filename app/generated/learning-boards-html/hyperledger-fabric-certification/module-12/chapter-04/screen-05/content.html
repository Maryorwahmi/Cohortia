Module 12 › Chapter 12.4 › Centralized Logging
Logging pipeline checklist
  1. Enable and standardize log formats and levels across peers, orderers, and CAs.
  2. Install a log-forwarding agent to send logs to a central aggregator.
  3. Index fields like component, peer ID, channel, transaction ID, and error codes for cross-component searches.
  4. Define retention and rotation policies to avoid disk exhaustion and meet compliance needs.
  5. Create alert rules for abnormal log volume, repeated errors, and security events.
Privacy & security
Never log private keys or sensitive MSP material. Protect log storage and restrict access to audit logs.
Example trace
A transaction fails at validation. Search by transaction ID across the peer, orderer and client logs to find the failing endorsement policy or validation error.
Common mistake

Waiting until an outage to configure log aggregation makes post-incident forensics slow and error-prone.
