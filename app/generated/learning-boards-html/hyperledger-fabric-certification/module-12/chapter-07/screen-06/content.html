Definition Immutability & Audit
What immutability delivers
  • Tamper-evident history via cryptographic hashes.
  • Reliable audit trails for compliance and dispute investigation.
  • Provenance of state changes tied to endorsing identities.
Practical pattern
Keep PII off-chain and store hashes on the ledger. Deleting off-chain data satisfies right-to-be-forgotten while preserving an immutable proof.
Example
Customer KYC documents encrypted in secure storage. Ledger stores the document hash and access events. If deletion is required, remove off-chain documents and record the deletion event on chain.
Common Misconception

Immutability alone does not guarantee data correctness; you must secure input systems and identities to ensure the ledger records trustworthy events.

Key Takeaway

Use off-chain storage for PII and ledger hashes for auditability to reconcile immutability with privacy requirements.
