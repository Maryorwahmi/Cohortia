Integration checklist
  • Package and install chaincode on peers for all required orgs.
  • Approve and commit the chaincode definition with correct endorsements.
  • Invoke transactions via SDK or peer CLI to validate endorsements and state changes.
  • Run migration functions and verify transformed records.
Terminal demo style
Script packaging, install, and approval steps, then run both valid and invalid commands to observe success and error responses. Capture logs from peers to diagnose endorsement or schema issues.
Tip
Automate your integration tests in CI so upgrades and migration scripts run before merging changes to mainline branches.
