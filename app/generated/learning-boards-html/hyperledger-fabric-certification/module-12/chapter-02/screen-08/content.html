LevelDB
Optimized for exact key lookups and range scans. Use when queries can be satisfied by well-structured keys or composite keys. Fast and low-overhead for most common patterns.
When to use
  • Direct GetState and PutState use cases.
  • Range queries where composite keys provide the index.
CouchDB
Supports rich JSON queries via Mango and index definitions. Useful for attribute-based searches, but requires index planning and can be resource-intensive for large datasets.
Guidance
  • Create indexes for frequent queries to avoid full scans.
  • Paginate and limit results to reduce timeouts and memory use.
Performance tip
Favor key designs for predictable performance and use CouchDB selectively.
Common mistake
Running complex Mango queries without indexes can cause timeouts and heavy CPU use on peers.
Action
If you need CouchDB, define indexes early and test query performance against realistic datasets.
