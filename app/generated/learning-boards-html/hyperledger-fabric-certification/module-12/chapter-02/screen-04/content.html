Definition
Input validation

Systematic verification of every external parameter to ensure type safety, length, format and domain rules. Validation prevents bad state and runtime errors during endorsement.

Common patterns
  • Check presence (non-empty) for identifiers and owner fields.
  • Parse and validate numeric ranges for sizes or values.
  • Trim and normalize strings to avoid accidental duplicates.
  • Validate length and permitted characters for IDs.
Key Takeaway

Validation lives in chaincode: it documents rules, prevents bad endorsements, and reduces wasted execution.

Concrete example
// Input validation example (Go)
func validateCreateInput(id string, color string, size int, owner string) error {
  if id == "" || color == "" || owner == "" || size <= 0 {
    return fmt.Errorf("asset ID, color, owner, and size must be provided and valid")
  }
  return nil
}
Misconception check

Do not rely on client-side validation or assume only trusted callers will submit correct data. Peers must validate because all transactions get executed and endorsed by peers.
