Deterministic execution

Avoid on-chain randomness and implicit timestamps. If you need external data, submit it as transaction input so all endorsers see the same values.

Performance cautions
  • Large GetQueryResult operations need indexes and pagination.
  • Avoid looping over many records in a single transaction.
  • Store large objects off-chain and keep hashes on the ledger.
Common vulnerabilities
  • Missing authorization checks on administrative functions.
  • Insufficient validation leading to invalid or inconsistent state.
  • Expensive queries enabling resource exhaustion.
Closing question
Can your chaincode be invoked by unauthorized callers or trigger expensive queries? If so, plan fixes now.
