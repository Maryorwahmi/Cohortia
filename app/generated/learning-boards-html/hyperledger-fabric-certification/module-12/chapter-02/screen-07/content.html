Architecture
Key and data modeling

Choose keys to support access patterns. Composite keys let you query by multiple attributes while keeping each object single-sourced.

Composite key example
CreateCompositeKey("asset~owner~type", []string{assetID, owner, assetType}) lets you perform range queries for a given owner or type by building a prefix.
Why lean matters
Smaller JSON reduces endorsement payloads, speeds replication, and keeps CouchDB index sizes manageable.
Patterns & cautions
  • Store hashes or URIs for large binaries and keep the actual files in secure off-chain storage.
  • Design CouchDB indexes for frequent Mango queries to avoid full scans.
  • Avoid deep nesting of objects that make partial updates complex.
Key takeaway
Design your keys and JSON to match query and update patterns; plan indexes when using CouchDB for rich queries.
