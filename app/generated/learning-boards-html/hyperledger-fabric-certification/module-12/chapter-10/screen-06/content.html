Integration
AI, IoT and Analytics
Patterns for provenance, device identity, and off-chain processing.
AI / ML
Record immutable training metadata and dataset hashes so model provenance is auditable.
IoT
Manage device identity and anchor sensor data with hashes or batched commitments rather than raw telemetry.
Analytics & Cloud
Use Fabric as a verification layer while cloud systems perform heavy processing and storage.
Concrete scenario
A refrigerated transport solution records temperature telemetry in a gateway. The gateway stores raw readings in cloud storage and writes periodic hashes to Fabric. If a regulator audits a shipment, the shipper provides raw files and the regulator verifies hashes against the ledger.
Design checklist
  • • Decide what belongs on-chain (hashes, receipts) vs off-chain (raw telemetry).
  • • Use device identities and short-lived credentials for IoT devices.
  • • Plan batching frequency and anchor strategy to balance cost and traceability.
  • • Ensure analytics pipelines can resolve ledger pointers to raw data for verification.
Key Takeaway

Use Fabric as a tamper-evident provenance layer and avoid storing high-volume raw data on-chain; design identity and anchoring strategies up front.
