Module 12 › Chapter 12.4 › Storage & 3-2-1
Storage options
On-site: Fast restores, vulnerable to site disasters.
Off-site: Protects against site failure, but retrieval has latency and cost.
Cloud: Durable and scalable; requires secure configuration and cost planning.
Example implementation
Primary server, local NAS for quick recovery, and cloud object storage for off-site durability with lifecycle rules.
3-2-1 applied
Three copies, two media, one off-site
Practical choices: local disk, tape or object storage, and cloud archival. Implement immutable retention on the off-site copy when ransomware is a concern.
Key Takeaway

Balance speed and durability; keep an off-site copy and use multiple media types to reduce correlated failure risk.
