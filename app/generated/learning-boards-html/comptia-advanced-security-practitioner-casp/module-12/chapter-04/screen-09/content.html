Module 12 › Chapter 12.4 › Snapshots
What a snapshot does
Creates a point-in-time image including data and configuration.
Typically very fast and space-efficient on the same storage backend.
Ideal for recent logical error recovery and quick rollbacks.
Example use
Take snapshots before planned changes, then revert quickly if a configuration change causes an issue.
Limitations
  • Snapshots usually live on the same storage and are vulnerable to the same hardware issues.
  • They are not a substitute for immutable, off-site backups for long-term retention.
  • Combine snapshots with replication and periodic off-site backups for layered protection.
Key Takeaway

Use snapshots for speed and local rollback, but keep off-site, immutable backups for disaster resilience.
