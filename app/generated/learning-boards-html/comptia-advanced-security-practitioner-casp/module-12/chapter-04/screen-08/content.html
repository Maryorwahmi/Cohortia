Module 12 › Chapter 12.4 › Replication
When to replicate
Use replication for systems requiring minimal data loss or rapid failover.
Choose the replication layer based on recovery needs and complexity: storage, database, or application.
Always secure replication channels and use dedicated replication accounts with limited privileges.
Important

Replication is not a substitute for off-site backups because it mirrors both good and bad data.

Conceptual setup
-- Primary configuration: enable WAL and archive
wal_level = replica
archive_mode = on
archive_command = 'cp %p /path/to/wal_archive/%f'

-- Create a replication user
CREATE ROLE replica_user WITH REPLICATION LOGIN PASSWORD 'secure_password';
