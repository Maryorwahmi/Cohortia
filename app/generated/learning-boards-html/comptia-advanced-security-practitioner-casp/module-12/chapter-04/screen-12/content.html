Module 12 › Chapter 12.4 › Immutability & Air-gap
Immutable storage
Configure storage to prevent object modification or deletion for a set retention window. This protects backups against tampering and helps meet regulatory retention requirements.
Practical note
Enable object lock or equivalent features and test restores from immutable snapshots regularly.
Air-gapped backups
Keep a physically disconnected copy of critical backups, rotated and stored securely off-network. Air-gapped media provide the highest assurance that backups cannot be altered via network attacks.
Key Takeaway

Combine immutability and air-gapped copies to mitigate ransomware risk, and ensure procedures for accessing and restoring those copies are tested and documented.
