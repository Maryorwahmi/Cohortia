Module 12 › Chapter 12.4 › Backup Types
Type comparison
Full Backup
Copies all data. Pros: simplest restore. Cons: largest storage and longest runtime.
Incremental Backup
Copies changes since last backup of any type. Pros: fastest, smallest. Cons: restore requires chain of incrementals.
Differential Backup
Copies changes since last full backup. Pros: simpler restore than incremental. Cons: grows over time.
Key Takeaway

Match the backup type to expected restore speed and storage cost, and never favor backup speed over restore reliability without testing.

Concrete scenario
Weekly full + daily differential
This pattern restores with the last full plus the latest differential. It balances storage and restore complexity for many file servers with daily change windows.
Misconception
Incremental backups always save space without cost. In truth, they can increase restore risk because the chain must be intact; if retention policies accidentally delete an intermediate incremental, recovery fails.
