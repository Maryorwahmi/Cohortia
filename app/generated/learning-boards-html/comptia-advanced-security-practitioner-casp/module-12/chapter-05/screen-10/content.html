Designing an integrated exercise
  • Define a realistic scenario that spans IR, BCP, and DRP (e.g., ransomware + infrastructure failure).
  • Include all relevant stakeholders and decision-makers.
  • Force use of escalation thresholds and require a formal handoff.
  • Require snapshot and log preservation steps and document them.
  • Conduct a thorough post-exercise debrief and feed findings back into playbooks.
Example

Simulate a multi-stage ransomware event that also causes a data center power loss. Test how teams prioritize preservation and restoration while keeping critical services running via BCP.

Common mistakes in exercises
Running discipline-specific drills that never exercise handoffs, not including executives, and failing to implement lessons learned.
Key Takeaway

Make integrated exercises recurring, include decision authorities, and mandate post-exercise updates to playbooks.
