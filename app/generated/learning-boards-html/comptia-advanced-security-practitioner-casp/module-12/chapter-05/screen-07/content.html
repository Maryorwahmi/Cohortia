Module 12 › Chapter 12.5 › Communications
Required channels
  • Dedicated secure chat or conference bridge isolated from production networks.
  • Emergency phone tree for executive notification.
  • Immutable log offload destination for system and network logs.
  • Shared incident platform for status, tasks, and artifacts.
Artifact model
Incident logs, forensic findings, system status with RTO/RPO, and business impact reports form the authoritative set of records for decisions and audits.
Concrete example
IR uploads IOCs and affected host list to the incident ticket. DRP marks which backups are verified clean. BCP updates customer-facing availability expectations. Communications crafts the public statement once legal approves. Each entry is time-stamped and linked in the single incident record.
Key Takeaway

Predefine channels and artifacts so teams read and write to the same authoritative incident record under secure conditions.

Misconception: 'We can use email' — email lacks structure, speed, and separation from compromised systems. Prefer platformed incident records and encrypted, isolated communications.
