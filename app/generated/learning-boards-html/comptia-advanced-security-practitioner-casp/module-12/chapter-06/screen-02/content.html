Learning Objectives
Understand and apply crisis communication practices in BCP/DRP contexts.
Learn → Understand → Apply → Master
01
Build Crisis Plans
Create structured plans for internal and external communication.
You will learn the components that make a plan operational, such as spokespersons, channels, templates, and approval gates, so communication complements technical recovery.
Plan = Playbook
VERIFIED COMPETENCY MILESTONE
02
Map Stakeholders
Identify internal and external groups and their needs.
You will categorize employees, executives, customers, regulators, vendors, and media so messages are targeted and avoid information overload or omission.
Stake = Map
VERIFIED COMPETENCY MILESTONE
03
Craft Key Messaging
Write clear, consistent, and timely statements for audiences.
You will practice templates that acknowledge the event, state factual impact, outline actions, give next update timings, and convey empathy without exposing operational details that may harm recovery.
Message = Template
VERIFIED COMPETENCY MILESTONE
04
Monitor & Comply
Set up media relations, social listening, and legal-aware notification processes.
You will define monitoring tools, escalation for misinformation, and timelines for regulator notifications to avoid fines and reputational risk.
Monitor = Listen
VERIFIED COMPETENCY MILESTONE
