Module 12 › Chapter 12.7 › Full Interruption Tests
High Risk

Full interruption requires strict safeguards

It shifts production to recovery site and validates end-to-end recovery. Require approvals and a tested rollback plan.

Preconditions
Executive approval, communication plan, rollback strategy, and off-peak timing.
During test
Monitor transactions, validate data, and be ready to execute rollback if verification fails.
Safety Checklist
  • • Obtain clear executive sign-off and stakeholder notifications.
  • • Confirm rollback procedure and test it separately if possible.
  • • Select off-peak windows and have contingency contacts on call.
  • • Ensure monitoring and validation scripts are ready.
Key Takeaway

Treat a full interruption like a planned migration: prepare, approve, test rollback, and validate thoroughly.
