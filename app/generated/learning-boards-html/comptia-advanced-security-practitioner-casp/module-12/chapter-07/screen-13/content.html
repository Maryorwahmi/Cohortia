Task

Define objectives

  • • Objective 1: Restore application and DB to recovery environment within target RTO.
  • • Objective 2: Verify data integrity with no more than target RPO.
  • • Objective 3: Confirm communications and stakeholder notifications follow runbook templates.
Mnemonic: objective, scenario, steps, resources, KPI, owner, verify.
Plan

Scenario & steps

Scenario:
Storage array failure renders primary DB inaccessible; restore from off-site backup to recovery site.
  1. Declare DRP activation and notify teams.
  2. Provision recovery VMs and network isolation.
  3. Restore latest DB backup to recovery DB server.
  4. Restore web/application server images.
  5. Configure DNS/load balancer for recovery verification only.
  6. Run functional tests and data integrity checks.
  7. Validate access and secure credentials.
Proposed KPI

Actual Recovery Time (ART) measured from DRP declaration to verified full functionality, compared against the RTO target.
