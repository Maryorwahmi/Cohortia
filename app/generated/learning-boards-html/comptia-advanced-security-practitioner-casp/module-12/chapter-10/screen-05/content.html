Module 12 › Chapter 12.10 › Cloud-native building blocks
Primary services
Cross-Region Replication — automatic data copies across regions for low RPO and geographic redundancy.
Managed Databases — Multi-AZ and point-in-time recovery reduce manual failover work and simplify RPO management.
Serverless & Containers — portable compute that reduces infrastructure-dependency during failover.
Infrastructure as Code — codified stacks for rapid, repeatable provisioning of recovery environments.
Practical notes and examples
Examples to consider when designing a DR architecture:
  • Enable provider-native cross-region replication for object storage to avoid manual copy steps.
  • Use managed DB replicas or Multi-AZ features and validate point-in-time restores as part of tests.
  • Design applications to be stateless where possible so compute can scale quickly in a DR region.
  • Store IaC templates in source control and run automated tests that execute a dry provisioning to detect drift.
Key Takeaway

Choose the right combination of managed services and IaC to meet your RTO/RPO goals, then validate with repeatable tests.
