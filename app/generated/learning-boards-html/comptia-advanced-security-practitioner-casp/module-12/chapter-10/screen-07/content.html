Module 12 › Chapter 12.10 › AI / ML for Resilience
Capabilities
AI/ML can:
  • Perform predictive analytics on logs and metrics to identify upcoming failures.
  • Run continuous anomaly detection to shorten detection time for incidents.
  • Drive intelligent automation for recovery orchestration based on incident classification.
Misconception: Automating everything immediately is risky. Start with guided actions and validate models before enabling autonomous recovery.
Practical example
An ML model monitors RDS metrics and detects unusual latency patterns. Instead of an immediate failover, the system can trigger a scaled-up read replica, run health checks, and create a ticket for an operator when confidence thresholds are exceeded.
Concrete card: Predictive alert reduced outages by allowing proactive resource scaling before a full failure.
Common-mistake card: Relying on a single metric without context produces false positives; combine signals.
