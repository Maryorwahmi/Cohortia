GlobalTech mapping
A concise responsibilities table for multi-cloud components.
Backend API — AWS EC2 (IaaS)
  • Customer: OS patching, DB hardening, EDR, NSGs, logging.
  • Provider: hypervisor, physical infra, network fabric.
Frontend — Azure App Service (PaaS)
  • Customer: secure code, secrets in Key Vault, auth config, telemetry.
  • Provider: runtime patching, OS, middleware availability.
Support System — Salesforce (SaaS)
  • Customer: user lifecycle, MFA, role assignment, DLP/sharing rules.
  • Provider: application stack, platform security, uptime.
Action
Create runbooks and monitoring ownership: which alerts come from the provider, which alerts your SOC will investigate, and where to find evidence for compliance audits.
