Exercise: Assign ownership
For each task decide who owns it and list a remediation tool or process.
Tasks
  • Patch OS on a VM
  • Rotate an API key used by your app
  • Enable tenant-wide MFA
  • Configure runtime TLS settings
Guidance
  • If task touches OS or host config → Customer (IaaS).
  • If task touches code, secrets, or app config → Customer (PaaS).
  • If task touches user accounts or data sharing → Customer (SaaS).
  • If task touches physical infra or hypervisor → Provider.
Answer checklist
Explain your choice and name a tool or process, e.g., patch orchestration for VMs, Key Vault for secrets, identity provider and MFA for SaaS.
