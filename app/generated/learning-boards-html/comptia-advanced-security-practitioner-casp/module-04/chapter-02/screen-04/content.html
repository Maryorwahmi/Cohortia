IaaS — definition and analogy
Think: renting a car. Provider maintains the vehicle frame; you drive it and fill it.
  • Customer manages: guest OS, applications, data, patches, endpoint protection.
  • Provider manages: hypervisor, physical servers, networking, and data center facilities.
  • Common tasks: configure security groups or NSGs, harden OS, manage secrets, deploy EDR.
Example
AWS EC2: customer patches OS, installs antivirus, configures firewall rules.
Common mistake
Assuming provider patches guest OS; unpatched VMs remain vulnerable.
Visual: Responsibility stack
Provider: Physical infrastructure & hypervisor
Customer: Guest OS and middleware
Customer: Applications and data
Customer: Network security groups, logging, patching
Key Takeaway

IaaS provides flexibility and control but requires ownership of OS and application security processes.
