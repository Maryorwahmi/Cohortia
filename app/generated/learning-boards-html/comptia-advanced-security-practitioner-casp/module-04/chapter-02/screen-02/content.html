Learning Objectives
Skills to demonstrate after completing this chapter
Bloom: Learn → Understand → Apply → Master
01
Distinguish service models
Name IaaS, PaaS, SaaS and explain why each model changes what you must secure. Practice using analogies to remember boundaries.
VERIFIED COMPETENCY MILESTONE
02
Analyze shared responsibility
Map provider and customer responsibilities for each model so you can allocate controls and incident response scope effectively.
VERIFIED COMPETENCY MILESTONE
03
Design model-specific controls
Choose controls that match the model: patching and EDR for IaaS, secure coding and secrets management for PaaS, and access governance for SaaS.
VERIFIED COMPETENCY MILESTONE
04
Identify misconfigurations
Recognize common mistakes like unpatched VMs, exposed keys in PaaS, or permissive SaaS sharing and remediate them quickly.
VERIFIED COMPETENCY MILESTONE
