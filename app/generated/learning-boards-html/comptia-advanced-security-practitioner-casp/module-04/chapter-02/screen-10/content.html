Control selection by model
Choose controls where responsibility and risk live.
IaaS
  • Patch automation, EDR, host hardening
  • Network segmentation, NSGs, flow logs
  • Centralized logging and vulnerability scanning
PaaS
  • Secure coding, SAST/DAST
  • Secrets management and managed identities
  • Runtime telemetry and platform RBAC
SaaS
  • MFA, identity federation
  • Least privilege and role review
  • DLP, sharing controls, audit settings
Architectural note
Avoid mismatched controls. Use provider-native telemetry where possible rather than treating managed runtimes like VMs. Align tooling ownership with the shared responsibility map.
Key Takeaway

Design controls by ownership: keep host controls for IaaS, app controls for PaaS, and identity/data controls for SaaS.
