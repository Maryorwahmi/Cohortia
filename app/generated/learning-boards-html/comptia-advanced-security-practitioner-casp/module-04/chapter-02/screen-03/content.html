Practice: Responsibilities Table
Complete the table for each component in the scenario to prove you can allocate security tasks.
Backend API
Service model: IaaS (EC2)
  • Customer: OS patching, database hardening, EDR.
  • Provider: hypervisor, physical security, networking fabric.
Frontend Web App
Service model: PaaS (Azure App Service)
  • Customer: application code security, connection strings, auth.
  • Provider: runtime patching, OS, infrastructure.
Support System
Service model: SaaS (Salesforce)
  • Customer: user accounts, MFA, data sharing settings.
  • Provider: application stack, platform security, uptime.
