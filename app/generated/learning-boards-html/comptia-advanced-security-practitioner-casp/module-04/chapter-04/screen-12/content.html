Core Practice Secrets Management
Principles
  • Never bake secrets into images or commit them to source control.
  • Use an authenticated secrets store with access controls and rotation.
  • Inject secrets at runtime and mount them as files when possible.
Conceptual example
# Concept: inject secret at pod start
apiVersion: v1
kind: Pod
metadata:
  name: app
spec:
  containers:
  - name: app
    image: myapp@sha256:...
    env:
    - name: DB_PASSWORD
      valueFrom:
        secretKeyRef:
          name: db-secret
          key: password
Use a secret backend that supports rotation and auditing rather than static values in the image.
