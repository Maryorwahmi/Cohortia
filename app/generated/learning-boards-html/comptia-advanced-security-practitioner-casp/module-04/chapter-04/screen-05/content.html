Provenance and Integrity

Use image digests to pin an exact image and digital signatures to validate the publisher. Provenance shows who produced each layer and when.

Best practice
Pin images to a digest and require signed images for production deployments.
Common mistake
Using the latest tag leads to unreviewed changes and unpredictable vulnerabilities.
Registry Risks
  • Public registries can host malicious or outdated images.
  • Access controls and immutability policies reduce unauthorized pushes.
  • Automated scanning on push or pull helps detect vulnerabilities early.
Example
Integrate a scanner to block images that exceed a CVE severity threshold from being promoted to production.
