Common Mistakes Mistakes & Defenses
Using latest tag
Risk: unpredictable changes and hidden vulnerabilities. Defense: pin to digest and require review.
Privileged containers
Risk: breaks isolation and can lead to host compromise. Defense: avoid privileged mode and drop unnecessary capabilities.
Exposed daemon
Risk: remote control of host. Defense: secure the API with TLS and strict access control.
No vulnerability scanning
Risk: unknown CVEs reach production. Defense: integrate scanners into CI and schedule rescans.
Secrets in images
Risk: leaked credentials. Defense: use secret stores and inject at runtime.
Ignoring host security
Risk: kernel or runtime compromise undermines containers. Defense: keep host patched and monitored.
