Core Concept What containers are
Container & Image Definition

A container image bundles code, runtime, libraries, and configuration into a repeatable unit. A container is the running instance that uses namespaces and cgroups to isolate processes and resources, while sharing the host kernel.

Analogy
Think of an image as a sealed appliance and the container as the appliance running in your kitchen: many appliances share the same power grid (kernel).
Misconception
Containers are not full VMs. Kernel-level issues can affect all containers on a host.
Practical implications
  • Keep host kernel and container runtime patched; a host compromise affects all containers.
  • Limit privileges inside containers to reduce potential impact of an exploit.
  • Use user namespaces to map container root to an unprivileged host user when possible.
Key Takeaway
Treat the shared kernel as part of the attack surface and design defenses accordingly.
