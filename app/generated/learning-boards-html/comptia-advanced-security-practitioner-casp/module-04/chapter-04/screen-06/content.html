Process Image Scanning in CI/CD
Pipeline Flow
  1. Build image and tag with immutable digest.
  2. Push to staging registry.
  3. Run vulnerability scanner and collect machine-readable report.
  4. Enforce a policy: fail or block promotion if severity threshold is exceeded.
Rescan persisted images periodically and alert when new critical CVEs appear for images in use.
Example scanner output
{
  "image":"myapp@sha256:abc123",
  "findings":[
    {"cve":"CVE-2024-XXXX","severity":"HIGH","package":"libssl","fixed_in":"1.1.1k"}
  ]
}
Use this structured output to fail builds or create automated remediation tasks.
