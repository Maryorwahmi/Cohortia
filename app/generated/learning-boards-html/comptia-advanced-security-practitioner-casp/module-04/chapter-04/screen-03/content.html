Objective → Action
Inspect
Open an image manifest and list layers and packages to trace provenance.
Pin & Sign
Pin images to digests and require digital signatures before deploy.
Harden Runtime
Run non-root, drop capabilities, and set resource requests and limits.
Secrets & Scan
Use a secret store and integrate vulnerability scanning into pre-deploy CI checks.
Verification
Automated CI gates, audit scripts that check pod user and capability sets, and periodic image scanning reports are practical ways to prove compliance.
