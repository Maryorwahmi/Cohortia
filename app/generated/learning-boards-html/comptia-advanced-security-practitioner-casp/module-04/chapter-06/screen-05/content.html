Module 4 › Chapter 4.6 › Data Classification Process
Process
Inventory-to-Monitor workflow
1
Inventory
Catalog buckets, databases, and flows so you know where data lives.
2
Evaluate sensitivity
Classify by business impact and legal exposure.
3
Map regulations
Identify GDPR, HIPAA, PCI obligations that affect handling.
4
Apply controls
Select encryption, access rules, retention, and logging.
5
Monitor
Automate scans and audit logs to detect classification drift.
Example & Pitfalls
Reclassification prevents under-protection

If a public bucket later receives user uploads containing PII, automated reclassification and policy enforcement ensure encryption and access controls are applied before that data is exposed.

Common mistake: Relying on a one-time classification event instead of continuous checks.
Tip: Integrate cloud classification services to flag sensitive content and trigger remediation.
Key Takeaway
Make classification an ongoing, automated part of cloud operations.
