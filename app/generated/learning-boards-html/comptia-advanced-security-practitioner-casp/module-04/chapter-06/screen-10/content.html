Module 4 › Chapter 4.6 › Key Management Principles
Hierarchy
Root keys, data keys, and envelope encryption
A typical model uses a KMS-protected root or master key that wraps short-lived data keys used by applications. This reduces exposure and simplifies rotation.
Envelope encryption: applications request ephemeral data keys from KMS to encrypt data.
HSMs provide tamper-resistant key storage for the highest assurance keys.
Operational Controls
Rotation, access, and logging

Define rotation schedules and enforce least-privilege for key access. Log every key operation to support audits and incident response.

Mistake: Embedding keys into code repositories exposes secrets when code is shared or breached.
Key Takeaway
Use KMS and envelope encryption for operational safety; keep keys out of application code and document policies for audits.
