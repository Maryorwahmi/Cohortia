Module 4 › Chapter 4.6 › What is Cloud Data Security?
Definition
Protecting data across its lifecycle

Cloud data security requires different controls depending on whether data is stored, transmitted, or processed. This slide ties the lifecycle model to actionable steps: classify, protect, and operationalize.

Classify data to determine sensitivity and legal obligations.
Map controls: storage encryption, TLS/VPNs, and processing protections.
Operationalize with KMS, rotation, and auditable logs.
Analogy
A bank vault + armored truck + guarded teller

Think of storage like a vault, transit like an armored truck, and processing like the teller who sees the cash. Each needs different controls and monitoring.

Example: Customer orders are stored in a database (vault), sent by HTTPS (armored truck), and processed by backend services (teller).
Key Takeaway
Design controls for each state; don’t assume one control covers all risks.
