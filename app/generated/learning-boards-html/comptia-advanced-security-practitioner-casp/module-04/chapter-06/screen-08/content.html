Module 4 › Chapter 4.6 › Protecting Data in Transit
Core Controls
TLS, VPN, and mutual authentication
Ensure HTTPS with managed certificates for user-facing traffic.
Use mutual TLS or service mesh protections for inter-service authentication and encryption.
Use VPNs for on-premises to cloud links and encrypt cross-region replication channels.
Operational Example
Mutual auth between microservices

Require each microservice to present a certificate signed by a trusted CA and validate peers. This prevents stolen tokens or impersonation inside the cloud network.

Pitfall: Leaving internal service ports unencrypted because they are "private" increases lateral movement risk.
Key Takeaway
Encrypt all sensitive flows, including internal and hybrid links, and manage certificate lifecycles.
