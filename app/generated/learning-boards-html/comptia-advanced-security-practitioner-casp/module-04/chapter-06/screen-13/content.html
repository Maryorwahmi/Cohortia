Module 4 › Chapter 4.6 › Scenario: Multi-Tier Encryption
Task Steps
1. Classify RDS as Highly Confidential; S3 images as Public (reclassify if user data appears).
2. At-rest: Enable RDS engine encryption / disk encryption; use SSE-KMS for S3 to track key usage.
3. In-transit: Enforce HTTPS for browser to EC2, TLS for EC2 to RDS, and mutual TLS for microservices.
4. Key management: Use AWS KMS, envelope encryption for data keys, define rotation and IAM access policies.
Deliverable
Signed encryption plan

Produce a written plan: classification labels, encryption choices for each store, transit protections, KMS configuration and rotation schedule, and evidence collection method for audits.

Checkpoint: Verify snapshots and backups inherit encryption and are logged.
Key Takeaway
Translate the scenario into an auditable set of configuration steps and checks that enforce encryption and key governance.
