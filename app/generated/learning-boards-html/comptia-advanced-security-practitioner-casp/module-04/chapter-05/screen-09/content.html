Module 4 › Chapter 4.5 › Auditing & Monitoring
Log sources and storage
Enable CloudTrail or Activity Log and send events to immutable centralized storage with limited write/delete permissions.
  • Record management events and API calls for IAM changes.
  • Enable object versioning and write-once storage for audit integrity.
  • Control access to the log storage account tightly.
Key takeaway
Collect logs centrally, prevent tampering, and forward to a SIEM for analysis and alerting.
Detection and response
Create alerts for policy changes that add wildcard permissions, new admin roles, new access keys, and anomalous geographic access.
Common mistake
Relying on manual log review only. At scale you need automated detection and analyst reviews informed by alerts.
Check
Do your alerts cover policy changes, new keys, and privilege escalations, and are those alerts routed to an incident response workflow?
