Module 4 › Chapter 4.5 › S3 Least-Privilege Policy
IAM Policy JSON (example)
This policy grants only the s3:GetObject action on objects in the named bucket.
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::secure-app-data-12345/*"
    }
  ]
}
After creating this policy, attach it to a role or user. For a human user, require MFA. For an application, attach to a service role or instance profile and use temporary credentials where possible.
Testing checklist
  • Verify GetObject succeeds for permitted objects.
  • Verify PutObject and ListBucket are denied.
  • Check CloudTrail logs for the API calls and their evaluation result.
  • Rotate any existing keys and remove unused roles after testing.
Key takeaway
Write narrowly scoped policies and validate denies as well as allows to ensure least privilege.
