Operational objectives
Practical outcomes you will be able to perform after the lab.
Create scoped IAM policies
Write JSON policies that target specific actions and resource ARNs rather than using wildcards.
VERIFIED COMPETENCY MILESTONE
Enable MFA and SSO
Configure second factors for admins and federate with on-premises directories for single sign-on.
VERIFIED COMPETENCY MILESTONE
Collect and retain logs
Send CloudTrail or Activity Log events to immutable storage and a SIEM for alerts and forensic analysis.
VERIFIED COMPETENCY MILESTONE
Mnemonic & quick checklist
  • Identify actors: users, services, roles.
  • Define minimal actions: list required API calls.
  • Scope resources: specify exact ARNs or resource IDs.
  • Enable MFA and central logging.
Real-world connection
Teams that adopt these operational steps dramatically reduce the likelihood that a single compromised credential leads to full account compromise.
