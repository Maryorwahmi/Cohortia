Module 4 › Chapter 4.5 › Key Concepts
IAM
Framework for identities, policies, and enforcement that controls cloud access.
PoLP
Grant only the minimum permissions required for the task to limit exposure.
RBAC
Assign permissions to roles for consistent, scalable management of access.
Summary takeaway
Combine role-based definitions, least-privilege policies, MFA, federated identity, and immutable logging to create a resilient cloud identity posture.
