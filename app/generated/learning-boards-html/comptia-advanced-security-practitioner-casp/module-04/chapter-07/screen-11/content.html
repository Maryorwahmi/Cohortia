Module 5 › Chapter 4.7 › Cloud Incident Response
IR playbook elements
  • Roles and escalation paths, including CSP contact points.
  • Automated containment actions triggered by alerts.
  • Procedures for collecting ephemeral artifacts and snapshots.
  • Immutable central logging and retention for forensic integrity.
Example automated response
Anomalous WAF traffic triggers a serverless playbook that blocks the source IP in the security group, disables the suspect function’s trigger, and archives recent logs to an immutable store for analysis.
Key takeaway
Automate containment and evidence collection; ensure ownership and logging policies are clear before an incident occurs.
