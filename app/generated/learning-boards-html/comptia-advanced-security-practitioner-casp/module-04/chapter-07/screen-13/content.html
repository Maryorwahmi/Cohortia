Module 5 › Chapter 4.7 › Secure Architecture
Preventative
DevSecOps: SAST, IaC scanning, image scanning to stop insecure artifacts from being deployed.
Detective
CSPM: continuous posture; CWPP: runtime anomalies; service mesh metrics and tracing for visibility.
Responsive
Automated IR playbooks, artifact preservation, and immutable logging for forensics and recovery.
Key takeaway
Build layered controls mapped to lifecycle stages, and ensure each alert has an owner and an automated or documented action.
