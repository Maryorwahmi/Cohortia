Module 5 › Chapter 4.7 › CWPP
CWPP capabilities
Protect running compute with detection, mitigation, and enforcement.
Vulnerability scanning of runtime packages
Runtime anomaly detection and alerts
Host-based intrusion detection
Micro-segmentation and process controls
Example: A CWPP integration with Kubernetes detects a pod initiating unusual outbound traffic patterns. The platform isolates the pod's network access and raises an incident for investigation, limiting potential data exfiltration.
Misconception
Some teams view CWPP as optional if they have CSPM. In truth, CSPM does not see runtime exploitation; CWPP does.
Key takeaway
Combine CSPM and CWPP to cover both configuration drift and runtime threats, and integrate telemetry into response playbooks.
