Module 5 › Chapter 4.7 › Key Concepts
DevSecOps
Embed security checks into CI/CD and IaC to prevent insecure deployments.
CSPM
Continuous monitoring for misconfigurations and compliance across cloud accounts.
CWPP
Runtime protection for VMs, containers, and workloads to detect and contain threats.
Summary takeaway

Combine prevention in pipelines, continuous posture monitoring, runtime defenses, secure serverless practices, and automated IR to build resilient cloud security.
