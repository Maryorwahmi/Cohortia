Module 5 › Chapter 4.7 › DevSecOps
Definition
Security integrated into every development and deployment step, enforced by automated checks and policy-as-code.
• SAST: scan source code for patterns that introduce vulnerabilities.
• DAST: test running applications for exploitable behaviors.
• Image scanning: detect vulnerable packages before container push.
• IaC scanning: validate templates to prevent insecure infrastructure.
Common mistake
Turning every finding into a hard fail without developer context, which leads to bypasses or disabled checks.
Key takeaway
Start with fast, high-value checks in CI, then expand to deeper scans and automated remediations.
Pipeline example (conceptual)
Steps
1. Commit
Source commit triggers pipeline
2. SAST
Fast static scan on changed files
3. IaC scan
Validate Terraform/CloudFormation
4. Image scan
Block images with critical CVEs
Example
A pull request triggers SAST and an IaC scan. The IaC scanner marks an S3 bucket as public and failing the gate, so the developer must remove the public flag and enable server-side encryption before merge.
