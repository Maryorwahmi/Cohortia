Module 5 › Chapter 4.7 › CSPM
What CSPM does
Continuously scans cloud accounts to identify misconfigurations, compliance violations, and risky changes.
Unencrypted storage detection
Overly permissive IAM policy discovery
Open network ports and exposure
Drift from expected IaC configuration
Example: A CSPM tool alerts when an S3 bucket is created without encryption. The alert ties back to a rule in your policy inventory and suggests enabling server-side encryption and applying a bucket policy. If configured, automatic remediation could apply the encryption setting for newly detected buckets marked as low-risk changes.
Common misconception
CSPM is not a substitute for IaC scanning. It catches runtime drift and changes made outside of CI/CD, which IaC scanning cannot see.
Key takeaway
Use CSPM for continuous visibility and to trigger remediation or tickets for discovered misconfigurations.
