Module 4 › Chapter 4.1 › Hybrid Cloud
Four-step decision process
  1. Classify data and workloads for sensitivity and compliance.
  2. Choose secure connectivity (VPN, Direct Connect, ExpressRoute).
  3. Design unified identity (federation or directory sync).
  4. Centralize monitoring and logging for both environments.
Why it matters
Integration points are high-risk; a clear process prevents policy drift and reduces attack surface between clouds.
Concrete scenario
Move a web front end to public cloud but keep a PHI database on-premises. Use a dedicated interconnect for high bandwidth, enforce end-to-end encryption, federate identities for single sign-on, and ingest logs into a centralized SIEM for unified detection.
Common pitfall
Inconsistent access policies across environments create vulnerabilities at the connection boundary. Make policies identical or compensating controls clear.
