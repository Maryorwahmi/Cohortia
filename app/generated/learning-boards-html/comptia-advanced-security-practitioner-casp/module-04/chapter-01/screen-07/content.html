Module 4 › Chapter 4.1 › Community Cloud
Definition
Infrastructure shared by organizations with common regulatory or security needs, managed collectively or by a third party.
Security trade-offs
  • Shared compliance costs and specialized controls.
  • Requires governance: policies, roles, and trust agreements.
  • Each participant still secures application-level data and controls.
Concrete example
A consortium of healthcare providers uses a HIPAA-aligned community cloud. The infrastructure provides compliance controls centrally, but each provider implements and audits their own applications and patient data handling.
Governance check
Require a written trust framework, role definitions for access, and shared incident response procedures before onboarding.
