Module 4 › Chapter 4.1 › Identity & Access
Options
Synchronization copies identities into cloud IAM. Federation delegates authentication to your primary identity provider using SAML or OAuth.
Operational practices
  • Define role mappings and test for privilege creep.
  • Use conditional access and just-in-time elevation for sensitive roles.
  • Centralize access logs for auditing and incident response.
Concrete example
Use a directory sync tool or federation so employees sign in with their corporate account. Map cloud roles to on-prem roles carefully and audit for any mismatches that would grant extra privileges in the cloud.
Misconception
Assuming identity sync equals consistent access. Without role mapping and audits, privileges will diverge.
