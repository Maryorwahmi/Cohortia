Module 4 › Chapter 4.1 › Network Segmentation
Key patterns
  • Public subnets for front-end services, private subnets for data stores.
  • Dedicated interconnects for hybrid links and strict firewall rules at both ends.
  • Management plane isolation and just-in-time administrative access.
Key takeaway

Combine segmentation with flow logs and centralized monitoring to detect policy violations early.

Concrete example
Place a database containing sensitive records in a private subnet accessible only via a bastion host with MFA, and capture VPC flow logs forwarded to your SIEM to alert on unexpected access patterns.
Misconception
Segmentation without monitoring gives a false sense of security. Logs and alerts are essential to validate controls.
