Module 4 › Chapter 4.3 › Resource Allocation and Data Protection
Process

Quotas, reservations and encryption

  • Define CPU/memory reservations for critical VMs
  • Use storage quotas to avoid resource exhaustion
  • Enable disk encryption inside guests and TLS for data in transit
Concrete example
Reserve CPU and memory for a critical database VM so it cannot be starved by other VMs during spikes. Enable BitLocker inside Windows Server guests and require TLS for all database connections.
Misconception
Assuming storage-layer encryption alone is enough — combine hypervisor, storage, and guest-level protections with proper key management.
Key Takeaway

Guarantee resources for critical workloads and protect data both at rest and in transit using layered encryption and key management.
