Module 4 › Chapter 4.3 › Type 1 vs Type 2 Hypervisors
Comparison

Architecture and attack surface

Type 1 — Bare-metal
Runs directly on hardware, smaller codebase, preferred for production security. Example: ESXi, Hyper-V.
Type 2 — Hosted
Runs on top of a host OS, convenient for dev/test, larger attack surface because host OS vulnerabilities affect VMs. Example: VirtualBox.
Example scenario
Production vs Developer laptop
In production, choose Type 1 and dedicate a management network with MFA. On a developer laptop, Type 2 is fine but keep the host patched and avoid mixing sensitive workloads.
Misconception check
Type 2 is not inherently insecure; it simply inherits host risk. Security controls and context determine safety for a given use case.
Key Takeaway

Select the hypervisor model that matches operational controls: Type 1 for hardened production, Type 2 for isolated development usage.
