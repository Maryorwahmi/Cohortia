Operational Competency

Implement hardening and verify controls

You will practice specific steps for ESXi host hardening, Windows Server guest hardening, and for designing virtual network policies that enforce least privilege between VMs.

Why it matters
Operational verification prevents configuration drift and ensures a VM compromise cannot escalate to a full host compromise. Tools such as automated inventory and infrastructure-as-code help ensure consistent, auditable deployments.
Hands-on
ESXi and Windows Server 2019 hardening scenario
You will list host and guest hardening steps and design a vSwitch/port group layout to isolate a critical VM from less sensitive services.
Measurement
Success is measured by a documented hardening checklist, an isolated network design for the critical VM, and a plan to automate provisioning and inventory to prevent sprawl.
