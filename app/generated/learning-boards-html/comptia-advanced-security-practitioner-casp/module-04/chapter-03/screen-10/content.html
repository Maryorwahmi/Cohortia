Module 4 › Chapter 4.3 › Hardening Guest Operating Systems
Definition

Treat VMs as endpoints

  • Apply security baselines (CIS)
  • Install and maintain EDR/antivirus
  • Regular patching schedule for OS and apps
  • Enable disk encryption for sensitive workloads
Concrete example
Windows Server 2019 guest
Apply CIS baseline, enable BitLocker, install EDR, and schedule automated monthly patch windows. Use provisioning templates to ensure these controls are present at creation.
Misconception
A secure hypervisor makes guest hardening optional — false. Guests require their own security controls regardless of host protections.
Key Takeaway

Ensure each VM is provisioned with baseline security controls and automated to remain compliant across its lifecycle.
