Core Concept

Hypervisor responsibilities

A hypervisor abstracts physical resources and enforces isolation between guest VMs. Security depends on the hypervisor's integrity, code size, and exposed services.

Tasks
  • CPU and memory scheduling
  • Virtual device emulation
  • Network and storage multiplexing
Security role
Enforce isolation, host management access, and apply patches to any hypervisor services.
Analogy
A hypervisor is like a building manager
The manager allocates rooms and services; if the manager is compromised, tenants' isolation fails. That illustrates why the hypervisor must be minimal and tightly controlled.
Common misconception
Treating the hypervisor like a normal application leads to lax patching and unnecessary services. Instead, harden and monitor it as critical infrastructure.
Key Takeaway

Protect the hypervisor first — its compromise undermines all guest isolation and platform security.
