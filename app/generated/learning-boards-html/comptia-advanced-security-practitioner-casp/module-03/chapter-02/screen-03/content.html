Lab Walk-through Objectives

Vendor-agnostic checkpoints you will complete in the lab.

Checklist style
WPA3 Components
  • Access Points, RADIUS server, CA, client profiles
  • Document EAP choice and certificate lifecycle
MDM Policy
  • Password rules, encryption, app control, remote wipe actions
  • Enrollment and compliance reporting steps
Guest Network
  • VLAN isolation, firewall ACLs, captive portal, rate limiting
  • Verify no Layer 3 access to internal VLANs
Rogue AP Checklist
WIDS signature alerts, scans for duplicate SSIDs, physical inspection, and port security on switches to limit unknown devices.
Verification Milestone
Documented configuration that enforces 802.1X, an MDM policy, and a verified guest isolation rule set.
