Hands-On Activity

Checklist: RADIUS, AP, Client

Use this vendor-agnostic sequence to configure WPA3 Enterprise and validate authentication.
Step Checklist
  1. Prepare CA and issue server certificate for RADIUS.
  2. Configure RADIUS: enable 802.1X, select EAP method, connect to identity store.
  3. AP configuration: create SSID with WPA3 Enterprise, point to RADIUS and set shared secret.
  4. Client setup: provision Wi‑Fi profile, require server certificate validation; install client certs if EAP-TLS.
  5. Verify: initiate connection and review RADIUS logs for acceptance and assigned VLAN.
Key Takeaway

Work in small batches: validate the full chain—CA, RADIUS, AP, client—before wide deployment to catch certificate and validation issues early.

Verification Example
RADIUS Log Walk-through
# Example conceptual log lines
EAP-Request/Identity for user@example.com
EAP-Response received, initiating TLS tunnel
User authenticated; Access-Accept; VLAN assigned
Session start: radius-username=user@example.com; vlan=100
Interpretation: confirm EAP exchange, Access-Accept, and VLAN assignment to verify successful authentication.
Common Mistake
Skipping client configuration for server certificate validation allows rogue RADIUS impersonation. Always test client validation behavior.
