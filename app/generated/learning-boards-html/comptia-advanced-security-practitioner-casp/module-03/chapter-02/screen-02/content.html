Learning Objectives

Skills to evaluate, design, and deploy secure wireless and mobile controls.

Bloom: Learn → Understand → Apply → Master
01
Deploy WPA3 Enterprise

Implement SAE and 802.1X with RADIUS to provide stronger per-user authentication and forward secrecy. Verified competency milestone: network uses 802.1X for user authentication.

Mnemonic: lock + certificate icon
02
Choose EAP methods securely

Evaluate EAP-TLS, PEAP, and TTLS; enforce server certificate validation to prevent credential interception. Verified competency milestone: EAP method rationale documented.

Mnemonic: shield + tunnel
03
Design MDM & MAM policies

Create enforceable device and app policies for encryption, passwords, app restrictions, and selective wiping. Verified competency milestone: MDM policy template completed.

Mnemonic: phone with shield
04
Detect and prevent rogue APs

Use WIDS, port security, and audits to detect unauthorized APs and respond. Verified competency milestone: rogue AP response checklist available.

Mnemonic: radar
