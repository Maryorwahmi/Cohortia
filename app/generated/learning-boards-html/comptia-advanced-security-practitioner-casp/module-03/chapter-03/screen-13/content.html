Common mistakes and remedies

Mistake: Broad SNMP views
Remedy: Create restrictive views that expose only necessary OIDs for monitoring and map those to SNMPv3 groups.
Mistake: DNSSEC but open/unpatched servers
Remedy: Harden and patch DNS servers, restrict recursion, and automate key rollovers for DNSSEC.
Mistake: CoPP too aggressive
Remedy: Test policer thresholds in lab and monitor counters to ensure routing and management traffic continue at safe rates.
Mistake: SSH keys not generated
Remedy: Ensure domain name is set and RSA keys are generated, then prefer key-based auth and disable legacy versions.
Reflect

Which mistake is most likely in your network? Plan one immediate test you will run to reveal that misconfiguration and one fix you will apply in the next maintenance window.
