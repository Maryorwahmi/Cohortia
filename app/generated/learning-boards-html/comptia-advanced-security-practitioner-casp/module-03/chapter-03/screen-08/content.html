Authenticated NTP and redundancy

Authenticate NTP associations to prevent spoofed time updates. Use multiple independent trusted sources so a single compromised server cannot corrupt device clocks.

Command examples
ntp authenticate
ntp trusted-key 1
ntp server 192.0.2.1 key 1
ntp server 198.51.100.2 key 1
Verification
  • Check NTP associations show authenticated status.
  • Confirm logs show consistent timestamps across devices.
Why it matters

Accurate, trusted time underpins forensic timelines and certificate validity. Protecting NTP prevents attackers from masking or altering events.

Key Takeaway

Treat NTP as a security service: authenticate peers and use redundancy to maintain reliable timestamps.
