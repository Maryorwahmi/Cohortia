Module 3 › Chapter 3.3 › Device Hardening Essentials
Definition

Remove defaults and unused attack vectors

Hardening reduces easy entry points by changing defaults, disabling insecure protocols, and shutting down unused interfaces so the device exposes only required services.

Checklist
  • Change default credentials and use MFA where possible.
  • Disable Telnet, HTTP; enable SSH only.
  • Shutdown unused interfaces and remove from active VLANs.
  • Remove unused services and verify running processes.
Key Takeaway

Hardening basics block the majority of opportunistic attacks; automate them in device baselines.

Concrete example: disabling unused interfaces
interface GigabitEthernet0/1
 description Unused — reserved
 switchport access vlan 999
 shutdown
!
interface GigabitEthernet0/2
 description Production — DO NOT SHUTDOWN
 switchport access vlan 10
 no shutdown
Misconception

Some operators think placing an unused port in an unused VLAN is enough. That reduces risk but leaving the interface up still allows cable-level access and attacks like ARP spoofing. Shutdown is the correct default for unused ports.

Pro tip
Include shutdown in your device bootstrap so every fresh device arrives hardened.
Check
Use show interface status and configuration audit scripts to confirm interfaces are administratively down when unused.
