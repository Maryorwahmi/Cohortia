Module 3 › Chapter 3.3 › SNMPv3: Secure Monitoring
Definition

SNMPv3 with views, groups, and users

SNMPv3 adds authentication and encryption. Restrict access with views and groups so monitoring accounts can only read required OIDs.

snmp-server view SECUREVIEW iso included
snmp-server group SECUREGROUP v3 auth priv read SECUREVIEW
snmp-server user COHORTIAUSER SECUREGROUP v3 auth sha COHORTIAPASS priv aes 128 COHORTIAENC
Verification steps
  • Query allowed OIDs with an SNMPv3 client and confirm restricted output.
  • Confirm encryption and auth algorithms active in device show output.
Why it matters

SNMP data is valuable to attackers; using SNMPv3 prevents credential exposure and limits what an attacker could learn from a stolen monitoring account.

Common mistake

Using SNMPv3 but binding it to a broad view that exposes configuration defeats the purpose. Apply least privilege to OIDs.

Key Takeaway

SNMPv3 must be scoped and encrypted; treat the collector and transport path as part of the trust boundary.
