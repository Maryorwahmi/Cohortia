Module 3 › Chapter 3.3 › NetFlow/IPFIX
Concept

Flow telemetry for security analysis

NetFlow and IPFIX export compact flow records that reveal traffic patterns and help detect anomalies that point to compromise or exfiltration.

Best practices
  • Export to a dedicated, secured collector on a management network.
  • Use encrypted tunnels if exports traverse untrusted segments.
  • Integrate flows into SIEM for correlation with logs and alerts.
Concrete setup example

Configure a router to export NetFlow to 10.10.10.5 over an IPsec-protected management link or place the collector on an isolated VLAN reachable only by security tools.

Why it matters

Visibility through flows helps detect attacks early; secure the pipeline so visibility cannot be disrupted by an attacker.
