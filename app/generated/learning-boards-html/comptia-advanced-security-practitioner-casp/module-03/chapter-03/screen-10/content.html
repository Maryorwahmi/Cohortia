Module 3 › Chapter 3.3 › Control Plane Policing (CoPP)
Process

Match → Classify → Police → Apply

Define ACLs to match control traffic, group matches with class-maps, police via policy-maps, and apply to the control-plane to protect CPU resources.

ip access-list extended COPP_ACL
 permit tcp any any eq 22
 permit udp any any eq 161
class-map match-all COPP_CLASS
 match access-group name COPP_ACL
policy-map COPP_POLICY
 class COPP_CLASS
  police 8000 1500 conform-action transmit exceed-action drop
control-plane
 service-policy input COPP_POLICY
Verification
  • Check policer counters for exceed events.
  • Confirm necessary control protocols still pass at expected rates.
Why it matters

CoPP prevents an attacker from overwhelming CPU resources with floods targeting routing or management functions, preserving device and network availability.

Common mistake

Overly broad policing can drop legitimate control traffic; tune limits and monitor counters to avoid collateral impact.
