SSHv2 with RSA keys

ip domain name cohortia.local
crypto key generate rsa modulus 2048
ip ssh version 2
username admin privilege 15 secret StrongSecret!
line vty 0 4
 transport input ssh
 login local
Verification
  • Confirm rsa key size and SSH version via show commands.
  • Attempt key-based auth from a client and confirm password auth behavior.
Why it matters

Encrypted management prevents credential theft and session tampering. Keys reduce replay and brute-force risk. Disabling older protocol versions reduces cryptographic attack surface.

Common mistake

Forgetting to set the domain name prevents key generation on many devices. Also, leaving password-based login enabled without lockout allows brute-force attempts.

Try this

Generate an RSA key, enable SSHv2, and test a key-based login from a lab client to confirm the flow.
