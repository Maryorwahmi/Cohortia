snmp-server group SECUREGROUP v3 auth priv read SECUREVIEW
snmp-server user COHORTIAUSER SECUREGROUP v3 auth sha COHORTIAPASS priv aes 128 COHORTIAENC
!
! CoPP
ip access-list extended COPP_ACL
 permit tcp any any eq 22
 permit udp any any eq 161
class-map match-all COPP_CLASS
 match access-group name COPP_ACL
policy-map COPP_POLICY
 class COPP_CLASS
  police 8000 1500 conform-action transmit exceed-action drop
control-plane
 service-policy input COPP_POLICY
Test plan
  1. Confirm SSHv2 key-based login from lab client.
  2. Run SNMPv3 queries scoped to SECUREVIEW and verify output.
  3. Simulate a flood and check CoPP counters and policy hits.
Common mistake

Applying CoPP without validating ACL matches can block legitimate admin traffic. Validate ACLs in a lab and monitor counters after deployment.

Key Takeaway

Build and validate a hardened baseline in lab, then automate its deployment with configuration management tools.
