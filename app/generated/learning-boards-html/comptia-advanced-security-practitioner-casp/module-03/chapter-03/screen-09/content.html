Signed zones for name integrity

DNSSEC uses keys to sign DNS records so resolvers can verify authenticity. It prevents cache poisoning and ensures a domain's IP mappings are the owner's choices.

Operational notes
  • Sign zones and publish DS records in the parent zone.
  • Plan key rollovers and maintain signing automation.
  • Harden DNS servers and restrict recursion where unnecessary.
Common mistake

Relying only on DNSSEC but leaving servers with open recursion or known vulnerabilities still exposes resolution infrastructure. DNSSEC protects responses, not server operations.

Key Takeaway

Use DNSSEC to validate records and harden servers to prevent attackers from abusing resolver or authoritative implementations.
