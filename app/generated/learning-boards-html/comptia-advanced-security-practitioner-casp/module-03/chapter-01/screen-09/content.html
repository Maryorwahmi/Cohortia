Process Flow

Secure inter-VLAN routing

Define allowed flows, implement ACLs or firewall rules at the Layer 3 hop, then monitor and refine.

Step 1: Inventory flows
List required services between segments (protocol, port, source, destination).
Step 2: Implement rules
Translate inventory into ACLs or firewall rules at the router or Layer 3 switch.
Step 3: Verify and log
Run connection tests, capture traffic where necessary, and enable deny logging to detect abuse.
Example ACL excerpt
access-list 101 permit tcp host 10.10.1.5 host 10.10.2.8 eq 22
access-list 101 permit tcp 10.10.1.0 0.0.0.255 10.10.3.0 0.0.0.255 eq 443
access-list 101 deny ip any any log
interface GigabitEthernet0/0.1
 ip address 10.10.1.1 255.255.255.0
 ip access-group 101 in
Key Takeaway

Enforce least privilege at the routing hop, log denies for detection, and avoid broad allow rules to reduce lateral movement risk.
