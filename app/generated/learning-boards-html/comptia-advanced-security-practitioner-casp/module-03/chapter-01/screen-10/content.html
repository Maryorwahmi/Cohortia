Comparison

Switch spoofing vs double tagging

Switch spoofing
An attacker negotiates a trunk to access multiple VLANs. Defend by disabling DTP and explicitly configuring trunk/access modes.
Double tagging
A frame carries two VLAN tags to slip into another VLAN. Defend by keeping native VLANs unused and ensuring trunk native configuration is explicit.
Practical mitigations
  • Disable DTP on user-facing ports.
  • Use explicit access and trunk port configuration.
  • Set a dedicated, unused native VLAN on trunks.
  • Implement port security to limit MAC addresses per port.
Common mistake

Overlooking native VLAN and DTP settings on trunk ports can leave an otherwise segmented network vulnerable to VLAN hopping attacks.
