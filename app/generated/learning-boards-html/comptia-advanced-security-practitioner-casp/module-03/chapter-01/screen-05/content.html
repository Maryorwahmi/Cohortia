Definition

VLANs and PVLANs

VLANs separate broadcast domains. PVLANs restrict communication between hosts inside the same primary VLAN to prevent lateral movement.

PVLAN port types
  • Promiscuous: can reach all ports in the PVLAN.
  • Isolated: can only reach promiscuous ports.
  • Community: can reach promiscuous ports and other community members.
Analogy
Think of a primary VLAN as a floor in a building; PVLANs are private offices on that floor. The receptionist (promiscuous) can reach all offices, but offices can't reach each other unless they're in the same suite (community).
Key Takeaway

PVLANs give fine-grained host isolation within a VLAN, ideal for DMZs and shared hosting scenarios when properly configured and tested.

Configuration checklist
  • Define primary VLAN and secondary isolated/community VLANs.
  • Associate secondary VLANs with the primary VLAN.
  • Set host ports to private-vlan host and assign associations.
  • Mark firewall or uplink as promiscuous and map secondary VLANs to it.
  • Verify reachability matrix and management access.
Example scenario
Two web servers should both reach the firewall but must not reach each other to prevent lateral movement if one is compromised.
