PVLAN Configuration

Below is a concise, Cisco IOS-like configuration snippet you can adapt to a simulator. Use this as a template and change interface names and VLAN IDs for your lab.

! Global Configuration
vlan 100
 private-vlan primary
vlan 101
 private-vlan isolated
vlan 102
 private-vlan isolated
vlan 100
 private-vlan association 101,102

! Interface for Server A
interface GigabitEthernet0/1
 switchport mode private-vlan host
 switchport private-vlan host-association 100 101

! Interface for Server B
interface GigabitEthernet0/2
 switchport mode private-vlan host
 switchport private-vlan host-association 100 102

! Interface for Firewall
interface GigabitEthernet0/3
 switchport mode private-vlan promiscuous
 switchport private-vlan mapping 100 101,102
Verification steps
  1. Show VLAN brief and confirm primary and secondary VLANs exist.
  2. Show private-vlan mapping to confirm associations.
  3. From Server A, ping firewall and Server B: expect firewall success, Server B fail.
  4. Capture traffic on the firewall port to confirm only expected flows egress.
Common mistake

Not mapping secondary VLANs to the promiscuous port prevents firewall reachability or allows unintended peer connectivity. Always verify mappings and port modes.
