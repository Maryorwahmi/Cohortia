Hands-on Activity

Implement PVLANs for DMZ Isolation

Step-by-step
  1. Create VLAN 100 as primary and VLANs 101 and 102 as isolated secondaries.
  2. Associate 101 and 102 with primary 100.
  3. Configure Server A port as private-vlan host associated with 100/101.
  4. Configure Server B port as private-vlan host associated with 100/102.
  5. Configure firewall port as promiscuous and map it to 100/101,102.
  6. Verify reachability: Server A → firewall: success, Server B → firewall: success, Server A → Server B: fail.
Verification checklist
show vlan brief, show private-vlan mapping, ping matrix, packet capture on firewall, document results.

Key Takeaway

Follow the mapping strictly and verify. Mis-assigned secondary VLANs or promiscuous mappings are the usual causes of failed isolation.
