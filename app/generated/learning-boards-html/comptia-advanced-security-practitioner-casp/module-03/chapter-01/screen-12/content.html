Assessment idea

What to test

  • Concept question: VRF is best for separate routing tables with overlapping addresses.
  • Configuration submission: PVLAN and VRF command snippets.
  • Verification artifacts: ping matrix, packet captures, and ACL logs.
Common operational pitfalls
  • Not applying ACLs at inter-VLAN routing points.
  • Mistaken PVLAN associations or missing promiscuous mappings.
  • Using native VLANs for user traffic and leaving DTP enabled.
  • Failing to secure SDN controller or NFV orchestration APIs.
Validation Tip

Require both configs and evidence: a configuration alone is not enough without verified reachability results and logs.
