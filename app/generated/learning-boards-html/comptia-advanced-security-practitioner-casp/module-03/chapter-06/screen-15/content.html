Key Concepts: Part 1

Foundational Terms in Virtualization and Container Security

Hypervisor

Software that creates and runs VMs, abstracting hardware. Type 1 (bare-metal) is more secure for production.

VM Escape

An attack where an attacker breaks out of a compromised VM to gain control of the hypervisor or other VMs.

Containerization

Lightweight virtualization packaging apps into isolated user-space environments sharing the host OS kernel.

Summary Takeaway

Virtualization and containerization offer distinct abstraction layers, each with unique security challenges like VM escape, requiring specialized protection strategies.
