Learning Objectives
Understand and apply cloud configuration and identity controls for IaaS and PaaS.
01
Apply the shared responsibility model
Explain provider vs customer security duties and why OS and network configuration in IaaS belong to you. Verified competency milestone: create a responsibility matrix for a migration.
02
Secure IaaS components
Harden VMs, enforce network rules, and enable encryption for storage. Milestone: apply host hardening and a security group that implements least privilege.
03
Analyze PaaS risks
Identify responsibilities for serverless and managed databases, like code security and auth. Milestone: create a checklist for securing functions and managed DBs.
04
Design IAM and CSPM strategy
Write least-privilege IAM policies and integrate CSPM for continuous detection and remediation. Milestone: attach a restrictive policy and validate via test.
