Comparison
Security Groups (Stateful)
Instance-level firewall that remembers connection state. Ideal for per-instance access rules and fine-grained control.
When to use
Limit SSH, database ports, and application endpoints to specific sources.
Behavior
Tracks state; return traffic is allowed automatically if outbound was allowed.
Comparison
Network ACLs (Stateless)
Subnet-level filters. Each direction requires explicit rules. Useful as an additional layer or to enforce broad policies.
When to use
Apply a subnet-wide deny for unexpected ports or to restrict traffic to firewall appliances.
Behavior
Stateless: you must add rules for inbound and outbound separately.
Example
Allow SSH only from a jump host using security groups; deny other IP ranges with NACLs.
Common mistake
Permitting 0.0.0.0/0 for management ports for convenience.
Key takeaway
Apply both layers as needed and enforce least privilege for network rules.
