IAM Policy JSON — Read-only to a bucket
A minimal least-privilege policy that allows object reads and denies writes and listing.
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:GetObject"
      ],
      "Resource": [
        "arn:aws:s3:::cohortia-secure-data/*"
      ]
    },
    {
      "Effect": "Deny",
      "Action": [
        "s3:PutObject",
        "s3:DeleteObject",
        "s3:ListBucket"
      ],
      "Resource": [
        "arn:aws:s3:::cohortia-secure-data/*",
        "arn:aws:s3:::cohortia-secure-data"
      ]
    }
  ]
}
Explanation
Allow grants GetObject on object ARNs. Deny explicitly prevents PutObject, DeleteObject, and ListBucket on the bucket and objects.
Verification
Attach to a test user and try upload, delete, list, and download. Only download should succeed.
Key Takeaway

Use explicit resource ARNs and Deny statements to reinforce least privilege when other policies may exist.
