Module 4 › Chapter 3.7 › Verification Tasks
Task: Responsibility Matrix
Map provider vs customer for infrastructure, OS, apps, and data. Use this to avoid operational gaps.
Task: Harden a VM
Apply hardened image, install patches, and restrict inbound rules to necessary ports only.
Task: Secure a bucket
Enable block public access, default encryption, and versioning for recovery.
Task: Least-privilege policy
Author a policy that only allows GetObject on a specific bucket and validate actions with test credentials.
