Definition
Serverless Functions
The provider manages servers; you manage code, dependencies, and the identity permissions the function uses.
Code security
Sanitize inputs, avoid injection patterns, and scan dependencies for vulnerabilities.
Permission management
Assign a role with only required permissions. Avoid wildcards in action lists.
Concrete example
A function that processes images should have permissions only for reading from a specific bucket and writing thumbnails to a different bucket. It should not have broad list or delete permissions.
Common mistake
Granting a function broad roles that include administrative actions because it simplifies development. This increases blast radius if code is compromised.
Key Takeaway

Treat serverless functions as privileged code: secure dependencies, validate inputs, and use strict IAM roles.
