Module 4 › Chapter 3.7 › Key Concepts
Shared Responsibility
Provider secures infrastructure; you secure OS, apps, data, network, and identity.
IaaS vs PaaS
IaaS needs OS patching and hardening; PaaS reduces host duties but not app or data security.
Network Controls
Security groups are stateful; NACLs are stateless. Use both to limit blast radius.
Summary

Clear responsibility mapping and defense-in-depth across compute, storage, network, and identity reduce risk in cloud deployments.
