Secure Boot: Trusting the Boot Process

Preventing low-level malware from compromising system startup

Definition

Secure Boot is a feature of UEFI firmware that ensures only trusted software (signed by a valid digital certificate) can load during the boot process, preventing rootkits and low-level malware.

How it Works
  • •UEFI firmware checks digital signatures of boot components.
  • •Only signed and approved software is allowed to load.
  • •Blocks unauthorized bootloaders or OS components.
  • •Establishes a chain of trust from firmware to OS.
