Module 3 › Chapter 3.4 › SIEM Integration
Architecture

Collect, normalize, correlate

Collection
Forward logs from NGFW and IPS to the SIEM with timestamps and context.
Normalization
Standardize fields so events can be correlated across sources.
Correlation example
Failed server login + an IPS-detected port scan from the same IP = likely targeted attack; escalate priority.
Operational tips
  • Prioritize high-value logs to manage volume.
  • Use enrichment (user, asset) to add context to alerts.
  • Tune correlation rules to avoid flooding analysts with low-value incidents.
