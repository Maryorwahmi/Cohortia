Conceptual Policy - Readable
NGFW Security Policy - Internet Egress

Rule 1: IT Admin Access (User-Aware)
    Source Zone: Internal_IT
    Source User Group: IT_Admins (from AD)
    Destination Zone: Internet
    Applications: Any
    URL Category: Any
    Action: Allow
    Logging: Enabled

Rule 2: General Employee Web Access
    Source Zone: Internal_Users
    Source User Group: All_Employees (from AD)
    Destination Zone: Internet
    Applications: web-browsing, smtp, pop3, imap, corporate-vpn
    URL Category: news, business, education (allow); gambling, adult, malware (block)
    Action: Allow (for allowed apps/categories), Block (for blocked categories)
    Logging: Enabled
    Threat Profile: Apply default-threat-prevention-profile

Rule 3: Block High-Risk Applications
    Source Zone: Any
    Source User Group: Any
    Destination Zone: Internet
    Applications: bittorrent, tor, any-p2p
    Action: Deny
    Logging: Enabled
    Threat Profile: Apply strict-threat-prevention-profile

IPS Tuning Example:
    Problem: SNORT_ALERT_12345_INTERNAL_APP_SQLI triggers on ReportGen -> ReportingDB
    Solution: Verify, then create an exception for ReportGen IP to ReportingDB IP on DB port or create a custom signature.
Example usage
Deploy in monitoring mode, review logs, then enforce rules in phases while tuning IPS signatures.
Checkpoint
Verify that blocking a category doesn't prevent business-critical sites; maintain an allowlist for exceptions.
