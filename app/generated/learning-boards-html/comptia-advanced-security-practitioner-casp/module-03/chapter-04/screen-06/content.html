Module 3 › Chapter 3.4 › Configuring NGFW Features
Process

Phased NGFW configuration

1
Inventory apps & categories
List business apps and risky categories before writing rules.
2
Create baseline policies
Allow essential services and block known risky apps.
3
Monitor, sandbox, tune
Use monitoring mode and sandboxing to refine rules before enforcement.
4
Enforce and review
Enable enforcement in phases and keep logging active for SIEM ingestion.
Concrete example
Policy: Allow HTTP/HTTPS, corporate VPN, and mail; block bittorrent, tor; block URL categories gambling, adult, known malware. Send unknown executables to sandbox for analysis before blocking.
Common Mistake

Turning on every prevention feature at once leads to false positives and capacity problems.
