Module 3 › Chapter 3.4 › Traditional vs NGFW
Comparison

Traditional firewall

Inspects IP, port, and connection state. Fast and predictable, but blind to the application payload.

Layer 3/4 rules
Decisions based on IP and port.
Low payload visibility
Cannot enforce app-specific policies.
Comparison

Next-Generation Firewall

Adds DPI, application awareness, user identity integration, and often integrated IPS and threat prevention profiles.

Application control
Policies target applications, not only ports.
User identity awareness
Tie rules to AD groups for finer control.
Example

An NGFW recognizes Facebook traffic even if it is on port 80 and can block only the Facebook app while allowing other web browsing. This is useful where app-level control matters for productivity or risk reduction.

Key Takeaway

NGFWs provide context that enables precise policy and integrated prevention, but they must be tuned to avoid performance or false-positive issues.
