Process

Sensor placement workflow

  1. Map asset criticality and traffic flows.
  2. Identify perimeter and internal chokepoints for NIPS placement.
  3. Deploy HIPS on critical hosts where host context is needed.
  4. Collect baseline alerts in monitoring mode and tune signatures.
  5. Plan redundancy and fail-open / fail-closed behavior for availability.
Scenario card
Place a NIPS at the internet egress to catch scans and malicious inbound traffic. Add a NIPS between the DMZ and internal network to monitor web server traffic to backend databases. Install HIPS on database servers to detect suspicious local activity.
Pro tip

Begin in monitoring mode and tune signatures for the observed traffic patterns before enabling inline blocking.
