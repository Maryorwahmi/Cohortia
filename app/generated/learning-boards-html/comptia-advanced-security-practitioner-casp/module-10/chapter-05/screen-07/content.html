Module 10 › Chapter 10.5 › Software Composition Analysis
Purpose

Identify known vulnerabilities and licensing issues in open-source and third-party components.

Automation
Run on dependency files and build artifacts as part of CI.
Remediation
Suggest upgrades or alternative components and integrate with issue trackers.
Concrete Scenario
An SCA scan reports a critical CVE in a transitive dependency. The pipeline creates a high-priority ticket linking the affected artifact and suggests specific versions to upgrade. The responsible developer schedules the fix into the next sprint and the pipeline blocks deployment until remediation is complete or an approved exception is documented.
Common Mistake

Treating every CVE the same causes fatigue. Prioritize based on severity, exposure, and exploitability.
