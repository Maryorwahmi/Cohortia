Module 10 › Chapter 10.5 › Security Tool Families
Tool Comparison

How tool groups map to CI/CD stages and feedback types.

SAST — Code
Finds code-level vulnerabilities and insecure patterns before execution.
SCA — Dependencies
Reports known CVEs and licensing issues in third-party components.
DAST — Runtime
Exercises the running app to find runtime and configuration flaws.
IaC & Container Scan
Prevent insecure infra and vulnerable images from being provisioned or deployed.
Operational Tools

Secrets management and SOAR tie security into runtime and operations.

Secrets Management
Secure stores inject credentials at runtime and eliminate hardcoded secrets.
SOAR
Automates playbooks: incident triage, ticketing, enrichment, and remediation triggers.
Misconception

No single tool covers all risks. Use complementary tools and tuned policies for coverage and signal quality.
