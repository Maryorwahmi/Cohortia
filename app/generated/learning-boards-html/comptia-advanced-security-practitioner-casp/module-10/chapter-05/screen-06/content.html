Module 10 › Chapter 10.5 › SAST
What SAST Does

Analyzes source code for insecure patterns without executing the program.

Automation
Run on commits and PRs to give fast developer feedback.
Limitations
May produce false positives; does not detect runtime misconfigurations.
Example
A SAST scan flags hardcoded credentials in a file. The scan comments on the pull request and the build status is set to failed for critical severity. The developer replaces the secret with a secure reference and re-runs the pipeline.
Key Takeaway

SAST gives early, file-level feedback but must be tuned and paired with other scanners for comprehensive coverage.
