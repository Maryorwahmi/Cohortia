Learning Objectives

Skill-based milestones to verify your DevSecOps competency.

Bloom: Learn → Understand → Apply → Master
01
Explain DevSecOps Principles

Describe automation, integration, collaboration, feedback, and continuous improvement and why each is necessary for secure CI/CD.

VERIFIED COMPETENCY MILESTONE
02
Identify Automation Candidates

List security activities that should be automated in CI/CD and explain the expected developer feedback loop.

VERIFIED COMPETENCY MILESTONE
03
Evaluate Tool Classes

Compare SAST, SCA, DAST, IaC scanning, container scanning, secrets management, and SOAR in terms of purpose and feedback.

VERIFIED COMPETENCY MILESTONE
04
Design a Secured Pipeline

Create a conceptual CI/CD flow that includes automated security gates and SOAR feedback for remediation and incident response.
