Module 10 › Chapter 10.5 › DAST
What DAST Finds

Runtime vulnerabilities, configuration issues, authentication and session flaws, and business logic problems.

Execution
Run against deployed test/staging environment after build and deploy steps.
Integration
Feed findings into ticketing systems and remediation workflows.
Practical Scenario
Automated DAST reports an exposed API that discloses user data due to a misconfigured route. The team reproduces the request in staging, fixes routing rules, and the subsequent DAST run confirms removal of the issue.
Key Takeaway

DAST validates runtime behavior and discovers issues static analysis cannot; use representative staging environments for accurate results.

Common Mistake
Running DAST without authentication context or against non-representative environments yields false positives and missed issues.
