Definition
Circuit Breaker
Detect failing dependencies and stop calls to them until they recover, providing a fallback to avoid resource exhaustion.
When to use
Use when remote calls can fail or return slowly and retries would worsen the situation.
Monitoring
Track open/half-open/closed states and request rejections as alerts.
Pseudocode Example
A decorated call returns a fallback when the circuit is open.
// Pseudocode for a circuit breaker
CircuitBreaker cb = CircuitBreaker.of("myService", CircuitBreakerConfig.ofDefaults());
Supplier<String> decorated = CircuitBreaker.decorateSupplier(cb, () -> myService.callExternalApi());

try {
  String result = decorated.get();
} catch (CallNotPermittedException e) {
  // Circuit is open: return cached result or default
}
Misconception
Don't rely on long blocking retries; without a breaker, retries amplify failures and increase latency.
