Graceful Degradation
Design a reduced experience that preserves the core user path during failures.
Example: E-commerce
Disable non-critical features like recommendations, allow checkout using cached inventory.
Example: Streaming
Reduce bitrate to preserve continuous playback rather than stalling.
Design Steps
  1. Prioritize essential flows and data.
  2. Implement fallbacks (cache, lower fidelity modes).
  3. Expose feature flags to toggle behavior safely.
  4. Test degraded modes under load and failure injection.
Common mistake
Not exercising degraded modes in tests leads to surprises in production when fallbacks are first used.
Key Takeaway

Decide what must remain functional and actively test degraded behavior to avoid unexpected outages.
