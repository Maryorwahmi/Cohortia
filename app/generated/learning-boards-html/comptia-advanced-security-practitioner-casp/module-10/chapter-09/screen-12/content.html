Design a Chaos Test
Follow the experiment loop: Hypothesis → Steady state → Inject → Observe → Remediate.
Hypothesis: OrderProcessingService queues orders and retries payments under high gateway latency without losing orders.
Steady state: Order latency < 2s; success rate > 99%; queue length stable.
Failure injection: Add 2s latency to PaymentGateway for one instance via proxy.
Observe: queue length, duplicate transactions, error spikes, retry behavior.
Expected Remediations
  • Add circuit breaker around payment calls.
  • Implement async payment queue and idempotent tokens.
  • Secure and automate rollback of the experiment.
Deliverable
A written plan with hypothesis, metrics, injection method and remediation steps that you can run and validate.
