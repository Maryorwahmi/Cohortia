Process
Experiment Steps
  1. Form hypothesis and define steady-state metrics.
  2. Choose target and minimize blast radius.
  3. Inject failure and observe metrics & logs.
  4. Verify hypothesis and remediate if needed.
  5. Automate and repeat with larger scope.
Steady-state example
PaymentService latency < 50ms; error rate < 0.1%; successful payments > 99%.
Failure Injection Example (Toxiproxy)
# Create a proxy for InventoryService
toxiproxy-cli create inventory-proxy -l 0.0.0.0:8081 -u inventory-service:8080
# Add latency
toxiproxy-cli toxic add inventory-proxy -t latency -a latency=2000 -a jitter=500
# Simulate down
toxiproxy-cli toxic add inventory-proxy -t latency -a latency=0 -a jitter=0 -a timeout=1000 -a up=false
Key Takeaway

Keep the blast radius small, instrument the experiment, and have an automated rollback plan to avoid unintended outages.
