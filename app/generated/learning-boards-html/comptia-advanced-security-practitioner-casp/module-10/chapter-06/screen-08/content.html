Module 10 › Chapter 10.6 › Kubernetes Security
Security pillars
Pod Security Standards (Restricted, Baseline, Privileged)
Role-Based Access Control (least privilege for users and service accounts)
Network Policies (deny-by-default segmentation)
Secrets & external secret managers
Example enforcement
Combine Restricted PSS for workload admission, RBAC to limit API actions, and deny-all Network Policies that only allow required flows.
Operational items
  • Enable audit logging and forward to SIEM.
  • Rotate and audit service-account permissions.
  • Integrate runtime tools like Falco for detection of suspicious syscalls.
Key Takeaway

No single control suffices. Use PSS, RBAC, Network Policies, secrets management, and logging together to reduce risk in Kubernetes clusters.
