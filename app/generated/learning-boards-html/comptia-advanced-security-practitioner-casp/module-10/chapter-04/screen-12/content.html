Threat Example
Typosquatting vs Dependency Confusion
Two attack patterns that insert malicious packages into builds.
Typosquatting
Attacker creates a similarly named package so a typo pulls a malicious artifact.
Dependency confusion
A private package name collides with a public package; if resolution prefers public, builds fetch the wrong package.
Defenses
Use curated internal repos, enforce registry order in resolution, and verify hashes or signatures of packages.
Operational checklist
  • Enforce internal registries for private packages.
  • Verify package integrity via hashes or signatures on download.
  • Monitor for suspicious package names similar to internal packages.
Misconception
Assuming only human errors cause these attacks; automated tooling and CI pipelines are common targets too.
Key Takeaway

Control package resolution and verify integrity to reduce the risk of malicious package substitution.
