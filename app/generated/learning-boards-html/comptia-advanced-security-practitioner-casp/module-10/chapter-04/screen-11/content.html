Hands-on Activity
Analyzing Dependencies with OWASP Dependency-Check
Use the CLI to scan a sample Maven project and review the HTML report.
Sample pom.xml
<project xmlns="http://maven.apache.org/POM/4.0.0" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>
    <groupId>com.cohortia</groupId>
    <artifactId>my-java-app</artifactId>
    <version>1.0.0-SNAPSHOT</version>
    <packaging>jar</packaging>

    <properties>
        <java.version>11</java.version>
    </properties>

    <dependencies>
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
            <version>2.5.0</version>
        </dependency>
        <dependency>
            <groupId>com.fasterxml.jackson.core</groupId>
            <artifactId>jackson-databind</artifactId>
            <version>2.12.0</version>
        </dependency>
        <dependency>
            <groupId>org.apache.logging.log4j</groupId>
            <artifactId>log4j-core</artifactId>
            <version>2.14.1</version>
        </dependency>
    </dependencies>
</project>
Run the scan
Example commands to run Dependency-Check CLI and produce an HTML report.
# On Linux/macOS
./dependency-check.sh --project "MyJavaApp" --scan /path/to/my-java-app --format HTML --out /path/to/my-java-app/dependency-check-report.html

# On Windows
dependency-check.bat --project "MyJavaApp" --scan C:\path  o\my-java-app --format HTML --out C:\path  o\my-java-app\dependency-check-report.html
Analysis guidance
Open the HTML report, identify critical CVEs, note suggested upgrades, and capture a screenshot of critical findings as your deliverable.
Key Takeaway

Hands-on scanning turns theory into actionable findings: run scans, interpret reports, and prioritize fixes based on context.
