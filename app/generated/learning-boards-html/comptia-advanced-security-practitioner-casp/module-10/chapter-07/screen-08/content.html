Pattern

Validate inputs with schemas

Declare the shape and constraints of expected data using a schema library, and reject anything that does not conform.

from flask import request, jsonify
from marshmallow import Schema, fields, validate

class UserSchema(Schema):
    username = fields.String(required=True, validate=validate.Length(min=3, max=30))
    email = fields.Email(required=True)
    password = fields.String(required=True, validate=validate.Length(min=8))

# In an endpoint: validate and reject with 400 on errors
Explanation
Why validation matters
Prevents injection attacks and ensures your business logic receives expected, safe data.
Output encoding
When API data may be shown in browsers, encode it to avoid cross-site scripting even if inputs were validated.
Misconception
Validating only on the client or relying on type annotations is insufficient. Server-side validation is essential.
Key Takeaway

Use declarative schemas to validate inputs and always encode outputs destined for a browser.
