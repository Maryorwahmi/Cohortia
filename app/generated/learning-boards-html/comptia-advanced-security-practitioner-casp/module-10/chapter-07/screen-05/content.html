Module 10 › Chapter 10.7 › Authentication options
Comparison
OAuth 2.0 / OpenID Connect
Delegated authorization and identity. Best for apps and machine-to-machine flows that require scopes and revocation.
API Keys
Simple to issue and use. Treat as secrets, scope them, and rotate frequently.
JSON Web Tokens (JWT)
Compact token format. Always verify signatures and avoid placing secrets or sensitive data in unencrypted claims.
Example: Client credentials flow
curl -X POST https://auth.example.com/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials&client_id=YOUR_CLIENT_ID&client_secret=YOUR_CLIENT_SECRET"
Guidance
Choose by risk
High-value data and third-party access favor OAuth with scopes and short-lived tokens.
Rotate and revoke
Plan for key rotation and token revocation to reduce exposure from leaked credentials.
Misuse to avoid
Do not embed long-lived keys in client-side code or return unverified tokens from untrusted sources.
Key Takeaway

Match authentication style to client type, risk profile, and operational ability to rotate and revoke credentials.
