Module 10 › Chapter 10.7 › Rate Limiting
Implementation
Nginx example
limit_req_zone $binary_remote_addr zone=mylimit:10m rate=5r/s;

server {
  listen 80;
  location /api/login {
    limit_req zone=mylimit burst=10 nodelay;
    # proxy_pass to backend
  }
}
Guidance
Where to place limits
At the gateway or load balancer so abusive traffic is filtered before reaching services.
Adjust for real traffic
Tune rates to avoid false positives for legitimate bursts and consider authenticated vs anonymous clients separately.
Test approach
Simulate repeated login attempts from a client and verify the gateway returns a rate-limited response while the backend stays protected.
Key Takeaway

Rate limiting preserves availability and directly reduces the impact of brute-force and volumetric attacks.
