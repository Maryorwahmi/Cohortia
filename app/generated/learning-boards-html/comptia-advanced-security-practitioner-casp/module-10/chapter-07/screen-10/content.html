Module 10 › Chapter 10.7 › Gateway & WAF
API Gateway
Responsibilities
  • Authentication and token validation
  • Rate limiting, quota enforcement, request routing
  • Centralized logging and policy application
Examples include managed solutions and self-hosted gateways used to standardize enforcement across services.
Web Application Firewall (WAF)
Responsibilities
  • HTTP payload inspection and pattern matching
  • Blocking known attack signatures like injection patterns
  • Providing early blocks before requests reach backend services
Key Takeaway

Gateways standardize policy and WAFs filter malicious input; both reduce backend exposure but do not replace server-side checks.
