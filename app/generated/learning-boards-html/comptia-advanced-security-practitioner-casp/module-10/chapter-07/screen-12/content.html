Module 10 › Chapter 10.7 › Common Mistakes
Ignoring Authorization
Authentication without per-object authorization allows unauthorized data access.
Overly Permissive CORS
Allowing all origins increases the risk that malicious pages can reuse API credentials in a victim's browser.
Verbose Error Messages
Exposing stack traces leaks system internals; return generic errors to clients and log details internally.
Missing Rate Limits
Allows credential stuffing and DoS attacks; apply limits at the gateway or proxy.
Not Validating Input
Even innocuous fields can be weaponized; validate everything on the server.
Weak API Keys & Dependency Risks
Rotate keys, avoid hardcoding, and run composition analysis on third-party libraries.
Key Takeaway

Fix common mistakes with repeatable processes: policy, automation, and monitoring prevent regressions.
