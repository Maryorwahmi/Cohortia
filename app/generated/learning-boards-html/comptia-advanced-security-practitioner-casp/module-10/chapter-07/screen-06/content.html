Module 10 › Chapter 10.7 › Authorization & BOLA
Definition

Broken Object Level Authorization (BOLA)

Occurs when an endpoint accepts an object ID but does not verify the caller’s right to access that specific object.

Vulnerable example
An API returns any user record given a numeric identifier without checking if the requester owns that record.
Mitigation
On each request resolve the object, check its ownership or access policy against the requester's identity, and deny or filter data accordingly.
Practice
Testing strategy
Create a test account, attempt to fetch or modify another account’s resources, and assert the API returns forbidden or not found.
Common pitfall
Relying on opaque or hard-to-guess IDs as a security control. Obscurity does not replace server-side authorization checks.
Check your understanding
Why is a server-side ownership check preferred over client-side enforcement when protecting object access?
Key Takeaway

Server-side authorization per object is non-negotiable for APIs that accept object identifiers.
