Module 10 › Chapter 10.3 › Broken Authentication
Problems
  • Weak or unsalted password hashes.
  • Predictable or non-rotated session IDs.
  • Verbose login errors that reveal valid usernames.
  • No brute-force protections or MFA.
Controls
  • Store passwords with salted, adaptive algorithms like Argon2 or bcrypt.
  • Implement MFA and account throttling.
  • Generate cryptographically secure session tokens and invalidate them on logout.
  • Return generic error messages for authentication failures.
Key Takeaway

Authentication failures are often implementation details; standard libraries and careful lifecycle policies reduce risk dramatically.
