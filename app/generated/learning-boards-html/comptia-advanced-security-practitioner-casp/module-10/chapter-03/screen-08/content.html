Module 10 › Chapter 10.3 › Insecure Deserialization

What can go wrong

  • Remote code execution via crafted objects.
  • Denial-of-service through large or recursive objects.
  • Authentication or logic bypass by controlling deserialized fields.

Mitigations

  1. Avoid deserializing untrusted input.
  2. Use safe formats and strict schema validation.
  3. Sign or MAC serialized payloads and verify before deserializing.
  4. Restrict allowable types and run deserialization in a sandbox.
