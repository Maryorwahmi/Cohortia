Vulnerable example
# Vulnerable Python example
username = request.args.get('username')
password = request.args.get('password')
query = f"SELECT * FROM users WHERE username = '{username}' AND password = '{password}';"
cursor.execute(query)
Secure alternative
query = "SELECT * FROM users WHERE username = %s AND password = %s;"
cursor.execute(query, (username, password))
Example: For the Flask feedback form, replacing the INSERT built by string interpolation with parameter binding ensures submitted text cannot alter the SQL structure.
Why it matters

Parameterized queries prevent user data from being interpreted as SQL. They are supported by database connectors and ORMs and are the recommended remedy for injection flaws.

Common mistake
Trusting escaping or input length checks instead of parameterization.
Check
Scan for string-built SQL and require an explicit parameter tuple in the execute call.
