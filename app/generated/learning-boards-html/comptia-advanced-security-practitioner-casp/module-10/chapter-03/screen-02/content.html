How to use these objectives

Use the objectives as acceptance criteria for pull requests and pipeline gates. Each objective maps to observable work: code changes that replace concatenation with parameterization, templating that escapes output, CI steps that run SAST and DAST, and a secrets policy that removes credentials from repositories.

Mnemonic
Scan, Fix, Verify, Protect — repeat.
Quick check
  • Are inputs validated and encoded?
  • Are queries parameterized?
  • Are secrets kept out of code?
