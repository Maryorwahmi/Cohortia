Module 10 › Chapter 10.3 › XSS & Output Encoding
Vulnerable template
<p>Feedback: {{ item.text }}</p>  <!-- No escaping shown -->
Secure template
<p>Feedback: {{ item.text | e }}</p>  <!-- escape filter or auto-escaping enabled -->
If the application must allow limited HTML, use a vetted sanitizer that strips dangerous tags rather than raw rendering.
Testing & verification
  • Try common XSS payloads in input fields and verify responses encode them.
  • Enable auto-escaping in the template engine by default.
  • If HTML is required, apply a strict sanitizer before storing or rendering.
Common mistake
Relying only on client-side validation or partial escaping for one context while rendering in another.
