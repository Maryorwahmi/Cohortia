Module 10 › Chapter 10.3 › SAST / DAST / IAST
SAST
Analyzes source code for insecure patterns before execution. Integrate into IDEs and CI. Good for injection, insecure crypto, and hardcoded secrets.
DAST
Scans a running application by sending inputs and observing responses. Finds authentication, configuration, and runtime issues that static analysis can miss.
IAST
Combines runtime observation with code context, offering more accurate findings and fewer false positives during integration tests.
Key Takeaway

Use the three tools together: SAST early, DAST for runtime validation, IAST to connect findings to code with higher fidelity.
