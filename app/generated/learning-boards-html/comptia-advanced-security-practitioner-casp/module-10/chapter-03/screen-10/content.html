Module 10 › Chapter 10.3 › Secrets Management
Recommended practice
  • Store secrets in a dedicated manager with roles and rotation.
  • Inject secrets at runtime via secure agents or connectors.
  • Audit access and rotate on suspected exposure.
Quick actions for teams
  1. Remove any secrets found in the repo and rotate them immediately.
  2. Configure CI to use encrypted variables or secret store integrations.
  3. Document secret lifecycle and emergency rotation steps.
Common mistake
Using long-lived static keys for services without rotation or access controls.
