Module 10 › Chapter 10.2 › UserProfileService Activity
Principle: Least Privilege

Database account limited to specific tables and CRUD operations only; service tokens scoped to required endpoints.

-- Example DB permissions
GRANT SELECT, INSERT, UPDATE, DELETE ON users, profiles TO user_profile_service;
Principle: Defense in Depth
  • API gateway: auth, rate limiting, input validation.
  • Service layer: runtime input checks, output minimization.
  • Data layer: encryption and strict DB permissions.
  • Monitoring: anomalous access alerts.
Principle: Separation of Concerns

Isolate UserProfileService in its own runtime and network segment; do not allow direct DB access from other services without going through defined APIs.

Principle: Secure Defaults
  • TLS required by default.
  • Administrative roles disabled unless explicitly granted.
  • Ports closed until needed; hardened configuration templates provided.
