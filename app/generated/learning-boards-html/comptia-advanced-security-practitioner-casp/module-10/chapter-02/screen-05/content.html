The six STRIDE categories
Spoofing
Impersonation of users or components; mitigations include strong authentication and token validation.
Tampering
Modification of data or code; mitigations include integrity checks and signed payloads.
Repudiation
Denying actions without proof; mitigations include robust logging and non-repudiation controls.
Information Disclosure
Unauthorized data access; mitigations include encryption and least-privilege data access.
Denial of Service
Preventing legitimate access; mitigations include rate limiting and resilient architectures.
Elevation of Privilege
Gaining greater rights than intended; mitigations include strict authorization and separation of duties.
Applying STRIDE to a DFD

Walk each DFD node and flow and ask the six STRIDE questions. For each hit, record the threat, a brief example, and an initial mitigation mapped to a secure design principle.

Example entry
Flow: API Gateway → UserProfileService. STRIDE hits: Information Disclosure (sensitive fields in response), Tampering (malformed requests). Mitigations: limit response fields, input validation, API gateway authorization.
Common mistake

Do not stop at identification. Always propose a design-level mitigation tied to a principle like least privilege or defense in depth.
