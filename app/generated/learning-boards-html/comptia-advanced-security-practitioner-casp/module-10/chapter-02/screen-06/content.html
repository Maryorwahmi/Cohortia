DREAD factors
  • Damage potential: Business impact if exploited.
  • Reproducibility: How reliably an attacker can reproduce the attack.
  • Exploitability: How easy it is to perform the attack.
  • Affected users: How many users would be impacted.
  • Discoverability: How easily attackers can find the issue.
Scoring practice

Score each factor on a consistent scale and sum them. Use the result to compare threats and recommend mitigation order.

Concrete example

Threat: API endpoint leaks user email in error messages. Damage potential: medium. Reproducibility: high. Exploitability: low to medium. Affected users: depends on scale. Discoverability: high if errors are public. Aggregate these to decide whether to fix immediately or schedule as part of a larger release.

Misconception

DREAD provides guidance, not an absolute rule. Always consider business context and stakeholder risk tolerance when using scores.

Key Takeaway

Use scoring to focus effort, but pair scores with business context and governance decisions.
