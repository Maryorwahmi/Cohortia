Objective Artifacts
Threat List
Component and flow entries from a Data Flow Diagram, annotated with STRIDE categories and brief examples.
Risk Scores
Numeric or ranked priorities using DREAD-style factors to guide mitigation order.
Mitigation Plan
High-level design changes mapped to secure design principles and expected residual risk.
Communication Sheet
One-paragraph justification for stakeholders explaining impact, cost drivers, and recommended next steps.
How to iterate

Start with a minimal DFD, apply STRIDE to each node and flow, score threats, then map mitigations to secure principles. Revisit the model as requirements change or new services are added.

Practical mnemonic

Think: identify, prioritize, mitigate, and communicate. This keeps threat modeling actionable and visible to decision makers.
