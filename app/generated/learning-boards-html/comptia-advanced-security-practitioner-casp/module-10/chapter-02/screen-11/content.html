Separation of Concerns / Compartmentalization

Divide the system into isolated components so a compromise affects only a limited scope. Microservices and scoped databases exemplify this principle.

Fail Securely
When failures occur, deny unsafe actions rather than allowing permissive behavior.
Minimizing Attack Surface
Remove unused services, close unused ports, and limit exposed API functionality.
Complete Mediation & Psychological Acceptability

Complete mediation ensures every access request is authorized each time. Psychological acceptability balances security with usability so users do not bypass controls.

Design check
  • Do components rely on cached authorization decisions too long?
  • Are critical services unnecessarily exposed to the public internet?
  • Would users be tempted to bypass controls because they are cumbersome?
