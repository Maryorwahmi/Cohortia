Module 10 › Chapter 10.2 › Defense in Depth & Secure Defaults
Defense in Depth
Combine multiple controls so a single failure does not expose assets. Controls should be different in nature and independent where possible.
Network
Firewalls, segmentation, and gateway controls.
Application
Input validation, authorization checks, and secure coding.
Data
Encryption at rest and in transit, and field-level minimization.
Secure Defaults

Systems should be configured securely out-of-the-box so administrators must opt out to reduce protections, avoiding dangerous defaults.

Example defaults
  • TLS enabled by default
  • Administrative ports closed until explicitly opened
  • New user accounts non-administrative by default
Key Takeaway

Combine layered controls and secure defaults to reduce the chance that operator error or a single failure produces a breach.
