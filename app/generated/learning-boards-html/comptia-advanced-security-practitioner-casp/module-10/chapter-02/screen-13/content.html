Module 10 › Chapter 10.2 › Threat → Mitigation Walkthrough
Identified threats
  • Information Disclosure: sensitive fields in responses
  • Tampering: malformed or altered profile update payloads
Mitigations
  • Response minimization: only return required fields.
  • Input validation and integrity checks on update requests.
  • Scoped DB account and encrypted transport.
Verification plan
Create tests and monitors tied to acceptance criteria so mitigations are measurable and durable.
Tests
Unit and integration tests assert no sensitive fields in public responses and validate input sanitization logic.
Monitoring
Alerts on unusual error rates, anomalous query patterns, or spikes in denied authorizations.
Key Takeaway

Always pair mitigations with tests and monitoring so controls remain effective over time.
