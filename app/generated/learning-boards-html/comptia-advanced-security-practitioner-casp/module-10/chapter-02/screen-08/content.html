DFD anatomy

List actors, external systems, processes, data stores, and the flows that connect them. Keep it simple and expand for high-risk areas.

Action
Apply STRIDE questions to each element and log concise threat statements linked to the element.
Practice tip
Iterate the DFD as you discover higher-risk flows; avoid over-detailing initially.
Example

Marking the API Gateway → UserProfileService flow as high risk yields mitigations: response minimization, input validation, and DB account restriction.
