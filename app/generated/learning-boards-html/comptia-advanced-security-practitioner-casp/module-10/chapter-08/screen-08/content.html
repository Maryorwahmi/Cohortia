Code Walkthrough (Pseudo)
# Build and sign firmware (conceptual)
build_firmware --output firmware.bin
hsm_sign --key-id signing-key --in firmware.bin --out firmware.bin.sig
publish_update --file firmware.bin --sig firmware.bin.sig --version 1.2.3

# Device verification (conceptual)
verify_signature(public_key, firmware.bin, firmware.bin.sig)
check_version(monotonic_counter, firmware.version)
if signature_valid and newer_version:
  install_firmware(firmware.bin)
else:
  reject_update()
Checks and Controls
  • Sign artifacts with keys stored in an HSM; do not expose private keys in build servers.
  • Verify signatures using a public key linked to the device HRoT.
  • Use version counters or monotonic counters to prevent rollback attacks.
Common Mistake

Failing to implement rollback protection allows attackers to revert devices to known vulnerable firmware even when updates are signed.
