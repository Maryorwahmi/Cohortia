Module 10 › Chapter 10.8 › Secure Communication
Comparison
MQTT + TLS
Reliable TCP transport for telemetry. TLS provides strong session security and is widely supported.
Use when reliability and existing broker ecosystems matter.
CoAP + DTLS
Lightweight UDP-based protocol suited for constrained networks. DTLS brings the same guarantees as TLS over UDP.
Use when low latency or smaller headers are required.
Cipher and Key Choices
  • Prefer standard, vetted algorithms: AES-128 or ChaCha20-Poly1305.
  • Use mutual authentication with device-specific certificates when possible.
  • Leverage hardware crypto accelerators to reduce overhead where available.
Practical Tip

Test TLS/DTLS implementations under device resource limits and prefer libraries with proven constrained-device support.
