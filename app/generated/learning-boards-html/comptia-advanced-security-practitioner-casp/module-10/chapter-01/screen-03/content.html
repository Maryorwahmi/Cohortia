Learning Objectives

Skills you will practice and demonstrate in the hands-on activity and assessments.

Bloom: Learn → Understand → Apply → Master
01
Write abuse cases & security stories

Document attacker scenarios for key features so requirements include non-functional security needs like privacy, resilience, and compliance.

VERIFIED COMPETENCY MILESTONE
02
Apply threat modeling (STRIDE/PASTA)

Identify trust boundaries and likely threats during design, and tie each threat to an architectural mitigation and acceptance criteria.

VERIFIED COMPETENCY MILESTONE
03
Integrate SAST, DAST, and pen testing

Design a testing strategy where static, dynamic, and manual tests complement each other to catch code, configuration, and runtime issues.

VERIFIED COMPETENCY MILESTONE
04
Coordinate stakeholder roles

Define responsibilities for product owners, architects, developers, security engineers, and ops so reviews and gates are explicit and repeatable.

VERIFIED COMPETENCY MILESTONE
Tip: Use a RACI or similar matrix to make stakeholder responsibilities visible during each SDLC gate.
