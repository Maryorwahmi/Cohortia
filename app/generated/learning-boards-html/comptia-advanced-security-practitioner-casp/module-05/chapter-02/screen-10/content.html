OpenSSL AES-256-GCM Commands
# Create a sample file
echo "This is a secret message for our enterprise." > secret_message.txt

# Generate a random 256-bit (32-byte) key
openssl rand -hex 32 > aes_key.txt
AES_KEY=$(cat aes_key.txt)

# Generate a random 12-byte (96-bit) IV
openssl rand -hex 12 > aes_iv.txt
AES_IV=$(cat aes_iv.txt)

# Encrypt the file using AES-256-GCM
openssl enc -e -aes-256-gcm -K $AES_KEY -iv $AES_IV -in secret_message.txt -out secret_message.enc -taglen 16

# Decrypt the file
openssl enc -d -aes-256-gcm -K $AES_KEY -iv $AES_IV -in secret_message.enc -out decrypted_message.txt
Note: Keep the key and IV secret and remove temporary files after the experiment.
Experiment

After encryption, modify a byte of the ciphertext and attempt decryption. OpenSSL should report an authentication tag mismatch, demonstrating GCM’s integrity protection.

Common Mistake

Reusing the IV or failing to check the tag will compromise the security properties expected from AEAD.

Key Takeaway

Hands-on experiments show authentication failures explicitly, reinforcing the need to manage IVs and tags carefully.
