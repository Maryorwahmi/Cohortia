Definition
RSA Hardness

Security claim: factoring a large composite is computationally infeasible for sufficiently large keys. Choose large primes and secure key generation.

Misconception: Bigger numeric key length is always better — but algorithmic differences mean size isn't directly comparable across systems.
ECC Hardness

Security claim: the elliptic curve discrete logarithm problem is hard for chosen curves and parameters, enabling much smaller keys for equivalent strength.

Misconception: Not all curves are equal; use standardized curves vetted by the community and vendors.
Key Takeaway

Document the hardness assumption and chosen parameters to make sound architectural decisions and support audits.
