Learning Objectives — Applied Milestones

01 • AEAD

Configure AES-GCM in a TLS stack or storage client, then tamper with a ciphertext to observe an authentication failure. Verify associated data prevents header tampering.

Verified competency milestone
02 • RSA vs ECC

Measure signature or key-exchange latency and bandwidth for RSA and ECC keys; document the choice for constrained devices and server workloads.

Verified competency milestone
03 • Key Management

Use a CSPRNG to generate keys in an HSM or cloud KMS, rotate a wrapping key, and demonstrate access continuity to encrypted data after rotation.

Verified competency milestone
04 • Mathematical Analysis

Summarize the hardness assumptions: integer factorization for RSA and the elliptic curve discrete logarithm for ECC, and map key sizes to equivalent strengths.

Verified competency milestone
