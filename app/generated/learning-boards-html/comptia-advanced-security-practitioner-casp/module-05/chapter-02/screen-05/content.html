Comparison

ECB vs CBC vs CTR

ECB
Deterministic, reveals block patterns. Use only for pseudorandom data or single-block messages.
CBC
Uses IV and chaining. Requires separate integrity (HMAC) and careful ordering to avoid padding oracle attacks.
CTR
Parallelizable stream mode. Must never reuse nonces under the same key.
Common Implementation Mistakes
  • Relying on CBC without adding authentication; believe encryption equals integrity — it does not.
  • Reusing IVs or nonces, especially in CTR/GCM, which can lead to key recovery or plaintext disclosure.
  • Improper MAC placement or incorrect error handling leading to padding oracle vulnerabilities.
Key Takeaway

Implementation details matter: choose AEAD where possible to reduce the chance of subtle errors.
