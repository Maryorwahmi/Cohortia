Definition › Cryptographic Agility
What is cryptographic agility?
An architectural approach that allows algorithms and parameters to be swapped without redesigning applications.
• Example: moving from one hash to another by changing a configuration value and re-signing artifacts with automated tooling.
• Misconception: agility is not plug-and-play; it requires migration tooling, testing, and inventory of where keys and algorithms are used.
Key Takeaway
Make cryptographic choices configurable and maintain migration tooling to respond to vulnerabilities quickly.
Design checklist
• Externalize cryptographic choices into configuration or policy layers.
• Provide migration tools to re-encrypt or re-sign data when algorithms are deprecated.
• Maintain test suites that exercise new algorithms and validate compatibility across clients and servers.
