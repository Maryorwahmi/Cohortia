Birthday Attack
Targets hash collisions using 2^(N/2) work; mitigate by using hash outputs of 256 bits or more for collision-sensitive uses.
Downgrade Attack
Forces endpoints to use weaker protocols; counter by disabling legacy TLS versions, preferring AEAD suites with PFS, and enabling HSTS.
Agility & PQC
Design for algorithm replacement and start planning PQC migration now for long-lived secrets and signatures.
Final takeaway

Combine configuration hardening, implementation protections, and agility planning to reduce current risk and prepare for future cryptographic threats.
