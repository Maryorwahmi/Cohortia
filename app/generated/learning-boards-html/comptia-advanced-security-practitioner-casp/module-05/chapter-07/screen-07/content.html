Core Concept › Birthday Attacks
The birthday paradox applied
Collision searching needs about 2^(N/2) work for an N-bit hash, so output length matters for collision resistance.
• Example: a 128-bit hash has a collision resistance around 2^64 operations, which is feasible for well-resourced attackers.
• Misconception: collision attacks are the same as preimage attacks — they are different properties and require different defenses.
Key Takeaway
Choose hash functions with large outputs (e.g., 256 bits or more) for collision-sensitive uses like signatures and code signing.
Assessment actions
• Inventory uses of MD5, SHA-1, or other small-output hashes in signing and integrity checks.
• Prioritize transitions for signatures and certificate functions to larger hash outputs.
• Validate that build systems and update mechanisms use collision-resistant hashes to prevent substitution attacks.
