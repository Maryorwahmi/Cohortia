How to use these objectives
Treat the objectives as decision checks. When designing a secure channel, ask: which primitive provides confidentiality? Which provides integrity? How will keys be distributed securely? These questions map directly to the objectives above.
Mnemonic
C I K R — Confidentiality, Integrity, Key distribution, Resilience. Use this to map primitives to goals.
Common misconception
Assuming asymmetric encryption should replace symmetric ciphers. In practice they serve complementary roles; hybrid designs are common for that reason.
