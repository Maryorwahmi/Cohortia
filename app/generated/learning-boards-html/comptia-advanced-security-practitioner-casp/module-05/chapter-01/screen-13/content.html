Key management lifecycle
Generate, store, rotate, revoke, and audit keys across their lifecycle.
Protect
Use HSMs or TPMs for high-value keys and limit exposure by minimizing cleartext key use.
Rotate
Regular rotation limits the window of vulnerability. Automate rotations and test rollovers to avoid outages.
Audit
Maintain an inventory of keys and their uses, and audit access regularly to detect misuse.
Concrete example
A cloud service uses a key vault for data encryption keys, an HSM for signing certificates, and an automated workflow to rotate data keys monthly with zero-downtime re-encryption strategies.
Common pitfall
Failing to test key rotation and rollback procedures. Unattended rotations can cause service outages if compatible key versions are not supported.
Action
Document where each key is used and simulate compromise and rotation exercises to validate recovery processes.
Key Takeaway

Operational practices determine cryptography's real-world effectiveness: protect, rotate, and audit keys according to the value and lifetime of the data they protect.
