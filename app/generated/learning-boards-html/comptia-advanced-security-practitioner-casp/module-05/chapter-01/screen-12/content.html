Part 1 — SHA-256 with openssl
Quick integrity-style digest. Not suitable alone for password storage.
echo -n "MySecretPassword123!" | openssl dgst -sha256
Observe the short, fixed-size output and the speed of computation. Use this for file checksums, not raw password storage.
Part 2 — PBKDF2 with passlib (Python)
A parameterized, salted, iterated output intended for password verification.
from passlib.hash import pbkdf2_sha256

password = "MySecretPassword123!"
salt = b"randomsaltvalue"
iterations = 290000

hashed_password = pbkdf2_sha256.using(salt=salt, rounds=iterations).hash(password)
print(hashed_password)
The printed value encodes algorithm, salt, and rounds. Verification requires the same parameters and is intentionally slower to defend against brute-force attempts.
Key Takeaway

Compare both outputs and measure time to compute. Use parameterized stretched hashes with per-password salt for credential stores, not raw fast digests.
