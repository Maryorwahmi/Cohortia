Practical checklist
  • Does the cipher provide authenticated encryption for data integrity?
  • Are session keys ephemeral and does the server prefer PFS suites?
  • Are password stores salted and using key stretching with an appropriate iteration count?
  • Does algorithm selection meet regulatory and performance constraints?
Tip
Make decisions defensible: document threat model, expected lifetime of keys, and reasons for choosing each primitive.
