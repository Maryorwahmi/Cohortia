Module 5 › Chapter 5.1 › Key Concepts
Key Stretching
Iterative hashing with salt to increase attacker workload for password guessing.
Perfect Forward Secrecy
Use ephemeral exchanges so compromise of long-term keys cannot decrypt past sessions.
Hybrid Cryptography
Combine public-key exchange for keys and symmetric encryption for bulk data to get the best of both worlds.
Summary
Operationalize these concepts: stretch passwords with salt, enable PFS in TLS, and use hybrid designs so keys and bulk encryption serve their intended purposes.
