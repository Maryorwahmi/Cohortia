Module 5 › Chapter 5.1 › Key Concepts
Symmetric Encryption
One shared secret for both encryption and decryption; suited to bulk data confidentiality.
Asymmetric Encryption
Public and private keys enable secure key exchange and digital signatures; used for handshakes and authentication.
Cryptographic Hashing
One-way digests for verifying integrity and supporting signatures; not for hiding data.
Summary
Remember these primitives and their roles: confidentiality via symmetric ciphers, secure exchange and authenticity via asymmetric methods, and integrity via hashing. Combine them thoughtfully in architectures.
