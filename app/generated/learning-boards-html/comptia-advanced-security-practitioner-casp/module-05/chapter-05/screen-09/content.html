Module 5 › Chapter 5.5 › GPG Signing
Commands (visual)
# Create a test file
echo "This document is confidential." > document.txt

# Create a detached signature
# gpg --output document.txt.sig --detach-sign document.txt

# Verify the signature
# gpg --verify document.txt.sig document.txt
These commands illustrate the detached-sign and verify pattern. In production, follow organizational key policies and use signed key distribution mechanisms.
Operational notes
  • Store private keys securely and rotate them on compromise.
  • Distribute public keys through trusted channels or a PKI.
  • Use detached signatures for large binaries to avoid re-wrapping artifacts.
Key Takeaway

Detached signatures let verifiers validate artifacts independently; key trust is the essential operational control.
