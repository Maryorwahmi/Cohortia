Module 5 › Chapter 5.5 › Final Notes
Hash = Integrity
Useful for tamper detection but not proof of origin.
MAC = Shared Authenticity
Efficient for point-to-point verification when secrets are manageable.
Signature = Public Trust
Enables verification by anyone with the public key and supports non-repudiation.
Final rule: pair integrity checks with appropriate authenticity mechanisms and keep a plan to replace weak hashes when needed.
