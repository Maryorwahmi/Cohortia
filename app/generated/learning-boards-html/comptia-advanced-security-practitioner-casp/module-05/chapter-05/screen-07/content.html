Module 5 › Chapter 5.5 › Hash vs MAC vs Signature
Hash
Integrity only. No key required. Anyone can compute it.
Use for quick tamper checks and content indexing.
MAC
Integrity + authenticity with shared secret. Not publicly verifiable.
Use for internal APIs and secure channels.
Digital Signature
Integrity + authenticity + non-repudiation via asymmetric keys.
Use for code signing, document signing, and distributed verification.
Concrete scenario
Distributing updates publicly: prefer digital signatures so each client can verify with the vendor's public key.
Common mistake
Publishing a checksum without protecting the checksum itself leads to easy tampering of both file and checksum.
