Module 5 › Chapter 5.5 › Cryptographic Agility
Principles for agility
  • Use libraries that allow algorithm selection at runtime.
  • Attach algorithm metadata to signed artifacts.
  • Plan for dual verification during transitions.
Migration tip
Prioritize replacing hashes used in signatures first, then non-critical places like internal checksums.
Practical checklist
  1. Inventory algorithm usage across systems.
  2. Test new algorithm signatures in parallel with legacy ones.
  3. Rotate keys and publish revocation procedures.
Key Takeaway

Cryptographic agility reduces risk and operational friction when deprecating weak algorithms; plan and test transitions carefully.
