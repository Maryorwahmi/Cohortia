Module 5 › Chapter 5.5 › What is a cryptographic hash?
Definition and Properties
A deterministic, fixed-size digest that exhibits the avalanche effect and resists inversion.
  • Detects accidental or malicious changes to data.
  • Deterministic: same input produces same digest every time.
  • One-way: digest alone should not reveal the input.
Analogy
Think of a hash as a compact fingerprint. It tells you if a fingerprint changed but not who left it.
Concrete example
openssl dgst -sha256 original_document.txt
Running the digest before and after a one-character change shows a completely different output. This is the avalanche property in action.
Key Takeaway

Use hashes to detect tampering but pair them with a MAC or signature when you need to prove who created the data.
