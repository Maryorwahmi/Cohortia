Module 5 › Chapter 5.5 › Hash Properties
What to evaluate
  • Collision resistance — prevents two inputs from producing the same digest.
  • Avalanche effect — small changes cause large digest differences.
  • Fixed output size — simplifies storage and comparison.
  • Resistance to inversion — cannot recover input from digest.
Common mistake
Treating a published checksum as authoritative when the checksum itself is not signed. An attacker can replace both file and checksum.
Practical guidance
Use SHA-2 or SHA-3 families for security-critical integrity checks. When you must deprecate a broken algorithm, update both signing tools and verification processes and provide a transition window.
Key Takeaway

Collision resistance matters for signatures; choose modern hashes and plan algorithm migration early.
