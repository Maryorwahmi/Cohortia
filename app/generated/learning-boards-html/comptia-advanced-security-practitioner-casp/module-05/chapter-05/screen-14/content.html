Module 5 › Chapter 5.5 › Assessment Scenarios
Scenario 1: Software updates
Goal: ensure updates originate from vendor and are unmodified. Use digital signatures; distribute public key through a PKI or trusted channel so every server can verify independently.
Why it matters
Signatures remove the need to share secrets with every recipient and provide non-repudiation for audits.
Scenario 2: Password storage
Goal: resist brute-force. Use key-stretching algorithms designed to be slow and memory hard, not a fast hash function. Avoid MD5 and SHA-1 entirely for this purpose.
Key Takeaway

Match primitives to goals: signatures for provenance, key-stretching for password resilience, and strong collision-resistant hashes for integrity checks.
