Module 5 › Chapter 5.5 › Key Concepts
Cryptographic Hashing
One-way digest for integrity; does not provide authenticity alone.
Message Authentication Code
Keyed checksum providing integrity and authenticity for shared-secret contexts.
Digital Signature
Asymmetric signing that provides integrity, authenticity, and non-repudiation.
Keep a migration plan for deprecated hashes and design systems to accept new algorithms without wide code changes.
