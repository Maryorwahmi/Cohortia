Module 5 › Chapter 5.5 › Hands-on: SHA-256
Exercise commands (visual)
# Create a sample file
echo "This is the original document content." > original_document.txt

# Compute SHA-256
openssl dgst -sha256 original_document.txt

# Modify a single character and recompute
sed -i 's/original/Original/' original_document.txt
openssl dgst -sha256 original_document.txt
Compare the two digest outputs and notice the completely different values. This simple check is useful for validating file integrity after transfer.
Checklist and pitfalls
  • Always compute the digest on the received artifact, not a previously cached value.
  • Beware of different newline conventions when comparing text files across platforms.
  • Do not rely on unsafely published checksums; sign them if authenticity is required.
Key Takeaway

Use digest checks as a quick tamper detection, and combine them with signatures for provenance.
