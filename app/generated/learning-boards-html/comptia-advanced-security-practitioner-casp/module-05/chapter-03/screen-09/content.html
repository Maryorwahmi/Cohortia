Definition
Key certificate fields

Read these fields to confirm identity, purpose, and validity of a certificate before trusting it in production.

Subject: the entity (person, server, or organization) the cert represents.
Issuer: the CA that signed the certificate.
Public Key / Serial: the public key and a unique serial for tracking.
Validity: notBefore and notAfter define the accepted window.
Signature Algorithm: shows how the CA signed the certificate.
Important extensions
Subject Alternative Name (SAN)
Allows multiple hostnames or addresses in a single certificate; required for modern TLS.
Key Usage
Specifies cryptographic purposes, e.g., digitalSignature, keyEncipherment.
Extended Key Usage (EKU)
Limits the certificate to applications like Server Authentication or Code Signing.
Key Takeaway

Extensions determine acceptance. Check SAN and EKU carefully when diagnosing connection failures or policy mismatches.
