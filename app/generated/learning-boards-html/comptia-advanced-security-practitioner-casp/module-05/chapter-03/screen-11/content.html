Module 5 › Chapter 5.3 › Trust Models
Hierarchical
Single root, intermediates below. Clear trust path and centralized policy. Preferred for internal enterprise PKI.
Mesh (Cross-certification)
CAs trust each other directly. Useful for peer federation but increases complexity in path discovery and revocation.
Bridge
A bridge CA mediates trust between hierarchies. Maintains local autonomy while enabling cross-domain trust.
Operational note
Federated models require careful certificate path analysis and coordinated revocation procedures. Prefer hierarchical where you control most participants.
