Module 5 › Chapter 5.3 › Certificate Lifecycle
Timeline
Stages of a certificate
  1. Generation/Issuance: generate key pair, create CSR, verify identity, issue.
  2. Distribution: deliver cert to holder and publish to repository.
  3. Usage: certificate used in protocols like TLS or code signing.
  4. Renewal: replace expiring certs, usually with new keys.
  5. Revocation: react immediately to compromise or invalidation.
  6. Expiration: certificate becomes invalid after its validity period.
Key Takeaway

Operationalize monitoring and automation for renewals and revocations to avoid outages and reduce compromise windows.

Example — renewal vs revocation
Plan renewals weeks before expiry with automated workflows. If a private key is stolen, revoke immediately and publish status via OCSP or CRL to prevent misuse.
Operational checklist
Monitor expirations, test revocation checks, document RA procedures, and restrict root CA access.
Common error
Neglecting revocation publication frequency leads to stale acceptance of compromised certificates.
