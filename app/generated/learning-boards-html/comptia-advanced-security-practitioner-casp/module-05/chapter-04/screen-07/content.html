Comparison › CRL vs OCSP
Certificate Revocation List (CRL)
List-based revocation published periodically to a CDP.
  • Simple to implement and cacheable by clients.
  • Large CRLs can be heavy; frequent updates increase load.
  • Requires CDP endpoints to be reachable by clients.
Example
Publish hourly CRLs if certificates are revoked frequently, but ensure distribution servers scale.
OCSP and Stapling
Real-time status via OCSP responders; stapling lets servers include signed responses in handshakes.
  • Provides up-to-date status and reduces client bandwidth when stapling is used.
  • Resiliency is critical; responder outages affect client validation.
  • Stapling improves privacy by avoiding client queries to the responder.
Key Takeaway
Use CRL for simple distribution and OCSP for immediacy; combine stapling and high availability for web services.
