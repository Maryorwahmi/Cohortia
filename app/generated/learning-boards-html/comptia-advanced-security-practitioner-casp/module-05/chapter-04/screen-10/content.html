Core Concept › Non-Windows PKI & Cloud CA
When to choose alternatives
  • Mixed OS environments where AD join is not feasible.
  • Requirements for API-driven certificate issuance and automation.
  • Need to integrate with cloud key vaults and managed HSMs.
Example
An EJBCA instance with HSM backing issues certificates to containers and Linux hosts via automation scripts and REST APIs.
Operational checklist
Support for CRL and OCSP, HSM integration, automated enrollment, and clear template/policy mapping.
Ensure logs, monitoring, and recovery procedures are consistent across platforms.
Key Takeaway
Choose a CA platform that matches your environment and supports automation, revocation, and secure key storage.
