Module 5 › Chapter 5.6 › Key Derivation Functions (KDF)
Definition
From shared secret to usable keys
KDFs take the binary output of an exchange and produce keys sized and bounded for encryption, MACs, or other cryptographic uses, often mixing in nonces or context strings.
Why not use the raw secret?
Raw secrets can be improperly sized or reused. KDFs provide domain separation and defend against cross-protocol misuse.
Concrete example
DH secret → KDF → Encryption key + MAC key
Derive separate keys for confidentiality and integrity by including session-specific context in the KDF inputs to avoid key reuse across purposes.
Check
Always document which KDF and inputs are used in your protocol so keys are reproducible and bounded to session semantics.
