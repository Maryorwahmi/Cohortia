Module 5 › Chapter 5.6 › Key Concepts
Diffie-Hellman (DH)
Establishes shared secrets without transmitting private keys, relying on the discrete logarithm hardness.
Elliptic Curve DH (ECDH)
Offers equivalent security with smaller keys and faster operations, suitable for constrained environments.
Key Rotation
Regularly change keys according to role: ephemeral per session, periodic for master keys; automate where possible.
Hardware Security Module
Tamper-resistant device that generates and stores keys and performs crypto operations without exposing plaintext keys to the host.
Trusted Platform Module
Device-embedded secure microcontroller for platform integrity and device-bound key storage.
Key Escrow
Storing key copies for recoverability; requires split control, multi-party authorization, and strict audits to mitigate risk.
Summary takeaway
Balance performance, protection, and recoverability when choosing exchange protocols and storage mechanisms. Protect high-value keys in hardware and limit escrow to well-governed scenarios.
