Module 5 › Chapter 5.6 › Software Key Storage & KMS
Comparison
Vault / KMS vs Local encrypted files
Vault / Managed KMS
Centralized API-based operations, automated rotation, fine-grained access control, and audit logs—reduces secrets on hosts.
Local encrypted storage
Simpler but riskier. Keys encrypted on host are only as safe as the host's protections.
Warning
Do not store key-encrypting keys on the same system as the encrypted key material.
Operational example
Database master key
Store the master key in a centralized KMS and perform encryption operations via KMS APIs; rotate quarterly and archive old keys per retention policy.
Pro-tip
Automate rotation and use least-privilege access to KMS APIs; logging provides an audit trail if a key is requested for decryption or export.
