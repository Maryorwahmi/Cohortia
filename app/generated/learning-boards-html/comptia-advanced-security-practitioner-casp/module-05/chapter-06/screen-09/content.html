Module 5 › Chapter 5.6 › Hardware Security Modules (HSMs)
Architecture
HSM components and workflow
Key lifecycle in HSM
Generate inside device → perform crypto operations → never export plaintext → backup wrapped keys.
Controls
Multi-person authorization, role separation, tamper detection, and audit logs.
Operational caveat
HSMs protect keys but do not immunize the host. Privileged or compromised hosts can request cryptographic operations if they hold credentials, so protect HSM access credentials and use restricted service accounts.
Concrete use
Root CA protection
Keep root CA private keys in an HSM. Sign intermediate certificates via HSM operations so the root private key never leaves the device.
Pro-tip
Combine HSM protections with strict administrative processes and audit trails to limit misuse even by privileged operators.
