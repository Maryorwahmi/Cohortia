Module 5 › Chapter 5.6 › Trusted Platform Module (TPM)
Definition & Use
Platform-rooted key protection
TPMs are embedded chips that store keys, perform crypto operations, and measure system state for attestation and disk encryption use cases.
Common uses
  • Protecting disk encryption keys like BitLocker.
  • Attesting boot integrity measurements.
  • Storing client certificates tied to hardware.
Comparison with HSM
TPM
Device-specific, low-capacity, excellent for attestation and disk keys.
HSM
Centralized, high-assurance, for enterprise master keys and signing operations.
Design decision
Use TPMs for client and platform protections; use HSMs when keys must be shared across services and require tamper-resistant hardware and centralized control.
