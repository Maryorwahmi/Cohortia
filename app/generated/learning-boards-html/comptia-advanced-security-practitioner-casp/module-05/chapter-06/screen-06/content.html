Module 5 › Chapter 5.6 › Perfect Forward Secrecy
Definition
Ephemeral keys protect past sessions
Generate per session
Create a fresh private exponent every handshake.
Derive via KDF
Run raw shared secret through a key derivation function before use.
Zeroize
Remove ephemeral private material after session ends.
Misconception
Using a strong long-term key without ephemeral session keys does not provide PFS; attackers with the long-term key can decrypt recorded sessions.
Scenario
TLS with ephemeral ECDH
Each connection uses ephemeral curve private values. If the server certificate is later compromised, recorded sessions remain protected because session keys were not derivable from the long-term key.
Check your understanding
Why must ephemeral private values be securely zeroized? Because persistence could enable retroactive decryption or escalate a compromise.
