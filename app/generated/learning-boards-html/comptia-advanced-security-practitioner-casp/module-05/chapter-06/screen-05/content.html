Module 5 › Chapter 5.6 › ECDH: Efficiency and Practical Trade-offs
Comparison
ECDH vs DH
ECDH benefits
Smaller key sizes, faster computation, lower bandwidth—ideal for constrained devices and high-load servers.
DH characteristics
Mature, widely understood, but requires larger key sizes for comparable security.
Common pitfall
Choosing non-standard curves or outdated libraries can introduce vulnerabilities despite small key benefits.
Practical scenario
Mobile app + cloud API
Use ECDH for session negotiation to minimize battery and latency, while ensuring ephemeral keys for PFS.
Pro-tip
Prefer well-known curves and library updates. The performance gains are only safe with vetted parameters.
