Hands-on Activity

Threat Modeling: Photo App

Create a DFD, mark trust boundaries, apply STRIDE, and propose mitigations with owners and timelines.

Step 1: DFD
Sketch components: user → web server → file storage and database for metadata.
Step 2: Trust boundaries
Mark where trust changes, such as between the user and server or server and storage.
Step 3: Apply STRIDE
For each flow list threats and score them to prioritize mitigations.
Sample findings
Tampering: modified metadata. Mitigation: server-side sanitization and strip EXIF. Owner: backend team. Timeline: 2 sprints.
Denial of Service
Mitigation: rate limiting and file size quotas.
Information Disclosure
Mitigation: encryption at rest and restricted access roles for sensitive storage.
Key Takeaway
Assign owners and timelines so threat-model findings become tracked work items.
