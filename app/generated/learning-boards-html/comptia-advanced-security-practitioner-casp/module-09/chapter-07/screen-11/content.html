Monitoring, Response & Audits

Use logs, alerts, and playbooks to detect incidents and improve controls back in the SSDLC.

Monitoring targets
Auth failures, unusual uploads, privilege escalations, and integrity violations.
Incident response
Prepared playbooks with roles, containment steps, and verification to shorten recovery time.
Example
Alert: surge in failed logins. Response: rate limit, lock suspect accounts, escalate to SOC, and analyze logs to improve detection and reset password policies.
Feedback loop
Feed production incidents into architecture and code reviews so fixes are systemic, not temporary.
Key Takeaway
Production telemetry identifies real threats and informs prioritized improvements to the SSDLC.
Reflective question: Which telemetry would give you the earliest warning of a likely attack?
