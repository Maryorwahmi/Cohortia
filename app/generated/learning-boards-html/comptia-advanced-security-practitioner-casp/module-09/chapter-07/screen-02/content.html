Learning Objectives

From understanding phases to applying threat modeling and enforcing security gates.

Bloom: Learn → Understand → Apply → Master
01
Map SSDLC phases and responsibilities
Define security requirements and checkpoints for each phase so teams know their responsibilities and handoffs. Verified competency milestone: documented phase-level security activities.
02
Apply threat modeling (STRIDE/DREAD)
Use structured methods to list and prioritize threats before coding starts. Verified competency milestone: completed threat model with prioritized mitigations.
03
Implement secure coding and SAST
Integrate static analysis and peer review to catch common vulnerabilities. Verified competency milestone: SAST in CI/CD and documented code-review checklist.
04
Define security gates and monitoring
Establish go/no-go rules and runtime checks so production risk is measured and managed. Verified competency milestone: enforceable security gate checklist and alerts.
