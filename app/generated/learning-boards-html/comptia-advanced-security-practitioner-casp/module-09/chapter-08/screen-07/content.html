Step-by-step (safe)
  1. Set up a vulnerable app in an isolated VM or container.
  2. Install OWASP ZAP and set target URL to the local app.
  3. Run Automated Scan and wait for completion.
  4. Review Alerts, reproduce requests, and confirm exploitability.
  5. Triage, fix, and re-test.
Safety Reminder: Only test systems you own or authorized targets in a controlled environment.
Terminal-style callouts
# Example: start ZAP in daemon mode
zap.sh -daemon -port 8081
# Point scanner to http://localhost:3000 and run automated scan from the GUI or API
# After scan, inspect Alerts tab and open details for reproduction steps
Scenario
ZAP finds possible SQL injection on search endpoint; reproduce the request to confirm.
Misconception
An alert does not always mean exploitability; always validate manually.
