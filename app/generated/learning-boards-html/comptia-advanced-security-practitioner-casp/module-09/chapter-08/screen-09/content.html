Module 9 › Chapter 9.8 › RASP
What RASP does
Protects from inside the runtime
  • Inspects application behavior and context to detect attacks.
  • Can block or neutralize attack payloads before they reach sensitive resources.
  • Operates in enforcement or monitoring-only modes.
Deployment considerations
Start with monitoring to collect baseline behavior, tune detection rules, and then enable enforcement for critical endpoints. Track performance and false positives closely.
Misconception
RASP replaces secure coding. It doesn't; it reduces impact while fixes are developed.
Key takeaway
Use RASP for high-risk endpoints as a compensating control, and always follow up with root-cause remediation.
