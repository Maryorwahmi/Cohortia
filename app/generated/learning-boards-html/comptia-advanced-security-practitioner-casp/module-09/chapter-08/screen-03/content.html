Module 9 › Chapter 9.8 › Competency Milestones
Milestone cards
SAST
Run a static scan, explain a flagged SQL injection finding, and show the secure fix.
DAST
Run a safe automated scan in a test environment and interpret alerts.
Remediation
Triage a report and recommend root-cause fixes and training actions.
Success checklist
  • Documented scan results with code context.
  • CI/CD gate plan that runs SAST and schedules DAST.
  • Re-test evidence after remediation.
