Module 9 › Chapter 9.8 › Remediation
Triage steps
  1. Assess severity, exploitability, and business impact.
  2. Assign owner and timeline based on risk.
  3. Perform root cause analysis to identify systemic fixes.
  4. Fix, document, and re-test with targeted scans and manual validation.
Practical example
A penetration test finds SQL injection on a search endpoint. Immediate fix: parameterize the query. Root cause: lack of input handling policy and no SAST rule coverage for that framework. Long-term actions: add a SAST rule, update secure coding standards, and add a CI gate for similar endpoints.
Key takeaway
Remediation that only fixes symptoms will repeat. Pair fixes with process and training changes and re-test to confirm closure.
