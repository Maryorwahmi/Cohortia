STRIDE applied to a feature
Identify assets, entry points, STRIDE threats, and mitigations to shape design choices.
Assets
User credentials, photos, database, cloud storage
Entry Points
Login form, upload API, viewing endpoint
Example Threats
SQL injection (tampering), XSS (information disclosure)
Mitigations
  • Use parameterized queries to prevent SQL injection.
  • Apply output encoding and input validation to mitigate XSS.
  • Enforce least privilege for storage access and separate upload processing.
Design Principles
Apply least privilege, defense in depth, secure defaults, and separation of concerns to make attacks harder and failures safer.
