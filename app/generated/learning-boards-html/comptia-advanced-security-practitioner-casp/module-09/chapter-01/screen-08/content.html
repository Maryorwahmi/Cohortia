Secure coding practices
Preferred habits: safe libraries, input validation, dependency management, and peer review.
  • Use well‑maintained libraries and enforce dependency scanning.
  • Perform peer code reviews that include security checklist items.
  • Automate SAST in CI to catch common patterns before merge.
  • Follow coding standards that avoid unsafe constructs and race conditions.
Code example (illustrative)
<!-- PSEUDO: avoid building queries with string concatenation -->
// Bad practice:
query = "SELECT * FROM photos WHERE owner = '" + userInput + "'";
// Good practice:
query = db.prepare("SELECT * FROM photos WHERE owner = ?");
query.bind(userInput);
results = query.execute();
Key Takeaway

Automate SAST in CI and require security items in PR reviews so risky patterns are corrected before release.
