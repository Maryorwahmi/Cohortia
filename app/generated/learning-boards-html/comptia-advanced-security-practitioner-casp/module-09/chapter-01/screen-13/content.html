Module 09 › Chapter 9.1 › Feedback Loops
Process Flow

From test findings to lasting change

Create a formal loop so test and incident results convert into updated requirements, design fixes, and developer education.

Detect
SAST, DAST, IAST, pen tests, and monitoring surface issues.
Triage
Assess risk, assign owner, and schedule remediation.
Improve
Update requirements, code standards, tests, and training based on root cause.
Concrete example

If several tests reveal insecure file handling, mandate a secure file handling library in the requirements, add unit tests for upload validation, and retrain developers on safe patterns.

Verification

After fixes, re-run relevant tests and monitor related telemetry to confirm the issue is resolved in production.
