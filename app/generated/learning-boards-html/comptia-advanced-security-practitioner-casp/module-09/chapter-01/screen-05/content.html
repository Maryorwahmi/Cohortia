Module 9 › Chapter 9.1 › Shift Left
Shift Left — Process view
Move security tasks earlier to reduce remediation cost and improve design choices.
Requirements: capture security controls and compliance obligations early.
Design: run threat modeling and apply secure design principles to reduce attack surface.
Development: use static analysis, secure libraries, and code review to catch mistakes early.
Concrete Example
If a login feature requires hashed credentials at requirements, design and code will conform; otherwise a late change may touch many modules and disrupt schedules.
Misconception Check
Shift left does not remove testing. It reduces late critical defects and changes the balance of preventive vs corrective work.
Key Takeaway

Adopt a checklist that enforces at least one security requirement and a short design review before development starts.
