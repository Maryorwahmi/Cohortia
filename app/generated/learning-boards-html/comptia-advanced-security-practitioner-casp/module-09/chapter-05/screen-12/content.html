Module 9 › Chapter 9.5 › Design Strategy
Stepwise approach
  1. Inventory and classify data with owners and review cycles.
  2. Create a protection matrix by state for each classification.
  3. Select key management and logging practices that scale across classes.
  4. Map data to regions per residency and sovereignty rules.
  5. Document processes and schedule audits and reviews.
Concrete scenario
For an EHR: label PHI restricted, use TDE for databases, TLS for API traffic, TEEs for high-risk processing, and keep data within required regions for legal compliance.
Key takeaway
Design a single artifact — the protection matrix — that implementers can follow to apply controls consistently.
