Module 9 › Chapter 9.5 › What is Data Classification?
Definition & Purpose

Classification assigns labels to data so handling rules are clear and consistent across storage, transit, and use.

Example
An HR payroll spreadsheet labeled confidential receives encryption and RBAC; a marketing brochure labeled public does not.
Common mistake
Not linking labels to concrete protections or failing to assign an owner for review.
Key takeaway
Labels must trigger actions: which encryption, which access controls, and which retention policy.
Analogy: Factory Sorting

Imagine materials on a conveyor sorted into bins. Each bin maps to a storage area with its own protections: open shelves for public items, locked vaults for restricted ones. The sorting rules are your classification policy.
