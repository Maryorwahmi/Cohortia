Module 9 › Chapter 9.5 › Data at Rest
Protections
  • Encryption: FDE, TDE, or managed storage encryption.
  • Access controls: RBAC, IAM, database roles.
  • Key management: rotation, limited key access, audits.
  • Lifecycle: retention policies and secure deletion (cryptographic erase).
Example — Database
Apply TDE, restrict DBA roles, encrypt backups with managed keys, and log all decrypt operations for audit.
Policy Template (example)
# Storage Asset: Payment DB
classification: Restricted
encryption: TDE enabled; backups encrypted with managed keys
access_control: RBAC; least privilege; MFA for admin roles
key_management: rotate keys annually; split duties for key access
retention: 7 years per policy; secure deletion after retention
audit: log all access and decryption operations
Misconception
Encrypting data at rest without strict key access controls is insufficient — keys are the gatekeepers.
