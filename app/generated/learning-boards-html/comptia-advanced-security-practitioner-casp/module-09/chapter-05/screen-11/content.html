Module 9 › Chapter 9.5 › Residency & Sovereignty
Implications for architecture
Map regulatory requirements to each data class and decide where data can be stored or processed.
Design replication and backups to honor geographic restrictions and document exceptions.
Ensure cloud provider contracts and data center agreements support required controls.
Example
An EHR may store PHI only in region A and block replication to region B unless legal requirements are satisfied.
Checklist
  • Inventory where each dataset is stored and processed.
  • Map applicable laws to those locations.
  • Use region selection and provider features to honor restrictions.
