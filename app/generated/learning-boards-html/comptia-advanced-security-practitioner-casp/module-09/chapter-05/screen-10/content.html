Key management checklist
  • Use hardware-backed or managed key storage for high-value keys.
  • Rotate keys periodically and after suspected compromise.
  • Limit key usage with least privilege and audit key operations.
  • Separate duties between key admins and data operators.
Example scenarios
Backups: Use a different, tightly controlled key and store keys separately from backup files.
Database columns: Apply column-level encryption for SSNs while relying on TDE for broader protection.
Dev vs Prod: Never reuse production keys in development environments.
