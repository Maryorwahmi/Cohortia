Response Sequence

Validate → Contain → Investigate → Remediate

Use contextual evidence and fingerprints to confirm an incident before taking disruptive containment actions. Follow documented playbooks for common scenarios.

Example Workflow
  1. Alert: outbound email detected with employee SSNs.
  2. Triage: confirm file contains SSNs using fingerprinting and logs.
  3. Contain: quarantine the message and block recipient addresses.
  4. Investigate: find attachments, prior shares, and file copies.
  5. Remediate: revoke shares, rotate credentials if leaked, notify stakeholders.
  6. Review: update policy to prevent similar future incidents and train users.
Runbook Essentials
  • Roles and contact list for triage and escalation.
  • Preapproved containment actions per scenario.
  • Logging requirements and evidence preservation steps.
Key Takeaway

Integrate DLP alerts with incident response playbooks. Ensure roles and containment actions are predefined to reduce response time and errors.
