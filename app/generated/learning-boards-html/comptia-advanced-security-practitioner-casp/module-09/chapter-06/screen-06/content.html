Module 9 › Chapter 9.6 › Endpoint, Network, and Cloud DLP
Endpoint DLP
Agents on user devices monitor clipboard, removable media, local file moves, and application transfers to prevent leaks at the source.
Scenario
Block copying payroll to USB and prevent pasting sensitive data into external webmail.
Network DLP
Inspects egress traffic at gateways and mail servers to stop sensitive content transmitted outside the network perimeter.
Scenario
Quarantine an outbound email that includes multiple social security numbers.
Cloud DLP
Monitors cloud storage and SaaS apps via API or CASB integration; enforces sharing, encryption, and access policies.
Scenario
Prevent external sharing of a confidential document stored in cloud drive and require encryption for approved exports.
Why not one model?

Each model covers different stages of data movement. Layering reduces gaps and accounts for encrypted traffic and cloud flows.

Key Takeaway

Select deployments by where data is created, transmitted, and stored, and combine models to close exposure gaps.
