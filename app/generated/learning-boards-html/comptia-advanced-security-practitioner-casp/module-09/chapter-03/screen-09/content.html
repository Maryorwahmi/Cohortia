RASP — Runtime Defense
Integrate protection into the application to detect and stop attacks in real time.
What RASP does
  • Monitor runtime behavior and data flow for attack patterns.
  • Block suspicious requests and alert security teams immediately.
  • Act as a mitigation while developers patch the root cause.
Production use
RASP is useful in production to reduce exposure, but it requires careful tuning to avoid disrupting legitimate traffic.
Benefits and trade-offs
  • Immediate protection against detected attacks.
  • May create false positives that require tuning.
  • Should not replace fixing vulnerabilities at the code level.
Analogy
Think of RASP as an on-site security guard who stops suspicious activity while the building owner repairs the broken lock.
Key Takeaway

RASP supplies real-time protection in production, reducing exposure but not replacing remediation upstream.
