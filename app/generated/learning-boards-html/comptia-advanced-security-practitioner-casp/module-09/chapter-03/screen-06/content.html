Definition Dynamic Application Security Testing
DAST — Runtime Scanning
Interact with an application to reveal vulnerabilities that require execution to appear.
Typical findings
  • Cross-site scripting visible in responses.
  • SQL injection visible via error messages or behavior.
  • Authentication or session management bypasses.
Lab-ready example
Use OWASP ZAP's Automated Scan against a local app and review the Sites tree and Alerts to see evidence and suggested fixes.
Caution

Active DAST can produce traffic with side effects. Prefer staging or isolated environments unless you understand the impact.

How to analyze results
Review alerts with request and response evidence, reproduce issues manually to validate exploitability, and prioritize fixes that have high impact and high confidence.
Tool examples
OWASP ZAP, Burp Suite, Acunetix as referenced in the chapter.
Key Takeaway

DAST confirms what an attacker can reach, but requires good crawling and test coverage to find all exposed paths.
