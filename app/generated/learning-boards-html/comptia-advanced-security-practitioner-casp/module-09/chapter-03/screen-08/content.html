Core ConceptInteractive Application Security Testing
IAST — Instrumented Runtime
Monitor execution and link findings to code with high precision.
How IAST operates
  • Deploy an agent or instrument the application runtime.
  • Monitor data flow, method calls and HTTP traffic during tests.
  • Correlate runtime evidence with specific code locations.
When to use
Run in QA during automated functional tests to reduce false positives and get exact remediation pointers.
Benefits and limits
  • High accuracy and actionable remediation guidance.
  • Requires instrumentation and sufficient test coverage.
  • Not a full replacement for SAST or DAST.
Example tool references
Contrast Security and HCL AppScan are examples discussed in the chapter.
Key Takeaway

IAST gives the best of both worlds for tested code paths: actionable findings with low false positives, when test coverage exists.
