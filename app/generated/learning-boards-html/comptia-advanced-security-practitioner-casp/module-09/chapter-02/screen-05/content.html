Module 9 › Chapter 9.2 › Input Validation
Process
Validation steps to apply
1. Define schema: accepted types, lengths, and patterns.
2. Apply allow-list checks and normalization.
3. Reject malformed data with safe user-facing errors.
4. Log failures for monitoring and triage.
Example
-- Pseudo-logic
if not is_integer(input['id']):
  reject('Invalid identifier')
if length(name) > 100:
  reject('Name too long')
Common mistakes
  • Relying only on client-side checks for enforcement.
  • Using broad regexes that accidentally accept malicious payloads.
  • Logging raw input including secrets or PII.
Key Takeaway

Validation reduces injection risk and clarifies the contract between callers and the application.
