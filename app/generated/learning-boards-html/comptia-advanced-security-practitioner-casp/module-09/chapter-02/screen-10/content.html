Module 9 › Chapter 9.2 › Credential Management
Do
  • Use a secrets manager or vault for runtime credentials.
  • Hash passwords with strong algorithms and salts.
  • Grant minimal permissions and design for rotation.
Don't
  • Commit keys or tokens to source control or config files.
  • Log secrets or include them in error messages.
  • Use fast unsalted hashes for password storage.
Key Takeaway

Treat secrets as sensitive resources: store them in vaults, restrict access, and plan rotation.
