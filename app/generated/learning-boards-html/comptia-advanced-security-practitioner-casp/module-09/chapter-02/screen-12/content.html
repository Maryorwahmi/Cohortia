Mistake
String-building SQL
Fix: parameterize queries or use ORM.
Mistake
Rendering raw user HTML
Fix: enable auto-escaping and use context encoding.
Mistake
Hardcoded secrets
Fix: use vaults and environment configuration with rotation.
Pro tip

Add unit tests that include malicious payloads and fail the build if those payloads change behavior or render as active content.
