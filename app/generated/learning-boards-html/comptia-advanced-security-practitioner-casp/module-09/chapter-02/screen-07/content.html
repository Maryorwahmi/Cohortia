Module 9 › Chapter 9.2 › SQL Injection
Vulnerable
Building SQL with string concatenation treats input as code. Attackers can inject additional statements or alter query logic.
username = request.form['username']
password = request.form['password']
query = f"SELECT * FROM users WHERE username = '{username}' AND password = '{password}'"
cursor.execute(query)
Secure
Parameterized queries send SQL and data separately so values never change the statement structure.
query = "SELECT * FROM users WHERE username = %s AND password = %s"
cursor.execute(query, (username, password))
Key Takeaway

Parameterize every database call; add tests that try injection payloads to prove coverage.
