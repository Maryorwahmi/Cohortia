Module 9 › Chapter 9.4 › CI/CD Pipeline Security
Architecture

Protect build agents, secrets, and artifact integrity

Access controls
Enforce least privilege, require MFA, and audit changes to pipeline definitions.
Secret management
Keep signing keys and tokens in a secure vault and inject them at runtime only when needed.
Immutable build agents
Use ephemeral, versioned images to prevent persistent compromise of build hosts.
Concrete control — artifact signing
Sign each artifact with a private key stored in a hardware-backed vault. Verify the signature in the deployment gate so only signed artifacts reach production.
Pro tip
Rotate signing keys periodically and preserve historical keys to validate older artifacts when needed.
Key Takeaway

Protect the pipeline like production: restrict access, isolate agents, and cryptographically sign artifacts to detect tampering.
