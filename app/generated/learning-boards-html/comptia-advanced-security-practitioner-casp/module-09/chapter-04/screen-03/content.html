Module 9 › Chapter 9.4 › Learning Objectives — Applied Milestones
Milestone: Generate an SBOM
Run a tool like Syft to output a machine-readable inventory for one service and store it with the build artifacts.
Evidence: a stored SBOM file listing direct and transitive components.
Milestone: Automated dependency scanning
Configure a scanner that runs on each pull request and produces an actionable report with severity and remediation suggestions.
Evidence: scheduled scans and a reduced open-vulnerability backlog.
Milestone: Signing critical artifacts
Add a signing step to the pipeline and verify signatures before deployment to detect tampering.
Evidence: artifact signatures and automated verification checks.
Milestone: Harden CI/CD access
Apply least privilege, require multi-factor authentication for pipeline changes, and isolate build networks from production services.
Evidence: access logs showing MFA and role-based policies.
