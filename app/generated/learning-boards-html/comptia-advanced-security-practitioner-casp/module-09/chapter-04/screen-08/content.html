Module 9 › Chapter 9.4 › Code Signing and Artifact Integrity
Definition

Sign artifacts to prove origin and integrity

Sign with a private key in a secure store and verify signatures before deployment to detect tampering.

Key Takeaway

Protect signing keys and integrate verification checks into deployment gates.

Concrete example
After a trusted CI build completes, the artifact is signed using a private key in a hardware-backed vault. The deployment system verifies the signature before allowing the artifact into production. If the signature is missing or invalid, the deployment is rejected.
Common mistake
Leaving signing keys accessible on developer machines or in plain text scripts undermines the value of signatures.
