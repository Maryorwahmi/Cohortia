Module 9 › Chapter 9.4 › What is the Software Supply Chain?
Definition

The ecosystem that builds software

It includes code, dependencies, build tools, CI/CD pipelines, vendors, and deployment artifacts. Each element can introduce risk.

Why it matters
  • Compromise at one point can impact many applications.
  • Transitive dependencies often hide risk if not inventoried.
  • Build tools and CI/CD are attack surfaces as well.
Analogy
Think of software as a recipe. The SBOM is the ingredient list; failing to list ingredients hides allergens.
Example inventory snippet
{
  "component": "example-service",
  "dependencies": [
    { "name": "express", "version": "4.17.1" },
    { "name": "lodash", "version": "4.17.21" }
  ],
  "transitive": [
    { "name": "debug", "version": "2.6.9" }
  ]
}
Key Takeaway

Inventory every direct and transitive component; visibility is the first step to control.
