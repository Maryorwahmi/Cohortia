Module 9 › Chapter 9.4 › Software Bill of Materials (SBOM)
Definition

An inventory of components and versions

Generate an SBOM per build and store it with the artifact so you can quickly map vulnerabilities to affected products.

Tools
Use SBOM generators that output SPDX or similar machine-readable formats to integrate with scanners and registries.
Example SBOM fragment
{
  "name": "app-service",
  "components": [
    { "name": "express", "version": "4.17.1", "hash": "sha256:..." }
  ]
}
Key Takeaway

An SBOM speeds impact analysis; maintain it per build and tie it to artifact storage.
