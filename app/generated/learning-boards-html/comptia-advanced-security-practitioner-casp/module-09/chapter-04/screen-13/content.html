Module 9 › Chapter 9.4 › Analyzing Open-Source Dependencies with npm audit
Terminal Demo (text-first)
Follow these steps in a terminal: navigate to your project folder, run npm audit, interpret the report, attempt remediation, and re-audit to verify.
$ cd my-node-app
$ npm install express lodash
$ npm audit

# Review the report: affected package, severity, path, remediation
$ npm audit fix
$ npm audit
Limitations to note
Depends on public advisories, may miss zero-days or non-npm components, and does not substitute for SBOM-based inventory.
Example package.json
{
  "name": "my-node-app",
  "version": "1.0.0",
  "dependencies": {
    "express": "^4.17.1",
    "lodash": "^4.17.21"
  }
}
Key Takeaway

Use npm audit for quick checks, but integrate SBOM generation and include transitive scanning as part of your pipeline.
