Module 9 › Chapter 9.4 › Build Environment Protections
Controls
  • Secret manager for signing keys and tokens.
  • Network segmentation between build and production.
  • Ephemeral build agents and immutable images.
  • Audit logging and MFA for pipeline changes.
Scenario
If a developer workstation is compromised and credentials are stolen, limiting pipeline permissions and using MFA reduces the attacker’s ability to modify builds. Immutable agents mean any injected state is removed between runs.
Pro tip
Require verification of artifact signatures before any deployment to production networks.
Key Takeaway

Treat build systems as production-adjacent assets and remove unnecessary access to production credentials.
