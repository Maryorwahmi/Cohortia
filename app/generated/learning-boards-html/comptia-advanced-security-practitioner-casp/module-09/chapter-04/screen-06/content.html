Module 9 › Chapter 9.4 › Dependency Scanning and Management
Process

Discover → Assess → Remediate → Verify

Discover
Generate SBOMs and run automated scanners to list direct and transitive dependencies.
Assess
Map components to vulnerability databases and prioritize by severity and exposure.
Remediate
Upgrade, pin, replace, or apply mitigations while tracking change control.
Verify
Rescan after changes and validate artifacts no longer carry the vulnerable component.
Concrete example
Run a tool to generate an SBOM, feed that into a vulnerability scanner, triage results by severity, and then open remediation tasks linking to the affected component and version.
Misconception
Assuming a single scanner will find everything. No single tool covers all ecosystems and zero-days.
Key Takeaway

Automate scans across pull requests and include transitive dependencies so fixes are timely and verifiable.
