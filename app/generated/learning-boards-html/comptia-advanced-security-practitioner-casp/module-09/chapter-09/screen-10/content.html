Module 10 › Chapter 9.9 › DLP Strategy
DLP comparison
Detection types
  • Content inspection (patterns, regex)
  • Contextual rules (user, destination, device)
  • Label-based (classification-driven)
Response actions
  • Block or quarantine
  • Alert or notify
  • Apply encryption or tokenization
Concrete scenario
Export of financial data triggers label-based DLP that checks both file tags and content patterns. If the destination is external, block and create an incident for review.
Misconception
DLP is not a set-and-forget control; it requires classification integration and continuous tuning to remain effective.
Key Takeaway

Align DLP with classification and incident workflows; tune policies to balance protection and business continuity.
