Module 10 › Chapter 9.9 › Data Classification
Definition

What is data classification?

Assigning sensitivity labels that drive handling rules such as encryption, access controls, retention, and monitoring.

Levels
  • Public
  • Internal
  • Confidential
  • Restricted
Common mistakes
  • Over-classifying everything
  • Not updating labels for derivatives
  • Missing enforcement hooks
Key Takeaway

Classification must be actionable and maintained; labels should map to enforcement such as encryption and access policy.

Process & Example

A simple process: discover data, map sensitivity, assign label, implement controls, audit results.

Concrete example
Customer PII → Restricted: store in encrypted database with TDE, require MFA for access, log every access, do not export without DLP clearance.
Analogy
Think of classification as an address label on a parcel: it declares how fragile or confidential the contents are, and carriers follow rules when handling it.
