Key management architecture
Core functions
  • Generate keys securely
  • Store keys in HSM or managed KMS
  • Control access with RBAC and separation of duties
  • Rotate and revoke keys as part of lifecycle
HSM vs Managed KMS
HSMs provide physical tamper resistance and strong separation; managed KMS offers operational simplicity. Choose based on threat model and compliance needs.
Example workflow
Generate a key in an HSM, use wrapped keys for application encryption, rotate keys quarterly, and log all key uses for audit. In a compromise, revoke keys and re-encrypt critical data as needed.
Misconception
Assuming keys stored in code or shared documents are safe; this practice breaks encryption guarantees and must be eliminated.
Check your plan
Do you have documented rotation windows, recovery procedures, and an auditable key use trail? If not, develop them now.
