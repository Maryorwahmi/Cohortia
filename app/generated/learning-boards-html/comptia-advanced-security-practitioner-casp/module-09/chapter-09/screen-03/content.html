Implementation Focus

What you must deliver: maps, policies, tuned controls, and audit evidence.

Inventory & Classification Map
Catalog systems, datasets, and processing flows. Link each to a classification and handling policy.
Mnemonic: Discover → Label → Route
Key Management Plan
Define who generates keys, where they are stored (HSM/KMS), rotation windows, and emergency recovery.
Mnemonic: Generate → Protect → Rotate
DLP Tuning & Response
Create policies from classification labels, tune rules to reduce false positives, and define incident triage steps.
Mnemonic: Detect → Tune → Remediate
Privacy Impact & PET Use
Run DPIAs for new projects and apply PETs where analysis and privacy must co-exist.
Mnemonic: Assess → Apply → Validate
