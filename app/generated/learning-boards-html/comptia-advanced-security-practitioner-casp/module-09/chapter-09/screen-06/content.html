Module 10 › Chapter 9.9 › Encryption at Rest
Common patterns
  • Full-disk encryption (FDE): Transparent protection for endpoints and servers.
  • Transparent Data Encryption (TDE): Database-level protection to secure data files and backups.
  • File/Object encryption: Per-file keys for cloud storage and export protection.
Example
Use TDE for production databases and object-level encryption for exported CSVs to enable selective key rotation and stronger separation of duties.
Trade-offs & guidance
Choose the pattern that balances operational need and threat profile. Use object-level encryption for shared buckets with mixed sensitivity; use TDE to protect puzzles involving backups and DB file theft.
Misconception
Encryption without proper key controls is ineffective. Key exposure defeats all at-rest protection.
Pro tip
Prefer managed KMS or HSMs for production keys and enforce separation of duties between key custodians and data owners.
Key Takeaway

Match encryption pattern to the use case and always design for secure key lifecycle management.
