Module 10 › Chapter 9.9 › Designing Classification
Step-by-step

Five steps to an enforceable scheme

1. Discover
Inventory systems and flows; use scanners as an aid.
2. Define Levels
Map labels to business and regulatory impact.
3. Map Controls
Tie labels to encryption, access, and DLP rules.
4. Monitor
Audit coverage, tune DLP, measure incidents.
5. Govern
Periodic review, owner accountability, training.
Concrete scenario
A cloud storage bucket contains export files. Scanner flags PII. Data owner splits files, assigns Restricted to PII with object encryption and DLP rules that block external uploads unless approved.
Misconception
Automation alone is not enough; owners must validate edge cases and maintain context for derived datasets.
Key Takeaway

Design for enforceability: labels must map to controls and measurable checks.
