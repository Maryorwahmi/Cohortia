Module 11 › Chapter 11.8 › Process Flow
1. Discover

Inventory accounts, resources, and identities to avoid blind spots.

2. Assess

Compare live state to CIS and regulatory baselines; generate findings.

3. Triage

Apply risk scoring and attack-path context to prioritize fixes.

4. Remediate

Use audit-only, manual approval, then automated remediation for safe issues.

Example policy lifecycle
Audit-only: monitor S3 public ACLs
Manual: create ticket to change bucket policy
Automated: enable public access block for known buckets
