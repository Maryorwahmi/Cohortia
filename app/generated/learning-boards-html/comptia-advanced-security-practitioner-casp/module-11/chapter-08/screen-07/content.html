Remediation modes

Audit-only

Observe noncompliant resources without making changes to measure impact.

Guided

Create runbooks or approval steps before applying fixes.

Automated

Automatic, idempotent fixes for well-understood, low-risk issues.

Operational controls
  • Owner notification and approval gates
  • Rollback and audit logs for every automated action
  • Scoped automation using tags or environment filters
Example: Public S3 bucket remediation
Detection: CSPM flags public ACL. Audit: track occurrences. Guided: open ticket to apply public access block. Automated: Lambda toggles public access block for buckets without owner objections after 24-hour window.
Key Takeaway

Safe automation balances speed with controls: audit, validate, then automate with rollbacks and owner communication.
