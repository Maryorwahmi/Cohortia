Module 11 › Chapter 11.4 › Learning Objectives
01
Identify shared responsibility
Recognize what the cloud provider secures versus what you must secure.
Understand which layers are managed and where application and data protections must be applied. A useful mnemonic is Platform vs. Application vs. Data layers.
VERIFIED COMPETENCY MILESTONE
02
Harden managed services
Configure encryption, network isolation, and auditing for databases and app platforms.
You will learn to require TLS, restrict database ingress to application servers, and enable auditing so suspicious queries are visible in central logs.
VERIFIED COMPETENCY MILESTONE
03
Apply serverless best practices
Assign minimal permissions, validate inputs, and avoid hardcoded secrets.
Learn to craft IAM roles narrowly scoped to required resources, secure triggers, and retrieve secrets at runtime from a Secrets Manager or Key Vault.
VERIFIED COMPETENCY MILESTONE
04
Secure APIs and gateways
Enforce authentication, input validation, rate limiting, and WAF protections.
You will design gateways that validate requests early, throttle abusive clients, and integrate with a WAF so common web exploits are blocked before backend processing.
VERIFIED COMPETENCY MILESTONE
