Module 11 › Chapter 11.4 › Logging & Monitoring
Monitoring timeline
Instrument: Enable audit logs, function invocation logs, and WAF logs.
Aggregate: Forward logs to a central SIEM or log store for correlation.
Alert: Create rules for anomalous behavior and failed auth spikes.
Respond: Execute runbooks to isolate, rotate secrets, and remediate.
Combine detection with tested response plans so alerts lead to swift containment and recovery.
Network and recovery
Integrate functions needing DB access with a VPC, restrict egress, and verify backups and RTO/RPO. Test recovery frequently so backups are reliable when needed.
Key Takeaway

Operational controls make security actionable: logs, alerts, network limits, and runbooks are required complements to configuration hardening.
