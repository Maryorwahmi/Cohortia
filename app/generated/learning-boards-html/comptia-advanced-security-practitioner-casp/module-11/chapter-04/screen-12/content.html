Python example (runtime retrieval)
import boto3
import os
import json

def get_secret(secret_name, region_name="us-east-1"):
  client = boto3.client('secretsmanager', region_name=region_name)
  resp = client.get_secret_value(SecretId=secret_name)
  return resp.get('SecretString')

def lambda_handler(event, context):
  secret_name = os.environ['EXTERNAL_API_KEY_SECRET_NAME']
  api_key = get_secret(secret_name)
  # Use api_key transiently
  return {'statusCode': 200, 'body': json.dumps('OK')}
Operational checklist
  • Store secret name in env var; do not store the secret itself.
  • Grant the function identity secretsmanager:GetSecretValue only for the required secret ARN.
  • Audit GetSecretValue calls and rotate secrets periodically.
  • Scan dependencies and keep them minimal to reduce supply-chain risk.
Key Takeaway

Use managed secret stores and managed identities to retrieve secrets at runtime. Avoid environment-level secrets that are visible in portal UIs or logs.
