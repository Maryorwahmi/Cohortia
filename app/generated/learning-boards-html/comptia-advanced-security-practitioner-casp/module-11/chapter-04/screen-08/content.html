Module 11 › Chapter 11.4 › Common Mistakes
Mistake
Overly permissive network access to managed DBs
Mitigation: Use security group references and private endpoints; avoid wide CIDR rules.
Mistake
Hardcoding secrets in code or config
Mitigation: Move secrets to Key Vault/Secrets Manager and use managed identities to retrieve them at runtime.
Mistake
Neglecting application-layer security
Mitigation: Add SAST/DAST, use WAFs, and validate input early at the gateway.
Mistake
Not centralizing logs
Mitigation: Forward audit and access logs to a SIEM and create alerting rules for anomalies.
Quick playbook
  • Confirm network rules use identity references
  • Remove secrets from code, use secret manager
  • Add CI/CD security scans
  • Enable WAF and gateway validation
