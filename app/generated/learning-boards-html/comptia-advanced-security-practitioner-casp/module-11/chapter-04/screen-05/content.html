Module 11 › Chapter 11.4 › Managed Databases
Architecture view
Example controls span encryption, IAM, network, backups, and audit forwarding.
Encryption
Enable at-rest and enforce TLS for in-transit connections.
Network Isolation
Place DB in private subnet and authorize AppServer SG only.
Auditing & Backups
Forward logs and verify RPO/RTO match policy.
Concrete configuration example
# Allow inbound traffic on MySQL port from the AppServerSG
aws ec2 authorize-security-group-ingress \
  --group-id sg-0abcdef1234567890 \
  --protocol tcp \
  --port 3306 \
  --source-group sg-0fedcba987654321
This example restricts database ingress to a trusted application server security group rather than opening the database to a range of IP addresses. It adapts to scaling and reduces exposure to the internet.
Key Takeaway

Confirm encryption, restrict network access to specific application identities, and centralize auditing for detection.
