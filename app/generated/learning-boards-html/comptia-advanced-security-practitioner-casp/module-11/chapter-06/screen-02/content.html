Learning Objectives

Learn, understand, apply, and master serverless security fundamentals.

Bloom: Learn → Understand → Apply → Master
01
Shared responsibility

Explain which controls the provider manages and which you must secure. Verified competency: identify provider-managed runtime, and list three customer-owned controls.

VERIFIED COMPETENCY MILESTONE
02
Threats to functions

Identify injection, broken auth, and secrets exposure specific to event-driven functions. Verified competency: map three vulnerabilities to remediation patterns.

VERIFIED COMPETENCY MILESTONE
03
Least-privilege IAM

Design function roles that grant only necessary actions on specific resources. Verified competency: create an IAM policy scoped to a single bucket or secret ARN.

VERIFIED COMPETENCY MILESTONE
04
Secrets & telemetry

Use a secrets manager and robust logging to enable detection and secure runtime retrieval. Verified competency: integrate a secrets manager and validate logs sent to a SIEM.

VERIFIED COMPETENCY MILESTONE
