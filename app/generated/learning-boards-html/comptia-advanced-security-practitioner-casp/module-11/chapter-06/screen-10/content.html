Module 11 › Chapter 11.6 › Secure Request Flow
Client → API Gateway
Authenticate, validate schema, throttle, and apply WAF rules to drop obvious attacks before invocation.
API Gateway → Function
Function re-validates input, enforces business rules, retrieves secrets securely, and logs masked context.
Function → Database
Use parameterized queries, scoped DB user, and record queries in audit logs for later investigation.
Why layered controls work

Blocking at multiple points reduces the chance that a single misconfiguration allows an exploit to traverse the entire path. If the gateway misses an issue, the function can still reject it and log the attempt.

Misconception

Edge validation is sufficient. It is not. Always validate again in the function because other triggers may bypass the gateway.
