Secure an AWS Lambda: Walkthrough

Follow these steps in your environment to see the security improvements in practice.

Step 1 — Deploy insecure function
zip insecure_lambda.zip insecure_lambda.py
aws lambda create-function --function-name InsecureLambdaFunction --runtime python3.9 --role  --handler insecure_lambda.lambda_handler --zip-file fileb://insecure_lambda.zip
Step 2 — Create secret
aws secretsmanager create-secret --name my-app-api-key --secret-string '{"api_key": "my-secure-api-key-456"}'
Step 3 — Deploy secure function
zip secure_lambda.zip secure_lambda.py
aws lambda create-function --function-name SecureLambdaFunction --runtime python3.9 --role  --handler secure_lambda.lambda_handler --zip-file fileb://secure_lambda.zip
Validation

Invoke the secure function with valid and invalid inputs and review CloudWatch logs to confirm the secret was retrieved securely and not logged in plain text.
