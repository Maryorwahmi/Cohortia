Why not hardcode

Hardcoded secrets are exposed if code or configuration is leaked and are difficult to rotate. Environment variables are also visible with the right permissions and are not a substitute for a secrets store.

Secure retrieval pattern
import boto3
import json

def get_secret(secret_name):
  client = boto3.client('secretsmanager')
  response = client.get_secret_value(SecretId=secret_name)
  if 'SecretString' in response:
    return json.loads(response['SecretString'])
  else:
    return response['SecretBinary']
Pro Tip

Cache secrets in-memory during the execution context to avoid repeated calls while still preventing storage in code or static config.

Operational controls
  • Use dedicated secrets service and enable rotation where possible
  • Grant functions GetSecretValue only on the specific secret ARN
  • Mask secret values in logs; log only masked length or status
  • Audit access to secrets and configure alerts for unusual retrieval patterns
Key Takeaway

Move secrets out of code, retrieve them at runtime using least-privilege access, and monitor secret access for anomalies.
