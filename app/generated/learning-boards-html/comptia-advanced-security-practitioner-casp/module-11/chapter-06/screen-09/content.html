Module 11 › Chapter 11.6 › Network & API Gateway
VPC & Security Groups

Attach functions to the VPC only when necessary. When you do, apply least-privilege network rules, ensure private subnets for sensitive resources, and configure NACLs to limit exposure.

Example control
Allow outbound database connections only to the DB subnet and restrict inbound management ports to admin ranges.
Misconception
Assuming VPC attachment is always safe. It adds complexity and must be configured carefully to avoid widening the attack surface.
API Gateway protections

Use request validation, throttling, and WAF integration to stop malformed or abusive traffic before it hits your function. Add custom authorizers to enforce authentication at the gateway layer.

Key Takeaway

Edge protections reduce unnecessary invocations, limit risk, and improve detection when paired with function-level validation.

Request validation: enforce schema and types for incoming payloads.
Throttling: limit rate to prevent abuse and sudden cost spikes.
WAF: block common web exploits such as SQLi and XSS at the edge.
