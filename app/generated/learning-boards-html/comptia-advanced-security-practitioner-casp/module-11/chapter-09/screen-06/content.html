Module 12 › Chapter 11.9 › Centralized Logging & Monitoring
Architecture pattern
Ingest provider audit logs, flow logs, and application logs into a centralized SIEM or log store. Index events and retain them according to your retention policy so they are available for investigations.
Sources
CloudTrail / Activity Logs, VPC Flow Logs, CloudWatch logs, and security service findings.
Processing
Forward logs to SIEM for enrichment and correlation rules for suspicious API activity and data exfiltration.
Practical example
An alert triggers when CloudTrail shows a PutBucketPolicy. The SIEM query retrieves events, cross-references flow logs for large GET requests, and triggers snapshot creation for affected volumes. This chain yields a timeline and preserved artifacts for forensics.
Common Mistake

Only enabling management logs and neglecting flow or application logs makes constructing a complete timeline difficult.
