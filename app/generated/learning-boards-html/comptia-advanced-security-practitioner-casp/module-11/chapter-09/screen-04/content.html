Module 12 › Chapter 11.9 › Adapting the IR lifecycle for cloud
Process steps (cloud-mapped)
  1. Preparation: enable CloudTrail/Activity logs, flow logs, snapshot policies, and playbooks.
  2. Identification: correlate API events, flow logs, and security findings to build a timeline.
  3. Containment: revoke credentials, modify network rules, or quarantine resources via API calls.
  4. Eradication: replace compromised resources using immutable images; patch and harden images.
  5. Recovery & Lessons: restore from snapshots and update playbooks and retention settings.
Key Takeaway

Treat each IR phase as a set of API calls, logs, and immutable artifacts so you can act despite limited host access.
