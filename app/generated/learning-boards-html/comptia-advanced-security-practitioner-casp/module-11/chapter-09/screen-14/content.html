Module 12 › Chapter 11.9 › Eradication & Recovery with immutable infrastructure
Workflow
  1. Preserve artifacts and logs.
  2. Identify root cause and patch the image or pipeline.
  3. Terminate compromised resources and redeploy from hardened images.
  4. Restore data from secure backups and validate integrity.
  5. Update playbooks and test recovery procedures.
Example
A compromised web server is terminated and replaced by an image built from a CI pipeline that includes vulnerability scanning and configuration hardening. Data is restored from encrypted backups, and monitoring verifies the new deployment behaves normally.
Key Takeaway

Immutable infrastructure shortens recovery time and reduces the risk of missed artifacts or persistent compromise.
