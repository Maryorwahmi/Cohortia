Module 12 › Chapter 11.9 › Querying CloudTrail and building timelines
CLI example (visual)
# Example AWS CLI command to query CloudTrail for suspicious activity
# This looks for unauthorized API calls changing bucket policies
aws cloudtrail lookup-events \
    --lookup-attributes AttributeKey=EventName,AttributeValue=PutBucketPolicy \
    --start-time 2023-01-01T00:00:00Z \
    --end-time 2023-01-01T23:59:59Z \
    --query 'Events[?contains(CloudTrailEvent, `UnauthorizedOperation`) == `true`]'
Use the query to identify who made the change, which role or IP was used, and when. Save results to secure storage with incident tags.
Checklist
  • Scope query by time and resource to reduce noise.
  • Cross-reference flow logs for large transfers or external destinations.
  • Save raw query output to encrypted, versioned storage with incident metadata.
Pro Tip

Automate queries for known IoCs and export results to an immutable bucket for later analysis.
