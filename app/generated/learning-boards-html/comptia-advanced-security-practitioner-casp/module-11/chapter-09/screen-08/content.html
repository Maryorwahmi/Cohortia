Module 12 › Chapter 11.9 › Rapid containment via APIs
Containment options
  • Network Isolation: associate a restrictive security group or revoke routing to block traffic.
  • Credential Revocation: revoke compromised keys, disable IAM users, or rotate instance role credentials.
  • Resource Quarantine: stop or move the instance to a quarantine subnet for offline analysis.
Key Takeaway

Containment actions should prioritize limiting attacker access while preserving snapshots and logs for later forensic review.

Concrete scenario
If an EC2 instance is suspected, create an empty quarantine security group and replace the instance's security groups with it. Verify isolation, then create EBS snapshots of attached volumes for analysis. Document each API call and tag snapshots with the incident ID.
Common Mistake

Taking the instance offline before creating snapshots destroys volatile evidence; always snapshot first when feasible.
