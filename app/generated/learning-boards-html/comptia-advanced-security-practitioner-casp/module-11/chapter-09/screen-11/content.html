Module 12 › Chapter 11.9 › Forensics for serverless and containers
Comparison: VM vs Ephemeral
VMsDisk snapshots, possible memory acquisition, persistent host artifacts.
Containers/FunctionsEphemeral runtime, rely on invocation logs, image metadata, and runtime telemetry.
Strategies
  • Centralize logs and enable invocation tracing for functions and pods.
  • Scan and preserve container images from your registry.
  • Deploy runtime detection agents to capture live behavior when possible.
