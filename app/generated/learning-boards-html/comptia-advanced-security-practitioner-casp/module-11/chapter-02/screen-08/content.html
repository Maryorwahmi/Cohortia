Module 11 › Chapter 11.2 › IaaS / PaaS / SaaS Comparison
Comparison
IaaS
  • Customer: OS, apps, network configs, data
  • Provider: physical hosts, hypervisor, core network
  • Tooling focus: patching, segmentation
PaaS
  • Customer: app code, data, secrets, platform settings
  • Provider: runtime, middleware, infra
  • Tooling focus: CI/CD security, secret rotation
SaaS
  • Customer: IAM, data governance, app config
  • Provider: full app stack, availability, patches
  • Tooling focus: identity federation, DLP, retention
Key Takeaway

Assign controls to the party responsible and choose tools that align with whether you need host-level patching, secure code checks, or identity governance.

Check Your Policy
When adopting a new service, list expected responsibilities and verify them against the CSP's shared responsibility matrix before deployment.
