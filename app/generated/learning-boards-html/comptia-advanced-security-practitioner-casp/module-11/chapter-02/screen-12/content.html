Module 11 › Chapter 11.2 › Key Concepts
Shared Responsibility Model
Framework defining CSP and customer security obligations.
Model shifts
IaaS → PaaS → SaaS shifts responsibility from customer to provider progressively.
Operationalize controls
Use automation, logging, and least-privilege to ensure customer-side security is enforceable and auditable.
Summary
When evaluating services or investigating incidents, map each control to the shared responsibility model and implement the correct remediation path for customer-side failures.
