Common missteps

These mistakes are frequent and preventable. They all represent customer-side responsibilities in the shared model.

Public storage
Misconfigured bucket policies or ACLs expose sensitive data. Use account-level blocks and scan for public objects.
Open network ports
Security groups allowing inbound access from anywhere enable remote compromise. Use restrictive rules and bastion hosts where needed.
Secrets in code
Storing keys in code or environment variables risks leakage. Use managed secret stores and rotate keys regularly.
Defensive Controls
  • Automated configuration scanning and CSPM tools
  • Account-level public access blocks and deny rules
  • Immutable infrastructure and automated patching
  • Secret vaults and least-privilege IAM
Key Takeaway

Automation and guardrails catch many of these errors before they become breaches. Prioritize preventive controls and continuous monitoring.
