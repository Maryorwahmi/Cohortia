Process

Where the boundary moves in PaaS

Provider covers
Runtime patching, middleware maintenance, and underlying infrastructure availability.
Customer covers
  • Application code and dependencies
  • Data encryption and classification
  • Secrets and API key management
  • Platform configuration and access controls
Key Takeaway

PaaS reduces host management but increases application governance responsibilities; treat platform settings and secrets as first-class security objects.

Concrete Example
A managed database is patched by the CSP, but you must create strong database users, limit privileges, and encrypt sensitive columns. Platform maintenance does not remove your need for least-privilege design.
Misconception
Believing that PaaS automatically protects application-level vulnerabilities is incorrect; use SAST and DAST in your pipelines and protect runtime secrets.
