Assessments and Practical Tasks

Tasks focus on mapping breaches to responsibility, and proposing defensible customer controls.

Breach Analysis Task
Identify which aspects of a breach fall to the CSP and which belong to the customer. Produce a mitigation list for each customer-side failure.
Configuration Review
Audit security groups, bucket policies, and managed database access rules to validate customer controls are in place.
Vendor Documentation Check
Use the CSP's shared responsibility matrix to verify the boundary for services you use; do not assume default coverage.
Quick Example
If an S3 bucket is public due to a bucket policy you configured, the customer is responsible for that exposure and must fix the policy or enable account-level public access blocks.
Why check documentation
Provider documentation changes. Confirm service-level boundaries before writing your remediation plan to avoid incorrect assumptions.
