Module 11 › Chapter 11.10 › CWPP: Scanning & Runtime
Vulnerability Management
Scan container and VM images in registries and in CI/CD to detect known vulnerabilities before deployment. Feed results into a vulnerability program to track fixes.
CI/CD Integration
Fail builds or block images that contain critical vulnerabilities to prevent deployment of risky artifacts.
Telemetry Forwarding
Send scan results to SIEM and vulnerability trackers so remediation is coordinated and tracked.
Runtime Detection
Monitor processes, file integrity, and network anomalies. Detect behaviors like spawning shells or contacting suspicious endpoints and trigger containment.
Techniques
Host-based intrusion detection, system call monitoring, and memory protections are common methods used by CWPPs.
Common Mistake
Relying on scanning alone misses runtime exploits. Combine scanning and telemetry for thorough coverage.
Key Takeaway

Use image scanning to prevent vulnerable artifacts and runtime detection to catch active attacks. Integrate both into your SOC and vulnerability program.
