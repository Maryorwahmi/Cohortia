Module 11 › Chapter 11.10 › Key Concepts — Part 1
Cloud Security Posture Management (CSPM)
Continuously monitor cloud configurations for misconfigurations, compliance violations and security risks.
Cloud Workload Protection Platform (CWPP)
Protects workloads—VMs, containers, serverless—through image scanning, runtime monitoring, and application control.
Configuration Auditing
Reviewing cloud resource settings against security best practices and policies to find deviations.
Summary
Keep these definitions handy when you choose tools, write playbooks, and explain capabilities to stakeholders.
