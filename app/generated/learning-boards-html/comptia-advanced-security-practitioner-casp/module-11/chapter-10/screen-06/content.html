Module 11 › Chapter 11.10 › What is CWPP?
Definition

Runtime protection for workloads

CWPP focuses on scanning images, monitoring runtime behavior, enforcing application control, and applying network micro-segmentation across VMs, containers, and serverless.

Vulnerability Management
Scan container and VM images for known vulnerabilities and integrate results into deployment pipelines.
Runtime Protection
Monitor processes, system calls, and network activity to detect anomalies like a server spawning a shell unexpectedly.
Examples & Pitfalls
Application Control
Enforce allowlists so only approved executables and processes run on a workload.
Micro-Segmentation
Limit lateral movement by controlling pod-to-pod or host-to-host communication at a granular level.
Common Mistake
Deploying agents without testing can cause performance problems. Test in staging and monitor overhead.
Key Takeaway

CWPP secures the running workload through scanning, monitoring, application control, and network isolation. Integrate telemetry into your SOC to act on alerts.
