Module 11 › Chapter 11.10 › Container & Serverless Security
Container Security
Scan images in registries and CI/CD, use admission control to block risky images, add runtime monitoring, and enforce network policies to isolate workloads.
Admission Control
Prevent deployment of images that fail vulnerability checks or violate policy.
Runtime Sidecars
Deploy monitoring sidecars or DaemonSets for continuous runtime telemetry without modifying app code.
Serverless Security
Monitor function execution for anomalous behavior, ensure least privilege on function roles, and scan dependencies in deployment packages to mitigate supply chain risks.
Supply Chain
Dependencies in images or packages must be scanned; vulnerabilities in libraries affect all functions that use them.
Misconception
Serverless does not eliminate the need for vulnerability scanning or least-privilege controls.
Key Takeaway

Apply image scanning, admission controls, and runtime monitoring across containers and serverless, and treat supply chain risks seriously.
