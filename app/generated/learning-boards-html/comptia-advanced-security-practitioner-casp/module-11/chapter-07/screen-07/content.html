Definition
Network Policies create micro-perimeters
Build policies that explicitly allow traffic and rely on implicit deny to block everything else.
Key fields: podSelector, policyTypes, ingress, egress, from/to selectors, ports.
Design tip
Map application tiers with labels and create policies that allow only the necessary cross-tier ports.
Concrete YAML example
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: allow-frontend-to-backend
  namespace: my-app-namespace
spec:
  podSelector:
    matchLabels:
      app: backend
  policyTypes:
    - Ingress
  ingress:
    - from:
        - podSelector:
            matchLabels:
              app: frontend
      ports:
        - protocol: TCP
          port: 8080
Test
After apply, confirm frontend logs show successful calls and other pods fail to connect.
Misconception
Not all CNIs enforce NetworkPolicy; verify support before relying on policies for isolation.
Key Takeaway

Define explicit allow rules and test connectivity; Network Policies are a simple, high-impact control to reduce lateral movement.
