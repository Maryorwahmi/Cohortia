Comparison
Image controls vs gaps
Trusted registries: approved sources only
Scanning: block critical CVEs in CI
Signing: verify image provenance on pull
Practical steps
  1. Enforce allowed registries with an admission controller or image policy.
  2. Scan images in CI and fail builds with critical vulnerabilities.
  3. Sign images and verify signatures at admission time.
Pitfall
Using mutable tags like latest or pulling directly from public registries without verification.
Key Takeaway

Image security is layered: trusted registries, CI scanning, and signing plus admission checks give the strongest guarantees.
