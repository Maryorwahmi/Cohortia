Best practices
  • Create dedicated ServiceAccounts for each workload.
  • Write Roles scoped to namespace and to required verbs only.
  • Use RoleBindings, not ClusterRoleBindings, unless cluster scope is required.
  • Test allowed vs forbidden actions to confirm behavior.
Comparison
Common mistakes
  • Using cluster-admin for convenience.
  • Relying on default service accounts without reviewing permissions.
  • Not rotating or auditing tokens and bindings regularly.
  • Assuming RBAC alone prevents all misuse without network controls.
Key Takeaway

Prefer explicit, narrow Roles and live tests; remove or tighten any role that grants more than the exact required verbs.
