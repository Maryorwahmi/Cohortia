Pod Security Standards
Enforce safe runtime contexts via admission controllers at create/update time.
Service Account
Pod identity for API access; bind to narrowly-scoped Roles to limit impact of a compromise.
Container Image Security
Scan, use trusted registries, sign images, and enforce policies to prevent untrusted images from running.
Final takeaway
Security is layered: protect the control plane, enforce least privilege, segment networks, secure secrets and images, and instrument logging and response.
