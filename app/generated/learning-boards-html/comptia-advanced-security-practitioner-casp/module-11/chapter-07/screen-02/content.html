Module 11 › Chapter 11.7 › Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Secure control plane & nodes
Identify vulnerabilities in the API server, etcd, kubelet, and runtime, and apply targeted mitigations to reduce the cluster attack surface.
Mnemonic: layered boxes (control plane → nodes → workloads)
VERIFIED COMPETENCY MILESTONE
02
Implement RBAC least privilege
Define Roles and RoleBindings that limit actions to what a service account or user actually needs; avoid cluster-admin elevation.
Mnemonic: lock icon + scope ring
VERIFIED COMPETENCY MILESTONE
03
Design Network Policies
Create selectors, ingress and egress rules so pods communicate only with approved peers and services, reducing lateral movement.
Mnemonic: small segmented network diagram
VERIFIED COMPETENCY MILESTONE
04
Enforce Pod Security Standards
Apply PSS levels and admission controllers to prevent running as root, privileged containers, or dangerous host mounts.
Mnemonic: shield with three levels
VERIFIED COMPETENCY MILESTONE
