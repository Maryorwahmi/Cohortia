Module 11 › Chapter 11.1 › Key Concepts
Public Cloud

Third-party shared infrastructure. Provider manages physical security; customer controls identity and configuration.

Private Cloud

Dedicated infrastructure for a single organization. Offers control but requires full operational security efforts.

Hybrid & Multi-Cloud

Hybrid mixes private and public with secure links and policy parity. Multi-cloud uses multiple public providers to diversify but requires unified governance.

Takeaway

Select deployment models by matching control requirements to operational capacity, and enforce consistent security across chosen environments.
