Module 11 › Chapter 11.1 › FaaS (Serverless)
What FaaS provides

Event-driven, ephemeral execution of small units of code where the provider manages provisioning and scaling of runtime environments.

Security priorities
  • Least-privilege IAM per function.
  • Secure API gateway and input validation.
  • Dependency scanning and code review pipelines.
Example

A function triggered by object storage events that transforms uploaded files and pushes sanitized results to a managed database with narrowly scoped permissions.

Common risks
  • Overly broad function permissions leading to privilege escalation.
  • Insufficient input validation allowing injection attacks.
  • Lack of runtime visibility for ephemeral executions.
Mitigations

Adopt CI pipelines with static analysis, grant minimal IAM rights, use short-lived credentials, and centralize logs and metrics for anomaly detection.

Key Takeaway

FaaS simplifies scaling but shifts security toward developers: secure code, manage dependencies, and apply least privilege consistently.
