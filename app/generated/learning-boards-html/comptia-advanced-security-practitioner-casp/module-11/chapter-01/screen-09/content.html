What PaaS provides

A managed platform for building and running applications without managing OS and middleware. Typical features include runtimes, managed databases, and deployment services.

Security focus
  • Application code security and dependency management.
  • Platform configuration and role-based access controls.
  • Use of managed secrets and encryption features.
Practical guidance
  • Integrate code scanning and dependency checks into CI/CD.
  • Use provider-managed key stores for secrets and keys.
  • Enable platform WAFs and runtime monitoring where available.
Example

Hosting a customer portal on a PaaS where you secure the application code and the provider secures the runtime and OS.

Key Takeaway

PaaS simplifies infrastructure management but shifts the security boundary to the application and platform configuration; treat code as your primary responsibility.
