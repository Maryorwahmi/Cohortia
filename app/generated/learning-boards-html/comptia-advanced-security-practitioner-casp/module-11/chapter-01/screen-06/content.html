Module 11 › Chapter 11.1 › Hybrid Cloud
Definition

A hybrid environment connects private and public cloud infrastructures to enable portability of data and applications while keeping each domain unique.

Connectivity patterns
  • Site-to-site VPN for encrypted tunnels.
  • Direct connect / ExpressRoute for high-bandwidth, low-latency links.
  • API gateways and secure proxies for bounded interactions.
Scenario

Keep sensitive databases on private infrastructure and host the public portal in a public PaaS. Use an API gateway with authentication and TLS to mediate traffic.

Security challenges
  • Policy drift between environments reduces visibility.
  • Different IAM models complicate consistent access control.
  • Data sovereignty concerns as data moves across boundaries.
Mitigations

Centralize logging, adopt federated identity, standardize encryption and key management, and implement API gateways to enforce uniform controls.

Key Takeaway

Achieve policy parity and secure connectivity to reduce risk when workloads cross private and public boundaries.
