What IaaS provides

Virtual machines, storage, and virtual networks where the provider manages physical infrastructure but the customer manages OS and above.

Customer responsibilities
  • OS hardening and patch management.
  • Application security and data protection.
  • Virtual network configuration and firewalls.
Example

Moving a web application to cloud VMs: configure host firewalls, disable unused services, and automate OS patching.

Security checklist
  • Automate patching with immutable images or configuration management.
  • Restrict administrative access via bastion hosts and MFA.
  • Ship host logs to a centralized SIEM for detection.
Key Takeaway

IaaS gives flexibility and control but requires strong operational security practices to prevent exposure from unpatched or misconfigured systems.
