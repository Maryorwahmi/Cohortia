What SaaS provides

Fully managed applications accessible over the internet. Provider handles infrastructure, runtime, and application maintenance.

Customer focus areas
  • Strong identity and access controls (MFA, provisioning).
  • Data classification and loss prevention.
  • Vendor risk assessments and contractual protections.
Practical controls
  • Enforce MFA and least privilege for administrative roles.
  • Configure DLP rules and monitor file export activity.
  • Audit third-party integrations and API access tokens.
Example

Using a hosted collaboration suite: enable conditional access, limit external sharing, and set retention and DLP policies for sensitive data.

Key Takeaway

SaaS reduces infrastructure work but requires disciplined identity governance, data controls, and vendor risk management to remain secure.
