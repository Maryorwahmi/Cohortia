Module 11 › Chapter 11.1 › Public Cloud
Definition

A public cloud provides shared compute, storage, and network services operated by a third-party provider. Tenants are logically isolated but share the underlying physical infrastructure.

Security implications
  • Provider secures physical hosts and platform services.
  • Customer must manage IAM, network controls, and data protection.
  • Monitoring and configuration management are essential to detect misconfigurations.
Example

Hosting a customer portal on a public PaaS while storing sensitive records in an encrypted managed database.

Common mistake

Granting overly broad IAM roles or leaving network security group rules permissive.

Key Takeaway

Public cloud gives strong platform security; your focus must be on identity, network isolation, encryption, and continuous posture checks.

Practical checklist
  • Enable MFA and least-privilege IAM policies.
  • Use network security groups and private subnets for sensitive services.
  • Encrypt data at rest and in transit using provider-managed or customer keys.
  • Centralize logs and enable alerting for anomalous access.
  • Automate configuration scans and remediate drift immediately.
Why this matters

Even with a hardened provider platform, tenant misconfiguration is the leading cause of cloud exposure. Proper controls keep the isolation promise intact.
