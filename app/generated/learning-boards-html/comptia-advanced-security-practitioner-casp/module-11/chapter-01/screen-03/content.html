Module 11 › Chapter 11.1 › Learning Objectives
Assessment Task

Map a monolithic application into a hybrid architecture, proposing cloud placements and secure connectivity. Explain compliance and control decisions.

Deliverable

Component mapping table and secure connectivity plan.

Success

Clear justification for placement, and concrete mitigations for risks.

Common pitfalls to avoid
  • Over-permissioned identities and service roles.
  • Assuming the provider secures application logic or data by default.
  • Inconsistent encryption or network controls across clouds.
Rubric highlights
  1. Correct mapping of sensitivity to model.
  2. Clear secure connectivity design.
  3. Identification of realistic mitigation strategies.
