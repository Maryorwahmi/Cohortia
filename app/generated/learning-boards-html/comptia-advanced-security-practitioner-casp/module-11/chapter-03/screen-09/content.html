Linux hardening snippet
# Disable password authentication for SSH
sudo sed -i 's/#PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config
# Disable root login
sudo sed -i 's/#PermitRootLogin prohibit-password/PermitRootLogin no/' /etc/ssh/sshd_config
# Restart SSH
sudo systemctl restart sshd
# Ensure firewalld is enabled
sudo systemctl enable firewalld --now
sudo firewall-cmd --permanent --add-service=ssh
sudo firewall-cmd --reload
Insert this into your image build or configuration management system rather than running interactively on production instances.
S3 bucket policy snippet
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "DenyInsecureTransport",
      "Effect": "Deny",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::your-sensitive-bucket/*",
      "Condition": { "Bool": { "aws:SecureTransport": "false" } }
    }
  ]
}
Replace the bucket ARN and combine this with a block-public-access setting to prevent accidental exposure.
