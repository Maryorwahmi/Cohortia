Public → App → Database
Three-tier CIDR template
Example starting point for a secure deployment. Expand across AZs for high availability.
Subnet Name CIDR Type
Public Subnet 110.0.1.0/24Public (web tier)
Private App Subnet 110.0.2.0/24Private (app tier)
Private DB Subnet 110.0.3.0/24Private (datastore, no internet)
Use an Internet Gateway for public subnets and NAT Gateway(s) for private subnets that need outbound internet access for updates. Keep databases in subnets without an IGW attachment and restrict inbound traffic via security groups.
Checklist
  • Pick a VPC CIDR large enough for current and planned subnets.
  • Create public and private subnets per AZ for redundancy.
  • Deploy NAT Gateways for safe outbound-only connectivity.
  • Restrict database subnet access via security groups only from app tier.
Key Takeaway

Design subnets to separate exposure and reduce lateral movement. Test changes in non-production first to avoid outages.
