Definition • Storage
Object • Block • File
Object Storage
Used for unstructured data and accessed via APIs. Ensure default server-side encryption and strict bucket policies to prevent public exposure.
Block Storage
Attached to instances as raw volumes. Use provider-managed encryption for volumes and enforce OS-level file permissions.
File Storage
Shared file systems presented via NFS/SMB. Control access through network controls, mount options, and file-level permissions.
Encryption at rest: enable default encryption (KMS-managed or provider-managed).
Encryption in transit: enforce TLS endpoints and authenticated client connections.
Mistake to avoid: encrypted data with public access or overly permissive ACLs.
Key Takeaway

Encryption protects confidentiality but must be combined with access controls; enforce both at creation and in policy.
