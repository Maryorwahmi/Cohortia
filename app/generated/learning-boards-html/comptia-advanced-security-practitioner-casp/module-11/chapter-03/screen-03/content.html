Focus: operate, detect, recover
Enable monitoring and logging
Forward OS and application logs to cloud logging services, use HIDS or EDR, and keep central alerts for suspicious activity.
Mnemonic: collect, alert, investigate.
VERIFIED COMPETENCY MILESTONE
Apply least privilege everywhere
Use roles, instance profiles, and scoped IAM policies so services get only the permissions they need to operate.
Mnemonic: give minimal rights, review regularly.
VERIFIED COMPETENCY MILESTONE
Audit and remediate common misconfigurations
  • Check for public object storage and block public access at account and bucket levels.
  • Review security groups for wide CIDR ranges and remove unnecessary rules.
  • Ensure default encryption is enabled and keys are managed via KMS where possible.
