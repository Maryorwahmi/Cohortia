Module 11 › Chapter 11.3 › Learning Objectives
Learn → Understand → Apply → Master
01
Harden compute resources
Select hardened images, disable services, configure key-based auth and secure remote access. This reduces the attack surface of instances and prevents easy footholds.
Mnemonic: reduce installed surface area → fewer exploitable components.
VERIFIED COMPETENCY MILESTONE
02
Manage patches and updates
Implement automated patching and test updates in staging. Timely patches correct known vulnerabilities before attackers exploit them.
Mnemonic: test → stage → deploy.
VERIFIED COMPETENCY MILESTONE
03
Protect storage with encryption
Enforce default encryption at rest, use TLS for transit, and enable versioning to recover from accidental or malicious deletions.
Mnemonic: always encrypted, both at rest and in flight.
VERIFIED COMPETENCY MILESTONE
04
Design secure networks
Use VPCs, public/private subnets, security groups, NACLs, and NATs to control traffic flows and minimize exposure of sensitive tiers.
Mnemonic: separate tiers, limit flows, log traffic.
VERIFIED COMPETENCY MILESTONE
