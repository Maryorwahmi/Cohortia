Comparison • Network Controls
Security Groups • NACLs • Gateways
Security Groups (stateful)
Applied to instances, automatically allow return traffic. Best for fine-grained, instance-level rules like limiting SSH to admin CIDR or allowing web traffic from load balancer security groups.
Tip: use security group references (allow traffic from another SG) instead of broad CIDR ranges when possible.
Network ACLs (stateless)
Applied at the subnet level, require explicit inbound and outbound rules. Useful as an additional coarse layer of defense or to block ranges across a subnet.
Caution: because they are stateless, you must add both directions for expected flows.
Internet Gateway: provides internet access for public subnets.
NAT Gateway: allows private subnets to initiate outbound internet connections while blocking inbound.
VPC Endpoint: private connectivity to supported services without internet routing.
Key Takeaway

Use security groups for fine-grain controls, NACLs for subnet-level defense, and NATs for safe outbound access. Test rules to avoid accidental outages.
