Architecture • Segmentation
Zones • Micro-segmentation
Strategy
Start with separate VPCs or subnets for environments and tiers. Use security groups and host firewalls for micro-segmentation. Apply least privilege on both network and identity layers.
Zone example: Prod VPC, Dev VPC, Test VPC
Tier example: Public web subnets, private app subnets, restricted DB subnets
Micro rule: DB SG allows traffic only from App SG on DB port
Host controls: host firewalls or EDR to restrict inter-host flows
Practical checks
  • Verify SG-to-SG references instead of wide CIDRs.
  • Ensure private subnets do not have route to IGW.
  • Use flow logs to detect unexpected lateral traffic.
Key Takeaway

Segmentation and micro-segmentation limit attacker movement and make breaches containable. Implement and monitor both network and host controls.
