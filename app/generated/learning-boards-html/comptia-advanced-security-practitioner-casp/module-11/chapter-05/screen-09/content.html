Definition

Multi-Factor Authentication (MFA)

Require two or more verification factors to authenticate, especially for administrative and high-risk accounts.

Types
  • Virtual MFA apps or one-time codes
  • Hardware tokens or FIDO U2F devices
Policy enforcement example
{
  "Condition": {
    "Bool": {
      "aws:MultiFactorAuthPresent": "true"
    }
  }
}
Common mistake

Not enforcing MFA for privilege-bearing accounts or assuming password complexity alone is sufficient protection.

Key Takeaway

Enforce MFA for administrative and sensitive operations and test policy conditions to validate enforcement.
