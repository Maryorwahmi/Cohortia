Process

Secure programmatic access

  • Prefer roles/managed identities over static keys.
  • When using keys, store them in a secrets manager and rotate frequently.
  • Restrict keys with minimal permissions and remove unused keys immediately.
Concrete practice

Assign a managed identity to your compute resource and verify it can request an access token to call storage APIs without any keys present on disk.

CLI/Code checklist
Checklist
  • Remove hardcoded keys from repositories.
  • Use secret managers (e.g., Key Vault, Secrets Manager) for storage.
  • Rotate keys and deactivate unused credentials immediately.
Common mistake

Treating rotation as a substitute for eliminating static credentials; rotation helps but does not replace managed identities.

Key Takeaway

Remove keys where possible, prefer ephemeral credentials, and protect any remaining keys with vaults and rotation schedules.
