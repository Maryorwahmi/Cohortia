Learning Objectives

Bloom: Learn → Understand → Apply → Master
01
Design federated identity and SSO
Develop federation flows using SAML or OIDC so corporate credentials grant access to cloud services without separate cloud accounts. This reduces account sprawl and enforces central policies.
Mnemonic: Single passport
VERIFIED COMPETENCY MILESTONE
02
Apply least privilege to users, groups, and roles
Author policies with granular actions and resource ARNs, and use conditions like tags or IP restrictions to narrow access to only what's required for tasks.
Mnemonic: Smallest key
VERIFIED COMPETENCY MILESTONE
03
Configure MFA for privileged accounts
Mandate multi-factor authentication for administrative logins and sensitive actions to significantly reduce credential compromise risks.
Mnemonic: Two locks
VERIFIED COMPETENCY MILESTONE
04
Secure programmatic access and audit IAM activity
Use roles or managed identities for services, rotate API keys when necessary, and enable audit logs to detect anomalous IAM actions.
Mnemonic: Keys rotate
VERIFIED COMPETENCY MILESTONE
