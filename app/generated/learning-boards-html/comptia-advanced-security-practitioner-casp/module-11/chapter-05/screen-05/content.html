Definition

Federated Identity & SSO

Allow users to authenticate with their corporate IdP and access multiple cloud services without separate accounts for each cloud provider.

SAML 2.0
XML-based assertions often used for enterprise cloud and SaaS integrations.
OIDC
JSON/RESTful identity layer on OAuth 2.0, well suited for modern web and mobile clients.
Benefits
  • Centralized identity management and MFA enforcement.
  • Improved user experience with single sign-on.
  • Reduced account management overhead and shadow IT.
SAML federation flow (concrete example)
  1. User requests cloud console access and is redirected to corporate IdP.
  2. User authenticates with corporate credentials and MFA as required.
  3. IdP issues a SAML assertion and returns it through the browser to the cloud provider.
  4. Cloud provider maps assertion attributes to an IAM role and issues temporary credentials.
Common misconception

SSO is not merely convenience; it centralizes policy enforcement, reduces credential duplication, and strengthens MFA coverage.

Key Takeaway

Choose the protocol that fits your apps: SAML for enterprise apps, OIDC for modern clients, and ensure IdP-to-role mapping supports group attributes.
