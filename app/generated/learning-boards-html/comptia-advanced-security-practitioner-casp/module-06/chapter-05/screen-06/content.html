Module 06 › Chapter 6.5 › EDR Hunting
EDR capabilities
Process creation, parent-child relationships, command-line capture, module loads, network sockets, and memory access events.
Supporting bullets:
  • Pivot from SIEM alerts to endpoint timelines to validate sequences.
  • Look for LOLBINs spawned with unusual arguments or encoded payloads.
  • Prioritize hosts with anomalous behavior flagged by behavioral analytics.
Concrete Example
Search for events where winword.exe spawned powershell.exe; this pattern often indicates a malicious document executing a script.
Key Takeaway

EDR is the source of truth for endpoint behavior. Ensure its collection settings align with your hunting questions.

EDR Query (conceptual)
PROCESS_CREATE where ParentProcessName = "winword.exe" and ProcessName = "powershell.exe"
| select _time, host_name, process_name, parent_process_name, command_line, user
This conceptual query locates instances of a document spawning a shell and returns the command line and user context for investigation.
Misconception
Assuming EDR always retains long timelines by default. Retention and telemetry level are configurable and may be limited.
