Module 06 › Chapter 6.5 › Refining Queries
Refinement Steps
  1. Validate required fields exist in your data sources.
  2. Limit time windows to the smallest period that tests your hypothesis.
  3. Enrich with lookups (geoip, asset tags) to add context.
  4. Aggregate to surface rare occurrences and sort by frequency.
  5. Iterate and test on historical data to measure false positives.
Common Mistake
Using overly broad rules that flood analysts with low-value alerts. Narrow and enrich instead.
Key Takeaway

Good hunting is iterative: refine queries until they return a manageable, high-value set of leads.

Example: Missing Command-Line
If command-line fields are missing, add endpoint collection checks to your operational backlog before trusting process-based detections.
Check list to fix blind spots:
  • Confirm agent configuration for command-line capture.
  • Validate SIEM parsers extract these fields consistently.
  • Adjust retention to keep evidence for your investigation window.
Pro Tip
Run small, controlled tests where you execute a known chain and verify logs across SIEM, EDR, and network tools to ensure end-to-end visibility.
