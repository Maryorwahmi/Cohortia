Module 06 › Chapter 6.5 › Key Concepts
SIEM
Centralized log aggregation for correlation, historical queries, and visual analysis.
EDR
Endpoint telemetry for process behavior, memory events, and pivotable investigations.
Network Analysis
Packet, parsed logs, and flow metadata used to confirm communications and exfiltration.
Summary

Combine SIEM, EDR, and network telemetry to move from anomaly to evidence with confidence.
