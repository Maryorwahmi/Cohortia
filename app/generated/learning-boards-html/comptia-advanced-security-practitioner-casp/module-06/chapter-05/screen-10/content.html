Module 06 › Chapter 6.5 › Lateral Movement Scenario
Scenario
Alert: svc_web_app logged into DB_PROD_01 at 03:00. Normally this account only accesses WEB_APP_01.
Investigative steps:
  1. Run a SIEM query for other logins by svc_web_app in the last 24 hours.
  2. If WEB_APP_01 is the src_host, pivot to EDR on WEB_APP_01 for process creation between 02:50 and 03:10.
  3. Look for suspicious parents or LOLBIN usage and capture command-line details.
Expected Outputs
SIEM: _time, user, src_host, dest_host, event_id. EDR: _time, process_name, command_line, parent_process_name, user.
Check Your Understanding

If EDR shows powershell started by winword on WEB_APP_01 near 3 AM, what would you investigate next? (Hint: credential dumping and network pivots.)

SIEM Query (conceptual)
index=windows_events event_id=4624 user="svc_web_app" dest_host!="WEB_APP_01" _time > relative_time(now(), "-24h")
| table _time, user, src_host, dest_host, event_id
EDR Query (conceptual)
// Conceptual EDR query
host_name="WEB_APP_01" AND event_time BETWEEN "2023-10-26T02:50:00Z" AND "2023-10-26T03:10:00Z" AND
(
  process_name IN ("powershell.exe", "cmd.exe", "wmic.exe", "psexec.exe") OR
  command_line CONTAINS "Invoke-Mimikatz" OR
  command_line CONTAINS "net user"
)
| select event_time, process_name, command_line, parent_process_name, user
Run the SIEM query to map scope, then the EDR query to inspect the suspected source host for process activity and command lines.
