Module 06 › Chapter 6.5 › Network Tools
tcpdump / Wireshark
Full packet capture for payload inspection, protocol decoding, and identifying C2 signatures.
Use when you need to validate payload contents or detect covert channels.
Zeek (Bro)
Parses packets into high-fidelity logs: DNS, HTTP, connections, and file transfers for behavioral hunting.
Use for scalable behavioral searches and forensics without storing full packets.
NetFlow / IPFIX
Lightweight flow metadata for spotting unusual volumes, destinations, and long-lived conversations.
Use to triage and identify hosts needing deeper capture or Zeek parsing.
Example Filter
http.request.method == "POST" and http.request.uri contains "upload"
A Wireshark display filter to look for potential data upload behavior in HTTP traffic.
Key Takeaway

Combine flows, parsed logs, and packets: each layer narrows hypotheses until you can confirm or rule out malicious activity.
