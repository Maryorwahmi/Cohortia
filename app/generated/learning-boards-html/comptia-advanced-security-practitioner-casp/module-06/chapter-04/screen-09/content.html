Module 6 › Chapter 6.4 › Hands-on Hypotheses: PowerShell Empire
Definition

Build and test three hypotheses

Hypothesis 1
TTP: Encoded PowerShell execution. Data: EDR process events, SIEM command_line. Query: search for powershell with '-EncodedCommand' or very long command lines in recent 48 hours.
Hypothesis 2
TTP: Unusual scheduled task creation for persistence. Data: EDR task events, Windows TaskScheduler logs. Query: list task create events from non-admin workstations in last 7 days.
Hypothesis 3
TTP: Lateral movement using legitimate admin tools. Data: authentication logs, EDR connections, remote execution events. Query: correlate unusual admin tool use from workstations to multiple servers within short time windows.
Follow-up
For validated hits, collect process ancestry, created files, scheduled tasks, and network connections. This maps scope and informs containment.
Safety note
Ensure hunts do not alter production state or disrupt users. Use read-only queries and coordinate sensitive investigations with ops and legal teams.
Key Takeaway

Translate intelligence into testable hypotheses, verify telemetry availability, and document follow-up actions for any confirmed findings.
