Module 6 › Chapter 6.4 › Telemetry and Data Sources for Hunting
Definition

What telemetry matters and why

Primary sources
  • EDR: process creation, parent-child chains, command lines, and file activities.
  • SIEM: aggregated event logs, authentication events, and cross-host correlation.
  • Network logs: proxy/dns/flow data for external communication and large transfers.
  • Endpoint forensics: registry keys, scheduled tasks, and persistence artifacts.
Practical mapping
Before each hunt, list which logs you need and verify retention and field availability. This prevents wasted queries and false negatives.
Visibility checks
Ask: Are command-line arguments logged? Do network logs include DNS entries? Is EDR parent process data captured? If not, adjust hypotheses or instrumentation.
Common mistake
Hunting without checking telemetry availability leads to false negatives and wasted time. Always validate data before running broad queries.
Key Takeaway

Map each hypothesis to specific telemetry and verify field-level visibility before hunting to get reliable results.
