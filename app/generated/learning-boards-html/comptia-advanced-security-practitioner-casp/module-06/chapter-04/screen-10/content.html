Module 6 › Chapter 6.4 › Behavioral Hunting and Anomaly Detection
Process Flow

Use baselines to expose novel techniques

How to build behavioral hunts
  1. Choose measurable behavior features: process chains, login sources, data transfer sizes.
  2. Create baselines using historical data and define alerting thresholds or anomaly models.
  3. Run anomaly detection and validate results with contextual checks to reduce false positives.
  4. When validated, capture comprehensive telemetry for response and enrichment.
Examples of behavioral indicators
  • Unusual parent-child process chains such as svchost → powershell encoded commands.
  • Non-admin workstations initiating administrative remote commands to many servers.
  • Large data staging in temporary directories preceding an external transfer.
Pro tip
Start behavioral hunts with targeted features to limit false positives and iterate models with human feedback.
Misconception
Not every anomaly is malicious; contextual validation is required before escalation.
Key Takeaway

Behavioral hunts surface unknown techniques. Prioritize contextual validation and collect surrounding telemetry for confident triage.
