Process

Examples of focused hunt queries

Design tips
  • Identify required fields before querying: command_line, process_name, parent_process, source_ip, event_id.
  • Scope by time and hosts to reduce noise and validate hits quickly.
  • Iterate: narrow, confirm, then expand as needed across retention windows.
Misconception
Long, broad queries create noise and overload systems. Start focused and expand only after validation.
Concrete query examples
-- Conceptual SIEM query for encoded PowerShell
search event_id=4688 AND process_name="powershell.exe"
| where command_line like "%-EncodedCommand%"
| stats count by host, _time, command_line
-- Conceptual EDR query for scheduled task creation
SELECT timestamp, host, user, task_name
FROM edr_task_events
WHERE action = "create" AND task_name LIKE "%update%" AND timestamp > now() - 7d
Key Takeaway

Make queries explicit and scoped, document rationale and results, and capture related events to build investigation context.
