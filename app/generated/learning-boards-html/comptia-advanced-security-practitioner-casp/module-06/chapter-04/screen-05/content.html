Process Flow

Iterative steps that produce detections

Step-by-step loop
  1. Formulate hypothesis — use threat intelligence or anomalies to define a measurable claim.
  2. Investigate / collect data — query SIEM, EDR, network logs, and endpoint forensics.
  3. Analyze — find patterns or anomalies using tools and manual inspection.
  4. Uncover or refine — if you find a threat, escalate; if not, refine and iterate.
  5. Enrich and automate — add IoCs, build detection rules, and update playbooks.
Supporting notes
  • Document each hunt, including negative results; they inform future hypotheses.
  • Data fidelity matters: missing command-line logging limits detection capability.
  • Automation should codify successful queries into alerts, but avoid noisy rules.
Example
Hypothesis: encoded PowerShell used for lateral movement. Data: EDR process creation events and SIEM command-line logs. Outcome: refine or escalate.
Key Takeaway

Treat hunting as a loop: each iteration improves detection and reduces dwell time.
