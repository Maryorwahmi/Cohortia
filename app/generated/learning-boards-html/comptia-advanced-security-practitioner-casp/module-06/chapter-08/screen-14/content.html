# WEB_PROD_01 post-incident checklist
1) Eradication
  - Search and remove web shell variants in web directories
  - Check scheduled tasks, services, and startup items
  - Enumerate and remove suspicious accounts and revoke keys
  - Collect forensic artifacts and timestamps
2) Recovery
  - Verify backup snapshot ID and integrity prior to restore
  - Restore to isolated staging VLAN and run full scans
  - Harden server (MFA, least privilege, close ports)
3) Post-Incident
  - Run lessons learned and produce incident report
  - Update patch policy for web apps and assign remediation owners
  - Perform cost analysis and legal/PR review
Use this template to populate evidence fields and assign owners. The restored image must pass scans and monitoring before reintroduction.
Suggested answers (examples)
  • Eradication steps: search web directories, remove scheduled tasks, revoke tokens, rotate service credentials.
  • Lessons learned questions: Why was the web app unpatched? Were detection and patching processes effective? Was communication timely?
  • Control improvements: enforce automated patching for web apps, deploy web app firewall rules, require periodic backups validated for integrity.
Reflection
Assign clear owners and deadlines for each remediation item and track them until verified complete.
