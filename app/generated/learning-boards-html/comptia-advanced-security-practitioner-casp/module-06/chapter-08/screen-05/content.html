Module 7 › Chapter 6.8 › Eradication & RCA
Definition
Eradication and Root Cause Analysis
Eradication: remove threat artifacts and persistence. RCA: identify the underlying vulnerability or process failure that enabled the incident.
Analogy
Eradication is like removing every root and seed after pulling a weed; RCA is asking how the seeds got into the soil so they don't regrow.
Practical checklist
  • Collect forensic snapshots and logs before destructive actions.
  • Search for persistence: startup items, scheduled tasks, services, web shells, backdoor binaries.
  • Locate and remove malicious accounts and remote access tools.
  • Patch vulnerabilities and apply configuration fixes identified by RCA.
  • Document each removal with artifacts and timestamps for audit.
Common misconception
Deleting a visible malicious file often misses persistence and lateral copies; always pair deletion with forensic search and RCA.
