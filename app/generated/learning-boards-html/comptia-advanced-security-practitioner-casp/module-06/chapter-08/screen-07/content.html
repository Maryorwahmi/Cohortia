Detection vs Removal
Detection
  • Unexpected accounts or privilege changes
  • Web directory anomalies and unknown scripts
  • New scheduled tasks or services
Removal
  • Rotate affected credentials first
  • Delete accounts and revoke keys/tokens
  • Remove web shells and close remote consoles
Practical example
An attacker created a service account and stored SSH keys on several hosts. Response: list all accounts created recently, rotate service passwords and SSH keys, remove keys from authorized lists, and revoke tokens from central identity provider. Document the revocations and monitor for login attempts with the deleted identity.
Common mistake
Assuming account deletion at one directory service removes tokens or keys held elsewhere. Always search identity stores and endpoints for shadow artifacts.
