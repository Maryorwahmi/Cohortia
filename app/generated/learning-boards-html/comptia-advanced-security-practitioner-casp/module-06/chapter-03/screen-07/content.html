Module 6 › Chapter 6.3 › Data Enrichment
Definition

Enrich indicators with context

Enrichment supplies WHOIS, GeoIP, historical sightings, TTPs, and other context that make indicators actionable.

Common enrichments
  • WHOIS and ownership
  • GeoIP and ASN
  • Malware family or TTP links
Operational rules
Cache results for performance, log provenance, and chain enrichments in a predictable order.
Quality checks
Monitor freshness and source reputation; stale or noisy enrichment can distort scoring.
Example
An IP enriched with WHOIS showing registration to a bulletproof hoster and linked to past ransomware C2s will get higher operational priority.
Misconception
Enrichment is not a single API call; it's a pipeline that must be ordered and validated to avoid misleading context.
Key Takeaway

Enrichment is the difference between a raw IoC and an intelligence object that an analyst or automation can act upon with confidence.
