Module 6 › Chapter 6.3 › Data Normalization
Definition

Normalization and canonicalization

Make disparate inputs comparable by mapping them into a consistent internal schema.

Normalization tasks
  • Field mapping and renaming
  • Value canonicalization (IP formats, hash case)
  • Timezone and timestamp alignment
  • Deduplication and merging metadata
Why it matters
Normalization lets the TIP correlate observations from feeds and telemetry, enabling detection of campaigns and reducing missed links between indicators.
Example
A feed labels an IP as 'src_ip' while another uses 'address'. Normalization maps both to the internal 'ip' field so correlation matches them.
Misconception
Normalization is not purely cosmetic. Poor mapping can remove context or produce false merges, so mappings must be reviewed and logged.
Key Takeaway

Reliable normalization is the foundation that makes enrichment, correlation, and scoring accurate across all sources.
