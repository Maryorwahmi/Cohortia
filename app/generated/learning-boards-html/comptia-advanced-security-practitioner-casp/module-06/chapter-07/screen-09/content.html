Module 6 › Chapter 6.7 › Analysis: triage, scoping, severity
Three-step analysis

Triage → Scoping → Severity

Work quickly but thoroughly: triage to confirm, scope to measure reach, and assess severity by business impact across confidentiality, integrity, and availability.

Triage
Confirm true incident, identify affected asset, and choose immediate next steps.
Scoping
Identify all affected hosts, accounts, and potential data exposure windows.
Severity
Assign Critical/High/Medium/Low based on CIA impact and business operations.
Misconception

Scope size does not equal severity; a narrow compromise of a critical system can be more severe than a widespread low-risk anomaly.

Scenario
Database server communicating with a known C2 IP. Triage confirms unusual outbound flows, scoping checks other database instances, and severity is set to Critical due to sensitive data exposure.
Documentation
  • Alert source and timestamps
  • Correlated logs used for scoping
  • Preliminary severity and justification
Key Takeaway

Structure analysis into triage, scoping, and severity so decisions are traceable and prioritized.
