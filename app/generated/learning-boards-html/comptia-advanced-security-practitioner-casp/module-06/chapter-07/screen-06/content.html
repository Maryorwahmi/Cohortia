Module 6 › Chapter 6.7 › IDS and IPS: network-level detection
Core idea

Signature and anomaly detection on the network

IDS detects and logs suspicious traffic; IPS can block it. Signatures catch known patterns; anomaly detection reveals new or stealthy behaviors but needs tuning.

When it helps
Spot lateral movement, C2 channels, or abnormal data flows that endpoints may not surface immediately.
Action
Collect packet captures and netflow for the alert window and synchronize timestamps across systems for cross-correlation.
Misconception

A network alert alone rarely proves cause; pair it with endpoint artifacts to identify root cause and scope.

Concrete example
Frequent, patterned DNS queries from a server may be a DNS command channel. Capture DNS query logs, packet data, and correlate with the endpoint process that initiated DNS requests.
Checklist
  • Save pcap for alert window
  • Export related netflow records
  • Sync timestamps with SIEM and EDR
Key takeaway
Network sensors reveal movement that endpoints can miss; use both to scope incidents correctly.
