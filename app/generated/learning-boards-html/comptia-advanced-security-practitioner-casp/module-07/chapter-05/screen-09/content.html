Module 7 › Chapter 7.5 › Log Analysis
Key fields to parse
  • CloudTrail: eventName, userIdentity, sourceIPAddress, eventTime, requestParameters
  • VPC Flow Logs: srcAddr, dstAddr, srcPort, dstPort, bytes, action
  • Azure Activity Logs: operationName, caller, status
Example sequence
CreateUser → AssumeRole → DeleteSnapshot. Correlate timings and identities to assess intent and scope.
Analyst checklist
  1. Identify sensitive API calls and unusual source IPs.
  2. Search VPC Flow Logs for new instances making outbound connections.
  3. Check CSPM/CASB for concurrent configuration or data access anomalies.
  4. Enrich events with asset and identity data in the SIEM.
Misconception
Relying on single-source alerts creates blind spots. Correlation across logs reveals multi-stage attacks.
