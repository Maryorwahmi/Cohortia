Module 7 › Chapter 7.5 › RunInstances Detection
Sequence of investigation
  1. Alert: metric filter detects RunInstances from unfamiliar IP.
  2. Query CloudTrail for the API call, userIdentity, and sourceIPAddress.
  3. Match new instance IDs and query VPC Flow Logs for outbound connections.
  4. Check GuardDuty/Defender findings and CSPM for missing agents or insecure configs.
Decision criteria
Escalate if you have at least two signals: unusual API call plus unexpected outbound flows or a posture gap. If only one signal exists, continue investigation and enrich events in the SIEM.
Analyst tip
Enrich events with account and template metadata to quickly determine if the instance was expected (autoscaling tags) or suspicious.
Why this works
Combining API, network, and posture signals raises confidence in detections and reduces analyst time spent chasing false positives.
