1) CloudTrail configuration (summary)
Enable a multi-region trail, include management events, and enable data events for the S3 buckets that store sensitive objects. Deliver logs to a dedicated bucket with SSE enabled and enable log file validation.
Illustrative trail JSON
{
  "Name": "cloudguard-trail",
  "IsMultiRegionTrail": true,
  "IncludeGlobalServiceEvents": true,
  "S3BucketName": "cloudguard-cloudtrail-logs-1234567890"
}
2) S3 bucket policy for CloudTrail
This policy allows the CloudTrail service to write logs and denies uploads that are not encrypted.
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AWSCloudTrailAclCheck",
      "Effect": "Allow",
      "Principal": {"Service": "cloudtrail.amazonaws.com"},
      "Action": "s3:GetBucketAcl",
      "Resource": "arn:aws:s3:::cloudguard-cloudtrail-logs-1234567890"
    },
    {
      "Sid": "AWSCloudTrailWrite",
      "Effect": "Allow",
      "Principal": {"Service": "cloudtrail.amazonaws.com"},
      "Action": "s3:PutObject",
      "Resource": "arn:aws:s3:::cloudguard-cloudtrail-logs-1234567890/AWSLogs/1234567890/*",
      "Condition": {"StringEquals": {"s3:x-amz-acl": "bucket-owner-full-control"}}
    },
    {
      "Sid": "DenyUnencryptedObjectUploads",
      "Effect": "Deny",
      "Principal": "*",
      "Action": "s3:PutObject",
      "Resource": "arn:aws:s3:::cloudguard-cloudtrail-logs-1234567890/*",
      "Condition": {"StringNotEquals": {"s3:x-amz-server-side-encryption": "AES256"}}
    }
  ]
}
3) CloudWatch metric filter and alarm (summary)
Create a metric filter on the CloudTrail log group that matches IAM policy creation or deletion events and produce a metric named IAMPolicyModification. Use a CloudWatch Alarm to alert on a value >=1 within a 5-minute period to get near real-time notification.
{
  "FilterPattern": "{ ($.eventName = \"DeleteRolePolicy\") || ($.eventName = \"DeleteUserPolicy\") || ($.eventName = \"PutUserPolicy\") }",
  "MetricName": "IAMPolicyModification",
  "MetricNamespace": "CloudGuard/Alerts",
  "MetricValue": "1"
}
Test your filter using sample CloudTrail events to validate matches and reduce false positives.
