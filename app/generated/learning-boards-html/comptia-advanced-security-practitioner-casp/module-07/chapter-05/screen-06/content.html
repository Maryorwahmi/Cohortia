Module 7 › Chapter 7.5 › Enable & Store
Step-by-step enablement
  1. Inventory required log types: API, data events, network flows, orchestration/audit logs.
  2. Enable CloudTrail / Activity Logs / Cloud Audit Logs and enable data events where needed.
  3. Send logs to an encrypted, dedicated storage location with restricted write/read permissions.
  4. Forward to a log collector or SIEM for normalization and correlation.
Misconfiguration risk
Not enabling data events or forgetting a region can create blind spots. Use automation to ensure consistency.
Concrete Example
A robust setup will: enable CloudTrail for all regions, enable S3 data events for critical buckets, deliver logs to an SSE-KMS encrypted S3 bucket, and forward events to CloudWatch Logs for alarms and to your SIEM pipeline for correlation.
