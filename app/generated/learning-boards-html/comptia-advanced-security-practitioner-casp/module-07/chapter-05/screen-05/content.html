Module 7 › Chapter 7.5 › Provider Logs
AWS — Core Services
CloudTrail
API and management events; enable data events for S3 to capture object-level activity.
VPC Flow Logs
Network traffic metadata between network interfaces; useful to spot unexpected outbound connections.
CloudWatch Logs & GuardDuty
Application logs, metrics, and intelligent threat findings derived from underlying logs.
Azure & GCP — Core Services
Azure Activity Logs
Subscription-level events for resource creation, deletion and control-plane changes.
Azure Monitor / Defender for Cloud
Metrics, logs, and posture/threat detection integrated into Defender for Cloud.
GCP Cloud Audit & Logging
Administrative and data access audit logs plus general logging managed by Cloud Logging.
Practical checklist
Enable required services
Secure storage with encryption and access controls
Forward to central pipeline for correlation
