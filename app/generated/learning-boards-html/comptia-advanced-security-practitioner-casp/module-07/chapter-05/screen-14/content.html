Module 7 › Chapter 7.5 › Key Concepts
Cloud-Native Logging
CloudTrail, Activity Logs, and Cloud Audit Logs are the primary sources of audit data; enable data events where needed.
CSPM & CASB
CSPM finds misconfigurations; CASB enforces SaaS access and DLP. Both produce alerts that should be centralized.
SIEM Integration
Secure, encrypted pipelines into a SIEM that normalizes and correlates events across cloud and on-premise sources.
Summary Takeaway

Enable the right logs, secure and centralize them, and correlate across signals to detect and respond to cloud threats effectively.
