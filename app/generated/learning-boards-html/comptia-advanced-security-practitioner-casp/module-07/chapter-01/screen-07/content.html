Correlation Rules: Simple vs Advanced
How rule complexity trades off precision and coverage.
Simple threshold rule
Trigger when failed logins > 10 in 5 minutes. Easy but noisy during automated tasks.
Advanced rule elements
  • Temporal windows: events tied within defined timespans.
  • Logical composition: AND, OR, NOT to chain event types.
  • Aggregation and profiling: counts, rates, and baselines.
  • Threat-intel enrichment: add context to increase confidence.
Example scenario
Failed logins (many), followed by successful login from unusual IP, followed by data access—correlate all within short windows and to the same user to raise high-severity alert.
Misconception: Tight rules always improve detection. In practice, overly narrow rules can miss variants of an attack.
Pro tip: Use baselining to set dynamic thresholds rather than fixed numbers.
