Design Exercise: GlobalTech SIEM Architecture
A structured template to propose collectors, indexers, data flow and a critical correlation rule.
Starter checklist
  • 1. Identify at least 5 on-premise and 5 AWS data sources.
  • 2. Propose placement of collectors, aggregators, indexers, and search heads.
  • 3. Describe the log flow: collect → parse → normalize → index.
  • 4. Draft one critical correlation rule to detect cross-boundary compromise.
Example answers (concise)
Key data sources: AD domain controllers, firewall logs, IDS alerts, Linux syslogs, EDR alerts; CloudTrail, VPC Flow Logs, GuardDuty, WAF, app logs.
Components: Forwarders at endpoints, regional aggregators, central indexer cluster, search head cluster, management server.
Data flow: Local collection → regional pre-parse and normalization → central indexing → correlation → SOAR trigger for response.
Correlation rule idea: Link failed AD logins to AWS console success for same user from unusual IP, then to security group modifications within 10 minutes.
Assessment tip: Validate parsing with real logs and replay history to tune rule windows and reduce false positives.
