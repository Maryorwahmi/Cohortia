Definition
Log Normalization
Map extracted fields to a common schema so multi-source correlation is reliable.
Normalization steps
  • Define a common information model with canonical field names.
  • Create mappings from source parsers to canonical fields.
  • Standardize value formats and data types.
  • Enrich with context (geo-IP, asset tags) where needed.
Example mapping
CloudTrail: sourceIPAddress → src_ip; Web logs: Client-IP → src_ip; Windows: IpAddress → src_ip.
Pitfall
Unmapped fields cause inconsistent searches and missed correlations across tools.
Validation checklist
  • Sample live events from each source and verify canonical field presence.
  • Run cross-source searches that join on canonical keys and review results.
  • Iterate parsing and mapping until coverage is acceptable.
Key takeaway: normalization is the invisible foundation for meaningful correlation and reliable detection.
