Operational notes
Use caches and TTLs for enrichment to avoid adding latency to correlation pipelines.
Tag enrichment source and timestamp so analysts can see when context last refreshed.
Avoid over-enriching every event; prioritize fields that change alert priority or triage speed.
Key Takeaway

Normalization enables consistent searches; enrichment supplies the context that turns alerts into investigation-ready leads.
