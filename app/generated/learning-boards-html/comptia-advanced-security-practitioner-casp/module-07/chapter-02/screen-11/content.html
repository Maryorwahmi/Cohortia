Module 7 › Chapter 7.2 › Web Exploit to Shell
Pseudocode (visual)
// Stage 1: Web Attack Attempt
IF Nginx_Request.URI CONTAINS suspicious_payload
AND Nginx_Response_Code = 200
THEN FLAG Source_IP and Request_URI

// Stage 2: Suspicious Process Creation
IF Syslog.Event_Type = Process_Creation
AND Process_Name IN (nc, bash, python, perl)
AND Parent_Process_Name = nginx
AND Syslog.Source_IP = FLAGGED_WEB_ATTACK_SOURCE.IP
AND WITHIN 5 minutes
THEN GENERATE CRITICAL ALERT "Web App Compromise & Shell Spawn"
Notes & tuning
Whitelist known scanners and benign cloud IP ranges to reduce false positives.
Require both web indicators and host process evidence for critical alerts.
Allow for slight clock skew by using flexible windows and normalized timestamps.
Key Takeaway

Cross-layer correlation between web and host telemetry gives high-confidence detection of exploitation and post-exploitation behavior.
