Module 7 › Chapter 7.2 › Temporal Correlation
Staged correlation example
  1. Detect multiple failed logins from an IP within 5 minutes and flag IP as suspicious.
  2. Within 10 minutes, if successful login from flagged IP occurs, attach user and IP to context.
  3. Within 2 minutes of that successful login, if access to sensitive data is observed, generate a critical alert.
Misconception
Temporal correlation is not just 'events in order'. It requires context, expiration, and attention to window sizes to avoid linking unrelated actions.
Tuning guidance
  • Start with narrow windows for high-confidence flows and expand only when you miss known attack patterns.
  • Use enrichment like asset criticality to raise severity when sensitive systems are involved.
  • Clear context variables after expiry to avoid stale associations causing false alerts.
Key Takeaway

Temporal rules detect chains. Choose windows based on attacker behavior and measure precision to tune them.
