Module 7 › Chapter 7.2 › Hands-on Activity
Activity template
1. Attack description: define TTPs you want to detect.
2. Log sources: Okta, Nginx, App server, PostgreSQL, host syslog.
3. Stages & windows: failed logins window, successful login window, sensitive access window.
4. Pseudocode: stage aggregation, set context variables, follow-on condition checks.
5. Test & tune: run queries, measure FP/TP rates, adjust thresholds and enrichments.
Assessment idea
Develop two rules for the e-commerce scenario provided in the chapter. For each rule, submit the attack scenario, logs used, and pseudocode. Demonstrate tuning by showing changes to false positive counts after adjustments.
Key Takeaway

Use the template to create reproducible, testable correlation rules and measure tuning impact with clear metrics.
