Core components
SIEM: log aggregation and correlation to build timelines
EDR: endpoint process, file, and connection visibility
NSM: network flows and packet context for lateral movement and exfiltration
IoCs and IoAs

IoCs are forensic artifacts like hashes or malicious IPs; IoAs are behaviors that indicate attacker tactics. Use both to increase detection accuracy.

Example

A file hash seen on an EDR alert, matched to a known malicious domain in threat intel, and unusual outbound data flows in NSM together support an incident designation.

Pro tip

Tune detection rules and maintain retention policies so you have both current alerts and historical context for investigations.
