# CyberSafe Corp: Phishing Incident Response Playbook Outline

## Incident Type: Successful Phishing Attack (Credential Compromise)

### 1. Preparation Phase (Pre-Incident)
* 1.1. Team & Roles: SOC L1/L2, Forensic Investigator, IT Admin, Communications, Legal
* 1.2. Tools: SIEM, EDR, Email Gateway, Identity Provider, Forensic workstation
* 1.3. Policies: MFA, password policy, communication plan
* 1.4. Hardening: DMARC/SPF/DKIM, browser security

### 2. Identification Phase
* 2.1. Initial Detection: user report, SIEM alerts
* 2.2. Validation: email header analysis, proxy logs, IDP logs, EDR endpoint checks

### 3. Containment Phase
* 3.1. Immediate: force password reset, terminate sessions, block URL/IP, quarantine emails
* 3.2. Further: isolate endpoint if malware suspected, review access rights

### 4. Eradication Phase
* 4.1. Remove artifacts: clean or reimage endpoints, remove persistence
* 4.2. Address root cause: patch systems, tighten email filtering
* 4.3. Verify: threat hunt and full scans
Hands-on guidance
  • Assign a communications lead and legal reviewer for every incident.
  • Record chain of custody entries when creating images or handling evidence.
  • Run a tabletop exercise to validate timing and ownership.
Common mistake

Omitting forensic documentation or skipping the tabletop validation produces fragile playbooks that fail under stress.

Key Takeaway

A clear playbook with owners and evidence steps saves time and preserves admissibility during real incidents.
