Module 7 › Chapter 7.6 › Identification Phase
Identification steps
  1. Collect initial alert information and timestamps from SIEM/EDR.
  2. Validate the alert by reviewing logs and correlating telemetry.
  3. Classify the incident type and estimate affected scope.
  4. Decide whether to escalate to containment and forensic collection.
Example

A login from an unusual country plus a file exfiltration alert on an endpoint suggests a coordinated compromise; combining these signals confirms an incident and narrows the affected assets.

What to collect
  • Relevant SIEM correlation logs and raw events
  • EDR activity for affected endpoints
  • Identity provider logs for authentication events
  • Network captures or proxy logs if lateral movement is suspected
Common mistake

Failing to correlate multiple telemetry sources, which can leave the real scope underestimated.

Pro tip

Preserve timestamps and timezones when collecting logs to ensure accurate event sequencing during analysis.
