Module 07 › Chapter 7.7 › Learning Objectives
01
Differentiate Live vs Dead Acquisition
Recognize when to capture volatile RAM and when to power down and image media to prevent changes.
Mnemonic: Volatile first → RAM, processes, sockets
VERIFIED COMPETENCY MILESTONE
02
Perform Forensic Imaging
Use dd, FTK Imager or EnCase to create bit-for-bit images and preserve originals with write-blockers.
Mnemonic: Image → Hash → Store
VERIFIED COMPETENCY MILESTONE
03
Analyze File Systems (NTFS / ext4)
Examine MFT or inode metadata, recover deleted entries, and interpret MACB timestamps for a timeline.
Mnemonic: MFT ⇄ inode ⇄ timeline
VERIFIED COMPETENCY MILESTONE
04
Conduct Memory Forensics
Use Volatility to extract processes, network sockets, and artifacts that exist only in RAM.
Mnemonic: pslist → netscan → malfind
VERIFIED COMPETENCY MILESTONE
Bloom Progress
Learn → Understand → Apply → Master
Learn: Recognize acquisition types
Understand: Why hashing, write-blockers, and chain of custody matter
Apply: Run imaging and basic Volatility commands
Master: Produce admissible evidence and build a timeline
