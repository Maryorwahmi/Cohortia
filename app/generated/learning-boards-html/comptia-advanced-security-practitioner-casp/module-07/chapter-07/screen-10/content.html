Module 07 › Chapter 7.7 › Network Forensics
Capture and Parse
Capture full packets, then parse using Zeek for high-fidelity logs or Wireshark for session reconstruction and payload extraction.
Protocol analysis: detect non-standard or tunneled protocols
Payload extraction: recover files or credentials transmitted over HTTP/FTP
Session reconstruction: rebuild conversations to understand attacker actions
Example
Filter a pcap for an IP observed in memory, reconstruct the HTTP session, and extract an uploaded file that the attacker used to stage further activity.
Common Pitfall
Capturing only flow metadata instead of full packets can miss payloads; when payloads matter, capture full packets from the outset.
Key Takeaway

Network captures provide evidence of communications and exfiltration; combine payload extraction with session timing and host artifacts for attribution.

Tool Notes
Use tcpdump or equivalent to capture, then analyze with Wireshark for extraction or Zeek to turn pcaps into structured logs for large-scale review.
