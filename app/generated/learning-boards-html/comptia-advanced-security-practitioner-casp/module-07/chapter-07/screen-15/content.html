Disk Imaging & Hashing
Make bit-for-bit images and compute MD5 or SHA256 to prove integrity.
Write-Blocker
Hardware device that prevents any writes to original media during acquisition.
Memory Forensics
Use Volatility to extract runtime artifacts like processes, netscan results, and malfind hits.
Network forensics: capture full packets, reconstruct sessions, and extract payloads.
File system analysis: examine MFT/inodes, MACB timestamps, ADS, and extended attributes for hidden artifacts.
Chain of custody: document each handling step, tool, hash, and transfer to support admissibility.
Final Takeaway

Follow the checklist: capture volatile data when necessary, image and hash media through write-blockers, analyze memory and network artifacts, and record every action in the chain of custody.
