Module 07 › Chapter 7.7 › Memory Acquisition
Acquisition Process
  1. Prepare trusted media and verify tool integrity before use.
  2. Run the memory capture utility from the trusted medium with minimal interaction.
  3. Store resulting image on secured storage and compute a SHA256 hash immediately.
  4. Document every step, timestamp, and actor in the chain-of-custody log.
Example Scenario
On SRV-WEB-001 with suspected fileless malware, run a trusted memory capture tool from a write-protected USB, save the .raw file to external storage, and hash it before analysis.
Common-Mistake
Running unverified tools on the compromised host or storing the image back onto the local disk can contaminate evidence and break admissibility.
Pro Tip
Always verify the checksum of the acquisition tool itself and record it in your notes before running anything on a live system.
Acquisition Command (illustrative)
E:\winpmem.exe -o C:  emp\SRV-WEB-001_memory.raw
Run from trusted, write-protected media; do not browse files before capture.
