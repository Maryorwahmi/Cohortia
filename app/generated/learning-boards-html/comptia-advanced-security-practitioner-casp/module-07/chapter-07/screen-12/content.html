Module 07 › Chapter 7.7 › Common Mistakes
Mistake: No write-blocker
Why it fails: The original media can be modified during connection or imaging. Correct practice: always use a hardware write-blocker when imaging disks.
Mistake: Missing hashes
Why it fails: You cannot prove the image matches the original. Correct practice: hash original and image immediately and compare values.
Mistake: Running unverified tools
Why it fails: Tools can alter evidence or be tampered with. Correct practice: verify tool integrity and run from trusted media.
Mistake: Ignoring hidden storage
Why it fails: Alternate data streams and extended attributes hide attacker artifacts. Correct practice: include ADS and extended attribute scans in file system analysis.
Key Takeaway

Follow defensive procedures strictly; small process lapses can invalidate otherwise solid technical work.
