Module 07 › Chapter 7.7 › File System Analysis
Key Structures
NTFS uses the Master File Table (MFT) to track files and metadata; ext4 uses inodes. Both store timestamps and pointers that reveal file lifecycles and deleted content.
MFT: locate deleted entries and alternate data streams (ADS)
inode table: recover deleted file records and extended attributes on ext4
MACB timestamps: assemble chronological events for a timeline
Analyst Checklist
  • Export MFT or inode records and parse MACB timestamps.
  • Search for alternate data streams and extended attributes.
  • Recover deleted content and compare with memory/network artifacts.
Concrete Example
If a deleted script appears in the MFT with a recent modification time, correlate that timestamp with process listings recovered from memory to prove execution even if the file is gone on disk.
Key Takeaway

Do not rely only on visible directories. Inspect metadata structures and hidden storage mechanisms to find evidence attackers hide or delete.

Tools
Autopsy, sleuthkit, FTK Imager, and EnCase can parse MFT and inode structures and support deleted file recovery.
