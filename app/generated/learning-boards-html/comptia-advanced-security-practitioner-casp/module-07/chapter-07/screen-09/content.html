Module 07 › Chapter 7.7 › Volatility Commands
Command 1 — Process Listing
vol.py -f SRV-WEB-001_memory.raw --profile=Win2012R2x64 pslist
Purpose: Lists running processes and helps spot unusual parent-child relationships.
Command 2 — Network Scan
vol.py -f SRV-WEB-001_memory.raw --profile=Win2012R2x64 netscan
Purpose: Reveals active and recent network connections tied to processes found in the memory image.
Command 3 — Malfind
vol.py -f SRV-WEB-001_memory.raw --profile=Win2012R2x64 malfind
Purpose: Detects suspicious executable memory regions that may contain injected shellcode or hidden modules.
Concrete Walkthrough
If pslist shows powershell.exe spawned by a web server, note the PID and then run netscan to locate remote endpoints used by that PID. Run malfind on that PID to extract suspicious code regions for further static analysis.
Check Your Understanding
Ask: If netscan shows an outbound connection but no corresponding process in pslist, what might that indicate about the attacker technique or timeline?
Misconception
Do not assume a process name alone proves maliciousness—investigate parentage, memory contents, and network context to confirm.
