Acquisition Steps (Checklist)
  1. Verify acquisition tool integrity and prepare write-protected media.
  2. Run the memory capture from trusted media and save the .raw file to secure storage.
  3. Compute and record SHA256 on the memory image; record tool and timestamps.
  4. Transfer image to forensic workstation for Volatility analysis.
Volatility Triage
Run a focused set of commands: process listing, network scan, and malfind to extract immediate indicators of compromise for further analysis.
Illustrative Commands
# Memory acquisition (conceptual)
E:\winpmem.exe -o C:  emp\SRV-WEB-001_memory.raw

# Volatility triage
vol.py -f SRV-WEB-001_memory.raw --profile=Win2012R2x64 pslist
vol.py -f SRV-WEB-001_memory.raw --profile=Win2012R2x64 netscan
vol.py -f SRV-WEB-001_memory.raw --profile=Win2012R2x64 malfind
Run these commands on your forensic workstation after transferring and hashing the image.
Reflection
After running triage, ask: Which processes show suspicious parentage? What remote endpoints appear? Do malfind results contain extractable code?
Safety Note
Minimize changes to the live system, record everything, and avoid actions that are not directly related to acquisition.
