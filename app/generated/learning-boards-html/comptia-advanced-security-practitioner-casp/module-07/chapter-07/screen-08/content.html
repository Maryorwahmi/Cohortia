Module 07 › Chapter 7.7 › Memory Forensics
Volatility Essentials
Use profile detection, then run plugins to list processes, network sockets, loaded modules, and registry hives. These artifacts together reveal runtime behavior.
pslist / pstree — enumerate running processes and parent-child relationships
netscan — reveal active and recently closed network connections
malfind — detect injected or hidden code regions
Concrete Example
After acquiring a memory dump, run pslist to find an unexpected powershell.exe process spawned by a web server process, then use malfind to extract injected code snippets for deeper analysis.
Traces You Can Extract
  • Running processes and suspicious parentage
  • Open and recently closed network sockets
  • Loaded libraries and registry hives
  • Evidence of rootkits or API hooks
Key Takeaway

Memory often contains the only reliable record of transient activity. Use Volatility to turn RAM into readable evidence for detection and attribution.
