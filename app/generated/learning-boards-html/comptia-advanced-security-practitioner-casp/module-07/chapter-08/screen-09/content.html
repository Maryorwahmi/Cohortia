Module 8 › Chapter 7.8 › Dynamic Analysis
What to capture
Process Activity
Process creation, injections, parent/child chains, and suspicious names.
Filesystem & Registry
File writes/renames/deletions, Run keys, scheduled tasks, and persistence artifacts.
Network Traffic
DNS queries, HTTP requests, and outbound connections captured by Wireshark and controlled by FakeNet-NG.
API Calls
Sequence of system calls that reveal technique: file IO, crypto, network.
Example
Observe CreateFile -> ReadFile -> CryptEncrypt -> WriteFile to confirm encryption behavior, and capture any network beaconing that follows.
Practical cards
Checklist
Snapshot taken, Procmon logging, Wireshark capture, FakeNet active, test files present.
Common mistake
Not using simulated network services; malware may fail to demonstrate behavior if it expects C2 responses.
Key Takeaway
Multiple runs and controlled inputs reveal fuller behavior than a single, unmonitored execution.
