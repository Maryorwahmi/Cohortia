Module 8 › Chapter 7.8 › Monitoring Toolset
Tool Roles
Procmon
Tracks processes, files, and registry modifications in detail.
Wireshark
Sniffs network packets for DNS, HTTP, and TCP/UDP traffic analysis.
FakeNet-NG
Simulates network services to safely observe malware behavior without reaching the internet.
Correlate logs: record timestamps, process IDs, and file hashes so you can link a network call in Wireshark back to the originating process and the file that was modified.
Example correlation
Wireshark shows a DNS lookup for bad.example; FakeNet logs the request and returns a controlled IP; Procmon shows the process that issued the DNS query. Together they form a reliable network IoC and process attribution.
Key Takeaway
Use multiple observability layers and precise timestamps to produce correlated, actionable intelligence.
