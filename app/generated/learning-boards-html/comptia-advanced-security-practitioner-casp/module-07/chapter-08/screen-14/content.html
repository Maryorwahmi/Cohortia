Module 8 › Chapter 7.8 › Key Concepts
Static Analysis
Inspect files, strings, and imports without executing the sample.
Dynamic Analysis
Execute inside a snapshot-enabled VM with simulated network services to observe real behavior.
Reverse Engineering
Use disassemblers and debuggers to reveal packed or obfuscated code paths and functions.
Summary

Safe, documented, and correlated analysis across static and dynamic methods produces the IoCs defenders need to stop attacks.
