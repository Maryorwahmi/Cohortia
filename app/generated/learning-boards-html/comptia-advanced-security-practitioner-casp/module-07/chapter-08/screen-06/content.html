Module 8 › Chapter 7.8 › Safe Dynamic Analysis
VM Preparation Steps
  1. Build a dedicated analysis VM with no production access.
  2. Disable host networking or route through an isolated lab bridge.
  3. Install Process Monitor, Wireshark, and API logging tools.
  4. Create a clean snapshot before any execution.
  5. Use FakeNet-NG/INetSim to simulate network services when needed.
Monitoring & Safety
Place dummy documents in the VM to measure file-targeting behavior. Keep shared folders disabled to avoid accidental host infection.
Example Configuration
Snapshot labeled clean-0001, FakeNet-NG running on a private lab subnet, Process Monitor logging to file, Wireshark capturing to disk.
Common mistake
Leaving host-only or shared folders enabled; never use your workstation for analysis.
Key Takeaway
Isolation, snapshots, and simulated network services let you observe behavior safely and repeatably.
