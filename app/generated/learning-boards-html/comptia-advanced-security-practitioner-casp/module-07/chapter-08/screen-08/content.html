Inspecting Imports & Functions
Load the binary, examine the import table, and view cross-references to find where imports are used.
// Pseudo decompiler snippet
function do_encrypt() {
  open_file();         // CreateFile
  read_contents();
  call_crypto_api();   // CryptEncrypt
  write_encrypted();   // WriteFile
}
Cross-reference the crypto call to see which files are passed; that gives you file patterns to watch during dynamic runs.
Practical tips
  • • Verify decompiler output against the raw assembly.
  • • Use call-graph and function-size heuristics to find packing stubs.
  • • Label functions you confirm to speed later navigation.
Common misconception
Decompilers are infallible. They are tools that reduce effort; you must validate their output with assembly and runtime observations.
