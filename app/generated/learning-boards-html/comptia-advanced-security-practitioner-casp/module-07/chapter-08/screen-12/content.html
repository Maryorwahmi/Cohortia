Module 8 › Chapter 7.8 › invoice.exe Workflow
Static Steps (Example)
1) file / PEiD to identify PE and check packers. 2) sha256sum to record the hash. 3) strings or FLOSS to find filenames, ransom-note text, or API strings. 4) Dependency analysis to view imports like ws2_32 and kernel32.
# Example commands
file invoice.exe
sha256sum invoice.exe
strings invoice.exe | grep -i "README\|encrypt\|bitcoin"
Dynamic Setup & Execution
Prepare an isolated VM with a clean snapshot, install Procmon, Wireshark, and FakeNet. Place test documents. Start monitoring and then execute the sample. Capture process events, file writes and registry changes, and all network traffic.
Watch for CreateFile → ReadFile → CryptEncrypt → WriteFile sequences and for Run key additions indicating persistence.

File hashes (SHA256)
Network indicators (domains, IPs)
