Module 8 › Chapter 7.8 › Static Analysis Techniques
Core Static Steps
  • • File type and packer identification (file, PEiD).
  • • Hashing for IoC (SHA256).
  • • String extraction (strings, FLOSS).
  • • Import/dependency analysis (Dependency Walker, Ghidra).
  • • Disassembly to inspect code flow (Ghidra/IDA).
Example output
strings invoice.exe
---> "README.txt"
---> "CreateFile"
---> "ws2_32.dll"
---> "C:\\Users\\Public\\Documents\\Invoices"
Interpreting clues
A reference to README.txt and file APIs suggests dropping a ransom note or manipulating files; networking imports indicate possible C2 or data exfiltration.
Common mistake
Assuming obvious strings prove full behavior. Always confirm with imports, disassembly, or dynamic testing.
Pro tip
Always compute and record hashes before any analysis so you can reference the sample reliably.
Key Takeaway
Static tools provide safe, fast clues — packers and obfuscation often require debugger-assisted unpacking.
