Learning Objectives

These objectives focus on applied skills: deploying sensors, analyzing flows, capturing packets, and correlating data so you can detect and investigate real network threats.

01
Configure advanced IDS/IPS

Set up detection and prevention points and tune rules to reduce false positives while blocking known threats.

VERIFIED COMPETENCY MILESTONE
02
Analyze NetFlow/IPFIX records

Interpret flow metadata to discover anomalous patterns, spikes, and suspicious external connections.

VERIFIED COMPETENCY MILESTONE
03
Use full packet capture for forensics

Capture targeted packets to reconstruct sessions, inspect payloads, and extract evidence when content matters.

VERIFIED COMPETENCY MILESTONE
04
Integrate NSM with SIEM and hunt

Correlate network telemetry with host logs and threat intelligence to hunt for stealthy intrusions and confirm impact.

VERIFIED COMPETENCY MILESTONE
