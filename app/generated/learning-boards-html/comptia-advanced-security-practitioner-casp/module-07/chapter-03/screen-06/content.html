NetFlow / IPFIX

Conversation metadata at scale

NetFlow and IPFIX export compact records about who talked to whom, when, and how much data was transferred.

  • Common fields: source/destination IP, ports, protocol, byte and packet counts, timestamps.
  • Use flows to spot high-level anomalies and baseline normal network behavior.
  • Flow tools provide dashboards for top talkers, unusual ports, and volume spikes.
Example
If a server shows many outbound flows to a foreign IP on port 4444, treat it as a lead for targeted capture or host investigation to confirm C2 behavior.
Tooling
Tools like ntopng or flow collectors can ingest NetFlow/IPFIX and visualize trends for analyst triage.
Misconception

Flow records do not include payloads. Do not assume you can reconstruct data exfiltration from flows alone.
