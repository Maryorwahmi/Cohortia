Module 7 › Chapter 7.3 › What is NSM?
Definition

Network Security Monitoring

Continuous collection and analysis of network data to detect, investigate, and respond to incidents.

Why it matters

It reveals communication patterns and interactions that host logs alone cannot show.

Common misconception

Capturing everything is not practical; targeted captures and flow summaries are more sustainable.

Key Takeaway

Select telemetry by purpose: flows for detection at scale, packets for content and proof.

Telemetry Triad
Alerts
IDS/IPS signatures and behavior alerts for focused detection.
Flows
NetFlow/IPFIX summaries for conversation patterns and volume analysis.
Packets
Full packet capture for payload inspection and session reconstruction.
Practical example
If a flow spike shows many outbound connections on an unusual port, use a targeted FPC to capture payloads and confirm whether data is being exfiltrated.
