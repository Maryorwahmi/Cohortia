Architecture

Correlate network telemetry with host and cloud logs

The SIEM connects alerts, flows, and indices or pointers to packet captures so analysts can see incident context end-to-end.

IDS/IPS
Alert events with signatures and severity for immediate triage.
Flow records
Summarized conversations for scope and pattern analysis.
Packet indices
References or metadata that point to stored capture files for forensic retrieval.
Operational tips
  • Normalize timestamps and enrich records with host and user context.
  • Index capture metadata in the SIEM rather than ingesting full pcaps.
  • Use threat intelligence to flag known bad actors in flows and alerts.
