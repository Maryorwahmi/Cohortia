Module 7 › Chapter 7.3 › SecureCorp Investigation
Task

Capture and conceptual analysis

sudo tcpdump -i eth0 -s 0 -w suspicious_traffic.pcap 'host 10.0.1.50 and host 203.0.113.10 and port 4444'

Capture full packets for the two hosts on the suspected port to create an evidence file for Wireshark analysis.

What to look for
  • Protocol type and handshake patterns.
  • Payload contents: cleartext commands, base64, or known signatures.
  • Beaconing patterns or repeated small packets.
Immediate actions
  • Isolate 10.0.1.50 or block outbound to 203.0.113.10.
  • Preserve and encrypt the pcap, and start forensic endpoint investigation.
Follow-up
Search flow records for similar connections and hunt for other hosts showing the same pattern. Update IDS/IPS rules and SIEM correlations as needed to detect related activity earlier.
