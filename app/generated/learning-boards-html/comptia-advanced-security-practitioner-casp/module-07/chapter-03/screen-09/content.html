Terminal Demo (conceptual)

Capture command example

sudo tcpdump -i eth0 -s 0 -w suspicious_traffic.pcap 'host 10.0.1.50 and host 203.0.113.10 and port 4444'

This captures the full packet length for traffic between the two hosts on port 4444 and writes it to a pcap file for later analysis in Wireshark.

Analysis checklist
  • Confirm protocol and handshake behavior.
  • Inspect payloads for commands or exfiltration artifacts.
  • Look for beaconing patterns and timing regularity.
Safety & governance
  • Encrypt pcap files at rest and log access.
  • Limit capture scope to minimize sensitive data collection.
Conceptual Wireshark steps
  1. Open the pcap and confirm the IPs and ports.
  2. Check TCP flags for abnormal sequences.
  3. Inspect payload for ASCII strings, base64, or protocol anomalies.
