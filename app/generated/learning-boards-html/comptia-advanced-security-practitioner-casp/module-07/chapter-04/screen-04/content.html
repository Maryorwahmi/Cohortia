EDR: continuous detection, investigation, and response

EDR collects telemetry continuously and looks for behavioral patterns that indicate compromise, complementing signature-based protection.

What it collects
  • Process execution and lineage
  • File system changes and file writes
  • Network connections and ports
  • Registry modifications and user actions
Example
PowerShell invoked with obfuscated download commands, followed by outbound connection and file changes — an EDR can correlate these events into a high-fidelity detection.
Key Takeaway

EDR augments prevention with continuous monitoring and response, making endpoints less blind to sophisticated attacks.

Misconception & Contrast
Many teams assume EDR will automatically block everything. In reality EDR surfaces behavioral signals and offers containment options which must be tuned and tested to avoid business disruption.
Analogy
Think of antivirus as a locked door and EDR as a security camera and alarm: the camera detects suspicious behavior that the locked door cannot stop if bypassed.
Check your understanding
If an administrator runs a legitimate maintenance script that looks like malicious behavior, what signals would you inspect to avoid a false positive?
Pro tip
Use role- and application-based baselines to distinguish legitimate administrator activity from malicious living-off-the-land usage.
