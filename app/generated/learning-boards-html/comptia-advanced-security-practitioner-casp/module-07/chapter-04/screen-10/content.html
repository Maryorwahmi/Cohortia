Module 7 › Chapter 7.4 › Automated Response
Common automated actions
  • Process Termination: kill malicious processes to stop execution.
  • File Quarantine: isolate or remove suspicious files for analysis.
  • Network Isolation: disconnect the endpoint from the network to prevent spread.
  • Registry Reversal: undo malicious persistence changes.
  • Endpoint Snapshotting: capture a forensic image for deeper analysis.
Tradeoffs to consider
Automated isolation reduces spread but can break services. Snapshotting preserves evidence but consumes storage and time. Design actions by impact and endpoint criticality.
Operational example
For high-severity ransomware behavior on a workstation, immediate network isolation is often the best first automated step. For a critical server, configure the platform to require human approval before isolation.
Key Takeaway

Define safe automation policies by endpoint role and severity, test them, and maintain rollback and escalation options.
