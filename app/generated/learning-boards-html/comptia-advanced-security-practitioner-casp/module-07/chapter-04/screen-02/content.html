How these objectives map to operations
  • Know what telemetry to collect and why each signal matters for detection.
  • Design agent rollout plans that use Group Policy, SCCM, cloud tools, or orchestration scripts.
  • Use EDR query languages to reconstruct process trees and network activity for hunting.
  • Define automated responses with safe boundaries to avoid business disruption.
Each objective includes a short practical exercise to verify competency.
