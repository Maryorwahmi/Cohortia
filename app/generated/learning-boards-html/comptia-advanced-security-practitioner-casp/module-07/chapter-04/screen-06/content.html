Module 7 › Chapter 7.4 › Endpoint Telemetry
Telemetry categories
Process Execution & Lineage
Parent-child relationships and full command-line arguments reveal origin and intent.
File Activity
Files created, modified, or deleted — especially in temp and system folders — support payload discovery.
Network Connections
Outbound IPs, DNS, and ports help identify C2 and exfiltration paths.
Registry & Persistence
Registry changes can show persistence mechanisms such as Run keys and service additions.
Plan collection by endpoint role: servers may need longer retention and deeper collection than workstations.
Concrete example
A PowerShell command with download strings plus file writes in temporary folders and a subsequent new process is a strong indicator of a fileless payload. Correlating those signals reduces false positives.
Common mistake
Enabling verbose telemetry for all endpoints without bandwidth planning; the result can be dropped events or increased costs that undermine detection.
Key Takeaway

Collect the signals necessary to support hunting and response while tuning retention and verbosity for endpoint roles.
