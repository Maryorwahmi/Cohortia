Agent → Telemetry → Platform

Agents emit detailed telemetry which the central platform analyzes with ML, heuristics, and threat intelligence.

Agent responsibilities
  • Collect process, file, network, registry, and user activity.
  • Maintain local buffering when connectivity is limited.
  • Implement response actions on command from the platform.
Platform capabilities
  • Storage and correlation of telemetry.
  • Behavioral models and threat intelligence enrichment.
  • Orchestration of automated responses and investigation tools.
Operational note
Plan for agent health monitoring, software updates, and telemetry bandwidth. Excessive verbose logging across all endpoints can overload networks and storage.
Topology cards
Endpoint Agents
Installed on servers, workstations, and mobile devices to capture local events and execute commands.
Telemetry Stream
Continuous events: process execution, command lines, network sockets, file writes, registry edits.
Central Platform
Ingest, correlate, score, and enrich telemetry with threat intelligence and behavioral models.
Response & Forensics
Execute containment, snapshot endpoints for forensics, and feed evidence back into rules.
Consider how retention and scale requirements affect storage and detection latency.
