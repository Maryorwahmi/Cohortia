Module 7 › Chapter 7.4 › Key Concepts
EDR
Continuous monitoring and response system for endpoints.
Endpoint Telemetry
Process, file, network, registry, and user activity used for detection and investigation.
Behavioral Analytics
Baselining and anomaly detection to surface stealthy or novel attacks.
Threat Hunting
Proactive searches across telemetry for unknown or unmet alerts.
Automated Response
Predefined actions like kill, quarantine, isolate, and snapshot to contain incidents.
Network Isolation
Disconnect compromised endpoints to prevent lateral movement and data exfiltration.
Summary

These concepts form the foundation for EDR operations: collect the right telemetry, detect anomalies, hunt proactively, and respond safely to contain incidents.
