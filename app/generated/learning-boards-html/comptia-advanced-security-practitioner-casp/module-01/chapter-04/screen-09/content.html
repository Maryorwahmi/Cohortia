Module 1 › Chapter 1.4 › Kubernetes Security
Control plane protections
  • Authenticate and authorize API access; secure kubelet and API endpoints.
  • Encrypt etcd and restrict its network access to control-plane nodes.
  • Use private cluster control plane endpoints or guarded bastions for admin access.
Misconception

Treating Kubernetes as secure by default. Administrative and network defaults must be hardened before production use.

Operational controls
  • Apply RBAC with least privilege for users and service accounts.
  • Use network policies to minimize lateral movement between pods.
  • Manage secrets through KMS-backed solutions and restrict secret access.
Key Takeaway

Harden defaults, scope RBAC, protect control-plane storage, and enforce network policies to keep clusters safe.
