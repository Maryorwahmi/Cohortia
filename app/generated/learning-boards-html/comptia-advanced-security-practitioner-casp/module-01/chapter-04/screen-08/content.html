Module 1 › Chapter 1.4 › Container Image & Runtime
Image security checklist
  • Use minimal, trusted base images and scan for vulnerabilities.
  • Sign images and enforce registry policies that only allow signed images to deploy.
  • Store images in a private registry with access controls and scanning on push.
Runtime protections

Drop unnecessary Linux capabilities, run processes as non-root, and use runtime detection tools to watch for anomalous behavior.

Kubernetes-specific controls
  • Protect the control plane and etcd with network restrictions and encryption.
  • Use network policies to restrict pod communications to required flows.
  • Enforce RBAC and avoid granting cluster-admin to applications or service accounts.
Key Takeaway

Protect both the image supply chain and runtime. Defaults are risky — tighten them and monitor continuously.
