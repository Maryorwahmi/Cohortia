Designing secure network topologies with layered controls and segmentation.

Key Activities
  • Detailed threat modeling.
  • Define security requirements (app & infra).
  • Design secure network topologies (e.g., micro-segmentation).
  • Select security controls (WAFs, IDS/IPS).
  • Design secure data flows & API security.
Secure by Design Example

For a new API, mandate OAuth 2.0 authentication and OpenID Connect authorization from the initial specification, rather than retrofitting later.

Key Takeaway

The design phase is crucial for embedding security into the architecture's core, ensuring controls and secure practices are integral to the blueprint.
