Host-based Firewalls
Precision at the workload level; can filter by process and local socket. High operational overhead and visibility challenges without central tooling.
Overlay Virtualization
Centralized policies mapped to virtual network constructs. Enables consistent policy across hosts but requires controller security and integration work.
Cloud Security Groups
Stateful instance-level rules that are easy to manage and integrate with cloud APIs; limited by cloud rule expressiveness and vendor models.
Concrete Example
In AWS, a security group rule can allow TCP/8080 from another security group's ID, granting app-to-app access without IP addresses.
Common Mistake
Relying on a single control type. Mixing controls and centralizing visibility yields stronger, maintainable policies.
