Micro-segmentation explained
Isolate workloads so that only required ports and peers are allowed, even within the same subnet or host.
Definition: Granular isolation around workloads using host, overlay, or cloud controls.
Example: Web tier allowed only to talk to app tier on internal API port; app tier to DB on database port.
Misconception: More rules are better. Reality: complexity leads to errors. Monitor first, then enforce.
Key Takeaway

Micro-segmentation limits lateral movement by enforcing least privilege per workload; validate with logs before enforcement.

Implementation options
Host-based firewalls
Enforce rules at the OS or container level for precise control.
Overlay virtualization
Use network overlays to apply policies independent of underlay topology.
Cloud security groups
Stateful instance-level rules that map naturally to micro-segmentation in cloud environments.
