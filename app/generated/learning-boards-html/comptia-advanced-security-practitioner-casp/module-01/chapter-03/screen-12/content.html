Communication & controls
LB → Web: TCP/443 — AWS SG on LB allows 0.0.0.0/0 inbound; Web SG allows inbound from LB SG on 443.
Web → App: TCP/8080 — App SG allows inbound from Web SG on 8080.
App → DB: TCP/5432 — On-prem firewall allows App CIDR via Direct Connect; App SG allows outbound to DB CIDR on 5432.
Validation: enable VPC flow logs, perform curl/telnet probes, and review denied flows before enforcement.
