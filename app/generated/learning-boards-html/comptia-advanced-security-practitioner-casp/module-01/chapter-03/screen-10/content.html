Module 1 › Chapter 1.3 › NGFW / WAF / IDS-IPS
Role of NGFW
Application-aware enforcement, identity-based rules, integrated IPS, and threat feed integration to block or quarantine malicious traffic.
Placement: perimeter, hub inspection points, or east-west choke points in a cloud transit topology.
WAF & IDS/IPS
WAFs protect web applications at Layer 7. IDS alerts on anomalies; IPS blocks them. Tune to reduce false positives.
Concrete Example
Front web traffic with a WAF to stop common HTTP attacks, then inspect with NGFW for lateral movements and unusual protocols.
Key Takeaway

Layered inspection combines WAF, NGFW, and IDS/IPS to provide defense-in-depth; tune and scale these controls to avoid operational impact.
