Module 1 › Chapter 1.5 › Mobile App Flow
Data Types & Classification
Location: Confidential (PII) or Pseudonymized. Email: Confidential. Payment Info: Restricted (PCI scope).
Flow & Controls
  1. Mobile App: obtain consent, validate inputs, use TLS to API.
  2. API Gateway: mTLS or TLS, authn/authz, WAF, tokenize payments, pseudonymize location.
  3. Microservice: RBAC, TLS to DB, DLP scanning for outbound data.
  4. Database: Encryption at rest (TDE), RBAC, DAM, masking in non-production.
  5. Policies: retention and erasure mechanisms, audit logs for requests.
Concrete example
Tokenize card data at the gateway, store token in DB; log token usage and restrict access to tokenization service. Aggregate location to city-level before persisting to reduce identifiability.
