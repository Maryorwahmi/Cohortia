Module 1 › Chapter 1.5 › Governance
Governance steps
  1. Define owner roles and clear label meanings tied to controls.
  2. Automate obvious patterns for tagging and flag for human review.
  3. Train users and provide a simple override workflow with justification.
  4. Audit labels, report accuracy metrics, and iterate policies.
Operational knobs
  • Auto-tag with regex or ML for credit cards, SSNs, and emails.
  • Trigger DLP and encryption policies automatically from tags.
  • Use sampling audits to measure false positive and false negative rates.
Check your understanding
If automated tagging flags a file as Restricted but a human marks it Internal, require justification and record it for audit.
