Module 1 › Chapter 1.5 › Database Security
Core protections
  • Granular RBAC and least privilege
  • Encryption at rest and, where needed, field-level encryption
  • Database Activity Monitoring for real-time insights
  • Masking or redaction for test and staging data
Operational practices
Regular vulnerability scanning, strict admin controls, and mapping classification labels to table-level controls help maintain a defensible posture. Use auditing logs to support investigations without exposing sensitive contents.
Example
Store payment tokens in a restricted table, enable DAM on queries accessing that table, and mask values in non-production copies.
