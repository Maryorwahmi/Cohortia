Module 1 › Chapter 1.5 › Data Classification
Definition

Classification scheme

Use a limited set of categories that map directly to controls and retention. Make rules actionable and automatable where possible so users do not have to guess.

Public
Integrity checks; no confidentiality requirement.
Internal
Restricted use; basic access controls and logging.
Confidential
Encryption and stricter access controls.
Restricted
Strong encryption, tokenization, and detailed auditing.
Practical policy

From label to control

Use pattern-based automation for obvious cases and provide a simple override workflow for unclear items. Ensure every label states required encryption, retention, and DLP action. Audit labels and use sampling to measure accuracy.
Example: Mobile app
Classify payment info as Restricted, email as Confidential, and raw location as Confidential or Pseudonymized if not needed.
Key takeaway
Simplicity and automation drive adoption; misclassification leaves data exposed.
