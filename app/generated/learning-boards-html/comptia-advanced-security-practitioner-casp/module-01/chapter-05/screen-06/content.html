Encryption types
At Rest
Full disk, TDE, or object storage encryption to protect persisted data.
In Transit
TLS, IPsec, or SSH to protect data across networks.
Format-Preserving Encryption
Maintains format for legacy compatibility, e.g., 16-digit to 16-digit.
Tokenization
Replaces sensitive values with tokens and stores originals in a vault.
Homomorphic Encryption
Enables computation on ciphertexts to reduce exposure during analytics.
Decision factors
  • Compatibility: Can downstream systems accept transformed formats?
  • Performance: Does the encryption method meet latency and throughput needs?
  • Scope reduction: Will tokenization or encryption reduce compliance burden?
  • Key management: Are keys stored and rotated securely?
Example
Use TLS for API traffic, tokenization at the gateway for payments, and TDE in the database. Consider FPE when a legacy payment processor requires fixed-length values.
