Key Concepts: Frameworks

Essential Frameworks for ESA

TOGAF

A comprehensive framework for enterprise architecture, including security architecture content.

SABSA

A business-driven framework for security architecture, linking security directly to business attributes.

NIST CSF

A risk-based framework for managing cybersecurity risk, providing guidance on identifying, protecting, detecting, responding, and recovering.

Chapter Summary

These frameworks provide structured methodologies to ensure security architecture is comprehensive, business-aligned, and effectively manages risk across the enterprise.
