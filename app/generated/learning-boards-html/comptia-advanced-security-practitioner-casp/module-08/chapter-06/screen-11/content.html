Module 8 › Chapter 8.6 › Indicators of Compromise
Email IoCs
Sender anomalies, link mismatches, generic greetings, and urgent action language.
  • Domain mismatch between display name and real sender domain.
  • Links where preview URL differs from anchor text.
  • Language that creates unnecessary urgency or fear.
  • Requests for sensitive actions without documented processes.
Physical IoCs
Unlocked doors, missing surveillance, discarded documents with sensitive information, and unexplained devices in public spaces.
Using IoCs constructively
Aggregate results to find systemic weaknesses. Use targeted training and technical controls rather than individual discipline.
Key Takeaway
IoCs tell you what to fix. Measure trends to show defense improvement over time.
