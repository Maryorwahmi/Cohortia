Module 8 › Chapter 8.6 › Phishing Variants
Phishing process
Reconnaissance, message crafting, hook, and payload.
1
Reconnaissance
Gather public data about targets to make messages believable.
2
Message crafting
Personalize subject, sender, and content to match the audience.
3
Hook and payload
Links or attachments aim to capture credentials or deliver malware; in simulations they log clicks only.
Example: mass phishing
A generic password expiration message sent to all employees to harvest clicks.
Example: whaling
An urgent fund-transfer request crafted for the CFO referencing board-approved invoices.
Defensive focus by scope
Mass campaigns: email filtering, DMARC, user training. Targeted campaigns: role-based training, executive awareness, simulated whaling exercises.
