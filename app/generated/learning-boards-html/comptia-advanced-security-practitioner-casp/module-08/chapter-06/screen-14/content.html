Module 8 › Chapter 8.6 › Activity: Phish Design
Activity template
Choose theme, draft email, define call to action, set IoCs, and obtain approvals.
1. Choose a theme: password expiry, IT update, or package delivery—avoid sensitive topics.
2. Draft the email: subject, spoofed sender name, body text, and a harmless logging link.
3. Define IoCs: misspellings, generic greetings, link mismatch, odd sender domain.
4. Approvals: written authorization and stakeholder notifications are mandatory.
5. Debrief: plan immediate educational feedback and aggregated reporting.
Example draft
Subject: Urgent: Your Password Expires Today - Action Required! — link leads to a safe landing page explaining the test.
Common mistake: choosing emotionally charged themes. Avoid causing real distress.
