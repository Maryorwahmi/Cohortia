Module 8 › Chapter 8.6 › Key Concepts
Pretexting
Fabricated stories used to extract information or access from targets.
Baiting
Using physical lures like unknown media to entice unsafe behavior.
Get-Out-Of-Jail Letter
Authorized documentation testers carry to verify activities during physical assessments.
Takeaway
Testing must be ethical and constructive. Use clear approvals, safe payloads, and aggregated reporting to improve controls and culture.
