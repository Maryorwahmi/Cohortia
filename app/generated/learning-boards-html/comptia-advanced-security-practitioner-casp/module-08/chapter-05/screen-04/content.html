Module 8 › Chapter 8.5 › Domain Differences
Definition
What makes a penetration test "mobile" or "cloud" focused.
Mobile surface
  • Local storage and OS APIs
  • Runtime hooks and device features
  • Backend API interactions specific to mobile flows
Cloud surface
  • IAM and identity policies
  • Storage access controls and network rules
  • Container images and serverless functions
Comparison
Common misconception
Treating mobile like a web app ignores device-specific storage, runtime and tampering vectors. Treating cloud like on-prem ignores shared responsibility and tenant configuration controls.
Concrete example
An API token accessible via a web endpoint is similar across domains, but when that token is stored unencrypted on a mobile device it becomes exposed to local attacks that web testing does not reveal.
Key takeaway
Choose tools and scope to match the platform. Validate findings with domain-appropriate proof-of-concept techniques.
