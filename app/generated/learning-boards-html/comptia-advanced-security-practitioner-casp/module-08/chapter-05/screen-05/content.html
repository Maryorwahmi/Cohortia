Module 8 › Chapter 8.5 › Mobile Vulnerabilities
Common vulnerability classes
Focus areas for mobile assessments
Insecure Data Storage
Unencrypted tokens or PII in files, shared prefs, or local DBs.
Insecure Communication
Missing TLS validation, weak ciphers, or SSL pinning bypasses.
Session & Auth Issues
Predictable tokens, missing MFA, improper invalidation.
Examples & checks
Use static analysis to flag storage in code and dynamic instrumentation to observe runtime secrets. Verify session invalidation by forcing logout flows and checking token revocation.
Concrete example
A session token stored in shared preferences can be pulled with ADB from a debug or rooted device and used to access the API if tokens are not bound to device context.
Common mistake
Assuming obfuscation prevents reverse engineering; attackers can still extract strings and logic with proper tooling unless robust protections are applied.
