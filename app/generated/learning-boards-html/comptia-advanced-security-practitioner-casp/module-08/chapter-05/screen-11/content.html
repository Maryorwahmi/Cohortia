Module 8 › Chapter 8.5 › S3 Policy Walkthrough
Simulated policy analysis
Identify public read by reading statements
Checklist
  1. Find any Statement with "Effect": "Allow"
  2. Check if "Principal" is "*" or empty
  3. See whether "Action" includes "s3:GetObject"
Concrete policy snippet
{"Sid": "AllowPublicRead", "Effect": "Allow", "Principal": "*", "Action": "s3:GetObject", "Resource": "arn:aws:s3:::my-sensitive-data-bucket/*"}
Impact & guidance
If public read is present, sensitive data can be exfiltrated without credentials. Recommend removing public principals or moving public assets to a controlled static-hosting setup with appropriate CDN controls.
