Module 8 › Chapter 8.5 › Cloud Attack Vectors
Priority vectors
Focus where misconfiguration and identity errors create access paths
IAM misconfigurations
Overly permissive roles, weak MFA, exposed access keys.
Storage misconfigurations
Public buckets or improper ACLs that expose data.
Network & containers
Open security groups, insecure container images, and misconfigured clusters.
Checks & examples
Use read-only CLI queries and posture scanners to enumerate IAM roles and bucket policies. Combine findings to map potential attack chains.
Concrete example
An EC2 instance role that allows full S3 access plus a public bucket containing secrets creates an immediate data-exfiltration path.
