Activity: Is the bucket public?
Apply the policy checklist to the provided JSON and determine public readability.
Steps
  1. Find Statements with Effect Allow
  2. Check Principal for wildcard *
  3. Confirm Action includes s3:GetObject
Simulated result
The statement named "AllowPublicRead" contains Principal "*" and Action "s3:GetObject". Conclusion: my-sensitive-data-bucket is publicly readable.
Follow-up
Validate remediation by re-fetching the policy and performing a controlled read test in an isolated account, and suggest signing or CDN controls for intentionally public files.
