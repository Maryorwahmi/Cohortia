Module 8 › Chapter 8.5 › Mobile Tooling
Workflow
Static → Dynamic → Evidence collection
MobSF (static)
Flags insecure storage hints, hard-coded keys, and manifest settings.
Frida / objection (dynamic)
Hook APIs at runtime to bypass protections and observe secret handling.
ADB (device)
Access app files and databases on emulators or rooted devices to extract artifacts.
Code examples (conceptual)
Examples below show how a tester might list and pull an app database on a test Android device, and an objection command to disable SSL pinning during analysis. Use only in controlled, authorized environments.
# Example: Using ADB to inspect app files (requires debug/root)
adb shell
su
cd /data/data/com.example.myapp
ls -la
exit
adb pull /data/data/com.example.myapp/databases/myapp.db .

# Example: objection conceptual sequence (requires Frida server)
# objection --gadget "com.example.myapp" explore
# android sslpinning disable
