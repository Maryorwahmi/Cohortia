Module 08 › Chapter 8.7 › Goal-Oriented Red Teaming
Claim

Minimal prior knowledge, maximum realism

Operate like an external adversary by building objectives first and discovering how to achieve them during the engagement.

Objective example: Exfiltrate customer records without detection.
Technique chain: Phishing → valid account use → network share access → covert upload.
Measurement: Was the chain detected, and how long until containment?
Practice

Map objectives using ATT&CK

Start with a success criterion, then pick ATT&CK tactics and techniques that a real adversary would use to reach it. That map becomes your exercise plan and reporting backbone.
Pro tip

Define success criteria explicitly. The measurement of detection and containment is what separates a red team report from a vulnerability list.

Misconception check
Red teams are not simply louder pen tests. Their aim is to test detection and response using realistic tradecraft and persistence tactics.
Key Takeaway

Write objectives first. Then design attack chains that measure detection, not just exploitation.
