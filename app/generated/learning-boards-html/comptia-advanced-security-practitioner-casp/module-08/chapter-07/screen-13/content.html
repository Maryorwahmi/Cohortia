Scenario

Insider data exfiltration

Alice uses valid credentials, runs PowerShell, finds a share, copies files, and uploads to cloud storage.

Steps & ATT&CK mapping (suggested)
  • Initial Access — T1078 Valid Accounts
  • Execution — PowerShell command activity (Execution / Discovery)
  • Discovery — Enumerate network shares
  • Collection — Copy sensitive files locally
  • Exfiltration — Upload to cloud storage
Telemetry candidates
  • Authentication logs for account usage
  • PowerShell script and command logging
  • File access audit logs on shares
  • Network logs for large outbound uploads
Action

Use this mapping as input to a purple-team session: prioritize telemetry that detects each mapped technique and assign owners to implement those detections.
