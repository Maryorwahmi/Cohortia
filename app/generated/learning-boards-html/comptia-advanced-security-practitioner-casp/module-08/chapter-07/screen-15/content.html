Module 08 › Chapter 8.7 › Key Concepts
Red Teaming
Goal-oriented emulation that tests detection and response across people, processes, and technology.
MITRE ATT&CK
A taxonomy of tactics and techniques used to plan, execute, and report emulation.
C2 & Malleable C2
Frameworks manage beacons; Malleable C2 shapes network indicators to blend with normal traffic.
OPSEC
Dedicated infra, plausible domains, and low-noise techniques protect the exercise's validity.
Common Mistake
Noisy tests that trigger easy alerts, which do not validate detection of stealthy adversary tradecraft.
Purple Teaming
Collaborative debrief to convert red findings into tuned detection rules and telemetry improvements.
Summary

Plan with ATT&CK, use OPSEC and Malleable C2 responsibly, and close the loop with purple teaming to improve detection and response.
