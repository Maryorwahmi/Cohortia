Module 08 › Chapter 8.7 › Pen Test vs Red Team
Definition

Penetration Testing

A scoped assessment to identify and exploit vulnerabilities for remediation.

Scope: defined boundaries and assets
Success: list of vulnerabilities and proof-of-concept
Reporting: remediation-focused
Example
A tester finds an unpatched web server and provides steps to patch and harden it.
Definition

Red Teaming

A goal-driven simulation that evaluates detection, response, and resilience across people, processes, and technology.

Scope: minimal prior knowledge, black/grey-box approach
Success: objective reached or defensive failure identified
Reporting: attack path, detection gaps, and remediation for processes and telemetry
Example
A team attempts to gain domain admin privileges and measures detection and containment steps by defenders.
Key Takeaway

If your goal is to improve detection and response, choose red teaming and measure telemetry and processes, not just patched vulnerabilities.

Common Mistake
Running noisy, unopsec tests that trigger alarms and do not reflect realistic attacker behavior.
