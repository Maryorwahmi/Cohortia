Overview

Cobalt Strike, Empire, Metasploit

These frameworks provide payloads, beacons, and server components to coordinate agents and perform post-exploitation tasks.

Cobalt Strike: Beacon payloads and Malleable C2 for traffic shaping.
Empire: PowerShell-first open-source framework for post-exploitation.
Metasploit: Exploit framework with Meterpreter for session control.

Decision card
Choose tooling based on required features, OPSEC needs, and the ability to shape traffic to match the environment under test.
Caution

Tools without careful configuration often produce recognizable, noisy indicators that do not reflect real adversaries.
