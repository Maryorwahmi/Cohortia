Example plan
Objective: exfiltrate customer records.
Initial access: T1078 Valid Accounts (preferred) ; alternate: T1566 Phishing. Follow with discovery techniques to find shares, use T1055 process injection if needed for persistence, then collection and exfiltration steps.
Mapping artifact
Step 1: Initial Access - T1078
Step 2: Discovery - T1046
Step 3: Collection - T1115
Step 4: Exfiltration - T1041
Detection checklist
  • Monitor authentication anomalies for valid account misuse.
  • Alert on unusual large uploads to external services.
  • Log process injection and suspicious PowerShell activity.
Pro tip

Design alternates ahead of time. If the preferred vector fails, that branch will keep the exercise realistic rather than forcing noisy workarounds.
