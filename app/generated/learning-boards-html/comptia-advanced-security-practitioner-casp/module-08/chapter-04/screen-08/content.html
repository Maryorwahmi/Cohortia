Module 08 › Chapter 8.4 › Cross-Site Scripting (XSS)
What XSS does

Injects client-side script into web pages so attackers can execute code in other users' browsers, potentially stealing cookies or performing actions on behalf of the user.

Variants
Reflected, stored, and DOM-based. Store and reflect affect server responses; DOM-based runs entirely in client JS.
Safe example payload
A non-destructive alert demonstration proves script execution without exfiltration in a lab.
Remediation checklist
  • Apply context-aware output encoding for HTML, attributes, and JS contexts.
  • Use Content Security Policy to reduce impact of injected scripts.
  • Validate inputs but encode at render time as the canonical defense.
Key Takeaway

Encode user data when rendering, and use CSP to limit script execution; input validation alone is insufficient.
