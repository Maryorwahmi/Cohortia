Module 08 › Chapter 8.4 › Broken Access Control
Definition

ID tampering and missing checks

Change resource identifiers and validate whether the server enforces object-level authorization. If not, you can access others' data or perform unauthorized actions.

Concrete example

Request /api/users/123 then modify the path to /api/users/124 in an intercepted request. If you receive the full profile for 124, the endpoint is missing authorization checks.

Common mistake

Relying on obscured or sequential IDs as a control instead of enforcing server-side authorization.

Testing steps
  1. Intercept the request retrieving a resource.
  2. Change the identifier to another value and send the request.
  3. Observe whether the response returns data for the modified identifier.
  4. Report with original and modified requests and the responses showing unauthorized access.
Remediation
Add server-side, object-level authorization checks and centralize enforcement in middleware or service layers; never rely on client obfuscation.
