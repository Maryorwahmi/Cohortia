Module 08 › Chapter 8.4 › Remediation Strategies
SQL Injection

Use parameterized queries, validate inputs as data, and restrict DB privileges.

XSS

Apply context-aware output encoding and implement CSP; sanitize inputs when appropriate.

Broken Access Control

Enforce object-level authorization server-side and centralize checks in middleware.

Acceptance criteria
  • Provide code changes that use secure patterns (e.g., prepared statements).
  • Demonstrate tests that confirm payloads no longer change behavior.
  • Confirm no regression across related endpoints and that logging captures attempts.
