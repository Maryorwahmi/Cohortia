Module 08 › Chapter 8.4 › APIs & SPAs
API testing

Capture API calls, craft JSON requests with tools or curl, and modify identifiers and fields to test authorization and data exposure.

Key checks
BOLA/IDOR, excessive data exposure, rate limits, auth enforcement.
Report
Include request/response pairs and minimal reproduction steps.
SPA testing

Inspect JavaScript bundles for secrets or logic assumptions and tamper with client-side state to see if server-side checks exist. SPAs often call APIs directly and may expose unprotected endpoints.

Common mistake
Assuming client-side controls prevent abuse; enforce authorization and validation on the server.
