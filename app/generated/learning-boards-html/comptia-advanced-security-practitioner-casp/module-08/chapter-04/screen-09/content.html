Intercepting Proxy

Burp sits between the browser and server. Install the CA cert to decrypt HTTPS in a controlled lab so you can see and modify traffic safely.

Repeater
Manual modify-and-send to refine payloads and understand server responses.
Intruder
Automate supplied payloads for fuzzing or brute-force tests with careful throttling.
Scanner
Automated discovery of common issues; validate findings manually.
Sequencer
Analyze token randomness to detect predictable session values.
Workflow example
  1. Configure browser proxy and install CA cert.
  2. Intercept a request and send to Repeater to craft payloads.
  3. Use Intruder to extend tests where automation helps, and Sequencer to analyze tokens.
  4. Document reproducible requests and recommended fixes.
Testing etiquette
Throttle automated tests, avoid destructive payloads, and work in sandbox environments to prevent data loss or service disruption.
