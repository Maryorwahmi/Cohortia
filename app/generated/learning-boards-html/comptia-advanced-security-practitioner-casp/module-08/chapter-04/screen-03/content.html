Objective 1: Proxy configuration

Configure your browser to proxy through the intercepting tool and install its CA certificate so HTTPS can be inspected safely in a controlled lab.

Mnemonic
Set proxy → Install CA → Intercept
Why it matters
Intercepting lets you see raw requests and responses and test how the server reacts to altered inputs.
Objective 2: Use Repeater & Intruder

Use Repeater for focused, manual request modification and Intruder for controlled automation such as fuzzing or credential testing. Understand when automation supports, not replaces, manual reasoning.

Mnemonic
Probe → Confirm → Automate
Misconception
Automated scanners miss logic flaws; manual probing is essential for complex vulnerabilities.
Objective 3: API & SPA testing

Test APIs by crafting JSON requests with tools like curl or Postman and intercepting them with your proxy. For SPAs, inspect JavaScript for sensitive information and test client-side logic for tampering.

Mnemonic
Inspect → Alter → Validate
Safety note
Avoid destructive payloads and always test in an isolated environment.
