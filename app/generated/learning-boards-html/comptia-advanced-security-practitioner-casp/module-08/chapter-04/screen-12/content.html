Module 08 › Chapter 8.4 › Repeater Lab
Steps
  1. Configure browser proxy and install CA cert for HTTPS interception in a lab environment.
  2. Open a product page and capture the GET request in the proxy.
  3. Send the request to Repeater and change id=123 to id=124.
  4. Send the modified request and compare the responses to identify unauthorized access.
Safety note
Do not run this against production systems. Avoid destructive or privacy-invasive payloads during tests.
# Conceptual curl equivalent
curl "http://target.com/product?id=123"

# Modified to simulate Repeater change
curl "http://target.com/product?id=124"

# If the response for 124 returns protected data, the endpoint lacks object-level authorization.
Document
Include original and modified requests and both responses in your report.
Recommend
Add server-side authorization checks that bind access to the authenticated actor.
