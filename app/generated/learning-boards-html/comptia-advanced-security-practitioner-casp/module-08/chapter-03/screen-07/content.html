Module 08 › Chapter 8.3 › Module Selection
Step-by-step checklist
1
Recon: confirm software and version
Verify banners, headers, and other indicators before assuming a vulnerability exists.
2
Search for a precise module
Prefer modules that explicitly mention the target version or environment.
3
Inspect options and requirements
Use show options and read module documentation for prerequisites and side effects.
4
Set RHOSTS, RPORT, and any target fields
Confirm the exact IPs and ports are within scope and correct.
5
Choose and configure payload
Select a payload aligned with your proof goals and set listener options like LHOST and LPORT.
6
Validate reachability and scope
Confirm network rules allow the callback and that the target is authorized for testing.
Examples and checks
Example
If a module requires a path argument, confirm the application exposes that path before attempting exploitation.
Common error
Setting LHOST incorrectly so the callback never reaches the listener; validate interfaces and NAT settings first.
Key Takeaway

Follow a checklist to avoid careless misconfiguration and accidental impact outside scope.
