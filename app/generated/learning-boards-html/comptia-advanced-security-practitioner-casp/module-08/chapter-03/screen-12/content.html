Module 08 › Chapter 8.3 › Ethical & Legal
Core requirements
  • Explicit written authorization that names assets and activities.
  • Clear Rules of Engagement including allowed and forbidden techniques.
  • Defined reporting requirements and cleanup expectations.
  • Escalation path for accidental outages or sensitive discoveries.
Common error
Assuming verbal approval covers all activities. Always secure written and signed RoE before testing.
Scenario and guidance
If a client asks for a full audit including employee behavior, clarify social engineering limits and get explicit consent for any phishing. If they want domain admin proof, consider a red team exercise with extended scope and coordinated detection testing.
Key Takeaway

Protect yourself and the client with written scope and RoE. When in doubt, pause and seek clarification before proceeding.
