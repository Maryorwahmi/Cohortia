Module 08 › Chapter 8.3 › Assessment Types
Comparison overview
Understand how scope, depth, and objectives shape each activity’s value.
Vulnerability Scanning
Automated, broad, and identifies known CVEs. Good for inventory and baseline remediation planning.
Penetration Testing
Targeted exploitation to prove impact for prioritized systems. Manual steps show real risk and exploitability.
Red Team
Goal-based, persistent, and broader tactics including social engineering and physical elements when needed.
Concrete example
A scan flags an outdated web library; a pen test crafts a working exploit to obtain a shell; a red team uses that shell plus phishing to reach domain credentials and exfiltrate data.
Common mistake
Running a full exploit against production without written scope. Always confirm RoE and schedule maintenance windows where needed.
Decision guide
  • Need quick inventory? Use vulnerability scanning to find surface issues.
  • Need proof of exploitability? Use penetration testing focused on specific critical assets.
  • Need to test detection and response? Use red teaming with explicit objectives and longer timeframes.
Key Takeaway

Pick the assessment that matches the organization’s objectives and prepare authorization accordingly.
