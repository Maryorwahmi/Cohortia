Module 08 › Chapter 8.1 › Vulnerability Management Lifecycle
Process Steps
A step-by-step sequence you will apply
1. Asset Inventory & Discovery
Enumerate hosts, cloud resources, and applications to build a single source of truth.
2. Vulnerability Identification
Use automated scanners to surface missing patches, misconfigurations, and default credentials.
3. Assessment & Prioritization
Score findings using CVSS and business context to determine remediation order.
4. Remediation
Patch, change configuration, or apply compensating controls with assigned owners.
5. Verification & Monitoring
Re-scan and review metrics to ensure vulnerabilities are closed and program improves over time.
Key Takeaway

A lifecycle turns detection into measurable risk reduction; skipping verification creates false confidence.

Process visualization

Identify
Automated tools find known issues; results require validation.
Assess
CVSS and context drive priority instead of raw severity alone.
Common-mistake: treating every high-severity finding identically. Contrast: a high CVSS on an isolated test server often deserves lower urgency than a medium CVSS on a public production server that processes sensitive data.
