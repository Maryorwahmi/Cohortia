Module 08 › Chapter 8.1 › Vulnerability Identification
Scanner types and modes
Automated tools plus manual follow-up where needed
Automated scanners
Nessus, Qualys, OpenVAS compare targets to vulnerability databases and produce findings for review.
Unauthenticated scans
Simulate an external attacker; useful for public exposure discovery.
Authenticated scans
Use credentials to inspect internal state and reduce false positives.
Manual testing
Human analysis for business logic, authorization, and complex exploitation paths.
Scan configuration snippet (illustrative)
<scan-config>
  <target>app.example.com</target>
  <mode>authenticated</mode>
  <credentials>service-account</credentials>
  <checks>patches,misconfigurations,defaults</checks>
  <schedule>weekly</schedule>
</scan-config>
Note: protect credentials used for authenticated scans and document scope. Avoid running heavy authenticated scans during peak production hours; schedule accordingly to balance coverage and performance impact.
