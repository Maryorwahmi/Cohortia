Module 08 › Chapter 8.1 › Asset Inventory & Discovery
What counts as an asset?
Servers, containers, cloud resources, network devices, and applications.
Discovery techniques
  • Network host discovery using scanning tools.
  • Cloud inventory via provider APIs for cloud instances.
  • Application and container registries for higher-level assets.
Essential metadata
Owner, environment, criticality, exposure, and sensitivity fields that support prioritization.
Common mistake
Fragmented lists across teams leave unmanaged assets unprotected. Automate updates to avoid drift.
Why it matters

Inventory drives coverage. If discovery misses an asset, downstream scanning, remediation, and verification cannot protect it.

Practical example
A cloud account contains a forgotten pre-production virtual machine that is internet accessible. Discovery via the cloud provider API finds it and adds it to inventory with owner, environment, and exposure flags. This entry triggers weekly authenticated scanning and assigns a remediation owner.
Check your understanding: When you find an asset with no owner, the correct next step is to escalate and assign ownership rather than deferring remediation; ownership ensures accountability and tracking.
