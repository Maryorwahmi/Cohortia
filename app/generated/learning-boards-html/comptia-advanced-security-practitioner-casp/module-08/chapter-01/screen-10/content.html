# Section 4: Vulnerability Scanning and Remediation for Internet-Facing Web Applications

## 4.1 Scope
This policy section applies to all internet-facing web applications owned or operated by the organization, including those hosted on-premises or in public cloud environments.

## 4.2 Scanning Frequency
Authenticated scans: weekly for in-scope web applications.
Unauthenticated scans: monthly for external exposure checks.

## 4.3 Remediation Timelines
Critical: remediate within 24 hours.
High: remediate within 72 hours.
Medium: remediate within 30 days.
Low: remediate within 90 days or during scheduled maintenance.

## 4.4 Roles and Responsibilities
Application Owners: implement remediation.
Vulnerability Management Team: perform scans and track remediation.
Internal Audit: periodically verify remediation effectiveness.
Use SOPs to operationalize these statements so each scan and remediation action has clear, repeatable steps and required evidence for auditors.
