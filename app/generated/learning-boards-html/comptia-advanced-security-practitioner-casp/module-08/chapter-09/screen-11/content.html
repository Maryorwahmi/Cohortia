Module 9 › Chapter 8.9 › Monitoring & KPIs
Key monitoring tools
  • SIEM for event aggregation and alerting.
  • EDR for endpoint detection and containment.
  • Cloud posture management for misconfiguration detection.
Feedback loops

Feed assessment results back into pipelines, policy, and training so fixes become preventive controls.

Suggested KPIs
Average time to patch critical vulnerabilities
Percentage of systems with up-to-date agents
Number of repeat findings per application
Reporting cadence

Report KPIs monthly to operations and quarterly to leadership, and use them to set improvement targets.
