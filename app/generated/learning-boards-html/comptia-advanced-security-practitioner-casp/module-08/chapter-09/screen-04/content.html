Module 9 › Chapter 8.9 › Effective Security Assessment Reports
Report Anatomy
Executive Summary

Top risks, business impact, three recommended actions with timelines.

Technical Appendix

CVE identifiers, PoC, affected hosts, remediation steps, and evidence for implementers.

Prioritization Table

Rank findings by business impact and expected exploitability to allocate resources.

Key takeaway

Each finding should map to a single, actionable remediation task with verification steps.

Example: Finding Entry
Title: Remote command injection in web component
  • CVE: CVE-YYYY-XXXX
  • Affected host: prod-web-01 (customer portal)
  • Business impact: exposure of payment data
  • Remediation: apply vendor patch version 2.1.4 and restart service
  • Verification: run authenticated test case and confirm no PoC
Common mistakes
Too technical in executive summary.
Too vague in technical steps—no verification method.
