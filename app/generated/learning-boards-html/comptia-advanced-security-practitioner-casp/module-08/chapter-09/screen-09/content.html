Module 9 › Chapter 8.9 › Compensating Controls
Common compensating controls
  • Network segmentation and access restrictions.
  • Web Application Firewall to filter exploit traffic.
  • Tightened configuration and service hardening.
  • Enhanced logging and detection rules.
Example scenario
Legacy app cannot be patched immediately

Apply network segmentation and a WAF, increase logging for the app, and set a POAM milestone for replacement. Verify by external scans, attack simulation, and log review.

Misconception

Do not treat compensating controls as permanent; treat them as documented interim measures with an expiration and monitoring.
