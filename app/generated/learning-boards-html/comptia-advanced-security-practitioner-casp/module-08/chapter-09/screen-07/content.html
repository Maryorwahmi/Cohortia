Remediation steps
1. Create remediation ticket with full finding details and CVSS.
2. Assign owner and set milestones with dates.
3. Evaluate fix: patch, config change, or compensating control.
4. Define verification steps and close ticket after validation.
POAM example
Finding: Legacy app with unpatched vulnerable library
  • Owner: App Team Lead
  • Milestone 1: Implement network segmentation (30 days)
  • Milestone 2: Test segmentation and review logs (45 days)
  • Compensating control: WAF in front of the app until patch available
  • Verification: External scan shows no remote access to vulnerable endpoint
Common mistake

Listing tasks without a measurable verification step prevents reliable closure; always define the proof-of-fix.
