Module 9 › Chapter 8.9 › Patch Management
Patch lifecycle
  1. Inventory and classify assets by criticality.
  2. Test updates in a staging environment aligned to production.
  3. Deploy via controlled channels and maintenance windows.
  4. Verify with scans and roll back if needed.
Emergency process

Define an expedited workflow for exploited vulnerabilities including immediate testing, rapid deployment, and communications to affected teams.

Practical checklist
  • Map top assets and owners.
  • Define cadence per criticality (emergency, monthly, quarterly).
  • Document rollback and verification steps.
  • Record compensating controls for unpatchable systems.
Key takeaway

Testing and verification are as important as deployment; a patch without verification leaves risk unmeasured.
