Module 08 › Chapter 8.8 › Configuration Audits
Concept

Compare system configurations to a known secure baseline. Capture deviations, assign risk, and remediate with verification evidence.

Tooling
Use automated scanners and configuration management to enforce and report on baselines.
Common mistake
Relying only on one-off manual checks that cannot show consistent enforcement over time.
Key Takeaway

Automate configuration audits and keep baseline definitions alongside scan outputs to provide clear audit evidence.

Conceptual command checks
# Example: Basic Linux configuration check (conceptual)
# Check for strong password policy in /etc/login.defs
grep -E "PASS_MAX_DAYS|PASS_MIN_DAYS|PASS_WARN_AGE" /etc/login.defs

# Check for SSH root login disabled in /etc/ssh/sshd_config
grep "PermitRootLogin" /etc/ssh/sshd_config
# Expected output: PermitRootLogin no

# Check for firewall status (e.g., using firewalld)
sudo firewall-cmd --state
sudo firewall-cmd --list-all
Capture these outputs and include them with the baseline reference. Auditors will compare the output to the expected secure values.
