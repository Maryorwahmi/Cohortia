Module 08 › Chapter 8.8 › Log Analysis
Log management essentials
  • Centralized collection and consistent timestamps
  • Correlation and alert rules that surface meaningful events
  • Retention policies aligned with compliance requirements
Include alert definitions and ticketing records with log excerpts so auditors can see detection, investigation, and remediation as a single traceable flow.
Simulated log excerpt
Mar 15 10:30:05 webserver sshd[12345]: Failed password for invalid user admin from 203.0.113.4 port 54321 ssh2
Mar 15 10:30:10 webserver sshd[12346]: Accepted password for root from 192.168.1.10 port 12345 ssh2
Mar 15 10:30:15 webserver sudo:    john : TTY=pts/0 ; PWD=/home/john ; USER=root ; COMMAND=/bin/cat /etc/shadow
Mar 15 10:30:20 webserver sshd[12347]: Accepted password for admin from 203.0.113.5 port 67890 ssh2
Use this excerpt with an alert definition (e.g., failed admin attempts) and an incident ticket to show auditors that detection triggered investigation and response.
Check your understanding

Does the failed admin attempt include username and source IP? Is there any evidence of admin login from an external IP that could be a policy violation?
