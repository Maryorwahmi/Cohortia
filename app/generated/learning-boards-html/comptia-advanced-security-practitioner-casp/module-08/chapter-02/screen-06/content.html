Definition
Network Scans — What They Check
Detect services, versions, known CVEs, weak protocols, and misconfigurations across hosts and devices.
Common checks
  • Open ports and service detection
  • Version mapping to CVEs
  • Weak protocol or cipher detection
  • Default or weak credentials
Example finding
SSH server supports older MAC algorithms; recommended action is to update server configuration to strong algorithms.
Practical step: initial discovery
sudo nmap -sV -p 22,80,443 192.168.1.0/24
# -sV probes to identify service/version
# limit ports to reduce noise
Key Takeaway

Use discovery scans to scope targets, then run credentialed checks where appropriate. Avoid intrusive plugins on production without authorization.
