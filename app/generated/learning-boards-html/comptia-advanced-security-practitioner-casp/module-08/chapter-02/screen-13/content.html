CI/CD Integration: Trivy Example
Scan images during build; fail only on defined severity thresholds to keep the pipeline actionable.
Pipeline snippet
build_and_scan:
  stage: build
  script:
    - docker build -t my-app:latest .
    - docker run --rm -v $PWD:/root/.cache aquasec/trivy:latest image --severity HIGH,CRITICAL my-app:latest
    - if [ $? -ne 0 ]; then echo "Vulnerabilities found, failing build!"; exit 1; fi
Concrete example
If Trivy finds a critical OpenSSL CVE in the base image, the build fails and the developer updates the base image or applies an alternative patch before retrying the pipeline.
Key Takeaway

Automate image scanning in CI with clear severity policies. Fail builds on critical issues and generate tickets for lower-severity findings.
