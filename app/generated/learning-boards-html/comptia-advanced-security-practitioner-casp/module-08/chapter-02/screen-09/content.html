Configuring Nessus and Discovery
Plan credentials, discover targets, then run tuned authenticated scans.
Credential guidance
  • Create scanner accounts with just enough privileges to enumerate packages and read configs.
  • Store credentials securely and rotate regularly.
  • Test credentials on a non-production host first.
Discovery example (terminal)
sudo nmap -sV -p 22,80,443 192.168.1.0/24
# -sV probes services for version info
# limit ports to reduce impact
Nessus scan config (mockup)
Targets: 192.168.1.50-192.168.1.80. Policy: Advanced Scan (non-intrusive plugins enabled). Credentials: SSH key for account 'scanner' with inventory privileges only.
Key Takeaway

Discovery first, then credentialed checks. Tune policies to avoid intrusive checks on production systems.
