Architecture
Container & Cloud Scanning
Image scanning finds package CVEs; cloud config scanning detects risky policies and public services.
Container example
Trivy flags a deprecated OpenSSL library in a base image; fix by updating base image and rebuilding.
Cloud example
Scanner finds a storage bucket with public read permission. Action: review policy and restrict to required principals.
CI integration pattern
Scan images during build. If severity >= HIGH, fail the build and notify developers to remediate before deployment.
Key Takeaway

Scan containers and cloud settings early. Scans inform patching and policy changes, and prevent insecure artifacts from reaching production.
