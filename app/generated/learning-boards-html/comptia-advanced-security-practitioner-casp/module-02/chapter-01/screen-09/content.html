Securing Switches: Port Security and VLANs

Controlling Access and Isolating Network Segments

Port Security

Limits the number of MAC addresses that can connect to a switch port, preventing unauthorized device access. Violation actions include restrict, protect, or shutdown.

Example

Configuring a port to allow only one specific MAC address ensures only the authorized workstation can connect.

VLAN Segmentation

Divides a physical network into multiple logical broadcast domains, isolating sensitive systems and limiting lateral movement for attackers.

Example

Creating a dedicated VLAN for financial application servers isolates them from general user traffic, even on the same physical switch.

Common Mistake

Neglecting to implement port security or VLANs, leaving internal network segments vulnerable to unauthorized access and internal threats, allowing attackers to move freely.
