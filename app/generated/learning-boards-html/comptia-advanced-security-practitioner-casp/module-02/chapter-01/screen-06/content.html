Intrusion Detection vs. Prevention Systems

Monitoring for Threats vs. Actively Blocking Attacks

Intrusion Detection System (IDS)

  • •Passive Monitoring: Observes network traffic without interfering.
  • •Alerts Administrators: Notifies security teams of suspicious activity.
  • •Visibility: Provides insights into potential threats and anomalies.
Role

Acts like a silent alarm, detecting threats and providing alerts for investigation.

Intrusion Prevention System (IPS)

  • •Active Intervention: Blocks or prevents detected threats in real-time.
  • •In-line Deployment: Sits directly in the network path to enforce policies.
  • •Enforcement: Provides immediate protection against active attacks.
Role

Acts like a security guard, actively stopping intruders and preventing attacks.

Concrete Example

An IDS might detect a series of failed login attempts against a server and alert an administrator, while an IPS would automatically block the source IP address after a predefined number of failed attempts, preventing a brute-force attack.
