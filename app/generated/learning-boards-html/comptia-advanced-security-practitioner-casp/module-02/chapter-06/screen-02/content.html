Learning Objectives
Bloom pathway: Learn → Understand → Apply → Master
01
Integrate SAST & DAST
Run SAST on commits and DAST in staging to catch code and runtime issues early. This reduces remediation cost and improves release confidence.
Verified Competency Milestone
02
Implement IAST & RASP
Deploy agents for in-context detection and active runtime protection to reduce false positives and block attacks in production.
Verified Competency Milestone
03
Configure WAFs & API Gateways
Use perimeter controls to block common web attacks and enforce auth and rate limits for APIs without changing app code.
Verified Competency Milestone
04
Design DevSecOps Pipeline
Automate SAST, dependency and container scanning, DAST in staging, and runtime monitoring so security scales with delivery.
Verified Competency Milestone
