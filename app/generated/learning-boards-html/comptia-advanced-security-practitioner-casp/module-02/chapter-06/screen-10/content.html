Comparison
SAST · DAST · IAST · RASP
SAST
White-box, finds code patterns, fast feedback in CI, misses runtime configs.
DAST
Black-box, tests running app, finds runtime issues and auth flaws, slow for deep scans.
IAST
Hybrid, traces execution and maps to code, high-confidence findings with context.
RASP
Runtime protection, blocks attacks in real time, acts as mitigation while fixes are deployed.
Concrete scenario
SAST flags SQL concatenation on a PR, DAST demonstrates exploitability in staging, IAST shows the request path in code, and RASP blocks similar requests in production while the fix is deployed.
Misconception
No single tool is sufficient; combine tools to cover code, runtime, and active defense.
