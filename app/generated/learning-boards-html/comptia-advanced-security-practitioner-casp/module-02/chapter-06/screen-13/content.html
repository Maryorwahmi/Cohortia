Hands-on Activity
Design a DevSecOps pipeline
Outline stages and list which security tools run at each stage. Consider scan duration, developer feedback, and operational readiness.
Plan & Code
Threat modeling and lightweight SAST on workstations and PRs for rapid feedback.
Build (CI)
Full SAST, dependency scanning, and container image scanning; gate critical issues.
Test & Staging
DAST and IAST to validate exploitability and produce contextual findings for remediation.
Release
Deploy WAF and API Gateway with policies before routing production traffic.
Operate
Enable RASP if required and forward all telemetry to SIEM for correlation and incident response.
Key Takeaway

Map each tool to the stage where it gives the most actionable context and lowest remediation cost, and automate feedback into developer workflows.
