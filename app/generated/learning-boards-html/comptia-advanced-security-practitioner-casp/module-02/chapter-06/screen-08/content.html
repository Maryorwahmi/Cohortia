Definition
API Gateway
A centralized service that manages API traffic, providing auth, rate-limiting, and routing for microservices.
Common functions
  • Authentication and authorization enforcement for all API calls.
  • Rate limiting and quota enforcement to protect backend services.
  • Centralized logging and observability for API calls.
Scenario
Use an API Gateway to reject unauthenticated requests and apply rate limiting to prevent abusive clients from overwhelming services.
Pro Tip
Combine gateway policies with WAF rules for layered defenses: WAF for general attack patterns, gateway for API-specific auth and quotas.
Key Takeaway

API Gateways centralize security controls and observability for APIs; make them part of your deployment plan and monitoring strategy.
