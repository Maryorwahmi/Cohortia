Process Flow
Security tool placements in CI/CD
Plan & Code
Threat modeling, secure coding, lightweight SAST on workstations and PRs.
Build (CI)
Automated SAST, dependency scanning, container image scanning; gate merges on critical findings.
Test (Staging)
DAST and optional IAST agents run against deployed staging instances, plus manual pentests.
Release & Operate
Deploy WAF and API Gateway before routing traffic. Enable RASP and forward logs to SIEM for monitoring.
Example
Light SAST on PRs, full SAST on CI, quick DAST on merge, nightly deep DAST and IAST in staging.
Balance
Trade scan depth with pipeline speed: gate critical issues, schedule expensive scans off-peak.
Pitfall
Adding tools without automation or developer workflows creates noise and no real protection.
