Module 2 › Chapter 2.2 › Directory Services Integration
Core idea

AD & LDAP sync

Synchronize the authoritative on-prem identity store to cloud directories and choose between federation or provisioning for authentication.

• Decide authoritative source and which attributes to sync such as UPN, email, and groups.
• Consider Azure AD Connect or agents to bridge AD to cloud IdPs.
• Plan schema extensions and test compatibility before deployment.
Security note
Directory servers must be hardened and segmented; they are prime targets because compromise can enable wide access changes.
Concrete example
Use Azure AD Connect to synchronize AD users and groups to Azure AD, then map the AD UPN to SAML NameID so cloud applications receive the expected identity claim.
Common mistake
Failing to include group membership or required attributes in sync results in authorization failures despite successful authentication.
Pro tip
Document attribute mappings and test with representative accounts before enabling production sync.
Key Takeaway

Treat directory integration as architecture work: plan attributes, test schema changes, and protect directory infrastructure as critical security assets.
