Module 2 › Chapter 2.2 › AD → Cloud SAML Integration
Prepare
  • • Ensure AD health and connectivity.
  • • Identify attributes to sync: UPN, email, groups.
  • • Enforce password policy and MFA where possible.
Deploy IdP
Install an agent like Azure AD Connect or an IdP connector and configure AD as the authoritative source for identities.
Configure SP
Provide the IdP metadata or SSO URL, issuer, and certificate to the cloud application. Ensure the application expects the correct attribute names such as NameID or emailaddress.
Map attributes
In the IdP, map AD attributes to the SP attributes and assign the correct users or groups.
Test & validate
Use a test user, verify assertion and attribute reception at the SP, and check IdP logs for signature and audience validation.
Common oversight

Missing group or attribute mapping often causes authorization problems even when authentication succeeds; include both authN and authZ checks in testing.
