Evaluate federation and SSO
Assess SAML and OIDC support, metadata handling, and how trust will be established. This matters because misconfigured trust can allow unauthorized access or break authentication flows.

02
Integrate MFA with SSO
Choose suitable factors and ensure MFA covers privileged accounts as well as user logins. Partial MFA is a common gap; broad coverage reduces credential theft risk.
Timeline mnemonic: Enforce → Verify → Rotate
VERIFIED COMPETENCY MILESTONE
03
Plan PAM integration
Identify privileged accounts, plan vaulting and session proxying, and require the strongest MFA for PAM administrators to protect that control plane.
Icon mnemonic: Key + Record

04
Design directory integration
Plan AD/LDAP synchronization and attribute mapping for hybrid and multi-cloud setups, ensuring consistent identities across systems to avoid access drift.

How to use these objectives

Use the objectives to guide hands-on activities: evaluate an IdP, configure an application for SAML, enable MFA for privileged accounts, and plan an AD sync strategy using tools like Azure AD Connect.
