Module 2 › Chapter 2.2 › Onboarding Privileged Accounts to PAM
Step-by-step
  1. Discovery: inventory admin, root, and service accounts.
  2. Mapping: identify where credentials are used and by what systems.
  3. Vaulting: store credentials in PAM and disable direct usage.
  4. Proxying: enable proxied sessions and recording.
  5. Rotation: set automated rotation and alerts.
Common pitfall
Missing credentials in scripts and service configurations delays rollout; include application owners early.
Concrete example
A database admin account embedded in application config is migrated into PAM: the app calls a secure retrieval API to get short-lived credentials, removing the static secret from the repository.
Pro tip
Automate credential retrieval for applications using secure APIs so rotation does not break services.
Checklist
Inventory, owner sign-off, test proxied sessions, verify recordings, enable rotation, and monitor alerts.
Key Takeaway

Onboarding is an operational effort: plan discovery, app changes, and automation to realize diminished privileged credential risk.
