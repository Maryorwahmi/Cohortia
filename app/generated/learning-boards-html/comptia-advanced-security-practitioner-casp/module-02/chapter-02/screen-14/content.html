Module 2 › Chapter 2.2 › Security Implications & Mistakes
Common mistakes
  • • Not validating IdP certificates and metadata for SAML.
  • • Enabling MFA only for external users and not for privileged accounts.
  • • Missing attribute or group mappings when syncing directories.
Mitigations
Use defense-in-depth: segment identity infrastructure, require MFA, audit changes, and use IGA for entitlement hygiene.
Concrete example
A misconfigured SAML audience field allowed assertions intended for one app to be accepted by another. Proper audience validation and metadata checks prevent such cross-acceptance.
Checklist
Validate signatures, certificates, ACS URLs, attribute schemas, MFA enforcement, and PAM protections before go-live.
Pro tip
Regularly review IdP logs for anomalous authenticaton patterns and test PAM session recordings for completeness.
Key Takeaway

Treat integration as security-critical work: validate trust, enforce MFA widely, and monitor identity systems continuously.
