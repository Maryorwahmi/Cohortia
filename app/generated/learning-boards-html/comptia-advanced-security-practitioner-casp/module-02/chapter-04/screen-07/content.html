Module 2 › Chapter 2.4 › SaaS & CASB
SaaS security essentials
Focus on authentication, data governance, and activity monitoring for SaaS apps you do not control at the infrastructure level.
Authentication
Implement SSO and MFA via a corporate identity provider to centralize access control.
Data governance
Classify data, enforce DLP, and set retention and sharing policies inside SaaS tools.
Monitoring
Collect user activity logs and integrate with SIEM for anomalous behavior detection.
CASB deployment options
Compare proxy vs API modes and align choice to enforcement needs.
Proxy mode
Inline enforcement that blocks or encrypts traffic in real time. Higher complexity; best when inline control is required.
API mode
Uses SaaS APIs to inspect stored content and remediate. Easier to deploy for visibility into stored files but not inline session blocking.
Example

A CASB in API mode scans OneDrive for PII and quarantines offending files; in proxy mode it can block an outgoing email that contains detected PII.

Misconception

CASB does not replace SSO/MFA; it complements identity controls by enforcing data-level policies.
