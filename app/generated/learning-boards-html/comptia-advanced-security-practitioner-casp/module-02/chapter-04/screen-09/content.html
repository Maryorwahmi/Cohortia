Module 2 › Chapter 2.4 › CWPP
What CWPP provides
Vulnerability scanning, runtime protection, behavioral detection, and host-level controls for workloads in the cloud.
Deployment models
Agents on VMs, sidecars for containers, or orchestration integrations for Kubernetes.
Capabilities
Host firewalling, integrity monitoring, runtime blocking, and vulnerability management.
Scenario
A containerized app on Kubernetes: integrate the CWPP to monitor pod activity, detect surprising process execution, scan container images for known vulnerabilities, and apply policies to prevent privilege escalation.
Key takeaway

CWPPs supply runtime defenses and visibility; use agents or orchestration hooks where they provide the richest enforcement.

Misconception

Agentless monitoring gives visibility but often lacks the enforcement power of agents for runtime blocking.
