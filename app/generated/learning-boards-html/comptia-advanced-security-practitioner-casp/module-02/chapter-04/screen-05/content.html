Process: Secure an IaaS workload
A sequence you can repeat for VMs and other IaaS resources.
1. Network segmentation
Design VPC/VNet subnets and security groups to restrict traffic to necessary flows only.
2. IAM & roles
Use provider IAM roles and temporary credentials instead of embedded keys.
3. Host protection
Install CWPP agents, enable host firewalling, and automate patching.
4. Monitoring
Send logs to SIEM and enable cloud provider threat detection services for telemetry correlation.
Concrete scenario
You deploy an application on an AWS EC2 instance. Implement a security group that only allows the app port from the load balancer, assign an IAM role to access S3, install a CWPP agent for runtime protection, enable GuardDuty for threat detection, and forward logs to your enterprise SIEM.
Key takeaway

Redesign on-premises controls to use cloud-native features and automation for correctness and scale.

Common mistake

Expecting identical behavior from on-premises firewalls in cloud networks leads to policy gaps and false assumptions.
