Learning Objectives
Bloom: Learn → Understand → Apply → Master
Learn → Understand → Apply → Master
01
Design secure integration for IaaS/PaaS/SaaS
Learn to match controls to the service model and avoid lift-and-shift mistakes. Verified competency milestone: design a control mapping for one VM, one managed app, and one SaaS product.
02
Use CSPM and CWPP effectively
Understand scanning and runtime protection roles. Milestone: configure a CSPM read-only scan and describe CWPP agent placement on a VM.
03
Integrate CASB for SaaS governance
Enforce DLP, encryption, and policy enforcement for SaaS. Milestone: outline a CASB deployment for Microsoft 365 to prevent external PII sharing.
04
Secure hybrid connectivity and identity
Plan VPN/Direct Connect, identity sync, and unified data protection. Milestone: draft an architecture for hybrid SSO and encrypted data backups.
