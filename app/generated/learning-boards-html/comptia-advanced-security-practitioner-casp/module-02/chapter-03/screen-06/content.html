Parsing vs Normalization
Parsing
Extract raw fields from log messages: source_ip, username, event_id, bytes_transferred.
Normalization
Map parsed fields to canonical names and types so rules can compare events from different sources.
Practical validation
  • Run a query across multiple sources using the canonical field name to confirm matches.
  • Check timestamps are normalized to a consistent timezone and format for temporal correlation.
  • Ensure IP and username types are consistent (strings vs structured objects).
Key Takeaway
Both steps are required: parsing extracts data, normalization makes it comparable for reliable correlation.
