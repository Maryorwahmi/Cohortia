Comparison
Before vs After Enrichment
Enriched alerts carry context that changes severity and response urgency.
Raw Alert: Brute-force followed by login — needs manual context lookup.
Enriched Alert: Same sequence + IOC match + high-value asset → auto-escalate and trigger playbook.
Enrichment sources
  • Threat intelligence feeds (IP/domain/hash reputation)
  • Asset inventory (sensitivity, owner, criticality)
  • EDR telemetry and recent process/network activity
Example
A login to a database server that matches an IOC and shows suspicious endpoint behavior is prioritized higher and routed for immediate containment.
