Definition
Log Source Inventory & Prioritization
Capture every system that emits security telemetry and plan phased onboarding to protect critical assets first.
What to inventory
Firewalls, routers, servers, endpoints, applications, cloud APIs, IDS/IPS, EDR, DLP.
Formats & connectors
Syslog, Windows Event Log, JSON, vendor APIs; agents or API pulls may be required.
Priority checklist
Start with identity/auth logs, perimeter devices, and high-value servers; then bring in endpoints and cloud services.
Key Takeaway
A clear, phased inventory reduces missed telemetry and controls SIEM load so detection is reliable.
Practical checklist
Phase 1: Identity logs, perimeter firewalls — validate parsing and ingestion.
Phase 2: Endpoints and EDR — ensure agent compatibility and bandwidth planning.
Phase 3: Applications & DBs — handle proprietary formats or APIs.
Example scenario
Onboard Active Directory and perimeter firewall logs first, generate a test authentication failure and confirm it appears and normalizes correctly in the SIEM.
