Process
Design & Tune Correlation Rules
Hypothesis → event types → grouping keys → thresholds → test → iterate.
Step 1: Hypothesis
Describe the attacker steps you want to detect.
Step 2: Map events
Choose event types and canonical fields for grouping.
Step 3: Set thresholds
Use baselines to choose counts and time windows.
Step 4: Test & tune
Run against historical data and adjust thresholds and enrichment conditions.
Checklist to reduce false positives
  • Use asset sensitivity and user baselines as additional conditions.
  • Add threat-intel reputation checks before automatic escalation.
  • Log tuning changes and maintain a test dataset for regression checks.
Example
Adjusting a brute-force rule from 10 to 15 failed attempts after historical testing reduced noise on a busy VPN gateway.
