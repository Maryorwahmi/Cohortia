Conceptual correlation rule
The example uses count thresholds and temporal relationships to link failed attempts and a later successful login.
IF event.type == "auth_failure" AND count(source_ip) > 10 WITHIN 5 minutes GROUP BY target_username, source_ip AND THEN IF event.type == "auth_success" WITHIN 10 minutes AFTER previous WHERE source_ip != previous.source_ip OR source_location == "unusual" THEN generate alert severity: high enrich: query threat_feed for source_ip action: notify SOC; optional SOAR playbook trigger
Design tips
  • Define clear grouping keys such as target_username to tie events together.
  • Choose time windows appropriate for your environment and attack types.
  • Iterate thresholds using historical data to balance detection and noise.
Common misconception
Assuming one-size-fits-all thresholds; tuning must be environment-specific and based on baseline behavior.
