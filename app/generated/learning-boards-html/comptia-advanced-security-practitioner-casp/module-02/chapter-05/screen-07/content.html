Hunt: Suspicious PowerShell Execution

Build a focused query to detect script interpreters running from unusual paths with network activity or child processes.

Step 1: Define a time window and baseline for normal PowerShell usage.
Step 2: Search for process name containing powershell or pwsh and command lines with encoded content or download flags.
Step 3: Filter out known management accounts and legitimate admin tools.
Step 4: Enrich with network and file hash data, then pivot to related hosts.
Conceptual Query (pseudo)
process where process.name in ("powershell.exe","pwsh.exe")
  and process.command_line contains_any ("-EncodedCommand","Invoke-WebRequest","-NoProfile")
  and not process.parent in ("managed-svc.exe","automation-agent.exe")
  | where process.created_path not startswith "C:\\Program Files"
Investigator Notes
  • Start tight, then expand scope if you see patterns across hosts.
  • Use file hashes to query intelligence services and check for re-use.
  • Exclude legitimate automation tools to avoid noise.
Misconception

Broad hunts are less effective than iterative, refined hunts with enrichment and pivot steps.
