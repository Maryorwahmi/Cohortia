EDR Incident Investigation Steps

Investigation Steps
  1. Initial Alert: record host, user, and alert context.
  2. Containment Decision: isolate host if high risk.
  3. Process Analysis: examine parent-child chains and command lines.
  4. Network Review: list outbound IPs and ports for IOC checks.
  5. File & Registry: find new executables and persistence entries.
  6. Artifact Collection: memory or disk images when needed.
  7. Remediation: terminate, delete, scan, and restore.
  8. Post-Incident Review: update rules and playbooks.
Concrete Example: Windows Laptop
Alert: "Unusual PowerShell Execution". Actions: isolate host, inspect process tree showing outlook.exe→powershell.exe→cmd.exe, check network to unknown IP, remove run key persistence, collect memory if lateral movement suspected, reimage if root cause unknown.
Key Takeaway

A documented, repeatable checklist reduces mistakes and speeds recovery while preserving evidence for root-cause analysis.
