Process Flow

Alert to Remediation

1
Initial Alert
Collect host, user, and summary.
2
Contain
Consider isolation vs business impact.
3
Analyze
Process tree, network, files, registry.
4
Collect Artifacts
Memory, disk image when needed.
5
Remediate & Review
Terminate, clean, reimage, then update playbooks.
Concrete Scenario
Alert: "Malicious Process Detected" on a Windows laptop. Steps: isolate, analyze process tree for parent=outlook.exe spawning cmd.exe, check network connections, remove persistence entries, collect memory if lateral movement suspected, then return to service after monitoring.
Key Takeaway

A repeatable workflow reduces mistakes: triage, contain, analyze, collect, remediate, and learn.
