Module 1 › Chapter 1.2 › Data Collection Methods
Collection options
Decide by visibility and deployment pattern.
Agents / Exporters
Lightweight processes exposing host or service metrics, e.g., a node exporter for CPU and memory.
SDKs / Libraries
Instrument application code for business or request-level metrics; offers rich labels and context.
Sidecars
Containerized collectors used in orchestration platforms to centralize telemetry without changing application images.
Details & Example
Example scenario
For a Flask web app running in containers, use an SDK to count request latencies, node_exporter on the host for CPU, and an OpenTelemetry sidecar to forward logs and traces to a collector for enrichment.
Pro tip
Combine methods: exporters for system metrics, SDKs for business metrics, and sidecars for language-agnostic tracing.
Common mistake
Relying only on agents will miss application-level semantics that SDKs provide, making root cause analysis harder.
Key Takeaway

Pick a mix of collectors to capture both system and application semantics without duplicating effort.
