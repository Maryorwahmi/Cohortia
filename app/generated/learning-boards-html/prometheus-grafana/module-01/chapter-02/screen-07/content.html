Why process metrics?
Precompute expensive queries and enrich data to simplify analysis.
Recording rules example
A recording rule can take a raw counter and compute a per-minute rate, writing that result as a new series that dashboards can read directly.
Example
Precompute an HTTP error rate every 30 seconds and store it, reducing realtime computation cost on dashboards.
Enrichment
Add metadata like deployment id or region in a processing pipeline to make queries simpler and more selective.
Pitfall
Downsampling too aggressively loses the resolution needed for root cause analysis; keep high-resolution recent data long enough to debug incidents.
Quick checklist
  • Identify frequently used queries for recording rules.
  • Retain raw series for incident windows.
  • Enrich data near collection for consistent labels.
  • Document retention and downsampling policies.
Key Takeaway

Precompute heavy queries but keep raw data long enough for deep diagnostics.
