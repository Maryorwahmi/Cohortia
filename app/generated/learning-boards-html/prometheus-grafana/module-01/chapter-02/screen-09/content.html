Module 1 › Chapter 1.2 › Push vs Pull Collection Models
Pull model (scrape)
Monitoring server scrapes metrics endpoints exposed by targets.
Advantages
  • Simpler discovery and centralized scraping.
  • Targets need not know collection endpoints.
  • Easier firewall configuration in many cases.
Push model (pushgateway)
Targets push metrics to a gateway or collector for capture.
Advantages
  • Works well for ephemeral jobs that finish quickly.
  • Useful in environments with outbound-only network rules.
  • Supports disconnected or batch workflows.
Concrete example
Use node_exporter with a pull model to scrape host metrics, and Pushgateway for short-lived batch jobs that must publish final counts before exit.
Key Takeaway

Choose the model that matches your target lifespan and network topology; you can safely combine both patterns where needed.
