Minimal metrics endpoint (text)
A plain-text response lists metric samples and values.
# HELP http_requests_total Total HTTP requests
# TYPE http_requests_total counter
http_requests_total{method="GET",handler="/api"} 1027
# HELP cpu_usage_percent CPU usage percentage
# TYPE cpu_usage_percent gauge
cpu_usage_percent 72.5
This is the simple format a scraper parses. Use stable metric names, meaningful labels, and avoid labels with high cardinality such as unique request ids.
Guidance
  • Use descriptive metric names and unit suffixes.
  • Limit label values that vary per user or request.
  • Document metric semantics so dashboards and alerts are consistent.
Key Takeaway

A small, consistent metrics format enables reliable scraping and reduces cardinality risks.
