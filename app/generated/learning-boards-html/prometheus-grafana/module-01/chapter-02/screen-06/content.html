Module 1 › Chapter 1.2 › Time-Series Databases (TSDB)
What is a TSDB?
Focused on time-ordered data, compression, and range queries.
High write throughput
TSDBs are optimized for constant appends from many instruments.
Compression & retention
Use retention and downsampling to balance resolution against storage cost.
Query patterns
Range queries over time windows and aggregations are central to dashboards and alerts.
Scenario
If your application emits 1000 unique label combinations per second, multiply that by retention days to estimate required storage and query cost. High cardinality is the primary risk to TSDB scalability.
Key Takeaway

Size a TSDB based on expected write rate, cardinality, and retention; treat label cardinality as a primary cost driver.

Misconception
Don't assume a relational database will scale cost-effectively for continuous metric streams; it will slow as writes and scans grow.
