Practice steps

Inspect dashboards and queries

  1. Open a public Grafana demo and locate dashboards labeled Prometheus or Kubernetes.
  2. Change the time range to compare short-term spikes with longer trends.
  3. Use dashboard variables to filter to a single instance or namespace and observe panel updates.
  4. Inspect a panel’s query to see metric names and labels referenced by the dashboard.
Learning note
Dashboards are examples; they assume certain exporters and metrics exist. Use inspection to learn what to instrument in your systems.
Reflection questions
What metrics did the dashboard rely on? Which labels allowed filtering? Can you identify any metrics you would add to your application?
Key Takeaway

Exploration of demos teaches how dashboards map queries to visuals and which metrics and labels matter most.
