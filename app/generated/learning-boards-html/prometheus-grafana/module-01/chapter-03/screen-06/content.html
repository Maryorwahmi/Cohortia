Module 2 › Chapter 1.3 › Exporters & components
Definition

Key ecosystem components

Exporters
Adapters that expose metrics from systems like databases, hosts, or orchestration components in Prometheus format. Example: a node exporter for host metrics.
Pushgateway
Accepts pushed metrics from short-lived processes, so Prometheus can scrape them later. Use it for ephemeral jobs that cannot be scraped directly.
Alertmanager
Receives alerts from Prometheus, groups and deduplicates them, and routes notifications to receivers. Proper configuration avoids alert storms and noisy notifications.
Scenario
A nightly batch job pushes summary metrics to Pushgateway so its success rate is visible in Prometheus even after the job exits.
Misconfiguration risk
If Alertmanager routing is too broad, unrelated alerts may group together and cause confusion; design routes by team and severity.
Concrete example
Use a node exporter to expose CPU and memory metrics from hosts, kube-state-metrics to expose Kubernetes object health, and configure Alertmanager to route critical alerts to on-call channels while sending low-priority issues to a team inbox.
Key Takeaway

Use exporters to adapt systems, Pushgateway for ephemeral jobs, and Alertmanager to control how alerts reach responders.
