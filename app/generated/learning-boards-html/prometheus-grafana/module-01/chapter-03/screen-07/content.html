Module 2 › Chapter 1.3 › PromQL overview
Definition

Querying labeled time-series

PromQL helps you filter by metric name and labels, aggregate by dimensions, and compute derived values that drive dashboards and alerts.

Metric identity reminder
Remember the metric example with labels: http_requests_total with method, path, and status labels. PromQL uses that same identity to select matching series.
Where you use it
PromQL is used in dashboard panels and alerting rules so queries produce the numeric signals you visualize and act upon.
Concrete guidance
Example use
Filter a metric by path and compute rate over a time window to detect rising request rates for a particular endpoint.
Misconception
PromQL is not a log query language. Use it for numeric time-series; pair it with a log store when you need raw event details.
Practice tip
Start by identifying the metric name and labels you need, then write a focused selection before adding aggregations or transformations.
Key Takeaway

PromQL converts labeled metrics into meaningful signals for dashboards and alerts, but it is focused on numeric time-series rather than raw logs.
