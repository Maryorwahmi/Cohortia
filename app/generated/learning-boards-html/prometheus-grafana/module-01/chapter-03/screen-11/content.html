Use Case

Cluster observability workflow

Sources to scrape
kube-state-metrics for object health, node exporters for host metrics, and application endpoints for app metrics.
Alerting flow
Prometheus evaluates rules and sends alerts to Alertmanager, which groups and routes notifications to the right teams.
Investigation loop
An alert prompts an engineer to open Grafana dashboards that query Prometheus, visualize the metrics, and correlate signals to diagnose the root cause.
Common pitfalls
  • Not tuning retention or storage for expected data volumes.
  • Alert thresholds that are too sensitive, causing alert fatigue.
  • Using high-cardinality labels unintentionally.
Key Takeaway

Design scrapes, alerts, and dashboards together so detection and investigation form a smooth operational flow.
