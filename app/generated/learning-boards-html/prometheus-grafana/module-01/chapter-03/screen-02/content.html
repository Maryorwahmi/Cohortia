Learning Objectives

Build a mental map for Prometheus, Grafana, and their ecosystem.

Bloom: Learn → Understand → Apply → Master
01
Explain Prometheus
Describe its purpose, scraper model, and multi-dimensional metrics.
Mnemonic: labeled metric = name + labels (think tags)
VERIFIED COMPETENCY MILESTONE
02
Describe Grafana
Explain dashboarding, data source connectivity, and templating.
Mnemonic: dashboards = windows into your metrics
VERIFIED COMPETENCY MILESTONE
03
Identify components
Recognize exporters, Pushgateway, and Alertmanager and their roles.
Mnemonic: exporters expose, Pushgateway accepts, Alertmanager routes
VERIFIED COMPETENCY MILESTONE
04
Explain the stack synergy
Understand why Prometheus plus Grafana is a common monitoring combination.
Mnemonic: collect, query, visualize, act
VERIFIED COMPETENCY MILESTONE
Each milestone will be reinforced with examples and a short practical activity so you can connect the concept to a real cluster or demo dashboard.
