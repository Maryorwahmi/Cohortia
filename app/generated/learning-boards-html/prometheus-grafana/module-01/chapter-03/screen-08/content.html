Architecture

Visualization and data federation

Grafana connects to many data sources, queries them at panel time, and displays unified dashboards for analysis and incident response.

Dashboarding
Create panels for metrics and combine them to tell a system health story. Interactive features like time range selection help exploration.
Data source agnostic
Grafana queries Prometheus or other backends; it does not act as the primary storage for those sources.
Practical items
Templating
Use variables so dashboards can switch context between services or clusters without duplicating panels.
Alerting note
Grafana supports basic alerting on panels, but teams commonly rely on Alertmanager for complex routing and deduplication of alerts raised by Prometheus.
Key Takeaway

Treat Grafana as the visualization and exploration layer that queries your data where it lives and helps teams act on insights.
