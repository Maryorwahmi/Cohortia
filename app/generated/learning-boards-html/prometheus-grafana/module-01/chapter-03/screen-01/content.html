Quick scenario
Imagine a Kubernetes cluster where Prometheus scrapes kube-state-metrics and node exporter metrics, stores them locally, and exposes queries to Grafana. Grafana queries Prometheus and renders dashboards showing cluster health, request rates, and pod resource usage for on-call engineers to act on.
