Metric literal and meaning

Metric literal
http_requests_total{method="POST", path="/api/users", status="200"}
Read this as: total HTTP requests where method equals POST, path equals slash api slash users, and status equals two hundred.
Why labels
They let you filter and aggregate precisely, such as isolating error rates for a single endpoint or grouping by method for a service.
Cardinality warning
Avoid adding labels with many unique values, like user identifiers, unless you have a clear aggregation need.
Scenario
To calculate requests per second for that endpoint, you would select those labeled series and compute a rate over a short time window. This distilled signal is what you would display on a Grafana panel.
Key Takeaway

Choose labels that support useful aggregations; read metric literals aloud to avoid mistakes when writing queries or alerts.
