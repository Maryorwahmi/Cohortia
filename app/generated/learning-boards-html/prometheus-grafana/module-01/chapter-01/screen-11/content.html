Module 1 › Chapter 1.1 › Correlation IDs
Instrumentation architecture
Propagate a request-scoped ID across all service calls and include it in logs and spans.
  1. Generate or accept an incoming request ID.
  2. Attach it to logs, and span metadata, and thread it across async work.
  3. Avoid putting PII or secrets into the ID or span payloads.
Practical note
Make propagation part of middleware so it is consistent and less error-prone than ad-hoc instrumentation.
Scenario: missing propagation
If an ID is not present in a downstream job, logs become hard to correlate and traces may be partial. Test propagation across sync and async boundaries during deployment.
Do
Add propagation to middleware and workers.
Avoid
Using user identifiers or secrets as correlation keys.
