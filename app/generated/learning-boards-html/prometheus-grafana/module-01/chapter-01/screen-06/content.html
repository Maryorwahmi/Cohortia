Metrics & Labels
Numbers over time with labels for slicing and alerting.
Example metric lines
http_requests_total{method="PUT",status="500",endpoint="/profile"} 1 1698424205
profile_service_database_connection_errors_total 1 1698424205
These lines show the metric name, labels, value, and timestamp. Labels let you filter and aggregate without storing every event.
Use for
Trend analysis, alerting, dashboards, and impact quantification.
Watch out
High-cardinality labels can degrade storage and query performance.
Practical example
If http_requests_total for endpoint="/profile" drops to zero, metrics indicate the service is not receiving requests. If error_rate spikes, metrics show impact across instances and time windows. Combine with logs to see the exact error and traces to find the slow downstream call.
Pro Tip
Design labels for common operational slices: instance, endpoint, status. Avoid labels that vary per user or request identifier.
