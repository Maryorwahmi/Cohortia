Question 1
CPU at 90% but no function identified. Which pillar reveals the root cause?
Answer
Traces. Metrics show the symptom and timing; traces reveal which request or function consumed CPU across services.
Question 2
Design priorities for a new microservice: structured logs or business metrics first?
Recommended approach
Start with core business and system metrics for alerting and dashboards, and alongside them implement essential error logs with request IDs for debugging.
Reflection
Instrumentation choices should be revisited after incidents. Use real incidents to refine which labels, logs, and traces you need for efficient diagnosis.
