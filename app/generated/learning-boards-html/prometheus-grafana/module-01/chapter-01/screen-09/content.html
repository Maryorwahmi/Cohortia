Investigative steps
A consistent process helps you use the three pillars effectively.
1. Capture alert details: metric, timestamp, labels, affected service.
2. Scope logs to the alert window; find errors and request IDs.
3. Use request IDs to open traces and inspect spans for latency or failures.
4. Cross-check other metrics for systemic impact and document remediation steps.
Check your understanding
If you have an alert but no request ID in logs, consider whether your logging includes the required correlation data, and add minimal structured fields to support future troubleshooting.
