Data Snippet 1 — Log
2023-10-27T10:30:05.123Z ERROR [profile-service] [request-id: abc-123] Failed to update user profile for user_id: 456. Error: Database connection timeout.
This is a log entry. It contains an error message, a timestamp, service, and a request-id used to correlate across systems.
Data Snippet 2 — Metrics
Metric: profile_service_http_requests_total{method="PUT", status="500"}
Value: 1 (at 2023-10-27T10:30:05Z)

Metric: profile_service_database_connection_errors_total
Value: 1 (at 2023-10-27T10:30:05Z)
These metrics show counts at a timestamp and labels for slicing. They announce the error and its timing across the system.
Data Snippet 3 — Trace
Trace ID: abc-123
  Span 1: WebApp -> ProfileService (duration: 500ms)
    Span 2: ProfileService -> Database (duration: 450ms, error: true)
The trace links spans by the trace ID and shows which span experienced an error and where time was spent.
