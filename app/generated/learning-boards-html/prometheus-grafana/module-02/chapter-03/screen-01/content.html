Basic PromQL: Querying Your Metrics
Select metrics, filter with labels, use vectors and functions to compute rates and aggregates.

This lesson focuses on clear, repeatable query patterns you can use immediately in the Prometheus Graph. You will practice metric selection, label matching, range selections, and the key functions like rate and aggregation operators such as sum and avg. Each pattern includes a concrete example you can type into the Graph tab.
