Module 3 › Chapter 2.3 › Arithmetic
When to use arithmetic

Create percentages, normalize metrics across instances, or combine counters into totals. Always consider label alignment first.

Label matching caution

If two vectors have different label sets, the arithmetic may not match series as you expect. Use aggregation by() to align labels before arithmetic if needed.

Key Takeaway

Aggregate or align labels before arithmetic to ensure results represent the intended grouping.

Concrete example
100 - (avg by (instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)

This computes non-idle CPU percentage per instance by averaging the idle rate and converting to percent, then subtracting from 100.
