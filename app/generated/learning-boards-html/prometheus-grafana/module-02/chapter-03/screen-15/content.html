Inspect labels
Run the metric raw to discover labels and values before writing matchers or aggregations.
Vector types
Use range vectors for functions that need history; use instant for snapshot math.
Explicit aggregation
Always choose by() or without() to preserve or drop the labels you care about.
Final tip: experiment in the Prometheus Graph with short, incremental changes and confirm labels at each step to avoid surprises.
