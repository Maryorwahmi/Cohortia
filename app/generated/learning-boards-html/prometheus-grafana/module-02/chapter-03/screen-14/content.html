Module 3 › Chapter 2.3 › Key Concepts
PromQL
Functional language to select and aggregate time series from Prometheus.
Label Matchers
Use =, !=, =~, and !~ inside curly braces to filter series by label values.
Vectors
Instant vectors are single-sample; range vectors include a time window for functions like rate.
Aggregation
Use sum, avg, count with by() or without() to control grouping dimensions.
Rate & irate
rate() averages counter increases; irate() estimates instant rate using recent samples.
Pitfalls
Avoid rate on gauges, check label case, and verify aggregation scope to prevent surprises.
Summary: Inspect raw selectors, choose the right vector type, use functions appropriately, and control aggregation labels for predictable results.
