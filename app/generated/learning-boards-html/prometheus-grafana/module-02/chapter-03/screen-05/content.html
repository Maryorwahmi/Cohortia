Matcher quick reference
  • = exact equals, for example mode="idle"
  • != not equals, for example mode!="idle"
  • =~ regex match, for example mode=~"idle|user"
  • !~ regex negative match, for example mode!~"idle|user"
Why this matters

Match only the series you need before applying functions or aggregation. This keeps graphs readable and alerts accurate.

Common mistake

Assuming matchers are case-insensitive or that regex is implied. Explicitly use =~ for regex and respect case.

Concrete examples
node_cpu_seconds_total{mode="idle"}
node_cpu_seconds_total{mode!="idle", cpu="0"}
node_cpu_seconds_total{mode=~"idle|user"}

Try these in Graph to see how the returned series change. Notice label lists for each series so you can plan aggregation.
