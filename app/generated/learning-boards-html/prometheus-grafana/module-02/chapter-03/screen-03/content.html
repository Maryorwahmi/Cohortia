Practical Verifications
Short, repeatable checks to confirm each objective in the Prometheus Graph.
Metric selection
Type node_cpu_seconds_total, then add {mode="idle"} and observe filtered series.
Vectors
Add [5m] to a selector to create a range vector and feed it to rate() to check historical behavior.
Arithmetic
Compute memory usage percent by dividing used by total and multiplying by 100.
Aggregation
Run sum(node_cpu_seconds_total) by (mode) and compare to sum without a by clause to see label collapse.
Rates
Execute rate(http_requests_total[10m]) and compare to irate on a 1m window to feel smoothing differences.
