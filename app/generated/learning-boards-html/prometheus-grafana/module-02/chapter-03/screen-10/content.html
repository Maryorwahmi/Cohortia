Module 3 › Chapter 2.3 › CPU & Memory
CPU usage example
100 - (avg by (instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)

This yields non-idle CPU percentage per instance by first averaging the idle rate per instance and converting to percent.

Memory usage example
(node_memory_MemTotal_bytes - node_memory_MemFree_bytes) / node_memory_MemTotal_bytes * 100

This computes used memory percentage. If you want cluster-level average, wrap with avg(...) by (cluster) or remove instance with without(instance).
