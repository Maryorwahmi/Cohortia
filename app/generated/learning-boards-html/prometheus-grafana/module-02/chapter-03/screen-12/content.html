Checklist for debugging
  1. Run the bare metric name to inspect available labels and values.
  2. Check label matchers for exact case and correct regex syntax.
  3. Confirm functions accept range vectors; add a duration if required.
  4. Verify aggregation groups with by() or without() as intended.
  5. When arithmetic drops series, check label sets and consider aggregating first.
Common mistake

Forgetting to inspect raw labels before complex expressions leads to surprises. Always confirm the label dimensions you are operating on.
