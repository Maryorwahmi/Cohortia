Module 3 › Chapter 2.3 › Metric selection
Definition
A raw metric name selects all series with that name, each identified by labels.
Why it matters

Discovering the full label set for a metric lets you decide how to filter and aggregate. Use the raw name when exploring what dimensions are available in your environment.

Common misconception

A metric name does not return a single number; it returns a set of series, one per label combination.

Key Takeaway

Start with the bare metric to discover labels, then refine with matchers or aggregations for dashboards.

Concrete example
node_cpu_seconds_total

Execute this in Graph to see many series. Look for labels such as instance, cpu, and mode to guide your next filter.
