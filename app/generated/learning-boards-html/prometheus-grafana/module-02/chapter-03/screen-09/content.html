How aggregation works

Aggregation combines multiple series into a smaller set by applying a function across matching series. Use by() to keep labels you care about or without() to drop noisy labels.

Examples
sum(node_cpu_seconds_total) by (mode)
avg(node_memory_MemFree_bytes) without (instance)
sum(rate(http_requests_total[10m])) by (service)
Common mistake

Forgetting by() can collapse data into a single scalar, hiding per-instance or per-service variation that is important for troubleshooting.

Quick decision guide
  • Keep labels with by() when you need per-group metrics.
  • Use without() to remove labels that cause unnecessary series count.
  • Combine aggregation with rate for per-second group metrics.
Key Takeaway

Plan aggregations by deciding which labels must remain for meaningful dashboards and alerts.
