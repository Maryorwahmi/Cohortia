Module 3 › Chapter 2.3 › Vectors
Definition & use

Use instant vectors when you need the current snapshot across series. Use range vectors when a function must inspect historical samples to compute rates or deltas.

Example
node_cpu_seconds_total{mode="idle"}          # instant vector
node_cpu_seconds_total{mode="idle"}[5m]       # range vector for last 5 minutes
rate(node_cpu_seconds_total{mode="idle"}[5m])  # valid use of range vector
Misconception

Trying to call rate() without a range or feeding an instant vector to functions expecting ranges will produce errors or meaningless results. Always check function requirements.

Practical tip

Short windows like one minute reveal bursts but are noisy; longer windows smooth spikes but can hide short incidents. Choose the window to match the signal you want to highlight.

Key Takeaway

Range vectors provide history needed by functions; instant vectors give a snapshot. Match the vector type to the function's needs.
