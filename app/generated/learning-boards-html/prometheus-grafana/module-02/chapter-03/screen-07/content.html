Module 3 › Chapter 2.3 › Rate & irate
What rate() does

rate(metric[duration]) computes the average per-second increase of a counter over the specified window. It smooths spikes and reduces noise from sampling variability.

What irate() does

irate uses the two most recent samples to estimate an instantaneous per-second rate. It is more responsive but noisier.

Common mistake

Applying rate() to a gauge will give nonsensical results because gauges can decrease. Only use rate on counters.

Examples to run
rate(http_requests_total[10m])
irate(http_requests_total[1m])
rate(node_network_receive_bytes_total[5m])

Try these with different windows to see how smoothing changes. Use rate for dashboarding and irate for short anomaly detection when you want immediate changes reflected.

Pro tip

For alerting, prefer a slightly longer rate window to avoid firing on brief, harmless spikes unless the alert specifically requires instant response.
