Exporter responsibilities

  • Collect metrics from a target system using its native interfaces.
  • Translate those metrics into Prometheus metric names, labels, and types.
  • Expose the results on a /metrics HTTP endpoint for scraping.
Placement: exporters often run on the same host (e.g., Node Exporter) or on a host that can access the target system's API.
Node Exporter
Collects CPU, memory, disk I/O, network, and filesystem metrics from Linux and exposes them under node_ prefixed metric names on port 9100 by default.
Safety note
Do not expose exporters directly to the public internet. Use firewall rules and restrict access to Prometheus or its trusted network segment.
Key takeaway
Exporters make non-Prometheus metrics accessible without changing the original system; manage and secure them like any infrastructure service.
