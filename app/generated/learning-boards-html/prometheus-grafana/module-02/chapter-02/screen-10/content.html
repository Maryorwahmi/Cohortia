Terminal commands

Run these commands to download, extract, and run Node Exporter on a Linux AMD64 machine.
# Download (example release)
wget https://github.com/prometheus/node_exporter/releases/download/v1.7.0/node_exporter-1.7.0.linux-amd64.tar.gz
tar xvfz node_exporter-1.7.0.linux-amd64.tar.gz
cd node_exporter-1.7.0.linux-amd64
./node_exporter
After the exporter runs, open http://localhost:9100/metrics or run curl to inspect the output. Look for node_cpu_seconds_total and node_memory_MemFree_bytes to confirm data is present.
Verification
Command: curl http://localhost:9100/metrics — you should see multiple node_ metrics in plain text.
Troubleshoot
If you see connection refused, check process logs, ensure you ran the binary, and verify no firewall is blocking port 9100.
Key takeaway
Node Exporter is a single binary that exposes host metrics on /metrics; verify with curl before updating Prometheus configuration.
