Definition › Counter

Counter: cumulative, monotonic

Counters only increase and are reset on restart. They are perfect for totals like request counts or bytes transferred.

Example metric
http_requests_total — use rate(http_requests_total[5m]) to get requests per second.
Pro tip
When calculating error rates, divide the rate of the error counter by the rate of the request counter to get a stable percentage.
Common mistake
Do not model an instantaneous value as a counter. Active sessions should be a Gauge, not a counter.
Concrete scenario
To measure network throughput, collect a counter that accumulates bytes transmitted. Then compute bytes per second with an appropriate rate() expression to drive graphs and alerts.
Key takeaway
Counters measure totals over time; convert them to rates for real-time monitoring and alerting.
