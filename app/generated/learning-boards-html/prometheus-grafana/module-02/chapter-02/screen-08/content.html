Scrape lifecycle

  1. Application or exporter exposes metrics at /metrics in the Prometheus text format.
  2. Prometheus sends an HTTP GET to the target on the configured interval.
  3. Prometheus parses the response and appends samples to each time series.
  4. Stored series are available via the Prometheus UI and PromQL queries.
Use curl to inspect an endpoint: curl http://localhost:9100/metrics and look for node_ prefixed metrics from the Node Exporter.
Important note
Prometheus pulls metrics. If Prometheus cannot reach the endpoint due to firewall or network isolation, targets will show DOWN in the UI.
Practical tip
Adjust scrape_interval to balance data granularity and load. For exporters exposing system metrics, 15 seconds is a common default.
Key takeaway
Expose /metrics reliably and ensure Prometheus can reach targets; use curl to validate endpoints before editing prometheus.yml.
