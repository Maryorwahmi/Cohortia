Definition › Gauge

Gauge: up and down

Gauges hold current values that can rise or fall. Use them for metrics that represent present state or resource levels.

Example metrics
node_memory_MemFree_bytes, cpu_temperature_celsius, active_sessions
When to alert
Alert when a gauge crosses a threshold, for example when free memory falls under a safe limit or CPU usage stays above 90%.
Misconception
Do not use a gauge to accumulate totals—choosing a gauge for cumulative metrics hides the growth pattern you often need for rate analysis.
Concrete scenario
If you want to monitor current active user sessions, record a gauge called active_sessions and alert when it exceeds a capacity threshold. This gives immediate, intuitive readings.
Key takeaway
Gauges measure current state. Use them for thresholds and instantaneous insights.
