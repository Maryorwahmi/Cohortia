Common Mistakes › Troubleshooting exporters
Issue 1: Firewall
If Prometheus cannot connect, the Targets page shows DOWN. Use curl from Prometheus to the exporter host to confirm reachability and open the exporter port in firewall rules if needed.
Issue 2: Wrong port
Ensure the exporter is listening on the port you configured. Check process logs and netstat/lsof to confirm the actual listening port and update prometheus.yml accordingly.
Issue 3: Configuration error
prometheus.yml syntax or indentation errors, or typos in target addresses, will prevent scraping. Reload Prometheus after fixes and re-check Targets.
Suggested verification steps
  1. From the Prometheus host run: curl http://localhost:9100/metrics
  2. Check exporter logs for startup failures or port binding errors.
  3. Validate prometheus.yml and restart or reload Prometheus.
Key takeaway
A short troubleshooting checklist — curl, exporter status, prometheus.yml — resolves most DOWN target problems quickly.
