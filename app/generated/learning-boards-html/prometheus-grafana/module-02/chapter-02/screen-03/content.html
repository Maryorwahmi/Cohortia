Verification steps
  1. Read sample metrics and justify the metric type used.
  2. Use curl to fetch an app or exporter /metrics endpoint and inspect the text format.
  3. Install Node Exporter, run it, and confirm it listens on port 9100.
  4. Add a scrape_config entry to prometheus.yml, reload Prometheus, and check Targets for UP.
Mini checklist
Metrics present and parseable on /metrics.
Prometheus scrape target configured and accessible.
Firewalls verified and ports opened between Prometheus and targets.
Tip: For production, run exporters as managed services to ensure automatic restarts.
