Final Takeaways › Quick Reference
Keep cardinality low
Use labels for stable dimensions like host, region, or status code, not for unique IDs.
Match type to intent
Counters for totals, Gauges for current state, Histograms for aggregatable percentiles.
Secure and verify exporters
Run exporters as services, restrict access, and confirm scraping with curl and the Prometheus Targets page.
Final summary
These three rules will help you design metrics and exporter deployments that produce reliable, actionable observability data.
