Comparison › Histogram vs Summary

Histogram

Buckets + counts + sum allow aggregation across instances. Use for fleet-wide percentile estimates.

Example metric
http_request_duration_seconds_bucket{le="0.1"} 240
  • Provides bucket counts and sum
  • Aggregatable across replicas
  • Good for global percentile approximations

Summary

Client-side quantiles over a sliding window; not trivially aggregatable across instances.

Example metric
request_duration_seconds{quantile="0.9"} 0.23
  • Reports quantiles directly per instance
  • Not recommended when you need aggregated percentiles
  • Useful for per-instance reporting without cross-instance aggregation
Key takeaway
Choose histograms for aggregatable distribution metrics across multiple instances; use summaries when per-instance quantiles are sufficient.
