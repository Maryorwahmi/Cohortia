Module 2 › Chapter 2.1 › Key Concepts
Prometheus Server
The component that scrapes, stores, and answers queries for metrics.
prometheus.yml
Primary config file defining global settings, scrape jobs, and targets.
Targets & Jobs
scrape_configs, job_name, and static_configs define which endpoints Prometheus collects metrics from.
Summary
Install the binary, edit a minimal prometheus.yml to scrape localhost, validate with promtool, run Prometheus, and confirm scraping via the targets page and a prometheus_up query.
