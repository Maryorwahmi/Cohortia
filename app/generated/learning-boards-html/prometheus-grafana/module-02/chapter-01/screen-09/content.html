Module 2 › Chapter 2.1 › Verify Prometheus using the Web UI
Targets page
The targets view displays each scrape job and its targets with their current state. Look for prometheus job and a target with a UP state for localhost.
Verification steps
  1. Open the web UI at the server address and port.
  2. Navigate to Status → Targets and check the prometheus job's target shows UP.
  3. Use the Graph tab and query prometheus_up to see the numeric result for the target.
Concrete example
On success the targets list shows job: prometheus, target: localhost:9090, state: UP. Running the prometheus_up query returns a value of 1 indicating the scrape is healthy.
If it's not UP
Check server logs for binding or parse errors, validate prometheus.yml with promtool, and verify the target address and port are reachable and not blocked by a firewall.
Key Takeaway
Combine the targets view and a prometheus_up query to confirm the server is scraping its own metrics correctly before adding other targets.
