Module 2 › Chapter 2.1 › Minimal prometheus.yml
YAML example to copy
global:
  scrape_interval: 15s
  evaluation_interval: 15s

scrape_configs:
  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']
Notes: metrics_path and scheme default to /metrics and http. This minimal file is intentionally small so you can quickly verify the server, then extend scrape_configs when you add more targets.
Validation & common pitfalls
Before running
  • Ensure you use spaces, not tabs, and consistent indentation levels.
  • Run the configuration utility to validate the file for syntax errors.
  • If you change ports, update the target address accordingly.
Key Takeaway
A small, validated prometheus.yml that scrapes localhost allows you to prove the server is running before adding complexity.
