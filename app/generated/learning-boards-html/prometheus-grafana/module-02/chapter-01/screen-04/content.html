Module 2 › Chapter 2.1 › Prometheus binary and bundled files
Definition & purpose

The archive includes three practical components: the Prometheus server binary, promtool for configuration validation, and a default prometheus.yml that shows a minimal working setup. Understanding each file prevents mistakes when you customize your deployment.

Server binary
Runs scrapes, stores series, and serves the web UI and query API.
promtool
Validates the prometheus.yml so you catch YAML errors before runtime.
prometheus.yml
Defines global intervals, scrape_configs, and initial example jobs you can adapt.
Concrete example
What you see after extraction
A directory containing the prometheus executable, promtool, console libraries, and a prometheus.yml. Inspecting these files helps you decide where to place them on the system and how to run the server.
Common mistake
Editing the prometheus.yml before understanding its structure can introduce indentation errors. Always validate with promtool before launching Prometheus.
Key Takeaway
Know what is in the archive, validate configs with promtool, and use the default file as a safe starting point.
