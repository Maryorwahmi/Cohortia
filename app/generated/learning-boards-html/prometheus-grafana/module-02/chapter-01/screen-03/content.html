Terminal Demo Flow
A short checklist of commands and checks you'll run in the terminal to install and validate Prometheus.
Download archive, extract to a safe directory, and inspect the prometheus binary and promtool.
Edit the default prometheus.yml to include a self-scrape job and save with correct YAML indentation.
Run Prometheus specifying the config file and watch startup logs for the server ready message and target manager start.
Open the web UI, navigate to targets, and confirm the prometheus job target reports UP and prometheus_up equals one.
Skill Cards
Config Validation
Use the bundled configuration utility to check for indentation and syntax errors before starting Prometheus.
Port Management
If 9090 is occupied, change the listening address or port and re-run, then re-verify the UI target state.
Quick Checks
A simple query for prometheus_up will quickly tell you if Prometheus is scraping itself successfully.
