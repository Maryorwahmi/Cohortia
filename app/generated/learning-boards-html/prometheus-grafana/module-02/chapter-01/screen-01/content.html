Installing and Running Prometheus

Follow a terminal-first path to download Prometheus, adjust the minimal prometheus.yml, run the server, and confirm that "prometheus_up" reports a running service. This module focuses on practicality and verification.

In this lesson

Configure

Run & Verify
Start Prometheus and confirm targets are UP via the web UI.
