Module 2 › Chapter 2.1 › Running Prometheus and reading logs
Startup checklist
Provide the path to your prometheus.yml when starting the server so it loads the intended configuration and you can read the resulting log messages.
Key log indicators
  • Server ready to receive web requests – indicates the web UI should be available.
  • Starting target manager – indicates scrape jobs are being scheduled.
  • Configuration parse errors – indicates prometheus.yml issues requiring fix.
  • Address already in use – indicates a port conflict you must resolve.
Example log snippets
Server ready to receive web requests Starting target manager Loaded configuration file
Troubleshoot
If you see address binding errors, change the listening port or stop the process using that port. If YAML parse errors appear, validate with promtool and correct indentation.
Key Takeaway
Use logs as the primary diagnostic source. They tell you whether the server bound correctly and whether your config parsed successfully.
