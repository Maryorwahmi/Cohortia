Module 2 › Chapter 2.1 › Port conflicts & firewall
Typical causes
  • Another service already bound to the same port.
  • Firewall rules blocking the port.
  • Server bound to localhost only while you try a remote connection.
Quick fixes
Free the port by stopping the conflicting process or use an alternate port.
Adjust firewall rules to allow inbound access to the Prometheus port.
Change the web listening address to bind to a different port if needed.
Diagnostic flow
  1. Read the Prometheus logs for an address binding error.
  2. Identify the process using the port or select an alternate port.
  3. Adjust firewall rules if the server is running but unreachable remotely.
Key Takeaway
Treat binding errors as configuration or environment issues, not Prometheus failures. Logs indicate the corrective action to take.
