Module 2 › Chapter 2.1 › Download and extract Prometheus
Terminal sequence
# Example terminal steps after choosing a download URL
wget [prometheus-release-archive].tar.gz
# extract the archive
# change into the extracted folder and list files
What to check
  • prometheus executable exists and is executable
  • promtool is present for validation
  • prometheus.yml is available to edit
Placement
Choose a directory such as /opt/prometheus or /usr/local/prometheus and move the extracted folder there if needed. This is a manual step.
Concrete example — post-extract listing
prometheus promtool prometheus.yml consoles/ console_libraries/
Common mistake
Assuming the archive installs to a system location automatically. You must choose where to keep the extracted folder and set permissions as needed.
Key Takeaway
Extract and inspect immediately. Confirm the three core items before moving on to configuration edits.
