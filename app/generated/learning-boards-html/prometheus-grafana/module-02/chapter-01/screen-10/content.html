Module 2 › Chapter 2.1 › Using promtool and manual checks
promtool
Use to validate prometheus.yml for syntax and indentation problems before launching Prometheus. This prevents parse-time failures.
Logs
Read startup output for messages about server readiness, target manager start, configuration load, and error conditions like address binding failures.
Web UI
Confirm targets are UP on the targets page and run a basic query for prometheus_up to see a numeric confirmation of scraping success.
Workflow example
1) Validate config with promtool. 2) Start Prometheus and watch logs for server ready messages. 3) Open the web UI and confirm the prometheus job target shows UP and prometheus_up returns one.
