Module 2 › Chapter 2.1 › Hands-on: install, configure, run, verify
Lab checklist
  1. Download the Prometheus release archive for your platform and extract it.
  2. Inspect the extracted directory for prometheus, promtool, and prometheus.yml.
  3. Edit prometheus.yml to create a minimal self-scrape job and set global intervals.
  4. Validate the configuration with the validation utility before starting.
  5. Start the server and monitor logs for readiness and target manager startup.
  6. Open the web UI, check Targets, and run a query for prometheus_up to confirm scraping.
Example verification questions
Did promtool report any syntax errors? Does the log contain a server ready message? Is the prometheus job's target state UP? Does prometheus_up return the expected value?
Key Takeaway
Follow the checklist sequentially, validate before running, and use logs plus the UI to confirm a successful installation.
