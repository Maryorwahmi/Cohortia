Question 1 — Connection refused
Likely causes: Prometheus failed to start due to config parse error or port is occupied. Troubleshoot by checking terminal logs, validating with promtool, and confirming firewall or port usage.
Question 2 — Intervals
scrape_interval determines how often metrics are scraped from targets. evaluation_interval determines how often recording and alerting rules are evaluated. Shorter intervals increase data volume and resource usage.
Key Takeaway
Good troubleshooting combines configuration validation, log inspection, and web UI checks. Interval settings affect both the freshness of metrics and system resource needs.
