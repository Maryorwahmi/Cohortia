Encapsulation and Access Specifiers

Why protecting state and exposing controlled interfaces makes gameplay code robust and designer-friendly.

Interactive 16:9 Masterclass
Principle

Encapsulation bundles data and methods, keeping internal state private and presenting a small public interface for interaction.

Unreal Layer

UPROPERTY and UFUNCTION let you control editor visibility and Blueprint access on top of C++ visibility.

Practical example

A door actor keeps its open flag private, shows it as VisibleAnywhere, allows designers to set open speed with EditAnywhere, and exposes OpenDoor as BlueprintCallable.

Key Takeaway

Protect core state in C++, expose only what editors and Blueprints need via UPROPERTY/UFUNCTION.

Visual concept
Cards represent C++ visibility; lines show Unreal reflection mapping to editor and Blueprint.
