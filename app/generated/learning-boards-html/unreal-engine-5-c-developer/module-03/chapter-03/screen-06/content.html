Common UPROPERTY specifiers
  • EditAnywhere: allow editing in the Details panel for instances and defaults.
  • VisibleAnywhere: show the value but prevent editing.
  • BlueprintReadWrite: Blueprints can read and write the property.
  • BlueprintReadOnly: Blueprints can only read the property.
  • Category = "...": groups the property in the Details panel.
Design note: use VisibleAnywhere for diagnostic state and EditAnywhere for tunables; prefer BlueprintReadOnly when only reading is needed.
Key Takeaway

UPROPERTY specifiers make your C++ work well with designers. Match editor exposure to intended usage.

Concrete mapping
Private + VisibleAnywhere

Designers can view runtime state; only C++ can change it.

Private + EditAnywhere, BlueprintReadOnly

Designers set initial values in the editor; Blueprints can read but not overwrite runtime state.

Misconception check

Don't assume UPROPERTY overrides C++ access. A private variable with EditAnywhere still prevents other C++ classes from writing to it — the editor exposure is separate from code-level access.
