Module 3 › Chapter 3.3 › AMyDoor.h Walkthrough
Header snippet
// MyDoor.h
UCLASS()
class MYPROJECT_API AMyDoor : public AActor
{
    GENERATED_BODY()

private:
    UPROPERTY(VisibleAnywhere, Category = "Door State")
    bool bIsOpen; 

    UPROPERTY(EditAnywhere, Category = "Door Settings")
    float DoorOpenDuration;

    UPROPERTY(VisibleAnywhere, Category = "Door State")
    float CurrentOpenAlpha;

    void UpdateDoorPosition(float DeltaTime);

public:
    UFUNCTION(BlueprintCallable, Category = "Door Actions")
    void OpenDoor();

    UFUNCTION(BlueprintCallable, Category = "Door Actions")
    void CloseDoor();

    UFUNCTION(BlueprintPure, BlueprintCallable, Category = "Door State")
    bool IsDoorOpen() const;
};
Explanation
  • bIsOpen is private and VisibleAnywhere — visible to designers for diagnostics but only C++ changes it.
  • DoorOpenDuration is EditAnywhere so designers can tune timing in the Details panel.
  • OpenDoor/CloseDoor are BlueprintCallable so designers can wire them into level logic.
  • IsDoorOpen is pure: safe as a read-only check in Blueprints.
Misuse to avoid: making bIsOpen BlueprintReadWrite. That would let Blueprints directly flip the flag and bypass guard logic in OpenDoor/CloseDoor.
Key Takeaway

Combine C++ visibility and UPROPERTY to make safe, designer-friendly classes.
