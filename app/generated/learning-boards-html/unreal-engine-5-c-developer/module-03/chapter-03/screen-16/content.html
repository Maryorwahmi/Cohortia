Module 3 › Chapter 3.3 › Key Concepts
EditAnywhere

Editable in the Details panel; good for designer tunables.

VisibleAnywhere

Visible but not editable; useful for runtime diagnostics.

BlueprintReadOnly / ReadWrite

Control Blueprint read and write access; prefer read-only for state you want Blueprints to observe but not mutate.

Final takeaway

Match specifiers to intent: who owns the state, who tunes it, and who triggers behavior? That alignment keeps projects maintainable.
