Module 3 › Chapter 3.3 › Decision Checklist
A repeatable process
Is this runtime state? If yes, private.
Editable by designer? Use EditAnywhere but prefer BlueprintReadOnly.
Should Blueprints initiate behavior? Expose BlueprintCallable methods.
Is it a pure getter? Mark BlueprintPure for read-only checks.

Follow these checks to ensure your class is predictable and designer-friendly. When in doubt, start with stricter access and relax only when necessary.

Key Takeaway

A short checklist keeps decisions consistent and reduces accidental over-exposure.
