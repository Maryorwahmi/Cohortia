Correct declaration
private:
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Player Stats")
    float PlayerStamina;
This declaration allows level designers to set an initial maximum in the Details panel, while Blueprints may read the value but cannot write to it directly. Controlled mutation happens through C++ functions such as SpendStamina or RegenerateStamina, which can validate input and apply any game rules.
Why this works
  • EditAnywhere exposes the field in the editor for tuning defaults.
  • BlueprintReadOnly prevents Blueprint writers from mutating the value directly.
  • private C++ access prevents other C++ classes from writing it without going through public methods.
Testing tip: compile, set a value in the Details panel, then attempt to write it from a Blueprint to confirm write protection.
