Module 3 › Chapter 3.3 › Encapsulation
Definition and benefits

Encapsulation bundles data and methods so internal state is only changed through the class's controlled interfaces. This protects invariants and reduces coupling between systems.

Protects state from unintended external modification.
Makes code modular: internal changes don't force external updates.
Simplifies reasoning: public interface documents intended uses.
Key Takeaway

Design public methods that enforce rules; keep raw state private or protected.

Analogy: a car

You control a car through a small set of inputs. The engine internals are not exposed. Similarly, expose only the methods designers and other systems need.

Concrete example
Player Health

Keep current health private. Provide public TakeDamage and Heal functions that clamp values and apply invulnerability frames.

Common mistake: making every field public for convenience. This increases coupling and debugging cost.
