Learning Objectives
Build and call reusable behavior contracts
Bloom: Learn → Understand → Apply → Master
01
Understand abstract classes

Explain pure virtual functions and why an abstract class cannot be instantiated. Practice: create an ABaseEnemy with a pure virtual AttackBehavior().

VERIFIED COMPETENCY MILESTONE
02
Declare a UInterface

Write UINTERFACE and the I-prefixed class with a BlueprintNativeEvent. Example: IInteractable with OnInteract(AActor*).

VERIFIED COMPETENCY MILESTONE
03
Implement interfaces in actors

Add public IInteractable to a UCLASS, implement OnInteract_Implementation, and test behavior in both C++ and Blueprint overrides.

VERIFIED COMPETENCY MILESTONE
04
Call interfaces safely

Learn to check Implements<UYourInterface>() and call IYourInterface::Execute_Function(Actor, params) so Blueprint overrides and C++ implementations are dispatched correctly.

VERIFIED COMPETENCY MILESTONE
