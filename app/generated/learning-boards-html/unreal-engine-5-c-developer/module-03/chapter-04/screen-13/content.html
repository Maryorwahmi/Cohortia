Module 4 › Chapter 3.4 › Hands-on Activity
Step-by-step
  1. Create Interactable UInterface with OnInteract(AActor*).
  2. Create ADoor and APickupItem; add public IInteractable and implement OnInteract_Implementation.
  3. Create AMyPlayerCharacter::TryInteract performing a line trace and calling Execute_OnInteract.
  4. Bind input, place actors in level, and test logs or on-screen debug messages.
Example checks
  • Does the door log "Door is locked" when bIsLocked is true?
  • Does the pickup log "Item collected" and destroy itself?
  • Does the player log "Nothing to interact with" when the trace misses?
Key Takeaway

This lab ties declaration, implementation, and runtime dispatch together so you can iterate with designers using Blueprints and programmers using C++.
