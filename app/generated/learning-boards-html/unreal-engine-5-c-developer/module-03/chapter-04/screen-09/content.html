Module 4 › Chapter 3.4 › BlueprintNativeEvent
Concept

BlueprintNativeEvent enables a default C++ implementation and still allows a Blueprint to override the function. Implement the C++ default using FunctionName_Implementation and use Execute_ to call the function so Blueprint overrides are respected.

Contrast
BlueprintImplementableEvent provides no C++ default; BlueprintNativeEvent does. Choose based on whether you need a C++ fallback.
Test scenario
  1. Implement OnInteract_Implementation in C++ with default behavior.
  2. Create a Blueprint that implements the interface and override OnInteract.
  3. From runtime code call IInteractable::Execute_OnInteract(Target, Instigator) and observe the Blueprint override running.
Key Takeaway

Use BlueprintNativeEvent when you want a reliable C++ fallback while keeping designer-friendly Blueprint overrides.
