Module 4 › Chapter 3.4 › Key Concepts
I-prefix
The C++ interface should begin with I, while the UINTERFACE has the U prefix.
Execute_ Dispatch
Use IInterface::Execute_Function to ensure the reflection system calls Blueprints or C++ implementations correctly.
BlueprintNativeEvent
Choose this specifier when you want to provide a C++ fallback and still allow Blueprint overrides.
Final takeaway
Combine abstract bases and interfaces thoughtfully: leverage shared code where appropriate and expose capabilities through interfaces to keep systems decoupled and easy to extend.
