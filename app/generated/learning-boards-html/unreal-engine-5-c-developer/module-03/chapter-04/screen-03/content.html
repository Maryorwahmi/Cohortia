Design & Debug

Practice combining an abstract base and UInterface: share common AI or movement in the base class while attaching discrete behaviors with interfaces. This separation keeps code maintainable and prevents deep, rigid inheritance chains.

Hands-on milestone
Compile, place ADoor and APickupItem, and bind TryInteract on the player. Confirm message logs or on-screen debug output to verify the interface calls succeed.
Avoid common mistakes
  • Don't call interface functions directly; use Execute_ to ensure Blueprint or C++ dispatch.
  • Remember the C++ interface class should start with an I prefix, e.g., IInteractable.
  • Avoid adding interfaces for trivial one-off behaviors that won't be shared.
