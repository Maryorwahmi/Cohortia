Abstract Classes & Interfaces
How to design contracts and call them safely in Unreal C++

This lesson shows two patterns: the abstract C++ base with pure virtual functions for strong "is-a" relationships, and Unreal's UInterface for flexible "can-do" behavior across unrelated classes. We'll use examples like a base enemy behavior and an interactable interface used by doors and pickup items, and show the required Execute_ call that ensures correct dispatch through Unreal's reflection system.

Quick takeaway
Use abstract classes to share implementation for a related family. Use UInterface for loose coupling when objects should share behavior without shared ancestry.
