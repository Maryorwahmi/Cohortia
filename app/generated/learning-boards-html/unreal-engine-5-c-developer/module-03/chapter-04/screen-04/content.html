Module 4 › Chapter 3.4 › What is an Abstract Class?
Definition
Pure virtual functions enforce derived implementations
Key points:
  • Contains at least one pure virtual function declared with = 0.
  • Cannot be instantiated directly; used as a base type.
  • Can still provide shared helpers and member data.
Example
// ABaseEnemy.h
class ABaseEnemy
{
public:
  virtual void AttackBehavior() = 0; // pure virtual: makes class abstract
  void MoveToTarget(); // shared helper implementation
};

// AZombie inherits and implements the attack behavior
class AZombie : public ABaseEnemy
{
public:
  void AttackBehavior() override { /* zombie-specific attack */ }
};
Concrete example and misconception

You can store heterogeneous enemies in an ABaseEnemy* array and call AttackBehavior on each. A common misconception is that abstract classes cannot contain any implementation; in practice you often implement common utilities in the base and leave only the variable behavior pure virtual.

Key Takeaway

Use abstract bases when types share identity and some implementation, but require specific methods implemented by each derived class.
