Module 4 › Chapter 3.4 › Calling Interface Functions
Pattern
Follow this safe sequence:
  1. Check pointer validity.
  2. Use Target->Implements<UYourInterface>() to ensure the actor supports the interface.
  3. Call IYourInterface::Execute_YourFunction(Target, params) to dispatch correctly.
// Example inside player code
if (HitActor && HitActor->Implements<UInteractable>())
{
  IInteractable::Execute_OnInteract(HitActor, this);
}
else
{
  UE_LOG(LogTemp, Warning, TEXT("Not interactable"));
}
Common pitfalls
  • Don't call the interface method directly on the actor pointer.
  • Remember to include the interface header where you call Execute_.
  • Use clear logging to help designers understand when an object is missing the expected interface.
Key Takeaway

The Implements check plus Execute_ call ensures reliable dispatch across C++ and Blueprint implementations.
