Module 4 › Chapter 3.4 › Declaring IInteractable
Header example
// Interactable.h
#pragma once
#include "CoreMinimal.h"
#include "UObject/Interface.h"
#include "Interactable.generated.h"

UINTERFACE(MinimalAPI, Blueprintable)
class UInteractable : public UInterface
{
    GENERATED_BODY()
};

class MYPROJECT_API IInteractable
{
    GENERATED_BODY()

public:
    UFUNCTION(BlueprintCallable, BlueprintNativeEvent, Category = "Interaction")
    void OnInteract(AActor* InstigatorActor);
};
Key notes
  • UINTERFACE declares the UObject wrapper for the reflection system.
  • I-prefixed class holds the UFUNCTION declarations used by implementers.
  • BlueprintNativeEvent allows an optional C++ default with an _Implementation override.
Pro tip

Keep the generated header name consistent and include the generated .h to avoid macro errors during compile.
