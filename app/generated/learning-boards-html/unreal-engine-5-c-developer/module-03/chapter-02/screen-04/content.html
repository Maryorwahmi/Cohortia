Module 3 › Chapter 3.2 › Inheritance
Definition

A derived class is built from a base class and automatically receives its properties and functions, forming an "is-a" relationship used to group related game objects.

Example
AEnemy defines Health and Attack(); AZombieEnemy inherits those members and adds zombie-specific effects.
Common misconception

Inheritance is not just for reuse. It models relationships and enables polymorphism. Avoid placing unrelated features in one base class.

Key Takeaway

Design narrow base classes that capture shared behavior and a clear contract for derived types.

Hierarchy example
UObject
Base engine object
AActor
World presence, lifecycle hooks
ACharacter
Movement and input for characters
Use this pattern in your code: place shared fields and helper methods in a focused base class, then override or extend behavior in derived classes where necessary.
