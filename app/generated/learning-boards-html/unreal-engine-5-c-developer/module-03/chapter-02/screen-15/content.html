Module 3 › Chapter 3.2 › Key Concepts — Practical
Use pointers
Pointers preserve derived data and enable polymorphism; avoid passing polymorphic objects by value.
Use override
Make your intent explicit so the compiler can catch mismatches between base and derived signatures.
Verify with logs
Use distinct on-screen messages or log lines in derived methods to confirm polymorphic dispatch during testing.
Final thought
Small habits like override and pointer-based arrays yield large dividends in maintainability and correctness for gameplay systems.
