Module 3 › Chapter 3.2 › Key Concepts
Inheritance
Create a base that captures shared state and let derived classes specialize behavior.
Polymorphism
Call methods through base pointers and let the runtime choose the derived implementation via virtual dispatch.
Virtual vs Pure Virtual
Virtual allows defaults; pure virtual forces derived classes to implement the method and makes the base abstract.
Summary
Design narrow base classes, mark varying behavior virtual, use override, and operate on pointers to preserve polymorphism.
