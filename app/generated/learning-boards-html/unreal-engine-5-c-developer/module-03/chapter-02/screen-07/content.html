Pure virtual example
// Enemy.h
virtual void TakeDamage(float DamageAmount) = 0; // pure virtual

This makes AEnemy abstract. No AEnemy instances can be created. Derived enemies must implement TakeDamage.

When to use
  • When a behavior is required of all derived types.
  • When you want to enforce a contract at compile-time.
  • When a default implementation would be misleading or impossible.
Analogy

Think of an abstract class as a blueprint that lists required rooms but does not furnish them — derived classes must add the furniture.
