Module 3 › Chapter 3.2 › Common Mistakes
Missing virtual

If base methods are not virtual, derived overrides won't be called through base pointers. This causes unexpected base behavior at runtime.

Function hiding

A signature mismatch in the derived class creates a new function rather than overriding. Use override to catch this at compile time.

Object slicing

Passing derived objects by value to functions expecting a base value slices off derived data. Use pointers or references for polymorphic types.

Instantiating abstract classes

Attempting to create an instance of a class with pure virtual methods produces a compiler error. Implement required methods in derived classes instead.
