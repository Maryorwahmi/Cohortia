Three-step process
1. Base interface
Declare virtual methods that describe behaviors you need to call generically.
2. Derived implementations
Override the virtual methods with type-specific logic and state.
3. Manager calls
Store base pointers and call the interface method, letting the runtime dispatch to the correct implementation.
Example: AWeapon base, ARifle and APistol derived, AWeaponManager with TArray<AWeapon*> that iterates and calls Fire(). Adding new weapons requires no manager changes.
