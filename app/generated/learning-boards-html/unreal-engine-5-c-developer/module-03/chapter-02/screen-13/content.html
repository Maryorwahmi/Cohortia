Module 3 › Chapter 3.2 › Compile & Test
Runbook
  1. Create AWeapon and declare virtual Fire().
  2. Make ARifle and APistol and override Fire() using override.
  3. Create AWeaponManager with TArray<AWeapon*> and populate with instances.
  4. Call Fire() on each pointer in BeginPlay and check logs.
  5. If behavior is wrong, check for missing virtual, missing override, or value semantics.
Quick debug tips
  • Use distinct on-screen messages per derived Fire() to verify which implementation runs.
  • Ensure WeaponsInInventory stores pointers to actors, not class types unless you spawn them.
  • Use the compiler errors from override to find signature mismatches quickly.
Key Takeaway

A short checklist and clear debug messages will usually reveal the cause of polymorphism failures within minutes.
