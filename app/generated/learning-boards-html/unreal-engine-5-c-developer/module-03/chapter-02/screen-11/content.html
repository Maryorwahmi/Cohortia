Module 3 › Chapter 3.2 › Lifecycle Hooks
Why they're virtual

Engine-managed events like BeginPlay and Tick must allow game code to supply actor-specific behavior. Declaring them virtual in base classes gives that flexibility.

When overriding, call Super::BeginPlay() or Super::Tick() unless you have a reason to replace the base behavior. Neglecting to call Super can break component initialization or engine assumptions in complex hierarchies.
Example
ACharacter overrides BeginPlay to set up animations; the engine calls BeginPlay on AActor pointers and the overridden implementation runs.
Key Takeaway

Lifecycle hooks are the sanctioned extension points of the engine; use them to place type-specific initialization and per-frame logic.
