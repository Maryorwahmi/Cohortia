Module 3 › Chapter 3.2 › Virtual Functions
Base declaration
// Enemy.h (excerpt)
UCLASS()
class MYPROJECT_API AEnemy : public AActor
{
  GENERATED_BODY()
public:
  UFUNCTION(BlueprintCallable, Category = "Combat")
  virtual void Attack();
};
Derived override
// ZombieEnemy.h (excerpt)
UCLASS()
class MYPROJECT_API AZombieEnemy : public AEnemy
{
  GENERATED_BODY()
public:
  UFUNCTION(BlueprintCallable, Category = "Combat")
  virtual void Attack() override;
};
Using override communicates intent and lets the compiler catch mismatches between base and derived signatures, preventing silent hiding bugs.
