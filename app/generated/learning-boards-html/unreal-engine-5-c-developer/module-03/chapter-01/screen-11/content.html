Module 3 › Chapter 3.1 › Hands-on: AMySimpleActor
Step-by-step
  1. Create a new C++ Actor class named AMySimpleActor via the Editor.
  2. Add UPROPERTY(EditAnywhere, BlueprintReadWrite) float MyFloatValue to the header.
  3. Add UFUNCTION(PrintMyValue) and implement it to print to screen and log.
  4. Compile, place actor in level, and verify the property in Details panel.
Check
If the property does not appear, check includes, GENERATED_BODY, and successful compilation.
Implementation snippet
// MySimpleActor.cpp
#include "MySimpleActor.h"
#include "Engine/Engine.h"

AMySimpleActor::AMySimpleActor()
{
  PrimaryActorTick.bCanEverTick = true;
  MyFloatValue = 100.0f;
}

void AMySimpleActor::BeginPlay()
{
  Super::BeginPlay();
  PrintMyValue();
}

void AMySimpleActor::PrintMyValue()
{
  if (GEngine)
  {
    GEngine->AddOnScreenDebugMessage(-1, 5.f, FColor::Green, FString::Printf(TEXT("MyFloatValue is: %f"), MyFloatValue));
    UE_LOG(LogTemp, Warning, TEXT("MyFloatValue is: %f"), MyFloatValue);
  }
}
Key Takeaway
This simple cycle — edit header, implement, compile, verify in Editor — is your fast feedback loop for engine-aware C++ development.
