Module 3 › Chapter 3.1 › Pitfalls
Compilation & Visibility
  • Missing GENERATED_BODY or generated include blocks type registration.
  • Compile failures prevent Editor from showing new types.
Pointer Safety
  • Do not delete UObjects manually; use engine-managed lifecycles.
  • Use TWeakObjectPtr for references that may be destroyed.
Exposure Discipline
Choose the narrowest UPROPERTY/UFUNCTION specifiers to avoid exposing internal state unnecessarily.
Struct Semantics
USTRUCTs copy by value. If you need reference semantics, use a UObject-based type or pointer wrappers.
Quick fix checklist
If something behaves oddly, recompile, check GENERATED_BODY and includes, confirm pointer types, and verify property specifiers.
