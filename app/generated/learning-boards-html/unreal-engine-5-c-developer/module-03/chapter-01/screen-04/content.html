What is a class?
A template with member variables and functions that defines behavior and structure.
  • Member variable: stores state for instances, e.g., MaxSpeed.
  • Member function: behavior such as TakeOff or FireWeapon.
  • Instances have unique values but share the class implementation.
Analogy
Think of a class as a vehicle blueprint and each object as one assembled car with its VIN and options.
Concrete example
// FighterJet example class FighterJet { public: float MaxSpeed; float FuelCapacity; void FireWeapon(); }; // Object: an F-16 instance with its own MaxSpeed and FuelCapacity
Common mistake
Putting global state in the class instead of instance fields causes unexpected sharing between objects.
Key Takeaway
Separate shared behavior (class) from per-object data (instance) to make components reusable and safe.
