Module 3 › Chapter 3.1 › UPROPERTY / UFUNCTION
Common specifiers
  • EditAnywhere — editable in the Editor and at runtime where applicable.
  • BlueprintReadWrite — Blueprints can read and write the value.
  • BlueprintCallable — function can be called from Blueprint graphs.
Design note
Expose only what designers or Blueprints need to change; keep others private to maintain invariants.
Concrete example
UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Collectible")
int32 CollectibleValue;

UFUNCTION(BlueprintCallable, Category = "Collectible")
void OnCollected();
This combination makes the integer editable in the Editor and accessible from Blueprint scripts, while the function can be invoked by designers in visual logic.
Common mistake
Applying broad specifiers by default can expose internal state and make future refactors risky.
Key Takeaway
Use the narrowest specifier that accomplishes the needed Editor or Blueprint exposure.
