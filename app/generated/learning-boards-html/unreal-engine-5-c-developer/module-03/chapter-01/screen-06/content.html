Module 3 › Chapter 3.1 › AMyCollectible.h
Key header elements
  • Include the generated header and CoreMinimal.
  • UCLASS above the type tells Unreal this is engine-visible.
  • GENERATED_BODY inside class is required for reflection plumbing.
Pro tip
Use consistent naming: MyClass.h and MyClass.generated.h for predictable UHT processing.
Example header
// MyCollectible.h
#pragma once

#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "MyCollectible.generated.h"

UCLASS()
class MYPROJECT_API AMyCollectible : public AActor
{
  GENERATED_BODY()

public:
  AMyCollectible();

  UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Collectible")
  int32 CollectibleValue;

  UFUNCTION(BlueprintCallable, Category = "Collectible")
  void OnCollected();
};
Key Takeaway
This header pattern is the minimal recipe to make an actor show editable properties and callable functions in the engine's tools.
