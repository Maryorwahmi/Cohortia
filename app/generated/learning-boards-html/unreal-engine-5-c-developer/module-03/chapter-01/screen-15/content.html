Module 3 › Chapter 3.1 › Key Concepts
USTRUCT()
Annotate structs with USTRUCT and GENERATED_BODY to make data types editable and serializable in the engine.
Reflection System
The engine inspects metadata produced by macros to power the Editor, Blueprints, serialization, and more.
Garbage Collection
Unreal's GC manages UObject lifetimes; use safe pointer types to avoid dangling references when objects are destroyed.
Closing takeaway
Keep reflection, struct vs UObject semantics, and GC behavior in mind while designing types to make code that is both engine-friendly and robust.
