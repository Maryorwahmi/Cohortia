What GENERATED_BODY does
It injects necessary boilerplate and registration code so the Unreal Header Tool can collect metadata about fields and functions. This is how reflection metadata is produced for the engine to consume.
  • Registers properties and functions with reflection metadata.
  • Provides engine hooks used by serialization and replication.
  • Expands to constructors or helpers required by UObject-derived types.
Diagnostic checklist
• If fields don't appear in the Details panel, check for GENERATED_BODY and the generated header include.
• If compilation errors mention missing reflection helpers, look for mismatched specifiers or missing macros.
Misconception
GENERATED_BODY is not optional; it is the bridge between your C++ and engine metadata.
Key Takeaway
Treat GENERATED_BODY as essential reflection wiring rather than cosmetic boilerplate.
