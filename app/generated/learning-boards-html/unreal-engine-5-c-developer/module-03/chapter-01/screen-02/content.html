Module 3 › Chapter 3.1 › Learning Objectives
01
Model classes and objects
Describe classes as blueprints and objects as instances, and apply that when designing game entities. This mental model guides how you represent shared behavior versus instance data.
VERIFIED COMPETENCY MILESTONE
02
Differentiate C++ and Unreal types
Explain how UCLASS/USTRUCT add reflection metadata and why that enables Editor and Blueprint integration. Contrast with plain C++ types that are invisible to the engine.
VERIFIED COMPETENCY MILESTONE
03
Declare Unreal-aware classes
Write a class that inherits from AActor or UObject, add GENERATED_BODY, and prepare UPROPERTY and UFUNCTION to expose behavior in the Editor and Blueprints.
VERIFIED COMPETENCY MILESTONE
04
Understand GENERATED macros
Learn why GENERATED_BODY is mandatory for reflection and what common compilation errors indicate when it is missing.
VERIFIED COMPETENCY MILESTONE
