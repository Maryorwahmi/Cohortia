Module 3 › Chapter 3.1 › USTRUCT Example
Why USTRUCT?
  • Exposes grouped data to Blueprints and Editor.
  • Is value-type; copying semantics apply.
  • Good for serializable, lightweight game data.
Design tip
Use USTRUCT for small, composable data packets like stats or hit info.
Example struct
// MyStruct.h
#pragma once

#include "CoreMinimal.h"
#include "MyStruct.generated.h"

USTRUCT(BlueprintType)
struct FMyCustomData
{
  GENERATED_BODY()

  UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Custom Data")
  int32 ID;

  UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Custom Data")
  FString Name;

  UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Custom Data")
  float Value;

  FMyCustomData()
    : ID(0)
    , Name(TEXT("Default"))
    , Value(0.0f)
  {}
};
Common mistake
Treating a USTRUCT like a UObject reference leads to bugs; remember it copies when assigned.
Key Takeaway
USTRUCTs are ideal for editable, serializable data that designers and Blueprints can use safely.
