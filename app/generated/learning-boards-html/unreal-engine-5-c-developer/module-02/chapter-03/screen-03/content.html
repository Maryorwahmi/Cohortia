Module 3 › Chapter 2.3 › Practice & Validation
Four quick validation exercises
Create UObject class
Generate UMyDataContainer, add a UPROPERTY int, and compile to see generated code references.
Expose a function
Add a UFUNCTION and confirm it is callable from Blueprint.
Instantiate with NewObject
Create an instance in BeginPlay and log its value to verify creation and lifetime.
Test UPROPERTY removal
Remove UPROPERTY from a pointer in a controlled test to observe GC-related crashes.
Checklist
  • Confirm generated headers update when you add macros.
  • Use logs or on-screen debug messages to confirm creation.
  • Re-run after removing UPROPERTY to observe changes safely.
