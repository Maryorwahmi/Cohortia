Module 3 › Chapter 2.3 › Practice Questions
Question 1
Which declaration ensures a UWeapon instance owned by a character is tracked by GC?
Correct answer
Use UPROPERTY() UWeapon* CurrentWeapon; so the GC and reflection system track the reference.
Question 2
Which function should you use to create a UObject-derived instance and why?
Correct answer
Use NewObject<T>(Outer) because it registers the object with the engine and sets its Outer for proper lifecycle and GC handling.
Reflection prompt
When you review a codebase, look for UPROPERTY on UObject members and for NewObject usage where objects are created. Replace unsafe patterns incrementally and verify with small tests.
