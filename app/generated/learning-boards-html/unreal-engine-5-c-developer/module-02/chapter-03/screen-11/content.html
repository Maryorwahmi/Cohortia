Storing multiple UObjects safely
Use UPROPERTY with TArray to ensure GC inspects array contents and preserves objects while referenced.
Pattern
UPROPERTY() TArray<UMyObject*> MyObjects; // GC-aware container
If the array itself is not a UPROPERTY, the garbage collector will not examine its elements. For non-UObject data, regular C++ containers and smart pointers remain appropriate. Always match container annotations to their element types.
Checklist
  • Is the container a UPROPERTY when it contains UObject pointers?
  • Are elements non-owning references using TWeakObjectPtr where appropriate?
  • Do you initialize and clear arrays in a predictable lifecycle method?
