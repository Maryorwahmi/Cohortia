Module 3 › Chapter 2.3 › Debugging Lifetimes
Steps to reproduce lifecycle issues
1. Add logs when objects are created and right before they are expected to be destroyed. Observe timestamps and context.
2. Use IsValid or TWeakObjectPtr checks before using pointers to avoid crashes while investigating.
3. Build a minimal repro: create the object in BeginPlay, clear references, and run to see if GC reclaims it unexpectedly.
Pro tip
Temporarily add logging for the object's address and Outer to inspect ownership at runtime.
Quick check list
  • Is the pointer a UPROPERTY or TWeakObjectPtr?
  • Was the object created with NewObject and given the expected Outer?
  • Are there unexpected references preventing collection or missing references causing premature collection?
