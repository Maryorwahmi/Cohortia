NewObject instantiation
NewObject ensures the engine registers the UObject and assigns an Outer which participates in lifetime and hierarchy.
Example usage (conceptual)
// Create an instance with the owning actor as Outer
// NewObject<UMyCustomObject>(OwnerActor);
The exact code above registers the object with the engine and places it under OwnerActor's hierarchy for GC purposes.
Guidelines for choosing an Outer
  • Choose the logical owner: an actor for actor-owned data, a component for component-owned resources.
  • For global resources, a long-lived Outer such as GameInstance may be appropriate, but avoid leaking objects by over-long ownership.
  • Avoid raw new; it bypasses engine registration and GC tracking.
Key takeaway
NewObject is the safe factory and Outer defines the ownership path for GC and hierarchy.
