Understanding UObject & Garbage Collection
Why UObject, reflection, and NewObject matter for safe C++ in Unreal Engine

Unreal's UObject system centralizes features that raw C++ does not offer. It enables runtime reflection, serialization, networking, editor integration, and a garbage collector that only sees references declared via the reflection system. Learning these relationships prevents crashes and makes your components interoperable with the engine and editor.

Reflection
UCLASS, UPROPERTY, UFUNCTION feed UHT for runtime metadata.
GC
Engine GC traverses objects starting from root set to find reachable UObjects.
New Objects
Use NewObject<T> with an Outer to register with the engine.
