How to use these objectives
  • Inspect class headers to verify UPROPERTY decorations appear in generated code.
  • Instantiate UObjects at runtime and confirm editor or log output to validate creation.
  • Run a small scene and test for crashes to discover dangling pointers or missed UPROPERTYs.
  • Practice converting unsafe pointers into UPROPERTY or TWeakObjectPtr as appropriate.
