Module 3 › Chapter 2.3 › UPROPERTY & GC
Correct (GC-tracked)
UPROPERTY() on a UObject* member registers the reference in the reflection data so GC will consider the referenced object reachable.
Behavior
Object remains alive while referenced by UPROPERTY members during GC passes.
Incorrect (not tracked)
A raw UObject* without UPROPERTY is invisible to the generated reflection data and thus invisible to GC traversal, risking premature collection and dangling pointers.
Risk
Crash or undefined behavior when GC reclaims the referenced object.
Guidelines
  • Use UPROPERTY for owning member pointers to UObjects.
  • Use TWeakObjectPtr for non-owning references and check IsValid before use.
  • When in doubt, mark the member with UPROPERTY and document ownership semantics.
