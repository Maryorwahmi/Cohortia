Learning Objectives

Four practical setup and verification skills for UE5 C++ development.

Learn → Understand → Apply → Master
01
Install UE5 & Tools

Install Epic Games Launcher and Unreal Engine, ensuring you can access engine versions and create projects. Verified Competency Milestone

Mnemonic: launcher → engine
02
Select IDE workloads

Choose the "Game development with C++" and "Desktop development with C++" workloads in Visual Studio so compilers and SDKs are present. Verified Competency Milestone

Mnemonic: workloads = toolchain
03
Create a C++ project

Generate a project like MyFirstCPPProject with the C++ template and inspect generated files in the editor and IDE. Verified Competency Milestone

Mnemonic: project → solution
04
Compile & troubleshoot

Build from the editor and IDE, use hot reloading, and read output logs to resolve common errors. Verified Competency Milestone

Mnemonic: compile → inspect logs
