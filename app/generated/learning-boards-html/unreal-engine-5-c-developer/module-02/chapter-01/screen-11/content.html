How it works

Editor Compile and Hot Reload

Quick iteration
Click Compile in the editor after editing C++ to let the engine try to inject code changes without restarting.
When to restart
Restart after structural changes like new UPROPERTY/UFUNCTION, class hierarchy changes, or memory layout modifications.
Debugging tools
Output Log
Check compilation and runtime messages after using Compile in the editor.
Visual Studio Error List
When building in the IDE, consult the Error List for precise compiler and linker diagnostics.
Misconception
Hot reload is not guaranteed for structural changes; restart to avoid subtle inconsistencies.
