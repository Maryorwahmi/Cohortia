Step sequence

Create MyFirstCPPProject

  1. Open Unreal Engine and the Project Browser.
  2. Choose Games → select a template such as Blank or Third Person.
  3. Set Project Type to C++ and name the project MyFirstCPPProject.
  4. Choose No Starter Content for a lean setup.
  5. Click Create; wait for project files and the editor to open.
Practical note

Templates with a playable character help you test C++ gameplay code immediately after compile.
