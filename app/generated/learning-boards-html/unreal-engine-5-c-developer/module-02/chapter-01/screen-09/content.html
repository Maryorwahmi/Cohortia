Panel overview

Key editor panels

Viewport
Interact with the level, preview physics, and play the scene to test gameplay and visuals.
World Outliner
Lists all actors in the level so you can select and focus on the one you want to modify from code.
Details Panel
Shows editable properties; UPROPERTY-marked members from C++ appear here for designers to change.
Content Browser
Manage assets and find C++ classes that appear as usable assets after compilation.
Practical example
Test a new C++ actor
Compile your new actor class in the editor, locate it in the Content Browser, drag it into the Viewport, then inspect and tweak properties in the Details Panel while observing behavior in the Viewport.
Misconception

Changing properties at runtime does not always persist to C++ defaults; save and recompile if you need code defaults updated.
