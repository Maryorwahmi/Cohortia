Verify your setup with quick checks

Each milestone is a short verification you can perform after installation to ensure the next steps will succeed.

01 • Engine installed

Open the Epic Games Launcher and confirm your chosen engine version is listed in Library. If not, re-run the installer.

02 • Workloads present

In the Visual Studio installer, confirm "Game development with C++" and "Desktop development with C++" are selected and MSVC/Windows SDK components are installed.

03 • Project files generated

Create MyFirstCPPProject and check that a .uproject and a solution file exist in the project folder.

04 • Successful compile

Use the editor's Compile button, then inspect the Output Log or Visual Studio Error List to confirm a clean build.

Quick tip

If compilation fails, stop and inspect the installer selections first. Many errors stem from missing workloads rather than code bugs at this stage.
