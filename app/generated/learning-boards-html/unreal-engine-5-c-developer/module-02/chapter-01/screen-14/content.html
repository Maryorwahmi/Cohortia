Module 2 › Chapter 2.1 › Key Concepts
Epic Games Launcher
App used to download and manage Unreal Engine versions.
Visual Studio / Xcode
Integrated Development Environments for writing and building C++ code.
Workloads
Groups of components in Visual Studio such as "Game development with C++" that provide compilers and SDKs.
Summary

These components together create the environment Unreal needs to build and run C++ projects. Verify them first when debugging build issues.
