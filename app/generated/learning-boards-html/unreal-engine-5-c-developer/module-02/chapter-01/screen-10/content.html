Practical steps
Edit and build
Make a small change to a C++ class and run Build in Visual Studio to verify the compiler and linker work.
Common issue
If the IDE build fails with missing toolchain messages, add the correct Visual Studio workloads or install Xcode on macOS.
Check
A successful IDE build is your signal that the compiler and SDKs are present and functioning.
