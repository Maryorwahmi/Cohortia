Module 2 › Chapter 2.1 › Install UE5
Step-by-step

Install via Epic Games Launcher

1. Download Launcher
Install the Epic Games Launcher, then open it and sign into your account.
2. Library → Add Engine
Open the Unreal Engine tab and add a new engine version; pick the stable UE5 build you want to use.
3. Verify install
After download, confirm the engine entry appears in Library and can be launched.
Checks & tips
Select stable builds
Avoid preview releases for production work. If collaborating, standardize on an engine version.
Installation path
Choose a common path and ensure you have disk space; projects will reference this path.
Common mistake
Assuming the launcher icon equals the engine install. Verify in Library that the engine version is installed and launchable.
Test

Launch the engine and create a blank C++ project to confirm the editor opens and generates project files.
