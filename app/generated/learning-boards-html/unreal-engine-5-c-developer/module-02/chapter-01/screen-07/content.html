macOS toolchain

Install Xcode

Xcode supplies Clang, macOS SDKs, and the build tools Unreal needs on macOS.

Install from App Store
Install Xcode and accept required components. Then install command line tools if prompted.
Open generated project
After creating a C++ project, open the Xcode workspace to inspect targets and build settings.
Checks & troubleshooting
Verify toolchain
Run a small build in Xcode and watch the build log for missing SDK or compile errors.
Common misconception
The editor alone cannot compile without Xcode providing the compiler and SDKs on macOS.
Tip
Keep Xcode updated to match macOS SDK expectations in build logs when upgrading the engine.
