Lab checklist: install → create → compile

Follow each step and confirm the verification milestone before moving on.

Step 1
Install Launcher & UE5
Confirm engine appears in Library.
Step 2
Install IDE and workloads
On Windows include both C++ workloads; on macOS install Xcode.
Step 3
Create MyFirstCPPProject
Choose C++ template and No Starter Content for a minimal start.
Step 4
Compile in Editor
Click Compile and inspect the Output Log for success or errors.
Step 5
Open IDE & Build
Open the .sln or Xcode project and run Build to verify the IDE toolchain.
If something fails
Check installer selections, then rebuild and re-inspect logs. Work from the error messages outward.
Lab outcome

A successful lab results in a working project named MyFirstCPPProject and a clean build both in the editor and IDE.
