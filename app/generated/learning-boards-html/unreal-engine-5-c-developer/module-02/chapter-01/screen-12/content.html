Symptoms & causes

Diagnose build failures

Missing compiler or SDK
Cause: incomplete Visual Studio workloads or missing Xcode tools. Fix: add workloads or install Xcode command line tools.
Linker errors
Cause: incorrect include/library paths or plugin conflicts. Fix: check project settings and try disabling third-party plugins.
First steps
Check logs
Open the Output Log in the editor and the Error List in the IDE to read exact messages.
Reinstall or add components
If workloads are missing, run the Visual Studio installer and add them, then rebuild.
Misconception
Assuming code is wrong before verifying the environment. Always check toolchain and logs first.
