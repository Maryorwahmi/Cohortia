Common Errors
  • Missing generated header include stops reflection code generation.
  • Forgotten UPROPERTY means the field won't appear in the Editor.
  • Incorrect specifier syntax causes build-time reflection errors.
  • Heavy Tick logic degrades performance if run every frame unnecessarily.
Best Practices
  • Keep generated include last in the header.
  • Group properties using Category to help designers.
  • Use BlueprintCallable for functions designers should trigger.
  • Prefer events, timers, or delegates over Tick when possible.
Quick recovery
If reflection errors occur, check the header for misplaced macros or invalid specifier lists, fix the issue, recompile, and recheck the editor for the property/function presence.
