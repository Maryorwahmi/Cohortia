Module 2 › Chapter 2.2 › C++ vs Blueprints
C++ (Core Systems)
Precise control, better performance, suitable for complex algorithms and engine changes. Use it for per-frame heavy logic or memory-sensitive code.
Example
Implement interaction distance calculations and optimized search in C++ so they run fast every frame.
Common mistake
Putting designer-editable fields only in C++ with no exposure makes iteration slow for artists.
Blueprints (Iteration)
Fast to prototype, visual, and accessible to non-programmers. Ideal for event wiring, tuning, and designer-controlled behaviors.
Example
Expose an interaction range via UPROPERTY and let designers adjust it in the Details Panel or Blueprint child.
Common misconception
Thinking Blueprints cannot scale — they can, but heavy per-frame logic is better in C++.
Analogy
Treat C++ as the engine room and Blueprints as the control panel. Place heavy machinery in the engine room and let designers flip switches on the panel.
