Module 2 › Chapter 2.2 › Checklist
Step 1
Create class with Actor base
Use Unreal Editor's File → New C++ Class, name it MyFirstActor.
Step 2
Add macros and specifiers
Add UCLASS(Blueprintable, BlueprintType), then UPROPERTY and UFUNCTION as needed.
Step 3
Implement lifecycle methods
Override BeginPlay and Tick; add debug messages to validate behavior.
Step 4
Compile and test in editor
Drag the actor into your level, inspect the Details Panel, and call functions from the editor or Blueprints.
