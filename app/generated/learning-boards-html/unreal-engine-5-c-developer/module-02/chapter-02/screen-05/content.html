Module 2 › Chapter 2.2 › Create Class
Wizard Steps
  1. 1. File → New C++ Class → choose Actor base.
  2. 2. Name the class MyFirstActor and create it.
  3. 3. Let the Editor generate the header and source files.
  4. 4. Open files in your IDE and inspect stubs like BeginPlay and Tick.
  5. 5. Compile in Editor and drag the actor into your level.
Why this matters
Following the full flow registers your class with the engine and ensures reflection metadata is generated correctly.
Quick checklist
  • Confirm #include "YourClass.generated.h" is present and last.
  • Verify UCLASS macro above the class declaration.
  • Compile and watch the Output Log for reflection errors.
Misstep to avoid
Modifying files before the build finishes can cause missing generated headers until the build is complete.
