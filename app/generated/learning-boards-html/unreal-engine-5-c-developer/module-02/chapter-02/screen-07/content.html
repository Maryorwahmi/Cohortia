Module 2 › Chapter 2.2 › UCLASS()
What it does
Enables reflection so the Editor can see, serialize, and manage the class. Required for UPROPERTY and UFUNCTION to work.
Example specifiers
Blueprintable, BlueprintType — add them when you want Blueprint subclasses or Blueprint variables that reference the type.
Pitfalls
Forgetting the generated header include or adding macros incorrectly will prevent reflection data from being produced at build time.
Check this
Make sure #include "YourClass.generated.h" is the last include in the header file.
Analogy
Think of UCLASS as registering the class with the engine's directory so the Editor can list and interact with it. Specifiers control what registry notes are added.
