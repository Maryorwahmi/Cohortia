Module 2 › Chapter 2.2 › Key Concepts
UCLASS()
Registers a C++ class with Unreal's reflection system so the Editor can use it.
UPROPERTY() / UFUNCTION()
Expose variables and methods to the Editor and Blueprints with controlled access.
Lifecycle
Constructor sets defaults; BeginPlay initializes runtime state; Tick updates per frame when enabled.
Summary

Combine C++ control with Blueprint exposure: write core logic in C++ and expose simple, safe hooks for designers to tune and extend.
