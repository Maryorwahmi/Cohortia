Module 2 › Chapter 2.2 › UFUNCTION()
Common Specifiers
  • BlueprintCallable — callable from Blueprints.
  • BlueprintPure — read-only function returning a value, no execution pins in Blueprint.
  • Server/Client/NetMulticast — used for networked functions (advanced).
Parameter tips
Use const references for large types and mark UObject inputs carefully to avoid lifetime issues.
Example Declaration
UFUNCTION(BlueprintCallable, Category = "My Functions")
void PrintMyMessage();
Marking a method this way makes it visible to Blueprint graphs and editor call sites that support function invocation.
