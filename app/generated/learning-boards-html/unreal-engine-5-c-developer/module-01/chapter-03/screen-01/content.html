Decisions and repetitions that run your game

Explore the statements that let your code branch and repeat. These are the building blocks for player state, menus, enemy loops, and simple game AI.

In this lesson • Coming up: conditionals, switch, loops, break/continue
Conditionals
Use if, else if, else to check conditions and take different actions when they are true or false.
Loops
Use for, while, and do-while to repeat logic for enemies, items, or the main game loop.
Branching
Switch statements offer clean multi-way branching for discrete choices like menu options.
Loop Control
Break and continue alter loop flow to exit early or skip iterations, useful in search or filtering logic.
