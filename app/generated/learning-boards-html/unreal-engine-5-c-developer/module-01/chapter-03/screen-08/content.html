Module 2 › Chapter 1.3 › While loop
When to use

Repeat until a condition changes

Use while when the number of iterations is unknown and depends on runtime events like player actions or incoming network messages.

Example
int enemiesRemaining = 3;
while (enemiesRemaining > 0) {
    std::cout << "Enemy defeated! " << enemiesRemaining << " remaining." << std::endl;
    enemiesRemaining--; // Update ensures termination
}
std::cout << "All enemies cleared!" << std::endl;
Safety note
If you forget to update the counter or change the condition, the loop becomes infinite. Always verify the transition that will make the condition false.
Defensive pattern
Consider adding a maximum-iteration counter inside complex while loops to bail out if something goes wrong.
Key Takeaway

While runs while a condition is true. Ensure the loop body makes progress toward termination to avoid infinite execution.
