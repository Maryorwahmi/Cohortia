Module 2 › Chapter 1.3 › For loop
Structure

Initialization · Condition · Increment

Use when you know how many iterations you need. Count from zero when indexing arrays or tiles to avoid off-by-one errors.

Example — spawn enemies
// Simulate spawning 5 enemies
for (int i = 0; i < 5; i++) {
    std::cout << "Spawning enemy #" << (i + 1) << std::endl;
}
Common error
Using i <= 5 when you intended 5 iterations starting at zero will run six times. Prefer i < count when counting from zero.
Debugging tip
Print the loop index and the condition to confirm how many iterations actually occur under different inputs.
Key Takeaway

For loops are for fixed counts. Pick bounds carefully and ensure the increment makes progress toward loop termination.
