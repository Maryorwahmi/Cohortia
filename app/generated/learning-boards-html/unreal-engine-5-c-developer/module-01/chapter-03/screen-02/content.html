Learning Objectives

Master concrete control flow patterns for C++ game code and avoid common bugs.

Bloom: Learn → Understand → Apply → Master
01 • Conditionals
Implement if / else if / else

Write code that branches on runtime state, for example showing "Game Over" when player health is zero. This matters because branching controls how your game reacts to events.

VERIFIED COMPETENCY MILESTONE
02 • Switch
Use switch for multi-way branching

Handle discrete choices like menu selections cleanly. Remember to use break to avoid fall-through and include a default for unexpected values.

VERIFIED COMPETENCY MILESTONE
03 • Loops
Construct for, while, do-while loops

Repeat updates like enemy ticks or input polling. Learn the right loop for a known count, unknown count, or guaranteed-at-least-once behavior.

VERIFIED COMPETENCY MILESTONE
04 • Break & Continue
Control loop flow

Use break to exit when a condition is met and continue to skip an iteration. This is essential for efficient searches and filtering inside loops.

VERIFIED COMPETENCY MILESTONE
