Module 2 › Chapter 1.3 › Loop + Conditional Pattern
Pattern

Iterate entities and branch per item

Process each game entity with focused checks: skip if disabled, update if active, and remove when finished. Manage removals carefully to avoid index errors.

Scenario
For each enemy: if disabled, continue. Apply movement and damage. If enemy health <= 0, mark for removal or remove safely after the loop.
Pitfall
Removing items while iterating forward can skip the next item. Iterate backwards or collect indices to remove after the loop.
Best practice
Keep loop bodies short and side-effect-free where possible. Use helper functions to encapsulate complex per-entity logic.
Key Takeaway

Compose loops and conditionals to process game entities safely. Avoid in-loop modifications that change indexing unexpectedly.
