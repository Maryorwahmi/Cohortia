Module 2 › Chapter 1.3 › Break & Continue
What they do

Exit early or skip an iteration

Use break to stop searching once you find what you need. Use continue to avoid processing unwanted entries but keep iterating.

Example
for (int i = 0; i < 10; i++) {
    if (i == 3) {
        continue; // Skip printing 3
    }
    if (i == 7) {
        break; // Exit loop when i is 7
    }
    std::cout << i << " ";
}
// Output: 0 1 2 4 5 6
Nested loops note
Break only exits the innermost loop. To exit multiple layers, consider flags or structured control flow outside the loops.
When to avoid
Avoid using break and continue to patch unclear loop conditions. Prefer clearer loop predicates when possible for maintainability.
Key Takeaway

Break and continue let you control loop flow precisely. Use them for efficient searches and skipping undesired iterations.
