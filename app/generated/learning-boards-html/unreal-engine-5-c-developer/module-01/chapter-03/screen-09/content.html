Module 2 › Chapter 1.3 › Do-while loop
Behavior

Execute once, then repeat if true

Useful for an input prompt or a menu where you must show options at least once and then repeat based on a response.

Example
char playerInput;
do {
    std::cout << "Press 'Q' to quit: ";
    std::cin >> playerInput;
} while (playerInput != 'Q' && playerInput != 'q');
std::cout << "Exiting game loop." << std::endl;
Misconception
Do not assume do-while is interchangeable with while. Use it only when initial execution is required regardless of the condition.
Practical tip
For console input, validate input inside the loop before using it to avoid processing invalid values in the first iteration.
Key Takeaway

Do-while guarantees one execution before the condition is checked. Use it for prompts or menus that must appear first.
