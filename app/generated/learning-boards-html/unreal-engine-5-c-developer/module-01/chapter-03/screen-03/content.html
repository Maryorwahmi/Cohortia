Objective focus

Safe comparisons and loop exits

Small mistakes like using assignment instead of equality or missing an increment can cause wrong behavior or infinite loops. Practice writing explicit checks and updating counters reliably.

Mnemonic
Check then change. Compare values before making assignments that alter state.
Scenario
Loop until player guesses correctly, but limit attempts to avoid infinite waiting.
Verified competency

You should be able to explain and identify off-by-one mistakes, write a loop with a safe exit, and choose the correct branching structure for a menu or state check.
