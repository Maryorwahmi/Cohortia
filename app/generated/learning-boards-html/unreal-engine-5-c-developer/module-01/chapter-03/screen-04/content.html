Module 2 › Chapter 1.3 › If statement
Definition

If — single conditional execution

Use when you need to run a block only if one condition is true. Not a loop; it does not repeat.

Common operators used in conditions:
  • Equality and inequality: ==, !=
  • Comparisons: <, >, <=, >=
  • Logical combination: &&, ||, !
Concrete example
int playerHealth = 75;
if (playerHealth <= 0) {
  std::cout << "Player has been defeated! Game Over." << std::endl;
}
Common mistake
Using = instead of == changes the value instead of comparing it. That can silently alter program state and produce hard-to-find bugs.
Pro tip
Test boundary values like zero and negative health to ensure your condition covers edge cases.
Key Takeaway

If executes code once when a condition is true. Use it for single decisions such as handling death or unlocking a door.
