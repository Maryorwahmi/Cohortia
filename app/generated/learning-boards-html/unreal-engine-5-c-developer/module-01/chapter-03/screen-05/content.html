Module 2 › Chapter 1.3 › Else-if chains
Pattern

Choose one action among many

Place conditions from most specific to least specific and rely on the fact that later checks only run if earlier ones were false.

Example
int playerScore = 1200;
if (playerScore >= 2000) {
  std::cout << "You achieved a Gold rank!" << std::endl;
} else if (playerScore >= 1000) {
  std::cout << "You achieved a Silver rank!" << std::endl;
} else {
  std::cout << "Keep practicing for a higher rank!" << std::endl;
}
Misconception
Placing ranges out of order can cause higher tiers to never be reached. Always check the largest thresholds first if using greater-than comparisons.
Quick check
Rewrite an overlapping chain so each case is exclusive. For example, use else-if with descending thresholds or use range checks that avoid overlap.
Key Takeaway

Else-if chains make single-choice decisions among many conditions; order them deliberately.
