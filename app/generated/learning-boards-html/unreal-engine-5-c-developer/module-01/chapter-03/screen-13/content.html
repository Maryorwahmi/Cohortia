Module 2 › Chapter 1.3 › Loop comparison
For
Best when count is known. Compact form expresses loop variables and progression.
While
Best when repetition depends on a condition that may change at runtime.
Do-while
Guarantees at least one execution before checking the condition, ideal for prompts.
Practical test
Try the same enemy update with each loop type and test zero, one, and many enemies to see how initial conditions affect execution.
