When to use

Discrete-choice branching

Use switch when the value you check can take a limited set of known discrete values. It reads better than many else-if checks for this case.

Example
int playerChoice = 2; // 1 Attack, 2 Defend, 3 Use Item
switch (playerChoice) {
    case 1:
        std::cout << "Player attacks!" << std::endl;
        break;
    case 2:
        std::cout << "Player defends!" << std::endl;
        break;
    case 3:
        std::cout << "Player uses an item!" << std::endl;
        break;
    default:
        std::cout << "Invalid choice." << std::endl;
        break;
}
Watch out
Dropping break causes fall-through, which often leads to multiple case blocks running unintentionally. Only use fall-through when intentionally combining logic between cases.
Pro tip
Use enums or named constants for case labels to improve readability and avoid magic numbers in your switch statements.
Key Takeaway

Switch is concise for exact matches. Use break to stop execution and default to catch unexpected values.
