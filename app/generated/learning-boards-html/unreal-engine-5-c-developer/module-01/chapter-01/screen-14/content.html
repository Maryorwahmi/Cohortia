Key Concepts — Part 1

C++
A performance-oriented language used to build game engines and systems.
Compiler
Transforms source code into machine-executable binary code.
IDE
Manages projects, runs builds, and integrates debugging tools like breakpoints and stepping.
Summary

These three terms are the foundation: they explain how code becomes a running program and where to look when problems occur.
