The preprocessor and headers

Headers provide declarations; the preprocessor inserts them before compilation.

What happens
During preprocessing, include directives are replaced with the header content so the compiler sees the full declarations when compiling the translation unit.
Practical tip
Use include guards or pragma once to prevent multiple inclusion errors when headers are referenced from many files.
Example
Including iostream provides declarations for the output object and related types used to print text to the console.
Common error
Missing include leads to a compile-time error because the compiler doesn't know the symbol's declaration.
Key Takeaway

Headers supply declarations. Ensure correct includes and guards to avoid compilation and linking issues.
