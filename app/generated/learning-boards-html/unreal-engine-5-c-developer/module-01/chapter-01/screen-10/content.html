Module 1 › Chapter 1.1 › Console Output
Code Walkthrough
#include <iostream>

int main()
{
  std::cout << "Hello!" << std::endl;
  std::cout << "Multiple lines" << std::endl;
  return 0;
}
Chaining output and using the newline manipulator ensures clear, flushed console output suitable for debug prints in small programs.
Common Mistakes
• Forgetting to include iostream results in an unknown symbol error. • Omitting the std:: prefix leads to unresolved identifier unless a using declaration is present.
Practice Task
Try printing a personalized message and two additional lines to practice chaining and flushing behavior.
Key Takeaway

Master basic output early — it's the simplest way to confirm program flow and variables when you begin debugging.
