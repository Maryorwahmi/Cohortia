Create a Console App

Template files and project settings let you compile immediately.

Quick Steps
  1. Open Visual Studio and choose Create a new project.
  2. Select Console App (C++) and give it a name like MyFirstGameProgram.
  3. Open Source.cpp or main.cpp and review the main function.
Verification
Build the solution. A successful build produces an executable you can run from the IDE or terminal.
Example activity
Change the greeting text in the template to a personalized message and rebuild. If compilation succeeds, run it to see your message in the console.
Key Takeaway

A template project gives you a reliable sandbox to test compilation before moving to engine projects.
