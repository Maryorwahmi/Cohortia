Common compilation errors

Identify the error, inspect the indicated line, then correct and rebuild.

Missing semicolon
Symptoms: syntax error, many cascading errors; Fix: add the semicolon at the end of the statement.
Missing include
Symptoms: unknown identifier for library symbols; Fix: add the appropriate header such as iostream.
Missing std::
Symptoms: unresolved identifier; Fix: prefix with std:: or add an explicit using declaration carefully.
Assessment idea
Given a small snippet with two errors, identify and correct them. Practice reading the error list to find the root cause.
Key Takeaway

Start with the first reported compiler error. Fixing it often resolves many subsequent errors.
