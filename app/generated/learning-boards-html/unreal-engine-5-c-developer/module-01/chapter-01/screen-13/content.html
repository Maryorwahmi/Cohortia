Hands-on: Hello World

Follow these steps in Visual Studio to confirm your toolchain.

Steps
  1. Create a Console App project named MyFirstGameProgram.
  2. Open Source.cpp or main.cpp and paste the example code.
  3. Build the solution and run without debugging to see console output.
Challenge
Modify the greeting to include your name and print a second line. Rebuild and run to confirm both lines appear.
Troubleshooting
If you see compiler errors, read the first one, go to the file and line number, fix the code, and rebuild. For missing includes, add the iostream header.
Key Takeaway

A short lab that compiles and runs proves your environment and builds essential debugging habits.
