Definition

Essential parts of a program

• #include: a preprocessor directive that inserts declarations from headers so the compiler knows about functions and types.
• main(): the entry point where execution begins. It returns an integer status.
• return 0;: signals successful termination to the operating system.
• std::cout and the insertion operator send text to the console via the iostream library.
Code Walkthrough
#include <iostream>

int main()
{
  std::cout << "Hello, Cohortia Game Developer!" << std::endl;
  return 0;
}
This snippet includes the iostream header, prints a greeting, and returns a success code. Use it to verify your build.
Key Takeaway

Recognize includes, entry points, and return codes. These recur across C++ projects, including engine tools.
