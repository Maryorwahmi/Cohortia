Module 1 › Chapter 1.2 › char, bool, const
Definition

Characters, booleans, and immutable values

Use char for single symbols; bool for true/false flags. Use const to protect values that must not change during execution.
char example
char initial = 'J'; // single letter stored as a small integer
bool example
bool hasKey = false; // true or false state for gameplay logic
const example
const float GAME_GRAVITY = 9.81f; // protects a constant game parameter
Pitfall & tip
Chars promote to ints in arithmetic. When mixing char with numeric operations, be explicit to avoid surprises. Use bool for binary logic rather than integers for clearer code.
Key Takeaway

Choose small types for clarity, and use const to declare invariants that document and enforce intent.
