Process

Declare, then initialize or initialize immediately

Choose one of these safe forms and prefer initializing at declaration to avoid undefined values.
Pattern 1 — Declare & Initialize
int playerScore = 0; // recommended for counters and scores
Pattern 2 — Declare then assign
int enemyCount; enemyCount = 5; // allowed, but riskier if read before assign
Pattern 3 — Constant
const float MAX_HEALTH = 100.0f; // prevents accidental change
Key Takeaway

Prefer initialization at declaration and use const for values that must not change.

Common examples
<!-- Code panel --> 
#include <iostream>

int main() {
  int playerScore = 0;
  float playerHealth = 100.0f;
  bool isGameOver = false;
  const int MAX_PLAYERS = 4;

  // Later in code
  playerScore += 10;
  return 0;
}
Note: using the 'f' suffix on 100.0f indicates a float literal. Without it the literal is double and may be implicitly converted.
