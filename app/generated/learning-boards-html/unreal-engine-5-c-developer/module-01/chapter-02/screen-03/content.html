Practice checks and common mistakes

These objectives focus on real bugs you will encounter and simple verification steps to confirm your fixes.

01 — Integer sizes
Explain short vs long vs long long and when unsigned improves range for counts like total currency, then test with edge values.
02 — float vs double
Justify using float for game logic positions and double for engine calculations; run small math to see precision differences.
03 — Integer division
Show 15 divided by 4 with int operands, then cast to float to get the true fractional average.
04 — Init & mismatch
Always initialize variables and prefer explicit casts when converting between types to avoid silent truncation.
