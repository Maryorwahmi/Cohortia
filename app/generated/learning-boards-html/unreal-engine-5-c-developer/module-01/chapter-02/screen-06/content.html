Comparison

int vs short vs long vs unsigned

int
Default choice for counters and scores. Balance of range and performance.
short / long
Use only when memory or range needs demand it; long long for very large totals.
unsigned
For strictly non-negative values. Beware of underflow when subtracting.
Mixing types
Implicit conversions between signed and unsigned can yield surprising results; use explicit casts.
Concrete scenario
Use int for enemyCount and score. Use unsigned for inventory slots if you are confident values remain non-negative. If totals may grow enormous, choose long long.
Example & warning
// Example
int score = 100;
unsigned int coins = 50;
// Subtracting signed value from unsigned can underflow
int penalty = 75;
coins = coins - penalty; // careful: unsigned underflow possible
Check your arithmetic and conversions when mixing signed and unsigned values; prefer explicit casts to document intent.
