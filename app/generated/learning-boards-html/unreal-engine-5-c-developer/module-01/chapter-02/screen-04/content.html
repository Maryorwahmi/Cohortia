Module 1 › Chapter 1.2 › What is a Variable?
Definition

Variable as named storage

A variable binds a name to a value and allocates memory sized by its type. This binding lets your code read and write game state predictably when initialized correctly.

Analogy
Imagine labeled boxes for health, score, and position. If a box is empty you cannot rely on its contents—initialize it before use.
Example
int playerScore = 0; // a labeled box starting at zero
Misconception
Declaring without initializing leaves unpredictable data in that memory location.
Visual: variable anatomy
Name
Label you use in code
Type
Determines size and interpretation
Value
The current data stored in memory
Key Takeaway

Always choose a type that matches the data's nature and initialize variables to prevent undefined behavior.
