Comparison

Precision and performance trade-offs

Float uses less memory and is commonly used for positions, rotations, and per-vertex data. Double gives you more numeric precision which can be important for long-running accumulations or physics steps in engine code.
When to use float
Large arrays of coordinates, per-frame game logic, and when memory and cache are a priority.
When to use double
Critical engine calculations, physics integrators over long durations, or precise numeric tools.
Example test
// Accumulate small steps many times
float posF = 0.0f;
for (int i=0; i<1000000; ++i) posF += 0.0001f;

double posD = 0.0;
for (int i=0; i<1000000; ++i) posD += 0.0001;

// Compare final results to see drift
Run this loop to observe larger rounding drift in float than double. Use the result to decide which type fits your subsystem.
