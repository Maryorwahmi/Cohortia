Definition & fix

Truncation and explicit casting

When dividing two ints, the fractional part is dropped. To keep fractions, ensure a float or double operand via literal suffix or cast.
// Integer division truncates
int a = 15;
int b = 4;
float avg1 = a / b; // avg1 == 3.0 due to integer division

// Correct: make one operand float
float avg2 = static_cast(a) / b; // avg2 == 3.75
Misconception check
Assigning integer division into a float does not produce the missing fraction. Always inspect operand types first.
Pro Tip

Use static_cast to explicitly convert types; it makes your intent clear to reviewers.
