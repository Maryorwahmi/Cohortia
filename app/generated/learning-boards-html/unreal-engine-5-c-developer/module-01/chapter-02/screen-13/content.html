Common Mistakes

Uninitialized variables and type issues

Uninitialized
Declare and initialize to a safe default, e.g., int count = 0; to avoid garbage values.
Type mismatch
Use explicit casts to show intent and avoid silent truncation or sign changes.
Integer division
Cast before division to preserve fractions; do not rely on assigning to float afterwards to fix truncation.
Debugging tip
Print intermediate values with std::cout to quickly inspect state and find where a value diverges from expectations.
Input handling
After failed extraction, clear std::cin and ignore the rest of the line before re-prompting the user.
Key Takeaway

Small disciplined habits—initialize, cast explicitly, check divisors, validate input—prevent many early bugs and speed development.
