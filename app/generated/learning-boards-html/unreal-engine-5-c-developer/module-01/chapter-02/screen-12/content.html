Architecture

How insertion and extraction work

std::cout uses the insertion operator to stream text and variables. std::cin uses extraction to parse input into variables but stops at whitespace, making it unsuitable for multi-word strings without getline.
Example prompts
std::cout << "Enter name: "; std::cin >> playerName; // reads a single word
Input mismatch
If the user types letters where an int is expected, extraction fails and the stream enters a failed state. Clear and recover before retrying.
Common patterns
  • Prompt clearly and validate immediately after extraction.
  • Use std::getline for full-line text when spaces are needed.
  • Handle failed input by clearing the stream state and ignoring bad input before retrying.
Pro Tip

For console demos keep prompts simple and validate types to make tests reliable.
