Rule set

Order of evaluation and safe patterns

Multiplication and division before addition and subtraction. Use parentheses to express intent and avoid subtle bugs.
Example 1
2 + 3 * 4 evaluates to 14. To change order, use (2 + 3) * 4 which evaluates to 20.
Example 2 — Modulo
10 % 3 yields 1. Useful for wrapping indices and checking parity.
Guard division
Always check for zero in divisors to avoid runtime errors or undefined behavior.
