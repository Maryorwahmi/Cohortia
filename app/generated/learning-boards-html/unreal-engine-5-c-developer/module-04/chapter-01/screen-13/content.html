Architecture
Scaling & Best Practices
Context organization
  • Group related actions: Movement, Combat, Driving, UI.
  • Use shared context for global actions like Pause.
  • Activate or remove contexts when entering gameplay states.
Priority
Pass a priority integer to AddMappingContext to determine which context's mappings win during overlaps.
Performance & clarity
Avoid creating many unneeded Input Actions. Prefer clear naming and document each IMC's purpose. Keep bindings in one place per pawn or controller to reduce scattered logic.
Safety note
Excessive contexts and actions make debugging harder and can incur maintenance overhead. Design modularly.
