What to Remember
Key Concepts
Input Actions
Typed assets that define player commands like Move or Fire.
Mapping Contexts
Collections mapping physical inputs to actions and activated per local player.
Binding in C++
Cast to UEnhancedInputComponent and BindAction with the correct trigger and typed reads.
Summary Takeaway

Design input as intent-first: assets express player commands, contexts map devices, and C++ handlers read typed values. This pattern makes input consistent across devices and gameplay states.
