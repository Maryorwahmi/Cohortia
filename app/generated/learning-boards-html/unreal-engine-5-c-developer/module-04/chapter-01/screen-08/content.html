Core Concept
BindAction in SetupPlayerInputComponent
Cast the input component and attach handlers for Input Actions.
Example code
void AMyPawn::SetupPlayerInputComponent(UInputComponent* PlayerInputComponent)
{
    Super::SetupPlayerInputComponent(PlayerInputComponent);

    // Cast to Enhanced Input Component
    if (UEnhancedInputComponent* EnhancedInputComponent = Cast<UEnhancedInputComponent>(PlayerInputComponent))
    {
        // Bind the Move Action
        if (MoveAction)
        {
            EnhancedInputComponent->BindAction(MoveAction, ETriggerEvent::Triggered, this, &AMyPawn::Move);
        }

        // Bind the Look Action
        if (LookAction)
        {
            EnhancedInputComponent->BindAction(LookAction, ETriggerEvent::Triggered, this, &AMyPawn::Look);
        }
    }
}
Checklist
  • Cast UInputComponent to UEnhancedInputComponent before binding.
  • Ensure MoveAction and LookAction UPROPERTY pointers are assigned.
  • Choose an appropriate ETriggerEvent for each action.
Common mistake
Using the base input component's BindAction will not accept UInputAction pointers. Always cast.
