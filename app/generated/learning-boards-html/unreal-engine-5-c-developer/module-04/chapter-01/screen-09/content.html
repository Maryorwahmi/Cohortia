Reading FInputActionValue
Move handler example
void AMyPawn::Move(const FInputActionValue& Value)
{
    // Read the FVector2D value from the action
    FVector2D MovementVector = Value.Get<FVector2D>();

    // We'll implement actual movement logic in the next chapter
    UE_LOG(LogTemp, Warning, TEXT("Move Input: %s"), *MovementVector.ToString());
}

void AMyPawn::Look(const FInputActionValue& Value)
{
    FVector2D LookAxisVector = Value.Get<FVector2D>();
    UE_LOG(LogTemp, Warning, TEXT("Look Input: %s"), *LookAxisVector.ToString());
}
Quick guidance
  • Match Get<Type> with the Input Action's Value Type.
  • Log values first to validate mapping and orientation.
  • Check Controller before applying gameplay changes to avoid null pointers.
