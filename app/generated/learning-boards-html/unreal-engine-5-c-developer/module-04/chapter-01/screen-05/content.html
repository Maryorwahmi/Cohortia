Definition
Input Action Value Types
Pick the payload shape that matches your gameplay needs.
Digital
Boolean-style events for single presses: Jump, Fire. Trigger events like Started and Completed are meaningful here.
Axis1D
Single float values like throttle or trigger pressure.
Axis2D
Two-dimensional vectors for movement or look; use FVector2D in handlers.
Concrete examples
  • IA_Fire: Digital — one-shot when pressed.
  • IA_Throttle: Axis1D — analog trigger values.
  • IA_Move: Axis2D — returns FVector2D for forward/right axes.
  • IA_Position: Axis3D — used rarely for 3D controllers or spatial input.
Common mistake
Picking Digital for a joystick axis results in loss of analog information and incorrect handler types.
