Comparison
ETriggerEvent choices
Started
Fires once at the start of an input. Use for single-press actions like FireWeapon.
Triggered
Fires repeatedly while input is active. Use for continuous movement or analog values.
Completed
Fires when input ends. Useful for actions that should occur on release.
Assessment snippet
// Correct bind for a single-shot fire
EnhancedInputComponent->BindAction(IA_Fire, ETriggerEvent::Started, this, &AMyCharacter::FireWeapon);
