Hands-on Activity
Create a basic C++ pawn and set up input
Steps
  1. Create a C++ Pawn named MyPlayerPawn.
  2. Create IA_Move (Axis2D) and IA_Look (Axis2D) in Content Browser.
  3. Create IMC_Player and map W/A/S/D and Mouse X/Y.
  4. Add IMC in BeginPlay via AddMappingContext.
  5. Cast to UEnhancedInputComponent in SetupPlayerInputComponent and BindAction.
  6. Assign assets to pawn defaults, place pawn, and play.
Starter header and snippets
// MyPlayerPawn.h (excerpt)

Test
Assign the IMC and actions in the pawn defaults, play, and verify Move Input logs appear in the Output Log when pressing W/A/S/D.
