Process Flow
Configure IMC_Player
Map physical inputs to actions and use modifiers for axis orientation.
Step-by-step
  1. Create IMC_Player in Content Browser via Input → Input Mapping Context.
  2. Add Mapping: select IA_Move (Axis2D) and add W, S, A, D with appropriate modifiers.
  3. Use Swizzle( XYZ→YXZ ) or Negate to ensure keys feed X and Y correctly.
  4. Add Mapping: select IA_Look and add Mouse X and Mouse Y; negate Mouse Y if you prefer inverted look.
  5. Save and assign the IMC to your pawn or controller UPROPERTY for runtime use.
Example mapping card
IA_Move → Keyboard
W = Y+, S = Y-, A = X-, D = X+
IA_Look → Mouse
Mouse X = X axis, Mouse Y = Y axis (Negate for inverted pitch)
Pro tip
Test mappings in PIE and verify the Output Log receives FVector2D values in your handlers.
