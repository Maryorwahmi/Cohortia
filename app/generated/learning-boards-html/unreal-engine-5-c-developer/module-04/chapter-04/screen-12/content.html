Common Mistake
Why an event never fires
A step-by-step checklist to locate configuration issues preventing delegates from being called.
  1. Confirm components are created and registered on the actor.
  2. Check Object Type and Collision Responses on both components.
  3. Ensure Generate Overlap Events or Notify Rigid Body Collision is enabled as required.
  4. Verify UFUNCTION signature matches delegate and AddDynamic binding succeeded.
  5. Use Show → Collision in the editor and observe the Output Log for UE_LOG prints.
Quick Fix

Temporarily set the responses to OverlapAll or BlockAll to force a visible event, then adjust the matrix to the intended configuration once you confirm which event fires.

Pro Tip
Add UE_LOG at the end of your constructor to confirm your AddDynamic lines ran; missing logs indicate binding did not occur.
