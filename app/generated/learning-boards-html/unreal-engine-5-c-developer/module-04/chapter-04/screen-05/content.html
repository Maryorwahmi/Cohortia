Definition
Presets & Object Types
Presets are ready-made response sets; object types categorize components for matrix-based filtering.
Collision Preset
A convenient profile such as BlockAll or OverlapAll used to assign default responses quickly.
Object Type
Labels the component (e.g., Pawn, WorldStatic, Projectile) used by the response matrix to determine interactions.
Key Takeaway

Use presets for quick setup; use custom channels and object types to precisely control which things block, ignore, or overlap one another.

Concrete Scenario
Create a Projectile object type that blocks world geometry and characters but overlaps pickups. Assign the Projectile preset to your projectile's collision component.
Common Mistake
Relying only on presets without checking the matrix. A preset may not set the response you expect to a custom channel, so always inspect the responses after creating channels.
Quick Checklist
  • Confirm Object Type is correct for the component.
  • Check the response to each relevant channel: Block, Overlap, or Ignore.
  • When in doubt, create a custom Projectile channel for clarity.
