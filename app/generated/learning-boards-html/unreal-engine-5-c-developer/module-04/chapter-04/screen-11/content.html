Comparison
Overlap vs Hit
A quick comparison to help you decide which event to use.
Overlap
Non-blocking, needs Generate Overlap Events, used for triggers and pickups.
Hit
Blocking or physics collision, requires Block responses and physics or notify flags for events.
Consideration

Match the event type to gameplay intention: notification only or physical response. Confirm flags and object-type responses so the engine emits the expected event.

Scenario Cards
Healing Zone
Use Overlap, enable Generate Overlap Events, set zone to Overlap Pawn.
Force Field
Use Hit/Block. Ensure collision is set to Block and player capsule will be stopped; enable notify or physics as needed.
