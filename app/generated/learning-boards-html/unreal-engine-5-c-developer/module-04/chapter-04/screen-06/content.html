Definition
Overlap Events
Non-blocking notifications fired when shapes intersect and at least one side generates overlap events.
Requirements
  • At least one component has Generate Overlap Events = true
  • Collision response between object types is set to Overlap
  • Bind OnComponentBeginOverlap to a UFUNCTION with AddDynamic
Key Takeaway

Use overlaps for triggers and pickups. If you want a physical stop, choose hit-based blocking instead.

Concrete Example
A healing zone is a UBoxComponent set to Overlap the Pawn object type, with Generate Overlap Events enabled. OnComponentBeginOverlap grants health when the player's capsule enters.
Common Mistakes
Forgetting Generate Overlap Events or setting the response to Block or Ignore prevents overlap callbacks. Also, if both sides block, you will not get overlap events.
Check
  • Are both components' object types correct?
  • Is the collision response set to Overlap?
  • Is the handler bound with AddDynamic?
