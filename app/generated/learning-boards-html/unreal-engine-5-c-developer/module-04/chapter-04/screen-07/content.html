Core Concept
Hit Events
Events that fire when collisions physically block movement and contact occurs.
Requirements
  • Collision responses set to Block between involved object types
  • Simulate Physics enabled for physics objects or Generate Hit Events / NotifyRigidBodyCollision enabled
  • Bind OnComponentHit using AddDynamic
Key Takeaway

Use hit events for impacts and physical responses and ensure physics or notify flags are set so the delegate is invoked.

Concrete Example
A thrown object with Simulate Physics enabled collides with a wall set to Block. OnComponentHit provides the impact location and NormalImpulse for playing a sound or spawning an effect.
Common Mistakes
Expecting OnComponentHit when both sides are configured to Overlap, or forgetting to enable Notify Rigid Body Collision on non-physics components.
Check
  • Are responses set to Block between these object types?
  • Is Simulate Physics or Notify Rigid Body Collision enabled where required?
