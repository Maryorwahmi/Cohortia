Process
Create Projectile Profile
Steps to define a reusable collision profile in Project Settings.
  1. Open Project Settings → Engine → Collision and add a new preset named Projectile.
  2. Set Object Type to WorldDynamic and Collision Enabled to Query and Physics.
  3. For Collision Responses set Pawn, WorldStatic, WorldDynamic to Block; set Pickup or pickup channel to Overlap.
  4. Ensure Generate Overlap Events is checked where needed.
Key Takeaway

Profiles reduce per-component setup and make it easier to update behavior across many actors from one configuration point.

Concrete Example
Assign Projectile preset to the sphere collision with SetCollisionProfileName(TEXT("Projectile")) in the constructor or via the editor details panel to ensure consistent runtime behavior.
Common Mistake
Not enabling Generate Overlap Events in the profile or forgetting to reassign existing components after editing the preset, which leads to inconsistent event firing across actors.
