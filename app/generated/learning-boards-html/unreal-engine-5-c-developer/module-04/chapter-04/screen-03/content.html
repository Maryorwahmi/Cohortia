Practice & Debug Objectives
Steps to confirm your collision code behaves as expected in the editor and at runtime.
Workflow: Configure → Compile → Spawn → Visualize → Log
Step
Create Projectile Profile
Add a custom preset, set Object Type to WorldDynamic, enable Query and Physics, and configure Block/Overlap responses.
Step
Set Component Flags
Call SetGenerateOverlapEvents(true) for triggers and SetNotifyRigidBodyCollision(true) for hits where necessary.
Step
Debug and Verify
Use the Show Collision view, spawn the actor, and check the Output Log for UE_LOG messages from your handlers.
