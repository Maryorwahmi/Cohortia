Hands-on Activity
Create and test MyProjectile
A concise step flow to implement, compile, and verify overlap and hit events in the editor.
Step 1: Class
Create MyProjectile C++ actor with USphereComponent and UProjectileMovementComponent.
Step 2: Configure
Set collision profile, SetGenerateOverlapEvents(true), SetNotifyRigidBodyCollision(true), bind delegates.
Step 3: Test
Spawn projectile, check Output Log for overlap and hit messages, use Show Collision to inspect shapes.
Key Takeaway

A single projectile can demonstrate both overlap and hit if configured and tested properly; use logs and visualization to confirm behavior.
