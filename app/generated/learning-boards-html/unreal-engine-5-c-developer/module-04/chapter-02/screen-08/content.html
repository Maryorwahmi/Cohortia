Architecture
UFloatingPawnMovement
Create it in the constructor to enable movement handling.
Constructor snippet
// In AMyPlayerPawn.h
#include "GameFramework/FloatingPawnMovement.h"

// In AMyPlayerPawn.cpp constructor
AMyPlayerPawn::AMyPlayerPawn()
{
  UFloatingPawnMovement* FloatingPawnMovement = CreateDefaultSubobject<UFloatingPawnMovement>(TEXT("FloatingPawnMovement"));
  FloatingPawnMovement->MaxSpeed = 1000.0f;
}
Why it matters
  • The movement component processes aggregated AddMovementInput calls into motion and collision response.
  • Setting MaxSpeed gives you a top speed the component enforces.
  • Without it, AddMovementInput may have no visible effect or require custom movement logic.
Safety note
Very high speeds can cause tunneling; test with realistic MaxSpeed and adjust collision thickness or physics if needed.
