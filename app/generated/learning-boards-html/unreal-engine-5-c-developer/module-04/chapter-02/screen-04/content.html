Core Concept
APawn & AController
Controller supplies view; pawn executes movement and collision.
Definition card
Key definition

AController provides possession and viewpoint. GetControlRotation returns the controller's world rotation; use its yaw to derive directional vectors for intuitive player movement.

Concrete example
If the controller faces 45 degrees right and the player presses forward, deriving forward from controller yaw moves the pawn along that 45-degree heading, ensuring camera and movement match.
Common misconception
Don't assume pawn rotation equals controller rotation. Only enable pawn rotation from controller explicitly or use controller yaw to compute movement vectors.
Visual mnemonic
Controller = View
Yaw gives horizontal facing used for forward/right axes.
Key takeaway
Use controller yaw to make movement match the player's look direction.
