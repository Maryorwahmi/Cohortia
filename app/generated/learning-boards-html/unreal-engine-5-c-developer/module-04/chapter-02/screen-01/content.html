Implementing Basic Character Movement
Turn input actions into physics-aware movement and camera control for an APawn using AddMovementInput, controller rotation, and a floating movement component.
In this lesson
Movement with AddMovementInput, controller rotation, delta seconds, and UFloatingPawnMovement.
Movement

Camera

Explore key topics
Frame-rate independence: multiply by delta seconds for consistent speeds.
Controller rotation: derive forward/right vectors from yaw.
Movement components: UFloatingPawnMovement enables collision-aware motion.
Quick code snapshot
Move (concept)
// Use controller yaw to get forward and right
FVector Forward = FRotationMatrix(YawRotation).GetUnitAxis(EAxis::X);
FVector Right   = FRotationMatrix(YawRotation).GetUnitAxis(EAxis::Y);
AddMovementInput(Forward, InputY * Speed * GetWorld()->GetDeltaSeconds());
AddMovementInput(Right,   InputX * Speed * GetWorld()->GetDeltaSeconds());
Look (concept)
// Add yaw and pitch to controller
AddControllerYawInput(LookX);
AddControllerPitchInput(LookY);
