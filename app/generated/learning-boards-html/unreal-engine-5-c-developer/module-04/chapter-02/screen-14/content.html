Module 04 › Chapter 4.2 › Key Concepts
AddMovementInput
Queues directional requests processed by movement components.
Controller yaw
Use GetControlRotation and a yaw-only rotator to derive forward/right vectors.
Delta seconds
Multiply by GetWorld()->GetDeltaSeconds() so movement is measured per second, not per frame.
Summary
Pair AddMovementInput with a movement component, derive vectors from the controller when you want camera-relative input, and always scale by delta seconds. Use AddControllerYawInput and AddControllerPitchInput for camera control and handle inversion in your input mappings.
