Comparison
AddMovementInput vs SetActorLocation
Tradeoffs between request-based movement and direct transforms.
AddMovementInput + Component
  • Processed by movement component.
  • Handles sliding and collision.
  • Frame-rate independent when scaled by delta seconds.
SetActorLocation (direct)
  • Immediate position change, bypasses movement pipeline.
  • Risk of clipping/tunneling unless swept collision is used.
  • Requires manual collision and physics handling for robust results.
Pro tip

Choose AddMovementInput for standard player motion; reserve direct location changes for special scripted placements and use swept collision when doing so.
