Learning Objectives
Learn the practical code patterns to move a pawn, rotate the camera, and keep movement stable across frame rates.
01
Implement directional movement
Call AddMovementInput with a world-space vector and scaled input.
Mnemonic: Input vector + direction = movement
VERIFIED COMPETENCY MILESTONE
02
Control camera rotation
Use AddControllerYawInput and AddControllerPitchInput to drive view orientation.
Mnemonic: Yaw for look-left/right, pitch for look-up/down
VERIFIED COMPETENCY MILESTONE
03
Understand AController role
GetControlRotation supplies orientation used to derive forward and right axes.
Mnemonic: Controller = viewpoint provider
VERIFIED COMPETENCY MILESTONE
04
Frame-rate independent movement
Multiply movement by GetWorld()->GetDeltaSeconds() and tune MovementSpeed / MaxSpeed.
Mnemonic: Delta scales speed to seconds
VERIFIED COMPETENCY MILESTONE
