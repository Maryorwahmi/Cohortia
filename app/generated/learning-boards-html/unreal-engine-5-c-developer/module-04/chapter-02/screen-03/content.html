Module 04 › Chapter 4.2 › Validation & Testing
Quick validation checklist
  • Confirm W/A/S/D moves pawn relative to where the player looks when using controller rotation.
  • Toggle delta time scaling test to ensure consistent speed across frame rates.
  • Ensure AddMovementInput is handled by a movement component like UFloatingPawnMovement.
  • Test inverted Y by checking input mapping for the Look action, not just code logic.
Common quick-fixes
Forgot Delta
Add GetWorld()->GetDeltaSeconds() to movement scale.
No Movement Component
Create UFloatingPawnMovement in constructor.
