Definition
Frame-rate independent movement
Why it matters
Speeds should be consistent across devices. Multiply MovementSpeed by GetWorld()->GetDeltaSeconds() so the movement applied each frame equals the fraction of a second passed.
Numeric example
MovementSpeed = 500 units/s. At 60 FPS delta is ~0.016: per-frame move ≈ 8 units. At 30 FPS delta ~0.033: per-frame move ≈ 16 units, but fewer frames keep distance per second consistent.
Common bug & fix
Bug: movement tied to frame rate because code omitted delta seconds. Fix: include GetWorld()->GetDeltaSeconds() when scaling movement input.
Check your code
// Incorrect
AddMovementInput(Forward, InputY * MovementSpeed);

// Correct
AddMovementInput(Forward, InputY * MovementSpeed * GetWorld()->GetDeltaSeconds());
