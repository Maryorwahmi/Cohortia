Process
AddMovementInput mechanics
Queue a directional request that movement components honor.
API pattern
// Move (conceptual scale uses delta seconds)
AddMovementInput(ForwardDirection, InputY * MovementSpeed * GetWorld()->GetDeltaSeconds());
AddMovementInput(RightDirection,   InputX * MovementSpeed * GetWorld()->GetDeltaSeconds());
Remember: direction should be a unit vector and scale drives how far the pawn should move this frame. The movement component may normalize or combine multiple requests before applying velocity and collision.
Explanation bullets
  • It accumulates inputs each frame — call it whenever you have input.
  • Movement components process the accumulated inputs, performing sliding and collision response.
  • Scale by GetWorld()->GetDeltaSeconds() for frame-rate independence.
  • Do not use SetActorLocation in input handlers; it bypasses physics and collision.
Concrete scenario
Pressing forward while looking down a corridor should produce smooth forward motion and sliding off small obstacles if a movement component handles the input.
Key Takeaway

Treat AddMovementInput as a per-frame request; pair it with UFloatingPawnMovement or a proper movement component and scale by delta seconds.
