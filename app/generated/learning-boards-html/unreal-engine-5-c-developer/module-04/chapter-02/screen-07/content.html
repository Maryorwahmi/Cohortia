Look function (C++)
Forward input deltas to the controller to rotate view.
Full snippet
// In AMyPlayerPawn.cpp, within the Look function:
void AMyPlayerPawn::Look(const FInputActionValue& Value)
{
  FVector2D LookAxisVector = Value.Get<FVector2D>();

  if (Controller && (LookAxisVector.X != 0.0f || LookAxisVector.Y != 0.0f))
  {
    AddControllerYawInput(LookAxisVector.X);
    AddControllerPitchInput(LookAxisVector.Y);
  }
}
Practical notes
  • Invert Y in the input mapping if you want typical inverted mouse behavior; avoid double-negation in code.
  • Clamp pitch using the camera's spring arm or controller constraints to prevent camera flipping.
  • Small sensitivity multipliers can be applied in mapping or before passing to the controller for tuning.
Example
If LookAxisVector.X is 2.0 from input scaling, calling AddControllerYawInput with that value rotates the controller immediately by that delta amount for the frame.
