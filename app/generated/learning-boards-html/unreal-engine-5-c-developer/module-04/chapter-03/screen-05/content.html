Module 4 › Chapter 4.3 › UCharacterMovementComponent

What it provides

A physics-aware movement subsystem that handles ground and air behaviors and network prediction for ACharacter instances.

MaxWalkSpeed
Top walking/running speed used by movement calculations.
JumpZVelocity
Vertical impulse applied when Jump is called; controls jump height and arc.
AirControl
How much the character can steer while airborne.
bOrientRotationToMovement
Make the character face the movement direction automatically.
Concrete Example
A set of constructor defaults used in the chapter: JumpZVelocity = 600, AirControl = 0.2, MaxWalkSpeed = 600, BrakingDecelerationWalking = 2000. These give a responsive walk and a clear jump arc as a starting point for tuning.
Key Takeaway

Tune component properties, not input scaling. UCharacterMovementComponent handles time integration and prediction.
