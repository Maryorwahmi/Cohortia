Conversion checklist

A repeatable pattern for creating AMyPlayerCharacter and preparing it for movement and input.

Constructor
  • • InitCapsuleSize(42, 96)
  • • bUseControllerRotationYaw = false
  • • GetCharacterMovement()->bOrientRotationToMovement = true
  • • Set JumpZVelocity, AirControl, MaxWalkSpeed
BeginPlay & Input
  • • DefaultWalkSpeed = GetCharacterMovement()->MaxWalkSpeed
  • • Bind Move and Look actions
  • • Bind Jump and Sprint Started/Completed
Scenario
After conversion, place the character in the level, set it as the default pawn in GameMode, and play to verify movement, jump height, and that sprint toggles correctly revert to default speed.
