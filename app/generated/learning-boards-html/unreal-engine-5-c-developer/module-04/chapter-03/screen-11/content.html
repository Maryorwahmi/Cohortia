Sprint implementation

Use a stored default speed and multiply it for sprint, then restore to avoid cumulative changes.

BeginPlay store
DefaultWalkSpeed = GetCharacterMovement()->MaxWalkSpeed; This captures any Blueprint or editor overrides.
Sprint handlers
SprintStarted sets MaxWalkSpeed = DefaultWalkSpeed * SprintSpeedMultiplier. SprintCompleted restores MaxWalkSpeed = DefaultWalkSpeed.
Common Pitfall
Not initializing DefaultWalkSpeed or altering MaxWalkSpeed elsewhere leads to incorrect sprint behavior; always restore from the stored default.
