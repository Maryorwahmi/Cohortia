Move and Look implementations

Use controller yaw to build forward/right vectors and pass raw input to AddMovementInput; use controller input functions for look.

Move example
void AMyPlayerCharacter::Move(const FInputActionValue& Value)
{
  FVector2D MovementVector = Value.Get();
  if (Controller != nullptr)
  {
    const FRotator Rotation = Controller->GetControlRotation();
    const FRotator YawRotation(0, Rotation.Yaw, 0);
    const FVector ForwardDirection = FRotationMatrix(YawRotation).GetUnitAxis(EAxis::X);
    const FVector RightDirection = FRotationMatrix(YawRotation).GetUnitAxis(EAxis::Y);
    AddMovementInput(ForwardDirection, MovementVector.Y);
    AddMovementInput(RightDirection, MovementVector.X);
  }
}
Look example
Call AddControllerYawInput and AddControllerPitchInput with look axis values and ensure Controller is valid first.
Key Takeaway

Do not multiply input by delta seconds for AddMovementInput when using CharacterMovementComponent; it handles integration.
