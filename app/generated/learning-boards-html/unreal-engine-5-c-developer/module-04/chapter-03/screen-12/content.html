Avoid rotation conflicts

Either let the controller directly rotate the pawn or let the movement component orient the mesh — don't do both.

• If you want character to face movement direction, set bUseControllerRotationYaw = false and bOrientRotationToMovement = true.
• If you want controller-driven facing, set bUseControllerRotationYaw = true and disable bOrientRotationToMovement.
• Test combinations during gameplay; jitter indicates conflicting rotation inputs.
Quick Fix
Set bUseControllerRotationYaw = false in constructor and GetCharacterMovement()->bOrientRotationToMovement = true to produce expected movement-aligned facing.
Common Bug
Enabling both flags causes jerky rotation because two systems fight to set actor yaw.
