Module 4 › Chapter 4.3 › APawn vs ACharacter
Comparison

APawn — clean slate

APawn is minimal and ideal for vehicles, flying actors, or special movement that doesn't map to bipedal walking.

  • • Lightweight base class for custom movement
  • • No capsule or CharacterMovement by default
  • • Good for spaceships, cameras, or floating drones
Example
A drivable spaceship uses APawn with a custom thrust and rotation component rather than a CharacterMovementComponent.
Comparison

ACharacter — humanoid system

ACharacter includes a UCapsuleComponent and UCharacterMovementComponent that implement gravity, walking, jumping, slope behavior, and prediction.

  • • Built-in capsule collision
  • • CharacterMovement handles Jump, gravity, and slopes
  • • Network-aware movement prediction
Example
A third-person player who walks, turns, jumps, and crouches should use ACharacter to leverage the movement component.
