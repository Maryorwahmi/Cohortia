AMyPlayerCharacter.h — structure

Expose input assets and movement members so the editor can wire the input mappings and you can capture runtime defaults.

Input UPROPERTYs
PlayerInputMappingContext, MoveAction, LookAction, JumpAction, SprintAction — all EditAnywhere, BlueprintReadOnly so designers can assign them.
Movement members
SprintSpeedMultiplier (editable) and DefaultWalkSpeed (runtime store). Declare movement handler functions here.
Pro Tip
Keep DefaultWalkSpeed uninitialized in the header and assign it in BeginPlay so Blueprint overrides of MaxWalkSpeed are respected.
