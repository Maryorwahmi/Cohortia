Module 5 › Chapter 5.3 › Key Concepts
UMG
Unreal's visual UI system for building in-game interfaces.
Widget Blueprint
An asset defining layout, bindings and local UI logic, typically a UUserWidget subclass.
CreateWidget & AddToViewport
C++ pattern to instantiate a UUserWidget and display it on screen.
Takeaway

Use UMG to separate UI design from game logic, choose appropriate panel widgets for responsiveness, and instantiate widgets from C++ with clear lifecycle management.
