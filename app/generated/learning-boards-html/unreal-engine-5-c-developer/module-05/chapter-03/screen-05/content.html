Editor panels at a glance
Use these panels together to create interactive widgets.
Palette
Contains prebuilt widgets you drag onto the Designer.
Hierarchy
Shows nesting and parent-child relationships of widgets.
Designer
Visual canvas for arranging and previewing your layout.
Details & Graph
Details edits properties; Graph adds interactive logic and bindings.
Concrete example
Drag a Canvas Panel, place a Text Block with text "Health: 100", select the Text Block and change Font Size in Details. Open Graph to create an event that updates the text when the player's health changes.
Key Takeaway

Editor panels map to authoring, structure, properties, and logic — use them together for dynamic UI.
