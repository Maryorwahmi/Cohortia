Module 5 › Chapter 5.3 › Common Mistakes
Frequent issues and remedies
Absolute layout
Problem: UI breaks across screens. Fix: use anchors and box panels for adaptive layouts.
Not visible
Problem: widget created but unseen. Fix: call AddToViewport or set Visible after creation.
Tick overload
Problem: performance drops. Fix: initialize in Construct and use events for updates.
Unset class
Problem: CreateWidget fails. Fix: ensure PlayerHUDClass is assigned in Blueprint controller.
Debugging tips
  • Add UE_LOG after widget creation to confirm runtime flow.
  • Verify Game Mode references the correct Player Controller class.
  • Use Designer preview for different resolutions to test anchors.
Key Takeaway

Follow a small debug checklist when widgets don’t appear: class assigned, added to viewport, correct controller, and log output.
