Module 5 › Chapter 5.3 › Create a Simple Player HUD
Step-by-step
  1. Create a new Widget Blueprint named WBP_PlayerHUD.
  2. Add a Canvas Panel as the root container.
  3. Place a Text Block and set the text to "Health: 100"; anchor top-left.
  4. Add a Button; place a child Text Block with "Menu"; anchor top-right.
  5. Save and inspect the Hierarchy and Details for your widgets.
Pro tip
Use anchor presets to keep HUD elements stable when resolution changes.
Concrete example
After adding the widget and button, open Play In Editor. You should be able to see the static text and button positions. This verifies the widget visually before wiring it to code.
Key Takeaway

A Canvas Panel is useful for HUD placement, but anchor responsibly for adaptive layout.
