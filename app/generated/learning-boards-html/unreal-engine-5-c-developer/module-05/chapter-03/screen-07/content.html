Panel widget comparison
Canvas Panel
Absolute placement with anchors; great for anchored HUD elements but poor for menus.
Horizontal Box
Arranges children in a horizontal row; ideal for condensed counters like ammo and health bars.
Vertical Box
Arranges children vertically; perfect for menus and stacked lists.
Grid Panel
Cells-based layout for uniform grids like inventories.
Overlay
Stack content to present pop-ups and modal layers.
Size Box
Force or limit child dimensions when consistency is required.
Example scenario
Use a Canvas anchored corners for a minimap and health display. Use a Vertical Box for the main menu so adding buttons doesn't require repositioning every item.
Key Takeaway

Choose panels that express the relationship you want: flow (boxes), grid (grid), stacked overlays (overlay), anchored HUDs (canvas).
