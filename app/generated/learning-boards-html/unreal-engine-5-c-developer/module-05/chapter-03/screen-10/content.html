Module 5 › Chapter 5.3 › Widget Lifecycle
Lifecycle events
Construct: widget initialization, bind events, prepare visuals.
Tick: called every frame if enabled — avoid expensive operations here.
Destruct: clean up timers and event bindings when widget is removed.
Concrete example
Bind a button's OnClicked delegate in Construct rather than searching for buttons inside Tick every frame.
Performance tip
If you need per-frame updates, limit the data updated and consider throttling to fewer frames or using event-driven state pushes from gameplay code.
Key Takeaway

Prefer Construct for setup and event-driven updates over Tick to preserve runtime performance.
