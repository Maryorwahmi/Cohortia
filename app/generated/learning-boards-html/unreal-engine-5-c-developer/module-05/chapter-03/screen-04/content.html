UMG — A concise definition
A visual editor for Widget Blueprints that map to UUserWidget subclasses.
Why use UMG?
Faster iteration, designer-friendly layout, and built-in widgets for common UI patterns.
Concrete example
A HUD showing "Health: 100" built in WBP_PlayerHUD and added by the PlayerController at BeginPlay.
Common misconception
UMG is not only for designers; it integrates with C++ and Blueprint logic for real gameplay interactions.
Structure of a Widget
  • Widget Blueprint asset → visual layout and Graph logic.
  • Widgets like Text Block, Image, Button compose the layout.
  • Widget instances are UUserWidget objects at runtime.
Key Takeaway

Treat UMG as the presentation layer and keep game logic in controllers or game state for clarity and reuse.
