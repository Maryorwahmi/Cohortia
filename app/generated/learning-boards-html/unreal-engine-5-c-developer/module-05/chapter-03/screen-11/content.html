Module 5 › Chapter 5.3 › Lab Walkthrough
Guided steps
  1. Create WBP_PlayerHUD, add Canvas Panel, Text Block "Health: 100", and a Button "Menu".
  2. Create MyPlayerController C++ class with PlayerHUDClass property and PlayerHUD pointer.
  3. Implement CreateAndAddPlayerHUD to CreateWidget and AddToViewport at BeginPlay.
  4. Create BP_MyPlayerController and assign PlayerHUDClass to WBP_PlayerHUD.
  5. Set Game Mode Player Controller to BP_MyPlayerController and test Play In Editor.
Common test failures
  • PlayerHUDClass left unset in Blueprint controller.
  • Game Mode still using a different controller class.
  • Widget created but hidden due to visibility settings; ensure it's Visible or added to viewport.
Key Takeaway

Follow the lab checklist and verify both the blueprint assignment and game mode configuration to ensure the HUD appears.
