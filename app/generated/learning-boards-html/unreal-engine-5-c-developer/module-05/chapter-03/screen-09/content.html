Module 5 › Chapter 5.3 › Blueprint Binding & Game Mode
Workflow checklist
  1. Create BP_MyPlayerController from your C++ controller class.
  2. Open BP_MyPlayerController and set PlayerHUDClass to WBP_PlayerHUD in Details.
  3. Open your Game Mode Blueprint and set Player Controller Class to BP_MyPlayerController.
  4. Play and confirm the HUD appears and the log shows a creation message.
Why this helps
Designers can swap widget assets without C++ changes, enabling rapid UI iteration and testing.
Quick test
If HUD does not appear, check: is the Game Mode using your controller, is PlayerHUDClass set, and did BeginPlay log creation?
Common Mistake

Forgetting to change the Game Mode to use your Blueprint controller results in the widget not being created at runtime.
