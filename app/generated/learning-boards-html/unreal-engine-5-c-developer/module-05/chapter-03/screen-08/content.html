Starter C++ pattern
// Header (relevant parts)
UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "UI")
TSubclassOf<UUserWidget> PlayerHUDClass;

UPROPERTY()
UUserWidget* PlayerHUD;

// Source (relevant parts)
void AMyPlayerController::BeginPlay()
{
  Super::BeginPlay();
  CreateAndAddPlayerHUD();
}

void AMyPlayerController::CreateAndAddPlayerHUD()
{
  if (PlayerHUDClass)
  {
    PlayerHUD = CreateWidget<UUserWidget>(this, PlayerHUDClass);
    if (PlayerHUD)
    {
      PlayerHUD->AddToViewport();
      UE_LOG(LogTemp, Warning, TEXT("Player HUD created and added to viewport."));
    }
  }
  else
  {
    UE_LOG(LogTemp, Error, TEXT("PlayerHUDClass is not set in MyPlayerController!"));
  }
}
Explanation
  • Make the TSubclassOf editable so designers assign the Blueprint asset.
  • CreateWidget returns a UUserWidget instance you store and manage.
  • Call AddToViewport to make the widget visible to the player.
Key Takeaway

Expose the class to Blueprints, create the widget in BeginPlay, and log errors if the class is unset.
