Module 5 › Chapter 5.3 › Toggle Inventory
Implementation outline
  1. Expose InventoryClass and hold InventoryWidget pointer in PlayerController.
  2. Bind an input action for the inventory key in SetupInputComponent.
  3. In the handler, if widget not created, CreateWidget; toggle AddToViewport and RemoveFromParent accordingly.
  4. Track open state with a boolean flag to manage visibility.
Memory choice
Decide whether to keep the widget instance when hidden to trade memory for faster re-opening.
Assessment check
  • Does the inventory open and close with the key press?
  • Is the widget instance managed without leaking memory or leaving orphaned pointers?
  • Are logs or breakpoints confirming the input handler fires?
Key Takeaway

The toggle pattern combines UI instantiation, input binding, and state tracking — a compact test of UMG integration.
