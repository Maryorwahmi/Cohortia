Event Construct
In Event Construct: GetPlayerCharacter → Cast To MyCharacter → Drag character reference → OnHealthChanged → Bind Event → create UpdateHealthDisplay(NewHealth, MaxHealth).
Update handler
Set ProgressBar.Percent to NewHealth / MaxHealth and set HealthText using a formatted string from the event parameters.
Graph notes
Event Construct
  -> GetPlayerCharacter
  -> Cast To MyCharacter
  -> Bind Event to OnHealthChanged (create UpdateHealthDisplay)

UpdateHealthDisplay(float NewHealth, float MaxHealth)
  -> HealthProgressBar.SetPercent(NewHealth / MaxHealth)
  -> HealthText.SetText(Format Text("Health: {N}/{M}", NewHealth, MaxHealth))
