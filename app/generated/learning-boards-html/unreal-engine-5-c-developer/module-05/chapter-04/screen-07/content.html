Module 5 › Chapter 5.4 › Health Text Binding
Goal
Format health as readable text
Bind a Text Block to return an FText like "Health: 75/100" by reading CurrentHealth and MaxHealth and using Format Text in the Graph, or return FText from C++.
// In Widget Graph binding (visual nodes):
GetPlayerCharacter -> Cast To MyCharacter -> Get CurrentHealth
Get MaxHealth -> Format Text("Health: {Cur}/{Max}") -> Return FText
Notes
  • Return FText for Text bindings; returning a raw float will fail type checks.
  • Consider doing formatting in C++ if multiple widgets reuse the same string format.
  • Format Text nodes integrate with localization if you need translations later.
Misconception
Formatting in the widget Graph is always better. In practice centralizing formatting in C++ may reduce duplication and keep localization concerns together.
