Module 5 › Chapter 5.4 › Quick Reference
Expose
BlueprintReadOnly for fields, BlueprintPure for getters.
Broadcast
Use BlueprintAssignable delegates to notify widgets of changes.
Callbacks
Use BlueprintCallable for UI-initiated actions like Heal or settings changes.
One-line summary

Expose, subscribe, and call: make C++ authoritative, let UI subscribe to changes, and let UI trigger sanctioned C++ actions.
