Module 5 › Chapter 5.4 › Expose C++ State
Goal
Let Blueprints read and call C++
Expose variables with UPROPERTY(BlueprintReadOnly) and expose getters/actions with UFUNCTION. Keep getters pure and side-effect free.
// AMyCharacter.h (excerpt)
UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Health")
float CurrentHealth;

UFUNCTION(BlueprintPure, Category = "Health")
float GetHealthPercentage() const;

UFUNCTION(BlueprintCallable, Category = "Health")
void Heal(float HealAmount);
Note: BlueprintPure is for getters without execution pins; BlueprintCallable appears with execution pins and is used for actions like Heal.
Example mapping
  • CurrentHealth → UPROPERTY(BlueprintReadOnly) for direct reading in Graphs.
  • GetHealthPercentage → UFUNCTION(BlueprintPure) for binding to ProgressBar.Percent.
  • Heal → UFUNCTION(BlueprintCallable) so OnClicked can invoke it from UMG.
Misconception
Making everything BlueprintCallable is not ideal; prefer clear separation between read-only getters and mutating actions for clarity and safety.
