Module 5 › Chapter 5.4 › ProgressBar Binding
One-sentence
Bind Percent to a pure getter
  1. Implement GetHealthPercentage() in AMyCharacter and mark BlueprintPure.
  2. Add ProgressBar to WBP_PlayerHUD and choose Bind → Create Binding.
  3. In Graph: GetPlayerCharacter → Cast To MyCharacter → Call GetHealthPercentage → Return value.
Example
CurrentHealth 75, MaxHealth 100 → GetHealthPercentage returns 0.75 → ProgressBar shows 75%.
Code (excerpt)
// AMyCharacter.cpp
float AMyCharacter::GetHealthPercentage() const
{
  return CurrentHealth / MaxHealth;
}

// WBP_PlayerHUD Graph: GetPlayerCharacter -> Cast To MyCharacter -> GetHealthPercentage
Guard casts and ensure the player reference is valid before calling getters in the binding graph.
