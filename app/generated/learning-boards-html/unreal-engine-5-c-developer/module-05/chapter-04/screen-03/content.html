Practical checks
  • Broadcast initial health in BeginPlay so the HUD has starting values.
  • Bind event dispatchers in Event Construct and update ProgressBar and Text directly from event parameters.
  • Use the editor console or a test button to call TakeDamage and Heal, and observe the UI change.
  • Prefer event-driven updates for frequent changes to reduce per-frame binding cost.
Mnemonic
Expose → Bind → Broadcast → Update. Think: C++ gives data, widget binds or subscribes, and game broadcasts changes.
