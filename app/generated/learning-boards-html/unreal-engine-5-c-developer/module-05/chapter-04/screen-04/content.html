Module 5 › Chapter 5.4 › What is Data Binding
Definition
Binding connects UI to game data
Binding lets widgets request or receive values instead of storing their own copy. It keeps presentation in sync with the authoritative C++ state.
Example: Health bar binding
Bind ProgressBar.Percent to a BlueprintPure GetHealthPercentage() that returns CurrentHealth / MaxHealth.
Misconception
Bindings are free. In practice, many per-frame bindings add cost; prefer event-driven updates for high-frequency changes.
Key Takeaway
Use simple bindings for occasional reads and consider delegates when updates are frequent.
Visual
// In AMyCharacter.h
UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Health")
float CurrentHealth;

UFUNCTION(BlueprintPure, Category = "Health")
float GetHealthPercentage() const;

// In WBP_PlayerHUD: bind ProgressBar.Percent to GetHealthPercentage()
Analogy
Think of binding like a sensor: the UI reads a live value from the game rather than keeping its own copy that might go out of date.
