Module 5 › Chapter 5.4 › Common Mistakes
Checklist
  • Correct UPROPERTY/UFUNCTION specifiers.
  • Bind once in Event Construct, don't rebind in Tick.
  • Use events for frequent updates, bindings for occasional reads.
  • Match return types (FText vs float) for UI properties.
  • Broadcast initial values in BeginPlay.
Performance tip
If many widgets bind to a value, move the logic to event-driven broadcasts to avoid repeated calculations during binding evaluation.
Debugging
Log in TakeDamage/Heal and check that Broadcast runs. Use initial broadcast in BeginPlay and verify the widget receives it on Construct.
