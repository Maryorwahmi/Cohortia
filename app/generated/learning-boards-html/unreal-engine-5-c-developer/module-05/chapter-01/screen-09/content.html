Module 5 › Chapter 5.1 › Shape Traces
When to use
Use shape traces for area effects, melee arcs, and any case where a volume sweep better represents the gameplay than a single line.
SphereTrace
BoxTrace
CapsuleTrace
Concrete Example
Replace many line traces in a melee swing with a single SphereTraceMultiByChannel sweeping the arc. The sweep returns all actors inside the volume, simplifying logic and improving performance.
Key Takeaway
Match trace shape to gameplay geometry: volume sweeps for area effects, line traces for precise hits.
