Module 5 › Chapter 5.1 › Learning Objectives
Implementation Outcome

Implement UpdateInteractionTrace, ignore the owner, and toggle custom depth to highlight looked-at actors. Use a safe CurrentHighlightedActor pattern to avoid resource leaks.

Mnemonic: eye → ray → filter → highlight
Debugging & Visual Checks

Use DrawDebugLine and DrawDebugSphere to visualize single and swept traces while testing collision responses and query param choices.

Mnemonic: see what you cast
Assessment Ideas

Evaluate trace choice for headshots (line trace with bTraceComplex true) and melee arcs (sphere or box sweep multi traces).

Mnemonic: precision = line, area = shape
Performance Check

Decide how often traces run and prefer simple collision unless per-poly accuracy is necessary. Profile if traces run frequently across many actors.

Mnemonic: frequency × complexity = cost
