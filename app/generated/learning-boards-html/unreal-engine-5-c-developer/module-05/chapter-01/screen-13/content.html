Module 5 › Chapter 5.1 › Common Mistakes
Frequent Errors
  • Not ignoring the tracing actor.
  • Using complex collision unnecessarily.
  • Incorrect collision channel causing stray hits.
  • Toggling render state without primitive cast.
Guard Patterns
Use AddIgnoredActor, set bTraceComplex consciously, check component presets, cast to UPrimitiveComponent before SetRenderCustomDepth, and only update when actor changes.
Debugging hint
If a trace misses expected geometry, visualize the trace and verify each component’s response to the chosen channel in the editor.
