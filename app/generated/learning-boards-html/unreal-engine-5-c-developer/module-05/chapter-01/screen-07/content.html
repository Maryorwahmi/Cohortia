Channels & Presets
Use built-in channels like Visibility for camera and line-of-sight queries, and define custom channels for interaction and projectiles. Set each component’s object type and response to determine whether it blocks or ignores a trace channel.

  • Set pickups to block your interaction channel only so they’re found by interaction traces.
  • Keep world geometry blocking Visibility for line-of-sight tests.

Key Takeaway

Map channels to gameplay intent and use component responses to ensure traces return only relevant actors.
