Module 5 › Chapter 5.1 › FCollisionQueryParams
Common Settings
  • AddIgnoredActor(this) — prevent self-hits.
  • bTraceComplex — true for per-polygon accuracy, false for simple collision.
  • bReturnPhysicalMaterial — request material info only when needed.
Example Pattern
For highlighting an actor while looking: ignore the owner, use simple collision for speed, and avoid extra returns to keep traces lightweight. Switch to complex only when you need exact bone hits.
Common mistake
Forgetting to call AddIgnoredActor(this) causes the trace to hit your own capsule or camera immediately, producing false positives.
