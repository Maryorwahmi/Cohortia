Module 5 › Chapter 5.1 › UpdateInteractionTrace
Step-by-step
1. Compute Start = camera location, End = Start + forward * distance.
2. Prepare FCollisionQueryParams, AddIgnoredActor(this), set bTraceComplex appropriately.
3. Call LineTraceSingleByChannel and check boolean result.
4. If hit actor != CurrentHighlightedActor, un-highlight old and highlight new via UPrimitiveComponent SetRenderCustomDepth.
Concrete Code Tips
  • Cast GetRootComponent() to UPrimitiveComponent before toggling custom depth.
  • Only update materials or depth when the highlighted actor changes to reduce per-frame work.
  • Choose a sensible trace range, e.g., 500 units for interaction reach.
Common Pitfall
Attempting SetRenderCustomDepth on a non-primitive component will fail; always validate the cast first.
