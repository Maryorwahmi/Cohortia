Module 6 › Chapter 5.5 › Input Modes Defined
Definition

GameOnly, UIOnly, GameAndUI

These modes are configured through SetInputMode on APlayerController. They determine whether UI widgets receive focus and whether gameplay input remains active.

FInputModeGameOnly
Route all input to gameplay systems; UI will not accept keyboard or gamepad input.
FInputModeUIOnly
Route input to UI only. Show cursor and block gameplay controls.
FInputModeGameAndUI
Allow both UI and game to receive input; manage event consumption carefully.
Concrete Example
Pause Menu

When opening a pause menu you typically pause the game, show the cursor, and switch to UIOnly so menu navigation does not move the player. When the menu closes, revert to GameOnly and hide the cursor.

Key takeaway
Key Takeaway

Pick the simplest input mode that achieves your UX goal. Use GameAndUI only when you design clear event consumption rules.
