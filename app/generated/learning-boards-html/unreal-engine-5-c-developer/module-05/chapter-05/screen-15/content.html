Module 6 › Chapter 5.5 › What to Remember
Cursor + Mode
Always set bShowMouseCursor when switching input modes for predictable mouse interactions.
Centralize Toggles
Put SetInputMode and pause toggles in PlayerController to avoid conflicting requests from widgets.
Reuse Widgets
Prefer visibility states for frequently toggled UI to reduce allocation and draw spikes.
One final question

Which input mode will your inventory use and why? Sketch that lifecycle before you start coding.
