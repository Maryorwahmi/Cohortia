Memory aids
  • Input modes: "Game, UI, Both" — pick based on whether gameplay should respond while UI is open.
  • Focus: Initialize focus to the first actionable widget every time a menu opens.
  • Lifecycle: Create/Show → SetInputMode → SetFocus → PlayAnimation → Hide/Destroy.
Quick checklist
Before showing UI
Decide input mode and whether to pause the game.
When showing UI
Set focus and show the mouse cursor if needed; play entry animation for polish.
When hiding UI
Revert input mode, hide cursor, and either collapse or remove the widget depending on reuse.
