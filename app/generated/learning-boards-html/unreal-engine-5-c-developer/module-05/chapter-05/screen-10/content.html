Module 6 › Chapter 5.5 › Performance Optimization
Avoid Event Tick

If you update UI each frame, you consume CPU and possibly thread contention. Instead, update widgets only when the underlying data changes, such as inventory contents or health values.

Use Collapsed or Hidden for quick toggles without reallocating widget trees.
RemoveFromParent when you need to free memory for rarely used screens.
Draw call reduction

Reduce unique textures and use atlases. Group static imagery to avoid multiple material switches.

Checklist
  • Avoid Tick where possible.
  • Reuse widgets and toggle visibility.
  • Break big widgets into children for selective updates.
