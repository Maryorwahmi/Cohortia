Advanced UI Concepts & Input Handling

This chapter equips you to route input correctly between gameplay and UI, set focus for gamepad and keyboard, animate widgets, and keep UI performant even as systems grow complex.

In this lesson

Why this matters

Poor input routing breaks player control and accessibility. Correct focus and input mode choices make menus predictable across keyboard, mouse, and gamepad users.

Visual concept: Input modes & focus
FInputModeGameOnly
Game receives input; UI does not. Use for core gameplay.
FInputModeUIOnly
UI receives input exclusively; show mouse cursor and lock game input.
FInputModeGameAndUI
Both systems receive input; requires careful consumption to avoid conflicts.
