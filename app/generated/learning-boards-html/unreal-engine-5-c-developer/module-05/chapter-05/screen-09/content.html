Bind a UWidgetAnimation in C++

// In UMyPauseMenuWidget.h
UPROPERTY(Transient, meta=(BindWidgetAnim))
UWidgetAnimation* FadeInAnimation;

// In UMyPauseMenuWidget.cpp
void UMyPauseMenuWidget::NativeConstruct()
{
    Super::NativeConstruct();
    if (FadeInAnimation)
    {
        PlayAnimation(FadeInAnimation);
    }
}
Explanation
  • BindWidgetAnim attaches the Designer animation to a C++ pointer at runtime.
  • Call PlayAnimation in NativeConstruct to start the animation when the widget appears.
  • Avoid using Event Tick for animation; prefer Designer animations for performance and authoring clarity.
Pro tip: If an animation must complete before input is allowed, disable focus until OnAnimationFinished fires, then set focus and input mode.
