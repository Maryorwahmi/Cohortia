Module 6 › Chapter 5.5 › Assessment & Mistakes
Assessment checks
  • Inventory open: UIOnly active, cursor visible, drag-and-drop functions and no character movement.
  • Pause toggle: game paused, fade-in plays, and Resume returns to GameOnly with cursor hidden.
  • Controller navigation: first button receives focus and Down navigation goes to next item reliably.
Common mistakes
  • Not resetting input mode and cursor when closing menus.
  • Leaving pointers to removed widgets, causing dangling references.
  • Using Tick for UI updates rather than event-driven updates.
Quick fix: centralize toggle behavior in one function on the PlayerController to avoid duplicated mode changes across Blueprints or widgets.
