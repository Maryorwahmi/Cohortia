Module 6 › Chapter 5.5 › UI Focus & Navigation
Steps to reliable focus
  1. Open or show the widget and ensure the owning player controller is available.
  2. Call SetUserFocus or SetKeyboardFocus on the target widget.
  3. Set or verify explicit navigation rules in the UMG Designer when automatic behavior fails.
  4. Test with a controller and keyboard to confirm the flow is predictable.
Concrete scenario
A vertical list of menu buttons sometimes skips a button when navigating with a gamepad. Fix it by opening the widget, selecting the first button, and setting Down navigation explicitly for each button in the Designer. This ensures stable movement between items regardless of layout changes.
Misconception
Layout order always determines navigation. In practice, nested containers and padding can alter automatic rules; explicit navigation is more reliable.
