Module 6 › Chapter 5.5 › Reusable UI Components
Component strategy
  • Create small child widgets for repeating elements.
  • Populate lists dynamically and update only changed items.
  • Localize animations and logic to children to reduce coupling.
Memory pattern
Use Collapsed for quick hides, Hidden if you need layout preservation, and RemoveFromParent when you want to free resources permanently. Pre-create rarely changing elements during loading to avoid spikes.
Centralize SetInputMode in PlayerController so widgets request changes through a single API. This prevents conflicting mode changes when multiple widgets are active.
