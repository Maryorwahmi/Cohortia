FInputMode*
GameOnly, UIOnly, and GameAndUI control event routing between gameplay and UI.
UI Focus
SetUserFocus and SetKeyboardFocus ensure keyboard/gamepad users can interact predictably.
Animation & Perf
Bind animations in C++ when needed and prefer event updates over Tick to keep UI efficient.
Summary
