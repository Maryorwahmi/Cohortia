Module 6 › Chapter 5.5 › Build a Pause Menu
Step-by-step
  1. Create WBP_PauseMenu with Canvas Panel and centered Vertical Box of three Buttons.
  2. Add FadeInAnimation that animates Render Opacity from 0 to 1 at 0.5s.
  3. Add PauseMenuWidgetClass and PauseMenuWidget members to your PlayerController.
  4. Implement TogglePauseMenu: SetGamePaused, CreateWidget/AddToViewport, SetInputMode(UIOnly), SetWidgetToFocus, bShowMouseCursor = true.
  5. On resume: RemoveFromParent, SetInputMode(GameOnly), bShowMouseCursor = false.
Testing checklist
  • Press Pause: verify game paused, cursor visible, fade-in plays, and first button has focus.
  • Press Resume: verify game resumes, cursor hides, and widget is removed or collapsed.
  • Test with gamepad navigation to ensure Up/Down rules are correct.
Tip: Bind Resume button OnClicked to a BlueprintCallable function that calls TogglePauseMenu for one-code toggling consistency.
