Hands-on › Starter integration
Starter checklist
  1. Create InteractableInterface.h/.cpp with BlueprintNativeEvent functions and compile.
  2. Implement ADoor with Interact_Implementation and CanInteract_Implementation, include a log line.
  3. Declare OnDoorOpened delegate and call Broadcast in Interact_Implementation.
  4. Update AMyCharacter trace to set TScriptInterface and bind Interact input.
  5. Place ADoor instances, run, and press Interact to observe logs and broadcasts.
Diagnostic tips
  • Compile after adding UINTERFACE to avoid missing symbols.
  • Check for the _Implementation suffix if the function never executes.
  • Ensure TScriptInterface is UPROPERTY so GC doesn't remove the object reference.
  • Bind delegates early and remove bindings on EndPlay to avoid crashes.
