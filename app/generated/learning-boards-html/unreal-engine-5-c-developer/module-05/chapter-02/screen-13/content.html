Warning › Pitfalls
Binding & lifecycle
  • Verify AddDynamic or blueprint binding occurred before Broadcast.
  • RemoveDynamic in EndPlay or before object destruction to avoid dangling calls.
  • Prefer UObject listeners to allow GC to clear stale references.
Interface call mistakes
  • Always use Execute_Function with the UObject* first parameter for BlueprintNativeEvent functions.
  • Don't forget the _Implementation suffix when defining default C++ behavior.
  • Keep detection and action separate: trace selects candidate, input triggers action.
Quick checklist
Implements check, UPROPERTY on TScriptInterface, RemoveDynamic on end, Execute_ with GetObject, verify CanInteract before Interact.
