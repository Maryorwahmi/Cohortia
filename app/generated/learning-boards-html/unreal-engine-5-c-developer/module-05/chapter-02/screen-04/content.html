What a UInterface is

A UInterface provides a contract of functions that any UObject-derived class can implement, enabling polymorphic behavior without knowing concrete types.

Contract: Interact(AActor*), CanInteract(AActor*)
Specifier: BlueprintNativeEvent for C++ defaults and Blueprint overrides.
Common misconception

Interfaces are not multiple inheritance for implementation. They are a runtime contract. Calling the interface must use Execute_ for BlueprintNativeEvent routing.

Key takeaway

Design contracts, not dependencies. Use Execute_ calls to respect Blueprint overrides.

Header example (InteractableInterface.h)
#pragma once

#include "CoreMinimal.h"
#include "UObject/Interface.h"
#include "InteractableInterface.generated.h"

UINTERFACE(MinimalAPI, Blueprintable)
class UInteractableInterface : public UInterface
{
	GENERATED_BODY()
};

class UNREALENGINE5CDEVELOPER_API IInteractableInterface
{
	GENERATED_BODY()

public:
	UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "Interaction")
	void Interact(AActor* Interactor);

	UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "Interaction")
	bool CanInteract(AActor* Interactor) const;
};
Example: ADoor implements Interact_Implementation to toggle bIsOpen and Broadcast OnDoorOpened.
Remember: call Execute_Interact when you have a UObject pointer to ensure Blueprint overrides run.
