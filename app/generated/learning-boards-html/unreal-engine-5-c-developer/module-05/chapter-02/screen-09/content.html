Comparison › Communication methods
Direct Function Calls

Use when an object has a clear ownership or direct reference to the callee. Fast and explicit, but tightly coupled.

Example: Weapon component calling owner->Reload().
Interfaces (UInterface)

Define a contract that many concrete classes implement. Allows polymorphic interaction without knowing the type at compile time.

Example: Interact called on any IInteractableInterface implementer.
Event Dispatchers

Broadcast events to many listeners without the broadcaster needing to know them. Great for UI, audio, and telemetry.

Example: OnDoorOpened.Broadcast(this) notifies audio and UI systems.
Decision guide
If you need single-target polymorphism, prefer interfaces. If you need many listeners, prefer delegates. Use direct calls when both objects are tightly coupled.
