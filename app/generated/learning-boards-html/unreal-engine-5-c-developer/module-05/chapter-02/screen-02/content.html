Learning Objectives
A practical roadmap to the skills you'll use in code and Blueprints
Bloom: Learn → Understand → Apply → Master
01
Design UInterface contracts

Define Interact and CanInteract as BlueprintNativeEvent functions so both C++ and Blueprint can implement them. This lets any object accept interaction without exposing concrete types.

VERIFIED COMPETENCY MILESTONE
02
Use dynamic multicast delegates

Declare DECLARE_DYNAMIC_MULTICAST_DELEGATE macros and expose UPROPERTY(BlueprintAssignable) so Blueprints and C++ can bind. Broadcasting lets many systems react to one event.

VERIFIED COMPETENCY MILESTONE
03
Integrate tracing with TScriptInterface

Store the result of a trace in a TScriptInterface<IInteractableInterface> so the player can call Execute_Interact safely, using GetObject when needed for Execute calls.

VERIFIED COMPETENCY MILESTONE
04
Choose direct vs interface vs dispatcher

Understand when tight coupling is acceptable and when you need polymorphism or broadcast decoupling to keep systems maintainable and extensible.

VERIFIED COMPETENCY MILESTONE
