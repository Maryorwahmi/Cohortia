Process › Delegates on ADoor
Declaration & broadcast
// ADoor.h
DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FDoorOpenedSignature, AActor*, DoorActor);

UPROPERTY(BlueprintAssignable, Category = "Interaction")
FDoorOpenedSignature OnDoorOpened;

// ADoor.cpp (inside Interact_Implementation)
OnDoorOpened.Broadcast(this);
Binding & cleanup
Bind in BeginPlay or when an object needs to listen, and remove binding in EndPlay or when the listener is destroyed.
// Binding example
Door->OnDoorOpened.AddDynamic(this, &ASoundEmitter::PlayDoorSound);

// Cleanup
Door->OnDoorOpened.RemoveDynamic(this, &ASoundEmitter::PlayDoorSound);
Designer tip
Mark delegates BlueprintAssignable so designers can wire responses without C++ changes.
