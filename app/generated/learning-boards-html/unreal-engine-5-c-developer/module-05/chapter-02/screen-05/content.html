Implementation steps
  1. Create InteractableInterface.h/.cpp and declare BlueprintNativeEvent functions.
  2. Create ADoor actor; include header and inherit IInteractableInterface.
  3. Define Interact_Implementation(AActor* Interactor) in ADoor.cpp to toggle bIsOpen and UE_LOG a message.
  4. Implement CanInteract_Implementation to return true or a condition like !bIsLocked.
  5. Optionally: declare a delegate and broadcast OnDoorOpened.Broadcast(this) inside Interact_Implementation.
Common mistakes
Forgetting the _Implementation suffix or not compiling after adding the UINTERFACE will lead to undefined behavior or missing overrides.
ADoor snippets
// ADoor.h (excerpt)
#include "InteractableInterface.h"

UCLASS()
class ADoor : public AActor, public IInteractableInterface
{
	GENERATED_BODY()

public:
	virtual void Interact_Implementation(AActor* Interactor) override;
	virtual bool CanInteract_Implementation(AActor* Interactor) const override;
	bool bIsOpen;
};

// ADoor.cpp (excerpt)
void ADoor::Interact_Implementation(AActor* Interactor)
{
	bIsOpen = !bIsOpen;
	UE_LOG(LogTemp, Warning, TEXT("Door interacted by %s!"), *Interactor->GetName());
	// OnDoorOpened.Broadcast(this); // if declared
}

bool ADoor::CanInteract_Implementation(AActor* Interactor) const
{
	return true; // or !bIsLocked
}
