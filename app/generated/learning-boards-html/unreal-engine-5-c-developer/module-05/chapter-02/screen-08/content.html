Architecture › Interaction manager
Component responsibilities
  • Perform trace each tick to detect candidates.
  • Filter results by Implements<UInteractableInterface> and priority rules.
  • Set CurrentInteractableActor as a TScriptInterface and update highlight/UI.
  • Respond to InteractInput by calling Execute_CanInteract and Execute_Interact.
Priority rule example
Choose the candidate closest to camera center, then nearest by distance if tie.
Handling multiple interactables
Keep detection separate from action. The trace suggests; InteractInput acts.
Clear stored interface immediately if the object is destroyed in Interact to avoid stale references.
Use UPROPERTY() on TScriptInterface members so garbage collection is respected.
Key takeaway
Separation of detection, presentation, and action improves predictability and designer control.
