Practical milestones
Concrete checks you can run in your project
Apply → Test → Confirm
Create interface files

Add InteractableInterface.h/.cpp with UINTERFACE and IInteractableInterface signatures. Confirm BlueprintNativeEvent is present for Interact and CanInteract.

Implement ADoor

Make ADoor inherit IInteractableInterface, implement Interact_Implementation to toggle a boolean and log a message, and implement CanInteract_Implementation to return true or conditional logic.

Update player trace

When a trace hits an actor that Implements<UInteractableInterface>, store it in a TScriptInterface member. Use Execute_ calls on InteractInput.

Declare and bind delegates

Add a DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam for OnDoorOpened, broadcast from Interact_Implementation, and bind listeners with AddDynamic.
