Learning Objectives

Master ownership semantics, inline callbacks, and delegate patterns used in UE5 C++.

01
Smart pointer selection

Pick TUniquePtr for single ownership and TSharedPtr when multiple owners must hold references. This prevents leaks by making intent explicit.

VERIFIED COMPETENCY MILESTONE
02
Lambda functions

Write concise, inline callables for small tasks, captures let you access local state without extra member functions.

VERIFIED COMPETENCY MILESTONE
03
Delegates and multicast

Use single-cast delegates for one listener and multicast delegates when multiple systems must react to an event.

VERIFIED COMPETENCY MILESTONE
04
Dynamic delegates & Blueprint

Expose events to Blueprint with dynamic delegates only when designers must bind visually. Beware reflection cost in tight loops.
