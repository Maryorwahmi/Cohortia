Comparison › TDelegate vs TMulticastDelegate

TDelegate (single-cast)

Binds a single handler. Good for cases with exactly one consumer, simple and lower overhead.

Example:
Button click that triggers one explicit action.

TMulticastDelegate (multi-cast)

Supports multiple bindings. Broadcast calls every bound function, useful when many systems react to an event.

Example:
Health changed event that updates UI, plays sound, and notifies analytics.
Misconception
Using multicast for everything can hide design intent and add unnecessary invocation overhead.
Tip
Prefer non-dynamic delegates for C++ internal events; use dynamic delegates only for Blueprint exposure.
