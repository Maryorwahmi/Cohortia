Core Concept › Pitfalls & Practices
Cycle prevention
Use TWeakPtr to break circular references between shared owners.
Weak pointer validation
Lock TWeakPtr and check validity before dereferencing to avoid null access.
Delegate cost
Prefer non-dynamic delegates for high-frequency C++ events to avoid reflection overhead.
Lambda captures
Capture safely; do not capture stack-only references for long-lived callbacks.
State clamping
Clamp values like health to valid ranges inside mutators to preserve invariants.
Document intent
Comment why a pointer is shared or weak to prevent accidental misuses during refactorings.
