Core Concept › Lambdas

What lambdas give you

Inline anonymous functions that can capture local variables to make short handlers or predicates without separate named functions.

Use case
Bind a lambda to a health-changed delegate that prints the new health and delta to the log, capturing a debug name for clarity.
Watch out
Avoid capturing raw stack references for lambdas that may run later; prefer captured shared or weak pointers or ensure the lambda's lifetime is limited.
Key Takeaway

Lambdas keep small logic local and readable, but always review capture semantics for lifetime safety.
