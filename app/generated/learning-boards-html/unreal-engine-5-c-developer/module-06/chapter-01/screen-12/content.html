Process Flow › Lambda binding
Example actor BeginPlay that binds a lambda to the health component's multicast delegate.
// AMyGameCharacter.cpp (BeginPlay binding snippet)
void AMyGameCharacter::BeginPlay()
{
    Super::BeginPlay();

    if (HealthComponent)
    {
        const FString NameTag = TEXT("PlayerChar");
        HealthComponent->OnHealthChanged.AddLambda([NameTag](float NewHealth, float Delta)
        {
            UE_LOG(LogTemp, Log, TEXT("New Health: %f, Delta: %f - %s"), NewHealth, Delta, *NameTag);
        });
    }
}
When damage or healing is applied, the multicast delegate invokes this lambda and you will see log lines like the expected output. This validates both the broadcast and binding behavior.
