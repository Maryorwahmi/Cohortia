Project Structure, Plugins & Modularity

Organize Source/Public/Private by feature, craft plugins that compile as separate modules, and use interfaces to decouple systems.

In this lesson

Explore Key Topics
Folder & Naming Conventions
Use Source/YourGame/Public|Private and prefixes like A, U, F, E to improve readability.
Plugins & .Build.cs
Plugins compile as separate modules. .Build.cs declares dependencies such as Core, CoreUObject, Engine.
C++ Interfaces
UINTERFACE and I[Name] define contracts so actors can interoperate without class knowledge.

Why this matters

Maintainability, reuse, and team boundaries

A clear structure reduces merge conflicts, makes reviewing and testing easier, and lets teams own modules or plugins without stepping on each other's changes.

Key Takeaway

Design folders and modules with reuse in mind; reserve plugins for cross-project or team-shared systems and use interfaces to avoid tight coupling.
