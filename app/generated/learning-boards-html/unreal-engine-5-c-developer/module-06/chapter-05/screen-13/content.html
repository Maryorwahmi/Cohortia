Module 6 › Chapter 6.5 › Hands-on Activity
Task 1 — IInteractable
  1. Create Interactable via New C++ Class → None and name it Interactable.
  2. Edit IInteractable.h to declare Interact as BlueprintNativeEvent and implement default Interact_Implementation in cpp.
  3. Implement public IInteractable on an actor and define Interact_Implementation to log or toggle state.
  4. From player code, check Implements<UInteractable>() and call IInteractable::Execute_Interact(HitActor, ThisPlayer).
Task 2 — MyUtilityPlugin
  1. Create Blank plugin named MyUtilityPlugin and restart the editor.
  2. Edit Build.cs to add CoreUObject, Engine to PublicDependencyModuleNames.
  3. Add UMyBlueprintFunctionLibrary with static BlueprintCallable GetGreetingMessage.
  4. Compile and call the function from a Blueprint to verify the plugin API.
Testing tips
Restart editor after creating plugin, include interface headers where you call Implements<>, and use the _Implementation suffix for BlueprintNativeEvent functions.
