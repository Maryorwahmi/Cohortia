Module 6 › Chapter 6.5 › What Is a Plugin?
Overview

Self-contained, reusable, compiled modules

Plugins have their own Source folder, Public/Private structure, and build configuration. They are compiled separately and can declare dependencies in .Build.cs.

Use cases
  • Reusable gameplay systems across projects
  • Third-party SDK encapsulation
  • Team separation and modding support
