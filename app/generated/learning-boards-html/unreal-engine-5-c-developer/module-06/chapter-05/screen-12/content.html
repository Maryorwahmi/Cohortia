Module 6 › Chapter 6.5 › Plugins vs Game Module
When to use a Plugin
  • Systems you want reusable across projects
  • Third-party SDKs encapsulation
  • Team-owned modules and modding APIs
When to use Game Module
  • Highly game-specific mechanics
  • Rapid prototype code with low reuse expectation
  • Avoid plugin overhead for tiny features
Example: Inventory System
If you plan to reuse inventory mechanics in future projects, create a plugin; otherwise keep it in the game module.
Example: Single Boss Logic
If the boss is unique to this game and tightly coupled, keep it in the game module to avoid plugin maintenance.
