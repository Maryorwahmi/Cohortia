Module 6 › Chapter 6.5 › Create a Blank Plugin
Step-by-step
  1. Editor → Plugins → New Plugin → Blank → Name MyUtilityPlugin.
  2. Restart editor so the plugin registers with the project.
  3. Edit MyUtilityPlugin.Build.cs and add Core, CoreUObject, Engine to PublicDependencyModuleNames.
  4. Add UMyBlueprintFunctionLibrary deriving from UBlueprintFunctionLibrary and a static BlueprintCallable function.
  5. Compile and test the function from a Blueprint.
Example function
UFUNCTION(BlueprintCallable, Category = "MyUtility")
static FString GetGreetingMessage();
Common mistakes
  • Not restarting the editor after creating the plugin scaffold.
  • Forgetting to add CoreUObject when using UObject types.
  • Placing highly game-specific logic in a plugin unnecessarily.
Key Takeaway

Follow scaffold → declare dependencies → implement code → compile → test in Blueprint to confirm plugin functionality.
