Module 6 › Chapter 6.2 › Learning Objectives
01. Use Profiling Tools
Stat commands & Session Frontend
Run Stat FPS, Unit, and Game to get quick timing checks. Capture a Session Frontend trace to analyze CPU, GPU, and call stacks. These give you measurable targets.
Verified competency milestone
02. Apply C++ Optimizations
Cache, allocations, ticks
Re-layout hot data to be contiguous, reduce per-frame allocations, and disable ticks when not needed. These changes reduce CPU cache misses and allocator pressure.
Verified competency milestone
03. Debug with IDEs
Breakpoints, stepping, call stacks
Attach Visual Studio or Rider to the editor or packaged process. Use conditional breakpoints and watch windows to inspect runtime state without guessing.
Verified competency milestone
04. Use UE_LOG Effectively
Categories & verbosity
Prefer UE_LOG with defined categories and Verbose levels for detailed traces. This keeps logs structured and filterable in editor and builds.
Verified competency milestone
