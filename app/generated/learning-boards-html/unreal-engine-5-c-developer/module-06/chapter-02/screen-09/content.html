Module 6 › Chapter 6.2 › Const Correctness
Definition
Const correctness
Mark functions and parameters const to prevent unintended mutation and avoid needless copies, aiding both correctness and optimization.
Example: pass large structs as const references to avoid a copy per call in hot loops.
Why it matters: fewer copies reduce CPU and memory overhead and make intent explicit for future maintainers.
Common Mistake
Treating const as an optimization magic. Use it primarily for correctness and to remove copies; verify with profiling for measurable gains.
Pro Tip
Combined with contiguous layouts and reduced allocations, const usage helps keep hot code paths tight and predictable.
