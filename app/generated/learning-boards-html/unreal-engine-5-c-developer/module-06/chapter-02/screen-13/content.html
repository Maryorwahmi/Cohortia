Module 6 › Chapter 6.2 › Lab Workflow
Step-by-step
  1. Place several MyPerformanceActor instances in a level and run the editor to collect baseline Stat Unit and Stat Game readings.
  2. Open Session Frontend and record a 5–10 second capture reproducing the frame drop.
  3. Identify AMyPerformanceActor::Tick in the CPU view and note its self-time.
  4. Make a single optimization (reduce NumIterations, run every N frames, or disable Tick and run on demand).
  5. Rebuild, re-run the same capture sequence, and compare traces and Stat outputs to confirm improvement.
Reflection
Which change reduced self-time the most? Did any change affect correctness or behavior? If so, adjust your approach and re-test.
Key Takeaway
Measure before and after to know which optimization actually improved frame time. Data prevents wasted effort and regressions.
