How to use
UE_LOG with categories
Define categories and choose verbosity to keep logs useful and filterable. Avoid heavy logging in hot loops.
// Define a category
DEFINE_LOG_CATEGORY_STATIC(MyPerfLog, Log, All);

// Use the log
UE_LOG(MyPerfLog, Verbose, TEXT("Iteration %d result: %f"), i, Result);
Practical guidance
Use Verbose for detailed traces you only enable during deep debugging. Use Warning or Error for issues that should be visible by default. Turn off or gate Verbose logs in production builds to avoid overhead.
Common Pitfall
Leaving high-volume logs unguarded in a hot loop can itself create performance problems and large log files. Always re-profile after adding logs if they run frequently.
