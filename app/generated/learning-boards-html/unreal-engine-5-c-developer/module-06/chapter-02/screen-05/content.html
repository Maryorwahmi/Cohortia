Module 6 › Chapter 6.2 › Session Frontend
Workflow
Capture and analyze a profile
Record a Session Frontend trace while reproducing the issue, then use CPU and GPU views to find functions with high self-time and analyze their call stacks.
Connect & Capture
  1. Open Session Frontend from Window → Developer Tools.
  2. Connect to the editor instance and start a capture.
  3. Reproduce the slow frame and stop the capture.
Inspect Threads
Open CPU usage, switch to call stacks, sort by self-time. Look for top entries like AMyPerformanceActor::Tick to target optimization.
Concrete Example
Capture a 5–10 second trace while MyPerformanceActor instances run. In the CPU view, search for Tick and inspect its call stack. If the heavy loop appears, you now know where to change code.
Key Takeaway
Session Frontend proves cause by showing function-level timings and call stacks. Use it to avoid guesswork.
