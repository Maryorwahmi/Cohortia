Module 6 › Chapter 6.2 › Stat Commands
Definition
Stat Commands
Console commands that report runtime metrics for quick diagnosis. They are low overhead and ideal for triage.
Stat FPS — shows frame rate and frame time.
Stat Unit — splits frame time into Game, Draw, GPU, RHI.
Stat Game — shows game-thread breakdown including actor ticks and AI.
Concrete Example
Add the MyPerformanceActor to a level and run the editor. Open the console and type Stat Unit. If Game time spikes above Draw and GPU, the actor's Tick is likely the culprit. This gives a hypothesis to confirm with Session Frontend.
Process
Step-by-step triage using Stat commands
1
Run Stat FPS
Confirm whether the symptom is a general frame-rate drop.
2
Run Stat Unit
See Game vs Draw vs GPU to identify the dominant subsystem.
3
Run Stat Game
Look for high actor tick times or AI entries that point to specific code areas.
Common Mistake
Assuming visible stutter equals CPU time. Stat Unit often shows that GPU or Render Thread is the actual bottleneck; optimize where the data points you to.
