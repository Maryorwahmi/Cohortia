Concept
Cache Locality
Place frequently accessed, related data contiguously so CPU caches can load and reuse it efficiently.
Why it matters: Reduced cache misses lower memory latency and improve per-frame timings in hot loops.
How to detect: Use Session Frontend to find hot loops, then inspect data access patterns in code.
Quick win: Replace scattered pointers with contiguous arrays for update loops.
Analogy & Example
Think of cache as a small workbench. If all tools you need are on the bench, you avoid trips to the warehouse. In code: iterate a TArray of structs rather than following pointers to heap objects.
Common Mistake
Rewriting an algorithm before checking memory layout. Cache fixes are lower risk and often give immediate gains for tight loops.
