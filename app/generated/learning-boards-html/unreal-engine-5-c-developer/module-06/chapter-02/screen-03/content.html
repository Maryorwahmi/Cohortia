01 Learn
Run Stat FPS, Stat Unit and Stat Game to see immediate timing and thread breakdowns. Memorize the output so you can spot anomalies quickly.
02 Understand
Capture a Session Frontend profile, inspect CPU and GPU timings, and drill into call stacks to locate the function with the highest self-time.
03 Apply
Apply focused C++ fixes such as better data layout, object pooling, and disabling unneeded ticks. Change only the hot path proved by the profiler.
04 Master
Verify improvements by re-running Stat and Session Frontend and use your IDE to debug edge cases. Maintain readable UE_LOG outputs for long-term diagnosis.
