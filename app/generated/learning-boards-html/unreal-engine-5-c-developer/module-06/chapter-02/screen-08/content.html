Module 6 › Chapter 6.2 › Tick Policy
Definition & Strategy
Avoid unnecessary Tick work
Evaluate if a computation must run every frame. Use conditional execution, timers, or event-driven signals to reduce per-frame load.
A
Move to events
If a value changes on input or collision, compute it when the event occurs rather than every Tick.
B
Frame-skipping
Perform heavy work every N frames using GetWorld()->GetFrameNumber() % N == 0 to spread cost.
C
Disable Tick
If the actor never needs per-frame updates, set PrimaryActorTick.bCanEverTick = false and call a function when needed.
Example
Change the heavy loop in MyPerformanceActor::Tick to only run when GetWorld()->GetFrameNumber() % 10 == 0. Re-profile to confirm lower game thread usage.
Key Takeaway
Every Tick entry increases game-thread cost. Move or reduce frequency for heavy work to improve frame stability.
