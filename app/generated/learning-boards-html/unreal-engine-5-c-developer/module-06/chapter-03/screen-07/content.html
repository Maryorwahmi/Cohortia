Module 6 › Chapter 6.3 › Implementing Variable Replication
Step-by-step
  1. 1. Mark property: UPROPERTY(Replicated) or ReplicatedUsing=OnRep_Fn.
  2. 2. Ensure actor/component has bReplicates = true.
  3. 3. Override GetLifetimeReplicatedProps and call DOREPLIFETIME(Class, Property).
  4. 4. Implement OnRep to react on clients, update UI or broadcast delegates.
Mistake to avoid
Omitting Super::GetLifetimeReplicatedProps or passing the wrong class to DOREPLIFETIME stops registration.
Concrete code snippet
UPROPERTY(ReplicatedUsing=OnRep_CurrentHealth)
float CurrentHealth;

UFUNCTION()
void OnRep_CurrentHealth();

void UMyHealthComponent::GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const
{
  Super::GetLifetimeReplicatedProps(OutLifetimeProps);
  DOREPLIFETIME(UMyHealthComponent, CurrentHealth);
}
This pairing ensures the server-owned CurrentHealth is sent to clients and that they run OnRep_CurrentHealth when the value changes.
Key Takeaway

Register every replicated property for lifetime replication and use OnRep callbacks to react on clients.
