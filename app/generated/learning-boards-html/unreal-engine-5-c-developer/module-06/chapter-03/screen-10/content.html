Module 6 › Chapter 6.3 › bReplicates and Ownership
bReplicates
Set bReplicates = true in constructors of actors or ensure components are attached to replicated actors. Without it, replication and RPCs will not propagate as expected.
Ownership
Only the owning client can call Server RPCs on an actor. Ensure ownership is assigned correctly for dynamic actors you expect clients to control.
Diagnostic checklist
  • Confirm bReplicates is true in constructor.
  • Check actor roles at runtime (Authority vs Remote) to understand where code runs.
  • Verify ownership for actors clients need to call Server RPCs on.
Warning
Missing replication flags is a silent failure that looks like code not executing; add checks early in testing.
