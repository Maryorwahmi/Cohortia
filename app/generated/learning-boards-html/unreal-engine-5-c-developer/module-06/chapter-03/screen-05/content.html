Module 6 › Chapter 6.3 › Replication Fundamentals
Key steps
  • 1. Use UPROPERTY(Replicated) on variables that must travel to clients.
  • 2. Override GetLifetimeReplicatedProps and call DOREPLIFETIME for each property.
  • 3. Optionally use ReplicatedUsing to run an OnRep callback on clients.
  • 4. Use replication conditions to restrict who receives data.
Common mistake
Adding Replicated without DOREPLIFETIME: the engine will not actually send updates unless the property is registered for lifetime replication.
Example: GetLifetimeReplicatedProps
// In MyHealthComponent.cpp
void UMyHealthComponent::GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const
{
  Super::GetLifetimeReplicatedProps(OutLifetimeProps);
  DOREPLIFETIME(UMyHealthComponent, CurrentHealth);
}
This registration tells Unreal which properties to watch and send to clients. Use conditions like COND_OwnerOnly when data should be private to the owning player.
Key Takeaway

Replication requires both marking and registration; OnRep callbacks let clients react when values arrive.
