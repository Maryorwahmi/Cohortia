Module 6 › Chapter 6.3 › Testing & Debugging Multiplayer
Step checklist
  1. 1. Launch server instance and client instance.
  2. 2. Trigger Server RPC from client and observe server logs.
  3. 3. Watch for replicated property updates and OnRep calls on client logs.
  4. 4. Confirm multicast effects appear on all clients.
Debug tip
Add UE_LOG messages to Server_ApplyDamage_Implementation, OnRep_CurrentHealth, and Multicast_PlayDamageEffect to track event flow across processes.
Sample logs to add
UE_LOG(LogTemp, Warning, TEXT("Server: Applying damage %f"), DamageAmount);
UE_LOG(LogTemp, Warning, TEXT("Client: Health updated to %f"), CurrentHealth);
UE_LOG(LogTemp, Warning, TEXT("Playing damage effect!"));
These logs make it clear where each step runs and whether replication and multicast calls execute as expected.
