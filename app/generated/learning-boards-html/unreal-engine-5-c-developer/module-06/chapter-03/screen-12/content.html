Module 6 › Chapter 6.3 › Bandwidth & Replication Conditions
When to limit replication
  • Private data (inventories, personal UI) → COND_OwnerOnly
  • Cosmetic-only data → prefer local simulation instead of replication
  • Large arrays or containers → consider USTRUCTs, delta updates, or server-side queries
Key Takeaway

Be deliberate about what to replicate. Use conditions to save bandwidth and avoid leaking private information.

Example registration with condition
DOREPLIFETIME_CONDITION(AMyCharacter, Inventory, COND_OwnerOnly);
This ensures Inventory is replicated only to the owning client, protecting privacy and saving network bandwidth.
