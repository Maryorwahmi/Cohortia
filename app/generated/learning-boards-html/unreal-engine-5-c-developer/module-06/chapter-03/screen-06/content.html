Module 6 › Chapter 6.3 › RPC Types
Server RPC
Called by a client, runs on the server. Use for validated, authoritative actions like ApplyDamage. Mark Reliable if arrival matters and WithValidation for custom checks.
Client RPC
Called by server, runs only on the owning client. Use for owner-specific UI updates or sounds.
NetMulticast RPC
Called by server, runs on all clients and server. Use for global effects like explosions or shared animations.
Concrete code examples
// Server RPC
UFUNCTION(Server, Reliable, WithValidation)
void Server_ApplyDamage(float DamageAmount);

// Client RPC
UFUNCTION(Client, Reliable)
void Client_DisplayHitMarker();

// NetMulticast RPC
UFUNCTION(NetMulticast, Reliable)
void Multicast_PlayDamageEffect();
Pitfall
RPCs must originate from correct authority and owning actor. Calling Server RPCs from non-owning clients silently fails.
Key Takeaway

Match RPC type to intent: validation on server, owner feedback on client, shared visual effects via multicast.
