Client-Server Model
Server is authoritative; clients send input and simulate until confirmed.
Replication
Mark variables and register them in GetLifetimeReplicatedProps so the engine sends updates.
RPC Types
Server, Client, NetMulticast each have defined execution contexts; pick the one that matches your intent.
Takeaway
Design with authority, mark and register replicated state, and test with server/client instances to verify behavior.
