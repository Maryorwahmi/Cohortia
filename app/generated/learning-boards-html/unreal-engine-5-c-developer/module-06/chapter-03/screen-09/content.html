void UMyHealthComponent::Server_ApplyDamage_Implementation(float DamageAmount)
{
  // Run on server
  CurrentHealth = FMath::Clamp(CurrentHealth - DamageAmount, 0.0f, MaxHealth);
  // Trigger visual effect on all clients
  Multicast_PlayDamageEffect();
}

void UMyHealthComponent::Multicast_PlayDamageEffect_Implementation()
{
  UE_LOG(LogTemp, Warning, TEXT("Playing damage effect!"));
}
Explanation
Validate to avoid bogus input, modify server state so it becomes authoritative, then multicast local visuals for all clients.
Misconception
OnRep functions run on clients only; do not rely on them for server-side logic.
Key Takeaway

Server code changes state; multicast informs clients to play shared effects.
