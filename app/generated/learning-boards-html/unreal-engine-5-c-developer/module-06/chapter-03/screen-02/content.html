01
Explain Client-Server Architecture
Describe authoritative server role and client input flow.
You will be able to name authority rules and reason about who validates actions. A concrete example: why the server must validate a pickup action to prevent cheating.
Verified competency milestone
02
Understand Replication
Explain how server synchronizes variables to clients.
You will explain what gets replicated and why manual registration via GetLifetimeReplicatedProps is essential for bandwidth control and privacy.
Verified competency milestone
03
Implement Replicated Variables
Use UPROPERTY(Replicated) and DOREPLIFETIME in C++.
You will edit a component to mark CurrentHealth as replicated and register it for lifetime replication so clients receive updates automatically.
Verified competency milestone
04
Differentiate RPC Types
Recognize Server, Client, and NetMulticast uses.
You will pick RPCs for input validation, client-specific feedback, and global visual effects, and avoid common authority mistakes.
Verified competency milestone
