Header excerpt
// MyHealthComponent.h (excerpt)
UPROPERTY(ReplicatedUsing=OnRep_CurrentHealth, VisibleAnywhere, Category="Health")
float CurrentHealth;

UFUNCTION()
void OnRep_CurrentHealth();

UFUNCTION(Server, Reliable, WithValidation)
void Server_ApplyDamage(float DamageAmount);

UFUNCTION(NetMulticast, Reliable)
void Multicast_PlayDamageEffect();

virtual void GetLifetimeReplicatedProps(TArray<FLifetimeProperty>& OutLifetimeProps) const override;
Explanation
  • CurrentHealth: replicated using an OnRep callback for client-side reactions.
  • Server_ApplyDamage: client-to-server request with validation for security.
  • Multicast_PlayDamageEffect: server-triggered visual feedback for all clients.
  • GetLifetimeReplicatedProps: registers CurrentHealth with DOREPLIFETIME.
Pro tip
Keep replication surfaces small: replicate only what you need to reduce bandwidth and complexity.
