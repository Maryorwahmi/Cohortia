Troubleshooting
Frequent mistakes and fixes
Committed binaries
If Binaries or DerivedDataCache are in history, the repo will be large. Untrack them and consider cleaning history if needed.
Wrong build config
Shipping removes diagnostics. Use Development during debugging and only Shipping for final releases.
Missing plugins or maps
Confirm required plugins and default maps are set to avoid runtime failures in the packaged build.
Quick diagnostics
  • Inspect packaging logs for cook errors.
  • Run git status to find unexpected tracked files.
  • Untrack generated files with git rm --cached when needed.
Pro tip
Add a quick pre-package checklist that includes git status, plugin checks, and free disk space verification.
