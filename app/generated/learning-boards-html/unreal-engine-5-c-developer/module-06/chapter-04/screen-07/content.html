Module 6 › Chapter 6.4 › Automated Packaging
Process
Make packaging scriptable
Write a script that invokes the editor's headless or build tools with explicit platform and configuration arguments. Keep configuration in the project file so CI runs can use the same settings.
Why automate?
  • Reproducible builds for CI or nightly artifacts.
  • Eliminate human steps and configuration drift.
  • Archive artifacts for testers or release pipelines.
Script fragment (visual)
# Example headless call (visual only)
# Invoke the editor to run a packaging command for Windows Shipping
"UE4Editor.exe" "YourGame.uproject" -run=Cook -TargetPlatform=WindowsNoEditor -unattended
"UE4Editor-Cmd.exe" "YourGame.uproject" -run=Package -TargetPlatform=WindowsNoEditor -cook -build
This shows the idea of calling editor tools in a script. Replace with your engine and project paths and confirm flags for your engine version.
Checklist for CI
Ensure runner has required SDKs, set environment variables, and archive resulting artifacts for testers.
