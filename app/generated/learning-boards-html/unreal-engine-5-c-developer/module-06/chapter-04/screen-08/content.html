Module 6 › Chapter 6.4 › .gitignore for Unreal
Definition
Which folders to ignore
Ignore generated and per-machine files: Binaries, Build, Intermediate, DerivedDataCache, and Saved. Also exclude IDE files and temporary logs. Track code, configuration, and essential assets only.
Why ignore these folders?
They are large, machine-specific, and change frequently, which would bloat and fragment repository history.
What to keep
Keep source files (.cpp, .h), config (.ini), and essential assets (.uasset, .umap) needed to build and reproduce content.
Minimal example (.gitignore snippet)
# Unreal Engine generated
Binaries/
Build/
DerivedDataCache/
Intermediate/
Saved/
*.log
# IDE files
.vs/
.idea/
Start with a minimal ignore and add project-specific exclusions. After adding .gitignore, re-run git status to confirm excluded files no longer appear.
