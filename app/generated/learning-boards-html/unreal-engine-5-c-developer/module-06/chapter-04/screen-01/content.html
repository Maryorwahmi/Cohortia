Packaging, Deployment & Version Control
Move builds to players and keep project history tidy with Git.

Packaging creates a standalone executable for a target platform by compiling C++ code, cooking assets, and bundling configuration.

Version control with Git records changes and prevents repository bloat by excluding generated files using .gitignore.

In this lesson
  • How build configurations affect final builds and debugging.
  • Practical packaging steps for Windows and automation options.
  • Setting up Git, creating a sound .gitignore, and basic Git commands.
Coming up
  • Hands-on activity: package a game and initialize Git properly.
  • Common mistakes and how to avoid repository bloat.
