Essential Git commands
Run these commands from your project root where YourGame.uproject is located. Close the editor first to avoid locked files.
git init
git add .
git commit -m "Initial commit of Unreal Engine project"
# Later:
git add path/to/changed/file
git commit -m "Describe the change briefly"
git push origin main
git pull origin main
Guidance and common errors
Commit small, logical changes and write descriptive messages. Always run git status before committing to see unstaged files. Pull before starting new work to reduce merge conflicts.
Pitfall
Committing generated binaries dramatically increases repository size and causes frequent conflicts. Use a good .gitignore.
Pro tip
Make small, frequent commits and push often. This creates logical checkpoints and simplifies collaboration.
