Module 6 › Chapter 6.4 › What is Packaging?
Definition
Packaging explained
Packaging bundles compiled game modules and cooked assets into a distributable folder. It converts editor content into runtime formats and includes platform-specific binaries so the game runs outside the editor.
Compile C++ modules and link binaries for the target platform.
Cook assets into runtime-friendly formats and include them in the build.
Collect configuration such as default maps, game instance, and packaging settings.
Concrete example
Windows package of a small project
A Windows packaging run compiles modules to a 64-bit executable, cooks textures and maps, and produces a folder with the .exe and content subfolders. Run the executable to verify launch and the chosen default map.
Checklist before packaging
  • Default maps set in project settings.
  • Required plugins enabled and configured.
  • Packaging destination selected and disk space available.
Common mistake
Packaging with Development or DebugGame when Shipping was intended leads to larger files and retained debug hooks. Verify build configuration before long runs.
Key Takeaway

Packaging is more than copying files; it compiles, cooks, and configures a playable build you can test and ship.
