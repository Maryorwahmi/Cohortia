Walkthrough
Package then set up Git
Follow these steps as you perform the activity and keep notes about any packaging errors or Git surprises you encounter.
Packaging steps
  • Confirm default map and plugins.
  • Perform Development package, run the exe, fix issues.
  • Perform Shipping package for final verification.
Git setup
cd /path/to/project
# create .gitignore with Unreal exclusions
git init
git add .gitignore
git add .
git commit -m "Initial commit of Unreal Engine project"
Checks and reflections
After packaging, run the executable and confirm the default map loads. After git setup, run git status and verify no large generated folders are tracked. Note any differences between editor-play and packaged behavior.
Key Takeaway
Practice both packaging and Git setup so building and sharing a project becomes routine and reliable.
