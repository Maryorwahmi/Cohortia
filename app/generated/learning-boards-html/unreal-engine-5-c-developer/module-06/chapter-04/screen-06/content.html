Process Flow
Packaging checklist
1
Prepare project settings
Verify default maps, game instance, and required plugins are enabled.
2
Choose build configuration
Select Development for testing, Shipping for release.
3
Select platform and destination
Pick the target platform and an empty destination folder with enough disk space.
4
Run packaging and monitor logs
Watch for cooking errors, missing assets, or plugin failures in the output log.
5
Validate the build
Run the executable, confirm default map, and perform a smoke test of gameplay.
Example validation
After packaging, open the output folder and run the executable. Confirm the game opens on the expected default map and basic interactions work. If it fails, open packaging logs to find missing asset references or plugin errors.
Common mistake
Assuming the editor launch equals packaged success. Always run the packaged exe; editor-only content or editor modules may be missing in the build.
Pro tip
Do a Development package first to catch issues faster, then produce a Shipping build for final distribution.
