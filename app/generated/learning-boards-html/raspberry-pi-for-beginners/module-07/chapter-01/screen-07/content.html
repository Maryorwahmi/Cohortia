Process

Enable, start, check, and follow logs

Use the systemctl and journalctl commands to iterate until the unit runs reliably, then enable it to start at boot.

Reload manager
sudo systemctl daemon-reload
Enable unit
sudo systemctl enable myproject.service
Start & status
sudo systemctl start myproject.service
sudo systemctl status myproject.service
Follow logs
journalctl -u myproject.service -f
Example verification flow
  1. Reload manager after editing the unit file.
  2. Start the unit and watch status until it becomes active.
  3. Follow the journal to confirm expected output appears.
  4. When stable, enable so it starts on future boots.
Common pitfall
Enabling a broken unit can cause boot failures or noisy error logs. Test first, then enable.
Key Takeaway

Iterate with start and status until the service is stable, then enable for boot persistence.
