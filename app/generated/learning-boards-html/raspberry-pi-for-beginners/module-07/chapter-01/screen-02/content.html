Learning Objectives

Build and verify automatic startup for Pi projects.

Bloom: Learn → Understand → Apply → Master
01
Use systemd services

Write and enable a service unit so a Python script runs at boot and restarts on failure. Verified competency milestone.

Mnemonic: service file = tiny config map
02
Schedule with @reboot

Use crontab with @reboot to run a command once on startup and redirect output to a log. Verified competency milestone.

Mnemonic: @reboot = one-shot cron trigger
03
Manage long-running processes

Apply Restart and RestartSec so services recover after crashes without constant restarts. Verified competency milestone.

Mnemonic: Restart = auto-heal
04
Log output from services

Redirect stdout and stderr to a file or use journalctl to inspect the system journal. Verified competency milestone.

Mnemonic: logs = your service's memory
