cron @reboot

Quick startup

A single-line cron entry runs a command at boot. It is easy to configure but offers no supervision.

Example line
@reboot /usr/bin/python3 /home/alex/myscript.py >> /home/alex/myscript.log 2>&1
Redirects both normal output and errors into a log file so you can inspect runs after reboot.
Common misconception
People often assume cron restarts crashed scripts. It does not; it runs at boot only.
systemd

Supervised services

systemd manages service units with restart policies, user control, and built-in logging via the journal. It is suited to long-running processes.

Service snippet
[Service]
ExecStart=/usr/bin/python3 /home/alex/myproject/main.py
User=alex
Restart=always
RestartSec=5
Restart ensures recovery; User avoids running as root. RestartSec avoids a tight restart loop.
Practical choice
If your process must run continuously and recover from failure, use systemd; otherwise cron is a lightweight option.
