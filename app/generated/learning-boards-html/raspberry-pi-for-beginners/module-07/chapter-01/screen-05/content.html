Process

Edit crontab and add @reboot

Open crontab with crontab -e and add an @reboot entry that calls Python with full paths and redirects output to a log file.

Checklist
  • Use absolute paths for interpreter and script.
  • Redirect stdout and stderr so you can inspect results after reboot.
  • Reboot to confirm the line runs and writes the log.
  • Don't assume cron restarts failed processes.
Example
@reboot /usr/bin/python3 /home/alex/myscript.py >> /home/alex/myscript.log 2>&1
Appends both normal output and errors into myscript.log so you can verify runs.
Common mistake
Using relative paths or trusting a shell profile — cron runs in a minimal environment. Explicitly set paths inside the command or script.
Key Takeaway

cron @reboot is fast to set up; use it for single-run startup tasks but not for supervised daemons.
