Module 7 › Chapter 7.1 › Running services as non-root
Why it matters

Least privilege

Running as a normal user reduces the potential impact of bugs. Use User= in your unit to set the account the service will run under.

Example field
User=alex
Ensure the account owns any files the service needs to write.
Checklist
  • Set WorkingDirectory to a folder the user can access.
  • Give the user ownership of log files the service will append to.
  • Consider group access for hardware devices if needed.
Misconception
Believing root is required for boot startup. systemd can launch a unit under any user account when configured and enabled.
Key Takeaway

Run services with the least privilege necessary and grant explicit file or device permissions as required.
