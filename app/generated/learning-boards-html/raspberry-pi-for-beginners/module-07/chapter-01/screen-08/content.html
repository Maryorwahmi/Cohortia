Module 7 › Chapter 7.1 › Logging output
Cron file logging

Redirect stdout and stderr

@reboot /usr/bin/python3 /home/alex/myscript.py >> /home/alex/myscript.log 2>&1
Both streams are appended so you can read what happened after boot.
Test by writing a known message from the script and confirming it appears in the log after reboot or after cron runs.
systemd journal

Use journalctl for managed services

journalctl -u myproject.service -f
Follow live log entries for the named unit, including startup messages and tracebacks.
A common mistake is checking only process presence; examine logs to ensure the service is performing its expected actions.
Key Takeaway

Pick a logging strategy appropriate for your launcher: file redirection for cron, journalctl for systemd services.
