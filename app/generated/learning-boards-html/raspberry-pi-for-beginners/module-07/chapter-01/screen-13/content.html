Module 7 › Chapter 7.1 › Key Concepts
@reboot
Runs a command once at boot; simple to use but not supervised or restartable.
systemd service files
Declare execution, working directory, user, restart behaviour, and install target for robust services.
Logging & Security
Capture output to files or use journalctl, and run services as non-root users whenever possible.
Summary

Choose the startup method that matches your project's needs, verify with logs and status, and apply least privilege for safer services.
