Restart

Policies and delays

Restart=always makes systemd restart on any exit; RestartSec sets a pause between attempts. These combine to create resilient services.

Example fields
Restart=always
RestartSec=5
A short pause prevents tight restart loops and gives external dependencies time to recover.
Testing
Force the script to exit to verify systemd restarts it. If it repeatedly fails, examine logs and add a longer RestartSec or fix the root cause.
Common mistake
Using Restart=always without a RestartSec can generate a busy restart loop. Always include a sensible delay.
Key Takeaway

Combine restart policy with a delay, and ensure logs give context for why restarts occur.
