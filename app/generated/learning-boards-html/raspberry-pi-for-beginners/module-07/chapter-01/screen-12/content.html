Troubleshooting

Quick diagnostic checklist

1. Check logs
Inspect redirected log files or use journalctl -u unit -n 50 to see recent entries.
2. Verify paths
Ensure ExecStart and any in-script file paths are absolute and valid.
3. Confirm permissions
Check the service user owns the working dir and can write logs.
4. Read status
Use sudo systemctl status to see exit codes and recent log excerpts.
5. Reload manager
Run daemon-reload after edits so systemd picks up changes.
6. Test intentionally
Trigger an expected log line or controlled exit to ensure behavior is observable and recoverable.
Final tip

Make small iterative changes and test after each one so you can identify which action fixed the issue.
