Script

Simple timestamp logger

# Pseudocode layout
import time
with open('/home/alex/myproject/log.txt','a') as f:
    while True:
        f.write(time.strftime('%Y-%m-%d %H:%M:%S') + ' - alive\n')
        f.flush()
        time.sleep(10)
The script appends a timestamp every ten seconds so you can confirm activity after reboot.
Ensure the script file is executable and owned by the user specified in the unit so writes succeed.
Service unit
[Service]
ExecStart=/usr/bin/python3 /home/alex/myproject/logger.py
WorkingDirectory=/home/alex/myproject
User=alex
Restart=always
RestartSec=5
Place the full unit in /etc/systemd/system/myproject.service and use daemon-reload before starting.
After starting, use journalctl -u myproject.service -f to watch timestamps appear, then enable and reboot to confirm persistence.
