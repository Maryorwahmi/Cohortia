Module 7 › Chapter 7.1 › Learning Objectives — Practical Focus

Practice and verify

Apply each objective to a real script and use the system tools to prove it works across a reboot.

Practice 1
Create a service file, enable it, and check status until it runs reliably.
Practice 2
Use @reboot for a quick startup, then confirm log file writes after reboot.
Practice 3
Simulate a crash to confirm systemd restarts the process with Restart=always.
Practice 4
Use journalctl or redirected logs to diagnose start failures.
Milestone
After completing these steps, you can deploy a service that survives reboots and reports its status and logs.
Verified Competency Milestone

Service runs after reboot, restarts if it fails, and writes logs you can inspect.
