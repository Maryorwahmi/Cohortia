Enable and verify interfaces
I2C, SPI, and serial often need explicit enabling via raspi-config before use.
Step: Enable interface
Use raspi-config to enable the required interface, then reboot if needed so the kernel exposes devices.
Step: Install compatible library
Confirm the Python package is installed in the interpreter you use and that it supports your Pi model.
Concrete example
If a sensor returns garbage, enable the interface in raspi-config, confirm the device node appears, then run a minimal script that only opens and reads the sensor. If that script fails with a module-not-found error, install the required package in the same environment and try again.
Common mistake
Forgetting to enable an interface or installing a library in the wrong Python environment causes confusing errors that look like hardware faults.
