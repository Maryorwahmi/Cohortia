Module 7 › Chapter 7.3 › Boot Diagnosis
Boot LED patterns
Use LED behavior to triage power vs SD issues.
Power LED blinks or off
Usually insufficient power. Try a known-good power supply and cable before changing other parts.
Red steady, green inactive
Indicates SD card missing, corrupted, or not flashed. Re-flash or try another card.
Concrete example
If you see only a steady red LED at power-up, remove the SD card, re-flash the image on another machine, and reinsert it. If the green activity LED appears, the boot files were the issue.
Quick checks
  • Confirm power supply rating and cable condition.
  • Try a different SD card or re-flash the image if green activity is absent.
  • Connect a monitor to observe boot messages when possible.
Key Takeaway

LEDs give immediate clues. Fix power or SD first before changing application code.
