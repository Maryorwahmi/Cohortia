Confirming connectivity
Steps to separate network issues from SSH problems.
Find the IP
Use your router's admin page or connect a monitor to the Pi to read the address. Knowing the IP is essential for connectivity tests.
Ping to test reachability
A successful ping shows the network path is alive. If ping fails, fix network settings before changing SSH configuration.
Terminal-style callouts
ping 192.168.1.42 — returns replies if reachable
Concrete example
If ping gives replies but SSH times out, the issue is likely SSH configuration or firewall rules. If ping times out, the network path is broken and must be fixed first.
Common mistake
Assuming SSH is the only problem. Always confirm basic network reachability first with a ping or router check.
