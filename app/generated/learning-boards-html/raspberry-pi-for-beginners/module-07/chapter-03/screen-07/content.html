Module 7 › Chapter 7.3 › Multimeter Use
Measure before you change code
Confirm voltages and continuity so you know whether a problem is electrical.
Common checks
  • Verify 3.3V and 5V supply rails.
  • Check GPIO pin voltage when toggled by a script.
  • Confirm ground continuity between components.
Practical example
If an LED does not light, measure the pin while the script runs. If you see the expected voltage, focus on LED orientation and resistor; if not, inspect code and pin setup.
Key Takeaway

A quick voltage or continuity check rules out many hardware causes before you change software.

Visual toolbox
Multimeter reading: 3.3 V
Common mistake
Assuming wiring is correct because it looks right. Always verify pin numbers and continuity with a meter.
