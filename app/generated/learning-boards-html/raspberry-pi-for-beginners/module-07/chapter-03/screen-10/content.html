Traceback reading pattern
Locate the error type and message, then follow the stack to the offending line.
Traceback (most recent call last): File "script.py", line 42, in sensor.read() File "sensor.py", line 10, in read raise ModuleNotFoundError('No module named "gpiozero"') ModuleNotFoundError: No module named 'gpiozero'
Concrete example
This traceback shows the final line names the missing module. Install the package in the environment you run, then re-run and confirm the traceback disappears or changes to a different error.
Common misconception
Don't assume the topmost frame is the cause; the actual error type at the bottom explains why the exception occurred.
Action checklist
  • Read the last traceback line for the error type and message.
  • Trace up to see which call in your code caused it.
  • Add a print or logging line before the failure to inspect variables, then run again.
