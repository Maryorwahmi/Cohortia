Tools & Practical Checks
Hands-on techniques to confirm hypotheses and gather evidence.
LED interpretation
Recognize power and activity LED patterns to separate power/SD problems from booting failures.
Network reachability
Confirm same-network presence and test reach with a simple connectivity check.
GPIO measurement
Use a multimeter, confirm pin mapping and component orientation before assuming a code bug.
Verification mnemonic
Observe LEDs and logs, isolate a single variable, reproduce the issue in a minimal setup, then restore components stepwise.
Milestone task
Introduce a deliberate wrong pin or disabled interface and then find and fix it using the tools above.
