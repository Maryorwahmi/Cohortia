Module 7 › Chapter 7.3 › Process Flow
Observe → Isolate → Test → Verify
A disciplined sequence to narrow down faults quickly.
01
Observe
Collect LED states, error messages, and exact symptoms without guessing.
02
Isolate
Remove unrelated components so only one variable remains under test.
03
Test
Use the correct tool: multimeter for voltage, ping for network, print or debugger for code.
04
Verify
Restore components gradually and confirm the problem no longer appears.
Key Takeaway

Make one change per test. If you change many things, you cannot know which one fixed the problem.

Concrete example: sensor + display project
Step-by-step
  1. Observe: the display stays blank and sensor returns no data.
  2. Isolate: disconnect the display, test the sensor alone.
  3. Test: use a short script or a multimeter to confirm sensor power and data lines.
  4. Verify: fix wiring or code, reconnect the display, and confirm the full system works.
Common mistake
Changing code and wiring at the same time. If a problem disappears, you cannot tell whether the code or the wiring caused it.
