Module 7 › Chapter 7.3 › Key Concepts
Boot LEDs
Interpret red and green LED behavior to triage boot problems quickly.
Network checks
Confirm same network and use ping to verify reachability before debugging SSH.
Multimeter checks
Voltage and continuity measurements quickly reveal wiring and power issues.
Summary: Start with quick physical checks before changing code. These three verifications are the fastest way to narrow most faults.
