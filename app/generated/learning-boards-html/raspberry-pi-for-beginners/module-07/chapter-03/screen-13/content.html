Module 7 › Chapter 7.3 › Lab: Isolate Variables
Lab setup
Introduce either a wrong pin number in code or disable an interface like SPI for the lab.
Step 1: Observe
Run the project and note the exact symptom: no LED, no sensor data, or errors printed to the terminal.
Step 2: Isolate
Disconnect the display or sensor and test each one separately with a minimal script.
Step 3: Test
Use a multimeter, perform a ping if network related, and read logs or tracebacks to find the failing component.
Example bug
You set the script to use pin 18 but wired the LED to the header for BCM 17. Multimeter shows no voltage on the wired pin while the code toggles a different pin. Correct the numbering in code or rewire to match, then re-run.
Key Takeaway

A single, focused test finds the cause faster than many simultaneous changes. Record what you changed and why.
