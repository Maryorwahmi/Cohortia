Process Flow › Automating with cron
Safe automation pattern
  1. Create a small script that runs rsync and writes a timestamped log.
  2. Include checks: ensure destination is mounted and has sufficient space.
  3. Test the script manually, then add it to cron with an explicit schedule.
  4. Monitor logs and test restores weekly.
Pro tip
Use a log rotation policy or dated backup folders so old backups do not fill the destination.
Example cron entry (visual)
# Run backup script every night at midnight
# 0 0 * * * /home/pi/bin/backup_rsync.sh >> /var/log/backup_rsync.log 2>&1
Make the script idempotent and safe: check mounts and return meaningful exit codes for monitoring.
Common mistake
Scheduling without testing or logging leads to silent failures. Always test and monitor logs or alerts.
