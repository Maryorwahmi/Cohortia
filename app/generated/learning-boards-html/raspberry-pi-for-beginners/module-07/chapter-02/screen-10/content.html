Definition › Project documentation
Essential README sections
  • Project description and goals — what problem the project solves.
  • Hardware list — part numbers, power requirements, and connectors.
  • Wiring notes — diagrams or photos, pin mappings for sensors and cameras.
  • Software dependencies — packages and versions, installation commands.
  • Run and restore steps — how to run, where backups live, and how to restore from an image or rsync mirror.
Example: Restore steps (short)
Write the stored backup image to a spare SD card, boot the Pi, then run the post-restore script to re-enable services and update paths.
Why docs matter
Clear docs save hours when restoring. They also help collaborators and future-you understand design choices and required steps.
Common omission
Missing post-restore steps like re-enabling services or regenerating keys often prevent a restored system from working immediately.
