Definition › Using dd safely
What dd does

Dd copies raw blocks from a device to a file or from a file to a device. It ignores filesystem structure and preserves every byte, which makes it suitable for full images.

Safe workflow
  • Unmount the SD card partitions.
  • Confirm the device name with a reliable tool.
  • Run the copy and verify the resulting image.
  • Test by writing to a spare card and booting the Pi.
Critical warning
If you switch input and output, dd will overwrite drives. Always triple-check the device paths before running the command.
Visual code reference
# Example: create an image of the SD card
# sudo dd if=/dev/sdX of=backup.img bs=4M status=progress

# Example: restore the image to a card
# sudo dd if=backup.img of=/dev/sdX bs=4M status=progress
Note: commands shown for visual reference in the lesson. Do not run without adapting device paths.
Misconception
Dd is not an incremental backup. It creates one full image each time and will overwrite target devices if used incorrectly.
