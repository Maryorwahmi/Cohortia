Learning Objectives
Practical skills to image, backup, automate, and document
Learn → Understand → Apply → Master
01
Create full SD image
Make an image of the entire SD card so you can restore a complete system. This is essential for recovering a broken or corrupted card quickly.
VERIFIED COMPETENCY MILESTONE
02
Restore from image
Write an image back to an SD card to return a Pi to a known working state. Confirm device paths before writing to avoid data loss.
VERIFIED COMPETENCY MILESTONE
03
Use rsync for backups
Learn rsync options to copy only changed files and keep a backup mirror in sync, including the use of deletion when appropriate.
VERIFIED COMPETENCY MILESTONE
04
Document a rebuild process
Create a README with hardware, wiring, dependencies, and restore steps so the project can be rebuilt reliably.
VERIFIED COMPETENCY MILESTONE
