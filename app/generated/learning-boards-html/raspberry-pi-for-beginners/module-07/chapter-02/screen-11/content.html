Hands-on Activity › Image + rsync
Step 1 — Create and verify image
Save the image to your laptop, check file size and checksum, and write to a spare card to boot and confirm.
Step 2 — rsync script
#!/bin/sh
# backup_rsync.sh
# rsync -avz --delete /home/pi/projects/ /mnt/backup/pi_projects/
Make the script check that /mnt/backup is mounted and write logs with timestamps.
Step 3 — Schedule and verify
Add a cron entry for midnight, then inspect the resulting log after the first run. Perform a restore from both the image and the rsync copy to confirm completeness.
Verification checklist
  • Destination mounted and writable.
  • Rsync dry-run succeeds.
  • Log file contains success lines and no errors.
  • Restore test boots and runs as expected.
