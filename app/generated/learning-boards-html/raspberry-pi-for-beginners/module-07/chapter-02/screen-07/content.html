Process Flow › File-level backups with rsync
Rsync essentials

Use rsync to copy changed files, preserve permissions, and optionally compress for network transfers. It’s efficient for nightly backups or synchronizing a development folder.

Key options to know
  • -a archive mode to preserve attributes.
  • -v verbose so you can see progress.
  • -z compress over network transfers.
  • --delete remove files from the backup that no longer exist on the source.
Common mistake
Using --delete without testing can remove files unintentionally. Always test with a dry run first.
Example command (visual)
# Back up a home directory to a mounted backup folder
# rsync -avz --delete /home/alex/ /mnt/backup/pi_home/
Tip: the trailing slash on the source copies contents of the directory. Omit it to copy the directory itself.
Protection strategy
Run rsync with --dry-run first to confirm actions. Keep a short history or dated folders to recover unintended deletions.
