Five-day plan (process)
Day 1
Set up Pi, test each sensor, print terminal values to confirm wiring and readings.
Day 2
Integrate display and format output so values update cleanly.
Day 3
Implement CSV logging and MQTT publishing for persistence and networking.
Day 4
Build Flask dashboard and alert logic to notify when thresholds are exceeded.
Day 5
Add auto-start, assemble enclosure, test thoroughly, and document everything.
Checkpoints
  • CSV file grows with timestamped rows.
  • MQTT messages are visible to a subscriber.
  • Dashboard reachable from another device.
  • Alert triggers at configured threshold.
