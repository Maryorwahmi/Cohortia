Module 8 › Chapter 7.4 › Alert Logic
Implementation steps
  1. Define a user-set threshold in config or UI.
  2. Compare latest temperature to threshold on each read.
  3. Set GPIO output high when above threshold, low when below with hysteresis.
  4. Use proper current limiting, relay modules, or drivers for safety.
Testing checklist
  • Confirm LED lights at the configured threshold.
  • Verify relay and fan, if used, engage safely.
  • Show hysteresis prevents rapid toggling around the threshold.
Caution
Never drive high-current devices directly from a GPIO pin; use a relay module or transistor driver and document wiring clearly.
