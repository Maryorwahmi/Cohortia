Core loop pattern
  1. Import sensor and CSV libraries and set constants for pins and file path.
  2. Read sensor value, check for valid result, retry if necessary.
  3. Build a timestamped row and append to CSV safely.
  4. Publish or update the display with a formatted value.
  5. Sleep for the configured interval and repeat.
Concrete example
A DHT22 read_retry followed by appending timestamp and numeric value to temperature_log.csv ensures persistent storage for later analysis.
