Module 8 › Chapter 7.4 › Auto-start
Use systemd
Write a service unit with ExecStart pointing to your monitoring script, set Restart=on-failure, enable it with systemctl enable, and check logs with journalctl -u yourservice.
Alternative: cron @reboot
A cron @reboot entry may be acceptable for simple demos but lacks automatic restart and richer logging compared to systemd.
Key Takeaway
Prefer systemd for a robust auto-start solution and document the service file and enable steps for grading.
