Essential checks
  • Sensors produce readable values.
  • Display updates cleanly without flicker.
  • CSV file appends timestamped rows correctly.
  • MQTT messages received by a subscriber.
Deployment & docs
  • Flask dashboard accessible from another device.
  • Alert activates at configured threshold.
  • README, wiring diagram, and backup instructions included.
Key Takeaway
Prepare a short demo that proves every checklist item with reproducible steps for the grader.
