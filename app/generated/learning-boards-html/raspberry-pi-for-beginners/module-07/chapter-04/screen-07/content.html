Module 8 › Chapter 7.4 › Data Flows
Architecture overview
Sensor Input
DHT22 for temperature & humidity; LDR or digital light sensor for light levels. ADC required for analog LDR.
Processing Script
Reads sensors on schedule, validates values, updates outputs, and handles errors without crashing.
Outputs
Local display, CSV file, MQTT topics, and a Flask web page for network access.
Alerts & Deployment
GPIO alert LED or relay and auto-start via systemd/cron to keep the service running after reboot.
Test scenario
Trigger a temperature rise and confirm: display updates, CSV new row, MQTT subscriber receives a message, and Flask page shows the new value.
Key Takeaway
Design for redundancy: multiple outputs protect data availability and support different use cases.
