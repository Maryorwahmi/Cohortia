Module 8 › Chapter 7.4 › Flask Dashboard
Design choices
  • Write latest readings to a small JSON or shared cache for the Flask app to read.
  • Host with host='0.0.0.0' so devices on the network can access the page.
  • Keep the UI minimal: timestamp, temp, humidity, light, and an update control.
Test & demonstrate
From another device, open the Pi's IP address and verify the page shows the latest reading. Document the URL and access steps in your README for grading.
Key Takeaway
A lightweight Flask page with reliable shared data is enough; ensure it is reachable and documented for assessment.
