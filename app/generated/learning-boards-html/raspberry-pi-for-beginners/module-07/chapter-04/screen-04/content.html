Module 8 › Chapter 7.4 › Project Requirements
Definition
The brief defines exact responsibilities your station must meet to pass assessment.
Sampling intervals
Temperature & humidity: every 5s. Light: every 10s.
Outputs
Local display, CSV log file, MQTT topics, and a Flask web page that shows latest values.
Reliability
Auto-start at boot via systemd or cron and documented wiring and backup instructions.
Why it matters
  • Timely sampling keeps data useful for automation and monitoring.
  • Multiple outputs (display, CSV, MQTT, web) give redundancy and accessibility.
  • Auto-start and documentation make the project reproducible and grade-ready.
Key Takeaway

Define measurable behaviors and verify each: sampling, display, logging, publishing, web access, alerts, and auto-start.
