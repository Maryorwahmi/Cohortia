Module 5 › Chapter 5.4 › Servo motors: wires, ranges, and PWM
Three-wire servo
Power
Provides motor current; often 5V for hobby servos. Use a supply sized for the servo's stall current.
Ground
Common reference. Tie servo ground to the Pi ground so the signal has the correct reference voltage.
Signal
PWM pulses from a GPIO pin tell the servo what angle to hold. Use gpiozero's Servo class for control.
Concrete wiring example
Connect servo power to a 5V supply capable of the servo's current, tie grounds together, and attach the signal wire to GPIO 17 if it supports PWM on your Pi model. After wiring, run a short sweep script to confirm movement.
Common mistake
Using the Pi's 5V pin for high-current servos can cause browning out or damage. If the servo draws significant current, use a dedicated supply and test at low load first.
Try this
Label the three servo wires on a real model and trace where each connects in your circuit. Confirm your supplies and common ground before powering up.
