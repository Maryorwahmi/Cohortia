Module 5 › Chapter 5.4 › Positioning a servo with gpiozero
Code example
from gpiozero import Servo
from time import sleep

servo = Servo(17)

servo.min()
sleep(1)
servo.mid()
sleep(1)
servo.max()
sleep(1)
servo.detach()
This sequence moves to min, mid, and max with pauses to let the servo reach each position, then detaches to stop holding current.
Explanation
  • Create a Servo bound to a GPIO pin that supports PWM.
  • Call min, mid, and max to move the horn; include sleep so movement completes.
  • Detach to let the servo stop holding position and reduce current draw.
  • Use a separate power supply if the servo draws more current than the Pi can safely deliver.
Common mistake

Not allowing time between commands can yield abrupt movement or incomplete travel. Pause so the servo reaches each target.
