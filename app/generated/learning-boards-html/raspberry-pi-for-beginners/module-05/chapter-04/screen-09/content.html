Driver domains
  • Logic inputs: GPIO pins that set direction and enable.
  • Motor power: separate V+ that supplies motor current.
  • Motor outputs: the terminals that feed the motor coils.
Power-up checklist
Power off → wire motor supply → tie grounds → attach GPIOs → power logic then motor → test at low speed.
Common mistakes and fixes
Missing common ground
Fix: Tie driver ground and Pi ground to ensure logic signals reference the same 0V.
Loose power terminals
Fix: Secure screws and test connections under low load before full operation.
Incorrect PWM pin
Fix: Use a PWM-capable GPIO for speed control and verify gpiozero accepts that pin for PWM output.
