Module 5 › Chapter 5.4 › Driving a DC motor with gpiozero Motor
Code example
from gpiozero import Motor
from time import sleep

motor = Motor(forward=17, backward=18)

motor.forward(speed=0.5)
sleep(2)
motor.stop()
This uses two GPIOs for direction and PWM for speed. The actual motor current flows through the driver, not the Pi.
Practical notes
  • Bind forward/backward to driver logic pins, and use a PWM-capable GPIO for the enable line if required.
  • Start at low speed to confirm wiring and power stability before raising the duty cycle.
  • Monitor motor and driver temperature during extended runs and verify the power supply handles peaks.
Key Takeaway

Control speed with PWM through the driver; the Pi sends logic only. Never route motor current through GPIO pins.
