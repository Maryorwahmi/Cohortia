Module 5 › Chapter 5.5 › SPI Fundamentals
Definition

SPI uses separate data lines and chip selects

MOSI carries master-to-slave data, MISO slave-to-master, SCLK is the clock, and CE lines select devices.

Pi pin mapping
MOSI = GPIO 10, MISO = GPIO 9, SCLK = GPIO 11, CE0 = GPIO 8, CE1 = GPIO 7.
Common devices
ADC chips, faster displays, and some radio or sensor modules that require higher throughput.
Comparison & Takeaway
SPI is chosen for speed. You trade extra chip select lines for higher transfer rates. Share MOSI/MISO/SCLK across devices but give each device its own CE or equivalent. If your project needs several high-bandwidth devices, plan for available CE pins or use GPIO expanders for selects.
Key Takeaway

SPI gives speed at the cost of chip-select wiring; plan selects when connecting many devices.
