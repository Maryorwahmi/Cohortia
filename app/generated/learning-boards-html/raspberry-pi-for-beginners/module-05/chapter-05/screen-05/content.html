Module 5 › Chapter 5.5 › i2cdetect & Addresses
Process

Scan, interpret, and fix

  1. Enable I2C with the configuration tool, then reboot if required to expose the bus.
  2. Run the detection utility to list responding addresses so you can confirm devices are connected.
  3. If an expected device is missing, check power, ground, SDA, and SCL wiring and try again.
  4. If two devices respond at the same address, look for hardware address jumpers or move one device to another bus or use different hardware.
Example & Takeaway
Imagine two temperature sensors on the same bus with the same fixed address. They will both try to answer and the master can’t distinguish them. The practical fix is to use a device with configurable address or place the second sensor on a different bus or module that provides address lines.
Key Takeaway

Always detect addresses after wiring and resolve collisions before coding higher-level communication.
