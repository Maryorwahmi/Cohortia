Skills & Quick Checks
Enable Interfaces
Use raspi-config to turn on I2C and SPI. This ensures the kernel exposes the buses for user space tools.
Discover I2C Devices
Run the detection command to confirm addresses and prevent collisions on the shared bus.
Verify SPI Wiring
Confirm MOSI, MISO, SCLK, and a CE pin, then read from an ADC to verify data lines are correct.
Prepare UART
Disable the serial console if you need TX/RX for a GPS or GSM module, and match baud rates when connecting.
