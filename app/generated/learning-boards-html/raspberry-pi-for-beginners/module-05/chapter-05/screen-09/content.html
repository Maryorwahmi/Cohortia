Module 5 › Chapter 5.5 › UART Fundamentals
Definition

UART is a two-wire asynchronous serial link

TX is transmit and RX is receive. Both ends must use the same baud rate to communicate correctly.

Pi pin mapping
GPIO 14 = TX, GPIO 15 = RX. These pins may be used by the serial console by default.
Use cases & tip
UART suits GPS and modem modules and simple console connections. If connecting an Arduino or GPS, match baud rates and wire the Pi TX to the device RX and Pi RX to the device TX. Disable the console if the pins must be used exclusively by your peripheral.
Misconception
UART is not a shared bus like I2C; it creates a single link between two devices, and cannot easily support multiple devices on the same pair of wires.
