Learning Objectives

Four practical goals to guide your work with I2C, SPI, and UART.

Bloom: Learn → Understand → Apply → Master
01
Enable and use I2C, SPI, UART

Enable interfaces with the Pi configuration tool and verify connections before communicating with devices. VERIFIED COMPETENCY MILESTONE

02
Explain protocol differences

Describe why I2C uses addresses, why SPI uses chip selects, and where UART fits. VERIFIED COMPETENCY MILESTONE

03
Connect I2C sensors and displays

Wire SDA and SCL and confirm addresses to avoid conflicts on the shared bus. VERIFIED COMPETENCY MILESTONE

04
Use SPI for speed, UART for serial modules

Select SPI for ADCs or fast displays, and use UART where a single serial link is expected. VERIFIED COMPETENCY MILESTONE
