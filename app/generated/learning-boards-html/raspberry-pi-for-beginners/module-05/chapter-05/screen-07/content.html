Module 5 › Chapter 5.5 › SPI: Chip Selects
Step-by-step
  1. Plan CE lines: choose CE0, CE1 or spare GPIOs for additional devices.
  2. Wire MOSI, MISO, and SCLK to all devices in parallel.
  3. Wire each device’s CE to a dedicated GPIO on the master and label them.
  4. Test one device at a time and confirm MISO is driven only by the active slave.
Example scenario
You have an ADC and a small display on SPI. Use CE0 for the ADC and CE1 for the display. Activate CE0 only when reading the ADC and CE1 when updating the display. If either device uses an active-low select, invert your GPIO logic accordingly in software.
Common mistake
Tying select lines together will make multiple devices respond at once and corrupt the bus.
