Module 5 › Chapter 5.5 › Key Concepts
I2C
SDA and SCL, multi-device via addresses.
SPI
MOSI/MISO/SCLK plus chip select per device for speed.
UART
TX and RX for point-to-point serial; match baud rates.
Final tip
Enable the appropriate interfaces with the Pi configuration tool, verify wiring and power, and test devices individually before integrating them into a larger program.
