Module 5 › Chapter 5.5 › I2C Fundamentals
Definition

I2C is a two-wire shared bus

SDA carries data and SCL carries a clock. Devices have 7-bit addresses and share the lines.

Pins on Raspberry Pi
GPIO 2 = SDA, GPIO 3 = SCL
Common devices
OLED and LCD displays, temperature sensors, real-time clocks, Sense HAT.
Key Takeaway

I2C saves pins by sharing two lines; avoid address clashes and verify devices before use.

Annotated Example
How addressing works
Each device listens for its unique address; the master starts a transaction and the addressed device responds. If two devices share the same address, neither works reliably.
Diagnostic check
Use the detection command to list addresses and confirm devices are present before coding higher-level interfaces.
Common mistake
Connecting power or ground incorrectly, or assuming all modules use the same address without checking.
Pro tip
Label SDA and SCL on your wires and use short runs to reduce noise for reliable communication.
