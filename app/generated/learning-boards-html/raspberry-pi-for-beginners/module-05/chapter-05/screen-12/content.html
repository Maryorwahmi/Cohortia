Module 5 › Chapter 5.5 › Hands-on Activity
Project Plan

Read analog data with MCP3008 and show it on an I2C OLED

Step 1 – Prepare
Enable I2C and SPI with the configuration tool and reboot if required, then wire power and ground to all devices.
Step 2 – Wire devices
Connect OLED to SDA (GPIO2) and SCL (GPIO3). Connect MCP3008 to MOSI, MISO, SCLK, and CE. Ensure common ground.
Step 3 – Verify
Run the I2C detection command to confirm the display and test a simple SPI read to verify the ADC returns values.
Step 4 – Integrate
Write a small loop that reads the ADC channel and updates the OLED over I2C to display the measured value.
Key Takeaway

This lab shows how the Pi can use multiple interfaces at once and teaches verification steps to avoid common wiring and configuration errors.
