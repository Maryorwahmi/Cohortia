Module 5 › Chapter 5.5 › Enable Interfaces
Checklist
  • Open the configuration tool and select interfacing options.
  • Enable I2C to expose SDA and SCL to the system.
  • Enable SPI to expose MOSI, MISO, SCLK and CE lines.
  • If using UART for devices, disable the Pi serial console so TX/RX are free.
Why it matters
The configuration tool ensures kernel drivers and device nodes are created. If an interface is not enabled, user programs cannot access the hardware lines even if the wires are connected. Reboot when prompted and then run small detection or read tests to confirm functionality.
Key Takeaway

Enabling interfaces in software is the first step; confirm with a reboot and quick device checks before building your application.
