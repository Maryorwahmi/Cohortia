Module 5 › Chapter 5.5 › Protocol Comparison
I2C
Few pins, shared bus, multiple devices by address. Good for displays and many sensors when pin count is limited.
SPI
Higher speed, separate data lines, chip-select per device. Use for ADCs and fast displays.
UART
TX/RX pair for point-to-point serial. Ideal for GPS, GSM, and simple serial consoles; match baud rates.
Decision rule
List device interfaces, map required speed and available pins, and prefer I2C for many low-speed peripherals, SPI for speed, and UART for single serial modules.
