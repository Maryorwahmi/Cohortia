Module 5 › Chapter 5.5 › Pin Mapping
I2C
SDA = GPIO 2
SCL = GPIO 3
SPI
MOSI = GPIO 10
MISO = GPIO 9
SCLK = GPIO 11
CE0 = GPIO 8, CE1 = GPIO 7
UART
TX = GPIO 14
RX = GPIO 15
Practical note
Always confirm power and ground, and use the default mappings for standard tutorials. If a project requires alternate pin functions, check the device and kernel documentation before remapping.
