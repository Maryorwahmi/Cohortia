Module 05 › Chapter 5.3 › SSD1306 OLED
What it does
A pixel-based display driven over I2C. Use luma.oled with Pillow to draw text at coordinates and simple shapes like bars.
Typical pattern
Create an I2C serial with port and address, instantiate device, then draw within a canvas context to render text and shapes.
Example
Open a canvas and write "Hello, OLED!" and a second line with a temperature. Map humidity percent to a rectangle width for a small bar graph.
Pro Tip

Throttle redraws and only update when values change to reduce flicker and CPU load.

Key Takeaway

SSD1306 with luma.oled gives flexible pixel drawing; manage redraw frequency and coordinate placement carefully.
