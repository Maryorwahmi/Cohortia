Module 05 › Chapter 5.3 › Formatting Sensor Data
Control precision
Use formatted strings to limit decimals so numbers are quick to read, for example one decimal for temperature when appropriate.
Padding and clearing
Clear the line before writing or use a fixed-width formatted string padded with spaces to avoid leftover characters on character LCDs.
Update strategy
Only update on meaningful value changes or at a modest rate, for example every two seconds, to reduce flicker and CPU use.
Key Takeaway

Readable displays need controlled precision, careful clearing, and sensible refresh intervals.

Concrete example
Compare last and new readings and only redraw if the change exceeds a small threshold. Format numbers with a fixed precision and pad strings when writing to a fixed-width character display.
