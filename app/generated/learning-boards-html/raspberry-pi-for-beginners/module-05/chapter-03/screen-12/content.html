Module 05 › Chapter 5.3 › OLED Bar Graph
Transition checklist
  • Find the OLED address with the detector, often 0x3C.
  • Install luma.oled and Pillow and create an I2C serial for the address.
  • Instantiate the SSD1306 device and draw within a canvas using text and rectangle primitives.
Bar mapping
Map humidity percent to pixel width. For example, percent divided by 100 times available pixel width yields the rectangle width for a filled bar.
Example
Draw "Temp: 23.5 C" and below it a humidity bar scaled to percent. Use a left margin and a thin border for clarity.
Key Takeaway

A single rectangle scaled to percent creates an effective mini bar graph for OLED displays.
