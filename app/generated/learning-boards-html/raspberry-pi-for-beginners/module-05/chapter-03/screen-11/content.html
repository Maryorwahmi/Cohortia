Module 05 › Chapter 5.3 › Activity: 16x2 with DHT22
Steps
  • Wire VCC, GND, SDA, SCL between Pi and I2C backpack; enable I2C and detect the address.
  • Install and import an LCD library and a DHT library for sensor reads.
  • In a loop, read sensor, format values to chosen precision, and display them. Update every two seconds or on meaningful change.
  • Clear or pad lines to avoid leftover characters when values shorten.
Example output
Line one: "Room" — Line two: "23.5 C" formatted to one decimal place and updated every two seconds.
Key Takeaway

A simple activity shows wiring, detection, formatting, and cadence—core display skills for many Pi projects.
