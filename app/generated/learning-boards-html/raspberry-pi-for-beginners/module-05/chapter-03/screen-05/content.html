Module 05 › Chapter 5.3 › Enable I2C
Step-by-step
  1. Open the Raspberry Pi configuration tool and choose Interface Options.
  2. Select I2C and enable it, then reboot the Pi to load I2C modules.
  3. Install the I2C tools package if missing.
  4. Run the detector on bus one and note addresses shown, e.g., 27 or 3C.
Remember: if no addresses appear, check wiring and the enabled state in the config tool before troubleshooting code.
Detector output
The detector prints a grid. A number like 27 indicates a device at 0x27. Use that address when creating device objects in Python.
Pro Tip

If you have multiple devices, label each by address before coding so you can avoid address conflicts on the bus.

Pitfall

Forgetting to reboot after enabling I2C or using the wrong bus number will make the detector show no devices.
