Module 05 › Chapter 5.3 › i2cdetect Output
What the grid shows
Hex addresses for devices that responded on the I2C bus; for example 27 corresponds to 0x27.
Assessment question
You see 27 in the detector output. What does it mean? Answer: a device is present at address 0x27; use it in your code when creating the display object.
Troubleshooting hints
  • Enable I2C and reboot before running the detector.
  • Verify wiring and bus number if no devices show.
  • Re-run after changes to confirm the device still appears.
