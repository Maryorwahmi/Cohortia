Module 05 › Chapter 5.3 › Character LCDs
Definition
Fixed character cells arranged in rows and columns. Controlled via parallel pins or an I2C backpack.
Sizes to expect
16×2 for simple status lines; 20×4 for longer menus and more lines of data.
I2C backpack role
Translates I2C commands to the LCD's parallel interface, letting you use SDA and SCL instead of many GPIO lines.
Common misconception
The backpack simplifies wiring but does not change how characters are stored or how cursor addressing works.
Example
Display two lines: device name on line one, and a formatted temperature on line two. Use the cursor to place values precisely and clear trailing characters when updating shorter values.
Key Takeaway

I2C backpacks make wiring simple; you still manage line lengths and cursor updates to keep text clean.

Common Mistake

Writing a shorter string over a longer one without clearing leaves stray characters; always clear or pad lines before updating.
