Module 05 › Chapter 5.3 › LCD vs OLED
Character LCD
  • Best for stable textual menus and status lines.
  • Simple API usage for writing fixed rows of text.
  • Requires cursor and clearing logic when updating values.
Example: 16×2 showing "Room" and "23.5 C" as two lines.
SSD1306 OLED
  • Pixel-based; supports text and simple graphics via Pillow rendering.
  • Good for tiny bar graphs, icons, or more flexible layouts.
  • Redraw strategy affects perceived flicker; throttle updates.
Example: OLED renders "Temp: 23.5 C" and a horizontal humidity bar at 60% width.
Key Takeaway

Pick character LCDs for simple text and OLEDs for small graphics; match update strategy to the display type to avoid flicker.
