Module 05 › Chapter 5.3 › LCD Libraries
Code Walkthrough (concept)
Typical pattern: create object, write text to a line, pause, and clear when appropriate.
Example (illustrative)
Instantiate an LCD object, write a label on line one and a formatted value on line two, sleep briefly, then clear. Test first with the correct I2C address.
rpi_lcd
Minimal API focused on writing lines and clearing; good for status displays.
lcd1602 / others
Offer cursor control, custom characters, and backlight management; check arguments for I2C address handling.
Pro Tip

Try a small example first to confirm addressing and whether the library auto-clears lines.

Key Takeaway

Library differences matter; match the library's API to your needs and test hardware addresses.
