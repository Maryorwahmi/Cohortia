Module 05 › Chapter 5.3 › Quick Reference
Detect address
Run i2cdetect and use the hex address it shows when instantiating libraries.
Match display
Choose character LCD for text, SSD1306 OLED for small graphics and bar displays.
Format & update
Limit decimals, clear or pad, and refresh only when necessary to avoid flicker.
Short checklist

Enable I2C → run detector → test simple write → format values → throttle updates.
