Displays: Character LCD and OLED
Connect by I2C, detect addresses, and format readable sensor output.
Character LCDs
16x2 or 20x4 text blocks; often use an I2C backpack to save pins.
SSD1306 OLED
Monochrome pixel display; supports text, shapes, and small graphs via SSD1306 driver.
I2C Wiring
VCC, GND, SDA, SCL. Use i2cdetect to confirm connected addresses like 0x27 or 0x3C.

I2C Backpack
Reduces parallel pins to SDA and SCL for simpler wiring.
Common addresses include 0x27, 0x3F for character LCD backpacks and 0x3C for many SSD1306 OLEDs. Detect before you code.
Key Takeaway

Enable I2C, detect addresses, then pick the right library and format output to keep displays clear and readable.
