Module 6 › Chapter 5.6 › Connector Orientation
Procedure

Seat the CSI flex cable correctly

  1. Power down the Raspberry Pi before connecting hardware when possible.
  2. Lift the small connector latch on the CSI socket gently.
  3. Insert the camera flex cable fully, with the exposed conductor side facing the board contacts.
  4. Close the latch to clamp the cable and secure the module in place.
  5. Fasten the module so the cable is not strained during use.
Common mistakes
  • Rotating the cable 180 degrees so conductors face away from the contacts.
  • Leaving the latch open or only partially closed.
  • Allowing cable strain that loosens the connector over time.
Pro tip
If the camera isn’t detected after boot, power down, reseat the cable, and try again before changing software settings.
