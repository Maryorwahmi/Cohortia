Module 6 › Chapter 5.6 › Hands-on Activity
Activity steps
  1. Attach and orient the camera flex cable, enable the camera in raspi-config, and reboot.
  2. Create a script that starts Picamera2 and waits for a gpiozero Button press to call capture_file.
  3. Run the script, press the button, and confirm the saved photo appears on disk with a unique name.
  4. Optional: if OpenCV is installed, capture a frame, detect faces, draw rectangles, and save the annotated image.
Example goal
A button-activated camera that saves timestamped images and optionally marks faces.
Common mistake
Overwriting files — add timestamps and simple rotation to manage storage.
Key Takeaway

Build step by step: hardware, simple capture, then detection. Each step verifies the previous one.
