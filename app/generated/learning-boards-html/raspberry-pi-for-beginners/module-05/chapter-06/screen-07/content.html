Module 6 › Chapter 5.6 › Capture a Still Image
Example

Minimal picamera2 still capture

from picamera2 import Picamera2
from time import sleep

camera = Picamera2()
camera.start()
sleep(2)  # allow time for auto exposure
camera.capture_file("image.jpg")
camera.stop()
print("Image saved")
Run this script to produce image.jpg. If the photo looks too dark or bright, increase the warmup delay and check lighting. This quick test proves the capture pipeline works.
Notes & takeaways
  • Sleep for a couple seconds to allow auto exposure to settle.
  • Use the saved image as a baseline before adding OpenCV processing.
  • If you see errors, verify camera enabled in raspi-config and cable seating.
Key Takeaway

A short exposure warmup produces reliable saved images; use this minimal script as a first functional test.
