Raspberry Pi Camera Module

Install the official camera, enable the OS interface, and capture images and video with picamera2. Add OpenCV overlays for detection and use a PIR sensor to trigger captures.

Variants

Capture
Still images and video using the picamera2 library
Vision
OpenCV for face detection, color tracking, and motion snapshots
Why this chapter matters

A camera adds visual sensing to Raspberry Pi projects. Knowing how to wire it correctly, enable the interface, and use picamera2 plus OpenCV opens many simple IoT and robotics experiments without complex cloud services.
