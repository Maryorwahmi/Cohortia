Module 6 › Chapter 5.6 › Motion-triggered Camera
Example code
import cv2
from picamera2 import Picamera2
from gpiozero import MotionSensor

pir = MotionSensor(18)
camera = Picamera2()
camera.start()

while True:
    pir.wait_for_motion()
    frame = camera.capture_array()
    cv2.imwrite("motion.jpg", frame)
    print("Motion captured")
    pir.wait_for_no_motion()
This loop waits for motion, saves a snapshot, and waits for motion to stop before continuing. Add timestamps to filenames in a real project.
Setup tips
  • Place the PIR sensor with a clear view of the monitored area.
  • Test sensitivity and cooldown to avoid rapid false triggers.
  • Use timestamped filenames and file rotation to manage storage.
Common mistake

Saving large uncompressed images on every trigger can quickly exhaust storage; plan filenames and rotation.
