Module 6 › Chapter 5.6 › Face Detection
Procedure

Detect faces and draw overlays

Capture a frame, run a face detection routine on the array to return bounding boxes, then draw rectangles on the original frame so you can visually confirm detections. Save annotated images for debugging or stream them to a display when testing in real time.
Concrete example steps
  1. Capture a frame with camera.capture_array().
  2. Run the detector to obtain face coordinates.
  3. Use drawing routines to add rectangles to the frame.
  4. Save with cv2.imwrite for review.
Misconceptions
Detection quality depends on lighting, scale, and model accuracy — it is not guaranteed in poor conditions.
Key Takeaway

Annotated frames provide immediate feedback for tuning detection; start by testing in the lighting where your system will run.
