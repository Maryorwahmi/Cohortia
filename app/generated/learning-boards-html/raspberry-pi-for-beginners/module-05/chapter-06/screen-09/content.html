Module 6 › Chapter 5.6 › OpenCV Integration
Pipeline

How frames move through your code

Capture
camera.capture_array() returns an image array to Python.
Process
Use OpenCV functions to analyze or detect features.
Output
Save images, draw overlays, or trigger actions based on detections.
Installation
sudo apt install python3-opencv
This provides the cv2 module used for detection and drawing overlays.
Concrete example
Capture a frame, run a detection routine to find faces or colors, draw rectangles on the frame, then save with cv2.imwrite.
Misconception

OpenCV won’t capture images itself in this setup; you explicitly pass the camera’s frame array into OpenCV functions.
