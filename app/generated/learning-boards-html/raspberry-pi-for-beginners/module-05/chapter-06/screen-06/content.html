Module 6 › Chapter 5.6 › Enable Camera
Definition

Enable camera via raspi-config

Use raspi-config Interface Options to enable the camera interface. Reboot after enabling so the kernel loads the proper support.

Why this step
Registers the CSI camera with the OS and prepares drivers.
Quick test
Run a capture script after reboot to confirm functionality.
Legacy note
Older systems used the legacy picamera library; Bookworm+ favors picamera2.
Common mistake

Forgetting to reboot after enabling the interface or assuming drivers will load without a restart.
