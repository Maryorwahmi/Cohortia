Definition

DHT11 vs DHT22

Choose the sensor according to budget and required accuracy. Both require timing-aware reads via libraries.

DHT11

Lower cost, temperature accuracy around ±2°C and humidity around ±5 percent. Good for simple projects where rough values are acceptable.

DHT22

Higher accuracy and wider measurement range. Use when you need tighter readings and more reliable data in varied conditions.

Key Takeaway

Pick DHT22 for accuracy and range. Use a DHT-aware library and always validate readings before use.

Concrete Example
Python example (visual only)
humidity, temperature = Adafruit_DHT.read_retry(sensor, pin)
if humidity is not None and temperature is not None:
    print a formatted temperature and humidity
else:
    print a failed read message
Misconception

Believing that a single DHT read always succeeds. In practice timing issues or electrical noise can return invalid readings, so implement checks and retries.

Practical tip: if you move to the adafruit circuitpython dht library ensure that required system packages are installed on recent Raspberry Pi OS releases. Test reads in the terminal before integrating into larger scripts.
