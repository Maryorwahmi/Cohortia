Learning Objectives

Four practical skills you will practise in terminal-driven examples.

Bloom: Learn → Understand → Apply → Master
01
Read DHT11 / DHT22

Learn the single-wire protocol and use recommended libraries to collect temperature and humidity. Practice retry logic so failed reads do not crash your program.

VERIFIED COMPETENCY MILESTONE
02
Measure light with LDR

Construct a voltage divider with a 10k resistor, feed the junction to an MCP3008 ADC, and map ADC values to a percentage for usable readings.

VERIFIED COMPETENCY MILESTONE
03
Detect motion with PIR

Wire a PIR to a GPIO pin, use event-driven handlers to respond to motion, and adjust sensitivity or hold time using the sensor's potentiometers.

VERIFIED COMPETENCY MILESTONE
04
Calibrate and handle errors

Record min and max ADC values for lighting conditions, check for None or invalid readings from DHT sensors, and retry or fall back to safe defaults.

VERIFIED COMPETENCY MILESTONE
