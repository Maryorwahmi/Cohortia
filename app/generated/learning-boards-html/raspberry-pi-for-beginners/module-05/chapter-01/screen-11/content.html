Calibration and Error Handling Checklist
DHT
  • Use read retry helpers.
  • Check for None and log failures.
  • Delay between retries to prevent timing conflicts.
LDR
  • Record min and max ADC values in situ.
  • Map raw counts to percent and clamp results.
  • Persist calibration values to a file.
PIR
  • Adjust sensitivity and hold time with potentiometers.
  • Validate with test walks at various distances.
  • Prefer event handlers to polling.
Example troubleshooting step

If DHT reads fail intermittently, verify wiring and avoid sharing the data pin with other devices. Add logging to capture when failures occur to look for patterns linked to temperature, timing, or CPU load.
