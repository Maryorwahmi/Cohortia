Common Failures and Fixes
DHT returns None
  1. Check wiring and 3.3V supply.
  2. Use a DHT-aware library and retries.
  3. Avoid multiple reads from different threads.
ADC stuck at 0 or full
  • Verify MCP3008 power and ground and that SPI is enabled.
  • Confirm channel wiring and junction connection.
PIR false triggers
  • Adjust sensitivity pot and time delay pot.
  • Test in actual installation environment to tune settings.
Logging tip

Record timestamps, raw readings, and event messages so you can correlate failures with actions or environmental changes and iterate on fixes faster.
