Definition

How PIR detects motion

PIR looks for changes in infrared radiation. When movement changes the measured infrared pattern the sensor raises its output pin to HIGH.

Wiring checklist
  • VCC to 3.3V, GND to ground, data to a GPIO pin.
  • Ensure common ground and 3.3V compatibility.
Key Takeaway

Use event-based handlers and adjust sensitivity to avoid false positives from reflections or heat sources near the sensor.

Concrete Example
Motion detected! No motion
Potentiometer tips

If the sensor triggers too easily reduce sensitivity and check the time delay pot so the output does not remain HIGH longer than needed.

Testing in your space is essential. Walk at different distances and speeds to tune sensitivity and timeout for the use case you intend, whether it is an LED indicator or a security trigger.
