Module 5 › Chapter 5.1 › Key Concepts
Match signal type
Digital to GPIO, analog to ADC, timing-sensitive to dedicated libraries.
Calibrate
Record ADC baselines for LDRs and validate DHT values before using them.
Prefer events for PIR
Event-driven handlers are responsive and efficient compared with polling loops.
Takeaway

Design your hardware and code to match the sensor's signal type, calibrate in place, and handle failures gracefully for reliable projects.
