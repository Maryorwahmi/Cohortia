HC-SR04 pin roles
  • VCC — 5V power for the sensor electronics
  • Trig — driven by the Pi to start an ultrasonic burst (GPIO output)
  • Echo — goes high while waiting for the return; measures round-trip time
  • GND — common reference, must be shared with the Pi
Voltage divider
Use 1kΩ in series from Echo to Pi input and 2kΩ from input to ground to scale 5V → ≈3.3V.
Verification
After wiring, trigger once and confirm the input toggles and the steady voltage never exceeds ~3.3V.
Common mistakes
  • Wiring Echo directly to Pi input — risk of permanent damage.
  • Not sharing ground between Pi and sensor — readings become unreliable.
  • Long unshielded wires increasing noise and false echoes.
Example: resistor values
Selecting 1k and 2k gives a divider output of 5V * (2k / (1k + 2k)) = 3.33V. This is a safe level for Raspberry Pi GPIO pins.
Quick test
After powering, send one trigger pulse and observe a clean echo-high transition at the input using a simple script or logic monitor.
Key Takeaway
Protect your Pi: never accept 5V on GPIO. Use the divider pattern and shared ground for reliable communication.
