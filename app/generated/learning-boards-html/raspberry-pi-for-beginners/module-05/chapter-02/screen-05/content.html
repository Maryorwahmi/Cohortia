Step-by-step timing
  1. Set Trig low to settle the sensor, then send a 10 microsecond high pulse on Trig.
  2. Sensor emits ultrasonic burst and sets Echo high while waiting for the return.
  3. Measure when Echo goes high (start time) and when it goes low (end time).
  4. Compute pulse_duration = end - start, divide by two for one-way travel, and convert to centimeters using the speed of sound.
  5. Validate value: check expected range and optionally average samples.
Timeout handling
Always include a maximum wait for Echo transitions to avoid infinite loops when no echo returns.
Concrete example
If Echo stays high for 1500 microseconds, use the formula time times 0.034 centimeters per microsecond divided by two to get 25.5 centimeters, matching the assessment example provided in this chapter.
Misconception
Do not forget to divide the round-trip time by two before converting; otherwise distance will be twice what it should be.
Key Takeaway
Accurate start and stop times and a timeout guard are essential for reliable distance calculations.
