Manual timing pattern
import RPi.GPIO as GPIO
import time

TRIG = 23
ECHO = 24

GPIO.setmode(GPIO.BCM)
GPIO.setup(TRIG, GPIO.OUT)
GPIO.setup(ECHO, GPIO.IN)

try:
    while True:
        GPIO.output(TRIG, False)
        time.sleep(0.05)
        GPIO.output(TRIG, True)
        time.sleep(0.00001)  # 10 microseconds
        GPIO.output(TRIG, False)

        while GPIO.input(ECHO) == 0:
            pulse_start = time.time()
        while GPIO.input(ECHO) == 1:
            pulse_end = time.time()

        pulse_duration = pulse_end - pulse_start
        distance = pulse_duration * 17150
        print(f"Distance: {distance:.1f} cm")
        time.sleep(1)
except KeyboardInterrupt:
    GPIO.cleanup()
The numeric factor 17150 comes from converting the speed of sound to centimeters and dividing by two for the round trip. Use this pattern to log raw durations for diagnostics.
Practical notes
  • Include maximum wait thresholds on the while loops to avoid blocking.
  • Use time.time for seconds; if you need higher resolution, consider time.perf_counter.
Gotcha
Missing a timeout will cause your script to hang if the sensor never sets Echo, so always plan for hardware failure modes.
Key Takeaway
Manual timing exposes the pulse durations you need to debug and tune sensor responses; treat timeouts as essential safeguards.
