Minimal gpiozero example
from gpiozero import DistanceSensor
from time import sleep

sensor = DistanceSensor(echo=24, trigger=23)

while True:
    print(f"Distance: {sensor.distance * 100:.1f} cm")
    sleep(1)
This class abstracts trigger/echo handling so you can focus on application logic like LEDs or a buzzer that reacts to the measured distance.
When to use gpiozero
  • Quick prototype or when you don't need microsecond control
  • Good for demonstration projects and classroom tasks
Limitations
If you need to measure pulse boundaries, or diagnose timing jitter, manual timing exposes the internal measurements you need for debugging.
Key Takeaway
Use gpiozero for speed and simplicity, then drop to manual timing if you must debug or tune performance.
