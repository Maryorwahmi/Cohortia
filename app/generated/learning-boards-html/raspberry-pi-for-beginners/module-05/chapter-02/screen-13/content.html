Module 5 › Chapter 5.2 › Key Concepts
Pins & Divider
VCC, Trig, Echo, GND. Use a 1k/2k divider so Echo never drives more than ≈3.3V into the Pi.
Timing & Formula
Send 10 μs trigger, measure echo duration, divide by two, multiply by 17150 to get centimeters.
Code & Reliability
Use gpiozero for speed, manual timing for debug. Add timeouts, bounds checks and median filtering to stabilize readings.
Summary
Protect the Pi, measure time carefully, and filter results for dependable distance sensing in projects like a parking sensor.
