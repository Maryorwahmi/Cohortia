Protect GPIO
Echo → 1k → Pi pin → 2k → GND.
Timing formula
Distance (cm) = pulse_duration (s) * 17150.
Validate
Timeouts + median/average + ruler checks at known distances.
Final tip
Start with gpiozero to confirm wiring, then use manual timing when you need to diagnose or tune behavior.
