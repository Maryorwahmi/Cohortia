Module 5 › Chapter 5.2 › Parking Sensor
Component roles
  • HC-SR04 — measures distance
  • Raspberry Pi — runs measurement logic and controls the buzzer
  • Buzzer — provides audible feedback; drive via transistor when current exceeds GPIO limits
Distance bands (example)
>150 cm: silent. 60–150 cm: slow beeps. 30–60 cm: medium beeps. <30 cm: fast or continuous beep.
Practical tips
  • Confirm the sensor readings before wiring the buzzer logic.
  • Debounce state transitions with repeated confirmations to avoid flicker.
Key Takeaway
A reliable parking sensor combines safe wiring, filtered measurements, and debounced control logic for a predictable user experience.
