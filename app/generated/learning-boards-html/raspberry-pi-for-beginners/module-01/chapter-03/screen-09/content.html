Module 1 › Chapter 1.3 › Headless vs Desktop
Desktop Operation
Includes keyboard, mouse, and monitor for interactive use and initial configuration.
Best for learning, graphical apps, or when local interaction is required.
Use during first boot to set up Wi‑Fi, locale, and user accounts if you are new to headless setup.
Headless Operation
Run without local peripherals and control the Pi remotely over SSH or VNC.
Best for servers, IoT, or when you want low power and small physical footprint.
Tip: configure remote access during initial desktop session or follow a documented headless setup to ensure network credentials are correct.
Key Takeaway

Use desktop for setup and learning; switch to headless for deployed, remote, or space-constrained projects.
