Learning Objectives
Learn, Understand, Apply, Master
01
Install Raspberry Pi OS
Use Raspberry Pi Imager to write the recommended OS image to a microSD card, ensuring the correct variant for your project. This gives you a reliable base system for desktop or headless use.
VERIFIED COMPETENCY MILESTONE
02
Preconfigure network and credentials
Set hostname, create a unique user and strong password, and enter Wi‑Fi and locale settings so the Pi can boot without manual input. This saves time and improves security.
VERIFIED COMPETENCY MILESTONE
03
Perform first boot and initial setup
Complete the setup wizard or verify headless startup via SSH, ensuring filesystem expansion and locale choices are correct. Confirm the OS version after login.
VERIFIED COMPETENCY MILESTONE
04
Use raspi-config for interfaces
Enable SSH, VNC, SPI, I2C, UART, and camera through raspi-config and understand when a reboot is required for changes to take effect.
VERIFIED COMPETENCY MILESTONE
