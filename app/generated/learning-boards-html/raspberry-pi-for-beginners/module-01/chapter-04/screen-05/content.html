Module 1 › Chapter 1.4 › Raspberry Pi Imager
Step-by-step
1. Install Imager and insert microSD
Use a USB card reader if needed and ensure the card is rated for your Pi's workload.
2. Choose Device and OS
Select the correct Raspberry Pi model and pick the recommended OS image variant.
3. Configure settings
Set hostname, username, password, Wi‑Fi, locale, and enable SSH if needed.
4. Write and verify
Start the write, wait for verification, then safely eject the card.
Visual Checklist
Preconfigure Wi‑Fi & SSH
Enables headless login; avoids connecting a monitor for first boot.
Set hostname and credentials
Use a descriptive hostname and a unique username for security and network clarity.
Common pitfall
Skipping preconfiguration leaves headless devices inaccessible until a monitor is attached.
Key Takeaway

Use Imager’s settings to automate hostname, credentials, Wi‑Fi, and SSH so the Pi starts ready for your workflow.
