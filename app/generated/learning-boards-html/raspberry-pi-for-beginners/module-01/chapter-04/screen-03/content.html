Learning Objectives — Practical Focus
Practice steps that save time and prevent common errors
Select the right OS image
Desktop provides a GUI; Lite is minimal for headless use. Choose based on whether you need a monitor or plan to SSH in.
VERIFIED COMPETENCY MILESTONE
Create credentials and hostname
Avoid legacy defaults by creating a unique username and strong password during preconfiguration for improved security and manageability.
VERIFIED COMPETENCY MILESTONE
Enable SSH and Wi‑Fi for headless boot
Supplying Wi‑Fi and SSH options in Imager prevents the need for direct input at first boot and allows remote access immediately after startup.
VERIFIED COMPETENCY MILESTONE
Use raspi-config for hardware interfaces
Enable interfaces like SPI, I2C, UART, and camera when you attach hardware; remember that many changes need a reboot to take effect.
