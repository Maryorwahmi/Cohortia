Module 1 › Chapter 1.4 › Hands-on Activity
Activity Steps
1. Select image and device
Pick Desktop or Lite and the correct Pi model in Imager.
2. Preconfigure settings
Set hostname, username, password, Wi‑Fi, locale, and enable SSH.
3. Write and verify
Wait for write and verification, then safely eject the card.
4. Boot and connect
Insert the card, power the Pi, then SSH or use the GUI to finish setup.
5. Verify OS
Run the system release command to confirm the installed OS variant and version.
Example check
SSH in and confirm the OS to validate the installation before proceeding to hardware projects.
If you fail to connect
Verify Wi‑Fi credentials, hostname, and SSH enablement in your Imager settings and rewrite if necessary.
