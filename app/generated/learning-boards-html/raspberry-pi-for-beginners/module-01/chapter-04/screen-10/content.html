SSH Walkthrough
Open a terminal on your computer. Connect to the Pi using the SSH command with the username and hostname you configured. Accept the fingerprint when prompted and enter your password to authenticate.
What to expect
Prompt to accept host fingerprint once, then a password prompt. After login, you have a shell to run commands and verify system details.
Key Takeaway

Use SSH to manage a headless Pi. Confirm the OS version after login to ensure the correct image was installed.

Example Command
ssh username@raspberrypi.local
After authenticating, run the command to show distribution release information and confirm the OS variant and version.
Security Note
Use strong passwords and consider SSH keys for ongoing deployments to reduce risk from password guessing.
