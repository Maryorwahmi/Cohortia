Module 1 › Chapter 1.4 › Write & Verify
Write Process
Imager downloads the OS image if needed, writes it to the selected microSD card, and verifies the written data. Do not interrupt these steps.
Start Write
Begin only after confirming device and OS selection.
Verify
Wait for verification to ensure integrity; progress bars may not reflect final verification completion.
Safe Eject
Use your OS eject or unmount action before removing the card to avoid corruption.
Example scenario
Start the write on your workstation and walk away; return when Imager shows completion and then safely eject the card.
Common mistake
Removing the card immediately after the progress bar reaches 100% can leave verification incomplete and create a non-bootable card.
Key Takeaway

Let Imager finish writing and verifying, then eject safely. Verification protects against corrupted installations.
