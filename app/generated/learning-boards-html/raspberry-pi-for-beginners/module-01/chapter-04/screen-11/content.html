Module 1 › Chapter 1.4 › VNC Remote Desktop
Enable VNC
Open a terminal on the Pi and run raspi-config. Under Interface Options, choose VNC and enable it. Reboot if prompted to apply the change.
After enabling
Connect using a VNC viewer with the Pi’s hostname or IP and authenticate with your credentials.
Security & Example
Example: enable VNC and connect via a viewer to raspberrypi.local after reboot. For security, prefer SSH tunnels or ensure your network is trusted when exposing VNC.
Common misconception
Turning on VNC does not automatically grant external access; network configuration and authentication still control access.
Key Takeaway

Enable VNC from raspi-config for GUI access, then secure connections and prefer tunnels for untrusted networks.
