Module 1 › Chapter 1.4 › OS Variants
Desktop
Includes GUI and recommended software
  • Good for users who plan to attach a monitor and use a desktop environment.
  • Includes applications that help you get started quickly.
  • Uses more storage and memory than Lite.
Example
Use Desktop 64‑bit for a graphical coding environment on a recent Pi model.
Lite
Minimal, no graphical interface
  • Ideal for headless servers, scripts, and small-footprint projects.
  • Saves storage and reduces background services.
  • Requires comfort with the command line.
Example
Choose Lite 32‑bit for a headless data logger that only needs SSH access.
32‑bit vs 64‑bit
32‑bit images are broadly compatible across Pi models. 64‑bit images can address more memory and may improve performance for certain workloads if the hardware supports it. Match bitness to hardware and software requirements.
When to pick Desktop
If you need a GUI and preinstalled apps.
When to pick Lite
If you operate headless or want minimal services.
Common mistake
Choosing Desktop for a server project increases overhead unnecessarily.
