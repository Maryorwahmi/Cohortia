What raspi-config Controls
Use it to enable hardware interfaces and change system-level settings such as hostname and locale. Access interface options to turn on SPI, I2C, UART, and the camera.
SPI
For SPI peripheral communication with certain sensors and displays.
I2C
Used by many sensors and small peripherals on a shared bus.
UART
Serial communication for modules and debug consoles.
Camera
Enable before using camera modules; reboot may be required.
Example
Enable the camera in raspi-config, then reboot before testing camera software so drivers initialize correctly.
Common mistake
Assuming enabled interfaces work instantly; many require a reboot to load modules and apply settings.
Key Takeaway

Use raspi-config to turn on needed interfaces and reboot when requested to ensure hardware is usable by software.
