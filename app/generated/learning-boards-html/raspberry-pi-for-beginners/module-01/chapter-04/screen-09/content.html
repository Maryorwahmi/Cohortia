What Happens on First Boot
The system expands the filesystem to use the entire microSD card and applies configuration tasks. If preconfiguration was provided, such as Wi‑Fi and SSH, the wizard may skip those prompts.
Filesystem Expand
Ensures the OS can use all available space on the card.
Setup Wizard
Guides locale choices and password setup if not preconfigured.
Headless Access
With Wi‑Fi and SSH prefilled, the Pi joins your network and is reachable remotely.
Example
Preconfigured Pi boots headless and accepts SSH under the configured username at the configured hostname.
Common misconception
Believing the setup wizard always requires manual input — it will skip prompts if you already provided values via Imager.
Key Takeaway

First boot readies the filesystem and applies configured options, enabling GUI or headless workflows depending on what you prepared.
