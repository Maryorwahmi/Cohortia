First Boot: Install Raspberry Pi OS and Complete Initial Setup
Prepare the microSD card, preconfigure Wi‑Fi and SSH, perform the first boot, and use raspi-config to enable hardware interfaces.
What you will learn
Install and preconfigure OS, boot the Pi, enable remote access, and use raspi-config for interfaces and localization.
Why it matters
A correct first boot and configuration avoids connection problems later and ensures hardware interfaces work when you need them.
In this lesson
Write Raspberry Pi OS with Imager, set hostname and credentials, enable SSH and Wi‑Fi for headless use, run first boot, and use raspi-config to enable interfaces.

Explore Key Topics
Three compact topics you will use throughout the course.
Raspberry Pi Imager — the easy tool that selects and writes the correct OS image and lets you preconfigure options.
Headless setup — prefill Wi‑Fi and enable SSH to avoid needing a monitor and keyboard at first boot.
raspi-config — the system utility to turn on hardware interfaces and change locale settings after boot.
