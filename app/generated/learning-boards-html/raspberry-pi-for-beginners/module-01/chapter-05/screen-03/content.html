Practice Tasks

Short actionable steps that reinforce each objective and build safe wiring habits.

Mark the Pinout

Print a pinout chart and label 3.3V, 5V, and at least one GND pin to avoid errors when connecting parts.

Measure Rails

Use a multimeter to measure 3.3V and 5V relative to ground before attaching components to confirm correct power behavior.

Confirm Numbering

Find physical pin 11 and verify it is GPIO 17 in BCM mode to practice mapping between BOARD and BCM systems.

Wire an LED

Connect an LED with a current‑limiting resistor to GPIO 18 (physical pin 12) and observe brightness control using PWM. Use a driver if the LED requires more current.

Key Takeaway

Small checks and one safe wiring project build confidence and reduce the risk of hardware damage.
