Module 2 › Chapter 1.5 › BOARD vs BCM Numbering
Definition

Two numbering systems

Understand which numbering is in use by code or tutorials to place wires on the correct physical pins.

BOARD numbering
Counts physical pins 1–40. Use when instructions explicitly say physical pin numbers or show a printed header layout.
BCM numbering
Uses the SoC’s GPIO identifiers such as GPIO 17. Libraries like gpiozero commonly default to BCM mode.
Quick conversion examples
  • Physical pin 11 → BCM GPIO 17
  • Physical pin 12 → BCM GPIO 18 (PWM capable)
  • Physical pins 3 and 5 → BCM GPIO 2 and 3 (I2C SDA and SCL)
Misconception
A tutorial saying "connect to pin 11" might mean physical 11 or BCM 11. Always check which numbering the tutorial or code expects.
Key Takeaway

Confirm BOARD vs BCM before wiring. When in doubt, consult the library default or pinout diagram.
