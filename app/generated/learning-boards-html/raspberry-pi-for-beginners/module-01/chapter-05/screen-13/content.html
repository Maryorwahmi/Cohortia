Module 2 › Chapter 1.5 › Assessment: Pinout Question and Wiring Task

Assessment prompt

A short question plus a practical wiring and coding task to validate skills.

Question
Which physical pin corresponds to GPIO 18, and what special feature does it provide?
Expected answer: physical pin 12 and hardware PWM support.
Task
Mark the pinout, wire an LED with a current‑limiting resistor to physical pin 12 and a GND pin, then write code to vary duty cycle and observe smooth brightness changes.
Common errors to check
  • Wiring to 5V instead of the GPIO pin
  • Not including a resistor with the LED
  • Using software PWM when hardware PWM is required for precision
Key Takeaway

A short question plus a hands‑on task verifies mapping, PWM understanding, and safe wiring practice.
