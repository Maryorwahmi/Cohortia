Module 2 › Chapter 1.5 › PWM: Hardware vs Software
Definition

What PWM does

Control perceived voltage or power by varying the duty cycle of a digital signal; used for dimming and speed control.

Hardware PWM pins
GPIO 12, 13, 18 and 19 provide hardware PWM for precise timing and lower CPU use.
Software PWM
Available on any GPIO but less precise and sensitive to CPU load.
Concrete example
To dim an LED with stable duty cycle, use GPIO 18 (physical pin 12) and a PWM class. For a one‑off blinking LED a software PWM on another GPIO will usually be sufficient but expect some jitter if the Pi is under heavy load.
Misconception
Assuming software PWM is as precise as hardware PWM. Use hardware pins for stable control.
Key Takeaway

Match your timing needs to hardware PWM when precision matters; use software PWM for simple or tolerant tasks.
