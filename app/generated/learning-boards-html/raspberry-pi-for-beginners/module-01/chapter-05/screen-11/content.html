Conceptual code walkthrough

You declare a device by BCM GPIO number, then control it via library objects. The library handles timing details but not electrical safety.

# conceptual example: create a PWM LED on BCM 18 (physical pin 12) pwm_led = PWMLED(18) pwm_led.value = 0.5 # half brightness (conceptual)
Note: this panel shows conceptual code only; confirm mapping and wiring before running code.
Practical points
  • Libraries commonly default to BCM numbering—verify before wiring.
  • PWM classes simplify brightness control but don’t change current limits.
  • Test with low current components first and use drivers for larger loads.
Key Takeaway

Match code’s numbering to your wiring and treat library abstractions as convenience, not a substitute for safe hardware design.
