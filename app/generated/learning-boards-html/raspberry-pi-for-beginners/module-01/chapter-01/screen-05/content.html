Module 1 › Chapter 1.1 › What is an SBC?
Definition

Single-board computer

A compact, integrated computer where CPU, memory, and I/O live on one printed circuit board.

Boots from SD card
Includes HDMI, USB, and network
Low power and cost
Limited upgradeability
Example
A Pi used as a classroom server boots Raspberry Pi OS from a card, provides network services, and stores student work locally or on attached storage.
Comparison snapshot
SBC
Compact, inexpensive, integrated components.
Desktop
Upgradeable, more powerful, and designed for sustained heavy use.
Misconception
Assuming SBCs are only for hobbyists. In reality, they power many useful, durable projects where low cost and size matter.
