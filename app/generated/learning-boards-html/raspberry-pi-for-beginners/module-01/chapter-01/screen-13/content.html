Module 1 › Chapter 1.1 › Classify Projects
Project 1 — Classroom coding server
Runs exercises, stores student files, and serves content. Classification: Pi as computer. Reason: needs OS, storage, and network services.
Project 2 — Battery temperature logger
Samples temperature every minute for months and stores data. Classification depends: if spreadsheet handling is required, Pi as computer; if ultra-low power is required, microcontroller as controller.
Project 3 — Robot with vision
Needs image processing and motor control. Classification: both. Reason: Pi handles vision and higher-level logic while controllers handle low-level motor timing.
Tips
  • Always check power and timing constraints.
  • Use both devices together when roles are complementary.
Assessment idea
Would you choose Arduino or Pi for a sensor that logs to a spreadsheet for six months? Expect: Raspberry Pi, because it can run an OS and store files easily.
