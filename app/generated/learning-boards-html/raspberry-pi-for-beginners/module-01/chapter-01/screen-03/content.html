Application exercises
Classify three sample projects and justify the choice
  • Project A: A classroom coding server hosting exercises for students — likely uses the Pi as a computer for networking and file storage.
  • Project B: A battery-powered temperature logger that wakes once per minute — better suited to a microcontroller unless local files and spreadsheets are required.
  • Project C: A robot that needs computer vision and motor control — the Pi can act as both a computer for vision and a controller for motors.

Decision checklist
Ask these questions: Do you need file storage or an OS? Do you need real-time, low-power sensing? Do you need network services or multimedia? Matching answers points you to a Pi, an Arduino, or both.
