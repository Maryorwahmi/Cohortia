Core definition

What the Raspberry Pi is

A low-cost single-board computer designed to run an operating system and support learning and making.

Origin and mission
Created to make computing affordable and to support education and hobbyist communities.
Concrete classroom example
Use a Pi as a low-cost lab machine for teaching networking and Python without full desktops.
Key Takeaway

The Pi is both an educational device and a capable small computer — treat it seriously, not just as a toy.

Definition visual
Single-board computer
One board includes CPU, memory, connectors, and ports so it functions like a standalone computer.
Misconception
Don't assume the Pi is only a toy. It runs a real OS and can handle many production-style tasks, though with limits on speed and RAM.
