Learning Objectives

Skills to demonstrate: comparison, specification understanding, model choice, and component identification.

Bloom: Learn → Understand → Apply → Master
01
Compare major models

Read CPU, RAM, ports and connectivity to decide what each model suits. Practically, compare Pi 5, Pi 4 and Zero for a media server versus a sensor node.

VERIFIED COMPETENCY MILESTONE
02
Understand specs & impact

Interpret CPU type, RAM amount, and ports to predict performance and power use. Example: more RAM supports multiple services or databases.

VERIFIED COMPETENCY MILESTONE
03
Choose the right model

Weigh budget, size, and power. For example, a small battery monitor favors Zero while a media server favors Pi 5 or Pi 4.

VERIFIED COMPETENCY MILESTONE
04
Identify board components

Locate the SoC, RAM, USB/Ethernet controller, microSD slot, camera and display connectors, and the 40-pin GPIO header.
