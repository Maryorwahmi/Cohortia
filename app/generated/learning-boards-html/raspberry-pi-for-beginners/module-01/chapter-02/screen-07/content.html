Module 1 › Chapter 1.2 › Pi 3 & Earlier
Definition

Pi 3 family and predecessors

Earlier models with quad-core Cortex-A53 CPUs, built-in Wi-Fi on later Pi 3 revisions, single HDMI output, and micro-USB power. Great for sensor nodes and automation.

Use case
Headless monitoring, local automation, and simple data logging where extensive memory and ports are not required.
Connectivity
Single HDMI, Ethernet on some boards, and built-in Wi-Fi on Pi 3 B+ variants.
Concrete example
Home automation hub

A Pi 3 can reliably run MQTT brokers, simple web dashboards, and sensor collectors without needing newer hardware.

Misconception
Believing older Pis are obsolete. They are often the right fit when power, cost, and simplicity matter more than top performance.
Key Takeaway

Match board capability to the problem: older Pis are efficient choices when you don't need advanced video or expansion options.
