Definition

Key components and functions

Know what to look for: the SoC drives computation, RAM holds active data, controllers manage I/O, and connectors link cameras and displays.

SoC
Contains CPU and GPU. Determines the board's processing and graphics capabilities for tasks like media playback and inference.
RAM
Stores running programs and in-memory data. More RAM supports running multiple services or larger data sets.
USB & Ethernet controller
Manages USB ports and wired networking. Bandwidth and protocol versions affect connected peripheral performance.
GPIO header
40-pin header for digital I/O, PWM, I2C, SPI. Central to interfacing sensors and HATs across models.
Practical check
List required connectors

Before buying, list camera, display, USB and Ethernet needs and verify the board provides the correct connectors and controller capabilities.

Misconception
Assuming all USB ports deliver the same speed. Distinguish USB 3.0 from USB 2.0 when bandwidth matters.
Key Takeaway

Identify the three components that will most affect your project—SoC, RAM, and I/O controllers—and match them to your requirements.
