Core Concept

Raspberry Pi 5

High-performance board with PCIe, fan connector, and dual 4K outputs. Best for media, desktop, AI inference, and robotics.

Processor & RAM
Broadcom BCM2712: quad-core Cortex-A76 at 2.4 GHz. Up to 8 GB LPDDR4X supports multiple services and heavier workloads.
I/O & Expansion
Dual 4K HDMI, USB 3.0 ports, PCIe connector for NVMe or other expansion, Gigabit Ethernet, Wi-Fi and Bluetooth.
Power & Cooling
Requires 5V 5A USB-C for full performance. Fan connector supports active cooling under sustained load.
Concrete Example
Home media server with hardware acceleration

Pi 5 can stream dual 4K displays and transcode media while running background services like a local database and a web UI.

Common Mistake
Choosing Pi 5 for every project because it is newest. Often unnecessary for small battery or headless tasks.
Key Takeaway

Use Pi 5 when you need sustained CPU performance, expansion via PCIe, and multiple high-resolution displays; otherwise a lighter model may be preferable.
