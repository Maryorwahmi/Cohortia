Module 4 › Chapter 3.5 › Learning Objectives
01
Read & write text, CSV, JSON
Practice opening files, writing content, and reading structured data so your Pi can store and share results. This skill matters because different projects need different formats: plain text for notes, CSV for tables, and JSON for nested data.
Verified Competency Milestone
02
Append timestamped logs
Learn to add rows with ISO-formatted timestamps to a CSV log so later analysis is simple and chronological. It makes debugging and plotting much easier.
Verified Competency Milestone
03
Fetch and parse APIs
Use the requests library to make HTTP calls and parse JSON responses so your Pi can use remote data like current weather. This extends offline sensors with live context.
Verified Competency Milestone
04
Handle file & network errors
Wrap file operations and requests in try and except blocks, check status codes and timeouts, and avoid crashes from temporary failures.
Verified Competency Milestone
