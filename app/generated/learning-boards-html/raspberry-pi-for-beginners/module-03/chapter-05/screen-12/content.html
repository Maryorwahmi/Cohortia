Module 4 › Chapter 3.5 › One-minute data logger
Starter script (outline)
import csv
import time
from datetime import datetime
import random

# write header
with open("temperature_log.csv", "w", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["timestamp", "temperature", "humidity"])

# append readings every 5 seconds for 1 minute
for _ in range(12):
    ts = datetime.now().isoformat()
    temp = round(20 + random.random() * 5, 2)
    hum = round(40 + random.random() * 10, 1)
    with open("temperature_log.csv", "a", newline="") as f:
        writer = csv.writer(f)
        writer.writerow([ts, temp, hum])
    print(ts, temp, hum)
    time.sleep(5)
Checklist
  1. Run script in Thonny or terminal.
  2. Confirm temperature_log.csv has header plus twelve rows.
  3. Open CSV in a spreadsheet and plot temperature vs timestamp.
Common pitfall
Opening the file in write mode inside the loop will erase previous rows. Use append mode inside the loop or open once outside for all appends.
Key Takeaway

This lab shows how file modes, timestamps, and small loops produce reproducible logs you can analyze later.
