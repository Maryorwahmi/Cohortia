Common try/except pattern
try:
    response = requests.get(url, timeout=10)
    response.raise_for_status()
    data = response.json()
except requests.RequestException as e:
    print("Error fetching data:", e)
    # consider retrying or writing an error record
File errors
Catch OSError when writes fail due to permissions or full disk, and log the incident to diagnose later.
Network errors
Handle timeouts, DNS failures, and HTTP errors. Decide whether to retry, back off, or fall back to cached data.
Pro tip
Record errors to a local log file so you can inspect failures after the run without losing context.
