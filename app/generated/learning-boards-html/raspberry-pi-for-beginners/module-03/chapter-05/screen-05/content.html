Module 4 › Chapter 3.5 › File modes
Mode comparison
"r" — read
Open for reading. Fails if file does not exist. Use to inspect data without changing it.
"w" — write
Create or truncate file. Useful for fresh exports, but will overwrite existing logs if misused.
"a" — append
Add data to the end of a file. Ideal for ongoing logs where preserving past rows is required.
"r+" — read and write
Open for both reading and writing. Use with caution and explicit cursor moves to avoid accidental overwrites.
Concrete example
Create readings.csv with write mode to add the header row, then open it in append mode for sensor rows so old data is preserved.
with open("readings.csv", "w", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["timestamp", "temperature", "humidity"])

# later, append rows
with open("readings.csv", "a", newline="") as f:
    writer = csv.writer(f)
    writer.writerow([timestamp, temp, hum])
Common mistake
Using write to add new rows will erase existing history. When in doubt, append for logs.
Key Takeaway

Select file mode intentionally: write for fresh files, append for ongoing logs, and read-only for safe inspection.
