Module 4 › Chapter 3.5 › Timestamped logging
Append a timestamped line
from datetime import datetime

timestamp = datetime.now().isoformat()
line = f"{timestamp},23.5,48\n"

with open("sensor_log.csv", "a") as f:
    f.write(line)
Why ISO timestamps
ISO format sorts by date and time when treated as plain text, making logs easy to order and filter without parsing timestamps first.
Example entry
2026-06-30T10:00:00,23.5,48 — ready for spreadsheets or simple CSV readers.
Key Takeaway

Append timestamped rows in append mode and use ISO format so your log is stable and sortable.
