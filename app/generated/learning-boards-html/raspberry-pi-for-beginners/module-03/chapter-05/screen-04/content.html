Module 4 › Chapter 3.5 › Safe file handling
Definition and example
The with statement opens a file and guarantees closing it when the block ends. This is the recommended pattern for reading or writing files in Python.
# safe write example
with open("notes.txt", "w") as f:
    f.write("First line\n")
    f.write("Second line\n")
Why it matters
Files close automatically after the block, preventing partial writes and locked handles that are hard to debug.
Common mistake
Relying on manual close can leave a file open if an exception occurs before close is called.
Concrete analogy
With is like using a context manager that locks a door when you enter and always unlocks it when you leave, even if you drop your keys.
Key Takeaway

Prefer with for file operations to ensure safe open and close behavior across errors.

Try this
Open a file with with and intentionally raise an exception inside the block to see that the file is still closed afterwards.
