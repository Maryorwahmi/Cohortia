Module 4 › Chapter 3.5 › CSV with csv module
Code example
import csv

with open("readings.csv", "w", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["timestamp", "temperature", "humidity"])
    writer.writerow(["2026-06-30T10:00:00", 23.5, 48])
Why newline=""?
Specifying newline equals empty string prevents extra blank lines in CSV output on Windows and some environments.
When to use CSV
Use CSV for flat, tabular data you want to open in spreadsheets or plot with simple tools. For nested or hierarchical data use JSON instead.
Key Takeaway

CSV plus the csv module gives predictable rows and correct quoting without manual string joining.
