Module 4 › Chapter 3.5 › Learning Objectives
Objective demo: CSV file
Create readings.csv with headers timestamp, temperature, humidity. Open it in a spreadsheet to plot after the run.
Mnemonic
CSV = Comma Separated Values; think rows and columns for plotting.
Objective demo: Timestamped logger
Append ISO timestamps every five seconds for one minute. This produces ten rows you can sort by time.
Mnemonic
ISO timestamp sorts lexicographically, so files stay in order.
Objective demo: API call
Use requests.get with query parameters, parse the JSON response, and print a single data point like current temperature.
Mnemonic
Requests = reliable HTTP; JSON = structured response you can index like a dict.
Objective demo: Error handling
Wrap file writes and requests in try and except, call response.raise_for_status, and print helpful messages on exceptions.
Mnemonic
Exceptions are expected; plan how to log or retry rather than aborting.
