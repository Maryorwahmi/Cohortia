# write and then read
with open("notes.txt", "w") as f:
    f.write("First line\n")
    f.write("Second line\n")

with open("notes.txt", "r") as f:
    content = f.read()
    print(content)

# expected output:
# First line
# Second line
Explanation
  • Use with to open and guarantee close.
  • f.read returns the whole file as a string; iterate lines with a for loop or readlines when needed.
  • Printing content confirms the file writes succeeded before moving to logging loops.
Concrete checklist
Run the snippet in Thonny, inspect notes.txt in the file browser, then open it with a text viewer to verify both lines are present.
Key Takeaway

Confirm file writes immediately by reopening and printing the content; this keeps debugging fast.
