Module 4 › Chapter 3.5 › JSON basics
Code example
import json

data = {"temperature": 23.5, "humidity": 48}
json_string = json.dumps(data, indent=2)
print(json_string)

parsed = json.loads(json_string)
print(parsed["temperature"])  # 23.5
Why JSON
JSON is human-readable, language-agnostic, and ideal for nested API responses and configuration files your Pi may share with other tools.
Common limitation
JSON does not encode Python-specific types like tuples or bytes directly; convert those to lists or strings first.
Key Takeaway

Use JSON for structured data exchange and parsing API responses into usable Python objects.
