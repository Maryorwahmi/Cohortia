Module 3 › Chapter 3.3 › if vs elif vs else
Comparison

Ordered checks vs independent checks

If you want only one branch to run, chain with elif. If you want multiple checks to run independently, use separate if statements.

Mistake: overlapping conditions
Put specific checks before broader ones to avoid unreachable branches.
When to use separate ifs
Use this when multiple sensors should trigger independent actions, such as logging and alerting both happening together.
Key Takeaway

Order matters in chained checks; use separate checks when events are independent.

Example
temperature = 28
# correct order
if temperature > 30:
    print("Very warm")
elif temperature > 25:
    print("Warm")
elif temperature > 20:
    print("Comfortable")
else:
    print("Cold")

# independent checks
if motion_detected:
    print("Motion logged")
if light_level < low_threshold:
    print("Turn on light")
Test both patterns. Use independent ifs when both actions could happen for the same input set.
