Module 3 › Chapter 3.3 › Key Concepts
if / elif / else
Ordered checks that let your program choose between branches based on conditions.
for loops & range()
Iterate known sequences or numeric ranges for predictable repetition.
while loops
Run until a condition changes or a stop event occurs; used for main program loops.
break & continue
Control loop flow: break exits, continue skips to next iteration.
Safe main loops
Use sleep and KeyboardInterrupt handling to run and stop long-running programs safely.
Practical patterns
Combine loops and conditionals for threshold alerts, menu systems, and reliable sensor polling.
Summary
Test each branch and loop using sample inputs, simulate sensor data before using hardware, and prefer clear, maintainable loop logic.
