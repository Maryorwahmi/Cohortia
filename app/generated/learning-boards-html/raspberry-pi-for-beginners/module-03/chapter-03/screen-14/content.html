Ordered checks
if → elif → else; the first true branch runs.
Pick loop type
Use for for known sequences, while for open-ended repetition.
Control flow hygiene
Validate inputs, sleep between polls, and handle KeyboardInterrupt for safe stops.
Final thought
Start small, run sample inputs, and trace outputs; these habits prevent common control-flow bugs on your Pi.
