Activity

Warn above threshold and stop on three consecutive highs

This activity shows how to combine a for loop and conditionals to detect sustained high readings and stop early using a consecutive counter and break.

Common bug
Not resetting consecutive counters causes false triggers. Reset to zero when a reading is below threshold.
Practical tip
Simulate readings first before hooking sensors to avoid hardware surprises and to confirm logic works.
Key Takeaway

Track consecutive events to detect sustained conditions and use break to stop processing early when needed.

Starter code
temps = [29, 31, 32, 33, 28, 31]
consecutive = 0
for t in temps:
    if t > 30:
        print("Warning: high temp", t)
        consecutive += 1
    else:
        consecutive = 0
    if consecutive == 3:
        print("Three consecutive highs: stopping early")
        break
Run this code and observe when the loop breaks. Modify the list to test edge cases where highs are not consecutive.
