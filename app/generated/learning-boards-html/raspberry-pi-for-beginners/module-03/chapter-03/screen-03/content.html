Practice Roadmap

Small exercises to confirm each objective and give a runnable expected output.

Thermostat conditional

Write an if, elif, else that prints warm/comfortable/cold for a given numeric temperature.

Try: check 28 and 18
Loop over sensors

Use a for loop over a list like [temperature, humidity, light] and print each item to simulate readings.

Try: three sensor names
Main loop with stop

Create while True that sleeps and catches a keyboard interrupt to stop gracefully.

Try: sleep one second
Key Takeaway

Small, testable scripts are the fastest way to confirm control flow understanding on your Pi.
