Learning Objectives

Skills to build and check on your Pi

Learn → Understand → Apply → Master
01
Use if, elif, else

Write conditional branches that choose actions based on sensor values or user input. Master indentation so blocks run in the right branch.

Venn: conditions vs actions
VERIFIED COMPETENCY MILESTONE
02
Write for and while loops

Repeat actions with for for known sequences and while when iterations depend on changing conditions. Know when to use range or the items in a list.

Timeline: sequence → repeat
VERIFIED COMPETENCY MILESTONE
03
Iterate lists, dicts, ranges

Loop across common data types to process multiple sensor readings or configuration entries. Practice indexing and item access safely.

Mnemonic: list = items, dict = keys
VERIFIED COMPETENCY MILESTONE
04
Apply to Pi projects

Use control flow for sensor thresholds, simple menus, and a safe main loop that you can stop with keyboard interrupt handling.

Visual: menu flow
VERIFIED COMPETENCY MILESTONE
Practice each milestone with short scripts: a thermostat conditional, a sensor-reading loop, and a main loop that handles Ctrl+C.
