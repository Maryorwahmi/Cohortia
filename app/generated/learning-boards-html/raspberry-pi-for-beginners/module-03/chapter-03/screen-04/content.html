Module 3 › Chapter 3.3 › What is control flow?
Definition

Control flow in plain terms

Decisions pick which code runs. Loops repeat work. Together they let your Pi react and continue doing tasks until you stop it.

Common misconception
Loops and conditionals serve different goals. A conditional does not repeat; a loop does. Don’t use if when you need repetition.
Why indentation matters
In Python, indentation groups lines into the branch or loop body. Misaligned indentation changes program behavior and often causes errors.
Key Takeaway

Think of conditionals as forks and loops as repeaters — both are essential for interactive Pi programs.

Concrete example
temperature = 28.0
if temperature > 25.0:
    print("It is warm.")
elif temperature > 20.0:
    print("It is comfortable.")
else:
    print("It is cold.")
Run this example with different temperature values to confirm which branch prints. Try 28.0, 22.0, and 18.0 to exercise each branch.
Check your understanding
  • What prints when temperature is 25.0?
  • How would you add a new branch for very warm temperatures above 30?
