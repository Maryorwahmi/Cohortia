Code Walkthrough

while for open-ended repetition

Use while when the number of repeats depends on runtime state. Update the condition each loop to avoid infinite loops, and include sleep when polling hardware.

Practical warning
Infinite loops are common when the condition never becomes false. Use deliberate updates and test with print statements before deploying on hardware.
When to use while True
Main program loops that should run until the user stops can use while True combined with exception handling for a safe shutdown.
Key Takeaway

While loops are powerful for ongoing tasks, but require explicit updates, pauses, or break conditions to avoid locking the program.

Example
count = 0
while count < 5:
    print(count)
    count += 1
Trace the loop to verify output: zero, one, two, three, four. If you omit the increment you will create an infinite loop and the program will not progress.
