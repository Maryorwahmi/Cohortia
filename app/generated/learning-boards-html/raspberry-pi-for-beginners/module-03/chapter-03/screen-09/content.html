Module 3 › Chapter 3.3 › Main loop pattern
Architecture

A safe long-running loop

Wrap a while True loop with try/except to catch user stop commands, include sleep to pace work, and keep sensor reads inside the loop for steady updates.

Resource cleanup
On stop, close files and reset GPIO where needed to leave hardware in a safe state.
Sleep to reduce load
A short sleep between iterations avoids high CPU use and gives hardware time to settle between reads.
Key Takeaway

A predictable, interruptible main loop is a reliable foundation for Raspberry Pi applications.

Example
from time import sleep

try:
    while True:
        print("Running...")
        sleep(1)
except KeyboardInterrupt:
    print("Stopped by user.")
Run this on your Pi to see the loop and practice stopping with Ctrl+C. Add sensor reads inside the loop for a continuous monitoring script.
