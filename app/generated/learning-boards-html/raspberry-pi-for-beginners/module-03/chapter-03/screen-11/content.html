Comparison

Lists, dicts, ranges, and nested loops

Choose the iteration style that matches your data: lists for ordered items, dictionaries for key/value maps, and range for numeric sequences. Nested loops handle multiple dimensions like a grid of coordinates.

Dict iteration
Use for k, v in mydict.items() to access both key and value while iterating a dictionary.
Nested loop note
The inner loop completes all iterations for each single iteration of the outer loop. Trace with small ranges to confirm order.
Key Takeaway

Pick the iteration form to match your data, and trace nested loops to predict output order.

Examples
thresholds = {"temp":30, "humidity":70}
for k, v in thresholds.items():
    print(k, "->", v)

for r in range(3):
    for c in range(3):
        print(f"({r},{c})")
The nested loop example prints nine coordinate pairs. Use small ranges when tracing to confirm the printed order.
