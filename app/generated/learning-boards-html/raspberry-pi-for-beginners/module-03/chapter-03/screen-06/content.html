Iterating sequences

For loops execute once per item in a sequence. Use lists for named items and range for numeric sequences or fixed repeats.

Practical tip
If you need to modify a list while iterating, iterate over a copy or build a new list to avoid surprising behavior.
Use case
Loop over sensor names to perform the same read-and-log operation without duplicating code.
Key Takeaway

For loops give concise, readable iteration for lists and ranges; choose the right loop for the job.

Examples
for i in range(5):
    print(i)

sensors = ["temperature", "humidity", "light"]
for sensor in sensors:
    print(f"Reading {sensor}...")
First example prints numbers zero through four. Second iterates three sensor names. Try changing the list and re-running to see different outputs.
