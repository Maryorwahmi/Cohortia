Suggested modules
  • sensors.py — reading and normalizing sensors
  • conversions.py — unit conversion functions
  • display.py — rendering or screen updates
  • webapp.py — HTTP endpoints or dashboard code
Keep modules focused and avoid import-time hardware actions.
Testing & initialization
Provide explicit initialization functions so you can import modules in tests without triggering hardware code. Mock hardware interfaces during unit tests to verify logic independently.
Why it works

Clear boundaries reduce coupling and make it easier to fix hardware or UI issues without touching unrelated code.
