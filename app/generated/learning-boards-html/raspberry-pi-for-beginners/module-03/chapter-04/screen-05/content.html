How parameters work
Parameters are placeholders for values the caller provides. Defaults supply fallback values so callers can omit arguments when the default is acceptable.
Misconception
Avoid using mutable default parameters; they can persist unexpected state across calls. Use None and create new objects inside the function instead.
Pro Tip

Design defaults that reflect common usage so most calls remain concise.

Concrete example
def describe_sensor(name, value, unit="units"):
    return f"{name}: {value} {unit}"

print(describe_sensor("Temperature", 22.5, "°C"))
print(describe_sensor("Humidity", 60, "%"))
This shows a default unit value and two calls: one that specifies a unit and one that relies on the default. Returning a formatted string lets other parts of the program display consistent sensor labels.
