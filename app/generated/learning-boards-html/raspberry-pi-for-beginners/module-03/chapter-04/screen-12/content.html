Common Mistakes › Chapter 3.4 › Pitfalls & Remedies
Mistake → Fix
  • Import-time hardware calls → Provide init() and call from main.
  • Circular imports → Refactor responsibilities or use local imports.
  • Mutable defaults → Use None and allocate inside function.
Dependency issues
Install packages in a virtual environment. Keep a requirements file to reproduce the environment on another machine.
Quick checklist: explicit init, no circular imports, safe defaults, per-project venv, requirements.txt
