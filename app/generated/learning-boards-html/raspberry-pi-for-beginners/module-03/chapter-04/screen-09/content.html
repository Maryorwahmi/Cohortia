Process › Chapter 3.4 › Virtual Environment
Commands to run
python3 -m venv myproject_env
source myproject_env/bin/activate
pip install gpiozero flask
# when done
deactivate
These commands create, activate, install packages into, and deactivate a project environment.
Why it matters
Environments prevent version conflicts and make your project reproducible. When sharing code, include a requirements file listing package versions.
Misconception

Virtual environments are not heavyweight virtual machines; they are isolated package directories around the same interpreter.
