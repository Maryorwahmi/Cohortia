Code Walkthrough › Chapter 3.4 › Read JSON config
Code example
import json

with open("config.json", "r") as f:
    config = json.load(f)

print(config["sensor_interval"])
This reads the file, parses it, and accesses a key. Add checks for missing files and missing keys before using values in production.
Best practices
  • Provide sensible defaults when keys are missing.
  • Validate types — ensure a polling interval is numeric and within expected bounds.
  • Keep sensitive secrets out of plain JSON in production.
Check

If the config file is missing, decide a safe default and log a warning rather than crashing.
