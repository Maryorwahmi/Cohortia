Process Flow › Chapter 3.4 › From Functions to Modules
Three-step process
  1. Identify related functions that change together or share responsibility.
  2. Create a module file, e.g. conversions.py, sensors.py, display.py, and move functions there.
  3. Import specific functions into scripts to keep the main program concise.
Avoid circular imports by keeping modules' top-level behavior minimal and importing only the functions you need.
Key Takeaway

Modules group responsibilities. Import what you need and keep module interfaces small and stable.

Analogy: kitchen stations
Each module is an ingredient station with recipes. The main script orchestrates stations to produce the final dish.
Example layout
sensors.py — sensor read functions; display.py — rendering helpers; webapp.py — web endpoints. Import these modules into a central runner script.
