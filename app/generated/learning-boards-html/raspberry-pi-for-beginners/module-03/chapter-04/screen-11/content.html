conversions.py (example)
def celsius_to_fahrenheit(celsius):
    return (celsius * 9/5) + 32

def cm_to_inches(cm):
    return cm / 2.54

if __name__ == "__main__":
    print(celsius_to_fahrenheit(0))
Keep runnable examples under the main guard so importing the module from other scripts doesn't execute them automatically.
Importer script
from conversions import celsius_to_fahrenheit

readings = [22.5, 18.0, 25.0]
for r in readings:
    print(celsius_to_fahrenheit(r))
