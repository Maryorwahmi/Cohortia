Definition & purpose

Functions reduce repetition, clarify intent, and allow unit testing of small pieces of logic. They accept parameters and return values.

Common mistakes
  • Making functions do too many things instead of one clear task.
  • Relying heavily on global state instead of passing needed values as parameters.
Key Takeaway

Choose clear names, keep functions focused, and return values for predictable composition.

Example: Celsius to Fahrenheit
def celsius_to_fahrenheit(celsius):
    return (celsius * 9/5) + 32

temp_f = celsius_to_fahrenheit(25)
print(temp_f)
This example shows declaration, a call with an input, and output. Tests can call the function with multiple inputs to verify correctness.
Analogy: a single recipe that produces consistent results when you supply different ingredients.
