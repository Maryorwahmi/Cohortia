Module 3 › Chapter 3.4 › Objective Details
01 Define functions
Outcome
Produce reusable functions with parameters, default values, and explicit return values for predictable behavior.
02 Organize modules
Outcome
Split hardware, logging, and UI into separate files that are easy to test and update independently.
03 Use libraries
Outcome
Install and import libraries like gpiozero to interact with sensors without rewriting low-level code.
04 Virtual environments
Outcome
Create isolated environments so project dependencies do not conflict with system packages or other projects.
Learning Path
Practice by writing conversion functions, grouping them into a conversions module, then create a virtual environment and install gpiozero to test code on a real sensor.
