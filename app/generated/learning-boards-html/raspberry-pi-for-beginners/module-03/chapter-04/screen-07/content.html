Comparison › Chapter 3.4 › Standard vs Third-Party
Standard library
  • time, datetime — sleep, timestamps, and delays
  • json — read and write configuration and structured data
  • csv — read/write CSV files for logs
  • os, sys — file paths and process-level utilities
  • random, math, statistics — common computations
These modules require no installation and form the backbone of many Pi scripts.
Third-party libraries
Examples on Raspberry Pi include gpiozero, RPi.GPIO, smbus2, spidev, picamera2, flask, and paho-mqtt. These provide hardware and service integrations that simplify development.
Misconception
Not all third-party packages are heavy; some are thin wrappers that save a lot of boilerplate. Evaluate stability and community adoption before depending on them.
