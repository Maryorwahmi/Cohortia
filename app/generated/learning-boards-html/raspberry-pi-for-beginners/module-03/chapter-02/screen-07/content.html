Module 3 › Chapter 3.2 › Lists
Step-by-step: collect readings
  1. Create an empty list to hold numeric readings.
  2. When a new reading arrives, append the numeric value to the list.
  3. Optionally trim the list to keep only the most recent N values.
  4. Compute summary statistics using sum, len, min, and max.
  5. Format the results for display using the print function and an f-string.
Example
Store five float readings, compute average, and display a formatted summary while keeping the numeric list intact for future calculations.
Scenario card
You receive readings every minute and keep the last five. Use append to add, then if the list is longer than five remove the oldest element to maintain a sliding window.
Pro tip
If memory is a concern, use a fixed-size structure or collections with a deque configured with a max length to manage recent readings automatically.
Key Takeaway

Lists make it easy to accumulate and summarize numeric data; manage mutability and keep numeric storage separate from display strings.
