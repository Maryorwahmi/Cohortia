Three micro-tasks
Short questions to test the chapter's main ideas.
Convert input
How would you turn a raw numeric string into a float before computing an average? Explain the conversion step and why it matters.
Store readings
Why keep numeric values in a list rather than storing formatted strings? Describe the benefit for later calculations.
Format output
Describe how to present an average with a single decimal and a unit using a formatted print line for clear logs.
Final note
