Learning Objectives
From naming values to formatting output for logs.
Learn → Understand → Apply → Master
01
Use variables and dynamic typing
Name values without declaring types and rely on Python to track the type for you. This reduces boilerplate and speeds prototyping on a Pi.
Mnemonic: name → value → trust Python
VERIFIED COMPETENCY MILESTONE
02
Work with built-in types
Use integers, floats, strings, booleans, lists, tuples, and dictionaries where they fit best for sensor values and configuration data.
Mnemonic: scalar, sequence, mapping
VERIFIED COMPETENCY MILESTONE
03
Use operators for logic and math
Apply arithmetic for calculations and comparison or logical operators for control flow and testing sensor thresholds.
Mnemonic: compute → compare → decide
VERIFIED COMPETENCY MILESTONE
04
Format and clean text
Use f-strings and string methods to present tidy output and log messages that are easy to read and parse.
Mnemonic: format → display → log
VERIFIED COMPETENCY MILESTONE
