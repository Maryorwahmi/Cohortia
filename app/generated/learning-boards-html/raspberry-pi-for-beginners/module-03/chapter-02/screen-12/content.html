Module 3 › Chapter 3.2 › f-strings & Formatting
Why f-strings
They are concise, readable, and avoid awkward concatenation when building messages for display or logging.
Example scenario
After computing an average numeric value, format with a fixed number of decimals and include units so the output is clear to humans.
Keep the numeric value for calculations. Format only when creating lines for display, logs, or sending to external systems that expect a string.
Formatting checklist
  • Compute numeric results separately from formatting.
  • Use f-strings to produce human-friendly output with units.
  • Round visually with format specifiers only in the display step.
  • Prefer consistent formats to simplify parsing and logs.
Pitfall
Embedding raw data without units or context makes logs harder to interpret. Always include a label and unit where relevant.
Key Takeaway

Keep calculations and formatting separate. Use f-strings for readable, consistent output.
