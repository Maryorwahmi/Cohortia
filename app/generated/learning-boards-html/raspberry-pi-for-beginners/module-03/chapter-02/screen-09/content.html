Structure of a dictionary
Use descriptive keys to label each value, e.g. device, temperature, humidity, timestamp. This grouping makes data self-describing and easy to serialize.
Use case
Package a sensor reading with metadata for logging or sending to a server.
When working with dictionaries, validate presence of keys before reading and convert string inputs into the expected numeric types.
Scenario
Receive parsed values from a line, convert them to floats or ints, create a dictionary with keys for labels and timestamp, and print or serialize the dictionary for storage.
Pro tip
Keep numeric and textual fields in their appropriate types inside the dictionary. Format only when presenting the data to humans.
Key Takeaway

Dictionaries make sensor messages self-describing and easy to integrate with formats like JSON for telemetry and logs.
