Concept Map
Variables → Types → Operators → Output
Variable
A name that refers to a value. No explicit declaration required.
Collection
Lists and dictionaries hold multiple readings and structured data.
Operator
Perform arithmetic, comparisons, and logical checks.
Format
f-strings produce readable messages for logs and displays.
Quick start
Try storing a temperature reading in a variable, then print a formatted line using the print function and an f-string. That small practice ties naming, types, and formatting together.
