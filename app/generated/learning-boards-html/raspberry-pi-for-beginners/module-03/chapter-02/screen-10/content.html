Common operators
  • Addition: +
  • Subtraction: -
  • Multiplication: *
  • Division: / (returns float)
  • Integer division: //
  • Modulo: %
  • Exponent: **
Use case
Compute averages, convert units, and check cycles using modulo for periodic tasks.
Scenario: average and rounding
Sum readings and divide by count for the average. Then choose how many decimal places to display, but keep the raw numeric average for further calculations.
Common Mistake
Using integer division where you need fractional precision leads to incorrect averages. Use normal division for precise results.
Key Takeaway

Pick operators that preserve the precision you need and keep calculations numeric until formatting time.
