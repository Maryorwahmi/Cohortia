Module 3 › Chapter 3.2 › Integers & Floats
Integers
Whole numbers for counts, indices, and discrete values.
When to use
Counting button presses, array indices, or device IDs.
Floats
Decimals for measurements like temperature or voltage where fractions matter.
Tip
Keep calculations in numeric form and only format for display. Avoid storing rounded strings back into variables used for math.
Common Mistake

Comparing floats for equality often fails due to tiny rounding differences. Compare within a small tolerance instead.

Example: compute average
Take a list of readings, sum them, and divide by the count to compute a float average. Format for display with one decimal place when printing.
Scenario
Sensor gives readings 22.5, 23.0, 22.8, 23.2. Use floats to average and then display a rounded value while keeping the numeric average for further calculations.
Misconception check: integer division versus float division — modern Python makes division return a float, but integer division operator produces an integer quotient when that's what you want.
