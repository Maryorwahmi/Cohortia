Module 3 › Chapter 3.2 › Tuples vs Lists
Lists
Mutable, use for streams of readings where you append or update values.
Examples
[22.5, 23.0, 22.8]
Operations: append, remove, index assignment. Great for sliding windows and dynamic collections.
Tuples
Immutable, use for fixed sets of values such as configuration or coordinates.
Examples
(3, 4) for a point, or ('pi-01', 9600) for device settings that shouldn't change.
Choosing mutability intentionally documents how the data will be used and prevents accidental modifications.
Common Mistake

Trying to change a tuple raises an error. If you plan to modify the collection, use a list instead.

Key Takeaway

Pick the structure that matches whether the data should change; that choice helps prevent bugs.
