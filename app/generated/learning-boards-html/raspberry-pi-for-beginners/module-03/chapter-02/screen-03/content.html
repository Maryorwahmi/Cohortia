Practice Tasks
Four short scripts to try on your Raspberry Pi.
Assign & Print
Store a temperature and a label, then print a formatted message using the print function and an f-string. Verify the output is human-friendly.
Type checks
Try simple expressions combining integers and floats, then inspect types to understand Python's choices. See how division produces floats.
Threshold decision
Use comparison and logical operators to decide whether a heater or fan should be active based on two readings.
String cleaning
Take a raw sensor label, strip whitespace, change case, split fields, and produce a tidy log line ready for display or storage.
