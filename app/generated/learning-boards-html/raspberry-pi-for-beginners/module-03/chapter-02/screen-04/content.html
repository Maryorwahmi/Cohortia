What is a variable?
A variable is simply a label that refers to a value in memory. Python decides the type when you assign.
Example
Assign a temperature reading and later reuse it for computations or formatting. Choose names that describe the data's role.
Common pitfalls
  • Reassigning a variable to a different type can break later code that expects the original type.
  • Assuming a value is numeric without checking can cause runtime errors when performing arithmetic.
  • Using unclear variable names makes debugging sensor scripts harder.
Key Takeaway

Use descriptive names, trust dynamic typing, and convert or check types when you need numeric operations.

Visual: variable examples
Numeric value
temperature = 23.5 — name indicates a measured value stored as a float for calculations.
Boolean flag
is_running = True — a flag used for control flow, evaluated in conditional statements.
Label
name = "Living Room" — text for display and logging, kept separate from numeric data until formatting time.
Misconception check: dynamic typing does not remove the need to manage types; it moves some decisions to runtime, so validate inputs in device scripts.
