Module 3 › Chapter 3.1 › Python Versions
Quick checks
$ python3 --version
Python 3.x.x

$ python --version
Python 2.7.x  # possible on older systems
If python reports a 2.x version, always use python3 to run scripts and avoid syntax mismatches.
Contrast
Python 2 (legacy)

Older syntax and no longer supported; some keywords behave differently.

Python 3 (current)

Modern features, widely supported libraries, and the version to use on Raspberry Pi.

Common Mistake

Typing python instead of python3 can silently run the wrong interpreter and produce confusing errors.
