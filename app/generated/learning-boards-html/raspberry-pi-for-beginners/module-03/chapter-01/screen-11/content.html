Module 3 › Chapter 3.1 › Indentation
Rules
  • Indentation defines block scope in Python.
  • Use consistent spaces (commonly four) and avoid mixing tabs.
  • Errors refer to the line number to help find mismatches.
Example error
for i in range(3):
print(i)  # IndentationError: expected an indented block
Fix by indenting the print line with consistent spaces. Configure your editor to convert tabs to spaces to avoid this issue.
