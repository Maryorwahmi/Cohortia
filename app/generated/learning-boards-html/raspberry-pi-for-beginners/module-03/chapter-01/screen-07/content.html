What the REPL does
  • Read the expression you type.
  • Evaluate it immediately.
  • Print the result and wait for more input.
Good for testing functions, library calls, and trying expressions before making a script.
REPL example
$ python3
>>> 2 + 3
5
>>> print('Hi')
Hi
>>> exit()
Remember that the session is temporary. Copy working lines into a file to save them.
Pro Tip

Use the REPL to confirm small pieces of logic before placing them in a script file for repeatable runs.
