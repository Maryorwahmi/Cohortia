Module 3 › Chapter 3.1 › Terminal Run
Steps
$ cd /path/to/project
$ python3 add.py
Ensure the file is saved before running. The terminal shows tracebacks and error lines for debugging.
When to use the terminal
  • Running scripts repeatedly or on schedule.
  • Deploying code to run at boot or via automation.
  • Testing behavior outside an IDE environment.
Pro Tip

Use the terminal for automation and when a script must run without a graphical session.
