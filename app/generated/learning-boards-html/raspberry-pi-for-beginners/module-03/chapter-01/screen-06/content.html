Module 3 › Chapter 3.1 › Interpreter Flow
Execution steps
  1. Open and read the file into memory.
  2. Parse source into structures and check syntax.
  3. Execute statements from top to bottom.
  4. Report errors with tracebacks and line numbers.
This process means order matters: put setup code before actions that depend on it.
Concrete example
# hello.py
print("Hello, Raspberry Pi!")
name = input("What is your name? ")
print(f"Nice to meet you, {name}!")
Running python3 hello.py prints the greeting, waits for your input, then prints the response. Errors point to specific lines to help debugging.
Key Takeaway

Scripts execute sequentially; place code in the order you want it to run and use control structures to change flow.
