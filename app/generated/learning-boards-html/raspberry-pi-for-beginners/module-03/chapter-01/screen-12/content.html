Starter code
# add.py
x = input("Enter first number: ")
y = input("Enter second number: ")
# Convert to numbers before adding
sum = float(x) + float(y)
print(f"The sum is {sum}")
Run in Thonny first, then save and run with python3 add.py in a terminal to test repeatable behavior.
Common pitfalls
  • Not converting input causes string concatenation.
  • Not handling invalid input can crash the script.
