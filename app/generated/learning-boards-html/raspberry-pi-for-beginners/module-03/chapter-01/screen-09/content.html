Module 3 › Chapter 3.1 › Thonny IDE
What Thonny provides
  • Syntax highlighting and simple run controls.
  • Variable viewer to inspect program state.
  • Beginner-friendly debugger and clear error messages.
Workflow suggestion

Start in Thonny to prototype and learn. When confident, try VS Code for more advanced features like integrated terminals and extensions.

Common Mistake

Assuming the IDE will correct logic errors. It helps you inspect state, but reasoning and fixes are manual.
