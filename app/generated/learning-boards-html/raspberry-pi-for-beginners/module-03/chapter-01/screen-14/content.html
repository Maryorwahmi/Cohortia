Module 3 › Chapter 3.1 › Troubleshooting
Common errors
  • SyntaxError — check parentheses and quotes.
  • IndentationError — ensure consistent spaces, not tabs.
  • NameError — define variables before use.
Quick fixes
  1. Read the traceback to find the line number.
  2. Open the file in Thonny to see highlighted errors.
  3. Confirm you run python3 and save files before execution.
Remember

Errors are learning signals. Tracebacks guide you to the problem line — use them to iteratively fix and re-run your code.
