Module 3 › Chapter 3.1 › hello.py Walkthrough
Code example
print("Hello, Raspberry Pi!")
name = input("What is your name? ")
print(f"Nice to meet you, {name}!")
Save this as hello.py and run python3 hello.py to try it. Thonny provides a one-click run alternative and a variables view.
Explanation
  • The print function outputs text to the console.
  • The input function waits for user input and returns it as a string.
  • Formatted printing inserts the captured name into the final message.
Key Takeaway

This simple program teaches input/output, sequence, and saving files for repeatable execution.
