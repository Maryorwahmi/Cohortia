from gpiozero import MCP3008
from time import sleep

adc = MCP3008(channel=0)

while True:
    value = adc.value  # normalized 0.0 - 1.0
    voltage = value * 3.3
    print(f"raw: {value:.3f}  voltage: {voltage:.2f} V")
    sleep(0.5)
The example prints a normalized value and a calculated voltage. If you need raw counts on a 10-bit ADC, multiply the normalized value by 1023 and round to an integer.
Concrete check
If the printed voltage reads about 1.65 V at midpoint, the conversion and wiring are likely correct.
Misconception
Do not assume adc.value is a raw integer; it is normalized. Convert if you require the actual 10-bit count.
Terminal demo
Run the example in a terminal to observe live readings as you change sensor inputs. This instant feedback is the fastest way to verify wiring and conversion math.
Key Takeaway

Use the helper to get normalized values, convert to volts by multiplying by VREF, and confirm midpoint values for sanity checking.
