Potentiometer → ADC → PWM LED

Wire the potentiometer between 3.3V and ground, with the wiper to MCP3008 channel 0. Read adc.value and map it to PWM duty cycle to control LED brightness safely.
Simple mapping example
value = adc.value  # 0.0 - 1.0
duty_percent = value * 100  # 0 - 100%
# write duty_percent to a PWM output pin via a safe driver
Safety tip
Use a transistor or LED driver and a current-limiting resistor to avoid damaging the Pi GPIO.
Debug tip
If brightness is erratic, check VREF and ground connections for noise or floating pins.
Concrete scenario
Connect LED to a transistor, control transistor base with a PWM GPIO, and read ADC to vary duty cycle in real time.
Key Takeaway

Mapping ADC readings to PWM controls a physical output; always use proper drivers and confirm reference consistency.
