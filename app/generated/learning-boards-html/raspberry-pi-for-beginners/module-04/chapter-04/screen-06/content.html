Architecture

MCP3008 + SPI signals

The MCP3008 houses eight input channels and converts each selected channel to a 10-bit digital value sent over SPI. SPI is synchronous and requires explicit selection of the chip using CS.
SPI lines
  • MOSI — Pi to MCP3008
  • MISO — MCP3008 to Pi
  • SCLK — clock signal
  • CE/CS — chip select
Power pins
  • VDD → 3.3V
  • VREF → 3.3V
  • AGND, DGND → GND
Operational handshake

The Pi asserts CS, sends the channel selection sequence on MOSI while pulsing SCLK, then reads the 10-bit result on MISO. If CS is never asserted or wiring is wrong, reads fail or return noise.

Pin mapping (Pi → MCP3008)
GPIO 10 → DIN (MOSI), GPIO 9 → DOUT (MISO), GPIO 11 → CLK, GPIO 8 → CS (CE0). VDD and VREF to 3.3V, grounds tied together.
Key Takeaway

SPI is a four-wire synchronous link; correct wiring and stable VREF are essential for reliable ADC readings.
