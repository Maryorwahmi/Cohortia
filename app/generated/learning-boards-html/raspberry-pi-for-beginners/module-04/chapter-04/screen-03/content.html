Learning Objectives — Practical Focus

Four verifiable tasks to practice on your Pi and breadboard.

Explain ADC necessity

Task: show that a direct GPIO read returns only high or low while an ADC reports variable values as you move the potentiometer.

VERIFIED COMPETENCY MILESTONE
Wire MCP3008 + enable SPI

Task: connect power, reference, ground, CLK, MOSI, MISO, and CS; then enable SPI in raspi-config and reboot.

VERIFIED COMPETENCY MILESTONE
Read with gpiozero

Task: run a small Python loop that prints adc.value and see a continuous range between zero and one as the sensor changes.

VERIFIED COMPETENCY MILESTONE
Convert and calibrate

Task: record extremes, compute voltage by multiplying by 3.3, and map the ADC range to a 0–100 percentage scale for display or control.
