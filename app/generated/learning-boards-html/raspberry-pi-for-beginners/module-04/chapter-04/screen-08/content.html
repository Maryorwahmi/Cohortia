Enable SPI

OS-level enablement and verification

Use the Raspberry Pi configuration tool to enable SPI, reboot, then verify the kernel exposed an SPI device node such as spi0.0.
Verification steps
  1. Run the configuration tool and enable SPI.
  2. Reboot the Pi.
  3. List devices to confirm SPI appears (spi0.0).
  4. Run a short Python script to open the MCP3008 device and read a value.
Common pitfalls
  • Forgetting to reboot after enabling SPI.
  • Not having the hardware header enabled on some Pi models.
  • Expecting code to work without kernel support for SPI.
Key Takeaway

Enabling SPI at the OS level is necessary for the MCP3008 to appear as a device the Python libraries can use.
