Calibration

LDR in a voltage divider

Choose a fixed resistor so the divider voltage spans a useful portion of the ADC range in your lighting conditions. Then record extremes and map the readings to percent.

Calibration example
bright_value = read_adc(); dark_value = read_adc() in darkness; percent = (value - dark_value) / (bright_value - dark_value) * 100
Concrete step
Record and save calibration values rather than hard-coding them every run to improve accuracy.
Adjustment tip
If readings saturate, change the fixed resistor value so the divider output shifts within the ADC range.
Real-world use
Calibrated light percentages are useful for UI elements, thresholds, or logging environmental data consistently across devices.
Key Takeaway

Calibration turns raw ADC counts into meaningful percentages by recording extremes and mapping intermediate values linearly.
