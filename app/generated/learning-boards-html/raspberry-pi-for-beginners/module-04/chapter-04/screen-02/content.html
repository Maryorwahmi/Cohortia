01
Explain why an ADC is required

Describe the mismatch: Pi GPIO is digital while many sensors output continuous voltages. Knowing this avoids wrong wiring and wrong assumptions.

Venn: digital vs analog
VERIFIED COMPETENCY MILESTONE
02
Wire an MCP3008 with SPI

Match VDD, VREF, AGND, DGND, CLK, DOUT, DIN, and CS to the Pi pins and power rails; enable SPI in the OS first.

Mnemonic: 4 SPI wires + 4 power/ground
VERIFIED COMPETENCY MILESTONE
03
Read values in Python

Use gpiozero's MCP3008 to get a normalized value between zero and one, then verify live readings in a terminal loop.

Timeline: enable SPI → wire → run script
VERIFIED COMPETENCY MILESTONE
04
Convert and calibrate readings

Multiply the normalized value by the reference voltage, then calibrate sensors (e.g. map min/max ADC to 0–100%).

Mnemonic: normalize → scale → map
