Module 4 › Chapter 4.3 › Creating a smooth LED fade
Process Flow

Circuit → Code → Tune → Observe

1. Circuit
Use a current-limiting resistor and confirm LED polarity on GPIO 17.
2. Code
Use PWMLED and a loop to change value from zero to one and back.
3. Tune
Smaller steps and ~20ms delay give smooth fades; adjust for perception.
4. Observe
If stutter appears under load, consider hardware PWM on supported pins.
Example task
Build two LED circuits on GPIO 17 and 27. Make one fade up while the other fades down by inverting the value sequence.
Check
If LEDs step visibly, decrease step size or increase update frequency. Never omit the resistor.
