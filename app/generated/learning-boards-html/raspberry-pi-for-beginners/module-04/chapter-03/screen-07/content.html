Module 4 › Chapter 4.3 › Servo control with PWM
Definition

Pulse width controls position

Unlike LED brightness, servo position depends on the width of each pulse within a roughly twenty millisecond period. The width, measured in milliseconds, maps to physical angle.
Typical mapping
~1.0 ms → one extreme, ~1.5 ms → center, ~2.0 ms → opposite extreme.
gpiozero Servo
Use Servo class methods min, mid, max, and detach so you don't manage raw pulse timing yourself.
Concrete example
Call servo.min(), wait, servo.mid(), wait, servo.max(), and detach to observe centered and extreme positions. gpiozero handles the timing for you.
Common mistake
Treating servo control like LED duty. Remember to think in pulse width milliseconds rather than average duty percentage for position.
Key Takeaway

Servo position depends on pulse width; use gpiozero Servo helpers to avoid manual timing errors.
