Module 4 › Chapter 4.3 › Build: fading two LEDs in opposite directions
Circuit steps
Wire LED with resistor to GPIO 17, and a second LED with resistor to GPIO 27. Share a common ground. Verify polarity and resistor values before powering.
Code pattern
from gpiozero import PWMLED
from time import sleep

led1 = PWMLED(17)
led2 = PWMLED(27)

while True:
    for i in range(0, 101):
        v = i / 100
        led1.value = v
        led2.value = 1 - v
        sleep(0.02)
Observation and tuning
If you see stepping, reduce step size or change delay. If one LED jitters under CPU load, try moving it to a hardware PWM pin for comparison.
Key Takeaway

Opposite fades illustrate how duty cycle proportions combine. Inverting values produces a smooth crossfade when tuned correctly.
