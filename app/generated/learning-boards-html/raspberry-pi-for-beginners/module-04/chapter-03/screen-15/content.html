Module 4 › Chapter 4.3 › What to Remember
Duty cycle
Percent on-time equals percent average power. Compute when troubleshooting brightness.
Servos
Position via pulse width in milliseconds; use mid, min, max helpers for reliable moves.
Hardware pins
GPIO 12, 13, 18, 19 for stable PWM when you need precision.
One-line summary

PWM manipulates time to simulate analog outputs. Balance convenience and precision by choosing software or hardware PWM appropriately.
