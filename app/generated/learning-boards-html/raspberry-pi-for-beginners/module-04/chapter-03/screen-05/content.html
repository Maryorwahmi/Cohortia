PWMLED examples

Two code patterns help you learn: a simple step demo and a smooth fade loop. Use a current-limiting resistor and test values slowly at first.
Simple demo
from gpiozero import PWMLED
from time import sleep

led = PWMLED(17)

led.value = 0.0
sleep(0.5)
led.value = 0.5
sleep(0.5)
led.value = 1.0
sleep(0.5)
Smooth fade
Loop from zero to one in small increments to create a pleasing fade. Adjust sleep to taste.
Fade loop
from gpiozero import PWMLED
from time import sleep

led = PWMLED(17)

while True:
    for b in range(0, 101):
        led.value = b / 100
        sleep(0.02)
    for b in range(100, -1, -1):
        led.value = b / 100
        sleep(0.02)
Common mistake

Skipping the resistor or using too-large step values causes visible stepping or risks hardware damage.
