Comparison

Hardware vs Software

Hardware PWM
Generated by dedicated circuitry on specific pins. Offers precise timing even when the CPU is busy.
Software PWM
Uses CPU to toggle pins and can be used on any GPIO pin. Timing may vary under load.
When to choose
Hardware for precision devices; software for simple LEDs and flexible pin choices.
Quick test
Run a CPU-heavy task while observing PWM. If output jitters, prefer hardware PWM.
Hardware PWM pins
GPIO 12, 13, 18, 19
Remember these four pins when you need steady, low-jitter signals for motors or precision servo control.
Misconception check
Software PWM isn't broken; it simply depends on the CPU. For many beginner projects it works fine and gpiozero hides the details.
Pro tip

Start with software PWM. If you see timing instability, move the signal to a hardware PWM pin.
