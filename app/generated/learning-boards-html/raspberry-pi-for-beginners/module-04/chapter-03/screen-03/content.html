Learning Objectives — Skills and checks

Concrete actions to verify competency
Practice checklist
1
Explain PWM
Describe duty cycle, frequency, and compute percent average power for a signal example.
Check: compute 25% duty → 25% average power.
2
Use PWMLED
Run a script that sets the value property to 0, 0.5 and 1 to see the LED response.
Check: brightness looks proportional to value.
3
Control Servo
Call min, mid, and max and observe positions; note pulse widths around one to two milliseconds every twenty milliseconds.
Check: mid centers the arm.
4
Identify PWM pins
Memorize GPIO 12, 13, 18, 19 as hardware PWM pins and practice explaining why they are preferred under heavy load.
Check: list those four pins from memory.
