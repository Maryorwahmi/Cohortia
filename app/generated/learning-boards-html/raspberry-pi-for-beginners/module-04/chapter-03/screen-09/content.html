Hardware PWM pins
The Raspberry Pi provides hardware PWM on four GPIO pins. Use these for stable, low-jitter signals.
GPIO 12
Hardware PWM channel available for precise timing.
GPIO 13
Paired hardware PWM pin for alternate channels.
GPIO 18
Common choice for PWM peripherals; stable under load.
GPIO 19
Another hardware PWM option; remember the set of four.
Practical notes
Start on any pin with software PWM. If timing becomes unstable under load or you need precise servo timing, move to a hardware PWM pin.
Power and noise
Keep power rails stable when using motors. Noise and shared supplies cause unpredictable behavior even with hardware PWM.
Key Takeaway

Remember GPIO 12, 13, 18, and 19 for hardware PWM when timing stability is essential.
