GPIO: programmable inputs and outputs
Pins present either a HIGH at 3.3 volts or a LOW at ground; software sets mode.
Key behaviors
  • Output: drives HIGH or LOW and can source or sink small current.
  • Input: reads external voltage and requires the signal be within 0 to 3.3 volts.
  • Some pins have pull-up or pull-down defaults to avoid floating inputs.
Concrete example
Set GPIO 17 as an output, write HIGH, and measure about 3.3 volts between the pin and ground with a multimeter.
Key Takeaway

Treat pins as logic-level signals, not power rails; always check mode and limits before wiring.

Common misconceptions
  • GPIO pins supply unlimited power like a wall adapter — false.
  • All pins are interchangeable — false; some pins have reserved roles or default pulls.
Check your understanding
If a pin configured as input reads floating values, add a pull-up or pull-down resistor or enable the internal pull option.
Practice: measure pin voltage in both modes with a meter.
