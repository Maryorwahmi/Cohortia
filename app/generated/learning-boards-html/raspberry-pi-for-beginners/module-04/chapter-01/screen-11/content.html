Module 04 › Chapter 4.1 › Pin Numbering
Pin numbering and gpiozero practice
Keep wiring and code aligned by choosing a numbering convention and sticking to it.
BOARD vs BCM
BOARD maps to physical header pin numbers; BCM maps to Broadcom GPIO labels. Mixing them creates mismatches.
gpiozero style
Use device objects like an LED class for readable control, keeping wiring details isolated from higher-level logic.
Practical tip
Label your breadboard or use colored wires for ground and power to reduce visual wiring errors.
