Module 04 › Chapter 4.2 › Key Concepts
Objects for devices
LED and Button wrap pin behaviour in friendly methods and attributes for clearer code.
BCM numbering
Code uses GPIO numbers by default. Confirm mapping to the physical header to avoid wiring errors.
Internal pull-ups
Pull-ups keep inputs in a known state so button presses reliably change the reading to ground (LOW).
Summary takeaway
Start simple: verify installation, run blink, read a button with polling, then refactor to events to build robust interactions.
