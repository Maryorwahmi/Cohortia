Comparison

BCM and BOARD numbering

Understand which numbering scheme your code is using so your wiring matches the software expectation.

BCM (chip GPIO)
References the GPIO pin as named by the Broadcom SoC. Example: GPIO 17 is LED(17).
BOARD (physical)
References the header pin location. Physical pin numbers differ from BCM names on many pins.
Common mistake
Mixing numbering schemes when following an online wiring diagram often produces silent failures.
Key Takeaway
Pick BCM for Python examples unless you have a diagram labeled with BOARD numbers and double-check the mapping before wiring.
Quick mapping example
If your code uses LED(17), find the header pin corresponding to GPIO 17. If you instead wire to physical pin 17, verify whether that pin is indeed GPIO 17 on your model — they are not the same on most Pi models.
Practical test
Temporarily run a quick script that sets a pin high and use a multimeter or a known-good LED to verify the header pin toggles as expected before finalising your wiring.
