Formative assessment

Ask and demonstrate the difference between immediate checks and event handlers.

Task A — Polling
while True:
    if button.is_pressed:
        print('pressed')
    sleep(0.1)
Explain when this runs and why the sleep matters.
Task B — Event
def on_press():
    print('pressed')

button.when_pressed = on_press
input('Enter to stop')
Explain callback assignment and why we don't call the function when assigning.
Common mistake
Writing button.when_pressed = on_press() calls the function immediately, instead of assigning it as a handler.
Key Takeaway
Require a short demo: student runs both patterns and explains the resource and clarity trade-offs.
