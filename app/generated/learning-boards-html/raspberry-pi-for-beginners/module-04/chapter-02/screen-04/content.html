Definition

Install and verify gpiozero

A short process to ensure your development environment is ready for GPIO work.

Step 1 — Check preinstalled
Open Thonny or the terminal and try import gpiozero in a Python 3 session. No error means you can continue.
Step 2 — Install if needed
If missing, run sudo apt install python3-gpiozero to install the library and its dependencies.
Step 3 — Confirm Python 3
Make sure Thonny or your terminal is using Python 3 so the package resolves correctly.
Common mistake
Running the install with plain python instead of python3 can leave you with the package in the wrong interpreter.
Code check
sudo apt install python3-gpiozero

# In Python REPL
from gpiozero import LED
print(LED)
Why this matters
  • Verifying import reduces wasted time on wiring problems that are actually software issues.
  • The library picks a backend automatically so you avoid manual driver choices on modern Pi models.
  • Using Python 3 consistently prevents package confusion between interpreters.
Key Takeaway
Confirm imports and interpreter before wiring hardware to streamline the lab session.
