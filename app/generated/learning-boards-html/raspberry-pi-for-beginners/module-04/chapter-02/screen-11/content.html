Module 04 › Chapter 4.2 › Pull-up Resistors
Definition

Why pull-ups matter

Pull-up resistors ensure the input reads a steady HIGH when the switch is open and cleanly reads LOW when pressed.

Idle state
Internal pull-up ties the pin to a known HIGH through a resistor so the value is stable when unpressed.
Pressed state
Pressing connects the pin to ground so the pin reads LOW. Button abstracts this so is_pressed is True on a press.
Common mistake
Assuming the raw HIGH/LOW maps directly to pressed/unpressed without understanding the pull-up can lead to inverted logic errors.
Simple wiring visual
GPIO pin —[internal pull-up]—> HIGH when open. Press connects pin to GND → LOW.
Key Takeaway
Rely on the internal pull-up for simple momentary switches and avoid floating inputs that cause unreliable behavior.
