Module 04 › Chapter 4.2 › Button Reading
Definition

Wiring and polling

Connect the switch between a GPIO pin and ground. gpiozero sets the pull-up so idle reads are HIGH.

from gpiozero import Button
from time import sleep

button = Button(2)

while True:
    if button.is_pressed:
        print("Button is pressed")
    else:
        print("Button is not pressed")
    sleep(0.1)
This loop prints the state and pauses to reduce CPU use. Short sleeps make the interface more responsive but cost more CPU cycles.
Wiring note
One terminal of the button to GPIO 2, the other to ground. gpiozero's internal pull-up keeps the pin at a defined HIGH when the button is open.
Common mistake
Wiring the button to 3.3V instead of ground reverses behavior and can short when pressed. Always route the other side to ground when using internal pull-ups.
Key Takeaway
Button objects save you from manually enabling pull-ups and provide an easy attribute for polling the pressed state.
