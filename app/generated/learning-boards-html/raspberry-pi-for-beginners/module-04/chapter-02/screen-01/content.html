Digital Outputs and Inputs with gpiozero

A practical introduction to controlling LEDs and reading buttons using gpiozero's object model on the Raspberry Pi.

Orientation

You will install or confirm gpiozero, run small scripts that control an LED, read a button, and refactor polling code into cleaner event-driven handlers. Expect hands-on wiring and a short troubleshooting checklist so you can get reproducible results on your Pi.

Explore Key Topics
Install
Confirm gpiozero or install with apt for Python3 on Raspberry Pi OS.
Output
Control an LED using LED.on, LED.off, or LED.blink methods.
Input
Read a button with is_pressed or assign when_pressed callbacks.
Visual Concept
LED object
LED(17) represents a physical LED wired to GPIO 17.
Button object
Button(2) uses an internal pull-up so idle reads are HIGH and press pulls to ground.
Key Takeaway
Think in objects: call methods for outputs, read attributes or attach events for inputs.
