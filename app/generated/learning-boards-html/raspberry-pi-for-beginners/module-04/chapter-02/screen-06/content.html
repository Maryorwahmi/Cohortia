Manual blink loop

A simple explicit loop shows how to change timing or combine other logic between toggles.

from gpiozero import LED
from time import sleep

led = LED(17)

while True:
    led.on()
    sleep(1)
    led.off()
    sleep(1)
Run this script and observe the LED flash every second. If it does not, re-check the wiring and pin numbering.
Key Takeaway
Use explicit loops for full control; use built-in blink for quick demos.
Simplified API

Using blink()

from gpiozero import LED
led = LED(17)
led.blink()

input("Press Enter to stop...")
blink runs in the background until you stop the program. This is handy for demonstrations and reduces boilerplate code.
Example scenario
Use blink() when showing hardware in a classroom. Use a loop when you want to sample sensors between flashes or react to inputs.
