Module 04 › Chapter 4.2 › Quick Reference
Outputs
Use LED.on, LED.off, LED.blink to express output behavior plainly.
Button wiring
Wire the switch between GPIO and ground so the internal pull-up yields stable readings.
Interaction pattern
Use polling to debug and events for production-like responsiveness.
Practical suggestion
Keep the verified milestone handy: wire LED to GPIO 17 and button to GPIO 2, then implement both polling and event-driven versions of the same behavior.
