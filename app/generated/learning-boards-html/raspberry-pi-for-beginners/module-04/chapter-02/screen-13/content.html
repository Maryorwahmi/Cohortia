Module 04 › Chapter 4.2 › Hands-on Activity
Process

Wire, test, iterate

  1. Power down the Pi and wire the LED with a resistor: anode to GPIO 17, cathode to GND.
  2. Wire the button: one terminal to GPIO 2 and the other to GND.
  3. Power up and run the blink script to verify the LED wiring.
  4. Run the polling script to observe button.is_pressed changes as you press and release.
  5. Run the event-driven toggle script and press the button to toggle the LED state.
Troubleshooting
If the LED doesn't light, double-check BCM pin mapping and resistor placement. If button readings are noisy, confirm the wiring to ground and check for bounce-related multiple triggers.
Starter code snippets
# Blink test
from gpiozero import LED
from time import sleep
led = LED(17)
while True:
    led.on()
    sleep(1)
    led.off()
    sleep(1)
Key Takeaway
Test one thing at a time: LED, then button, then combined behavior to isolate faults quickly.
