Learning Objectives

Progress from installation to event-driven inputs with verified checkpoints.

Bloom: Learn → Understand → Apply → Master
01
Install and import gpiozero

Confirm gpiozero on Raspberry Pi OS or install via apt for Python3. This gives you the high-level API for GPIO control.

VERIFIED COMPETENCY MILESTONE
02
Control LEDs and outputs

Use LED objects with methods like on, off and blink to show state changes physically and in code.

VERIFIED COMPETENCY MILESTONE
03
Read buttons and digital inputs

Create Button objects and read is_pressed or attach events to react to presses reliably thanks to internal pull-ups.

VERIFIED COMPETENCY MILESTONE
04
Understand Button vs DigitalInputDevice

Recognize Button as a convenience device with pull-up behavior and know that lower-level input classes exist when you need fine control.

VERIFIED COMPETENCY MILESTONE
