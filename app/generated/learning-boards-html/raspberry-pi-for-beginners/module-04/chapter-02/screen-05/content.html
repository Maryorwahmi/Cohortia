Core Concept

Components as objects

Encapsulate pin behaviour with device objects so your code maps to physical things you build.

LED object
LED(17) provides on, off and blink methods that abstract the pin-level writes needed to light an LED.
Button object
Button(2) exposes is_pressed and event attributes. gpiozero sets up recommended pull resistors for you.
Misconception
gpiozero doesn't remove the need for correct wiring; it simplifies code by wrapping pin operations in friendly methods.
Concrete examples
from gpiozero import LED
led = LED(17)
led.on()
# wait then
led.off()
Analogy
Think of device objects as remote controls for hardware: they expose the buttons you need rather than exposing internal wiring details.
Key Takeaway
Use device objects so your code reads like instructions to physical parts: clearer, shorter, and easier to maintain.
