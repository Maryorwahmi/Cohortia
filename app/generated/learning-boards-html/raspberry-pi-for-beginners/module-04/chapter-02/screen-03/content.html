Practical Checklist

Follow these measurable steps when you wire and code.

1. Confirm installation

Run the apt install command if needed, or open Thonny and import gpiozero to ensure the library is present.

2. Wire the LED

Connect LED to GPIO 17 and the correct resistor to ground. Create LED(17) in Python and call on and off to observe behavior.

3. Wire the button

Connect one side of the momentary switch to GPIO 2 and the other to ground. Create Button(2) and test is_pressed to read state.

4. Test polling and events

Run a polling loop and then refactor to when_pressed callbacks to compare CPU usage and code clarity.

Verified Milestone
Build the LED-on-GPIO17 and button-on-GPIO2 circuit and write a script that toggles the LED on each button press.
