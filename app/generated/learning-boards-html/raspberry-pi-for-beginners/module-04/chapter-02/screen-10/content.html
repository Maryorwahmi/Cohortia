Code Walkthrough

Toggle LED on press

from gpiozero import LED, Button

led = LED(17)
button = Button(2)

def toggle_led():
    led.toggle()

button.when_pressed = toggle_led

input("Press Enter to exit...")
Run this and press the button repeatedly. Each press causes the function to run and toggle the LED state.
Pro tip
If you see multiple toggles per press, account for mechanical bounce by adding a short delay or using gpiozero's built-in debounce settings where available.
Example scenario
Use this toggle pattern for mode switches: press to move between states like on, off, and a blink pattern without holding the button.
Key Takeaway
Event handlers make interactive behavior concise and keep the main loop free for other tasks.
