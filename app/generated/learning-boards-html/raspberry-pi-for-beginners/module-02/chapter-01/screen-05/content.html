Prompt anatomy
User, host, working directory, and privilege indicator form a short safety snapshot before you run commands.
Why it matters
Knowing where commands run prevents accidental damage and helps you target the correct files for copying or deletion.
Misconception
Seeing a dollar sign does not guarantee safety: you could still be in a system folder owned by your user account. Confirm the directory explicitly first.
Check
Habit: glance at prompt, run the current-directory command to confirm, then execute file changes.
Visual callout
Prompt example (visual only)
alex@raspberrypi:~ $
Try out loud
Say each part of the prompt aloud: username, device, and current directory. That reinforces checking before acting.
