Module 2 › Chapter 2.1 › pwd & ls
Commands to confirm and inspect
Check your working directory and use list options to reveal hidden files and detailed attributes.
Visual examples (type these in your terminal)
# prints the current directory
alex@raspberrypi:~ $ pwd
/home/alex

# list with details and hidden files
alex@raspberrypi:~ $ ls -la
total 20
drwxr-xr-x 4 alex alex 4096 Jun 1 10:00 .
# ...
Explanation & checklist
  • Always run the print-directory command before destructive actions to confirm context.
  • Use list with the long option to read permissions, sizes, and modification times.
  • When you expect configuration or hidden files, include the option to show hidden entries.
  • Combine options when you want both detail and hidden files in one view.
Key Takeaway
Confirm your location and inspect files with detail and hidden flags before changing anything.
