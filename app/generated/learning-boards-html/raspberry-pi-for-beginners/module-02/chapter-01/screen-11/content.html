Comparison: remove vs move backup
Removing deletes data. Moving to a backup folder preserves a copy you can restore.
Safer pattern
List files first, copy important files to a backup folder, then remove only the intended targets.
Common mistake
Using recursive removal with broad patterns can remove system or personal files unintentionally.
Example workflow
Visual only
# list and inspect
alex@raspberrypi:~/linux_practice $ ls -la
# move to backup folder first
alex@raspberrypi:~/linux_practice $ mv file1.txt ../backups/
# then remove only what you intend
alex@raspberrypi:~/linux_practice $ rm file2.txt
Check your plan
Before removing, ask: Have I listed the files? Is there a backup? Am I in the expected directory?
