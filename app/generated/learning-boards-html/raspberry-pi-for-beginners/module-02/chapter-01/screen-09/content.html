Module 2 › Chapter 2.1 › mkdir & touch
Create directories and files
Use a folder for practice and create empty files to test copy and rename operations safely.
Example sequence (visual only)
alex@raspberrypi:~ $ mkdir linux_practice
alex@raspberrypi:~ $ cd linux_practice
alex@raspberrypi:~/linux_practice $ touch file1.txt file2.txt file3.txt
alex@raspberrypi:~/linux_practice $ ls -la
Notes & tips
  • Use a single create-file command to make multiple empty files at once by listing names.
  • mdir can create nested folders when you include the option to create parents automatically.
  • Empty files are perfect test objects; they won't hold secrets and are easy to remove.
Key Takeaway
Create a dedicated practice folder in your home and populate it with empty files to learn safely.
