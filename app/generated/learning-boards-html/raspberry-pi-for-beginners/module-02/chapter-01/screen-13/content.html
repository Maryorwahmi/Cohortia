Module 2 › Chapter 2.1 › Tab Completion & History
Type less, do more
Tab completion completes names and shows choices. History lets you find and rerun previous commands.
Tab completion
Start typing a name and press Tab. If one match exists it completes; if many exist it lists options to choose from.
History
Use the history command or keyboard shortcuts to search and rerun earlier commands without retyping them.
Practice
Visual hints
# type 'no' then press Tab to complete 'notes.txt'
# use history to find recent copy commands
alex@raspberrypi:~/linux_practice $ history | grep cp
Key Takeaway
Learn a few keyboard shortcuts and use tab completion plus history to work with speed and accuracy.
