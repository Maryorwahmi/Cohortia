Module 2 › Chapter 2.1 › Options & Flags
What options do
Options let you request more detail or change how a command behaves. Combine them thoughtfully and test first.
Combine options
You can pass multiple options together; for listing, combined options show both hidden entries and long details at once.
Test before change
When exploring an unfamiliar option that may modify files, try a read-only variant first to see the effect.
Example
Visual only
# combined options give more insight
alex@raspberrypi:~/linux_practice $ ls -la
# -l shows details, -a shows hidden files
Key Takeaway
Combine flags to tune commands, but always test on safe examples first to confirm behavior.
