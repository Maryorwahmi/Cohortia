Module 2 › Chapter 2.1 › Filesystem Layout
Tree structure
Root is written as slash. Home is where user folders live. System folders are separate branches that provide services and binaries.
Common folders
Examples include bin for essential programs, etc for configuration, usr for installed packages, var for variable data, and home for user files.
Tip
Keep practice folders in home. Avoid creating files directly under root or system directories unless you need administrative access.
Hierarchy visual (cards)
/
Root — top of the tree. Contains system folders and home.
/home
Users' directories. Each user has a subfolder here where their files live.
~/
Tilde indicates your home folder in the prompt and in path shortcuts.
Try
When you create linux_practice, create it inside home so it's easy to find and safe to remove later.
