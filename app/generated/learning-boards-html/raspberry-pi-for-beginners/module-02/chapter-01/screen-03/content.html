Module 2 › Chapter 2.1 › Practice & Safety
Guided practice sequence
A short, repeatable set of commands builds muscle memory and safety awareness.
Step 1 — Create a practice folder
Make a directory called linux_practice and move into it. This keeps experiments isolated from important files.
Step 2 — Create three files
Create simple empty files to observe how listing and renaming behave.
Step 3 — List, rename, copy, remove
List with details, rename one file, copy it to a backup, and remove the original if needed — always check the prompt first.
Safety mnemonic
Remember P-C-V: Prompt, Current folder, Verify. Check the prompt, confirm the working directory, and verify filenames before deletions.
