Module 2 › Chapter 2.1 › Terminal & Shell
Definition and role
The terminal provides the interface; the shell interprets commands and communicates with the operating system kernel.
Concrete example
When you SSH into a Pi from another computer, you open a terminal and interact with Bash. There is no graphical desktop, so the shell is your control layer.
Common misconception
The terminal does not execute commands itself; it only displays input and output. The shell executes and provides features like completion and history.
Key takeaway
Learning shell features unlocks automation and headless administration on the Pi.
Analogy
Think of the terminal as a telephone and the shell as the person on the other end who follows your spoken instructions.
Example terminal snippet (visual only)
alex@raspberrypi:~ $  # prompt shows user, host, directory, and prompt symbol
Try this
Open a terminal on your Pi and notice the prompt. Say the user and folder out loud to build awareness before running commands.
