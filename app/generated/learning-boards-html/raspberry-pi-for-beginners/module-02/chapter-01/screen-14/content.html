Terminal & Shell
Terminal is the interface; the shell interprets commands. Together they enable scripting and headless access.
Read the Prompt
User, host, directory, privilege symbol — check them to avoid surprises before running commands.
Home vs Root
Use your home directory for practice; avoid system directories unless you have a specific reason and permissions.
Quick takeaway
Build habits: check the prompt, confirm the working directory, and keep experiments in home.
