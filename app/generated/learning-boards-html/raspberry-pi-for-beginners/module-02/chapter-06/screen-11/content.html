Scheduling with cron
Use crontab to add scheduled entries that run commands at specific times.
crontab -e
# Example: run backup at 03:00 daily
0 3 * * * /home/alex/backup.sh
Tip: redirect output to a log file so you can verify runs later, for example append standard output and error to a timestamped log.
Example
An hourly system check can be scheduled and its output appended to a persistent log so you can inspect system state over time.
Common pitfall
Cron provides a minimal environment. Always use absolute paths and perform any environment setup inside the script to avoid missing commands or variables.
Key Takeaway

Use crontab to schedule jobs and make scripts self-contained so they run reliably under cron's limited environment.
