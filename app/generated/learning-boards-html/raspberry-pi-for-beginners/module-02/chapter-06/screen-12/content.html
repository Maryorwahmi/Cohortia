The five fields
Each field narrows when a job runs. Use wildcards or step values for repeated schedules.
Minute
Hour
Day of month
Month
Day of week
Practical examples
0 3 * * * /home/alex/backup.sh — runs daily at 03:00 */10 * * * * /home/alex/check_temp.sh — runs every 10 minutes @reboot /home/alex/startup-script.sh — runs once at system startup
Common error: putting fields in the wrong order. If a job doesn't run when expected, verify each position corresponds to the correct time unit.
Key Takeaway

Learn the five positions and test schedules by logging output so you can confirm runs.
