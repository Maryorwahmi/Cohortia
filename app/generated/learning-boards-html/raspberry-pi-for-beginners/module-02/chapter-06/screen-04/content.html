Module 3 › Chapter 2.6 › What is a shell script?
Core idea
Capture commands in a file so you can run them later or repeatedly without typing.
#!/bin/bash echo "Hello, Raspberry Pi!" echo "Today is $(date)"
Why it matters
  • Automates repetitive maintenance tasks like backups and checks.
  • Makes procedures reproducible and shareable across devices.
Example
Create hello.sh, add the shebang and two echo lines, run chmod +x, then run ./hello.sh to see the greeting and date.
Common misconception
Some learners assume scripts must be long or complex. Small scripts are valuable: a two-line script that logs a date is already automation.
Key Takeaway

A script packages commands into a repeatable program you can run and schedule.
