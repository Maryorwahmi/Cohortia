Repeat with for
Loop over items or numbers to perform a repeated action without copying lines.
for i in 1 2 3 4 5; do
  echo "Count: $i"
done
Example
Use a for loop to iterate over a short list of files or a sequence of numbers when you need repeated checks or reports.
Gotcha
When iterating filenames, be careful with names that include spaces. Quoting and safe patterns help avoid broken loops.
Key Takeaway

For loops eliminate repetitive typing by running the same commands for each item in a list.
