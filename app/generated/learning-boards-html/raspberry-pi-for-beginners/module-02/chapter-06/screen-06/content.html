Module 3 › Chapter 2.6 › Variables & Command Substitution
Storing values
Assign a value and reference it later so the script is easier to update and reuse.
USER_NAME="Alex"
echo "Hello, $USER_NAME!"
Command substitution runs a command and inserts its output where needed. Use it to include dynamic data like the current date.
Concrete example
echo "Today is $(date)" prints a line that includes the system date at the moment the script runs.
Misconception
Variables set in a script do not persist across separate runs unless you write them to a file or export them into a persistent environment.
Key Takeaway

Use variables and command substitution to make scripts adaptable and informative.
