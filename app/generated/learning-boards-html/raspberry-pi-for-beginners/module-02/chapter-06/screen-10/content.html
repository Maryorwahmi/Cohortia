Repeat while a condition is true
Use while loops when the number of repetitions depends on changing state.
count=1
while [ $count -le 5 ]; do
  echo "Count: $count"
  count=$((count + 1))
done
Example
A loop that polls a sensor value, sleeps a short time between checks, and exits when a threshold is reached.
Common mistake
Forgetting to change the condition or add a sleep can produce an infinite loop that consumes system resources.
Key Takeaway

Ensure while loops include a clear termination condition and, when appropriate, a short sleep to pace checks.
