Module 3 › Chapter 2.6 › Accepting Arguments
Positional parameters
Pass values when you run the script so the same script can handle different inputs without editing.
echo "First argument: $1"
echo "Second argument: $2"
Example
Run the script with two words after the filename. The script will print those words so you can verify arguments are passed correctly.
Validation tip
Check for required arguments and show a usage message if they are missing. This prevents silent failures when scripts expect input.
Key Takeaway

Arguments let one script handle many cases; always validate inputs to avoid mistakes.
