If / Elif / Else pattern
Make decisions based on input values so your script can act differently in different modes.
if [ "$1" = "start" ]; then
  echo "Starting..."
elif [ "$1" = "stop" ]; then
  echo "Stopping..."
else
  echo "Usage: script.sh start|stop"
fi
Concrete example
Run with start to see the starting message, run with stop to see the stopping message, and run with no argument to see the usage line.
Common mistake
Unquoted parameters can break the test when values are empty or contain spaces. Always quote parameters in conditionals to avoid syntax errors.
Key Takeaway

Use conditionals to make scripts responsive to input and to provide helpful usage messages.
