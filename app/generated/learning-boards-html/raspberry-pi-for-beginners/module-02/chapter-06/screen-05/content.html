Module 3 › Chapter 2.6 › Shebang & Executable
Shebang
Identifies the shell interpreter so your script runs with predictable behavior.
#!/bin/bash
echo "Hello, Raspberry Pi!"
Make executable
Run the permission command to add execute permission to your script. Then execute using the path to the file so the shell runs that script rather than searching PATH.
Example walkthrough
Create hello.sh with a shebang. Run the permission command to make it executable. Run dot-slash hello.sh and observe the greeting and date output appear.
Common mistake
Forgetting to set the execute permission is the most common reason a script won't run as expected. Also check the shebang path matches an installed interpreter on your system.
Key Takeaway

A shebang plus execute permission makes a text file run reliably as a script.
