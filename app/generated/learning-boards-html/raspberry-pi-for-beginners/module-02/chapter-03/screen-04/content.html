Module 2 › Chapter 2.3 › Users and least privilege
Definition

User accounts and permissions

A user is an identity on the system with assigned groups and permissions. Least privilege means limiting rights to only what that user needs.

Concrete example
Create a guest account for visitors and keep administrative access off that account. The guest can browse files in their home directory but cannot install packages or change network settings.
Common mistake
A frequent error is assuming group changes are immediate. The user must re-login for the updated group membership to apply.
Key Takeaway

Limit privileges by default. Create separate accounts for different roles and verify group membership after changes.

Terminal reference
# create a user (visual example shown in terminal)
adduser guest
# add the user to the administrative group
usermod -aG sudo guest
# check groups for a user
groups guest
Explanation bullets
  • Adding to the administrative group allows elevated commands when the user authenticates.
  • The append option preserves existing group memberships while adding a new one.
  • Always verify with a group listing and expect to re-login to see the change in effect.
