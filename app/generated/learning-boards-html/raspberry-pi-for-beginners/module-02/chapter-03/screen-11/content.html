Module 2 › Chapter 2.3 › Quick system checks
Useful commands
# memory in human readable form
free -h

# disk usage per filesystem
df -h

# Raspberry Pi CPU temperature
vcgencmd measure_temp

# uptime and load averages
uptime
Interpreting results
  • Memory low and active swapping indicates a need to reduce memory usage or add swap.
  • Disk near full can prevent applications from writing files and cause failures.
  • High temperature may lead to throttling; check cooling and load patterns.
  • Load averages represent runnable tasks over time, not direct CPU percentage.
Practical check
Run the four commands in sequence after a workload to correlate resource spikes with temperature and uptime.
Key Takeaway

Short, repeatable checks yield a clear picture quickly. Combine them rather than relying on a single metric.
