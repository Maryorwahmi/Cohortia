Module 2 › Chapter 2.3 › Groups & sudo
Hierarchy
System user accounts (identities)
Groups (collections of users specifying capabilities)
Privileges enabled for group members by the elevation tool
Groups give administrators an easy way to grant and revoke elevated capabilities without modifying each user's files. The typical workflow is to append a user to an administrative group and then verify membership.
Checks and validation
After changing groups, instruct the user to re-login. Running a group listing confirms membership. Attempting an elevation that prompts for the password verifies the capability works.
Misconception
Group edits do not update already-running shells. Expect to start a new session to pick up changes.
Key Takeaway

Use groups to grant capabilities; verify by re-login and a small privileged test.
