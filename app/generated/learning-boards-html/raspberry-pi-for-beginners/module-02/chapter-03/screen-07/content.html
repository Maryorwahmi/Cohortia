Module 2 › Chapter 2.3 › What is a process?
Definition & behavior

A process owns memory and CPU time. The operating system schedules processes and tracks their resource use. Processes are identified by numeric IDs so you can act on a specific instance.

Key points
  • Snapshot listings give one-time details about all running processes.
  • Live monitors update and sort to highlight the largest resource consumers.
  • Use the process ID for precise operations, not just the name.
Example listings
# snapshot listing example
USER     PID %CPU %MEM COMMAND
pi       1024  0.1  1.2 /usr/bin/python3
root     781   0.0  0.4 /sbin/cron
If you need to stop a misbehaving instance, identify its PID and act only on that PID. This prevents accidentally terminating other instances of the same program name.
Key Takeaway

Treat each running program as an individual unit identified by its process ID. Use snapshot and live tools together to diagnose behavior accurately.
