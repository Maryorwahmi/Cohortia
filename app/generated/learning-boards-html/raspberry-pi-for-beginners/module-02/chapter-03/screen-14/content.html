Module 2 › Chapter 2.3 › Key Concepts
Snapshot vs live
Use ps for records and top or htop for watching activity in real time.
Start vs enable
Start changes runtime state now; enable configures the service to start on the next boot.
Combined health checks
Run memory, disk, temperature, and uptime together to correlate symptoms and causes.
Final thought: the next time the Pi is slow, run a short sequence of the checks you learned and observe which one changes when you apply a fix.
