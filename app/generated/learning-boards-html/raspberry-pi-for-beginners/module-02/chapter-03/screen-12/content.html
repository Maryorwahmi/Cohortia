Module 2 › Chapter 2.3 › Hands-on activity
Steps
  1. Create a new user for testing and set a secure password.
  2. Optionally append the user to the administrative group if they need elevated tasks.
  3. Open a new session as that user and run a group listing to confirm membership.
  4. List processes and use a pipeline search to find a program instance and note its PID.
  5. Open a live monitor to watch the system while you run a short workload.
  6. Run memory, disk, temperature, and uptime checks to correlate results.
Troubleshooting checks
If the new group does not appear, ensure the user restarted their login session. If your process search returns many matches, refine the search string. If a service fails to start, inspect status output and recent logs for errors.
# example verification commands
# list groups for the user
groups guest

# snapshot of all processes
ps aux | grep some_program

# quick health checks
free -h && df -h && uptime
Key Takeaway

Follow the sequence create, verify, inspect, and monitor to make accurate, low-risk changes and to catch issues quickly.
