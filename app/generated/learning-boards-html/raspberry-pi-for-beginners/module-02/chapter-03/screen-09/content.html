Module 2 › Chapter 2.3 › Pipes and grep
Pattern

Produce a full listing and filter it with a search to show only relevant lines. This narrows down candidates so you can identify a PID safely.

# list all processes and filter for a program name
ps aux | grep python
Inspect the left columns for user and PID, and the right columns for the actual command to avoid false matches.
Common pitfalls
  • Short search terms can match unrelated commands; include a longer substring for precision.
  • Some search results include the search process itself; ignore entries that reflect your search tool running.
  • Always act on the PID rather than the command name to avoid killing unrelated instances.
Pro tip

Combine a listing with a timestamped log or redirect output to a file if you need to capture results for later analysis.
