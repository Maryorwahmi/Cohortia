Learning Objectives

What you will be able to do after this chapter.

01
Understand user accounts
Know why least privilege matters and how it limits risk.
You will explain why day-to-day work should use a normal user and how elevating only when needed reduces accidental damage or exposure.
VERIFIED COMPETENCY MILESTONE
02
Create and manage users
Add and remove accounts, and assign group memberships for permissions.
You will create a user and add them to an administrative group, then verify group membership with a group listing.
VERIFIED COMPETENCY MILESTONE
03
View and find processes
List processes, use live monitors, and locate a target process using pipes.
You will inspect active processes with listing tools and use a search pipeline to find a specific program when troubleshooting.
VERIFIED COMPETENCY MILESTONE
04
Manage services and monitor health
Control services and read memory, disk, temperature, and uptime metrics.
You will start and enable services to run on boot, and gather quick health checks with memory, disk, and temperature commands.
VERIFIED COMPETENCY MILESTONE
