Module 2 › Chapter 2.3 › Create & manage users
Command walkthrough
A terminal-first example shows the typical sequence you will run.
$ adduser guest
# follow prompts to set a password and info

$ usermod -aG sudo guest
# append guest to the administrative group

$ groups guest
# verify memberships
Explanation
  • The creation command sets up a home folder and prompts for a password.
  • The append option preserves prior groups while adding a new one.
  • Always verify group membership and ask the user to re-login if changes are not visible.
Concrete scenario
You need to set up a temporary account for a workshop attendee. Create the account, append them to the admin group only if required, and verify groups before the workshop starts.
Common mistake
Using an option that replaces all groups may remove required permissions. Use the append form to avoid this.
Key Takeaway

Create, append, and verify — that order avoids accidental permission loss and ensures the account behaves as expected.
