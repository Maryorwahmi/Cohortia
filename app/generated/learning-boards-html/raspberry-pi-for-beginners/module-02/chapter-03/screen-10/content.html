Module 2 › Chapter 2.3 › systemctl & services
Common commands
# check service status
systemctl status ssh

# stop a service
systemctl stop ssh

# start a service
systemctl start ssh

# enable on boot
systemctl enable ssh

# disable on boot
systemctl disable ssh
Concepts
  • Status gives runtime information and recent log excerpts.
  • Stop and start change the current runtime only.
  • Enable and disable change boot-time behavior, not current runtime.
Scenario
You notice a service failing at boot. Enable it to ensure it should run, then inspect status and recent logs to diagnose why it failed to start.
Key Takeaway

Think of start/stop as immediate actions and enable/disable as configuring behavior for the next boot.
