Module 2 › Chapter 2.3 › Practical checks
Account verification
Create a user, then run a group listing to confirm membership. If changes don't appear, log out and back in.
Process checks
Run a snapshot listing and a live monitor while you start a program to observe CPU and memory spikes.
Service checks
Query status, stop and start a service, then enable it to persist across reboots so you can confirm boot behavior.
Resource checks
Run the quick memory, disk, temperature, and uptime checks and note values before and after a workload.
Key Takeaway

Verification steps are short commands you can repeat to confirm behavior and catch timing issues like the need to re-login after group changes.
