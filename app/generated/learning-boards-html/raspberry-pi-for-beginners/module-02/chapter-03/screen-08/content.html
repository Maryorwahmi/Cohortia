Module 2 › Chapter 2.3 › ps / top / htop
ps (snapshot)
Outputs a one-time list of processes suitable for piping and saving. Use it to create an audit or run searches.
Example: run a full listing then pipe to a search to find instances.
top (live)
Live, scrolling display that updates resource usage and shows load averages. Good for ongoing observation.
Example: open during a workload to spot the highest CPU processes.
htop (friendly live)
A more readable live monitor with clearer columns and easier navigation; install if you prefer interactive selection.
Example: use htop to scroll, select a process, and display full command lines.
Practical workflow
Use ps to create a record and find suspect PIDs, then switch to top or htop to observe behavior while reproducing an issue.
Common misconception
Relying on a live monitor alone may miss short spikes; take a snapshot right after reproducing the event to capture exact numbers.
