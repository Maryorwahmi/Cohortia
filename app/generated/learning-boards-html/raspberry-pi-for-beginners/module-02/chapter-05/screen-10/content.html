Module 2 › Chapter 2.5 › Find & Read Docs
Locate commands
  • which: prints the path to the executable your shell will run.
  • whereis: searches standard locations for binaries, source and manual pages.
Read documentation
Use man to view full manual pages. If a man page is missing, try the command's --help to get usage and common flags.
Key Takeaway

Combine which, whereis and man to locate executables and learn their options before scripting or automating.

Terminal examples (visual)
$ which python3
/usr/bin/python3

$ whereis python3
python3: /usr/bin/python3 /usr/lib/python3

$ man ls  # read manual, press q to quit

$ ls --help  # quick usage
Use which to confirm the exact binary used in scripts. Use man to understand flags and behavior so automation behaves as you expect.
Misconception check
Do which and whereis always show the same path? Not necessarily — which reflects PATH order, whereis searches common directories.
