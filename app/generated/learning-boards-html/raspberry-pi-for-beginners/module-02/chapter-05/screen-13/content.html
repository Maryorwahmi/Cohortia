Module 2 › Chapter 2.5 › Key Concepts
apt & repositories
Repositories provide curated packages; update refreshes the index so apt can find the latest versions.
Install, remove, purge
Use install to add, remove to uninstall, purge to delete config, and autoremove to clear unused dependencies.
.deb & dpkg
Install vendor packages with dpkg, then run apt --fix-broken install to resolve dependencies from repositories.
Summary takeaway
Follow update → install → verify → tidy. Use the right tool for the scope and always verify that installed software runs and is located where you expect.
