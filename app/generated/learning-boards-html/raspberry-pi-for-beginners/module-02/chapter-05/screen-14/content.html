Module 2 › Chapter 2.5 › Quick Reference
Before you install
Always run update so apt knows the latest package versions before installing or upgrading.
Clean up
Use remove, purge, and autoremove appropriately to keep the system tidy and recover disk space.
Repair .deb installs
After dpkg, run apt --fix-broken install to let apt resolve and fetch missing dependencies from repositories.
Bottom line
Follow the update, install, verify, tidy loop and use the right tools for the job to avoid conflicts and broken installs.
