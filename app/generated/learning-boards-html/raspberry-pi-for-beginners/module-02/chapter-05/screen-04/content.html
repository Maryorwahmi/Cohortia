Module 2 › Chapter 2.5 › What is apt
Definition

Apt is the package management interface that consults remote repositories containing pre-compiled packages and dependency information. It automates download, install, upgrade and removal operations for system software.

How repositories help
  • Provide curated and versioned packages for consistent installs.
  • Supply dependency metadata so apt can fetch required libraries.
  • Allow centralized security updates through apt upgrade.
Key Takeaway

Apt relies on repositories to supply tested packages; updating the list is the first step before installing or upgrading.

Terminal example (visual only)
$ sudo apt update
Hit:1 archive ...
Reading package lists... Done
This output tells apt it refreshed the index. No packages were installed yet; the system now knows the latest available versions.
Analogy
Think of repositories as an app store catalogue and apt as the client that reads that catalogue to download and install approved apps for the system.
