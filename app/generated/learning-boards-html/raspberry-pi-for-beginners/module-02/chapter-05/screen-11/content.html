Module 2 › Chapter 2.5 › Hands-on Activity
Step-by-step checklist
  1. Run update to refresh indexes and check for errors.
  2. Install htop, neofetch and git in a single install command.
  3. Open htop to observe processes and confirm it runs.
  4. Remove neofetch, then run autoremove to clear dependencies.
  5. If you installed a .deb, run apt --fix-broken install to resolve dependencies.
Reflection prompts
After the activity, ask: where is the executable located? Did autoremove reclaim packages? Were there any broken dependencies to fix?
Terminal walkthrough (visual)
# Update index
sudo apt update

# Install three packages at once
sudo apt install htop neofetch git

# Run and verify
htop

# Remove one package and tidy
sudo apt remove neofetch
sudo apt autoremove
Safety note
Run these commands on a Pi where you have permission and understand the impact. Read prompts before confirming if you are not using the automatic yes flag.
