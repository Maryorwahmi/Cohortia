Module 2 › Chapter 2.5 › .deb & dpkg
When to use .deb files

Use a downloaded .deb when the software vendor provides a package not available in the repositories, or when you require a specific build version.

Repairing with apt

If dpkg reports missing dependencies, run apt --fix-broken install to let apt fetch and install the required packages from your repositories.

Common mistake

Relying on dpkg alone for dependency resolution. Always follow with apt to fix and fetch missing libraries.

Terminal sequence (visual)
$ sudo dpkg -i package-name.deb
(installation output)
# if errors about missing packages
$ sudo apt --fix-broken install
Follow the dpkg install with apt to resolve dependencies. This two-step flow avoids broken packages on the system.
Analogy
Think of dpkg as unpacking a box you got in the mail. If the box needs extra parts, apt fetches those parts from the store so the item works correctly.
