Module 2 › Chapter 2.5 › Install & Remove
Typical install workflow
  1. Refresh the package index with update.
  2. Install desired packages with install and list names separated by spaces.
  3. Verify the program runs and find its location.
Removal options
  • remove: uninstalls binaries but keeps configuration files.
  • purge: removes package and configuration files.
  • autoremove: deletes dependencies no longer required.
Key Takeaway

Choose remove or purge depending on whether you want to keep configuration, and run autoremove to reclaim space.

Terminal demo (visual)
$ sudo apt install nano htop
...
$ htop  # run to check
$ sudo apt remove htop
$ sudo apt autoremove
Practice installing multiple packages in a single command, then run the program and remove it to observe cleanup behavior.
Common mistake
Expecting complete cleanup without purge. If configuration files remain, use purge to remove them as well.
