Module 2 › Chapter 2.5 › Dependencies & Repair
What are dependencies?

Dependencies are other packages or libraries that a program needs. Apt uses dependency metadata to fetch required packages automatically when installing from repositories.

Repair command

Running apt --fix-broken install instructs apt to examine broken package states and download any missing dependencies so the system returns to a consistent state.

Key Takeaway

When dpkg reports missing libraries, use apt --fix-broken install to let the package manager resolve and fetch the missing pieces.

Troubleshooting example
You install a .deb and see dependency errors. Instead of manually locating packages, run the repair command to fetch the correct versions from your repositories and ensure compatibility.
Pro tip
Run apt update before running fix-broken so apt can find the required dependency packages in the freshest index.
