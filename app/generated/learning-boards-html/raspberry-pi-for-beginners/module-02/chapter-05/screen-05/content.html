Module 2 › Chapter 2.5 › Update vs Upgrade
Step definitions
  • Update: refresh the package index so apt knows available versions.
  • Upgrade: apply available newer versions for installed packages.
  • Combine: use logical sequencing so upgrade runs only if update succeeds.
Common command patterns (visual)
sudo apt update && sudo apt upgrade -y
The && operator runs the second command only if the first completes successfully. The -y flag answers yes to prompts automatically.
Illustrative scenario

Imagine you want to install an updated driver. If you skip update, apt may use an old index and install a package that conflicts with other packages. Running update first ensures apt will consider the correct dependency graph before upgrading.

Common mistake

Treating update as an upgrade. Remember: update refreshes metadata; upgrade changes installed files.
