Package Management and Software Installation
Manage system packages, install downloaded .deb files, and distinguish system vs Python packages.
Why this matters

Keeping packages up to date prevents bugs and security issues. Installing correctly avoids broken dependencies, and knowing where a command lives helps debugging and automation.

In this lesson
You will practice apt update and install, read man pages, and install a downloaded .deb safely.
