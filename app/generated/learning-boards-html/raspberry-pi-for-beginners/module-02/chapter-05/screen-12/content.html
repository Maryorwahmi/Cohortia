Module 2 › Chapter 2.5 › Assessment
Question

Explain the difference between updating the package list and upgrading installed packages. Then describe the steps you would take when dpkg reports missing dependencies after installing a downloaded .deb.

Rubric
  • Clear definition of update vs upgrade.
  • Repair steps: apt update, apt --fix-broken install, verify program runs.
  • Verification: use which and man to confirm path and usage.
Sample feedback
Look for learners who describe update as metadata refresh and upgrade as file changes, use apt --fix-broken to resolve missing dependencies, and demonstrate verification steps using which or opening the installed program.
Wrap-up
This assessment checks both conceptual understanding and practical troubleshooting — two essential abilities for managing a Raspberry Pi reliably.
