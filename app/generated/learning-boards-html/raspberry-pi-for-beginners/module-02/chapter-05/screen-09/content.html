Module 2 › Chapter 2.5 › apt vs pip
System packages (apt)
Installed system-wide, placed in standard paths, and managed by the OS-level package manager. Suitable for shared utilities and core libraries.
Python packages (pip)
Installed into Python environments; best used inside virtual environments for project isolation to avoid clashing with system packages.
Common mistake

Installing a Python package system-wide with pip can overwrite system-managed files and create conflicts. Prefer virtual environments for project dependencies.

Concrete scenario

If you need a Python library for a single project, create a virtual environment and use pip there. If you need a system tool available to all users, install it with apt so it integrates with system paths and service managers.

Quick rule
Scope decides the tool: system-wide → apt; project-specific Python → pip (inside virtual env).
