Verification checklist
  • Refresh package index and confirm no errors during update.
  • Install htop and open it to observe processes.
  • Remove neofetch and run autoremove to tidy dependencies.
  • Install a .deb and run apt --fix-broken if needed.
  • Use which and man to find and read documentation for installed commands.
Common quick checks
Did the install print errors?
Can you run the program?
Was a new binary created in /usr/bin or /usr/local/bin?
Are leftover packages present after removal?
Micro-mnemonic
Update → Install → Verify → Tidy. Repeat before large changes.
