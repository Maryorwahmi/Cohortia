Symbolic syntax
who (u/g/o/a), operator (+/-/=), permissions (r/w/x)
Examples
chmod u+x script.py — add execute for owner.
chmod go-w notes.txt — remove write for group and others.
chmod a+r document.txt — add read for everyone.
Process
1. Inspect with ls -l. 2. Decide minimal change. 3. Run chmod symbolic. 4. Verify with ls -l.
Misconception
Using equals sets the full set for that who field and can remove permissions you didn't intend to change. Use plus or minus to adjust bits safely.
Try this

Try adding execute to a script with chmod u+x and confirm you can run it. If it still fails, check the file's shebang or interpreter and whether you invoked it correctly.
