Owner, Group, Others
Definition and how they map to permission sets.
Owner
User who created or was assigned the file; owner permissions apply to them.
Group
Named team that can be given shared access using the group permission bits.
Others
All other users on the system who are neither the owner nor in the file's group.
Example
If alex:staff owns notes.txt and perms are -rw-r-----, alex can read/write, staff can read, others have no access. Add a user to staff to grant them team read access without making the file public.
Supporting Details
  • Ownership fields are visible in ls -l output as two columns: owner and group names.
  • Changing group membership is often necessary when sharing files within a team.
  • chown changes owner and optionally group; chgrp changes group only.
Analogy
Owner is the file's keyholder, group is a shared key for a team, others are people outside the team.
Common mistake
Assuming everyone in group has the same shell or environment; group controls only file access, not user settings.
