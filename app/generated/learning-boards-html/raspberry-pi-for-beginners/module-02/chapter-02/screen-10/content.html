chown basics
Change owner and group with chown. Often requires sudo for non-user files.
sudo chown root:root sensitive_file.txt
chown alex:staff project.txt
Safety and checks
  • Use ls -l to confirm current owners before changing them.
  • Avoid recursive chown unless you know exactly which files should change.
  • Prefer changing group membership or permissions first rather than changing ownership widely.
Example scenario
You need to move a service file into a system directory. Use sudo chown root:root after copying, then verify ownership so the service runs with correct privileges. If you accidentally chown files in your home to root, you'll lose normal write access without sudo to revert changes.
