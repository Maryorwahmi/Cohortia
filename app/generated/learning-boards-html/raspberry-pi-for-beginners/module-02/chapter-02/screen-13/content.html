Quick diagnostic steps
  1. Run ls -l on the file or ls -ld on the directory.
  2. Check owner and group; confirm group membership if sharing is expected.
  3. Verify execute bit for scripts and directory execute for traversal.
Common fixes
chmod u+x script.py to make it runnable; chmod 600 for private files; chown to correct owner if needed using sudo. Always re-run ls -l to confirm changes.
Danger sign
Commands applying 777 or recursive ownership changes are high risk. Pause and inspect before running them.
Example scenario
If a file belongs to root and you cannot edit it, check ownership with ls -l. If ownership must be normal user, use sudo chown youruser:yourgroup file and then adjust permissions as needed. Verify with ls -l to ensure access is restored.
