Learning Objectives
Bloom bar: Learn → Understand → Apply → Master
Progressive mastery
01
Understand permissions
Explain owner/group/others and the meaning of read, write, and execute bits in the file model.
VERIFIED COMPETENCY MILESTONE
02
Read ls -l output
Translate a line like -rw-r--r-- to identify who may read, write, or execute a file.
VERIFIED COMPETENCY MILESTONE
03
Change permissions
Use chmod with symbolic and numeric modes to set permissions reliably for files and directories.
VERIFIED COMPETENCY MILESTONE
04
Manage ownership safely
Use chown to change owner and group and use sudo only when you understand the change's impact.
VERIFIED COMPETENCY MILESTONE
How these objectives connect

Understanding the conceptual model of ownership and permission bits lets you read ls -l. Reading ls -l informs safe chmod and chown operations. Those operations, when combined with prudent sudo use, keep your Pi functional and secure.

Mnemonic
Think: owner = who, group = team, others = everyone else, triplets read-write-execute.
Practice tip
Try ls -l, change one bit with chmod symbolic, then confirm with ls -l again.
