Practice Tasks
Private file task
Create secret.txt and set permissions so only the owner can read and write. Verify with ls -la to confirm no group or other access.
Shared directory task
Create shared and set owner full access, group read+execute, others execute only. Verify directory behaviour by attempting to create files as another user if available.
Safety Rules
  • Use sudo only when chown or system files require it. Understand the command before running it.
  • After changing permissions, run ls -la to verify the result matches intent.
  • Avoid world-writable files unless intentionally shared; they are a common security problem.
