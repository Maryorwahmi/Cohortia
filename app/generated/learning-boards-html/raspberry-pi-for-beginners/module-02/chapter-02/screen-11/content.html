Module 2 › Chapter 2.2 › Using sudo safely
Why sudo matters
It temporarily elevates privileges to do tasks that require root permissions. Use it sparingly and deliberately.
Safe workflow
Inspect, plan, run a single command, verify with ls -l.
Avoid
Do not run unclear commands from the internet with sudo; they can do irreversible damage.
Example check
Before sudo chown -R root:root /some/path, list the contents of /some/path and ensure those files should indeed be owned by root. Consider testing on a copy first.
Pro tip

If unsure, run the command without sudo first when possible, or run with echo to preview arguments in scripts before elevating.
