Module 2 › Chapter 2.2 › Symbolic vs Numeric
Symbolic
Good for incremental, human-readable changes. Example: chmod u+x script.py
Operator-based: who (+/-/=) + perms. Safer for single edits.
Watch out: equals overwrites existing bits.
Numeric
Good for concise, one-line settings of all categories. Example: chmod 755 script.py
Three digits: owner, group, others — each is sum of 4,2,1.
Watch out: it's easy to mistype a digit and grant too much access.
Quick decision guide
If you want to modify one bit use symbolic. If you want to set a standard set across many files or in automation, numeric is faster. Always verify with ls -l.
