Module 2 › Chapter 2.2 › chmod Numeric
Permission values
Read = 4, Write = 2, Execute = 1. Sum them for each category: owner, group, others.
Owner Group Others 7 5 5 → chmod 755 script.py
6 4 4 → chmod 644 file.txt (owner rw, group r, others r)
Key Takeaway

Numeric mode is concise for one-step permission settings. Always verify the resulting bits after running the command.

Common mistakes
  • Omitting execute for scripts when you expect to run them directly.
  • Using 777 which makes files world-writable and is usually unsafe.
  • Applying numeric chmod recursively without understanding its impact on directories versus files.
Practice
Convert intended bits to digits before running chmod, then confirm with ls -l.
