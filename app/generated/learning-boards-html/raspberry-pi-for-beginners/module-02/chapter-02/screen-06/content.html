Module 2 › Chapter 2.2 › Permissions: File vs Directory
Permissions on files
  • Read: open and view file contents.
  • Write: edit or replace the file contents.
  • Execute: run the file as a program or script.
Example: chmod u+x script.py adds execute for the owner so the script can be run directly.
Permissions on directories
  • Read: list filenames in the directory.
  • Write: create, delete, or rename files inside.
  • Execute: enter or traverse the directory with cd and access contained files if permitted.
Example: drwxr-xr-x means owner can do everything, group and others can list and enter but not create files.
Common mistake and check
If collaborators report they cannot create files, verify the directory group and owner bits include write. If they can see names but cannot access files, check execute permission is set so traversal is allowed.
