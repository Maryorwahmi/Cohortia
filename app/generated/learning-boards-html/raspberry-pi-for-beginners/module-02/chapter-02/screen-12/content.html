Private file: secret.txt
Steps to create and lock a file to the owner.
touch secret.txt chmod 600 secret.txt ls -la secret.txt
Expect -rw------- which means only the owner can read and write.
Check
If another user needs access, adjust group and add that user to the group rather than making the file world-readable.
Shared directory: shared
Create a directory with owner full access, group read+execute, others execute only.
mkdir shared chmod 751 shared ls -ld shared
drwxr-x--x indicates owner rwx, group r-x, others --x. Adjust to 775 if group should create files.
Misconception
Setting group read does not let group create files unless group write is also set and users are in the group.
