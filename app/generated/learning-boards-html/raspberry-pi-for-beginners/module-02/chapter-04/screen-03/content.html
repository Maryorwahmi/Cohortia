Troubleshoot & Secure
Concrete checks that prevent common failures and exposures.
Verified
Troubleshooting checklist
Check the interface name, confirm the IP address is present, ping a reliable host, and verify the target service is listening.
Security quick wins
Change default password, use SSH keys, keep packages updated, and disable services you do not use.
Assessment focus
You will be asked to find an IP, connect with SSH, transfer a folder to the Pi, and explain one security step you applied.
Mnemonic
IP, ping, SSH, transfer, secure.
