Module 2 › Chapter 2.4 › Wired vs Wireless
Why this comparison matters

Matching your connection type to a project reduces downtime and improves performance. Consider power, mobility, and expected traffic.

Key bullet points
  • Ethernet (eth0) typically delivers steady, low‑latency connectivity for servers.
  • Wi‑Fi (wlan0) offers mobility; performance depends on signal and congestion.
  • DHCP usually assigns a private IP; check it after connecting to locate the Pi.
  • Use Ethernet for long‑running services; use Wi‑Fi for portable or low‑traffic projects.
Side‑by‑side
Ethernet (eth0)
Stable, minimal interference, preferred for servers and Pi models with a gigabit port.
Wi‑Fi (wlan0)
Convenient for mobile setups; signal strength and network load affect performance.
Concrete example
For a home media server, plug the Pi into Ethernet to avoid stutters. For a field demo using a Pi Zero W, configure Wi‑Fi with saved credentials so it joins the event network automatically.
Key Takeaway

Pick Ethernet for reliability and Wi‑Fi for convenience; always verify the assigned IP after connecting.
