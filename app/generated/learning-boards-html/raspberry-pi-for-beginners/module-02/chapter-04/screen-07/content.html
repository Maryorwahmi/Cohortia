What SSH gives you
  • Encrypted terminal session to run commands remotely.
  • Secure channel for administration and scripting.
  • Works over local networks and, with care, across the internet.
Example
Open a secure shell from your laptop to the Pi to run package updates or inspect logs without a monitor attached to the Pi.
Hostname vs IP
On many home networks mDNS resolves names such as raspberrypi.local. If that fails, use the numeric IP you discovered. Name resolution is convenient but not guaranteed across every network.
Misconception

SSH is not only for advanced users; basic connections are simple and safe when you follow password or key guidance.

Takeaway: SSH is the efficient, encrypted way to manage a headless Pi and should be your first tool for remote command tasks.
