Module 2 › Chapter 2.4 › Find the IP Address
Command overview
Run the ip address command to list interfaces and addresses. Find eth0 or wlan0 and read the inet entry for the IPv4 address assigned by DHCP.
Example output
3: wlan0: <…>
inet 192.168.1.45/24 brd 192.168.1.255 scope global dynamic wlan0
2: eth0: <…>
inet 192.168.1.12/24 brd 192.168.1.255 scope global dynamic eth0
Quick check
If no inet appears, DHCP did not assign an address. Try restarting networking or replugging the cable, or configure a static address for special setups.
Common mistake & fix
Assuming the hostname resolves. If the name does not resolve, use the numeric IP to connect. Also avoid trusting an IP without verifying reachability with a simple connectivity test.
Concrete task
On your Pi run the ip address command, note the inet address for the active interface, and write it down to use for SSH or VNC.
Key Takeaway

The numeric IP is the reliable handle for remote connections when name resolution is unavailable or unreliable.
