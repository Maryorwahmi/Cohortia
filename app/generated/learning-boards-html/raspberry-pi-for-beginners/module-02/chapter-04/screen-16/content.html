Module 2 › Chapter 2.4 › What to Remember
Verify
Use the ip command and ping to confirm the Pi’s address and reachability before connecting.
Connect Securely
Use SSH for shells, scp for single files, and rsync for directory syncs — prefer SSH keys for authentication.
Secure the Device
Change defaults, update packages, disable unused services, and avoid exposing SSH to the internet without protections.
Final Tip

A simple checklist repeated for each Pi setup saves time and reduces security surprises later.
