Module 2 › Chapter 2.4 › Connect with SSH
Step-by-step
  1. 1. Confirm the Pi has an IP and responds to ping.
  2. 2. Ensure SSH is enabled on the Pi.
  3. 3. From your client run a secure shell command to the Pi’s user and host.
  4. 4. Accept the host key if prompted and authenticate.
Troubleshoot
If you see connection refused, check that the SSH service is running and that port 22 is not blocked by a firewall on the Pi or the network.
Concrete example
After noting 192.168.1.45 as the Pi’s IP, open a terminal on your laptop and use the secure shell command to connect as the Pi user. If the host key is new accept it, then authenticate and you will see the Pi’s shell prompt.
Key Takeaway

SSH is one command away but requires correct IP, an enabled service, and network reachability.
