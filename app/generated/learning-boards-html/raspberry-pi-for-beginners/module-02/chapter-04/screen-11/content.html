Module 2 › Chapter 2.4 › VNC Remote Desktop
When to use VNC
  • Run GUI applications remotely.
  • Assist another user by viewing and controlling their desktop.
  • Troubleshoot display or configuration issues without a physical monitor.
Note
Graphical sessions are sensitive to network latency; for best experience use wired connections when possible.
Concrete steps
Enable VNC via the Raspberry Pi Configuration tool or configuration utility. Install a compatible VNC viewer on your computer, then connect using the Pi’s address.
Common misconception

VNC is not always the fastest way to copy files or run commands; remain comfortable using SSH for those tasks and use VNC when a GUI is necessary.
