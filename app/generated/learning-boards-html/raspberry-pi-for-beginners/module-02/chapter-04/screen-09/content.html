Module 2 › Chapter 2.4 › Copy files with scp
When to use scp

Choose scp for simple, single-file transfers or a quick copy of a small asset to the Pi. It is encrypted and straightforward.

Example command
scp notes.txt pi@192.168.1.45:/home/pi/
After copying, verify the file exists on the Pi and check ownership and permissions so the intended user can read or execute it.
Common pitfalls
  • Forgetting the remote username or mistyping the host address.
  • Using scp for large directories — it will copy everything each time.
  • Ignoring permissions; files may be owned by root if copied with elevated privileges.
Key Takeaway

scp is secure and ideal for quick single-file transfers. For larger or repeated syncs use rsync instead.
