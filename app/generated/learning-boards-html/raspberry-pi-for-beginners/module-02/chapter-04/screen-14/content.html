Module 2 › Chapter 2.4 › Hands-on Activity
Step checklist
  1. Run the ip address command and note the inet address.
  2. Ping that address from another device to confirm reachability.
  3. SSH into the Pi and list files in your home directory.
  4. Use scp to copy a small text file to the Pi and verify it exists.
  5. Enable VNC, connect, open a GUI app, and save a file.
  6. Apply a security step: change password or add an SSH key.
Concrete example
Find 192.168.1.45, ping it, SSH in as the Pi user, copy notes.txt with scp, enable VNC and confirm you can open the file manager and save a file.
Reflection
Which step failed, if any, and what did you check to resolve it? Write one troubleshooting note for future reference.
Key Takeaway

A verified, repeatable sequence makes remote Pi management reliable. Practice until these steps are comfortable and quick.
