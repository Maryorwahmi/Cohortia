How rsync works

rsync inspects source and destination and transfers only changed files or file blocks. This reduces bandwidth for repeated transfers and is ideal for backups and project syncs.

Example command
rsync -avz projects/ pi@192.168.1.45:/home/pi/projects/
The options commonly used preserve attributes and compress data during transfer.
When to prefer rsync
  • Large directories updated incrementally.
  • Frequent backups where only small changes occur.
  • When you want to preserve timestamps, permissions, and ownership.
Key Takeaway

rsync reduces transfer time and bandwidth for directories by syncing only changes. Run it over SSH for encrypted transfers.
