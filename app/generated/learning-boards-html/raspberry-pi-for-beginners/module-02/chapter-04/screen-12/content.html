Module 2 › Chapter 2.4 › Enable VNC
Quick enable flow
  1. Open Raspberry Pi Configuration or run the configuration utility.
  2. Enable the VNC server and confirm the service is active.
  3. On your computer, open a VNC viewer and enter the Pi’s IP or hostname.
  4. Authenticate and accept any security prompts to start the session.
Troubleshooting
If the viewer cannot connect, verify the Pi’s IP, ensure VNC is running, and check local firewall rules. Consider tunneling VNC over SSH if direct connections are blocked.
Concrete task
Enable VNC on the Pi, install a viewer on your computer, connect, open a small GUI app, and save a file to confirm write access.
Key Takeaway

VNC gives useful GUI access; verify the service and network reachability and prefer encrypted viewers or SSH tunnels for security.
