What ping tells you

Ping confirms that IP packets reach a host and that responses return. It reports latency and loss, but it does not test higher-level services like SSH.

Use cases
  • Ping the router to confirm local link is up.
  • Ping a public host to check internet access.
  • Use the result to gauge latency for time-sensitive tasks.
Concrete scenario
If SSH fails, ping the Pi from another device to verify it is reachable. If ping shows high loss or no replies, investigate the interface or router rather than assuming SSH is misconfigured.
Common mistake

A successful ping does not guarantee SSH or VNC access. Use ping as a first check, then test the specific service you need.
