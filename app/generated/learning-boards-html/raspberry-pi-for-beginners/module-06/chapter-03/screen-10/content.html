Module 6 › Chapter 6.3 › JSON payloads
Good payload structure
Keep field names clear and units consistent.
Example fields
  • device_id — unique identifier for the Pi or sensor node
  • temperature — numeric value in degrees Celsius
  • timestamp — ISO 8601 or let server add time
Common mistake

Inconsistent units or field names across sends makes later analysis hard. Choose a simple schema and use it consistently.

Practical tips
  • Use the requests library's JSON parameter to set headers automatically.
  • Include only necessary metadata to conserve bandwidth.
  • Validate on the server and return clear errors for malformed payloads.
Key Takeaway

A small consistent JSON schema simplifies parsing and future analysis.
