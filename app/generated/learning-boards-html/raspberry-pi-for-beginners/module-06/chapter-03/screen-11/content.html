Module 6 › Chapter 6.3 › API keys & HTTPS
Where to store keys
  • Environment variables — preferred for runtime secrets.
  • .env files loaded locally and excluded from version control.
  • Secret managers for production systems when available.
Warning

Do not commit API keys to public repositories. Treat keys like passwords.

Transport security
Always use HTTPS so credentials and payloads are encrypted in transit.
Quick checklist
  • Use HTTPS endpoints only.
  • Remove secrets from logs and print statements.
  • Rotate keys periodically and revoke compromised keys.
Small step: store your API key in an environment variable and confirm your script reads it before sending a test value.
