Checklist
Follow these checks in order to find most failures quickly.
1. Network
Ping or curl a known site to confirm connectivity.
2. API key
Check for missing characters or extra quotes in environment variables.
3. Method & payload
Confirm GET vs POST and that JSON is valid if used.
4. Response codes
Log the status codes and any error messages for clues.
5. Rate limits
Ensure you wait at least the minimum interval between updates.
6. Server logs
For custom endpoints, check server output and validation failures.
A short log that records the timestamp, value, and response code is invaluable when diagnosing intermittent failures.
