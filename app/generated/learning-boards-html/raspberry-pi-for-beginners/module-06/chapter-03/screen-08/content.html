Module 6 › Chapter 6.3 › Flask receiver
Minimal Flask server (visual)
from flask import Flask, request

app = Flask(__name__)

@app.route("/data", methods=["POST"])
def receive_data():
    data = request.json
    print(data)
    return {"status": "ok"}

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
This example prints the JSON payload to the server console. Add validation and storage for real projects.
Practical notes
  • Use POST with JSON when the receiver expects structured data.
  • Add simple validation to check required fields before storage.
  • Host behind HTTPS or a reverse proxy to protect transport.
Common pitfall

Exposing a development server to the public without TLS or authentication can leak data or allow misuse. Harden before production.
