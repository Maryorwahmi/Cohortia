Module 7 › Chapter 6.4 › Least privilege & HTTPS
Least privilege
Create dedicated service users and avoid running network services as root. This limits what an attacker can do if a service is compromised.
Monitoring
Use journalctl to review logs for unusual activity and to help detect potential compromises early.
HTTPS for web interfaces
Use TLS for any web interface exposed beyond a trusted LAN so credentials and data are encrypted in transit.
Key Takeaway

Least privilege and encrypted channels reduce both the chance of compromise and its potential impact.
