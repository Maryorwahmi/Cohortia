Module 7 › Chapter 6.4 › Keep software updated
Update commands
sudo apt update
sudo apt upgrade
Run updates regularly and review any notes before applying large upgrades. For critical devices, test updates in a separate environment first.
Why it matters
Updates patch known vulnerabilities. An unpatched package is a known route attackers can exploit; routine updates close those routes.
Key Takeaway

Make updates a scheduled task so security fixes are applied promptly and your device remains protected against known issues.
