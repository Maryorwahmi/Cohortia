Module 7 › Chapter 6.4 › Secure SSH configuration
Configuration
PasswordAuthentication no
PermitRootLogin no
Place these lines in /etc/ssh/sshd_config and save the file. They prevent password logins and root remote sign-in.
Safe restart
sudo systemctl restart ssh
Open a second SSH session before restarting so you retain a recovery connection. Only close the old session after the new login is confirmed.
Checklist before restart
  • Confirm public key exists in authorized_keys for your user.
  • Open a second SSH session to the Pi.
  • Apply config change and restart SSH, then verify new session works.
