Module 7 › Chapter 6.4 › SSH key-based authentication
Commands to run
ssh-keygen -t ed25519 -C "your_email@example.com"
ssh-copy-id alex@raspberrypi.local
Generate the key locally, then copy the public key to the Pi for the target user. Test login using your SSH client; it should use the private key automatically.
Edit SSH server
# in /etc/ssh/sshd_config
PasswordAuthentication no
PermitRootLogin no
After confirming key login works, change these settings and restart SSH with the command shown in the chapter to apply the change.
Misconception check
Do not disable password authentication until you can log in with the key. Otherwise you risk locking yourself out of the device.
Key Takeaway
Use ed25519 keys, install the public key on the Pi, verify key login, then disable password-based SSH to prevent brute-force attacks.
