Module 7 › Chapter 6.4 › Firewall with ufw
Install and allow commands
sudo apt install ufw
sudo ufw allow 22/tcp # SSH
sudo ufw allow 80/tcp # HTTP
sudo ufw allow 1883/tcp # MQTT
sudo ufw enable
Run only rules you need. After enabling, verify active rules with the status command provided in the chapter.
Practical guidance
  • Only open ports required by the project.
  • Avoid exposing SSH publicly when not needed.
  • Consider restricting rules to known IPs where possible.
Key Takeaway

UFW is a lightweight control to enforce which ports are reachable; use it to minimize network exposure before publishing services.
