Module 7 › Chapter 6.4 › Key Concepts
Strong Credentials
Remove defaults and use unique passwords to block easy automated access.
SSH Key Auth
Use ed25519 keys and disable password authentication once key login is confirmed.
Firewall (ufw)
Allow only required ports and verify rules to reduce network exposure.
Summary

Start with these three controls to secure a Raspberry Pi quickly: credentials, keys, and firewall. They provide immediate, high-impact protection.
