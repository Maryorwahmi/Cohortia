Module 7 › Chapter 6.4 › Change default user
Step-by-step
  1. Create a new user and set a strong password.
  2. Grant sudo if needed and confirm sudo works.
  3. Move SSH keys or configs to the new user.
  4. Delete the old 'pi' account only after verification.
Concrete example
Create user 'alex', test login and sudo, then delete 'pi' to prevent automated login attempts using that account.
Common mistake
Deleting the default user before confirming the new account works. Always verify access first to avoid lockout.
Pro tip
Use a password manager to create unique passwords and avoid reuse across devices and services.
Key Takeaway

Replace default accounts immediately and verify new account access before removal to close the most basic attack vector.
