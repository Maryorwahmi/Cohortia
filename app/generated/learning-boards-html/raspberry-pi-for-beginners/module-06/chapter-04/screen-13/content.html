Module 7 › Chapter 6.4 › Hands-on activity
Activity steps
  1. Generate keys: ssh-keygen -t ed25519 -C "your_email@example.com".
  2. Copy public key: ssh-copy-id alex@raspberrypi.local and test key login.
  3. Edit /etc/ssh/sshd_config to set PasswordAuthentication no and PermitRootLogin no, open a second session then sudo systemctl restart ssh.
  4. Install ufw, allow 22/tcp and 80/tcp if needed, enable ufw and run status to confirm.
Common mistake
Enabling the firewall without ensuring SSH key access and an allow rule first, which can lock you out.
