Learning Objectives
Learn the practical skills to secure a Raspberry Pi from first boot to maintenance.
01
Identify common security risks
Recognize how exposed services and default credentials invite attack. This helps you prioritize defenses for your project.
VERIFIED COMPETENCY MILESTONE
02
Secure SSH using keys
Generate an ed25519 key pair, install the public key on the Pi, and disable password login to reduce brute-force risk.
VERIFIED COMPETENCY MILESTONE
03
Configure ufw firewall
Allow only necessary ports such as SSH and HTTP, then enable ufw and check its status to confirm rules are active.
VERIFIED COMPETENCY MILESTONE
04
Maintain updates and least privilege
Apply system updates, disable unused services, and run servers as non-root users to minimize attack surface and impact.
VERIFIED COMPETENCY MILESTONE
