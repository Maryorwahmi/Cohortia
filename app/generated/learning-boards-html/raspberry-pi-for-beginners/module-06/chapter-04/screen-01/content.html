Change Default Users
Create a new user, strong password, then remove the 'pi' account to prevent common, automated attacks.
SSH Key Auth
Use an ed25519 key pair and disable password login to block brute-force password attempts.
Firewall with ufw
Install ufw, allow only required ports like 22 and 80, then enable the firewall to reduce open surface.
