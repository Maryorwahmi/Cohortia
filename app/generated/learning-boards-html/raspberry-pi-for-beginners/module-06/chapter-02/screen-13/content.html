Module 6 › Chapter 6.2 › Hands-on Activity
Activity overview
Set up Mosquitto, publish a DHT22 temperature to home/temperature every five seconds, and subscribe to home/led to switch an LED.
Step 1: Install and verify
sudo apt install mosquitto mosquitto-clients sudo systemctl enable mosquitto sudo systemctl start mosquitto
Step 2: Publisher
Install paho‑mqtt and write a loop that reads the DHT22 and publishes to home/temperature every five seconds. Print values locally for verification.
Step 3: Subscriber
Write a subscriber for home/led to decode ON/OFF and use gpiozero to toggle the LED. Test with mosquitto_pub before relying on automated commands.
Testing checklist
  • Can you see published values in a subscriber terminal?
  • Does sending "ON" turn the LED on and "OFF" turn it off?
  • Are topic strings identical in both scripts?
Key Takeaway

Break the lab into install, command‑line test, publisher code, and subscriber code to isolate failures and validate behavior step by step.
