Module 6 › Chapter 6.2 › Python Publisher
Install
pip install paho-mqtt
After installation, use the client to connect and publish. Keep your scripts simple while testing.
Publisher example
import paho.mqtt.client as mqtt
from time import sleep
from gpiozero import DistanceSensor

client = mqtt.Client()
client.connect("localhost", 1883, 60)

sensor = DistanceSensor(echo=24, trigger=23)

while True:
    distance = sensor.distance * 100
    client.publish("pi/distance", f"{distance:.1f}")
    print(f"Published: {distance:.1f} cm")
    sleep(2)
Developer tips
  • Print published values to confirm messages are sent.
  • Use a sleep interval to avoid flooding the broker.
  • Ensure the broker is running before starting the publisher.
Key Takeaway

Install paho‑mqtt, connect the client to localhost, and publish formatted sensor readings at a controlled cadence.
