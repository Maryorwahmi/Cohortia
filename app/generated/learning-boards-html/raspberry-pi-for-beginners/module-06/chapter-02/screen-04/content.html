Core Concept

Publish‑Subscribe

Devices publish messages to topics. Subscribers listen for topics. The broker routes messages to interested subscribers.

Analogy
Topics are mailboxes; publishers drop mail, subscribers open the mailbox when they care.
Concrete example
A distance sensor publishes readings to pi/distance every two seconds. A logger subscribes to pi/distance to store readings.
Common misconception
Some expect many peer connections; instead, clients keep one connection to the broker and the broker handles fan‑out.
Key Takeaway

Use clear topic names and a single broker connection to keep devices decoupled and scalable.
