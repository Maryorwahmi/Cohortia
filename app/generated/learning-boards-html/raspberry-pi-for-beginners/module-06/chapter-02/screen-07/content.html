Command-line smoke test
Use the clients bundled with Mosquitto to prove messaging works.
Subscriber terminal
mosquitto_sub -t "test/topic"
Leave this running to display messages received on the topic.
Publisher terminal
mosquitto_pub -t "test/topic" -m "Hello MQTT"
Publishing prints no output by default; the subscriber will display the message.
Troubleshooting checklist
  • Is mosquitto running?
  • Are topic strings identical?
  • Are you using localhost when testing locally?
Key Takeaway

Command-line publish/subscribe is the fastest way to confirm the broker and network are working before running application code.
