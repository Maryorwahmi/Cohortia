Core Terms

Broker
Server that receives and forwards messages between clients.
Client
Any device that connects to the broker to publish or subscribe.
Topic
A string label such as home/livingroom/temperature that classifies messages.
Publish / Subscribe
Publish sends a message to a topic. Subscribe requests messages for a topic from the broker.
QoS
Quality of Service controls message delivery reliability as required by your application.
Practical card
Decide topic names for sensors and actuators in your Pi network and document which clients publish or subscribe to each topic.
Misconception
Topics are not devices. Keep names descriptive and hierarchical to avoid accidental overlap of responsibilities.
