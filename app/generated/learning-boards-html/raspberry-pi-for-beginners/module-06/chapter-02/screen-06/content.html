Module 6 › Chapter 6.2 › Mosquitto Installation
Step-by-step
Run these commands on your Raspberry Pi to install and start the Mosquitto broker.
Install and enable
sudo apt install mosquitto mosquitto-clients
sudo systemctl enable mosquitto
sudo systemctl start mosquitto
These commands add the broker and client tools, then ensure the broker runs now and after reboot.
Test with two terminals
Terminal A: mosquitto_sub -t "test/topic" Terminal B: mosquitto_pub -t "test/topic" -m "Hello MQTT"
Seeing the message appear verifies the broker forwards messages correctly.
Common mistakes
  • Forgetting to start the mosquitto service.
  • Running publish before the subscriber subscribes locally.
  • Using the wrong broker address when testing from another machine.
Key Takeaway

Install, enable, and start Mosquitto, then verify message flow with mosquitto_sub and mosquitto_pub before writing Python code.
