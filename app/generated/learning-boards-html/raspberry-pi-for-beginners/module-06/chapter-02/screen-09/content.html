Module 6 › Chapter 6.2 › Publisher Breakdown
Key lines explained
client = mqtt.Client() creates the client object to publish messages.
client.connect("localhost", 1883, 60) ensures messages are sent to the local broker.
sensor = DistanceSensor(echo=24, trigger=23) provides hardware readings.
Loop behavior
Read sensor, convert to centimeters, publish string payload, print confirmation, sleep to control rate.
Design note
Simple string payloads are easy to parse; if you need multiple fields, format JSON consistently and document the schema for subscribers.
Key Takeaway

Publish small, regular payloads and print locally to verify the data you are sending to subscribers.
