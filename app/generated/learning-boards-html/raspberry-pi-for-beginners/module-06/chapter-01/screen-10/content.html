Design a clear page for controls and readings

Start with a single page that groups controls and sensor output to make testing simple.

Example HTML layout (concept)
<h1>Pi LED Control</h1>
<div>Turn the LED on or off:</div>
<div><a href="/on">On</a> <a href="/off">Off</a></div>
<div id="sensor">Voltage: -- V</div>
Start with simple anchors for testing, then replace them with JavaScript calls for a smoother interface once the backend works.
Practical guidance
  • Group related controls and label them clearly to avoid accidental activation.
  • Include a small status text that confirms the last action or shows the latest sensor reading.
  • Keep the initial UI minimal: three controls are enough to validate the core interaction loop.
Key takeaway
A clean dashboard makes debugging faster and testing from a phone simpler.
