Key Concepts

Three compact reminders to keep handy while you work.

Flask framework
A lightweight layer that exposes Python functions over HTTP for easy prototyping.
Routes & views
Decorators map URLs to functions that return HTML or text responses.
GPIO control
Use gpiozero calls inside route functions to control LEDs or other outputs from the web.
Summary takeaway

Combine Flask routes with gpiozero reads or writes to create accessible, hands-on Pi projects on your local network.
