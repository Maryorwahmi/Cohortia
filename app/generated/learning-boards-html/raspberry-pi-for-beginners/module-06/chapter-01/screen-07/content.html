Route example

A minimal route that returns an HTML heading and links for testing.

Example code (static display)
from flask import Flask

app = Flask(__name__)

@app.route("/")
def index():
    return "<h1>Pi LED Control</h1><p>Use your browser to send requests to control hardware.</p>"

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
Note: angle brackets are escaped here for safe display. Copy the structure into your app file and test by visiting the Pi’s address from another device.
Explanation bullets
  • The @app.route decorator registers the URL route with Flask.
  • The index function returns a string that Flask sends as the HTTP response.
  • Start small with text responses, then move to templates for more complex HTML.
