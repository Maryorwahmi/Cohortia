Flask is a tiny, explicit web layer

It exposes Python functions as web endpoints so browsers can trigger actions or receive data.

Minimal app example
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Hello from Raspberry Pi!"

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000, debug=True)
Bulleted explanation:
  • Create an app object and use a decorator to map a route.
  • The function returns the response the browser displays.
  • Binding to 0.0.0.0 makes the server reachable from other devices on the network.
Concrete example & analogy
Imagine the Pi as a small shop and Flask as the shopkeeper. A browser is a customer asking for a product. A route is a labeled shelf; when the customer looks there, the shopkeeper brings back a specific item or triggers an action like flipping a switch. This helps you reason about requests and responses when you connect hardware like an LED.
Key takeaway
Flask is intentionally small: learn request→handler→response to control hardware from the network.
Common mistake
Treating Flask's built‑in server as production. For learning it's fine; for public services use a production server later.
