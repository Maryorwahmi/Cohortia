When to move beyond the built-in server

The built-in server is great for learning; Gunicorn and Nginx help when you need production features.

Development server
Flask's server is simple to run and ideal for experiments and local dashboards. It is not designed for handling heavy load or public internet exposure.
Production options
  • Gunicorn: a WSGI server that runs multiple worker processes for improved stability.
  • Nginx: a reverse proxy to serve static files, terminate TLS, and forward requests to Gunicorn.
Practical next steps
After you complete the hands‑on activity, refactor your HTML into templates, add simple client-side code if you want a smoother UI, and later explore Gunicorn/Nginx when you want to host beyond your local network.
Misconception check
You do not need production servers for local learning; only adopt them when availability, performance, or public access is required.
