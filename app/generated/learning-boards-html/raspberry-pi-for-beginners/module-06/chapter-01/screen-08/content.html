Module 6 › Chapter 6.1 › Controlling an LED from the web

Two practical methods

Compare a simple route-based approach with a JavaScript-enhanced approach for user experience.

Route-based (beginner)
from gpiozero import LED
led = LED(17)

@app.route('/on')
def turn_on():
    led.on()
    return 'LED is ON'
Simple to implement and great for testing hardware control. Each action is triggered by a GET request and returns a small response.
POST / JS (smoother UX)
Use a POST endpoint and client‑side JavaScript to call it asynchronously and update the page state without navigation. This requires extra code but creates a more responsive dashboard.
When to use
Choose POST/JS when you need immediate UI updates or when multiple controls are active simultaneously.
Concrete example
Wire LED to pin 17, test route-based on/off behavior, then decide whether to upgrade UI with JavaScript.
Safety note
Always include a resistor with an LED and confirm the correct pin numbering to avoid damaging hardware.
