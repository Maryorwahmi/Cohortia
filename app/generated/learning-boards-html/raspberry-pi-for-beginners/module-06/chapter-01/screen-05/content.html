Module 6 › Chapter 6.1 › Set up a virtual environment

Install steps

Three simple commands to prepare your Pi for Flask-based projects.

1. Create the environment
python3 -m venv web_env
This makes an isolated Python environment inside a folder named web_env.
2. Activate the environment
source web_env/bin/activate
Activating ensures subsequent installs go into web_env and that python points to the environment interpreter.
3. Install packages
pip install flask gpiozero
Install Flask for the web layer and gpiozero for GPIO access from Python.
Why this matters

Keeping dependencies isolated prevents version clashes between projects, makes deployment easier, and helps you debug missing-package errors quickly. It also makes it safe to experiment on the Pi without risking system packages.

Tip
If pip reports permissions or system-site packages, ensure the environment is activated and re-run the install inside it.
Common mistake
Forgetting to activate the virtualenv before running the app will lead to import failures or unexpected package versions.
Check your install
Quick test: python -c "import flask; print(flask.__version__)" to confirm Flask is available in the environment.
