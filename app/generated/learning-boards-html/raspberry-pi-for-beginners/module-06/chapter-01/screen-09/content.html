Sensor read route

Read an ADC channel and return a formatted voltage string to the browser.

Example ADC code
from flask import Flask
from gpiozero import MCP3008

app = Flask(__name__)
adc = MCP3008(channel=0)

@app.route('/')
def index():
    voltage = adc.value * 3.3
    return f"<h1>Sensor Reading</h1><p>Voltage: {voltage:.2f} V</p>"
This code reads the ADC at request time and returns a simple HTML fragment showing the voltage with two decimals.
Explanation bullets
  • adc.value returns a normalized number between 0 and 1 for MCP3008; multiply by reference voltage to get voltage.
  • Formatting with two decimals makes the readout easy to scan on a phone.
  • Request-time reads are simple to implement and reliable for manual refresh polling.
Try this
Wire an LDR or potentiometer to the ADC channel, then change the light or knob and refresh the page to observe the voltage change.
