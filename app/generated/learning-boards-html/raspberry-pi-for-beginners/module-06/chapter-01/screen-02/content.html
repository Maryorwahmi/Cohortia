Learning Objectives

Four core competencies you will verify through practice.

01
Install Flask in a virtualenv
VERIFIED COMPETENCY MILESTONE

Set up a Python virtual environment, activate it, and install Flask and gpiozero so your project dependencies stay contained and reproducible. This matters so different projects on the Pi won't conflict.

Mnemonic: isolated box
02
Create routes and serve HTML
VERIFIED COMPETENCY MILESTONE

Write URL routes that map to functions returning HTML or text. This is how you build pages like a dashboard or sensor readout. Practice with a minimal "Hello" route first to confirm connectivity.

Mnemonic: URL → function → view
03
Control GPIO from a browser
VERIFIED COMPETENCY MILESTONE

Use gpiozero inside route functions to toggle outputs like an LED when a route is visited. This connects the network to physical outputs and helps you prototype interactive projects quickly.

Mnemonic: click → request → action
04
Read and display sensor data
VERIFIED COMPETENCY MILESTONE

Read analog or digital sensors using gpiozero or an ADC and return the measurement as formatted HTML so a phone or browser sees live values. This is essential for dashboards and monitoring.

Mnemonic: sense → format → show
