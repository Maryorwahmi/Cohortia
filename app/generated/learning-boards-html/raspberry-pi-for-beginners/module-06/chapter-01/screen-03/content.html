Practice checks

Concrete tests that prove each objective works on your Pi.

Install check
  • Activate the virtual environment where Flask and gpiozero were installed.
  • Run python to import Flask without errors as a smoke test.
Route check
  • Start the minimal app and open the Pi’s IP with port 5000 from another device.
  • Confirm the expected text or heading appears in the browser.
GPIO check
  • Wire an LED to the specified pin and observe it toggling when the related route is hit.
  • Verify correct resistor use and pin numbering to avoid mistakes.
Sensor check
  • Read the sensor value via the route and see a changing numeric value that reflects physical changes.
  • Compare results after small environmental changes to confirm responsiveness.
