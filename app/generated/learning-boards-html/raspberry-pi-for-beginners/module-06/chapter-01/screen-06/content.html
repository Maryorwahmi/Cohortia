Host and port explained

Use host and port to control who can connect and where the app listens.

Typical run command
app.run(host="0.0.0.0", port=5000)
  • host="0.0.0.0" listens on all interfaces so other devices on the same network can connect.
  • port=5000 is the conventional development port; if occupied, choose another unused port.
  • To reach the server, use the Pi’s IP address or a local host name followed by the port.
Concrete example
Start the app on the Pi, find its IP using a network tool or the Pi’s settings, then open the IP with :5000 on your phone’s browser. You should see the app’s response if both devices are on the same Wi‑Fi.
Tip
If you cannot connect, verify the Pi and phone are on the same subnet and that no firewall is blocking traffic.
Misconception
Binding to 0.0.0.0 does not automatically expose your Pi to the internet; it only accepts local network connections unless additional routing is configured.
Check your URL
Use http://raspberrypi.local:5000 or http://PI_IP:5000 to connect from another device.
