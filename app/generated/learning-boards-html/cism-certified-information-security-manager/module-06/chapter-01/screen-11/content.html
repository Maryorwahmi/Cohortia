Future State Definition

Defining the Desired Future State

Outlining the target security posture aligned with objectives.

Key Characteristics
  • Alignment: Must align with overall strategic objectives and risk appetite.
  • Measurable Outcomes: Focus on specific, measurable, achievable, relevant, and time-bound (SMART) goals.
  • Realistic: Ambitious yet attainable, managing risk to an acceptable level.
  • Holistic: Consider technology, processes, people, and culture.
Example Objectives
  • Reduce critical security incidents by 50% within two years.
  • Achieve ISO 27001 certification within 18 months.
  • Implement a comprehensive security awareness program reaching 95% of employees annually.
  • Integrate security testing into 100% of new software development projects.
Key Takeaway

A clearly defined, measurable, and business-aligned future state provides the essential target for guiding security strategy development and implementation.
