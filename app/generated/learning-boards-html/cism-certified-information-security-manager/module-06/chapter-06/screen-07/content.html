Design Principles

Secure by Default

Minimizing Attack Surface from the Start

Core Definition

Systems are designed and configured securely from the outset, with insecure features disabled by default.

Example: Server Installation

A new server should be installed with only essential services running and default passwords changed immediately.

Separation of Duties

Preventing Fraud and Misuse of Privileges

Core Definition

No single individual should be able to complete a critical or sensitive task alone.

Example: Financial Transaction

One person approves a financial transaction, while another executes it, ensuring checks and balances.

Key Takeaway

Secure by Default reduces attack surface, while Separation of Duties prevents single points of failure in critical processes.
