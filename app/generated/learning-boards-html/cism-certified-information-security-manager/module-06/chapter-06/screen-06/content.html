Design Principles

Least Privilege

Minimizing Access to Limit Damage

Core Definition

Users, processes, and systems are granted only the minimum necessary permissions to perform their legitimate functions.

Example: Database Access

A web application's database user should only have READ access to display data, not WRITE or administrative privileges.

Fail-Safe Defaults

Ensuring Secure States During Failure

Core Definition

When a system fails, it should default to a secure state, typically denying access rather than granting it.

Example: Authentication Server

If an authentication server goes down, access should be DENIED by default, preventing unverified entry.

Key Takeaway

Least Privilege and Fail-Safe Defaults are crucial for limiting potential damage from compromise and maintaining security during system failures.
