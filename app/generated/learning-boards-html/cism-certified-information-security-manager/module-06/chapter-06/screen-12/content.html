Module 6 › Chapter 6.6 › Deployment & Maintenance
SDLC Stages

Security in Deployment

Secure Configuration and Automation

Key Activities

  • Implement secure configuration management (e.g., hardening, baselines).
  • Automate deployments to ensure consistency and reduce errors.
  • Ensure secure infrastructure provisioning.

Security in Maintenance

Continuous Monitoring and Adaptation

Key Activities

  • Monitor for new vulnerabilities and apply patches promptly.
  • Conduct regular security audits and reviews.
  • Update security controls as threats evolve.
Key Takeaway

Security is an ongoing process; secure deployment and continuous maintenance are vital for protecting systems throughout their operational life.
