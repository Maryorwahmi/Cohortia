SDLC Stages

Security in Requirements

Defining Security Needs Upfront

Key Activities

  • Define security requirements alongside functional ones.
  • Specify authentication, authorization, data protection, and privacy needs.
  • Example: "System must authenticate users with MFA."

Security in Design

Proactive Threat Mitigation

Key Activities

  • Conduct threat modeling to identify potential attack vectors.
  • Incorporate secure design patterns (e.g., least privilege, defense in depth).
  • Design for secure data flows and trust boundaries.
Key Takeaway

Embedding security in requirements and design phases is critical for preventing vulnerabilities and building a strong security foundation.
