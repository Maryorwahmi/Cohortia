Who is the Data Custodian?

The Data Custodian is the individual or department (typically IT or security operations) responsible for the technical implementation and maintenance of security controls to protect the data, as directed by the Data Owner.

Core Responsibility

Implements and maintains technical controls (storage, backup, access, encryption) to protect data according to its classification.

Common Mistake

Confusing data ownership with data custodianship. Owner decides 'what' and 'how much' protection; Custodian implements 'how'.

KEY DUTIES OF A DATA CUSTODIAN
Manage Data Storage & Backup

Ensures data is stored securely and backed up regularly.

Provision Access

Grants or revokes user access based on owner's directives.

Implement Encryption

Applies cryptographic controls to protect data confidentiality.

Key Takeaway

The Data Custodian is the technical implementer of security controls, ensuring data is protected operationally as per the Data Owner's directives.
