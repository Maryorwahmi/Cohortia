Core Concept

The Information Security Policy Framework

A Hierarchical Approach to Security Governance

Key Idea

The framework is a pyramid: policies set intent, standards enforce requirements, guidelines advise, and procedures detail execution.

Why it matters
  • Ensures consistency across all security efforts.
  • Provides clear direction for employees and systems.
  • Facilitates compliance with legal and regulatory requirements.
  • Reduces ad-hoc security practices and potential gaps.
Framework Hierarchy
Policies (What & Why)
Standards (How - Mandatory)
Guidelines (How - Recommended)
Procedures (How - Step-by-Step)
