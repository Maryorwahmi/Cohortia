Core Concept

The Incident Response Plan (IRP) Lifecycle

A structured approach to managing security incidents.

Preparation

Establish IRT, policies, tools, and training *before* an incident occurs. This is the foundation.

Identification

Detect and confirm incidents by monitoring alerts, logs, and user reports to understand scope.

Containment

Limit damage and prevent spread by isolating affected systems or blocking malicious activity.

Eradication

Remove the root cause, such as patching vulnerabilities or cleaning infected systems.

Recovery

Restore systems and data to normal, secure operations, validating integrity.

Example Scenario

Ransomware Attack

Preparation

Security team trained on ransomware response, forensic tools ready, offline backups verified.

Identification

SIEM alerts flag unusual file encryption activity; users report inaccessible files.

Containment

Affected servers isolated from the network; malicious processes terminated.

Eradication

Ransomware identified and removed; exploited vulnerability patched.

Recovery

Systems restored from clean, offline backups; data integrity verified.

Lessons Learned

Post-incident review identifies need for enhanced endpoint detection and user awareness training.
