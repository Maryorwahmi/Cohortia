ISO/IEC 27002: Information Security Controls

A comprehensive international standard for security controls guidance

Key Features

  • **International Standard:** Globally recognized for information security.
  • **Comprehensive Controls:** Provides 114 controls across 14 domains.
  • **Implementation Guidance:** Offers detailed advice on how to implement controls.
  • **Part of ISO 27000 Family:** Used with ISO 27001 for ISMS certification.
  • **Highly Prescriptive:** Detailed guidance makes it suitable for robust, certifiable systems.
Key Takeaway

ISO 27002 provides a detailed, prescriptive set of international security controls, making it ideal for organizations aiming for ISMS certification in conjunction with ISO 27001.
