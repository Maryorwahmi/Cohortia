Mapping Organizational Controls to Framework Requirements

Aligning existing security measures with framework objectives

The Mapping Process

  1. **Identify Organizational Controls:** List all existing security policies, procedures, and technical controls.
  2. **Select Framework Requirements:** Pinpoint specific controls or objectives within the chosen framework.
  3. **Establish Linkages:** Draw direct connections between your organizational controls and the framework's requirements.
  4. **Document & Analyze:** Record the mappings and identify any gaps where framework requirements are not met.
  5. **Prioritize Remediation:** Address identified gaps by implementing new controls or enhancing existing ones.

Example: Password Policy Mapping

Organizational Control:

"Strong Password Policy" (complexity, length, rotation)

Mapping to ISO 27002:

A.9.2.4 Management of secret authentication information

Mapping to NIST CSF:

PR.AC-1 Identity Management (e.g., authentication policies)
Key Takeaway

Control mapping is a critical exercise to align existing security measures with framework requirements, identify gaps, and demonstrate compliance effectively.
