Key Concepts (Continued)

Reinforcing your understanding of core security principles

COBIT

A business-focused framework for the governance and management of enterprise IT, integrating security into broader IT processes.

Information Security Management System (ISMS)

A systematic approach for managing sensitive company information so that it remains secure, typically based on a framework like ISO 27001.

Gap Analysis

A process to compare an organization's current security posture against the requirements of a chosen framework to identify deficiencies.

Chapter Summary

COBIT provides IT governance, an ISMS offers systematic security management, and gap analysis is key for identifying and addressing security deficiencies within a framework.
