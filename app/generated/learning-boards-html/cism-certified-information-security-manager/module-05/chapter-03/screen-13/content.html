Core Concepts for Risk Mitigation

Administrative Controls

Policies, procedures, standards, and guidelines that govern security behavior and management.

Technical Controls

Hardware or software mechanisms that enforce security policies and protect systems/data.

Physical Controls

Tangible measures to protect physical assets, facilities, and the environment.

Summary Takeaway

Understanding these three distinct yet interconnected control types is fundamental to designing a comprehensive and effective security strategy.
