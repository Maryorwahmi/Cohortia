Extracting Actionable Insights: SIEM Query Example

Using a pseudo-command to identify potential brute-force attempts from security logs.

# Example of a pseudo-command for querying a SIEM for KRI data
splunk | index=security sourcetype=authentication "failed login" severity=high earliest=-24h
        | stats count by src_ip
        | where count > 100
        | sort -count
        | table src_ip, count
# Identifies IPs with >100 failed logins in 24h
Command Purpose

Searches for high-severity failed login events to detect potential brute-force attacks.

KRI Relevance

The count of failed logins from a single IP serves as a KRI, indicating increasing risk exposure.

Key Takeaway

SIEM queries enable security teams to proactively identify and report on critical risk indicators, enhancing overall security posture.
