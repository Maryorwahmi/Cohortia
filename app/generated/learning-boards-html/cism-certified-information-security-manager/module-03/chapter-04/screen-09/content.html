Module 3 › Chapter 3.4 › Vendor / Third-Party Policy
Definition
Vendor / Third-Party Security Policy
Defines due diligence, contractual security requirements, monitoring, and termination steps to manage third-party risk.
Example clause
Vendors processing Restricted data must use encryption and report security incidents within 24 hours.
Operational focus
Integrate vendor requirements into procurement and include monitoring and termination steps in policy.
Common mistake
Not defining post-contract monitoring or missing breach reporting timelines, weakening assurance over time.
Key Takeaway

Tie vendor obligations to the classification of data they handle and include monitoring and contractual assurances.
