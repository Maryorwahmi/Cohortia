Module 3 › Chapter 3.4 › Data Classification Policy
Definition
Data Classification Policy
Defines categories for information and prescribes how each category must be handled, stored, transmitted, and disposed.
Public
Suitable for broad distribution; minimal protection required.
Restricted
Highly sensitive, e.g., patient records; encryption required and tight access controls.
Example
A Data Classification Policy requires that any record marked Restricted is encrypted at rest and in transit and tagged in the asset inventory so access controls and incident response treat it as high priority.
Common mistake
Leaving category definitions abstract without examples makes classification inconsistent across teams.
Key Takeaway

Classification creates the policy link between data sensitivity and technical controls; keep categories clear and provide examples.
