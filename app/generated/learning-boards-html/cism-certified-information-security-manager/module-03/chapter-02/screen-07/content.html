Module 3 › Chapter 3.2 › Strategic, Tactical, Operational Plans
Definition

Strategy

High-level, multi-year goals that align security to business outcomes.

Tactics

Shorter-term projects and objectives that deliver strategic goals.

Operations

Day-to-day processes and procedures that implement tactics.

Example hierarchy
Strategic
Become a leader in secure cloud services over 3–5 years.
Tactical
Migrate 50% of applications to secure cloud within 18 months.
Operational
Create Infrastructure as Code templates to enforce cloud configurations per deployment.
Misconception

Treating tools and controls as strategy leads to fragmented investments and poor executive support.

Pro Tip

Trace each operational task back to a tactical milestone and each tactical milestone back to a strategic objective to validate alignment.
