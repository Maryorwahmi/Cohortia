Assessment Idea

Strategic vs Tactical — Worked Example

Operational

Train analysts on threat hunting and update alert rules to improve day-to-day detection.

Tactical

Deploy a SIEM system to centralize logs and alerts within a defined project timeline.

Strategic

Develop a multi-year plan to integrate threat intelligence, detection engineering, and proactive hunting across all environments with executive funding.

Reflection

Ask: which of these requires board-level commitment and changes how detection is funded and governed?
