NIST IR Lifecycle

Phase 3: Containment

Limiting Incident Scope and Impact

01

Isolate Affected Systems

Disconnect compromised systems from the network to prevent further spread of malware or unauthorized access.

02

Block Malicious Traffic

Implement firewall rules or network access controls to block known malicious IP addresses or communication channels.

03

Preserve Evidence

Balance containment actions with the need to preserve forensic evidence for root cause analysis and potential legal action.

Example: Ransomware

Upon detecting ransomware, immediately disconnect the infected host from the network to prevent encryption of shared drives and other systems.

Risk: Delayed Containment

Delaying containment allows incidents to escalate, increasing damage, data loss, and recovery complexity. Swift action is paramount.

Key Takeaway

Containment is about swift, decisive action to limit incident scope and impact, balancing damage control with the critical need to preserve forensic evidence.
