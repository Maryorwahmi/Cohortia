Log Sources

Network and Server Event Sources

Unpacking Logs from Infrastructure Core

Network Devices

  • Firewalls: Traffic flows, blocked connections.
  • Routers: Network path, connection attempts.
  • IDS/IPS: Detected attacks, suspicious patterns.

Example: Firewall blocking repeated access from a blacklisted IP.

Concrete Example: Network Anomaly

A firewall log shows BLOCK TCP 192.168.1.10:54321 -> 203.0.113.42:4444. This indicates an internal host attempting to connect to a suspicious external IP on a non-standard port, potentially a C2 channel.

Servers

  • OS Logs (Windows Event, syslog): System activity, user access.
  • Application Logs: Web server, database activity, exploits.
  • Authentication Logs: User logins, failed attempts.

Example: Multiple failed logins followed by a successful one from a new user.

Key Takeaway

Network and server logs are foundational for detecting both external attacks and internal system compromises, requiring careful collection and analysis.
