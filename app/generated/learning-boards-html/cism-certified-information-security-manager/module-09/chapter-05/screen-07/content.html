Log Sources

Endpoint, Cloud, and Security Tool Event Sources

Expanding Visibility Beyond the Traditional Perimeter

Endpoints (Workstations, Laptops, Mobile)

  • Process execution, file access, registry changes.
  • Network connections, EDR solutions provide deep visibility.

Example: Unusual process spawning a network connection.

Cloud Environments (AWS, Azure, GCP)

  • API calls, resource provisioning, access attempts.
  • Detailed audit trails for cloud security.

Example: Unauthorized API call to delete a critical resource.

Security Tools (Antivirus, DLP, Scanners)

  • Antivirus: Malware detection alerts.
  • Vulnerability Scanners: Detected vulnerabilities.
  • DLP: Data exfiltration attempts.

Example: DLP alert on sensitive data being uploaded to an unauthorized cloud storage.

Key Takeaway

Modern detection requires integrating logs from endpoints, cloud environments, and specialized security tools to gain comprehensive visibility and detect advanced threats.
