Indicators of Compromise (IoCs)

The Digital Breadcrumbs of an Attack

What are IoCs?

Forensic artifacts found on a network or operating system that indicate a computer intrusion. They are concrete evidence of a compromise.

Common IoC Categories

  • Network-based: Malicious IP addresses/domains, unusual traffic.
  • Host-based: File hashes, suspicious files/registry keys, unauthorized accounts.
  • Behavioral: Unusual authentication patterns, privilege escalation.
  • Email-based: Specific headers/attachments in phishing campaigns.

Concrete Example: IoC in a Log

A web server access log shows a GET /wp-content/plugins/revslider/temp/update_extract/revslider/exploit.php HTTP/1.1 request. The request for a known exploit path (exploit.php within revslider plugin) is a clear IoC, indicating an attempted web application compromise.

Key Takeaway

Identifying and monitoring for Indicators of Compromise is fundamental for confirming security incidents and initiating a timely and effective response.
