Security Information and Event Management (SIEM)

Aggregating and Correlating Security Intelligence

SIEM Core Functions

  • Aggregation: Collects logs from all sources.
  • Normalization: Converts logs to a common format.
  • Correlation: Applies rules to identify attack patterns.
  • Alerting: Notifies security teams of potential incidents.

Popular SIEM Solutions

  • Splunk
  • IBM QRadar
  • Microsoft Sentinel
  • Elastic SIEM

Concrete Example: Correlating Events

A SIEM detects a failed login attempt on a server, followed by a successful login from a different, suspicious IP address, and then unusual data transfer activity. The SIEM correlates these seemingly disparate events into a single, high-priority incident alert, indicating a potential compromise.

Key Takeaway

SIEM systems are essential for centralizing security data, enabling the detection of complex attack patterns through aggregation, normalization, and correlation.
