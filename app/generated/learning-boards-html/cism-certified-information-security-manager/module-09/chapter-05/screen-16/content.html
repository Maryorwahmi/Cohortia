Key Concepts

Essential Terms for Incident Detection

SIEM

Aggregates, normalizes, and correlates security logs from various sources to detect incidents.

EDR

Tools providing continuous monitoring and recording of endpoint activities to detect and respond to threats.

IoCs

Forensic artifacts indicating a computer intrusion (e.g., malicious IPs, file hashes, unusual traffic).

Summary Takeaway

SIEM, EDR, and IoCs form the technological and evidentiary backbone of effective incident detection, enabling organizations to identify and respond to threats proactively.
