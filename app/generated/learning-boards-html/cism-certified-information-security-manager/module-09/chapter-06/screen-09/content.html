Phase 2: Eradication

Eradication: Removing the Threat and Root Cause

Eliminating Malicious Elements and Preventing Recurrence

Key Eradication Actions

1

Remove Malware: Delete malicious files, clean registry entries, and eliminate all traces.

2

Patch Vulnerabilities: Apply security updates to systems that were exploited to close attack vectors.

3

Reconfigure Systems: Harden systems, change default passwords, and implement stronger access controls.

4

Rebuild Compromised Systems: In severe cases, rebuild from trusted, clean images for guaranteed cleanliness.

Supporting Explanation

  • Thoroughness is Key: Incomplete eradication leads to re-infection.
  • Root Cause Focus: Identifying 'how' and 'why' is essential for prevention.
  • CISM's Responsibility: Ensure IRT has access to necessary tools and data (e.g., vulnerability management).
  • Proactive Measures: Eradication often involves implementing stronger security controls.
Example

After a phishing attack, the compromised workstation is scanned, malware removed, and the user's account password is reset. The root cause is identified as a lack of phishing awareness training, which is then scheduled.

Key Takeaway

Eradication is not just about removing the threat, but also about identifying and addressing its root cause to prevent future incidents.
