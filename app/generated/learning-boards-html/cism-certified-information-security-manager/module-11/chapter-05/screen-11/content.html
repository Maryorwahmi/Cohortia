Framework Spotlight

PCI DSS: Securing Cardholder Data

Global standard for payment card industry security

The Payment Card Industry Data Security Standard (PCI DSS) is a global standard for organizations that store, process, or transmit cardholder data, ensuring its protection.

  • •Secure Network: Build and maintain a secure network and systems.
  • •Protect Data: Protect cardholder data with encryption.
  • •Vulnerability Mgmt: Maintain a vulnerability management program.
  • •Access Control: Implement strong access control measures.
Key Takeaway

PCI DSS is a non-negotiable industry standard for anyone handling payment card data, with severe financial and operational consequences for non-compliance.

CISM's Role

Ensuring PCI DSS Compliance

  • •Network Segmentation: Isolate cardholder data environments (CDEs).
  • •Encryption: Implement strong encryption for cardholder data.
  • •Vulnerability Scanning: Conduct regular scans and penetration tests.
  • •Policy Enforcement: Ensure security policies are documented and enforced.
Example: Implementing firewalls and intrusion detection systems to protect the CDE.
Common Misconception

Outsourcing Responsibility

Many organizations mistakenly believe that by using a third-party payment processor, they are entirely absolved of PCI DSS responsibility. While the scope may be reduced, the organization still retains some obligations, particularly regarding how cardholder data is handled before it reaches the processor and how the processor's compliance is validated.
