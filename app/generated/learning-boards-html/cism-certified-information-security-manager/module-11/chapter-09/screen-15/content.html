Key Concepts to Remember

Essential Terms for Security Frameworks

NIST Cybersecurity Framework (CSF)

A voluntary framework to help organizations manage and reduce cybersecurity risk.

NIST CSF Functions

The five core functions: Identify, Protect, Detect, Respond, Recover.

SOC 2 (Service Organization Control 2)

Assurance report on controls relevant to security, availability, processing integrity, confidentiality, or privacy.

Trust Services Criteria (TSC)

Principles used in SOC 2 reports: Security, Availability, Processing Integrity, Confidentiality, Privacy.

Statement of Applicability (SoA)

An ISO 27001 document detailing which Annex A controls are implemented and why.

Summary Takeaway

NIST CSF provides a flexible risk management approach, SOC 2 offers critical third-party assurance, and the SoA clarifies ISO 27001 control implementation, all vital for a CISM.
