Action Phase

Control Implementation and Remediation

Deploying Safeguards and Addressing Gaps

Types of Controls

  • Technical: Firewalls, IDS, encryption, multi-factor authentication.
  • Administrative: Security awareness training, background checks, policies.
  • Operational: Change management, incident response, vulnerability management.
Common Pitfall

Failing to adequately resource remediation efforts or not tracking them to completion can leave critical vulnerabilities unaddressed.

Remediation Plan Components

Identified Gap

e.g., Inadequate access controls.

Remediation Action

e.g., Implement MFA, review permissions.

Owner & Timeline

Accountability and completion target.

Effective remediation turns identified gaps into tangible security improvements.
