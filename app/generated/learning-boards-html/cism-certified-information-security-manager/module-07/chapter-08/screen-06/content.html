The PDCA Cycle: Check and Act in Practice

Monitoring Effectiveness and Formalizing Success

3. Check: Monitor Effectiveness

  • Collect metrics and conduct reviews.
  • Perform tests to verify desired outcomes.
  • Evaluate if changes achieved objectives.

4. Act: Standardize & Refine

  • Standardize successful changes into processes.
  • Initiate further improvements based on 'Check' phase findings.
  • Refine or restart the cycle if changes were ineffective.
Key Takeaway

The 'Check' phase validates improvements, while 'Act' formalizes success or initiates further refinement, ensuring continuous program evolution.

PDCA Cycle: Check & Act

These phases ensure that implemented changes are effective and lead to sustained improvements in the security program.

Example: Phishing Simulation

Check: Run a new phishing simulation after updated awareness training. Act: If click-through rates decrease, formalize the new training. If not, refine the training and re-plan.
