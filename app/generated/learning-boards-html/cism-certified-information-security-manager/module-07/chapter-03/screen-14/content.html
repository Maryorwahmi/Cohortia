Essential Incident Response Concepts

Core Definitions for CISMs

Incident Response Plan (IRP)

A documented set of procedures for detecting, responding to, and recovering from information security incidents.

Incident Response Team (IRT)

A dedicated group of individuals responsible for executing the IRP.

Incident Response Lifecycle

A structured approach to managing security incidents, typically including preparation, detection & analysis, containment, eradication, recovery, and post-incident activity.

Summary Takeaway

Understanding the IRP, IRT, and the Incident Response Lifecycle provides the foundational knowledge for effective security incident management.
