Phase 2: Detecting and Analyzing Incidents

Identifying and Prioritizing Security Events

  • 1

    Monitor Systems: Continuously watch for signs of compromise using various security tools.

  • 2

    Analyze Alerts: Investigate alerts from SIEM, IDS/IPS, and other security solutions.

  • 3

    Differentiate Threats: Distinguish between false positives and actual security incidents.

  • 4

    Prioritize Incidents: Assess impact and urgency to determine response priority.

  • 5

    Gather Initial Evidence: Collect relevant data for forensic analysis and documentation.

Example: SIEM Alert Investigation

A real-world scenario demonstrating detection in action.

Unusual Login Attempts

A SIEM system flags multiple failed login attempts from an unexpected geographic location.

Immediate Investigation

Analysts investigate to confirm if it's a legitimate threat or a false alarm, gathering logs and user context.

Key Takeaway

Detection and Analysis involves monitoring systems for compromise, analyzing alerts from security tools, differentiating threats from false positives, prioritizing incidents, and gathering initial evidence.
