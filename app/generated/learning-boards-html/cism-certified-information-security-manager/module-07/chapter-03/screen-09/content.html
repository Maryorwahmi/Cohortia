Phase 4: Eradicating the Root Cause

Eliminating the Threat Completely

  • 1

    Clean Malware: Remove all malicious software from affected systems.

  • 2

    Patch Vulnerabilities: Apply security patches to address exploited weaknesses.

  • 3

    Reconfigure Systems: Restore secure configurations and remove unauthorized changes.

  • 4

    Rebuild from Backups: Reconstruct compromised servers or data from trusted, clean backups.

Example: Web App Vulnerability

Ensuring the threat is fully removed to prevent recurrence.

Data Breach via Web App

An attacker exploited a vulnerability in a web application to exfiltrate sensitive data.

Patch & Rebuild

The vulnerability is patched, and the web application server is rebuilt from a clean image to ensure no backdoors remain.

Key Takeaway

Eradication focuses on completely removing the root cause of the incident, such as cleaning malware, patching vulnerabilities, reconfiguring systems, or rebuilding from trusted backups, to prevent re-infection.
