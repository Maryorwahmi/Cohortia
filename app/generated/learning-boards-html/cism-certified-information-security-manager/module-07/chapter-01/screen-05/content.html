Metric Type

Operational Metrics: Daily Insights

Tracking Day-to-Day Security Activities and Efficiency

Definition

Measures focusing on the day-to-day activities and immediate efficiency of security controls. These are granular and process-oriented.

Number of patches deployed per week.

Average time to resolve a vulnerability.

Percentage of employees completing security training.

Key Takeaway

Operational metrics provide granular, day-to-day data on security control efficiency, vital for internal team management and process optimization.

Scanning and threat intelligence.

4. Verify & Monitor
