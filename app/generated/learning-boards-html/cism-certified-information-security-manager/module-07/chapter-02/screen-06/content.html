Foundational Security Awareness

Protecting Against Common Cyber Threats: Phishing and Password Security

Phishing and Social Engineering

  • Identify suspicious emails, calls, or messages.
  • Understand common tactics like urgency and impersonation.
  • Know the correct procedure for reporting potential incidents.

Password Security

  • Best practices for creating strong, unique passwords.
  • Importance of avoiding password reuse across accounts.
  • Mandatory use of multi-factor authentication (MFA).

Example: Targeted Phishing

An email appearing to be from the CEO requests urgent wire transfer details. An employee trained in phishing awareness would verify the request through an alternative, trusted channel, preventing a significant financial loss.

Key Takeaway

Strong foundational training in phishing and password security equips employees with essential skills to protect themselves and the organization from common and impactful cyber threats.
