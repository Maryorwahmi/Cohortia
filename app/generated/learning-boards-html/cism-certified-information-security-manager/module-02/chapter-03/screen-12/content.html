Hands-on Activity
Policy Hierarchy Exercise
Use the HealthSecure policy and produce two artifacts: a PHI Encryption Standard and the opening steps of a Procedure for encrypting PHI in cloud storage.
PHI Encryption Standard — checklist
  • AES-256 for PHI at rest.
  • TLS 1.2 or higher for PHI in transit.
  • Keys managed by FIPS 140-2 validated KMS/HSM.
  • Full disk encryption for endpoints storing PHI.
  • Logging and audit records for key and access events.
Procedure — starter steps
Title: Procedure for Encrypting PHI in Cloud Storage
Purpose: Configure cloud storage to meet the PHI Encryption Standard.
Scope: Personnel managing PHI storage.
Steps:
  1. Authenticate with the authorized IAM role for storage management.
  2. Select or create the storage container in the approved region.
  3. Set default server-side encryption with the approved KMS key.
  4. Enforce TLS-only access via bucket policy or network controls.
  5. Enable access and object-level logging and capture key ARN.
  6. Record the key ARN and rotation schedule in the key register.
  7. Run validation checks and capture evidence for the change log.
