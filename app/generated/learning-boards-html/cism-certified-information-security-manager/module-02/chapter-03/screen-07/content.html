Definition
Documentation Hierarchy
Policy
High-level mandatory statements of management intent that define what must be achieved and why.
Standard
Mandatory technical or configuration requirements that implement policies.
Procedure
Step-by-step instructions that operators use to perform tasks that satisfy standards.
Guideline
Advisory best practices that help teams implement standards where full compliance is impractical.
