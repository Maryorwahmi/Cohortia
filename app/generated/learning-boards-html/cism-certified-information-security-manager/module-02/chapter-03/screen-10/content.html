Architecture
Control Mapping Template
1. Business Process
E.g., Patient records intake and storage.
2. Assets & Data
E.g., PHI databases, object storage, backups.
3. Mapped Controls
List standards and procedures that mitigate identified risks.
4. Owner & Metrics
Assign an owning team and a measurable metric for compliance.
Example: PHI in cloud storage
Process: Store patient intake forms. Assets: S3 buckets, backup snapshots. Controls: PHI Encryption Standard, S3 encryption procedure, access logging requirement. Owner: Cloud Security Team. Metrics: percentage of buckets with SSE-KMS enabled; last key rotation date; access log completeness.
Why this matters
Auditors and leadership will want to see that controls were chosen because they address specific business risks and that compliance can be measured and improved.
