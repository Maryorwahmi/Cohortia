Module 3 › Chapter 2.6 › Data Collection
Sources
SIEM: alerts and event volumes; useful but noisy.
Vulnerability scanners: findings and patch status; authoritative for vulnerabilities.
IRP/SOAR: incident lifecycle timestamps for MTTD and MTTR.
Asset inventory: owners, criticality, and dependencies.
Surveys and training platforms: human-factor metrics.
Collection Plan
Define owner, cadence, validation, and storage for each metric.
Example: % critical vulns remediated
Owner: Vulnerability Manager; Cadence: weekly; Validation: reconcile with change logs; Storage: GRC platform.
Pitfall: accepting unvalidated or overlapping data sources creates inconsistent trends and erodes trust.
