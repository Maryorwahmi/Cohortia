Module 3 › Chapter 2.6 › Dashboard Design
Board visualization
Line charts with target bands, one-sentence narrative, and a financial impact estimate. Color: green/amber/red status.
Headline: "Reduction in critical vulnerability exposure estimated to save X in potential loss."
Executive visualization
Project progress bars, resource heatmaps, annotated incident summaries and recommended decisions.
Operational visualization
Prioritized lists, sortable tables, incident timelines with timestamps and runbook links.
Annotation pattern: Title (one sentence), What changed (one line), Recommended action (one line), Owner.
Consistency tip: Use the same metric definitions and time windows across all views so trends are comparable.
