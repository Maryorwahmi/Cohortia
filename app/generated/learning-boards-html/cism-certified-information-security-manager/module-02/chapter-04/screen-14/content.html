Module 2 › Chapter 2.4 › Key Concepts
Segregation of Duties

Divide critical tasks so no single person can both perform and conceal a harmful action.

Accountable vs Responsible

One accountable owner; one or more responsible parties. Document both to avoid gaps and overlaps.

Technical Controls

RBAC, PAM, immutable logs and automated alerts are essential to enforce SoD in daily operations.

Summary Takeaway

A secure program pairs clear role definitions with technical enforcement and regular independent review. That combination prevents single-point abuse and supports reliable audits.
