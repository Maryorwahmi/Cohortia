Definition

RACI for security activities

Use RACI to assign roles for repeatable tasks like patch deployment and incident response.

Note: ensure only one Accountable per activity and record the matrix for audit and training purposes.
Concrete example
Initial Detection & Verification: SOC Analyst (R), IT Ops Manager (A), CISO (C), Executive Management (I). This prevents both duplication and gaps.
Common mistake
Multiple Accountable persons confuse escalation. Always pick a single A for clarity.
Key Takeaway

A clear RACI matrix removes ambiguity and supports auditability and escalation for security tasks.
