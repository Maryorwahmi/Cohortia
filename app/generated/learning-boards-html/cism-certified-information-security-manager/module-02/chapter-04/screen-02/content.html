Learning Objectives

Learn, Understand, Apply, Master — a short pathway to verified competency.

Bloom: Learn → Understand → Apply → Master
01
Identify key security roles
List who holds responsibility from the Board to users and why each role matters for protecting assets.
Mnemonic: Pyramid — oversight, leadership, operations, users.
VERIFIED COMPETENCY MILESTONE
02
Define and assign responsibilities
Translate high-level governance into specific, assigned actions so accountability can be enforced and measured.
Visual: 2×2 role/task grid showing gaps and overlaps.
VERIFIED COMPETENCY MILESTONE
03
Use a RACI matrix
Assign who is Responsible, Accountable, Consulted, and Informed for specific security tasks to avoid ambiguity.
Visual: labeled table cells for R,A,C,I.
VERIFIED COMPETENCY MILESTONE
04
Apply Segregation of Duties
Design roles so no one individual can undetectably create and exploit a vulnerability or commit fraud.
Mnemonic: Two keys to the vault — split authority.
VERIFIED COMPETENCY MILESTONE
