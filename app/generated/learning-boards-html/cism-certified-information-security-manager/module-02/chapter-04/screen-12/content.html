Module 2 › Chapter 2.4 › Cloud Migration Roles
Role Mapping

Sample Accountability & Responsibility

Responsibility / Accountable
  • Data Classification: A = Data Owner · R = Data Owner
  • Cloud Security Policy: A = CISO · R = Cloud Architect
  • Technical Controls: A = Cloud Architect · R = Cloud Operations Team
  • Audit & Assurance: A = Internal Audit · R = Internal Audit
  • Incident Response: A = CISO · R = Cloud Operations Team, SOC
Justification

Business owners understand sensitivity, architects design secure patterns, operations implement controls, and audit provides independent review. This separation reduces conflict and enforces checks.

Deployment Gates

Use formal gates for design approval, security control validation, and final acceptance. Each gate requires signatures from accountable roles to proceed.

Key Takeaway

Document accountability in the charter, require independent review, and gate deployments to preserve SoD during migration.

Concrete Action

Migration Checklist

  • Assign A and R for each responsibility.
  • Record approvals in the project charter.
  • Enable PAM for deployment tasks.
  • Schedule independent post-migration audit.
Check Your Plan

Does your migration plan clearly show who will attest to compliance after cutover? If not, add an accountable owner and an independent reviewer.
