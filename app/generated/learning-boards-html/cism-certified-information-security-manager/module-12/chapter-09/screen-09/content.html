Response Phase

Eradication: Eliminating the Threat

Removing the root cause and all traces of the attacker.

Eradication Actions

  • Patching vulnerabilities exploited by the attacker.
  • Cleaning malware from all infected systems.
  • Rebuilding compromised systems from trusted, clean backups.
  • Implementing stronger security controls to prevent recurrence.
Key Takeaway

Eradication is about thorough removal of the threat and its root cause, ensuring that the organization is not vulnerable to the same attack again.

Eradication Process

Identify Root Cause

Vulnerability, misconfiguration

Remove Malicious Components

Malware, backdoors, rogue accounts

Secure & Harden Systems

Patching, configuration changes
