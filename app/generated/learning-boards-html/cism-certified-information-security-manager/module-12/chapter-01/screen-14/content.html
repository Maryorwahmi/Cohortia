Key Concepts

Essential terms for AI/ML security

Adversarial AI

Techniques used to fool machine learning models, often by making subtle modifications to input data or by poisoning training data.

Data Poisoning

An attack where malicious data is introduced into an AI model's training set, causing the model to learn incorrect patterns or biases.

Model Inversion

An attack that aims to reconstruct sensitive information from the training dataset by querying the deployed AI model.

Summary Takeaway

These concepts highlight the diverse and sophisticated ways AI systems can be attacked, from corrupting data to extracting sensitive information.
