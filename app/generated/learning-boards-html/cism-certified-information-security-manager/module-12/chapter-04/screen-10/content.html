The Advanced Shared Responsibility Model

Understanding how security responsibilities shift between cloud providers and customers across IaaS, PaaS, and SaaS models.

IaaS (Infrastructure as a Service)

Customer manages OS, network config, applications, and data. Provider manages physical infrastructure.

PaaS (Platform as a Service)

Customer manages applications and data. Provider manages OS, middleware, and runtime.

SaaS (Software as a Service)

Customer manages data and user access. Provider manages almost everything else, including applications.

Common Misconception

A frequent mistake is assuming the cloud provider handles all security. In reality, the customer always retains some level of responsibility, especially for data and access management, regardless of the service model.

Key Takeaway

Clearly understanding and communicating the shared responsibility model is paramount for CISM professionals to ensure all security tasks are appropriately assigned and managed, preventing critical gaps.
