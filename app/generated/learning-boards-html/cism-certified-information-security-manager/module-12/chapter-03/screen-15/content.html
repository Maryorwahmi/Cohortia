Key Concepts

More essential terms and ideas from this chapter.

51% Attack

An attack where an entity controls >50% of network computing power/stake, potentially manipulating the ledger.

Reentrancy Vulnerability

A smart contract bug allowing an external contract to repeatedly call back before execution finishes, draining funds.

Private vs. Public Blockchain

Distinction between open, permissionless DLTs and restricted, permissioned DLTs, each with unique security models.

Summary Takeaway

Understanding specific attack vectors like 51% attacks and reentrancy, alongside the differences between public and private DLTs, is crucial for comprehensive security management.
