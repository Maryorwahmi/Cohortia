Dynamic Application Security Testing (DAST)

Testing Running Applications for Runtime Vulnerabilities

What DAST Does

Tests a running application from the outside, simulating attacks to find vulnerabilities that manifest at runtime.

Vulnerabilities Found

Authentication flaws, session management issues, server-side misconfigurations, business logic flaws.

Integration Point

Typically used in staging/test environments after the application is built and deployed.

DAST vs. SAST: Complementary Approaches

SAST

  • White-box testing
  • Scans source/compiled code
  • Finds coding errors
  • Early in SDLC

DAST

  • Black-box testing
  • Tests running application
  • Finds runtime issues, config flaws
  • Later in SDLC (staging)
Key Takeaway

DAST provides a crucial black-box perspective, testing the running application to uncover vulnerabilities that only manifest at runtime, complementing static analysis.
