Definition

What is Data Classification?

Data classification is the process of categorizing data based on its sensitivity and potential business impact if compromised. It's a fundamental step in determining appropriate security controls.

Sensitivity

A measure of potential harm if data is disclosed, altered, or destroyed without authorization.

Business Impact

The potential negative consequences to the organization if specific data is compromised.

Key Takeaway

Data classification ensures that security efforts are aligned with the actual value and risk of the information, preventing both over- and under-protection.

Common Misconception

One Size Fits All Security

A common mistake is assuming all data requires the same level of protection. This leads to inefficient resource allocation and potential vulnerabilities for truly sensitive information.

CISM's Mandate

Ensure clear data classification policies are defined and understood across all business units before any third-party engagement.
