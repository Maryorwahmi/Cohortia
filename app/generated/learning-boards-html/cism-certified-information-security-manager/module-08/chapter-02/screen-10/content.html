Mandatory Data Classification for Engagements

Avoiding Common Pitfalls in Vendor Risk

01

Initial Engagement: Public Data

Marketing agency accesses only public materials (website, social media content).

Outcome

Data Classification: Public
Associated Risk: Low
Security Requirements: Basic contractual terms.

02

Expanded Engagement: Sensitive Data

Marketing agency gains access to customer email lists containing PII for targeted campaigns.

Outcome

Data Classification: Confidential / Restricted
Associated Risk: High
Security Requirements: Significantly more stringent, including audits and detailed clauses.

Key Takeaway

Mandatory data classification for every third-party engagement prevents underestimating risk and ensures appropriate security controls are in place.
