Understanding Standard Data Sensitivity Tiers

From Public Information to Restricted Data

01

Public

Information intended for general public consumption; no harm if disclosed.

Example

Company press releases, public website content.

02

Internal Use Only

Not for public disclosure; minor inconvenience if disclosed.

Example

Internal memos, organizational charts.

03

Confidential

Unauthorized disclosure would cause serious harm to the organization.

Example

Customer PII, financial data, trade secrets.

04

Restricted

Unauthorized disclosure would cause severe or catastrophic harm, often legally protected.

Example

Highly sensitive PII, classified intellectual property.

Key Takeaway

Each data classification level demands specific security controls, ensuring that the most sensitive information receives the highest degree of protection.
