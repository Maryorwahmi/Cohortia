Learning Objectives: Part 2

Advanced skills for managing third-party security compliance.

Bloom's Taxonomy:

03

Establish KPIs and Metrics

Establish key performance indicators (KPIs) and metrics for evaluating third-party security effectiveness. Learn to align these with contractual security clauses and SLAs.

VERIFIED COMPETENCY MILESTONE
04

Formulate Remediation Strategies

Formulate strategies for managing non-compliance and ensuring remediation of identified security deficiencies. This includes notification, plan development, verification, and escalation.
