RISK CATEGORY

Vulnerabilities in the Software Ecosystem

From open-source to update mechanisms.

Common Software Risk Vectors

  • Open-Source Libraries: Vulnerabilities in widely used, publicly available code.
  • COTS Software: Commercial off-the-shelf products with embedded, unverified components.
  • Development Toolchains: Compromised compilers, build servers, or IDEs.
  • Update Mechanisms: Malicious code injected into legitimate software updates.
  • Software Repositories: Tampered code or compromised access to package managers.
Key Takeaway

Software supply chain risks are pervasive, requiring vigilance over all components, development tools, and distribution channels to ensure integrity.

Software Supply Chain Flow

1. Open-Source / COTS Components

2. Development & Build Environments

3. Software Repositories & Distribution

4. Updates & Deployment

Example: SolarWinds Attack

Malicious code injected into a software update mechanism, compromising thousands of organizations globally.
