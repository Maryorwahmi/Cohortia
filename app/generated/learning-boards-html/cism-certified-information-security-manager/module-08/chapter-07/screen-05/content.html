Assessment Method

Software Bill of Materials (SBoM) and SCA

Gaining transparency into software components and dependencies.

What is an SBoM?

A detailed inventory of all open-source and commercial components, libraries, and dependencies within a software product.

How SBoM Helps

Allows cross-referencing components against known vulnerability databases (e.g., CVEs) to identify risks.

Software Composition Analysis (SCA)

Automated tools that scan software for known vulnerable components, streamlining the assessment process.

Key Takeaway

SBoM and SCA are foundational for proactive software supply chain risk management, providing essential visibility into component-level vulnerabilities.

Demand SBoMs from all software vendors and integrate SCA tools into your procurement and continuous monitoring processes to automatically detect vulnerable components.
