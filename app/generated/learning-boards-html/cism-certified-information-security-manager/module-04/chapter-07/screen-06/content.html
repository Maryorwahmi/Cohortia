Populating a Risk Register Entry

See how a specific risk is documented with all its essential attributes.

Example Entry:
  • Risk ID: R001
  • Description: Data breach of sensitive customer PII due to unpatched web server.
  • Assets: Customer Database, Web Server
  • Threat/Vulnerability: External attacker / CVE-2023-XXXX (unpatched Apache)
  • Likelihood: High, Impact: Catastrophic
  • Inherent Risk: Extreme
  • Existing Controls: Firewall, IDS
  • Residual Risk: High
  • Owner: IT Operations
  • Treatment: Mitigate
  • Mitigation Plan: Patch server, implement WAF, weekly scans.
  • Target Residual Risk: Medium
  • Status: In Progress
  • Review Date: 2024-03-15
Key Takeaway

Each field in the risk register entry provides critical context for understanding, prioritizing, and managing the risk effectively.
