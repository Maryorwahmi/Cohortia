Populating a New Risk Entry

Let's apply what we've learned to a practical scenario.

Scenario:

Risk: Unauthorized access to internal HR data via a vulnerable legacy application.

Your Task:
  • Risk ID: R005
  • Description: Unauthorized access to internal HR data via a vulnerable legacy application.
  • Assets Affected: HR Database, Legacy HR Application
  • Threat/Vulnerability: Insider threat or external attacker / Unpatched SQL injection vulnerability.
  • Likelihood (Inherent): High
  • Impact (Inherent): Catastrophic
  • Existing Controls: Basic firewall, antivirus.
  • Risk Owner: Head of Human Resources
  • Treatment Strategy: Mitigate
  • Mitigation Plan: Patch app, implement WAF, migrate data (6mo), awareness training.
  • Target Residual Risk: Medium
  • Status: Open
  • Review Date: [Today's Date]
Key Takeaway

Documenting risks thoroughly with all relevant attributes is crucial for effective tracking, prioritization, and management.
