Key Concepts

Essential Terms for Vulnerability Management

Vulnerability

A weakness in an asset or its protective controls that can be exploited by a threat.

Vulnerability Scanner

An automated tool that identifies known security weaknesses in systems, networks, or applications.

Configuration Review

The process of examining system and application configurations against security baselines.

Summary Takeaway

Understanding these core concepts provides the foundation for identifying and addressing security weaknesses across all domains.
