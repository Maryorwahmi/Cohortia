Defining Vulnerabilities

Gaps in Security Controls That Threats Can Exploit

Definition

A vulnerability is a weakness in an asset or its protective controls that can be exploited by a threat to cause harm or unauthorized access.

Understanding vulnerabilities means recognizing they are not just technical. They represent any flaw that could be leveraged, requiring a broad perspective for effective security management.

Key Takeaway

Effective vulnerability identification requires looking beyond technical flaws to include process and human weaknesses.

Technical Vulnerabilities

  • Software bugs and coding errors
  • Misconfigurations in systems or networks
  • Weak encryption protocols
  • Unpatched operating systems or applications

Process-Related Vulnerabilities

  • Lack of robust change management
  • Inadequate incident response plans
  • Poor backup and recovery procedures
  • Weak access control policies and enforcement

Human-Related Vulnerabilities

  • Insufficient security awareness training
  • Weak password creation habits
  • Susceptibility to social engineering attacks
  • Insider negligence or malicious intent
