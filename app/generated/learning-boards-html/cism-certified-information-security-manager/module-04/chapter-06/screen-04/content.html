Core Concept
Single Loss Expectancy (SLE)
Quantifying the immediate financial impact of a single threat event.
Formula

SLE = Asset Value (AV) × Exposure Factor (EF)

Example Calculation
Asset Value (AV)
$1,000,000
Exposure Factor (EF)
0.4 (40% data loss)
Single Loss Expectancy (SLE)
$400,000
