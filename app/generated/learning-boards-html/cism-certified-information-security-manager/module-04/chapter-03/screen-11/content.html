Deconstructing STRIDE for Threat Analysis

Categorizing Threats for Comprehensive System Review

S Spoofing

Impersonating something or someone else (e.g., attacker pretending to be a legitimate user).

Example

Phishing email with a fake sender address.

T Tampering

Modification of data or code (e.g., altering a transaction, injecting malicious code).

Example

SQL injection to modify database records.

R Repudiation

Denying an action without proof to the contrary (e.g., user denying a money transfer).

Example

Lack of audit trails for critical system changes.

I Information Disclosure

Exposure of sensitive data to unauthorized individuals (e.g., system leaking customer details).

Example

Unencrypted data transmitted over public networks.

D Denial of Service

Preventing legitimate users from accessing a service or resource (e.g., DDoS attack).

Example

Overwhelming a web server with traffic.

E Elevation of Privilege

Unprivileged user gains unauthorized higher-level access (e.g., standard user becoming admin).

Example

Exploiting a software bug to gain root access.

Key Takeaway

STRIDE provides a systematic framework for identifying diverse threats by categorizing them into Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, and Elevation of Privilege.
