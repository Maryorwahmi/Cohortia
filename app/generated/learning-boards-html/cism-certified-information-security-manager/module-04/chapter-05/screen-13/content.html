Chapter Summary

Key Concepts

Essential definitions from this chapter.

Qualitative Risk Assessment

A subjective method using descriptive terms (e.g., High, Medium, Low) for likelihood and impact.

Quantitative Risk Assessment

An objective method using numerical values and financial terms for likelihood and impact.

NIST RMF

A structured, multi-step process for managing risk to information systems, primarily for U.S. federal agencies.

Summary Takeaway

Understanding the core differences between qualitative and quantitative risk assessments, alongside key frameworks like NIST RMF, is fundamental for effective security management.
