Learning Objectives

Learn → Understand → Apply → Master

01
Explain culture's role

Define how shared values and routines influence security behavior and incident outcomes. Example: a team that feels safe to report errors reduces hidden breaches.

VERIFIED COMPETENCY MILESTONE
02
Identify human vulnerabilities

Recognize common behaviors that lead to breaches, like clicking phishing links or weak password reuse. Example: spotting social engineering indicators in emails.

VERIFIED COMPETENCY MILESTONE
03
Describe training components

Articulate the parts of an effective program: objectives, role-based content, engaging delivery, cadence, policy links, and leadership support.

VERIFIED COMPETENCY MILESTONE
04
Measure and improve

Use metrics like phishing click-through, reporting rates, completion, quiz scores, and incident trends to refine programs and show ROI.
