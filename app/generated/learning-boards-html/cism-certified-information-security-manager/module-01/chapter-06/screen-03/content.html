Module 2 › Chapter 1.6 › Objectives — Skills and Evidence

Apply and Prove It

Create scenarios, run a phishing simulation, and collect evidence. Focus on metrics that show behavior change rather than only completion statistics.

Skill
Design a targeted phishing simulation
Evidence
Phishing click rate and reporting rate trends
Leadership
Visible executive support and policy reinforcement
Avoid
Treating training as a checkbox or using irrelevant content
Milestone
Complete a simulation plan and a targeted follow-up module with measurable success criteria.
