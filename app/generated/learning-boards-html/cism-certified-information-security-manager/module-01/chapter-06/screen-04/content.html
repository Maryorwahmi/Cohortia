Module 2 › Chapter 1.6 › Organizational Culture: definition and impact
Definition

Shared values, beliefs, and everyday practices that influence how employees perceive and act on security responsibilities.

Impact Example
Daily team rituals that encourage reporting reduce time to detect and contain incidents.
Common Mistake
Relying solely on technical controls while ignoring how people actually work.
Key Takeaway
Culture shapes whether security practices survive real-world pressures.
Practical Cards
Recognition
Acknowledge employees who report issues to reinforce reporting behavior.
Routine
Embed short security reminders into daily work processes.
Leadership
Visible support from management signals that security matters.
