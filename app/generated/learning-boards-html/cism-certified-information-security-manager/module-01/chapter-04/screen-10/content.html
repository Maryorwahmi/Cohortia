DataSecure Corp - Data Classification

1. Purpose: Establish a framework for classifying information assets by sensitivity to ensure appropriate protection.

2. Scope: Applies to all employees, contractors, vendors, and information assets in any format or location.

3. Classification Levels:
  - Public: Information intended for public release; minimal handling controls.
  - Internal: For internal use; protected from external disclosure.
  - Confidential: Sensitive business or personal data; requires encryption and access controls.
  - (Optional) Restricted: Highly sensitive assets requiring the highest protections.

4. Responsibilities: Data Owners classify and review assets. Data Users handle information per classification. InfoSec maintains guidance and enforces policy.

5. Review: Annual review or when significant changes occur.
Key Takeaway

Keep the statement concise, name owners, and include handling requirements and a review cadence.

Example use

Use this template as the high-level text and link to standards for encryption, access controls, and procedures for labeling and handling.

Check your draft
  • Is purpose stated and tied to risk?
  • Is scope explicit?
  • Are levels described with handling requirements?
  • Is an owner named and review cadence set?
Common mistake

Avoid placing encryption commands or technical configuration details inside this high-level statement; link to standards and procedures instead.
