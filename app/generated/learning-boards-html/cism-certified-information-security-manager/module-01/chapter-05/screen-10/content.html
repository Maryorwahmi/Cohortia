Module 1 › Chapter 1.5 › Compliance Frameworks
ISO/IEC 27001
An international standard for ISMS with a formal certification process. It provides a management system approach to protecting information through documented policies and controls.
NIST CSF
A voluntary, risk-based framework widely used to manage cybersecurity risk across identify, protect, detect, respond, and recover functions.
COBIT
A governance-focused framework linking IT controls to business objectives and performance metrics, useful for executive reporting and governance alignment.
How to use a framework
  1. Choose a framework as the program backbone based on regulatory overlap and stakeholder needs.
  2. Map legal requirements to framework controls so one control can satisfy multiple obligations where appropriate.
  3. Document evidence and assign control owners linked to framework outcomes for audits.
Key takeaway

Use frameworks to create an auditable program that reduces duplication and demonstrates due diligence across regulations.
