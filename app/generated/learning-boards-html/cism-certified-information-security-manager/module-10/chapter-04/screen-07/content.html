NIST Phase: Detection & Analysis

Detection & Analysis: Spotting the Signs

From Security Events to Confirmed Incidents

Key Activity

Monitoring security tools (SIEM, IDS/IPS) and analyzing logs for anomalies.

Misconception

Every alert is an incident. False positives can lead to alert fatigue and wasted resources.

Key Takeaway

The Detection & Analysis phase focuses on identifying potential security events through continuous monitoring and confirming them as actual incidents.

The Detection & Analysis Flow

1. Monitor Security Tools

SIEM, IDS/IPS, EDR, network traffic

2. Analyze Logs & Triage Alerts

Look for anomalies, correlate events, prioritize severity

3. Confirm Incident

Verify if an event is a genuine security incident
