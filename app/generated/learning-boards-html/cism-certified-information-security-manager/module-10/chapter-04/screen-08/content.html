Detection & Analysis: Gathering Intelligence

Collecting Information and Prioritizing the Response

Example Scenario

Unusual outbound traffic from a server, correlated with a new user account, escalates to a high-priority incident.

Documentation is Key

Thorough documentation of findings forms the basis for subsequent actions and forensic analysis.

Key Takeaway

Effective incident analysis involves rapid information gathering, accurate classification, and strategic prioritization to guide subsequent response actions.

Information Gathering & Prioritization

Initial Information

Affected systems, compromised data, start time, attack vector.

Incident Classification

Categorize by type (malware, unauthorized access, DoS).

Prioritization

Based on impact to business, data confidentiality, integrity, availability.

Thorough Documentation

Record all findings for forensic analysis and legal basis.
