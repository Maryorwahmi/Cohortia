Detection Mechanisms

IDS vs. IPS: Monitor and Protect

Understanding Network and Host-Based Systems

Intrusion Detection System (IDS)

Monitors for malicious activity and policy violations, generating alerts.

Intrusion Prevention System (IPS)

Extends IDS by actively blocking or preventing detected threats.

Signature-Based Detection

Effective against known threats by matching predefined patterns. Struggles with zero-days.

Anomaly-Based Detection

Establishes normal behavior baselines and flags deviations. Prone to false positives if not tuned.

Deployment Types

Network-based (NIDS/NIPS)

Monitors traffic across network segments for malicious activity.

Host-based (HIDS/HIPS)

Operates on individual servers or workstations, monitoring system calls and file integrity.

Key Takeaway

IDS provides alerts, while IPS actively prevents threats. Both NIDS/NIPS and HIDS/HIPS utilize signature and anomaly-based detection, each with distinct advantages and challenges.
