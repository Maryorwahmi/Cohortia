Module 10 › Chapter 10.5 › Preserving Evidence During Containment

The Importance of Evidence

While containment focuses on stopping the attack, preserving evidence is crucial for understanding the incident and for legal/forensic purposes.

Supports root cause analysis.
Maintains chain of custody.

Key Actions for Preservation

Forensic images of compromised systems should be taken *before* significant changes are made, if possible.

  • Imaging: Create bit-for-bit copies of affected drives.
  • Documentation: Record all actions, timestamps, and personnel.
  • Prioritization: Integrate preservation into IR plan and training.

Example: Compromised Server

A critical database server is found to be compromised and actively exfiltrating data.

  • Incorrect Action: Immediately power off the server. (Destroys volatile memory evidence)
  • Correct Action: First, capture volatile memory (RAM) image, then create a full disk image, then disconnect from network.
  • Rationale: Preserves maximum evidence for forensic analysis.
Key Takeaway

Evidence preservation is a non-negotiable aspect of containment, ensuring accountability and enabling thorough post-incident analysis.
