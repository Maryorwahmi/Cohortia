Strategy Overview

Immediate Actions to Halt Attacks

Short-term containment focuses on rapid, often disruptive measures to stop an attack's progression, limit its scope, and prevent further damage. Speed is paramount.

Core Techniques

Network Segmentation

Host Isolation

Immediate Firewall Rules

Example Scenario

DDoS Attack on a Database Server

If a critical database server is under a DoS attack, immediate short-term containment might involve:

  • •Blackholing the attacker's IP address at the perimeter firewall.
  • •Leveraging a DDoS mitigation service to absorb and filter malicious traffic.
  • •Temporarily re-routing traffic to a clean, hardened server.
Consideration: Disruption

These actions are often highly disruptive to normal business operations but are deemed necessary to prevent greater, more widespread harm.

Key Takeaway

Short-term containment prioritizes immediate threat neutralization over business continuity, using decisive actions to prevent an incident from escalating.
