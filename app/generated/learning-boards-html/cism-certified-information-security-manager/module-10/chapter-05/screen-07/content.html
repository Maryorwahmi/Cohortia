Technique Overview

Disconnecting Compromised Systems

Host isolation involves severing a compromised system's network connectivity to prevent malware propagation, data exfiltration, and attacker lateral movement within the network.

Methods of Isolation
  • •Physical disconnection (unplugging cables).
  • •Disabling network adapters (logical).
  • •Applying host-based firewall rules.
Code Example: Windows Host Isolation

Disabling Network Adapter with PowerShell

# Disable network adapter on a Windows machine
Disable-NetAdapter -Name "Ethernet0" -Confirm:$false
Caution: Extreme Disruption

This action will immediately halt all network communication for the specified adapter. Use with extreme caution as it will disrupt all services running on the host.

Key Takeaway

Host isolation is a highly effective but disruptive containment measure, requiring careful consideration of business impact and forensic evidence preservation.
