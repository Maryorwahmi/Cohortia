Rapid Firewall Rule Deployment

Firewall rules are a primary tool for short-term containment, allowing immediate blocking of malicious IP addresses, ports, or traffic patterns to prevent further attack progression.

Key Actions
  • •Block known malicious source IPs.
  • •Restrict outbound connections from compromised hosts.
  • •Disable specific ports or protocols used by attackers.
Code Example: Linux Firewall

Blocking Malicious IP with `iptables` and `firewall-cmd`

# Block all traffic from a known malicious IP to sensitive internal network
iptables -A INPUT -s 198.51.100.10 -j DROP

# Using firewall-cmd for persistent rules (CentOS/RHEL)
firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="198.51.100.10" reject'
firewall-cmd --reload
Explanation

These commands add rules to the firewall to immediately drop or reject any incoming connections from the specified malicious IP address, effectively cutting off its access.

Key Takeaway

Firewall rules provide an immediate and effective way to block attacker communications, but require careful implementation to avoid unintended service disruption.
