Module 10›Chapter 3›Security Analysts: Triage and Investigation
Tier 1

Alert Triage

Monitor security tools (SIEM, EDR), perform initial alert validation, and escalate confirmed incidents. They are the first line of detection.

Tier 2

Incident Handlers

Investigate escalated incidents, perform initial containment, gather forensic data, and execute specific response procedures. They have deeper technical skills.

Key Takeaway

A clear distinction between Tier 1 and Tier 2 roles ensures efficient alert processing and focused incident investigation, preventing alert fatigue and improving response times.

The Analyst Progression

Incidents flow from initial detection to deeper investigation, requiring different skill sets at each stage.

Tier 1 Example

Unusual Login Alert

A Tier 1 analyst receives an alert for a login from an unusual geographic location. They quickly verify if the user is traveling or if it's a false positive before escalating.

Tier 2 Example

Malware Containment

A Tier 2 analyst investigates an escalated malware alert, analyzes its behavior, isolates affected systems, and deploys countermeasures to prevent further spread.
