Creating a Virtual Network and Subnet

# Step 1: Create a resource group
az group create --name MyNetworkRG --location westus

# Step 2: Create a virtual network
az network vnet create --resource-group MyNetworkRG --name MyVNet --address-prefix 10.0.0.0/16

# Step 3: Create a subnet within the virtual network
az network vnet subnet create --resource-group MyNetworkRG --vnet-name MyVNet --name MySubnet --address-prefix 10.0.1.0/24
Explanation
  • 1. Resource Group: We first establish a logical container, MyNetworkRG, in westus to hold our network components.
  • 2. Virtual Network (VNet): Next, we create MyVNet within our resource group, defining its overall IP address space as 10.0.0.0/16.
  • 3. Subnet: Finally, we create MySubnet inside MyVNet, allocating a smaller IP range 10.0.1.0/24 for specific resources.
  • Automation Benefit: These commands can be easily combined into a script for rapid, consistent, and repeatable deployments of network infrastructure.
Key Takeaway

Azure CLI allows for precise, programmatic control over network resource creation, enabling efficient and scalable infrastructure deployment.
