Flexible Output Options

Tailoring CLI Output for Your Needs

Azure CLI supports various output formats, crucial for scripting and integrating with other tools. This allows for easy parsing and data extraction.

JSON / JSONC

Standard for programmatic parsing; JSONC includes comments.

Table

Human-readable, formatted as a clear table in the console.

TSV

Tab-separated values, simple for scripting and spreadsheet import.

YAML

Human-friendly data serialization format, often used for configuration.

Example: Querying JSON Output
# Create a resource group and output its ID
az group create --name MyQueryRG --location eastus --query id --output tsv

# Expected Output (example):
/subscriptions/<subscription-id>/resourceGroups/MyQueryRG

Using --query with --output tsv allows you to extract specific data points directly, making it ideal for chaining commands in scripts.

Key Takeaway

Leveraging Azure CLI's output formats and the --query parameter is essential for building robust, data-driven automation scripts.
