Creating Storage & Uploading Files

# 1. Create a resource group
az group create --name MyStorageRG --location eastus

# 2. Create a storage account (replace with unique name)
az storage account create --name mycohortiastorage123 --resource-group MyStorageRG --location eastus --sku Standard_LRS --kind StorageV2

# 3. Get connection string
az storage account show-connection-string --name mycohortiastorage123 --resource-group MyStorageRG --query connectionString --output tsv

# 4. Set connection string as environment variable
export AZURE_STORAGE_CONNECTION_STRING="<paste_your_connection_string_here>"

# 5. Create a container
az storage container create --name myfiles

# 6. Create a local text file
echo "Hello, Cohortia! This is my first file in Azure Storage." > myfirstfile.txt

# 7. Upload the file
az storage blob upload --container-name myfiles --file myfirstfile.txt --name myfirstfile.txt

# 8. Verify upload
az storage blob list --container-name myfiles --output table
Key Steps Explained
  • Resource Group: Establishes a logical boundary for our storage resources.
  • Storage Account: Provisions the core storage service, specifying its type and redundancy.
  • Connection String: Essential for authenticating subsequent storage operations.
  • Container & Blob: Demonstrates creating a logical folder and uploading a file (blob) into it.
  • Verification: Confirms the successful upload by listing the blobs.
Key Takeaway

The Azure CLI provides comprehensive control over Azure Storage, from provisioning accounts to managing data, ideal for automated workflows.
