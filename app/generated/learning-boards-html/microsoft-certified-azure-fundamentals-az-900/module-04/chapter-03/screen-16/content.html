Module 4 › Chapter 4.3 › Key Concepts

Azure Portal

A web-based, unified console providing a graphical user interface for managing all Azure resources visually.

Azure Cloud Shell

An interactive, browser-accessible shell pre-configured with Azure CLI, Azure PowerShell, and other tools for command-line management.

Azure CLI

A set of commands used to create and manage Azure resources, available locally or in Cloud Shell, ideal for scripting and automation.

Summary Takeaway

The Azure Portal, Cloud Shell, and Azure CLI are distinct yet complementary tools, each offering unique advantages for managing your cloud resources effectively.
