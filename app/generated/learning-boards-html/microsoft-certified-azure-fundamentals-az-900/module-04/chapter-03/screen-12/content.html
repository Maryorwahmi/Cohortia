Module 4 › Chapter 4.3 › Tool Selection

Azure Portal

Best For: Visual management, ad-hoc tasks, monitoring, exploring services, and individual resource configuration.

  • Intuitive GUI
  • Beginner-friendly
  • Real-time monitoring

Azure Cloud Shell

Best For: Quick command execution, script testing, managing resources from any device, learning CLI commands.

  • Browser-based CLI
  • Pre-configured tools
  • Persistent storage

Azure CLI

Best For: Automation, scripting, Infrastructure as Code (IaC), repetitive tasks, CI/CD integration.

  • Powerful scripting
  • Programmatic control
  • Fast and efficient
Key Takeaway

Effective Azure management involves strategically combining the Azure Portal for visual tasks, Cloud Shell for quick CLI access, and Azure CLI for automation and scripting.
