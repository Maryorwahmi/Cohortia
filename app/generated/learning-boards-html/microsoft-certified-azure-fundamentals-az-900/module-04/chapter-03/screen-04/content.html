Core Concept

The Azure Management Ecosystem

Diverse Tools for Comprehensive Cloud Control

Azure Portal

Web-based graphical interface for visual management and monitoring.

  • Intuitive for beginners
  • Visual resource configuration
  • Ad-hoc management

Azure Cloud Shell

Browser-accessible command-line environment with pre-installed tools.

  • No local setup required
  • Persistent storage
  • Quick script testing

Azure CLI

Powerful command-line interface for scripting and automation.

  • Ideal for automation
  • Consistent command structure
  • Local or Cloud Shell use
Key Takeaway

Azure provides a diverse set of management tools—Portal, Cloud Shell, and CLI—each designed to optimize different aspects of cloud operations, from visual management to automation.
