Anatomy of an ARM Template

Understanding the JSON definition of Azure resources

Key Sections of an ARM Template

  • $schema: Specifies the template language schema version.
  • contentVersion: Your template's version for tracking changes.
  • parameters: Input values provided at deployment time for reusability.
  • variables: Values defined within the template to simplify expressions.
  • resources: The core section defining Azure resources to be deployed.
  • outputs: Values returned from the deployment, useful for chaining templates.
Key Takeaway

ARM Templates are structured JSON files that use parameters, resources, and outputs to define and deploy Azure infrastructure in a reusable and organized manner.

Simplified ARM Template Structure
{
  "$schema": "...deploymentTemplate.json#",
  "contentVersion": "1.0.0.0",
  "parameters": {
    "resourceName": { "type": "string" }
  },
  "variables": {
    "uniqueString": "[uniqueString(resourceGroup().id)]"
  },
  "resources": [
    {
      "type": "Microsoft.Storage/storageAccounts",
      "apiVersion": "2021-09-01",
      "name": "[parameters('resourceName')]",
      "location": "[resourceGroup().location]",
      "sku": { "name": "Standard_LRS" }
    }
  ],
  "outputs": {
    "storageId": { "type": "string", "value": "[resourceId('Microsoft.Storage/storageAccounts', parameters('resourceName'))]" }
  }
}
Common Mistake

Getting overwhelmed by complex JSON syntax. Start with simple templates and gradually add complexity. Use IntelliSense tools.
