Learning Objectives

What you will learn in this chapter

01

Serverless Computing

Understand benefits and use cases of Azure Functions and Logic Apps, focusing on event-driven execution without infrastructure management.

02

DevOps Practices

Describe how Azure supports DevOps with Azure DevOps and GitHub integration for streamlined development and operations.

03

Hybrid Cloud Solutions

Explain concepts and advantages of hybrid cloud using Azure Arc and Azure Stack for managing resources across environments.

04

Scenario Identification

Identify common scenarios where serverless, DevOps, and hybrid cloud architectures are most appropriate for business needs.
