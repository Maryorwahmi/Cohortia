Module 4 › Chapter 4.2 › Azure Arc and Azure Stack
Azure Arc

Azure Arc extends Azure management and services to any infrastructure, anywhere—on-premises, edge, or multi-cloud. It provides a unified control plane for managing distributed resources.

Azure Stack Family

The Azure Stack family (Hub, HCI, Edge) brings Azure services and capabilities to your on-premises environment, enabling consistent development and operations.

Synergy

Azure Arc provides the management layer, while Azure Stack provides the on-premises Azure services, creating a comprehensive hybrid cloud solution.

Unified Hybrid Management

Manage and extend Azure services across environments.
