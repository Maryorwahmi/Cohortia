Simulating IoT Data Ingestion

Setting up Azure IoT Hub and simulating device messages.

Lab Steps

Azure CLI Commands

Follow these commands in Azure Cloud Shell or your local CLI:

# Create resource group
az group create --name MyIoTRG --location eastus

# Create IoT Hub (replace myuniqueiothubname)
az iot hub create --resource-group MyIoTRG --name myuniqueiothubname --sku S1 --partition-count 2

# Register a device
az iot hub device-identity create --hub-name myuniqueiothubname --device-id myTestDevice

# Get device connection string (copy this)
az iot hub device-identity show-connection-string --hub-name myuniqueiothubname --device-id myTestDevice --query 'connectionString'

# Simulate sending messages (replace connection string)
az iot device simulate --device-connection-string "<yourDeviceConnectionString>" --data "{{\"temperature\": 25.5, \"humidity\": 60}}" --interval 5

# Monitor events
az iot hub monitor-events --hub-name myuniqueiothubname --device-id myTestDevice
Verification

Monitoring Events

Use the `az iot hub monitor-events` command to see the messages arriving at your IoT Hub in near real-time. This confirms your simulated device is successfully transmitting data.

Key Takeaway

Successfully setting up Azure IoT Hub and simulating device messages demonstrates the foundational steps for ingesting data from the physical world into Azure.
