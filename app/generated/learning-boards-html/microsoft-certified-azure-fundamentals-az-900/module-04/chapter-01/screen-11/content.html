Scenario

Big Data & IoT Processing Needs

An organization needs to process vast amounts of real-time sensor data from thousands of IoT devices, store it cost-effectively, and run complex analytical queries using Apache Spark. Which Azure services combination is best?

Analysis

Evaluating Options

  • A) VMs, SQL DB, Functions: Lacks scale for Big Data ingestion/Spark.
  • B) IoT Hub, Data Lake Storage Gen2, Databricks: Ideal for ingestion, scalable storage, and Spark analytics.
  • C) App Service, Cosmos DB, Logic Apps: Suited for apps/transactions, not Big Data processing.
  • D) AKS, Files, Cognitive Services: Lacks specialized Big Data ingestion/processing.
Key Takeaway

Selecting the right combination of Azure services, like IoT Hub for ingestion, Data Lake Storage for storage, and Databricks for Spark analytics, is crucial for effective Big Data and IoT solutions.
