Learning Objectives

Skills You'll Master in Core Database Services

LearnUnderstandApplyMaster
01

Distinguish Database Types

Differentiate between relational and NoSQL database services offered in Azure. This skill is foundational for selecting the appropriate data storage solution based on application needs.

VERIFIED COMPETENCY MILESTONE
02

Understand Azure SQL Database

Grasp the capabilities and use cases for Azure SQL Database as a fully managed relational database. This includes understanding its PaaS benefits and deployment options.

VERIFIED COMPETENCY MILESTONE
03

Identify Open-Source DB Scenarios

Recognize scenarios where Azure Database for MySQL, PostgreSQL, or MariaDB are the most appropriate choices. This involves matching application needs to specific open-source strengths.
