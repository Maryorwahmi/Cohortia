Azure Load Balancer: Layer 4 Traffic Distribution

High-performance, low-latency distribution of network traffic.

Layer 4 Operation

Distributes traffic based on IP address and port (TCP/UDP), without inspecting content.

High Availability

Ensures continuous service by routing traffic only to healthy backend instances.
