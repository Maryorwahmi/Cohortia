Network Security

Network Security Groups: Virtual Firewalls

Filtering traffic to and from Azure resources at a granular level.

Rule-Based Filtering

Define rules based on IP address, port, and protocol to allow or deny traffic.

Flexible Association

Apply NSGs to entire subnets or individual network interfaces (NICs) of VMs.

Traffic Flow to VM/Subnet
Common Mistake

Creating overly permissive NSG rules, such as allowing RDP (port 3389) from 'Any' source, which exposes VMs to potential attacks from the internet.

Key Takeaway

NSGs are crucial for implementing network segmentation and security, allowing precise control over traffic flow to protect your Azure resources.
