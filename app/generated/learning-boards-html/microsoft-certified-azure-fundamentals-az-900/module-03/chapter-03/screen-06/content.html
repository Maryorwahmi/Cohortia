Blob Access Tiers: Balancing Cost and Access

Hot, Cool, and Archive for Optimal Data Management

🔥

Hot Tier

Optimized for frequently accessed data. Higher storage costs, lower access costs.

  • Access: Frequent
  • Retention: Any duration
  • Latency: Milliseconds

Use Case: User profile pictures, active website content.

❄️

Cool Tier

Optimized for infrequently accessed data. Lower storage costs, higher access costs.

  • Access: Infrequent
  • Retention: Min 30 days
  • Latency: Milliseconds

Use Case: Short-term backups, older project files.

📦

Archive Tier

Optimized for rarely accessed data. Lowest storage costs, highest access costs.

  • Access: Rare
  • Retention: Min 180 days
  • Latency: Hours

Use Case: Long-term compliance data, historical archives.

Common Mistake

Using the Hot tier for archival data leads to unnecessarily high storage costs. Always match tier to access frequency.

Key Takeaway

Selecting the correct Blob access tier based on data access frequency and retention period is vital for cost optimization and efficient data management.
