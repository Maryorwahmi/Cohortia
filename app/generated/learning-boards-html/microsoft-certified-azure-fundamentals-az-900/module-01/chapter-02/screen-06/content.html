Shared Responsibility

IaaS: Who Manages What?

Understanding customer and Azure responsibilities in Infrastructure as a Service.

IaaS Shared Responsibility Model
Customer Responsibility
  • Operating System
  • Applications
  • Data
  • Network Configuration (within VM)
  • Security Configuration (OS/App)
Azure Responsibility
  • Physical Data Center
  • Physical Network
  • Physical Hosts
  • Virtualization Layer
  • Underlying Infrastructure
Azure Example: With Azure Virtual Machines, Microsoft manages the physical hardware and virtualization, while you manage the OS, applications, and data within the VM.
Key Idea

IaaS gives customers the most control, but also the most responsibility, starting from the OS layer.

Control vs. Management

Higher control in IaaS means more management overhead for the customer.

Security Note

Customer is always responsible for data classification, client-side encryption, and endpoint protection.

Use Case

Ideal for custom environments or migrating legacy applications without re-architecture.
