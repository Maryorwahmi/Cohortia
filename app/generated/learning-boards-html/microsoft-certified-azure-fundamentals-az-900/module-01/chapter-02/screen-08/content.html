Shared Responsibility

PaaS: Building on Managed Infrastructure

Azure handles more, allowing you to focus on your code and data.

PaaS Shared Responsibility Model
Customer Responsibility
  • Applications
  • Data
  • Application Configuration
  • Access Management (App Level)
Azure Responsibility
  • Physical Data Center
  • Physical Network
  • Physical Hosts
  • Operating System
  • Middleware
  • Runtime Environment
Azure Example: With Azure App Service, Microsoft manages the OS, web server, and scaling, while you deploy and manage your web application code.
Key Idea

PaaS significantly reduces operational overhead, allowing developers to focus on innovation.

Benefit

Accelerates development and deployment cycles for new applications.

Azure Examples

Azure App Service, Azure SQL Database, and Azure Functions are key PaaS offerings.
