Key Concepts

Essential takeaways from this chapter

Shared Responsibility Model

A framework outlining the security and management responsibilities of the cloud provider and the customer, which varies by service model.

Azure Virtual Machines (IaaS)

An Azure IaaS offering that allows you to deploy and manage virtualized servers, giving you full control over the OS.

Azure App Service (PaaS)

An Azure PaaS offering for building, deploying, and scaling web apps and APIs, where Azure manages the underlying platform.

Summary Takeaway

Azure provides a range of services across IaaS, PaaS, and SaaS, each designed to meet different levels of management and control needs.
