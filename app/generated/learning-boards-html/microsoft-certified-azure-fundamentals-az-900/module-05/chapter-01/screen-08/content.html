Rule Priority

Rules are processed in order of priority (lowest number first). Conflicting rules are resolved by the lowest priority number.

Common Mistake: Unassociated NSG

Creating an NSG but forgetting to associate it with a subnet or NIC means it won't filter any traffic.

Common Mistake: Overly Permissive Rules

Using 'Any' for source/destination IP or port ranges can create significant security vulnerabilities.

Key Takeaway

Always apply the principle of least privilege when configuring NSG rules, allowing only necessary traffic and ensuring proper association.
