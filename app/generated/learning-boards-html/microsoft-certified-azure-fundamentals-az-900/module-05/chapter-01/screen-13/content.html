Key Concepts

Essential Terms to Remember

CIDR (Classless Inter-Domain Routing)

A method for specifying IP address ranges, crucial for defining VNet and subnet sizes.

Network Security Group (NSG)

A virtual firewall that filters network traffic to and from Azure resources based on rules.

Security Rule

A component of an NSG that defines whether to allow or deny traffic based on specified criteria (source, destination, port, protocol, priority).

Summary Takeaway

CIDR, NSGs, and Security Rules are fundamental for defining network boundaries and controlling traffic flow, ensuring robust security and connectivity.
