Private IP Address

Used for communication within the VNet and with connected on-premises networks. Not directly accessible from the internet.

Public IP Address

Allows Azure resources to communicate with the internet. Essential for public-facing services like web servers.

Static vs. Dynamic Public IPs
  • Dynamic: Changes upon VM deallocation.
  • Static: Persists even after deallocation; preferred for production.
Key Takeaway

Use private IPs for internal communication and public IPs only when internet access is explicitly required, preferring static for consistency.

IP ADDRESS USAGE SCENARIOS

Private IP: Internal Communication

Database servers, application backends, internal services within a VNet.

Public IP: Internet Access

Web servers, VPN gateways, public load balancers, jump boxes for administration.

Common Mistake: Over-exposure

Assigning public IPs to resources that don't need internet access, increasing security risk.
