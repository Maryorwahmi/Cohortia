Security Rules Applied
Function

NSGs filter network traffic to and from Azure resources based on defined security rules.

Rule Components
  • Source/Destination IP
  • Source/Destination Port
  • Protocol (TCP, UDP, Any)
  • Direction (Inbound/Outbound)
  • Priority (100-4096, lower is higher)
  • Access (Allow/Deny)
Default Rules

Allow VNet-to-VNet, Allow Azure Load Balancer inbound, Deny all other inbound/outbound internet traffic.

Key Takeaway

NSGs are virtual firewalls that use prioritized rules to control traffic, providing a critical layer of security for your Azure network.
