Purpose

Subnets segment a VNet's IP address space, allowing for logical grouping of resources and application tiers.

IP Address Allocation

Each subnet is assigned a portion of the VNet's address space. Azure reserves 5 IPs per subnet for internal use (first 4, last 1).

Common Mistake

Forgetting Azure's reserved IP addresses can lead to insufficient available IPs for your resources, especially in smaller subnets.

Key Takeaway

Subnets are crucial for organizing resources, applying security policies, and managing IP addresses efficiently within your VNet.
