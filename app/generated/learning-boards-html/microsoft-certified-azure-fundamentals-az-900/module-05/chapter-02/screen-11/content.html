Exploring Firewall Policy with Azure CLI

A conceptual walkthrough of creating rules.

Step 1: Resource Group & VNet

Create a resource group and a VNet with a dedicated 'AzureFirewallSubnet'.

Step 2: Create Firewall & Policy

Provision the Azure Firewall (conceptual) and then create a Firewall Policy.

Step 3: Add Rules

Add Network Rule Collections (IP/Port) and Application Rule Collections (FQDN) to the policy.

Azure CLI Commands (Conceptual)
# 1. Create a Resource Group (if not already done) az group create --name myFirewallRG --location eastus # 2. Create a VNet and a dedicated subnet for Azure Firewall az network vnet create \ --resource-group myFirewallRG \ --name myFirewallVNet \ --address-prefix 10.1.0.0/16 \ --subnet-name AzureFirewallSubnet \ --subnet-prefix 10.1.0.0/24 # 3. Create an Azure Firewall (Conceptual - takes time) # az network firewall create \ # --resource-group myFirewallRG \ # --name myAzureFirewall \ # --location eastus \ # --sku Standard \ # --public-ip-address myFirewallPublicIP # (You'd need to create a Public IP first) # 4. Create a Firewall Policy az network firewall policy create \ --resource-group myFirewallRG \ --name myFirewallPolicy \ --location eastus # 5. Add a Network Rule Collection az network firewall policy rule-collection-group network-rule create \ --resource-group myFirewallRG \ --policy-name myFirewallPolicy \ --rule-collection-group-name DefaultNetworkRuleCollectionGroup \ --name AllowOutboundHTTP \ --protocols TCP \ --source-addresses '*' \ --destination-addresses '8.8.8.8' \ --destination-ports 80 \ --action Allow \ --priority 1000 # 6. Add an Application Rule Collection az network firewall policy rule-collection-group application-rule create \ --resource-group myFirewallRG \ --policy-name myFirewallPolicy \ --rule-collection-group-name DefaultApplicationRuleCollectionGroup \ --name AllowMicrosoftUpdate \ --protocols Http=80 Https=443 \ --source-addresses '*' \ --target-fqdns 'www.microsoft.com' 'download.microsoft.com' \ --action Allow \ --priority 1000
Key Takeaway

The Azure CLI provides a programmatic way to define and manage Azure Firewall policies and rules, offering granular control over network traffic within your Azure environment.
