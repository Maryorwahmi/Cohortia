Key Feature

Creates secure, encrypted connections (VPN tunnels).

Managed Service

Azure handles the underlying infrastructure.

Core Service

Introducing Azure VPN Gateway: Encrypted Connections

Creating secure tunnels over the public internet.

Key Benefit

Cost-effective and relatively easy to set up for secure cross-premises connectivity.

Consideration

Performance can be subject to public internet congestion, impacting latency and bandwidth predictability.

Common Use Case

Connecting a branch office network to an Azure Virtual Network for secure resource access.

Key Takeaway

Azure VPN Gateway provides a secure, encrypted, and cost-effective way to extend your on-premises network to Azure over the public internet, ideal for many hybrid scenarios.
