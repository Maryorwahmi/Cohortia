Core Concept

Azure Active Directory: Your Cloud Identity Hub

Understanding Microsoft Entra ID's central role in Azure.

What is Microsoft Entra ID?

  • Microsoft's cloud-based identity and access management service.
  • Provides a single control plane for users, groups, and applications.
  • Every Azure subscription trusts an Azure AD tenant.

Azure AD Tenant Explained

A dedicated instance of Azure AD for your organization. It stores your user accounts, groups, and application registrations, acting as your organization's digital boundary.

Example: Your company's unique '.onmicrosoft.com' domain.

Azure AD vs. Windows Server AD

  • Azure AD is cloud-based; Windows Server AD is on-premises.
  • They can synchronize for hybrid identity solutions.
Key Takeaway

Microsoft Entra ID is the foundational cloud identity service for Azure, distinct from on-premises Active Directory but capable of integration.
