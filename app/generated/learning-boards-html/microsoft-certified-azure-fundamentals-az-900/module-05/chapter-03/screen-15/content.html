Key Concepts

Essential terms from this chapter

Microsoft Entra ID

Microsoft's cloud-based identity and access management service, providing a central directory for users, groups, and applications.

Tenant

A dedicated instance of Azure AD for an organization, containing its users, groups, and application registrations.

Authentication

The process of verifying a user's identity (e.g., username and password).

Summary Takeaway

Azure AD, tenants, authentication, and authorization are the foundational elements for managing identities and access in the cloud.
