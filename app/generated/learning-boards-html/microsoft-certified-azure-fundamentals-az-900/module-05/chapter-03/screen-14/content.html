Hands-on Activity

Creating a New User and Enabling MFA in Azure AD

A guided walkthrough to enhance user account security.

1

Create a New User

  • Log in to Azure Portal and navigate to Azure Active Directory.
  • Select Users, then + New user, and fill in the required details.
  • Click Review + create, then Create.
Important

Remember to replace yourtenant with your actual tenant name in the username.

2

Enable MFA for the User

  • In Azure AD, go to Users and click Per-user MFA.
  • Locate your new user, select them, and click Enable.
  • Confirm by clicking Enable multi-factor auth.
Key Takeaway

This activity demonstrates the practical steps to create a user and enable MFA, a fundamental security measure in Azure AD.
