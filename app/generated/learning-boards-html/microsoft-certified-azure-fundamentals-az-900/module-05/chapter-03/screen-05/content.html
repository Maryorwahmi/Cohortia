Core Concept

Authentication vs. Authorization: Knowing Who and What

Differentiating identity verification from access permissions.

Authentication

The process of verifying who a user is. It confirms your identity based on credentials.

  • Example: Entering username and password.
  • Result: User is verified.
Common Mistake

Confusing authentication with authorization can lead to security gaps.

Authorization

The process of determining what an authenticated user is allowed to do. It grants or denies access to resources.

  • Example: Checking permissions to delete a VM.
  • Result: User is granted or denied access/action.
Key Takeaway

Always apply the principle of least privilege: grant only the necessary permissions.
