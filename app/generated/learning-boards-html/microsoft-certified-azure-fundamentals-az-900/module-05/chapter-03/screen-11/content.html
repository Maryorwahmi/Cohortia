Role Differentiation

Azure Roles vs. Azure AD Roles: Scoping Permissions

Distinguishing between identity management and resource management roles.

Azure AD Roles

Govern permissions within the Azure AD tenant itself. Focus on identity and access management.

  • Examples: Global Administrator, User Administrator, Billing Administrator.
  • Scope: Azure AD tenant-wide.
Common Mistake

Using an Azure AD role to manage Azure resources directly (e.g., VMs).

Azure Roles (RBAC)

Govern permissions to manage Azure resources (e.g., VMs, storage accounts). Focus on resource management.

  • Examples: Owner, Contributor, Reader.
  • Scope: Subscription, resource group, or individual resource.
Key Takeaway

Azure AD roles manage identities, while Azure RBAC roles manage resources. Use both for comprehensive access control.
