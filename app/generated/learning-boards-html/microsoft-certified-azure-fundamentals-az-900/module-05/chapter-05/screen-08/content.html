Lock Types

Types of Azure Resource Locks

Choosing the Right Level of Protection for Your Resources

Azure Resource Locks come in two main types, offering different levels of protection against accidental changes.

CanNotDelete

Allows read and modify, but prevents deletion.

ReadOnly

Allows only read access; prevents deletion and modification.

Key Takeaway

Azure Resource Locks offer 'CanNotDelete' (read/modify, no delete) and 'ReadOnly' (read only) types for varying levels of resource protection.

Lock Type Scenarios

CanNotDelete: Production databases, critical network components.

ReadOnly: Archived data, immutable compliance environments.
