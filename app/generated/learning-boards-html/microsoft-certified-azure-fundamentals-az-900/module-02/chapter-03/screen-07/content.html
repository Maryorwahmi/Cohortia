Template Structure

Inside an ARM Template

Understanding the JSON Structure for Resource Deployment

Schema & Version

Defines the template's structure and API version for validation.

Resources Array

Where individual Azure resources (VMs, storage) are declaratively defined.

Parameters Section

Allows for dynamic input values, making templates reusable and flexible.

Key Takeaway

ARM templates are JSON files that declaratively define Azure infrastructure, using sections for schema, resources, and flexible parameters.

{
  "$schema": "https://schema.management.azure.com/schemas/2019-04-01/deploymentTemplate.json#",
  "contentVersion": "1.0.0.0",
  "resources": [
    {
      "type": "Microsoft.Storage/storageAccounts",
      "apiVersion": "2021-09-01",
      "name": "[parameters('storageAccountName')]",
      "location": "[parameters('location')]",
      "sku": {
        "name": "Standard_LRS"
      },
      "kind": "StorageV2",
      "properties": {}
    }
  ],
  "parameters": {
    "storageAccountName": {
      "type": "string",
      "metadata": {
        "description": "Name of the storage account"
      }
    },
    "location": {
      "type": "string",
      "defaultValue": "[resourceGroup().location]",
      "metadata": {
        "description": "Location for the storage account"
      }
    }
  }
}
