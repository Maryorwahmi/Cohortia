Azure Resource Groups
Logical containers for managing resources with a shared lifecycle.

A Resource Group is a logical container for Azure resources.

All resources in an RG share the same lifecycle: deleting the RG deletes its resources.

Useful for managing applications or projects as a single unit.

A resource can only belong to one RG, but an RG can contain resources from different regions.
