Resource Hierarchy in Azure
Understanding the nested structure from Management Groups down to Resources.

Management Groups: Govern multiple subscriptions.

Subscriptions: Billing, access, limits; contain Resource Groups.

Resource Groups: Logical containers for resources with shared lifecycles.

Resources: Individual Azure services (VMs, databases, etc.).

This nested structure ensures organization, security, and cost-effectiveness.
