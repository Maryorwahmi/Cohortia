Scenario: Organizing a New Project
Applying concepts of resources, RGs, and subscriptions.

Scenario: New microservices application with Dev, Test, and Prod environments.

Strategy: Use separate Subscriptions for each environment (Dev, Test, Prod).

Resource Groups: Create dedicated RGs within each subscription for the application's resources.

Example RG Name: `rg-myapp-dev-eastus`.

This ensures clear separation, access control, and lifecycle management.

Project Structure
Dev Subscription
rg-myapp-dev-eastus
rg-myapp-prod-eastus
