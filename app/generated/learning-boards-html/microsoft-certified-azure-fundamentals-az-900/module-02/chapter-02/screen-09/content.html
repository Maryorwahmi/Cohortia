Resource Group Naming Conventions
Best practices for naming RGs to improve clarity and management.

Consistent naming is crucial for clarity and automation.

A common pattern: `rg---`.

Example: `rg-myapp-dev-eastus`.

This provides immediate context about the RG's purpose and location.

Adherence reduces ambiguity and simplifies management.

Example Naming Convention
rg- Application Name
dev Environment
eastus Region
Resulting Name
rg-myapp-dev-eastus
