Common Misconception
Resource Groups vs. Subscriptions
Understanding the distinct roles and scopes of RGs and Subscriptions.

Resource Groups (RG): Manage resource lifecycles. Think 'project folder'. Deleting RG deletes its resources.

Subscriptions: Manage billing, access, and limits. Think 'financial/admin boundary'.

Resources live within RGs; RGs live within Subscriptions.

Example: Separate Subscriptions for Dev/Test/Prod; RGs within each for specific apps.
