What is an Azure Resource?
The fundamental building blocks of your cloud solutions.

An Azure Resource is any service or entity that you create, deploy, or manage within Azure. It's the fundamental unit of your cloud infrastructure.

This includes a vast array of services: virtual machines (VMs), storage accounts, virtual networks, databases, web apps, load balancers, and many more.

Every action you take in Azure ultimately involves interacting with one or more of these resources.
