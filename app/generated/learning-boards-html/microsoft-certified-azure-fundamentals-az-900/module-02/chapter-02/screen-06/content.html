Management Boundary
Azure Subscriptions
Billing, access control, and service limits for your resources.

A Subscription is a logical container for Resource Groups and resources.

It serves as a boundary for billing, tracking all usage and costs.

It's a key boundary for access control using Role-Based Access Control (RBAC).

Subscriptions also enforce service limits and quotas.

Organizations often use multiple subscriptions for different environments or departments.
