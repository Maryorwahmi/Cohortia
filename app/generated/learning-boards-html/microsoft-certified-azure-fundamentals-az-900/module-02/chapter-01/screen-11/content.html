Global Widgets Inc. Deployment

Applying Location Concepts

Requirement: EU data residency, customer-facing web app serving Europe, disaster recovery.

Geography: 'Europe' to meet data residency.

Primary Region: e.g., 'West Europe' for user proximity.

Region Pair: 'North Europe' for disaster recovery.

Availability Zones: Within 'West Europe' for high availability.

West Europe & North Europe

Primary deployment in West Europe, with disaster recovery in its paired region, North Europe. Availability Zones within West Europe ensure high availability.

Key Takeaway

A layered approach using geographies, regions, region pairs, and availability zones is key to robust cloud architecture.
