Key Concepts

Essential Takeaways from This Chapter

Azure Geography

Discrete market area for data residency and compliance.

Azure Region

Physical location with data centers for deploying services.

Region Pair

Two regions for disaster recovery with asynchronous replication.

Availability Zone

Physically separate data center within a region for high availability.

Data Residency

The physical location where data is stored, governed by legal requirements.

Summary Takeaway

Understanding Azure's global infrastructure is key to building compliant, resilient, and performant cloud solutions.
