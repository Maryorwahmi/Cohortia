Identity Basics

Azure AD Users

Users represent individuals who need access to resources within your Azure AD tenant.

User Types

Cloud-only: Created directly in Azure AD.
Synchronized: From on-premises Active Directory.
Guest: Invited from other organizations.

Unique Identifiers

Each user has a unique User Principal Name (UPN) and an Object ID.

User Management Tasks

Day-to-Day Administration

Common tasks for managing user accounts:

  • Creating new user accounts.
  • Resetting passwords.
  • Assigning licenses for cloud services.
  • Blocking or unblocking sign-ins.
Practical Scenario

When a new employee joins, an Azure AD user account is created for them, granting initial access to company resources.

Key Takeaway

Users are the individual identities in Azure AD, requiring careful management to ensure secure and appropriate access.
