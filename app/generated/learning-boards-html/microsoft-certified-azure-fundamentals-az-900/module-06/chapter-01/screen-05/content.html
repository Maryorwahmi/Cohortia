Service Overview

What is Azure Active Directory?

Azure AD is a cloud-based identity and access management service that helps your employees sign in and access resources.

Key Purpose

Provides identity services for applications, employees, and external partners, enabling secure access to cloud resources.

Cloud-Native Design

Built for the modern internet-facing world, it is not a domain controller in the cloud but a comprehensive identity solution.

Core Capabilities

Single Sign-On (SSO)

Allows users to access multiple applications with one set of login credentials.

  • Access thousands of SaaS apps (e.g., Microsoft 365, Salesforce).
  • Integrate custom applications.
  • Enhance user experience and security.
Common Misconception

Azure AD is NOT a direct replacement for on-premises Active Directory Domain Services. It's a different service for different needs.

Key Takeaway

Azure AD is a cloud-native IAM service that centralizes identity for cloud applications and users, enabling SSO.
