Core Component

The Azure AD Tenant

A dedicated instance of Azure AD for your organization, automatically associated with your Azure subscription.

Logical Container

Holds all your users, groups, applications, and devices, serving as the primary directory for managing access.

Isolation & Security

Each tenant is distinct and isolated from others, ensuring your organization's identity data remains separate and secure.

Tenant Characteristics

Naming & Association

Tenants are often named like yourcompany.onmicrosoft.com.

  • Automatically created with an Azure subscription.
  • Multiple subscriptions can link to the same tenant.
  • Provides a centralized identity management point.
Common Misconception

An Azure subscription is linked to a tenant, but they are not the same. The tenant manages identities, the subscription manages billing and resources.

Key Takeaway

An Azure AD tenant is your organization's isolated, dedicated instance for managing all cloud identities and access.
