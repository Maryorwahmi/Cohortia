Your First Steps in Azure AD Management

01

Log in to Azure Portal

Access the Azure management interface at portal.azure.com with your Azure account.

Tip: Ensure you have appropriate permissions.
02

Navigate to Azure AD

Use the search bar to find and select "Azure Active Directory" from the services list.

Path: Azure Portal > Search > Azure Active Directory.
03

Create a New User

Go to Users > + New user, fill in details like username and name, then create.

Example: dev.analyst with a strong password.
04

Create a New Security Group

Go to Groups > + New group, select 'Security' type, and provide a name.

Example: Group name "Development Team".
05

Add User to Group

Open the group's properties, go to Members > + Add members, and select your user.

Action: Add Dev Analyst to "Development Team".
Key Takeaway

Mastering user and group creation is a foundational skill for managing access and identities effectively in Azure AD.
