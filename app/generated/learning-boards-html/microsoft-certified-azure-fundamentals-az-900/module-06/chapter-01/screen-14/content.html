Essential Azure AD Terminology

Recap of foundational identity concepts.

Azure Active Directory (Azure AD)

Microsoft's cloud-based identity and access management service, providing identity for users, applications, and devices.

Tenant

A dedicated instance of Azure AD for an organization, containing its users, groups, and applications, isolated from others.

User

An individual identity within Azure AD, representing an employee, partner, or customer who needs access to resources.

Summary Takeaway

These core terms are the building blocks for understanding and managing identity and access in Azure's cloud environment.
