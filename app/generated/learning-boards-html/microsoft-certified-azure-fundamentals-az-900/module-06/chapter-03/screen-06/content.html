Azure Subscriptions: Billing and Resource Boundaries

The primary unit for deploying resources and managing costs

Resource Container

All Azure resources (VMs, storage, databases) must reside within a subscription.

Billing Boundary

All costs for resources within a subscription are rolled up to that specific subscription.

Linked to Tenant

Each subscription is linked to an Azure account, which is tied to your Azure AD Tenant for identity management.
