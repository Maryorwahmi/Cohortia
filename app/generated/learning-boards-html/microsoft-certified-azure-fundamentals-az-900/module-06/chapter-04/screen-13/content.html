Key Concepts to Remember (Continued)

Deepening your governance vocabulary

Role-Based Access Control (RBAC)

An authorization system providing fine-grained access management to Azure resources by assigning roles.

Security Principal

The 'who' – a user, group, or service principal – to which an RBAC role is assigned.

Scope

The 'where' – the level in the Azure hierarchy (Management Group, Subscription, Resource Group, Resource) where an RBAC assignment applies.

Summary Takeaway

RBAC, with its principals, roles, and scopes, combined with the principle of least privilege, forms the backbone of secure access control in Azure.
