Core Concept

Understanding Role-Based Access Control (RBAC)

Who can access what resources, and what they can do.

Definition

RBAC is an authorization system that provides fine-grained access management to Azure resources.

Purpose

It governs who can access what resources and what actions they can perform with those resources.

Contrast with Policy

RBAC controls who can do what, while Azure Policy controls what resources can be deployed and how they are configured.

Key Takeaway

RBAC is Azure's core system for managing user permissions, ensuring only authorized identities can perform specific actions on resources.

Example: Contributor Role
