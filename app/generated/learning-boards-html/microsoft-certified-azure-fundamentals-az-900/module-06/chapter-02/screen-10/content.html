SSO Mechanics

How Single Sign-On Works with Azure AD

Understanding the roles of Identity Provider and Service Provider in the SSO flow.

Key Roles in SSO

  • •
    Identity Provider (IdP): Authenticates the user and issues security tokens (Azure AD).
  • •
    Service Provider (SP): The application that trusts the IdP and grants access based on the token.

The SSO Flow

1. User Authenticates: User logs into Azure AD (IdP) with credentials.

2. Token Issued: Azure AD issues a security token to the user's browser.

3. Access Granted: Application (SP) trusts the token and grants access.

Key Takeaway

SSO works by establishing trust between Azure AD (Identity Provider) and applications (Service Providers), allowing users to access multiple services with a single authentication token.
