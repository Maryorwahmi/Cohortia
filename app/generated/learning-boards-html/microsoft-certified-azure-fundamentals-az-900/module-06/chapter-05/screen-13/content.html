Scenario: Cost Reduction for Development VMs

An organization uses non-production VMs 24/7 for a development environment and wants to significantly reduce costs over three years.

  • A) Shutting down the VMs nightly.
  • B) Using Azure Spot Instances.
  • C) Purchasing Azure Reservations for the VMs.
  • D) Migrating the VMs to a cheaper region.
Key Takeaway

Matching the right cost optimization strategy to workload characteristics is crucial for maximum savings.

Correct Answer: C

Purchasing Azure Reservations for the VMs.

Explanation:

Azure Reservations offer substantial discounts (up to 72%) for consistent, long-running workloads like 24/7 development VMs, making them the most effective strategy for long-term cost reduction.
