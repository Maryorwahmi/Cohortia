Definition
Cohesion
High cohesion keeps related behavior together and limits unrelated responsibilities inside a module.
High Cohesion
All functions in the module serve a single purpose, making testing and reasoning straightforward.
Low Cohesion
A module handles unrelated tasks, causing maintenance headaches and hidden coupling.
Example & Exercise
Module A (low cohesion)
Handles authentication, profile updates, and sending notification emails — responsibilities that should be split.
Module B (high cohesion)
Handles only payment processing tasks and related validations.
