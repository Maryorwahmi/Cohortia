Definition
Non-Functional Requirements
Quality attributes expressed as measurable targets that directly influence design and operations.
Performance
E.g., page load time < 2 seconds for 95% of requests during peak hours.
Scalability & Availability
E.g., system must support 10,000 concurrent users and be available 99.99% monthly.
Security
E.g., all user data encrypted at rest and in transit; role-based access controls enforced.
Example & Measurement
Scenario
If search must support high concurrency, you might add caching, index tuning, and horizontal scaling. The NFR specifies the target so you can validate design choices with load tests.
Exercise

Attach at least one measurable NFR to each of your three user stories and decide how you would test it.

Misconception
NFRs are not a checklist item; they often determine architecture and operational strategy and should be prioritized early.
