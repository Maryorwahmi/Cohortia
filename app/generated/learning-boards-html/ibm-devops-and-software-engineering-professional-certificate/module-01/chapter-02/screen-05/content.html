Process
Write effective user stories
Keep stories focused on users, actions, and benefits. Pair with acceptance criteria.
Format
As a [user], I want [action] so that [benefit].
Acceptance Criteria
  • Describe testable outcomes and edge cases.
  • Keep criteria numeric or boolean where possible.
Misconception
Do not include implementation detail in the story. Implementation belongs to design tasks linked to the story.
Examples & Practice
As a customer, I want to search for books by title or ISBN so that I can find a specific edition.
Acceptance criteria:
- Results include exact ISBN matches and fuzzy title matches.
- Search returns within 1.5 seconds for 90% of queries.
As a customer, I want to add books to a shopping cart so that I can purchase multiple items.
Acceptance criteria:
- Cart persists for signed-in users across sessions.
- Adding an unavailable item returns a clear error.
