Definition
Functional vs Non-Functional
Clear definitions reduce ambiguity and make requirements testable.
Functional Requirements
Describe what the system must do. Example: "As a customer, I want to add items to a cart so I can buy multiple books."
Non-Functional Requirements
Describe how the system performs. Example: "Search results must load within 1.5 seconds for 90% of queries."
Common Mistake
Writing vague NFRs like "fast" or "secure" without measurable criteria. Fix by adding numbers, percentiles, or levels.
Concrete Example — Online Bookstore
Functional (User Story)
As a customer, I want to search for books by title or ISBN so that I can find desired items quickly.
Non-Functional (Measurable)
Performance: Search results must return within 1.5 seconds for 90% of queries during normal operation.
Key Takeaway

Always convert qualitative statements into measurable, testable criteria so design and operations can meet them.
