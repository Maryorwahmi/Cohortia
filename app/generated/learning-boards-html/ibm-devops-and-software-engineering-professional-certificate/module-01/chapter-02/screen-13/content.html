Best Practices
Common Mistakes and How to Fix Them
Concrete remedies you can apply in planning and design reviews.
Tight Coupling
Refactor using API boundaries, introduce adapter patterns, and write integration tests to validate contracts.
Low Cohesion
Split responsibilities into focused modules and move cross-cutting concerns to shared services as needed.
Over-Engineering
Avoid designing for unlikely futures; prioritize current NFRs and allow controlled extension points.
Traceability
Link requirements to design decisions so the team can revisit choices when requirements change.
NFRs in Planning
Include NFRs during backlog grooming and design reviews; treat them as acceptance criteria for architecture work.
Action

This week, pick one module and run a five-minute cohesion check: list responsibilities and decide what can be split or clarified.
