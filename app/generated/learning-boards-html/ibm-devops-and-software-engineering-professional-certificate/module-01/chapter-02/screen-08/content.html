User story
As a customer, I want to filter search results by price and rating so that I can find books within my budget.
Attached NFR
Performance. Target: median filter response < 1 second under normal load. Measurement: automated UI tests with sample catalog of 50,000 items.
Key Takeaway

Always attach measurement and test method to each NFR so validation is straightforward.
