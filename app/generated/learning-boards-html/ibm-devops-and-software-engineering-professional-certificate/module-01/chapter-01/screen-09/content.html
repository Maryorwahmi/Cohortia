Module 1 › Chapter 1.1 › Testing Phase
Test types
  • Unit tests validate individual functions or modules.
  • Integration tests validate interactions between components.
  • Acceptance tests confirm requirements are met from a user perspective.
Example: login testing

Write unit tests for credential validation, integration tests for token exchange, and acceptance tests to ensure the login flow works end-to-end.

Common mistake
Starting testing late or relying only on manual tests increases the chance of late defects and expensive fixes.
Key Takeaway
Automate layered tests and run them continuously so defects are caught early and reliably.
