Maintenance essentials

Maintenance covers bug fixes, updates, and enhancements after release. Plan for documentation, monitoring, and scheduled updates so the product remains usable and secure.

Documentation
Keep design notes, API contracts, and test evidence for future teams to use.
Security across the SDLC
  • Requirements: include security constraints and compliance needs.
  • Design: perform threat modeling and secure architecture choices.
  • Implementation: apply secure coding practices and scans.
  • Testing: include security tests and vulnerability checks.
Key Takeaway

Treat maintenance as long-term work and embed security activities in every phase to reduce vulnerabilities and costly remediation later.
