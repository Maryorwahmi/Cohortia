The Agile Manifesto — four core values
Use these values to guide decisions about trade-offs in a project.
Value 1
Individuals & interactions
Collaboration is primary; tools should enable, not replace, communication.
Value 2
Working software
Deliver functional increments; documentation supports, but does not replace, value.
Value 3
Customer collaboration
Engage customers continuously to keep the product relevant and prioritized.
Value 4
Responding to change
Adapt plans as you learn; change is expected and useful for improvement.
Quick Example
When user feedback requests a different watchlist sort, prioritize the user value and update the backlog instead of waiting for the next big release.
Misconception
Agile is not no planning; it is continuous, lightweight planning that adapts to new information.
Key Takeaway

Use the manifesto as guidance for trade-offs, not as a strict checklist.
