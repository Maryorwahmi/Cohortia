Kanban basics
A flow-based method that visualizes work and reduces bottlenecks.
Visualize Workflow
Make all work visible with a board and cards.
Limit WIP
Set limits per column to focus on finishing work.
Manage Flow
Monitor throughput and resolve bottlenecks proactively.
Explicit Policies
Define how work moves between states so team members share the same expectations and handoffs are clear.
Example
When testing becomes a bottleneck, the team reduces WIP in development so testing can catch up and flow improves.
Misconception
Kanban is not less disciplined; it requires strict WIP limits and clear policies to improve flow.
Key Takeaway

Kanban optimizes flow by making work visible and constraining parallel work until bottlenecks are addressed.
