Defining user stories
Use the template to keep focus on users and value.
Feature: User Watchlist for Online Video Streaming Service

User Stories:
1. As a registered user, I want to add a movie or TV show to my watchlist so that I can easily find it later to watch.
2. As a registered user, I want to view my watchlist with clear thumbnails and titles so that I can quickly choose what to play next.
3. As a registered user, I want to remove items from my watchlist so that I can keep it relevant and organized.
Notice how each story names the user, the capability, and the reason. These are backlog-ready and can be estimated and placed in a Sprint Backlog.
Common Mistake
Avoid writing technical tasks as stories. Stories should describe user outcomes, not implementation details.
Key Takeaway

Good user stories make planning and delivery faster by focusing on clear, testable user value.
