Module 6 › Chapter 6.3 › Key Concepts
Service
An abstract resource that provides a stable IP and DNS name and routes traffic to matching Pods.
ClusterIP
Exposes the Service on an internal cluster IP only; use for internal communication.
NodePort & LoadBalancer
NodePort exposes a static port on nodes for external testing; LoadBalancer gets a cloud public IP for production exposure.
Takeaway

Pick the least-exposing Service type you need, verify selectors and ports, and use Ingress for HTTP routing and TLS termination when serving multiple services under the same domain.
