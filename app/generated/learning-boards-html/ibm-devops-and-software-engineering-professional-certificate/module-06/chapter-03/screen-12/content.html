Networking mistakes and safety
A prioritized checklist for debugging and secure exposure.
Priority checklist
  1. Confirm Service selector matches Pod labels exactly.
  2. Confirm targetPort equals containerPort in the Pod spec.
  3. Ensure an Ingress controller is running before relying on Ingress rules.
  4. Verify NodePort is inside 30000-32767 if using NodePort.
Security caution
Avoid using LoadBalancer or NodePort for internal-only services; use network policies and Ingress with TLS for public exposure.
Example: selector mismatch
Pods labeled app: my-api but Service selector app: backend will result in no endpoints; check labels with kubectl get pods --show-labels.
Best practice
Verify internal connectivity, tighten exposure with network policies, and centralize TLS in Ingress to reduce attack surface.
