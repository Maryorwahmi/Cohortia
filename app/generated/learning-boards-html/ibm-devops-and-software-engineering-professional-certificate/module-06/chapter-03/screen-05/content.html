Definition
Service resource breakdown
Know which fields determine routing and exposure.
Field guide
  • metadata.name: the Service name and DNS entry.
  • spec.selector: matches Pod labels to form endpoints.
  • spec.ports: defines port, targetPort, and protocol.
  • spec.type: ClusterIP, NodePort, LoadBalancer, or ExternalName.
Example check
Confirm targetPort matches the containerPort in your Pod spec before applying.
Misconception
Assuming ClusterIP works externally. ClusterIP is internal only.
YAML walkthrough
apiVersion: v1
kind: Service
metadata:
  name: nginx-service
spec:
  selector:
    app: nginx
  ports:
    - protocol: TCP
      port: 80
      targetPort: 80
  type: ClusterIP
Apply and then run kubectl describe service nginx-service to inspect endpoints and port mappings.
Quick debugging steps
  1. kubectl get pods --show-labels to confirm labels.
  2. kubectl describe service <name> to see endpoints.
  3. If endpoints are empty, re-check the selector labels on Pods.
