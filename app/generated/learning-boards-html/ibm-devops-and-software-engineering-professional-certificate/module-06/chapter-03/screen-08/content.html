Definition
LoadBalancer and ExternalName
Two distinct ways Services interact with external systems.
LoadBalancer
Requests a cloud provider-managed load balancer and public IP to expose the Service externally. Check kubectl get svc to see the external IP.
ExternalName
Maps a Service name to an external DNS record. It does not route traffic through cluster Pods; it provides a DNS alias for clients.
Security note
When exposing services publicly, centralize TLS via Ingress and limit exposure with network policies.
LoadBalancer example
spec:
  type: LoadBalancer
  ports:
    - port: 80
      targetPort: 80
After apply, check kubectl get svc to see the assigned EXTERNAL-IP from the cloud provider.
ExternalName example
apiVersion: v1
kind: Service
metadata:
  name: external-db
spec:
  type: ExternalName
  externalName: my.database.example.com
