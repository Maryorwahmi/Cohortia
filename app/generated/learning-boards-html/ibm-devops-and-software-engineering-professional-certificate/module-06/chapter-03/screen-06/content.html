Service types compared
When to use ClusterIP, NodePort, or LoadBalancer.
ClusterIP
Internal-only access. Use for backend services and internal APIs.
NodePort
Exposes service on each node's IP at a static port for external testing. NodePort is handy for minikube or quick tests.
LoadBalancer
Requests a cloud provider load balancer and public IP. Use for production public services on supported clouds.
NodePort example
spec:
  type: NodePort
  ports:
    - port: 80
      targetPort: 80
      nodePort: 30080
Access via http://<NodeIP>:30080 for testing.
Decision guide
  • Need internal only → ClusterIP.
  • Local external access for testing → NodePort.
  • Public, cloud-backed IP → LoadBalancer.
