Process Flow
Expose a Deployment: ClusterIP then NodePort
A tested sequence for internal verification and external testing.
  1. Apply the Deployment with labels app: my-web-app and containerPort: 5678.
  2. Create a ClusterIP Service mapping port 80 → targetPort 5678 and apply it.
  3. Run a temporary busybox Pod and curl the Service DNS name to verify response.
  4. Delete ClusterIP, create NodePort with nodePort: 30080 and apply it.
  5. Find Node IP, then access http://<NodeIP>:30080 to test externally.
Example commands
Use kubectl apply -f my-web-app-deployment.yaml and kubectl apply -f my-web-app-clusterip-service.yaml, then kubectl run busybox --image=busybox --restart=Never -- /bin/sh to test inside the cluster.
ClusterIP Service example
apiVersion: v1
kind: Service
metadata:
  name: my-web-app-clusterip-service
spec:
  selector:
    app: my-web-app
  ports:
    - protocol: TCP
      port: 80
      targetPort: 5678
  type: ClusterIP
Testing tips
  • Use kubectl exec or a temporary busybox Pod to test ClusterIP services from inside the cluster.
  • Use minikube service or the node IP plus nodePort to test NodePort externally.
