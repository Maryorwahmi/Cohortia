my-web-app walkthrough
A compact lab to deploy and expose a simple web app.
Deployment YAML (summary)
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-web-app-deployment
  labels:
    app: my-web-app
spec:
  replicas: 2
  template:
    metadata:
      labels:
        app: my-web-app
    spec:
      containers:
      - name: my-web-app-container
        image: hashicorp/http-echo:latest
        args: ["-text", "Hello from Cohortia Web App!"]
        ports:
        - containerPort: 5678
ClusterIP Service
apiVersion: v1
kind: Service
metadata:
  name: my-web-app-clusterip-service
spec:
  selector:
    app: my-web-app
  ports:
    - port: 80
      targetPort: 5678
  type: ClusterIP
NodePort Service (external test)
apiVersion: v1
kind: Service
metadata:
  name: my-web-app-nodeport-service
spec:
  selector:
    app: my-web-app
  ports:
    - port: 80
      targetPort: 5678
      nodePort: 30080
  type: NodePort
