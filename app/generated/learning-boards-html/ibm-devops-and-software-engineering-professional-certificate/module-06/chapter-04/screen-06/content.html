Module 6 › Chapter 6.4 › emptyDir Example
Code walkthrough

This YAML creates a Pod that writes timestamps to /data using an emptyDir volume. Apply it, inspect the file, then delete the Pod and re-create it to observe data loss on Pod deletion.

apiVersion: v1
kind: Pod
metadata:
  name: my-pod-with-emptydir
spec:
  containers:
  - name: my-container
    image: busybox
    command: ["/bin/sh", "-c", "while true; do echo $(date) >> /data/log.txt; sleep 5; done"]
    volumeMounts:
    - name: my-emptydir-volume
      mountPath: /data
  volumes:
  - name: my-emptydir-volume
    emptyDir: {}
Practical check
After apply: kubectl exec into the Pod and cat /data/log.txt. Then kubectl delete pod my-pod-with-emptydir and recreate. The file will be gone after Pod deletion.
When to use
Temporary caches, build artifacts, and inter-container file sharing within the same Pod.
Watch out
Not durable across Pod deletion or node reschedule. Do not use for critical data.
Key Takeaway
emptyDir is simple and fast but ephemeral—choose PV/PVC for durability.
