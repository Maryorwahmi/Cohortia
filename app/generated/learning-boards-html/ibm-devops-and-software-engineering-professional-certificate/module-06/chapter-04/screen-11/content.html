What a StorageClass does

Defines how to dynamically provision storage: selects a provisioner, performance tier, and parameters. PVCs referencing a class trigger PV creation without manual admin steps.

  • Automates PV provisioning based on the requested class.
  • Useful in cloud environments and Minikube with a default class.
  • Choose class to match performance, availability, and reclaim policy.
Example usage
Create a PVC with storageClassName: standard and watch the provisioner create a PV on demand.
Reclaim policy
Delete removes cloud disks on PVC delete. Retain keeps disks for manual cleanup. Choose based on backup strategy.
Key Takeaway
StorageClasses are the preferred way to provision PVs automatically and consistently in cloud environments.
