Module 6 › Chapter 6.4 › Kubernetes Volumes
What is a Volume?

A directory mounted into a Pod that containers can access. Some volumes are pod-scoped; others are backed by cluster storage that outlives Pods.

  • Pod-scoped volumes are created with the Pod and usually removed with it.
  • Cluster-backed volumes like PVs are independent resources and persist beyond Pod deletion.
  • Choice affects scheduling, portability, and durability.
Example decision

Use emptyDir for a cache shared by sidecars. Use a PVC for a database that must keep its files after a Pod is replaced.

Volume types snapshot
emptyDir: Pod-lifetime. hostPath: node filesystem. PV/PVC: cluster-level durable storage.
Common mistake
Assuming all mounted Volumes are durable. Verify the backing resource before relying on data persistence.
Key Takeaway
Match volume lifetime to data durability requirements: pod-scoped for transient, PV-backed for durable needs.
