Module 6 › Chapter 6.4 › hostPath
Code example

This YAML mounts a directory from the node into the Pod. Useful for node-level tasks but dangerous for production data that must be highly available.

apiVersion: v1
kind: Pod
metadata:
  name: my-pod-with-hostpath
spec:
  containers:
  - name: my-container
    image: busybox
    command: ["/bin/sh", "-c", "tail -f /var/log/nginx/access.log"]
    volumeMounts:
    - name: host-log-volume
      mountPath: /var/log/nginx
  volumes:
  - name: host-log-volume
    hostPath:
      path: /var/log/nginx
      type: DirectoryOrCreate
Operational caveat
hostPath binds workload to a node. If the node fails, the data stays on that node and becomes inaccessible to Pods that reschedule elsewhere.
When to use
Local node tools, device access, or debugging—but not scalable persistence.
Key Takeaway
Prefer PVs for resilient storage; use hostPath only for node-local needs and with caution.
