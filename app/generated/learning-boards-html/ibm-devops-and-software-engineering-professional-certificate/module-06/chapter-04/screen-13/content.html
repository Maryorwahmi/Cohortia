Module 6 › Chapter 6.4 › Key Concepts
Volume
A directory for containers in a Pod; often pod-scoped and not durable after Pod deletion.
PV & PVC
PVs are cluster storage resources; PVCs request storage. StorageClasses can automate provisioning.
StatefulSet
Use when you need stable hostnames, per-pod volumes, and ordered lifecycle management.
Summary takeaway

Design storage around durability needs: temporary caches use emptyDir, node tasks can use hostPath with caution, and durable cluster storage should use PV/PVC and StorageClasses; choose StatefulSets when identity and stable per-replica storage are required.
