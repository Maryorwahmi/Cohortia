Deployment: declarative controller

Declare how many replicas you want and the Pod template. The Deployment manages ReplicaSets which maintain those Pods.

Plan
Deployment declares desired replicas and Pod template.
Engine
ReplicaSet observes Deployment and ensures the right number of Pods exist.
Update
Changing the template creates a new ReplicaSet and triggers a rolling update.
Selector mismatch pitfall

If selector.matchLabels does not exactly match template.metadata.labels, the Deployment will not manage the Pods it creates. Verify labels carefully.

Resource guidance

Always specify resources.requests and resources.limits to prevent resource contention in shared clusters.
