Module 6 › Chapter 6.2 › Scaling a Deployment
Scaling options
Imperative
kubectl scale deployment nginx-deployment --replicas=5
Quick operational change for immediate scaling.
Declarative
# edit replicas: 5 in yaml
kubectl apply -f nginx-deployment.yaml
Preferred for reproducibility and version control.
Key Takeaway

Scaling changes desired replica count; readiness and scheduler decisions determine when new Pods actually serve traffic.
