Module 6 › Chapter 6.2 › nginx-deployment.yaml walkthrough
YAML manifest
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
  labels:
    app: nginx
spec:
  replicas: 3 # We want 3 instances of our Nginx Pod
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:latest # Use the latest Nginx image
        ports:
        - containerPort: 80
Explanation
  • apiVersion: apps/v1 is the common API used for Deployments.
  • replicas: Number of Pod replicas to maintain.
  • selector/template labels: These must match so the Deployment can manage the Pods.
  • image: Pin to a version in production; latest can cause unpredictable updates.
  • containerPort: Exposes the container's port inside the Pod network.
Key Takeaway

Write clear selectors and templates, pin image versions, and keep manifests declarative so kubectl apply produces consistent results.
