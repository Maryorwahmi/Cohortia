Module 6 › Chapter 6.2 › Common Mistakes
Raw Pods vs Deployments

Raw Pods are ephemeral and unmanaged. Use Deployments for healing, scaling, and updates.

Selector mismatch

Ensure selector.matchLabels exactly equals template.metadata.labels to let Deployments manage Pods.

Image pinning

Avoid using latest in production; pin image versions for reproducible deployments.

Resource limits

Set requests and limits to prevent resource contention in shared clusters.

Warning

Neglecting these safety notes leads to outages, unpredictable versions, and hard-to-debug failures. Validate and test changes in staging before production.
