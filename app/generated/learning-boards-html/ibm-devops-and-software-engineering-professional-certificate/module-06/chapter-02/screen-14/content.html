Module 6 › Chapter 6.2 › Key Concepts
Pod
Smallest deployable unit; ephemeral and may contain multiple containers sharing network and storage.
Deployment
Declarative controller that manages ReplicaSets to ensure desired replica count and rolling updates.
ReplicaSet
Ensures a stable set of Pod replicas; typically managed by Deployments.
Summary
Design for ephemeral Pods, use Deployments for availability and updates, and validate changes with kubectl commands.
