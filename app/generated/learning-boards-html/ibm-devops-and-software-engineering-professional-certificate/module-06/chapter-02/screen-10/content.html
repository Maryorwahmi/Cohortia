Module 6 › Chapter 6.2 › Rolling Updates
Update commands
# Update image in yaml then:
kubectl apply -f nginx-deployment.yaml
kubectl rollout status deployment/nginx-deployment
kubectl rollout history deployment/nginx-deployment
Safety notes
  • Pin image versions for reproducible updates.
  • Monitor readiness probes so only healthy Pods receive traffic.
  • Use rollout history to enable safe rollbacks if the new revision fails.
