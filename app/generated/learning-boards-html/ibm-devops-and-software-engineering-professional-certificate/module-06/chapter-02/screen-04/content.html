Module 6 › Chapter 6.2 › What is a Pod?
Definition

Pod — smallest deployable unit

A Pod runs one or more containers that share network and storage. Treat Pods as replaceable; do not rely on their IP or local storage for long-term data.

Example
Web app container + logging sidecar sharing a volume and localhost communication.
Common misconception
Treating a Pod IP or container file system as stable; Pods are recreated, so use volumes and services for stable access.
Annotated details
  • Shared network: Containers in a Pod share an IP and can reach each other over localhost.
  • Shared storage: Volumes mounted into a Pod provide persistence across container restarts within the Pod.
  • Ephemeral lifecycle: Pods can be created and destroyed; controllers recreate new Pods rather than repairing the same Pod object.
Key Takeaway

Design for Pod replacement: use services for stable network identity and volumes for persistent data.
