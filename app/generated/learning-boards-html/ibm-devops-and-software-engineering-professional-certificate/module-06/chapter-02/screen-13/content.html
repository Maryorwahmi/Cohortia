Module 6 › Chapter 6.2 › Lab: my-web-app
Starter manifest
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-web-app-deployment
  labels:
    app: my-web-app
spec:
  replicas: 2 # Start with 2 replicas
  selector:
    matchLabels:
      app: my-web-app
  template:
    metadata:
      labels:
        app: my-web-app
    spec:
      containers:
      - name: my-web-app-container
        image: hashicorp/http-echo:latest # A simple HTTP echo server
        args: ["-text", "Hello from Cohortia v1!"]
        ports:
        - containerPort: 5678
Lab steps
  1. Create the YAML file and run kubectl apply -f my-web-app-deployment.yaml.
  2. Verify resources: kubectl get deployments and kubectl get pods -l app=my-web-app.
  3. Scale: kubectl scale deployment my-web-app-deployment --replicas=4.
  4. Update the args text and kubectl apply to trigger a rolling update.
  5. Check rollout status and history, then rollback if needed.
  6. Clean up with kubectl delete -f my-web-app-deployment.yaml.
