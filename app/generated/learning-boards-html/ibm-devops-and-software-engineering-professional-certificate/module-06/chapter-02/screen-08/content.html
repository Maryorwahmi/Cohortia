Module 6 › Chapter 6.2 › kubectl apply & inspect
Commands
kubectl apply -f nginx-deployment.yaml
kubectl get deployments
kubectl get replicasets
kubectl get pods
Watch the resources appear in this order: Deployment → ReplicaSet → Pods. Use label selectors to filter outputs.
Troubleshooting
kubectl describe pod <pod-name>
kubectl logs <pod-name>
kubectl rollout status deployment/nginx-deployment
Use describe to read events like failed scheduling or image pull issues. Logs show container output for runtime errors.
