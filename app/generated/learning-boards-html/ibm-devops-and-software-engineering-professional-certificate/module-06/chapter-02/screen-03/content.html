How you'll prove your work

Concrete commands and validations used during the hands-on activity.

Apply & Inspect
kubectl apply -f my-web-app-deployment.yaml
kubectl get deployments
kubectl get pods -l app=my-web-app
Scale & Update
kubectl scale deployment my-web-app-deployment --replicas=4
kubectl apply -f my-web-app-deployment.yaml
kubectl rollout status deployment/my-web-app-deployment
Troubleshoot
kubectl describe pod <pod-name>
kubectl logs <pod-name>
Safe Practice

Validate YAML with a dry-run and pin image versions instead of using latest to ensure reproducible deployments.
