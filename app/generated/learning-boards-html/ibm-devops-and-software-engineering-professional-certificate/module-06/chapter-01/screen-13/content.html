Module 6 › Chapter 6.1 › What to Remember
Confirm connectivity
Run kubectl version and cluster-info before any changes.
Manifests as code
Store YAML manifests in version control and prefer declarative deployments.
Map outputs to architecture
Use kubectl outputs to decide whether issues are control plane, node, or Pod related.
Final takeaway

These simple habits—verify connectivity, use declarative manifests, and interpret kubectl output—will make your first experiences with Kubernetes safer and more effective.
