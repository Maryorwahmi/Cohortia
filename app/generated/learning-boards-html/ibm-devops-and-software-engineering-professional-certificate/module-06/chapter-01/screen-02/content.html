Learning Objectives

Learn, Understand, Apply, Master
Bloom: Learn → Understand → Apply → Master
01
Explain orchestration need
Describe why manual container management breaks at scale and how orchestration automates deployment, scaling, and recovery.
Verified competency milestone
02
Identify cluster components
Distinguish control plane roles from worker node roles and map names like API Server, etcd, kubelet, and kube-proxy to their responsibilities.
Verified competency milestone
03
Understand declarative configuration
Explain how declaring desired state differs from imperative commands and why reconciliation and self-healing follow from that model.
Verified competency milestone
04
Use kubectl for inspection
Run commands like version, cluster-info, get nodes, and list kube-system Pods to verify connectivity and locate control plane services.
Verified competency milestone
