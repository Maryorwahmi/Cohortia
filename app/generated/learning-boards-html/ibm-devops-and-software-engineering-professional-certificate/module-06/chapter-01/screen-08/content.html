Module 6 › Chapter 6.1 › Declarative vs Imperative
Declarative

Describe desired state

Write manifests that declare the intended number of replicas, images, and configuration. Kubernetes continuously reconciles cluster state to match these manifests.

Example
A Deployment manifest declaring three replicas will be enforced by controllers so three Pods remain running.
Imperative

Tell the system how

Run command sequences to create or modify resources. Useful for quick experiments but prone to drift when not recorded as code.

Pitfall
Imperative edits applied manually are hard to reproduce and complicate rollbacks and auditing.
Check: Use imperative commands for testing and the declarative model for production manifests stored in version control to ensure reproducibility and safe rollouts.
