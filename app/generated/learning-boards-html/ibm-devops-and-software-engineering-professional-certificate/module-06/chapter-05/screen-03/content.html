Practice & Assessment

Each objective links to a concrete practice and a short assessment so you can verify competency.

Practice: Inventory what a provider manages

Write a short list comparing responsibilities in a self-managed cluster versus a managed service. Assessment: multiple-choice question on control-plane ownership.

Practice: Feature matrix

Create a one-page matrix comparing integration with IAM, storage, logging, and enterprise tooling for IKS, EKS, AKS, and GKE. Assessment: short rubric-based review.

Practice: CI/CD image update

Implement a pipeline step that builds and pushes a Docker image, then runs a kubectl set image and checks rollout. Assessment: pipeline log and rollout output.

Practice: Security & cost checklist

Create a checklist for least-privilege IAM, secrets, quotas, and image scanning. Assessment: peer review of the checklist.

Key Takeaway

Practice with a small real or simulated pipeline update to build confidence and generate evidence you can review during assessments.
