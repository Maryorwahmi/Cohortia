Module 6 › Chapter 6.5 › Monitoring & Image Security
Observability Essentials
Logs, metrics, health probes, and image checks
What to collect
  • Application logs and structured traces.
  • Cluster metrics (CPU, memory, pod counts).
  • Events and health probe statuses.
  • Image vulnerability reports from CI before push.
Investigation commands
kubectl logs -l app=my-app --since=10m
kubectl get events --sort-by=.metadata.creationTimestamp
kubectl rollout history deployment/my-app-deployment
CI integration
Add a build stage that fails promotion when an image scan reports critical vulnerabilities. Block deployment until issues are fixed to avoid pushing risky images to production.
Misconception
Collecting more logs without structured analysis and alerts often delays detection. Instrument key metrics and set actionable alerts.
Key Takeaway

Observability plus pre-deploy image checks reduce risk and speed diagnosis when incidents occur.
