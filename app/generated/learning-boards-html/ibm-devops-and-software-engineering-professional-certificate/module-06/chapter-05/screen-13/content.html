Comparing portability choices
Managed convenience
  • Faster provisioning and upgrades.
  • Built-in integrations like load balancers and IAM.
  • Lower operational overhead for the control plane.
Portability cost
  • Provider APIs or storage classes may be non-portable.
  • Migration requires mapping provider features to alternatives.
  • Testing migration pathways is essential.
Practical pattern
Keep application manifests, Helm charts, and IaC in Git. Isolate cloud-specific pieces in overlays or Helm values so a single substitution can adapt deployments for another provider.
Example
Store a generic storage class in manifests and maintain a provider-specific values file that maps to the provider's storage class name during deployment.
Key Takeaway

Balance the convenience of managed services with design patterns that make replacing provider-specific pieces straightforward.
