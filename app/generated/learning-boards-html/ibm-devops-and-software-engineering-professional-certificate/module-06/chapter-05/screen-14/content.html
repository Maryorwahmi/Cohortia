Module 6 › Chapter 6.5 › Key Concepts
Managed Kubernetes Service
A cloud offering where the provider manages the control plane, reducing operational overhead for your team.
CI/CD Pipeline
An automated workflow that builds, tests, and deploys applications to a target environment.
Helm
A package manager for Kubernetes that helps define, install, and upgrade applications as charts.
Summary

These tools and practices work together: managed clusters give you reliable control planes, CI/CD delivers tested artifacts, and Helm or templates manage release configuration.
