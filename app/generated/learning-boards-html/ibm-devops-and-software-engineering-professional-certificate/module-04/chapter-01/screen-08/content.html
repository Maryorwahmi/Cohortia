Test types and purpose

  • Unit tests: fast, validate single functions or classes.
  • Integration tests: verify multiple components working together.
  • Acceptance tests: simulate user journeys and business rules.
  • Smoke tests: quick health checks after deployment.
Tip: Run unit tests on every commit and schedule longer integration suites on push to main to balance speed and coverage.
Concrete example
Price calculation
Unit test asserts expected totals. Integration test calls pricing API with test DB to verify real interactions.
Misconception
Misbelief
High coverage alone is not safety; tests must be meaningful, deterministic, and maintained to be effective.
