Pipeline stages (numbered)

  1. Source Control: commits trigger pipelines and provide traceability.
  2. Build: compile or assemble artifacts like Docker images.
  3. Unit Tests: fast checks for logic correctness.
  4. Integration / Acceptance Tests: verify component interactions.
  5. Package / Artifact Creation: produce immutable deployables.
  6. Deploy to Staging: run production-like validations.
  7. Production Promotion: manual or automatic deployment to live users.
Tip: Track stage duration and flakiness; long-running or flaky stages are the usual bottlenecks.
Concrete example: Flask app
Build step
Create Docker image, install dependencies, run lint.
Test steps
Unit tests for business logic, integration tests against test DB, health checks.
Key Takeaway

Organize stages to fail fast and keep deployable artifacts immutable for traceability and rollback.
