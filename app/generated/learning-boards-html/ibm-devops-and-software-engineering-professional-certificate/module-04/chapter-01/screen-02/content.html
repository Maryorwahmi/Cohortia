Learning Objectives

Learn the what, why, and how of CI/CD for reliable releases
Bloom: Learn → Understand → Apply → Master
01
Explain CI and CD benefits

Describe how automation shortens feedback loops and lowers release risk. You will be able to cite speed and reliability as tangible outcomes.

VERIFIED COMPETENCY MILESTONE
02
Differentiate CI, CD, CDP

Identify which parts of the release path are automated and which require manual gates, with examples of when each model fits.

VERIFIED COMPETENCY MILESTONE
03
Identify pipeline components

Map stages from source control to artifact to staging and production, and explain the purpose of each stage.

VERIFIED COMPETENCY MILESTONE
04
Recognize anti-patterns

Spot broken pipelines, over-automation, and security gaps and know pragmatic fixes to restore trust in automation.
