Definition

Post-deployment Health Check

A programmatic check that validates production health and gates pipeline success.

Why it matters

It gives the pipeline an automated signal about the real runtime state of the application, enabling immediate rollback when necessary.

Tip
Keep checks fast and deterministic; long-running checks block the pipeline and increase risk windows.
Example script
HEALTH_STATUS=$(curl -s -o /dev/null -w "%{http_code}" http://my-app-production.com/health)
if [ "$HEALTH_STATUS" -ne 200 ]; then
  echo "Health check failed! Status: $HEALTH_STATUS"
  exit 1 # Trigger rollback
fi
echo "Health check passed."
This snippet fails the pipeline on non-200 responses, allowing a rollback stage to run automatically.
