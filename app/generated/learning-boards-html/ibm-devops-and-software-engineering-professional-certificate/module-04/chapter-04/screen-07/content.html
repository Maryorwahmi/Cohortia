Architecture

Blue/Green Deployments

Duplicate environments and a traffic switch for instant rollback.

Flow
  1. Provision Green environment identical to Blue.
  2. Run full validation and smoke tests on Green.
  3. Switch traffic to Green when validation passes.
  4. Switch back to Blue instantly if issues are detected.
Trade-off
Offers instant rollback but requires duplicate capacity during cutover.
Concrete scenario
Deploy a payment service upgrade to Green, run payments smoke tests, then switch traffic if Green passes. If errors appear, revert routing to Blue immediately.
Key takeaway
Blue/Green minimizes user impact when you need an atomic cutover and a simple rollback plan.
