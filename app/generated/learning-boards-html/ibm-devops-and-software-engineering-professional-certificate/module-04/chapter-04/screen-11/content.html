Automated Rollbacks

When checks fail, the pipeline must revert to the last known good state automatically.

Trigger sources
  • Health check failures returned by the pipeline script.
  • Monitoring alerts for error spikes or latency regressions.
  • Automated canary failures detected by objective metrics.
Practice
Run rollback drills regularly to ensure runbooks and automation behave under pressure.
Example rollback
echo "Deployment failed, initiating rollback..."
kubectl rollout undo deployment/my-app-production-deployment
echo "Rollback initiated."
This command returns the deployment to the previous ReplicaSet; combine with observability to automate the trigger.
