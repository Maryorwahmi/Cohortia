Module 4 › Chapter 4.3 › kubectl & image policies
Process Flow

Apply, validate, observe

1. Ensure cluster
Provision staging via IaC and confirm cluster access.
2. Apply manifests
kubectl apply -f my-app-staging.yaml to create deployment and service.
3. Validate
kubectl get pods/services and check readiness and health probes before proceeding.
Local note: imagePullPolicy: Never lets you use locally built images without pushing to a registry. For shared staging, push images and reference immutable tags.
Commands reference
# Apply the manifest
kubectl apply -f my-app-staging.yaml

# Check deployments and pods
kubectl get deployments -l env=staging
kubectl get pods -l env=staging
Key Takeaway

After applying manifests, always validate environment health before moving to approval. Select imagePullPolicy based on where your image lives.
