Activity: Deploy to local Kubernetes

Follow these steps to simulate a staging deployment using your locally built Docker image.

Prerequisites
Docker Desktop with Kubernetes or Minikube, kubectl, and a built image my_flask_app:latest.
Create manifest
Create flask-app-staging-deployment.yaml with Deployment and Service definitions; set imagePullPolicy: Never for local images.
Apply and verify
kubectl apply -f flask-app-staging-deployment.yaml then kubectl get deployments/services/pods -l env=staging.
Access the app
Use minikube service --url or kubectl port-forward to reach the app on localhost for UAT.
Key Takeaway

This lab shows how CD uses kubectl to deploy the CI-built artifact to staging. Validate the deployment and match image policies to your environment.
