Module 4 › Chapter 4.3 › Common mistakes
Warnings & Mitigations
Inconsistent environments
Use IaC and containers to keep staging and production aligned.
Hardcoding configs
Inject configs at deploy time and store secrets in a manager.
Neglecting staging tests
Run UAT, performance, and security scans in staging before approval.
No rollback strategy
Keep prior artifacts and scripted rollback steps; test rollback paths.
Insufficient monitoring
Ensure staging has observability so issues are detected before approval.
Key Takeaway

Apply IaC, separate secrets, run robust staging tests, define rollback steps, and instrument monitoring to make staging a reliable safety net.
