Module 4 › Chapter 4.3 › Config vs Secrets
Comparison
Environment variables
Used for non-sensitive values like DATABASE_URL and logging levels; injected per environment by the CD pipeline.
Secrets
Use a secret manager or Kubernetes Secrets for credentials and API keys. Reference them in manifests instead of inlining.
Practical example
In the Kubernetes manifest, DATABASE_URL is provided as an environment variable and API_KEY uses valueFrom.secretKeyRef to reference a named secret created in the cluster for staging.
Misconception
Putting secrets in source-controlled manifests or images avoids best practices; it also prevents secret rotation and auditing.
Key Takeaway

Inject non-sensitive configs as variables and manage secrets with a dedicated secret store, referenced at deploy time for security and flexibility.
