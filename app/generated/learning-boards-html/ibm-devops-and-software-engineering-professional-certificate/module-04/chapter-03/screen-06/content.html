Code Walkthrough

Pull the exact image produced by CI

# Example: Pulling a Docker image from a registry in a CD pipeline
docker pull myregistry.com/my_app:v1.2.3-abcd123

# Verify digest matches the CI-recorded digest
docker inspect --format='{{index .RepoDigests 0}}' myregistry.com/my_app:v1.2.3-abcd123
Use the exact tag or digest passed from CI. Do not rely on mutable tags or local rebuilds when deploying to staging.
Practical notes
  • Pass artifact identifiers from CI to CD via pipeline variables or build metadata.
  • Verify the pulled artifact digest against the CI-recorded digest before deployment.
  • Use secure access to the registry with credentials stored in secret managers.
Key Takeaway

Treat the registry pull and digest check as the trust boundary between CI and CD. If they don't match, stop the deploy.
