Module 4 › Chapter 4.2 › What is Continuous Integration?
Definition
Continuous Integration automates building and verifying code on every commit so integration issues are found early.
Why it helps: prevents integration drift and provides quick developer feedback.
Team habit: fix broken builds promptly to preserve CI value.
Misconception: CI is a tool only; in fact it's a practice plus automation.
Key Takeaway

CI combines automation and team discipline to keep integration predictable and fast.

Concrete Example
A developer commits a change. The CI server runs a build and unit tests. If a test fails, the pipeline marks the build broken and the team is alerted. The image or package is not promoted until tests pass.
Quick checklist
  • Run dependency install and build automatically.
  • Execute unit tests and block progression on failure.
  • Store artifacts with a version tied to a commit.
