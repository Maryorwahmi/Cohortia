Module 4 › Chapter 4.2 › Unit Tests vs Integration Tests
Unit Tests
Fast, isolated, and run on every commit. Use mocks and fixtures to test small units of behavior.
Speed: seconds per run
Scope: single function or class
Value: immediate developer feedback
Integration Tests
Verify interactions between components, such as services, databases, and external APIs. Tend to be slower and more brittle if not well isolated.
Speed: slower, often minutes
Scope: multiple components working together
Value: catches interaction-level failures
Misconception: running all integration tests on every push improves quality. In practice, it slows feedback. Instead, run a focused integration suite where it brings most value.
