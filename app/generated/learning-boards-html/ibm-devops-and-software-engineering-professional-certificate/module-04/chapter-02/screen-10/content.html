Module 4 › Chapter 4.2 › Build Artifacts & Repos
Artifact Types
Docker images
JAR/WAR files
Compiled executables
Store these artifacts in a repository. Tag artifacts with commit hashes or semantic versions so you can trace what was tested and deployed.
Misconception: rebuilding on deploy yields the same artifact. In reality, rebuilds can differ due to floating dependency versions or changed build tools. Instead, deploy the artifact produced by CI.
Repository Practices
  • Use an authenticated registry to store images.
  • Keep immutable tags for deployed artifacts.
  • Keep metadata linking artifact to commit hash and pipeline run.
Key Takeaway

Treat artifacts as primary deliverables and store them where they can be promoted and traced reliably.
