Module 4 › Chapter 4.2 › Static Code Analysis
What it does
  • Detects potential bugs and security patterns without execution.
  • Measures code complexity and style adherence.
  • Gives maintainability and security insights to act on early.
Start in report mode to tune rules. Failing the build immediately is an option after you calibrate severity thresholds and remove noise.
Example command
Run ESLint in CI as shown in the chapter:
npm install eslint
npx eslint . --format compact
If using SonarQube, upload a scanner report and consult the dashboard for quality gates that can pass or fail the pipeline.
