Module 4 › Chapter 4.2 › Troubleshooting CI Failures
Diagnostic Steps
  1. Locate the failed pipeline stage and note the exit code.
  2. Read the error lines in the log focusing on the first failure message.
  3. Try to reproduce the failing command locally inside a container matching CI.
  4. Check for missing environment variables, pinned versions, or network access issues.
  5. Fix CI configuration, rerun, and verify tests pass before merging.
Example common cause: "Dependency not found"—the CI environment needs explicit installation of that dependency or a cache restoring it before the build step. Update the pipeline to install dependencies prior to compilation.
Example log snippet
ERROR: Could not find a version that satisfies the requirement requests==2.0.0 Command failed with exit code 1
Interpretation: the pipeline tried to install a specific package version that doesn't exist or cannot be fetched. Check requirements and package indexes used in CI.
