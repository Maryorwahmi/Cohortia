ci_script.sh (annotated)
The script illustrates three stages: build the Docker image, run tests in a container, and perform a placeholder static analysis.
#!/bin/bash
set -e # Exit immediately if a command exits with a non-zero status

echo "--- CI Pipeline Started ---"

echo "Building Docker image..."
docker build -t my_flask_app:latest ./my_flask_app

echo "Running tests..."
docker run --rm -v "$(pwd)/my_flask_app:/app" python:3.9-slim-buster /bin/bash -c "pip install Flask==2.3.3 pytest && pytest /app/test_app.py"

echo "Performing static analysis (placeholder)..."

echo "--- CI Pipeline Completed Successfully ---"
Note: set -e causes the script to stop on the first error so the CI system receives a failing exit code. Running tests in a container reduces environment differences between CI and local machines.
