Activity
Transform a monthly-release process
Culture
Joint planning and shared ownership for deployment criteria and incident response.
Automation
Automate builds and core tests to detect integration issues early and shorten release windows.
Lean & Measure
Map the flow, select lead time for changes as the primary metric, and run time-boxed experiments to reduce it.
Sharing
Create concise runbooks, hold post-release reviews, and publish action items for cross-team learning.
Suggested first experiment
Automate the build and core unit tests to run on each commit. Measure lead time for changes before and after the experiment.
Key Takeaway

Run small, measurable experiments that combine CALMS elements to produce observable improvements and learning.
